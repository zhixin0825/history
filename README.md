## 阅读范围

前800—前701年为一组，前700—前601年为下一组；公元1—100年为一组，101—200年为下一组。每组正好100个年号，不设0年。已写页数不等于某世纪已经完整覆盖，更不等于所有史书都已汇入。原有缺年、归年争议和待复核材料不因本次目录整理而消失。

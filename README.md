# 逐年读史

把不同史书写到的同一年，合在一张大白话页面里。读故事时能点回原文；史料有分歧，就在对应注脚交代采用哪种说法及理由。

仓库以编年阅读为中心，只保留三类目录：

| 目录 | 放什么 | 入口 |
|---|---|---|
| `sources/` | 二十四史等原文、版本材料与实际引用的摘录 | [史料目录](sources/README.md) |
| `years/` | 正常时期一年一页，按世纪分组；无法确年的上古材料按时期阅读 | [时间目录](years/README.md) |
| `meta/` | 编写规则、来源许可、纪年考证、引文去向 | [编写依据](meta/README.md) |

不为《汉书》《晋书》等另建独立编年子项目。同一事件在几本书里出现，只补充正文、原文和异说，不反复讲成几件事。

## 当前进度

**《史记》已按卷序完成卷001—010的阅读汇入，下一卷为011《孝景本纪》。** 卷010《孝文本纪》共43个工作单元：41个叙事、诏议与回顾单元，加太史公论和后附《索隐述赞》。编号不是事件数，也不是原书固有段号；后人注赞与司马迁原文分层。

本轮新增前178—158年之间原先缺少的20张年页（前168年已有），以及前156年，共21张。前180、179、168、157年四张既有正文合并补写，前132年只调整导航。卷010跳过的年份，以《汉书》《通鉴》有据年条连接；保留前168年黄河决口、前180年诛吕与少帝终局，不另建“文帝编年史”。

## 年份与材料怎么处理

年度正文按连续100年的世纪目录分类，公元前递减、公元后递增，没有0年。能确年的事件回到该年，未确年的前事在人物登场处说明，跨年过程不挤成同一年。

**秦汉古历年条与公历年界不完全重合。** 十月岁首，前206年文件的汉元年冬十月秦降通常仍属公历前207年；不把古月直接换成同号公历月份。[秦历与年页](meta/考证/史记-卷006-纪年与异说.md#秦历与年页)。文帝前后元年、相位异月、淮南王案远接及刑制边界见[卷010考证](meta/考证/史记-卷010-纪年与异说.md)。

上古年代参考夏商周断代工程及相应研究，保留约数和争议。诏令、颂辞、传说、史家评论与实际事件分层；原文摘录供阅读定位，不冒称不同点校本已经逐字校勘。

# 逐年读史

把不同史书写到的同一年，合在一张大白话页面里。读故事时能点回原文；史料有分歧，就在对应注脚交代采用哪种说法及理由。

仓库以编年阅读为中心，只保留三类目录：

| 目录 | 放什么 | 入口 |
|---|---|---|
| `sources/` | 二十四史等原文、版本材料与实际引用的摘录 | [史料目录](sources/README.md) |
| `years/` | 正常时期一年一页，按世纪分组；无法确年的上古材料按时期阅读 | [时间目录](years/README.md) |
| `meta/` | 编写规则、来源许可、纪年考证、引文去向 | [编写依据](meta/README.md) |

不为《汉书》《晋书》等另建独立编年子项目。同一事件在几本书里出现，只补充正文、原文和异说，不反复讲成几件事。

## 年份与材料怎么处理

年度正文按连续100年的世纪目录分类，公元前递减、公元后递增，没有0年。能确年的事件回到该年，未确年前事在人物登场处说明，跨年过程不挤成同一年。首次称元年未必等于本年首次受命，更不宜一律称作后世意义的年号。

**秦汉古历年条与公历年界不完全重合。** 十月岁首，前206年文件的汉元年冬十月秦降通常仍属公历前207年；不把古月换成同号公历月份。[秦历与年页](meta/考证/史记-卷006-纪年与异说.md#秦历与年页)。景帝三段纪年等见[卷011考证](meta/考证/史记-卷011-纪年与异说.md)。

上古参考夏商周断代工程及相应研究，保留约数和争议。诏令、颂辞、传说、史家评论与实际事件分层；原文摘录供定位，不冒称异本已经逐字校勘。

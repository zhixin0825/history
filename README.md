## 阅读范围与未完成处

前800—前701年为一组，前700—前601年为下一组；公元1—100年为一组，101—200年为下一组。每组正好100个年号，不设0年。已写页数不等于所有史事或所有史书已经汇入。

**《春秋／左传》还不能称为全部完成。** 当前主分支的襄公三十一年范围（前572—前542）未完整并入：其中仅前570、561、560、557、548、545、544七年有现存年度页，不能据此算经传整组完成；其余二十四年尚缺年页。可直接核对[前600—501年目录](years/bce-0600-0501/README.md)。推进到哀公末年不代表中间已无缺口，本次整理上古也没有消除这一缺口。

归年争议、未确年材料和旧版本中的待复核项继续保留；“整卷阅读完成”表示实质文字有去向，不等于逐项史实或逐字校勘全部完成。

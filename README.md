## 阅读范围与未完成处

前800—前701年为一组，前700—前601年为下一组；公元1—100年为一组，101—200年为下一组。每组正好100个年号，不设0年。已写页数不等于所有史事或所有史书已经汇入。

**《春秋／左传》逐年整理已补齐前722—前468年，共255张连续年页。** 本轮完成襄公三十一年、保留七张旧《史记》增量页的全部入口，并补核早期漏条与误读。原经到哀公十四年获麟为止，续经、后段传文另标范围，不把255年都称为《春秋》原经。[完成范围与核对记录](meta/记录/春秋-完整覆盖核对.md)。

归年争议、未确年材料和旧版本中的待复核项继续保留；“整卷阅读完成”表示实质文字有去向，不等于逐项史实或逐字校勘全部完成。

# 逐年读史

把不同史书写到的同一年，合在一张大白话页面里。读故事时能点回原文；史料有分歧，就在对应注脚交代采用哪种说法及理由。

仓库以编年阅读为中心，只保留三类目录：

| 目录 | 放什么 | 入口 |
|---|---|---|
| `sources/` | 二十四史等原文、版本材料与实际引用的摘录 | [史料目录](sources/README.md) |
| `years/` | 正常时期一年一页，按世纪分组；无法确年的上古材料按时期阅读 | [时间目录](years/README.md) |
| `meta/` | 编写规则、来源许可、纪年考证、引文去向 | [编写依据](meta/README.md) |

不为《汉书》《晋书》等另建独立编年子项目。同一事件在几本书里出现，只补充正文、原文和异说，不反复讲成几件事。

## 年份与材料怎么处理

正常年页按连续100年的世纪目录分类，公元前递减、公元后递增，没有0年。只有已写内容才建立页面；能确年的事件回到该年，未确年的早年经历在人物登场处说明，跨年过程不挤成同一年。

**秦汉古历年条与公历年界并不完全重合。** 秦历十月岁首；现有前206年文件对应“汉元年”，其中冬十月子婴投降按公历年界通常归前207年，相关年页明确提示，不把古月直接换成同号公历月份。详见[秦历与年页](meta/考证/史记-卷006-纪年与异说.md#秦历与年页)。本轮对太上皇死葬、马邑与平城、称帝与改元等另有[逐项取舍](meta/考证/史记-卷008-纪年与异说.md)。

上古年代参考夏商周断代工程及相应研究，保留约数和争议；不把传说强行拆成伪精确的年度表。诏令、颂辞、神异故事、作者评论与实际事件分层呈现。原文摘录供阅读定位，不冒称完成了不同点校本的逐字校勘。

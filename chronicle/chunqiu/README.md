# 逐年读《春秋》与《左传》

这里先按鲁国十二公逐组完成，再连接成连续年表。每年一页。

原则：

- **《春秋》经文逐条用白话说明，不漏条。**
- **《左传》用于补足事情经过、前因后果和《春秋》为什么记／不记某事。**
- 不把《左传》的“君子曰”等评论冒充事件本身。
- 原文有日期、称谓或异文疑点时，直接保留，不为了叙事顺滑强行统一。
- 人物背景只交代到理解当年事件所必需的程度，不展开成长篇人物传。
- 每页链接到本项目保存的有标点经传原文和固定来源页面。

# 逐年读《春秋》与《左传》

这里按鲁国十二公逐组完成，再连接成连续年表。每年一页。**页面结构严格照用户上传 PDF 的层级：先列当年事件 outline，每条紧接白话细节，并用 [n] 对到页尾“本年相关史料”；不再把《春秋》和《左传》拆成两套叙述。**

## 页面结构

1. **一句话 outline。** 先让读者知道发生了什么。
2. **紧接着补细节。** 把《左传》提供的前因、经过、结果直接并进同一条，不另开“《左传》补充”章节。
3. **条末用 [n] 标出处。** 与页尾同号“本年相关史料”一一对应。
4. **本年相关史料。** 集中列出《春秋》《左传》的对应原文；完整有标点原文另有固定链接。

## 编辑规则

- 《春秋》经文有记载的事项不漏；《左传》中对理解当年政治、战争、外交和因果关系重要的独有记载，也作为正常年度条目进入 outline。
- 史家评论与事件事实区分开；必要的评价放到对应史料下面，不在正文反复交代“哪本书怎么评价”。
- 原文有日期、地点、称谓或异文冲突时，正文先保持中性叙事；冲突放到页尾对应史料后的“说明”里，不为了页面顺滑强行统一。
- 人物背景只交代到理解当年事件所需的程度，不展开成长篇人物传。
- 每页链接到项目保存的有标点经传原文和来源页面。
- “完成”表示该组已经按上述模板做完第一轮可读整理，不等于完成现代学术校勘。

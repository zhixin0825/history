## 春秋经

<a id="cq-11-15-p001"></a>

### 1. 邾子来朝

春天王正月，邾子来鲁朝见。

[看对应原文](#source-cq-11-15-p001)

<a id="cq-11-15-p002"></a>

### 2. 郊牛被鼠咬死，改选祭牛

鼷鼠啃咬郊祭用牛，牛死了，鲁重新占卜选择另一头牛。

[看对应原文](#source-cq-11-15-p002)

<a id="cq-11-15-p003"></a>

### 3. 楚灭胡

二月辛丑，楚子灭胡，带走胡子豹。

[看对应原文](#source-cq-11-15-p003)

<a id="cq-11-15-p004"></a>

### 4. 五月郊祭

夏天五月辛亥，鲁举行郊祭。

[看对应原文](#source-cq-11-15-p004)

<details><summary>字句与编年说明</summary>

五月照原文，不为迁就通行祭季而改月。

</details>

<a id="cq-11-15-p005"></a>

### 5. 定公死于高寝

壬申，定公在高寝去世。

[看对应原文](#source-cq-11-15-p005)

<a id="cq-11-15-p006"></a>

### 6. 郑罕达伐宋

郑罕达率军攻宋。

[看对应原文](#source-cq-11-15-p006)

<a id="cq-11-15-p007"></a>

### 7. 齐卫驻渠蒢

齐侯、卫侯驻渠蒢。

[看对应原文](#source-cq-11-15-p007)

<a id="cq-11-15-p008"></a>

### 8. 邾子来奔丧

邾子到鲁奔丧。

[看对应原文](#source-cq-11-15-p008)

<a id="cq-11-15-p009"></a>

### 9. 姒氏去世

秋天七月壬申，姒氏去世。

[看对应原文](#source-cq-11-15-p009)

<a id="cq-11-15-p010"></a>

### 10. 八月日食

八月庚辰初一，发生日食。

[看对应原文](#source-cq-11-15-p010)

<a id="cq-11-15-p011"></a>

### 11. 滕子来会葬

九月，滕子来鲁参加葬礼。

[看对应原文](#source-cq-11-15-p011)

<a id="cq-11-15-p012"></a>

### 12. 雨使定公葬礼延迟

丁巳，原定安葬定公，却因下雨未能下葬。

[看对应原文](#source-cq-11-15-p012)

<a id="cq-11-15-p013"></a>

### 13. 次日才完成下葬

到戊午才办成安葬。

[看对应原文](#source-cq-11-15-p013)

<details><summary>字句与编年说明</summary>

时刻部分原文作“日下昊”，有疑字，暂不默改成“日下昃”后冒称原文无误。

</details>

<a id="cq-11-15-p014"></a>

### 14. 葬定姒

辛巳，安葬定姒。

[看对应原文](#source-cq-11-15-p014)

<a id="cq-11-15-p015"></a>

### 15. 筑漆城

冬天，鲁在漆筑城。

[看对应原文](#source-cq-11-15-p015)

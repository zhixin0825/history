# 公元前504年（鲁定公六年）

## 本年纪事

<a id="event-1"></a>

1. **郑国趁楚战败，攻灭许国。**

正月癸亥，郑国游速率军灭许，俘获许君斯。楚国刚遭吴军重创，无力像以往一样保护许国，郑国便乘此机会出兵。 [1](#note-1)

<a id="event-2"></a>

2. **定公替晋攻郑，返程过卫引发争执。**

二月，定公攻郑，取得匡地，替晋追究郑国进攻胥靡之事。鲁军去时未经卫国许可借道，返回时阳虎又令季、孟两家军队穿过卫城。卫侯派人追击，公叔文子劝他不要以一时冲突抹去此前援助鲁昭公的往来，卫侯才停止追击。定公随后返鲁。 [2](#note-2)

<a id="event-3"></a>

3. **季桓子、孟懿子赴晋，孟氏谈起阳虎的去向。**

夏季，季桓子赴晋献郑国俘虏。阳虎强令孟懿子一同前往，办理答谢聘币之事。晋国合并宴享二人，孟懿子向范献子提出，若阳虎日后不能留鲁而投晋，应给他中军司马一职；范献子没有应允。事后范献子向赵鞅解释，鲁人已经忧虑阳虎，孟氏知道他可能逃晋，才故意提出这种请求。 [3](#note-3)

<a id="event-4"></a>

4. **吴国接连击败楚军，楚国迁都鄀并调整政务。**

四月，吴太子终累击败楚国舟师，俘获多名大夫。楚国子期率领的陆军又在繁扬失利。子西利用这次危机推动调整，楚国将郢迁到鄀，重新安排政务，试图稳住战后局面。 [4](#note-4)

<a id="event-5"></a>

5. **儋翩联合郑国扰周，敬王再避居姑莸。**

王子朝虽然已死，儋翩仍率其党众，借郑国势力准备在周室起事。郑军攻冯、滑、胥靡等地，晋国六月派阎没驻周、修筑胥靡。到十二月，敬王为避乱迁居姑莸。 [5](#note-5)

<a id="event-6"></a>

6. **宋使乐祁在晋遭拘，范、赵之间的往来成为争端。**

八月，宋国乐祁建议按时出使晋国，景公便派他前往。乐祁的家宰陈寅预先劝他安排继承人。抵晋后，赵鞅在绵上迎他饮酒，乐祁又献六十面杨木盾。范献子以使者尚未完成国命便私宴为由，向晋侯提出追究，晋方拘捕乐祁。 [6](#note-6)

<a id="event-7"></a>

7. **阳虎再次迫鲁君与三桓盟誓。**

阳虎在周社与定公、三桓盟誓，又在亳社令国人盟誓，在五父之衢举行诅誓。控制不再只限季氏一家，而涉及国君、卿族与国人。 [7](#note-7)

<a id="event-8"></a>

8. **鲁国筑中城，又由季、孟率军围郓。**

冬季，鲁国修筑中城。季孙斯与仲孙何忌又率军围攻郓地，继续处理昭公流亡后留下的据点问题。 [8](#note-8)

> 二月，公侵郑取匡，为晋讨郑之伐胥靡也。往不假道于卫；及还，阳虎使季孟自南门入，出自东门，舍于豚泽。卫侯怒，使弥子瑕追之。公叔文子老矣，辇而如公，曰：“尤人而效之，非礼也。昭公之难，君将以文之舒鼎，成之昭兆，定之鞶鉴，苟可以纳之，择用一焉。公子与二三臣之子，诸侯苟忧之，将以为之质。此群臣之所闻也。今将以小忿蒙旧德，无乃不可乎？大姒之子，唯周公、康叔为相睦也。而效小人以弃之，不亦诬乎！天将多阳虎之罪以毙之，君姑待之，若何？”乃止。

**说明：** 此处匡为本条战地，不直接用来推定孔子后来“畏于匡”的全部经过。卫军最终未追战，不写成鲁卫已大战。

**《左传》·定公六年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0504.md#L35-L35)

> 夏，季桓子如晋，献郑俘也。阳虎强使孟懿子往报夫人之币。晋人兼享之。孟孙立于房外，谓范献子曰：“阳虎若不能居鲁，而息肩于晋，所不以为中军司马者，有如先君。”献子曰：“寡君有官，将使其人。鞅何知焉？”献子谓简子曰：“鲁人患阳虎矣，孟孙知其衅，以为必適晋，故强为之请，以取入焉。”

### [6] 宋使乐祁在晋遭拘，范、赵之间的往来成为争端。

**《春秋》·定公六年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0504.md#L21-L21)

> 秋，晋人执宋行人乐祁犁。

**《左传》·定公六年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0504.md#L41-L41)

> 秋八月，宋乐祁言于景公曰：“诸侯唯我事晋，今使不往，晋其憾矣。”乐祁告其宰陈寅。陈寅曰：“必使子往。”他日，公谓乐祁曰：“唯寡人说子之言，子必往。”陈寅曰：“子立后而行，吾室亦不亡。唯君亦以我为知难而行也。”见溷而行。赵简子逆而饮之酒于绵上，献杨楯六十于简子。陈寅曰：“昔吾主范氏，今子主赵氏，又有纳焉。以杨楯贾祸，弗可为也已。然子死晋国，子孙必得志于宋。”范献子言于晋侯曰：“以君命越疆而使，未致使而私饮酒，不敬二君，不可不讨也。”乃执乐祁。

**说明：** 乐祁又称乐祁犁、子梁。陈寅将此事联系宋原先亲范、现在亲赵的变化，作为他的分析保留；不可仅据盾牌馈赠就额外认定一项未载的贿赂罪。

# 公元前505年（鲁定公五年）

[上一年：前506](bce-0506.md) · [定公目录](../dinggong/README.md) · [春秋目录](../README.md) · [下一年：前504](bce-0504.md)

> 第一轮白话整理，附原文、异说与归年依据。古历月份不直接等同公历月份；段落覆盖不等于逐句翻译或现代学术校勘完成。

## 本年纪事

<a id="event-1"></a>

1. **周王使人到楚国杀王子朝。**

春季，周王一方派人在楚国杀死王子朝。此前王子朝携典籍奔楚，至此本人被杀，但留在周境的党众并未同时消失。 [1](#note-1)

<a id="event-2"></a>

2. **三月朔发生日食。**

三月辛亥朔，发生日食。 [2](#note-2)

<a id="event-3"></a>

3. **鲁国向蔡输送粮食。**

夏季，鲁国向蔡国送粮，救助其急需与物资不足。蔡国经历楚军围攻、向吴求援之后，仍需要外部接济。 [3](#note-3)

<a id="event-4"></a>

4. **越军趁吴军在楚，进入吴国。**

吴国主力仍在楚地，越军趁隙进入吴国。吴国因此同时面临占领区作战与后方受袭。 [4](#note-4)

<a id="event-5"></a>

5. **季平子去世，季氏家臣因丧葬用玉、人事礼遇起争执。**

六月，季孙意如巡视东野，返程未至家便死于房。阳虎打算用玙璠玉随敛，仲梁怀反对，两人发生冲突。季桓子继掌季氏后到费，费宰公山不狃又因仲梁怀失礼而不满，转向阳虎，支持对付仲梁怀。 [5](#note-5)

<a id="event-6"></a>

6. **秦军到楚参战，夫概一部遭击败。**

申包胥带秦援军抵达，子蒲、子虎统车五百乘。秦将先让楚军与吴接战，再会军，击败夫概部队。与此同时，吴军仍有俘获薳射的战果，薳射之子率逃散部众投子西，又在军祥击败吴军，战线并非一边倒。 [6](#note-6)

<a id="event-7"></a>

7. **秦楚灭唐，夫概返吴自立失败后投楚。**

七月，子期与秦将子蒲灭唐，打击曾助吴伐楚的一国。九月，夫概返回吴国，自立为王，与阖庐交战失败，转逃楚国，成为堂谿氏。 [7](#note-7)

<a id="event-8"></a>

8. **秦楚接连反攻，吴军退出楚国。**

吴军在雍澨取胜后，秦军又击败吴军。吴驻麇时，楚将子期主张火攻，子西担忧战地尚有己方遗骨，双方争辩后仍实施火攻。楚军随后在公壻之谿大败吴军，阖庐撤回。被吴拘获或带走的楚人有人逃归，其中也留下舆罢、后臧的返国故事。 [8](#note-8)

<a id="event-9"></a>

9. **叔孙成子去世。**

七月壬子，叔孙不敢去世，即此前迎昭公灵柩回鲁的叔孙成子。 [9](#note-9)

<a id="event-10"></a>

10. **阳虎拘季桓子、逐仲梁怀，以盟誓巩固控制。**

乙亥，阳虎拘禁季桓子与公父文伯，逐走仲梁怀。入冬后又杀公何藐，在稷门内迫季桓子盟誓，随后举行大诅，公父歜、秦遄等被逐往齐。盟誓后季桓子获释，季氏家臣对宗主的控制已公开化。 [10](#note-10)

<a id="event-11"></a>

11. **楚昭王返郢，酬报护从者，申包胥辞赏。**

昭王回到郢都，准备惩罚此前不肯借船的蓝尹亹，子西劝他不要重蹈囊瓦记怨之失，昭王改为复其原职。昭王赏斗辛、王孙由于等从亡人员，也包括一度想害他的斗怀；申包胥不愿以救国求己利，避开赏赐。季芈嫁给曾负她逃难的钟建，钟建任乐尹。 [11](#note-11)

<a id="event-12"></a>

12. **楚国恢复政务，子西与王孙由于争论各人所长。**

昭王逃难期间，子西曾暂借王者车服维持道路和据点秩序，知道昭王所在后才前往会合。恢复后，王孙由于受命修麇城，复命时答不出城墙高厚。子西责其不知任事，由于则展示护王时的伤痕，说明各有所能，自己并不擅长筑城。 [12](#note-12)

<a id="event-13"></a>

13. **晋国围鲜虞，报观虎被俘之役。**

冬季，士鞅率晋军围攻鲜虞，报复前507年平中战败、观虎被俘。 [13](#note-13)

### [8] 秦楚接连反攻，吴军退出楚国。

**《左传》·定公五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0505.md#L41-L41)

> 吴师败楚师于雍澨，秦师又败吴师。吴师居麇。子期将焚之，子西曰：“父兄亲暴骨焉，不能收，又焚之，不可。”子期曰：“国亡矣！死者若有知也，可以歆旧祀，岂惮焚之？”焚之而又战，吴师败。又战于公壻之谿，吴师大败，吴子乃归。囚舆罢。舆罢请先，遂逃归。叶公诸梁之弟后臧从其母于吴，不待而归。叶公终不正视。

### [11] 楚昭王返郢，酬报护从者，申包胥辞赏。

**《左传》·定公五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0505.md#L47-L47)

> 楚子入于郢。初，鬥辛闻吴人之争宫也，曰：“吾闻之，不让则不和，不和不可以远征。吴争于楚，必有乱。有乱则必归，焉能定楚？”王之奔随也，将涉于成臼，蓝尹亹涉其帑，不与王舟。及宁，王欲杀之。子西曰：“子常唯思旧怨以败，君何效焉？”王曰：“善。使复其所，吾以志前恶。”王赏鬥辛、王孙由于、王孙圉、钟建、鬥巢、申包胥、王孙贾、宋木、鬥怀。子西曰：“请舍怀也。”王曰：“大德灭小怨，道也。”申包胥曰：“吾为君也，非为身也。君既定矣，又何求？且吾尤子旗，其又为诸？”遂逃赏。王将嫁季芈，季芈辞曰：“所以为女子，远丈夫也。钟建负我矣。”以妻钟建，以为乐尹。

**说明：** 斗辛此前从吴将争宫判断其必有内乱，是回叙中的推测，不是本年新发生的吴宫争执。世家其他篇的鞭尸等故事未在本批无引添入。

### [12] 楚国恢复政务，子西与王孙由于争论各人所长。

**《左传》·定公五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0505.md#L49-L49)

> 王之在随也，子西为王舆服以保路，国于脾洩。闻王所在，而后从王。王使由于城麇，复命，子西问高厚焉，弗知。子西曰：“不能，如辞。城不知高厚小大，何知？”对曰：“固辞不能，子使余也。人各有能有不能。王遇盗于云中，余受其戈，其所犹在。”袒而视之背，曰：“此余所能也。脾洩之事，余亦弗能也。”

## 春秋经

<a id="cq-11-04-p001"></a>

### 1. 陈侯吴去世

春天王二月癸巳，陈侯吴去世。

[看对应原文](#source-cq-11-04-p001)

<a id="cq-11-04-p002"></a>

### 2. 十九方会召陵侵楚

三月，定公与刘子、晋侯、宋公、蔡侯、卫侯、陈子、郑伯、许男、曹伯、莒子、邾子、顿子、胡子、滕子、薛伯、杞伯、小邾子、齐国夏在召陵会合，侵入楚国。

[看对应原文](#source-cq-11-04-p002)

<details><summary>字句与编年说明</summary>

所有参与方保留；陈子处丧期的称谓不改为另一位陈侯。

</details>

<a id="cq-11-04-p003"></a>

### 3. 蔡灭沈并杀沈君嘉

夏天四月庚辰，蔡公孙姓率军灭沈，带走沈子嘉，后来将他杀死。

[看对应原文](#source-cq-11-04-p003)

<details><summary>字句与编年说明</summary>

公孙姓为姓名，不能把姓字当作等待补齐的姓氏标签。

</details>

<a id="cq-11-04-p004"></a>

### 4. 诸侯盟皋鼬

五月，定公与诸侯在皋鼬结盟。

[看对应原文](#source-cq-11-04-p004)

<a id="cq-11-04-p005"></a>

### 5. 杞伯成死于会中

杞伯成在会合期间去世。

[看对应原文](#source-cq-11-04-p005)

<a id="cq-11-04-p006"></a>

### 6. 葬陈惠公

六月，安葬陈惠公。

[看对应原文](#source-cq-11-04-p006)

<a id="cq-11-04-p007"></a>

### 7. 许迁容城

许国迁到容城。

[看对应原文](#source-cq-11-04-p007)

<a id="cq-11-04-p008"></a>

### 8. 定公自会回来

秋天七月，定公回鲁。

[看对应原文](#source-cq-11-04-p008)

<a id="cq-11-04-p009"></a>

### 9. 刘卷去世

刘卷去世。

[看对应原文](#source-cq-11-04-p009)

<details><summary>字句与编年说明</summary>

刘是当时采邑、氏称，不据现代姓氏习惯增补来历。

</details>

<a id="cq-11-04-p010"></a>

### 10. 葬杞悼公

安葬杞悼公。

[看对应原文](#source-cq-11-04-p010)

### 11. 楚围蔡

楚人围蔡。

[看对应原文](#source-cq-11-04-p011)

<a id="cq-11-04-p012"></a>

### 12. 晋卫伐鲜虞

晋士鞅、卫孔圉率军进攻鲜虞。

[看对应原文](#source-cq-11-04-p012)

<a id="cq-11-04-p013"></a>

### 13. 葬刘文公

安葬刘文公。

[看对应原文](#source-cq-11-04-p013)

<a id="cq-11-04-p014"></a>

### 14. 柏举之战楚败

冬天十一月庚午，蔡侯联合吴子，在柏举与楚军交战，楚军败。

[看对应原文](#source-cq-11-04-p014)

<details><summary>字句与编年说明</summary>

经文的“以吴子”保留蔡引吴助战关系，不漏写蔡方。

</details>

<a id="cq-11-04-p015"></a>

### 15. 囊瓦奔郑

楚囊瓦逃往郑国。

[看对应原文](#source-cq-11-04-p015)

<a id="cq-11-04-p016"></a>

### 16. 吴军进入郢

庚辰，吴军攻入郢都。

[看对应原文](#source-cq-11-04-p016)

<details><summary>字句与编年说明</summary>

与柏举不同干支，不能写成同日克都。

</details>

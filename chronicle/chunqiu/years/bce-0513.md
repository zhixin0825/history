# 公元前513年（鲁昭公二十九年）

[上一年：前514](bce-0514.md) · [昭公目录](../zhaogong/README.md) · [春秋目录](../README.md) · [下一年：前512](bce-0512.md)

> 第一轮白话整理，附逐段原文与归年说明。古历月份不直接等同公历月份；段落覆盖不等于现代学术校勘完成。

## 本年纪事

<a id="event-1"></a>

1. **昭公由乾侯返郓，因齐使称呼再生不满，又回乾侯。**

春季，昭公从乾侯回郓。齐景公派高张来慰问，使者称昭公为“主君”。子家羁认为这降低了国君应有的称谓，昭公随后又到乾侯，继续向晋寻求出路。 [1](#note-1)

<a id="event-2"></a>

2. **周室处死召伯盈、尹氏固等人。**

三月己卯，周都处死召伯盈、尹氏固及原伯鲁的儿子。尹固此前曾逃出又回到周境，传文保存一名妇人在郊外批评他的插曲。 [2](#note-2)

<a id="event-3"></a>

3. **叔诣去世。**

四月庚子，鲁国叔诣去世。 [3](#note-3)

<a id="event-4"></a>

4. **王子赵车据鄻叛乱，被阴不佞击败。**

五月庚寅，王子赵车进入鄻地起兵叛乱，阴不佞将其击败。 [4](#note-4)

<a id="event-5"></a>

5. **乾侯物资供给中断，昭公也接受卫侯赠马。**

季平子原每年买马，连同随从所需衣鞋送到乾侯。昭公拘捕送马者并卖掉他们，季氏便不再送马。卫侯另外送来名为启服的乘马，马坠沟而死。昭公想为马制棺，子家羁指出随从生活困苦，建议用马肉供食，昭公最后用帷布包裹马尸。 [5](#note-5)

<a id="event-6"></a>

6. **昭公获得阳穀，并改立公衍为太子。**

昭公让公衍向齐侯献龙辅，公衍又把获赐的羔裘一并进献，齐侯给昭公阳穀。昭公既为获邑而喜，又思及鲁国，责怪公为牵动此前祸乱。公衍原比公为早出生，但两位母亲报生先后使公为长期被当作兄长；昭公这时调整继承安排，改立公衍为太子。 [6](#note-6)

<a id="event-7"></a>

7. **绛郊传出见龙之事，蔡墨讲述豢龙、御龙旧说。**

秋季，晋国绛郊有见龙的记载。魏献子向蔡墨询问龙是否特别有智，蔡墨认为问题在人的知识和官守中断，讲述董父、刘累养龙的旧传，并联系五行之官、社稷祭祀和《易》中的龙辞解释。 [7](#note-7)

<a id="event-8"></a>

8. **晋国铸刑鼎，将范宣子刑书公布于鼎。**

冬季，赵鞅、荀寅率军筑汝滨之城，征集铁料，铸造刑鼎，将范宣子所作刑书铸在上面。围绕公开刑书，传文保存孔子担心旧有等级职守被改变的议论，史墨则从卿职、擅作法器等方面提出批评。 [8](#note-8)

<a id="event-9"></a>

9. **十月，郓地溃散。**

十月，昭公此前在鲁境内的据点郓发生溃散。他没有借此恢复鲁国君位，随后各年仍居乾侯。 [9](#note-9)

### [6] 昭公获得阳穀，并改立公衍为太子。

**《左传》·昭公二十九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0513.md#L37-L37)

<a id="note-7"></a>

### [7] 绛郊传出见龙之事，蔡墨讲述豢龙、御龙旧说。

**《春秋》·昭公二十九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0513.md#L21-L21)

> 秋七月。

**《左传》·昭公二十九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0513.md#L39-L39)

> 秋，龙见于绛郊。魏献子问于蔡墨曰：“吾闻之，虫莫知于龙，以其不生得也。谓之知，信乎？”对曰：“人实不知，非龙实知。古者畜龙，故国有豢龙氏，有御龙氏。”献子曰：“是二氏者，吾亦闻之，而不知其故。是何谓也？”对曰：“昔有飂叔安，有裔子曰董父，实甚好龙，能求其耆欲以饮食之，龙多归之。乃扰畜龙，以服事帝舜。帝赐之姓曰董，氏曰豢龙。封诸鬷川，鬷夷氏其后也。故帝舜氏世有畜龙。及有夏孔甲，扰于有帝。帝赐之乘龙，河、汉各二，各有雌雄，孔甲不能食，而未获豢龙氏。有陶唐氏既衰，其后有刘累，学扰龙于豢龙氏，以事孔甲，能饮食之。夏后嘉之，赐氏曰御龙，以更豕韦之后。龙一雌死，潜醢以食夏后。夏后飨之，既而使求之。惧而迁于鲁县，范氏其后也。”献子曰：“今何故无之？”对曰：“夫物物有其官，官修其方，朝夕思之。一日失职，则死及之。失官不食，官宿其业，其物乃至。若泯弃之，物乃坻伏，郁湮不育。故有五行之官，是谓五官。实列受氏姓，封为上公，祀为贵神。社稷五祀，是尊是奉。木正曰句芒，火正曰祝融，金正曰蓐收，水正曰玄冥，土正曰后土。龙，水物也。水官弃矣，故龙不生得。不然，《周易》有之，在《乾》之《姤》，曰：‘潜龙勿用。’其《同人》曰：‘见龙在田。’其《大有》曰：‘飞龙在天。’其《夬》曰：‘亢龙有悔。’其《坤》曰：‘见群龙无首，吉。’《坤》之《剥》曰：‘龙战于野。’若不朝夕见，谁能物之？”献子曰：“社稷五祀，谁氏之五官也？”对曰：“少皞氏有四叔，曰重，曰该，曰修，曰煕，实能金木及水。使重为句芒，该为蓐收，修及熙为玄冥。世不失职，遂济穷桑，此其三祀也。颛顼氏有子曰犁，为祝融，共工氏有子曰句龙，为后土，此其二祀也。后土为社，稷，田正也。有烈山氏之子曰柱为稷，自夏以上祀之。周弃亦为稷，自商以来祀之。”

**说明：** 经文“秋七月”是月令，不另造独立史事；传文仅称秋，正文不硬定见龙在七月某日。养龙旧传、龙肉故事与祭神谱系全部为当时知识叙事，不作已证动物学史。

### [8] 晋国铸刑鼎，将范宣子刑书公布于鼎。

**《左传》·昭公二十九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0513.md#L41-L41)

> 冬，晋赵鞅、荀寅帅师城汝滨，遂赋晋国一鼓铁，以铸刑鼎，著范宣子所为刑书焉。仲尼曰：“晋其亡乎，失其度矣。夫晋国将守唐叔之所受法度，以经纬其民，卿大夫以序守之。民是以能尊其贵，贵是以能守其业。贵贱不愆，所谓度也。文公是以作执秩之官，为被庐之法，以为盟主。今弃是度也，而为刑鼎，民在鼎矣，何以尊贵？贵何业之守？贵贱无序，何以为国？且夫宣子之刑，夷之蒐也，晋国之乱制也，若之何以为法？”蔡史墨曰：“范氏、中行氏其亡乎。中行寅为下卿，而干上令，擅作刑器，以为国法，是法奸也。又加范氏焉，易之，亡也。其及赵氏，赵孟与焉；然不得已，若德可以免。”

**说明：** 写清公布刑书这一行动，不把它简单等同现代法治，也不把当时反对意见当作项目立场。征铁“一鼓”不擅换算成现代吨数。

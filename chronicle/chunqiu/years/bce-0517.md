# 公元前517年（鲁昭公二十五年）

## 本年纪事

<a id="event-1"></a>

1. **叔孙婼出聘宋国，并为季平子迎娶宋女。**

春季，叔孙婼赴宋聘问，参加宋元公的宴享，也负责为季平子迎娶宋女。季氏族人季公若随行，劝宋方停止婚事，声称鲁国将逐季氏；宋国乐祁则判断季氏已经长期掌政，建议照常成婚，不要把未经实现的驱逐计划当成既成事实。 [1](#note-1)

<a id="event-2"></a>

2. **诸国大夫会于黄父，筹粮出兵支援周室。**

夏季，晋国赵鞅召诸国大夫会于黄父，要求输送粮食、准备驻军，计划次年护送敬王恢复王都秩序。宋国乐大心以宋是周室宾客为由拒绝输粟，遭晋使援引共同盟约反驳，才接受文书。会中子大叔还向赵鞅说明，揖让周旋只是仪节，礼还涉及君臣、家庭、赋役和赏罚的安排。 [2](#note-2)

<a id="event-3"></a>

3. **鸲鹆来鲁筑巢，师己提起旧童谣。**

鸲鹆来到鲁国筑巢，因不同寻常而被记录。师己提起一首旧童谣，其中说到鲁君流落在外、居于乾侯等景象；后来昭公的流亡，使这首歌谣在叙事中显得格外醒目。 [3](#note-3)

<a id="event-4"></a>

4. **七月两次大雩，鲁国旱情严重。**

七月上辛、季辛，鲁国两次举行大雩祈雨。频繁祈雨反映本年旱情持续。 [4](#note-4)

<a id="event-5"></a>

5. **季氏内部与臧、郈两家的积怨汇合，昭公决定动手。**

季公若替申夜姑等人求情，却被季平子拒之门外，双方因此结怨；郈昭伯因斗鸡、住宅扩建起争执；臧氏又因臧会逃依季氏及家臣被拘而不满。昭公诸子与这些反季力量相联系，反复促请国君动手。子家羁提醒，季氏掌政已久，党众与依附者很多，谋划失败将由国君承担后果，但没有阻止行动。 [5](#note-5)

<a id="event-6"></a>

6. **昭公围攻季氏，叔孙、孟孙出兵救援，昭公败走齐境。**

九月戊戌，昭公率军进入季氏住宅，季平子登台请求到沂上待查、到费受囚，或率五乘离境，均未获准。叔孙氏家臣鬷戾召众救季，孟氏看到叔孙旗帜也参战，杀死昭公派来的郈昭伯。昭公军败，次日出奔，停在阳州，并在野井接受齐景公安慰。齐侯许以大片土地，子家羁劝昭公不要用放弃鲁国宗业换取附属于齐的地位，也建议及早向晋求助。 [6](#note-6)

<a id="event-7"></a>

7. **叔孙昭子往返调停，十月去世。**

叔孙昭子从阚回来，责季平子逐君，又到齐国见昭公，打算安定众人、迎君回国。昭公从者中有人伏兵欲杀叔孙，昭公得报，改道送他返回。季平子此后态度又有变化，迎君没有落实。十月戊辰，叔孙昭子去世，昭公一方与国内联系进一步受阻。 [7](#note-7)

<a id="event-8"></a>

8. **尹文公渡巩攻东訾，未能攻下。**

周室内战仍在继续。尹文公渡过巩地一线，焚攻东訾，但未能攻克。 [8](#note-8)

<a id="event-9"></a>

9. **宋元公为昭公赴晋求援，途中死于曲棘。**

十一月，宋元公准备赴晋，帮助昭公争取复位。出发前他与六卿谈身后丧葬，希望有所减省，六卿坚持守宋国旧制。元公仍上路，己亥死在曲棘，没有完成出使。 [9](#note-9)

<a id="event-10"></a>

10. **齐军围郓，准备为昭公取得落脚之地。**

十二月，齐景公率军围郓。郓位于鲁地，后来成为昭公在鲁国境内的据点。 [10](#note-10)

<a id="event-11"></a>

11. **楚国接连筑城、迁民，经营边地。**

楚国命薳射、熊相禖、季然等修筑州屈、丘皇，并为巢、卷修筑外郭，并迁置茄人、訾人。郑国子大叔听说后，担忧接连迁徙使民众不安。 [11](#note-11)

### [2] 诸国大夫会于黄父，筹粮出兵支援周室。

**《春秋》·昭公二十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0517.md#L15-L15)

**《左传》·昭公二十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0517.md#L39-L39)

> 夏，会于黄父，谋王室也。赵简子令诸侯之大夫，输王粟，具戍人，曰：“明年将纳王。”子大叔见赵简子，简子问揖让周旋之礼焉。对曰：“是仪也，非礼也。”简子曰：“敢问何谓礼？”对曰：“吉也闻诸先大夫子产曰：‘夫礼，天之经也，地之义也，民之行也。天地之经，而民实则之。则天之明，因地之性，生其六气，用其五行。气为五味，发为五色，章为五声，淫则昏乱，民失其性。是故为礼以奉之。为六畜、五牲、三牺，以奉五味。为九文、六采、五章，以奉五色。为九歌、八风、七音、六律，以奉五声。为君臣、上下，以则地义。为夫妇、外内，以经二物。为父子、兄弟、姑姊、甥舅、昏媾、姻亚，以象天明。为政事、庸力、行务，以从四时。为刑罚、威狱，使民畏忌，以类其震曜杀戮。为温慈、惠和，以效天之生殖长育。民有好、恶、喜、怒、哀、乐，生于六气。是故审则宜类，以制六志。哀有哭泣，乐有歌舞，喜有施舍，怒有战斗。喜生于好，怒生于恶。是故审行信令，祸福赏罚，以制死生。生，好物也。死，恶物也。好物，乐也。恶物，哀也。哀乐不失，乃能协于天地之性，是以长久’”简子曰：“甚哉，礼之大也。”对曰：“礼，上下之纪，天地之经纬也，民之所以生也，是以先王尚之。故人之能自曲直以赴礼者，谓之成人。大，不亦宜乎？”简子曰：“鞅也请终身守此言也。”

**《左传》·昭公二十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0517.md#L41-L41)

> 宋乐大心曰：“我不输粟，我于周为客，若之何使客？”晋士伯曰：“自践土以来，宋何役之不会，而何盟之不同？曰同恤王室，子焉得辟之？子奉君命，以会大事，而宋背盟，无乃不可乎！”右师不敢对，受牒而退。士伯告简子曰：“宋右师必亡。奉君命以使，而欲背盟以干盟主，无不祥大焉。”

**说明：** 叔诣代表鲁国与会。子大叔所述礼论归为会议中的言说，不编成另一次礼制改革。

### [5] 季氏内部与臧、郈两家的积怨汇合，昭公决定动手。

**《左传》·昭公二十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0517.md#L47-L47)

> 初，季公鸟娶妻于齐鲍文子，生甲。公鸟死，季公亥与公思展与公鸟之臣申夜姑相其室。及季姒与饔人檀通，而惧，乃使其妾抶己，以示秦遄之妻曰：“公若欲使余，余不可而抶余。”又诉于公甫曰：“展与夜姑将要余。”秦姬以告公之，公之与公甫告平子。平子拘展于卞而执夜姑，将杀之。公若泣而哀之曰：“杀是，是杀余也。”将为之请。平子使竖勿内，日中不得请。有司逆命，公之使速杀之。故公若怨平子。

**《左传》·昭公二十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0517.md#L49-L49)

> 季、郈之鸡斗。季氏介其鸡，郈氏为之金距。平子怒，益宫于郈氏，且让之。故郈昭伯亦怨平子。臧昭伯之从弟会，为谗于臧氏，而逃于季氏，臧氏执旃。平子怒，拘臧氏老。将禘于襄公，万者二人，其众万于季氏。臧孙曰：“此之谓不能庸先君之庙。”大夫遂怨平子。公若献弓于公为，且与之出射于外，而谋去季氏。公为告公果、公贲。公果、公贲使侍人僚柤告公。公寝，将以戈击之，乃走。公曰：“执之。”亦无命也。惧而不出，数月不见，公不怒。又使言，公执戈以惧之，乃走。又使言，公曰：“非小人之所及也。”公果自言，公以告臧孙，臧孙以难。告郈孙，郈孙以可，劝。告子家懿伯，懿伯曰：“谗人以君徼幸，事若不克，君受其名，不可为也。舍民数世以求克，事不可必也。且政在焉，其难图也。”公退之。辞曰：“臣与闻命矣，言若洩，臣不获死。”乃馆于公。

**《左传》·昭公二十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0517.md#L61-L61)

> 初，臧昭伯如晋，臧会窃其宝龟偻句。以卜为信与僭，僭吉。臧氏老将如晋问，会请往。昭伯问家故，尽对。及内子与母弟叔孙，则不对。再三问，不对。归及郊，会逆，问，又如初。至，次于外而察之，皆无之。执而戮之，逸奔郈。郈鲂假使为贾正焉。计于季氏。臧氏使五人以戈楯伏诸桐汝之闾。会出，逐之。反奔，执诸季氏中门之外。平子怒曰：“何故以兵入吾门？”拘臧氏老。季、臧有恶。及昭伯从公，平子立臧会。会曰：“偻句不余欺也。”

**《史记·鲁周公世家》·二十五年：季、郈、臧三家的积怨** · [固定版本原文](https://zh.wikisource.org/w/index.php?title=史記/魯周公世家&oldid=7909289)

> 季氏與郈氏鬬雞，季氏芥雞羽，郈氏金距。季平子怒而侵郈氏，郈昭伯亦怒平子。臧昭伯之弟會偽讒臧氏，匿季氏，臧昭伯囚季氏人。季平子怒，囚臧氏老。臧、郈氏以難告昭公。

**说明：** 季公若即季公亥，子家羁即子家懿伯，世家称子家驹。臧会与臧昭伯，传文作从弟、世家作弟，不强断为亲弟。第15传段回叙臧氏旧怨，末句则记政变后季氏立臧会，须分开时间。斗鸡只是积怨之一，不是政变唯一原因。

> 九月己亥，公孙于齐，次于阳州，齐侯唁公于野井。

**《左传》·昭公二十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0517.md#L51-L51)

> 叔孙昭子如阚，公居于长府。九月戊戌，伐季氏，杀公之于门，遂入之。平子登台而请曰：“君不察臣之罪，使有司讨臣以干戈，臣请待于沂上以察罪。”弗许。请囚于费，弗许。请以五乘亡，弗许。子家子曰：“君其许之！政自之出久矣，隐民多取食焉。为之徒者众矣，日入慝作，弗可知也。众怒不可蓄也。蓄而弗治，将蕰。蕰畜，民将生心；生心，同求将合。君必悔之。”弗听。郈孙曰：“必杀之。”公使郈孙逆孟懿子。叔孙氏之司马鬷戾言于其众曰：“若之何？”莫对。又曰：“我，家臣也，不敢知国。凡有季氏与无，于我孰利？”皆曰：“无季氏，是无叔孙氏也。”鬷戾曰：“然则救诸。”帅徒以往，陷西北隅以入。公徒释甲，执冰而踞。遂逐之。孟氏使登西北隅，以望季氏。见叔孙氏之旌，以告。孟氏执郈昭伯，杀之于南门之西，遂伐公徒。子家子曰：“诸臣伪劫君者，而负罪以出，君止。意如之事君也，不敢不改。”公曰：“余不忍也。”与臧孙如墓谋，遂行。己亥，公孙于齐，次于阳州。齐侯将唁公于平阴，公先至于野井。齐侯曰：“寡人之罪也。”使有司待于平阴，为近故也。书曰：“公孙于齐，次于阳州，齐侯唁公于野井。”礼也。将求于人，则先下之，礼之善物也。齐侯曰：“自莒疆以西，请致千社，以待君命。寡人将帅敝赋以从执事，唯命是听。君之忧，寡人之忧也。”公喜。子家子曰：“天禄不再，天若胙君，不过周公，以鲁足矣。失鲁，而以千社为臣，谁与之立？且齐君无信，不如早之晋。”弗从。臧昭伯率从者将盟，载书曰：“戮力壹心，好恶同之。信罪之有无，缱绻从公，无通外内。”以公命示子家子。子家子曰：“如此，吾不可以盟。羁也不佞，不能与二三子同心，而以为皆有罪。或欲通外内，且欲去君。二三子好亡而恶定，焉可同也？陷君于难，罪孰大焉？通外内而去君，君将速入，弗通何为？而何守焉？”乃不与盟。

**《史记·鲁周公世家》·二十五年：伐季氏、三家反击与昭公出奔** · [固定版本原文](https://zh.wikisource.org/w/index.php?title=史記/魯周公世家&oldid=7909289)

> 昭公九月戊戌伐季氏，遂入。平子登臺請曰：『君以讒不察臣罪，誅之，請遷沂上。』弗許。請囚於鄪，弗許。請以五乘亡，弗許。子家駒曰：『君其許之。政自季氏久矣，爲徒者眾，眾將合謀。』弗聽。郈氏曰：『必殺之。』叔孫氏之臣戾謂其眾曰：『無季氏與有，孰利？』皆曰：『無季氏是無叔孫氏。』戾曰：『然，救季氏！』遂敗公師。孟懿子聞叔孫氏勝，亦殺郈昭伯。郈昭伯爲公使，故孟氏得之。三家共伐公，公遂奔。己亥，公至于齊。

**《史记·鲁周公世家》·二十五年：齐国许地与子家的劝告** · [固定版本原文](https://zh.wikisource.org/w/index.php?title=史記/魯周公世家&oldid=7909289)

> 齊景公曰：『請致千社待君。』子家曰：『棄周公之業而臣於齊，可乎？』乃止。子家曰：『齊景公無信，不如早之晉。』弗從。

**说明：** 经文“公孙于齐”的“孙”是出奔的婉辞，不是姓名。《史记》概括“三家共伐公”，传文具体表明叔孙氏救兵由家臣鬷戾发动；叔孙昭子本人当时在阚，不能写成他亲自率援军。齐国“千社”是许诺，不写成已实际交割。

### [7] 叔孙昭子往返调停，十月去世。

**《春秋》·昭公二十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0517.md#L23-L23)

> 冬十月戊辰，叔孙婼卒。

**《左传》·昭公二十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0517.md#L53-L53)

> 昭子自阚归，见平子。平子稽颡曰：“子若我何？”昭子曰：“人谁不死？子以逐君成名，子孙不忘，不亦伤乎！将若子何？”平子曰：“苟使意如得改事君，所谓生死而肉骨也。”昭子从公于齐，与公言。子家子命適公馆者执之。公与昭子言于幄内，曰：“将安众而纳公。”公徒将杀昭子，伏诸道。左师展告公，公使昭子自铸归。平子有异志。冬十月辛酉，昭子齊于其寝，使祝宗祈死，戊辰，卒。左师展将以公乘马而归，公徒执之。

**《史记·鲁周公世家》·二十五年：叔孙调停与孟季态度变化** · [固定版本原文](https://zh.wikisource.org/w/index.php?title=史記/魯周公世家&oldid=7909289)

> 叔孫見公還，見平子，平子頓首。初欲迎昭公，孟孫、季孫後悔，乃止。

**说明：** 《史记》叙成叔孙先见公、回来再见平子，且说孟、季后来反悔；传文为先自阚归见平子，再赴齐见公。正文依传文连续行程，差异留此，不声称已证现代学界一致。祈死是原文所记宗教举动，不能据此断言死亡原因。

### [9] 宋元公为昭公赴晋求援，途中死于曲棘。

**《春秋》·昭公二十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0517.md#L25-L25)

> 十有一月己亥，宋公佐卒于曲棘。

**《左传》·昭公二十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0517.md#L57-L57)

> 十一月，宋元公将为公故如晋。梦大子栾即位于庙，己与平公服而相之。旦召六卿。公曰：“寡人不佞，不能事父兄，以为二三子忧，寡人之罪也。若以群子之灵，获保首领以没，唯是楄柎所以藉幹者，请无及先君。”仲幾对曰：“君若以社稷之故，私降昵宴，群臣弗敢知。若夫宋国之法，死生之度，先君有命矣。群臣以死守之，弗敢失队。臣之失职，常刑不赦。臣不忍其死，君命祇辱。”宋公遂行。己亥，卒于曲棘。

**说明：** 梦见太子继位是出行前的梦叙；宋元公尚未到晋，不能写成晋国已答应他的请求。

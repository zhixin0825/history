## 春秋经

<a id="cq-10-11-p001"></a>

### 1. 叔弓赴宋葬平公

春天王二月，叔弓到宋参加宋平公葬礼。

[看对应原文](#source-cq-10-11-p001)

<a id="cq-10-11-p002"></a>

### 2. 楚虔诱杀蔡侯般

夏天四月丁巳，楚子虔把蔡侯般诱到申地杀死。

[看对应原文](#source-cq-10-11-p002)

<a id="cq-10-11-p003"></a>

### 3. 弃疾围蔡

楚公子弃疾率军围蔡。

[看对应原文](#source-cq-10-11-p003)

<a id="cq-10-11-p004"></a>

### 4. 夫人归氏去世

五月甲申，夫人归氏去世。

[看对应原文](#source-cq-10-11-p004)

<a id="cq-10-11-p005"></a>

### 5. 比蒲大蒐

鲁在比蒲举行大规模田猎、军事检阅。

[看对应原文](#source-cq-10-11-p005)

<a id="cq-10-11-p006"></a>

### 6. 鲁邾盟祲祥

仲孙貜会邾子，在祲祥结盟。

[看对应原文](#source-cq-10-11-p006)

<a id="cq-10-11-p007"></a>

### 7. 八方会厥慭

秋天，季孙意如与晋韩起、齐国弱、宋华亥、卫北宫佗、郑罕虎、曹人、杞人在厥慭会面。

[看对应原文](#source-cq-10-11-p007)

<a id="cq-10-11-p008"></a>

### 8. 葬齐归

九月己亥，鲁安葬夫人齐归。

[看对应原文](#source-cq-10-11-p008)

<details><summary>字句与编年说明</summary>

齐归是夫人称号，不当成一项齐国归还土地的行动。

</details>

<a id="cq-10-11-p009"></a>

### 9. 楚灭蔡，俘世子有用于祭祀

冬天十一月丁酉，楚军灭蔡，扣住蔡世子有带回，并把他用于祭祀。

[看对应原文](#source-cq-10-11-p009)

<details><summary>字句与编年说明</summary>

“有”为世子姓名；“用之”的祭祀解释保留原词及传文入口，不添刑杀细节。

</details>

## 春秋经

<a id="cq-09-16-p001"></a>

### 1. 葬晋悼公

春天王正月，安葬晋悼公。

[看对应原文](#source-cq-09-16-p001)

<a id="cq-09-16-p002"></a>

### 2. 十一国会湨梁

三月，襄公与晋侯、宋公、卫侯、郑伯、曹伯、莒子、邾子、薛伯、杞伯、小邾子在湨梁会合。

[看对应原文](#source-cq-09-16-p002)

<a id="cq-09-16-p003"></a>

### 3. 大夫结盟

戊寅，参加会合的大夫举行盟誓。

[看对应原文](#source-cq-09-16-p003)

<a id="cq-09-16-p004"></a>

### 4. 晋带走莒、邾国君

晋人扣莒子、邾子，将他们带走。

[看对应原文](#source-cq-09-16-p004)

<a id="cq-09-16-p005"></a>

### 5. 齐攻鲁北境

齐侯进攻鲁北境。

[看对应原文](#source-cq-09-16-p005)

<a id="cq-09-16-p006"></a>

### 6. 襄公自会回来

夏天，襄公回鲁。

[看对应原文](#source-cq-09-16-p006)

<a id="cq-09-16-p007"></a>

### 7. 五月地震

五月甲子，发生地震。

[看对应原文](#source-cq-09-16-p007)

<a id="cq-09-16-p008"></a>

### 8. 五方伐许

叔老与郑伯、晋荀偃、卫甯殖、宋人共同攻许。

[看对应原文](#source-cq-09-16-p008)

<a id="cq-09-16-p009"></a>

### 9. 齐再次围成

秋天，齐侯又攻鲁北部边境，围成。

[看对应原文](#source-cq-09-16-p009)

<a id="cq-09-16-p010"></a>

### 10. 举行大雩

鲁举行大雩求雨。

[看对应原文](#source-cq-09-16-p010)

<a id="cq-09-16-p011"></a>

### 11. 叔孙豹赴晋

冬天，叔孙豹去晋。

[看对应原文](#source-cq-09-16-p011)

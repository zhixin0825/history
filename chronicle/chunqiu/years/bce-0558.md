# 公元前558年（鲁襄公十五年）

[上一年：前559](bce-0559.md) · [目录](../README.md) · [下一年：前557](bce-0557.md)

1. **春，宋向戌来鲁聘问并与鲁国在刘地重申盟约。** [1]

2. **周王室派刘夏到齐国迎娶王后。** [2]

3. **夏，齐侯进攻鲁国北境并包围成地。** 鲁襄公亲自救成，季孙宿、叔孙豹又加筑成地外城。[3]

4. **秋八月，发生日食。** 邾国随后进攻鲁国南境。[4]

5. **冬，晋悼公去世。** 原定由晋国召集诸侯讨伐邾、莒的行动因此停止。[5]

6. **宋国有人献宝玉给司城子罕，子罕拒绝，称自己以“不贪”为宝。** [6]

## 本年相关史料

1. **《春秋·襄公十五年》**：“十有五年春，宋公使向戌来聘。二月己亥，及向戌盟于刘。”

2. **《春秋·襄公十五年》**：“刘夏逆王后于齐。”

3. **《春秋·襄公十五年》**：“夏，齐侯伐我北鄙，围成。公救成，至遇。季孙宿、叔孙豹帅师城成郛。”

4. **《春秋·襄公十五年》**：“秋八月丁巳，日有食之。邾人伐我南鄙。”

5. **《春秋·襄公十五年》**：“冬十有一月癸亥，晋侯周卒。”  
   **《左传·襄公十五年》**详记因悼公有疾而取消会讨邾莒。

6. **《左传·襄公十五年》**详记子罕不受玉，以不贪为宝。

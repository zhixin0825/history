## 春秋经

<a id="cq-09-14-p001"></a>

### 1. 诸国大夫在向会吴

春天王正月，季孙宿、叔老会晋士匄、齐、宋、卫、郑公孙虿、曹、莒、邾、滕、薛、杞、小邾各方，在向会吴。

[看对应原文](#source-cq-09-14-p001)

<details><summary>字句与编年说明</summary>

鲁有两位大夫，名单不压成只有一人出使。

</details>

<a id="cq-09-14-p002"></a>

### 2. 二月日食

二月乙未初一，发生日食。

[看对应原文](#source-cq-09-14-p002)

<a id="cq-09-14-p003"></a>

### 3. 十三方伐秦

夏天四月，叔孙豹与晋荀偃、齐人、宋人、卫北宫括、郑公孙虿、曹、莒、邾、滕、薛、杞、小邾各方共同攻秦。

[看对应原文](#source-cq-09-14-p003)

<a id="cq-09-14-p004"></a>

### 4. 卫侯奔齐

己未，卫侯逃到齐国。

[看对应原文](#source-cq-09-14-p004)

<a id="cq-09-14-p005"></a>

### 5. 莒侵鲁东境

莒人侵入鲁东部边境。

[看对应原文](#source-cq-09-14-p005)

<a id="cq-09-14-p006"></a>

### 6. 楚贞伐吴

秋天，楚公子贞率军攻吴。

[看对应原文](#source-cq-09-14-p006)

<a id="cq-09-14-p007"></a>

### 7. 七方在戚会合

冬天，季孙宿会晋士匄、宋华阅、卫孙林父、郑公孙虿、莒人、邾人于戚。

[看对应原文](#source-cq-09-14-p007)

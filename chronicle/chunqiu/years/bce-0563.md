## 春秋经

<a id="cq-09-10-p001"></a>

### 1. 诸侯在柤会吴

春天，襄公与晋侯、宋公、卫侯、曹伯、莒子、邾子、滕子、薛伯、杞伯、小邾子、齐世子光，在柤会吴国代表。

[看对应原文](#source-cq-09-10-p001)

<a id="cq-09-10-p002"></a>

### 2. 联军灭偪阳

夏天五月甲午，参加会合的联军随后灭偪阳。

[看对应原文](#source-cq-09-10-p002)

<a id="cq-09-10-p003"></a>

### 3. 襄公自会回来

襄公回鲁。

[看对应原文](#source-cq-09-10-p003)

<a id="cq-09-10-p004"></a>

### 4. 楚郑攻宋

楚公子贞、郑公孙辄率军攻宋。

[看对应原文](#source-cq-09-10-p004)

<a id="cq-09-10-p005"></a>

### 5. 晋伐秦

晋军进攻秦。

[看对应原文](#source-cq-09-10-p005)

<a id="cq-09-10-p006"></a>

### 6. 莒再攻鲁东境

秋天，莒人攻鲁东部边境。

[看对应原文](#source-cq-09-10-p006)

<a id="cq-09-10-p007"></a>

### 7. 十二方伐郑

襄公与晋侯、宋公、卫侯、曹伯、莒子、邾子、齐世子光、滕子、薛伯、杞伯、小邾子共同攻郑。

[看对应原文](#source-cq-09-10-p007)

<a id="cq-09-10-p008"></a>

### 8. 郑国三名公族被杀

冬天，盗贼杀郑公子斐、公子发、公孙辄。

[看对应原文](#source-cq-09-10-p008)

<details><summary>字句与编年说明</summary>

“盗”是经文称呼，不凭此补具体集团姓名。

</details>

<a id="cq-09-10-p009"></a>

### 9. 戍守郑虎牢

鲁等方面派兵戍守郑国虎牢。

[看对应原文](#source-cq-09-10-p009)

<details><summary>字句与编年说明</summary>

省略主语的军队组成不擅补齐。

</details>

<a id="cq-09-10-p010"></a>

### 10. 楚救郑，襄公回鲁

楚公子贞率军救郑，襄公结束伐郑之行回国。

[看对应原文](#source-cq-09-10-p010)

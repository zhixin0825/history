# 公元前567年（鲁襄公六年）

[上一年：前568](bce-0568.md) · [目录](../README.md) · [下一年：前566](bce-0566.md)

1. **春，杞桓公去世；夏，宋华弱出奔鲁国。** [1]

2. **宋国内华弱与乐辔长期争斗，宋平公把华弱驱逐。** 华弱逃鲁后，宋又把另一方子荡逐出，随后仍恢复关系。[2]

3. **秋，鲁国安葬杞桓公；滕成公首次来朝襄公。** [3]

4. **莒国灭掉鄫国。** 鄫国长期依靠鲁国保护，最终仍被莒吞并。[4]

5. **冬，叔孙豹赴邾修好；季孙宿赴晋接受晋国因鄫亡而来的问责。** [5]

6. **齐灵公经过长期围攻，最终灭莱国，并把莱人迁往郳地。** [6]

## 本年相关史料

1. **《春秋·襄公六年》**：“六年春，王三月壬午，杞伯姑容卒。夏，宋华弱来奔。”

2. **《左传·襄公六年》**详记华弱、乐辔、子荡之争。

3. **《春秋·襄公六年》**：“秋，葬杞桓公。滕子来朝。”

4. **《春秋·襄公六年》**：“莒人灭鄫。”

5. **《春秋·襄公六年》**：“冬，叔孙豹如邾。季孙宿如晋。”

6. **《春秋·襄公六年》**：“十有二月，齐侯灭莱。”  
   **《左传·襄公六年》**详记齐围莱、入莱、灭棠并迁莱。

## 春秋经

<a id="cq-08-11-p001"></a>

### 1. 成公自晋回鲁

春天王三月，成公从晋回鲁。

[看对应原文](#source-cq-08-11-p001)

<a id="cq-08-11-p002"></a>

### 2. 郤犫来聘

晋侯派郤犫来鲁访问。

[看对应原文](#source-cq-08-11-p002)

<a id="cq-08-11-p003"></a>

### 3. 鲁与郤犫结盟

己丑，鲁方与郤犫结盟。

[看对应原文](#source-cq-08-11-p003)

<a id="cq-08-11-p004"></a>

### 4. 季孙行父赴晋

夏天，季孙行父去晋。

[看对应原文](#source-cq-08-11-p004)

<a id="cq-08-11-p005"></a>

### 5. 叔孙侨如赴齐

秋天，叔孙侨如到齐国。

[看对应原文](#source-cq-08-11-p005)

<details><summary>字句与编年说明</summary>

原文连续两个“如”，前一个属于姓名，后一个是前往，不能删一个汉字当作格式清理。

</details>

<a id="cq-08-11-p006"></a>

### 6. 〔时间提示〕冬十月

经文列冬十月，未另记事件。

[看对应原文](#source-cq-08-11-p006)

## 春秋经

<a id="cq-08-10-p001"></a>

### 1. 卫黑背侵郑

春天，卫侯的弟弟黑背率军侵郑。

<a id="cq-08-10-p002"></a>

### 2. 五次卜郊不成，取消祭祀

夏天四月，鲁五次占卜郊祭，结果不允，于是没有举行郊祭。

[看对应原文](#source-cq-08-10-p002)

<a id="cq-08-10-p003"></a>

### 3. 六国伐郑

五月，成公会晋侯、齐侯、宋公、卫侯、曹伯，共同攻郑。

[看对应原文](#source-cq-08-10-p003)

<a id="cq-08-10-p004"></a>

### 4. 齐来送媵

齐人来鲁安排随嫁的媵。

[看对应原文](#source-cq-08-10-p004)

<a id="cq-08-10-p005"></a>

### 5. 晋侯獳去世

丙午，晋侯獳去世。

[看对应原文](#source-cq-08-10-p005)

<a id="cq-08-10-p006"></a>

### 6. 成公赴晋

秋天七月，成公去晋。

[看对应原文](#source-cq-08-10-p006)

<a id="cq-08-10-p007"></a>

### 7. 〔时间提示〕冬十月

## 春秋经

<a id="cq-08-09-p001"></a>

### 1. 杞迎叔姬之丧

春天王正月，杞伯来鲁迎接叔姬的丧，带回杞国。

[看对应原文](#source-cq-08-09-p001)

<a id="cq-08-09-p002"></a>

### 2. 九国在蒲同盟

成公与晋侯、齐侯、宋公、卫侯、郑伯、曹伯、莒子、杞伯在蒲共同结盟。

[看对应原文](#source-cq-08-09-p002)

<a id="cq-08-09-p003"></a>

### 3. 成公自会归鲁

成公从会盟回鲁。

[看对应原文](#source-cq-08-09-p003)

<a id="cq-08-09-p004"></a>

### 4. 伯姬嫁宋

二月，伯姬嫁到宋国。

[看对应原文](#source-cq-08-09-p004)

<a id="cq-08-09-p005"></a>

### 5. 季孙赴宋致女

夏天，季孙行父到宋国，办理伯姬出嫁后的致女礼。

[看对应原文](#source-cq-08-09-p005)

<details><summary>字句与编年说明</summary>

不凭礼名补全整个婚礼程序。

</details>

<a id="cq-08-09-p006"></a>

### 6. 晋送媵来鲁

晋人来鲁安排随嫁的媵。

[看对应原文](#source-cq-08-09-p006)

<a id="cq-08-09-p007"></a>

### 7. 齐侯无野去世

秋天七月丙子，齐侯无野去世。

[看对应原文](#source-cq-08-09-p007)

<a id="cq-08-09-p008"></a>

### 8. 晋扣郑伯

晋人扣押郑伯。

[看对应原文](#source-cq-08-09-p008)

<a id="cq-08-09-p009"></a>

### 9. 栾书伐郑

晋栾书率军攻郑。

[看对应原文](#source-cq-08-09-p009)

<a id="cq-08-09-p010"></a>

### 10. 葬齐顷公

冬天十一月，安葬齐顷公。

[看对应原文](#source-cq-08-09-p010)

<a id="cq-08-09-p011"></a>

### 11. 楚婴齐攻郑

楚公子婴齐率军伐郑。

[看对应原文](#source-cq-08-09-p011)

<a id="cq-08-09-p012"></a>

### 12. 莒国溃散

庚申，莒国发生溃散。

[看对应原文](#source-cq-08-09-p012)

<details><summary>字句与编年说明</summary>

具体因兵败或国内变动，原句未说明，不擅加敌方。

</details>

<a id="cq-08-09-p013"></a>

### 13. 楚入郓

楚人攻入郓。

[看对应原文](#source-cq-08-09-p013)

<a id="cq-08-09-p014"></a>

### 14. 秦与白狄伐晋

秦人和白狄共同攻晋。

[看对应原文](#source-cq-08-09-p014)

<a id="cq-08-09-p015"></a>

### 15. 郑围许，鲁修中城

郑人围许；鲁修筑中城。

[看对应原文](#source-cq-08-09-p015)

<details><summary>字句与编年说明</summary>

两项分别记，不把“城中城”误作郑在许筑两座城。

</details>

## 春秋经

<a id="cq-08-08-p001"></a>

### 1. 晋要求鲁把汶阳田还齐

春天，晋侯派韩穿来鲁，要求把汶阳之田归还齐国。

[看对应原文](#source-cq-08-08-p001)

<details><summary>字句与编年说明</summary>

要求与实际交割日期分开，不补本句没有的交割仪式。

</details>

<a id="cq-08-08-p002"></a>

### 2. 栾书侵蔡

晋栾书率军侵入蔡国。

[看对应原文](#source-cq-08-08-p002)

<a id="cq-08-08-p003"></a>

### 3. 公孙婴齐赴莒

公孙婴齐前往莒国。

[看对应原文](#source-cq-08-08-p003)

<a id="cq-08-08-p004"></a>

### 4. 华元来聘

宋公派华元来鲁访问。

[看对应原文](#source-cq-08-08-p004)

<a id="cq-08-08-p005"></a>

### 5. 宋送婚姻聘礼

夏天，宋公派公孙寿到鲁送聘礼。

[看对应原文](#source-cq-08-08-p005)

<a id="cq-08-08-p006"></a>

### 6. 晋杀赵同、赵括

晋国杀大夫赵同、赵括。

[看对应原文](#source-cq-08-08-p006)

<details><summary>字句与编年说明</summary>

不从后世戏曲填补屠岸贾、孤儿救亡等情节。

</details>

<a id="cq-08-08-p007"></a>

### 7. 召伯来赐命

秋天七月，周天子派召伯向成公赐命。

[看对应原文](#source-cq-08-08-p007)

<a id="cq-08-08-p008"></a>

### 8. 杞叔姬去世

冬天十月癸卯，杞叔姬去世。

[看对应原文](#source-cq-08-08-p008)

<a id="cq-08-08-p009"></a>

### 9. 士燮来聘

晋侯派士燮来鲁访问。

[看对应原文](#source-cq-08-08-p009)

<a id="cq-08-08-p010"></a>

### 10. 鲁晋齐邾伐郯

叔孙侨如会晋士燮、齐人、邾人，共同攻郯。

[看对应原文](#source-cq-08-08-p010)

<a id="cq-08-08-p011"></a>

### 11. 卫来送媵

卫人来鲁安排随嫁的媵。

[看对应原文](#source-cq-08-08-p011)

<details><summary>字句与编年说明</summary>

不把“媵”译成军事援军，也不无据补随嫁人数。

</details>

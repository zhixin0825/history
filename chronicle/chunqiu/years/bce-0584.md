## 春秋经

<a id="cq-08-07-p001"></a>

### 1. 郊牛角受鼠咬，改选祭牛

春天王正月，鼷鼠啃坏郊祭牛的角，鲁重新占卜选择祭牛。

[看对应原文](#source-cq-08-07-p001)

<a id="cq-08-07-p002"></a>

### 2. 替换的牛又受伤，遂免用

鼷鼠又咬坏替换之牛的角，鲁于是将这头牛放免、不再作郊祭用。

[看对应原文](#source-cq-08-07-p002)

<a id="cq-08-07-p003"></a>

### 3. 吴伐郯

吴国进攻郯国。

[看对应原文](#source-cq-08-07-p003)

<a id="cq-08-07-p004"></a>

### 4. 曹伯来朝

夏天五月，曹伯来鲁朝见。

[看对应原文](#source-cq-08-07-p004)

<a id="cq-08-07-p005"></a>

### 5. 不行郊祭，仍行三望

鲁没有举行郊祭，却仍举行三望祭。

[看对应原文](#source-cq-08-07-p005)

<a id="cq-08-07-p006"></a>

### 6. 楚婴齐再攻郑

秋天，楚公子婴齐率军伐郑。

[看对应原文](#source-cq-08-07-p006)

<a id="cq-08-07-p007"></a>

### 7. 九国救郑

成公与晋侯、齐侯、宋公、卫侯、曹伯、莒子、邾子、杞伯共同救郑。

[看对应原文](#source-cq-08-07-p007)

<a id="cq-08-07-p008"></a>

### 8. 马陵同盟

八月戊辰，诸侯在马陵共同结盟。

[看对应原文](#source-cq-08-07-p008)

<a id="cq-08-07-p009"></a>

### 9. 成公从会盟返回

成公回鲁。

[看对应原文](#source-cq-08-07-p009)

<a id="cq-08-07-p010"></a>

### 10. 吴军入州来

吴国军队攻入州来。

[看对应原文](#source-cq-08-07-p010)

<a id="cq-08-07-p011"></a>

### 11. 冬季大雩

冬天，鲁举行大雩求雨。

[看对应原文](#source-cq-08-07-p011)

<a id="cq-08-07-p012"></a>

### 12. 孙林父奔晋

卫孙林父逃往晋国。

[看对应原文](#source-cq-08-07-p012)

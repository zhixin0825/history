## 春秋经

<a id="cq-07-08-p001"></a>

### 1. 宣公从会中回来

春天，宣公从会合之行回鲁。

[看对应原文](#source-cq-07-08-p001)

<a id="cq-07-08-p002"></a>

### 2. 公子遂赴齐半途折返

夏天六月，公子遂去齐，到黄地后折返。

[看对应原文](#source-cq-07-08-p002)

<a id="cq-07-08-p003"></a>

### 3. 太庙祭祀时仲遂去世

辛巳，鲁在太庙祭祀；仲遂死于垂。

[看对应原文](#source-cq-07-08-p003)

<details><summary>字句与编年说明</summary>

两地并记，不说他死在太庙。

</details>

<a id="cq-07-08-p004"></a>

### 4. 继续绎祭但去籥

壬午，鲁仍继续绎祭，让万舞入场，却撤去籥这一部分音乐。

[看对应原文](#source-cq-07-08-p004)

<details><summary>字句与编年说明</summary>

万为舞名，不译成一万人进入。

</details>

<a id="cq-07-08-p005"></a>

### 5. 夫人嬴氏去世

戊子，夫人嬴氏去世。

[看对应原文](#source-cq-07-08-p005)

<a id="cq-07-08-p006"></a>

### 6. 晋与白狄攻秦

晋军和白狄共同攻秦。

[看对应原文](#source-cq-07-08-p006)

<a id="cq-07-08-p007"></a>

### 7. 楚灭舒、蓼

楚人攻灭经文所列的舒、蓼。

[看对应原文](#source-cq-07-08-p007)

<details><summary>字句与编年说明</summary>

源页以顿号分列，另一断作舒蓼的版本需并存，不把现代标点当绝对国名考证。

</details>

<a id="cq-07-08-p008"></a>

### 8. 七月日全食

秋天七月甲子发生日食，经文说食尽。

[看对应原文](#source-cq-07-08-p008)

<a id="cq-07-08-p009"></a>

### 9. 准备安葬敬嬴

冬天十月己丑，鲁安排安葬夫人敬嬴。

[看对应原文](#source-cq-07-08-p009)

<details><summary>字句与编年说明</summary>

与下一条因雨延迟合读，不说葬了两次。

</details>

<a id="cq-07-08-p010"></a>

### 10. 雨阻葬礼，次日中午才完成

因下雨未能下葬，到庚寅日中午才办成葬礼。

[看对应原文](#source-cq-07-08-p010)

<a id="cq-07-08-p011"></a>

### 11. 筑平阳城

鲁在平阳筑城。

[看对应原文](#source-cq-07-08-p011)

<a id="cq-07-08-p012"></a>

### 12. 楚军伐陈

楚军攻陈。

[看对应原文](#source-cq-07-08-p012)

## 春秋经

<a id="cq-07-01-p001"></a>

### 1. 宣公即位，公子遂迎亲

春天王正月，鲁宣公即位；公子遂去齐迎娶女子。

[看对应原文](#source-cq-07-01-p001)

<a id="cq-07-01-p002"></a>

### 2. 夫人姜氏来到鲁

三月，公子遂带着夫人姜氏从齐来到鲁。

[看对应原文](#source-cq-07-01-p002)

<a id="cq-07-01-p003"></a>

### 3. 季孙行父赴齐

夏天，季孙行父去齐。

[看对应原文](#source-cq-07-01-p003)

<a id="cq-07-01-p004"></a>

### 4. 晋放逐胥甲父

晋把大夫胥甲父放逐到卫国。

[看对应原文](#source-cq-07-01-p004)

<a id="cq-07-01-p005"></a>

### 5. 鲁齐会平州

宣公与齐侯在平州会面。

[看对应原文](#source-cq-07-01-p005)

<a id="cq-07-01-p006"></a>

### 6. 公子遂赴齐

公子遂去齐国。

[看对应原文](#source-cq-07-01-p006)

<a id="cq-07-01-p007"></a>

### 7. 齐取济西田

六月，齐人取得鲁在济西的田地。

[看对应原文](#source-cq-07-01-p007)

<a id="cq-07-01-p008"></a>

### 8. 邾子来朝

秋天，邾子来鲁朝见。

[看对应原文](#source-cq-07-01-p008)

<a id="cq-07-01-p009"></a>

### 9. 楚郑侵陈、宋

楚子与郑军侵陈，随后侵宋。

[看对应原文](#source-cq-07-01-p009)

<a id="cq-07-01-p010"></a>

### 10. 赵盾救陈

晋赵盾率军救陈。

[看对应原文](#source-cq-07-01-p010)

<a id="cq-07-01-p011"></a>

### 11. 五方会棐林伐郑

宋公、陈侯、卫侯、曹伯在棐林会合晋军，共同攻郑。

[看对应原文](#source-cq-07-01-p011)

<a id="cq-07-01-p012"></a>

### 12. 赵穿侵崇

冬天，晋赵穿率军侵崇。

[看对应原文](#source-cq-07-01-p012)

<a id="cq-07-01-p013"></a>

### 13. 晋宋伐郑

晋、宋两国军队进攻郑。

[看对应原文](#source-cq-07-01-p013)

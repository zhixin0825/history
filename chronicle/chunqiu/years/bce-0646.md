# 公元前646年（鲁僖公十四年）

[上一年：前647](bce-0647.md) · [目录](../README.md) · [下一年：前645](bce-0645.md)

1. **春，诸侯为躲避淮夷威胁，在缘陵筑城并迁移杞国。** 杞国在齐桓公体系保护下获得新的安置地。[1]

2. **夏，季姬在防地会见鄫子，并要求鄫子来鲁朝见。** 此前鄫子长期不朝，季姬回鲁后受到庄公留置，这次通过会面推动鄫国履行礼节。[2]

3. **秋八月，沙鹿山崩。** 晋国卜偃据此预言次年将发生足以危及国家的大灾祸。[3]

4. **秋，狄人侵郑。** 郑国继续面对北方部族压力。[4]

5. **冬，秦国发生饥荒，向晋国求粮；晋惠公却拒绝回报秦国。** 庆郑等大夫指出，秦国此前在晋饥时大规模输粮，如今拒绝救秦既背施又幸灾，必将失去民心和外援。[5]

6. **冬，蔡侯去世。** 蔡国进入君主更替。[6]

## 本年相关史料

1. **《春秋·僖公十四年》**：“十有四年春，诸侯城缘陵。”  
   **《左传·僖公十四年》**：“诸侯城缘陵而迁杞焉。”

2. **《春秋·僖公十四年》**：“夏六月，季姬及鄫子遇于防，使鄫子来朝。”  
   **《左传·僖公十四年》**详记季姬来宁、僖公因鄫子不朝而留她。

3. **《春秋·僖公十四年》**：“秋八月辛卯，沙鹿崩。”  
   **《左传·僖公十四年》**载卜偃预言“期年将有大咎”。

4. **《春秋·僖公十四年》**：“狄侵郑。”

5. **《左传·僖公十四年》**详记秦饥乞籴于晋，晋拒绝，庆郑以“背施无亲，幸灾不仁”力谏。

6. **《春秋·僖公十四年》**：“冬，蔡侯肸卒。”

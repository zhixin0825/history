# 公元前647年（鲁僖公十三年）

[上一年：前648](bce-0648.md) · [目录](../README.md) · [下一年：前646](bce-0646.md)

1. **春，狄人进攻卫国。** 北方边患持续。[1]

2. **夏，鲁国安葬陈宣公；同月齐桓公召集鲁、宋、陈、卫、郑、许、曹等国在咸地会盟。** 淮夷正在侵扰杞国，诸侯同时还要继续处理周王室问题。[2]

3. **秋，因为王室仍受戎患威胁，诸侯派兵戍守周都。** 齐国仲孙湫负责协调这次驻防。[3]

4. **冬，晋国发生饥荒，向秦国请求购粮。** 秦国内部有人主张趁机伐晋，秦穆公拒绝，认为晋君有过，百姓无罪。[4]

5. **秦国从雍地沿黄河一路运粮到晋都绛，史称“泛舟之役”。** 秦晋关系在韩原之战前仍保留着明显的救灾与恩惠关系。[5]

6. **冬，公子友前往齐国。** 鲁齐外交继续保持。[6]

## 本年相关史料

2. **《春秋·僖公十三年》**：“夏四月，葬陈宣公。公会齐侯、宋公、陈侯、卫侯、郑伯、许男、曹伯于鹹。”  
   **《左传·僖公十三年》**：“会于鹹，淮夷病杞故，且谋王室也。”

3. **《左传·僖公十三年》**：“秋，为戎难故，诸侯戍周，齐仲孙湫致之。”

4. **《左传·僖公十三年》**详记晋饥向秦乞籴，百里奚主张“救灾恤邻”。

5. **《左传·僖公十三年》**：“秦于是乎输粟于晋，自雍及绛，相继。命之曰‘汎舟之役’。”

6. **《春秋·僖公十三年》**：“冬，公子友如齐。”

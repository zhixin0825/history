# 公元前654年（鲁僖公六年）

[上一年：前655](bce-0655.md) · [目录](../README.md) · [下一年：前653](bce-0653.md)

1. **春，晋国攻打夷吾所在的屈地，夷吾无法守住，转而逃往梁国。** 晋献公几位成年公子都已离开国都。[1]

2. **夏，齐桓公率鲁、宋、陈、卫、曹等诸侯伐郑，包围新密。** 这是对郑伯逃离首止盟会的惩罚。[2]

3. **秋，楚国包围许国，以迫使齐国联盟放弃伐郑；诸侯转而救许，最终撤军。** 齐楚双方继续通过援助盟国间接竞争。[3]

4. **冬，许僖公亲自到楚国请罪，采取面缚衔璧、士舆榇的降服礼。** 楚王参照周武王处置微子的先例，解开束缚、接受玉璧并让许君复国。[4]

## 本年相关史料

1. **《左传·僖公六年》**：“晋侯使贾华伐屈，夷吾不能守……乃之梁。”

2. **《春秋·僖公六年》**：“夏，公会齐侯、宋公、陈侯、卫侯、曹伯伐郑，围新城。”  
   **《左传·僖公六年》**：“以其逃首止之盟故也。围新密。”

   **说明：** 经文作“新城”，传文作“新密”；正文只写围攻郑国要地，不据此强行校定地名。

3. **《春秋·僖公六年》**：“秋，楚人围许。诸侯遂救许。”

4. **《左传·僖公六年》**详记许男面缚衔璧、舆榇见楚王，楚王依微子旧礼释之。

## 春秋经

<a id="cq-05-04-p001"></a>

### 1. 诸侯先攻蔡，再进楚

春天王正月，僖公与齐侯、宋公、陈侯、卫侯、郑伯、许男、曹伯联合侵蔡，蔡军溃散；联军接着攻楚，驻在陉。

[看对应原文](#source-cq-05-04-p001)

<a id="cq-05-04-p002"></a>

### 2. 许男新臣去世

夏天，许国国君新臣去世。

[看对应原文](#source-cq-05-04-p002)

<a id="cq-05-04-p003"></a>

### 3. 屈完到军中，在召陵结盟

楚国屈完来到联军中议盟，双方在召陵结盟。

[看对应原文](#source-cq-05-04-p003)

<a id="cq-05-04-p004"></a>

### 4. 齐扣辕涛涂

齐人扣押陈国辕涛涂。

[看对应原文](#source-cq-05-04-p004)

<a id="cq-05-04-p005"></a>

### 5. 鲁与江黄伐陈

秋天，鲁方会同江人、黄人进攻陈国。

[看对应原文](#source-cq-05-04-p005)

<details><summary>字句与编年说明</summary>

原句未列鲁方个人姓名。

</details>

<a id="cq-05-04-p006"></a>

### 6. 僖公从伐楚军中回来

八月，僖公结束伐楚之行回国。

[看对应原文](#source-cq-05-04-p006)

<a id="cq-05-04-p007"></a>

### 7. 葬许穆公

安葬许穆公。

[看对应原文](#source-cq-05-04-p007)

<a id="cq-05-04-p008"></a>

### 8. 公孙兹会六国侵陈

冬天十二月，公孙兹率军，与齐、宋、卫、郑、许、曹军一起侵陈。

[看对应原文](#source-cq-05-04-p008)

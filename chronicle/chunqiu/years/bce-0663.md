# 公元前663年（鲁庄公三十一年）

[上一年：前664](bce-0664.md) · [目录](../README.md) · [下一年：前662](bce-0662.md)

1. **春，鲁国在郎地筑台；夏又在薛地筑台；秋再在秦地筑台。** 一年之内连续修建高台，显示庄公后期频繁兴作。[1]

2. **夏四月，薛伯去世。** 薛国发生君主更替。[2]

3. **六月，齐桓公把讨伐山戎所得的战果送到鲁国展示。** 按当时礼制，诸侯击败四夷应当向周王献功，而不是彼此赠送俘获，因此受到批评。[3]

4. **冬，鲁国长期不雨。** 旱情开始显现。[4]

## 本年相关史料

1. **《春秋·庄公三十一年》**：“三十有一年春，筑台于郎……筑台于薛……秋，筑台于秦。”

2. **《春秋·庄公三十一年》**：“夏四月，薛伯卒。”

3. **《春秋·庄公三十一年》**：“六月，齐侯来献戎捷。”  
   **《左传·庄公三十一年》**：“诸侯有四夷之功，则献于王……诸侯不相遗俘。”

4. **《春秋·庄公三十一年》**：“冬，不雨。”

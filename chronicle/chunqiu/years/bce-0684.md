# 公元前684年（鲁庄公十年）

[上一年：前685](bce-0685.md) · [目录](../README.md) · [下一年：前683](bce-0683.md)

1. **春，齐军伐鲁，鲁庄公在长勺迎战。** 曹刿认为战争胜负取决于能否取得民众信任，庄公以处理诉讼尽量合情作为可以一战的依据。[1]

2. **长勺之战中，曹刿等齐军三次击鼓后才让鲁军进攻，又确认齐军车辙混乱、旗帜倒伏后才追击。** 鲁军最终击败齐军，形成著名的“一鼓作气”战例。[2]

3. **二月，鲁国进攻宋国。** 鲁齐战后，鲁国又把军事行动转向宋国。[3]

4. **夏，齐、宋联军驻郎地准备进攻鲁国；鲁将公子偃先行袭击宋军，在乘丘大败宋师，齐军随即撤走。** 鲁国连续两次击退外来进攻。[4]

5. **息侯借楚国报复蔡哀侯，楚军在莘地击败蔡军，并俘获蔡侯献舞。** 一次姻亲礼遇纠纷被放大成楚国向中原扩张的机会。[5]

6. **冬，齐桓公灭谭，谭君逃往莒国。** 齐桓公此前经过谭国时未受礼遇，复位后各国来贺，谭国又没有来，因此齐国出兵灭谭。[6]

## 本年相关史料

1. **《春秋·庄公十年》**：“十年春，王正月，公败齐师于长勺。”  
   **《左传·庄公十年》**详记曹刿请见并问“何以战”。

2. **《左传·庄公十年》**详记齐人三鼓后鲁军出击，并有“一鼓作气，再而衰，三而竭”之说。

3. **《春秋·庄公十年》**：“二月，公侵宋。”

4. **《春秋·庄公十年》**：“夏六月，齐师、宋师次于郎。公败宋师于乘丘。”  
   **《左传·庄公十年》**详记公子偃擅自先击宋军，庄公随后跟进。

5. **《春秋·庄公十年》**：“秋九月，荆败蔡师于莘，以蔡侯献舞归。”  
   **《左传·庄公十年》**详记蔡、息婚姻纠纷与息侯借楚伐蔡。

6. **《春秋·庄公十年》**：“冬十月，齐师灭谭。谭子奔莒。”  
   **《左传·庄公十年》**：“谭无礼也。”

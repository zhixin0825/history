# 公元前702年（鲁桓公十年）

[上一年：前703](bce-0703.md) · [目录](../README.md) · [下一年：前701](bce-0701.md)

1. **春，曹桓公去世；五月下葬。** 曹国完成君主更替，鲁国按诸侯礼制记录其丧事。[1]

2. **虢仲在周王面前诬告大夫詹父，詹父反而借王师进攻虢国，虢公逃到虞国。** 周王室内部的权力斗争直接演变成武装冲突。[2]

3. **秋，秦国把芮伯万送回芮国。** 芮伯此前被周、秦联军抓走，这一年重新回到本国。[3]

4. **虞叔先后被虞公索要玉璧和宝剑，最终起兵攻打虞公，虞公逃往共池。** 虞叔最初不愿献玉，后来担心“怀璧其罪”才交出；虞公得寸进尺又要宝剑，虞叔认为对方贪得无厌，索性先发制人。[4]

5. **秋，鲁桓公准备与卫侯在桃丘会面，却没有真正相见。** 这次会面没有完成，现存记载也没有再交代具体原因。[5]

6. **冬十二月，齐、卫、郑联军来到郎地同鲁军交战。** 导火索可追溯到此前北戎攻齐：郑太子忽救齐有大功，齐国犒劳诸侯时让鲁国按周礼排班，把郑国排在鲁国之后。郑国对此长期不满，最终联合齐、卫对鲁动兵。[6]

## 本年相关史料

1. **《春秋·桓公十年》**：“十年春，王正月庚申，曹伯终生卒。夏五月，葬曹桓公。”

2. **《左传·桓公十年》**：“虢仲谮其大夫詹父于王。詹父有辞，以王师伐虢。夏，虢公出奔虞。”

3. **《左传·桓公十年》**：“秋，秦人纳芮伯万于芮。”

4. **《左传·桓公十年》**详记虞叔献玉又被索剑，遂“伐虞公，故虞公出奔共池”。

5. **《春秋·桓公十年》**：“秋，公会卫侯于桃丘，弗遇。”

6. **《春秋·桓公十年》**：“冬十有二月丙午，齐侯、卫侯、郑伯来战于郎。”  
   **《左传·桓公十年》**详叙北戎攻齐后鲁国排班“后郑”，郑人因此愤怒，遂请齐师并联卫军来战。

# 公元前708年（鲁桓公四年）

[上一年：前709](bce-0709.md) · [目录](../README.md) · [下一年：前707](bce-0707.md)

1. **春正月，鲁桓公在郎地狩猎。** 这次狩猎发生在合适的季节，被视为正常的国君田猎活动。[1]

2. **夏，周王派宰渠伯纠到鲁国聘问。** 这是周王室与鲁国之间的一次正式外交往来。[2]

3. **秋，秦军进攻芮国，却遭到失败。** 芮国内乱已经持续数年，秦国开始直接介入。[3]

4. **冬，周王师与秦军联合包围魏地，抓获芮伯并带走。** 芮国的内部纷争最终演变为周、秦共同出兵。[4]

## 本年相关史料

1. **《春秋·桓公四年》**：“四年春正月，公狩于郎。”  
   **《左传·桓公四年》**：“书时，礼也。”

2. **《春秋·桓公四年》**：“夏，天王使宰渠伯纠来聘。”  
   **《左传·桓公四年》**：“周宰渠伯纠来聘。”

3. **《左传·桓公四年》**：“秋，秦师侵芮，败焉。”

4. **《左传·桓公四年》**：“冬，王师、秦师围魏，执芮伯以归。”

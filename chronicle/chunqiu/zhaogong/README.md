## 第二段几个重要取舍

- **十二年朝晋至河而返：** 《史记》写“晋平公谢还之”，但晋平公已在十年去世；正文依经传本年叙事与取郠之诉，不沿用这一称谓。
- **十三年楚灵王之死：** 《春秋》把“弑君”归在公子比，《史记》归到弃疾；《左传》具体记灵王自缢、子干也自杀。正文用《左传》交代死法，把“弑”作为经史责任归属放在脚注。
- **十五年至十六年昭公留晋：** 昭公十五年冬赴晋，十六年春仍被留、夏归鲁；晋昭公十六年秋才死。故《史记》“留之葬晋昭公”不能按字面照录。
- **二十年齐景公入鲁问礼：** 《史记》有记载，《左传》无。三家注已指出这一点，后世又有真伪争论，所以作为《史记》独载材料保留。

梦、鬼神、占候、预言都按“记载中的信念与解释”展示，不确认为客观因果。人物评论与事实分层，回叙不重新计成本年事件。

本批仍未完成现代整理本、专题论文和《史记》其他篇章的全量交叉校勘；因此“完成”仍只表示第一轮可读整理和逐段去向检查通过。

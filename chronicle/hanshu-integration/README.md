# 《汉书》汇入现有逐年年表

《汉书》继续沿用本项目已经确认的规则：**一年一页、先讲清楚事情、同一事件多书合并、冲突进史料说明、无法确年的前事不强行编年。** 正文仍放在 `chronicle/years/`，本目录只保存《汉书》的章节切分、段落去向和版本核查记录。

## 第一批：高帝纪，前209—前206

- [前207年](../years/bce-0207.md)：刘邦推进南阳、武关、蓝田；赵高杀二世，子婴诛赵高。

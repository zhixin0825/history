## 与《汉书》的衔接

公元22—23年仍处王莽末年，是《汉书》尾声与《后汉书》开篇的重叠区。这里先完成《后汉书》层的审读，不抢写第二套年度正文；另一个《汉书》工作流完成相同年份后，应以**同一事件合并、互见注明差异**的方式汇入。

公元24年以后《汉书》不再覆盖，东汉部分以《资治通鉴》作逐年骨架，《后汉书》作为首要正史补充。列传中的早年事、未确年故事、史家论赞仍按既定规则分别处理，不因传记叙次强行定年。

## 第一批的几个重要口径

昆阳兵力数字按史书原载保存，但正文不把“百万”“甲士四十二万”当作现代意义上已经核实的精确统计；《通鉴》与《后汉书》互见也不自动算两份独立证据。

滹沱河“适逢冰合”、赤伏符等内容属于史书实际记载，可以讲清楚“史书记作什么”，但不把祥瑞、谶纬转述成已证实的自然或超自然因果。

刘秀在25年六月即位，不等于当时天下已经统一；同月赤眉立刘盆子，公孙述已称帝，更始政权尚未立即消失。年度叙事要保留这种并立格局。

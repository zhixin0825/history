# 逐年读《晋书》｜工作入口

> 状态：**卷一《宣帝纪》第一批已开始拆年**。目前只表示下列《晋书》材料已经逐段审读并找到去向，不表示《晋书》全书或这些年份的全部史事已经完成。

## 我们怎么处理《晋书》

继续沿用总项目已经确认的规则：

- 正文直接讲历史，不把“某书说”写成叙事主体；原文、异文、取舍理由统一放在同号史料说明。
- 能确定实际年份的材料，放回实际年份。卷一虽然是《晋书》，但从司马懿在汉末、曹魏时期写起，所以本书的第一张可确定年份页是 **201年（建安六年）**，不是265年。
- 一段传记里如果前后跳年，先拆开，再归年，不按原文段落顺序硬塞。
- 人物首次进入有据可编的事件时，可以补“登场前事”，但明确说明这些背景并不都发生在该年。
- 只有相对先后、没有可靠年份的材料放到 [未确年材料](UNPLACED.md)，不为了页面整齐强行定年。
- 同一事件出现不同归功、不同细节时，正文采用能够共同支持的叙述，差异留在史料说明。

## 下一步的自然接点

卷一接下来从黄初二年继续，随后是司马懿在魏明帝时期的军事与辅政经历。处理方法仍然是逐段拆年；到265年以后，再把《晋书》本纪与《资治通鉴》晋纪按同一年合并，不另造一套互不相通的“晋书年代”。

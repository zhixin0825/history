# 逐年读《史记》｜累计进度

原文130篇全部建立索引；目前 **9篇逐段分流初审**。累计 **240条来源记录**，明确合并后 **236个叙述单元、74张年份页**。

**不是全书编年完成，也不是这些年份已搜齐所有史料。** 源记录包含事件、背景、评论与异说；这些数字不是经过独立复核的原子事件总数。

本轮增加《吴太伯世家》《司马穰苴列传》《孙子吴起列传》《伍子胥列传》，重点处理互见、跨年、人物登场。原有五篇及旧链接保留。

# 未确年、跨年与人物背景

[返回目录](../README.md)

这些记录没有被丢弃，只是不伪造年份。保留原篇次序，继续寻找年代锚点。

<a id="sj-029-L2876-01"></a>

### 禹治洪水、分九州

**时间：传说中的禹时代** · 记载

《河渠书》引用《夏书》，说禹治水十三年，经过家门也不进去。他按不同地形换用交通工具，疏通山川，把各地分成九州，并按土地情况安排贡赋。叙述尤其强调黄河泛滥的危害，接着列出导河线路及入海的安排。

[《史记》卷29 河渠书 L2876](sources.md#ref-sj-2876)

<details><summary>归年依据与待核问题</summary>

上古叙述保留；十三年是历时，不是公元纪年。

</details>

<a id="sj-029-L2877-01"></a>

### 各地开渠行船，也用水灌田

**时间：跨地区、跨时代** · 背景

这一段接连讲到鸿沟以及楚、吴、齐等地的水道，说明河渠既供行船，也供灌溉。它是在总览各地水利，不是说这些工程同时开工。

[《史记》卷29 河渠书 L2877](sources.md#ref-sj-2877)

<details><summary>归年依据与待核问题</summary>

不同地区工程分别保留检索入口，尚未逐渠核年。

</details>

<a id="sj-029-L2877-02"></a>

### 蜀守冰治理水道

**时间：蜀守冰任内，未记年** · 事件

书中说，蜀守冰开凿离碓，排除沫水造成的水患，让两条水道穿过成都；水道可以行船，多出来的水也用来灌田。

[《史记》卷29 河渠书 L2877](sources.md#ref-sj-2877)

<details><summary>归年依据与待核问题</summary>

原文只称蜀守冰；不从模型记忆补入某个开工年份。

</details>

<a id="sj-029-L2878-01"></a>

### 西门豹引漳水灌田

**时间：西门豹在邺时** · 事件

西门豹把漳水引到邺地灌溉。《史记》把魏国河内地区因此富庶的变化归功于这项工程。

[《史记》卷29 河渠书 L2878](sources.md#ref-sj-2878)

<details><summary>归年依据与待核问题</summary>

未记确年，也不把后来长期收益当成开工当天的结果。

</details>

<a id="sj-029-L2879-02"></a>

### 郑国身份败露，秦仍让他完成工程

**时间：郑国渠施工中及竣工后** · 事件

施工途中，秦发现郑国原来受韩国派遣，准备杀他。郑国承认最初的任务，却指出渠建成也会使秦受益。秦接受了这个说法，仍让他完成工程。书中接着说，渠成后灌溉四万余顷，关中因而富庶；这些是后续工程和效益记载。

[《史记》卷29 河渠书 L2879](sources.md#ref-sj-2879) · [《资治通鉴》卷6 L354](sources.md#ref-tj006-354-361)

<details><summary>归年依据与待核问题</summary>

竣工没有在所引原文中单独记年；不由“元年”给整个故事统一打日期。

</details>

<a id="sj-029-L2881-02"></a>

### 田蚡反对继续强堵

**时间：瓠子决口之后** · 事件

《史记》说，田蚡的食邑在黄河北边，河水南流时那里没有遭灾，收成反而多。他向皇帝主张，江河决口是天事，不容易靠人力强堵；望气占数的人也赞同。随后朝廷长期没有再继续堵口。

[《史记》卷29 河渠书 L2881](sources.md#ref-sj-2881) · [《资治通鉴》卷18 L117](sources.md#ref-tj018-117-123)

<details><summary>归年依据与待核问题</summary>

利益关系与动机归于《史记》的解释；“久之”不强定为元光三年内。

</details>

<a id="sj-029-L2882-02"></a>

### 漕渠花了三年才通

**时间：元光六年启动后，三岁而通** · 事件

工程不是批准后马上就成了。《史记》说，漕渠经过三年开通，运粮因此方便，后来运量逐渐增加，沿渠居民也得到灌溉之利。

[《史记》卷29 河渠书 L2882](sources.md#ref-sj-2882) · [《资治通鉴》卷18 L351](sources.md#ref-tj018-351-354)

<details><summary>归年依据与待核问题</summary>

保留“三岁而通”；未指定算法把它强算成一个竣工公历年。

</details>

<a id="sj-029-L2883-01"></a>

### 河东开渠种田，预计收益没有实现

**时间：其后数岁、久之** · 事件

河东守番系提出，引汾水和黄河水灌溉，可以利用大片河边闲地，并减少粮食运过砥柱的损失。皇帝批准并征人施工。但几年后黄河改道，渠不好用了，种地连种子成本也收不回来；更晚时工程田被放弃，改给越人使用。

[《史记》卷29 河渠书 L2883](sources.md#ref-sj-2883)

<details><summary>归年依据与待核问题</summary>

五千顷、二百万石是方案估计，不是验收统计；起讫年仍待定位。

</details>

<a id="sj-029-L2884-01"></a>

### 褒斜道修成，水路运粮却不通

**时间：张汤任御史大夫期间** · 事件

有人提议打通褒斜道，并把褒水、斜水接入运粮线路。张汤询问后支持方案，朝廷任命他的儿子卬为汉中守，征发数万人修路。陆路确实更近，但水流急、石头多，设想中的漕运没有实现。

[《史记》卷29 河渠书 L2884](sources.md#ref-sj-2884)

<details><summary>归年依据与待核问题</summary>

以官职作相对年代线索，不把文中的“其后”自动当作次年。

</details>

<a id="sj-029-L2885-01"></a>

### 龙首渠用了井下相通的办法

**时间：龙首渠施工十余年** · 事件

庄熊罴提出引洛水灌溉重泉以东的盐碱地。施工遇到容易坍塌的河岸，就开凿深井，在井下相通引水。书中说因挖到龙骨而得名龙首渠。工程做了十多年，水道渐通，但还没有得到预期的丰收。

[《史记》卷29 河渠书 L2885](sources.md#ref-sj-2885)

<details><summary>归年依据与待核问题</summary>

“龙骨”为原书记载的命名缘由；不判断其现代生物类别，也不补开工年份。

</details>

<a id="sj-029-L2888-01"></a>

### 各地接着争相兴办水利

**时间：宣房堵口以后** · 背景

宣房工程之后，官员纷纷提出水利项目。书中列出朔方、西河、河西、酒泉、关中、汝南、九江、东海、泰山等地引河灌田的情况，也说许多小渠难以一一数清。

[《史记》卷29 河渠书 L2888](sources.md#ref-sj-2888)

<details><summary>归年依据与待核问题</summary>

这是跨地区、跨年综述，保留全部地名，不移入某一个年度的已完成项目清单。

</details>

### 管仲怎样谈治国和民生

**时间：管仲执政期间** · 背景

《史记》把发展贸易、积聚财富以及顺应民众需要，归入管仲的施政。它引用“仓廪实而知礼节”等话，说明这种主张先关心衣食，再谈礼节荣辱。

[《史记》卷62 管晏列传 L4594](sources.md#ref-sj-4594)

<details><summary>归年依据与待核问题</summary>

<a id="sj-062-L4596-01"></a>

### 管仲的财富和齐国后来的施政

**时间：管仲在世及去世以后** · 背景

《史记》说管仲的财富接近齐国公室，齐人没有因此把他视为奢侈；他死后，齐国仍沿用其政。随后叙述一下跳到一百多年后的晏子。

[《史记》卷62 管晏列传 L4596](sources.md#ref-sj-4596)

<details><summary>归年依据与待核问题</summary>

本轮不从这一段推出死亡年份；管仲之死的具体系年留待专门比对。

</details>

<a id="sj-062-L4599-01"></a>

</details>

<a id="sj-062-L4600-01"></a>

### 陈胜旧友获罪，门客逐渐离去

**时间：陈胜在位的六个月内** · 事件

陈胜做王后，旧日一起耕田的人来见他，在宫中直言旧事。有人说这损害王的威望，陈胜于是杀了旧友；书中说此后故人逐渐离开。

## 完整可读快照

<div><p><b>鄭桓公</b>（？—771），<a title="姬姓"><b>姬</b>姓</a>，名<b>友</b><sup id="cite_ref-友_1-0"><a href="#cite_note-友-1"><span>[</span>1<span>]</span></a></sup>，或稱<b>多父</b><sup id="cite_ref-“多父”_2-0"><a href="#cite_note-“多父”-2"><span>[</span>2<span>]</span></a></sup>，是<a title="中國">中國</a><a title="周代">周代</a><a title="鄭國">鄭國</a>的開國君主。
</p>

<div><h2 id="出身"><span id=".E5.87.BA.E8.BA.AB"></span>出身</h2></div>
<a id="cited-2"></a><p>傳世經典文獻中，《<a title="史记">史记</a>》称他是<a title="周厉王">周厉王</a>的兒子，<a title="周宣王">周宣王</a>的弟弟<sup id="cite_ref-友_1-1"><a href="#cite_note-友-1"><span>[</span>1<span>]</span></a></sup>。《<a title="左傳">左傳</a>》亦稱鄭國以厲王為祖<sup id="cite_ref-3"><a href="#cite_note-3"><span>[</span>3<span>]</span></a></sup><sup id="cite_ref-4"><a href="#cite_note-4"><span>[</span>4<span>]</span></a></sup><sup id="cite_ref-5"><a href="#cite_note-5"><span>[</span>5<span>]</span></a></sup>。唯《<a title="國語 (書)">國語</a>》稱「鄭出自宣王」，不過<a title="韋昭">韋昭</a>注釋為鄭國封出于周宣王時<sup id="cite_ref-6"><a href="#cite_note-6"><span>[</span>6<span>]</span></a></sup>。
</p><a id="cited-3"></a><p>已失傳的《<a title="竹书纪年">竹书纪年</a>》對鄭桓公的身世説法保存在《水經注·洧水》中，但由於文字傳抄訛誤，變成了「同惠王子多父」<sup id="cite_ref-“多父”_2-1"><a href="#cite_note-“多父”-2"><span>[</span>2<span>]</span></a></sup>。唐代<a title="劉知幾">劉知幾</a>的《<a title="史通">史通</a>》提到《竹書紀年》稱「鄭桓公厲王之子」，但劉知幾要舉出的是《竹書紀年》與經典文獻的不同之處<sup id="cite_ref-7"><a href="#cite_note-7"><span>[</span>7<span>]</span></a></sup>，<a title="雷學淇">雷學淇</a>等人因此主張《竹書紀年》原本的記載是鄭桓公為宣王之子<sup id="cite_ref-8"><a href="#cite_note-8"><span>[</span>8<span>]</span></a></sup>。張以仁指出，「厲」訛變為「惠」遠比「宣」訛變為「惠」的可能性大得多<sup id="cite_ref-9"><a href="#cite_note-9"><span>[</span>9<span>]</span></a></sup>。又有學者提出或爲劉知幾據《國語》「鄭出自宣王」等文誤會鄭桓公為宣王之子，不宜據此妄改《水經注》所引《紀年》<sup id="cite_ref-10"><a href="#cite_note-10"><span>[</span>10<span>]</span></a></sup>。<a title="清華簡">清華簡</a>被發現後，由於曾與<a title="周平王">周平王</a>並立的<a title="周攜王">周攜王</a>在清華簡中被稱為「攜惠王」或「惠王」，因此也有學者認為《水經注》所引《紀年》文字並無訛誤，且「同惠王子多父」中的「子」應理解為「使」，即派遣，與鄭桓公身世無關<sup id="cite_ref-11"><a href="#cite_note-11"><span>[</span>11<span>]</span></a></sup>。
</p>
<div><h2 id="問策逃死"><span id=".E5.95.8F.E7.AD.96.E9.80.83.E6.AD.BB"></span>問策逃死</h2></div>
<a id="cited-5"></a><p>前806年，周宣王封鄭桓公於<a title="鄭">鄭</a>（今<a title="陝西省">陝西省</a><a title="渭南市">渭南市</a><a title="华州区">華州区</a>東北）<sup id="cite_ref-12"><a href="#cite_note-12"><span>[</span>12<span>]</span></a></sup>。<a title="周幽王">周幽王</a>八年，桓公被委任為<a title="司徒">司徒</a>，得到百姓愛戴<sup id="cite_ref-司徒_13-0"><a href="#cite_note-司徒-13"><span>[</span>13<span>]</span></a></sup><sup id="cite_ref-14"><a href="#cite_note-14"><span>[</span>14<span>]</span></a></sup>。一年後，桓公深感周地局勢不穩，詢問周<a title="伯阳父">太史伯</a>「逃死」之策<sup id="cite_ref-15"><a href="#cite_note-15"><span>[</span>15<span>]</span></a></sup><sup id="cite_ref-16"><a href="#cite_note-16"><span>[</span>16<span>]</span></a></sup>。史伯指出河洛之間的<a title="東虢國">虢</a>、<a title="郐">鄶</a>之君驕貪，鄭桓公可以用財物向兩國買來土地。等到周王室動亂傾覆后，虢、鄶必然背叛桓公，届時桓公如果憑藉<a title="成周">成周</a>的人馬奉辭伐罪，定能攻滅<sup id="cite_ref-17"><a href="#cite_note-17"><span>[</span>17<span>]</span></a></sup>。
</p><p>鄭桓公表示欲把封國遷至南方<a title="長江流域">長江流域</a>或<a title="謝國">謝</a>（今<a title="河南省">河南省</a><a title="南阳市">南阳市</a><a title="宛城区">宛城区</a>）以西，史伯表示周朝衰敗後<a title="楚國">楚國</a>將於南方興起，遷至長江附近會使國家處於不利之地<sup id="cite_ref-18"><a href="#cite_note-18"><span>[</span>18<span>]</span></a></sup><sup id="cite_ref-19"><a href="#cite_note-19"><span>[</span>19<span>]</span></a></sup>；又稱謝地以西的人民性格貪婪殘忍，不可親近，只有<a title="謝國">謝</a>、<a title="郟縣">郟</a>之間國君驕奢、人民懈怠，容易攻取而且能長治久安<sup id="cite_ref-20"><a href="#cite_note-20"><span>[</span>20<span>]</span></a></sup>。史伯又說如今<a title="申國">申國</a>、<a title="鄫國">繒國</a>等諸侯和<a title="西戎">西戎</a>勢強，而王室如今動蕩不安，恐怕不出三年就要滅亡，勸桓公早做準備、以免禍及己身<sup id="cite_ref-21"><a href="#cite_note-21"><span>[</span>21<span>]</span></a></sup>。
</p><p>桓公聽從史伯的建議，以財物向<a title="東虢國">虢</a>、<a title="鄶國">鄶</a>等十<a title="邑">邑</a>購買土地，預備為新鄭國的<a title="领土">领土</a><sup id="cite_ref-22"><a href="#cite_note-22"><span>[</span>22<span>]</span></a></sup><sup id="cite_ref-23"><a href="#cite_note-23"><span>[</span>23<span>]</span></a></sup>。
</p>
<div><h2 id="出周東遷"><span id=".E5.87.BA.E5.91.A8.E6.9D.B1.E9.81.B7"></span>出周東遷</h2></div>
<p>周幽王十一年，西戎<a title="犬戎攻周之戰">攻陷</a><a title="镐京">镐京</a>，殺<a title="周幽王">周幽王</a>。一般根據《史記》的說法，鄭桓公因勤王被殺，其子掘突繼位，是為<a title="鄭武公">鄭武公</a><sup id="cite_ref-24"><a href="#cite_note-24"><span>[</span>24<span>]</span></a></sup>。《<a title="漢書">漢書</a>》亦說鄭桓公死後，鄭武公與平王東遷，滅了<a title="鄭滅虢之戰">虢</a>、<a title="鄭滅鄶之戰">鄶</a>二國<sup id="cite_ref-25"><a href="#cite_note-25"><span>[</span>25<span>]</span></a></sup>。
</p><p>然而，《<a title="左傳">左傳</a>》《<a title="韓非子">韓非子</a>》《<a title="清華簡">清華簡</a>》等先秦文獻卻說鄭桓公成功出周滅鄶<sup id="cite_ref-26"><a href="#cite_note-26"><span>[</span>26<span>]</span></a></sup><sup id="cite_ref-27"><a href="#cite_note-27"><span>[</span>27<span>]</span></a></sup><sup id="cite_ref-28"><a href="#cite_note-28"><span>[</span>28<span>]</span></a></sup><sup id="cite_ref-29"><a href="#cite_note-29"><span>[</span>29<span>]</span></a></sup>。尤其是《漢書》<a title="臣瓚">臣瓚</a>注明確表示滅鄶、虢二國乃是鄭桓公在周幽王死後完成的<sup id="cite_ref-30"><a href="#cite_note-30"><span>[</span>30<span>]</span></a></sup>，其內容可與《竹書紀年》的記載相參照<sup id="cite_ref-“多父”_2-2"><a href="#cite_note-“多父”-2"><span>[</span>2<span>]</span></a></sup>。沈長雲等人提出，《國語·鄭語》「十一年而斃」<sup id="cite_ref-司徒_13-1"><a href="#cite_note-司徒-13"><span>[</span>13<span>]</span></a></sup>說的是周王室的覆亡，司馬遷誤會成了鄭桓公之死；鄭桓公並未死於幽王之難，而是棄周東遷<sup id="cite_ref-31"><a href="#cite_note-31"><span>[</span>31<span>]</span></a></sup><sup id="cite_ref-32"><a href="#cite_note-32"><span>[</span>32<span>]</span></a></sup>。
</p>

<li id="cite_note-16"><span><b><a href="#cite_ref-16">^</a></b></span> <span>《史記·鄭世家第十二》：為司徒一歲，幽王以褒后故，王室治多邪，諸侯或畔之。於是桓公問太史伯曰：「王室多故，予安逃死乎？」</span>
</li>
<li id="cite_note-17"><span><b><a href="#cite_ref-17">^</a></b></span> <span>《國語·鄭語》：史伯對曰：「……其濟、洛、河、潁之間乎！是其子男之國，虢、鄶為大，虢叔恃勢，鄶仲恃險，是皆有驕侈怠慢之心，而加之以貪冒。君若以周難之故，寄孥與賄焉，不敢不許。周亂而弊，是驕而貪，必將背君，君若以成周之眾，奉辭伐罪，無不克矣。……」</span>
</li>
<li id="cite_note-18"><span><b><a href="#cite_ref-18">^</a></b></span> <span>《國語·鄭語》：公曰：「南方不可乎？」對曰：「……唯荊實有昭德，若周衰，其必興矣。……」</span>
</li>
<li id="cite_note-19"><span><b><a href="#cite_ref-19">^</a></b></span> <span>《史記·鄭世家第十二》：公曰：「吾欲南之江上，何如？」對曰：「……周衰，楚必興。興，非鄭之利也。」</span>
</li>
<li id="cite_note-20"><span><b><a href="#cite_ref-20">^</a></b></span> <span>《國語·鄭語》：公曰：「謝西之九州，何如？」對曰：「其民沓貪而忍，不可因也。唯謝、郟之間，其冢君侈驕，其民怠沓其君，而未及周德；若更君而周訓之，是易取也，且可長用也。」</span>
</li>
<li id="cite_note-21"><span><b><a href="#cite_ref-21">^</a></b></span> <span>《國語·鄭語》：公曰：「周其弊乎〔一〕？」對曰：「……申、繒、西戎方彊，王室方騷……凡周存亡，不三稔矣！君若欲避其難，其速規所矣，時至而求用，恐無及也！」</span>
</li>
<li id="cite_note-22"><span><b><a href="#cite_ref-22">^</a></b></span> <span>《國語.鄭語》：公說，乃東寄帑與賄，虢、鄶受之，十邑皆有寄地。</span>
</li>
<li id="cite_note-23"><span><b><a href="#cite_ref-23">^</a></b></span> <span>《史記·鄭世家第十二》：而虢、劊果獻十邑，竟國之。</span>
</li>
<li id="cite_note-24"><span><b><a href="#cite_ref-24">^</a></b></span> <span>《史記·鄭世家第十二》：二歲，犬戎殺幽王於驪山下，并殺桓公。鄭人共立其子掘突，是為武公。</span>
</li>
<li id="cite_note-25"><span><b><a href="#cite_ref-25">^</a></b></span> <span>《漢書·地理志第八下》：威（桓）公死，其子武公與平王東遷，卒定虢、會之地。</span>
</li>
<li id="cite_note-26"><span><b><a href="#cite_ref-26">^</a></b></span> <span>《左傳·昭公十六年》：子產對曰：「……昔我先君桓公與商人皆出自周……」</span>
</li>
<li id="cite_note-27"><span><b><a href="#cite_ref-27">^</a></b></span> <span>《韓非子·內儲說下》：鄭桓公將欲襲鄶，先問鄶之豪傑、良臣、辯智果敢之士，盡與姓名，擇鄶之良田賂之，為官爵之名而書之，因為設壇場郭門之外而埋之，釁之以雞豭，若盟狀。鄶君以為內難也，而盡殺其良臣。桓公襲鄶，遂取之。</span>
</li>
<li id="cite_note-28"><span><b><a href="#cite_ref-28">^</a></b></span> <span>《清華簡·良臣》：鄭桓公與周之遺老：史伯、宦仲、虢叔、杜伯，後出邦。</span>
</li>
<li id="cite_note-29"><span><b><a href="#cite_ref-29">^</a></b></span> <span>《清華簡·鄭文公問太伯》：昔吾先君桓公後出自周……覆車襲介、克鄶。</span>
</li>
<li id="cite_note-30"><span><b><a href="#cite_ref-30">^</a></b></span> <span>《漢書·地理志第八上》臣瓚注：初桓公爲周司徒，王室將亂，故謀於史伯而寄帑與賄於虢、會之間。幽王既敗，二年而滅會，四年而滅虢，居於鄭父之丘，是以爲鄭桓公。</span>
</li>

</li>

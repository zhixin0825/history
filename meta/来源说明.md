# 史料来源、版本与许可

本仓库收录二十四史、《资治通鉴》（胡三省音注）以及十三经与《庄子》的 UTF-8 文本。各文件保持上游发布的原始字节，不进行繁简转换、断句重排或无依据的人工校字；已知源文件问题单独记录。

## 中华书局点校本二十四史

`sources/二十四史/中华书局/` 收录本地提供的中华书局新版点校本，共 241 个 PDF，并附原目录文件。文件名和按史书分册的目录结构保持不变；该目录另有独立的 [`SHA256SUMS.txt`](../sources/二十四史/中华书局/SHA256SUMS.txt) 供完整性校验。

## 资治通鉴

- 文件：`sources/资治通鉴/KR2b0007_000.txt` 至 `KR2b0007_294.txt`。
- `000` 为提要、序、进表等卷前资料，`001` 至 `294` 为正文。
- 文本含胡三省音注，也保留 Kanripo/Mandoku 的页码、版本和文本标记，适合溯源；使用前可按研究目的另行清洗。
- 上游另有一个 175 字节的 `KR2b0007_295.txt` 空壳，卷号元数据写成“卷二百九十5”，故未纳入。

## 已知问题

OSF 原始文件中有 92 个 Unicode 替代字符 `U+FFFD`（`�`）。它们不是本仓库复制过程造成的乱码。为避免无依据地猜字，本仓库保持原文：

| 文件 | `U+FFFD` 数量 |
|---|---:|
| `02_hanshu_full.txt` | 3 |
| `03_houhanshu_full.txt` | 1 |
| `07_nanqi_full.txt` | 20 |
| `17_xintangshi_full.txt` | 21 |
| `20_songshi_full.txt` | 31 |
| `22_jinshi_full.txt` | 12 |
| `23_yuanshi_full.txt` | 1 |
| `24_mingshi_full.txt` | 3 |

这些文件适合语料分析和检索，但不应在未经版本校勘的情况下作为严格的点校本使用。

十三经与《庄子》中，`13_yili_mod.txt` 的 OSF 原始文件另有 5 个 `U+FFFD`；其余 13 个文件没有该字符。《资治通鉴》295 个 TXT 文件没有 `U+FFFD`。

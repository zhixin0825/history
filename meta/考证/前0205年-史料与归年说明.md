## 内容

### 本次阅读结构与内容取舍

年页以一个历史事件为一个编号，正文32条、同号史料32条，双方以事件名称和返回链接相连。多卷相同史事合在同号下；原文在同年页直接展示，完整来源页保留。旧的卷次、逐月覆盖、计算口径和长篇异说迁存于本页；年页只留与事件直接有关的短说明及入口。

底本为main提交[2b77039a18d0af515de2872fe0bd1293269bc565](https://github.com/zhixin0825/history/commit/2b77039a18d0af515de2872fe0bd1293269bc565)的既有年页。原页23个显式锚点全部保留在年页相应事件或同号史料处；本页亦保留相关旧注定位以承接迁存内容。旧原表引文逐字保全，正文中的历史信息已重新合并，编辑性因果评论不当作原书实证。

新补张良成信侯、关中大饥和韩信请兵三万等原PDF内容，均据汉书P034—P043与通鉴二年段复核。原PDF将董公进言与发丧分两条，本次合为因果相连的一条；新增的北畤、人事和后九月破代则各有同号史料。原PDF“司马卬战死”收束为原书可证的“死”，不增确切死亡方式。古历月名照原书年条，不直接改作同号公历月。

### 本轮新增及仍保留的边界

第26条将原有萧何后方职掌按通鉴的八月实际年条展开；第30条据通鉴二年后九月补韩信在阏与破代、擒夏说，原文作禽，未据此增写被杀。它与次年井陉之战、陈馀与赵歇结局分开。第31、32条为本年人事总括与未定月北畤事项，不因排在页末就断言发生在后九月之后。

《汉书·高帝纪》P034—P043的文句作为底本直接节引，引用中仅去除排版空白，不把PDF编辑加入的月份括号当原书原字。有关句子均已对原典核读；通鉴引文据[卷九固定版2174852](https://zh.wikisource.org/w/index.php?title=資治通鑑/卷009&oldid=2174852)。北畤原文据[《封禅书》汉二年段](https://zh.wikisource.org/wiki/史記/卷028)，同时与既有卷026考证互见。卢绾任太尉随军之说另核[《韩信卢绾列传》固定版368019](https://zh.wikisource.org/w/index.php?title=史記/卷093&oldid=368019)；新注直接列出有关原文。访问日期2026-11-04。古籍原文属公有领域，数字转录的来源与许可沿各来源页；本轮未改原始TXT、PDF或源文摘录。

#### 卷022｜将相表互见与异说

[本年原表R002](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r002) · [《汉书·百官公卿表》](https://zh.wikisource.org/wiki/漢書/卷019b)。

> 纪年：二；大事纪：春，定塞、翟、魏、河南、韓、殷國。夏，伐項籍，至彭城。立太子。還據滎陽。；相位：二。守關中。；将位：一。太尉長安侯盧綰。；御史大夫位：〔空〕

塞、翟归附在前206年已经发生，本格以二年春总括东进，不另记第二次投降。魏豹是先归汉、随伐楚而后反汉，韩国的韩王信与攻魏的大将韩信分开。相位的“守关中”是萧何的后方职责；将位以卢绾太尉起数，侯号作为辨人称谓，不由此倒推封爵的确日。



<a id="note-yidi"></a>
#### 1｜义帝之死及跨年归档

[卷007 P022—P024](../../sources/摘录/史记-卷007-项羽本纪.md#p022) · [卷008 P021](../../sources/摘录/史记-卷008-高祖本纪.md#p021) · [《通鉴》卷九](https://zh.wikisource.org/wiki/資治通鑑/卷009)。本纪把迁、杀义帝相接，《通鉴》明系汉二年冬十月，故入本页，不等于现代前205年10月。执行者名单中，史记列衡山、临江，通鉴另列九江；不硬定每人的具体下手方式。[跨年说明](../../meta/考证/史记-卷007-纪年与异说.md#跨年)。

#### 2｜齐、赵及反复归降

田荣并三齐前206，陈馀复赵前205初。北击田荣，本纪概称二年冬，《通鉴》正月，正文沿编年底本；田广立齐由同书四月条定位。魏豹、司马欣的先归汉再附楚分开，不因人物重新出现就当成两个人。卷008把塞、翟、河南归降合在二年概述，前206已写塞翟归汉，不重复改旗。

<a id="家属与兵数"></a>
#### 3｜彭城、兵数与家属

[卷007 P025—P027](../../sources/摘录/史记-卷007-项羽本纪.md#p025)与卷008互见。五十六万、三万及两处十余万人损失均属史书记数，不计算独立核实的歼灭率。谷、泗、睢不混作一河，风沙不作为天意证据。孝惠、鲁元是后称；卷008笼统写“父母妻子”，与刘母先亡等材料有问题，正文保持可由后续核合的太公、吕后等人物，不凭笼统家属称谓令刘媪复生。

<a id="sj008-government-note"></a>
#### 4｜苑囿、社稷与年条的范围

[卷008 P023、P027、P029](../../sources/摘录/史记-卷008-高祖本纪.md#p023)。本轮补苑囿开放、奖降、郡制、章平、祭祀及太子守栎阳。开放供田不等于所有园林当年已全部改成耕地；万户奖励是政策所许，不是每位将领已获实收户数。郡名与秦原行政区重叠，是恢复、改置和实际控制的叙述，不称各郡此前从未存在。

卷008三年开头回写魏豹被俘，正文仍从年表、《通鉴》放二年九月；后面的攻赵、张耳立赵王分别见前204、203年。随何出使、黥布起事、败退归汉亦不全部挤进一个月。萧何征兵“老弱未傅”保留非常征发性质，不擅算统一年龄或儿童人数。军费、人口、徭役的细节仅依所用材料，不将本卷阅读完成等同于所有制度研究已解决。

### 卷016｜逐月互见与取舍

<a id="sj016-m10-note"></a>
#### 十月｜义帝、赵地与陕

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0205-10)义帝格接[遇害条](../../years/bce-0300-0201/bce-0205.md#sj007-yidi)及[执行者异说](../../years/bce-0300-0201/bce-0205.md#note-yidi)，常山、代两格分别为张耳降汉、赵歇复王赵，合入[陈馀复赵](../../years/bce-0300-0201/bce-0205.md#sj007-zhao)。汉栏刘邦至陕接[关外经营](../../years/bce-0300-0201/bce-0205.md#sj008-han-government)，不是现代陕西省全境的同日征服。

<a id="sj016-m11-note"></a>
#### 十一月｜陇西、韩与河南

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0205-11)雍栏汉拔陇西、韩栏汉立韩王信、河南栏改郡，合入[本页军政经营](../../years/bce-0300-0201/bce-0205.md#sj008-han-government)。前一年汉军遣将略陇西与本年继续取得城邑可以衔接，不重复造一场相同回师。韩王信不是攻魏的韩信；申阳归降与改河南郡仍是一组事件，不是国王被杀。

<a id="sj016-m12-note"></a>
#### 十二月｜陈馀取得代王名号

[本月原常山栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0205-12)接[陈馀封代、夏说留守](../../years/bce-0300-0201/bce-0205.md#sj007-zhao)。原格“故成安君”指陈馀先前称号。新代王续写在原常山位置，而赵歇的赵国续在原代位置，是表格安排，不能据此交换实际国土或把两人合为一位赵王。

<a id="sj016-m01-note"></a>
#### 正月｜田荣败死与北地

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0205-01)齐栏田荣败走平原后为民所杀，接春季齐事；并非项羽亲手在城阳杀他。雍栏北地被汉夺取接[关中与边地经营](../../years/bce-0300-0201/bce-0205.md#sj008-han-government)，与章平被俘合读，不把仅有的地名扩大成未经核定的现代行政区。

<a id="sj016-m02-note"></a>
#### 二月｜田假复位

[本月齐栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0205-02)项羽复立田假接正文，继以[三月再败](../../years/bce-0300-0201/bce-0205.md#sj016-tianjia)。他在前208年被逐后逃楚，本年才有这次复位；其他栏“二年一月”是各王计月重启，不把该行改为正月。

<a id="sj016-m03-note"></a>
#### 三月｜田假的终局与汉取河内

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0205-03)齐栏田横反城阳、逐田假、楚杀假补[田假终局](../../years/bce-0300-0201/bce-0205.md#sj016-tianjia)，不猜杀害者个人姓名与理由。汉、西魏、殷三栏为攻殷、魏豹降汉、司马卬降而被废，合入[渡河东征](../../years/bce-0300-0201/bce-0205.md#sj008-han-government)。表“降”与本纪“虏”是不同概括，不能再加一场同月杀殷王。

<a id="sj016-m04-note"></a>
#### 四月｜彭城与田广

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0205-04)项、汉、西魏、韩四栏同属[彭城战局](../../years/bce-0300-0201/bce-0205.md#sj007-pengcheng)，三万与五十六万不按栏相加。齐栏田广受田横拥立接齐地抵抗；殷栏河内郡为前月灭殷后的改属，接[军政条](../../years/bce-0300-0201/bce-0205.md#sj008-han-government)，不重演一次征服。

<a id="sj016-m05-note"></a>
#### 五月｜退荥阳与魏豹反汉

[本月汉、西魏两格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0205-05)接本页彭城后收军、退荥阳及魏豹归国反汉。三月归附、四月随军、五月叛离是同一人的转变，不因“降”和“叛”相反就删除其中一段。

<a id="sj016-m06-note"></a>
#### 六月｜太子与废丘

[本月汉、雍两格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0205-06)归本页六月：入关、立太子、回荥阳与废丘攻克是几个步骤。表“汉杀邯废丘”与本纪、[汉书P042](../../sources/摘录/汉书-高帝纪.md#p042)章邯自杀的详细叙述有别，正文仍取水攻后自杀，不写汉王亲手斩邯。

<a id="sj016-m07-note"></a>
#### 七月｜雍地改属

[本月雍栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0205-07)“属汉，为陇西、北地、中地郡”接[郡制说明](../../years/bce-0300-0201/bce-0205.md#sj008-government-note)。与前一年塞、翟改属分别对应，不从名称推定每一郡的设置都是全国历史上第一次，也不凭短格画疆界。八月原格只有纪月与空位，未据空栏添事。

<a id="sj016-m09-note"></a>
#### 九月｜魏豹被俘

[本月西魏栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0205-09)接九月韩信攻魏、俘豹送荥阳；表“汉将信”是大将韩信，不是本表同时在韩栏连续计月的韩王信。魏豹被俘不等于此月死亡，后续见[前204年](../../years/bce-0300-0201/bce-0204.md#sj007-jixin)。

<a id="sj016-m09b-note"></a>
#### 后九月｜魏亡后的郡

[本月西魏栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0205-09b)列河东、上党，合入攻魏后的郡制主线。汉书另列太原，下一年表又在原常山／代栏写太原，国别栏目与郡名不能直接拼成无矛盾疆域图，参[前204年注](../../years/bce-0300-0201/bce-0204.md#sj016-m11-note)。本年后九月为独立闰月，不抹作九月，也不改成汉三年十月。


<a id="sj026-note"></a>
### 卷026｜北畤的年次与汉初沿秦历

[《历书》P009](../../sources/摘录/史记-卷026-历书.md#p009)只概称“汉兴”，以刘邦“北畤待我而起”说明其水德解释。增立北畤按[《史记·封禅书》汉二年](https://zh.wikisource.org/wiki/史記/卷028)及[《汉书·郊祀志上》二年](https://zh.wikisource.org/wiki/漢書/卷025上)归入本页，未由“汉兴”直接当成前202年称帝之日；相关段落把东击项籍、还关与祭祀相接，月份不从相邻军事叙述硬定。

卷026概称汉初沿秦正朔服色；卷028又说刘邦起兵尚赤，汉书还见“外黑内赤”。这些是不同层面的制度与象征记述，不抹平成汉初处处只有一种颜色，更不因北畤祀黑帝便断言其五德理论全无异说。见[秦汉说明](../../meta/考证/史记-卷026-纪年与异说.md#秦汉)。

## 内容

<a id="秦历与年页"></a>
### 1．古史年条，不等于公历一月至十二月

秦王政元年用前246年，二十六年用前221年，三十七年用前210年；二世元年至三年用前209—207年的传统年条对应。即位和元年分开：政在前247年接位，次年称元年；胡亥在前210年接位，次年称二世元年。[P001](../../sources/摘录/史记-卷006-秦始皇本纪.md#p001)、[P052—P054](../../sources/摘录/史记-卷006-秦始皇本纪.md#p052)。

**秦历以十月为岁首。** 同一古历年内，冬十月、十一月会出现在正月、七月之前。未作历算时保留古月和干支，不换成同号公历日期。年页文件所标年份首先是古史年条的常用对应，不能保证其中每一天都属于同一公历年。[P029](../../sources/摘录/史记-卷006-秦始皇本纪.md#p029)。

既有[前206年页](../../years/bce-0300-0201/bce-0206.md)按《汉书》“汉元年”归档，开头冬十月的子婴投降，按公历年界通常归前207年。本轮保留原文件和链接，并在前207、206两页明确说明：**秦降紧接二世三年九月，不是到了现代历前206年10月。** 这是整年归档的局限，不隐瞒，也不凭“四十六日”推算未经核定的唯一公历日期。[《汉书》P022—P023](../../sources/摘录/汉书-高帝纪.md#p022)、[本纪P064—P065](../../sources/摘录/史记-卷006-秦始皇本纪.md#p064)。

“后五年，天下定于汉”接汉五年、前202年的阶段终点，不从前206机械减五排成前201年；前205—203年详细战争仍待后续各卷汇入。[P066](../../sources/摘录/史记-卷006-秦始皇本纪.md#p066)、[《高祖本纪》](https://zh.wikisource.org/wiki/史記/卷008)。

<a id="卫君与合纵"></a>
### 2．迁往野王的卫君，不能直接写成角

本纪六年称“其君角”迁野王；《卫康叔世家》却写元君迁野王，元君死后才由角继位，角后来在秦二世时才被废。正文因此只称卫君，注中保留冲突，不让角提前登场。[P007](../../sources/摘录/史记-卷006-秦始皇本纪.md#p007)、[卷037](https://zh.wikisource.org/wiki/史記/卷037)。

本纪合纵名单为韩、魏、赵、卫、楚，与其他篇章不尽相同。本轮采用本纪六年安排事件，但不强凑唯一完整名单，也不把各阶段定到同一月日。东郡设置、迫卫迁徙及后来卫君的更替分开处理。[《通鉴》卷六](https://zh.wikisource.org/wiki/資治通鑑/卷006)。

### 3．秦方取城，不等于完整战局没有秦败

前233年本纪记取宜安、平阳、武城，赵方相关材料及《通鉴》又记李牧反击。正文采用“取得城邑，随后遭到反击”的分阶段写法，既不删除取城，也不只保留胜利。[P015](../../sources/摘录/史记-卷006-秦始皇本纪.md#p015)、[《通鉴》卷六](https://zh.wikisource.org/wiki/資治通鑑/卷006)。

前232年的狼孟与互见材料中的番吾，不未经地理考证便认作同一地方。王翦选兵的“十八日”“斗食以下”“什推二人”等简略句，不能直接换成整个战役时长或精确裁军比例。[P012](../../sources/摘录/史记-卷006-秦始皇本纪.md#p012)、[P016](../../sources/摘录/史记-卷006-秦始皇本纪.md#p016)。

### 5．刻石、神异、数字与工程，不是同一类证据

**刻石是政治宣示。** 峄山、泰山、琅邪、之罘两篇、碣石、会稽及二世补刻均已处理。颂辞中的安宁、兵革永息、黎庶免劳是君臣对统治的自我表述，不是生活状况调查；二世的附诏也不会使始皇原刻全部变成二世元年的作品。[P033—P034](../../sources/摘录/史记-卷006-秦始皇本纪.md#p033)、[P038](../../sources/摘录/史记-卷006-秦始皇本纪.md#p038)、[P041](../../sources/摘录/史记-卷006-秦始皇本纪.md#p041)、[P050](../../sources/摘录/史记-卷006-秦始皇本纪.md#p050)、[P055](../../sources/摘录/史记-卷006-秦始皇本纪.md#p055)。

**行动与传说分开。** 徐巿出海是所记行动，仙山和不死药是当时说法；石上刻字属人为政治言辞，还璧、祖龙死、亡秦者胡、海神和白虎梦境属神异与解释层。天象记录不能自动证明预言准确。无明确来源的日本目的地、巨鱼现代物种均未补造。[P035](../../sources/摘录/史记-卷006-秦始皇本纪.md#p035)、[P042](../../sources/摘录/史记-卷006-秦始皇本纪.md#p042)、[P049](../../sources/摘录/史记-卷006-秦始皇本纪.md#p049)、[P051](../../sources/摘录/史记-卷006-秦始皇本纪.md#p051)。

**阿房宫不能从文学倒写成考古事实。** 年表二十八年写为阿房，本纪三十五年叙营建；正文沿后者归前212年，保留前者异说。七十余万人为阿房、骊山合写的一组，不拆成各七十余万。本纪明写阿房未成，秦亡时烧宫室又未点名阿房。[P046](../../sources/摘录/史记-卷006-秦始皇本纪.md#p046)、[P066](../../sources/摘录/史记-卷006-秦始皇本纪.md#p066)、[年表旧摘录](../../sources/摘录/史记-条目原文.md#ref-sj-1470)。[西安市文物局所载2025年考古收获](https://wwj.xa.gov.cn/xwzx/wbzx/2005535230505029634.html)支持区分未完成的阿房前殿工程与咸阳宫室的焚毁；不把后世文学写法当本年施工实录，也不扩展为所有附属建筑都未施工。

**陵墓描述不等于已经发掘主墓室。** 水银河海、机关弩、天文地理、人鱼膏、封闭工匠都作为传世记载呈现；初即位开工、统一后扩大与前210年葬仪分层，不倒填为少年即位时就已有后来规模。[P053](../../sources/摘录/史记-卷006-秦始皇本纪.md#p053)。

### 6．焚书与诸生案分年，对象和刑罚也要辨别

焚书令归前213年，诸生案归前212年。焚书所列史记、民间诗书百家语，与博士官职掌、医药卜筮种树书的保留范围一并交代；不能说所有书全烧，也不能因有例外就断言文化损失很小。[P045](../../sources/摘录/史记-卷006-秦始皇本纪.md#p045)。

诸生案起于方士事，扶苏谏辞又提诵法孔子，不能断定所有涉案者只有一种身份。坑／阬的具体执行方式不能只凭一个字全部翻成活埋，四百六十余也不是出土遗骸统计。[P048](../../sources/摘录/史记-卷006-秦始皇本纪.md#p048)。

<a id="沙丘继位"></a>
### 7．沙丘的传世主线与《赵正书》异说

本纪及《李斯列传》写赵高、李斯、胡亥毁扶苏封书、改立胡亥、伪书赐死。正文依此讲述，但原封书只明确“与丧会咸阳而葬”，**并没有明文“传位扶苏”**；对继承含义的推断与明写传位的诏令不是一回事。[P052](../../sources/摘录/史记-卷006-秦始皇本纪.md#p052)、[卷087](https://zh.wikisource.org/wiki/史記/卷087)。

北大汉简《赵正书》则写李斯、去疾请立胡亥，秦王答“可”。这与诈立故事不同，不能忽略；但文本性质、形成目的与可信程度仍有争论，也不能因出自简本便宣布已经推翻《史记》。[公开释文](https://zh.wikisource.org/wiki/趙正書)。

杨涛2024年《汉简〈赵正书〉文本新探之一》的[作者机构摘要](https://scholarship.libraries.rutgers.edu/esploro/outputs/acceptedManuscript/A-new-textual-study-of-the/991031933295804646)提示争论，并提出与汉高祖改立太子议题有关的政治文本解释。此处引用的是公开摘要，不冒称完成其论文全文复核；引用只用于说明存在实质分歧，不把新说当成共识。

指鹿为马依本纪保留沉默、言马、言鹿三种反应，不换成另一版本的全员言马；也不因另有文本就宣称故事全真或全伪已经得到独立证明。[P062](../../sources/摘录/史记-卷006-秦始皇本纪.md#p062)。

### 8．秦末的压缩叙述，要拆开归年

| 材料 | 问题 | 采用的安排 |

<a id="秦先君世系"></a>
### 9．篇末秦先君世系的处理

[P071](../../sources/摘录/史记-卷006-秦始皇本纪.md#p071)完整保存所据见证的先君世系、在位数、宫居、葬地与附见记事。未另记年的居宫、安葬不能自动放到元年；“生某公”也不提供确切出生年。已有卷005及春秋同事不重复，新异说不静默覆盖旧主线。

| 材料群 | 取舍 |
|---|---|
| 襄公西畤、西垂；文、静、宪等先君 | 与卷005对应段互见，宪／宁等名号、世次差异保留，不重造自洽而无据的家谱 |
| 出子、三庶长、武公、德公 | 同一政变、继位不记两遍，附加宫居葬地留原文 |
| 德公初伏、宣公初志闰月 | 与卷005异文、所属君时分开看；未明确王年不自选一年，“志闰月”不等于发明闰月 |
| 成公段齐伐山戎孤竹 | 与既有春秋战事合读，不写成秦成公率齐军出征 |
| 穆公至悼公 | 霸业、君位承接与既有材料互见，未确年的宫居葬地仍留原文 |
| 厉共十年、躁公元年彗星 | 同卷005对应王年合读，不重复增加天象；绝对年沿原考证 |
| 怀公、灵公、简公亲缘 | “怀生灵”“灵为昭子子”“灵生简”等并非一套能直接拼合的谱系，照录差别 |
| 简公七年带剑 | 卷005作六年，既有前409年沿卷005，七年留异说，不新造第二次初带剑 |
| 出公自杀 | 卷005叙出子与母被杀，死亡方式冲突保留，不强解为先自杀再被杀 |
| 孝公十三年始都咸阳 | 卷005十二年，正文沿[前350年](../../years/bce-0400-0301/bce-0350.md)，不另造第二次迁都 |
| 惠文、武、昭襄十九岁，孝文五十三，庄襄三十二 | 与即位、次年元年及古年龄口径一起考察，不推出未核生日 |
| 始皇三十七、二世三及总六百一十岁 | 归已有统治阶段，二世年龄冲突另注；总数不倒推全部先君确年 |

相关王年主线继续参考[卷005纪年与异说](史记-卷005-纪年与异说.md)。

**有明确王年的制度、灾异补记已经进入年页：**[前378年行市](../../years/bce-0400-0301/bce-0378.md)、[前375年户籍相伍](../../years/bce-0400-0301/bce-0375.md)、[前346年桃李冬花](../../years/bce-0400-0301/bce-0346.md)、[前336年初行钱](../../years/bce-0400-0301/bce-0336.md)、[前308年渭水赤](../../years/bce-0400-0301/bce-0308.md)、[前303年田开阡陌](../../years/bce-0400-0301/bce-0303.md)。婴儿“秦且王”随前336年附为传说。[P072—P076](../../sources/摘录/史记-卷006-秦始皇本纪.md#p072)。

庄襄元年赦赏、东周与阳人奉祀、二年取太原，与[前249年](../../years/bce-0300-0201/bce-0249.md)、[前248年](../../years/bce-0300-0201/bce-0248.md)现有事件合读，新增互见保留于本表与去向页，不另造一次灭东周。军事取得太原与后来置郡也不是同一措辞。[P077](../../sources/摘录/史记-卷006-秦始皇本纪.md#p077)。

### 10．贾生三组议论，不全部改写成政令

[P067](../../sources/摘录/史记-卷006-秦始皇本纪.md#p067)由太史公回顾秦先世、始皇自负，引出贾生评论。先世与卷005、上古主线互见，不从唐虞传说硬定绝对年。

[P068](../../sources/摘录/史记-卷006-秦始皇本纪.md#p068)强调秦地险固本可守、君臣失信与禁谏造成壅蔽；“子婴可保秦”是历史反事实，不是已证明必然成功的方案。

[P069](../../sources/摘录/史记-卷006-秦始皇本纪.md#p069)用强秦与弱小陈涉的对照，提出“仁义不施，攻守势异”的解释。长段跨代汇聚名将谋臣，有修辞综合，不能拆成他们全部参加同一场合纵的名单；这个解释也不消除军队、财政、地方组织等其他问题。

[P070](../../sources/摘录/史记-卷006-秦始皇本纪.md#p070)讨论新君原可借民困救弊，设想分封、赦罪、减税、散财、省刑。正文没有把这些条件句写成二世真的做过的政策。贾生主张分封也不与李斯反分封的发言合成一个无矛盾的共同立场。

<a id="班固附记"></a>
### 11．班固反对把积败全压给子婴

[P079](../../sources/摘录/史记-卷006-秦始皇本纪.md#p079)署汉明帝十七年，即永平十七年、公元74年的文本时间。它是后人附记，不是司马迁亲笔，更不因主题讨论秦亡便归秦亡之年。本轮不为一篇评论的署时单开空泛年度页。

班固批评始皇、二世积累祸患，却赞子婴诛赵高的决断，认为到他接手时已经土崩瓦解，不应责其挽回多年积败。这与贾生“秦之地可全”的设想存在正面分歧，两说都保留，不把卷末评论并成单一结论。

附记“车裂赵高”与正文“刺杀”措辞不同，不能直接复原成确定的连续处刑过程；其中“吕政”、星象和天图等也属于作者用语与思想背景，不成为始皇生父或神谕已经被证明的证据。

### 摘录口径

原文页引用固定修订版，选段之外用编者文字说明材料范围，长篇全文可沿页首链接核对。异体与标点不用于制造新史事；实质分歧如王年、年龄、人物亲属及死亡方式在相应注脚说明。P002将卷首末句“晋阳反”和下一年平定分别摘出；吕不韦门客处分、湘君问句、焚书令末句等已在整理稿中保留所据见证用字。阅读覆盖完成不等于所有点校本已逐字核校，更不等于所有年代与历史解释已经定论。

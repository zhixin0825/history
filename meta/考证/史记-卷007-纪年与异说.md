## 内容

### 1．底本、分段和“完成”的含义

阅读见证为[维基文库固定修订版5978360](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7007.md#ref-9b8fed66695797)。[摘录页](../../sources/摘录/史记-卷007-项羽本纪.md)以P001—P046作本项目定位，长段节引之外另述范围；原书没有这套编号，46也不是事件总数。本文通读至太史公论并处理网页所附索隐述赞，不把正文、后人注赞混为一层。

编年主要参照《史记》卷016秦楚之际月表、卷018高祖功臣侯者年表及[《通鉴》卷八](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7008.md#ref-c51452f393c5df)、[卷九](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7009.md#ref-7413c633fd8ddd)、[卷十（四库全书本文本）](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91%20%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29-%E5%8D%B7010.md#ref-57856186849bfb)、[卷十一](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7011.md#ref-62d0356f37479e)。只使用解决当前问题所需条目，不冒称这些卷或现代研究全部整理完成。四库本文本中夹注与《通鉴》正文分开，胡三省解释不是汉代人物发言。

### 2．秦汉古历年条与公历年界

沿用项目已确认的古史整年对应：二世元年至三年为前209—207年条，汉元年至五年为前206—202年条。秦及汉初以十月为岁首，冬十月、十一月、十二月在同年正月前；未作逐日历算时不直接换成同号公历月份。[卷006既有口径](史记-卷006-纪年与异说.md#秦历与年页)。

因此汉元年冬十月秦降在前206年文件中，却通常按公历年界归前207年；汉七年十月的平皋初封也不能按文件名直接理解为现代前200年10月。正文开头明示这一限制，不用跨年材料制造同一事件发生两次。

### 3．项羽首次登场与此前经历

[P002](../../sources/摘录/史记-卷007-项羽本纪.md#p002)明写叔侄看始皇游会稽、渡浙江，与[卷006三十七年会稽行程](../../sources/摘录/史记-卷006-秦始皇本纪.md#p050)合读，放[前210年](../../years/bce-0300-0201/bce-0210.md#sj007-first)。求学、项梁狱案、曹咎司马欣援助、杀人避仇吴中、主持役丧，均作为已在这次观巡之前的背景，不各自配上虚构年份。

P001“初起时年二十四”不用于造一个有确切月日的出生页；项燕世系中的顺带提名不是项羽参与史事的首次登场。项燕死于王翦、昌平君之立和死年沿卷006已列差异，不因卷007一句话又重写一套自洽但无据的灭楚次序。

<a id="跨年"></a>
### 4．同一自然段常常跨年

| 材料 | 采用的归档 | 不作的机械处理 |
|---|---|---|
| P004召平假命、项梁渡江 | 陈王败后的二世二年阶段，前208 | 不因紧接元年起兵段就全部归前209年九月 |
| P011宋义与项羽 | 任命在前208；安阳停留、十一月杀宋义与楚王追认在前207 | 不把任命、停留、杀将都写成同年同日；所谓楚王密令仅属项羽公布的说法 |
| P015新安杀降 | 汉元年冬，前206年条；与《通鉴》约法、入关段相接 | 不沿章邯降约的前207年 |
| P022义帝 | 汉元年迁郴；二年冬十月遇害，前205年条 | 不因段首“四月就国”就把最后杀害也放同月 |
| P023齐、赵 | 田荣并三齐在前206；陈馀击常山、迎赵歇回赵在前205初 | 不把齐、赵同段统称同一年全部反楚 |
| P024北击齐 | 本纪写二年冬，《通鉴》系正月；仍为前205年条 | 正文采用编年底本的季节，不伪称两书逐月一致 |
| P027田广及粮道 | 田广立齐、汉建粮路在前205；断粮求和在前204 | 不因写在彭城以后就断言田广必在战后才立，也不让甬道建造和断绝成同一天 |
| P039末次追击 | 鸿沟和约后决意追在前203末；固陵、会军、垓下在前202 | 不让整场决战继承上一段和议年份 |
| P042、P044封侯 | 战斗、保全项氏在前202；初封按卷018回到前201、200、199、195 | 不把所有爵号当作战死当天立刻兑现 |

义帝执行者名单亦不完全相同：本纪说衡山、临江王，《通鉴》另列九江；正文不擅自复原每人具体如何下手。章邯在前207年降约中先获雍王安排，前206年分封确定咸阳以西，不是两次互不相关的独立封国。

<a id="成皋"></a>
### 5．成皋、曹咎与龙且：必须调整传记行文顺序

[P031](../../sources/摘录/史记-卷007-项羽本纪.md#p031)写“汉之四年，项王进兵围成皋”。但[《高祖本纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7008.md#ref-e19b1e4caf1e16)、[《淮阴侯列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7092.md#ref-2106cc6ab3d048)及《通鉴》把刘邦与滕公北逃、入张耳韩信营夺军放汉三年六月。故本轮归[前204年](../../years/bce-0300-0201/bce-0204.md#sj007-chenggao-loss)，下一年的“复取成皋”作为后续，不让刘邦两年各从同一事件中逃一次。

P035先写龙且军破、韩信王齐，再转项羽东击彭越、令曹咎守城；这是回叙，不足以确定全部故事的顺序。采用《通鉴》的安排如下：

| 古史年次 | 事件 | 年页 |
|---|---|---|
| 汉三年六月 | 荥阳破、成皋被围，刘邦北渡，楚取城 | 前204 |
| 三年八月 | 刘贾、卢绾助彭越袭楚粮，刘邦暂守河内 | 前204 |
| 三年九月 | 项羽东击梁地，令曹咎守；外黄少年劝免杀戮 | 前204 |
| 四年冬十月 | 曹咎渡汜水败亡，汉复成皋；项羽返援钟离眛 | 前203 |
| 四年十一月 | 龙且救齐，在潍水败亡 | 前203 |
| 四年春二月 | 汉正式立韩信为齐王 | 前203 |
| 四年九月 | 鸿沟和议，家属归还，楚军东归 | 前203 |

广武对话、太公受胁和汉王中箭在长期相持阶段展开，不能因为《通鉴》接在十月攻城段后，就把几个月的相持与每句话都挤成十月的一天。正文用分节叙事，不假装事件在现代日历中的逐日位置已知。

### 6．韩信“自立”和刘邦回师三秦的月次

P035概称韩信“因自立为齐王”，相关列传和《通鉴》保留请假王、刘邦愤怒、张良陈平劝说、正式持印立王的程序。正文采用详细过程，并在注脚保留本纪简写；不写成完全绕过汉王的独立政变。书中多次称“淮阴侯”是后称，不在龙且战前提前改爵。

前206旧页随《汉书》P030用五月，卷006的历史核对记录也据此说明。本轮为串联诸侯就国和回师后的战局，**当前正文明确改采《高祖本纪》《通鉴》的八月**，S5继续保留旧汉书五月的出处。卷006记录中的“本轮保留五月”是前一批次的处理，不能据它认为当前三书已完全一致，也不在两个月各记一次同样的回师。

### 7．已有材料与不应混淆的人

前209、208年的《陈涉世家》全部旧事件锚点及《汉书》P009—P033主线保留。景驹原页概称被项梁杀，本轮按P005细分为秦嘉战死胡陵、景驹逃死梁地；没有删除整个原事件，而是更正概述中过度直接的死亡方式。

韩王信是韩国宗室，荥阳被俘的韩王不能与攻齐的大将韩信混为一人。鸿门传话的陈平仍为楚官，前205年另有归汉；项伯、项缠为同一人的不同称谓。P037“长史翳”与董翳前期归汉的经历之间仍有缺口，正文只保留能与《通鉴》核合的曹咎、司马欣死亡，不凭孤句编造董翳的返楚年月。

| 项它／刘它 | 平皋侯 | 六年归汉赐姓；七年十月癸亥初封 | [前201](../../years/bce-0300-0201/bce-0201.md)、[前200年条](../../years/bce-0200-0101/bce-0200.md) |
| 吕马童 | 中水侯 | 七年正月己酉 | [前200](../../years/bce-0200-0101/bce-0200.md) |

| 杨喜 | 赤泉侯 | 七年正月己酉 | [前200](../../years/bce-0200-0101/bce-0200.md) |
| 吕胜 | 涅阳侯 | 七年中，月未列 | [前200](../../years/bce-0200-0101/bce-0200.md)，不借别人的月日 |
| 杨武 | 本纪吴防侯；表吴房 | 八年三月辛卯 | [前199](../../years/bce-0200-0101/bce-0199.md) |

这些年页只承接本卷可确年的后叙，不将功臣表中每位后嗣的承袭、除国、复封及所有其他功臣全部搬入本轮，也不把战斗日期移到初封年。桃侯刘襄不能与齐王刘襄仅凭同名合并。

<a id="终局"></a>
### 9．垓下、虞与乌江的叙事边界

[P040](../../sources/摘录/史记-卷007-项羽本纪.md#p040)正文写项羽悲歌、虞相和，并没有写虞自刎，也没有写出她的完整和歌。年页不把戏曲和后人叙述当成本纪本来就有的事实。

P041叙东城快战，P042接乌江拒渡、自刎，P045又概称身死东城。地理层级、叙事压缩与不同篇章表述需要专门考察。本轮沿详细叙事讲过程，保留概称差异；不凭一个地名就另造一次死亡，不未经全面论证宣布乌江段已被证实全假，也不确认具体现代遗址坐标。

八千江东子弟、一当十、八百余骑、二十八骑、项羽自称七十余战及新安二十余万、彭城两组十余万伤亡，均按传世文本性质处理，不算成已经核准的损失比。新安“夜击坑”表明大规模杀降，不在没有证据时补出统一活埋程序。神异的望气、重瞳舜裔之问、风沙脱围及天亡之说也不转化为现代事实断言。

### 10．太史公论与索隐述赞不是同一作者

P045肯定项羽迅速统合诸侯、灭秦、主持封王的历史分量，同时批评其背关怀楚、逐义帝、恃力征、缺乏反省。末句直接反对“天亡我，非用兵之罪”的开脱。它是史家的解释，不是独立统计证明，也不能被压缩成作者只看见项羽残暴、全无功业。

P046的《索隐述赞》属于司马贞注释层，既责宋义无罪而遭杀、范增尽诚不被信，又说“战非无功，天实不与”。它与司马迁对“天亡”说的批评有不同表达，必须分层，不能一起当作司马迁同段自相矛盾的判断。评论放在本考证和来源页，由前202年结局回链，不假造唐代某一年项羽又发生了政治事件。

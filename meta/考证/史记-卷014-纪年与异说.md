## 表格结构与起止

原卷有表序、**366行**逐年国别记录、篇末太史公评论。仓库二十四史TXT可按行序匹配前841至前476年，但展平文本没有保留完整国别空白列；重建国栏必须对照[卷014原表](https://zh.wikisource.org/wiki/史記/卷014)的周、鲁、齐、晋、秦、楚、宋、卫、陈、蔡、曹、郑、燕、吴列，不能把TXT中相邻的“二”“十四”直接判给某国。

原来源页保留[固定版本入口](https://zh.wikisource.org/w/index.php?title=史記/卷014&oldid=2607001)。上一批曾说明固定入口未成功抓取；本批使用可读公开表页，页脚修订号与2607001相接，没有改动原始年行、空白或疑字。读取版本、正文改写与源表校勘应分开。

**前722—476年含首尾共247年，旧记录246少算一年。** 已登记的五批是前722—700年23行、前699—675年25行、前674—660年15行、前659—645年15行及前644—630年15行，共93行；后续前629—476年154行，早期前841—723年119行，93＋154＋119＝366。表行数、已有年页数和真正完成逐栏内容验收的范围，是三个不同的数。

### 共和、宣王与鲁国伯御

前841年共和元年与前828年共和罢、前827年宣王元年，是不同的计数转换。既有前841页保留二相共和、共伯和传说并列。前806年一行同时记鲁孝公称元年与伯御立为君，前796年又记宣王诛伯御立称，可能涉及称年追计、传本排布。现分别写伯御夺位与宣王干预，**不把鲁孝公、伯御说成共同执政**，也不称前806年已发生前796年的诛杀；需继续核对《鲁周公世家》与年表版本。

### 晋国由穆侯到曲沃

前805年伐条、太子仇出生；前802年千亩之战、成师出生；前785年穆侯死而殇叔自立、太子仇出奔；前781年仇杀殇叔，前780年才书晋文侯仇元年。表中“二子名反，君子讥之，后乱”是后来的解释，不作前802年已经内乱的实录。曲沃分封在前745，曲沃庄伯杀晋孝侯在前724，鄂侯前723始元年。多年因果不挤在一页，也不因本批核至并晋就宣称早期年数链全已解决。

### 继位、诞生与后称

前757年“生庄公寤生”是郑庄公出生，不是即位；前754年共叔段出生与母亲想立他，与前722年庄公击段分开。楚“武王立”写于前740年，不因谥号便断定该年正式称王。前748年宋武公栏“生鲁桓公母”只可读为世系追记，不凭此补婚期；前735年桓公立与前734年卫桓公完元年也须分开。

本批另辨前695年周栏“有弟克”：它只说明亲属，不是出生纪年。与前696年明写“生子颓”性质不同，详见下文。

### 敬王逝世与鲁哀公赴丧

卷014前477年行记敬王崩；[前476年既有页](../../years/bce-0500-0401/bce-0476.md#note-3)记鲁哀公十九年叔青赴京为敬王之丧，《左传正义》指出赴丧不能唯一确定卒年。另有《周本纪》推算差别，不能把前476年赴丧自动改成同年死亡。此前暂以各年分别记录赴丧、表所载卒年，等待互校；最新699—675年审读不扩大成已经复核477、476年。

<a id="孔丘生年"></a>
### 孔丘生年的前551／前552两说

年表鲁襄公二十二年行记孔子生，《孔子世家》《鲁周公世家》也有这一系，通常对应前551年；《公羊传》《谷梁传》系鲁襄公二十一年，通常对应前552年，月次仍有异同。此前[前551年](../../years/bce-0600-0501/bce-0551.md#sj014-confucius-birth)已加入出生并注明另一说，不能由卷014排除前552年。[两种生年传统](https://shandong-chorography.org/database/zzmj/section/25/article/11/) · [《孔子世家》](https://zh.wikisource.org/wiki/史記/卷047)。

### 表序的作者性与褒贬

表序论厉王、五霸、孔子、《左传》、《吕氏春秋》、张苍、董仲舒等不同层次，是司马迁说明跨国对读的方法，不是共和元年的政治清单。篇末比较儒者断义、历人取年月、谱牒记世谥，也属于史学方法论。“五伯”“孔子游七十余君”不代表每项均可独立精确归年；君子评论、天象祥瑞不改写成考古已核的因果。

## 前722—700年上一批处理（保留）

<a id="郑庄公见母"></a>
### 迁母与和好只留一处主述

《左传·隐公元年》连叙迁母、立誓、后悔、颍考叔与母子相见；《郑世家》记“居岁余”，表在庄公二十三年另列穿地相见。现以[前722年](../../years/bce-0800-0701/bce-0722.md#event-4)记迁母立誓、[前721年](../../years/bce-0800-0701/bce-0721.md#sj-042-L3772-02)作和好主体，双方注脚保留另一条时间线索。不宣称月份已校定，但避免相同事件完整记两遍。

<a id="晋鄂侯与小子侯"></a>
### 鄂侯生死、小子遇害与缗王年仍有矛盾

[前718年表](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0718)及《晋世家》将鄂侯卒放在曲沃进攻以前，《左传》却有本年翼侯奔随、次年迎入鄂。正文保留经传过程，死亡说留注，不拼成死后复生；世家所称平王遣兵又与前720年平王死亡相抵，不照搬。[前718年注2、5](../../years/bce-0800-0701/bce-0718.md#note-2)。

[前706年表](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0706)合记杀小子、王伐曲沃、立缗，并起缗元年；经传在[前705年冬](../../years/bce-0800-0701/bce-0705.md#note-5)记诱杀、[前704年冬](../../years/bce-0800-0701/bce-0704.md#note-7)记王命。保留分阶段主线，不改原表数字。前704年灭翼不是前679年前后最终并晋的同一行动。

<a id="陈佗与厉公"></a>
### 陈佗、五父与陈厉公跃不能强拼

《春秋》桓六记蔡杀陈佗，桓十二记陈侯跃卒；《左传》庄二十二追述“蔡人杀五父而立之”，辨陈厉公与子完一系。传世《史记》混置佗、五父及厉、利，[卷036《索隐》](https://zh.wikisource.org/wiki/史記三家註/卷036)已指出问题。

[前706年](../../years/bce-0800-0701/bce-0706.md#cq-source-4)区分佗被杀、跃继立，[前700年](../../years/bce-0700-0601/bce-0700.md#note-4)保留经文陈侯跃卒，不从“公淫蔡、蔡杀公”另造第二次杀佗。表所系[前705年陈完出生](../../years/bce-0800-0701/bce-0705.md#sj014-0705-note)仍依赖邻近谱系有问题的传世纪年；周史筮完是少时回叙，不定成出生当天，不把后世齐国结果作独立验证预言的证据。

<a id="卫急子与寿"></a>
### 急子、寿之死从回叙归到前701年

年表及[《卫康叔世家》](https://zh.wikisource.org/wiki/史記/卷037)以宣公十八年记双亡，次年宣公死。《左传》桓十六从“初”字讲往事，解释左右公子为何怨惠公。主体已放[前701年](../../years/bce-0800-0701/bce-0701.md#sj014-0701-wei)，[前696年](../../years/bce-0700-0601/bce-0696.md#event-4)保留旧锚点、明确前情回链，不令宣公死后再下命令。惠公出奔、复入的进一步异年核对见下节；本批没有撤回这项修正。

### 新君元年与语义复核

秦宁公、出子、燕宣侯、曹庄公元年与前君死亡分开。燕穆侯卒由世家穆十八年与后继元年互校；曹射姑、夕姑按异写处理。前709年燕栏空白不自动填“二”；此前37ee0d5已补蔡桓侯等项，不重复新增。

邾请郑攻宋时“敝邑为道”的主语是邾；齐调停宋卫“于郑”，对象是宋卫与郑；公子忽成昏、亲迎分别归前716、715。楚巴夹攻时邓军“背巴师”不可前后颠倒，“四邑必离”是计议判断，不是四国行动已逐项核明。

上一批最后回读也纠正过度删改：六年只写犒军后郑，但桓十回叙明确“鲁以周班后郑”，故前706、702年保留周班依据，不称旧说全无来源。复核不能只选一段略文否定另一处详文。

## 前699—675年最新补充

<a id="桓十三年交战阵营"></a>
### 经文明确的败绩名单，不能被传文句读倒置

[前699年注3](../../years/bce-0700-0601/bce-0699.md#note-3)保留经文齐、宋、卫、燕败绩，与传文“以纪、鲁及齐与宋、卫、燕战”的歧义对读。旧页将齐当成鲁纪郑盟友，与明确败绩名单矛盾；正文现写鲁纪郑对齐宋卫燕。没有直接从原文删掉“及齐”，也没有获得足够现代校勘证据来判这两字必为衍文。史事取舍与文本定字是不同判断。[《左传》桓公篇](https://zh.wikisource.org/wiki/春秋左氏傳/桓公)。

<a id="后元年与亲属"></a>
### 复位、后元年与亲属背景

前698年武公由原来的太子身份被改立为君，不是旧秦君复位。前697年厉公五月奔蔡、昭公六月乙亥入、厉公九月入栎，三个步骤分开；前696年昭公元年只承接复位后的计年。

前680年《左传》明确六月甲子纳厉公，子仪与二子被傅瑕杀、傅瑕反遭厉公杀、原繁自杀俱在主述；前679年的后元年不再重复整场政变。甫假／傅瑕、子婴／子仪为互见，不造两套人物。[前680年](../../years/bce-0700-0601/bce-0680.md#event-3) · [前679年](../../years/bce-0700-0601/bce-0679.md#sj014-0679-zheng)。

前696年郑栏“忽母邓女，祭仲取之”，是祭仲为庄公娶邓女，不是祭仲自己与忽母结婚；该背景已在[昭公元年旁](../../years/bce-0700-0601/bce-0696.md#sj014-0696-zheng)说明，不硬定婚期。“有弟克”只是庄王有弟，放[前694年子克争位背景](../../years/bce-0700-0601/bce-0694.md#note-6)，不定出生于前695；“生子颓”则是表明列的出生年。周王子克又称子仪，与郑子婴之子仪异称不是同人。[《郑世家》](https://zh.wikisource.org/wiki/史記/卷042) · [《读史记十表》卷二](https://zh.wikisource.org/wiki/讀史記十表/卷二)。后者是旧考证材料，不冒称现代研究共识。

<a id="卫惠公出入"></a>
### 出奔一次、复入一次，不按表中重复句增造政变

卫表前697记朔奔齐、立黔牟，前696起黔牟元年；经传明确[前696年十一月](../../years/bce-0700-0601/bce-0696.md#event-6)出奔、拥立。前689鲁栏纳惠公是出兵目的，实际[前688年六月](../../years/bce-0700-0601/bce-0688.md#event-2)入卫；表前687、686又分别有立惠公、复入，均保留为异年互见，不能编成多次同样复位。整条卫君在位数尚未因一项归年选择而校定。

<a id="曲沃与楚王年"></a>
### 曲沃并晋与楚文王之死

前679年晋栏连记灭缗、献宝、受命，前678年又说明不更元。当前[前679年](../../years/bce-0700-0601/bce-0679.md#sj014-0679-event)讲并国与献宝，正式册命依《左传》庄十六见[前678年](../../years/bce-0700-0601/bce-0678.md#event-5)。曲沃时期年数延续，不是并晋后又过三十八年；旧考证中的二十八／三十八等文字问题也保留。分阶段叙述不等于已经消除所有晋侯年次冲突。

楚表前676年已起堵敖元年，楚世家文王十三年死通常折前677；经传却在前675年仍记文王败巴、伐黄、病卒。主述保留[前675年的详细过程](../../years/bce-0700-0601/bce-0675.md#event-1)，前676堵敖元年仅列另一纪年，不把两套体系都写成同时在位。楚文王始都郢仍前689，不能单靠“始都”断言考古已经锁定城址与竣工月份。

<a id="语义与漏项"></a>
### 补入的故事，与修正的主语

前690年说心神不安的是楚武王，夫人邓曼作答，随后死于军中的仍是王；用完整经传疏通年表“伐随告夫人心动”短句，不能误将夫人当成病亡者。前684年息妫过蔡、蔡侯失礼、息侯让楚佯攻诱蔡来援，补足莘战的前因；楚、蔡两栏分别记起因和俘获，为同一战役。

前683年宋君自罪在答鲁使之辞，不另外造罪己诏，御说起草与后来得知其才干的评价分开。前682年仇牧有义为褒评，其实际行动是闻乱赴宫、遇害。曹沫柯盟索地从原史料区移到[正文原锚点](../../years/bce-0700-0601/bce-0681.md#sj-062-L4595-03)；经传不记胁迫而史记保存故事的差异继续放注，不将多个同书篇章算成独立证词。

前689年“郳犁来来朝”中犁来为名字，旧正文截成犁已改；前687年“与雨偕”保留降雨而不只是数量比喻。前693年经不书即位，不足以证明没有即位礼；前692年鲁史列葬陈君，不等于鲁独力主持他国葬事；前676年三君“使原庄公”迎王后，实际去迎的是使者。秦德公四门用狗、伏祭按原文补礼仪位置，不追加防病疗效。

前675年宋栏“取卫女，文公弟”，[《宋微子世家》](https://zh.wikisource.org/wiki/史記/卷038)详写文公女弟，故补宋桓公娶卫文公妹妹；文公为后称，不能提前使其在位。“女弟”不误作男性弟弟，婚礼年月与夫人本名不补猜。[对应年页](../../years/bce-0700-0601/bce-0675.md#sj014-0675-song)。

<a id="子颓与燕军"></a>
### 子颓之乱的主语、五大夫及燕国别

《左传》庄十九先记五大夫攻王不克而出奔温，再记苏子奉子颓奔卫，卫、燕出兵，冬立颓；年表则压缩记王奔温。不能把五大夫败退的主语偷换为已经被他们打败的惠王；不同阶段出现温，不证明其主语始终相同。[前675年注3、4](../../years/bce-0700-0601/bce-0675.md#note-3)。

旧页把子禽、祝跪直接分开，又列其他大夫，名单与“五大夫”不合。正文改蒍国等五大夫，不凭顿号多造第六人；分词、官秩和人数仍待专门校核。表将燕卫伐周写在燕国王年栏，不能单凭列位置确定必为北燕庄公亲征；南燕、北燕对应未独立定案，正文保留燕军，不补现代路线、统帅。

公父定叔出奔在前678，后来的“三年而复”保存相对说明，未仅凭加减就确定新的绝对年事件。该类后叙可继续参核，不能因本批终点恰在前675就自动归到末页。

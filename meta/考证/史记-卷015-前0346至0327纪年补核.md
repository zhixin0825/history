## 内容

### 本轮证据与使用边界

本批以[《六国年表》公开八栏](https://zh.wikisource.org/wiki/史記/卷015)为转录见证，另核相关本纪、世家、列传、三家注与《水经注》所引《纪年》。前346—327年原格的旧王年、田馊等异字及网页括号照录，不能把正文校订倒写成原表原有的字句。网页的公元前年标也是现代编排。本轮没有对仓库所存点校本PDF逐页校勘，不以亲读网页冒称已核实体版本。

现代研究具体使用了[王政冬《田庄子至齐威王间田齐诸君年代考》](https://www.fdgwz.org.cn/Web/Show/3072)、[朱渊清《从校勘学到历史学》](https://fdgwz.org.cn/Web/Show/1490)有关魏惠王年链的讨论和[潘定武《苏秦行年试说》](https://xb.hsu.edu.cn/_upload/article/files/57/28/3894139b489182e3b9676de45df5/56c761e3-83c0-4a38-8556-2f26d55a4af3.pdf)正文。钱穆《先秦诸子系年》的相关论点，本轮只核到[出版方所列目录](https://www.sanmin.com.tw/product/index/011154269)；蔡运章、蔡奉哲《战国纵横家书全注全译》则核到[出版社书介](https://www.chunghwabook.com.hk/book/detail/id/1378029545429739203)。后二者足以标明作者取说，不能代替尚未读到的完整论证或帛书图版。

<a id="齐魏君次"></a>
### 齐威王继续在位，魏惠王改元不等于襄王继位

既有编年已恢复田和、田侯剡、田午、因齐的先后，齐威王交接仍保留前357—356年范围。因此原表[前342年齐格](../../sources/摘录/史记-卷015-六国年表.md#y0342)“齐宣王辟彊元年”不能再写成一次确实发生的即位；本批齐国叙事采用齐威王。具体元年仍有前356、355年两种衔接，不能一面保留这一差异，一面把以后每个齐王年都当作已独立核定。

[《魏世家·索隐》](https://zh.wikisource.org/wiki/史記三家註/卷044)明确保存惠成王三十六年改元称一年、尚未去世的说明。沿本项目暂取前369年元年，三十六年为前334年，当年重新计为后元元年；不再等待一个未经来源支持的“次年后元元年”。原表[前334年](../../years/bce-0400-0301/bce-0334.md)徐州相王仍可叙述，但两国君主改用魏惠王、齐威王，不写魏襄王登位。前335年旧年链中的惠王终局也不沿用。

朱渊清所论的前334／335年改元、前369／370年元年，分别连到不同的后元在位数和古书引文，说明这不是把全部魏国事件统一移动一年就能解决的问题。本批保留所选起点，具体事件仍逐条互证。未来惠王终年与襄王年链须接续核查，本次不宣布魏国所有王年已经完全校齐。

| 原表位置 | 对读资料所见的另一年次 | 本批正文去向 |
|---|---|---|
| 前336年齐：平阿南会魏 | 《孟尝君列传·索隐》引《纪年》惠王后元十一年，列传另有韩君、田婴参与 | 暂系[前324年平阿会](../../years/bce-0400-0301/bce-0324.md#sj015-pinga)，不采用与新年次冲突的韩昭侯、齐宣王君称 |
| 前335年齐：会魏于甄 | 同注引后元十三年与齐威王会鄄 | 暂系[前322年甄会](../../years/bce-0400-0301/bce-0322.md#sj015-zhen)，保留甄／鄄异字 |
| 前336年魏：孟子来、问利 | 梁玉绳据惠王后期失地等事，主张后元十五、十六年间 | 在[前320年](../../years/bce-0400-0301/bce-0320.md#sj015-mengzi)附约前320—319年记述，不硬断初见恰为前320年 |

平阿与甄会的直接依据为[《孟尝君列传》开篇古注](https://zh.wikisource.org/wiki/史記三家註/卷075)。列传正文说“明年”再会甄，古注却为后元十一、十三年，仍有一年差；本批采用古注分年并在同号注说明。平阿／东阿地名差异以及旧“是岁梁惠王卒”也没有静默消除。三处异年承接只补既有唯一年页，原表仍止于前327年，不能因此把原表进度算到前320年。

<a id="马陵与田忌"></a>
### 马陵暂留前341年，田忌去国改按战后未确年补叙

[《秦本纪》](https://zh.wikisource.org/wiki/史記三家註/卷005)以孝公二十一年记齐败魏于马陵，对应前341年；[《通鉴》卷二](https://zh.wikisource.org/wiki/資治通鑑/卷002)显王二十八年条及原有编年也采用这一位置。本批继续以[前341年](../../years/bce-0400-0301/bce-0341.md)保存唯一完整战役叙述。这些传世记载可能具有共同来源，不按书名数量宣称已形成独立证据多数。

另一年链由古注所引梁惠王二十八年得到前342年。王政冬2017年论文结合齐威王年数采用前342年马陵；《孙子吴起列传·索隐》相关二十七／二十八年的校字也影响换算。本批在[前342年](../../years/bce-0400-0301/bce-0342.md)与前341年同号注保留这一有据异说，尚不称两说已经裁定。原表“田馊”照录，正文所用田盼等名与异字分别注明；不因名字并列便补造无据的血缘或确定职掌。

[前344年齐格](../../sources/摘录/史记-卷015-六国年表.md#y0344)记田忌袭齐不胜，若直接顺表写，便会让田忌先去国、再回头率军打马陵。《田世家·索隐》已指出他在马陵败魏后受构陷、不得入齐的问题。[《田世家》](https://zh.wikisource.org/wiki/史記三家註/卷046)和《孟尝君列传》对袭齐、临淄或边邑的表述也并不全同。因此原年页留出说明并转挂前341年页的“马陵以后未确年的田忌去国”补叙；这只是叙事接续位置，不表示田忌的后事都发生在前341年，更不把战后故事变成初次登场前的经历。

<a id="秦周与秦魏"></a>
### 会诸侯、岸门与雕阴：先辨互见，再定年份

**前344与前342年的诸侯集会。** [《周本纪》](https://zh.wikisource.org/wiki/史記/卷004)显王二十五年记秦会诸侯于周，对应前344；《秦本纪》孝公二十年另记少官率师会逢泽、朝天子，对应前342。所读《通鉴》网页现代校刊曾移条并处理“逢潭”等文字，不能把现代移条又算作独立的前344年证据。前344年保留既有短述及锚点，前342年保存少官逢泽的完整记事；两者究竟同次而误年，还是另有集会，仍在同号注中保留问题，不推成秦主持某个已知制度化联盟。

**前339与前338年的岸门／雁门。** 原表秦孝公二十三年记与晋战岸门；《秦本纪》二十四年记雁门之战、俘魏错。《索隐》引《纪年》岸门，并指出岸、雁可能音讹。本批在新增[前339年](../../years/bce-0400-0301/bce-0339.md)暂从年表主叙，原[前338年](../../years/bce-0400-0301/bce-0338.md)旧锚点保留为异年回链，不增加第二场俘魏错之战。辑本《古本竹书纪年辑校》所补“〈三十二年，〉”出于据年表配置的编辑处理，不能冒充独立古引文再反证另一个公元年。原文“晋”与三晋称谓的使用另注，也不解释为晋国重新复国。

**前333、前331与前330年的雕阴。** 原表在前333年魏格写秦败魏雕阴；《秦本纪》惠文君七年记俘龙贾，对应前331；《魏世家》旧襄王五年又对应前330。现将同一场大败和龙贾被俘的核心叙述保留在[前331年](../../years/bce-0400-0301/bce-0331.md)，前333、330年说明不同系年并回链。各书记统帅公子卬或犀首等差异分别留注，不为凑齐年行拆成三场相同大战。河西、上郡以及焦、曲沃等后续交割仍按各自记载分年，不一并吞进雕阴战果。

前340年卫鞅俘公子卬、受商于之封，前338年孝公去世及商鞅败亡，按各自故事先后接读。[《商君列传》](https://zh.wikisource.org/wiki/史記三家註/卷068)提供其逃亡、魏拒纳及返回秦地后的经过；表文“反”与各书对死所彤地、黾池等差异留注，不能仅据一个字重构已经核实的罪名和全部审判过程。前335年攻韩宜阳与前307年甘茂取宜阳也不混为一次战事；“拔”字及先后是否相同性质仍依同号注取舍。

<a id="孟子苏秦"></a>
### 孟子用晚至魏的范围；苏秦行年保留真实存在的分歧

[《孟子·梁惠王上》](https://zh.wikisource.org/wiki/孟子/梁惠王上)记惠王自述败于齐、失地于秦、受辱于楚，这些信息使原表前336年首次来魏说发生困难。[梁玉绳《史记志疑》卷十](https://www.shidianguji.com/zh/book/NGJ892412000002866151907/chapter/1lqqusb38ejvm)“孟子来”条直接提出惠王改元后十五、十六年间来魏，并说明旧惠王三十五年说与误认改元为襄王继位有关。因此本批使用约前320—319年范围，不把几次对话及其中自述的往事都当作前320年的新事件。

孟子前事根据[卷074开篇](https://zh.wikisource.org/wiki/史記三家註/卷074)，只交代邹人、名轲及受业于子思门人的传承，不填写未经本轮核定的生年、年龄和游国年月。他的仁义之说与百姓生计相连，不能把“何必曰利”缩成反对一切物质生活。惠王所说“长子死焉”与马陵太子申被俘的《史记》表述有差别，本批不据此另定申的死亡日期。

原表[前334年燕格](../../sources/摘录/史记-卷015-六国年表.md#y0334)记苏秦说燕。潘定武《苏秦行年试说》（《黄山学院学报》2009年第11卷第2期，第45—48页）实际主张较早的苏秦年谱，保留前334年见燕文侯并推其终局约前319；不能反过来引用该文证明苏秦晚于张仪一代。相对的晚期说，本轮核到蔡运章、蔡奉哲译注本的出版社介绍，明确采用苏秦较张仪晚、活动于燕昭王时期的解释，并列唐兰、马雍研究为附录。书介是该书取向的证据，未读到的附录全文不称已经核读。

因此前334年只保留传世“苏秦说燕”的材料及有关燕赵相保的说辞，行年明确待考，不写成已经在该年落实的六国同盟。也不宣称全学界对苏秦先后已有一致结论。[前328年张仪任秦相及入秦前事](../../years/bce-0400-0301/bce-0328.md)的早年说明与任相、攻魏的有年事实分开；苏秦激张仪入秦的故事不能在上述冲突未解时无条件变成确定的登场前经历。

<a id="人物与短记"></a>
### 短格、君年和同名人物的未决项

| 材料 | 本批处理与理由 |
|---|---|
| 前346年齐“杀其大夫牟辛” | 大夫／夫人存在古注异文；《纪年》杀君母、杀王后的不同年条不能机械并到本年。只按同号注呈现所能确定的内容，身份不臆定。 |
| 前345年全行为数字 | 另据《水经注》汾水注引《纪年》补绛地裂。《水经注疏》卷六记录朱本“梁武王”，《笺》校为梁惠成王等版本差异；王国维辑校归惠成王二十五年，按本项目元年暂置前345。今本另系周显王二十三年，对应前346，异年留注；不编造震级或政治征兆。 |
| 前344年魏“丹封名会” | 梁玉绳也认为四字难解，只疑“名会”为“于浍”之讹；这是一项校字猜测。原字保留，不凭猜测写成已确定的封地与仪式。 |
| 前343年楚栏“鲁景公偃元年” | 属于鲁国，与前段康公在位年链同核；不因栏位而写楚王继位，仍待考。 |
| 前338年秦“（秦）大荔围合阳” | 保留见证原字及古注断句问题，不据“大荔”补造戎国复兴、秦国臣属身份或无据地理细节。 |
| 前336年宋太丘社亡 | 属宋事，虽记在秦栏仍不转成秦国祠社；汉代礼志的另一年次及记载性质入注，不写成宋国灭亡。 |
| 前328年宋君偃元年 | 《宋微子世家》及古注的剔成、偃在位数互有矛盾；钱穆目录所载另一方案为前338年幼年嗣位、前328年称王。本轮未读其完整论证，保留分歧，不把登位、政变、称王都定在前328年。 |
| 前327年《赵世家》补叙韩举败死桑丘 | 该年原表赵格只有年数，《赵世家》另记其死；后续前325年旧韩年材料仍有韩举，而赵将身份又见《纪年》及古注。国属、死获、地名与年次须合核，本条补叙明确待考，不擅补同名亲属或第二位韩举。 |

绛地裂校字的直接复核见[《水经注疏》卷六](https://www.kepub.net/book/51073/10006)汾水、绛县故城段；牟辛、丹封、孟子与宜阳等古考见上引《史记志疑》相应表年。宋君年链对照[《宋微子世家》及古注](https://zh.wikisource.org/wiki/史記三家註/卷038)，韩举问题对照[《韩世家·索隐》](https://zh.wikisource.org/wiki/史記三家註/卷045)与[《赵世家》](https://zh.wikisource.org/wiki/史記三家註/卷043)。待考格均有可追踪去向；登记完成不等于史实和日期已经全部裁定。

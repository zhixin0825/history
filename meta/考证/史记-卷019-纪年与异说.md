# 《史记》卷019《惠景间侯者年表》｜纪年与异说

核读：2026-11-02。主表、三家注、《汉书》王子侯表、两部功臣表与外戚恩泽侯表分开使用；正文归入唯一年页。全部93行完成阅读与落点，不等于已经校定每个任期、干支或争议身份。

<a id="口径"></a>
## 一、行数、人数与年代的三个层次

四段实际行数为3、31、28、31；题下注却为3、31、29、30。原表总计仍为93个位置，但不能据总数正好相等就说中间毫无缺漏。刘富的休侯、红侯分别占行；《汉书》景功臣表篇末颜师古也指出休、红重复计人的问题。汉书王子侯表另列杨丘刘安及后嗣，可补编年，却不足以证明所有传本计数差的唯一形成原因。主表不凭需要凑数。

原生格数502＝21＋186＋140＋155，其中国名、侯功186格，纪年316格。纪年格166实质、10纯数、140空格。每格可以含初封、几代继承、后来获罪，故166不等于独立事件总数。侯功的长履历也不是每句都发生在侯元年。

惠帝七年、高后八年、文帝二十三年、景帝十六年合计54个古史年条，序言“五十载”是概说，不要求改四朝年数凑成50。首次受侯范围与后嗣范围不同，现存末项到武帝后元二年前87年；前91、88、87年的后事不能移回景帝朝。十月岁首、景帝前中后三段、文帝前后改元分清，未逐日换算公历。

<a id="表序"></a>
## 二、表序、误字与后世评语

读到便侯而谈长沙，是以长沙吴氏的忠谨和后裔受侯解释封赏。五世无嗣终点在文帝后七年前157年，已经见既有长沙王统；并不是惠帝在位时吴氏五代已经结束。“著令甲”是回顾其获得特殊承认，不据表序另造惠帝颁一条新法的年月。“无功而侯”针对宗亲恩泽的受爵依据，不译成这些人全无任何任事、官职或社会作用。

主见证“长江”、重写“禅五世”、意无过、遣功臣等保存原形；阅读释义参考三家注的长沙、竟、遗。疑文可更正阅读，不可删掉原证据再说传本一致。网页已经校为“连嚣”等官名，也须注明现代编辑层。古注释“肺腑”可联系杮附、木札树皮，不能只有现代人体比喻一种解释。

司马贞《索隐述赞》概括诸吕、七国、条侯、壮武、薄窦及死事官员，是唐代评论。它有意将数十年人物并举，不按每句顺序重新排列各年的史事；称颂或批评都不自动成为某年新诏令。

<a id="亲缘"></a>
## 三、同名、同爵与母系冲突

张侈、张寿在本表称张敖与鲁元之子，本纪却明确是张敖前姬所生、被封来辅佐鲁元之子张偃。正文保留已有详细叙事，明确是张偃同父异母的兄弟；表的母系冲突放注，不靠多造一个张侈／张受解决。南宫张买本表记诛吕时被杀，汉表却列后嗣延续；不与张偃、张生凭同侯国强接，也不把该家灭爵年当作无争议事实。

赘其吕胜与滕侯吕更始由两张侯表分开，撤回旧年页把吕更始写成赘其的做法，保留本纪原文差异。吕庄受东平侯的五月与吕通进燕王的十月不同，不将同段排版当作同月授命。扶柳吕平为吕后姊子，姓吕有古注疑问，父姓未明，不擅补。

同国异人特别分开：前期周阳赵兼与后期田胜，平曲公孙昆邪与周氏，魏其窦婴与周氏，建陵张泽与卫绾，俞吕它与栾布，塞直氏与陈始，松兹／祝兹徐氏与吕荣。成陶侯周勃不是绛侯周勃，轵侯戎奴不是管侯戎奴；亚谷卢氏不得当作汉高祖刘氏。

<a id="起年"></a>
## 四、起年、死年与旧叙事的交叉检查

多数短格只有承侯元年，不由此一律倒推父亲上年死亡。弓高行景元年侯则元年，与韩颓当前154年领兵及汉表失载嗣年冲突，前156年只登记异说，不写韩颓当已死。徐厉一支两张侯表前173年已列悼嗣，却与前158年军记徐厉屯棘门冲突；正文暂称祝兹侯所部，既不擅改为徐悼，也不将表中父辈复活。

申屠嘉列侯初封史表在前161年，既有本纪、列传线置前162年；本轮保留已有主线，另注表年。早期关内侯与后来的故安列侯不同。其后世系在《张丞相列传》另有去病，表中略去，臾又更封清安；不默写成蔑直接生臾且终身同一国号。

亚谷承袭采用汉表前136年漏嗣，使种前143年起算七年的年链可相接，保留史表前140年偏元年。其他樊、江阳、容成、易、建平、范阳等一两年的差异，逐条明记暂采用的明确年号与另一表的年数。没有查到足以证明唯一结论的现代专题意见时，不声称“学界已经一致”；采用位置是阅读安排，不是删去异本的裁决。

<a id="未知"></a>
## 五、不能强定年的材料

南𨜓侯起后来因“后父故”降关内侯，只知文帝时，不能由前面的封侯元年、一年数字把处罚精确到前173年，更不能猜后父所指。遒侯隆强之后缺嗣侯年名，直到侯则前88年案才有落点；垣侯赐“不得及嗣”也是失载，不等于已知无后。

波陵魏驷的十二年、成陶周勃的十五年，以及若干后嗣任期有明年、历年歧义。正文采用处明确标暂定，不以补足年度页的需要强排日期。少数罪由只有“有罪”，不补谋反、宫廷阴谋或处死。张买一支两表对延续和灭爵差异较大，保留在前180年异说注，未创造一条无矛盾但没有史料支持的新世系。

<a id="处置"></a>
## 六、“国除”不是统一刑罚

王子由侯进王，原侯国自然结束，不是被处死或罢为民；刘富由休改红也不新增一个人。列侯无后而除国只是法定爵位无人承袭，不证明一切生物后裔灭绝。

垣侯“赐死”的赐是人名，不能按现代熟语直接译成奉旨自杀。新市始昌“为人所杀”不是朝廷行刑。轪侯擅发兵护卫当斩而遇赦，最后免侯；沈犹削司寇、山阳完城旦、宋昌降关内侯，也分别处理，不能写成同样死刑。章武谋杀未杀不改成已经杀人；太常祭牲、酎金和宫廷服制各有制度语境。

前112年多家酎金免爵与商陵赵周以丞相身份被追责、自杀分开。卷018已记全国一百零六人的统计，本卷增加的是其中可定位的另一组，不重复相加成新一批一百零六人。祝诅案只据司法材料叙述控罪、处分，不当作诅咒实际产生效果的证据。

## 内容

<a id="结构"></a>
### 原表结构、计数与表尾

本轮主见证162行、每行8栏，共1296原生位置；国名与王子号324格，纪年972格。纪年实质283、纯数字291、空白398。易侯王子号空白保留，两处陉城不同王子不合并；表首两段及唐代述赞另计，不当额外王子侯行。

原王子号文字口径：中山靖王19、城阳顷王19、长沙定王15、城阳共王13、赵敬肃王13、淄川懿王12、河间献王11、济北贞王11、齐孝王10、代共王9、江都易王7、鲁共王6、广川惠王4、淄川靖王4、胶东康王3、楚安王2、广川穆王2、衡山王赐1、空白1。此为原格计数，包含错系宗支；不能先把易空白补为赵、把济北两代合并，再冒称仍是底本文字。

清汪越《读史记十表》卷九的概述与本轮所见网页逐行数有差，如其代共王子八、淄川靖王子五等；本轮实数分别九、四，正文不为凑清人概数删补原行。其正文酎金五十五、补论五十六两个数字也不能混称一致。本轮直接检出史表明确酎金56行；汉表校云另补见，不能改称史表57行。

太初纯4通常指前104—101年四个年条；今侯只是作者表中当时持侯者，不是“今人”或一次新封。空格不表示某支必在本栏开始便死，也不表示必活到全栏末年。仅明嗣年而不明父卒年者不另补一次精确死亡。

<a id="表首"></a>
### 诏令、太史公评语与唐代述赞

P001诏文规定诸侯王逐条上报愿分给子弟的邑，由皇帝审定号名；没有写成所有儿子自动均分王国。P002天子之德是史家赞语，清人又有似颂似讽的理解，不能直接译为政策使所有人客观受益。P003索隐述赞属于唐代司马贞，回看汉初同姓封建、主父推恩与宗室屏藩；不是武帝当年的诏书，也不再造一次立法。

<a id="推恩"></a>
### 早期分封、推恩诏与献策时间

元光五年前130年茲侯、六年前129年长沙与楚王子、元朔元年前128年鲁与江都王子已受封，均早于前127年。王子封侯并不始于主父偃，分封个案与一项允许诸王主动申请的政策要区别。正文仍依汉武帝纪、通鉴元朔二年正月诏的明确年条，回接既有前127年推恩事件，不重写一次。

现代专题并非没有分歧：[岳庆平《主父偃献策推恩与汉武帝下推恩令应为元朔二年辨》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-515d705585d20493.md#cite-1)，北京大学学报1985年第2期129—130页，题旨支持二年，公开摘要述高敏主张更早的异说。本轮实际读到的是刊物页及摘要，不声称已读完整两页论证。[石洋《秦汉财产调查制度初探》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-920b6c1491bb02b4.md#cite-1)，汉学研究33卷1期（2015）23—24页，把推恩策实施系二年春正月，其对照表也显示列传排列并非严格按各策实施的日期先后。正文采用诏令明年；不把主父口头献策首次发生的具体月日也说成已定案。

[丁佳伟2018年论文开头](https://www.fx361.com/page/2018/0612/15550200.shtml)讨论诏文的申请机制及酎金以后继续推恩；本轮网页只有开头，后文需APP，故不用其未读结论证明所有诸王如何执行。上述局部核读不等于穷尽专题或现代学界一致。

<a id="城阳错栏"></a>
### 城阳顷王十九／二十条、挍与挾以及成组错栏

史表R135—153共19条初封落元狩栏，汉表明确以元鼎元年四月戊寅列20条；清汪越卷九存疑也在元鼎元年讨论此批。正文采用前116年，而非原栏对应前122年。原格6与栏宽相等，不能据此证明真正初封年；后续明确元鼎五年酎金仍前112年。

史挍侯霸，汉挾釐侯霸与校靖侯云两行。依清人名邑参错的具体辨析，正文把霸辨为挾侯，校云另以汉表补见H001；史原行不挪名补字、不删除。汉表是互校见证，不能把其额外一行伪装成史表原有第163行。

其后R154—159，淄川靖王、广川穆王诸子，史置元狩栏，汉承元鼎元年，七月又与史十月或四月异；同样暂取前116年，争议月份不填在正文。R160—162胶东诸子，史置元鼎栏，汉明元封元年；正文取前110年。皋虞嗣另取汉太初四年前101年，与史元鼎四年前113年并列保留。祝茲后事不能因此继续写在前112年，见u02。

<a id="年差"></a>
### 个别年线与终局

壤／怀昌取汉元朔四年前125年嗣（史前116年），距阳取汉元鼎五年前112年嗣（史前118年），两者有初封及任期可相接；姓名、侯名仍留原。阴城取汉前104年父卒、子不得代（史前110年有罪除），不把父亲死亡和儿子有罪合成一人犯罪。建成取汉前115年使者朝贺未及会而免（史前117年不朝），具体案由与两个年条均留注。

平酌中时嗣、剧魁昭及德嗣暂按史表前116、110、107年；汉网页元狩元年和父在侯十七年的组合不能一概自洽。陪安史前115嗣、114卒与汉114嗣、三年薨相冲突；不只靠三年强造一个无明确年条的死亡年。繁安史前101寿嗣，汉前107守嗣、后另有寿汉无确年，未强认成同一人或同一代。上述均为逐项可追溯的工作选择，不以书名决定全部优先权。

茲侯死法史弃市、汉自杀，正文取因杀人案而死亡除国；东城史有罪除、汉为孺子所杀，只取侯统一度中断，不拼成两案。国除并不一律处死。东平汉狱死、洛陵汉自杀、有利与宜成弃市、平侯遇赦仍服役分别处理。指控按传世案情讲述，不由道德评价独立证明全部事实。

<a id="数值"></a>
### 972格数值与边界

398空格、291纯数栏宽相合、264文字格至少一种年度边界可合、18格无独立历年数、1格分段数不能合。该疑项为夫夷元鼎原4、6，五年禹嗣前后应4与2；原6不改。雷侯元鼎原5可按含酎金处罚年得到，其他多格4排末，两种边界并存，不指称每个5必错或统一照一个公式改原数。

始封、嗣年与终局只在明年范围内复算；同日月份干支未独立历算，侯年不是完整周年。算术能合与持侯、身份、文本栏位正确是不同结论。所有格位、算式与缺数说明见数值复核。

<a id="未定年"></a>
### 未定年后续：保留阅读位置

<a id="u01"></a>
#### 土军侯的终局

史元鼎栏无年地记郢客与人妻奸、弃市；汉记改封钜乘而酎金免。仅栏位只能给前116—111年的范围，不足指定某年；汉也没有同样明确免爵年。本文前126年只叙初封，并从同页进入此处，后事不提前成初封当天。两种结局不拼成已证实的连续案情。

<a id="u02"></a>
#### 祝茲侯失爵

史前116年封、前112年弃印出国除；采用汉前110年初封后，原112年不能成为其后失侯。汉五年可读任期而未明终局年，按含首尾或排末分别落前106／105年，尚无独立明年证据定其中一个。正文前110年只叙受封，终局留此；不硬据一套公式造精确年。延／延年、祝茲／祀玆并留。

<a id="u03"></a>
#### 富侯的任期与元康字

史富侯襲原列济北贞王子；汉富侯龙列式王子，写十六年、元康元年使奴杀人、狱死。前126至前65年的61年差不等于十六年，但不能因此擅改元康为元封。此处只保存身份、数字和年号冲突，不补前111、110或65年任一为已确定的本卷终局。前126年是阅读位置。

<a id="作者层"></a>
### 一、读到鸿嘉元年，不把后补说成司马迁亲记

现传《汉兴以来将相名臣年表》从高皇帝元年到成帝鸿嘉元年，传统公元年对照为前206—20年，连续187行。它没有单独的太史公表序；不能因为前几卷有表序，就给本卷补造一段。最后的《索隐述赞》属唐代司马贞。

[三家注卷022](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7022.md#ref-f681aed5de2db6)太始元年附近保留《集解》引班固“迁记事讫于天汉，其后皆后人所续”之说；[述赞](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#z001)也批评天汉以后续表。因而本次把太始元年前96年以后的行标为传统判断下的续补范围，不把昭、宣、元、成各朝条目归为司马迁亲笔。关于亡篇与续作者的古代意见不尽相同；不能再推成现表每字都非原作，或没有证据地将全部续文归给褚少孙一人。

### 二、用五个逻辑栏读表，不按落栏误认官职

本卷古表逻辑为纪年、大事纪、相位、将位、御史大夫位。在线主见证的“元前”是现代定位列。本次依187行五栏展开为935个逻辑位置，纪年187；四事项栏748＝实质274、纯数136、空白338。这个数不冒称古刻本物理方格或HTML合并格数。网页提取每行六个文本槽，能保存列界；原始TXT没有列界，只用于对照字序。

周苛死、赵尧抵罪、庄青翟改太子太傅等字样有的写入别一官栏；职务必须结合句意和互见，不能因“尧抵罪”落在将位就编出将军赵尧。御史栏空白只是本格未记，不表示该年没有御史，也不把前一格姓名自动复制为每年新任。相位中的数字一般是逐年计一的任年，同年交替可同时写旧相任年和新相任命；不是每个数字都表示新任一次。

[任年复核](../记录/史记-卷022-任年数值复核.md)保留明确算式、换人和缺数。灌婴太尉两格与原表任命年起算不合，不能以移动任命年来使所有数字看似通过。张苍、张禹的空格不补改原字，推算值只写在核对说明中。

### 三、汉初到文景：异年、异名与前瞻

主见证为[卷022固定版2607038](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7022.md#ref-f55f83546636a5)。本仓`01_shiji_full.txt`卷022的187行去掉排版空白后，与主见证逐行同字。相同字序证明本次摘录没有漏字，不等于两个转录有独立史料来源，更不证明表里的纪年全部正确。

官历主要定向对读[《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-section-41)，疑点另参考[汪越《读史记十表》卷十](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%AE%80%E5%8F%B2%E8%A8%98%E5%8D%81%E8%A1%A8-%E5%8D%B7%E5%8D%81.md#ref-2ff05bdf2e66c4)。不以“史记”或“汉书”的书名大小自动裁断，采用理由落实在本年的同号史料注中。

| 问题 | 处理原则与阅读位置 |
|---|---|
| 周苛守荥阳及死年 | 元年格的守荥阳不能当作汉军尚未出汉中便已经守该城；本表四年前203年的死条与本纪、通鉴前204年互见，不重写第二次死亡。两位韩信也按当时国号和官职分辨。 |
| 萧何、曹参及王陵陈平交替 | 萧何前193、曹参前190的死亡与后继分别归既有故事；曹参死日乙丑／己丑、陵平上任己巳／己丑留异日，不生成一个混合的精确公历日期。 |
| 任敖、曹窋和周勃 | 任敖御史的惠六／高后元年、曹窋高后二／四年，以及周勃太尉的惠六／高后四年均有异年。正文用较可相接的官历，原格保留，不能写成同一职位反复新任。 |
| 高后末年审食其 | 相位格中陈平的任年与食其的太傅、复相、免相不能合为陈平一人的官历。诛吕、废少帝及迎立刘恒沿用旧核心事件。 |
| 文四申屠嘉／围 | 汉表文四载名为围，文十六才载申屠嘉；汪越据此提出史表的问题。正文依汉表分人分年，不凭史表一格让嘉连续担任十四年御史。 |
| 文九御史敬 | 汉表作冯敬，任命列文七年前173；两年互见，不另造一个无姓的敬。 |
| 文十诸侯皆至长安 | 王表和本纪不能充分支持扩写为所有诸侯王本年确实齐集；史表概记保留于注，不强行造一场全国大会。 |
| 景四御史蚡／介 | 汉表作介，汪越并以田蚡传当时官职存疑。正文不把田蚡在景帝前元四年提前升为御史。 |
| 景六、后元二岑迈 | 史表两条相隔多年，汉表缺对应且汪越存疑；不能由孤名制造确定的第二段官历或精确任期。原格及疑点都保留。 |

### 四、武帝段：不要让表格年次制造第二次战役、任命或死亡

元光、元朔、元狩各年的战争，与已有王表、侯表及祠祭线合读。只补本卷确有的将军职名、上下属关系和任官，不以将领同占一行就把跨季、跨年的战事压成同一次出征，也不因本表窄列漏记某将便否定其他记载。

| 问题 | 取舍 |
|---|---|
| 田蚡、灌夫、窦婴 | 史表将十月诛灌夫及窦婴列元光五年，汪越指出应四年；田蚡死、审案和窦婴死须按互见的跨年过程分开，不让已死者再参与后一年的争论。 |
| 卫子夫为后 | 原表置元朔元年，汉纪同年春三月甲子可接；与元光五年陈皇后被废分开，不把两事并为同年。 |
| 建元五年钱制 | “行三分钱”与汉纪罢三铢、行半两不合，正文取具体的废止与恢复，不扩写成未经证实的三分钱新制。 |
| 公孙弘继任御史 | 元朔五年本表未列番系；汉表明确载其任官。缺格不等于御史空缺三年；新增互见明确标汉表出处。 |
| 张汤御史任年 | 史表元狩二年、汉表三年有差；与其死前六年任期互看，保留一年的起算问题。 |
| 赵周、石庆 | 赵周的八月自杀／九月下狱死、石庆九月辛巳／丙申任相，是月份、日干和死法三个问题，不拼成一套貌似一致的日期。 |
| 石庆死、公孙贺相 | 史、汉的卒日戊寅／戊申及任相三月／闰月、丁卯／丁丑均在本年注保留；不擅改原表。 |
| 御史简称 | 卿、周、胜之由汉表互见辨为王卿、杜周、暴胜之，不按简称另造同名官员。 |
| 公孙贺父子案 | 史表征和元年冬与汉纪、汉表征和二年又有月份差。正文接前91年旧案；前92原格导向这一事件的异年注，不为误年再编一场处死。 |
| 武帝遗命辅政 | 上官“舛”与“桀”、大将军与左将军不同，依[汉书卷068](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7068.md#ref-45cba5441de53e)等辨为上官桀、左将军；不造两位大将军。原表日期及封侯语仍存，任官、遗诏封爵与实际受封分别处理。 |

### 五、昭宣元成续表：同名、官名、死亡和退休

后续段仍逐行读完，不因续作便略去，也不因为原表有日期就省掉互校。宣帝本始二年出兵、神爵元年击羌，与[汉书卷008](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-d78bf1d67c8629)等合读，范明友的度辽将军与田顺的云中太守不互换；许后死月、立霍后月份等差别保留在实际年页注。

王訢的封侯国号、前83年的王莽左／右将军、韦玄成与于定国官历、尹忠死年、前29年王商“右丞相”等逐项互见。其中王商任丞相的“右”不作为成帝恢复左右双相的依据；表中昭帝时卫尉王莽也不与后来篡汉的王莽混为一人。前41等年多将军迁转中的左、右官号分别保存，不把原表自身的前后简称抹平。

<a id="王章"></a>
**安平侯王章与京兆尹王章是两个人。** 原表前26及前21年作“平安侯”，须与汉书侯表和百官表的安平侯支互看；不能把京兆尹王章在前24年被杀，与侯爵支的将军、光禄勋官历串成一人死后再任。安平侯王章的前22／21年死亡与嗣侯元年分开说明，正文只死一次。原表国号不静默改字，采用安平侯的理由在注。

<a id="张禹"></a>
**鸿嘉元年前20年的张禹是退休，不是去世。** 史表末行“禹卒”照录；[《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0020)明确三月庚戌免、四月庚辰薛宣相；[卷081张禹传](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7081.md#ref-a9881114fe0d2e)又记其乞骸骨及退休后活动。正文采用退休，薛宣继任单列。张禹前5年才死的异年说明不作为本轮另开前5年年页的理由。

定向百科对照仅用于张禹的退相与卒年：已核[维基百科张禹（西汉）](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E7%BB%B4%E5%9F%BA%E5%8F%82%E8%80%83/%E5%BC%A0%E7%A6%B9_%28%E8%A5%BF%E6%B1%89%29-89560006.md#%E6%A0%B8%E5%AF%B9%E8%8C%83%E5%9B%B4)及[百度百科张禹](https://bkso.baidu.com/item/张禹/17571)。它们不替代上述汉书证据，也不冒称187年每位官员都完成了百科逐词条检索。

### 六、古历、任年与未决范围

古历十月岁首、后九月与太初改历继续沿既有规则；公元前年页只是整年对照，不能把十月直接变成同号公历十月。原文月日和现代年代换算是两层证据，本轮未独立换算所有干支，不给出虚假的统一公历日。

完成表示现传本187行、四事项栏以及述赞均已阅读、分类并给出正文或考证去向。史表自己的疑年、疑名、缺格和两格太尉任年疑数仍可保留，不等于没有把本卷读完。互见汉书的具体条目不表示汉书卷019、068、081均已整卷编完；原始全史TXT、点校本PDF不改。

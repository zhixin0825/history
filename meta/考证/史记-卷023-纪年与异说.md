## 内容

<a id="文本层次"></a>
### 全文、平行段与作者层次

本轮以维基文库固定版2607039为主见证，把旧24个稳定阅读单元补成全文。正文和唐代述赞共27个显示段落，去排版空白后2921个字符；合并24单元与主见证逐字相同。旧概要、所有稳定编号继续可用，原字不随正文采用线校改。

《礼说》欲望、养与辨、儒墨段，《礼法》三本、祭祀等差、情文段，以及篇末传本题太史公曰的长段，与荀子礼论相近；楚甲、唐昧、庄蹻、鄢郢、商纣及尧刑诸例则与荀子议兵相近。本轮列出14组相应荀子段落全文，余10单元核古注、相关纪传与性质；不再只笼统标礼论为全部平行出处。相近文字不能重复当成两份独立史事证据。

所见《索隐》在篇末称太史公取荀卿之意，《正义》在全篇末又称褚先生取荀卿补成。两个解释本身有张力，不能因有太史公曰署语就把传本文字作者一概定为司马迁，也不能不加辨析就改题褚少孙独作。唐代司马贞述赞独立于汉代正文。

现代讨论参[王衡《礼书来源问题论衡》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-2cecca0c2c648ee0.md#cite-1)，渭南师范学院学报2017年第32卷21期59—63、74页。文章梳理亡佚、褚补、司马迁因袭及后人补写诸说，并论摘取前人文字与史迁写作策略可以相容。本轮据此保留成篇争议，不把一篇论文当作作者问题的学界定案。

<a id="大行"></a>
### 大行礼官与官名更改

篇首余至大行礼官只提供所见礼官的叙述，不能独立推出作者担任该官或此段写成日。所见索隐称秦大行、景帝改大鸿胪；[汉书百官公卿表典客条](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-section-15)则明确典客是秦官，景帝中六年前144年改大行令，武帝太初元年前104年改大鸿胪。后者区分两次更名，正文采用此官历，不沿古注混称景帝已改大鸿胪。

### 秦汉制度回顾与确定的旧事件

| 单元 | 时间与采用线 | 归年界限 |
|---|---|---|
| Y003秦择六国仪 | 前221年统一主线作阅读入口 | 不能定各仪节全在统一当日施行 |
| Y004叔孙通朝仪 | 前200年长乐宫十月朝贺 | 野外演习、增损秦仪与正式朝会分过程，不再制一次 |
| Y005文帝停议礼 | 文帝在位期，确年未定 | 前179年仅范围入口，非该年新政 |
| Y006晁错与诸国 | 前154年七国之乱，晁错死而战事未止 | 原六国保留，不改七国名单 |
| Y007十余年不就 | 武帝朝跨期议礼，前110年只是已核一阶段 | 不从年数均匀制造会议日期 |
| Y008太初综合叙述 | 前104年改正朔、服色；前110年已有首次封禅 | 不能把首封与宗庙百官仪各项全定前104年 |

Y006主见证六国，所见正义列吴、楚、赵、菑川、济南、胶西六名，漏胶东，并以齐王守城释其不言七。七国名单实际不含齐而含胶东；吴王濞列传的起兵名单可核。因此正文沿既有七国史事，古注解释另存，不据其错漏增删参与者。既有晁错、袁盎及景帝的核心过程不重复叙述。

<a id="楚事"></a>
### 唐昧、庄蹻及鄢郢

唐昧败亡沿已核前301年，原垂涉、唐昧与荀子垂沙、唐蔑异文一并保存。列国攻楚、秦自身战事的参战与战果口径仍按既有年页，不把三种文字变成三次唐昧被杀。

庄蹻起与唐昧死并列没有给起兵确年，也没有证明其与西南夷列传楚威王时入滇的庄蹻故事全部同一人、同一次行动。史文四參，荀子三四；古注又有四字后断句、参作验的解释。本轮只说明楚局势分裂的论旨，不落实为楚国当年正式划成四个已考定的政区。

[梁英旭关于庄蹻入滇叙事的研究](../../sources/补充阅读/开放参考/ref-9ee2b4aa74b8594c.md#checked)从祖源记忆建构解释该故事，是一种现代论证路径；它不足单独证明本篇的起兵人和入滇人必同或必异。此处保留不确定性，不为与战役衔接而添加一个精确起事年。

鄢、郢不是同一地名。[秦本纪](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7005.md#ref-d254e8637100e6)昭襄王二十八年记白起取鄢、邓，二十九年记郢陷；现有年页分别为前279、278年。旧卷023摘要把前278秦取鄢郢连作一个年份，现明确订正。礼书与议兵把连年战果压成理论例证，不足另定同年攻取、同日陷落或固定用兵速度。

<a id="礼义释读"></a>
### 论旨、疑字与制度史的界限

| 原文问题 | 本轮读法及保留的差别 |
|---|---|
| 欲不得而忿／求 | 史、荀措词不同；讲欲望、资源与规则，不把礼一概译成禁欲 |
| 礼者养也与贵贱有等 | 供养和身份等差并行，非现代平等供给制度已实行的证明 |
| 儒者两得、墨者两失 | 是篇中文本立场，不当墨家观点的完整中立摘要 |
| 玄酒、大羹 | 据古注分别为水、不调以盐菜的肉汤，非黑酒或盛宴菜谱名 |
| 诸侯不敢怀／坏 | 主见证与荀子字差留原，古注两解不统一成已无争议制度 |
| 郊畴、函及／郊止、道及 | 古注本有字形、训释争议，不凭一字造另一套祭祀官制 |
| 七世、五世、三世、二世 | 先保存祭祖世数口径，不自动换成各国实有固定庙数的实证 |
| 特牲而食／持手而食 | 两见证不同，庶人不得立宗庙的礼说不等于已证所有庶人皆无任何祭祖形式 |
| 弗啐／不醮、三侑／三臭 | 祭礼阶段、献酒劝食等解释另存，不直译为日常三餐禁令 |
| 脱／梲、稅／悦校 | 史注稅读悦，论简略、文饰与人情和悦，不是征税政策 |
| 隆杀 | 厚薄、减省和礼的程度，不是政治杀戮或废除人的情欲 |
| 宫庭、礼域 | 伦理秩序的比喻，非君子一律不能出宫的禁足令 |
| 楚、商、尧刑例证 | 论证政道胜于器械、险阻和严刑；不因同文增加独立史证数，也不造确年刑案 |

三家注引用微子太师挚等乐官散处，用来释礼坏乐崩。该援引不能证明这些乐官都是孔子受业弟子，更不能把他们全在孔子去世后同一年出走列成事实。原文周衰到孔门跨代评论保留，人物、言论的各自日期未由这一段排定。

<a id="未定年"></a>
### 未能独立定年的材料

<a id="u01"></a>
#### 文帝罢议礼

在位期内确年未载。前179年只是范围入口；不能由即位一词便定前元年。文帝身教节俭的古注例证也不保证与罢议礼当天相连，不能拼成一次新诏。

<a id="u02"></a>
#### 武帝召儒与十余年议礼

初始召儒、每次集议及所引制诏各自日期没有在本段分列。前110、104年各有可接史事，但不能反推整个十余年都发生其一，或仅凭十余年算出唯一召集年。

<a id="u03"></a>
#### 庄蹻起及三四分裂

本段缺起兵日年及行军路线，也没有足够信息把起兵、暴郢、入滇三类记载合为一段连续确年履历。前301年为唐昧战败的阅读入口，非这里已确庄蹻起兵年。

<a id="u04"></a>
#### 子夏心战、孔子正名与仲尼坐树

前两者在礼书无确年；正名之言不能直接当一次已实际完成的卫国制度改革。述赞坐树可与孔子世家树下习礼相接，但本轮未以世家压缩行程独立校定其绝对年；不为此往前492年既有页硬添一场宋难。叔孙通蕝野则只补前200年朝仪背景。

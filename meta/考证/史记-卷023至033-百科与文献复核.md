# 《史记》卷023–033｜百科与文献系年复核

[考证目录](README.md) · [本轮校对记录](../记录/2026-11-13-百科与文献系年复核.md)

以两部百科的具名条目作为异说入口，系年回到仓内经传、纪表及本地原文。各卷原有逐段、历数和异文核对记录继续作为底本依据。本页记录本轮实际核到的主题；百科未载的段落沿其原典校记。

| 卷与节点 | 百科所载 | 原典、研究与编年取舍 |
|---|---|---|
| [023 礼书](史记-卷023-纪年与异说.md) · 鄢、郢 | 中文维基与百度《鄢郢之战》（3999239）都列前279–278年。百度《公元前278年》（3039894）概述又把开战和拔郢写在同年。 | [《秦本纪》P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)分昭王二十八年取鄢、邓与二十九年取郢。清华出土文献研究《西陵县与“东故徵”》也逐年辨其推进。沿[前279](../../years/bce-0300-0201/bce-0279.md)取鄢、[前278](../../years/bce-0300-0201/bce-0278.md#note-1)取郢。两书所见庄蹻行事有不同传统，维基《前278年》串联拔郢与庄蹻入滇，仍不足以给后者单独确年。 |
| [024 乐书](史记-卷024-天马纪年与文本层次补核.md) · 两首天马歌 | 百度《天马歌》13185同时列前120、前113，3941789从前113；中文维基《李广利》《汉攻大宛之战》另有前104出兵、前101凯旋。 | 《汉书·武帝纪》分别记元鼎四年得渥洼马及太初四年得宛马；《礼乐志》《通鉴》把前事系元狩三年。沿[前113渥洼](../../years/bce-0200-0101/bce-0113.md#sj024)、[前120异说](../../years/bce-0200-0101/bce-0120.md#sj024-alternative)、[前101大宛](../../years/bce-0200-0101/bce-0101.md#sj024)。参《汉代郊祀歌〈天马〉章考释》对马源、称名与祭歌的辨别；公孙弘前121已卒，两种渥洼年都不能容其发言。 |
| [025 律书](史记-卷025-纪年与异说.md) · 文帝议兵 | 中文维基《汉文帝》与百度《公元前179年》均叙文帝再遣陆贾往南越；陆贾使事不能为陈武议兵赋年。 | [《律书》P009](../../sources/摘录/史记-卷025-律书.md#p009)仅据“历至孝文即位”起叙，陈武所提南越、朝鲜是一次未确年的议兵背景。保留[前179的未定年阅读入口](../../years/bce-0200-0101/bce-0179.md#sj025-note)，不另加本年事件；八风十二律和历数照原有数值复核。 |
| [026 历书](史记-卷026-纪年与异说.md) · 太初改历 | 中文维基《太初曆》、百度《公元前104年》（973534）都系颁历于前104；都并列多名参与者。 | [前104同号史料](../../years/bce-0200-0101/bce-0104.md#note-5)分提议者、分天区者、历算者和最后采用的邓平八十一分法。肖尧《试论太初改历中的历元确定与藉半日法问题》（《中国科技史杂志》2022年第1期，第77–88页）讨论历元本身；《历术甲子篇》甲寅起点与前104颁历史事仍分读，百科简述不能证明历表作者。 |
| [027 天官书](史记-卷027-纪年与异说.md) · 星陨与陨石 | 中文维基《流星雨》、百度《星陨》（4579132）都据鲁庄公七年作前687，又同样将其认作天琴座流星雨。NASA沿天琴座解释，Ahn 2004年的东亚流星雨目录则归于宝瓶座η。 | [前687](../../years/bce-0700-0601/bce-0687.md#note-2)的“星陨如雨”与[前644](../../years/bce-0700-0601/bce-0644.md#note-1)的“陨石于宋五”分记。《汉书·五行志》亦分两条；何志华《〈荀子·天论篇〉“星队木鸣，国人皆恐”解诂》以五石例讨论听见与观察。年页保留经传原纪年，不把不同现代流星群识别升格为古书记事。 |
| 028 封禅书 · 泰山初封与明堂祀礼 | 中文维基《封禅》《前110年》与百度《公元前110年》（1029790）同用前110；中文维基《元封》另在年号说明中用前111年的纪法。 | [前110年](../../years/bce-0200-0101/bce-0110.md#note-5)首封泰山，与[《封禅书》p83](../../sources/史记三家注/卷028.md#p83)仪节及《泰山志》的系年相合。前104年《孝武本纪》作「每修封禪」，[《封禅书》p95](../../sources/史记三家注/卷028.md#p95)作「毋脩封禪」，徐广注同释为只祭明堂。[前104年祀礼注](../../years/bce-0200-0101/bce-0104.md#note-1)补引该异文，仍依《汉书·武帝纪》和《封禅书》记明堂祀礼，颁历另列本年第5条。辛德勇论汉代改元指出应分别看诏文、当时用年和追书年次。本轮核及这两条已发布年页的史事与底本。 |
| [029 河渠书](史记-卷029-纪年与异说.md) · 郑国渠、瓠子、井渠 | 中文维基《郑国渠》列前246开工、前237或前236告成，百度《郑国渠》同用前246为开端。 | [前246同号史料](../../years/bce-0300-0201/bce-0246.md#note-3)保留开工与施工后续的分别；《河渠书》《汉书·沟洫志》无明文竣工年。[前132瓠子初决](../../years/bce-0200-0101/bce-0132.md)、[前109塞瓠子](../../years/bce-0200-0101/bce-0109.md)据《汉书·武帝纪》年条；黄世锦《试论〈史记·河渠书〉中汉武帝对国家水利工程的建设》对井渠工法与坎儿井源流另有辨析，井渠仍随跨年项目读。 |
| [030 平准书](史记-卷030-纪年与异说.md) · 初算缗、告缗 | 中文维基《算缗》《告缗》和百度《算缗告缗》（8702419）都列前119初算缗、前114告缗诏；百度《告缗》（1705349）另叙前110结束。 | [《汉书·武帝纪》元狩四年](../../sources/本地分卷/汉书/汉书-卷006.md#L416)及[元鼎三年](../../sources/本地分卷/汉书/汉书-卷006.md#L437)两条相隔五年；《平准书》早一层制度文字已写告发分赏。以[前119](../../years/bce-0200-0101/bce-0119.md#sj030-suanmin-note)收初算缗与原条所见分赏，前114有[明确诏令](../../years/bce-0200-0101/bce-0114.md#sj030-gaomin-note)。实际稽查历时多年的概述留在同注，前110结束的百科说不作有明文的停令。 |
| [031 吴太伯世家](史记-卷031-纪年与异说.md) · 余祭 | 中文维基《餘祭》正文用前544卒并列《史记》在位至前531；百度《余祭》也用前544，另给未经古籍证实的生年。 | [《春秋》《左传》及年表](../../years/bce-0600-0501/bce-0544.md#event-7)支持余祭被弑于前544；本传另叙十七年卒，见[前531异说](../../years/bce-0600-0501/bce-0531.md)。元民帅《苏州博物馆藏吴王余昧剑铭文与余祭、余昧史事》以铭文研究其兄弟和承嗣关系，又列古书不同年数。剑铭没有公历卒年，沿经传主条。 |
| [032 齐太公世家](史记-卷032-纪年与异说.md) · 齐昭公与舍 | 中文维基《前613年》与百度《齐昭公》均记前613昭公卒、舍继位；史表及经传的逐项取舍见下。 | [经传及年表互校](../../sources/摘录/史记-卷032-互校原文.md#z-zhao-death)从鲁文公十四年；本传昭公十九年依元年折前614，弑舍称十月，《春秋》经作秋。死亡与继位仍只在[前613](../../years/bce-0700-0601/bce-0613.md#note-3)编排一次，保留月次差。 |
| [033 鲁周公世家](史记-卷033-纪年与异说.md) · 楚灭鲁 | 中文维基《鲁国》叙事用前256、君表又列至前249；《楚灭鲁之战》把前256、249连成两阶段。百度《东鲁》（363040）列前249、256、255三个口径；曲阜文博资料采用前249。 | [《鲁世家》](../../sources/摘录/史记-卷033-鲁周公世家.md)由顷公二年拔郢（前278）推二十四年为前256；[《六国年表》](史记-卷015-前0286至0247纪年补核.md)另有前255取鲁封莒、前249灭鲁和迁置。保留[前256本传主叙](../../years/bce-0300-0201/bce-0256.md)及另两年对读，现有文字不足以逐年坐实百科重构的完整过程。 |

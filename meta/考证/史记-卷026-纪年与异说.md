<a id="历制总说"></a>
### 历制总说不是逐年发生的政令

P001以孟春、物候、昼夜、四时和十二节说明安排历日的意义，P002说受命改正朔、服色。这是篇首的历制论述，没有可分配的确年；不能把十二节拆成十二件有日期的新事，也不能把“孟春”一律当成现代公历二月。《索隐》把前段部分语句联系《大戴礼》，它是注家的平行文本辨认，不是给黄帝时代添加一份现场档案。

“正”在此关系岁首、月份等历制，“朔”是月初日；改正朔也不自动意味着全部观测、岁实、朔策在一次诏令中同时革新。P001“卒于冬分”，注家以一岁季冬结束解释，不宜无说明直接译作冬至；“日归于西、月归于东”等为古代观察与义理表述，不改成现代天体运行公式。

<a id="上古"></a>
### 黄帝、重黎与羲和：传统先后有据，绝对年无据

P003黄帝考定星历、设五官、分民神，接[黄帝与颛顼时期页](../../years/上古/01-黄帝至帝喾.md#sj026-note)。这类圣王叙事包含历职起源与理想治世，不能依据“灾祸不生”“民无夭疫”创建远古灾害和疾病逐年统计，更不能倒推现代意义的行政部门成立日。

P004以少暤衰世、九黎乱德为背景，叙颛顼命南正重司天、火正黎司地。原字保留“南”“火”；《集解》应劭、《索隐》所录臣瓒及其自身解释涉及阴阳官职、兼职和“火”“北”形近等不同意见，不将其中一说偷偷换入原文。重、黎并非因为被后世联系到羲和，就能排成可核的个人生卒年链。

P005写三苗承九黎乱德、二官废职、闰余失次，继而叙尧恢复重黎后人、立羲和，接[尧舜至禹原有历职主线](../../years/上古/02-尧舜至禹.md#sj026-note)。这是本卷的制度起源传统，不能只从同名号、后裔关系就把所有卷次的九黎、三苗、共工材料拼成单个人的连续履历。“天之历数在尔躬”及舜命禹兼有君位、天命的意义，不能只释为某个历法参数交接。

<a id="三正"></a>
### 三正的传统对照与实际历日的边界

P006以夏正正月、殷正十二月、周正十一月说明三正循环。本次在[夏代时期页](../../years/上古/03-夏代.md#sj026-note)合并互见，并链接已有商初改正朔与商周之际内容，不给夏商各王新造一个改历公元年。

三种月名按夏正对照，是建寅、建丑、建子这一传世框架；不等于各朝自己都把岁首称作“正月／十二月／十一月”这三个夏历同号，也不等于每一传世年、月、日已能无争议换算。刘次沅《周初历法问题两议》从《武成》历日讨论“周历建子”的适用限制，提出西周置闰不稳定、建正游移的可能；本轮只读到期刊官网摘要，采用它提醒“不将整齐传统直接当作出土历日已证实”，不宣称这一具体解释是全体学界定论。详见[现代研究范围](#现代研究)。

<a id="春秋"></a>
### 周襄王二十六年闰三月：归前626年同一事件

P007“周襄王二十六年”与鲁文公元年对应，仍入[前626年既有年页](../../years/bce-0700-0601/bce-0626.md#sj026-note)。该页原有第10条、左传T002全文及锚点全部保留，本轮只补卷026互见，不新增另一场闰月。

《春秋》经文在本年没有逐字写出“于是闰三月，非礼也”；这些话及履端、举正、归余三原则见于《左传》。所以《历书》“春秋非之”按传义概称理解，不据此给《春秋》经文塞入一段原无的文字。《历书》作“归邪”，古注音余，与《左传》的“归馀／归餘”相通。

本轮没有排算鲁历全年的朔闰和中气，也没有以现代公历闰年原理裁判此条。把材料归到古史前626年年条，不表示已将古历三月换成同号公历月份。

<a id="秦汉"></a>
### 邹衍背景、秦水德与汉北畤分别安排

| 单元 | 可归档内容 | 阅读位置与限制 |
|---|---|---|
| P008前半 | 战国邹衍五德之说及诸侯并争的概括 | 是学说背景；本卷未给生平、献说的确年，不任选秦统一年作为邹衍创说年 |
| P008后半 | 秦以水德解释统治、德水、十月岁首、尚黑 | 接[前221年既有秦制说明](../../years/bce-0300-0201/bce-0221.md#sj026-note)，原编年采用本纪、《通鉴》，不因卷026回叙再造同事 |
| P009 | 高祖增北畤、汉初沿秦正朔及张苍水德说 | 北畤据《封禅书》与《汉书·郊祀志》汉二年接[前205年](../../years/bce-0300-0201/bce-0205.md#sj026-note)；“汉兴”不是只有前202年称帝一个时间点 |

《封禅书》称二年东击项籍而还入关，遂问秦祠、增立黑帝祠；《汉书·郊祀志》亦系二年，相关叙述与军事行程的月份不完全清楚。本页补北畤在汉二年的制度行动，不从“东击还关”四字另推出彭城败后某日刘邦本人祭黑帝。两书都说有司进祠、上不亲往。

正朔、服色、祀帝和五德理论彼此有关，仍不可强作处处一致的一套颜色。《历书》概称沿秦服色；《封禅书》另记高祖起兵尚赤；《汉书·郊祀志》有外黑内赤的说法。保留这些层次，不把黑帝祠与汉初各类服饰一律画等号。秦历也不因本卷说历度闰余未睹其真，就获得可量化的“每年误差多少天”结论。

<a id="文帝"></a>
### 公孙臣、新垣平与张苍：一段总叙跨越数年

P010没有独立纪年，不能以段落顺序把所有事情挤成文帝某一年的连续动作。本次保留既有年线并补互见：

| 事项 | 采用的年页／时间精度 | 依据与取舍 |
|---|---|---|
| 公孙臣初议汉当土德，张苍反对 | [前166年作为原有阅读入口](../../years/bce-0200-0101/bce-0166.md#sj026-note)；初次上书确年留疑 | 《孝文本纪》在十四年段叙，《通鉴》十四年以“初”回叙；不凭回叙当成当年初发 |
| 成纪报黄龙，公孙臣为博士、草改历服色 | [前165年](../../years/bce-0200-0101/bce-0165.md#sj026-note) | 《孝文本纪》《汉书·文帝纪》与《通鉴》十五年；记录报告及政策行动，不作神异独立证实 |
| 张苍自黜／自绌、谢病称老 | 与前165年土德之议互见，不能直接改称正式免相 | 《张丞相列传》在此以后还叙所任中候犯法、受责、病免；“自绌”与后来免相分层 |
| 新垣平入见，营渭阳五帝庙 | [前165年](../../years/bce-0200-0101/bce-0165.md#sj026-note) | 从本纪、汉纪、《通鉴》年条；《封禅书》“其明年”不强压过相互支撑的明确年条 |
| 亲祀渭阳、授新垣平上大夫，献杯与改元预告 | [前164年](../../years/bce-0200-0101/bce-0164.md#sj026-note) | 汉纪十六年四月、九月及《通鉴》；《孝文本纪》把玉杯接十七年，异文保留在旧注 |
| 新垣平气神欺诈案发、被诛夷 | [前163年](../../years/bce-0200-0101/bce-0163.md#sj026-note) | 汉纪后元年冬十月、《通鉴》；“后作乱”不另造一次武装反叛 |
| 张苍正式免相，申屠嘉接任 | [前162年](../../years/bce-0200-0101/bce-0162.md#sj026-note) | 本纪、将相表、汉表与《通鉴》后元二年；不把本年移回黄龙初见之年 |

公孙臣初议尤其不能装作已无异说。《封禅书》先叙文帝十三年除秘祝，又在“是岁”之诏自称即位十三年，接公孙臣上书，后说“后三岁”黄龙见；与十五年黄龙的明确年条不易完全衔接。《汉书·郊祀志》由十三年接“明年”增祭，再叙公孙臣，又以“明年”接黄龙，更接近十四年初议、十五年黄龙的线索。《通鉴》虽列十四年却用“初”，实际仍可为此前。故维持旧前166年阅读入口而标实际初议未确年，不另建前167年第二条上书，也不宣称已唯一判定原始日期。

新垣平案后的“不复问”，依《封禅书》《汉书·郊祀志》和《通鉴》，是文帝怠于相应改正、服色、鬼神事业；渭阳、长门祭祀仍由祠官按时办理。既不扩大成汉朝以后永不改历，也不说全部祭祀停止。

<a id="太初"></a>
### 太初改历、首次封泰山与岁名必须分开

P011从“至今上即位”写到唐都、落下闳，再概称改元、更官号、封泰山。这是武帝时期的总叙，不能把改历参与者的全部工作钉在武帝前141年即位当天；首次封泰山仍在[前110年](../../years/bce-0200-0101/bce-0110.md#sj026-note)，太初改历仍在[前104年](../../years/bce-0200-0101/bce-0104.md#sj026-note)。已有官名沿革由旧卷各自的明确年月支持，不以这里的一个“更”字重造所有官号的同时变更。

诏中“其更以七年为太初元年”，《索隐》释元封七年改太初元年。十一月甲子朔旦冬至与夏五月定正历，是古史同一年度叙述内的不同环节；不以现代一月岁首重排后悄改原文。诏中的“今日顺夏至”保留原字，《索隐》释兼指夏至、冬至；它不足以断定颁诏当日正是现代历算所得夏至，也不能为了读起来顺而静默改成“冬至”。

| 名称／说法 | 材料层次 | 本次采用方式 |
|---|---|---|
| 焉逢摄提格，甲寅 | 卷026表首及《索隐》等对太岁岁名的解释 | 是本表起排和历元表述，逐字保存；不直接覆盖实际前104年的连续干支标年 |
| 丙子 | 《索隐》引《汉志》，并以三统、太初体系差异解释 | 记录为注家所论的异说，不据其一种解释强使所有系统一致 |
| 丁丑 | 《通鉴》太初元年标年；四库本卷后考证以之反驳把本表甲寅直接等同武帝实年 | 编年仍用古史太初元年与前104年对应；不因此回改源文“焉逢摄提格” |

岁名、实际年干支与历元托始的关系，古注和后世考证已有不同解释。本轮采最低限度可共证的处理：历表保留自己的甲寅起点；统一编年保留太初元年的实际历史年条；两者不能仅凭表旁附年号就无缝套用。现代关于太岁体系与岁首衔接的解释亦属研究论证，不据某一论文宣布诸说已全部统一。

<a id="历表"></a>
### 76行四分法表不是76项天文实测新闻

《历术甲子篇》按所附年号，自太初元年至建始四年，阅读上对应前104—前29年，共76行。本仓TXT的元平元年／本始元年、初元元年／正东二年两处物理行粘连按逻辑拆分，原字不丢；数字逐行另见[历术数值复核](../记录/史记-卷026-历术数值复核.md)。

复算能说明原表采用的平均朔策、岁实、章蔀结构及数值内在一致性；不等于把它认证为76年的天文观测日志，也不等于已经重建每月实用朔闰、中气及每次改历后的官方历谱。四分法的一岁365又1/4日，与日法八十一一系的历算不能只因都出现“太初”就混同。[《汉书·律历志上》颜师古注本](https://zh.wikisource.org/w/index.php?title=漢書顏師古註/卷021&oldid=2688075)明确叙唐都、落下闳与邓平等参与、朔策29又43/81日，并称诏司马迁用邓平所造八十一分律历、经淳于陵渠覆校而用邓平历。这里是《汉书》记颁历与校候的历史叙述，不把其八十一分常数套进本表940分的月小余。

刘次沅1997年原研究的期刊摘要明确区分同一76年区间的《甲子篇》四分法历谱与《太初历》八十一分法历谱，并进行对排。这里据之采用“本表算法须独立辨认”的结论；摘要英文缺失若干书名、数学符号，不能靠残缺摘要断言论文每一项历史结论。现代精确日历互校没有在本轮全部重做，不宣称由152组余数算合就解决了汉初行历、太初颁历与三统历的所有争论。

表旁已经列成帝建始四年的年号，自然不是司马迁在太初改历时逐年实记到未来。唐《索隐》在太始、征和以下年次处归给褚先生续；《正义》对尾部“小余”释义等又疑后加，三家注转录作“恐褚先生沒後人所加”，四库转录作“恐褚先生及後人所加”，两种原字及断读见[逐段互校](../记录/史记-卷026-逐段互校.md)；四库卷后《考证》臣照则辨历元托始，认为后人续衍并连是否褚少孙之笔也存疑。它们判断的对象、范围和信心并不相同：不能简单宣布“全表确定由褚少孙一次写完”，也不能反过来仅由后附年号否认全部原有数术可能更早。

<a id="文本层次"></a>
### 原文、古注、后补与现代排版分别保留

本轮以仓库完整TXT为转录底本，逐字保留11段总叙、重复的历术标题、表前说明、76逻辑行、尾注及述赞；原始全史TXT不修改。纯正文固定版、三家注和四库本是互校见证，不是任选一个网页就证明传写绝无问题。具体异字和尾注释义见[逐段互校](../记录/史记-卷026-逐段互校.md)；四库所见个别数值不能因版本较古就免于复算，也不反改原底本。

“右历书：大余者，日也。小余者，月也……”的尾注须与运算所见的日余分解释分层；古注自己已怀疑这一段的后加性质，不能据“小余者月也”就把小余解释成几个月。现代“评论”标签保留为TXT编排标识，不冒充司马迁正文。卷末《索隐述赞》为唐代司马贞论赞，既非汉代实录，也不能拿它补定黄帝、容成的活动年份。

本次只将有新增史事的北畤、改历参与等补入既有年页，其余同事增加来源说明；上古归既有时期页。不按76个表行创建76条重复“改历”，不将算法展演另立为第二套逐年历史正文。

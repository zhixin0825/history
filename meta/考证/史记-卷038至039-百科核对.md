## 内容

### 百科核对的用途与边界

本轮实际打开百度百科和中文维基百科的宋国、晋世家、宋景公、晋出公、晋静公、宋剔成君、微仲等条目，检查有关叙事、君表及所列注释。百科同一页、同一站的表格与正文也会混用不同年链，不能整表照录。下列“百科所见”只记录本次页面内容；网页随后可能更改。正式叙述仍以各项可复查的原典及已有考证为依据，不把年表、世家、经传的矛盾一律解释为承位与次年改元之差。

本轮直接核读的是仓内卷038、039存量TXT逐行读本、三家注、卷014与015相关年行、《左传》相应年条，以及既有卷015考证和所需互见段落。百科列举的杨宽、杨伯峻、白光琦、夏含夷等研究，本轮未因此取得各书或论文全文；未将百科转述冒称为已经核读原著的结论。

### 宋国：早期君年、泓之战与晚宋年链

| 问题 | 百科所见 | 原典核对与本轮处理 |
|---|---|---|
| 微子与微仲的关系 | B6列微仲为微子之弟，同时提到《汉书·古今人表》“启子”的异说；W7还加入微子后人为周人质、因而不能继位的解释。 | [卷038主文及三家注](../../sources/史记三家注/卷038.md#p22)明记微子卒后立弟衍，微仲卒后其子稽立，古注另引《礼记》《家语》。本轮可据此讲明所用世系，不能追加本卷所无的人质因果。尚未直接核读《汉书》该表，故“启子说”只登记为百科提示的待核异说，不宣称已解决；上古各君不据百科补造精确公元年。 |
| 宋釐、惠、哀、戴的衔接 | B1君表采用惠公卒前800年、戴公至前766年的年链。 | [卷014前841年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0841)为宋釐公十八年，卷038却将共和系于十七年。[前800年表](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0800)记惠三十一年卒，世家则用惠三十年卒、哀公元年卒；按惠元年前830推算，会形成前801、800两年先后去世的另一链。不能既取表的惠卒800，又凭世家短君年另造同一链上未经说明的哀公元年；戴元年前799与其后可核年点须分别交代。 |
| 宋殇公年次 | 百科常直接给出前719—710年的起讫。 | [卷014前719年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0719)为殇公元年；[前710年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0710)已记庄公元年，承位与表内起算有同年重合。世家在殇九年连记鲁隐公被杀，与经传前712年不合，不能把鲁隐公之死再移到前711年。具体战事仍各归已有经传年页。 |
| 泓之战与宋襄公之死 | B1、W1将泓之战置前638年；有关伤后死亡的概述容易读成同年。 | [前638年经传](../../sources/春秋左传/有标点原文/bce-0638.md)记十一月己巳朔败于泓、襄公伤股；[前637年](../../sources/春秋左传/有标点原文/bce-0637.md)五月庚寅才记宋公兹父卒，并追叙泓伤。两件事分年，不将死亡提前到战斗当年；月日保留古历，不换算成未经历算的公历日期。 |
| 宋灭曹与景公君年 | B3同段把“景公三十年”和“三十七年”都括成前480年；W2又将前487、480年分别称景公二十七、三十五年。 | 按景元年前516年，三十年为前487、三十七年为前480。[前487年经传](../../sources/春秋左传/有标点原文/bce-0487.md)支持灭曹年点。三十七年的荧惑故事不能因此合并为灭曹之年；世家该段兼叙楚灭陈又与经传[前478年](../../sources/春秋左传/有标点原文/bce-0478.md)不合，须拆开说明。灾异占说保留叙事性质，不据道德应验断定天文实测。 |
| 景公卒年、昭公继立 | W1表并列景公47、64、66年及昭公47、65年等方案；B1列景公前516—453、昭公前452—404共49年。W2把公孙得写成已定太子。 | [卷038三家注](../../sources/史记三家注/卷038.md#p54)已指出主文“攻杀太子”与《左传》不同；[前469年经传](../../sources/春秋左传/有标点原文/bce-0469.md)记得、启养于公宫而“未有立焉”，景公卒后大尹立启、六卿逐大尹而立得。叙事按这一直接年条展开；世家景64年、[年表前451年卒条](../../sources/摘录/史记-卷015-六国年表.md#y0451)及其后昭公年数留作实质分歧，不虚构三次死亡或继位。 |
| 悼、休、辟、剔成的君次和年数 | W1表列多套研究方案，W6信息框采用剔成前369—329年，正文却另说前356—350年间篡位及在位27年。 | [卷038三家注](../../sources/史记三家注/卷038.md#p55)已载悼八年／《纪年》十八年，辟公／桓侯璧兵，以及主文父死子继／《纪年》易城盱废君自立的差异。前372年“宋辟公元年”、前369年“宋剔成元年”继续按[既有卷015说明](史记-卷015-前0376至0367纪年补核.md#晋鲁宋)留异说，不将不同方案拼成一条无缝父子世系，也不在两个年份各写一次已定继位。 |
| 偃夺位、称王与宋亡 | W1正文把偃夺位写在前318年；其君表和B1又用前328年元年、前318年称王。B1并列偃前328—286共43年及前328—282共47年的算法。 | [年表前328年](../../sources/摘录/史记-卷015-六国年表.md#y0328)记宋君偃元年，[前318年](../../sources/摘录/史记-卷015-六国年表.md#y0318)记称王，[前286年](../../sources/摘录/史记-卷015-六国年表.md#y0286)记齐灭宋及宋王死于魏温；世家47年与集解所标年表43年不同。既有前286年终局保留，偃在位数与末段具体死法、分地叙法分别入注，不凭47年算术另造前282年第二次宋亡。 |

正考父与《商颂》另有并非现代百科才发现的时间冲突：[卷末太史公论及索隐](../../sources/史记三家注/卷038.md#p57)把“襄公时正考父作颂”的说法与“正考父佐戴、武、宣，早襄公约百年”相对照，并区别“得商颂”与“作商颂”。读本须保留太史公褒贬的实际意思，同时揭明古注已指出的错置，不在宋襄公年页增造正考父作颂的史事。本轮这里直接读到的是索隐的引述，并未以此冒称通读《毛诗序》《国语》。

### 晋国：曲沃代晋、春秋年点与末代晋君

|---|---|---|
| 靖、釐、献、穆的早期君年 | B2君表用釐侯前840—823年；W5末表列前841—823年，而正文仍用釐十四年周宣初立、十八年卒。 | [卷014前841年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0841)为靖侯十八年，[前840年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0840)为釐元年；世家却用靖十七年共和。应分别注明承位、表内元年及共和记年异数。表中釐十四年前827、献元年前822、穆元年前811是本轮实际核到的年格，不倒用百科起年覆盖原文。 |

| 厉、悼、平的相邻年事 | 君年换算不足以保证一段内所有事都同年。 | 依经传分清前574年诛三郤与前573年厉公遇弑；[卷014前572年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0572)才列悼公元年。悼十四年前559年的秦役，世家称“大败秦军”，[当年《左传》](../../sources/春秋左传/有标点原文/bce-0559.md)却叙无功而还，这是战果冲突。平元年为[前557年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0557)，围临淄则在[前555年](../../sources/春秋左传/有标点原文/bce-0555.md)，不能机械从世家“元年”另造提前两年的同一场围齐。 |
| 出公十七、十八、二十三年及哀／懿公 | B5、W4采用出公前474—452年的23年链，但仍保留十七年分地叙事；其不同政治过程不能直接拼合。 | [卷039三家注](../../sources/史记三家注/卷039.md#p133)已并列出公十七年主文、年表十八年、或二十年、《纪年》二十三年，并列哀公、懿公、敬公、忌与骄及其亲属差异。原表君年与出奔、智氏拥立、三家分智地各有不同来源，不把诸说压为一位姓名世系全部确定的君主，也不靠加减六年宣称所有事件已校齐。 |
| 三家分晋与晋国终局 | B2概述把前403年三家受命接成晋国灭亡；B4同段将静公元年标前356、二年标前376；W3则并列前356—349与《通鉴》前378—376的两套说法。 | 前453年分智氏地、前403年三家获周命、前376年废晋是不同阶段。世家[静公二年段及索隐](../../sources/史记三家注/卷039.md#p141)已指出同时列举魏武侯、韩哀侯、赵敬侯的卒年不合。延续[前376年废晋](../../years/bce-0400-0301/bce-0376.md)、[前359年端氏安置](../../years/bce-0400-0301/bce-0359.md)、[前349年迁屯留](../../years/bce-0400-0301/bce-0349.md)的既有分层说明；不把每次安置写成再次亡国，不将“绝不祀”扩大成所有晋公族同时被杀。静公俱酒、孝／桓公等末代君次仍保留来源差异。 |

前349年“韩姬／韩玘弑其君悼公”另有身份未决问题。B4提及将其联系晋静公的意见，不能据此认定；已核的[卷015前366—347年考证](史记-卷015-前0366至0347纪年补核.md#韩君)明确记下《韩世家·索隐》所引王邵“不知何君”的边界，本轮不取消该说明。

### 两种本地见证的完整性

卷038存量TXT去掉卷首标记后有59个非空正文单位，含58段世家正文及太史公论、1段索隐述赞；三家注对应 `p0` 至 `p58`。本轮未发现整段主文缺失，夹注与索隐述赞均按其文本层次处理。

卷039存量TXT除卷首和分君标签外有142个非空单位，三家注为 `p0` 至 `p143`，共144段。这一数量差不能直接解释为漏两段：三家注有合段、分段差异。已确认缺失的完整主文是 [p12“鄂侯二年，鲁隐公初立”](../../sources/史记三家注/卷039.md#p12)，须以三家注的独立来源补入阅读去向，不改写存量TXT原字节。

另核到卷039存量原文的局部脱讹：[原行L3481](../../sources/本地分卷/史记/史记-卷039.md#L3481)“子胛桓叔”，三家注[p11](../../sources/史记三家注/卷039.md#p11)作“子鱓……代桓叔”；[原行L3492](../../sources/本地分卷/史记/史记-卷039.md#L3492)“曲沃武公伐，灭之”缺宾语，三家注[p18](../../sources/史记三家注/卷039.md#p18)有“晋侯缗”；[原行L3494](../../sources/本地分卷/史记/史记-卷039.md#L3494)段首“者，始封曲沃”脱主语，三家注[p20](../../sources/史记三家注/卷039.md#p20)有“桓叔者”。读本据完整见证释明，原始引文保留各本差异；百科转录与存量TXT共有的脱讹不能算另一个独立证据。

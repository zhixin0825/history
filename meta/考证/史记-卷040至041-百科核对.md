## 内容

### 实际阅读范围与使用边界

本轮直接读完卷040存量TXT逐行读本的 L3637—L3738、三家注 p0—p101，以及卷041存量TXT逐行读本的 L3739—L3767、三家注 p0—p27；将两种本地见证逐段对照，另核卷014楚栏有关年行、卷015有关楚齐韩年格、《左传》相应年条、《通鉴》卷002的楚越段，以及既有年度正文和卷014、015考证。卷071只核了整书中甘茂亡秦奔齐至范蜎说楚王的相邻原行，卷114只核了无诸、摇的开头一段；《韩非子·内储说下六微》只核了干象劝楚王不要以甘茂相秦的一段，未因此声称这些篇卷已经整卷完成。

实际打开的百科页面为下列 B1—B4、W1—W8。页内君表、概要、叙事和引用也可能互相矛盾；下表记的是本次访问所见，不把百科当作覆盖原典的裁定本。百科所列杨宽、曹锦炎、童书业等研究，未因页面列出书目便算本轮读过；尤其杨宽1991年《关于越国灭亡年代的再商讨》未取得全文，不将百科脚注的转述冒称核读原论文。

### 楚：早期年链与春秋事件

|---|---|---|
| 楚越先祖及绝对起年 | W1把鬻熊以下早君留为未确年；B1却将夏代越国开国写成精确的前2032年。 | [卷040开头](../../sources/史记三家注/卷040.md#p0)载颛顼、重黎、吴回、陆终等祖先传说，且明说其后世次不能尽记；[卷041开头](../../sources/史记三家注/卷041.md#p0)述禹后、少康庶子受封。这些传说可完整说明，不据现代百科补造公元年、父子出生年或历代连续在位表。楚熊渠之子“越章王”也不能仅凭越字就等同勾践所属越国。 |
| 熊勇六／七年与早楚君年 | W1正文沿世家写熊勇六年前841年，君表却用前847—838十年。 | [卷014前841年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0841)为熊勇七年，[卷040](../../sources/史记三家注/卷040.md#p7)为六年；同篇勇十年卒与下一君表元年也受这一年差影响。按表年次，熊严十年为前828、熊霜六年为前822、熊徇二十二年为前800、熊咢九年为前791，后继元年分别在下一年。可以交代换算依据，不能说六与七只是同一数字的两种写法，更不能把勇的两条年链拼成一次毫无分歧的确年死亡。 |
| 文王十三年卒、堵敖五年与另一年链 | W1君表用文王前689—675十五年、堵敖前674—672三年。 | [世家文王十三年、杜敖五年](../../sources/史记三家注/卷040.md#p16)与年表旧链相合，却同[前675年《左传》](../../sources/春秋左传/有标点原文/bce-0675.md)详记楚文王败巴、伐黄、六月庚申卒不合。本站已有[前676年说明](../../years/bce-0700-0601/bce-0676.md#sj014-0676-zhou-chu-note)，主述保留前675年终局；不能在前677先写死文王，再让他在前675出征，也不能将堵敖两个起点分别写成两次即位。 |
| 成王三十九年与取谷、灭夔、城濮 | 百科概述不够细，单靠君年换算会把相邻年史事连成一年。 | [世家p22](../../sources/史记三家注/卷040.md#p22)在三十九年连叙鲁请师、伐齐置雍、灭夔，然而[前634年《左传》](../../sources/春秋左传/有标点原文/bce-0634.md)已有这些事情；其后[p23城濮](../../sources/史记三家注/卷040.md#p23)则在[前632年](../../sources/春秋左传/有标点原文/bce-0632.md)。同理，[前638年泓战](../../sources/春秋左传/有标点原文/bce-0638.md)与[前637年宋襄公卒](../../sources/春秋左传/有标点原文/bce-0637.md)不能因世家一句“遂病创死”合年。 |
| 围郑“三月克之”与先围十七日 | 作者在合并前提出月名／时长疑问，本项追加核了古代注疏，不是据百科作断。 | [世家p30](../../sources/史记三家注/卷040.md#p30)作春围郑、三月克之；[前597年《左传》](../../sources/春秋左传/有标点原文/bce-0597.md#t001)先记围十七日，随后退师、郑修城、再围，才接三月克之。追加核读的孔疏明确说明杜预将“三月”释为再围时长，又据六月晋援军到河才闻郑败，论其并非季春月名。因此不能用“旬有七日”宣布三月必指三月份；也不把十七日说成完整围期。孔疏估算总约一百二十日仍是古注推算，不据此另定确切破城月日。具体访问与核读范围列下文P1。 |
| 围宋“五月”与鄢陵子反之死 | 通俗概述易把围宋时长、获释谈判和自杀／被杀化成一条简单故事。 | [前595年《左传》](../../sources/春秋左传/有标点原文/bce-0595.md)记九月开始围宋，[前594年](../../sources/春秋左传/有标点原文/bce-0594.md)记五月和议；年表本年楚栏也是“围宋。五月，华元告子反以诚”。[世家p31](../../sources/史记三家注/卷040.md#p31)的“围宋五月”不能无说明地讲成仅围五个月；华元夜见子反与世家直接归于庄王的赞语分开标明来源。[p33](../../sources/史记三家注/卷040.md#p33)称共王射杀醉酒子反，与经传的具体过程须并列，不以一种死法悄悄改写另一种原文。 |
| 章华台、灵王灭陈与乾谿问鼎 | W1给灵王十二年起讫，不能据此保证每件事的年数无误。 | [前535年《左传》](../../sources/春秋左传/有标点原文/bce-0535.md)已经记“楚子成章华之台”，而[世家p38](../../sources/史记三家注/卷040.md#p38)系灵王七年，按表为前534；[p39](../../sources/史记三家注/卷040.md#p39)灵王八年灭陈，按表为前533，经传及年表则在[前534年](../../sources/春秋左传/有标点原文/bce-0534.md)。[p40的索隐、正义](../../sources/史记三家注/卷040.md#p40)又已明确指出：求鼎、求许田的答话在《左传》属于子革，主文作析父是人物错置。 |
| 灵王死日、平王夺位与秦女 | 古月日及相邻君年的差异不能全归为承位、改元之别。 | [p43](../../sources/史记三家注/卷040.md#p43)正文为夏五月癸丑，正义引《左传》为癸亥；[前529年经传](../../sources/春秋左传/有标点原文/bce-0529.md)记申亥家自缢，与世家所叙饥困终局仍须分层。[p48平王二年娶秦女](../../sources/史记三家注/卷040.md#p48)按表为前527，而[前523年经传](../../sources/春秋左传/有标点原文/bce-0523.md)记秦夫人至、建居城父；诛伍奢及伍尚则在[前522年](../../sources/春秋左传/有标点原文/bce-0522.md)，不能一并落在世家“六年”之下。 |
| 昭王时期的吴楚事件与死亡 | W1君表取前489年秋七月；B3、W5都把前489年说成惠王承位年，但君年实际从前488起算。 | [p54索隐](../../sources/史记三家注/卷040.md#p54)指出正文“三公子”并不准确；[前512年经传](../../sources/春秋左传/有标点原文/bce-0512.md#all-20261109-t004)实记吴使徐执掩余、使钟吾执烛庸，二公子再奔楚。注本现存“二父公”字序及“钟离”地名另存，不把“二父公”当成第三个人名。[p59](../../sources/史记三家注/卷040.md#p59)将灭顿、灭胡连记在昭王二十年，经传实际分[前496年](../../sources/春秋左传/有标点原文/bce-0496.md)与[前495年](../../sources/春秋左传/有标点原文/bce-0495.md)；阖闾败死在前496年，不能按下句昭王二十一年另移前495。[p60—61](../../sources/史记三家注/卷040.md#p60)先记十月病、再记庚寅卒，经传却明确为[前489年秋七月庚寅](../../sources/春秋左传/有标点原文/bce-0489.md)。 |
| 白公之乱与灭陈 | B3正文、W5分别列前479年白公之乱、前478年灭陈；但B3概要又称惠王八年、前481年发生白公之乱，同页不一致。 | [p62](../../sources/史记三家注/卷040.md#p62)八年救郑后连叙白公劫王，末句“是岁灭陈”集解又标“惠王之十年”。[卷014前479年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0479)虽记惠王十年白公乱，也把陈亡放在该年；[前479年《左传》](../../sources/春秋左传/有标点原文/bce-0479.md)与[前478年《左传》](../../sources/春秋左传/有标点原文/bce-0478.md)才分清乱与灭陈。集解改为十年仍不等于与经传完全一致。负王者“屈固／圉公阳”、白公“攻杀／奔山缢”也各保留出处。 |

### 楚：战国君称、怀王后半与楚亡

| 问题 | 百科所见或核对线索 | 原典核对与编写边界 |
|---|---|---|
| 简王八年“三晋始列诸侯” | W1简王前431—408年的君表，使八年直接落前424；这一说法不能同时等于前403年周命三晋。 | [世家p65](../../sources/史记三家注/卷040.md#p65)原文与[前403年年表](../../sources/摘录/史记-卷015-六国年表.md#y0403)、[既有三家受命正文](../../years/bce-0500-0401/bce-0403.md)存在实质差异。三家分地、世家所称列侯、周王正式册命不能凭相近表述强合；不在前424年另造一次已经确定的同一册命。 |
| 怀王即位与元年 | B2信息框在位前329—299，W6信息框前328—299，正文又同记前329年威王卒、怀王承位。 | [p71—72](../../sources/史记三家注/卷040.md#p71)本就先记威王十一年卒，再起怀王元年。前329承位、前328起元年在此可以区分；这不构成把其他所有两年差、君名错置也如此解释的理由。 |
| 合纵时的苏秦与齐王称号 | W6概述采用前318年合纵、前313年欺楚等常用年点。 | [p75](../../sources/史记三家注/卷040.md#p75)以苏秦领衔，并在怀王十二年称齐湣王；[p81](../../sources/史记三家注/卷040.md#p81)来书也称湣王。本站已经采用齐威王前320年卒、齐宣王前301年卒的[校订年链](史记-卷015-前0326至0287纪年补核.md)，苏秦早晚行年也有[既有讨论](史记-卷015-前0346至0327纪年补核.md)。沿用所取编年与人物时，原称号、归属仍照录，不把尚未在位的齐湣王无注释地放回这些年份。 |
| 怀王二十／二十六年与宜阳、武遂 | B2将前306年列为怀王二十三年破越；W3、W4借昭雎说辞支持相同年代。 | [原行L3718](../../sources/本地分卷/史记/史记-卷040.md#L3718)作“二十［六］年”，[注本p81](../../sources/史记三家注/卷040.md#p81)作二十年，索隐讨论衍六字；紧接[p82集解](../../sources/史记三家注/卷040.md#p82)又明确说秦拔宜阳、取武遂在怀二十二年，归武遂在二十三年，因此昭雎说辞非二十年事。不能只删六字就宣布全段已校齐。说辞中的“东取地于越”是已发生行动的回顾，本身没有给无疆死亡的确日确年。 |
| 亡国阶段、负刍与项燕 | W1末表列前223年负刍终局，随后另列昌平君；只抄最后一任会遮蔽各篇的战事差异。 | [p98—99](../../sources/史记三家注/卷040.md#p98)分负刍四年王翦败楚杀项燕、五年虏负刍；《秦始皇本纪》对俘王、昌平君、项燕死的次序另有叙法。沿[既有前224年与前223年分层](史记-卷015-前0246至0207纪年补核.md)处理，不在相邻两年各杀一次项燕，也不因一句省文另造一次俘负刍。前222年对江南、越地的推进并非又一次同名楚亡。 |

### 越：吴越战争、越王世系与范蠡故事

| 问题 | 百科所见或核对线索 | 原典核对与编写边界 |
|---|---|---|
| 檇李、夫椒及勾践元年 | B4、W7以元年前496、三年前494叙两场战事；W2写阖闾伤重死于姑苏。 | [卷041p1—2](../../sources/史记三家注/卷041.md#p1)与[前496年《左传》](../../sources/春秋左传/有标点原文/bce-0496.md)、[前494年《左传》](../../sources/春秋左传/有标点原文/bce-0494.md)互核。经传另记灵姑浮以戈伤阖闾足、还卒于距檇李七里的陉，不能直接采用百科的姑苏死地，更不能将卷040昭王二十一年的误差传给这一场战事。 |

| 艾陵、伍子胥死与黄池 | B4、W7把艾陵及伍子胥死置前484，黄池置前482；世家以“归七年、居二年、居三年、明年”连续叙述。 | [p7索隐](../../sources/史记三家注/卷041.md#p7)直接标艾陵为鲁哀十一年，即前484；[p9索隐](../../sources/史记三家注/卷041.md#p9)标黄池为哀十三年，即前482。两处确年之间容不下从同一节点机械累加居三年再明年的算法；[前484年经传](../../sources/春秋左传/有标点原文/bce-0484.md)、[前482年经传](../../sources/春秋左传/有标点原文/bce-0482.md)须分别接回。黄池主力在外、越袭吴、吴太子死、保密与再和议各有实际内容，不能仅留年数说明。 |

### 无疆败亡：四组资料不能强合为一个无争议年份

B1采用前333年楚破越；B2、W3、W4采用前306年怀王破越。W2正文又把无疆继立放在前354，而W3信息框写前342—306，正文称三十六年；同站已有不同起点。W2的前306年叙述还直接接“在徐州击败齐国”，W4则把游说国君改作齐宣王。它们反映不同年代方案及概述拼接，不能作为已经校齐楚威王、怀王与齐威王、宣王的证明。

| 证据层 | 实际可核内容 | 可作的判断与不可越过的边界 |
|---|---|---|
| 卷041主文及卷040互见 | [卷041p14—15](../../sources/史记三家注/卷041.md#p14)明确称楚威王、齐威王，叙越转攻楚、无疆被杀、楚取吴地、北破齐徐州、越公族分立；[卷040p70](../../sources/史记三家注/卷040.md#p70)威王七年徐州战，集解还说当时楚已灭越而伐齐。 | 这是一条把破越与威王伐齐相连的传世叙事。无疆之死、取地和公族分散须说明，不能把主文两位威王默改为怀王、宣王，再称原文就是如此。 |

### 追加的原典释义核读

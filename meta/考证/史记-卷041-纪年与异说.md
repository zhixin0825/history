<a id="会稽与归国"></a>
### 二、槜李、会稽与“二岁而吴归蠡”

勾践元年槜李之战由[索隐p1](../../sources/史记三家注/卷041.md#p1)明确联到鲁定公十四年，即[前496年](../../years/bce-0500-0401/bce-0496.md#note-4)。先世禹裔、少康庶子守会稽与“二十余世”是登场前的传承叙述，不能倒算建国年。主文说射伤阖庐，经传记灵姑浮以戈伤足；正文采用既有经传战场过程，同号注保存武器与伤处差异，不连写成两次先后受伤。允常卒和勾践承位是战前接续，原文未提供另一个可以独立定日的卒年。

勾践三年接[前494年夫椒、会稽](../../years/bce-0500-0401/bce-0494.md#note-3)。范蠡战前进谏、文种两次求和、勾践欲杀妻儿焚宝死战而被劝止，均为本事实质，不能删成一句“越降吴”，也不能把被劝止的计划写成已经实施。文种举汤、文王、重耳、小白的故事是此次对话中的历史比喻，不能把这些前代人物都编在本年。

[归国段](../../sources/本地分卷/史记/史记-卷041.md#L3745)实际记置胆、仰胆、尝胆，没有卧薪。范蠡自陈善兵而不如文种治国，随后“范蠡与大夫柘稽行成为质于吴。二岁而吴归蠡”；句法上被放回的是范蠡，不是勾践。故将节用养民、内政军事分工和质吴写入[和议后的阶段正文](../../years/bce-0500-0401/bce-0494.md#sj041-event-9)，说明持续多年而非当年全部完成，不由“两岁”另造勾践服吴两年或前492确定返国事件。

伍员一度想自杀而吴王阻止、夫差早年曾许半国而伍员不受，都是本篇有而简写容易遗漏的转折，已进入白话及前484实际正文。谗辞关于伍员怨君、将乱的指控，不当作已证实的谋反。其“后三年吴其墟”是人物警告；实际吴亡在前473，不能把预警当作精确预言应验。世家“虏齐高、国”与索隐所认高昭、国惠，也不能压过经传对艾陵参战者国书、高无的明文。

黄池期间，本篇说春季及“遂杀吴太子”；[经传六月袭吴](../../sources/春秋左传/有标点原文/bce-0482.md#all-20261109-t003)说获太子友。正文保留六月进兵与被俘，不把两书合写成同日先俘后杀。习流二千、教士四万、君子六千、诸御千人保存原称和数字；古注对习流、君子的解释并不唯一，不能强转为现代兵种编制。

<a id="灭吴与伯嚭"></a>
### 四、灭吴、伯嚭之死与称霸的时间层次

[前473经传](../../sources/春秋左传/有标点原文/bce-0473.md#all-20261109-t002)为冬十一月丁卯越灭吴，夫差拒绝甬东安置而缢。本篇还有公孙雄袒胸膝行、勾践不忍、范蠡催兵、蔽面无颜见伍员与安葬的叙事，已并入同一条，未重造第二次灭吴。“谋之二十二年”从前494会稽至前473包首尾正有二十二个年位，不等于总在位年、服吴年数或围城年数。

本篇接记诛伯嚭；然而[前471经传](../../sources/春秋左传/有标点原文/bce-0471.md#all-20261109-t004)仍写季孙通过大宰嚭向越方纳赂、阻止婚姻安排。这里至少存在人物结局或材料层次的冲突。正文不把前473处死列为无争议事实，同号保留原句与矛盾，也不凭空制造另一个同名伯嚭来消解。

渡淮会齐晋、贡周、受周元王胙与命伯，以及归还宋地、给楚淮上地、给鲁泗东方百里，属于灭吴后的活动，暂附[前473第3组](../../years/bce-0500-0401/bce-0473.md#sj041-note-3)，不等同于吴亡当日。徐州地望不得仅凭今名套定。太史公所论禹、勾践、范蠡入同号注，为汉代评价；它不证明称霸仪礼与后半范蠡故事全部发生在一个年份。

<a id="越君年链"></a>
### 五、勾践卒与后继越君：有条件归年，不隐去计算前提

[索隐p13](../../sources/史记三家注/卷041.md#p13)明确引“晋出公十年十一月”勾践卒。本站[前474年表](../../sources/摘录/史记-卷015-六国年表.md#y0474)列晋出公元年，故474−9＝465，将勾践卒、鼫与承位暂系[前465](../../years/bce-0500-0401/bce-0465.md#sj041-note-2)。前464是另一同步链的结果，不能在沿474起元时又直接搬入464，或将两年各作一次死亡。

接续假设为后继君次年起元：鹿郢／鼫与前464至459六年，不寿前458至449十年，朱勾／翁前448至412三十七年，翳前411至376三十六年。因此这些主文卒立分别实际进入[前459](../../years/bce-0500-0401/bce-0459.md#sj041-note-1)、[前449](../../years/bce-0500-0401/bce-0449.md#sj041-note-4)、[前412](../../years/bce-0500-0401/bce-0412.md#sj041-note-3)与[前376](../../years/bce-0400-0301/bce-0376.md#sj041-note-5)，每组正文说明“暂系”。这是据古注年数和已选起点连推，并非每年都有第二份独立的绝对日期。

前376组保留七月诸咎弑翳、十月诸咎又被杀、吴人立错枝。原主文直接把翳与之侯接为父子承位，古注却多出中间君位和“明年”寺区立无余之，索隐才推认之侯即无余之。无余之后段究竟以承位当年还是次年起元，又分成两条；不能沿前半链一路无说明硬推至无疆。全部关系、相对年数及两种后段算式见[王年与世系核对](../记录/史记-卷041-王年与世系核对.md#后继越君)。

[王国维《古本竹书纪年辑校》](../../sources/补充古籍/阅读本/古本竹書紀年輯校.md#L815)在勾践卒及[翳被弑](../../sources/补充古籍/阅读本/古本竹書紀年輯校.md#L919)等条，明标取自《越世家》索隐。它是后世辑校本，不是此处新增一份与索隐完全独立的出土原简。其[L817](../../sources/补充古籍/阅读本/古本竹書紀年輯校.md#L817)另以鲁哀二十六年配晋出公十年，按本站鲁年为前469；这项同步不支持本轮沿晋出公元474得到的465，故两链分列，不能只摘相同年数字句便称互证。寺区弟在仓内三家注作“忠”，[辑校作“思”](../../sources/补充古籍/阅读本/古本竹書紀年輯校.md#L958)；无疆为无颛之弟，索隐用“盖”字，是推测，不得去掉语气变为确定谱系。

<a id="楚越之战"></a>
### 六、楚破越与徐州：前334、333、323、306的证据不能混用

主文[北伐齐、西伐楚及齐使说辞](../../sources/本地分卷/史记/史记-卷041.md#L3754)以齐威王、楚威王为背景，随后[败越段](../../sources/本地分卷/史记/史记-卷041.md#L3755)一气连写楚败越、杀无疆、取旧吴地至浙江、北破齐于徐州和越各宗族分散。这一长句内部不自带公元年，也不保证各事同年完成。

| 年份或体系 | 实际所据 | 本轮处理 |
|---|---|---|
| 前334 | [《通鉴》卷二L433](../../sources/本地分卷/资治通鉴/资治通鉴-卷002.md#L433)起周显王三十五年，[L441—451](../../sources/本地分卷/资治通鉴/资治通鉴-卷002.md#L441)接越转攻楚、被败、楚取故吴地至浙江、越散诸族朝楚 | [前334第6组](../../years/bce-0400-0301/bce-0334.md#sj041-note-6)作为现用编年传统下的暂系点；通鉴此处并未明写杀无疆，死亡仍另存争议 |
| 前333 | [《通鉴》L452](../../sources/本地分卷/资治通鉴/资治通鉴-卷002.md#L452)另起三十六年楚围徐州 | 本篇“北破齐于徐州”拆入[前333已有齐楚战第2组](../../years/bce-0400-0301/bce-0333.md#note-2)，不因句子相连就把前334、333并成一个年 |
| 前323 | [集解p15](../../sources/史记三家注/卷041.md#p15)徐广明作“周显王之四十六年” | 按所用周年即前323，与楚威王身份不合；原文保存，不悄改“四十六”为“三十六”来凑齐 |
| 楚怀王阶段，近现代常有前306说 | [甘茂列传原整书L5039](../../sources/二十四史/txt/01_shiji_full.txt#L5039)为怀王与秦新合婚后，范蜎追说先前用召滑于越、越乱而楚郡江东；[《韩非子》L243—249](../../sources/补充古籍/阅读本/韓非子-內儲說下六微.md#L243)同类问答称邵滑赴越五年而能亡越 | 提供怀王阶段楚越关系的相对证据，不能仅凭这两段直推出无疆确于306被杀；本轮不在306再编一次确定无疆死亡 |

索隐p15还说明，其所见《纪年》在无颛薨后十年记楚伐徐州，**没有楚败越、杀无疆之语**。不能引用索隐却反称《纪年》已经独立证成无疆死于徐州之战。若把本卷后继君年链推至无颛卒，再加十年，与现用徐州前333链不能完全吻合，这正是不能将诸书君年拼成唯一表的理由之一。

《甘茂列传》段次应据实际原文核验：[L5038](../../sources/二十四史/txt/01_shiji_full.txt#L5038)先写甘茂亡秦奔齐，L5039才接齐使甘茂于楚、怀王问相秦及范蜎之言；不能把引语放到甘茂出奔以前，再据错误的叙事先后定一个唯一界年。这里“前尝”只有先前的相对义，《韩非子》的“五年”也不是明载无疆的王年。《韩非子》说话者为干象，《史记》为范蜎，召滑／邵滑的字形也各守来源。

齐使与越王的长篇问答已完整释读：韩、魏怕覆军失将使边邑受危；越希望它们只集兵牵制楚；齐使反称楚已分兵，何必再等，并以“知二五而不知十”指责越王不能由已有情势作出结论；粮食、木材产地被截断的主张才是最终攻楚理由。说辞中的军数、三千七百里、地名与归属都不能当作已独立核实的战场统计。复讎、竟泽陵等疑字，按索隐犨、竟陵泽理解，原引不改；古注不同地理解释也不强合成一幅精确现代地图。

### 七、范蠡后半生与楚救子故事有实际正文，但没有伪造确年

[春秋末与战国初时期页](../../years/bce-0500-0401/未定年-春秋末与战国初.md)承接前473灭吴以后，按相对先后完整叙述范蠡离越、文种之死、相齐而辞相、居陶货殖、幼子成年、中子囚楚、长子取金、先杀后赦、父亲的解释与终老。它属于前5世纪相关时期正文，不放在上古目录，也不把勾践后数代直到前4世纪的无疆材料一并拖入范蠡时期。

| 齐相、迁陶与财富 | [P019](../../sources/摘录/史记-卷041-越王勾践世家.md#p019)“居无几何”“居无何”不是年号；逐什一之利为经营收益，不是税率，也不能由三徙、三致富硬算准确寿数 |
| 庄生是不是庄周 | [p19索隐、正义](../../sources/史记三家注/卷041.md#p19)已争论时段；索隐的反问不构成身份实证，正义明言不合。正文称庄生，不给他庄周的生平和学派 |
| 庄生为何收金 | [P022](../../sources/摘录/史记-卷041-越王勾践世家.md#p022)预告事成归还，病故未及交代也要妻子归还；不是和长子共谋瓜分贿金 |
| “羞为儿子所卖” | 指被这个年轻长子轻侮、耍弄，不是庄生被自己的儿子出卖 |
| 三钱之府及汉代例证 | [p22](../../sources/史记三家注/卷041.md#p22)币制解释、集解引汉灵帝时张成候赦，均为后出注释；不编成楚国故事中的汉代制度和人物 |
| 杀与赦的先后 | [P024](../../sources/摘录/史记-卷041-越王勾践世家.md#p024)先论杀中子，次日才赦；并非大赦完全取消，更非全楚囚徒被杀 |
| 父亲之笑 | [P025](../../sources/摘录/史记-卷041-越王勾践世家.md#p025)明确唯朱公独笑，已在实际正文保留；其贫富经历说是人物对择使失败的解释，不转成普遍人性定律 |
| 范蠡卒年与墓地 | [P026及古注](../../sources/史记三家注/卷041.md#p25)只言老死陶，古注又有华容、平阴陶山等说并称未详；不能据之添加前448卒年、精确寿数或现代纪念日 |

<a id="无诸与摇"></a>
### 八、无诸、摇与汉高帝、惠帝的两次册封

本篇[P017](../../sources/摘录/史记-卷041-越王勾践世家.md#p017)“后七世至闽君摇”以下把参加灭秦、汉高帝复立越王与越后合叙，但[《东越列传》开头L6203](../../sources/本地分卷/史记/史记-卷114.md#L6203)明确区分无诸与摇：二人先从诸侯灭秦，再率越人助汉；汉五年复立无诸为闽越王、都东冶，孝惠三年才立摇为东海王、都东瓯。

因此[前202第24组](../../years/bce-0300-0201/bce-0202.md#sj041-note-24)实际写无诸，[前192第4组](../../years/bce-0200-0101/bce-0192.md#note-4)实际写摇。本篇高帝封摇之句在202同号注揭示混称，不在202又造一次确定的摇称王。七世只有概括的传承数字，不能用两次册封的校正去补造七个无据的祖名；秦末参战保留为此前经历，也不因叙在本年就变成封王当年才灭秦。

## 内容

### 见证范围与文本层次

主TXT从全书L4353章标开始，L4354—L4369为P001—P016，L4370为“評論”标签，L4371为太史公论P017，L4372为唐代司马贞《索隐述赞》Z001。[三家注原HTML](../../sources/史记三家注/原始HTML/053.htm)的18个p与上述18个内容段逐一对应；p0没有另立篇首序说。主TXT已收唐赞，因此不是本轮从注本另补一段。原TXT、HTML及逐行MD均不回写；词义取舍在白话中标明，原引仍用原字。

本轮实际通读18段三家注，尤其查文无害、卒史、钱三五、上来以闻、鄂君、贳贷、收槁、王卫尉及论赞异字；这项阅读与字符覆盖核验分别记录。全文古注见[三家注读本](../../sources/史记三家注/卷053.md#text)。

P001—P003是起沛以前的经历，放在前209年萧何参与起事的登场位置补叙。P014是无确年的持家习惯，随前193年病卒条回顾。P016后嗣总叙、P017太史公论与Z001唐赞放在同号注中作身后附读，不把阅读位置当成后人罪免、续封或文章写作的年份。

### 相国置卫、自污与请苑案

**陈豨起兵与韩信案。** P010“汉十一年，陈豨反”是简并起因；陈豨起兵已在前197年的明条，不能在前196又起一次。P010前半并入[前196年韩信案第3组](../../years/bce-0200-0101/bce-0196.md#event-3)，保留朝廷指控、诈召与现代独立证明的区分。后半的相国、增封五千户、五百卒一都尉、召平劝辞让与出私财，本来已在本页侯籍附录叙述，本次升为[连续编号正文](../../years/bce-0200-0101/bce-0196.md#sj053-xiangguo-event)，并非新增第二次任相国。[侯表R015](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r015)九年与本篇、汉传十一年不同，仍采用后者，旧注的异年保留。

**征黥布的十二年秋。** P011与三家注p10均作“汉十二年秋”，百度篇名页和维基人物页也直接沿用这一时间。可是本纪明确十一年秋七月起兵，汉传L7187在韩信案后用“其秋”承接；刘邦已经在十二年四月去世，不能又在该年秋亲征。本轮把自污故事接[前196年征布期间](../../years/bce-0200-0101/bce-0196.md#sj053-self-taint-event)，[前195年](../../years/bce-0200-0101/bce-0195.md#sj053-shanglin-event)接回军后百姓告状、请苑与下狱。故事独立月日仍未知；“十一年秋”是战役的编年背景，不等于已证每一次问候、自污都发生在起兵的同月。原年次不回写为十一年。

**三次疑忌故事的证据身份。** 鲍生、召平、无名宾客分别解释慰劳、置卫和问事的用意，这是传中人物对君臣关系的判断。正文交代这些劝说及萧何的行动，不另造皇帝已经明确下诏监控相国的文书。秦东陵侯召平与高后时的齐相召平，不能只因同名便合一；本卷仅叙可见的秦侯、种瓜与劝萧何事。

**请苑与受贿指控。** P012“毋收槁为禽兽食”，三家注索隐解释“苗子还种田人，留稿入官”。可是本地[《通鉴》L467](../../sources/本地分卷/资治通鉴/资治通鉴-卷012.md#L467)与[L468](../../sources/本地分卷/资治通鉴/资治通鉴-卷012.md#L468)还保存颜师古“不收其槀税也”的相反解释，并引索隐“收槀入官”。完整白话依“毋收”及颜注译为不征禾稿，同时并列索隐的粮归耕者、稿入官说；年度正文只记请开放闲地，不把稿税归属写成定论，也不推为免天下田赋。刘邦指称受商人财物，王卫尉以相国职责和前此掌关中未谋私反驳，案文没有另给经核实的受贿证据。刘邦赦后说拘禁是为示己过，只作为他的说辞，不倒推为预先安排的试探计划。参见[三家注p11](../../sources/史记三家注/卷053.md#p11)、[本篇P012](../../sources/摘录/史记-卷053-萧相国世家.md#p012)。

### 词义、异字与人物

| 位置 | 核对结果与白话口径 |
|---|---|
| P001文无害、主吏掾 | 集解、索隐保留有文而不枉害、公平吏、无比、文理无伤害等解释。采用文书律令与不苛害的意思，保留无比一说；索隐释主吏为功曹。感昴精是纬书神异，不用于编出生。 |
| P002钱三、五；P009赢二 | 主文未写百，李奇及索隐释三百、五百，另引一当百钱说；原数不改，白话说明古注。增邑二千户不是送钱二的法定兑换。 |
| P003常辨之、卒史 | 古注释办事明辨；卒史是郡吏。不是争辩不休，也不是普通士卒。御史问答时援古典论泗水情势的铺陈，在本篇和相关古注找不到依据，不采网络扩写。 |
| P005上来以闻 | 集解释上回来以后报告。不是萧何每次都先到朝廷。来不及请示时先便宜施行，与平时先奏并存。 |
| P008于是乃令萧何 | 主TXT缺“第一”，[汉传L7185](../../sources/本地分卷/汉书/汉书-卷039.md#L7185)有“于是乃令何第一”。白话明列位次，原引不补。带剑履上殿是佩剑、着鞋入殿的礼遇，不能把带字拆成赐锦带。 |
| P008鄂君 | 注本指鄂千秋；侯表作谔千秋，汉表作鄂秋，同一举明萧何功劳者。其“群臣议皆误”不可译成群臣没有错；贬曹参一时功、赞萧何长远功是进言，不是编者独立证明的战争反事实。 |
| P009父子／父母 | 主TXT父子兄弟，汉传父母兄弟，两者照录。获食邑的十余亲属不全被扩大成同等级列侯。 |
| P011贱贳贷 | 正义只释贳为赊并注贷音。依上下文低价赊取、借取而自污，不说成免费贷款惠民；不添具体利率、抵押或还款制度。 |
| P012数千万／数千人 | 主篇写田宅数额数千万，汉传L7188写告事涉及数千人。属于不同记数口径，不能换算，也不把数千万称作人数。 |
| P012王卫尉 | 集解引如淳明确王氏而无名字，只写王姓卫尉。不能据官位推定为王陵等有名人物。 |
| P013不相能与病中问曹参 | 汉帝先问曹参，萧何叩头认可；不改成萧何主动先报姓名。“不相能”指不相投合，不能译成萧何畏惧与曹参比较能力。早年交好、将相时有隙的细节与卷054合读。 |
| P017疾法／疾，奉法／疾秦法 | 主TXT作“因民之疾法”，三家注正文作“因民之疾，奉法顺流与之更始”，汉传L7208有疾秦法。白话依主TXT读顺应百姓厌恶苛法，标明三见证，不将秦或奉字偷偷补回原引。 |
| Z001秦兵、画一、带砺 | 秦兵承关中补兵，不是秦王朝另援汉军。画一回顾制度，带砺回顾封爵誓约；赞者为唐代司马贞，均不另作前193年颁行的政策。 |

### 现代检索的实际阅读及边界

2026年11月12日实际打开并阅读百度百科《萧相国世家》的原文、词句注释、白话译文与赏析部分，检索呈现第78—232行可读，未遇正文阻挡。用于比对的差异是将十二年秋直接换作前195年秋、在通行文本中补第一与秦字等；本轮仍依据仓内本纪、汉传和原见证分别处理，未抄录其译文。

同日实际打开维基百科《萧何》，阅读资料栏、生平、逸话、世系及相关注释，页面显示修订于2026年10月30日。其前202初封、十二年秋征布、鄂君发言的反向翻译、赐锦带及以畏惧比较释不相能，均已回原典核对而未采用。世系仅作寻找汉传、侯表的线索，不据网页图形补造亲缘。百科检索不是本轮归年的独立证据，发表链接均指向仓内原典与古注。

### 尚未消除的原典分歧

侯表九年任相国、本篇十二年秋征布、父子与父母、数千万与数千人、论赞疾法等仍是见证差异，采取可说明的阅读与编年口径，不宣称已经校定原本。“四世”的逐名范围未由本段给出；萧氏后嗣的亲缘、侯年及失侯方式见专门核对，不以汉传续到王莽败的长叙直接限定《史记》这一句的时代。

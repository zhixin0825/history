## 内容

### 见证与文本层次

主TXT卷标L4393，实质正文P001—P030与唐赞Z001对应L4394—L4425；L4423“評論”只是编者标签。注本有26个实际HTML p，不与31个TXT实质段机械等同。p0—p24保留篇本文、集解、索隐、正义，p25为唐司马贞述赞。本次实际完整阅读全部主文和26个p的古注；既有三家注可读转录、原HTML、原TXT及逐行MD均未改写。[主见证](../../sources/本地分卷/史记/史记-卷055.md#text)与[注本](../../sources/史记三家注/卷055.md#text)分别可核，行段映射见[去向表](../记录/史记-卷055-引文去向.md)。

长对话保留原语及完整白话，包括三次圯上约期、鸿门前夜自量、郦食其汤武建议、八难的七次“未能”与第八反问、南宫封雍齿之议、关中形势、招四人及劝吕后、宴见问答与全首楚歌。徐广在p6另引樊哙长谏，主TXT没有全文；它作为异本注引在[前206第2注](../../years/bce-0300-0201/bce-0206.md#note-2)完整译读，未擅入主文。P026已经写出的“马邑下出奇计”“立萧何相国”“从容言天下事甚众”均保留，不因作者随后说“故不著”而删去。

### 人名、语词与神异层

| 读法或异说 | 保留与释读 |
|---|---|
| 五世相韩、韩人、城父 | 五位韩君由张开地、张平两代侍奉；不误为五代家相。索隐城父籍贯、姬姓推说单列为注，不据其一说裁定今日诸地籍贯争议。 |
| 仓海君 | 注有东夷及后世沧海郡联想，不能借汉武帝郡名给秦时人物确定现代国籍。 |
| 直堕履、太公书 | 古注对直字有故意与适值等解；老人试人、化石与天授保留为叙事。现存兵书的作者、年代不由故事题名即可认定。 |
| 道还／遇、申徒／司徒 | 主TXT原还字、申徒照存，释读用相遇及古官司徒，不涂改见证。 |
| 鯫生 | 浅陋儒生与姓氏说都有古注；不为匿名献策者创造姓名。 |
| 借箸、楚唯无彊 | 主释借筷子筹说，古注另释前世明著之事。后句是楚强则复立六国仍会屈楚，不译成希望楚强或六国一定抗楚。 |
| 建成侯吕泽 | 本篇及汉传皆如此称，侯表却以吕泽为周吕、吕释之为建成，吕台在九年另封郦侯。原字不改，正文用亲属、建成侯等中性指代；不能让已见后嗣的吕泽在十一年被默认为无疑在世。 |
| 鸿鴈／鸿鹄 | 主TXT为鸿鴈，注本与汉传为鸿鹄；全歌均译，比较的是文本，不造真实射鸟事件。 |
| 马邑下／下马邑 | 一为城下设奇计，一为出奇计攻下马邑，语义不全相同；未提供足以识别某场战役的日期，暂留时期页。 |
| 太史公“物”、子羽、画像 | 物的古注释精怪、药物，并非现代物质主义用语。子羽丑美在古籍也有不同形貌叙法；作者见画像不等于见张良本人。 |
| 唐赞“进履宜假” | 保留宜假原字，白话交代进履受教的上下文；诗语解释尚有余地，不另造借鞋故事，亦不改赞作史家原论。 |

这组释读依据[三家注全部段](../../sources/史记三家注/卷055.md#text)，其中p0—p2涉及家世、仓海君和受书，p7鯫生，p11箸及楚强，p17—p19四皓，p20马邑、赤松，p24—p25论赞。神异故事与史家态度各保说话主体，未把反问写成科学证据，也未删去它们。

### 本轮未决事项

卒年189与186、太子招请者吕泽／吕释之、景驹是否终见、元年正月／二月、固陵秋／冬、汉传文三／文五，均留原典分歧；马邑具体战役、授书与黄石的绝对年、张良出生与墓址没有足够证据补定。现代百科与两篇专题论文只作核对辅助，实际阅读范围及所用论证见[核对记录](史记-卷055-百科与研究核对.md)，不将现代通说替换原始见证。

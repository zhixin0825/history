## 内容

### 底本与分层

主TXT的七段全部保留原字，分别编为P001—P007。P001含“太史公曰”前后的史料取舍与箕山见闻，在三家注本中分成p1、p2；P005的天道议论在注本分成p5、p6。两处都是段界差异，不能漏掉后半，也不能因“太史公曰”在第一段中间就把前半当作商末当年的事件。[逐行原见证](../../sources/本地分卷/史记/史记-卷061.md#text)、[三家注全文](../../sources/史记三家注/卷061.md#text)均未回写。

注本p0为索隐、正义对“列传”体例的解释，单列N001；p9为唐代司马贞《索隐述赞》，单列Z001。两者主TXT均未收录。本轮保存的是注本实际原段，不能称其为司马迁原赞，也不把唐人释体例编进商末。作者逐段阅读记录与自动字符覆盖结果分开，见[逐段全读](../记录/史记-卷061-逐段全读.json)及[整卷核验](../记录/史记-卷061-整卷核验.json)。

### 唯一集中叙事的归置

P003的让位、归周、叩马、不食周粟与采薇歌是连贯的传世故事，归入既有[商末周初时期页](../../years/上古/06-商末与周初.md#sj061-boyi-shuqi-event)。该条为回读商周更替的另一种记忆，不因编排在页末便说故事发生在熊绎封楚以后。没有证据把二人生年、孤竹君卒年、出走年、叩马日或饿死年落实为公元前某年。

| 问题 | 原典与古注 | 本轮处理 |
|---|---|---|
| 兄弟让国 | 本篇说父欲立叔齐；父死后叔齐让伯夷，伯夷以父命为重而逃，叔齐也逃，国人立中子。 | 逐步保留三次继承选择。中子是另一兄弟，不把它误写成叔齐的孩子；也不凭后出名字补成确切家谱。 |
| 到周时文王是否在世 | 本篇“及至，西伯卒”接武王载木主；既有周本纪叙事把夷齐归附放在文王在世时。 | 保留本篇到达时西伯已死的传述，并在同号注指出差别，不改旧本纪或硬接成两个有确年的访问。 |
| 父死不葬、以臣弑君 | 是叩马劝谏中二人的指责。 | 保留人物立场；不把这一对白变成项目已经校定的武王治丧日程，也不据此推翻本纪相对年数。 |
| “左右欲兵之”“扶而去之” | 左右欲加兵，太公称义人并使其离开。 | 不扩写成已有伤亡、审判、流放或放归孤竹的事实。 |
| 不食周粟与采薇 | 传文把这一行动连于二人对周取殷的伦理判断。 | “周粟”照其政治归属理解；不推算实际饥饿天数，不把今人生态常识当成校改原文的证据。 |
| 采薇歌 | 史家称其为逸诗，注家也以未入《诗》三百篇解释。 | 保存全部诗句及逐句白话，“以暴易暴”为歌中判断，不由编者改作中立的政治定论；诗的传承与现场写作均不获独立确证。 |

### 首阳、薇与注家传说

[注本p3](../../sources/史记三家注/卷061.md#p3)保存河东蒲阪、陇西、洛阳东北偃师一带、辽西等首阳说，又引北海避纣、岐阳及清源之说，并明说诸书所指凡五处、先后不详。正义末句倾向清源，是该注家的选择；不能删除此前歧说后宣布全体古籍只指一个现代景区。本轮时期正文仅作首阳山，不附现代坐标。

同段索隐以薇为蕨，正义引陆玑则说是茎叶似小豆的蔓生山菜。植物定名未在本轮解决；正文保留“采薇”，不擅自限定为今天同名作物，也不据现代食物分类构造二人死亡的营养学结论。孤竹氏姓、伯夷叔齐名与字、殷汤封国月日等后出材料，在完整古注可读，但不据此给无年故事补一张精确世系年表。

### 史家议论没有被编成古代事件

| 单元 | 内容层次与译读 |
|---|---|
| P001 | 司马迁以六艺考信，与诸子所说许由、卞随、务光相比较；“余登箕山”“盖有许由冢云”是他的见闻和传闻语气，并未实证许由让天下。索隐认为“太史公曰”为后加，只保存为古注推测。 |
| P002、P004 | “不念旧恶，怨是用希”“求仁得仁”与采薇歌的怨词相对。保留司马迁“怨邪非邪”的问题，不将人物强改成完全无怨，也不把“怨是用希”单独等同于其心中没有任何怨意。 |
| P005 | 伯夷饿死、颜回贫而早夭、盗跖暴而寿终、近世善恶遭遇用于质疑天道报偿。不是给这些不同时代的人同时立年条。正义对“傥”的未定语气不宜删去；“天道是邪非邪”不能译成已证实天道不存在。 |
| P006 | “道不同”“富贵如可求”“岁寒”并陈各从其志与乱世操守。松柏译为天寒后才看出凋伤最晚，避免误成常绿树必须在某一时点全部凋零。轻重反问的两种古注都保留，未单定为财产多少或自主选择贫富。 |
| P007 | 贾谊之言、同类相求、孔子彰名、附骥尾与青云之士共同谈记述与传名。是篇章自述与文学比喻，不编孔子替伯夷封爵、颜回骑神骏等事件。主TXT在“云从龙”附近引号不配，原字保留，白话按成句读。 |
| N001、Z001 | 前者释列传体例，后者是唐人对天道、报施与素士无名的追赞；都放在时期页附读。Z001“得自前闻”只按承孔子罕言命暂释，不虚构一条具体师承。 |

古注借屈原、伍子胥、比干等说明遭祸，属于注家阐释；本轮没有把这些例子当作主TXT漏写的同年人物再扩入正文。集解、索隐、正义所说盗跖身份与墓地也非全无差异，白话仅保留本段论证所需的传说内容，不以其为可逐日验证的犯罪案卷。“肝人之肉”古注据《庄子》释吃人肝，本轮不再臆造烹饪过程。

百度百科篇名页直连、移动页和镜像检索均遇到访问错误或正文不可读；搜索结果摘文可见篇目结构与赏析线索，**本轮不声称已通读百度《伯夷列传》原文、注释或译文**。已完成的整卷原典阅读依仓内TXT和10段三家注，不由这个受阻网页替代。

### 尚存问题与使用边界

二人归周时文王存亡、首阳地望、薇的定名、诗歌传承、“得自前闻”的简约措辞，均没有因新增白话而变成定论。本轮完成的是整卷可追溯的阅读与分层编年，不是重新校定全部传说或推造远古年表。

# 卷063至064的现代百科与研究核对摘要

[史料目录](../../sources/README.md) · [卷063考证](史记-卷063-纪年与异说.md) · [卷064考证](史记-卷064-纪年与异说.md)

**性质与范围：** 2026-11-12实际访问记录及自写摘要。百科用于发现异说与追索出处，不能代替原典。现代著作未获取全文者明确限定阅读范围；以下不复制其正文，也不把网页引述的书籍视为已亲读。

## 内容

<a id="laozi"></a>
### 老子：人物合并、寿数与后裔

实际打开[中文维基百科“老子”](https://zh.wikipedia.org/wiki/老子)的身份争议及家族条目段，和[百度百科可读移动页](https://wapbaike.baidu.com/item/%E3%80%8A%E8%80%81%E5%AD%90%E3%80%8B/5448)的概要、基本资料及生平年次。百度可见页一面用约前571年出生，一面给出确定卒年及一串任史、罢官、问礼年份；这些细年没有因网页列表而获得本卷原文支持。维基所列李耳、老聃、太史儋的异说和新增家族人物也不合并为一条已定世系。

另实际阅读[Stanford Encyclopedia of Philosophy “Laozi”](https://plato.stanford.edu/entries/laozi/)的导言与第1节“The Laozi Story”（页面标示2025-10-22修订），未声明通读全部思想史章节。该节区分司马迁传述、较晚神仙传说及现代身份论争，允许讨论一位较孔子年长的人物，却没有消除传记组合和年代的疑问。因此本次保留史记自身“或曰”“世莫知”的限度，不按百科生卒推超长寿，也不把后出神异出生说写入实年。

<a id="zhuangzi"></a>
### 庄周：估计生卒与地望

实际打开[中文维基百科“庄子”](https://zh.wikipedia.org/wiki/莊子)的生平、著述段及[百度百科“庄子”](https://wapbaike.baidu.com/item/庄子/8074)的文学、生卒与籍贯争议段。通行前369—286的两端是现代年谱框架，原传只给梁惠王、齐宣王同时；本次不把它们升级为可核生日、卒年。蒙地有多种现代定位，保留古地名。百度相关段把《括地志》说明归在裴骃《集解》名下，仓内三家注实际显示该段属于张守节《正义》，本次以原注署名。

楚威王聘相只收在其在位时期；所读现代页面和古注均不足以确定聘请发生在元年。原传牺牛喻与正义引濮水神龟喻是不同说法，不相加成两次有日期的聘相。

<a id="shen"></a>
### 申不害：任相十五年与现代年链

实际阅读[维基百科“申不害”](https://zh.wikipedia.org/wiki/申不害)的生平及注释，和[百度百科可读页“申不害”](https://bkso.baidu.com/item/申不害/1407321)的生平年次。百度采用前355任相、前338卒，维基概述用接近二十年而所引传文仍为十五年。前355到前338首尾十八年，与十五年并不自动相合；不能把两组数据无说明拼接。

本项目已有前351、前337的周王年链和原表、通鉴出处，首尾十五年；本轮保留这一已采用链，并列现代其他排列。没有实际获取杨宽或其他学者相关全书论证，因而不以网络转述冒称完成其年谱考订。古注早已指出昭侯时多次兵争，“无侵韩者”不作逐年零战争统计。

<a id="hanfei"></a>
### 韩非：早年、使秦年与说难寓言

实际打开[维基百科“韩非”](https://zh.wikipedia.org/wiki/韩非)的生平段及[百度百科可读页“韩非”](https://bkso.baidu.com/item/韩非/1111)的主要正文。维基并列不同出生年推算；百度给出许多早年阅读、著书、求学的具体年次，但本卷不足以支持这些精度。百度可见页又分别将韩王安三年配为前235、前234，内部已不一致。本次使秦死亡仍沿既有秦王政十四年前233年，同时保存《韩世家》王安五年的另一年链，未补死亡日。原文只有口吃，不借两百科轻重措辞诊断其程度。

实际阅读王奕然[〈试论先秦诸子寓言中的“宋人”形象〉](https://humanities.ccu.edu.tw/var/file/56/1056/img/1319/13_04.pdf)，载《中正大学中文学术年刊》2009年第1期（总第13期），页81—94；实际范围为摘要、前言、页90相关小节及结论，未称全篇逐页通读。文章把宋富人一例放在寓言与言说困境中分析，有助区分史事记录和为论点服务的故事。本次完整保存《说难》的论证次序与故事，但不由这些寓言另造宋、郑、卫的确年事件。

<a id="rangju"></a>
### 穰苴：景公说、湣王说与斩庄贾年次

实际打开[维基百科“田穰苴”](https://zh.wikipedia.org/wiki/司馬穰苴)主要正文和[百度百科“田穰苴”可读页](https://bkso.baidu.com/item/田穰苴/0?fromModule=lemma_inlink)概要。两者主要沿景公故事；百度概要仍说生卒不详。通俗页把“仆”读作御者，不能替代主TXT与索隐“仆车”的断句比较；维基涉及田氏代齐的压缩表述也不能消除田和与威王为不同世代的事实。

实际读[国家图书馆出版社《子藏·兵家部·六韬卷（附司马法 尉缭子）》书目页](https://www.nlcpress.com/ProductView.aspx?Id=11066)所载《司马法》前言部分，书目列方勇编、2019年、ISBN 9787501368372；未读该套书正文。前言概述景公、湣王两种时代说及《司马法》整理层次，提示本篇叙人和后世编书须分开。这是一篇现代研究概述，不据其归纳声称学界已无异议。

实际阅读[山东地方志资料镜像“生平主要活动”](https://shandong-chorography.org/database/zzmj/section/18/article/4/)所见完整条文。该条转引杨善群《孙子评传》第245页把活动估在约前528年；本轮未获得原书该页论证，故只登记线索，既不采用此估年，也不取网上另见前531年说。新增正文仍是景公时期的篇传故事，后世质疑见[本地古籍节录](../../sources/补充古籍/阅读本/史记-卷064-时代争议古籍节录.md#siku-critique)。

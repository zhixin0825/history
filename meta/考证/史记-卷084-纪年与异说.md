### 屈原事怀王、顷襄王的时间范围

P000—P002只给屈平在怀王朝任左徒、拟令遭谗及《离骚》写作的前后关系。王逸被《正义》引为「上官靳尚」，P001正文只称上官大夫，P004另称张仪所结交者为靳尚。后世古注的指认随文留存。P010由渔父口称三闾大夫，不能据此补一个确年改任的官职条。原HTML P001「屈平屬草藁二未定」在[仓内《史记》全文TXT](../../sources/二十四史/txt/01_shiji_full.txt)第5326行作「屈平屬草槁未定」，本卷照录HTML，依草稿未定理解，不另添第二份法令。《离骚》题义，《索隐》并录应劭「離，遭也」及《离骚序》「離，別也」二解。

| 事项 | 采用位置与歧异 |
|---|---|
| 张仪以地欺楚，丹阳、蓝田两战 | P003把张仪诱楚绝齐、秦败楚并取汉中、楚再攻秦合叙。《集解》明确分怀王十六、十七年，合[《六国年表》前313](../../sources/摘录/史记-卷015-六国年表.md#y0313)和[前312](../../sources/摘录/史记-卷015-六国年表.md#y0312)。张仪说辞归前313，丹阳和蓝田各沿前312年页原有条目。HTML作「丹陽」「屈匄」，全文TXT有「丹、淅」，[《楚世家》P078](../../sources/摘录/史记-卷040-楚世家.md#p078)作「丹陽」「屈丐」，并说韩、魏袭楚至邓，本传只举魏。地名、姓名异文和联军范围在同条合读。 |
| 秦议割汉中，张仪获释 | P004承上说「明年，秦割漢中地與楚以和」，[《楚世家》P079—P080](../../sources/摘录/史记-卷040-楚世家.md#p079)系怀王十八年，具体作分汉中之半求和，怀王拒地而索张仪，故不记秦当年已把汉中交还。[《张仪列传》P032](../../sources/摘录/史记-卷070-张仪列传.md#p032)让屈原就和约劝楚王勿复听张仪，[前311年](../../years/bce-0400-0301/bce-0311.md#sj040-zhangyi-chu-release-note)的本传和世家记出使齐归来劝杀、王追不及，均是同一轮张仪赴楚的不同写法。 |
| 重丘击楚，唐昧败亡 | P005徐广系怀王二十八年，与[《六国年表》前301楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0301)及[《资治通鉴》卷003](../../sources/本地分卷/资治通鉴/资治通鉴-卷003.md#L552)互证。楚栏作唐眛，并列秦、韩、魏、齐，既有同号史料保存各路战事。 |
| 武关被扣与顷襄王即位 | P006徐广定怀王三十年入秦。卷084让屈平劝止，[《楚世家》P084](../../sources/摘录/史记-卷040-楚世家.md#p084)记昭雎，P006《索隐》推测二人或皆谏，两篇各有侧重。子兰劝行、秦扣王索地同见[前299年](../../years/bce-0300-0201/bce-0299.md#note-2)。P007在怀王死亡后接写顷襄王立，是叙事顺序。[《楚世家》P085](../../sources/摘录/史记-卷040-楚世家.md#p085)先记怀王被扣、楚自齐迎太子横即位，故承位归[前299年](../../years/bce-0300-0201/bce-0299.md#note-7)，[前298年](../../years/bce-0300-0201/bce-0298.md#note-4)为新王元年。子兰任令尹无独立确月。 |
| 怀王逃秦、归葬 | P006把投赵不纳、再入秦、死秦归葬紧接叙述。《楚世家》P086与《六国年表》分系[前297年](../../years/bce-0300-0201/bce-0297.md#note-1)出逃，[前296年](../../years/bce-0300-0201/bce-0296.md#note-2)死于秦及归葬。P008论「亡其六郡」是史家总结政治得失，无六郡一并交割的年月或清单。 |

### 《怀沙》、汨罗与节俗

P009明写顷襄王迁逐屈原，《集解》引《离骚序》称江南；没有王年。P010渔父问答含「三閭大夫」「新沐」「新浴」等叙事，不能据文学对话确定行程中的某日。P011—P015是《怀沙》的引语与赋辞，孟夏、沅湘、南土皆保存；其中「孟夏」不足以与P016的投水日期画等号。诗题、押韵、用典与《楚词》异读按夹注原位保存。

P016只记「於是懷石，遂自投汨羅以死」。《正义》引后出的《续齐谐记》附五月五日、竹筒投米及五色丝等节俗传闻，不能作为确立战国卒年月的当时证据。前278常与郢陷并举，[《楚世家》顷襄王二十一年及《六国年表》](../../years/bce-0300-0201/bce-0278.md#note-1)能够确定郢陷与楚廷退陈，此传并未把汨罗之死明确系于这一战事或这一年。P017「數十年」与P018「百有餘年」皆为概数，既不能从[前223秦灭楚](../../years/bce-0300-0201/bce-0223.md#note-1)逆算，也不能从[前176贾谊赴长沙](../../years/bce-0200-0101/bce-0176.md#note-4)逆算。宋玉、唐勒、景差列于屈原之后，以赋著称及「終莫敢直諫」是传文的比较，无任官、生卒确年。详见[屈原放逐与楚辞](../../years/bce-0300-0201/时期-屈原放逐与楚辞.md)。

### 贾谊入朝、改制、两赋与两次出傅

| 事项 | 采用位置与歧异 |
|---|---|
| 吴公荐用与太中大夫 | P019写文帝初立召河南守吴公为廷尉，吴公荐贾谊为博士，[《通鉴》卷013](../../sources/本地分卷/资治通鉴/资治通鉴-卷013.md#L546)系文帝元年，接写「一嵗中超遷至太中大夫」，故以[前179年](../../years/bce-0200-0101/bce-0179.md#note-12)为召用入口，升迁保留一年内的时距。十八岁知名是任官以前，无对应确年。 |
| 制度议与列侯就国 | P021说改正朔、服色尚黄、数用五、变更官名和兴礼乐，文帝初年没有全面实施。《汉书》卷048传、赞均可对读，班固的总体评语「誼之所陳略施行矣」并未说各项在同年尽行。《孝文本纪》二年[前178](../../years/bce-0200-0101/bce-0178.md#note-1)已令列侯就国，次年[前177](../../years/bce-0200-0101/bce-0177.md#note-1)文帝催促未行者，以周勃先行。贾谊传归其倡议，不据此把全部律令调整系在初下诏或催行一年。 |
| 出傅长沙、渡湘吊屈原 | [《通鉴》卷014](../../sources/本地分卷/资治通鉴/资治通鉴-卷014.md#L149)在四年叙天子议擢用和谗毁外任，[前176年](../../years/bce-0200-0101/bce-0176.md#note-4)沿这一系年。P018、P022—P024记赴任渡湘作赋，作品可随任命前后阅读，没有具体写作日。P021《索隐》和P025《正义》认为贾谊所傅是长沙靖王吴差，和后来的长沙定王刘发有别。P021《正义》称冯敬为御史大夫，而[前173年](../../years/bce-0200-0101/bce-0173.md#note-11)年表有自典客迁御史大夫条，注家官衔可能是追称，不能单用此衔改定出傅。 |
| 鵩入舍与《鵩鸟赋》 | P025明写长沙太傅三年，P026「單閼之歲」指卯年，徐广明确「文帝六年歲在丁卯」，合[前174年](../../years/bce-0200-0101/bce-0174.md#note-13)及由前176年起首尾三年。P026还写四月庚子，原载日名保留，未经历法换算不写现代日期。古注「日施」音移、义为日斜，《汉书》卷048作「日斜」。P027—P028是赋托鵩而答的设言，吴越、李斯、傅说是说理的前例。 |
| 宣室召见与梁怀王太傅 | P029从鵩入舍、作赋之后说「後歲餘」，接「居頃之」任梁傅，《汉书》卷048亦有召见与任傅相承。[《通鉴》卷014文帝六年条](../../sources/本地分卷/资治通鉴/资治通鉴-卷014.md#L296)叙上疏时已称「梁太傅賈誼」，胡三省注明自长沙被征。六年署职和本传「後歲餘」不易同定，兼留两条证据，宣室、任职及相继奏疏按[时期页第4条](../../years/bce-0200-0101/时期-贾谊辞赋与政议.md#event-4)合读。 |
| 封厉王四子、论削诸侯 | P030前两句互证[《通鉴》文帝八年](../../sources/本地分卷/资治通鉴/资治通鉴-卷014.md#L539)，归[前172年](../../years/bce-0200-0101/bce-0172.md#note-2)。四人为列侯，后来厉王三子封王另有[前164年页](../../years/bce-0200-0101/bce-0164.md)。P030后半「數上疏」的范围广于这一次谏封，传文「文帝不聽」与班固对后世部分实施的评价时间口径不同，亦须同《梁孝王世家》文帝接受部分封国安排对读。 |
| 梁王死亡、贾谊卒与后裔 | P031《集解》徐广载文帝十一年，[《汉兴以来诸侯王年表》](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0169)及[《通鉴》卷015](../../sources/本地分卷/资治通鉴/资治通鉴-卷015.md#L14)相合，坠马与无后归[前169年](../../years/bce-0200-0101/bce-0169.md#note-1)。本传 P029《索隐》名楫，《通鉴》用揖，[《梁孝王世家》](../../sources/摘录/史记-卷058-梁孝王世家.md#p003)与《汉书》卷048用胜，同指先于刘武的梁怀王。传、汉书及[《通鉴》本段后叙](../../sources/本地分卷/资治通鉴/资治通鉴-卷015.md#L41)仅记贾谊在梁怀王死后一岁多卒，约前168可作推算，独立卒年、月日无考。P031从孝文崩跳写孝武立，中间仍有景帝一朝；《汉书》只称武帝初举其二孙，并无确年。贾嘉入九卿及与司马迁通书同列本传后叙。 |

### 两种本地底本与辞赋层次

本批以原始HTML主文和含注文本逐段回读；[仓内整书TXT](../../sources/二十四史/txt/01_shiji_full.txt)第5325—5360行剔除分节标签「賈誼」「評論」后与34段顺序对应。除丹阳、丹淅等异文外，P016 HTML「自投」对TXT「自（投）［沈］」，P032「服鳥賦」对TXT「服烏賦」，P033 HTML「比㓗」对TXT「比潔」，分别依原本保留。

[《汉书》卷048《贾谊传》](../../sources/二十四史/txt/02_hanshu_full.txt)全文TXT第7568—7610行与P019以下多处平行，亦有篇章和字句差异。P023此本「世謂伯夷貪兮，謂盜跖廉」，该传另举卞随、伯夷及盗跖、庄蹻；P024「瞝九州」在《汉书》作「歷九州」；P027「大專槃物」在《汉书》作「大鈞播物」。索隐已列部分异读，白话据本HTML及古注互解。P002、P008随传评议，P032是太史公论，P033是唐代述赞，文学评论、借古议论和传中发生的事按原层次阅读。

## 扁鹊故事的传述年代

- **赵简子病梦。** 本卷P002作“當晉昭公時”。《索隐》据《左传》、[《赵世家》P023—024](../../sources/摘录/史记-卷043-赵世家.md#p023)改从晋定公初，张守节在P003注另以梦辞“七世而亡”推定公十一年（约前501年）。《赵世家》将病梦置于阳虎来奔以后，并未单给病年月。李钟琴《“神医”扁鹊（秦越人）真相新考》（《医学与哲学》2019年第14期）采用约前500年的解释。本卷沿[前497年赵氏、董安于原有互见入口](../../years/bce-0500-0401/bce-0497.md#sj105-p002)附读，以[时期第2条](../../years/bce-0200-0101/时期-扁鹊医事传说与淳于意诊籍.md#note-2)为故事完整去向。前497年是该人物背景条的阅读位置，病梦未独立定年。秦穆公旧梦和范魁预言各随原段保留。
- **虢太子与齐桓侯。** P004《索隐》引傅玄说晋献公灭虢在故事所叙时代以前百二十余年，司马贞另疑虢为郭。P007《集解》同时保留傅玄称其时齐无桓侯、裴骃称田齐桓公田午两说。《韩诗外传》卷十及《说苑·辨物》保存虢／赵太子平行故事，《韩非子·喻老》则写蔡桓公。人物称谓有异，不能据[虢国覆亡](../../years/bce-0700-0601/bce-0655.md)或[田午卒与齐威王承位](../../years/bce-0400-0301/bce-0356.md#note-6)指定诊治之年。
- **秦越人里籍、生卒和遇害。** 底本“勃海郡鄭”与徐广、司马贞辨认的地名各存；《正义》所引又称家于卢。维基百科《扁鹊》所列约前407年至前310年及百度百科《扁鹊》所列多种活动年代，只作检索线索。《战国策·秦策》有见秦武王事，卷105却未记所见秦王，也无李醯刺杀的年号。关于扁鹊一名可能汇入多代医家传闻，可参金仕起《扁鹊仓公列传命题析义》（《国立政治大学历史学报》2008年第29期）及李钟琴前引文。本卷从学、游医、遇害均放时期页。

## 淳于意的从师、狱案与受诏

| 事项 | 依据与归年 |
|---|---|
| 从阳庆学医 | P010、P014都作高后八年，接[前180年](../../years/bce-0200-0101/bce-0180.md#sj105-p010)。P045所述公孙光荐意在此之前。所学三年及后来任齐太仓长都保留相对次序，任职始年无载。 |
| 缇萦上书与除肉刑 | P011原作“文帝四年中”，[整书TXT同](../../sources/二十四史/txt/01_shiji_full.txt#L5889)。[《孝文本纪》](../../sources/本地分卷/史记/史记-卷010.md#L671)、[《汉书·文帝纪》](../../sources/本地分卷/汉书/汉书-卷004.md#L218)、[《刑法志》](../../sources/本地分卷/汉书/汉书-卷023.md#L5014)、[《通鉴》卷十五](../../sources/本地分卷/资治通鉴/资治通鉴-卷015.md#L264)都支持文帝前元十三年五月除肉刑。张苍、冯敬的任官重合亦支持这一年线。并入[前167年第3条](../../years/bce-0200-0101/bce-0167.md#sj105-p011-e3)和[第3条](../../years/bce-0200-0101/bce-0167.md#sj105-p011-e4)，保留本传异年与原句。 |
| 齐文王及阳虚侯 | [《汉书·高五王传》](../../sources/本地分卷/汉书/汉书-卷038.md#L7165)明载齐文王刘则前165年卒、次年六王立。本篇P043只以闻知解释病情，卒事与[前165年](../../years/bce-0200-0101/bce-0165.md#sj105-p043)互见，诊治细节仍留时期。P036“故爲陽虛侯”指后为齐孝王的刘将闾，与[前164年](../../years/bce-0200-0101/bce-0164.md#sj105-p036)人物身份互读；原病年月未载。[汉王子侯表](../../sources/本地分卷/汉书/汉书-卷015.md#L1540)作“楊虛”。 |
| 诏问与诊籍 | P012—014写家居后受问及从师，P015—038录诊籍，P039—047另答方法、误差及师徒。“年盡三年”指哪一个年次，取决于传本与语法。金仕起以齐文王死、诸王受封与七国王仍在的称谓限定范围，也讨论多次答问汇编的可能。张传玺《西汉淳于意狱案发覆》（《法学研究》2025年第4期）释“三年”为后元三年（前161），据此主张后元四年（前160）召问。两说并存，暂不另立确定诏问年。 |
| 传囚、服刑和获赦 | 张传玺结合《囚律》、胡家草场汉简提出齐国治狱及传囚长安的“两狱说”，推可能被处髡钳城旦、前165年遇赦返乡。本传只明说传囚、缇萦请赎及除肉刑。罪名、实际服刑及获赦细节依研究存为推说。 |
| 随阳虚侯赴长安与安陵诊案 | P042以侯入朝解释赴安陵见项处。金仕起在正文讨论文帝十四年（前166）前后，在表中又列后元三年（前161）前后；后一读法要解释为何已王齐仍称阳虚侯。现有[前161年齐王入朝](../../years/bce-0200-0101/bce-0161.md#note-4)仅供比较，不能作为项处诊病的独立确年。 |

维基百科《淳于意》列前205年至前150年，百度百科列约前215年至约前140年。P014《集解》据徐广注从师时“二十六”，异本还有“三十六”说；文帝召问的时间也有不同解释。沿本卷可直接核定的经历归年，生卒暂不取两百科的确数。

## 底本分段与诊籍用字

仓内HTML保留P000—P052共53段、226处段内注标记。P000是《索隐》《正义》的卷首意见；P048为太史公论、P049为司马贞述赞。P050只有《正义》及其所附说明，P051—052接续篇末脏腑经脉文字，分层释读。仓内[整书TXT](../../sources/二十四史/txt/01_shiji_full.txt#L5877)另有“仓公”“评论”等分节标记，P025的乳母与女子豎分作[两行](../../sources/二十四史/txt/01_shiji_full.txt#L5903-L5904)，P047末问“能全無失乎”没有同段对应，依HTML保留。P017“蹷人中／蹙入中”、P027“莨𦿆／莨碭”、P032“汜里／氾里”、P045“楊慶／陽慶”保留底本文字或相应异读。病案按所载人物、诊断、观察结果和解释分开，方药、症因和身体尺度均作为古代文献内容阅读。

# 公元192年（初平三年）整页复核

[192年年页](../../years/ce-0101-0200/ce-0192.md) · [裴注校补](../../sources/摘录/三国志-初平三年裴注校补.md) · [纪年异说](../考证/三国志-全书纪年与异说.md)

本轮先逐段对读《资治通鉴》卷六十仓内 L283–L526（从初平三年题起至初平四年前），对照《后汉书·献帝纪》及具体条目的相关列传，再反查《三国志》魏书和相关蜀、吴列传。裴注用仓内中华书局点校本第一册影印页校补，页码见上方校补页。仓内整书 TXT 继续作为本纪、列传正文的转录底本。

| 对读范围 | 年页落点与归年处理 |
|---|---|
| 正月中牟、冀州战事 | [第38条](../../years/ce-0101-0200/ce-0192.md#sg-note-38)区分此役与同年召朱儁入朝。[第3条](../../years/ce-0101-0200/ce-0192.md#hh-note-3)载界桥，钜鹿的董昭事见第50条，年底龙凑另见第26条。 |
| 董卓被诛、王允执政及身死 | 第4、5、10、11、14、20条依次容纳谋诛、执政、拒赦与围城、长安城破、收杀王允与授官。牛辅、蔡邕、荀攸、贾诩另有各自阶段。 |
| 兖州与关东 | 刘岱战死、曹操领州、寿张战斗、济北受降分别核对。金尚、毛玠、董昭、钟繇据传文和《通鉴》补入。 |
| 年界异说 | 孙坚之死在[191年《通鉴》条](../../years/ce-0101-0200/ce-0191.md#sg-review-191-note)及[192年正史条](../../years/ce-0101-0200/ce-0192.md#hh-note-2)互见。陈温在[192年《通鉴》条](../../years/ce-0101-0200/ce-0192.md#sg-note-47)及[193年《献帝纪》条](../../years/ce-0101-0200/ce-0193.md#hh-note-3)互见。 |
| 未硬定年 | 《公孙瓒传》在界桥后连叙故安、巨马水与田楷连年作战；故安、巨马水无明年，见[本传后续](../../sources/本地分卷/后汉书/后汉书-卷073.md#L5222)。袁绍后日致公孙瓒书作界桥、龙凑的回证，书信本身未归192年。 |

新增13个编号，归并第27、30、31、34四个旧条，保留原跳转锚。重校后192年有46条正文，和同号史料逐条互链。

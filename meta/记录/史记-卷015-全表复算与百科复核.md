## 内容

### 一、原表逐格比对

本轮重读[维基文库《史记》卷十五](../%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7015.md#ref-d07966c53cd16a)全表，与仓库已存原表逐格比较。网页在周亡以后省去周栏，在六国亡后只剩秦栏；先按原有八栏还原空位，再比较每格。只归一化空白字符，以及仓库表示空位的“—”，不把异字、标点或史事年份自行改成相同。

270行的2160格全部相合。分类复核为632个文字、君号或元年格，1290个纯王年数字格，238个空格，三者之和为2160。632不是独立事件数；同一格可以有数件事，同一件事也可能分记在不同国栏。表序和后出的《索隐述赞》不混入这项格数。

既有[整卷完成核对](史记-卷015-整卷完成核对.md)和各分段记录继续负责文字去向；本记录补足数字与跨来源复核，不将原来的故事重新编成第二套时间线。

### 二、2152个相邻年度边界的复算

以同一国栏前后相邻两年为一组，共269×8＝2152组。先辨认本国纪年，再判读是否换君、改元、空栏或借记别国。不能在格中看见任何“元年”便把本国数字清零。

| 分类 | 数量 | 核查结果 |
|---|---:|---|
| 两格均可识别当前纪年，且不是另起元年 | 1810 | 后格均为前格加一 |
| 后格明确另起本国元年 | 90 | 按换君或改元边界单列，不误判为数字倒退 |
| 后格为空 | 238 | 保留空位，不为亡国后诸栏延造王年 |
| 无本国数字或借记其他国家的边界 | 14 | 逐项解释如下，不强行参与本国加一计算 |
| 合计 | 2152 | 没有尚未解释的数字跳跃 |

十四个不能当作本国王年连续计算的位置，以下以后格年份为准：

| 后格年份 | 所在栏 | 原因 |
|---|---|---|
| 前475、474 | 魏 | 晋定公卒、晋出公元年，属于晋君记录 |
| 前470 | 魏 | 卫出公出奔，无魏国王年数字 |
| 前464、463、462 | 韩 | 知伯伐郑、郑声公卒、郑哀公元年；不能变作韩君纪年 |
| 前456、455 | 魏 | 晋哀公、卫悼公的君次 |
| 前453 | 魏、韩各一格 | 魏桓子、韩康子败智伯的纪事，未给可连续计算的本国数字 |
| 前450、431、425 | 魏 | 卫敬公、卫昭公、卫悼公的君次 |
| 前437 | 魏 | 晋幽公元年 |

另外，两处必须先按文意切分：前210年秦栏开头“三十七十月”是三十七年及十月，不能将连写数字读作一个年数；前209年“二世元年”是秦二世元年，不能把君号的“二”误作二年。前476年首行的君名加数字作为各栏起点，也不能因前面有姓名便丢弃。

以上计算检查的是所存年表内部的递进关系。魏惠王后元、齐威宣君次等问题即使数字连续，仍须凭另见史料判断；原表数字没有被改写来迁就正文采用的年代。

### 三、百科交叉核查与取舍

本轮实际阅读下列百科条目的相关正文。百科覆盖的是有较高混淆风险的起讫、君次、即位与元年等问题，不声称每个表格单元都在两家百科中有独立对应条目。

| 已查条目 | 核查事项 | 本项目处理 |
|---|---|---|
| [维基百科：六国年表](../%E6%9D%A5%E6%BA%90/%E7%BB%B4%E5%9F%BA%E5%8F%82%E8%80%83/%E5%85%AD%E5%9B%BD%E5%B9%B4%E8%A1%A8-94099814.md#%E6%A0%B8%E5%AF%B9%E8%8C%83%E5%9B%B4) | 篇名、前476—207年的范围、实际八栏与“六国”题名的关系 | 与仓库范围相合；仍保留周、秦两栏，不因篇名删成六栏 |
| [维基百科：魏惠王](../%E6%9D%A5%E6%BA%90/%E7%BB%B4%E5%9F%BA%E5%8F%82%E8%80%83/%E9%AD%8F%E6%83%A0%E7%8E%8B-95063714.md#%E6%A0%B8%E5%AF%B9%E8%8C%83%E5%9B%B4) | 实际承位、次年元年、后元与卒年 | 保留前370年承位背景、前369年元年、前334年后元、前319年卒的既有采用方案 |
| [百度百科：魏惠王](../%E6%9D%A5%E6%BA%90/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-787e690b1c213679.md#cite-1) | 基本信息与“历史争议”中的在位年次、改元讨论 | 与维基百科互校；同页各处用语须分辨即位年与元年，不能只复制信息框 |
| [维基百科：魏襄王](../%E6%9D%A5%E6%BA%90/%E7%BB%B4%E5%9F%BA%E5%8F%82%E8%80%83/%E9%AD%8F%E8%A5%84%E7%8E%8B-94719641.md#%E6%A0%B8%E5%AF%B9%E8%8C%83%E5%9B%B4) | 前319年承位、前318年元年，以及旧材料“襄”“哀”的混乱 | 保留同一继承链，不在前318年另造一个同时期魏哀王 |

决定正文取舍的具体历史依据仍见[《魏世家·索隐》](../%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-bbc6418b560533)所引惠成王改元材料及[《资治通鉴》卷三](../%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-e8c211280db45f)。对应正文分别在[前369年](../../years/bce-0400-0301/bce-0369.md)、[前334年](../../years/bce-0400-0301/bce-0334.md)、[前319年](../../years/bce-0400-0301/bce-0319.md)和[前318年](../../years/bce-0400-0301/bce-0318.md)。这些修正原已存在，本轮确认保留，不列作本轮新发现。

本轮也查到[百度百科：无彊](../%E6%9D%A5%E6%BA%90/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-6dc7dae3e885dba1.md#cite-1)所列灭越年代争论。它不能反过来证明本卷每一处楚越战争都是同一场灭国；卷十五原表与当前年页未出现需要据此直接更改的同一条叙事，故未越出证据范围增造“灭越年”。相关世家今后整卷阅读时仍应核对。

### 四、尚存问题与完成口径

原有考证中的齐魏旧君次、马陵异年、苏秦行年、鲁亡年链、前476年楚栏国别、宋卫短格等分歧继续保留。没有把“全表读入”“数字校算完成”和“古史全部定论”写成同一件事，也没有通过删除待考注来使完成状态显得整齐。

本卷此次没有发现需要新增独立年度页或反转既有主线的新证据；新增的是可追溯的逐格复核、数字边界解释和百科对照记录。

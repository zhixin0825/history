## 内容

### 范围与口径

将[固定见证9484995](../%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7018.md#ref-a77ff2d5779f41)的143行、六段帝纪858格全部分类：477格含文字，243格为纯数字，138格为空。表内裸数字常是该帝时期某一侯的年数；与明确写出的皇帝纪年、初封、嗣侯、复封、国除分开计算。

有明年起讫的段落按起止年份计算相隔年数，同时检查含终年与不含终年的口径。两个口径都能在表内找到例子，因此相差一年的任期不能先被判成编辑错误。具体年月和史料异说仍以原文及互校为准。

### 已复算的类别

| 类别 | 数量与结果 | 限度 |
|---|---|---|
| 全部纯数字格 | 243格；242格等于相应帝纪栏的完整年数，慎阳文帝格为22而非23 | 纯数字表示一段侯年，不据此新造事件 |
| 高祖初封且惠帝栏继续的段落 | 136行，裸数分段之和均等于高祖十三减初封年 | 算的是本朝覆盖；不是每一位侯的生卒年龄 |
| 惠帝完整跨栏加总 | 134格相合；3格因边界、终止等另读 | 不能把空白自动当成仍在位 |
| 高后完整跨栏加总 | 121格相合；4格有中断或疑数，9格边界不完整 | 夺爵、复封的间隔应扣开 |
| 文帝完整跨栏加总 | 99格相合；7格有中断或疑数，20格边界不完整 | 新增列出貰、慎阳疑数；曲城等旧异说继续保留 |
| 景帝完整跨栏加总 | 60格相合；9格有中断或疑数，39格边界不完整 | 阿陵“一八”连写须分层辨认，不能解析为十八 |
| 武帝明年相邻段 | 46行中60对明确年号起讫，均有可与相隔年数或含终年数相合的表内任期数字 | 内部相合不证明其与汉表同年；梁邹、壮等仍有实质年差 |
| 武帝不能配成明确起讫的文字格 | 26行 | 不从单个裸数强补承侯、死亡或免爵年 |

这些检查类别有重叠，不能加总为已核事件数。跨栏相合只说明表内数字结构可成立，不把任期加总相合等同于历史年线唯一正确。

### 具体疑数及处置

| 行 | 发现 | 取舍 |
|---|---|---|
| R034 貰 | 文帝格开头为“二”，又明记赤元年、遗十二年元年；两次起年相隔11年。《汉书》明记赤十一年薨 | 正文仍在前179、168年记承爵；增加数字不合说明，原字不改成十一 |
| R107 慎阳 | 文帝格“二十二”与前179—157年的23个年度不齐；全段2＋7＋8＋22＋12＝51，汉表也记始侯51年 | 不能只为凑23改原文，亦不能以任期51擅改景中六年承侯；明确登记一年的计数差 |
| R051 阿陵 | 景帝格“一八”连写；文帝格实际为“二、二十一、三年欧元年” | 文帝3—23共21年，前177年欧承爵有据；景帝连写按既有前155承、约前148失爵、前144复封说明，保留疑字 |
| R038 曲城 | 景帝先“十三”失爵、再中五年复封，若当同一连续时期便倒错 | 既有考证已改用较连贯的汉表年线，此次不把加总18误写成景帝在位18年 |
| R075 深泽 | 高后、文帝、景帝三栏均有夺、绝、复封；将夜/将夕还有死亡与复封矛盾 | 各段分开，沿既有异说；不把空缺补齐凑满帝纪年数 |
| R103 宣平 | 高后“六”与张偃转王压写同格；武帝广元光三年到昌元鼎二年相隔17、含首尾18 | 先区分跨年的压写；武帝十八可与含首尾年数对应，不自动改成十七 |
| R101 离、R125 中牟高祖栏 | 有初封日期但没有可加总的裸数字；离行又明言起讫失载 | 保留明年初封，不补完整任期 |
| R025 阳夏、R040 淮阴、R041 芒、R093 阏氏、R106 沛 | 高祖时期已反、被诛、失爵、无后或转王 | 分别核起讫性质；如韩信“六年侯—十一年诛”配五，不能统一强套首尾俱计 |

武帝26行未形成明确起讫配对：R003、R005、R009、R020、R023、R028、R030、R033、R041、R042、R045、R062、R063、R064、R070、R075、R079、R093、R098、R099、R100、R104、R111、R123、R132、R135。其中有明记终局、未记本段起点者，也有承嗣先后不具两端者；已有可由别篇补定的正文年份仍按逐格记录处理。本表不制造新的精确日期。

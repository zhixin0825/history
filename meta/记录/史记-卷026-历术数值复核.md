## 内容

<a id="口径"></a>
### 表能验证什么

仓库TXT的历术表依次附太初元年至建始四年年号，按通行年号对应前104—前29年，共76行。这里的公元前数只说明传本年号的阅读位置，不能证明整张表就是这76年实际颁行的历日。表的数值结构是岁实365又1/4日、朔策29又499/940日的四分法；[《汉书·律历志上》颜师古注固定版2688075](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8%E9%A1%8F%E5%B8%AB%E5%8F%A4%E8%A8%BB-%E5%8D%B7021.md#ref-9d81003449d9e8)的造历段明列朔策29又43/81日，并记诏用邓平所造八十一分律历、覆校后继续采用；该算法与本表须分别阅读。本轮只复核本表内部算法，没有以现代天文软件重算这76年的真实合朔、冬至或逐月大小。

刘次沅〈史记《甲子篇》历谱及其与《太初历》的比较〉，《陕西天文台台刊》1997(00)：107—112，[期刊官方摘要](https://sxtt.cbpt.cnki.net/portal/journal/portal/client/paper/b843d1be938770fc1945e80d426081fe)明确分别编排《甲子篇》四分法历谱与太初八十一分法历谱。这是区分算法对象的研究依据；本轮实读的是网页摘要及书目信息，没有取得论文全文，不冒称复验该文的完整940朔日比较。

[三家注固定版2514838](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7026.md#ref-54139b2441c8a3)在表首说明，前一对为朔的大小余，后一对为冬至的大小余；《正义》解释小余为未满一日的分数。末尾N001的“小餘者，月也”仍存原字，但不能把小余348理解成348个月，也不能把两个不同日法的小余直接相减。[四库本固定版838397](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E9%9B%86%E8%A7%A3%20%28%E5%8F%B8%E9%A6%AC%E9%81%B7%2C%20%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29-%E5%8D%B7026.md#ref-4c612fa1582a84)及其考证又指出历元、真实年干支和后续附表不可混同。上述网页访问于2026-11-04。

<a id="算法"></a>
### 精确算式和进位

令n为从首行起已经过的年数，R001对应n=0；M(n)为此前累计月数。用表所示十九年章的规则独立计算M(n)=⌊235n/19⌋，则第n行的月数是M(n+1)−M(n)。所有76行的12／13月都与这个规则相合；它只给相邻两个子月朔之间的月数，不直接给出闰在几月。

| 对象 | 精确量 | 从累计日数取表值的方法 |
|---|---|---|
| 平均朔望月 | 29+499/940=27759/940日 | 月朔累计L(n)=M(n)×27759/940 |
| 平年12个月 | 354+348/940日 | 大余增54，小余增348；满940进1日，大余满60去之 |
| 闰年13个月 | 383+847/940日 | 大余增23，小余增847；满940进1日，大余满60去之 |
| 岁实 | 365+1/4=1461/4日 | 冬至累计S(n)=1461n/4 |
| 冬至一年增量 | 365+8/32日 | 大余增5，小余增8；满32进1日，大余满60去之 |
| 两种大余 | ⌊L(n)⌋或⌊S(n)⌋除60的余数 | 甲子取0，乙丑取1，依次循环；0写作无大余 |
| 朔小余 | L(n)的小数部分乘940 | 范围0—939，0写作无小余 |
| 冬至小余 | S(n)的小数部分乘32 | 本表只取0、8、16、24；0写作无小余 |

这里的“加23”已经是383除60后的余数，不是在平年354日上只加23日。亦可先加12个月的量，再多加一个整闰月29+499/940日，统一进位；两种算法相同。复算全用分数，未用小数四舍五入。

几个容易被误判的数：R009朔余14+22/940，经过该行13个月，得到R010的37+869/940；再加12个月，得到R011的32+277/940。“869”与“277”均算合。R030为12+42/940，经过13个月得到R031的35+889/940，再经过12个月得到R032的30+297/940；原TXT把后两行粘在一个物理行，并非缺少本始元年。R057经13个月得到R058的59+235/940，原TXT另把正东首行与前行粘连，也没有少一年。

每章19年=235月=6939又3/4日，其中12个月的年12个，13个月的年7个。四章共76年、28闰、940月，恰为27759日；这就是四章成一蔀、日内余分归零的算术关系。章首冬至时刻由子至酉、午、卯，是每19年累计3/4日的结果；方位不是四个观测地点，也不是四个不同朝代。

R076仍是最后一年的起点，其所列13个月须经过后，才到满76年的边界。由R076朔余15+93/940加383+847/940，得整数399日，除60余39；由其冬至余33+24/32加365+8/32，也余39日而小余0。因此一蔀末是39而非0日：小余回零不等于日干支同时回到甲子，更不能说表中每行都在朔旦冬至。延伸算术上20蔀的日数才是60的整数倍，此处未据此增加表外年页。

<a id="岁名"></a>
### 岁名次序与真实年干支

本表岁阳从焉逢、端蒙、游兆、彊梧、徒維、祝犁、商橫、昭陽、橫艾、尚章顺次循环；依本篇古注，分别对应甲至癸。本篇的“昭陽”在这个序列中对应辛，不能从另一部书的同名年表直接套来作癸。岁阴从攝提格、單閼、執徐、大荒落、敦牂、協洽、涒灘、作噩、淹茂、大淵獻、困敦、赤奮若循环，对应寅至丑。R001为本篇甲寅式岁名，R061再次为焉逢攝提格，符合60循环。

| 原字位置 | 本轮检查时的同位对照 | 处理 |
|---|---|---|
| R008作鄂 | 作噩，酉位 | 原字保留；三家注集解本已载噩／鄂异写 |
| R016大芒落 | 大荒落，巳位 | 原字保留；古注载芒／荒异文 |
| R018、R030汁洽 | 協洽，未位 | 原字保留；古注载汁／協异文 |
| R033、R069閹茂 | 淹茂，戌位 | 原字保留；古注载淹／閹异文 |
| R053敦執 | 敦牂，午位 | 按循环和其他见证对照；不在源文静默校字 |
| 祝犁、彊梧等 | 其他见证有祝犂、強梧等字形 | 只作同位核对，不将全卷强行统一字形 |

以上“合”检验的是本表内部序列。四库考证以通行连续纪年的丁丑解释太初元年，并将本篇甲寅解作历元托始；这是一种明确的古代考证意见，不是以数值算合就能独立证明的全部年名史。[《后汉书·律历下》固定版1484757](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%BE%8C%E6%BC%A2%E6%9B%B8-%E5%8D%B793.md#ref-1ed3ec065b6e55)也有太初历元用丁丑的说法。三家注讨论《汉书》太岁法的丙子，而本篇表岁名从焉逢攝提格（甲寅）自递推；太岁所在、历元托始、年首衔接和后世连续干支年不能只因都用干支便机械等同。故这里不把R001的焉逢攝提格直接改写成“前104年是甲寅年”，也不用表中76组岁名去重编既有年页。

### 具体版本异数和注内误算

底本TXT和当前三家注在下列本表数值上相合；四库在线转录有具体不合。此处只确定所读数字页面的读数，没有用计算结果冒充已查验四库影像原刻；究竟原刻误字或现代转录误字仍应据影像再判。源文一律不因此改动。

| 位置 | TXT／三家注所见 | 四库在线所见 | 精确复核及取舍 |
|---|---|---|---|
| R014，征和二年年号 | 二年 | 三年；下一行仍三年 | 从征和元年递进和76行连续年号支持二；四库此处与前后不合 |
| R047，神雀四年朔大余 | 三十三 | 三十二 | R046的39+144/940加12个月，得33+492/940，支持33；不是32 |
| R058，初元二年朔小余 | 二百三十五 | 二百二十五 | R057的35+328/940加13个月，得59+235/940，支持235；不是225 |
| 闰年过后大余增量的正义文字 | 三家注作加二十九 | 四库作加二十三 | 整闰年383日除60余23；加29将使下一大余错6。应分清“比平年多一个29日余分的月”和“整年除60的余数” |
| 朔小余进位日法的正义文字 | 三家注两处作九百四十 | 四库两处作九百三十八 | 按940，76行皆合；按938，R004起即不合。940还是76年940月的同一算法结构，不是为凑单行临时选数 |
| N001尾释 | 小餘者，月也 | 同样作月 | 正义明确以日之余分释之；不采小余为整月数量的字面误解 |

三家注《索隐》在太初二年处把上述朔策称作“太初历法”，但同卷前注又引邓平、落下闳29又43/81日的朔策；前者比后者少1/76140日。这个差值是两算法的精确差，940月累计少1/81日，仍可能因跨日边界影响排朔；它不许可把一种系统的表直接当作另一种实行历。这里采用现代研究所明确区分的算法对象，保留古注名称，不盲从术名而混算。

四库考证认为历术及其附载年号有后续层累，《索隐》又有褚先生续文说；N001尾注《正义》的后人添加疑问有其特定范围。数值算合只能证明传本表有自洽的四分法结构，不能单凭算合判定全表作者、实际编成年代、岁名附会者或每个传写层次。

### 本轮边界

本次没有把12／13月直接扩充成940张月表，没有声称还原每一实际闰月位置；没有将太阳度数、平均岁实、真实回归年混作同一现代常数。古历元的象征性设定、岁名超辰问题、司马迁正文与后续附表归属仍见[纪年与异说](../考证/史记-卷026-纪年与异说.md)。整卷源文和校勘均保留，计算与版本问题各有确切位置。

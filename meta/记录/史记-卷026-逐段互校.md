### 底本、对照文本与证据边界

本页记录实际核读的数字见证，不冒称校遍所有刻本。四库在线文字是转录，不等于本轮已经逐叶检查原刻影像；下列写错、异数均明确指所见网页。三个网页有共同的《史记》及三家注传统，不能按网址数量当作三份相互独立的古代证据。原字完整存入来源页，白话及校读不回填引文。

底本90个物理行，按两处明确粘连拆成92个阅读单元：P001—P011共11段序文，H001—H002两项篇题／表前引语，R001—R076历表76行，N001尾注，M001现代评论标签，Z001唐代述赞。两处拆行均不补原来没有的句号，重复的曆術甲子篇也保留。来源页所有引文依原顺序连接、去排版空白后为3970字，与原卷逐字相同；这个总数包含现代评论和述赞原标签，不能误称3970字全属司马迁本文。

### 11段序文逐项核读

<a id="p001"></a>
#### P001｜孟春建正、昼夜与岁时

[底本全文与释读](../../sources/摘录/史记-卷026-历书.md#p001)

**实际对读：** 底本物乃，纯正文物廼，三家注物迺，四库物廼；保留乃。底本撫十二節，三家注撫十二〔月〕節的月是整理补字，四库无月；底本不补。句读在冬分／时鸡之间有差别，不能由标点另造天象。

**读法与层次：** 索隐称开头至十二月节源于《大戴礼》虞史伯夷之辞，正不率天以下是孔子所称周太史之辞；这是注家的引书判断。正义以寅至丑的十二辰释后半，原文十二节不能机械译成现代十二个节气。

<a id="p002"></a>
#### P002｜易姓受命与改正朔

[底本全文与释读](../../sources/摘录/史记-卷026-历书.md#p002)

**实际对读：** 所对三种数字正文均具此段，无整句删漏；四库与上段连排而非缺段。

**读法与层次：** 索隐以天元为元气行运所至，说明段落的王朝受命论性质；原文不提供某次改历的具体年号。

<a id="p003"></a>
#### P003｜黄帝考历与五官

[底本全文与释读](../../sources/摘录/史记-卷026-历书.md#p003)

**实际对读：** 所对正文保留神农以前、黄帝考历、五官和民神异业诸句；神祇／神祗等字样随见证不同，底本神祇照录。

**读法与层次：** 索隐引《系本》《律历志》的羲和、常仪等名单属注，不混入正文。正义此处所引月法29+43/81，与表内可复算的29+499/940并非同数；历术模型与颁行太初法分辨见数值复核。

<a id="p004"></a>
#### P004｜重黎分职

[底本全文与释读](../../sources/摘录/史记-卷026-历书.md#p004)

**实际对读：** 底本少暤，四库少皥；菑、薦等字样存各本形体，核心重司天、黎司地均保留。

**读法与层次：** 集解解释火正，索隐评刘氏疑南字及臣瓒火似北之说；本页原火正不改北正。不能把注家争辩变成原文已有的两个并列任命。

<a id="p005"></a>
#### P005｜尧羲和、舜禹历数

[底本全文与释读](../../sources/摘录/史记-卷026-历书.md#p005)

**实际对读：** 纯正文对重黎加顿号，底本连写；三家注申戒的一作敕是注中异文，底本戒照录。全段无实质删漏。

**读法与层次：** 孟陬、摄提、斗建、月名的解释分属古注；天之历数并不是给出可机械换算的绝对年份。祥瑞、风雨与德治因果保留其古代叙事层次。

<a id="p006"></a>
#### P006｜夏殷周三正

[底本全文与释读](../../sources/摘录/史记-卷026-历书.md#p006)

**实际对读：** 三种对照均保留正月／十二月／十一月及三王之正循环的论述。

**读法与层次：** 月序按相对历法理解，不能把周正十一月写成公历11月，亦不由轮转理论补出各朝缺失历日。

<a id="p007"></a>
#### P007｜周衰、闰三月与置闰原则

**读法与层次：** 原文春秋非之与后文成套话语应和《左传》文公元年对读，不把它们全称《春秋》经的逐字引句。韦昭注以邪为余分，音、古注和原字分层。

<a id="p008"></a>
#### P008｜邹衍与秦的水德正朔

[底本全文与释读](../../sources/摘录/史记-卷026-历书.md#p008)

**实际对读：** 纯正文与底本战国并争用并，三家注及四库常作並；核心邹衍、五德、德水、十月、尚黑均存。

**读法与层次：** 禽敌的禽是擒取义，五胜为五行相胜。秦未暇整顿是本篇评价，不扩写成没有历法。邹衍的活动年代与秦统一后制度不能合并为同年。

<a id="p009"></a>
#### P009｜汉初北畤与承秦

**读法与层次：** 原段跨高祖至高后。北畤建置的事件、张苍历说及沿用制度不因同段而复制为同年新事。

<a id="p010"></a>
#### P010｜文帝改历建议的压缩叙述

**读法与层次：** 自黜不能单凭本段推为黄龙出现当年罢相；与本纪、封禅书、张苍列传分年核对，见纪年与异说。黄龙是报告和政治解释，非现代已验证动物观察。

<a id="p011"></a>
#### P011｜太初诏与历元

[底本全文与释读](../../sources/摘录/史记-卷026-历书.md#p011)

**实际对读：** 纯正文断作招致方士，唐都分其天部；底本及三家注断作招致方士唐都，分其天部。正文未能詹、已詹均保留，徐广注售、汉书讐是校释。名察度验与《汉书》名察发敛的差别由索隐指出，不用后一词替换正文。

**读法与层次：** 索隐释夏至为夏至、冬至，不能译颁诏当日恰是夏至；原夏字不改冬／夏正／夏时。三家注索隐改以建寅，四库在线对应注改以建子，正文与夏正同保留；改元、改官、封泰山在本段压缩概括，须分别核年。

### 篇题、历元与表体

底本P011后先独列曆術甲子篇（H001），下一物理行又以曆術甲子篇太初元年起（H002）。三家注网页的节标题和带索隐的篇题也重出；纯正文网页在卷前及表前列题。主底本的篇题重出原样保留，不由网页排版反推多出一篇正文。索隐称甲子篇取甲子日作为阳气支干之首，不是说这个年份为甲子岁。

H002所列焉逢摄提格是本篇的甲寅岁名；《汉书》另有丙子纪岁，后汉历志及四库考证又以丁丑与之讨论。岁名、实际年干支、推算历元必须分别说明。索隐维护此篇甲寅并以历法不同解释《汉书》之异；四库卷末臣照按主张甲寅是托始历元，批评后人径当实际年。两说各署其名，本轮不以“相差三年所以全表错误”取代研究，也不靠表内循环吻合宣布实际年即甲寅。

### 表后尾注：日余分、括字与后加判断

底本N001写“小餘者，月也”，纯正文、三家注、四库在线也有此句。正义指出小余是日之余分，不能从原尾注把348解释为348个月；索隐有从每两月余58分等角度解释小余的文字，不能因此取消940为分母的日分含义。

底本端（旃）蒙保留括字，纯正文端蒙，三家注端（删除线旃）蒙，四库转录端旃蒙。标删格式、括字和正文原有称呼分列，不能把三字连成新的完整干名。尾注只举丑、寅和丙等少数例子，并不完整。

右历书以下归属的正义，三家注数字转录为“恐褚先生沒後人所加”，四库转录为“恐褚先生及後人所加”。所指是尾注范围，且两个数字见证字有差别；本轮不靠“没”字的现代断句把它直接改述为已经查明某位补作者。正北、西、南、东的子、酉、午、卯时来自章首的冬至分数，不是四个地理站点。

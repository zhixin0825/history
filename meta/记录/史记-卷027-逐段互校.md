## 内容

P号按本项目主底本物理行，三家注的p0为篇题注，p1—p125正好承接本卷125单元。下面逐项说明材料性质、异字异数、古注署名与释读限度；它是实际核读记录，不是未经人工判断的逐字符版本差异全集。近似字形、简繁、标点异文不自动视作独立史实。

### P001｜中宫天极与紫宫的帝王家室

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p001) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p1)；整书原始物理行L2645。

本页所对三家注是另一转录见证，并非主底本的同版注释。“句”读如“钩”，指弯曲；“太一”在这里是神名，不直接改写为某颗现代恒星。三家注《索隐》指出，《星经》把后面四星称为四辅，另以勾陈六星配六宫，和本段的四星后妃说不同。正文的星数和角色均按主底本保留，不把别家星图合成同一套。

<a id="p002"></a>
### P002｜阴德 天枪 天棓与阁道

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p002) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p2)；整书原始物理行L2646。

“直”是正当、相对，“兌”在此读为锐，“汉”是银河。“隨北端兌”的字句不甚明晰；三家注《索隐》另讨论“隋斗端兌”，并记斗一作北，不能把注本的字直接换入主底本。《正义》所引阴德二星、天一一星，亦与正文“三星”的列法不同。

<a id="p003"></a>
### P003｜北斗的三时建指与天时统摄

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p003) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p3)；整书原始物理行L2647。

本段把实见的北斗方位、按时取指的月建法、地上分区和帝车比喻并列，不是说北斗实际驾驶诸天体。“殷”古注释为当或中。“旋、璣、玉衡”“七政”有星名、仪器及日月五星等不同解释，三家注《索隐》并存诸说；正文不强定为一种现代仪器。

<a id="p004"></a>
### P004｜文昌 三能与辅星的君臣象征

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p004) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p4)；整书原始物理行L2648。

“三能”的能，三家注《集解》引苏林读作台，即三台，正文仍存“能”。《集解》以天理四星解释贵人之牢，以北斗第六星旁的星解释辅星。这些为具名古注的辨认，不把注家的新增星数混入正文。

### P005｜斗柄旁的矛盾与庶民牢狱

“句圜”是弯曲成环，“属”是连属；“内、外”按《集解》所引孟康、晋灼理解为距北斗的近远。《索隐》把此牢联系贯索，《正义》却说贯索九星，和正文十五颗不同，不能据注删改星数。

<a id="p006"></a>

三家注《集解》引李奇说“角”指光芒形成的尖角，不是把恒星本体说成有实体的角。“兵起”是占候判断，本段不是一次战争的观测实录。

<a id="p007"></a>
### P007｜苍龙房心与天市的宫廷市肆

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p007) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p7)；整书原始物理行L2651。

“驷、骖、舝”采用车马意象；舝读辖，是车轴端键。“其阴”不据现代理解强补绝对方位。三家注《正义》所举两旗各九星、天市二十三星，与正文旗十二星、天市四星不是相同数目；正文与注说分列，不能拼成一幅无差异星图。

<a id="p008"></a>
### P008｜角亢氐与摄提的时节职掌

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p008) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p8)；整书原始物理行L2652。

“李”三家注《索隐》释为理，即法官，不作姓氏。“疏庙”的疏，古注释外，庙又有朝的异说。“其南北两大星”与《正义》所述南门在库楼南的定位并不相同，此处不擅移方位。本段的摄提为星官，后文摄提格又用于岁名，须随语境分辨。

<a id="p009"></a>
### P009｜尾宿九子与箕宿口舌

“斥”是远离。“敖客”三家注《索隐》引宋均以调弄和宾客往来解释，《正义》读敖如傲。九子、君臣、口舌都是象征角色，不据此补出具体人物或史事。

<a id="p010"></a>
### P010｜荧惑犯角与守房心

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p010) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p10)；整书原始物理行L2654。

“火”在此指荧惑星，不是地上的火灾；《索隐》引韦昭明确如此释读。末句承前省去犯守的动词。《正义》还举箕尾氐及自生芒角等说法，那是注释扩展，不增入本段原文。

<a id="p011"></a>
### P011｜朱鸟权衡 太微廷与轩辕后宫

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p011) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p11)；整书原始物理行L2655。

“三光”指日、月、五星三类；“司”在此为察看，“隋”据古注读为垂列。正文十二星、诸侯六星、少微五星，与《正义》太微垣十星、内五诸侯、少微四星等数目不全相合，不调成一版。“中坐，成形”古注有犯帝座、祸福形见及刑戮解释，本释采取前者，不将诛杀写成已发生事实。

<a id="p012"></a>
### P012｜井鬼 水道关梁与刑祸象征

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p012) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p12)；整书原始物理行L2656。

“质”是本段星象名称，不径以现代星团名称替代。“德成衡”等属占候归类；三家注《集解》引晋灼释“观”为占，《索隐》又以王者游观解之，并引“德成潢，败成钺”异文。此处显示解释分歧，不能把两种“观”义并成确定结论。

<a id="p013"></a>
### P013｜朱鸟的喙颈嗉翼

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p013) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p13)；整书原始物理行L2657。

“注”三家注《索隐》说《汉书·天文志》作喙；“素”释为嗉，即鸟储食之处。正文“员官”不依注中“员宫”径改。这里的七星是星宿名称，不能与北斗七星或日月五星的七政混淆。

<a id="p014"></a>
### P014｜轸 长沙与天库楼的车马占

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p014) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p14)；整书原始物理行L2658。

主底本“星星不欲明”两个星字均保留，释读按指长沙理解，不偷偷删去重字。《正义》所述长沙明而主长寿，与本段明而主兵的占辞不同。“无处车马”语意简短，只释车马不得安处，不补战争地点、战果。

<a id="p015"></a>
### P015｜咸池五潢与三柱

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p015) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p15)；整书原始物理行L2659。

“火、金、水”均为行星简称，不是火焰、金属和水直接进入星区。《正义》分别说咸池三星、五车五星、三柱九星，反映星官区分和解释层次；主底本“咸池，曰天五潢”的关系照存，不据注重写名称。

<a id="p016"></a>
### P016｜奎娄胃与廥积

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p016) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p16)；整书原始物理行L2660。

“封”在封豕中有大义，不是封国；“廥”三家注《集解》引如淳解释为积存刍草的地方。水道、聚众、仓储是星官职掌，不等于本段记载了实际水利或储粮工程。

<a id="p017"></a>
### P017｜昴毕 附耳与天街分界

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p017) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p17)；整书原始物理行L2661。

“白衣会”按丧服聚会释，不译成某次已经发生的集会。“罕”与捕猎网具的意象有关。天街阴阳国的分配，正文只作原则性称呼；三家注《集解》和《正义》的地理解释各有表述，不把它直接套成今天的国界。

<a id="p018"></a>
### P018｜参宿白虎及其周围诸星

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p018) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p18)；整书原始物理行L2662。

“参”读shēn；“罚”古注记亦作伐。“葆旅”古注有采野生可食之物与守御军旅两说，本释采用《集解》《正义》的前说，并保留异解。正文弧四星，《正义》说九星；西面“九星，三处罗”与注中天旗九、天苑十六、九游九也不能拼成同一计数。“兌”指尖形；这里的尺寸、颜色及见否是古代观象描述，不增配未经核验的现代星座表。

<a id="p019"></a>
### P019｜附耳入毕的兵事占

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p019) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p19)；整书原始物理行L2663。

本段与P017附耳摇动的占辞相关，但现主底本独立成行，照其顺序单列；“入”是所见位置关系，不能从这一句推定一次有确年可考的天象或战争。

<a id="p020"></a>
### P020｜玄武虚危与哭泣盖屋

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p020) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p20)；整书原始物理行L2664。

三家注《索隐》引宋均以危上一星、旁两星的形状解释盖屋；《正义》却认为危当作架屋，盖屋另有星官，疑正文有误。此为古注提出的疑问，本页保留“盖屋”，不代为裁改。

<a id="p021"></a>
### P021｜羽林天军 北落与危东六星

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p021) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p21)；整书原始物理行L2665。

主底本“水，［水］患”的方括号与补字一并保存。末句司空，《正义》认为应是司命等星，并说司空只有一星且不在危东，这是注家的辨误意见，不据此改正文。前句把五星入军总说为兵起，后句又列木土吉占，是原文规则的层次差别，不抹去其张力。

<a id="p022"></a>
### P022｜营室 王良与渡汉诸星

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p022) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p22)；整书原始物理行L2666。

“绝汉”是横越银河，绝不是断绝；“王良策马”是御者与马的星象比附，不是在叙述人物出行。此处天驷为银河四星，与P007称房为天驷不可无条件合并。《正义》释江为尾北天江，和正文随天潢而叙的关系须分别看待。

<a id="p023"></a>
### P023｜杵臼 匏瓜与鱼盐物价

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p023) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p23)；整书原始物理行L2667。

正文杵臼四星，《正义》另述杵臼三星等位置，不据注减字减数。“守”是行星或其他可见星体在该星区停留的占候用语；正文没有说明是哪一种星，不能擅定。鱼盐贵是预测内容，不是这段已证实的物价统计。

<a id="p024"></a>
### P024｜南斗 建星 河鼓与织女

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p024) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p24)；整书原始物理行L2668。

正文把牵牛、河鼓分列；三家注《索隐》引《尔雅》又记河鼓亦称牵牛，故不能把所有古书中的牵牛都当作一个无歧义名称。“天女孙”《集解》记孙一作名，《索隐》又作“天孙”并引天子女之说，本释依主底本女孙义，不消除异说。

<a id="p025"></a>
### P025｜岁星的五行归属与赢缩占法

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p025) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p25)；整书原始物理行L2669。

“舍”指星体止宿的区域，“命国”是指定所应分野；“将亡”《正义》把将读为将帅的将。本段写“义失”，而《正义》所引《天文志》配木星以仁，不能用后者替换正文。本段既有所在国受庇护的总说，也有赢缩致凶的条件说，按层次分别解释。

<a id="p026"></a>
### P026｜摄提格岁与监德

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p026) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p26)；整书原始物理行L2670。

“岁阴”是与岁星相配的纪年位置系统，不当作另一颗实际看得见的行星。“有应见柳”只说对应征象在柳，不直接译成岁星本身移到柳。《索隐》指出这组条文取石氏说，并说《汉书》兼载甘氏及太初星历、所在宿不同，不能把这些表当作同版同年的实测记录。

<a id="p027"></a>
### P027｜岁星的顺逆行与十二年周天数

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p027) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p27)；整书原始物理行L2671。

这里的“度”用古代周天尺度，不能不加换算就等同于现代三百六十度制。三十又十六分之七度乘十二，得三百六十五又四分之一度；以一年三百六十五又四分之一日配日行十二分之一度也得到同一年行数，这是文本内部可核的算术关系，不代表其模型符合现代精密轨道。“出、入”是见伏，不是说行星每日从东升西落的普通周日运动。

<a id="p028"></a>
### P028｜单阏岁与降入

[主底本完整原文](../../sources/摘录/史记-卷027-天官书.md#p028) · [三家注相应段](../../sources/摘录/史记-卷027-三家注对照.md#p28)；整书原始物理行L2672。

## 年数

| 检查 | 算式／结果 | 判读 |
|---|---|---|
| 汉兴39年 | 206−168＋1＝39 | 含起年相合；不从前202年称帝起算 |
| 酸枣至瓠子 | 168−132＝36 | 汉志三十六岁相合；史记四十余年不合，原文不改 |
| 瓠子至宣房 | 132−109＝23 | 与二十余岁相容；不是逐年灾情统计 |
| 郑国渠至六辅渠 | 246−111＋1＝136 | 与汉志含首尾136岁相合；纯相减为135 |
| 长安漕渠 | 开工前129年；三岁而通 | 可知多年工程，不能仅据“三岁”确定竣工公元年及月日 |
| 龙首渠 | 十余岁，颇通 | 既无完整起讫年，也不是已全部竣工的报告 |

|---|---|---|

| [P010](../../sources/摘录/史记-卷029-河渠书.md#p010) | 万余顷、亩十石；井深四十余丈，相关地下段十余里 | 亩产为承诺，末明言未得其饶；未给统一古尺，不换现代米或立方米 |
| [P011](../../sources/摘录/史记-卷029-河渠书.md#p011) | 数万人、群臣负薪、淇园竹楗 | 无总劳役日、造价或断面数据，不计算凭空的成本收益率 |
| [P012](../../sources/摘录/史记-卷029-河渠书.md#p012) | 两歌、二渠、宣房宫 | 两歌不是两次独立堵口；二渠与禹旧迹是书中说法，不替代古河道实测 |
| [P013](../../sources/摘录/史记-卷029-河渠书.md#p013) | 各地“各万余顷” | 项目边界、是否重叠不明，不按地名个数相乘求全国总量 |

钟、石、顷、亩、里、丈保留各底本文字。以上算式只检验文内计年或计划含义，不证明产量真实、工程投资回报或现代量制换算。三种明确非全面成功的结局都保留：河东渠田废弃、褒斜不可漕、龙首未得其饶。

# 《平准书》｜财政、数量与单位核对

[原文](../../sources/摘录/史记-卷030-平准书.md) · [汉书互校](../../sources/摘录/史记-卷030-汉书互校.md) · [通鉴古注](../../sources/摘录/史记-卷030-通鉴互校.md) · [纪年取舍](../考证/史记-卷030-纪年与异说.md)

| 对象 | 原文或计算 | 解释边界 |
|---|---|---|
| 汉初粮马价格（P001） | 米石万钱、马匹百金 | 地域、时段未细列，不当成全国统一平均价格 |
| 四铢半两（P003） | 重四铢，文半两 | 钱重与铭文分开，不依铭文直接换算实重 |
| 文帝改钱至皮币（P016） | 前175→前119，差56年；本卷作“四十余年” | 是真实的相对纪年张力，不用含首尾的1年差掩盖；不移动明确帝纪年条来凑数 |
| 皮币（P016） | 方尺，直400000钱；苍璧仅数千（P030） | 制度额定与市场材料成本不等同；不译作流通纸钞 |
| 白金（P017） | 龙：八两／3000；马：500；龟：300 | 后两类未给确定重量，不推造重量比例；非铂金币 |
| 武功爵（P009） | 级十七万、凡直三十余万金 | 古注对级数、递增与总价争论详[摘核](../../sources/摘录/史记-卷030-通鉴互校.md#t-price)；不把不确定金额计算成精确财政进项 |
| 算缗（P023） | 2000钱一算；部分经营4000钱一算 | 据胡注一算120钱，可分别算120/2000=6%、120/4000=3%；仅为所报财物的名义征算比，不是收入税率或已知逐年税率 |
| 车船（P023） | 普通、商车有差，船五丈以上一算 | 豁免句读照存；不把所有车船都概括一律同税 |
| 告缗分赏（P023、031） | 所得的一半 | 不是把申报财产中任意一半都直接分给告者；要结合查没对象与法律措辞 |
| 迁民（P015） | 七十余万；帝纪725000口 | 725000在“七十余万”的范围内，但时间、地区范围并非完全相同，不能相加为第二批人口 |
| 浑邪迎车（P012） | 史记20000乘；汉志30000两 | 两书差10000，不代表可以平均为25000；车乘不是人数 |
| 运输（P008） | 十余钟致一石 | 不同单位，不直接给出百分比运输损耗 |
| 战费（P009、012、020） | 金、钱、人马、车甲转漕分列 | 本卷多次明言部分费用“不与”，不能把不齐全且单位不同项目相加成“总军费” |
| 牧畜／官秩（P025、028） | 外繇400人；郎至600石 | 外繇非赠奴人数，600石非购官应缴粮价 |
| 赤侧（P032） | 一当五 | 是法定交换或纳款折值，不是含铜量或重量五倍 |
| 没入奴婢（P035） | 以千万数 | 原文大量概称保留，不直接换成精确1000万人的人口统计 |
| 官漕（P038、048） | 四百万石；后来六百万石 | 只是不同叙述时段的量级；不声称严格同比增长50% |
| 边马（P041） | 三岁而归，息什一 | 以繁殖、归还为语境，不能直接等同每年10%现金利息 |
| 卜式金赏（P044） | 史记60斤；汉书40斤 | 差异保存，不选择较大数写成诸本一致 |
| 平准成效（P048） | 漕600万石、均输帛500万匹；黄金再百斤=200斤 | 仓储、货物流量、个人奖赏是不同项目；不能拼成净利润或财政余额 |

上述算术是对原文口径的复核，不作古代货币到美元、人民币、现代吨数或购买力的无据换算。单位说明与原数据均可沿原文和互校定位。

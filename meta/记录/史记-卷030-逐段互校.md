# 《平准书》｜逐段互校记录

[完整史记原文](../../sources/摘录/史记-卷030-平准书.md) · [实际采用的汉书原文](../../sources/摘录/史记-卷030-汉书互校.md) · [通鉴与古注摘核](../../sources/摘录/史记-卷030-通鉴互校.md) · [纪年与异说](../考证/史记-卷030-纪年与异说.md)

《汉书·食货志》与《平准书》大量同文，相似不等于两份互不相关的独立见证。此表覆盖全部正文：有的逐句平行，有的《汉书》删略而另见卜式传，有的只是主题相关；一律说明，不用自动匹配率代替史学互证。

## P001｜战后匮乏与汉初钱币

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p001)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h001)。

这是汉初多年的总叙，不把粮价、驾马困难和所有币制变化都定为前202年同一天；“一黄金一斤”保留底本，不能据此制造一条足够明确的铜钱兑换率。

## P002｜抑商规定与国家、皇室收入的区分

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p002)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h001)。

制度沿革跨高祖、惠帝、高后数朝，放在战后背景附录。“山东”指关隘以东的广大区域，不等于今日山东省；“私奉养”是原书对财政归属的划分，不替古代建立现代预算科目。

<a id="p003"></a>

## P003｜四铢半两钱与吴、邓铸钱

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p003)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h002)。

四铢钱见《汉书》文帝五年，即前175年；吴王反叛另在前154年，不能随本段倒放在前175年。吴、邓开始经营铜山和后来的禁铸也不是本年同时完成的三条事件。

## P004｜以边地输粟换爵

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p004)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h003)。

对接前168年晁错建议与文帝入粟授爵条。《汉书》提供不同输粟量与爵等；不是每位普通农民都可无成本获得高爵，也不把爵位等同实际官职。

## P005｜景帝时期卖爵与宫苑扩张

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p005)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h004)。

本段没有给旱灾的确年，《汉书》也只以“其后”连叙。置景帝末年页面的跨年附录，不把此事直接等同景帝纪任一场已知旱灾。

<a id="p006"></a>

## P006｜文景积蓄、武帝初年的富足与兼并

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p006)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h004)。

富足与兼并是同段两面，不据此宣布所有农户没有贫困。“七十余年”与“即位数岁”是回顾性的时段描述，不把这一幅社会图景全部归到武帝即位当年。

<a id="p007"></a>

## P007｜多方向用兵与筹资压力

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p007)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h005)。

这是跨年的支出清单。底本“彭吴贾灭朝鲜”句读、文字有疑，《汉书》作经营秽貊、朝鲜与沧海郡；不能写成此时已灭卫氏朝鲜，更不能把前108年的战争提前。

<a id="p008"></a>

## P008｜筑朔方与长途转运耗费

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p008)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h006)。

前127年接取河南地与筑朔方；西南、沧海是并列背景，不全定同年。钟、石单位不同，不能把“十余钟致一石”直接算成十比一的损耗率；免役与做官也分属不同奖励。

<a id="p009"></a>

## P009｜军赏耗财与武功爵

前124、123年的作战分别对接旧条，武功爵按《通鉴》前123年六月。原文“级十七万”“凡直三十余万金”及爵级、价额的古注意见不同，不拼出一张自称确定的十七级价目表。

## P010｜经义断狱、严法与诸王案件

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p010)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h008)。

本卷将三王并列，既有年页按本纪与年表把淮南、衡山置前122年、江都置前121年；“其明年”不能把三案合并为同一场已经起兵的战争。

<a id="p011"></a>

## P011｜公孙弘的节俭与社会趋利

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p011)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h008)。

这是作者对政治风气的判断，不把公孙弘的个体生活方式直接证明为全国节支实效，也不能据此判定每名被荐士人都贪财。

<a id="p012"></a>

## P012｜河西胜利与接纳浑邪降众的开支

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p012)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h009)。

对接前121年既有河西战事、浑邪归降。《史记》迎接车辆二万乘，《汉书》食货志三万两，不合并成同一个无争议的精确数字；“获首”与“虏”也不全部改写成被杀人数。

<a id="p013"></a>

## P013｜水利工程与军费相互叠加

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p013)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h010)。

接卷029已整理的前129年漕渠及跨年工程背景，不重复制造一次开工。“历二三期、功未就”是某阶段的记载，不与其他篇章后来“三岁而通”的完成记载混为矛盾或同一时刻。

<a id="p014"></a>

## P014｜养马、安置降众与动用内藏

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p014)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h011)。

“县官”在这里主要指国家、朝廷，不能逐句译为县令。“损膳”与“出内藏”说明应急措施，不证明此后宫廷已经持续全面节俭。

<a id="p015"></a>

## P015｜灾民迁徙与长期安置

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p015)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h012)。

本卷以浑邪归降次年连叙，接前120年灾荒背景；《武帝纪》前119年冬报告累计迁七十二万五千口，地点还包括会稽。两条口径、时点不同，不造两次各七十余万的迁民。

<a id="p016"></a>

## P016｜白鹿皮币与额定价值

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p016)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h013)。

按《武帝纪》前119年。它兼具朝聘礼仪与强制购买性质，不等于普通市场广泛接受的纸币；原书把钱轻与物贵连在一起，不据此计算现代意义的通胀率。

<a id="p017"></a>

## P017｜银锡白金三品与三铢钱

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p017)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h014)。

白金是本段银锡币，不是现代化学所指的铂。马、龟两类只说逐次减轻，不填未载重量。三铢、五铢的先后与《武帝纪》“罢半两”用语并列说明，不删除差异。

<a id="p018"></a>

## P018｜东郭咸阳、孔仅与桑弘羊

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p018)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h015)。

“十三侍中”回叙桑弘羊的早年，不是说这次任用时才十三岁。官名遵本卷的大农体系；《汉书》某些段落称大司农是书写差别，不倒推此时已完成太初改名。

<a id="p019"></a>

## P019｜买复与征役不足，谪吏凿昆明池

《武帝纪》明确前120年发谪吏穿昆明池，早于前119年改币，显示本卷叙事有回顾，不机械套相邻段落的“于是”。底本“（通）适”校符照存。

<a id="p020"></a>

## P020｜漠北远征后的赏赐与欠俸

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p020)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h017)。

对接前119年漠北作战。人数、军马损失、金与钱不能相加成一个总耗费；本段的军马数与P009“士马”也不是同一统计口径。

<a id="p021"></a>

## P021｜由三铢轻钱转向五铢

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p021)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h018)。

《武帝纪》将“罢半两钱，行五铢钱”明记元狩五年，即前118年。此前的三铢叙述与本纪用语均保留；郡国铸五铢和后来三官专铸不是同一阶段。

<a id="p022"></a>

## P022｜盐铁官营的组织办法

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p022)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h019)。

官府掌控并不表示每道生产工序都由官吏亲手做，也不把脚钳误译为直接斩脚。政策起议与各地落实有过程；《通鉴》系前119年，原书本段无单独确日。

<a id="p023"></a>

## P023｜算缗、车船算与瞒报处罚

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p023)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h020)。

前119年“初算缗”与前114年扩大告缗、告发分赏的明确年条分开。二千、四千是财产计税基数，不是利润额；车船条句读和豁免对象保留原文，不把它概括为人人一律同税。

## P024｜表彰卜式以劝富户助财

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p024)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h021)。

没有独立确日，放在前119年筹财的背景附录，与P025、P026合成一条跨年生平，不将召拜、牧羊、县令、齐相写成同一年连续任命。

<a id="p025"></a>

## P025｜卜式由牧羊致富到两次助国

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p025)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h022)。

十余年牧羊、初请、数年不报、再助迁民均是回叙。外繇四百人不是赐四百名奴婢；原段记一种徭役相关收益或复除权益，具体折算不擅定。

<a id="p026"></a>

## P026｜牧羊比喻与卜式的升迁

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p026)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h023)。

这是从牧畜到治理的比喻，不能把整套国家政策等同驱逐“坏羊”。《汉书》续写转齐相；具体任职年不由“岁余”逐级拼出。

<a id="p027"></a>

## P027｜孔仅升任与早期均输

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p027)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h021)。

本卷“三年中”不提供完整起讫，不能直接据前119年加三定成前116年。此处的渐置均输早于元封元年全面部署，不能说前110年以前完全没有均输。

## P028｜入谷补官

六百石是官秩，不是本段规定的购官粮价。确年不足，作为筹资制度的跨年背景；与文帝入粟授爵也不能当成同一政策完全不变地重复。

<a id="p029"></a>

## P029｜盗铸、赦免与巡察

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p029)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h024)。

“后五岁”与张汤尚在、武帝纪前117年遣博士巡行的年序难完全相合；不把所有人数都硬定到前114或113年。“天下大抵皆铸”是范围极广的概括，不是逐户普查。

<a id="p030"></a>

## P030｜颜异之死与腹诽

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p030)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h024)。

本卷本段未给死年。《通鉴》据百官公卿表的任年把颜异之死系前117年，并反对徐广系前119年的说法；年页采用前117年而保留异说，不新造确月。腹诽是当时的定罪解释，不是编者已知其内心。

<a id="p031"></a>

## P031｜由劝输转向扩大告缗

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p031)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h025)。

算缗是征算与申报，告缗是借告发追查瞒报，二者关联但不等同。按《武帝纪》前114年明确分赏条处理，不把所有告缗执行压在同日。

<a id="p032"></a>

## P032｜赤侧钱与白金失去信用

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p032)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h026)。

法定一当五不是金属重量五倍。白金贬值、禁令和最终废止有历时；结合张汤死年可看前115年前后的背景，不给本段未载的首次发行确月。

<a id="p033"></a>

## P033｜张汤之死的评语

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p033)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h026)。

实际日期沿《武帝纪》前115年冬十一月。评价是一种史家概括，不证明全国人意见一致；其他篇章的案情仍在原年页，不再添一次死亡。

<a id="p034"></a>

## P034｜三官专铸与地方旧钱退出

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p034)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h026)。

按张汤死于前115年、其后二年暂接前113年；《通鉴》却将三官专铸编在前115年，必须留异说。首次五铢、赤侧与专铸各是一层，不以制度后来持续证明一次性立即完成全国回收。

<a id="p035"></a>

## P035｜告缗执行、财产没收与民间反应

[史记原段](../../sources/摘录/史记-卷030-平准书.md#p035)；[汉书对照](../../sources/摘录/史记-卷030-汉书互校.md#h027)。

这是跨年执行与作者概述，不用“以千万数”编制精确的奴婢人口表，也不把告发一概写成经过独立核实的真实逃税。官府收入增多与民众福利提高不是同义句。

<a id="p036"></a>

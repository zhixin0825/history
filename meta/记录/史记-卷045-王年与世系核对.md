## 内容

### 算法与正文边界

公元前年数递减。给定元年B，第n年为B−n＋1；本式只能检查换算，不能证明元年B本身没有史料问题。卒年、同年承位、次年元年分别处理。全卷按源序保存的原字与每个实际落点在[单元数据](史记-卷045-单元数据.json)、[引句清单](史记-卷045-新增引句清单.json)；主线既有《左传》、两年表和秦晋赵各篇均继续保留。

### 春秋韩氏及世系异文

| 人物／阶段 | 本文与古注 | 处理 |
|---|---|---|
| 韩武子、韩万与韩厥 | 同周姬姓，封韩原；正文“后三世”，注引《世本》万—赇伯—定伯简—舆—厥 | 祖源与韩万登场前事随前709阅读；世数不平均折算绝对年，也不说韩厥此时已经活动。 |
| 韩厥保赵 | 景公三年异传、十七年复赵；鞌战十一年 | 救孤完整异传附前583同号注；鞌战前589、增军赏功前588分开。 |
| 韩厥退休 | 主TXT（十）［七］，注本仍十；经传襄七 | 退休前566；若十年得563，作为异文。韩厥卒与韩起迁州无独立确年，不压到退休当年。 |
| 韩宣子韩起 | 季札聘晋、分县、攻范中行在本文连属同人 | 经传前514韩起已卒，分县由魏舒主持；前497领军为韩不信，不能使韩起死后十七年再作战。 |
| 贞子／平子须、简子、庄子、康子 | 注引《世本》与旧本对简庄二代有无不同；迁平阳者又见景子 | 保存各名与异传，不定无依据的承继年；康子参与前453灭智为确切事件入口。 |
| 武子至文侯 | 景虔／景子处、列／武侯、文侯有无等异说 | 本篇主线与古注所引不同系统同时列明，不能把异名直接增为数位额外国君。 |

### 君年框架不能机械拼接

| 君主 | 本篇旧年链的元年至末年 | 年数复核与采用边界 |
|---|---|---|
| 韩武子 | 424—409 | 424−16＋1＝409；景侯于409承位、408元年。 |
| 韩景侯 | 408—400 | 408−9＋1＝400；403为六年、受周命列侯。 |
| 韩列侯 | 399—387 | 399−13＋1＝387；与文侯承继合本篇，不能让尾句“是岁魏文侯卒”把魏文侯从396推后到387。 |
| 韩文侯 | 386—377 | 386−10＋1＝377；哀侯376元年。 |
| 韩哀侯 | 376—371（原六年链） | 原六年得371；既有主线按《纪年》魏武侯同步暂取374死亡。这是同一死亡的异年，371不再死一次。 |
| 韩懿侯 | 370—359（续原哀六链） | 十二年得359；若从374死亡并次年起元续算，懿元373、末362；另有同年起元的374—363排法。三种算法不是同一无缝年链。 |
| 韩昭侯 | 358—333（本篇后半与既有编年相合的链） | 二十六年得333。现代常见362起元会把八年、二十二年分别算为355、341，不能仍同时把它们称作351、337。“362—333”本身含30年，和本文26不是同一计数。 |
| 宣惠王 | 332—312 | 二十一年得312；本篇十一年称王得322，与主线323有一年差；区鼠会保留322。 |
| 襄王 | 311—296 | 十六年得296；十二年是300，不是301；301是十一年唐昧败亡。 |
| 釐王 | 295—273 | 二十三年得273；华阳主条及其卒年同接273，次年桓惠元年。 |
| 桓惠王 | 272—239 | 三十四年得239；元年与卒年连贯，但中间上党、长平的本篇年次数值有错位，须逐事核，不整体平移。 |
| 王安 | 238—230 | 九年得230；五年得234，与秦篇韩非出使遇害233差一年。 |

懿侯、昭侯早段没有足够根据在不同系统之间唯一裁定全链。本轮不另加无争议的懿侯卒年条，而把“懿侯卒、子昭侯立”作为前358西山之战以前的承继背景附读；[前362上党会](../../years/bce-0400-0301/bce-0362.md)改称赵成侯与韩君，赵篇“昭侯”与韩篇年链矛盾留在同号注。[前361](../../years/bce-0400-0301/bce-0361.md)的回指也不再把该称号当无争议事实。

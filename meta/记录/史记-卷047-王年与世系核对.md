### 行旅和守丧时长

离鲁前497至返鲁前484，497−484＋1＝14，与“去鲁凡十四岁”按首尾计数可合；实际年度差为13，不说隔足十四周年。这是现有主条的对照，并不能消除本篇定14离鲁与各段“明年”的矛盾。[P020—P021](../../sources/摘录/史记-卷047-孔子世家.md#p020)、[P055—P056](../../sources/摘录/史记-卷047-孔子世家.md#p055)分别保留原句。

卫十月、蒲后月余、再居卫月余、居陈三岁、迁蔡三岁，属于不同叙事段的相对时长。陈、蔡、卫、齐的已知事件夹在其间，又有错年和跳叙；不能把这些数字机械相加，造出逐月不断的路线。三年心丧、子贡凡六年亦是相对时长及礼制说法，不未经辨析就写成前476、前473某日的确切终点。[陈蔡行旅](../../sources/摘录/史记-卷047-孔子世家.md#p026)、[葬礼与守丧](../../sources/摘录/史记-卷047-孔子世家.md#p078)。

### 家世、寿数与承继不能混算

孔氏先世从宋入鲁，本篇列防叔—伯夏—叔梁纥—孔子。弗父何让位、正考父三命益恭等是孟僖子遗言引述的远祖家风，不给出完整连续生年。南宫敬叔与孟懿子同属孟僖子之子，不能误作孟懿子的下一代。[P001与P004](../../sources/摘录/史记-卷047-孔子世家.md#p004)。

| 本篇世系次序 | 名字、字号、寿数或官历 | 可知与不可知 |
|---|---|---|
| 孔子之子 | 鲤，字伯鱼，年50 | 明言先父卒；无独立生卒年，不由父子年龄差倒算。 |
| 鲤子 | 伋，字子思，年62；困宋；《中庸》归于他 | 年龄、宋难、著述归属分别保存，不强定宋难年月。 |
| 伋子 | 白，字子上，年47 | 只给承继和寿数。 |
| 白子 | 求，字子家，年45 | 同上。 |
| 求子 | 箕，字子京，年46 | 同上。 |
| 箕子 | 穿，字子高，年51 | 同上。 |
| 穿子 | 子慎，年57；曾为魏相 | 本篇此处以子慎称之，不任意补姓名、任职年。 |
| 子慎子 | 鲋，年57；陈王涉博士，死陈下 | 前209陈涉起事提供活动时代，死亡原句未给独立年月。 |
| 鲋弟 | 子襄，年57；惠帝博士、后任长沙太守 | 只有帝王时期和官职先后；不从兄弟寿数倒算出生。 |
| 子襄子 | 忠，年57 | 本篇无其确年官历。 |
| 忠子及后代 | 武生延年、安国；安国生卬、卬生驩 | 安国为武帝博士，至临淮太守，早卒；不由“早”字自行定年龄。 |

上述寿数来自[P079—P084](../../sources/摘录/史记-卷047-孔子世家.md#p079)，没有各代生子时年龄，既不能相加为历年，也不能用一组现代谱表默改原文。孔子→鲤→伋→白→求→箕→穿→慎→鲋，本篇可数出孔子以下八层承继；别篇孔甲的“八世孙”等称谓及古注同人说另有计代口径，不能仅凭一数直接判定为异人或强行削去一代。[三家注p82](../../sources/史记三家注/卷047.md#p82)。

### 汉代官历和史家所处时代

高帝十二年过鲁祭孔，直接纪年依据是[《汉书·高帝纪》L103、L108](../../sources/本地分卷/汉书/汉书-卷001.md#L108)：十二年冬十月行程之后，记十一月自淮南还、过鲁以大牢祠孔子。本项目接前195既有高帝十二年主条；古十月岁首与现代历年不强作同月换算。《孔子世家》本段只给祭孔行为，没有自行提供年号。

惠帝前195承位，前194为元年，前188卒；孔子襄“为惠帝博士”只给任职时期，不等于元年任命，也不表示长沙太守任免与死亡全在一岁。孔安国“今皇帝博士”的相对称谓，在司马迁所处语境指汉武帝；不能因此指定世家某一段的成文日期。孔庙延续“至于汉”、卿相先谒庙的概括、司马迁访鲁与至圣评价另在西汉时期页，不回置前479。[汉代后裔与史家评论](../../sources/摘录/史记-卷047-孔子世家.md#p083)。

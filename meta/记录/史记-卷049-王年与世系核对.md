### 年龄与相对时长只作交叉检验

| 原句或旁证 | 对照 | 处理 |
|---|---|---|
| 代王立十七年 | 前196至前180，196−180＋1＝17 | 封代与即帝位各有史实锚点，不能理解为足17周年后再即位。 |
| 汉传文帝八岁封代 | 前203生至前196，203−196＋1＝8 | 生年另有汉四年明确记录，并非只由年龄倒算。 |
| 武帝4岁胶东、7岁太子、16岁即位 | 前153、150、141三点均相应前156出生 | 索隐引乙酉也合前156；不以主文“即位，生男”误归157。 |
| 薄太后后文帝二年 | 前157至前155年度差2 | 原文同时明记景前2，前155死亡与南陵经营起点不同。 |
| 窦太后后景帝六岁 | 前141至前135年度差6 | 建元六年与汉纪相合，汉传“元光六年”视为传本讹。 |
| 王太后后景帝16岁、元朔4年 | 对应前125 | 本篇原数保留；汉纪、汉传另明15岁／元朔3，实际采用前126。 |
| 卫后立7年而子立太子 | 前128至前122首尾计7 | 元狩元年四月丁卯立储另有汉纪明文，不以年度差6改为别年。 |
| 武帝70乃生昭帝、昭帝5岁立 | 与生94、立87、武帝生156不相合 | 汉纪及徐广校为昭帝8岁立，武帝70是崩时，生昭帝时传统计岁63。 |

“岁余不得幸”“入宫岁余”“先死”“早卒”并不等于可以补一个公元年。尤其妇人怀孕、每次生育、兄弟侍中任命和末年选择继承人的谈话，不由篇中年龄或后一事件倒推出确日。[本卷全句](../../sources/摘录/史记-卷049-外戚世家.md#p043)、[徐广与索隐校读](../../sources/史记三家注/卷049.md#p43)。

### 王氏姐妹、景帝十四子与同姓异人

臧儿先嫁王仲，生王信与两女；后嫁田氏，生田蚡、田胜。王皇后曾与金王孙有一女，后来被迎为修成君；入刘启宫后生平阳、南宫、隆虑三公主及刘彻。妹妹王儿姁另生四子。王太后名字“娡”来自索隐引皇甫谧，不冒称主文已经写出。[P018—P026](../../sources/摘录/史记-卷049-外戚世家.md#p018)。

| 母亲 | 景帝子嗣 | 核对 |
|---|---|---|
| 栗姬 | 荣、德、阏于 | 三王，荣曾为太子。 |
| 程姬 | 余、非、端 | 三王。 |
| 贾夫人 | 彭祖、胜 | 二王。 |
| 唐姬 | 发 | 一王。 |
| 王儿姁 | 越、寄、乘、舜 | 四王，母早卒未详年。 |
| 王皇后 | 彻 | 承帝位，另有三位公主不计入男性总数。 |

前五行共13王，再加武帝为14子。《五宗世家》[L4511](../../sources/本地分卷/史记/史记-卷059.md#L4511)开头“子凡十三人为王”并无“只有十三子”之意；《外戚世家》“十三男，一帝十二王”数字不能因此被证实。原句照存，实际世系采用可逐名核对的14子／13王。

武帝后来宠爱的“赵之王夫人”是齐王刘闳之母，与王皇太后不是一人；前者又不同于河间赵氏钩弋夫人。王信前145受盖侯，田蚡、田胜前141受侯，死去王仲的共侯是追尊，不能把三名实际列侯扩计为四名。

### 卫氏、李氏与下一代

| 关系 | 人物、侯号或王号 | 核对 |
|---|---|---|
| 卫氏姐弟 | 长君、卫少儿、卫子夫、卫青 | 长君先卒；少儿生霍去病，子夫生刘据及三女。 |
| 卫青三子 | 伉—宜春；不疑—阴安；登—发干 | 前124各1300户；伉已是宜春侯，不能依褚补再算第四子。 |
| 卫氏五侯 | 卫青、三子、霍去病 | 卫青127长平，三子124，霍123冠军；三子承父功而非亲自参战。 |
| 将军号 | 卫青124大将军；霍去病121骠骑 | 与长平、冠军受爵年分开。 |
| 李姬 | 刘旦、刘胥 | 燕、广陵二王前117受封。 |
| 中山李夫人 | 刘髆；其兄李延年、李广利 | 刘髆前97封昌邑；刘贺为其子，正义p32“名贺”混淆父子。 |
| 赵地王夫人 | 刘闳 | 前117封齐；受宠与早卒未详。 |
| 钩弋赵夫人 | 刘弗陵 | 前94生，前87即位；她自己死亡仅置武帝末前91—87范围。 |

平阳公主是武帝的姐姐，刘嫖是他的姑母，陈皇后是刘嫖之女；两位长公主与陈、卫两后之间的关系不可换位。平阳与卫青的婚期无独立明年，不把前夫材料与卫青官号机械拼接。修成君的女儿，主文作王后、集解说淮南王安太子妃，身份差异照录；修成子仲的“仲”也不擅与外祖王仲同一命名解释。[褚补诸段](../../sources/摘录/史记-卷049-外戚世家.md#p036)。

### 世系与同名人物

| 支系或人物 | 核定关系与限制 |
|---|---|
| 刘伯—刘信 | 伯是高祖早亡长兄；信为其子，受羹颉侯。“巨嫂”是刘邦长嫂、刘信之母。 |
| 刘仲／喜—刘濞、刘广 | 仲是高祖二兄，名喜；濞是吴王，广是德侯。广子承侯者有通，但本篇拟立德侯子不记名，不能把表推论伪装成本篇明文。 |
| 刘交—郢客—戊 | 楚国早期父子相承，戊反而死。韩信是此前的异姓楚王，没有进入刘交家谱。 |
| 刘交—礼—道—注—纯—延寿 | 七国乱后转由元王另一子刘礼延统。刘礼不是刘戊亲子；刘纯不是宣帝地节案中自杀的延寿。 |
| 刘友—遂、辟强—福 | 遂与河间辟强是兄弟，福是辟强子。刘友是高祖儿子，“中子”不强译成已核定的第二子。 |
| 楚刘富之子辟强 | 与赵幽王之子、河间文王刘辟强同名异人；汉楚元王传后半另叙其子刘德及孙刘向。 |
| 河间刘德 | 景帝之子，是前155另封的一支，非刘福的嗣子；前165国除与后来复置分开。 |
| 楚张尚、赵夷吾 | 楚相与太傅，被刘戊杀。赵夷吾姓赵而任职楚，不能误列赵国谏臣。 |
| 赵建德、王悍 | 赵相建德失姓，内史王悍姓王；两人被刘遂烧杀，不合成“王建德”。 |
| 申公、白生、穆生、韦孟 | 申公又名培，申、白受劳役，穆生先离楚，韦孟谏诗另见汉韦贤传；不能一律写成四人同日被刘戊杀。 |
| 防与先生 | 太史公举为赵应任之贤者，索隐承认本篇及汉传不载其具体不用之事，保留身份不补故事。 |
| 赵何齐、长年、赵长平／赵成 | 汉传说何齐是延寿后母的弟弟，父长年告发；侯表称赵长平或赵成获功。姓名见证分别保存，不将“后母弟”误解成同父异母弟，不凭近名强订所有别名。 |

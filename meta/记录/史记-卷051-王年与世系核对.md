### 汉王与高祖年次

| 原年次 | 年页 | 核对结果 |
|---|---|---|
| 汉王元年 | [前206](../../years/bce-0300-0201/bce-0206.md#note-23) | 刘贾为将军、定塞；“从东击项籍”是后续行军概括，不另虚定月日。 |
| 汉三年／本篇汉四年 | [前204](../../years/bce-0300-0201/bce-0204.md#note-20) | 汉高帝纪同一白马津袭粮在三年，主线沿前204，原文四年仍在引句。 |
| 汉三年 | [前204](../../years/bce-0300-0201/bce-0204.md#note-25) | 刘泽郎中；职任早于营陵封爵。 |
| 汉五年 | [前202](../../years/bce-0300-0201/bce-0202.md#note-3) | 围寿春、招周殷、会垓下；攻临江接同年第15条，围攻数月。 |
| 高祖六年 | [前201](../../years/bce-0300-0201/bce-0201.md#note-4) | 冬十二月擒韩信，随后春正月分封荆楚及齐，不以本篇的压缩叙述抹去年内先后。 |
| 高祖十一年 | [前196](../../years/bce-0200-0101/bce-0196.md#note-1) | 刘泽讨陈豨、得王黄、封营陵；同年秋刘贾败走富陵被杀。 |
| 高祖十二年 | [前195](../../years/bce-0200-0101/bce-0195.md#note-4) | 击破黥布与刘濞封吴沿该年原事；荆王死亡不迁后一年。 |

年次依据[本篇P001—P006](../../sources/摘录/史记-卷051-荆燕世家.md#p001)、[汉高帝纪L53](../../sources/本地分卷/汉书/汉书-卷001.md#L53)、[L63—L64](../../sources/本地分卷/汉书/汉书-卷001.md#L63)、[L75—L77](../../sources/本地分卷/汉书/汉书-卷001.md#L75)、[营陵侯原格](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r113)。古历十月、十一月、十二月在正月以前，本项目使用整年对应，不把古月数字当成现代公历月。

### 两支宗属与称谓

| 人物 | 本篇所见 | 其他见证及处理 |
|---|---|---|
| 荆王刘贾 | 诸刘，不知何属；太史公称属疏 | [汉传L7013](../../sources/本地分卷/汉书/汉书-卷035.md#L7013)称高帝从父兄。[索隐p0](../../sources/史记三家注/卷051.md#p0)说班固或别有所见。正文不径改成确定的堂兄关系。 |
| 吴王刘濞 | 原沛侯，十二年王故荆地 | [汉传L7023](../../sources/本地分卷/汉书/汉书-卷035.md#L7023)为高帝兄仲之子；不是刘贾之子，也不属于燕王三代。 |
| 燕王刘泽 | 诸刘远属；郎中、将军、营陵侯、琅邪王、燕王依次出现 | [汉传L7018](../../sources/本地分卷/汉书/汉书-卷035.md#L7018)称从祖昆弟，[索隐p5](../../sources/史记三家注/卷051.md#p5)以宗家说明仍疏。琅邪与燕是先后迁封，不是两国同时在手。 |
| 田生 | 齐人，以画干刘泽；其子结交张卿 | [古注p6](../../sources/史记三家注/卷051.md#p6)引《楚汉春秋》作田子春。儿子引见设宴，屏人游说的主体仍为田生，不互换父子。 |
| 张子卿／张卿 | 吕后所幸大谒者 | 徐广注称名泽，如淳称宦者；姓张而非刘，与刘泽同名不等于同人。田生许其万户侯是游说许诺，实际建陵侯记载另在高后八年，不倒置到第一次谈话时。 |
| 刘嘉 | 刘泽之子，康王 | 与荆王刘贾、吕王吕嘉均为异人；嘉、贾虽音近，不作同一人。 |
| 刘定国 | 刘嘉之子、刘泽之孙 | 与后来江都王子睢陵侯刘定国同名异支。燕定国案不与王子侯表人物合并。 |

### 琅邪与燕的连续王统

| 时点 | 本次实际归年 | 原典及边界 |
|---|---|---|
| 营陵侯升琅邪王 | [前181](../../years/bce-0200-0101/bce-0181.md#note-6)，高后七年 | 汉高后纪及诸侯王表明七年；史记功臣侯表六年异说留前182原注。田生故事的两年后、数月不能把整篇强定高后二年或最后封王一年内。 |
| 琅邪二年 | 前181—前180 | [汉传L7020](../../sources/本地分卷/汉书/汉书-卷035.md#L7020)明“泽王琅邪二年而太后崩”；前180是高后八年、文帝即位年，不是文帝元年。 |
| 迁燕 | [前179](../../years/bce-0200-0101/bce-0179.md#note-1)，文帝元年 | 本篇没有单列年，汉传、汉王表明确元年。孝文本纪十月与汉文帝纪十二月的异月承接旧注；不另在180或179各迁一次。 |
| 燕敬王刘泽薨 | [前178](../../years/bce-0200-0101/bce-0178.md#note-7)，文帝二年 | 179—178首尾计燕王二年；此前琅邪王二年另计。 |
| 燕康王刘嘉元年 | [前177](../../years/bce-0200-0101/bce-0177.md#note-7)，文帝三年 | 父卒后的继位事实与王表逾年元年分开。 |
| 刘嘉二十六年薨 | [前152](../../years/bce-0200-0101/bce-0152.md#note-5)，景帝五年 | 177−152＋1＝26，与两书王表相合；孝景本纪前154异年原注保留。 |
| 刘定国元年 | [前151](../../years/bce-0200-0101/bce-0151.md#note-6)，景帝六年 | 嘉薨后承袭，次年列元年；不能把前152承接与前151元年混为史料互斥。 |
| 刘定国之死、燕国除 | 主接[前127](../../years/bce-0200-0101/bce-0127.md#note-3)，元朔二年 | 本篇元朔元年及表二十四年指前128，汉武帝纪明元朔二年秋。沿既有127主线公开存异，不暗改二十四为二十五。 |

[汉书诸侯王表L1395](../../sources/本地分卷/汉书/汉书-卷014.md#L1395)在一行内依次给琅邪二年、燕二年、嘉二十六年、定国二十四年；[史记诸侯王表](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0177)可逐年检验。现有年页所采用的定国终局与二十四年数不完全相容，这是真实分歧，不以重新计算消除。

### 九年、四十二年与末年差别

[汉书荆燕吴传L7021](../../sources/本地分卷/汉书/汉书-卷035.md#L7021)却写“子康王嘉嗣，九年薨”“定国……立四十二年”，又只泛称元朔中。嘉若从前177计九年将止前169，定国若从前151计四十二年将止前110，均无法与该传自身元朔年间终局、两书王表及既有年页同时成立。本次不自行校改这些原数，也不以九年、四十二年倒造新的王统；完整引用路径保留，工作线继续取表序，终局保留本纪与表相差一年的问题。

《齐悼惠王世家》齐宫婚议提到燕王新死，只能给叙事先后线索，不能单凭一个“新”字确定婚议年，也不能证明定国自杀在前128而燕国除在前127。告发、议罪、自杀、除国在所见文字中是连续步骤，并无足够材料强分成两个确年终局。

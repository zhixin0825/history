原证：[本篇P034—P035](../../sources/摘录/史记-卷052-齐悼惠王世家.md#p034)、[汉表L1347—L1353](../../sources/本地分卷/汉书/汉书-卷014.md#L1347)、[汉传L7162](../../sources/本地分卷/汉书/汉书-卷038.md#L7162)、[三家注p33—p34](../../sources/史记三家注/卷052.md#p33)。后继证明用于识别前30的卒字冲突，本轮不借此把本篇以后的每一代另编入时间线。

刘喜迁国须逐格看。[史表前169](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0169)城阳栏“八，徙淮南”，[前168](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0168)淮南栏记迁王元年；[前165](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0165)淮南栏“四，徙城阳”，[前164](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0164)城阳栏续“十三年”。索隐和汉传又以文十二为迁淮南，汉传说五年复还。统一主线继续沿前169迁、前164正式复城阳，保留前165先导格位，不让同一人连年重复迁同一国。若采用169迁、164返，相距五年、连首尾六年，本篇迁后“四年”仍无法闭合；依168迁至164则相距四年、连首尾五年，可与汉传“五年”对应，却又不能让本篇“八年”与“四年”同时无差。总三十三年连续计算，不将迁国年数另加，也不为凑数删除另一年原格。

### 亲属、同名与发言身份

| 对象 | 核对 |
|---|---|
| 刘肥母曹氏、吕后、鲁元 | 曹氏为外妇；吕后是惠帝与鲁元生母。鲁元所得尊号不是刘肥真实生母的改变。 |
| 刘泽对齐王说嫡长孙 | 是脱身游说中的名分主张；篇首刘肥长庶子不被删改。 |
| 纪太后与汉王太后 | 前者齐厉王母，后者武帝母；两人不是同一太后。 |
| 纪翁主、纪氏王后 | 翁主是厉王亲姊；王后是纪太后弟女、厉王表妹，不互换身份。 |
| 修成君与娥 | 王太后前嫁金氏之女与外孙女；修成君非刘氏皇女，娥不是武帝亲女。 |
| 夏侯婴与灌婴 | 清宫的太仆婴为滕公夏侯婴；荥阳驻兵、文帝时任丞相者是灌婴。 |
| 齐相召平 | 索隐提示不宜与广陵召平、东陵侯召平强合。 |
| 七国中的平阳侯 | 古注解释为曹奇，非早已去世的曹参。 |
| 後来的济北王 | 刘兴居、刘志、迁来的刘勃及其后人分支不同，不能见济北便并成一人。 |

原证分别见[三家注p1、p9、p25—p27](../../sources/史记三家注/卷052.md#p25)、[汉传L7135、L7163、L7170](../../sources/本地分卷/汉书/汉书-卷038.md#L7170)及本卷各同号白话。

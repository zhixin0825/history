## 001｜曹操别名及曹氏上古世系的说法

四库本 1a，原行 20—22。附见[《武帝纪》正文 L3](../本地分卷/三国志/三国志-卷001.md#l3)。

<a id="pei-001-1"></a>

> 太祖一名吉利小字阿瞞王沈魏書曰其先出於黃帝當高陽世陸終之子曰安是為曹姓周武王克殷存先世之後封曹俠於邾春秋之世與於盟會逮至戰國為楚所滅子孫分流或家于沛

**曹操别名及曹氏上古世系的说法** 曹操一名吉利、小字阿瞒。王沈《魏书》上推祖源到黄帝、高阳、陆终与曹安，据称周武王封曹侠于邾，春秋时参与盟会，战国为楚所灭，后人流散，部分居沛。

**系年依据** 《魏书》累计叙述数代和多个时代，不能连成可逐年判定的世系；邾为楚所灭的年份亦未见本句或同事确证。

[曹操别名及曹氏上古世系的说法（时期）](../../years/ce-0201-0300/时期-三国志魏纪后妃及汉末群雄.md#wu-period-p-001-1)

<a id="pei-001-2"></a>

> 漢高祖之起曹參以功封平陽侯

**曹参因功定封平阳侯** 曹参从汉高祖起兵，论功获封平阳侯。

**系年依据** 《史记·高祖功臣侯者年表》《汉书·高惠高后文功臣表》表定高祖六年十二月甲申正式受封，与前201年第6条既有史事相合。

[前201年第6条](../../years/bce-0300-0201/bce-0201.md#wu-p-001-2)

<a id="pei-001-3"></a>

> 世襲爵土絶而復紹至今適嗣國於容城

**曹参后代袭封和恢复** 曹氏后代继承爵土，中间断绝后又恢复；《魏书》叙至编者时代嫡嗣居容城。

**系年依据** 多代合述。东汉建初二年（77）章帝重新封曹湛为平阳侯，可互见77年第9条，但本注未逐代说明断绝、恢复及转封容城的具体年份。

## 002｜曹腾家世、父曹节让猪与初仕

四库本 1b—2a，原行 24—33。附见[《武帝纪》正文 L3](../本地分卷/三国志/三国志-卷001.md#l3)。

<a id="pei-002-1"></a>

> 司馬彪續漢書曰騰父節字元偉素以仁厚稱鄰人有亡豕者與節豕相類詣門認之節不與爭後所亡豕自還其家豕主人大慙送所認豕幷辭謝節節笑而受之由是鄉黨貴歎焉長子伯興次子仲興次子叔興騰字季興少除黃門從官

**曹腾家世、父曹节让猪与初仕** 《续汉书》说曹节仁厚，有邻人误认曹节家的猪，曹节不争，邻人找回自家猪才送还致歉；又举曹节四子，称曹腾少时任黄门从官。

**系年依据** 让猪与曹氏兄弟无确年。《后汉书·曹腾传》仅称他在安帝朝任黄门从官。

[曹腾家世、父曹节让猪与初仕（时期）](../../years/ce-0201-0300/时期-三国志魏纪后妃及汉末群雄.md#wu-period-p-002-1)

<a id="pei-002-2"></a>

> 永寧元年鄧太后詔黃門令選中黃門從官年少温謹者配皇太子書騰應其選太子特親愛騰飲食賞賜與衆有異

**曹腾应选伴皇太子读书** 邓太后令挑选年轻温谨的黄门从官陪皇太子读书，曹腾入选，受到太子格外礼遇。

**系年依据** 《续汉书》明记永宁元年，120年第5条为立刘保为皇太子并改元；可并为宫中后续。

[120年第5条](../../years/ce-0101-0200/ce-0120.md#wu-p-002-2)

<a id="pei-002-3"></a>

> 順帝卽位為小黃門

**顺帝即位后曹腾为小黄门** 顺帝即位，曹腾为小黄门。

**系年依据** 《后汉书·顺帝纪》L812–813及125年第28条载延光四年十一月即位；小黄门任命具体日月未载。

[125年第28条](../../years/ce-0101-0200/ce-0125.md#wu-p-002-3)

<a id="pei-002-4"></a>

> 遷至中常侍大長秋在省闥三十餘年歴事四帝未嘗有過好進達賢能終無所毁傷其所稱薦若陳留虞放邊韶南陽延固張温弘農張奐潁川堂谿典等皆致位公卿而不伐其善

**曹腾历仕与荐举** 曹腾后来迁中常侍、大长秋，在宫中任事三十余年、经历四帝，推荐虞放、边韶等人，不自居功。

**系年依据** 分属多朝；《后汉书》L5572说明中常侍在顺帝时，大长秋在桓帝得立后，本句为合述。

[曹腾历仕与荐举（时期）](../../years/ce-0201-0300/时期-三国志魏纪后妃及汉末群雄.md#wu-period-p-002-4)

<a id="pei-002-5"></a>

> 蜀郡太守因計吏修敬於騰益州刺史种暠於函谷關搜得其牋上太守并奏騰内臣外交所不當為請免官治罪帝曰牋自外來騰書不出非其罪也乃寢暠奏騰不以介意常稱歎暠以為暠得事上之節

**种暠劾曹腾未成** 益州刺史种暠搜得蜀郡太守给曹腾的信，认为其不当结交外官，请治罪。皇帝以信由外面寄来为由不追究，曹腾也称赏种暠尽职，未记恨他。

**系年依据** 《后汉书·曹腾传》L5573 并载，但未系年；该书所载地名作斜谷关，与注作函谷关有异。

[种暠劾曹腾未成（时期）](../../years/ce-0201-0300/时期-三国志魏纪后妃及汉末群雄.md#wu-period-p-002-5)

<a id="pei-002-6"></a>

> 暠後為司徒語人曰今日為公乃曹常侍恩也騰之行事皆此類也

**种暠为司徒，称得曹腾助力** 种暠任司徒后说，自己能位列三公有曹腾的帮助；史书称曹腾不计前嫌。

**系年依据** 《后汉书·桓帝纪》及《种暠传》明延熹四年迁司徒；称谢只知在为司徒后。

[161年第4条](../../years/ce-0101-0200/ce-0161.md#wu-p-002-6)

<a id="pei-002-7"></a>

> 桓帝卽位以騰先帝舊臣忠孝彰著封費亭侯加位特進

**桓帝即位后封曹腾费亭侯** 桓帝即位后，以曹腾是先朝旧臣且忠孝有名，封费亭侯、加特进。

**系年依据** 《后汉书·曹腾传》L5572说因定策之功封侯；桓帝立于本初元年。

[146年第16条](../../years/ce-0101-0200/ce-0146.md#wu-p-002-7)

<a id="pei-002-8"></a>

> 太和三年追尊騰曰高皇帝

**魏明帝追尊曹腾为高皇帝** 太和三年，魏明帝追尊曹腾为高皇帝。

**系年依据** 本注明太和三年；本书卷003《明帝纪》二月戊申可互校，229年第3条。

[229年第3条](../../years/ce-0201-0300/ce-0229.md#wu-p-002-8)

## 004｜曹操少时装病骗过叔父

四库本 2a，原行 37—40。附见[《武帝纪》正文 L4](../本地分卷/三国志/三国志-卷001.md#l4)。

<a id="pei-004-1"></a>

> 曹瞞傳云太祖少好飛鷹走狗游蕩無度其叔父數言之於嵩太祖患之後逢叔父於路乃陽敗面喎口叔父怪而問其故太祖曰卒中惡風叔父以告嵩嵩驚愕呼太祖太祖口貌如故嵩問曰叔父言汝中風已差乎太祖曰初不中風但失愛於叔父故見罔耳嵩乃疑焉自後叔父有以告嵩終不復信太祖於是益得肆意矣

**曹操少时装病骗过叔父** 《曹瞒传》说曹操年少时爱放鹰走狗，被叔父屡次告知父亲曹嵩。曹操假装中风，叔父报告后曹嵩召见却发现他神色正常，自此不再相信叔父的议论。

**系年依据** 原注只说“少”“後”，没有年。底本署名为《曹瞞傳》；点校影印相关校补及异文见卷页校记。

## 005｜桥玄识曹操及桥玄为人

四库本 2b—3a，原行 43—50。附见[《武帝纪》正文 L4](../本地分卷/三国志/三国志-卷001.md#l4)。

<a id="pei-005-1"></a>

> 魏書曰太尉橋玄世名知人覩太祖而異之曰吾見天下名士多矣未有若君者也君善自持吾老矣願以妻子為託由是聲名益重續漢書曰玄字公祖嚴明有才略長於人物張璠漢紀曰玄歴位中外以剛斷稱謙儉下士不以王爵私親

**桥玄识曹操及桥玄为人** 《魏书》记桥玄十分看重曹操，并想托付妻儿，曹操因此知名。《续汉书》说桥玄有才略、善识人；张璠《汉纪》说他任职中外、刚断谦俭。

**系年依据** 《后汉书·桥玄传》L3865说曹操微时拜见，无确年。在引文中“太尉”可以是回称，不能直接当会见时的现职。

> 光和中為太尉

**桥玄拜太尉** 光和年间，桥玄拜太尉。

**系年依据** 《后汉书·灵帝纪》将此事系光和元年十二月丁巳。

[178年第22条](../../years/ce-0101-0200/ce-0178.md#wu-p-005-2)

<a id="pei-005-3"></a>

> 以久病策罷拜大中大夫

**桥玄因病免太尉，拜太中大夫** 桥玄久病免太尉，改拜太中大夫。

**系年依据** 《后汉书·灵帝纪》明光和二年桥玄免；桥玄本传与注同言拜太中大夫，承免官记。

[179年第3条](../../years/ce-0101-0200/ce-0179.md#wu-p-005-3)

<a id="pei-005-4"></a>

> 卒家貧乏產業柩無所殯當世以此稱為名臣

**桥玄卒，家贫未能停柩办丧** 桥玄去世时家无产业，灵柩无所停放，当时人称其为名臣。

**系年依据** 《后汉书·桥玄传》L3864直书光和六年卒。

[183年第10条](../../years/ce-0101-0200/ce-0183.md#wu-p-005-4)

<a id="pei-005-5"></a>

> 世語曰玄謂太祖曰君未有名可交許子將太祖乃造子將子將納焉由是知名孫盛異同雜語云太祖嘗私入中常侍張讓室讓覺之乃舞手㦸於庭踰垣而出才武絶人莫之能害博覽羣書特好兵法抄集諸家兵法名曰接要又注孫武十三篇皆傳於世嘗問許子將我何如人子將不答固問之子將曰子治世之能臣亂世之姦雄太祖大笑

**曹操见许劭、闯张让宅及研究兵法** 《世语》称桥玄荐曹操去见许劭，曹操因而取得声名。孙盛说曹操闯入张让居处后挥戟翻墙脱身，遍览群书、编《接要》并注《孙武》十三篇，又问许劭自己怎样，许劭以“治世之能臣、乱世之姦雄”品评。

**系年依据** 会见许劭、越墙、著述均未明年。《后汉书·许劭传》另记品评措辞，不能用赞语在本纪的位置定著述年。

## 006｜曹操任北部尉立五色棒，后迁顿丘

四库本 3a，原行 51—53。附见[《武帝纪》正文 L4](../本地分卷/三国志/三国志-卷001.md#l4)。

<a id="pei-006-1"></a>

> 曹瞞傳曰太祖初入尉廨繕治四門造五色棒縣門左右各十餘枚有犯禁者不避豪彊皆棒殺之後數月靈帝愛幸小黃門蹇碩叔父夜行卽殺之京師歛迹莫敢犯者近習寵臣咸疾之然不能傷於是共稱薦之故遷為頓丘令

**曹操任北部尉立五色棒，后迁顿丘** 《曹瞒传》说曹操整饬尉署，设五色棒，违禁不避权贵。数月后，他棒杀小黄门蹇硕的叔父；宫中权贵因而忌恨，反借举荐将他调做顿丘令。

**系年依据** 仅“初入”“後數月”，与正文L4的任职先后吻合；各事件年月均无独立记载，不以举孝廉推年硬定。

<a id="pei-117-10"></a>

> 及在兖州陳留邊讓言議頗侵太祖太祖殺讓族其家

**曹操诛边让及其家** 《曹瞒传》称曹操在兖州时，陈留边让出言冒犯，曹操杀边让并族其家。

**系年依据** 《通鉴》卷061叙入194年兖州叛变的前因，使用“嘗”，《后汉书·边让传》称建安中，《袁绍传》所录陈琳檄文把此事放在失兖州前，纪年相冲，暂归时期。

> 忠邵俱避難交州太祖遣使就太守士燮盡族之桓邵得出首拜謝於庭中太祖謂曰跪可解死邪遂殺之

**袁忠、桓邵避交州及曹操追杀的异载** 《曹瞒传》称袁忠、桓邵逃往交州，曹操遣使通知士燮诛其族，桓邵出来自首仍被处死。

**系年依据** 原注未标年；《后汉书·袁安传》称袁忠徵为卫尉未到而卒，与此说须保留分别，不能因边让之事推定年。

> 常出軍行經麥中令士卒無敗麥犯者死騎士皆下馬付麥以相持於是太祖馬騰入麥中勑主簿議罪主簿對以春秋之義罰不加於尊太祖曰制法而自犯之何以帥下然孤為軍帥不可自殺請自刑因援劒割髮以置地

**曹操军中禁践麦与割发** 《曹瞒传》记曹操下令禁军士践麦，自马入麦后要求议罚；主簿援引尊者不受罚，曹操遂割发作为自刑。

**曹操杀侍妾的传闻** 《曹瞒传》称侍妾没有照嘱咐叫醒熟睡的曹操，曹操醒来把她打死。

## 119｜纠虔天刑一词与《国语》

维基文库四库本原行 33—33。附见[《武帝纪》正文 L88](../本地分卷/三国志/三国志-卷001.md#l88)。

> 糾䖍天刑語出國語韋昭注曰糾察也䖍敬也刑法也

**纠虔天刑一词与《国语》** 裴松之指出“糾䖍天刑”出自《国语》，引韦昭解释纠为察、虔为敬、刑为法。

## 001｜曹操器重幼时的曹叡

Kanripo四库本 1a原行 20—21。附见[正文 L167](../本地分卷/三国志/三国志-卷003.md#l167)。

<a id="pei-001-1"></a>

> 魏書曰帝生數歲而有岐嶷之姿武皇帝異之曰我基於爾三世矣每朝宴會同與侍中近臣並列帷幄好學多識特留意於法理

**曹操器重幼时的曹叡** 《魏书》说曹叡年仅数岁便显出聪慧，曹操说子孙三世的基业在他身上，往往让他和侍中近臣同列帷幄；曹叡还爱读书，关注法律。

**归年依据** 童年及反复伴随曹操无具体年，至迟在曹操220年去世以前。“我基於爾三世”是所引对话，不给出处日期。

[曹操器重幼时的曹叡（时期）](../../years/ce-0201-0300/时期-三国志卷003-明帝纪纪年待考.md#period-sgz003-p-001-1)。

## 002｜曹丕让郭皇后养曹叡，并曾考虑京兆王

Kanripo四库本 1a—1b原行 22—27。附见[正文 L167](../本地分卷/三国志/三国志-卷003.md#l167)。

<a id="pei-002-1"></a>

> 魏畧曰文帝以郭后無子詔使子養帝帝以母不以道終意甚不平後不獲已乃敬事郭后旦夕因長御問起居郭后亦自以無子遂加慈愛文帝始以帝不悅有意欲以他姬子京兆王為嗣故久不拜太子

**曹丕让郭皇后养曹叡，并曾考虑京兆王** 《魏略》说曹丕令无子的郭皇后以曹叡为子；曹叡因甄氏死不平，后来不得已问候郭后，郭后对他转而慈爱。曹丕曾有意立另一妃嫔所生的京兆王，因此较晚立曹叡为太子。

**归年依据** 甄氏死于221年，郭氏立皇后于222年，曹叡立太子在226年。收养、转变态度和另择太子的各次决定未见确年。“京兆王”也可能是追称。

[曹丕让郭皇后养曹叡，并曾考虑京兆王（时期）](../../years/ce-0201-0300/时期-三国志卷003-明帝纪纪年待考.md#period-sgz003-p-002-1)。

<a id="pei-002-2"></a>

> 魏末傳曰帝常從文帝獵見子母鹿文帝射殺鹿母使帝射鹿子帝不從曰陛下已殺其母臣不忍復殺其子因涕泣文帝即放弓箭以此深竒之而樹立之意定

**猎鹿故事解释曹丕立储之意** 《魏末传》说曹丕猎杀母鹿、让曹叡射小鹿，曹叡想起母子关系，含泪拒绝，曹丕由此决定立他为太子。

**归年依据** 这是另一个文献对立储动机的解释，狩猎没有明确日期，只能置于226年立储之前。

[猎鹿故事解释曹丕立储之意（时期）](../../years/ce-0201-0300/时期-三国志卷003-明帝纪纪年待考.md#period-sgz003-p-002-2)。

## 003｜曹叡即位后召见刘晔

Kanripo四库本 1b原行 29—30。附见[正文 L167](../本地分卷/三国志/三国志-卷003.md#l167)。

<a id="pei-003-1"></a>

> 世語曰帝與朝士素不接即位之後羣下想聞風采居數日獨見侍中劉曄語盡日衆人側聼曄既出問何如曄曰秦始皇漢孝武之儔才具微不及耳

**曹叡即位后召见刘晔** 《世语》记曹叡原本少与朝臣往来，即位数日召见刘晔谈了一整天，刘晔以秦始皇、汉武帝为比，说曹叡才具略逊。

**归年依据** 附在本纪黄初七年即位后，注有“居數日”的相对时点。

[226年第16条](../../years/ce-0201-0300/ce-0226.md#sgz003-p-003-1)。

## 004｜孟他以家财结交张让家奴、拜凉州刺史

Kanripo四库本 3a—4a原行 54—73。附见[正文 L170](../本地分卷/三国志/三国志-卷003.md#l170)。

<a id="pei-004-1"></a>

> 三輔決錄曰伯郎涼州人名不令休其注曰伯郎姓孟名他扶風人靈帝時中常侍張讓專朝政讓監奴典䕶家事他仕不遂乃盡以家財賂監奴與共結親積年家業為之破盡衆奴皆慙問他所欲他曰欲得卿曹拜耳奴被恩久皆許諾時賔客求見讓者門下車常數百乘或累日不得通他最後到衆奴伺其至皆迎車而拜徑將他車獨入衆人悉驚謂他與讓善爭以珍物遺他他得之盡以賂讓讓大喜他又以蒲桃酒一斛遺讓即拜涼州刺史

**孟他以家财结交张让家奴、拜凉州刺史** 《三辅决录》及其注称孟他字伯郎，扶风人。孟他用尽家财结交张让家奴，家奴假装厚待他，引其他求见者献赠财物。孟他转献张让，又送蒲萄酒而得拜凉州刺史。

**归年依据** 仅称灵帝在位、张让掌事，未载孟他获任日期。

[孟他以家财结交张让家奴、拜凉州刺史（时期）](../../years/ce-0201-0300/时期-三国志卷003-明帝纪纪年待考.md#period-sgz003-p-004-1)。

<a id="pei-004-2"></a>

> 他生達少入蜀其處蜀事迹在劉封傳

**孟达是孟他之子，早年入蜀** 孟他生孟达；孟达年轻时入蜀，相关事见《刘封传》。

**归年依据** 卷040载孟达与法正入蜀过程，注自身“少入蜀”不明是入刘璋幕府哪一年。

[孟达是孟他之子，早年入蜀（时期）](../../years/ce-0201-0300/时期-三国志卷003-明帝纪纪年待考.md#period-sgz003-p-004-2)。

<a id="pei-004-3"></a>

> 魏畧曰達以延康元年率部曲四千餘家歸魏文帝時初即王位既宿知有達聞其來甚悅令貴臣有識察者徃觀之還曰將帥之才也或曰卿相之器也

**孟达率四千余家降魏** 《魏略》明说延康元年孟达率部曲四千余家归魏。曹丕刚即魏王，先派人察看孟达，来人称其有将帅或卿相之才。

**归年依据** 注直书延康元年，卷002《文帝纪》和卷040《刘封传》可互证，220年第25、48条为同一归降。

[220年第25条](../../years/ce-0201-0300/ce-0220.md#sgz003-p-004-3)。

<a id="pei-004-4"></a>

> 王益欽達逆與達書曰近日有命未足達㫖何者昔伊摯背商而歸周百里去虞而入秦樂毅感鴟夷以蟬蛻王遵識逆順以去就皆審廢興之符效知成敗之必然故丹靑畫其形容良史載其功勲聞卿姿度純茂器量優絕當騁能明時收名傳記今者翻然濯鱗清流甚相嘉樂虚心西望依依若舊下筆屬辭歡心從之昔虞卿入趙再見取相陳平就漢一覲參乘孤今於卿情過於徃故致所御馬物以昭忠愛又曰今者海内淸定萬里一統三垂無邊塵之警中夏無狗吠之虞以是弛罔濶禁與世無疑保官空虚初無資任卿來相就當明孤意慎勿令家人繽紛道路以親駭疎也若卿欲來相見且當先安部曲有所保固然後徐徐輕騎來東

**曹丕致书孟达，劝先安置部曲** 曹丕来信礼遇孟达，列举伊尹、百里奚、陈平等改变事主的先例，送御用马物并告以不需送家属为质，嘱先安置部曲再轻骑来见。

**归年依据** 同年延康初以魏王身份接纳孟达，两封书承接其归降，古人事例为信中引用。四库校证提“資任”当作“質任”。

[220年第25条](../../years/ce-0201-0300/ce-0220.md#sgz003-p-004-4)。

<a id="pei-004-5"></a>

> 達既至譙進見閑雅才辨過人衆莫不屬目又王近出乘小輦執達手撫其背戲之曰卿得無為劉備刺客邪遂與同載又加拜散騎常侍領新城太守委以西南之任時衆臣或以為待之大猥又不宜委以方任王聞之曰吾保其無他亦譬以蒿箭射蒿中耳

**曹丕接见孟达，以之领新城太守** 孟达到谯见曹丕，仪态从容、才辩受到注意。曹丕与他同车，任散骑常侍兼新城太守，使镇西南，虽众臣有疑仍任用他。

**归年依据** 注接孟达延康元年归魏；《刘封传》并载曹丕后将房陵、上庸、西城为新城郡，以孟达领郡。与下文“初入新城登白馬塞”互证。

[220年第25条](../../years/ce-0201-0300/ce-0220.md#sgz003-p-004-5)。

<a id="pei-004-6"></a>

> 達既為文帝所寵又與桓階夏侯尚親善

**孟达受曹丕宠遇，与桓阶、夏侯尚善** 孟达受曹丕优待，也与桓阶、夏侯尚亲善。

**归年依据** 这一交往跨曹丕在位数年，本注未给单一时点。

[孟达受曹丕宠遇，与桓阶、夏侯尚善（时期）](../../years/ce-0201-0300/时期-三国志卷003-明帝纪纪年待考.md#period-sgz003-p-004-6)。

<a id="pei-004-7"></a>

> 及文帝崩時階尚皆卒達自以羇旅久在疆場心不自安

**曹丕死后孟达失援** 注称曹丕去世时，桓阶、夏侯尚也都已去世，孟达念及自己客居边地而不安。

**归年依据** 文帝死确为226年；“皆卒”为到此已死，并非两人均在226年死。卷009载夏侯尚黄初七年薨，《魏略》注无桓阶死年。

[226年第6条](../../years/ce-0201-0300/ce-0226.md#sgz003-p-004-7)。

<a id="pei-004-8"></a>

> 諸葛亮聞之隂欲誘達數書招之達與相報答魏興太守申儀與達有隙宻表達與蜀潛通帝未之信也司馬宣王遣叅軍梁㡬察之又勸其入朝達驚懼遂反

**孟达与诸葛亮通书，被申仪告发而反** 诸葛亮多次写信引诱孟达，孟达回书。申仪上表揭发，魏明帝最初不信；司马懿派梁几察看并劝孟达入朝，孟达惊惧反叛。

**归年依据** 本纪太和元年十二月孟达反；通鉴卷070太和元年条详述通书及魏廷应对，来往书札各次未明。

[227年第15条](../../years/ce-0201-0300/ce-0227.md#sgz003-p-004-8)。

<a id="pei-004-9"></a>

> 干寳晉紀曰達初入新城登白馬塞歎曰劉封申耽據金城千里而失之乎

**孟达初到新城，叹旧守失其险地** 干宝《晋纪》说孟达初到新城，登白马塞，感叹刘封、申耽坐据险固之地却不能保全。

**归年依据** 这是对初任新城的回顾，接220年归魏及领新城，与227叛魏分别。

[220年第25条](../../years/ce-0201-0300/ce-0220.md#sgz003-p-004-9)。

## 005｜李辅、邓贤开新城迎魏军

**李辅、邓贤开新城迎魏军** 司马懿诱孟达部将李辅和孟达外甥邓贤归降；他们开门纳魏军。孟达被围十六日败，首级送洛阳并在大道焚毁。

## 006｜曹叡料诸葛亮不能守所取三郡

Kanripo四库本 4b原行 78—80。附见[正文 L172](../本地分卷/三国志/三国志-卷003.md#l172)。

<a id="pei-006-1"></a>

> 魏書曰是時朝臣未知計所出帝曰亮阻山為固今者自來既合兵書致人之術且亮貪三郡知進而不知退今因此時破亮必也乃部勒兵馬歩騎五萬拒亮

**曹叡料诸葛亮不能守所取三郡** 诸葛亮进军、魏三郡响应，朝臣一时无策，曹叡说诸葛亮熟知主动出兵却贪地不知退，部署步骑五万抵禦。

**归年依据** 本纪太和二年春第一次北伐；注从曹叡角度记判断和领兵人数。

## 007｜曹叡在街亭战后发布露布告蜀

Kanripo四库本 4b—5a原行 81—90。附见[正文 L172](../本地分卷/三国志/三国志-卷003.md#l172)。

<a id="pei-007-1"></a>

> 魏畧載帝露布天下幷班告益州曰劉備背恩自竄巴蜀諸葛亮棄父母之國阿殘賊之黨神人被毒惡積身滅亮外慕立孤之名而内貪專擅之實劉升之兄弟守空城而已亮又侮易益土虐用其民是以利狼宕渠高定靑羌莫不瓦解為亮讐敵而亮反裘負薪裏盡毛殫刖趾適屨刻肌傷骨反更稱說自以為能行兵於井底游歩於牛蹄自朕即位三邊無事猶哀憐天下數遭兵革且欲養四海之耆老長後生之孤幼先移風於禮樂次講武於農隙置亮畫外未以為虞而亮懐李熊愚勇之智不思荆邯度徳之戒驅畧吏民盜利祁山王師方振膽破氣奪馬謖高祥望旗奔敗虎臣逐北蹈尸渉血亮也小子震驚朕師猛銳踊躍咸思長驅朕惟率土莫非王臣師之所處荆棘生焉不欲使千室之邑忠信貞良與夫淫昏之黨共受塗炭故先開示以昭國誠勉思變化無滯亂邦巴蜀將吏士民諸為亮所刼廹公卿已下皆聴束手

**曹叡在街亭战后发布露布告蜀** 《魏略》记曹叡公布文告，贬斥刘备与诸葛亮，指责蜀方长期困敝，举祁山、马谡、高祥败退，称魏不欲百姓与其兵患同受摧残，招诱蜀将吏士民归降。

**归年依据** 本纪太和二年曹叡幸长安、街亭战后。露布中的旧事与敌我评价系文告的论证或宣传，勿当作228年的独立事实。

[228年第3条](../../years/ce-0201-0300/ce-0228.md#sgz003-p-007-1)。

## 009｜郝昭预先修陈仓城

Kanripo四库本 5b—6a原行 100—111。附见[正文 L172](../本地分卷/三国志/三国志-卷003.md#l172)。

<a id="pei-009-1"></a>

> 魏畧曰先是使將軍郝昭築陳倉城會亮至圍昭不能㧞

**归年依据** 卷009曹真本传载太和二年破祁山后曹真预命郝昭、王生守陈仓，当年内筑防，先于十二月围城。

> 魏書載詔曰蓋帝王受命莫不恭承天地以章神明尊祀世統以昭功徳故先代之典既著則禘郊祖宗之制備也昔漢氏之初承秦滅學之後采摭殘缺以備郊祀自甘泉后土雍宫五畤神祗兆位多不見經是以制度無常一彼一此四百餘年廢無禘祀古代之所更立者遂有闕焉曹氏系世出自有虞氏今祀圜丘以始祖帝舜配號圜丘曰皇皇帝天方丘所祭曰皇皇后地以舜妃伊氏配天郊所祭曰皇天之神以太祖武皇帝配地郊所祭曰皇地之祗以武宣后配宗祀皇考高祖文皇帝於明堂以配上帝

**《魏书》详曹叡设圆丘与郊祀各自配祭** 曹叡在诏中回顾秦汉礼制，称曹氏先世出舜，规定圜丘祀天配舜、方丘祀地配舜妃伊氏，天郊配曹操、地郊配卞后、明堂以曹丕配上帝。

**归年依据** 固定维基四库见证补此注；《晋书·礼志》L3122明景初元年十月乙卯建洛阳委粟山圜丘并录同诏，冬至始祭见237年第31条。

> 至晉泰始二年幷圜丘方丘二至之祀於南北郊

**晋合圜丘、方丘之祭于南北郊** 晋泰始二年，把圜丘和方丘的冬至、夏至祭祀合并在南郊和北郊举行。

**归年依据** 此为注文末的回顾，直书泰始二年；《晋书·武帝纪》L136 和《礼志》L3123均明同年十一月。266年页原无晋祀此事。

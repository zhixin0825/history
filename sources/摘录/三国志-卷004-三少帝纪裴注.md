<a id="pei-001-1"></a>

> 魏氏春秋曰或云任城王楷子

**曹芳生父的异说** 孙盛《魏氏春秋》说有人认为曹芳是任城王曹楷之子。

## 002｜异物志载斯调火洲造布之说

Kanripo四库本 1b—2b原行 29—42。附见[正文 L212](../本地分卷/三国志/三国志-卷004.md#l212)。

<a id="pei-002-1"></a>

> 異物志曰斯調國有火洲在南海中其土有野火春夏自生秋冬自死有木生於其中而不消也枝皮更活秋冬火死則皆枯瘁其俗常冬采其皮以為布色小青黑若塵垢汚之便投火中則更鮮明也

**异物志载斯调火洲造布之说** 《异物志》传斯调国南海火洲草木能生于焰中，冬采树皮织布，布污可投火洗净。

**归年依据** 属异域物产传说，没有纪年。

[异物志载斯调火洲造布之说（时期）](../../years/ce-0201-0300/时期-三国志卷004-三少帝纪纪年待考.md#period-sgz004-p-002-1)。

<a id="pei-002-2"></a>

> 傅子曰漢桓帝時大將軍梁冀以火浣布為單衣常大會賓客冀陽爭酒失杯而汙之偽怒解衣曰燒之布得火煒燄赫然如燒凡布垢盡火滅粲然絜白若用灰水焉

**傅子载东汉梁冀试焚火浣衣** 《傅子》记梁冀宴客时故意污衣，令烧衣，污渍去除而布洁白。

**归年依据** 注只限定桓帝时、梁冀任大将军期间，未定年。

[傅子载东汉梁冀试焚火浣衣（时期）](../../years/ce-0201-0300/时期-三国志卷004-三少帝纪纪年待考.md#period-sgz004-p-002-2)。

<a id="pei-002-3"></a>

> 捜神記曰崐崘之墟有炎火之山山上有鳥獸草木皆生於炎火之中故有火浣布非此山草木之皮枲則其鳥獸之毛也

**搜神记所记火浣布来源传说** 引《搜神记》昆仑炎火山草木与鸟兽的说法，称其皮或毛可织火浣布。

**归年依据** 地理传说，无纪年。

[搜神记所记火浣布来源传说（时期）](../../years/ce-0201-0300/时期-三国志卷004-三少帝纪纪年待考.md#period-sgz004-p-002-3)。

<a id="pei-002-4"></a>

> 漢世西域舊獻此布中間久絶至魏初時人疑其無有文帝以為火性酷烈無含生之氣著之典論明其不然之事絶智者之聽

**旧贡火浣布与曹丕疑其物** 西域汉时曾入献火浣布，后来贡品断绝，魏初多人存疑。曹丕以为烈火中无生气，把质疑写入《典论》。

**归年依据** 汉世旧贡、久绝、魏初撰论均无确年，分别不强系。

[旧贡火浣布与曹丕疑其物（时期）](../../years/ce-0201-0300/时期-三国志卷004-三少帝纪纪年待考.md#period-sgz004-p-002-4)。

<a id="pei-002-5"></a>

> 及明帝立詔三公曰先帝昔著典論不朽之格言其刋石于廟門之外及太學與石經並以永示來世

**魏明帝诏刻文帝典论** 曹叡命三公将先帝《典论》作为教诫刻石示后世；注提庙门和太学两处。

**归年依据** 《明帝纪》太和四年二月戊子明记诏立石于庙门外。

[230年第2条](../../years/ce-0201-0300/ce-0230.md#sgz004-p-002-5)。

<a id="pei-002-6"></a>

> 至是西域使至而獻火浣布焉於是刋滅此論而天下笑之

**西域使献火浣布后刋除典论异说** 使者实际献火浣布后，魏删去石刻中否定此物的论说。

**归年依据** “至是”承景初三年二月西域献火浣布。

[239年第9条](../../years/ce-0201-0300/ce-0239.md#sgz004-p-002-6)。

<a id="pei-002-7"></a>

> 臣松之昔從征西至洛陽歴觀舊物見典論石在太學者尚存而廟門外無之問諸長老云晉初受禪即用魏廟移此石於太學非兩處立也竊謂此言為不然

**裴松之在洛阳考见典论刻石** 裴松之称太学有石而太庙外无石。长者说晋初承用魏庙后移石太学，裴松之表示怀疑。

**归年依据** 裴氏实地见闻无年；长者所说移石在“晋初”，不是原立石年份。

[裴松之在洛阳考见典论刻石（时期）](../../years/ce-0201-0300/时期-三国志卷004-三少帝纪纪年待考.md#period-sgz004-p-002-7)。

<a id="pei-002-8"></a>

> 又東方朔神異經曰南荒之外有火山長三十里廣五十里其中皆生不燼之木晝夜火燒得暴風不猛猛雨不滅火中有鼠重百斤毛長二尺餘細如絲可以作布常居火中色洞赤時時出外而色白以水逐而沃之即死續其毛織以為布

**神异经火山、火鼠传说** 书中说南荒火山出不烬木，火鼠毛可织布，离火体色变白，被水泼即死。

**归年依据** 记传说而无确年。

[神异经火山、火鼠传说（时期）](../../years/ce-0201-0300/时期-三国志卷004-三少帝纪纪年待考.md#period-sgz004-p-002-8)。

## 003｜裴松之考魏太祖配享次第

Kanripo四库本 5a—5b原行 93—96。附见[正文 L221](../本地分卷/三国志/三国志-卷004.md#l221)。

<a id="pei-003-1"></a>

> 臣松之以為故魏氏配饗不及荀彧蓋以其末年異議又位非魏臣故也至於升程昱而遺郭嘉先鍾繇而後荀攸則未詳厥趣也徐佗謀逆而許褚心動忠義之至逺同於日磾且潼關之危非褚不濟褚之功烈有過典韋今祀韋而不及褚又所未達也

**裴松之考魏太祖配享次第** 裴松之推想荀彧未配享或因晚年政见和非魏臣身份，又不解程昱先于郭嘉、钟繇先于荀攸、典韦入祀而许褚不入。以许褚忠于曹操并救潼关之危为比较。

**归年依据** 注释244年荀攸配享，占位是对多年祭制的考语。郭嘉增入见262，潼关见211。

[244年第7条](../../years/ce-0201-0300/ce-0244.md#sgz004-p-003-1)。

## 004｜裴松之比较曹芳两道解放官奴婢诏

Kanripo四库本 6a原行 110—112。附见[正文 L223](../本地分卷/三国志/三国志-卷004.md#l223)。

<a id="pei-004-1"></a>

> 臣松之案帝初即位有詔官奴婢六十以上免為良人既有此詔則宜遂為永制七八年間而復貨年七十者且七十奴婢及癃疾殘病竝非可售之物而鬻之於市此皆事之難解

**裴松之比较曹芳两道解放官奴婢诏** 裴松之指出曹芳即位时释放六十以上官奴婢，七八年后市上仍在出售七十岁及残疾者，对诏令未延续表示不解。

## 005｜朱然攻柤中与司马懿曹爽争论迁民

Kanripo四库本 6b—7a原行 119—130。附见[正文 L224](../本地分卷/三国志/三国志-卷004.md#l224)。

<a id="pei-005-1"></a>

> 習鑿齒漢晉春秋曰是年吳將朱然入柤中斬獲數千柤中民吏萬餘家渡沔司馬宣王謂曹爽曰若便令還必復致寇宜權留之爽曰今不修守沔南留民沔北非長策也宣王曰不然凡物置之安地則安危地則危故兵書曰成敗形也安危勢也形勢御衆之要不可不審設令賊二萬人斷沔水三萬人與沔南諸軍相持萬人陸鈔柤中君將何以救之爽不聽卒令還然後襲破之

**朱然攻柤中与司马懿曹爽争论迁民** 《汉晋春秋》载朱然入柤中，军民万余家渡沔；司马懿主张暂留，曹爽认为长留沔北非策，命居民回去，吴军后来又侵袭。

**归年依据** “是年”承正始七年，与吴书《朱然传》赤乌九年一致；再次袭击无确月。

[246年第10条](../../years/ce-0201-0300/ce-0246.md#sgz004-p-005-1)。

<a id="pei-005-2"></a>

> 袁淮言於爽曰吳楚之民脆弱寡能英才大賢不出其土比技量力不足與中國相抗然自上世以來常為中國患者蓋以江漢為池舟楫為用利則陸鈔不利則入水攻之道逺中國之長技無所用之也孫權自十數年以來大畋江北繕治甲兵精其守禦數出盜竊敢逺其水陸次平土此中國所願聞也夫用兵者貴以飽待饑以逸擊勞師不欲久行不欲逺守少則固力專則彊當今宜損淮漢以南退却避之若賊能入居中央來侵邊境則隨其所短中國之長技得用矣若不敢來則邊境得安無鈔盜之憂矣使我國富兵彊政修民一陵其國不足為逺矣今襄陽孤在漢南賊循漢而上則斷而不通一戰而勝則不攻而自服故置之無益於國亡之不足為辱自江夏已東淮南諸郡三后已來其所亡幾何以近賊疆界易鈔掠之故哉若徙之淮北逺絶其間則民人安樂何鳴吠之驚乎遂不徙

**袁淮劝曹爽收缩江汉淮南防线** 袁淮以吴善舟师、水为屏障，主张舍近敌难保之地，把居民移至较远处，使吴军失其水上便利、魏军得用所长，曹爽没有迁徙。

**归年依据** 承246年柤中战事，《汉晋春秋》同注。讲的是建议，不能当作已迁。

[246年第10条](../../years/ce-0201-0300/ce-0246.md#sgz004-p-005-2)。

## 007｜王肃奉册命司马懿为丞相及辞让

Kanripo四库本 9a—9b原行 163—169。附见[正文 L228](../本地分卷/三国志/三国志-卷004.md#l228)。

<a id="pei-007-1"></a>

> 孔衍漢魏春秋曰詔使太常王肅册命太傅為丞相増邑萬户羣臣奏事不得稱名如漢霍光故事太傅上書辭讓曰臣親受顧命憂深責重慿賴天威摧弊姦凶贖罪為幸功不足論又三公之官聖王所制著之典禮至於丞相始自秦政漢氏因之無復變改今三公之官皆備横復寵臣違越先典革聖明之經襲秦漢之路雖在異人臣所宜正况當臣身而不固爭四方議者將謂臣何書十餘上詔乃許之

**王肃奉册命司马懿为丞相及辞让** 《汉魏春秋》说太常王肃奉册，拟增食邑万户并享奏事不名；司马懿上书自称只依天威除弊，并以秦汉丞相官制为由多次辞谢，获准。

**归年依据** 嘉平元年正月，以本纪丁未为任命日期。

[249年第3条](../../years/ce-0201-0300/ce-0249.md#sgz004-p-007-1)。

<a id="pei-007-2"></a>

> 復加九錫之禮太傅又言太祖有大功大德漢氏崇重故加九錫此乃歴代異事非後代之君臣所得議也又辭不受

**司马懿又辞九锡** 司马懿称曹操受九锡有特殊历史条件，自己不能比，拒受九锡。

**归年依据** 同一政变后册礼与辞让，《晋书·宣帝纪》亦系本年。

[249年第3条](../../years/ce-0201-0300/ce-0249.md#sgz004-p-007-2)。

## 008｜孙权在东兴筑堤拦巢湖水

Kanripo四库本 10b原行 189—192。附见[正文 L232](../本地分卷/三国志/三国志-卷004.md#l232)。

<a id="pei-008-1"></a>

> 漢晉春秋曰初孫權築東興隄以遏巢湖後征淮南壊不復修

**孙权在东兴筑堤拦巢湖水** 原为孙权所筑，后来孙权出兵时堤坏废弃。

**归年依据** 《诸葛恪传》明载黄龙二年筑堤（230）；堤坏不载确年。

<a id="pei-008-2"></a>

**诸葛恪重筑东兴堤及两城** 诸葛恪夹山重筑两城，令全端、留略戍守。

**归年依据** “是岁”指嘉平四年；《诸葛恪传》吴建兴元年十月。

[252年第5条](../../years/ce-0201-0300/ce-0252.md#sgz004-p-008-2)。

<a id="pei-008-3"></a>

**诸葛诞为魏议攻吴两城** 据注诸葛诞建议王昶逼江陵、毌丘俭向武昌牵制，再以精兵打两城，司马师采纳。

**归年依据** 同年魏三路伐吴筹划。“司马景王从之”与下一注战败后自谓未采诸葛诞之言有矛盾，依《汉晋春秋》两处存异。

[252年第4条](../../years/ce-0201-0300/ce-0252.md#sgz004-p-008-3)。

## 009｜东关兵败后司马师自承其责

Kanripo四库本 11a原行 196—202。附见[正文 L232](../本地分卷/三国志/三国志-卷004.md#l232)。

<a id="pei-009-1"></a>

> 漢晉春秋曰毌丘儉王昶聞東軍敗各燒屯走朝議欲貶黜諸將景王曰我不聽公休以至於此此我過也諸將何罪悉原之時司馬文王為監軍統諸軍惟削文王爵而已

**东关兵败后司马师自承其责** 《汉晋春秋》载毌丘俭、王昶闻东路军败即烧屯撤走；司马师拒绝贬罚诸将并自承未听诸葛诞，只削监军司马昭爵。

**归年依据** 承嘉平四年冬东兴战败，原注与前注的纳议说相左。处分实月未载；另见《晋书·文帝纪》。

[252年第5条](../../years/ce-0201-0300/ce-0252.md#sgz004-p-009-1)。

<a id="pei-009-2"></a>

**成济兄弟拒捕被杀的异载** 《魏氏春秋》说兄弟二人不肯伏罪，袒身登屋叫骂，下面放箭射杀。

**归年依据** 承260年五月司马昭归罪成济，具体拘捕日未另记。

## 030｜石苞在长安卖铁、为司马懿识用

Kanripo四库本 36a原行 646—648。附见[正文 L274](../本地分卷/三国志/三国志-卷004.md#l274)。

<a id="pei-030-1"></a>

> 世語曰初青龍中石苞鬻鐵於長安得見司馬宣王宣王知焉後擢為尚書郎歴青州刺史鎮東將軍

**石苞在长安卖铁、为司马懿识用** 《世语》说石苞青龙年间卖铁，因被司马懿识拔，后来升尚书郎并历任青州刺史、镇东将军。

**归年依据** 青龙只定233–237，举用和迁官跨更长时期，见《晋书·石苞传》。

[石苞在长安卖铁、为司马懿识用（时期）](../../years/ce-0201-0300/时期-三国志卷004-三少帝纪纪年待考.md#period-sgz004-p-030-1)。

<a id="pei-030-2"></a>

> 甘露中入朝當還辭高貴鄉公留中盡日文王遣人要令過文王問苞何淹留也苞曰非常人也明日發至滎陽數日而難作

**石苞离洛阳后，曹髦事件发生** 石苞还镇前曹髦留谈整日，司马昭派人召问，石苞称曹髦是非常之人；翌日启程，才出到荥阳数日便发曹髦被杀事。

**归年依据** “數日而難作”与甘露五年五月曹髦遇害相接，按这一叙事可系260。

<a id="pei-031-1"></a>

> 漢晉春秋曰晉公既進爵為王太尉王祥司徒何曾司空荀顗並詣王顗曰相王尊重何侯與一朝之臣皆已盡敬今日便當相率而拜無所疑也祥曰相國位勢誠為尊貴然要是魏之宰相吾等魏之三公公王相去一階而已班列大同安有天子三公可輙拜人者損魏朝之望虧晉王之德君子愛人以禮吾不為也及入顗遂拜而祥獨長揖王謂祥曰今日然後知君見顧之重

**归年依据** 附咸熙元年三月司马昭进爵为晋王，注谓既进爵。《晋书·王祥传》亦有此事。

## 034｜全琮攻芍陂及吴三路进兵

维基文库四库本原行 12—12。附见[正文 L218](../本地分卷/三国志/三国志-卷004.md#l218)。

<a id="pei-034-1"></a>

> 干寳晉紀曰吳將全琮寇芍陂朱然孫倫五萬人圍樊城諸葛瑾步騭寇柤中琮已破走而樊圍急

**全琮攻芍陂及吴三路进兵** 干宝《晋纪》记全琮攻芍陂，朱然、孙伦围樊，诸葛瑾、步骘入柤中。全琮转退而樊围仍急。

**归年依据** 附正始二年吴攻魏，《吴主传》赤乌四年记三路。孙伦保留维基四库底本文字，它本作孙纶。

[241年第9条](../../years/ce-0201-0300/ce-0241.md#sgz004-p-034-1)。

<a id="pei-034-2"></a>

> 宣王曰柤中民夷十萬隔在水南流離無主樊城被攻歴月不解此危事也請自討之議者咸言賊逺圍樊城不可抜剉於堅城之下有自破之勢宜長策以御之宣王曰軍志有之將能而御之此為糜軍不能而任之此為覆軍今疆塲騷動民心疑惑是社稷之大憂也六月督諸軍南征車駕送津陽城門外宣王以南方暑溼不宜持久使輕騎挑之然不敢動於是乃令諸軍休息洗沐簡精鋭募先登申號令示必攻之勢然等聞之乃夜遁追至三州口大殺獲

**司马懿发兵救樊，朱然等撤退** 司马懿反对迟救，六月督诸军南征，曹芳在津阳门外送行。司马懿派轻骑挑敌、整兵示攻，朱然等夜遁，魏追至三州口。

**归年依据** 同正始二年六月，《吴主传》记五月救樊、六月军还，均在241。

[241年第2条](../../years/ce-0201-0300/ce-0241.md#sgz004-p-034-2)。

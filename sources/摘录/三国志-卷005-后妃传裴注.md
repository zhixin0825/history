## 001｜卞氏生于齊郡白亭

Kanripo四库本 2a—2b原行 44—46。附见[正文 L304](../本地分卷/三国志/三国志-卷005.md#l304)。

<a id="pei-001-1"></a>

> 魏書曰后以漢延熹三年十二月己巳生齊郡白亭有黃氣滿室移日父敬侯怪之以問卜者王旦旦曰此吉祥也

**卞氏生于齊郡白亭** 《魏书》记卞氏延熹三年十二月己巳出生在齐郡白亭，又叙出生见黄气、占者称吉的传说。

**归年依据** 注文直书延熹三年，异象只作为《魏书》的记述。

[160年第21条](../../years/ce-0101-0200/ce-0160.md#sgz005-p-001-1)。

## 002｜丁夫人养曹昂

Kanripo四库本 2b—3a原行 52—61。附见[正文 L304](../本地分卷/三国志/三国志-卷005.md#l304)。

<a id="pei-002-1"></a>

> 魏畧曰太祖始有丁夫人又劉夫人生子脩及清河長公主劉早終丁養子脩

**丁夫人养曹昂** 曹操先有丁夫人，刘夫人生曹昂与清河公主后早卒，丁夫人抚养曹昂。

**归年依据** 早年家事，时间只明在曹昂197年战死之前。

[丁夫人养曹昂（时期）](../../years/ce-0201-0300/时期-三国志卷005-后妃传纪年待考.md#period-sgz005-p-002-1)。

<a id="pei-002-2"></a>

> 子脩亡於穰丁常言將我兒殺之都不復念遂哭泣無節太祖忿之遣歸家欲其意折

**曹昂死，丁夫人悲泣** 《魏略》称曹昂阵亡后，丁夫人责曹操送子赴死，曹操把她遣回娘家。

**归年依据** 卷001在197年宛城战记曹昂遇害；注称“穰”，保存地名差异。遣归只依事件相接，精确日月不明。

[197年第10条](../../years/ce-0101-0200/ce-0197.md#sgz005-p-002-2)。

<a id="pei-002-3"></a>

> 後太祖就見之夫人方織外人傳云公至夫人踞機如故太祖到撫其背曰顧我共載歸乎夫人不顧又不應太祖却行立於户外復云得無尚可邪遂不應太祖曰真訣矣遂與絶欲其家嫁之其家不敢初丁夫人既為嫡加有子脩丁視后母子不足后為繼室不念舊惡因太祖出行常四時使人饋遺又私迎之延以上坐而已下之迎來送去有如昔日丁謝曰廢放之人夫人何能常爾邪其後丁亡后請太祖殯葬許之乃葬許城南

**曹操与丁夫人断绝，卞氏厚待丁氏** 曹操上门求丁夫人复归未果。卞氏成为继室后仍按节送礼，以原夫人之礼相待；丁氏死后卞氏代请料理丧葬。

**归年依据** 曹昂死后、曹操病困前的长期经过，初次劝归、离异、改立继室、丧葬分别无明年。

[曹操与丁夫人断绝，卞氏厚待丁氏（时期）](../../years/ce-0201-0300/时期-三国志卷005-后妃传纪年待考.md#period-sgz005-p-002-3)。

<a id="pei-002-4"></a>

> 後太祖病困自慮不起歎曰我前後行意於心未曽有所負也假令死而有靈子脩若問我母所在我將何辭以答

**曹操病中想起丁夫人和曹昂** 曹操病重自料不起，想到死后若曹昂问丁夫人何在，不知如何作答。

**归年依据** 紧承曹操病困且“自慮不起”，可附220年去世，注文未明独立日月。

[220年第1条](../../years/ce-0201-0300/ce-0220.md#sgz005-p-002-4)。

<a id="pei-002-5"></a>

> 魏書曰后性約儉不尚華麗無文繡珠玉器皆黑漆太祖常得名璫數具命后自選一具后取其中者太祖問其故對曰取其上者為貪取其下者為偽故取其中者

**卞氏生活俭约，选择中等耳饰** 《魏书》述卞氏生活俭朴。曹操让她从数对耳饰中挑选，她选中等，以免贪好或故作清高。

**归年依据** 在曹操生时，缺确年。

[卞氏生活俭约，选择中等耳饰（时期）](../../years/ce-0201-0300/时期-三国志卷005-后妃传纪年待考.md#period-sgz005-p-002-5)。

## 003｜卞太后节省御食、撤去金银器皿

Kanripo四库本 3b—4a原行 70—78。附见[正文 L305](../本地分卷/三国志/三国志-卷005.md#l305)。

<a id="pei-003-1"></a>

> 魏書曰后以國用不足减損御食諸金銀器物皆去之

**卞太后节省御食、撤去金银器皿** 《魏书》称卞氏因国用不足减御食、去金银器。

**归年依据** 附在称太后后，皇太后时期为220—226，未见单独施行年。

[卞太后节省御食、撤去金银器皿（时期）](../../years/ce-0201-0300/时期-三国志卷005-后妃传纪年待考.md#period-sgz005-p-003-1)。

<a id="pei-003-2"></a>

> 東阿王植太后少子最愛之後植犯法為有司所奏文帝令太后弟子奉車都尉蘭持公卿議白太后太后曰不意此兒所作如是汝還語帝不可以我故壊國法及自見帝不以為言

**卞太后答复曹植犯法案** 曹植被有司弹劾，曹丕使卞兰把公卿议论报太后。卞氏劝勿因自己毁国法。

**归年依据** 曹植遭有司劾而贬见卷019黄初二年。后称东阿王是追称，曹植在曹丕朝尚未封东阿。

[221年第30条](../../years/ce-0201-0300/ce-0221.md#sgz005-p-003-2)。

<a id="pei-003-3"></a>

> 臣松之案文帝夢磨錢欲使文滅而更愈明以問周宣宣答曰此陛下家事雖意欲爾而太后不聽則太后用意不得如此書所言也

**裴松之以曹丕问梦考校卞太后说** 裴松之引曹丕问周宣磨钱之梦，指出“太后不听”与《魏书》形象并不容易相合。

**归年依据** 问梦无独立年份，以曹丕在位为限，其所指是否即221年弹劾存疑。

[裴松之以曹丕问梦考校卞太后说（时期）](../../years/ce-0201-0300/时期-三国志卷005-后妃传纪年待考.md#period-sgz005-p-003-3)。

<a id="pei-003-4"></a>

> 魏書又曰太后每隨軍征行見高年白首輙住車呼問賜與絹帛對之涕泣曰恨父母不及我時也太后每見外親不假以顔色常言居處當務節儉不當望賞賜念自佚也外舍常怪吾遇之太薄吾自有常度故也吾事武帝四五十年行儉日久不能自變為奢有犯科禁者吾且能加罪一等耳莫望錢米恩貸也帝為太后弟秉起第第成太后幸第請諸家外親設下厨無異膳太后左右菜食粟飯無魚肉其儉如此

**卞太后见老人赐帛、要求外戚节俭** 卞氏行军途中赐帛给老人，常告诫外戚勿求赏、勿犯禁；曹丕为卞秉建宅，卞太后赴宅，饮食仍俭朴。

**归年依据** 行军、告诫及宫中饮食是长期行为，建宅具体年月未载。

[卞太后见老人赐帛、要求外戚节俭（时期）](../../years/ce-0201-0300/时期-三国志卷005-后妃传纪年待考.md#period-sgz005-p-003-4)。

Kanripo四库本 5a原行 91—94。附见[正文 L307](../本地分卷/三国志/三国志-卷005.md#l307)。

## 006｜卞兰数谏曹叡并拒饮符水

Kanripo四库本 5a原行 94—97。附见[正文 L307](../本地分卷/三国志/三国志-卷005.md#l307)。

<a id="pei-006-1"></a>

> 魏畧曰明帝時蘭見外有二難而帝留意於宫室常因侍從數切諫帝雖不能從猶納其誠欵後蘭苦酒消渴時帝信巫女用水方使人持水賜蘭蘭不肯飲詔問其意蘭言治病自當以方藥何信於此帝為變色而蘭終不服後渴稍甚以至於亡故時人見蘭好直言謂帝面折之而蘭自殺其實不然

**卞兰数谏曹叡并拒饮符水** 卞兰常规劝曹叡停止营宫；患消渴后拒用巫水，病卒。《魏略》驳斥他因君臣争执自杀的传言。

**归年依据** 在曹叡朝226—239，注文只给前后次序。

**甄逸婚姻与儿女** 甄逸娶常山张氏，生三男五女，诸兄履历连叙。

<a id="pei-008-1"></a>

> 魏畧曰后年十四䘮中兄儼悲哀過制事寡嫂謙敬事處其勞撫養儼子慈愛甚篤后母性嚴待諸婦有常后數諫母兄不幸早終嫂年少守節顧留一子以大義言之待之當如婦愛之宜如女母感后言流涕便令后與嫂共止寢息坐起常相隨恩愛益密

## 009｜甄氏留在邺侍奉婆母

Kanripo四库本 6b—7b原行 120—136。附见[正文 L310](../本地分卷/三国志/三国志-卷005.md#l310)。

<a id="pei-009-1"></a>

> 魏畧曰熙出在幽州后留侍姑

**甄氏留在邺侍奉婆母** 袁熙去幽州，甄氏留侍袁绍妻刘氏。

**归年依据** 建安年间、204年邺城陷落前。

[甄氏留在邺侍奉婆母（时期）](../../years/ce-0201-0300/时期-三国志卷005-后妃传纪年待考.md#period-sgz005-p-009-1)。

<a id="pei-009-2"></a>

> 及鄴城破紹妻及后共坐室堂上文帝入紹舍見紹妻及后后怖以頭伏姑膝上紹妻兩手自搏文帝謂曰劉夫人云何如此令新婦舉頭姑乃捧后令仰文帝就視見其顔色非凡稱歎之太祖聞其意遂為迎取世語曰太祖下鄴文帝先入袁尚府有婦人披髪垢面垂涕立紹妻劉後文帝問之劉荅是熙妻顧擥髪髻以巾拭面姿貌絶倫既過劉謂后不憂死矣遂見納有寵

**曹丕在邺见甄氏并纳入后宫** 《魏略》称曹丕见甄氏伏在婆母膝上，由曹操代为迎取。《世语》称曹丕先入袁尚家，替甄氏拭面，后纳之。

**归年依据** 两种说法都以建安九年邺城陷落为时点。人物位置和迎取经过有别。

[204年第1条](../../years/ce-0201-0300/ce-0204.md#sgz005-p-009-2)。

<a id="pei-009-3"></a>

> 魏書曰后寵愈隆而彌自挹損後宮有寵者勸勉之其無寵者慰誨之毎因閑宴常勸帝言昔黄帝子孫蕃育蓋由妾媵衆多乃獲斯祚耳所願廣求淑媛以豐繼嗣帝心嘉焉其後帝欲遣任氏后請於帝曰任既鄉黨名族德色妾等不及也如何遣之帝曰任性狷急不婉順前後忿吾非一是以遣之耳后流涕固請曰妾受敬遇之恩衆人所知必謂任之出是妾之由上懼有見私之譏下受專寵之罪願重留意帝不聽遂出之

**甄氏劝广纳后宫，为任氏求情** 《魏书》称甄氏劝曹丕广纳淑女、多育后嗣，并为被遣任氏流泪说情，曹丕没有采纳。

**归年依据** 在曹丕纳甄氏之后、221年以前。任氏被遣没有独立年月。

**《魏略》所载郭太后殡葬异说** 李夫人向曹叡述甄后受害及非常殡敛，曹叡下令郭后也照甄后旧例殡敛。

**归年依据** 附在郭太后卒葬段，235年。甄后掩发的内容为所回忆的221年殡敛。

[235年第6条](../../years/ce-0201-0300/ce-0235.md#sgz005-p-017-2)。

<a id="pei-017-3"></a>

> 漢晉春秋曰初甄后之誅由郭后之寵及殯令被髮覆面以糠塞口

**《汉晋春秋》称甄后因郭氏受宠被杀** 《汉晋春秋》称甄后下葬时被以发覆面、以糠塞口。

**归年依据** 据本传甄后于221年死。引书叙原因及丧葬异说。

[221年第21条](../../years/ce-0201-0300/ce-0221.md#sgz005-p-017-3)。

<a id="pei-017-4"></a>

> 遂立郭后使養明帝

**郭氏被立并抚养曹叡的说法** 《汉晋春秋》称郭氏被立为后，并抚养曹叡。

**归年依据** 立后见黄初三年；开始抚养曹叡时日未另记。

[222年第22条](../../years/ce-0201-0300/ce-0222.md#sgz005-p-017-4)。

<a id="pei-017-5"></a>

> 帝知之心常懐忿數泣問甄后死狀郭后曰先帝自殺何以責問我且汝為人子可追讐死父為前母枉殺後母邪明帝怒遂逼殺之勅殯者使如甄后故事

**《汉晋春秋》称曹叡逼死郭太后** 曹叡追问生母死状，郭太后以父母名分反诘，曹叡怒而逼死她，命殡敛如甄后。

**归年依据** 与《魏略》“忧暴崩”异，系郭太后卒葬的235年。对话仅依该书。

[235年第4条](../../years/ce-0201-0300/ce-0235.md#sgz005-p-017-5)。

<a id="pei-017-6"></a>

> 魏書載哀䇿曰維青龍二年三月壬申皇太后梓宮啟殯將葬于首陽之西陵哀子皇帝叡親奉冊祖載遂親遣奠叩心擗踊號咷仰訴痛靈魂之遷幸悲容車之向路背三光以潛翳就黃壚而安厝嗚呼哀哉昔二女妃虞帝道以彰三母嬪周聖善彌光既多受祉享國延長哀哀慈妣興化閨房龍飛紫極作合聖皇不虞中年暴離災殃愍予小子㷀㷀摧傷魂雖永逝定省曷望嗚呼哀哉

**曹叡所制郭太后哀册与纪年冲突** 《魏书》载汉式哀册，述曹叡亲祭与哀痛，原注哀册开头写“青龙二年三月壬申”。

**归年依据** 不能把传正文和《明帝纪》同载的青龙三年戊子卒、三月庚寅葬改到234。哀册保留异年异日，系正文丧葬处互校。

[235年第6条](../../years/ce-0201-0300/ce-0235.md#sgz005-p-017-6)。

## 021｜郭后在册立时上表自谦

> 魏書曰后上表謝曰妾無皇英釐降之節又非姜任思齊之倫誠不足以假充女君之盛位處中饋之重任

## 004｜董卓拒受少府任命，不交部兵

Kanripo四库本 2a—2b原行 39—44。附见[正文 L329](../本地分卷/三国志/三国志-卷006.md#l329)。

<a id="pei-004-1"></a>

> 靈帝紀曰中平五年徵卓為少府勅以營吏士屬左將軍皇甫嵩詣行在所卓上言凉州擾亂鯨鯢未减此臣奮發効命之秋吏士踊躍戀恩念報各遮臣車辭聲懇惻未得即路也輙且行前將軍事盡心慰卹効力行陣

**董卓拒受少府任命，不交部兵** 《灵帝纪》称朝廷征董卓为少府并命其麾下属皇甫嵩，董卓上书以边患未减、将士恋恩为辞，称将继续行前将军事。

**归年依据** 《灵帝纪》逸文作中平五年（188），《后汉书·董卓传》作中平六年（189）。并州牧任命是随后另一事。

[188年第37条](../../years/ce-0101-0200/ce-0188.md#sgz006-p-004-1)。

<a id="pei-004-2"></a>

> 六年以卓為并州牧又勅以吏兵屬皇甫嵩卓復上言臣掌戎十年士卒大小相狎彌久戀臣畜養之恩樂為國家奮一旦之命乞將之州効力邊陲卓再違詔勅會為何進所召

**董卓再拒交兵皇甫嵩** 朝廷任董卓并州牧，再要求交兵。董卓以掌兵十年、士卒恋恩为辞，希望带兵赴边，后来受何进召。

**归年依据** 注自署中平六年，与后汉书、正文皆可对读。

[189年第57条](../../years/ce-0101-0200/ce-0189.md#sgz006-p-004-2)。

## 005｜何进家世和由妹进身

Kanripo四库本 2b—3a原行 48—54。附见[正文 L330](../本地分卷/三国志/三国志-卷006.md#l330)。

<a id="pei-005-1"></a>

> 漢記曰進字遂高南陽人太后異母兄也進本屠家子父曰真真死後進以妹倚黃門得入掖庭有寵

**何进家世和由妹进身** 《汉记》说何进出身屠家，是太后异母兄，父名真，何氏入掖庭得宠。

**归年依据** 何氏具体入宫时间，本段无载。

[何进家世和由妹进身（时期）](../../years/ce-0201-0300/时期-三国志卷006-董二袁刘传纪年待考.md#period-sgz006-p-005-1)。

<a id="pei-005-2"></a>

> 光和三年立為皇后進由是貴幸

**何氏立为皇后，何进贵幸** 光和三年，何氏立为皇后，何进由此贵幸。

**归年依据** 注书光和三年，《后汉书·灵帝纪》同。

[180年第10条](../../years/ce-0101-0200/ce-0180.md#sgz006-p-005-2)。

<a id="pei-005-3"></a>

> 中平元年黃巾起拜進大將軍

**何进拜大将军** 黄巾起，朝廷以何进为大将军。

**归年依据** 注自书中平元年。

[184年第3条](../../years/ce-0101-0200/ce-0184.md#sgz006-p-005-3)。

<a id="pei-005-4"></a>

> 典畧載卓表曰臣伏惟天下所以有逆不止者各由黃門常侍張讓等侮慢天常操擅王命父子兄弟並據州郡一書出門便獲千金京畿諸郡數百萬膏腴美田皆屬讓等至使怨氣上蒸妖賊蠭起臣前奉詔討於扶羅將士饑乏不肯渡河皆言欲詣京師先誅閹豎以除民害從臺閣求乞資直臣隨慰撫以至新安臣聞揚湯止沸不如滅火去薪潰癰雖痛勝於養肉及溺呼船悔之無及

**董卓奏请除宦官** 《典略》载董卓上表指责张让等出卖官爵、兼并土地，把叛乱归给宦官，声称所部请先诛宦官，劝朝廷除患去根。

**归年依据** 何进召董卓带兵入京时，189；表中先前讨于扶罗是追记。

[189年第55条](../../years/ce-0101-0200/ce-0189.md#sgz006-p-005-4)。

## 006｜少帝与陈留王夜行

Kanripo四库本 3a—3b原行 56—66。附见[正文 L330](../本地分卷/三国志/三国志-卷006.md#l330)。

<a id="pei-006-1"></a>

> 張璠漢記曰帝以八月庚午為諸黃門所劫步出穀門走至河上諸黃門既投河死時帝年十四陳留王年九歲兄弟獨夜步行欲還宫闇瞑逐螢火而行數里得民家以露車載送

**少帝与陈留王夜行** 张璠《汉记》称少帝八月庚午被劫至河上，宦官投河后兄弟逐萤夜行、搭民车回京。

**归年依据** 《后汉书·孝献帝纪》庚午幸北宫、辛未步出穀门、小平津，和张璠所系日期略异。

[189年第24条](../../years/ce-0101-0200/ce-0189.md#sgz006-p-006-1)。

<a id="pei-006-2"></a>

> 辛未公卿以下與卓共迎帝於北芒阪下獻帝春秋曰先是童謡曰侯非侯王非王千乗萬騎走北芒卓時適至屯顯陽苑聞帝當還率衆迎帝典畧曰帝望見卓兵涕泣羣公謂卓曰有詔卻兵卓曰公諸人為國大臣不能匡正王室至使國家播蕩何卻兵之有遂俱入城獻帝紀曰卓與帝語語不可了乃更與陳留王語問禍亂由起王答自初至終無所遺失卓大喜乃有廢立意英雄記曰河南中部掾閔貢扶帝及陳留王上至雒舍止帝獨乗一馬陳留王與貢共乗一馬從雒舍南行公卿百官奉迎於北芒阪下故太尉崔烈在前導卓將步騎數千來迎烈呵使避卓罵烈曰晝夜三百里來何云避我不能斷卿頭邪前見帝曰陛下令常侍小黄門作亂乃爾以取禍敗為負不小邪又趨陳留王曰我董卓也從我抱來乃於貢抱中取王英雄記曰一本云王不就卓抱卓與王併馬而行也

**董卓迎帝的诸家记载** 《汉记》记北芒迎驾，《献帝春秋》记童谣与屯显阳苑，《典略》记董卓不肯退兵，《献帝纪》说董卓见陈留王对答而萌废立意，《英雄记》有抱王及并马两本。

**归年依据** 中平六年八月帝出返之际；保留辛未迎驾与《献帝纪》壬申还宫的表述。

[189年第27条](../../years/ce-0101-0200/ce-0189.md#sgz006-p-006-2)。

## 009｜董卓议废立，卢植反对

Kanripo四库本 4a—5a原行 77—90。附见[正文 L332](../本地分卷/三国志/三国志-卷006.md#l332)。

<a id="pei-009-1"></a>

> 獻帝紀曰卓謀廢帝會羣臣於朝堂議曰大者天地次者君臣所以為治今皇帝闇弱不可以奉宗廟為天下主欲依伊尹霍光故事立陳留王何如尚書盧植曰案尚書太甲既立不明伊尹放之桐宫昌邑王立二十七日罪過千餘故霍光廢之今上富於春秋行未有失非前事之比也卓怒罷坐欲誅植侍中蔡邕勸之得免

**董卓议废立，卢植反对** 《献帝纪》记董卓拟效伊尹、霍光废少立陈留王，卢植指出年龄与行迹不同，蔡邕劝董卓免杀卢植。

**归年依据** 中平六年九月甲戌正式废立前；《后汉书·卢植传》参见。

[189年第80条](../../years/ce-0101-0200/ce-0189.md#sgz006-p-009-1)。

<a id="pei-009-2"></a>

> 九月甲戌卓復大會羣臣曰太后逼廹永樂太后令以憂死逆婦姑之禮無孝順之節天子㓜質軟弱不君昔伊尹放太甲霍光廢昌邑著在典籍僉以為善今太后宜如太甲皇帝宜如昌邑陳留王仁孝宜即皇帝祚獻帝起居注載䇿曰孝靈皇帝不究高宗眉壽之祚早棄臣子皇帝承紹海内側望而帝天姿輕佻威儀不恪在䘮慢惰衰如故焉凶德既彰滛穢發聞損辱神器黍汚宗廟皇太后教無母儀統政荒亂永樂太后暴崩衆論惑焉三綱之道天地之紀而乃有闕罪之大者陳留王協聖德偉茂規矩邈然豐下兑上有堯圖之表居䘮哀戚言不及邪岐嶷之性有周成之懿休聲美稱天下所聞宜承洪業為萬世統可以承宗廟廢皇帝為弘農王皇太后還政尚書讀冊畢羣臣莫有言尚書丁宮曰天禍漢室䘮亂弘多昔祭仲廢忽立突春秋大其權今大臣量宜為社稷計誠合天人請稱萬歲

**董卓废少帝并宣废立策** 董卓责何太后、刘辩，宣布陈留王宜即位；《献帝起居注》录废立文书，丁宫排众请称万岁。

**归年依据** 裴注自书九月甲戌，参《后汉书·孝献帝纪》。

[189年第31条](../../years/ce-0101-0200/ce-0189.md#sgz006-p-009-2)。

<a id="pei-009-3"></a>

> 卓以太后見廢故公卿以下不布服會葬素衣而已

**何太后以素服送葬** 董卓以何太后已废为由，只许公卿穿素衣会葬。

**归年依据** 中平六年九月何氏被杀后，《献帝纪》十月葬灵思皇后。

[189年第40条](../../years/ce-0101-0200/ce-0189.md#sgz006-p-009-3)。

## 011｜周毖、伍琼名籍及伍孚仕历

Kanripo四库本 5b—6a原行 104—111。附见[正文 L333](../本地分卷/三国志/三国志-卷006.md#l333)。

<a id="pei-011-1"></a>

> 英雄記曰毖字仲逺武威人瓊字德瑜汝南人謝承後漢書曰伍孚字德瑜少有大節為郡門下書佐其本邑長有罪太守使孚出教勅曹下督郵收之孚不肯受教伏地仰諫曰君雖不君臣不可不臣明府柰何令孚受教勅外收本邑長乎乞更授他吏太守竒而聽之後大將軍何進辟為東曹屬稍遷侍中河南尹越騎校尉

**周毖、伍琼名籍及伍孚仕历** 《英雄记》记周毖和伍琼字号里籍；谢承书记伍孚早年为郡门下书佐，为本县长守臣礼，后来历任东曹属、侍中、河南尹、越骑校尉。

**归年依据** 各项出身、仕历无确年。

## 001｜丁原表字、出身与早年任吏

Kanripo四库本 1a原行 21—22。附见[正文 L374](../本地分卷/三国志/三国志-卷007.md#l374)。

<a id="pei-001-1"></a>

> 英雄記曰原字建陽本出自寒家為人麤略有武勇善騎射為南縣吏受使不辭難有警急追寇虜輒在其前裁知書少有吏用

**丁原表字、出身与早年任吏** 丁原字建阳，生于寒家，勇于骑射，做县吏时不辞危难，追捕在前，略通书文，年轻时便有办事能力。

## 003｜吕布与郭汜在长安城北交战

Kanripo四库本 2a原行 38—40。附见[正文 L376](../本地分卷/三国志/三国志-卷007.md#l376)。

<a id="pei-003-1"></a>

> 英雄記曰郭汜在城北布聞城門將兵就汜言且却兵但身决勝負汜布乃獨共對戰布以矛刺中汜汜後騎遂前救汜汜布遂各兩罷

**吕布与郭汜在长安城北交战** 郭汜在城北，吕布劝两军退开，两人单独搏斗。吕布以矛刺中郭汜，郭汜后骑驰救，双方随后停战。

**归年依据** 依附初平三年六月长安攻防，《英雄记》提供本传失城前的局部战斗。

## 004｜裴松之考董卓死至长安陷不足六十日

Kanripo四库本 2a—2b原行 40—42。附见[正文 L376](../本地分卷/三国志/三国志-卷007.md#l376)。

<a id="pei-004-1"></a>

> 臣松之案英雄記曰諸書布以四月二十三日殺卓六月一日敗走時又無閏不及六旬

**裴松之考董卓死至长安陷不足六十日** 《英雄记》等说吕布四月二十三日诛董卓、六月一日败走，中间没有闰月，裴松之据此质疑本传“六旬”。

**归年依据** 《后汉书·献帝纪》同纪初平三年四月辛巳诛董卓、六月戊午陷长安；均为同一年。

[192年第11条](../../years/ce-0101-0200/ce-0192.md#sgz007-p-004-1)。

## 006｜袁绍谋刺吕布，吕布逃回张杨处

Kanripo四库本 2b—3a原行 48—52。附见[正文 L377](../本地分卷/三国志/三国志-卷007.md#l377)。

<a id="pei-006-1"></a>

> 英雄記曰布自以有功於袁氏輕傲紹下諸将以為擅相署置不足貴也布求還洛紹假布領司隷校尉外言當遣内欲殺布明日當發紹遣甲士三十人辭以送布布使止於帳側偽使人於帳中鼓筝紹兵卧布無何出帳去而兵不覺夜半兵起亂砍布床被謂為已死明日紹訊問知布尚在乃閉城門布遂引去

## 007｜李傕郭汜悬赏购吕布，张杨暗中保护

Kanripo四库本 3a原行 53—55。附见[正文 L377](../本地分卷/三国志/三国志-卷007.md#l377)。

<a id="pei-007-1"></a>

> 英䧺記曰楊及部曲諸將皆受傕汜購募共圗布布聞之謂楊曰布卿州里也卿殺布於卿弱不如賣布可極得汜傕爵寵楊於是外許汜傕内實保䕶布汜傕患之更下大封詔書以布為潁川太守

## 008｜吕布东投刘备，以同出边地旧谊相待

Kanripo四库本 4b原行 78—80。附见[正文 L380](../本地分卷/三国志/三国志-卷007.md#l380)。

<a id="pei-008-1"></a>

> 英雄記曰布見備甚敬之謂備曰我與卿同邉地人也布見闗東起兵欲誅董卓布殺卓東出闗東諸將無安布者皆欲殺布耳請備於帳中坐婦牀上令婦向拜酌酒飲食名備為弟備見布語言無常外然之而内不説

**吕布东投刘备，以同出边地旧谊相待** 吕布礼待刘备，提到自己杀董卓后关东诸将不相容，邀刘备在帐中坐妻床，让妻向他敬拜并设饮食，呼为弟。刘备以其言行无常而表面接受、心里不悦。

**归年依据** 《英雄记》所说见刘备，接兴平二年吕布失兖州东奔，所叙杀卓及东出武关属初平三年旧事。

## 009｜张邈是否见袁术并劝阻僭号

Kanripo四库本 4b—5a原行 82—87。附见[正文 L381](../本地分卷/三国志/三国志-卷007.md#l381)。

<a id="pei-009-1"></a>

> 獻帝春秋曰袁術議稱尊號邈謂術曰漢據火徳絶而復揚徳澤豐流誕生明公公居軸處中入則享于上席出則為衆目之所屬華霍不能増其高淵泉不能同其量可謂巍巍蕩蕩無與為貳何為捨此而欲稱制恐福不盈眥禍將溢世荘周之稱郊祭犧牛養飼經年衣以文繡宰執鸞刀以入廟門當此之時求為孤犢不可得也按本傳邈詣術未至而死而此云諫稱尊號未詳孰是

**张邈是否见袁术并劝阻僭号** 《献帝春秋》载张邈以汉室仍复兴、袁术位望已极及郊祭牲牛之喻，劝其莫为称帝招祸；裴松之指出本传记张邈未见袁术即被杀。

**归年依据** 本传记张邈兴平二年求救未至而死；已有同年袁术议尊号、阎象劝谏，也不能用来确定出自异传的对话。

## 010｜袁术致书利诱吕布袭下邳

Kanripo四库本 5a—6a原行 88—107。附见[正文 L382](../本地分卷/三国志/三国志-卷007.md#l382)。

<a id="pei-010-1"></a>

> 英䧺記曰布初入徐州書與袁術術報書曰昔董卓作亂破壊王室禍害術門戸術舉兵闗東未能屠裂卓將軍誅卓送其頭首為術掃滅讐恥使術明目於當世死生不愧其功一也昔將金元休向兖州甫詣封部為曹操逆所拒破流離迸走幾至滅亡將軍破兖州術復明目於遐邇其功二也術生年已來不聞天下有劉備備乃舉兵與術對戰術憑將軍威靈得以破備其功三也將軍有三大功在術術雖不敏奉以生死將軍連年攻戰軍糧苦少今送米二十萬斛迎逢道路非直此止當駱驛復致若兵器戰具佗所乏少大小唯命布得書大喜遂造下邳

**袁术致书利诱吕布袭下邳** 袁术说吕布有诛董卓、攻占兖州、助破刘备三功，称要输二十万斛米、再供器械；吕布得书大喜，赴下邳。

**归年依据** 本传、《先主传》及武帝纪 L35定袭下邳在建安元年。信所举诛董192、金尚遭曹操拒入兖州192、吕布攻兖194均是回叙。

[196年第42条](../../years/ce-0101-0200/ce-0196.md#sgz007-p-010-1)。

<a id="pei-010-2"></a>

> 典略曰元休名尚京兆人也尚與同郡韋休甫第五文休俱著名號為三休

**金尚与二休并称** 元休名金尚，为京兆人；金尚与同郡韦休甫、第五文休并称三休。

**归年依据** 人物名号未载起年。

[金尚与二休并称（时期）](../../years/ce-0201-0300/时期-三国志卷007-吕布臧洪传纪年待考.md#period-sgz007-p-010-2)。

<a id="pei-010-3"></a>

> 尚獻帝初為兖州刺史東之郡而太祖已臨兖州尚南依袁術

**金尚受命往兖州，被曹操拒绝后投袁术** 献帝初，金尚任兖州刺史，曹操已掌兖州，金尚于是南依袁术。

**归年依据** 《通鉴》卷060 L396–400系初平三年朝廷任金尚，受曹操击而投袁术。

[192年第42条](../../years/ce-0101-0200/ce-0192.md#sgz007-p-010-3)。

<a id="pei-010-4"></a>

> 術僣號欲以尚為太尉不敢顯言私使人諷之尚無屈意術亦不敢彊也建安初尚逃還為術所害

**袁术杀拒受伪命的金尚** 袁术僭号后暗劝金尚做太尉，金尚没有屈服；袁术起初不敢强迫，金尚逃离时被袁术杀害。

**归年依据** 《通鉴》卷062 L371–380系袁术建安二年称帝之后、当年三月之前，裴注仅说“建安初”。

[197年第26条](../../years/ce-0101-0200/ce-0197.md#sgz007-p-010-4)。

<a id="pei-010-5"></a>

> 其後尚喪與太傅馬日磾喪俱至京師天子嘉尚忠烈為之咨嗟詔百官弔祭拜子瑋郎中而日磾不與焉

**金尚灵柩抵京并获诏吊祭** 金尚灵柩与太傅马日磾之丧俱至京，献帝褒其忠烈，诏百官吊祭、拜其子金玮为郎中；马日磾没有受到同样礼遇。

**归年依据** 《通鉴》卷062 L477–482于建安二年十一月前记两丧抵京和朝廷不同处置。马日磾本人早于194年卒，子句所叙是归丧。

[197年第27条](../../years/ce-0101-0200/ce-0197.md#sgz007-p-010-5)。

<a id="pei-010-6"></a>

> 英䧺記日布水陸東下軍到下邳西四十里備中郎將丹陽許耽夜遣司馬章誑來詣布言張益徳與下邳相曹豹共爭益徳殺豹城中大亂不相信丹陽兵有千人屯西白城門内聞將軍來東大小踴躍如復更生將軍兵向城西門丹陽軍便開門内將軍矣布遂夜進晨到城下天明丹陽兵悉開門内布兵布於門上坐歩騎放火大破益徳兵獲備妻子軍資及部曲將吏士家口

**丹杨兵开门迎吕布，吕布袭下邳** 吕布水陆东进，许耽遣司马章诳夜报张飞杀曹豹、城中大乱，并请走西门；丹杨兵开门后吕布纵骑步兵燃火，击破张飞，所得有刘备家人与军资部众。

**归年依据** 《先主传》、武帝纪 L35及《通鉴》卷062皆系建安元年。张飞与曹豹争端，通鉴主文和考异另述说法。

[196年第42条](../../years/ce-0101-0200/ce-0196.md#sgz007-p-010-6)。

<a id="pei-010-7"></a>

> 建安元年六月夜半時布將河内郝萌反將兵入布所治下邳府詣㕔事閤外同聲大呼攻閤閤堅不得入布不知反者為誰直牽婦科頭袒衣相將從溷上排壁出詣都督高順營直排順門入順問將軍有所隠不布言河内兒聲順言此郝萌也順即嚴兵入府弓弩並射萌衆萌衆亂走天明還故營萌將曹性反萌與對戰萌刺傷性性斫萌一臂順斫萌首牀輿性送詣布

**郝萌夜袭吕布，被高顺平定** 郝萌半夜攻击吕布所居府署，吕布带妻子翻出至高顺营；高顺认出叛者，率兵射退之。曹性伤郝萌一臂，高顺斩郝萌送曹性见吕布。

**归年依据** 《英雄记》明建安元年六月夜半。曹性由叛军倒戈而后受吕布任命，同一曲折。

[196年第52条](../../years/ce-0101-0200/ce-0196.md#sgz007-p-010-7)。

<a id="pei-010-8"></a>

> 布問性言萌受袁術謀謀者悉誰性言陳宫同謀時宫在坐上面赤傍人悉覺之布以宫大將不問也性言萌常以此問性言呂將軍大將有神不可擊也不意萌狂惑不止布謂性曰卿徤兒也善養視之創愈使安撫萌故營領其衆

**郝萌夜袭吕布，被高顺平定** 曹性供称郝萌受袁术指使、陈宫同谋；陈宫在座脸红，吕布以其为大将而不问。曹性自谓曾劝阻郝萌，吕布命他养伤后统领郝萌旧众。

**归年依据** 承建安元年六月郝萌事；袁术与陈宫所涉是曹性供述。

[196年第52条](../../years/ce-0101-0200/ce-0196.md#sgz007-p-010-8)。

## 011｜献帝在河东召吕布，朝廷任其平东将军

Kanripo四库本 7a—7b原行 127—135。附见[正文 L383](../本地分卷/三国志/三国志-卷007.md#l383)。

<a id="pei-011-1"></a>

> 英䧺記曰初天子在河東有手筆版書召布來迎布軍無畜積不能自致遣使上書朝廷以布為平東將軍封平陶侯使人於山陽界亡失文字

**献帝在河东召吕布，朝廷任其平东将军** 献帝在河东亲笔召吕布来迎，吕布军无积蓄不能前往，遣使上书，朝廷授平东将军、平陶侯，授命文书在山阳遗失。

**归年依据** 献帝自兴平二年冬停河东至建安元年夏东还洛阳；此处只写在河东与失文书，无独立确年。

**归年依据** 《通鉴》卷059 L598–603将事全置初平元年；本传与《后汉书·臧洪传》L4318叙焦和卒和臧洪出使幽冀以后接任相连，跨年有疑。

## 024｜公孙瓒表称袁绍杀刘勋，裴松之疑即子璜

> 臣松之案公孫瓉表列紹罪過云紹與故虎牙將軍劉勲首共造兵勲仍有效而以小忿枉害於勲紹罪七也疑此是子璜也

## 025｜徐众评论臧洪救张超及反袁绍

Kanripo四库本 21a原行 378—382。附见[正文 L398](../本地分卷/三国志/三国志-卷007.md#l398)。

<a id="pei-025-1"></a>

> 徐衆三國評曰洪敦天下名義救舊君之危其恩足以感人情義足以勵薄俗然袁亦知己親友致位州郡雖非君臣且實盟主既受其命義不應貳袁曹方睦夾輔皇室呂布反覆無義志在逆亂而邈超擅立布為州牧其於王法乃一罪人也曹公討之袁氏弗救未為非理也洪本不當就袁請兵又不當還為怨讐為洪計者茍力所不足可奔他國以求赴救若謀力未展以待事機則宜徐更觀釁效死於超何必誓守窮城而無變通身死殄民功名不立良可哀也

**徐众评论臧洪救张超及反袁绍** 徐众肯定臧洪救故主之义，又认为袁绍任用臧洪且为盟主，张超等拥吕布有罪，袁不救亦有理由，臧洪可寻其它救策，不该与袁结仇坚守至死、连累百姓。

**归年依据** 属《三国评》后见之论，话及兴平元年迎吕布、兴平二年救张超及其后围城。

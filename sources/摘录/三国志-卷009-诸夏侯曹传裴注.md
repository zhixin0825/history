## 001｜东汉光武时阴贵人母弟遭劫

Kanripo四库本 2a原行 40—42。附见[正文 L445](../本地分卷/三国志/三国志-卷009.md#l445)。

<a id="pei-001-1"></a>

> 孫盛曰案光武紀建武九年盗劫隂貴人母弟吏以不得拘質廹盗盗遂殺之也

**东汉光武时阴贵人母弟遭劫** 孙盛引《光武纪》，称建武九年贼劫持阴贵人母弟，吏受制不能逼贼，贼竟杀人。

**归年依据** 注自标建武九年。《后汉书·皇后纪》详阴贵人母邓氏及弟訢同被贼杀，帝甚伤之，正文朝代和裴注引年可互比。

[33年第13条](../../years/ce-0001-0100/ce-0033.md#sgz009-p-001-1)。

<a id="pei-001-2"></a>

> 然則合擊者乃古制也自安順已降政教陵遲劫質不避王公而有司莫能遵奉國憲者

**孙盛考旧制与安顺以后劫质** 孙盛认为合击劫质者是古制，安帝、顺帝以来政教衰微，连王公也遭劫，而有司不遵国宪。

**归年依据** 历朝制度评价无单年，另分当时事。

[孙盛考旧制与安顺以后劫质（时期）](../../years/ce-0201-0300/时期-三国志卷009-诸夏侯曹传纪年待考.md#period-sgz009-p-001-2)。

<a id="pei-001-3"></a>

> 浩始復斬之故魏武嘉焉

**韩浩救出夏侯惇** 孙盛说韩浩恢复依律诛杀劫质者，故曹操赞赏。

**归年依据** 正文 L445 和卷010 L504兴平元年吕布袭濮阳同役。

[194年第58条](../../years/ce-0101-0200/ce-0194.md#sgz009-p-001-3)。

## 002｜军中叫夏侯惇“盲夏侯”

Kanripo四库本 2a原行 43—44。附见[正文 L446](../本地分卷/三国志/三国志-卷009.md#l446)。

<a id="pei-002-1"></a>

**军中叫夏侯惇“盲夏侯”** 夏侯惇和夏侯渊同为将军，有人称夏侯惇“盲夏侯”。他对此生气，照镜恼怒便把镜掷地。

## 003｜夏侯惇固请任魏前将军

Kanripo四库本 3a原行 55—57。附见[正文 L446](../本地分卷/三国志/三国志-卷009.md#l446)。

<a id="pei-003-1"></a>

> 魏書曰時諸將皆受魏官號惇獨漢官乃上疏自陳不當不臣之禮太祖曰吾聞太上師臣其次友臣夫臣者貴徳之人也區區之魏而臣足以屈君乎惇固請乃拜為前將軍

**夏侯惇固请任魏前将军** 其余诸将皆领魏官，夏侯惇独领汉官。他上疏自请任魏官，曹操最初谓师友不应屈于臣礼，夏侯惇固请，才拜前将军。

**归年依据** 本传 L446承建安二十四年曹军屯摩陂后，卷002 L130明220二月以前已拜前将军。

**归年依据** 《魏略》在夏侯楙西还后记“其後”，仅限明帝时，没给年月。

## 006｜韩浩在县聚众御盗

维基文库四库本原行 11—11。附见[正文 L449](../本地分卷/三国志/三国志-卷009.md#l449)。

<a id="pei-006-1"></a>

> 魏書曰韓浩字元嗣漢末兵起縣近山藪多寇浩聚徒衆為縣藩衞

**韩浩在县聚众御盗** 韩浩字元嗣，汉末县近山泽多盗，他聚众保护本县。

**归年依据** 泛言汉末起兵，无确年。

[韩浩在县聚众御盗（时期）](../../years/ce-0201-0300/时期-三国志卷009-诸夏侯曹传纪年待考.md#period-sgz009-p-006-1)。

<a id="pei-006-2"></a>

> 太守王匡以為從事將兵拒董卓於盟津時浩舅杜陽為河隂令卓執之使招浩浩不從

**王匡以韩浩拒董卓于盟津** 王匡以韩浩为从事，使领兵拒董卓于盟津；董卓抓其任河阴令的舅杜阳招他，他不降。

**归年依据** 卷001 L8–9、卷006《董卓传》及《通鉴》卷059记初平元年王匡参加讨董和河阳津攻防。

<a id="pei-006-3"></a>

> 袁術聞而壯之以為騎都尉夏侯惇聞其名請與相見大竒之使領兵從征伐

**袁术任韩浩骑都尉，夏侯惇召其从军** 袁术赏识韩浩任骑都尉，夏侯惇闻名相见后奇之，使带兵出征。

**归年依据** 在初平元年拒董之后，兴平元年已为夏侯惇将，往从具体年月未载。

[袁术任韩浩骑都尉，夏侯惇召其从军（时期）](../../years/ce-0201-0300/时期-三国志卷009-诸夏侯曹传纪年待考.md#period-sgz009-p-006-3)。

<a id="pei-006-4"></a>

> 時大議損益浩以為當急田太祖善之遷護軍

**韩浩倡急务屯田，曹操纳言** 议国家措施时韩浩主张赶紧发展屯田，曹操认同，升他做护军。

**归年依据** 卷001 L38明确建安元年用枣祗、韩浩议始屯田，升任在注内相接。

[196年第41条](../../years/ce-0101-0200/ce-0196.md#sgz009-p-006-4)。

<a id="pei-006-5"></a>

> 太祖欲討栁城領軍史渙以為道逺深入非完計也欲與浩共諫浩曰今兵勢彊盛威加四海戰勝攻取無不如志不以此時遂除天下之患將為後憂且公神武舉無遺䇿吾與君為中軍主不宜沮衆

**韩浩反驳史涣反对深征柳城意见** 史涣以深入过远劝与韩浩同谏，韩浩认为曹军正盛应乘时除患，也不当以统军主帅身分扰军心。

**归年依据** 卷001 L71–72明建安十二年攻柳城；王沈《魏书》补中军将议。

[207年第16条](../../years/ce-0201-0300/ce-0207.md#sgz009-p-006-5)。

<a id="pei-006-6"></a>

> 遂從破栁城改其官為中護軍置長史司馬

**韩浩从破柳城，改中护军** 韩浩随军打破柳城，改官为中护军，设长史、司马。

**归年依据** 卷001 L71–72明建安十二年破蹋顿的柳城战后。

[207年第1条](../../years/ce-0201-0300/ce-0207.md#sgz009-p-006-6)。

<a id="pei-006-7"></a>

> 從討張魯魯降議者以浩智略足以綏邉欲留使都督諸軍鎮漢中太祖曰吾安可以無護軍乃與俱還其見親任如此

**平汉中后曹操不舍韩浩留守** 韩浩随攻张鲁，张鲁归降，有人建议留韩浩督汉中，曹操不愿没有护军，把他带回。

**归年依据** 卷001 L100–105、卷008《张鲁传》及通鉴卷067记建安二十年冬张鲁降、曹操还军。

[215年第11条](../../years/ce-0201-0300/ce-0215.md#sgz009-p-006-7)。

<a id="pei-006-8"></a>

> 及薨太祖愍惜之無子以養子榮嗣

**韩浩去世，养子韩荣继嗣** 韩浩死后曹操哀惜，韩浩无亲子，以养子韩荣承袭。

**归年依据** 在215从征张鲁后、曹操220死前，不能凭此确定216或其他年份。

[韩浩去世，养子韩荣继嗣（时期）](../../years/ce-0201-0300/时期-三国志卷009-诸夏侯曹传纪年待考.md#period-sgz009-p-006-8)。

**归年依据** 魏书注“十四年”，承建安。

## 001｜荀淑为名士所师，任朗陵侯相

Kanripo四库本 1a—1b原行 21—28。附见[正文 L503](../本地分卷/三国志/三国志-卷010.md#l503)。

<a id="pei-001-1"></a>

> 續漢書曰淑有髙才王暢李&KR0574;皆以為師為朗陵侯相號稱神君

**荀淑为名士所师，任朗陵侯相** 《续汉书》称荀淑才高，王畅、李膺以他为师；任朗陵侯相时，人称神君。

**归年依据** 《后汉书·荀淑传》L4532有李膺等师事。“&KR0574;”是此底本未直接录成的异体字，范书作膺。

[荀淑为名士所师，任朗陵侯相（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（1）.md#period-sgz010-p-001-1)。

<a id="pei-001-2"></a>

> 張璠漢紀曰淑博學有髙行與李固李&KR0574;同志友善抜李昭于小吏友黄叔度于㓜童以賢良方正徵對策譏切梁氏出補朗陵侯相

**荀淑举贤良讥切梁氏、被外任朗陵** 张璠称荀淑好学有德，与李固、李膺友善，赏识李昭、黄叔度；对策讥梁氏而被出为朗陵侯相。

**归年依据** 《后汉书》L4532说在梁太后临朝，杜乔和房植推举。诏令与任命确年尚未合查齐。

[荀淑举贤良讥切梁氏、被外任朗陵（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（1）.md#period-sgz010-p-001-2)。

<a id="pei-001-3"></a>

> 卒官

**荀淑去世** 张璠说荀淑卒于所任。

**归年依据** 《后汉书》L4532明建和三年卒，但说先弃官归居，所以保留是否卒官的异说；149年第17、26条均为荀淑死。

[149年第17条](../../years/ce-0101-0200/ce-0149.md#sgz010-p-001-3)。

<a id="pei-001-4"></a>

> 八子儉緄靖燾詵爽肅旉爽字慈明㓜好學年十二通春秋論語躭思經典不應徵命積十數年

**荀淑八子及荀爽少有学行** 荀淑八子有俭、绲、靖等。荀爽字慈明，十二学通《春秋》《论语》，深究经术，多年不应征。

**归年依据** 人物家世、少年以及屡征不就无确年。

[荀淑八子及荀爽少有学行（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（1）.md#period-sgz010-p-001-4)。

<a id="pei-001-5"></a>

> 董卓秉政復徵爽爽欲遁去吏持之急詔下郡即拜平原相行至苑陵又追拜光禄勲視事三日策拜司空爽起自布衣九十五日而至三公

**董卓征荀爽，迅速擢为司空** 董卓征荀爽，荀爽想逃未成；先拜平原相，途中追拜光禄勋，仅任三天便拜司空，从平民到三公九十五日。

**归年依据** 《献帝纪》于中平六年冬十一月明记光禄勋荀爽为司空，范书《荀爽传》同。

[189年第51条](../../years/ce-0101-0200/ce-0189.md#sgz010-p-001-5)。

<a id="pei-001-6"></a>

> 淑舊居西豪里縣令苑康曰昔髙陽氏有才子八人署其里為髙陽里

**荀氏里因八子改名高阳** 苑康把荀淑故里西豪里改名高阳里，以古高阳氏有八才子为比。

**归年依据** 《后汉书》L4533同载，苑康改名未给确年。

[荀氏里因八子改名高阳（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（1）.md#period-sgz010-p-001-6)。

<a id="pei-001-7"></a>

> 靖字叔慈亦有至徳名幾亞爽隐居終身皇甫謐逸士傳或問許子将靖與爽孰賢子将曰二人皆玉也慈明外朗叔慈内潤

**荀靖终身隐居，许劭评荀靖荀爽如玉** 荀靖字叔慈，有德隐居，名望次于荀爽；许劭说二人皆玉，荀爽外明、荀靖内润。

**归年依据** 概叙终身，一次品评也未署年。

[荀靖终身隐居，许劭评荀靖荀爽如玉（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（1）.md#period-sgz010-p-001-7)。

## 002｜典略称荀绲慕权收唐衡女为荀彧妻

Kanripo四库本 1b—2a原行 28—35。附见[正文 L504](../本地分卷/三国志/三国志-卷010.md#l504)。

<a id="pei-002-1"></a>

> 典略曰中常侍唐衡欲以女妻汝南傅公明公明不娶轉以與彧父緄慕衡勢為彧娶之彧為論者所譏

**典略称荀绲慕权收唐衡女为荀彧妻** 唐衡先欲嫁女给傅公明，傅辞，改嫁荀彧，《典略》说荀绲慕其势，议者讥。

**归年依据** 择婚确年不详，裴松之另引唐衡亡年质疑慕势说。

[典略称荀绲慕权收唐衡女为荀彧妻（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（1）.md#period-sgz010-p-002-1)。

<a id="pei-002-2"></a>

> 臣松之案漢記云唐衡以桓帝延熹七年死計彧于時年始二歲則彧婚之日衡之没久矣慕勢之言為不然也

**唐衡卒，裴松之据此考婚年** 裴松之引《汉记》唐衡延熹七年死，按当时荀彧约二岁，待成婚时唐衡死已久，不成立慕势之说。

**归年依据** 张璠《汉记》记延熹七年（164）唐卒；荀彧仅为据年龄推，成婚年仍无明文。

[164年第20条](../../years/ce-0101-0200/ce-0164.md#sgz010-p-002-2)。

<a id="pei-002-3"></a>

> 臣松之又以為緄八龍之一必非茍得者也将有逼而然何云慕勢哉昔鄭忽以違齊致譏雋生以拒霍見美致譏在于失援見美嘉其慮逺並無交至之害故得各全其志耳至于閹䜿用事四海屏氣左悺唐衡殺生在口故于時諺云左廻天唐獨坐言威權莫二也順之則六親以安忤違則大禍立至斯誠以存易亡蒙恥期全之日昔蔣詡姻于王氏無損清髙之操緄之此婚庸何傷乎

**裴松之辨荀绲允婚亦可能受权宦胁迫** 裴松之称荀绲为八龙之一，不会苟求。用郑忽、隽不疑旧事比照，说明当权宦官威逼下顺逆关乎家族存亡，举蒋诩婚事说不损品节。

**归年依据** 按语涉及多个历史事例和长期环境，无独立确年；宦官唐衡、左悺曾在159年同诛梁冀。

[裴松之辨荀绲允婚亦可能受权宦胁迫（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（1）.md#period-sgz010-p-002-3)。

## 003｜裴松之以荀彧的十万之言质疑官渡曹军不足一万

Kanripo四库本 4b原行 78—79。附见[正文 L505](../本地分卷/三国志/三国志-卷010.md#l505)。

<a id="pei-003-1"></a>

> 臣松之以為于時徐州未平兖州又叛而云十萬之衆雖是抑抗之言要非寡弱之稱益知官渡之役不得云兵不滿萬也

**裴松之以荀彧的十万之言质疑官渡曹军不足一万** 裴松之说195年徐州未平、兖州又叛时荀彧仍称十万，即使话有夸张，可见官渡说曹兵不足万可疑。

**归年依据** 校议串195阻徐州与200官渡两时，已分别列史事。

## 004｜曹瞒传记曹操屠戮徐州、泗水不流

Kanripo四库本 4b原行 79—81。附见[正文 L505](../本地分卷/三国志/三国志-卷010.md#l505)。

<a id="pei-004-1"></a>

> 曹瞞傳云自京師遭董卓之亂人民流移東出多依彭城間遇太祖至坑殺男女數萬口于泗水水為不流陶謙帥其衆軍武原太祖不得進引軍從泗南攻取慮睢陵夏丘諸縣皆屠之雞犬亦盡墟邑無復行人

**曹瞒传记曹操屠戮徐州、泗水不流** 董卓之乱后许多外迁民聚彭城，曹军至，《曹瞒传》说坑杀多民，陶谦屯武原使曹不得进，曹操沿泗水南取取虑、睢陵、夏丘并屠，鸡犬皆尽。

**归年依据** 《后汉书·陶谦传》与通鉴卷060将徐州五县屠杀、彭城泗水并系初平四年首次征徐州；《武帝纪》仅直记194第二次“所過多所殘戮”。两载不混。

[193年第22条](../../years/ce-0101-0200/ce-0193.md#sgz010-p-004-1)。

## 005｜荀彧在台阁推让礼士，不任不才的族人

Kanripo四库本 5b原行 100—101。附见[正文 L506](../本地分卷/三国志/三国志-卷010.md#l506)。

<a id="pei-005-1"></a>

> 典略曰彧折節下士坐不累席其在䑓閣不以私欲撓意彧有羣從一人才行實薄或謂彧以君當事不可不以某為議郎邪彧笑曰官者所以表才也若如來言衆人其謂我何邪其持心平正皆類此

**荀彧在台阁推让礼士，不任不才的族人** 荀彧折节礼下，处台阁不因私欲扰公事；有人想任才行不足的族人为议郎，荀彧笑说官要表才，无才不任。

**归年依据** 《典略》概述荀彧在台阁长期做法，轶事未纪年。

[荀彧在台阁推让礼士，不任不才的族人（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（1）.md#period-sgz010-p-005-1)。

## 006｜典略称荀彧仪貌出众

维基文库四库本原行 11—11。附见[正文 L506](../本地分卷/三国志/三国志-卷010.md#l506)。

<a id="pei-006-1"></a>

> 典略曰彧為人偉美又平原禰衡傳

**典略称荀彧仪貌出众** 《典略》称荀彧相貌端美，继引祢衡传为旁证。

**归年依据** 人物仪容无确定年份。

[典略称荀彧仪貌出众（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（1）.md#period-sgz010-p-006-1)。

<a id="pei-006-2"></a>

> 曰衡字正平建安初自荆州北游許都恃才傲逸臧否過差見不如己者不與語人皆以是憎之惟少府孔融髙貴其才

**祢衡建安初由荆州到许，气高好品评** 祢衡字正平，建安初北游许都，恃才傲物，称量人过于严厉，多人不喜；孔融重其才。

**归年依据** 《后汉书·祢衡传》L5938也作“建安初”；《通鉴》卷062 L307–318把其与曹操、刘表、黄祖始末附叙在196年底，后续具体年份另考。

[祢衡建安初由荆州到许，气高好品评（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（1）.md#period-sgz010-p-006-2)。

<a id="pei-006-3"></a>

> 上書薦之曰淑質貞亮英才卓犖初渉藝文升堂覩奥目所一見輙誦於口耳所暫聞不忘於心性與道合思若有神宏羊心計安世黙識以衡凖之誠不足怪衡時年二十四

**孔融上疏举荐祢衡** 孔融称赞祢衡资质纯正、天赋卓异，读听即记，机思出众，认为桑弘羊的心算、张安世的默记尚不奇。祢衡时年二十四。

**归年依据** 《后汉书》L5939–5940存荐表全文，未署年；引录年龄不足换算实际年份。

[孔融上疏举荐祢衡（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（1）.md#period-sgz010-p-006-3)。

<a id="pei-006-4"></a>

> 是時許都雖新建尚饒人士衡嘗書一刺懐之字漫滅而無所適或問之曰何不從陳長文司馬伯達乎衡曰卿欲使我從屠沽兒軰也又問曰當今許中誰最可者衡曰大兒有孔文舉小兒有楊徳祖又問曺公荀令君趙盪寇皆足盖世乎衡稱曹公不甚多又見荀有儀容趙有腹尺因答曰文若可借面弔䘮稚長可使監厨請客其意以為荀但有貌趙健啖肉也於是衆人皆切齒

**祢衡在许无所就，讥陈群、司马朗、荀彧等** 许都新建，祢衡怀名帖久无拜访，鄙陈群、司马朗，独称孔融、杨修，并借荀彧容貌、赵融食量作讽，众怨。

**归年依据** 建安初在许，无确年；《后汉书》L5938叙大略相合。

[祢衡在许无所就，讥陈群、司马朗、荀彧等（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（1）.md#period-sgz010-p-006-4)。

<a id="pei-006-5"></a>

> 衡知衆不悅将南還荆州装束臨發衆人為祖道先設供帳於城南自共相誡曰衡數不遜今因其後到以不起報之及衡至衆人皆坐不起衡乃號咷大哭衆又問其故衡曰行屍柩之間能不悲乎

**祢衡将离许，送行者不迎而祢衡哭讥** 祢衡南去荆州时，众人城南饯行却不起作报复；祢衡大哭说好似在尸柩间。

**归年依据** 《后汉书》L5942把此事接曹操送祢衡给刘表，具体年仍未署。

[祢衡将离许，送行者不迎而祢衡哭讥（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（2）.md#period-sgz010-p-006-5)。

<a id="pei-006-6"></a>

> 衡南見劉表表甚禮之将軍黄祖屯夏口祖子射與衡善随到夏口祖嘉其才每在坐席有異賓介使與衡談

**刘表礼待祢衡，祢衡后赴黄祖军** 刘表礼待祢衡；黄祖驻夏口，子黄射与祢衡善，祢衡随至夏口。黄祖喜其才，每有宾客使与祢衡谈。

**归年依据** 《后汉书》L5943–5946及通鉴卷062大体同。彼时可约建安初，未明哪一年。

[刘表礼待祢衡，祢衡后赴黄祖军（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（2）.md#period-sgz010-p-006-6)。

<a id="pei-006-7"></a>

> 後衡驕蹇答祖言俳優饒言祖以為罵己也大怒顧伍伯捉頭出左右遂扶以去拉而殺之

**黄祖怒祢衡骄对而杀之** 祢衡骄傲且言辞近戏，黄祖以为他骂自己，命伍伯捉下杀死。

**归年依据** 范书《祢衡传》记死年二十六，没有纪年年号。《通鉴》卷062 L307–318以建安元年底并叙全事，不把赴许至死强归同一年。

[黄祖怒祢衡骄对而杀之（时期）](../../years/ce-0201-0300/时期-三国志卷010-二荀贾传纪年待考（2）.md#period-sgz010-p-006-7)。

<a id="pei-006-8"></a>

> 臣松之以本傳不稱彧容貌故載典略與衡傳以見之又潘朂為彧碑文稱彧瓌姿奇表

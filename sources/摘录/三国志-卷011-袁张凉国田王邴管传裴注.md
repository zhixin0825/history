## 001｜袁滂清素自处

Kanripo四库本 1a原行 22—23。附见[正文 L534](../本地分卷/三国志/三国志-卷011.md#l534)。

<a id="pei-001-1"></a>

> 袁宏漢紀曰滂字公熙純素寡欲終不言人之短當權寵之盛或以同異致禍滂獨中立於朝故愛憎不及焉

**袁滂清素自处** 《袁宏汉纪》说袁滂字公熙，寡欲不议人短，权贵盛时独中立于朝，未卷进爱憎。

## 002｜吕布军破后袁涣对曹操长揖

Kanripo四库本 2a原行 37—40。附见[正文 L536](../本地分卷/三国志/三国志-卷011.md#l536)。

<a id="pei-002-1"></a>

> 袁氏世紀曰布之破也陳羣父子時亦在布之軍見太祖皆拜渙獨髙揖不為禮太祖甚嚴憚之

**吕布军破后袁涣对曹操长揖** 陈群父子见曹操皆拜，袁涣只长揖，不卑屈，曹操反而敬畏。

**归年依据** 《袁氏世纪》从《武帝纪》建安三年吕布军破。

[198年第4条](../../years/ce-0101-0200/ce-0198.md#sgz011-p-002-1)。

<a id="pei-002-2"></a>

> 時太祖又給衆官車各數乘使取布軍中物唯其所欲衆人皆重載唯渙取書數百卷資糧而已

**袁涣破吕布后只取书粮** 曹操令百官各驾车自取吕布营物，众人满载，袁涣只取数百卷书、资粮。

**归年依据** 同次处置。

[198年第4条](../../years/ce-0101-0200/ce-0198.md#sgz011-p-002-2)。

<a id="pei-002-3"></a>

> 衆人聞之大慙渙謂所親曰脱我以行陳令軍發足以為行糧而已不以此為我有由是厲名也大悔恨之太祖益以此重焉

**袁涣自述领物非私取，却悔近于求名** 旁人听说此事惭愧。袁涣说资粮够行军所需，并非划为私有，反悔因此得名，曹操更重他。

**归年依据** 同次事件的即时反应。

[198年第4条](../../years/ce-0101-0200/ce-0198.md#sgz011-p-002-3)。

## 003｜呂岐署朱渊袁津祭酒而杀二人

Kanripo四库本 3a—3b原行 59—67。附见[正文 L537](../本地分卷/三国志/三国志-卷011.md#l537)。

<a id="pei-003-1"></a>

> 魏書曰穀熟長呂岐善朱淵袁津遣使行學還召用之與相見出署淵師友祭酒津决疑祭酒淵等因各歸家不受署岐大怒将吏民收淵等皆杖殺之議者多非焉

**呂岐署朱渊袁津祭酒而杀二人** 谷熟长吕岐本与朱渊、袁津交好，派他们外出视学，归来授师友及决疑祭酒；二人未受，吕岐发怒杖杀，舆论多非议。

**归年依据** 《魏书》在袁涣任梁相段插入，谷熟属梁国，年月不详。

[呂岐署朱渊袁津祭酒而杀二人（时期）](../../years/ce-0201-0300/时期-三国志卷011-袁张凉国田王邴管传纪年待考（3）.md#period-sgz011-p-003-1)。

<a id="pei-003-2"></a>

**袁涣、孙徽等议吕岐擅杀的界限** 袁涣先令勿劾；主簿提出二人罪不该死，长吏没有专杀权，把对方称师友而杀之名实相悖。

<a id="pei-003-3"></a>

> 渙教曰主簿以不請為罪此則然矣謂淵等罪不足死則非也夫師友之名古今有之然有君之師友有士大夫之師友夫君置師友之官者所以敬其臣也有罪加於刑焉國之法也今不論其罪而謂之戮師友斯失之矣主簿取弟子戮師之名而加君誅臣之實非其類也

**袁涣以君臣及师友不同答主簿** 袁涣可责吕岐未经请示，反对以师友之名自动减罪，天子之臣有罪可以依刑法处理，不能以弟子戮老师的名目看君臣关系。

**袁涣称应因时制权，吕岐不坐** 袁涣以乱世百姓陵上为实情，认为应强调尊君，不可变本加厉迁就时过，终于不劾。

> 袁氏世紀曰渙有四子侃寓奥凖侃字公然論議清當柔而不犯善與人交在廢興之間人之所趣務者常謙退不為也時人以是稱之歴位黄門選部郎號為清平稍遷至尚書早卒

**袁侃议论清当，退谦而有清名** 《袁氏世纪》记袁涣四子，详袁侃处进退之间谦逊，擅交游，曾任黄门选部郎，迁尚书早卒。

**袁准学行及其论著** 袁准忠信公正，不耻下问，避仕途之险，自序撰十余万言讲治世与六经疑义。

## 001｜曹操赐死曹植衣绣之妻

维基文库四库本原行 12—12。附见[正文 L590](../本地分卷/三国志/三国志-卷012.md#l590)。

<a id="pei-001-1"></a>

> 世語曰植妻衣繡太祖登臺見之以違制命還家賜死

**曹操赐死曹植衣绣之妻** 《世语》记曹操登台见曹植妻服绣，以违制令她回家死。

**归年依据** 注附夫家姻亲文，未载年月；仅可限曹操220卒前。

## 002｜崔琰持清议掌铨选十余年

维基文库四库本原行 12—12。附见[正文 L591](../本地分卷/三国志/三国志-卷012.md#l591)。

<a id="pei-002-1"></a>

> 先賢行状曰琰清忠髙亮雅識經遠推方直道正色扵朝魏氏初載委授銓衡㧾齊清議十有餘年文武羣才多所眀㧞朝廷歸髙天下稱仁

**崔琰持清议掌铨选十余年** 《先贤行状》称崔琰清忠识远，魏氏早年主铨衡清议，拔人才，朝廷及天下称誉。

**归年依据** 长期仕历，无将“十有余年”确定起年。

## 003｜曹操以致杨训书罪崔琰

Kanripo四库本 4a—4b原行 78—83。附见[正文 L591](../本地分卷/三国志/三国志-卷012.md#l591)。

<a id="pei-003-1"></a>

> 魏略曰人得琰書以褁幘籠持其籠行都道中時有與琰宿不平者遙見琰名著幘籠従而視之遂白之

**曹操以致杨训书罪崔琰** 《魏略》说得崔琰书者包帻笼上街，旧怨人见名开读而告发。

**归年依据** 《通鉴》卷067建安二十一年；同一崔琰案。

[216年第24条](../../years/ce-0201-0300/ce-0216.md#sgz012-p-003-1)。

<a id="pei-003-2"></a>

> 太祖以為琰腹誹心謗乃収付獄髠刑輸徒前所白琰者又復白之云琰為徒虬鬚直視心似不平

**曹操以致杨训书罪崔琰** 曹操认定崔琰心谤而髡为徒，原告又称崔琰昂然不平。

**归年依据** 同案。

[216年第24条](../../years/ce-0201-0300/ce-0216.md#sgz012-p-003-2)。

<a id="pei-003-3"></a>

> 時太祖亦以為然遂欲殺之乃使清公大吏往經營琰教吏曰三日期消息琰不悟

**曹操以致杨训书罪崔琰** 曹操命官吏探视，三日回报，崔琰没明白示意。

**归年依据** 同案。

[216年第24条](../../years/ce-0201-0300/ce-0216.md#sgz012-p-003-3)。

<a id="pei-003-4"></a>

> 後數日吏故白琰平安公忿然曰崔琰必欲使孤行刀鋸乎吏以是教告琰琰謝吏曰我殊不宜不知公意至此也遂自殺

**曹操以致杨训书罪崔琰** 曹操因报他平安发怒，令吏转告杀意；崔琰才懂，遂自杀。

**归年依据** 与正文“賜死”同一死亡，两书详略不同。

[216年第24条](../../years/ce-0201-0300/ce-0216.md#sgz012-p-003-4)。

## 005｜崔林与陈群争论崔琰品地

Kanripo四库本 5a原行 91—92。附见[正文 L592](../本地分卷/三国志/三国志-卷012.md#l592)。

<a id="pei-005-1"></a>

> 魏略曰明帝時崔林甞與司空陳羣共論冀州人士稱琰為首羣以智不存身貶之林曰大丈夫為有邂逅耳即如卿諸人良足貴乎

**崔林与陈群争论崔琰品地** 崔林以崔琰为冀州人首，陈群说其智不足自保，崔林反言人有机遇而陈群等未必可贵。

**归年依据** 《魏略》说明帝时，陈群226–236居司空；《通鉴》216处追叙，谈话并非216。

[崔林与陈群争论崔琰品地（时期）](../../years/ce-0201-0300/时期-三国志卷012-崔毛徐何邢鲍司马传纪年待考（3）.md#period-sgz012-p-005-1)。

## 006｜孔融名字世系及父祖

Kanripo四库本 5a—8a原行 93—144。附见[正文 L594](../本地分卷/三国志/三国志-卷012.md#l594)。

<a id="pei-006-1"></a>

> 融字文舉續漢書曰融孔子二十世孫也髙祖父尚鉅鹿太守父宙太山都尉

**孔融名字世系及父祖** 孔融字文举，传为孔子二十世孙，高祖孔尚任钜鹿太守、父孔宙任泰山都尉。

**归年依据** 历世家系。

[孔融名字世系及父祖（时期）](../../years/ce-0201-0300/时期-三国志卷012-崔毛徐何邢鲍司马传纪年待考（3）.md#period-sgz012-p-006-1)。

<a id="pei-006-2"></a>

> 融㓜有異才時河南尹李膺有重名勅門下簡通賔客非當世英賢及通家子孫弗見也融年十餘嵗欲觀其為人遂造膺門語門者曰我李君通家子孫也

**少年孔融见李膺** 李膺用门客筛选来访者；十余岁孔融自称世交故入。

**归年依据** 只载少年年龄，李膺任河南尹具体时点两传没有相同精度。

[少年孔融见李膺（时期）](../../years/ce-0201-0300/时期-三国志卷012-崔毛徐何邢鲍司马传纪年待考（3）.md#period-sgz012-p-006-2)。

<a id="pei-006-3"></a>

> 膺見融問曰髙明父祖甞與僕周旋乎融曰然先君孔子與君先人李老君同徳比義而相師友則融與君累世通家也衆坐竒之僉曰異童子也

**孔融以孔子、老子为师友证明通家** 孔融说孔子和李老君为师友，自己同李膺当然也是累世通家，满座称奇。

**归年依据** 同次访李。

[孔融以孔子、老子为师友证明通家（时期）](../../years/ce-0201-0300/时期-三国志卷012-崔毛徐何邢鲍司马传纪年待考（3）.md#period-sgz012-p-006-3)。

<a id="pei-006-4"></a>

> 太中大夫陳煒後至同坐以告煒煒曰人小時了了者大亦未必竒也融答曰即如所言君之㓜時豈實慧乎膺大笑顧謂曰髙明長大必為偉器

**孔融巧答童年早慧不能预知将来** 陈炜说早慧未必成人奇特，孔融反问他幼时是否一定聪慧，李膺赞孔融长成必为伟器。

**归年依据** 同次谈话；《后汉书》来客名陈韪。

[孔融巧答童年早慧不能预知将来（时期）](../../years/ce-0201-0300/时期-三国志卷012-崔毛徐何邢鲍司马传纪年待考（3）.md#period-sgz012-p-006-4)。

<a id="pei-006-5"></a>

> 山陽張儉以中正為中常侍侯覧所忿疾覽為刋章下州郡捕儉

**侯览悬捕张俭** 侯览因忌恨张俭，发告捕，州郡追缉。

**归年依据** 《后汉书·张俭传》建宁二年；与张俭从前劾侯览区分。

[169年第18条](../../years/ce-0101-0200/ce-0169.md#sgz012-p-006-5)。

<a id="pei-006-6"></a>

> 儉與融兄褒有舊亡投褒遇褒出時融年十六儉以其少不告也融知儉長者有窘迫色謂曰吾獨不能為君主邪因留舍藏之

**孔融藏张俭，孔褒为之担罪** 张俭投孔褒不遇，十六岁的孔融看出窘迫，请将他藏在家。

**归年依据** 承建宁二年受捕，《后汉书·孔融传》与年龄相合。

[169年第22条](../../years/ce-0101-0200/ce-0169.md#sgz012-p-006-6)。

<a id="pei-006-7"></a>

> 後事泄國相以下密就掩捕儉得脫走登時收融及褒送獄融曰保納藏舍者融也融當坐之褒曰彼来求我罪我之由非弟之過我當坐之兄弟爭死

**孔融藏张俭，孔褒为之担罪** 事泄后张俭逃走，郡国拘孔氏兄弟，二人争认藏匿之罪。

**归年依据** 同案。

[169年第22条](../../years/ce-0101-0200/ce-0169.md#sgz012-p-006-7)。

<a id="pei-006-8"></a>

> 郡縣疑不䏻决乃上讞詔書令褒坐焉

**孔融藏张俭，孔褒为之担罪** 地方不能判决，上奏汉廷，诏判孔褒有罪。

**归年依据** 《后汉书》同案，其诏月日无独立记载。

[169年第22条](../../years/ce-0101-0200/ce-0169.md#sgz012-p-006-8)。

<a id="pei-006-9"></a>

> 融由是名震逺近與平原陶邱洪陳留邉讓並以俊秀為後進冠盖融持論經理不及讓等而逸才宏博過之

**孔融与陶丘洪边让齐名** 孔融因此知名，与陶丘洪、边让为青年冠盖，理论逊边让而宏博过之。

**归年依据** 以169藏张俭为起因，知名长期。

[孔融与陶丘洪边让齐名（时期）](../../years/ce-0201-0300/时期-三国志卷012-崔毛徐何邢鲍司马传纪年待考（3）.md#period-sgz012-p-006-9)。

<a id="pei-006-10"></a>

> 司徒大司馬辟舉髙第累遷北軍中候虎賁中郎将北海相時年二十八

**孔融由公府进北军中候、虎贲中郎将** 由公府辟举高第，历武官及北海相。

**归年依据** 董卓废立189时已任虎贲中郎将，任北海当其掌权之际；此注称28，与208卒年56相去过远，保留原数字。

[孔融由公府进北军中候、虎贲中郎将（时期）](../../years/ce-0201-0300/时期-三国志卷012-崔毛徐何邢鲍司马传纪年待考（3）.md#period-sgz012-p-006-10)。

<a id="pei-006-11"></a>

> 承黄巾殘破之後修復城邑崇學校設庠序舉賢才顯儒士以彭璆為方正邴原為有道王修為孝亷

**孔融修北海城邑、兴学校、荐贤** 修残破城邑、办学，举彭璆方正、邴原有道、王脩孝廉。

**归年依据** 北海任内，后汉书亦载但无同时一岁。

<a id="pei-006-12"></a>

> 告髙密縣為鄭玄特立一鄊名為鄭公鄊又國人無後及四方㳺士有死亡者皆為棺木以殯葬之

**孔融置郑公乡、助无后与游士收葬** 请高密为郑玄特立一乡，又为国中无后及死去游士助棺收葬。

**许都征孔融为将作大匠** 建安元年征还朝任将作大匠，后迁任少府，朝议常主发言。

**归年依据** 《续汉书》明确征还为196，少府升任可能稍后。

> 司馬彪九州春秋曰融在北海自以智䏻優贍溢才命世當時豪俊皆不䏻及亦自許大志且欲舉軍曜甲與羣賢要功自扵海岱結殖根本不肯碌碌如平居郡守事方伯赴期㑹而已然其所任用好竒取異皆輕剽之才

**归年依据** 《九州春秋》总论北海经营。

**孔融杀督邮，奸吏仍乱** 因赋敛稍迟并杀五部督邮，未能治理奸民污吏。

<a id="pei-006-19"></a>

> 幽州精兵亂至徐州卒到城下舉國皆恐融直出說之令無異志遂與别校謀夜覆幽州幽州軍敗悉有其衆無㡬時還復叛亡

## 001｜钟皓操行教徒及郡功曹

Kanripo四库本 1a—2a原行 19—33。附见[正文 L646](../本地分卷/三国志/三国志-卷013.md#l646)。

<a id="pei-001-1"></a>

> 先賢行狀曰鍾皓字季明温良篤慎博學詩律教授門生千有餘人為郡功曹

**钟皓操行教徒及郡功曹** 钟皓字季明，温良笃慎，经学与法度博闻，授徒千余，任郡功曹。

**归年依据** 《先贤行状》开篇。

[钟皓操行教徒及郡功曹（时期）](../../years/ce-0201-0300/时期-三国志卷013-钟繇华歆王朗传纪年待考（2）.md#period-sgz013-p-001-1)。

<a id="pei-001-2"></a>

> 時太丘長陳實為西門亭長皓深獨敬異實少皓十七嵗常禮待與同分義㑹辟公府臨辭太守問誰可代君皓曰明府欲必得其人西門亭長可用實曰鍾君似不察人為意不知何獨識我

**钟皓任郡功曹时赏识陈寔** 陈寔当时为西门亭长，比钟皓小十七岁；钟皓敬异，与他交好，受公府辟别时荐陈寔接己职。

**归年依据** 有年龄差与职衔，缺事件年。

[钟皓任郡功曹时赏识陈寔（时期）](../../years/ce-0201-0300/时期-三国志卷013-钟繇华歆王朗传纪年待考（2）.md#period-sgz013-p-001-2)。

<a id="pei-001-3"></a>

> 皓為司徒掾公出道路泥濘導從惡其相灑去公車絶逺公椎軾言司徒今日為獨行耳還府向閤鈴下不扶令揖掾屬公奮手不顧

**司徒遇道泥，怪导从离远** 侍从为避泥污离车太远，司徒叹自己好像独行，返后从吏和属掾都不获理。

**归年依据** 钟皓任司徒府掾时。

[司徒遇道泥，怪导从离远（时期）](../../years/ce-0201-0300/时期-三国志卷013-钟繇华歆王朗传纪年待考（2）.md#period-sgz013-p-001-3)。

<a id="pei-001-4"></a>

> 時舉府掾屬皆投劾出皓為西曹掾即開府門分布曉語已出者曰臣下不能得自直扵君若司隷舉繩墨以公失宰相之禮又不勝任諸君終身何所任邪掾屬以故皆止都官果移西曹掾問空府去意皓召都官吏以見掾屬名示之乃止

**钟皓止司徒属吏投劾出府** 全府自劾离去；钟皓指出擅离既暴司徒失礼也会断自身仕途，挽回众人；都官来问，示诸掾在府而止。

**归年依据** 同一府事。

[钟皓止司徒属吏投劾出府（时期）](../../years/ce-0201-0300/时期-三国志卷013-钟繇华歆王朗传纪年待考（2）.md#period-sgz013-p-001-4)。

<a id="pei-001-5"></a>

> 前後九辟三府遷南鄉林慮長不之官時郡中先軰為海内所歸者蒼梧太守定陵陳稚叔故黎陽令潁隂荀淑及皓少府李膺常宗此三人曰荀君清識難尚陳鍾至徳可師

**钟皓屡拒辟命，乡里名士相推** 九辟三府，南乡林虑长未赴；李膺称荀淑清识出众，陈寔钟皓德行可师。

**归年依据** 长期知名。

[钟皓屡拒辟命，乡里名士相推（时期）](../../years/ce-0201-0300/时期-三国志卷013-钟繇华歆王朗传纪年待考（2）.md#period-sgz013-p-001-5)。

<a id="pei-001-6"></a>

> 膺之姑為皓兄之妻生子覲與膺年齊並有令名覲又好學慕古有退譲之行為童㓜時膺祖太尉修言覲似我家性國有道不廢國無道免於刑戮者也復以膺妹妻之覲辟州宰未嘗屈就

**钟觐与李膺同龄齐名、结婚姻** 李膺姑母为钟皓兄妻，生钟觐；李修认其学古退让，李膺以妹嫁之，州郡辟而不就。

**归年依据** 早年与通婚年月不定。

[钟觐与李膺同龄齐名、结婚姻（时期）](../../years/ce-0201-0300/时期-三国志卷013-钟繇华歆王朗传纪年待考（2）.md#period-sgz013-p-001-6)。

<a id="pei-001-7"></a>

> 膺謂覲曰孟軻以為人無好惡是非之心非人也弟扵人何太無皂白邪覲嘗以膺之言白皓皓曰元禮祖公在位諸父並盛韓公之甥故得然耳國武子好昭人過以為怨本今豈其時保身全家汝道是也

**李膺问钟觐无皂白，钟皓劝远怨全家** 李膺问为何不明示爱憎是非；钟皓言李氏世贵可行，钟觐当如处危险时守身避怨。

**归年依据** 党锢前警语，具体不明。

[李膺问钟觐无皂白，钟皓劝远怨全家（时期）](../../years/ce-0201-0300/时期-三国志卷013-钟繇华歆王朗传纪年待考（2）.md#period-sgz013-p-001-7)。

<a id="pei-001-8"></a>

> 覲早亡膺雖荷功名位至卿佐而卒隕身世禍

**钟觐早亡，李膺显位终为党祸所害** 钟觐早亡，李膺官至卿佐，终于身遭时祸。

**归年依据** 李膺死于169第二次党锢，钟觐早亡不定同年。

[钟觐早亡，李膺显位终为党祸所害（时期）](../../years/ce-0201-0300/时期-三国志卷013-钟繇华歆王朗传纪年待考（2）.md#period-sgz013-p-001-8)。

<a id="pei-001-9"></a>

> 皓年六十九終扵家皓二子廸敷並以黨錮不仕繇則廸之孫

**钟皓卒于家及钟氏党锢谱系** 六十九卒，两子钟迪钟敷因党锢不仕，钟繇是钟迪之孙。

**归年依据** 只载卒岁数及党锢多年的状态。

[钟皓卒于家及钟氏党锢谱系（时期）](../../years/ce-0201-0300/时期-三国志卷013-钟繇华歆王朗传纪年待考（2）.md#period-sgz013-p-001-9)。

## 004｜郭援南单于进河东，傅干劝马腾

维基文库四库本原行 11—11。附见[正文 L647](../本地分卷/三国志/三国志-卷013.md#l647)。

<a id="pei-004-1"></a>

> 司馬彪戰畧曰袁尚遣高幹郭援將兵數萬人與匈奴單于宼河東遣使與馬騰韓遂等連和騰等隂許之

**郭援南单于进河东，傅干劝马腾** 袁尚遣高干郭援与单于寇河东，邀马韩合兵，马韩暗允。

**归年依据** 《通鉴》建安七年，固定维基四库全注校补。

[202年第11条](../../years/ce-0201-0300/ce-0202.md#sgz013-p-004-1)。

<a id="pei-004-2"></a>

> 傳幹說騰曰古人有言順道者昌逆徳者亡曹公奉天子誅暴亂法明國治上下用命有義必賞無義必罰可謂順道矣袁氏背王命驅胡虜以陵中國寛而多忌仁而無㫁兵雖强實失天下心可謂逆徳矣

**傅干以曹操顺道说马腾** 主张曹操奉帝讨乱、明正赏罚，袁氏违令并驱胡为侵，失民心。

**归年依据** 同次说辞。

[202年第11条](../../years/ce-0201-0300/ce-0202.md#sgz013-p-004-2)。

<a id="pei-004-3"></a>

> 今將軍既事有道不盡其力隂懐兩端欲以坐觀成敗吾恐成敗既定奉辭責罪將軍先為誅首矣

**傅干警告马腾不能持两端** 若观望待胜负，获胜者会奉诏论罪，将军先受诛。

**归年依据** 同次说辞。

[202年第11条](../../years/ce-0201-0300/ce-0202.md#sgz013-p-004-3)。

<a id="pei-004-4"></a>

> 扵是騰懼幹曰智者轉禍為福今曹公與袁氏相持而髙幹郭援獨制河東曹公雖有萬全之計不能禁河東之不危也將軍誠能引兵討援内外擊之其勢必舉是將軍一舉㫁袁氏之臂觧一方之急曹公必重徳將軍將軍功名竹帛不能盡載也惟將軍審所擇

**傅干陈内外夹击郭援之利** 劝马腾发兵讨郭援以断袁氏一臂、解河东急，曹操必嘉其功。

**归年依据** 同次说辞。

[202年第11条](../../years/ce-0201-0300/ce-0202.md#sgz013-p-004-4)。

<a id="pei-004-5"></a>

> 騰曰敬從教扵是遣子超将精兵萬餘人并将遂等兵與繇㑹擊援等大敗之

**马腾遣马超率军会钟繇击郭援** 马超率精兵万余，又合韩遂等部，和钟繇会师击败郭援。

**归年依据** 同次关中战役；正文主记张既说马腾，注文另述傅干。

[202年第11条](../../years/ce-0201-0300/ce-0202.md#sgz013-p-004-5)。

## 005｜卫固等叛、联络高干与张晟

维基文库四库本原行 11—11。附见[正文 L647](../本地分卷/三国志/三国志-卷013.md#l647)。

<a id="pei-005-1"></a>

> 魏畧曰詔徴河東太守王邑邑以天下未定心不願徴而吏民亦戀邑郡掾衛固中郎將范先等各詣繇求乞邑而詔已拜杜畿為太守畿已入界

**卫固等叛、联络高干与张晟** 王邑不愿离郡，吏民亦不舍，卫固范先找钟繇请留，杜畿已受命入界。

**归年依据** 《通鉴》卷064建安十年冬。

[205年第28条](../../years/ce-0201-0300/ce-0205.md#sgz013-p-005-1)。

<a id="pei-005-2"></a>

> 繇不聼先等促邑交符邑佩卬綬徑從河北詣許自歸

**卫固等叛、联络高干与张晟** 钟繇拒请求，王邑佩绶经河北县往许归朝。

**归年依据** 同次郡守交替。

[205年第28条](../../years/ce-0201-0300/ce-0205.md#sgz013-p-005-2)。

<a id="pei-005-3"></a>

> 繇時治在洛陽自以威禁失督司之法乃上書自劾曰臣前上言故鎮北將軍領河東太守安陽亭侯王邑巧辟治官犯突科條事當推劾檢實姦詐被詔書當如所紏以其歸罪故加寛赦

**钟繇自劾失督察，追陈王邑违令** 任治洛阳时，上书自劾，先申王邑任官犯条和归罪后获赦。

**归年依据** 据《魏略》附205河东案，自劾称“渉夏”，或206夏，暂无独立年证。

[钟繇自劾失督察，追陈王邑违令（时期）](../../years/ce-0201-0300/时期-三国志卷013-钟繇华歆王朗传纪年待考（2）.md#period-sgz013-p-005-3)。

<a id="pei-005-4"></a>

> 又臣上言吏民大小各懐顧望謂邑當還拒太守杜畿今皆反悔共迎畿之官

**钟繇自劾失督察，追陈河东民情转变** 报告大小官吏观望拒杜畿，后来反悔共同迎他。

**归年依据** 同书回述。

[钟繇自劾失督察，追陈河东民情转变（时期）](../../years/ce-0201-0300/时期-三国志卷013-钟繇华歆王朗传纪年待考（2）.md#period-sgz013-p-005-4)。

<a id="pei-005-5"></a>

> 謹按文書臣以空虗被䝉㧞擢入充近侍兼典機衡忝膺重任總統偏方既無徳政以惠民物又無威刑以檢不恪至使邑違犯詔書郡掾衛固誑廹吏民訟訴之言交驛道路漸失其禮不䖍王命今雖反悔醜聲流聞咎皆由臣威刑不攝

**钟繇因卫固胁民自陈有亏任职** 己承信任总地方大权却不能惠民执法，王邑违诏、卫固胁民不敬王命，原因在督察失职。

**归年依据** 同一自劾。

[钟繇因卫固胁民自陈有亏任职（时期）](../../years/ce-0201-0300/时期-三国志卷013-钟繇华歆王朗传纪年待考（2）.md#period-sgz013-p-005-5)。

<a id="pei-005-6"></a>

> 臣又疾病前後歴年氣力日㣲尸素重禄曠廢職任罪明法正

**钟繇自陈多年病重失职** 屡病气衰，误司隶职任，应该明法。

**归年依据** 同一自劾。

[钟繇自陈多年病重失职（时期）](../../years/ce-0201-0300/时期-三国志卷013-钟繇华歆王朗传纪年待考（2）.md#period-sgz013-p-005-6)。

<a id="pei-005-7"></a>

> 謹按侍中守司〔四库字图1452〕校尉東武亭侯鍾繇幸得䝉恩以斗筲之才仍見㧞擢顯從近密銜命督師明知詔書深疾長吏政教寛弱檢下無刑乆病淹滯衆職荒頓法令失張邑雖違科當必繩正法既舉文書操弹失理至乃使邑逺詣闕廷隳忝使命挫傷爪牙而固誑廹吏民拒畿連月今雖反悔犯順失正海内兇赫罪一由繇威刑闇弱又繇乆病不任所職非繇大臣當所宜為繇輕慢憲度不畏詔令不與國同心為臣不忠無所畏忌大為不敬又不承用詔書奉詔不謹又聰明蔽塞為下所欺弱不勝任數罪謹以劾

**归年依据** 同一次自劾；完整文本据固定四库本。

<a id="pei-005-8"></a>

> 臣請法車徴詣廷尉治繇罪大鴻臚削爵土臣乆嬰篤疾渉夏盛劇命縣呼吸不任部官輙以文書付功曹從事馬適議免冠徒跣伏須罪誅詔不聼

**钟繇自求治罪，诏不许** 请下廷尉和削爵，病重移公文给功曹从事，免冠跣足待罪，朝廷不许。

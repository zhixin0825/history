## 001｜刘弘早年与司马炎同里，因旧交历仕

Kanripo四库本 3b—4a原行 64—74。附见[正文 L784](../本地分卷/三国志/三国志-卷015.md#l784)。

<a id="pei-001-1"></a>

> 晉陽秋曰劉弘字叔和熙之弟也弘與晉世祖同年居同里以舊恩屢登顯位自靖至弘世不曠名而有政事才

**刘弘早年与司马炎同里，因旧交历仕** 刘靖少子刘弘字叔和，和晋武帝同岁同里，因旧恩屡登显位。父子都有声名及政才。

**归年依据** 《晋书·刘弘传》字和季，称少时同住洛阳永安里同学；年龄及诸次早期升迁未书年。

[刘弘早年与司马炎同里，因旧交历仕（时期）](../../years/ce-0201-0300/时期-三国志卷015-刘司马梁张温贾传纪年待考（2）.md#period-sgz015-p-001-1)。

<a id="pei-001-2"></a>

> 晉西朝之末弘為車騎大將軍開府荆州刺史假節都督荆交廣州諸軍事封新城郡公

**刘弘晚任荆州及封新城郡公** 《晋阳秋》总列车骑大将军、开府、刺荆州，都督荆交广并封新城郡公。

**归年依据** 《晋书·刘弘传》记永兴三年（306）进车骑将军，死后赠新城郡公，开府与刺荆州已有在先；本注压缩先后于一语。

[306年第2条](../../years/ce-0301-0400/ce-0306.md#sgz015-p-001-2)。

<a id="pei-001-3"></a>

> 其在江漢值王室多難得專命一方盡其器能推誠羣下厲以公義簡刑獄務農桑每有興發手書郡國丁寜欵密故莫不感悅顚倒奔赴咸曰得劉公一紙書賢於十部從事也

**刘弘治荆州简刑劝农而信用群下** 王室多难时主持江汉，简刑、劝农与诚意手札使地方相应，时称其一纸书胜十从事。

**归年依据** 任内长期政绩，非一日一事。

[刘弘治荆州简刑劝农而信用群下（时期）](../../years/ce-0201-0300/时期-三国志卷015-刘司马梁张温贾传纪年待考（2）.md#period-sgz015-p-001-3)。

<a id="pei-001-4"></a>

> 時帝在長安命弘得選用宰守徵士武陵伍朝髙尚其事牙門將皮初有勲江漢弘上朝為零陵太守

**刘弘奏选伍朝、皮初等守宰** 刘弘推许武陵征士伍朝与牙门将皮初。裴注“零陵太守”疑有脱文，伍朝才是被举为此郡太守的人。

**归年依据** 《晋书·刘弘传》同一奏内明确伍朝补零陵、皮初补襄阳，《资治通鉴》卷八十五系惠帝太安二年；《晋阳秋》“帝在长安”与303年行止相抵，保留异说。

[303年第4条](../../years/ce-0301-0400/ce-0303.md#sgz015-p-001-4)。

<a id="pei-001-5"></a>

> 初為襄陽太守詔書以襄陽顯郡初資名輕淺以弘壻夏侯陟為襄陽弘曰夫統天下者當與天下同心治一國者當與一國推實吾統荆州十郡安得十女壻然後為治哉乃表陟姻親舊制不得相監臨事初勲宜見酬報聼之衆益服其公

**刘弘荐皮初作襄阳太守，不许女婿出任** 朝廷意欲以夏侯陟替望轻的皮初，刘弘以任贤和避亲旧令拒绝，皮初得任。

**归年依据** 《资治通鉴》卷八十五惠帝太安二年接讨张昌收此，与《晋书·刘弘传》相合。

[303年第4条](../../years/ce-0301-0400/ce-0303.md#sgz015-p-001-5)。

<a id="pei-001-6"></a>

> 當廣漢太守辛冉以天子蒙塵四方雲擾進從橫計於弘弘怒斬之時人莫不稱善

**刘弘不从辛冉合纵之说而斩他** 辛冉欲利用天子流离、诸方乱事游说刘弘，刘弘怒斩，世人嘉许。

**归年依据** 《资治通鉴》卷八十六晋永兴二年，直接纪录辛冉说弘。

[305年第2条](../../years/ce-0301-0400/ce-0305.md#sgz015-p-001-6)。

<a id="pei-001-7"></a>

> 晉諸公讚曰于時天下雖亂荆州安全弘有劉景升保有江漢之志不附太傅司馬越越甚銜之

**《晋诸公赞》言刘弘割据江汉而不附司马越** 《赞》谓刘弘治荆州使之安宁，有保江汉之志，不附太傅司马越而为越所恨。

**归年依据** 刘弘据荆数年；与《晋书·刘弘传》极力劝诸司马和解、助奉迎之叙角度不同。

[《晋诸公赞》言刘弘割据江汉而不附司马越（时期）](../../years/ce-0201-0300/时期-三国志卷015-刘司马梁张温贾传纪年待考（2）.md#period-sgz015-p-001-7)。

<a id="pei-001-8"></a>

> 㑹弘病卒子璠北中郎將

**刘弘病卒** 刘弘病逝，其子刘璠为北中郎将。

**归年依据** 《资治通鉴》卷八十六光熙元年八月，刘弘卒，郭舒等推刘璠平乱。《晋书·刘弘传》叙刘璠为顺阳内史、越骑校尉等，《晋阳秋》另存北中郎将而不具任年。

[306年第3条](../../years/ce-0301-0400/ce-0306.md#sgz015-p-001-8)。

## 002｜司马隽博古有度，官颍川太守

Kanripo四库本 4a—4b原行 75—80。附见[正文 L786](../本地分卷/三国志/三国志-卷015.md#l786)。

<a id="pei-002-1"></a>

> 司馬彪序傳曰朗祖父雋字元異博學好古倜儻有大度長八尺三寸腰帶十圍儀狀魁岸與衆有異鄉黨宗族咸景附焉位至潁川太守

**司马隽博古有度，官颍川太守** 司马彪称司马朗祖父字元异，博古大度，体魁伟，宗族乡里多依附。

**归年依据** 无任职年月。

[司马隽博古有度，官颍川太守（时期）](../../years/ce-0201-0300/时期-三国志卷015-刘司马梁张温贾传纪年待考（2）.md#period-sgz015-p-002-1)。

<a id="pei-002-2"></a>

> 父防字建公性質直公方雖閑居宴處威儀不忒雅好漢書名臣列傳所諷誦者數十萬言少仕州郡歴官洛陽令京兆尹以年老轉拜騎都尉養志閭巷闔門自守諸子雖冠成人不命曰進不敢進不命曰坐不敢坐不指有所問不敢言父子之間肅如也

**司马防严正教子，历令尹与骑都尉** 司马防字建公，熟读汉书，历洛阳令、京兆尹，年老转骑都尉，平居仍严守威仪，成年诸子也须听命进坐问答。

**归年依据** 《司马彪序传》总叙仕历及家法，无单年。

[司马防严正教子，历令尹与骑都尉（时期）](../../years/ce-0201-0300/时期-三国志卷015-刘司马梁张温贾传纪年待考（2）.md#period-sgz015-p-002-2)。

<a id="pei-002-3"></a>

> 年七十一建安二十四年終有子八人朗最長次即晉宣皇帝也

**司马防于建安二十四年去世** 司马防卒，年七十一；有八子，司马朗居长，次子司马懿即后追尊晋宣帝。

**归年依据** 《司马彪序传》明书建安二十四年，子女名次为附记。

[219年第36条](../../years/ce-0201-0300/ce-0219.md#sgz015-p-002-3)。

## 003｜裴松之评司马朗与董卓问答

Kanripo四库本 5b原行 100—101。附见[正文 L787](../本地分卷/三国志/三国志-卷015.md#l787)。

<a id="pei-003-1"></a>

> 臣松之案朗此對但為稱述卓功徳末相箴誨而已了不自申釋而卓便云吾亦悟之卿言有意客主之辭如為不相酬塞也

**裴松之评司马朗与董卓问答** 裴松之指出司马朗称卓功德、末加规谏，却没有为私逃自辩；董卓说“吾亦悟之”，答语并不对应。

[268年第6条](../../years/ce-0201-0300/ce-0268.md#sgz015-p-006-5)。

## 008｜梁习与鲜卑育延互市，断狱斩首领

Kanripo四库本 9a—9b原行 162—171。附见[正文 L794](../本地分卷/三国志/三国志-卷015.md#l794)。

<a id="pei-008-1"></a>

> 魏畧曰鮮卑大人育延常為州所畏而一旦將其部落五千餘騎詣習求互市習念不聽則恐其怨若聽到州下又恐為所畧於是乃許之往與㑹空城中交市遂敕郡縣自將治中以下軍往就之市易未畢市吏收縳一胡延騎皆驚上馬彎弓圍習數重吏民惶怖不知所施習乃徐呼市吏問縳胡意而胡實侵犯人習乃使譯呼延延到習責延曰汝胡自犯法吏不侵汝汝何為使諸騎驚駭邪遂斬之餘胡破膽不敢動是後無寇虜

**梁习与鲜卑育延互市，断狱斩首领** 梁习允五千余骑到空城互市，一胡犯禁被缚，诸骑张弓环围。梁习查实后召育延责问且斩之，余部不敢动。

**归年依据** 《魏略》只明在建安二十二年以前，互市及斩育延无确年。

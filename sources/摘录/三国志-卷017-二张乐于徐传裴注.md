## 001｜张辽劝曹操防刘备袭许

Kanripo四库本 2b原行 44—45。附见[正文 L873](../本地分卷/三国志/三国志-卷017.md#l873)。

<a id="pei-001-1"></a>

> 傅子曰太祖將征柳城遼諫曰夫許天下之㑹也今天子在許公遠北征若劉表遣劉備襲許據之以號令四方公之勢去矣太祖䇿表必不能任備遂行也

**张辽劝曹操防刘备袭许** 《傅子》记北征前张辽担心刘表用刘备取许挟天子，曹操判断刘表不会任用刘备，仍出兵。

**归年依据** 北征柳城是建安十二年；这里述出师前议论，与本传临阵劝战属于两个时间点。

[207年第1条](../../years/ce-0201-0300/ce-0207.md#sgz017-p-001-1)。

## 002｜孙盛评合肥密教与三将配合

Kanripo四库本 4a—4b原行 74—79。附见[正文 L875](../本地分卷/三国志/三国志-卷017.md#l875)。

<a id="pei-002-1"></a>

> 孫盛曰夫兵固詭道竒正相資若乃命將出征推轂委權或頼率然之形或慿犄角之勢羣帥不和則棄師之道也至於合肥之守縣弱無援專任勇者則好戰生患專任怯者則懼心難保且彼衆我寡必懐貪墮以致命之兵擊貪墮之卒其勢必勝勝而後守守則必固是以魏武推選方員參以同異為之密敎節宣其用事至而應若合符契妙矣夫

**孙盛评合肥密教与三将配合** 兵法重奇正互用，三帅不能不和；孙盛以合肥兵少援绝、对手众多而懈怠，说明曹操兼用长短、密教调度才能奏效。

**归年依据** 所评战役在215年，孙盛发论系晋人史评，确年无载。

[孙盛评合肥密教与三将配合（时期）](../../years/ce-0201-0300/时期-三国志卷017-二张乐于徐传纪年待考.md#period-sgz017-p-002-1)。

## 004｜裴松之批评于禁斩降将昌豨

Kanripo四库本 9b原行 170—171。附见[正文 L882](../本地分卷/三国志/三国志-卷017.md#l882)。

<a id="pei-004-1"></a>

> 臣松之以為圍而後降法雖不赦囚而送之未為違命禁曾不為舊交希冀萬一而肆其好殺之心以戾衆人之議所以卒為降虜死加惡諡宜哉

**裴松之批评于禁斩降将昌豨** 裴松之认为围后降不赦仍可先送曹操办理，且于禁才是旧友，他的操作近于好杀；又以本人后来降敌、获恶谥作对比。

**归年依据** 本注为刘宋时评述206年斩昌豨及219年降，评语单年不可考。

[裴松之批评于禁斩降将昌豨（时期）](../../years/ce-0201-0300/时期-三国志卷017-二张乐于徐传纪年待考.md#period-sgz017-p-004-1)。

## 005｜曹丕召见还魏的于禁

Kanripo四库本 10b原行 191—192。附见[正文 L883](../本地分卷/三国志/三国志-卷017.md#l883)。

<a id="pei-005-1"></a>

> 魏書載制曰昔荀林父敗績於邲孟明喪師於殽秦晉不替使復其位其後晉獲狄土秦霸西戎區區小國猶尚若斯而况萬乘乎樊城之敗水災暴至非戰之咎其復禁等官

**曹丕召见还魏的于禁** 魏诏举荀林父败于邲、孟明视败于崤后仍被任用的前例，认为樊城因猝遇大水而败，诏复于禁等官。

**归年依据** 《文帝纪》黄初二年八月送还于禁，拜安远将军与引见相承。诏中邲战、崤战为引用的前代事例。

[221年第63条](../../years/ce-0201-0300/ce-0221.md#sgz017-p-005-1)。

## 006｜张郃建议袁绍切断曹军南路

Kanripo四库本 11a原行 200—200。附见[正文 L885](../本地分卷/三国志/三国志-卷017.md#l885)。

<a id="pei-006-1"></a>

> 漢晉春秋曰郃説紹曰公雖連勝然勿與曹公戰也密遣輕騎鈔絶其南則兵自敗矣紹不從之

**张郃建议袁绍切断曹军南路** 《汉晋春秋》载张郃劝袁绍莫主动交锋，密以轻骑截断曹军南路，可使曹军自行溃散。袁绍未采用。

**归年依据** 附官渡相拒，建安五年。

[200年第8条](../../years/ce-0101-0200/ce-0200.md#sgz017-p-006-1)。

## 007｜裴松之指出官渡溃军、张郃归降的异序

Kanripo四库本 11b原行 208—210。附见[正文 L885](../本地分卷/三国志/三国志-卷017.md#l885)。

<a id="pei-007-1"></a>

> 臣松之案武紀及袁紹傳並云袁紹使張郃髙覧攻太祖營郃等聞淳于瓊破遂來降紹衆於是大潰是則緣郃等降而後紹軍壊也至如此傳為紹軍先潰懼郭圖之譖來歸太祖為參錯不同矣

**裴松之指出官渡溃军、张郃归降的异序** 裴松之按《武帝纪》《袁绍传》，张郃、高览先降，袁绍大军后溃；本传则先记溃败，再记张郃被郭图诬谤而降。

**归年依据** 三种文字指建安五年同一战事，保留相反先后次序。

[200年第8条](../../years/ce-0101-0200/ce-0200.md#sgz017-p-007-1)。

## 008｜《魏略》记刘备得知夏侯渊被斩后的话

Kanripo四库本 12b原行 226—227。附见[正文 L886](../本地分卷/三国志/三国志-卷017.md#l886)。

<a id="pei-008-1"></a>

> 魏畧曰淵雖為都督劉備憚郃而易淵及殺淵備曰當得其魁用此何為邪

## 009｜《魏略》记司马懿强令张郃追击

Kanripo四库本 14b原行 259—260。附见[正文 L889](../本地分卷/三国志/三国志-卷017.md#l889)。

<a id="pei-009-1"></a>

> 魏畧曰亮軍退司馬宣王使郃追之郃曰軍法圍城必開出路歸軍勿追宣王不聽郃不得已遂進蜀軍乘髙布伏弓弩亂發矢中郃髀

**《魏略》记司马懿强令张郃追击** 诸葛亮退军，张郃主张归军勿追，司马懿仍命他进击；蜀军设高地伏，矢中其髀。

**归年依据** 太和五年木门追击，正文说中右膝，裴注所引说中大腿。

[231年第3条](../../years/ce-0201-0300/ce-0231.md#sgz017-p-009-1)。

> 臣松之云案晃于時未應稱臣傳寫者誤也

**裴松之疑徐晃自称臣为传写误** 裴松之按当时名分认为徐晃无需自称「臣」，怀疑抄本误写。

## 012｜朱灵攻取鄃城，母弟遇难

Kanripo四库本 18b—19a原行 331—340。附见[正文 L897](../本地分卷/三国志/三国志-卷017.md#l897)。

<a id="pei-012-1"></a>

> 九州春秋曰初清河季雍以鄃叛袁紹而降公孫瓚瓚遣兵衛之紹遣靈攻之靈家在城中瓚將靈母弟置城上誘呼靈靈望城涕泣曰丈夫一出身與人豈復顧家邪遂力戰抜之生禽雍而靈家皆死

**朱灵攻取鄃城，母弟遇难** 《九州春秋》说清河季雍背袁绍投公孙瓒，朱灵家在城内；公孙瓒部以家人胁他，朱灵仍攻破鄃城，擒季雍，家人尽死。

**归年依据** 袁绍、公孙瓒交战在191至199年间，此役所在的确年注无明文。

[朱灵攻取鄃城，母弟遇难（时期）](../../years/ce-0201-0300/时期-三国志卷017-二张乐于徐传纪年待考.md#period-sgz017-p-012-1)。

<a id="pei-012-2"></a>

> 魏書曰靈字文博太祖既平冀州遣靈將新兵五千人騎千匹守許南太祖戒之曰冀州新兵數乘寛緩暫見齊整意尚怏怏卿名先有威嚴善以道寛之不然即有變靈至陽翟中郎將程昻等果反即斬昻以狀聞

**曹操遣朱灵领冀州新兵南屯，程昂反叛** 《魏书》记朱灵字文博，平冀后曹操令其领兵五千、骑千匹守许南，嘱他宽待新兵；到阳翟，程昂等果反，朱灵斩昂汇报。

**归年依据** 平冀的204年为下限，派兵和兵变无确年。

[曹操遣朱灵领冀州新兵南屯，程昂反叛（时期）](../../years/ce-0201-0300/时期-三国志卷017-二张乐于徐传纪年待考.md#period-sgz017-p-012-2)。

<a id="pei-012-3"></a>

> 太祖手書曰兵中所以為危險者外對敵國内有姦謀不測之變昔鄧禹中分光武軍西行而有宗歆馮愔之難後將二十四騎還洛陽禹豈以是減損哉來書懇惻多引咎過未必如所云也

**曹操答朱灵平兵变书** 曹操说军中内外皆有猝变，以邓禹军中旧事为例，宽慰朱灵无需过分引咎。

**归年依据** 曹操手书承前，未标答书年月；所引邓禹是早年的旧史。

[曹操答朱灵平兵变书（时期）](../../years/ce-0201-0300/时期-三国志卷017-二张乐于徐传纪年待考.md#period-sgz017-p-012-3)。

<a id="pei-012-4"></a>

> 文帝即位封靈鄃侯増其户邑詔曰將軍佐命先帝典兵歴年威過方邵功踰綘灌圖籍所美何以加焉朕受天命帝有海内元功之將社稷之臣皆朕所與同福共慶傳之無窮者也今封鄃侯富貴不歸故鄉如夜行衣繡若平常所志願勿難言

**曹丕封朱灵鄃侯** 曹丕称赞朱灵历年辅佐曹操，以方叔、召虎、周勃、灌婴拟其战功，因受天命与有功者共享，封朱灵为鄃侯，并问其本愿。

**归年依据** 诏言「朕受天命」，附黄初元年曹丕受禅后封赏。

[220年第4条](../../years/ce-0201-0300/ce-0220.md#sgz017-p-012-4)。

<a id="pei-012-5"></a>

> 靈謝曰髙唐宿所願於是更封髙唐侯薨諡曰威侯子術嗣

**朱灵改封高唐，谥威侯** 朱灵说本愿在高唐，曹丕依请改封。朱灵薨后谥威侯，子朱术继。

**归年依据** 改封约在220至226年曹丕在位，卒、谥、继爵确年均不载，243年入太祖庙庭可参考。

[朱灵改封高唐，谥威侯（时期）](../../years/ce-0201-0300/时期-三国志卷017-二张乐于徐传纪年待考.md#period-sgz017-p-012-5)。

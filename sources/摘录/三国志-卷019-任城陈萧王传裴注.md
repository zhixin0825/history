## 001｜裴松之辨桑乾旧县与当时名称

维基文库四库本原行 11—11。附见[正文 L945](../本地分卷/三国志/三国志-卷019.md#l945)。

<a id="pei-001-1"></a>

> 臣松之案桑乾縣屬代郡今北虜居之號為索干之都

**裴松之辨桑乾旧县与当时名称** 桑乾县本属代郡，裴松之说其时北方族群在此居住、称作索干之都。

**归年依据** 县名与裴松之所说“今”的地望考释，各无独立记年。

## 002｜曹操汉中对阵刘备，欲召曹彰

维基文库四库本原行 11—11。附见[正文 L945](../本地分卷/三国志/三国志-卷019.md#l945)。

<a id="pei-002-1"></a>

> 魏畧曰太祖在漢中而劉備栖於山頭使劉封下挑戰太祖罵曰賣履舍兒長使假子拒汝公乎待呼我黄鬚來令擊之

**曹操汉中对阵刘备，欲召曹彰** 曹操已进入汉中，刘备居山使刘封下山挑衅，曹操讥其遣假子并说将唤“黄须”迎敌。

**归年依据** 《魏略》明曹操亲在汉中，《武帝纪》仅219年三至五月亲临这一战场。

[219年第11条](../../years/ce-0201-0300/ce-0219.md#sgz019-p-002-1)。

<a id="pei-002-2"></a>

> 乃召彰彰晨夜進道西到長安而太祖已還從漢中而歸彰鬚黄故以呼之

**曹操汉中召曹彰未及会战** 曹彰接命晨夜兼程，到长安时曹操已经自汉中回撤；魏略解释黄须是因其胡须颜色。

**归年依据** 同一战局，五月曹操归长安。

[219年第11条](../../years/ce-0201-0300/ce-0219.md#sgz019-p-002-2)。

## 003｜曹彰曹植谈曹操临终召见用意

维基文库四库本原行 11—11。附见[正文 L946](../本地分卷/三国志/三国志-卷019.md#l946)。

<a id="pei-003-1"></a>

> 魏畧曰彰至謂臨菑侯植曰先王召我者欲立汝也植曰不可不見袁氏兄弟乎

**曹彰曹植谈曹操临终召见用意** 《魏略》说曹彰到后认为先王要立曹植，曹植以袁绍诸子相争为戒。

**归年依据** 接本传220年曹操临终召曹彰；这是魏略转录的曹彰判断。

[220年第1条](../../years/ce-0201-0300/ce-0220.md#sgz019-p-003-1)。

## 004｜曹丕令曹彰就国、增邑

维基文库四库本原行 11—11。附见[正文 L946](../本地分卷/三国志/三国志-卷019.md#l946)。

<a id="pei-004-1"></a>

> 魏畧曰太子嗣立既葬遣彰之國始彰自以先王見任有功冀因此遂見授用而聞當隨例意甚不悦不待遣而去時以鄢陵塉薄使治中牟

**曹丕令曹彰就国、增邑** 魏略称曹丕继位葬曹操后遣彰就国，曹彰自恃有功求任，见须照例赴国便不悦先离；因鄢陵地薄，令他治中牟。

**归年依据** 220年曹丕继魏王位及曹操葬后；本传同记遣就国、增邑。

[220年第141条](../../years/ce-0201-0300/ce-0220.md#sgz019-p-004-1)。

<a id="pei-004-2"></a>

> 及帝受禪因封為中牟王

**《魏略》称曹丕禅代后封曹彰中牟王** 魏略把中牟王封给曹彰本人的事连在曹丕受禅之后。

**归年依据** 曹丕黄初元年受禅。本传221进公、222封任城王，223以中牟改封曹楷，二说并存。

[220年第142条](../../years/ce-0201-0300/ce-0220.md#sgz019-p-004-2)。

<a id="pei-004-3"></a>

> 是後大駕幸許昌北州諸侯上下皆畏彰之剛嚴毎過中牟不敢不速

**曹丕幸许昌时诸侯畏曹彰** 魏略说天子到许昌，北州诸侯畏惧曹彰刚严，路过中牟均匆匆。

**归年依据** 黄初元年后、曹彰223年死前；帝纪所记幸许昌多次，不锁一次。

[曹丕幸许昌时诸侯畏曹彰（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（1）.md#period-sgz019-p-004-3)。

## 005｜《魏氏春秋》称曹彰先问玺绶

维基文库四库本原行 11—11。附见[正文 L946](../本地分卷/三国志/三国志-卷019.md#l946)。

<a id="pei-005-1"></a>

> 魏氏春秋曰初彰問璽綬將有異志

**《魏氏春秋》称曹彰先问玺绶** 孙盛记曹彰早先询问玺绶，认为有所异志，由此解释后来未即获得接见。

**归年依据** 材料只记“初”；语意系属继承嫌疑，但问玺确日未载。

[《魏氏春秋》称曹彰先问玺绶（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（1）.md#period-sgz019-p-005-1)。

<a id="pei-005-2"></a>

> 故來朝不即得見彰忿怒暴薨

**《魏氏春秋》称曹彰不得即见而忿怒暴死** 曹彰赴京后不能立即见皇帝，恼怒而突然去世，与本传称病逝相异。

**归年依据** 本传、《文帝纪》黄初四年六月甲戌记卒；魏氏春秋对死因别叙。

[223年第12条](../../years/ce-0201-0300/ce-0223.md#sgz019-p-005-2)。

## 007｜曹植登铜雀台作赋

维基文库四库本原行 11—11。附见[正文 L948](../本地分卷/三国志/三国志-卷019.md#l948)。

<a id="pei-007-1"></a>

> 陰澹魏紀載植賦曰從明后而嬉游兮登層臺以娛情見太府之廣開兮觀聖徳之所營建髙門之嵯峨兮浮雙闕乎太清立中天之華觀兮連飛閣乎西城

**曹植登铜雀台作赋** 据阴澹《魏纪》，曹植与曹操游铜雀台，见府署敞开、高门双阙与相连飞阁。

**归年依据** 曹丕《登台赋序》（《艺文类聚》卷六十二）明建安十七年春受命兄弟同作；210年为始建。

[212年第29条](../../years/ce-0201-0300/ce-0212.md#sgz019-p-007-1)。

<a id="pei-007-2"></a>

> 臨漳水之長流兮望園果之滋榮仰春風之和穆兮聼百鳥之悲鳴天雲垣其既立兮家願得而獲逞揚仁化於宇内兮盡肅恭於上京

**曹植登铜雀台作赋** 台上可见漳水长流、园果繁荣，感春风和暖而听鸟鸣；又颂台垣建成、仁化远及宇内。

**归年依据** 同篇登台赋，附212年春作赋。

[212年第29条](../../years/ce-0201-0300/ce-0212.md#sgz019-p-007-2)。

<a id="pei-007-3"></a>

> 惟桓文之為盛兮豈足方乎聖明休矣美矣恵澤逺揚翼佐我皇家兮寧彼四方同天地之規量兮齊日月之暉光永貴尊而無極兮等年壽於東王云云太祖深異之

**曹植登铜雀台作赋** 赋以齐桓公晋文公比而不及，赞颂皇家教泽、宁定四方并祝尊寿；阴澹说曹操深为称异。

**归年依据** 同篇登台赋，附212年春作赋。

[212年第29条](../../years/ce-0201-0300/ce-0212.md#sgz019-p-007-3)。

## 008｜曹操一度器重曹植可定大事

> 魏武故事載令曰始者謂子建兒中最可定大事

**曹操一度器重曹植可定大事** 《魏武故事》保存曹操令追述早先在诸子中最看重曹植。

**归年依据** 令所追记的态度及令本日期不明。

[曹操一度器重曹植可定大事（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（1）.md#period-sgz019-p-008-1)。

**曹操因曹植私开司马门而变其看法** 曹操令称临菑侯曹植私出司马门至金门，从此另眼看待。

**归年依据** 本传继217年增邑载旧事、未标独立年月；曹植214年为临菑侯。

[曹操因曹植私开司马门而变其看法（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（1）.md#period-sgz019-p-008-2)。

<a id="pei-008-3"></a>

> 又令曰諸侯長史及帳下吏知吾出輒將諸侯行意否從子建私開司馬門來吾都不復信諸侯也恐吾適出便復私出故攝將行不可恒使吾爾誰為心腹也

**曹操出行时防诸侯擅出** 曹操令问诸侯长史等是否知道自己远行会带诸侯同行，因曹植前事不信诸侯，担心自己出门又有人私出。

**归年依据** 《魏武故事》承私开司马门，诸令单独发布日期不明。

## 009｜杨修家世、才行和仕历

维基文库四库本原行 11—11。附见[正文 L954](../本地分卷/三国志/三国志-卷019.md#l954)。

<a id="pei-009-1"></a>

> 典畧曰楊脩字徳祖太尉彪子也謙㳟才博建安中舉孝亷除郎中丞相請署倉曹屬主簿是時軍國多事脩總知外内事皆稱意自魏太子已下並爭與交好

**杨修家世、才行和仕历** 《典略》称杨彪之子杨修谦恭才博，建安中举孝廉、除郎中，曹操辟为仓曹属、主簿，办理军国事得当，魏太子以下争与之结交。

**归年依据** “建安中”宽泛；除授与太子交游先后无逐一纪日。

[杨修家世、才行和仕历（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（1）.md#period-sgz019-p-009-1)。

<a id="pei-009-2"></a>

> 又是時臨菑侯植以才捷愛幸來意投修數與脩書書曰數日不見思子為勞想同之也僕少好辭賦迄至于今二十有五年矣然今世作者可畧而言也

**曹植交杨修并致书叙谈** 曹植受曹操宠幸，与杨修投契，多通信往来；信前说数日不见而思，少好辞赋，欲评论当世作者。

**归年依据** 称临菑侯，限214–220；杨修于219年被杀，信具体年未载。

[曹植交杨修并致书叙谈（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（1）.md#period-sgz019-p-009-2)。

<a id="pei-009-3"></a>

> 昔仲宣獨步於漢南孔璋鷹揚於河朔偉長擅名於青土公幹振藻於海隅徳璉發迹於大魏足下髙視於上京當此之時人人自謂掘靈蛇之珠家家自謂抱荆山之玉也吾王於是設天綱以該之頓八紘以掩之今盡集兹國矣

**曹植列举建安文士并赞曹操罗致人才** 按各自活动地称举王粲、陈琳、徐干、刘桢、应玚、杨修，说魏王广罗俊彦。

**归年依据** 曹植答赠杨修书；有追述，不能由人物在世径定写信年。

[曹植列举建安文士并赞曹操罗致人才（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（1）.md#period-sgz019-p-009-3)。

<a id="pei-009-4"></a>

> 然此數子猶不能飛翰絶迹一舉千里也以孔璋之才不閑辭賦而多自謂與司馬長卿同風譬畫虎不成還為狗者也前為書啁之反作論盛道僕贊其文

**曹植评诸文士才能与陈琳之赋** 赞多位作者而谓尚未卓绝，称陈琳才高却不长辞赋；谈此前自己写信戏评陈琳，陈琳反作论褒己。

**归年依据** 曹植致杨修信，前后文章的独立年月皆缺。

[曹植评诸文士才能与陈琳之赋（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（1）.md#period-sgz019-p-009-4)。

<a id="pei-009-5"></a>

> 夫鍾期不失聼于今稱之吾亦不敢妄歎者畏後之嗤余也世人著述不能無病僕常好人譏彈其文有不善者應時改定

**曹植主张作者听取批评** 以钟子期知音为例，说不随意称赏，且常希望别人指出自己作品中的错误，随即改正。

**归年依据** 曹植致杨修信。

[曹植主张作者听取批评（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（1）.md#period-sgz019-p-009-5)。

<a id="pei-009-6"></a>

> 昔丁敬禮嘗作小文使僕潤飾之僕自以才不能過若人辭不為也敬禮云卿何所疑難乎文之佳麗吾自得之後世誰相知定吾文者邪吾常歎此逹言以為美談

**曹植引丁廙谈改文** 丁廙请曹植润色，曹植开始以才不及辞谢；丁说文好后人归自己、不会辨改者是谁，曹植赞其通达。

**归年依据** 信引旧事，丁廙交文无独立年。

[曹植引丁廙谈改文（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（1）.md#period-sgz019-p-009-6)。

<a id="pei-009-7"></a>

> 昔尼父之文辭與人通流至於制春秋游夏之徒不能錯一字過此而言不病者吾未之見也盖有南威之容乃可以論於淑媛有龍淵之利乃可以議於割斷

**曹植引孔子修《春秋》论作者难免缺点** 说游、夏不能增损孔子《春秋》一字，旁人却无此能力；又以南威美貌、龙渊锋利比评鉴资格。

**归年依据** 信内古例和主张。

[曹植引孔子修《春秋》论作者难免缺点（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（1）.md#period-sgz019-p-009-7)。

<a id="pei-009-8"></a>

> 劉季緒才不逮於作者而好詆呵文章掎摭利病昔田巴毁五帝罪三王呰五伯於稷下一旦而服千人魯連一説使終身杜口劉生之辯未若田氏今之仲連求之不難可無歎息乎

**曹植批刘季绪好作文章攻讦** 以田巴在稷下攻讦古人、经鲁仲连一言而罢比刘季绪，称其才辩不及而喜挑剔。

<a id="pei-019-1"></a>

> 植常為瑟瑟調歌辭曰吁嗟此轉蓬居世何獨然長去本根逝夙夜無休閑東西經七陌南北越九阡

**曹植《瑟瑟调歌辞》写转蓬离根** 以蓬草离根昼夜不休、东奔西走的形象比漂泊身世。

**归年依据** 本传只有“常为”；裴注未记写作年，勿从移封或卒年倒定。

[曹植《瑟瑟调歌辞》写转蓬离根（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（2）.md#period-sgz019-p-019-1)。

<a id="pei-019-2"></a>

> 卒遇回風起吹我入雲間自謂終天路忽焉下沈淵

**《瑟瑟调歌辞》写蓬草飞云间又沉下** 旋风把蓬吹上云端，自觉似可长飞，却突然下沉深渊。

**归年依据** 同诗，比兴无独立史年。

[《瑟瑟调歌辞》写蓬草飞云间又沉下（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（2）.md#period-sgz019-p-019-2)。

<a id="pei-019-3"></a>

> 驚飈接我出故歸彼中田當南而更北謂東而反西宕宕當何依忽亡而復存

**《瑟瑟调歌辞》写转蓬方向不由己** 暴风把蓬草卷回田间，南北东西变幻，忽没忽现，不知安身何处。

**归年依据** 同诗。

[《瑟瑟调歌辞》写转蓬方向不由己（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（2）.md#period-sgz019-p-019-3)。

<a id="pei-019-4"></a>

> 飄颻周八澤連翩歴五山流轉無恒處誰知吾若艱願為中林草秋随野火燔糜滅豈不痛願與林葉連

**《瑟瑟调歌辞》写宁为林间草** 写蓬草飞遍湖泽山川而无常处，宁愿化作林间草，即使被野火烧也愿依从林叶。

**归年依据** 同诗收束。

[《瑟瑟调歌辞》写宁为林间草（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（2）.md#period-sgz019-p-019-4)。

<a id="pei-019-5"></a>

> 孫盛曰異哉魏氏之封建也不度先王之典不思藩屏之術違敦穆之風背維城之義漢初之封或權侔人主雖云不度時勢然也魏氏諸侯陋同匹夫雖懲七國矯枉過也且魏之代漢非積徳之由風澤既㣲六合未一而彫翦枝幹委權異族勢同廆木危若巢幕不嗣忽諸非天喪也

**孙盛评曹魏藩国封建过弱** 史家比较汉初诸侯过强与曹魏矫枉过正，批评藩国如匹夫、削弱同姓而权归异姓，自损根基。

**归年依据** 晋人孙盛史评，概述魏制度及亡国原因，无确年事件。

[孙盛评曹魏藩国封建过弱（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（2）.md#period-sgz019-p-019-5)。

<a id="pei-019-6"></a>

> 五等之制萬世不易之典六代興亡曹同論之詳矣

**孙盛称五等封制永垂，并引曹冏为证** 孙盛自述五等制为常典，称曹冏《六代论》已详述历史兴亡。

**归年依据** 注内按语，非曹魏时期实行五等制度的实事。

[孙盛称五等封制永垂，并引曹冏为证（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（2）.md#period-sgz019-p-019-6)。

<a id="pei-020-1"></a>

> 志别傳曰志字允㳟好學有才行

**曹志字允恭、好学有才行** 《曹志别传》述曹志表字和爱学才行。

**归年依据** 人物背景。

[曹志字允恭、好学有才行（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（2）.md#period-sgz019-p-020-1)。

<a id="pei-020-2"></a>

> 晉武帝為中撫軍迎常道鄉公于鄴志夜與帝相見帝與語從暮至旦甚器之

**司马炎奉命迎曹奂，夜与曹志谈至天明** 司马炎任中抚军至邺迎常道乡公时，曹志夜见，谈至清晨，司马炎赏识之。

**归年依据** 《三少帝纪》景元元年五月己卯使司马炎出迎，六月曹奂即位；当时名曹璜，后改奂。

[260年第6条](../../years/ce-0201-0300/ce-0260.md#sgz019-p-020-2)。

<a id="pei-020-3"></a>

> 及受禪改封鄄城公

**晋受魏禅后降曹志为鄄城公** 司马炎受禅后，把魏济北王曹志降为鄄城公。

**归年依据** 按《晋书·武帝纪》泰始元年、《三少帝纪》咸熙二年十二月，仓内改朝事件系265年，月份换公历跨次年。

[265年第4条](../../years/ce-0201-0300/ce-0265.md#sgz019-p-020-3)。

<a id="pei-020-4"></a>

> 發詔以志為樂平太守歴章武趙郡

**司马炎令曹志任乐平太守，后历章武赵郡** 西晋先诏用曹志任乐平太守，后来迁章武、赵郡。

**归年依据** 《晋书·曹志传》诏自称此前少有空缺，任命不必同受禅年；郡任亦无独年。

> 遷散騎常侍國子博士

**归年依据** 《晋书·曹志传》系咸宁初；《职官志》记咸宁四年初立国子学，相关表述难据以硬定个人除授年。

**曹志反对司马攸出藩，晋武帝免其官** 晋武帝要礼官议齐王出藩当赐的典仪；曹志认为才亲兼具不应使其远在海隅，奏谏甚切，皇帝大怒免官。

## 021｜鱼豢认为曹操未及早阻遏宗子窥望

维基文库四库本原行 13—13。附见[正文 L1046](../本地分卷/三国志/三国志-卷019.md#l1046)。

<a id="pei-021-1"></a>

> 魚豢曰諺言貧不學儉卑不學㳟非人性分也勢使然耳此實然之勢信不虚矣假令太祖防遏植等在於疇昔此賢之心何緣有窺望乎

**鱼豢认为曹操未及早阻遏宗子窥望** 以贫迫使俭、卑位促恭说明时势，并说曹操若及早规束，曹彰、曹植何至动储位之心。

**归年依据** 鱼豢论赞，回顾储位争夺，无一时一事。

[鱼豢认为曹操未及早阻遏宗子窥望（时期）](../../years/ce-0201-0300/时期-三国志卷019-任城陈萧王传纪年待考（2）.md#period-sgz019-p-021-1)。

<a id="pei-021-2"></a>

> 彰之挾恨尚無所至至於植者乃令楊修以倚注遇害丁儀以希意族滅哀夫余每覽植之華采思若有神以此推之太祖之動心亦良有以也

**鱼豢评曹彰、曹植遭遇与魏廷储争** 鱼豢称曹彰含恨，亲附曹植的杨修、丁仪因此受害；又赞曹植文采思若神明，理解曹操为其动心。

**归年依据** 鱼豢综合评议，杨修219年、丁氏220年遭杀另有正文及注文对应。

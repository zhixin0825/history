## 002｜桓阶以长子曹丕的才德劝曹操定储

<a id="pei-002-1"></a>

> 魏書稱階諌曰今太子位冠羣子名昭海内仁聖達節天下莫不聞而大王甫以植而問臣臣誠惑之於是太祖知階篤於守正深益重焉

**桓阶以长子曹丕的才德劝曹操定储** 《魏书》载桓阶称曹丕在诸子中居首，声名与仁智皆著，无法认同为曹植动议，曹操愈加看重其守正。

**归年依据** 本传明太子未定，曹植临菑侯214、曹丕217立；此劝说无具体年。

## 004｜陈氏三人的表字及声望

维基文库四库本原行 12—12。附见[正文 L1179](../本地分卷/三国志/三国志-卷022.md#l1179)。

<a id="pei-004-1"></a>

> 寔字仲弓紀字元方諶字季方魏書曰寔徳冠當時紀諶並名重於世

**陈氏三人的表字及声望** 陈寔字仲弓，陈纪字元方，陈谌字季方，父子皆有著名德行。

**归年依据** 家世总述。

[陈氏三人的表字及声望（时期）](../../years/ce-0201-0300/时期-三国志卷022-桓二陈徐卫卢传纪年待考（2）.md#period-sgz022-p-004-1)。

<a id="pei-004-2"></a>

> 寔為太丘長遭黨錮隱居荆山遠近宗師之

**陈寔任太丘长，遭党锢后隐居** 因党锢隐居荆山，四方士人尊之为师。

**归年依据** 首次党锢、复捕及隐居有先后，注不标任长、隐居的单一年，参《后汉书·陈寔传》。

[陈寔任太丘长，遭党锢后隐居（时期）](../../years/ce-0201-0300/时期-三国志卷022-桓二陈徐卫卢传纪年待考（2）.md#period-sgz022-p-004-2)。

<a id="pei-004-3"></a>

> 靈帝崩何進輔政引用天下名士徵寔欲以為參軍以老病遂不屈節

**《魏书》称何进在灵帝死后征陈寔** 何进任政用名士，欲征陈寔参军，陈寔以老病不从。

**归年依据** 若照魏书措辞则在189年，但《后汉书·陈寔传》明卒中平四年（187），又记何进征在党禁初解后且人尚在，故保留矛盾，征召不锁189。

[《魏书》称何进在灵帝死后征陈寔（时期）](../../years/ce-0201-0300/时期-三国志卷022-桓二陈徐卫卢传纪年待考（2）.md#period-sgz022-p-004-3)。

<a id="pei-004-4"></a>

> 諶為司空掾早卒

**陈谌任司空掾后早卒** 陈谌官任司空府掾，早年去世。

**归年依据** 注不明任官与卒年月。

[陈谌任司空掾后早卒（时期）](../../years/ce-0201-0300/时期-三国志卷022-桓二陈徐卫卢传纪年待考（2）.md#period-sgz022-p-004-4)。

<a id="pei-004-5"></a>

> 紀歴位平原相侍中大鴻臚著書數十篇世謂之陳子

**陈纪历平原相等并著《陈子》** 陈纪曾任平原相、侍中、大鸿胪，有著作多篇，世称《陈子》。

**归年依据** 《后汉书·陈寔传附陈纪》分别叙其为侍中、平原相、大鸿胪的官序，只有大鸿胪可限定建安初，书作年份缺。

[陈纪历平原相等并著《陈子》（时期）](../../years/ce-0201-0300/时期-三国志卷022-桓二陈徐卫卢传纪年待考（2）.md#period-sgz022-p-004-5)。

<a id="pei-004-6"></a>

> 寔之亡也司空荀爽太僕令韓融並制緦麻執子孫禮四方至者車數千乘自太原郭泰等無不造門

**陈寔去世，荀爽与韩融服缌麻** 魏书记二人以子孙礼服丧，来致哀数千车，连郭泰等名士皆被举来说明其门誉。

**归年依据** 《后汉书》定陈寔中平四年（187）卒。郭泰同书本传在建宁二年（169）已卒，故这句不能释为他187年到场。

[187年第17条](../../years/ce-0101-0200/ce-0187.md#sgz022-p-004-6)。

<a id="pei-004-7"></a>

> 傅子曰寔亡天下致弔㑹其葬者三萬人制縗麻者以百數

**《傅子》述三万人会陈寔葬礼** 远近致吊三万人，服衰麻以百计。

**归年依据** 《后汉书·陈寔传》同列中平四年卒吊。

[187年第17条](../../years/ce-0101-0200/ce-0187.md#sgz022-p-004-7)。

<a id="pei-004-8"></a>

> 先賢行狀曰大將軍何進遣屬弔祠諡曰文範先生

**何进遣属吊祭陈寔，谥文范先生** 何进遣人吊祠，陈寔得谥文范先生。

**归年依据** 《后汉书·陈寔传》中平四年去世并载何进遣使祭。

[187年第17条](../../years/ce-0101-0200/ce-0187.md#sgz022-p-004-8)。

<a id="pei-004-9"></a>

> 于時寔紀高名並著而諶又配之世號曰三君每宰府辟命率皆同時羔鴈成羣丞掾交至豫州百姓皆圖畫寔紀諶之形象

**陈氏三君并著、官府常同时征聘** 陈寔、陈纪、陈谌合称三君；各官府征辟常同时到，豫州百姓画三人形象。

**归年依据** 多次征召及画像无确年。《后汉书》另写图范陈纪至孝，不日系。

[陈氏三君并著、官府常同时征聘（时期）](../../years/ce-0201-0300/时期-三国志卷022-桓二陈徐卫卢传纪年待考（2）.md#period-sgz022-p-004-9)。

## 005｜裴松之引用元始二年汝南户籍

维基文库四库本原行 12—12。附见[正文 L1191](../本地分卷/三国志/三国志-卷022.md#l1191)。

<a id="pei-005-1"></a>

> 臣松之案漢書地理志云元始二年天下戸口最盛汝南郡為大郡有三十餘萬戸則文景之時不能如是多也

**裴松之引用元始二年汝南户籍** 引《汉书·地理志》，称元始二年全国户口盛，汝南大郡三十余万户，据此认为文景时不会比它更多。

**归年依据** 《汉书·地理志》人口数据元始二年一组；注以此核陈群之论。

[2年第28条](../../years/ce-0001-0100/ce-0002.md#sgz022-p-005-1)。

<a id="pei-005-2"></a>

> 案晉太康三年地記晉戸有三百七十七萬吳蜀戸不能居半以此言之魏雖始承喪亂方晉亦當無乃大殊長文之言於是為過

**裴松之据《太康三年地记》驳陈群所估魏户数** 该书载晋有三百七十七万户，裴松之以吴蜀不足占半，推知魏不能少至等同汉一大郡。

**归年依据** 裴注书名明确太康三年（282）；《晋书·地理志》太康元年平吴总户数为另一数字、另年，不能互换。

[282年第5条](../../years/ce-0201-0300/ce-0282.md#sgz022-p-005-2)。

## 006｜孙盛批华饰宫室可开后世奢风

维基文库四库本原行 12—12。附见[正文 L1193](../本地分卷/三国志/三国志-卷022.md#l1193)。

<a id="pei-006-1"></a>

> 孫盛曰周禮天子之宫有斵礱之制然質文之飾與時推移漢承周秦之弊宜敦簡約之化而何崇飾宫室示侈後嗣此乃武帝千門萬戸所以大興豈無所復増之謂邪

**孙盛批华饰宫室可开后世奢风** 以《周礼》有宫室加工而文饰随时为出发，认为汉承周秦积弊应崇简，华饰失当使后代宫室更奢。

**归年依据** 史家回论汉魏营建，汉武帝千门万户只是概括。

[孙盛批华饰宫室可开后世奢风（时期）](../../years/ce-0201-0300/时期-三国志卷022-桓二陈徐卫卢传纪年待考（2）.md#period-sgz022-p-006-1)。

<a id="pei-006-2"></a>

> 况乃魏氏方有吳蜀之難四海罹塗炭之艱而述蕭何之過議以為令軌豈不惑於大道而昧得失之辨哉使百代之君眩於奢侈之中何之由矣詩云斯言之玷不可為也其斯之謂乎

**孙盛认为曹叡错以萧何故事作营造准则** 吴、蜀仍为对手、民力疲困时，仿萧何所作会使后世混淆奢俭，也引《诗》评其言不可弥补。

**归年依据** 结合陈群235年谏建宫的后世史论，独立评论时间无确年。

[孙盛认为曹叡错以萧何故事作营造准则（时期）](../../years/ce-0201-0300/时期-三国志卷022-桓二陈徐卫卢传纪年待考（2）.md#period-sgz022-p-006-2)。

## 007｜陈群生前密疏直谏，削去底稿

维基文库四库本原行 12—12。附见[正文 L1196](../本地分卷/三国志/三国志-卷022.md#l1196)。

<a id="pei-007-1"></a>

> 魏書曰羣前後數密陳得失每上封事輙削其草時人及其子弟莫能知也論者或譏羣居位拱黙

**陈群生前密疏直谏，削去底稿** 魏书记他反复密上得失，稿子常删，外人及子弟不知，一度有人批评其居位拱默。

**归年依据** 多次封事，无各次年月。

[陈群生前密疏直谏，削去底稿（时期）](../../years/ce-0201-0300/时期-三国志卷022-桓二陈徐卫卢传纪年待考（2）.md#period-sgz022-p-007-1)。

<a id="pei-007-2"></a>

> 正始中詔撰羣臣上書以為名臣奏議朝士乃見羣諫事皆歎息焉

**朝廷正始中辑臣下奏议，陈群谏事为众人所知** 编《名臣奏议》以后，朝士始知他曾多次进谏，皆叹息。

**归年依据** 魏正始240–249，诏没有具体年。

[朝廷正始中辑臣下奏议，陈群谏事为众人所知（时期）](../../years/ce-0201-0300/时期-三国志卷022-桓二陈徐卫卢传纪年待考（2）.md#period-sgz022-p-007-2)。

<a id="pei-007-3"></a>

> 袁子曰或云故少府楊阜豈非忠臣哉見人主之非則勃然怒而觸之與人言未嘗不道也豈非所謂王臣謇謇匪躬之故者歟答曰然可謂直士忠則吾不知也夫仁者愛人施於君謂之忠施於親謂之孝忠孝者其本一也故仁愛之至者君親有過諫而不入求之反覆不得已而言不忍宣也今為人臣見人主失道直詆其非而播揚其惡可謂直士未為忠臣也

**袁准辨杨阜直与忠** 有人说杨阜直斥君非、向人常言，是尽忠；袁子承认直，认为忠孝同根，谏若不得入亦不忍宣亲君之恶。

**归年依据** 史论及政论引例，非杨阜一次特定进谏。

[袁准辨杨阜直与忠（时期）](../../years/ce-0201-0300/时期-三国志卷022-桓二陈徐卫卢传纪年待考（2）.md#period-sgz022-p-007-3)。

<a id="pei-007-4"></a>

> 故司空陳羣則不然其談論終日未嘗言人主之非書數十上而外人不知君子謂羣於是乎長者矣

**袁准评陈群不扬君过而屡谏** 说陈群谈论终日不宣君过，数十次书谏不为外人知，君子以为厚重贤长。

**归年依据** 袁子人物史论，所举进谏有多次。

[袁准评陈群不扬君过而屡谏（时期）](../../years/ce-0201-0300/时期-三国志卷022-桓二陈徐卫卢传纪年待考（2）.md#period-sgz022-p-007-4)。

## 008｜裴松之质疑狄道救援叙次自相冲突

> 臣松之案此傳云謂救兵當須衆集而卒聞已至謂有奇變上下震懼此則救至出於不意若不知救至何故伏兵深險乃經三日乎設伏相伺非不知之謂此皆語之不通也

**裴松之质疑狄道救援叙次自相冲突** 传称姜维毫无准备地闻援至而惊，又说事先设伏三日；裴松之指出若全不知反不应先设伏。

**归年依据** 评论所据正元二年狄道之围，附现成史事说明传文内证问题。

## 009｜干宝记曹髦被杀后司马昭召集朝臣

维基文库四库本原行 12—12。附见[正文 L1203](../本地分卷/三国志/三国志-卷022.md#l1203)。

<a id="pei-009-1"></a>

> 干寶晉紀曰高貴鄉公之殺司馬文王㑹朝臣謀其故太常陳泰不至使其舅荀顗召之顗至告以可否泰曰世之論者以泰方於舅今舅不如泰也子弟内外咸共逼之垂涕而入

**干宝记曹髦被杀后司马昭召集朝臣** 司马昭集众议事，陈泰不至，命荀顗劝召。陈泰说自己一直被与舅父相提并论，如今舅不如己；亲人催他方泣而入。

**归年依据** 景元元年五月曹髦被杀；《通鉴》卷077用其主要叙事。《晋纪》称陈泰太常，裴松之另驳。

[260年第3条](../../years/ce-0201-0300/ce-0260.md#sgz022-p-009-1)。

<a id="pei-009-2"></a>

> 王待之曲室謂曰玄伯卿何以處我對曰誅賈充以謝天下文王曰為吾更思其次泰曰泰言惟有進於此不知其次文王乃不更言

**陈泰建议司马昭诛贾充以谢天下** 司马昭私问陈泰如何应对，陈泰主张杀贾充；司马昭要其次，陈泰说只能加重而无其次。

**归年依据** 同为景元元年曹髦死后的朝议。

[260年第3条](../../years/ce-0201-0300/ce-0260.md#sgz022-p-009-2)。

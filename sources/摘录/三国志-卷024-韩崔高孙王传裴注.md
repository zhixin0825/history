## 001｜《楚国先贤传》记韩暨先世

> 楚國先賢傳曰暨韓王信之後祖術河東太守父純南郡太守

## 004｜司徒韩曁薨

Kanripo四库本 2a—2b原行 40—47。附见[正文 L1279](../本地分卷/三国志/三国志-卷024.md#l1279)。

<a id="pei-004-1"></a>

> 楚國先賢傳曰暨臨終遺書曰夫俗奢者示之以儉儉則節之以禮歴見前代送終過制失之甚矣若爾曹敬聽吾言斂以時服葬以土藏穿畢便葬送以瓦器慎勿有增益

**司徒韩曁薨** 韩暨遗命从俭：时服收殓、土藏瓦器，不增其制。

**归年依据** 《楚国先贤传》所述临终之言，同韩暨238年薨。

[238年第4条](../../years/ce-0201-0300/ce-0238.md#sgz024-p-004-1)。

<a id="pei-004-2"></a>

> 又上疏曰生有益於民死猶不害於民况臣備位台司在職日淺未能宣揚聖徳以廣益黎庶寢疾彌留奄即幽冥方今百姓農務不宜勞役乞不令洛陽吏民供設喪具懼國典有常使臣私願不得展從謹冐以聞惟䝉哀許

**司徒韩曁薨** 奏称秋农劳务，不使洛阳吏民供设丧具，请皇帝成全。

**归年依据** 临病遗疏，承238年任司徒及卒。

[238年第4条](../../years/ce-0201-0300/ce-0238.md#sgz024-p-004-2)。

<a id="pei-004-3"></a>

> 帝得表嗟歎乃詔曰故司徒韓暨積徳履行忠以立朝至於黃髪直亮不虧既登三事望獲毗輔之助如何奄忽天命不永曾參臨没易簀以禮晏嬰尚儉遣車降制今司徒知命遺言䘏民必欲崇約可謂善始令終者也其喪禮所設皆如故事勿有所闕特賜溫明祕器衣一稱五時朝服玉具劍佩

**司徒韩曁薨** 曹叡叹韩暨年高德厚，比曾参易箦、晏婴尚俭，以不减法典丧礼并赐秘器等。

**归年依据** 同次丧诏。

[238年第4条](../../years/ce-0201-0300/ce-0238.md#sgz024-p-004-3)。

## 005｜《楚国先贤传》记韩邦历任被杀

Kanripo四库本 2b—3a原行 48—53。附见[正文 L1279](../本地分卷/三国志/三国志-卷024.md#l1279)。

<a id="pei-005-1"></a>

> 楚國先賢傳曰邦字長林少有才學晉武帝時為野王令有稱績為新城太守坐舉野王故吏為新城計吏武帝大怒遂殺邦

**《楚国先贤传》记韩邦历任被杀** 韩邦字长林，少有才，晋武帝时由野王令至新城太守，因举旧吏为计吏被诛。

**归年依据** 武帝在位间，未知确年。

[《楚国先贤传》记韩邦历任被杀（时期）](../../years/ce-0201-0300/时期-三国志卷024-韩崔高孙王传纪年待考（2）.md#period-sgz024-p-005-1)。

> 暨次子繇高陽太守繇子洪侍御史洪子夀字徳貞

**韩繇、韩洪、韩寿的世系** 韩暨次子繇任高阳太守，繇子洪任侍御史，洪子寿字德贞。

**归年依据** 家世无年。

[韩繇、韩洪、韩寿的世系（时期）](../../years/ce-0201-0300/时期-三国志卷024-韩崔高孙王传纪年待考（2）.md#period-sgz024-p-005-2)。

**《晋诸公赞》评韩寿家风** 韩家世守素业，韩寿性忠厚，早历清职。

**归年依据** 家世与仕历无年。

[《晋诸公赞》评韩寿家风（时期）](../../years/ce-0201-0300/时期-三国志卷024-韩崔高孙王传纪年待考（2）.md#period-sgz024-p-005-3)。

<a id="pei-005-4"></a>

> 惠帝踐阼為散騎常侍

**晋惠帝即位任韩寿为散骑常侍** 惠帝即位，韩寿任近侍。

**归年依据** 《晋书·惠帝纪》太熙元年即位；不能兼定后续升迁。

[290年第2条](../../years/ce-0201-0300/ce-0290.md#sgz024-p-005-4)。

<a id="pei-005-5"></a>

> 遷守河南尹病卒贈驃騎將軍

**韩寿任河南尹，身后赠骠骑将军** 迁河南尹，病卒追赠。

**归年依据** 《晋书》本传也未署卒年，待考。

[韩寿任河南尹，身后赠骠骑将军（时期）](../../years/ce-0201-0300/时期-三国志卷024-韩崔高孙王传纪年待考（2）.md#period-sgz024-p-005-5)。

<a id="pei-005-6"></a>

> 夀妻賈充女充無後以夀子謐為嗣弱冠為祕書監侍中性驕佚而才出衆少子蔚亦有器望

**贾充以韩寿子为后** 韩寿妻为贾充女，其子贾谧为贾充继嗣，年少有才而骄，官至秘书监侍中；弟蔚也有才望。

**归年依据** 世系、继嗣与历职并叙，无单一年。

[贾充以韩寿子为后（时期）](../../years/ce-0201-0300/时期-三国志卷024-韩崔高孙王传纪年待考（2）.md#period-sgz024-p-005-6)。

<a id="pei-005-7"></a>

> 並為趙王倫所誅韓氏遂滅

**赵王伦诛贾谧** 贾谧、韩蔚被诛，韩家此系绝。

**归年依据** 《晋书·惠帝纪》永康元年四月诛贾谧，同事。

[300年第2条](../../years/ce-0201-0300/ce-0300.md#sgz024-p-005-7)。

## 006｜《王氏谱》记王雄宗族

Kanripo四库本 3b—4a原行 66—75。附见[正文 L1282](../本地分卷/三国志/三国志-卷024.md#l1282)。

**归年依据** 谱系无年。

[《王氏谱》记王雄宗族（时期）](../../years/ce-0201-0300/时期-三国志卷024-韩崔高孙王传纪年待考（2）.md#period-sgz024-p-006-1)。

<a id="pei-006-2"></a>

> 魏名臣表載安定太守孟達薦䧺曰臣聞明君以求賢為業忠臣以進善為效故易稱拔茅連茹傳曰舉爾所知臣不自量竊慕其義臣昔以人乏謬充備部職時涿郡太守王雄為西部從事與臣同僚雄天性良固果而有謀歴試三縣政成人和及在近職奉宣威恩懷柔有術清慎持法臣往年出使經過雄郡自說特受陛下拔擢之恩常勵節精心思投命為効言辭激揚情趣欵惻臣雖愚闇不識真偽以謂雄才兼資文武忠烈之性踰越倫輩今涿郡領戸三千孤寡之家參居其半北有守兵藩衛之固誠不足舒雄智力展其勤幹也臣受恩深厚無以報國不勝慺慺淺見之情謹冐陳聞

**孟达奏荐涿郡太守王雄** 称曾与王雄同僚，见三县政成，现怀柔慎法、忠烈兼资，宜改擢；涿郡户少不足用其长。

**归年依据** 涿守王雄、安定守孟达同在曹魏初，表无纪年。

[孟达奏荐涿郡太守王雄（时期）](../../years/ce-0201-0300/时期-三国志卷024-韩崔高孙王传纪年待考（2）.md#period-sgz024-p-006-2)。

<a id="pei-006-3"></a>

> 詔曰昔蕭何薦韓信鄧禹進吳漢惟賢知賢也雄有膽智技能文武之姿吾宿知之今便以參散騎之選方使少在吾門下知指歸便大用之矣天下之士欲使皆先歴散騎然後出據州郡是吾本意也

**魏廷敕王雄预备散骑之选** 诏举萧何荐韩信、邓禹荐吴汉，自言早识王雄胆智，欲近侍后出典州郡。

**归年依据** 答同一表，不专系明确年。

[魏廷敕王雄预备散骑之选（时期）](../../years/ce-0201-0300/时期-三国志卷024-韩崔高孙王传纪年待考（2）.md#period-sgz024-p-006-3)。

<a id="pei-006-4"></a>

> 雄後為幽州刺史

**王雄后任幽州刺史** 从涿郡等职转主幽州。

**归年依据** 《通鉴》235年已有王雄遣韩龙，但不据此断上任年。

[王雄后任幽州刺史（时期）](../../years/ce-0201-0300/时期-三国志卷024-韩崔高孙王传纪年待考（2）.md#period-sgz024-p-006-4)。

**《王氏谱》列王雄子孙官职** 子浑、乂分任凉州刺史、平北将军。孙王戎、王衍、王澄官显，属于两房。

## 007｜辛毗说崔林因非尚书才出守河间

Kanripo四库本 4a—4b原行 76—78。附见[正文 L1282](../本地分卷/三国志/三国志-卷024.md#l1282)。

<a id="pei-007-1"></a>

> 魏名臣奏載侍中辛毗奏曰昔桓階為尚書令以崔林非尚書才遷以為河間太守與此傳不同

**辛毗说崔林因非尚书才出守河间** 本传称崔林不敬吴质左迁，辛毗另称尚书令桓阶认为崔林不宜尚书，故迁河间守。

**归年依据** 原因与本传不同，均无任日。

## 009｜裴松之援孟子论孔子

Kanripo四库本 6b—7a原行 117—124。附见[正文 L1286](../本地分卷/三国志/三国志-卷024.md#l1286)。

<a id="pei-009-1"></a>

> 臣松之以為孟軻稱宰我之辭曰以予觀夫子賢於堯舜遠矣又曰生民以來未有盛於孔子者也斯非通賢之格言商較之定凖乎雖妙極則同萬聖猶一然淳薄異時質文殊用或當時則榮没則已焉是以遺風所被實有深淺

**裴松之援孟子论孔子** 引宰我褒孔子上于尧舜，讨论圣人同理而淳薄、文质不同，教泽深浅有别。

<a id="pei-010-1"></a>

[《晋诸公赞》记崔随为晋尚书仆射（时期）](../../years/ce-0201-0300/时期-三国志卷024-韩崔高孙王传纪年待考（2）.md#period-sgz024-p-010-1)。

<a id="pei-010-2"></a>

> 趙王倫簒位隨與其事倫敗隨亦廢錮而卒

**赵王伦篡位** 崔随参与赵王伦篡位，伦败后也被废锢而终。

**归年依据** 《晋书·惠帝纪》永宁元年篡位及败；崔随卒年未知。

[301年第6条](../../years/ce-0301-0400/ce-0301.md#sgz024-p-010-2)。

<a id="pei-014-2"></a>

**司马懿攻克襄平** 仁威足使远人服，无须质亲；若仍用质任，质者可以并坐，否则伤政。

**司马懿攻克襄平** 孙盛说听质子预告便尽宥会鼓励背亲、自存，定高柔所论为小善。

**司马懿攻克襄平** 裴松之认为质任是三分形势下羁防之举，先告有善与质制是否废除各属一事。

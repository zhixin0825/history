## 001｜尚攻之急，谭遣辛毗乞降请救

Kanripo四库本 1a—1b原行 21—26。附见[正文 L1318](../本地分卷/三国志/三国志-卷025.md#l1318)。

<a id="pei-001-1"></a>

> 英雄記曰譚尚戰於外門譚軍敗奔北郭圖說譚曰今將軍國小兵少糧匱勢弱顯甫之來久則不敵愚以為可呼曹公來擊顯甫

**尚攻之急，谭遣辛毗乞降请救** 袁谭败于外门。郭图说粮少难敌，召曹操攻邺可解围并占河北诸地。

**归年依据** 《英雄记》展开《武帝纪》203年袁氏兄弟内战。

[203年第10条](../../years/ce-0201-0300/ce-0203.md#sgz025-p-001-1)。

<a id="pei-001-2"></a>

> 曹公至必先攻鄴顯甫還救將軍引兵而西自鄴以北皆可虜得若顯甫軍破其兵奔亡又可斂取以拒曹公曹公遠僑而來糧餉不繼必自逃去比此之際趙國以北皆我之有亦足與曹公為對矣不然不諧

**尚攻之急，谭遣辛毗乞降请救** 郭图预计二袁可趁曹军远征得地聚兵，曹操军粮不继会退，便能与曹操对抗。

**归年依据** 同次说袁谭。

[203年第10条](../../years/ce-0201-0300/ce-0203.md#sgz025-p-001-2)。

<a id="pei-001-3"></a>

> 譚始不納後遂從之問圖誰可使圖荅辛佐治可譚遂遣毗詣太祖

**尚攻之急，谭遣辛毗乞降请救** 袁谭始不答应，后从策，按郭图所荐派辛毗求和。

**归年依据** 同次出使。

[203年第10条](../../years/ce-0201-0300/ce-0203.md#sgz025-p-001-3)。

## 002｜诸葛亮寇天水，诏大将军司马宣王拒之

Kanripo四库本 6a原行 104—111。附见[正文 L1324](../本地分卷/三国志/三国志-卷025.md#l1324)。

<a id="pei-002-1"></a>

> 魏畧曰諸葛亮圍祁山不克引退張郃追之為流矢所中死

**诸葛亮寇天水，诏大将军司马宣王拒之** 《魏略》说诸葛亮围祁山不克而还，张郃追击，中流矢身亡。

**归年依据** 《张郃传》《明帝纪》太和五年；《魏略》“追之”与其他相关叙事并见。

[231年第3条](../../years/ce-0201-0300/ce-0231.md#sgz025-p-002-1)。

<a id="pei-002-2"></a>

> 帝惜郃臨朝而歎曰蜀未平而郃死將若之何司空陳羣曰郃誠良將國所依也毗心以為郃雖可惜然已死不當内弱主意而示外以不大也

**魏廷议张郃战死** 曹叡哀惜张郃，陈群附议不可失将，辛毗不愿内弱君心。

**归年依据** 依张郃卒后当廷问答，系231；裴氏质疑经记。

[231年第31条](../../years/ce-0201-0300/ce-0231.md#sgz025-p-002-2)。

<a id="pei-002-3"></a>

> 乃持羣曰陳公是何言歟當建安之末天下不可一日無武皇帝也及委國祚而文皇帝受命黃初之世亦謂不可無文皇帝也及委棄天下而陛下龍興今國内所少豈張郃乎陳羣曰亦誠如辛毗言帝笑曰陳公可謂善變矣

**魏廷议张郃战死** 辛毗以曹操、曹丕与曹叡继世为国家有主之证，说不应以失一将为不可；陈群转而赞同，帝以善变相戏。

**归年依据** 同一问答，属于注文所载说法。

[231年第31条](../../years/ce-0201-0300/ce-0231.md#sgz025-p-002-3)。

<a id="pei-002-4"></a>

> 臣松之以為擬人必於其倫取譬宜引其類故君子於其言無所茍而已矣毗欲弘廣主意當舉若張遼之疇安有於一將之死而可以祖宗為譬哉非所宜言莫過於兹進違其類退似諂佞佐治剛正之體不宜有此魏畧既已難信習氏又從而載之竊謂斯人受誣不少

**魏廷议张郃战死** 裴松之认为用曹氏祖宗比一将不伦，若为宽君心当引张辽等才合适，疑《魏略》及习氏记载不实。

**归年依据** 后出按语随其所评的231年事。

[231年第31条](../../years/ce-0201-0300/ce-0231.md#sgz025-p-002-4)。

## 003｜诸葛亮出斜谷，与司马懿相持

Kanripo四库本 6b原行 115—115。附见[正文 L1325](../本地分卷/三国志/三国志-卷025.md#l1325)。

<a id="pei-003-1"></a>

[234年第11条](../../years/ce-0201-0300/ce-0234.md#sgz025-p-003-1)。

## 004｜《世语》记辛敞与辛宪英家世

Kanripo四库本 6b—7b原行 116—132。附见[正文 L1325](../本地分卷/三国志/三国志-卷025.md#l1325)。

<a id="pei-004-1"></a>

> 世語曰敞字泰雍官至衞尉毗女憲英適太常泰山羊耽外孫夏侯湛為其傳曰憲英聰明有才鑒

**《世语》记辛敞与辛宪英家世** 辛敞字泰雍、终官卫尉。姐姐宪英嫁泰山羊耽，有才鉴，外孙夏侯湛作传。

**归年依据** 家世与敞官终未署年。

[《世语》记辛敞与辛宪英家世（时期）](../../years/ce-0201-0300/时期-三国志卷025-辛毗杨阜高堂隆传纪年待考（2）.md#period-sgz025-p-004-1)。

<a id="pei-004-2"></a>

> 初文帝與陳思王爭為太子既而文帝得立抱毗頸而喜曰辛君知我喜不毗以告憲英憲英歎曰太子代君主宗廟社稷者也代君不可以不戚主國不可以不懼宜戚而喜何以能久魏其不昌乎

**曹丕立为魏太子** 曹丕战胜曹植而成太子，抱辛毗颈喜问，宪英闻之认为承宗庙本当敬忧，恐魏不昌。

**归年依据** 《武帝纪》建安二十二年，《通鉴》卷六十八亦录此事。

[217年第12条](../../years/ce-0201-0300/ce-0217.md#sgz025-p-004-2)。

<a id="pei-004-3"></a>

> 弟敞為大將軍曹爽参軍

**辛敞任曹爽参军** 辛宪英之弟辛敞佐曹爽。

**归年依据** 只知受任于曹爽执政时，任年不明。

[辛敞任曹爽参军（时期）](../../years/ce-0201-0300/时期-三国志卷025-辛毗杨阜高堂隆传纪年待考（2）.md#period-sgz025-p-004-3)。

<a id="pei-004-4"></a>

> 司馬宣王將誅爽因爽出閉城門大將軍司馬魯芝將爽府兵犯門斬關出城門赴爽來呼敞俱去敞懼問憲英曰天子在外太傅閉城門人云將不利國家於亊可得爾乎

**高平陵政变与曹爽被诛** 司马懿起事闭城，鲁芝破关出赴曹爽，呼辛敞同行，辛敞问姊。

**归年依据** 《齐王纪》嘉平元年正月，《晋书·列女传》所录亦同。

[249年第1条](../../years/ce-0201-0300/ce-0249.md#sgz025-p-004-4)。

<a id="pei-004-5"></a>

> 憲英曰天下有不可知然以吾度之太傅不得不爾明皇帝臨崩把太傅臂以後事付之此言猶在朝士之耳且曹爽與太傅俱受寄託之任而獨専權勢行以驕奢於王室不忠於人道不直此舉不過以誅曹爽耳敞曰然則事就乎憲英曰得無殆就爽之才非太傅之偶也

**高平陵政变与曹爽被诛** 宪英判司马懿受明帝临终托付，曹爽独权，这次只为诛曹爽，曹爽难匹敌。

**归年依据** 同日对答；临终托付在239年，是谈话的追叙。

[249年第1条](../../years/ce-0201-0300/ce-0249.md#sgz025-p-004-5)。

<a id="pei-004-6"></a>

> 敞曰然則敞可以無出乎憲英曰安可不出職守人之大義也凡人在難猶或恤之為人執鞭而棄其事不祥不可也且為人死為人任親昵之職也從衆而已敞遂出宣王果誅爽事定之後敞歎曰吾不謀於姊幾不獲於義

**高平陵政变与曹爽被诛** 辛敞问可否不出，宪英说守职为义，随众可；敞出，曹爽果诛，敞感念姊教。

**归年依据** 仍属政变时的处置及近接结果。

[249年第1条](../../years/ce-0201-0300/ce-0249.md#sgz025-p-004-6)。

<a id="pei-004-7"></a>

> 逮鍾㑹為鎮西將軍憲英謂從子羊祜曰鍾士季何故西出祜曰將為滅蜀也憲英曰㑹在事縱恣非持久處下之道吾畏其有他志也祜曰季母勿多言

**辛宪英忧钟会伐蜀别有志** 钟会为镇西将军出师，宪英对羊祜说钟会恣纵不能久居人下，恐有他意。

**归年依据** 《钟会传》景元三年冬任命，四年伐蜀；此对话明确以西出灭蜀为背景，《晋书·列女传》同。

[263年第34条](../../years/ce-0201-0300/ce-0263.md#sgz025-p-004-7)。

<a id="pei-004-8"></a>

> 其後㑹請子琇為參軍憲英憂曰他日見鍾㑹之出吾為國憂之矣今日難至吾家此國之大事必不得止也琇固請司馬文王文王不聽憲英語琇曰行矣戒之古之君子入則致孝於親出則致節於國在職思其所司在義思其所立不遺父母憂患而已軍旅之間可以濟者其惟仁恕乎汝其慎之琇竟以全身

**辛宪英忧钟会伐蜀别有志** 钟会请羊琇任参军，羊琇欲辞，司马昭不允；宪英劝忠孝守义，以仁恕全身，羊琇果全。

**归年依据** 承此役征辟；平蜀后钟会反起于264，结果是后叙。

[263年第34条](../../years/ce-0201-0300/ce-0263.md#sgz025-p-004-8)。

<a id="pei-004-9"></a>

> 憲英年至七十有九泰始五年卒

**辛宪英去世** 年七十九，晋泰始五年卒。

**归年依据** 注文明确年号，据《晋书·列女传》同。

[269年第7条](../../years/ce-0201-0300/ce-0269.md#sgz025-p-004-9)。

## 006｜马超在汉阳，复因羌、胡爲害

Kanripo四库本 10a—11b原行 179—205。附见[正文 L1330](../本地分卷/三国志/三国志-卷025.md#l1330)。

<a id="pei-006-1"></a>

> 皇甫謐烈女傳曰姜敘母者天水姜伯奕之母也建安中馬超攻冀害凉州刺史韋康州人悽然莫不感憤敘為撫夷將軍擁兵屯歴敘姑子楊阜故為康從事同等十餘人皆畧屬超隂相結為康報仇未有間

**马超在汉阳，复因羌、胡爲害** 皇甫谧《列女传》先记冀城陷、韦康死，姜叙屯历，杨阜等旧吏暗约复仇。

**归年依据** 注文仅称建安中，参《通鉴》十八年同案及《考异》。

[213年第18条](../../years/ce-0201-0300/ce-0213.md#sgz025-p-006-1)。

<a id="pei-006-2"></a>

> 㑹阜妻死辭超寧歸西因過至歴候敘母說康被害及冀中之難相對泣良久姜敘舉室感悲敘母曰咄伯奕韋使君遇難豈一州之恥亦汝之負豈獨義山哉汝無顧我事淹變生人誰不死死國忠義之大者但當速發我自為汝當之不以餘年累汝也

**杨阜等举兵逐马超** 杨阜因妻丧访姜叙母，叙说韦康被害，姜母自任遇害风险，催姜叙发兵。

**归年依据** 《通鉴》十八年同姜母敦促部署。

[213年第39条](../../years/ce-0201-0300/ce-0213.md#sgz025-p-006-2)。

<a id="pei-006-3"></a>

> 因勅敘與阜參議許諾分人傳語鄉里尹奉趙昂及安定梁寛等令敘先舉兵叛超超怒必自來擊敘寛等因從後閉門約誓已定敘遂進兵入鹵昂奉守祁山超聞果自出擊敘寛等從後閉冀門

**杨阜等举兵逐马超** 与尹奉、赵昂、梁宽约谋，姜叙先入卤城引马超出，赵昂等守祁山，梁宽闭冀门。

**归年依据** 同次举兵。正文记十七年，《考异》定十八年。

[213年第39条](../../years/ce-0201-0300/ce-0213.md#sgz025-p-006-3)。

<a id="pei-006-4"></a>

> 超失據過鹵叙守鹵超因進至歴歴中見超往以為敘軍還又傳聞超已走奔漢中故歴無備及超入歴執敘母母怒罵超超被罵大怒即殺敘母及其子燒城而去

**杨阜等举兵逐马超** 马超绕卤城入历城，守军误以为己方；马超杀骂他的姜叙母及其子，烧城而去。

**归年依据** 同次举兵。

[213年第39条](../../years/ce-0201-0300/ce-0213.md#sgz025-p-006-4)。

<a id="pei-006-5"></a>

> 阜等以狀聞太祖甚嘉之手令褒揚語如本傳

**曹操赏逐马超将士，杨阜辞功** 曹操听闻战况，下手令嘉奖姜母等。

**归年依据** 接建安十八年平定与封赏，承本传。

[213年第40条](../../years/ce-0201-0300/ce-0213.md#sgz025-p-006-5)。

<a id="pei-006-6"></a>

> 臣松之案謐稱阜為敘姑子而本傳云敘為阜外兄與今名内外為不同

**裴松之质疑杨阜与姜叙亲属称谓** 《列女传》说杨阜为姜叙姑之子，与正文姜叙是杨阜外兄不一致。

**归年依据** 人伦称谓异说无事年。

[裴松之质疑杨阜与姜叙亲属称谓（时期）](../../years/ce-0201-0300/时期-三国志卷025-辛毗杨阜高堂隆传纪年待考（2）.md#period-sgz025-p-006-6)。

<a id="pei-006-7"></a>

> 謐又載趙昂妻曰趙昂妻異者故益州刺史天水趙偉璋妻王氏女也

**《列女传》记赵昂妻王异籍贯** 王异是天水赵昂之妻，赵昂后为益州刺史。

**归年依据** 家世无确年。

[《列女传》记赵昂妻王异籍贯（时期）](../../years/ce-0201-0300/时期-三国志卷025-辛毗杨阜高堂隆传纪年待考（2）.md#period-sgz025-p-006-7)。

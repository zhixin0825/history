## 001｜裴松之批评满宠拷治杨彪

Kanripo四库本 2a原行 34—35。附见[正文 L1373](../本地分卷/三国志/三国志-卷026.md#l1373)。

<a id="pei-001-1"></a>

> 臣松之以為楊公積徳之門身為名臣縱有愆負猶宜保祐况淫刑所濫而可加其楚掠乎若理應考訊荀孔二賢豈其妄有相請屬哉寵以此為能酷吏之用心耳雖有後善何解前虐

**裴松之批评满宠拷治杨彪** 裴松之说即使名臣杨彪有过也应保全，指满宠加刑是酷吏用心，后来劝赦不能消解前虐。

**归年依据** 所评案在197年，刘宋裴氏作按确年不见。

## 002｜曹叡察满宠尚强健，命其还镇

Kanripo四库本 4b—5a原行 83—87。附见[正文 L1376](../本地分卷/三国志/三国志-卷026.md#l1376)。

<a id="pei-002-1"></a>

> 世語曰王凌表寵年過耽酒不可居方任帝將召寵給事中郭謀曰寵為汝南太守豫州刺史二十餘年有勲方岳及鎮淮南吳人憚之若不如所表將為所闚可令還朝問以方事以察之帝從之寵既至進見飲酒至一石不亂帝慰勞之遣還

**曹叡察满宠尚强健，命其还镇** 《世语》作王凌上表说满宠年老贪酒。郭谋建议返朝问边事检验，满宠进见能饮不乱，曹叡慰劳遣还。

**归年依据** 附太和五年召满宠与前后孙布诈降；细节与本传存异。

[231年第28条](../../years/ce-0201-0300/ce-0231.md#sgz026-p-002-1)。

## 003｜满伟字公衡，子满长武入大将军府

Kanripo四库本 7a原行 123—128。附见[正文 L1378](../本地分卷/三国志/三国志-卷026.md#l1378)。

<a id="pei-003-1"></a>

> 世語曰偉字公衡偉子長武有寵風年二十四為大將軍掾

**满伟字公衡，子满长武入大将军府** 满长武继满宠风采，二十四岁任大将军掾。

**归年依据** 这是260年高贵乡公遇害前的履历，确年无载。

[满伟字公衡，子满长武入大将军府（时期）](../../years/ce-0201-0300/时期-三国志卷026-满田牵郭传纪年待考（1）.md#period-sgz026-p-003-1)。

<a id="pei-003-2"></a>

> 高貴鄉公之難以掾守閶闔掖門司馬文王弟安陽亭侯幹欲入幹妃偉妹也長武謂幹曰此門近公且來無有入者可從東掖門幹遂從之文王問幹入何遲幹言其故參軍王羡亦不得入恨之既而羡因王左右咨王滿掾斷門不内人宜推劾

**曹髦遇害时满长武守阊阖掖门** 满长武以司马昭将至为由请司马干改走东掖门，司马昭闻其故；王羡也未得入而怨恨，建议追究。

**归年依据** 《高贵乡公纪》甘露五年五月曹髦遇害，本注所涉为同日门禁，追责另附后段。

[260年第34条](../../years/ce-0201-0300/ce-0260.md#sgz026-p-003-2)。

<a id="pei-003-3"></a>

> 夀春之役偉從文王至許以疾不進子從求還省疾事定乃從歸

**寿春之役满伟至许停进，长武请归探父** 《世语》后叙寿春战时满伟因病停在许，长武请求回探，事定后归。

**归年依据** 以诸葛诞起事的甘露二年至三年为限，随出兵主条257，事定可到258年。注文后叙是追溯旧事。

[257年第9条](../../years/ce-0201-0300/ce-0257.md#sgz026-p-003-3)。

<a id="pei-003-4"></a>

> 由此内見恨収長武考死杖下偉免為庶人時人寃之

**满长武被拷死，满伟免为庶人** 满长武获罪被收，死于杖下，满伟被免官爵，时人以其冤。

**归年依据** 叙因寿春事及后来禁门招怨，执行没有另载年月，不能反倒在曹髦死前。

[满长武被拷死，满伟免为庶人（时期）](../../years/ce-0201-0300/时期-三国志卷026-满田牵郭传纪年待考（1）.md#period-sgz026-p-003-4)。

<a id="pei-003-5"></a>

> 偉弟子奮晉元康中至尚書令司隸校尉寵偉長武奮皆長八尺荀綽冀州記曰奮性清平有識檢晉諸公贊曰奮體量通雅有寵風也

**满奋在元康任尚书令、司隶校尉** 注文称满宠、满伟、满长武、满奋身长皆八尺，并引两书赞满奋性清、雅量。

**归年依据** 元康跨291至299年，任尚书令及司隶校尉未单载确年；汇列身形及史评无年。

[满奋在元康任尚书令、司隶校尉（时期）](../../years/ce-0201-0300/时期-三国志卷026-满田牵郭传纪年待考（1）.md#period-sgz026-p-003-5)。

## 005｜田豫退居魏县，厚待汝南健步

Kanripo四库本 11b原行 205—209。附见[正文 L1387](../本地分卷/三国志/三国志-卷026.md#l1387)。

<a id="pei-005-1"></a>

> 魏畧曰豫罷官歸居魏縣㑹汝南遣健歩詣征北感豫宿恩過拜之豫為殺雞炊黍送詣至陌頭謂之曰罷老苦汝來遇無能有益若何健歩愍其貧羸流涕而去還為故吏民說之汝南為具資數千匹遣人餉豫豫一不受

**田豫退居魏县，厚待汝南健步** 吏卒过访报宿恩，田豫杀鸡炊黍并送至路头，健步为其清贫落泪。汝南民众备财相送，田豫尽不受。

**归年依据** 魏略记罢官后至卒前无年。

[田豫退居魏县，厚待汝南健步（时期）](../../years/ce-0201-0300/时期-三国志卷026-满田牵郭传纪年待考（1）.md#period-sgz026-p-005-1)。

<a id="pei-005-2"></a>

> 㑹病亡戒其妻子曰葬我必於西門豹邊妻子難之言西門豹古之神人那可葬於其邊乎豫言豹所履行與我敵等耳使死而有靈必與我善妻子從之汝南聞其死也悲之既為畫像又就為立碑銘

**田豫遗命葬西门豹墓旁，汝南立碑像** 田豫认为自己做官与西门豹相若。妻子从命，汝南人闻卒，绘像立碑纪念。

**归年依据** 本传仅记享年八十二，无确年，不假托墓期。

## 006｜素利等私赠牲畜和金，田豫交官

Kanripo四库本 12a原行 212—215。附见[正文 L1388](../本地分卷/三国志/三国志-卷026.md#l1388)。

<a id="pei-006-1"></a>

> 魏畧曰鮮卑素利等數來客見多以牛馬遺豫豫轉送官胡以為前所與豫物顯露不如持金乃密懷金三十斤謂豫曰願避左右我欲有所道豫從之胡因跪曰我見公貧故前後遺公牛馬公輒送官今密以此上公可以為家資豫張袖受之答其厚意胡去之後皆悉付外具以狀聞

**素利等私赠牲畜和金，田豫交官** 鲜卑客以为送牛马太显，私送三十斤金；田豫以袖收下，客走后全部付官，奏告朝廷。

**归年依据** 素利仍在至太和二年卒前，赠献过程多次，无确年。

[素利等私赠牲畜和金，田豫交官（时期）](../../years/ce-0201-0300/时期-三国志卷026-满田牵郭传纪年待考（1）.md#period-sgz026-p-006-1)。

<a id="pei-006-2"></a>

> 於是詔褒之曰昔魏絳開懷以納戎今卿舉袖以受狄金朕甚嘉焉乃即賜絹五百匹豫得賜分以其半藏小府後胡復來以半與之

**魏帝赐田豫绢五百匹，田豫转赠** 皇帝以魏绛相拟，表扬田豫廉洁，给绢五百，田豫留半在小府，后来给再访胡人。

**归年依据** 从前述献金的处理，帝年未载，也不同于254年赐家钱谷。

[魏帝赐田豫绢五百匹，田豫转赠（时期）](../../years/ce-0201-0300/时期-三国志卷026-满田牵郭传纪年待考（1）.md#period-sgz026-p-006-2)。

## 009｜王凌案牵及郭淮妻，部众请留

Kanripo四库本 20b—21a原行 371—376。附见[正文 L1404](../本地分卷/三国志/三国志-卷026.md#l1404)。

<a id="pei-009-1"></a>

**王凌案牵及郭淮妻，部众请留** 郭淮妻是王凌之妹，依法当连坐，御史来捕；郭淮起先不答将吏和羌胡数千人恳请留妻。

**归年依据** 《齐王纪》嘉平三年王凌案；《世语》补郭淮一家。

**郭淮追回妻子并致书司马懿，获宽免** 郭淮见部众和五子哀求后派数千骑追回，称若无母则无五子也无郭淮，愿自请罪；司马懿宽许。

**归年依据** 同一嘉平三年王凌案，司马懿该年七月去世，为行动上限。

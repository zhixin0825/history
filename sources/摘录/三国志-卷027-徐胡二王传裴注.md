## 004｜武周字号、历光禄大夫及三子

Kanripo四库本 4b—5a原行 82—90。附见[正文 L1414](../本地分卷/三国志/三国志-卷027.md#l1414)。

<a id="pei-004-1"></a>

> 虞預晉書曰周字伯南沛國竹邑人位至光祿大夫子陔字元夏陔及二弟韶茂皆總角見稱並有器望雖鄉人諸父未能覺其多少

**武周字号、历光禄大夫及三子** 虞预说武周字伯南、沛国竹邑人，官光禄大夫。武陔字元夏，与两弟少年已获好评。

**归年依据** 履历、世系无独立史年。

[武周字号、历光禄大夫及三子（时期）](../../years/ce-0201-0300/时期-三国志卷027-徐胡二王传纪年待考（2）.md#period-sgz027-p-004-1)。

<a id="pei-004-2"></a>

> 時同郡劉公榮名知人嘗造周周謂曰卿有知人之眀欲使三兒見卿卿為目髙下以效郭許之聽可乎公榮乃自詣陔兄弟與共言語觀其舉動出語周曰君三子皆國士也元夏器量最優有輔佐之風展力仕宦可為亞公叔夏季夏不減常伯納言也

**刘公荣品评武周三子** 刘公荣看三兄弟举止，认为都可为国士，武陔尤有辅佐大臣器量，两弟也能担任要职。

**归年依据** 拜访与辨才的年月未载。

[刘公荣品评武周三子（时期）](../../years/ce-0201-0300/时期-三国志卷027-徐胡二王传纪年待考（2）.md#period-sgz027-p-004-2)。

<a id="pei-004-3"></a>

> 陔少出仕宦歴職内外泰始初為吏部尚書遷左僕射右光祿大夫開府儀同三司卒於官陔以在魏已為大臣本非佐命之數懐遜讓不得已而居位故在官職無所荷任夙夜思恭而已終始全潔當世以為美談

**武陔泰始初任吏部尚书等职** 武陔自魏历任内外职，晋初至吏部尚书、左仆射、右光禄大夫、开府，卒官；自知非晋佐命，持谦恭保全。

**归年依据** 泰始初限定早年授职的阶段，诸任和卒年缺见。

[武陔泰始初任吏部尚书等职（时期）](../../years/ce-0201-0300/时期-三国志卷027-徐胡二王传纪年待考（2）.md#period-sgz027-p-004-3)。

<a id="pei-004-4"></a>

> 韶歴二官吏部郎山濤啓事稱韶清白有誠終於散騎常侍茂至侍中尚書潁川荀愷宣帝外孫世祖姑子自負貴戚要與茂交茂拒而不答由是見怒

**武韶清白，武茂不与荀恺结交** 武韶历二官，官散骑常侍。武茂至侍中尚书，荀恺凭亲贵要求结交，武茂拒绝而被怨。

**归年依据** 这一段为西晋中前期，生平段不算291年案内新事。

[武韶清白，武茂不与荀恺结交（时期）](../../years/ce-0201-0300/时期-三国志卷027-徐胡二王传纪年待考（2）.md#period-sgz027-p-004-4)。

<a id="pei-004-5"></a>

> 元康元年楊駿被誅愷時為尚書僕射以茂駿之姨弟陷為駿黨遂枉見殺衆咸寃痛之

**武茂被指为杨骏党而遇害** 荀恺借武茂是杨骏姨弟将他列为党羽，武茂被杀，众以为冤。

**归年依据** 虞预《晋书》明元康元年，与《晋书·惠帝纪》杨骏案同年同案。

## 005｜胡威徒步驴行赴荆州探父

Kanripo四库本 6a—6b原行 107—115。附见[正文 L1417](../本地分卷/三国志/三国志-卷027.md#l1417)。

<a id="pei-005-1"></a>

> 晉陽秋曰威字伯虎少有志尚厲操清白質之為荆州也威自京都省之家貧無車馬僮僕威自驅驢單行拜見父停廐中十餘日告歸臨辭質賜其絹一匹為道路糧威跪曰大人清白不審於何得此絹質曰是吾俸祿之餘故以為汝糧耳威受之辭歸每至客舎自放驢取樵炊㸑食畢復随旅進道往還如是

**胡威徒步驴行赴荆州探父** 胡威家贫，无车马僮仆，自驱驴赴荆州，见父后停十余日，受父所赐俸禄余绢一匹作路费。

**归年依据** 胡质在荆州刺史任内，确年不见。

[胡威徒步驴行赴荆州探父（时期）](../../years/ce-0201-0300/时期-三国志卷027-徐胡二王传纪年待考（2）.md#period-sgz027-p-005-1)。

<a id="pei-005-2"></a>

> 質帳下都督素不相識先其将歸請假還家隂資装百餘里要之因與為伴每事佐助經營之又少進飲食行數百里威疑之宻誘問乃知其都督也因取向所賜絹答謝而遣之後因他信具以白質質杖其都督一百除吏名其父子清慎如此

**胡威拒父亲都督私助，胡质处分之** 都督假请假追上并供食装，胡威查实以绢酬谢而令其离开，后告胡质，胡质杖罚并除其吏名。

**归年依据** 同一次回程，无具体日。

[胡威拒父亲都督私助，胡质处分之（时期）](../../years/ce-0201-0300/时期-三国志卷027-徐胡二王传纪年待考（2）.md#period-sgz027-p-005-2)。

<a id="pei-005-3"></a>

> 於是名譽著聞歴位宰牧晉武帝賜見論邊事語及平生帝歎其父清謂威曰卿清孰與父清威對曰臣不如也帝曰以何為不如對曰臣父清恐人知臣清恐人不知是臣不如者逺也

**胡威历官，答晋武帝问父子孰清** 武帝称胡质清节；胡威说父亲清廉怕人知，自己清廉怕人不知，自认远不及父。

**归年依据** 武帝在位期间，进见具体年不详。

[胡威历官，答晋武帝问父子孰清（时期）](../../years/ce-0201-0300/时期-三国志卷027-徐胡二王传纪年待考（2）.md#period-sgz027-p-005-3)。

<a id="pei-005-4"></a>

> 官至前将軍青州刺史太康元年卒追贈鎮東将軍

**胡威太康元年卒，死所异文** 胡威官前将军、青州刺史，太康元年卒，赠镇东将军。

**归年依据** 《晋书·胡威传》及《资治通鉴》卷八十一同系280年；本传作在安定卒，保留死所差异。

[280年第10条](../../years/ce-0201-0300/ce-0280.md#sgz027-p-005-4)。

<a id="pei-005-5"></a>

> 威弟熊字季象征南将軍威子奕字次孫平東将軍並以潔行垂名

**胡熊与胡奕官职、清名** 胡威之弟胡熊任征南将军，胡威子胡奕任平东将军，均以清行名世。

**归年依据** 家世、任官无确年。

[胡熊与胡奕官职、清名（时期）](../../years/ce-0201-0300/时期-三国志卷027-徐胡二王传纪年待考（2）.md#period-sgz027-p-005-5)。

<a id="pei-009-1"></a>

> 臣松之以為援之此誡可謂切至之言不刋之訓也凡道人過失盖謂居室之愆人未之知則由已而發者也若乃行事得失已暴於世因其善惡即以為誡方之於彼則有愈焉然援誡稱龍伯髙之美言杜季良之惡致使事徹時主季良以敗言之傷人孰大於此與其所誡自相違伐

## 013｜任嘏出于博昌著姓，早称聪慧

Kanripo四库本 11a—12a原行 199—212。附见[正文 L1423](../本地分卷/三国志/三国志-卷027.md#l1423)。

<a id="pei-013-1"></a>

> 昭先名嘏别傳曰嘏樂安博昌人世為著姓夙智早成故鄉人為之語曰蔣氏翁任氏童

**任嘏出于博昌著姓，早称聪慧** 任嘏字昭先，郡人为蒋氏之翁、任氏之童作俗语。

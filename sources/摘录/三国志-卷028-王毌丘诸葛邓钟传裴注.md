## 001｜王凌早年因案受髡又被曹操用

维基文库四库本原行 12—12。附见[正文 L1442](../本地分卷/三国志/三国志-卷028.md#l1442)。

<a id="pei-001-1"></a>

> 魏畧曰凌為長遇事髠刑五嵗當道掃除時太祖車過問此何徒左右以狀對太祖曰此子師兄子也所坐亦公耳於是主者選為驍騎主簿

**王凌早年因案受髡又被曹操用** 守县时坐事，髡五年，曾扫道被曹操看见。曹操以王子师侄、所坐为公，使主者选授骁骑主簿。

**归年依据** 太祖尚在，早年事无确年。

## 002｜王广反对拥曹彪，论曹爽失众和司马懿得人

维基文库四库本原行 12—12。附见[正文 L1445](../本地分卷/三国志/三国志-卷028.md#l1445)。

<a id="pei-002-1"></a>

> 漢晉春秋曰凌愚謀以帝㓜制於彊臣不堪為主楚王彪長而才欲迎立之以興曹氏凌使人告廣廣曰凡舉大事應本人情今曹爽以驕奢失民何平叔虛而不治丁畢桓鄧雖並有宿望皆専競於世加變易朝典政令數改所存雖髙而事不下接民習於舊衆莫之從故雖勢傾四海聲震天下同日斬戮名士減半而百姓安之莫或之哀失民故也今懿情雖難量事未有逆而擢用賢能廣樹勝己脩先朝之政令副衆心之所求爽之所以為惡者彼莫不必改夙夜匪懈以恤民為先父子兄弟並握兵要未易亡也凌不從

**王广反对拥曹彪，论曹爽失众和司马懿得人** 按《汉晋春秋》，王广认为曹爽等因奢侈及改令失民心，司马懿慎于用人及施政，握重兵，难以仓促取代；王凌不从。

**归年依据** 嘉平元年谋立曹彪同条；作者并借言追述249高平陵。

[249年第8条](../../years/ce-0201-0300/ce-0249.md#sgz028-p-002-1)。

<a id="pei-002-2"></a>

> 臣松之以為如此言之類皆前史所不載而獨出習氏且制言法體不似於昔疑悉鑿齒所自造者也

**裴松之怀疑王广劝说是习凿齿拟辞** 前史未载，遣辞文体不似当时，怀疑注家自拟。

**归年依据** 史源批判，不是新增事件。

[裴松之怀疑王广劝说是习凿齿拟辞（时期）](../../years/ce-0201-0300/时期-三国志卷028-王毌丘诸葛邓钟传纪年待考（1）.md#period-sgz028-p-002-2)。

## 003｜令狐浚因问责田豫被曹丕治罪，改名愚

维基文库四库本原行 12—12。附见[正文 L1445](../本地分卷/三国志/三国志-卷028.md#l1445)。

<a id="pei-003-1"></a>

> 魏書曰愚字公治本名浚黄初中為和戎䕶軍烏丸校尉田豫討胡有功小違節度愚以法繩之帝怒械繫愚免官治罪詔曰浚何愚遂以名之

**令狐浚因问责田豫被曹丕治罪，改名愚** 为和戎护军时按法责田豫略违节度，曹丕怒逮治，诏责“何愚”，遂以为名。

**归年依据** 黄初间，田豫多次出塞，未指确役确年。

[令狐浚因问责田豫被曹丕治罪，改名愚（时期）](../../years/ce-0201-0300/时期-三国志卷028-王毌丘诸葛邓钟传纪年待考（1）.md#period-sgz028-p-003-1)。

<a id="pei-003-2"></a>

> 正始中為曹爽長史後出為兖州刺史

**令狐愚为曹爽长史，出为兖州刺史** 先任曹爽幕僚，后为兖州刺史。

**归年依据** 正始240—249，多职顺序；249已在兖州。

[令狐愚为曹爽长史，出为兖州刺史（时期）](../../years/ce-0201-0300/时期-三国志卷028-王毌丘诸葛邓钟传纪年待考（1）.md#period-sgz028-p-003-2)。

<a id="pei-003-3"></a>

> 魏畧曰愚聞楚王彪有智勇初東郡有譌言云白馬河出妖馬夜過官牧邊鳴呼衆馬皆應眀日見其跡大如斛行數里還入河中又有謡言白馬素羈西南馳其誰乗者朱虎騎楚王小字朱虎

**《魏略》载白马妖马传闻及童谣** 东郡说从河出大马，后来传“白马素羁”指小名朱虎的曹彪。

**归年依据** 谣言无年，早于密立往来。

[《魏略》载白马妖马传闻及童谣（时期）](../../years/ce-0201-0300/时期-三国志卷028-王毌丘诸葛邓钟传纪年待考（1）.md#period-sgz028-p-003-3)。

<a id="pei-003-4"></a>

> 故愚與王凌隂謀立楚王乃先使人通意於王言使君謝王天下事不可知願王自愛彪亦隂知其意答言謝使君知厚意也

**令狐愚与曹彪互达意向** 令狐愚遣人暗示大局不定，劝曹彪自重；曹彪理解并谢其厚意。

**归年依据** 本传嘉平元年明记使者两次往来。

[249年第8条](../../years/ce-0201-0300/ce-0249.md#sgz028-p-003-4)。

## 004｜浩详迎合王凌，以星占王者再兴

维基文库四库本原行 12—12。附见[正文 L1446](../本地分卷/三国志/三国志-卷028.md#l1446)。

<a id="pei-004-1"></a>

> 魏畧曰凌聞東平民浩詳知星呼問詳詳疑凌有所挾欲恱其意不言吳當有死喪而言淮南楚分也今吳楚同占當有王者興故凌計遂定

**浩详迎合王凌，以星占王者再兴** 王凌向浩详问荧惑，浩详不提吴有死丧，只称楚与吴同占，会有王者兴。

**归年依据** 依本传嘉平二年星占；与吴地同类天象一条。

[250年第18条](../../years/ce-0201-0300/ce-0250.md#sgz028-p-004-1)。

## 005｜王凌致司马懿书请归命

维基文库四库本原行 12—12。附见[正文 L1446](../本地分卷/三国志/三国志-卷028.md#l1446)。

<a id="pei-005-1"></a>

> 魏畧載凌與太傅書曰卒聞神軍宻發已在百尺雖知命窮盡遲於相見身首分離不以為恨前後遣使有書未得還報企踵西望無物以譬昨遣書之後便乗船來相迎宿丘頭旦發於浦口奉被露布赦書又得二十三日况累紙誨示聞命驚愕五内失守不知何地可以自處僕乆忝朝恩歴試無效統御戎馬董齊東夏事有闕廢中心犯義罪在二百妻子同縣無所禱矣不圖聖恩天覆地載橫䝉視息復覩日月亡甥令狐愚擕惑羣小之言僕即時呵抑使不得竟其語既人已知神眀所鍳夫非事無隂卒至發露知此梟夷之罪也生我者父母活我者子也

**王凌致司马懿书请归命** 称听知兵到百尺，自己往迎，接赦惊愕；推责亡甥令狐愚、称自己最初阻挠。

**归年依据** 《魏略》所引是王凌251面对东征时自说。

[251年第6条](../../years/ce-0201-0300/ce-0251.md#sgz028-p-005-1)。

<a id="pei-005-2"></a>

> 又重曰身䧟刑罪謬蒙赦宥今遣掾送印綬頃至當如詔書自縛歸命雖足下私之官法有分及到如書太傅使人解其縛凌既䝉赦加怙舊好不復自疑徑乗小船自趣太傅太傅使人逆止之住船淮中相去十餘丈凌知見外乃遥謂太傅曰卿直以折簡召我我當敢不至邪而乃引軍來乎太傅曰以卿非肯逐折簡者故也凌曰卿負我太傅曰我寧負卿不負國家遂使人送來西

**王凌再书送印绶、自缚请罪** 称虽蒙赦仍如诏归命。司马懿令解缚但不让王凌贴近，两人隔水问答，司马懿说宁负王凌不负国家。

**归年依据** 同251王凌迎降。

[251年第6条](../../years/ce-0201-0300/ce-0251.md#sgz028-p-005-2)。

<a id="pei-005-3"></a>

> 凌自知罪重試索棺釘以觀太傅意太傅給之凌行到項夜呼椽屬與決曰行年八十身名並滅邪遂自殺

**王凌索棺钉，至项自杀** 索棺钉试探处置，至项夜向属吏辞别，叹年八十身名并灭。

**归年依据** 《魏略》自杀说，与本传251年五月同。

[251年第7条](../../years/ce-0201-0300/ce-0251.md#sgz028-p-005-3)。

<a id="pei-005-4"></a>

> 干寳晉紀曰凌到項見賈逵祠在水側凌呼曰賈梁道王凌固忠於魏之社稷者惟爾有神知之

**干宝记王凌呼贾逵祠** 在项见故人祠，自诉仍忠魏社稷。

**归年依据** 随至项自杀前，251同事。

[251年第7条](../../years/ce-0201-0300/ce-0251.md#sgz028-p-005-4)。

<a id="pei-005-5"></a>

> 其年八月太傅有疾夢凌逵為厲甚惡之遂薨

**干宝记司马懿死前梦王凌贾逵** 《晋纪》说司马懿病时责恶梦中二人作祟，不久卒。

**归年依据** 魏本纪嘉平三年秋七月戊寅，干宝作“八月”，存同一死亡异月。

[251年第11条](../../years/ce-0201-0300/ce-0251.md#sgz028-p-005-5)。

## 006｜单固在母劝说下受令狐愚征辟

维基文库四库本原行 12—12。附见[正文 L1447](../本地分卷/三国志/三国志-卷028.md#l1447)。

<a id="pei-006-1"></a>

> 魏畧載山陽單固字恭夏為人有器實正始中兖州刺史令狐愚與固父伯龍善辟固欲以為别駕固不樂為州吏辭以疾愚禮意愈厚固不欲應固母夏侯氏謂固曰使君與汝父乆善故命汝不止汝亦固當仕進自可往耳固不獲已遂往與兼治中從事楊康並為愚腹心

**单固在母劝说下受令狐愚征辟** 令狐愚与其父善，辟单固；单原不愿做州吏，母劝应召，他和杨康成为其近属。

**归年依据** 正始中，具体年无载。

[单固在母劝说下受令狐愚征辟（时期）](../../years/ce-0201-0300/时期-三国志卷028-王毌丘诸葛邓钟传纪年待考（1）.md#period-sgz028-p-006-1)。

<a id="pei-006-2"></a>

> 後愚與王凌通謀康固皆知其計㑹愚病康應司徒召詣洛陽固亦以疾解祿

**单固杨康知谋，令狐愚病时分别去职** 两人皆知令狐愚与王凌之谋，愚病时杨康应召还洛、单固辞官。

**归年依据** 本传嘉平元年冬令狐愚病卒。

[249年第8条](../../years/ce-0201-0300/ce-0249.md#sgz028-p-006-2)。

<a id="pei-006-3"></a>

> 康在京師露其事太傅乃東取王凌到夀春固見太傅太傅問曰卿知其亊為邪固對不知太傅曰且置近事問卿令狐及乎固又曰無而楊康白亊亊與固連遂收捕固及家屬皆繫廷尉考實數十固故云無有太傅錄楊康與固對相詰固辭窮乃罵康曰老庸既負使君又滅我族顧汝當活邪辭定事上須報廷尉以舊皆聽得與其母妻子相見固見其母不仰視其母知其慙也字謂之曰恭夏汝本自不欲應州郡也我强故耳汝為人吏自當爾耳此自門户衰我無恨也汝本意與我語固終不仰又不語以至於死

**杨康告发后单固被收并伏诛** 杨康在洛阳陈其事。司马懿问单固不得实，调查并对质，单固痛骂杨康，见母不敢仰面，同亲属受审伏诛。

**归年依据** 同王凌曹彪案后株连，251。

[251年第8条](../../years/ce-0201-0300/ce-0251.md#sgz028-p-006-3)。

<a id="pei-006-4"></a>

> 初楊康自以白其事冀得封拜後以辭頗參錯亦并斬臨刑俱出獄固又罵康曰老奴汝死自分耳若令死者有知汝何面目以行地下也

**告密的杨康同被杀** 原望获封，因说辞前后失据同被斩；单固在刑前再骂他。

**归年依据** 同案收尾。

[251年第8条](../../years/ce-0201-0300/ce-0251.md#sgz028-p-006-4)。

## 009｜张既称毌丘兴在武威绥边

维基文库四库本原行 13—13。附见[正文 L1449](../本地分卷/三国志/三国志-卷028.md#l1449)。

<a id="pei-009-1"></a>

> 魏名臣奏載雍州刺史張既表曰河右遐逺喪亂彌乆武威當諸郡路通喉轄之要加民夷雜處數冇兵難領太守毌丘興到官内撫吏民外懐羌胡卒使柔附為官效用

**张既称毌丘兴在武威绥边** 说武威当道路冲要，民夷杂处兵难频仍，毌丘兴抚吏民、怀羌胡，皆附而效用。

**归年依据** 毌丘兴在武威期间，未载确年。

## 049｜《史记》越王无疆故事，裴注释目论

维基文库四库本原行 17—17。附见[正文 L1515](../本地分卷/三国志/三国志-卷028.md#l1515)。

<a id="pei-049-1"></a>

> 史記曰越王無彊與中國爭彊當楚威王時越北伐齊齊威王使人說越云越王不納齊使者曰幸也越之不亡也吾不貴其用智之如目目見毫毛而不自見其睫也今王知晉之失而不自知越之失是目論也

**《史记》越王无疆故事，裴注释目论** 越王一度图攻齐，齐使以眼见细毛却不见眼睫比越只察他国不自省，注家用作陈寿“目论”的出处。

**归年依据** 《史记·越王句践世家》置楚威王时，依仓内前334第6条沿《通鉴》显王三十五年系；保留楚怀王时期异说。

[前334年第6条](../../years/bce-0400-0301/bce-0334.md#sgz028-p-049-1)。

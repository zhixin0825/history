## 002｜《华佗别传》记病者不能步行

维基文库四库本原行 13—13。附见[正文 L1532](../本地分卷/三国志/三国志-卷029.md#l1532)。

<a id="pei-002-1"></a>

> 佗别傳曰有人病兩脚躄不能行轝詣佗佗望見云已飽針灸服藥矣不復須看脉便使解衣㸃背數十處相去或一寸或五寸縱邪不相當言灸此各十壮灸創愈即行後灸處夾脊一寸上下行端直均調如引繩也

**归年依据** 患者及年月皆未载；作为古籍病例释读。

## 004｜刘景宗追记华佗行医

维基文库四库本原行 13—13。附见[正文 L1535](../本地分卷/三国志/三国志-卷029.md#l1535)。

<a id="pei-004-1"></a>

> 佗别傳曰人有在青龍中見山陽太守廣陵劉景宗景宗說中平日數見華佗其治病手脉之候其驗若神

**刘景宗追记华佗行医** 有人在青龙中遇山阳太守刘景宗；刘景宗说中平时多次见华佗、称其诊脉灵验。

> 琅邪劉勲為河内太守有女年㡬二十左脚膝裏上有瘡癢而不痛瘡愈數十日復發如此七八年迎佗使視佗曰是易治之當得稻糠黄色犬一頭好馬二匹以繩繫犬頸使走馬牽犬馬極輒易計馬走三十餘里犬不能行復令歩人拖曵計向五十里乃以藥飲女女即安卧不知人因取大刀斷犬腹近後脚之前以所斷之處向瘡口令去二三寸停之須臾有若虵者從瘡中而出便以鐵錐横貫虵頭虵在皮中動揺良乆須臾不動乃牽出長三尺許純是虵但有眼處而無童子又逆鱗耳以膏散著瘡中七日愈

**《华佗别传》记刘勋女病** 琅邪刘勋任河内太守时请华佗诊治女儿，别传叙有蛇自病处引出及七天好转的故事。

**归年依据** 刘勋降曹在199；各书载此次诊疗无年。

## 005｜《华佗别传》记青黏及樊阿

维基文库四库本原行 13—13。附见[正文 L1536](../本地分卷/三国志/三国志-卷029.md#l1536)。

<a id="pei-005-1"></a>

> 佗别傳曰青黏者一名地節一名黄芝主理五藏益精氣本出於迷入山者見仙人服之以告佗佗以為佳輙語阿阿又秘之近者人見阿之夀而氣力彊盛怪之遂責阿所服因醉亂誤道之法一施人多服者皆有大驗

**《华佗别传》记青黏及樊阿** 注载青黏又名地节、黄芝，传说从山中得知；华佗告诉樊阿，樊阿起初不传，后来饮醉泄露。

**归年依据** 药名、传说及传授年皆无载。

## 006｜傅玄评马钧的巧思

维基文库四库本原行 14—14。附见[正文 L1541](../本地分卷/三国志/三国志-卷029.md#l1541)。

<a id="pei-006-1"></a>

> 時有扶風馬鈞巧思絶世傅玄序之曰馬先生天下之名巧也少而游豫不自知其為巧也當此之時言不及巧焉可以言知乎

**傅玄评马钧的巧思** 马钧扶风人，少时自己还不知擅长制器，傅玄以此提出如何识别才能的问题。

**归年依据** 行状与傅序写作各无确年。

[傅玄评马钧的巧思（时期）](../../years/ce-0201-0300/时期-三国志卷029-方技传纪年待考（2）.md#period-sgz029-p-006-1)。

<a id="pei-006-2"></a>

> 為博士居貧乃思綾機之變不言而世人知其巧矣舊綾機五十綜者五十躡六十綜者六十躡先生患其䘮功費日乃皆易以十二躡其竒文異變因感而作者猶自然之成形隂陽之無窮此輪扁之對不可以言言者又焉可以言校也

**马钧改良绫织机** 任博士而家贫，注意到旧机多综多蹑，改以十二蹑以节省操作。

**归年依据** 傅序无任博士与改机的具体年。

[马钧改良绫织机（时期）](../../years/ce-0201-0300/时期-三国志卷029-方技传纪年待考（2）.md#period-sgz029-p-006-2)。

<a id="pei-006-3"></a>

> 先生為給事中與常侍髙堂隆驍騎將軍秦朗爭論於朝言及指南車二子謂古無指南車記言之虛也先生曰古有之未之思耳夫何逺之有二子哂之曰先生名鈞字徳衡鈞者器之模而衡者所以定物之輕重輕重無準而莫不模哉先生曰虛爭空言不如試之易效也於是二子遂以白眀帝詔先生作之而指南車成此一異也又不可以言者也從是天下服其巧矣

**曹叡命马钧造指南车** 高堂隆、秦朗疑古无指南车，马钧说应实践；两人禀曹叡，马钧奉诏制成。

**归年依据** 《宋书》卷十八置青龙中233—237，仅有年段；傅序作给事中、《宋书》称博士。

[曹叡命马钧造指南车（时期）](../../years/ce-0201-0300/时期-三国志卷029-方技传纪年待考（2）.md#period-sgz029-p-006-3)。

<a id="pei-006-4"></a>

> 居京都城内有坡可為囿患無水以灌之乃作翻車令童兒轉之而灌水自覆更入更出其巧百倍於常此二異也

**马钧为园地制翻车灌水** 京城有可作园囿之地，原无水灌溉，他制成转动即可连续提灌的翻车。

**归年依据** 在京都的行事，无独立年。

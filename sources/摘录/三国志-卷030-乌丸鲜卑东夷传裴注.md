## 001｜冒顿灭东胡与乌丸源流

维基文库四库本原行 11—11。附见[正文 L1579](../本地分卷/三国志/三国志-卷030.md#l1579)。

<a id="pei-001-1"></a>

> 魏書曰烏丸者東胡也漢初匈奴冐頓滅其國餘類保烏丸山因以為號焉

**冒顿灭东胡与乌丸源流** 《魏书》称乌丸出自东胡，冒顿灭其国后残部保乌丸山得名。

**归年依据** 《史记·匈奴列传》系于冒顿初立、秦汉之际，无确年；与TXT L1579所录同注异本。

[冒顿灭东胡与乌丸源流（时期）](../../years/ce-0201-0300/时期-三国志卷030-乌丸鲜卑东夷传纪年待考（3）.md#period-sgz030-p-001-1)。

<a id="pei-001-2"></a>

> 俗善騎射随水草放牧居無常處以穹廬為宅皆東向日弋獵禽獸食肉飲酪以毛毳為衣

**乌丸骑射、帐幕和衣食** 逐水草畜牧，居东向穹庐，以禽兽为食，饮酪，以毛毳为衣。

**归年依据** 部族风俗，无单年。

[乌丸骑射、帐幕和衣食（时期）](../../years/ce-0201-0300/时期-三国志卷030-乌丸鲜卑东夷传纪年待考（3）.md#period-sgz030-p-001-2)。

> 貴少賤老其性悍驁怒則殺父兄而終不害其母以母有族類父兄以己為種無復報者故也常推募勇健能理决鬪訟相侵犯者為大人邑落各有小帥不世繼也數百千落自為一部大人有所召呼刻木為信邑落傳行無文字而部衆莫敢違犯氏姓無常以大人健者名字為姓大人以下各自畜牧治産不相徭役

**乌丸组织和推选首领** 重少轻老，记母族约束；大人由勇健善理讼者当任，各邑有小帅，刻木传令，依大人名为姓，各自经营。

**归年依据** 亲属、首领与部落制度。

[乌丸组织和推选首领（时期）](../../years/ce-0201-0300/时期-三国志卷030-乌丸鲜卑东夷传纪年待考（3）.md#period-sgz030-p-001-3)。

<a id="pei-001-4"></a>

> 其嫁娶皆先私通畧将女去或半嵗百日然後遣媒人送馬牛羊以為聘娶之禮壻随妻歸見妻家無尊卑旦起皆拜而不自拜其父母為妻家僕役二年妻家乃厚遣送女居處財物一出妻家故其俗從婦人計至戰鬪時乃自决之父子男女相對蹲踞悉秃頭以為輕便婦人至嫁時乃養髪分為髻着句决餙以金碧猶中國有冠步揺也父兄死妻後母執嫂若無執嫂者則己子以親之次妻伯叔焉死則歸其故夫

**乌丸婚聘、妇人及髡发** 送牲畜聘礼，婿役妻家，平日常从妇人筹划；所记女子鬟饰及夫死后续嫁均是旧俗。

**归年依据** 婚姻、服饰风俗。

[乌丸婚聘、妇人及髡发（时期）](../../years/ce-0201-0300/时期-三国志卷030-乌丸鲜卑东夷传纪年待考（3）.md#period-sgz030-p-001-4)。

<a id="pei-001-5"></a>

> 俗識鳥獸孕乳時以四節耕種常以布穀鳴為〔四库字图1974〕地宜青穄東牆東牆似蓬草實如葵子至十月熟能作白酒而不知作麴糵米常仰中國大人能作弓矢鞍勒鍛金鐡為兵器能刺韋作文繡織縷氊〔四库字图2035〕有病知以艾灸或燒石自熨燒地卧上或随痛病處以刀决脉出血及祝天地山川之神無鍼藥

**乌丸农艺、制物及疗病** 以鸟兽物候和布谷声安排耕种，记谷物、酒、兵器、皮毡、艾灸及放血等。

**归年依据** 物候、生产与医疗风俗。

[乌丸农艺、制物及疗病（时期）](../../years/ce-0201-0300/时期-三国志卷030-乌丸鲜卑东夷传纪年待考（3）.md#period-sgz030-p-001-5)。

<a id="pei-001-6"></a>

> 貴兵死歛屍有棺始死則哭塟則歌舞相送肥養犬以采繩嬰牽幷取亡者所乘馬衣服生時服餙皆燒以送之特屬累犬使䕶死者神靈歸乎赤山赤山在遼東西北數千里如中國人以死之魂神歸泰山也至葬日夜聚親舊員坐牽犬馬歴位或歌哭者擲肉與之使二人口誦呪文使死者魂神徑至歴險阻勿令横鬼遮䕶逹其赤山然後殺犬馬衣物燒之敬鬼神祠天地日月星辰山川及先大人有健名者亦同祠以牛羊祠畢皆燒之飲食必先祭

**乌丸送葬、赤山及祭祀** 以犬马、衣物焚送亡灵，令其归赤山，并祭天地星辰、山川和前代名领。

**归年依据** 丧葬及信仰风俗。

[乌丸送葬、赤山及祭祀（时期）](../../years/ce-0201-0300/时期-三国志卷030-乌丸鲜卑东夷传纪年待考（3）.md#period-sgz030-p-001-6)。

<a id="pei-001-7"></a>

> 其約法違大人言死盗不止死其相殘殺令部落自相報相報不止詣大人平之有罪者出牛羊以贖死命乃止自殺其父兄無罪其亡叛為大人所捕者諸邑落不肯受皆逐使至雍狂地地無山有沙漠流水草木多蝮虵在丁令之西南烏孫之東北以窮困之

**乌丸相报、赎罪与放逐** 违令或盗窃不停者可处死，杀人由部落报复或交首领调判、以牲畜赎；亡叛者被放逐雍狂地。

**归年依据** 刑罚制度及地理传闻。

[乌丸相报、赎罪与放逐（时期）](../../years/ce-0201-0300/时期-三国志卷030-乌丸鲜卑东夷传纪年待考（3）.md#period-sgz030-p-001-7)。

<a id="pei-001-8"></a>

> 自其先為匈奴所破之後人衆孤弱為匈奴臣服常嵗輸牛馬羊過時不具輙虜其妻子

**乌丸向匈奴输纳** 被匈奴击败后逐年纳牲畜，缴纳短缺可遭掳掠家属。

**归年依据** 冒顿击东胡以来的长期关系。

[乌丸向匈奴输纳（时期）](../../years/ce-0201-0300/时期-三国志卷030-乌丸鲜卑东夷传纪年待考（3）.md#period-sgz030-p-001-8)。

<a id="pei-001-9"></a>

> 至匈奴壹衍鞮單于時烏丸轉彊發掘匈奴單于冡将以報冒頓所破之恥壹衍鞮單于大怒發二萬騎以擊烏丸大將軍霍光聞之遣度遼将軍范明友将三萬騎出遼東追擊匈奴比明友兵至匈奴已引去烏丸新被匈奴兵乘其衰〔四库字图1000〕遂進擊烏丸斬首六千餘級獲三王首還

**乌丸掘单于冢、范明友改击乌丸** 匈奴出兵后，霍光令范明友由辽东追击，匈奴先撤，汉军遂攻乌丸并斩获多人。

**归年依据** 《汉书·昭帝纪》元凤三年冬发兵；《汉书·匈奴传》作壶衍鞮，与四库本文壹衍鞮不同；前77受封为战后另事。

[前78年第1条](../../years/bce-0100-0001/bce-0078.md#sgz030-p-001-9)。

<a id="pei-001-10"></a>

> 後數復犯塞明友輙征破之

**范明友再击乌丸** 乌丸屡犯塞，范明友再次出兵。

**归年依据** 《汉书·昭帝纪》元凤六年九月载又遣范明友。其他犯塞无确年。

> 至王莽末並與匈奴為宼

**王莽末年乌丸与匈奴为寇** 乌丸与匈奴一同骚扰边塞。

**归年依据** 只记王莽后期。

[王莽末年乌丸与匈奴为寇（时期）](../../years/ce-0201-0300/时期-三国志卷030-乌丸鲜卑东夷传纪年待考（3）.md#period-sgz030-p-001-11)。

<a id="pei-001-12"></a>

> 光武定天下遣伏波將軍馬援將三千騎從五原闗出塞征之無利而殺馬千餘匹

**马援出塞讨乌丸不利** 马援出五原关，率三千骑进兵，损失千余战马。

**归年依据** 《后汉书·光武帝纪》建武二十一年，附同一役；《后汉书·乌桓传》关名作五阮。

[45年第4条](../../years/ce-0001-0100/ce-0045.md#sgz030-p-001-12)。

<a id="pei-001-13"></a>

> 烏丸遂盛鈔擊匈奴匈奴轉徙千里漠南地空

**乌丸击匈奴，漠南空虚** 乌丸转强击匈奴，匈奴北迁，漠南地空。

**归年依据** 《后汉书·南匈奴传》建武二十二年。

[46年第12条](../../years/ce-0001-0100/ce-0046.md#sgz030-p-001-13)。

<a id="pei-001-14"></a>

> 建武二十五年烏丸大人郝且等九千餘人率衆詣闕封其渠帥為侯王者八十餘人使居塞内布列遼東屬國遼西右北平漁陽廣陽上谷代郡鴈門太原朔方諸郡界招来種人給其衣食置校尉以領䕶之遂為漢偵備擊匈奴鮮卑

**郝且等归汉、入塞安置** 乌丸多部入朝，渠帅封王侯，沿边安置，朝廷供衣食并置校尉护领，由其侦防。

**归年依据** 注直载建武二十五年；四库本郝且，仓内TXT郝旦。

[49年第9条](../../years/ce-0001-0100/ce-0049.md#sgz030-p-001-14)。

<a id="pei-001-15"></a>

> 至永平中漁陽烏丸大人欽志賁帥種人叛鮮卑還為宼害遼東太守祭彤募殺志賁遂破其衆

**祭彤征乌丸欽志賁** 祭彤利用鲜卑击破反叛的乌丸首领。

**归年依据** 《后汉书·鲜卑传》永平元年同事，作祭肜、歆志賁；固定本照录。

[58年第8条](../../years/ce-0001-0100/ce-0058.md#sgz030-p-001-15)。

<a id="pei-001-16"></a>

> 至安帝時漁陽右北平鴈門烏丸率衆王無何等復與鮮卑匈奴合鈔畧代郡上谷涿郡五原乃以大司農何熙行車騎将軍左右羽林五營士發縁邉七郡黎陽營兵合二萬人擊之匈奴降鮮卑烏丸各逺塞外

**何熙击乌丸、鲜卑、匈奴** 乌丸无何等联兵犯多郡，何熙领车骑将军调兵，匈奴降，鲜卑乌丸退。

**归年依据** 《后汉书·乌桓传》安帝永初三年。

[109年第29条](../../years/ce-0101-0200/ce-0109.md#sgz030-p-001-16)。

**戎末廆领都尉** 乌丸渐归汉，戎末廆受都尉职。

**归年依据** 109年后，《后汉书》作戎朱廆，任命未载单年。

[戎末廆领都尉（时期）](../../years/ce-0201-0300/时期-三国志卷030-乌丸鲜卑东夷传纪年待考（3）.md#period-sgz030-p-001-17)。

<a id="pei-001-18"></a>

> 至順帝時戎末廆率將王侯咄歸去延等從烏丸校尉耿曄出塞擊鮮卑有功還皆拜為率衆王賜束帛

**耿晔遣乌丸部出塞击鲜卑** 戎末廆、咄归、去延等出塞立功，回师获封赐。

**归年依据** 《后汉书·鲜卑传》阳嘉元年冬耿晔遣戎朱廆、咄归等出击；原注兼叙封赏。

## 004｜鲜卑源流、所居和婚会物产

维基文库四库本原行 12—12。附见[正文 L1582](../本地分卷/三国志/三国志-卷030.md#l1582)。

<a id="pei-004-1"></a>

> 魏書曰鮮卑亦東胡之餘也别保鮮卑山因號焉其言語習俗與烏丸同其地東接遼水西當西城常以季春大㑹作樂水上嫁女娶婦髠頭飲宴其獸異於中國者野馬羱羊端牛端牛角為弓世謂之角端者也又冇貂豽鼲子皮毛柔蠕故天下以為名裘

**鲜卑源流、所居和婚会物产** 《魏书》称鲜卑为东胡余部，居鲜卑山与乌丸近，暮春临水聚会并婚娶，出角端、貂鼲等。

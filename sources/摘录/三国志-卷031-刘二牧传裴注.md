## 001｜祝公为司徒祝恬

维基文库四库本原行 11—11。附见[正文 L1630](../本地分卷/三国志/三国志-卷031.md#l1630)。

<a id="pei-001-1"></a>

> 臣松之案祝公司徒祝恬也

**祝公为司徒祝恬** 裴松之辨明刘焉守丧的老师是司徒祝恬。

**归年依据** 《后汉书·桓帝纪》延熹三年六月辛丑记祝恬去世。刘焉具体离职时间仍未明。

## 003｜《续汉书》并列州牧及待遇

维基文库四库本原行 11—11。附见[正文 L1631](../本地分卷/三国志/三国志-卷031.md#l1631)。

<a id="pei-003-1"></a>

> 續漢書曰是時用劉虞為幽州劉焉為益州劉表為荆州賈琮為冀州虞等皆海内清名之士或從列卿尚書以選為牧伯各以本秩居任舊典傳車叅駕施赤為帷裳

**《续汉书》并列州牧及待遇** 《续汉书》列刘虞、刘焉、刘表、贾琮及牧伯从旧秩任职、车帷等。

**归年依据** 本传、通鉴系刘虞、刘焉之任于188年。此段刘表时序由裴松之另辨。

[188年第26条](../../years/ce-0101-0200/ce-0188.md#sgz031-p-003-1)。

<a id="pei-003-2"></a>

> 臣松之案靈帝崩後義軍起孫堅殺荆州刺史王叡然後劉表為荆州不與焉同時也

**刘表继王叡治荆州** 裴松之说孙坚杀王叡后才有刘表领荆州，不能与188年刘焉同步。

**归年依据** 《通鉴》及纪传所记关东军兴、孙坚杀王叡在初平元年。

[190年第21条](../../years/ce-0101-0200/ce-0190.md#sgz031-p-003-2)。

<a id="pei-003-3"></a>

> 漢靈帝紀曰帝引見焉宣示方畧加以賞賜勅焉為益州刺史前刺史劉儁郤儉皆貪殘放溢取受狼籍元元無聊呼嗟充野焉到便收攝行法以示萬姓勿令漏露使癰疽决潰為國生梗焉受命而行以道路不通住荆州東界

**汉灵帝令刘焉查办益州旧刺史** 灵帝命刘焉惩治前任刺史聚敛，刘焉受命后因路不通先住荆州东界。

**归年依据** 此行与中平五年改州牧相连。《汉灵帝纪》称刺史，与诸书记牧有称谓异文。

[188年第26条](../../years/ce-0101-0200/ce-0188.md#sgz031-p-003-3)。

## 004｜董扶受学、游京师讲授

维基文库四库本原行 11—11。附见[正文 L1631](../本地分卷/三国志/三国志-卷031.md#l1631)。

<a id="pei-004-1"></a>

> 陳夀益部耆舊傳曰董扶字茂安少從師學兼通數經善歐陽尚書又事聘士楊厚䆒極圖䜟遂至京師遊覧太學還家講授子弟自逺而来

**董扶受学、游京师讲授** 董扶学经、事杨厚，游太学后归里授徒。

**归年依据** 生平早段，年月未载。

[董扶受学、游京师讲授（时期）](../../years/ce-0201-0300/时期-三国志卷031-刘二牧传纪年待考.md#period-sgz031-p-004-1)。

<a id="pei-004-2"></a>

> 永康元年日有蝕之詔舉賢良方正之士策問得失左馮翊趙謙等舉扶扶以病不詣遥於長安上封事遂稱疾篤歸家

**董扶因日食诏举而被荐** 日食后朝廷策问，赵谦举荐董扶。董扶没到朝廷，曾在长安上封事后归家。

**归年依据** 注文明确永康元年日食，附本年。上封事是这次荐举后不赴的叙事。

[167年第8条](../../years/ce-0101-0200/ce-0167.md#sgz031-p-004-2)。

<a id="pei-004-3"></a>

> 前後宰府十辟公車三徴再舉賢良方正博士有道皆不就名稱尤重

**董扶屡辞征聘** 宰府、公车多次征召，董扶不就，名声愈重。

**归年依据** 多次任用跨年。

[董扶屡辞征聘（时期）](../../years/ce-0201-0300/时期-三国志卷031-刘二牧传纪年待考.md#period-sgz031-p-004-3)。

<a id="pei-004-4"></a>

> 大將軍何進表薦扶曰資游夏之徳述孔氏之風内懐焦董消復之術方今幷涼騷擾西戎蠢叛宜勑公車特詔待以異禮諮謀竒策於是靈帝徴扶即拜侍中在朝稱為儒宗甚見器重求為蜀郡屬國都尉扶出一嵗而靈帝崩天下大亂後去官年八十二卒于家始扶發辭抗論益部少雙故號曰致止言人莫能當所至而談止也

**何进推荐董扶，朝廷征为侍中** 何进称董扶通经、熟悉政事谶候，朝廷征拜侍中。

**归年依据** 何进任大将军在184—189；董扶至少在188年与刘焉商谈时已任侍中，未见单一日期。

[何进推荐董扶，朝廷征为侍中（时期）](../../years/ce-0201-0300/时期-三国志卷031-刘二牧传纪年待考.md#period-sgz031-p-004-4)。

<a id="pei-004-5"></a>

> 後丞相諸葛亮問秦宓以扶所長宓曰董扶褒秋毫之善貶纎芥之惡

**诸葛亮与秦宓谈董扶** 诸葛亮向秦宓询问董扶所长，秦宓称他能辨很细微的善恶。

**归年依据** 秦宓死于226，诸葛亮称丞相始221，问答未记哪一年。

[诸葛亮与秦宓谈董扶（时期）](../../years/ce-0201-0300/时期-三国志卷031-刘二牧传纪年待考.md#period-sgz031-p-004-5)。

## 006｜任岐、赵谦、贾龙及刘焉交战

维基文库四库本原行 11—11。附见[正文 L1632](../本地分卷/三国志/三国志-卷031.md#l1632)。

<a id="pei-006-1"></a>

> 英雄記曰劉焉起兵不與天下討董卓保州自守犍為太守任岐自稱將軍與從事陳超舉兵擊焉焉擊破之董卓使司徒趙謙将兵向州説校尉賈龍使引兵還擊焉焉出青羌與戰故能破殺岐龍等皆蜀郡人

## 012｜东州兵的来源及与旧人的冲突

维基文库四库本原行 12—12。附见[正文 L1636](../本地分卷/三国志/三国志-卷031.md#l1636)。

<a id="pei-012-1"></a>

> 英雄記曰先是南陽三輔人流入益州數萬家收以為兵名曰東州兵璋性寛柔無威畧東州人侵暴舊民璋不能禁政令多闕益州頗怨

**东州兵的来源及与旧人的冲突** 南阳、三辅人流入益州后被收为东州兵，侵暴旧民，刘璋无法制止。

**归年依据** 是赵韙反叛之前的多年背景。

[东州兵的来源及与旧人的冲突（时期）](../../years/ce-0201-0300/时期-三国志卷031-刘二牧传纪年待考.md#period-sgz031-p-012-1)。

<a id="pei-012-2"></a>

> 趙韙素得人心璋委任之韙因民怨謀叛乃厚賂荆州請和隂結州中大姓與俱起兵還擊璋蜀郡廣漢犍為皆應韙

**赵韙联合大姓起兵** 赵韙利用益州旧民不满，向荆州纳贿求和，与州中大族联结反刘璋，蜀、广汉、犍为诸郡响应。

**归年依据** 《资治通鉴》卷063建安五年；200年第15条记益州诸郡响应。

[200年第15条](../../years/ce-0101-0200/ce-0200.md#sgz031-p-012-2)。

<a id="pei-012-3"></a>

> 璋馳入成都城守東州人畏威咸同心幷力助璋皆殊死戰遂破反者進攻韙於江州韙將龎樂李異反殺韙軍斬韙

**赵韙败死江州** 刘璋退守成都，东州人合力为其作战。赵韙部将庞乐、李异倒戈，赵韙身死。

**归年依据** 《通鉴》卷064建安六年接续。

[201年第15条](../../years/ce-0201-0300/ce-0201.md#sgz031-p-012-3)。

<a id="pei-012-4"></a>

> 漢獻帝春秋曰漢朝聞益州亂遣五官中郎將牛亶為益州刺史徴璋為卿不至

**汉廷遣牛亶赴益州，刘璋未应征** 汉廷听闻益州乱，任牛亶为益州刺史，征刘璋为卿，刘璋没有应征。

**归年依据** 《资治通鉴》卷六十四于建安六年赵韙败亡之后记此事。

[201年第15条](../../years/ce-0201-0300/ce-0201.md#sgz031-p-012-4)。

## 014｜张松使曹、归劝刘璋断绝

维基文库四库本原行 12—12。附见[正文 L1637](../本地分卷/三国志/三国志-卷031.md#l1637)。

<a id="pei-014-1"></a>

> 漢晉春秋曰張松見曹公曹公方自矜伐不存録松松歸乃勸璋自絶

**张松使曹、归劝刘璋断绝** 《汉晋春秋》称曹操自矜，对张松疏慢，张松回蜀后劝刘璋断绝曹操。

**归年依据** 赤壁前后，使曹与回劝在建安十三年叙事。

[208年第9条](../../years/ce-0201-0300/ce-0208.md#sgz031-p-014-1)。

<a id="pei-014-2"></a>

> 習鑿齒曰昔齊桓一矜其功而叛者九國曹操暫自驕伐而天下三分皆勤之於數十年之内而棄之於俯仰之頃豈不惜哉是以君子勞謙日昃慮以下人功髙而居之以讓勢尊而守之以卑情近於物故雖貴而人不厭其重徳洽羣生故業廣而天下愈欣其慶夫然故能有其富貴保其功業隆顯當時傳福百世何驕矜之有哉君子是以知曹操之不能遂兼天下者也

**习凿齿评论曹操失去统一机会** 习凿齿比较齐桓公及曹操，劝掌功势者用谦德，认为曹操自夸使人背离。

**归年依据** 史评，无独立日期。

## 020｜张璠评论刘璋与张松、法正

维基文库四库本原行 13—13。附见[正文 L1640](../本地分卷/三国志/三国志-卷031.md#l1640)。

<a id="pei-020-1"></a>

> 張璠曰劉璋愚弱而守善言斯亦宋㐮公徐偃王之徒未為無道之主也張松法正雖君臣之義不正然固己委名附質進不顯陳事勢若韓嵩劉光之説劉表退不告絶奔七若陳平韓信之去項羽而両端擕貳為謀不忠罪之次也

**张璠评论刘璋与张松、法正** 张璠说刘璋软弱但不是无道。张松、法正既委身事人，应明谏或告绝，不应暗中两属，遂引古人离主的行为相比较。

**归年依据** 整段是对益州易主和臣下行为的史论，写作年代未具。

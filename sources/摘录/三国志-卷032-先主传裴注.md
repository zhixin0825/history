## 001｜刘备世系的另一种说法

维基文库四库本原行 11—11。附见[正文 L1643](../本地分卷/三国志/三国志-卷032.md#l1643)。

<a id="pei-001-1"></a>

> 典畧曰備本臨邑侯枝屬也

**刘备世系的另一种说法** 《典略》称刘备本为临邑侯支系，与正文称中山靖王后裔的定位不同。

**归年依据** 世系异说，各代传承缺乏材料。

## 003｜张纯叛，刘备经刘子平推荐参战

维基文库四库本原行 11—11。附见[正文 L1645](../本地分卷/三国志/三国志-卷032.md#l1645)。

<a id="pei-003-1"></a>

> 典畧曰平原劉子平知備有武勇時張純反叛青州被詔遣從事將兵討純過平原子平薦備于徔事遂與相随遇賊於野備中創陽死賊去後故人以車載之得免

**张纯叛，刘备经刘子平推荐参战** 《典略》称张纯反叛，青州受命遣兵，过平原时刘子平推荐刘备从军，刘备野战重伤诈死，战后获旧交车载而免。

**归年依据** 张纯于中平四年起兵，至189败死；本注以叛乱定位起事，个人参战月份和确年未见，勿等同黄巾184。

[187年第10条](../../years/ce-0101-0200/ce-0187.md#sgz032-p-003-1)。

<a id="pei-003-2"></a>

> 後以軍功為中山安喜尉

**《典略》载刘备以军功为安喜尉** 刘备后以军功补中山安喜尉，注意承讨张纯。

**归年依据** 本传承184黄巾军功，本注承187–189张纯作乱军功，任官不硬定一年。

## 005｜督邮欲汰刘备，刘备绑缚痛打

维基文库四库本原行 11—11。附见[正文 L1645](../本地分卷/三国志/三国志-卷032.md#l1645)。

<a id="pei-005-1"></a>

> 典畧曰其後州郡被詔書其有軍功為長吏者當沙汰之備疑在遣中督郵至縣當遣備備素知之聞督郵在傳舍備欲求見督郵督郵稱疾不肯見備備恨之因還治將吏卒更詣傳舍突入門言我被府君宻教收督郵遂就牀縛之將出到界自觧其綬以繫督郵頸縳之著樹鞭杖百餘下欲殺之督郵求哀乃釋去之

**督邮欲汰刘备，刘备绑缚痛打** 《典略》称朝廷欲裁撤以军功任长吏者，刘备料督邮要汰己。求见被拒后带吏卒闯传舍，将督邮绑到县界鞭杖，最终应其求饶放走。

**归年依据** 任安喜尉后、何进遣毌丘毅前；《典略》把任安喜尉接于张纯事。与正文绑在马枊、二百杖有出入。

<a id="pei-009-1"></a>

> 英䧺記曰備留張飛守下邳引兵與袁術戰於淮隂石亭更有勝負陶謙故將曹豹在下邳張飛欲殺之豹衆堅營自守使人招吕布布取下邳張飛敗走備聞之引兵還北至下邳兵潰収散卒東取廣陵與袁術戰又敗

**《魏书》记刘备请求屯小沛** 吕布诸将劝尽早处置刘备，吕布不从并告刘备。刘备不安，托人请求屯小沛，吕布同意。

**归年依据** 注自书建安三年十月与曹操会师；《武帝纪》九月起兵，动作有别。

<a id="pei-015-1"></a>

> 胡沖吴歴曰曹公數遣親近宻覘諸将有賔客酒食者輙因事害之備時閉門将人種蕪菁曺公使人闚門既去備謂張飛闗羽曰吾豈種菜者乎曹公必有疑意不可復留其夜開後棚與飛䓁輕騎俱去所得賜遺衣服悉封留之乃徃小沛收合兵衆

**《吴历》载刘备种菜掩护出走** 胡冲称曹操遣人暗察诸将，刘备先掩门种菜，察觉遭疑，当夜弃所赐衣物与张飞等轻骑离去，往小沛收兵。

**归年依据** 建安四年刘备离曹控制去小沛的异说，不能与曹操派遣说都当真实事件。

[199年第24条](../../years/ce-0101-0200/ce-0199.md#sgz032-p-015-1)。

**裴松之驳刘备种菜出逃说** 裴松之认为刘备是曹操派遣去拦截袁术，郭嘉等反对而未获采纳；故胡冲所记种菜出逃不实。

**归年依据** 文献校辨，刘备实际离许过程见199正文。

<a id="pei-042-1"></a>

> 魏書曰備聞曹公薨遣掾韓冉奉書弔幷致賻贈之禮文帝惡其因䘮求好勑荆州刺史斬冉絶使命

**《魏书》记刘备遣韩冉致吊、曹丕命斩** 曹操死后，刘备遣韩冉奉书吊丧、致赠，曹丕以其求好，命荆州刺史斩韩冉绝使。

**归年依据** 曹操黄初前建安二十五年春卒，《武帝纪》参见；杀韩冉只记为魏书说法。

<a id="pei-042-2"></a>

**《典略》记韩冉止上庸、魏廷答书** 《典略》称韩冉携吊书和锦布，称病停在上庸，书由上庸上达，正逢曹丕受禅，魏廷赐答拟引致。

**归年依据** 文本以220十月受禅为定位，与《魏书》直接斩使不同。后接备得报书称制须另年。

**归年依据** 本传刘备221四月登基；裴注书为两事相承，不能直接推为答书为唯一动因。

## 047｜刘备临终遗诏论病及勉励刘禅

维基文库四库本原行 20—20。附见[正文 L1676](../本地分卷/三国志/三国志-卷032.md#l1676)。

<a id="pei-047-1"></a>

> 諸葛亮集載先主遺詔勑後主曰朕初疾但下痢耳後轉雜他病殆不自濟人五十不稱夭年已六十有餘何所復恨不復自傷但以卿兄弟為念射君到説丞相歎卿智量甚大増修過於所望審能如此吾復何憂勉之勉之勿以惡小而為之勿以善小而不為惟賢惟徳能服於人汝父徳薄勿效之

**刘备临终遗诏论病及勉励刘禅** 《诸葛亮集》载刘备说初患下痢，后病势重，自知难愈，只念诸子。使臣转诸葛亮夸刘禅有长进，刘备勉以勿因善小而不为、勿因恶小而为。

**归年依据** 章武三年四月刘备病危、临终时；所说下痢为先前病情。

[223年第2条](../../years/ce-0201-0300/ce-0223.md#sgz032-p-047-1)。

<a id="pei-047-2"></a>

> 可讀漢書禮記閑暇歴觀諸子及六韜商君書益人意智聞丞相為寫申韓管子六韜一通已畢未送道亡可自更求聞逹

**刘备遗命刘禅读诸书** 刘备劝刘禅读《汉书》《礼记》及诸子兵法；诸葛亮原抄申、韩、管子等，路上遗失，可另寻求。

**归年依据** 同一临终遗诏。

[223年第2条](../../years/ce-0201-0300/ce-0223.md#sgz032-p-047-2)。

<a id="pei-047-3"></a>

> 臨終時呼魯王與語吾亡之後汝兄弟父事丞相令卿與丞相共事而已

**刘备告鲁王兄弟父事诸葛亮** 刘备临终又召鲁王刘永，嘱其兄弟应视诸葛亮如父。

**归年依据** 章武三年四月临终，对鲁王另一次交代。

[223年第2条](../../years/ce-0201-0300/ce-0223.md#sgz032-p-047-3)。

## 048｜《神仙传》叙刘备伐吴前问李意其

维基文库四库本原行 20—20。附见[正文 L1679](../本地分卷/三国志/三国志-卷032.md#l1679)。

<a id="pei-048-1"></a>

> 葛洪神仙傳曰仙人李意其蜀人也傳世見之云是漢文帝時人先主欲伐吳遣人迎意其意其到先主禮敬之問以吉凶意其不荅而求紙筆畫作兵馬器仗數十紙已便一一以手裂壊之又畫作一大人掘地埋之便徑去

**《神仙传》叙刘备伐吴前问李意其** 葛洪称李意其是蜀人，相传活自汉文帝。刘备拟伐吴时礼请问吉凶，李意其不答，以画兵器撕纸、画人埋地比示。

**归年依据** 章武元年刘备东征前传说，年代来自传说所托事件，汉文帝时仙人说不能当事实。

[221年第57条](../../years/ce-0201-0300/ce-0221.md#sgz032-p-048-1)。

<a id="pei-048-2"></a>

> 先主大不喜而自出軍征吳大敗還忿恥發病死衆人乃知其意其畫作大人而埋之者即是言先主死意

**《神仙传》借刘备败亡解释画谜** 本注说刘备不悦而出兵，败归后因愤而病死，人们才把埋画像解为预言刘备死。

**归年依据** 传说把221出兵、222败、223亡合叙，三事已各入正文；作者推病因不另立确实史事。

[《神仙传》借刘备败亡解释画谜（时期）](../../years/ce-0201-0300/时期-三国志卷032-先主传纪年待考.md#period-sgz032-p-048-2)。

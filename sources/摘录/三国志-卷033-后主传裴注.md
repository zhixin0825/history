## 001｜《礼记》释册皇太子文“一物而三善”

维基文库四库本原行 11—11。附见[正文 L1683](../本地分卷/三国志/三国志-卷033.md#l1683)。

<a id="pei-001-1"></a>

> 禮記曰行一物而三善者惟世子而已其齒於學之謂也鄭玄曰物猶事也

**《礼记》释册皇太子文“一物而三善”** 裴注引《礼记》说世子在学中按年龄同列，从一事得三善。郑玄释“物”即“事”。

**归年依据** 本注附于章武元年五月辛巳册太子；礼经及郑注本身无事件年。

[221年第32条](../../years/ce-0201-0300/ce-0221.md#sgz033-p-001-1)。

## 002｜《魏略》借小沛战败起叙刘禅离散

维基文库四库本原行 11—11。附见[正文 L1683](../本地分卷/三国志/三国志-卷033.md#l1683)。

<a id="pei-002-1"></a>

> 魏畧曰初偹在小沛不意曹公卒至遑遽棄家屬後奔荆州禪時年數嵗竄匿随人西入漢中為人所賣

**《魏略》借小沛战败起叙刘禅离散** 《魏略》称曹操突然到小沛，刘备仓促弃家，后来投奔荆州，刘禅则辗转入汉中被卖。

**归年依据** 曹操破小沛据《武帝纪》《先主传》为建安五年。奔荆州是其后，刘禅失散是裴松之明确驳斥的异说。只与既有小沛战事互证。

[200年第13条](../../years/ce-0101-0200/ce-0200.md#sgz033-p-002-1)。

<a id="pei-002-2"></a>

> 及建安十六年關中破亂扶風人劉括避亂入漢中買得禅問知其良家子遂飬為子與娶婦生一子

**《魏略》称刘括入汉中获刘禅** 《魏略》说关中战乱时扶风刘括避入汉中，买下刘禅并抚养，替他娶妻生子。

**归年依据** 故事自称建安十六年，《武帝纪》同年有马超、韩遂之战，不能因此证实刘禅身世故事；婚娶生子亦未标明当在本年。

[211年第1条](../../years/ce-0201-0300/ce-0211.md#sgz033-p-002-2)。

<a id="pei-002-3"></a>

> 初禅與偹相失時識其父字玄徳比舍人有姓簡者及偹得益州而簡為將軍備遣簡到漢中舍都邸禅乃詣簡簡相檢訊事皆符驗簡喜以語張魯魯乃洗沐送詣益州備乃立以為太子

**《魏略》称张鲁验明刘禅身份并送还益州** 《魏略》说刘禅少时记得父字和简氏，刘备取得益州后派姓简的使者到汉中，认出刘禅，张鲁送其归蜀，刘备立为太子。

**归年依据** 故事称在刘备得益州后、立太子前，部分又与张鲁建安二十年降曹相冲突。全段为异说，无确年。

[《魏略》称张鲁验明刘禅身份并送还益州（时期）](../../years/ce-0201-0300/时期-三国志卷033-后主传纪年待考.md#period-sgz033-p-002-3)。

<a id="pei-002-4"></a>

> 初備以諸葛亮為太子太傅及禅立以亮為丞相委以諸事謂亮曰政由葛氏祭則寡人亮亦以禪未閑於政遂總内外

**《魏略》说诸葛亮受托总内外政务** 《魏略》称刘备先任诸葛亮为太子太傅，刘禅继位后以丞相委国政，说葛氏掌政、自己祭祀，诸葛亮遂总内外。

**归年依据** 任丞相据本书《诸葛亮传》在刘备称帝时，太子太傅无同代依据；上文把不同时期交叙，声音依《魏略》记录。

[《魏略》说诸葛亮受托总内外政务（时期）](../../years/ce-0201-0300/时期-三国志卷033-后主传纪年待考.md#period-sgz033-p-002-4)。

<a id="pei-002-5"></a>

> 臣松之案二主妃子傳曰後主生於荆州後主傳云初即帝位年十七則建安十二年生也

**刘禅在荆州出生** 裴松之将甘皇后随刘备入荆州生子和刘禅即位时年十七相核，得建安十二年。

**归年依据** 223即位十七岁，以虚岁回推207；整书TXT的L1683误混入同段后半。

[207年第20条](../../years/ce-0201-0300/ce-0207.md#sgz033-p-002-5)。

<a id="pei-002-6"></a>

> 十三年敗於長阪備棄妻子走趙雲傳曰雲身抱弱子以免即後主也如此備與禅未嘗相失也

**赵云于长坂保护刘禅并未失散** 裴松之引《赵云传》证明长坂败后赵云抱幼弱刘禅脱难，刘备父子并未失散。

**归年依据** 建安十三年长坂见《先主传》《赵云传》；整书TXT L1683误混入同注。

[208年第23条](../../years/ce-0201-0300/ce-0208.md#sgz033-p-002-6)。

<a id="pei-002-7"></a>

> 又諸葛亮以禅立之眀年領益州牧其年與主簿杜㣲書曰朝廷今年十八與禪傳相應理當非虗

**诸葛亮致杜微书以刘禅十八岁** 裴松之据刘禅即位次年诸葛亮致杜微书称“朝廷今年十八”，认为刘禅生年可以互证。

**归年依据** 建兴元年的次年为224年；《杜微传》同一封书。孔明领益州牧这项时间，正文《诸葛亮传》系建兴元年，不能由该注统作224任命。

[224年第18条](../../years/ce-0201-0300/ce-0224.md#sgz033-p-002-7)。

<a id="pei-002-8"></a>

> 而魚豢云備敗扵小沛禪時年始生及奔荆州能識其父字玄徳計當五六嵗備則敗扵小沛時建安五年也至禪初立首尾二十四年禪應過三十矣以事相驗理不得然此則魏畧之妄説乃至二百餘言異也又案諸書記及諸葛亮集亮亦不為太子太傅

**裴松之驳小沛失子和诸葛亮为太子太傅** 裴松之指鱼豢所云幼年、虚岁与200年小沛至223年即位的年距不合，并查书与集均无诸葛亮任太子太傅。

**归年依据** 属编注者对几个年份和官位的互校。四库本末称过“三十”，整书TXT仓本称过“二十”，依来源分别保留，不以异数字为实龄。

[裴松之驳小沛失子和诸葛亮为太子太傅（时期）](../../years/ce-0201-0300/时期-三国志卷033-后主传纪年待考.md#period-sgz033-p-002-8)。

## 003｜《魏氏春秋》记常房查朱褒与遭杀

维基文库四库本原行 12—12。附见[正文 L1684](../本地分卷/三国志/三国志-卷033.md#l1684)。

<a id="pei-003-1"></a>

> 魏氏春秋曰初益州從事常房行部聞褒將有異志收其主簿按問殺之襃怒攻殺房誣以謀反諸葛亮誅房諸子徙其四弟於越巂欲以安之

**《魏氏春秋》记常房查朱褒与遭杀** 常房行部时查朱褒的主簿并杀之，朱褒怒而杀常房，诬以谋反；注又称诸葛亮为安抚朱褒杀常房诸子、徙其弟。

**归年依据** 在朱褒建兴元年夏公开叛乱前，常房遭杀与所谓处置家属无独立年次，末有裴松之驳斥。

[《魏氏春秋》记常房查朱褒与遭杀（时期）](../../years/ce-0201-0300/时期-三国志卷033-后主传纪年待考.md#period-sgz033-p-003-1)。

<a id="pei-003-2"></a>

> 襃猶不悛改遂以郡叛應雍闓

**牂牁太守朱褒据郡反蜀** 朱褒仍据郡作乱，响应雍闿。

**归年依据** 本传建兴元年夏载朱褒起兵，《通鉴》卷070同归223。

[223年第55条](../../years/ce-0201-0300/ce-0223.md#sgz033-p-003-2)。

<a id="pei-003-3"></a>

> 臣松之案以為房為襃所誣執政所宜澄察安有妄殺不辜以悦奸慝斯殆妄矣

**裴松之驳诸葛亮妄杀常房诸子之说** 裴松之说常房为朱褒所诬，执政者应该查明，不应滥杀无辜以讨好奸恶，因而质疑《魏氏春秋》。

**归年依据** 后代文本批评，无前代事件日期。

[裴松之驳诸葛亮妄杀常房诸子之说（时期）](../../years/ce-0201-0300/时期-三国志卷033-后主传纪年待考.md#period-sgz033-p-003-3)。

## 005｜刘禅诏诸葛亮出师称汉魏兴亡

维基文库四库本原行 14—14。附见[正文 L1688](../本地分卷/三国志/三国志-卷033.md#l1688)。

<a id="pei-005-1"></a>

> 諸葛亮集載禅三月下詔曰朕聞天地之道福仁而祻滛善積者昌惡積者䘮古今常數也是以湯武修徳而王桀紂極暴而亡曩者漢祚中㣲網漏凶慝董卓造難震蕩京畿曹操階祻竊執天衡殘剥海内懐無君之心子丕孤竪敢尋亂階盗㨿神器更姓改物世濟其凶當此之時皇極幽昧天下無主則我帝命隕越於下昭烈皇帝體明叡之徳光演文武應乾坤之運出身平難經營四方人鬼同謀百姓與能兆民欣戴奉順符䜟建位易號丕承天序補弊興衰存復祖業膺誕皇綱不墜於地萬國未静早世遐殂

**刘禅诏诸葛亮出师称汉魏兴亡** 《诸葛亮集》记三月诏，以商周王朝兴替为例，谴责董卓和曹氏，称刘备承继汉室并叙其死。

**归年依据** 挂本传建兴五年春出屯汉中；引诏仅注明三月，其中刘备与曹氏是追叙。

[227年第19条](../../years/ce-0201-0300/ce-0227.md#sgz033-p-005-1)。

<a id="pei-005-2"></a>

> 朕以㓜冲繼統鴻基未習保傅之訓而膺祖宗之重六合壅否社稷不建永惟所以念在匡救光載前緒未有攸濟朕甚懼焉是以夙興夜寐不敢自逸每從菲薄以益國用勸分務穡以阜民財授方任能以參其聴斷私降意以飬将士欲奮剱長驅指討凶逆朱旗未舉而丕復隕丧斯所謂不然我薪而自焚也

**刘禅诏自叙继位后务农用士** 刘禅说自己幼而继统，节省供用、劝农、任贤和抚养军士，意欲讨魏，出军前魏文帝已死。

**归年依据** 建兴五年出师诏；曹丕死属226，此是为下一年诏文提供先后证据。

[227年第19条](../../years/ce-0201-0300/ce-0227.md#sgz033-p-005-2)。

<a id="pei-005-3"></a>

> 殘類餘醜又支天禍恣睢河洛阻兵未弭諸葛丞相弘毅忠壯忘身憂國先帝託以天下以朂朕躬今授之以旄鉞之重付之以專命之權統領歩騎二十萬衆董督元戎龔行天伐除患寜亂克復舊都在此行也昔項籍縂一彊衆跨州兼土所務者大然卒敗垓下死於東城宗族如焚為笑千載皆不以義陵上虐下故也今賊傚尤天人所怨奉時宜速庻憑炎精祖宗威靈相助之福所向必克

**刘禅授诸葛亮旄钺，命进兵复都** 诏授诸葛亮专命之权、令领步骑二十万出征，并以项羽自兴自败为鉴，宣称战事在于克复旧都。

**归年依据** 建兴五年屯汉中一事；二十万属诏书表述，实到汉中兵额另无证据。

[227年第19条](../../years/ce-0201-0300/ce-0227.md#sgz033-p-005-3)。

<a id="pei-005-4"></a>

> 吴王孫權同恤灾患潛軍合謀犄角其後涼州諸國王各遣月支康居胡侯支富康植䓁二十餘人詣授節度大軍北出便欲率將兵馬奮戈先驅天命既集人事又至師貞勢并必無敵矣

**刘禅诏称吴可合谋、凉州及远方诸王送人** 诏说吴王孙权与蜀合谋策应，凉州诸部王派月支、康居等人来受节度，愿在北出时率兵前驱。

**归年依据** 同一227年出师诏；所称各方最初送人与会谈确时无法再分年。

[227年第19条](../../years/ce-0201-0300/ce-0227.md#sgz033-p-005-4)。

<a id="pei-005-5"></a>

> 夫王者之兵有征無戰尊而且義莫敢抗也故鳴條之役軍不血刄牧野之師啇人倒戈今旍麾首路其所經至亦不欲窮兵極武有能棄邪從正簞食壺漿以迎王師者國有常典封寵大小各有品限及魏之宗族枝葉中外有能規利害審逆順之數来詣降者皆原除之昔輔果絶親於智氏而蒙全宗之福微子去殷項伯歸漢皆受茅土之慶此前世之明驗也若其迷沉不返将助亂人不式王命戮及妻孥罔有攸赦廣宣恩威貸其元帥弔其殘民他如詔書律令丞相其露布天下使稱朕意焉

**刘禅诏布告进兵赏降与严惩拒命** 诏以鸣条、牧野等史事申明王师，列出迎接及归降者所受封赏、拒命者惩处，命诸葛亮公布天下。

**归年依据** 同一建兴五年三月出师文书，古代典故无须作本卷新年史事。

[227年第19条](../../years/ce-0201-0300/ce-0227.md#sgz033-p-005-5)。

## 007｜江阳到江州之间群鸟渡江坠水

维基文库四库本原行 18—18。附见[正文 L1692](../本地分卷/三国志/三国志-卷033.md#l1692)。

> 漢書春秋曰冬十月江陽至江州有鳥從江南飛渡江北不能逹堕水死者以千數

**江阳到江州之间群鸟渡江坠水** 《汉书春秋》说十月江阳至江州间，许多鸟从江南往江北飞渡，中途坠水大量死亡。

## 009｜《魏略》记蒋琬死后刘禅亲理国事

维基文库四库本原行 30—30。附见[正文 L1706](../本地分卷/三国志/三国志-卷033.md#l1706)。

## 015｜诸葛亮与刘备谈赦免，《华阳国志》说法

维基文库四库本原行 44—44。附见[正文 L1730](../本地分卷/三国志/三国志-卷033.md#l1730)。

<a id="pei-015-1"></a>

> 華陽國志曰丞相亮時有言公惜赦者亮答曰治世以大徳不以小恵故匡衡吴漢不願為赦先帝亦言吾周旋陳元方鄭康成間每見啟告治亂之道悉矣曽不語赦也若劉景升季玉父子嵗嵗赦宥何益於治

**诸葛亮与刘备谈赦免，《华阳国志》说法** 诸葛亮答责其吝赦者，以匡衡和吴汉之例说明治理不靠小惠；又引刘备说陈纪、郑玄谈治乱时未以赦为法，刘表、刘璋年年赦也未曾有益。

**归年依据** 统摄刘备和诸葛亮两阶段言论，无可核定的对白年月。

[诸葛亮与刘备谈赦免，《华阳国志》说法（时期）](../../years/ce-0201-0300/时期-三国志卷033-后主传纪年待考.md#period-sgz033-p-015-1)。

<a id="pei-015-2"></a>

> 臣松之以為赦不妄下誠為可稱至於年名不易猶所未逹案建武建安之號皆久而不改未聞前史以為美談經載十二盖何足云豈别有他意求之未至乎亮歿後延熙之號數盈二十兹制漸虧事又不然也

**裴松之称许慎赦，驳久不改元的评论** 裴松之同意慎赦可称，但举建武、建安久未改元及蜀延熙二十年，指出沿用年号超过十二年不足为美，且与诸葛亮身后不久改元之论不合。

**归年依据** 为裴松之驳陈寿的跨年史评；实际延熙238至257，景耀258开始，可由本传复核。

[裴松之称许慎赦，驳久不改元的评论（时期）](../../years/ce-0201-0300/时期-三国志卷033-后主传纪年待考.md#period-sgz033-p-015-2)。

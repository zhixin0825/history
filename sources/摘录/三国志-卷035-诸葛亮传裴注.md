## 001｜诸葛玄获授豫章的异说

维基文库四库本原行 11—11。附见[正文 L1752](../本地分卷/三国志/三国志-卷035.md#l1752)。

<a id="pei-001-1"></a>

> 獻帝春秋曰初豫章太守周術病卒劉表上諸葛玄為豫章太守治南昌漢朝聞周術死遣朱皓代玄皓從揚州太守劉繇求兵擊玄玄退屯西城皓入南昌

**诸葛玄获授豫章的异说** 《献帝春秋》称周术病死，由刘表上奏以诸葛玄接豫章，治南昌。朱皓应汉命至，取刘繇军援，诸葛玄退西城。

**归年依据** 任玄年份未载，授任者与正文袁术不同，去向也与依刘表说有异。

[诸葛玄获授豫章的异说（时期）](../../years/ce-0201-0300/时期-三国志卷035-诸葛亮传纪年待考（1）.md#period-sgz035-p-001-1)。

<a id="pei-001-2"></a>

> 建安二年正月西城民反殺玄送首詣繇此書所云與本傳不同

**《献帝春秋》称诸葛玄被西城人杀** 西城居民反，杀诸葛玄，送首刘繇。

**归年依据** 引书明建安二年正月。本传仅称玄依刘表后卒，不取同一死法为确定事实。

## 003｜崔州平为崔烈之子

维基文库四库本原行 11—11。附见[正文 L1752](../本地分卷/三国志/三国志-卷035.md#l1752)。

> 按崔氏譜州平太尉烈子均之弟也

**崔州平为崔烈之子** 《崔氏谱》记崔州平家属。

**归年依据** 父子兄弟无单年。

[崔州平为崔烈之子（时期）](../../years/ce-0201-0300/时期-三国志卷035-诸葛亮传纪年待考（1）.md#period-sgz035-p-003-1)。

<a id="pei-003-2"></a>

> 魏畧曰亮在荆州以建安初與潁川石廣元徐元直汝南孟公威等俱㳺學三人務於精熟而亮獨觀其大畧每晨夜從容常抱膝長嘯而謂三人曰卿三人仕進可至刺史郡守也三人問其所至亮但笑而不言

**诸葛亮与石广元、徐庶、孟公威游学** 《魏略》谓三人精读，诸葛亮看要旨，自信但不明言自己的仕途。

**归年依据** 仅称建安初，具体一起游学的时间未见。

[诸葛亮与石广元、徐庶、孟公威游学（时期）](../../years/ce-0201-0300/时期-三国志卷035-诸葛亮传纪年待考（1）.md#period-sgz035-p-003-2)。

> 後公威思鄉里欲北歸亮謂之曰中國饒士大夫遨逰何必故鄉邪

**诸葛亮劝孟公威不要只思故乡** 孟公威想北归，亮说中原士大夫多，可遨游择地。

**归年依据** 谈话无年月。

[诸葛亮劝孟公威不要只思故乡（时期）](../../years/ce-0201-0300/时期-三国志卷035-诸葛亮传纪年待考（1）.md#period-sgz035-p-003-3)。

<a id="pei-003-4"></a>

> 臣松之以為魏畧此言謂諸葛亮為公威計者可也若謂兼為已言可謂未達其心矣老氏稱知人者智自知者明凡在賢達之流固必兼而有焉以諸葛亮之鑒識豈不能自審其分乎夫其髙吟俟時情見乎言志氣所存既已定於其始矣若使㳺歩中華騁其龍光豈夫多士所能沈翳哉委質魏氏展其噐能誠非陳長文司馬仲達所能頡頑而况於餘哉茍不患功業不就道之不行雖志恢宇宙而終不北向者葢以權御已移漢祚將傾方將翊贊宗傑以興微繼絶克復為己任故也豈其區區利在邉鄙而已乎此相如所謂鵾鵬已翔於遼廓而羅者猶視於藪澤者矣公威名建在魏亦貴達

**裴松之认为诸葛亮并无仕魏之心** 驳将为孟公威之谋视为亮的自计，认为亮自知才志，以恢复汉室为己任，因而不北向；补孟公威在魏亦显达。

**归年依据** 为刘宋史评，评论未定年。

[裴松之认为诸葛亮并无仕魏之心（时期）](../../years/ce-0201-0300/时期-三国志卷035-诸葛亮传纪年待考（1）.md#period-sgz035-p-003-4)。

## 005｜《魏略》及《九州春秋》记诸葛亮主动求见

维基文库四库本原行 11—11。附见[正文 L1755](../本地分卷/三国志/三国志-卷035.md#l1755)。

<a id="pei-005-1"></a>

> 魏畧曰劉備屯於樊城是時曺公方定河北亮知荆州次當受敵而劉表性緩不曉軍事亮乃北行見備備與亮非舊又以其年少以諸生意待之坐集既畢衆賓皆去而亮獨㽞備亦不問其所欲言

**《魏略》及《九州春秋》记诸葛亮主动求见** 刘备屯樊城，诸葛亮判断荆州将受曹操攻击，北行见刘备，起先被以年轻学者相待。

**归年依据** 异于207年新野三顾，另一传所称曹操方定河北范围较宽，未给独立确年。

[《魏略》及《九州春秋》记诸葛亮主动求见（时期）](../../years/ce-0201-0300/时期-三国志卷035-诸葛亮传纪年待考（1）.md#period-sgz035-p-005-1)。

<a id="pei-005-2"></a>

> 備性好結眊時適有人以髦牛尾與備者備因手自結之亮乃進曰明將軍當復有逺志但結眊而已邪備知亮非常人也乃投眊而言曰是何言與我聊以忘憂耳

**《魏略》记诸葛亮借刘备结眊发问** 刘备用牦牛尾结眊，诸葛亮说应有远志；刘备答为忘忧。

**归年依据** 同次樊城相见的异说。

[《魏略》记诸葛亮借刘备结眊发问（时期）](../../years/ce-0201-0300/时期-三国志卷035-诸葛亮传纪年待考（1）.md#period-sgz035-p-005-2)。

<a id="pei-005-3"></a>

> 亮遂言曰將軍度劉鎮南孰與曺公邪備曰不及亮乂曰將軍自度何如也備曰亦不如曰今皆不及而將軍之衆不過數千人以此待敵得無非計乎備曰我亦愁之當若之何亮曰今荆州非少人也而著籍者寡平居發調則人心不恱可語鎮南令國中凡有㳺戸皆使自實因録以益衆可也備從其計故衆遂彊備由此知亮有英畧乃以上客禮之

**《魏略》记诸葛亮建议荆州登记游户** 诸葛亮问刘备和刘表与曹操相较，指出刘备兵少；建议让游户自陈入籍以增人数，刘备听从。

**归年依据** 异说同一场面，办法确日不可追。

[《魏略》记诸葛亮建议荆州登记游户（时期）](../../years/ce-0201-0300/时期-三国志卷035-诸葛亮传纪年待考（1）.md#period-sgz035-p-005-3)。

<a id="pei-005-4"></a>

> 九州春秋所言亦如之臣松之以為亮表云先帝不以臣卑鄙猥自枉屈三顧臣於草廬之中諮臣以當世之事則非亮先詣備明矣雖聞見異辭各生彼此然乖背至是亦良為可怪

**裴松之以先表质疑亮先见备** 《九州春秋》同《魏略》，裴松之以《出师表》自述三顾辨其与陈寿本传不合。

**归年依据** 评论属刘宋，所论相见以207年通鉴编次为参照。

[裴松之以先表质疑亮先见备（时期）](../../years/ce-0201-0300/时期-三国志卷035-诸葛亮传纪年待考（1）.md#period-sgz035-p-005-4)。

## 007｜张昭向孙权推荐诸葛亮，诸葛亮辞留

维基文库四库本原行 11—11。附见[正文 L1757](../本地分卷/三国志/三国志-卷035.md#l1757)。

<a id="pei-007-1"></a>

> 袁子曰張子布薦亮於孫權亮不肯㽞人問其故曰孫將軍可謂人主然觀其度能賢亮而不能盡亮吾是以不㽞

**张昭向孙权推荐诸葛亮，诸葛亮辞留** 《袁子》称张昭荐诸葛亮，亮说孙权虽是人主，却不能尽其所长，故不留。

**归年依据** 原注附柴桑使吴，《袁子》说法依208年场景注明；裴松之明驳。

[208年第49条](../../years/ce-0201-0300/ce-0208.md#sgz035-p-007-1)。

<a id="pei-007-2"></a>

> 臣松之以為袁孝尼著文立論甚重諸葛之為人至如此言則失之殊逺觀亮君臣相遇可謂希世一時終始之分誰能間之寧有中違斷金甫懐擇主設使權盡其量便當翻然去就乎葛生行已豈其然哉關羽為曹公所獲遇之甚厚可謂能盡其用矣猶義不背本曽謂孔明之不若雲長乎

**裴松之驳诸葛亮有择主之意** 认为亮与刘备关系忠贞持久，举关羽得曹操厚遇仍不背刘备反问其说。

**归年依据** 裴松之论辨无确年。

## 009｜晋初郭冲向扶风王等论诸葛亮

维基文库四库本原行 11—11。附见[正文 L1758](../本地分卷/三国志/三国志-卷035.md#l1758)。

<a id="pei-009-1"></a>

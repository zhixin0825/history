## 001｜蜀记载关羽求娶秦宜禄妻

维基文库四库本原行 11—11。附见[正文 L1792](../本地分卷/三国志/三国志-卷036.md#l1792)。

<a id="pei-001-1"></a>

> 蜀記曰曹公與劉備圍吕布於下邳關羽啓公布使秦宜祿行求救乞娶其妻公許之臨破又屢啓於公公疑其有異色先遣迎㸔因自留之羽心不自安此與魏氏春秋所説異也

**蜀记载关羽求娶秦宜禄妻** 围下邳时关羽数次请娶吕布求援使秦宜禄的妻子，曹操派人先迎而自留，关羽不安。

**归年依据** 《蜀记》明接建安三年曹操、刘备围下邳，裴松之标有《魏氏春秋》记述之别。

[198年第4条](../../years/ce-0101-0200/ce-0198.md#sgz036-p-001-1)。

> 傅子曰遼欲白太祖恐太祖之殺羽不白非事君之道乃歎曰公居父也羽兄弟耳遂白之太祖曰事君不〔四库字图2982〕其夲天下義士也度何時能去遼曰羽受公恩必立效報公而後去也

**傅子记张辽以关羽去意禀告曹操** 张辽不忍关羽被杀，又不愿瞒主，终于告知，曹操赞关羽能事君不忘根本，问何时去。

## 005｜蜀记记许地狩猎时关羽建议杀曹操

维基文库四库本原行 11—11。附见[正文 L1794](../本地分卷/三国志/三国志-卷036.md#l1794)。

<a id="pei-005-1"></a>

> 蜀記曰初劉備在許與曹公共獵獵中衆散羽勸備殺公備不從

**蜀记记许地狩猎时关羽建议杀曹操** 关羽趁随从分散，劝刘备杀曹操，刘备未听。

**归年依据** 叙刘备在许，时间可约于198—199，狩猎和建议无确年。

[蜀记记许地狩猎时关羽建议杀曹操（时期）](../../years/ce-0201-0300/时期-三国志卷036-关张马黄赵传纪年待考.md#period-sgz036-p-005-1)。

<a id="pei-005-2"></a>

> 及至夏口飄颻江渚羽怒曰徃日獵中若從羽言可無今日之困備曰是時亦為國家惜之耳若天道輔正安知此不為福邪

**关羽在夏口提及错失诛曹机会** 蜀记说关羽以今困怨昔日不听，刘备答说曾为国家惜曹操。

**归年依据** 长坂后到夏口，建安十三年；话据《蜀记》。

[208年第22条](../../years/ce-0201-0300/ce-0208.md#sgz036-p-005-2)。

<a id="pei-005-3"></a>

> 臣松之以為備後與董承等結謀但事泄不克諧耳若為國家惜曹公其如此言何羽若果有此勸而備不肯從者将以曹公腹心親戚實繁有徒事不宿搆非造次所行曹雖可殺身必不免故以計而止何惜之有乎既徃之事故託為雅言耳

**裴松之辨刘备以国惜曹一说** 裴松之以董承共谋反证，认为即使关羽真曾建议，刘备也可能担心曹党报复，答话乃事后托辞。

**归年依据** 作者按断，跨许地狩猎、199筹谋至208。

[裴松之辨刘备以国惜曹一说（时期）](../../years/ce-0201-0300/时期-三国志卷036-关张马黄赵传纪年待考.md#period-sgz036-p-005-3)。

## 006｜典略谓孙权允援关羽，关羽反加斥责

维基文库四库本原行 11—11。附见[正文 L1796](../本地分卷/三国志/三国志-卷036.md#l1796)。

<a id="pei-006-1"></a>

> 典畧曰羽圍樊權遣使求助之勑使莫速進又遣主簿先致命於羽羽忿其淹遲又自已得于禁等乃罵曰狢子敢爾如使樊城㧞吾不能滅汝邪權聞之知其輕已偽手書以謝羽許以自徃

**典略谓孙权允援关羽，关羽反加斥责** 关羽围樊并得于禁后，责孙权故意迟缓，且扬言攻下樊城后对付孙权，孙权以书退让。

**归年依据** 219围樊城期间，仅为《典略》之说；裴松之明驳。

[219年第1条](../../years/ce-0201-0300/ce-0219.md#sgz036-p-006-1)。

<a id="pei-006-2"></a>

> 臣松之以為荆吴雖外睦而内相猜防故權之襲羽潜師宻發按吕蒙傳云伏精兵於〔四库字图557〕〔四库字图558〕之中使白衣摇櫓作啇賈服以此言之羽不求助於權權必不語羽當徃也若許相援助何故匿其形迹乎

**裴松之质疑孙权允援关羽说** 裴松之以《吕蒙传》白衣潜袭为证，反问若答应支援为何要隐蔽行踪。

**归年依据** 史家辨证与219荆州战事分读；图字按四库电子本。

## 008｜蜀记说孙权与部属议处关羽

维基文库四库本原行 11—11。附见[正文 L1796](../本地分卷/三国志/三国志-卷036.md#l1796)。

<a id="pei-008-1"></a>

> 蜀記曰權遣将軍擊羽獲羽及子平權欲活羽以敵劉曹左右曰狼子不可飬後必為害曹公不即除之自取大患乃議徙都今豈可生乃斬之

**蜀记说孙权与部属议处关羽** 《蜀记》称孙权欲留关羽对付刘备、曹操，经部属进言后斩关羽。

**归年依据** 本传建安二十四年遭擒并被杀；是否曾议释为注中异说。

[219年第8条](../../years/ce-0201-0300/ce-0219.md#sgz036-p-008-1)。

<a id="pei-008-2"></a>

> 臣松之按吴書孫權遣将潘璋逆斷羽走路羽至即斬且臨沮去江陵二三百里豈容不時殺羽方議其生死乎又云權欲活羽以敵劉曹此書不然可以絶智者之口

**裴松之据吴书记斩关羽经过反驳** 潘璋截路，关羽到临沮即被杀，且临沮离江陵数百里，裴松之认为无暇送去议处。

**归年依据** 史家按语，所评本事在219。

[裴松之据吴书记斩关羽经过反驳（时期）](../../years/ce-0201-0300/时期-三国志卷036-关张马黄赵传纪年待考.md#period-sgz036-p-008-2)。

<a id="pei-008-3"></a>

> 吴歴曰權送羽首於曹公以諸侯禮葬其屍骸

**吴历记孙权送关羽首往曹操** 吴方向曹操送首，用诸侯礼葬关羽身。

**归年依据** 《武帝纪》建安二十五年春正月，220，和擒斩建安二十四年十二月分开。

[220年第7条](../../years/ce-0201-0300/ce-0220.md#sgz036-p-008-3)。

## 012｜典略记马腾父母与早年

维基文库四库本原行 13—13。附见[正文 L1803](../本地分卷/三国志/三国志-卷036.md#l1803)。

<a id="pei-012-1"></a>

> 典畧曰騰字夀成馬援後也桓帝時其父字子碩嘗為天水蘭干尉後失官因留隴西與羌錯居家貧無妻遂娶羌女生騰騰少貧無産業常從鄣山中斫材木負販詣城市以自供給騰為人長八尺餘身體洪大靣鼻雄異而性賢厚人多敬之

**典略记马腾父母与早年** 父为天水兰干尉，失职后留陇西，娶羌女而生马腾。马腾年少砍柴谋生，性敦厚。

**归年依据** 父任职仅约汉桓帝时，世系、出生与少时经历无单一年。

[典略记马腾父母与早年（时期）](../../years/ce-0201-0300/时期-三国志卷036-关张马黄赵传纪年待考.md#period-sgz036-p-012-1)。

<a id="pei-012-2"></a>

> 靈帝末涼州刺史耿鄙任信奸吏民王國等及氐羌反叛州郡募發民中有勇力者欲討之騰在募中州郡異之署為軍行事典領部衆討賊有功拜軍司馬後以功遷偏將軍又遷征西将軍常屯汧隴之間

**耿鄙、王国等事与马腾应募** 马腾应募随州郡作战，获立军功并由军司马晋升。

**归年依据** 《后汉书·灵帝纪》187耿鄙讨叛与失利，注合叙应募至后续任迁，晋升月日未载。

[187年第5条](../../years/ce-0101-0200/ce-0187.md#sgz036-p-012-2)。

<a id="pei-012-3"></a>

> 初平中拜征東將軍是時西州少穀騰自表軍人多乏求就穀於池陽遂移屯長平岸頭而將王承等恐騰為己害乃攻騰營時騰近出無備遂破走西上

**马腾更号征东，西州乏粮时移屯** 马腾缺粮请求到池阳，移到长平岸头。王承等疑其不利，袭其营，马腾因无备退西。

**归年依据** 只明“初平中”范围190—193，其征东名号与正文192征西说不同。

[马腾更号征东，西州乏粮时移屯（时期）](../../years/ce-0201-0300/时期-三国志卷036-关张马黄赵传纪年待考.md#period-sgz036-p-012-3)。

<a id="pei-012-4"></a>

> 㑹三輔亂不復來東而與鎮西將軍韓遂結為異姓兄弟始甚相親後轉以部曲相侵又更為讐敵騰攻遂遂走合衆還攻騰殺騰妻子連兵不解

**马腾韩遂先为异姓兄弟，继而相攻** 马腾不再入三辅，与韩遂结兄弟，又因部曲彼此侵凌复成仇敌。马腾击韩遂，韩遂回兵杀其妻子。

**归年依据** 从初平末跨至建安初，结盟、交兵及家人遇害无明年。

[马腾韩遂先为异姓兄弟，继而相攻（时期）](../../years/ce-0201-0300/时期-三国志卷036-关张马黄赵传纪年待考.md#period-sgz036-p-012-4)。

<a id="pei-012-5"></a>

> 建安之初國家綱紀殆弛乃使司〔四库字图1452〕校尉鍾繇涼州牧韋瑞和觧之徵騰還屯槐里轉拜為前將軍假節封槐里侯北備胡宼東備白騎待士進賢矜救民命三輔甚安愛之

**钟繇、凉州州官调解，马腾屯槐里** 调解后马腾领军屯槐里，转任前将军并封侯，负责御胡白骑，三辅倚安。

**归年依据** 只指建安初年；《资治通鉴》卷065校凉州刺史韦端，注写韦瑞。

[钟繇、凉州州官调解，马腾屯槐里（时期）](../../years/ce-0201-0300/时期-三国志卷036-关张马黄赵传纪年待考.md#period-sgz036-p-012-5)。

<a id="pei-012-6"></a>

> 十五年徴為衛尉騰自見年老遂入宿衛

**典略谓马腾建安十五年征为卫尉** 马腾因年老入朝宿卫。

**归年依据** 《通鉴》卷065考异依《张既传》曹操将征荆州在208，推断“十五”为“十三”之讹；《典略》的210原文保留。

[208年第30条](../../years/ce-0201-0300/ce-0208.md#sgz036-p-012-6)。

<a id="pei-012-7"></a>

> 夏侯淵敗曹公争漢中地運米北山下數千萬囊黄忠以為可取雲兵隨忠取米忠過期不還雲将數十騎輕行出圍迎視忠等值曹公揚兵大出雲為公前鋒所擊方戰其大衆至勢偪遂前突其陣且闘且却公軍散已復合雲䧟敵還趣圍將張著被創雲復馳馬還營迎著公軍追至圍此時沔陽長張翼在雲圍内翼欲閉門拒守而雲入營更大開門偃旗息鼓公軍疑雲有伏兵引去雲擂鼔震天惟以戎弩於後射公軍公軍驚駭自相蹂踐墮漢水中死者甚多

**赵云于汉水掩护黄忠、据营设疑兵** 夏侯渊败后，黄忠拟取对方粮，过期未返。赵云出迎并救张著，再开营偃旗使曹军退却，继而用弓弩追击，敌兵相蹈。

**赵云箕谷退军亲自断后** 诸葛亮问邓芝部众退时何以未散，邓芝说赵云自己压阵断后，所以辎重、将士大抵完好。

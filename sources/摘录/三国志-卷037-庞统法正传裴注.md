## 001｜《襄阳记》称庞德公名诸葛亮卧龙、庞统凤雏、司马徽水镜

维基文库四库本原行 11—11。附见[正文 L1819](../本地分卷/三国志/三国志-卷037.md#l1819)。

<a id="pei-001-1"></a>

> 襄陽記曰諸葛孔明為卧龍龎士元為鳳雛司馬徳操為水鏡皆龎徳公語也徳公襄陽人孔明每至其家獨拜牀下徳公初不令止

**《襄阳记》称庞德公名诸葛亮卧龙、庞统凤雏、司马徽水镜** 《襄阳记》将诸葛亮、庞统、司马徽三个称誉归于庞德公，并记诸葛亮来访总敬拜于其床下。

**归年依据** 为襄阳地方人物称呼与交游，各称号最初使用无单一年。

[《襄阳记》称庞德公名诸葛亮卧龙、庞统凤雏、司马徽水镜（时期）](../../years/ce-0201-0300/时期-三国志卷037-庞统法正传纪年待考.md#period-sgz037-p-001-1)。

<a id="pei-001-2"></a>

> 徳操嘗造徳公值其渡沔上祀先人墓徳操徑入其室呼徳公妻子使速作黍徐元直向云有客當來就我與龎公譚其妻子皆羅列拜於堂下奔走供設須㬰徳公還直入相就不知何者是客也徳操年小徳公十歳兄事之呼作龎公故世人遂謂龎公是徳公名非也

**司马徽造访庞德公及“庞公”称谓** 司马徽来访时庞德公已渡沔水祭祖，司马徽径入其家吩咐待客。史家又说司马徽比庞德公小十岁，称其庞公而讹为名字。

**归年依据** 家事、称谓传闻无纪年。

[司马徽造访庞德公及“庞公”称谓（时期）](../../years/ce-0201-0300/时期-三国志卷037-庞统法正传纪年待考.md#period-sgz037-p-001-2)。

<a id="pei-001-3"></a>

> 徳公字山民亦有令名娶諸葛孔明小姊為魏黄門吏部郎早卒子渙字世文晋太康中為牂牁太守

**庞家与诸葛氏成婚及魏晋官历** 注在“庞公”称呼后述山民的声望、娶诸葛亮幼姊、出仕魏廷而早死，以及子庞涣在晋太康中为牂牁太守。

**归年依据** 太康为280–289；底本此处断作“徳公字山民”可能混淆父子，《襄阳耆旧记》所存相近叙法以山民为庞德公子。

[庞家与诸葛氏成婚及魏晋官历（时期）](../../years/ce-0201-0300/时期-三国志卷037-庞统法正传纪年待考.md#period-sgz037-p-001-3)。

<a id="pei-001-4"></a>

> 統徳公從子也少未有識者惟徳公重之年十八使徃見徳操徳操與語既而歎曰徳公誠知人此實盛徳也

**庞德公荐少年庞统见司马徽** 《襄阳记》说庞统是庞德公从子，十八岁时由其荐往见司马徽。司马徽与庞统谈后称赞。

**归年依据** 本传作“弱冠”，注为十八，谈见确年无载；不能用死亡年龄反复推定会面。

[庞德公荐少年庞统见司马徽（时期）](../../years/ce-0201-0300/时期-三国志卷037-庞统法正传纪年待考.md#period-sgz037-p-001-4)。

## 002｜庞统在昌门会陆绩、顾劭、全琮

维基文库四库本原行 11—11。附见[正文 L1819](../本地分卷/三国志/三国志-卷037.md#l1819)。

<a id="pei-002-1"></a>

> 張勃吴錄曰或問統曰如所目陸子為勝乎統曰駑馬雖精所致一人耳駑牛一日行三百里所致豈一人之重哉劭就統宿語因問卿名知人吾與卿孰愈統曰陶冶世俗甄綜人物吾不及卿論帝王之祕䇿攬倚伏之要最吾似有一日之長劭安其言而親之

**庞统在昌门会陆绩、顾劭、全琮** 张勃《吴录》载庞统用马快但只致一人、牛慢却负载重的比喻回应询问；顾劭随后以知人问题追问，庞统称品评人物不及顾而论帝王之策略胜。

**归年依据** 依本传210年送周瑜丧返西前在昌门会陆、顾、全，宿语与该行相连。

<a id="pei-003-1"></a>

> 蒋濟萬機論云許子将襃貶不平以拔樊子昭而抑許文休劉曄曰子昭拔自賈豎年至耳順退能守静進能不苟濟答曰子昭誠自長幼完潔然觀其臿齒牙樹頰胲吐唇吻自非文休敵也胲音改

**蒋济、刘晔谈许劭评价樊子昭和许靖** 蒋济说许劭抬举樊子昭而压低许靖，刘晔肯定樊的操行；蒋济仍认为樊的言语才力不能与许靖相比，注附“胲音改”。

**归年依据** 因庞统品题全琮引出的后论，不属于昌门会谈原时；蒋济、刘晔对谈无年。

<a id="pei-004-1"></a>

> 江表傳曰先主與統從容宴語問曰卿為周公瑾功曹孤到吴聞此人宻有白事勸仲謀相留有之乎在君為君卿其無隱統對曰有之備歎息曰孤時危急當有所求故不得不徃殆不免周瑜之手天下智謀之士所見畧同耳時孔明諫孤莫行其意獨篤亦慮此也孤以仲謀所防在北當頼孤為援故决意不疑此誠出於險塗非萬全之計也

**归年依据** 谈话无确时。《通鉴》卷066将赴京、周瑜及吕范劝留、刘备闻之列210；这里是以后宴谈追述。

## 005｜庞统劝刘备赴益州

维基文库四库本原行 11—11。附见[正文 L1820](../本地分卷/三国志/三国志-卷037.md#l1820)。

<a id="pei-005-1"></a>

> 九州春秋曰統説備曰荆州荒殘人物殫盡東有吴孫北有曹氏鼎足之計難以得志今益州國富民强戸口百萬四部兵馬所出必具寳貨無求於外今可權借以定大事備曰今指與吾為水火者曹操也操以急吾以寛操以暴吾以仁操以譎吾以忠每與操反事乃可成耳今以小故而失信義於天下者吾所不取也

**庞统劝刘备赴益州** 庞统认为荆州残破且受曹操、孙权挟制，可依益州人口、军马和财富立业，刘备以不能因小事失信作答。

**归年依据** 本传接庞统随刘备西入；《通鉴》卷066建安十六年亦同载此对答。

[211年第3条](../../years/ce-0201-0300/ce-0211.md#sgz037-p-005-1)。

<a id="pei-005-2"></a>

> 統曰權變之時固非一道所能定也兼弱攻昧五伯之事逆取順守報之以義事定之後封以大國何負於信今日不取終為人利耳備遂行

**庞统劝暂以权变、得益州后报刘璋** 庞统主张先弱其国再用礼义报之，事定厚封刘璋即不负信；劝刘备莫错失机会，刘备遂行。

**归年依据** 同一建安十六年谋入益州的对答，《通鉴》同载刘备从议。

[211年第3条](../../years/ce-0201-0300/ce-0211.md#sgz037-p-005-2)。

## 006｜习凿齿评论庞统在涪宴进谏

维基文库四库本原行 11—11。附见[正文 L1821](../本地分卷/三国志/三国志-卷037.md#l1821)。

<a id="pei-006-1"></a>

> 習鑿齒曰夫霸王者必體仁義以為夲杖信順以為宗一物不具則其道乖矣今劉備襲奪璋土權以濟業負信違情徳義具愆雖功由是隆宜大傷其敗譬斷手全軀何樂之有龎統懼斯言之泄宣知其君之必悟故衆中匡其失而不修常謙之道矯然太當盡其謇諤之風夫上失而能正是冇臣也納勝而無執是從理也有臣則陛隆堂髙從理則羣䇿必舉一言而三善兼明暫諫而義彰百代可謂達乎大體矣若惜其小失而廢大益矜此過言自絶逺讜能成業濟務者未之有也

**习凿齿评论庞统在涪宴进谏** 习凿齿说刘备用权术夺刘璋之地，有损信义，庞统当众直谏和刘备后来纳言有益于君臣。

**归年依据** 东晋习凿齿的追评，所议涪宴在建安十七年末起兵之后，宴年不足证。

[习凿齿评论庞统在涪宴进谏（时期）](../../years/ce-0201-0300/时期-三国志卷037-庞统法正传纪年待考.md#period-sgz037-p-006-1)。

<a id="pei-006-2"></a>

> 臣松之以為謀襲劉璋計雖出於統然違義成功夲由詭道心既内疚則歡情自戢故聞備稱樂之言不覺率爾而對也備宴酣失時事同樂祸自比武王曾無愧色此備有非而統無失其云君臣俱失盖分謗之言耳習氏所論雖大㫖無乖然推演之辭近為流宕也

**裴松之论庞统分谤并评习凿齿** 裴松之说献策虽出庞统，听刘备称乐而直言并无失，事后说君臣均失只是分担指责；习氏大意可取而推论稍远。

**归年依据** 史家追评，无独立史事年。

## 007｜庞林之妻习氏在曹操取荆州时与夫失散

维基文库四库本原行 11—11。附见[正文 L1822](../本地分卷/三国志/三国志-卷037.md#l1822)。

<a id="pei-007-1"></a>

**庞林之妻习氏在曹操取荆州时与夫失散** 《襄阳记》记庞林妻是习祯之妹，曹操攻破荆州后夫妻分离，习氏独自养幼女十余年。

**归年依据** 《武帝纪》建安十三年曹操进江陵，史源未明夫妻已在哪一地失散；长年抚养跨越208至222。

## 010｜孙盛批评礼遇许靖

<a id="pei-011-1"></a>

> 孫盛曰夫威福自下亡家害國之道刑縱於寵毁政亂理之源安可以功臣而極其陵肆嬖幸而藉其國柄者哉故顛頡雖勤不免違命之刑楊千雖親猶加亂行之戮夫豈不愛王憲故也諸葛氏之言於是乎失政刑矣

**归年依据** 史论述政刑；法正擅杀及有人请求约束无准确年月。

> 臣松之以為蜀與漢中其由唇齒也劉主之智豈不及此将計畧未展正先發之耳夫聼用嘉謀以成功業霸王之主誰不皆然魏武以為人所教亦豈劣哉此盖耻恨之餘辭非測實之常言也

## 013｜法正立于刘备前受矢，劝其一同退军

维基文库四库本原行 13—13。附见[正文 L1830](../本地分卷/三国志/三国志-卷037.md#l1830)。

<a id="pei-013-1"></a>

> 先主與曹公争勢有不便宜退而先主大怒不肯退無敢諫者矢下如雨正乃徃當先主前先主云孝直避箭正曰明公親當矢石况小人乎先主乃曰孝直吾與汝俱去遂退

**法正立于刘备前受矢，劝其一同退军** 一次刘备与曹操军争，局势不利而不肯退。法正站到他前面，称刘备既亲冒矢石，自己也不可避，刘备才同他后撤。

**归年依据** 注文无地名日月，所指可能是219汉中对峙，但《先主传》说曹操亲至阳平后刘备终不交锋，不能凭猜测归年或定位。

## 001｜《蜀记》载许靖自述避董卓之由

维基文库四库本原行 11—11。附见[正文 L1833](../本地分卷/三国志/三国志-卷038.md#l1833)。

<a id="pei-001-1"></a>

> 蜀記云靖後自表曰黨賊求生情所不忍守官自危死不成義竊念古人當難詭常權以濟其道

**《蜀记》载许靖自述避董卓之由** 许靖在后来表文中说，不忍助贼求生，也不愿守官冒死却不能成就义举，所以从权避难。

## 003｜裴松之评许靖因孙策渡江而入交州

维基文库四库本原行 11—11。附见[正文 L1835](../本地分卷/三国志/三国志-卷038.md#l1835)。

<a id="pei-003-1"></a>

> 臣松之以為孔子稱賢者避世其次避地盖貴其識見安危去就得所也許靖羇客㑹稽閭閻之士孫策之來於靖何為而乃泛萬里之海入疫癘之鄉致使尊弱塗炭百罹備經可謂自貽矣謀臣若斯難以言智孰若安時䖏順端拱吴越與張昭張紘之儔同保元吉者哉

**裴松之评许靖因孙策渡江而入交州** 裴松之引孔子谈避世避地，认为许靖作为会稽寓客，本可以像张昭、张纮一样留吴，不必远走海路导致亲人伤亡。

**归年依据** 对195年孙策渡江后移避的追评，不把南渡全程、亲人死亡都归渡江当年。

## 006｜王商声名及谏刘璋宜信任大臣

维基文库四库本原行 11—11。附见[正文 L1839](../本地分卷/三国志/三国志-卷038.md#l1839)。

<a id="pei-006-1"></a>

> 益州耆舊傳曰啇字文表廣漢人以才學稱聲問著於州里劉璋辟為治中從事是時王塗隔絶州之牧伯猶七國之諸侯也而璋懦弱多疑不能黨信大臣商奏記諫璋璋頗感悟

**王商声名及谏刘璋宜信任大臣** 《益州耆旧传》称广汉人王商字文表，刘璋辟为治中。王商见刘璋不信大臣而奏记劝谏，使之有所领悟。

**归年依据** 在刘璋领益州期间，受辟和进谏均无确年。

[王商声名及谏刘璋宜信任大臣（时期）](../../years/ce-0201-0300/时期-三国志卷038-许麋孙简伊秦传纪年待考.md#period-sgz038-p-006-1)。

<a id="pei-006-2"></a>

> 初韓遂與馬騰作亂關中數與璋父焉交通信至騰子超復與璋相聞有連蜀之意商謂璋曰超勇而不仁見得不思義不可以為唇齒老子曰國之利器不可以示人今之益部土美民豐寳物所出斯乃狡夫所欲傾覆超等所以西望也若引而近之則由養虎而自遺患矣璋從其言乃拒絶之

**王商谏刘璋不要结马超** 裴注先追叙韩遂、马腾与刘焉相通，继称马超想与刘璋联络。王商以马超勇而不仁、欲窥益州财富为由劝刘璋拒绝。

**归年依据** 初平、兴平间旧事与后来的马超一段有别。马超联系刘璋在王商在世时，不能混同211年马超与韩遂抗曹。

[王商谏刘璋不要结马超（时期）](../../years/ce-0201-0300/时期-三国志卷038-许麋孙简伊秦传纪年待考.md#period-sgz038-p-006-2)。

<a id="pei-006-3"></a>

> 荆州牧劉表及儒者宋忠咸聞其名遺書與商叙致殷勤許靖號為臧否至蜀見商而稱之曰設使啇生於華夏雖王景興無以加也

**王商获刘表、宋忠和许靖推重** 刘表、宋忠写书向王商致意，许靖入蜀后说若王商生在中原，其名可与王朗齐。

**归年依据** 刘表寄书在208卒前，许靖见王商则在211接任蜀郡前，赞誉没有同一年。

[王商获刘表、宋忠和许靖推重（时期）](../../years/ce-0201-0300/时期-三国志卷038-许麋孙简伊秦传纪年待考.md#period-sgz038-p-006-3)。

<a id="pei-006-4"></a>

> 璋以商為蜀郡太守成都禽堅有至孝之行商表其墓追贈孝亷又與嚴君平李弘立祠作銘以旌先賢修學廣農百姓便之

**王商城郡表孝与立严君平李弘祠** 刘璋任王商为蜀郡太守。王商表彰成都孝子禽坚，并为严君平、李弘立祠作铭，修学兴农。

**归年依据** 任郡间各事未逐一标年月，卷038秦宓书另记为严、李立祠。

[王商城郡表孝与立严君平李弘祠（时期）](../../years/ce-0201-0300/时期-三国志卷038-许麋孙简伊秦传纪年待考.md#period-sgz038-p-006-4)。

<a id="pei-006-5"></a>

> 在郡十載卒於官許靖代之

**王商卒后许靖代任蜀郡太守** 王商任蜀郡太守十年，在任上去世，许靖继任。

**归年依据** 211是本传许靖“转在蜀郡”之年；王商卒无独立月日，若任官间有空缺也不能以此确定卒年。

[211年第18条](../../years/ce-0201-0300/ce-0211.md#sgz038-p-006-5)。

## 008｜王朗书问候许靖并回忆久别

> 魏畧王朗與文休書曰文休足下消息平安甚善甚善豈意脱别三十餘年而無相見之縁乎詩人比一日之别於嵗月豈况悠悠歴累紀之年者哉自與子别若沒而復浮若絶而復連者數矣而今而後居升平之京師攀附於飛龍之聖主儕軰略盡幸得老與足下並為遺種之叟而相去數千里加有邅蹇之隔時聞消息於風聲托舊情於思想〔四库字图1505〕〔四库字图1505〕異處與異世無以異也

**王朗书问候许靖并回忆久别** 王朗问许靖平安，感慨二人离别三十多年而音问时断时通，幸两人年老尚存却相距数千里。

**归年依据** 信首无绝对时间，自称侍奉“飞龙之圣主”，大体处曹丕称帝之后。

[王朗书问候许靖并回忆久别（时期）](../../years/ce-0201-0300/时期-三国志卷038-许麋孙简伊秦传纪年待考.md#period-sgz038-p-008-1)。

<a id="pei-008-2"></a>

> 徃者隨軍到荆州見鄧子孝桓元將粗聞足下動静云夫子既在益州執職領郡徳素規矩老而不墯是時侍宿武皇帝於江陵劉景升聼事之上共道足下於通夜拳拳饑渴誠無已也

**王朗书回忆曹操到江陵时问及许靖** 王朗说自己昔年随军到荆州，从邓子孝等处听说许靖治郡事，当时夜侍曹操时一同谈许靖。

**归年依据** 文内追叙可能对应208年曹操入江陵；许靖本传211转蜀郡、此前曾任巴郡广汉，不能把王朗所闻具体认作当年转蜀郡。

<a id="pei-008-3"></a>

> 自天子在東宫及即位之後每㑹羣賢論天下髦雋之見在者豈獨人盡易為英士鮮易取最故乃猥以原壤之朽質感夫子之情聼每叙足下以為謀首豈其注意乃復過於前世書曰人惟求舊易稱同聲相應同氣相求劉将軍之與大魏兼而兩之總此二義前世邂逅以同為暌非武皇帝之㫖頃者蹉跌其泰而否亦非足下之意也深思書易之義利結分於宿好故遣降者送吳所獻致名馬貂罽得因無嫌道初開通展叙舊情以逹聲問久濶情慉非夫筆墨所能寫陳亦想足下同其志念今者親生男女凡有幾人年並幾何僕連失一男一女今有二男大男名肅年二十九生於㑹稽小兒裁歳餘臨書愴恨有懐緬然

**王朗书述曹丕知许靖并遣人送马问家** 王朗称曹丕身居东宫及即位后论名士多及许靖，又谈论双方关系、输送名马貂裘以通旧情，问许靖子女并述己家。

**归年依据** 220起至许靖卒前的书信，其提到的曹丕居东宫又更早。礼物发送和收讫年月无据。

<a id="pei-008-4"></a>

> 又曰過聞受終於文祖之言於尚書又聞歴數在躬允執其中之文於論語豈自意得於老耄之齒正值天命受於聖主之㑹親見三讓之弘辭觀衆瑞之總集覩升堂穆穆之盛禮瞻燔燎焜曜之青烟于時忽自以為處唐虞之運際於紫微之天庭也徒慨不得携子之手共列於世有二子之數以聼有唐欽哉之命也子雖在裔土想亦極目而廻望側耳而遐聼延頸而鶴立也昔汝南陳公初拜不依故常讓上卿於李元禮以此推之吾宜退身以避子位也茍得避子以竊譲名然後綬帶委質㳺談於平勃之間與子共陳徃時避地之艱辛樂酒酣讌高談大噱亦足遺憂而㤀老捉筆陳情隨以喜笑

**王朗书忆曹魏受禅、望与许靖同朝** 王朗以尧舜受终故事赞曹丕三让后受禅，称自己亲历盛礼，也说愿避许靖而后与他同列叙旧。

**归年依据** 魏受禅为220年旧事，此是王朗书中追述，未给该函日期。

[王朗书忆曹魏受禅、望与许靖同朝（时期）](../../years/ce-0201-0300/时期-三国志卷038-许麋孙简伊秦传纪年待考.md#period-sgz038-p-008-4)。

<a id="pei-008-5"></a>

> 又曰前夏有書而未達今重有書而并致前問皇帝既深悼劉將軍之早世又愍其孤之不易又惜使足下孔明等士人氣類之徒遂沉溺於羌夷異種之間永與華夏乖絶而無朝聘中國之期縁瞻睎故土桑梓之望也故復運慈念而勞仁心重下明詔以發徳音申勑朗等使重為書與足下等以足下聰眀揆殷勤之聖意亦足悟海岱之所常在知百川之所宜注矣昔伊尹去夏而就殷陳平違楚而歸漢猶矅徳於阿衡著功於宰相若足下能弼人之遺孤定人之猶豫去非常之偽號事受命之大魏客主兼不世之榮名上下蒙不朽之常耀功與事並聲與勲著考績效足以超越伊吕矣

**王朗书奉命劝蜀汉臣子归魏** 王朗说前夏信未达，今奉曹丕命重写。书中先称皇帝悼“刘将军”早死，怜其孤，又劝许靖和诸葛亮放弃蜀地称号而归魏。

**归年依据** 文中文字若实指223年死的刘备，与本书许靖222年卒相冲；引书的层次、受书对象及作年需存疑，不以推测作定年。

<a id="pei-008-6"></a>

> 既承詔直且服舊之情情不能已若不言足下之所能陳足下之所見則無以宣明詔命弘光大之恩叙夙昔夣想之思若天啓衆心子導蜀意誠此意有擕手之期若險路未夷子謀不從則懼聲問或否復面何由前後二書言每及斯希不切然有動於懐足下周㳺江湖以暨南海歴觀夷俗可謂徧矣想子之心結思華夏可謂深矣為身擇居猶願中土為主擇居安豈可以不繫意於京師而持疑於荒裔乎詳思愚言速示還報也

**归年依据** 接上一封无法确年之劝降文，书中称两次寄书而前书未达，不能为其丧年冲突自造解释。

## 009｜《搜神记》载麋竺车中女客与家火传闻

## 004｜刘巴祖父刘曜及父刘祥官历

维基文库四库本原行 13—13。附见[正文 L1868](../本地分卷/三国志/三国志-卷039.md#l1868)。

<a id="pei-004-1"></a>

> 零陵先賢傳曰巴祖父曜蒼梧太守父祥江夏太守盪宼将軍

**刘巴祖父刘曜及父刘祥官历** 《零陵先贤传》列刘曜为苍梧太守，刘祥任江夏太守、荡寇将军。

**归年依据** 家世与官名未记分别的授任年。

[刘巴祖父刘曜及父刘祥官历（时期）](../../years/ce-0201-0300/时期-三国志卷039-董刘马陈董吕传纪年待考.md#period-sgz039-p-004-1)。

<a id="pei-004-2"></a>

> 時孫堅舉兵討董卓以南陽太守張咨不給軍粮殺之祥與同心南陽士民由此怨祥舉兵攻之與戰敗亾

**刘祥与孙坚同心、为南阳人击败** 孙坚以张咨不供军粮杀之，注称刘祥与孙坚共谋或同意，南阳士民因而起兵败刘祥。

**归年依据** 《吴志·孙坚传》《后汉书·献帝纪》与通鉴卷059系孙坚杀张咨在190反董卓时，刘祥后续只依该注。

[190年第21条](../../years/ce-0101-0200/ce-0190.md#sgz039-p-004-2)。

<a id="pei-004-3"></a>

> 劉表亦素不善祥拘巴欲殺之數遣祥故所親信人宻詐謂巴曰劉牧欲相危害可相隨逃之如此再三巴輒不應且以報表表乃不殺巴

**刘表拘刘巴欲杀，刘巴不从试探而获免** 刘表因不喜刘祥而拘刘巴，派刘祥旧人骗其出逃试探，刘巴不从，反报刘表，得免。

**归年依据** 在刘祥争战亡后，刘表拘问年月未记。

[刘表拘刘巴欲杀，刘巴不从试探而获免（时期）](../../years/ce-0201-0300/时期-三国志卷039-董刘马陈董吕传纪年待考.md#period-sgz039-p-004-3)。

<a id="pei-004-4"></a>

> 年十八郡署戸曹史主記主簿

**刘巴十八岁为郡吏** 郡里署刘巴为户曹史、主记主簿。

**归年依据** 只记年龄，无直接可用生年。

[刘巴十八岁为郡吏（时期）](../../years/ce-0201-0300/时期-三国志卷039-董刘马陈董吕传纪年待考.md#period-sgz039-p-004-4)。

<a id="pei-004-5"></a>

> 劉先主欲遣周不疑就巴學巴答曰昔㳺荆北時渉師門記問之學不足紀名内無楊朱守静之術外無墨翟務時之風猶天之南箕虗而不用賜書乃欲令賢甥摧鸞鳳之艶遊燕雀之宇将何以啓明之哉愧於有若無實若虗何以堪之

**刘巴辞教周不疑** 刘先欲遣外甥周不疑就学，刘巴以为自己学不足启发而礼辞。

**归年依据** 四库连写“劉先主”，点校快照区分“劉先（主）”。卷021《刘廙传》刘先别见，周不疑的外甥关系可供断句，事件不明年。

## 005｜曹操乌林败后拟遣人招荆州三郡

维基文库四库本原行 13—13。附见[正文 L1868](../本地分卷/三国志/三国志-卷039.md#l1868)。

<a id="pei-005-1"></a>

> 零陵先賢傳曰曹公敗於烏林還北時欲遣桓階階辭不如巴巴謂曹公曰劉備據荆州不可也公曰備如相圖孤以六軍繼之也

**曹操乌林败后拟遣人招荆州三郡** 《零陵先贤传》说曹操在乌林败后想让桓阶去，桓阶推荐刘巴；刘巴忧刘备据荆州，曹操称如遭攻击将率军支援。

**归年依据** 《武帝纪》建安十三年赤壁乌林战；本注附败还之际，差遣确日无载。

[208年第8条](../../years/ce-0201-0300/ce-0208.md#sgz039-p-005-1)。

## 006｜刘巴招零陵未成，拟经交州北还

维基文库四库本原行 13—13。附见[正文 L1868](../本地分卷/三国志/三国志-卷039.md#l1868)。

<a id="pei-006-1"></a>

> 零陵先賢傳云巴徃零陵事不成欲㳺交州道還京師時諸葛亮在臨烝巴與亮書曰乗危歴險到值思義之民自與之衆承天之心順物之性非余身謀所能勸動若道窮數盡将託命於滄海不復顧荆州矣

**刘巴招零陵未成，拟经交州北还** 刘巴未能招降零陵，写信给临烝的诸葛亮，称进退无路可能远托海上。

**归年依据** 曹操在208年底兵败后的后续，但所至零陵及写信无具体日年。

[刘巴招零陵未成，拟经交州北还（时期）](../../years/ce-0201-0300/时期-三国志卷039-董刘马陈董吕传纪年待考.md#period-sgz039-p-006-1)。

<a id="pei-006-2"></a>

> 亮追謂曰劉公雄才盖世據有荆土莫不歸徳天人去就已可知矣足下欲何之巴曰受命而來不成當還此其宜也足下何言邪

**诸葛亮劝刘巴来归，刘巴以复命作答** 诸葛亮称刘备据荆州而人心所归，刘巴坚持自己原奉命而来，不成当还。

**归年依据** 同一未定年的劝降往返，见《通鉴》卷067平蜀后追述。

[诸葛亮劝刘巴来归，刘巴以复命作答（时期）](../../years/ce-0201-0300/时期-三国志卷039-董刘马陈董吕传纪年待考.md#period-sgz039-p-006-2)。

## 007｜刘巴交趾改姓、经牂牁入蜀

维基文库四库本原行 13—13。附见[正文 L1869](../本地分卷/三国志/三国志-卷039.md#l1869)。

<a id="pei-007-1"></a>

> 零陵先賢傳曰巴入交阯更姓為張與交阯太守士爕計議不合乃由牂牱道去為益州郡所拘留太守欲殺之主簿曰此非常人不可殺也主簿請自送至州見益州牧劉璋

**刘巴交趾改姓、经牂牁入蜀** 刘巴到交阯改姓张，因与士燮议事不合走牂牁道，被益州郡扣后在主簿协助下进见刘璋。

**归年依据** 在曹操南征后、刘璋211迎刘备前，沿途各阶段无确年。

[刘巴交趾改姓、经牂牁入蜀（时期）](../../years/ce-0201-0300/时期-三国志卷039-董刘马陈董吕传纪年待考.md#period-sgz039-p-007-1)。

<a id="pei-007-2"></a>

> 璋父焉昔為巴父祥所舉孝亷見巴驚喜每大事輒以咨訪

**《零陵先贤传》说刘璋厚待刘巴及两家旧识异说** 注家称刘祥曾举刘焉孝廉，以此解释刘璋见刘巴很喜，多问大事。

**归年依据** 旧事无明确年份，且与刘祥官历、刘焉资序抵牾，参裴松之本条下片。

[《零陵先贤传》说刘璋厚待刘巴及两家旧识异说（时期）](../../years/ce-0201-0300/时期-三国志卷039-董刘马陈董吕传纪年待考.md#period-sgz039-p-007-2)。

<a id="pei-007-3"></a>

> 臣松之案劉焉在漢靈帝時已經宗正太常出為益州牧祥始以孫堅作長沙時為江夏太守不得舉焉為孝亷明也

**裴松之校刘祥不可能举刘焉为孝廉** 裴松之说刘焉在灵帝时已经做过宗正、太常并出领益州；刘祥任江夏太守在孫坚出守长沙时期，此时不可能为刘焉举孝廉。

**归年依据** 为根据官历断是非的史源考证。并非同年能发生的诸事。

[裴松之校刘祥不可能举刘焉为孝廉（时期）](../../years/ce-0201-0300/时期-三国志卷039-董刘马陈董吕传纪年待考.md#period-sgz039-p-007-3)。

## 008｜刘巴两度劝刘璋勿纳、勿用刘备

维基文库四库本原行 13—13。附见[正文 L1869](../本地分卷/三国志/三国志-卷039.md#l1869)。

<a id="pei-008-1"></a>

> 零陵先賢傳曰璋遣法正迎劉備巴諫曰備雄人也入必為害不可内也既入巴復諫曰若使備討張魯是放虎於山林也璋不聼巴閉門稱疾

**刘巴两度劝刘璋勿纳、勿用刘备** 刘巴先劝刘璋不可纳刘备，刘备入蜀后又说令其讨张鲁会让他放手成势；刘璋不听，刘巴闭门称病。

**归年依据** 同一次入蜀缘起见《先主传》建安十六年、《通鉴》卷066，第二劝接原拟讨张鲁之后。

[211年第3条](../../years/ce-0201-0300/ce-0211.md#sgz039-p-008-1)。

<a id="pei-008-2"></a>

> 備攻成都令軍中曰其有害巴者誅及三族及得巴甚喜

**刘备下令成都城破勿害刘巴** 刘备围成都时命军中不得伤害刘巴，得到刘巴后很高兴。

**归年依据** 214年刘备攻成都，《通鉴》卷067记同一军令。

[214年第3条](../../years/ce-0201-0300/ce-0214.md#sgz039-p-008-2)。

## 009｜张飞来宿，刘巴拒交

维基文库四库本原行 13—13。附见[正文 L1869](../本地分卷/三国志/三国志-卷039.md#l1869)。

<a id="pei-009-1"></a>

> 零陵先賢傳曰張飛嘗就巴宿巴不與語飛遂忿恚葛亮謂巴曰張飛雖實武人敬慕足下主公今方收合文武以定大事足下雖天素髙亮宜少降意也巴曰大丈夫處世當交四海英雄如何與兵子共語乎

**张飞来宿，刘巴拒交** 张飞来刘巴处住，刘巴不与他说话，张飞生气。诸葛亮劝刘巴礼遇张飞，刘巴称不愿与武人往来。

**归年依据** 在刘巴入刘备幕府后、张飞221卒前；逸事未给年月。

[张飞来宿，刘巴拒交（时期）](../../years/ce-0201-0300/时期-三国志卷039-董刘马陈董吕传纪年待考.md#period-sgz039-p-009-1)。

<a id="pei-009-2"></a>

> 備聞之怒曰孤欲定天下而子初專亂之其欲還北假道於此豈欲成孤事邪備又曰子初才智絶人如孤可任用之非孤者難獨任也亮亦曰運籌䇿於幃幄之中吾不如子初逺矣若提枹鼓㑹軍門使百姓喜勇當與人議之耳

**刘备先责刘巴轻张飞，后赞其才并与诸葛亮评论** 刘备闻言先责他妨害大事，也认为唯自己可任用他；诸葛亮肯定刘巴筹策才能。

**归年依据** 和前一件交游是相连故事，刘备两次话与诸葛亮评语具体年均无记载。

[刘备先责刘巴轻张飞，后赞其才并与诸葛亮评论（时期）](../../years/ce-0201-0300/时期-三国志卷039-董刘马陈董吕传纪年待考.md#period-sgz039-p-009-2)。

<a id="pei-009-3"></a>

> 初攻劉璋備與士衆約若事定府庫百物孤無預焉及拔成都士衆皆捨干戈赴諸藏競取寶物軍用不足備甚憂之巴曰易耳但當鑄直百錢平諸物賈令吏為官市備從之數月之間府庫充實

**刘巴议铸直百钱并设官市** 刘备许士卒取蜀府库物资，成都破后府库空耗。刘巴建议铸直百钱、平物价、令吏设官市，刘备听从，国库数月充实。

**归年依据** 《通鉴》卷067于214平成都后的取财和理财中载相同措施，数月后补足可能越年，仍按措施缘起归。

[214年第33条](../../years/ce-0201-0300/ce-0214.md#sgz039-p-009-3)。

## 010｜刘巴、雍茂劝刘备缓称帝

维基文库四库本原行 13—13。附见[正文 L1870](../本地分卷/三国志/三国志-卷039.md#l1870)。

<a id="pei-010-1"></a>

> 零陵先賢傳曰是時中夏人情未一聞備在蜀四方延頸而備鋭意欲即眞巴以為如此示天下不廣且欲緩之與主簿雍茂諫備

**刘巴、雍茂劝刘备缓称帝** 刘巴见刘备拟即帝位，认为中原人心未定、应迟些，与主簿雍茂劝谏。

**归年依据** 《先主传》章武元年称帝，此谏在即位议中，据此归221。

[221年第1条](../../years/ce-0201-0300/ce-0221.md#sgz039-p-010-1)。

<a id="pei-010-2"></a>

> 備以他事殺茂由是逺人不復至矣

**《零陵先贤传》称刘备以他事杀雍茂** 裴注称雍茂劝谏后，刘备以另一件事杀他，又断称外人自此不来归附。

**归年依据** 本注不记处死年份，所说原因和后果是注所引叙述，勿同称帝劝谏强定同年。

<a id="pei-014-1"></a>

> 襄陽記曰謖臨終與亮書曰明公視謖猶子謖視明公猶父願深惟殛鯀興禹之義使平生之交不虧於此謖雖死無恨於黄壤也于時十萬之衆為之垂泣亮自臨祭待其遺孤若平生

**马谡临终致诸葛亮书，诸葛亮祭而抚其子** 马谡以父子情及殛鲧用禹旧事请保交情；注称军士哭泣，诸葛亮亲祭并善待子女。

**蒋琬与诸葛亮议是否当杀马谡** 蒋琬借楚杀子玉令人敌国欢喜的旧事叹息诛马谡；诸葛亮说军法必须公明，处战时更不可废。

**习凿齿批评诸葛亮不能量才节任** 习凿齿比较晋国与楚国处置败将，认为蜀本来人才有限，任马谡和事后杀马谡均有失，并说失在不能照才用人与权衡军法。

> 臣松之以為陳羣子泰陸遜子抗傳皆以子繫父不别載姓及王肅杜恕張承顧劭之流莫不皆然惟董允獨否未詳其意當以允名位優重事跡踰父故邪夏侯玄陳表並有騂角之美而亦如泰者魏書總名此卷云諸夏侯曹傳故不復稍加品藻陳武與表俱至偏將軍以位不相過故也

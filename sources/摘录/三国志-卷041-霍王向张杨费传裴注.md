## 001｜霍弋欲赴成都，蜀亡后哀临

维基文库四库本原行 11—11。附见[正文 L1937](../本地分卷/三国志/三国志-卷041.md#l1937)。

<a id="pei-001-1"></a>

> 漢晋春秋曰霍弋聞魏軍來弋欲赴成都後主以備敵既定不聼及成都不守弋素服號哭大臨三日諸將咸勸宜速降弋曰今道路隔塞未詳主之安危大故去就不可茍也若主上與魏和見遇以禮則保境而降不晩也若萬一危辱吾將以死拒之何論遲速邪

**霍弋欲赴成都，蜀亡后哀临** 《汉晋春秋》说魏军进蜀时霍弋请赴成都，刘禅以部署已定不许。城破后霍弋素服哭临三日，拒绝在未知君主安危时贸然投降。

**归年依据** 景耀六年魏灭蜀，参《通鉴》卷078用初字跨年追叙。

[263年第16条](../../years/ce-0201-0300/ce-0263.md#sgz041-p-001-1)。

<a id="pei-001-2"></a>

> 得後主東遷之問始率六郡將守上表曰臣聞人生於三事之如一惟難所在則致其命今臣國敗主附守死無所是以委質不敢有二晋文王善之又拜南中都督委以夲任

**霍弋闻刘禅东迁，率六郡将守归魏** 证实刘禅东迁后，霍弋率六郡官将上表归附，以对原君本无二心申报。司马昭肯定，仍委南中都督。

**归年依据** 《资治通鉴》卷078景元五年前半刘禅迁洛阳。霍弋称委质于魏年月原未书。

[264年第43条](../../years/ce-0201-0300/ce-0264.md#sgz041-p-001-2)。

<a id="pei-001-3"></a>

> 後遣將兵救援吕興平交阯日南九真三郡功封列侯進號崇賞焉

**霍弋派兵援吕兴，交州三郡归魏** 霍弋后来派兵援吕兴，注概括为平交趾、日南、九真，以此功封侯进号。

**归年依据** 《通鉴》卷078咸熙元年九月吕兴受职、霍弋遥领交州刺史发兵；守三郡与战功后果延续数年，非都在264。

[264年第51条](../../years/ce-0201-0300/ce-0264.md#sgz041-p-001-3)。

<a id="pei-001-4"></a>

> 弋孫彪晋越嶲太守

**霍弋孙霍彪仕晋** 霍彪在晋任越巂太守。

**归年依据** 无独立任年。

[霍弋孙霍彪仕晋（时期）](../../years/ce-0201-0300/时期-三国志卷041-霍王向张杨费传纪年待考.md#period-sgz041-p-001-4)。

<a id="pei-001-5"></a>

> 襄陽記曰羅憲字令則父䝉避亂於蜀官至廣漢太守憲少以才學知名年十三能屬文後主立太子為太子舍人遷庶子尚書吏部郎以宣信校尉再使於吳吳人稱羡焉

**罗宪家世、才学及早期历官** 罗宪字令则。父罗蒙避乱入蜀任广汉太守。罗宪少时能文，先为太子官，转尚书吏部郎，以宣信校尉两次出使吴。

**归年依据** 本注无各职月年。刘璿立太子始238，但本句还包括后续官职。

[罗宪家世、才学及早期历官（时期）](../../years/ce-0201-0300/时期-三国志卷041-霍王向张杨费传纪年待考.md#period-sgz041-p-001-5)。

<a id="pei-001-6"></a>

> 時黄皓預政衆多附之憲獨不與同皓恚左遷巴東太守時右大將軍閻宇都督巴東為領軍後主拜憲為宇副貳

**罗宪不附黄皓，左迁巴东** 黄皓执政，罗宪不附，被谪巴东太守，在巴东都督阎宇之下为领军、副贰。

**归年依据** 蜀季黄皓用事，左迁无确年。

[罗宪不附黄皓，左迁巴东（时期）](../../years/ce-0201-0300/时期-三国志卷041-霍王向张杨费传纪年待考.md#period-sgz041-p-001-6)。

<a id="pei-001-7"></a>

> 魏之伐蜀召宇西還留宇二千人令憲守永安城尋聞成都敗城中擾動江邉長吏皆棄城走憲斬稱成都亂者一人百姓乃定得後主委質問至乃帥所統臨于都亭三日

**阎宇回蜀，罗宪守永安并镇定局势** 魏伐蜀，阎宇受召西还，留二千兵于罗宪守永安。闻成都陷落，长吏离城，罗宪斩散布乱情者，得刘禅归附讯后举军在都亭哀临三日。

**归年依据** 《晋书·罗宪传》《通鉴》卷078追叙景耀六年末蜀亡时。

[263年第16条](../../years/ce-0201-0300/ce-0263.md#sgz041-p-001-7)。

<a id="pei-001-8"></a>

> 吳聞蜀敗起兵西上外託救援内欲襲憲憲曰夲朝傾覆吴為脣齒不恤我難而徼其利背盟違約且漢已亡吴何得久寧能為吴降虜乎保城繕甲告誓將士厲以節義莫不用命

**吴借救援向蜀西上，罗宪保城** 吴闻蜀亡，表称救援实欲夺巴东。罗宪称吴方离盟逐利，修甲守城，告誓将士。

**归年依据** 《晋书·罗宪传》初闻蜀败阶段；吴另派步协之战在264。

[263年第16条](../../years/ce-0201-0300/ce-0263.md#sgz041-p-001-8)。

<a id="pei-001-9"></a>

> 吳聞鍾鄧敗百城無主有兼蜀之志而巴東固守兵不得過使歩恊率衆而西憲臨江拒射不能禦遣參軍楊宗突圍北出告急安東將軍陳騫又送文武印綬任子詣晋王恊攻城憲出與戰大破其軍孫休怒復遣陸抗等帥衆三萬人增憲之圍被攻凡六月日而救援不到城中疾病大半或説憲奔走之計憲曰夫為人主百姓所仰危不能安急而棄之君子不為也畢命於此矣陳騫言於晋王遣荆州刺史胡烈救憲抗等引退晋王即委前任拜憲凌江將軍封萬年亭侯

**吴攻罗宪，胡烈驰援，吴军引退** 吴闻钟会和邓艾死，使步协攻巴东。罗宪令杨宗出围向陈骞求援，送印绶、人质致司马昭，又出战败步协。孙休加派陆抗，被围六月，罗宪不肯走。胡烈援后吴退，罗宪获官爵。

**归年依据** 《吴主传》永安七年二月围罗宪、七月吴军退，《通鉴》卷078同年。晋书加职作陵江将军，四库作凌江，底本保留。

[264年第14条](../../years/ce-0201-0300/ce-0264.md#sgz041-p-001-9)。

<a id="pei-001-10"></a>

> 㑹武陵四縣舉衆叛吳以憲為武陵太守巴東監軍

**武陵举众归附，罗宪领武陵太守** 武陵四县反吴，罗宪领武陵太守、巴东监军。

**归年依据** 与264吴军撤离相承，武陵四、五县有史异，《魏志·陈留王纪》引诏同年作五县。

[264年第52条](../../years/ce-0201-0300/ce-0264.md#sgz041-p-001-10)。

<a id="pei-001-11"></a>

> 泰始元年改封西鄂縣侯憲遣妻子居洛陽武帝以子襲為給事中

**罗宪改封西鄂侯，家属安居洛阳** 晋泰始元年罗宪改封西鄂县侯，妻儿迁洛阳，武帝用其子为给事中。

**归年依据** 《襄阳记》自书泰始元年。晋书把西鄂侯叙作追封，并称泰始初入朝；各家官爵异说。

[265年第24条](../../years/ce-0201-0300/ce-0265.md#sgz041-p-001-11)。

<a id="pei-001-12"></a>

> 三年冬入朝進位冠軍将軍假節

**罗宪入朝进冠军将军** 泰始三年冬罗宪入朝，进冠军将军、假节。

**归年依据** 本注自书三年，承西晋泰始元年。

[267年第7条](../../years/ce-0201-0300/ce-0267.md#sgz041-p-001-12)。

<a id="pei-001-13"></a>

> 四年三月從帝宴于華林園詔問蜀大臣子弟後問先軰宜時叙用者憲薦蜀郡常忌杜軫壽良巴西陳夀南郡髙軌高陽吕雅許國江夏費恭琅琊諸葛京汝南陳裕即皆叙用咸顯於世

**罗宪在华林园荐蜀地士人** 随晋武帝宴华林园，武帝问蜀国大臣子弟和宜任用的人，罗宪荐举常忌、杜轸、寿良、陈寿等人，后来皆获任用。

**归年依据** 本注自书泰始四年三月。后续各次任命无独立年。

[268年第4条](../../years/ce-0201-0300/ce-0268.md#sgz041-p-001-13)。

<a id="pei-001-14"></a>

> 憲還襲取吳之巫城因上伐吳之䇿憲方亮嚴正待士不倦輕財好施不治産業

**罗宪攻取巫城并献伐吴策** 罗宪由晋京返回，袭吴得巫城，上伐吴策。注又概述其待士好施。

**归年依据** 接泰始四年华林园还后，袭城和上策无月年，不硬系268。

[罗宪攻取巫城并献伐吴策（时期）](../../years/ce-0201-0300/时期-三国志卷041-霍王向张杨费传纪年待考.md#period-sgz041-p-001-14)。

<a id="pei-001-15"></a>

> 六年薨贈安南將軍諡曰烈侯

**罗宪去世，谥烈侯** 罗宪去世，追赠安南将军，谥烈侯。

**归年依据** 本注自书泰始六年，《晋书·罗宪传》同。

[270年第8条](../../years/ce-0201-0300/ce-0270.md#sgz041-p-001-15)。

<a id="pei-001-16"></a>

> 子襲以陵江將軍領部曲早卒追贈廣漢太守

**罗宪子罗袭亡及追赠** 罗袭任陵江将军掌部曲，早卒，追赠广汉太守。

**归年依据** 罗袭任职、卒无独立年月。

[罗宪子罗袭亡及追赠（时期）](../../years/ce-0201-0300/时期-三国志卷041-霍王向张杨费传纪年待考.md#period-sgz041-p-001-16)。

**罗徽被王如杀** 罗袭子罗徽任顺阳内史，永嘉五年被王如杀。

**归年依据** 本注自纪永嘉五年。子名异说见末句。

[311年第1条](../../years/ce-0301-0400/ce-0311.md#sgz041-p-001-17)。

## 004｜向朗留下戒子之言

维基文库四库本原行 13—13。附见[正文 L1940](../本地分卷/三国志/三国志-卷041.md#l1940)。

> 㐮陽記曰朗遺言戒子曰傳稱師克在和不在衆此言天地和則萬物生君臣和則國家平九族和則動得所求静得所安是以聖人守和以存以亡也吾楚國之小子耳而早䘮所天為二兄所誘養使其性行不隨禄利以墮今但貧耳貧非人患惟和為貴汝其勉之

**向朗留下戒子之言** 《襄阳记》记向朗引师克在和不在众，要求儿子以和治家，以自幼丧父由兄长养大说明贫非患。

**归年依据** 遗言附延熙十年卒，具体发言年月未单载。

## 006｜卫瓘在成都得璧和印

维基文库四库本原行 13—13。附见[正文 L1943](../本地分卷/三国志/三国志-卷041.md#l1943)。

<a id="pei-006-1"></a>

> 㐮陽記曰魏咸熙元年六月鎮南〔四库字图2877〕軍衛瓘至於成都得璧玉印各一枚文似成信字魏人宣示百官藏于相國府充聞之曰吾聞譙周之言先帝諱備其訓具也後主諱禪其訓授也如言劉已具矣當授與人也今中撫軍名炎而漢年極於炎興瑞出成都而藏之於相國府此殆天意也

**卫瓘在成都得璧和印** 《襄阳记》称魏咸熙元年六月卫瓘到成都，得一璧一印，似成信字，魏示百官后藏相国府。向充借此称预兆司马炎接续蜀汉。

**归年依据** 裴注自书咸熙元年；四库鎮南〔图字2877〕軍，点校鎮西將軍，2877可对读將，方向异文保留。

## 007｜裴松之辨书信与张裔应对

维基文库四库本原行 14—14。附见[正文 L1946](../本地分卷/三国志/三国志-卷041.md#l1946)。

<a id="pei-007-1"></a>

> 臣松之以為談啁貴於機㨗書疏可容留意今因書疏之巧以著談啁之速非其理也

**裴松之辨书信与张裔应对** 裴松之认为机敏主要体现在即时谈谐，写信可反复构思，不能单凭书信证明张裔谈吐快。

**归年依据** 只议作者论证。

## 009｜何祗、杨洪朝会戏答

维基文库四库本原行 15—15。附见[正文 L1954](../本地分卷/三国志/三国志-卷041.md#l1954)。

<a id="pei-009-1"></a>

> 益部耆舊傳雜記曰每朝㑹祗次洪坐嘲祗曰君馬何駛祗曰故吏馬不敢駛但明府未著鞭耳衆傳之以為笑

**何祗、杨洪朝会戏答** 何祗朝会坐杨洪旁，杨洪问其马为何快，何祗以长官尚未著鞭作答，时人传笑。

**归年依据** 用马喻升迁，朝会确年未详。

[何祗、杨洪朝会戏答（时期）](../../years/ce-0201-0300/时期-三国志卷041-霍王向张杨费传纪年待考.md#period-sgz041-p-009-1)。

<a id="pei-009-2"></a>

> 祗字君肅少寒貧為人寛厚通濟體甚壮大又能飲食好聲色不持節儉故時人少貴之者常夢井中生桑以問占夢趙直直曰桒非井中之物㑹當移植然桒字四十下八君壽恐不過此祗笑言得此足矣

**何祗出身及赵直为梦断年龄** 何祗少贫而为人宽厚，喜饮食声色、不节俭，一度少人重视。梦井中生桑，赵直拆字说他或活不过四十八，何祗觉得够了。

**归年依据** 人物概说与占梦传闻，无年。

[何祗出身及赵直为梦断年龄（时期）](../../years/ce-0201-0300/时期-三国志卷041-霍王向张杨费传纪年待考.md#period-sgz041-p-009-2)。

<a id="pei-009-3"></a>

> 初往郡後為督軍從事時諸葛亮用法峻宻陰聞祗㳺戲放縦不勤所職嘗奄徃錄獄衆人咸為祗懼祗宻聞之夜張燈火見囚讀諸解状諸葛晨往祗悉已闇誦答對解釋無所凝滯亮甚異之

**何祗熟记讼案，诸葛亮惊异** 何祗任督军从事时诸葛亮听说他懈怠，欲突查。他知情后连夜见囚犯、读文案，诸葛亮来时答对流畅，深为惊异。

**归年依据** 诸葛亮掌政及何祗做督军从事期间，无独立年。

[何祗熟记讼案，诸葛亮惊异（时期）](../../years/ce-0201-0300/时期-三国志卷041-霍王向张杨费传纪年待考.md#period-sgz041-p-009-3)。

<a id="pei-009-4"></a>

> 出補成都令時郫縣令缺以祗兼二縣二縣户口猥多切近都治饒諸奸穢每比人常眠睡值其覺寤輒得奸詐衆咸畏祗之發摘或以為有術無敢欺者使人投筭祗聼其讀而心計之不差升合其精如此

**何祗兼成都、郫县两令** 何祗出任成都令，因郫县空缺兼领，善察奸伪且精于心算。

**归年依据** 诸葛亮委任后，不见年。

[何祗兼成都、郫县两令（时期）](../../years/ce-0201-0300/时期-三国志卷041-霍王向张杨费传纪年待考.md#period-sgz041-p-009-4)。

<a id="pei-009-5"></a>

> 汶山夷不安以祗為汶山太守民夷服信遷廣漢後夷反叛辭令得前何府君乃能安我耳時難屈祗拔祗族人為汶山復得安轉祗為犍為年四十八卒如直所言

**何祗出守汶山、广汉、犍为并卒** 汶山夷众乱，何祗出任太守，获信任。迁广汉后汶山再乱，只愿受原先何府君治理，另拔其族人为守才安。何祗转任犍为、四十八岁死。

**归年依据** 多任和死亡无确年。正文杨洪尚在蜀郡时何祗已守广汉，亦未见确年。

[何祗出守汶山、广汉、犍为并卒（时期）](../../years/ce-0201-0300/时期-三国志卷041-霍王向张杨费传纪年待考.md#period-sgz041-p-009-5)。

<a id="pei-009-6"></a>

> 後有廣漢王離字伯元亦以才幹顯為督軍從事推法平當稍遷代祗為犍為太守治有美績雖聦明不及祗而文采過之也

**王离继任何祗，有治理业绩** 王离字伯元，才干出众，任督军从事、判法公允，后代何祗为犍为太守，有美绩且文采胜于何祗。

**归年依据** 继任何祗后，无确年。

## 010｜习凿齿与裴松之评蜀汉称帝

维基文库四库本原行 16—16。附见[正文 L1956](../本地分卷/三国志/三国志-卷041.md#l1956)。

<a id="pei-010-1"></a>

> 習鑿齒曰夫創夲之君俟大定而後正已纂統之主須速建以係衆心是故惠公朝虜而子圉夕立更始尚存而光武舉號夫豈〔四库字图2982〕主徼利社稷之故也今先主紏合義兵將以討賊賊彊禍大主沒國䘮二祖之廟絶而不祀茍非親賢孰能紹此嗣祖配天非咸陽之譬杖正討逆何推譲之有於此時也不知速尊有徳以奉大統使民欣反正世覩舊物杖順者齊心附逆者同懼可謂闇惑矣其黜降也宜哉臣松之以為鑿齒論議惟此議最善

**习凿齿与裴松之评蜀汉称帝** 习凿齿认为创业待天下定、继统宜尽早联系民心，引惠公、子圉及更始光武加以说明，所以费诗不应不许刘备继统，受黜合宜；裴松之赞其议。

**归年依据** 议论及反复举古，费诗谏与黜仍见221。

## 011｜费立等费氏后裔仕晋

维基文库四库本原行 16—16。附见[正文 L1958](../本地分卷/三国志/三国志-卷041.md#l1958)。

<a id="pei-011-1"></a>

> 孫盛蜀世譜曰詩子立晋散騎常侍自後益州諸費有名位者多是詩之後也

**费立等费氏后裔仕晋** 孙盛《蜀世谱》说费诗子费立为晋散骑常侍，后来益州有名位的费氏多是费诗后代。

**归年依据** 入晋任官无确年，世系归时期。

## 001｜越巂异事及周群的易代之占

维基文库四库本原行 12—12。附见[正文 L1970](../本地分卷/三国志/三国志-卷042.md#l1970)。

<a id="pei-001-1"></a>

> 續漢書曰建安七年越嶲有男子化為女人時羣言哀帝時亦有此將易代之祥也

**越巂异事及周群的易代之占** 《续汉书》说越巂有男子化为女子的传闻，周群以哀帝时同类传闻附会为改朝换代的征兆。

**归年依据** 该书明书建安七年；异事及占验只按古书所载，不当作因果。

[202年第3条](../../years/ce-0201-0300/ce-0202.md#sgz042-p-001-1)。

<a id="pei-001-2"></a>

> 至二十五年獻帝果封于山陽

**献帝禅位后封山阳公** 献帝在建安二十五年改元后交出帝位，曹丕封他为山阳公。

**归年依据** 《后汉书·献帝纪》《文帝纪》，在当年受禅同号。

[220年第4条](../../years/ce-0201-0300/ce-0220.md#sgz042-p-001-2)。

<a id="pei-001-3"></a>

> 十二年十月有星孛于鶉尾荆州分野羣以為荆州牧將死而失土

**鹑尾见彗，周群以为关乎荆州** 记十月鹑尾出现彗星，在分野说中属荆州，周群预言其牧将失地而死。

**归年依据** 建安十二年；《献帝纪》同年记“有星孛於鹑尾”。

[207年第2条](../../years/ce-0201-0300/ce-0207.md#sgz042-p-001-3)。

<a id="pei-001-4"></a>

> 眀年秋劉表卒曹公平荆州

**刘表去世，曹操攻取荆州** 刘表次年秋卒，荆州归曹操。

**归年依据** 《武帝纪》《刘表传》建安十三年；对前一年星象所作的事后联结仍按原书。

[208年第6条](../../years/ce-0201-0300/ce-0208.md#sgz042-p-001-4)。

<a id="pei-001-5"></a>

> 十七年十二月星孛于五諸侯羣以為西方專據土地者皆將失土是時劉璋據益州張魯據漢中韓遂據涼州宋建據枹罕

**五诸侯星区见彗，周群占西方诸人将失土** 周群预言当时在西部拥有土地的刘璋、张鲁、韩遂、宋建失去割据地。

**归年依据** 《后汉书·天文志》及引注文建安十七年十二月；列举四人在位不是同年败亡。

[212年第6条](../../years/ce-0201-0300/ce-0212.md#sgz042-p-001-5)。

<a id="pei-001-6"></a>

> 明年冬曹公遣偏將擊涼州

**曹操遣将击凉州** 次年冬曹操遣偏将击凉州。

**归年依据** 注文承建安十七年，明年为十八；《武帝纪》十九年始有夏侯渊攻宋建等纪日，行军阶段不可并作一事。

[213年第31条](../../years/ce-0201-0300/ce-0213.md#sgz042-p-001-6)。

<a id="pei-001-7"></a>

> 十九年獲宋建

**曹军攻克枹罕，擒宋建** 夏侯渊攻取枹罕，擒获割据宋建。

**归年依据** 《武帝纪》《夏侯渊传》建安十九年十月。

[214年第4条](../../years/ce-0201-0300/ce-0214.md#sgz042-p-001-7)。

<a id="pei-001-8"></a>

> 韓遂逃于羗中被殺

**韩遂逃走后被杀，异年并存** 韩遂逃往羌中，后被杀。

**归年依据** 夹在《续汉书》十九年取宋建句之后；《武帝纪》建安二十年秋七月麴演等斩送首，归215并存旧叙。

[215年第15条](../../years/ce-0201-0300/ce-0215.md#sgz042-p-001-8)。

<a id="pei-001-9"></a>

> 其年秋璋失益州

**刘璋失益州记作秋** 刘璋失去益州。

**归年依据** 作“其年秋”承十九年；《先主传》定州在夏，保留季节差。

[214年第3条](../../years/ce-0201-0300/ce-0214.md#sgz042-p-001-9)。

<a id="pei-001-10"></a>

> 二十年秋曹公攻漢中張魯降

**曹操入汉中，张鲁降** 曹操攻汉中，张鲁后来归降。

**归年依据** 《武帝纪》建安二十年七月破阳平、十一月张鲁降；古注把战事及受降概叙为秋。

[215年第16条](../../years/ce-0201-0300/ce-0215.md#sgz042-p-001-10)。

## 010｜诸葛亮免来敏职，命其闭门思过

维基文库四库本原行 15—15。附见[正文 L1986](../本地分卷/三国志/三国志-卷042.md#l1986)。

<a id="pei-010-1"></a>

> 亮集有教曰將軍來敏對上官顯言新人有何功徳而奪我榮資與之邪諸人共憎我何故如是敏年老狂悖生此怨言昔成都初定議者以為來敏亂羣先帝以新定之際故遂含容無所禮用後劉子初選以為太子家令先帝不悅而不忍拒也後主即位吾闇於知人遂復擢為將軍祭酒違議者之審見背先帝所疎外自謂能以敦厲薄俗帥之以義今既不能表退職使閉門思愆

**诸葛亮免来敏职，命其闭门思过** 来敏对上官显埋怨新人夺禄，诸葛亮以文书责其狂悖，宣告罢退。文书追说刘备初定成都时有议者不喜来敏，刘巴荐为太子家令，自己又错误擢为祭酒。

**归年依据** 《诸葛亮集》教写于汉中任来敏祭酒后、234前；追述定成都214与东宫任命，不能用于倒推免职年。

## 013｜孙绰批评谯周劝降

维基文库四库本原行 18—18。附见[正文 L2004](../本地分卷/三国志/三国志-卷042.md#l2004)。

<a id="pei-013-1"></a>

> 孫綽評曰譙周説後主降魏可乎曰自為天子而乞降請命何恥之深乎夫為杜稷死則死之為社稷亡則亡之先君正魏之篡不與同天矣推過於其父俛首而事讎可謂茍存豈大居正之道哉

**孙绰批评谯周劝降** 孙绰认为国君有为社稷死或亡之义，责刘禅有违先帝并屈降敌国，也不认同谯周所劝。

**归年依据** 晋人史评所涉263蜀降，并未记孙绰写作年。

[孙绰批评谯周劝降（时期）](../../years/ce-0201-0300/时期-三国志卷042-二杜周许孟来尹李谯郤传纪年待考（2）.md#period-sgz042-p-013-1)。

<a id="pei-013-2"></a>

> 孫盛曰春秋之義國君死社稷卿大夫死位况穪天子而可辱於人乎周謂萬乗之君偷生茍免亡禮希利要冀微榮惑矣且以事勢言之理有未盡何者禪雖庸主實無桀紂之酷戰雖屢北未有土崩之亂縱不能君臣固守背城借一自可退次東鄙以思後圖

**孙盛从君臣死节立论批评谯周** 孙盛说《春秋》下国君、卿大夫各有死难之义，尤不该让称天子的人向敌乞降。他认为形势也还未至全不可守。

**归年依据** 晋人评263国事，无单独评论年。

> 越絶書曰昔越王勾踐有寶劒五枚聞於天下客有能相劒者名薛燭王召而問之吾有寶劒五請以示子乃取其豪曹巨闕薛燭曰皆非也又取純鈎湛盧燭曰觀其劒鈔爛爛如列宿之行觀其光渾渾如水之將溢於塘觀其文渙渙如氷將釋此所謂純鈎邪王曰是也王曰客有直之者有市之鄉三駿馬千匹千戸之都二可乎薛燭曰不可當造此劒之時赤菫之山破而出錫若邪之溪涸而出銅兩師掃灑雷公擊鼓太一下觀天精下之歐冶乃因天之精悉其伎巧一曰純鈎二曰湛盧今赤菫之山已合若邪之溪深而不測歐冶子已死雖傾城量金珠玉竭河獨不得此一物有市之鄉三駿馬千匹千户之都二亦何足言與

## 024｜《淮南子》以楚子发借盗者才解敌为比

维基文库四库本原行 19—19。附见[正文 L2014](../本地分卷/三国志/三国志-卷042.md#l2014)。

<a id="pei-024-1"></a>

> 淮南子曰楚將子發好求技道之士楚有善為偷者往見曰聞君求技道之士臣偷也願以技備一卒子發聞之衣不及帶冠不暇正出見而禮之左右諫曰偷者天下之盗也何為禮之君曰此非左右之所得與後無幾何齊興兵伐楚子發將師以當之兵三却楚賢大夫皆盡其計而悉其誠齊師愈强於是卒偷進請曰臣有薄技願為君行之君曰諾偷即夜出解齊將軍之帳而獻之子發子發使人歸之曰卒有出採薪者得將軍之帳使使歸於執事明日又復往取枕子發又使歸之明日又復往取簪子發又使歸之齊師聞之大駭將軍與軍吏謀曰今日不去楚軍恐取吾頭矣即旋師而去

**归年依据** 旧籍军事寓事，缺战役确年，不以人名强定。

## 025｜雍门周以琴使孟尝君感政治盛衰

维基文库四库本原行 19—19。附见[正文 L2014](../本地分卷/三国志/三国志-卷042.md#l2014)。

<a id="pei-025-1"></a>

> 桓譚新論曰雍門周以琴見孟嘗君曰先生鼓琴亦能令文悲乎對曰臣之所能令悲者先貴而後賤昔富而今貧擯壓窮巷不交四鄰不若身材髙妙懷質抱真逢䜛罹謗怨結而不得信不若交歡而結愛無怨而生離逺赴絶國無相見期不若幼無父母壯無妻兒出以野澤為鄰入用堀坎為家困於朝夕無所假貸若此人也但聞飛鳥之號秋風鳴條則傷心矣臣一為之援琴而長太息未有不悽惻而涕泣者也今若足下居則廣厦髙堂連闥洞房下羅帷來清風倡優在前謟䛕侍側揚激楚舞鄭妾流聲以娛耳練色以滛目水戱則舫龍舟建羽旗鼔鈎乎不測之淵野游則登平原馳廣囿强弩下髙鳥勇士格猛獸置酒娛樂沈醉忘歸方此之時視天地曾不若一指雖有善鼓琴未能動足下也孟嘗君曰固然雍門周曰然臣竊為足下有所常悲夫角帝而困秦者君也連五國而伐楚者又君也天下未嘗無事不從即衡從成則楚王衡成則秦帝夫以秦楚之彊而報弱薛猶磨蕭斧而伐朝菌也有識之士莫不為足下寒心天道不常盛寒暑更進退千秋萬歲之後宗廟必不血食高臺既已傾曲池又已平墳墓生荆棘狐狸穴其中游兒牧豎躑躅其足而歌其上曰孟嘗君之尊貴亦猶若是乎於是孟嘗君喟然太息涕淚承睫而未下雍門周引琴而鼓之徐動宮徴叩角羽終而成曲孟嘗君遂歔欷而就之曰先生鼓琴令文立若亡國之人也

**雍门周以琴使孟尝君感政治盛衰** 雍门周说困苦的人易闻琴动心，孟尝君正富贵享乐难动；继而提他夹在秦楚之间，势盛难久，身后亦可能荒废。田文感叹，听琴终于落泪。

**归年依据** 桓谭《新论》叙谈无独立年，所举“角帝”“连五国”是回顾。

## 027｜卢敖与若士相会的寓言

维基文库四库本原行 19—19。附见[正文 L2014](../本地分卷/三国志/三国志-卷042.md#l2014)。

<a id="pei-027-1"></a>

> 淮南子曰盧敖游乎北海經乎太隂入乎玄闕至於蒙轂之上見一士焉深目而玄凖戾頸而鳶肩豐上而殺下軒軒然方迎風而舞顧見盧敖慢然下其臂遯逃乎碑下盧敖俯而視之方卷龜殻而食合梨盧敖乃與之語曰惟敖為背羣離黨窮觀於六合之外者非敖而已乎敖幼而好游長不喻解周行四極惟北陰之不闚今卒睹夫子於是子殆可與敖為交乎若士者齤然而笑曰嘻乎子中州民寧肯而逺至此此猶光乎日月而戴列星陰陽之所行四時之所生此其比夫不名之地猶突奥也若我南遊乎罔䍚之野北息于沉墨之鄉西窮㝠㝠之黨東貫鴻濛之光此其下無地而上無天聽焉無聞視焉則眴此其外猶有沈沈之汜其餘一舉而千萬里吾猶未能之在今子游始至於此乃語窮觀豈不亦逺哉然子處矣吾與汗漫期於九垓之上吾不可以乆若士舉臂而竦身遂入雲中盧敖仰而視之弗見乃止曰吾比夫子也猶黄鵠之與壤蟲終日行不離咫尺自以為逺不亦悲哉

**卢敖与若士相会的寓言** 《淮南子》说卢敖北游过玄阙，邀若士交友；若士以四极之外比其见识狭窄，飞入云中，卢敖叹自己如地虫望黄鹄。

**归年依据** 为寓言用典，无史事年。

## 028｜张璠评谯周能说动刘禅

维基文库四库本原行 20—20。附见[正文 L2017](../本地分卷/三国志/三国志-卷042.md#l2017)。

<a id="pei-028-1"></a>

> 張璠以為譙周所陳降魏之䇿蓋素料劉禪懦弱心無害戾故得行也如遇忿肆之人雖無他算然矜殉鄙恥或發怒妄誅以立一時之威快其斯湏之意者此亦夷滅之禍云

**张璠评谯周能说动刘禅** 张璠认为谯周早知刘禅性弱无杀心才能劝降；若碰到恣怒者，可能以屈辱为由迁怒谏臣而导致全家被杀。

**归年依据** 后出史评所涉263，发论无可归确年。

## 003｜孙权以常用宝刀赠费祎

维基文库四库本原行 12—12。附见[正文 L2068](../本地分卷/三国志/三国志-卷044.md#l2068)。

<a id="pei-003-1"></a>

> 褘别傳曰權乃以手中常所執寶刀贈之褘答曰臣以不才何以堪明命然刀所以討不庭禁暴亂者也但願大王勉建功業同奬漢室臣雖闇弱終不負東顧

**孙权以常用宝刀赠费祎** 孙权把自己常执的宝刀送给费祎。费祎说刀用来惩不服、禁暴乱，愿孙权建功，双方共扶汉室。

**归年依据** 裴注插在建兴三年南征归后首次使吴的宾主问答与“还”之间，以首次出使归年；赠刀无独立日月。

## 004｜费祎任尚书令时裁理众务

维基文库四库本原行 12—12。附见[正文 L2069](../本地分卷/三国志/三国志-卷044.md#l2069)。

<a id="pei-004-1"></a>

> 褘别傳曰于時軍國多事公務煩猥褘識悟過人每省讀書記舉目暫視已究其意㫖其速數倍於人終亦不忘常以朝晡聽事其間接納賔客飲食嬉戲加之博弈每盡人之歡事亦不廢

**费祎任尚书令时裁理众务** 费祎检阅文书很快，早晚处理公务，间或接宾、饮宴、弈棋，也未误事。

**归年依据** 所述为任内常态；本传在诸葛亮卒后代蒋琬，至大将军时董允守尚书令。

[费祎任尚书令时裁理众务（时期）](../../years/ce-0201-0300/时期-三国志卷044-蒋琬费祎姜维传纪年待考.md#period-sgz044-p-004-1)。

<a id="pei-004-2"></a>

> 董允代褘為尚書令欲斆褘之所行旬日之中事多愆滯允乃歎曰人才力相縣若此甚逺此非吾之所及也聽事終日猶有不暇爾

**董允接掌尚书令并试仿费祎办事** 董允试学费祎从速处事，十日之内反积滞许多公务，慨叹才力相差，整日办公仍忙不过来。

**归年依据** 《董允传》延熙七年以侍中守尚书令，为大将军费祎副贰；模仿发生在接事后，未另载年。

[244年第18条](../../years/ce-0201-0300/ce-0244.md#sgz044-p-004-2)。

## 005｜费祎作甲乙论评曹爽之死

维基文库四库本原行 12—12。附见[正文 L2070](../本地分卷/三国志/三国志-卷044.md#l2070)。

<a id="pei-005-1"></a>

> 殷基通語曰司馬懿誅曹爽褘設甲乙論平其是非甲以為曹爽兄弟凡品庸人茍以宗子枝屬得蒙顧命之任而驕奢僭逸交非其人私樹朋黨謀以亂國懿奮誅討一朝殄盡此所以稱其任副士民之望也

**费祎作甲乙论评曹爽之死** 殷基载费祎列两说评司马懿诛曹爽：先陈一方认为曹爽兄弟骄奢聚党，司马懿诛之副众望。

**归年依据** 政变可据《齐王纪》系嘉平元年，作论年月未记；原文作为政变的史论互证。

[249年第1条](../../years/ce-0201-0300/ce-0249.md#sgz044-p-005-1)。

<a id="pei-005-2"></a>

> 乙以為懿感曹仲附已不一豈爽與相干事勢不專以此隂成疵瑕初無忠告侃爾之訓一朝屠戮䜛其不意豈大人經國篤本之事乎若爽信有謀主之心大逆已構而發兵之日更以芳委爽兄弟懿父子從後閉門舉兵蹙而向芳必無悉寜忠臣為君深慮之謂乎以此推之爽無大惡明矣若懿以爽奢僭廢之刑之可也滅其尺口被以不義絶子丹血食及何晏子魏之親甥亦與同戮為僭濫不當矣

**甲乙论又驳突然屠戮并滥及亲族** 另一方认为曹爽与司马懿不一心还不足论重罪，谴责未经劝诫而突然屠戮。若确已谋逆，本无须在发兵之日把曹芳交给曹爽等；即便依法诛曹爽，也不应绝曹真一支祭祀或滥及何晏之子。

**归年依据** 同为殷基录费祎就嘉平元年政变所论；系年条所收是所评史事，评文本身时月未详。

[249年第1条](../../years/ce-0201-0300/ce-0249.md#sgz044-p-005-2)。

## 009｜《魏略》记马遵、郭淮返上邽

维基文库四库本原行 13—13。附见[正文 L2073](../本地分卷/三国志/三国志-卷044.md#l2073)。

<a id="pei-009-1"></a>

> 魏略曰天水太守馬遵將維及諸官屬隨雍州刺史郭淮偶自西至洛門案行會聞亮已到祁山淮顧遵曰是欲不善遂驅東還上邽遵念所治冀縣界乎西偏又恐吏民樂亂遂亦隨淮去

**《魏略》记马遵、郭淮返上邽** 天水太守马遵和从吏随雍州刺史郭淮巡视至洛门，听说诸葛亮已到祁山，郭淮东返上邽，马遵也随行。

**归年依据** 两传同在建兴六年、魏太和二年诸葛亮首次出祁山；《魏略》所记巡视、路线与本传叙法不同。

[228年第3条](../../years/ce-0201-0300/ce-0228.md#sgz044-p-009-1)。

<a id="pei-009-2"></a>

> 時維謂遵曰明府當還冀遵謂維等曰卿諸人回復信皆賊也各自行維亦無如遵何而家在冀遂與郡吏上官子脩等還冀冀中吏民見維等大喜便令見亮二人不獲已乃共詣亮亮見大悅未及遣迎冀中人

**《魏略》记姜维返冀转见诸葛亮** 姜维建议马遵回冀，马遵把他们指为贼。姜维与上官子脩等回冀，当地人推他们去见诸葛亮，二人不得已前往，诸葛亮大喜。

**归年依据** 建兴六年归蜀之异说；本传列梁绪、尹赏、梁虔，且称先遭城门拒绝。

[228年第19条](../../years/ce-0201-0300/ce-0228.md#sgz044-p-009-2)。

<a id="pei-009-3"></a>

> 㑹亮前鋒為張郃費繇等所破遂將維等却縮維不得還遂入蜀諸軍攻冀皆得維母妻子亦以維本無去意故不没其家但擊保官以延之此語與本傳不同

**街亭败后姜维入蜀，家属仍在魏** 张郃、费繇等击退蜀军前锋，姜维未能归冀，随蜀军撤走。《魏略》称魏军得到姜维母、妻、子，认为他本无离意，未没其家，仅由官府保管以待其归。

**归年依据** 建兴六年街亭之役后；末句四库“擊保官”、点校“系保官”，依对读释义，异说原字保留。

[228年第3条](../../years/ce-0201-0300/ce-0228.md#sgz044-p-009-3)。

## 012｜姜维请刘禅杀黄皓，刘禅令其致歉

<a id="pei-012-1"></a>

> 華陽國志曰維惡黄皓恣擅啟後主欲殺之後主曰皓趨走小臣耳往董允切齒吾常恨之君何足介意維見皓枝附葉連懼於失言遜辭而出後主勅皓詣維陳謝

**姜维请刘禅杀黄皓，刘禅令其致歉** 黄皓恣意用权，姜维请刘禅杀他。后主称黄皓是奔走小臣，并说自己一直不满董允疾恶黄皓。姜维见其党羽多，婉词离开，后主令黄皓上门道歉。

**归年依据** 《后主传》景耀元年记黄皓始专政；《资治通鉴》卷078在262洮阳战事后用“初”追叙，胡三省注指是战前，初次争论的独立年份失载。

<a id="pei-012-2"></a>

> 維說皓求沓中種麥以避内逼爾

**姜维争取到沓中种麦** 姜维说服黄皓，让自己在沓中种麦，借此避开成都朝中的排挤和压力。

**归年依据** 《资治通鉴》卷078明系景元三年姜维返自洮阳后求屯种，吕思勉等后世辨说不作为本条依据。

## 013｜《汉晋春秋》记蒋舒降胡烈与傅佥战死

<a id="pei-013-1"></a>

> 漢晉春秋曰蔣舒將出降乃詭謂傅僉曰今賊至不撃而閉城自守非良圖也僉曰受命保城惟全為功今違命出戰若䘮師負國死無益矣舒曰子以保城獲全為功我以出戰克敵為功請名行其志遂率衆出僉謂其戰也至隂平以降胡烈烈乘虚襲城僉格鬭而死魏人義之

**《汉晋春秋》记蒋舒降胡烈与傅佥战死** 蒋舒借口出战，骗过决守的傅佥，带兵至阴平投降胡烈。胡烈袭城，傅佥格斗而死，魏人称其义。

**归年依据** 《钟会传》《资治通鉴》卷078景元四年别遣胡烈攻阳安关口，与正文“蔣舒開城出降，傅僉格鬥而死”同役。

[263年第26条](../../years/ce-0201-0300/ce-0263.md#sgz044-p-013-1)。

<a id="pei-013-2"></a>

> 蜀記曰蔣舒為武興督在事無稱蜀命人代之因留舒助漢中守舒恨故開城出降

**《蜀记》解释蒋舒投降起因** 《蜀记》说蒋舒任武兴督时没有功绩，蜀任命他人接替，留蒋舒增援汉中，他因怀怨而开城降敌。

**归年依据** 景元四年阳安关陷落同事；被撤换的任期及时间无载，不从关陷之年倒推。

[263年第26条](../../years/ce-0201-0300/ce-0263.md#sgz044-p-013-2)。

## 015｜《世语》论姜维为蜀官中翘楚

维基文库四库本原行 13—13。附见[正文 L2080](../本地分卷/三国志/三国志-卷044.md#l2080)。

<a id="pei-015-1"></a>

> 世語曰時蜀官屬皆天下英俊無出維右

**《世语》论姜维为蜀官中翘楚** 《世语》说当时蜀汉官属都是俊杰，其中没有超过姜维的。

**归年依据** 这是附在钟会给姜维品评之后的后世评语，无独立事年。

## 016｜《汉晋春秋》记姜维揣摩钟会心意

维基文库四库本原行 13—13。附见[正文 L2080](../本地分卷/三国志/三国志-卷044.md#l2080)。

<a id="pei-016-1"></a>

> 漢晉春秋曰會隂懐異圖維見而知其心謂可構成擾亂以圖克復也乃詭說會曰聞君自淮南以來算無遺策晉道克昌皆君之力今復定蜀威徳振世民髙其功主畏其謀欲以此安歸乎夫韓信不背漢於擾攘以見疑於既平大夫種不從范蠡於五湖卒伏劍而妄死彼豈闇主愚臣哉利害使之然也今君大功既立大徳已著何不法陶朱公泛舟絶迹全功保身登峨嵋之嶺而從赤松游乎會曰君言遠矣我不能行且為今之道或未盡於此也維曰其他則君智力之所能無煩於老夫矣由是情好歡甚

**《汉晋春秋》记姜维揣摩钟会心意** 姜维试探钟会，举韩信、文种为例，称他灭蜀功高会使君主疑惧，劝他学范蠡退隐。钟会答不愿如此，姜维说其他办法钟会自能筹划，两人由是亲近。

**归年依据** 《资治通鉴》卷078置这番话于263年、264年下诏槛车征邓艾之前；不与成都起兵当日混作同一层。

[263年第13条](../../years/ce-0201-0300/ce-0263.md#sgz044-p-016-1)。

<a id="pei-016-2"></a>

> 華陽國志曰維教會誅北來諸將諸將既死徐欲殺會盡坑魏兵還復蜀祚密書與後主曰願陛下忍數日之辱臣欲使社稷危而復安日月幽而復明

**《华阳国志》记姜维密谋恢复蜀汉** 常璩书称姜维劝钟会诛北来诸将，再打算杀钟会、尽坑魏兵、恢复蜀汉，密书刘禅请暂忍数日之辱。

**归年依据** 《资治通鉴》卷078景元五年正月钟会兵变纪事采载姜维密谋；属于可考的谋议与史源表述，计划未实施。

[264年第4条](../../years/ce-0201-0300/ce-0264.md#sgz044-p-016-2)。

<a id="pei-016-3"></a>

> 孫盛晉陽秋曰盛以永和初從安西將軍平蜀見諸故老及

**孙盛随桓温平蜀，见蜀中故老** 孙盛追记自己在晋永和初随安西将军平蜀，见了当地故老、并提及下文姜维密疏。

**归年依据** 《晋书·穆帝纪》桓温永和二年十一月伐蜀、三年三月克成都；见故老连入永和三年。

[347年第1条](../../years/ce-0301-0400/ce-0347.md#sgz044-p-016-3)。

<a id="pei-016-4"></a>

> 姜維既降之後密與劉禪表疏說欲偽服事鍾會因殺之以復蜀土會事不㨗遂至泯滅蜀人于今傷之

**《晋阳秋》追述姜维曾密疏刘禅** 孙盛称姜维投降后密疏刘禅，打算假意服事钟会，再杀钟会恢复蜀地；钟会举事失败，蜀人仍以为哀。

**归年依据** 这是孙盛追记的景元五年同一密谋，不是他在永和年间另见姜维。

[264年第4条](../../years/ce-0201-0300/ce-0264.md#sgz044-p-016-4)。

<a id="pei-016-5"></a>

> 盛以為古人云非所困而困焉名必辱非所據而據焉身必危既辱且危死期將至其姜維之謂乎鄧艾之入江油士衆鮮少維進不能奮節緜竹之下退不能總帥五將擁衛蜀主思後圖之計而乃反覆於逆順之間希違情於難冀之會以衰弱之國而屢觀兵於三秦已滅之邦冀理外之竒舉不亦闇哉

**孙盛责姜维伐魏、亡国时不能安主** 孙盛援古说比姜维自取困危，责其在邓艾入蜀时没能在绵竹抗敌或护卫刘禅，反在蜀亡后寄望罕见的机会。

**归年依据** 史家合评数年战争与263–264鼎革，无孙盛定稿年。

[孙盛责姜维伐魏、亡国时不能安主（时期）](../../years/ce-0201-0300/时期-三国志卷044-蒋琬费祎姜维传纪年待考.md#period-sgz044-p-016-5)。

<a id="pei-016-6"></a>

> 臣松之以為盛之譏維又為不當于時鍾㑹大衆既造劍閣與維諸將列營守險㑹不得進已議還計全蜀之功幾乎立矣但鄧艾詭道傍入出於其後諸葛瞻既敗成都自潰維若回兵救内則會乘其背當時之勢焉得兩濟而責維不能奮節緜竹擁衛蜀主非其理也

**裴松之答孙盛：蜀难同时挡钟会和邓艾** 裴松之称姜维固守剑阁，魏军几退；邓艾从旁道到其后、诸葛瞻败后，姜维若回军又会被钟会从后突击，无从兼顾。

**归年依据** 评论针对景元四年剑阁、阴平和绵竹诸役；裴松之作注时间不是论中史事发生年。

[裴松之答孙盛：蜀难同时挡钟会和邓艾（时期）](../../years/ce-0201-0300/时期-三国志卷044-蒋琬费祎姜维传纪年待考.md#period-sgz044-p-016-6)。

<a id="pei-016-7"></a>

> 會欲盡坑魏將以舉大事授維重兵使為前驅若令魏將皆死兵事在維手殺會復蜀不為難也夫功成理外然後為竒不可以事有差牙而抑謂不然設使田單之計邂逅不會復可謂之愚闇哉

**裴松之答孙盛：恢复蜀汉原有条件** 裴松之认为钟会若杀魏将并把重兵交姜维，姜维就可能反杀钟会；用田单之计说明不能因结果失败就判谋画愚昧。

**归年依据** 南朝裴松之对264年兵变的一段反事实论证，无一条可独立确年的实施事件。

[裴松之答孙盛：恢复蜀汉原有条件（时期）](../../years/ce-0201-0300/时期-三国志卷044-蒋琬费祎姜维传纪年待考.md#period-sgz044-p-016-7)。

## 017｜《世语》载姜维死后剖视之说

维基文库四库本原行 13—13。附见[正文 L2080](../本地分卷/三国志/三国志-卷044.md#l2080)。

<a id="pei-017-1"></a>

> 世語曰維死時見剖膽如斗大

**《世语》载姜维死后剖视之说** 《世语》称姜维死时被剖视，胆如斗大，属该书所记异闻。

**归年依据** 死于景元五年钟会兵变，《陈留王纪》《钟会传》可证；斗大一语仅为异闻，四库实有“斗”，点校示补。

## 018｜孙盛批评郤正对姜维的褒扬

维基文库四库本原行 13—13。附见[正文 L2081](../本地分卷/三国志/三国志-卷044.md#l2081)。

<a id="pei-018-1"></a>

> 孫盛曰異哉郤氏之論也夫士雖百行操業萬殊至於忠孝義節百行之冠冕也姜維䇿名魏室而外奔蜀朝違君徇利不可謂忠捐親茍免不可謂孝害加舊邦不可謂義敗不死難不可謂節且徳政未敷而疲民以逞居禦侮之任而致敵䘮守於夫智勇莫可云也凡斯六者維無一焉實有魏之逋臣亡國之亂相而云人之儀表斯亦惑矣縱維好書而微自藻潔豈異夫盗者分財之義而程鄭降階之善也

**孙盛批评郤正对姜维的褒扬** 孙盛说士人最重忠孝义节，批姜维离魏、弃亲、攻旧国、败而未死、劳民和失守，各不合其尺度，不可因好学自律就视为表率。

**归年依据** 史论横贯228年归蜀至蜀汉灭亡，无独立事年。

[孙盛批评郤正对姜维的褒扬（时期）](../../years/ce-0201-0300/时期-三国志卷044-蒋琬费祎姜维传纪年待考.md#period-sgz044-p-018-1)。

<a id="pei-018-2"></a>

> 臣松之以為郤正此論取其可稱不謂維始終行事皆可凖則也所云一時儀表止在好學與儉素耳本傳及魏略皆云維本無叛心以急逼歸蜀盛相譏貶惟可責其背母餘既過苦又非所以難郤正也

**裴松之为郤正辩，指出归蜀的两种记载** 裴松之说郤正只取姜维好学节俭，不称全生可为准则；本传、《魏略》都显示他原无叛心，被逼后才归蜀，疑批评中仅背母一项有据。

**归年依据** 这是南朝裴松之论郤正、孙盛及228年归蜀诸书异同。

## 019｜裴松之论蒋琬、费祎遵制及守蜀

维基文库四库本原行 14—14。附见[正文 L2083](../本地分卷/三国志/三国志-卷044.md#l2083)。

<a id="pei-019-1"></a>

> 臣松之以為蔣費為相克遵畫一未嘗徇功妄動有所虧䘮外却駱谷之師内保寧緝之實治小之宜居靜之理何以過於此哉今議其未盡而不著其事故使覽者不知所謂也

**裴松之论蒋琬、费祎遵制及守蜀** 裴松之以二人不妄求事功、外退骆谷来兵、内保安宁反驳陈寿“未尽治小之宜”之论，并认为陈寿没有举出失当事例。

**归年依据** 论总体治理；退骆谷师是所举244兴势实例，非评论年份。

## 020｜干宝评姜维死节时机

维基文库四库本原行 14—14。附见[正文 L2083](../本地分卷/三国志/三国志-卷044.md#l2083)。

<a id="pei-020-1"></a>

> 干寶曰姜維為蜀相國亡主辱弗之死而死於鍾㑹之亂惜哉非死之難處死之難也是以古之烈士見危授命投節如歸非不愛死也固知命之不長而懼不得其所也

**干宝评姜维死节时机** 干宝慨叹姜维居蜀重职，在国亡主辱时不死，却死于钟会之乱，认为难的是死得其所。

**归年依据** 晋人评263年蜀亡与264年兵变两事，无独立评议之年。

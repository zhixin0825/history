## 001｜《江表传》记孙权出生形貌

维基文库四库本原行 11—11。附见[正文 L2269](../本地分卷/三国志/三国志-卷047.md#l2269)。

<a id="pei-001-1"></a>

> 江表傳曰堅為下邳丞時權生方頤大口目有精光堅異之以為有貴象

**《江表传》记孙权出生形貌** 孙权出生时孙坚任下邳丞。孙坚因他骨相、目有神采，以为不凡。

**归年依据** 只知孙坚任职。依建安初年龄和252年享年推182年前后，古注无独立生日。

[《江表传》记孙权出生形貌（时期）](../../years/ce-0201-0300/时期-三国志卷047-吴主传纪年待考.md#period-sgz047-p-001-1)。

<a id="pei-001-2"></a>

> 及堅亡策起事江東權常隨從性度弘朗仁而多斷好俠飬士始有知名侔於父兄矣每參同計謀策甚竒之自以為不及也每請會賔客常顧權曰此諸君汝之将也

**孙权从孙策并获其赞誉** 孙坚去世后，孙权常随孙策征伐，广交士人、能决事，参谋受兄赞赏。孙策告孙权宾客将为其部属。

**归年依据** 孙策早期江东征战，分项无年月。

[孙权从孙策并获其赞誉（时期）](../../years/ce-0201-0300/时期-三国志卷047-吴主传纪年待考.md#period-sgz047-p-001-2)。

维基文库四库本原行 13—13。附见[正文 L2270](../本地分卷/三国志/三国志-卷047.md#l2270)。

<a id="pei-002-1"></a>

> 臣松之按禮記曾子問子夏曰三年之喪金革之事無避也者禮與初有司與孔子曰吾聞諸老聃曰昔者魯公伯禽有為為之也鄭氏注曰周人卒哭而致事時有徐戎作難伯禽卒哭而征之急王事也昭所云伯禽不師蓋謂此也

## 003｜孙策表李术为庐江太守

维基文库四库本原行 13—13。附见[正文 L2270](../本地分卷/三国志/三国志-卷047.md#l2270)。

<a id="pei-003-1"></a>

> 江表傳曰初策表用李術為廬江太守

**孙策表李术为庐江太守** 孙策表任李术守庐江。

**归年依据** 《孙策传》裴注所引《江表传》明记孙策克皖后表用李术，《资治通鉴》卷六十三系建安四年。

[199年第27条](../../years/ce-0101-0200/ce-0199.md#sgz047-p-003-1)。

<a id="pei-003-2"></a>

> 策亡之後術不肯事權而多納其亡叛權移書求索術報曰有徳見歸無徳見叛不應復還

**李术不奉孙权并收纳亡叛** 李术在孙策死后不肯奉孙权，收纳其逃亡者，拒绝归还。

**归年依据** 《江表传》系孙策去世之后。《通鉴》卷六十三叙200年。

[200年第50条](../../years/ce-0101-0200/ce-0200.md#sgz047-p-003-2)。

<a id="pei-003-3"></a>

> 權大怒乃以状白曹公曰嚴刺史昔為公所用又是州舉将而李術凶惡輕犯漢制殘害州司肆其無道宜速誅滅以懲醜類今欲討之進為國朝掃除鯨鯢退為舉将報塞怨讎此天下達義夙夜所甘心術必懼誅復詭説求救明公所居阿衡之任海内所瞻願勑執事勿復聼受

**孙权请曹操拒救李术** 孙权陈说李术杀旧刺史严象，宣布讨伐，要求曹操拒绝李术将来的求援。

**归年依据** 《通鉴》卷六十三同系建安五年，严象见魏纪及裴注。

[200年第50条](../../years/ce-0101-0200/ce-0200.md#sgz047-p-003-3)。

<a id="pei-003-4"></a>

> 是歲舉兵攻術於皖城術閉門自守求救於曹公曹公不救糧食乏盡婦女或丸泥而吞之遂屠其城梟術首徙其部曲三萬餘人

**孙权破皖城杀李术** 李术守皖、曹操不救，粮尽时有人吞泥，孙权攻克斩李术，迁其部众三万余。

**归年依据** 本注系孙策死年。《通鉴》记部曲二万余，两载各存。

[200年第50条](../../years/ce-0101-0200/ce-0200.md#sgz047-p-003-4)。

## 004｜孙权杀沈友

维基文库四库本原行 16—16。附见[正文 L2273](../本地分卷/三国志/三国志-卷047.md#l2273)。

<a id="pei-004-1"></a>

> 吳錄曰是時權大㑹官寮沈友有所是非令人扶出謂曰人言卿欲反友知不得脱乃曰主上在許有無君之心者可謂非反乎遂殺之

**孙权杀沈友** 官宴上沈友论政，孙权命扶出，问谋反之言，沈友以献帝尚在、众有无君之心回应，被孙权所杀。

**归年依据** 裴注以“是時”附建安九年，未有月日。

[204年第30条](../../years/ce-0201-0300/ce-0204.md#sgz047-p-004-1)。

<a id="pei-004-2"></a>

> 友字子正吳郡人年十一華歆行風俗見而異之因呼曰沈郎可登車語乎友逡廵却曰君子講好㑹晏以禮今仁義陵遲聖道漸壊先生銜命将以禆補先王之教整齊風俗而輕脱威儀猶負薪救火無乃更崇其熾乎歆慙曰自桓靈以來雖多英彦未有㓜童若此者

**少年沈友质问华歆威仪** 华歆巡视风俗时请十一岁的沈友登车语，沈友认为当以礼修风俗，不可失威仪，华歆惭而称奇。

**归年依据** 只载岁数，无法独立定年。

[少年沈友质问华歆威仪（时期）](../../years/ce-0201-0300/时期-三国志卷047-吴主传纪年待考.md#period-sgz047-p-004-2)。

<a id="pei-004-3"></a>

> 弱冠博學多所貫綜善屬文辭兼好武事注孫子兵法又辯於口每所至衆人皆黙然莫與為對咸言其筆之妙舌之妙刀之妙三者皆過絶於人

**沈友以文章、辩才和武艺见称** 沈友博学著文，注《孙子》，又善辩与武事，有笔、舌、刀三妙之誉。

**归年依据** 人物综述。

[沈友以文章、辩才和武艺见称（时期）](../../years/ce-0201-0300/时期-三国志卷047-吴主传纪年待考.md#period-sgz047-p-004-3)。

<a id="pei-004-4"></a>

> 權以禮聘既至論王覇之略當時之務權歛容敬焉陳荆州宜并之計納之

**沈友受聘，建议兼并荆州** 孙权礼请沈友，听其论王霸和时务，接受并荆州计划。

**归年依据** 其事在204年前，未记确年。

[沈友受聘，建议兼并荆州（时期）](../../years/ce-0201-0300/时期-三国志卷047-吴主传纪年待考.md#period-sgz047-p-004-4)。

<a id="pei-004-5"></a>

> 正色立朝清議峻厲為庸臣所譖誣以謀反權亦以終不為己用故害之時年二十九

**孙权杀沈友** 沈友好严正清议，遭人谗告谋反。注以孙权疑他不会为己所用而杀他，时年二十九。

**归年依据** 同一沈友案，注从上承建安九年。

[204年第30条](../../years/ce-0201-0300/ce-0204.md#sgz047-p-004-5)。

## 008｜曹操致书威胁孙权

## 009｜曹军夜渡濡须中洲为吴所败

维基文库四库本原行 23—23。附见[正文 L2280](../本地分卷/三国志/三国志-卷047.md#l2280)。

<a id="pei-009-1"></a>

> 吳歴曰曹公出濡須作油船夜渡洲上權以水軍圍取得三千餘人其沒溺者亦數千人

**曹军夜渡濡须中洲为吴所败** 曹操造油船夜渡，孙权以水军围攻，记载曹军被俘和溺亡各数千。

**归年依据** 黄武纪元前，建安十八年正月濡须之战。《通鉴》卷六十六互见战局。

[213年第10条](../../years/ce-0201-0300/ce-0213.md#sgz047-p-009-1)。

<a id="pei-009-2"></a>

> 權數挑戰公堅守不出權乃自來乗輕船從濡湏口入公軍諸將皆以為是挑戰者欲擊之公曰此必孫權欲身見吾軍部伍也勒軍中皆精嚴弓弩不得妄發

**孙权乘轻船观察曹军** 孙权多次挑战，曹操不出，孙权遂驾轻船进入濡须口。曹操判断孙权来观军，命严整而不许妄发弓矢。

**归年依据** 同役，《吴历》一说。

[213年第10条](../../years/ce-0201-0300/ce-0213.md#sgz047-p-009-2)。

<a id="pei-009-3"></a>

> 權行五六里廻還作鼔吹公見舟船器仗軍伍整肅喟然歎曰生子當如孫仲謀劉景升兒子若豚犬耳

**曹操赞孙权军整** 孙权行五六里后鼓吹返回，曹操见其舟船部伍严整，赞叹孙仲谋而轻刘表之子。

**归年依据** 同役，《吴历》一说。

[213年第10条](../../years/ce-0201-0300/ce-0213.md#sgz047-p-009-3)。

<a id="pei-009-4"></a>

> 權為牋與曹公説春水方生公宜速去别紙言足下不死孤不得安曹公語諸将曰孫權不欺孤乃徹軍還

**孙权劝曹操避春水撤军** 孙权以江水将涨劝曹操早走，另说曹操不死不得安，曹操以为没有欺骗而引还。

**归年依据** 同役。

[213年第10条](../../years/ce-0201-0300/ce-0213.md#sgz047-p-009-4)。

<a id="pei-009-5"></a>

> 魏略曰權乗大船來觀軍公使弓弩亂發箭著其船船偏重将覆權因廻船復以一面受箭箭均船平乃還

**孙权转船均受箭的异说** 《魏略》称曹操命乱箭射孙权船，船一侧受箭偏重，孙权调船使另一侧也受箭，才平衡归去。

**归年依据** 与《吴历》说曹操禁止发箭互异，都是濡须阅军的叙法。

[213年第10条](../../years/ce-0201-0300/ce-0213.md#sgz047-p-009-5)。

## 011｜张辽事后问降人紫髯将军身份

维基文库四库本原行 24—24。附见[正文 L2281](../本地分卷/三国志/三国志-卷047.md#l2281)。

<a id="pei-011-1"></a>

> 獻帝春秋曰張遼問吳降人向有紫髯将軍長上短下便馬善射是誰降人答曰是孫㑹稽遼及樂進相遇言不早知之急追自得舉軍歎恨

**张辽事后问降人紫髯将军身份** 张辽向吴降人问及善骑射的紫髯将军，得知是孙权；他与乐进都恨没有早认出孙权而猛追。

**归年依据** 《献帝春秋》记逍遥津战后。

> 江表傳曰權乘駿馬上津橋橋南已見徹丈餘無版谷利在馬後使權持鞍緩控利於後著鞭以助馬勢遂得超度權既得免即拜利都亭侯

**谷利助孙权越津桥** 孙权马到津桥，南侧缺板。谷利在后助鞭，孙权越过后授谷利都亭侯。

**归年依据** 《江表传》补本纪逍遥津战事。

**归年依据** 生平概述。

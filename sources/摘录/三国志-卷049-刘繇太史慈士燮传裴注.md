## 001｜《续汉书》记刘繇祖父为儒者

维基文库四库本原行 11—11。附见[正文 L2384](../本地分卷/三国志/三国志-卷049.md#l2384)。

<a id="pei-001-1"></a>

> 續漢書曰繇祖父本師受經傳博學羣書號為通儒舉賢良方正為般長卒官

**《续汉书》记刘繇祖父为儒者** 从师受经、博学群书，举贤良方正为般长，卒于官。

**归年依据** 《后汉书·刘宠传》记刘宠父名丕；任卒无独立年。

[《续汉书》记刘繇祖父为儒者（时期）](../../years/ce-0201-0300/时期-三国志卷049-刘繇太史慈士燮传纪年待考.md#period-sgz049-p-001-1)。

<a id="pei-001-2"></a>

> 寵字祖榮受父業以經明行脩舉孝廉光禄大夫察四行除東平陵令視事數年以母病棄官百姓士民攀輿拒輪充塞道路車不得前乃止亭輕服潛遁歸脩供飬

**刘宠早期举孝廉、出宰东平陵** 因母病离职，百姓攀车阻行，刘宠换轻服离去奉母。

**归年依据** 初仕和离任年份无载；注中“光禄大夫察四行”是察举背景。

[刘宠早期举孝廉、出宰东平陵（时期）](../../years/ce-0201-0300/时期-三国志卷049-刘繇太史慈士燮传纪年待考.md#period-sgz049-p-001-2)。

<a id="pei-001-3"></a>

> 後辟大將軍府稍遷㑹稽太守正身率下郡中大治徴入為將作大匠山隂縣民去治數十里有若邪中在山谷間五六老翁年皆七八十聞寵遷相率共送寵人齎百錢寵見勞來曰父老何乃自苦逺來皆對曰山谷鄙老生未嘗至郡縣他時吏發求不去民間或夜不絶狗吠竟夕民不得安自明府下車以來狗不夜吠吏稀至民間年老遭值聖化今聞當見棄去故勠力來送寵謝之為選受一大錢故㑹稽號寵為取一錢太守其清如是

**刘宠治会稽，父老送百钱而仅受一钱** 刘宠外任时治理有方，被召为将作大匠时老人送别，刘宠各择一大钱，得一钱太守之号。

**归年依据** 《后汉书·刘宠传》也有此事；任期与辞郡月年未载。

[刘宠治会稽，父老送百钱而仅受一钱（时期）](../../years/ce-0201-0300/时期-三国志卷049-刘繇太史慈士燮传纪年待考.md#period-sgz049-p-001-3)。

<a id="pei-001-4"></a>

> 寵前後歴二郡八居九列四登三事家不藏賄無重寳器恒菲飲食薄衣服弊車羸馬號為窶陋三去相位輒歸本土往來京師嘗下道脱驂過人莫知焉寵嘗欲止亭亭吏止之曰整頓傳舎以待劉公不可得止寵因過去其廉儉皆此類也以老病卒於家

**刘宠历任九卿三公而清俭** 饮食薄、车马敝，多次罢相归里，曾一度因驿馆预留房间而不住，老病卒。

**归年依据** 历官、清廉故事和卒年不能一起系169，任太尉另见正文。

[刘宠历任九卿三公而清俭（时期）](../../years/ce-0201-0300/时期-三国志卷049-刘繇太史慈士燮传纪年待考.md#period-sgz049-p-001-4)。

## 006｜《吴历》说太史慈在神亭被擒并如约返

维基文库四库本原行 12—12。附见[正文 L2395](../本地分卷/三国志/三国志-卷049.md#l2395)。

<a id="pei-006-1"></a>

> 呉歴云慈於神亭戰敗為䇿所執䇿素聞其名即解縛請見咨問進取之術慈答曰破軍之將不足與論亊策曰昔韓信定計於廣武今策决疑於仁者君何辭焉慈曰州軍新破士卒離心若倘分散難復合聚欲出宣恩安集恐不合尊意䇿長跪答曰誠夲心所望也明日中望君来還諸軍皆疑策曰太史子義靑州名士以信義為先終不欺䇿明日大請諸將豫設酒食立竿視影日中而慈至策大恱常與參論諸軍亊

**《吴历》说太史慈在神亭被擒并如约返** 孙策擒而释太史慈并询进取。太史慈请往收散兵，孙策定第二日中见，太史慈赶到。

**归年依据** 从《吴历》所托195神亭。它把被擒位置、两次收抚故事与本传记法记得不同，裴松之明确存疑。

[195年第43条](../../years/ce-0101-0200/ce-0195.md#sgz049-p-006-1)。

<a id="pei-006-2"></a>

> 臣松之按呉歴云慈於神亭戰敗為䇿所得與本傳大異疑為謬誤

**裴松之辨神亭被擒异说** 裴松之指出《吴历》所言神亭已为孙策擒获，与本传相差大，疑《吴历》错误。

**归年依据** 史家考辨；相关本事正文分195神亭、198勇里。

[裴松之辨神亭被擒异说（时期）](../../years/ce-0201-0300/时期-三国志卷049-刘繇太史慈士燮传纪年待考.md#period-sgz049-p-006-2)。

<a id="pei-006-3"></a>

> 江表傳曰策謂慈曰聞卿昔為太守刼州章赴文舉請詣玄徳皆有烈義天下智士也但所託未得其人射鉤斬祛古人不嫌孤是卿知己勿憂不如意也出教曰龍欲騰翥先階尺水者也

**孙策擒太史慈，解缚任将** 以太史慈救孔融、截州章夸其烈义，称自己是知己，又布教少有尝试才可大用。

**归年依据** 《通鉴》卷062记建安三年勇里擒后，采其中言语。

[198年第30条](../../years/ce-0101-0200/ce-0198.md#sgz049-p-006-3)。

## 007｜太史慈受命收抚刘繇故众

维基文库四库本原行 12—12。附见[正文 L2395](../本地分卷/三国志/三国志-卷049.md#l2395)。

<a id="pei-007-1"></a>

> 江表傳曰策謂慈曰劉牧往責吾為袁氏攻廬江其意頗猥理恕不足何者先君手下兵數千餘人盡在公路許孤志在立亊不得不屈意於公路求索故兵再往纔得千餘人耳仍令孤攻廬江爾時亊勢不得不為行但其後不達臣節自棄作邪僭亊諌之不從丈夫義交苟有大故不得不離孤交求公路及絶之本末如此今劉繇喪亡恨不及其生時與共論辯今兒子在豫章不知華子魚待遇如何其故部曲復依随之否卿則州人昔又從事寧能往視其兒子並宣孤意於其部曲部曲樂来者便與俱来不樂来者且安慰之并觀察子魚所以牧禦方規何似視廬陵鄱陽人民親附之否卿手下兵宜將多少自由意慈對曰慈有不赦之罪將軍量同桓文待遇過望古人報生以死期於盡節沒而後已今並息兵兵不宜多將數十人自足以往還也

**太史慈受命收抚刘繇故众** 孙策回顾从袁术领回父兵与绝袁，命太史慈视刘繇家与华歆、各郡和故部。太史慈请少带人。

**归年依据** 《通鉴》卷062把建安三年刘繇卒、遣太史慈接叙；前文袁术旧事为谈话所引。

[198年第31条](../../years/ce-0101-0200/ce-0198.md#sgz049-p-007-1)。

<a id="pei-008-1"></a>

> 江表傳曰䇿初遣慈也議者紛紜謂慈未可信或云與華子魚州里恐留彼為籌策或疑慈西託黄祖假路還北多言遣之非計策曰諸君語皆非也孤斷之詳矣太史子義雖氣勇有膽烈然非縱横之人其心有士謨志經道義貴重然諾一以意許知己死亡不相負諸君勿復憂也慈從豫章還議者乃始服慈見策曰華子魚良徳也然非籌略才無他方規自守而已又丹陽僮芝自擅廬陵詐言被詔書為太守鄱陽民帥别立宗部阻兵守界不受子魚所遣長吏言我以别立郡須漢遣真太守来當迎之耳子魚不但不能諧廬陵鄱陽近自海昬有上繚壁有五六千家相結聚作宗伍惟輸租布於郡耳發召一人遂不可得子魚亦覩視之而已䇿拊掌大笑仍冇兼并之志矣

## 012｜士䵋名的字音

维基文库四库本原行 13—13。附见[正文 L2400](../本地分卷/三国志/三国志-卷049.md#l2400)。

<a id="pei-012-1"></a>

> 䵋音于鄙反見字林

**士䵋名的字音** 据《字林》，䵋音于鄙反。

**归年依据** 音释。

## 013｜《神仙传》记董奉使士燮复苏故事

维基文库四库本原行 13—13。附见[正文 L2402](../本地分卷/三国志/三国志-卷049.md#l2402)。

<a id="pei-013-1"></a>

> 葛洪神仙傳曰爕嘗病死已三日仙人董奉以一丸藥與服以水含之捧其頥搖稍之食頃即䦕目動手顔色漸復半日能起坐四日復能語遂復常奉字君異候官人也

**《神仙传》记董奉使士燮复苏故事** 士燮据称病死三日，董奉给丸药后苏醒，四日后复能说话；末附董奉名字籍贯。

**归年依据** 志怪故事无年，不能与黄武五年真实卒年并条。

## 014｜孙盛称信义是远服与安近的根本

维基文库四库本原行 13—13。附见[正文 L2405](../本地分卷/三国志/三国志-卷049.md#l2405)。

<a id="pei-014-1"></a>

> 孫盛曰夫柔逺能邇莫善於信保大定功莫善於義故齊桓創基徳彰於柯㑹晉文始霸義顯於伐原故能九合一匡世主夏盟令問長世貽範百王

**孙盛称信义是远服与安近的根本** 以齐桓公柯会和晋文公伐原为例。

**归年依据** 史论与古代典故，用于批评后面的吕岱行为。

[孙盛称信义是远服与安近的根本（时期）](../../years/ce-0201-0300/时期-三国志卷049-刘繇太史慈士燮传纪年待考.md#period-sgz049-p-014-1)。

<a id="pei-014-2"></a>

> 吕岱師友士匡使通信誓徽兄弟肉袒推心委命岱因滅之以要功利君子是以知孫權之不能逺畧而吕氏之祚不延者也

**孙盛批评吕岱诛已请降的士徽兄弟** 认为士匡替吕岱通有信用的约，士徽等投降却被杀以求功，并批评孙吴难以远略。

**归年依据** 史论，所评平士徽见226年第29条。

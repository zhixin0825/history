## 002｜《会稽典录》述周昕家学及出仕

维基文库四库本原行 11—11。附见[正文 L2440](../本地分卷/三国志/三国志-卷051.md#l2440)。

<a id="pei-002-1"></a>

> 㑹稽典錄曰昕字大明少游京師師事太傅陳蕃博覧羣書明於風角善推災異辟太尉府舉髙第稍遷丹陽太守

**《会稽典录》述周昕家学及出仕** 周昕字大明，曾在京师从太傅陈蕃学习，博学而通风角灾异；入太尉府、举高第，后任丹杨太守。

**归年依据** 周昕早年与仕历合叙，没有初仕及任郡确年。

[《会稽典录》述周昕家学及出仕（时期）](../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考（1）.md#period-sgz051-p-002-1)。

<a id="pei-002-2"></a>

> 曹公起義兵昕前後遣兵萬餘人助公征伐袁術之在淮南也昕惡其滛虐絶不與通

**周昕支持曹操起兵并拒袁术交往** 曹操起兵后周昕前后发万余援兵；袁术到淮南后，周昕厌其残暴，不同他往来。

**归年依据** 曹操于189年底起兵，袁术193年到淮南；数次援兵和拒交没有独立年份。

[周昕支持曹操起兵并拒袁术交往（时期）](../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考（1）.md#period-sgz051-p-002-2)。

<a id="pei-002-3"></a>

> 獻帝春秋曰袁術遣吳景攻昕未㧞景乃募百姓敢從周昕者死不赦昕曰我則不徳百姓何罪遂〔四库字图340〕兵還本郡

**吴景逼退周昕而领丹杨** 吴景攻周昕未下，声称追随周昕者皆死；周昕不愿连累百姓，散兵回本郡。

**归年依据** 《通鉴》卷六十一以兴平元年载吴景逐周昕，成事时间从该系年；书中的四库字图为𣪚，通散。

## 003｜吴议由武昌迁都建业

维基文库四库本原行 14—14。附见[正文 L2449](../本地分卷/三国志/三国志-卷051.md#l2449)。

<a id="pei-003-1"></a>

> 江表傳曰初權在武昌欲遷都建業而慮水道泝流二千里一旦有警不相赴及以此懐疑及至夏口於塢中大㑹百官議之詔曰諸将吏勿拘位任其有計者為國言之諸將或陳宜立柵夏口或言宜重設鐵鎻者權皆以為非計

**吴议由武昌迁都建业** 孙权拟迁建业而怕溯流路远、有警难救，于夏口召集百官，不限身份请献计；有人主张立栅或设铁锁，孙权都不用。

**归年依据** 《吴主传》黄龙元年九月迁都建业；《江表传》所述为该次迁都议。

[229年第14条](../../years/ce-0201-0300/ce-0229.md#sgz051-p-003-1)。

<a id="pei-003-2"></a>

> 時梁為小將未有知名乃越席而進曰臣聞香餌引泉魚重幣購勇士今宜明樹賞罰之信遣將入沔與敵争利形勢既成彼不敢干也使武昌有精兵萬人付智畧者任將常使嚴整一旦有警應聲相赴作甘水城輕艦數千諸所冝用皆使備具如此開門延敵敵自不來矣

**张梁就迁都陈江防之议** 张梁主张建立明确赏罚，遣将入沔牵制魏军，在武昌备万人精兵待警，修甘水城，备轻舰器用。

**归年依据** 同次迁都前商议。

[229年第14条](../../years/ce-0201-0300/ce-0229.md#sgz051-p-003-2)。

<a id="pei-003-3"></a>

> 權以梁計為最得即超増梁位

**孙权采用张梁方案并升其位** 孙权认定此计最合适，破格提升张梁。

**归年依据** 承229迁都议。

[229年第14条](../../years/ce-0201-0300/ce-0229.md#sgz051-p-003-3)。

<a id="pei-003-4"></a>

> 後稍以功進至沔中督

**张梁后来升为沔中督** 张梁积功进至沔中督。

**归年依据** 《江表传》未记最后授任年。

[张梁后来升为沔中督（时期）](../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考（1）.md#period-sgz051-p-003-4)。

## 004｜吴景孙贲孙香在袁术麾下任职

维基文库四库本原行 15—15。附见[正文 L2452](../本地分卷/三国志/三国志-卷051.md#l2452)。

<a id="pei-004-1"></a>

> 江表傳曰袁術以呉景守廣陵䇿族兄香亦為術所用作汝南太守而令賁為將軍領兵在夀春

**吴景孙贲孙香在袁术麾下任职** 袁术用吴景守广陵、孙香守汝南，令孙贲在寿春掌兵。

**归年依据** 各职同时与否未明；《吴夫人传》附吴景，情况在袁术称帝前后。

[吴景孙贲孙香在袁术麾下任职（时期）](../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考（1）.md#period-sgz051-p-004-1)。

<a id="pei-004-2"></a>

> 策與景等書曰今征江東未知二三君意云何耳景即棄守歸賁因而獲免香以道逺獨不得還

**孙策招吴景等脱离袁术** 孙策写信问宗亲去就，吴景弃守回孙策处，孙贲也脱离袁术，孙香因路远未能回。

**归年依据** 本传《孙贲传》、附吴景事及《吴主传》连于袁术建安二年称帝、孙策绝交。

[197年第1条](../../years/ce-0101-0200/ce-0197.md#sgz051-p-004-2)。

<a id="pei-004-3"></a>

> 吳書曰香字文陽父儒字仲孺堅再從弟也仕郡主簿功曹香從堅征伐有功拜郎中後為袁術驅馳加征南将軍死於夀春

**孙香家世、随孙坚作战及后仕袁术** 孙香是孙坚再从弟孙儒之子，随孙坚征战后任郎中，后随袁术为征南将军，卒于寿春。

**归年依据** 随征、封号与卒年均无明文。

[孙香家世、随孙坚作战及后仕袁术（时期）](../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考（1）.md#period-sgz051-p-004-3)。

## 005｜孙策置庐陵，任孙辅太守

维基文库四库本原行 15—15。附见[正文 L2452](../本地分卷/三国志/三国志-卷051.md#l2452)。

<a id="pei-005-1"></a>

> 江表傳曰時丹陽僮芝自署廬陵太守策留賁弟輔領兵住南昌策謂賁曰兄今據豫章是扼僮芝咽喉而守其門戸矣但當伺其形便因令國儀杖兵而進使公瑾為作勢援一舉可定也

**孙策置庐陵，任孙辅太守** 僮芝自领庐陵，孙策留孙辅在南昌，嘱孙贲待机从豫章发兵，并令周瑜助势。

**归年依据** 《通鉴》卷六十三建安四年末叙分豫章置庐陵、用孙辅取郡；僮芝自署系更早背景。

[199年第36条](../../years/ce-0101-0200/ce-0199.md#sgz051-p-005-1)。

<a id="pei-005-2"></a>

> 後賁聞芝病即如策計周瑜到巴丘輔遂得進據廬陵

**孙策置庐陵，任孙辅太守** 孙贲听闻僮芝病，按孙策之计，使孙辅进据庐陵，周瑜至巴丘响应。

**归年依据** 《通鉴》卷六十三建安四年冬整段收录；《周瑜传》裴注辨巴丘并非后来巴陵一带。

[199年第36条](../../years/ce-0101-0200/ce-0199.md#sgz051-p-005-2)。

## 008｜《吴历》增录孙邻子孙任职

维基文库四库本原行 15—15。附见[正文 L2454](../本地分卷/三国志/三国志-卷051.md#l2454)。

<a id="pei-008-1"></a>

> 吳歴曰鄰又有子曰述為武昌督平荆州事震無難督諧城門校尉歆樂鄉督

**《吴历》增录孙邻子孙任职** 孙述任武昌督、平荆州事，孙震任无难督，孙谐任城门校尉，孙歆任乐乡督。

**归年依据** 宗室子弟任命无确年。

[《吴历》增录孙邻子孙任职（时期）](../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考（1）.md#period-sgz051-p-008-1)。

<a id="pei-008-2"></a>

> 震後禦晉單與張悌俱死

**孙震与张悌抗晋而战死** 孙震与张悌同御晋，战败身死。

**归年依据** 《晋书·武帝纪》太康元年与《通鉴》卷八十一明确记孙震、张悌阵亡；底本「單」字照存。

[280年第1条](../../years/ce-0201-0300/ce-0280.md#sgz051-p-008-2)。

<a id="pei-008-3"></a>

> 賁曽孫惠字徳施惠别傳曰惠好學有才智

**孙惠籍贯家世及才学** 孙惠字德施，是孙贲曾孙，爱好学习而有才识。

**归年依据** 为族系与性情总述。

[孙惠籍贯家世及才学（时期）](../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考（1）.md#period-sgz051-p-008-3)。

<a id="pei-008-4"></a>

> 晉永寧元年赴齊王冏義以功封晉興侯辟大司馬賊曹屬

**孙惠参与司马冏讨赵王伦** 孙惠应齐王司马冏起兵，因功封晋兴侯并入大司马幕府。

**归年依据** 本注明记永宁元年，《晋书·孙惠传》及《通鉴》卷八十四相证；《晋书》起本为户曹掾，注作贼曹属。

[301年第4条](../../years/ce-0301-0400/ce-0301.md#sgz051-p-008-4)。

<a id="pei-008-5"></a>

> 冏驕矜僭侈天下失望惠獻言於冏諷以五難四不可勸令委譲萬機歸藩青岱辭甚深切冏不能納

**孙惠谏齐王司马冏还藩** 司马冏骄纵僭侈，孙惠列风险，劝其辞权归藩，司马冏不听。

**归年依据** 司马冏301年掌朝至302年死间，奏疏未载确年。

[孙惠谏齐王司马冏还藩（时期）](../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考（1）.md#period-sgz051-p-008-5)。

<a id="pei-008-6"></a>

> 頃之果敗

**司马冏兵败遇诛** 司马冏不纳孙惠退藩之谏，不久果然败亡。

**归年依据** 《晋书·惠帝纪》《通鉴》卷八十四太安元年十二月。

[302年第2条](../../years/ce-0301-0400/ce-0302.md#sgz051-p-008-6)。

<a id="pei-008-7"></a>

> 成都王頴召為大將軍參軍

**司马颖召孙惠为参军** 成都王司马颖任孙惠为大将军参军。

**归年依据** 在司马冏败后、陆机任前锋之前，未记独立确年。

[司马颖召孙惠为参军（时期）](../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考（1）.md#period-sgz051-p-008-7)。

<a id="pei-008-8"></a>

> 是時頴将有事於長沙以陸機為前鋒都督惠與機鄉里親厚憂其致禍謂之曰子盍譲都督於王粹乎機曰將謂吾避賊首䑕更速其害機尋被戮二弟雲耽亦見殺惠甚傷恨之

**孙惠谏陆机辞都督，陆氏兄弟被杀** 司马颖征长沙王乂，使陆机作前锋；孙惠劝陆机让与王粹，陆机恐遭猜忌，随后遭诛，陆云、陆耽也被杀。

**归年依据** 《晋书·陆机传》《孙惠传》及《通鉴》卷八十五均证太安二年。

[303年第2条](../../years/ce-0301-0400/ce-0303.md#sgz051-p-008-8)。

<a id="pei-008-9"></a>

> 永興元年乗輿幸鄴司空東海王越治兵下邳惠以書干越詭其姓名自稱南岳逸民秦秘之勉以勤王匡世之畧辭義甚美越省其書牓題道衢推求其人惠乃出見越即以為記室參軍

**孙惠诣司马越并劝勤王** 惠帝幸邺，东海王司马越在下邳练兵，孙惠用化名致书劝勤王，司马越设法求得其人、引为记室参军。

**归年依据** 本注明记永兴元年，惠帝幸邺同《晋书·惠帝纪》。

[304年第2条](../../years/ce-0301-0400/ce-0304.md#sgz051-p-008-9)。

## 001｜应劭主张为旧君避讳

维基文库四库本原行 12—12。附见[正文 L2470](../本地分卷/三国志/三国志-卷052.md#l2470)。

<a id="pei-001-1"></a>

> 時汝南主簿應劭議宜為舊君諱論者皆互有異同事在風俗通

**应劭主张为旧君避讳** 汝南主簿应劭提出为旧日长官避名讳，论者各有异同，《风俗通》收录。

**归年依据** 应劭任主簿和著讨论均无明确年。

[应劭主张为旧君避讳（时期）](../../years/ce-0201-0300/时期-三国志卷052-张顾诸葛步传纪年待考（2）.md#period-sgz052-p-001-1)。

<a id="pei-001-2"></a>

> 昭著論曰客有見大國之議士君子之論云起元建武已來舊君名諱五十六人以為後生不得協也取乎經論譬諸行事義高辭麗甚可嘉羡愚意褊淺竊有疑焉

**张昭论旧君讳，起辨对方论据** 张昭转述对方从光武建武以后列旧君五十六人、主张后辈不可同名，先肯定辞义再提出疑问。

**归年依据** 论题追溯东汉初，成文无年。

[张昭论旧君讳，起辨对方论据（时期）](../../years/ce-0201-0300/时期-三国志卷052-张顾诸葛步传纪年待考（2）.md#period-sgz052-p-001-2)。

<a id="pei-001-3"></a>

> 葢乾坤剖分萬物定形肇有父子君臣之經故聖人順天之性制禮尚敬在三之義君實食之在喪之哀君親臨之厚莫重焉恩莫大焉誠臣子所尊仰萬夫所天恃焉得而同之哉

**张昭论君亲在礼中的地位** 父子君臣皆是礼之所尊，受其供养和关爱者应以重礼、哀丧表示敬仰。

**归年依据** 礼论，无独立年。

[张昭论君亲在礼中的地位（时期）](../../years/ce-0201-0300/时期-三国志卷052-张顾诸葛步传纪年待考（2）.md#period-sgz052-p-001-3)。

<a id="pei-001-4"></a>

> 然親親冇衰尊尊有殺故禮服上不盡髙祖下不盡玄孫又傳記四世而緦麻服之窮也五世袒免降殺同姓也六世而親屬竭矣

**张昭辨由亲疏贵贱递减的服礼** 称亲亲有服等、尊尊也有差等，礼丧随关系所及而止；不可把今君-臣关系不加区分归给旧君。

**归年依据** 礼论，无独立年。

[张昭辨由亲疏贵贱递减的服礼（时期）](../../years/ce-0201-0300/时期-三国志卷052-张顾诸葛步传纪年待考（2）.md#period-sgz052-p-001-4)。

<a id="pei-001-5"></a>

> 又曲禮有不逮事之義則不諱不諱者葢名之謂屬絶之義不拘於協况乃古君五十六哉

**张昭引《曲礼》辨避讳的适用范围** 以礼经引证，指出礼文所指各有范围，世次和称谓也有等差。

**归年依据** 礼论引文，无独立年。

[张昭引《曲礼》辨避讳的适用范围（时期）](../../years/ce-0201-0300/时期-三国志卷052-张顾诸葛步传纪年待考（2）.md#period-sgz052-p-001-5)。

<a id="pei-001-6"></a>

> 邾子會盟季友來歸不稱其名咸書字者是時魯人嘉之也何觧臣子為君父諱乎周穆王諱滿至定王時冇王孫滿者其為大夫是臣協君也又厲王諱胡及莊王之子名胡其比衆多

**张昭引《春秋》与旧事辨称名** 举邾子盟会等称名用法辨礼及权衡，看似相类的记载各有立意。

**归年依据** 古事用为论据，与成文分辨；行文未纪单年。

[张昭引《春秋》与旧事辨称名（时期）](../../years/ce-0201-0300/时期-三国志卷052-张顾诸葛步传纪年待考（2）.md#period-sgz052-p-001-6)。

<a id="pei-001-7"></a>

> 夫類事建議經冇眀據傳有徵案然後進攻退守萬無奔北垂示百世永無咎失

**张昭论由类比立义当可推及** 引类比拟议必须照顾语义和可贯彻的礼制；反对只取相似辞形便建立新制。

**归年依据** 礼论，无独立年。

[张昭论由类比立义当可推及（时期）](../../years/ce-0201-0300/时期-三国志卷052-张顾诸葛步传纪年待考（2）.md#period-sgz052-p-001-7)。

<a id="pei-001-8"></a>

> 今應劭雖上尊舊君之名而下無所斷齊猶歸之疑云曲禮之篇疑事無質觀省上下闕義自證文辭可為倡而不法將來何觀言聲一放猶拾瀋也過辭在前悔其何追

**张昭回应应劭并告诫慎言** 认为应劭重视旧君的初意可取，取法及章句自证尚有不足，成文可以激发讨论；已出之言难收。

**归年依据** 论辩作年无载。

[张昭回应应劭并告诫慎言（时期）](../../years/ce-0201-0300/时期-三国志卷052-张顾诸葛步传纪年待考（2）.md#period-sgz052-p-001-8)。

维基文库四库本原行 12—12。附见[正文 L2471](../本地分卷/三国志/三国志-卷052.md#l2471)。

> 吳書曰是時天下分裂擅命者衆孫策涖事日淺恩澤未洽一旦傾隕士民狼狽頗有同異及昭輔權綏撫百姓諸侯賓旅寄寓之士得用自安

**张昭辅助接位的孙权安定江东** 《吴书》称孙策临事不久即死，士民惊惧多异议，张昭扶孙权并安抚本地居民和侨寓士人。

**归年依据** 孙策200卒、孙权继掌江东；安抚实际可能延续。

**孙权出征留张昭主幕府** 孙权每出兵，往往使张昭居守，统摄幕府。

**归年依据** 任事多次。

**归年依据** 本事并208—209围合肥，《吴主传》《通鉴》作别攻当涂；保留两写法和战役分期。

## 006｜孙权即帝位，张昭欲称颂而受讥

维基文库四库本原行 12—12。附见[正文 L2473](../本地分卷/三国志/三国志-卷052.md#l2473)。

<a id="pei-006-1"></a>

> 江表傳曰權既即尊位請㑹百官歸功周堬昭舉笏欲褒贊功徳未及言權曰如張公之計今已乞食矣昭大慙伏地流汗

**孙权即帝位，张昭欲称颂而受讥** 孙权宴群臣把功劳归周瑜，张昭举笏欲称颂，孙权说听张昭的主意自己今日已在乞讨，张昭惭惧。

**归年依据** 同孙权黄龙元年称尊号。

[229年第13条](../../years/ce-0201-0300/ce-0229.md#sgz052-p-006-1)。

<a id="pei-006-2"></a>

> 昭忠謇亮直有大臣節權敬重之然所以不相昭者葢以昔駁周瑜魯肅等議為非也

**《江表传》解释孙权不用张昭为相** 记张昭直谏有大臣节，孙权一向敬重，但不拜相缘其曾反对周瑜、鲁肃抗曹。

**归年依据** 作者对221、225两次择相的一体解释，本传另载两次各有理由。

[《江表传》解释孙权不用张昭为相（时期）](../../years/ce-0201-0300/时期-三国志卷052-张顾诸葛步传纪年待考（2）.md#period-sgz052-p-006-2)。

<a id="pei-006-3"></a>

> 臣松之以為張昭勸迎曹公所存豈不逺乎夫其揚休正色委質孫氏誠以厄運初遘塗炭方始自策及權才畧足輔是以盡誠匡弼以成其業上藩漢室下保民物鼎峙之計夲非其志也

**裴松之评论张昭在赤壁会战前建议归曹** 认为张昭至诚辅孙氏，志在上护汉室、下保百姓，割据鼎峙本非所求；所以其建议不可只从事后一统分立看。

**归年依据** 评论针对建安十三年赤壁战前决策，作者写作不系208。

[208年第8条](../../years/ce-0201-0300/ce-0208.md#sgz052-p-006-3)。

<a id="pei-006-4"></a>

> 曹公仗順而起功以義立冀以清一諸華拓平荆郢大定之機在於此㑹若使昭議獲從則六合為一豈冇兵連禍結遂為戰國之弊哉雖無功於孫氏有大當於天下矣

**裴松之论张昭迎曹方案的当时利害** 认为曹操挟奉汉廷、诛除不顺者的形势，孙权有并扬越、据荆楚的打算；弱势归附可能保护天下人的生计。

**归年依据** 裴氏承接赤壁决策的论证与反事实。

[裴松之论张昭迎曹方案的当时利害（时期）](../../years/ce-0201-0300/时期-三国志卷052-张顾诸葛步传纪年待考（2）.md#period-sgz052-p-006-4)。

<a id="pei-006-5"></a>

> 昔竇融歸漢與國升降張魯降魏賞延于世況權舉全呉望風順服寵靈之厚其可測量哉然則昭為人謀豈不忠且正乎

**裴松之以窦融、田畴等类比归附待遇** 列数史例估计若孙权率全吴归顺，所得优礼也许更厚，认为张昭用心在为其主着想。

**归年依据** 裴氏举事为论，不是一项独立的新归降事实。

[裴松之以窦融、田畴等类比归附待遇（时期）](../../years/ce-0201-0300/时期-三国志卷052-张顾诸葛步传纪年待考（2）.md#period-sgz052-p-006-5)。

## 007｜孙权烧张昭门后和解

维基文库四库本原行 12—12。附见[正文 L2475](../本地分卷/三国志/三国志-卷052.md#l2475)。

<a id="pei-007-1"></a>

> 習鑿齒曰張昭於是乎不臣矣夫臣人者三諌不從則奉身而退身茍不絶何忿懟之有且秦穆違諌卒霸西戎晉文暫怒終成大業遺誓以悔過見錄狐偃無怨絶之辭君臣道泰上下俱榮今權悔徃之非而求昭後益廻慮降心不逺而復是其善也昭為人臣不度權得道匡其後失夙夜匪懈以延來譽乃追忿不用歸罪於君閉戸拒命坐待焚滅豈不悖哉

**孙权烧张昭门后和解** 批评张昭谏不从而闭门赌气，认为孙权已回心求助，臣当尽力纠正后失。举秦穆公、晋文公遇谏事来说明。

**归年依据** 评论针对嘉禾二年册封公孙渊的君臣争执；与正文“孙权烧张昭门后和解”同事。

[233年第29条](../../years/ce-0201-0300/ce-0233.md#sgz052-p-007-1)。

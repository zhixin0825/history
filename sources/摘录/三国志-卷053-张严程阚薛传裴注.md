**张纮辞大将军何进征辟** 何进征辟张纮为掾，他称病不就。

## 003｜张纮与张昭分担留守、从征

维基文库四库本原行 12—12。附见[正文 L2528](../本地分卷/三国志/三国志-卷053.md#l2528)。

<a id="pei-003-1"></a>

> 呉書曰紘與張昭並與參謀常令一人居守一人從征討

**张纮与张昭分担留守、从征** 二人为孙策谋画，常各分守与随军。

**归年依据** 《通鉴》卷六十一在195孙策取丹杨下叙此任用；为时期延续活动。

[195年第43条](../../years/ce-0101-0200/ce-0195.md#sgz053-p-003-1)。

<a id="pei-003-2"></a>

> 後呂布襲取徐州因為之牧不欲令紘與策從事追舉茂才移書發遣紘紘心惡布恥為之屈策亦重惜紘欲以自輔答記不遣曰海産明珠所在為寳楚雖有才晉實用之英偉君子所游見珍何必本州哉

**吕布据徐州后试图召张纮** 吕布袭取徐州后不愿张纮事孙策，追举茂才行文催送；张纮厌恶吕布，孙策惜才，以楚才晋用、海珠所在为宝答文拒遣。

**归年依据** 《武帝纪》《吕布传》建安元年吕布袭下邳，本条依注系该年后续，确月无据。

[196年第42条](../../years/ce-0101-0200/ce-0196.md#sgz053-p-003-2)。

## 004｜张纮在许都陈孙策之功

维基文库四库本原行 12—12。附见[正文 L2529](../本地分卷/三国志/三国志-卷053.md#l2529)。

<a id="pei-004-1"></a>

> 呉書曰紘至與在朝公卿及知舊述策材畧絶異平定三郡風行草偃加以忠敬欵誠乃心王室時曹公為司空欲加恩厚以悦逺人至乃優文褒崇改號加封辟紘為掾舉高第補侍御史

**张纮在许都陈孙策之功** 张纮向公卿及故交称述孙策平定三郡、忠心汉室；曹操为抚远而褒封其主，辟张纮为掾又推为侍御史。

**归年依据** 承正文建安四年；注中先后也是《通鉴》改系198的理由，勿把两说并作两次奉章。

[199年第28条](../../years/ce-0101-0200/ce-0199.md#sgz053-p-004-1)。

> 後以紘為九江太守紘心戀舊恩思還反命以疾固辭

**张纮固辞九江太守** 曹操后拟任命张纮为九江太守，张纮心念孙氏，称病固辞，盼能返江东复命。

**归年依据** 先留许后归吴间，任命年月无载。

## 005｜孙权初掌江东，吴太夫人托张纮辅政

维基文库四库本原行 12—12。附见[正文 L2529](../本地分卷/三国志/三国志-卷053.md#l2529)。

<a id="pei-005-1"></a>

> 呉書曰權初承統春秋方富太夫人以方外多難深懐憂勞數有優令辭謝付屬以輔助之義紘輒拜牋答謝思惟補察每有異事宻計及章表書記與四方交結常令紘與張昭草創撰作

**孙权初掌江东，吴太夫人托张纮辅政** 孙权年轻新继业，太夫人忧遣优令相托，张纮上箋谢受而尽力补察；孙权涉异事机密及和邻方通使，常让张纮与张昭拟文。

**归年依据** 《通鉴》卷六十三建安五年收录前半；文书活动延续其后。

[200年第11条](../../years/ce-0101-0200/ce-0200.md#sgz053-p-005-1)。

<a id="pei-005-2"></a>

> 紘以破虜有破走董卓扶持漢室之勲討逆平定江外建立大業宜冇紀頌以昭公義既成呈權權省讀悲感曰君真識孤家門閥閲也

**张纮为孙坚、孙策撰纪颂** 张纮以孙坚破董卓、孙策定江外之功应有纪颂，作成呈示，孙权为之感伤。

**归年依据** 撰颂年未明。两人军事功业为回顾。

[张纮为孙坚、孙策撰纪颂（时期）](../../years/ce-0201-0300/时期-三国志卷053-张严程阚薛传纪年待考（1）.md#period-sgz053-p-005-2)。

<a id="pei-005-3"></a>

> 乃遣紘之部或以紘夲受北任嫌其志趣不止於此權不以介意

**孙权派张纮赴会稽东部** 有人怀疑张纮曾受北方任命，孙权仍信任，派他到所领之部。

**归年依据** 《通鉴》卷六十三系建安五年。

[200年第56条](../../years/ce-0101-0200/ce-0200.md#sgz053-p-005-3)。

<a id="pei-005-4"></a>

> 初琅邪趙昱為廣陵太守察紘孝㢘昱後為笮融所殺紘甚傷憤而力不能討

**赵昱察举张纮孝廉、后遭笮融杀害** 赵昱守广陵时察张纮为孝廉，后死于笮融之手，张纮愤恨却无力为赵讨仇。

**归年依据** 《刘繇传》《后汉书·陶谦传》杀赵昱发生在曹操攻陶谦后；《通鉴》卷六十一在195回叙之，察举之年更未明。

[赵昱察举张纮孝廉、后遭笮融杀害（时期）](../../years/ce-0201-0300/时期-三国志卷053-张严程阚薛传纪年待考（1）.md#period-sgz053-p-005-4)。

<a id="pei-005-5"></a>

> 昱門戸絶滅及紘在東部遣主簿至琅邪設祭并求親戚為之後以書屬琅邪相臧宣宣以趙宗中五嵗男奉昱祀權聞而嘉之

**张纮为赵昱求奉祀后人** 赵昱一户绝灭，张纮在会稽东部遣属祭奠、请臧宣寻赵宗五岁子奉祀，孙权嘉许。

**归年依据** 张纮就任东部都尉后，无确年。

[张纮为赵昱求奉祀后人（时期）](../../years/ce-0201-0300/时期-三国志卷053-张严程阚薛传纪年待考（1）.md#period-sgz053-p-005-5)。

<a id="pei-005-6"></a>

> 及討江夏以東部少事命紘居守遥領所職孔融遺紘書曰聞大軍西征足下留鎮不有居者誰守社稷深固折衝亦大勲也無乃李廣之氣循髪益怒樂一當單于以盡餘憤乎南北並定世將無事孫叔投戈絳灌爼豆亦在今日但用離析無緣會面為愁歎耳道直途清相見豈復難㦲

**孙权伐江夏令张纮留守** 征江夏时孙权因东部事少召张纮留镇而遥领本职；孔融在信中称许守国之功，又叹未能相见。

**归年依据** 《吴主传》203、207、208均讨黄祖；孔融208年死，不足以分辨哪次出征。

[孙权伐江夏令张纮留守（时期）](../../years/ce-0201-0300/时期-三国志卷053-张严程阚薛传纪年待考（1）.md#period-sgz053-p-005-6)。

<a id="pei-005-7"></a>

> 權以紘冇鎮守之勞欲論功加賞紘厚自挹損不敢䝉寵權不奪其志每從容侍燕微言宻指常冇以規諷

**孙权欲赏张纮留守功** 张纮谦辞不受，孙权也同意；张纮平时在宴席多借微言规讽。

**归年依据** 承讨江夏留守，先后可知，单年无明文。

[孙权欲赏张纮留守功（时期）](../../years/ce-0201-0300/时期-三国志卷053-张严程阚薛传纪年待考（1）.md#period-sgz053-p-005-7)。

<a id="pei-005-8"></a>

**孙权尊称张昭、张纮** 孙权常呼群臣字，对张昭则叫张公，叫张纮东部，以示看重。

**归年依据** 孙权承统后、张纮任东部都尉期间。

## 006｜合肥未拔，张纮建议开围一面

维基文库四库本原行 12—12。附见[正文 L2529](../本地分卷/三国志/三国志-卷053.md#l2529)。

<a id="pei-006-1"></a>

> 吳書曰合肥城久不拔紘進計曰古之圍城聞其一面以疑衆心今圍之甚宻攻之又急誠懼并命戮力死戰之寇固難卒拔及救未至可小寛之以觀其變議者不同㑹救騎至數至圍下馳騁挑戰

**归年依据** 《通鉴》卷六十六以围逾月、解围在209春；《武帝纪》初围在208冬。援骑说与蒋济设伪信有区别。

## 007｜张纮论金陵地势可建都

维基文库四库本原行 12—12。附见[正文 L2530](../本地分卷/三国志/三国志-卷053.md#l2530)。

<a id="pei-007-1"></a>

> 江表傳曰紘謂權曰秣陵楚武王所置名為金陵地勢岡阜連石頭訪問故老云昔秦始皇東廵㑹稽經此縣望氣者云金陵地形有王者都邑之氣故掘斷連岡改名秣陵今處所具存地有其氣天之所命宜為都邑權善其議未能從也

**张纮论金陵地势可建都** 张纮讲秣陵形势及秦始皇改名的地方传闻，建议作都邑，孙权认为好却一时未办。

**归年依据** 建议确年未载；《通鉴》212回叙，正文吴主211已徙治。

[张纮论金陵地势可建都（时期）](../../years/ce-0201-0300/时期-三国志卷053-张严程阚薛传纪年待考（1）.md#period-sgz053-p-007-1)。

<a id="pei-007-2"></a>

> 後劉備之東宿於秣陵周觀地形亦勸權都之權曰智者意同遂都焉

**刘备到秣陵也劝孙权迁治** 刘备东来宿秣陵，察地形也劝孙权以其为治所，孙权称二人所见相同。

**归年依据** 《先主传》刘备赴京口，仓内并210；注只明此东行；《吴主传》211徙治。

[210年第13条](../../years/ce-0201-0300/ce-0210.md#sgz053-p-007-2)。

<a id="pei-007-3"></a>

> 獻帝春秋云劉備至京謂孫權曰吳去此數百里即有警急赴救為難將軍無意屯京乎權曰秣陵有小江百餘里可以安大船吾方理水軍當移據之備曰蕪湖近濡須亦佳也權曰吾欲圗徐州宜近下也

**《献帝春秋》记孙刘比较京、秣陵、芜湖** 刘备提议屯京口，孙权谈秣陵可容大船；刘备说芜湖邻濡须也佳，孙权认为图徐州要处下游。

**归年依据** 与《先主传》刘备至京会权相连，安在210年页为该事异文。

[210年第13条](../../years/ce-0201-0300/ce-0210.md#sgz053-p-007-3)。

<a id="pei-007-4"></a>

> 臣松之以為秣陵之與蕪湖道理所校無㡬於北侵利便亦有何異而云欲闚徐州貪秣陵近下非其理也諸書皆云劉備勸都秣陵而此獨云權自欲都之又為虚錯

**裴松之质疑《献帝春秋》归因** 秣陵与芜湖相距不大，北伐利便无大异；其他史书说是刘备劝，只有《献帝春秋》说孙权自为此议，裴松之认为失实。

**归年依据** 刘备赴京为史事背景，裴氏考辨本身无可确年。

[裴松之质疑《献帝春秋》归因（时期）](../../years/ce-0201-0300/时期-三国志卷053-张严程阚薛传纪年待考（2）.md#period-sgz053-p-007-4)。

## 009｜张纮与陈琳互称文章

维基文库四库本原行 12—12。附见[正文 L2531](../本地分卷/三国志/三国志-卷053.md#l2531)。

<a id="pei-009-1"></a>

> 呉書曰紘見柟榴枕愛其文為作賦陳琳在北見之以示人曰此吾鄉里張子綱所作也後紘見陳琳作武庫賦應機論與琳書深歎羙之琳答曰自僕在河北與天下隔此間率少於文章易為雄伯故使僕受此過差之譚非其實也今景興在此足下與子布在彼所謂小巫見大巫神氣盡矣

**张纮与陈琳互称文章** 张纮作柟榴枕赋，陈琳向人夸赞；张纮也赞陈琳赋论，陈琳回信谦称不逮张纮、张昭、王朗。

**归年依据** 陈琳在河北为背景，往还无具体年。

> 元帝踐阼累遷丹陽尹尚書又為太子少傅自綜至兼三世傅東宫

**薛兼在晋元帝时任丹阳尹、尚书、太子少傅** 晋元帝即位，薛兼累迁丹阳尹、尚书，继祖父薛综、父薛莹为第三代东宫辅臣。

**归年依据** 元帝318即帝位；后续为累迁，《薛兼传》谓中兴建转尹，未硬系各任同年。

## 001｜谢承《后汉书》述周景早年

维基文库四库本原行 11—11。附见[正文 L2560](../本地分卷/三国志/三国志-卷054.md#l2560)。

<a id="pei-001-1"></a>

> 謝承後漢書曰景字仲嚮少以亷能見稱以眀學察孝亷辟公府

**谢承《后汉书》述周景早年** 周景字仲向，少以廉能为人所知，因学问而被察孝廉，受公府征辟。

**归年依据** 周景仕履早年无确年。

[谢承《后汉书》述周景早年（时期）](../../years/ce-0201-0300/时期-三国志卷054-周瑜鲁肃吕蒙传纪年待考.md#period-sgz054-p-001-1)。

<a id="pei-001-2"></a>

> 後為豫州刺史辟汝南陳蕃為别駕穎川李膺荀緄杜宻沛國朱㝢為從事皆天下英俊之士也

**周景任豫州刺史广辟名士** 辟陈蕃为别驾，李膺、荀绲、杜密、朱寓为从事，皆才俊。

**归年依据** 《后汉书·周荣传》载任豫州刺史，具体辟召年未载。

[周景任豫州刺史广辟名士（时期）](../../years/ce-0201-0300/时期-三国志卷054-周瑜鲁肃吕蒙传纪年待考.md#period-sgz054-p-001-2)。

<a id="pei-001-3"></a>

> 稍遷至尚書令遂登太尉

**周景历尚书令并任太尉** 后来历任尚书令，最终拜为太尉。

**归年依据** 《后汉书·桓帝纪》延熹九年拜太尉；尚书令为往职。

[166年第17条](../../years/ce-0101-0200/ce-0166.md#sgz054-p-001-3)。

<a id="pei-001-4"></a>

> 張璠漢紀曰景父榮章和世為尚書令

**周荣为尚书令** 张璠记周景父周荣在章帝、和帝时代官至尚书令。

**归年依据** 章和两朝跨75—106年；授官确年未明。

[周荣为尚书令（时期）](../../years/ce-0201-0300/时期-三国志卷054-周瑜鲁肃吕蒙传纪年待考.md#period-sgz054-p-001-4)。

<a id="pei-001-5"></a>

> 初景歴位牧守好善愛士每嵗舉考㢘延請入上後堂與家人宴㑹如此者數四及贈送既備又選用其子弟常稱曰移臣作子於政何有

**周景招待孝廉并任用其子弟** 周景历任地方长官期间常亲设家宴厚赠孝廉，又选用其子弟，称视臣为子无妨政事。

**归年依据** 多次施行，非同年。

[周景招待孝廉并任用其子弟（时期）](../../years/ce-0201-0300/时期-三国志卷054-周瑜鲁肃吕蒙传纪年待考.md#period-sgz054-p-001-5)。

<a id="pei-001-6"></a>

> 先是司徒韓縯為河内太守在公無私所舉一辭而已後亦不及其門户曰我舉若可矣不令恩偏稱一家也當時論者或兩譏焉

**韩縯举荐保持公私分别** 韩縯为河内太守时举人仅一辞，不延私门，自言不应偏恩一家；时人亦有评论双方。

**归年依据** 韩縯任太守的确年未获；司徒为后称。

[韩縯举荐保持公私分别（时期）](../../years/ce-0201-0300/时期-三国志卷054-周瑜鲁肃吕蒙传纪年待考.md#period-sgz054-p-001-6)。

## 002｜周瑜回吴，孙策拜建威中郎将

维基文库四库本原行 11—11。附见[正文 L2561](../本地分卷/三国志/三国志-卷054.md#l2561)。

<a id="pei-002-1"></a>

> 江表傳曰策又給瑜鼓吹為治館舍贈賜莫與為比䇿令曰周公瑾英儁異才與孤有總角之好骨肉之分如前在丹陽發衆及船糧以濟大事論徳酬功此未足以報者也

**周瑜回吴，孙策拜建威中郎将** 孙策为周瑜治馆舍，给鼓吹、厚物，令中称两人少年如骨肉，礼物难以报偿丹杨时兵船粮助。

**归年依据** 本传周瑜建安三年回吴；同年受兵军礼，从“孙策授周瑜建威中郎将”。

[198年第39条](../../years/ce-0101-0200/ce-0198.md#sgz054-p-002-1)。

维基文库四库本原行 11—11。附见[正文 L2561](../本地分卷/三国志/三国志-卷054.md#l2561)。

> 臣松之案孫策于時始得豫章廬陵尚未能得定江夏瑜之所鎮應在今巴邱縣也與後所平巴邱處不同

**裴松之辨周瑜早年镇巴丘** 孙策当时仅新得豫章、庐陵，尚未稳定江夏，周瑜所镇应是巴丘县，和后来的巴丘卒地不同。

## 005｜曹操索孙权质子，孙权拒送

维基文库四库本原行 11—11。附见[正文 L2562](../本地分卷/三国志/三国志-卷054.md#l2562)。

<a id="pei-005-1"></a>

> 江表傳曰曹公新破袁紹兵威日盛建安七年下書責權質任子權召羣臣㑹議張昭秦松等猶豫不能决權意不欲遣質乃獨將瑜詣母前定議

**曹操索孙权质子，孙权拒送** 曹操破袁绍后向孙权索取质子，张昭、秦松等犹豫。孙权不愿送，于母亲前同周瑜定议。

**归年依据** 原注明书建安七年，《通鉴》卷六十四采用；与208朱治劝孙贲勿质不同。

[202年第17条](../../years/ce-0201-0300/ce-0202.md#sgz054-p-005-1)。

<a id="pei-005-2"></a>

> 瑜曰昔楚國初封於荆山之側不滿百里之地繼嗣賢能廣土開境立基於郢遂據荆陽至於南海傳業延祚九百餘年今將軍承父兄餘資兼六郡之衆兵精糧多將士用命鑄山為銅煮海為鹽境内富饒人不思亂汎舟舉㠶朝發夕到土風勁勇所向無敵冇何偪廹而欲送質質一入不得不與曹氏相首尾與相首尾則命召不得不往便見制於人也極不過一侯印僕從十餘人車數乗馬數匹豈與南面稱孤同哉不如勿遣徐觀其變若曹氏能率義以正天下將軍事之未晩若圖為暴亂兵猶火也不戢將自焚將軍韜勇抗威以待天命何送質之冇

**曹操索孙权质子，孙权拒送** 周瑜以楚从小发展为强作譬，指出孙权已有六郡、兵粮富足，失质子将交出自主，所得不过微薄侯爵；宜观曹操能否扶义再定。

**归年依据** 同202质子事，楚始封只是所引往事。

[202年第17条](../../years/ce-0201-0300/ce-0202.md#sgz054-p-005-2)。

<a id="pei-005-3"></a>

> 權母曰公瑾議是也公瑾與伯符同年小一月耳我視之如子也汝其兄事之遂不送質

**曹操索孙权质子，孙权拒送** 吴夫人支持周瑜，称其比孙策小一月如同己子，叫孙权以兄礼待，最终不遣质。

**归年依据** 同202拒质。

[202年第17条](../../years/ce-0201-0300/ce-0202.md#sgz054-p-005-3)。

## 006｜孙权斫案明决意抗曹

维基文库四库本原行 11—11。附见[正文 L2565](../本地分卷/三国志/三国志-卷054.md#l2565)。

<a id="pei-006-1"></a>

> 江表傳曰權拔刀斫前奏案曰諸將吏敢復有言當迎操者與此案同

**孙权斫案明决意抗曹** 孙权用刀砍奏案，警告再提迎曹的将吏。

**归年依据** 《江表传》赤壁前，卷六十五同。

[208年第8条](../../years/ce-0201-0300/ce-0208.md#sgz054-p-006-1)。

<a id="pei-006-2"></a>

> 及㑹罷之夜瑜請見曰諸人徒見操書言水歩八十萬而各恐懾不復料其虚實便開此議甚無謂也今以實校之彼所將中國人不過十五六萬且軍已久疲所得表衆亦極七八萬耳尚懐狐疑夫以疲病之卒御狐疑之衆衆數雖多甚未足畏得精兵五萬自足制之願將軍勿慮

**周瑜夜见孙权析曹军虚实** 曹操称水陆八十万，周瑜估北军十五六万且疲，降来荆州兵最多七八万且疑惧，吴得精兵五万能战。

**归年依据** 同208抗曹谋议；这里是周瑜估算，与主传请三万是两个说法的有效上下文。

[208年第8条](../../years/ce-0201-0300/ce-0208.md#sgz054-p-006-2)。

<a id="pei-006-3"></a>

> 權撫背曰公瑾卿言至此甚合孤心子布文表諸人各顧妻子挾持私慮深失所望獨卿與子敬與孤同耳此天以卿二人贊孤也五萬兵難卒合已選三萬人船糧戰具俱辦卿與子敬程公便在前發孤當續發人衆多載資糧為卿後援卿能辦之者誠决邂逅不如意便還就孤孤當與孟徳决之

**孙权已集三万先付周瑜等** 称周瑜鲁肃谋合，五万未能速集，已有三万、船粮战具，令周瑜、鲁肃、程普先发，愿亲作后援。

**归年依据** 同建安十三年赤壁前。

[208年第8条](../../years/ce-0201-0300/ce-0208.md#sgz054-p-006-3)。

<a id="pei-006-4"></a>

> 臣松之以為建計拒曹公實始魯肅于時周瑜使鄱陽肅勸權呼瑜瑜使鄱陽還但與肅闇同故能共成大勲夲傳直云權延見羣下問以計策瑜擺撥衆人之議獨言抗拒之計了不云肅先有謀殆為攘肅之善也

**裴松之辨倡抗曹之首为鲁肃** 鲁肃先有抗曹决策，周瑜当时出使鄱阳，由鲁肃请召回，继而同心成事；裴松之批评周瑜传有争美之嫌。

**归年依据** 附赤壁前廷议，由《鲁肃传》互校，同一事不同归功。

[208年第8条](../../years/ce-0201-0300/ce-0208.md#sgz054-p-006-4)。

> 江表傳載葢書曰葢受孫氏厚恩常為將帥見遇不薄然顧天下事有大勢用江東六郡山越之人以當中國百萬之衆衆寡不敵海内所共見也東方將吏無冇愚智皆知其不可惟周瑜魯肅偏懐淺戅意未觧耳今日歸命是其實計瑜所督領自易摧破交鋒之日葢為前部當因事變化效命在近

## 008｜《江表传》记十艘火船装荻柴鱼膏

维基文库四库本原行 11—11。附见[正文 L2566](../本地分卷/三国志/三国志-卷054.md#l2566)。

<a id="pei-008-1"></a>

> 江表傳曰至戰日葢先取輕利艦十舫載燥荻枯柴積其中灌以魚膏赤幔覆之建旌旗龍幡於艦上時東南風急因以十艦最著前中江舉帆

**《江表传》记十艘火船装荻柴鱼膏** 十条轻船装干荻、枯柴、鱼油，覆赤幔，立旌旗，乘东南急风先航。

**归年依据** 与本传数十蒙冲斗舰并载，指同一火攻。

[208年第8条](../../years/ce-0201-0300/ce-0208.md#sgz054-p-008-1)。

<a id="pei-008-2"></a>

> 葢舉火白諸校使衆兵齊聲大呌曰降焉操軍人皆出營立觀去北軍二里餘同時發火火烈風猛往船如箭飛埃赩爛燒盡北船延及岸邊營砦

**黄盖佯呼投降后燃船** 众军齐呼来降，曹军出营观望，距离二里多一起点火，船快如箭，火烧至岸寨。

**归年依据** 同208赤壁火攻。

[208年第8条](../../years/ce-0201-0300/ce-0208.md#sgz054-p-008-2)。

<a id="pei-008-3"></a>

> 瑜等率輕銳軍繼其後雷鼔大進北軍大壊曹公退走

**周瑜率锐兵随火船进击** 周瑜诸军鼓进，曹军大乱后退。

**归年依据** 同208赤壁，曹操自称焚余船退的异说见本注11。

[208年第8条](../../years/ce-0201-0300/ce-0208.md#sgz054-p-008-3)。

## 011｜程普由凌辱周瑜至敬服

维基文库四库本原行 11—11。附见[正文 L2569](../本地分卷/三国志/三国志-卷054.md#l2569)。

<a id="pei-011-1"></a>

> 江表傳曰普頗以年長數陵侮瑜瑜折節容下終不與校普後自敬服而親重之乃告人曰與周公瑾交若飲醇醪不覺自醉時人以其謙讓服人如此

**程普由凌辱周瑜至敬服** 周瑜礼让不计，程普后以饮醇酒自醉比舒畅，时人因此知周瑜能容人。

**归年依据** 《孙皎传》亦载两人矛盾，和解年月未载。

## 020｜吕蒙建议修濡须坞

维基文库四库本原行 13—13。附见[正文 L2589](../本地分卷/三国志/三国志-卷054.md#l2589)。

<a id="pei-020-1"></a>

> 吳錄曰權欲作塢諸將皆曰上岸擊賊洗足入船何用塢為吕蒙曰兵有利鈍戰無百勝如有邂逅敵歩騎蹙人不暇及水其得入船乎權曰善遂作之

**吕蒙建议修濡须坞** 诸将说上岸作战即便可退入船，吕蒙指出遇北军骑兵逼迫可能赶不上船，孙权纳议立坞。

**归年依据** 同212年建坞，本传与《吴录》《通鉴》互证，次年濡须战分开。

[212年第25条](../../years/ce-0201-0300/ce-0212.md#sgz054-p-020-1)。

## 021｜吕蒙反对以土山和攻具久攻皖城

维基文库四库本原行 13—13。附见[正文 L2590](../本地分卷/三国志/三国志-卷054.md#l2590)。

<a id="pei-021-1"></a>

> 呉書曰諸將皆勸作土山添攻具䝉趨進曰治攻具及土山必歴月乃成城備既修外救必至不可圗也且乗雨水以入若留經日水必向盡還道艱難䝉竊危之今觀此城不能甚固以三軍鋭氣四面並攻不移時可拔及水以歸全勝之道也權從之

**吕蒙反对以土山和攻具久攻皖城** 将领建议堆土山，吕蒙说耗时致外援到、回程水退，宜乘城未坚即时四面强攻并借水返回，孙权采纳。

**归年依据** 建安十九年攻皖，为正文所含同役论策。

[214年第23条](../../years/ce-0201-0300/ce-0214.md#sgz054-p-021-1)。

## 022｜虞翻至公安劝降士仁

维基文库四库本原行 13—13。附见[正文 L2596](../本地分卷/三国志/三国志-卷054.md#l2596)。

<a id="pei-022-1"></a>

> 呉書曰將軍士仁在公安拒守䝉令虞翻説之翻至城門謂守者曰吾欲與汝將軍語仁不肯相見

**虞翻至公安劝降士仁** 士仁拒见，吕蒙令虞翻改书劝其权衡吉凶。

**归年依据** 建安二十四年取公安。

[219年第8条](../../years/ce-0201-0300/ce-0219.md#sgz054-p-022-1)。

<a id="pei-022-2"></a>

> 乃為書曰明者防禍於未萌智者圖患於將來知得知失可與為人知存知亡足别吉凶大軍之行斥候不及施烽火不及舉此非天命必有内應將軍不先見時時至又不應之獨守縈帶之城而不降死戰則毁宗㓕祀為天下譏笑呂虎威欲徑到南郡斷絶陸道生路一塞案其地形將軍為在箕舌上耳奔走不得免降則失義竊為將軍不安幸熟思焉

**虞翻书陈士仁坚守之祸** 吴军已突破耳目，可能有内应；若吕蒙直入南郡切陆道，公安将孤立无路，不降而死将灭宗。

**归年依据** 同219年劝降士仁书。

[219年第8条](../../years/ce-0201-0300/ce-0219.md#sgz054-p-022-2)。

<a id="pei-022-3"></a>

> 仁得書流涕而降翻謂䝉曰此譎兵也當將仁行留兵備城遂將仁至南郡南郡太守麋芳城守䝉以仁示之遂降

**士仁降，吕蒙携之示麋芳** 虞翻劝带士仁进军并留兵守公安，麋芳守南郡见士仁而降。

**归年依据** 《吴主传》建安二十四年；比本传写明先公安、后南郡。

[219年第8条](../../years/ce-0201-0300/ce-0219.md#sgz054-p-022-3)。

<a id="pei-022-4"></a>

> 呉錄曰初南郡城中失火頗焚燒軍器羽以責芳芳内畏懼權聞而誘之芳潛相和

**《吴录》补麋芳私下通孙权因由** 江陵火烧军器后关羽责备麋芳，麋芳惧而被孙权诱引，私下通和。

**归年依据** 回叙219降前事，失火与初通之年未明。

<a id="pei-022-5"></a>

> 及䝉攻之乃以牛酒出降

**《吴录》称麋芳持牛酒出降** 吕蒙进攻时，麋芳以牛酒出迎归降。

**归年依据** 与《吴书》示士仁后降同次，原因异说。

## 023｜孙权于公安表彰吕蒙擒羽功

维基文库四库本原行 13—13。附见[正文 L2597](../本地分卷/三国志/三国志-卷054.md#l2597)。

<a id="pei-023-1"></a>

> 江表傳曰權於公安大㑹呂䝉以疾辭權笑曰禽羽之功子明謀也今大功已㨗慶賞未行豈邑邑邪乃增給歩騎鼓吹勑選虎威將軍官屬并南郡廬江二郡威儀拜畢還營兵馬導從前後鼓吹光耀于路

**孙权于公安表彰吕蒙擒羽功** 吕蒙因病辞会，孙权以擒羽是吕蒙谋笑劝，增步骑鼓吹，选虎威府属并给南郡、庐江二郡礼仪，拜后前后鼓吹。

**归年依据** 《江表传》与219封赏、病发相连。

[219年第20条](../../years/ce-0201-0300/ce-0219.md#sgz054-p-023-1)。

## 001｜朱治劝孙贲勿遣子质曹

维基文库四库本原行 11—11。附见[正文 L2680](../本地分卷/三国志/三国志-卷056.md#l2680)。

<a id="pei-001-1"></a>

> 江表傳載治說賁曰破虜將軍昔率義兵入討董卓聲冠中夏義士壯之討逆繼世廓定六郡特以君侯骨肉至親噐為時生故表漢朝剖符大郡兼建將校仍闗綜兩府榮冠宗室為逺近所瞻加討虜聦明神武繼承洪業攬結英雄周濟世務軍衆日盛事業日隆雖昔蕭王之在河北無以加也必克成王基應運東南故劉玄徳逺布腹心求見拯救此天下所共知也

**朱治劝孙贲勿遣子质曹** 朱治称孙坚起兵讨卓、孙策平六郡，孙贲备受信任而主持大郡，孙权统军日强，刘备亦由远来相求。

**归年依据** 本传曹操破荆州为208，书说中对创业的追叙是举证；孙坚起兵等各见对应年。

[208年第43条](../../years/ce-0201-0300/ce-0208.md#sgz056-p-001-1)。

<a id="pei-001-2"></a>

> 前在東聞道路之言云將軍有異趣良用憮然今曹公阻兵傾覆漢室㓜帝流離百姓元元未知所歸而中國蕭條或百里無煙城邑空虚道殣相望士歎於外婦怨乎室加之以師旅因之以饑饉以此料之豈能越長江與我爭利哉

**朱治劝孙贲勿遣子质曹** 朱治听说孙贲有意改事曹操，以汉室受制、中原凋敝、百姓困于军与灾荒说明曹操难以渡江争利。

**归年依据** 本传劝止208年曹操破荆州后事；注记现时动乱。

[208年第43条](../../years/ce-0201-0300/ce-0208.md#sgz056-p-001-2)。

<a id="pei-001-3"></a>

> 將軍當斯時也而欲背骨肉之親違萬安之計割同氣之膚啖虎狼之口為一女子改慮易圗失機毫釐差以千里豈不惜哉

**朱治劝孙贲勿遣子质曹** 朱治说不能为女儿嫁入曹氏改变宗族大计，提醒一时失误可能酿成大患。

**归年依据** 同一208年游说。

[208年第43条](../../years/ce-0201-0300/ce-0208.md#sgz056-p-001-3)。

## 005｜《孙氏异同评》把朱然胡质战系景初元年

维基文库四库本原行 12—12。附见[正文 L2688](../本地分卷/三国志/三国志-卷056.md#l2688)。

<a id="pei-005-1"></a>

> 孫氏異同評曰魏志及江表傳云然以景初元年

**《孙氏异同评》把朱然胡质战系景初元年** 孙盛据《魏书》一系和《江表传》，并举景初元年、正始二年两次朱然出兵。

**归年依据** 本句含237与241两年，同注下片续明；《明帝纪》景初元年七月记朱然围江夏，受胡质迎击而退。

[237年第17条](../../years/ce-0201-0300/ce-0237.md#sgz056-p-005-1)。

<a id="pei-005-2"></a>

> 正始二年再出為寇

**《孙氏异同评》另举正始二年朱然出兵** 《孙氏异同评》同时说朱然于正始二年另出兵。

**归年依据** 《齐王纪》和《吴主传》明确记241朱然围樊，和237异说日期相分。

[241年第2条](../../years/ce-0201-0300/ce-0241.md#sgz056-p-005-2)。

<a id="pei-005-3"></a>

> 所破胡質蒲忠在景初元年魏志承魏書依違不說質等為然所破而直云然退耳

**《孙氏异同评》辨魏吴两书记战果** 孙氏说蒲忠、胡质受挫属景初元年，但魏史只称朱然退，交战叙述不同。

**归年依据** 与237《明帝纪》及本注互证；本传把该组人物和战果载于242。

[237年第17条](../../years/ce-0201-0300/ce-0237.md#sgz056-p-005-3)。

<a id="pei-005-4"></a>

> 吳志說赤烏五年於魏為正始三年魏將蒲忠與朱然戰忠不利質等皆退按魏少帝紀及孫權傳是嵗竝無事當是陳夀誤以吳嘉禾六年為赤烏五年耳

**《孙氏异同评》质疑赤乌五年之记** 吴传明记赤乌五年战蒲忠、胡质，孙氏指出当年魏少帝纪和吴主纪无此战，疑陈寿误把嘉禾六年写为赤乌五年。

**归年依据** 赤乌五年为242，嘉禾六年为237。系在既有242本传条，并明与237之记为同役一说、避免重复判定。

[242年第15条](../../years/ce-0201-0300/ce-0242.md#sgz056-p-005-4)。

> 江表傳曰䇿從容獨與範棊範曰今將軍事業日大士衆日盛範在逺聞綱紀猶有不整者範願蹔領都督佐將軍部分之策曰子衡卿既上大夫加手下已有大衆立功於外豈宜復屈小職知軍中細碎事乎範曰不然今捨本土而託將軍者非為妻子也欲濟世務猶同舟渉海一事不牢即俱受其敗此亦範討非但將軍也策笑無以答

**《九州春秋》记陈祎死后陈瑀领扬州牧** 《九州春秋》称扬州刺史陈祎初平三年死，袁术命陈瑀领扬州牧。

**归年依据** 初平三年为192；「陳禕」见《许靖传》，《通鉴》据诸说作陈温、先后还有袁遗，与《献帝纪》193被杀相异，字图为「揚」。

<a id="pei-007-2"></a>

> 後術為曹公所敗於封丘南人叛瑀瑀拒之術走隂陵好辭以下瑀瑀不知權而又怯不即攻術術於淮北集兵向夀春瑀懼使其弟公琰請和於術術執之而進瑀走歸下邳

## 009｜孙权迁建业后与严畯论鲁肃吕范

维基文库四库本原行 13—13。附见[正文 L2699](../本地分卷/三国志/三国志-卷056.md#l2699)。

<a id="pei-009-1"></a>

> 江表傳曰初權移都建業大㑹將相文武時謂嚴畯曰孤昔歎魯子敬比鄧禹吕子衡方吳漢聞卿諸人未平此論今定云何畯退席曰臣未解指趣謂肅範受饒褒歎過實

**孙权迁建业后与严畯论鲁肃吕范** 大会文武时孙权问严畯，为何不同意以鲁肃比邓禹、吕范比吴汉；严畯说原以为过誉。

**归年依据** 《吴主传》黄龙元年秋迁建业。

[229年第14条](../../years/ce-0201-0300/ce-0229.md#sgz056-p-009-1)。

<a id="pei-009-2"></a>

> 權曰昔鄧仲華初見光武光武時受更始使撫河北行大司馬事耳未有帝王志也禹勸之以復漢業是禹開初議之端矣子敬英爽有殊畧孤始與一語便及大計與禹相似故比之

**孙权说明鲁肃如邓禹先建大计** 邓禹早劝刘秀重兴汉业；鲁肃初见即提战略大计，故孙权以两人相拟。

**归年依据** 同次229年大会所论，典故不另移入该年。

[229年第14条](../../years/ce-0201-0300/ce-0229.md#sgz056-p-009-2)。

<a id="pei-009-3"></a>

> 吕子衡忠篤亮直性雖好奢然以憂公為先不足為損避袁術自歸於兄兄作大將别領部曲故憂兄事乞為都督辦䕶脩整加之恪勤與吳漢相類故方之皆有旨趣非孤私之也畯乃服

**孙权说明吕范忠直勤政如吴汉** 吕范忠直，虽很重外在服饰却忧公为先，归孙策后主动请都督整军，孙权说这与吴汉相似；严畯听服。

**归年依据** 同次229年大会所论。

[229年第14条](../../years/ce-0201-0300/ce-0229.md#sgz056-p-009-3)。

维基文库四库本原行 14—14。附见[正文 L2707](../本地分卷/三国志/三国志-卷056.md#l2707)。

> 孫盛曰書云臣無作威作福作威作福則㓙于而家害于而國桓之賊忍殆虎狼也人君且猶不可况將相乎語曰得一夫而失一國縱罪虧刑失孰大焉

**《吴录》述朱桓行前捋孙权须** 孙权送朱桓远行，朱桓称想再捋陛下的胡须，获许后开玩笑自己真是捋虎须，孙权大笑。

**归年依据** 接朱桓称病后获遣还军，本传只记数月，约237–238。

## 013｜朱异随诸葛恪围新城并劝退

维基文库四库本原行 15—15。附见[正文 L2710](../本地分卷/三国志/三国志-卷056.md#l2710)。

<a id="pei-013-1"></a>

> 吳書曰異又隨諸葛恪圍新城城既不㧞異等皆言宜速還豫章襲石頭城不過數日可㧞恪以書曉異

**朱异随诸葛恪围新城并劝退** 围新城不下，朱异等劝早撤，文中并说回豫章与袭石头城；诸葛恪写信回复。

**归年依据** 《三嗣主传》《诸葛恪传》吴建兴二年；「豫章襲石頭城」在异本亦见地名、断句歧说，保持原字。

[253年第2条](../../years/ce-0201-0300/ce-0253.md#sgz056-p-013-1)。

<a id="pei-013-2"></a>

> 異投書於地曰不用我計而用侯子言恪大怒立奪其兵遂廢還建業

**朱异不满诸葛恪回书而被夺兵** 朱异把信掷地，抱怨诸葛恪舍己之计而用他人，恪怒，夺去兵权，废还建业。

**归年依据** 同一253年新城役。

[253年第2条](../../years/ce-0201-0300/ce-0253.md#sgz056-p-013-2)。

## 014｜陆抗劝朱异勿赴孙綝约而不获从

维基文库四库本原行 15—15。附见[正文 L2710](../本地分卷/三国志/三国志-卷056.md#l2710)。

<a id="pei-014-1"></a>

> 吳書曰綝要異相見將往恐陸抗止之異曰子通家人耳當何所疑乎

**陆抗劝朱异勿赴孙綝约而不获从** 孙綝约见朱异，陆抗劝阻，朱异认为宗亲相约无须怀疑。

**归年依据** 《三嗣主传》太平二年秋九月杀朱异，《吴书》补前因；底本「將往恐陸抗止之」有讹，普通本作「將往，陸抗止之」。

[257年第16条](../../years/ce-0201-0300/ce-0257.md#sgz056-p-014-1)。

<a id="pei-014-2"></a>

> 遂往綝使力人於坐上取之異曰我吳國忠臣冇何罪乎乃拉殺之

**孙綝命人当场杀朱异** 朱异赴会，孙綝命力士当场擒杀，朱异说自己忠于吴国、并无罪。

**归年依据** 《三嗣主传》太平二年九月朔。

[257年第16条](../../years/ce-0201-0300/ce-0257.md#sgz056-p-014-2)。

## 001｜虞翻少年致书责客见称

维基文库四库本原行 11—11。附见[正文 L2714](../本地分卷/三国志/三国志-卷057.md#l2714)。

<a id="pei-001-1"></a>

> 吳書曰翻少好學有髙氣年十二客有〔四库字图1974〕其兄者不過翻翻追與書曰僕聞虎魄不取腐芥磁石不受曲鍼過而不存不亦宜乎客得書竒之由是見稱

**虞翻少年致书责客见称** 客人拜谒其兄而不访虞翻，十二岁的虞翻以琥珀、磁石为比，写信讥讽对方，反获其赏识。

## 002｜虞翻阻王朗往交州

维基文库四库本原行 11—11。附见[正文 L2714](../本地分卷/三国志/三国志-卷057.md#l2714)。

<a id="pei-002-1"></a>

> 吳書曰翻始欲送朗到廣陵朗惑王方平訊言疾來邀我南岳相求故遂南行既至侯官又欲投交州翻諫朗曰此妄書耳交州無南岳安所投乎乃止

**虞翻阻王朗往交州** 王朗因疑信王方平来书，改向南行，到侯官又欲去交州。虞翻说信是假，南岳又不在交州，王朗乃止。

**归年依据** 《吴书》补孙策取会稽后王朗走侯官时的路线。

[196年第65条](../../years/ce-0101-0200/ce-0196.md#sgz057-p-002-1)。

## 003｜虞翻护送王朗与奔丧异说

维基文库四库本原行 11—11。附见[正文 L2714](../本地分卷/三国志/三国志-卷057.md#l2714)。

<a id="pei-003-1"></a>

> 翻别傳曰朗使翻見豫章太守華歆圗起義兵翻未至豫章聞孫策向㑹稽翻乃還㑹遭父喪以臣使有節不敢過家星行追朗至侯官朗遣翻還然後奔喪

**虞翻护送王朗与奔丧异说** 虞翻奉王朗命求华歆助兵，未到即闻孙策进攻；虞翻虽遇父丧仍追王朗到侯官，获遣之后才奔丧。

**归年依据** 《翻别传》与本传战前衰绖入府劝战不同，同系建安元年。

[196年第65条](../../years/ce-0101-0200/ce-0196.md#sgz057-p-003-1)。

<a id="pei-003-2"></a>

> 而傳云孫策之來翻衰絰詣府門勸朗避策則為大異

**裴注对勘虞翻奔丧先后** 注文指出本传称孙策来时虞翻已穿丧服入府，这与《翻别传》大异。

**归年依据** 史料异文，附196年事。

## 004｜孙策书示不用郡吏礼待虞翻

维基文库四库本原行 11—11。附见[正文 L2714](../本地分卷/三国志/三国志-卷057.md#l2714)。

<a id="pei-004-1"></a>

> 江表傳曰策書謂翻曰今日之事當與卿共之勿謂孫策作郡吏相待也

**孙策书示不用郡吏礼待虞翻** 孙策写信说事情应同虞翻一起办，不以普通郡吏之礼待他。

**归年依据** 《江表传》补重新任虞翻功曹时的礼遇。

## 005｜虞翻保护孙策离开山地

维基文库四库本原行 11—11。附见[正文 L2715](../本地分卷/三国志/三国志-卷057.md#l2715)。

<a id="pei-005-1"></a>

> 吳書曰策討山越斬其渠帥悉令左右分行逐賊獨騎與翻相得山中翻問左右安在策曰悉行逐賊翻曰危事也令策下馬此草深卒有驚急馬不及縈策但牽之執弓矢以歩翻善用矛請在前行得平地勸策乗馬策曰卿無馬奈何答曰翻能歩行日可二百里自征討以來吏卒無及翻者明府試躍馬翻能疏歩隨之行一大道得一鼓吏策取角自鳴之部曲識聲小大皆出遂從周旋平定三郡

**虞翻保护孙策离开山地** 孙策攻山越后部下走散，虞翻请他牵马步行以免草深有伏、自己持矛开路；至大道重聚军队。

**归年依据** 《吴书》在孙策周旋平定三郡时，事无清楚年月。

[虞翻保护孙策离开山地（时期）](../../years/ce-0201-0300/时期-三国志卷057-虞陆张骆陆吾朱传纪年待考（2）.md#period-sgz057-p-005-1)。

<a id="pei-005-2"></a>

> 江表傳曰策討黄祖旋軍欲過取豫章特請翻語曰華子魚自有名字然非吾敵也加聞其戰具甚少若不開門譲城金鼓一震不得無所傷害卿便在前具宣孤意

**孙策命虞翻往说华歆** 孙策征黄祖归，欲取豫章，认为华歆非敌手，请虞翻劝其让城。

**归年依据** 《通鉴》卷六十三系建安四年沙羡后，同一取豫章事。

[199年第35条](../../years/ce-0101-0200/ce-0199.md#sgz057-p-005-2)。

<a id="pei-005-3"></a>

> 翻即奉命辭行徑到郡請被褠葛巾與敵相見謂歆曰君自料名聲之在海内孰與鄙郡故王府君歆曰不及也翻曰豫章資糧多少噐仗精否士民勇果孰與鄙郡又曰不如也翻曰討逆將軍智畧超世用兵如神前走劉揚州君所親見南定鄙郡亦君所聞也今欲守孤城自料資糧已知不足不早為計悔無及也今大軍已次椒丘僕便還去明日日中迎檄不到者與君辭矣翻既去歆明旦出城遣吏迎策

**虞翻陈利害，华歆迎孙策** 虞翻问华歆名望、战备及士民勇力与王朗相比如何，继以孙策诸战劝其降，华歆次晨出城派吏迎孙策。

**归年依据** 《江表传》同一交涉。

[199年第35条](../../years/ce-0101-0200/ce-0199.md#sgz057-p-005-3)。

<a id="pei-005-4"></a>

> 策既定豫章引軍還吳饗賜將士計功行賞謂翻曰孤昔再至夀春見馬日磾及與中州士大夫㑹語我東方人多才耳但恨學問不愽語議之間有所不及耳孤意猶謂未耳卿博學洽聞故前欲令卿一詣許交見朝士以折中國妄語兒卿不願行便使子綱恐子綱不能結兒軰舌也翻曰翻是明府家寳而以示人人倘留之則去明府良佐故前不行耳

**孙策与虞翻论东南士才** 孙策在吴地赏军，称虞翻博学能辩，曾欲派他赴许与中州士交谈，虞翻笑答离开反失良佐。

**归年依据** 《江表传》称定豫章而还后，按同一战后奖赏场面，单独日期未见。

[199年第35条](../../years/ce-0101-0200/ce-0199.md#sgz057-p-005-4)。

<a id="pei-005-5"></a>

> 策笑曰然因曰孤有征討事未得還府卿復以功曹為吾蕭何守㑹稽耳後三日便遣翻還郡

**孙策令虞翻再守会稽** 孙策比虞翻为萧何，令以功曹身份守会稽，三日后遣回。

**归年依据** 连载定豫章之后。

[199年第35条](../../years/ce-0101-0200/ce-0199.md#sgz057-p-005-5)。

<a id="pei-005-6"></a>

> 臣松之以為王華二公於擾攘之時抗猛銳之鋒俱非所能歆之名徳實髙於朗而江表傳述翻說華云海内名聲孰與於王此言非也然王公拒戰華逆請服實由孫策初起名微衆寡故王能舉兵豈武勝哉策後威力轉盛勢不可敵華量力而止非必用仲翔之說也若使易地而居亦華戰王服耳

**裴松之评论王朗、华歆应付孙策** 裴松之反对以名声断王朗优于华歆，认为孙策初起人众少，王朗尚能抵抗，孙策势盛，华歆权衡投降，情势差别重于虞翻劝辞。

**归年依据** 把196、199年事比较的后出史评。

[裴松之评论王朗、华歆应付孙策（时期）](../../years/ce-0201-0300/时期-三国志卷057-虞陆张骆陆吾朱传纪年待考（2）.md#period-sgz057-p-005-6)。

<a id="pei-005-7"></a>

> 按吳歴載翻謂歆曰竊聞明府與王府君齊名中州海内所宗雖在東垂常懐瞻仰歆答曰孤不如王㑹稽翻復問不審豫章精兵何如㑹稽對曰大不如也翻曰明府言不如王㑹稽謙光之譚耳精兵不如㑹稽實如尊教因述孫䇿才畧殊異用兵之竒歆乃答云當去此說為勝也翻出歆遣使迎策二說有不同

**《吴历》异记虞翻会华歆** 《吴历》写虞翻先称华歆、王朗齐名，华歆自谦不及，又称豫章兵不及会稽，最后派使迎孙策。

**归年依据** 同一取豫章事件的一种说法，裴松之指出《江表传》对白有异，《通鉴》主要用《吴历》说。

[199年第35条](../../years/ce-0101-0200/ce-0199.md#sgz057-p-005-7)。

## 006｜孙策死后孙暠谋取会稽

维基文库四库本原行 11—11。附见[正文 L2716](../本地分卷/三国志/三国志-卷057.md#l2716)。

<a id="pei-006-1"></a>

> 吳書曰策薨權繞事定武中郎將暠䇿之從兄也屯烏程整帥吏士欲取㑹稽㑹稽聞之使民守城以俟嗣主之命因令人告諭暠

**孙策死后孙暠谋取会稽** 孙策死，堂兄孙暠据乌程欲取会稽，会稽守城等孙权命令，派人告谕。

**归年依据** 《吴书》建安五年孙策卒后。

[200年第11条](../../years/ce-0101-0200/ce-0200.md#sgz057-p-006-1)。

<a id="pei-006-2"></a>

> 㑹稽典録載翻說暠曰討逆明府不竟天年今攝事綂衆宜在孝亷翻已與一郡吏士嬰城固守必欲出一旦之命為孝亷除害執亊圗之於是暠退

**虞翻警告孙暠勿进** 虞翻称应由孙权承业，自己已同吏士固守，若孙暠进则决战；孙暠退去。

**归年依据** 《会稽典录》承孙策死后。

[200年第11条](../../years/ce-0101-0200/ce-0200.md#sgz057-p-006-2)。

<a id="pei-006-3"></a>

> 臣松之案此二書所說䇿亡之時翻猶為功曹與本傳不同

**裴松之对勘虞翻身份** 裴松之认为《吴书》《会稽典录》都把此时的虞翻写为功曹，与本传出任富春长不同。

**归年依据** 200年身份异说，属后设考证。

[裴松之对勘虞翻身份（时期）](../../years/ce-0201-0300/时期-三国志卷057-虞陆张骆陆吾朱传纪年待考（2）.md#period-sgz057-p-006-3)。

## 008｜虞翻反对于禁返魏

维基文库四库本原行 11—11。附见[正文 L2719](../本地分卷/三国志/三国志-卷057.md#l2719)。

<a id="pei-008-1"></a>

> 吳書曰後權與魏和欲遣禁還歸北翻復諫曰禁敗數萬衆身為降虜又不能死北習軍政得禁必不如所規還之雖無所損猶為放盗不如斬以令三軍示為人臣有二心者權不聼

**虞翻反对于禁返魏** 吴魏和，孙权要送于禁回魏。虞翻认为于禁败而未死，不宜放走，请处斩示军，孙权没有采纳。

**归年依据** 《吴主传》《于禁传》黄初二年遣还，互见卷四十七、卷十七。

[221年第63条](../../years/ce-0201-0300/ce-0221.md#sgz057-p-008-1)。

<a id="pei-008-2"></a>

> 羣臣送禁翻謂禁曰卿勿謂吳無人吾謀適不用耳禁雖為翻所惡然猶盛歎翻

**虞翻在于禁临别时反言吴并非无人** 群臣送于禁时，虞翻说别以为吴无人，只是他的计策没有被用；于禁仍赞叹虞翻。

**归年依据** 承同一送行。

[221年第63条](../../years/ce-0201-0300/ce-0221.md#sgz057-p-008-2)。

<a id="pei-008-3"></a>

> 魏文帝常為翻設虛坐

**曹丕为虞翻设虚座** 曹丕常为虞翻预留席位。

**归年依据** 《吴书》未说席位初设年月。

[曹丕为虞翻设虚座（时期）](../../years/ce-0201-0300/时期-三国志卷057-虞陆张骆陆吾朱传纪年待考（2）.md#period-sgz057-p-008-3)。

## 009｜虞翻贺孙权即帝位

维基文库四库本原行 11—11。附见[正文 L2721](../本地分卷/三国志/三国志-卷057.md#l2721)。

<a id="pei-009-1"></a>

> 翻别傳曰權即尊號翻因上書曰陛下膺明聖之徳體舜禹之孝歴運當期順天濟物奉承策命臣獨抃舞罪棄兩絶拜賀無階仰瞻宸極且喜且悲

**虞翻贺孙权即帝位** 虞翻称颂孙权应命登尊，自己放逐海隅，无法参加朝贺，既喜且悲。

**归年依据** 《吴主传》黄龙元年四月即帝位。

[229年第13条](../../years/ce-0201-0300/ce-0229.md#sgz057-p-009-1)。

<a id="pei-009-2"></a>

> 臣伏自刻省命輕雀䑕性輶毫釐罪惡莫大不容于誅昊天罔極全宥九載退當念戮頻受生活復偷視息臣年耳順思咎憂憤形容枯悴髪白齒落雖未能死自悼終沒不見宫闕百官之富不覩皇輿金軒之飾仰觀巍巍衆民之謡傍聼鍾鼔侃然之樂永隕海隅棄骸絶域不勝悲慕逸豫大慶悅以忘罪

**虞翻在贺表自陈获宥与衰老** 虞翻自述受罪仍获宽宥九年，已到耳顺之年而形容衰悴，恐将老死海边，难见朝仪。

**归年依据** 同一贺表。“全宥九載”与“年耳顺”是生卒与放逐先后的旁证，不能各从一数硬定。

[229年第13条](../../years/ce-0201-0300/ce-0229.md#sgz057-p-009-2)。

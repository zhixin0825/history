## 001｜陆纡、陆骏的品行与官职

## 004｜《吴书》记陆逊阻诸将迎击刘备

维基文库四库本原行 11—11。附见[正文 L2772](../本地分卷/三国志/三国志-卷058.md#l2772)。

<a id="pei-004-1"></a>

> 吳書曰諸將竝欲迎擊備遜以為不可曰備舉軍東下鋭氣始盛且乘髙守險難可卒攻攻之縱下猶難盡克若有不利損我大勢非小故也今但且奨厲將士廣施方畧以觀其變若此間是平原曠野當恐有顛沛交馳之憂今縁山行軍勢不得展自當罷於木石之間徐制其弊耳諸將不解以為遜畏之各懐憤恨

**《吴书》记陆逊阻诸将迎击刘备** 蜀军气盛，又占险地，强攻有损；应先振励士卒，等敌人在山林难列阵而自疲。部将不解，误以为陆逊惧敌。

**归年依据** 相持约章武二年，注随吴班立平地营段；《通鉴》卷六十九转述。

## 005｜《吴录》记刘备以再东进试探陆逊

维基文库四库本原行 11—11。附见[正文 L2778](../本地分卷/三国志/三国志-卷058.md#l2778)。

<a id="pei-005-1"></a>

> 吳録曰劉備聞魏軍大出書與遜云賊今已在江陵吾將復東將軍謂其能然不遜答曰但恐軍新破創痍未復始求通親且當自補未暇窮兵耳若不推算欲復以傾覆之餘逺送以來者無所逃命

**《吴录》记刘备以再东进试探陆逊** 刘备听闻魏军攻到江陵，问能否再来；陆逊说蜀刚受重创，当补恢复睦，无暇再开战，否则来军难逃。

**归年依据** 魏三路出兵起于黄初三年，刘备崩在223；《通鉴》卷六十九紧叙魏进军，附222，往返具体月存考。

## 007｜陆逊撤至白围后袭江夏三县

维基文库四库本原行 11—11。附见[正文 L2787](../本地分卷/三国志/三国志-卷058.md#l2787)。

<a id="pei-007-1"></a>

> 臣松之以為遜慮孫權已退魏得専力於己既能張拓形勢使敵不敢犯方舟順流無復怵惕矣何為復潛遣諸將奄襲小縣致令市人駭奔自相傷害俘馘千人未足損魏徒使無事之民横罹荼酷與諸葛渭濱之師何其殊哉

**陆逊撤至白围后袭江夏三县** 裴松之认为陆逊已脱追兵，无须再袭小县、致百姓仓皇互伤；比较诸葛亮渭滨军纪，深责伤害无辜。

**归年依据** 本传嘉禾五年，独立史事系年参《吴主传》《通鉴》卷七十二234，裴评附所评战事。

[234年第62条](../../years/ce-0201-0300/ce-0234.md#sgz058-p-007-1)。

<a id="pei-007-2"></a>

> 用兵之道既違失律之凶宜應其祚無三世及孫而滅豈此之餘殃哉

**裴松之论用兵失律与吴亡** 裴松之怀疑滥杀有余殃，孙权子孙未传三世而亡是否与之相关。

**归年依据** 后出的历史褒贬；吴亡实际280，本评为因果推论。

[裴松之论用兵失律与吴亡（时期）](../../years/ce-0201-0300/时期-三国志卷058-陆逊传纪年待考.md#period-sgz058-p-007-2)。

## 012｜陆抗与羊祜交好

维基文库四库本原行 12—12。附见[正文 L2804](../本地分卷/三国志/三国志-卷058.md#l2804)。

<a id="pei-012-1"></a>

> 晋陽秋曰抗與羊祜推僑札之好抗嘗遺祜酒祜飲之不疑抗有疾祜饋之藥抗亦推心服之于時以為華元子反復見於今

**陆抗与羊祜交好** 《晋阳秋》说两将有季札、子产之交，陆抗馈酒、羊祜无疑；陆抗有病，亦信羊祜所馈药，时人比华元、子反。

**归年依据** 《通鉴》卷七十九在272西陵战后集叙；各次馈赠具体日月不载。

[272年第12条](../../years/ce-0201-0300/ce-0272.md#sgz058-p-012-1)。

<a id="pei-012-2"></a>

> 漢晋春秋曰羊祜既歸増修徳信以懐吳人陸抗毎告其邉戍曰彼專為徳我專為暴是不戰而自服也各保分界無求細益而已於是吳晋之間餘糧栖畆而不犯牛馬逸而入境可宣告而取也沔上獵吴獲晋人先傷者皆送而相還

**陆抗与羊祜交好** 羊祜自江陵还后以德信怀吴，陆抗也告边卒守界勿争小利；牛马越界可取，双方狩猎互还对境先伤之物。

**归年依据** 《通鉴》卷七十九272西陵役后，德信做法持续。

[272年第12条](../../years/ce-0201-0300/ce-0272.md#sgz058-p-012-2)。

<a id="pei-012-3"></a>

> 抗嘗疾求藥於祜祜以成合與之曰此上藥也近始自作未及服以君疾急故相致抗得而服之諸將或諫抗不答

**陆抗与羊祜交好** 陆抗病中求药，羊祜说明新配未尝，陆抗服之而不答部下谏止。

**归年依据** 同卷七十九272互遣使故事，疾病具体时月无记。

[272年第12条](../../years/ce-0201-0300/ce-0272.md#sgz058-p-012-3)。

<a id="pei-012-4"></a>

> 孫晧聞二境交和以詰於抗抗曰夫一邑一鄉不可以無信義之人而況大國乎臣不如是正足以彰其徳耳於祜無傷也或以祜抗為失臣節兩譏之

**陆抗与羊祜交好** 孙皓质问与晋交好，陆抗说国家必须讲信义，自己若失信只彰羊祜之德，也有人讥两人失臣节。

**归年依据** 《通鉴》随272西陵战后列。

[272年第12条](../../years/ce-0201-0300/ce-0272.md#sgz058-p-012-4)。

<a id="pei-012-5"></a>

> 習鑿齒曰夫理勝者天下之所保信順者萬人之所宗雖大猷既喪義聲乆淪狙詐馳於當塗權畧周乎急務負力從横之人臧獲牧豎之智未有不慿此以創功捨兹而獨立者也是故晋文退舍而原城請命穆子圍鼔訓之以力冶夫獻策而費人斯歸樂毅緩攻而風烈長流觀其所以服物制勝者豈徒威力相詐而已哉

**习凿齿论信义可成事功** 天下保合理、众人宗信顺，不能只靠权诈；引晋文公、叔孙穆子、冶夫、乐毅诸先例证成。

**归年依据** 两晋史家事后作评；诸比喻属更早史事。

[习凿齿论信义可成事功（时期）](../../years/ce-0201-0300/时期-三国志卷058-陆逊传纪年待考.md#period-sgz058-p-012-5)。

<a id="pei-012-6"></a>

> 自今三家鼎足四十有餘年矣吳人不能越淮沔而進取中國中國不能陵長江以爭利者力均而智侔道不足以相傾也夫殘彼而利我未若利我而無殘振武以懼物未若徳廣而民懐匹夫猶不可以力服而况一國乎力服猶不如以徳來而況不制乎

**习凿齿评论三国均衡以德优于威** 三国长期相持，彼此智力相近而难入对境；求让自己获利且不害人，应以德怀远。

**归年依据** 作者总评数十年，单年不适用。

[习凿齿评论三国均衡以德优于威（时期）](../../years/ce-0201-0300/时期-三国志卷058-陆逊传纪年待考.md#period-sgz058-p-012-6)。

<a id="pei-012-7"></a>

> 是以羊祜恢大同之畧思五兵之則齊其民人均其施澤振義〔四库字图3508〕以羅彊吳明兼愛以革暴俗易生民之視聼馳不戰乎江表故能徳音悅暢而襁負雲集殊鄰異域義譲交弘自吳之遇敵未有若此者也

**习凿齿论羊祜以德怀吴** 羊祜以德及民，兼爱去暴，吴人扶携归附，无须先开战。

**归年依据** 史家后评，所议是羊祜历年边事。

[习凿齿论羊祜以德怀吴（时期）](../../years/ce-0201-0300/时期-三国志卷058-陆逊传纪年待考.md#period-sgz058-p-012-7)。

<a id="pei-012-8"></a>

> 抗見國小主暴而晋徳彌昌人積兼己之善而已無固夲之規百姓懐嚴敵之徳闔境有棄主之慮思所以鎮定民心緝寜外内奮其危弱抗權上國者莫若親行斯道以侔其勝使彼徳靡加吾而此善流聞歸重邦國弘明逺風折衝於枕席之上校勝於帷幄之内傾敵而不以甲兵之力保國而不浚溝池之固信義感於寇讎丹懐體於先日豈設狙詐以危賢狥己身之私名貪外物之重我闇服之而不備者哉

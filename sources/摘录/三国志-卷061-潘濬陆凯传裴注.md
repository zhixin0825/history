## 001｜《吴书》载王粲称赏潘濬

维基文库四库本原行 11—11。附见[正文 L2892](../本地分卷/三国志/三国志-卷061.md#l2892)。

> 吳書曰濬為人聰察對問有機理山陽王粲見而貴異之由是知名為郡功曹

**《吴书》载王粲称赏潘濬** 潘濬聪颖，答问得理，王粲见而器重，由此出名并任郡功曹。

## 002｜孙权入江陵后延见潘濬

维基文库四库本原行 11—11。附见[正文 L2893](../本地分卷/三国志/三国志-卷061.md#l2893)。

<a id="pei-002-1"></a>

> 江表傳曰權克荆州将吏悉皆歸附而濬獨稱疾不見權遣人以牀就家輿致之濬伏面著牀席不起涕泣交横哀咽不能自勝

**孙权入江陵后延见潘濬** 荆州诸吏归附，潘濬独称病不见。孙权令连床抬到跟前，潘濬伏床啼哭，一时不能自持。

**归年依据** 《通鉴》卷六十八建安二十四年夺荆州后。

[219年第8条](../../years/ce-0201-0300/ce-0219.md#sgz061-p-002-1)。

<a id="pei-002-2"></a>

> 權慰勞與語呼其字曰承明昔觀丁父鄀俘也武王以為軍師彭仲爽申俘也文王以為令尹此二人卿荆國之先賢也初雖見囚後皆擢用為楚名臣卿獨不然未肯降意将以孤異古人之量耶使親近以手巾拭其面濬起下地拜謝即以為治中荆州諸軍事一以諮之

**孙权引楚国先例劝用潘濬** 孙权以楚人任俘臣观丁父和彭仲爽作比，劝潘濬信他容人；令人拭泪，潘濬拜谢，受任治中，孙权以荆州军事咨询之。

**归年依据** 同年《通鉴》；《江表传》称治中，本传称辅军中郎将，记载视角不同。

[219年第8条](../../years/ce-0201-0300/ce-0219.md#sgz061-p-002-2)。

<a id="pei-002-3"></a>

> 武陵部從事樊伷誘導諸夷圗以武陵屬劉備外白差督督萬人徃討之權不聼特召問濬濬答以五千兵徃足可以擒伷權曰卿何以輕之濬曰伷是南陽舊姓頗能弄脣吻而實無辯論之才臣所以知之者伷昔嘗為州人設饌比至日中食不可得而十餘自起此亦侏儒觀一莭之騐也

**潘濬判断五千人足以平樊伷** 樊伷联合地方诸部拟归刘备，有人请发万人，孙权问潘濬。潘濬说樊伷徒善口头应对而筹事不足，以他曾迟迟办不成宴为例，建议五千兵可平。

**归年依据** 《通鉴》卷六十八连于建安二十四年潘濬受孙权任用。

[219年第8条](../../years/ce-0201-0300/ce-0219.md#sgz061-p-002-3)。

<a id="pei-002-4"></a>

> 權大笑而納其言即遣濬将五千徃果斬平之

**孙权遣潘濬率五千讨斩樊伷** 孙权采用潘濬意见，遣其领五千兵，讨平并斩樊伷。

**归年依据** 《通鉴》卷六十八建安二十四年。

[219年第8条](../../years/ce-0201-0300/ce-0219.md#sgz061-p-002-4)。

## 003｜芮玄卒，潘濬领其兵屯夏口

维基文库四库本原行 11—11。附见[正文 L2893](../本地分卷/三国志/三国志-卷061.md#l2893)。

<a id="pei-003-1"></a>

> 吳書曰芮玄卒濬并領玄兵屯夏口

**芮玄卒，潘濬领其兵屯夏口** 芮玄死后，潘濬兼领他的兵马屯夏口。

**归年依据** 同注末明记芮玄黄武五年卒，接管承其卒。

[226年第48条](../../years/ce-0201-0300/ce-0226.md#sgz061-p-003-1)。

<a id="pei-003-2"></a>

> 玄字文表丹陽人父祉字宣嗣從孫堅征伐有功堅薦祉為九江太守後轉吳郡所在有聲

**芮玄家世、父芮祉官履** 芮玄字文表，丹杨人；父芮祉随孙坚立功，孙坚荐为九江太守，后守吴郡有声望。

**归年依据** 家世及芮祉历职无确年。

[芮玄家世、父芮祉官履（时期）](../../years/ce-0201-0300/时期-三国志卷061-潘濬陆凯传纪年待考.md#period-sgz061-p-003-2)。

<a id="pei-003-3"></a>

> 玄兄良字文鸞随孫䇿平定江東策以為㑹稽東部都尉卒玄領良兵拜奮武中郎将以功封溧陽侯

**芮良随孙策平江东，芮玄继领其兵** 芮良从孙策平江东，为会稽东部都尉，死后芮玄领其部曲，拜奋武中郎将，因功封溧阳侯。

**归年依据** 历年征战和早期任命合叙，无法以一日期覆盖。

[芮良随孙策平江东，芮玄继领其兵（时期）](../../years/ce-0201-0300/时期-三国志卷061-潘濬陆凯传纪年待考.md#period-sgz061-p-003-3)。

<a id="pei-003-4"></a>

> 權為子登揀擇淑媛羣臣咸稱玄父祉兄良并以徳義文武顯名三世故遂娉玄女為妃焉

**孙权选芮玄女作孙登妃** 群臣称芮祉、芮良、芮玄三代文武著称，孙权聘芮玄女为孙登妃。

**归年依据** 《孙登传》及本注未记芮妃成礼年月；周瑜女为另一材料。

[孙权选芮玄女作孙登妃（时期）](../../years/ce-0201-0300/时期-三国志卷061-潘濬陆凯传纪年待考.md#period-sgz061-p-003-4)。

<a id="pei-003-5"></a>

> 黄武五年卒權甚愍惜之

**芮玄卒，潘濬领其兵屯夏口** 芮玄黄武五年去世，孙权很惋惜。

**归年依据** 《吴书》注文明记黄武五年。

[226年第48条](../../years/ce-0201-0300/ce-0226.md#sgz061-p-003-5)。

## 004｜潘濬劝孙权戒射雉

维基文库四库本原行 11—11。附见[正文 L2893](../本地分卷/三国志/三国志-卷061.md#l2893)。

<a id="pei-004-1"></a>

> 江表傳曰權數射雉濬諫權權曰相與别後時時蹔出耳不復如徃日之時也濬曰天下未定萬機務多射雉非急〔四库字图2959〕絶括破皆能為害乞特為臣故息置之濬出見雉翳故在乃手自撤壊之權由是自絶不復射雉

**潘濬劝孙权戒射雉** 孙权称非久出射雉，潘濬说天下未定、射雉又易致弓弦箭括损坏而伤人，出见雉翳亲自拆毁，孙权从此戒射。

**归年依据** 此事未记年；字图依点校作「弦」。

## 005｜潘濬劝孙权勿许步骘自行召募

维基文库四库本原行 11—11。附见[正文 L2893](../本地分卷/三国志/三国志-卷061.md#l2893)。

<a id="pei-005-1"></a>

> 吳書曰驃騎将軍歩隲屯漚口求召募諸郡以増兵權以問濬濬曰豪将在民間耗亂為害加隲有名勢在所所媚不可聼也權從之

**潘濬劝孙权勿许步骘自行召募** 步骘屯沤口，想自诸郡募兵扩众，潘濬说豪将本多扰民，步骘又位高势重，孙权从而未准。

**归年依据** 《步骘传》各次驻屯、升骠骑可参，但特定请求无确年。

[潘濬劝孙权勿许步骘自行召募（时期）](../../years/ce-0201-0300/时期-三国志卷061-潘濬陆凯传纪年待考.md#period-sgz061-p-005-1)。

<a id="pei-005-2"></a>

> 中郎将豫章徐宗有名士也嘗到亰師與孔融交結然儒生誕莭部曲寛縱不奉莭度為衆作殿濬遂斬之其奉法不憚私議皆此類也

**潘濬斩不奉军令的徐宗** 徐宗虽有名、与孔融交好，却放纵部曲、不守节制，潘濬将他斩首，作者用作不徇私例证。

**归年依据** 与孔融相交是早年背景，处置徐宗仍无确年。

[潘濬斩不奉军令的徐宗（时期）](../../years/ce-0201-0300/时期-三国志卷061-潘濬陆凯传纪年待考.md#period-sgz061-p-005-2)。

<a id="pei-005-3"></a>

> 歸義隐蕃以口辯為豪傑所善濬子翥亦與周旋饋餉之濬聞大怒疏責翥曰吾受國厚恩志報以命爾輩在都當念恭順親賢慕善何故與降虜交以糧餉之在逺聞此心震面熱惆悵累旬疏到急就徃使受杖一百促責所餉

**潘濬责子潘翥亲近隐蕃** 隐蕃善辩为权贵喜爱，潘翥来往送粮，潘濬严责其辜负国恩，命到派来的人处受杖一百并追回馈物。

**归年依据** 《通鉴》卷七十一魏太和四年（吴黄龙二年）叙隐蕃入吴与受责。

[230年第20条](../../years/ce-0201-0300/ce-0230.md#sgz061-p-005-3)。

<a id="pei-005-4"></a>

> 當時人咸恠濬而蕃果圗叛誅夷衆乃歸服

**隐蕃谋变后众人服潘濬先见** 旁人初惊讶责子，隐蕃果谋叛而遭诛，众人服潘濬。

**归年依据** 《通鉴》卷七十一连叙太和四年隐蕃案，未记个别处分月。

[230年第20条](../../years/ce-0201-0300/ce-0230.md#sgz061-p-005-4)。

<a id="pei-005-5"></a>

> 江表傳曰時濬姨兄零陵蒋琬為蜀大将軍或有間濬于武陵太守衛旍者云濬遣宻使與琬相聞欲有自託之計旍以啓權權曰承明不為此也即封旍表以示於濬而召旍還免官

**孙权不信卫旌告潘濬私通蒋琬** 有言潘濬密遣使联系表兄蒋琬，卫旌据以上奏；孙权驳斥，封起奏章给潘濬看，召回免卫旌职。

**归年依据** 《通鉴》卷七十二太和五年同讨五溪载本事，称蒋琬时为诸葛亮长史；《江表传》称大将军，235始任此官，故按年序明记231并存官称异文。

[231年第16条](../../years/ce-0201-0300/ce-0231.md#sgz061-p-005-5)。

## 007｜《吴录》对陆凯谋废传闻的另一记法

维基文库四库本原行 12—12。附见[正文 L2910](../本地分卷/三国志/三国志-卷061.md#l2910)。

<a id="pei-007-1"></a>

> 吳録曰舊拜廟選兼大将軍領三千兵為衛凱欲因此兵以圗之令選曹白用丁奉晧偶不欲曰更選凱令執據雖蹔兼然宜得其人晧曰用留平凱令其子禕以謀語平

**《吴录》对陆凯谋废传闻的另一记法** 吴旧例谒庙选兼大将军为卫，传说陆凯想借此，荐丁奉，孙皓改选留平。陆凯遣子陆祎探意。

**归年依据** 承本传或曰266十二月事项；《通鉴》考异不取。

[266年第5条](../../years/ce-0201-0300/ce-0266.md#sgz061-p-007-1)。

<a id="pei-007-2"></a>

> 平素與丁奉有隙禕未及得宣凱旨平語禕曰聞野猪入丁奉營此凶徴也有喜色禕乃不敢言還因具啓凱故輟止

**《吴录》异说陆祎未向留平明言** 留平向来与丁奉有隙，在陆祎尚未吐露来意前就喜谈丁奉军中不祥，陆祎遂不敢说，回来报告，谋因而停止。

**归年依据** 同一原传传闻；与正文留平已听明确内容而拒的叙述不同。

[266年第5条](../../years/ce-0201-0300/ce-0266.md#sgz061-p-007-2)。

## 009｜陆凯谏孙皓积恶招乱

维基文库四库本原行 12—12。附见[正文 L2933](../本地分卷/三国志/三国志-卷061.md#l2933)。

<a id="pei-009-1"></a>

> 江表傳曰晧所行彌暴凱知其将亡上表曰臣聞惡不可積過不可長積惡長過䘮亂之源也是以古人懼不聞非故設進善之旍立敢諌之鼓武公九十思聞警戒詩美其徳士悦其行臣察陛下無思警戒之義而有積惡之漸臣深憂之此禍兆見矣故畧陳其要寫盡愚懐

**陆凯谏孙皓积恶招乱** 传说陆凯见孙皓愈暴，上疏以古人求谏及卫武公晚年求警为例，指责孙皓渐积恶行。

**归年依据** 《江表传》未系此疏年月，处孙皓264即位至269陆凯卒间。

[陆凯谏孙皓积恶招乱（时期）](../../years/ce-0201-0300/时期-三国志卷061-潘濬陆凯传纪年待考.md#period-sgz061-p-009-1)。

## 001｜吴范秘术的缘由

维基文库四库本原行 11—11。附见[正文 L2968](../本地分卷/三国志/三国志-卷063.md#l2968)。

<a id="pei-001-1"></a>

> 吳録曰範獨心計所以見重者術術亡則身棄矣故終不言

**吴范秘术的缘由** 《吴录》说吴范担心把术交出便失去孙权重视，因而终不说明。

**归年依据** 训释本传反复问术的过程，无明确一次问答的年月。

## 002｜魏滕的世系、品行和仕历

维基文库四库本原行 11—11。附见[正文 L2971](../本地分卷/三国志/三国志-卷063.md#l2971)。

<a id="pei-002-1"></a>

> 㑹稽典録曰滕字周林祖父河内太守朗字少英列在八俊滕性剛直行不苟合雖遭困偪終不逥撓初亦忤䇿㡬殆頼太妃救得免語見妃嬪傳歴厯山潘陽山隂三縣令鄱陽太守

**魏滕的世系、品行和仕历** 《会稽典录》述魏滕祖父魏朗名列八俊、魏滕刚直。魏滕曾冒犯孙策，赖太妃救免，另历县令与鄱阳太守。

**归年依据** 各任官缺独立年月。孙策与太妃一案属孙策统事时，不能混同本传孙权、吴范一案。

## 003｜《吴录》记吴范自言死期

维基文库四库本原行 11—11。附见[正文 L2972](../本地分卷/三国志/三国志-卷063.md#l2972)。

<a id="pei-003-1"></a>

> 吳録曰範先知其死日謂權曰陛下某日當䘮軍師權曰吾無軍師焉得䘮之範曰陛下出軍臨敵湏臣言而後行臣乃陛下之軍師也至其日果卒

**《吴录》记吴范自言死期** 《吴录》说吴范提前向孙权说自己将在某日死，后来果然去世。

**归年依据** 本传明黄武五年卒。所谓预言、具体日子仅属所引记述。

[226年第32条](../../years/ce-0201-0300/ce-0226.md#sgz063-p-003-1)。

<a id="pei-003-2"></a>

> 臣松之案範死時權未稱帝此云陛下非也

**裴松之校正《吴录》“陛下”称谓** 裴松之指出吴范亡时孙权没有称帝，不能有“陛下”的称呼。

**归年依据** 吴范卒226，孙权称帝229，所据年条可相参。“陛下”属引本文字。

[裴松之校正《吴录》“陛下”称谓（时期）](../../years/ce-0201-0300/时期-三国志卷063-吴范刘惇赵达传纪年待考.md#period-sgz063-p-003-2)。

## 004｜孙权称帝后问赵达帝祚

维基文库四库本原行 13—13。附见[正文 L2979](../本地分卷/三国志/三国志-卷063.md#l2979)。

<a id="pei-004-1"></a>

> 吳書曰初權即尊號令達算作天子之後當復㡬年達曰髙祖建元十二年陛下倍之權大喜左右稱萬嵗果如逹言

**孙权称帝后问赵达帝祚** 《吴书》记孙权称帝请赵达推算国祚，赵达以高祖十二年加倍回答，孙权欢喜。

**归年依据** 原注以孙权即尊号指称帝，黄龙元年（229）。计算和应验是《吴书》叙事。

[229年第13条](../../years/ce-0201-0300/ce-0229.md#sgz063-p-004-1)。

## 005｜《吴录》记江东八绝

维基文库四库本原行 13—13。附见[正文 L2979](../本地分卷/三国志/三国志-卷063.md#l2979)。

<a id="pei-005-1"></a>

> 吳録曰皇象字休明廣陵江都人㓜工書時有張子並陳梁甫能書甫恨逋並恨峻象斟酌其間甚得其妙中國善書者不能及也嚴武字子卿衛尉畯再從子也圍棊莫與為輩宋夀占夢十不失一曹不興善畫權使畫屏風誤落茟㸃素因就以作蠅既進御權以為生蠅舉手彈之孤城鄭嫗能相人及範惇達八人世皆稱妙謂之八絶云

**《吴录》记江东八绝** 《吴录》合述皇象书法、严武围棋、宋寿占梦、曹不兴绘画、郑妪相人和三传术士的事迹。

**归年依据** 皇象等生涯与传闻跨年。曹不兴画屏只标孙权在时，无具体年。

[《吴录》记江东八绝（时期）](../../years/ce-0201-0300/时期-三国志卷063-吴范刘惇赵达传纪年待考.md#period-sgz063-p-005-1)。

<a id="pei-005-2"></a>

> 晉陽秋曰吳有葛衡字思真明達天官能為機巧作渾天使地居于中以機動之天轉而地止以上應晷度

**葛衡制作浑天器** 《晋阳秋》记葛衡通天官、善机巧，制作地居中、天转的浑天器。

**归年依据** 只明属吴，制作年份无载。

[葛衡制作浑天器（时期）](../../years/ce-0201-0300/时期-三国志卷063-吴范刘惇赵达传纪年待考.md#period-sgz063-p-005-2)。

## 006｜孙盛批评赵达术数之说

维基文库四库本原行 14—14。附见[正文 L2980](../本地分卷/三国志/三国志-卷063.md#l2980)。

<a id="pei-006-1"></a>

> 孫盛曰夫玄覧未然逆鍳来事雖禆竈梓慎其猶病諸况術之下此者乎吳史書逹知東南當有王氣故輕舉濟江魏承漢緒受命中畿達不能豫覩兆萌而流竄吳越又不知吝術之鄙見薄于時安在其能逆覩天道而審帝王之符瑞哉昔聖王觀天地之文以畫八卦之象故亹亹成于蓍策變化形乎六爻是以三易雖殊卦繇理一安有逥轉一籌可以鉤深測隐意對逆占而能遂知来物者乎流俗好異妄設神竒不幸之中仲尼所棄是以君子志其大者無所取諸

**孙盛批评赵达术数之说** 孙盛认为赵达无法预知魏兴，批评占术神奇的传闻，并引三易、六爻作反驳。

**归年依据** 孙盛史论跨魏吴。魏受禅220是论据，不能当作赵达渡江的日期。

[孙盛批评赵达术数之说（时期）](../../years/ce-0201-0300/时期-三国志卷063-吴范刘惇赵达传纪年待考.md#period-sgz063-p-006-1)。

<a id="pei-006-2"></a>

> 臣松之以為盛云君子志其大者無所取諸故評家之㫖非新聲也其餘所譏則皆為非理自中原酷亂至于建安數十年間生民殆盡比至小康皆百死之餘耳江左雖有兵革不能如中國之甚也焉知逹不算其安危知禍有多少利在東南以全其身乎而責不知魏氏将興流播吳越在京房之籌猶不能自免刑戮况逹但以祕術見薄在悔吝之間乎古之道術盖非一方探賾之功豈惟六爻苟得其要則可以易而知之矣迴轉一籌胡足怪哉逹之推算窮其要妙以知幽測隐何愧于古而以禆梓限之謂逹為妄非䔍論也

**裴松之回应孙盛** 裴松之认为陈寿已指出君子志大，孙盛据赵达避祸与惜术否定其他术数的说法也有问题。

**归年依据** 南朝校注史评，所举中原战乱、京房等跨时期，无对应单年。

[裴松之回应孙盛（时期）](../../years/ce-0201-0300/时期-三国志卷063-吴范刘惇赵达传纪年待考.md#period-sgz063-p-006-2)。

<a id="pei-006-3"></a>

> 抱朴子曰時有葛仙公者毎飲酒醉常入人家門前陂水中卧竟日乃出曽從吳主别到洌洲還遇大風百官船多没仙公船亦沈淪吳主甚悵恨明日使人鈎求公船而登髙以望焉久之見公歩從水上来衣履不沾而有酒色既見而言曰臣昨侍從而伍子胥見請暫過設酒忽忽不得即委之

**葛仙公遇风落水的传闻** 《抱朴子》说葛仙公随吴主归途中遇风，次日传说从水上走来，自称被伍子胥留饮。

**归年依据** 神仙叙事，无具体年。吴主当为孙权，传闻照出处留存。

[葛仙公遇风落水的传闻（时期）](../../years/ce-0201-0300/时期-三国志卷063-吴范刘惇赵达传纪年待考.md#period-sgz063-p-006-3)。

<a id="pei-006-4"></a>

> 又有姚光者有火術吳主身臨試之積荻數千束使光坐其上又以數千束荻褁之因猛風而燔之荻了盡謂光當以化為燼而光端坐灰中振衣而起把一卷書吳主取其書視之不能觧也

**吴主试姚光火术的传闻** 《抱朴子》记姚光坐在苇薪之中举火，火后能从灰中起身。

**归年依据** 神仙术传闻，仅知称吴主，无确年。

[吴主试姚光火术的传闻（时期）](../../years/ce-0201-0300/时期-三国志卷063-吴范刘惇赵达传纪年待考.md#period-sgz063-p-006-4)。

<a id="pei-006-5"></a>

> 又曰吳景帝有疾求覡視者得一人景帝欲試之乃殺鵝而埋于苑中築小屋施牀几以婦人屐履服物著其上乃使覡視之告曰若能說此冡中鬼婦人形状者當加賞而即信矣竟日盡夕無言帝推問之急乃曰實不見有鬼但見一頭白鵝立墓上所以不即白之疑是鬼神變化作此相當〔四库字图1974〕其真形而定無復移易不知何故不敢不以實上聞景帝乃厚賜之然則鵝死亦有鬼也

**吴景帝以白鹅试巫** 《抱朴子》记吴景帝将白鹅葬入园中，试问巫者见到什么，巫者最后说见白鹅。

**归年依据** 吴景帝孙休在位258—264，疾病及试巫年份无从确证。

[吴景帝以白鹅试巫（时期）](../../years/ce-0201-0300/时期-三国志卷063-吴范刘惇赵达传纪年待考.md#period-sgz063-p-006-5)。

<a id="pei-006-6"></a>

> 葛洪神仙傳曰仙人介象字元則㑹稽人有諸方術吳主聞之徴象到武昌甚敬貴之稱為介君為起宅以御帳給之賜遺前後累千金從象學蔽形之術試還後宫及出殿門莫有見者又使象作變化種〔四库字图2201〕菜百果皆立生可食吳主共論鱠魚何者最羙象曰鯔魚為上吳主曰論近道魚耳此出海中安可得邪象曰可得耳乃令人于殿庭中作方埳汲水滿之并求鉤象起餌之垂綸于埳中湏臾果得鯔魚吳主驚喜問象曰可食不象曰故為陛下取以作生鱠安敢取不可食之物乃使厨下切之吳主曰聞蜀使来得蜀薑作韲甚好恨爾時無此象曰蜀薑豈不易得願差所使者可付值吳主指左右一人以錢五十付之象書一符以著青竹杖中使行人閉目騎杖杖止便買薑訖復閉目此人承其言騎杖湏臾止已至成都不知是何處問人人言是蜀市中乃買薑于時吳使張温先在蜀既于市中相識甚驚便作書寄其家此人買薑畢捉書負薑騎杖閉目湏臾己還到吳厨下切鱠適了

**孙权召介象及介象诸方术传说** 《神仙传》叙孙权在武昌召介象，试其隐身、种植、得海鱼和从成都买姜之术。

**归年依据** 张温224年出使蜀可作为传说中的时间线索，但各术并合，尚不足以据此确定召介象和试术的日期。

[孙权召介象及介象诸方术传说（时期）](../../years/ce-0201-0300/时期-三国志卷063-吴范刘惇赵达传纪年待考.md#period-sgz063-p-006-6)。

<a id="pei-006-7"></a>

> 臣松之以為葛洪所記近為惑衆其書文頗行世故撮取數事載之萹末也神仙之術詎可測量臣之臆斷以為惑衆所謂夏蟲不知冷冰耳

**裴松之评论葛洪方术叙事** 裴松之说葛洪的说法近于惑众，因著作流传而择数事附录。

**归年依据** 后出评论无确年，明标所引为传闻。

[裴松之评论葛洪方术叙事（时期）](../../years/ce-0201-0300/时期-三国志卷063-吴范刘惇赵达传纪年待考.md#period-sgz063-p-006-7)。

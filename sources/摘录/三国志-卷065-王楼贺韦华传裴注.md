## 001｜《江表传》另载孙皓问射义未答即斩王蕃

维基文库四库本原行 11—11。附见[正文 L3037](../本地分卷/三国志/三国志-卷065.md#l3037)。

<a id="pei-001-1"></a>

> 江表傳曰晧用巫史之言謂建業宮不利乃西廵武昌仍有遷都之意恐羣臣不從乃大請㑹賜將吏問蕃射不主皮為力不同科其義云何蕃思維未答即於殿上斬蕃出登來山使親近將跳蕃首作虎跳狼爭咋齧之頭皆碎壊欲以示威使衆不敢犯也此與本傳不同

**《江表传》另载孙皓问射义未答即斩王蕃** 因巫言西巡及谋迁都，孙皓集众问王蕃射义，答案未出便斩，后使人抛掷毁首。

**归年依据** 与266杀王蕃同一人物和结果，设问、迁都先后与醉酒说不同，传中时序不单取。

[266年第6条](../../years/ce-0201-0300/ce-0266.md#sgz065-p-001-1)。

<a id="pei-001-2"></a>

> 吳錄曰晧毎於㑹因酒酣輒令侍臣嘲謔公卿以為笑樂萬彧既為左丞相蕃嘲彧曰魚潜於淵出水煦沬何則物有本性不可横處非分也彧出自谿谷羊質虎皮虚受光赫之寵跨越三九之位犬馬尤能識飬将何以報厚施乎彧曰唐虞之朝無謬舉之才造父之門無駑蹇之質蕃上誣眀選下訕楨幹亦何傷於日月適多見其不知量耳

**《吴录》以宴席嘲万彧解释王蕃案** 万彧为相后，王蕃嘲其逾分，万彧反驳。

**归年依据** 注本说王蕃死前万彧已经为相，与实际任官时间不合，裴松之下辨。

[《吴录》以宴席嘲万彧解释王蕃案（时期）](../../years/ce-0201-0300/时期-三国志卷065-王楼贺韦华传纪年待考.md#period-sgz065-p-001-2)。

<a id="pei-001-3"></a>

> 臣松之按本傳云丁忠使晋還晧為大㑹於㑹中殺蕃檢忠從北還在此年之春彧時尚未為丞相至秋乃為相耳吴錄所言為乖互不同

**裴松之对照王蕃死和万彧任丞相先后** 丁忠春还吴，宴中杀王蕃，当时万彧尚未任丞相，至同年秋才为相。

**归年依据** 校文字义，针对266年春秋；不立另一杀人条。

[裴松之对照王蕃死和万彧任丞相先后（时期）](../../years/ce-0201-0300/时期-三国志卷065-王楼贺韦华传纪年待考.md#period-sgz065-p-001-3)。

## 002｜楼玄被转徙交阯，后见密敕自杀

维基文库四库本原行 12—12。附见[正文 L3043](../本地分卷/三国志/三国志-卷065.md#l3043)。

<a id="pei-002-1"></a>

> 江表傳曰晧遣將張奕追賜元鴆奕以元賢者不忍即宣詔致藥元隂知之謂弈曰當早告元元何惜邪即服藥死

**楼玄被转徙交阯，后见密敕自杀** 《江表传》说张奕不忍立刻宣诏赐鸩，楼玄知后主动请求明白告知而服药。

**归年依据** 《通鉴》卷079将楼玄赴交州及死随272被诬记。正文见密敕自杀，裴注另说。

[272年第6条](../../years/ce-0201-0300/ce-0272.md#sgz065-p-002-1)。

<a id="pei-002-2"></a>

> 臣松之以元之清髙必不以安危易操無縁驟拜張弈以虧其節且禍機既發豈百拜所免江表傳所言於理為長

**裴松之取《江表传》楼玄自知受鸩说** 以楼玄清高不以生死改变操守，不会频拜张奕求免为理由。

**归年依据** 史家评议并列。

[裴松之取《江表传》楼玄自知受鸩说（时期）](../../years/ce-0201-0300/时期-三国志卷065-王楼贺韦华传纪年待考.md#period-sgz065-p-002-2)。

## 004｜贺循少因贺邵案流放海隅

维基文库四库本原行 13—13。附见[正文 L3052](../本地分卷/三国志/三国志-卷065.md#l3052)。

<a id="pei-004-1"></a>

> 邵子循字彦先虞預晉書曰循丁家禍流放海濵

**贺循少因贺邵案流放海隅** 虞预《晋书》写贺邵子贺循家难，少年流放。

**归年依据** 父275被杀、家人徙临海，但本文未载贺循具体被遣月份。

[贺循少因贺邵案流放海隅（时期）](../../years/ce-0201-0300/时期-三国志卷065-王楼贺韦华传纪年待考.md#period-sgz065-p-004-1)。

<a id="pei-004-2"></a>

> 吳平還鄉里

**晋平吴，贺循归乡** 吴亡后贺循得归。

**归年依据** 《晋书·贺循传》同作吴平乃还本郡，太康元年，归乡具体月日不载。

[280年第4条](../../years/ce-0201-0300/ce-0280.md#sgz065-p-004-2)。

<a id="pei-004-3"></a>

> 節操髙厲童齓不羣言行舉動必以禮譲好學博聞尤善三禮舉秀才除陽羡武康令

**贺循少有节操，通三礼，举秀才宰两县** 贺循举秀才，任阳羡及武康县令。

**归年依据** 学行、举秀才与两任年月无独立证。

[贺循少有节操，通三礼，举秀才宰两县（时期）](../../years/ce-0201-0300/时期-三国志卷065-王楼贺韦华传纪年待考.md#period-sgz065-p-004-3)。

<a id="pei-004-4"></a>

> 顧榮陸機陸雲表薦循曰伏見吳興武康令賀循徳量邃茂才鑒清逺服膺道素風操凝峻歴踐三城刑政肅穆守職下縣編名凡萃出自新邦朝無知已恪居遐外志不自營年時倏忽而邈無階緒實州黨愚智所為悵然臣等並以凡才累授飾進被服㤙澤忝豫朝未知良士後時而守局無言懼有蔽賢之咎是以不勝愚管謹冒死表聞久之召為太子舍人

**顾荣、陆机、陆云举荐贺循，后补太子舍人** 表赞其才鉴与政绩，称来自吴地无朝援，久后受任东宫。

**归年依据** 虞预列顾、二陆，《晋书·贺循传》引陆机表，并荐郭讷，两本有出入。表与任官无确年。

[顾荣、陆机、陆云举荐贺循，后补太子舍人（时期）](../../years/ce-0201-0300/时期-三国志卷065-王楼贺韦华传纪年待考.md#period-sgz065-p-004-4)。

<a id="pei-004-5"></a>

> 石沐破揚州循亦合衆

**石冰攻扬州，贺循起兵** 贺循随江东响应起兵，反击石冰。

**归年依据** 《通鉴》卷085太安二年十二月记贺循起兵于会稽。底本“石沐”，《晋书》和《通鉴》作石冰。

[303年第1条](../../years/ce-0301-0400/ce-0303.md#sgz065-p-004-5)。

<a id="pei-004-6"></a>

> 事平杜門不出

**石冰败死，贺循解众归隐** 事平后贺循闭门不出。

**归年依据** 《通鉴》卷085永兴元年三月石冰被杀，周玘、贺循皆散众归。

[304年第1条](../../years/ce-0301-0400/ce-0304.md#sgz065-p-004-6)。

<a id="pei-004-7"></a>

> 陳敏作亂以循為丹陽内史循稱疾固辭敏不敢逼於是江東豪右無不受敏爵位惟循與同郡朱誕不挂賊網

**陈敏欲用贺循为丹阳内史，贺循拒绝** 陈敏据江东时贺循称疾，并与朱诞等不受其职。

**归年依据** 《通鉴》卷086永兴二年陈敏据江东并授职，贺循抗拒自此。

[305年第1条](../../years/ce-0301-0400/ce-0305.md#sgz065-p-004-7)。

<a id="pei-004-8"></a>

> 後除吳國内史不就元皇帝為鎮東將軍請循為軍司馬

**贺循辞吴国内史，司马睿引其为僚** 晋廷拟任郡守不就，司马睿后来征为军司马。

**归年依据** 《晋书》写安东、镇东两阶段并叙顾荣卒后任军司，本注较简，授与辞让不强定年。

[贺循辞吴国内史，司马睿引其为僚（时期）](../../years/ce-0201-0300/时期-三国志卷065-王楼贺韦华传纪年待考.md#period-sgz065-p-004-8)。

<a id="pei-004-9"></a>

> 帝為晉王以循為中書令固譲不受轉太常領太子太傅時朝廷初建動有疑議宗廟制度皆循所定朝野諮詢為一時儒宗

**司马睿为晋王，任贺循中书令，贺循辞而改太常** 贺循推辞中书令，改任太常及后来领太子太傅，议定新朝礼仪。

**归年依据** 《晋书·贺循传》《通鉴》卷090建武元年受命并辞在317；太傅与礼制后续不必全在该年。

[317年第1条](../../years/ce-0301-0400/ce-0317.md#sgz065-p-004-9)。

<a id="pei-004-10"></a>

> 年六十太興二年卒追贈司空謚曰穆循諸所著論並傳於世子隰臨海太守

**贺循病逝，追赠司空，谥穆** 贺循六十岁卒，著论行世，其子贺隰任临海太守。

**归年依据** 本注与《晋书·贺循传》同书太兴二年。其子任官无纪年。

[319年第1条](../../years/ce-0301-0400/ce-0319.md#sgz065-p-004-10)。

## 卷首与秦王政前二十五年

<a id="p001"></a>
### P001｜身世、出生、继位与接手局势

> 秦始皇帝者，秦莊襄王子也。莊襄王為秦質子於趙，見呂不韋姬，悅而取之，生始皇。以秦昭王四十八年正月生於邯鄲。及生，名為政，姓趙氏。年十三歲，莊襄王死，政代立為秦王。

> 呂不韋為相，封十萬戶，號曰文信侯。招致賓客游士，欲以并天下。李斯為舍人。蒙驁、王齮、麃公等為將軍。王年少，初即位，委國事大臣。

范围还包括秦已取得巴蜀、汉中、南郡、河东太原上党、三川等地的局势概述。出生归前259年，继位归前247年，接手局势放前246年阅读；不将疆域形成、诸人此前任职全部算在元年。

<a id="p002"></a>
### P002｜元年，晋阳

卷首末句：

> 晉陽反。

下一年条：

> 秦始皇元年，將軍蒙驁擊定之。

两处连接阅读，不伪称原来就是同一个自然段。

<a id="p003"></a>
### P003｜二年，麃公攻卷

> 二年，麃公將卒攻卷，斬首三萬。

<a id="p004"></a>
### P004｜三年，攻韩魏与饥荒

> 三年，蒙驁攻韓，取十三城。王齮死。十月，將軍蒙驁攻魏氏暢、有詭。歲大饑。

<a id="p005"></a>
### P005｜四年，罢兵、质子、蝗疫与纳粟

> 四年，拔暢、有詭。三月，軍罷。秦質子歸自趙，趙太子出歸國。十月庚寅，蝗蟲從東方來，蔽天。天下疫。百姓內粟千石，拜爵一級。

<a id="p006"></a>
### P006｜五年，东郡

> 五年，將軍驁攻魏，定酸棗、燕、虛、長平、雍丘、山陽城，皆拔之，取二十城。初置東郡。冬雷。

<a id="p007"></a>
### P007｜六年，合纵与卫迁野王

> 六年，韓、魏、趙、衛、楚共擊秦，取壽陵。秦出兵，五國兵罷。拔衛，迫東郡，其君角率其支屬徙居野王，阻其山以保魏之河內。

“其君角”与《卫康叔世家》的世次抵牾，正文只称卫君。联军名单也有互见差异，见考证。

<a id="p008"></a>
### P008｜七年，将领、太后与彗星

> 七年，彗星先出東方，見北方，五月見西方。將軍驁死。以攻龍、孤、慶都，還兵攻汲。彗星復見西方十六日。夏太后死。

<a id="p009"></a>
### P009｜八年，成蟜与嫪毐

> 八年，王弟長安君成蟜將軍擊趙，反，死屯留，軍吏皆斬死，遷其民於臨洮。將軍壁死，卒屯留、蒲鶴反，戮其尸。河魚大上，輕車重馬東就食。

> 嫪毐封為長信侯。予之山陽地，令毐居之。宮室車馬衣服苑囿馳獵恣毐。事無小大皆決於毐。又以河西太原郡更為毐國。

“将军壁死”以下句读有困难，不据此编造一位已经确认名叫“壁”的将军。

<a id="p010"></a>
### P010｜九年，冠礼、嫪毐之乱与处罚

> 四月，上宿雍。己酉，王冠，帶劍。長信侯毐作亂而覺，矯王御璽及太后璽以發縣卒及衛卒、官騎、戎翟君公、舍人，將欲攻蘄年宮為亂。王知之，令相國昌平君、昌文君發卒攻毐。戰咸陽，斬首數百，皆拜爵，及宦者皆在戰中，亦拜爵一級。

> 毐等敗走。即令國中：有生得毐，賜錢百萬；殺之，五十萬。盡得毐等。

范围续含卫尉、内史等二十人枭首，车裂嫪毐、灭族，门客轻者鬼薪，夺爵迁蜀四千余家、家房陵。年条还记彗星、攻魏垣蒲阳、杨端和取衍氏及寒冻死人。寒冻月份在网页保留“（四）［是］月”校记，正文不隐去异文。

<a id="p011"></a>
### P011｜十年，免相、迎太后、逐客与尉缭

> 十年，相國呂不韋坐嫪毐免。桓齮為將軍。齊、趙來置酒。

> 秦王乃迎太后於雍而入咸陽，復居甘泉宮。

> 大索，逐客，李斯上書說，乃止逐客令。

范围包括茅焦以迁母太后有损招徕天下劝谏；李斯主张取韩威慑他国，韩国与韩非谋划；尉缭以三十万金贿赂诸侯重臣、拆散合纵为策，受秦王厚遇，后欲离去，仍被挽留为国尉。尉缭以秦王相貌推断性情的言辞是人物评价，不作编者已证实的心理结论。

<a id="p012"></a>
### P012｜十一年，分路攻赵与选兵

> 十一年，王翦、桓齮、楊端和攻鄴，取九城。王翦攻閼與、橑楊，皆并為一軍。翦將十八日，軍歸斗食以下，什推二人從軍取鄴安陽，桓齮將。

末句的句读和省略主语不能直接展开为无缺的军制表，也不证明整场战争只打十八日。

<a id="p013"></a>
### P013｜十二年，吕不韦死、门客处分与旱

> 十二年，文信侯不韋死，竊葬。其舍人臨者，晉人也逐出之；秦人六百石以上奪爵，遷；五百石以下不臨，遷，勿奪爵。自今以來，操國事不道如嫪毐、不韋者籍其門，視此。秋，復嫪毐舍人遷蜀者。當是之時，天下大旱，六月至八月乃雨。

门客处分中的“不临”照见证保留，不未经校勘改成“临”。饮毒及迁蜀书信是年页另引《通鉴》等补足，不伪称本段已写全。

<a id="p014"></a>
### P014｜十三年，桓齮攻赵

> 十三年，桓齮攻趙平陽，殺趙將扈輒，斬首十萬。王之河南。正月，彗星見東方。十月，桓齮攻趙。

<a id="p015"></a>
### P015｜十四年，取赵城与韩非之死

> 十四年，攻趙軍於平陽，取宜安，破之，殺其將軍。桓齮定平陽、武城。韓非使秦，秦用李斯謀，留非，非死雲陽。韓王請為臣。

须与李牧反击、韩非列传合读，不因本段只记秦取城，就写成整个战局秦从无败绩。

<a id="p016"></a>
### P016｜十五年，大举攻赵

> 十五年，大興兵，一軍至鄴，一軍至太原，取狼孟。地動。

<a id="p017"></a>
### P017｜十六年，接地、书年与丽邑

> 十六年九月，發卒受地韓南陽假守騰。初令男子書年。魏獻地於秦。秦置麗邑。

<a id="p018"></a>
### P018｜十七年，灭韩

> 十七年，內史騰攻韓，得韓王安，盡納其地，以其地為郡，命曰潁川。地動。華陽太后卒。民大饑。

<a id="p019"></a>
### P019｜十八年，围邯郸

> 十八年，大興兵攻趙，王翦將上地，下井陘，端和將河內，羌瘣伐趙，端和圍邯鄲城。

<a id="p020"></a>
### P020｜十九年，赵王被俘与代政权

> 十九年，王翦、羌瘣盡定取趙地東陽，得趙王。引兵欲攻燕，屯中山。秦王之邯鄲，諸嘗與王生趙時母家有仇怨，皆阬之。秦王還，從太原、上郡歸。始皇帝母太后崩。趙公子嘉率其宗數百人之代，自立為代王，東與燕合兵，軍上谷。大饑。

<a id="p021"></a>
### P021｜二十年，荆轲与易水

> 二十年，燕太子丹患秦兵至國，恐，使荊軻刺秦王。秦王覺之，體解軻以徇，而使王翦、辛勝攻燕。燕、代發兵擊秦軍，秦軍破燕易水之西。

<a id="p022"></a>
### P022｜二十一年，蓟、楚、新郑与昌平君

> 二十一年，王賁攻（薊）［荊］。乃益發卒詣王翦軍，遂破燕太子軍，取燕薊城，得太子丹之首。燕王東收遼東而王之。王翦謝病老歸。新鄭反。昌平君徙於郢。大雨雪，深二尺五寸。

括号为所据网页校改标记，不是本项目新造地名。

<a id="p023"></a>
### P023｜二十二年，水攻大梁

> 二十二年，王賁攻魏，引河溝灌大梁，大梁城壞，其王請降，盡取其地。

<a id="p024"></a>
### P024｜二十三年，攻楚的一种编排

> 二十三年，秦王復召王翦，彊起之，使將擊荊。取陳以南至平輿，虜荊王。秦王游至郢陳。荊將項燕立昌平君為荊王，反秦於淮南。

俘楚王与《通鉴》次年俘负刍的编排不一致。项燕、昌平君的次序还与其他篇章抵牾，见考证，不拼成无争议的逐月故事。

<a id="p025"></a>
### P025｜二十四年，楚军与昌平君、项燕

> 二十四年，王翦、蒙武攻荊，破荊軍，昌平君死，項燕遂自殺。

<a id="p026"></a>
### P026｜二十五年，燕、代与江南

> 二十五年，大興兵，使王賁將，攻燕遼東，得燕王喜。還攻代，虜代王嘉。王翦遂定荊江南地；降越君，置會稽郡。五月，天下大酺。

## 统一后的制度与巡行

<a id="p027"></a>
### P027｜二十六年，灭齐

> 二十六年，齊王建與其相后勝發兵守其西界，不通秦。秦使將軍王賁從燕南攻齊，得齊王建。

<a id="p028"></a>
### P028｜议帝号、追尊与废谥

范围：秦王陈述六国罪责，群臣议泰皇、制诏朕等称谓，秦王定皇帝号，追尊庄襄王，废除谥法。战争回顾是诏令自述，不另记作本年六次新战争。

> 去「泰」，著「皇」，采上古「帝」位號，號曰「皇帝」。他如議。

> 追尊莊襄王為太上皇。

> 朕為始皇帝。後世以計數，二世三世至于萬世，傳之無窮。

最后一句是制度安排与愿望，不是实际王朝延续的结果。

<a id="p029"></a>
### P029｜水德、岁首、尚黑与严法

> 朝賀皆自十月朔。衣服旄旌節旗皆上黑。數以六為紀。

> 於是急法，久者不赦。

范围包括五德相胜、周火秦水的解释；符、法冠、车辆、步长、乘马等用六为纪，黄河改称德水；以水德配合严峻用法。这是观念与制度叙述，不证明五德真能决定政权兴亡。

<a id="p030"></a>
### P030｜分封还是郡县

> 諸侯初破，燕、齊、荊地遠，不為置王，毋以填之。請立諸子，唯上幸許。

> 今海內賴陛下神靈一統，皆為郡縣，諸子功臣以公賦稅重賞賜之，甚足易制。

范围：王绾等建议封皇子坐镇远方；李斯以周代同姓封国后来互相攻伐反对；始皇赞同李斯，认为重新立国就是重新树兵。奖励皇子功臣与赋予独立封国不是同一政策。

<a id="p031"></a>
### P031｜统一制度、收兵迁户与跨年宫室

> 分天下以為三十六郡，郡置守、尉、監。更名民曰「黔首」。大酺。收天下兵，聚之咸陽，銷以為鐘鐻，金人十二，重各千石，置廷宮中。一法度衡石丈尺。車同軌。書同文字。

> 徙天下豪富於咸陽十二萬戶。

> 秦每破諸侯，寫放其宮室，作之咸陽北阪上，南臨渭，自雍門以東至涇、渭，殿屋複道周閣相屬。所得諸侯美人鐘鼓，以充入之。

还包括帝国四至、渭南宗庙、章台、上林的全局描述。历年营建与后续拓地范围，不一概当成前221年新完成。

<a id="p032"></a>
### P032｜二十七年，西巡、宫路与驰道

> 二十七年，始皇巡隴西、北地，出雞頭山，過回中。

> 是歲，賜爵一級。治馳道。

中间记渭南信宫改极庙、取象天极，极庙通骊山，甘泉前殿及自咸阳相连的甬道。未记各工程逐段竣工日。

<a id="p033"></a>
### P033｜二十八年，峄山、泰山与封禅

范围：东巡郡县，峄山立石，与鲁儒议封禅、山川祭祀；登泰山封祭，下山遇风雨、树下避雨、封树五大夫，禅梁父。泰山颂辞节引：

> 二十有六年，初并天下，罔不賓服。

这里回顾二十六年统一，不把二十八年立石误归前221年。颂辞续颂皇帝勤政、法式、后嗣遵法、贵贱男女秩序；是朝廷规范性陈述。

<a id="p034"></a>
### P034｜沿海到琅邪：迁民、建台、刻辞与群臣议论

范围：沿勃海，经黄、腄、成山、之罘，南登琅邪，留三月，迁三万户，复十二岁，筑琅邪台并刻石。刻辞分引：

> 維二十八年，皇帝作始。端平法度，萬物之紀。

> 上農除末，黔首是富。普天之下，摶心揖志。器械一量，同書文字。

> 黔首安寧，不用兵革。

王离、王贲、赵亥、成、冯毋择、隗林、王绾、李斯、王戊、赵婴、杨樛等从臣还共同议论古帝王与郡县一统，赞新制、贬前代。原名衔以固定见证为准，不据从臣名单推定首次任职年；“不用兵革”等不能替代对当时战争的实际记载。

<a id="p035"></a>
### P035｜徐巿出海

> 既已，齊人徐巿等上書，言海中有三神山，名曰蓬萊、方丈、瀛洲，僊人居之。請得齋戒，與童男女求之。於是遣徐巿發童男女數千人，入海求僊人。

“徐巿”通常与徐福合读，不造两个人各出海一次；本段没有确记抵达日本。

<a id="p036"></a>
### P036｜泗水求鼎、湘山与回程

> 始皇還，過彭城，齋戒禱祠，欲出周鼎泗水。使千人沒水求之，弗得。乃西南渡淮水，之衡山、南郡。浮江，至湘山祠。逢大風，幾不得渡。上問博士曰：「湘君神？」博士對曰：「聞之，堯女，舜之妻，而葬此。」於是始皇大怒，使刑徒三千人皆伐湘山樹，赭其山。上自南郡由武關歸。

<a id="p037"></a>
### P037｜二十九年，博浪沙

> 二十九年，始皇東游。至陽武博狼沙中，為盜所驚。求弗得，乃令天下大索十日。

本卷此处没有直接点名张良。原文作“博狼沙”，正文用通行写法“博浪沙”。

<a id="p038"></a>
### P038｜之罘两篇刻辞及返程

第一篇节引：

> 維二十九年，時在中春，陽和方起。皇帝東游，巡登之罘，臨照于海。從臣嘉觀，原念休烈，追誦本始。

第一篇续称六国贪戾、秦义讨除暴、普施明法。第二篇即“其东观曰”，节引：

> 皇帝明德，經理宇內，視聽不怠。作立大義，昭設備器，咸有章旗。職臣遵分，各知所行，事無嫌疑。

第二篇还颂六王被灭、永偃戎兵、名分与后嗣循业。两篇均有去向，不当作本年再次兼并六国。

> 旋，遂之瑯邪，道上黨入。

<a id="p039"></a>
### P039｜三十年，无事

> 三十年，無事。

只表示本纪本年没有另列纪事，不能断言全国一年没有任何活动。

<a id="p040"></a>
### P040｜三十一年，嘉平、兰池与米价

> 三十一年十二月，更名臘曰「嘉平」。賜黔首裏六石米，二羊。始皇為微行咸陽，與武士四人俱，夜出逢盜蘭池，見窘，武士擊殺盜，關中大索二十日。米石千六百。

<a id="p041"></a>
### P041｜三十二年，碣石与方士

> 三十二年，始皇之碣石，使燕人盧生求羨門、高誓。刻碣石門。壞城郭，決通隄防。

刻辞节引：

> 遂興師旅，誅戮無道，為逆滅息。武殄暴逆，文復無罪，庶心咸服。惠論功勞，賞及牛馬，恩肥土域。

续有拆城、防川、夷险、男女安业、黎庶无繇等颂辞。皇帝又使韩终、侯公、石生求仙人及不死药。刻辞不是撤销全部实际徭役的政令。

<a id="p042"></a>
### P042｜卢生谶言与蒙恬北伐

> 始皇巡北邊，從上郡入。燕人盧生使入海還，以鬼神事，因奏錄圖書，曰「亡秦者胡也」。始皇乃使將軍蒙恬發兵三十萬人北擊胡，略取河南地。

谶语与出兵的叙事衔接，不证明谶语能预知未来或是战争唯一原因。

<a id="p043"></a>
### P043｜三十三年，南北扩张

> 三十三年，發諸嘗逋亡人、贅婿、賈人略取陸梁地，為桂林、象郡、南海，以適遣戍。西北斥逐匈奴。自榆中并河以東，屬之陰山，以為三十四縣，城河上為塞。又使蒙恬渡河取高闕、陽山、北假中，筑亭障以逐戎人。徙謫，實之初縣。禁不得祠。明星出西方。

<a id="p044"></a>
### P044｜三十四年，治狱不直者受谪

> 三十四年，適治獄吏不直者，筑長城及南越地。

<a id="p045"></a>
### P045｜宴饮、分封争论与焚书令

范围：七十博士上寿，周青臣颂郡县，淳于越批其面谀并主张封子弟、师古，李斯反对以古非今、私学议令。李斯所请及批准：

> 臣請史官非秦記皆燒之。非博士官所職，天下敢有藏詩、書、百家語者，悉詣守、尉雜燒之。有敢偶語詩書者棄市。以古非今者族。吏見知不舉者與同罪。令下三十日不燒，黥為城旦。所不去者，醫藥卜筮種樹之書。若有欲學法令者，以吏為師。

> 制曰：「可。」

对象、例外、刑罚必须一起读，不简化为“一切书全部烧掉”；也不是下一年诸生案的同一命令。

<a id="p046"></a>
### P046｜三十五年，直道、阿房与物料人口

> 三十五年，除道，道九原抵雲陽，塹山堙谷，直通之。

> 阿房宮未成；成，欲更擇令名名之。

范围：嫌咸阳人多、宫庭小，营渭南上林苑新朝宫，先做阿房前殿，记五百步、五十丈及容万人等尺度，南山门阙与跨渭复道取象星宫；七十余万人分作阿房、骊山，发北山石、输蜀楚材，记关中三百宫与关外四百余宫；朐界秦东门立石，迁丽邑三万家、云阳五万家，复十年。上述各项均回年页，人数不能拆成阿房与骊山各七十余万。

<a id="p047"></a>
### P047｜隐秘宫居与泄密追杀

> 行所幸，有言其處者，罪死。

范围：卢生以真人、恶鬼及不死药劝皇帝隐藏行踪，皇帝自称真人；咸阳二百里内二百七十宫观用复道甬道相连，配置钟鼓帷帐宫人。梁山宫见丞相车骑多而不悦，丞相闻讯减少车骑，皇帝追查传言不得，尽杀当时在旁者。此后更无人知道其行踪，群臣受决事在咸阳宫。这里将因果、人数范围及听政地点分别说明，不误写成政府从此完全没有办公地点。

<a id="p048"></a>
### P048｜侯卢逃亡、诸生案与扶苏

> 始皇長子扶蘇諫曰：「天下初定，遠方黔首未集，諸生皆誦法孔子，今上皆重法繩之，臣恐天下不安。唯上察之。」始皇怒，使扶蘇北監蒙恬於上郡。

范围：侯生、卢生批评皇帝独断、刑杀、衡石量书及群臣畏罪，随后逃走；始皇以求药耗费和方士谤议发怒，御史调查咸阳诸生，彼此告引，四百六十余人犯禁而遭坑，另加谪徙。人数是文本记数，“诸生”“阬”的身份与刑罚实施有辨析空间，不能未经证据全译成某一职业或全部活埋。

<a id="p049"></a>
### P049｜三十六年，天象、陨石、还璧与迁民

> 三十六年，熒惑守心。有墜星下東郡，至地為石，黔首或刻其石曰「始皇帝死而地分」。始皇聞之，遣御史逐問，莫服，盡取石旁居人誅之，因燔銷其石。始皇不樂，使博士為仙真人詩，及行所游天下，傳令樂人歌弦之。

范围续含秋夜华阴平舒道使者得璧、滈池君、今年祖龙死、八年前旧璧、占卜游徙吉。还璧和预言属于神异叙事，不当作已验证事件。

> 遷北河榆中三萬家。拜爵一級。

## 始皇终局与秦亡

<a id="p050"></a>
### P050｜三十七年，末次巡行与会稽刻石

范围：十月癸丑出巡，李斯随、冯去疾守，胡亥同行；十一月云梦望祭舜，沿江丹阳钱唐，绕渡浙江，登会稽祭禹、望海刻石。会稽刻辞分引：

> 皇帝休烈，平一宇內，德惠修長。三十有七年，親巡天下，周覽遠方。遂登會稽，宣省習俗，黔首齋莊。

> 飾省宣義，有子而嫁，倍死不貞。防隔內外，禁止淫泆，男女絜誠。夫為寄豭，殺之無罪，男秉義程。妻為逃嫁，子不得母，咸化廉清。

全刻还含六王罪状、征讨、法度、职任、善否呈报与后世奉法。记载这些性别和婚姻规范，不表示现代编者接受其评价。

<a id="p051"></a>
### P051｜徐巿之说与始皇射鱼

> 方士徐巿等入海求神藥，數歲不得，費多，恐譴，乃詐曰：「蓬萊藥可得，然常為大鮫魚所苦，故不得至，願請善射與俱，見則以連弩射之。」

> 至之罘，見巨魚，射殺一魚。遂并海西。

范围：回经吴、江乘、琅邪；始皇梦海神，博士解梦，配捕鱼器具、连弩；沿海到荣成山而未见，至之罘射鱼。梦与方术解释不当作海神真实现身，古鱼名不强定现代物种。

<a id="p052"></a>
### P052｜病、沙丘之死与改诏

> 至平原津而病。始皇惡言死，群臣莫敢言死事。上病益甚，乃為璽書賜公子扶蘇曰：「與喪會咸陽而葬。」書已封，在中車府令趙高行符璽事所，未授使者。七月丙寅，始皇崩於沙丘平臺。

> 高乃與公子胡亥、丞相斯陰謀破去始皇所封書賜公子扶蘇者，而更詐為丞相斯受始皇遺詔沙丘，立子胡亥為太子。

> 會暑，上輼車臭，乃詔從官令車載一石鮑魚，以亂其臭。

范围还包括李斯秘不发丧、棺载辒凉车、宦者假批奏事、伪书赐死扶苏蒙恬及井陉九原返程。“会丧”不是明文“传位扶苏”；赐死命令也不等于两人在同一刻实际死亡，过程与异说见年页及考证。

<a id="p053"></a>
### P053｜二世继位、九月葬与陵墓回叙

> 行從直道至咸陽，發喪。太子胡亥襲位，為二世皇帝。九月，葬始皇酈山。始皇初即位，穿治酈山，及并天下，天下徒送詣七十餘萬人，穿三泉，下銅而致槨，宮觀百官奇器珍怪徙臧滿之。

> 以水銀為百川江河大海，機相灌輸，上具天文，下具地理。以人魚膏為燭，度不滅者久之。

后续还记机关弩、无子后宫从死、闭工匠于墓道、种草木象山。早年开工的回叙归前246年，规模扩大与前210年葬仪分层。陵内描述不是本项目宣称主墓室已发掘后逐项证实。

<a id="p054"></a>
### P054｜二世元年，宗庙与称谓

> 二世皇帝元年，年二十一。趙高為郎中令，任用事。二世下詔，增始皇寢廟犧牲及山川百祀之禮。

范围续含尊始皇为帝者祖庙，依天子七庙调整旧庙及二世复称朕。正文二十一岁与篇末十二岁不同，不改出两个即位者。

<a id="p055"></a>
### P055｜二世东巡与旧石附刻

> 春，二世東行郡縣，李斯從。到碣石，并海，南至會稽，而盡刻始皇所立刻石，石旁著大臣從者名，以章先帝成功盛德焉。

> 皇帝曰：「金石刻盡始皇帝所為也。今襲號而金石刻辭不稱始皇帝，其於久遠也如後嗣為之者，不稱成功盛德。」

李斯、冯去疾、御史大夫德请将诏辞刻入，获得批准；年条又接辽东而还。始皇旧刻与二世增刻是两个年代层次。

<a id="p056"></a>
### P056｜宗室官员清洗与将闾兄弟

> 公子將閭昆弟三人囚於內宮，議其罪獨後。

> 將閭乃仰天大呼天者三，曰：「天乎！吾無罪！」昆弟三人皆流涕拔劍自殺。

范围：二世、赵高以旧臣诸公子不服为由严法清算，大臣、诸公子、近侍牵连，六公子戮于杜；将闾求问罪名不得，与兄弟自杀，宗室惊恐、谏者以为诽谤。数字和其他列传不直接相加作无重叠总数。

<a id="p057"></a>
### P057｜四月复工阿房与粮草压力

> 四月，二世還至咸陽，曰：「先帝為咸陽朝廷小，故營阿房宮為室堂。未就，會上崩，罷其作者，復土酈山。酈山事大畢，今釋阿房宮弗就，則是章先帝舉事過也。」復作阿房宮。

> 盡徵其材士五萬人為屯衛咸陽，令教射狗馬禽獸。當食者多，度不足，下調郡縣轉輸菽粟芻稿，皆令自齎糧食，咸陽三百里內不得食其穀。用法益刻深。

<a id="p058"></a>
### P058｜反秦四起与使者报讯

> 七月，戍卒陳勝等反故荊地，為「張楚」。勝自立為楚王，居陳，遣諸將徇地。

> 謁者使東方來，以反者聞二世。二世怒，下吏。後使者至，上問，對曰：「群盜，郡守尉方逐捕，今盡得，不足憂。」上悅。

同段总括武臣、魏咎、田儋及沛公、项梁，须与月表及现有各方年页合读，不将全部称王行动都定在七月。

<a id="p059"></a>
### P059｜二年段压缩的战争

> 二年冬，陳涉所遣周章等將西至戲，兵數十萬。

> 二世益遣長史司馬欣、董翳佐章邯擊盜，殺陳勝城父，破項梁定陶，滅魏咎臨濟。

范围包括二世惊、章邯请赦骊山徒授兵、周章败走与曹阳之死，以及章邯北围赵歇于巨鹿。本段与月表、列传存在次序和压缩问题：周文至戏初败在元年九月，最后渑池自杀在二年十一月；陈胜被庄贾杀，魏咎先于项梁死，巨鹿又跨三年。年页分阶段归前209—207年，不机械照抄。

<a id="p060"></a>
### P060｜隔绝君臣与冯、李谏诤

> 於是二世常居禁中，與高決諸事。其後公卿希得朝見，盜賊益多，而關中卒發東擊盜者毋已。

范围：赵高劝二世不亲见臣下决事，以免显出年少失误；冯去疾、李斯、冯劫指出戍漕转输、工役赋税重导致反乱，主张停阿房、减边戍转输；二世长篇答辩贵在肆意极欲，并引韩子责大臣不能尽忠止乱，将三人交吏另案。两冯自杀，李斯受五刑。其案件年次与下一单元相冲突，年页归二世二年，见考证。

<a id="p061"></a>
### P061｜三年，巨鹿、司马欣与章邯降楚

> 趙高用事於中，將軍有功亦誅，無功亦誅。

范围：项羽救巨鹿，秦军数退、二世责章邯；司马欣请事而赵高不见、不信，逃回，赵高追之不及；王离被俘、章邯降诸侯。本段也在三年冬又提李斯被杀，不能让已在前208年死去的人在前207年再死一次。司马欣之言是人物对朝廷的判断，不当作全部败因的唯一证明。

<a id="p062"></a>
### P062｜八月，指鹿为马

> 八月己亥，趙高欲為亂，恐群臣不聽，乃先設驗，持鹿獻於二世，曰：「馬也。」二世笑曰：「丞相誤邪？謂鹿為馬。」問左右，左右或默，或言馬以阿順趙高。

后续记坚持言鹿者遭赵高暗中治罪，群臣畏惧。沉默、说马、说鹿是三种反应，不换成另一版本的全员说马。

<a id="p063"></a>
### P063｜望夷宫与二世之死

> 二世曰：「吾願得一郡為王。」弗許。又曰：「願為萬戶侯。」弗許。曰：「願與妻子為黔首，比諸公子。」

> 二世自殺。

范围：刘邦入武关使赵高恐受责；二世梦白虎、占梦、祭泾水而居望夷；赵高、赵成、阎乐谋更立，假追贼突宫、杀守卫郎宦；二世求见丞相与逐级求退皆不许，最终自杀。神异是叙事背景，政变不简化为赵高手刃二世。

<a id="p064"></a>
### P064｜子婴为王，杀赵高

> 立二世之兄子公子嬰為秦王。以黔首葬二世杜南宜春苑中。令子嬰齋，當廟見，受王璽。齋五日，子嬰與其子二人謀曰……

> 子嬰遂刺殺高於齋宮，三族高家以徇咸陽。

范围：赵高以地缩、诸侯复立解释去帝号；子婴疑其借庙见加害，称病不往，赵高亲至，遂被杀。子婴亲缘有不同版本，年页不把一种说法当成定论。

<a id="p065"></a>
### P065｜在位四十六日与刘邦受降

> 子嬰為秦王四十六日，楚將沛公破秦軍入武關，遂至霸上，使人約降子嬰。子嬰即系頸以組，白馬素車，奉天子璽符，降軹道旁。沛公遂入咸陽，封宮室府庫，還軍霸上。

与《汉书》汉元年冬十月相接，古历整年归档与公历年界差别见年页提示。

<a id="p066"></a>
### P066｜项羽入关、三秦与远接汉定天下

> 居月餘，諸侯兵至，項籍為從長，殺子嬰及秦諸公子宗族。遂屠咸陽，燒其宮室，虜其子女，收其珍寶貨財，諸侯共分之。

> 後五年，天下定於漢。

中间记秦地分为雍、塞、翟三秦，项羽为西楚霸王、主命封诸侯。入关杀降与分封接汉元年，远接结语归汉五年、前202年；不以普通减法误算前201年，也不借这句结语冒称楚汉战争各年已写完。

## 论赞、秦先君世系与附记

<a id="p067"></a>
### P067｜太史公引出贾生评论

> 善哉乎賈生推言之也！

范围：回顾秦先伯翳唐虞功勋、西垂、穆公后蚕食诸侯，始皇自负超过五帝三王，以此引入贾生。唐虞部分是传统先世回顾，不据它补造绝对年。

<a id="p068"></a>
### P068｜贾生第一组议论：险固、禁谏与壅蔽

> 藉使子嬰有庸主之材，僅得中佐，山東雖亂，秦之地可全而有，宗廟之祀未當絕也。

范围：陈涉起兵、诸侯并起、秦朝君臣互不信任；设想子婴本可凭险固守；批评三主不改、忠言难进、奸情不上闻，主张以前事为师。这是解释和反事实，不是一份已经实施的军事计划。

<a id="p069"></a>
### P069｜贾生第二组议论：强秦与攻守势异

> 仁義不施，而攻守之勢異也。

范围：孝公据殽函、商君耕战法制，惠文至昭襄扩张，跨代列举诸侯谋臣将领，始皇兼并及南北征战、焚书收兵据险，对照陈涉出身微弱却引起崩溃。修辞上综合的跨代人名不编成同一场合纵的实际名单。

<a id="p070"></a>
### P070｜贾生第三组议论：二世本可救弊

> 天下之嗷嗷，新主之資也。此言勞民之易為仁也。

范围：百姓疲困企盼安定，新君原可改过，作者设想分封功臣、赦罪、散财、轻赋少事、约法省刑，使人自新；实际却复阿房、重刑税、使上下自危。这些好政策是“本可做”的议论，不是二世真实颁布的诏令。

<a id="p071"></a>
### P071｜秦先君世系、宫居、葬地与附见记事

本段与卷005的人名、世次、年数及死亡方式不尽一致。完整保留所据见证这一组世系文字，不用它覆盖此前已经采用的编年主线。

> 襄公立，享國十二年。初為西畤。葬西垂。生文公。
>
> 文公立，居西垂宮。五十年死，葬西垂。生靜公。
>
> 靜公不享國而死。生憲公。
>
> 憲公享國十二年，居西新邑。死，葬衙。生武公、德公、出子。
>
> 出子享國六年，居西陵。庶長弗忌、威累、參父三人，率賊賊出子鄙衍，葬衙。武公立。
>
> 武公享國二十年。居平陽封宮。葬宣陽聚東南。三庶長伏其罪。德公立。
>
> 德公享國二年。居雍大鄭宮。生宣公、成公、繆公。葬陽。初伏，以御蠱。
>
> 宣公享國十二年。居陽宮。葬陽。初志閏月。
>
> 成公享國四年，居雍之宮。葬陽。齊伐山戎、孤竹。
>
> 繆公享國三十九年。天子致霸。葬雍。繆公學著人。生康公。
>
> 康公享國十二年。居雍高寢。葬竘社。生共公。
>
> 共公享國五年，居雍高寢。葬康公南。生桓公。
>
> 桓公享國二十七年。居雍太寢。葬義裏丘北。生景公。
>
> 景公享國四十年。居雍高寢，葬丘裏南。生畢公。
>
> 畢公享國三十六年。葬車裏北。生夷公。
>
> 夷公不享國。死，葬左宮。生惠公。
>
> 惠公享國十年。葬車里（康景）。生悼公。
>
> 悼公享國十五年。葬僖公西。城雍。生剌龔公。
>
> 剌龔公享國三十四年。葬入里。生躁公、懷公。其十年，彗星見。
>
> 躁公享國十四年。居受寢。葬悼公南。其元年，彗星見。
>
> 懷公從晉來。享國四年。葬櫟圉氏。生靈公。諸臣圍懷公，懷公自殺。
>
> 肅靈公，昭子子也。居涇陽。享國十年。葬悼公西。生簡公。
>

>

>
> 悼武王享國四年，葬永陵。
>
> 昭襄王享國五十六年。葬茝陽。生孝文王。

宫居、葬地没有另注明年的，不自动归君主元年；“生某公”也不等于本段已经给出出生年。宣公初志闰月等未确年补记保留于相应时期材料，确有王年的异说见考证对照。

> 孝公立十六年。時桃李冬華。

<a id="p074"></a>
### P074｜惠文王年龄、行钱与婴儿传言

> 惠文王生十九年而立。立二年，初行錢。有新生嬰兒曰「秦且王」。

婴儿预言按神异传说处理，“初行钱”不扩大成中国首次出现货币。

<a id="p075"></a>
### P075｜武王年龄与渭水赤

> 悼武王生十九年而立。立三年，渭水赤三日。

<a id="p076"></a>
### P076｜昭襄王四年开阡陌

> 昭襄王生十九年而立。立四年，初為田開阡陌。

与孝公时田界改革分开保留，不能无声改写为孝公十二年同一条。

<a id="p077"></a>
### P077｜孝文、庄襄与东周

> 孝文王生五十三年而立。
>
> 莊襄王生三十二年而立。立二年，取太原地。莊襄王元年，大赦，修先王功臣，施德厚骨肉，布惠於民。東周與諸侯謀秦，秦使相國不韋誅之，盡入其國。秦不絕其祀，以陽人地賜周君，奉其祭祀。

与既有前249、248年同事互见，不另造第二次灭东周。年龄口径与即位、次年元年分开考察。

<a id="p078"></a>
### P078｜始皇、二世与六百一十岁

> 始皇享國三十七年。葬酈邑。生二世皇帝。始皇生十三年而立。
>
> 二世皇帝享國三年。葬宜春。趙高為丞相安武侯。二世生十二年而立。
>
> 右秦襄公至二世，六百一十歲。

本见证“十二”与P054“二十一”抵牾；总数不能未经辨析反算所有秦先君的绝对年。年龄不是按现代周岁自动换算。

<a id="p079"></a>
### P079｜署名班固的篇后附记

> 孝明皇帝十七年十月十五日乙丑，曰：

> 秦之積衰，天下土崩瓦解，雖有周旦之材，無所復陳其巧，而以責一日之孤，誤哉！

> 吾讀秦紀，至於子嬰車裂趙高，未嘗不健其決，憐其志。嬰死生之義備矣。

范围：批始皇残虐、胡亥纵欲复阿房、杀大臣任赵高；赞子婴父子诛奸决断，反对贾谊与司马迁仍责其未能保秦，认为积败至此已无可挽回。全文还用郑伯、纪季及星象等典故论述，不改写为秦代现场发生的新事。

署时是汉明帝永平十七年、公元74年的文本时间，不是秦亡时间，也不是司马迁亲笔写于东汉。“车裂赵高”与前文“刺杀”的措辞差别保留，不拼成已确实复原的处刑过程。

## 早年与起兵

<a id="p001"></a>
### P001｜姓名、出身与年龄

> 項籍者，下相人也，字羽。初起時，年二十四。其季父項梁，梁父即楚將項燕，為秦將王翦所戮者也。項氏世世為楚將，封於項，故姓項氏。

项燕之死与卷006、王翦列传有差别，不据此再造一次死亡。二十四是起兵年龄，不用它制造有确日的出生页。

<a id="p002"></a>
### P002｜求学、项梁早年、吴中组织与观始皇

> 項籍少時，學書不成，去，學劍，又不成。項梁怒之。籍曰：「書足以記名姓而已。劍一人敵，不足學，學萬人敵！」於是項梁乃教籍兵法，籍大喜，略知其意，又不肯竟學。

> 秦始皇帝游會稽，渡浙江，梁與籍俱觀。籍曰：「彼可取而代也。」梁掩其口，曰：「毋妄言，族矣！」梁以此奇籍。

范围还包括项梁栎阳狱事、曹咎写信请司马欣帮助；杀人避仇吴中，主持徭役、丧事时以兵法编组宾客子弟、识别才能；项羽长八尺余、力能扛鼎。观巡据卷006会稽行程归前210，其余作为此前背景，不各强配年份。

<a id="p003"></a>
### P003｜二世元年九月，夺会稽郡政权

> 其九月，會稽守通謂梁曰：「江西皆反，此亦天亡秦之時也。吾聞先即制人，後則為人所制。吾欲發兵，使公及桓楚將。」

> 於是籍遂拔劍斬守頭。項梁持守頭，佩其印綬。

> 於是梁為會稽守，籍為裨將，徇下縣。

范围：借召逃亡者桓楚使项籍入府，杀守及压服府中人；召豪吏、收下县，得精兵八千；依旧日办事表现任校尉、候、司马。“江西”不是现代江西省，守通完整姓名不由简写强补。

<a id="p004"></a>
### P004｜召平假命、渡江与陈婴归附

> 聞陳王敗走，秦兵又且至，乃渡江矯陳王命，拜梁為楚王上柱國。

> 項梁渡淮，黥布、蒲將軍亦以兵屬焉。凡六七萬人，軍下邳。

范围：召平未下广陵；陈婴本为东阳令史，信谨获推为首，收众二万；母亲劝不宜骤称王，陈婴转依项氏名望而归项梁。召平是假传陈王命，不写成陈胜亲自批准。各部归附月日未全定。

<a id="p005"></a>
### P005｜秦嘉、景驹败亡与襄城屠杀

> 項梁謂軍吏曰：「陳王先首事，戰不利，未聞所在。今秦嘉倍陳王而立景駒，逆無道。」

> 項梁前使項羽別攻襄城，襄城堅守不下。已拔，皆阬之。

范围：秦嘉败至胡陵、还战而死；景驹走死梁地；余樊君战死，朱鸡石败归被诛；襄城为“前使”回叙，闻陈王确死后会薛，刘邦亦来。不把景驹逃死改为项梁当场亲手杀死。

<a id="p006"></a>
### P006｜范增进言与楚怀王

> 今君起江東，楚蠭起之將皆爭附君者，以君世世楚將，為能復立楚之後也。

> 乃求楚懷王孫心民間，為人牧羊，立以為楚懷王，從民所望也。

范围：范增居鄛、年七十，以旧怀王不返、楚南公三户之言解释民望，反对陈胜自立；陈婴为上柱国、封五县，与怀王都盱台，项梁武信君。南公之言属于被引用的政治言辞。

<a id="p007"></a>
### P007｜东阿解围、齐楚失和及项羽刘邦合战

> 田榮曰：「楚殺田假，趙殺田角、田閒，乃發兵。」項梁曰：「田假為與國之王，窮來從我，不忍殺之。」

范围：项梁与田荣、龙且救东阿；田荣逐田假、立田市，因楚赵不交出齐人而不再出兵；刘邦项羽屠城阳、破秦濮阳东、攻定陶不下、雍丘杀李由、外黄未下。军事与外交分别进入原有本年事件，不合成一句胜利。

<a id="p008"></a>
### P008｜宋义谏、定陶败亡与东退

> 宋義乃諫項梁曰：「戰勝而將驕卒惰者敗。今卒少惰矣，秦兵日益，臣為君畏之。」項梁弗聽。

> 秦果悉起兵益章邯，擊楚軍，大破之定陶，項梁死。

范围：宋义使齐时对高陵君显说项梁必败；刘邦项羽攻陈留未下，闻败东退，与吕臣分驻彭城东西及砀。预言性对话按传世记载归属。

<a id="p009"></a>
### P009｜秦围巨鹿的部署

> 章邯令王離、涉閒圍鉅鹿，章邯軍其南，筑甬道而輸之粟。陳餘為將，將卒數萬人而軍鉅鹿之北，此所謂河北之軍也。

赵歇、张耳入城，陈馀另在城外。围城、野战和输粮分工不抹掉。

<a id="p010"></a>
### P010｜怀王迁都收兵权

> 楚兵已破於定陶，懷王恐，從盱台之彭城，并項羽、呂臣軍自將之。以呂臣為司徒，以其父呂青為令尹。以沛公為碭郡長，封為武安侯，將碭郡兵。

<a id="p011"></a>
### P011｜宋义统军、安阳停留与项羽夺帅

> 行至安陽，留四十六日不進。

> 項羽晨朝上將軍宋義，即其帳中斬宋義頭，出令軍中曰：「宋義與齊謀反楚，楚王陰令羽誅之。」

> 使桓楚報命於懷王。懷王因使項羽為上將軍，當陽君、蒲將軍皆屬項羽。

范围：高陵君显荐宋义，任上将军，项羽鲁公次将、范增末将；等秦赵相耗与立即夹击的争论；宋义送子相齐、饮酒而军中冻饥；项羽杀将，军中先推假上将军，追杀宋襄，再请楚王追认。所谓阴令是项羽公布的理由，不等于已另得密令证据。任命与夺帅分年。

<a id="p012"></a>
### P012｜巨鹿与诸侯归服

> 項羽乃悉引兵渡河，皆沈船，破釜甑，燒廬舍，持三日糧，以示士卒必死，無一還心。

> 九戰，絕其甬道，大破之，殺蘇角，虜王離。涉閒不降楚，自燒殺。

范围：当阳君、蒲将军先以二万人试战，陈馀请援；项羽全军渡河；诸侯十余壁观望，战后膝行入辕门，项羽为诸侯上将军。一当十、九战等不能当作现代伤亡统计。

<a id="p013"></a>
### P013｜司马欣、陈馀说降与再战

> 今戰能勝，高必疾妒吾功；戰不能勝，不免於死。願將軍孰計之。

> 約未成，項羽使蒲將軍日夜引兵度三戶，軍漳南，與秦戰，再破之。項羽悉引兵擊秦軍汙水上，大破之。

范围：棘原、漳南相持；司马欣咸阳三日不见、避追归营；陈馀用白起蒙恬结局劝降，始成接洽；议和未定仍打击。书信中的旧事及封王前景为说降话语，不单靠它们改写相关人物已经整理的结局。

<a id="p014"></a>
### P014｜殷虚降约与秦军安排

> 項羽召軍吏謀曰：「糧少，欲聽其約。」軍吏皆曰：「善。」項羽乃與期洹水南殷虛上。

> 項羽乃立章邯為雍王，置楚軍中。使長史欣為上將軍，將秦軍為前行。

楚亦粮少，章邯流泪诉赵高。降约许王与后来分封地盘连接，不生出两个雍国。

<a id="p015"></a>
### P015｜新安杀降

> 秦吏卒多竊言曰：「章將軍等詐吾屬降諸侯，今能入關破秦，大善；即不能，諸侯虜吾屬而東，秦必盡誅吾父母妻子。」

> 於是楚軍夜擊阬秦卒二十餘萬人新安城南。

范围：诸侯吏卒因昔日受辱而反过来奴役降卒，降卒恐惧不满；项羽与黥布、蒲将军决定杀之，仅带章邯、司马欣、董翳入关。杀戮程序不据“坑”自行全译活埋。

## 入关与分封

<a id="p016"></a>
### P016｜函谷关、曹无伤与范增

> 沛公左司馬曹無傷使人言於項羽曰：「沛公欲王關中，使子嬰為相，珍寶盡有之。」

> 當是時，項羽兵四十萬，在新豐鴻門，沛公兵十萬，在霸上。

范围：项羽怒、命当阳君等破关；范增以刘邦不取财色、望气天子相劝急击。曹无伤的指控不是子婴已实际任相的证明。

<a id="p017"></a>
### P017｜项伯夜访与刘邦解释

> 張良曰：「秦時與臣游，項伯殺人，臣活之。今事有急，故幸來告良。」

> 沛公奉巵酒為壽，約為婚姻。

范围：项伯想救张良离开，张良先报告刘邦；刘邦承认兵力不如，邀项伯见、解释守关和封库；项伯令次日谢罪，再劝项羽以刘邦破秦功劳善待。旧恩补叙不归鸿门当年，婚约不等于已完婚。

<a id="p018"></a>
### P018｜鸿门宴

> 范增數目項王，舉所佩玉珪以示之者三，項王默然不應。

> 項莊拔劍起舞，項伯亦拔劍起舞，常以身翼蔽沛公，莊不得擊。

范围：百余骑来见，项羽说出告密人、宴席方位；项庄舞剑、项伯遮护；张良找樊哙、持盾闯帐、饮酒食彘肩、反对杀有功者；刘邦借如厕出帐。此见证作玉珪，与通行玉玦不同，照见证选引不悄改。

<a id="p019"></a>
### P019｜脱身、献礼与诛告密者

> 項王使都尉陳平召沛公。

> 亞父受玉斗，置之地，拔劍撞而破之。

> 沛公至軍，立誅殺曹無傷。

范围：樊哙以刀俎鱼肉劝勿拘礼，刘邦弃车骑、从骊山芷阳间道回军，张良估其抵达再献璧和玉斗。陈平仍在楚，不提前算汉方谋士。

<a id="p020"></a>
### P020｜咸阳焚掠与东归

> 項羽引兵西屠咸陽，殺秦降王子嬰，燒秦宮室，火三月不滅；收其貨寶婦女而東。

> 富貴不歸故鄉，如衣繡夜行，誰知之者！

范围：劝都关中未听，说者讥沐猴而冠被烹。所烧秦宫不径改为阿房宫，三月为文本记数。

<a id="p021"></a>
### P021｜如约、义帝与十八王

> 項王使人致命懷王。懷王曰：「如約。」乃尊懷王為義帝。

> 項王自立為西楚霸王，王九郡，都彭城。

范围：以将相亲战有功为由重分天下；汉刘邦、雍章邯、塞司马欣、翟董翳、西魏魏豹、河南申阳、韩成、殷司马卬、代赵歇、常山张耳、九江黥布、衡山吴芮、临江共敖、辽东韩广、燕臧荼、胶东田市、齐田都、济北田安，共十八王，项羽另计。具体辖地、都城、原因完整列入前206年表；未记都城的不凭猜测填入。

田荣不封，陈馀环封三县，梅鋗十万户侯，不混入十八王。巴蜀属于关中是当时规避原约的说法，不作现代地理断言；司马欣援项梁、董翳劝降等前事不全归本年。

<a id="p022"></a>
### P022｜就国、迁杀义帝与韩燕变局

> 漢之元年四月，諸侯罷戲下，各就國。

> 乃使使徙義帝長沙郴縣。

范围：催义帝迁行、群臣渐离、密令衡山临江王杀于江中；韩成不准就国，到彭城废侯后杀；臧荼逼韩广迁辽东、不从而杀于无终。义帝最终遇害另按二年十月归档，非全段共用四月。

<a id="p023"></a>
### P023｜田荣并三齐、陈馀复赵

> 榮因自立為齊王，而西殺擊濟北王田安，并王三齊。

> 陳餘迎故趙王歇於代，反之趙。趙王因立陳餘為代王。

范围：逐田都、拒徙田市，市仍往胶东，荣追杀即墨，再杀田安，给彭越将军印；陈馀遣张同夏说求齐兵，与三县兵合击张耳。齐事前206、复赵前205，不因同段而硬合。

<a id="p024"></a>
### P024｜汉东返与项羽击齐

> 漢王失職，欲得關中，如約即止，不敢東。

> 徵兵九江王布。布稱疾不往，使將將數千人行。項王由此怨布也。

范围：汉回三秦，项羽立郑昌拒汉，彭越败萧公角；张良书转移楚注意，九江不亲来；汉二年项羽北击田荣，荣败死平原，楚焚杀掳掠，田横聚众反抗。全段跨汉元、二年。

## 彭城至鸿沟

<a id="p025"></a>
### P025｜彭城败战与刘邦家属

> 春，漢王部五諸侯兵，凡五十六萬人，東伐楚。

> 項王聞之，即令諸將擊齊，而自以精兵三萬人南從魯出胡陵。

> 漢王急，推墮孝惠、魯元車下，滕公常下收載之。如是者三。

范围：四月联军占彭城置酒，项羽自萧晨击至午大败汉；谷泗、睢水两段十余万人损失、风沙脱围；刘邦寻家不遇、滕公救二子，太公吕后与审食其为楚所获。兵数、伤亡、风沙均依叙事归属，孝惠等后称不使孩子提前即位。

<a id="p026"></a>
### P026｜下邑、荥阳收军与京索

> 至滎陽，諸敗軍皆會，蕭何亦發關中老弱未傅悉詣滎陽，復大振。

范围：刘邦投下邑吕后兄周吕侯，逐步收卒；楚追至京索被汉击败，不能越荥阳西进。“未傅”的具体年龄制度不擅改成全员儿童。

<a id="p027"></a>
### P027｜田广、诸侯倒向与粮道

> 漢軍滎陽，築甬道屬之河，以取敖倉粟。漢之三年，項王數侵奪漢甬道，漢王食乏，恐，請和，割滎陽以西為漢。

范围：田横立田广，彭城败后诸侯背汉；粮路形成与三年被夺分年，田广立王不能只据排列认定在彭城败后。

<a id="p028"></a>
### P028｜反间与范增离去

> 吾以為亞父使者，乃反項王使者。

> 行未至彭城，疽發背而死。

范围：项羽欲许和、范增急攻；陈平设盛宴又换恶食，挑动楚使猜疑，项羽夺范增权；范增请求离开。病死不简单写成气死。

<a id="p029"></a>
### P029｜纪信替王与出荥阳

> 紀信乘黃屋車，傅左纛，曰：「城中食盡，漢王降。」

> 漢王亦與數十騎從城西門出，走成皋。

范围：两千披甲女子夜出东门，引楚围观；纪信假降后被烧杀。女子的最终结局未列，不虚构。

<a id="p030"></a>
### P030｜荥阳守将与陷城

> 周苛、樅公謀曰：「反國之王，難與守城。」乃共殺魏豹。

> 項王怒，烹周苛，井殺樅公。

范围：汉王留守军，守将先杀魏豹；城破，周苛拒绝上将军、三万户之诱，被杀。见证“井杀”与《通鉴》并杀不同，不据此另造刑名。

<a id="p031"></a>
### P031｜宛叶、黥布、成皋失守与北渡

> 漢之四年，項王進兵圍成皋。漢王逃，獨與滕公出成皋北門，渡河走修武，從張耳、韓信軍。

范围：汉王南走宛叶收军、与黥布相接，再返成皋；楚被汉阻巩。此段“四年”与《高祖本纪》《淮阴侯列传》《通鉴》三年六月不合，正文归前204年，原句保留。

<a id="p032"></a>
### P032｜彭越、刘贾与两地拉锯

> 使劉賈將兵佐彭越，燒楚積聚。

范围：彭越杀薛公、项羽东援，汉王得韩信军，听郑忠暂不渡战，刘贾助袭粮；汉复成皋、据敖仓、广武相持。前段前204、复城前203，避免重复造城池易手。

<a id="p033"></a>
### P033｜太公受胁与项伯劝止

> 吾翁即若翁，必欲烹而翁，則幸分我一桮羹。

范围：楚粮路受断，项羽置太公于高俎威胁；刘邦用兄弟盟约应答，项伯说杀之无益、徒增祸，项羽作罢。威胁不等于已经杀害。

<a id="p034"></a>
### P034｜挑战、楼烦与伏弩

> 吾寧鬬智，不能鬬力。

> 漢王不聽，項王伏弩射中漢王。漢王傷，走入成皋。

范围：百姓疲于军旅漕运，项羽邀独战、刘邦不许；楼烦射杀挑战者，遇项羽叱喝退避；两王临广武、刘邦数罪、项羽射伤。详列罪状属于政治控诉，不单以控诉证明其每个细节。

<a id="p035"></a>
### P035｜龙且、齐王、武涉与回叙曹咎

> 項王聞龍且軍破，則恐，使盱台人武涉往說淮陰侯。淮陰侯弗聽。

> 謹守成皋，則漢欲挑戰，慎勿與戰，毋令得東而已。

范围：韩信灌婴败龙且，韩信王齐，武涉说韩信；再回写彭越袭梁粮路、项羽命曹咎守城而东征。前半前203、后半前204；“因自立”与别传请王授印程序分层，“淮阴侯”是后称。

<a id="p036"></a>
### P036｜外黄少年止杀

> 大王至，又皆阬之，百姓豈有歸心？

> 項王然其言，乃赦外黃當阬者。

范围：外黄守数日乃降，项羽欲杀十五岁以上男子；县令舍人十三岁儿子以彭越强迫及他城恐惧劝止；项羽赦之，往睢阳沿途争降。少年姓名未记。

<a id="p037"></a>
### P037｜曹咎渡汜水败亡，项羽返援

> 士卒半渡，漢擊之，大破楚軍，盡得楚國貨賂。

> 大司馬咎、長史翳、塞王欣皆自剄汜水上。

范围：汉挑衅辱骂五六日，曹咎违令出战；曹咎司马欣昔日援项梁的回叙；项羽在睢阳闻败归，汉围钟离眛闻援而退。“长史翳”的身份和经历不以猜测补齐。

<a id="p038"></a>
### P038｜鸿沟之约与侯公

> 割鴻溝以西者為漢，鴻溝而東者為楚。

范围：汉粮多、楚粮竭，陆贾请太公未成、侯公续谈；家属归、军欢呼，侯公受平国君号但不获常见，项羽东归。两次出使和谈判结果分别保留。

<a id="p039"></a>
### P039｜追击、固陵与会垓下

> 楚破，自陳以東傅海與齊王，睢陽以北至穀城與彭相國。

范围：张良陈平劝汉乘疲追击；汉五年追至阳夏、固陵，韩信彭越不到，汉败；许地后两军响应，韩信南下、刘贾由寿春、周殷反楚带九江兵会垓下。决定追击与次年实行分年，许地不等于当日完成交割。

## 败亡、善后与论赞

<a id="p040"></a>
### P040｜四面楚歌与虞、骓

> 夜聞漢軍四面皆楚歌，項王乃大驚曰：「漢皆已得楚乎？是何楚人之多也！」

> 歌數闋，美人和之。項王泣數行下，左右皆泣，莫能仰視。

范围：项羽军壁垓下、兵少食尽，汉及诸侯重围；帐中饮酒，虞与骓相随，项羽作力拔山之歌。本纪未写虞自刎，亦未列和歌全文，不从后人戏剧补造。

<a id="p041"></a>
### P041｜突围、东城快战与自述

> 此天之亡我，非戰之罪也。

范围：八百余骑突围，灌婴五千骑追；过淮百余，阴陵问路陷泽，东城二十八；分四队斩将、叱退追者、再聚，自称三胜。八年七十余战是项羽自述，不能取消书中已经记过的败仗。

<a id="p042"></a>
### P042｜乌江拒渡、自刎与五人分功

> 且籍與江東子弟八千人渡江而西，今無一人還，縱江東父兄憐而王我，我何面目見之？

> 吾聞漢購我頭千金，邑萬戶，吾為若德。

范围：亭长备船，项羽拒绝、赠骓，下马短兵战、受创；见吕马童而自刎；王翳得首，杨喜、吕马童、吕胜、杨武得其部分遗体，合验分功。后叙封侯的实际年月见T1，不都归本年。

<a id="p043"></a>
### P043｜鲁降与谷城葬礼

> 乃持項王頭視魯，魯父兄乃降。

> 故以魯公禮葬項王穀城。漢王為發哀，泣之而去。

范围：楚地多降，鲁仍守，刘邦原拟屠之，因其守节改示首。鲁公是先前名号，此时用于葬礼，不重复授爵。

<a id="p044"></a>
### P044｜项氏枝属

> 諸項氏枝屬，漢王皆不誅。乃封項伯為射陽侯。桃侯、平皋侯、玄武侯皆項氏，賜姓劉氏。

赦免、归附、赐姓和初封不全同年。射阳、平皋、桃核T1，玄武尚未获得可靠姓名、初封年对应，不造确年事件。

<a id="p045"></a>
### P045｜太史公论

> 乃引「天亡我，非用兵之罪也」，豈不謬哉！

范围：以重瞳、是否舜裔的传聞发问；肯定由无地而灭秦、统诸侯、主持分封的崛起；批背关怀楚、逐义帝、恃力征、矜功不反省。重瞳与舜裔非已证实谱系；论中身死东城与乌江叙事措辞差别保留。

<a id="p046"></a>
### P046｜索隐述赞

> 卿子無罪，亞父推誠。

> 戰非無功，天實不與。

范围：颂起兵救赵、责杀子婴背约、迁故主和分封不平、恃战。《索隐述赞》属于司马贞的后出注释层，不与司马迁末论当成同一作者的相反判断。

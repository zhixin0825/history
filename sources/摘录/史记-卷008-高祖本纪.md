## 起兵以前与沛公时期

<a id="p001"></a>
### P001｜出身、相貌与亭长生活

> 高祖，沛豐邑中陽里人，姓劉氏，字季。父曰太公，母曰劉媼。

> 及壯，試為吏，為泗水亭長。

范围：刘媪梦神、太公见蛟龙的出生传说；相貌、左股黑子及宽宏形象；不治家业，好酒色，向王媪、武负赊酒，两家年终折券免债。龙现、酒销量随之增加属于传说叙事，不据此造出生确年或商业统计。

<a id="p002"></a>
### P002｜咸阳观秦皇帝

> 高祖常繇咸陽，縱觀，觀秦皇帝，喟然太息曰：「嗟乎，大丈夫當如此也！」

没有明确年、月、帝王行程，不与项羽前210年观会稽巡行混为同一场合。

<a id="p003"></a>
### P003｜吕公嫁女

> 乃紿為謁曰「賀錢萬」，實不持一錢。

范围：吕公避仇来沛，与沛令交好；萧何主持贺客座次；刘邦虚报贺钱、坐上座，吕公看相留客、许女，吕媪不满；婚后子女用孝惠、鲁元的后称。婚姻在起兵前，子女后来的身份不提前当作此时已有爵号。

<a id="p004"></a>
### P004｜田间老父看相

> 及高祖貴，遂不知老父處。

范围：吕后耕作时施食给老人，老人称母子大贵，刘邦追问又获贵相预言。此为早年传奇，预言不作为可独立验证的政治事实。

<a id="p005"></a>
### P005｜刘氏冠

> 高祖為亭長，乃以竹皮為冠，令求盜之薛治之，時時冠之，及貴常冠，所謂「劉氏冠」乃是也。

亭长时期制冠与后来仍戴是跨期习惯，不造一次未定年的全国冠服改革。

<a id="p006"></a>
### P006｜送徒、纵徒与斩蛇

> 公等皆去，吾亦從此逝矣！

范围：送刑徒去骊山，途中逃亡渐多，刘邦在丰西泽中放人，十余壮士相随；醉后斩蛇，后人遇老妇解释赤帝子、白帝子的神异故事。释徒与神异解释分层，所据网页老妇句存在疑难用字，不借疑句考定神祇身份。

<a id="p007"></a>
### P007｜芒砀藏身与云气

> 沛中子弟或聞之，多欲附者矣。

范围：始皇所谓东南天子气、刘邦亡匿芒砀、吕后借云气寻人，传闻吸引追随者。不能以传说倒推一场已定年的始皇专门搜捕刘邦行动。

<a id="p008"></a>
### P008｜沛令欲应陈涉

> 乃令樊噲召劉季。劉季之眾已數十百人矣。

范围：陈胜起兵称王，各郡县杀长吏；沛令想响应，萧何曹参建议招集亡人。合入前209年已有起兵事件。

<a id="p009"></a>
### P009｜父老迎立、祭祀与招兵

> 祠黃帝，祭蚩尤於沛庭，而釁鼓旗，幟皆赤。

范围：沛令反悔闭城，萧曹逃出，帛书射城，父老杀令迎刘邦，数让后立沛公；祠祭、衅鼓旗与赤帜，收子弟二三千人、攻胡陵方与还丰。颜色的神话解释不等于祭祀行动本身未发生。

<a id="p010"></a>
### P010｜丰邑反复与向景驹、项梁求援

> 雍齒雅不欲屬沛公，及魏招之，即反為魏守豐。

范围：围丰的监平被击退，郡守壮败薛、死戚；周市招雍齿，刘邦攻丰失败、患病返沛；投东阳甯君和景驹，萧西败、三日取砀、下下邑，增至五六千，再向项梁求兵。开头回述周章、各国立王和项氏起吴，不能全挪二世二年；守壮“泗州／泗川”异称不强定现代地名。

<a id="p011"></a>
### P011｜楚王重立、合战与项梁败亡

> 秦益章邯兵，夜銜枚擊項梁，大破之定陶，項梁死。

范围：会薛、楚怀王孙心、盱台、武信君；亢父东阿、城阳屠城、濮阳与环水、定陶不下、雍丘杀李由、外黄不下；宋义谏、项梁死、楚军分驻、秦北围赵。与卷007相同事件合并。

<a id="p012"></a>
### P012｜楚王收军与两路分工

> 與諸將約，先入定關中者王之。

范围：怀王迁彭城、收吕臣项羽军，刘邦砀郡长武安侯、项羽长安侯鲁公、吕氏父子任职；宋义项羽范增北救赵，刘邦西行，楚老将以宽大与残暴比较二人。迁都任命的年次与其他篇章有跨年差别，保留原有前208年主线，不再制造第二次任命。

<a id="p013"></a>
### P013｜昌邑、陈留与颍阳

> 沛公引兵西，遇彭越昌邑，因與俱攻秦軍，戰不利。

范围：夺刚武侯约四千兵、合魏将攻昌邑未下；郦食其以失礼劝刘邦起身谢，谋取陈留粮，广野君、郦商领军；开封未下、白马曲遇败杨熊，秦诛杨熊；南攻颍阳屠之，借张良略韩地轘辕。不能只保留“宽大”，漏掉刘邦军的屠城。

<a id="p014"></a>
### P014｜截河津、宛城谈降与继续西进

> 莫若約降，封其守，因使止守，引其甲卒與之西。

范围：截司马卬入关路线，洛阳东败，犨东胜南阳守齮；回围宛，陈恢说降、守封殷侯、恢千户；丹水、西陵、胡阳，遇梅鋗、降析郦，遣甯昌使秦未返；章邯已在赵降项羽。高武侯鳃、襄侯王陵句的地名和断句不凭此重建全部履历。

<a id="p015"></a>
### P015｜说秦将与武关、蓝田

> 諸所過毋得掠鹵，秦人喜，秦軍解，因大破之。

范围：先回顾项羽杀宋义、破王离、降章邯；赵高想分关中，刘邦疑诈，让郦食其、陆贾说秦将，用利诱与疑兵进攻武关、蓝田。攻武关和二世死亡的叙次与别篇不同，不硬定唯一逐日过程。

## 汉王时期

<a id="p016"></a>
### P016｜受降、封库与约法

> 吾所以還軍霸上，待諸侯至而定約束耳。

范围：汉元年十月子婴降，拒绝杀降，樊哙张良劝退宫室，约法三章，派人与秦吏告谕县乡，拒受牛羊酒食。受降十月、约法十一月依《通鉴》拆开，原段不等于全部同月。

<a id="p017"></a>
### P017｜守关与鸿门

> 項羽兵四十萬，號百萬。沛公兵十萬，號二十萬，力不敵。

范围：劝守关、征关中兵；十一月破关、十二月至戏；曹无伤告密求封，项伯救张良，鸿门谢罪、樊哙张良助脱，诛曹无伤。兵数与号称分开，不当作独立核验数。

<a id="p018"></a>
### P018｜焚秦与尊义帝

> 乃詳尊懷王為義帝，實不用其命。

范围：项羽焚掠、秦人失望而不敢不服；怀王要求如约，项羽以项氏拥立及将相功劳拒绝听命。合入原事件，不再发生一次秦亡。

<a id="p019"></a>
### P019｜分封

> 正月，項羽自立為西楚霸王，王梁、楚地九郡，都彭城。

范围：刘邦汉王、三秦、河南殷常山代、九江临江衡山、燕辽东，韩广被杀及陈馀三县、梅鋗侯。分封月与卷007、《汉书》《通鉴》二月不合；不据简名单删掉原十八王表，韩广终局为后叙。

<a id="p020"></a>
### P020｜进入汉中与利用思归

> 軍吏士卒皆山東之人也，日夜跂而望歸，及其鋒而用之，可以有大功。

范围：四月就国，项羽给三万兵，其他自愿相随者数万；经杜南蚀中、烧栈道，南郑逃兵多，韩信劝趁思归东进。政治上的被迁与临时军心分开说明。

<a id="p021"></a>
### P021｜义帝、三齐与复赵的跨年概述

> 陳餘怨項羽之弗王己也，令夏說說田榮，請兵擊張耳。

范围：义帝迁杀、田荣反楚、彭越败萧公角、陈馀逐张耳、赵歇复赵、项羽北击齐。所据本纪写田荣“杀田都”，卷007及《通鉴》是田都败逃楚，正文沿已采用的后说；不把田都写死又复活。

<a id="p022"></a>
### P022｜八月还定三秦与迎家属

> 八月，漢王用韓信之計，從故道還，襲雍王章邯。

范围：陈仓好畤败雍军、围废丘、略陇西北地上郡，薛欧王吸由武关迎家属、在阳夏受阻，郑昌拒汉。迎家属依据汉书置九月，不全部继承八月。

<a id="p023"></a>
### P023｜二年开国措施

> 諸故秦苑囿園池，皆令人得田之。

> 二月，令除秦社稷，更立漢社稷。

范围：受塞翟河南降、击郑昌立韩王信、设郡、奖万人或一郡归附者、修河上塞；正月俘章平及大赦，出陕抚父老厚待张耳，二月更社稷。塞翟投降在其他年表为汉元年后段，不重复改旗。

<a id="p024"></a>
### P024｜董公劝举义帝之丧

> 天下共立義帝，北面事之。

范围：三月临晋渡河，魏豹从，下河内、俘殷王置郡；平阴津到洛阳，董公劝，发丧三日、告诸侯讨楚。名分是刘邦号召战争的理由，不是现代编者裁决正邪。

<a id="p025"></a>
### P025｜彭城败战与盟友离散

> 當是時，諸侯見楚彊漢敗，還皆去漢復為楚。塞王欣亡入楚。

范围：田荣败死、齐民再反、田广立；汉趁楚陷齐入彭城，楚回军重创汉，家属为质。这里“父母妻子”与刘母早卒等叙述不宜机械拼合；正文按确有后续的太公、吕后等称谓。

<a id="p026"></a>
### P026｜收兵与随何使九江

> 公能令布舉兵叛楚，項羽必留擊之。

范围：下邑吕泽、西过梁至虞，派随何争取黥布；布背楚，楚遣龙且进攻。出使、起事、失利归汉分阶段，不能全继承彭城月份。

<a id="p027"></a>
### P027｜立太子、废丘与祭祀

> 六月，立為太子，大赦罪人。令太子守櫟陽，諸侯子在關中者皆集櫟陽為衛。

范围：与家人失散后得刘盈；灌废丘、章邯自杀、改槐里；祭天地、四方上帝山川，发关内卒守塞。此时太子不是皇帝。

<a id="p028"></a>
### P028｜黥布归汉与京索

> 是以兵大振滎陽，破楚京、索閒。

范围：黥布不胜龙且而间行归汉，刘邦收卒、关中增兵，京索拒楚。文本汇叙不能迫使本来不同时的归附和京索之战同月发生。

<a id="p029"></a>
### P029｜魏、赵与张耳王号

> 其明年，立張耳為趙王。

范围：本纪三年开头追魏豹归叛、劝降未成、韩信俘豹置三郡，再写井陉陈馀赵歇、次年张耳为赵王。魏豹被俘仍归前205，攻赵前204，张耳立王前203，不依段首把所有事情搬到三年。

<a id="p030"></a>
### P030｜荥阳反间与范增离去

> 予陳平金四萬斤，以閒疏楚君臣。

范围：荥阳粮道、久持、断粮围城、求和、反间、范增疑而辞去病死；四万斤是文本所报，不据此换算现代预算。

<a id="p031"></a>
### P031｜纪信与留守者

> 諸將卒不能從者，盡在城中。

范围：女子出东门、纪信代王、刘邦西逃，周苛魏豹枞公留下，周枞以魏豹反复为由杀之。纪信与魏豹不是同一种死亡经过。

<a id="p032"></a>
### P032｜宛叶牵制与重回成皋

> 如此，則楚所備者多，力分，漢得休。

范围：袁生建议由武关南出分楚兵，刘邦与黥布收军；彭越战项声薛公，项羽东去、刘邦回成皋，项羽再返，荥阳破、周枞死、韩王信俘。袁／辕为互见姓名写法。

<a id="p033"></a>
### P033｜夺张耳韩信军与白马津袭粮

> 自稱使者，晨馳入張耳、韓信壁，而奪之軍。

范围：出成皋玉门、修武夺军、令张耳收赵兵韩信攻齐；郑忠劝深沟，卢绾刘贾二万步卒数百骑过白马津，助彭越复梁城。此为三年事件，和卷007“四年”冲突另注。

<a id="p034"></a>
### P034｜齐国与龙且

> 齊王烹酈生，東走高密。

范围：郦食其说齐、韩信用蒯通策袭齐，楚派龙且周兰，韩信灌婴败楚、龙且死；“齐王广奔彭越”与田广被俘、田横奔彭越不合，不机械接受。战事跨三四年，沿既有前204—203年页。

<a id="p035"></a>
### P035｜曹咎失守

> 大司馬咎、長史欣皆自剄汜水上。

范围：项羽东攻陈留外黄睢阳，曹咎不听固守之戒，中渡遭击；楚财物为汉所得，项羽返援钟离眛，汉退险处。曹咎受命前一年、败亡次年，不能照段首一律四年。

<a id="p036"></a>
### P036｜齐王韩信与武涉

> 乃遣張良操印綬立韓信為齊王。

范围：请求假王、刘邦不满、张良劝因立之；项羽使武涉游说，韩信不听。淮阴侯是本纪对韩信的后称，不提前改封。

<a id="p037"></a>
### P037｜广武十罪与负伤

> 漢王傷匈，乃捫足曰：「虜中吾指！」

十罪范围：背关中之约、假命杀宋义、擅统诸侯入关、烧掠秦宫与掘陵指控、杀子婴、新安杀降、迁故王、逐义帝夺地、暗杀义帝、为政不平背约。它们是战争控诉，不是十项都已独立核验；继写伏弩伤、张良劝劳军、退成皋。

<a id="p038"></a>
### P038｜伤愈回栎阳

> 梟故塞王欣頭櫟陽市。留四日，復如軍，軍廣武。

范围：存问父老、置酒、示司马欣首级、返前线与关中增兵。这是死后示众，不让司马欣在本年又死一次。

<a id="p039"></a>
### P039｜鸿沟至固陵、垓下会军

> 乃與漢王約，中分天下。

范围：彭越断粮、田横从、齐王进楚；鸿沟和议归家属，张良陈平劝追；固陵不获援而败，许地后韩彭到、刘贾围寿春、周殷起九江兵、黥布淮南王。后半汉五年，不能全置四年。碧陵等疑文保留固定见证，不另造第二次固陵之败。

<a id="p040"></a>
### P040｜垓下部署与战后夺军

> 淮陰先合，不利，卻。孔將軍、費將軍縱，楚兵不利，淮陰侯復乘之，大敗垓下。

> 還至定陶，馳入齊王壁，奪其軍。

范围：韩信居前、孔费两翼、刘邦及其他将领在后；楚歌、骑兵追项羽东城、所报八万斩首、鲁降和鲁公礼葬。称皇帝为作者后称，且不把摘要“追杀东城”改成另一场已确证的项羽死亡。

<a id="p041"></a>
### P041｜请尊号与即帝位

> 甲午，乃即皇帝位汜水之陽。

本段从正月请尊号直接接甲午即位；《汉书》《通鉴》明确二月甲午。请尊与即位分阶段，不说三书都明确写正月或二月。

<a id="p042"></a>
### P042｜战后王国安排

> 齊王韓信習楚風俗，徙為楚王，都下邳。

范围：彭越梁王定陶、韩王信阳翟、吴芮长沙临湘，淮南黥布、燕臧荼、赵敖；梅鋗助入武关的前事；赵敖承位与前五年张耳死分阶段，不整段当作同日任命。

<a id="p043"></a>
### P043｜临江最后抵抗

> 令盧綰、劉賈圍之，不下。數月而降，殺之雒陽。

本纪称临江王驩，《通鉴》称共尉；作同一末代临江王的异名处理，不与先王共敖混成一人。

<a id="p044"></a>
### P044｜罢兵与复免

> 五月，兵皆罷歸家。諸侯子在關中者復之十二歲，其歸者復之六歲，食之一歲。

“诸侯子”所指及后续受免对象有解释空间，不扩大成全国人人免税十二年。

<a id="p045"></a>
### P045｜南宫宴论取天下

> 此三者，皆人傑也，吾能用之，此吾所以取天下也。

范围：高起王陵论分利赏功，刘邦论张良谋略、萧何粮政、韩信统军，对比项羽不用范增。原文也说刘邦慢侮、项羽仁爱，显示谈话评价与其他段落并非单一脸谱；作为胜者的解释，不单靠自述确定唯一胜因。

<a id="p046"></a>
### P046｜由洛阳进入关中

> 高祖是日駕，入都關中。六月，大赦天下。

范围：本想长都洛阳，刘敬说、张良赞成，遂西行。迁都决策、长乐宫成、百官迁治、未央宫成是不同阶段。

<a id="p047"></a>
### P047｜臧荼、卢绾与利几

> 即立太尉盧綰為燕王。

范围：本纪此处“十月”写臧荼反、攻代、被俘、卢绾继王，随后秋利几反；《汉书》《通鉴》臧荼七月反、九月俘，依后者归前202。利几为降汉的项氏旧将，因被召登记而害怕，起兵后逃走，不补已经捕杀。

## 称帝以后

<a id="p048"></a>
### P048｜尊太公为太上皇

> 高祖五日一朝太公，如家人父子禮。

范围：家令提出君臣与父子礼冲突，太公执帚迎门退行，刘邦扶父、尊太上皇、赏家令。家内礼到皇室制度的调整；具体五月依《通鉴》补。

<a id="p049"></a>
### P049｜云梦之会捕韩信与田肯说形势

> 乃偽遊雲夢，會諸侯於陳，楚王信迎，即因執之。

范围：有人告反、陈平用巡游诱见、十二月拘捕赦天下；田肯比较关中与齐形势，主张齐应属亲子弟，获五百斤金。告发不等于现代已证实韩信当时确有叛乱；百二、十二不简单译成精确战力。

<a id="p050"></a>
### P050｜韩信降侯与封王论功

> 後十餘日，封韓信為淮陰侯，分其地為二國。

范围：刘贾荆王、刘交楚王、刘肥齐王、论功剖符封侯，韩王信迁太原；民能齐言皆属齐是概括，不是准确语言人口地图。涉及两位韩信，必须区分。

<a id="p051"></a>
### P051｜韩王信、赵利与平城

> 匈奴圍我平城，七日而後罷去。

范围：马邑韩王信与匈奴相结、曼丘臣王黄立赵利、皇帝亲征、寒冻伤卒、围城七日、樊哙留定代、刘仲代王。马邑降在六年九月，平城在七年，分到前201、200年。

<a id="p052"></a>
### P052｜返长安与朝廷迁治

> 二月，高祖自平城過趙、雒陽，至長安。長樂宮成，丞相已下徙治長安。

《通鉴》七年冬十月已记长乐宫朝仪；二月是返都及迁治叙事，不无依据再造第二座宫竣工。

<a id="p053"></a>
### P053｜八年东垣、未央营建、柏人与刘仲

> 非壯麗無以重威，且無令後世有以加也。

范围：东击韩王信余部，萧何建未央宫阙前殿武库太仓，刘邦责奢、萧何解释皇威；柏人貫高等谋刺未成；刘仲弃代归洛阳、废合阳侯。建宫与宫成分年，柏人之“心动”非证实预知危险。

<a id="p054"></a>
### P054｜赵国案与迁徙大族

> 廢趙王敖為宣平侯。

范围：貫高等案发、赵敖被废、楚昭屈景怀和齐田氏迁关中。貫高案应与《张耳陈馀列传》详审过程合读，不把赵敖也说成经证实参与行刺。

<a id="p055"></a>
### P055｜未央宫成与父子宴话

> 今某之業所就孰與仲多？

范围：新宫大朝会，刘邦向太上皇敬酒，拿父亲昔日说他不如二兄善治产业的话开玩笑，群臣大笑。这不是政权产业价值的实际估价。

<a id="p056"></a>
### P056｜十年朝会、太公去世与新丰

> 更命酈邑曰新豐。

范围：十月列诸王来朝、春夏无事，太上皇死于栎阳、楚梁送葬、赦栎阳囚。列来朝者中“长沙王吴芮”与吴芮已死抵牾，正文只写长沙王。太公死月本纪七月、汉书通鉴五月死七月葬，分层取舍。

<a id="p057"></a>
### P057｜陈豨反与亲征

> 代地吏民非有罪也。其赦代吏民。

范围：本纪八月反、九月征，通鉴九月正式举兵；刘邦到邯郸评其未据南境，借将领多商人出身，以金招降。不能用此叙述推论所有商人必见利忘义。

<a id="p058"></a>
### P058｜十一年北方战事与刘恒封代

> 於是乃分趙山北，立子恒以為代王，都晉陽。

范围：侯敞、王黄、张春等活动，郭蒙与齐将、周勃分路作战；马邑被破，东垣守军辱骂，陷城后追杀骂者，赦其他人。陈豨部队败与陈豨本人死亡不是同年同事。

<a id="p059"></a>
### P059｜韩信、彭越被处死与宗室封王

> 春，淮陰侯韓信謀反關中，夷三族。

> 夏，梁王彭越謀反，廢遷蜀；復欲反，遂夷三族。

范围：两案及刘恢梁王、刘友淮阳王。以上是本纪的罪名概括；彭越列传另写吕后促成再告案，不能把“复欲反”无条件写成流放后另一次已实际发兵的反叛。月次与分封依年表及《通鉴》细分。

<a id="p060"></a>
### P060｜黥布反、刘贾覆亡与新淮南王

> 秋七月，淮南王黥布反。

范围：并荆地、刘交退薛、刘邦亲征、刘长淮南王。刘贾之死、本年起兵与次年追杀黥布分开；刘长立王不用段落紧接强定七月。

<a id="p061"></a>
### P061｜十二年败布、归沛与封吴

> 大風起兮雲飛揚，威加海內兮歸故鄉，安得猛士兮守四方！

范围：十月会甀败布遣追、沛宫宴父老、教一百二十歌儿、击筑歌舞；沛为汤沐邑世世复免，留十余日，再留三日；丰因雍齿旧怨未免，父老请后同免；刘濞吴王。诗为古代公有领域原作；歌曲所诉怀乡与守四方之忧不等于作者已给出确切心理测量。

<a id="p062"></a>
### P062｜黥布与陈豨的终局

> 追得斬布鄱陽。

> 樊噲別將兵定代，斬陳豨當城。

范围：洮水南北诸战；陈豨死的将领归功与《通鉴》周勃不同，正文按汉军行动写，不给两将各造一次斩同一人的战功。

<a id="p063"></a>
### P063｜守冢、赦免与燕国危机

> 秦皇帝二十家，魏公子無忌五家。

范围：十一月返长安；十二月为秦始皇、陈涉、魏安釐王、齐湣王、赵悼襄王及魏无忌配置守冢户，赦被陈豨赵利胁迫吏民；降将告卢绾通谋、辟阳侯迎而不至，二月樊哙周勃击燕、赦燕吏民、刘建燕王。后来的军事结果不全部塞在十二月。

<a id="p064"></a>
### P064｜病中拒医与吕后问后事

> 命乃在天，雖扁鵲何益！

范围：击布时中流矢，病重拒医，赐医金罢遣；吕后问萧何死后用谁，刘邦说曹参、王陵陈平、周勃。这里是对未来的意见，不等于几位大臣已在本年依次拜相；预言色彩须留意。

<a id="p065"></a>
### P065｜卢绾在塞下等待

> 幸上病愈自入謝。

等待和后来出匈奴分开；本句是传世文本对其意图的说明，不是已获得个人书信证实。

<a id="p066"></a>
### P066｜四月死亡、秘丧与杀将之议

> 四月甲辰，高祖崩長樂宮。四日不發喪。

范围：吕后审食其担心少主不能制功臣，议诛将；郦将军警告内外反乱，审食其转劝，丁未公布、大赦。计划未实行，不能写成吕后已经在此杀尽诸将；诸军人数为劝阻时所举。

<a id="p067"></a>
### P067｜卢绾出走

> 盧綰聞高祖崩，遂亡入匈奴。

<a id="p068"></a>
### P068｜安葬与惠帝继位

> 上尊號為高皇帝。太子襲號為皇帝，孝惠帝也。

范围：丙寅葬、己巳立太子、太上皇庙议太祖功、郡国立庙。具体五月依《通鉴》；高皇帝、太祖与习称高祖分辨，不把各名号等同于同一制度。

<a id="p069"></a>
### P069｜惠帝五年沛宫原庙

> 以沛宮為高祖原廟。

范围：纪念高祖归沛之悲乐，将旧歌儿一百二十人组织为乐人、缺额补足。地点为沛，与长安渭北原庙不可见同名便合成同一建筑。

<a id="p070"></a>
### P070｜八子的世系及后叙

> 次代王恒，已立為孝文帝，薄太后子。

范围：刘肥、刘盈、刘如意、刘恒、刘恢、刘友、刘长、刘建；刘恢由梁徙赵、刘友由淮阳徙赵、刘恒后来称帝。后续有可核年的分别回前194、181、180年；其余母系、排序与后谥作世系背景，不因一个谥号就额外编造死亡事件。

<a id="p071"></a>
### P071｜太史公论

> 故漢興，承敝易變，使人不倦，得天統矣。

范围：夏忠、殷敬、周文及各自流弊的循环解释，批秦不改而酷刑，肯定汉变革；十月朝贺、黄屋左纛、葬长陵。此为史家解释与制度概括，不倒填为刘邦本年新颁的三代通则。

<a id="p072"></a>
### P072｜索隐述赞

> 威加四海，還歌大風。

范围：起于徒中、泗上沛公、豪杰、云龙星蛇、巴蜀失约、三秦东进、氾水帝位与宫室、归唱大风。司马贞注赞与司马迁原论分层，歌颂及神异不另作确年事件。

<a id="s001"></a>
## S001｜太史公为什么不用黄帝以来的确年表

序文明确区分殷以前难谱、周以来稍可写、孔子《春秋》年月较详与《尚书》多缺年月几个层次。核心取舍是“故疑則傳疑”，又说黄帝以来的不同历谱、牒记和五德终始记载“乖異”。因此作从黄帝到共和的“世表”，**不是宣布黄帝至共和每一年都已考定**。

[固定版序文及原表](../%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7013.md#ref-7b1efe2dcbdd51) · [上古年代考证](../../meta/考证/史记-卷013-纪年与异说.md#年代与表格)。

<a id="t001"></a>
## T001｜五帝、夏、殷、周各支的共同远祖

以下为原表“顓頊屬、俈屬、堯屬、舜屬、夏屬、殷屬、周屬”七栏的**按支系转写**，以箭头表示表文的祖孙／生子连接，不表示统治交接，也不是现代已证实的血缘树：

| 支系 | 表文的先后连接 | 读到哪里 |
|---|---|---|
| 颛顼 | 黄帝—昌意—颛顼（高阳） | [黄帝与两支后人](../../years/上古/01-黄帝至帝喾.md#sj013-five-branches) |
| 帝喾 | 黄帝—玄嚣—蟜极—高辛（帝喾） | 同上 |
| 尧 | 帝喾（高辛）—放勋（尧） | [尧舜时期](../../years/上古/02-尧舜至禹.md) |
| 舜 | 黄帝—昌意—颛顼—穷蝉—敬康—句望—蟜牛（桥牛）—瞽叟—重华（舜） | [舜的登场前事](../../years/上古/02-尧舜至禹.md#shun-early) |
| 夏 | 黄帝—昌意—颛顼—鲧—文命（禹），**中间可能有缺代** | [禹与夏](../../years/上古/02-尧舜至禹.md#yu-works) |
| 殷 | 高辛—契（禼），后接T003商先公 | [契的登场](../../years/上古/02-尧舜至禹.md#xie) |
| 周 | 高辛—后稷（弃），后接T004周先公 | [后稷的登场](../../years/上古/02-尧舜至禹.md#houji) |

**不能把帝喾和颛顼写成父子**：两支分别由玄嚣、昌意分出。三家注指出《汉书·律历志》所记鲧与颛顼相隔数代，与简写“颛顼生鲧”不同。[三家注对应表列](../%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7013.md#ref-0146ab228f82e9)。

<a id="t002"></a>
## T002｜夏王位顺序：全部十七个名号

禹—启—太康—中康—相—少康—予（杼）—槐—芒—泄—不降—扃—廑—孔甲—皋—发—履癸（桀）。

原表明确“仲康，太康弟”“扃，不降弟”“孔甲，不降子”；这就表明十七个王位**不能等同于十七次父传子**。表末给出“從禹至桀十七世，從黃帝至桀二十世”，只记录其传世计数，不换算每世寿命。

[夏王序和相应故事](../../years/上古/03-夏代.md#succession) · [固定版夏表原栏](../%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7013.md#ref-9811ad140ff23b)。

<a id="t003"></a>
## T003｜商先公：契至成汤的完整链条

黄帝—玄嚣—蟜极—高辛—契—昭明—相土—昌若—曹圉—冥—振—微—报丁—报乙—报丙—主壬—主癸—天乙（汤）。

这一栏穿插在夏王名号旁边，是为了并读**不同族系的传承**，并非说“商的曹圉在夏太康同年即位”。原表另称“從黃帝至湯十七世”；对振、王亥及若干古名字的辨读仍须与出土文字逐项互核。

<a id="t004"></a>
## T004｜周先公：后稷到武王的完整链条

黄帝—玄嚣—蟜极—高辛—后稷—不窋—鞠—公刘—庆节—皇仆—差弗—毁隃—公非—高圉—亚圉—公叔祖类—古公亶父—季历—文王昌—武王发。

表文称“從黃帝至武王十九世”，不是武王已登位的第十九个公元年份。前段后稷、不窋、公刘在[夏代时期页](../../years/上古/03-夏代.md#zhou-ancestors)，古公与季历及西伯、武王在[商末与周初](../../years/上古/06-商末与周初.md#zhou-family)。原表对各支系的同一行排版不能解释成严格的同时代清单。

<a id="t005"></a>
## T005｜商朝自成汤至帝辛的王位顺序

本卷“殷”段给出的顺序，**连同汤共列出三十个姓名／王号**；“太丁（成汤的太子）先卒”作为继承背景，不另列为一位已即位的王：

| 顺序段 | 王名，依表文排列 |
|---|---|
| 汤以后前十位 | 外丙、仲壬、太甲、沃丁、太庚、小甲、雍己、太戊、中丁、外壬 |
| 续十位 | 河亶甲、祖乙、祖辛、沃甲、祖丁、南庚、阳甲、盘庚、小辛、小乙 |
| 最后九位 | 武丁、祖庚、帝甲（祖甲）、廪辛、庚丁、武乙、太丁、帝乙、帝辛（纣） |

连成整个王序须在最前面加上成汤，王名数量才是三十；表末的“從湯至紂二十九世”属于原文计数法，不强行解释为“二十九位在位者”。这里跨越[商前期](../../years/上古/04-商代前期.md)、[盘庚和武丁](../../years/上古/05-盘庚与武丁.md)、[商末](../../years/上古/06-商末与周初.md)。

本卷“小甲，太庚弟”，《殷本纪》则以太庚之子叙小甲；此外《三家注》指出魏公／微公、沃甲／开甲等异写。[差异解释](../../meta/考证/史记-卷013-纪年与异说.md#异文与世数)。

<a id="t006"></a>
## T006｜西周前段：周王与十一国诸侯支系

原表把成、康、昭、穆、恭、懿、孝、夷、厉及共和放在首栏，将鲁、齐、晋、秦、楚、宋、卫、陈、蔡、曹、燕并排。为了避免在窄屏上横向读错，以下**依国家转置原表各格自上而下的顺序**；空格不等于该国无人，也不标为同时即位。详细原格仍见[原始表格“周”段](../%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7013.md#ref-bcd6276f7e37ec)。

| 王室／国别 | 本表可见的王侯及先世（原列顺序） |
|---|---|
| 周王室 | 成王诵—康王钊—昭王瑕—穆王满—恭王伊扈—懿王坚—孝王方—夷王燮—厉王胡—共和（不是一位国王） |
| 鲁 | 周公旦—伯禽—考公—炀公—幽公—魏公—厉公—献公—真公—武公 |
| 齐 | 太公尚—丁公吕伋—乙公—癸公—哀公—胡公—献公—武公 |
| 晋 | 唐叔虞—晋侯燮—武侯—成侯—厉侯—靖侯 |
| 秦 | 恶来—女防—旁皋—大几—大骆—非子—秦侯—公伯—秦仲 |
| 楚 | 熊绎—熊乂—熊黮—熊胜—熊炀—熊渠—熊无康—熊挚红—熊延—熊勇 |
| 宋 | 微子启—微仲—宋公—丁公—湣公—炀公—厉公—釐公 |
| 卫 | 康叔—康伯—孝伯—嗣伯—疌伯—靖伯—贞伯—顷侯—釐侯 |
| 陈 | 胡公满—申公—相公—孝公—慎公—幽公—釐公 |
| 蔡 | 蔡叔度—蔡仲—蔡伯—宫侯—厉侯—武侯 |
| 曹 | 曹叔振铎—太伯—仲君—宫伯—孝伯—夷伯 |
| 燕 | 召公奭；表文只概括“九世至惠侯”，没有逐格列出其中九代姓名 |

《三代世表》将鲁周公、齐太公、晋唐叔、秦恶来同列于周初横行，**并不表示恶来在成王朝受封为秦诸侯**（恶来助纣，秦邑是西周孝王授予非子）；“成王”行的早期封国事件也不是同一天发生。共王与共和、周召二公及共伯和异说，见[西周时期页](../../years/上古/07-西周的治理与危机.md#sj013-kingdoms)和[前841年](../../years/bce-0900-0801/bce-0841.md)。

<a id="p001"></a>
## P001｜张夫子问褚先生：契、后稷有父还是感生

此处在表后以“張夫子問褚先生”另起：问题是《诗》中玄鸟生契、巨人足迹生后稷，与史传中父系出自帝喾为何不同。褚先生试图调和，说文本一边写天命、一边保留父系，“信以傳信，疑以傳疑”，又叙简狄含卵、姜嫄履迹和弃子得救的故事。

这些说法是**褚少孙一层的解释**，不是司马迁把古代现场出生记录列入了家谱；与已写的[契](../../years/上古/02-尧舜至禹.md#xie)、[后稷](../../years/上古/02-尧舜至禹.md#houji)两段同一故事互见，不另造可确年的两次出生。[原文最后问答](../%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7013.md#ref-3d941d675bd5b6)。

<a id="p002"></a>
## P002｜褚先生进一步谈蜀王、霍光和天命

后文以蜀王、霍氏先世为例，推衍黄帝后世与王侯福泽。里面明确说到汉廷霍子孟（霍光）及幼主辅政，这已经属于**司马迁所处时代以后**的材料；本项目将此层与表序区别，不为了替神异说安排时间而编造蜀王入朝或霍光受命的本卷独立事件。

霍国、晋灭霍、平阳迁居等被用来解释“霍”字与谱系的可能联系，不能据同字便确证霍光从黄帝到汉的全部生物学血缘链。褚先生引用的方士谶言也保留为他当时的话语，不用作预测历史事实的可靠独立证据。

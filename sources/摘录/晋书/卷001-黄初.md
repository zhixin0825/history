# 《晋书》卷001：黄初段原文摘录

[史料总目录](../../README.md) · [引文去向与归年说明](../../../meta/记录/晋书-卷001-黄初段引文去向.md)

本文件只保存实际引用的原文，不构成另一套编年正文。对应《晋书》卷一《帝纪第一·宣帝》，从“黄初二年”至“迁骠骑将军”。原文中的“帝”指司马懿，“天子”主要指曹丕；不得因此把司马懿写成本时在位的皇帝。

**核对来源：** [维基文库《晋书》卷001·黄初](../../%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%99%89%E6%9B%B8-%E5%8D%B7001.md#ref-58af03b356ae35)。以下保留该转录本繁体字与标点；正文另作白话叙述。本次未逐页校勘中华书局扫描本，不把网络转录冒称点校本原页。仓库完整TXT仍保留在[二十四史原文目录](../../二十四史/txt/05_jinshu_full.txt)。古籍原文属公有领域，现代校刊附记未混入以下引文。

<a id="hc01"></a>
## HC01｜黄初二年迁官

> 黃初二年，督軍官罷，遷侍中、尚書右僕射。

<a id="hc02"></a>
## HC02｜黄初五年留镇许昌

> 五年，天子南巡，觀兵吳疆。帝留鎮許昌，改封向鄉侯，轉撫軍、假節，領兵五千，加給事中、錄尚書事。帝固辭。天子曰：「吾於庶事，以夜繼晝，無須臾寧息。此非以為榮，乃分憂耳。」

<a id="hc03"></a>
## HC03｜黄初六年留守及南征还朝

> 六年，天子復大興舟師征吳，復命帝居守，內鎮百姓，外供軍資。臨行，詔曰：「吾深以後事為念，故以委卿。曹參雖有戰功，而蕭何為重。使吾無西顧之憂，不亦可乎！」天子自廣陵還洛陽，詔帝曰：「吾東，撫軍當總西事；吾西，撫軍當總東事。」於是帝留鎮許昌。

归年提醒：此段有跨年收束。《资治通鉴》卷070把曹丕回洛阳明确列在黄初七年正月；不能将全段都压入225年。

<a id="hc04"></a>
## HC04｜受顾命与明帝即位

> 及天子疾篤，帝與曹真、陳羣等見於崇華殿之南堂，並受顧命輔政。詔太子曰：「有間此三公者，慎勿疑之。」明帝即位，改封舞陽侯。

<a id="hc05"></a>
## HC05｜吴军攻江夏、襄阳及迁官

> 及孫權圍江夏，遣其將諸葛瑾、張霸并攻襄陽，帝督諸軍討權，走之。進擊，敗瑾，斬霸，并首級千餘。遷驃騎將軍。

归年提醒：以《资治通鉴》卷070黄初七年分开江夏守城、襄阳交战、十二月迁官，不把相邻两处战场的战功全部并到一人身上。

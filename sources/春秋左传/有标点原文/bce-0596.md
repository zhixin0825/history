## 传

<a id="all-20261109-t001"></a>

十三年春，齐师伐莒，莒恃晋而不事齐故也。

<a id="all-20261109-t002"></a>

夏，楚子伐宋，以其救萧也。君子曰：“清丘之盟，唯宋可以免焉。”

<a id="all-20261109-t003"></a>

秋，赤狄伐晋，及清，先縠召之也。

<a id="all-20261109-t004"></a>

冬，晋人讨邲之败，与清之师，归罪于先縠而杀之，尽灭其族。君子曰：“恶之来也，己则取之，其先縠之谓乎。”

<a id="all-20261109-t005"></a>

清丘之盟，晋以卫之救陈也讨焉。使人弗去，曰：“罪无所归，将加而师。”孔达曰：“苟利社稷，请以我说。罪我之由。我则为政而亢大国之讨，将以谁任？我则死之。”

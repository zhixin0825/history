## 经

<a id="all-20261109-j001"></a>

十年春，公如齐。公至自齐。齐人归我济西田。

<a id="all-20261109-j002"></a>

夏四月丙辰，日有食之。

<a id="all-20261109-j003"></a>

己巳，齐侯元卒。

<a id="all-20261109-j004"></a>

齐崔氏出奔卫。

<a id="all-20261109-j005"></a>

公如齐。

<a id="all-20261109-j006"></a>

五月，公至自齐。

<a id="all-20261109-j007"></a>

癸巳，陈夏徵舒弑其君平国。

<a id="all-20261109-j008"></a>

六月，宋师伐滕。

<a id="all-20261109-j009"></a>

公孙归父如齐，葬齐惠公。

<a id="all-20261109-j010"></a>

晋人、宋人、卫人、曹人伐郑。

<a id="all-20261109-j011"></a>

秋，天王使王季子来聘。

<a id="all-20261109-j012"></a>

公孙归父帅师伐邾，取绎。大水。季孙行父如齐。

<a id="all-20261109-j013"></a>

冬，公孙归父如齐。齐侯使国佐来聘。

<a id="all-20261109-j014"></a>

饥。楚子伐郑。

## 传

<a id="all-20261109-t001"></a>

十年春，公如齐。齐侯以我服故，归济西之田。

<a id="all-20261109-t002"></a>

夏，齐惠公卒。崔杼有宠于惠公，高、国畏其偪也，公卒而逐之，奔卫。书曰“崔氏”，非其罪也，且告以族，不以名。凡诸侯之大夫违，告于诸侯曰：“某氏之守臣某，失守宗庙，敢告。”所有玉帛之使者则告，不然，则否。

<a id="all-20261109-t003"></a>

公如齐奔丧。

<a id="all-20261109-t004"></a>

陈灵公与孔宁、仪行父饮酒于夏氏。公谓行父曰：“徵舒似女。”对曰：“亦似君。”徵舒病之。公出，自其厩射而杀之。二子奔楚。

<a id="all-20261109-t005"></a>

滕人恃晋而不事宋，六月，宋师伐滕。

<a id="all-20261109-t006"></a>

郑及楚平。诸侯之师伐郑，取成而还。

<a id="all-20261109-t007"></a>

秋，刘康公来报聘。

<a id="all-20261109-t008"></a>

师伐邾，取绎。

<a id="all-20261109-t009"></a>

季文子初聘于齐。

<a id="all-20261109-t010"></a>

冬，子家如齐，伐邾故也。

<a id="all-20261109-t011"></a>

国武子来报聘。

<a id="all-20261109-t012"></a>

楚子伐郑。晋士会救郑，逐楚师于颍北。诸侯之师戍郑。郑子家卒。郑人讨幽公之乱，斫子家之棺而逐其族。改葬幽公，谥之曰灵。

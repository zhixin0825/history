## 经

<a id="j001"></a>

八年春，公至自会。

<a id="j002"></a>

夏六月，公子遂如齐，至黄乃复。

<a id="j003"></a>

辛巳，有事于大庙，仲遂卒于垂。

<a id="j004"></a>

壬午，犹绎。《万》入去籥。

<a id="j005"></a>

戊子，夫人嬴氏薨。

<a id="j006"></a>

晋师、白狄伐秦。

<a id="j007"></a>

楚人灭舒、蓼。

<a id="j008"></a>

秋七月甲子，日有食之，既。

<a id="j009"></a>

冬十月己丑，葬我小君敬嬴。

<a id="j010"></a>

雨，不克葬。庚寅，日中而克葬。

<a id="j011"></a>

城平阳。

<a id="j012"></a>

楚师伐陈。

## 传

<a id="t001"></a>

八年春，白狄及晋平。

<a id="t002"></a>

夏，会晋伐秦。晋人获秦谍，杀诸绛市，六日而苏。

<a id="t003"></a>

有事于大庙，襄仲卒而绎，非礼也。

<a id="t004"></a>

楚为众舒叛故，伐舒、蓼，灭之。楚子疆之，及滑汭。盟吴、越而还。

<a id="t005"></a>

晋胥克有蛊疾，郤缺为政。

<a id="t006"></a>

秋，废胥克。使赵朔佐下军。

<a id="t007"></a>

冬，葬敬嬴。旱，无麻，始用葛茀。雨，不克葬，礼也。礼，卜葬先远日，辟不怀也。

<a id="t008"></a>

城平阳，书时也。

<a id="t009"></a>

陈及晋平。楚师伐陈，取成而还。

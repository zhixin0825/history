## 经

<a id="batch-20261109-j001"></a>

二十年春，新作南门。

<a id="batch-20261109-j002"></a>

夏，郜子来朝。

<a id="batch-20261109-j003"></a>

五月乙巳，西宫灾。

<a id="batch-20261109-j004"></a>

郑人入滑。

<a id="batch-20261109-j005"></a>

秋，齐人、狄人盟于邢。

<a id="batch-20261109-j006"></a>

冬，楚人伐随。

## 传

<a id="batch-20261109-t001"></a>

二十年春，新作南门，书不时也。凡启塞从时。

<a id="batch-20261109-t002"></a>

滑人叛郑而服于卫。

<a id="batch-20261109-t003"></a>

夏，郑公子士、洩堵寇帅师入滑。

<a id="batch-20261109-t004"></a>

秋，齐、狄盟于邢，为邢谋卫难也。于是卫方病邢。随以汉东诸侯叛楚。

<a id="batch-20261109-t005"></a>

冬，楚鬥穀於菟帅师伐随，取成而还。君子曰：“随之见伐，不量力也。量力而动，其过鲜矣。善败由己，而由人乎哉？《诗》曰：‘岂不夙夜，谓行多露。’”

<a id="batch-20261109-t006"></a>

宋襄公欲合诸侯，臧文仲闻之，曰：“以欲从人则可，以人从欲鲜济。”

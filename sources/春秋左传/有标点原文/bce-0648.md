## 传

<a id="t001"></a>

<a id="batch-20261109-t001"></a>

十二年春，诸侯城卫楚丘之郛，惧狄难也。

<a id="t002"></a>

<a id="batch-20261109-t002"></a>

黄人恃诸侯之睦于齐也，不共楚职，曰：“自郢及我九百里，焉能害我？”夏，楚灭黄。

<a id="t003"></a>

<a id="batch-20261109-t003"></a>

王以戎难故，讨王子带。

<a id="t004"></a>

<a id="batch-20261109-t004"></a>

秋，王子带奔齐。冬，齐侯使管夷吾平戎于王，使隰朋平戎于晋。

<a id="t005"></a>

<a id="batch-20261109-t005"></a>

王以上卿之礼飨管仲，管仲辞曰：“臣，贱有司也，有天子之二守国、高在。若节春秋来承王命，何以礼焉？陪臣敢辞。”王曰：“舅氏，余嘉乃勋，应乃懿德，谓督不忘。往践乃职，无逆朕命。”管仲受下卿之礼而还。君子曰：“管氏之世祀也宜哉！让不忘其上。《诗》曰：‘恺悌君子，神所劳矣。’”

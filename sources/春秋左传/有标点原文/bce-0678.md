## 经

<a id="batch-20261109-j001"></a>

十有六年春，王正月。

<a id="batch-20261109-j002"></a>

夏，宋人、齐人、卫人伐郑。

<a id="batch-20261109-j003"></a>

秋，荆伐郑。

<a id="batch-20261109-j004"></a>

冬十有二月，会齐侯、宋公、陈侯、卫侯、郑伯、许男、滑伯、滕子同盟于幽。

<a id="batch-20261109-j005"></a>

邾子克卒。

## 传

<a id="batch-20261109-t001"></a>

十六年夏，诸侯伐郑，宋故也。郑伯自栎入，缓告于楚。

<a id="batch-20261109-t002"></a>

秋，楚伐郑，及栎，为不礼故也。

<a id="batch-20261109-t003"></a>

郑伯治与于雍纠之乱者。九月，杀公子阏，刖强鉏。公父定叔出奔卫。三年而复之，曰：“不可使共叔无后于郑。”使以十月入，曰：“良月也，就盈数焉。”君子谓：“强鉏不能卫其足。”

<a id="batch-20261109-t004"></a>

冬，同盟于幽，郑成也。

<a id="batch-20261109-t005"></a>

王使虢公命曲沃伯以一军为晋侯。初，晋武公伐夷，执夷诡诸。蒍国请而免之。既而弗报。故子国作乱，谓晋人曰：“与我伐夷而取其地。”遂以晋师伐夷，杀夷诡诸。周公忌父出奔虢。惠王立而复之。

## 经

<a id="j001"></a>

九年春，齐人杀无知。公及齐大夫盟于蔇。

<a id="j002"></a>

夏，公伐齐，纳子纠。齐小白入于齐。

<a id="j003"></a>

秋七月丁酉，葬齐襄公。

<a id="j004"></a>

八月庚申，及齐师战于乾时，我师败绩。

<a id="j005"></a>

九月，齐人取子纠，杀之。

<a id="j006"></a>

冬，浚洙。

## 传

<a id="t001"></a>

九年春，雍廪杀无知。公及齐大夫盟于蔇，齐无君也。

<a id="t002"></a>

夏，公伐齐，纳子纠。桓公自莒先入。

<a id="t003"></a>

秋，师及齐师战于乾时，我师败绩。公丧戎路，传乘而归。秦子、梁子以公旗辟于下道，是以皆止。

<a id="t004"></a>

鲍叔帅师来言曰：“子纠，亲也，请君讨之。管、召，仇也，请受而甘心焉。”乃杀子纠于生窦，召忽死之。管仲请囚，鲍叔受之，及堂阜而税之。归而以告曰：“管夷吾治于高傒，使相可也。”公从之。

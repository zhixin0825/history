## 经

<a id="all-20261109-j001"></a>

八年春正月己卯，烝。天王使家父来聘。

<a id="all-20261109-j002"></a>

夏五月丁丑，烝。

<a id="all-20261109-j003"></a>

秋，伐邾。

<a id="all-20261109-j004"></a>

冬十月，雨雪。祭公来，遂逆王后于纪。

## 传

<a id="all-20261109-t001"></a>

八年春，灭翼。随少师有宠。楚鬥伯比曰：“可矣。仇有衅，不可失也。”

<a id="all-20261109-t002"></a>

夏，楚子合诸侯于沈鹿。黄、随不会。使薳章让黄。楚子伐随，军于汉、淮之间。

<a id="all-20261109-t003"></a>

季梁请下之，弗许而后战，所以怒我而怠寇也。少师谓随侯曰：“必速战。不然，将失楚师。”随侯御之，望楚师。季梁曰：“楚人上左，君必左，无与王遇。且攻其右，右无良焉，必败。偏败，众乃携矣。”少师曰：“不当王，非敌也。”弗从。战于速杞，随师败绩。随侯逸，鬥丹获其戎车，与其戎右少师。

<a id="all-20261109-t004"></a>

秋，随及楚平。楚子将不许，鬥伯比曰：“天去其疾矣，随未可克也。”乃盟而还。

<a id="all-20261109-t005"></a>

冬，王命虢仲立晋哀侯之弟缗于晋。祭公来，遂逆王后于纪，礼也。

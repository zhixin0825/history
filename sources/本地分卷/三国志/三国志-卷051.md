## 孫靜傳

<a id="txt-l5"></a>

<a id="l2440"></a>

<a id="edition-wu051-l5-1"></a>

孫靜字幼臺，堅季弟也。堅始舉事，靜糾合鄉曲及宗室五六百人以爲保障，衆咸附焉。

[孫靜集眾自保及家系](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l5-1)

<a id="edition-wu051-l5-2"></a>

策破劉繇，定諸縣，

[195 年第 13 條](../../../years/ce-0101-0200/ce-0195.md#wu051-l5-2)

<a id="edition-wu051-l5-3"></a>

進攻會稽，遣人請靜，靜將家屬與策會于錢唐。是時太守王朗拒策於固陵，策數渡水戰，不能克。

[196 年第 10 條](../../../years/ce-0101-0200/ce-0196.md#wu051-l5-3)

<a id="edition-wu051-l5-4"></a>

靜說策曰：「朗負阻城守，難可卒拔。查瀆南去此數十里，而道之要徑也，宜從彼據其內，所謂攻其無備、出其不意者也。吾當自帥衆爲軍前隊，破之必矣。」

[196 年第 10 條](../../../years/ce-0101-0200/ce-0196.md#wu051-l5-4)

<a id="edition-wu051-l5-5"></a>

策曰：「善。」乃詐令軍中曰：「頃連雨水濁，兵飲之多腹痛，令促具甖缶數百口澄水。」至昏暮，羅以然火誑朗，便分軍夜投查瀆道，襲高遷屯。

[196 年第 10 條](../../../years/ce-0101-0200/ce-0196.md#wu051-l5-5)

## 孫瑜傳

<a id="txt-l13"></a>

<a id="l2442"></a>

<a id="edition-wu051-l13-1"></a>

瑜字仲異，以恭義校尉始領兵衆。是時賔客諸將多江西人，瑜虛心綏撫，得其歡心。

[孫瑜初領兵，安撫部將](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l13-1)

<a id="edition-wu051-l13-2"></a>

建安九年，領丹楊太守，爲衆所附，至萬餘人。加綏遠將軍。

[204 年第 11 條](../../../years/ce-0201-0300/ce-0204.md#wu051-l13-2)

<a id="edition-wu051-l13-3"></a>

十一年，與周瑜共討麻、保二屯，破之。

[206 年第 6 條](../../../years/ce-0201-0300/ce-0206.md#wu051-l13-3)

<a id="edition-wu051-l13-4"></a>

後從權拒曹公於濡須，權欲交戰，瑜說權持重，權不從，軍果無功。

<a id="edition-wu051-l13-5"></a>

[孫瑜遷屯牛渚，招納廬江降附者](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l13-5)

[孫瑜禮馬普，在軍府興學](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l13-6)

[215 年第 7 條](../../../years/ce-0201-0300/ce-0215.md#wu051-l13-7)

<a id="edition-wu051-l13-8"></a>

瑜五子：彌、熈、燿、曼、紘。曼至將軍，封侯。

[孫瑜的五子](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l13-8)

## 孫皎傳

<a id="txt-l17"></a>

<a id="l2444"></a>

<a id="l2445"></a>

<a id="l2446"></a>

<a id="l2447"></a>

<a id="edition-wu051-l17-1"></a>

皎字叔朗，始拜護軍校尉，領衆二千餘人。是時曹公數出濡須，皎每赴拒，號爲精銳。

[孫皎任護軍，拒曹於濡須並接掌夏口](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l17-1)

<a id="edition-wu051-l17-2"></a>

遷都護征虜將軍，代程普督夏口。黃蓋及兄瑜卒，又并其軍。賜沙羨、雲杜、南新市、竟陵爲奉邑，自置長吏。

[孫皎任護軍，拒曹於濡須並接掌夏口](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l17-2)

<a id="edition-wu051-l17-3"></a>

輕財能施，善於交結，與諸葛瑾至厚，委廬江劉靖以得失，江夏李允以衆事，廣陵吳碩、河南張梁以軍旅，而傾心親待，莫不自盡。

[孫皎任用僚屬，禁擾江淮百姓](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l17-3)

<a id="edition-wu051-l17-4"></a>

皎嘗遣兵候獲魏邊將吏美女以進皎，皎更其衣服送還之，下令曰：「今所誅者曹氏，其百姓何罪？自今以往，不得擊其老弱。」由是江淮間多歸附者。

[孫皎任用僚屬，禁擾江淮百姓](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l17-4)

<a id="edition-wu051-l17-5"></a>

嘗以小故與甘寧忿爭，或以諫寧，寧曰：「臣子一例，征虜雖公子，何可專行侮人邪！吾值明主，但當輸効力命，以報所天，誠不能隨俗屈曲矣。」權聞之，以書讓皎曰：「

[孫皎與甘寧失和，孫權致書勸解](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l17-5)

<a id="edition-wu051-l17-6"></a>

自吾與北方爲敵，中間十年，初時相遲年小，今者且三十矣。孔子言『三十而立』，非但謂五經也。授卿以精兵，委卿以大任，都護諸將於千里之外，欲使如楚任昭奚恤，揚威於北境，非徒相使逞私志而已。

[孫皎與甘寧失和，孫權致書勸解](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l17-6)

<a id="edition-wu051-l17-7"></a>

近聞卿與甘興霸飲，因酒發作，侵陵其人，其人求屬呂蒙督中。此人雖麤豪，有不如人意時，然其較略大丈夫也。吾親之者，非私之也。吾親愛之，卿踈憎之；卿所爲每與吾違，其可乆乎？

[孫皎與甘寧失和，孫權致書勸解](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l17-7)

<a id="edition-wu051-l17-8"></a>

夫居敬而行簡，可以臨民；愛人多容，可以得衆。二者尚不能知，安可董督在遠，禦寇濟難乎？卿行長大，特受重任，上有遠方瞻望之觀，下有部曲朝夕從事，何可恣意有盛怒邪？人誰無過，貴其能改，宜追前愆，深自咎責。今故煩諸葛子瑜重宣吾意。臨書摧愴，心悲淚下。」

[孫皎與甘寧失和，孫權致書勸解](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l17-8)

<a id="edition-wu051-l17-9"></a>

皎得書，上疏陳謝，遂與寧結厚。

[孫皎與甘寧失和，孫權致書勸解](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l17-9)

<a id="edition-wu051-l17-10"></a>

後呂蒙當襲南郡，權欲令皎與蒙爲左右部大督，蒙說權曰：「若至尊以征虜能，宜用之；以蒙能，宜用蒙。昔周瑜、程普爲左右部督，共攻江陵，雖事決於瑜，普自恃乆將，且俱是督，遂共不睦，幾敗國事，此目前之戒也。」

[219 年第 4 條](../../../years/ce-0201-0300/ce-0219.md#wu051-l17-10)

<a id="edition-wu051-l17-11"></a>

權寤，謝蒙曰：「以卿爲大督，命皎爲後繼。」禽關羽，定荊州，皎有力焉。

[219 年第 4 條](../../../years/ce-0201-0300/ce-0219.md#wu051-l17-11)

<a id="edition-wu051-l17-12"></a>

建安二十四年卒。

[219 年第 4 條](../../../years/ce-0201-0300/ce-0219.md#wu051-l17-12)

<a id="edition-wu051-l17-13"></a>

權追錄其功，封子胤爲丹楊侯。胤卒，無子。弟晞嗣，領兵，有罪自殺，國除。

[孫皎諸子封爵、襲爵與國除](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l17-13)

<a id="edition-wu051-l17-14"></a>

弟咨、彌、儀皆將軍，封侯。咨羽林督，儀無難督。

[孫皎諸子封爵、襲爵與國除](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l17-14)

<a id="edition-wu051-l17-15"></a>

咨爲滕胤所殺，

[孫皎諸子封爵、襲爵與國除](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l17-15)

## 孫奐傳

<a id="txt-l21"></a>

<a id="l2449"></a>

<a id="edition-wu051-l21-1"></a>

孫奐字季明。兄皎旣卒，代統其衆，以揚武中郎將領江夏太守。

[孫奐接掌江夏，沿用孫皎舊臣](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l21-1)

<a id="edition-wu051-l21-2"></a>

在事一年，遵皎舊迹，禮劉靖、李允、吳碩、張梁及江夏閭舉等，並納其善。奐訥於造次而敏於當官，軍民稱之。

[孫奐接掌江夏，沿用孫皎舊臣](../../../years/ce-0201-0300/时期-三国志卷051-宗室传纪年待考.md#wu051-l21-2)

<a id="edition-wu051-l21-3"></a>

黃武五年，權攻石陽，奐以地主，使所部將軍鮮于丹帥五千人先斷淮道，自帥吳碩、張梁五千人爲軍前鋒，降高城，得三將。

[226 年第 11 條](../../../years/ce-0201-0300/ce-0226.md#wu051-l21-3)

<a id="edition-wu051-l21-4"></a>

大軍引還，權詔使在前往，駕過其軍，見奐軍陣整齊，權歎曰：「初吾憂其遲鈍，今治軍，諸將少能及者，吾無憂矣。」拜揚威將軍，封沙羨侯。吳碩、張梁皆裨將軍，賜爵關內侯。

[226 年第 11 條](../../../years/ce-0201-0300/ce-0226.md#wu051-l21-4)

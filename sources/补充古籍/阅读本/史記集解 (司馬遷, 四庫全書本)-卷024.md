<a id="L425"></a>

(禆衣而冠冕也裨衣/衮之屬也搢插也)而虎賁之士稅劒也祀乎明堂(鄭/𤣥)¶

<a id="L429"></a>

<a id="L432"></a>

夫武之遲久不亦宜乎(鄭𤣥曰言武遲/久為重禮樂也)子貢見師乙而¶

<a id="L433"></a>

問焉(鄭𤣥曰師樂/官也乙名也)曰賜聞聲歌各有宜也(鄭𤣥曰/氣順性)如賜¶

<a id="L434"></a>

者宜何歌也師乙曰乙賤工也(鄭𤣥曰樂/人稱工也)何足以問所¶

<a id="L435"></a>

宜請誦其所聞而吾子自執焉(鄭𤣥曰執/猶處也)寛而靜柔而¶

<a id="L436"></a>

正者宜歌頌廣大而靜疏達而信者宜歌大雅恭儉而¶

<a id="L437"></a>

好禮者宜歌小雅正直清亷而謙者宜歌風肆直而慈¶

<a id="L438"></a>

愛者(鄭𤣥曰/肆正也)宜歌商温良而能斷者宜歌齊夫歌者直¶

<a id="L439"></a>

&lt;pb:KR2a0002_WYG_024-25a&gt;¶

<a id="L440"></a>

已而陳德(鄭𤣥曰各因/其德歌所宜)動已而天地應焉四時和焉星¶

<a id="L441"></a>

辰理焉萬物育焉(鄭𤣥曰/育生也)故商者五帝之遺聲也商人¶

<a id="L442"></a>

志之故謂之商齊者三代之遺聲也齊人志之故謂之¶

<a id="L443"></a>

齊明乎商之詩者臨事而屢斷(鄭𤣥曰以/其肆直)明乎齊之詩¶

<a id="L444"></a>

者見利而讓也(鄭𤣥曰以其温/良而能斷也)臨事而屢斷勇也見利¶

<a id="L445"></a>

而讓義也有勇有義非歌孰能保此故歌者上如抗下¶

<a id="L446"></a>

如隊曲如折止如槀木居中矩句中鉤累累乎殷如貫¶

<a id="L447"></a>

珠(鄭𤣥曰言歌聲之著動/人心之審而有此事)故歌之為言也長言之也(鄭/𤣥)¶

<a id="L448"></a>

&lt;pb:KR2a0002_WYG_024-25b&gt;¶

<a id="L449"></a>

(曰長言/引其聲)說之故言之言之不足故長言之長言之不足¶

<a id="L450"></a>

故嗟歎之嗟歎之不足故不知手之舞之足之蹈之(鄭/𤣥)¶

<a id="L451"></a>

(曰手舞足/蹈歡之至)子貢問樂凡音由於人心天之與人有以相¶

<a id="L452"></a>

通如景之象形響之應聲故為善者天報之以福為惡¶

<a id="L453"></a>

者天與之以殃其自然者也故舜彈五弦之琴歌南風¶

<a id="L454"></a>

之詩而天下治紂為朝歌北鄙之音身死國亡舜之道¶

<a id="L455"></a>

何𢎞也紂之道何隘也夫南風之詩者生長之音也舜¶

<a id="L456"></a>

樂好之樂與天地同意得萬國之驩心故天下治也夫¶

<a id="L457"></a>

&lt;pb:KR2a0002_WYG_024-26a&gt;¶

<a id="L458"></a>

朝歌者不時也北者敗也鄙者陋也紂樂好之與萬國¶

<a id="L459"></a>

殊心諸侯不附百姓不親天下畔之故身死國亡而衛靈¶

<a id="L460"></a>

公之時將之晉至於濮水之上舍夜半時聞鼓琴聲問¶

<a id="L461"></a>

左右皆對曰不聞乃召師涓曰吾聞鼓琴音問左右皆¶

<a id="L462"></a>

不聞其狀似鬼神為我聽而冩之師涓曰諾因端坐援¶

<a id="L463"></a>

琴聽而寫之明日曰臣得之矣然未習也請宿習之靈¶

<a id="L464"></a>

公曰可因復宿明日報曰習矣即去之晉見晉平公平¶

<a id="L465"></a>

公置酒於施惠之臺酒酣靈公曰今者來聞新聲請奏¶

<a id="L466"></a>

&lt;pb:KR2a0002_WYG_024-26b&gt;¶

<a id="L467"></a>

之平公曰可即令師涓坐師曠旁援琴鼓之未終師曠¶

<a id="L468"></a>

撫而止之曰此亡國之聲也不可聽平公曰何道出師¶

<a id="L469"></a>

曠曰師延所作也與紂為靡靡之樂武王伐紂師延東¶

<a id="L470"></a>

走自投濮水之中故聞此聲必於濮水之上先聞此聲¶

<a id="L471"></a>

者國削平公曰寡人所好者音也願遂聞之師涓鼓而¶

<a id="L472"></a>

終之平公曰音無此最悲乎師曠曰有平公曰可得聞¶

<a id="L473"></a>

乎師曠曰君德義薄不可以聽之平公曰寡人所好者¶

<a id="L474"></a>

音也願聞之師曠不得已援琴而鼓之一奏之有𤣥鶴¶

<a id="L475"></a>

<a id="L476"></a>

二八集乎廊門再奏之延頸而鳴舒翼而舞平公大喜¶

<a id="L477"></a>

起而為師曠夀反坐問曰音無此最悲乎師曠曰有昔¶

<a id="L478"></a>

者黃帝以大合鬼神今君德義薄不足以聽之聽之將¶

<a id="L479"></a>

敗平公曰寡人老矣所好者音也願遂聞之師曠不得¶

<a id="L480"></a>

已援琴而鼓之一奏之有白雲從西北起再奏之大風¶

<a id="L481"></a>

至而雨隨之飛廊瓦左右皆奔走平公恐懼伏於廊屋¶

<a id="L482"></a>

之間晉國大旱赤地三年聽者或吉或凶夫樂不可妄¶

<a id="L483"></a>

<a id="L485"></a>

太史公曰夫上古明王舉樂者非以娛心自樂快意恣¶

<a id="L486"></a>

欲將欲為治也正教者皆始於音音正而行正故音樂¶

<a id="L487"></a>

者所以動盪血脉通流精神而和正心也故宫動脾而¶

<a id="L488"></a>

和正聖商動肺而和正義角動肝而和正仁徵動心而¶

<a id="L489"></a>

和正禮羽動腎而和正智故樂所以内輔正心而外異¶

<a id="L490"></a>

貴賤也上以事宗廟下以變化黎庶也琴長八尺一寸¶

<a id="L491"></a>

正度也弦大者為宫而居中央君也商張右傍其餘大¶

<a id="L492"></a>

小相次不失其次序則君臣之位正矣故聞宫音使人¶

<a id="L493"></a>

&lt;pb:KR2a0002_WYG_024-28a&gt;¶

<a id="L494"></a>

温舒而廣大聞商音使人方正而好義聞角音使人惻¶

<a id="L495"></a>

隱而愛人聞徵音使人樂善而好施聞羽音使人整齊¶

<a id="L496"></a>

而好禮夫禮由外入樂自内出故君子不可須臾離禮¶

<a id="L497"></a>

須臾離禮則暴慢之行窮外不可須臾離樂須㬰離樂¶

<a id="L498"></a>

則姦邪之行窮内故樂音者君子之所養義也夫古者¶

<a id="L499"></a>

天子諸侯聽鐘磬未嘗離於庭卿大夫聽琴琴之音未¶

<a id="L500"></a>

嘗離於前所以養行義而防淫佚也夫淫佚生於無禮¶

<a id="L501"></a>

故聖人使人耳聞雅頌之音目視威儀之禮足行恭敬¶

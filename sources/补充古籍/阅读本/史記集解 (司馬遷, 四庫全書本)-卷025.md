陽氣之應不用事也其於十二子為亥亥者該也言陽¶

<a id="L63"></a>

<a id="L64"></a>

<a id="L65"></a>

陽氣冬則宛藏於虚日冬至則一隂下藏一陽上舒故¶

<a id="L66"></a>

<a id="L67"></a>

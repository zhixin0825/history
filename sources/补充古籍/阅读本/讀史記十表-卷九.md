<a id="L115"></a>

　　讀建元以來王子侯者年表¶

<a id="L116"></a>

　讀王子侯者表亦以天子為主時主父偃説上曰古¶

<a id="L117"></a>

　者諸侯不過百里强弱之形易制今或連城數十地¶

<a id="L118"></a>

　方千里緩則驕奢易為淫亂急則阻其疆而合從以¶

<a id="L119"></a>

　逆京師若以法制削之則逆節萌起今諸侯子弟或¶

<a id="L120"></a>

　十數而適嗣代立餘無尺寸地封願陛下令諸侯得¶

<a id="L121"></a>

　推恩分子弟以地侯之彼人人喜得所願上以徳施¶

<a id="L122"></a>

　實分其國不削而自弱矣上從之故太史公曰盛哉¶

<a id="L123"></a>

&lt;pb:KR2a0005_WYG_009-43b&gt;¶

<a id="L124"></a>

　天子之徳一人有慶天下賴之陳仁子云遷之言似¶

<a id="L125"></a>

　頌似諷¶

<a id="L126"></a>

　秦制有徹侯漢避武帝名諱徹為通有關内侯(無食/邑)¶

<a id="L127"></a>

　以賞功勞漢約非軍功不侯武帝始侯諸王子有食¶

<a id="L128"></a>

　邑但即其父所封國使支庶侯者分食之此所謂衆¶

<a id="L129"></a>

　建而少其力實賈誼遺䇿也¶

<a id="L130"></a>

　表國名今所受侯食邑也次表王子號從其父明宗¶

<a id="L131"></a>

　室親屬也次表姓名王朝年月侯者元年或不具年¶

<a id="L132"></a>

&lt;pb:KR2a0005_WYG_009-44a&gt;¶

<a id="L133"></a>

　月者闕文也¶

<a id="L134"></a>

　漢書侯所食邑多書其郡縣于下史記不書而索隱¶

<a id="L135"></a>

　具載之劉氏曰諸侯封名史漢表各有不同不敢輙¶

<a id="L136"></a>

　改但畧檢表志同異以備多識也¶

<a id="L137"></a>

黄履翁曰史記王子侯者表斷自建元葢是時始行分¶

<a id="L138"></a>

封之典遷意正自有在也固則起于高祖自謂聖祖建¶

<a id="L139"></a>

業以廣親親殊失王子侯表之本旨矣¶

<a id="L140"></a>

　按史記斷自建元以大封諸王支庶實始于主父偃¶

<a id="L141"></a>

&lt;pb:KR2a0005_WYG_009-44b&gt;¶

<a id="L142"></a>

　䇿也漢書起高祖訖孝平離為上下篇備一代王子¶

<a id="L143"></a>

　封典故也¶

<a id="L144"></a>

　河間獻王子十一人長沙定王子十五人楚安王子¶

<a id="L145"></a>

　二人魯共王子六人江都易王子七人菑川懿王子¶

<a id="L146"></a>

　十二人城陽共王子十三人趙敬肅王子十四人中¶

<a id="L147"></a>

　山靖王子十九人廣川惠王子四人濟北貞王子十¶

<a id="L148"></a>

　一人(漢書載濟北貞王子六/人濟北式王子五人)代共王子八人齊孝王¶

<a id="L149"></a>

　子十人衡山王賜子一人城陽頃王子十九人菑川¶

<a id="L150"></a>

&lt;pb:KR2a0005_WYG_009-45a&gt;¶

<a id="L151"></a>

　靖王子五人廣川穆王子二人膠東康王子三人有¶

<a id="L152"></a>

　同是一王之子而前後别見者葢異年封也¶

<a id="L153"></a>

　諸王子之後失侯者坐酎金凡五十五無後四此外¶

<a id="L154"></a>

　則不朝不敬一棄綬出國不敬一其甚者則簒死罪¶

<a id="L155"></a>

　一姦人妻一姦姊妹一殺人坐棄市一殺弟坐棄市¶

<a id="L156"></a>

　一有罪不明所坐十而謀叛者無聞焉豈非户邑分¶

<a id="L157"></a>

　而勢銷弱故歟然漢自是遂無大藩國至于哀平之¶

<a id="L158"></a>

　際王氏專政一嵗之中無罪而免者數十捽而去之¶

<a id="L159"></a>

&lt;pb:KR2a0005_WYG_009-45b&gt;¶

<a id="L160"></a>

　如揮羊豕其欲誅莽者武平侯璜陵鄉侯曽翟義所¶

<a id="L161"></a>

　立者嚴鄉侯信祗駢首就戮無一人應惡覩所謂百¶

<a id="L162"></a>

　足不僵者乎故觀王子侯表合漢興以來諸侯表究¶

<a id="L163"></a>

　其終始此西京二百三十年之大勢也¶

<a id="L164"></a>

洪邁曰漢列侯八百餘人至光武而存者平陽富平二¶

<a id="L165"></a>

侯耳(按稱八百餘則/是兼異姓也)¶

<a id="L166"></a>

&lt;pb:KR2a0005_WYG_009-46a&gt;¶

<a id="L167"></a>

　　讀建元以來王子侯者年表補¶

<a id="L168"></a>

　王子封侯在昔已然不自主父偃言始也偃之言在¶

<a id="L169"></a>

　元朔二年元光五六年間已封河間獻王子侯一人¶

<a id="L170"></a>

　長沙定王子四人楚安王子二人元朔元年侯魯共¶

<a id="L171"></a>

　王子一人江都易王子五人論者謂建元始行分封¶

<a id="L172"></a>

　之典何也葢前此之封恩自上逮或侯或不侯不盡¶

<a id="L173"></a>

　封也至是始令諸侯各得推私恩分子弟恩自下推¶

<a id="L174"></a>

　上特臨定之耳所以藩國悉分支庶畢侯不削而自¶

<a id="L175"></a>

&lt;pb:KR2a0005_WYG_009-46b&gt;¶

<a id="L176"></a>

　弱也¶

<a id="L177"></a>

　文帝采賈誼之言武帝用主父之䇿其事一也而實¶

<a id="L178"></a>

　不同文帝之心在分地以保全之不失親親之本故¶

<a id="L179"></a>

　淮南厲王廢死隨立其嗣武帝之心在分地以削弱¶

<a id="L180"></a>

　之假以推恩之名故封不數年以酎金小過除國者¶

<a id="L181"></a>

　凡五十六人汲黯所謂内多欲而外施仁義者即此¶

<a id="L182"></a>

　可見也惡得與文帝比哉¶

<a id="L183"></a>

　論者輙謂封建不行則三代之治不復非也自古有¶

<a id="L184"></a>

&lt;pb:KR2a0005_WYG_009-47a&gt;¶

<a id="L185"></a>

　治人無治法謂封建為聖王公天下之心則可謂天¶

<a id="L186"></a>

　下之治安繫于此則不然漢事不足論觀周之天下¶

<a id="L187"></a>

　可見矣列國分爭干戈不息無論天子僅守府生民¶

<a id="L188"></a>

　之塗炭其何以堪如謂秦以孤立速亡夫以秦之暴¶

<a id="L189"></a>

　即封建得無亡乎栁子厚謂秦之失在政不在制非¶

<a id="L190"></a>

　過論也天下之治亂安危繫于君徳封建何與焉¶

<a id="L191"></a>

　　存疑¶

<a id="L192"></a>

　元鼎元年四月戊寅封城陽頃王子十九人按漢表¶

<a id="L193"></a>

&lt;pb:KR2a0005_WYG_009-47b&gt;¶

<a id="L194"></a>

　二十人内有挍侯雲挾釐侯霸史表載挍侯霸名邑¶

<a id="L195"></a>

　參錯故失其一當從漢書為是漢表别載不得封年¶

<a id="L196"></a>

　十人史表無之又征和元年封四人二年封一人此¶

<a id="L197"></a>

　在史表後也¶

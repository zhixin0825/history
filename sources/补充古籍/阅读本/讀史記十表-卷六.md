　髙祖功臣年表第六¶

<a id="L12"></a>

　　(正義曰髙祖初定天下表明/有功之臣而侯之若蕭曹等)¶

<a id="L13"></a>

太史公曰古者人臣功有五品以德立宗廟定社稷曰勲以¶

<a id="L14"></a>

言曰勞用力曰功明其等曰伐積日曰閲封爵之誓曰使河¶

<a id="L15"></a>

如帶泰山如厲國以永寧爰及苗裔始未嘗不欲固其根本¶

<a id="L16"></a>

&lt;pb:KR2a0005_WYG_006-1b&gt;¶

<a id="L17"></a>

而枝葉稍陵夷衰㣲也余讀髙祖侯功臣察其首封所以失¶

<a id="L18"></a>

之者曰異哉所聞書曰協和萬國遷於夏商或數千歳蓋周¶

<a id="L19"></a>

封八百幽厲之後見於春秋尚書有唐虞之侯伯歴三代千¶

<a id="L20"></a>

有餘載自全以蕃衛天子豈非篤於仁義奉上法哉漢興功¶

<a id="L21"></a>

臣受封者百有餘人(索𨼆曰案下文髙祖功臣百三十七人/兼外戚及王子凡一百四十三人受封)¶

<a id="L22"></a>

天下初定故大城名都㪚亡戸口可得而數者十二三(索𨼆/曰言)¶

<a id="L23"></a>

(十分纔二/三在耳)是以大侯不過萬家小者五六百户後數世民咸¶

<a id="L24"></a>

歸鄉里户益息蕭曹絳灌之屬或至四萬小侯自倍(索𨼆曰/倍其初)¶

<a id="L25"></a>

&lt;pb:KR2a0005_WYG_006-2a&gt;¶

<a id="L26"></a>

(封時户/口也)富厚如之子孫驕溢忘其先滛嬖至太初百年之間¶

<a id="L27"></a>

見侯五(正義曰謂平陽侯曹宗曲周侯酈終根/陽河侯齊仁戴侯秘䝉穀陵侯馮偃也)餘皆坐法隕¶

<a id="L28"></a>

命亡國耗矣罔亦少宻焉然皆身無兢兢於當世之禁云居¶

<a id="L29"></a>

今之世志古之道所以自鏡也未必盡同帝王者各殊禮而¶

<a id="L30"></a>

異務要以成功為統紀豈可緄乎(孚逺曰此數語無註蓋不/敢斥言漢家少恩故為𨼆)¶

<a id="L31"></a>

(語/也)觀所以得尊寵及所以廢辱亦當時得失之林也何必舊¶

<a id="L32"></a>

聞於是謹其終始表見其文頗有所不盡本末著其明疑者¶

<a id="L33"></a>

闕之後有君子欲推而列之得以覽焉¶

<a id="L195"></a>

　　讀髙祖功臣年表¶

<a id="L196"></a>

　讀功臣年表以侯功為主按漢書髙祖八年天下平¶

<a id="L197"></a>

　論功定封訖十二年侯者百四十有三人又作十八¶

<a id="L198"></a>

　侯位次髙后二年詔丞相陳平盡差列侯之功録第¶

<a id="L199"></a>

　下竟藏諸宗廟副在有司太史公所表侯第是也¶

<a id="L200"></a>

韋昭曰漢封功臣大者王小者侯也¶

<a id="L201"></a>

　按功臣封王在髙帝四年五年間是時天下初定如¶

<a id="L202"></a>

　韓彭等不得不王之耳自六年以後漢約非劉氏不¶

<a id="L203"></a>

&lt;pb:KR2a0005_WYG_006-75b&gt;¶

<a id="L204"></a>

　王非軍功不侯¶

<a id="L205"></a>

索𨼆曰漢書音義云曹參功第二而表在首蕭何功第¶

<a id="L206"></a>

一而表在十三者以封有先後故也¶

<a id="L207"></a>

索𨼆曰封參在六年十二月封何在六年正月髙祖十¶

<a id="L208"></a>

月因秦改元故十二月在正月前也¶

<a id="L209"></a>

　表侯功太約從起豊沛從至霸上定秦從至漢中從¶

<a id="L210"></a>

　滅項羽功之大者也餘功如從大將擊齊魏擊趙韓¶

<a id="L211"></a>

　燕代定諸侯如䕶太公呂后如奉孝惠魯元公主如¶

<a id="L212"></a>

&lt;pb:KR2a0005_WYG_006-76a&gt;¶

<a id="L213"></a>

　解鴻門如為漢守如從擊黥布彭越陳豨盧綰韓王¶

<a id="L214"></a>

　信等皆表而出之明不與恩澤侯同也¶

<a id="L215"></a>

　凡有罪失侯者大約如酎金如為太常犧牲不如令¶

<a id="L216"></a>

　如為太常酒酸罪之輕者也餘罪如為太守知民不¶

<a id="L217"></a>

　用赤仄錢為賦如不償人責如尚南宮公主不敬如¶

<a id="L218"></a>

　出入屬車間如坐出界如買塞外禁物如入上林謀¶

<a id="L219"></a>

　盜鹿如為太常與樂舞人闌入凾谷關如賣宅縣官¶

<a id="L220"></a>

　故貴猶皆在可議之列也餘重罪則謀為大逆大不¶

<a id="L221"></a>

&lt;pb:KR2a0005_WYG_006-76b&gt;¶

<a id="L222"></a>

　敬過律姦淫畧人傷人摠之所謂不奉上法者也或¶

<a id="L223"></a>

　但云有罪疑獄也不明所坐或史闕之¶

<a id="L224"></a>

　按太史序曰漢興功臣受封者百有餘人至太初百¶

<a id="L225"></a>

　年之間見侯五餘皆坐法隕命亾國嘆不能副河山¶

<a id="L226"></a>

　帶礪之誓而苗裔衰微也今第追録侯功謂察其首¶

<a id="L227"></a>

　封所以得尊寵而各書罪狀國所自除則所以失之¶

<a id="L228"></a>

　而致廢辱者責在下矣故曰當世得失之林也然本¶

<a id="L229"></a>

　其先天下初定大都名邦户口散亾漸以益息乃至¶

<a id="L230"></a>

&lt;pb:KR2a0005_WYG_006-77a&gt;¶

<a id="L231"></a>

　富厚未幾子孫驕溢不能篤于仁義奉上法以自取¶

<a id="L232"></a>

　戾而首稱功有五品以深致欷歔之意且夫協和萬¶

<a id="L233"></a>

　國遷于夏商或數千嵗何古者封建之澤長而今兹¶

<a id="L234"></a>

　之促也惜哉其罪累上毋亦使人謂漢法之過嚴乎¶

<a id="L235"></a>

　此下四表皆國經而年緯凡標國名侯功于端以貫¶

<a id="L236"></a>

　其下者縱也標髙祖孝惠髙后孝文孝景與建元至¶

<a id="L237"></a>

　太初已復準王朝厯數以紀諸侯之年者衡也前十¶

<a id="L238"></a>

　二諸侯年表以下皆年經而國緯故冠帝年于端體¶

<a id="L239"></a>

&lt;pb:KR2a0005_WYG_006-77b&gt;¶

<a id="L240"></a>

　各不同也¶

<a id="L241"></a>

　何謂準王朝厯數定諸侯之年如表首平陽侯曹參¶

<a id="L242"></a>

　在髙祖朝以六年十二月封是其元年盡髙祖十二¶

<a id="L243"></a>

　年凡七年其在孝惠朝凡五年(合計之何在/位十二年)子窟嗣¶

<a id="L244"></a>

　盡孝惠七年凡二年其在髙后朝八年在孝文朝凡¶

<a id="L245"></a>

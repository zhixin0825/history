<a id="L9"></a>

　韓非子卷十　　　　　　　元　何犿　註¶

<a id="L10"></a>

　　内儲說下六㣲第三十一¶

<a id="L11"></a>

六㣲一曰權借在下二曰利異外借三曰託於似類四¶

<a id="L12"></a>

曰利害有反五曰叅疑内争六曰敵國廢置此六者主¶

<a id="L13"></a>

之所察也¶

<a id="L14"></a>

權勢不可以借人上失其一臣以為百故臣得借則力¶

<a id="L15"></a>

多力多則内外為用内外為用則人主壅其說在老聃¶

<a id="L16"></a>

&lt;pb:KR3c0005_WYG_010-1b&gt;¶

<a id="L17"></a>

之言失魚也是以人主久語而左右鬻懐尉其患在胥¶

<a id="L18"></a>

僮之諫厲公與州侯之一言而燕人浴矢也¶

<a id="L19"></a>

　　　權借一¶

<a id="L20"></a>

君臣之利異故人臣莫忠故臣利立而主利滅是以姦¶

<a id="L21"></a>

臣者召敵兵以内除舉外事以眩主茍成其私利不顧¶

<a id="L22"></a>

國患其說在衛人之妻夫禱祝也故戴歇議子弟而三¶

<a id="L23"></a>

桓攻昭公公叔内齊軍而翟璜召韓兵大宰嚭說大夫¶

<a id="L24"></a>

種大成牛教申不害司馬喜告趙王吕倉規秦楚宋石¶

<a id="L25"></a>

&lt;pb:KR3c0005_WYG_010-2a&gt;¶

<a id="L26"></a>

遺衛君書白圭教暴譴¶

<a id="L27"></a>

　　　利異二¶

<a id="L28"></a>

似類之事人主之所以失誅而大臣之所以成私也是¶

<a id="L29"></a>

以門人捐水而夷射誅濟陽自矯而二人罪司馬喜殺¶

<a id="L30"></a>

爰騫而季辛誅鄭袖言惡臭而新人劓費無忌教郄宛¶

<a id="L31"></a>

而令尹誅陳需殺張夀而犀首走故燒芻廥而中山罪¶

<a id="L32"></a>

殺老儒而濟陽賞也¶

<a id="L33"></a>

　　　事類三¶

<a id="L34"></a>

&lt;pb:KR3c0005_WYG_010-2b&gt;¶

<a id="L35"></a>

事起而有所利其尸主之有所害必反察之是以明主¶

<a id="L36"></a>

之論也國害則省其利者臣害則察其反者其說在楚¶

<a id="L37"></a>

兵至而陳需相黍種貴而廩吏覆是以昭奚恤執販茅¶

<a id="L38"></a>

而僖侯譙其次文公髪繞炙而穰侯請立帝¶

<a id="L39"></a>

　　　有反四¶

<a id="L40"></a>

叅疑之勢亂之所由生也故明主愼之是以晉驪姬殺¶

<a id="L41"></a>

太子申生而鄭夫人用毒藥衛州吁殺其君完公子根¶

<a id="L42"></a>

取東周王子職甚有寵而商臣果作亂嚴遂韓廆争而¶

<a id="L43"></a>

&lt;pb:KR3c0005_WYG_010-3a&gt;¶

<a id="L44"></a>

哀侯果遇賊田常闞止戴驩皇喜敵而宋君簡公殺其¶

<a id="L45"></a>

說在狐突之稱二好與鄭昭之對未生也¶

<a id="L46"></a>

　　　參疑五¶

<a id="L47"></a>

敵之所務在淫察而就靡人主不察則敵廢置矣故文¶

<a id="L48"></a>

王資費仲而秦王患楚使黎且去仲尼而干象沮甘茂¶

<a id="L49"></a>

是以子胥宣言而子常用内羙人而虞虢亡佯遺書而¶

<a id="L50"></a>

萇死用雞猳而鄶傑盡¶

<a id="L51"></a>

　　　廢置六¶

<a id="L52"></a>

&lt;pb:KR3c0005_WYG_010-3b&gt;¶

<a id="L53"></a>

叅疑廢置之事明主絶之於内而施之於外資其輕者¶

<a id="L54"></a>

輔其弱者此謂廟攻參伍既用於内觀聽又行於外則¶

<a id="L55"></a>

敵偽得其說在秦侏儒之告惠文君也故襄疵言襲鄴¶

<a id="L56"></a>

而嗣公賜令蓆¶

<a id="L57"></a>

　　　廟攻七右經¶

<a id="L58"></a>

一勢重者人主之淵也臣者勢重之魚也魚失於淵而¶

<a id="L59"></a>

不可復得也人主失其勢重於臣而不可復收也古之¶

<a id="L60"></a>

人難正言故託之於魚¶

<a id="L61"></a>

&lt;pb:KR3c0005_WYG_010-4a&gt;¶

<a id="L62"></a>

賞罰者利器也君操之以制臣臣得之以壅主故君先¶

<a id="L63"></a>

見所賞則臣鬻之以為徳君先見所罰則臣鬻之以為¶

<a id="L64"></a>

威故曰國之利器不可以示人¶

<a id="L65"></a>

靖郭君相齊與故人久語則故人富懐左右尉則左右¶

<a id="L66"></a>

重久語懐尉小資也猶以成富況於吏勢乎晉厲公之¶

<a id="L67"></a>

時六卿貴胥僮長魚矯諫曰大臣貴重敵主争事外市¶

<a id="L68"></a>

樹黨下亂國法上以刧主而國不危者未嘗有也公曰¶

<a id="L69"></a>

善乃誅三卿胥僮長魚矯又諫曰夫同罪之人偏誅而¶

<a id="L70"></a>

&lt;pb:KR3c0005_WYG_010-4b&gt;¶

<a id="L71"></a>

不盡是懐怨而借之間也公曰吾一朝而夷三卿予不¶

<a id="L72"></a>

忍盡也長魚矯對曰公不忍之彼將忍公公不聽居三¶

<a id="L73"></a>

月諸卿作難遂殺厲公而分其地¶

<a id="L74"></a>

州侯相荆貴而主斷荆王疑之因問左右左右對曰無¶

<a id="L75"></a>

有如出一口也燕人無惑故浴狗矢燕人其妻有私通¶

<a id="L76"></a>

於士其夫早自外而來士適出夫曰何客也其妻曰無¶

<a id="L77"></a>

客問左右左右言無有如出一口其妻曰公惑易也因¶

<a id="L78"></a>

浴之以狗矢一曰燕人李季好逺出其妻私有通於士¶

<a id="L79"></a>

&lt;pb:KR3c0005_WYG_010-5a&gt;¶

<a id="L80"></a>

季突至士在内中妻患之其室婦曰令公子裸而解髪¶

<a id="L81"></a>

直出門吾屬佯不見也於是公子從其計疾走出門季¶

<a id="L82"></a>

曰是何人也家室皆曰無有季曰吾見鬼乎婦人曰然¶

<a id="L83"></a>

為之奈何曰取五姓之矢(一云/尿)浴之季曰諾乃浴以矢¶

<a id="L84"></a>

一曰浴以蘭湯¶

<a id="L85"></a>

二衛人有夫妻禱者而祝曰使我無故得百束布其夫¶

<a id="L86"></a>

曰何少也對曰益是子將以買妾¶

<a id="L87"></a>

荆王欲宦諸公子於四隣戴歇曰不可宦公子於四隣¶

<a id="L88"></a>

&lt;pb:KR3c0005_WYG_010-5b&gt;¶

<a id="L89"></a>

四隣必重之曰子出者重重則必為所重之國黨則是¶

<a id="L90"></a>

教子於外市也不便¶

<a id="L91"></a>

魯孟孫叔孫季孫相戮力刧昭公遂奪其國而擅其制¶

<a id="L92"></a>

魯三桓逼昭公攻季孫氏而孟孫氏叔孫氏相與謀曰¶

<a id="L93"></a>

救之乎叔孫氏之御者曰我家臣也安知公家凡有季¶

<a id="L94"></a>

孫與無季孫於我孰利皆曰無季孫必無叔孫然則救¶

<a id="L95"></a>

之於是撞西北隅而入孟孫見叔孫之旗入亦救之三¶

<a id="L96"></a>

桓為一昭公不勝逐之死於乾侯¶

<a id="L97"></a>

&lt;pb:KR3c0005_WYG_010-6a&gt;¶

<a id="L98"></a>

公叔相韓而有功齊公仲甚重於王公叔恐王之相公¶

<a id="L99"></a>

仲也使齊韓約而攻衛公叔因内齊軍於鄭以劫其君¶

<a id="L100"></a>

以固其位而信兩國之約¶

<a id="L101"></a>

翟璜魏王之臣也而善於韓乃召韓兵令之攻魏因請¶

<a id="L102"></a>

為魏王搆之以自重也¶

<a id="L103"></a>

越王攻吳王吳王謝而告服越王欲許之范蠡大夫種¶

<a id="L104"></a>

曰不可昔天以越與吳吳不受今天反夫差亦天禍也¶

<a id="L105"></a>

以吳予越再拜受之不可許也大宰嚭遺大夫種書曰¶

<a id="L106"></a>

&lt;pb:KR3c0005_WYG_010-6b&gt;¶

<a id="L107"></a>

狡兎盡則良犬烹敵國滅則謀臣亡大夫何不釋吳而¶

<a id="L108"></a>

患越乎大夫種受書讀之太息而歎曰殺之越與吳同¶

<a id="L109"></a>

命¶

<a id="L110"></a>

大成牛從趙謂申不害於韓曰以韓重我於趙請以趙¶

<a id="L111"></a>

重子於韓是子有兩韓我有兩趙¶

<a id="L112"></a>

司馬喜中山君之臣也而善於趙嘗以中山之謀㣲告¶

<a id="L113"></a>

趙王吕倉魏王之臣也而善於秦荆㣲諷秦荆令之攻¶

<a id="L114"></a>

魏因請行和以自重也¶

<a id="L115"></a>

&lt;pb:KR3c0005_WYG_010-7a&gt;¶

<a id="L116"></a>

宋石衛將也衛君荆將也兩國搆難二子皆將宋石遺¶

<a id="L117"></a>

衛君書曰二軍相當兩旗相望唯毋一戰戰必不兩存¶

<a id="L118"></a>

此乃兩主之事也與子無有私怨善者相避也¶

<a id="L119"></a>

白圭相魏暴譴相韓白圭謂暴譴曰子以韓輔我於魏¶

<a id="L120"></a>

我以魏待子於韓臣長用魏子長用韓¶

<a id="L121"></a>

三齊中大夫有夷射者御飲於王醉甚而出倚於郎門¶

<a id="L122"></a>

門者刖跪請曰足下無意賜之餘瀝乎夷射曰叱去刑¶

<a id="L123"></a>

餘之人何事乃敢乞飲長者刖跪走退及夷射去刖跪¶

<a id="L124"></a>

&lt;pb:KR3c0005_WYG_010-7b&gt;¶

<a id="L125"></a>

因捐水郎門霤下類溺者之狀明日王出而訶之曰誰¶

<a id="L126"></a>

溺於是刖跪對曰臣不見也雖然昨日中大夫夷射立¶

<a id="L127"></a>

於此王因誅夷射而殺之¶

<a id="L128"></a>

魏王臣二人不善濟陽君濟陽君因偽令人矯王命而¶

<a id="L129"></a>

謀攻已王使人問濟陽君曰誰與恨對曰無敢與恨雖¶

<a id="L130"></a>

然嘗與二人不善不足以至於此王問左右左右曰固¶

<a id="L131"></a>

然王因誅二人者¶

<a id="L132"></a>

季辛與爰騫相怨司馬喜新與季辛惡因㣲令人殺爰¶

<a id="L133"></a>

&lt;pb:KR3c0005_WYG_010-8a&gt;¶

<a id="L134"></a>

騫中山之君以為季辛也因誅之¶

<a id="L135"></a>

荆王所愛妾有鄭袖者荆王新得羙女鄭袖因教之曰¶

<a id="L136"></a>

王甚喜人之掩口也為近王必掩口羙女入見近王因掩¶

<a id="L137"></a>

口王問其故鄭袖曰此固言惡王之臭及王與鄭袖羙女¶

<a id="L138"></a>

三人坐袖因先誡御者曰王適有言必亟聽從王言羙女¶

<a id="L139"></a>

前近王甚數掩口王勃然怒曰劓之御因揄刀而劓羙人¶

<a id="L140"></a>

一曰魏王遺荆王羙人荆王甚恱之夫人鄭袖知王恱¶

<a id="L141"></a>

愛之也亦恱愛之甚於王衣服玩好擇其所欲為之王¶

<a id="L142"></a>

&lt;pb:KR3c0005_WYG_010-8b&gt;¶

<a id="L143"></a>

曰夫人知我愛新人也其恱愛之甚於寡人此孝子所¶

<a id="L144"></a>

以養親忠臣之所以事君也夫人知王之不以己為妬¶

<a id="L145"></a>

也因謂新人曰王甚恱愛子然惡子之鼻子見王常掩¶

<a id="L146"></a>

鼻則王長幸子矣於是新人從之每見王常掩鼻王謂¶

<a id="L147"></a>

夫人曰新人見寡人常掩鼻何也對曰不已知也王强¶

<a id="L148"></a>

問之對曰頃嘗言惡聞王臭王怒曰劓之夫人先誡御¶

<a id="L149"></a>

者曰王適有言必可從命御者因揄刀而劓羙人¶

<a id="L150"></a>

費無極荆令尹之近者也郄宛新事令尹令尹甚愛之¶

<a id="L151"></a>

&lt;pb:KR3c0005_WYG_010-9a&gt;¶

<a id="L152"></a>

無極因謂令尹曰君愛宛甚何不一為酒其家令尹曰¶

<a id="L153"></a>

善因令之為具於郄宛之家無極教宛曰令尹甚傲而¶

<a id="L154"></a>

好兵子必謹敬先亟陳兵堂下及門庭宛因為之令尹¶

<a id="L155"></a>

徃而大驚曰此何也無極曰君殆去之事未可知也令¶

<a id="L156"></a>

尹大怒舉兵而誅郄宛遂殺之¶

<a id="L157"></a>

犀首與張夀為怨陳需新入不善犀首因使人㣲殺張¶

<a id="L158"></a>

夀魏王以為犀首也乃誅之¶

<a id="L159"></a>

中山有賤公子馬甚瘦車甚弊左右有私不善者乃為¶

<a id="L160"></a>

&lt;pb:KR3c0005_WYG_010-9b&gt;¶

<a id="L161"></a>

之請王曰公子甚貧馬甚瘦王何不益之馬食王不許¶

<a id="L162"></a>

左右因㣲令夜燒芻廐王以為賤公子也乃誅之¶

<a id="L163"></a>

魏有老儒不善濟陽君客有與老儒私怨者因攻老儒¶

<a id="L164"></a>

殺之以徳於濟陽君曰臣為其不善君也故為君殺之¶

<a id="L165"></a>

濟陽君因不察而賞之一曰濟陽君有少庶子者不見¶

<a id="L166"></a>

知欲入愛於君者齊使老儒掘藥於馬梨之山濟陽少¶

<a id="L167"></a>

庶子欲以為功入見於君曰齊使老儒掘藥於馬梨之¶

<a id="L168"></a>

山名掘藥也實間君之國君殺之是將以濟陽君抵罪¶

<a id="L169"></a>

&lt;pb:KR3c0005_WYG_010-10a&gt;¶

<a id="L170"></a>

於齊矣臣請刺之君曰可於是明日得之城陰而刺之¶

<a id="L171"></a>

濟陽君還益親之¶

<a id="L172"></a>

四陳需魏王之臣也善於荆王而令荆攻魏荆攻魏陳¶

<a id="L173"></a>

需因請為魏王行解之因以荆勢相魏¶

<a id="L174"></a>

韓昭侯之時黍種常貴甚昭侯令人覆廪吏果竊黍種¶

<a id="L175"></a>

而糶之甚多¶

<a id="L176"></a>

昭奚恤之用荆也有燒倉廥&amp;KR0034;者而不知其人昭奚恤¶

<a id="L177"></a>

令吏執販茅者而問之果燒也¶

<a id="L178"></a>

&lt;pb:KR3c0005_WYG_010-10b&gt;¶

<a id="L179"></a>

昭奚侯之時宰人上食而羮中有生肝焉昭侯召宰人¶

<a id="L180"></a>

之次而誚之曰若何為置生肝寡人羮中宰人頓首服¶

<a id="L181"></a>

死罪曰竊欲去尚宰人也一曰僖侯浴湯中有礫僖侯¶

<a id="L182"></a>

曰尚浴免則有當代者乎左右對曰有僖侯曰召而來¶

<a id="L183"></a>

譙之曰何為置礫湯中對曰尚浴免則臣得代之是以¶

<a id="L184"></a>

置礫湯中¶

<a id="L185"></a>

文公之時宰臣上炙而髮繞之文公召宰人而譙之曰¶

<a id="L186"></a>

女欲寡人之哽耶奚為以髮繞炙宰人頓首再拜請曰¶

<a id="L187"></a>

&lt;pb:KR3c0005_WYG_010-11a&gt;¶

<a id="L188"></a>

有死罪三援礪砥刀利猶干將也切肉肉斷而髪不斷¶

<a id="L189"></a>

臣之罪一也援木而貫臠而不見髪臣之罪二也奉熾¶

<a id="L190"></a>

爐炭火盡赤紅而炙熟而髪不燒臣之罪三也堂下得¶

<a id="L191"></a>

無㣲有疾臣者乎公曰善乃召其堂下而譙之果然乃¶

<a id="L192"></a>

誅之一曰晉平公觴客少庶子進炙而髪繞之平公趣¶

<a id="L193"></a>

殺炮人毋有反令炮人呼天曰嗟乎臣有三罪死而不¶

<a id="L194"></a>

自知乎平公曰何謂也對曰臣刀之利風靡骨斷而髪¶

<a id="L195"></a>

不斷是臣之一死也桑炭炙之肉紅白而髪不焦是臣¶

<a id="L196"></a>

&lt;pb:KR3c0005_WYG_010-11b&gt;¶

<a id="L197"></a>

之二死也炙熟又重睫而視之髪繞炙而目不見是臣¶

<a id="L198"></a>

之三死也意者堂下其有翳憎臣者乎殺臣不亦蚤乎¶

<a id="L199"></a>

穰侯相秦而齊强穰侯欲立秦為帝而齊不聽因請立¶

<a id="L200"></a>

齊為東帝而不能成也¶

<a id="L201"></a>

五晉獻公之時驪姬貴擬於后妻而欲以其子奚齊代¶

<a id="L202"></a>

太子申生因患申生於君而殺之遂立奚齊為太子¶

<a id="L203"></a>

鄭君已立太子矣而有所愛羙女欲以其子為後夫人¶

<a id="L204"></a>

恐因用毒藥賊君殺之¶

<a id="L205"></a>

&lt;pb:KR3c0005_WYG_010-12a&gt;¶

<a id="L206"></a>

衛州吁重於衛擬於君羣臣百姓盡畏其勢重州吁果¶

<a id="L207"></a>

殺其君而奪之政¶

<a id="L208"></a>

公子朝周太子也弟公子根甚有寵於君君死遂以東¶

<a id="L209"></a>

周叛分為兩國¶

<a id="L210"></a>

楚成王以商臣為太子既而又欲置公子職商臣作亂¶

<a id="L211"></a>

遂攻殺成王一曰楚成王商臣為太子既欲置太子職¶

<a id="L212"></a>

商臣聞之未察也乃謂其傅潘崇曰奈何察之也潘崇¶

<a id="L213"></a>

曰饗江芊而勿敬也太子聽之江芉曰呼役夫宜君王¶

<a id="L214"></a>

&lt;pb:KR3c0005_WYG_010-12b&gt;¶

<a id="L215"></a>

之欲廢女而立職也商臣曰信矣潘崇曰能事之乎曰¶

<a id="L216"></a>

不能能為之諸侯乎曰不能能舉大事乎曰能於是乃¶

<a id="L217"></a>

起宿營之甲而攻成王成王請食熊膰而死不許遂自¶

<a id="L218"></a>

殺¶

<a id="L219"></a>

韓廆相哀侯嚴遂重於君二人甚相害也嚴遂乃令人¶

<a id="L220"></a>

刺韓廆而兼哀侯¶

<a id="L221"></a>

田恒相齊闞止重於簡公二人相憎而欲相賊也田恒¶

<a id="L222"></a>

因行私惠以取其國遂殺簡公而奪之政¶

<a id="L223"></a>

&lt;pb:KR3c0005_WYG_010-13a&gt;¶

<a id="L224"></a>

戴驩為宋太宰皇喜重於君二人争事而相害也皇喜¶

<a id="L225"></a>

遂殺宋君而奪其政¶

<a id="L226"></a>

狐突曰國君好内則太子危好外則相室危¶

<a id="L227"></a>

鄭君為鄭昭曰太子亦何如對曰太子未生也君曰太¶

<a id="L228"></a>

子已置而曰未生何也對曰太子雖置然而君之好色¶

<a id="L229"></a>

不已所愛有子君必愛之愛之則必欲以為後臣故曰¶

<a id="L230"></a>

太子未生也¶

<a id="L231"></a>

六文王資費仲而遊於紂之旁令之諫紂而亂其心¶

<a id="L232"></a>

&lt;pb:KR3c0005_WYG_010-13b&gt;¶

<a id="L233"></a>

荆王使人之秦秦王甚禮之王曰敵國有賢者國之憂¶

<a id="L234"></a>

也今荆王之使者甚賢寡人患之羣臣諫曰以王之賢¶

<a id="L235"></a>

聖與國之資厚願荆王之賢人王何不深知之而隂有¶

<a id="L236"></a>

之荆以為外用也則必誅之¶

<a id="L237"></a>

仲尼為政於魯道不拾遺齊景公患之黎且謂景公曰¶

<a id="L238"></a>

去仲尼猶吹毛耳君何不迎之以重祿高位遺哀公女¶

<a id="L239"></a>

樂以驕榮其意哀公新樂之必怠於政仲尼必諫諫必¶

<a id="L240"></a>

輕絶於魯景公曰善乃令黎且以女樂六遺哀公哀公¶

<a id="L241"></a>

&lt;pb:KR3c0005_WYG_010-14a&gt;¶

<a id="L242"></a>

樂之果怠於政仲尼諫不聽去而之楚¶

<a id="L243"></a>

楚王謂干象曰吾欲以楚扶甘茂而相之秦可乎干象¶

<a id="L244"></a>

對曰不可也王曰何也曰甘茂少而事史舉先生史舉¶

<a id="L245"></a>

上蔡之監門也大不事君小不事家以苛刻聞天下茂¶

<a id="L246"></a>

事之順焉惠王之明張儀之辨也茂事之取十官而免¶

<a id="L247"></a>

於罪是茂賢也王曰相人敵國而相賢其不可何也干¶

<a id="L248"></a>

象曰前時王使邵滑之越五年而能亡越所以然者越¶

<a id="L249"></a>

亂而楚治也日者知用之越今亡之秦不亦太亟亡乎¶

<a id="L250"></a>

&lt;pb:KR3c0005_WYG_010-14b&gt;¶

<a id="L251"></a>

王曰然則為之奈何干象對曰不如相共立王曰共立¶

<a id="L252"></a>

可相何也對曰共立少見愛幸長為貴卿被王衣含杜¶

<a id="L253"></a>

若握玉環以聽於朝且利以亂秦矣(共立一云/公子赫)¶

<a id="L254"></a>

吳攻荆子胥使人宣言於荆曰子期用將擊之子常用¶

<a id="L255"></a>

將去之荆人聞之因用子常而退子期也吳人擊之遂¶

<a id="L256"></a>

勝之¶

晉獻公伐虞虢乃遺之屈産之乘垂棘之璧女樂六以¶

<a id="L258"></a>

榮其意而亂其政¶

<a id="L260"></a>

叔向之讒萇𢎞也為書曰萇𢎞謂叔向曰子為我謂晉¶

<a id="L261"></a>

君所與君期者時可矣何不亟以兵來因佯遺其書周¶

<a id="L262"></a>

之¶

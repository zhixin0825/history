# 《说难》古籍对读节录

[史料目录](../README.md) · [卷063三家注](../史记三家注/卷063.md) · [卷063完整读本](../摘录/史记-卷063-老子韩非列传.md)

**文本性质：** 公版古籍短节录，用来核对《史记》所引《说难》的异文；不以今见《韩非子》替换主TXT。

**实际阅读范围：** 2026-11-12实际打开维基文库《韩非子·说难》，读完该页全部篇文；本页仅保存与本次释读有关的五处。原网页为繁体转录，未取得点校本校勘记，不称独立善本。来源：[维基文库《韩非子／说难》](https://zh.wikisource.org/wiki/韓非子/說難)。以下保留所见原字与句读。

## 内容

<a id="concealed-purpose"></a>
### 公开行事与另有用意

> 彼顯有所出事，而乃以成他故，說者不徒知所出而已矣，又知其所以爲，如此者身危。

对读说明：《史记》主TXT“迺自以為也故”难通，三家注本另有断句，索隐、正义分别从争功及营为解释。此句仅用于提示另一传本文意，白话采用“公开行事而自有筹划，知其情由也有危险”的宽译，不暗改底本。

<a id="admonition"></a>
### 尽言与触忤

> 大意無所拂悟，辭言無所繫縻，然後極騁智辯焉。此道所得，親近不疑而得盡辭也。

对读说明：《史记》主TXT作“大忠无所拂悟，辞言无所击排”“知尽之难”，古注又保存不同分句和徐广“知／得、难／辞”异文。不把所有版本拼成一个未经说明的新正文。

<a id="yiyin-bailixi"></a>
### 伊尹、百里奚与“所耻”

> 伊尹爲宰，百里奚爲虜，皆所以干其上也。此二人者，皆聖人也；然猶不能無役身以進，如此其汙也！今以吾言爲宰虜，而可以聽用而振世，此非能仕之所恥也。

对读说明：《史记》主TXT“则非能仕之所设也”有疑；本卷索隐也明引《韩子》“非能士之所耻也”。白话说明据“耻”义理解，原引仍保存“设”。伊尹、百里奚在这里是论辩中的例证，不新增任官或被俘的纪年。

<a id="hu-marriage"></a>
### 郑武公故事的婚姻用字

> 昔者鄭武公欲伐胡，故先以其女妻胡君以娛其意。

对读说明：《史记》作“迺以其子妻之”，此处以“女妻胡君”互证，白话释为把女儿嫁给胡君；不把“子”误作儿子。

<a id="know-and-place"></a>
### 两则故事的论点

> 此二人說者皆當矣，厚者爲戮，薄者見疑，則非知之難也，處知則難也。

对读说明：《韩非子》先郑武公、后宋富人，《史记》次序相反；两者均以“知”与“处知”的区分作论点，不据故事次序编出两件确定相继的年代事件。

# 穰苴时代争议的古籍节录

[史料目录](../README.md) · [卷064三家注](../史记三家注/卷064.md) · [卷064完整读本](../摘录/史记-卷064-司马穰苴列传.md)

**文本性质：** 三处公版古籍的实际可见节录；它们呈现不同传述与后世质疑，不据其中一条替穰苴确定生卒或斩庄贾的公元年份。

**核对日期：** 2026-11-12。下列只声明已经实际读到的篇段。四库本末考证是转引苏辙、叶适，未据此冒称读完《古史》或《习学记言》。

## 内容

<a id="siku-critique"></a>
### 四库本卷末考证转引苏辙、叶适

来源：[《史记集解》四库本卷064网页转录](https://wk.100ke.info/zh-hans/史記集解_(司馬遷,_四庫全書本)/卷064)，所见版本页标旧版号838440；实际读完该页卷末考证。以下照录该段简体转录原字，不另加现代标点。

> 司马穰苴列传齐景公时晋伐阿甄而燕侵河上○古史曰太史公为司马穰苴传言齐景公拔以为将遂以成功归为大司马大夫高国害之谮而杀之其言甚美世皆信之予以春秋左氏考之未有燕晋伐齐者也而战国䇿称司马穰苴执政者也湣王杀之故大臣不附意者穰苴湣王之臣尝为湣王却燕晋而战国杂说遂以为景公时耶习学记言曰左氏前后载齐事甚详使有穰苴暴起立功不应遗落也况伐阿鄄侵河上皆景公时所无大司马亦非齐官迁故称田乞田豹由此怨高国若不考信于左氏者盖作书之人夸大其词而迁信之尔

释读范围：转引的苏辙说，按《左氏》查考，未见景公时燕、晋如此伐齐，另据《战国策》湣王杀穰苴的说法，怀疑人物时代错接。转引的叶适同样质疑《左氏》为何不载、战事与官名是否相合，并怀疑夸大之说被史家采信。这些是后世辨伪论证，不是本轮已独立穷尽《左传》后的检索结论；也不能直接把列传全部故事移到湣王某一年。

<a id="qiliu-minwang"></a>
### 《战国策·齐六》在齐湣王叙事中的“司马穰苴”

来源：[识典古籍《战国策校注》齐六对应章](https://www.shidianguji.com/book/SBCK039/chapter/1mebm88yfzimn)。实际读该章从齐负郭之民至燕伐齐、湣王奔莒及襄王承接的上下文；这里只节录关键四句，沿网页所见简体字及“闵”字。

> 齐负郭之民有孤狐咺者正议，闵王斮之檀衢，百姓不附；齐孙室子陈举直言，杀之东闾，宗室离心；司马穰苴为政者也，杀之，大臣不亲。以故燕举兵，使昌国君将而击之。

对读说明：这里确在湣王失人心、燕军来攻的论述中出现穰苴姓名，与《史记》景公用将的时代不同。仅凭同名尚不能解决是否一人、传误或故事移植的问题。

<a id="yanzi-night"></a>
### 《晏子春秋》景公夜访穰苴的传述

来源：[维基文库《晏子春秋》卷五](https://zh.wikisource.org/zh-hant/晏子春秋/卷五)，实际读完第十二章景公夜饮移访晏婴、穰苴、梁丘据及篇末君子评语；这里只节录访问穰苴的段落。章首人物为景公，承接处不另换主语。

> 公曰：「移於司馬穰苴之家。」前驅款門曰：「君至。」穰苴介胃操戟，立於門，曰：「諸侯得微有兵乎？大臣得微有叛者乎？君何為非時而夜辱？」公曰：「酒醴之味，金石之聲，願與夫子樂之。」穰苴對曰：「夫布薦席，陳簠簋者有人，臣不敢與焉。」

对读说明：这一故事也把穰苴置于齐景公身旁，是景公时期传述的互见；它不提供斩庄贾的年次，也不能仅凭两书同叙就消除另一时代的疑点。“介胃”照所见转录保留。

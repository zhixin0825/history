<pre><a id="L6"></a>竹书纪年义证卷之三十八
<a id="L7"></a>
<a id="L8"></a>通州雷学淇述。
<a id="L9"></a>
<a id="L10"></a>二十三年，魏殷臣、赵公孙裒伐燕，还取夏屋，城曲逆。
<a id="L11"></a>此显王二十一年，赵肃侯二年也。赵世家曰：二十五年，成侯卒，公子𫄬与太子肃侯争立，𫄬败，亡奔韩。肃侯元年，夺晋君端氏，徙处屯留。二年，与魏惠王遇于阴晋。索隐曰：世本云：肃侯名语，苏秦传。索隐引世本云：肃侯名言。史记年表以此为燕文侯十四年，索隐不言纪年有异，是竹书与史说同也。夏屋与赵世家襄子所登之夏屋同名。襄子所登乃山名，在今山西代州西五里，一名贾屋山。魏、赵所取乃邑名，在今完县。曲逆即春秋左传襄公四年，齐伐晋，取曲时者。汉以为县，属山国，后改名蒲阴。今故址在完县东南二十里。水经滱水注曰：濡水出蒲阴县西昌安郭南，其水自源东迳其故城南，枉渚回湍，率多曲复，故谓之为曲逆水也。张晏曰：县亦因水名而氏曲逆矣。又曰：濡水东得蒲口水，水出西北蒲阴山，南迳安阳亭东，又东南迳安阳关下，出关北流，又东迳夏屋故城，实中崄绝。竹书纪年曰：魏殷臣、赵公孙裒代燕，还取夏屋，城曲逆者也。其水又东南流，迳蒲阴县故城北。汉章帝章和二年，巡行北岳，以曲逆名不善，因山水之名，改曰蒲阴焉。今按：二邑皆近中山，而中山为惠王叔父䜣之封国。此后六年，中山君公子牟遂相魏，自惠王二十年归赵邯郸，与之修睦，故此年会于阴晋，与谋伐燕，必燕或侵轶山，故魏约赵师共伐之也。
<a id="L12"></a>二十四年壬寅，孙何侵楚，入三户都。
<a id="L13"></a>
<a id="L14"></a>此显王二二年，楚宣王二十三年也。孙何，魏臣。唐书世系表谓孙氏有三：一出姬姓，卫武公七世孙孙桓子良夫之后；一出芊姓，楚鼢冒四世孙孙叔敖之后；一出妫姓，陈公子完五世孙孙书之后。史记言卫属三晋，如小侯，则此孙何疑姬姓者。然不可楚邑名，即春秋左传哀公十四年，晋执戎蛮子与其五大夫以畀楚师于三户者。杜注云：在丹水县北也。今河南内乡县西南有三亭故址，水经丹水注谓即孙何所入。春秋隐五年左传杜洼云：郛，城外大郭也。
<a id="L15"></a>
<a id="L16"></a>二十五年，魏章帅师及郑师伐楚，取上蔡，孙何取稳阳。
<a id="L17"></a>此显王二三年，郑昭厘侯十七年，楚宣王二十四年也。魏章，魏公族，后仕秦为庶长，击楚于丹阳，卒归于魏而卒。详见秦本纪及六国年表。上蔡即蔡叔之封国，详见周纪。隐阳在濦水之北者也。水经颍水注曰：颍水自临颍县西小稳水出焉。又东南迳泽城北，即古城皋亭矣。春秋书公及诸侯盟于皋鼬者也。皋、泽字相似，名与字乘耳。㶏水又东迳赝阳城南。竹书纪年曰：孙何取稳阳。愚按：左传杜注谓繁昌东南有城皋亭，故郦氏引以为证。今河南临颖县在皋上，乃隋大业所徙，故城在西北三十里，稳阳城又在故城之东。汉以封坚镡为侯，即此。战国秦策曰：梁君伐楚胜齐，制韩、赵之兵。所谓伐楚，即三户、上蔡、灠阳诸役；所谓胜齐，即襄陵之败，齐使景舍求成事。所谓制韩、赵之兵，即前此拔赵邯郸，明年败韩于马陵之事。盖魏至此时极盛，又二年，遂率十二诸侯朝天子于孟津也。
<a id="L18"></a>
<a id="L19"></a>绛中地圹，西绝于汾。
<a id="L20"></a>
<a id="L21"></a>绛者，晋旧都也。圹，古坼字。地墀，谓地裂也。汾，汾水，自绛至汾，地大𠦉裂，书之，纪灾异也。
<a id="L22"></a>
<a id="L23"></a>二十六年，魏败韩于马陵，
<a id="L24"></a>此显王二十四年，韩昭厘侯十八年，齐威王十二年也。马陵有三说：春秋左传成公七年：诸侯同盟于马陵。杜注云：阳平元城县东南有地名马陵。后汉书郡国志亦载之。刘昭补注于河东平阳国又云：是同盟马陵处。魏世家谓庞涓败于马陵。徐广亦云：马陵在元城。正义引虞喜志林则云：马陵在濮州鄄城县东北六十里，涧谷深峻，可以置伏。按庞涓败即此也。徐说马陵在魏州元城县东南一里，庞涓败此地，非也。又曰：齐师退走，不合更渡河至魏州元城。徐说定非也。愚按：此三说者，同盟处，杜注为是，今大名府治东南十五里之马陵乜，庞涓败处，志林为是，今濮州东北之马陵也。此纪之马陵，不知何在。韩世家谓懿侯二年，魏败之马陵。正义用元城之说，岂本在此年，史记误系之懿侯欤？或前后两事也。国策谓梁君制韩、赵之兵，此与南梁之役，即所谓制韩者巳。惠王在位，前后元共五十二年，此时为最盛。东胜齐与宋、卫地，至今山东兖州，北胜燕、赵地，至今保定唐县。南伐楚地至上蔡，西和秦地，至鄜州。明年且驱泗上十二诸侯，朝天子于孟津，而盟之臼里，虽齐桓、晋文之霸，何以加焉。
<a id="L25"></a>然以服人淫名相榻，制丹衣，建九斿，乘夏车而称夏王，效夫差、句践之为，又加厉焉。南梁之役，遂为祸阶，加以西丧南辱，耻无洒矣。推原其故。皆拔邯郸，战梁赫，二役启之。然则战国之大势系于三晋。三晋之不合，此秦人所以东向而承其敝也。
<a id="L26"></a>
<a id="L27"></a>楚伐徐州，
<a id="L28"></a>
<a id="L29"></a>徐州即田恒置简公处，贾逵谓即陈氏邑，威王使默夫守之，此时亦为田忌食邑，故前传曰徐州子期。此徐州当在今薛县北，即后元年会诸侯处。三一年，邳迁于薛，改名徐州。彼徐州即因迁居之地，与此徐州相近，故通称之，非迁薛之后，始有徐州之名也。徐，说文作䣄，舒䣄徐古音通，非有异也。楚伐徐州，事多异说。齐世家谓宣王十年，楚围我徐州。楚世家谓威王七年，田婴欺楚威王，败之于徐州。越世家谓无疆伐齐，齐威王使人说越伐楚，楚威王败越，杀无疆，北破齐于徐州。据六国年表，此时为齐威王三十四年，楚宣王二十五年。据竹书，则此为宣王二五年，齐威王十二年。索隐谓此是楚杀越无疆时事。然则越世家误以楚宣王之伐徐州，并为楚威王之事耳。战国齐策曰：楚威王战胜于徐州。此齐人败魏于马陵以后事，即秦策所谓郢威王闻之，又破齐泗水之上者也，非此役矣。
<a id="L30"></a>
<a id="L31"></a>二十八年，穰疵帅师及郑孔夜战于梁赫，郑师败逋。
<a id="L32"></a>此显王二六年，郑昭厘侯二年，齐威王四年也。穰庇，魏臣名。韩非子六微篇曰：邺令襄疵。吕氏春秋无义篇曰：公孙鞅以其私属与母归魏，里庇不受。高诱法云：襄庇，魏人。然则庇以魏人为邺令，今且为军将也。孔夜，郑臣名。梁即南梁，赫即霍。春秋哀公四年左传云：为一昔之期，袭梁及霍，即此梁赫也。战言二邑者，转战于二邑之间，犹前纪田期来伐，战桂阳矣。杜注曰：梁，河南梁县西南故城也。梁南有霍阳山。服虔注云：梁、霍周南鄙也。以战国策文证之，即齐策所谓南梁之难矣。高诱注曰：南梁，韩邑，大梁在北，故曰南梁。太康地记曰：战国谓梁为南梁者，别大乐、少梁。唐书地理志曰：汝州梁县，本周承休，又有古梁县，在西南四十五里。贞观元年省，更承休曰梁。九域志曰：汝州治梁县，在东京开封府南四百五十里。据诸说，是南梁在今汝州西南，霍阳山又在南梁之南矣。今古梁城在州之西南四十里，山在古城东南二十里。水经渠水注解此纪染赫谓是大梁之西赤城，殊误。伐郑而战，无由韩师反在大梁，且与国策南梁之说不合。鲍彪策注谓南梁乃鲁国著县南梁水，尤谬。齐策曰：南梁之难，韩氏请救于齐，田侯召大臣而谋。田臣思曰：我阴结韩之亲，而晚承魏之敝，则国可重，利可得，名可尊矣。田侯曰：善。乃阴告韩使者而遣之。韩自以为有齐助，五战五不胜，东诉于齐，齐因起兵击魏，大破之马陵。五战五不胜，即此时转战于梁赫也。大破之马陵，即下纪是己。
<a id="L33"></a>十二月，齐田肸伐梁，败我于马陵。
<a id="L34"></a>
<a id="L35"></a>孟子梁惠王曰：及寡人之身，东败于齐，长子死焉。即此时事。田盻、马陵俱见上。战国齐策曰：田忌为齐将，系梁太子申，禽庞涓。魏策曰：魏惠王起境内众，将太子申而攻齐。客谓公子理之傅曰：太子年少，不习于兵。田盼宿将也，而孙子善用兵，必不胜，不胜必禽。又曰：魏太子自将过宋外黄，与齐人战而死。又曰：齐、魏战于马陵，齐大胜，魏杀太子申，覆十万之军。皆言此事，盖即因南梁之难，致此败也。
<a id="L36"></a>
<a id="L37"></a>史记述此，所在互异。齐魏世家、孙子列传每牵混桂陵之役，以赵为词，又自矛盾其说，谓其事当齐宣王二年、梁惠王三十年，此最误之甚者。其余皆与纪年、国策互相证明，犹可考桑。盖南梁之役，魏以襄底为将，闻齐将助郑，乃令庞涓益兵攻韩，故韩人五战五不胜。及齐人果来伐梁，乃又令太子申迎击之也。是时，齐以三田为将，孙子为师，故孙吴列传言庞涓攻韩，田忌将而往，直走大梁。孟尝君传则曰：田忌与孙膑、田婴俱伐魏，败之马陵。年表则曰：败魏马陵。田忌、田婴、田盼将，孙子为师。今国策不言襄庇、田婴，竹书不言庞涓、太子、田婴、田忌。盖南梁搆难，魏有并韩之心，故齐人声言救韩，而庞涓之师继出。
<a id="L38"></a>迨齐师果发，孙子设谋，使盼与婴攻其东鄙，使田忌扬言伐魏，直走大梁，未及韩都，不战而退，伪遁减灶以诱敌师，且使盼与婴阳拒太子，而阴马陵设伏以待。迨庞涓闻齐人来伐，掣兵而归，留襄疵在韩，涓乃东逐齐师，倍并行，遂败于马陵也。齐人乘胜尽破魏军，并虏太子。史记于孙子列传言之惟详，参以纪年、国策之文，大略可识。他书言此事多异，缘未悉心推勘耳。
<a id="L39"></a>
<a id="L40"></a>二十九年五月，齐田盻及宋人伐我东鄙，围平阳。
<a id="L41"></a>
<a id="L42"></a>此显王二十七年、齐威王十五年，秦孝公二十年，赵肃侯八年也。平阳，即南平阳县，今山东兖州邹县地名也。水经曰：泗水又南过平阳县西。注云：县即山阳郡之南平阳县也。竹书纪年曰：梁惠成王二九年，齐田肸及宋人伐我东鄙，围平阳者也。魏世家曰：惠王三十年，败马陵。三一年，秦、赵、齐共伐我。即此与下纪之事。特史记误移此事后二年耳。
<a id="L43"></a>
<a id="L44"></a>九月，秦卫鞅伐我西鄙。十月，邯郸伐我北鄙。王攻卫鞅，我师败逋。
<a id="L45"></a>卫鞅即商君。史记列传曰：商君者，卫之诸庶孽公子也，名鞅，姓公孙氏。其祖本姬姓也。鞅少好刑名之学，事魏相公叔座为中庶子。公叔既死，公孙鞅闻秦孝公下令，国求贤者，将修缪公之业，东复侵地，乃遂西入秦，因孝公宠臣景监以求见。孝公以卫鞅为左庶长，卒定变法之令。行之十年，秦民大说，于是以鞅为大良造。居三年，为筑冀阙宫庭于咸阳，秦自雍徙都之。居五年，秦人富疆，天子致昨于孝公，诸侯毕贺。
<a id="L46"></a>
<a id="L47"></a>其明年，齐败魏兵于马陵，虏其太子申，杀将军庞涓。其明年，卫鞅说孝公曰：魏往年大破于齐，诸侯畔之，可因此时伐魏，魏必不支，秦必东徙。东徙，秦据河山之固，东向以制诸侯，此帝王之业也。孝公以为然，使魏鞅将而伐魏，此即九月卫鞅伐我西鄙事也。魏世家曰：惠王三十一年，齐、赵数破我。年表谓是年齐与赵会伐魏，此即邯郸伐我北鄙事也。王攻卫鞅，我师败逋者，王遣公子卬攻卫鞅，鞅诈劫印而师徒挠败也。
<a id="L48"></a>吕氏春秋无义曰：公孙鞅为秦将而攻魏，魏使公子卬将而当之。公孙鞅之居魏也，固善公子卬，使人谓公子卬曰：凡所为游而欲贵者，以公子之故。也。今秦令鞅将，魏令公子当之，岂且忍相与战哉？公子言之公子之主，鞅请亦言之主而皆罢军。于是将归矣。使人谓公曰：归未有时相见，愿奥公子坐而相去别也。公子曰：诺。魏吏争之曰：不可。公不听，遂相与坐。公孙鞅因伏卒与车骑以取公子卬。
<a id="L49"></a>
<a id="L50"></a>史记魏世家及商君传亦纪其事，且曰：鞅伏甲士而袭虏公子印，因攻其军，尽破之，以归秦。魏惠王兵数破于齐，秦国内空以削恐，乃使使割河西之地献秦以和。按惠王之败于齐、秦，此胜衰一转关也。显王二十五年前，魏最强，败齐胜燕，侵楚拔赵，致鲁、卫、宋、郑之君而朝之，且率泗上十二诸侯，朝天子于孟津，以西谋秦，为臼里之盟，欲复兴周室，岂不盛哉？及彭喜言于郑君以败其盟，而惠王亦侈然自放，乘夏车而称夏王，此所以动天下之兵，而子申、子卬遂皆糜于锋刃矣。自是而齐威奋于东夏，秦孝起于西陲，东帝西帝之势，即成于此矣。
<a id="L51"></a>
<a id="L52"></a>秦会诸侯于逢泽。
<a id="L53"></a>秦孝公者，灵公孙，献公子也。秦本纪曰：惠公卒，出子立。出子二年，庶子改迎灵公之子献公于河西而立之。二十四年，献公卒，子孝公立，年已二十一岁矣。又曰：孝公十九年，天致伯。二十年，诸侯毕贺。秦使公子少官率师会诸候逢泽，朝天子。徐广曰：开封东北有逢泽。盖此因魏败秦，献洛西之地，故显王致伯于秦，诸侯毕贺，秦乃使少师会诸侯于魏郊，朝王于逢忌之薮也。
<a id="L54"></a>
<a id="L55"></a>史记误将马陵及公子印之事移后二年，谓惠王此时尚未败于齐、秦，甚误。年表曰：显王二十五年，诸侯会。周本纪。亦谓秦会之，尤误。
<a id="L56"></a>
<a id="L57"></a>按战国、秦策曰：梁君伐楚，胜齐，制韩、赵之兵，驱十二诸侯以朝天子于孟津。后子死，身布冠而拘秦。又曰：魏伐邯郸，因退而为逢泽之遇，乘夏车，称夏王，朝为天子，天下皆从。齐太公闻之，举兵伐魏，梁王身抱质执璧，请为陈侯臣。齐策曰：昔者魏王拥土千里，带甲三十六万，恃其强而拔邯郸，西围定阳，又从十二诸侯朝天子，以西谋秦。秦王恐之。卫鞅见魏王曰：大王不如先行王服，然后图齐、楚。魏王说于卫鞅之言也，故身广公宫，制丹衣，建九斿，从七星之𭤰，此天子之位，而魏王处之。于是齐、楚诸侯奔齐。齐人伐魏，杀其太子，覆其十万之军。魏王大恐，跣行按兵于国，而东次于齐。
<a id="L58"></a>韩策曰：魏王为九重之盟，且复天子。房喜谓韩王曰：勿听之也。大国恶有天子，而小国利之。王与大国弗听，魏安能与小国立之？
<a id="L59"></a>
<a id="L60"></a>据此诸说，是惠王于胜韩、赵之后，即率十二诸侯朝天子于孟津。因郑君弗听，秦又说之，使行王服，于是齐与秦始起而败之。核以纪年之文，年表之，显王二五年会诸侯，实即惠王之事。盖十八年败齐，拔赵，二十三年伐燕，二十四年及二十五年伐楚，二六年败韩，此实惠王极盛之时，其明年即显王之二十五年矣。魏之会诸侯朝天子，在此年无疑。过此，则二十八年、二十九年皆败于齐、秦之岁矣。策以败于齐、秦二事，紧接朝天子之文，此尤可徵信。盖败于齐、秦在魏会诸侯朝天子之后，非是秦会诸侯朝天子之后也。
<a id="L61"></a>
<a id="L62"></a>国策在汉初错竺改莒。会，魏王为御，韩王为右。若如史说，此会在魏败马陵之前，此时魏方自率诸侯朝天子，以西谋秦，岂肯俯受秦命，使秦人勒兵近郊，供其会事哉？三十年，秦封卫鞅于邬，改名曰商。
<a id="L63"></a>齐人伐魏，杀其太子，覆其十万之军。魏王大恐，跣行按兵于国，而东次于齐。韩策曰：魏王为九重之盟，且复天子。房喜谓韩王曰：听之也。大国恶有天子，而小国利之。王与大国弗听，魏安能与小国立之？据此诸说，是惠王于胜韩、赵之后，即率十二诸侯朝天子于孟津，因郑君弗听，秦又说之，使行王服，于是齐与秦始起而败之。核以纪年之文，年表之，显王二五年会诸侯，实即惠王之事。盖十八年败齐，拔赵，二十三年伐燕，二十四年及二十五年伐楚，二六年败韩，此实惠王极盛之时，其明年即显王之二十五年矣。魏之会诸侯朝天子在此年无疑，过此则二十八年、二十九年皆败齐、秦之岁矣。策以败于齐、秦二事，紧接朝天子之文，此尤可徵信。盖败于齐、秦，在魏会诸侯朝天子之后，非是秦会诸侯朝天子之后也。国策在汉初，错乱糅筥，故太史公序事多误。吕氏春秋报更曰：逢泽之会，魏王为御，韩王为右。若如史说，此会在魏败马陵之前，此时魏方自率诸侯朝天子以西谋秦，岂肯俯受秦命，使秦人勒兵近郊，供其会事哉？三十年，秦封卫鞅于邬，改名曰啇。
<a id="L64"></a>此显王二十八年，秦孝公二十一年乜。秦本纪曰：卫鞅击魏，虏魏公子印，封鞅为列侯，号商君。商君传曰：卫鞅。既破魏还，秦封之于商十五邑，号为商君。徐广音义曰：宏农商县也。索隐曰：于商二县名，在宏农。正义曰：于商在邓州内乡县东七里，古於邑也。商洛县在商州东八十九里，本商邑。愚按：徐氏以于为语，见索隐正义以于为邑名。小司马又谓纪年与此文同。盖读于为乌，谓即纪年之邬也。此因张仪诈楚，请献商于之地六百里，故谓此邬即彼于矣。然纪云改名曰商，是商即邬之后名，非商之外别有邬也。汉书地理志宏农郡商县注云：秦相卫鞅邑。其丹水县注止云密阳乡，故商密也，不云有于。楚世家集解始云：内乡、丹水二县有商城在于中，故谓之商于。张仪传索隐引刘氏云：商今之商州，有古商城，其西二百余里有古于城，则其说愈支矣。考此时，丹水、内乡尚是楚境，据国策、汉志，秦之东境在洛水南，止及武关，武关之内，商阪为扼要之区，故孝公封鞅于此。此距丹水县境尚三百余里，鞅之封，无由至内乡也。汉志及徐氏之说，自为得实。水经浊漳水注又谓邬是衡水所迳之邬县，此则失之愈远矣。邬县在古大河北，乃赵地。
<a id="L65"></a>
<a id="L66"></a>三十一年，邳迁于薛，改名徐州。
<a id="L67"></a>此显王二十九年，齐威王十七年也。邳即下邳，古邳侯国。奚仲之迁都也，详太康纪。薛即汉志之薛县，夏奚仲之故封也，详外壬纪定公元年。左传。薛宰曰：薛之皇祖奚仲居薛，以为夏车正；奚仲迁邳，仲虺居薛，以为汤左相。盖奚仲本封仲虺城东三里之故薛城地，与鲁之常邑相倚。诗曰：居常与许。春秋庄公三十一年筑。台于薛即此。后奚仲迁于下邳，地，在今之邳州。传曰：商有姚邳，即此。仲虺为汤左相，迁于薛城之西三里，是为上邳，即仲虺城也，俗谓之斗城。周之薛侯皆居此也。春秋时，齐侵薛之西境，谓之舒州，即史记齐世家之徐州也，实为田氏之邑。战国时，齐更东侵至郭，郭乃漷上之邑，近薛城而界于鲁、宋者。左传庄十一年，公败宋师于郭，即此。此靖郭君田婴之封邑也。是时，薛因齐人逼处，复迁居下邳，楚世家所谓邹、费、郯、邳是也。至是年，以下邳封成侯驺忌，邳仍迁于奚仲所居之薛城，统薛郭之地，而皆被以徐州之名，以为田忌之食邑，使檀子守之，而薛乃自此替矣。
<a id="L68"></a>薛君之见于经传者，止献、襄、惠三公，其系次已不可详考。此时之迁，乃齐人迁之，犹春秋时宋之迁宿，齐之迁阳也。至惠王后元十三年，齐封田婴于薛，谓之靖郭君，时薛犹延祀。至宣王之世，更东北侵鲁之常邑，而并于薛，以封田文，而薛乃灭绝。即孟子谓齐人将筑薛是乜。故战国策谓田文为薛公。又曰孟尝君，即今王十九年会于釜邱之薛侯已。
<a id="L69"></a>
<a id="L70"></a>汉书地理志鲁国薛县注云：夏车正奚仲所国，后迁于邳。晋书地道记曰：仲虺城在薛城西三十里。晋太康地记谓田文亦封于古薛城。徐广史记音义以仲虺城为上邳。水经泗水注谓：漷水出东海郡合乡县，西南流入邾，经邹山东南，又西南迳蕃县故城南，又西迳薛县故城北，又西迳仲虺城北，又西迳湖陆县，入泗。汉书后志谓六国。时改名徐州。水经注谓梁惠王时，邳迁于薛，皆是薛县故城。此皆旧说之可据者也。
<a id="L71"></a>
<a id="L72"></a>今薛县故城，在山东滕县南四里，仲虺城在故薛城西三十里。合乡即论语之互乡，在今峄县西北。湖陆即古湖陵，在今鱼台县东。
<a id="L73"></a>
<a id="L74"></a>三月为大沟于北郛，以行圃田之水。
<a id="L75"></a>北郛，梁之北郭也。古制城郭沟池之设，有山川则因之，自文王作丰，筑城伊淢，周公作洛，南系于洛水，北因于郏山，皆此义也。所谓城郭沟池，谓城之外有池，郭之外有沟也。梁城西北有圃田，东北有浚水，自十年入河水于圃田，又为大沟，引水至梁之正南为鸿沟，下通睢，过沙、颍。今又为大沟于北郛，引圃田之水，东合浚水以入汳也。故秦、汉以后，谓梁城为浚仪，即因此被名。水经渠水注引陈留风俗传曰：浚仪县北有浚水，象而仪之，故曰浚仪。郦氏谓即汳沙阴沟。愚按阴沟在开封、陈留之间，首受汳水，西南入鸿沟。沙沟即梁沟，在浚仪、开封之东，首受圃田水，东南为鸿沟，即十年所开掘者。因其近梁城为惠王所掘，故曰梁沟。因其下通沙水，故又曰沙沟。汳水自梁之西北，分受济流，东过大梁、开封、陈留三城之北，又东南入泗。此在梁掘鸿沟以前，非此年之事。此年止是引圃水入汳，或又通浚水，使分承汳流，西南入鸿沟耳。至舆地广记谓浚郊、浚都、寒泉，皆在开封。诗经地理考引李氏说云：浚水出浚仪，经邶地入济，此无足辨矣。
<a id="L76"></a>
<a id="L77"></a>三十二年，与秦战岸门，
<a id="L78"></a>此显王三年，秦孝公二十三年，卫平侯八年也。岸门。之战有二：韩策所谓韩王绝和于秦，秦果大怒，兴师与韩氏战岸门，楚救不至，韩氏大败，此即燕策所云岸门之战也，在梁襄王之时。秦本纪谓孝公二四年，与晋战雁门，虏其将魏错。此即年表所云孝公二三年，与晋战岸门者也，即此年之事矣。索隐以雁门为声之误，本纪谓在明年者，当亦夏正、周正之异。徐广云：岸门即岸亭，在颍阴。正义引括地志云：岸门在许州长社县西北二十八里，名西武亭。
<a id="L79"></a>
<a id="L80"></a>卫平侯卒，子孝襄侯立。
<a id="L81"></a>
<a id="L82"></a>平侯成侯子孝襄侯即嗣君也。卫世家曰：二十九年，成侯卒，子平侯立。平侯八年卒，子嗣君女。索隐曰：乐资据纪年以嗣君即孝襄侯。

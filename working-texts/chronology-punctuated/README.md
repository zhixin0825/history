# 有标点的编年候选底本

**无标点清洁版仅作中间文件、校核对照，不作为正式编年输入。** 本目录采用已有标点文本；程序只处理明确网页标记，不新造句读。

《通鉴》已取得294卷，其中 294 卷通过标点与结构初筛。《春秋左氏传》取得十二公，6 部分初筛通过，其余进入 review/，不可作为合格底本。

**初筛只排除无标点、密集分隔点、模板残留等明显问题，不证明文字、句读、引号和年代全部正确。** 未解决的《左传》部分没有凑进可用目录；上古经传续文也未在这一步重新划分。

现代标点及录入文字的再分发遵循[维基文库版权说明](https://zh.wikisource.org/wiki/Wikisource:版权信息)和各来源页面许可。保留贡献者历史、许可链接及修改说明；改动仅为格式转换和显式标记分层。

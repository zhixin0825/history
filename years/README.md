## 分组规则

一个目录覆盖连续100年，但只放已经写好的年份页。公元前按数字递减阅读，公元后按数字递增阅读；前1年后接公元1年，没有0年。目录名保留四位年份以便检索，例如 `bce-0800-0701`、`ce-0001-0100`。

年页的前后导航连接相邻的**已编年页**，可以跨世纪；目录中没有的年份表示尚无已编页面。

## 分组规则

每个世纪目录覆盖连续100年，只列已有正文。公元前数字递减、公元后递增；前1年后接公元1年，没有0年。未确年的古事置时期页，前后导航连接相邻已编页，可以跨世纪；缺页不伪装成连续覆盖。

秦汉年条沿古史整年对应，不是公历逐日换算。[前206年](bce-0300-0201/bce-0206.md)汉元年十月通常仍属公历前207年；景帝前、中、后三段属于同一君主的年次，不重复生成年度。[秦历口径](../meta/考证/史记-卷006-纪年与异说.md#秦历与年页) · [文帝年次](../meta/考证/史记-卷010-纪年与异说.md#即位与年次) · [景帝年次](../meta/考证/史记-卷011-纪年与异说.md)。

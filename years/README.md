## 编年引文的核对标准

- 同一诏令、奏疏、书信或问答，在相关年页的同号史料中合引，自开头读到文末。确年未明时放在相应时期页。裴注插在中途时照底本次序标明，接续正文。
- 文书追述的往事可以在各自年页节引。注明「节引」并直链完整引文；完整引文和分卷原文能够双向点到。
- 提交前逐条用仓内底本核对引文首尾、正文与裴注的交接，以及两个方向的锚点。遇到引文止于「曰：」「詔曰：」或未合拢的引号，检查后续正文和注文，确认该段在同一个史料块可完整读到。底本原有阙文时注明底本所载的边界。

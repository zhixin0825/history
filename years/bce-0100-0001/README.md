# 公元前100—1年

[← 上一个已有内容的世纪](../bce-0200-0101/README.md) · [全部世纪](../README.md) · [项目首页](../../README.md) · [下一个已有内容的世纪 →](../ce-0001-0100/README.md)

本目录覆盖公元前100年至前1年，现有 **6张年度页**。卷018新增四张有明确侯籍年条的页面，卷019又补前91年；未编的年份不补空白故事。

| 年份 | 本页主线 |
|---|---|
| [公元前98年](bce-0098.md) | 武帝天汉三年，再修封泰山、返祭常山与求仙反思 |
| [公元前93年](bce-0093.md) | 江邹侯靳石因职事案免侯 |
| [公元前91年](bce-0091.md) | 亚谷侯贺牵涉太子事件，卷019后事 |
| [公元前90年](bce-0090.md) | 埤山侯仁与母亲被以祝诅罪追究 |
| [公元前88年](bce-0088.md) | 戴侯蒙因祝诅罪被诛 |
| [公元前87年](bce-0087.md) | 繆侯郦终根被诛，现存功臣表最晚年条 |

前98年据[卷012](../../sources/摘录/史记-卷012-孝武本纪.md#p029)与《汉书·武帝纪》互校，四张新增页据[卷018](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md)及功臣表互见。[全卷去向](../../meta/记录/史记-卷018-引文去向.md)。往前可接[前101年](../bce-0200-0101/bce-0101.md)，前87年以后跳至已有[公元22年](../ce-0001-0100/ce-0022.md)。跳页表示未编，不是这些年份没有历史事件；本世纪及武帝晚年全国史事均未声称完备。

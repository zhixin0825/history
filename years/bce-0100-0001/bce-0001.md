# 公元前1年｜匈奴单于与乌孙大昆弥来朝、调整三公、司直和司隶职掌

[← 公元前2年](bce-0002.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元1年 →](../ce-0001-0100/ce-0001.md)

**汉哀帝元寿二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **匈奴单于与乌孙大昆弥来朝。** 元寿二年正月，匈奴单于与乌孙大昆弥入朝；二月归国，单于不悦，本纪指向《匈奴传》。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **四月日食。** 四月壬辰晦，纪文记日食，沿用原古月和干支。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **调整三公、司直和司隶职掌。** 五月定三公分工，董贤为大司马，孔光为大司徒，彭宣为大司空并封长平侯。整顿司直、司隶，拟置司寇，相关事项尚未定。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **哀帝在未央宫去世。** 元寿二年六月戊午，哀帝死于未央宫。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **葬哀帝于义陵。** 本纪作元寿二年九月壬寅；《资治通鉴》作十月壬寅。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **董贤免官后自杀。** 王政君命董贤交大司马印绶并免官，董贤当日自杀。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **王莽复任大司马。** 哀帝去世后，新都侯王莽任大司马并掌尚书事务。 何武与公孙禄担心外戚辅佐幼主，彼此举荐出任大司马。王莽复任后，两人被劾免职。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **王舜、左咸持节迎中山王。** 七月遣王舜、左咸迎接中山王刘箕子入京。 王莽请太后起用孙宝为光禄大夫，孙宝随王舜等同行。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **赵傅两后退居及外戚免徙。** 赵皇太后降为成帝皇后、退居北宫，哀帝傅皇后退居桂宫。孔乡侯傅晏、董贤之父董恭等免官爵徙合浦。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **刘箕子即位、谒高庙。** 九月辛酉，中山王刘箕子即帝位，谒高庙，大赦。次年改元元始。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **王政君临朝、王莽执政。** 刘箕子即位时年九岁，太皇太后王政君临朝，大司马王莽执政。 王莽利用孔光的旧相声望，借孔光奏劾旧臣；孔光请求退休，改为幼帝太傅。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **诏禁追奏赦前事。** 诏令有司不得重举已赦之旧事，也不得因已赦轻过妨碍选举人才，违令者以不道论。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **刘縯嗣淮阳王。** 刘縯嗣淮阳王。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **刘勋绍封德侯。** 元寿二年五月甲子，侯勳以广玄孙之孙长安公乘接续旧封，千户，九年，王莽夺取皇位，这一支封爵中断。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **黄节侯顺一支去世。** 元寿二年去世，无子嗣承继。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **昌乡侯宪一支封爵后续。** 元寿二年，因……获罪使家丞封上印绶，免去侯爵。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **乐平侯欣一支封爵后续。** 元寿二年改授侯国共乐侯。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **武安侯㥅一支封爵后续。** 元寿二年，因……获罪使家奴杀人免去侯爵，元始元年恢复侯爵，八年免去侯爵。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **四月丁酉分封王子侯。** 《王子侯表》列四月丁酉受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **平阳侯曹本始｜绍封。** 表载平阳侯曹本始一支本年接续了原有封爵。表中所载事项为五月甲子，侯本始因参玄孙之玄孙杜陵公士接续封爵，千户。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **清河定侯王吸｜赐爵。** 表载清河定侯王吸一支本年另获赐爵。表中所载事项为八月，下诏赐予吸代後爵关内获封，不言世。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **颍阴懿侯灌婴｜赐爵。** 表载颍阴懿侯灌婴一支本年另获赐爵。表中所载事项为八月，下诏赐予婴代後者谊爵关内侯。 [[22]](#hs-note-22)

<a id="hs-event-23"></a>

23. **海阳齐信侯摇母余｜赐爵。** 表载海阳齐信侯摇母余一支本年另获赐爵。表中所载事项为八月，下诏赐予母余代後者贤爵关内侯。 [[23]](#hs-note-23)

<a id="hs-event-24"></a>

24. **武阳侯史丹｜承爵。** 表载武阳侯史丹一支本年记载侯位承袭。表中所载事项为侯获承爵。 [[24]](#hs-note-24)

<a id="hs-event-25"></a>

25. **汝昌侯傅商｜绍封。** 表载汝昌侯傅商一支本年接续了原有封爵。表中所载事项为五月，侯昌因商兄子绍奉祀封。 [[25]](#hs-note-25)

<a id="hs-event-26"></a>

26. **汝昌侯傅商｜免爵或免官。** 表载汝昌侯傅商一支本年载免除或失爵。表中所载事项为因罪案非正失爵。 [[26]](#hs-note-26)

<a id="hs-event-27"></a>

27. **阳新侯郑业｜获罪。** 表载阳新侯郑业一支本年载相关罪案及处分。表中所载事项为因罪案非正失爵。 [[27]](#hs-note-27)

<a id="hs-event-28"></a>

28. **方阳侯孙宠｜获罪。** 表载方阳侯孙宠一支本年载相关罪案及处分。表中所载事项为因罪案前为奸谗失爵，徙合浦。 [[28]](#hs-note-28)

<a id="hs-event-29"></a>

29. **宜陵侯息夫躬｜获罪。** 表载宜陵侯息夫躬一支本年载相关罪案及处分。表中所载事项为因罪案祝诅，下狱死。 [[29]](#hs-note-29)

<a id="hs-event-30"></a>

30. **哀帝复置太傅。** 元寿二年，朝廷恢复太傅。 [[30]](#hs-note-30)

<a id="hs-event-31"></a>

31. **廷尉复称大理。** 哀帝又将廷尉更名大理。 [[31]](#hs-note-31)

<a id="hs-event-32"></a>

32. **刺史再改州牧。** 哀帝元寿二年恢复州牧。 [[32]](#hs-note-32)

<a id="hs-event-33"></a>

33. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[33]](#hs-note-33)

<a id="hs-event-34"></a>

34. **彭宣辞大司空，赴长平侯国。** 哀帝去世、王莽掌权后，彭宣主动求退。王莽禀太后收大司空印，命他就国，未按常例赏金车。 [[34]](#hs-note-34)

<a id="hs-event-35"></a>

35. **王莽令劾旧案，毌将隆等免徙。** 王莽借孔光奏劾先朝冯氏之狱及郑崇狱，毌将隆、史立、丁玄、张由、赵昌等被免徙合浦。本传称毌将隆只连署旧案。 [[35]](#hs-note-35)

### 7. 王莽复任大司马

[返回正文第7条](#hs-event-7)

<a id="hs086-l9366-e7"></a>

**[《汉书·何武王嘉师丹传》P012](../../sources/摘录/汉书-卷086-何武王嘉师丹传.md#p012)** · [仓内TXT L9366](../../sources/本地分卷/汉书/汉书-卷086.md#L9366)

> 後數月，哀帝崩，太后即日引莽入，收大司馬董賢印綬，詔有司舉可大司馬者。莽故大司馬，辭位辟丁、傅，眾庶稱以為賢，又太后近親，自大司徒孔光以下舉朝皆舉莽。武為前將軍，素與左將軍公孫祿相善，二人獨謀，以為往時孝惠、孝昭少主之世，外戚呂、霍、上官持權，幾危社稷，今孝成、孝哀比世無嗣，方當選立親近輔幼主，不宜令異姓大臣持權，親疏相錯，為國計便。於是武舉公孫祿可大司馬，而祿亦舉武。太后竟自用莽為大司馬。莽風有司劾奏武、公孫祿互相稱舉，皆免。

**互校说明** 从《哀帝纪》《通鉴》元寿二年哀帝崩、王莽复任。传详何武、公孙禄互举与失官。

### 8. 王舜、左咸持节迎中山王

### 34. 彭宣辞大司空，赴长平侯国

[返回正文第34条](#hs-event-34)

<a id="hs071-l8740-e34"></a>

**[《汉书·隽疏于薛平彭传》P034](../../sources/摘录/汉书-卷071-隽疏于薛平彭传.md#p034)** · [仓内TXT L8740](../../sources/本地分卷/汉书/汉书-卷071.md#L8740)

> 會哀帝崩，新都侯王莽為大司馬，秉政專權。宣上書言：「三公鼎足承君，一足不任，則覆亂美實。臣資性淺薄，年齒老眊，數伏疾病，昏亂遺忘，願上大司空、長平侯印綬，乞骸骨歸鄉里，俟置溝壑。」莽白太后，策宣曰：「惟君視事日寡，功德未效，迫於老眊昏亂，非所以輔國家、綏海內也。使光祿勳豐冊詔君，其上大司空印綬，便就國。」莽恨宣求退，故不賜黃金、安車駟馬。

**互校说明** 《通鉴》卷035于元寿二年八月记；卷019同月以王崇继彭宣。

### 35. 王莽令劾旧案，毌将隆等免徙

[返回正文第35条](#hs-event-35)

**[《汉书·盖诸葛刘郑孙毋将何传》P035](../../sources/摘录/汉书-卷077-盖诸葛刘郑孙毋将何传.md#p035)** · [仓内TXT L9047](../../sources/本地分卷/汉书/汉书-卷077.md#L9047)

> 哀帝崩，莽秉政，使大司徒孔光奏隆前為冀州牧治中山馮太后獄冤陷無辜，不宜處位在中土。本中謁者令史立、侍御史丁玄自典考之，但與隆連名奏事。史立時為中太僕，丁玄泰山太守，及尚書令趙昌譖鄭崇者為河內太守，皆免官，徙合浦。

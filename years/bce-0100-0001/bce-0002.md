# 公元前2年｜日食、求谏与大赦、皇太太后傅氏去世

[← 公元前3年](bce-0003.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前1年 →](bce-0001.md)

**汉哀帝元寿元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **日食、求谏与大赦。** 元寿元年正月辛丑朔，纪文记日食。哀帝自责施政失当，责公卿任仁厚之人、罢黜残酷官吏、举荐贤良方正敢直言者，允许直陈皇帝过失，并大赦。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **皇太太后傅氏去世。** 丁巳，哀帝祖母傅氏去世，仍按本纪所用皇太太后名号称呼。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **丞相王嘉死于狱中。** 三月丞相王嘉获罪下狱而死；《恩泽侯表》和本传另详其案。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **丁明被免。** 秋九月，大司马骠骑将军丁明被免官。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **孝元庙门铜铺首鸣。** 孝元庙殿门上龟蛇形铜质铺首发声，作为本纪灾异记载保存。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **刘纡嗣楚王。** 刘纡嗣楚王。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **五月乙卯分封王子侯。** 《王子侯表》列五月乙卯受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **高昌壮侯董忠｜承爵。** 表载高昌壮侯董忠一支本年记载侯位承袭。表中所载事项为侯武承爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **博山简烈侯孔光｜复封。** 表载博山简烈侯孔光一支本年恢复先前中断的封爵。表中所载事项为五月乙卯复因丞相侯。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **汝昌侯傅商｜获罪。** 表载汝昌侯傅商一支本年载相关罪案及处分。表中所载事项为因罪案外附诸侯失爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **护军都尉更名司寇。** 哀帝改护军都尉为司寇。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **岁星入太微犯右执法。** 《汉书》在本年记载岁星入太微犯右执法。 [[13]](#hs-note-13)

> 元壽元年春正月辛丑朔，日有蝕之。詔曰：「朕獲保宗廟，不明不敏，宿夜憂勞，未皇寧息。惟陰陽不調，元元不贍，未睹厥咎。婁敕公卿，庶幾有望。至今有司執法，未得其中，或上暴虐，假勢獲名，溫良寬柔，陷於亡滅。是故殘賊彌長，和睦日衰，百姓愁怨，靡所錯躬。乃正月朔，日有蝕之，厥咎不遠，在余一人。公卿大夫其各悉心勉帥百寮，敦任仁人，黜遠殘賊，期於安民。陳朕之過失，無有所諱。其與將軍、列侯、中二千石舉賢良方正能直言者各一人。大赦天下。」

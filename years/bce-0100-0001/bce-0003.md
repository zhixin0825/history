# 公元前3年｜旱灾与西王母筹、傅商封汝昌侯

[← 公元前4年](bce-0004.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前2年 →](bce-0002.md)

**汉哀帝建平四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **旱灾与西王母筹。** 建平四年春大旱，关东民众传递西王母筹，经过郡国入关至京师，聚集祭祀；也有夜里持火登屋、击鼓呼叫的记载。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **傅商封汝昌侯。** 建平四年二月，封傅太后的堂弟傅商为汝昌侯。《恩泽侯表》具二月癸卯。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **郑业受封。** 建平四年，傅太后的外甥郑业受封。本纪把郑业与傅商并书在二月，作阳信侯；《恩泽侯表》系八月辛卯，作阳新侯。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **董贤等因东平王案受封。** 三月董贤、息夫躬、孙宠因告发东平王而封列侯；《恩泽侯表》列受封于同年八月辛卯；告发与上一年本案处置分年。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **赐官吏和成年男子爵。** 五月赐中二千石至六百石官员及天下男子爵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **进傅氏为皇太太后。** 六月将帝太太后傅氏进尊为皇太太后，区别于王政君的太皇太后。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **恭皇陵园北门失火。** 八月恭皇陵园北门失火。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **荐明兵法者。** 冬，命将军和中二千石官员荐通兵法、有远谋的人。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **刘永嗣淄川王。** 刘永嗣淄川王。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **刘嘉嗣广阳王。** 刘嘉嗣广阳王。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **三月丁卯分封王子侯。** 《王子侯表》列三月丁卯受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **五月丙午分封王子侯。** 《王子侯表》列五月丙午受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **阳平顷侯王禁｜承爵。** 表载阳平顷侯王禁一支本年记载侯位承袭。表中所载事项为康侯岑承爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **山阳湖陵雨血的记录。** 《汉书》在本年记载山阳湖陵雨血的记录。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **山阳方与诞育异常传闻。** 《汉书》在本年记载山阳方与诞育异常传闻。 [[16]](#hs-note-16)

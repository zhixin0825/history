# 公元前4年｜刘广汉立广平王、桂宫正殿失火

[← 公元前5年](bce-0005.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前3年 →](bce-0003.md)

**汉哀帝建平三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **刘广汉立广平王。** 建平三年正月，立广德夷王刘云客的弟弟刘广汉为广平王，另立广平一支。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **桂宫正殿失火。** 癸卯，帝太太后傅氏所住的桂宫正殿失火。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **丞相平当去世。** 三月己酉，丞相平当去世。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **河鼓见孛星。** 本纪本年三月条记河鼓附近有孛星。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘闵绍封鲁王。** 六月立鲁顷王之子、郚乡侯刘闵为王；《诸侯王表》具六月辛卯；鲁文王无子后，立其弟刘闵承封。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **复甘泉泰畤、汾阴后土祠。** 十一月壬子，恢复甘泉泰畤及汾阴后土祭祀，撤长安南北郊。此事与绥和二年恢复南北郊方向相反。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **东平王刘云案。** 东平王刘云、王后谒及安成恭侯夫人放获罪；刘云自杀，谒与放在市中处决。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **昌成节侯元一支去世。** 建平三年去世，无子嗣承继。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **宜春敬侯王欣｜承爵。** 表载宜春敬侯王欣一支本年记载侯位承袭。表中所载事项为侯强承爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **新甫侯王嘉｜受封。** 《汉书》侯籍列新甫侯王嘉本年受封，所引月份、干支依表保留。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **零陵倒木记录。** 《汉书》在本年记载零陵倒木记录。 [[12]](#hs-note-12)

### 7. 东平王刘云案

[返回正文第7条](#hs-event-7)

<a id="hs045-l7485-e7"></a>

**[《汉书·蒯伍江息夫传》P017](../../sources/摘录/汉书-卷045-蒯伍江息夫传.md#p017)** · [仓内TXT L7485](../../sources/本地分卷/汉书/汉书-卷045.md#L7485)

> 是後無鹽危山有石自立，開道。躬與寵謀曰：「上亡繼嗣，體久不平，關東諸侯，心爭陰謀。今無鹽有大石自立，聞邪臣託往事，以為大山石立而先帝龍興。東平王雲以故與其后日夜祠祭祝詛上，欲求非望。而后舅伍宏反因方術以醫技得幸，出入禁門。霍顯之謀將行於杯杓，荊軻之變必起於帷幄。事勢若此，告之必成；發國姦，誅主讎，取封侯之計也。」躬、寵乃與中郎右師譚，共因中常侍宋弘上變事告焉。上惡之，下有司案驗，東平王雲、雲后謁及伍宏等皆坐誅。上擢寵為南陽太守，譚穎川都尉，弘、躬皆光祿大夫左曹給事中。

<a id="hs011-l1026-e7"></a>

**[《汉书·哀帝纪》P029](../../sources/摘录/汉书-卷011-哀帝纪.md#p029)** · [仓内TXT L1026](../../sources/本地分卷/汉书/汉书-卷011.md#L1026)

> 東平王雲、雲后謁、安成恭侯夫人放皆有罪。雲自殺，謁、放棄市。

**互校说明** 后一年董贤等因告发本案而受封，属于后续奖赏。

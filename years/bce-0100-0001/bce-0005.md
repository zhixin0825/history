# 公元前5年｜罢大司空复御史大夫、改尊傅丁并在京师立恭皇庙

[← 公元前6年](bce-0006.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前4年 →](bce-0004.md)

**汉哀帝建平二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **罢大司空复御史大夫。** 建平二年三月撤大司空、恢复御史大夫，元寿二年另有改回大司空之举。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **改尊傅丁并在京师立恭皇庙。** 四月，去恭皇帝号前的“定陶”，尊傅氏为帝太太后、丁氏为帝太后，立恭皇庙于京师。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **四月赦天下徒。** 建平二年四月，赦免天下徒囚。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **罢州牧复刺史。** 朝廷撤州牧恢复刺史，改回地方监察官的旧名制。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **帝太后丁氏去世。** 六月庚申，哀帝生母丁氏去世。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **葬丁太后于定陶恭皇陵园。** 哀帝据古礼决定丁太后葬在恭皇陵园，发陈留、济阴等地五万人治葬。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **夏贺良等倡太初元将改制。** 夏贺良等引赤精子谶说汉朝需要再受天命，哀帝诏大赦，将建平二年改为太初元将元年，自号陈圣刘太平皇帝，将漏刻尺度改作一百二十。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **择渭城陵地而不徙民。** 七月选渭城西北原永陵亭部为初陵之地，下令不迁郡国百姓。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **撤太初元将改制并治夏贺良案。** 八月诏称所行无效又背古，撤六月甲子诏书及相应改制，把夏贺良等交有司治罪。原文“非赦令也”有不算赦令、赦令除外两解；与同书《李寻传》和《通鉴》合读。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **朱博自杀、赵玄傅晏受罚。** 丞相朱博、御史大夫赵玄、孔乡侯傅晏获罪。朱博自杀，赵玄减死罪二等，傅晏削四分之一食户。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **刘尚嗣河间王。** 刘尚嗣河间王。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **刘景迁信都王。** 刘景迁信都王。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **五月丁酉分封王子侯。** 《王子侯表》列五月丁酉受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **高昌壮侯董忠｜复封。** 表载高昌壮侯董忠一支本年恢复先前中断的封爵。表中所载事项为复封故国。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **邛成共侯王奉光｜获罪。** 表载邛成共侯王奉光一支本年载相关罪案及处分。表中所载事项为因罪案选举不因实，骂廷史，大不敬，失爵。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **安昌节侯张禹｜承爵。** 表载安昌节侯张禹一支本年记载侯位承袭。表中所载事项为侯宏承爵。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **博山简烈侯孔光｜获罪。** 表载博山简烈侯孔光一支本年载相关罪案及处分。表中所载事项为因罪案衆职废，失爵。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **杨乡侯朱博｜受封。** 表载杨乡侯朱博一支本年有始封记载。表中所载事项为四月乙亥封。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **大司马复冠将军号。** 大司马去印绶和属官，恢复冠将军号。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **恢复长、相黄绶。** 哀帝恢复长、相的黄绶。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **彗星见于牵牛。** 《汉书》在本年记载彗星见于牵牛。 [[22]](#hs-note-22)

<a id="hs-event-23"></a>

23. **朱博和赵玄受策时殿内钟状异声。** 《汉书》在本年记载朱博和赵玄受策时殿内钟状异声。 [[23]](#hs-note-23)

<a id="hs-event-24"></a>

24. **定襄三足马驹的记录。** 《汉书》在本年记载定襄三足马驹的记录。 [[24]](#hs-note-24)

### 7. 夏贺良等倡太初元将改制

[返回正文第7条](#hs-event-7)

<a id="hs011-l1017-e7"></a>

**[《汉书·哀帝纪》P020](../../sources/摘录/汉书-卷011-哀帝纪.md#p020)** · [仓内TXT L1017](../../sources/本地分卷/汉书/汉书-卷011.md#L1017)

> 侍詔夏賀良等言赤精子之讖，漢家曆運中衰，當再受命，宜改元易號。詔曰：「漢興二百載，曆數開元。皇天降非材之佑，漢國再獲受命之符，朕之不德，曷敢不通！夫基事之元命，必與天下自新，其大赦天下。以建平二年為太初元將元年。號曰陳聖劉太平皇帝。漏刻以百二十為度。」

**互校说明** 《天文志》L5420及下文L1019可定改令为六月甲子；在八月撤销，与建平二年同年，不另立公元年。

> 四月戊午，大司空博為御史大夫，乙亥遷。中尉趙玄為御史大夫，五月下獄論。九月乙酉，諸吏散騎光祿勳平當為御史大夫，二月遷。十月丙寅，京兆尹王嘉為御史大夫，一年遷。

第5栏

> 光祿勳丁望為左將軍卒。執金吾公孫祿為右將軍，一年遷。

第7栏

> 衞尉望為光祿勳，一月遷。光祿大夫平當為光祿勳，四月遷。

第8栏

> 少府賈延為衞尉，十一月還故官。執金吾孫雲為衞尉，四年遷。

第9栏

> 城門校尉丁憲子尉為太僕，四年遷。

第11栏

> 大鴻臚雲陽畢申世叔，五年徙。

第13栏

> 衞尉賈延為少府，一年遷。五官中郎將潁川公孫祿中子為執金吾。

第14栏

> 侍中水衡都尉讓。大鴻臚謝堯為扶風，一年遷。

# 公元前5年｜罢大司空复御史大夫、改尊傅丁并在京师立恭皇庙

[← 公元前6年](bce-0006.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前4年 →](bce-0004.md)

**汉哀帝建平二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **罢大司空复御史大夫。** 建平二年三月撤大司空、恢复御史大夫，元寿二年另有改回大司空之举。 朱博奏称御史大夫督百官，又是拜相选序中的一职，应恢复旧制。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **改尊傅丁并在京师立恭皇庙。** 四月，去恭皇帝号前的“定陶”，尊傅氏为帝太太后、丁氏为帝太后，立恭皇庙于京师。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **四月赦天下徒。** 建平二年四月，赦免天下徒囚。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **罢州牧复刺史。** 朝廷撤州牧恢复刺史，改回地方监察官的旧名制。 朱博认为州牧秩高，容易安位不求功绩，提议恢复刺史，获准。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **帝太后丁氏去世。** 六月庚申，哀帝生母丁氏去世。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **葬丁太后于定陶恭皇陵园。** 哀帝据古礼决定丁太后葬在恭皇陵园，发陈留、济阴等地五万人治葬。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **夏贺良等倡太初元将改制。** 夏贺良等用赤精子谶说劝哀帝重新受命。哀帝大赦，改元太初元将，自号陈圣刘太平皇帝，并把漏刻尺度改作一百二十。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **择渭城陵地而不徙民。** 七月选渭城西北原永陵亭部为初陵之地，下令不迁郡国百姓。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **撤太初元将改制并治夏贺良案。** 八月诏称所行无效又背古，撤六月甲子诏书及相应改制，把夏贺良等交有司治罪。原文“非赦令也”有不算赦令、赦令除外两解；与同书《李寻传》和《通鉴》合读。 夏贺良等再欲更置辅政，哀帝撤改制并下狱；贺良等被诛，李寻、解光减死徙敦煌。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **朱博自杀、赵玄傅晏受罚。** 朱博、赵玄奏请夺傅喜、何武的侯爵。哀帝查问后追究朱博、赵玄、傅晏。朱博自杀，傅晏削四分之一食户，赵玄免死降罪。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **刘尚嗣河间王。** 刘尚嗣河间王。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **刘景迁信都王。** 刘景迁信都王。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **五月丁酉分封王子侯。** [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **高昌壮侯董忠｜复封。** 表载高昌壮侯董忠一支本年恢复先前中断的封爵。表中所载事项为复封故国。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **邛成共侯王奉光｜获罪。** 表载邛成共侯王奉光一支本年载相关罪案及处分。表中所载事项为因罪案选举不因实，骂廷史，大不敬，失爵。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **安昌节侯张禹｜承爵。** 表载安昌节侯张禹一支本年记载侯位承袭。表中所载事项为侯宏承爵。 张禹于本年去世，谥节侯，长子张宏承袭。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **博山简烈侯孔光｜获罪。** 表载博山简烈侯孔光一支本年载相关罪案及处分。表中所载事项为因罪案衆职废，失爵。 孔光因抵制傅太后称尊号等事遭毁谮，被收相印与侯印。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **杨乡侯朱博｜受封。** 表载杨乡侯朱博一支本年有始封记载。表中所载事项为四月乙亥封。 朱博承傅氏之意取代孔光，封阳乡侯，继而辞让部分食邑。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **大司马复冠将军号。** 大司马去印绶和属官，恢复冠将军号。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **恢复长、相黄绶。** 哀帝恢复长、相的黄绶。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 彭宣被收左将军印，以关内侯归里；诏书所举原因为王国籍贯及其子与淮阳王家的婚姻。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **彗星见于牵牛。** [[22]](#hs-note-22)

<a id="hs-event-23"></a>

23. **朱博和赵玄受策时殿内钟状异声。** 四月乙亥朔，朱博与赵玄在前殿受策，殿中郎吏听到钟鸣般的巨响。 [[23]](#hs-note-23)

<a id="hs-event-24"></a>

24. **定襄三足马驹的记录。** 定襄太守上报，当地有三足马驹，能随群饮食。 [[24]](#hs-note-24)

<a id="hs-event-25"></a>

25. **傅喜免大司马并被遣就国。** 傅喜反对傅太后求与成帝母并尊。师丹已先被免，哀帝本年收傅喜大司马印，傅太后又遣傅喜就侯国，但其侯爵仍在。 [[25]](#hs-note-25)

<a id="hs-event-26"></a>

26. **汉遣使责匈奴归还乌孙人质。** 乌孙卑援疐翕侯部众掠匈奴，单于反击，卑援疐献子趋逯为质。汉遣丁野林、公乘音令单于归还趋逯，单于遵命。 [[26]](#hs-note-26)

<a id="hs-event-27"></a>

27. **王莽与王仁被遣就国。** 有司追论王莽拒傅丁尊号以及王仁藏匿赵昭仪亲属，令各就侯国，当时亦有为王氏称冤的意见。 [[27]](#hs-note-27)

### 1. 罢大司空复御史大夫

[返回正文第1条](#hs-event-1)

<a id="hs083-l9255-e1"></a>

**[《汉书·薛宣朱博传》P031](../../sources/摘录/汉书-卷083-薛宣朱博传.md#p031)** · [仓内TXT L9255](../../sources/本地分卷/汉书/汉书-卷083.md#L9255)

> 後二歲餘，朱博為大司空，奏言「帝王之道不必相襲，各繇時務。高皇帝以聖德受命，建立鴻業，置御史大夫，位次丞相，典正法度，以職相參，總領百官，上下相監臨，歷載二百年，天下安寧。今更為大司空，與丞相同位，未獲嘉祐。故事，選郡國守相高第為中二千石，選中二千石為御史大夫，任職者為丞相，位次有序，所以尊聖德，重國相也。今中二千石未更御史大夫而為丞相，權輕，非所以重國政也。臣愚以為大司空官可罷，復置御史大夫，遵奉舊制。臣願盡力，以御史大夫為百僚率。」哀帝從之，乃更拜博為御史大夫。

**互校说明** 《哀帝纪》建平二年三月先复御史大夫官，官表四月戊午朱博正式拜任。

### 7. 夏贺良等倡太初元将改制

[返回正文第7条](#hs-event-7)

**异文与补证** 《李寻传》所录诏书引用《尚书》和历数申说再受命。

**[《汉书·眭两夏侯京翼李传》P057](../../sources/摘录/汉书-卷075-眭两夏侯京翼李传.md#p057)** · [仓内TXT L8945](../../sources/本地分卷/汉书/汉书-卷075.md#L8945)

> 尋遂白賀良等皆待詔黃門，數召見，陳說「漢曆中衰，當更受命。成帝不應天命，故絕嗣。今陛下久疾，變異屢數，天所以譴告人也。宜急改元易號，乃得延年益壽，皇子生，災異息矣。得道不得行，咎殃且亡，不有洪水將出，災火且起，滌盪人民。」

### 27. 王莽与王仁被遣就国

[返回正文第27条](#hs-event-27)

<a id="hs098-l10302-e27"></a>

**[《汉书·元后传》P028](../../sources/摘录/汉书-卷098-元后传.md#p028)** · [仓内TXT L10302](../../sources/本地分卷/汉书/汉书-卷098.md#L10302)

> 後二歲，傅太后、帝母丁姬皆稱尊號。有司奏：「新都侯莽前為大司馬，貶抑尊號之議，虧損孝道，及平阿侯仁臧匿趙昭儀親屬，皆就國。」天下多冤王氏。

**互校说明** 《通鉴》建平二年；傅丁尊号、京师立恭皇庙见本年另一条。

<a id="hs099-l10322-e27"></a>

**[《汉书·王莽传》P006](../../sources/摘录/汉书-卷099-王莽传.md#p006)** · [仓内TXT L10322](../../sources/本地分卷/汉书/汉书-卷099.md#L10322)

> 時哀帝祖母定陶傅太后、母丁姬在，高昌侯董宏上書言：「春秋之義，母以子貴，丁姬宜上尊號。」莽與師丹共劾宏誤朝不道，語在《丹傳》。後日，未央宮置酒，內者令為傅太后張幄，坐於太皇太后坐旁。莽案行，責內者令曰：「定陶太后藩妾，何以得與至尊並！」徹去，更設坐。傅太后聞之，大怒，不肯會，重怨恚莽。莽復乞骸骨，哀帝賜莽黃金五百斤，安車駟馬，罷就第。公卿大夫多稱之者，上乃加恩寵，置使家中黃門十日一賜餐。下詔曰：「新都侯莽憂勞國家，執義堅固，朕庶幾與為治。太皇太后詔莽就第，朕甚閔焉。其以黃郵聚戶三百五十益封莽，位特進，給事中，朝朔望見禮如三公，車駕乘綠車從。」後二歲，傅太后、丁姬皆稱尊號，丞相朱博奏：「莽前不廣尊尊之義，抑貶尊號，虧損孝道，當伏顯戮，幸蒙赦令，不宜有爵土，請免為庶人。」上曰：「以莽與太皇太后有屬，勿免，遣就國。」

**互校说明** 列传剪接多事，就国从《通鉴》建平二年。

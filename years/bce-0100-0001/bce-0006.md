# 公元前6年｜建平元年正月大赦、赵钦、赵訢失爵并徙辽西

[← 公元前7年](bce-0007.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前5年 →](bce-0005.md)

**汉哀帝建平元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **建平元年正月大赦。** 建平元年正月大赦天下。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **赵钦、赵訢失爵并徙辽西。** 新成侯赵钦、成阳侯赵訢获罪免为庶人，徙辽西。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **王氏外家田给贫民。** 太皇太后王政君下令把王家除坟墓外的田地分给贫民。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **诏荐孝悌直言通政者。** 二月命大司马、列侯、将军、中二千石、州牧、郡守及国相，各荐一名孝悌敦厚、敢直言、通政务、可亲近百姓者，也可从未显达的人中举荐。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **赐王侯和官员财物。** 三月按身份赏诸侯王、公主、列侯以及从丞相将军到京署郎吏金钱布帛。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **冯媛与冯参之死。** 冬，中山孝王之母冯媛、宜乡侯冯参遭追治，本纪称两人自杀。《外戚传》详记调查与逼迫过程。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **成献侯喜一支去世。** 建平元年去世，无子嗣承继。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **高昌壮侯董忠｜获罪。** 表载高昌壮侯董忠一支本年载相关罪案及处分。表中所载事项为因罪案佞邪，失爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **义成侯甘延寿｜改封。** 表载义成侯甘延寿一支本年爵号或封邑改易。表中所载事项为节侯迁承爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **富平敬侯张安世｜改封。** 表载富平敬侯张安世一支本年爵号或封邑改易。表中所载事项为侯纯承爵，王莽。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **成都景成侯王商｜绍封。** 表载成都景成侯王商一支本年接续了原有封爵。表中所载事项为侯邑因况弟接续封爵。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **曲阳炀侯王根｜承爵。** 表载曲阳炀侯王根一支本年记载侯位承袭。表中所载事项为侯涉承爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **师丹因漏泄被免。** 《恩泽侯表》将师丹因漏泄获免列建平元年。后来改封义阳侯，另见元始三年。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **高武贞侯傅喜｜受封。** 表载高武贞侯傅喜一支本年有始封记载。表中所载事项为正月丁酉封。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[15]](#hs-note-15)

# 公元前7年｜丞相翟方进自杀、成帝在未央宫去世

[← 公元前8年](bce-0008.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前6年 →](bce-0006.md)

**汉成帝绥和二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **甘泉郊泰畤。** 正月赴甘泉祭泰畤。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **丞相翟方进自杀。** 本纪记丞相翟方进二月壬子薨。《天文志》作乙丑并记自杀，翟方进本传详记受赐册后即日自杀。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **河东祠后土。** 三月赴河东祭后土。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **成帝在未央宫去世。** 三月，本纪载成帝丙戌在未央宫去世。《通鉴考异》另列荀悦《汉纪》的异日。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **恢复长安南北郊祭。** 皇太后下诏恢复长安南北郊祭。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **葬成帝于延陵。** 本纪载四月己卯葬延陵。《通鉴考异》指出该月无己卯并列异说，干支按引文照录。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **刘欣即位并尊王、赵两太后。** 四月丙午，刘欣即位、谒高庙。成帝生母王政君进尊太皇太后，成帝皇后赵氏进尊皇太后。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **哀帝即位后大赦并赐爵。** 哀帝大赦，赏宗室王子车马、吏民爵，另按身份赐牛酒与布帛。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **尊定陶恭王为恭皇。** 王政君下诏尊刘欣生父定陶恭王刘康为恭皇。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **傅氏立为皇后。** 五月丙戌，刘欣立傅氏为皇后。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **尊生母丁姬与祖母傅太后。** 哀帝尊祖母傅氏为恭皇太后，尊生母丁姬为恭皇后，官属与邑入比照皇太后与皇后。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **傅、丁、赵氏封侯与追尊。** 朝廷追尊傅氏、丁氏之父，分别封丁明、丁满、傅晏、赵钦，并追谥丁忠。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **罢乐府。** 六月哀帝以郑声淫乱雅乐为由下诏裁撤乐府。《礼乐志》保存具体减员，仍保留并改隶一部分祭祀、礼仪与武乐人员。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **王根、王舜等增封。** 曲阳侯王根因先前参与定储增封二千户，太仆安阳侯王舜因辅导有旧恩增五百户；丞相孔光和大司空、氾乡侯何武各增千户。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **河间王刘良增封。** 诏称河间王刘良为母服丧三年，可作宗室表率，增封一万户。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **议限田与奴婢数额。** 朝廷命议限制豪富名田、蓄奴婢。臣下按身份定名田地域和名田、蓄奴婢上限，并拟禁商人名田、为吏。《食货志》及《通鉴》明载限田议因贵戚反对而搁置。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **罢繁织、废任子及增低秩吏俸等。** 本纪续列停织部分繁缛服饰、废任子及诽谤诋欺法、遣部分宫人归嫁、释年老官奴婢、禁贡珍兽、增低秩吏俸、退酷吏、禁追赦前事及给博士弟子守丧假等。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **王根就国、王况免爵。** 秋，曲阳侯王根和成都侯王况获罪；王根遣就封国，王况削爵为民并还原籍。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **河南颍川洪灾与蠲免租赋。** 诏把天象、地动与洪水视为警告。河南、颍川洪水毁屋并致人死亡，光禄大夫巡察登记，给每位死者棺钱三千；受灾达四成的地方，家资不足十万者免本年租赋。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **刘箕子嗣中山王。** 中山孝王刘兴之子刘箕子三岁继承中山王。《诸侯王表》卷014 L1502系绥和二年。父王去世另见前8年。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **刘杨嗣真定王。** 刘杨嗣真定王。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **高阳侯薛宣｜获罪。** 表载高阳侯薛宣一支本年载相关罪案及处分。表中所载事项为因罪案不忠孝，父子贼伤近臣，失爵。 [[22]](#hs-note-22)

<a id="hs-event-23"></a>

23. **翟宣承高陵侯。** 前7年翟方进去世后，翟宣承高陵侯；表另叙翟义起兵及灭宗，属于居摄元年前后的另一阶段。 [[23]](#hs-note-23)

<a id="hs-event-24"></a>

24. **博山简烈侯孔光｜受封。** 《汉书》侯籍列博山简烈侯孔光本年受封，所引月份、干支依表保留。 [[24]](#hs-note-24)

<a id="hs-event-25"></a>

25. **高乐节侯师丹｜受封。** 表载高乐节侯师丹一支本年有始封记载。表中所载事项为七月庚午封。 [[25]](#hs-note-25)

<a id="hs-event-26"></a>

26. **哀帝恢复司隶。** 恢复司隶官，改称司隶，属大司空。 [[26]](#hs-note-26)

<a id="hs-event-27"></a>

27. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[27]](#hs-note-27)

<a id="hs-event-28"></a>

28. **哀帝初年恢复方术诸祠。** 本志叙哀帝即位前后重广祠官，七百余处与岁祠三万七千乃总数；独立具体月日不详。 [[28]](#hs-note-28)

<a id="hs-event-29"></a>

29. **荧惑守心。** 《汉书》在本年记载荧惑守心。 [[29]](#hs-note-29)

<a id="hs-event-30"></a>

30. **天水平襄燕生雀的记录。** 《汉书》在本年记载天水平襄燕生雀的记录。 [[30]](#hs-note-30)

<a id="hs-event-31"></a>

31. **王褒闯北司马门。** 《汉书》在本年记载王褒闯北司马门。 [[31]](#hs-note-31)

<a id="hs-event-32"></a>

32. **平当议疏河与贾让水利三策。** 平当请访疏河之士。待诏贾让提出迁居民并改河、分洪引灌、增筑旧堤三策，既有意见之利害分载于同条。 [[32]](#hs-note-32)

<a id="hs-event-33"></a>

33. **哀帝初使刘歆续校藏书。** 刘歆字子骏，善《诗》《书》和属文，成帝时任黄门郎，河平间随父校秘藏，涉经传、诸子、诗赋、术数、方技。父卒后任中垒校尉；哀帝初经王莽荐升侍中等职，主持五经校理并分类编为《七略》。 [[33]](#hs-note-33)

> 治河有上中下策。古者立國居民，疆理土地，必遺川澤之分，度水勢所不及。大川無防，小水得入，陂障卑下，以為汙澤，使秋水多，得有所休息，左右游波，寬緩而不迫。夫土之有川，猶人之有口也。治土而防其川，猶止兒啼而塞其口，豈不遽止，然其死可立而待也。故曰：「善為川者，決之使道；善為民者，宣之使言。」蓋隄防之作，近起戰國，雍防百川，各以自利。齊與趙、魏，以河為竟。趙、魏瀕山，齊地卑下，作隄去河二十五里。河水東抵齊隄，則西泛趙、魏，趙、魏亦為隄去河二十五里。雖非其正，水尚有所游盪。時至而去，則填淤肥美，民耕田之。或久無害，稍築室宅，遂成聚落。大水時至漂沒，則更起隄防以自救，稍去其城郭，排水澤而居之，湛溺自其宜也。今隄防骥者去水數百步，遠者數里。近黎陽南故大金隄，從河西西北行，至西山南頭，乃折東，與東山相屬。民居金隄東，為廬舍，住十餘歲更起隄，從東山南頭直南與故大隄會。又內黃界中有澤，方數十里，環之有隄，往十餘歲太守以賦民，民今起廬舍其中，此臣親所見者也。東郡白馬故大隄亦復數重，民皆居其間。從黎陽北盡魏界，故大隄去河遠者數十里，內亦數重，此皆前世所排也。河從河內北至黎陽為石隄，激使東抵東郡平剛；又為石隄，使西北抵黎陽、觀下；又為石隄，使東北抵東郡津北；又為石隄，使西北抵魏郡昭陽；又為石隄，激使東北。百餘里間，河再西三東，迫阨如此，不得安息。

**互校说明** 本志仅说哀帝初，《资治通鉴》卷033排在绥和二年哀帝即位后。

<a id="hs029-l6122-e32"></a>

**[《汉书·沟洫志》P028](../../sources/摘录/汉书-卷029-沟洫志.md#p028)** · [仓内TXT L6122](../../sources/本地分卷/汉书/汉书-卷029.md#L6122)

> 今行上策，徙冀州之民當水衝者，決黎陽遮害亭，放河使北入海。河西薄大山，東薄金隄，勢不能遠泛濫，期月自定。難者將曰：「若如此，敗壞城郭田廬冢墓以萬數，百姓怨恨。」昔大禹治水，山陵當路者毀之，故鑿龍門，辟伊闕，析底柱，破碣石，墮斷天地之性。此乃人功所造，何足言也！今瀕河十郡治隄歲費且萬萬，及其大決，所殘無數。如出數年治河之費，以業所徙之民，遵古聖之法，定山川之位，使神人各處其所，而不相奸。且以大漢方制萬里，豈其與水爭咫尺之地哉？此功一立，河定民安，千載無患，故謂之上策。

**互校说明** 本志仅说哀帝初，《资治通鉴》卷033排在绥和二年哀帝即位后。

<a id="hs029-l6123-e32"></a>

**[《汉书·沟洫志》P029](../../sources/摘录/汉书-卷029-沟洫志.md#p029)** · [仓内TXT L6123](../../sources/本地分卷/汉书/汉书-卷029.md#L6123)

> 若乃多穿漕渠於冀州地，使民得以溉田，分殺水怒，雖非聖人法，然亦救敗術也。難者將曰：「河水高於平地，歲增隄防，猶尚決溢，不可以開渠。」臣竊按視遮害亭西十八里，至淇水口，乃有金隄，高一丈。自是東，地稍下，隄稍高，至遮害亭，高四五丈。往六七歲，河水大盛，增丈七尺，壞黎陽南郭門，入至隄下。水未踰隄二尺所，從隄上北望，河高出民屋，百姓皆走上山。水留十三日，隄潰二所，吏民塞之。臣循隄上，行視水勢，南七十餘里，至淇口，水適至隄半，計出地上五尺所。今可從淇口以東為石隄，多張水門。初元中，遮害亭下河去隄足數十步，至今四十餘歲，適至隄足。由是言之，其地堅矣。恐議者疑河大川難禁制，滎陽漕渠足以下之，其水門但用木與土耳，今據堅地作石隄，勢必完安。冀州渠首盡當卬此水門。治渠非穿地也，但為東方一隄，北行三百餘里，入漳水中，其西因山足高地，諸渠皆往往股引取之；旱則開東方下水門溉冀州，水則開西方高門分河流。通渠有三利，不通有三害。民常罷於救水，半失作業；水行地上，湊潤上徹，民則病溼氣，木皆立枯，鹵不生穀；決溢有敗，為魚鱉食：此三害也。若有渠溉，則鹽鹵下溼，填淤加肥；故種禾麥，更為岻稻，高田五倍，下田十倍；轉漕舟船之便：此三利也。今瀕河隄吏卒郡數千人，伐買薪石之費歲數千萬，足以通渠成水門；又民利其溉灌，相率治渠，雖勞不罷。民田適治，河隄亦成，此誠富國安民，興利除害，支數百歲，故謂之中策。

**互校说明** 本志仅说哀帝初，《资治通鉴》卷033排在绥和二年哀帝即位后。

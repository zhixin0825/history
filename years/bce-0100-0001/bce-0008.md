**汉成帝绥和元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

## 本年概述

成帝立定陶王刘欣为太子，改立刘景为定陶王。朝廷调整三公、州牧与王国官属，淳于长获罪下狱。匈奴车牙单于去世，汉使议起张掖北地。

## 太子与王位安排

<a id="hs-event-2"></a>

1. **刘欣立为皇太子。** 成帝称在位已久仍无子，选定陶王刘欣为嗣；封中山王之舅冯参并增中山封户，同时分赐王侯和百姓。 孔光主张选成帝弟刘兴为嗣。刘欣既立，为安抚刘兴，成帝封其舅冯参；增中山户数本传“萬戶”、本纪“三萬戶”。 孔光在廷议中独荐成帝亲弟中山王，未被采用，随后由御史大夫降任廷尉。 [[1]](#hs-note-2)

<a id="hs-event-6"></a>

2. **中山王刘兴去世。** 八月庚戌中山王刘兴去世。 刘兴病时请求让舅父冯参减为关内侯而留京，成帝准留长安，仍以列侯身份朝见。 [[2]](#hs-note-6)

<a id="hs-event-7"></a>

3. **刘景立为定陶王。** 十一月立楚孝王之孙刘景为定陶王。 [[3]](#hs-note-7)

<a id="hs-event-8"></a>

4. **淳于长死狱、许氏被赐药。** 淳于长以大逆下狱死亡。廷尉孔光持节给贵人许氏药，许氏饮后死亡。 翟方进条奏淳于长亲善者，京兆尹孙宝、右扶风萧育等因案免官。 孔光另为已离开淳于长或已经再嫁的女子辨罪，成帝采用其无连坐之议。 淳于长曾贿红阳侯王立代请留京；帝遣王立就国，朱博、孙闳、陈咸亦因与王立交好被遣。 [[4]](#hs-note-8)

## 官制、庙礼及赦令

<a id="hs-event-1"></a>

5. **绥和元年大赦。** 正月赦天下。 [[5]](#hs-note-1)

<a id="hs-event-3"></a>

6. **封殷周后裔。** 朝廷以保存前二王之后为礼，立孔吉为殷绍嘉侯，三月把他与周承休侯一起进为公，各给百里地。 [[6]](#hs-note-3)

<a id="hs-event-4"></a>

7. **赴雍祭五畤。** 成帝到雍祭五畤。 [[7]](#hs-note-4)

<a id="hs-event-5"></a>

<a id="hs-event-15"></a>

8. **三公职掌调整，护军都尉改属大司马府。** 调整大司马与大司空。王根改以大司马任职，免原将军号；御史大夫改称大司空、封列侯，两官俸禄增到与丞相相同。改官此前，何武以丞相独兼三公之事，提议分定三公职掌。成帝时护军都尉在大司马府，位比司直。 [[8]](#hs-note-5)

<a id="hs-event-9"></a>

9. **废刺史改州牧。** 十二月废部刺史，设秩二千石的州牧。 何武、翟方进以部刺史秩在郡守下而督察郡守不妥，请改州牧。 [[9]](#hs-note-9)

<a id="hs-event-16"></a>

<a id="hs-event-17"></a>

10. **王国撤内史定由相治民，更定印绶。** 王国撤内史并由相治民。成帝省王国内史，令相治理居民，同郡太守；中尉同郡都尉。绥和元年，长和相均用黑绶。 [[10]](#hs-note-16)

<a id="hs-event-18"></a>

11. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[11]](#hs-note-18)

<a id="hs-event-19"></a>

12. **犍为得古磬，刘向请立辟雍。** 犍为水边得十六古磬，刘向建议兴辟雍、设庠序。 [[12]](#hs-note-19)

# 公元前8年｜绥和元年大赦、刘欣立为皇太子

[← 公元前9年](bce-0009.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前7年 →](bce-0007.md)

**汉成帝绥和元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **绥和元年大赦。** 正月赦天下。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **刘欣立为皇太子。** 成帝称在位已久仍无子，选定陶王刘欣为嗣；封中山王之舅冯参并增中山封户，同时分赐王侯和百姓。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **封殷周后裔。** 朝廷以保存前二王之后为礼，立孔吉为殷绍嘉侯，三月把他与周承休侯一起进为公，各给百里地。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **赴雍祭五畤。** 成帝到雍祭五畤。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **调整大司马与大司空。** 王根改以大司马任职，免原将军号；御史大夫改称大司空、封列侯，两官俸禄增到与丞相相同。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **中山王刘兴去世。** 八月庚戌中山王刘兴去世。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **刘景立为定陶王。** 十一月立楚孝王之孙刘景为定陶王。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **淳于长死狱、许氏被赐药。** 淳于长以大逆下狱死亡。廷尉孔光持节给贵人许氏药，许氏饮后死亡。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **废刺史改州牧。** 十二月废部刺史，设秩二千石的州牧。 [[9]](#hs-note-9)

### 2. 刘欣立为皇太子

[返回正文第2条](#hs-event-2)

<a id="hs010-l984-e2"></a>

**[《汉书·成帝纪》P125](../../sources/摘录/汉书-卷010-成帝纪.md#p125)** · [仓内TXT L984](../../sources/本地分卷/汉书/汉书-卷010.md#L984)

> 二月癸丑，詔曰：「朕承太祖鴻業，奉宗廟二十五年，德不能綏理宇內，百姓怨望者眾。不蒙天祐，至今未有繼嗣，天下無所係心。觀于往古近事之戒，禍亂之萌，皆由斯焉。定陶王欣於朕為子，慈仁孝順，可以承天序，繼祭祀。其立欣為皇太子。封中山王舅諫大夫馮參為宜鄉侯，益中山國三萬戶，以慰其意。賜諸侯王、列侯金，天下當為父後者爵，三老、孝弟力田帛，各有差。」

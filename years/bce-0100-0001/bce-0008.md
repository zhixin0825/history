# 公元前8年｜绥和元年大赦、刘欣立为皇太子

[← 公元前9年](bce-0009.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前7年 →](bce-0007.md)

**汉成帝绥和元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **绥和元年大赦。** 正月赦天下。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **刘欣立为皇太子。** 成帝称在位已久仍无子，选定陶王刘欣为嗣；封中山王之舅冯参并增中山封户，同时分赐王侯和百姓。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **封殷周后裔。** 朝廷以保存前二王之后为礼，立孔吉为殷绍嘉侯，三月把他与周承休侯一起进为公，各给百里地。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **赴雍祭五畤。** 成帝到雍祭五畤。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **调整大司马与大司空。** 王根改以大司马任职，免原将军号；御史大夫改称大司空、封列侯，两官俸禄增到与丞相相同。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **中山王刘兴去世。** 八月庚戌中山王刘兴去世。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **刘景立为定陶王。** 十一月立楚孝王之孙刘景为定陶王。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **淳于长死狱、许氏被赐药。** 淳于长以大逆下狱死亡。廷尉孔光持节给贵人许氏药，许氏饮后死亡。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **废刺史改州牧。** 十二月废部刺史，设秩二千石的州牧。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **五月戊午分封王子侯。** 《王子侯表》列五月戊午受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **六月丙寅分封王子侯。** 《王子侯表》列六月丙寅受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **酂侯萧章｜承爵。** 表载酂侯萧章一支本年记载侯位承袭。表中所载事项为质侯章承爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **周子南君姬嘉｜进爵。** 表载周子南君姬嘉一支本年升爵。表中所载事项为进爵为公，地满百里。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **泛乡侯何武｜受封。** 《汉书》侯籍列泛乡侯何武本年受封，所引月份、干支依表保留。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **护军都尉归大司马府。** 成帝时护军都尉在大司马府，位比司直。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **王国撤内史并由相治民。** 成帝省王国内史，令相治理居民，同郡太守；中尉同郡都尉。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **长、相用黑绶。** 绥和元年，长和相均用黑绶。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[18]](#hs-note-18)

<a id="hs-note-18"></a>

### 18. 百官公卿表所记官历

[返回正文第18条](#hs-event-18)

<a id="hs019-cell-8-18"></a>

**[《汉书·百官公卿表》完整见证本年行](../../sources/补充阅读/汉书-卷019-维基文库9347363-完整读本.md#ws019-bce-0008)** · [年表去向](../../sources/摘录/汉书-卷019-百官公卿表.md#table-ws019-bce-0008)

第3栏

> 四月丁丑，大司馬票騎將軍根更為大司馬，七月甲寅賜金，安車駟馬免。十一月丙寅，侍中騎都尉光祿大夫王莽為大司馬。

第4栏

> 三月戊午，廷尉何武為御史大夫，四月乙卯為大司空，一年免。

第5栏

> 廷尉孔光為左將軍，一年遷。執金吾王咸為右將軍，一年遷。

第7栏

> 侍中光祿大夫師丹為諸吏散騎光祿勳，十一月為太子太傅。大司農許商為光祿勳，四月遷。

第8栏

> 成陽侯趙訢君偉為衞尉，六月。侍中光祿大夫司農趙玄為衞尉，一月為中少府。

第9栏

> 駙馬都尉王舜為太僕，二年病免。

第10栏

> 御史大夫孔光為廷尉，九月遷。少府龐真為廷尉，二年為長信少府。

第12栏

> 侍中光祿大夫許商為大司農，數月遷。太原太守彭宣為大司農，一年遷。

第13栏

> 詹事平陵賈延初卿為少府，三年。太僕宏為執金吾，十一月貶為代郡太守。光祿大夫王臧幼公為執金吾，三月遷，南陽謝堯長平一年遷。

第14栏

> 京兆都尉甄豐長伯為水衡都尉，二年為泗水相。

第15栏

> 長信少府薛宣為京兆尹，一年貶為淮陽相。丞相司直琅邪遂義子贛為左馮翊，坐選舉免。

**汉成帝元延四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **甘泉郊祭。** 正月赴甘泉郊泰畤。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **罢司隶校尉。** 二月撤销司隶校尉一职。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **河东祭后土。** 三月到河东祠后土。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **甘露报告与赐牛酒。** 京师报告甘露，朝廷赐长安百姓牛酒。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **定陶王刘欣与中山王刘兴入朝。** 两王同来朝见，刘欣遵照法令带傅、相、中尉并能释《诗》，刘兴只带傅。本纪接叙成帝询问与两王表现。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **刘友嗣淄川王。** 刘友嗣淄川王。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **成都景成侯王商｜承爵。** 表载成都景成侯王商一支本年记载侯位承袭。表中所载事项为侯况承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **高平戴侯王逢时｜承爵。** 表载高平戴侯王逢时一支本年记载侯位承袭。表中所载事项为侯置承爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **裁司隶校尉。** 成帝元延四年省司隶校尉。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 王根举北地太守谷永为大司农。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **都关坠陨石二。** [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **卫姬在中山王宫生刘衎。** 中山孝王刘兴的姬妾卫氏生子，后来继位为平帝；平帝旧名箕子，即位后改名衎。 [[12]](#hs-note-12)

### 5. 定陶王刘欣与中山王刘兴入朝

[返回正文第5条](#hs-event-5)

<a id="hs097-l10245-e5"></a>

**[《汉书·外戚传》P125](../../sources/摘录/汉书-卷097-外戚传.md#p125)** · [仓内TXT L10245](../../sources/本地分卷/汉书/汉书-卷097.md#L10245)

> 元延四年，孝王及定陶王皆入朝。

**互校说明** 本传明记元延四年，《成帝纪》同。

<a id="hs011-l998-e5"></a>

**[《汉书·哀帝纪》P001](../../sources/摘录/汉书-卷011-哀帝纪.md#p001)** · [仓内TXT L998](../../sources/本地分卷/汉书/汉书-卷011.md#L998)

> 元延四年入朝，盡從傅、相、中尉。時成帝少弟中山孝王亦來朝，獨從傅。上怪之，以問定陶王，對曰：「令，諸侯王朝，得從其國二千石。傅、相、中尉皆國二千石，故盡從之。」上令誦詩，通習，能說。他日問中山王：「

<a id="hs011-l999-e5"></a>

**[《汉书·哀帝纪》P002](../../sources/摘录/汉书-卷011-哀帝纪.md#p002)** · [仓内TXT L999](../../sources/本地分卷/汉书/汉书-卷011.md#L999)

> 獨從傅在何法令？」不能對。令誦尚書，又廢。及賜食於前，後飽；起下，陉係解。成帝由此以為不能，而賢定陶王，數稱其材。時王祖母傅太后隨王來朝，私賂遺上所幸趙昭儀及帝舅票騎將軍曲陽侯王根。昭儀及根見上亡子，亦欲豫自結為長久計，皆更稱定陶王，勸帝以為嗣。成帝亦自美其材，為加元服而遣之，時年十七矣。

**互校说明** 傅氏游说、刘欣受冠归国接元延四年朝见；次年召立为储另列。

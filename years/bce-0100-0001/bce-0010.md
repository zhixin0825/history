# 公元前10年｜岷山山崩壅江

[← 公元前11年](bce-0011.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前9年 →](bce-0009.md)

**汉成帝元延三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **岷山山崩壅江。** 正月丙寅蜀郡岷山崩，江水被壅三天，断流。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **淳于长封侯。** 二月封侍中卫尉淳于长为定陵侯。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **赴雍祭五畤。** 三月成帝到雍祠五畤。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **刘隐嗣赵王。** 刘隐嗣赵王。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘靖嗣泗水王。** 刘靖嗣泗水王。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **蒲领炀侯禄一支封爵后续。** 元延三年，节侯不识以推弟接续旧封。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **营平壮侯赵充国｜获罪。** 表载营平壮侯赵充国一支本年载相关罪案及处分。表中所载事项为因罪案父钦诈因长安女子王君侠子为承爵，失爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **定陵侯淳于长｜受封。** 表载定陵侯淳于长一支本年有始封记载。表中所载事项为二月丙午封。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[9]](#hs-note-9)

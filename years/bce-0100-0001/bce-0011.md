# 公元前11年｜立刘守为广陵王

[← 公元前12年](bce-0012.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前10年 →](bce-0010.md)

**汉成帝元延二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **甘泉郊祭。** 正月赴甘泉郊泰畤。 《扬雄传》叙扬雄随驾祭泰畤，归后献《甘泉赋》以讽。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **河东祠后土。** 三月赴河东祭后土。 《扬雄传》补祭后游介山、安邑、龙门等地，扬雄归献《河东赋》。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **立刘守为广陵王。** 四月立广陵孝王刘霸之子刘守为王。《诸侯王表》记广陵哀王刘护无后，刘守随后绍封。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **十二月羽猎，扬雄随驾。** 《扬雄传》记本年十二月羽猎，次年秋又从驾到长杨射熊馆。《成帝纪》把从胡客长杨大校猎系本年冬，记宿萯阳宫和赐从官。《通鉴考异》从传分年，[次年长杨条](bce-0010.md#hs087-l9441-e11)载秋收受扰及《长杨赋》。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **桑中戴侯广汉一支封爵后续。** 元延二年，侯舜以敬弟接续旧封，十九年免去侯爵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **锺武节侯度一支封爵后续。** 元延二年，节侯则以霸叔父接续旧封。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **成乡质侯庆一支封爵后续。** 元延二年，侯果以霸弟接续旧封，十九年免去侯爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **正月癸卯分封王子侯。** 《王子侯表》列正月癸卯受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **四月甲寅分封王子侯。** 《王子侯表》列四月甲寅受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **乐陵安侯史高｜绍封。** 表载乐陵安侯史高一支本年接续了原有封爵。表中所载事项为六月癸巳，侯淑因崇弟接续封爵，无继承人。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **博望顷侯许舜｜绍封。** 表载博望顷侯许舜一支本年接续了原有封爵。表中所载事项为六月癸巳，侯报子因并弟接续封爵，千户。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **乐成侯许恭｜绍封。** 表载乐成侯许恭一支本年接续了原有封爵。表中所载事项为节侯恭因常弟接续封爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **成阳节侯赵临｜承爵。** 表载成阳节侯赵临一支本年记载侯位承袭。表中所载事项为侯欣承爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 官表记孙宝本年任京兆尹。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **段会宗奉命诛番丘。** 末振将杀大昆弥后也死，汉朝遣段会宗追究。段会宗诛末振将的太子番丘，获关内侯爵。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **段会宗再使乌孙安辑。** 乌孙内部仍争，汉朝再遣段会宗使乌孙安辑。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **郭舜议遣还康居侍子。** 康居遣子入侍。都护郭舜陈说接待负担、礼仪争议，主张遣还其子并断绝派使，朝廷仍沿用羁縻交往。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **解光奏追记许美人所生皇子遭害。** 按解光后来奏辞，许美人于元延二年十一月生子，成帝与赵昭仪同处并屏退侍者；随后籍武接下埋葬死儿的指令。 [[18]](#hs-note-18)

### 15. 段会宗奉命诛番丘

[返回正文第15条](#hs-event-15)

<a id="hs096-l10050-e15"></a>

**[《汉书·西域传》P102](../../sources/摘录/汉书-卷096-西域传.md#p102)** · [仓内TXT L10050](../../sources/本地分卷/汉书/汉书-卷096.md#L10050)

> 漢恨不自誅末振將，復使段會宗即斬其太子番丘。還，賜爵關內侯。是歲，元延二年也。

**互校说明** 元延二年明确附于段会宗诛番丘与还受爵，以上乌孙诸次内争为前史。

<a id="hs070-l8703-e15"></a>

**[《汉书·傅常郑甘陈段传》P045](../../sources/摘录/汉书-卷070-傅常郑甘陈段传.md#p045)** · [仓内TXT L8703](../../sources/本地分卷/汉书/汉书-卷070.md#L8703)

> 元延中，復遣會宗發戊己校尉諸國兵，即誅末振將太子番丘。會宗恐大兵入烏孫，驚番丘，亡逃不可得，即留所發兵墊婁地，選精兵三十弩，徑至昆彌所在，召番丘，責以「末振將骨肉相殺，殺漢公主子孫，未伏誅而死，使者受詔誅番丘。」即手劔擊殺番丘。官屬以下驚恐，馳歸。小昆彌烏犂靡者，末振將兄子也，勒兵數千騎圍會宗，會宗爲言來誅之意：「今圍守殺我，如取漢牛一毛耳。宛王郅支頭縣槀街，烏孫所知也。」昆彌以下服，曰：「末振將負漢，誅其子可也，獨不可告我，令飲食之邪？」會宗曰：「豫告昆彌，逃匿之，爲大罪。即飲食以付我，傷骨肉恩，故不先告。」昆彌以下號泣罷去。會宗還奏事，公卿議會宗權得便宜，以輕兵深入烏孫，即誅番丘，宣明國威，宜加重賞。天子賜會宗爵關內侯，黃金百斤。

**互校说明** 本传只称元延中，据《西域传》明记元延二年，《通鉴》同。《段会宗传》称末振将病死，《西域传》记末振将被难栖所杀。初立末振将见本卷前一段，年月未定。

### 16. 段会宗再使乌孙安辑

[返回正文第16条](#hs-event-16)

<a id="hs096-l10051-e16"></a>

**[《汉书·西域传》P103](../../sources/摘录/汉书-卷096-西域传.md#p103)** · [仓内TXT L10051](../../sources/本地分卷/汉书/汉书-卷096.md#L10051)

> 會宗以翕侯難棲殺末振將，雖不指為漢，合於討賊，奏以為堅守都尉。責大祿、大吏、大監以雌栗靡見殺狀，奪金印紫綬，更與銅墨雲。末振將弟卑爰疐本共謀殺大昆彌，將眾八萬餘口北附康居，謀欲借兵兼併兩昆彌。兩昆彌畏之，親倚都護。

### 17. 郭舜议遣还康居侍子

[返回正文第17条](#hs-event-17)

<a id="hs096-l10012-e17"></a>

**[《汉书·西域传》P064](../../sources/摘录/汉书-卷096-西域传.md#p064)** · [仓内TXT L10012](../../sources/本地分卷/汉书/汉书-卷096.md#L10012)

> 至成帝時，康居遣子侍漢，貢獻，然自以絕遠，獨驕嫚，不肯與諸國相望。都護郭舜數上言：「本匈奴盛時，非以兼有烏孫、康居故也；及其稱臣妾，非以失二國也。漢雖皆受其質子，然三國內相輸遺，交通如故，亦相候司，見便則發；合不能相親信，離不能相臣役。以今言之，結配烏孫竟未有益，反為中國生事。然烏孫既結在前，今與匈奴俱稱臣，義不可距。而康居驕黠，訖不肯拜使者。都護吏至其國，坐之烏孫諸使下，王及貴人先飲食已，乃飲啖都護吏，故為無所省以誇旁國。以此度之，何故遣子入侍？其欲賈市為好，辭之詐也。匈奴百蠻大國，今事漢其備，聞康居不拜，且使單于有自下之意，宜歸其侍子，絕勿復使，以章漢家不通無禮之國。敦煌、酒泉小郡及南道八國，給使者往來人、馬、驢、橐駝食，皆苦之。空罷耗所過，送迎驕黠絕遠之國，非至計也。」漢為其新通，重致遠人。終羈縻而未絕。

**互校说明** 《通鉴》卷032列元延二年；本传无具体月日。

<a id="hs-note-18"></a>

### 18. 解光奏追记许美人所生皇子遭害

[返回正文第18条](#hs-event-18)

<a id="hs097-l10233-e18"></a>

**[《汉书·外戚传》P113](../../sources/摘录/汉书-卷097-外戚传.md#p113)** · [仓内TXT L10233](../../sources/本地分卷/汉书/汉书-卷097.md#L10233)

> 元延二年褱子，其十一月乳。詔使嚴持乳毉及五種和藥丸三，送美人所。後客子、偏、兼聞昭儀謂成帝曰：「常紿我言從宮中來，即從中宮來，許美人兒何從生中？許氏竟當復立邪！」懟，以手自擣，以頭擊壁戶柱，從床上自投地，啼泣不肯食，曰：「今當安置我，欲歸耳！」帝曰：「今故告之，反怒為！殊不可曉也。」帝亦不食。昭儀曰：「陛下自知是，不食為何？陛下常自言『約不負女』，今美人有子，竟負約，謂何？」帝曰：「約以趙氏，故不立許氏。使天下無出趙氏上者，毋憂也！」後詔使嚴持綠囊書予許美人，告嚴曰：「美人當有以予女，受來，置飾室中簾南。」美人以葦篋一合盛所生兒，緘封，及綠囊報書予嚴。嚴持篋書，置飾室簾南去。帝與昭儀坐，使客子解篋緘。未已，帝使客子、偏、兼皆出，自閉戶，獨與昭儀在。須臾開戶，呼客子、偏、兼，使緘封篋及綠綈方底，推置屏風東。恭受詔，持篋方底予武，皆封以御史中丞印，曰：「告武：篋中有死兒，埋屏處，勿令人知。」武穿獄樓垣下為坎，埋其中。

**互校说明** 《外戚传》录解光奏分别记曹宫与许美人怀产之年，本条按许美人所生婴儿的独立证据入前11年。记为奏辞所举，年份、人物须与前12年曹宫案分看。

# 公元前11年｜立刘守为广陵王

[← 公元前12年](bce-0012.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前10年 →](bce-0010.md)

**汉成帝元延二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **甘泉郊祭。** 正月赴甘泉郊泰畤。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **河东祠后土。** 三月赴河东祭后土。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **立刘守为广陵王。** 四月立广陵孝王刘霸之子刘守为王。《诸侯王表》记广陵哀王刘护无后，刘守随后绍封。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **从胡客校猎。** 冬到长杨宫，与胡客举行大规模田猎，宿萯阳宫并赐从官。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **桑中戴侯广汉一支封爵后续。** 元延二年，侯舜以敬弟接续旧封，十九年免去侯爵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **锺武节侯度一支封爵后续。** 元延二年，节侯则以霸叔父接续旧封。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **成乡质侯庆一支封爵后续。** 元延二年，侯果以霸弟接续旧封，十九年免去侯爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **正月癸卯分封王子侯。** 《王子侯表》列正月癸卯受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **四月甲寅分封王子侯。** 《王子侯表》列四月甲寅受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **乐陵安侯史高｜绍封。** 表载乐陵安侯史高一支本年接续了原有封爵。表中所载事项为六月癸巳，侯淑因崇弟接续封爵，无继承人。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **博望顷侯许舜｜绍封。** 表载博望顷侯许舜一支本年接续了原有封爵。表中所载事项为六月癸巳，侯报子因并弟接续封爵，千户。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **乐成侯许恭｜绍封。** 表载乐成侯许恭一支本年接续了原有封爵。表中所载事项为节侯恭因常弟接续封爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **成阳节侯赵临｜承爵。** 表载成阳节侯赵临一支本年记载侯位承袭。表中所载事项为侯欣承爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[14]](#hs-note-14)

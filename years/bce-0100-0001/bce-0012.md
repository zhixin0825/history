# 公元前12年｜元延元年日食记录、无云雷光与大赦

[← 公元前13年](bce-0013.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前11年 →](bce-0011.md)

**汉成帝元延元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **元延元年日食记录。** 正月己亥朔记日食。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **赴雍祭祀。** 三月在雍祭五畤。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **无云雷光与大赦。** 四月丁酉记无云而雷、四面有光至地并在黄昏停止，随后大赦。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

<a id="hs-event-17"></a>

4. **东井见孛星，朝廷诏举贤士。** 七月东井有彗。诏责群臣少进忠言，命经术之士议政、内郡各举直谏，北边二十二郡举勇而知兵者。元延元年东井孛星。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **王商去世。** 十二月辛亥，大司马大将军王商去世。 王商死后红阳侯王立本当代掌政，朝廷因孙宝查出王立营私案而越次用弟王根。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **赵昭仪害皇子。** 赵昭仪赵合德迫害皇子，此事后来受到调查。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **新昌节侯庆一支封爵后续。** 元延元年，厘侯嫋以未央弟接续旧封。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **高郭节侯壒一支封爵后续。** 元延元年，侯异衆以霸弟接续旧封。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **式节侯宪一支封爵后续。** 元延元年，侯萌以霸弟接续旧封，十九年免去侯爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **二月癸卯分封王子侯。** [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **騏侯駒詩｜绍封。** 表载騏侯駒詩一支本年接续了原有封爵。表中所载事项为六月己未，侯诗因崇弟接续封爵，五百五十户。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **开陵侯成级｜绍封。** 表载开陵侯成级一支本年接续了原有封爵。表中所载事项为六月乙未，厘侯级因襃弟接续封爵，千二十户。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **宜春敬侯王欣｜承爵。** 表载宜春敬侯王欣一支本年记载侯位承袭。表中所载事项为厘侯章承爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **扶阳节侯韦贤｜承爵。** 表载扶阳节侯韦贤一支本年记载侯位承袭。表中所载事项为厘侯育承爵。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **长安和函谷关的门牡亡失。** [[16]](#hs-note-16)

<a id="hs-event-18"></a>

17. **朱云请剑折槛。** 朱云请尚方剑斩前丞相张禹，成帝怒命御史带走。朱云攀住殿槛，栏杆折断。左将军辛庆忌力谏，成帝才宽免朱云，又命修槛时保留折处。 [[17]](#hs-note-18)

<a id="hs-event-19"></a>

18. **左将军辛庆忌去世。** 辛庆忌去世。他曾在乌孙、焉耆从军，历守张掖、酒泉，后任左将军。 [[18]](#hs-note-19)

<a id="hs-event-20"></a>

19. **陈咸因王立荐举入朝又被免。** 红阳侯王立举陈咸为方正，拜光禄大夫给事中。丞相翟方进劾其前因贪邪被免、举荐不实，成帝免陈咸而未劾王立。 [[19]](#hs-note-20)

<a id="hs-event-21"></a>

20. **谷永将赴北地，上疏请弭内乱与救灾。** 成帝接受将赴北地的谷永所陈。谷永借当年日食、流星、彗星，重申止微行、节宫宠、减常税、赈流民。 [[20]](#hs-note-21)

<a id="hs-event-22"></a>

21. **搜谐单于病死于入朝途中，且莫车继立。** 搜谐未入汉塞病死，弟且莫车为车牙若鞮单于，囊知牙斯为左贤王。 [[21]](#hs-note-22)

> 至成帝時，丞相故安昌侯張禹以帝師位特進，甚尊重。雲上書求見，公卿在前。雲曰：「今朝庭大臣上不能匡主，下亡以益民，皆尸位素餐，孔子所謂『鄙夫不可與事君』，『苟患失之，亡所不至』者也。臣願賜尚方斬馬劔，斷佞臣一人以厲其餘。」上問：「誰也？」對曰「安昌侯張禹。」上大怒，曰：「小臣居下訕上，廷辱師傅，罪死不赦。」御史將雲下，雲攀殿檻，檻折。雲呼曰：「臣得下從龍逢、比干遊於地下，足矣！未知聖朝何如耳？」御史遂將雲去。於是左將軍辛慶忌免冠解印綬，叩頭殿下曰：「此臣素著狂直於世。使其言是，不可誅；其言非，固當容之。臣敢以死爭。」慶忌叩頭流血。上意解，然後得已。及後當治檻，上曰：「勿易！因而輯之，以旌直臣。」

**互校说明** 传明记元延元年；《通鉴》卷032据本纪七月东井彗象接叙，可与本年第四条互读。

<a id="hs085-l9335-e21"></a>

**[《汉书·谷永杜邺传》P031](../../sources/摘录/汉书-卷085-谷永杜邺传.md#p031)** · [仓内TXT L9335](../../sources/本地分卷/汉书/汉书-卷085.md#L9335)

> 臣永幸得以愚朽之材為太中大夫，備拾遺之臣，從朝者之後，進不能盡思納忠輔宣聖德，退無被堅執銳討不義之功，猥蒙厚恩，仍遷至北地太守。絕命隕首，身膏草野，不足以報塞萬分。陛下聖德寬仁，不遺易忘之臣，垂周文之聽，下及芻蕘之愚，有詔使衛尉受臣永所欲言。臣聞事君之義，有言責者盡其忠，有官守者修其職。臣永幸得免於言責之辜，有官守之任，當畢力遵職，養綏百姓而已，不宜復關得失之辭。忠臣之於上，志在過厚，是故遠不違君，死不忘國。昔史魚既沒，餘忠未訖，委柩後寑，以屍達誠；汲黯身外思內，發憤舒憂，遺言李息。經曰：「雖爾身在外，乃心無不在王室。」臣永幸得給事中出入三年，雖執干戈守邊垂，思慕之心常存於省闥，是以敢越郡吏之職，陳累年之憂。

**互校说明** 同一元延元年奏对。

<a id="hs085-l9336-e21"></a>

**[《汉书·谷永杜邺传》P032](../../sources/摘录/汉书-卷085-谷永杜邺传.md#p032)** · [仓内TXT L9336](../../sources/本地分卷/汉书/汉书-卷085.md#L9336)

> 臣聞天生蒸民，不能相治，為立王者以統理之，方制海內非為天子，列土封疆非為諸侯，皆以為民也。垂三統，列三正，去無道，開有德，不私一姓，明天下乃天下之天下，非一人之天下也。王者躬行道德，承順天地，博愛仁恕，恩及行葦，籍稅取民不過常法，宮室車服不踰制度，事節財足，黎庶和睦，則卦氣理效，五徵時序，百姓壽考，庶屮蕃滋，符瑞並降，以昭保右。失道妄行，逆天暴物，窮奢極欲，湛湎荒淫，婦言是從，誅逐仁賢，離逖骨肉，群小用事，峻刑重賦，百姓愁怨，則卦氣悖亂，咎徵著郵，上天震怒，災異婁降，日月薄食，五星失行，山崩川潰，水泉踊出，妖孽並見，茀星耀光，饑饉荐臻，百姓短折，萬物夭傷。終不改寤，惡洽變備，不復譴告，更命有德。《詩》云：「乃眷西顧，此惟予宅。」

**互校说明** 同一奏对提出“天下乃天下之天下”，论天命可以易姓。

<a id="hs085-l9337-e21"></a>

**[《汉书·谷永杜邺传》P033](../../sources/摘录/汉书-卷085-谷永杜邺传.md#p033)** · [仓内TXT L9337](../../sources/本地分卷/汉书/汉书-卷085.md#L9337)

> 夫去惡奪弱，遷命賢聖，天地之常經，百王之所同也。加以功德有厚薄，期質有修短，時世有中季，天道有盛衰。陛下承八世之功業，當陽數之標季，涉三七之節紀，遭无妄之卦運，直百六之災阨。三難異科，雜焉同會。建始元年以來二十載間，群災大異，交錯鋒起，多於春秋所書。八世著記，久不塞除，重以今年正月己亥朔日有食之，三朝之會，四月丁酉四方眾星白晝流隕，七月辛未彗星橫天。乘三難之際會，畜眾多之災異，因之以饑饉，接之以不贍。彗星，極異也，土精所生，流隕之應出於飢變之後，兵亂作矣，厥期不久，隆德積善，懼不克濟。內則為深宮後庭將有驕臣悍妾醉酒狂悖卒起之敗，北宮苑囿街巷之中臣妾之家幽閒之處徵舒、崔杼之亂；外則為諸夏下土將有樊並、蘇令、陳勝、項梁奮臂之禍。內亂朝暮，日戒諸夏，舉兵以火角為期。安危之分界，宗廟之至憂，臣永所以破膽寒心，豫言之累年。下有其萌，然後變見於上，可不致慎！

**互校说明** 同一奏对合论古近旧事、行星及天变；文中的祸期属于谷永的推断。

<a id="hs085-l9338-e21"></a>

**[《汉书·谷永杜邺传》P034](../../sources/摘录/汉书-卷085-谷永杜邺传.md#p034)** · [仓内TXT L9338](../../sources/本地分卷/汉书/汉书-卷085.md#L9338)

> 禍起細微，姦生所易。願陛下正君臣之義，無復與群小媟黷燕飲；中黃門後庭素驕慢不謹嘗以醉酒失臣禮者，悉出勿留。勤三綱之嚴，修後宮之政，抑遠驕妒之寵，崇近婉順之行，加惠失志之人，懷柔怨恨之心。保至尊之重，秉帝王之威，朝覲法出而後駕，陳兵清道而後行，無復輕身獨出，飲食臣妾之家。三者既除，內亂之路塞矣。

**互校说明** 同疏要求近侍守礼，皇帝停止私自出饮。

<a id="hs085-l9339-e21"></a>

**[《汉书·谷永杜邺传》P035](../../sources/摘录/汉书-卷085-谷永杜邺传.md#p035)** · [仓内TXT L9339](../../sources/本地分卷/汉书/汉书-卷085.md#L9339)

> 諸夏舉兵，萌在民饑饉而吏不卹，興於百姓困而賦斂重，發於下怨離而上不知。《易》曰：「屯其膏，小貞吉，大貞凶。」傳曰：「飢而不損茲謂泰，厥災水，厥咎亡。」訞辭曰：「關動牡飛，辟為無道，臣為非，厥咎亂臣謀篡。」王者遭衰難之世，有飢饉之災，不損用而大自潤，故凶；百姓困貧無以共求，愁悲怨恨，故水；城關守國之固，固將去焉，故牡飛。往年郡國二十一傷於水災，禾黍不入。今年蠶麥咸惡。百川沸騰，江河溢決，大水泛濫郡國十五有餘。比年喪稼，時過無宿麥。百姓失業流散，群輩守關。大異較炳如彼，水災浩浩，黎庶窮困如此，宜損常稅小自潤之時，而有司奏請加賦，甚繆經義，逆於民心，布怨趨禍之道也。牡飛之狀，殆為此發。古者穀不登虧膳，災婁至損服，凶年不塈塗，明王之制也。《詩》云：「凡民有喪，扶服捄之。」論語曰：「百姓不足，君孰予足？」臣願陛下勿許加賦之奏，益減大官、導官、中御府、均官、掌畜、廩犧用度，止尚方、織室、京師郡國工服官發輸造作，以助大司農。流恩廣施，振贍困乏，開關梁，內流民，恣所欲之，以救其急。立春，遣使者循行風俗，宣布聖德，存卹孤寡，問民所苦，勞二千石，敕勸耕桑，毋奪農時，以慰綏元元之心，防塞大姦之侽。諸夏之亂，庶幾可息。

**互校说明** 本段记谷永所陈灾情、流民及止增赋、裁内用的建议，对“往年”和“今年”须分辨。

<a id="hs085-l9340-e21"></a>

**[《汉书·谷永杜邺传》P036](../../sources/摘录/汉书-卷085-谷永杜邺传.md#p036)** · [仓内TXT L9340](../../sources/本地分卷/汉书/汉书-卷085.md#L9340)

> 臣聞上主可與為善而不可與為惡，下主可與為惡而不可與為善。陛下天然之性，疏通聰敏，上主之姿也。少省愚臣之言，感寤三難，深畏大異，定心為善，捐忘邪志，毋貳舊愆，厲精致改，至誠應天，則積異塞於上，禍亂伏於下，何憂患之有？竊恐陛下公志未專，私好頗存，尚愛群小，不肯為耳！

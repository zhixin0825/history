# 公元前12年｜元延元年日食记录、无云雷光与大赦

[← 公元前13年](bce-0013.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前11年 →](bce-0011.md)

**汉成帝元延元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **元延元年日食记录。** 正月己亥朔记日食。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **赴雍祭祀。** 三月在雍祭五畤。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **无云雷光与大赦。** 四月丁酉记无云而雷、四面有光至地并在黄昏停止，随后大赦。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **东井彗象与举士诏。** 七月东井有彗。诏责群臣少进忠言，命经术之士议政、内郡各举直谏，北边二十二郡举勇而知兵者。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **王商去世。** 十二月辛亥，大司马大将军王商去世。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **赵昭仪害皇子。** 赵昭仪即赵合德。《五行志》记本年有两名皇子被害，《外戚传》另载日后按验。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **新昌节侯庆一支封爵后续。** 元延元年，厘侯嫋以未央弟接续旧封。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **高郭节侯壒一支封爵后续。** 元延元年，侯异衆以霸弟接续旧封。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **式节侯宪一支封爵后续。** 元延元年，侯萌以霸弟接续旧封，十九年免去侯爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **二月癸卯分封王子侯。** 《王子侯表》列二月癸卯受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **騏侯駒詩｜绍封。** 表载騏侯駒詩一支本年接续了原有封爵。表中所载事项为六月己未，侯诗因崇弟接续封爵，五百五十户。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **开陵侯成级｜绍封。** 表载开陵侯成级一支本年接续了原有封爵。表中所载事项为六月乙未，厘侯级因襃弟接续封爵，千二十户。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **宜春敬侯王欣｜承爵。** 表载宜春敬侯王欣一支本年记载侯位承袭。表中所载事项为厘侯章承爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **扶阳节侯韦贤｜承爵。** 表载扶阳节侯韦贤一支本年记载侯位承袭。表中所载事项为厘侯育承爵。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **长安和函谷关的门牡亡失。** 《汉书》在本年记载长安和函谷关的门牡亡失。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **元延元年东井孛星。** 《汉书》在本年记载元延元年东井孛星。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **朱云请剑折槛。** 朱云请尚方剑斩前丞相张禹，成帝怒命御史带走。朱云攀住殿槛，栏杆折断。左将军辛庆忌力谏，成帝才宽免朱云，又命修槛时保留折处。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **左将军辛庆忌去世。** 辛庆忌去世。他曾在乌孙、焉耆从军，历守张掖、酒泉，后任左将军。 [[19]](#hs-note-19)

### 18. 朱云请剑折槛

[返回正文第18条](#hs-event-18)

<a id="hs067-l8543-e18"></a>

**[《汉书·杨胡朱梅云传》P013](../../sources/摘录/汉书-卷067-杨胡朱梅云传.md#p013)** · [仓内TXT L8543](../../sources/本地分卷/汉书/汉书-卷067.md#L8543)

> 至成帝時，丞相故安昌侯張禹以帝師位特進，甚尊重。雲上書求見，公卿在前。雲曰：「今朝庭大臣上不能匡主，下亡以益民，皆尸位素餐，孔子所謂『鄙夫不可與事君』，『苟患失之，亡所不至』者也。臣願賜尚方斬馬劔，斷佞臣一人以厲其餘。」上問：「誰也？」對曰「安昌侯張禹。」上大怒，曰：「小臣居下訕上，廷辱師傅，罪死不赦。」御史將雲下，雲攀殿檻，檻折。雲呼曰：「臣得下從龍逢、比干遊於地下，足矣！未知聖朝何如耳？」御史遂將雲去。於是左將軍辛慶忌免冠解印綬，叩頭殿下曰：「此臣素著狂直於世。使其言是，不可誅；其言非，固當容之。臣敢以死爭。」慶忌叩頭流血。上意解，然後得已。及後當治檻，上曰：「勿易！因而輯之，以旌直臣。」

**互校说明** 本传只称成帝时、张禹以故相特进，《通鉴》卷032系元延元年。

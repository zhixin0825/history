# 公元前13年｜甘泉与河东恢复巡祀、霸陵火灾与遣归宫人

[← 公元前14年](bce-0014.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前12年 →](bce-0012.md)

**汉成帝永始四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **甘泉与河东恢复巡祀。** 正月祭甘泉、记紫殿见光并大赦赏赐，三月祠河东后土，同例赏吏民并免巡经地田租。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **两宫火灾。** 四月癸未长乐宫临华殿、未央宫东司马门先后在同日记灾。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **霸陵火灾与遣归宫人。** 六月甲午霸陵园门阙失火，杜陵未承御宫人遣归；诏令官员解释京师地震和频繁火灾。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **限制奢侈僭越。** 成帝批评公卿近臣宅园、奴婢、女乐、婚葬与车服超制并引起效仿，令循序禁止，暂不禁民间常穿的青绿，司隶察不改者。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **七月日食记录。** 七月辛未晦记日食。 [[5]](#hs-note-5)

### 4. 限制奢侈僭越

[返回正文第4条](#hs-event-4)

<a id="hs010-l963-e4"></a>

**[《汉书·成帝纪》P104](../../sources/摘录/汉书-卷010-成帝纪.md#p104)** · [仓内TXT L963](../../sources/本地分卷/汉书/汉书-卷010.md#L963)

> 又曰：「聖王明禮制以序尊卑，異車服以章有德，雖有其財，而無其尊，不得踰制，故民興行，上義而下利。方今世俗奢僭罔極，靡有厭足。公卿列侯親屬近臣，四方所則，未聞修身遵禮，同心憂國者也。或乃奢侈逸豫，務廣第宅，治園池，多畜奴婢，被服綺穀，設鐘鼓，備女樂，車服嫁娶葬埋過制。吏民慕效，娅以成俗，而欲望百姓儉節，家給人足，豈不難哉！詩不云乎？『赫赫師尹，民具爾瞻。』其申敕有司，以漸禁之。青綠民所常服，且勿止。列侯近臣，各自省改。司隸校尉察不變者。」

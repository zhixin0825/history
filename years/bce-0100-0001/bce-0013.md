# 公元前13年｜甘泉与河东恢复巡祀、霸陵火灾与遣归宫人

[← 公元前14年](bce-0014.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前12年 →](bce-0012.md)

**汉成帝永始四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **甘泉与河东恢复巡祀。** 正月祭甘泉、记紫殿见光并大赦赏赐，三月祠河东后土，同例赏吏民并免巡经地田租。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **两宫火灾。** 四月癸未长乐宫临华殿、未央宫东司马门先后在同日记灾。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **霸陵火灾与遣归宫人。** 六月甲午霸陵园门阙失火，杜陵未承御宫人遣归；诏令官员解释京师地震和频繁火灾。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **限制奢侈僭越。** 成帝批评公卿近臣宅园、奴婢、女乐、婚葬与车服超制并引起效仿，令循序禁止，暂不禁民间常穿的青绿，司隶察不改者。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **七月日食记录。** 七月辛未晦记日食。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **五月戊申分封王子侯。** 《王子侯表》列五月戊申受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **酂侯萧尊｜承爵。** 表载酂侯萧尊一支本年记载侯位承袭。表中所载事项为质侯尊承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **爰戚靖侯赵长平｜承爵。** 表载爰戚靖侯赵长平一支本年记载侯位承袭。表中所载事项为侯牧承爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **平定樊并案后四人分别受封。** 功臣表明列李谭、称忠、钟祖、訾顺四人，事起在前14年，表将四家受封书于次年永始四年。纪称五人、表列四人；各家具体干支按侯籍保存。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **武阳侯史丹｜承爵。** 表载武阳侯史丹一支本年记载侯位承袭。表中所载事项为炀侯邯承爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **永始四年夏大旱。** 《汉书》在本年记载永始四年夏大旱。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **梅福上书批评言路不通。** 梅福上书批评朝臣顺承上意，民间奏疏动辄被定为大不敬。他以高祖不拘出身纳士为例，请成帝放开言路，未被采纳。 [[13]](#hs-note-13)

### 13. 梅福上书批评言路不通

[返回正文第13条](#hs-event-13)

<a id="hs067-l8552-e13"></a>

**[《汉书·杨胡朱梅云传》P022](../../sources/摘录/汉书-卷067-杨胡朱梅云传.md#p022)** · [仓内TXT L8552](../../sources/本地分卷/汉书/汉书-卷067.md#L8552)

> 自陽朔以來，天下以言爲諱，朝廷尤甚，羣臣皆承順上指，莫有執正。何以明其然也？取民所上書，陛下之所善，試下之廷尉，廷尉必曰「非所宜言，大不敬。」以此卜之，一矣。故京兆尹王章資質忠直，敢面引廷爭，孝元皇帝擢之，以厲具臣而矯曲朝。及至陛下，戮及妻子。且惡惡止其身，王章非有反畔之辜，而殃及家。折直士之節，結諫臣之舌，羣臣皆知其非，然不敢爭，天下以言爲戒，最國家之大患也。願陛下循高祖之軌，杜亡秦之路，數御十月之歌，留意亡逸之戒，除不急之法，下亡諱之詔，博覽兼聽，謀及疏賤，令深者不隱，遠者不塞，所謂「辟四門，明四目」也。且不急之法，誹謗之微者也。「往者不可及，來者猶可追。」方今君命犯而主威奪，外戚之權日以益隆，陛下不見其形，願察其景。建始以來，日食地震，以率言之，三倍春秋，水災亡與比數。陰盛陽微，金鐵爲飛，此何景也！漢興以來，社稷二危。呂、霍、上官皆母后之家也，親親之道，全之爲右，當與之賢師良傅，敎以忠孝之道。今迺尊寵其位，授以魁柄，使之驕逆，至於夷滅，此失親親之大者也。自霍光之賢，不能爲子孫慮，故權臣易世則危。書曰：「毋若火，始庸庸。」埶陵於君，權隆於主，然後防之，亦亡及已。

**互校说明** 《通鉴》卷031把这组劝开言路的疏置永始三年，底本只以阳朔以来作回顾。

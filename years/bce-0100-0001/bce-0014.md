# 公元前14年｜日食后遣使访民举士、太后命恢复旧郊祀

[← 公元前15年](bce-0015.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前13年 →](bce-0013.md)

**汉成帝永始三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **日食后遣使访民举士。** 正月己卯晦记日食，遣大中大夫等巡问老者和民众疾苦，会同刺史荐朴厚谦让有义行者。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **太后命恢复旧郊祀。** 皇太后令恢复甘泉泰畤、汾阴后土、雍五畤和陈仓陈宝祠。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **樊并在陈留起事。** 樊并等十三人杀陈留太守。李谭等平乱并获封；本纪将起事系于十一月，《天文志》系十二月，受封人数和部分封日也有异。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **山阳铁官徒苏令起事。** 苏令等夺兵起事，本纪称波及十九郡国。《天文志》《五行志》记四十余郡国、逾年始平。本纪接记严訢平乱获赏，具体月日难据这段文字确定。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘殷嗣胶东王。** 刘殷嗣胶东王。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **三月庚申分封王子侯。** 《王子侯表》列三月庚申受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **六月辛卯分封王子侯。** 《王子侯表》列六月辛卯受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **永始三年夏大旱。** 《汉书》在本年记载永始三年夏大旱。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **翟方进因陈汤旧案举劾陈咸、逢信。** 陈汤被徙敦煌后，翟方进指陈咸、逢信曾馈赠陈汤并求他荐引，奏请免官。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **召谷永为太中大夫。** 成帝重新召谷永为太中大夫，传接叙后来迁光禄大夫给事中。 [[11]](#hs-note-11)

### 10. 翟方进因陈汤旧案举劾陈咸、逢信

[返回正文第10条](#hs-event-10)

<a id="hs084-l9271-e10"></a>

**[《汉书·翟方进传》P009](../../sources/摘录/汉书-卷084-翟方进传.md#p009)** · [仓内TXT L9271](../../sources/本地分卷/汉书/汉书-卷084.md#L9271)

> 居亡何，方進奏咸與逢信「邪枉貪汙，營私多欲。皆知陳湯姦佞傾覆，利口不軌，而親交賂遺，以求薦舉。後為少府，數饋遺湯。信、咸幸得備九卿，不思盡忠正身，內自知行辟亡功效，而官媚邪臣，欲以徼幸，苟得亡恥。孔子曰：『鄙夫可與事君也與哉！』咸、信之謂也。過惡暴見，不宜處位，臣請免以示天下。」奏可。

**互校说明** 本传在永始二年陈汤案后接叙。司马光《通鉴》卷031考异说咸、信免官在“明年以后”；《百官表》列陈咸永始元年为少府、逢信二年为卫尉，皆“二年免”。故先以永始三年接读奏劾，二人罢免是否同日待考。

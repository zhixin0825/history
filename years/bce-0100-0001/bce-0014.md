# 公元前14年｜日食后遣使访民举士、太后命恢复旧郊祀

[← 公元前15年](bce-0015.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前13年 →](bce-0013.md)

**汉成帝永始三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **日食后遣使访民举士。** 正月己卯晦记日食，遣大中大夫等巡问老者和民众疾苦，会同刺史荐朴厚谦让有义行者。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **太后命恢复旧郊祀。** 皇太后令恢复甘泉泰畤、汾阴后土、雍五畤和陈仓陈宝祠。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **樊并在陈留起事。** 樊并等十三人杀陈留太守。李谭等平乱并获封；本纪将起事系于十一月，《天文志》系十二月，受封人数和部分封日也有异。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **山阳铁官徒苏令起事。** 苏令等夺兵起事，本纪称波及十九郡国。《天文志》《五行志》记四十余郡国、逾年始平。本纪接记严訢平乱获赏，具体月日难据这段文字确定。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘殷嗣胶东王。** 刘殷嗣胶东王。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **三月庚申分封王子侯。** 《王子侯表》列三月庚申受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **六月辛卯分封王子侯。** 《王子侯表》列六月辛卯受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[8]](#hs-note-8)

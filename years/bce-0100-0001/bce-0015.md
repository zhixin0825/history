# 公元前15年｜日食流星与赈济奖赏、究办昌陵工程、褒奖止工者

[← 公元前16年](bce-0016.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前14年 →](bce-0014.md)

**汉成帝永始二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **王音去世。** 正月己丑大司马车骑将军王音去世。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **日食流星与赈济奖赏。** 二月记流星如雨与日食，诏查可裁减的支出、免追贫民借贷。赈济有贡献者按金额分获爵、补官、迁级或免租赋。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **赴雍祭五畤。** 十一月赴雍祭五畤。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **究办昌陵工程、褒奖止工者。** 诏责万年明知地势低下仍大兴土木，致耗财害民；表扬早奏停工的闳与长，赐爵食邑，将万年徙敦煌。 陈汤因妄言还要迁民等事获罪，成帝念其平郅支之功，免为庶人，与解万年同徙敦煌。 平当不赞成只凭淳于长先议罢工就封侯，自己因前议失当左迁钜鹿太守。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **御史大夫王骏去世。** 本年王骏去世，本文未记月。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **五月乙亥分封王子侯。** 《王子侯表》列五月乙亥受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **周子南君姬嘉｜承爵。** 表载周子南君姬嘉一支本年记载侯位承袭。表中所载事项为侯当承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **高阳侯薛宣｜获罪。** 薛宣因广汉盗乱与太后丧事中的征敛被问责，失去相位和高阳侯爵。《恩泽侯表》写“其年復封”，《薛宣传》称免后两年经翟方进推荐复爵，见[前13年](bce-0013.md)。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **安阳敬侯王音｜承爵。** 表载安阳敬侯王音一支本年记载侯位承袭。表中所载事项为侯舜承爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **高陵共侯翟方进｜受封。** 表载高陵共侯翟方进一支本年有始封记载。表中所载事项为十一月壬子封，八千户。 薛宣受问责去职后，翟方进由执金吾升为丞相，并封高陵侯；同一侯表的户数栏和编年栏写法不一。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **梁国、平原郡连年水灾。** 成帝永始二年书连年水灾及官吏问责。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **薛宣、翟方进合劾张放。** 成帝诸舅和太后责张放导帝逸游。丞相薛宣、御史大夫翟方进以拒使伤人、奢淫不制等事请免张放，成帝将他左迁北地都尉。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **谷永将赴凉州，借灾异谏成帝。** 谷永拟赴凉州，成帝令尚书问所欲言；谷永进疏批评后宫、微行和昌陵耗费，帝怒欲追，后自行悔解。 [[14]](#hs-note-14)

> 輒上聞，則商周不易姓而迭興，三正不變改而更用。夏商之將亡也，行道之人皆知之，晏然自以若天有日莫能危，是故惡日廣而不自知，大命傾而不寤。《易》曰：「危者有其安者也，亡者保其存者也。」陛下誠垂寬明之聽，無忌諱之誅，使芻蕘之臣得盡所聞於前，不懼於後患，直言之路開，則四方眾賢不遠千里，輻湊陳忠，群臣之上願，社稷之長福也。

<a id="hs085-l9328-e14"></a>

**[《汉书·谷永杜邺传》P024](../../sources/摘录/汉书-卷085-谷永杜邺传.md#p024)** · [仓内TXT L9328](../../sources/本地分卷/汉书/汉书-卷085.md#L9328)

> 漢家行夏正，夏正色黑，黑龍，同姓之象也。龍陽德，由小之大，故為王者瑞應。未知同姓有見本朝無繼嗣之慶，多危殆之隙，欲因擾亂舉兵而起者邪？將動心冀為後者，殘賊不仁，若廣陵、昌邑之類？臣愚不能處也。元年九月黑龍見，其晦，日有食之。今年二月己未夜星隕，乙酉，日有食之。六月之間，大異四發，二而同月，三代之末，春秋之亂，未嘗有也。臣聞三代所以隕社稷喪宗廟者，皆由婦人與群惡沈湎於酒。書曰：「乃用婦人之言，自絕于天；」「四方之述逃多罪。是宗是長，是信是使。」《詩》云：「燎之方陽，寧或滅之？赫赫宗周，褒姒滅之！」《易》曰：「濡其首，有孚失是。」秦所以二世十六年而亡者，養生泰奢，奉終泰厚也。二者陛下兼而有之，臣請略陳其效。

**互校说明** 同一奏疏，列永始元、二年四种所称异常并引古代失国为鉴。

<a id="hs085-l9329-e14"></a>

**[《汉书·谷永杜邺传》P025](../../sources/摘录/汉书-卷085-谷永杜邺传.md#p025)** · [仓内TXT L9329](../../sources/本地分卷/汉书/汉书-卷085.md#L9329)

> 《易》曰「在中餽，無攸遂」，言婦人不得與事也。《詩》曰：「懿厥悊婦，為梟為鴟；」「匪降自天，生自婦人。」建始、河平之際，許、班之貴，頃動前朝，熏灼四方，賞賜無量，空虛內臧，女寵至極，不可上矣；今之後起，天所不饗，什倍於前。廢先帝法度，聽用其言，官秩不當，縱釋王誅，驕其親屬，假之威權，從橫亂政，刺舉之吏，莫敢奉憲。又以掖庭獄大為亂阱，榜箠钇於炮格，絕滅人命，主為趙、李報德復怨，反除白罪，建治正吏，多繫無辜，掠立迫恐，至為人起責，分利受謝。生入死出者，不可勝數。是以日食再既，以昭其辜。

**互校说明** 本段指摘近幸家臣和掖庭狱，并用当时灾异说论证。

> 王者必先自絕，然后天絕之。陛下棄萬乘之至貴，樂家人之賤事，厭高美之尊號，好匹夫之卑字，崇聚僄輕無義小人以為私客，數離深宮之固，挺身晨夜，與群小相隨，烏集雜會，飲醉吏民之家，亂服共坐，流湎媟嫚，溷殽無別，閔免遁樂，晝夜在路。典門戶奉宿衛之臣執干戈而守空宮，公卿百僚不知陛下所在，積數年矣。

**[《汉书·谷永杜邺传》P027](../../sources/摘录/汉书-卷085-谷永杜邺传.md#p027)** · [仓内TXT L9331](../../sources/本地分卷/汉书/汉书-卷085.md#L9331)

> 王者以民為基，民以財為本，財竭則下畔，下畔則上亡。是以明王愛養基本，不敢窮極，使民如承大祭。今陛下輕奪民財，不愛民力，聽邪臣之計，去高敞初陵，捐十年功緒，改作昌陵，反天地之性，因下為高，積土為山，發徒起邑，並治宮館，大興繇役，重增賦斂，徵法如雨，役百乾谿，費疑驪山，靡敝天下，五年不成而後反故，又廣盱營表，發人冢墓，斷截骸骨，暴揚尸柩。百姓財竭力盡，愁恨感天，災異婁降，饑饉仍臻。流散冗食，餧死於道，以百萬數。公家無一年之畜，百姓無旬日之儲，上下俱匱，無以相救。《詩》云：「殷監不遠，在夏后之世。」願陛下追觀夏、商、周、秦所以失之，以鏡考己行。有不合者，臣當伏妄言之誅！

**[《汉书·谷永杜邺传》P028](../../sources/摘录/汉书-卷085-谷永杜邺传.md#p028)** · [仓内TXT L9332](../../sources/本地分卷/汉书/汉书-卷085.md#L9332)

> 漢興九世，百九十餘載，繼體之主七，皆承天順道，遵先祖法度，或以中興，或以治安。至於陛下，獨違道縱欲，輕身妄行，當盛壯之隆，無繼嗣之福，有危亡之憂，積失君道，不合天意，亦已多矣。為人後嗣，守人功業，如此，豈不負哉！方今社稷宗廟禍福安危之機在於陛下，陛下誠肯發明聖之德，昭然遠寤，畏此上天之威怒，深懼危亡之徵兆，蕩滌邪辟之惡志，厲精致政，專心反道，絕群小之私客，免不正之詔除，悉罷北宮私奴車馬惰出之具，克己復禮，毋貳微行出飲之過，以防迫切之禍，深惟日食再既之意，抑損椒房玉堂之盛寵，毋聽後宮之請謁，除掖庭之亂獄，出炮格之陷阱，誅戮邪佞之臣及左右執左道以事上者以塞天下之望，且寑初陵之作，止諸繕治宮室，闕更減賦，盡休力役，存卹振捄困乏之人以弭遠方，厲崇忠直，放退殘賊，無使素餐之吏久尸厚祿，以次貫行，固執無違，夙夜孳孳，婁省無怠，舊衍畢改，新德既章，纖介之邪不復載心，則赫赫大異庶幾可銷，天命去就庶幾可復，社稷宗廟庶幾可保。唯陛下留神反覆，熟省臣言。臣幸得備邊部之吏，不知本朝失得，瞽言觸忌諱，罪當萬死。

**互校说明** 同一疏提出节用、减役、救荒、罢苛吏等要求。

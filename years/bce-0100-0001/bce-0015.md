# 公元前15年｜日食流星与赈济奖赏、究办昌陵工程、褒奖止工者

[← 公元前16年](bce-0016.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前14年 →](bce-0014.md)

**汉成帝永始二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **王音去世。** 正月己丑大司马车骑将军王音去世。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **日食流星与赈济奖赏。** 二月记流星如雨与日食，诏查可裁减的支出、免追贫民借贷。赈济有贡献者按金额分获爵、补官、迁级或免租赋。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **赴雍祭五畤。** 十一月赴雍祭五畤。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **究办昌陵工程、褒奖止工者。** 诏责万年明知地势低下仍大兴土木，致耗财害民；表扬早奏停工的闳与长，赐爵食邑，将万年徙敦煌。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **御史大夫王骏去世。** 本年王骏去世，本文未记月。 [[5]](#hs-note-5)

### 2. 日食流星与赈济奖赏

[返回正文第2条](#hs-event-2)

<a id="hs010-l952-e2"></a>

**[《汉书·成帝纪》P093](../../sources/摘录/汉书-卷010-成帝纪.md#p093)** · [仓内TXT L952](../../sources/本地分卷/汉书/汉书-卷010.md#L952)

> 二月癸未夜，星隕如雨。乙酉晦，日有蝕之。詔曰：「乃者，龍見于東萊，日有蝕之。天著變異，以顯朕郵，朕甚懼焉。公卿申敕百寮，深思天誡，有可省減便安百姓者，條奏。所振貸貧民，勿收。」又曰：「關東比歲不登，吏民以義收食貧民、入穀物助縣官振贍者，已賜直，其百萬以上，加賜爵右更，欲為吏補三百石，其吏也遷二等。三十萬以上，賜爵五大夫，吏亦遷二等，民補郎。十萬以上，家無出租賦三歲。萬錢以上，一年。」

### 4. 究办昌陵工程、褒奖止工者

[返回正文第4条](#hs-event-4)

<a id="hs010-l954-e4"></a>

**[《汉书·成帝纪》P095](../../sources/摘录/汉书-卷010-成帝纪.md#p095)** · [仓内TXT L954](../../sources/本地分卷/汉书/汉书-卷010.md#L954)

> 十二月，詔曰：「前將作大匠萬年知昌陵卑下，不可為萬歲居，奏請營作，建置郭邑，妄為巧詐，積土增高，多賦斂繇役，興卒暴之作。卒徒蒙辜，死者連屬，百姓罷極，天下匱竭。常侍閎前為大司農中丞，數奏昌陵不可成。侍中衛尉長數白宜早止，徙家反故處。朕以長言下閎章，公卿議者皆合長計。首建至策，閎典主省大費，民以康寧。閎前賜爵關內侯，黃金百斤。其賜長爵關內侯，食邑千戶，閎五百戶。萬年佞邪不忠，毒流眾庶，海內怨望，至今不息，雖蒙赦令，不宜居京師。其徙萬年敦煌郡。」

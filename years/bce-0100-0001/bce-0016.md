# 公元前16年｜太官凌室和戾后园失火、封赵临、王莽并立赵皇后

[← 公元前17年](bce-0017.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前15年 →](bce-0015.md)

**汉成帝永始元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **太官凌室和戾后园失火。** 正月癸丑太官藏冰处失火，戊午戾后园门阙失火。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **封赵临、王莽并立赵皇后。** 四月封赵氏父赵临，五月封王莽为新都侯，六月立赵氏为皇后并大赦。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **停建昌陵与封城阳王。** 成帝称听信万年三年可成之说，五年后工程仍无效又劳民，遂罢昌陵并停为故陵迁人；另立城阳孝王子刘俚。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **邛成王太后去世。** 八月丁丑，太皇太后王氏去世。她是宣帝皇后、王奉光之女，史称邛成太后。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **功臣表记萧喜绍封酂侯。** 《高惠高后文功臣表》记，永始元年七月癸卯，萧喜绍封；永始四年前13年萧尊嗣。所引《成帝纪》将萧喜受封记于元延元年前12年，系同一封爵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **酇文终侯萧何｜获罪。** 表载酇文终侯萧何一支本年载相关罪案及处分。表中所载事项为因罪案使奴杀人，减死，未处肉刑，服城旦劳役。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **长平烈侯衞青｜任官。** 表载长平烈侯衞青一支本年有相应记事。表中所载事项为青曾孙玄因长安公乘为侍郎。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **平阿安侯王谭｜承爵。** 表载平阿安侯王谭一支本年记载侯位承袭。表中所载事项为剌侯仁承爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **新都侯王莽｜受封。** 表载新都侯王莽一支本年有始封记载。表中所载事项为五月乙未，因帝舅曼子获封，千五百户。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **成阳节侯赵临｜受封。** 表载成阳节侯赵临一支本年有始封记载。表中所载事项为四月乙亥封。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[11]](#hs-note-11)

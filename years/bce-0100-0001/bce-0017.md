# 公元前17年｜救助青幽冀等地流民、渤海清河河水泛滥

[← 公元前18年](bce-0018.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前16年 →](bce-0016.md)

**汉成帝鸿嘉四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **救助青幽冀等地流民。** 成帝批评官吏连宗拘系、使农民失业。遣使巡行，重灾区资产不足三万者免租赋，免收未清欠贷；登记入关流民并令各地救活。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **渤海清河河水泛滥。** 秋渤海、清河被河水淹，官府赈贷。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **赵护平郑躬。** 郑躬党扩至近万人、波及四县。朝廷令赵护发广汉与蜀郡兵三万，允捕斩者免罪，旬月平定；赵护升执金吾获金。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **厘乡侯固一支失爵。** 鸿嘉四年，因……获罪上书归印绶，免去侯爵。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **六月乙巳分封王子侯。** 《王子侯表》列六月乙巳受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **信都雨鱼的记录。** 《汉书》在本年记载信都雨鱼的记录。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **杨焉凿砥柱。** 成帝从杨焉议凿广砥柱，反使水势更急。 [[8]](#hs-note-8)

### 1. 救助青幽冀等地流民

[返回正文第1条](#hs-event-1)

<a id="hs010-l944-e1"></a>

**[《汉书·成帝纪》P085](../../sources/摘录/汉书-卷010-成帝纪.md#p085)** · [仓内TXT L944](../../sources/本地分卷/汉书/汉书-卷010.md#L944)

> 四年春正月，詔曰：「數敕有司，務行寬大，而禁苛暴，訖今不改。一人有辜，舉宗拘繫，農民失業，怨恨者眾，傷害和氣，水旱為災，關東流冗者眾，青、幽、冀部尤劇，朕甚痛焉。未聞在位有惻然者，孰當助朕憂之！已遣使者循行郡國。被災害什四以上，民貲不滿三萬，勿出租賦。逋貸未入，皆勿收。流民欲入關，輒籍內。所之郡國，謹遇以理，務有以全活之，思稱朕意。」

### 2. 渤海清河河水泛滥

[返回正文第2条](#hs-event-2)

<a id="hs029-l6119-e2"></a>

**[《汉书·沟洫志》P025](../../sources/摘录/汉书-卷029-沟洫志.md#p025)** · [仓内TXT L6119](../../sources/本地分卷/汉书/汉书-卷029.md#L6119)

> 是歲，勃海、清河、信都河水湓溢，灌縣邑三十一，敗官亭民舍四萬餘所。河隄都尉許商與丞相史孫禁共行視，圖方略。禁以為「今河溢之害數倍於前決平原時。今可決平原金隄間，開通大河，令入故篤馬河。至海五百餘里，水道浚利，又乾三郡水地，得美田且二十餘萬頃，足以償所開傷民田廬處，又省吏卒治隄救水，歲三萬人以上。」許商以為「古說九河之名，有徒駭、胡蘇、鬲津，今見在成平、東光、鬲界中。自鬲以北至徒駭間，相去二百餘里，今河雖數移徙，不離此域。孫禁所欲開者，在九河南篤馬河，失水之跡，處勢平夷，旱則淤絕，水則為敗，不可許。」公卿皆從商言。先是，谷永以為「河，中國之經瀆，聖王興則出圖書，王道廢則竭絕。今潰溢橫流，漂沒陵阜，異之大者也。修政以應之，災變自除。」是時李尋、解光亦言「陰氣盛則水為之長，故一日之間，晝減夜增，江河滿溢，所謂水不潤下，雖常於卑下之地，猶日月變見於朔望，明天道有因而作也。眾庶見王延世蒙重賞，競言便巧，不可用。議者常欲求索九河故跡而穿之，今因其自決，可且勿塞，以觀水勢。河欲居之，當稍自成川，跳出沙土，然後順天心而圖之，必有成功，而用財力寡。」於是遂止不塞。滿昌、師丹等數言百姓可哀，上數遣使者處業振贍之。

<a id="hs010-l945-e2"></a>

**[《汉书·成帝纪》P086](../../sources/摘录/汉书-卷010-成帝纪.md#p086)** · [仓内TXT L945](../../sources/本地分卷/汉书/汉书-卷010.md#L945)

> 秋，勃海、清河河溢，被災者振貸之。

# 公元前18年｜大赦及允许买爵、景帝庙门阙火灾

[← 公元前19年](bce-0019.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前17年 →](bce-0017.md)

**汉成帝鸿嘉三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **大赦及允许买爵。** 四月大赦，准官民每级用一千钱买爵。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **大旱。** 本纪记本年发生大旱。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **景帝庙门阙火灾。** 八月乙卯景帝庙门阙失火。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **废许皇后。** 十一月甲寅许皇后被废。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **广汉郑躬起事。** 郑躬等六十余人攻官署、夺囚徒和兵器，自号山君。 [[5]](#hs-note-5)

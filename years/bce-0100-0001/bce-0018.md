# 公元前18年｜大赦及允许买爵、景帝庙门阙火灾

[← 公元前19年](bce-0019.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前17年 →](bce-0017.md)

**汉成帝鸿嘉三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **大赦及允许买爵。** 四月大赦，准官民每级用一千钱买爵。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **大旱。** 本年大旱。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **景帝庙门阙火灾。** 八月乙卯景帝庙门阙失火。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **废许皇后。** 十一月甲寅许皇后被废。 许后被废时班婕妤也受讯，她否认以祝诅求福，成帝接受了她的解释。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **广汉郑躬起事。** 郑躬等六十余人攻官署、夺囚徒和兵器，自号山君。 传记朝廷另选孙宝为益州刺史，他入山谷招抚，遣非谋首者还乡。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **成乡质侯庆一支去世。** 鸿嘉三年去世，无子嗣承继。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **成陵节侯充一支后事。** 鸿嘉三年，因……获罪弟与後母乱，共杀兄，德知不举，不道，下狱瘐死亡。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **蒲侯苏昌｜获罪。** 表载蒲侯苏昌一支本年载相关罪案及处分。表中所载事项为因罪案婢自赎为民後略因为婢，失爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **乐成侯许延寿后嗣｜去世。** 表载乐成侯许延寿后嗣一支本年记载去世。表中所载事项为去世，无继承人，侯修承爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **裁詹事并入大长秋。** 成帝裁詹事，职掌并属大长秋。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **天水冀南山石鸣。** 五月乙亥，天水冀县南山传来雷鸣般的响声，当地人认为出自大石。 [[12]](#hs-note-12)

# 公元前19年｜博士饮酒礼与野雉、举敦厚有行能直言者

[← 公元前20年](bce-0020.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前18年 →](bce-0018.md)

**汉成帝鸿嘉二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **成帝赴云阳。** 春季巡幸云阳。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **博士饮酒礼与野雉。** 三月博士行饮酒礼时，有雉飞入庭、上阶鸣叫，后来还聚于诸府及承明殿。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **举敦厚有行能直言者。** 成帝叹水旱疫病使百姓困乏，又疑选士渠道受阻或荐举失当，诏举品行敦厚、能直言者。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **迁五千豪富户到昌陵。** 迁资产在五百万以上的郡国豪富五千户赴昌陵，并给高级官员、列侯及公主冢地宅第。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **立刘云客为广德王。** 六月立刘云客为广德王。本纪称他是中山宪王之孙，《景十三王传》则系于中山宪王弟一支、称他为利乡侯之子。 [[5]](#hs-note-5)

### 3. 举敦厚有行能直言者

> 詔曰：「古之選賢，傅納以言，明試以功，故官無廢事，下無逸民，教化流行，風雨和時，百穀用成，眾庶樂業，咸以康寧。朕承鴻業十有餘年，數遭水旱疾疫之災，黎民婁困於飢寒，而望禮義之興，豈不難哉！朕既無以率道，帝王之道日以陵夷，意乃招賢選士之路鬱滯而不通與，將舉者未得其人也？其舉敦厚有行義能直言者，冀聞切言嘉謀，匡朕之不逮。」

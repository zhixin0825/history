# 公元前19年｜博士饮酒礼与野雉、举敦厚有行能直言者

[← 公元前20年](bce-0020.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前18年 →](bce-0018.md)

**汉成帝鸿嘉二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **成帝赴云阳。** 春季巡幸云阳。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **博士饮酒礼与野雉。** 三月博士行饮酒礼时，有雉飞入庭、上阶鸣叫，后来还聚于诸府及承明殿。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **举敦厚有行能直言者。** 成帝叹水旱疫病使百姓困乏，又疑选士渠道受阻或荐举失当，诏举品行敦厚、能直言者。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **迁五千豪富户到昌陵。** 迁资产在五百万以上的郡国豪富五千户赴昌陵，并给高级官员、列侯及公主冢地宅第。 《陈汤传》补记解万年与陈汤商议营建昌陵邑和迁入郡国民户的经过。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **立刘云客为广德王。** 六月立刘云客为广德王。本纪称他是中山宪王之孙，《景十三王传》则系于中山宪王弟一支、称他为利乡侯之子。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **刘云承城阳王。** 刘云承城阳王。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **承乡节侯当一支失爵。** 鸿嘉二年，因……获罪恐猲国人，受财臧五百以上，免去侯爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **正月戊子分封王子侯。** 《王子侯表》列正月戊子受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **五月戊子分封王子侯。** 《王子侯表》列五月戊子受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **平恩戴侯许广汉｜承爵。** 表载平恩戴侯许广汉一支本年记载侯位承袭。表中所载事项为质侯旦承爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **邛成共侯王奉光｜承爵。** 表载邛成共侯王奉光一支本年记载侯位承袭。表中所载事项为侯勳承爵。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **平台康侯史玄｜承爵。** 表载平台康侯史玄一支本年记载侯位承袭。表中所载事项为侯习承爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **博士行射礼时飞雉入庭。** 《汉书》在本年记载博士行射礼时飞雉入庭。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **杜衍坠陨石三。** 《汉书》在本年记载杜衍坠陨石三。 [[15]](#hs-note-15)

> 詔曰：「古之選賢，傅納以言，明試以功，故官無廢事，下無逸民，教化流行，風雨和時，百穀用成，眾庶樂業，咸以康寧。朕承鴻業十有餘年，數遭水旱疾疫之災，黎民婁困於飢寒，而望禮義之興，豈不難哉！朕既無以率道，帝王之道日以陵夷，意乃招賢選士之路鬱滯而不通與，將舉者未得其人也？其舉敦厚有行義能直言者，冀聞切言嘉謀，匡朕之不逮。」

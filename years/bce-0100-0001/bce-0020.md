# 公元前20年｜张禹退休，薛宣接任丞相

[← 公元前21年](bce-0021.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前19年 →](bce-0019.md)

**汉成帝鸿嘉元年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **三月，张禹因年老多病获准辞去丞相，回家养老，仍以列侯身份朝见，享受特别礼遇。** 四月，薛宣接任丞相。张禹此后仍参与朝廷议论。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **巡举冤狱与免追旧贷。** 成帝承认刑罚失当，遣谏大夫查三辅、三河、弘农冤狱，命官员监督地方，赐爵与牛酒帛并免收逋贷。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **设昌陵县奉初陵。** 壬午赴初陵，赦在此服役者，以新丰戏乡设昌陵县供奉，并赐牛酒。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **成帝开始微服出行。** 本纪在本年首次记成帝隐身份出行。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **真定黄龙报告。** 冬真定有见黄龙的报告。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **刘慎嗣高密王。** 刘慎嗣高密王。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **式节侯宪一支去世。** 鸿嘉元年去世，无子嗣承继。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **正月癸巳分封王子侯。** 《王子侯表》列正月癸巳受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **四月辛巳分封王子侯。** 《王子侯表》列四月辛巳受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **弓高壮侯韩隤当｜去世。** 表载弓高壮侯韩隤当一支本年记载去世。表中所载事项为去世，无继承人。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **驷望忠侯冷广｜受封。** 表载驷望忠侯冷广一支本年有始封记载。表中所载事项为正月辛丑封，去世。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **平昌节侯王无故｜承爵。** 表载平昌节侯王无故一支本年记载侯位承袭。表中所载事项为侯获承爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **博阳定侯丙吉｜绍封。** 表载博阳定侯丙吉一支本年接续了原有封爵。表中所载事项为六月己巳，康侯昌因吉孙接续封爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **西平安侯于定国｜承爵。** 表载西平安侯于定国一支本年记载侯位承袭。表中所载事项为侯恬承爵。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **高阳侯薛宣｜受封。** 表载高阳侯薛宣一支本年有始封记载。表中所载事项为四月庚辰封。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **安阳敬侯王音｜受封。** 《汉书》侯籍列安阳敬侯王音本年受封，所引月份、干支依表保留。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **成帝定未满七岁重罪奏请减死。** 七岁以下犯所列重罪，可经廷尉奏请、减死。 [[18]](#hs-note-18)

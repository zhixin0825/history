# 公元前21年｜御史大夫于永去世

[← 公元前22年](bce-0022.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前20年 →](bce-0020.md)

**汉成帝阳朔四年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **闰月，于永去世，御史大夫职位再次出现交接。** [[1]](#note-1)

<a id="hs-event-2"></a>

2. **劝农桑诏。** 成帝称粮食是安民根本，指民间舍农趋末，令二千石趁春耕亲到田间劝勉。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **二月大赦。** 二月赦天下。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **东平王刘宇去世。** 九月壬申东平王去世。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **胶乡敬侯汉一支去世。** 阳朔四年去世，无子嗣承继。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **四月甲寅分封王子侯。** 《王子侯表》列四月甲寅受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **安平夷侯王舜｜承爵。** 表载安平夷侯王舜一支本年记载侯位承袭。表中所载事项为厘侯渊承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **飞星西南入斗下。** 《汉书》在本年记载飞星西南入斗下。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **阳朔四年春雪及燕雀死。** 《汉书》在本年记载阳朔四年春雪及燕雀死。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **段会宗复任西域都护。** 西域诸国上书请求召回旧都护，段会宗再任西域都护。 [[11]](#hs-note-11)

#### 卷022｜将相表互见与异说

[本年原行R186](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r186) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0021)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史表闰月壬戌永卒与汉010阳朔四年闰月壬戌御史大夫于永卒相合，采用本年。相位夹“七月乙丑，右将军光禄勋平安侯王章卒”，该人既非丞相张禹、也非京兆尹王章，侯号采用汉表安平；死亡年暂取[前22年](bce-0022.md#sj022)，此处存史表前21年异年与乙丑日字，不复演 · [成帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7010.md#ref-70b9e4dd62c009) · [外戚恩泽侯表互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-557825f5097bfd)。

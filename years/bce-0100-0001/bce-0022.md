<a id="event-1"></a>

1. **八月，王凤去世。** 九月，王音由御史大夫升大司马车骑将军；十一月，于永由光禄勋升御史大夫。右将军安平侯王章也在本年转任光禄勋，不久去世。 谷永劝年次本在王音之前的平阿侯王谭辞领城门兵，王谭接受，与王音由此不睦。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **东郡陨石。** 三月壬戌记八块陨石坠于东郡。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **颍川铁官徒众起事。** 申屠圣等一百八十人杀长吏、夺库兵并经九郡，朝廷令丞相长史和御史中丞依军兴规定追捕，最后平定。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **刘欣承袭定陶王。** 定陶恭王刘康之子刘欣三岁承袭定陶王。《诸侯王表》卷014 L1501明确系在阳朔三年前22年。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘普嗣真定王。** 刘普嗣真定王。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **成安严侯郭忠｜承爵。** 表载成安严侯郭忠一支本年记载侯位承袭。表中所载事项为𨜐侯长承爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **营平壮侯赵充国｜承爵。** 表载营平壮侯赵充国一支本年记载侯位承袭。表中所载事项为侯岑承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **建成定侯黄霸｜承爵。** 表载建成定侯黄霸一支本年记载侯位承袭。表中所载事项为忠侯辅承爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **阳平顷侯王禁｜承爵。** 表载阳平顷侯王禁一支本年记载侯位承袭。表中所载事项为厘侯襄承爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **裁将作大匠属官。** 成帝省中候及各中校的五个丞。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[11]](#hs-note-11)

### 1. 八月，王凤去世

> 會大將軍王鳳病，長侍病，晨夜扶丞左右，甚爲甥舅之恩。鳳且終，以長屬托太后及帝。

**互校说明** 《成帝纪》以阳朔三年八月丁巳王凤薨；侍疾和托付为去世前事。

<a id="hs098-l10292-e1"></a>

**[《汉书·元后传》P018](../../拆分史书/汉书/卷098.md#p018)** · [仓内TXT L10292](../../拆分史书/汉书/卷098.md#part-1-L10292)

> 鳳輔政凡十一歲。陽朔三年秋，鳳疾，天子數自臨問，親執其手，涕泣曰：「將軍病，如有不可言，平阿侯譚次將軍矣。」鳳頓首泣曰：「譚等雖與臣至親，行皆奢僭，無以率導百姓，不如御史大夫音謹敕，臣敢以死保之。」及鳳且死，上疏謝上，復固薦音自代，言譚等五人必不可用。天子然之。

**互校说明** 《成帝纪》阳朔三年王凤卒，本传补病中荐王音。

<a id="hs098-l10293-e1"></a>

**[《汉书·元后传》P019](../../拆分史书/汉书/卷098.md#p019)** · [仓内TXT L10293](../../拆分史书/汉书/卷098.md#part-1-L10293)

> 初，譚倨，不肯事鳳，而音敬鳳，卑恭如子，故薦之。鳳薨，天子臨吊贈寵，送以輕車介士，軍陳自長安至渭陵，謚曰敬成侯。子襄嗣侯，為衛尉。御史大夫音竟代鳳為大司馬車騎將軍，而平阿侯譚位特進，領城門兵。谷永說譚，令讓不受城門職，由是與音不平，語在《永傳》。

**互校说明** 同年王凤病死、王音代为大司马。王襄承爵另见本年侯表。

<a id="hs071-l8725-e1"></a>

**[《汉书·隽疏于薛平彭传》P019](../../拆分史书/汉书/卷071.md#p019)** · [仓内TXT L8725](../../拆分史书/汉书/卷071.md#part-1-L8725)

> 由是以列侯為散騎、光祿勳，至御史大夫。

**互校说明** 卷019记阳朔三年十一月；以句末升任为本年事。

<a id="hs085-l9323-e1"></a>

**[《汉书·谷永杜邺传》P019](../../拆分史书/汉书/卷085.md#p019)** · [仓内TXT L9323](../../拆分史书/汉书/卷085.md#part-1-L9323)

> 陽朔中，鳳薨。鳳病困，薦從弟御史大夫音以自代。上從之，以音為大司馬車騎將軍，領尚書事，而平阿侯譚位特進，領城門兵。永聞之，與譚書曰：「君侯躬周召之德，執管晏之操，敬賢下士，樂善不倦，宜在上將久矣，以大將軍在，故抑鬱於家，不得舒憤。今大將軍不幸蚤薨，絫親疏，序材能，宜在君侯。拜吏之日，京師士大夫悵然失望。此皆永等愚劣，不能褒揚萬一。屬聞以特進領城門兵，是則車騎將軍秉政雍容于內，而至戚賢舅執管籥於外也。愚竊不為君侯喜。宜深辭職，自陳淺薄不足以固城門之守，收太伯之讓，保謙謙之路，闔門高枕，為知者首。願君侯與博覽者參之，小子為君侯安此。」譚得其書大感，遂辭讓不受領城門職。由是譚、音相與不平。

**互校说明** 王凤阳朔三年八月卒、九月王音继任见《成帝纪》《百官表》；谷永劝王谭辞领城门兵见《通鉴》卷031同年。

**[《汉书·谷永杜邺传》P042](../../拆分史书/汉书/卷085.md#p042)** · [仓内TXT L9346](../../拆分史书/汉书/卷085.md#part-1-L9346)

> 平阿侯譚不受城門職

**互校说明** 本传补平阿侯不受任；同卷谷永传有劝辞，《通鉴》卷031系阳朔三年。

#### 卷022｜将相表互见与异说

[本年原行R185](../../拆分史书/史记/卷022.md#r185) · [《汉书·百官公卿表》](../../拆分史书/汉书/卷019.md#part-3-ws019-bce-0022)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

王凤死亡为汉010、019阳朔三年八月丁巳明条，是解释王音接职的必要互见；史表只写车骑，汉表有大司马。于永任御史史十月乙卯、汉019十一月丁卯，采用汉表。王章死亡史表在前21年七月，汉019本年记转光禄勋“数月薨”，汉018前21年子渊嗣与本年父卒相接，正文暂归前22，下一年保留异年不再死亡一次。不得与前24年死的京兆尹王章混合 · [成帝纪互见](../../拆分史书/汉书/卷010.md#part-1-text) · [外戚恩泽侯表互见](../../拆分史书/汉书/卷018.md#part-1-text)。

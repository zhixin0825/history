# 公元前22年｜王凤去世，王音接掌军政；王章转光禄勋后去世

[← 公元前23年](bce-0023.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前21年 →](bce-0021.md)

**汉成帝阳朔三年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **八月，王凤去世。** 九月，王音由御史大夫升大司马车骑将军；十一月，于永由光禄勋升御史大夫。右将军安平侯王章也在本年转任光禄勋，不久去世。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **东郡陨石。** 三月壬戌记八块陨石坠于东郡。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **颍川铁官徒众起事。** 申屠圣等一百八十人杀长吏、夺库兵并经九郡，朝廷令丞相长史和御史中丞依军兴规定追捕，最后平定。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **刘欣承袭定陶王。** 定陶恭王刘康之子刘欣三岁承袭定陶王。《诸侯王表》卷014 L1501明确系在阳朔三年前22年。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘普嗣真定王。** 刘普嗣真定王。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **成安严侯郭忠｜承爵。** 表载成安严侯郭忠一支本年记载侯位承袭。表中所载事项为𨜐侯长承爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **营平壮侯赵充国｜承爵。** 表载营平壮侯赵充国一支本年记载侯位承袭。表中所载事项为侯岑承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **建成定侯黄霸｜承爵。** 表载建成定侯黄霸一支本年记载侯位承袭。表中所载事项为忠侯辅承爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **阳平顷侯王禁｜承爵。** 表载阳平顷侯王禁一支本年记载侯位承袭。表中所载事项为厘侯襄承爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **裁将作大匠属官。** 成帝省中候及各中校的五个丞。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[11]](#hs-note-11)

#### 卷022｜将相表互见与异说

[本年原行R185](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r185) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0022)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

王凤死亡为汉010、019阳朔三年八月丁巳明条，是解释王音接职的必要互见；史表只写车骑，汉表有大司马。于永任御史史十月乙卯、汉019十一月丁卯，采用汉表。王章死亡史表在前21年七月，汉019本年记转光禄勋“数月薨”，汉018前21年子渊嗣与本年父卒相接，正文暂归前22，下一年保留异年不再死亡一次。不得与前24年死的京兆尹王章混合 · [成帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7010.md#ref-d3a1668fa1df68) · [外戚恩泽侯表互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-1fa2999ed9fb7b)。

# 公元前23年｜张忠去世，王音接任御史

[← 公元前24年](bce-0024.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前22年 →](bce-0022.md)

**汉成帝阳朔二年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **御史大夫张忠在本年去世，太仆王音接任御史大夫。** 王音随后还将转掌军政，御史任期并未延续到整个张禹相期。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **春寒与顺时月令诏。** 春天气候寒冷，成帝引尧设羲和以定四时，批评奏请不遵时政，要求遵循月令。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **三月大赦。** 三月大赦天下。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **废二级官秩。** 五月废八百石及五百石两级官秩。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **关东洪水与开放流民过关。** 关东大水，诏不要苛留经函谷、天井、壶口、五阮关的流民，派谏大夫、博士分道察视。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **定陶王刘康去世。** 八月甲申，刘康去世。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **重新选举博士。** 奉使人选表现不称职，成帝重申博士须通古今、懂政体，命丞相御史会同官员推举胜任者。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **刘睃嗣鲁王。** 刘睃嗣鲁王。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **刘育嗣六安王。** 刘育嗣六安王。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **刘璜嗣广阳王。** 刘璜嗣广阳王。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **刘衍绍封楚王。** 刘衍绍封楚王。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **刘兴徙中山王。** 刘兴徙中山王。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **正月丙午分封王子侯。** 《王子侯表》列正月丙午受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **閏六月壬午分封王子侯。** 《王子侯表》列閏六月壬午受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **骐侯驹几｜去世。** 表载骐侯驹几一支本年记载去世。表中所载事项为去世，无继承人。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **宜城戴侯燕仓｜承爵。** 表载宜城戴侯燕仓一支本年记载侯位承袭。表中所载事项为炀侯武承爵。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **周子南君姬嘉｜承爵。** 表载周子南君姬嘉一支本年记载侯位承袭。表中所载事项为厘侯世承爵。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **取消八百石、五百石秩。** 成帝废除八百石与五百石两秩。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[19]](#hs-note-19)

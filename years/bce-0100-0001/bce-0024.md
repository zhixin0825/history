# 公元前24年｜阳朔元年开始、二月日食记录

[← 公元前25年](bce-0025.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前23年 →](bce-0023.md)

**汉成帝阳朔元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **阳朔元年开始。** 本年改用阳朔纪年。此前山阳石中生火被作为改元缘由。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **二月日食记录。** 二月丁未晦记日食。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **三月赦徒。** 三月赦天下徒囚。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **王章死狱中。** 冬，京兆尹王章下狱而死。他与前26年所记安平侯、任右将军的王章同名。 [[4]](#hs-note-4)

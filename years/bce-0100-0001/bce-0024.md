# 公元前24年｜阳朔元年开始、二月日食记录

[← 公元前25年](bce-0025.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前23年 →](bce-0023.md)

**汉成帝阳朔元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **阳朔元年开始。** 本年改用阳朔纪年。此前山阳石中生火被作为改元缘由。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **二月日食记录。** 二月丁未晦记日食。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **三月赦徒。** 三月赦天下徒囚。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **王章死狱中。** 冬，京兆尹王章下狱而死。他与前26年所记安平侯、任右将军的王章同名。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘立嗣梁王。** 刘立嗣梁王。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **刘芳嗣楚王。** 刘芳嗣楚王。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **弋阳节侯任宫｜承爵。** 表载弋阳节侯任宫一支本年记载侯位承袭。表中所载事项为孝侯岑承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **义成侯甘延寿｜承爵。** 表载义成侯甘延寿一支本年记载侯位承袭。表中所载事项为炀侯建承爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **月犯心星。** 《汉书》在本年记载月犯心星。 [[10]](#hs-note-10)

### 4. 王章死狱中

[返回正文第4条](#hs-event-4)

<a id="hs060-l8225-e4"></a>

**[《汉书·杜周传》P026](../../sources/摘录/汉书-卷060-杜周传.md#p026)** · [仓内TXT L8225](../../sources/本地分卷/汉书/汉书-卷060.md#L8225)

> 頃之，復日蝕，京兆尹王章上封事求見，果言鳳專權蔽主之過，宜廢勿用，以應天變。於是天子感悟，召見章，與議，欲退鳳。鳳甚憂懼，欽令鳳上疏謝罪，乞骸骨，文指甚哀。太后涕泣為不食。上少而親倚鳳，亦不忍廢，復起鳳就位。鳳心慚，稱病篤，欲遂退。

**互校说明** 同前24二月食、冬狱的连续政治经过。此所涉为京兆尹王章。

<a id="hs060-l8225-e4-2"></a>

**[《汉书·杜周传》P026](../../sources/摘录/汉书-卷060-杜周传.md#p026)** · [仓内TXT L8225](../../sources/本地分卷/汉书/汉书-卷060.md#L8225)

> 鳳復起視事。上令尚書劾奏京兆尹章，章死詔獄。

**互校说明** 《成帝纪》阳朔元年冬。另有同名安平侯王章，务辨。

<a id="hs060-l8226-e4"></a>

**[《汉书·杜周传》P027](../../sources/摘录/汉书-卷060-杜周传.md#p027)** · [仓内TXT L8226](../../sources/本地分卷/汉书/汉书-卷060.md#L8226)

> 章既死，眾庶冤之，以譏朝廷。欽欲救其過，復說鳳曰：「京兆尹章所坐事密，吏民見章素好言事，以為不坐官職，疑其以日蝕見對有所言也。假令章內有所犯，雖陷正法，事不暴揚，自京師不曉，況於遠方。恐天下不知章實有罪，而以為坐言事也。如是，塞爭引之原，損寬明之德。欽愚以為宜因章事舉直言極諫，並見郎從官展盡其章，加於往前，以明示四方，使天下咸知主上聖明，不以言罪下也。

**互校说明** 此为狱后补救劝议，未另明日月。

<a id="hs066-l8524-e4"></a>

**[《汉书·公孙刘田王杨蔡陈郑传》P053](../../sources/摘录/汉书-卷066-公孙刘田王杨蔡陈郑传.md#p053)** · [仓内TXT L8524](../../sources/本地分卷/汉书/汉书-卷066.md#L8524)

> 坐爲京兆尹王章所薦，章誅，咸免官。

<a id="hs067-l8549-e4"></a>

**[《汉书·杨胡朱梅云传》P019](../../sources/摘录/汉书-卷067-杨胡朱梅云传.md#p019)** · [仓内TXT L8549](../../sources/本地分卷/汉书/汉书-卷067.md#L8549)

> 是時成帝委任大將軍王鳳，鳳專埶擅朝，而京兆尹王章素忠直，譏刺鳳，爲鳳所誅。

**互校说明** 王章死有《成帝纪》阳朔元年。下文长疏见《通鉴》另一年。

<a id="hs010-l915-e4"></a>

**[《汉书·成帝纪》P056](../../sources/摘录/汉书-卷010-成帝纪.md#p056)** · [仓内TXT L915](../../sources/本地分卷/汉书/汉书-卷010.md#L915)

# 公元前25年｜王商退相，张禹接掌政务

[← 公元前26年](bce-0026.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前24年 →](bce-0024.md)

**汉成帝河平四年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **四月，王商被免去丞相职位。** 六月，张禹接任丞相；他曾教授成帝《论语》，新君即位后又参与中枢政务，如今以帝师身份进入相位。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **匈奴单于入朝。** 正月匈奴单于来朝。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **赦徒、赐爵与免追欠贷。** 赦天下徒，孝悌力田晋爵两级，未清缴的租赋及赈贷免追。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **单于归国。** 二月单于告退返国。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **三月日食记录。** 癸丑朔记日食。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **黄河沿岸赈灾与给葬。** 派十一人查看沿河水患，对不能自立者给财借贷；死者无力安葬则给棺，已葬每人给两千钱，避灾他郡者给食并妥善照顾，同时荐直言之士。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **长陵附近岸崩。** 壬申长陵近泾水一岸崩塌，壅塞泾水。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **楚王刘嚣去世。** 六月庚戌楚王刘嚣去世。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **山阳石中生火的记录。** 河平四年六月条末记山阳石中生火，并联系次年的改元。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **刘康迁定陶王。** 刘康迁定陶王。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **杜侯复陆支｜获罪。** 表载杜侯复陆支一支本年载相关罪案及处分。表中所载事项为因罪案非子失爵。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **长罗壮侯常惠｜承爵。** 表载长罗壮侯常惠一支本年记载侯位承袭。表中所载事项为侯翕承爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **乐昌共侯王武｜承爵。** 表载乐昌共侯王武一支本年记载侯位承袭。表中所载事项为侯安承爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **博望顷侯许舜｜承爵。** 表载博望顷侯许舜一支本年记载侯位承袭。表中所载事项为厘侯并承爵，去世，无继承人。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **安昌节侯张禹｜受封。** 表载安昌节侯张禹一支本年有始封记载。表中所载事项为六月丙午封。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[16]](#hs-note-16)

#### 卷022｜将相表互见与异说

[本年原行R182](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r182) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0025)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

两表相位同四月壬寅王商免、六月丙午张禹任。张禹早年读经、授太子之事由汉081辨明前情，不都归本年发生。此王商是乐昌侯，不能与成帝母家后来任大司马的成都侯王商混合 · [匡张孔马传互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7081.md#ref-5a448241d7aec3)。

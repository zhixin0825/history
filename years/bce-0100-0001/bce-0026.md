# 公元前26年｜史丹转左将军，王章接右将军

**汉成帝河平三年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **十月，史丹转任左将军，太仆王章接任右将军。** 王章所承袭的是安平侯爵，进入将军官列属于另一项任命。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **犍为地震山崩。** 二月丙戌，犍为地震山崩，堵住江水，水流倒逆。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **八月日食记录。** 乙卯晦记日食。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **刘向校书、陈农访书。** 朝廷令光禄大夫刘向校中秘藏书，遣谒者陈农到各地搜求散失典籍。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **二月乙亥分封王子侯。** 刘嚣入朝有病，朝廷嘉其为王二十余年无过，以广戚四千三百户封其子刘勋。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **弋阳节侯任宫｜承爵。** 表载弋阳节侯任宫一支本年记载侯位承袭。表中所载事项为愿侯恽承爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **东郡侯母辟等起事。** [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **平原再次决口，遣多官共治。** 平原再决后，王延世等奉命治河，六月告成。 [[9]](#hs-note-9)

### 9. 平原再次决口，遣多官共治

[返回正文第9条](#hs-event-9)

<a id="hs029-l6117-e9"></a>

**[《汉书·沟洫志》P023](../../sources/摘录/汉书-卷029-沟洫志.md#p023)** · [仓内TXT L6117](../../sources/本地分卷/汉书/汉书-卷029.md#L6117)

> 後二歲，河復決平原，流入濟南、千乘，所壞敗者半建始時，復遣王延世治之。杜欽說大將軍王鳳，以為「前河決，丞相史楊焉言延世受焉術以塞之，蔽不肯見。今獨任延世，延世見前塞之易，恐其慮害不深。又審如焉言，延世之巧，反不如焉。且水勢各異，不博議利害而任一人，如使不及今冬成，來春桃華水盛，必羨溢，有填淤反壤之害。如此，數郡種不得下，民人流散，盜賊將生，雖重誅延世，無益於事。宜遣焉及將作大匠許商、諫大夫乘馬延年雜作。延世與焉必相破壞，深論便宜，以相難極。商、延年皆明計算，能商功利，足以分別是非，擇其善而從之，必有成功。」鳳如欽言，白遣焉等作治，六月乃成。復賜延世黃金百斤。治河卒非受平賈者，為著外繇六月。

**互校说明** 依《资治通鉴》卷030河平三年。与先前东郡金堤决口及堵塞分年。

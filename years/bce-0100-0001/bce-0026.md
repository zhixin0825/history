# 公元前26年｜史丹转左将军，王章接右将军

**汉成帝河平三年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **十月，史丹转任左将军，太仆王章接任右将军。** 王章所承袭的是安平侯爵，进入将军官列属于另一项任命。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **犍为地震山崩。** 二月丙戌，犍为地震山崩，堵住江水，水流倒逆。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **八月日食记录。** 乙卯晦记日食。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **刘向校书、陈农访书。** 朝廷令光禄大夫刘向校中秘藏书，遣谒者陈农到各地搜求散失典籍。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **二月乙亥分封王子侯。** 《王子侯表》列二月乙亥受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **弋阳节侯任宫｜承爵。** 表载弋阳节侯任宫一支本年记载侯位承袭。表中所载事项为愿侯恽承爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[7]](#hs-note-7)

[本年原行R181](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r181) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0026)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史表本行王章侯号作平安，汉019竟宁元年与汉018王奉光支作安平；采用安平。王章字子然，承安平侯王舜一支，并非后来前24年下狱死的京兆尹王章；同名不把两人的仕历并为一人。史表十月辛卯两项迁将，汉019同河平三年而省月日 · [外戚恩泽侯表互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-d77dd1ef5581f5)。

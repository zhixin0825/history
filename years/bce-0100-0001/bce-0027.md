<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **沛郡冶铁异象。** 记沛郡铁官冶铁时有铁飞异象，详细情节转见五行志。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **五舅封列侯。** 六月王谭、商、立、根、逢时同获列侯爵。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **刘玄嗣淮阳王。** 刘玄嗣淮阳王。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **填星、岁星、荧惑相近。** 《汉书》在本年记载填星、岁星、荧惑相近。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **牂柯太守捕杀夜郎王歆。** 《汉书》在本年记载牂柯太守捕杀夜郎王歆。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **楚国大雹。** 《汉书》在本年记载楚国大雹。 [[7]](#hs-note-7)

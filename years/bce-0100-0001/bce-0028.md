# 公元前28年｜王延世堵河、改元河平、四月日全食记录和大赦

[← 公元前29年](bce-0029.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前27年 →](bce-0027.md)

**汉成帝河平元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **王延世堵河、改元河平。** 三月诏称东郡决口影响两州，校尉王延世堵堤奏效，遂改元河平并分等赐爵。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **四月日全食记录和大赦。** 己亥晦记日食至全。成帝引当时灾异观念责己，命进仁退暴、群臣陈过，随后大赦。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **典属国并入大鸿胪。** 六月撤典属国，将其职事并入大鸿胪。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **恢复太上皇寝庙园。** 九月恢复太上皇寝庙园。 平当引孝道与尊奉汉始祖的礼义为恢复寝庙园进言。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘授嗣胶东王。** 刘授嗣胶东王。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **平恩戴侯许广汉｜承爵。** 表载平恩戴侯许广汉一支本年记载侯位承袭。表中所载事项为严侯况承爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **裁东织并改西织官名。** 省去东织，改西织为织室。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **成帝下诏议减死刑与简律。** 成帝以律令繁多、死刑千余条、比附日增为由，诏会同二千石官、博士及习律者，讨论减少死刑、删繁约省。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **泰山桑谷鸟巢火的记录。** 二月庚子，泰山桑谷有鸟巢起火。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **河平元年日月呈红黑黄的记录。** 正、二月曾见红色日出；二月一度夜月呈红色，又有晨间日光暗弱、地面映出红黄色的现象。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **日出黄、日中见黑气。** [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **成帝复东平王所削两县。** 刘宇在数年前被削樊、亢父二县。成帝闻其改行亲贤，下诏归还。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **复株絫遣右皋林王伊邪莫演奉献。** 河平元年，复株絫遣右皋林王奉献贺正，次年入朝归途又发生请降争议。 [[14]](#hs-note-14)

### 1. 王延世堵河、改元河平

[返回正文第1条](#hs-event-1)

<a id="hs029-l6116-e1"></a>

**[《汉书·沟洫志》P022](../../sources/摘录/汉书-卷029-沟洫志.md#p022)** · [仓内TXT L6116](../../sources/本地分卷/汉书/汉书-卷029.md#L6116)

> 河隄使者王延世使塞，以竹落長四丈，大九圍，盛以小石，兩船夾載而下之。三十六日，河隄成。上曰：「東郡河決，流漂二州，校尉延世隄防三旬立塞。其以五年為河平元年。卒治河者為著外繇六月。惟延世長於計策，功費約省，用力日寡，朕甚嘉之。其以延世為光祿大夫，秩中二千石，賜爵關內侯，黃金百斤。」

**互校说明** 河决在前29，正式告成、改元在前28。

### 4. 恢复太上皇寝庙园

[返回正文第4条](#hs-event-4)

<a id="hs071-l8733-e4"></a>

**[《汉书·隽疏于薛平彭传》P027](../../sources/摘录/汉书-卷071-隽疏于薛平彭传.md#p027)** · [仓内TXT L8733](../../sources/本地分卷/汉书/汉书-卷071.md#L8733)

> 自元帝時，韋玄成為丞相，奏罷太上皇寢廟園，當上書言：「臣聞孔子曰：『如有王者，必世而後仁。』三十年之間，道德和洽，制禮興樂，災害不生，禍亂不作。今聖漢受命而王，繼體承業二百餘年，孜孜不怠，政令清矣。然風俗未和，陰陽未調，災害數見，意者大本有不立與？何德化休征不應之久也！禍福不虛，必有因而至者焉。宜深跡其道而務修其本。昔者帝堯南面而治，先『克膽俊德，以親九族』，而化及萬國《孝經》曰『天地之性人為貴，人之行莫大於孝，孝莫大於嚴父，嚴父莫大於配天，則周公其人也。』夫孝子善述人之志，周公既成文、武之業而製作禮樂，修嚴父配天之事，知文王不欲以子臨父，故推而序之，上極於後稷而以配天。此聖人之德，亡以加於孝也。高皇帝聖德受命，有天下，尊太上皇，猶周文、武之追王太王、王季也。此漢之始祖，後嗣所宜尊奉以廣盛德，孝之至也。《書》云：『正稽古建功立事，可以永年，傳於亡窮。』」上納其言，下詔復太上皇寢廟園。

**互校说明** 传从元帝时罢庙立论，未直书复祀之君与年月；《通鉴》卷030明确平当奏议获纳系成帝河平元年九月，与卷073和《成帝纪》同。

<a id="hs073-l8861-e4"></a>

**[《汉书·韦贤传》P038](../../sources/摘录/汉书-卷073-韦贤传.md#p038)** · [仓内TXT L8861](../../sources/本地分卷/汉书/汉书-卷073.md#L8861)

> 成帝時以無繼嗣，河平元年復復太上皇寢廟園，世世奉祠。昭靈后、武哀王、昭哀后并食於太上寢廟如故，又復擅議宗廟之命。

**互校说明** 《成帝纪》河平元年九月。卷071平当进议，《通鉴》卷030列于同年。

### 9. 成帝下诏议减死刑与简律

[返回正文第9条](#hs-event-9)

<a id="hs023-l5020-e9"></a>

**[《汉书·刑法志》P023](../../sources/摘录/汉书-卷023-刑法志.md#p023)** · [仓内TXT L5020](../../sources/本地分卷/汉书/汉书-卷023.md#L5020)

> 至成帝河平中，復下詔曰：「甫刑云『五刑之屬三千，大辟之罰其屬二百』，今大辟之刑千有餘條，律令煩多，百有餘萬言，奇請它比，日以益滋，自明習者不知所由，欲以曉喻眾庶，不亦難乎！於以羅元元之民，夭絕亡辜，豈不哀哉！其與中二千石、二千石、博士及明習律令者議減死刑及可蠲除約省者，令較然易知，條奏。書不云乎？『惟刑之恤哉！』其審核之，務準古法，朕將盡心覽焉。」有司無仲山父將明之材，不能因時廣宣主恩，建立明制，為一代之法，而徒鉤摭微細，毛舉數事，以塞詔而已。是以大議不立，遂以至今。議者或曰，法難數變，此庸人不達，疑塞治道，聖智之所常患者也。故略舉漢興以來，法令稍定而合古便今者。

**互校说明** 本志仅称河平中；《资治通鉴》卷030 L282、L327–335把同诏列于河平元年。诏前有九月事项，本条未另明月份。

### 13. 成帝复东平王所削两县

[返回正文第13条](#hs-event-13)

<a id="hs080-l9126-e13"></a>

**[《汉书·宣元六王传》P021](../../sources/摘录/汉书-卷080-宣元六王传.md#p021)** · [仓内TXT L9126](../../sources/本地分卷/汉书/汉书-卷080.md#L9126)

> 後三歲，天子詔有司曰：「蓋聞仁以親親，古之道也。前東平王有闕，有司請廢，朕不忍。又請削，朕不敢專。惟王之至親，未嘗忘於心。今聞王改行自新，尊修經術，親近仁人，非法之求，不以奸吏，朕甚嘉焉。傳不雲乎？朝過夕改，君子與之。其復前所削縣如故。」

# 公元前28年｜王延世堵河、改元河平、四月日全食记录和大赦

[← 公元前29年](bce-0029.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前27年 →](bce-0027.md)

**汉成帝河平元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **王延世堵河、改元河平。** 三月诏称东郡决口影响两州，校尉王延世堵堤奏效，遂改元河平并分等赐爵。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **四月日全食记录和大赦。** 己亥晦记日食至全。成帝引当时灾异观念责己，命进仁退暴、群臣陈过，随后大赦。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **典属国并入大鸿胪。** 六月撤典属国，将其职事并入大鸿胪。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **恢复太上皇寝庙园。** 九月恢复太上皇寝庙园。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘授嗣胶东王。** 刘授嗣胶东王。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **平恩戴侯许广汉｜承爵。** 表载平恩戴侯许广汉一支本年记载侯位承袭。表中所载事项为严侯况承爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **裁东织并改西织官名。** 省去东织，改西织为织室。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **成帝下诏议减死刑与简律。** 成帝以律令繁多、死刑千余条、比附日增为由，诏会同二千石官、博士及习律者，讨论减少死刑、删繁约省。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **泰山桑谷鸟巢火的记录。** 《汉书》在本年记载泰山桑谷鸟巢火的记录。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **河平元年日月呈红黑黄的记录。** 《汉书》在本年记载河平元年日月呈红黑黄的记录。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **日出黄、日中见黑气。** 《汉书》在本年记载日出黄、日中见黑气。 [[12]](#hs-note-12)

### 1. 王延世堵河、改元河平

[返回正文第1条](#hs-event-1)

<a id="hs029-l6116-e1"></a>

**[《汉书·沟洫志》P022](../../sources/摘录/汉书-卷029-沟洫志.md#p022)** · [仓内TXT L6116](../../sources/本地分卷/汉书/汉书-卷029.md#L6116)

> 河隄使者王延世使塞，以竹落長四丈，大九圍，盛以小石，兩船夾載而下之。三十六日，河隄成。上曰：「東郡河決，流漂二州，校尉延世隄防三旬立塞。其以五年為河平元年。卒治河者為著外繇六月。惟延世長於計策，功費約省，用力日寡，朕甚嘉之。其以延世為光祿大夫，秩中二千石，賜爵關內侯，黃金百斤。」

**互校说明** 河决在前29，正式告成、改元在前28。

<a id="hs010-l895-e1"></a>

**[《汉书·成帝纪》P036](../../sources/摘录/汉书-卷010-成帝纪.md#p036)** · [仓内TXT L895](../../sources/本地分卷/汉书/汉书-卷010.md#L895)

> 河平元年春三月，詔曰：「河決東郡，流漂二州，校尉王延世隄塞輒平，其改元為河平。賜天下吏民爵，各有差。」

### 2. 四月日全食记录和大赦

[返回正文第2条](#hs-event-2)

<a id="hs027-l5804-e2"></a>

**[《汉书·五行志》P060](../../sources/摘录/汉书-卷027-五行志.md#p060)** · [仓内TXT L5804](../../sources/本地分卷/汉书/汉书-卷027.md#L5804)

<a id="hs010-l896-e2"></a>

> 夏四月己亥晦，日有蝕之，既。詔曰：「朕獲保宗廟，戰戰栗栗，未能奉稱。傳曰：『男教不修，陽事不得，則日為之蝕。』天著厥異，辜在朕躬。公卿大夫其勉悉心，以輔不逮。百寮各修其職，惇任仁人，退遠殘賊。陳朕過失，無有所諱。」大赦天下。

### 9. 成帝下诏议减死刑与简律

[返回正文第9条](#hs-event-9)

<a id="hs023-l5020-e9"></a>

**[《汉书·刑法志》P023](../../sources/摘录/汉书-卷023-刑法志.md#p023)** · [仓内TXT L5020](../../sources/本地分卷/汉书/汉书-卷023.md#L5020)

> 至成帝河平中，復下詔曰：「甫刑云『五刑之屬三千，大辟之罰其屬二百』，今大辟之刑千有餘條，律令煩多，百有餘萬言，奇請它比，日以益滋，自明習者不知所由，欲以曉喻眾庶，不亦難乎！於以羅元元之民，夭絕亡辜，豈不哀哉！其與中二千石、二千石、博士及明習律令者議減死刑及可蠲除約省者，令較然易知，條奏。書不云乎？『惟刑之恤哉！』其審核之，務準古法，朕將盡心覽焉。」有司無仲山父將明之材，不能因時廣宣主恩，建立明制，為一代之法，而徒鉤摭微細，毛舉數事，以塞詔而已。是以大議不立，遂以至今。議者或曰，法難數變，此庸人不達，疑塞治道，聖智之所常患者也。故略舉漢興以來，法令稍定而合古便今者。

**互校说明** 本志仅称河平中；《资治通鉴》卷030 L282、L327–335把同诏列于河平元年。诏前有九月事项，本条未另明月份。

# 公元前29年｜王商任丞相，御史尹忠自杀

**汉成帝建始四年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **三月，王商出任丞相。** 任千秋转左将军，史丹接右将军。秋记桃李结实，黄河大水决东郡金堤。御史大夫尹忠因治河失职，在十月自杀；十一月，张忠由少府升御史大夫。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **罢中书宦官、置尚书。** 春罢中书宦官，初定尚书员五人。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **四月雨雪。** 四月降雪。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **陈临在殿中杀辕丰。** 五月中谒者丞陈临在宫殿中杀司隶校尉辕丰。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **蒌节侯退一支去世。** 建始四年去世，无子嗣承继。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **博成侯张章｜获罪。** 表载博成侯张章一支本年载相关罪案及处分。表中所载事项为因罪案尚阳邑公主与婢奸主旁，数醉骂主，失爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **营平壮侯赵充国｜承爵。** 表载营平壮侯赵充国一支本年记载侯位承袭。表中所载事项为考侯钦承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **乐安侯匡衡｜获罪。** 表载乐安侯匡衡一支本年载相关罪案及处分。表中所载事项为因罪案颛地盗土，失爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **荧惑近岁星。** 《汉书》在本年记载荧惑近岁星。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **月掩填星。** 《汉书》在本年记载月掩填星。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **建始四年九月久雨。** 《汉书》在本年记载建始四年九月久雨。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **长安城南树间群鼠。** 《汉书》在本年记载长安城南树间群鼠。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **稾与肥累坠陨石。** 《汉书》在本年记载稾与肥累坠陨石。 [[14]](#hs-note-14)

#### 卷022｜将相表互见与异说

[本年原行R178](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r178) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0029)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史表相位“右丞相”，汉019只丞相；正文不据一个右字宣称成帝恢复左右双相制度。史表尹忠十月己亥，汉010明建始四年十月以河决不忧职自杀，采用该月；汉表张忠十一月壬戌接职，未将原格张忠与尹忠因同名“忠”误合。王商在汉表相位仍沿称右将军，与前一年将位左将军有差，前官称呼存异，不造第二位同名丞相 · [成帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7010.md#ref-8aabaa692723a7)。

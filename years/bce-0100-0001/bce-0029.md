古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **三月，王商出任丞相。** 任千秋转左将军，史丹接右将军。秋记桃李结实，黄河大水决东郡金堤。御史大夫尹忠因治河失职，在十月自杀；十一月，张忠由少府升御史大夫。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **罢中书宦官、置尚书。** 春罢中书宦官，初定尚书员五人。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **四月雨雪。** 四月降雪。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **陈临在殿中杀辕丰。** 五月中谒者丞陈临在宫殿中杀司隶校尉辕丰。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **蒌节侯退一支去世。** 建始四年去世，无子嗣承继。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **博成侯张章｜获罪。** 表载博成侯张章一支本年载相关罪案及处分。表中所载事项为因罪案尚阳邑公主与婢奸主旁，数醉骂主，失爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **营平壮侯赵充国｜承爵。** 表载营平壮侯赵充国一支本年记载侯位承袭。表中所载事项为考侯钦承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **乐安侯匡衡｜获罪。** 表载乐安侯匡衡一支本年载相关罪案及处分。表中所载事项为因罪案颛地盗土，失爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **荧惑近岁星。** 《汉书》在本年记载荧惑近岁星。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **月掩填星。** 《汉书》在本年记载月掩填星。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **建始四年九月久雨。** 《汉书》在本年记载建始四年九月久雨。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **长安城南树间群鼠。** 《汉书》在本年记载长安城南树间群鼠。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **稾与肥累坠陨石。** 《汉书》在本年记载稾与肥累坠陨石。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **杜钦等在白虎殿再对直言策。** 夏，成帝在白虎殿召见先前举荐的直言之士，问天地、经义、取士、治国。杜钦以仁义与孝为本，并劝变奢伪、少偏宠以广继嗣。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **段会宗被围，陈汤论可自解。** 段会宗报告在西域被乌孙兵围，朝廷议救未定。陈汤判断围兵不足以攻克、远兵也难及时到达，后来驿报送到，围已解除。 [[16]](#hs-note-16)

<a id="hs060-l8221-e15"></a>

**[《汉书·杜周传》P022](../../sources/摘录/汉书-卷060-杜周传.md#p022)** · [仓内TXT L8221](../../sources/本地分卷/汉书/汉书-卷060.md#L8221)

> 其夏，上盡召直言之士詣白虎殿對策，策曰：「天地之道何貴？王者之法何如？《六經》之義何上？人之行何先？取人之術何以？當世之治何務？各以經對。」

**互校说明** 《通鉴》卷030明确把白虎殿再策系建始四年夏，接建始三年冬灾变求言。

<a id="hs060-l8222-e15"></a>

**[《汉书·杜周传》P023](../../sources/摘录/汉书-卷060-杜周传.md#p023)** · [仓内TXT L8222](../../sources/本地分卷/汉书/汉书-卷060.md#L8222)

> 臣聞天道貴信，地道貴貞；不信不貞，萬物不生。生，天地之所貴也。王者承天地之所生，理而成之，昆蟲草木靡不得其所。王者法天地，非仁無以廣施，非義無以正身；克己就義，恕以及人，《六經》之所上也。不孝，則事君不忠，蒞官不敬，戰陳無勇，朋友不信。孔子曰：『孝無終始，而患不及者，未之有也。』孝，人行之所先也。觀本行於鄉黨，考功能於官職，達觀其所舉，富觀其所予，窮觀其所不為，乏觀其所不取，近觀其所為主，遠觀其所主。孔子曰：『視其所以，觀其所由，察其所安，人焉瘦哉？』取人之術也。殷因於夏尚質，周因於殷尚文，今漢家承周、秦之敝，宜抑文尚質，廢奢長儉，表實去偽。孔子曰『惡紫之奪硃』，當世治之所務也。

**互校说明** 同一次白虎殿复策，全文见读本。

<a id="hs-note-16"></a>

### 16. 段会宗被围，陈汤论可自解

[返回正文第16条](#hs-event-16)

<a id="hs070-l8692-e16"></a>

**[《汉书·傅常郑甘陈段传》P034](../../sources/摘录/汉书-卷070-傅常郑甘陈段传.md#p034)** · [仓内TXT L8692](../../sources/本地分卷/汉书/汉书-卷070.md#L8692)

> 後數歲，西域都護段會宗爲烏孫兵所圍，驛騎上書，願發城郭燉煌兵以自救。丞相王商、大將軍王鳳及百僚議數日不決。鳳言「湯多籌策，習外國事，可問。」上召湯見宣室。湯擊郅支時中寒病，兩臂不詘申。湯入見，有詔毋拜，示以會宗奏。湯辭謝，曰：「將相九卿皆賢材通明，小臣罷癃，不足以策大事。」上曰：「國家有急，君其毋讓。」對曰：「臣以爲此必無可憂也。」上曰：「何以言之？」湯曰：「夫胡兵五而當漢兵一，何者？兵刃朴鈍，弓弩不利。今聞頗得漢巧，然猶三而當一。又兵法曰『客倍而主人半然後敵』，今圍會宗者人衆不足以勝會宗，唯陛下勿憂！且兵輕行五十里，重行三十里，今會宗欲發城郭燉煌，歷時迺至，所謂報讎之兵，非救急之用也。」上曰：「奈何？其解可必乎？度何時解？」湯知烏孫瓦合，不能久攻，故事不過數日，因對曰：「已解矣！」詘指計其日，曰：「不出五日，當有吉語聞。」居四日，軍書到，言已解。大將軍鳳奏以爲從事中郎，莫府事壹決於湯。湯明法令，善因事爲埶，納說多從。常受人金錢作章奏，卒以此敗。

**互校说明** 《通鉴》卷030编于建始四年，本传于陈汤免官后只称“後數歲”。围兵无力破城是陈汤的判断。

#### 卷022｜将相表互见与异说

[本年原行R178](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r178) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0029)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

<a id="event-1"></a>

1. **八月，朝廷遣光禄勋收回许嘉的大司马印绶，赐金二百斤。** 十月，尹忠任御史大夫，王商转左将军，任千秋接右将军。十二月，匡衡被免去丞相职务。 王骏任司隶校尉时奏劾匡衡，使匡衡免去丞相职。 匡衡长子杀人被捕，属吏营救未成；匡衡则因侵地另被举劾。 [[1]](#note-1)

<a id="sj052-supplement-event"></a>

2. **卷052的两支世系续记到建始三年，刘景、刘横的卒字与汉表不合。** 城阳一支写到刘景“十五岁，卒”，菑川一支写刘横“十一岁，卒”。但汉表刘景前43元年，在位二十四年；刘横前40元年，在位三十一年，两人本年仍在位。刘景本年从元年算是十四年，若连前44承位年一起算可得十五；刘横前40至前30恰为十一年。这里记录的是后世补叙的截止年及传本冲突，不新增两王在本年去世的事件。 [[2]](#sj052-supplement-note)

<a id="hs-event-3"></a>

3. **赦徒并免收欠贷。** 三月赦徒囚，孝悌力田晋爵二级，欠租赋和赈贷不再追收。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **关内洪水、京师误报与遣使。** 关内有实际洪灾。陈持弓听信洪水将至闯入宫禁，吏民惊登城墙。九月诏区分各地洪灾与京师讹传，责苛吏，遣谏大夫等巡行。 关于长安急传大水，王凤请令民上城避水，左将军王商判断为讹言，成帝听从。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **日食地震与诏举直谏。** 十二月戊申朔史籍记日食，当夜未央宫地震。成帝引灾异说责己，命公卿面陈政失，朝廷及内郡国举能直谏者。 刘庆忌荐太常丞谷永应诏待问。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **越嶲山崩。** 记越嶲地区发生山崩。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **新利侯偃一支失爵。** 建始三年又上书谩，免去侯爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **长罗壮侯常惠｜承爵。** 表载长罗壮侯常惠一支本年记载侯位承袭。表中所载事项为爱侯邯承爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **宜春敬侯王欣｜承爵。** 表载宜春敬侯王欣一支本年记载侯位承袭。表中所载事项为孝侯咸承爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **安成共侯王崇｜承爵。** 表载安成共侯王崇一支本年记载侯位承袭。表中所载事项为靖侯奉世承爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **三辅与十九郡国雨灾。** 《汉书》在本年记载三辅与十九郡国雨灾。 [[12]](#hs-note-12)

13. **京师一度惊传大水。** 《汉书》在本年记载京师一度惊传大水。 [[13]](#hs-note-13)

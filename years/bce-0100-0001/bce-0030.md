**汉成帝建始三年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **八月，朝廷遣光禄勋收回许嘉的大司马印绶，赐金二百斤。** 十月，尹忠任御史大夫，王商转左将军，任千秋接右将军。十二月，匡衡被免去丞相职务。 [[1]](#note-1)

<a id="sj052-supplement-event"></a>

2. **卷052的两支世系续记到建始三年，刘景、刘横的卒字与汉表不合。** 城阳一支写到刘景“十五岁，卒”，菑川一支写刘横“十一岁，卒”。但汉表刘景前43元年，在位二十四年；刘横前40元年，在位三十一年，两人本年仍在位。刘景本年从元年算是十四年，若连前44承位年一起算可得十五；刘横前40至前30恰为十一年。这里记录的是后世补叙的截止年及传本冲突，不新增两王在本年去世的事件。 [[2]](#sj052-supplement-note)

<a id="hs-event-3"></a>

3. **赦徒并免收欠贷。** 三月赦徒囚，孝悌力田晋爵二级，欠租赋和赈贷不再追收。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **关内洪水、京师误报与遣使。** 关内有实际洪灾。陈持弓听信洪水将至闯入宫禁，吏民惊登城墙。九月诏区分各地洪灾与京师讹传，责苛吏，遣谏大夫等巡行。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **日食地震与诏举直谏。** 十二月戊申朔史籍记日食，当夜未央宫地震。成帝引灾异说责己，命公卿面陈政失，朝廷及内郡国举能直谏者。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **越嶲山崩。** 记越嶲地区发生山崩。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **新利侯偃一支失爵。** 建始三年又上书谩，免去侯爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **长罗壮侯常惠｜承爵。** 表载长罗壮侯常惠一支本年记载侯位承袭。表中所载事项为爱侯邯承爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **宜春敬侯王欣｜承爵。** 表载宜春敬侯王欣一支本年记载侯位承袭。表中所载事项为孝侯咸承爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **安成共侯王崇｜承爵。** 表载安成共侯王崇一支本年记载侯位承袭。表中所载事项为靖侯奉世承爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **三辅与十九郡国雨灾。** 《汉书》在本年记载三辅与十九郡国雨灾。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **京师一度惊传大水。** 《汉书》在本年记载京师一度惊传大水。 [[13]](#hs-note-13)

#### 卷022｜将相表互见与异说

[本年原行R177](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r177) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0030)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史表王商同一格重称右将军，汉019明右将军王商改左将军，采用汉表迁职方向，不把光禄大夫与右将军的复述当成独立任命。张谭被免见史表同格，汉019以前瞻“三年坐选举不实免”相接，离职与尹忠接职联读。许嘉本格省主语，依据前官与汉表明确辨人。匡衡免日两表同十二月丁丑；未补他本年去世。

# 公元前31年｜南郊首祭与算赋减免、三辅与内郡举士

[← 公元前32年](bce-0032.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前30年 →](bce-0030.md)

**汉成帝建始二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **南郊首祭与算赋减免。** 正月先罢雍五畤，辛巳始在长安南郊祭上帝。诏说改祭地可减三辅供役，赦相关县与官署徒囚，每算减赋钱四十。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **选定初陵地。** 闰月以渭城延陵亭部为最初选定的皇陵地。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **三辅与内郡举士。** 二月诏三辅、内郡各举一名贤良方正。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **北宫井水上溢。** 三月北宫井水外溢。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **在北郊首次祠后土。** 辛丑，皇帝首次到长安北郊祭后土。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **立许皇后。** 丙午立许氏为皇后。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **罢六厩及技巧官。** 撤销六处御厩和主管技巧的官署。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **大旱。** 夏发生大旱。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **削东平王二县。** 东平王刘宇有罪，削其樊、亢父二县。 刘宇绞杀曾要告发他的姬人朐臑，有司请逮，成帝下诏削县。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **撤博望苑、减少御马。** 将太子旧苑地给在京朝请宗室，同时减少皇帝厩马。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **刘护嗣广陵王。** 刘护嗣广陵王。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **刘宽嗣高密王。** 刘宽嗣高密王。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **阳兴侯昌一支后事。** 建始二年，因……获罪朝私留它县，使庶子杀人，处死于市。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **陵乡侯欣一支失爵。** 建始二年，因……获罪使人伤家丞，又贷谷息过律，免去侯爵。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **正月分封王子侯。** 《王子侯表》列正月受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **合阳爱侯梁喜｜承爵。** 表载合阳爱侯梁喜一支本年记载侯位承袭。表中所载事项为侯放承爵。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **归德靖侯先贤掸｜承爵。** 表载归德靖侯先贤掸一支本年记载侯位承袭。表中所载事项为侯讽承爵。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **乐陵安侯史高｜承爵。** 表载乐陵安侯史高一支本年记载侯位承袭。表中所载事项为康侯崇承爵。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **省水衡技巧、六厩。** 成帝裁撤水衡都尉属下技巧、六厩两官。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **裁减四百七十五处官给祭祠。** 为首次南郊年重新清核祭祠，留二百零八处，详数见本志。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **呼韩邪去世，雕陶莫皋继为复株絫单于。** 呼韩邪本欲立且莫车，听取颛渠阏氏劝告，改立年长的雕陶莫皋，并约传位诸弟。 [[22]](#hs-note-22)

### 22. 呼韩邪去世，雕陶莫皋继为复株絫单于

[返回正文第22条](#hs-event-22)

<a id="hs094-l9857-e22"></a>

**[《汉书·匈奴传》P099](../../sources/摘录/汉书-卷094-匈奴传.md#p099)** · [仓内TXT L9857](../../sources/本地分卷/汉书/汉书-卷094.md#L9857)

> 呼韓邪立二十八年，建始二年死。

**互校说明** 本传与《通鉴》均系建始二年，妇子细节在传内。

<a id="hs094-l9858-e22"></a>

**[《汉书·匈奴传》P100](../../sources/摘录/汉书-卷094-匈奴传.md#p100)** · [仓内TXT L9858](../../sources/本地分卷/汉书/汉书-卷094.md#L9858)

> 匈奴亂十餘年，不絕如髮，賴蒙漢力，故得復安。今平定未久，人民創艾戰鬥，且莫車年少，百姓未附，恐復危國。我與大閼氏一家共子，不如立雕陶莫皋。」大閼氏曰：「且莫車雖少，大臣共持國事，今舍貴立賤，後世必亂。」單于卒從顓渠閼氏計，立雕陶莫皋，約令傳國與弟。呼韓邪死，雕陶莫皋立，為復株絫若鞮單于。

**互校说明** 接本段前呼韩邪建始二年崩，两位阏氏的争论为同一继承经过。

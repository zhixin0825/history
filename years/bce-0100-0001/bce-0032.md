# 公元前32年｜皇曾祖庙火灾、姚尹使团遭风火

[← 公元前33年](bce-0033.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前31年 →](bce-0031.md)

**汉成帝建始元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **皇曾祖庙火灾。** 正月乙丑，皇曾祖悼考庙失火。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **河间王再封。** 立旧河间王的弟弟、上郡库令刘良为王。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **营室彗象。** 史官记营室星区有彗星。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **撤上林诏狱。** 罢撤上林的诏狱。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **姚尹使团遭风火。** 姚尹等从匈奴返程，离塞尚百余里遇暴风火灾，姚尹等七人死。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **分赐官民金帛牛酒。** 按身份与秩级给王侯官吏、宗室、三老、孝悌力田及孤弱金钱与帛，吏民按户数赐牛酒。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **灾异诏及大赦。** 成帝把祖庙失火、彗象视作告戒，命百官行宽恕、去苛刻，下令大赦。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **封王崇与五舅。** 王崇封安成侯，其余五位舅父王谭、商、立、根、逢时获关内侯爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **黄雾与苍蝇群集。** 四月黄雾弥漫，朝廷广问公卿；六月记无数苍蝇聚在未央宫朝会坐处。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **停用上林二十五所宫馆。** 秋罢撤上林少有御幸的宫馆二十五所。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **清晨东方见两月。** 八月传文记清晨东方出现如两个月影相叠的天象。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **流星贯紫宫。** 九月戊子见强光流星照地，史官形容长四五丈、曲如蛇而经过紫宫。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **建长安南北郊、停甘泉汾阴旧祭。** 十二月设长安南北郊，罢甘泉、汾阴祠。同日大风拔甘泉大木，受灾达四成的郡国不征田租。 [[13]](#hs-note-13)

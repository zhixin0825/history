# 公元前33年｜成帝即位，王凤掌中枢军政

[← 公元前34年](bce-0034.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前32年 →](bce-0032.md)

**汉元帝竟宁元年；汉成帝本年即位**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **五月，元帝去世，六月刘骜即位。** 皇后的兄长王凤升大司马大将军，领尚书事。御史大夫延寿二月去世，张谭随后接任御史大夫；《冯奉世传》称李延寿，《陈汤传》作繁延寿。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **呼韩邪入朝及王嫱出塞。** 呼韩邪入朝，诏称其愿保边，以此改元竟宁，将掖庭待诏王嫱赐为其阏氏。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **太子加冠与赐爵。** 皇太子行冠礼，赐列侯嗣子五大夫，天下为父后者晋爵一级。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **恢复惠帝和两太后寝园。** 三月癸未恢复惠帝寝庙园及孝文、孝昭两位太后寝园。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **郅支战后封赏。** 夏封甘延寿为列侯，赐陈汤关内侯爵、黄金百斤。受赏与前36年出兵分年。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **元帝死后裁撤部分庙园。** 毁太上皇及惠帝、景帝庙，罢两太后、昭灵后、武哀王、昭哀后寝园。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **元帝葬渭陵。** 七月丙戌安葬渭陵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **裁去不合礼的随葬品。** 乙未有司奏称御车、牛马、禽兽不宜随葬，得到批准。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **七月大赦。** 七月大赦天下。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **四月丁卯分封王子侯。** 《王子侯表》列四月丁卯受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **建平敬侯杜延年｜承爵。** 表载建平敬侯杜延年一支本年记载侯位承袭。表中所载事项为荒侯业承爵。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **宜城戴侯燕仓｜承爵。** 表载宜城戴侯燕仓一支本年记载侯位承袭。表中所载事项为厘侯尊承爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **归德靖侯先贤掸｜承爵。** 表载归德靖侯先贤掸一支本年记载侯位承袭。表中所载事项为炀侯富昌承爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **段会宗首次任西域都护。** 五府推荐杜陵令段会宗任西域都护、骑都尉、光禄大夫。他在西域以恩信得人敬服。 [[15]](#hs-note-15)

<a id="hs070-l8687-e5"></a>

**[《汉书·傅常郑甘陈段传》P029](../../sources/摘录/汉书-卷070-傅常郑甘陈段传.md#p029)** · [仓内TXT L8687](../../sources/本地分卷/汉书/汉书-卷070.md#L8687)

> 司隷校尉移書道上，繫吏士按驗之。湯上疏言：「臣與吏士共誅郅支單于，幸得禽滅，萬里振旅，宜有使者迎勞道路。今司隷反逆収繫按驗，是爲郅支報讎也！」上立出吏士，令縣道具酒食以過軍。

<a id="hs070-l8688-e5"></a>

**[《汉书·傅常郑甘陈段传》P030](../../sources/摘录/汉书-卷070-傅常郑甘陈段传.md#p030)** · [仓内TXT L8688](../../sources/本地分卷/汉书/汉书-卷070.md#L8688)

> 故宗正劉向上疏曰：「郅支單于囚殺使者吏士以百數，事暴揚外國，傷威毀重，群臣皆閔焉。陛下赫然欲誅之，意未甞有忘。西域都護延壽、副校尉湯承聖指，倚神靈，緫百蠻之君，㩜城郭之兵，出百死，入絕域，遂蹈康居，屠五重城，搴歙侯之旗，斬郅支之首，縣旌萬里之外，揚威昆山之西，埽谷吉之恥，立昭明之功，萬夷慴伏，莫不懼震。呼韓邪單于見郅支已誅，且喜且懼，鄉風馳義，稽首來賔，願守北藩，累世稱臣。立千載之功，建萬世之安，羣臣之勳莫大焉。昔周大夫方叔、吉甫爲宣王誅獫狁而百蠻從，其詩曰：『嘽嘽焞焞，如霆如雷，顯允方叔，征伐獫狁，蠻荊來威。』《易》曰：『有嘉折首，獲匪其醜。』言美誅首惡之人，而諸不順者皆來從也。今延壽、湯所誅震，雖易之折首、詩之雷霆不能及也。論大功者不錄小過，舉大美者不疵細瑕。司馬法曰『軍賞不踰月』，欲民速得爲善之利也。蓋急武功，重用人也。吉甫之歸，周厚賜之，其《詩》曰：『吉甫宴喜，旣多受祉，來歸自鎬，我行永乆。』千里之鎬猶以爲遠，況萬里之外，其勤至矣！延壽、湯旣未獲受祉之報，反屈捐命之功，久挫於刀筆之前，非所以勸有功厲戎士也。昔齊桓公前有尊周之功，後有滅項之罪，君子以功覆過而爲之諱行事。貳師將軍李廣利捐五萬之師，靡億萬之費，經四年之勞，而廑獲駿馬三十匹，雖斬宛王毌鼔之首，作毌寡，而此云毌鼓，鼓寡聲相近，蓋戎狄之言不甚諦也。猶不足以復費，其私罪惡甚多。孝武以爲萬里征伐，不錄其過，遂封拜兩侯、三卿、二千石百有餘人。今康居國彊於大宛，郅支之號重於宛王，殺使者罪甚於留馬，而延壽、湯不煩漢士，不費斗糧，比於貳師，功德百之。且常惠隨欲擊之烏孫，鄭吉迎自來之日逐，猶皆裂土受爵。故言威武勤勞則大於方叔、吉甫，列功覆過則優於齊桓、貳師，近事之功則高於安遠、長羅，而大功未著，小惡數布，臣竊痛之！宜以時解縣通籍，除過勿治，尊寵爵位，以勸有功。」

**互校说明** 从封赏奏议接读；奏在授赏前，未另载月日。

# 公元前33年｜成帝即位，王凤掌中枢军政

[← 公元前34年](bce-0034.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前32年 →](bce-0032.md)

**汉元帝竟宁元年；汉成帝本年即位**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **五月，元帝去世，六月刘骜即位。** 皇后的兄长王凤升大司马大将军，领尚书事。御史大夫延寿二月去世，张谭随后接任御史大夫；《冯奉世传》称李延寿，《陈汤传》作繁延寿。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **呼韩邪入朝及王嫱出塞。** 呼韩邪入朝，诏称其愿保边，以此改元竟宁，将掖庭待诏王嫱赐为其阏氏。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **太子加冠与赐爵。** 皇太子行冠礼，赐列侯嗣子五大夫，天下为父后者晋爵一级。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **恢复惠帝和两太后寝园。** 三月癸未恢复惠帝寝庙园及孝文、孝昭两位太后寝园。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **郅支战后封赏。** 夏封甘延寿为列侯，赐陈汤关内侯爵、黄金百斤。受赏与前36年出兵分年。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **元帝死后裁撤部分庙园。** 毁太上皇及惠帝、景帝庙，罢两太后、昭灵后、武哀王、昭哀后寝园。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **元帝葬渭陵。** 七月丙戌安葬渭陵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **裁去不合礼的随葬品。** 乙未有司奏称御车、牛马、禽兽不宜随葬，得到批准。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **七月大赦。** 七月大赦天下。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **四月丁卯分封王子侯。** 《王子侯表》列四月丁卯受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **建平敬侯杜延年｜承爵。** 表载建平敬侯杜延年一支本年记载侯位承袭。表中所载事项为荒侯业承爵。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **宜城戴侯燕仓｜承爵。** 表载宜城戴侯燕仓一支本年记载侯位承袭。表中所载事项为厘侯尊承爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **归德靖侯先贤掸｜承爵。** 表载归德靖侯先贤掸一支本年记载侯位承袭。表中所载事项为炀侯富昌承爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[14]](#hs-note-14)

# 公元前34年｜元帝大赦并令官吏勿误春耕

[← 公元前35年](bce-0035.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前33年 →](bce-0033.md)

**汉元帝建昭五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **元帝大赦并令官吏勿误春耕。** 三月元帝大赦并赐爵物，又令各官不要重查小案、征召证人而耽误百姓春季耕织。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **恢复戾园。** 六月庚申恢复戾园。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **六月日食记录。** 壬申晦记日食，月份接上行六月。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **恢复诸寝庙园。** 七月庚子恢复太上皇寝庙园、原庙及昭灵后、武哀王、昭哀后、卫思后等祭园。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘意嗣广陵王。** 刘意嗣广陵王。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **十二月分封王子侯。** 《王子侯表》列十二月受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **橐茅乡社槐树与禁私社。** 《汉书》在本年记载橐茅乡社槐树与禁私社。 [[8]](#hs-note-8)

# 公元前35年｜郅支首级抵京，告祭郊庙并大赦、遣二十一人巡行访民举士

[← 公元前36年](bce-0036.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前34年 →](bce-0034.md)

**汉元帝建昭四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **郅支首级抵京，告祭郊庙并大赦。** 正月，朝廷告祭郊庙并大赦。《资治通鉴》同月记郅支首级抵京，廷议后悬示。交战与郅支之死见前36年。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **遣二十一人巡行访民举士。** 四月因饥荒，遣赏等二十一人巡问困弱、举特立茂才，令各官认真落实以察地方教化。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **中山王刘竟去世。** 六月甲申中山王刘竟去世。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **山崩沙石壅水。** 蓝田沙石壅霸水，安陵岸崩堵泾水，水流倒逆。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **藉阳侯显一支失爵。** 建昭四年，因……获罪恐猲国民取财物，免去侯爵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **六月分封王子侯。** 《王子侯表》列六月受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **安平夷侯王舜｜承爵。** 表载安平夷侯王舜一支本年记载侯位承袭。表中所载事项为刚侯章承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **建昭四年春雪和燕死。** 《汉书》在本年记载建昭四年春雪和燕死。 [[9]](#hs-note-9)

### 1. 郅支首级抵京，告祭郊庙并大赦

[返回正文第1条](#hs-event-1)

<a id="hs070-l8686-e1"></a>

**[《汉书·傅常郑甘陈段传》P028](../../sources/摘录/汉书-卷070-傅常郑甘陈段传.md#p028)** · [仓内TXT L8686](../../sources/本地分卷/汉书/汉书-卷070.md#L8686)

> 於是延壽、湯上疏曰：「臣聞天下之大義，當混爲一，昔有唐虞，今有彊漢。匈奴呼韓邪單于已稱北藩，唯郅支單于叛逆，未伏其辜，大夏之西，以爲彊漢不能臣也。郅支單于慘毒行於民，大惡通於天。臣延壽、臣湯將義兵，行天誅，賴陛下神靈，陰陽並應，天氣精明，陷陳克敵，斬郅支首及名王以下。宜縣頭槀街蠻夷邸閒，以示萬里，明犯彊漢者，雖遠必誅。」事下有司。丞相匡衡、御史大夫繁延壽以爲「郅支及名王首更歷諸國，蠻夷莫不聞知。月令春『掩骼埋胔』之時，宜勿縣。」車騎將軍許嘉、右將軍王商以爲「春秋夾谷之會，優施笑君，孔子誅之，方盛夏，首足異門而出。宜縣十日迺埋之。」有詔將軍議是。

**互校说明** 《元帝纪》把首级送京连书在建昭三年战事。《通鉴》将首至京、上疏和廷议续于四年正月。

<a id="hs009-l841-e1"></a>

**[《汉书·元帝纪》P060](../../sources/摘录/汉书-卷009-元帝纪.md#p060)** · [仓内TXT L841](../../sources/本地分卷/汉书/汉书-卷009.md#L841)

> 四年春正月，以誅郅支單于告祠郊廟。赦天下。群臣上壽置酒，以其圖書示後宮貴人。

### 2. 遣二十一人巡行访民举士

<a id="hs009-l842-e2"></a>

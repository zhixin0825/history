# 公元前35年｜郅支首级抵京，告祭郊庙并大赦、遣二十一人巡行访民举士

[← 公元前36年](bce-0036.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前34年 →](bce-0034.md)

**汉元帝建昭四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **郅支首级抵京，告祭郊庙并大赦。** 正月，朝廷告祭郊庙并大赦。《资治通鉴》同月记郅支首级抵京，廷议后悬示。交战与郅支之死见前36年。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **遣二十一人巡行访民举士。** 四月因饥荒，遣赏等二十一人巡问困弱、举特立茂才，令各官认真落实以察地方教化。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **中山王刘竟去世。** 六月甲申中山王刘竟去世。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **山崩沙石壅水。** 蓝田沙石壅霸水，安陵岸崩堵泾水，水流倒逆。 [[4]](#hs-note-4)

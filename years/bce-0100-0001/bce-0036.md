# 公元前36年｜韦玄成去世，匡衡接任丞相

[← 公元前37年](bce-0037.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前35年 →](bce-0035.md)

**汉元帝建昭三年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **六月，丞相韦玄成去世。** 七月，匡衡升为丞相，封乐安侯，御史大夫职位则由李延寿接任。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **都尉秩升二千石。** 三辅及大郡的都尉秩都定为二千石。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **甘延寿、陈汤出兵斩郅支。** 甘延寿、陈汤发屯田吏士和西域兵，冬季击杀郅支单于。本纪连书首级送京和悬示，《通鉴》系这些后续于次年前35年。 [[3]](#hs-note-3)

#### 卷022｜将相表互见与异说

[本年原行R171](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r171) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0036)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史、汉两表均六月甲辰玄成卒、七月癸亥匡衡任相。御史史作繁延寿，汉019为李延寿并注一姓縏；正文采用李延寿并保留繁、縏异姓，不混作较早的大司马许延寿或循吏韩延寿。“一姓”说明保留为姓名异文，不编成同年两位御史。

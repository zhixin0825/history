# 公元前37年｜御史职位由郑弘转给匡衡

**汉元帝建昭二年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **郑弘被免去御史大夫职位后，匡衡由光禄勋升任御史大夫。** 匡衡以经学进入朝廷，如今继续升入公卿之列。 京房、张博同年因西平侯案获罪，京房弃市，张博腰斩。 石显另借槐里令朱云案奏劾与朱云相善的御史中丞陈咸，陈咸减死为城旦。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **巡祭与提高三河太守秩。** 正月甘泉郊祭，三月河东祠后土，提高三河太守的秩级，以十二万户作为大郡标准。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **四月赦天下。** 夏四月施行大赦。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **立信都王、上官太皇太后去世。** 六月立皇子刘兴为信都王，闰月丁酉上官太皇太后去世。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **齐楚地震和大雪。** 十一月齐、楚地区地震并大雪，树折屋毁。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **宣阳侯赐一支失爵。** 建昭二年，因……获罪上书归印绶免去侯爵八百户。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **齐楚深雪。** 《汉书》在本年记载齐楚深雪。 [[8]](#hs-note-8)

> 時槐里令朱雲殘酷殺不辜，有司舉奏，未下。咸素善雲，雲從刺候，教令上書自訟。於是石顯微伺知之，白奏咸漏泄省中語，下獄掠治，減死，髡爲城旦，因廢。

**互校说明** 《通鉴》建昭二年接在京房、郑弘案后。两案同年，陈咸获罪因朱云案泄露省中语。

> 六歲，坐與京房論議免

**互校说明** 《百官公卿表》与《通鉴》建昭二年。

<a id="hs067-l8542-e1"></a>

**[《汉书·杨胡朱梅云传》P012](../../sources/摘录/汉书-卷067-杨胡朱梅云传.md#p012)** · [仓内TXT L8542](../../sources/本地分卷/汉书/汉书-卷067.md#L8542)

> 時中書令石顯用事，與充宗爲黨，百僚畏之。唯御史中丞陳咸年少抗節，不附顯等，而與雲相結。雲數上疏，言丞相韋玄成容身保位，亡能往來，而咸數毀石顯。乆之，有司考雲，疑風吏殺人。羣臣朝見，上問丞相以雲治行。丞相玄成言雲暴虐亡狀。時陳咸在前，聞之，以語雲。雲上書自訟，咸爲定奏草，求下御史中丞。事下丞相，丞相部吏考立其殺人罪。雲亡入長安，復與咸計議。丞相具發其事，奏「咸宿衞執法之臣，幸得進見，漏泄所聞，以私語雲，爲定奏草，欲令自下治，後知雲亡命罪人，而與交通，雲以故不得。」上於是下咸、雲獄，減死爲城旦。咸、雲遂廢錮，終元帝世。

**互校说明** 与卷066陈咸传对读，案结从《通鉴》建昭二年。朱云此前迁杜陵、槐里未据此一概归年。

**[《汉书·元帝纪》P056](../../sources/摘录/汉书-卷009-元帝纪.md#p056)** · [仓内TXT L837](../../sources/本地分卷/汉书/汉书-卷009.md#L837)

> 淮陽王舅張博、魏郡太守京房坐窺道諸侯王以邪意，漏泄省中語，博要斬，房棄市。

**互校说明** 《通鉴考异》据郑弘已在八月免官，认为本纪附在岁末的京房案月日未详。

**[公元前37年](../../sources/摘录/前0037年-御史任免原文.md#汉书066-郑弘传)**

> 鄭弘
> 鄭弘字稚卿，泰山剛人也。兄昌字次卿，亦好學，皆明經，通法律政事。次卿爲太原、涿郡太守，弘爲南陽太守，皆著治跡，條教法度，爲後所述。次卿用刑罰深，不如弘平。遷淮陽相，以髙弟入爲右扶風，京師稱之。代韋玄成爲御史大夫。六歲，坐與京房論議免，語在房傳。

#### 卷022｜将相表互见与异说

[本年原行R170](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r170) · [《汉书·百官公卿表》](../../sources/%E6%91%98%E5%BD%95/%E5%89%8D0037%E5%B9%B4-%E5%BE%A1%E5%8F%B2%E4%BB%BB%E5%85%8D%E5%8E%9F%E6%96%87.md#%E6%B1%89%E4%B9%A6019-%E7%99%BE%E5%AE%98%E5%85%AC%E5%8D%BF%E8%A1%A8)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

[汉066](../../sources/%E6%91%98%E5%BD%95/%E5%89%8D0037%E5%B9%B4-%E5%BE%A1%E5%8F%B2%E4%BB%BB%E5%85%8D%E5%8E%9F%E6%96%87.md#%E6%B1%89%E4%B9%A6066-%E9%83%91%E5%BC%98%E4%BC%A0) · [汉075](../../sources/%E6%91%98%E5%BD%95/%E5%89%8D0037%E5%B9%B4-%E5%BE%A1%E5%8F%B2%E4%BB%BB%E5%85%8D%E5%8E%9F%E6%96%87.md#%E6%B1%89%E4%B9%A6075-%E4%BA%AC%E6%88%BF%E4%BC%A0)。史表将位“弘免”指御史郑弘，不是将军免官。汉019永光二年记郑弘五年有罪自杀，建昭二年另明八月癸亥匡衡接职，前瞻任数与史表简单“免”不完全相同，汉066记与京房论议而免、汉075建昭二年京房案明记免为庶人，正文采用免官；不把汉表前瞻任年中的自杀写成已定终局。中文维基《郑弘（西汉）》正文列出自杀与仅罢免两说；百度《郑弘》在首段给前37卒，后引本传仍只记免官。百度《匡衡》将任光禄勋、御史并述于前37，《汉书·百官公卿表》在前38已记任光禄勋，次年八月接御史。

# 公元前38年｜废迁河间王与撤寝园

**汉元帝建昭元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **雍祭五畤。** 三月元帝到雍祭五畤。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **白蛾群飞。** 八月记白蛾从东都门到枳道群飞蔽日。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

<a id="hs-event-4"></a>

3. **河间王刘元被废徙房陵，并记撤寝园。** 废迁河间王与撤寝园。河间王刘元因罪废徙房陵，孝文、孝昭太后的寝园亦被停罢。刘元获罪废迁房陵。 [[3]](#hs-note-3)

<a id="hs-event-5"></a>

4. **刘雍嗣真定王。** 刘雍嗣真定王。 [[4]](#hs-note-5)

<a id="hs-event-6"></a>

5. **东襄爱侯宽一支去世。** 建昭元年去世，无子嗣承继。 [[5]](#hs-note-6)

<a id="hs-event-7"></a>

6. **正月分封王子侯。** [[6]](#hs-note-7)

<a id="hs-event-8"></a>

7. **平台康侯史玄｜承爵。** 表载平台康侯史玄一支本年记载侯位承袭。表中所载事项为戴侯恁承爵。 [[7]](#hs-note-8)

<a id="hs-event-9"></a>

8. **乐成侯许延寿后嗣｜承爵。** 表载乐成侯许延寿后嗣一支本年记载侯位承袭。表中所载事项为康侯去疾承爵。 [[8]](#hs-note-9)

<a id="hs-event-10"></a>

9. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[9]](#hs-note-10)

<a id="hs-event-11"></a>

10. **梁国坠陨石六。** [[10]](#hs-note-11)

<a id="hs-event-12"></a>

11. **冯婕妤在虎圈兽斗中挡熊。** 元帝观斗兽时熊逸出圈，冯婕妤站在帝座前，侍者将熊格杀。 [[11]](#hs-note-12)

### 11. 冯婕妤在虎圈兽斗中挡熊

[返回正文第11条](#hs-event-12)

<a id="hs097-l10259-e12"></a>

**[《汉书·外戚传》P139](../../拆分史书/汉书/卷097.md#p139)** · [仓内TXT L10259](../../拆分史书/汉书/卷097.md#part-1-L10259)

> 建昭中，上幸虎圈鬥獸，後宮皆坐。熊佚出圈，攀檻欲上殿。左右貴人傅昭儀等皆驚走，馮婕妤直前當熊而立，左右格殺熊。上問：「人情驚懼，何故前當熊？」婕妤對曰：「猛獸得人而止，妾恐熊至御坐，故以身當之。」元帝嗟嘆，以此倍敬重焉。傅昭儀等皆慚。

**互校说明** 本传称建昭中，下一句明说翌年夏其子立信都王；《元帝纪》明确刘兴封在建昭二年六月，故系建昭元年，无月日。

# 公元前39年｜甘泉、河东巡祭、颍川水灾与遣卒归

**汉元帝永光五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **甘泉、河东巡祭。** 正月甘泉祭泰畤，三月到河东祠后土。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

<a id="hs-event-7"></a>

2. **颍川等地水灾，朝廷遣卒归。** 颍川洪水致死伤；相关受灾官吏和从官获假，部分士卒遣归。颍川等四地水灾。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **长杨射熊馆田猎。** 冬赴长杨射熊馆，布置车骑举行大猎。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **毁太上皇、惠帝寝庙园。** 十二月乙酉，拆毁太上皇及孝惠帝的寝庙园。 高帝定为太祖、文帝定为太宗，韦玄成等奏定昭穆，并请将惠帝神主迁太祖庙。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘嘉嗣梁王。** 刘嘉嗣梁王。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **三月分封王子侯。** [[6]](#hs-note-6)

<a id="hs-event-8"></a>

7. **清河灵鸣犊口决而屯氏河断流。** 元帝永光五年清河灵鸣犊口决，屯氏河断流。 [[7]](#hs-note-8)

<a id="hs-event-9"></a>

8. **匡衡劝元帝守宣帝之政与正家。** 傅昭仪与刘康得宠，匡衡劝元帝承扬先帝政绩、辨嫡庶并依礼自省。 [[8]](#hs-note-9)

### 4. 毁太上皇、惠帝寝庙园

[返回正文第4条](#hs-event-4)

<a id="hs073-l8856-e4"></a>

**[《汉书·韦贤传》P033](../../sources/摘录/汉书-卷073-韦贤传.md#p033)** · [仓内TXT L8856](../../sources/本地分卷/汉书/汉书-卷073.md#L8856)

> 於是上重其事，依違者一年，乃下詔曰：「蓋聞王者祖有功而宗有德，尊尊之大義也；存親廟四，親親之至恩也。高皇帝為天下誅暴除亂，受命而帝，功莫大焉。孝文皇帝國為代王，諸呂作亂，海內搖動，然群臣黎庶靡不壹意，北面而歸心，猶謙辭固讓而後即位，削亂秦之跡，興三代之風，是以百姓晏然，咸獲嘉福，德莫盛焉。高皇帝為漢太祖，孝文皇帝為太宗，世世承祀，傳之無窮，朕甚樂之。孝宣皇帝為孝昭皇帝後，於義壹體。孝景皇帝廟及皇考廟皆親盡，其正禮儀。」玄成等奏曰：「祖宗之廟世世不毀，繼祖以下，五廟而迭毀。今高皇帝為太祖，孝文皇帝為太宗，孝景皇帝為昭，孝武皇帝為穆，孝昭皇帝與孝宣皇帝俱為昭。皇考廟親未盡。太上、孝惠廟皆親盡，宜毀。太上廟主宜瘞園，孝惠皇帝為穆，主遷於太祖廟，寢園皆無復修。」奏可。

**互校说明** 《通鉴》卷029系永光五年（前39年），见本卷以下引文，本行入该年。

<a id="hs081-l9151-e9"></a>

**[《汉书·匡张孔马传》P011](../../sources/摘录/汉书-卷081-匡张孔马传.md#p011)** · [仓内TXT L9151](../../sources/本地分卷/汉书/汉书-卷081.md#L9151)

> 臣聞治亂安危之機，在乎審所用心。蓋受命之王務在創業垂統傳之無窮，繼體之君心存於承宣先王之德而褒大其功。昔者成王之嗣位，思述文、武之道以養其心，休烈盛美皆歸之二後而不敢專其名，是以上天歆享，鬼神祐焉。其《詩》曰：「念我皇祖，陟降廷止。」言成王常思祖考之業，而鬼神祐助其治也。

**互校说明** 《通鉴》卷029永光五年记同一疏。

<a id="hs081-l9152-e9"></a>

**[《汉书·匡张孔马传》P012](../../sources/摘录/汉书-卷081-匡张孔马传.md#p012)** · [仓内TXT L9152](../../sources/本地分卷/汉书/汉书-卷081.md#L9152)

> 陛下聖德天覆，子愛海內，然陰陽未和，奸邪未禁者，殆論議者未丕揚先帝之盛功，爭言制度不可用也，務變更之，所更或不可行，而復復之，是以群下更相是非，吏民無所信。臣竊恨國家釋樂成之業，而虛為此紛紛也。願陛下詳覽統業之事，留神於遵制揚功，以定群下之心。《大雅》曰：「無念爾祖，聿修厥德。」孔子著之《孝經》首章，蓋至德之本也。傳曰：「審好惡，理情性，而王道畢矣。」能盡其性，然後能盡人物之性；能盡人物之性，可以贊天地之化。治性之道，必審已之所有餘，而強其所不足。蓋聰明疏通者戒於大察，寡聞少見者戒於雍蔽，勇猛剛強者戒於大暴，仁愛溫良者戒於無斷，湛靜安舒者戒於後時，廣心浩大者戒於遺忘。必審己之所當戒，而齊之以義，然後中和之化應，而巧偽之徒不敢比周而望進。唯陛下戒所以崇聖德。

**互校说明** 同为守宣帝成法之谏。

<a id="hs081-l9153-e9"></a>

**[《汉书·匡张孔马传》P013](../../sources/摘录/汉书-卷081-匡张孔马传.md#p013)** · [仓内TXT L9153](../../sources/本地分卷/汉书/汉书-卷081.md#L9153)

> 臣又聞室家之道修，則天下之理得，故《詩》始《國風》，《禮》本《冠》、《婚》。始乎《國風》，原情性而明人倫也；本乎《冠》、《婚》，正基兆而防未然也。福之興莫不本乎室家。道之衰莫不始乎閫內。故聖王必慎妃後之際，別適長之位。禮之於內也。卑不逾尊，新不先故，所以統人情而理陰氣也。其尊適而卑庶也，適子冠乎阼，禮之用醴，眾子不得與列，所以貴正體而明嫌疑也。非虛加其禮文而已，乃中心與之殊異，故禮探其情而見之外也。聖人動靜游燕，所親物得其序；得其序，則海內自修，百姓從化。如當親者疏，當尊者卑，則佞巧之奸因時而動，以亂國家。故聖人慎防其端，禁於未然，不以私恩害公義。陛下聖德純備，莫不修正，則天下無為而治。《詩》云：「於以四方，克定厥家。」傳曰：「正家而天下定矣。」

**互校说明** 同一疏劝正嫡庶。

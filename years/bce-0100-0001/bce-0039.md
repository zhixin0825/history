# 公元前39年｜甘泉、河东巡祭、颍川水灾与遣卒归

[← 公元前40年](bce-0040.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前38年 →](bce-0038.md)

**汉元帝永光五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **甘泉、河东巡祭。** 正月甘泉祭泰畤，三月到河东祠后土。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **颍川水灾与遣卒归。** 颍川洪水致死伤；相关受灾官吏和从官获假，部分士卒遣归。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **长杨射熊馆田猎。** 冬赴长杨射熊馆，布置车骑举行大猎。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **毁太上皇、惠帝寝庙园。** 十二月乙酉，拆毁太上皇及孝惠帝的寝庙园。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘嘉嗣梁王。** 刘嘉嗣梁王。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **三月分封王子侯。** 《王子侯表》列三月受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **颍川等四地水灾。** 《汉书》在本年记载颍川等四地水灾。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **清河灵鸣犊口决而屯氏河断流。** 元帝永光五年清河灵鸣犊口决，屯氏河断流。 [[8]](#hs-note-8)

# 公元前40年｜大赦并免收贫民借贷、宣帝陵园东阙失火

[← 公元前41年](bce-0041.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前39年 →](bce-0039.md)

**汉元帝永光四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **大赦并免收贫民借贷。** 二月诏因边事和军运增加民间负担，赦天下，令停止向贫民追收先前借贷。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **赴雍祭五畤。** 三月元帝到雍祭五畤。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **宣帝陵园东阙失火。** 六月甲戌，孝宣帝园东阙发生火灾。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **六月日食与求直言。** 戊寅晦记日食，诏检讨政令反复、公卿异议及侵削百姓，责群臣修身并尽言得失。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **撤部分陵园和郡国庙，寿陵不置邑。** 先停卫思后园、戾园，后罢郡国祖宗庙，分陵属三辅。元帝选初陵地，禁止以供陵为由迁民破业，不设陵邑，又罢若干奉邑。 [[5]](#hs-note-5)

### 4. 六月日食与求直言

[返回正文第4条](#hs-event-4)

<a id="hs009-l824-e4"></a>

**[《汉书·元帝纪》P043](../../sources/摘录/汉书-卷009-元帝纪.md#p043)** · [仓内TXT L824](../../sources/本地分卷/汉书/汉书-卷009.md#L824)

> 戊寅晦，日有蝕之。詔曰：「蓋聞明王在上，忠賢布職，則群生和樂，方外蒙澤。今朕晻于王道，夙夜憂 勞，不通其理，靡瞻不眩，靡聽不惑，是以政令多還，民心未得，邪說空進，事亡成功。此天下所著聞也。公卿大夫好惡不同，或緣姦作邪，侵削細民，元元安所歸 命哉！乃六月晦，日有蝕之。詩不云虖？『今此下民，亦孔之哀！』自今以來，公卿大夫其勉思天戒，慎身修永，以輔朕之不逮。直言盡意，無有所諱。」

### 5. 撤部分陵园和郡国庙，寿陵不置邑

[返回正文第5条](#hs-event-5)

<a id="hs009-l825-e5"></a>

**[《汉书·元帝纪》P044](../../sources/摘录/汉书-卷009-元帝纪.md#p044)** · [仓内TXT L825](../../sources/本地分卷/汉书/汉书-卷009.md#L825)

> 九月戊子，罷衛思后園及戾園。冬十月乙丑，罷祖宗廟在郡國者。諸陵分屬三輔。以渭城壽陵亭部原上為 初陵。詔曰：「安土重遷，黎民之性；骨肉相附，人情所願也。頃者有司緣臣子之義，奏徙郡國民以奉園陵，令百姓遠棄先祖墳墓，破業失產，親戚別離，人懷思慕 之心，家有不安之意。是以東垂被虛耗之害，關中有無聊之民，非久長之策也。詩不云虖？『民亦勞止，迄可小康，惠此中國，以綏四方。』今所為初陵者，勿置縣 邑，使天下咸安土樂業，亡有動搖之心。布告天下，令明知之。」又罷先后父母奉邑。

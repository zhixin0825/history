# 公元前41年｜许嘉升大司马，王商与冯奉世迁将职

**汉元帝永光三年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **四月，大司马王接去世。** 七月，许嘉接任大司马车骑将军；王商任右将军，冯奉世转左将军并兼光禄勋。正月西羌战事告一段落，朝廷撤去左右将军的屯兵。 [[1]](#note-1)

<a id="sj052-zichuan-shang-event"></a>

2. **菑川考王刘尚去世，儿子刘横承位。** 汉表刘尚初元三年前46元年、六年薨，刘横永光四年前40元年，因此本次卒与继在前41。本篇及汉传写刘尚五年，存作异数；采用汉表明确元年衔接，不用五年算出前42再重复一次承袭。 [[2]](#sj052-zichuan-shang-note)

<a id="hs-event-3"></a>

3. **刘康封济阳王。** 三月立皇子刘康为济阳王。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **地动、冬雨与盗贼诏。** 十一月诏提己丑地震、仲冬雨雾及盗贼并起，责官吏未及时处置，令各自陈明。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **复设盐铁官及博士弟子定额。** 冬因国家用度不足、免役者增多难支应役，恢复盐铁官及博士弟子员额。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **刘骏嗣泗水王。** 刘骏嗣泗水王。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **三月分封王子侯。** 《王子侯表》列三月受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **安远缪侯郑吉｜去世。** 表载安远缪侯郑吉一支本年记载去世。表中所载事项为去世，无继承人。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **信成侯王定｜去世。** 表载信成侯王定一支本年记载去世。表中所载事项为去世，无继承人。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **平昌节侯王无故｜承爵。** 表载平昌节侯王无故一支本年记载侯位承袭。表中所载事项为厘侯临承爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[11]](#hs-note-11)

#### 卷022｜将相表互见与异说

[本年原行R166](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r166) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0041)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史表许嘉仅作车骑，汉019为大司马车骑；以互见补全，不把大司马另当一次出征。王接卒据汉009、019永光三年四月癸未。史表王商前官作侍中光禄大夫，汉表作侍中中郎将，未将两种前官创作成同年另一次升迁。冯奉世“二年卒”为前瞻官历，不写成本年去世 · [元帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7009.md#ref-6df7a47675e761)。

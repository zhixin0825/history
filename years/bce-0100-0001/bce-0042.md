# 公元前42年｜韦玄成接相，西羌方面再起战事

**汉元帝永光二年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **二月，韦玄成由御史大夫升丞相，封扶阳侯；郑弘接任御史大夫。** 三月发生日食。七月西羌反，右将军冯奉世受命领兵；八月任千秋率另外五校并进，也拟让韩次君出兵，后者未成行。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **忧民流散而大赦。** 诏以灾异和官吏残害、盗贼流亡自责，赦天下，按官民身份和老弱、孝悌力田分别赐爵、金、帛、牛酒。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **三月日食并举谏士。** 三月壬戌朔记日食，诏认为执政者施禁失当、伤民，命各内郡国各荐一位能直言的贤良茂才。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **六月因连年饥荒赦天下。** 元帝说民众劳作而连年失收，自己不能庇民却加刑，遂大赦。 [[4]](#hs-note-4)

### 2. 忧民流散而大赦

[返回正文第2条](#hs-event-2)

<a id="hs009-l812-e2"></a>

**[《汉书·元帝纪》P031](../../sources/摘录/汉书-卷009-元帝纪.md#p031)** · [仓内TXT L812](../../sources/本地分卷/汉书/汉书-卷009.md#L812)

> 二年春二月，詔曰：「蓋聞唐虞象刑而民不犯，殷周法行而姦軌服。今朕獲承高祖之洪業，託位公侯之 上，夙夜戰栗，永惟百姓之急，未嘗有忘焉。然而陰陽未調，三光晻昧。元元大困，流散道路，盜賊並興。有司又長殘賊，失牧民之術。是皆朕之不明，政有所虧。 咎至於此，朕甚自恥。為民父母，若是之薄，謂百姓何！其大赦天下，賜民爵一級，女子百戶牛酒，鰥寡孤獨高年、三老、孝弟力田帛。」又賜諸侯王、公主、列侯 黃金，中二千石以下至中都官長吏各有差，吏六百石以上爵五大夫，勤事吏各二級。

### 3. 三月日食并举谏士

[返回正文第3条](#hs-event-3)

<a id="hs009-l813-e3"></a>

**[《汉书·元帝纪》P032](../../sources/摘录/汉书-卷009-元帝纪.md#p032)** · [仓内TXT L813](../../sources/本地分卷/汉书/汉书-卷009.md#L813)

> 三月壬戌朔，日有蝕之。詔曰：「朕戰戰栗栗，夙夜思過失，不敢荒寧。惟陰陽不調，未燭其咎。婁敕公 卿，日望有效。至今有司執政，未得其中，施與禁切，未合民心。暴猛之俗彌長，和睦之道日衰，百姓愁苦，靡所錯躬。是以氛邪歲增，侵犯太陽，正氣湛掩，日久 奪光。乃壬戌，日有蝕之。天見大異，以戒朕躬，朕甚悼焉。其令內郡國舉茂材異等賢良直言之士各一人。」

### 4. 六月因连年饥荒赦天下

[返回正文第4条](#hs-event-4)

<a id="hs009-l814-e4"></a>

**[《汉书·元帝纪》P033](../../sources/摘录/汉书-卷009-元帝纪.md#p033)** · [仓内TXT L814](../../sources/本地分卷/汉书/汉书-卷009.md#L814)

> 夏六月，詔曰：「間者連年不收，四方咸困。元元之民，勞於耕耘，又亡成功，困於饑饉，亡以相救。朕為民父母，德不能覆，而有其刑，甚自傷焉。其赦天下。」

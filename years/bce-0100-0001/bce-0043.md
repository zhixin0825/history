# 公元前43年｜于定国、史高退休，中枢重排人事

[← 公元前44年](bce-0044.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前42年 →](bce-0042.md)

**汉元帝永光元年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **于定国获准离开丞相职位，朝廷赐金和安车驷马。** 七月，史高也离开大司马职位，韦玄成由太子太傅升御史大夫；九月，王接升大司马车骑将军。薛广德离任与韦玄成接职相连。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **甘泉祭祀与免赋。** 正月祭泰畤，赦云阳徒，赐爵、牛酒和高年帛，免所过地租赋。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **举朴厚之士、考核郎从。** 丞相、御史荐朴素敦厚谦逊者，光禄每年按这些标准给郎官和从官评级。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **赦免、给田种与霜害。** 三月诏自责未能知贤，赦天下，准无田者借地和种粮，分级赐爵物。本月降雪霜伤麦，秋收受挫。 [[4]](#hs-note-4)

## 归年与考证

<a id="sj022-note"></a>
<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[本年原行R164](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r164) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0043)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史表于定国十月戊寅免，汉019同永光元年十一月戊寅免，是月差而非已证实的整年差；汉009本纪没有明记此事，不能据它改归前42。史表广德二月免而韦玄成七月接职，汉表只给薛广德一年病免、玄成七月辛亥任，不补五个月无人任职的制度结论。史子长即史高；平昌侯王接不是后来王莽。

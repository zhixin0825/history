# 公元前43年｜于定国、史高退休，中枢重排人事

[← 公元前44年](bce-0044.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前42年 →](bce-0042.md)

**汉元帝永光元年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **于定国获准离开丞相职位，朝廷赐金和安车驷马。** 七月，史高也离开大司马职位，韦玄成由太子太傅升御史大夫；九月，王接升大司马车骑将军。薛广德离任与韦玄成接职相连。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **甘泉祭祀与免赋。** 正月祭泰畤，赦云阳徒，赐爵、牛酒和高年帛，免所过地租赋。 祭毕原拟留猎，薛广德以关东流离和随从劳苦相谏，元帝即日还宫。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **举朴厚之士、考核郎从。** 丞相、御史荐朴素敦厚谦逊者，光禄每年按这些标准给郎官和从官评级。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **赦免、给田种与霜害。** 三月诏自责未能知贤，赦天下，准无田者借地和种粮，分级赐爵物。本月降雪霜伤麦，秋收受挫。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘景开始城阳王年。** 刘景开始城阳王年。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **陵邑分属三辅。** 元帝时诸陵邑分属三辅。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **永光元年两次重霜大饥。** 《汉书》在本年记载永光元年两次重霜大饥。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **元帝永光日光日影异色。** 《汉书》在本年记载元帝永光日光日影异色。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **刘更生上条灾异封事。** 刘更生把和气祥瑞与乖气异变视为古今通义，批评朝中贤邪不分、相互谗告、文书交错，权门以亲属、附从者操纵毁誉。以从衰周之迹而求太平犹如倒行追人作比，并指出自初元到上奏已六年，灾异密过所引《春秋》。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **周堪、张猛左迁。** 恭、显读奏后更加怨恨。夏寒、日光青暗，许史等把责任推给周堪与张猛。元帝欲得杨兴助言，杨兴察帝心转称宜厚赏而夺实权；诸葛丰也批评周、张。元帝虽免诸葛丰，仍把周堪左迁河东太守、张猛贬槐里令。 诸葛丰改任城门校尉后告周堪、张猛，元帝责其前誉后毁而无证，念其年老只免为庶人。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **贾捐之被诛，杨兴减死。** 贾捐之与杨兴拟相荐求进，石显得知后上报，二人俱下狱。贾捐之死，杨兴减死一等，服徒役。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **薛广德劝元帝祭庙改从桥。** 秋日酎祭宗庙，元帝出便门拟御楼船；御史大夫薛广德及光禄大夫张猛进谏，帝改从桥。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **清河王刘竟徙中山。** 宣帝之子刘竟先封清河王，后来徙中山，未成年而留在京邸。《通鉴》把徙封系永光元年。 [[14]](#hs-note-14)

**[《汉书·隽疏于薛平彭传》P023](../../sources/摘录/汉书-卷071-隽疏于薛平彭传.md#p023)** · [仓内TXT L8729](../../sources/本地分卷/汉书/汉书-卷071.md#L8729)

> 其秋，上酎祭宗廟，出便門，欲御樓船，廣德當乘輿車，免冠頓首曰：「宜從橋。」詔曰：「大夫冠。」廣德曰：「陛下不聽臣，臣自刎，以血污車輪，陛下不得入廟矣！」上不說。先驅光祿大夫張猛進曰：「臣聞主聖臣直。乘船危，就橋安，聖主不乘危。御史大夫言可聽。」上曰：「曉人不當如是邪！」乃從橋。

#### 卷022｜将相表互见与异说

[本年原行R164](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r164) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0043)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史表于定国十月戊寅免，汉019同永光元年十一月戊寅免，是月差而非已证实的整年差；汉009本纪没有明记此事，不能据它改归前42。史表广德二月免而韦玄成七月接职，汉表只给薛广德一年病免、玄成七月辛亥任，不补五个月无人任职的制度结论。史子长即史高；平昌侯王接不是后来王莽。

**汉元帝初元五年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **许嘉任左将军。** 六月，贡禹由长信少府升御史大夫；十二月丁未贡禹去世，薛广德接任。 [[1]](#note-1)

<a id="sj052-chengyang-hui-event"></a>

2. **城阳戴王刘恢去世，儿子刘景承位。** 刘恢自甘露三年前51起元，到本年共八个王年；刘景的孝王元年在下一年前43。本篇补叙的尾句直到建始三年前30另有年数和卒字问题，不把本次继位与前30混在一起。 [[2]](#sj052-chengyang-hui-note)

<a id="hs-event-3"></a>

3. **尊周后为周承休侯。** 以周子南君为周承休侯，班位在诸侯王之后。《恩泽侯表》载名姬延年。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **雍祭五畤。** 三月赴雍祭五畤。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **减省官营、刑罚与博士名额。** 四月出现彗象，元帝以灾荒为由削减御用、停若干苑馆与官营事务，包括盐铁、常平仓；取消博士弟子名额限制，赐物并省刑七十余事，另改若干保亲和入籍通行规定。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **谷吉出使未归。** 卫司马谷吉奉使匈奴而未返回。 谷吉请送郅支的侍子至单于庭，元帝准许。郅支随后杀害谷吉等人。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **刘舜嗣广阳王。** 刘舜嗣广阳王。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **六月分封王子侯。** 《王子侯表》列六月受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **信成侯王定｜承爵。** 表载信成侯王定一支本年记载侯位承袭。表中所载事项为侯广汉承爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **周子南君姬延年｜改封。** 表载周子南君姬延年一支本年爵号或封邑改易。表中所载事项为正月癸巳，改封为周承休侯。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **康居招纳郅支，郅支西徙。** 郅支担心汉及呼韩邪追击，接受康居共同对付乌孙的提议而西徙，路遇严寒，抵康居者约三千。 [[12]](#hs-note-12)

**[《汉书·傅常郑甘陈段传》P021](../../sources/摘录/汉书-卷070-傅常郑甘陈段传.md#p021)** · [仓内TXT L8679](../../sources/本地分卷/汉书/汉书-卷070.md#L8679)

> 漢議遣衞司馬谷吉送之。御史大夫貢禹、博士匡衡以爲春秋之義「許夷狄者不壹而足」，今郅支單于鄉化未醇，所在絕遠，宜令使者送其子至塞而還。吉上書言：「中國與夷狄有羈縻不絕之義，今旣養全其子十年，德澤甚厚，空絕而不送，近從塞還，示弃捐不畜，使無鄉從之心。弃前恩，立後怨，不便。議者見前江迺始無應敵之數，知勇俱困，以致恥辱，即豫爲臣憂。臣幸得建彊漢之節，承明聖之詔，宣諭厚恩，不宜敢桀。若懷禽獸，加無道於臣，則單于長嬰大罪，必遁逃遠舍，不敢近邊。沒一使以安百姓，國之計，臣之願也。願送至庭。」上以示朝者，禹復爭，以爲吉往必爲國取悔生事，不可許。右將軍馮奉世以爲可遣，上許焉。旣至，郅支單于怒，竟殺吉等。

**互校说明** 《元帝纪》初元五年记遣谷吉不还。《通鉴》卷028《考异》以贡禹始任御史大夫的月份互校，推测本传的初元四年是郅支请还侍子，次年才遣谷吉。

### 12. 康居招纳郅支，郅支西徙

[返回正文第12条](#hs-event-12)

<a id="hs094-l9853-e12"></a>

**[《汉书·匈奴传》P095](../../sources/摘录/汉书-卷094-匈奴传.md#p095)** · [仓内TXT L9853](../../sources/本地分卷/汉书/汉书-卷094.md#L9853)

> 郅支既殺使者，自知負漢，又聞呼韓邪益彊，恐見襲擊，欲遠去。會康居王數為烏孫所困，與諸翕侯計，以為匈奴大國，烏孫素服屬之，今郅支單于困阨在外，可迎置東邊，使合兵取烏孫以立之，長無匈奴憂矣。即使使至堅昆通語郅支。郅支素恐，又怨烏孫，聞康居計，大說，遂與相結，引兵而西。康居亦遣貴人，橐它驢馬數千匹，迎郅支。郅支人眾中寒道死，餘財三千人到康居。

**互校说明** 《通鉴》卷二十八承初元五年谷吉被杀写西徙。降至三千是传记的抵达数量，勿套作发兵数。

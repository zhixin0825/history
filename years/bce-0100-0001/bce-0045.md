**汉元帝初元四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **甘泉、河东巡祀与优恤。** 正月在甘泉祭泰畤，三月赴河东祠后土，赦汾阴徒，赐爵、牛酒及帛，免巡经地租赋。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **刘遂嗣梁王。** 刘遂嗣梁王。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **刘宗绍封长沙王。** 刘宗绍封长沙王。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **司隶校尉去节。** 元帝时司隶校尉不再持节。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **初元四年东平陵墓门梓柱生枝。** 《汉书》在本年记载初元四年东平陵墓门梓柱生枝。 [[6]](#hs-note-6)

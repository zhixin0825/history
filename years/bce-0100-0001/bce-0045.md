# 公元前45年｜甘泉、河东巡祀与优恤

[← 公元前46年](bce-0046.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前44年 →](bce-0044.md)

**汉元帝初元四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **甘泉、河东巡祀与优恤。** 正月在甘泉祭泰畤，三月赴河东祠后土，赦汾阴徒，赐爵、牛酒及帛，免巡经地租赋。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **刘遂嗣梁王。** 刘遂嗣梁王。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **刘宗绍封长沙王。** 刘宗绍封长沙王。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **司隶校尉去节。** 元帝时司隶校尉不再持节。 司隶校尉诸葛丰持节追捕侍中许章，许章驰入宫申诉。朝廷收回诸葛丰的符节。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **初元四年东平陵墓门梓柱生枝。** [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **郅支遣使请还侍子。** 郅支遣使进献，请汉廷送还留在长安的侍子，并称愿意归附。送侍子的谷吉于次年出使遇害。 [[7]](#hs-note-7)

> 時侍中許章以外屬貴幸，奢淫不奉法度，賓客犯事，與章相連。豐案劾章，欲奏其事，適逢許侍中私出，豐駐車舉節詔章曰：「下！」欲收之。章迫窘，馳車去，豐追之。許侍中因得入宮門，自歸上。豐亦上奏，於是收豐節。司隸去節自豐始。

**互校说明** 《百官公卿表》记元帝初元四年去节；本传补追捕许章不果、被收符节的缘由。

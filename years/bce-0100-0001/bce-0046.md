# 公元前46年｜冯奉世由执金吾转任右将军

[← 公元前47年](bce-0047.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前45年 →](bce-0045.md)

**汉元帝初元三年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **十二月，冯奉世由执金吾转任右将军。** 他此前已处理过边地事务，现在进入朝廷将军官列。 常惠死后冯奉世递升右将军；又领典属国、带诸吏衔。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **调整郡守与王国相位次。** 诏令诸侯王国相列位在郡守之下。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **裁撤珠崖郡。** 珠崖山南县等地的反抗持续。贾捐之主张罢郡、集中力量救荒，朝廷从其议。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **白鹤馆火灾与大赦。** 四月乙未晦，茂陵白鹤馆失火。诏以火灾责己与群臣，称百姓已困且受苛吏烦扰，下令大赦。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **旱灾与长沙、海昏封爵。** 夏旱，封长沙炀王弟刘宗继王，又使故海昏侯刘贺之子代宗受侯爵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **罢部分宫卫、裁费求言。** 六月诏以灾异求直言，认为百姓离家护卫少居宫室有妨农作，罢甘泉、建章的部分宫卫以归农，命各官减支、荐通阴阳灾异者。进言和被召见者随之增多。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **俞闾炀侯毋害一支去世。** 初元三年去世，无子嗣承继。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **海昬侯贺一支封爵后续。** 初元三年，厘侯代宗以贺子接续旧封。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[9]](#hs-note-9)

<a id="hs064-l8425-e3"></a>

**[《汉书·严朱吾丘主父徐严终王贾传》P085](../../sources/摘录/汉书-卷064-严朱吾丘主父徐严终王贾传.md#p085)** · [仓内TXT L8425](../../sources/本地分卷/汉书/汉书-卷064.md#L8425)

> 上與有司議大發軍，捐之建議，以為不當擊。上使侍中駙馬都尉樂昌侯王商詰問捐之曰：「珠崖內屬為郡久矣，今背畔逆節，而云不當擊，長蠻夷之亂，虧先帝功德，經義何以處之？」捐之對曰：

**互校说明** 本传未明系廷议年。《通鉴》卷028先在初元二年下叙议，次年春诏正式罢郡，以下奏文是罢郡所据。

<a id="hs064-l8429-e3"></a>

**[《汉书·严朱吾丘主父徐严终王贾传》P089](../../sources/摘录/汉书-卷064-严朱吾丘主父徐严终王贾传.md#p089)** · [仓内TXT L8429](../../sources/本地分卷/汉书/汉书-卷064.md#L8429)

> 今天下獨有關東，關東大者獨有齊楚，民眾久困，連年流離，離其城郭，相枕席於道路。人情莫親父母，莫樂夫婦，至嫁妻賣子，法不能禁，義不能止，此社稷之憂也。今陛下不忍悁悁之忿，欲驅士眾擠之大海之中，快心幽冥之地，非所以救助飢饉，保全元元也。

**互校说明** 疏以救关东流民为对策，当年刊诏参初元三年条。

<a id="hs064-l8430-e3"></a>

**[《汉书·严朱吾丘主父徐严终王贾传》P090](../../sources/摘录/汉书-卷064-严朱吾丘主父徐严终王贾传.md#p090)** · [仓内TXT L8430](../../sources/本地分卷/汉书/汉书-卷064.md#L8430)

> 臣愚以為非冠帶之國，禹貢所及，春秋所治，皆可且無以為。願遂棄珠崖，專用恤關東為憂。

<a id="hs064-l8431-e3"></a>

**[《汉书·严朱吾丘主父徐严终王贾传》P091](../../sources/摘录/汉书-卷064-严朱吾丘主父徐严终王贾传.md#p091)** · [仓内TXT L8431](../../sources/本地分卷/汉书/汉书-卷064.md#L8431)

> 對奏，上以問丞相御史。御史大夫陳萬年以為當擊；丞相于定國以為「前日興兵擊之連年，護軍都尉、校尉及丞凡十一人，還者二人，卒士及轉輸死者萬人以上，費用三萬萬餘，尚未能盡降。今關東困乏，民難搖動，捐之議是。」上乃從之。遂下詔曰：「珠崖虜殺吏民，背畔為逆，今廷議者或言可擊，或言可守，或欲棄之，其指各殊。朕日夜惟思議者之言，羞威不行，則欲誅之；狐疑辟難，則守屯田；通于時變，則憂萬民。夫萬民之饑餓，與遠蠻之不討，危孰大焉？且宗廟之祭，凶年不備，況乎辟不嫌之辱哉！今關東大困，倉庫空虛，無以相贍，又以動兵，非特勞民，凶年隨之。其罷珠崖郡。民有慕義欲內屬，便處之；不欲，勿彊。」珠崖由是罷。

**互校说明** 《元帝纪》《通鉴》均以初元三年春系罢郡诏；本传前面的议论、用兵与最后诏书有先后。

<a id="hs009-l799-e3"></a>

**[《汉书·元帝纪》P018](../../sources/摘录/汉书-卷009-元帝纪.md#p018)** · [仓内TXT L799](../../sources/本地分卷/汉书/汉书-卷009.md#L799)

> 珠崖郡山南縣反，博謀群臣。待詔賈捐之以為宜棄珠崖，救民饑饉。乃罷珠崖。

### 4. 白鹤馆火灾与大赦

[返回正文第4条](#hs-event-4)

<a id="hs075-l8919-e4"></a>

**[《汉书·眭两夏侯京翼李传》P031](../../sources/摘录/汉书-卷075-眭两夏侯京翼李传.md#p031)** · [仓内TXT L8919](../../sources/本地分卷/汉书/汉书-卷075.md#L8919)

> 明年夏四月乙未，孝武園白鶴館災。奉自以為中，上疏曰：「臣前上五際地震之效，曰極陰生陽，恐有火災。不合明聽，未見省答，臣竊內不自信。今白鶴館以四月乙未，時加於卯，月宿亢災，與前地震同法。臣奉乃深知道之可信也。不勝拳拳，願復賜間，卒其終始。」

**互校说明** 《元帝纪》初元三年四月乙未晦失火；时加于卯与占说为传中翼奉所述。

<a id="hs027-l5456-e4"></a>

**[《汉书·五行志》P007](../../sources/摘录/汉书-卷027-五行志.md#p007)** · [仓内TXT L5456](../../sources/本地分卷/汉书/汉书-卷027.md#L5456)

> 元帝初元三年四月乙未，孝武園白鶴館災。

<a id="hs009-l800-e4"></a>

**[《汉书·元帝纪》P019](../../sources/摘录/汉书-卷009-元帝纪.md#p019)** · [仓内TXT L800](../../sources/本地分卷/汉书/汉书-卷009.md#L800)

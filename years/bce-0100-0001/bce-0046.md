# 公元前46年｜冯奉世由执金吾转任右将军

**汉元帝初元三年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **十二月，冯奉世由执金吾转任右将军。** 他此前已处理过边地事务，现在进入朝廷将军官列。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **调整郡守与王国相位次。** 诏令诸侯王国相列位在郡守之下。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **裁撤珠崖郡。** 珠崖山南县等地反乱延续至本年。贾捐之主张放弃珠崖以集中救荒，朝廷遂罢郡。《贾捐之传》另记初元元年前48年已有反乱。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **白鹤馆火灾与大赦。** 四月乙未晦，茂陵白鹤馆失火。诏以火灾责己与群臣，称百姓已困且受苛吏烦扰，下令大赦。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **旱灾与长沙、海昏封爵。** 夏旱，封长沙炀王弟刘宗继王，又使故海昏侯刘贺之子代宗受侯爵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **罢部分宫卫、裁费求言。** 六月诏以灾异求直言，认为百姓离家护卫少居宫室有妨农作，罢甘泉、建章的部分宫卫以归农，命各官减支、荐通阴阳灾异者。进言和被召见者随之增多。 [[6]](#hs-note-6)

> 六月，詔曰：「蓋聞安民之道，本繇陰陽。間者陰陽錯謬，風雨不時。朕之不德，庶幾群公有敢言朕之過 者，今則不然。媮合苟從，未肯極言，朕甚閔焉。永惟烝庶之饑寒，遠離父母妻子，勞於非業之作，衛於不居之宮，恐非所以佐陰陽之道也。其罷甘泉、建章宮衛， 令就農。百官各省費。條奏毋有所諱。有司勉之，毋犯四時之禁。丞相御史舉天下明陰陽災異者各三人。」於是言事者眾，或進擢召見，人人自以得上意。

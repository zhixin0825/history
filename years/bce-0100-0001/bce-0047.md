1. **刘霸获立广陵王。** 元帝立刘胥之子刘霸为广陵王，恢复广陵国。刘霸死后谥孝。 [[1]](#note-1)

<a id="sj052-zichuan-zhonggu-event"></a>

2. **菑川思王刘终古去世，儿子刘尚承位。** 元平元年前74至本年共二十八王年，汉表下一年初元三年前46列刘尚元年。本篇称尚孝王，汉表、汉传称考王；刘横在汉书才称孝王，诸谥号不同不另造同名国王。 [[2]](#sj052-zichuan-zhonggu-note)

<a id="hs-event-3"></a>

3. **甘泉郊祭和云阳赐爵。** 正月幸甘泉祭泰畤，赐云阳民爵及女子户群牛酒。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **刘竟封清河王。** 立元帝之弟刘竟为清河王。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **陇西地震、赦免与荐士。** 将省下的宫廷用物和池苑资源转给贫民。诏详细记陇西地震、宗庙损毁、豲道民居压塌与山裂涌水，免重灾地租赋，赦天下并征求减省办法与直谏人才。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **立皇太子与赐爵赐钱。** 四月丁巳立皇太子。赐御史大夫关内侯等爵，给为父后者晋爵，按列侯、五大夫等级给钱。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **关东饥荒、北海水灾。** 六月关东饥、齐地相食，七月诏追述开仓赈济、给衣及歉收、地震与北海洪水，请公卿直陈皇帝过失。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

<a id="hs-event-9"></a>

<a id="hs-event-21"></a>

8. **萧望之获赐爵后被构陷，自杀。** 元帝念萧望之曾为自己讲经八年，赐关内侯，许其朔望入朝。弘恭、石显授意郑朋、华龙告萧望之排斥外戚，元帝起初误准交廷尉，得知入狱后令释，萧望之与周堪、刘更生仍免为庶人。萧望之子萧伋上书申冤，弘恭、石显又请捕治。十二月，使者围宅，萧望之不愿年老再下狱，饮鸩自尽。元帝哀悼，责弘恭、石显议事不详。 [[8]](#hs-note-8)

<a id="hs-event-10"></a>

<a id="hs-event-17"></a>

16. **初元二年朔旦冬至与两历分歧。** 世经记十一月癸亥朔旦冬至，而殷历作甲子并当纪首，刘歆结合十月日食不取。 [[16]](#hs-note-17)

<a id="hs-event-18"></a>

17. **客星见于昴分。** [[17]](#hs-note-18)

<a id="hs-event-19"></a>

18. **张勃荐陈汤，因举非其人获罪。** 元帝诏列侯举茂材，富平侯张勃举陈汤。陈汤因父死不奔丧被论罪，张勃也因举荐失实被削邑。 [[18]](#hs-note-19)

<a id="hs-event-20"></a>

19. **拟召张敞为左冯翊，会其病卒。** 郑朋建议让太原太守张敞辅导太子，萧望之认为他适于治繁剧事务。元帝欲改召他为左冯翊，张敞病死。 [[19]](#hs-note-20)

<a id="hs-event-22"></a>

20. **弘恭死，石显任中书令。** 弘恭病死，原中书仆射石显接为中书令。 [[20]](#hs-note-22)

### 5. 陇西地震、赦免与荐士

[返回正文第5条](#hs-event-5)

<a id="hs075-l8915-e5"></a>

**[《汉书·眭两夏侯京翼李传》P027](../../sources/摘录/汉书-卷075-眭两夏侯京翼李传.md#p027)** · [仓内TXT L8915](../../sources/本地分卷/汉书/汉书-卷075.md#L8915)

> 明年二月戊午，地震。其夏，齊地人相食。七月己酉，地復震。上曰：「蓋聞賢聖在位，陰陽和，風雨時，日月光，星辰靜，黎庶康寧，考終厥命。今朕共承天地，託于公侯之上，明不能燭，德不能綏，災異並臻，連年不息。乃二月戊午，地大震于隴西郡，毀落太上廟殿壁木飾，壞敗铠道縣城郭官寺及民室屋，厭殺人眾，山崩地裂，水泉涌出。一年地再動，天惟降災，震驚朕躬。治有大虧，咎至於此。夙夜兢兢，不通大變，深懷鬱悼，未知其序。比年不登，元元困乏，不勝飢寒，以陷刑辟，朕甚閔焉。憯怛於心。已詔吏虛倉廩，開府臧，振捄貧民。群司其茂思天地之戒，有可蠲除減省以便萬姓者，各條奏。悉意陳朕過失，靡有所諱。」因赦天下，舉直言極諫之士。

**互校说明** 《元帝纪》初元二年封诏和《五行志》互校，夏齐相食、秋再震与赈令是同年不同时段。

<a id="hs075-l8916-e5"></a>

**[《汉书·眭两夏侯京翼李传》P028](../../sources/摘录/汉书-卷075-眭两夏侯京翼李传.md#p028)** · [仓内TXT L8916](../../sources/本地分卷/汉书/汉书-卷075.md#L8916)

> 臣聞之於師曰，天地設位，懸日月，布星辰，分陰陽，定四時，列五行，以視聖人，名之曰道。聖人見道，然後知王治之象，故畫州土，建君臣，立律曆，陳成敗，以視賢者，名之曰經。賢者見經，然後知人道之務，則《詩》、《書》、《易》、《春秋》、《禮》、《樂》是也。《易》有陰陽，《詩》有五際，《春秋》有災異，皆列終始，推得失，考天心，以言王道之安危。至秦乃不說，傷之以法，是以大道不通，至於滅亡。今陛下明聖，深懷要道，燭臨萬方，布德流惠，靡有闕遺。罷省不急之用，振救困貧，賦醫藥，賜棺錢，恩澤甚厚。又舉直言，求過失，盛德純備，天下幸甚。

**互校说明** 原段自乡里灾赈、赐棺至举直言，接前段初元二年《元帝纪》同类诏举。

<a id="hs075-l8917-e5"></a>

**[《汉书·眭两夏侯京翼李传》P029](../../sources/摘录/汉书-卷075-眭两夏侯京翼李传.md#p029)** · [仓内TXT L8917](../../sources/本地分卷/汉书/汉书-卷075.md#L8917)

> 臣奉竊學齊詩，聞五際之要十月之交篇，知日蝕地震之效昭然可明，猶巢居知風，穴處知雨，亦不足多，適所習耳。臣聞人氣內逆，則感動天地；天變見於星氣日蝕，地變見於奇物震動。所以然者，陽用其精，陰用其形，猶人之有五臧六體，五臧象天，六體象地。故臧病則氣色發於面，體病則欠申動於貌。今年太陰建於甲戌，律以庚寅初用事，曆以甲午從春。曆中甲庚，律得參陽，性中仁義，情得公正貞廉，百年之精歲也。正以精歲，本首王位，日臨中時接律而地大震，其後連月久陰，雖有大令，猶不能復，陰氣盛矣。古者朝廷必有同姓以明親親，必有異姓以明賢賢，此聖王之所以大通天下也。同姓親而易進，異姓疏而難通，故同姓一，異姓五，乃為平均。今左右亡同姓，獨以舅后之家為親，異姓之臣又疏。二后之黨滿朝，非特處位，勢尤奢僭過度，呂、霍、上官足以卜之，甚非愛人之道，又非後嗣之長策也。陰氣之盛，不亦宜乎！

**互校说明** 同一封事的核心论外戚。灾异与政治间的感应属奏者解释。

<a id="hs075-l8918-e5"></a>

**[《汉书·眭两夏侯京翼李传》P030](../../sources/摘录/汉书-卷075-眭两夏侯京翼李传.md#p030)** · [仓内TXT L8918](../../sources/本地分卷/汉书/汉书-卷075.md#L8918)

> 臣又聞未央、建章、甘泉宮才人各以百數，皆不得天性。若杜陵園，其已御見者，臣子不敢有言，雖然，太皇太后之事也。及諸侯王園，與其後宮，宜為設員，出其過制者，此損陰氣應天救邪之道也。今異至不應，災將隨之。其法大水，極陰生陽，反為大旱，甚則有火災，春秋宋伯姬是矣。唯陛下財察。

**互校说明** 承同一地震后封事，白鹤馆火灾另在次年前46年。

<a id="hs036-l7062-e5"></a>

**[《汉书·楚元王传》P015](../../sources/摘录/汉书-卷036-楚元王传.md#p015)** · [仓内TXT L7062](../../sources/本地分卷/汉书/汉书-卷036.md#L7062)

> 其春地震

**互校说明** 《通鉴》考异指出传作三月，《元帝纪》系二月戊午，采用本纪的月日。

<a id="hs009-l793-e5"></a>

**[《汉书·元帝纪》P012](../../sources/摘录/汉书-卷009-元帝纪.md#p012)** · [仓内TXT L793](../../sources/本地分卷/汉书/汉书-卷009.md#L793)

> 詔罷黃門乘輿狗馬，水衡禁囿、宜春下苑、少府佽飛外池、嚴烃池田假與貧民。詔曰：「蓋聞賢聖在位， 陰陽和，風雨時，日月光，星辰靜，黎庶康寧，考終厥命。今朕恭承天地，託于公侯之上，明不能燭，德不能綏，災異並臻，連年不息。乃二月戊午，地震于隴西 郡，毀落太上皇廟殿壁木飾，壞敗豲道縣城郭官寺及民室屋，壓殺人眾。山崩地裂，水泉湧出。天惟降災，震驚朕師。治有大虧，咎至於斯。夙夜兢兢，不通大變， 深惟鬱悼，未知其序。間者歲數不登，元元困乏，不勝饑寒，以陷刑辟，朕甚閔之。郡國被地動災甚者無出租賦。赦天下。有可蠲除減省以便萬姓者，條奏，毋有所 諱。丞相、御史、中二千石舉茂材異等直言極諫之士，朕將親覽焉。」

> 初元二年，元帝詔列侯舉茂材，勃舉湯。湯待遷，父死不犇喪，司隷奏湯無循行，勃選舉故不以實，坐削戶二百，會薨，因賜謚曰繆侯。湯下獄論。

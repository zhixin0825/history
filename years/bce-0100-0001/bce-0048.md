<a id="event-1"></a>

1. **王政君成为皇后，王禁封阳平侯。** 元帝即位，太子妃王政君成为皇后，父亲王禁受封阳平侯。王禁出自魏郡，字稚君，做过丞相属吏；这次显贵首先来自女儿的皇后身份。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **安葬宣帝于杜陵。** 正月辛丑葬宣帝于杜陵，按身份赐金、钱帛，并大赦。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **以公田苑地和种粮扶助贫民。** 将可省的公田、苑地拿来扶持贫民生产，向财产不足千钱者贷给种粮与口粮。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **王舜、许嘉受封。** 王舜为安平侯，许嘉续平恩戴侯之后。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

<a id="hs-event-8"></a>

<a id="hs-event-18"></a>

5. **关东十一郡国水灾饥荒，朝廷遣使赈济。** 遣使巡行与关东灾赈。元帝以地动自警，遣褒等十二人巡问老弱困穷并访人才，责相守宣化。又诏重灾郡国免租赋，借少府所属水域园池给贫民，并分等赐马、帛与牛酒。九月关东多地水灾、饥荒，传有相食。朝廷调邻郡钱粮，暂停少用宫馆修缮，并节省养马、养兽开支。关东饥荒，琅邪人相食。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **因疫减宫廷用度。** 六月因民间有疫，减御膳、乐府员额和苑马，腾挪财物救济贫困者。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **上郡降胡出走。** 八月上郡属国一万多已归降的胡人逃入匈奴。 [[7]](#hs-note-7)

<a id="hs-event-9"></a>

8. **平邑侯敞一支后事。** 初元元年，因……获罪杀一家二人处死于市。 [[8]](#hs-note-9)

<a id="hs-event-10"></a>

<a id="hs-event-11"></a>

9. **三月分封王子侯。** 三月丁巳分封王子侯。三月分封王子侯。 [[9]](#hs-note-10)

<a id="hs-event-12"></a>

10. **安远缪侯郑吉｜承爵。** 表载安远缪侯郑吉一支本年记载侯位承袭。表中所载事项为侯光承爵。 [[10]](#hs-note-12)

<a id="hs-event-13"></a>

11. **阳城缪侯刘德｜承爵。** 表载阳城缪侯刘德一支本年记载侯位承袭。表中所载事项为厘侯庆忌承爵。 [[11]](#hs-note-13)

<a id="hs-event-14"></a>

12. **设置戊己校尉。** 元帝置戊己校尉，设丞、司马各一人及五候。 [[12]](#hs-note-14)

<a id="hs-event-15"></a>

13. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 水衡都尉冯奉世升执金吾。 [[13]](#hs-note-15)

<a id="hs-event-16"></a>

14. **南斗客星。** [[14]](#hs-note-16)

<a id="hs-event-17"></a>

15. **勃海海水大溢。** [[15]](#hs-note-17)

<a id="hs-event-19"></a>

16. **初元元年珠崖再反。** 珠崖有反乱，朝廷再次部署兵力；以后诸县又相继起事。 [[16]](#hs-note-19)

<a id="hs-event-20"></a>

17. **元帝征王吉、贡禹。** 元帝初年同征王吉和贡禹。王吉赴召途中病故，朝廷派使者吊祭；贡禹到朝受任谏大夫。 [[17]](#hs-note-20)

<a id="hs-event-21"></a>

18. **元帝初征翼奉待诏。** 翼奉本以《齐诗》及律历、阴阳之学自守，元帝即位后从诸儒荐征为宦者署待诏，多次宣问。 [[18]](#hs-note-21)

<a id="hs-event-22"></a>

19. **萧望之等建议中书改用士人。** 萧望之、周堪与刘更生、金敞向元帝议政。萧望之以宦者任中书并非旧制，请改用士人；史高及弘恭、石显反对，元帝未决。 [[19]](#hs-note-22)

<a id="hs-event-23"></a>

20. **元帝以师礼尊孔霸为褒成君。** 元帝征其旧师孔霸，赐关内侯、号褒成君，给事中，食邑八百户；后允许以所食邑祭孔子。 [[20]](#hs-note-23)

<a id="hs-event-24"></a>

21. **汉转云中、五原谷给呼韩邪。** 元帝即位之初，呼韩邪报告部众困乏，诏云中、五原两郡转粮两万斛。 [[21]](#hs-note-24)

### 5. 关东十一郡国水灾饥荒，朝廷遣使赈济

[返回正文第5条](#hs-event-5)

<a id="hs071-l8723-e5"></a>

**[《汉书·隽疏于薛平彭传》P017](../../sources/摘录/汉书-卷071-隽疏于薛平彭传.md#p017)** · [仓内TXT L8723](../../sources/本地分卷/汉书/汉书-卷071.md#L8723)

> 然上始即位，關東連年被災害，民流入關，言事者歸咎於大臣。上於是數以朝日引見丞相、御史，入受詔，條責以職事，曰：「惡吏負賊，妄意良民，至亡辜死。或盜賊發，吏不亟追而反系亡家，後不敢復告，以故浸廣。民多冤結，州郡不理，連上書者交於闕廷。二千石選舉不實，是以在位多不任職。民田有災害，吏不肯除，收趣其租，以故重困。關東流民饑寒疾疫，已詔吏轉漕，虛倉廩開府臧相振救，賜寒者衣，至春猶恐不贍。今丞相、御史將欲何施以塞此咎？悉意條狀，陳朕過失。」定國上書謝罪。

**互校说明** 传只以即位初概述连年灾情与反复召问。初元元年遣使灾赈及本条互见，不以此固定诏责月日。

> 夏四月，詔曰：「朕承先帝之聖緒，獲奉宗廟，戰戰兢兢。間者地數動而未靜，懼於天地之戒，不知所 繇。方田作時，朕憂蒸庶之失業，臨遣光祿大夫褒等十二人循行天下，存問耆老鰥寡孤獨困乏失職之民，延登賢俊，招顯側陋，因覽風俗之化。相守二千石誠能正躬 勞力，宣明教化，以親萬姓，則六合之內和親，庶幾虖無憂矣。書不云乎？『股肱良哉，庶事康哉！』布告天下，使明知朕意。」又曰：「關東今年穀不登，民多困 乏。其令郡國被災害甚者毋出租賦。江海陂湖園池屬少府者以假貧民，勿租賦。賜宗室有屬籍者馬一匹至二駟，三老、孝者帛五匹，弟者、力田三匹，鰥寡孤獨二 匹，吏民五十戶牛酒。」

# 公元前49年｜史高与萧望之奉命辅佐新君

[← 公元前50年](bce-0050.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前48年 →](bce-0048.md)

**汉宣帝黄龙元年；汉元帝本年即位**

古月、干支按古史年条保留，不直接换算为同号公历日期。

[本年相关史料](#sources-start)

<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **宣帝去世、元帝即位之际，乐陵侯史高任大司马车骑将军，太子太傅萧望之任前将军。** 史高以外戚身份参与辅政，萧望之则有教授太子的旧恩，两人共同进入新朝中枢。 宣帝临终还命太子少傅周堪为光禄大夫，与史高、萧望之同受遗诏并领尚书事。 元帝即位后遣淮阳王刘钦就国。 东平王刘宇也在元帝即位后就国。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **到甘泉祭泰畤。** 黄龙元年春正月，宣帝到甘泉郊祭泰畤。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **呼韩邪再次亲朝。** 呼韩邪再来朝见，汉依初次礼节接待赏赐，二月单于归国。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **整顿刑政偏差与上计虚报。** 诏批评地方官或放纵罪犯、或竞施酷刑，又指上计簿欺瞒以避考核。宣帝令停止有关减省卒徒自给的请奏，由御史核查可疑簿籍，查明真伪。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **孛星经过王良、阁道。** 三月，史官记孛星出现于王良、阁道，进入紫宫天区。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **限制廉吏荐举资格。** 四月诏指出六百石官秩位已等于大夫，俸禄、前途与试才机会已足，自今不得作为廉吏荐举。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **刘旦嗣长沙王。** 刘旦嗣长沙王。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **衆陵节侯贤一支爵位承袭。** 黄龙元年，顷侯庆继承侯爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **柳泉节侯强一支爵位承袭。** 黄龙元年，孝侯建继承侯爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **建陵靖侯遂一支爵位承袭。** 黄龙元年，节侯鲁继承侯爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **增博士员额。** 宣帝黄龙元年增加博士员额至十二人，依本表文字。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **客星由王梁近紫宫。** 《汉书》在本年记载客星由王梁近紫宫。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **未央殿雌鸡变化的记录。** 《汉书》在本年记载未央殿雌鸡变化的记录。 [[14]](#hs-note-14)

> 詔曰：「蓋聞上古之治，君臣同心，舉措曲直，各得其所。是以上下和洽，海內康平，其德弗可及已。朕 既不明，數申詔公卿大夫務行寬大，順民所疾苦，將欲配三王之隆，明先帝之德也。今吏或以不禁姦邪為寬大，縱釋有罪為不苛，或以酷惡為賢，皆失其中。奉詔宣 化如此，豈不繆哉！方今天下少事，繇役省減，兵革不動，而民多貧，盜賊不止，其咎安在？上計簿，具文而已，務為欺謾，以避其課。三公不以為意，朕將何任？ 諸請詔省卒徒自給者皆止。御史察計簿，疑非實者，按之，使真偽毋相亂。」

[本年原行R158](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r158) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0049)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史子长是史高之字，不另造一个姓史名子长的将军。汉019黄龙元年十二月癸酉记史高任大司马车骑，汉081也明宣帝崩后元帝即位的辅政安排。黄龙元年为前49，初元元年从前48起算；不为沿用年号把任命推迟一年 · [匡张孔马传互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7081.md#ref-1e8b6404b0c7a3)。

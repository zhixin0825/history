# 公元前49年｜史高与萧望之奉命辅佐新君

**汉宣帝黄龙元年；汉元帝本年即位**

古月、干支按古史年条保留，不直接换算为同号公历日期。

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **宣帝去世、元帝即位之际，乐陵侯史高任大司马车骑将军，太子太傅萧望之任前将军。** 史高以外戚身份参与辅政，萧望之则有教授太子的旧恩，两人共同进入新朝中枢。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **到甘泉祭泰畤。** 黄龙元年春正月，宣帝到甘泉郊祭泰畤。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **呼韩邪再次亲朝。** 呼韩邪再来朝见，汉依初次礼节接待赏赐，二月单于归国。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **整顿刑政偏差与上计虚报。** 诏批评地方官或放纵罪犯、或竞施酷刑，又指上计簿欺瞒以避考核。宣帝令停止有关减省卒徒自给的请奏，由御史核查可疑簿籍，查明真伪。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **孛星经过王良、阁道。** 三月，史官记孛星出现于王良、阁道，进入紫宫天区。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **限制廉吏荐举资格。** 四月诏指出六百石官秩位已等于大夫，俸禄、前途与试才机会已足，自今不得作为廉吏荐举。 [[6]](#hs-note-6)

### 4. 整顿刑政偏差与上计虚报

[返回正文第4条](#hs-event-4)

<a id="hs008-l776-e4"></a>

**[《汉书·宣帝纪》P134](../../sources/摘录/汉书-卷008-宣帝纪.md#p134)** · [仓内TXT L776](../../sources/本地分卷/汉书/汉书-卷008.md#L776)

> 詔曰：「蓋聞上古之治，君臣同心，舉措曲直，各得其所。是以上下和洽，海內康平，其德弗可及已。朕 既不明，數申詔公卿大夫務行寬大，順民所疾苦，將欲配三王之隆，明先帝之德也。今吏或以不禁姦邪為寬大，縱釋有罪為不苛，或以酷惡為賢，皆失其中。奉詔宣 化如此，豈不繆哉！方今天下少事，繇役省減，兵革不動，而民多貧，盜賊不止，其咎安在？上計簿，具文而已，務為欺謾，以避其課。三公不以為意，朕將何任？ 諸請詔省卒徒自給者皆止。御史察計簿，疑非實者，按之，使真偽毋相亂。」

**互校说明** 宽大、执法与上计核查为一诏的不同内容；“省卒徒自給”原文照存，不将含义可疑处硬解为某一新税。

### 6. 限制廉吏荐举资格

[返回正文第6条](#hs-event-6)

<a id="hs008-l778-e6"></a>

**[《汉书·宣帝纪》P136](../../sources/摘录/汉书-卷008-宣帝纪.md#p136)** · [仓内TXT L778](../../sources/本地分卷/汉书/汉书-卷008.md#L778)

> 夏四月，詔曰：「舉廉吏，誠欲得其真也。吏六百石位大夫，有罪先請，秩祿上通，足以效其賢材，自今以來毋得舉。」

**互校说明** 禁以六百石官为廉吏荐举，理由与秩、禄及已能效才相连，不是取消廉吏荐举。

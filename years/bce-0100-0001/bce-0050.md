# 公元前50年｜广川王刘海阳被废迁

[← 公元前51年](bce-0051.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前49年 →](bce-0049.md)

**汉宣帝甘露四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **广川王刘海阳被废迁。** 夏，广川王刘海阳获罪，废迁房陵。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **宣室阁失火。** 冬十月丁卯，未央宫宣室阁起火。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **广川王刘汝阳被废。** 广川王刘汝阳被废。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **刘光嗣六安王。** 刘光嗣六安王。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **封斯戴侯胡伤一支爵位承袭。** 甘露四年，孝侯宫继承侯爵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **新利侯偃一支封爵后续。** 甘露四年，因……获罪上书谩，免去侯爵，复改授侯国户都侯，建始三年又上书谩，免去侯爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **閏月丁亥分封王子侯。** 《王子侯表》列閏月丁亥受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **十一月壬申分封王子侯。** 《王子侯表》列十一月壬申受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 原任典属国的常惠拜右将军，仍兼典属国。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **定陶王刘嚣徙为楚王。** 宣帝之子刘嚣由定陶转封楚国。《通鉴》将此次徙封系在甘露四年。 [[10]](#hs-note-10)

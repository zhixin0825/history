<a id="event-1"></a>

1. **黄霸去世，于定国继任丞相。** 三月，黄霸去世；五月，于定国出任丞相，封西平侯。他接的是朝廷职任，不是黄家的建成侯爵。 [[1]](#note-1)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-2"></a>

2. **太仆陈万年接任御史大夫。** 于定国升丞相以后，另一位最高官员也从原有职务调入中枢。 [[2]](#note-2)

<a id="hs-event-3"></a>

3. **甘泉祭泰畤。** 甘露三年春正月，宣帝到甘泉郊祭泰畤。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **呼韩邪首次亲朝与返塞。** 呼韩邪入朝称藩臣，通报名号时不唱其本名。朝廷厚赐玺绶、车马、金帛，在建章宫设宴，夹道迎接。二月他返回，汉派骑兵万六千护送，令北边供粮，呼韩邪居于幕南、依托光禄城。纪文接写郅支远遁及局势安定，是此后事势的简括；《通鉴》把远徙展开在后年。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **新蔡祥鸟报告与赐免。** 诏称凤凰落在新蔡，众鸟相向而立；赐汝南太守与当地长吏等帛、给百姓升爵两级，免收当年租税。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **讲论五经与增置博士。** 宣帝召儒者讨论五经异同，由萧望之等评议上奏，亲自裁决。增置梁丘《易》、大小夏侯《尚书》、穀梁《春秋》的博士。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **乌孙公主归汉。** 冬，乌孙公主从乌孙返回汉朝。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **刘恢承城阳王。** 刘恢承城阳王。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **刘封嗣鲁王。** 刘封嗣鲁王。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **魏其炀侯昌一支爵位承袭。** 甘露三年，孝侯禹继承侯爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **南曲炀侯迁一支爵位承袭。** 甘露三年，节侯江继承侯爵。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **新市康侯吉一支爵位承袭。** 甘露三年，顷侯义继承侯爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **西梁节侯辟兵一支爵位承袭。** 甘露三年，孝侯广继承侯爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **富平敬侯张安世｜承爵。** 表载富平敬侯张安世一支本年记载侯位承袭。表中所载事项为缪侯敞承爵。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **营平壮侯赵充国｜承爵。** 表载营平壮侯赵充国一支本年记载侯位承袭。表中所载事项为质侯弘承爵。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **博望顷侯许舜｜承爵。** 表载博望顷侯许舜一支本年记载侯位承袭。表中所载事项为戾侯党承爵。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **建成定侯黄霸｜承爵。** 表载建成定侯黄霸一支本年记载侯位承袭。表中所载事项为思侯赏承爵。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **西平安侯于定国｜受封。** 表载西平安侯于定国一支本年有始封记载。表中所载事项为五月甲子封。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

### 4. 呼韩邪首次亲朝与返塞

[返回正文第4条](#hs-event-4)

<a id="hs008-l767-e4"></a>

**[《汉书·宣帝纪》P125](../../sources/摘录/汉书-卷008-宣帝纪.md#p125)** · [仓内TXT L767](../../sources/本地分卷/汉书/汉书-卷008.md#L767)

> 匈奴呼韓邪單于稽侯蛳來朝，贊謁稱藩臣而不名。賜以璽綬、冠帶、衣裳、安車、駟馬、黃金、錦繡、繒 絮。使有司道單于先行就邸長安，宿長平。上自甘泉宿池陽宮。上登長平阪，詔單于毋謁。其左右當戶之群皆列觀，蠻夷君長王侯迎者數萬人，夾道陳。上登渭橋， 咸稱萬歲。單于就邸。置酒建章宮，饗賜單于，觀以珍寶。二月，單于罷歸。之長樂衛尉高昌侯忠、車騎都尉昌、騎都尉虎將萬六千騎送單于。單于居幕南，保光祿 城。詔北邊振穀食。郅支單于遠遁，匈奴遂定。

**互校说明** 甘露三年是呼韩邪首朝和护送。段末“郅支單于遠遁”是合叙，《通鉴》卷027 L537–550把其西走展开在前49年；本条不把整个远遁过程系前51年。

#### 卷022｜将相表互见与异说

[本年原行R156](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r156) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0051)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

黄霸去世、于定国接相仍沿本页既有五月任相线。史表黄霸卒三月己丑，于定国任相七月丁巳；汉019分别二月己丑、五月甲午，通鉴亦取五月任相，死亡月差已在旧注，不另改写。本表陈万年任御史与汉019五月甲午相接，故只补一次任官 · [宣帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-4f46d176516815)。

#### 卷020｜原格、互见与采用的年线

<a id="sj020-e237-n"></a>
**黄霸去世，于定国继任丞相：** [S044 建成](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s044) · [S045 西平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s045)。三月黄霸卒、五月于定国为相与封西平据《通鉴》甘露三年；《百官公卿表》却作二月己丑黄霸薨，死亡月份仍有二／三月之别。通鉴任相日五月甲午，[《汉书·外戚恩泽侯表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-9ff4eb16f1d5a9)初封日五月甲子，不能说所有引书干支完全一致。任相、封侯只采用五月；死亡月份暂沿通鉴三月，保留汉表二月，不称两书全同。不据差日造第二次任相或两次封侯；西平也不是蔡义、王禁的阳平。 互校：[漢書/卷019](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0051) · [漢書/卷008](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-a45b39c5354709) · [漢書/卷018](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-58f1149d3db3a3) · [資治通鑑/卷027](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7027.md#ref-5e7fa459284ad0)。

1. **黄霸去世，于定国继相，陈万年任御史大夫。** 三月，黄霸去世；五月，于定国出任丞相，封西平侯。他接的是朝廷职任，不是黄家的建成侯爵。太仆陈万年接任御史大夫。于定国升丞相以后，另一位最高官员也从原有职务调入中枢。 [[1]](#note-1)

<a id="hs-event-3"></a>

2. **甘泉祭泰畤。** 甘露三年春正月，宣帝到甘泉郊祭泰畤。 [[2]](#hs-note-3)

<a id="hs-event-4"></a>

3. **呼韩邪首次亲朝与返塞。** 呼韩邪入朝称藩臣，宣帝礼遇他，通报名号时不唱其本名。朝廷赠以玺绶、车马、金帛，在建章宫设宴。二月呼韩邪返回，汉遣骑兵万六千护送，又令边郡供粮；他居于幕南，依托光禄城。萧望之主张待以客礼，班次在诸侯王之上。 [[3]](#hs-note-4)

<a id="hs-event-5"></a>

4. **新蔡祥鸟报告与赐免。** 诏称凤凰落在新蔡，众鸟相向而立；赐汝南太守与当地长吏等帛、给百姓升爵两级，免收当年租税。 [[4]](#hs-note-5)

<a id="hs-event-6"></a>

5. **讲论五经与增置博士。** 宣帝召儒者讨论五经异同，由萧望之等评议上奏，亲自裁决。增置梁丘《易》、大小夏侯《尚书》、穀梁《春秋》的博士。 石渠阁议中另有淮阳中尉韦玄成参与。 [[5]](#hs-note-6)

<a id="hs-event-7"></a>

6. **乌孙公主归汉。** 冬，乌孙公主从乌孙返回汉朝。 [[6]](#hs-note-7)

<a id="hs-event-8"></a>

7. **刘恢承城阳王。** 刘恢承城阳王。 [[7]](#hs-note-8)

<a id="hs-event-9"></a>

8. **刘封嗣鲁王。** 刘封嗣鲁王。 [[8]](#hs-note-9)

<a id="hs-event-10"></a>

9. **魏其炀侯昌一支爵位承袭。** 甘露三年，孝侯禹继承侯爵。 [[9]](#hs-note-10)

<a id="hs-event-11"></a>

<a id="hs-event-12"></a>

11. **新市康侯吉一支爵位承袭。** 甘露三年，顷侯义继承侯爵。 [[11]](#hs-note-12)

<a id="hs-event-13"></a>

12. **西梁节侯辟兵一支爵位承袭。** 甘露三年，孝侯广继承侯爵。 [[12]](#hs-note-13)

### 3. 呼韩邪首次亲朝与返塞

[返回正文第3条](#hs-event-4)

**异文与补证** 郅支远遁是后来事势，本纪与《通鉴》所叙时序有别。

<a id="hs094-l9850-e4"></a>

**[《汉书·匈奴传》P092](../../sources/摘录/汉书-卷094-匈奴传.md#p092)** · [仓内TXT L9850](../../sources/本地分卷/汉书/汉书-卷094.md#L9850)

> 漢遣車騎都尉韓昌迎，發過所七郡郡二千騎，為陳道上。單于正月朝天子于甘泉宮，漢寵以殊禮，位在諸侯王上，贊謁稱臣而不名。賜以冠帶衣裳，黃金璽盭綬，玉具劍，佩刀，弓一張，矢四發，谧戟十，安車一乘，鞍勒一具，馬十五匹，黃金二十斤，錢二十萬，衣被七十七襲，錦鏽綺縠雜帛八千匹，絮六千斤。禮畢，使使者道單于先行，宿長平。上自甘泉宿池陽宮。上登長平，詔單于毋謁，其左右當戶之群臣皆得列觀，及諸蠻夷君長王侯數萬，咸迎於渭橋下，夾道陳。上登渭橋，咸稱萬歲。單于就邸，留月餘，遣歸國。單于自請願留居光祿塞下，有急保漢受降城。漢遣長樂衛尉高昌侯董忠、車騎都尉韓昌將騎萬六千，又發邊郡士馬以千數，送單于出朔方雞鹿塞。詔忠等留衛單于，助誅不服，又轉邊穀米糒，前後三萬四千斛，給贍其食。是歲，郅支單于亦遣使奉獻，漢遇之甚厚。

**互校说明** 甘露三年首次亲朝于甘泉宫，礼遇及送保塞下均见。郅支遣使属同年并列外交。

**互校说明** 为其朝汉后的概括；《宣帝纪》甘露三年为首次亲朝。

<a id="hs078-l9068-e4"></a>

**[《汉书·萧望之传》P015](../../sources/摘录/汉书-卷078-萧望之传.md#p015)** · [仓内TXT L9068](../../sources/本地分卷/汉书/汉书-卷078.md#L9068)

> 初，匈奴呼韓邪單于來朝，詔公卿議其儀，丞相霸、御史大夫定國議曰：「聖王之制，施德行禮，先京師而後諸夏，先諸夏而後夷狄。《詩》云：『率禮不越，遂視既發；相土烈烈，海外有截。』陛下聖德充塞天地，光被四表，匈奴單于鄉風慕化，奉珍朝賀，自古未之有也。其禮儀宜如諸侯王，位次在下。」望之以為「單于非正朔所加，故稱敵國，宜待以不臣之禮，位在諸侯王上。外夷稽首稱藩，中國讓而不臣，此則羈縻之誼，謙亨之福也。書曰『戎狄荒服』，言其來，荒忽亡常。如使匈奴後嗣卒有鳥竄鼠伏，闕於朝享，不為畔臣。信讓行乎蠻貉，福祚流于亡窮，萬世之長策也。」天子采之，下詔曰：「蓋聞五帝三王教化所不施，不及以政。今匈奴單于稱北藩，朝正朔，朕之不逮，德不能弘覆。其以客禮待之，令單于位在諸侯王上，贊謁稱臣而不名。」

**互校说明** 《宣帝纪》《通鉴》甘露三年呼韩邪首次亲朝。本传述廷议。

<a id="hs008-l767-e4"></a>

**[《汉书·宣帝纪》P125](../../sources/摘录/汉书-卷008-宣帝纪.md#p125)** · [仓内TXT L767](../../sources/本地分卷/汉书/汉书-卷008.md#L767)

**互校说明** 甘露三年是呼韩邪首朝和护送。段末“郅支單于遠遁”是合叙，《通鉴》卷027 L537–550把其西走展开在前49年；本条不把整个远遁过程系前51年。

黄霸去世、于定国接相仍沿本页既有五月任相线。史表黄霸卒三月己丑，于定国任相七月丁巳；汉019分别二月己丑、五月甲午，通鉴亦取五月任相，死亡月差已在旧注，不另改写。本表陈万年任御史与汉019五月甲午相接，故只补一次任官 · [宣帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-4f46d176516815)。

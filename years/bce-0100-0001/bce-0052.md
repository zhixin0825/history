本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="杜延年退职于定国为御史大夫"></a>


<a id="event-1"></a>

1. **杜延年退职，于定国为御史大夫。** 杜延年年老多病，离开御史大夫职位。廷尉于定国升任御史大夫，随后还将接任丞相。于定国来自东海，从司法属吏一步步进入朝廷，任廷尉后又研习春秋，希望在用法时更为宽厚。 [[1]](#note-1)

<a id="sj052-chengyang-shun-event"></a>

2. **城阳荒王刘顺去世，儿子刘恢承位。** 刘顺从天汉四年前97起元，到甘露二年本年共四十六王年；徐广注也明记甘露二年。刘恢下一年前51起戴王元年，不把子之元年当成父之卒年。 [[2]](#sj052-chengyang-shun-note)

<a id="hs-event-3"></a>

3. **刘嚣立定陶王。** 正月，立皇子刘嚣为定陶王。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **大赦、减算与赏赐。** 诏书罗列凤凰、甘露、黄龙、醴泉等祥瑞报告，宣布大赦，减民算赋三十，给王侯大臣金钱，赐民爵及女子牛酒，并赐鳏寡孤独高年者布帛。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **派兵平珠崖。** 四月，遣护军都尉禄领兵进击珠崖。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **刘宇立东平王。** 九月，立皇子刘宇为东平王。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **到萯阳宫属玉观。** 冬十二月，宣帝到萯阳宫属玉观。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **商定呼韩邪来朝礼次。** 呼韩邪来到五原塞，请在甘露三年正月献礼朝见。群臣认为单于应按外宾及诸侯王礼，称臣而居诸侯王下。宣帝决定以客礼相待，位在诸侯王上。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **山原侯国一支爵位承袭。** 甘露二年，孝侯外人继承侯爵，十八年，建始五年去世。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **七月辛未分封王子侯。** [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **酇文终侯萧何｜承爵。** 表载酇文终侯萧何一支本年记载侯位承袭。表中所载事项为思侯辅承爵。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **建平敬侯杜延年｜承爵。** 表载建平敬侯杜延年一支本年记载侯位承袭。表中所载事项为孝侯缓承爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **乐昌共侯王武｜承爵。** 表载乐昌共侯王武一支本年记载侯位承袭。表中所载事项为戾侯商承爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **赵充国去世。** 曾主持平羌与屯田的营平侯赵充国去世，年八十六岁，谥壮侯。他退职以后，朝廷遇边政大事仍向他询问。 [[15]](#hs-note-15)

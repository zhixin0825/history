本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **许延寿去世，许汤接爵。** 二月，许延寿去世，儿子许汤接续乐成侯。 [[1]](#note-1)

<a id="sj020-e217"></a>
<a id="几位继承侯因宗庙礼仪被降为关内侯"></a>


<a id="event-2"></a>

2. **几位继承侯因宗庙礼仪被降为关内侯。** 韦玄成、魏弘、丙显因宗庙祭祀时骑马至门、未按规定乘车等礼仪问题受到处分，爵位降为关内侯。他们继承的扶阳、高平、博阳列侯国因而中断，但本人并不是被处死。 韦玄成本传补称逢雨路泥，未乘驷马车即骑至庙门。 [[2]](#note-2)

<a id="hs-event-3"></a>

3. **甘泉祭泰畤。** 甘露元年春正月，宣帝到甘泉祭泰畤。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

<a id="hs-event-7"></a>

4. **呼韩邪遣子入侍，匈奴遣左贤王贺正。** 呼韩邪单于遣子入侍。呼韩邪派儿子、右贤王铢娄渠堂赴汉入侍。冬，匈奴单于派弟弟左贤王入朝祝贺。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **新丰黄龙报告。** 四月，纪载新丰有人报告黄龙出现。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **太上皇庙与文帝庙先后起火。** 丙申太上皇庙失火，甲辰文帝庙又失火，宣帝着素服五日。 [[6]](#hs-note-6)

<a id="hs-event-8"></a>

7. **邯会衍侯仁一支爵位承袭。** 甘露元年，原侯张继承侯爵。 [[7]](#hs-note-8)

<a id="hs-event-9"></a>

8. **稻夷侯定一支爵位承袭。** 甘露元年，顷侯阅继承侯爵。 [[8]](#hs-note-9)

<a id="hs-event-10"></a>

9. **广饶康侯国一支爵位承袭。** 甘露元年，侯麟继承侯爵，王莽夺取皇位，这一支封爵中断。 [[9]](#hs-note-10)

<a id="hs-event-11"></a>

10. **兰旗顷侯临朝一支爵位承袭。** 甘露元年，厘侯嘉继承侯爵。 [[10]](#hs-note-11)

<a id="hs-event-12"></a>

11. **历乡康侯必胜一支爵位承袭。** 甘露元年，顷侯长寿继承侯爵。 [[11]](#hs-note-12)

<a id="hs-event-13"></a>

12. **三月壬辰分封王子侯。** [[12]](#hs-note-13)

<a id="hs-event-14"></a>

13. **高平宪侯魏相｜获罪。** 表载高平宪侯魏相一支本年载相关罪案及处分。表中所载事项为因罪案酎宗庙骑至司马门，不敬，削爵一级为关内侯。 [[13]](#hs-note-14)

<a id="hs-event-15"></a>

14. **乐成敬侯许延寿｜承爵。** 表载乐成敬侯许延寿一支本年记载侯位承袭。表中所载事项为思侯汤承爵。 [[14]](#hs-note-15)

<a id="hs-event-16"></a>

15. **博阳定侯丙吉｜获罪。** 表载博阳定侯丙吉一支本年载相关罪案及处分。表中所载事项为因罪案酎宗庙骑至司马门，不敬，夺爵一级为关内侯。 [[15]](#hs-note-16)

<a id="hs-event-17"></a>

16. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[16]](#hs-note-17)

<a id="hs-event-18"></a>

17. **甘露元年珠崖九县反。** 甘露元年，珠崖九县起事，官府发兵平定。 [[17]](#hs-note-18)

<a id="hs-event-19"></a>

18. **张敞因絮舜案去京兆，后复为冀州刺史。** 杨恽被诛后，张敞因与他相交而遭追究。絮舜以为张敞将免，不肯受差遣，被张敞逼吏问死。张敞被免京兆尹，数月后复任冀州刺史。 [[18]](#hs-note-19)

<a id="hs-event-20"></a>

19. **宣帝令韦玄成辅淮阳王。** 宣帝认为淮阳王刘钦才达而爱之，曾考虑改储，终于未改。以曾有让侯声名的韦玄成为淮阳中尉，望以谦让影响刘钦。 [[19]](#hs-note-20)

<a id="hs-event-21"></a>

<a id="hs-event-22"></a>

20. **解忧公主与汉使谋刺狂王，乌孙分立大小昆弥。** 解忧公主与汉使谋刺乌孙狂王。魏和意、任昌与解忧谋刺狂王，未成，受围于赤谷城，郑吉调兵解围。汉廷为狂王治伤，并治涉事人员。乌就屠夺位，汉廷通过冯嫽分立大小昆弥。乌就屠杀狂王自立。辛武贤进至敦煌备讨；冯嫽持节调停，汉立元贵靡与乌就屠分领大小昆弥。 [[20]](#hs-note-21)

### 4. 呼韩邪遣子入侍，匈奴遣左贤王贺正

[返回正文第4条](#hs-event-4)

<a id="hs094-l9849-e4"></a>

**[《汉书·匈奴传》P091](../../拆分史书/汉书/卷094.md#p091)** · [仓内TXT L9849](../../拆分史书/汉书/卷094.md#part-1-L9849)

> 呼韓邪之敗也，左伊秩訾王為呼韓邪計，勸令稱臣入朝事漢，從漢求助，如此匈奴乃定。呼韓邪議問諸大臣，皆曰：「不可。匈奴之俗，本上氣力而下服役，以馬上戰鬥為國，故有威名於百蠻。戰死，壯士所有也。今兄弟爭國，不在兄則在弟，雖死猶有威名，子孫常長諸國。漢雖彊，猶不能兼并匈奴，奈何亂先古之制，臣事於漢，卑辱先單于，為諸國所笑！雖如是而安，何以復長百蠻！」左伊秩訾曰：「不然。彊弱有時，今漢方盛，烏孫城郭諸國皆為臣妾。自且鞮侯單于以來，匈奴日削，不能取復，雖屈彊於此，未嘗一日安也。今事漢則安存，不事則危亡，計何以過此！」諸大人相難久之。呼韓邪從其計，引眾南近塞，遣子右賢王銖婁渠堂入侍。郅支單于亦遣子右大將駒于利受入侍。是歲，甘露元年也。

**互校说明** 甘露元年，既有条接两单于遣子入侍及左伊秩訾议；呼韩邪亲朝分年。

<a id="hs-note-19"></a>

### 18. 张敞因絮舜案去京兆，后复为冀州刺史

[返回正文第18条](#hs-event-19)

<a id="hs076-l8987-e19"></a>

**[《汉书·赵尹韩张两王传》P039](../../拆分史书/汉书/卷076.md#p039)** · [仓内TXT L8987](../../拆分史书/汉书/卷076.md#part-1-L8987)

> 敞使卒捕掾絮舜有所案驗。舜以敞劾奏當免，不肯為敞竟事，私歸其家。人或諫舜，舜曰：「吾為是公盡力多矣，今五日京兆耳，安能復案事？」敞聞舜語，即部吏收舜繫獄。是時冬月未盡數日，案事吏晝夜驗治舜，竟致其死事。舜當出死，敞使主簿持教告舜曰：「五日京兆竟何如？冬月已盡，延命乎？」乃棄舜市。會立春，行冤獄使者出，舜家載尸，并編敞教，自言使者。使者奏敞賊殺不辜。天子薄其罪，欲令敞得自便利，即先下敞前坐楊惲不宜處位奏，免為庶人。敞免奏既下，詣闕上印綬，便從闕下亡命。

**互校说明** 《通鉴·考异》据表及在职年数系甘露元年；《杨恽传》连写于前54年杨恽案，《荀纪》又牵连还作五凤二年。《百官表》记八年，本传九岁，所计口径有别。

<a id="hs076-l8988-e19"></a>

**[《汉书·赵尹韩张两王传》P040](../../拆分史书/汉书/卷076.md#p040)** · [仓内TXT L8988](../../拆分史书/汉书/卷076.md#part-1-L8988)

> 數月，京師吏民解弛，枹鼓數起，而冀州部中有大賊。天子思敞功效，使使者即家在所召敞。敞身被重劾，及使者至，妻子家室皆泣惶懼，而敞獨笑曰：「吾身亡命為民，郡吏當就捕，今使者來，此天子欲用我也。」即裝隨使者詣公書上車曰：「臣前幸得備位列卿，待罪京兆，坐殺賊捕掾絮舜。舜本臣敞素所厚吏，數蒙恩貸，以臣有章劾當免，受記考事，便歸臥家，謂臣『五日京兆』，背恩忘義，傷化薄俗。臣竊以舜無狀，枉法以誅之。臣敞賊殺無辜，鞠獄故不直，雖伏明法，死無所恨。」天子引見敞，拜為冀州刺史。

**互校说明** 《通鉴》卷027甘露元年于张敞失官后数月叙此；下文平广川、任太原为后事。

### 20. 解忧公主与汉使谋刺狂王，乌孙分立大小昆弥

[返回正文第20条](#hs-event-21)

<a id="hs096-l10044-e21"></a>

**[《汉书·西域传》P096](../../拆分史书/汉书/卷096.md#p096)** · [仓内TXT L10044](../../拆分史书/汉书/卷096.md#part-1-L10044)

> 狂王復尚楚主解憂，生一男鴟靡，不與主和，又暴惡失眾。漢使衛司馬魏和意、副侯任昌送侍子，公主言狂王為烏孫所患苦，易誅也。遂謀置酒會，罷，使士拔劍擊之。劍旁下，狂王傷，上馬馳去。其子細沈瘦會兵圍和意、昌及公主於赤谷城。數月，都護鄭吉發諸國兵救之，乃解去。漢遣中郎將張遵持醫藥治狂王，賜金二十斤，采繒。因收和意、昌系鎖，從尉犁檻車至長安，斬之。車騎將軍長史張翁留驗公主與使者謀殺狂王狀，主不服，叩頭謝，張翁捽主頭罵詈。主上書，翁還，坐死。副使季都別將醫養視狂王，狂王從十餘騎送之。都還，坐知狂王當誅，見便不發，下蠶室。

**互校说明** 《通鉴》卷027系甘露元年。

<a id="hs-note-22"></a>

<a id="hs096-l10045-e22"></a>

**[《汉书·西域传》P097](../../拆分史书/汉书/卷096.md#p097)** · [仓内TXT L10045](../../拆分史书/汉书/卷096.md#part-1-L10045)

> 初，肥王翁歸靡胡婦子烏就屠，狂五傷時驚，與諸翕侯俱去，居北山中，揚言母家匈奴兵來，故眾歸之。後遂襲殺狂王，自立為昆彌。漢遣破羌將軍辛武賢將兵萬五千人至郭煌，遣使者案行表，穿卑鞮侯井以西，欲通渠轉谷，積居廬倉以討之。

**互校说明** 《通鉴》卷027以此事接入甘露元年。

<a id="hs096-l10046-e22"></a>

**[《汉书·西域传》P098](../../拆分史书/汉书/卷096.md#p098)** · [仓内TXT L10046](../../拆分史书/汉书/卷096.md#part-1-L10046)

> 都護鄭吉使馮夫人說烏就屠，以漢兵方出，必見滅，不如降。烏就屠恐，曰：「願得小號。」宣帝征馮夫人，自問狀。遣謁者竺次、期門甘延壽為副，送馮夫人。馮夫人錦車持節，詔烏就屠詣長羅侯赤谷城，立元貴靡為大昆彌，烏就屠為小昆彌，皆賜印綬。破羌將軍不出塞還。

**互校说明** 《通鉴》卷027以此事接入甘露元年；常惠再分户口和地界的日期未明。

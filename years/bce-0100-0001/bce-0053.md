本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **许延寿去世，许汤接爵。** 二月，许延寿去世，儿子许汤接续乐成侯。 [[1]](#note-1)

<a id="sj020-e217"></a>
<a id="几位继承侯因宗庙礼仪被降为关内侯"></a>


<a id="event-2"></a>

2. **几位继承侯因宗庙礼仪被降为关内侯。** 韦玄成、魏弘、丙显因宗庙祭祀时骑马至门、未按规定乘车等礼仪问题受到处分，爵位降为关内侯。他们继承的扶阳、高平、博阳列侯国因而中断，但本人并不是被处死。 [[2]](#note-2)

<a id="hs-event-3"></a>

3. **甘泉祭泰畤。** 甘露元年春正月，宣帝到甘泉祭泰畤。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **呼韩邪单于遣子入侍。** 呼韩邪派儿子、右贤王铢娄渠堂赴汉入侍。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **新丰黄龙报告。** 四月，纪载新丰有人报告黄龙出现。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **太上皇庙与文帝庙先后起火。** 丙申太上皇庙失火，甲辰文帝庙又失火，宣帝着素服五日。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **匈奴遣左贤王朝贺。** 冬，匈奴单于派弟弟左贤王入朝祝贺。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **邯会衍侯仁一支爵位承袭。** 甘露元年，原侯张继承侯爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **稻夷侯定一支爵位承袭。** 甘露元年，顷侯阅继承侯爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **广饶康侯国一支爵位承袭。** 甘露元年，侯麟继承侯爵，王莽夺取皇位，这一支封爵中断。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **兰旗顷侯临朝一支爵位承袭。** 甘露元年，厘侯嘉继承侯爵。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **历乡康侯必胜一支爵位承袭。** 甘露元年，顷侯长寿继承侯爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **三月壬辰分封王子侯。** 《王子侯表》列三月壬辰受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **高平宪侯魏相｜获罪。** 表载高平宪侯魏相一支本年载相关罪案及处分。表中所载事项为因罪案酎宗庙骑至司马门，不敬，削爵一级为关内侯。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **乐成敬侯许延寿｜承爵。** 表载乐成敬侯许延寿一支本年记载侯位承袭。表中所载事项为思侯汤承爵。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **博阳定侯丙吉｜获罪。** 表载博阳定侯丙吉一支本年载相关罪案及处分。表中所载事项为因罪案酎宗庙骑至司马门，不敬，夺爵一级为关内侯。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[17]](#hs-note-17)

#### 卷020｜原格、互见与采用的年线

[完整原文](../../sources/摘录/史记-卷020-建元以来侯者年表.md) · [逐格去向](../../meta/记录/史记-卷020-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷020-纪年与异说.md)。初封、增邑、继承与任官分开；月日未明不补，谥号为后称，国除不一律等于处死。

<a id="sj020-e214-n"></a>
**许延寿去世，许汤接爵：** [S029 樂平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s029)。《宣帝纪》甘露元年二月丁巳明记许延寿卒，[《汉书·外戚恩泽侯表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-eeb51fe208434a)同年汤嗣。前63年初封至前53年相差10，正可对应表中十年不含末年算法；若机械含首尾则11，不能因此倒造前54年死亡。补录酒色致病是作者归因，不作医学结论。 互校：[漢書/卷008](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-c4a98c892b49fe) · [漢書/卷018](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-07b2e3fac200b4) · [資治通鑑/卷027](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7027.md#ref-50502223f4f99e)。 《宣帝纪》作甘露元年二月丁巳薨，《百官公卿表》作三月丁巳；正文采用本纪前53年二月，保留汉表三月的异文。互校：[百官公卿表](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0053)。

<a id="sj020-e217-n"></a>
**几位继承侯因宗庙礼仪被降为关内侯：** [S018 扶陽](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s018) · [S027 高平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s027) · [S043 博陽](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s043)。魏弘、丙显甘露元年明见汉恩泽表，韦玄成由神爵元年嗣九年的侯年及韦传相接，具体月日不明。补录丙显作翁孟；魏弘作宾。三家关系不能因同罪合并。董忠也有小车至庙受罚，但本卷没有确年，不强列入本案。 互校：[漢書/卷018](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-a5a32e407d9e54) · [漢書/卷073](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7073.md#ref-934bd7114927b1) · [漢書/卷074](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7074.md#ref-d0362c5074b4b8)。

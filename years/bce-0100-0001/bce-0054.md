# 公元前54年｜杨恽再遭追究，安平侯谭也受到牵连；广陵王刘胥因祝诅案自杀

**汉宣帝五凤四年**

本页收录已编史料及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **杨恽再遭追究，安平侯谭也受到牵连。** 失爵后的杨恽经营家业、与友人通信，怨言又被告发。朝廷按大逆无道判其腰斩，家属遭迁徙。安平侯杨谭因附和叔父言论被免为庶人，韦玄成等与杨恽交好者也失去官职。 [[1]](#note-1)

<a id="sj020-e220"></a>
<a id="广陵王刘胥因祝诅案自杀"></a>


<a id="event-2"></a>

2. **正月，广陵王刘胥因祝诅案自杀，王国撤销。** 刘胥在前69年楚王案中曾获免追治，此后又因祝诅皇帝的指控受到审讯，终于自缢而死，广陵王国被撤销。他从前117年受封到本年，按首尾计已在位六十四年。[[2]](#note-2)

<a id="hs-event-3"></a>

3. **单于遣弟入侍与减戍。** 匈奴单于称臣，遣弟谷蠡王入侍。汉廷因边塞暂时没有敌寇，将戍卒裁减十分之二。本纪没有指名这位单于。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **耿寿昌奏设常平仓。** 大司农中丞耿寿昌奏请建立常平仓，以供北边并减少长途转运，获赐关内侯。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **日食与遣使复查冤狱。** 四月辛丑晦记日食。宣帝将此解释为对执政的警示，复遣丞相、御史所属二十四人巡行天下，查举冤狱，检举擅行苛禁且不肯改过者。 [[5]](#hs-note-5)

### 1. 杨恽再遭追究，安平侯谭也受到牵连

<a id="hs008-l746-e1"></a>

**[《汉书·宣帝纪》P104](../../sources/摘录/汉书-卷008-宣帝纪.md#p104)** · [仓内TXT L746](../../sources/本地分卷/汉书/汉书-卷008.md#L746)

> 不悔過，怨望，大逆不道，要斬。

**互校说明** 本纪在五凤二年十二月连写免庶和腰斩。《通鉴》系前56年免、前54年斩；《汉书·功臣表》L2970又系前55年免。

**[《史记》卷020《建元以来侯者年表》｜安平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s016)**

**原文原格**

> 楊敞，家在華陰。故給事大將軍幕府，稍遷至大司農，為御史大夫。元鳳六年，代王訢為丞相，封二千戶。立二年，病死。子賁代立，十三年病死。子翁君代立，為典屬國。三歲，以季父惲故出惡言，繫獄當死，得免，為庶人，國除。

**[《史记》卷020《建元以来侯者年表》｜平通](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s035)**

**原文原格**

> 楊惲，家在華陰，故丞相楊敞少子，任為郎。好士，自喜知人，居眾人中常與人顏色，以故高昌侯董忠引與屏語，言霍氏謀反狀，共發覺告反侯，二千戶，為光祿動。到五鳳四年，作為妖言，大逆罪腰斬，國除。

**[《史记》卷020《建元以来侯者年表》｜扶陽](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s018)**

**原文原格**

> 韋賢，家在魯。通詩、禮、尚書，為博士，授魯大儒，入侍中，為昭帝師，遷為光祿大夫，大鴻臚，長信少府。以為人主師，本始三年代蔡義為丞相，封扶陽侯，千八百戶。為丞相五歲，多恩，不習吏事，免相就第，病死。子玄成代立，為太常。坐祠廟騎，奪爵，為關內侯。

### 2. 广陵王刘胥因祝诅案自杀

[返回正文第2条](#event-2)

<a id="hs008-l750-e2"></a>

**[《汉书·宣帝纪》P108](../../sources/摘录/汉书-卷008-宣帝纪.md#p108)** · [仓内TXT L750](../../sources/本地分卷/汉书/汉书-卷008.md#L750)

**[《史记》卷020《建元以来侯者年表》｜爰戚](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s037)**

**原文原格**

> 趙成。用發覺楚國事侯，二千三百戶。地節元年，楚王與廣陵王謀反，成發覺反狀，天子推恩廣德義，下詔書曰「無治廣陵王」，廣陵不變更。後復坐祝詛滅國，自殺，國除。今帝復立子為廣陵王。

[S037 爰戚](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s037) · [漢書/卷008](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-f9bce9d9715931) · [資治通鑑/卷027](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7027.md#ref-541c7740f279e8)

[史料说明](#sj020-e220-n)

<a id="sj060-cite-053"></a>

**[《史记·三王世家》P024｜广陵通楚与后来的祝诅终局](../../sources/摘录/史记-卷060-三王世家.md#p024)**

> 其後胥復祝詛謀反，自殺，國除。

**说明：** “其后”具体归五凤四年前54，以汉纪明年为据；前段延寿案另在前69。原文“自杀”不改成皇帝直接处斩。

> 四年春正月，廣陵王胥有罪，自殺。

**说明：** 本纪给五凤四年正月，未给干支日。

<a id="sj060-cite-055"></a>

**[《汉书》卷063互校｜L8326](../../sources/本地分卷/汉书/汉书-卷063.md#L8326)**

> 即以綬自絞死。及八子郭昭君等二人皆自殺。天子加恩，赦王諸子皆為庶人，賜謚曰厲王。立六十四年而誅，國除。

**说明：** 传中自绞与“而诛”并见；“而诛”概括罪案终局，不改变死亡方式。六十四年可与首尾计相合，王表六十三年可与两端年距相合；朝廷仍赦诸子为庶人。

### 5. 日食与遣使复查冤狱

[返回正文第5条](#hs-event-5)

<a id="hs008-l753-e5"></a>

**[《汉书·宣帝纪》P111](../../sources/摘录/汉书-卷008-宣帝纪.md#p111)** · [仓内TXT L753](../../sources/本地分卷/汉书/汉书-卷008.md#L753)

> 夏四月辛丑晦，日有蝕之。詔曰：「皇天見異，以戒朕躬，是朕之不逮，吏之不稱也。以前使使者問民所疾苦，復遣丞相、御史掾二十四人循行天下，舉冤獄，察擅為苛禁深刻不改者。」

**互校说明** 仓内本纪写“辛丑晦”，《五行志》L5799、《通鉴》卷027 L252–253作“辛丑朔”。同年一条，不作两次日食。诏令是遣人巡狱、察苛禁。

1. **杨恽再遭追究，安平侯谭也受到牵连。** 失爵后的杨恽经营家业、与友人通信，怨言又被告发。朝廷按大逆无道判其腰斩，家属遭迁徙。安平侯杨谭因附和叔父言论被免为庶人，韦玄成等与杨恽交好者也失去官职。 [[1]](#note-1)

<a id="sj020-e220"></a>

<a id="event-2"></a>

2. **正月，广陵王刘胥因祝诅案自杀，王国撤销。** 刘胥在前69年楚王案中曾获免追治，此后又因祝诅皇帝的指控受到审讯，终于自缢而死，广陵王国被撤销。他从前117年受封到本年，按首尾计已在位六十四年。 [[2]](#note-2)

<a id="hs-event-3"></a>

<a id="hs-event-12"></a>

3. **郅支击杀闰振，匈奴仍与汉往来。** 单于遣弟入侍与减戍。匈奴单于称臣，遣弟谷蠡王入侍。汉廷因边塞暂时没有敌寇，将戍卒裁减十分之二。本纪没有指名这位单于。郅支击杀闰振并逼走呼韩邪。闰振向东攻郅支而被杀，所属归郅支。郅支再击呼韩邪，后者兵败，郅支占单于庭。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **耿寿昌奏设常平仓。** 大司农中丞耿寿昌奏请建立常平仓，以供北边并减少长途转运，获赐关内侯。 本传补记萧望之曾反对耿寿昌此议。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **日食与遣使复查冤狱。** 四月辛丑晦记日食。宣帝将此解释为对执政的警示，复遣丞相、御史所属二十四人巡行天下，查举冤狱，检举擅行苛禁且不肯改过者。 [[5]](#hs-note-5)

### 2. 正月，广陵王刘胥因祝诅案自杀，王国撤销

[返回正文第2条](#event-2)

<a id="hs063-l8326-e2"></a>

**[《汉书·武五子传》P034](../../拆分史书/汉书/卷063.md#p034)** · [仓内TXT L8326](../../拆分史书/汉书/卷063.md#part-1-L8326)

> 居數月，祝詛事發覺，有司按驗，胥惶恐，藥殺巫及宮人二十餘人以絕口。公卿請誅胥，天子遣廷尉、大鴻臚即訊。胥謝曰：「罪死有餘，誠皆有之。事久遠，請歸思念具對。」胥既見使者還，置酒顯陽殿。召太子霸及子女董訾、胡生等夜飲，使所幸八子郭昭君、家人子趙左君等鼓瑟歌舞。王自歌曰：「欲久生兮無終，長不樂兮安窮！奉天期兮不得須臾，千里馬兮駐待路。黃泉下兮幽深，人生要死，何為苦心！何用為樂心所喜，出入無悰為樂亟。蒿裡召兮郭門閱，死不得取代庸，身自逝。」左右悉更涕泣奏酒，至雞鳴時罷。胥謂太子霸曰：「上遇我厚，今負之甚。我死，骸骨當暴。幸而得葬，薄之，無厚也。」即以綬自絞死。及八子郭昭君等二人皆自殺。天子加恩，赦王諸子皆為庶人，賜謚曰厲王。立六十四年而誅，國除。

**互校说明** 异象在案前数月，不强系全部在自杀年。

#### 卷022｜将相表互见与异说

[本年原行R153](../../拆分史书/史记/卷022.md#r153) · [《汉书·百官公卿表》](../../拆分史书/汉书/卷019.md#part-3-ws019-bce-0054)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

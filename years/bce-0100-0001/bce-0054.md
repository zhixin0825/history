# 公元前54年｜杨恽再遭追究，安平侯谭也受到牵连；广陵王刘胥因祝诅案自杀

**汉宣帝五凤四年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e216"></a>
### 杨恽再遭追究，安平侯谭也受到牵连

失爵后的杨恽经营家业、与友人通信，怨言又被告发。朝廷按大逆无道判其腰斩，家属遭迁徙。安平侯杨谭因附和叔父言论被免为庶人，韦玄成等与杨恽交好者也失去官职。 [原文与说明](#sj020-e216-n)

<a id="sj020-e220"></a>
### 广陵王刘胥因祝诅案自杀

广陵王刘胥后来再次涉案，这次因祝诅皇帝的指控遭到追查，自杀身亡，广陵王国撤销。 [原文与说明](#sj020-e220-n)

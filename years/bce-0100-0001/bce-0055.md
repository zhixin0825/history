# 公元前55年｜丙吉去世，丙显承博阳侯；黄霸任丞相，封建成侯

**汉宣帝五凤三年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e229"></a>
### 丙吉去世，丙显承博阳侯

正月，丞相丙吉去世，儿子丙显承袭博阳侯。子辈的将军、侍中官历与继爵相关，但不是丞相职位的世袭。 [原文与说明](#sj020-e229-n)

<a id="sj020-e235"></a>
### 黄霸任丞相，封建成侯

二月，黄霸接任丞相，受封建成侯。从地方治理、太子师傅、御史大夫到丞相，他经历了多次迁任，不能把这些官职一并当成本年初授。 [原文与说明](#sj020-e235-n)

<a id="sj020-e204"></a>
### 杜延年回朝任御史大夫

六月，杜延年由地方太守回到中央，出任御史大夫。先前免太仆、后来历任北地与西河，再到中央，是相隔多年的经历。 [原文与说明](#sj020-e204-n)

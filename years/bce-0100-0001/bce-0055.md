**汉宣帝五凤三年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **丙吉去世，丙显承博阳侯。** 正月，丞相丙吉去世，儿子丙显承袭博阳侯。子辈的将军、侍中官历与继爵相关，但不是丞相职位的世袭。 丙吉病时向宣帝推荐杜延年、于定国和陈万年。 [[1]](#note-1)

<a id="sj020-e235"></a>
<a id="黄霸任丞相封建成侯"></a>


<a id="event-2"></a>

2. **黄霸任丞相，封建成侯。** 二月，黄霸接任丞相，受封建成侯。从地方治理、太子师傅、御史大夫到丞相，他经历了多次迁任，不能把这些官职一并当成本年初授。 [[2]](#note-2)

<a id="sj020-e204"></a>
<a id="杜延年回朝任御史大夫"></a>


<a id="event-3"></a>

3. **杜延年回朝任御史大夫。** 六月，杜延年由地方太守回到中央，出任御史大夫。先前免太仆、后来历任北地与西河，再到中央，是相隔多年的经历。 [[3]](#note-3)

<a id="hs-event-4"></a>

4. **河东祠后土与减口钱。** 三月到河东祭祀后土。诏书回顾匈奴诸单于交战、损失和部众归汉，以称臣通好与边境安定为背景；又报告祭祀所见神光、甘露和鸾凤，命减口钱、赦殊死以下、赐爵与牛酒、准聚饮五日，并加赐鳏寡孤独高年者帛。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **安置匈奴降者。** 置西河、北地属国，以安置归降的匈奴人。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **临乐敦侯光一支爵位承袭。** 五凤三年，节侯万年继承侯爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **夫夷敬侯义一支爵位承袭。** 五凤三年，顷侯奉宗继承侯爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **陆元侯何一支失爵。** 五凤三年，因……获罪知女妹夫亡命笞二百，首匿罪，免去侯爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **昌成节侯元一支爵位承袭。** 五凤三年，顷侯齿继承侯爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **都成敬侯金安上｜承爵。** 表载都成敬侯金安上一支本年记载侯位承袭。表中所载事项为夷侯常承爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **义阳侯厉温敦｜受封。** 《汉书》侯籍列义阳侯厉温敦本年受封，所引月份、干支依表保留。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[12]](#hs-note-12)

### 4. 河东祠后土与减口钱

[返回正文第4条](#hs-event-4)

<a id="hs025-l5243-e4"></a>

**[《汉书·郊祀志》P045](../../sources/摘录/汉书-卷025-郊祀志.md#p045)** · [仓内TXT L5243](../../sources/本地分卷/汉书/汉书-卷025.md#L5243)

> 幸河東，祠后土，赦天下。

**互校说明** 按本纪五凤三年，本志还记赦。

<a id="hs008-l748-e4"></a>

**[《汉书·宣帝纪》P106](../../sources/摘录/汉书-卷008-宣帝纪.md#p106)** · [仓内TXT L748](../../sources/本地分卷/汉书/汉书-卷008.md#L748)

> 三月，行幸河東，祠后土。詔曰：「往者匈奴數為邊寇，百姓被其害。朕承至尊，未能綏定匈奴。虛閭權 渠單于請求和親，病死。右賢王屠耆堂代立。骨肉大臣立虛閭權渠單于子為呼韓邪單于，擊殺屠耆堂。諸王並自立，分為五單于，更相攻擊，死者以萬數，畜產大耗 什八九，人民飢餓，相燔燒以求食，因大乖亂。單于閼氏子孫昆弟及呼鸱累單于、名王、右伊秩訾、且渠、當戶以下將眾五萬餘人來降歸義。單于稱臣，使弟奉珍朝 賀正月，北邊晏然，靡有兵革之事。朕飭躬齊戒，郊上帝，祠后土，神光並見，或興于谷，燭燿齊宮，十有餘刻。甘露降，神爵集。已詔有司告祠上帝、宗廟。三月 辛丑，鸞鳳又集長樂宮東闕中樹上，飛下止地，文章五色，留十餘刻，吏民並觀。朕之不敏，懼不能任，婁蒙嘉瑞，獲茲祉福。書不云乎？『雖休勿休，祗事不 怠。』公卿大夫其勗焉。減天下口錢。赦殊死以下。賜民爵一級，女子百戶牛酒。大酺五日。加賜鰥寡孤獨高年帛。」

**互校说明** 三月诏回顾匈奴争立、来降与通好，不据诏把所有过程落到本年。右贤王屠耆堂是握衍朐鞮单于，与后起屠耆单于薄胥堂不同，见《匈奴传》L9843–9848。

[本年原行R152](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r152) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0055)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

丙吉卒、黄霸接相、杜延年御史均接本页旧事，不再造三项重复任命。史表黄霸相在三月壬申，汉019二月壬申、本页旧叙事已采用二月，保留月差；御史“延年”由既有杜延年官历辨人，不误作同年已身故的田延年 · [宣帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-51dfe6e93bb77c)。

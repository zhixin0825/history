# 公元前56年｜杨恽与戴长乐互相告发，均被免为庶人；黄霸升御史大夫；许延寿升大司马车骑将军

**汉宣帝五凤二年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e215"></a>
### 杨恽与戴长乐互相告发，均被免为庶人

杨恽与太仆戴长乐不和，互相告发。案情上奏以后，宣帝没有立即处死两人，而是都免为庶人。杨恽失去平通侯爵，却还活着，后来的刑案不能提前。 [原文与说明](#sj020-e215-n)

<a id="sj020-e234"></a>
### 黄霸升御史大夫

黄霸由太子太傅升为御史大夫，进入中枢最高官列。 [原文与说明](#sj020-e234-n)

<a id="sj020-xu-sima"></a>
### 许延寿升大司马车骑将军

五月，强弩将军许延寿升为大司马车骑将军。此时距他出兵西羌已有数年，不能把出征、还军与这次升任都压在同一年。 [原文与说明](#sj020-xu-sima-n)

<a id="sj020-e234-n"></a>
**黄霸升御史大夫：** [S044 建成](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s044)。通鉴五凤二年八月与相关官历相接，不提前到五凤元年。此时仍未封建成侯。 互校：[資治通鑑/卷027](https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B7027)。

<a id="sj020-xu-sima-n"></a>
**许延寿升大司马车骑将军：** [S029原文](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s029)。补录只说还更拜大司马、光禄勋；百官表在五凤二年五月明记大司马车骑将军，故把这一任命从未定年说明补入前56年。光禄勋一职的起止并不因此同时定案，也不把不同官称默改为完全相同。 互校：[《汉书·百官公卿表》](https://zh.wikisource.org/wiki/漢書/卷019)。

# 公元前56年｜杨恽与戴长乐互相告发，均被免为庶人；黄霸升御史大夫；许延寿升大司马车骑将军

**汉宣帝五凤二年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **杨恽与戴长乐互相告发，均被免为庶人。** 杨恽与太仆戴长乐不和，互相告发。 案情上奏以后，宣帝没有立即处死两人，而是都免为庶人。杨恽失去平通侯爵，却还活着，后来的刑案不能提前。 [[1]](#note-1)

<a id="sj020-e234"></a>
<a id="黄霸升御史大夫"></a>


<a id="event-2"></a>

2. **黄霸升御史大夫。** 黄霸由太子太傅升为御史大夫，进入中枢最高官列。 [[2]](#note-2)

<a id="sj020-xu-sima"></a>
<a id="许延寿升大司马车骑将军"></a>


<a id="event-3"></a>

3. **许延寿升大司马车骑将军。** 五月，强弩将军许延寿升为大司马车骑将军。此时距他出兵西羌已有数年，不能把出征、还军与这次升任都压在同一年。 [[3]](#note-3)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-4"></a>

4. **韩增在本年去世。** 他去世以后，许延寿接下了大司马车骑将军的职务。 [[4]](#note-4)

<a id="hs-event-5"></a>

5. **在雍祠五畤。** 五凤二年春三月，宣帝到雍祭祀五畤。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **解除禁办婚宴的苛令。** 八月诏称婚姻和酒食聚会关乎礼乐，一些二千石官员禁止民间在婚礼上以酒食相贺，致乡里礼俗废弛。宣帝命停止这种禁令。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **呼鸱累单于率众归汉。** 十一月，匈奴呼鸱累单于率部众来降，汉封他为列侯。 [[7]](#hs-note-7)

#### 卷022｜将相表互见与异说

[本年原行R151](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r151) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0056)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

许延寿、黄霸两项任命接本页旧事。史表五月己丑韩曾卒，汉019四月己丑韩增卒，采用本年而不统一月日。史表五月许延寿任将、汉表也五月；黄霸八月任御史据汉表和原注 · [宣帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-40633ea5fa6ff0)。

**杨恽与戴长乐互相告发，均被免为庶人：** [S035 平通](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s035)。《通鉴》系五凤二年免官失爵，汉功臣表系三年；《宣帝纪》二年条又连叙免庶、不悔、腰斩，不能声称本纪把处分阶段逐年分得同样清楚。本文仍按通鉴考异采用前56年免、前54年斩，后者与补录五凤四年相接；不同年条和叙法全部留注。 互校：[漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-b6a0de0407ba65) · [資治通鑑考異/卷01](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91%E8%80%83%E7%95%B0-%E5%8D%B701.md#ref-957a30617157a6) · [資治通鑑/卷027](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7027.md#ref-2e2b751b1e58ea)。

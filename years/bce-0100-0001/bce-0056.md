1. **杨恽与戴长乐互相告发，均被免为庶人。** 杨恽与太仆戴长乐不和，互相告发。 案情上奏以后，宣帝没有立即处死两人，而是都免为庶人。杨恽失去平通侯爵，却还活着，后来的刑案不能提前。 [[1]](#note-1)

<a id="sj020-e234"></a>
<a id="黄霸升御史大夫"></a>


<a id="event-2"></a>

2. **黄霸升御史大夫。** 黄霸由太子太傅升为御史大夫，进入中枢最高官列。 丞相司直劾萧望之失礼并私使属吏，宣帝免其御史大夫，改授太子太傅；黄霸继任御史大夫。 [[2]](#note-2)

<a id="sj020-xu-sima"></a>
<a id="许延寿升大司马车骑将军"></a>


<a id="event-3"></a>

3. **许延寿升大司马车骑将军。** 五月，强弩将军许延寿升为大司马车骑将军。此时距他出兵西羌已有数年，不能把出征、还军与这次升任都压在同一年。 [[3]](#note-3)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-4"></a>

4. **韩增在本年去世。** 他去世以后，许延寿接下了大司马车骑将军的职务。 [[4]](#note-4)

<a id="hs-event-5"></a>

5. **在雍祠五畤。** 五凤二年春三月，宣帝到雍祭祀五畤。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **解除禁办婚宴的苛令。** 八月诏称婚姻和酒食聚会关乎礼乐，一些二千石官员禁止民间在婚礼上以酒食相贺，致乡里礼俗废弛。宣帝命停止这种禁令。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **呼鸱累单于率众归汉。** 十一月，匈奴呼鸱累单于率部众来降，汉封他为列侯。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **平干王刘元获罪而死。** 平干王刘元获罪而死。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **信成侯王定｜受封。** 表载信成侯王定一支本年有始封记载。表中所载事项为九月癸巳封。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **阳城缪侯刘德｜承爵。** 表载阳城缪侯刘德一支本年记载侯位承袭。表中所载事项为节侯安民承爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **呼韩邪击败屠耆，车犁归附。** 呼韩邪西袭屠耆所屯军，屠耆亲率大军应战，兵败自杀。都隆奇与屠耆少子归汉，车犁向东归呼韩邪。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **乌厉屈和父亲乌厉温敦率众降汉。** 屠耆败后，呼韩邪部左大将乌厉屈与父亲乌厉温敦带数万人归汉。父子的侯号及异文见相邻侯表。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **闰振与郅支分别称单于。** 呼韩邪返回单于庭。屠耆旧部休旬王杀左大且渠、并其兵，在西方自立为闰振单于。呼韩邪兄呼屠吾斯在东部自立为郅支单于。 [[14]](#hs-note-14)

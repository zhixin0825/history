# 公元前57年｜甘泉郊祭泰畤、皇太子举行冠礼

[← 公元前58年](bce-0058.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前56年 →](bce-0056.md)

**汉宣帝五凤元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **甘泉郊祭泰畤。** 五凤元年春正月，宣帝到甘泉郊祭泰畤。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **皇太子举行冠礼。** 皇太子加冠。皇太后赐丞相、将军、列侯和中二千石官员每人帛百匹，大夫人八十匹，并给列侯嗣子赐五大夫爵，可为父后者赐爵一级。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **赦免修杜陵刑徒。** 夏，朝廷赦免在杜陵服劳役的刑徒。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **十二月朔日食记录。** 冬十二月乙酉朔，史官记日食。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **韩延寿被处死。** 左冯翊韩延寿获罪，被处弃市。 萧望之追查东郡旧事，韩延寿反劾萧；查实韩延寿以官物仿尚方铸兵器、布车骑过制等情。 公卿论韩延寿僭越并诬告，遂弃市。吏民数千送至渭城。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **蒌节侯退一支爵位承袭。** 五凤元年，安侯充世继承侯爵，三年去世。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **安阳侯乐一支爵位承袭。** 五凤元年，安侯戚继承侯爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **宁阳节侯恬一支爵位承袭。** 五凤元年，康侯信继承侯爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **公丘夷侯顺一支爵位承袭。** 五凤元年，思侯赏继承侯爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **俞闾炀侯毋害一支爵位承袭。** 五凤元年，侯暽继承侯爵，十二年，初元三年去世，无子嗣承继。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **四月乙未分封王子侯。** [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **七月壬午分封王子侯。** [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **十二月癸巳分封王子侯。** [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **弓高壮侯韩隤当｜承爵。** 表载弓高壮侯韩隤当一支本年记载侯位承袭。表中所载事项为思侯宝承爵。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **博成侯张章｜承爵。** 表载博成侯张章一支本年记载侯位承袭。表中所载事项为侯建承爵。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **平昌节侯王无故｜承爵。** 表载平昌节侯王无故一支本年记载侯位承袭。表中所载事项为考侯接承爵。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **萧望之反对乘匈奴多单于相争出兵。** 诸单于争立，有人建议乘机出伐。萧望之主张吊问及扶助较弱者，宣帝采纳。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **匈奴五单于争立。** 除呼韩邪、屠耆外，呼揭王、右奥鞬王及乌藉都尉也称单于。呼揭与乌藉后弃号，与车犁合力。屠耆分兵东防呼韩邪，西击车犁。 [[19]](#hs-note-19)

### 5. 韩延寿被处死

[返回正文第5条](#hs-event-5)

<a id="hs076-l8975-e5"></a>

**[《汉书·赵尹韩张两王传》P027](../../sources/摘录/汉书-卷076-赵尹韩张两王传.md#p027)** · [仓内TXT L8975](../../sources/本地分卷/汉书/汉书-卷076.md#L8975)

> 侍謁者福為望之道延壽在東郡時放散官錢千餘萬。望之與丞相丙吉議，吉以為更大赦，不須考。會御史當問事東郡，望之因令并問之。延壽聞知，即部吏案校望之在馮翊時廩犧官錢放散百餘萬。廩犧吏掠治急，自引與望之為姦。延壽劾奏，移殿門禁止望之。望之自奏「職在總領天下，聞事不敢不問，而為延壽所拘持。」上由是不直延壽，各令窮竟所考。望之卒無事實，而望之遣御史案東郡，具得其事。延壽在東郡時，試騎士，治飾兵車，畫龍虎朱爵。延壽衣黃紈方領，駕四馬，傅總，建幢棨，植羽葆，鼓車歌車。功曹引車，皆駕四馬，載棨戟。五騎為伍，分左右部，軍假司馬、千人持幢旁轂。歌者先居射室，望見延壽車，噭咷楚歌。延壽坐射室，騎吏持戟夾陛列立，騎士從者帶弓鞬羅後。令騎士兵車四面營陳，被甲鞮鞪居馬上，抱弩負籣。又使騎士戲車弄馬盜驂。延壽又取官銅物，候月蝕鑄作刀劍鉤鐔，放效尚方事。及取官錢帛，私假繇使吏。及治飾車甲三百萬以上。

**互校说明** 《宣帝纪》记本年韩延寿弃市，《通鉴》同号串联互劾；“在东郡时”所列举动是前因。

<a id="hs076-l8976-e5"></a>

**[《汉书·赵尹韩张两王传》P028](../../sources/摘录/汉书-卷076-赵尹韩张两王传.md#p028)** · [仓内TXT L8976](../../sources/本地分卷/汉书/汉书-卷076.md#L8976)

> 於是望之劾奏延壽上僭不道，又自陳：「前為延壽所奏，今復舉延壽罪，眾庶皆以臣懷不正之心，侵冤延壽。願下丞相、中二千石、博士議其罪。」事下公卿，皆以延壽前既無狀，後復誣愬典法大臣，欲以解罪，狡猾不道。天子惡之，延壽竟坐棄市。吏民數千人送至渭城，老小扶持車轂，爭奏酒炙。延壽不忍距逆，人人為飲，計飲酒石餘。使掾史分謝送者：「遠苦吏民，延壽死無所恨。」百姓莫不流涕。

**互校说明** 《宣帝纪》《通鉴》均系五凤元年。

> 五鳳中匈奴大亂，議者多曰匈奴為害日久，可因其壞亂舉兵滅之。詔遣中朝大司馬車騎將軍韓增、諸吏富平侯張延壽、光祿勳楊惲、太僕戴長樂問望之計策，望之對曰：「春秋晉士饨帥師侵齊，聞齊侯卒，引師而還，君子大其不伐喪，以為恩足以服孝子，誼足以動諸侯。前單于慕化鄉善稱弟，遣使請求和親，海內欣然，夷狄莫不聞。未終奉約，不幸為賊臣所殺，今而伐之，是乘亂而幸災也，彼必奔走遠遁。不以義動兵，恐勞而無功。宜遣使者弔問，輔其微弱，救其災患，四夷聞之，咸貴中國之仁義。如遂蒙恩得復其位，必稱臣服從，此德之盛也。」上從其議，

**[《汉书·匈奴传》P089](../../sources/摘录/汉书-卷094-匈奴传.md#p089)** · [仓内TXT L9847](../../sources/本地分卷/汉书/汉书-卷094.md#L9847)

> 明年秋，屠耆單于使日逐王先賢撣兄右奧鞬王為烏藉都尉各二萬騎，屯東方以備呼韓邪單于。是時，西方呼揭王來與唯犁當戶謀，共讒右賢王，言欲自立為烏藉單于。屠耆單于殺右賢王父子，後知其冤，復殺唯犁當戶。於是呼揭王恐，遂畔去，自立為呼揭單于。右奧鞬王聞之，即自立為車犁單于。烏藉都尉亦自立為烏藉單于。凡五單于。屠耆單于自將兵東擊車犁單于，使都隆奇擊烏藉。烏藉、車犁皆敗，西北走，與呼揭單于兵合為四萬人。烏藉、呼揭皆去單于號，共并力尊輔車犁單于。屠耆單于聞之，使左大將、都尉將四萬騎屯東方，以備呼韓邪單于，自將四萬騎西擊車犁單于。車犁單于敗，西北走，屠耆單于即引西南，留闟敦地。

**互校说明** 承神爵四年明年，与《通鉴》卷二十七五凤元年相合；相关汉廷战和之议见同年前57年既有条。

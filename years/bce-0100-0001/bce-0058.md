本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **黄霸获赐关内侯，随后进入东宫。** 朝廷表彰黄霸治理颍川，赐关内侯爵、黄金，提高秩级。数月后，他被征为太子太傅。关内侯与后来带封国的建成侯，是不同阶段的爵位。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **因祥瑞、郊祀而大赦。** 二月诏称京师有凤凰甘露等瑞应，朝廷修祀泰一、五帝、后土，并记祭坛和斋宫出现神光。诏大赦、赐民爵和牛酒，并赐鳏寡孤独高年者帛。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **举荐可亲民的贤良。** 朝廷命内郡、诸侯国各举荐可亲民治事的贤良一人。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **匈奴单于之弟入朝。** 五月，匈奴单于派弟弟呼留若王胜之入朝。王号在《匈奴传》有异文。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **杜陵凤凰报告。** 冬十月，纪载凤凰十一度聚于杜陵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **严延年弃市。** 十一月，河南太守严延年因罪被处弃市。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **上林苑凤凰报告。** 十二月，纪载凤凰聚于上林苑。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **平望夷侯赏一支爵位承袭。** 神爵四年，顷侯起继承侯爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **平的戴侯强一支爵位承袭。** 神爵四年，顷侯鼻继承侯爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **三月癸丑分封王子侯。** 《王子侯表》列三月癸丑受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **西梁节侯辟兵受封。** 广川戴王子西梁节侯辟兵受封。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **七月壬子分封王子侯。** 《王子侯表》列历乡、阳城两位王子侯于七月壬子受封。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **将陵哀侯史曾｜去世。** 表载将陵哀侯史曾一支本年记载去世。表中所载事项为去世，无继承人。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **呼韩邪被拥立，握衍朐鞮败亡。** 乌桓击东边，姑夕王惧责，与乌禅幕等拥立稽侯狦为呼韩邪。握衍朐鞮军溃后自杀，部众归呼韩邪。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **都隆奇等拥立屠耆单于，击退呼韩邪。** 都隆奇与右贤王举日逐王薄胥堂为屠耆单于，攻呼韩邪，使两子分别为左、右谷蠡王。 [[16]](#hs-note-16)

<a id="hs090-l9628-e6"></a>

**[《汉书·酷吏传》P047](../../sources/摘录/汉书-卷090-酷吏传.md#p047)** · [仓内TXT L9628](../../sources/本地分卷/汉书/汉书-卷090.md#L9628)

> 初，延年母從東海來，欲從延年臘，到雒陽，適見報囚。母大驚，便止都亭，不肯入府。延年出至都亭謁母，母閉閤不見。延年免冠頓首閤下，良久，母乃見之，因數責延年：幸得備郡守，專治千里，不聞仁愛教化，有以全安愚民，顧乘刑罰多刑殺人，欲以立威，豈為民父母意哉！」延年服罪，重頓首謝，因自為母御，歸府舍。母畢正臘，謂延年：「天道神明，人不可獨殺。我不意當老見壯子被刑戮也！行矣！去女東歸，埽除墓地耳。」遂去。歸郡，見昆弟宗人，復為言之。後歲餘，果敗。東海莫不賢知其母。延年兄弟五人皆有吏材，至大官，東海號曰「萬石嚴嫗」。次弟彭祖，至太子太傅，在儒林傳。

### 15. 呼韩邪被拥立，握衍朐鞮败亡

[返回正文第15条](#hs-event-15)

<a id="hs094-l9845-e15"></a>

**[《汉书·匈奴传》P087](../../sources/摘录/汉书-卷094-匈奴传.md#p087)** · [仓内TXT L9845](../../sources/本地分卷/汉书/汉书-卷094.md#L9845)

> 其明年，烏桓擊匈奴東邊姑夕王，頗得人民，單于怒。姑夕王恐，即與烏禪幕及左地貴人共立稽侯蛳為呼韓邪單于，發左地兵四五萬人，西擊握衍朐鞮單于，至姑且水北。未戰，握衍朐鞮單于兵敗走，使人報其弟右賢王曰：「匈奴共攻我，若肯發兵助我乎？」右賢王曰：「若不愛人，殺昆弟諸貴人。各自死若處，無來汙我。」握衍朐鞮單于恚，自殺。左大且渠都隆奇亡之右賢王所，其民眾盡降呼韓邪單于。是歲，神爵四年也。握衍朐鞮單于立三年而敗。

**互校说明** 本传明确“神爵四年”，《通鉴》卷二十七同；与其后多个单于分立为连续不同阶段。

<a id="hs-note-16"></a>

### 16. 都隆奇等拥立屠耆单于，击退呼韩邪

[返回正文第16条](#hs-event-16)

<a id="hs094-l9846-e16"></a>

**[《汉书·匈奴传》P088](../../sources/摘录/汉书-卷094-匈奴传.md#p088)** · [仓内TXT L9846](../../sources/本地分卷/汉书/汉书-卷094.md#L9846)

> 其冬，都隆奇與右賢王共立日逐王薄胥堂為屠耆單于，發兵數萬人東襲呼韓邪單于。呼韓邪單于兵敗走，屠耆單于還，以其長子都塗吾西為左谷蠡王，少子姑瞀樓頭為右谷蠡王，留居單于庭。

**互校说明** 承神爵四年。屠耆单于薄胥堂与前单于屠耆堂姓名不可合一。

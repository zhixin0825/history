# 公元前58年｜黄霸获赐关内侯，随后进入东宫

**汉宣帝神爵四年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **黄霸获赐关内侯，随后进入东宫。** 朝廷表彰黄霸治理颍川，赐关内侯爵、黄金，提高秩级。数月后，他被征为太子太傅。关内侯与后来带封国的建成侯，是不同阶段的爵位。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **因祥瑞、郊祀而大赦。** 二月诏称京师有凤凰甘露等瑞应，朝廷修祀泰一、五帝、后土，并记祭坛和斋宫出现神光。诏大赦、赐民爵和牛酒，并赐鳏寡孤独高年者帛。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **举荐可亲民的贤良。** 朝廷命内郡、诸侯国各举荐可亲民治事的贤良一人。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **匈奴单于之弟入朝。** 五月，匈奴单于派弟弟呼留若王胜之入朝。王号在《匈奴传》有异文。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **杜陵凤凰报告。** 冬十月，纪载凤凰十一度聚于杜陵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **严延年弃市。** 十一月，河南太守严延年因罪被处弃市。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **上林苑凤凰报告。** 十二月，纪载凤凰聚于上林苑。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **平望夷侯赏一支爵位承袭。** 神爵四年，顷侯起继承侯爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **平的戴侯强一支爵位承袭。** 神爵四年，顷侯鼻继承侯爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **三月癸丑分封王子侯。** 《王子侯表》列三月癸丑受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **西梁节侯辟兵受封。** 广川戴王子西梁节侯辟兵受封。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **七月壬子分封王子侯。** 《王子侯表》列历乡、阳城两位王子侯于七月壬子受封。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **将陵哀侯史曾｜去世。** 表载将陵哀侯史曾一支本年记载去世。表中所载事项为去世，无继承人。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[14]](#hs-note-14)

**原文原格**

> 黃霸，家在陽夏，以役使徙雲陽。以廉吏為河內守丞，遷為廷尉監，行丞相長史事。坐見知夏侯勝非詔書大不敬罪，久繫獄三歲，從勝學尚書。會赦，以賢良舉為揚州刺史，潁川太守。善化，男女異路，耕者讓畔，賜黃金百斤，秩中二千石。居潁川，入為太子傅，遷御史大夫。五鳳三年，代邴吉為丞相。封千八百戶。

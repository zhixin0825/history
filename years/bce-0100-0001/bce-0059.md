本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

1. **魏相去世，丙吉继相，萧望之任御史大夫。** 魏相去世，丙吉任丞相。三月，魏相去世，高平侯爵由其子弘接续；四月，御史大夫丙吉升为丞相。两位大臣各有侯国，丙吉没有继承魏家的高平爵位。七月，萧望之由大鸿胪升御史大夫，接替已经入相的丙吉。 [[1]](#note-1)

<a id="sj020-e212"></a>
<a id="许敞开始承袭博望侯"></a>


<a id="event-2"></a>

2. **许敞开始承袭博望侯。** 博望侯由许敞接续许舜，开始新的侯年。 [[2]](#note-2)

<a id="sj020-e227"></a>
<a id="郑吉封安远侯"></a>


<a id="event-3"></a>

3. **郑吉封安远侯。** 郑吉因迎接日逐王归降以及此前攻车师的功劳，受封安远侯。由屯田、军事行动到接收归降，他承担的职责逐步扩大。 [[3]](#note-3)

<a id="hs-event-5"></a>

4. **营建乐游苑。** 神爵三年春，朝廷兴建乐游苑。 [[4]](#hs-note-5)

<a id="hs-event-6"></a>

5. **提高小吏俸禄。** 八月，宣帝认为小吏俸薄而难求其不侵扰百姓，命百石以下官吏增俸十分之五。 [[5]](#hs-note-6)

<a id="hs-event-7"></a>

6. **邯冓节侯偃一支爵位承袭。** 神爵三年，厘侯胜继承侯爵。 [[6]](#hs-note-7)

<a id="hs-event-8"></a>

7. **乐乡宪侯佟一支爵位承袭。** 神爵三年，节侯蒯继承侯爵。 [[7]](#hs-note-8)

<a id="hs-event-9"></a>

8. **海昬侯贺一支去世。** 神爵三年去世。 [[8]](#hs-note-9)

<a id="hs-event-10"></a>

9. **四月戊戌分封王子侯。** [[9]](#hs-note-10)

<a id="hs-event-11"></a>

10. **七月壬申分封王子侯。** [[10]](#hs-note-11)

<a id="hs-event-12"></a>

11. **下摩侯謼毒尼｜获罪。** 表载下摩侯謼毒尼一支本年载相关罪案及处分。表中所载事项为诏令居弋居山，因罪案将家属阑入恶师居，失爵。 [[11]](#hs-note-12)

<a id="hs-event-13"></a>

12. **归德靖侯先贤掸｜受封。** 《汉书》侯籍列归德靖侯先贤掸本年受封，所引月份、干支依表保留。 [[12]](#hs-note-13)

<a id="hs-event-14"></a>

13. **阳都侯张彭祖｜遇害。** 表载阳都侯张彭祖一支本年有相应记事。表中所载事项为为小妻所杀。 [[13]](#hs-note-14)

<a id="hs-event-15"></a>

14. **高平宪侯魏相｜承爵。** 表载高平宪侯魏相一支本年记载侯位承袭。表中所载事项为侯弘承爵。 [[14]](#hs-note-15)

<a id="hs-event-16"></a>

15. **博望顷侯许舜｜承爵。** 表载博望顷侯许舜一支本年记载侯位承袭。表中所载事项为康侯敞承爵。 [[15]](#hs-note-16)

<a id="hs-event-17"></a>

16. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 此前任东郡太守的韩延寿接萧望之任左冯翊。 [[16]](#hs-note-17)

<a id="hs-event-18"></a>

17. **神爵三年珠崖三县反。** 珠崖在并入儋耳后仍有反乱，传记明记神爵三年三县作乱。 [[17]](#hs-note-18)

#### 卷022｜将相表互见与异说

[本年原行R148](../../拆分史书/史记/卷022.md#r148) · [《汉书·百官公卿表》](../../拆分史书/汉书/卷019.md#part-3-ws019-bce-0059)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

魏相卒、丙吉任相仍接本页同事。史表只称御史大夫望之，汉019明七月甲子大鸿胪萧望之，为辨姓与前官依据；“邴吉”和既有“丙吉”同人异字，不另立第二位丞相 · [宣帝纪互见](../../拆分史书/汉书/卷008.md#part-1-text)。

#### 卷020｜原格、互见与采用的年线

<a id="sj020-e205-n"></a>
**魏相去世，丙吉任丞相：** [S027 高平](../../拆分史书/史记/卷020.md#s027) · [S043 博陽](../../拆分史书/史记/卷020.md#s043)。《汉书·宣帝纪》神爵三年三月丙午记魏相薨，《百官公卿表》同作三月丙午卒、四月戊戌任相；《通鉴》同年三月丙辰记卒、夏四月戊辰记丙吉任相。正文改为三月父卒、四月新相，撤回把两事都系四月的旧写法；卒日丙午／丙辰、任相日戊戌／戊辰的差别留注，不强算唯一日。补录丙吉任相作神爵二年，仍留异年；魏相后嗣宾／弘另存，家爵承袭不等于丞相世袭。 互校：[漢書/卷019](../../拆分史书/汉书/卷019.md#part-3-ws019-bce-0059) · [漢書/卷008](../../拆分史书/汉书/卷008.md#part-1-text) · [漢書/卷018](../../拆分史书/汉书/卷018.md#part-1-text) · [漢書/卷074](../../拆分史书/汉书/卷074.md#part-1-text) · [資治通鑑/卷026](../../拆分史书/资治通鉴/卷026.md#text)。

<a id="sj020-e212-n"></a>
**许敞开始承袭博望侯：** [S028 博望](../../拆分史书/史记/卷020.md#s028)。汉表神爵三年康侯敞嗣，补录子名延年不同；按同一承爵位置保存，不把他误认成同时还在任的大臣杜延年。父亲具体卒月未载，不用儿子元年断言父亲同日去世。 互校：[漢書/卷018](../../拆分史书/汉书/卷018.md#part-1-text)。

<a id="sj020-e227-n"></a>
**郑吉封安远侯：** [S042 安遠](../../拆分史书/史记/卷020.md#s042)。[《汉书·景武昭宣元成功臣表》](../../拆分史书/汉书/卷017.md#part-1-text)明系神爵三年四月壬戌；《宣帝纪》神爵二年已写皆封列侯，《通鉴》二年也明确写封吉安远侯。此前只说西域传紧接叙述会误读前60年，漏掉了本纪、通鉴的明年分歧，本次补正。正文暂采用有封日的表年，受降见前60年；这只是阅读取舍，不是已经证明存在两步授爵制度。 互校：[漢書/卷017](../../拆分史书/汉书/卷017.md#part-1-text) · [漢書/卷096上](../../拆分史书/汉书/卷096.md#part-1-text)。

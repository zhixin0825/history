# 公元前59年｜魏相去世，丙吉任丞相；许敞开始承袭博望侯

[← 公元前60年](bce-0060.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前58年 →](bce-0058.md)

**汉宣帝神爵三年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e205"></a>
### 魏相去世，丙吉任丞相

三月，魏相去世，高平侯爵由其子弘接续；四月，御史大夫丙吉升为丞相。两位大臣各有侯国，丙吉没有继承魏家的高平爵位。 [原文与说明](#sj020-e205-n)

<a id="sj020-e212"></a>
### 许敞开始承袭博望侯

博望侯由许敞接续许舜，开始新的侯年。 [原文与说明](#sj020-e212-n)

<a id="sj020-e227"></a>
### 郑吉封安远侯

郑吉因迎接日逐王归降以及此前攻车师的功劳，受封安远侯。由屯田、军事行动到接收归降，他承担的职责逐步扩大。 [原文与说明](#sj020-e227-n)

<a id="sj022"></a>
## 朝廷人事与本年补记

七月，萧望之由大鸿胪升御史大夫，接替已经入相的丙吉。 [原文与说明](#sj022-note)

## 本年相关史料

<a id="sj022-note"></a>
### 卷022｜将相表互见与异说

[本年原行R148](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r148) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0059)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

魏相卒、丙吉任相仍接本页同事。史表只称御史大夫望之，汉019明七月甲子大鸿胪萧望之，为辨姓与前官依据；“邴吉”和既有“丙吉”同人异字，不另立第二位丞相 · [宣帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-439dd2c53da127)。

<a id="sj020-e205-n"></a>
**魏相去世，丙吉任丞相：** [S027 高平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s027) · [S043 博陽](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s043)。《汉书·宣帝纪》神爵三年三月丙午记魏相薨，《百官公卿表》同作三月丙午卒、四月戊戌任相；《通鉴》同年三月丙辰记卒、夏四月戊辰记丙吉任相。正文改为三月父卒、四月新相，撤回把两事都系四月的旧写法；卒日丙午／丙辰、任相日戊戌／戊辰的差别留注，不强算唯一日。补录丙吉任相作神爵二年，仍留异年；魏相后嗣宾／弘另存，家爵承袭不等于丞相世袭。 互校：[漢書/卷019](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0059) · [漢書/卷008](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-9d678d6c4ba07d) · [漢書/卷018](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-b88ef707988e7d) · [漢書/卷074](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7074.md#ref-4644e6d4441e6e) · [資治通鑑/卷026](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7026.md#ref-3123a657771aa7)。

<a id="sj020-e212-n"></a>
**许敞开始承袭博望侯：** [S028 博望](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s028)。汉表神爵三年康侯敞嗣，补录子名延年不同；按同一承爵位置保存，不把他误认成同时还在任的大臣杜延年。父亲具体卒月未载，不用儿子元年断言父亲同日去世。 互校：[漢書/卷018](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-fc20900bbda691)。

<a id="sj020-e227-n"></a>
**郑吉封安远侯：** [S042 安遠](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s042)。[《汉书·景武昭宣元成功臣表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-e12090a09658e1)明系神爵三年四月壬戌；《宣帝纪》神爵二年已写皆封列侯，《通鉴》二年也明确写封吉安远侯。此前只说西域传紧接叙述会误读前60年，漏掉了本纪、通鉴的明年分歧，本次补正。正文暂采用有封日的表年，受降见前60年；这只是阅读取舍，不是已经证明存在两步授爵制度。 互校：[漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-ff31fc9ef88781) · [漢書/卷096上](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7096%E4%B8%8A.md#ref-a72d320a397e7c)。

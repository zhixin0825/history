# 公元前59年｜魏相去世，丙吉任丞相；许敞开始承袭博望侯

**汉宣帝神爵三年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e205"></a>
### 魏相去世，丙吉任丞相

三月，魏相去世，高平侯爵由其子弘接续；四月，御史大夫丙吉升为丞相。两位大臣各有侯国，丙吉没有继承魏家的高平爵位。 [原文与说明](#sj020-e205-n)

<a id="sj020-e212"></a>
### 许敞开始承袭博望侯

博望侯由许敞接续许舜，开始新的侯年。 [原文与说明](#sj020-e212-n)

<a id="sj020-e227"></a>
### 郑吉封安远侯

郑吉因迎接日逐王归降以及此前攻车师的功劳，受封安远侯。由屯田、军事行动到接收归降，他承担的职责逐步扩大。 [原文与说明](#sj020-e227-n)

<a id="sj020-e205-n"></a>
**魏相去世，丙吉任丞相：** [S027 高平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s027) · [S043 博陽](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s043)。《汉书·宣帝纪》神爵三年三月丙午记魏相薨，《百官公卿表》同作三月丙午卒、四月戊戌任相；《通鉴》同年三月丙辰记卒、夏四月戊辰记丙吉任相。正文改为三月父卒、四月新相，撤回把两事都系四月的旧写法；卒日丙午／丙辰、任相日戊戌／戊辰的差别留注，不强算唯一日。补录丙吉任相作神爵二年，仍留异年；魏相后嗣宾／弘另存，家爵承袭不等于丞相世袭。 互校：[漢書/卷019](https://zh.wikisource.org/wiki/漢書/卷019) · [漢書/卷008](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7008) · [漢書/卷018](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7018) · [漢書/卷074](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7074) · [資治通鑑/卷026](https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B7026)。

<a id="sj020-e212-n"></a>
**许敞开始承袭博望侯：** [S028 博望](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s028)。汉表神爵三年康侯敞嗣，补录子名延年不同；按同一承爵位置保存，不把他误认成同时还在任的大臣杜延年。父亲具体卒月未载，不用儿子元年断言父亲同日去世。 互校：[漢書/卷018](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7018)。

<a id="sj020-e227-n"></a>
**郑吉封安远侯：** [S042 安遠](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s042)。[《汉书·景武昭宣元成功臣表》](https://zh.wikisource.org/wiki/漢書/卷017)明系神爵三年四月壬戌；《宣帝纪》神爵二年已写皆封列侯，《通鉴》二年也明确写封吉安远侯。此前只说西域传紧接叙述会误读前60年，漏掉了本纪、通鉴的明年分歧，本次补正。正文暂采用有封日的表年，受降见前60年；这只是阅读取舍，不是已经证明存在两步授爵制度。 互校：[漢書/卷017](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7017) · [漢書/卷096上](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7096%E4%B8%8A)。

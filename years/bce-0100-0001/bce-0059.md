# 公元前59年｜魏相去世，丙吉任丞相；许敞开始承袭博望侯

**汉宣帝神爵三年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e205"></a>
### 魏相去世，丙吉任丞相

四月，魏相去世，高平侯爵由其子弘接续；御史大夫丙吉升为丞相。两位大臣各有侯国，丙吉没有继承魏家的高平爵位。 [原文与说明](#sj020-e205-n)

<a id="sj020-e212"></a>
### 许敞开始承袭博望侯

博望侯由许敞接续许舜，开始新的侯年。 [原文与说明](#sj020-e212-n)

<a id="sj020-e227"></a>
### 郑吉封安远侯

郑吉因迎接日逐王归降以及此前攻车师的功劳，受封安远侯。由屯田、军事行动到接收归降，他承担的职责逐步扩大。 [原文与说明](#sj020-e227-n)

**魏相去世，丙吉任丞相：** [S027 高平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s027) · [S043 博陽](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s043)。宣帝纪神爵三年四月明记魏相卒、丙吉任相。补录把丙吉升相写神爵二年，本文不采用提前一年；魏相子名补作宾，汉表弘，按同一父子承袭留异写。 互校：[漢書/卷008](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7008) · [漢書/卷018](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7018) · [漢書/卷074](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7074) · [資治通鑑/卷026](https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B7026)。

<a id="sj020-e212-n"></a>
**许敞开始承袭博望侯：** [S028 博望](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s028)。汉表神爵三年康侯敞嗣，补录子名延年不同；按同一承爵位置保存，不把他误认成同时还在任的大臣杜延年。父亲具体卒月未载，不用儿子元年断言父亲同日去世。 互校：[漢書/卷018](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7018)。

<a id="sj020-e227-n"></a>
**郑吉封安远侯：** [S042 安遠](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s042)。汉功臣表明神爵三年四月壬戌初封；西域传把归降与封侯紧接，容易读成前60年。本文区分前60年受降、前59年表列授爵，保留传叙压缩，不重复受降。 互校：[漢書/卷017](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7017) · [漢書/卷096上](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7096%E4%B8%8A)。

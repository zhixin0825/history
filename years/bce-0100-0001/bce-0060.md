# 公元前60年｜日逐王归降，郑吉率人迎接

**汉宣帝神爵二年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **日逐王归降，郑吉率人迎接。** 匈奴内部争位，日逐王决定带部众归汉，先向郑吉传信。郑吉带吏卒前往接应，途中有人想返回，他处置了带头者，把归降人群带到汉境。 [[1]](#note-1)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-2"></a>

2. **宣帝到雍祭祀五畤。** 祋祤出土了被朝廷视为祥瑞的玉器，记入当年的政事。 [[2]](#note-2)

<a id="hs-event-3"></a>

3. **因祥鸟甘露报告大赦。** 二月诏说正月乙丑京师有凤凰、甘露及群鸟相从的报告，宣帝自陈敬谨并赦天下。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **西羌降服与金城属国。** 五月，西羌降服，首领杨玉、酋非被诛，汉廷置金城属国安置降羌。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **盖宽饶获罪自杀。** 九月，司隶校尉盖宽饶获罪，交有关官署办理，自杀。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **匈奴使者贺正月。** 匈奴单于遣有封号的王奉献礼物，祝贺正月。本纪由此记双方开始和亲往来。 [[6]](#hs-note-6)

#### 卷022｜将相表互见与异说

[本年原行R147](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r147) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0060)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史表所称“宝璧玉器”是当时赋予器物的政治与礼仪意义，不能据记载就断言它具有神异效力；祋祤与汾阴不混成同一出土地。前一年的西羌战争也不因本年将位留空就证明已在元旦停战 · [宣帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-40ee9d6a87bebd)。

**日逐王归降，郑吉率人迎接：** [S042 安遠](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s042)。受降据汉西域传、通鉴神爵二年；数百是补录中郑吉所带吏卒，不是日逐王全部降众。封侯另有明确异年：《宣帝纪》本年写皆封列侯，《通鉴》本年也明说上封吉为安远侯；功臣表却列神爵三年四月。主叙暂将受降放本年、表列初封放前59年，不宣称先受命后正式授爵的制度过程已经被证明。 互校：[資治通鑑/卷026](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7026.md#ref-19afba07387955) · [漢書/卷096上](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7096%E4%B8%8A.md#ref-3c0c7f2381fe27) · [漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-7333eabe156d1f)。

<a id="event-1"></a>

1. **日逐王归降，郑吉率人迎接。** 匈奴内部争位，日逐王决定带部众归汉，先向郑吉传信。郑吉带吏卒前往接应，途中有人想返回，他处置了带头者，把归降人群带到汉境。 郑吉此前负责南道，接纳日逐王后兼护北道，并称西域都护。 郑吉原护南道，迎日逐王降后兼护北道，号都护，匈奴所置僮仆都尉因此废去。 [[1]](#note-1)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-2"></a>

2. **宣帝到雍祭祀五畤。** 祋祤出土了被朝廷视为祥瑞的玉器，记入当年的政事。 [[2]](#note-2)

<a id="hs-event-3"></a>

3. **因祥鸟甘露报告大赦。** 二月诏说正月乙丑京师有凤凰、甘露及群鸟相从的报告，宣帝自陈敬谨并赦天下。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **西羌降服与金城属国。** 五月，赵充国奏请罢屯兵，朝廷批准。先零首领杨玉、猶非被杀，其余部众相继归降，汉廷置金城属国安置；首领伏诛与诸部归降的月序见同号史料。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **盖宽饶获罪自杀。** 九月，司隶校尉盖宽饶获罪，交有关官署办理，自杀。 盖宽饶疏论朝廷重刑法、任宦官，执金吾指其议论禅让为谋求受禅。郑昌争救未果，盖宽饶在北阙下自刎。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **匈奴使者贺正月。** 匈奴单于遣有封号的王奉献礼物，祝贺正月。本纪由此记双方开始和亲往来。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **瑕丘节侯政一支爵位承袭。** 神爵二年，炀侯奉义继承侯爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **松兹戴侯霸一支爵位承袭。** 神爵二年，共侯始继承侯爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **兰旗顷侯临朝一支爵位承袭。** 神爵二年，节侯去疾继承侯爵，七年去世。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **东阳节侯弘一支爵位承袭。** 神爵二年，厘侯纵继承侯爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **张侯嵩一支后事。** 神爵二年，因……获罪贼杀人，上书要上，下狱瘐死亡。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **苏武去世。** 曾出使匈奴、还汉后任典属国的苏武病逝，年八十余。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **赵卬被告泄禁语而自杀。** 赵充国归军后，辛武贤告赵卬泄露宫中语。赵卬在军中也曾有违规案由，终下吏而自杀。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **常惠送少主至敦煌，朝廷中止婚约。** 宣帝遣常惠送汉少主配元贵靡，未出塞已闻翁归靡死、狂王自立。常惠请少主暂留敦煌，赴乌孙责约，萧望之主张召还少主，宣帝从之。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **题除渠堂归汉告警，虚闾权渠撤军请和。** 虚闾权渠单于借沿塞打猎谋进攻汉境。题除渠堂降汉告警，赵充国率军九郡守边。单于因病撤军，遣使求和，未获答复即去世。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **颛渠阏氏等拥立握衍朐鞮单于。** 虚闾权渠卒后，颛渠阏氏与弟都隆奇抢在诸王会集前，立右贤王屠耆堂为握衍朐鞮单于。 [[17]](#hs-note-17)

### 5. 盖宽饶获罪自杀

[返回正文第5条](#hs-event-5)

<a id="hs077-l9018-e5"></a>

**[《汉书·盖诸葛刘郑孙毋将何传》P006](../../拆分史书/汉书/卷077.md#p006)** · [仓内TXT L9018](../../拆分史书/汉书/卷077.md#part-1-L9018)

> 是時上方用刑法，信任中尚書宦官，寬饒奏封事曰：「方今聖道浸廢，儒術不行，以刑餘為周召，以法律為詩書。」又引韓氏易傳言：「五帝官天下，三王家天下，家以傳子，官以傳賢，若四時之運，功成者去，不得其人則不居其位。」書奏，上以寬饒怨謗終不改，下其書中二千石。時執金吾議，以為寬饒指意欲求禪，大逆不道。諫大夫鄭昌愍傷寬饒忠直憂國，以言事不當意而為文吏所詆挫，上書頌寬饒曰：「臣聞山有猛獸，藜藿為之不采；國有忠臣，姦邪為之不起。司隸校尉寬饒居不求安，食不求飽，進有憂國之心，退有死節之義，上無許、史之屬，下無金、張之託，職在司察，直道而行，多仇少與，上書陳國事，有司劾以大辟，臣幸得從大夫之後，官以諫為名，不敢不言。」上不聽，遂下寬饒吏。寬饒引佩刀自剄北闕下，眾莫不憐之。

**互校说明** 《宣帝纪》神爵二年九月，传具奏议和自刎地点。

### 15. 常惠送少主至敦煌，朝廷中止婚约

[返回正文第15条](#hs-event-15)

<a id="hs096-l10043-e15"></a>

**[《汉书·西域传》P095](../../拆分史书/汉书/卷096.md#p095)** · [仓内TXT L10043](../../拆分史书/汉书/卷096.md#part-1-L10043)

> 上乃以烏孫主解憂弟子相夫為公主，置官屬侍御百餘人，捨上林中，學烏孫言。天子自臨平樂觀，會匈奴使者、外國君長大角抵，設樂而遣之。使長羅侯光祿大夫惠為副，凡持節者四人，送少主至郭煌。未出塞，聞烏孫昆彌翁歸靡死，烏孫貴人共從本約，立岑陬子泥靡代為昆靡，號狂王。惠上書：「願留少主郭煌，惠馳至烏孫責讓不立元貴靡為昆靡，還迎少主。」事下公卿，望之復以為：「烏孫持兩端，難約結。前公主在烏孫四十餘年，恩愛不親密，邊竟未得安，此已事已驗也。令少主以元貴靡不立而還，信無負於夷狄，中國之福也。少主不止，徭役將興，其原起此。」天子從之，征還少主。

**互校说明** 本传首记元康二年；《通鉴》卷026采《萧望之传》系神爵二年，考异以萧望之任大鸿胪的官历辨正。

<a id="hs078-l9063-e15"></a>

**[《汉书·萧望之传》P010](../../拆分史书/汉书/卷078.md#p010)** · [仓内TXT L9063](../../拆分史书/汉书/卷078.md#part-1-L9063)

> 神爵二年，遣長羅侯惠使送公主配元貴靡。未出塞，翁歸靡死，其兄子狂王背約自立。惠從塞下上書，願留少主敦煌郡。惠至烏孫，責以負約，因立元貴靡，還迎少主。詔下公卿議，望之復以為「不可。烏孫持兩端，亡堅約，其效可見。前少主在烏孫四十餘年，恩愛不親密，邊境未以安，此已事之驗也。今少主以元貴靡不得立而還，信無負於四夷，此中國之大福也。少主不止，繇役將興，其原起此。」天子從其議，徵少主還。

**互校说明** 本传明系神爵二年；卷096《乌孙传》称元康二年，司马光《考异》以萧望之当时未为大鸿胪为由从本传。后来分立大小昆弥是另一阶段。

> 其明年，單于將十萬餘騎旁塞獵，欲入邊寇。未至，會其民題除渠堂亡降漢言狀，漢以為言兵鹿奚盧侯，而遣後將軍趙充國將兵四萬餘騎屯緣邊九郡備虜。月餘，單于病歐血，因不敢入，還去，即罷兵。乃使題王都犁胡次等入漢，請和親，未報，會單于死。是歲，神爵二年也。

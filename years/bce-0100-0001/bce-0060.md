<a id="event-1"></a>

1. **日逐王归降，郑吉率人迎接。** 匈奴内部争位，日逐王决定带部众归汉，先向郑吉传信。郑吉带吏卒前往接应，途中有人想返回，他处置了带头者，把归降人群带到汉境。 郑吉此前负责南道，接纳日逐王后兼护北道，并称西域都护。 [[1]](#note-1)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-2"></a>

2. **宣帝到雍祭祀五畤。** 祋祤出土了被朝廷视为祥瑞的玉器，记入当年的政事。 [[2]](#note-2)

<a id="hs-event-3"></a>

3. **因祥鸟甘露报告大赦。** 二月诏说正月乙丑京师有凤凰、甘露及群鸟相从的报告，宣帝自陈敬谨并赦天下。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **西羌降服与金城属国。** 五月，赵充国奏请罢屯兵，朝廷批准。先零首领杨玉、猶非被杀，其余部众相继归降，汉廷置金城属国安置；首领伏诛与诸部归降的月序见同号史料。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **盖宽饶获罪自杀。** 九月，司隶校尉盖宽饶获罪，交有关官署办理，自杀。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **匈奴使者贺正月。** 匈奴单于遣有封号的王奉献礼物，祝贺正月。本纪由此记双方开始和亲往来。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **瑕丘节侯政一支爵位承袭。** 神爵二年，炀侯奉义继承侯爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **松兹戴侯霸一支爵位承袭。** 神爵二年，共侯始继承侯爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **兰旗顷侯临朝一支爵位承袭。** 神爵二年，节侯去疾继承侯爵，七年去世。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **东阳节侯弘一支爵位承袭。** 神爵二年，厘侯纵继承侯爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **张侯嵩一支后事。** 神爵二年，因……获罪贼杀人，上书要上，下狱瘐死亡。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **苏武去世。** 曾出使匈奴、还汉后任典属国的苏武病逝，年八十余。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **赵卬被告泄禁语而自杀。** 赵充国归军后，辛武贤告赵卬泄露宫中语。赵卬在军中也曾有违规案由，终下吏而自杀。 [[14]](#hs-note-14)

[完整原文](../../sources/摘录/史记-卷020-建元以来侯者年表.md) · [逐格去向](../../meta/记录/史记-卷020-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷020-纪年与异说.md)。初封、增邑、继承与任官分开；月日未明不补，谥号为后称，国除不一律等于处死。

<a id="sj020-e226-n"></a>
**日逐王归降，郑吉率人迎接：** [S042 安遠](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s042)。受降据汉西域传、通鉴神爵二年；数百是补录中郑吉所带吏卒，不是日逐王全部降众。封侯另有明确异年：《宣帝纪》本年写皆封列侯，《通鉴》本年也明说上封吉为安远侯；功臣表却列神爵三年四月。主叙暂将受降放本年、表列初封放前59年，不宣称先受命后正式授爵的制度过程已经被证明。 互校：[資治通鑑/卷026](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7026.md#ref-19afba07387955) · [漢書/卷096上](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7096%E4%B8%8A.md#ref-3c0c7f2381fe27) · [漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-7333eabe156d1f)。

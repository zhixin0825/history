# 公元前61年｜许广汉去世，平恩侯一支暂绝；许延寿以强弩将军出征西羌

**汉宣帝神爵元年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e195"></a>
### 许广汉去世，平恩侯一支暂绝

许广汉去世，没有儿子承接平恩侯，侯国一度中断。 [原文与说明](#sj020-e195-n)

<a id="sj020-e213"></a>
### 许延寿以强弩将军出征西羌

许延寿以强弩将军领兵参与西羌战争。此前因旧恩封侯，与此时承担军事任务，是两种不同的经历。 [原文与说明](#sj020-e213-n)

<a id="sj022"></a>
## 朝廷人事与本年补记

赵充国以後将军领兵西上，辛武贤获任破羌将军，与许延寿的强弩将军军队共同参与西羌战争。朝廷对用兵和屯田的意见并不完全一致，赵充国希望分清先零与其他部落，逐步招降。韩增另升大司马车骑将军。宣帝也前往甘泉与汾阴祭祀。 [原文与说明](#sj022-note)

### 卷022｜将相表互见与异说

[本年原行R146](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r146) · [《汉书·百官公卿表》](https://zh.wikisource.org/wiki/漢書/卷019)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

许延寿任将接本页旧事。史表四月列任将，不把这一月扩大为所有军队同日出发；赵充国、辛武贤官号由汉069互见，实际任将和后续军令在传中分阶段叙述。甘泉太畤、汾阴后土为两个祭祀对象，不合成同一地点的一场祭礼。韩曾/韩增仍按同一人辨认；汉019神爵元年任大司马车骑可证 · [宣帝纪互见](https://zh.wikisource.org/wiki/漢書/卷008) · [赵充国传互见](https://zh.wikisource.org/wiki/漢書/卷069)。

<a id="sj020-e195-n"></a>
**许广汉去世，平恩侯一支暂绝：** [S025 平恩](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s025)。汉恩泽表地节三年封、七年薨的年链对应神爵元年，本页注明是侯籍任期归年，不假称有独立卒月。后来同族再封是另一阶段；“无后”指当时承爵，不是说许氏或女系后裔都不存在。 互校：[漢書/卷018](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7018)。

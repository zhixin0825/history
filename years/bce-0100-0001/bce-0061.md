# 公元前61年｜许广汉去世，平恩侯一支暂绝；许延寿以强弩将军出征西羌

[← 公元前62年](bce-0062.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前60年 →](bce-0060.md)

**汉宣帝神爵元年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020-e195"></a>

<a id="event-1"></a>

1. **许广汉去世，平恩侯一支暂绝。** 许广汉去世，没有儿子承接平恩侯，侯国一度中断。 [[1]](#note-1)

<a id="sj020-e213"></a>
<a id="许延寿以强弩将军出征西羌"></a>


<a id="event-2"></a>

2. **许延寿以强弩将军出征西羌。** 许延寿以强弩将军领兵参与西羌战争。此前因旧恩封侯，与此时承担军事任务，是两种不同的经历。 [[2]](#note-2)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-3"></a>

3. **赵充国以後将军领兵西上，辛武贤获任破羌将军，与许延寿的强弩将军军队共同参与西羌战争。** 朝廷对用兵和屯田的意见并不完全一致，赵充国希望分清先零与其他部落，逐步招降。韩增另升大司马车骑将军。宣帝也前往甘泉与汾阴祭祀。 [[3]](#note-3)

<a id="hs-event-4"></a>

4. **祭泰畤、后土与改元神爵。** 正月赴甘泉祭泰畤，三月在河东祠后土。诏书回顾元康四年的嘉谷、神爵、金芝、异兽等报告，又叙祭祀行程所见祥瑞，将原本的五年改称神爵元年，给吏民赐爵、牛酒、帛，免收此前所贷物资和巡行所经之地田租。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **东方孛星。** 六月，史官记东方出现孛星。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **赐朱邑之子黄金奉祀。** 秋，赐已故大司农朱邑之子黄金百斤，以供奉祭。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **阿武戴侯豫一支爵位承袭。** 神爵元年，厘侯婴齐继承侯爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **南城节侯贞一支爵位承袭。** 神爵元年，元侯尊继承侯爵，二年去世。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **虖葭康侯泽一支爵位承袭。** 神爵元年，夷侯舞继承侯爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **挟厘侯霸一支爵位承袭。** 神爵元年，爵侯贤继承侯爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **猇节侯起一支爵位承袭。** 神爵元年，恭侯广明继承侯爵。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **成献侯喜一支爵位承袭。** 神爵元年，顷侯得疵继承侯爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **四月癸巳分封王子侯。** 《王子侯表》列四月癸巳受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **扶阳节侯韦贤｜承爵。** 表载扶阳节侯韦贤一支本年记载侯位承袭。表中所载事项为共侯玄成承爵。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **宣帝令祭江海、洛水。** 志系神爵改元后，并补祭地、频次和使者制度。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **宣帝以方士言增神祠。** 依《通鉴》卷026神爵元年与本志相顺；只采四宝祠确有同段证据，不给全部并陈诸祠各自立年。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **王褒持节求金马碧鸡。** 《通鉴》卷026列神爵元年；所求为益州方术传说。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **神爵元年秋大旱。** 《汉书》在本年记载神爵元年秋大旱。 [[19]](#hs-note-19)

<a id="hs008-l717-e4"></a>

**[《汉书·宣帝纪》P075](../../sources/摘录/汉书-卷008-宣帝纪.md#p075)** · [仓内TXT L717](../../sources/本地分卷/汉书/汉书-卷008.md#L717)

> 神爵元年春正月，行幸甘泉，郊泰畤。三月，行幸河東，祠后土。詔曰：「朕承宗廟，戰戰栗栗，惟萬事 統，未燭厥理。乃元康四年嘉穀玄稷降于郡國，神爵仍集，金芝九莖產于函德殿銅池中，九真獻奇獸，南郡獲白虎威鳳為寶。朕之不明，震于珍物，飭躬齋精，祈為 百姓。東濟大河，天氣清靜，神魚舞河。幸萬歲宮，神爵翔集。朕之不德，懼不能任。其以五年為神爵元年。賜天下勤事吏爵二級，民一級，女子百戶牛酒，鰥寡孤 獨高年帛。所振貸物勿收。行所過毋出田租。」

**互校说明** 元康四年祥瑞是诏书回叙；此处保存神爵元年祀典及改元，诸祥物按报告表述。

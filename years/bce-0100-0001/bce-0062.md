# 公元前62年｜张安世去世，张延寿承富平侯；韦贤去世，韦玄成推让侯爵

[← 公元前63年](bce-0063.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前61年 →](bce-0061.md)

**汉宣帝元康四年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **张安世去世，张延寿承富平侯。** 八月，张安世去世，张延寿承袭富平侯。延寿此前已经历任九卿，接爵以后又多次请求减少封邑，担心自己没有父辈功劳，难以长期承担大国厚赏。 [[1]](#note-1)

<a id="sj020-e182"></a>
<a id="韦贤去世韦玄成推让侯爵"></a>


<a id="event-2"></a>

2. **韦贤去世，韦玄成推让侯爵。** 韦贤去世后，家人安排由儿子玄成继承。玄成认为这未必符合父亲原意，故意表现失常，想把爵位让给兄长；朝廷核实后，仍让他受爵。 [[2]](#note-2)

<a id="hs-event-3"></a>

3. **遣十二使者巡察郡国。** 元康四年正月，派彊等十二名使者分赴郡国，访视鳏寡、察吏治和风俗并举荐人才。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **河东霍徵史等案。** 二月，河东霍徵史等被认定谋反，遭诛。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **京畿祥鸟报告与赐爵。** 三月诏载五彩神爵大量聚集于宫殿、甘泉泰畤和上林苑，因而赐吏民爵、女子牛酒，并按类别赐三老、孝悌力田及鳏寡孤独者布帛。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **赐尹翁归之子与功臣嫡嗣。** 八月，朝廷赐故右扶风尹翁归之子黄金百斤，以供奉祭，又赐功臣嫡嗣每人黄金二十斤。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **连年丰收与粮价记录。** 史书记载连年丰收，谷价每石五钱，是对当时物价的概述。 [[7]](#hs-note-7)

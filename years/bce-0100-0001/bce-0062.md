<a id="event-1"></a>

1. **张安世去世，张延寿承富平侯。** 八月，张安世去世，张延寿承袭富平侯。延寿此前已经历任九卿，接爵以后又多次请求减少封邑，担心自己没有父辈功劳，难以长期承担大国厚赏。 [[1]](#note-1)

<a id="sj020-e182"></a>
<a id="韦贤去世韦玄成推让侯爵"></a>


<a id="event-2"></a>

2. **韦贤去世，韦玄成推让侯爵。** 韦贤去世后，家人安排由儿子玄成继承。玄成认为这未必符合父亲原意，故意表现失常，想把爵位让给兄长；朝廷核实后，仍让他受爵。 [[2]](#note-2)

<a id="hs-event-3"></a>

3. **遣十二使者巡察郡国。** 元康四年正月，派彊等十二名使者分赴郡国，访视鳏寡、察吏治和风俗并举荐人才。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **河东霍徵史等案。** 二月，河东霍徵史等被认定谋反，遭诛。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **京畿祥鸟报告与赐爵。** 三月诏载五彩神爵大量聚集于宫殿、甘泉泰畤和上林苑，因而赐吏民爵、女子牛酒，并按类别赐三老、孝悌力田及鳏寡孤独者布帛。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **赐尹翁归之子与功臣嫡嗣。** 八月，朝廷赐故右扶风尹翁归之子黄金百斤，以供奉祭，又赐功臣嫡嗣每人黄金二十斤。 尹翁归于本年病死，家无余财；赐金以奉其祀。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **连年丰收与粮价记录。** 连年丰收，谷价一度每石五钱。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **定敷侯越一支爵位承袭。** 元康四年，宪侯福继承侯爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **乘丘节侯将夜一支失爵。** 元康四年，因……获罪为子时与後母乱，免去侯爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **瓡节侯息一支爵位承袭。** 元康四年，质侯守继承侯爵，七年去世。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **景成原侯雍一支爵位承袭。** 元康四年，顷侯欧继承侯爵。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **三月甲寅分封王子侯。** [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **功臣后裔分批获诏复家。** 宣帝陆续下诏免去早期功臣后裔本家的赋役，其中有些人还获赐金。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **合阳爱侯梁喜｜受封。** 表载合阳爱侯梁喜一支本年有始封记载。表中所载事项为二月壬午封。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 冯奉世由光禄大夫任水衡都尉。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **宣帝对高年者宽免刑责。** 宣帝元康四年诏，一般不科八十岁以上者罪，诬告杀伤人例外。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **汉遣殷广德索回车师王乌贵。** 殷广德向乌孙索回先前出奔的乌贵，带到汉廷，并赐住宅供乌贵及其妻儿居住。 [[17]](#hs-note-17)

> 及賢病篤，弘竟坐宗廟事繫獄，罪未決。室家問賢當為後者，賢恚恨不肯言。於是賢門下生博士義倩等與宗家計議，共矯賢令，使家丞上書言大行，以大河都尉玄成為後。賢薨，玄成在官聞喪，又言當為嗣，玄成深知其非賢雅意，即陽為病狂，臥便利，妄笑語昏亂。徵至長安，既葬，當襲爵，以病狂不應召。

**互校说明** 《通鉴》按元康四年连叙卒、改嗣与辞让。实际引拜参次年前61年侯表。

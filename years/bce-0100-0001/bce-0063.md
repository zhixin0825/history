2. **宣帝报答母族、太子外家与丙吉，授以列侯。** 宣帝追报未即位时的旧恩。许广汉的两个弟弟曾帮助刘病已，原任长乐卫尉的许舜封博望侯，少弟许延寿封乐成侯。宣帝祖母史良娣的亲族史曾、史玄分封将陵侯、平台侯。鲁地人丙吉早年办案入仕，曾在狱中保护皇曾孙，后来入大将军幕府、任御史大夫，封博阳侯。丙吉病中辞封，另荐确有劳的掖庭旧人胡组与郭徵卿。 [[2]](#note-2)

3. **黄霸在颍川推行教化、救济与基层约束。** 黄霸在颍川令地方官救济鳏寡贫穷，劝农桑、节用，借父老和基层组织防范违法；他也尽量稳定任职的属吏，减少频繁更换带来的负担。朝廷因其治理声誉，一度召他代理京兆尹，后来又让他回颍川。 [[3]](#note-8)

<a id="hs-event-9"></a>

4. **因泰山神爵报告普赐。** 春，因神爵屡集泰山的报告，朝廷按身份赐王侯、官吏金帛，并向民众赐爵、女子牛酒及鳏寡孤独高年者帛。 [[4]](#hs-note-9)

<a id="hs-event-10"></a>

5. **刘贺封海昏侯。** 三月诏引舜封有罪的象为例，表示顾念宗亲，将废帝刘贺封为海昏侯。 [[5]](#hs-note-10)

<a id="hs-event-11"></a>

6. **三辅春夏禁毁巢取卵射鸟。** 六月诏回顾前年神爵聚于雍、今春五色鸟飞经属县的报告，令三辅在春夏不得摘巢、取卵和射飞鸟，制为法令。 [[6]](#hs-note-11)

<a id="hs-event-12"></a>

7. **刘钦立淮阳王。** 立皇子刘钦为淮阳王。 [[7]](#hs-note-12)

> 時上垂意於治，數下恩澤詔書，吏不奉宣。太守霸為選擇良吏，分部宣布詔令，令民咸知上意。使郵亭鄉官皆畜雞豚，以贍鰥寡貧窮者，然後為條教，置父老師帥伍長，班行之於民間，勸以為善防姦之意，及務耕桑，節用殖財，種樹畜養，去食穀馬。米鹽靡密，初若煩碎，然霸精力能推行之。吏民見者，語次尋繹，問它陰伏，以相參考。嘗欲有所司察，擇長年廉吏遣行，屬令周密。吏出，不敢舍郵亭，食於道旁，烏攫其肉。民有欲詣府口言事者適見之，霸與語道此。後日吏還謁霸，霸見迎勞之，曰：「甚苦！食於道旁乃為烏所盜肉。」吏大驚，以霸具知其起居，所問豪氂不敢有所隱。鰥寡孤獨有死無以葬者，鄉部書言，霸具為區處，某所大木可以為棺，某亭豬子可以祭，吏往皆如言。其識事聰明如此，吏民不知所出，咸稱神明。姦人去入它郡，盜賊日少。

**许延寿封乐成侯：** [S029 樂平](../../拆分史书/史记/卷020.md#s029)。翁孙按汉纪表识为许延寿；补录爵名乐平，[《汉书·外戚恩泽侯表》](../../拆分史书/汉书/卷018.md#part-1-text)乐成，异号保留，不与霍山的乐平混为一支。出征西羌在前61年，后来大司马、光禄勋为后续，不在初封当天一并授完。 互校：[漢書/卷018](../../拆分史书/汉书/卷018.md#part-1-text) · [漢書/卷008](../../拆分史书/汉书/卷008.md#part-1-text)。

<a id="sj020-e209-n"></a>
**史曾封将陵侯：** [S030 將陵](../../拆分史书/史记/卷020.md#s030)。子回按汉纪表识为史曾；与史玄是补录所谓昆弟行的同辈关系，未据此添造同父同母家谱。妻宜君被控杀婢、媚道的案件没有确年，仍列跨期说明，不把初封本年写成案件发生年。 互校：[漢書/卷018](../../拆分史书/汉书/卷018.md#part-1-text) · [漢書/卷008](../../拆分史书/汉书/卷008.md#part-1-text)。

<a id="sj020-e210-n"></a>
**史玄封平台侯：** [S031 平臺](../../拆分史书/史记/卷020.md#s031)。子叔按汉纪表识为史玄。史氏与卫太子、鲁王的婚姻是此前家族背景，数次受赏也跨期；本年只落实封平台侯，不给两次婚姻硬定本年日期。史曾、史高分别是其他侯统，不因同属外家混合承爵。 互校：[漢書/卷018](../../拆分史书/汉书/卷018.md#part-1-text) · [漢書/卷008](../../拆分史书/汉书/卷008.md#part-1-text)。

<a id="sj020-e211-n"></a>
**丙吉封博阳侯：** [S043 博陽](../../拆分史书/史记/卷020.md#s043)。丙吉的博阳侯与汉初同号者分开。《宣帝纪》元康三年三月诏将吉、史曾、史玄、许舜、许延寿列在同一组旧恩封赏，[《汉书·外戚恩泽侯表》](../../拆分史书/汉书/卷018.md#part-1-text)丙吉行却记二月乙未，保留月份差。不得以共同诏旨把各表授爵日硬并成同一天。 互校：[漢書/卷018](../../拆分史书/汉书/卷018.md#part-1-text) · [漢書/卷008](../../拆分史书/汉书/卷008.md#part-1-text)。

<a id="sj020-e232-n"></a>
**黄霸在颍川推行教化、救济与基层约束：** [S044 建成](../../拆分史书/史记/卷020.md#s044)。通鉴元康三年收其治理叙述，这是一段时期的做法，不是每项措施都于本年首次下令。补录男女异路、耕者让畔为政治教化的赞语，不当作全国普查结果。 互校：[漢書/卷089](../../拆分史书/汉书/卷089.md#part-1-text) · [資治通鑑/卷025](../../拆分史书/资治通鉴/卷025.md#text)。

**未能唯一归年的后续与评论：**以下只是阅读入口，不表示均发生在本年。

**史曾妻宜君案件：** 补录记其妻宜君出于成王孙，杀婢、以残害产儿行媚道而被告、论弃市，史曾未失侯；事件没有确年。罪状按传世控词保存，不承认媚道有效，不把未记名的“成王”擅定为一个现代谱系，更不将案件硬放元康三年册封当天。 [考证记录](../../拆分史书/史记/卷020.md#kao-dd656ec25a-2f015d970)

<a id="event-1"></a>

1. **杨谭接续安平侯。** 安平侯由谭接续忠一代，开始新的侯年。 [[1]](#note-1)

<a id="sj020-e206"></a>
<a id="宣帝报答旧日照顾许史两家与丙吉受封"></a>

<a id="event-2"></a>

2. **宣帝回顾自己在民间和幼年受难时得到的帮助，给许舜、许延寿、史曾、史玄和丙吉封侯。** 许氏兄弟是许广汉的弟弟，曾帮助刘病已；史氏是其祖母一系亲族；丙吉则曾在狱中保护年幼的皇曾孙。爵赏所表彰的是不同人的旧恩，不是他们本年才一起救出皇帝。 [[2]](#note-2)

<a id="sj020-e207"></a>
<a id="许舜封博望侯"></a>


<a id="event-3"></a>

3. **许舜封博望侯。** 许舜字中翁，原任长乐卫尉，是许广汉之弟。本年因旧恩受封博望侯。 [[3]](#note-3)

<a id="sj020-e208"></a>
<a id="许延寿封乐成侯"></a>


<a id="event-4"></a>

4. **许延寿封乐成侯。** 许延寿字翁孙，是许广汉的少弟，在刘病已未即位时有旧恩。本年因旧恩受封乐成侯。 [[4]](#note-4)

<a id="sj020-e209"></a>
<a id="史曾封将陵侯"></a>


<a id="event-5"></a>

5. **史曾封将陵侯。** 史曾字子回，属于宣帝祖母史良娣兄长一支的亲属。本年因旧恩受封将陵侯。 [[5]](#note-5)

<a id="sj020-e210"></a>
<a id="史玄封平台侯"></a>


<a id="event-6"></a>

6. **史玄封平台侯。** 史玄字子叔，与史曾同辈，家族和太子、鲁王两支都有婚姻关系。本年因旧恩受封平台侯。 [[6]](#note-6)

<a id="sj020-e211"></a>
<a id="丙吉封博阳侯"></a>


<a id="event-7"></a>

7. **丙吉封博阳侯。** 丙吉来自鲁地，早以办案入仕，参与大将军幕府事务，后来任御史大夫。本年因旧恩受封博阳侯。 [[7]](#note-7)

<a id="sj020-e232"></a>
<a id="黄霸在颍川推行教化救济与基层约束"></a>

<a id="event-8"></a>

8. **黄霸在颍川推行教化、救济与基层约束。** 黄霸在颍川让地方官安排救济。 黄霸在颍川让地方官安排救济，劝农桑、节用，借父老和基层组织防范违法；他也尽量稳定任职的属吏，减少频繁更换带来的负担。朝廷因其治理声誉，一度召他代理京兆尹，后来又让他回颍川。 [[8]](#note-8)

> 又曰：「朕微眇時，御史大夫丙吉、中郎將史曾、史玄、長樂衛尉許舜、侍中光祿大夫許延壽皆與朕有舊 恩。及故掖庭令張賀輔導朕躬，修文學經術，恩惠卓異，厥功茂焉。詩不云乎？『無德不報。』封賀所子弟子侍中中郎將彭祖為陽都侯，追賜賀諡曰陽都哀侯。吉、 曾、玄、舜、延壽皆為列侯。故人下至郡邸獄復作嘗有阿保之功，皆受官祿田宅財物，各以恩深淺報之。」

**[《史记》卷020《建元以来侯者年表》｜博陽](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s043)**

**原文原格**

> 邴吉，家在魯。本以治獄為御史屬，給事大將軍幕府。常施舊恩宣帝，遷為御史大夫，封侯，二千戶。神爵二年，代魏相為丞相。立五歲，病死。子翁孟代立，為將軍，侍中。甘露元年，坐祠宗廟不乘大車而騎至廟門，有罪，奪爵，為關內侯。

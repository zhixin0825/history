# 公元前63年｜杨谭接续安平侯；宣帝报答旧日照顾，许、史两家与丙吉受封

**汉宣帝元康三年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e177"></a>
### 杨谭接续安平侯

安平侯由谭接续忠一代，开始新的侯年。 [原文与说明](#sj020-e177-n)

<a id="sj020-e206"></a>
### 宣帝报答旧日照顾，许、史两家与丙吉受封

宣帝回顾自己在民间和幼年受难时得到的帮助，给许舜、许延寿、史曾、史玄和丙吉封侯。许氏兄弟是许广汉的弟弟，曾帮助刘病已；史氏是其祖母一系亲族；丙吉则曾在狱中保护年幼的皇曾孙。爵赏所表彰的是不同人的旧恩，不是他们本年才一起救出皇帝。 [原文与说明](#sj020-e206-n)

<a id="sj020-e207"></a>
### 许舜封博望侯

许舜字中翁，原任长乐卫尉，是许广汉之弟。本年因旧恩受封博望侯。 [原文与说明](#sj020-e207-n)

<a id="sj020-e208"></a>
### 许延寿封乐成侯

许延寿字翁孙，是许广汉的少弟，在刘病已未即位时有旧恩。本年因旧恩受封乐成侯。 [原文与说明](#sj020-e208-n)

<a id="sj020-e209"></a>
### 史曾封将陵侯

史曾字子回，属于宣帝祖母史良娣兄长一支的亲属。本年因旧恩受封将陵侯。 [原文与说明](#sj020-e209-n)

<a id="sj020-e210"></a>
### 史玄封平台侯

史玄字子叔，与史曾同辈，家族和太子、鲁王两支都有婚姻关系。本年因旧恩受封平台侯。 [原文与说明](#sj020-e210-n)

<a id="sj020-e211"></a>
### 丙吉封博阳侯

丙吉来自鲁地，早以办案入仕，参与大将军幕府事务，后来任御史大夫。本年因旧恩受封博阳侯。 [原文与说明](#sj020-e211-n)

<a id="sj020-e232"></a>
### 黄霸在颍川推行教化、救济与基层约束

黄霸在颍川让地方官安排救济，劝农桑、节用，借父老和基层组织防范违法；他也尽量稳定任职的属吏，减少频繁更换带来的负担。朝廷因其治理声誉，一度召他代理京兆尹，后来又让他回颍川。 [原文与说明](#sj020-e232-n)

**未能唯一归年的后续与评论：**以下只是阅读入口，不表示均发生在本年。

**史曾妻宜君案件：** 补录记其妻宜君出于成王孙，杀婢、以残害产儿行媚道而被告、论弃市，史曾未失侯；事件没有确年。罪状按传世控词保存，不承认媚道有效，不把未记名的“成王”擅定为一个现代谱系，更不将案件硬放元康三年册封当天。 [考证记录](../../meta/考证/史记-卷020-纪年与异说.md#u08)

**史氏两支婚姻与累计赏赐：** 与卫太子、鲁王通婚是此前家族背景，数次得赏又跨期。只在初封处交代关系，不将婚姻和历年赏赐都定为前63年。 [考证记录](../../meta/考证/史记-卷020-纪年与异说.md#u09)

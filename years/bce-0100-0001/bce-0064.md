<a id="event-1"></a>

1. **王氏立后，王奉光封邛成侯。** 王氏被立为宣帝皇后，父亲王奉光受封邛成侯。王奉光来自房陵，与新皇后的亲缘，是这次授爵的直接理由。 宣帝选谨慎无子的王婕妤为后并令其抚养太子；议立其余婕妤见本传。 [[1]](#note-1)

<a id="sj096-event-2"></a>

2. **京兆尹赵广汉因案被处死。** 赵广汉任京兆尹时，与丞相魏相发生冲突，并派吏卒进入魏宅查问侍婢案。丞相司直奏劾后，赵广汉获罪被腰斩。 赵广汉借追查魏相傅婢之死对抗有司查其枉杀荣畜一案。处刑年本纪与官表、《通鉴》相差一年；傅婢去世是两说均早数年的前因。 [[2]](#note-2)

<a id="hs-event-3"></a>

3. **赦天下，与士大夫重新振作。** 正月引《尚书》论刑罚，指出官吏未能修身奉法、称朝廷之意，宣布大赦，勉励士大夫振作改过。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **因凤凰甘露而赐爵。** 三月，朝廷以凤凰、甘露的报告为由，赐天下官吏爵两级、百姓一级，并赐牛酒及帛给相应人群。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **整顿狱政、禁擅役并救疫。** 五月诏强调狱政关系性命，指斥官吏曲解法条、增饰案情、量刑失平，命二千石察核属官，要求平允执法。诏又斥擅兴徭役、奢办馆驿接待以求名，并免遭疫病最重郡国当年租赋。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **改名刘询并赦先前犯讳。** 宣帝指出百姓上书常触及原名禁忌，遂改名为询，并赦令前已触讳者。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **刘汝阳嗣广川王。** 刘汝阳嗣广川王。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **利昌康侯嘉一支爵位承袭。** 元康二年，顷侯万世继承侯爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **柴原侯代一支爵位承袭。** 元康二年，敬侯贤继承侯爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **五月丙戌分封王子侯。** 《王子侯表》列五月丙戌受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 萧望之由少府转左冯翊，宣帝遣金安上说明意在试其治民。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **宣帝命张敞察废昌邑王。** 宣帝遣使持玺书，嘱山阳太守张敞防备盗贼、稽察来客并保密。张敞回奏故王居处与举动，帝据奏认为刘贺不足忌。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **匈奴争车师，魏相谏止向匈奴右地出兵。** 匈奴再争车师屯田，宣帝与赵充国等拟出兵攻匈奴右地。魏相以边民困乏、内政急务劝阻，宣帝按其议停下攻势。《通鉴》续载常惠迎郑吉回渠犁、重新处置车师。 [[13]](#hs-note-13)

> 廣漢疑其邑子榮畜教令，後以它法論殺畜。人上書言之，事下丞相御史，案驗甚急。廣漢使所親信長安人為丞相府門卒，令微司丞相門內不法事。地節三年七月中，丞相傅婢有過，自絞死。廣漢聞之，疑丞相夫人妒殺之府舍。而丞相奉齋酎入廟祠，廣漢得此，使中郎趙奉壽風曉丞相，欲以脅之，毋令窮正己事。丞相不聽，按驗愈急。廣漢欲告之，先問太史知星氣者，言今年當有戮死大臣，廣漢即上書告丞相罪。制曰：「下京兆尹治。」廣漢知事迫切，遂自將吏卒突入丞相府，召其夫人跪庭下受辭，收奴婢十餘人去，責以殺婢事。丞相魏相上書自陳：「妻實不殺婢。廣漢數犯罪法不伏辜，以詐巧迫脅臣相，幸臣相寬不奏。願下明使者治廣漢所驗臣相家事。」事下廷尉治罪，實丞相自以過譴笞傅婢，出至外弟乃死，不如廣漢言。司直蕭望之劾奏：「廣漢摧辱大臣，欲以劫持奉公，逆節傷化，不道。」宣帝惡之，下廣漢廷尉獄，又坐賊殺不辜，鞠獄故不以實，擅斥除騎士乏軍興數罪。天子可其奏。吏民守闕號泣者數萬人，或言「臣生無益縣官，願代趙京兆死，使得牧養小民。」廣漢竟坐要斬。

### 13. 匈奴争车师，魏相谏止向匈奴右地出兵

[返回正文第13条](#hs-event-13)

<a id="hs074-l8871-e13"></a>

**[《汉书·魏相丙吉传》P004](../../sources/摘录/汉书-卷074-魏相丙吉传.md#p004)** · [仓内TXT L8871](../../sources/本地分卷/汉书/汉书-卷074.md#L8871)

> 元康中，匈奴遣兵擊漢屯田車師者，不能下。上與後將軍趙充國等議，欲因匈奴衰弱，出兵擊其右地，使不敢復擾西域。相上書諫曰：「臣聞之，救亂誅暴，謂之義兵，兵義者王；敵加於己，不得已而起者，謂之應兵，兵應者勝；爭恨小故，不忍憤怒者，謂之忿兵，兵忿者敗；利人土地貨寶者，謂之貪兵，兵貪者破；恃國家之大，矜民人之眾，欲見威於敵者，謂之驕兵，兵驕者滅：此五者，非但人事，乃天道也。間者匈奴嘗有善意，所得漢民輒奉歸之，未有犯於邊境，雖爭屯田車師，不足致意中。今聞諸將軍欲興兵入其地，臣愚不知此兵何名者也。今邊郡困乏，父子共犬羊之裘，食草萊之實，常恐不能自存，難於動兵。『軍旅之後，必有凶年，』言民以其愁苦之氣，傷陰陽之和也。出兵雖勝，猶有後憂，恐災害之變因此以生。今郡國守相多不實選，風俗尤薄，水旱不時。案今年計，子弟殺父兄、妻殺夫者，凡二百二十二人，臣愚以為此非小變也。今左右不憂此，乃欲發兵報纖介之忿於遠夷，殆孔子所謂『吾恐季孫之憂不在顓臾而在蕭牆之內』也。願陛下與平昌侯、樂昌侯、平恩侯及有識者詳議乃可。」上從其言而止。

**互校说明** 原传“元康中”，《通鉴》卷025 L417–447列元康二年；前67年郑吉、司马憙攻车师为前次，前60年郑吉迎日逐王降以后兼护南北道。

**赵广汉卒年**　《宣帝纪》系元康二年冬，年页保留原同号条。《资治通鉴》卷025《考异》结合《百官公卿表》在任年数和京兆尹继任官历，改系元康元年。见[本纪](../../sources/本地分卷/汉书/汉书-卷008.md#L705)与[《通鉴》考异](../../sources/本地分卷/资治通鉴/资治通鉴-卷025.md#L352)。

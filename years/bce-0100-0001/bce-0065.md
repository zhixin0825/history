# 公元前65年｜商利侯因代郡任内案件失爵；傅介子去世，继承人未能接爵；张延寿任太仆

**汉宣帝元康元年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e165"></a>
### 商利侯因代郡任内案件失爵

王山寿担任代郡太守后，被告发办案不实，受审。他在赦令下获免死，降为庶人，失去商利侯爵。 [原文与说明](#sj020-e165-n)

<a id="sj020-e170"></a>
### 傅介子去世，继承人未能接爵

傅介子去世后，继承人因罪不能承袭义阳侯，侯国中断。 [原文与说明](#sj020-e170-n)

<a id="sj020-zhang-taipu"></a>
### 张延寿任太仆

北海太守张延寿转任太仆。他的父亲张安世仍在世，不能把儿子的这次任官写成父亲死后才随袭侯新授。 [原文与说明](#sj020-zhang-taipu-n)

<a id="sj020-e165-n"></a>
**商利侯因代郡任内案件失爵：** [S011 商利](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s011)。汉表明元康元年，具体罪称为故意劾十人不直；补录另写他自请治民、下狱当死、遇赦，按相连过程讲述。出任代守未给确年，不假设前80年受封当日即任。 互校：[漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-4b1247aa1219fa)。

<a id="sj020-e170-n"></a>
**傅介子去世，继承人未能接爵：** [S010 義陽](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s010)。汉功臣表明元康元年薨、嗣子有罪不得代；补录说子厉“代立”后争财被告。正文采用没有成功延续侯爵的共同结局，是否已经短暂承袭留异说，不编成两个先后罪案。 互校：[漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-8f2f6eb179c822)。

<a id="sj020-zhang-taipu-n"></a>
**张延寿任太仆：** [S009原文](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s009)。百官表元康元年明记张延寿为太仆；父张安世卒于前62年。补录将代立、为太仆、侍中连叙，是跨年履历，不能据句序把太仆任命移到前62年。侍中任期另存，不以本条顺带定年。 互校：[《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0065)。

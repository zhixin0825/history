<a id="event-1"></a>

1. **商利侯因代郡任内案件失爵。** 王山寿担任代郡太守后，被告发办案不实，受审。他在赦令下获免死，降为庶人，失去商利侯爵。 [[1]](#note-1)

<a id="sj020-e170"></a>
<a id="傅介子去世继承人未能接爵"></a>


<a id="event-2"></a>

2. **傅介子去世，继承人未能接爵。** 傅介子去世后，继承人因罪不能承袭义阳侯，侯国中断。 [[2]](#note-2)

<a id="sj020-zhang-taipu"></a>
<a id="张延寿任太仆"></a>


<a id="event-3"></a>

3. **张延寿任太仆。** 北海太守张延寿转任太仆。他的父亲张安世仍在世，不能把儿子的这次任官写成父亲死后才随袭侯新授。 [[3]](#note-3)

<a id="hs-event-4"></a>

4. **选杜陵并迁官户、富户。** 元康元年春，朝廷把杜县东原选为宣帝初陵，改县名为杜陵，迁丞相、将军、列侯、二千石官员及资产百万者居住。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **因祥瑞赦徒、赏赐和免收贷物。** 三月诏列举泰山、陈留的凤凰和未央宫的甘露，援引《尚书》，以自省措辞回应。朝廷赦囚徒，按身份赐官吏、百姓爵，赐女子牛酒，另赐鳏寡孤独、三老及孝悌力田者帛，并免收已赈贷的物资。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **设皇考庙与奉明县。** 五月建立祭祀宣帝生父的皇考庙，增置奉明园的守奉户，设为奉明县。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **优免开国功臣后人以守祭。** 朝廷免除周勃等一百三十六名汉高帝功臣家子孙的有关徭役，使其世代奉祀。如无嫡系承继，则递及下一顺位。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **举荐通晓六艺先王之术者。** 八月诏自责不明六艺、风雨失时，要求广泛荐举操守端正、通晓经典和先王治术而能阐明其意的人，按所辖官民及中二千石官各定名额。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **设建章卫尉。** 冬，朝廷增置建章卫尉，负责建章宫卫戍。 [[9]](#hs-note-9)

22. **周子南君姬延年｜改封。** 表载周子南君姬延年一支本年爵号或封邑改易。表中所载事项为三月丙戌，君延年因当弟接续封爵。 [[22]](#hs-note-23)

<a id="hs-event-24"></a>

23. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 东海太守尹翁归以考绩上等入守右扶风。 平原太守萧望之言谏官悉外补使朝廷失去规谏，宣帝召守少府。 [[23]](#hs-note-24)

<a id="hs-event-25"></a>

24. **冯奉世发西域诸国兵平莎车。** 莎车王弟呼屠征杀汉所立王万年及汉使奚充国，邀盟而断南道。出使的冯奉世发南、北道诸国兵攻拔莎车，呼屠征自杀。事平后赴大宛，先发兵是否应封引起朝议。 [[24]](#hs-note-25)

<a id="hs-event-26"></a>

25. **龟兹王绛宾夫妇入朝。** 龟兹王绛宾与夫人（解忧公主之女）进京朝贺，两人获赐印绶，夫人获公主号。 [[25]](#hs-note-26)

### 24. 冯奉世发西域诸国兵平莎车

[返回正文第24条](#hs-event-25)

<a id="hs096-l10029-e25"></a>

**[《汉书·西域传》P081](../../sources/摘录/汉书-卷096-西域传.md#p081)** · [仓内TXT L10029](../../sources/本地分卷/汉书/汉书-卷096.md#L10029)

> 會衛候馮奉世使送大宛客，即以便宜發諸國兵擊殺之，更立它昆弟子為莎車王。還，拜奉世為光祿大夫。是歲，元康元年也。

**互校说明** 与《冯奉世传》互见；莎车前王卒、万年始立本段没有独立纪年。

<a id="hs079-l9085-e25"></a>

**[《汉书·冯奉世传》P003](../../sources/摘录/汉书-卷079-冯奉世传.md#p003)** · [仓内TXT L9085](../../sources/本地分卷/汉书/汉书-卷079.md#L9085)

> 至伊脩城，都尉宋將言莎車與旁國共攻殺漢所置莎車王萬年，並殺漢使者奚充國。時，匈奴又發兵攻車師城，不能下而去。莎車遣使揚言北道諸國已屬匈奴矣，於是攻劫南道，與歃盟畔漢，從鄯善以西皆絕不通。都護鄭吉、校尉司馬意皆在北道諸國間。奉世與其副嚴昌計，以為不亟擊之則莎車日強，其勢難制，必危西域。遂以節諭告諸國王，因發其兵，南北道合萬五千人進擊莎車，攻拔其城。莎車王自殺，傳其首詣長安。諸國悉平，威振西域。奉世乃罷兵以聞。

**互校说明** 《西域传·莎车》明记元康元年，《通鉴》同；《冯奉世传》追称郑吉为都护，不能据此把战事延到神爵二年。

<a id="hs079-l9085-e25-2"></a>

**[《汉书·冯奉世传》P003](../../sources/摘录/汉书-卷079-冯奉世传.md#p003)** · [仓内TXT L9085](../../sources/本地分卷/汉书/汉书-卷079.md#L9085)

> 奉世遂西至大苑。大苑聞其斬莎車王，敬之異於它使。得其名馬象龍而還。上甚說，下議封奉世。丞相、將軍皆曰：「《春秋》之義，大夫出疆，有可以安國家，則顓之可也。奉世功傚尤著，宜加爵士之賞。」少府蕭望之獨以奉世奉使有指，而擅矯制違命，發諸國兵，雖有功效，不可以為後法。即封奉世，開後奉使者利，以奉世為比，爭逐發兵，要功萬里之外，為國家生事於夷狄。漸不可長，奉世不宜受封。上善望之議，以奉世為光祿大夫、水衡都尉。

**互校说明** 《通鉴》随本年叙余事，卷096亦称元康元年还拜光禄大夫。水衡都尉按官表另见元康四年。

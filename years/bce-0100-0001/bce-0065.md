# 公元前65年｜商利侯因代郡任内案件失爵；傅介子去世，继承人未能接爵；张延寿任太仆

[← 公元前66年](bce-0066.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前64年 →](bce-0064.md)

**汉宣帝元康元年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **商利侯因代郡任内案件失爵。** 王山寿担任代郡太守后，被告发办案不实，受审。他在赦令下获免死，降为庶人，失去商利侯爵。 [[1]](#note-1)

<a id="sj020-e170"></a>
<a id="傅介子去世继承人未能接爵"></a>


<a id="event-2"></a>

2. **傅介子去世，继承人未能接爵。** 傅介子去世后，继承人因罪不能承袭义阳侯，侯国中断。 [[2]](#note-2)

<a id="sj020-zhang-taipu"></a>
<a id="张延寿任太仆"></a>


<a id="event-3"></a>

3. **张延寿任太仆。** 北海太守张延寿转任太仆。他的父亲张安世仍在世，不能把儿子的这次任官写成父亲死后才随袭侯新授。 [[3]](#note-3)

<a id="hs-event-4"></a>

4. **选杜陵并迁官户、富户。** 元康元年春，朝廷把杜县东原选为宣帝初陵，改县名为杜陵，迁丞相、将军、列侯、二千石官员及资产百万者居住。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **因祥瑞赦徒、赏赐和免收贷物。** 三月诏列举泰山、陈留的凤凰和未央宫的甘露，援引《尚书》，以自省措辞回应。朝廷赦囚徒，按身份赐官吏、百姓爵，赐女子牛酒，另赐鳏寡孤独、三老及孝悌力田者帛，并免收已赈贷的物资。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **设皇考庙与奉明县。** 五月建立祭祀宣帝生父的皇考庙，增置奉明园的守奉户，设为奉明县。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **优免开国功臣后人以守祭。** 朝廷免除周勃等一百三十六名汉高帝功臣家子孙的有关徭役，使其世代奉祀。如无嫡系承继，则递及下一顺位。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **举荐通晓六艺先王之术者。** 八月诏自责不明六艺、风雨失时，要求广泛荐举操守端正、通晓经典和先王治术而能阐明其意的人，按所辖官民及中二千石官各定名额。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **设建章卫尉。** 冬，朝廷增置建章卫尉，负责建章宫卫戍。 [[9]](#hs-note-9)

**商利侯因代郡任内案件失爵：** [S011 商利](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s011)。汉表明元康元年，具体罪称为故意劾十人不直；补录另写他自请治民、下狱当死、遇赦，按相连过程讲述。出任代守未给确年，不假设前80年受封当日即任。 互校：[漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-4b1247aa1219fa)。

**傅介子去世，继承人未能接爵：** [S010 義陽](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s010)。汉功臣表明元康元年薨、嗣子有罪不得代；补录说子厉“代立”后争财被告。正文采用没有成功延续侯爵的共同结局，是否已经短暂承袭留异说，不编成两个先后罪案。 互校：[漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-8f2f6eb179c822)。

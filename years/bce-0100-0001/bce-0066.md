本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="军政受封与侯国的接续"></a>

<a id="sj020-e222"></a>
<a id="萧建世续封酂侯"></a>


<a id="event-1"></a>

1. **萧建世续封酂侯。** 朝廷追念萧何开国时的功劳，重新寻找其后人，封萧建世为酂侯，延续功臣家族的祭祀。 [[1]](#note-1)

<a id="sj020-e223"></a>
<a id="宣帝找到母家两个舅父封侯"></a>


<a id="event-2"></a>

2. **宣帝找到母家，两个舅父封侯。** 朝廷找到宣帝母亲王翁须一家的亲属。王无故与弟王武分别封平昌侯、乐昌侯，宣帝的外祖母也得到尊号与奉养。母亲早在太子案中遇害，母家多年失去音讯，这次确认亲属是另一阶段。 [[2]](#note-2)

<a id="sj020-e196"></a>
<a id="霍氏案发博陆乐平等侯国被撤销"></a>

<a id="event-3"></a>

3. **霍氏案发，博陆、乐平等侯国被撤销。** 霍光死后，霍禹、霍山、霍云等不满权势被收回，案情发展为被指谋反。 朝廷大规模搜捕处置，霍禹遭处刑，霍山、霍云和与霍氏联姻的范明友等自杀，相关侯爵终止。家族与姻亲遭到广泛牵连，不能把每名被杀者都当成亲自策划叛乱的证据。 [[3]](#note-3)

<a id="sj020-e197"></a>
<a id="张章的告发沿着宫中关系传入朝廷"></a>


<a id="event-4"></a>

4. **张章的告发沿着宫中关系传入朝廷。** 失去官职的长安亭长张章到宫门上书，寄宿霍家，听到有关谋反的谈话。线索传给熟识的期门董忠，再经杨恽、金安上等人传报。朝廷据以追查霍氏，随后给告发者与有功近臣封侯。 [[4]](#note-4)

<a id="sj020-e198"></a>
<a id="史高封乐陵侯"></a>


<a id="event-5"></a>

5. **史高封乐陵侯。** 史高是宣帝外家史氏亲属，字子长，担任近侍，以参与揭发霍氏案获赏。朝廷封他为乐陵侯。 [[5]](#note-5)

<a id="sj020-e199"></a>
<a id="张章封博成侯"></a>


<a id="event-6"></a>

6. **张章封博成侯。** 张章的父辈来自颍川，他曾任长安亭长，这次因首先提供霍氏线索受赏。朝廷封他为博成侯。 [[6]](#note-6)

<a id="sj020-e200"></a>
<a id="金安上封都成侯"></a>


<a id="event-7"></a>

7. **金安上封都成侯。** 金安上承接并转报霍氏案的消息，又协助控制宫禁，因而获赏。他属于金日磾的亲族，不能写成日磾亲生之子。朝廷封他为都成侯。 [[7]](#note-7)

<a id="sj020-e201"></a>
<a id="杨恽封平通侯"></a>


<a id="event-8"></a>

8. **杨恽封平通侯。** 杨恽是故丞相杨敞的少子，从郎官进入朝廷，因参与传报霍氏案获赏；他与继承安平侯的兄长一支有不同爵号。朝廷封他为平通侯。 [[8]](#note-8)

<a id="sj020-e202"></a>
<a id="董忠封高昌侯"></a>


<a id="event-9"></a>

9. **董忠封高昌侯。** 董忠出自颍川阳翟家庭，随父至长安，善骑射、短兵，任期门卫士；这次因传报张章所说的消息获赏。朝廷封他为高昌侯。 [[9]](#note-9)

<a id="sj020-e203"></a>
<a id="杜延年被免职离开中央"></a>


<a id="event-10"></a>

10. **杜延年被免职，离开中央。** 杜延年因与霍光旧日关系密切，被免去太仆职务。他并未因此失去建平侯爵，后来又出任地方太守。 [[10]](#note-10)

<a id="sj020-ren-taichang"></a>
<a id="任宫任太常"></a>


<a id="event-11"></a>

11. **任宫任太常。** 弋阳侯任宫出任太常。这是前80年捕获上官桀、受封以后的一次任官，封侯与就任相隔多年。 [[11]](#note-11)

<a id="hs-event-12"></a>

12. **亲属丧期免徭役。** 诏称祖父母或父母去世时，官府不得征发丧家服役，以便收殓安葬、履行子孙的责任。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **亲属容隐制度。** 五月诏规定，子藏匿父母、妻藏匿丈夫、孙藏匿祖父母，都免于问罪。反向藏匿，即父母藏子、丈夫藏妻、祖父母藏孙，若所涉为死罪，则必须呈报廷尉请示。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **刘文立广川王。** 立广川惠王的孙子刘文为广川王。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **察民疾苦与降低盐价。** 九月诏说朝廷已遣使巡视各地，询问民众疾苦。宣帝责备部分官吏营私扰民，指出受水灾的地方已得赈贷，百姓仍苦于盐价昂贵，命降低天下盐价。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **狱中死亡报告与考课。** 诏书批评有囚犯因拷打、饥寒死在狱中，命各郡国每年上报有关囚犯的案由、所属县、爵、里等，由丞相和御史考核地方办案优劣。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **清河王刘年废迁。** 十二月，清河王刘年获罪，被废并迁往房陵。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **刘高绍封赵王。** 刘高绍封赵王。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **公丘夷侯顺一支爵位承袭。** 地节四年，炀侯延寿继承侯爵，九年去世。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **牟平共侯渫一支爵位承袭。** 地节四年，康侯建继承侯爵，一年去世。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **襄堤侯圣一支失爵。** 地节四年，因……获罪奉宗庙献纳用金斤八两少四两，免去侯爵。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **栗节侯乐一支爵位承袭。** 地节四年，炀侯忠继承侯爵。 [[22]](#hs-note-22)

<a id="hs-event-23"></a>

23. **新乡侯豹一支爵位承袭。** 地节四年，厘侯步可继承侯爵。 [[23]](#hs-note-23)

<a id="hs-event-24"></a>

24. **二月甲寅分封王子侯。** 《王子侯表》列二月甲寅受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[24]](#hs-note-24)

<a id="hs-event-25"></a>

25. **昆侯渠复絫｜去世。** 表载昆侯渠复絫一支本年记载去世。表中所载事项为去世，无继承人。 [[25]](#hs-note-25)

<a id="hs-event-26"></a>

26. **阳城缪侯刘德｜受封。** 《汉书》侯籍列阳城缪侯刘德本年受封，所引月份、干支依表保留。 [[26]](#hs-note-26)

<a id="hs-event-27"></a>

27. **山阳济阴大雹伤人。** 《汉书》在本年记载山阳济阴大雹伤人。 [[27]](#hs-note-27)

#### 卷022｜将相表互见与异说

[本年原行R141](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r141) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0066)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

本行相位“二”属于魏相；七月壬寅霍禹腰斩接本页霍氏案。霍禹不是丞相，夹记相栏不能改写他的官职。汉019将其被杀夹在地节三年，汉008地节四年明确霍氏案，沿本页前66年 · [宣帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-7ccdcf999a4932)。

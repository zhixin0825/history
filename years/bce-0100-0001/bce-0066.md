# 公元前66年｜萧建世续封酂侯；宣帝找到母家，两个舅父封侯；任宫任太常

**汉宣帝地节四年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020-e222"></a>
<a id="萧建世续封酂侯"></a>


<a id="event-1"></a>

1. **萧建世续封酂侯。** 朝廷追念萧何开国时的功劳，重新寻找其后人，封萧建世为酂侯，延续功臣家族的祭祀。 [[1]](#note-1)

<a id="sj020-e223"></a>
<a id="宣帝找到母家两个舅父封侯"></a>


<a id="event-2"></a>

2. **宣帝找到母家，两个舅父封侯。** 朝廷找到宣帝母亲王翁须一家的亲属。王无故与弟王武分别封平昌侯、乐昌侯，宣帝的外祖母也得到尊号与奉养。母亲早在太子案中遇害，母家多年失去音讯，这次确认亲属是另一阶段。 [[2]](#note-2)

<a id="sj020-e196"></a>
<a id="霍氏案发博陆乐平等侯国被撤销"></a>

<a id="event-3"></a>

3. **霍氏案发，博陆、乐平等侯国被撤销。** 霍光死后，霍禹、霍山、霍云等不满权势被收回，案情发展为被指谋反。 朝廷大规模搜捕处置，霍禹遭处刑，霍山、霍云和与霍氏联姻的范明友等自杀，相关侯爵终止。家族与姻亲遭到广泛牵连，不能把每名被杀者都当成亲自策划叛乱的证据。 [[3]](#note-3)

<a id="sj020-e197"></a>
<a id="张章的告发沿着宫中关系传入朝廷"></a>


<a id="event-4"></a>

4. **张章的告发沿着宫中关系传入朝廷。** 失去官职的长安亭长张章到宫门上书，寄宿霍家，听到有关谋反的谈话。线索传给熟识的期门董忠，再经杨恽、金安上等人传报。朝廷据以追查霍氏，随后给告发者与有功近臣封侯。 [[4]](#note-4)

<a id="sj020-e198"></a>
<a id="史高封乐陵侯"></a>


<a id="event-5"></a>

5. **史高封乐陵侯。** 史高是宣帝外家史氏亲属，字子长，担任近侍，以参与揭发霍氏案获赏。朝廷封他为乐陵侯。 [[5]](#note-5)

<a id="sj020-e199"></a>
<a id="张章封博成侯"></a>


<a id="event-6"></a>

6. **张章封博成侯。** 张章的父辈来自颍川，他曾任长安亭长，这次因首先提供霍氏线索受赏。朝廷封他为博成侯。 [[6]](#note-6)

<a id="sj020-e200"></a>
<a id="金安上封都成侯"></a>


<a id="event-7"></a>

7. **金安上封都成侯。** 金安上承接并转报霍氏案的消息，又协助控制宫禁，因而获赏。他属于金日磾的亲族，不能写成日磾亲生之子。朝廷封他为都成侯。 [[7]](#note-7)

<a id="sj020-e201"></a>
<a id="杨恽封平通侯"></a>


<a id="event-8"></a>

8. **杨恽封平通侯。** 杨恽是故丞相杨敞的少子，从郎官进入朝廷，因参与传报霍氏案获赏；他与继承安平侯的兄长一支有不同爵号。朝廷封他为平通侯。 [[8]](#note-8)

<a id="sj020-e202"></a>
<a id="董忠封高昌侯"></a>


<a id="event-9"></a>

9. **董忠封高昌侯。** 董忠出自颍川阳翟家庭，随父至长安，善骑射、短兵，任期门卫士；这次因传报张章所说的消息获赏。朝廷封他为高昌侯。 [[9]](#note-9)

<a id="sj020-e203"></a>
<a id="杜延年被免职离开中央"></a>


<a id="event-10"></a>

10. **杜延年被免职，离开中央。** 杜延年因与霍光旧日关系密切，被免去太仆职务。他并未因此失去建平侯爵，后来又出任地方太守。 [[10]](#note-10)

<a id="sj020-ren-taichang"></a>
<a id="任宫任太常"></a>


<a id="event-11"></a>

11. **任宫任太常。** 弋阳侯任宫出任太常。这是前80年捕获上官桀、受封以后的一次任官，封侯与就任相隔多年。 [[11]](#note-11)

**未能唯一归年的后续与评论：**以下只是阅读入口，不表示均发生在本年。

**杜延年西河之任的“元年”：** 补录只称“元年，出为西河太守”，没有清楚年号；汉传为前66年免太仆后，先北地、居岁余再西河。保留先后，至前55年入御史之前，不补一个确定的西河起任年。 [考证记录](../../meta/考证/史记-卷020-纪年与异说.md#u02)

**史高的德性赞语：** 重厚忠信是补作者对近臣的评价，不能当作本年新增可计数的政治事件；实际封侯归前66年。 [考证记录](../../meta/考证/史记-卷020-纪年与异说.md#u10)

**金安上的家风评价：** 谨善、退让、欲传功德于后人为补作者评论，附在封侯与亲缘辨析，不据此编造后代言行。 [考证记录](../../meta/考证/史记-卷020-纪年与异说.md#u11)

**董忠的后任与庙礼削户：** 梟骑都尉、侍中及乘小车祠庙被夺百户均未记确年；汉表记再犯法共削户，与补文口径不同。前53年魏弘、丙显骑至司马门有明年，但不足证明董忠也同年同案，故只作比较，不强编年。 [考证记录](../../meta/考证/史记-卷020-纪年与异说.md#u12)

# 公元前66年｜萧建世续封酂侯；宣帝找到母家，两个舅父封侯；任宫任太常

[← 公元前67年](bce-0067.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前65年 →](bce-0065.md)

**汉宣帝地节四年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e222"></a>
### 萧建世续封酂侯

朝廷追念萧何开国时的功劳，重新寻找其后人，封萧建世为酂侯，延续功臣家族的祭祀。 [原文与说明](#sj020-e222-n)

<a id="sj020-e223"></a>
### 宣帝找到母家，两个舅父封侯

朝廷找到宣帝母亲王翁须一家的亲属。王无故与弟王武分别封平昌侯、乐昌侯，宣帝的外祖母也得到尊号与奉养。母亲早在太子案中遇害，母家多年失去音讯，这次确认亲属是另一阶段。 [原文与说明](#sj020-e223-n)

<a id="sj020-e196"></a>
### 霍氏案发，博陆、乐平等侯国被撤销

霍光死后，霍禹、霍山、霍云等不满权势被收回，案情发展为被指谋反。朝廷大规模搜捕处置，霍禹遭处刑，霍山、霍云和与霍氏联姻的范明友等自杀，相关侯爵终止。家族与姻亲遭到广泛牵连，不能把每名被杀者都当成亲自策划叛乱的证据。 [原文与说明](#sj020-e196-n)

<a id="sj020-e197"></a>
### 张章的告发沿着宫中关系传入朝廷

失去官职的长安亭长张章到宫门上书，寄宿霍家，听到有关谋反的谈话。线索传给熟识的期门董忠，再经杨恽、金安上等人传报。朝廷据以追查霍氏，随后给告发者与有功近臣封侯。 [原文与说明](#sj020-e197-n)

<a id="sj020-e198"></a>
### 史高封乐陵侯

史高是宣帝外家史氏亲属，字子长，担任近侍，以参与揭发霍氏案获赏。朝廷封他为乐陵侯。 [原文与说明](#sj020-e198-n)

<a id="sj020-e199"></a>
### 张章封博成侯

张章的父辈来自颍川，他曾任长安亭长，这次因首先提供霍氏线索受赏。朝廷封他为博成侯。 [原文与说明](#sj020-e199-n)

<a id="sj020-e200"></a>
### 金安上封都成侯

金安上承接并转报霍氏案的消息，又协助控制宫禁，因而获赏。他属于金日磾的亲族，不能写成日磾亲生之子。朝廷封他为都成侯。 [原文与说明](#sj020-e200-n)

<a id="sj020-e201"></a>
### 杨恽封平通侯

杨恽是故丞相杨敞的少子，从郎官进入朝廷，因参与传报霍氏案获赏；他与继承安平侯的兄长一支有不同爵号。朝廷封他为平通侯。 [原文与说明](#sj020-e201-n)

<a id="sj020-e202"></a>
### 董忠封高昌侯

董忠出自颍川阳翟家庭，随父至长安，善骑射、短兵，任期门卫士；这次因传报张章所说的消息获赏。朝廷封他为高昌侯。 [原文与说明](#sj020-e202-n)

<a id="sj020-e203"></a>
### 杜延年被免职，离开中央

杜延年因与霍光旧日关系密切，被免去太仆职务。他并未因此失去建平侯爵，后来又出任地方太守。 [原文与说明](#sj020-e203-n)

<a id="sj020-ren-taichang"></a>
### 任宫任太常

弋阳侯任宫出任太常。这是前80年捕获上官桀、受封以后的一次任官，封侯与就任相隔多年。 [原文与说明](#sj020-ren-taichang-n)

### 卷022｜将相表互见与异说

**未能唯一归年的后续与评论：**以下只是阅读入口，不表示均发生在本年。

**杜延年西河之任的“元年”：** 补录只称“元年，出为西河太守”，没有清楚年号；汉传为前66年免太仆后，先北地、居岁余再西河。保留先后，至前55年入御史之前，不补一个确定的西河起任年。 [考证记录](../../meta/考证/史记-卷020-纪年与异说.md#u02)

**史高的德性赞语：** 重厚忠信是补作者对近臣的评价，不能当作本年新增可计数的政治事件；实际封侯归前66年。 [考证记录](../../meta/考证/史记-卷020-纪年与异说.md#u10)

**金安上的家风评价：** 谨善、退让、欲传功德于后人为补作者评论，附在封侯与亲缘辨析，不据此编造后代言行。 [考证记录](../../meta/考证/史记-卷020-纪年与异说.md#u11)

**董忠的后任与庙礼削户：** 梟骑都尉、侍中及乘小车祠庙被夺百户均未记确年；汉表记再犯法共削户，与补文口径不同。前53年魏弘、丙显骑至司马门有明年，但不足证明董忠也同年同案，故只作比较，不强编年。 [考证记录](../../meta/考证/史记-卷020-纪年与异说.md#u12)

<a id="sj020-ren-taichang-n"></a>
**任宫任太常：** [S013原文](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s013)。百官表地节四年明记任宫为太常，故撤回这项任命无确年的旧说明。原表随后说四年坐人盗茂陵园中物免，但未在这里独立核定免职月日；补录的行卫尉事、寿终也仍不强归本年。 互校：[《汉书·百官公卿表》](https://zh.wikisource.org/wiki/漢書/卷019)。

# 公元前67年｜韦贤退相，魏相接任；霍云受封，继续霍去病的宗祀

[← 公元前68年](bce-0068.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前66年 →](bce-0066.md)

**汉宣帝地节三年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="韦贤退相魏相接任"></a>


<a id="event-1"></a>

1. **韦贤退相，魏相接任。** 韦贤年老多病，免相回家。御史大夫魏相接任丞相，封高平侯。魏相早年学易，从地方吏、县令做到河南太守，曾因办案问题下狱，又在赦免后重新入仕；现在他要主持全国政务。 [[1]](#note-1)

<a id="sj020-e193"></a>
<a id="霍云受封继续霍去病的宗祀"></a>


<a id="event-2"></a>

2. **霍云因霍光之功获封冠阳侯。** 霍云是霍光的兄孙，宣帝以褒及霍光后辈为封赏理由。前一年奉祀霍去病而得封的乐平侯为[霍山](bce-0068.md#note-1)。 宣帝诏书以褒及霍光的晚辈为封霍云的理由，同年封号各本另有冠阳、冠军之写。 [[2]](#note-2)

<a id="sj020-e194"></a>
<a id="许广汉封平恩侯"></a>


<a id="event-3"></a>

3. **许广汉封平恩侯。** 皇太子刘奭确立以后，外祖父许广汉受封平恩侯。许广汉早年在宫中因案受刑，只有一个女儿许平君，后来把她嫁给尚未即位的刘病已，并在生活上照顾他。 [[3]](#note-3)

<a id="sj020-e225"></a>
<a id="郑吉在渠犁屯田又攻车师"></a>


<a id="event-4"></a>

4. **郑吉在渠犁屯田，又攻车师。** 郑吉与司马憙带领获免刑的士卒在渠犁种田积粮，又联合西域诸国军队攻车师。匈奴随后争夺车师，汉军的屯田、救援与各国转向成为长期反复的过程。 [[4]](#note-4)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-5"></a>

5. **刘奭被立为皇太子。** 丙吉由太子太傅升御史大夫；霍禹也取得大司马名号，朝廷继续重排霍光身后的人事。 丙吉初为太傅、疏广为少傅；丙吉改任御史大夫后，疏广继任太傅。 皇太子外祖父许广汉想以其弟许舜监护太子家，宣帝采纳疏广依贤才选师、勿专外戚的意见。 [[5]](#note-5)

<a id="hs-event-6"></a>

6. **王成招抚流民获赏。** 三月，宣帝以胶东相王成招徕流民有功，升他的俸秩为中二千石，赐关内侯。王成死后，又有人告发他虚增户口。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **赐帛并督察救济执行。** 宣帝重申曾借公田、贷粮种与口粮，又给鳏寡孤独和高龄者加赐帛，命各地二千石官督促属吏切实办理。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **举荐可治民的贤良方正。** 朝廷命郡国举荐能亲近并治理百姓的贤良方正之士。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **因地震求谏并减屯抚流。** 冬十月诏回顾九月地震，求直言进谏，罢车骑将军、右将军屯兵以减劳。又命未御幸的池苑等借给贫民，停修郡国宫馆，归乡流民可借公田、贷种粮并暂免算钱与徭役。原字“池烃”存于底本。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **命郡国各举孝弟有行者。** 十一月，宣帝认为教化仍有缺失，引孝悌为仁本的说法，命每郡国荐一名在乡里以孝弟和行义闻名的人。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

<a id="hs-event-24"></a>

11. **廷尉初置左右平。** 十二月，首次设置廷尉平四人，秩各六百石，协助平理狱案。宣帝于廷尉设左右平，皆秩六百石。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **撤文山郡并入蜀郡。** 朝廷撤销文山郡，将其并入蜀郡。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **羽康侯成一支爵位承袭。** 地节三年，恭侯系继承侯爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **安衆康侯丹一支爵位承袭。** 地节三年，缪侯毋妨继承侯爵。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **广饶康侯国一支爵位承袭。** 地节三年，共侯坊继承侯爵，十四年去世。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **俞闾炀侯毋害一支爵位承袭。** 地节三年，原侯况继承侯爵，十年去世。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **宣处节侯章一支爵位承袭。** 地节三年，原侯衆继承侯爵，去世，无子嗣承继。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **修市原侯寅一支爵位承袭。** 地节三年，顷侯千秋继承侯爵。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **冠阳侯霍云｜受封。** 表载冠阳侯霍云一支本年有始封记载。表中所载事项为因大将军光功封。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **周子南君姬嘉｜获罪。** 表载周子南君姬嘉一支本年载相关罪案及处分。表中所载事项为因罪案使奴杀家丞，被处死。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **平恩戴侯许广汉｜受封。** 表载平恩戴侯许广汉一支本年有始封记载。表中所载事项为四月戊申封。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **高平宪侯魏相｜受封。** 表载高平宪侯魏相一支本年有始封记载。表中所载事项为六月壬戌封。 [[22]](#hs-note-22)

<a id="hs-event-23"></a>

23. **大司马不冠将军号。** 宣帝置不兼将军号、无印绶属官的大司马。 [[23]](#hs-note-23)

<a id="hs-event-25"></a>

24. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[24]](#hs-note-25)

<a id="hs-event-26"></a>

25. **丞相魏相侍婢身亡。** 本传初说魏相傅婢自缢，后文载覆验为受魏相责笞后离舍而死。赵广汉几年后追查此事，处刑仍见前64年现有条目。 [[25]](#hs-note-26)

<a id="hs-event-27"></a>

26. **萧望之借京师雨雹论霍氏权势。** 夏，京师雨雹。萧望之借鲁大夫季氏专权之例，促宣帝亲政、选任贤臣、考核公卿。 [[26]](#hs-note-27)

### 4. 郑吉在渠犁屯田，又攻车师

[返回正文第4条](#event-4)

<a id="hs094-l9842-e4"></a>

**[《汉书·匈奴传》P084](../../sources/摘录/汉书-卷094-匈奴传.md#p084)** · [仓内TXT L9842](../../sources/本地分卷/汉书/汉书-卷094.md#L9842)

> 其明年，西域城郭共擊匈奴，取車師國，得其王及人眾而去。單于復以車師王昆弟兜莫為車師王，收其餘民東徙，不敢居故地。而漢益遣屯士分田車師地以實之。

**互校说明** 地节三年，和《西域传》郑吉发诸国兵击车师互补。

<a id="hs096-l10106-e4"></a>

**[《汉书·西域传》P158](../../sources/摘录/汉书-卷096-西域传.md#p158)** · [仓内TXT L10106](../../sources/本地分卷/汉书/汉书-卷096.md#L10106)

> 地節二年，漢遣侍郎鄭吉、校尉司馬喜將免刑罪人田渠犁，積穀，欲以攻車師。至秋收谷，吉、喜發城郭諸國兵萬餘人，自與所將田士千五百人共擊車師，攻交河城，破之。王尚在其北石城中，未得，會軍食盡，吉等且罷兵，歸渠犁田。收秋畢，復發兵攻車師王於石城。王聞漢兵且至，北走匈奴求救，匈奴未為發兵。王來還，與貴人蘇猶議欲降漢，恐不見信。蘇猶教王擊匈奴邊國小蒲類，斬首，略其人民，以降吉。車師旁小金附國隨漢軍後盜車師，車師王復自請擊破金附。

**互校说明** 本传作地节二年；《通鉴》卷025考异取《匈奴传》地节三年，本页沿用前67年。

<a id="hs096-l10107-e4"></a>

**[《汉书·西域传》P159](../../sources/摘录/汉书-卷096-西域传.md#p159)** · [仓内TXT L10107](../../sources/本地分卷/汉书/汉书-卷096.md#L10107)

> 匈奴聞車師降漢，發兵攻車師，吉、喜引兵北逢之，匈奴不敢前。吉、喜即留一候與卒二十人留守王，吉等引兵歸渠犁。車師王恐匈奴兵復至而見殺也，乃輕騎奔烏孫，吉即迎其妻子置渠犁。東奏事，至酒泉，有詔還田渠犁及車師，益積穀以安西國，侵匈奴。吉還，傳送車師王妻子詣長安，賞賜甚厚，每朝會四夷，常尊顯以示之。於是吉始使吏卒三百人別田車師。

**互校说明** 《通鉴》卷025在地节三年的郑吉攻车师下叙驻兵、置屯。

<a id="hs070-l8670-e4"></a>

**[《汉书·傅常郑甘陈段传》P012](../../sources/摘录/汉书-卷070-傅常郑甘陈段传.md#p012)** · [仓内TXT L8670](../../sources/本地分卷/汉书/汉书-卷070.md#L8670)

> 至宣帝時，吉以侍郎田渠黎，積穀，因發諸國兵攻破車師，遷衞司馬，使護鄯善以西南道。

**互校说明** 《西域传》《通鉴》地节三年；本段记此时护南道，兼护北道在接受日逐王之后。

### 26. 萧望之借京师雨雹论霍氏权势

[返回正文第26条](#hs-event-27)

<a id="hs078-l9058-e27"></a>

**[《汉书·萧望之传》P005](../../sources/摘录/汉书-卷078-萧望之传.md#p005)** · [仓内TXT L9058](../../sources/本地分卷/汉书/汉书-卷078.md#L9058)

> 地節三年夏，京師雨雹，望之因是上疏，願賜清閒之宴，口陳災異之意。

**互校说明** 本传明确地节三年夏。《通鉴》同年录霍氏据权，宫中雨雹与地节四年山阳济阴雹分开。

<a id="hs078-l9058-e27-2"></a>

**[《汉书·萧望之传》P005](../../sources/摘录/汉书-卷078-萧望之传.md#p005)** · [仓内TXT L9058](../../sources/本地分卷/汉书/汉书-卷078.md#L9058)

> 宣帝自在民間聞望之名，曰：「此東海蕭生邪？下少府宋畸問狀，無有所諱。」望之對，以為「春秋昭公三年大雨雹，是時季氏專權，卒逐昭公。鄉使魯君察於天變，宜亡此害。今陛下以聖德居位，思政求賢，堯舜之用心也。然而善祥未臻，陰陽不和，是大臣任政，一姓擅勢之所致也。附枝大者賊本心，私家盛者公室危。唯明主躬萬機，選同姓，舉賢材，以為腹心，與參政謀，令公卿大臣朝見奏事，明陳其職，以考功能。如是，則庶事理，公道立，姦邪塞，私權廢矣。」對奏，天子拜望之為謁者。

**互校说明** 紧接本传地节三年夏奏疏。迁谏大夫及丞相司直为随后的仕历。

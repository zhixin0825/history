# 公元前67年｜韦贤退相，魏相接任；霍云受封，继续霍去病的宗祀

[← 公元前68年](bce-0068.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前66年 →](bce-0066.md)

**汉宣帝地节三年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e181"></a>
### 韦贤退相，魏相接任

韦贤年老多病，免相回家。御史大夫魏相接任丞相，封高平侯。魏相早年学易，从地方吏、县令做到河南太守，曾因办案问题下狱，又在赦免后重新入仕；现在他要主持全国政务。 [原文与说明](#sj020-e181-n)

<a id="sj020-e193"></a>
### 霍云受封，继续霍去病的宗祀

朝廷以霍去病曾立大功、后嗣一度断绝为由，封其孙辈霍云为侯，延续这支功臣家族。 [原文与说明](#sj020-e193-n)

<a id="sj020-e194"></a>
### 许广汉封平恩侯

皇太子刘奭确立以后，外祖父许广汉受封平恩侯。许广汉早年在宫中因案受刑，只有一个女儿许平君，后来把她嫁给尚未即位的刘病已，并在生活上照顾他。 [原文与说明](#sj020-e194-n)

<a id="sj020-e225"></a>
### 郑吉在渠犁屯田，又攻车师

郑吉与司马憙带领获免刑的士卒在渠犁种田积粮，又联合西域诸国军队攻车师。匈奴随后争夺车师，汉军的屯田、救援与各国转向成为长期反复的过程。 [原文与说明](#sj020-e225-n)

<a id="sj022"></a>
## 朝廷人事与本年补记

刘奭被立为皇太子。丙吉由太子太傅升御史大夫；霍禹也取得大司马名号，朝廷继续重排霍光身后的人事。 [原文与说明](#sj022-note)

## 本年相关史料

### 卷022｜将相表互见与异说

[本年原行R140](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r140) · [《汉书·百官公卿表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7019.md#ref-b791d66c961e42)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

韦贤退休、魏相接相见本页旧叙事，史表五月甲申与汉019正月甲申有月差；任相六月壬辰相同。太子确立据史表及汉008四月戊申。丙吉史作邴吉为同人异字，汉019御史在六月辛丑。史表本年七月张安世任大司马卫将军，既有页以传记、通鉴系前68年，仍接[前68年](bce-0068.md#sj020-e167)不重复任命。汉019本行又误夹霍禹腰斩，不能把前66年案件提前一年；霍禹大司马名号与被杀分开 · [宣帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-b7c52baedb67f4)。

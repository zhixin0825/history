# 公元前67年｜韦贤退相，魏相接任；霍云受封，继续霍去病的宗祀

[← 公元前68年](bce-0068.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前66年 →](bce-0066.md)

**汉宣帝地节三年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="韦贤退相魏相接任"></a>


<a id="event-1"></a>

1. **韦贤退相，魏相接任。** 韦贤年老多病，免相回家。御史大夫魏相接任丞相，封高平侯。魏相早年学易，从地方吏、县令做到河南太守，曾因办案问题下狱，又在赦免后重新入仕；现在他要主持全国政务。 [[1]](#note-1)

<a id="sj020-e193"></a>
<a id="霍云受封继续霍去病的宗祀"></a>


<a id="event-2"></a>

2. **霍云因霍光之功获封冠阳侯。** 霍云是霍光的兄孙，宣帝以褒及霍光后辈为封赏理由。前一年奉祀霍去病而得封的乐平侯为[霍山](bce-0068.md#note-1)。 宣帝诏书以褒及霍光的晚辈为封霍云的理由，同年封号各本另有冠阳、冠军之写。 [[2]](#note-2)

<a id="sj020-e194"></a>
<a id="许广汉封平恩侯"></a>


<a id="event-3"></a>

3. **许广汉封平恩侯。** 皇太子刘奭确立以后，外祖父许广汉受封平恩侯。许广汉早年在宫中因案受刑，只有一个女儿许平君，后来把她嫁给尚未即位的刘病已，并在生活上照顾他。 [[3]](#note-3)

<a id="sj020-e225"></a>
<a id="郑吉在渠犁屯田又攻车师"></a>


<a id="event-4"></a>

4. **郑吉在渠犁屯田，又攻车师。** 郑吉与司马憙带领获免刑的士卒在渠犁种田积粮，又联合西域诸国军队攻车师。匈奴随后争夺车师，汉军的屯田、救援与各国转向成为长期反复的过程。 [[4]](#note-4)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-5"></a>

5. **刘奭被立为皇太子。** 丙吉由太子太傅升御史大夫；霍禹也取得大司马名号，朝廷继续重排霍光身后的人事。 [[5]](#note-5)

<a id="hs-event-6"></a>

6. **王成招抚流民获赏。** 三月诏称胶东相王成勤于招徕流亡百姓，有八万余人自行申报归籍，政绩特殊，升秩中二千石，赐关内侯。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **赐帛并督察救济执行。** 宣帝重申曾借公田、贷粮种与口粮，又给鳏寡孤独和高龄者加赐帛，命各地二千石官督促属吏切实办理。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **举荐可治民的贤良方正。** 朝廷命郡国举荐能亲近并治理百姓的贤良方正之士。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **因地震求谏并减屯抚流。** 冬十月诏回顾九月地震，求直言进谏，罢车骑将军、右将军屯兵以减劳。又命未御幸的池苑等借给贫民，停修郡国宫馆，归乡流民可借公田、贷种粮并暂免算钱与徭役。原字“池烃”存于底本。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **命郡国各举孝弟有行者。** 十一月，宣帝认为教化仍有缺失，引孝悌为仁本的说法，命每郡国荐一名在乡里以孝弟和行义闻名的人。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **设廷尉平。** 十二月，首次设置廷尉平四人，秩各六百石，协助平理狱案。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **撤文山郡并入蜀郡。** 朝廷撤销文山郡，将其并入蜀郡。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **羽康侯成一支爵位承袭。** 地节三年，恭侯系继承侯爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **安衆康侯丹一支爵位承袭。** 地节三年，缪侯毋妨继承侯爵。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **广饶康侯国一支爵位承袭。** 地节三年，共侯坊继承侯爵，十四年去世。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **俞闾炀侯毋害一支爵位承袭。** 地节三年，原侯况继承侯爵，十年去世。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **宣处节侯章一支爵位承袭。** 地节三年，原侯衆继承侯爵，去世，无子嗣承继。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **修市原侯寅一支爵位承袭。** 地节三年，顷侯千秋继承侯爵。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **冠阳侯霍云｜受封。** 表载冠阳侯霍云一支本年有始封记载。表中所载事项为因大将军光功封。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **周子南君姬嘉｜获罪。** 表载周子南君姬嘉一支本年载相关罪案及处分。表中所载事项为因罪案使奴杀家丞，被处死。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **平恩戴侯许广汉｜受封。** 表载平恩戴侯许广汉一支本年有始封记载。表中所载事项为四月戊申封。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **高平宪侯魏相｜受封。** 表载高平宪侯魏相一支本年有始封记载。表中所载事项为六月壬戌封。 [[22]](#hs-note-22)

<a id="hs-event-23"></a>

23. **大司马不冠将军号。** 宣帝置不兼将军号、无印绶属官的大司马。 [[23]](#hs-note-23)

<a id="hs-event-24"></a>

24. **廷尉初置左右平。** 宣帝于廷尉设左右平，皆秩六百石。 [[24]](#hs-note-24)

<a id="hs-event-25"></a>

25. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[25]](#hs-note-25)

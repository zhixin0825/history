1. **霍光去世，霍禹继侯，霍山受封延续去病一支。** 三月，霍光去世，霍禹继承博陆侯。朝廷又依霍光此前的请求，把部分封邑分给霍山，使霍去病这一支能够继续奉祀。霍山受封乐平侯，不是继承霍光的同一份博陆爵位。 [[1]](#note-1)

<a id="sj020-e219"></a>
<a id="赵长平因揭发楚国事封爰戚侯"></a>


<a id="event-2"></a>

2. **赵长平因揭发楚国事封爰戚侯。** 赵长平因前一年揭发楚国案，受封爰戚侯。 [[2]](#note-2)

<a id="sj020-e167"></a>
<a id="张安世在霍光死后主持军政"></a>


<a id="event-3"></a>

3. **张安世在霍光死后主持军政。** 霍光去世后，张安世受命为大司马车骑将军、领尚书事，随后改卫将军，掌握相关宿卫军队。皇帝重排中枢权力，霍光之子的尊号与实际兵权也开始分离。 [[3]](#note-3)

<a id="sj020-e191"></a>
<a id="王迁获罪平丘侯国终止"></a>


<a id="event-4"></a>

4. **王迁获罪，平丘侯国终止。** 王迁被追究私下受诸侯王财物、泄露宫中机密等罪，侯国终止。 [[4]](#note-4)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-5"></a>

5. **二月，霍禹获任右将军，随后又继承父亲霍光的博陆侯爵。** 将军职位与侯爵承袭是不同的名位。 [[5]](#note-5)

<a id="hs-event-6"></a>

6. **鲁郡祥鸟报告与大赦。** 四月，纪载凤凰聚于鲁郡，有群鸟相从，朝廷大赦。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **宣帝亲政与密封奏事。** 霍光死后，宣帝开始亲理政务，仍令霍山掌尚书事务以酬霍光旧功，并准大臣密封奏事。皇帝五日听政一次，令官员依职责奏事、核实言论与成效，对侍中、尚书中应升迁或表现突出者重赏。 魏相借许广汉进封事，请缩减霍氏兵权，取消先拆副封以压下正本奏章的惯例，宣帝采纳。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **缾敬侯成一支爵位承袭。** 地节二年，顷侯龙继承侯爵，五十年去世。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **南利侯昌一支失爵。** 地节二年，因……获罪贼杀人免去侯爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **四月癸卯分封王子侯。** [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **爰戚靖侯赵长平｜受封。** 表载爰戚靖侯赵长平一支本年有始封记载。表中所载事项为四月癸卯封。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **平丘侯王迁｜获罪。** 表载平丘侯王迁一支本年载相关罪案及处分。表中所载事项为因罪案平尚书听请受臧六百万，自杀。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **官制表记西域都护初置。** 职官表系于宣帝地节二年，述都护为加官及所辖官属；其所记初置与神爵年间职权扩大分读。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **壶衍鞮单于去世，虚闾权渠继立。** 壶衍鞮单于立十七年而卒，弟左贤王继为虚闾权渠单于。新单于黜前单于所宠颛渠阏氏。 [[15]](#hs-note-15)

### 3. 张安世在霍光死后主持军政

[返回正文第3条](#event-3)

<a id="hs059-l8175-e3"></a>

**[《汉书·张汤传》P017](../../sources/摘录/汉书-卷059-张汤传.md#p017)** · [仓内TXT L8175](../../sources/本地分卷/汉书/汉书-卷059.md#L8175)

> 大將軍光薨後數月，御史大夫魏相上封事曰：「聖王褒有德以懷萬方，顯有功以勸百寮，是以朝廷尊榮，天下鄉風。國家承祖宗之業，制諸侯之重，新失大將軍，宜宣章盛德以示天下，顯明功臣以填籓國。毋空大位，以塞爭權，所以安社稷絕未萌也。車騎將軍安世事孝武皇帝三十餘年，忠信謹厚，勤勞政事，夙夜不怠，與大將軍定策，天下受其福，國家重臣也，宜尊其位，以為大將軍，毋令領光祿勳事，使專精神，憂念天下，思惟得失。安世子延壽重厚，可以為光祿勳，領宿衛臣。」上亦欲用之。安世聞指，懼不敢當。請聞求見，免冠頓首曰：「老臣耳妄聞，言之為先事，不言情不達，誠自量不足以居大位，繼大將軍後，唯天子財哀，以全老臣之命。」上笑曰：「君言泰謙。君而不可，尚誰可者！」安世深辭弗能得。後數日，竟拜為大司馬車騎將軍，領尚書事。數月，罷車騎將軍屯兵，更為衛將軍，兩宮衛尉，城門、北軍兵屬焉。

**互校说明** 武帝朝任宫官系前事；魏相上疏、拜大司马、改卫将军归地节二年。

**[《史记》卷020《建元以来侯者年表》｜富平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s009)**

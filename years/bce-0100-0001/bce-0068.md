<a id="event-1"></a>

1. **霍光去世，霍禹继侯，霍山受封延续去病一支。** 三月，霍光去世，霍禹继承博陆侯。朝廷又依霍光此前的请求，把部分封邑分给霍山，使霍去病这一支能够继续奉祀。霍山受封乐平侯，不是继承霍光的同一份博陆爵位。 [[1]](#note-1)

<a id="sj020-e219"></a>
<a id="赵长平因揭发楚国事封爰戚侯"></a>


<a id="event-2"></a>

2. **赵长平因揭发楚国事封爰戚侯。** 赵长平因前一年揭发楚国案，受封爰戚侯。 [[2]](#note-2)

<a id="sj020-e167"></a>
<a id="张安世在霍光死后主持军政"></a>


<a id="event-3"></a>

3. **张安世在霍光死后主持军政。** 霍光去世后，张安世受命为大司马车骑将军、领尚书事，随后改卫将军，掌握相关宿卫军队。皇帝重排中枢权力，霍光之子的尊号与实际兵权也开始分离。 [[3]](#note-3)

<a id="sj020-e191"></a>
<a id="王迁获罪平丘侯国终止"></a>


<a id="event-4"></a>

4. **王迁获罪，平丘侯国终止。** 王迁被追究私下受诸侯王财物、泄露宫中机密等罪，侯国终止。 [[4]](#note-4)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-5"></a>

5. **二月，霍禹获任右将军，随后又继承父亲霍光的博陆侯爵。** 将军职位与侯爵承袭是不同的名位。 [[5]](#note-5)

<a id="hs-event-6"></a>

6. **鲁郡祥鸟报告与大赦。** 四月，纪载凤凰聚于鲁郡，有群鸟相从，朝廷大赦。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **宣帝亲政与密封奏事。** 霍光死后，宣帝开始亲理政务，仍令霍山掌尚书事务以酬霍光旧功，并准大臣密封奏事。皇帝五日听政一次，令官员依职责奏事、核实言论与成效，对侍中、尚书中应升迁或表现突出者重赏。 [[7]](#hs-note-7)

### 1. 霍光去世，霍禹继侯，霍山受封延续去病一支

[返回正文第1条](#event-1)

<a id="hs008-l674-e1"></a>

**[《汉书·宣帝纪》P032](../../sources/摘录/汉书-卷008-宣帝纪.md#p032)** · [仓内TXT L674](../../sources/本地分卷/汉书/汉书-卷008.md#L674)

> 二年春三月庚午，大司馬大將軍光薨。詔曰：「大司馬大將軍博陸侯宿衛孝武皇帝三十餘年，輔孝昭皇帝十有餘年，遭大難，躬秉義，率三公、諸侯、九卿、大夫定萬世策，以安宗廟。天下蒸庶，咸以康寧，功德茂盛，朕甚嘉之。復其後世，疇其爵邑，世世毋有所與。功如蕭相國。」

**[《史记》卷020《建元以来侯者年表》｜博陸](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s005)**

**原文原格**

> 霍光，家在平陽。以兄驃騎將軍故貴。前事武帝，覺捕得侍中謀反者馬何羅等功侯，三千戶。中輔幼主昭帝，為大將軍。謹信，用事擅治，尊為大司馬，益封邑萬戶。後事宣帝。歷事三主，天下信鄉之，益封二萬戶。子禹代立，謀反，族滅，國除。

**[《史记》卷020《建元以来侯者年表》｜樂成](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s023)**

**原文原格**

> 霍山。山者，大將軍光兄子也。光未死時上書曰：「臣兄驃騎將軍去病從軍有功，病死，賜謚景桓侯，絕無後，臣光願以所封東武陽邑三千五百戶分與山。」天子許之，拜山為侯。後坐謀反，族滅，國除。

> 上始親政事，又思報大將軍功德，乃復使樂平侯山領尚書事，而令群臣得奏封事，以知下情。五日一聽事，以下各奉職奏事，以傅奏其言，考試功能。侍中尚書功勞當遷及有異善，厚加賞賜，至于子孫，終不改易。樞機周密，品式備具，上下相安，莫有苟且之意也。

#### 卷022｜将相表互见与异说

[本年原行R139](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r139) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0068)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史表二月丁卯任右将军，汉019同年也列霍禹右将军；霍光三月庚午去世已在本页，不因相位栏夹写“光卒”便误作丞相韦贤死亡。张安世接掌军政沿本页已采用的前68年线；史表把大司马、卫将军写在下一年，见[前67年异年说明](bce-0067.md#sj022-note) · [宣帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-e787d9bc8c73a4)。

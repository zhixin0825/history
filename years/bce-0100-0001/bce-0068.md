# 公元前68年｜霍光去世，霍禹继侯，霍山受封延续去病一支；赵长平因揭发楚国事封爰戚侯

**汉宣帝地节二年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e192"></a>
### 霍光去世，霍禹继侯，霍山受封延续去病一支

三月，霍光去世，霍禹继承博陆侯。朝廷又依霍光此前的请求，把部分封邑分给霍山，使霍去病这一支能够继续奉祀。霍山受封乐平侯，不是继承霍光的同一份博陆爵位。 [原文与说明](#sj020-e192-n)

<a id="sj020-e219"></a>
### 赵长平因揭发楚国事封爰戚侯

赵长平因前一年揭发楚国案，受封爰戚侯。 [原文与说明](#sj020-e219-n)

<a id="sj020-e167"></a>
### 张安世在霍光死后主持军政

霍光去世后，张安世受命为大司马车骑将军、领尚书事，随后改卫将军，掌握相关宿卫军队。皇帝重排中枢权力，霍光之子的尊号与实际兵权也开始分离。 [原文与说明](#sj020-e167-n)

<a id="sj020-e191"></a>
### 王迁获罪，平丘侯国终止

王迁被追究私下受诸侯王财物、泄露宫中机密等罪，侯国终止。 [原文与说明](#sj020-e191-n)

<a id="sj022"></a>
## 朝廷人事与本年补记

二月，霍禹获任右将军，随后又继承父亲霍光的博陆侯爵。将军职位与侯爵承袭是不同的名位。 [原文与说明](#sj022-note)

## 本年相关史料

### 卷022｜将相表互见与异说

[本年原行R139](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r139) · [《汉书·百官公卿表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7019.md#ref-9852bd1508268d)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史表二月丁卯任右将军，汉019同年也列霍禹右将军；霍光三月庚午去世已在本页，不因相位栏夹写“光卒”便误作丞相韦贤死亡。张安世接掌军政沿本页已采用的前68年线；史表把大司马、卫将军写在下一年，见[前67年异年说明](bce-0067.md#sj022-note) · [宣帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-e787d9bc8c73a4)。

<a id="event-1"></a>

1. **黄霸遇赦出狱，转任地方官。** 大赦以后，黄霸获释，出任扬州刺史。他在狱中学习经书的经历，与此后治理地方连接起来，但不能因后来以循吏著名，就说此前案件从未发生。 [[1]](#note-1)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-2"></a>

2. **三月，霍氏成为皇后。** 她是霍光的女儿，许皇后去世后，中宫与辅政家族的联系更加紧密。 [[2]](#note-2)

<a id="hs-event-3"></a>

3. **歉收时节用、输粮与通关。** 正月因歉收而贷给贫民粮食，命太官减膳、少宰牲，乐府减员还农。丞相等官员可向长安仓输粮以助赈贷，民众用车船运粮入关可免凭传。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **四十九处地震，广询对策。** 四月壬寅，郡国四十九处地震，或山崩水涌，北海、琅邪祖庙受损。宣帝令大臣广问经学之士、荐贤良方正、条陈可删律令，免重灾区租赋并大赦。因宗庙损毁，他着素服避正殿五日。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **安丘、淳于祥鸟记录。** 五月，纪载凤凰落在北海郡安丘、淳于二地。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **广川王刘去废迁后自杀。** 秋，广川王获罪，被废而迁上庸，自杀。仓内本纪作“吉”，同书《诸侯王表》及《景十三王传》作“去”，《通鉴》从“去”。 [[6]](#hs-note-6)

### 1. 黄霸遇赦出狱，转任地方官

[返回正文第1条](#event-1)

**[《史记》卷020《建元以来侯者年表》｜建成](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s044)**

**原文原格**

> 黃霸，家在陽夏，以役使徙雲陽。以廉吏為河內守丞，遷為廷尉監，行丞相長史事。坐見知夏侯勝非詔書大不敬罪，久繫獄三歲，從勝學尚書。會赦，以賢良舉為揚州刺史，潁川太守。善化，男女異路，耕者讓畔，賜黃金百斤，秩中二千石。居潁川，入為太子傅，遷御史大夫。五鳳三年，代邴吉為丞相。封千八百戶。

### 4. 四十九处地震，广询对策

[返回正文第4条](#hs-event-4)

<a id="hs008-l666-e4"></a>

**[《汉书·宣帝纪》P024](../../sources/摘录/汉书-卷008-宣帝纪.md#p024)** · [仓内TXT L666](../../sources/本地分卷/汉书/汉书-卷008.md#L666)

> 夏四月壬寅，郡國四十九地震，或山崩水出。詔曰：「蓋災異者，天地之戒也。朕承洪業，奉宗廟，託于 士民之上，未能和群生。乃者地震北海、琅邪，壞祖宗廟，朕甚懼焉。丞相、御史其與列侯、中二千石博問經學之士，有以應變，輔朕之不逮，毋有所諱。令三輔、 太常、內郡國舉賢良方正各一人。律令有可蠲除以安百姓，條奏。被地震壞敗甚者，勿收租賦。」大赦天下。上以宗廟墮，素服，避正殿五日。

**互校说明** 灾害、赦免与政策并见。古代灾异解释按诏辞保存，不把地震同执政优劣写成现代因果。

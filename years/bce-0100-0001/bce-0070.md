本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="黄霸遇赦出狱转任地方官"></a>


<a id="event-1"></a>

1. **黄霸遇赦出狱，转任地方官。** 大赦以后，黄霸获释，出任扬州刺史。他在狱中学习经书的经历，与此后治理地方连接起来，但不能因后来以循吏著名，就说此前案件从未发生。 与黄霸同囚的夏侯胜也遇赦，出任谏大夫、给事中。 [[1]](#note-1)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-2"></a>

2. **三月，霍氏成为皇后。** 她是霍光的女儿，许皇后去世后，中宫与辅政家族的联系更加紧密。 [[2]](#note-2)

<a id="hs-event-3"></a>

3. **歉收时节用、输粮与通关。** 正月因歉收而贷给贫民粮食，命太官减膳、少宰牲，乐府减员还农。丞相等官员可向长安仓输粮以助赈贷，民众用车船运粮入关可免凭传。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **四十九处地震，广询对策。** 四月壬寅，郡国四十九处地震，或山崩水涌，北海、琅邪祖庙受损。宣帝令大臣广问经学之士、荐贤良方正、条陈可删律令，免重灾区租赋并大赦。因宗庙损毁，他着素服避正殿五日。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **安丘、淳于祥鸟记录。** 五月，纪载凤凰落在北海郡安丘、淳于二地。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **广川王刘去废迁后自杀。** 秋，广川王获罪，被废而迁上庸，自杀。仓内本纪作“吉”，同书《诸侯王表》及《景十三王传》作“去”，《通鉴》从“去”。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **瑕丘节侯政一支爵位承袭。** 本始四年，孝侯汤继承侯爵，十年去世。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **衆陵节侯贤一支爵位承袭。** 本始四年，戴侯真定继承侯爵，二十二年去世。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **魏其炀侯昌一支爵位承袭。** 本始四年，原侯傅光继承侯爵，三十三年去世。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **四月己丑分封王子侯。** 《王子侯表》列四月己丑受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **五月癸丑分封王子侯。** 《王子侯表》列五月癸丑受封的诸侯王后裔；各人侯名与宗支见同号引文。 本次分封有燕王刘旦之子刘庆，封为新昌侯。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **长罗壮侯常惠｜受封。** 表载长罗壮侯常惠一支本年有始封记载。表中所载事项为四月癸巳封。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **阳平节侯蔡义｜去世。** 表载阳平节侯蔡义一支本年记载去世。表中所载事项为去世，无继承人。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **月犯辰星，荧惑入舆鬼。** 《汉书》在本年记载月犯辰星，荧惑入舆鬼。 [[15]](#hs-note-15)

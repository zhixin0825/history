<a id="event-1"></a>

1. **两位带兵的侯因出征失职自杀。** 朝廷追究上次出兵的责任。田顺被指虚报俘获，田广明则未按要求到达，二人均下有司审处，自杀身亡，富民、昌水两处侯爵终止。 [[1]](#note-1)

<a id="sj020-e179"></a>
<a id="蔡义去世阳平侯国因无后终止"></a>


<a id="event-2"></a>

2. **蔡义去世，阳平侯国因无后终止。** 蔡义去世，没有后人承接阳平侯爵，封国撤销。 [[2]](#note-2)

<a id="sj020-e180"></a>
<a id="韦贤继任丞相封扶阳侯"></a>


<a id="event-3"></a>

3. **韦贤继任丞相，封扶阳侯。** 韦贤接任丞相，封扶阳侯。他来自鲁地，通晓诗、礼、尚书，曾任博士、近侍和礼宾官，也教过昭帝。经学与帝师经历，成为他跻身相位的重要条件。 [[3]](#note-3)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-4"></a>

4. **正月，皇后许平君去世。** 朝廷随后处理出兵失职的田广明、田顺，收回赵充国的将军印。六月魏相由大司农升御史大夫，接续中央监察职位。 霍显私使乳医淳于衍行毒，许后暴卒。霍光得知后未揭发，并令不追究淳于衍。 [[4]](#note-4)

<a id="hs-event-5"></a>

5. **常惠率乌孙兵取得战果。** 汉使常惠持节协助乌孙出兵，深入匈奴右部，取得重大战果。《宣帝纪》在战果后接叙封侯，侯表载[次年正式封长罗侯](bce-0070.md#hs-note-12)。 乌孙军由昆弥率领，常惠持汉节协助，俘获匈奴部众并夺得牲畜。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **旱灾免赋役。** 大旱，受灾严重的郡国免交租赋；三辅就食于物价较低处的百姓暂免征役，一直延至次年。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **刘申嗣真定王。** 刘申嗣真定王。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **四月壬申分封王子侯。** 《王子侯表》列四月壬申受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **六月甲辰分封王子侯。** 《王子侯表》列六月甲辰受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **成安严侯郭忠｜承爵。** 表载成安严侯郭忠一支本年记载侯位承袭。表中所载事项为爱侯迁承爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **富民定侯车千秋｜获罪。** 表载富民定侯车千秋一支本年载相关罪案及处分。表中所载事项为因罪案为虎牙将军击匈奴诈增虏获，自杀。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **扶阳节侯韦贤｜受封。** 《汉书》侯籍列扶阳节侯韦贤本年受封，所引月份、干支依表保留。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **本始三年夏大旱。** 《汉书》在本年记载本始三年夏大旱。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **汉军五路出塞，赵充国由酒泉北进。** 本始三年春，汉军五路出塞。蒲类将军赵充国由酒泉出军，杜缓以校尉随行，归后任谏大夫。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **常惠出使乌孙后诛龟兹姑翼。** 常惠奉使再赴乌孙，返途中追究此前汉使被害。龟兹王归咎于旧臣姑翼，将他交给常惠，常惠斩姑翼后返汉。 [[16]](#hs-note-16)

# 公元前71年｜两位带兵的侯因出征失职自杀；蔡义去世，阳平侯国因无后终止

**汉宣帝本始三年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **两位带兵的侯因出征失职自杀。** 朝廷追究上次出兵的责任。田顺被指虚报俘获，田广明则未按要求到达，二人均下有司审处，自杀身亡，富民、昌水两处侯爵终止。 [[1]](#note-1)

<a id="sj020-e179"></a>
<a id="蔡义去世阳平侯国因无后终止"></a>


<a id="event-2"></a>

2. **蔡义去世，阳平侯国因无后终止。** 蔡义去世，没有后人承接阳平侯爵，封国撤销。 [[2]](#note-2)

<a id="sj020-e180"></a>
<a id="韦贤继任丞相封扶阳侯"></a>


<a id="event-3"></a>

3. **韦贤继任丞相，封扶阳侯。** 韦贤接任丞相，封扶阳侯。他来自鲁地，通晓诗、礼、尚书，曾任博士、近侍和礼宾官，也教过昭帝。经学与帝师经历，成为他跻身相位的重要条件。 [[3]](#note-3)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-4"></a>

4. **正月，皇后许平君去世。** 朝廷随后处理出兵失职的田广明、田顺，收回赵充国的将军印。六月魏相由大司农升御史大夫，接续中央监察职位。 [[4]](#note-4)

### 1. 两位带兵的侯因出征失职自杀

[返回正文第1条](#event-1)

**[《史记》卷020《建元以来侯者年表》｜富民](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s004)**

**原文原格**

> 田千秋，家在長陵。以故高廟寢郎上書諫孝武曰：「子弄父兵，罪當笞。父子之怒，自古有之。蚩尤畔父，黃帝涉江」。上書至意，拜為大鴻臚。征和四年為丞相，封三千戶。至昭帝時病死，子順代立，為虎牙將軍，擊匈奴，不至質，誅死，國除。

**[《史记》卷020《建元以来侯者年表》｜昌水](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s026)**

**原文原格**

> 田廣明。故郎，為司馬，稍遷至南郡都尉、淮陽太守、鴻臚、左馮翊。昭帝崩，議廢昌邑王，立宣帝，決疑定策，以安宗廟。本始三年，封為侯，邑二千三百戶。為御史大夫。後為祁連將軍，擊匈奴，軍不至質，當死，自殺，國除。

### 2. 蔡义去世，阳平侯国因无后终止

[返回正文第2条](#event-2)

**[《史记》卷020《建元以来侯者年表》｜陽平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s017)**

**原文原格**

> 蔡義，家在溫。故師受韓詩，為博士，給事大將軍幕府，為杜城門候。入侍中，授昭帝韓詩，為御史大夫。是時年八十，衰老，常兩人扶持乃能行。然公卿大臣議，以為為人主師，當以為相。以元平元年代楊敞為丞相，封二千戶。病死，絕無後，國除。

#### 卷022｜将相表互见与异说

[本年原行R136](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r136) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0071)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

蔡义之死、韦贤接相、田广明田顺自杀均接本页原有事项。史表“皇后崩”作三月戊子，汉008本始三年明确正月癸亥，正文采用本纪；蔡义卒史六月乙丑，汉019/008六月己丑，只采用六月。史表赵充国夺印与两人自杀同列不等于他也自杀。魏相官名辨认据汉019 · [宣帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-d893bf9b06aa7f)。

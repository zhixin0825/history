# 公元前71年｜两位带兵的侯因出征失职自杀；蔡义去世，阳平侯国因无后终止

[← 公元前72年](bce-0072.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前70年 →](bce-0070.md)

**汉宣帝本始三年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e152"></a>
### 两位带兵的侯因出征失职自杀

朝廷追究上次出兵的责任。田顺被指虚报俘获，田广明则未按要求到达，二人均下有司审处，自杀身亡，富民、昌水两处侯爵终止。 [原文与说明](#sj020-e152-n)

<a id="sj020-e179"></a>
### 蔡义去世，阳平侯国因无后终止

蔡义去世，没有后人承接阳平侯爵，封国撤销。 [原文与说明](#sj020-e179-n)

<a id="sj020-e180"></a>
### 韦贤继任丞相，封扶阳侯

韦贤接任丞相，封扶阳侯。他来自鲁地，通晓诗、礼、尚书，曾任博士、近侍和礼宾官，也教过昭帝。经学与帝师经历，成为他跻身相位的重要条件。 [原文与说明](#sj020-e180-n)

<a id="sj022"></a>
## 朝廷人事与本年补记

正月，皇后许平君去世。朝廷随后处理出兵失职的田广明、田顺，收回赵充国的将军印。六月魏相由大司农升御史大夫，接续中央监察职位。 [原文与说明](#sj022-note)

## 本年相关史料

<a id="sj022-note"></a>
### 卷022｜将相表互见与异说

[本年原行R136](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r136) · [《汉书·百官公卿表》](https://zh.wikisource.org/wiki/漢書/卷019)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

蔡义之死、韦贤接相、田广明田顺自杀均接本页原有事项。史表“皇后崩”作三月戊子，汉008本始三年明确正月癸亥，正文采用本纪；蔡义卒史六月乙丑，汉019/008六月己丑，只采用六月。史表赵充国夺印与两人自杀同列不等于他也自杀。魏相官名辨认据汉019 · [宣帝纪互见](https://zh.wikisource.org/wiki/漢書/卷008)。

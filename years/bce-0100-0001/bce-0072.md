本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

### 田延年因侵吞丧事钱款自杀

<a id="event-1"></a>

1. **田延年因侵吞丧事钱款自杀。** 昭帝丧事期间，田延年主管租用民车，虚增费用，侵吞官钱。案情发觉以后，霍光一度希望有司讨论他的功过；田延年最终在被召审问时自杀，阳城侯国撤销。 [[1]](#note-1)

<a id="sj020-e230"></a>
<a id="黄霸因没有弹劾夏侯胜而入狱"></a>
### 黄霸因没有弹劾夏侯胜而入狱

<a id="event-2"></a>

2. **黄霸因没有弹劾夏侯胜而入狱。** 朝廷讨论给武帝增加庙乐，夏侯胜反对只颂功而不计征战、征敛造成的损害。黄霸没有按要求弹劾他，也被下狱。两人长期同囚，黄霸仍向夏侯胜学习尚书。 [[2]](#note-2)

<a id="sj020-e151"></a>
<a id="田顺田广明分道出击匈奴"></a>
### 田顺、田广明分道出击匈奴

<a id="event-3"></a>

3. **汉廷大举出兵，田顺以虎牙将军、田广明以祁连将军分别统军。** 两人本来都已封侯，出征不是一轮新的初封。 [[3]](#note-3)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-4"></a>

4. **朝廷征发骑兵，准备分路出击匈奴。** 除了田广明、田顺，韩增、赵充国和范明友也分别统军；赵充国加蒲类将军号，范明友仍以度辽将军领兵。这一轮调兵与次年春实际出发、战后问责连在一起。 [[4]](#note-4)

#### 卷022｜将相表互见与异说

[本年原行R135](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r135) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0072)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史表七月庚寅列五将军，范明友却写“为云中太守”；汉008本始二年秋明确云中太守是田顺，范明友为度辽将军；本始三年正月戊辰“五将军师发长安”。采用本纪将人、官分清，并把本年筹调与[前71年出发和追责](bce-0071.md)衔接；不误给范明友另授田顺的官。史表韩曾为后将军，汉008同段称韩增为前将军，故正文保留姓名而不据本格创设改后将军的一次独立官历 · [宣帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-3ba1156bff886d)。

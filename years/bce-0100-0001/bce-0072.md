# 公元前72年｜田延年因侵吞丧事钱款自杀；黄霸因没有弹劾夏侯胜而入狱

[← 公元前73年](bce-0073.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前71年 →](bce-0071.md)

**汉宣帝本始二年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e190"></a>
### 田延年因侵吞丧事钱款自杀

昭帝丧事期间，田延年主管租用民车，虚增费用，侵吞官钱。案情发觉以后，霍光一度希望有司讨论他的功过；田延年最终在被召审问时自杀，阳城侯国撤销。 [原文与说明](#sj020-e190-n)

<a id="sj020-e230"></a>
### 黄霸因没有弹劾夏侯胜而入狱

朝廷讨论给武帝增加庙乐，夏侯胜反对只颂功而不计征战、征敛造成的损害。黄霸没有按要求弹劾他，也被下狱。两人长期同囚，黄霸仍向夏侯胜学习尚书。 [原文与说明](#sj020-e230-n)

<a id="sj020-e151"></a>
### 田顺、田广明分道出击匈奴

汉廷大举出兵，田顺以虎牙将军、田广明以祁连将军分别统军。两人本来都已封侯，出征不是一轮新的初封。 [原文与说明](#sj020-e151-n)

<a id="sj022"></a>
## 朝廷人事与本年补记

朝廷征发骑兵，准备分路出击匈奴。除了田广明、田顺，韩增、赵充国和范明友也分别统军；赵充国加蒲类将军号，范明友仍以度辽将军领兵。这一轮调兵与次年春实际出发、战后问责连在一起。 [原文与说明](#sj022-note)

## 本年相关史料

<a id="sj022-note"></a>
### 卷022｜将相表互见与异说

[本年原行R135](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r135) · [《汉书·百官公卿表》](https://zh.wikisource.org/wiki/漢書/卷019)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史表七月庚寅列五将军，范明友却写“为云中太守”；汉008本始二年秋明确云中太守是田顺，范明友为度辽将军；本始三年正月戊辰“五将军师发长安”。采用本纪将人、官分清，并把本年筹调与[前71年出发和追责](bce-0071.md)衔接；不误给范明友另授田顺的官。史表韩曾为后将军，汉008同段称韩增为前将军，故正文保留姓名而不据本格创设改后将军的一次独立官历 · [宣帝纪互见](https://zh.wikisource.org/wiki/漢書/卷008)。

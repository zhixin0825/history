<a id="event-1"></a>

1. **田延年因侵吞丧事钱款自杀。** 昭帝丧事期间，田延年主管租用民车，虚增费用，侵吞官钱。案情发觉以后，霍光一度希望有司讨论他的功过；田延年最终在被召审问时自杀，阳城侯国撤销。 [[1]](#note-1)

<a id="sj020-e230"></a>
<a id="黄霸因没有弹劾夏侯胜而入狱"></a>


<a id="event-2"></a>

2. **黄霸因没有弹劾夏侯胜而入狱。** 朝廷讨论给武帝增加庙乐，夏侯胜反对只颂功而不计征战、征敛造成的损害。黄霸没有按要求弹劾他，也被下狱。两人长期同囚，黄霸仍向夏侯胜学习尚书。 [[2]](#note-2)

<a id="sj020-e151"></a>
<a id="田顺田广明分道出击匈奴"></a>

<a id="event-3"></a>

3. **田顺、田广明分道出击匈奴。** 汉廷大举出兵，田顺以虎牙将军、田广明以祁连将军分别统军。 两人本来都已封侯，出征不是一轮新的初封。 [[3]](#note-3)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-4"></a>

4. **朝廷征发骑兵，准备分路出击匈奴。** 除了田广明、田顺，韩增、赵充国和范明友也分别统军；赵充国加蒲类将军号，范明友仍以度辽将军领兵。这一轮调兵与次年春实际出发、战后问责连在一起。 [[4]](#note-4)

<a id="hs-event-5"></a>

5. **以水衡钱建平陵住宅。** 春季动用水衡所掌钱款建设平陵，为迁居民众营建住宅。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **安阳侯乐一支爵位承袭。** 本始二年，康侯记继承侯爵，十五年去世。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **驺丘敬侯宽一支后事。** 本始二年，因……获罪使人杀兄处死于市。 [[7]](#hs-note-7)

8. **稻夷侯定一支爵位承袭。** 本始二年，戴侯咸继承侯爵，四十二年去世。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **臯虞炀侯建一支爵位承袭。** 本始二年，节侯裒继承侯爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **温水侯安国一支失爵。** 本始二年，因……获罪上书为妖言，适逢赦免，免去侯爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

### 2. 黄霸因没有弹劾夏侯胜而入狱

[返回正文第2条](#event-2)

<a id="hs008-l659-e2"></a>

**[《汉书·宣帝纪》P017](../../sources/摘录/汉书-卷008-宣帝纪.md#p017)** · [仓内TXT L659](../../sources/本地分卷/汉书/汉书-卷008.md#L659)

> 夏五月，詔曰：「朕以眇身奉承祖宗，夙夜惟念孝武皇帝躬履仁義，選明將，討不服，匈奴遠遁，平氐、 羌、昆明、南越，百蠻鄉風，款塞來享；建太學，修郊祀，定正朔，協音律；封泰山，塞宣房，符瑞應，寶鼎出，白麟獲。功德茂盛，不能盡宣，而廟樂未稱，其議 奏。」有司奏請宜加尊號。六月庚午，尊孝武廟為世宗廟，奏盛德、文始、五行之舞，天子世世獻。武帝巡狩所幸之郡國，皆立廟。賜民爵一級，女子百戶牛酒。

**互校说明** 接既有黄霸、夏侯胜入狱所涉的同一武帝庙议。五月发议、六月正式尊庙、所巡郡国立庙分别读。

**原文原格**

> 黃霸，家在陽夏，以役使徙雲陽。以廉吏為河內守丞，遷為廷尉監，行丞相長史事。坐見知夏侯勝非詔書大不敬罪，久繫獄三歲，從勝學尚書。會赦，以賢良舉為揚州刺史，潁川太守。善化，男女異路，耕者讓畔，賜黃金百斤，秩中二千石。居潁川，入為太子傅，遷御史大夫。五鳳三年，代邴吉為丞相。封千八百戶。

**田延年因侵吞丧事钱款自杀：** [S021 陽成](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s021)。宣帝纪、通鉴均系本始二年。补录钱三千万为案卷数字，未独立核账；有定策功不等于案件已获赦，也不把死年后移到田广明案的前71年。 互校：[漢書/卷008](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7008.md#ref-b87b511073d839) · [漢書/卷066](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7066.md#ref-ef684379df60f8) · [漢書/卷018](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-15346429fe1699) · [資治通鑑/卷024](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7024.md#ref-212c87475f7a4b)。

<a id="sj020-e230-n"></a>
**黄霸因没有弹劾夏侯胜而入狱：** [S044 建成](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s044)。通鉴本始二年与汉书夏侯胜、黄霸传相接。补录“见知非诏书”是案由，不当作真实罪责的现代判断。两人年中入狱、跨两个冬天，不能把“系三岁”按整三十六个月强加到获赦年以后。 互校：[資治通鑑/卷024](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7024.md#ref-4e01630c195f8c) · [漢書/卷075](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7075.md#ref-664aa27abd9867) · [漢書/卷089](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7089.md#ref-6f988d99413d04)。

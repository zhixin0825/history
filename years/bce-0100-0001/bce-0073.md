# 公元前73年｜宣帝奖赏定策诸臣，封广陵诸子与燕王后裔

[← 公元前74年](bce-0074.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前72年 →](bce-0072.md)

本页收录已编史料及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **宣帝奖赏定策诸臣。** 宣帝对拥立自己的功臣增封。霍光、张安世取得大幅增加的封邑，杨敞虽已去世，朝廷仍把奖赏给其子；蔡义、范明友等人的爵邑也获增加。 [[1]](#note-1)

<a id="sj020-e186"></a>
<a id="赵充国以定策功封营平侯"></a>


<a id="event-2"></a>

2. **赵充国以定策功封营平侯。** 赵充国从陇西骑士起，在武帝、昭帝两朝多次从军，历任近侍与护军职务。朝廷以定策、安定宗庙的功劳封他为营平侯。 [[2]](#note-2)

<a id="sj020-e187"></a>
<a id="田延年以定策功封阳城侯"></a>


<a id="event-3"></a>

3. **田延年以定策功封阳城侯。** 田延年原是军吏，曾参与查办上官氏案而未及时封侯；他在废昌邑王、议立宣帝时态度坚决。朝廷以定策、安定宗庙的功劳封他为阳城侯。 [[3]](#note-3)

<a id="sj020-e188"></a>
<a id="王迁以定策功封平丘侯"></a>


<a id="event-4"></a>

4. **王迁以定策功封平丘侯。** 王迁来自卫地，熟悉文书，先做尚书郎和侍中，参与了新君的确定。朝廷以定策、安定宗庙的功劳封他为平丘侯。 [[4]](#note-4)

<a id="sj020-e189"></a>
<a id="田广明以定策功封昌水侯"></a>


<a id="event-5"></a>

5. **田广明以定策功封昌水侯。** 田广明历任地方军政官与礼宾官，曾任淮阳太守查办反案，后来以左冯翊等职参与废立。朝廷以定策、安定宗庙的功劳封他为昌水侯。 [[5]](#note-5)

<a id="sj060-guangling-sons-event"></a>

6. **广陵王刘胥诸子获封，刘弘为高密王。** 宣帝分出汉地封刘胥之子刘圣为朝阳侯、刘曾为平曲侯、刘昌为南利侯，又立少子刘弘为高密王。三侯封于七月壬子；刘弘封王也在本年，月份见同号考证。南利侯在传记中另有刘宝之名。 [[6]](#sj060-guangling-sons-note)

<a id="sj060-yan-heirs-event"></a>

7. **燕王刘旦后裔复得封爵，刘建立为广阳王。** 刘旦之子刘贤封安定侯，原太子刘建立为广阳王，奉祀父亲。刘贤封于七月壬子；刘建封王确定在本年，月次有不同记载。此次是新朝恢复后裔爵位，与前80年刘旦死后撤销燕国分别记载。 [[7]](#sj060-yan-heirs-note)

<a id="hs-event-8"></a>

8. **富户迁平陵与郡国教化。** 春正月招募郡国中资产百万以上的官民迁往平陵。遣持节使者晓谕各郡守、国相等二千石官员，要求善待百姓、推行教化。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **地震与荐举文学。** 四月庚午地震，命中央所辖郡和诸侯国各举文学成绩优等者一人。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **祥鸟报告、赦免与赏赐。** 五月有凤凰落于胶东、千乘的报告，朝廷大赦，按官阶给官吏赐爵，民众各升一级、孝行者两级，并按每百户给女子赐牛酒，本次租税不收。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **议戾太子谥号与园邑。** 六月，宣帝说旧太子葬于湖而还无谥号，命议谥、置园邑并按时奉祭。详情另见太子传。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **刘尊嗣赵王。** 刘尊嗣赵王。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **刘定嗣六安王。** 刘定嗣六安王。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **随桃顷侯赵光｜去世。** 表载随桃顷侯赵光一支本年记载去世。表中所载事项为去世。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **营平壮侯赵充国｜受封。** 表载营平壮侯赵充国一支本年有始封记载。表中所载事项为八月辛未封。 [[15]](#hs-note-15)

> 大將軍光稽首歸政，上謙讓委任焉。論定策功，益封大將軍光萬七千戶，車騎將軍光祿勳富平侯安世萬 戶。詔曰：「故丞相安平侯敞等居位守職，與大將軍光、車騎將軍安世建議定策，以安宗廟，功賞未加而薨。其益封敞嗣子忠及丞相陽平侯義、度遼將軍平陵侯明 友、前將軍龍雒侯增、太僕建平侯延年、太常蒲侯昌、諫大夫宜春侯譚、當塗侯平、杜侯屠耆堂、長信少府關內侯勝邑戶各有差。封御史大夫廣明為昌水侯，後將軍 充國為營平侯，大司農延年為陽城侯，少府樂成為爰氏侯，光祿大夫遷為平丘侯。賜右扶風德、典屬國武、廷尉光、宗正德、大鴻臚賢、詹事畸、光祿大夫吉、京輔 都尉廣漢爵皆關內侯。德、武食邑。」

**互校说明** 接既有定策合条，并与侯表各受封条交叉。后列官名、同名人及封户依不同史料校读，不据此重列每一侯国。

> 會昭帝崩，宣帝初立，緣恩行義，以本始元年中，裂漢地，盡以封廣陵王胥四子：一子為朝陽侯；一子為平曲侯；一子為南利侯；最愛少子弘，立以為高密王。

**说明：** 本篇“尽以封四子”为三侯一王，不能读成四侯再加弘。汉传圣、曾、宝、昌四侯另加弘，共五名；侯表仅对应朝阳圣、平曲曾、南利昌三侯，与史记封号数一致。宝与昌是否同人异名或传文讹衍未有充分证据，不另造第四侯国。昭帝死在前74，本始元年则为前73，篇中相对承接不能压平。

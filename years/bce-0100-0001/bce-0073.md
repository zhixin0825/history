# 公元前73年｜宣帝奖赏定策诸臣；赵充国以定策功封营平侯

**汉宣帝本始元年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e185"></a>
### 宣帝奖赏定策诸臣

宣帝对拥立自己的功臣增封。霍光、张安世取得大幅增加的封邑，杨敞虽已去世，朝廷仍把奖赏给其子；蔡义、范明友等人的爵邑也获增加。 [原文与说明](#sj020-e185-n)

<a id="sj020-e186"></a>
### 赵充国以定策功封营平侯

赵充国从陇西骑士起，在武帝、昭帝两朝多次从军，历任近侍与护军职务。朝廷以定策、安定宗庙的功劳封他为营平侯。 [原文与说明](#sj020-e186-n)

<a id="sj020-e187"></a>
### 田延年以定策功封阳城侯

田延年原是军吏，曾参与查办上官氏案而未及时封侯；他在废昌邑王、议立宣帝时态度坚决。朝廷以定策、安定宗庙的功劳封他为阳城侯。 [原文与说明](#sj020-e187-n)

<a id="sj020-e188"></a>
### 王迁以定策功封平丘侯

王迁来自卫地，熟悉文书，先做尚书郎和侍中，参与了新君的确定。朝廷以定策、安定宗庙的功劳封他为平丘侯。 [原文与说明](#sj020-e188-n)

<a id="sj020-e189"></a>
### 田广明以定策功封昌水侯

田广明历任地方军政官与礼宾官，曾任淮阳太守查办反案，后来以左冯翊等职参与废立。朝廷以定策、安定宗庙的功劳封他为昌水侯。 [原文与说明](#sj020-e189-n)

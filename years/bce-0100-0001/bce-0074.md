# 公元前74年｜昭帝去世，昌邑王被废，刘询入继；杨敞去世，安平侯由忠承接

[← 公元前75年](bce-0075.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前73年 →](bce-0073.md)

**汉昭帝元平元年**

昭帝本年去世，昌邑王被废后宣帝继位；本始元年从前73年起算。

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

1. **昭帝去世，昌邑王被废，刘询入继。** 昭帝去世，没有儿子继位。霍光等迎昌邑王刘贺入京，后来又决定将他废去，改立武帝曾孙刘病已。田延年力主废王，张安世参与商议，杨敞等大臣响应；赵充国、田广明、王迁也列入后来的定策功臣。于定国此前曾上书规劝昌邑王，因而得到新朝重用。 田延年通报废立时，丞相杨敞迟疑，杨敞之妻劝其立即与霍光同心。 昌邑群臣多被诛，王吉与龚遂因在国时屡进忠谏，减死为城旦。 丙吉原奉命迎刘贺，后来奏请详审武帝曾孙刘病已能否入继，最终与宗正刘德迎曾孙。 夏侯胜曾阻谏刘贺出行，刘贺废后，霍光令他授皇太后《尚书》。 赵广汉也参加废昌邑王、立宣帝的议策。 太仆丞张敞劝昌邑王先褒顾命大臣，在刘贺被废后获擢任。 王式受审时说，他以《诗》三百五篇反复劝谏刘贺，虽无谏书，仍获减死。 侍御史严延年随后奏劾霍光擅行废立，奏议未予处理。 [[1]](#note-1)

<a id="sj020-e176"></a>

2. **杨敞去世，安平侯由忠承接。** 八月，杨敞去世，儿子忠承袭安平侯爵。新君初立之际，丞相职位又要另选人接替。 [[2]](#note-2)

<a id="sj020-e178"></a>

<a id="event-3"></a>

3. **蔡义任丞相，封阳平侯。** 九月，蔡义出任丞相，封阳平侯。蔡义来自温县，研习韩诗，做过博士，又向昭帝讲授诗学；到任相时已经年老，朝廷仍以帝师和经学资历推重他。 [[3]](#note-3)

4. **韩增任前将军，赵充国任后将军，张安世由右将军升车骑将军。** 田广明升御史大夫。昭帝去世、朝廷先后迎立新君的这一年，中枢军政职位也在调整。 [[4]](#note-4)

<a id="hs071-l8721-e1"></a>

**[《汉书·隽疏于薛平彭传》P015](../../sources/摘录/汉书-卷071-隽疏于薛平彭传.md#p015)** · [仓内TXT L8721](../../sources/本地分卷/汉书/汉书-卷071.md#L8721)

> 會昭帝崩，昌邑王征即位，行淫亂，定國上書諫。後王廢，宣帝立，大將軍光領尚書事，條奏群臣諫昌邑王者皆超遷。定國由是為光祿大夫，平尚書事，甚見任用。

**互校说明** 卷007、卷008与卷068同见此年先后废立。

<a id="hs072-l8755-e1"></a>

**[《汉书·王贡两龚鲍传》P012](../../sources/摘录/汉书-卷072-王贡两龚鲍传.md#p012)** · [仓内TXT L8755](../../sources/本地分卷/汉书/汉书-卷072.md#L8755)

> 久之，昭帝崩，亡嗣，大將軍霍光秉政，遣大鴻臚宗正迎昌邑王。吉即奏書戒王曰：「臣聞高宗諒闇，三年不言。今大王以喪事徵，宜日夜哭泣悲哀而已，慎毋有所發。且何獨喪事，凡南面之君何言哉？天不言，四時行焉，百物生焉，願大王察之。大將軍仁愛勇智，忠信之德天下莫不聞，事孝武皇帝二十餘年未嘗有過。先帝棄群臣，屬以天下，寄幼孤焉，大將軍抱持幼君襁褓之中，布政施教，海內晏然，雖周公、伊尹亡以加也。今帝崩亡嗣，大將軍惟思可以奉宗廟者，攀援而立大王，其仁厚豈有量哉！臣願大王事之敬之，政事壹聽之，大王垂拱南面而已。願留意，嘗以為念。」

**互校说明** 本传补昌邑中尉王吉于刘贺进京前劝其谨守大丧并听霍光。

<a id="hs072-l8756-e1"></a>

**[《汉书·王贡两龚鲍传》P013](../../sources/摘录/汉书-卷072-王贡两龚鲍传.md#p013)** · [仓内TXT L8756](../../sources/本地分卷/汉书/汉书-卷072.md#L8756)

> 王既到，即位二十餘日以行淫亂廢。昌邑群臣坐在國時不舉奏王罪過，令漢朝不聞知，又不能輔道，陷王大惡，皆下獄誅。唯吉與郎中令龔遂以忠直數諫正得減死，髡為城旦。

**互校说明** 《霍光传》有群臣处置，本传点明王吉及龚遂的例外。

<a id="hs073-l8836-e1"></a>

**[《汉书·韦贤传》P013](../../sources/摘录/汉书-卷073-韦贤传.md#p013)** · [仓内TXT L8836](../../sources/本地分卷/汉书/汉书-卷073.md#L8836)

> 昭帝崩，無嗣，大將軍霍光與公卿共尊立孝宣帝。帝初即位，賢以與謀議，安宗廟，賜爵關內侯，食邑。

**互校说明** 此为即位初获关内侯，和本始三年始封扶阳列侯有别。

<a id="hs074-l8877-e1"></a>

**[《汉书·魏相丙吉传》P010](../../sources/摘录/汉书-卷074-魏相丙吉传.md#p010)** · [仓内TXT L8877](../../sources/本地分卷/汉书/汉书-卷074.md#L8877)

> 昭帝崩，亡嗣，大將軍光遣吉迎昌邑王賀。賀即位，以行淫亂廢，光與車騎將軍張安世諸大臣議所立，未定。吉奏記光曰：「將軍事孝武皇帝，受襁褓之屬，任天下之寄，孝昭皇帝早崩亡嗣，海內憂懼，欲亟聞嗣主，發喪之日以大誼立後，所立非其人，復以大誼廢之，天下莫不服焉。方今社稷宗廟群生之命在將軍之壹舉。竊伏聽於眾庶，察其所言，諸侯宗室在列位者，未有所聞於民間也。而遺詔所養武帝曾孫名病已在掖庭外家者，吉前使居郡邸時見其幼少，至今十八九矣，通經術，有美材，行安而節和。願將軍詳大議，參以蓍龜，豈宜褒顯，先使入侍，令天下昭然知之，然後決定大策，天下幸甚！」光覽其議，遂尊立皇曾孫，遣宗正劉德與吉迎曾孫於掖庭。宣帝初即位，賜吉爵關內侯。

**互校说明** 《宣帝纪》《霍光传》同系元平元年。关内侯是初立后的赏，不同后来的博阳侯。

<a id="hs075-l8890-e1"></a>

**[《汉书·眭两夏侯京翼李传》P002](../../sources/摘录/汉书-卷075-眭两夏侯京翼李传.md#p002)** · [仓内TXT L8890](../../sources/本地分卷/汉书/汉书-卷075.md#L8890)

> 後五年，孝宣帝興於民間，即位，徵孟子為郎。

**互校说明** 昭帝元凤三年前78到元平元年前74首尾计五年。只确认本年即位；征眭弘子为传文续叙，失载月日。

<a id="hs075-l8894-e1"></a>

**[《汉书·眭两夏侯京翼李传》P006](../../sources/摘录/汉书-卷075-眭两夏侯京翼李传.md#p006)** · [仓内TXT L8894](../../sources/本地分卷/汉书/汉书-卷075.md#L8894)

> 會昭帝崩，昌邑王嗣立，數出。勝當乘輿前諫曰：「天久陰而不雨，臣下有謀上者，陛下出欲何之？」王怒，謂勝為祅言，縛以屬吏。吏白大將軍霍光，光不舉法。是時，光與車騎將軍張安世謀欲廢昌邑王。光讓安世以為泄語，安世實不言。乃召問勝，勝對言：「在洪範傳曰『皇之不極，厥罰常陰，時則下人有伐上者』，惡察察言，故云臣下有謀。」光、安世大驚，以此益重經術士。後十餘日，光卒與安世共白太后，廢昌邑王，尊立宣帝。光以為群臣奏事東宮，太后省政，宜知經術，白令勝用尚書授太后。遷長信少府，賜爵關內侯，以與謀廢立，定策安宗廟，益千戶。

**互校说明** 《通鉴》卷024将谏王与授经随元平元年废立接叙；传中的车驾问答是人物自陈，非独立符验。

<a id="hs076-l8950-e1"></a>

**[《汉书·赵尹韩张两王传》P002](../../sources/摘录/汉书-卷076-赵尹韩张两王传.md#p002)** · [仓内TXT L8950](../../sources/本地分卷/汉书/汉书-卷076.md#L8950)

> 是時，昌邑王徵即位，行淫亂，大將軍霍光與群臣共廢王，尊立宣帝。

**互校说明** 朝廷废立归元平元年，赐爵另见前73。

<a id="hs076-l8979-e1"></a>

**[《汉书·赵尹韩张两王传》P031](../../sources/摘录/汉书-卷076-赵尹韩张两王传.md#p031)** · [仓内TXT L8979](../../sources/本地分卷/汉书/汉书-卷076.md#L8979)

> 會昌邑王徵即位，動作不由法度，敞上書諫曰：「孝昭皇帝蚤崩無嗣，大臣憂懼，選賢聖承宗廟，東迎之日，唯恐屬車之行遲。今天子以盛年初即位，天下莫不拭目傾耳，觀化聽風。國輔大臣未褒，而昌邑小輦先遷，此過之大者也。」後十餘日王賀廢，敞以切諫顯名，擢為豫州刺史。

**互校说明** 《通鉴》元平元年载本奏。

<a id="hs088-l9518-e1"></a>

**[《汉书·儒林传》P039](../../sources/摘录/汉书-卷088-儒林传.md#p039)** · [仓内TXT L9518](../../sources/本地分卷/汉书/汉书-卷088.md#L9518)

> 昭帝崩，昌邑王嗣立，以行淫亂廢，昌邑群臣皆下獄誅，唯中尉王吉、郎中令龔遂以數諫減死論。式繫獄當死，治事使者責問曰：「師何以無諫書？」式對曰：「臣以《詩》三百五篇朝夕授王，至於忠臣孝子之篇，未嘗不為王反覆誦之也；至於危亡失道之君，未嘗不流涕為王深陳之也。臣以三百五篇諫，是以亡諫書。」使者以聞，亦得減死論，歸家不教授。

**互校说明** 与《霍光传》同一废立案；本段补王式以讲《诗》劝戒为辞，免死。

<a id="hs089-l9572-e1"></a>

**[《汉书·循吏传》P028](../../sources/摘录/汉书-卷089-循吏传.md#p028)** · [仓内TXT L9572](../../sources/本地分卷/汉书/汉书-卷089.md#L9572)

> 會昭帝崩，亡子，昌邑王賀嗣立，官屬皆徵入。王相安樂遷長樂衛尉，遂見安樂，流涕謂曰：「王立為天子，日益驕溢，諫之不復聽，今哀痛未盡，日與近臣飲食作樂，鬥虎豹，召皮軒，車九流，驅馳東西，所為誖道。古制寬，大臣有隱退，今去不得，陽狂恐知，身死為世戮，奈何？君，陛下故相，宜極諫爭。」王即位二十七日，卒以淫亂廢。昌邑群臣坐陷王於惡不道，皆誅，死者二百餘人，唯遂與中尉王陽以數諫爭得減死，髡為城旦。

**互校说明** 昌邑王废黜同案，龚遂和王阳因屡次进谏减死。王阳即卷072称字为子阳的王吉。

<a id="hs090-l9620-e1"></a>

**[《汉书·酷吏传》P039](../../sources/摘录/汉书-卷090-酷吏传.md#p039)** · [仓内TXT L9620](../../sources/本地分卷/汉书/汉书-卷090.md#L9620)

> 會昭帝崩，昌邑王嗣位，淫亂，霍將軍憂懼，與公卿議廢之，莫敢發言。延年按劍，延叱群臣，即日議決，語在光傳。

**互校说明** 废立同案，田延年促断的过程互见《霍光传》。

<a id="hs090-l9623-e1"></a>

**[《汉书·酷吏传》P042](../../sources/摘录/汉书-卷090-酷吏传.md#p042)** · [仓内TXT L9623](../../sources/本地分卷/汉书/汉书-卷090.md#L9623)

> 是時大將軍霍光廢昌邑王，尊立宣帝。宣帝初即位，延年劾奏光「擅廢立，亡人臣禮，不道」。奏雖寢，然朝廷肅焉敬憚。

**互校说明** 合入废立旧条，补当时严延年对霍光的奏劾未被采纳。

<a id="hs054-l7944-e1"></a>

# 公元前74年｜昭帝去世，昌邑王被废，刘询入继；杨敞去世，安平侯由忠承接

[← 公元前75年](bce-0075.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前73年 →](bce-0073.md)

**汉昭帝元平元年**

昭帝本年去世，昌邑王被废后宣帝继位；本始元年从前73年起算。

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **昭帝去世，昌邑王被废，刘询入继。** 昭帝去世，没有儿子继位。霍光等迎昌邑王刘贺入京，后来又决定将他废去，改立武帝曾孙刘病已。田延年力主废王，张安世参与商议，杨敞等大臣响应；赵充国、田广明、王迁也列入后来的定策功臣。于定国此前曾上书规劝昌邑王，因而得到新朝重用。 [[1]](#note-1)

<a id="sj020-e176"></a>
<a id="杨敞去世安平侯由忠承接"></a>


<a id="event-2"></a>

2. **杨敞去世，安平侯由忠承接。** 八月，杨敞去世，儿子忠承袭安平侯爵。新君初立之际，丞相职位又要另选人接替。 [[2]](#note-2)

<a id="sj020-e178"></a>
<a id="蔡义任丞相封阳平侯"></a>


<a id="event-3"></a>

3. **蔡义任丞相，封阳平侯。** 九月，蔡义出任丞相，封阳平侯。蔡义来自温县，研习韩诗，做过博士，又向昭帝讲授诗学；到任相时已经年老，朝廷仍以帝师和经学资历推重他。 [[3]](#note-3)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-4"></a>

4. **韩增任前将军，赵充国任后将军，张安世由右将军升车骑将军。** 田广明升御史大夫。昭帝去世、朝廷先后迎立新君的这一年，中枢军政职位也在调整。 [[4]](#note-4)

### 2. 杨敞去世，安平侯由忠承接

**原文原格**

> 楊敞，家在華陰。故給事大將軍幕府，稍遷至大司農，為御史大夫。元鳳六年，代王訢為丞相，封二千戶。立二年，病死。子賁代立，十三年病死。子翁君代立，為典屬國。三歲，以季父惲故出惡言，繫獄當死，得免，為庶人，國除。

**[《史记》卷020《建元以来侯者年表》｜陽平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s017)**

#### 卷022｜将相表互见与异说

[本年原行R133](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r133) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0074)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

杨敞之死、蔡义任相接本页原叙事。史表韩曾、汉表韩增，按同一龙雒侯支辨认，不拆成二人；旧字原存。史表给韩增四月甲申、赵充国和张安世五月丁酉，汉019同元平年但未为每人都记该月日，正文不补唯一公历日期。田广明的昌水侯封赏在[前73年](bce-0073.md#sj020-e189)，任御史不等于同日封侯。

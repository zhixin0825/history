# 公元前74年｜昭帝去世，昌邑王被废，刘询入继；杨敞去世，安平侯由忠承接

[← 公元前75年](bce-0075.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前73年 →](bce-0073.md)

**汉昭帝元平元年**

昭帝本年去世，昌邑王被废后宣帝继位；本始元年从前73年起算。

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e175"></a>
### 昭帝去世，昌邑王被废，刘询入继

昭帝去世，没有儿子继位。霍光等迎昌邑王刘贺入京，后来又决定将他废去，改立武帝曾孙刘病已。田延年力主废王，张安世参与商议，杨敞等大臣响应；赵充国、田广明、王迁也列入后来的定策功臣。于定国此前曾上书规劝昌邑王，因而得到新朝重用。 [原文与说明](#sj020-e175-n)

<a id="sj020-e176"></a>
### 杨敞去世，安平侯由忠承接

八月，杨敞去世，儿子忠承袭安平侯爵。新君初立之际，丞相职位又要另选人接替。 [原文与说明](#sj020-e176-n)

<a id="sj020-e178"></a>
### 蔡义任丞相，封阳平侯

九月，蔡义出任丞相，封阳平侯。蔡义来自温县，研习韩诗，做过博士，又向昭帝讲授诗学；到任相时已经年老，朝廷仍以帝师和经学资历推重他。 [原文与说明](#sj020-e178-n)

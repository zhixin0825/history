**汉昭帝元凤六年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e166"></a>
### 张安世封富平侯

右将军、光禄勋张安世受封富平侯。他是御史大夫张汤之子，武帝时已在尚书机构办事，昭帝朝长期参与辅政；熟习政务与谨慎任事，是这次封赏的理由。 [原文与说明](#sj020-e166-n)

<a id="sj020-e173"></a>
### 王谭开始记宜春侯元年

王谭接续父亲一支，开始记宜春侯元年。父亲的丞相职位不随侯爵一同传给他。 [原文与说明](#sj020-e173-n)

<a id="sj020-e174"></a>
### 杨敞任丞相，封安平侯

杨敞升为丞相，封安平侯。他出身华阴，早在大将军幕府办事，历任大司农、御史大夫，才走到相位。 [原文与说明](#sj020-e174-n)

<a id="sj020-e166-n"></a>
**张安世封富平侯：** [S009 富平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s009)。恩泽表元凤六年十一月乙丑。补称辅政十三年是累计履历，不在本年重演十三年任官；杜陵为传记用地名，不能反推出生时该县已有后来名称。 互校：[漢書/卷018](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7018) · [漢書/卷059](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7059)。

<a id="sj020-e173-n"></a>
**王谭开始记宜春侯元年：** [S015 宜春](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s015)。恩泽表元凤六年嗣，父卒在前76年十二月。补录说儿子为属国都尉，具体任职时间未明，不自动安排在本年。 互校：[漢書/卷018](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7018)。

<a id="sj020-e174-n"></a>
**杨敞任丞相，封安平侯：** [S016 安平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s016)。元凤六年二月见汉恩泽表；补录概括的逐次升官为前情，不将每一官职同时授在本年。 互校：[漢書/卷007](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7007) · [漢書/卷018](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7018) · [漢書/卷066](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7066)。

**未能唯一归年的后续与评论：**以下只是阅读入口，不表示均发生在本年。

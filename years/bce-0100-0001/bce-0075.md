本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="张安世封富平侯"></a>
### 张安世封富平侯

<a id="event-1"></a>

1. **张安世封富平侯。** 右将军、光禄勋张安世受封富平侯。他是御史大夫张汤之子，武帝时已在尚书机构办事，昭帝朝长期参与辅政；熟习政务与谨慎任事，是这次封赏的理由。 [[1]](#note-1)

<a id="sj020-e173"></a>
<a id="王谭开始记宜春侯元年"></a>
### 王谭开始记宜春侯元年

<a id="event-2"></a>

2. **王谭开始记宜春侯元年。** 王谭接续父亲一支，开始记宜春侯元年。父亲的丞相职位不随侯爵一同传给他。 [[2]](#note-2)

<a id="sj020-e174"></a>
<a id="杨敞任丞相封安平侯"></a>
### 杨敞任丞相，封安平侯

<a id="event-3"></a>

3. **杨敞任丞相，封安平侯。** 杨敞升为丞相，封安平侯。他出身华阴，早在大将军幕府办事，历任大司农、御史大夫，才走到相位。 [[3]](#note-3)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-4"></a>

4. **九月，范明友再次以度辽将军领兵，出击乌桓。** 他此时已经是平陵侯，先前出征、受封与这一次军事行动各有先后。 [[4]](#note-4)

#### 卷022｜将相表互见与异说

[本年原行R132](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r132) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0075)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史表本年两项分开读：杨敞接相已见本页，史作十一月乙丑；汉019十一月己丑，汉018却记本年二月，既有注保留其差。范明友九月庚寅再击乌桓与前78—77年初次任将、战后封侯不是同一时点；不再给他初封一次平陵侯 · [昭帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7007.md#ref-31033e73316cda)。

# 公元前75年｜张安世封富平侯；王谭开始记宜春侯元年

[← 公元前76年](bce-0076.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前74年 →](bce-0074.md)

**汉昭帝元凤六年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020-e166"></a>
<a id="张安世封富平侯"></a>


<a id="event-1"></a>

1. **张安世封富平侯。** 右将军、光禄勋张安世受封富平侯。他是御史大夫张汤之子，武帝时已在尚书机构办事，昭帝朝长期参与辅政；熟习政务与谨慎任事，是这次封赏的理由。 [[1]](#note-1)

<a id="sj020-e173"></a>
<a id="王谭开始记宜春侯元年"></a>


<a id="event-2"></a>

2. **王谭开始记宜春侯元年。** 王谭接续父亲一支，开始记宜春侯元年。父亲的丞相职位不随侯爵一同传给他。 [[2]](#note-2)

<a id="sj020-e174"></a>
<a id="杨敞任丞相封安平侯"></a>


<a id="event-3"></a>

3. **杨敞任丞相，封安平侯。** 杨敞升为丞相，封安平侯。他出身华阴，早在大将军幕府办事，历任大司农、御史大夫，才走到相位。 [[3]](#note-3)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-4"></a>

4. **九月，范明友再次以度辽将军领兵，出击乌桓。** 他此时已经是平陵侯，先前出征、受封与这一次军事行动各有先后。 [[4]](#note-4)

<a id="sj052-zichuan-yi-event"></a>

5. **菑川顷王刘遗去世，儿子刘终古承位。** 汉表列刘遗元封二年前109元年、在位三十五年，下一年元平元年前74列终古元年，故将本次承袭归前75。本篇世系写三十六年，原文留作异数，不为凑它把相邻世代全部错移。 [[5]](#sj052-zichuan-yi-note)

<a id="hs-event-6"></a>

6. **募郡国徒筑玄菟城。** 正月招募郡国徒役，赴辽东筑玄菟城。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **夏大赦并准豆粟代赋。** 夏大赦。朝廷考虑谷价过低伤农，准三辅和太常郡用豆粟代当年赋。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **宁阳节侯恬一支爵位承袭。** 元凤六年，安侯庆忌继承侯爵，十八年去世。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **十一月乙丑分封王子侯。** 《王子侯表》列十一月乙丑受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **宜春敬侯王欣｜承爵。** 表载宜春敬侯王欣一支本年记载侯位承袭。表中所载事项为康侯谭承爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **安平敬侯杨敞｜受封。** 《汉书》侯籍列安平敬侯杨敞本年受封，所引月份、干支依表保留。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **富平敬侯张安世｜受封。** 《汉书》侯籍列富平敬侯张安世本年受封，所引月份、干支依表保留。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **昭帝朝复校历法，太初历居首。** 复候至元凤六年，邓平系太初法及徐万且、徐禹治太初法课第一，寿王、李信的调历仍疏。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **筑辽东、玄菟城。** 《汉书》在本年记载筑辽东、玄菟城。 [[15]](#hs-note-15)

[完整原文](../../sources/摘录/史记-卷020-建元以来侯者年表.md) · [逐格去向](../../meta/记录/史记-卷020-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷020-纪年与异说.md)。初封、增邑、继承与任官分开；月日未明不补，谥号为后称，国除不一律等于处死。

<a id="sj020-e166-n"></a>
**张安世封富平侯：** [S009 富平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s009)。[《汉书·外戚恩泽侯表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-bd175116e9d229)元凤六年十一月乙丑封；补录所说辅政十三年起点未清，不能凭它精确倒推一次未有明年的任职。汉表另说封侯十三年薨，由前75至前62年之差13可比，两种十三未必指同一段时间。杜陵是后称地名，不反推出生时县名。 互校：[漢書/卷018](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-c491ee270a13f6) · [漢書/卷059](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7059.md#ref-36900cea4a9742)。

<a id="sj020-e173-n"></a>
**王谭开始记宜春侯元年：** [S015 宜春](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s015)。恩泽表元凤六年嗣，父卒在前76年十二月。补录说儿子为属国都尉，具体任职时间未明，不自动安排在本年。 互校：[漢書/卷018](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-bcc735a639427b)。

<a id="sj020-e174-n"></a>
**杨敞任丞相，封安平侯：** [S016 安平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s016)。元凤六年二月见汉恩泽表；补录概括的逐次升官为前情，不将每一官职同时授在本年。 互校：[漢書/卷007](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7007.md#ref-3a4ba4c7a068e8) · [漢書/卷018](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-a672f8f38b0a8e) · [漢書/卷066](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7066.md#ref-78f43db2d354ca)。

**未能唯一归年的后续与评论：**以下只是阅读入口，不表示均发生在本年。

**王谭属国都尉任职：** 补录只在王訢之子代立后说为属国都尉，汉表前75年起侯年；任官日并无同样证据，不混作一次继承。 [考证记录](../../meta/考证/史记-卷020-纪年与异说.md#u05)

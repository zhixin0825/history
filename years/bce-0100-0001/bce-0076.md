# 公元前76年｜广陵王入朝获赏，丞相王訢去世

[← 公元前77年](bce-0077.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前75年 →](bce-0075.md)

**汉昭帝元凤五年**

本页收录已编史料及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj060-guangling-audience-event"></a>

1. **正月，广陵王刘胥入朝，再获增邑和赏赐。** 朝廷为刘胥增加食邑一万一千户，赐钱二千万、黄金二百斤、剑两把、安车一辆及乘马两驷。此次入朝与前86年的增封相隔十年。 [[1]](#sj060-guangling-audience-note)

<a id="sj020"></a>
<a id="军政受封与侯国的接续"></a>

<a id="sj020-e172"></a>
<a id="丞相王訢去世"></a>


<a id="event-1"></a>

2. **丞相王訢去世。** 王訢去世，宜春侯爵随后由子谭承接。 [[2]](#note-1)

<a id="hs-event-3"></a>

3. **夏大旱。** 夏季发生严重旱灾。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **征调人手屯辽东。** 六月征发各地恶少年及被告劾后逃亡的吏员，赴辽东屯驻。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **罢象郡。** 秋，撤销象郡，辖地分属郁林、牂柯。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **纪文记冬雷。** 十一月，史书记录雷声很大。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **利昌康侯嘉一支爵位承袭。** 元凤五年，戴侯乐继承侯爵，十二年去世。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **繁安夷侯忠一支爵位承袭。** 元凤五年，顷侯嘉继承侯爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **十一月庚子分封王子侯。** 《王子侯表》列十一月庚子受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[10]](#hs-note-10)

### 1. 正月，广陵王刘胥入朝，再获增邑和赏赐

[返回正文第1条](#sj060-guangling-audience-event)

<a id="hs007-l629-e1"></a>

**[《汉书·昭帝纪》P064](../../sources/摘录/汉书-卷007-昭帝纪.md#p064)** · [仓内TXT L629](../../sources/本地分卷/汉书/汉书-卷007.md#L629)

<a id="sj060-cite-037"></a>

**[《史记·三王世家》P022｜昭帝初年的广陵恩赏概述](../../sources/摘录/史记-卷060-三王世家.md#p022)**

> 會孝武帝崩，孝昭帝初立，先朝廣陵王胥，厚賞賜金錢財幣，直三千餘萬，益地百里，邑萬戶。

**说明：** 本段把武帝崩、昭帝初立与广陵入朝厚赐概叙在一起；汉纪、汉传可分前86的初次增封与元凤五年前76的入朝。三千余万为本篇财币估值概数、百里为地域、万户为食邑，不能相加，也不能自定金价把它硬合于汉纪钱二千万。

<!-- /sj060-cite-037 -->

<a id="sj060-cite-038"></a>

**[《汉书》卷007互校｜L629](../../sources/本地分卷/汉书/汉书-卷007.md#L629)**

> 五年春正月，廣陵王來朝，益國萬一千戶，賜錢二千萬，黃金二百斤，劍二，安車一，乘馬二駟。

**说明：** 正文采用本纪明列的元凤五年正月、一万一千户、二百斤及两驷；两驷为八匹马，不另补车制。

<!-- /sj060-cite-038 -->

<a id="sj060-cite-039"></a>

**[《汉书》卷063互校｜L8324](../../sources/本地分卷/汉书/汉书-卷063.md#L8324)**

> 元鳳中入朝，復益萬戶，賜錢二千萬，黃金二千斤，安車駟馬寶劍。

**说明：** 汉传作万户、黄金二千斤，与本纪一万一千户、二百斤不同；史记本段又有估值、增地口径，三者原数各存，不能默改一个零或把相差一千户认作另一场已证实的封赏。

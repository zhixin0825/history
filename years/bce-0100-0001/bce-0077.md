# 公元前77年｜田千秋去世，田顺承富民侯；傅介子刺杀楼兰王，受封义阳侯

[← 公元前78年](bce-0078.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前76年 →](bce-0076.md)

**汉昭帝元凤四年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **田千秋去世，田顺承富民侯。** 丞相田千秋去世，田顺承接父亲的富民侯爵。田顺后来领兵，并不是同时继承父亲的丞相职位。 [[1]](#note-1)

<a id="sj020-e169"></a>
<a id="傅介子刺杀楼兰王受封义阳侯"></a>


<a id="event-2"></a>

2. **傅介子刺杀楼兰王，受封义阳侯。** 傅介子奉使楼兰，在宴饮中杀死楼兰王，汉廷随后另立新王。朝廷以不用大军而完成报复为功，封傅介子为义阳侯。他此前从军为郎，任平乐监，此次出使把外交、武力与爵赏连在一起。 [[2]](#note-2)

<a id="sj020-e171"></a>
<a id="王訢任丞相封宜春侯"></a>


<a id="event-3"></a>

3. **王訢任丞相，封宜春侯。** 田千秋去世后，王訢由御史大夫升为丞相，封宜春侯。他从地方小吏做起，曾在右辅地区办理武帝出巡所需的供给，后来任右扶风，才进入中央最高官列。 [[3]](#note-3)

<a id="sj020-e184"></a>
<a id="范明友出击乌桓封平陵侯"></a>


<a id="event-4"></a>

4. **范明友出击乌桓，封平陵侯。** 范明友以度辽将军出击乌桓，因战功封平陵侯。他来自陇西，熟悉边事，曾承担西羌方面的使职，又是霍光的女婿，军事经历和朝廷亲缘同时影响其地位。 [[4]](#note-4)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-5"></a>

5. **王訢接任丞相以后，杨敞从大司农升为御史大夫。** 两人的升迁使丞相与御史两处职位相继得到补充。 [[5]](#note-5)

#### 卷022｜将相表互见与异说

[本年原行R130](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r130) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0077)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

田千秋之死与王訢接相接本页既有两事。史表两条均作三月，汉019为正月甲戌千秋卒、二月乙丑王訢任相；汉007也把千秋卒置正月。侯名史作富春，汉表及既有侯统为宜春，正文沿宜春。杨敞御史任命汉表亦在二月乙丑 · [昭帝纪互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7007.md#ref-2399bd7fcf5440)。

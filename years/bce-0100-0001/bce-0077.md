# 公元前77年｜田千秋去世，田顺承富民侯；傅介子刺杀楼兰王，受封义阳侯

**汉昭帝元凤四年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e150"></a>
### 田千秋去世，田顺承富民侯

丞相田千秋去世，田顺承接父亲的富民侯爵。田顺后来领兵，并不是同时继承父亲的丞相职位。 [原文与说明](#sj020-e150-n)

<a id="sj020-e169"></a>
### 傅介子刺杀楼兰王，受封义阳侯

傅介子奉使楼兰，在宴饮中杀死楼兰王，汉廷随后另立新王。朝廷以不用大军而完成报复为功，封傅介子为义阳侯。他此前从军为郎，任平乐监，此次出使把外交、武力与爵赏连在一起。 [原文与说明](#sj020-e169-n)

<a id="sj020-e171"></a>
### 王訢任丞相，封宜春侯

田千秋去世后，王訢由御史大夫升为丞相，封宜春侯。他从地方小吏做起，曾在右辅地区办理武帝出巡所需的供给，后来任右扶风，才进入中央最高官列。 [原文与说明](#sj020-e171-n)

<a id="sj020-e184"></a>
### 范明友出击乌桓，封平陵侯

范明友以度辽将军出击乌桓，因战功封平陵侯。他来自陇西，熟悉边事，曾承担西羌方面的使职，又是霍光的女婿，军事经历和朝廷亲缘同时影响其地位。 [原文与说明](#sj020-e184-n)

**田千秋去世，田顺承富民侯：** [S004 富民](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s004)。昭帝纪元凤四年正月明记父卒；汉表同年子顺嗣，与补录“至昭帝时病死”接合。 互校：[漢書/卷007](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7007) · [漢書/卷018](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7018) · [資治通鑑/卷024](https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B7024)。

<a id="sj020-e169-n"></a>
**傅介子刺杀楼兰王，受封义阳侯：** [S010 義陽](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s010)。补诏所谓“以直报怨”是汉廷正当性表达，不是编者替刺杀作道德裁判。封邑补称千三百、汉表七百五十九有差。楼兰王死、立尉屠耆与改名鄯善详见汉书西域传，不将诸事硬合为受封当日。 互校：[漢書/卷017](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7017) · [漢書/卷096上](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7096%E4%B8%8A) · [資治通鑑/卷024](https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B7024)。

<a id="sj020-e171-n"></a>
**王訢任丞相，封宜春侯：** [S015 宜春](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s015)。补录记元凤三年，昭帝纪与恩泽表明确四年二月，采用前77年。旧地方任职为此前经历，未给每次升迁捏造年份。 互校：[漢書/卷007](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7007) · [漢書/卷018](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7018) · [漢書/卷066](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7066) · [資治通鑑/卷024](https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B7024)。

**范明友出击乌桓，封平陵侯：** [S019 平陵](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s019)。补录把本行放在宣帝段，但初封确在昭帝元凤四年；采用昭帝纪、汉功臣表和通鉴。不得因栏目标题把出征后移至宣帝朝。具体“功”沿朝廷奏赏口径，不据此确认所有杀伤数。 互校：[漢書/卷007](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7007) · [漢書/卷017](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7017) · [資治通鑑/卷024](https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B7024)。

1. **田千秋去世，王訢继相，杨敞任御史大夫。** 丞相田千秋去世，田顺承接父亲的富民侯爵。田顺后来领兵，并不是同时继承父亲的丞相职位。王訢任丞相，封宜春侯。田千秋去世后，王訢由御史大夫升为丞相，封宜春侯。他从地方小吏做起，曾在右辅地区办理武帝出巡所需的供给，后来任右扶风，才进入中央最高官列。王訢接任丞相以后，杨敞从大司农升为御史大夫。两人的升迁使丞相与御史两处职位相继得到补充。 [[1]](#note-1)

<a id="sj020-e169"></a>
<a id="傅介子刺杀楼兰王受封义阳侯"></a>


<a id="event-2"></a>

2. **傅介子刺杀楼兰王，受封义阳侯。** 傅介子奉使楼兰，在宴饮中杀死楼兰王，汉廷随后另立新王。朝廷以不用大军而完成报复为功，封傅介子为义阳侯。他此前从军为郎，任平乐监，此次出使把外交、武力与爵赏连在一起。 尉屠耆入国前请在伊循屯田。朝廷派司马一人、吏士四十人，后改置都尉。 [[2]](#note-2)

<a id="sj020-e184"></a>
<a id="范明友出击乌桓封平陵侯"></a>


<a id="event-4"></a>

3. **范明友出击乌桓，封平陵侯。** 范明友以度辽将军出击乌桓，因战功封平陵侯。他来自陇西，熟悉边事，曾承担西羌方面的使职，又是霍光的女婿，军事经历和朝廷亲缘同时影响其地位。 [[3]](#note-4)

<a id="hs-event-6"></a>

4. **昭帝加元服并免部分口赋。** 正月丁亥加元服、谒高庙。朝廷按身份赐金帛牛酒爵位，免本年及次年口赋、免收部分欠缴更赋，天下大酺五日。 [[4]](#hs-note-6)

<a id="hs-event-7"></a>

5. **孝文庙失火，太常受处分。** 五月丁丑孝文庙正殿起火，君臣素服、调人修治，六日告成。主管官员被劾，逢赦后太常江德仍免为庶人。 [[5]](#hs-note-7)

<a id="hs-event-8"></a>

6. **六月大赦。** 六月，朝廷颁布大赦。 [[6]](#hs-note-8)

<a id="hs-event-9"></a>

7. **富民定侯车千秋｜承爵。** 表载富民定侯车千秋一支本年记载侯位承袭。表中所载事项为侯顺承爵。 [[7]](#hs-note-9)

<a id="hs-event-10"></a>

8. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[8]](#hs-note-10)

<a id="hs-event-11"></a>

9. **客星在紫宫。** [[9]](#hs-note-11)

<a id="hs-event-12"></a>

10. **龟兹杀轮台屯田校尉赖丹。** 昭帝授原杅弥质子赖丹校尉，令率兵田轮台。龟兹贵人姑翼劝国王杀赖丹，龟兹随后向汉廷谢罪。 [[10]](#hs-note-12)

### 2. 傅介子刺杀楼兰王，受封义阳侯

[返回正文第2条](#event-2)

<a id="hs096-l9963-e2"></a>

**[《汉书·西域传》P015](../../sources/摘录/汉书-卷096-西域传.md#p015)** · [仓内TXT L9963](../../sources/本地分卷/汉书/汉书-卷096.md#L9963)

> 元鳳四年，大將軍霍光白遣平樂監傅介子往刺其王。介子輕將勇敢士，繼金幣，揚言以賜外國為名。既至樓蘭，詐其王欲賜之，王喜，與介子飲，醉，將其王屏語，壯士二人從後刺殺之，貴人左右皆散走。介子告諭以：「王負漢罪，天子遣我誅王，當更立王弟尉屠耆在漢者。漢兵方至，毋敢動，自令滅國矣！」介子遂斬王嘗歸首，馳傳詣闕，懸首北闕下。封介子為義陽侯。乃立尉屠耆為王，更名其國為鄯善，為刻印章，賜以宮女為夫人，備車騎輜重，丞相將軍率百官送至橫門外，祖而遣之。王自請天子曰：「身在漢久，今歸，單弱，而前王有子在，恐為所殺。國中有伊循城，其地肥美，願漢遣一將屯田積穀，令臣得依其威重。」於是漢遣司馬一人、吏士四十人，田伊循以填撫之。其後更置都尉。伊循官置始此矣。

**互校说明** 傅介子与楼兰改名为同一次改立；尉屠耆请汉在伊循屯田，后来更置都尉。

> 介子與士卒俱齎金幣，揚言以賜外國爲名。至樓蘭，樓蘭王意不親介子，介子陽引去，至其西界，使譯謂曰：「漢使者持黃金錦繡行賜諸國，王不來受，我去之西國矣。」即出金幣以示譯。譯還報王，王貪漢物，來見使者。介子與坐飲，陳物示之。飲酒皆醉，介子謂王曰：「天子使我私報王。」王起隨介子入帳中，屏語，壯士二人從後刺之，刃交匈，立死。其貴人左右皆散走。介子告諭以「王負漢罪，天子遣我來誅王，當更立前太子質在漢者。漢兵方至，毋敢動，動，滅國矣！」遂持王首還詣闕，公卿將軍議者咸嘉其功。上迺下詔曰：「樓蘭王安歸甞爲匈奴閒，候遮漢使者，發兵殺略衞司馬安樂、光祿大夫忠、期門郎遂成等三輩，及安息、大宛使，盜取節印獻物，甚逆天理。平樂監傅介子持節使誅斬樓蘭王安歸首，縣之北闕，以直報怨，不煩師衆。其封介子爲義陽侯，食邑七百戶。士刺王者皆補侍郎。」

**互校说明** 本纪及此传写安归，非前108年赵破奴执楼兰王的同一事。

#### 卷022｜将相表互见与异说

[本年原行R130](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r130) · [《汉书·百官公卿表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%88%86%E5%8D%B7/%E6%B1%89%E4%B9%A6/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0077)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

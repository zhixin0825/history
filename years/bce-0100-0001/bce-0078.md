# 公元前78年｜范明友受命为度辽将军，出击乌桓

[← 公元前79年](bce-0079.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前77年 →](bce-0077.md)

**汉昭帝元凤三年**

古月、干支按古史年条保留，不直接换算为同号公历日期。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **冬季，朝廷以中郎将范明友为度辽将军，征调北边七郡骑兵，出击辽东乌桓。** 战事跨到次年，获胜和封平陵侯另见前77年。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **纪文记泰山大石与上林枯柳异象。** 正月，史书称泰山大石自行立起、上林倒伏枯柳复生。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **分中牟苑给贫民并免追部分旧贷。** 朝廷取消中牟苑并分给贫民，申明水灾赈济、停漕以及部分旧贷、边郡借牛不追偿。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **徐仁等因纵反者获罪。** 四月，徐仁、王平、贾胜胡因纵放涉谋反者获罪。徐仁自杀，王平、贾胜胡被处死。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **临衆敬侯始昌一支爵位承袭。** 元凤三年，顷侯广平继承侯爵，去世。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **益都敬侯胡一支失爵。** 元凤三年，因……获罪非广子免去侯爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **漳北侯宽一支后事。** 元凤三年，为奴所杀。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **成安严侯郭忠｜受封。** 《汉书》侯籍列成安严侯郭忠本年受封，所引月份、干支依表保留。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[9]](#hs-note-9)

### 2. 纪文记泰山大石与上林枯柳异象

[返回正文第2条](#hs-event-2)

<a id="hs007-l620-e2"></a>

**[《汉书·昭帝纪》P055](../../sources/摘录/汉书-卷007-昭帝纪.md#p055)** · [仓内TXT L620](../../sources/本地分卷/汉书/汉书-卷007.md#L620)

### 3. 分中牟苑给贫民并免追部分旧贷

[返回正文第3条](#hs-event-3)

<a id="hs007-l621-e3"></a>

**[《汉书·昭帝纪》P056](../../sources/摘录/汉书-卷007-昭帝纪.md#p056)** · [仓内TXT L621](../../sources/本地分卷/汉书/汉书-卷007.md#L621)

> 罷中牟苑賦貧民。詔曰：「乃者民被水災，頗匱於食，朕虛倉廩，使使者振困乏。其止四年毋漕。三年以前所振貸，非丞相御史所請，邊郡受牛者勿收責。」

**互校说明** “其止四年毋漕”语有歧解，避免断言是当年马上停运四个整年。

<a id="event-1"></a>

1. **冬季，朝廷以中郎将范明友为度辽将军，征调北边七郡骑兵，出击辽东乌桓。** 战事跨到次年，获胜和封平陵侯另见前77年。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **纪文记泰山大石与上林枯柳异象。** 正月，史书称泰山大石自行立起、上林倒伏枯柳复生。 眭弘据石柳异闻进说禅让，霍光将奏下廷尉，眭弘和替他递奏的内官长赐被诛。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **分中牟苑给贫民并免追部分旧贷。** 朝廷取消中牟苑并分给贫民，申明水灾赈济、停漕以及部分旧贷、边郡借牛不追偿。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **徐仁等因纵反者获罪。** 四月，徐仁、王平、贾胜胡因纵放涉谋反者获罪。徐仁自杀，王平、贾胜胡被处死。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **临衆敬侯始昌一支爵位承袭。** 元凤三年，顷侯广平继承侯爵，去世。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **益都敬侯胡一支失爵。** 元凤三年，因……获罪非广子免去侯爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **漳北侯宽一支后事。** 元凤三年，为奴所杀。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **成安严侯郭忠｜受封。** 《汉书》侯籍列成安严侯郭忠本年受封，所引月份、干支依表保留。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **昭帝朝命校十一家历法。** 太史令张寿王质疑太初历，鲜于妄人请与多人杂候日月、节气；诏在上林清台校验十一家。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **泰山莱芜石声及石起的记载。** 《汉书》在本年记载泰山莱芜石声及石起的记载。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **桑迁藏匿案、车千秋与杜延年。** 桑弘羊之子桑迁投父旧吏侯史吴而终伏法。廷尉王平、少府徐仁先以侯史吴仅匿随坐者而赦，御史复劾。丞相车千秋参与议法，杜延年劝霍光勿因此罢斥旧相。车千秋得免，王平、徐仁受追究。 [[12]](#hs-note-12)

### 2. 纪文记泰山大石与上林枯柳异象

[返回正文第2条](#hs-event-2)

<a id="hs075-l8890-e2"></a>

**[《汉书·眭两夏侯京翼李传》P002](../../sources/摘录/汉书-卷075-眭两夏侯京翼李传.md#p002)** · [仓内TXT L8890](../../sources/本地分卷/汉书/汉书-卷075.md#L8890)

> 孝昭元鳳三年正月，泰山萊蕪山南匈匈有數千人聲，民視之，有大石自立，高丈五尺，大四十八圍，入地深八尺，三石為足。石立後有白烏數千下集其旁。是時昌邑有枯社木臥復生，又上林苑中大柳樹斷枯臥地，亦自立生，有蟲食樹葉成文字，曰「公孫病已立」，孟推春秋之意，以為「石柳皆陰類，下民之象，而泰山者岱宗之嶽，王者易姓告代之處。今大石自立，僵柳復起，非人力所為，此當有從匹夫為天子者。枯社木復生，故廢之家公孫氏當復興者也。」孟意亦不知其所在，即說曰：「先師董仲舒有言，雖有繼體守文之君，不害聖人之受命。漢家堯後，有傳國之運。漢帝宜誰差天下，求索賢人，襢以帝位，而退自封百里，如殷周二王後，以承順天命。」孟使友人內官長賜上此書。時，昭帝幼，大將軍霍光秉政，惡之，下其書廷尉。奏賜、孟妄設祅言惑眾，大逆不道，皆伏誅。

**互校说明** 昭帝本纪载异象；《五行志》及《通鉴》卷023载眭弘因此案被诛，属于同年相关后续。

<a id="hs007-l620-e2"></a>

**[《汉书·昭帝纪》P055](../../sources/摘录/汉书-卷007-昭帝纪.md#p055)** · [仓内TXT L620](../../sources/本地分卷/汉书/汉书-卷007.md#L620)

> 三年春正月，泰山有大石自起立，上林有柳樹枯僵自起生。

**互校说明** 《通鉴》随后叙眭弘借异象谈禅代、被诛，原纪此句只记录异象，须区分政治附会。

### 12. 桑迁藏匿案、车千秋与杜延年

[返回正文第12条](#hs-event-12)

<a id="hs060-l8207-e12"></a>

**[《汉书·杜周传》P008](../../sources/摘录/汉书-卷060-杜周传.md#p008)** · [仓内TXT L8207](../../sources/本地分卷/汉书/汉书-卷060.md#L8207)

> 治燕王獄時，御史大夫桑弘羊子遷亡，過父故吏侯史吳。後遷捕得，伏法。會赦，侯史吳自出繫獄，廷尉王平與少府徐仁雜治反事，皆以為桑遷坐父謀反而侯史吳臧之，非匿反者，乃匿為隨者也。即以赦令除吳罪。後侍御史治實，以桑遷通經術，知父謀反而不諫爭，與反者身無異；侯史吳故三百石吏，首匿遷，不與庶人匿隨從者等，吳不得赦。奏請復治，劾廷尉、少府縱反者。少府徐仁即丞相車千秋女婿也，故千秋數為侯史吳言。恐光不聽，千秋即召中二千石、博士會公車門，議問吳法。議者知大將軍指，皆執吳為不道。明日，千秋封上眾議，光於是以千秋擅召中二千石以下，外內異言，遂下延尉平、少府仁獄。朝廷皆恐丞相坐之。延年乃奏記光爭，以為「吏縱罪人，有常法，今更詆吳為不道，恐於法深。又丞相素無所守持，而為好言於下，盡其素行也。至擅召中二千石，甚無狀。延年愚，以為丞相久故，及先帝用事，非有大故，不可棄也。間者民頗言獄深，吏為峻詆，今丞相所議，又獄事也，如是以及丞相，恐不合眾心。群下言雚嘩，庶人私議，流言四布，延年竊重將軍失此名於天下也！」光以廷尉、少府弄法輕重，皆論棄市，而不以及丞相，終與相竟。

**互校说明** 《通鉴》卷023系元凤三年，至四月徐仁自杀，王平和左冯翊贾胜胡腰斩。《汉书·杜周传》概记廷尉少府皆论弃市，保留判决与结局差别。

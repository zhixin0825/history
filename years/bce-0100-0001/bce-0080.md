# 公元前80年｜上官父子谋反案发，告发、捕获者获赏；王山寿封商利侯

[← 公元前82年](bce-0082.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前78年 →](bce-0078.md)

**汉昭帝元凤元年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e160"></a>
### 上官父子谋反案发，告发、捕获者获赏

上官桀、上官安与霍光的权力冲突发展成谋反案。朝廷处死上官父子及相关人员，安阳、桑乐侯国终止。上官皇后因年幼未参与谋划而保留皇后名位，不能把全族处置写成宫中所有亲属一律处死。 [原文与说明](#sj020-e160-n)

<a id="sj020-e161"></a>
### 王山寿封商利侯

王山寿以丞相属吏身份，诱使上官安进入丞相府，帮助捕获案犯。他被封为商利侯。 [原文与说明](#sj020-e161-n)

<a id="sj020-e162"></a>
### 杜延年封建平侯

杜延年原为御史大夫杜周之子，在霍光幕府任职，因参与揭发上官安等人的谋划受赏。他被封为建平侯。 [原文与说明](#sj020-e162-n)

<a id="sj020-e163"></a>
### 任宫封弋阳侯

任宫直接参与捕获上官桀，成为获赏者之一。他被封为弋阳侯。 [原文与说明](#sj020-e163-n)

<a id="sj020-e164"></a>
### 燕仓封宜城侯

燕仓发觉谋反线索，经过朝廷大臣传报，使案情得以追查。他被封为宜城侯。 [原文与说明](#sj020-e164-n)

<a id="sj022"></a>
## 朝廷人事与本年补记

九月，张安世由光禄勋升为右将军，仍兼掌原来的宫廷职务。王訢则由右扶风升御史大夫，接替中枢御史职位。 [原文与说明](#sj022-note)

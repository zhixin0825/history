1. **上官父子谋反案发，燕王刘旦自杀，相关王侯国被撤销。** 上官桀、上官安与霍光的权力冲突发展成谋反案；刘旦再次与上官桀等相谋，称太子已经不在，自己本应即位，却被大臣压制。霍光与公卿议定不再宽免。上官父子及相关人员被处死，安阳、桑乐侯国终止；刘旦自杀，燕国撤销。有司请求诛其妻子儿女，昭帝念亲，赦免死罪，降为庶人。上官皇后则因年幼、未参与谋划而保留皇后名位。[[1]](#note-1)

<a id="sj020-e161"></a>
<a id="王山寿封商利侯"></a>


<a id="event-2"></a>

2. **王山寿封商利侯。** 王山寿以丞相属吏身份，诱使上官安进入丞相府，帮助捕获案犯。他被封为商利侯。 [[2]](#note-2)

<a id="sj020-e162"></a>
<a id="杜延年封建平侯"></a>


<a id="event-3"></a>

3. **杜延年封建平侯。** 杜延年原为御史大夫杜周之子，在霍光幕府任职，因参与揭发上官安等人的谋划受赏。他被封为建平侯。 [[3]](#note-3)

<a id="sj020-e163"></a>
<a id="任宫封弋阳侯"></a>


<a id="event-4"></a>

4. **任宫封弋阳侯。** 任宫直接参与捕获上官桀，成为获赏者之一。他被封为弋阳侯。 [[4]](#note-4)

<a id="sj020-e164"></a>

5. **燕仓封宜城侯。** 燕仓发觉谋反线索，经过朝廷大臣传报，使案情得以追查。他被封为宜城侯。 [[5]](#note-5)

**[《汉书·昭帝纪》P051](../../sources/摘录/汉书-卷007-昭帝纪.md#p051)** · [仓内TXT L616](../../sources/本地分卷/汉书/汉书-卷007.md#L616)

> 九月，鄂邑長公主、燕王旦與左將軍上官桀、桀子票騎將軍安、御史大夫桑弘羊皆謀反，伏誅。初，桀、 安父子與大將軍光爭權，欲害之，詐使人為燕王旦上書言光罪。時上年十四，覺其詐。後有譖光者，上輒怒曰：「大將軍國家忠臣，先帝所屬，敢有譖毀者，坐 之。」光由是得盡忠。語在燕王、霍光傳。

**互校说明** 案发已记，原纪另详上官氏借燕王上书诬霍光及昭帝识破，勿重复立案。

<a id="hs007-l617-e1"></a>

**[《汉书·昭帝纪》P052](../../sources/摘录/汉书-卷007-昭帝纪.md#p052)** · [仓内TXT L617](../../sources/本地分卷/汉书/汉书-卷007.md#L617)

> 冬十月，詔曰：「左將軍安陽侯桀、票騎將軍桑樂侯安、御史大夫弘羊皆數以邪枉干輔政，大將軍不聽， 而懷怨望，與燕王通謀，置驛往來相約結。燕王遣壽西長、孫縱之等賂遺長公主、丁外人、謁者杜延年、大將軍長史公孫遺等，交通私書，共謀令長公主置酒，伏兵 殺大將軍光，徵立燕王為天子，大逆毋道。故稻田使者燕倉先發覺，以告大司農敞，敞告諫大夫延年，延年以聞。丞相徵事任宮手捕斬桀，丞相少史王壽誘將安入府 門，皆已伏誅，吏民得以安。封延年、倉、宮、壽皆為列侯。」又曰：「燕王迷惑失道，前與齊王子劉澤等為逆，抑而不揚，望王反道自新，今乃與長公主及左將軍 桀等謀危宗廟。王及公主皆自伏辜。其赦王太子建、公主子文信及宗室子與燕王、上官桀等謀反父母同產當坐者，皆免為庶人。其吏為桀等所詿誤，未發覺在吏者， 除其罪。」

**互校说明** 十月诏为九月案发的后续公布，四名有功者的授侯已有各同号条。

> 其後旦復與左將軍上官桀等謀反，宣言曰「我次太子，太子不在，我當立，大臣共抑我」云云。大將軍光輔政，與公卿大臣議曰：「燕王旦不改過悔正，行惡不變。」於是修法直斷，行罰誅。旦自殺，國除，如其策指。有司請誅旦妻子。孝昭以骨肉之親，不忍致法，寬赦旦妻子，免為庶人。傳曰「蘭根與白芷，漸之滫中，君子不近，庶人不服」者，所以漸然也。

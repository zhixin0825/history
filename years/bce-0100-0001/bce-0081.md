# 公元前81年｜昭帝在上林亲耕、召问贤良文学，议盐铁与酒榷

[← 公元前82年](bce-0082.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前80年 →](bce-0080.md)

**汉昭帝始元六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **昭帝在上林亲耕。** 春正月，昭帝在上林苑耕作。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **召问贤良文学，议盐铁与酒榷。** 二月，朝廷询问贤良、文学民间困苦，并商议废除盐、铁与酒类官营的请求。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **苏武归汉，受任典属国。** 苏武被匈奴拘留十九年后回国，仍保汉使身份，受任典属国、获赐钱百万。 同使常惠一并归汉，因奉使有劳拜光禄大夫。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **夏旱，举行雩祭。** 夏季干旱，朝廷举行大雩祈雨。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **罢酒榷，允许民间按律卖酒纳租。** 七月撤销酒类专卖官，准民按律申报缴纳卖酒税，纪文记每升四钱。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **设金城郡。** 因边塞地域辽阔，从天水、陇西、张掖各划二县设金城郡。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **毋波封钩町王，田广明获爵。** 毋波率部助战获功，由钩町侯升钩町王；田广明获关内侯爵和食邑。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **𤊱氏节侯贺一支爵位承袭。** 始元六年，康侯千秋继承侯爵，十六年去世。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **猇节侯起一支爵位承袭。** 始元六年，夷侯充国继承侯爵，二十年去世。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **五月乙卯分封王子侯。** 《王子侯表》列五月乙卯受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **六月乙未分封王子侯。** 《王子侯表》列六月乙未受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **始元六年大旱。** 《汉书》在本年记载始元六年大旱。 [[13]](#hs-note-13)

### 2. 召问贤良文学，议盐铁与酒榷

[返回正文第2条](#hs-event-2)

<a id="hs060-l8208-e2"></a>

**[《汉书·杜周传》P009](../../sources/摘录/汉书-卷060-杜周传.md#p009)** · [仓内TXT L8208](../../sources/本地分卷/汉书/汉书-卷060.md#L8208)

> 光納其言，舉賢良，議罷酒榷、鹽、鐵，皆自延年發之。

**互校说明** 二月举贤良文学、议盐铁酒榷见《昭帝纪》，本传追揭杜延年倡议，裁行另有日次。

<a id="hs066-l8488-e2"></a>

**[《汉书·公孙刘田王杨蔡陈郑传》P017](../../sources/摘录/汉书-卷066-公孙刘田王杨蔡陈郑传.md#p017)** · [仓内TXT L8488](../../sources/本地分卷/汉书/汉书-卷066.md#L8488)

> 始元六年，詔郡國舉賢良文學士，問以民所疾苦，於是鹽鐵之議起焉。

<a id="hs066-l8529-e2"></a>

**[《汉书·公孙刘田王杨蔡陈郑传》P058](../../sources/摘录/汉书-卷066-公孙刘田王杨蔡陈郑传.md#p058)** · [仓内TXT L8529](../../sources/本地分卷/汉书/汉书-卷066.md#L8529)

> 所謂鹽鐵議者，起始元中，徵文學賢良問以治亂，皆對願罷郡國鹽鐵酒榷均輸，務本抑末，毋與天下爭利，然後化可興。御史大夫弘羊以爲此乃所以安邊竟，制四夷，國家大業，不可廢也。當時相詰難，頗有其議文。

**互校说明** 下文引宣帝时宽次公论议；盐铁辩论与以后写作分开。

<a id="hs024-l5110-e2"></a>

**[《汉书·食货志》P046](../../sources/摘录/汉书-卷024-食货志.md#p046)** · [仓内TXT L5110](../../sources/本地分卷/汉书/汉书-卷024.md#L5110)

> 詔郡國舉賢良文學之士，問以民所疾苦，教化之要。

**互校说明** 昭帝始元六年召问，与八月罢榷酒分条。

<a id="hs007-l604-e2"></a>

**[《汉书·昭帝纪》P039](../../sources/摘录/汉书-卷007-昭帝纪.md#p039)** · [仓内TXT L604](../../sources/本地分卷/汉书/汉书-卷007.md#L604)

> 二月，詔有司問郡國所舉賢良文學民所疾苦。議罷鹽鐵榷酤。

**互校说明** 议盐铁、酒榷是二月，七月决策只明确罢酒榷，不能写盐铁全废。

### 3. 苏武归汉，受任典属国

[返回正文第3条](#hs-event-3)

<a id="hs054-l7940-e3"></a>

**[《汉书·李广苏建传》P038](../../sources/摘录/汉书-卷054-李广苏建传.md#p038)** · [仓内TXT L7940](../../sources/本地分卷/汉书/汉书-卷054.md#L7940)

> 後漢使復至匈奴，常惠請其守者與俱，得夜見漢使。具自陳過。教使者謂單于，言天子射上林中，得鴈，足有係帛書，言武等在荒澤中。使者大喜，如惠語以讓單于。單于視左右而驚，謝漢使曰：「武等實在。」

**互校说明** 交涉在归国之前，雁帛是常惠设辞，非实得天子书。

<a id="hs054-l7940-e3-2"></a>

**[《汉书·李广苏建传》P038](../../sources/摘录/汉书-卷054-李广苏建传.md#p038)** · [仓内TXT L7940](../../sources/本地分卷/汉书/汉书-卷054.md#L7940)

> 單于召會武官屬，前以降及物故，凡隨武還者九人。

<a id="hs054-l7941-e3"></a>

**[《汉书·李广苏建传》P039](../../sources/摘录/汉书-卷054-李广苏建传.md#p039)** · [仓内TXT L7941](../../sources/本地分卷/汉书/汉书-卷054.md#L7941)

> 武以始元六年春至京師。詔武奉一太守謁武帝園廟，拜為典屬國，秩中二千石，賜錢二百萬，公田二頃，宅一區。常惠、徐聖、趙終根皆拜為中郎，賜帛各二百匹。其餘六人老歸家，賜錢人十萬，復終身。常惠後至右將軍，封列侯，自有傳。武留匈奴凡十九歲，始以強壯出，及還，鬚髮盡白。

**互校说明** 本纪载赐钱百万；本传二百万，并录而不构成两次赏钱。

<a id="hs070-l8665-e3"></a>

**[《汉书·傅常郑甘陈段传》P007](../../sources/摘录/汉书-卷070-傅常郑甘陈段传.md#p007)** · [仓内TXT L8665](../../sources/本地分卷/汉书/汉书-卷070.md#L8665)

> 昭帝時迺還。漢嘉其勤勞，拜爲光祿大夫。

**互校说明** 常惠同使在前100年，归汉在始元六年。传写十余年，苏武传记十九年。

<a id="hs007-l605-e3"></a>

**[《汉书·昭帝纪》P040](../../sources/摘录/汉书-卷007-昭帝纪.md#p040)** · [仓内TXT L605](../../sources/本地分卷/汉书/汉书-卷007.md#L605)

> 栘中監蘇武前使匈奴，留單于庭十九歲乃還，奉使全節，以武為典屬國，賜錢百萬。

**互校说明** 出使、扣留与归汉分阶段；本纪十九岁、《通鉴》卷023 L217亦记十九岁。

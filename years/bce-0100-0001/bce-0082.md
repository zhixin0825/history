本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **皇后之父上官安封桑乐侯。** 六月，上官安因女儿为皇后，受封桑乐侯。父亲安阳侯上官桀、儿子桑乐侯上官安各有自己的侯爵，不是一人连封两次。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **追尊赵太后之父为顺成侯。** 朝廷追封昭帝外祖父为顺成侯。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **张延年冒称卫太子。** 夏阳男子张延年至北阙冒称卫太子，事败后被处死。 传补京兆尹雋不疑援《春秋》先行收捕的经过。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **罢亭母马、马弩关。** 夏撤销各亭所设母马，并罢马弩关禁。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **诏举贤良、文学并赐爵。** 朝廷命三辅、太常各举贤良二人，郡国各举文学高第一人，并依身份赐爵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **罢儋耳、真番二郡。** 朝廷撤销儋耳郡、真番郡。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **田广明、王平在益州作战。** 秋，田广明、王平出击益州，纪文记斩俘三万余人、获牲畜五万余头。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **刘音嗣胶东王。** 刘音嗣胶东王。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **挟厘侯霸一支爵位承袭。** 始元五年，夷侯戚继承侯爵，二十一年去世。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **六月辛丑分封王子侯。** 《王子侯表》列六月辛丑受封的诸侯王后裔；各人侯名与宗支见同号引文。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **衆利侯伊即轩｜去世。** 表载衆利侯伊即轩一支本年记载去世。表中所载事项为去世，无继承人，为诸县。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[12]](#hs-note-12)

### 3. 张延年冒称卫太子

[返回正文第3条](#hs-event-3)

<a id="hs071-l8710-e3"></a>

**[《汉书·隽疏于薛平彭传》P004](../../sources/摘录/汉书-卷071-隽疏于薛平彭传.md#p004)** · [仓内TXT L8710](../../sources/本地分卷/汉书/汉书-卷071.md#L8710)

> 始元五年，有一男子乘黃犢車，建黃旐，衣黃襜褕，著黃冒，詣北闕，自謂衛太子。公車以聞，詔使公卿、將軍、中二千石雜識視。長安中吏民聚觀者數萬人。右將軍勒兵闕下，以備非常。丞相、御史、中二千石至者並莫敢發言。京兆尹不疑後到，叱從吏收縛。或曰：「是非未可知，且安之。」不疑曰：「諸君何患於衛太子！昔蒯聵違命出奔，輒距而不納，《春秋》是之。衛太子得罪先帝，亡不即死，今來自詣，此罪人也。」遂送詔獄。

**互校说明** 据始元五年，收捕与验实见本年同案。

<a id="hs071-l8711-e3"></a>

**[《汉书·隽疏于薛平彭传》P005](../../sources/摘录/汉书-卷071-隽疏于薛平彭传.md#p005)** · [仓内TXT L8711](../../sources/本地分卷/汉书/汉书-卷071.md#L8711)

> 廷尉驗治何人，竟得奸詐。本夏陽人，姓成名方遂，居湖，以卜筮為事。有故太子舍人嘗從方遂卜，謂曰：「子狀貌甚似衛太子。」方遂心利其言，幾得以富貴，即詐自稱詣闕，廷尉逮召鄉里知識者張宗祿等，方遂坐誣罔不道，要斬東市。一雲姓張名延年。

**互校说明** 传先称成方遂，末附异说张延年；《昭帝纪》用张延年。两名属于同一案件。

<a id="hs007-l597-e3"></a>

**[《汉书·昭帝纪》P032](../../sources/摘录/汉书-卷007-昭帝纪.md#p032)** · [仓内TXT L597](../../sources/本地分卷/汉书/汉书-卷007.md#L597)

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

1. **上官氏立为皇后，上官安升车骑将军。** 上官安的女儿被立为昭帝皇后。上官安原因父亲上官桀的地位进入近侍圈，现在又成为皇后的父亲，家族在宫廷中的关系更加紧密。卫尉王莽进入将军官列，上官安也由骑都尉升为车骑将军。皇后父亲上官安与祖父上官桀分别担任军职，家族在中枢的地位进一步上升。 [[1]](#note-1)

<a id="hs-event-3"></a>

2. **迁三辅富户至云陵。** 朝廷迁三辅富户至云陵，每户给钱十万。 [[2]](#hs-note-3)

<a id="hs-event-4"></a>

3. **停止征民马、减中央供输。** 七月，因连年歉收、粮食缺乏和流民未全归，朝廷下令停征民马，并暂减供给京师各官署的物资。 [[3]](#hs-note-4)

<a id="hs-event-5"></a>

4. **田广明出兵益州。** 冬派大鸿胪田广明赴益州作战，次年前82报告战果。 [[4]](#hs-note-5)

<a id="hs-event-6"></a>

5. **廷尉李种因纵囚被杀。** 廷尉李种因故意纵放应判死罪者，受弃市之刑。 [[5]](#hs-note-6)

<a id="hs-event-7"></a>

6. **刘建德嗣长沙王。** 刘建德嗣长沙王。 [[6]](#hs-note-7)

<a id="hs-event-8"></a>

7. **刘禄嗣六安王。** 刘禄嗣六安王。 [[7]](#hs-note-8)

<a id="hs-event-9"></a>

8. **南城节侯贞一支爵位承袭。** 始元四年，戴侯猛继承侯爵，二十二年去世。 [[8]](#hs-note-9)

<a id="hs-event-10"></a>

9. **周子南君姬嘉｜承爵。** 表载周子南君姬嘉一支本年记载侯位承袭。表中所载事项为君当承爵。 [[9]](#hs-note-10)

<a id="hs-event-11"></a>

10. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[10]](#hs-note-11)

<a id="hs-event-12"></a>

11. **匈奴入代杀都尉。** 《匈奴传》以壶衍鞮初立的两年后记匈奴入代。其国内不和，卫律其后改变守城计划，提出送还汉使。 [[11]](#hs-note-12)

#### 卷022｜将相表互见与异说

[本年原行R124](../../拆分史书/史记/卷022.md#r124) · [《汉书·百官公卿表》](../../拆分史书/汉书/卷019.md#part-3-ws019-bce-0083)。此段属于现传表的天汉以后续补层，不称为司马迁亲历记事；古历月日照原年条保存，未换算公历日。

史表三月癸酉记王莽为“左将军”，汉019同年为“右将军卫尉”；正文只采用进入将军官列，不为左右各编一项任命。本年王莽是天水王莽稚叔，不能与以后篡汉的王莽合传。上官安在两表本年均作车骑，而汉007次年封侯时作骠骑，保留称号差别，不擅定一次未载月份的改官 · [昭帝纪互见](../../拆分史书/汉书/卷007.md#part-1-text)。

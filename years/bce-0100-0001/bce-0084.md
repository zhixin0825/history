**汉昭帝始元三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **西北出现孛星记录。** 始元三年二月，纪文记西北见孛星。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **募百姓迁云陵。** 秋募民迁云陵，赐钱、田及住宅；次年前83迁三辅富户是另一道措施。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **东海凤皇记录与祭祀。** 冬十月纪文记东海见凤皇，朝廷派使祭祀其地。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **纪文记十一月朔日食。** 十一月壬辰朔，史书记日食。 [[4]](#hs-note-4)

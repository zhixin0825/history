# 公元前84年｜西北出现孛星记录、募百姓迁云陵

[← 公元前85年](bce-0085.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前83年 →](bce-0083.md)

**汉昭帝始元三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **西北出现孛星记录。** 始元三年二月，纪文记西北见孛星。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **募百姓迁云陵。** 秋募民迁云陵，赐钱、田及住宅；次年前83迁三辅富户是另一道措施。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **东海凤皇记录与祭祀。** 冬十月纪文记东海见凤皇，朝廷派使祭祀其地。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **十一月朔发生日食。** 十一月壬辰朔，发生日食。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **广望节侯忠一支爵位承袭。** 始元三年，思侯何齐继承侯爵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **阿武戴侯豫一支爵位承袭。** 始元三年，节侯信继承侯爵，二十三年去世。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **山原侯国一支爵位承袭。** 始元三年，安侯守继承侯爵，二十二年去世。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **柏畅戴侯终古一支去世。** 始元三年去世，无子嗣承继。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[9]](#hs-note-9)

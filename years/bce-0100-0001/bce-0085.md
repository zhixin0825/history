# 公元前85年｜霍光、上官桀正式受封

[← 公元前86年](bce-0086.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前84年 →](bce-0084.md)

**汉昭帝始元二年**

本页收录卷020及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

<a id="event-1"></a>

1. **正月，霍光受封博陆侯，上官桀受封安阳侯。** 两人的爵赏依据是此前制止马何罗谋反、奉遗命辅政的功劳，不是本年新发生了一次同名宫变。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **举刘辟强和刘长乐为光禄大夫。** 朝廷任两位宗室为光禄大夫，刘辟强兼摄长乐卫尉。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **赈贷后免追种粮、免收当年田租。** 三月赈贷种子与口粮，八月因蚕麦受损和连年灾害，免追旧贷并免本年田租。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **调兵至朔方、张掖。** 冬调熟习战射者赴朔方，调旧吏赴张掖统领屯田。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘定国嗣梁王。** 刘定国嗣梁王。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **被阳敬侯燕一支爵位承袭。** 始元二年，顷侯寿继承侯爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **昭帝始元冬无冰。** 《汉书》在本年记载昭帝始元冬无冰。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **狐鹿姑单于去世，卫律等拥立壶衍鞮。** 狐鹿姑临终属意其弟右谷蠡王。卫律、颛渠阏氏隐瞒死讯，召贵人结盟，立其子左谷蠡王为壶衍鞮。 [[9]](#hs-note-9)

### 9. 狐鹿姑单于去世，卫律等拥立壶衍鞮

[返回正文第9条](#hs-event-9)

<a id="hs094-l9831-e9"></a>

**[《汉书·匈奴传》P073](../../sources/摘录/汉书-卷094-匈奴传.md#p073)** · [仓内TXT L9831](../../sources/本地分卷/汉书/汉书-卷094.md#L9831)

> 後三年，單于欲求和親，會病死。初，單于有異母弟為左大都尉，賢，國人鄉之，母閼氏恐單于不立子而立左大都尉也，乃私使殺之。左大都尉同母兄怨，遂不肯復會單于庭。又單于病且死，謂諸貴人：「我子少，不能治國，立弟右谷蠡王。」及單于死，衛律等與顓渠閼氏謀，匿單于死，詐撟單于令，與貴人飲盟，更立子左谷蠡王為壺衍鞮單于。是歲，始元二年也。

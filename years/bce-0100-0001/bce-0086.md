# 公元前86年｜燕王初次谋反事发获免追治，金日磾去世

[← 公元前87年](bce-0087.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前85年 →](bce-0085.md)

**汉昭帝始元元年**

本页收录已编史料及明确互见所能定位的事项；没有声称本年全国史事已经收齐。古月、干支不直接换算为同号公历日期。

[本年相关史料](#sources-start)

<a id="sj060-royal-grants-event"></a>

1. **二月，燕王刘旦与广陵王刘胥各获增封一万三千户。** 昭帝新朝增加两位皇兄的食邑，鄂邑长公主也获同额增封。此次增邑与广陵王后来入朝再获赏赐分开。 [[1]](#sj060-royal-grants-note)

<a id="sj060-yan-first-conspiracy-event"></a>

2. **燕王刘旦与刘泽谋反事发，朝廷暂不追治刘旦。** 刘旦自认为是武帝在世的长子，应当继位，散布昭帝不是武帝之子、而是大将军之子的言论，与齐孝王的孙子刘泽等筹划发兵。八月，刘泽之谋被揭发，刘泽等受诛，牵连到刘旦；昭帝念亲而未追治燕王。朝廷又派宗正、太中大夫公户满意及两名御史到燕，分日进见：宗正说明昭帝的宗属，御史以法律谕责，公户满意援引礼义，警告再犯可能身死国灭。刘旦恐惧叩头谢罪。 [[2]](#sj060-yan-first-conspiracy-note)

3. **金日磾临病受秺侯封爵，随后去世。** 金日磾病重，终于接受秺侯印绶，不久去世。儿子金赏承接爵位。这位休屠王之子在汉廷的经历，从养马、近侍直到参与辅政，并非一条从入汉当天就获高位的直线。 [[3]](#note-1)

### 2. 燕王刘旦与刘泽谋反事发，朝廷暂不追治刘旦

[返回正文第2条](#sj060-yan-first-conspiracy-event)

<a id="sj060-cite-031"></a>

**[《史记·三王世家》P027｜燕王初谋与使臣分次谕责](../../sources/摘录/史记-卷060-三王世家.md#p027)**

> 會武帝崩，昭帝初立，旦果作怨而望大臣。自以長子當立，與齊王子劉澤等謀為叛逆，出言曰：「我安得弟在者！今立者乃大將軍子也。」欲發兵。事發覺，當誅。昭帝緣恩寬忍，抑案不揚。公卿使大臣請，遣宗正與太中大夫公戶滿意、御史二人，偕往使燕，風喻之。到燕，各異日，更見責王。宗正者，主宗室諸劉屬籍，先見王，為列陳道昭帝實武帝子狀。侍御史乃復見王，責之以正法，問：「王欲發兵罪名明白，當坐之。漢家有正法，王犯纖介小罪過，即行法直斷耳，安能寬王。」驚動以文法。王意益下，心恐。公戶滿意習於經術，最後見王，稱引古今通義，國家大禮，文章爾雅。謂王曰：「古者天子必內有異姓大夫，所以正骨肉也；外有同姓大夫，所以正異族也。周公輔成王，誅其兩弟，故治。武帝在時，尚能寬王。今昭帝始立，年幼，富於春秋，未臨政，委任大臣。古者誅罰不阿親戚，故天下治。方今大臣輔政，奉法直行，無敢所阿，恐不能寬王。王可自謹，無自令身死國滅，為天下笑。」於是燕王旦乃恐懼服罪，叩頭謝過。大臣欲和合骨肉，難傷之以法。

**说明：** 始元元年八月来自汉纪刘泽案，劝谕使团本篇无另记月日，只随该案编排。公户为姓、满意为名，宗正与两御史合计四人。“齐王子”汉纪、汉传具体作齐孝王孙，非开国时燕敬王刘泽。昭帝乃大将军子是刘旦用来鼓动的说辞；索隐对刘旦疑怨的辩护也不能当作身世确证。内异姓、外同姓古注疑倒置，原字照存；“诛其两弟”不据以改写周公处置管蔡的既有年线。

> 八月，齊孝王孫劉澤謀反，欲殺青州刺史雋不疑，發覺，皆伏誅。遷不疑為京兆尹，賜錢百萬。

**说明：** 本纪给出八月及刘泽身份。

<!-- /sj060-cite-032 -->

<a id="sj060-cite-033"></a>

**[《汉书》卷063互校｜L8313](../../sources/本地分卷/汉书/汉书-卷063.md#L8313)**

> 會缾侯劉成知澤等謀，告之青州刺史雋不疑，不疑收捕澤以聞。天子遣大鴻臚丞治，連引燕王。有詔勿治，而劉澤等伏誅。益封缾侯。

**说明：** “勿治”不是已逮捕刘旦、判罪后又释放，也不表示刘泽一同获赦。使团劝谕由褚补补见，汉传的查案使者不无据合并成同一官员名单。

# 公元前87年｜繆侯郦终根被诛，传本功臣侯表至此收尾

[← 公元前88年](bce-0088.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前86年 →](bce-0086.md)

**汉武帝后元二年**

本页先收本卷能够归年的侯籍材料，尚不代表本年全国史事已齐。

<a id="sj018-wudi"></a>
## 功臣后裔的承爵与失国

繆侯郦终根被以诅咒皇帝之罪处死，封国撤销。 [R016](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r016)

<a id="sj018-note"></a>
### 卷018｜原格、异年与本页采用

**逐格定位：** <a id="sj018-r016-wu"></a>[R016](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r016)。

本页按原格中明确年号、承袭次序及互见材料分别定位；未载月份的不补日期，元年也不一律倒推父亲死年。侯爵与所任中央官职不是同一继承关系。

**R016：** 史表元光四年遂、元朔三年宗、元鼎二年终根，汉表分别作遂成、世宗，沿同一侯统识别。末案史表“后元二年咒诅诛”，汉表“后二年祝诅上，腰斩”，均落前87年；这是司法控罪，不是证明诅咒能产生现实效果。行首曲周是初封国，武帝段实际是繆侯，不将全部后裔一概称曲周侯。

互校：[《汉书》高惠高后文功臣表](https://zh.wikisource.org/wiki/漢書/卷016) · [《史记》三家注卷018](https://zh.wikisource.org/wiki/史記三家註/卷018)。传本的最后记事已到武帝后元二年；表序“至太初”与后续层次不同，不把所有晚出案件移回太初，也不据此断定全卷各句同一时日写成。

<a id="sj019"></a>
## 封侯、承袭与侯国的变化

<a id="sj019-r082-e04"></a>
三月壬辰，容成侯光因祠祝诅案被追究，侯国撤销。 [原文与说明](#sj019-r082-e04-n)


<a id="sj019-note"></a>
### 卷019｜本年侯籍与异说

[完整原表](../../sources/摘录/史记-卷019-惠景间侯者年表.md) · [逐格去向](../../meta/记录/史记-卷019-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷019-纪年与异说.md)。原格的承侯元年不一律等于前任死年；未载月日不补，谥号是后称，国除也不一律等于处死。

<a id="sj019-r082-e04-n"></a>
**容成｜[R082原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r082)：** [《汉书·景武昭宣元成功臣表》](https://zh.wikisource.org/wiki/漢書/卷017)补腰斩，并记光全任期40年。史表武帝至元封六年栏后段22年，加太初以后含本年18年，22+18=40；前126至前87年含首尾也为40。十八是后一栏段的年数，不能把光的元年推迟到前104年。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e155"></a>
### 武帝遗命三人辅佐少主

武帝病重，霍光、金日磾、上官桀受命辅佐幼主。武帝去世后，昭帝即位，霍光居于主持朝政的核心。此前平定宫中谋反的功劳，又成为遗诏封侯的依据，但几人没有立即一同受领爵印。 [原文与说明](#sj020-e155-n)

<a id="sj020-note"></a>
### 卷020｜原格、互见与采用的年线

[完整原文](../../sources/摘录/史记-卷020-建元以来侯者年表.md) · [逐格去向](../../meta/记录/史记-卷020-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷020-纪年与异说.md)。初封、增邑、继承与任官分开；月日未明不补，谥号为后称，国除不一律等于处死。

<a id="sj020-e155-n"></a>
**武帝遗命三人辅佐少主：** [S005 博陸](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s005) · [S006 秺](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s006) · [S007 安陽](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s007)。武帝死亡、昭帝即位据汉昭帝纪。遗命、实际受爵和以后增封分别处理，不用补文段落次序推成先封、后捕何罗。霍光为霍去病的异母弟，早事武帝，兄弟关系不是本年才出现。 互校：[漢書/卷007](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7007) · [漢書/卷068](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7068) · [資治通鑑/卷022](https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B7022)。

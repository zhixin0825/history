# 公元前88年｜戴侯蒙因祝诅罪被处死

**汉武帝后元元年**

本页先收本卷能够归年的侯籍材料，尚不代表本年全国史事已齐。

<a id="sj018-wudi"></a>
## 功臣后裔的承爵与失国

五月，戴侯蒙被以祝诅、无道罪处死，侯国撤销。 [R121](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r121)

<a id="sj018-note"></a>
### 卷018｜原格、异年与本页采用

**逐格定位：** <a id="sj018-r121-wu"></a>[R121](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r121)。

本页按原格中明确年号、承袭次序及互见材料分别定位；未载月份的不补日期，元年也不一律倒推父亲死年。侯爵与所任中央官职不是同一继承关系。

**R121：** 史表安期、汉表轸；蒙元鼎五年嗣、后元元年五月甲戌终局，汉表记祝诅上、腰斩。与次年前87年繆侯郦终根之案分开，不因为同属祝诅罪便合成同日一次清洗。

互校：[《汉书》高惠高后文功臣表](https://zh.wikisource.org/wiki/漢書/卷016) · [《史记》三家注卷018](https://zh.wikisource.org/wiki/史記三家註/卷018)。

<a id="sj019"></a>
## 封侯、承袭与侯国的变化

<a id="sj019-r081-e02"></a>
四月甲辰，遒侯则因使巫者齐少君祠祝诅而被追究，侯国撤销。 [原文与说明](#sj019-r081-e02-n)


<a id="sj019-note"></a>
### 卷019｜本年侯籍与异说

[完整原表](../../sources/摘录/史记-卷019-惠景间侯者年表.md) · [逐格去向](../../meta/记录/史记-卷019-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷019-纪年与异说.md)。原格的承侯元年不一律等于前任死年；未载月日不补，谥号是后称，国除也不一律等于处死。

<a id="sj019-r081-e02-n"></a>
**遒｜[R081原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r081)：** 本表“大道无道”与汉表大逆无道互校；司法记录的诅咒指控不证明巫术有实际效力。隆强至则之间的承袭姓名、年份失载，不补同一人长寿六十年。

3. **金日磾、霍光、上官桀制止马何罗一案。** 侍中马何罗与弟马通等谋反的案情暴露。 金日磾在宫中制住何罗，霍光、上官桀也参与处置。这次护卫皇帝的行动，后来成为三人受封的重要理由。 [[3]](#note-3)

<a id="event-4"></a>

4. **韩曾续封龙额侯。** 韩说在巫蛊之祸中被杀，按道侯传给儿子韩兴。韩曾是韩兴的弟弟，续封的是父亲早年曾获的龙额侯爵。韩曾又作韩增。 [[4]](#note-4)

<a id="hs-event-5"></a>

5. **武帝在甘泉郊泰畤。** 后元元年正月武帝到甘泉郊祀，接着出巡安定。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **昌邑王刘髆去世。** 昌邑王刘髆去世。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **北巡见鹤与赦令。** 二月诏说郊见上帝、北巡见群鹤而未设网捕捉，在泰畤行礼时见光，随后赦天下。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **御史大夫商丘成自杀。** 后元元年六月，本纪记御史大夫商丘成获罪自杀。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **地震与泉水涌出。** 七月地震，多处泉水涌出。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **刘庆忌嗣鲁王。** 刘庆忌嗣鲁王。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **安阳侯乐一支爵位承袭。** 後元元年，穅侯延年继承侯爵，十六年去世。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **逎侯陆强｜获罪。** 表载逎侯陆强一支本年载相关罪案及处分。表中所载事项为因罪案祝诅上，被腰斩。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **亚谷简侯卢它之｜承爵。** 表载亚谷简侯卢它之一支本年记载侯位承袭。表中所载事项为侯种承爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **塞侯直不疑｜受封。** 表载塞侯直不疑一支本年有始封记载。表中所载事项为八月封。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[15]](#hs-note-15)

**[《汉书·霍光金日磾传》P038](../../sources/摘录/汉书-卷068-霍光金日磾传.md#p038)** · [仓内TXT L8601](../../sources/本地分卷/汉书/汉书-卷068.md#L8601)

> 何羅兄弟懼及，遂謀爲逆。日磾視其志意有非常，心疑之，陰獨察其動靜，與俱上下。何羅亦覺日磾意，以故乆不得發。是時上行幸林光宮，日磾小疾卧廬。何羅與通及小弟安成矯制夜出，共殺使者，發兵。明旦，上未起，何羅亡何從外入。日磾奏厠心動，立入坐內戶下。須臾，何羅褏白刃從東箱上，見日磾，色變，走趨卧內欲入，行觸寶瑟，僵。日磾得抱何羅，因傳曰：「莽何羅反！」上驚起，左右拔刃欲格之，上恐并中日磾，止勿格。日磾捽胡投何羅殿下，得禽縛之，窮治皆伏辜。繇是著忠孝節。

**互校说明** 马通以平定前91年太子案立功、受封，马何罗谋刺在前88年。

#### 卷022｜将相表互见与异说

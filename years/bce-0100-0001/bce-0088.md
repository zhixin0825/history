# 公元前88年｜戴侯蒙因祝诅罪被处死

**汉武帝后元元年**

本页先收本卷能够归年的侯籍材料，尚不代表本年全国史事已齐。

<a id="sj018-wudi"></a>
## 功臣后裔的承爵与失国

五月，戴侯蒙被以祝诅、无道罪处死，侯国撤销。 [R121](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r121)

<a id="sj018-note"></a>
### 卷018｜原格、异年与本页采用

**逐格定位：** <a id="sj018-r121-wu"></a>[R121](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r121)。

本页按原格中明确年号、承袭次序及互见材料分别定位；未载月份的不补日期，元年也不一律倒推父亲死年。侯爵与所任中央官职不是同一继承关系。

**R121：** 史表安期、汉表轸；蒙元鼎五年嗣、后元元年五月甲戌终局，汉表记祝诅上、腰斩。与次年前87年繆侯郦终根之案分开，不因为同属祝诅罪便合成同日一次清洗。

互校：[《汉书》高惠高后文功臣表](https://zh.wikisource.org/wiki/漢書/卷016) · [《史记》三家注卷018](https://zh.wikisource.org/wiki/史記三家註/卷018)。

<a id="sj019"></a>
## 封侯、承袭与侯国的变化

<a id="sj019-r081-e02"></a>
四月甲辰，遒侯则因使巫者齐少君祠祝诅而被追究，侯国撤销。 [原文与说明](#sj019-r081-e02-n)


<a id="sj019-note"></a>
### 卷019｜本年侯籍与异说

[完整原表](../../sources/摘录/史记-卷019-惠景间侯者年表.md) · [逐格去向](../../meta/记录/史记-卷019-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷019-纪年与异说.md)。原格的承侯元年不一律等于前任死年；未载月日不补，谥号是后称，国除也不一律等于处死。

<a id="sj019-r081-e02-n"></a>
**遒｜[R081原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r081)：** 本表“大道无道”与汉表大逆无道互校；司法记录的诅咒指控不证明巫术有实际效力。隆强至则之间的承袭姓名、年份失载，不补同一人长寿六十年。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e154"></a>
### 金日磾、霍光、上官桀制止马何罗一案

侍中马何罗与弟马通等谋反的案情暴露。金日磾在宫中制住何罗，霍光、上官桀也参与处置。这次护卫皇帝的行动，后来成为三人受封的重要理由。 [原文与说明](#sj020-e154-n)

<a id="sj020-note"></a>
### 卷020｜原格、互见与采用的年线

[完整原文](../../sources/摘录/史记-卷020-建元以来侯者年表.md) · [逐格去向](../../meta/记录/史记-卷020-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷020-纪年与异说.md)。初封、增邑、继承与任官分开；月日未明不补，谥号为后称，国除不一律等于处死。

<a id="sj020-e154-n"></a>
**金日磾、霍光、上官桀制止马何罗一案：** [S005 博陸](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s005) · [S006 秺](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s006) · [S007 安陽](../../sources/摘录/史记-卷020-建元以来侯者年表.md#s007)。汉霍光金日磾传与通鉴系后元元年；原称马／莽何罗的字形分层保留。史料对主谋、弟弟及各人动作略有压缩，未将参与者都写成独自杀死同一人。 互校：[漢書/卷068](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7068) · [資治通鑑/卷022](https://zh.wikisource.org/wiki/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91/%E5%8D%B7022)。

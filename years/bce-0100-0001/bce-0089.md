<a id="event-1"></a>

1. **田千秋任丞相，封富民侯。** 六月，田千秋由大鸿胪升为丞相，封富民侯。进谏后的任官、取代前相与授爵是接续的步骤，侯号也与武帝晚年转向休息、富养百姓的意向相连。 [[1]](#note-1)

<a id="hs-event-2"></a>

2. **武帝东巡至海滨。** 征和四年正月武帝到东莱，来到海滨。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **雍地落两块陨石。** 二月丁酉，史官记雍地落下两块石头，声闻四百里。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **鉅定行耕礼与泰山修封。** 三月武帝在鉅定行亲耕礼，回至泰山修封，庚寅祭明堂，癸巳在石闾行礼；六月返回甘泉。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **八月晦日发生日食。** 八月辛酉晦，发生日食。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **刘辅嗣中山王。** 刘辅嗣中山王。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **刘偃嗣真定王。** 刘偃嗣真定王。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **安道侯揭阳定｜获罪。** 表载安道侯揭阳定一支本年载相关罪案及处分。表中所载事项为因罪案杀人，被处死。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **无锡侯多军｜获罪。** 表载无锡侯多军一支本年载相关罪案及处分。表中所载事项为因罪案与归义赵文王将兵追反虏，到弘农擅弃兵还，赎罪，失爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **承父侯续相如｜获罪。** 表载承父侯续相如一支本年载相关罪案及处分。表中所载事项为四月癸亥，因罪案贼杀军吏，谋入蛮夷，祝诅上，被腰斩。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **丞父侯孙王｜受封。** 《汉书》侯籍列丞父侯孙王本年受封，所引月份、干支依表保留。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **富民定侯车千秋｜受封。** 表载富民定侯车千秋一支本年有始封记载。表中所载事项为六月丁巳封。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **初置司隶校尉。** 表将始置司隶校尉系征和四年，持节领官徒，治巫蛊及豪猾。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **武帝劝农，任赵过试行代田。** 《通鉴》卷022联系征和四年末年的政令，授官与日后推广分读。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **征和四年夏蝗。** [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **李广利在匈奴被杀。** 贰师将军李广利前一年兵败降匈奴，一度获单于优待。卫律忌惮其受宠，适逢单于母患病，令巫者借先单于之命促成杀害。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **狐鹿姑单于向汉通书并索岁给。** 狐鹿姑自称“天之骄子”，提出开关、娶汉女及输与酒米杂缯。汉使报送其使时与单于左右论戾太子及冒顿旧事，遂被留三年。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **轮台屯田奏与武帝诏答。** 桑弘羊与丞相、御史请扩展轮台一带屯田。武帝以损耗民力为由拒绝远屯，要求禁苛暴、止擅赋、劝农牧马并整边备。 [[19]](#hs-note-19)

> 其明年，單于遣使遺漢書云：「南有大漢，北有強胡。胡者，天之驕子也，不為小禮以自煩。今欲與漢闓大關，取漢女為妻，歲給遺我糱酒萬石，稷米五千斛，雜繒萬匹，它如故約，則邊不相盜矣。」漢遣使者報送其使，單于使左右難漢使者，曰：「漢，禮義國也。貳師道前太子發兵反，何也？」使者曰：「然。乃丞相私與太子爭鬥，太子發兵欲誅丞相，丞相誣之，故誅丞相。此子弄父兵，罪當笞，小過耳。孰與冒頓單于身殺其父代立，常妻後母，禽獸行也！」單于留使者，三歲乃得還。

**互校说明** 本传“其明年”承李广利降于征和三年；使者被扣三年为后续时长。

<a id="hs096-l10063-e19"></a>

**[《汉书·西域传》P115](../../sources/摘录/汉书-卷096-西域传.md#p115)** · [仓内TXT L10063](../../sources/本地分卷/汉书/汉书-卷096.md#L10063)

> 前有司奏，欲益民賦三十助邊用，是重困老弱孤獨也。而今又請遣卒田輪台。輪台西於車師千餘里，前開陵侯擊車師時，危須、尉犁、樓蘭六國子弟在京師者皆先歸，發畜食迎漢軍，又自發兵，凡數萬人，王各自將，共圍車師，降其王。諸國兵便罷，力不能復至道上食漢軍。漢軍破城，食至多，然士自載不足以竟師，強者盡食畜產，羸者道死數千人。朕發酒泉驢、橐駝負食，出玉門迎軍。吏卒起張掖，不甚遠，然尚廝留其眾。曩者，朕之不明，以軍候弘上書言「匈奴縛馬前後足，置城下，馳言『秦人，我匄若馬』」，又漢使者久留不還，故興遣貳師將軍，欲以為使者威重也。古者卿大夫與謀，參以蓍龜，不吉不行。乃者以縛馬書遍視丞相、御史、二千石、諸大夫、郎為文學者，乃至郡屬國都尉成忠、趙破奴等，皆以「虜自縛其馬，不祥甚哉！」或以為「欲以見強，夫不足者視人有餘。」《易》之卦得《大過》，爻在九五，匈奴困敗。公軍方士、太史治星望氣，及太卜龜蓍，皆以為吉，匈奴必破，時不可再得也。又曰：「北伐行將，於釜山必克。」卦諸將，貳師最吉。故朕親發貳師下釜山，詔之必毋深入。今計謀卦兆皆反繆。重合侯得虜候者，言：「聞漢軍當來，匈奴使巫埋羊牛所出諸道及水上以詛軍。單于遺天子馬裘，常使巫祝之。縛馬者，詛軍事也。」又卜「漢軍一將不吉」。匈奴常言：「漢極大，然不能飢渴，失一狼，走千羊。」

**互校说明** 武帝在征和四年诏内回顾旧战，出兵车师另据《通鉴》系前90年。

**[《汉书·西域传》P116](../../sources/摘录/汉书-卷096-西域传.md#p116)** · [仓内TXT L10064](../../sources/本地分卷/汉书/汉书-卷096.md#L10064)

> 乃者貳師敗，軍士死略離散，悲痛常在朕心。今請遠田輪台，欲起亭隧，是擾勞天下，非所以優民也。今朕不忍聞。大鴻臚等又議，欲募囚徒送匈奴使者，明封侯之賞以報忿，五伯所弗能為也。且匈奴得漢降者，常提掖搜索，問以所聞。今邊塞未正，闌出不禁，障候長吏使卒獵獸，以皮肉為利，卒苦而烽火乏，失亦上集不得，後降者來，若捕生口虜，乃知之。當今務在禁苛暴，止擅賦，力本農，修馬復令，以補缺，毋乏武備而已。郡國二千石各上進畜馬方略補邊狀，與計對。

**互校说明** 承上一段诏书，保留申禁苛暴、重视农事也整顿边备的具体条款。

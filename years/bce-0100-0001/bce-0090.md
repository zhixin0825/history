2. **胡倩被田广明捕杀，公孙勇被圉县官吏捕获。** 公孙勇与胡倩谋划起事，胡倩冒称奉命督察盗贼的光禄大夫，被淮阳太守田广明察觉，发兵捕杀。 公孙勇乘车、着绣衣来到圉县，又被当地官吏抓住。魏不害、苏昌、江德因参与捕反受封，分别为当涂、蒲、潦阳侯。 [[2]](#note-2)

<a id="sj020-e148"></a>
<a id="田千秋为太子申冤受任大鸿胪"></a>


<a id="event-3"></a>

3. **田千秋为太子申冤，受任大鸿胪。** 高寝郎田千秋上书，认为太子与父亲发生冲突，不能简单等同普通臣下蓄谋叛乱。武帝受到触动，召见他，拜为大鸿胪。田千秋原是长陵人，这次从守护高庙寝园的郎官迅速进入朝廷高位。 [[3]](#note-3)

4. **刘屈氂因巫蛊案件下狱，被处腰斩。** 《武帝纪》记刘屈氂在六月伏法，妻子也被处死。李广利出师、败降及其与此案的先后，见[本年北边战事](#hs-event-5)。 [[4]](#note-4)

<a id="hs-event-5"></a>

5. **汉三路出塞与李广利降匈奴。** 征和三年正月，武帝经雍巡安定、北地；匈奴入五原、酒泉，杀两都尉。三月李广利七万自五原、商丘成二万自西河、马通四万骑自酒泉出兵。商丘成在浚稽山战，马通至天山并降车师，随后还师；李广利败降匈奴。 [[5]](#hs-note-5)

#### 卷022｜将相表互见与异说

[卷022 R117原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r117)。刘屈氂死汉纪、汉表均六月，刑名腰斩由汉表补，不用“因蛊”证明诅咒确有超自然作用。原表“莽通”据汉纪重合侯马通辨认；汉纪广利出五原、成出西河，本表分别朔方、河西，保留地理差别，不拼成同一条精确路线。原相位“二”是屈氂截至死年的年度计数；田千秋任相接明年前89年。

### 卷018｜原格、异年与本页采用

**逐格定位：** <a id="sj018-r069-wu"></a>[R069](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r069)。

本页按原格中明确年号、承袭次序及互见材料分别定位；未载月份的不补日期，元年也不一律倒推父亲死年。侯爵与所任中央官职不是同一继承关系。

**R069：** 史表章元鼎四年、埤山仁元封元年及征和三年十月终局均有明年；汉表父子姓名作齐章、齐仁，亦可见其／齐字异写，另列章十三年等任期，与两明年不能全合。本页只记录能够定位的承封与结案，不为凑年数创造一个中间侯，也不将本案与前91年所有巫蛊案件视为同一日发生。罪名不证明祝诅有效。

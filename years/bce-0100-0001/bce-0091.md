# 公元前91年｜亚谷侯贺卷入太子事件

[← 公元前93年](bce-0093.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前90年 →](bce-0090.md)

**汉武帝征和二年**

本页在卷019亚谷侯结局上，补入卷020的公孙贺父子、韩说及丙吉保护刘病已等材料。太子事件的完整前因经过和全国其他史事仍待相关本纪、列传汇入，不用数项侯籍记录冒充整年历史。

<a id="sj019"></a>
## 封侯、承袭与侯国的变化

<a id="sj019-r086-e05"></a>
七月辛巳，亚谷侯贺因接受太子刘据的节信而受到追究。朝廷怀疑他参与太子的行动，他在拷掠中死去，侯国也被撤销。这里的节信原本可以证明奉谁的命令办事，到了太子与朝廷冲突时，却成了使持有者受牵连的证据。 [原文与说明](#sj019-r086-e05-n)


<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e145"></a>
### 公孙贺父子案

公孙贺之子敬声获罪，追查又牵连父亲。父子下狱，最终死于狱中，葛绎侯国撤销。 [原文与说明](#sj020-e145-n)

<a id="sj020-e146"></a>
### 韩说被太子杀死，按道侯统中断

韩说参加搜查太子宫中的巫蛊案，遭太子一方杀死。儿子长承侯后又获罪失爵；另一子曾后来恢复龙额侯一支。 [原文与说明](#sj020-e146-n)

<a id="sj020-e228"></a>
### 丙吉保护狱中的幼儿刘病已

太子案牵连尚在襁褓的刘病已，他被关进郡邸狱。参与处理案件的丙吉认为幼儿无辜，安排女囚照料、供给衣食，使他得以活下来。多年以后，孩子成为宣帝，才把这段旧恩报答给丙吉。 [原文与说明](#sj020-e228-n)

<a id="sj022"></a>
## 朝廷人事与本年补记

**公孙贺死后，刘屈氂出任丞相，封彭城侯。** 七月太子刘据发兵，韩说与江充被杀，丞相随后统兵与太子军在长安交战。暴胜之在事后被追究而自杀，商丘成继任御史大夫；太子出逃，后来也自杀。 [原文与说明](#sj022-note)

## 本年相关史料

<a id="sj022-note"></a>
### 卷022｜将相表互见与异说

[卷022 R116原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r116)。公孙贺父子案及韩说之死接本页旧条；将相表把贺死记在[前92年原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r115)“冬”，汉武帝纪征和二年正月、汉表同年四月壬申，年次优先取共同的征和二年，月份分歧不凑定日。刘屈氂任相本表三月丁巳、汉表五月丁巳；御史“成”为商丘成，汉表九月任。七月壬午起兵及太子八月自杀据汉纪分清，不能把杀江充与太子死亡写为同一天。暴胜之的失纵控罪不等于已证其参与巫蛊。天汉后续补层另标。

**原行四栏：** 大事：七月壬午，太子發兵，殺游擊將軍說、使者江充。；相位：三月丁巳，涿郡太守劉屈氂為丞相，封彭城侯。；将位：〔空白〕；御史：御史大夫成。

互校：[《汉书·百官公卿表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7019.md#ref-61d4640bb84bf7) · [《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-67e0d533eff6c1) · [卷022纪年与异说](../../meta/考证/史记-卷022-纪年与异说.md)。原表数字与空栏照存，未作独立古历日换算。

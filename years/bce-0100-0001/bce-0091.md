# 公元前91年｜亚谷侯贺卷入太子事件

[← 公元前92年](bce-0092.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前90年 →](bce-0090.md)

**汉武帝征和二年**

本页在卷019亚谷侯结局上，补入卷020的公孙贺父子、韩说及丙吉保护刘病已等材料。太子事件的完整前因经过和全国其他史事仍待相关本纪、列传汇入，不用数项侯籍记录冒充整年历史。

<a id="sj019-r086-e05"></a>

<a id="event-1"></a>

1. **七月辛巳，亚谷侯贺因接受太子刘据的节信而受到追究。** 朝廷怀疑他参与太子的行动，他在拷掠中死去，侯国也被撤销。这里的节信原本可以证明奉谁的命令办事，到了太子与朝廷冲突时，却成了使持有者受牵连的证据。 [[1]](#note-1)

<a id="sj020"></a>
<a id="军政受封与侯国的接续"></a>

<a id="sj020-e145"></a>
<a id="公孙贺父子案"></a>


<a id="event-2"></a>

2. **公孙贺父子案。** 公孙贺之子敬声获罪，追查又牵连父亲。父子下狱，最终死于狱中，葛绎侯国撤销。 [[2]](#note-2)

<a id="sj020-e146"></a>
<a id="韩说被太子杀死按道侯统中断"></a>


<a id="event-3"></a>

3. **韩说被太子杀死，按道侯由其子承袭。** 韩说参与搜查太子宫，遭太子一方杀死。其子长承侯，后来获罪失爵。《汉书》作韩兴。韩曾续封龙额侯的时间见[前88年](bce-0088.md#event-4)。 [[3]](#note-3)

<a id="sj020-e228"></a>
<a id="丙吉保护狱中的幼儿刘病已"></a>


<a id="event-4"></a>

4. **丙吉保护狱中的幼儿刘病已。** 太子案牵连尚在襁褓的刘病已，他被关进郡邸狱。参与处理案件的丙吉认为幼儿无辜，安排女囚照料、供给衣食，使他得以活下来。多年以后，孩子成为宣帝，才把这段旧恩报答给丙吉。 [[4]](#note-4)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-5"></a>

5. **公孙贺死后，刘屈氂出任丞相，封彭城侯。** 七月太子刘据发兵，韩说与江充被杀，丞相随后统兵与太子军在长安交战。暴胜之在事后被追究而自杀，商丘成继任御史大夫；太子出逃，后来也自杀。 田仁与任安的处置见[本年田仁、任安条](#sj104-p007)。 [[5]](#note-5)

<a id="sj054-event-6"></a>

6. **平阳侯曹宗因案失国。** 曹宗是曹襄之子、曹参后裔。在太子事件所在的这一年，他被追究罪责，平阳侯国撤销。其受刑的具体结局有不同记载，详见同号原文。 [[6]](#sj054-note-6)

<a id="sj104-event-7"></a>

7. **司直田仁和北军使者任安在太子案中获罪。** 太子刘据起兵以后，司直田仁受命守门，因放行获罪；《汉书·武帝纪》记田仁被腰斩。褚少孙补述北军使者任安受节而闭营、事后被诛。原传与补述的归罪过程有异。 [[7]](#note-7)

<a id="hs-event-8"></a>

8. **大风毁屋折木。** 四月，大风掀毁屋宇、折断树木。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **两公主因巫蛊案死。** 闰月，诸邑公主、阳石公主都因巫蛊案死。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **武帝前往甘泉。** 夏季，武帝到甘泉。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **巫蛊兵变、卫皇后自杀。** 太子持节发兵，与刘屈氂在长安交战，败逃后卫皇后自杀。朝廷开始在城门屯兵，并更改节的形制。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **太子刘据在湖县自杀。** 八月辛亥，刘据在湖县自杀，承上条七月长安兵变。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **癸亥日地震。** 本纪记癸亥日发生地震。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **刘偃继立赵王。** 九月，朝廷立赵敬肃王刘彭祖之子刘偃为王，谥平王。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **匈奴入上谷、五原。** 匈奴入上谷、五原杀掠官民。 [[15]](#hs-note-15)

> 是時任安爲北軍使者護軍，太子立車北軍南門外，召任安，與節令發兵。安拜受節，入，閉門不出。武帝聞之，以爲任安爲佯邪，不傅事，何也？任安笞辱北軍錢官小吏，小吏上書言之，以爲受太子節，言「幸與我其鮮好者」。書上聞，武帝曰：「是老吏也，見兵事起，欲坐觀成敗，見勝者欲合從之，有兩心。安有當死之罪甚衆，吾常活之，今懷詐，有不忠之心。」下安吏，誅死。

**本卷归年说明：** 太子授节、任安闭营有《汉书·刘屈氂传》互见。小吏的告发及武帝对其动机的判断按褚补归属；处死精确月日未据此确定。

<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[卷022 R116原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r116)。公孙贺父子案及韩说之死接本页旧条；将相表把贺死记在[前92年原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r115)“冬”，汉武帝纪征和二年正月、汉表同年四月壬申，年次优先取共同的征和二年，月份分歧不凑定日。刘屈氂任相本表三月丁巳、汉表五月丁巳；御史“成”为商丘成，汉表九月任。七月壬午起兵及太子八月自杀据汉纪分清，不能把杀江充与太子死亡写为同一天。暴胜之的失纵控罪不等于已证其参与巫蛊。天汉后续补层另标。

**原行四栏：** 大事：七月壬午，太子發兵，殺游擊將軍說、使者江充。；相位：三月丁巳，涿郡太守劉屈氂為丞相，封彭城侯。；将位：〔空白〕；御史：御史大夫成。

互校：[《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0091) · [《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-67e0d533eff6c1) · [卷022纪年与异说](../../meta/考证/史记-卷022-纪年与异说.md)。原表数字与空栏照存，未作独立古历日换算。

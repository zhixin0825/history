# 公元前92年｜武帝还建章宫、赵王刘彭祖去世

[← 公元前93年](bce-0093.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前91年 →](bce-0091.md)

**汉武帝征和元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **武帝还建章宫。** 征和元年正月，武帝返回建章宫。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **赵王刘彭祖去世。** 三月，赵王刘彭祖去世。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **搜上林与巫蛊案发端。** 十一月征发三辅骑士大搜上林，关闭长安城门搜索十一天才解除。本纪接记巫蛊案由此起。 [[3]](#hs-note-3)

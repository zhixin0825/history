<a id="event-1"></a>

1. **五月，江邹侯靳石因太常等职务中的违法处置被免侯，封国撤销。** [[1]](#note-1)

<a id="hs-event-2"></a>

2. **泰山明堂祭、修封与巡幸。** 太始四年三月到泰山，壬午祀高祖配上帝并受计，癸未祀景帝，甲申修封，丙戌禅石闾。四月到不其，在交门宫祭神并作歌；五月回建章宫宴饮、大赦。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **赵地两群蛇相斗。** 七月，史书称赵国城外的蛇入城，与城内蛇在孝文庙下相斗，城中蛇死亡。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **冬十月日食记载。** 十月甲寅晦，本纪记日食。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **雍祭并巡安定、北地。** 十二月武帝到雍祠五畤，向西至安定、北地。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **汾阳严侯靳强｜获罪。** 表载汾阳严侯靳强一支本年载相关罪案及处分。表中所载事项为因罪案为太常行幸离宫道桥苦恶，大仆敬声系因谒闻，赦失爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **义阳侯衞山｜获罪。** 表载义阳侯衞山一支本年载相关罪案及处分。表中所载事项为因罪案敎人诳告衆利侯当时被处死罪，狱未断病死。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **梁期侯任破胡｜获罪。** 表载梁期侯任破胡一支本年载相关罪案及处分。表中所载事项为因罪案卖马一匹贾钱十五万，过平，臧五百因上，失爵。 [[8]](#hs-note-8)

**互校说明** 本纪列高祖、景帝先后配祭或受祭，各有干支；前106年初祀、前104年再祀上帝，均非同一次礼仪。

### 卷018｜原格、异年与本页采用

**逐格定位：** <a id="sj018-r120-wu"></a>[R120](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r120)。

本页按原格中明确年号、承袭次序及互见材料分别定位；未载月份的不补日期，元年也不一律倒推父亲死年。侯爵与所任中央官职不是同一继承关系。

**R120：** 元鼎五年石元年、太始四年五月丁卯国除在史表有明年，后案两表详略不同：史表“行太仆事，治啬夫可年，益纵年”断句难明；汉表另记行幸离宫道路桥梁不修、太仆敬声案与以谒闻获赦。正文只采用任官违法、免侯的共同结果，保留两种案文，不猜可年的完整身份，不把两说拼成两次独立刑案或添加死刑。

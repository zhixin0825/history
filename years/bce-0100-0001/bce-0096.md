# 公元前96年｜豪强与官民迁往两陵

[← 公元前97年](bce-0097.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前95年 →](bce-0095.md)

**汉武帝太始元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **公孙敖腰斩。** 太始元年正月，因杅将军公孙敖获罪，被腰斩。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **豪强与官民迁往两陵。** 把各郡国的官吏及民间豪强迁到茂陵、云陵，地名沿底本文字。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **六月大赦。** 六月，朝廷赦天下。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **临衆敬侯始昌一支爵位承袭。** 太始元年，康侯革生继承侯爵，十八年去世。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **公丘夷侯顺一支爵位承袭。** 太始元年，康侯置继承侯爵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **常乐侯稠雕｜去世。** 表载常乐侯稠雕一支本年记载去世。表中所载事项为去世，无继承人。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[7]](#hs-note-7)

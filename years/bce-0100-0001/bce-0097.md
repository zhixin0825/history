# 公元前97年｜李广利、公孙敖、韩说多路出兵匈奴

[← 公元前98年](bce-0098.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前95年 →](bce-0095.md)

**汉武帝天汉四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **汉廷再次多路出兵匈奴。** 李广利从朔方出发，在余吾水一带与单于交战；韩说从五原出兵，公孙敖由雁门出兵，路博德所部参加会军。李广利与公孙敖各路最后都退回。 [[1]](#note-1)

<a id="sj049-liubo-changyi-event"></a>

2. **皇子刘髆被封为昌邑王。** 他是武帝与中山李夫人之子；刘贺是他的下一代，不能用孙辈的名字替代本次受封者。李夫人受宠、生育与早逝的具体年月另作未定年阅读。 [[2]](#sj049-liubo-changyi-note)

<a id="sj058-liang-xiang-dies-event"></a>

3. **梁平王刘襄去世，儿子刘无伤承嗣。** 刘襄是梁共王刘买之子、梁孝王刘武之孙。刘无伤承继封国，下一年前96年开始记新王元年。 [[3]](#sj058-liang-xiang-dies-note)

<a id="sj109-event-4"></a>

4. **公孙敖还报，李陵家属被诛。** 公孙敖出塞试图接回李陵，回来后报告听俘虏说李陵在替匈奴练兵。汉廷随后诛杀李陵家属。《汉书》另记这一消息把已降匈奴的李绪错当成了李陵。 [[4]](#note-4)

### 1. 汉廷再次多路出兵匈奴

[返回正文第1条](#event-1)

<a id="sj110-p060-e1"></a>

**[《史记·匈奴列传》P060](../../sources/摘录/史记-卷110-匈奴列传.md#p060)** · [三家注](../../sources/史记三家注/卷110.md#p60)

> 後二歲，復使貳師將軍將六萬騎，步兵十萬，出朔方。彊弩都尉路博德將萬餘人，與貳師會。游擊將軍說將步騎三萬人，出五原。因杅將軍敖將萬騎步兵三萬人，出鴈門。匈奴聞，悉遠其累重於余吾水北，而單于以十萬騎待水南，與貳師將軍接戰。貳師乃解而引歸，與單于連戰十餘日。

**本卷归年说明：** 《汉书·武帝纪》天汉四年及《匈奴传》此役主帅均退回；步兵七万异本传“十万”。

<a id="sj110-p060-e1-2"></a>

**[《史记·匈奴列传》P060](../../sources/摘录/史记-卷110-匈奴列传.md#p060)** · [三家注](../../sources/史记三家注/卷110.md#p60)

> 游擊說無所得。因杅敖與左賢王戰，不利，引歸。

**本卷归年说明：** 这是韩说、公孙敖在同年各自一路的结果，前90年的实际出兵将领不同。

<a id="sj111-p029"></a>

**[《史记·卫将军骠骑列传》P029](../../sources/摘录/史记-卷111-卫将军骠骑列传.md#p029)** · [三家注](../../sources/史记三家注/卷111.md#p29)

> 七歲，復以因杅將軍再出擊匈奴，至余吾

**本卷归年说明：** 所述余吾战见《汉书》天汉四年，公孙敖路线出雁门；晚期诈死、族诛属后续。


**[卷022 R110原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r110)**

### 3. 梁平王刘襄去世，儿子刘无伤承嗣

[返回正文第3条](#sj058-liang-xiang-dies-event)

**归年与释读：** 无伤又作毋伤。汉表从建元五年前136年记刘襄元年，四十年接前97年，次年太始元年记无伤元年；本篇作三十九年卒，保存这一年数差别。

<a id="sj058-cite-044"></a>

**[《史记·梁孝王世家》P017](../../sources/摘录/史记-卷058-梁孝王世家.md#p017)**

> 襄立三十九年卒，謚為平王。子無傷立為梁王也。

**本卷说明：** 汉书王表明载襄四十年与无伤太始元年承嗣，因此本页采用前97卒、前96新王元年；不把本篇三十九年无说明套成同一算式。

<!-- /sj058-cite-044 -->

<a id="sj058-cite-045"></a>

**[《汉书·诸侯王表》梁王统](../../sources/本地分卷/汉书/汉书-卷014.md#L1400)**

> 建元五年，平王襄嗣，四十年薨。 太始元年，貞王毋傷嗣，十一年薨。

**本卷说明：** 表链支持本年死亡。无伤／毋伤为同一后嗣姓名异写。

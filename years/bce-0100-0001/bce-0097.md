# 公元前97年｜李广利、公孙敖、韩说多路出兵匈奴

[← 公元前98年](bce-0098.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前96年 →](bce-0096.md)

**汉武帝天汉四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **汉廷再次多路出兵匈奴。** 李广利从朔方出发，在余吾水一带与单于交战；韩说从五原出兵，公孙敖由雁门出兵，路博德所部参加会军。李广利与公孙敖各路最后都退回。 [[1]](#note-1)

<a id="sj049-liubo-changyi-event"></a>

2. **皇子刘髆被封为昌邑王。** 他是武帝与中山李夫人之子；刘贺是他的下一代，不能用孙辈的名字替代本次受封者。李夫人受宠、生育与早逝的具体年月另作未定年阅读。 [[2]](#sj049-liubo-changyi-note)

<a id="sj058-liang-xiang-dies-event"></a>

3. **梁平王刘襄去世，儿子刘无伤承嗣。** 刘襄是梁共王刘买之子、梁孝王刘武之孙。刘无伤承继封国，下一年前96年开始记新王元年。 [[3]](#sj058-liang-xiang-dies-note)

<a id="sj109-event-4"></a>

4. **公孙敖还报，李陵家属被诛。** 公孙敖出塞试图接回李陵，回来后报告听俘虏说李陵在替匈奴练兵。汉廷随后诛杀李陵家属。《汉书》另记这一消息把已降匈奴的李绪错当成了李陵。 [[4]](#note-4)

<a id="hs-event-5"></a>

5. **死罪人可赎减一等。** 九月规定死罪者可纳五十万钱赎减一等。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **刘顺承城阳王。** 刘顺承城阳王。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **刘宽嗣济北王。** 刘宽嗣济北王。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **刘庆嗣河间王。** 刘庆嗣河间王。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **广望节侯忠一支爵位承袭。** 天汉四年，顷侯中继承侯爵，十三年去世。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[10]](#hs-note-10)

#### 卷022｜将相表互见与异说

[卷022 R110原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r110)。本表列李广利、韩说、公孙敖三人，汉书武帝纪天汉四年另补路博德及敖从雁门的路线。各路兵数未合为同一场战斗中的即时人数，也不把天汉二年前99年的李陵败降误放本年。相位“七”续公孙贺。

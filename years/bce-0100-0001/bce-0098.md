# 公元前98年｜天汉三年再修封泰山，追问求仙的结果

[← 公元前100年](bce-0100.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前97年 →](bce-0097.md)

**汉武帝天汉三年**

本页记录《孝武本纪》涉及的宗庙、郊祭、方士与制度变化；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，卷十二的跨年回叙不当成同年新事。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj012-98-1"></a>
<a id="泰山再修封回程过祭常山"></a>

<a id="event-1"></a>

1. **春三月，武帝再登泰山修封、祭明堂，返程经过常山又行祭礼。** 卷十二结尾以「其后五年」略述这次巡封，独立年次据《汉书》天汉三年核对；不因古人包容计年方式而硬把它改成前97年。 [[1]](#note-1)

<a id="event-2"></a>

2. **长期求蓬莱仙人与延寿方术，至此仍拿不出验证。** 皇帝对虚妄之词渐觉厌倦，却未彻底断绝方士，因为仍抱着可能遇见真仙的希望。卷末的反思是跨多年的制度总结，而不是这年一纸宣布废除全部祭祀的诏书。 [[2]](#note-2)

   《汉书》天汉三年春三月明载「修封，祀明堂」与「祠常山」；卷012「其后五年」与严格差年不一致，依明年次处理。

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-3"></a>

3. **王卿获罪自杀，杜周由执金吾升任御史大夫。** 朝廷的人事更替与本页原有泰山巡封，是这一年两条并行的线索。 [[3]](#note-3)

#### 卷022｜将相表互见与异说

[卷022 R109原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r109)。本表御史“周”据汉表天汉三年二月“执金吾杜周”辨认；不是早已去世的周昌。王卿之死与汉书武帝纪同年二月相接；罪名原纪简，本文不据“有罪”补一份具体案情。相位“六”续公孙贺。

**原行四栏：** 大事：〔空白〕；相位：六；将位：〔空白〕；御史：御史大夫周。

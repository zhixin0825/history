# 公元前99年｜李陵出塞与李广利击匈奴

[← 公元前100年](bce-0100.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前98年 →](bce-0098.md)

**汉武帝天汉二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj109-event-1"></a>

1. **李广利从酒泉出击匈奴右贤王。** 五月，贰师将军李广利率三万骑从酒泉出塞，在天山与匈奴右贤王交战，后在回师中被围，赵充国等率兵突围，汉军伤亡严重。 [[1]](#note-1)

<a id="sj109-event-2"></a>

2. **李陵兵败，降于匈奴。** 李陵率五千步卒北出居延，试图分散匈奴兵力。单于在浚稽山一带围住这支汉军。李陵边打边退，最后粮尽矢绝、又无援军，投降匈奴，约四百部卒逃归。李广利一路自酒泉出兵，另见本年同役。 司马迁为李陵陈说，被武帝认为是在贬抑李广利，获罪入狱。 [[2]](#note-2)

<a id="sj122-event-3"></a>

3. **《资治通鉴》叙群盗与沈命法。** 朝廷遣绣衣使者捕盗。沈命法规定，群盗发生不发觉或发觉后捕获不足额，主管大小官吏皆死。官吏因畏罚相互隐匿。 绣衣使者暴胜之到勃海，听取雋不疑所陈刚柔并施之要，荐其为青州刺史。 [[3]](#note-3)

<a id="hs-event-4"></a>

4. **巡东海后到回中。** 天汉二年春武帝出行至东海，返后又到回中。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **停道路巫祠及再度大搜。** 秋季朝廷停止道路上的巫祠，又进行大规模搜查。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **渠黎等六国派使来献。** 本纪记渠黎等六国遣使进献。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **关都尉严查出入。** 十一月诏说豪强多与远处结交、依托东方群盗，命掌关官员谨慎查验出入者。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **澅清侯参｜获罪。** 表载澅清侯参一支本年载相关罪案及处分。表中所载事项为因罪案匿朝鲜亡虏，下狱病死。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **瓡讘侯杆者｜去世。** 表载瓡讘侯杆者一支本年记载去世。表中所载事项为去世，制所幸封，不得承爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **开陵侯率楼兰兵攻车师失利。** 介和王受封开陵侯，率楼兰兵攻车师，匈奴右贤王率兵来救，汉军撤回。 [[11]](#hs-note-11)

### 2. 李陵兵败，降于匈奴

[返回正文第2条](#sj109-event-2)

<a id="hs094-l9818-e2"></a>

**[《汉书·匈奴传》P060](../../sources/摘录/汉书-卷094-匈奴传.md#p060)** · [仓内TXT L9818](../../sources/本地分卷/汉书/汉书-卷094.md#L9818)

> 使騎都尉李陵將步兵五千人出居延北千餘里，與單于會，合戰，陵所殺傷萬餘人，兵食盡，欲歸，單于圍陵，陵降匈奴，其兵得脫歸漢者四百人。單于乃貴陵，以其女妻之。

**互校说明** 天汉二年李陵降及得归汉者之数，既有条接入；女婿关系是随后待遇。

<a id="hs054-l7920-e2"></a>

**[《汉书·李广苏建传》P018](../../sources/摘录/汉书-卷054-李广苏建传.md#p018)** · [仓内TXT L7920](../../sources/本地分卷/汉书/汉书-卷054.md#L7920)

> 召陵，欲使為貳師將輜重。陵召見武台，叩頭自請曰：「臣所將屯邊者，皆荊楚勇士奇材劍客也，力扼虎，射命中，願得自當一隊，到蘭干山南以分單于兵，毋令專鄉貳師軍。」上曰：「將惡相屬邪！吾發軍多，毋騎予女。」陵對：「無所事騎，臣願以少擊眾，步兵五千人涉單于庭。」上壯而許之，因詔強弩都尉路博德將兵半道迎陵軍。博德故伏波將軍，亦羞為陵後距，奏言：「方秋匈奴馬肥，未可與戰，臣願留陵至春，俱將酒泉、張掖騎各五千人並擊東西浚稽，可必禽也。」書奏，上怒，疑陵悔不欲出而教博德上書，乃詔博德：「吾欲予李陵騎，云『欲以少擊眾』。今虜入西河，其引兵走西河，遮鉤營之道。」詔陵：「以九月發，出庶虜鄣，至東浚稽山南龍勒水上，徘徊觀虜，即亡所見，從浞野侯趙破奴故道抵受降城休士，因騎置以聞。所與博德言者云何？具以書對。」陵於是將其步卒五千人出居延，北行三十日，至浚稽山止營，舉圖所過山川地形，使麾下騎陳步樂還以聞。步樂召見，道陵將率得士死力，上甚說，拜步樂為郎。

<a id="hs054-l7921-e2"></a>

**[《汉书·李广苏建传》P019](../../sources/摘录/汉书-卷054-李广苏建传.md#p019)** · [仓内TXT L7921](../../sources/本地分卷/汉书/汉书-卷054.md#L7921)

> 陵至浚稽山，與單于相直，騎可三萬圍陵軍。軍居兩山間，以大車為營。陵引士出營外為陳，前行持戟盾，後行持弓弩，令曰：「聞鼓聲而縱，聞金聲而止。」虜見漢軍少，直前就營。陵搏戰攻之，千弩俱發，應弦而倒。虜還走上山，漢軍追擊，殺數千人。

<a id="hs054-l7922-e2"></a>

**[《汉书·李广苏建传》P020](../../sources/摘录/汉书-卷054-李广苏建传.md#p020)** · [仓内TXT L7922](../../sources/本地分卷/汉书/汉书-卷054.md#L7922)

> 虜騎數千追之，韓延年戰死。陵曰：「無面目報陛下！」遂降。軍人分散，脫至塞者四百餘人。

<a id="hs054-l7923-e2"></a>

**[《汉书·李广苏建传》P021](../../sources/摘录/汉书-卷054-李广苏建传.md#p021)** · [仓内TXT L7923](../../sources/本地分卷/汉书/汉书-卷054.md#L7923)

> 陵敗處去塞百餘里，邊塞以聞。上欲陵死戰，召陵母及婦，使相者視之，無死喪色。後聞陵降，上怒甚，責問陳步樂，步樂自殺。群臣皆罪陵，上以問太史令司馬遷，遷盛言：「陵事親孝，與士信，常奮不顧身以殉國家之急。其素所畜積也，有國士之風。今舉事一不幸，全軀保妻子之臣隨而媒糵其短，誠可痛也！且陵提步卒不滿五千，深輮戎馬之地，抑數萬之師，虜救死扶傷不暇，悉舉引弓之民共攻圍之。轉鬪千里，矢盡道窮，士張空拳，冒白刃，北首爭死敵，得人之死力，雖古名將不過也。身雖䧟敗，然其所摧敗亦足暴於天下。彼之不死，宜欲得當以報漢也。」

**互校说明** 《酷吏传》与《通鉴》天汉二年条有魏郡群盗与绣衣使者，王贺个人去职未见该年明文。

<a id="hs071-l8708-e3"></a>

**[《汉书·隽疏于薛平彭传》P002](../../sources/摘录/汉书-卷071-隽疏于薛平彭传.md#p002)** · [仓内TXT L8708](../../sources/本地分卷/汉书/汉书-卷071.md#L8708)

> 武帝末，郡國盜賊群起，暴勝之為直指使者，衣繡衣，持斧，逐捕盜賊，督課郡國，東至海，以軍興誅不從命者，威振州郡。勝之素聞不疑賢，至勃海，遣吏請與相見。不疑冠進賢冠，帶櫑具劍，佩環玦，褒衣博帶，盛服至門上謁。門下欲使解劍，不疑曰：「劍者，君子武備，所以衛身，不可解。請退。」吏白勝之。勝之開閣延請，望見不疑容貌尊嚴，衣冠甚偉，勝之□履起迎。登堂坐定，不疑據地曰：「竊伏海瀕，聞暴公子威名舊矣，今乃承顏接辭。凡為吏，太剛則折，太柔則廢，威行施之以恩，然後樹功揚名，永終天祿。」勝之知不疑非庸人，敬納其戒，深接以禮意，問當世所施行。門下諸從事皆州郡選吏，側聽不疑，莫不驚駭。至昏夜，罷去。勝之遂表薦不疑，征詣公車，拜為青州刺史。

**互校说明** 传作武帝末；《通鉴》卷021在天汉二年群盗、沈命法条叙暴胜之到勃海及荐不疑。此为编次，见面与任命月日失载。

<a id="hs090-l9615-e3"></a>

**[《汉书·酷吏传》P034](../../sources/摘录/汉书-卷090-酷吏传.md#p034)** · [仓内TXT L9615](../../sources/本地分卷/汉书/汉书-卷090.md#L9615)

> 是時郡守尉諸侯相二千石欲為治者，大抵盡效王溫舒等，而吏民益輕犯法，盜賊滋起。南陽有梅免、百政，楚有段中、杜少，齊有徐勃，燕趙之間有堅盧、范主之屬。大群至數千人，擅自號，攻城邑，取庫兵，釋死罪，縛辱郡守都尉，殺二千石，為檄告縣趨具食；小群以百數，掠鹵鄉里者不可稱數。於是上始使御史中丞、丞相長史使督之，猶弗能禁，乃使光祿大夫范昆、諸部都尉及故九卿張德等衣繡衣持節，虎符發兵以興擊，斬首大部或至萬餘級。及以法誅通行飲食，坐相連郡，甚者數千人。數歲，乃頗得其渠率。散卒失亡，復聚黨阻山川。往往而群，無可奈何。於是作沈命法，曰：「群盜起不發覺，發覺而弗捕滿品者，二千石以下至小吏主者皆死。」其後小吏畏誅，雖有盜弗敢發，恐不能得，坐課累府，府亦使不言。故盜賊寖多，上下相為匿，以避文法焉。

**互校说明** 《通鉴》系群盗和沈命法于天汉二年。各地群盗发生有先后和持续，责任法及朝廷督捕措施合入原条。

<a id="hs006-l515-e3"></a>

**[《汉书·武帝纪》P197](../../sources/摘录/汉书-卷006-武帝纪.md#p197)** · [仓内TXT L515](../../sources/本地分卷/汉书/汉书-卷006.md#L515)

> 泰山、琅邪群盜徐绗等阻山攻城，道路不通。遣直指使者暴勝之等衣繡衣杖斧分部逐捕。刺史郡守以下皆伏誅。

**互校说明** 底本“徐绗”照录，《汉书·酷吏传》作“徐勃”；《资治通鉴》另详沈命法与治盗背景。

<a id="sj122-p036"></a>

**[《史记·酷吏列传》P036](../../sources/摘录/史记-卷122-酷吏列传.md#p036)** · [三家注](../../sources/史记三家注/卷122.md#p36)

> 於是作「沈命法」，曰羣盜起不發覺，發覺而捕弗滿品者，二千石以下至小吏主者皆死。其後小吏畏誅，雖有盜不敢發，恐不能得，坐課累府，府亦使其不言。

**本卷归年说明：** 《通鉴》在天汉二年叙群盗与沈命法，正文已明言缉捕数岁，故此系编年所载而非条文颁日。 [《资治通鉴》卷21](../../sources/资治通鉴/KR2b0007_021.txt#L710)

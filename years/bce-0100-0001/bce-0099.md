# 公元前99年｜李陵出塞与李广利击匈奴

[← 公元前100年](bce-0100.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前98年 →](bce-0098.md)

**汉武帝天汉二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj109-event-1"></a>

1. **李广利从酒泉出击匈奴右贤王。** 五月，贰师将军李广利率三万骑从酒泉出塞，在天山与匈奴右贤王交战，后在回师中被围，赵充国等率兵突围，汉军伤亡严重。 [[1]](#note-1)

<a id="sj109-event-2"></a>

2. **李陵兵败，降于匈奴。** 李陵率五千步卒北出居延，试图分散匈奴兵力。单于在浚稽山一带围住这支汉军。李陵边打边退，最后粮尽矢绝、又无援军，投降匈奴，约四百部卒逃归。李广利一路自酒泉出兵，另见本年同役。 司马迁为李陵陈说，被武帝认为是在贬抑李广利，获罪入狱。 [[2]](#note-2)

<a id="sj122-event-3"></a>

3. **《资治通鉴》叙群盗与沈命法。** 朝廷遣绣衣使者捕盗。沈命法规定，群盗发生不发觉或发觉后捕获不足额，主管大小官吏皆死。官吏因畏罚相互隐匿。 [[3]](#note-3)

<a id="hs-event-4"></a>

4. **巡东海后到回中。** 天汉二年春武帝出行至东海，返后又到回中。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **停道路巫祠及再度大搜。** 秋季朝廷停止道路上的巫祠，又进行大规模搜查。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **渠黎等六国派使来献。** 本纪记渠黎等六国遣使进献。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **关都尉严查出入。** 十一月诏说豪强多与远处结交、依托东方群盗，命掌关官员谨慎查验出入者。 [[7]](#hs-note-7)

### 2. 李陵兵败，降于匈奴

[返回正文第2条](#sj109-event-2)

<a id="hs006-l512-e2"></a>

**[《汉书·武帝纪》P194](../../sources/摘录/汉书-卷006-武帝纪.md#p194)** · [仓内TXT L512](../../sources/本地分卷/汉书/汉书-卷006.md#L512)

> 騎都尉李陵將步兵五千人出居延北，與單于戰，斬首虜萬餘級。陵兵敗，降匈奴。

<a id="sj130-p018"></a>

**[《史记·太史公自序》P018](../../sources/摘录/史记-卷130-太史公自序.md#p018)** · [三家注](../../sources/史记三家注/卷130.md#p18)

> 七年而太史公遭李陵之禍，幽於縲紲。

**本卷归年说明：** 卷130用“七年”追叙，汉书司马迁传作“十年”；两者均与李陵本传明确纪年的战事互校。《汉书·李广苏建传》列李陵降于天汉二年；《司马迁传》及《报任安书》补获罪缘由。其后刑罚施行日另存时期。


<a id="sj109-p016-e0-2"></a>

**[《史记·李将军列传》P016](../../sources/摘录/史记-卷109-李将军列传.md#p016)** · [三家注](../../sources/史记三家注/卷109.md#p16)

> 而使陵將其射士步兵五千人出居延北可千餘里，欲以分匈奴兵，毋令專走貳師也。陵旣至期還，而單于以兵八萬圍擊陵軍。陵軍五千人，兵矢旣盡，士死者過半，而所殺傷匈奴亦萬餘人。且引且戰，連鬬八日，還未到居延百餘里，匈奴遮狹絕道，陵食乏而救兵不到，虜急擊招降陵。陵曰：「無面目報陛下。」遂降匈奴。其兵盡沒，餘亡散得歸漢者四百餘人。

**本卷归年说明：** 本传八万围军、退战八日，《汉书》详传记先有三万骑、后会八万余。两书皆说约四百人脱归。《武帝纪》与《通鉴》同年，《通鉴》列秋九月令发。

**[《汉书·武帝纪》](../../sources/本地分卷/汉书/汉书-卷006.md#L512)**

**[《资治通鉴》卷二十一](../../sources/本地分卷/资治通鉴/资治通鉴-卷021.md#L629)**

**[《汉书·李广苏建传》](../../sources/二十四史/txt/02_hanshu_full.txt#L7920-L7925)**

<a id="sj110-p059-e0-2"></a>

**[《史记·匈奴列传》P059](../../sources/摘录/史记-卷110-匈奴列传.md#p059)** · [三家注](../../sources/史记三家注/卷110.md#p59)

> 又使騎都尉李陵將步騎五千人，出居延北千餘里，與單于會，合戰，陵所殺傷萬餘人，兵及食盡，欲解歸，匈奴圍陵，陵降匈奴，其兵遂沒，得還者四百人。單于乃貴陵，以其女妻之。

**本卷归年说明：** “步骑五千”与《汉书·李广苏建传》《武帝纪》的“步兵五千”异，采用汉书。婚配属投降后待遇，无确月。

### 3. 《资治通鉴》叙群盗与沈命法

[返回正文第3条](#sj122-event-3)

<a id="hs006-l515-e3"></a>

**[《汉书·武帝纪》P197](../../sources/摘录/汉书-卷006-武帝纪.md#p197)** · [仓内TXT L515](../../sources/本地分卷/汉书/汉书-卷006.md#L515)

> 泰山、琅邪群盜徐绗等阻山攻城，道路不通。遣直指使者暴勝之等衣繡衣杖斧分部逐捕。刺史郡守以下皆伏誅。

**互校说明** 底本“徐绗”照录，《汉书·酷吏传》作“徐勃”；《资治通鉴》另详沈命法与治盗背景。

<a id="sj122-p036"></a>

**[《史记·酷吏列传》P036](../../sources/摘录/史记-卷122-酷吏列传.md#p036)** · [三家注](../../sources/史记三家注/卷122.md#p36)

> 於是作「沈命法」，曰羣盜起不發覺，發覺而捕弗滿品者，二千石以下至小吏主者皆死。其後小吏畏誅，雖有盜不敢發，恐不能得，坐課累府，府亦使其不言。

**本卷归年说明：** 《通鉴》在天汉二年叙群盗与沈命法，正文已明言缉捕数岁，故此系编年所载而非条文颁日。 [《资治通鉴》卷21](../../sources/资治通鉴/KR2b0007_021.txt#L710)

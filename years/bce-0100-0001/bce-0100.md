# 公元前100年｜济南太守王卿入任御史大夫

[← 公元前101年](../bce-0200-0101/bce-0101.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前99年 →](bce-0099.md)

**汉武帝天汉元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-1"></a>

1. **济南太守王卿出任御史大夫。** 他从郡守升入中央，与继续在任的丞相公孙贺分掌不同职务。 [[1]](#note-1)

<a id="sj059-changsha-fuju-event"></a>

2. **长沙王刘鮒鮈开始记元年。** 刘鮒鮈又作附朐，是前一年去世的刘庸之子。本年为天汉元年，长沙王统由他延续。 [[2]](#sj059-changsha-fuju-note)

<a id="sj103-event-3"></a>

3. **牧丘侯石德任太常时获罪。** 《汉书》侯表将牧丘侯石德案系于天汉元年。获罪及失侯为两书互见，案件细节和处分措辞有差别。 [[3]](#note-3)

<a id="sj110-event-4"></a>

4. **汉遣苏武使匈奴。** 且鞮侯放还汉使之后，汉遣苏武送还被留在汉的匈奴使者，并携礼物出使。 [[4]](#note-4)

<a id="sj110-event-5"></a>

5. **赵破奴逃回汉境。** 赵破奴太初二年被匈奴俘获，至天汉元年逃回。 [[5]](#note-5)

<a id="sj111-event-6"></a>

6. **卫伉因擅入宫门失长平侯。** 卫伉承长平侯后，又因擅入宫禁获罪，按侯表登记除国。 [[6]](#note-6)

<a id="hs-event-7"></a>

7. **甘泉祭泰一与河东祭后土。** 天汉元年正月到甘泉郊祭泰畤，三月到河东祭后土。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **五月大赦。** 夏五月，朝廷赦天下。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **关门搜查及发人戍五原。** 秋季关闭城门大搜，另发谪戍人员屯五原。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **刘延寿继楚王。** 刘延寿继楚王。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **邵侯顺一支失爵。** 天汉元年，因杀人获罪及奴凡十六人，以捕匈奴千骑，免去侯爵。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **挟术侯昆景一支去世。** 天汉元年去世，无子嗣承继。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **宜春侯卫伉｜获罪。** 表载宜春侯卫伉一支本年载相关罪案及处分。表中所载事项为阑入宫，未处肉刑，服城旦劳役。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **天汉元年夏大旱。** 《汉书》在本年记载天汉元年夏大旱。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **天汉元年记天雨白毛。** 《汉书》在本年记载天汉元年记天雨白毛。 [[16]](#hs-note-16)

#### 卷022｜将相表互见与异说

[卷022 R107原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r107)。御史栏只写“卿”，汉表天汉元年明称“济南太守琅邪王卿”，故补全王姓与前职，不能误认文学词语“公卿”。相位“四”续公孙贺；原表其余空栏不另编无据的全国事件。

**原行四栏：** 大事：〔空白〕；相位：四；将位：〔空白〕；御史：御史大夫卿。

互校：[《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0100) · [《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-74baee44d72224) · [卷022纪年与异说](../../meta/考证/史记-卷022-纪年与异说.md)。原表数字与空栏照存，未作独立古历日换算。

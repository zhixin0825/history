# 汉书何武王嘉师丹仕履与封事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **何武少习王褒之诗。** 益州刺史王襄使王褒作三诗颂汉，何武少年时与杨覆众等学唱。宣帝在宣室召见，谦辞不敢当盛颂，留王褒待诏，赐何武等帛后遣归。 [[1]](#note-1)


<a id="event-2"></a>

2. **从学与初仕。** 何武从博士学《易》，射策甲科为郎，与翟方进相友。光禄勋按四种德行荐举，何武升鄠令，后坐法免职。 [[2]](#note-2)


<a id="event-3"></a>

3. **举荐查办自家租赋的市吏。** 何显家有市籍却常欠租，市啬夫求商加以追究。何武制止弟弟借官府报复，反向太守荐用求商，州里信服。 [[3]](#note-3)


<a id="event-4"></a>

4. **王音荐何武。** 何武由王音荐举，经过对策拜谏大夫，转扬州刺史。揭举二千石官时先公开奏章，认罪者按例减免，抗辩而实有罪者依法重论。 [[4]](#note-4)


<a id="event-5"></a>

5. **戴圣父子与平断。** 何武查实九江太守戴圣违法，戴圣惧而自行免官，后来又在朝中毁谤。戴圣之子因宾客为盗牵连，何武据实审理，使其免死，戴圣遂惭而谢。 [[5]](#note-5)


<a id="event-6"></a>

6. **扬州按部次序。** 何武及时奏报二千石的罪行，对未获罪的各郡守相以礼相待。巡行先察学校、问诸生，再访垦田和收成，最后见郡国长官。 [[6]](#note-6)


<a id="event-7"></a>

7. **以公职拒绝私谒。** 故太守何寿借宴席透露侄儿从未得到何武接见。何武认为刺史应举善退恶，无从私问属吏；亲友坚持，才见而赐酒，侄儿后来由本郡荐举。 [[7]](#note-7)


<a id="event-8"></a>

8. **何武拜大司空与改封。** 何武历刺史、郡守、京兆尹、廷尉诸任，接孔光为御史大夫。成帝改置三公，以何武为大司空，封氾乡侯；哀帝初改食南阳博望并增邑。原转录作“綏和三年”，拜御史大夫和改司空据纪表系绥和元年。 [[8]](#note-8)


<a id="event-9"></a>

9. **举用两龚两唐。** 何武在楚、沛赏识两龚、两唐，入朝后举荐。他避免结党，让文吏与儒者互相核验，按预定科条除授。他离官后仍被当地人怀念。 [[9]](#note-9)


<a id="event-10"></a>

10. **整顿王国内史及州官。** 何武、翟方进以王国的相、内史权位失衡，请相如郡太守，改内史为中尉，依郡都尉制度分职。罢刺史置州牧、改三公后来有过反复。 [[10]](#note-10)


<a id="event-11"></a>

11. **免司空与复任。** 朝中借成帝崩后何武未及时接继母责他不孝，哀帝又欲更换大臣，免其司空。经鲍宣、董贤推荐兼受王嘉遗言影响，何武复任御史大夫，继迁前将军。 [[11]](#note-11)


<a id="event-12"></a>

12. **哀帝崩后议选大司马。** 王邑假传太后旨为王莽求官，事发贬秩削户。哀帝崩后，何武、公孙禄忧外戚辅少主，互相举荐，太后仍用王莽，两人受劾免职。 [[12]](#note-12)


<a id="event-13"></a>

13. **吕宽案牵连何武。** 传记元始三年吕宽事起，甄丰承王莽之意扩大追治，何武受牵连被征而自杀。王莽为安抚非议使其子何况嗣侯，王莽代汉后又免何况为庶人。 [[13]](#note-13)


<a id="event-14"></a>

14. **王嘉分传。** 卷内小题，自此转叙王嘉。 [[14]](#note-14)


<a id="event-15"></a>

15. **王嘉从明经入相。** 王嘉射策出身，历县职、郡守及京兆尹、御史大夫，能直言而受知。建平三年接平当为丞相，封新甫侯。 [[15]](#note-15)


<a id="event-16"></a>

16. **王嘉嗣封与追谥。** 王嘉死而国除，次用孔光、何武。元始四年朝廷封王嘉子王崇为新甫侯，并追谥王嘉为忠侯。 [[16]](#note-16)


<a id="event-17"></a>

17. **师丹分传。** 卷内小题，自此转叙师丹。 [[17]](#note-17)


<a id="event-18"></a>

18. **师丹由经师入朝。** 师丹从匡衡治《诗》，曾任博士和诸侯王太傅，后以廉正深博受荐。刘欣为太子时师丹为太子太傅，哀帝朝位列三公并受封。 [[18]](#note-18)


<a id="event-19"></a>

19. **争傅太后的名分。** 董宏借秦庄襄王两母俱称太后，主张尊傅氏为皇太后。师丹等认为哀帝继大宗后应如礼降称，弹劾董宏；如同尊皇太后则昭示两统。 [[19]](#note-19)


<a id="event-20"></a>

20. **唐林为师丹申辩。** 唐林认为师丹为经术宿望、曾辅圣躬，过失轻，免爵过重，请恢复侯邑，使其奉朝请，未获采纳。 [[20]](#note-20)


<a id="event-21"></a>

21. **平帝朝复师丹爵。** 王莽转请废傅、丁尊礼及共皇庙，处分曾建尊号者；师丹先赐关内侯，后复封义阳侯，继而去世。 [[21]](#note-21)


<a id="event-22"></a>

22. **篇末评语小题。** 转录以“評論”提示下文班固赞语。 [[22]](#note-22)


<a id="event-23"></a>

23. **班固论三臣。** 班固并举何武抗外戚、王嘉争董贤、师丹争尊号，认为前二人虽抗而不胜，师丹与董宏则随局势互有奖惩。 [[23]](#note-23)

### 11. 免司空与复任

[返回正文第11条](#event-11)

<a id="hs086-p011"></a>

**[《汉书·何武王嘉师丹传》P011](../../sources/摘录/汉书-卷086-何武王嘉师丹传.md#p011)** · [仓内TXT L9365—L9365](../../sources/本地分卷/汉书/汉书-卷086.md#L9365)

> 多所舉奏，號為煩碎，不稱賢公。功名略比薛宣，其材不及也，而經術正直過之。武后母在郡，遣吏歸迎。會成帝崩，吏恐道路有盜賊，後母留止，左右或譏武事親不篤。哀帝亦欲改易大臣，遂策免武曰：「君舉錯煩苛，不合眾心，孝聲不聞，惡名流行，無以率示四方。其上大司空印綬，罷歸就國。」後五歲，諫大夫鮑宣數稱冤之，天子感丞相王嘉之對，而高安侯董賢亦薦武，武由是復徵為御史大夫。月餘，徙為前將軍。

<a id="note-12"></a>

### 12. 哀帝崩后议选大司马

[返回正文第12条](#event-12)

<a id="hs086-p012"></a>

**[《汉书·何武王嘉师丹传》P012](../../sources/摘录/汉书-卷086-何武王嘉师丹传.md#p012)** · [仓内TXT L9366—L9366](../../sources/本地分卷/汉书/汉书-卷086.md#L9366)

> 先是，新都侯王莽就國，數年，上以太皇太后故徵莽還京師。莽從弟成都侯王邑為侍中，矯稱太皇太后指白哀帝，為莽求特進給事中。哀帝復請之，事發覺。太后為謝，上以太后故不忍誅之，左遷邑為西河屬國都尉，削千戶。後有詔舉大常，莽私從武求舉，武不敢舉。後數月，哀帝崩，太后即日引莽入，收大司馬董賢印綬，詔有司舉可大司馬者。莽故大司馬，辭位辟丁、傅，眾庶稱以為賢，又太后近親，自大司徒孔光以下舉朝皆舉莽。武為前將軍，素與左將軍公孫祿相善，二人獨謀，以為往時孝惠、孝昭少主之世，外戚呂、霍、上官持權，幾危社稷，今孝成、孝哀比世無嗣，方當選立親近輔幼主，不宜令異姓大臣持權，親疏相錯，為國計便。於是武舉公孫祿可大司馬，而祿亦舉武。太后竟自用莽為大司馬。莽風有司劾奏武、公孫祿互相稱舉，皆免。

### 19. 争傅太后的名分

[返回正文第19条](#event-19)

<a id="hs086-p039"></a>

**[《汉书·何武王嘉师丹传》P039](../../sources/摘录/汉书-卷086-何武王嘉师丹传.md#p039)** · [仓内TXT L9393—L9393](../../sources/本地分卷/汉书/汉书-卷086.md#L9393)

> 初，哀帝即位，成帝母稱太皇太后，成帝趙皇后稱皇太后，而上祖母傅太后與母丁后皆在國邸，自以定陶共王為稱。高昌侯董宏上書言：「秦莊襄王母本夏氏，而為華陽夫人所子，及即位後，俱稱太后。宜立定陶共王后為皇太后。」事下有司，時丹以左將軍與大司馬王莽共劾奏宏「知皇太后至尊之號，天下一統，而稱引亡秦以為比喻，詿誤聖朝，非所宜言，大不道。」上新立，謙讓，納用莽、丹言，免宏為庶人。傅太后大怒。要上欲必稱尊號，上於是追尊定陶共王為共皇，尊傅太后為共皇太后，丁后為共皇后。郎中令泠褒、黃門郎段猶等復奏言：「定陶共皇太后、共皇后皆不宜復引定陶蕃國之名以冠大號，車馬衣服宜皆稱皇之意，置吏二千石以下各供厥職，又宜為共皇立廟京師。」上復下其議，有司皆以為宜如褒、猶言。丹議獨曰：「聖王制禮取法於天地，故尊卑之禮明則人倫之序正，人倫之序正則乾坤得其位而陰陽順其節，人主與萬民俱蒙祐福，尊卑者，所以正天地之位，不可亂也。今定陶共皇太后、共皇后以定陶共為號者，母從子妻從夫之義也。欲立官置吏，車服與太皇太后並，非所以明尊卑亡二上之義也。定陶共皇號諡已前定，義不得復改。禮：『父為士，子為天子，祭以天子，其尸服以士服。』子亡爵父之義，尊父母也。為人後者為之子，故為所後服斬衰三年，而降其父母期，明尊本祖而重正統也。孝成皇帝聖恩深遠，故為共王立後，奉承祭祀，今共皇長為一國太祖，萬世不毀，恩義已備。陛下既繼體先帝，持重大宗，承宗廟天地社稷之祀，義不得復奉定陶共皇祭入其廟。今欲立廟於京師，而使臣下祭之，是無主也。又親盡當毀，空去一國太祖不墮之祀，而就無主當毀不正之禮，非所以尊厚共皇也。」丹由是浸不合上意。

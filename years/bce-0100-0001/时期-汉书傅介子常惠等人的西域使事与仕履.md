# 汉书傅介子常惠等人的西域使事与仕履

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **傅介子请使大宛。** 傅介子为北地人，从军入官，传中混入赞语对其籍贯的补说。元凤间以骏马监请使大宛，奉令问责曾害汉使的楼兰、龟兹。 [[1]](#note-1)


<a id="event-2"></a>

2. **傅介子与霍光议再使。** 傅介子谓楼兰、龟兹反复，不受惩戒就难以约束，原想赴龟兹行刺。霍光以龟兹太远，让他先去楼兰。 [[2]](#note-2)


<a id="event-3"></a>

3. **傅介子身后承续。** 傅介子去世，子傅敞因罪不能嗣，封国终止。元始间复封曾孙傅长以续祀，王莽败后又绝。 [[3]](#note-3)


<a id="event-4"></a>

4. **常惠传题。** 下叙随苏武使匈奴、归汉后多任外交与军事职的常惠。 [[4]](#note-4)


<a id="event-5"></a>

5. **从苏武被拘与归汉。** 常惠家贫自募，随苏武使匈奴，同被拘十余年，昭帝时返汉，因劳获拜光禄大夫。 [[5]](#note-5)


<a id="event-6"></a>

6. **乌孙告急及汉出兵。** 乌孙公主称匈奴联合车师来攻，请汉出援，昭帝死后延至宣帝。宣帝本始二年遣常惠，昆弥和公主报受侵及愿出兵，与汉军相应。 [[6]](#note-6)


<a id="event-7"></a>

7. **常惠护乌孙兵与其余出使。** 常惠持节护乌孙军，昆弥率兵攻取单于部众、畜产。常惠途中失节而惧罪，汉以奉使有功封长罗侯。其后再往乌孙论赏、至龟兹责问前使之死，传并记有人负罪受诛。 [[7]](#note-7)


<a id="event-8"></a>

8. **代苏武、再任将军及卒。** 常惠后来接苏武任典属国，熟悉异域事务。赵充国死后再任右将军而兼前职；历仕元帝后卒谥壮武，侯祀至东汉建武时止。 [[8]](#note-8)


<a id="event-9"></a>

9. **郑吉传题。** 以下为郑吉领屯田、纳日逐王及初任西域都护。 [[9]](#note-9)


<a id="event-10"></a>

10. **渠黎屯田与攻车师。** 郑吉从士卒升郎，熟悉西域。宣帝时在渠黎屯田储粮，借当地诸国兵攻车师，升卫司马，负责鄯善以西南道。 [[10]](#note-10)


<a id="event-11"></a>

11. **安远侯与乌垒幕府。** 宣帝诏称护西域、纳日逐、破车师有功，封郑吉安远侯。郑吉在西域中央的乌垒设幕府，以平服兼怀柔治理诸国，传以张骞开端、郑吉成事概括。 [[11]](#note-11)


<a id="event-12"></a>

12. **郑吉侯爵后嗣。** 郑吉卒谥缪侯，子郑光继爵而无子国除，元始间复封曾孙郑永为安远侯。 [[12]](#note-12)


<a id="event-13"></a>

13. **甘延寿传题。** 下叙甘延寿由羽林而都护，和陈汤同破郅支。 [[13]](#note-13)


<a id="event-14"></a>

14. **由骑射进身与封义成侯。** 甘延寿出郁郅良家，以骑射、力量与敏捷见知，历羽林、郎、期门、辽东守。许嘉荐而任谏官、都护，和陈汤破郅支，封义成侯，死后谥壮。 [[14]](#note-14)


<a id="event-15"></a>

15. **陈汤传题。** 以下从陈汤早年记到破郅支、获罪和追封。 [[15]](#note-15)


<a id="event-16"></a>

16. **陈汤早年、被荐及获罪。** 陈汤家贫而好学善文，早年借贷过度而不为乡里所重。在长安任小官，张勃举茂材。陈汤父死不奔丧受究，张勃也以举非其人削邑，陈汤下狱后又获荐，终于出使西域。 [[16]](#note-16)


<a id="event-17"></a>

17. **郅支西走与汉使被杀。** 五单于争立时汉廷同时接纳呼韩邪、郅支送来的侍子。呼韩邪入朝后，郅支向西服三部，责汉偏助对手。元帝时汉遣谷吉护送郅支侍子，谷吉被杀，郅支又投康居并控制周边。 [[17]](#note-17)


<a id="event-18"></a>

18. **朝廷问罪与士卒获释。** 中书令等因私人关系及擅兴之事不肯维护；陈汤所得财物也有不法。司隶拘吏士，陈汤称远征归来本当慰劳，元帝下令放人并备酒食。 [[18]](#note-18)


<a id="event-19"></a>

19. **元帝诏封与承认越法。** 诏书仍指出擅发兵、矫制越法，但认为招诸国用兵、没有动员内地人马即可除怨，遂封甘延寿、赐陈汤关内侯，给食邑、金帛及职任。 [[19]](#note-19)


<a id="event-20"></a>

20. **甘延寿卒与陈汤成帝初去职。** 甘延寿任城门校尉、护军都尉，卒于官。成帝初匡衡以陈汤在西域擅权并侵盗所取财物奏劾，陈汤免官。 [[20]](#note-20)


<a id="event-21"></a>

21. **康居侍子案与谷永救解。** 陈汤上书怀疑康居侍汉人不是王子，查明属实，陈汤反以妄告当死。谷永上书列贤将护边之于国的重要，为陈汤辩护，朝廷免其死罪，夺爵为士伍。 [[21]](#note-21)


<a id="event-22"></a>

22. **初陵改营与迁民争议。** 成帝改营初陵，解万年与陈汤商议设陵邑、迁徙郡国民户。一方面以修陵给功奖为想望，一方面陈汤妻族可趁迁入长安；传列旧陵曾停迁民供对照。 [[22]](#note-22)


<a id="event-23"></a>

23. **王商劾陈汤，追查请封受钱。** 王商辅政时奏陈汤借议陵邑惑众，并查他为王莽谋封、收苟氏钱财求爵等旧事，陈汤获罪远徙。 [[23]](#note-23)


<a id="event-24"></a>

24. **自敦煌改徙安定。** 敦煌太守以陈汤破郅支而威名在外、安置不宜近塞为由奏请，朝廷改徙安定。 [[24]](#note-24)


<a id="event-25"></a>

25. **耿育讼功与陈汤晚年。** 耿育称元帝已肯定破郅支的功劳，又责匡衡等阻赏和后来迁徙处置，主张维护功臣。陈汤终于得返长安，年老而死。 [[25]](#note-25)


<a id="event-26"></a>

26. **王莽追奖甘陈与杜勋。** 王莽执政后念陈汤旧助，也借褒元帝讨郅支以奉承太后，增甘延寿孙封邑、追谥陈汤、封其子陈冯，并封杜勋。 [[26]](#note-26)


<a id="event-27"></a>

27. **段会宗传题。** 以下叙段会宗两入都护、数次赴乌孙。 [[27]](#note-27)


<a id="event-28"></a>

28. **段会宗两任都护。** 段会宗从杜陵令经五府荐为都护，任满还为太守，后坐法免。西域诸国请求其返任，阳朔间再任都护。 [[28]](#note-28)


<a id="event-29"></a>

29. **谷永赠书。** 朋友谷永称其怀柔远人的功德，又担心他年老远赴，不宜过求新功；用已有傅、郑、甘、陈的事迹劝其守成，全身归来。 [[29]](#note-29)


<a id="event-30"></a>

30. **小昆弥来谒与康居请降未成。** 诸国迎段会宗，小昆弥安日感念他曾立自己，不听部下劝阻而来谒。康居太子欲降，朝廷使者要求自缚，降者怨而离去；段会宗以擅发戊己校尉兵获罪而赎。 [[30]](#note-30)


<a id="event-31"></a>

31. **小昆弥被杀后再定乌孙。** 小昆弥遭杀，各部扰乱，段会宗奉命赴乌孙安辑，立其亲属末振将，局势初定而归。 [[31]](#note-31)


<a id="event-32"></a>

32. **论赞西域都护功迹。** 班固从张骞通西域、郑吉始任都护说到王莽时共十八人，列廉襃、郭舜、孙建特色，又叹陈汤不自约束而终于困穷。 [[32]](#note-32)

### 7. 常惠护乌孙兵与其余出使

### 17. 郅支西走与汉使被杀

[返回正文第17条](#event-17)

<a id="hs070-p021"></a>

**[《汉书·傅常郑甘陈段传》P021](../../sources/摘录/汉书-卷070-傅常郑甘陈段传.md#p021)** · [仓内TXT L8679—L8679](../../sources/本地分卷/汉书/汉书-卷070.md#L8679)

> 先是，宣帝時匈奴乖亂，五單于爭立，呼韓邪單于與郅支單于俱遣子入侍，漢兩受之。後呼韓邪單于身入稱臣朝見，郅支以爲呼韓邪破弱降漢，不能自還，即西収右地。會漢發兵送呼韓邪單于，郅支由是遂西破呼偈、堅昆、丁令，兼三國而都之。怨漢擁護呼韓邪而不助己，困辱漢使者江迺始等。初元四年，遣使奉獻，因求侍子，願爲內附。漢議遣衞司馬谷吉送之。御史大夫貢禹、博士匡衡以爲春秋之義「許夷狄者不壹而足」，今郅支單于鄉化未醇，所在絕遠，宜令使者送其子至塞而還。吉上書言：「中國與夷狄有羈縻不絕之義，今旣養全其子十年，德澤甚厚，空絕而不送，近從塞還，示弃捐不畜，使無鄉從之心。弃前恩，立後怨，不便。議者見前江迺始無應敵之數，知勇俱困，以致恥辱，即豫爲臣憂。臣幸得建彊漢之節，承明聖之詔，宣諭厚恩，不宜敢桀。若懷禽獸，加無道於臣，則單于長嬰大罪，必遁逃遠舍，不敢近邊。沒一使以安百姓，國之計，臣之願也。願送至庭。」上以示朝者，禹復爭，以爲吉往必爲國取悔生事，不可許。右將軍馮奉世以爲可遣，上許焉。旣至，郅支單于怒，竟殺吉等。自知負漢，又聞呼韓邪益彊，遂西奔康居。康居王以女妻郅支，郅支亦以女予康居王。康居甚尊敬郅支，欲倚其威以脅諸國。郅支數借兵擊烏孫，深入至赤谷城，殺略民人，敺畜產，烏孫不敢追，西邊空虛，不居者且千里。郅支單于自以大國，威名尊重，又乘勝驕，不爲康居王禮，怒殺康居王女及貴人、人民數百，或支解投都賴水中。發民作城，日作五百人，二歲迺已。又遣使責闔蘇、大宛諸國歲遺，不敢不予。漢遣使三輩至康居求谷吉等死，郅支困辱使者，不肯奉詔，而因都護上書言：「居困戹，願歸計彊漢，遣子入侍。」其驕嫚如此。

### 22. 初陵改营与迁民争议

### 25. 耿育讼功与陈汤晚年

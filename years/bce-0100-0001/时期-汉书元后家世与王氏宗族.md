# 汉书元后家世与王氏宗族

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **王莽自称的远祖。** 本传先录《自本》，把王氏从黄帝、虞舜、陈胡公、陈完叙到齐田氏，再到汉初王氏。这是王莽用以自立的谱系。 [[1]](#note-1)


<a id="event-2"></a>

2. **王贺任绣衣御史。** 王贺捕堅盧等党，对逗留的吏员和连坐者多宽免，因“不称”解职；同役别部诛人甚多，参读《酷吏传》。 [[2]](#note-2)


<a id="event-3"></a>

3. **王贺迁元城与沙麓说。** 王贺迁魏郡元城，为乡里三老。建公将《春秋》所载沙麓崩与王氏迁居相配，预言贵女兴起，属于本传附记的占验。 [[3]](#note-3)


<a id="event-4"></a>

4. **王政君出生和家族。** 王禁习法律为廷尉史，本始三年生政君。此段列四女八男及其字，王凤、王崇与政君同母，母李亲后改嫁。 [[4]](#note-4)


<a id="event-5"></a>

5. **政君入掖庭。** 母梦月及数次婚聘未成引出卜者“大贵”说。王禁教政君读书、弹琴，五凤中献入掖庭为家人子。 [[5]](#note-5)


<a id="event-6"></a>

6. **太子宫得子。** 司马良娣病死，太子因其遗言疏诸妾。宣帝令皇后荐掖庭女，政君获幸，甘露三年生刘骜，宣帝亲取名并爱育。 [[6]](#note-6)


<a id="event-7"></a>

7. **王政君立后、王氏护太子。** 元帝即位后尊王妃，封王禁；王禁卒，王凤嗣。元帝后来宠定陶王，王后、王凤忧太子被废，史丹帮助保全储位。 [[7]](#note-7)


<a id="event-8"></a>

8. **王崇之死与五侯同封。** 王崇卒后遗腹子奉世承侯。河平二年王谭、商、立、根、逢时同日封侯；太后异父弟苟参任侍中水衡都尉，未封侯。 [[8]](#note-8)


<a id="event-9"></a>

9. **王凤阻刘歆入近侍。** 成帝爱刘歆才艺，欲拜为中常侍，左右先请知王凤。王凤反对，任命停止，传藉以说明其权。 [[9]](#note-9)


<a id="event-10"></a>

10. **王凤势重和五侯生活。** 官僚多出王凤门下，王音升御史大夫。五侯以宅第、声乐、女乐及僮奴竞奢，传借诸家生活写外戚权势深入朝野。 [[10]](#note-10)


<a id="event-11"></a>

11. **王商、王根宅第僭侈。** 王商借宫避暑，穿城引水；成帝又见王根宅第僭用宫中规制。王音先以免冠请罪应对，王氏两家受到责谴。 [[11]](#note-11)


<a id="event-12"></a>

12. **王谭侯位承续与王曼追封。** 王谭卒，子王仁承侯。太后念早死的弟王曼及幼孤王莽，王氏诸人荐莽，成帝后来追封王曼。 [[12]](#note-12)


<a id="event-13"></a>

13. **王音、王商、王根相继辅政。** 成帝使王商领城门兵、置府，在王音死后以王商接替；王商死后王立当次，因过受黜，改用王根。 [[13]](#note-13)


<a id="event-14"></a>

14. **立定陶王刘欣为储。** 绥和元年傅太后以厚赂请王根为刘欣求汉嗣，王根进言，成帝亦有此意，征立定陶王。王根其后请退。 [[14]](#note-14)


<a id="event-15"></a>

15. **杨宣为王氏进言。** 杨宣以先帝择嗣、太皇太后年老念亲、王莽前后谦退为由，请保全和召还王氏，奏辞旨在劝哀帝慎全亲恩。 [[15]](#note-15)


<a id="event-16"></a>

16. **王莽与王仁还京。** 元寿元年日食，对策者多为王莽言，朝廷令王莽、王仁还京侍太皇太后。王根本年卒。 [[16]](#note-16)


<a id="event-17"></a>

17. **哀帝死，太后委政王莽。** 太后令王莽再任大司马，征立年幼的刘箕子，临朝而委政。王莽内忌王立、王仁，后借案迫其自杀。 [[17]](#note-17)


<a id="event-18"></a>

18. **尊太后姊妹、邀其欢心。** 王莽赐宫人、尊太后姊妹为广恩等君并给邑，以安排外出礼遇等取悦太后。 [[18]](#note-18)


<a id="event-19"></a>

19. **立孺子与王莽摄政。** 平帝无子，王莽择年幼的刘婴，以占卜为由让群臣请立为孺子，并请自己如周公居摄。太后反对，终无力禁止。 [[19]](#note-19)


<a id="event-20"></a>

20. **传国玺归新。** 本传先追叙秦降、高祖传玺的来历，再写王莽遣王舜向太后索玺。太后怒骂泣下，最后把玺掷于地。 [[20]](#note-20)


<a id="event-21"></a>

21. **王政君卒、合葬渭陵。** 始建国五年王政君崩，年八十四，三月与元帝合葬。扬雄奉令作诔，用沙麓和梦月写祥验。 [[21]](#note-21)


<a id="event-22"></a>

22. **王立族系在东汉初的后事。** 红阳侯王立与刘氏结纳，少子王丹曾任中山太守，投降光武为将而战死；其子王泓得封。 [[22]](#note-22)


<a id="event-23"></a>

23. **班彪的外戚论。** 班彪以汉代旧外戚危国为鉴，把王莽兴起与元后历朝的地位联系，属于史家的政伦理评断。 [[23]](#note-23)

[返回正文第6条](#event-6)

<a id="hs098-p006"></a>

**[《汉书·元后传》P006](../../拆分史书/汉书/卷098.md#p006)** · [仓内TXT L10280—L10280](../../拆分史书/汉书/卷098.md#part-1-L10280)

> 歲餘，會皇太子所愛幸司馬良娣病，且死，謂太子曰：「妾死非天命，乃諸娣妾良人更祝詛殺我。」太子憐之，且以為然。及司馬良娣死，太子悲恚發病，忽忽不樂，因以過怒諸娣妾，莫得進見者。久之，宣帝聞太子恨過諸娣妾，欲順適其意，乃令皇后擇後宮家人子可以虞侍太子者，政君與在其中。及太子朝，皇后乃見政君等五人，微令旁長御問知太子所欲。太子殊無意於五人者，不得已於皇后，強應曰：「此中一人可。」是時政君坐近太子，又獨衣絳緣諸于，長御即以為是。皇后使侍中杜輔、掖庭令濁賢交送政君太子宮，見丙殿。得御幸，有身。先是者，太子後宮娣妾以十數，御幸久者七八年，莫有子，及王妃一幸而有身。甘露三年，生成帝於甲館畫堂，為世適皇孫。宣帝愛之，自名曰驁，字太孫，常置左右。

### 11. 王商、王根宅第僭侈

[返回正文第11条](#event-11)

<a id="hs098-p021"></a>

**[《汉书·元后传》P021](../../拆分史书/汉书/卷098.md#p021)** · [仓内TXT L10295—L10295](../../拆分史书/汉书/卷098.md#part-1-L10295)

> 初，成都侯商嘗病，欲避暑，從上借明光宮，後又穿長安城，引內澧水注第中大陂以行船，立羽蓋，張周帷，輯濯越歌。上幸商第，見穿城引水，意恨，內銜之，未言。後微行出，過曲陽侯第，又見園中土山漸臺似類白虎殿。於是上怒，以讓車騎將軍音。商、根兄弟欲自黥、劓謝太后。上聞之大怒，乃使尚書責問司隸校尉、京兆尹：「知成都侯商擅穿帝城，決引澧水，曲陽侯根驕奢僭上，赤墀青瑣，紅陽侯立父子臧匿奸猾亡命，賓客為群盜，司隸、京兆皆阿縱不舉奏正法。」二人頓首省戶下。又賜車騎將軍音策書曰：「外家何甘樂禍敗，而欲自黥、劓，相戮辱於太后前，傷慈母之心，以危亂國！外家宗族強，上一身寢弱日久，今將一施之。君其召諸侯，令待府捨。」是日，詔尚書奏文帝時誅將軍薄昭故事。車騎將軍音藉槁請罪，商、立、根皆負斧質謝。上不忍誅，然後得已。

### 20. 传国玺归新

[返回正文第20条](#event-20)

<a id="hs098-p035"></a>

**[《汉书·元后传》P035](../../拆分史书/汉书/卷098.md#p035)** · [仓内TXT L10309—L10309](../../拆分史书/汉书/卷098.md#part-1-L10309)

> 初，漢高祖入咸陽至霸上，秦王子嬰降於軹道，奉上始皇璽。及高祖誅項籍，即天子位，因御服其璽，世世傳受，號曰漢傳國璽，以孺子未立，璽臧長樂宮。及莽即位，請璽，太后不肯授莽。莽使安陽侯舜諭指。舜素謹敕，太后雅愛信之。舜既見，太后知其為莽求璽，怒罵之曰：「而屬父子宗族蒙漢家力，富貴累世，既無以報，受人孤寄，乘便利時，奪取其國，不復顧恩義。人如此者，狗豬不食其餘，天下豈有而兄弟邪！且若自以金匱符命為新皇帝，變更正朔服制，亦當自更作璽，傳之萬世，何用此亡國不詳璽為，而欲求之？！我漢家老寡婦，旦暮且死，欲與此璽俱葬，終不可得！」太后因涕泣而言，旁側長御以下皆垂涕。舜亦悲不能自止，良久乃仰謂太后：「臣等已無可言者。莽必欲得傳國璽，太后寧能終不與邪！」太后聞舜語切，恐莽欲脅之，乃出漢傳國璽，投之地以授舜，曰：「我老已死，如而兄弟，今族滅也！」舜既得傳國璽，奏之，莽大說，乃為太后置酒未央宮漸臺，大縱眾樂。

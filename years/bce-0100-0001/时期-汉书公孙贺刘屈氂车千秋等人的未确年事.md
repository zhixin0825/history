# 汉书公孙贺刘屈氂车千秋等人的未确年事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **公孙贺家世。** 公孙贺字子叔，北地义渠人。祖父公孙昆邪在景帝时守陇西，从军平吴楚，封平曲侯，留有十多篇著作。 [[1]](#note-1)


<a id="event-2"></a>

2. **公孙贺军功、婚姻与拜相。** 公孙贺由骑士、太子舍人起家，累迁太仆，娶卫皇后姐姐卫君孺。先后出战马邑、云中、定襄、五原，因从卫青立功封南窌侯，又因酎金失侯。接石庆为相时惧祸推辞，仍被授印；此前几名丞相接连获罪。 [[2]](#note-2)


<a id="event-3"></a>

3. **公孙敬声传题。** 以下写贺之子由太仆犯法而牵累父族。 [[3]](#note-3)


<a id="event-4"></a>

4. **巫蛊案的牵连。** 叙事从朱安世的狱中告发转到江充治案，皇后、公主和太子相继遭祸；相关经过分见江充、戾太子本传。 [[4]](#note-4)


<a id="event-5"></a>

5. **刘屈氂传题。** 以下写刘屈氂由涿郡太守拜左丞相，参与巫蛊案，随后遭诛。 [[5]](#note-5)


<a id="event-6"></a>

6. **中山王子。** 刘屈氂是武帝兄中山靖王之子，传未记他最初如何进用。 [[6]](#note-6)


<a id="event-7"></a>

7. **太子起兵，左相走报甘泉。** 戾太子杀江充后发兵入相府，刘屈氂逃脱，失去印绶。长史驿报避暑甘泉的武帝，并称丞相秘而未发兵。 [[7]](#note-7)


<a id="event-8"></a>

8. **长安兵争与治罪。** 武帝回建章宫调三辅兵，使左相兼将。太子亦调囚徒和武库兵，任安受节而闭北军不发；莽通杀如侯，双方以节色区别。长安交战五日后太子出逃。田仁、任安被杀，暴胜之自尽，莽通等得封，随从受诛或徙敦煌，二十余日后太子在湖县被发现。 [[8]](#note-8)


<a id="event-9"></a>

9. **车千秋传题。** 车千秋本姓田，传以下文受优礼乘车解释称号。 [[9]](#note-9)


<a id="event-10"></a>

10. **田千秋讼卫太子冤而拜相。** 田千秋以高寝郎上急变，借父子关系统释太子用兵。武帝听后醒悟，提拔为大鸿胪，数月后拜相封富民侯。传又记单于讥汉以一言取相与武帝处理使者回报。 [[10]](#note-10)


<a id="event-11"></a>

11. **初为相与群臣上寿。** 千秋见巫蛊治狱多年、刑罚多，联同高官上寿，劝武帝施惠缓刑，借音乐调养心志、安定百姓。 [[11]](#note-11)


<a id="event-12"></a>

12. **武帝答千秋等。** 武帝说自己痛惜受祸的士大夫，也责廷尉和九卿未能查出案情，又述江充所查及自己相信尚有巫蛊的忧虑，因此拒绝举觞庆寿，命不要再言。 [[12]](#note-12)


<a id="event-13"></a>

13. **托孤、昭帝辅政与盐铁议。** 武帝立幼子，命霍光、金日磾、桑弘羊及车千秋共受遗诏。昭帝初由霍光决政，千秋谨厚少言，得光礼重。始元六年征贤良文学询民疾苦，由此引出盐铁议。 [[13]](#note-13)


<a id="event-14"></a>

14. **车丞相之称与继侯。** 千秋任相十二年卒，谥定。年高时特准乘小车入宫，因号车丞相。子田顺继侯，后来率军击匈奴，因虚增俘获自杀，国除。 [[14]](#note-14)


<a id="event-15"></a>

15. **桑弘羊与上官氏案。** 桑弘羊以盐铁专营的财计功劳自负，希望恩及子弟，又怨霍光，最终参与上官桀等人的谋反，族被诛灭。 [[15]](#note-15)


<a id="event-16"></a>

16. **王訢传题。** 以下为由地方官升为丞相的王訢。 [[16]](#note-16)


<a id="event-17"></a>

17. **以宽济威劝暴胜之。** 王訢由郡县吏积功至被阳令。暴胜之奉命捕盗、将斩訢，訢临刑说宽宥可施恩、使人尽力，杀他无助于增威，暴胜之赏识而免其死。 [[17]](#note-17)


<a id="event-18"></a>

18. **王訢任右扶风、御史大夫与丞相。** 暴胜之荐王訢，其后负责右扶风。整治武帝出行的宫馆、驰道并备供张，获拜实职。昭帝时任御史大夫，继千秋为相，封宜春侯，翌年卒谥敬。 [[18]](#note-18)


<a id="event-19"></a>

19. **王谭传题。** 以下叙王訢的侯爵由子孙传承。 [[19]](#note-19)


<a id="event-20"></a>

20. **王谭因定策增邑。** 王谭继侯，参与废昌邑王、迎立宣帝，增邑三百户。其后有王咸，王莽娶其女，宜春侯一系延至王莽败。 [[20]](#note-20)


<a id="event-21"></a>

21. **杨敞传题。** 以下是从霍光幕府出身、参与昭宣交替的杨敞。 [[21]](#note-21)


<a id="event-22"></a>

22. **杨敞由幕府至丞相。** 霍光厚待杨敞，迁大司农。稻田使者燕苍先向他报告上官氏谋反，他不敢直接上奏，托杜延年转报，故未随二人受封；后历御史大夫、丞相，封安平侯。 [[22]](#note-22)


<a id="event-23"></a>

23. **废昌邑王时杨敞与其妻。** 昭帝无嗣，昌邑王继位后，霍光和张安世定废立之计。田延年通知杨敞时他惊惧无言，妻子劝他立即表态以免先受诛，夫妻终于一同应承。宣帝立后杨敞增封，旋卒。 [[23]](#note-23)


<a id="event-24"></a>

24. **杨恽传题。** 以下由杨敞继嗣转写次子杨恽。 [[24]](#note-24)


<a id="event-25"></a>

25. **杨恽读太史公书与举霍氏谋反。** 杨恽之母为司马迁之女，他自少读外祖著作、治《春秋》，结交儒士。获悉霍家谋反，由金安上报帝，事后同他人受封，杨恽封平通侯。 [[25]](#note-25)


<a id="event-26"></a>

26. **改革郎署山郎旧例。** 郎官原由自出钱筹官用，或用贿赂谋好职、休假。杨恽把费用改由大司农供应，病假休沐依法，考察推举有才能者并奏免有过者，郎署风气一变。 [[26]](#note-26)


<a id="event-27"></a>

27. **散财宗族。** 杨恽将父亲遗财、封侯所得以及后母留给自己的钱财分给各方亲族，传以此写其轻财好义。 [[27]](#note-27)


<a id="event-28"></a>

28. **持法与树怨。** 杨恽在郎署清廉公平，但自夸行治，喜欢揭发隐私并报复与己不和者，终于与太仆戴长乐交恶。 [[28]](#note-28)


<a id="event-29"></a>

29. **戴长乐的由来。** 戴长乐在宣帝居民间时与其相识，故新帝擢用；一次奉使回来，向属吏说自己如何领受诏命，接下段告发。 [[29]](#note-29)


<a id="event-30"></a>

30. **失爵后的孙会宗来信。** 杨恽家居经营产业。朋友孙会宗来信劝废退大臣应闭门自警，勿继续经营和通宾客。杨恽自觉得罪不明，致书答辩。 [[30]](#note-30)


<a id="event-31"></a>

31. **答书自陈本末。** 杨恽自谦品行才质，却称孙会宗未察首尾、随俗议论；引孔子各言己志之意，决意说出真实想法。 [[31]](#note-31)


<a id="event-32"></a>

32. **自认任官素餐，感庆活命。** 回顾宗族十人乘朱轮时自己无所建明，也未能及时退位。身陷禁狱、妻子俱被收时曾以为族灭，幸而仍可奉先墓。 [[32]](#note-32)


<a id="event-33"></a>

33. **以田家酒歌答友。** 杨恽以人情不可强止说明获罪数年仍可伏腊宴饮，写秦声、赵瑟与歌舞，并以南山种豆的歌辞反问富贵何益，申明退居后自营。 [[33]](#note-33)


<a id="event-34"></a>

34. **以风俗历数会宗。** 从魏文侯旧土段干木、田子方的节操转到安定山谷习俗，带讽刺地问他是否改性，以毋多谈作结。 [[34]](#note-34)


<a id="event-35"></a>

35. **蔡义传题。** 以下为以讲《韩诗》进用、后任丞相的蔡义。 [[35]](#note-35)


<a id="event-36"></a>

36. **蔡义困贫入仕。** 蔡义为河内温人，以通经入大将军幕府，贫而常步行，同人凑钱给他买牛车，后来迁城门候。 [[36]](#note-36)


<a id="event-37"></a>

37. **进讲《韩诗》与拜相。** 待诏久未得见后，蔡义上书请求陈说经义。讲诗受赏，任光禄大夫教授昭帝，后历少府、御史大夫，继杨敞为相，封阳平侯，并因定策获增封金。 [[37]](#note-37)


<a id="event-38"></a>

38. **陈万年传题。** 以下叙陈万年及子陈咸的仕历。 [[38]](#note-38)


<a id="event-39"></a>

39. **陈万年由地方入中央。** 陈万年字幼公，沛郡相县人，由郡吏经察举为县令、广陵太守；政绩上等，迁右扶风、太仆。 [[39]](#note-39)


<a id="event-40"></a>

40. **周旋外戚，获丙吉举荐。** 陈万年行政廉平，生活有节，却倾家交结许、史，尤迎合史高。问疾丙吉时独留至夜，后来丙吉临终荐于定国、杜延年和他；他终任御史大夫，八年病卒。 [[40]](#note-40)


<a id="event-41"></a>

41. **陈咸传题。** 以下记陈咸敢言而又倚援进身的经历。 [[41]](#note-41)


<a id="event-42"></a>

42. **父子夜语。** 陈咸由父任入仕，先以屡言近臣被擢。父亲病中训戒至半夜，他打盹撞屏，直言已明白不过是教自己阿谀，父亲遂止。 [[42]](#note-42)


<a id="event-43"></a>

43. **因朱云自讼案失官。** 元帝重用陈咸考察刺史、总州郡奏事。陈咸批评石显，又指导被劾的朱云上书自辩，遭侦知，以泄禁中语下狱，减死为城旦。 [[43]](#note-43)


<a id="event-44"></a>

44. **成帝起用后治郡严酷。** 王凤认为陈咸有敢指石显的节操，荐他出仕。他历任史职、郡守，受王章举荐而随王章被诛遭免；复守南阳后以刑伐立威，苛责豪吏大姓。 [[44]](#note-44)


<a id="event-45"></a>

45. **托陈汤复进与数次罢免。** 陈咸贿陈汤求进，任少府时纠治属官侵财，宫吏畏惧。翟方进指他旧任残酷、监守自盗及攀附陈汤，奏免其官。王立荐他复任，后又被免，归乡忧死。 [[45]](#note-45)


<a id="event-46"></a>

46. **郑弘传题。** 以下是郑弘，兼叙其兄郑昌。 [[46]](#note-46)


<a id="event-47"></a>

47. **郑氏兄弟与郑弘免官。** 兄弟通经兼知法律。郑昌为政用刑较深，郑弘治南阳、淮阳等地以平著称，进右扶风、御史大夫，后因与京房论议获罪免任。 [[47]](#note-47)


<a id="event-48"></a>

48. **论赞标记。** 以下以盐铁议收束本卷数位公卿的行迹。 [[48]](#note-48)


<a id="event-49"></a>

49. **赞引盐铁议及宽次公评价。** 班固交代始元时贤良文学要求罢盐铁酒榷均输，桑弘羊以国用和守边相争。再引宽次公所作的重订论议，区分各家长短，称许敢言者，批评桑弘羊专财利及车千秋、两府僚属缄默逢迎。 [[49]](#note-49)

# 汉书冯奉世与冯氏子弟任官

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **冯亭死长平与家世。** 冯奉世为上党潞人，徙杜陵。先祖冯亭原守韩上党，在秦绝太行道后持地入赵，受封华阳君，随赵括拒秦而死于长平。宗族离散，有一支仕赵及代，冯毋擇、去疾、劫又仕秦为将相。 [[1]](#note-1)


<a id="event-2"></a>

2. **习经兵而从军。** 冯唐是代相之子，文帝时显名。冯奉世由良家子选郎，昭帝时补武安长，失职后始学《春秋》大义及兵法，韩增荐为军司空令；本始中从军击匈奴，军罢复为郎。 [[2]](#note-2)


<a id="event-3"></a>

3. **使西域征莎车及朝议封赏。** 韩增荐奉世以卫候持节送大宛等国客，奉世至伊脩城得知莎车杀汉所立王万年及使者奚充国，并挟诸国绝南道。奉世与副使严昌发诸国合兵攻城，莎车王自杀，首传长安。事平后奉世至大宛得象龙名马。公卿称其便宜有功，蕭望之谓赏矫制将引发以后擅兵邀功，宣帝只任光禄大夫、水衡都尉。 [[3]](#note-3)


<a id="event-4"></a>

4. **上郡降胡反与接替常惠。** 元帝即位，奉世任执金吾；上郡属国归降胡人万余逃离。传追记昭帝末伊酋若王反而奉世持节率兵追击。右将军常惠卒后，奉世接任右将军并典属国，加诸吏，后来兼光禄勋。 [[4]](#note-4)


<a id="event-5"></a>

5. **奉世病卒与宿将评价。** 回军一年多后奉世病死。全文后又说他死后二年甘延寿封侯，两个间隔无法与封侯确年同时吻合。他任武臣前后十年，传称是能御敌的宿将，功名次于赵充国。 [[5]](#note-5)


<a id="event-6"></a>

6. **任宫、任千秋父子的仕爵。** 任宫因捕斩上官桀获侯，宣帝时为太常而卒。任千秋承爵亦任太常；成帝朝王商从左将军入相，千秋曾历右、左将军，侯爵传至王莽才断绝。传文“王商代奉世为左将军”只交代该职先后，须与职官表补齐他人任免。 [[6]](#note-6)


<a id="event-7"></a>

7. **奉世子女与冯谭从军。** 奉世九子四女，长女媛后为元帝昭仪，生中山孝王，元帝死后为中山太后，随王就国。冯谭因孝廉任郎，后为天水司马；随父征羌将有功受拜，未及而病死，弟野王等显官。 [[7]](#note-7)


<a id="event-8"></a>

8. **冯野王进迁与池阳案。** 冯野王学《诗》，以父任出仕，十八岁请试治长安令，宣帝问魏相后不许。后历令、陇西守、左冯翊。督邮赵都查池阳令并之赃，捕时将其格杀，为明野王无私复自杀，京师因而称其威信，迁大鸿胪。 [[8]](#note-8)


<a id="event-9"></a>

9. **三公之选因外戚避嫌。** 御史大夫李延寿卒，尚书评中二千石，冯野王居首。元帝恐后世谓偏私昭仪兄长，诏列野王、五鹿充宗、张谭各有长处，越次用张谭。野王叹人因女子宠而贵，冯氏兄弟反为之受损。 [[9]](#note-9)


<a id="event-10"></a>

10. **冯野王出守与因赐告归家罢职。** 成帝即位后野王以中山王舅不宜居九卿而出守，萧育奏荐未果，后经治河堤任琅邪太守。王章荐以野王代王凤而获罪。野王称病得赐告，就医回杜陵，王凤促有司以持符越界不敬劾免。杜钦以令文、旧例及从疑去刑为辩而未被采用，病赐告不得归遂成例。 [[10]](#note-10)


<a id="event-11"></a>

11. **野王承爵与家族获罪。** 野王承父关内侯爵，免归后老死；子座承爵，至孙因中山太后案失爵。 [[11]](#note-11)


<a id="event-12"></a>

12. **冯逡经学及河堤之议。** 冯逡明《易》，经察举任郎、谒者，建昭中为复土校尉，后历县令、宿卫、都尉、太守，以廉平见称，四十余岁死。治河方略另见《沟洫志》。 [[12]](#note-12)


<a id="event-13"></a>

13. **冯立出守与百姓歌颂。** 竟宁中以中山王舅出为五原属国都尉，后来历五原、西河、上郡等郡。吏民以歌称颂大小冯君的公廉教化。冯立后因东海低湿致病徙太原，老卒官。 [[13]](#note-13)


<a id="event-14"></a>

14. **冯参守礼与封宜乡侯。** 冯参通《尚书》，宿卫矜严，因外戚出任渭陵，复历上河、代郡、安定等。因刘欣被立太子、未选中山王，成帝以宜乡侯封其舅冯参慰王。中山王病中求减其爵以留长安，帝允近朝而保列侯。翟方进劝他待五侯宜略为自屈，参仍守礼不变。 [[14]](#note-14)


<a id="event-15"></a>

15. **赞冯参威仪与悲受谗。** 班固用《诗》颂冯参威仪端方，叹其非罪而死，以伯奇被放、申生自尽、屈原投江等受谗旧事类比，哀冯氏姊弟。 [[15]](#note-15)

### 3. 使西域征莎车及朝议封赏

[返回正文第3条](#event-3)

<a id="hs079-p003"></a>

**[《汉书·冯奉世传》P003](../../sources/摘录/汉书-卷079-冯奉世传.md#p003)** · [仓内TXT L9085—L9085](../../sources/本地分卷/汉书/汉书-卷079.md#L9085)

> 先是時，漢數出使西域，多辱命不稱，或貪污，為外國所苦。是時，烏孫大有擊匈奴之功，而西域諸國新輯，漢方善遇，欲以安之，選可使外國者。前將軍增舉奉世以衛候使持節送大宛諸國客。至伊脩城，都尉宋將言莎車與旁國共攻殺漢所置莎車王萬年，並殺漢使者奚充國。時，匈奴又發兵攻車師城，不能下而去。莎車遣使揚言北道諸國已屬匈奴矣，於是攻劫南道，與歃盟畔漢，從鄯善以西皆絕不通。都護鄭吉、校尉司馬意皆在北道諸國間。奉世與其副嚴昌計，以為不亟擊之則莎車日強，其勢難制，必危西域。遂以節諭告諸國王，因發其兵，南北道合萬五千人進擊莎車，攻拔其城。莎車王自殺，傳其首詣長安。諸國悉平，威振西域。奉世乃罷兵以聞。宣帝召見韓增，曰：「賀將軍所舉得其人。」奉世遂西至大苑。大苑聞其斬莎車王，敬之異於它使。得其名馬象龍而還。上甚說，下議封奉世。丞相、將軍皆曰：「《春秋》之義，大夫出疆，有可以安國家，則顓之可也。奉世功傚尤著，宜加爵士之賞。」少府蕭望之獨以奉世奉使有指，而擅矯制違命，發諸國兵，雖有功效，不可以為後法。即封奉世，開後奉使者利，以奉世為比，爭逐發兵，要功萬里之外，為國家生事於夷狄。漸不可長，奉世不宜受封。上善望之議，以奉世為光祿大夫、水衡都尉。

### 9. 三公之选因外戚避嫌

[返回正文第9条](#event-9)

<a id="hs079-p015"></a>

**[《汉书·冯奉世传》P015](../../sources/摘录/汉书-卷079-冯奉世传.md#p015)** · [仓内TXT L9097—L9097](../../sources/本地分卷/汉书/汉书-卷079.md#L9097)

> 數年，御史大夫李延壽病卒，在位多舉野王。上使尚書選第中二千石，而野王行能第一。上曰：「吾用野王為三公，後世必謂我私後宮親屬，以野王為比。」乃下詔曰：「剛強堅固，確然亡欲，大鴻臚野王是也。心辨善辭，可使四方，少府五鹿充宗是也。廉潔節儉，太子少傅張譚是也。其以少傅為御史大夫。」上繇下第而用譚，越次避嫌不用野王，以昭儀兄故也。野王乃歎曰：「人皆以女寵貴，我兄弟獨以賤！」野王雖不為三公，甚見器重，有名當世。

### 10. 冯野王出守与因赐告归家罢职

[返回正文第10条](#event-10)

<a id="hs079-p016"></a>

**[《汉书·冯奉世传》P016](../../sources/摘录/汉书-卷079-冯奉世传.md#p016)** · [仓内TXT L9098—L9098](../../sources/本地分卷/汉书/汉书-卷079.md#L9098)

> 成帝立，有司奏野王王舅，不宜備九卿，以秩出為上郡太守，加賜黃金百斤。朔方刺史蕭育奏封事，薦言：「野王行能高妙，內足與圖身，外足以慮化。竊惜野王懷國之寶，而不得陪朝廷與朝者並。野王前以王舅出，以賢復入，明國家樂進賢也。」上自為太子時聞知野王。會其病免，復以故二千石使行河堤，因拜為琅邪太守。是時，成帝長舅陽平侯王鳳為大司馬大將軍，輔政八九年矣，時數有災異，京兆尹王章譏鳳專權不可任用，薦野王代鳳。上初納其言，而後誅章，語在《元后傳》。於是野王懼不自安，遂病，滿三月賜告，與妻子歸杜陵就醫藥。大將軍鳳風御史中丞劾奏野王賜告養病而私自便，持虎符出界歸家，奉詔不敬。杜欽時在大將軍莫府，欽素高野王父子行能，奏記於鳳，為野王言曰：「竊見令曰，吏二千石告，過長安謁，不分別予賜。今有司以為予告得歸，賜告不得，是一律兩科，失省刑之意。夫三最予告，令也；病滿三月賜告，詔恩也。令告則得，詔恩不得，失輕重之差。又二千石病賜告得歸有故事，不得去郡亡著令。傳曰：『賞疑從予，所以廣恩勸功也；罰疑從去，所以慎刑，闕難知也。』今釋令與故事而假不敬之法，甚違闕疑從去之意。即以二千石守千里之地，任兵馬之重，不宜去郡，將以制刑為後法者，則野王之罪，在未制令前也。刑賞大信，不可不慎。」鳳不聽，竟免野王。郡國二千石病賜告不得歸家，自此始。

> 參字叔平，學通《尚書》。少為黃門郎給事中，宿衛十餘年，參為人矜嚴，好修容儀，進退恂恂，甚可觀也。參，昭儀少弟，行又敕備，以嚴見憚，終不得親近侍帷幄。竟寧中，以王舅出補渭陵食官令。以數病徙為寢中郎，有詔勿事。陽朔中，中山王來朝，參擢為上河農都尉。病免官，復為渭陵寢中郎。永始中，超遷代郡太守。以邊郡道遠，徙為安定太守。數歲，病免，復為諫大夫，使領護左馮翊都水。綏和中，立定陶王為皇太子，以中山王見廢，故封王舅參為宜鄉侯，以慰王意。參之國，上書願至中山見王、太后。行未到而王薨。王病時，上奏願貶參爵以關內侯食邑留長安。上憐之，下詔曰：「中山孝王短命早薨，願以舅宜鄉侯參為關內侯，歸家，朕甚愍之。其還參京師，以列侯奉朝請。」五侯皆敬憚之。丞相翟方進亦甚重焉，數謂參：「物禁太甚。君侯以王舅見廢，不得在公卿位，今五侯至尊貴也，與之並列，宜少詘節卑體，視有所宗。而君侯盛修容貌以威嚴加之，此非所以下五侯而自益者也。」參性好禮儀，終不改其恆操。

> 贊曰：《詩》稱「抑抑威儀，惟德之隅。」宜鄉侯參鞠躬履方，擇地而行，可謂淑人君子，然卒死於非罪，不能自免，哀哉！讒邪交亂，貞良被害，自古而然。故伯奇放流，孟子宮刑，申生雉經，屈原赴湘，《小弁》之詩作，《離騷》之辭興。經曰：「心之憂矣，涕既隕之。」馮參姊弟，亦云悲矣！

# 汉书匡衡张禹孔光马宫仕履与奏议

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **佣作求学与善说诗。** 匡衡家世务农，家贫佣作维持所需，勤学研《诗》，时儒称他一讲便解人颐。 [[1]](#note-1)


<a id="event-2"></a>

2. **初举经学而返平原。** 匡衡射策列甲，因不应令补掌故、平原文学。萧望之、梁丘贺奉诏问《诗》大义；宣帝仍使归任，太子却赏识其答。 [[2]](#note-2)


<a id="event-3"></a>

3. **杨兴说史高荐匡衡。** 元帝即位后史高主辅政、萧望之为副，二人不合。杨兴劝史高在幕府任用真正经学人才以建立声誉，史高辟匡衡为议曹史，荐于朝廷，后为郎中、博士。 [[3]](#note-3)


<a id="event-4"></a>

4. **因地震日食而问政。** 皇帝以日食与地震诏问政治得失，匡衡上疏，后面四行连读。 [[4]](#note-4)


<a id="event-5"></a>

5. **大赦难改习俗之本。** 匡衡肯定准许百姓改过，却指出大赦后犯法依旧。原因在贪财声色、薄亲爱、厚私党等风习；若不清理根源，频赦也难废刑。 [[5]](#note-5)


<a id="event-6"></a>

6. **朝廷是风教根基。** 从公卿相让可教民不争说起，列好施、尚义、宽柔的效果，又以朝臣狠厉与求利来解释下民争害和盗窃，批评俗吏专靠峻刑。“F8B5”为底本文字编码痕迹。 [[6]](#note-6)


<a id="event-7"></a>

7. **以国风说明上行下效。** 匡衡并举周召、郑、秦、陈、晋、邠之俗，认为民风随居上者好恶而变，教化须从朝廷近处传到远方。长安自身仍多奢靡，尤其该先整饬。 [[7]](#note-7)


<a id="event-8"></a>

8. **因关东饥馑请俭约任贤。** 匡衡依天人感应论解释灾异，认为关东饥馑实有赋敛重和官吏不善安辑等原因。称许削宫卫、罢珠崖，再请省宫室、纳忠直、远巧佞，用温和廉洁之吏。 [[8]](#note-8)


<a id="event-9"></a>

9. **迁光禄大夫和太子少傅。** 元帝欣赏匡衡的上书，迁他为光禄大夫、太子少傅；两官的先后可与职官材料参照。 [[9]](#note-9)


<a id="event-10"></a>

10. **匡衡代韦玄成拜相。** 匡衡任少傅时常以经义对议，历光禄勋、御史大夫，建昭三年代韦玄成任丞相，封乐安侯。 [[10]](#note-10)


<a id="event-11"></a>

11. **议正南北郊、禁淫祀。** 成帝纳谏，匡衡又请改定南北郊祀、废不合礼的祭祀，具体安排见《郊祀志》。 [[11]](#note-11)


<a id="event-12"></a>

12. **乐安封地误图及责罚。** 郡图在初元元年错认地界，后定乐安封地多四百顷。成帝初郡重订界，匡衡属吏使郡复还其地，他收租谷入家，因而被劾监临自盗、越礼专地，免为庶人，卒于家。 [[12]](#note-12)


<a id="event-13"></a>

13. **匡氏后人能经。** 匡衡子匡咸也明习经书，任至九卿，家族多人曾为博士。 [[13]](#note-13)


<a id="event-14"></a>

14. **张禹传题。** 底本单列张禹姓名，以下叙其学业、辅政与家事。 [[14]](#note-14)


<a id="event-15"></a>

15. **张禹受易论语再任太子师。** 张禹幼时熟悉卜筮，长从施雠学《易》、从王阳与庸生习《论语》。宣帝朝经荐而退归，后任博士，经郑宽中推荐，入授太子《论语》，继迁光禄大夫、东平内史。 [[15]](#note-15)


<a id="event-16"></a>

16. **帝师封爵及拜相。** 成帝即位以师恩封张禹、郑宽中关内侯，张禹领尚书事，因跟王凤共政而求退，帝厚赐慰留；河平四年他代王商任相，封安昌侯。 [[16]](#note-16)


<a id="event-17"></a>

17. **老病罢相就第。** 鸿嘉元年准张禹因病去职，赐车马黄金，位特进，朔望以侯朝见，另添从事史和封户，后屡赐钱。 [[17]](#note-17)


<a id="event-18"></a>

18. **张禹置田与内宴。** 张禹持重而积财，富贵后买入多至四百顷的泾渭灌田，喜辨音声，家后堂设丝竹。 [[18]](#note-18)


<a id="event-19"></a>

19. **彭宣戴崇交往有别。** 彭宣节俭守度，与张禹在便坐讲经，受寻常饭食。戴崇和易多智，劝老师设乐，得在后堂与家中人宴饮，两人知道此事后各自安然。 [[19]](#note-19)


<a id="event-20"></a>

20. **赐坟地和亲家子弟得官。** 成帝赐张禹肥牛亭地，无视王根认为它是陵庙衣冠经行道的反对。探病见其思远嫁女，迁女婿萧咸近京，又因张禹眼色当席授小儿郎官。 [[20]](#note-20)


<a id="event-21"></a>

21. **释灾异以消帝疑王氏。** 成帝因连年地震日食私询张禹，示攻击王氏专政的奏书。张禹怕得罪王氏，指出灾异意义难断，劝专修政、不可信新学之言；王氏因此转而亲近张禹。 [[21]](#note-21)


<a id="event-22"></a>

22. **张禹卒及嗣侯。** 张禹历成、哀两朝，建平二年卒，谥节侯。长子张宏承爵，后任太常，三弟也列禁近官。 [[22]](#note-22)


<a id="event-23"></a>

23. **张侯论的形成。** 张禹为便成帝学习而献《论语章句》，兼取王阳和庸生学说。因其仕位尊贵，后学多归张氏，传中列出前代异篇学者。 [[23]](#note-23)


<a id="event-24"></a>

24. **孔光传题。** 底本单列孔光姓名，以下叙孔氏家世和孔光历朝仕历。 [[24]](#note-24)


<a id="event-25"></a>

25. **孔氏世系及孔霸师承。** 孔光为孔子十四世孙，传从伯鱼、子思列到孔霸。孔安国、孔延年以《尚书》为博士；孔霸学于夏侯胜，宣帝朝授储君经，历任詹事、高密相。 [[25]](#note-25)


<a id="event-26"></a>

26. **孔霸褒号及辞受。** 元帝即位，因师恩赐孔霸关内侯、号褒成君，后曾欲升相而他屡让。孔霸卒，元帝两次素服临吊，按列侯礼赠谥。 [[26]](#note-26)


<a id="event-27"></a>

27. **孔光典机密谨不泄事。** 孔光由经学进官，成帝朝以博士奉使、录冤振民，历尚书等掌机密十余年。应问依经法，删稿避彰君过，不让荐人得知，连温室省中树木也不告家人。 [[27]](#note-27)


<a id="event-28"></a>

28. **立储争议中独荐中山王。** 成帝无子，傅太后经营群臣后宫，多人荐定陶王。孔光以中山王为帝亲弟、援殷礼继及主立中山王；成帝从兄弟不相入庙之礼和近属意见立定陶王，孔光降廷尉。 [[28]](#note-28)


<a id="event-29"></a>

29. **哀帝初傅太后居宫与傅迁。** 哀帝初加孔光封户。孔光虑傅太后参与朝政，主张另筑宫，哀帝依何武议让她居北宫，傅太后遂藉复道往来。后孔光和师丹谏傅迁既罢不应复用，未果。 [[29]](#note-29)


<a id="event-30"></a>

30. **因议傅氏尊号免相。** 孔光、师丹拒绝傅太后与太皇太后并称尊号，师丹先免，傅氏及朱博继续毁谮孔光。哀帝诏以灾荒、盗起、百官怠惰等问责，收相、侯印。 [[30]](#note-30)


<a id="event-31"></a>

31. **哀帝数易相而念孔光。** 孔光退居，朱博因傅太后事自杀，平当继相数月卒，王嘉继任屡谏违旨。时人以三相不及孔光，哀帝重新想到他。 [[31]](#note-31)


<a id="event-32"></a>

32. **召为光禄大夫及举成公敞。** 哀帝重新任孔光给事，位次丞相。孔光按尚书由久次递迁的惯例推荐成公敞任尚书令，敞后来以荐举任东平太守。 [[32]](#note-32)


<a id="event-33"></a>

33. **复任宰相与傅嘉被放。** 王嘉下狱而死，御史大夫贾延免，孔光先继为御史大夫，再相并恢复博山侯爵。哀帝认为早先错误罢免孔光，切责谮者傅嘉，放归原籍。 [[33]](#note-33)


<a id="event-34"></a>

34. **历大司徒、太傅、太师。** 哀帝末改三公，孔光拜大司徒。平帝时王莽借其名望授意上奏排击旧臣，又以孔光为帝傅、转太师。孔光忧惧求退，太后仅许减朝礼、赐杖与食，官属照旧。 [[34]](#note-34)


<a id="event-35"></a>

35. **居公辅位与不私荐门人。** 孔光历成、哀、平三朝，三公及师傅位前后十七年。虽同门人讲疑义，不以高位私荐有人怨他。 [[35]](#note-35)


<a id="event-36"></a>

36. **孔光病中辞还食邑。** 孔光累计食邑一万一千户，病重请还其中七千户及获赐的一所宅第。 [[36]](#note-36)


<a id="event-37"></a>

37. **侯爵续袭与孔子奉祀。** 孔放嗣孔光爵；王莽后用孔永为大司马。另倒叙孔霸获关内侯并请祭孔子，归长子孔福名籍于鲁，后人相承；元始元年朝廷另封周公、孔子后为列侯。 [[37]](#note-37)


<a id="event-38"></a>

38. **马宫传题。** 底本单列马宫姓名，以下叙其治《春秋》入仕、历官和离职。 [[38]](#note-38)


<a id="event-39"></a>

39. **马宫任大司徒及太师。** 马宫习严氏《春秋》，以射策为郎。经师丹推举后历内外官，任右将军并代孔光为大司徒、封扶德侯；孔光死后兼任太师。 [[39]](#note-39)


<a id="event-40"></a>

40. **新朝任太子师。** 王莽代汉后任马宫为太子师，马宫在任而卒。 [[40]](#note-40)


<a id="event-41"></a>

41. **马宫本姓。** 传末注明马宫本姓马矢，仕、学后自称马氏。 [[41]](#note-41)


<a id="event-42"></a>

42. **总评题签。** 底本单列“評論”，接下来是班固总结。 [[42]](#note-42)


<a id="event-43"></a>

43. **评论儒相与自保之讥。** 班固列公孙弘以来以儒宗为相者，承认其传学与见识，却指出多保禄位、招阿谀之讥；也反问全以古人标准相比是否公平。 [[43]](#note-43)

### 3. 杨兴说史高荐匡衡

[返回正文第3条](#event-3)

<a id="hs081-p003"></a>

**[《汉书·匡张孔马传》P003](../../拆分史书/汉书/卷081.md#p003)** · [仓内TXT L9143—L9143](../../拆分史书/汉书/卷081.md#part-1-L9143)

> 會宣帝崩，元帝初即位，樂陵侯史高以外屬為大司馬車騎將軍，領尚書事，前將軍蕭望之為副。望之名儒，有師傅舊恩，天子任之，多所貢薦。高充位而已，與望之有隙。長安令楊興說高曰：「將軍以親戚輔政，貴重於天下無二，然眾庶論議令問休譽不專在將軍者何也？彼誠有所聞也。以將軍之莫府，海內莫不卬望。而所舉不過私門賓客，乳母子弟，人情忽不自知，然一夫竊議，語流天下。夫富貴在身而列士不譽，是有狐白之裘而反衣之也。古人病其若此，故卑體勞心，以求賢為務。傳曰：以賢難得之故因曰事不待賢，以食難得之故而曰飽不待食，或之甚者也。平原文學匡衡材智有餘，經學絕倫，但以無階朝廷，故隨牒在遠方。將軍誠召置莫府，學士歙然歸仁，與參事議，觀其所有，貢之朝廷，必為國器，以此顯示眾庶，名流於世。」高然其言，辟衡為議曹史，薦衡於上，上以為郎中，遷博士，給事中。

### 5. 大赦难改习俗之本

[返回正文第5条](#event-5)

<a id="hs081-p005"></a>

**[《汉书·匡张孔马传》P005](../../拆分史书/汉书/卷081.md#p005)** · [仓内TXT L9145—L9145](../../拆分史书/汉书/卷081.md#part-1-L9145)

> 臣聞五帝不同禮，三王各異教，民俗殊務，所遇之時異也。陛下躬聖德，開太平之路，閔愚吏民觸法抵禁，比年大赦，使百姓得改行自新，天下幸甚。臣竊見大赦之後，奸邪不為衰止，今日大赦，明日犯法，相隨入獄，此殆導之未得其務也。蓋保民者，「陳之以德義」，「示之以好惡」，觀其失而制其宜，故動之而和，綏之而安。今天下俗貪財賤義，好聲色，上侈靡，廉恥之節薄，淫辟之意縱，綱紀失序，疏者逾內，親戚之恩薄，婚姻之黨隆，苟合僥倖，以身設利。不改其原，雖歲赦之，刑猶難使錯而不用也。

### 6. 朝廷是风教根基

[返回正文第6条](#event-6)

<a id="hs081-p006"></a>

**[《汉书·匡张孔马传》P006](../../拆分史书/汉书/卷081.md#p006)** · [仓内TXT L9146—L9146](../../拆分史书/汉书/卷081.md#part-1-L9146)

> 臣愚以為宜一曠然大變其俗。孔子曰：「能以禮讓為國乎，何有？」朝廷者，天下之楨F8B5也。公卿大夫相與循禮恭讓，則民不爭；好仁樂施，則下不暴；上義高節，則民興行；寬柔和惠，則眾相愛。四者，明王之所以不嚴而成化也。何者？朝有變色之言，則下有爭鬥之患；上有自專之士，則下有不讓之人；上有克勝之佐，則下有傷害之心；上有好利之臣，則下有盜竊之民：此其本也。今俗吏之治，皆不本禮讓，而上克暴，或忮害好陷人於罪，貪財而慕勢，故犯法者眾，奸邪不止，雖嚴刑峻法，猶不為變。此非其天性，有由然也。

> 臣竊考《國風》之詩，《周南》、《召南》被賢聖之化深，故篤於行而廉於色。鄭伯好勇，而國人暴虎；秦穆貴信，而士多從死；陳夫人好巫，而民淫祀；晉侯好儉，而民畜聚；太王躬仁，邠國貴恕。由此觀之，治天下者審所上而已。今之偽薄忮害，不讓極矣。臣聞教化之流，非家至而人說之也。賢者在位，能者布職，朝廷崇禮，百僚敬讓，道德之行，由內及外，自近者始，然後民知所法，遷善日進而不自知。是以百姓安，陰陽和，神靈應，而嘉祥見。《詩》曰：「商邑翼翼，四方之極；壽考且寧，以保我後生」此成湯所以建至治，保子孫，化異俗而懷鬼方也。今長安天子之都，親承聖化，然其習俗無以異於遠方，郡國來者無所法則，或見侈靡而放效之。此教化之原本，風俗之樞機，宜先正者也。

### 27. 孔光典机密谨不泄事

**[《汉书·匡张孔马传》P038](../../拆分史书/汉书/卷081.md#p038)** · [仓内TXT L9178—L9178](../../拆分史书/汉书/卷081.md#part-1-L9178)

> 霸四子，長子福嗣關內侯。次子捷、捷弟喜皆列校尉、諸曹。光，最少子也，經學尤明，年未二十，舉為議郎。光祿勳匡衡舉光方正，為諫大夫。坐議有不合，左遷虹長，自免歸教授。成帝初即位，舉為博士，數使錄冤獄，行風俗，振贍流民，奉使稱旨，由是知名。是時，博士選三科，高為尚書，次為刺史，其不通政事，以久次補諸侯太傅。光以高第為尚書，觀故事品式，數歲明習漢制及法令。上甚信任之，轉為僕射、尚書令。有詔光周密謹慎，未嘗有過，加諸吏官，以子男放為侍郎，給事黃門。數年，遷諸吏光祿大夫，秩中二千石，給事中，賜黃金百斤，領尚書事。後為光祿勳，復領尚書，諸吏給事中如故，凡典樞機十餘年，守法度，修故事。上有所問，據經法以心所安而對，不希指苟合；如或不從，不敢強諫爭，以是久而安。時有所言，輒削草稿，以為章主之過，以奸忠直，人臣大罪也。有所薦舉，唯恐其人之聞知。沐日歸休，兄弟妻子燕語，終不及朝省政事。或問光：「溫室省中樹皆何木也？」光嘿不應，更答以他語，其不洩如是。光，帝師傅子，少以經行自著，進官蚤成。不結黨友，養遊說，有求於人。既性自守，亦其勢然也。徙光祿勳為御史大夫。

**[《汉书·匡张孔马传》P039](../../拆分史书/汉书/卷081.md#p039)** · [仓内TXT L9179—L9179](../../拆分史书/汉书/卷081.md#part-1-L9179)

### 29. 哀帝初傅太后居宫与傅迁

[返回正文第29条](#event-29)

<a id="hs081-p042"></a>

**[《汉书·匡张孔马传》P042](../../拆分史书/汉书/卷081.md#p042)** · [仓内TXT L9182—L9182](../../拆分史书/汉书/卷081.md#part-1-L9182)

> 哀帝初即位，躬行儉約，省減諸用，政事由己出，朝廷翕然，望至治焉。褒賞大臣，益封光千戶。時，成帝母太皇太后自居長樂宮，而帝祖母定陶傅太后在國邸，有詔問丞相、大司空：「定陶共王太后宜當何居？」光素聞傅太后為人剛暴，長於權謀，自帝在襁褓而養長教道至於成人，帝之立又有力。光心恐傅太后與政事，不欲令與帝旦夕相近，即議以為定陶太后宜改築宮。大司空何武曰：「可居北宮。」上從武言。北宮有紫房復道通未央宮，傅太后果從復道朝夕至帝所，求欲稱尊號，貴寵其親屬，使上不得直道行。頃之，太后從弟子傅遷在左右尤傾邪，上免官遣歸故郡。傅太后怒，上不得已復留遷。光與大司空師丹奏言：「詔書『侍中、駙馬都尉遷巧佞無義，漏洩不忠，國之賊也，免歸故郡。』復有詔止。天下疑惑，無所取信，虧損聖德，誠不小愆。陛下以變異連見，避正殿，見群臣，思求其故，至今未有所改。臣請歸遷故郡，以銷奸黨，應天戒。」卒不得遣，復為侍中。脅於傅太后，皆此類也。

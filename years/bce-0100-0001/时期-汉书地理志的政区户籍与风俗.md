# 汉书地理志的政区户籍与风俗

[本世纪目录](README.md) · [全部世纪](../README.md)

此处连读各志的制度沿革、学术分类与未详年次的史事；整段原文和已系年节录均可由卷内读本查阅。


<a id="event-1"></a>

1. **黄帝至禹的地理叙事。** 开头以舟车、封邦及分州解释早期地理知识，又引《禹贡》从治山川到定贡赋；黄帝、尧、禹部分是传世叙事。 [[1]](#note-1)


<a id="event-2"></a>

2. **《禹贡》冀、兖、青。** 据土壤与水势分田赋等差，列冀州白壤、兖州黑坟、青州白坟及漆丝、盐、絺、鱼盐等贡物和贡道。 [[2]](#note-2)


<a id="event-3"></a>

3. **《禹贡》徐、扬、荆。** 从淮泗、三江、震泽到江汉云梦，分述土壤、田赋、物产及运输。羽毛、织物、金料、木石之类随土产纳贡。 [[3]](#note-3)


<a id="event-4"></a>

4. **《禹贡》豫、梁、雍。** 豫为伊洛等水会处；梁、雍多记山峡、河源与贵材。田土与税赋各有另一套高下，勿将两者合算。 [[4]](#note-4)


<a id="event-5"></a>

5. **经文的治山与导水路线。** 记录所经山脉、高地及河、汉、江等水路，底本有截句与异字。经文所列九河为古代地理叙述。 [[5]](#note-5)


<a id="event-6"></a>

6. **九州、五服和告成。** 治水后分地定赋，设甸、侯、绥、要、荒五服，远近所纳与所任不同。玄圭告成及受禅承上古传说。 [[6]](#note-6)


<a id="event-7"></a>

7. **周代的制度沿革。** 班固说周参考夏商而损益，重分九州，设职方辨识疆域。州名同于《禹贡》者也有位置与统属差别。 [[7]](#note-7)


<a id="event-8"></a>

8. **《周官》扬、荆、豫。** 按山镇、薮泽、川浸、物产、男女人数比例和适种谷畜列扬、荆、豫州。比例是《周官》原文格例。 [[8]](#note-8)


<a id="event-9"></a>

9. **《周官》青、兖、雍。** 青、兖列蒲鱼、谷物水泽，雍列泾、渭、玉石及适养牛马、适种黍稷等。 [[9]](#note-9)


<a id="event-10"></a>

10. **《周官》幽、冀、并。** 幽州举医无闾及鱼盐，冀州列漳汾及松柏，北方并州列恒山诸水与布帛。 [[10]](#note-10)


<a id="event-11"></a>

11. **分星封域到汉代政区。** 以保章氏按星土定分野叙周代九州。五爵封地按等，诸侯兼并后入秦汉郡县。汉武拓境、置刺史，为下列郡国及古今沿革张本。TXT“十三郡”与通常的刺史部说法分读。 [[11]](#note-11)

132. **南海海道及黄支。** 由日南、徐闻、合浦出海，经都元、邑卢没、谌离、夫甘都卢至黄支。汉译长和募员带黄金丝织物换珠、琉璃与异物，往来借当地商船，也遇风浪、掠杀。元始年间王莽赠礼于黄支王，促遣使献活犀。末叙皮宗、象林和已程不的回航路线。航程约数与古国比定须另核。 [[132]](#note-132)

### 117. 风俗段总说

[返回正文第117条](#event-117)

<a id="hs028-p117"></a>

**[《汉书·地理志》P117](../../sources/摘录/汉书-卷028-地理志.md#p117)** · [仓内TXT L6025—L6025](../../sources/本地分卷/汉书/汉书-卷028.md#L6025)

> 凡民函五常之性，而其剛柔緩急，音聲不同，繫水土之風氣，故謂之風；好惡取舍，動靜亡常，隨君上之情欲，故謂之俗。孔子曰：「移風易俗，莫善於樂。」言聖王在上，統理人倫，必移其本，而易其末，此混同天下一之虖中和，然後王教成也。漢承百年之末，國土變改，民人遷徙，成帝時劉向略言其域分，丞相張禹使屬潁川朱贛條其風俗，猶未宣究，故輯而論之，終其本末著於篇。

### 132. 南海海道及黄支

[返回正文第132条](#event-132)

<a id="hs028-p132"></a>

**[《汉书·地理志》P132](../../sources/摘录/汉书-卷028-地理志.md#p132)** · [仓内TXT L6093—L6093](../../sources/本地分卷/汉书/汉书-卷028.md#L6093)

> 自日南障塞、徐聞、合浦船行可五月，有都元國；又船行可四月，有邑盧沒國；又船行可二十餘日，有諶離國；步行可十餘日，有夫甘都盧國。自夫甘都盧國船行可二月餘，有黃支國，民俗略與珠劯相類。其州廣大，戶口多，多異物，自武帝以來皆獻見。有譯長，屬黃門，與應募者俱入海巿明珠、璧流離、奇石異物，齎黃金雜繒而往。所至國皆稟食為耦，蠻夷賈船，轉送致之。亦利交易，剽殺人。又苦逢風波溺死，不者數年來還。大珠至圍二寸以下。平帝元始中，王莽輔政，欲燿威德，厚遺黃支王，令遣使獻生犀牛。自黃支船行可八月，到皮宗；船行可八月，到日南、象林界云。黃支之南，有已程不國，漢之譯使自此還矣。

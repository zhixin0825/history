# 汉书张骞李广利的西使与远征

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **张骞应募，十余年持节不失。** 张骞是汉中人，建元中任郎。降人说匈奴杀月氏王、以其头作饮器，月氏迁走并恨匈奴而无援。转录在此夹有解释饮器、偏榼、兽子和字音的注语。汉廷想联络月氏，张骞应募，与堂邑氏奴甘父从陇西出发。匈奴截获他，单于用汉是否肯让匈奴借道去越国反问，拘留他十余年，又给他妻子，生了孩子，他仍持汉节。 [[1]](#note-1)


<a id="event-2"></a>

2. **大宛引路而月氏无意报复。** 张骞逃出匈奴向西到大宛，许诺返汉后以厚礼答谢。大宛派向导和译人送至康居，康居转送大月氏。月氏旧王已死，其夫人为王，已控制大夏，安享肥饶之地，离汉又远，无心再攻匈奴；张骞虽到大夏，仍未得到协议。 [[2]](#note-2)


<a id="event-3"></a>

3. **再被扣留后返汉。** 张骞在西方停留一年有余，沿南山拟经羌地归汉，却再次被匈奴俘获。又一年有余，单于死，境内动乱，他同胡人妻子和堂邑父逃归。朝廷授张骞太中大夫、堂邑父奉使君。 [[3]](#note-3)


<a id="event-4"></a>

4. **去十三年与仅二人归。** 张骞健忍宽厚，取信远方居民。胡人堂邑父善射，困乏时打猎供食。起初同行百余人，十三年后只有张骞与堂邑父两名初行人员回来，仍应与上段另有胡妻同行合读。 [[4]](#note-4)


<a id="event-5"></a>

5. **亲历与转闻之别。** 大宛、大月氏、大夏、康居是张骞亲到之地，另外五六个大国的形势物产来自转述。底本所指后文篇名在此留空。 [[5]](#note-5)


<a id="event-6"></a>

6. **乌孙起源传说与张骞分遣副使。** 张骞追述难兜靡被月氏杀害、昆莫幼时由狼哺乳、乌衔肉相救，后受单于养育并以兵夺月氏故地，渐强而不再朝匈奴。漠北战后张骞劝以厚礼和联姻邀乌孙东归，牵制匈奴，并藉此招交大夏等国。武帝令他带三百使团、畜马金帛及持节副使前往。昆莫未明确应允；张骞派副使赴大宛、康居、月氏、大夏，乌孙遣人马随其归谢，顺道查知汉的规模。 [[6]](#note-6)


<a id="event-7"></a>

7. **归任大行与西域逐渐交通。** 张骞还汉出任大行，一年多后卒。后来副使陆续引来各地人，西北国家与汉往来渐广。转录夹注以开通孔道释鑿空，后使借博望侯旧号取信，乌孙最终同汉联姻。出使、归朝和后续互聘分开看。 [[7]](#note-7)


<a id="event-8"></a>

8. **马名、酒泉与西使行程。** 武帝卜说西北将出神马。乌孙良马初名天马，获大宛汗血马后改称乌孙马为西极马、宛马为天马。汉陆续筑令居以西、置酒泉以通西北，遣使远抵安息、奄蔡、犛靬、条支、身毒，继而屡遣使求宛马。早期大团数百，后渐精简，远行往返八九年、近者也需数年。 [[8]](#note-8)


<a id="event-9"></a>

9. **经营西南与使路持续受阻。** 平越以后，西南夷诸部震动并请设汉吏，汉在西南设牂柯、越巂、益州、沈黎、文山等郡，试图由相接之地去大夏。使者仍被昆明阻杀、掠去赍物，出兵后路仍不通。几郡设置有先后，传末指向的篇名脱失。 [[9]](#note-9)


<a id="event-10"></a>

10. **汉使与西域的冲突。** 自张骞得贵，争相出使者用奇闻或利害争取符节，侵吞公物、贸易谋私，有罪获赎后可再求出使。外国厌恶变动的说辞，又仗路远而停供饮食，使节遂与当地冲突。楼兰、姑师和匈奴截击使团，汉遣赵破奴出兵，逐渐击破姑师、俘楼兰王，酒泉亭障延到玉门。袭击、出塞和攻破须分别互读纪表。 [[10]](#note-10)


<a id="event-11"></a>

11. **远使入汉与探寻河源。** 大宛等遣使来观察汉朝物力，献大鸟卵与犛靬幻术艺人。往西的汉使探访当时所认定的河源，采玉回报，武帝据古图书将其山命名昆仑；这里是古人的命名过程。 [[11]](#note-11)


<a id="event-12"></a>

12. **巡狩接待与角抵兴盛。** 武帝巡视海上时带外国宾客出行，在人多的大邑赏财帛、厚给食宿，并让其看仓库储藏、角抵杂戏和大量酒肉，以展示国力。外来的幻术艺人推动节目变化；虽使者频繁往来，大宛以西诸国仍因路远而未服从汉的节制。 [[12]](#note-12)


<a id="event-13"></a>

13. **张猛分目。** 插叙张骞孙张猛，下面转入李广利。 [[13]](#note-13)


<a id="event-14"></a>

14. **张猛出使与自杀。** 张猛字子游，传称有才，元帝时任光禄大夫，曾出使匈奴并给事中，后受石显谗毁，自杀。此处官职与结局均只给元帝时期的范围。 [[14]](#note-14)


<a id="event-15"></a>

15. **李广利分目。** 下文转叙李广利西征大宛及之后的征伐。 [[15]](#note-15)


<a id="event-16"></a>

16. **返汉、侯赏和士卒损耗。** 乌孙受约发骑二千而观望，沿路小国使子弟随军入贡为质。回到玉门仅万人、千马，传将大量死亡归于将吏苛贪。武帝免追究远役，诏称惩治阻断使路和杀汉使之罪，封李广利海西侯、赵弟新畤侯，授赵始成、上官桀、李哆等职，赏士卒及军吏而不录因过谪发者；两伐历四年。底本“及。”处存缺。 [[16]](#note-16)


<a id="event-17"></a>

17. **班固对河源传说的怀疑。** 赞语举昆仑高二千五百里、遮映日月的传说，反问探河源的汉使何曾目睹这样的昆仑，认为《尚书》叙述九州山川较可信，批评《山经》传述夸渺。底本末尾保留脱文和未闭引号。 [[17]](#note-17)

> 張騫，漢中人也，建元中爲郎。時匈奴降者言匈奴破月氏王，以其頭爲飲器，云『以所破月氏王頭共飲血盟』，然則飲酒之器是也。韋云椑榼，晉云獸子，皆非也。椑榼，即今之偏榼，所以盛酒耳，非用飲者也。獸子褻器，所以溲便者也。椑音鼙。月氏遁而怨匈奴，無與共擊之。漢方欲事滅胡，聞此言，欲通使，道必更匈奴中，迺募能使者。騫以郎應募，使月氏，與堂邑氏奴甘父俱出隴西。徑匈奴，匈奴得之，傳詣單于。單于曰：「月氏在吾北，漢何以得往使？吾欲使越，漢肯聽我乎？」留騫十餘歲，予妻，有子，然騫持漢節不失。

> 天子數問騫大夏之屬。騫旣失侯，因曰：「臣居匈奴中，聞烏孫王號昆莫。昆莫父難兜靡本與大月氏俱在祁連、焞煌閒，小國也。大月氏攻殺難兜靡，奪其地，人民亡走匈奴。子昆莫新生，傅父布就翎侯抱亡置草中，爲求食，還，見狼乳之，又烏銜肉翔其旁，以爲神，遂持歸匈奴，單于愛養之。及壯，以其父民衆與昆莫，使將兵，數有功。時，月氏已爲匈奴所破，西擊塞王。塞王南走遠徙，月氏居其地。昆莫旣健，自請單于報父怨，遂西攻破大月氏。大月氏復西走，徙大夏地。昆莫略其衆，因留居，兵稍彊，會單于死，不肯復朝事匈奴。匈奴遣兵擊之，不勝，益以爲神而遠之。今單于新困於漢，而昆莫地空。蠻夷戀故地，又貪漢物，誠以此時厚賂烏孫，招以東居故地，漢遣公主爲夫人，結昆弟，其勢宜聽，則是斷匈奴右臂也。旣連烏孫，自其西大夏之屬皆可招來而爲外臣。」天子以爲然，拜騫爲中郎將，將三百人，馬各二匹，牛羊以萬數，齎金幣帛直數千鉅萬，多持節副使，道可便遣之旁國。騫旣至烏孫，致賜諭指，未能得其決。語在。騫即分遣副使使大宛、康居、月氏、大夏。烏孫發道譯送騫，與烏孫使數十人，馬數十匹，報謝，因令窺漢，知其廣大。

### 10. 汉使与西域的冲突

[返回正文第10条](#event-10)

<a id="hs061-p012"></a>

**[《汉书·张骞李广利传》P012](../../sources/摘录/汉书-卷061-张骞李广利传.md#p012)** · [仓内TXT L8248—L8248](../../sources/本地分卷/汉书/汉书-卷061.md#L8248)

> 自騫開外國道以尊貴，其吏士爭上書言外國竒怪利害，求使。天子爲其絕遠，非人所樂，聽其言，予節，募吏民無問所從來，爲具備人衆遣之，以廣其道。來還不能無侵盜幣物，及使失指，天子爲其習之，輒覆按致重罪，以激怒令贖，復求使。使端無窮，而輕犯法。其吏卒亦輒復盛推外國所有，言大者予節，言小者爲副，故妄言無行之徒皆爭相效。其使皆私縣官齎物，欲賤市以私其利。外國亦厭漢使人人有言輕重，度漢兵遠，不能至，而禁其食物，以苦漢使。漢使乏絕，責怨，至相攻擊。樓蘭、姑師小國，當空道，攻劫漢使王恢等尤甚。而匈奴竒兵又時時遮擊之。使者爭言外國利害，皆有城邑，兵弱易擊。於是天子遣從票侯破奴將屬國騎及郡兵數萬以擊胡，胡皆去。明年，擊破姑師，虜樓蘭王。酒泉列亭鄣至玉門矣。

> 是時，上方數巡狩海上，迺悉從外國客，大都多人則過之，散財帛賞賜，厚具饒給之，以覽視漢富厚焉。大角氐，出竒戲諸怪物，多聚觀者，行賞賜，酒池肉林，令外國客徧觀名倉庫府臧之積，欲以見漢廣大，傾駭之。及加其眩者之工，而角氐竒戲歲增變，其益興，自此始。而外國使更來更去。大宛以西皆自恃遠，尚驕恣，未可詘以禮羈縻而使也。

### 16. 返汉、侯赏和士卒损耗

[返回正文第16条](#event-16)

<a id="hs061-p023"></a>

**[《汉书·张骞李广利传》P023](../../sources/摘录/汉书-卷061-张骞李广利传.md#p023)** · [仓内TXT L8259—L8259](../../sources/本地分卷/汉书/汉书-卷061.md#L8259)

> 初，貳師後行，天子使使告烏孫大發兵擊宛。烏孫發二千騎往，持兩端，不肯前。貳師將軍之東，諸所過小國聞宛破，皆使其子弟從入貢獻，見天子，因爲質焉。軍還，入玉門者萬餘人，馬千餘匹。後行，非乏食，戰死不甚多，而將吏貪，不愛卒，侵牟之，以此物故者衆。及。天子爲萬里而伐，不錄其過，迺下詔曰：「匈奴爲害乆矣，今雖徙幕北，與帝國謀共要絕大月氏使，遮殺中郎將江、故鴈門守攘。危須以西及大宛皆合約殺期門車令、中郎將朝及身毒國使，隔東西道。貳師將軍廣利征討厥罪，伐勝大宛。賴天之靈，從泝河山，涉流沙，通西海，山雪不積，士大夫徑度，獲王首虜，珍怪之物畢陳於闕。其封廣利爲海西侯，食邑八千戶。」又封斬郁成王者趙弟爲新畤侯；軍正趙始成功最多，爲光祿大夫；上官桀敢深入，爲少府；李哆有計謀，爲上黨太守。軍官吏爲九卿者三人，諸侯相、郡守、二千石百餘人，千石以下千餘人。奮行者官過其望，以適過行者皆黜其勞。士卒賜直四萬錢。伐宛再反，凡四歲而得罷焉。

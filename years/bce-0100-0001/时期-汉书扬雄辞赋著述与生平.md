# 汉书扬雄辞赋著述与生平

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **扬氏由晋地迁蜀。** 自序说扬氏祖伯侨支庶食采于晋扬，后有扬侯；六卿争权迫使先人西迁，汉初一支溯江定居岷山之阳。 [[1]](#note-1)


<a id="event-2"></a>

2. **性情与为文准则。** 扬雄好博览通训诂，口吃寡言而深思，家贫安处。论著以合乎先王法度为准，作赋则服膺司马相如。 [[2]](#note-2)


<a id="event-3"></a>

3. **悼屈原而反其自沉。** 扬雄赞相如赋弘丽，尤哀屈原才高不容。认为君子随时行藏，无须自沉，渡湘时以《反离骚》寄意。 [[3]](#note-3)


<a id="event-4"></a>

4. **从扬氏先祖写到湘上吊屈原。** 赋先叙周、晋祖系，继以敬吊“湘纍”转向屈原。 [[4]](#note-4)


<a id="event-5"></a>

5. **清洁者陷于污浊。** 赋问守清者何以遭乱，归于污浊的世道，以纍指屈原。 [[5]](#note-5)


<a id="event-6"></a>

6. **阳朔自陈并写屈原服饰。** 作者标举阳朔的时令，称许屈原族系和辞章，用规矩、权衡、星象与华服寄托操守，又以美物错投异域写不见知。 [[6]](#note-6)


<a id="event-7"></a>

7. **凤骥难与庸物相竞。** 凤、骥对照群禽、驴骡，荆棘使猿猴也难落足；又讥楚王信椒兰之谗，责屈原未早察。 [[7]](#note-7)


<a id="event-8"></a>

8. **香服与众美的妒忌。** 屈原有芳洁的衣饰而不为人知，众美竞妍又相妒，作者问何必显扬自己的才德。 [[8]](#note-8)


<a id="event-9"></a>

9. **神龙待云与芳草遭霜。** 神龙伏渊待时，得云始起；屈原芳美却遭盛夏意外凝霜，表示君臣际遇反常。 [[9]](#note-9)


<a id="event-10"></a>

10. **渡湘欲问重华。** 驰渡江湘、望苍梧，想请舜裁断心中的烦惑，转又疑未必获同意；江涛之险也并非屈原独有。 [[10]](#note-10)


<a id="event-11"></a>

11. **本可养年却自陨。** 食玉屑秋菊可求延年，临汨罗却先自殒；以扶桑、鸾凰风云写时日奔驰难挽。 [[11]](#note-11)


<a id="event-12"></a>

12. **弃香草与不用神谕。** 卷香草而投水，求神占吉凶却不听灵氛的劝，终于自沉；作者着意指出可以另作选择。 [[12]](#note-12)


<a id="event-13"></a>

13. **等待贤辅与芳草失时。** 赋以傅说、鸟鸣及芳草写贤才晚遇之忧，问为何有可行的道路而不实践。 [[13]](#note-13)


<a id="event-14"></a>

14. **求女屡失与四方可择。** 从弃宓妃、求瑶台女到托媒失合，用求偶写不遇；四荒尚可周游，何必执着一高丘。 [[14]](#note-14)


<a id="event-15"></a>

15. **借孔子去鲁劝勿自毁。** 作者叹遭逢在时命，以孔子离鲁周游而归说明可以去亦可返，质问屈原何必沉湘。 [[15]](#note-15)


<a id="event-16"></a>

16. **随成帝到甘泉并献赋。** 有人以文似相如荐扬雄，成帝为求后嗣祠甘泉、河东，召为待诏。扬雄正月随驾返后奏《甘泉赋》，寓讽于颂。 [[16]](#note-16)


<a id="event-17"></a>

17. **郊祀前的仪卫。** 赋写将祀上天，群臣择吉列阵，星宿神灵承担警跸驱祟之职。 [[17]](#note-17)


<a id="event-18"></a>

18. **乘舆升行。** 帝车以龙凤为饰，旂旐与骑乘齐发，风雷天门等辞使车队带有升天的气势。 [[18]](#note-18)


<a id="event-19"></a>

19. **未至已见甘泉宫。** 远望通天台高不可度，林薄丘谷分布新建殿台，各处离宫错落相接。 [[19]](#note-19)


<a id="event-20"></a>

20. **宫观迷目与钟虡。** 殿阁交错令人几乎失去方向，玉树、壁饰与金人钟架交映，赋将宫中景物比作天帝之居。 [[20]](#note-20)


<a id="event-21"></a>

21. **宫室比拟天域。** 从星神、门户、神兽与仙山写方位，突出前殿浮柱飞椽和高阁相持的奇构。 [[21]](#note-21)


<a id="event-22"></a>

22. **风与香声入宫。** 旋风振动草木、拂门发香，钟声与风声交错。般、倕等巧工也仿佛弃具不能追及。 [[22]](#note-22)


<a id="event-23"></a>

23. **斋戒与求贤。** 盛观之后转到皇帝清心斋戒、迎神求福，并求皋陶、伊尹般的德臣同修祭礼。 [[23]](#note-23)


<a id="event-24"></a>

24. **柴祭、酒礼与神降。** 焚柴烟上，树灵旗、用玄瓒秬鬯，巫咸启天门，赋想象群神降坛、瑞应云集。 [[24]](#note-24)


<a id="event-25"></a>

25. **礼成还驾。** 车驾经三峦、棠梨返回，以雷鼓风雨和八荒和协写祭毕归途，推颂帝德久远。 [[25]](#note-25)


<a id="event-26"></a>

26. **《甘泉赋》乱辞。** 收束前文，重写圜丘、宫峦和天神徘徊，祈帝室子孙受福不绝。 [[26]](#note-26)


<a id="event-27"></a>

27. **甘泉旧宫与间接讽谏。** 甘泉旧有秦离宫，汉武帝增诸观，规格超过古君俭制。因非成帝新造，扬雄不便直谏，把话寄在赋中。 [[27]](#note-27)


<a id="event-28"></a>

28. **《河东赋》写暮春祭仪。** 赋从暮春埋祭后土起笔，群臣法服、车旗云集，再以星象风雷神话写行列。 [[28]](#note-28)


<a id="event-29"></a>

29. **祭毕巡游怀古。** 灵祇受祭后，帝驾经介山、龙门等，赋追怀介子推、大禹与舜等，连类评论前代兴衰。 [[29]](#note-29)


<a id="event-30"></a>

30. **以古圣理想收束河东赋。** 辞谓大汉本可兼总诸古功，召四时神引道，展六经而颂清庙，勉循三皇五帝之迹。 [[30]](#note-30)


<a id="event-31"></a>

31. **从十二月羽猎议苑囿。** 扬雄随驾冬猎，先申古代宫苑只求足礼和供给，不夺百姓良田，收获有余则可出现赋所称祥瑞。 [[31]](#note-31)


<a id="event-32"></a>

32. **以时代异宜铺叙颂辞。** 文中有以帝王制度随时而异为说，继转入富拟天地、车驾气象足越诸古王的铺叙。 [[32]](#note-32)


<a id="event-33"></a>

33. **冬猎前整治围场。** 冬末封域、命虞人理泽，清道备物，横罗汧渭、酆镐；借远古水土神的形象统领猎地。 [[33]](#note-33)


<a id="event-34"></a>

34. **帝车入苑。** 黎明帝车出宫，旗钟、神灵、随骑相从，经西园和诸苑地，燃烽举火，猎事展开。 [[34]](#note-34)


<a id="event-35"></a>

35. **壮士分道追搏。** 猎士追逐、搏击山谷林莽的多种禽兽，车骑登降汇合，辞铺陈速度、声响和声势。 [[35]](#note-35)


<a id="event-36"></a>

36. **猎队移围合击。** 从弓手列阵写帝车入上兰，各队调整围猎，夹击禽兽；赋中神电扫地的写法属铺张。 [[36]](#note-36)


<a id="event-37"></a>

37. **馆中观水与神异。** 猎渐歇而集靖冥馆，临大池观鸟鱼珠玉，遣善水之人操演；池中诸神怪为赋的想象。 [[37]](#note-37)


<a id="event-38"></a>

38. **诸儒陈礼与远国来贡。** 群儒在前讲典礼、修雅颂，赋由猎场转写文教声威及边地首领致贡，众臣推颂帝德。 [[38]](#note-38)


<a id="event-39"></a>

39. **由苑囿转写仁惠。** 帝谦抑不认盛颂，赋设想停奢游、节华饰、劝农桑，并开放禁苑、公储利民，落脚于德政。 [[39]](#note-39)


<a id="event-40"></a>

40. **长杨射熊馆之猎与赋。** 成帝欲向胡客夸示禽兽，右扶风发民捕兽送射熊馆，影响秋收。扬雄从行返后作《长杨赋》。 [[40]](#note-40)


<a id="event-41"></a>

41. **墨客问长杨猎扰民。** 子墨客卿设问，列征车骑、围捕多种兽类及妨碍农收，认为与圣主养民相抵牾。 [[41]](#note-41)


<a id="event-42"></a>

42. **翰林主人请陈大意。** 翰林主人以客只见其外相答，表示要略述校猎的深层理由。 [[42]](#note-42)


<a id="event-43"></a>

43. **墨客应答。** 客表示愿听，承接主人的历史与政治论说。 [[43]](#note-43)


<a id="event-44"></a>

44. **从秦乱写到高祖创业。** 主人说秦虐民，英雄竞争而天下动乱，高祖因受命举兵，不顾辛苦，为万民劳战。 [[44]](#note-44)


<a id="event-45"></a>

45. **文帝承平守俭。** 主人描绘文帝衣器宫室从简、拒绝奢华声色，以星度平正比喻政治清明。 [[45]](#note-45)


<a id="event-46"></a>

46. **武帝发兵四方。** 叙边地诸患与武帝出师，以卫青、霍去病等军势迅疾、进抵匈奴地而作颂辞。 [[46]](#note-46)


<a id="event-47"></a>

47. **以习武备患解释长杨之猎。** 主人称今朝尚仁，仍需安时防险，因此校骑武力；又以节用和避免过度耗民申说其尺度。 [[47]](#note-47)


<a id="event-48"></a>

48. **墨客承认受教。** 主客对话以墨客下席拜谢，称先前疑惑已解而收。 [[48]](#note-48)


<a id="event-49"></a>

49. **哀帝时写《太玄》并作《解嘲》。** 丁傅、董贤用权，趋附者升官很快，扬雄撰《太玄》自守。有人嘲讽，他写答辞。 [[49]](#note-49)


<a id="event-50"></a>

50. **客以进取嘲扬雄。** 客把显君荣亲、拜爵说成士的要务，指责扬雄不能献策游说，竟以深奥的《玄》自苦。 [[50]](#note-50)


<a id="event-51"></a>

51. **以战国游士释古今条件差异。** 扬雄说显位失足可祸及家族。诸国竞争时任用游士，所以邹衍、孟轲一类有机会进退。 [[51]](#note-51)


<a id="event-52"></a>

52. **一统后士众而路窄。** 天下郡县由朝廷节制，以刑法礼经约束，士人众多皆自比古贤；得途与失途并非各靠口才。 [[52]](#note-52)


<a id="event-53"></a>

53. **列游士遇合并陈今世的顾虑。** 旧时士可立谈受重亦可久不遇，能自由游说；今所言或行一异就见疑获罪，使人往往噤声。 [[53]](#note-53)


<a id="event-54"></a>

54. **守静可以全身。** 以雷火盛而终歇、门第太显招危等比喻收束，称清静守默为持德保身之道。 [[54]](#note-54)


<a id="event-55"></a>

55. **客再问何必《玄》。** 客追问范雎、蔡泽等无须《玄》也能成名，质疑扬雄所持。 [[55]](#note-55)


<a id="event-56"></a>

56. **以时势解释范蔡等人的成功。** 扬雄逐举范雎、蔡泽、娄敬等受用之例，强调其说切合处境与时机，不能指望在另一世照搬。 [[56]](#note-56)


<a id="event-57"></a>

57. **反省赋的讽谏效果。** 扬雄认为赋用华辞铺张，到归正时读者已受声色吸引。相如《大人赋》反助武帝求仙即为例，扬雄于是停作此类赋。 [[57]](#note-57)


<a id="event-58"></a>

58. **《解难》客以艰深相责。** 客认为著书应合人需要，讥《太玄》深幽难通，令著者与读者空耗精神。 [[58]](#note-58)


<a id="event-59"></a>

59. **扬雄答深义难用浅辞。** 扬雄以天象地度、虬龙升天及乐律等为比，认为所论幽深，文字不得不难；成书藏待后人。 [[59]](#note-59)


<a id="event-60"></a>

60. **《法言》写作缘起。** 扬雄不满诸子泥辩自异、司马迁史论不尽合经，把问答仿《论语》成十三篇，下列自序的篇目。 [[60]](#note-60)


<a id="event-61"></a>

61. **《法言·学行》。** 人初蒙昧容易任情，须用道理教导，列为第一篇。 [[61]](#note-61)


<a id="event-62"></a>

62. **《法言·吾子》。** 文周至孔子成王道，后来诸家分歧，列为第二篇。 [[62]](#note-62)


<a id="event-63"></a>

63. **《法言·修身》。** 行事有本，施于众人之前要从自身起，列为第三篇。 [[63]](#note-63)


<a id="event-64"></a>

64. **《法言·问道》。** 天道须循圣人考察，以得其中为度，过与不及皆失，列为第四篇。 [[64]](#note-64)


<a id="event-65"></a>

65. **《法言·问神》。** 深微心神可以经纬方物，其运用以道德仁义礼为依，列为第五篇。 [[65]](#note-65)


<a id="event-66"></a>

66. **《法言·问明》。** 明哲洞察又能谦谨避患而保天命，列为第六篇。 [[66]](#note-66)


<a id="event-67"></a>

67. **《法言·寡见》。** 立言应广大幽深、参合天地神明，超出浅近常谈，列为第七篇。 [[67]](#note-67)


<a id="event-68"></a>

68. **《法言·五百》。** 圣人聪明深厚，承天察灵，为众伦树立法度，列为第八篇。 [[68]](#note-68)


<a id="event-69"></a>

69. **《法言·先知》。** 施政化民贵在中和，而中和要能明察人情，列为第九篇。 [[69]](#note-69)


<a id="event-70"></a>

70. **《法言·重黎》。** 以圣人为衡量标准，论孔子以来君相名臣高下，列为第十篇。 [[70]](#note-70)


<a id="event-71"></a>

71. **《法言·渊骞》。** 从颜回、闵子骞的德行谈到汉代萧曹、名将的层次，列为第十一篇。 [[71]](#note-71)


<a id="event-72"></a>

72. **《法言·君子》。** 君子秉持德行始终如一，循法度而通圣人规范，列为第十二篇。 [[72]](#note-72)


<a id="event-73"></a>

73. **《法言·孝至》。** 从安亲到宁神，进而以四方悦服为安宁之极，列为第十三篇。 [[73]](#note-73)


<a id="event-74"></a>

74. **班固补扬雄入京、任官及问学。** 前文为扬雄自序。班固叙王音赏其文、荐待诏，献赋拜郎，与王莽、刘歆、董贤等同列，三朝少迁，学者曾从他问难。 [[74]](#note-74)


<a id="event-75"></a>

75. **侯芭传学和扬雄卒。** 扬雄贫而好酒，侯芭长期随居学习《太玄》《法言》。刘歆疑《太玄》不能传，扬雄笑而不答；天凤五年卒，侯芭为其营墓服丧。 [[75]](#note-75)


<a id="event-76"></a>

76. **桓谭论扬雄著作能否传世。** 王邑、严尤闻死，问桓谭。桓谭称世人轻同时之士，举老子书由近而远渐重为比，认为扬雄作品有文义定可流传。 [[76]](#note-76)

### 1. 扬氏由晋地迁蜀

[返回正文第1条](#event-1)

<a id="hs087-p001"></a>

**[《汉书·扬雄传》P001](../../sources/摘录/汉书-卷087-扬雄传.md#p001)** · [仓内TXT L9401—L9401](../../sources/本地分卷/汉书/汉书-卷087.md#L9401)

> 揚雄字子雲，蜀郡成都人也。其先出自有周伯僑者，以支庶初食采於晉之揚，因氏焉，不知伯僑周何別也。揚在河、汾之閒，周衰而揚氏或稱侯，號曰揚侯。會晉六卿爭權，韓、魏、趙興而范中行、知伯弊。當是時，偪揚侯，揚侯逃於楚巫山，因家焉。楚漢之興也，揚氏遡江上，處巴江州。而揚季官至廬江太守，漢元鼎閒避仇復遡江上，處㟭山之陽曰郫，有田一壥，有宅一區，世世以農桑爲業。自季至雄，五世而傳一子，故雄亡它揚於蜀。

> 雄以爲賦者，將以風之，必推類而言，極麗靡之辭，閎侈鉅衍，競於使人不能加也，旣迺歸之於正，然覽者已過矣。往時武帝好神仙，相如上《大人賦》，欲以風，帝反縹縹有陵雲之志。繇是言之，賦勸而不止，明矣。又頗似俳優淳于髡、優孟之徒，非法度所存，賢人君子詩賦之正也，於是輟不復爲。而大潭思渾天，參摹而四分之，極於八十一。旁則三摹九据，極之七百二十九贊，亦自然之道也。故觀《易》者，見其卦而名之；觀《玄》者，數其畫而定之。《玄》首四重者，非卦也，數也。其用自天元推一晝一夜陰陽數度律曆之紀，九九大運，與天終始。故玄三方、九州、二十七部、八十一家、二百四十三表、七百二十九贊，分爲三卷，曰一二三，與《泰初曆》相應，亦有顓頊之曆焉。𢶅之以三策，關之以休咎，絣之以象類，播之以人事，文之以五行，擬之以道德仁義禮知。無主無名，要合《五經》，苟非其事，文不虛生。爲其泰曼漶而不可知，故有《首》、《衝》、《錯》、《測》、《攡》、《瑩》、《數》、《文》、《掜》、《圖》、《告》十一篇，皆以解剥《玄》體，離散其文，章句尚不存焉。《玄》文多，故不著；觀之者難知，學之者難成。客有難玄大深，衆人之不好也，雄解之，號曰《解難》。其辭曰：

> 揚子曰：「俞。若夫閎言崇議，幽微之塗，蓋難與覽者同也。昔人有觀象於天，視度於地，察法於人者，天麗且彌，地普而深，昔人之辭，迺玉迺金。彼豈好爲艱難哉？埶不得已也。獨不見夫翠虯絳螭之將登虖天，必聳身於倉梧之淵；不階浮雲，翼疾風，虛舉而上升，則不能撠膠葛，騰九閎。日月之經不千里，則不能燭六合，燿八紘；泰山之高不嶕嶢，則不能浡滃雲而散歊烝。是以宓犧氏之作《易》也，緜絡天地，經以八卦，文王附六爻，孔子錯其象而彖其辭，然後發天地之臧，定萬物之基。《典》《謨》之篇，《雅》《頌》之聲，不溫純深潤，則不足揚鴻烈而章緝熙。蓋胥靡爲宰，寂寞爲尸；大味必淡，大音必希；大語叫叫，大道低回。是以聲之眇者不可同於衆人之耳，形之美者不可棍於世俗之目，辭之衍者不可齊於庸人之聽。今夫弦者，高張急徽，追趨逐耆，則坐者不期而附；試爲之施《咸池》，揄《六莖》，發《蕭韶》，詠《九成》，則莫有和也。是故鍾期死，伯牙絕弦破琴而不肯與衆鼓；獿人亡，則匠石輟斤而不敢妄斲。師曠之調鍾，竢知音者之在後也；孔子作《春秋》，幾君子之前睹也。老耼有遺言，貴知我者希，此非其操與！」

**[《汉书·扬雄传》P078](../../sources/摘录/汉书-卷087-扬雄传.md#p078)** · [仓内TXT L9478—L9478](../../sources/本地分卷/汉书/汉书-卷087.md#L9478)

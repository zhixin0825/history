# 汉书李广苏建苏武的生平与未详年事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **李广家世与文帝十四年从军。** 陇西成纪人，家世习射，传以秦将李信为祖。匈奴犯萧关，他以良家子参战、斩获而为郎骑常侍。文帝看到他搏兽善射，惜其不逢高祖立功之时。 [[1]](#note-1)


<a id="event-2"></a>

2. **景帝朝军功及徙守上郡。** 景帝继位，李广为骑郎将，七国之乱中从周亚夫战昌邑；因私受梁王将军印未受赏。后为上谷守，因公孙昆邪担心他屡战会死，改任上郡。 [[2]](#note-2)


<a id="event-3"></a>

3. **李广与程不识之治军。** 武帝起用李广、程不识为两宫卫尉，曾同守边。李广管理简易而远置斥候，军士乐从；程不识重营列、名籍、夜柝，禁令严明。两人方式利害不同。 [[3]](#note-3)


<a id="event-4"></a>

4. **李广复起与霸陵尉。** 退居时夜过霸陵亭受该尉留阻。辽西受袭后武帝召为右北平守。李广把霸陵尉带入军中处斩、自陈其罪，武帝以将军威势回应。北边称其飞将军。 [[4]](#note-4)


<a id="event-5"></a>

5. **射石与射虎。** 曾误射草中石而箭没，后来再射不能入。任太守时遇虎常亲射，右北平一次被虎所伤而终射杀虎。 [[5]](#note-5)


<a id="event-6"></a>

6. **李蔡受封拜相与李广不侯之问。** 李蔡从卫青击右贤王受封，后代公孙弘为相。李广不能封侯，问望气人王朔。李广忆杀降羌，王朔以为此事损德，是不侯之因；此为对谈中的解释。 [[6]](#note-6)


<a id="event-7"></a>

7. **李广平日待士与射法。** 任七郡守，赏赐均分部下，饮食与士卒共，家无余财。将众遇断水缺粮，士卒未遍饮食，自己不先尝；口讷善射，待敌近方发，故虽箭可立中亦屡受困伤。 [[7]](#note-7)


<a id="event-8"></a>

8. **李氏子侄军功、李蔡案和李敢之死。** 李当户、李椒早卒。李蔡盗取陵地，因下狱将至自杀。李敢漠北夺旗鼓而获关内侯，继任郎中令，后伤卫青；霍去病为舅报怨，甘泉射杀李敢，武帝托辞鹿触。篇末再记霍去病死。 [[8]](#note-8)


<a id="event-9"></a>

9. **李敢后代及李陵初出。** 李敢女事太子，子李禹亦得宠，曾受命斗虎被解。李当户遗腹子李陵将兵败降，李禹后来被告将投奔李陵而死。 [[9]](#note-9)


<a id="event-10"></a>

10. **李陵小目。** 以下详李陵由边军将领转为匈奴降将的过程。 [[10]](#note-10)


<a id="event-11"></a>

11. **李陵少年宿卫、训练边兵和征宛。** 年轻为建章监，善骑射而爱士，被武帝视为有李广风。曾小队巡居延察地形，后任骑都尉教射备边。贰师伐大宛时后继未及会战，循敦煌迎军后归张掖。 [[11]](#note-11)


<a id="event-12"></a>

12. **李陵遭围并连战南退。** 浚稽山遇单于军。对方起初被击退又增兵，李陵且战且引，伤员按伤情分派乘车与战守，又处决躲在车里的随军妇女。行经泽地、山谷屡战，单于怀疑前方有伏，一度欲罢。 [[12]](#note-12)


<a id="event-13"></a>

13. **管敢降敌与李陵兵败。** 叛卒管敢告匈奴汉军缺援缺箭，单于加强合攻。箭用尽，官兵弃车入险。李陵遣众各自逃生；夜间与韩延年突围，延年战死，李陵投降，逃到边塞四百余人。 [[13]](#note-13)


<a id="event-14"></a>

14. **司马迁受刑，武帝后悔未救。** 武帝以司马迁替李陵说项贬贰师，对司马迁用宫刑。后来武帝也悔未援李陵，派使赏其逃回部属；这些后续具体年月需与本传之外的材料另核。 [[14]](#note-14)


<a id="event-15"></a>

15. **公孙敖还报导致李陵族诛。** 公孙敖未能接回李陵，报告汉降将教练匈奴，朝廷诛李陵家。李陵称教兵者是李绪，遂刺杀李绪；大阏氏欲杀李陵，单于藏匿保护。 [[15]](#note-15)


<a id="event-16"></a>

16. **李陵与卫律在匈奴得贵。** 李陵娶单于女为右校王，有议事职责。卫律原在汉长，与协律都尉李延年友善，出使回汉时惧牵连李氏之狱而逃降，封丁灵王，多侍单于。 [[16]](#note-16)


<a id="event-17"></a>

17. **昭帝朝任立政劝李陵归汉。** 霍光、上官桀借故旧遣任立政等劝李陵回国，先借佩刀传暗示，后得私语。李陵称回归容易却怕再受辱，卫律也出言阻止。 [[17]](#note-17)


<a id="event-18"></a>

18. **苏建小目。** 以下叙苏建封侯、带兵和儿子。 [[18]](#note-18)


<a id="event-19"></a>

19. **苏建军功与失爵。** 杜陵人，从卫青有功受平陵侯，领筑朔方，又任游击及右将军。定襄作战赵信降、苏建失军，赎免为庶人，后任代郡守卒；三子中苏武最著名。 [[19]](#note-19)


<a id="event-20"></a>

20. **苏武小目。** 以下为苏武出使留匈奴近二十年。 [[20]](#note-20)


<a id="event-21"></a>

21. **苏武送还匈奴使者。** 苏武因父任为郎。汉匈屡互留使，且鞮侯初立主动释放汉使，武帝令苏武持节送还汉所留匈奴使并赠厚礼。张胜、常惠等及百余人同行。 [[21]](#note-21)


<a id="event-22"></a>

22. **张胜资助虞常，密谋失败。** 匈奴中缑王、虞常等欲劫主母归汉。虞常又私请张胜资助刺杀卫律。因有人告密，兵败，虞常被生擒；苏武原不知情。 [[22]](#note-22)


<a id="event-23"></a>

23. **苏武自刺不愿辱使命。** 张胜怕牵连，告苏武。卫律奉命问罪，单于曾想杀汉使后改劝降。苏武不愿屈节，自刺重伤，被卫律招医救回，张胜遭拘系。 [[23]](#note-23)


<a id="event-24"></a>

24. **卫律杀虞常并逼苏武降。** 卫律以刀威之，张胜请降，苏武拒绝连坐；卫律以自身爵禄诱降，苏武斥其背汉，并举前朝杀汉使而起争端的后果，坚拒。 [[24]](#note-24)


<a id="event-25"></a>

25. **幽窖挨饿，流徙北海。** 粮饮被绝，苏武嚼雪和毡毛却未死，单于徙之北海无人处，令公羊产乳方可回，常惠等分隔他所。 [[25]](#note-25)


<a id="event-26"></a>

26. **苏武持节牧羊与於靬王。** 掘鼠粮、持节牧羊，经年旄秃。於靬王见他能治射具而供衣食，病时赐畜具与毡帐。王死众去，丁令劫羊，他又陷困。 [[26]](#note-26)


<a id="event-27"></a>

27. **李陵来劝，苏武拒降。** 李陵以苏武旧友身份劝降，备述其兄弟死、母逝、妻再嫁，又借自身降胡力说武帝年高刑重。苏武念君恩父义，愿死效节。李陵终于感泣而别。这里先回叙天汉二年李陵投降，后文所叙劝降在其后，年月未著。 [[27]](#note-27)


<a id="event-28"></a>

28. **闻武帝崩而南向哭。** 李陵托妻赠给苏武牛羊，后带来云中俘虏所报告的武帝去世讯息，苏武南望哭至呕血，持续举哀数月。 [[28]](#note-28)


<a id="event-29"></a>

29. **雁足传书为使者托辞、李陵送别。** 昭帝时汉匈和亲，匈奴谎称苏武已死。常惠夜见汉使，拟以皇帝猎获雁足帛书作托辞，单于受诘承认苏武仍活，九人得还。李陵歌舞泣别，叹自己被族诛后已无报国之路。 [[29]](#note-29)


<a id="event-30"></a>

30. **霍光免追苏武而罢官。** 燕王等借苏武受官与霍光亲信任用相比，指控霍光专权。案破后因苏武与上官氏、桑弘羊有旧、儿子牵连，廷尉请捕苏武，霍光压下奏疏，只令免官。 [[30]](#note-30)


<a id="event-31"></a>

31. **参与定策与晚年复起。** 昭帝逝后参与立宣帝，受关内侯爵与食邑。后经张安世荐他通故实、不辱使节，又任右曹典属国，老臣许朔望朝并号祭酒。 [[31]](#note-31)


<a id="event-32"></a>

32. **赎迎通国与苏武卒。** 平日赏赐尽给亲故，诸重臣敬之。宣帝听说胡地有子苏通国，准遣使赠帛赎回，任其为郎，也任用苏武侄子。苏武神爵二年卒，年八十余。 [[32]](#note-32)


<a id="event-33"></a>

33. **麒麟阁十一名臣。** 甘露三年单于首次入朝，宣帝图画中兴重臣十一人，霍光只称姓不署名，余自张安世至苏武各署职爵。黄霸、于定国等虽有嘉绩而未列像。 [[33]](#note-33)


<a id="event-34"></a>

34. **评论标记。** 底本设“評論”一行，后接班固赞。 [[34]](#note-34)


<a id="event-35"></a>

35. **班固赞李广与苏武。** 以“桃李不言，下自成蹊”赞李广诚于士卒，又悲由李广至李陵宗族遭祸。苏武奉使守节，则用孔子杀身成仁、不辱君命相称。 [[35]](#note-35)

### 3. 李广与程不识之治军

[返回正文第3条](#event-3)

<a id="hs054-p004"></a>

**[《汉书·李广苏建传》P004](../../sources/摘录/汉书-卷054-李广苏建传.md#p004)** · [仓内TXT L7906—L7906](../../sources/本地分卷/汉书/汉书-卷054.md#L7906)

> 武帝即位，左右言廣名將也，由是入為未央衛尉，而程不識時亦為長樂衛尉。程不識故與廣俱以邊太守將屯。及出擊胡，而廣行無部曲行陳，就善水草頓捨，人人自便，不擊刁斗自衛，莫府省文書，然亦遠斥候，未嘗遇害。程不識正部曲行伍營陳，擊刁斗，吏治軍簿至明，軍不得自便。不識曰：「李將軍極簡易，然虜卒犯之，無以禁；而其士亦佚樂，為之死。我軍雖煩憂，虜亦不得犯我。」是時，漢邊郡李廣、程不識為名將，然匈奴畏廣，士卒多樂從，而苦程不識。不識孝景時以數直諫為太中大夫，為人廉，謹於文法。

### 4. 李广复起与霸陵尉

[返回正文第4条](#event-4)

<a id="hs054-p006"></a>

**[《汉书·李广苏建传》P006](../../sources/摘录/汉书-卷054-李广苏建传.md#p006)** · [仓内TXT L7908—L7908](../../sources/本地分卷/汉书/汉书-卷054.md#L7908)

> 數歲，與故穎陰侯屏居藍田南山中射獵。嘗夜從一騎出，從人田間飲。還至亭，霸陵尉醉，呵止廣，廣騎曰：「故李將軍。」尉曰：「今將軍尚不得夜行，何故也！」宿廣亭下。居無何，匈奴入遼西，殺太守，敗韓將軍。韓將軍後徙居右北平，死。於是上乃召拜廣為右北平太守。廣請霸陵尉與俱，至軍而斬之，上書自陳謝罪。上報曰：「將軍者，國之爪牙也。《司馬法》曰：『登車不式，遭喪不服，振旅撫師，以征不服，率三軍之心，同戰士之力，故怒形則千里竦，威振則萬物狀；是以名聲暴於夷貉，威稜憺乎鄰國。』夫報忿除害，捐殘去殺，朕之所圖於將軍也；若乃免冠徒跣，稽顙請罪，豈朕之指哉！將軍其率師東轅，彌節白檀，以臨右北平盛秋。」廣在郡，匈奴號曰「漢飛將軍」，避之，數歲不入界。

<a id="note-6"></a>

### 6. 李蔡受封拜相与李广不侯之问

[返回正文第6条](#event-6)

<a id="hs054-p009"></a>

**[《汉书·李广苏建传》P009](../../sources/摘录/汉书-卷054-李广苏建传.md#p009)** · [仓内TXT L7911—L7911](../../sources/本地分卷/汉书/汉书-卷054.md#L7911)

> 初，廣與從弟李蔡俱為郎，事文帝。景帝時，蔡積功至二千石。武帝元朔中，為輕車將軍，從大將軍擊右賢王，有功中率，封為樂安侯。元狩二年，代公孫弘為丞相。蔡為人在下中，名聲出廣下遠甚，然廣不得爵邑，官不過九卿。廣之軍吏及士卒或取封侯。廣與望氣王朔語云：「自漢擊匈奴，廣未嘗不在其中，而諸妄校尉已下，材能不及中，以軍功取侯者數十人。廣不為後人，然終無尺寸功以得封邑者，何也？豈吾相不當侯邪？」朔曰：「將軍自念，豈嘗有恨者乎？」廣曰：「吾為隴西守，羌嘗反，吾誘降者八百餘人，詐而同日殺之，至今恨獨此耳。」朔曰：「禍莫大於殺已降，此乃將軍所以不得侯者也。」

### 7. 李广平日待士与射法

[返回正文第7条](#event-7)

<a id="hs054-p010"></a>

**[《汉书·李广苏建传》P010](../../sources/摘录/汉书-卷054-李广苏建传.md#p010)** · [仓内TXT L7912—L7912](../../sources/本地分卷/汉书/汉书-卷054.md#L7912)

> 廣歷七郡太守，前後四十餘年，得賞賜，輒分其戲下，飲食與士卒共之。家無余財，終不言生產事。為人長，爰臂，其善射亦天性，雖子孫他人學者莫能及。廣吶口少言，與人居，則畫地為軍陳，射闊狹以飲。專以射為戲。將兵，乏絕處見水，士卒不盡飲，不近水；不盡餐，不嚐食；寬緩不苛，士以此愛樂為用。其射，見敵，非在數十步之內，度不中不發，發即應弦而倒。用此，其將數困辱，及射猛獸，亦數為所傷雲。

### 13. 管敢降敌与李陵兵败

[返回正文第13条](#event-13)

<a id="hs054-p020"></a>

**[《汉书·李广苏建传》P020](../../sources/摘录/汉书-卷054-李广苏建传.md#p020)** · [仓内TXT L7922—L7922](../../sources/本地分卷/汉书/汉书-卷054.md#L7922)

> 是時，陵軍益急，匈奴騎多，戰一日數十合，復傷殺虜二千餘人。虜不利，欲去，會陵軍候管敢為校尉所辱，亡降匈奴，具言「陵軍無後救，射矢且盡，獨將軍麾下及成安侯校各八百人為前行，以黃與白為幟，當使精騎射之即破矣。」成安侯者，穎川人，父韓千秋，故濟南相，奮擊南越戰死，武帝封子延年為侯，以校尉隨陵。單于得敢大喜，使騎並攻漢軍，疾呼曰：「李陵、韓延年趣降！」遂遮道急攻陵。陵居谷中，虜在山上，四面射，矢如雨下。漢軍南行，未至鞮汗山，一日五十萬矢皆盡，即棄車去。士尚三千餘人，徒斬車輻而持之，軍吏持尺刀，抵山入陿谷。單于遮其後，乘隅下壘石，士卒多死，不得行。昏後，陵便衣獨步出營，止左右：「毋隨我，丈夫一取單于耳！」良久，陵還，大息曰：「兵敗，死矣！」軍吏或曰：「將軍威震匈奴，天命不遂，後求道徑還歸，如浞野侯為虜所得，後亡還，天子客遇之，況於將軍乎！」陵曰：「公止！吾不死，非壯士也。」於是盡斬旌旗，及珍寶埋地中，陵歎曰：「復得數十矢，足以脫矣。今無兵復戰，天明坐受縛矣！各鳥獸散，猶有得脫歸報天子者。」令軍士人持二升糒，一半冰，期至遮虜鄣者相待。夜半時，擊鼓起士，鼓不鳴。陵與韓延年俱上馬，壯士從者十餘人。虜騎數千追之，韓延年戰死。陵曰：「無面目報陛下！」遂降。軍人分散，脫至塞者四百餘人。

> 武益愈，單于使使曉武。會論虞常，欲因此時降武。劍斬虞常已，律曰：「漢使張勝謀殺單于近臣，當死，單于募降者赦罪。」舉劍欲擊之，勝請降。律謂武曰：「副有罪，當相坐。」武曰：「本無謀，又非親屬，何謂相坐？」復舉劍擬之，武不動。律曰：「蘇君，律前負漢歸匈奴，幸蒙大恩，賜號稱王，擁眾數萬，馬畜彌山，富貴如此。蘇君今日降，明日復然。空以身膏草野，誰復知之！」武不應。律曰：「君因我降，與君為兄弟，今不聽吾計，後雖欲復見我，尚可得乎？」武罵律曰：「女為人臣子，不顧恩義，畔主背親，為降虜於蠻夷，何以女為見？且單于信女，使決人死生，不平心持正，反欲斗兩主，觀禍敗。南越殺漢使者，屠為九郡；宛王殺漢使者，頭縣北闕；朝鮮殺漢使者，即時誅滅。獨匈奴未耳。若知我不降明，欲令兩國相攻，匈奴之禍從我始矣。」

### 27. 李陵来劝，苏武拒降

[返回正文第27条](#event-27)

<a id="hs054-p036"></a>

**[《汉书·李广苏建传》P036](../../sources/摘录/汉书-卷054-李广苏建传.md#p036)** · [仓内TXT L7938—L7938](../../sources/本地分卷/汉书/汉书-卷054.md#L7938)

> 初，武與李陵俱為侍中，武使匈奴明年，陵降，不敢求武。久之，單于使陵至海上，為武置酒設樂，因謂武曰：「單于聞陵與子卿素厚，故使陵來說足下，虛心欲相待。終不得歸漢，空自苦亡人之地，信義安所見乎？前長君為奉車，從至雍棫陽宮，扶輦下除，觸柱折轅，劾大不敬，伏劍自刎，賜錢二百萬以葬。孺卿從祠河東后土，宦騎與黃門駙馬爭船，推墮駙馬河中溺死，宦騎亡，詔使孺卿逐捕不得，惶恐飲藥而死。來時，大夫人已不幸，陵送葬至陽陵。子卿婦年少，聞已更嫁矣。獨有女弟二人，兩女一男，今復十餘年，存亡不可知。人生如朝露，何久自苦如此！陵始降時，忽忽如狂，自痛負漢，加以老母系保宮，子卿不欲降，何以過陵？且陛下春秋高，法令亡常，大臣亡罪夷滅者數十家，安危不可知，子卿尚復誰為乎？願聽陵計，勿復有雲。」武曰：「武父子亡功德，皆為陛下所成就，位列將，爵通侯，兄弟親近，常願肝腦塗地。今得殺身自效，雖蒙斧鉞湯鑊，誠甘樂之。臣事君，猶子事父也。子為父死亡所恨。願勿復再言。」陵與武飲數日，復曰：「子卿壹聽陵言。」武曰：「自分已死久矣！王必欲降武，請畢今日之歡，效死於前！」陵見其至誠，喟然歎曰：「嗟乎，義士！陵與衛律之罪上通於天。」因泣下沾衿，與武決去。

### 29. 雁足传书为使者托辞、李陵送别

[返回正文第29条](#event-29)

<a id="hs054-p038"></a>

**[《汉书·李广苏建传》P038](../../sources/摘录/汉书-卷054-李广苏建传.md#p038)** · [仓内TXT L7940—L7940](../../sources/本地分卷/汉书/汉书-卷054.md#L7940)

> 昭帝即位數年，匈奴與漢和親。漢求武等，匈奴詭言武死。後漢使復至匈奴，常惠請其守者與俱，得夜見漢使。具自陳過。教使者謂單于，言天子射上林中，得鴈，足有係帛書，言武等在荒澤中。使者大喜，如惠語以讓單于。單于視左右而驚，謝漢使曰：「武等實在。」於是李陵置酒賀武曰：「今足下還歸，揚名於匈奴，功顯於漢室，雖古竹帛所載，丹青所畫，何以過子卿！陵雖駑怯，令漢且貰陵罪，全其老母，使得奮大辱之積志，庶幾乎曹柯之盟，此陵宿昔之所不忘也。收族陵家，為世大戮，陵尚復何顧乎？已矣！令子卿知吾心耳。異域之人，壹別長絕！」陵起舞，歌曰：「徑萬里兮度沙幕，為君將兮奮匈奴。路窮絕兮矢刃摧，士眾滅兮名已聵。老母已死，雖欲報恩將安歸！」陵泣下數行，因與武決。單于召會武官屬，前以降及物故，凡隨武還者九人。

### 33. 麒麟阁十一名臣

[返回正文第33条](#event-33)

<a id="hs054-p044"></a>

**[《汉书·李广苏建传》P044](../../sources/摘录/汉书-卷054-李广苏建传.md#p044)** · [仓内TXT L7946—L7946](../../sources/本地分卷/汉书/汉书-卷054.md#L7946)

> 甘露三年，單于始入朝。上思股肱之美，乃圖畫其人於麒麟閣，法其形貌，署其官爵、姓名。唯霍光不名，曰大司馬大將軍博陸侯姓霍氏，次曰衛將軍富平侯張安世，次曰車騎將軍龍額侯韓增，次曰後將軍營平侯趙充國，次曰丞相高平侯魏相，次曰丞相博陽侯丙吉，次曰御史大夫建平侯杜延年，次曰宗正陽城侯劉德，次曰少府梁丘賀，次曰太子太傅蕭望之，次曰典屬國蘇武。皆有功德，知名當世，是以表而揚之，明著中興輔佐，列於方叔、召虎、仲山甫焉。凡十一人，皆有傳。自丞相黃霸、廷尉於定國、大司農朱邑、京兆尹張敞、右扶風尹翁歸及儒者夏侯勝等，皆以善終，著名宣帝之世，然不得列於名臣之圖，以此知其選矣。

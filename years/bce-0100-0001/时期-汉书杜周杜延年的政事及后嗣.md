# 汉书杜周杜延年的政事及后嗣

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **杜周由南阳吏入廷尉府。** 杜周是南阳杜衍人，南阳太守义纵以他为亲信并荐给张汤。他做廷尉史，勘查边地逃亡，有很多人被论杀，奏合上意，与减宣相继任御史中丞。 [[1]](#note-1)


<a id="event-2"></a>

2. **杜周任廷尉按君意办狱。** 杜周外缓少言，内治酷刻，任廷尉后仿张汤而更善揣测君意：要治的人就推入罪，要释的人先羁留缓办、暗示其冤。有人问他为何不守成文法，他以律令本由先后君主制订而为己辩解。 [[2]](#note-2)


<a id="event-3"></a>

3. **诏狱扩大及牵连。** 杜周任廷尉时诏狱愈多，从二千石到远方郡吏被拘者多，新旧案件不断。大案牵及数百证人，囚人不认便拷讯，知将被捕者往往逃躲；一些案绵延十余年，诏狱牵涉数万，层层加上更多。 [[3]](#note-3)


<a id="event-4"></a>

4. **复起执金吾迁御史大夫。** 杜周中途免职，复任执金吾，追查桑弘羊、卫皇后族亲中的人，执法深刻；武帝认为肯尽力不徇私，升为御史大夫。 [[4]](#note-4)


<a id="event-5"></a>

5. **一家聚财与性情差异。** 杜周初为廷尉小史仅一马，任高官后家资亿万，两个儿子在黄河两边为二千石，父子多用酷法，惟幼子延年为人宽厚。 [[5]](#note-5)


<a id="event-6"></a>

6. **杜延年分传题签。** 以下叙杜周少子杜延年。 [[6]](#note-6)


<a id="event-7"></a>

7. **建议休养并审查吏民建议。** 因武帝用兵和奢费后民困、连年歉收，杜延年劝霍光仿文帝节俭宽和。霍光采纳而有举贤良及论榷酒盐铁。吏民条陈新政多交他复核，有可行见识的试任官，年满核验；他也同两府和廷尉处理案件。 [[7]](#note-7)


<a id="event-8"></a>

8. **掌政及赏赐。** 杜延年和厚通达，久掌政务，出则奉车驾，入则给事中。任九卿十余年，赐予和礼物很多，家资以千万计。 [[8]](#note-8)


<a id="event-9"></a>

9. **霍氏案后出守、复入御史和卒。** 霍氏败后延年以旧属并因苑马、奴婢供给问题免官削邑，旋任北地太守。初治绩不进获责，改用良吏、打击豪强后郡安，获赐并调西河。五凤中升御史大夫，刻意避父亲旧座。三年后病请退，帝赐金酒、医药及安车，数月后死，谥敬，子缓承爵。 [[9]](#note-9)


<a id="event-10"></a>

10. **杜缓分传题签。** 以下叙杜延年子杜缓。 [[10]](#note-10)


<a id="event-11"></a>

11. **杜缓从军、任太常与助赈。** 杜缓少为郎，本始时随蒲类将军出击匈奴，回任谏大夫等。父死被召视丧，后为太常。冬季报结刑狱时常停酒减食，属吏认为仁厚。元帝初粮贵流徙及永光间西羌反，他先后输送钱谷助国。 [[11]](#note-11)


<a id="event-12"></a>

12. **杜氏诸兄弟。** 杜缓六个弟弟有五人做大官，幼弟杜熊历任郡守、州牧与刺史而有能名，中弟杜钦官位未盛却最出名。 [[12]](#note-12)


<a id="event-13"></a>

13. **杜钦分传题签。** 以下叙杜缓弟杜钦。 [[13]](#note-13)


<a id="event-14"></a>

14. **两位杜子夏。** 杜钦字子夏，富家而一眼失明，少读经，不喜为吏。同姓同字的杜邺也以才著名。京师先以盲目区分二人，杜钦厌恶以疾受谤而戴小冠，俗称遂为小冠杜和大冠杜。 [[14]](#note-14)


<a id="event-15"></a>

15. **王凤用杜钦为武库令。** 成帝舅王凤以大将军辅政，找贤能作助手。王凤之父与杜缓交好，因此知道杜钦的才，奏用为大将军军府武库令，职事闲适。 [[15]](#note-15)


<a id="event-16"></a>

16. **选后宫时进九女之说。** 太后诏选民间女子，杜钦劝王凤限以古礼九女，重乡里品行与相夫之德而不取声色技艺。他借晋献公、申生为嫡庶相争之戒，将此事和皇嗣、寿考及世道相联。 [[16]](#note-16)


<a id="event-17"></a>

17. **再谏王凤及引疾退休。** 王凤转白太后，太后称没有旧例。杜钦再引《诗》《易》说行新礼应顺古便今，求贤淑可制纵情，王凤仍循旧例。碰到太后妹与杜钦侄私通被闻，杜钦惭惧，请退。 [[17]](#note-17)


<a id="event-18"></a>

18. **日食地震后上对。** 发生日食地震后合阳侯梁放荐杜钦直言。他以戊申日食、未央夜震比附后宫，认为嫡妾争宠可能不利于皇嗣，劝整后宫、抑奢游、勤政和奉养二宫；又说纵欲与谗佞即使无异象也会成为国患。 [[18]](#note-18)


<a id="event-19"></a>

19. **杜钦答白虎殿策。** 杜钦以天信地贞、生育万物说王者抚养，以仁义克己推己说六经，以孝说行本。取人应考家乡素行、任职功效、达穷富贫时的取舍；政急返质去奢伪。他仍从偏宠一人推到皇嗣不广、嫉妒纷起，请普施其德。 [[19]](#note-19)


<a id="event-20"></a>

20. **称病去职。** 杜钦因前事称病，领帛后退。后来为议郎，又因病免。 [[20]](#note-20)


<a id="event-21"></a>

21. **府中谋策与规戒王凤。** 王凤召杜钦入幕议政，杜钦常举王骏、韦安世、王延世等才，救解被责人员，并参与续绝抚边。见王凤权过重，以周公能谦惧、穰侯因权遭罢、田蚡恃宠失势劝他自抑。 [[21]](#note-21)


<a id="event-22"></a>

22. **王章劾王凤与王章狱死。** 再遇日食，京兆尹王章告王凤专权蔽主，成帝一度欲退王凤。杜钦建议王凤以辞职谢罪，太后悲泣，帝也不忍遣。杜钦再引周公和仲山甫劝受留，王凤复起。尚书随后奉命劾王章，王章死于诏狱。 [[22]](#note-22)


<a id="event-23"></a>

23. **劝继续求直谏以解流言。** 百姓为王章死鸣冤。杜钦说案情秘，人们会以为朝廷以进谏治罪，堵言路；劝王凤多举敢谏之士，让郎从官各尽其言、彰示不以言罪。王凤奏而施行。 [[23]](#note-23)


<a id="event-24"></a>

24. **杜钦寿终与杜业承侯。** 杜钦退居不仕，以寿终。同支多人至二千石。兄杜缓以列侯奉朝请而于成帝时死，子杜业接任。 [[24]](#note-24)


<a id="event-25"></a>

25. **杜业分传题签。** 以下叙杜缓子杜业。 [[25]](#note-25)


<a id="event-26"></a>

26. **杜业因淳于长案免官。** 杜业曾任太常，不附权贵，与翟方进、淳于长不合，后为函谷关都尉。淳于长先获罪就国，其舅红阳侯王立来书求关照；案件发展到下洛阳狱后信被搜得，有司以杜业听请不敬免遣还封国。 [[26]](#note-26)


<a id="event-27"></a>

27. **方进死后杜业上书。** 翟方进死而蒙厚葬，杜业指其昔与淳于长互荐却免牵连，对朱博、孙宏、陈咸等加罚不均；又举他与师丹推引人事、以巫求福的案情，称其专作威福、借公报私，劝帝戒之。这是杜业奏中指控。 [[27]](#note-27)


<a id="event-28"></a>

28. **议立恭王庙与再任免。** 杜业主张在京立恭王庙，董宏另请尊丁氏为帝太后而遭师丹等劾免，杜业申理。朱博后得再用，杜业也复太常，因选举失实由上党都尉位置被免还国。礼制建置另有本纪日期。 [[28]](#note-28)


<a id="event-29"></a>

29. **哀帝死后病卒。** 王莽秉政，前议立庙尊号者遭迁徙；杜业因已免官而免受此处置，忧惧发病死。他尚颍邑公主，家请合葬未准，谥荒，至孙绝。传末记杜氏自杜周徙茂陵，延年徙杜陵。 [[29]](#note-29)


<a id="event-30"></a>

30. **史家评议题签。** 以下是关于张汤、杜周及后人的合赞。 [[30]](#note-30)


<a id="event-31"></a>

31. **合评张杜功过与杜钦杜业。** 班固说张汤、杜周由文法小吏至三公而列酷吏，子孙多贤且爵位绵长，东汉建武间杜氏爵独绝。评杜钦深谋，尤早进女戒；杜业因势扬朱博而毁师丹，须留意奏议中的偏爱憎恶。 [[31]](#note-31)

### 16. 选后宫时进九女之说

<a id="hs060-p019"></a>

**[《汉书·杜周传》P019](../../拆分史书/汉书/卷060.md#p019)** · [仓内TXT L8218—L8218](../../拆分史书/汉书/卷060.md#part-1-L8218)

### 18. 日食地震后上对

[返回正文第18条](#event-18)

<a id="hs060-p021"></a>

**[《汉书·杜周传》P021](../../拆分史书/汉书/卷060.md#p021)** · [仓内TXT L8220—L8220](../../拆分史书/汉书/卷060.md#part-1-L8220)

> 後有日蝕、地震之變，詔舉賢良方正能直言士，合陽侯梁放舉欽。欽上對曰：「陛下畏天命，悼變異，延見公卿，舉直言之士，將以求天心，跡得失也。臣欽愚戇，經術淺薄，不足以奉大對。臣聞日蝕、地震，陽微陰盛也。臣者，君之陰也；子者，父之陰也；妻者，夫之陰也；夷狄者，中國之陰也。《春秋》日蝕三十六，地震五，或夷狄侵中國，或政權在臣下，或婦乘夫，或臣子背君父，事雖不同，其類一也。臣竊觀人事以考變異，則本朝大臣無不自安之人，外戚親屬無乖刺之心，關東諸侯無強大之國，三垂蠻夷無逆理之節；殆為後宮。何以言之？日以戊申蝕。時加未。戊未，土也。土者，中宮之部也。其夜地震未央宮殿中，此必適妾將有爭寵相害而為患者，唯陛下深戒之。變感以類相應，人事失於下，變象見於上。能應之以德，則異咎消亡；不能應之以善，則禍敗至。高宗遭雊雉之戒，飭己正事，享百年之壽，殷道復興，要在所以應之。應之非誠不立，非信不行。宋景公，小國之諸侯耳，有不忍移禍之誠，出人君之言三，熒惑為之退捨。以陛下聖明，內推至誠，深思天變，何應而不感？何搖而不動？孔子曰：『仁遠乎哉！』唯陛下正後妾，抑女寵，防奢泰，去佚游，躬節儉，親萬事，數御安車，由輦道，親二宮之饔膳，致晨昏之定省。如此，即堯、舜不足與比隆，咎異何足消滅？如不留聽於庶事，不論材而授位，殫天下之財以奉淫侈，匱萬姓之力以從耳目，近諂諛之人而遠公方，信讒賊之臣以誅忠良，賢俊失在巖穴，大臣怨於不以，雖無變異、社稷之憂也。天下至大，萬事至眾，祖業至重，誠不可以佚豫為，不可以奢泰持也。唯陛下忍無益之欲，以全眾庶之命。臣欽愚戇，言不足采。」

### 27. 方进死后杜业上书

[返回正文第27条](#event-27)

<a id="hs060-p031"></a>

**[《汉书·杜周传》P031](../../拆分史书/汉书/卷060.md#p031)** · [仓内TXT L8230—L8230](../../拆分史书/汉书/卷060.md#part-1-L8230)

> 其春，丞相方進薨，業上書言：「方進本與長深結厚，更相稱薦，長陷大惡，獨得不坐，苟慾障塞前過，不為陛下廣持平例，又無恐懼之心，反因時信其邪辟，報睚眥怨。故事，大逆朋友坐免官，無歸故郡者，今坐長者歸故郡，已深一等；紅陽侯立坐子受長貨賂故就國耳，非大逆也，而方進復奏立黨友後將軍朱博、巨鹿太守孫宏、故少府陳咸，皆免官，歸咸故郡。刑罰無平，在方進之筆端，眾庶莫不疑惑，皆言孫宏不與紅陽侯相愛。宏前為中丞時，方進為御史大夫，舉掾隆可侍御史，宏奉隆前奉使欺謾，不宜執法近侍，方進以此怨宏。又方進為京兆尹時，陳咸為少府，在九卿高弟，陛下所自知也。方進素與司直師丹相善，臨御史大夫缺，使丹奏咸為奸利，請案驗，卒不能有所得，而方進果自得御史大夫。為丞相，即時詆欺，奏免咸，復因紅陽侯事歸咸故郡。眾人皆言國家假方進權太甚。案師丹行能無異，及光祿勳許商被病殘人，皆但以附從方進，嘗獲尊官。丹前親薦邑子丞相史能使巫下神，為國求福，幾獲大利。幸賴陛下至明，遣使者毛莫如先考驗，卒得其奸，皆坐死。假令丹知而白之，此誣罔罪也；不知而白之，是背經術惑左道也：二者皆在大辟，重於朱博、孫宏、陳咸所坐。方進終不舉白，專作威福，阿黨所厚，排擠英俊，托公報私，橫厲無所畏忌，欲以熏轑天下。天下莫不望風而靡，自尚書近臣皆結舌杜口，骨肉親屬莫不股慄。威權泰盛而不忠信，非所以安國家也。今聞方進卒病死，不以尉示天下，反覆賞賜厚葬，唯陛下深思往事，以戒來今。」

> 業又言宜為恭王立廟京師，以章孝道。時，高昌侯董宏亦言宜尊帝母定陶王丁後為帝太后。大司空師丹等劾宏誤朝不道，坐免為庶人，業復上書訟宏。前後所言皆合指施行，朱博果見拔用。業由是征，復為太常。歲餘，左遷上黨都尉。會司隸奏業為太常選舉不實，業坐免官，復就國。

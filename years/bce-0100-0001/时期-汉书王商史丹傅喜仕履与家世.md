# 汉书王商史丹傅喜仕履与家世

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **王商家世与两支外戚侯爵。** 王商字子威。王无故、王武兄弟因是宣帝舅而封平昌侯、乐昌侯，这支王氏与阳平侯王凤家须分别辨认。 [[1]](#note-1)


<a id="event-2"></a>

2. **推财让弟与翼护太子。** 王商少任太子中庶子，袭父爵后把财产分给异母弟，又诚心居丧，获荐入近臣。元帝朝任右将军，在定陶王受宠、太子地位动摇时扶持太子。 [[2]](#note-2)


<a id="event-3"></a>

3. **拜相与接见单于。** 王商接替匡衡任丞相，另增封千户。单于入朝时在白虎殿见他，其高大威严使单于迟疑退后，成帝因而称许。 [[3]](#note-3)


<a id="event-4"></a>

4. **拟送女入宫以为援。** 太后先前有意选王商之女入后宫，王商以病推辞。被举劾后察觉是王凤所为，试图经李婕妤引见女儿，借此寻得内援。 [[4]](#note-4)


<a id="event-5"></a>

5. **史氏家世及史高辅元帝。** 史丹祖辈因史良娣生悼皇考而同宣帝关系密切。史恭三子各受封，史高举发霍禹而封乐陵侯，在宣帝临终前受命，辅元帝五年后去职。 [[5]](#note-5)


<a id="event-6"></a>

6. **奉诏护太子。** 史丹凭父任侍从太子十余年。元帝即位后任驸马都尉、侍中，受命照管太子家，当时帝宠傅昭仪与定陶王，王皇后失宠。 [[6]](#note-6)


<a id="event-7"></a>

7. **劝元帝勿以乐技判断储才。** 史丹用擅乐者未必可任宰相说明才具不在鼓乐。中山王去世，太子见帝时未哭；史丹称自己事先请太子不要刺激帝哀情，化解责难。底本含鼓字附近的异码和“皇太了”异文。 [[7]](#note-7)


<a id="event-8"></a>

8. **成帝擢用并封武阳侯。** 成帝继位后任史丹长乐卫尉，继迁将军并赐关内侯。鸿嘉元年诏以其昔日忠正辅导有功，封武阳侯，以东海郯的武强聚为国。 [[8]](#note-8)


<a id="event-9"></a>

9. **谨密与私生活及请退。** 史丹为人可亲而保密谨慎，独得父财又屡受厚赐，生活奢侈，姬妾众多。任将军前后十六年，病中请退，获准交还印绶并赐金、车马。 [[9]](#note-9)


<a id="event-10"></a>

10. **史丹卒与史氏诸支。** 史丹归家数月去世，谥顷侯，九子凭父任侍从。史氏有四支封侯，多至王莽时断绝，史曾一支无子而早绝。 [[10]](#note-10)


<a id="event-11"></a>

11. **傅喜谏傅太后与首次交将印。** 傅喜是定陶傅太后的从弟，哀帝继位后迁右将军。因多次阻谏傅太后预政未能接替王莽辅政，帝改用师丹，傅喜交将印以光禄大夫养病。 [[11]](#note-11)


<a id="event-12"></a>

12. **傅喜力议尊号而被遣就国。** 傅喜与孔光、师丹共同反对傅太后与成帝母并尊。师丹先免，傅喜随后被免大司马；太后又令其就国，哀帝未同意剥夺其侯爵。 [[12]](#note-12)


<a id="event-13"></a>

13. **以外戚比较三人行事。** 班固称王商刚毅而冤废，史丹善辅太子并以恳切之谏保住储位，傅喜守节而获追誉；也指出三王等外戚久贵而终至王莽倾覆汉室。 [[13]](#note-13)

### 7. 劝元帝勿以乐技判断储才

> 建昭之後，元帝被疾，不親政事，留好音樂。或置鼙鼓殿下，天子自臨軒檻上，隤銅丸以E74E鼓，聲中嚴鼓之節。後宮及左右習知音者莫能為，而定陶王亦能之，上數稱其材。丹進曰：「凡所謂材者，敏而好學，溫故知新，皇太了是也。若乃器人於絲竹鼓鼙之間，則是陳惠、李微高於匡衡，可相國也。」於是上嘿然而笑。其後，中山哀王薨，太子前吊。哀王者，帝之少弟，與太子遊學相長大。上望見太子，感念哀王，悲不能自止。太子既至前，不哀。上大恨曰：「安有人不慈仁而可奉宗廟為民父母者乎！」上以責謂丹。丹免冠謝上曰：「臣誠見陛下哀痛中山王，至以感損。向者太子當進見，臣竊戒屬毋涕泣，感傷陛下。罪乃在臣，當死。」上以為然，意乃解。丹之輔相，皆此類也。

### 12. 傅喜力议尊号而被遣就国

[返回正文第12条](#event-12)

<a id="hs082-p020"></a>

**[《汉书·王商史丹傅喜传》P020](../../拆分史书/汉书/卷082.md#p020)** · [仓内TXT L9221—L9221](../../拆分史书/汉书/卷082.md#part-1-L9221)

> 丁、傅驕奢，皆嫉喜之恭儉。又傅太后欲求稱尊號，與成帝母齊尊，喜與丞相孔光、大司空師丹共執正議。傅太后大怒，上不得已，先免師丹以感動喜，喜終不順。後數月，遂策免喜曰：「君輔政出入三年，未有昭然匡朕不逮，而本朝大臣遂其奸心，咎由君焉。其上大司馬印綬，就第。」傅太后又自詔丞相、御史曰：「高武侯喜無功而封，內懷不忠，附下罔上，與故大司空丹同心背畔，放命圮族，虧損德化，罪惡雖在赦前，不宜奉朝請，其遣就國。」後又欲奪喜侯，上亦不聽。

### 13. 以外戚比较三人行事

[返回正文第13条](#event-13)

<a id="hs082-p022"></a>

**[《汉书·王商史丹傅喜传》P022](../../拆分史书/汉书/卷082.md#p022)** · [仓内TXT L9223—L9223](../../拆分史书/汉书/卷082.md#part-1-L9223)

> 贊曰：自宜、元、成、哀外戚興者，許、史、三王、丁、傅之家，皆重侯累將，窮貴極富，見其位矣，未見其人也。陽平之王多有材能，好事慕名，其勢尤盛，曠貴最久。然至於莽，亦以覆國。王商有剛毅節，廢黜以憂死，非其罪也。史丹父子相繼，高以重厚，位至三公。丹之輔道副主，掩惡揚美，傅會善意，雖宿儒達士無以加焉。及其歷房闥，入臥內，推至誠，犯顏色，動寤萬乘，轉移大謀，卒成太子，安母后之位。「無言不讎」，終獲忠貞之報。傅喜守節不傾，亦蒙後凋之賞。哀、平際會，禍福速哉！

# 汉书班氏家世著述与全书叙目

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **班氏自叙远祖。** 班固将祖先追到楚令尹子文，并以虎乳子文、楚称虎为班解释姓氏，叙秦灭楚后迁晋代。 [[1]](#note-1)


<a id="event-2"></a>

2. **班壹在边地富起。** 秦末避楼烦，汉初禁令宽，凭牧畜兴家。惠帝、高后时为边郡富户，乡人据其名取字。 [[2]](#note-2)


<a id="event-3"></a>

3. **从班孺到班况。** 由任侠的班孺叙上谷守班长、长子令班回和历农都尉、骑校尉的班况。班况因女为婕妤而退休，曾徙昌陵，罢后另徙。 [[3]](#note-3)


<a id="event-4"></a>

4. **班伯受经与入侍。** 班伯从师丹学《诗》，王凤推荐后入近侍，与郑宽中、张禹、许商先后讲习经义，进封奉车都尉等职。 [[4]](#note-4)


<a id="event-5"></a>

5. **班伯出迎单于并守定襄。** 班伯求使北边，受节迎单于，又因当地豪姓杀吏，请试守定襄，朝廷命王舜代护单于并付班伯守印。 [[5]](#note-5)


<a id="event-6"></a>

6. **许后废及班婕妤退供养。** 许后被废，班婕妤往奉太后，李平进婕妤、赵氏立后。班伯称笃疾，后来皇帝临问才复视事。 [[6]](#note-6)


<a id="event-7"></a>

7. **画屏论酒色。** 班伯随成帝观画，借纣王妲己长夜宴饮和古书告戒劝君节制。前段叙张放等以微行宴游受宠。 [[7]](#note-7)


<a id="event-8"></a>

8. **太后劝远张放。** 太后见成帝憔悴，劝礼遇班伯而令张放就国。王音推动奏劾，张放外调后又还，太后再次进言；传又叙班伯后事。 [[8]](#note-8)


<a id="event-9"></a>

9. **班斿参与校书。** 班斿经师丹荐举入朝，与刘向校秘书，善于为帝进读并得到副本。史传以东平王求书被拒说明内府书不轻出。 [[9]](#note-9)


<a id="event-10"></a>

10. **班稚的近侍与外任。** 班稚作近侍时不私答定陶太子，哀帝即位后出任西河属国都尉，再为广平相。 [[10]](#note-10)


<a id="event-11"></a>

11. **班稚不报颂与王莽处置。** 王莽旧善班氏，执政后求各地报颂，班稚无所上。公孙闳报灾，甄丰遣吏弹劾，两人处置有异，班稚家事接叙。 [[11]](#note-11)


<a id="event-12"></a>

12. **班固评论成帝朝言路。** 传举王音、翟方进、王章、朱云等举劾敢言，借谷永评许、班与时人行事说明外家进退。 [[12]](#note-12)


<a id="event-13"></a>

13. **班彪与班嗣共学。** 班家有内府赐书，家资亦足，班彪自幼与班嗣游学，远近士人、扬雄等多来往。 [[13]](#note-13)


<a id="event-14"></a>

14. **班嗣论严君平。** 桓氏欲借书，班嗣回信称严君平重老氏、守自然，拒以仕禄和声名羁身，也说明学道与求取世利的分别。 [[14]](#note-14)


<a id="event-15"></a>

15. **班彪与隗嚣论时势。** 新末汉复兴时隗嚣据陇、公孙述据蜀。隗嚣问是否会再现战国格局，班彪反对，继以《王命论》申说。 [[15]](#note-15)


<a id="event-16"></a>

16. **以天命叙刘氏统绪。** 论援尧舜禅让与汤武，称刘氏接尧运，列祥异和顺民之说，这是班彪为汉室正统立论。 [[16]](#note-16)


<a id="event-17"></a>

17. **反对凭势窃居帝位。** 作者从贫者难改命类推出帝命不可妄据，举韩信、英布、项羽和王莽等终败反证。 [[17]](#note-17)


<a id="event-18"></a>

18. **陈婴、王陵两母知所归。** 陈婴之母劝勿自立而归附他人；王陵母判断项氏将败，坚令王陵事汉。作者借两故事示能审时。 [[18]](#note-18)


<a id="event-19"></a>

19. **汉高祖兴起的五端。** 列出身、相貌、征应、仁明、用人五项，又以张良、郦食其等例说明能听谏和授才。 [[19]](#note-19)


<a id="event-20"></a>

20. **以历代得失劝戒。** 作者要求据史事考运势，警告豪杰不可冒得君位，劝有识者顺势自保。 [[20]](#note-20)


<a id="event-21"></a>

21. **班彪离陇入河西。** 班彪见隗嚣不能受谏，避河西，获窦融延问荐举。后任徐令因病去，传总结他仕不为禄、述而不作的取向。 [[21]](#note-21)


<a id="event-22"></a>

22. **班固作《幽通赋》。** 班固早年丧父，作赋陈述命运和持志。 [[22]](#note-22)


<a id="event-23"></a>

23. **先祖高阳与世系。** 追叙远祖高阳与中世兴显，给自述家业发端。 [[23]](#note-23)


<a id="event-24"></a>

24. **北方兴起。** 写先人在北方迁徙立业，如蝉脱变而渐有声名。 [[24]](#note-24)


<a id="event-25"></a>

25. **数代后入京。** 以鸿鸟渐进为喻，叙后人在京师渐有班列。 [[25]](#note-25)


<a id="event-26"></a>

26. **王莽大乱与父辈受困。** 以巨人滔天比王莽乱政，写家中父辈遭患而仍有行事。 [[26]](#note-26)


<a id="event-27"></a>

27. **自保并留家法。** 父辈终保自身，留仪则与居处为后人所取。 [[27]](#note-27)


<a id="event-28"></a>

28. **前人德行可继。** 景仰前人德纯，盼无论穷达均能承继。 [[28]](#note-28)


<a id="event-29"></a>

29. **自叹年幼孤弱。** 孤而未明的作者恐家业失落，无人可依阶承接。 [[29]](#note-29)


<a id="event-30"></a>

30. **以家业为念。** 所担心的是世业能否传下，不把一己生死放在最前。 [[30]](#note-30)


<a id="event-31"></a>

31. **潜居长期思索。** 写退处沉思，岁月愈久而志虑愈深。 [[31]](#note-31)


<a id="event-32"></a>

32. **求立言无玷。** 不敢捡取党人言论，愿所立之言无玷污。 [[32]](#note-32)


<a id="event-33"></a>

33. **梦中与神意相感。** 孤魂求证，诚意在睡梦中引发神交意象。 [[33]](#note-33)


<a id="event-34"></a>

34. **梦登山遇隐者。** 登高远望，仿佛见幽居之人。 [[34]](#note-34)


<a id="event-35"></a>

35. **受葛藟与临谷告戒。** 梦者受蔓草，引视险谷，被告诫不要坠落。 [[35]](#note-35)


<a id="event-36"></a>

36. **醒来反思。** 拂晓而醒，思量梦兆，心中尚未明白。 [[36]](#note-36)


<a id="event-37"></a>

37. **以古遗谶自释。** 黄神远不可质问，只能参照遗言揣测其意义。 [[37]](#note-37)


<a id="event-38"></a>

38. **登高释作道可远通。** 将所遇理解为得以明察远途、自守而不迷。 [[38]](#note-38)


<a id="event-39"></a>

39. **葛蔓依木与《南风》。** 以藤木相附及南风之歌比安顺相助。 [[39]](#note-39)


<a id="event-40"></a>

40. **临深的戒意。** 梦中怕坠深谷，合《雅》里临深履薄的警惕。 [[40]](#note-40)


<a id="event-41"></a>

41. **吉象与警辞并下。** 神示有吉又另申戒，使受者须存敬慎。 [[41]](#note-41)


<a id="event-42"></a>

42. **把握不再来的时机。** 勉励及时奋进以合群，时日倏忽不可追回。 [[42]](#note-42)


<a id="event-43"></a>

43. **审察灵训，暂俟时机。** 作者接训后从容自持、踌躇待时。 [[43]](#note-43)


<a id="event-44"></a>

44. **天地长久而人生难处。** 天地无穷，众人所立于世者有限，转入历叙困境。 [[44]](#note-44)


<a id="event-45"></a>

45. **事多屯蹇、才不足。** 慨叹事势艰难反复，人的智慧难以全应。 [[45]](#note-45)


<a id="event-46"></a>

46. **圣者先悟而脱困。** 以能预悟、先图自拔为高处，众人难及。 [[46]](#note-46)


<a id="event-47"></a>

47. **卫叔辅兄反遭害。** 举卫国亲属相辅却反为所害，示祸从近处生。 [[47]](#note-47)


<a id="event-48"></a>

48. **管仲射敌而终得用。** 管仲曾射公子小白，后小白为君而任管仲，旧怨可变。 [[48]](#note-48)


<a id="event-49"></a>

49. **事势终始难测。** 正反际遇互相变易，不容易预知始终。 [[49]](#note-49)


<a id="event-50"></a>

50. **雍齿受封、丁公获戮。** 高祖先封曾怨的雍齿，反杀曾相助的丁公，借以论赏罚转折。 [[50]](#note-50)


<a id="event-51"></a>

51. **吉中有吊、戚处有庆。** 以两例说明吉凶可互生，不宜凭起初处境判断结局。 [[51]](#note-51)


<a id="event-52"></a>

52. **北叟识祸福倚伏。** 用塞上老翁式的思路概括祸福周转难料。 [[52]](#note-52)


<a id="event-53"></a>

53. **单豹、张毅各失一端。** 只养内或只治外都会受害，内外须兼顾。 [[53]](#note-53)


<a id="event-54"></a>

54. **中和也有不得志者。** 中和是理想，颜回、冉耕的遭际表明德行仍不能保证顺遂。 [[54]](#note-54)


<a id="event-55"></a>

55. **桀溺求孔门随己。** 用隐者招人从己并批评孔子，写处世主张的差异。 [[55]](#note-55)


<a id="event-56"></a>

56. **纵处世而仍有祸。** 说长久安于自身见解，也可能最终遭时祸。 [[56]](#note-56)


<a id="event-57"></a>

57. **游圣门亦未必免难。** 举子路一类身死之事，指出学于圣门仍可能遭难。 [[57]](#note-57)


<a id="event-58"></a>

58. **戒强梁而赖道免乱。** 刚强过甚可能致凶，须依正道行止，求免乱辱。 [[58]](#note-58)


<a id="event-59"></a>

59. **形气从根柢发。** 以根深而枝叶茂喻家德与个人行事相生。 [[59]](#note-59)


<a id="event-60"></a>

60. **庆余仍须谨慎。** 引罔两问影之意，担忧余庆并非可以坐待。 [[60]](#note-60)


<a id="event-61"></a>

61. **黎氏与芈姓兴盛。** 举黎氏于高辛、芈姓南方兴强的谱系掌故。 [[61]](#note-61)


<a id="event-62"></a>

62. **嬴、姜受命传世。** 以嬴、姜兴盛的传说与前段诸族并举，论古代天命。 [[62]](#note-62)


<a id="event-63"></a>

63. **仁与天道相应。** 以真实的仁德和天路通行作家世、时命诸例的小结。 [[63]](#note-63)


<a id="event-64"></a>

64. **桀纣失德与王者兴起。** 暴虐者杀仁人，与应时兴起的王者形成终局的比较。 [[64]](#note-64)


<a id="event-65"></a>

65. **妇人行义与孝名有异。** 举女子行烈反伤其孝名及伯者归处，继续写名实、吉凶难一。 [[65]](#note-65)


<a id="event-66"></a>

66. **回师与婚配的古例。** 借退军成全德性、醉行因缘成配，举结果与最初意向相反的故事。 [[66]](#note-66)


<a id="event-67"></a>

67. **龙漦历世至周乱。** 用龙漦自夏流传、终及周代的传说，写灾祸潜伏。 [[67]](#note-67)


<a id="event-68"></a>

68. **宣宫羽化与后灾。** 引另一妖异传说，以历多世才成灾写感应难测。 [[68]](#note-68)


<a id="event-69"></a>

69. **道长人世有限。** 叹道久远而一世短，难能尽见始末。 [[69]](#note-69)


<a id="event-70"></a>

70. **察物及卜问通幽。** 借观察物事与卜问以说明尝试穷究古今隐微。 [[70]](#note-70)


<a id="event-71"></a>

71. **以卜筮推世祀。** 举陈、周古代龟筮掌故，表示先人以卜论宗祀长短。 [[71]](#note-71)


<a id="event-72"></a>

72. **梦兆、铭谣与后世名谥。** 并举宣、曹及鲁、卫诸故事说明梦谣解释可系兴败声名。 [[72]](#note-72)


<a id="event-73"></a>

73. **听啼刻石与相理。** 以上古听啼知命和相占集理的故事连接道术讨论。 [[73]](#note-73)


<a id="event-74"></a>

74. **道同一原而术多流。** 大道本自然，术数诸说由同源分出。 [[74]](#note-74)


<a id="event-75"></a>

75. **心行与命有消长。** 神先察人心，命随行事变化，如消长消息。 [[75]](#note-75)


<a id="event-76"></a>

76. **遭遇盈缩不一。** 既有变化不遂，也就有处境与成果的赢缩。 [[76]](#note-76)


<a id="event-77"></a>

77. **本体守一与外在盈亏。** 以同体而外在移盈比喻迁变之中仍有可循常理。 [[77]](#note-77)


<a id="event-78"></a>

78. **众变令人疑惑。** 诸现象纷错，众人往往惑于繁多占兆。 [[78]](#note-78)


<a id="event-79"></a>

79. **相比周、贾论齐生死祸福。** 指庄周、贾谊一类以文齐同祸福死生，写其理论意处。 [[79]](#note-79)


<a id="event-80"></a>

80. **辨旷达之辞与身有所畏。** 作者说高言可矫常情，行为中仍有畏惧和顾忌。 [[80]](#note-80)


<a id="event-81"></a>

81. **守圣人论断。** 以顺天性与决行之义为准，作为面对诸说的尺度。 [[81]](#note-81)


<a id="event-82"></a>

82. **欲恶以义裁。** 欲望有所节制，恶感有所取舍，仍以应行之义为准。 [[82]](#note-82)


<a id="event-83"></a>

83. **守孔子约道。** 固守孔门的规范，德行轻简而不受外累。 [[83]](#note-83)


<a id="event-84"></a>

84. **不同的仁行同归。** 三仁行迹不同、夷惠进退有别，仍可同被称为仁贤。 [[84]](#note-84)


<a id="event-85"></a>

85. **段干木与申包胥。** 一个退居而保魏，一个奔走以存楚，各依处境行义。 [[85]](#note-85)


<a id="event-86"></a>

86. **纪信与四皓。** 纪信用身护汉王，四皓退养其志；救主和隐居都有所守。 [[86]](#note-86)


<a id="event-87"></a>

87. **草木各异而有实皆荣。** 用植物类别不同却皆可有实，譬喻君子各循合宜道路。 [[87]](#note-87)


<a id="event-88"></a>

88. **身死而志不朽。** 以先民的准则申说，身尽后其德义还可传下。 [[88]](#note-88)


<a id="event-89"></a>

89. **天道助诚信。** 仰观天网广覆，认为天助诚信、循道者。 [[89]](#note-89)


<a id="event-90"></a>

90. **先圣大谋受德信相助。** 把古圣事业与亲德信相援联系，承接上句。 [[90]](#note-90)


<a id="event-91"></a>

91. **韶乐、凤舞与孔子忘味。** 舜韶之德感动凤凰，孔子闻之久忘肉味，以写音乐通古今。 [[91]](#note-91)


<a id="event-92"></a>

92. **素王作经与汉承祚。** 以孔子著经获麟与汉承受旧文相连，是赋的符应解释。 [[92]](#note-92)


<a id="event-93"></a>

93. **精诚可感事物。** 认为精神通微而能感物，借下两例阐发。 [[93]](#note-93)


<a id="event-94"></a>

94. **射手发弓的异事。** 养由基、李广的故事象征技艺高度集中时能有超常效果。 [[94]](#note-94)


<a id="event-95"></a>

95. **以精诚与实说明感应。** 反问无诚无实如何能通或使人信。 [[95]](#note-95)


<a id="event-96"></a>

96. **由末技推论道真。** 连细小技艺都需真诚，进德守道更应专一。 [[96]](#note-96)


<a id="event-97"></a>

97. **随孔门先贤往来。** 以登降和群龙比喻参先贤的规范与道路。 [[97]](#note-97)


<a id="event-98"></a>

98. **从自省到践行。** 朝夕考察变化，专意于道而渐忘自身形体。 [[98]](#note-98)


<a id="event-99"></a>

99. **向后世哲人表志。** 愿以前人长寿之意等待后哲，向后来人通述此心。 [[99]](#note-99)


<a id="event-100"></a>

100. **《幽通赋》乱辞。** 总论性命、道义、身名与牺牲，愿理解天道并守住应持的原则。 [[100]](#note-100)


<a id="event-101"></a>

101. **校秘书与《答宾戏》。** 永平中班固校秘书，有人讥无事功，于是沿东方朔、扬雄设问答体回应，论君子守道。 [[101]](#note-101)


<a id="event-102"></a>

102. **宾诘立德立功。** 宾以圣贤奔走治世和学士及时立功问主人，质疑只著书不谋进身。 [[102]](#note-102)


<a id="event-103"></a>

103. **主人辨权势与德业。** 主人认为客只见势利，举战国游说、商鞅李斯的遭际说明一时显达不能等于守正。 [[103]](#note-103)


<a id="event-104"></a>

### 102. 宾诘立德立功

[返回正文第102条](#event-102)

<a id="hs100-p102"></a>

**[《汉书·叙传》P102](../../sources/摘录/汉书-卷100-叙传.md#p102)** · [仓内TXT L10678—L10678](../../sources/本地分卷/汉书/汉书-卷100.md#L10678)

> 賓戲主人曰：「蓋聞聖人有壹定之論，列士有不易之分，亦云名而已矣。故太上有立德，其次有立功。夫德不得後身而特盛，功不得背時而獨章，是以聖喆之治，棲棲皇皇，孔席不煗，墨突不黔。由此言之，取舍者昔人之上務，著作者前列之餘事耳。今吾子幸游帝王之世，躬帶冕之服，浮英華，湛道德，矕龍虎之文，舊矣。卒不能攄首尾，奮翼鱗，振拔洿塗，跨騰風雲，使見之者景駭，聞之者嚮震。徒樂枕經籍書，紆體衡門，上無所蔕，下無所根。獨攄意虖宇宙之外，銳思於豪芒之內，潛神默記，恆以年歲。然而器不賈於當己，用不效於一世，雖馳辯如濤波，摛藻如春華，猶無益於殿最。意者，且運朝夕之策，定合會之計，使存有顯號，亡有美諡，不亦優虖？」

### 103. 主人辨权势与德业

<a id="hs100-p103"></a>

**[《汉书·叙传》P103](../../sources/摘录/汉书-卷100-叙传.md#p103)** · [仓内TXT L10679—L10679](../../sources/本地分卷/汉书/汉书-卷100.md#L10679)

> 主人逌爾而咲曰：「若賓之言，斯所謂見勢利之華，闇道德之實，守穾奧之熒燭，未卬天庭而睹白日也。曩者王塗蕪穢，周失其御，侯伯方軌，戰國橫騖，於是七雄虓闞，分裂諸夏，龍戰而虎爭。游說之徒，風颺電激，並起而救之，其餘猋飛景附，煜霅其間者，蓋不可勝載。當此之時，搦朽摩鈍，鈆刀皆能壹斷，是故魯連飛一矢而蹶千金，虞卿以顧眄而捐相印也。夫啾發投曲，感耳之聲，合之律度，淫䵷而不可聽者，非韶、夏之樂也；因勢合變，偶時之會，風移俗易，乖忤而不可通者，非君子之法也。及至從人合之，衡人散之，亡命漂說，羇旅騁辭，商鞅挾三術以鑽孝公，李斯奮時務而要始皇，彼皆躡風雲之會，履顛沛之勢，據徼乘邪以求一日之富貴，朝為榮華，夕而焦瘁，福不盈眥，禍益於世，凶人且以自悔，況吉士而是賴虖！且功不可以虛成，名不可以偽立，韓設辯以徼君，呂行詐以賈國。說難既酋，其身乃囚；秦貨既貴，厥宗亦隧。是故仲尼抗浮雲之志，孟軻養浩然之氣，彼豈樂為迂闊哉？道不可以貳也。方今大漢洒埽群穢，夷險芟荒，廓帝紘，恢皇綱，基隆於羲、農，規廣於黃、唐；其君天下也，炎之如日，威之如神，函之如海，養之如春。是以六合之內，莫不同原共流，沐浴玄德，稟卬太和，枝附葉著，譬猶屮木之殖山林，鳥魚之毓川澤，得氣者蕃滋，失時者苓落，參天墬而施化，豈云人事之厚薄哉？今子處皇世而論戰國，耀所聞而疑所覿，欲從旄敦而度高虖泰山，懷氿濫而測深虖重淵，亦未至也。」

### 105. 以贤古著书释立业

[返回正文第105条](#event-105)

<a id="hs100-p105"></a>

**[《汉书·叙传》P105](../../sources/摘录/汉书-卷100-叙传.md#p105)** · [仓内TXT L10681—L10681](../../sources/本地分卷/汉书/汉书-卷100.md#L10681)

> 主人曰：「何為其然也！昔咎繇謨虞，箕子訪周，言通帝王，謀合聖神；殷說夢發於傅巖，周望兆動於渭濱，齊甯激聲於康衢，漢良受書於邳沂，皆俟命而神交，匪詞言之所信，故能建必然之策，展無窮之勳也。近者陸子優繇，新語以興；董生下帷，發藻儒林；劉向司籍，辯章舊聞；揚雄覃思，法言、大玄：皆及時君之門闈，究先聖之壼奧，婆娑虖術藝之場，休息虖篇籍之囿，以全其質而發其文，用納虖聖聽，列炳於後人，斯非其亞與！若乃夷抗行於首陽，惠降志於辱仕，顏耽樂於簞瓢，孔終篇於西狩，聲盈塞於天淵，真吾徒之師表也。且吾聞之：壹陰壹陽，天墬之方；乃文乃質，王道之綱；有同有異，聖喆之常。故曰：慎修所志，守爾天符，委命共己，味道之腴，神之聽之，名其舍諸！賓又不聞龢氏之璧韞於荊石，隨侯之珠藏於蜯蛤虖？歷世莫眡，不知其將含景耀，吐英精，曠千載而流夜光也。應龍潛於潢汙，魚黿媟之，不睹其能奮靈德，合風雲，超忽荒，而躆顥蒼也。故夫泥蟠而天飛者，應龍之神也；先賤而後貴者，龢、隨之珍也；時闇而久章者，君子之真也。若乃牙、曠清耳於管絃，離婁眇目於豪分；逢蒙絕技於弧矢，班輸榷巧於斧斤；良樂軼能於相馭，烏獲抗力於千鈞；龢、鵲發精於鍼石，研、桑心計於無垠。僕亦不任廁技於彼列，故密爾自娛於斯文。」

# 汉书盖宽饶与诸臣未确年奏议

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **盖宽饶早仕与劾张彭祖。** 盖宽饶以明经历察举、对策升谏大夫，代理郎中户将事。他指张彭祖未下殿门并牵劾张安世无补政事；彭祖实际已经下门，盖宽饶因奏劾失实被贬卫司马。 [[1]](#note-1)


<a id="event-2"></a>

2. **按旧令厘卫官职掌。** 旧行卫司马拜谒卫尉、为卫官役使购置市物。宽饶按令纠正礼节，私使时正式上谒；尚书因此责问卫尉，日后候、司马不再受卫官私役，出行按规定上奏。 [[2]](#note-2)


<a id="event-3"></a>

3. **爱护卫卒，擢任司隶。** 宽饶整服巡看卫卒寝食，问病给药。轮换卫士时群卒愿多留一年报恩，宣帝命他巡察风俗，褒贬得当，擢司隶校尉。他无所回避地劾察，廷尉采纳约半，京师贵戚及入朝吏员都因而慎法。 [[3]](#note-3)


<a id="event-4"></a>

4. **许伯宴与檀长卿失仪。** 平恩侯许伯迁居设宴，宽饶后至，遭魏相讥笑。他不悦檀长卿作猕猴斗犬之舞，告诫许伯富贵难保，出而劾檀失礼。宣帝意欲处罚，许伯代为谢罪才得解。 [[4]](#note-4)


<a id="event-5"></a>

5. **盖宽饶守节与王生致书。** 宽饶俸入分给助听察者，身居司隶而儿子步行戍边；同时失于深刻，又好讥政，致多怨同列后进者反得升进。王生承认其廉直，劝顺时守职，免遭文吏罗织，以蘧伯玉全身、伍子胥遇祸为比，盖宽饶不听。 [[5]](#note-5)


<a id="event-6"></a>

6. **诸葛丰分目。** 下文转叙诸葛丰。 [[6]](#note-6)


<a id="event-7"></a>

7. **由贡禹荐为御史。** 诸葛丰经学出身，名声刚特。贡禹任御史大夫时荐为侍御史，后元帝擢司隶校尉，加光禄大夫秩，京师有久未相见、今逢诸葛之俗语。 [[7]](#note-7)


<a id="event-8"></a>

8. **诸葛丰谢恩并请召对。** 诸葛丰恐未报擢用之恩，愿诛奸而就刑，指群臣苟合私党、天变和百姓困乏相应，转述尚书令堯奉诏告诫司隶须守中依法，不得独专褒贬，并请单独召见，帝不许。 [[8]](#note-8)


<a id="event-9"></a>

9. **再劝勿绝忠言。** 诸葛丰引伯奇、伍子胥、鲁隐公、叔武遭害和屈原受抑，表示愿为国捐身，惟恐自己未有助益先被排挤，从而阻忠臣智士说话。 [[9]](#note-9)


<a id="event-10"></a>

10. **刘辅分目。** 下文转叙河间宗室刘辅。 [[10]](#note-10)


<a id="event-11"></a>

11. **刘辅移狱减死。** 成帝将刘辅转系共工狱，减死一等，论为鬼薪，后终于家。 [[11]](#note-11)


<a id="event-12"></a>

12. **郑崇分目。** 下文转叙郑崇。 [[12]](#note-12)


<a id="event-13"></a>

13. **郑崇掌尚书与履声。** 郑崇祖出高密、徙平陵，其父为熟悉法令的正直御史。弟郑立与傅喜同学友善，傅喜任大司马时荐崇，哀帝擢尚书仆射，初多纳其谏，曾笑说听得出其拖履声。 [[13]](#note-13)


<a id="event-14"></a>

14. **孙宝分目。** 下文转叙孙宝。 [[14]](#note-14)


<a id="event-15"></a>

15. **拒往教张忠子与受荐。** 张忠征孙宝为属，想令教子，备舍储具，孙宝自免，后仍被留任主簿。他说学生理当来学，经道不可屈，官职可依公议，不可借此自高。张忠惭而荐其明经质直，孙宝为议郎、谏大夫。 [[15]](#note-15)


<a id="event-16"></a>

16. **广汉招抚与坐免复起。** 鸿嘉中广汉盗乱，刺史孙宝亲入山谷，招抚并遣回非首谋者。他自劾矫制，并指扈商失职酿乱；扈商反告他纵放本当治罪首率。孙宝因失死罪免，州人陈功，朝廷复用他为冀州刺史，继任丞相司直。 [[16]](#note-16)


<a id="event-17"></a>

17. **查王立请售田地。** 王立借南郡太守李尚取得并开垦草田，内有百姓租用的少府陂泽，却欲高价卖归官府。孙宝派吏查劾，李尚死狱。王立未坐罪，兄王商死后成帝没有依次用他，选弟王根掌兵。 [[17]](#note-17)


<a id="event-18"></a>

18. **再任西州绥辑。** 益州有边地违法动荡，朝廷以孙宝熟悉西州，任广汉太守，增秩并赐金。边地安定，吏民称许。 [[18]](#note-18)


<a id="event-19"></a>

19. **侯文视杜稚季为大害。** 孙宝礼请旧吏侯文任掾，立秋任东部督邮。侯文欲先治与淳于长等交厚的大侠杜稚季，孙宝为请托所困。侯文劝勿放虎办狐，杜闻风闭门改行；次年病死。淳于长获罪后孙宝及萧育等免官，侯文辞吏，末记杜氏子弟。 [[19]](#note-19)


<a id="event-20"></a>

20. **毌将隆分目。** 下文转叙毌将隆。 [[20]](#note-20)


<a id="event-21"></a>

21. **由王音荐进与议储。** 王音内领尚书、外典兵马，奏引毌将隆为从事中郎。成帝末隆建议使定陶王留京邸，后来定陶王立太子，其余官历包括冀州牧、颍川守；哀帝时由京兆尹进执金吾。 [[21]](#note-21)


<a id="event-22"></a>

22. **请为官婢正价被降。** 傅太后低价向诸京官购买官婢，毌将隆请重定价。哀帝责其为价格和永信宫争议而伤礼，兼因他早有安国之言，降为沛郡都尉，后迁南郡太守。 [[22]](#note-22)


<a id="event-23"></a>

23. **何并分目。** 下文转叙何并。 [[23]](#note-23)


<a id="event-24"></a>

24. **何并入仕治长陵。** 何并祖父因官自平舆徙平陵。何并由郡吏为大司空何武掾，何武称许其节行和治繁难之能，推荐任长陵令。 [[24]](#note-24)


<a id="event-25"></a>

25. **追王林卿与处置假扮奴客。** 故侍中王林卿以外戚结侠，何并知道其曾杀人，先促其离长陵。林卿命奴砍县鼓，何并追击，明知擒到的是强作林卿打扮的奴，仍借其说法处死，悬首及鼓示众。王林卿亡命，太后请问，哀帝嘉何并而任陇西太守。 [[25]](#note-25)


<a id="event-26"></a>

26. **颍川治豪猾与清俭遗命。** 何并代宽柔的严诩治颍川，钟元请减贪赃弟钟威之罪，何并拒绝，分任文武吏审捕钟威、赵季、李款，三人被杀并悬首案于市。传记颍川称治，清廉不许妻子居官舍；临终令薄葬不受法赙，王莽用其子恢，建武间用其孙。 [[26]](#note-26)


<a id="event-27"></a>

27. **班固评七人守直得失。** 班固称盖宽饶正色司察，叹未纳王生劝告；诸葛丰、刘辅、郑崇虽被讥狂，仍见其别有志节。又指毌将隆在冀州、孙宝对定陵不能尽节，而何并的操守近尹翁归。 [[27]](#note-27)

### 4. 许伯宴与檀长卿失仪

<a id="hs077-p004"></a>

**[《汉书·盖诸葛刘郑孙毋将何传》P004](../../拆分史书/汉书/卷077.md#p004)** · [仓内TXT L9016—L9016](../../拆分史书/汉书/卷077.md#part-1-L9016)

> 平恩侯許伯入第，丞相、御史、將軍、中二千石皆賀，寬饒不行。許伯請之，乃往，從西階上，東鄉特坐。許伯自酌曰：「蓋君後至。」寬饒曰：「無多酌我，我乃酒狂。」丞相魏侯笑曰：「次公醒而狂，何必酒也？」坐者皆屬目卑下之。酒酣樂作，長信少府檀長卿起舞，為沐猴與狗鬥，坐皆大笑。寬饒不說，卬視屋而歎曰：「美哉！然富貴無常，忽則易人，此如傳舍，所閱多矣。唯謹慎為得久，君侯可不戒哉！」因起趨出，劾奏長信少府以列卿而沐猴舞，失禮不敬。上欲罪少府，許伯為謝，良久，上乃解。

### 5. 盖宽饶守节与王生致书

[返回正文第5条](#event-5)

<a id="hs077-p005"></a>

**[《汉书·盖诸葛刘郑孙毋将何传》P005](../../拆分史书/汉书/卷077.md#p005)** · [仓内TXT L9017—L9017](../../拆分史书/汉书/卷077.md#part-1-L9017)

> 寬饒為人剛直高節，志在奉公。家貧，奉錢月數千，半以給吏民為耳目言事者。身為司隸，子常步行自戍北邊，公廉如此。然深刻喜陷害人，在位及貴戚人與為怨，又好言事刺譏，奸犯上意。上以其儒者，優容之，然亦不得遷。同列後進或至九卿，寬饒自以行清能高，有益於國，而為凡庸所越，愈失意不快，數上疏諫爭。太子庶子王生高寬饒節，而非其如此，予書曰：「明主知君絜白公正，不畏彊禦，故命君以司察之位，擅君以奉使之權，尊官厚祿已施於君矣。君宜夙夜惟思當世之務，奉法宣化，憂勞天下，雖日有益，月有功，猶未足以稱職而報恩也。自古之治，三王之術各有制度。今君不務循職而已，乃欲以太古久遠之事匡拂天子，數進不用難聽之語以摩切左右，非所以揚令名全壽命者也。方今用事之人皆明習法令，言足以飾君之辭，文足以成君之過，君不惟蘧氏之高蹤，而慕子胥之末行，用不訾之軀，臨不測之險，竊為君痛之。夫君子直而不挺，曲而不詘。大雅云：『既明且哲，以保其身。』狂夫之言，聖人擇焉。唯裁省覽。」寬饒不納其言。

### 8. 诸葛丰谢恩并请召对

<a id="hs077-p010"></a>

**[《汉书·盖诸葛刘郑孙毋将何传》P010](../../拆分史书/汉书/卷077.md#p010)** · [仓内TXT L9022—L9022](../../拆分史书/汉书/卷077.md#part-1-L9022)

> 豐上書謝曰：「臣豐駑怯，文不足以勸善，武不足以執邪。陛下不量臣能否，拜為司隸校尉，未有以自效，復秩臣為光祿大夫，官尊責重，非臣所當處也。又迫年歲衰暮，常恐卒填溝渠，德無以報厚，使論議士譏臣無補，長獲素餐之名。故常願捐一旦之命，不待時而斷姦臣之首，縣於都市，編書其罪，使四方明知為惡之罰，然後卻就斧鉞之誅，誠臣所甘心也。夫以布衣之士，尚猶有刎頸之交，今以四海之大，曾無伏節死誼之臣，率盡苟合取容，阿黨相為，念私門之利，忘國家之政。邪穢濁溷之氣上感于天，是以災變數見，百姓困乏。此臣下不忠之效也，臣誠恥之亡已。凡人情莫不欲安存而惡危亡，然忠臣直士不避患害者，誠為君也。今陛下天覆地載，物無不容，使尚書令堯賜臣豐書曰：『夫司隸者刺舉不法，善善惡惡，非得顓之也。免處中和，順經術意。』恩深德厚，臣豐頓首幸甚。臣竊不勝憤懣，願賜清宴，唯陛下裁幸。」上不許。

### 19. 侯文视杜稚季为大害

[返回正文第19条](#event-19)

<a id="hs077-p026"></a>

**[《汉书·盖诸葛刘郑孙毋将何传》P026](../../拆分史书/汉书/卷077.md#p026)** · [仓内TXT L9038—L9038](../../拆分史书/汉书/卷077.md#part-1-L9038)

> 徵為京兆尹。故吏侯文以剛直不苟合常稱疾不肯仕，寶以恩禮請文，欲為布衣友，日設酒食，妻子相對。文求受署為掾，進見如賓禮。數月，以立秋日署文東部督郵。入見，敕曰：「今日鷹隼始擊，當順天氣取姦惡，以成嚴霜之誅，掾部渠有其人乎？」文卬曰：「無其人不敢空受職。」寶曰：「誰也？」文曰：「霸陵杜稚季。」寶曰：「其次。」文曰：「豺狼橫道，不宜復問狐狸。」寶默然。稚季者大俠，與衛尉淳于長、大鴻臚蕭育等皆厚善。寶前失車騎將軍，與紅陽侯有卻，自恐見危，時淳于長方貴幸，友寶，寶亦欲附之，始視事而長以稚季託寶，故寶窮，無以復應文。文怪寶氣索，知其有故，因曰：「明府素著威名，今不敢取稚季，當且闔閤，勿有所問。如此竟歲，吏民未敢誣明府也。即度稚季而譴它事，眾口讙譁，終身自墮。」寶曰：「受教。」稚季耳目長，聞知之，杜門不通水火，穿舍後牆為小戶，但持鉏自治園，因文所厚自陳如此。文曰：「我與稚季幸同土壤，素無睚眥，顧受將命，分當相直。誠能自改，嚴將不治前事，即不更心，但更門戶，適趣禍耳。」稚季遂不敢犯法，寶亦竟歲無所譴。明年，稚季病死。寶為京兆尹三歲，京師稱之。會淳于長敗，寶與蕭育等皆坐免官。文復去吏，死於家。稚季子杜蒼，字君敖，名出稚季右，在游俠中。

### 25. 追王林卿与处置假扮奴客

[返回正文第25条](#event-25)

<a id="hs077-p038"></a>

**[《汉书·盖诸葛刘郑孙毋将何传》P038](../../拆分史书/汉书/卷077.md#p038)** · [仓内TXT L9050—L9050](../../拆分史书/汉书/卷077.md#part-1-L9050)

> 初，邛成太后外家王氏貴，而侍中王林卿通輕俠，傾京師。後坐法免，賓客愈盛，歸長陵上冢，因留飲連日。並恐其犯法，自造門上謁，謂林卿曰：「冢間單外，君宜以時歸。」林卿曰：「諾。」先是林卿殺婢婿埋冢舍，並具知之，以非己時，又見其新免，故不發舉，欲無令留界中而已，即且遣吏奉謁傳送。林卿素驕，慚於賓客，並度其為變，儲兵馬以待之。林卿既去，北度涇橋，令騎奴還至寺門，拔刀剝其建鼓。並自從吏兵追林卿。行數十里，林卿迫窘，乃令奴冠其冠被其襜褕自代，乘車從童騎，身變服從間徑馳去。會日暮追及，收縛冠奴，奴曰：「我非侍中，奴耳。」並心自知已失林卿，乃曰：「王君困，自稱奴，得脫死邪？」叱吏斷頭持還，縣所剝鼓置都亭下，署曰：「故侍中王林卿坐殺人埋冢舍，使奴剝寺門鼓。」吏民驚駭。林卿因亡命，眾庶讙譁，以為實死。成帝太后以邛成太后愛林卿故，聞之涕泣，為言哀帝。哀帝問狀而善之，遷並隴西太守。

### 26. 颍川治豪猾与清俭遗命

[返回正文第26条](#event-26)

# 汉书眭弘两夏侯京房翼奉李寻与灾异奏议

<a id="event-1"></a>

1. **眭弘由少年任侠转治《春秋》。** 眭弘字孟，鲁国蕃人，早年好侠、斗鸡走马，成年改志，从嬴公受《春秋》，以明经为议郎直至符节令。 [[1]](#note-1)


<a id="event-2"></a>

2. **夏侯始昌传分目。** 以下转叙武帝时的夏侯始昌。 [[2]](#note-2)


<a id="event-3"></a>

3. **夏侯始昌通五经并傅昌邑王。** 始昌鲁人，以齐诗、尚书教授。董仲舒、韩婴死后得到武帝重用。传称他预言柏梁台火日，后来应验；又为武帝所爱少子昌邑王之太傅，终以寿考。族子夏侯胜也用儒学出名。 [[3]](#note-3)


<a id="event-4"></a>

4. **夏侯胜传分目。** 以下叙夏侯胜，并联系族人夏侯建。 [[4]](#note-4)


<a id="event-5"></a>

5. **夏侯胜治《尚书》，从废立到授太后经。** 鲁恭王分宁乡封子节侯，大河后改东平，故胜籍东平。少孤从始昌学《尚书》洪范、复问多师，善礼服。昭帝死刘贺入继，胜用久阴不雨谏其出游，被绑交吏；霍光以为张安世泄了废王密谋，召问方知为经术推衍。后刘贺被废，胜奉命授太后《尚书》，为长信少府，赐关内侯益千户。 [[5]](#note-5)


<a id="event-6"></a>

6. **狱中传经。** 黄霸求在狱中受经，夏侯胜以将死辞，黄霸引朝闻道夕死可矣，胜敬其志而教。经过两个冬天仍不废讨论。 [[6]](#note-6)


<a id="event-7"></a>

7. **宣帝悦夏侯胜真率。** 夏侯胜质朴，仪度简略，或称宣帝为“君”、当面误称同僚之字。曾转述帝语，被责后以先王善言应供人诵传自解；重大朝议帝反请他不因从前获罪而失于直言。 [[7]](#note-7)


<a id="event-8"></a>

8. **受诏作经说，卒赐地与厚葬。** 再为长信少府、太子太傅，受诏撰《尚书》《论语》说，得金。九十岁卒于官，赐葬平陵；皇太后给钱二百万、素服五日，儒者视为师恩受礼。传未明卒年。 [[8]](#note-8)


<a id="event-9"></a>

9. **勉诸生明经取青紫。** 他劝诸生求通经术，经术精明则取显官如俯拾地芥，不明经不如归耕。 [[9]](#note-9)


<a id="event-10"></a>

10. **大小夏侯学与各自家传。** 夏侯建随族长胜和欧阳高等学，旁采各种章句，编次精细；胜责其破碎大道，建谓胜粗略难应变。建成一家，历议郎、博士、太子少傅；传并列胜、建族裔多任郡守、九卿、宫官。 [[10]](#note-10)


<a id="event-11"></a>

11. **京房传分目。** 以下叙治易、律吕与灾变之学的京房。 [[11]](#note-11)


<a id="event-12"></a>

12. **京房随焦延寿学易并举孝廉。** 京房字君明，东郡顿丘人。焦延寿字赣，梁王资助其学，举为小黄令，预知奸邪、爱民，民请留任而加秩，卒于任。他以六十四卦轮值候风雨寒暖，说京房将因得术亡身。京房精律知音，初元四年举孝廉为郎。 [[12]](#note-12)


<a id="event-13"></a>

13. **张博和京房草奏，石显以非谤告发。** 张博从京房学并嫁女，听他讲朝议，欲让外甥淮阳王刘钦入朝支持考课；京房还提出换丞相及中书令，代作求朝奏。石显暗中侦知，乘京房出守举告。卷075称房、博皆弃市，郑弘坐免为庶人；本纪张博作腰斩。京房本姓李，按律定京氏，死年四十一。 [[13]](#note-13)


<a id="event-14"></a>

14. **翼奉传分目。** 下节为用齐诗、律历之学向元帝进言的翼奉。 [[14]](#note-14)


<a id="event-15"></a>

15. **翼奉同门而重术，元帝召待诏。** 翼奉字少君，东海下邳人，与萧望之、匡衡同师受《齐诗》。萧施经于政，匡稍晚学，翼奉起初不仕而专律历阴阳；元帝即位后诸儒荐为待诏，屡得宴见。 [[15]](#note-15)


<a id="event-16"></a>

16. **拒传王临，以十二律释六情。** 王临自称奉诏求学，翼奉不肯，引师法说先辨邪正。以方位、情性与地支配贪狼、阴贼、廉贞等，解释为何避子卯、善午酉。他把当时西南暴风和王临数次见访的辰时作为近臣邪气的征验，这是其占说。 [[16]](#note-16)


<a id="event-17"></a>

17. **元帝问辰时，翼奉释客主正邪。** 翼奉任中郎后说师法用辰不用日，辰为来客、时为主人；又按侍者与来者之邪正解释辰与时如何相合，强调反复参验六合五行，用历观性、律观情，适合君主一人密用。 [[17]](#note-17)


<a id="event-18"></a>

18. **因祭祀与宫苑耗费上疏。** 应元帝再问得失，翼奉认为云阳、汾阴祭天地、亲尽未迁的诸寝庙及奢大宫苑都拖累储备；问题持久，需从制度根本调整。 [[18]](#note-18)


<a id="event-19"></a>

19. **以盘庚迁殷和文帝节俭为比。** 引盘庚迁邑，追述文帝时没有许多后来的宫殿名馆，一度拟建耗百金的台而撤，遗令不起山坟，归因文帝自节省民力。 [[19]](#note-19)


<a id="event-20"></a>

20. **请迁都成周以新制度。** 认为目前循旧难成大功，建议迁成周，据成皋、黾池、嵩山、大河、荥阳及敖仓等形势，压诸侯而远西北边患，借迁都改正郊祀寝庙制度、省宫馆耗费。方向“左”两见保留底本。 [[20]](#note-20)


<a id="event-21"></a>

21. **论迁都存续与预计储蓄。** 以盛周仍须戒成王、汉军远征耗财损士、当今东方连饥疫等进策，借天道循环说汉应改本更始。建议丙子孟夏东迁，估计七年后足蓄五年，再行考室礼；这只是同奏所拟计划。 [[21]](#note-21)


<a id="event-22"></a>

22. **元帝询问东徙园庙之法。** 帝问现有七园庙如何东徙，翼奉举成王迁洛、盘庚迁殷，请由君主裁定并宽其愚昧，传没有迁都成为事实之叙。 [[22]](#note-22)


<a id="event-23"></a>

23. **后续立迭毁礼并徙南北郊。** 贡禹后请定庙的迭毁礼，元帝终采；匡衡后来为相又请徙南北郊。传把议论源头追溯到翼奉，先议、后行各有年次。 [[23]](#note-23)


<a id="event-24"></a>

24. **翼奉晚年及家学。** 由中郎改博士、谏大夫，寿终，其子孙也以学问任儒官。 [[24]](#note-24)


<a id="event-25"></a>

25. **李寻传分目。** 以下叙西汉末应问灾异、治河和再受命案的李寻。 [[25]](#note-25)


<a id="event-26"></a>

26. **李寻研洪范与星历，受王根敬重。** 李寻字子长，平陵。同张孺、郑宽中习《尚书》，不同于诸同门守师法，爱洪范灾异、天文月令阴阳。丞相翟方进录为吏，王根为大司马后厚遇咨询，李寻担心洪水与国势转衰。 [[26]](#note-26)


<a id="event-27"></a>

27. **对王根论天官及得人之效。** 以天上帝廷、相将、少微与女宫布列劝尊贤，公卿责任首重得人；举秦穆公先悦佞恃勇受挫、后任百里奚而霸为鉴。 [[27]](#note-27)


<a id="event-28"></a>

28. **告外戚盛极宜用贤辅。** 李寻称士为国宝、功名之本，指出王根家九侯二十高车盛于汉代臣子。告物盛必衰，需贤友辅佐以保子孙与国。 [[28]](#note-28)


<a id="event-29"></a>

29. **贯通天文地理与政令。** 引《书》历象日月，建议结合天象、山川、人役风俗观察政令得失；称贤君闻警则修政博问，事不可转也须提前储备。 [[29]](#note-29)


<a id="event-30"></a>

30. **并举洪水、天象与政治改易。** 历举赤黄气、大兴土工、讹言水灾、宫旁泉涌、星入东井、地震河变、冬雷、流星彗与日食，用洪水之象警告王根。如贬退邪猾、改革则可延汉祚，这是他的奏说。 [[30]](#note-30)


<a id="event-31"></a>

31. **请求求贤、疏水与省税。** 劝拔擢隐者、罢谄佞与酷吏，以铁炭低昂喻政改影响阴阳；并请畅通积水相连处、修旧堤、省池泽税，征韩放，召周敞、王望议事。 [[31]](#note-31)


<a id="event-32"></a>

32. **答诏开陈天象条目。** 李寻称哀帝初政除忌讳、召贤，下问卑臣；表示愿按五经考文理、参天人，应象分条陈所闻。 [[32]](#note-32)


<a id="event-33"></a>

33. **请令君臣施政合四时月令。** 以《书》三考黜陟批治国求速，主张刑狱、发兵、封赏避非时。用冬耕虽尽力而不生作比，劝侍中尚书熟悉月令，出令失时应敢争。 [[33]](#note-33)


<a id="event-34"></a>

34. **由汝颍水灾劝抑外亲。** 把水看作公平均平的尺度，政治偏党则水涌失道，以汝、颍水与暴雨危及民生及《诗》百川沸腾为证，请少抑外戚大臣。 [[34]](#note-34)


<a id="event-35"></a>

35. **举贡禹受礼、王章受诛为用人正反例。** 认为士须素养，求贤面应广、标准不求全；昔贡禹因忠获荣，士重名节，王章因言被诛后外戚独断，正直者不敢言，归以至朝失继嗣和宫闱变乱为鉴。 [[35]](#note-35)


<a id="event-36"></a>

36. **请压外亲，清理近臣与郎博士。** 认为久积之患在任母后家，劝哀帝慎选内廷、擢贤、将无才学的郎吏与博士退归农业，以保本朝。自陈即使言当杀身也不避。 [[36]](#note-36)


<a id="event-37"></a>

37. **傅氏求尊号及李寻护河。** 哀帝初王氏尚强，丁、傅新贵；孔光、师丹争傅太后尊号终免。哀帝未全采李寻，遇变仍咨询，升黄门侍郎，因其言水患而任骑都尉护河堤。尊傅氏、二臣免职有先后，护河时点本传无明文。 [[37]](#note-37)


<a id="event-38"></a>

38. **由甘忠可造说到夏贺良等入奏。** 传称成帝时甘忠可造《天官历》《包元太平经》十二卷，赤精子下教再受命，授夏贺良等；刘向劾甘欺众，下狱病死。哀帝时解光荐旧说，刘歆反对；郭昌推动李寻使夏贺良等得待诏，因帝病无子以灾异劝改元易号。 [[38]](#note-38)


<a id="event-39"></a>

39. **赞语论阴阳学与因进言得罪。** 班固以《易》《春秋》所论天人起兴又引子贡谓天道难闻，数武昭宣元成哀平历时著名的灾异学者。指出用经联系象物有猜中之可能，追述董仲舒、夏侯胜、眭弘、李寻受罪，以京房指陈强臣又不慎保密而死收束。 [[39]](#note-39)

<a id="hs075-p006"></a>

**[《汉书·眭两夏侯京翼李传》P006](../../拆分史书/汉书/卷075.md#p006)** · [仓内TXT L8894—L8894](../../拆分史书/汉书/卷075.md#part-1-L8894)

> 夏侯勝字長公。初，魯共王分魯西寧鄉以封子節侯，別屬大河，大河後更名東平，故勝為東平人。勝少孤，好學，從始昌受尚書及洪範五行傳，說災異。後事蕑卿，又從歐陽氏問。為學精孰，所問非一師也。善說禮服。徵為博士、光祿大夫。會昭帝崩，昌邑王嗣立，數出。勝當乘輿前諫曰：「天久陰而不雨，臣下有謀上者，陛下出欲何之？」王怒，謂勝為祅言，縛以屬吏。吏白大將軍霍光，光不舉法。是時，光與車騎將軍張安世謀欲廢昌邑王。光讓安世以為泄語，安世實不言。乃召問勝，勝對言：「在洪範傳曰『皇之不極，厥罰常陰，時則下人有伐上者』，惡察察言，故云臣下有謀。」光、安世大驚，以此益重經術士。後十餘日，光卒與安世共白太后，廢昌邑王，尊立宣帝。光以為群臣奏事東宮，太后省政，宜知經術，白令勝用尚書授太后。遷長信少府，賜爵關內侯，以與謀廢立，定策安宗廟，益千戶。

### 16. 拒传王临，以十二律释六情

[返回正文第16条](#event-16)

<a id="hs075-p025"></a>

**[《汉书·眭两夏侯京翼李传》P025](../../拆分史书/汉书/卷075.md#p025)** · [仓内TXT L8913—L8913](../../拆分史书/汉书/卷075.md#part-1-L8913)

> 時，平昌侯王臨以宣布外屬侍中，稱詔欲從奉學其術。奉不肯與言，而上封事曰：「臣聞之於師，治道要務，在知下之邪正。人誠鄉正，雖愚為用；若乃懷邪，知益為害。知下之術，在於六情十二律而已。北方之情，好也；好行貪狼，申子主之。東方之情，怒也；怒行陰賊，亥卯主之。貪狼必待陰而後動，陰賊必待貪狼而後用，二陰並行，是以王者忌子卯也。禮經避之，春秋諱焉。南方之情，惡也；惡行廉貞，寅午主之。西方之情，喜也；喜行寬大，巳酉主之。二陽並行，是以王者吉午酉也。《詩》曰：『吉日庚午。』上方之情，樂也；樂行姦邪，辰未主之。下方之情，哀也；哀行公正，戌丑主之。九辰未屬陰，戌丑屬陽，萬物各以其類應。今陛下明聖虛靜以待物至，萬事雖眾，何聞而不諭，豈況乎執十二律而御六情！於以知下參實，亦甚優矣，萬不失一，自然之道也。乃正月癸未日加申，有暴風從西南來。未主姦邪，申主貪狼，風以大陰下抵建前，是人主左右邪臣之氣也。平昌侯比三來見臣，皆以正辰加邪時。辰為客，時為主人。以律知人情，王者之祕道也，愚臣誠不敢以語邪人。」

> 上以奉為中郎，召問奉：「來者以善日邪時，孰與邪日善時？」奉對曰：「師法用辰不用日。辰為客，時為主人。見於明主，侍者為主人。辰正時邪，見者正，侍者邪；辰邪時正，見者邪，侍者正。忠正之見，侍者雖邪，辰時俱正；大邪之見，侍者雖正，辰時俱邪。即以自知侍者之邪，而時邪辰正，見者反邪；即以自知侍者之正，而時正辰邪，見者反正。辰為常事，時為一行。辰疏而時精，其效同功，必參五觀之，然後可知。故曰：察其所繇，省其進退，參之六合五行，則可以見人性，知人情。難用外察，從中甚明，故詩之為學，情性而已。五性不相害，六情更興廢。觀性以曆，觀情以律，明主所宜獨用，難與二人共也。故曰：『顯諸仁，臧諸用。』露之則不神，獨行則自然矣，唯奉能用之，學者莫能行。」

> 竊見往者赤黃四塞，地氣大發，動土竭民，天下擾亂之徵也。彗星爭明，庶雄為桀，大寇之引也。此二者已頗效矣。城中訛言大水，奔走上城，朝廷驚駭，女孽入宮，此獨未效。間者重以水泉涌溢，旁宮闕仍出。月、太白入東井，犯積水，缺天淵。日數湛於極陽之色。羽氣乘宮，起風積雲。又錯以山崩地動，河不用其道。盛冬雷電，潛龍為孽。繼以隕星流彗，維、填上見，日蝕有背鄉。此亦高下易居，洪水之徵也。不憂不改，洪水乃欲盪滌，流彗乃欲埽除；改之，則有年亡期。故屬者頗有變改，小貶邪猾，日月光精，時雨氣應，此皇天右漢亡已也，何況致大改之！

### 33. 请令君臣施政合四时月令

[返回正文第33条](#event-33)

<a id="hs075-p051"></a>

**[《汉书·眭两夏侯京翼李传》P051](../../拆分史书/汉书/卷075.md#p051)** · [仓内TXT L8939—L8939](../../拆分史书/汉书/卷075.md#part-1-L8939)

> 治國故不可以戚戚，欲速則不達。經曰：「三載考績，三考黜陟。」加以號令不順四時，既往不咎，來事之師也。間者春三月治大獄，時賊陰立逆，恐歲小收；季夏舉兵法，時寒氣應，恐後有霜雹之災；秋月行封爵，其月土濕奧，恐後有雷雹之變。夫以喜怒賞罰，而不顧時禁，雖有堯舜之心，猶不能致和。善言天者，必有效於人。設上農夫而欲冬田，肉袒深耕，汗出種之，然猶不生者，非人心不至，天時不得也。《易》曰：「時止則止，時行則行，動靜不失其時，其道光明。」《書》曰：「敬授民時。」故古之王者，尊天地，重陰陽，敬四時，嚴月令。順之以善政，則和氣可立致，猶枹鼓之相應也。今朝廷忽於時月之令，諸侍中尚書近臣宜皆令通知月令之意，設群下請事；若陛下出令有謬於時者，當知爭之，以順時氣。

### 38. 由甘忠可造说到夏贺良等入奏

> 初，成帝時，齊人甘忠可詐造《天官曆》、《包元太平經》十二卷，以言「漢家逢天地之大終，當更受命於天，天帝使真人赤精子，下教我此道。」忠可以教重平夏賀良、容丘丁廣世、東郡郭昌等，中壘校尉劉向奏忠可假鬼神罔上惑眾，下獄治服，未斷病死。賀良等坐挾學忠可書以不敬論，後賀良等復私以相教。哀帝初立，司隸校尉解光亦以明經通災異得幸，白賀良等所挾忠可書。事下奉車都尉劉歆，歆以為不合五經，不可施行。而李尋亦好之。光曰：「前歆父向奏忠可下獄，歆安肯通此道？」時郭昌為長安令，勸尋宜助賀良等。尋遂白賀良等皆待詔黃門，數召見，陳說「漢曆中衰，當更受命。成帝不應天命，故絕嗣。今陛下久疾，變異屢數，天所以譴告人也。宜急改元易號，乃得延年益壽，皇子生，災異息矣。得道不得行，咎殃且亡，不有洪水將出，災火且起，滌盪人民。」

### 39. 赞语论阴阳学与因进言得罪

> 贊曰：幽贊神明，通合天人之道者，莫著乎易、春秋。然子贛猶云「夫子之文章可得而聞，夫子之言性與天道不可得而聞」已矣。漢興推陰陽言災異者，孝武時有董仲舒、夏侯始昌，昭、宣則眭孟、夏侯勝，元、成則京房、翼奉、劉向、谷永，哀、平則李尋、田終術。此其納說時君著明者也。察其所言，仿佛一端。假經設誼，依託象類，或不免乎「億則屢中」。仲舒下吏，夏侯囚執，眭孟誅戮，李尋流放，此學者之大戒也。京房區區，不量淺深，危言刺譏，構怨彊臣，罪辜不旋踵，亦不密以失身，悲夫！

# 汉书艺文志的书目与学术源流

[本世纪目录](README.md) · [全部世纪](../README.md)

此处连读各志的制度沿革、学术分类与未详年次的史事；整段原文和已系年节录均可由卷内读本查阅。


<a id="event-1"></a>

1. **汉家访书、校书与《七略》。** 志序从孔门之后传经分歧、战国诸说并起及秦焚书谈起。汉开献书之路，武帝建藏书和抄写制度，成帝命陈农搜书并分派刘向、任宏、尹咸、李柱国校四门。刘向逐书写篇目和提要，刘歆续业，编《七略》。辑略为总叙，另六略在本志分录。 [[1]](#note-1)


<a id="event-2"></a>

2. **六艺·易类书目。** 列施、孟、梁丘三家《易》及周氏以下各家传本、古杂、灾异、图及章句，京房相关记载须辨不同易家。结尾按十三家、二百九十四篇合记。 [[2]](#note-2)


<a id="event-3"></a>

3. **易类小序。** 以伏羲、文王、孔子解释所谓三圣三古。秦时《易》因用于卜筮得传，汉有官立诸家和民间费、高之学。刘向校出部分官本有脱字，本志认为费氏与古文在所较文本中相同。 [[3]](#note-3)


<a id="event-4"></a>

4. **六艺·尚书类书目。** 古文经四十六卷与二十九卷本分录，此外有欧阳、大小夏侯的章句、传说及议奏等。末记九家、四百一十二篇。 [[4]](#note-4)


<a id="event-5"></a>

5. **尚书小序及伏生、壁书异文。** 追述经篇起源、伏生藏书、三家学官和孔宅古文。刘向拿宫中藏本与三家官学本校读，发现《酒诰》《召诰》脱简及七百余处异文。文中的“武帝末”与鲁共王本传卒年不合，读作目录所传说法。 [[5]](#note-5)


<a id="event-6"></a>

6. **六艺·诗类书目。** 鲁、齐、韩诗经、故、传及说并列，毛诗经与故训传另见。合计六家、四百一十六卷。 [[6]](#note-6)


<a id="event-7"></a>

7. **诗类小序。** 志中区别诵诗和歌咏，以采诗观察风俗。秦后诗得保全归因于口传，汉初鲁申公、齐辕固、燕韩生三家立于学官，毛公传说另有河间献王支持，志记当时未立。 [[7]](#note-7)


<a id="event-8"></a>

8. **六艺·礼类书目。** 收古礼、公约性仪节、记与说、明堂和丧服等，并列本朝制度文书。志总十三家、五百五十五篇。 [[8]](#note-8)


<a id="event-9"></a>

9. **礼文的流传。** 礼的功能在规范敬与让。叙秦后礼文残缺、高堂生传《士礼》、后苍传诸弟子，以及古经、逸礼与戴、庆诸系的关系。 [[9]](#note-9)


<a id="event-10"></a>

10. **六艺·乐类书目。** 含《乐记》、雅歌诗、雅琴和各家琴谱传承。六家、一百六十五篇为志计。 [[10]](#note-10)


<a id="event-11"></a>

11. **乐舞文献及版本。** 乐序以音乐调和情志；周衰而礼乐文献不全。汉河间献王与毛生等采辑，王禹传其学；刘向校书另列异本，乐官能考日常钟律却不足以详明经义。 [[11]](#note-11)


<a id="event-12"></a>

12. **六艺·春秋经传上列。** 古经、经、左氏、公羊、穀梁、邹氏、夹氏诸传并列。经、传、章句、议奏的计数单位沿原文保留。 [[12]](#note-12)


<a id="event-13"></a>

13. **六艺·春秋经传续录。** 诸家训说、外传及《国语》《世本》《战国策》《太史公》等纪事类作品与春秋文献同列。末记二十三家、九百四十八篇。 [[13]](#note-13)


<a id="event-14"></a>

14. **春秋小序。** 志借古史官左、右职掌解释记事与记言，叙孔子据鲁史褒贬与左丘明传释，继论口传、各家分合和立于学官的情况。 [[14]](#note-14)


<a id="event-15"></a>

15. **六艺·论语书目。** 列古《论语》、齐论、鲁论及传说，也录孔门言行与相关经说。存本篇章、问答内容和传授门户各异。 [[15]](#note-15)


<a id="event-16"></a>

16. **论语小序。** 孔门弟子各记所闻，汇编为《论语》。汉代有鲁、齐、古三种篇次的说法。张禹兼采，所成传本在当时行用。 [[16]](#note-16)


<a id="event-17"></a>

17. **六艺·孝经书目。** 古孔氏条在TXT连见两行，照录。古、今文及诸家说附列，校勘时不可把重复电子行直接当作新增一种作品。 [[17]](#note-17)


<a id="event-18"></a>

18. **孝经小序。** 以孔子为曾子陈孝为传说起点。长孙氏、江翁、后仓、翼奉、张禹各传，志说诸家经文相同，孔壁古文在部分字读不同。 [[18]](#note-18)


<a id="event-19"></a>

19. **六艺·小学书目。** 目录所说小学为文字、字书、识读训诂；收《史籀》《苍颉》《急就》《凡将》等。作品和章数、篇数依表分列。 [[19]](#note-19)


<a id="event-20"></a>

20. **六书、六体与汉代字书。** 记八岁小学、六书分类和地方识字考官，说明六体用于古今字、印章与书信。秦三篇后合成《苍颉篇》，汉续有《凡将》《急就》《元尚》《训纂》及此志所叙续纂。 [[20]](#note-20)


<a id="event-21"></a>

21. **六艺合计与经学批评。** 录一百三家三千一百二十三篇的总计。序以易为诸经之原，说明诗、礼、乐、书、春秋作用，批评割裂经旨、把几个字铺成繁辞，六艺略分九种。 [[21]](#note-21)


<a id="event-22"></a>

22. **诸子·儒家上列。** 列经学之外的儒家著述和遗说，含孔门、孟荀等谱系；目录题名和叙录归属是汉代馆藏分类记录。 [[22]](#note-22)


<a id="event-23"></a>

23. **诸子·儒家续录。** 录多种议论、传记及汉臣作品，表末合计五十三家、八百三十六篇。 [[23]](#note-23)


<a id="event-24"></a>

24. **儒家小序。** 将儒家追溯到司徒教民，说其重仁义与祖述先王，亦批评失经义而借巧言求取名声者。班固的起源解释是一种经学分类。 [[24]](#note-24)


<a id="event-25"></a>

25. **诸子·道家上列。** 所录有古帝名下著作及老子诸本、庄周、列御寇等。题名可属托名或后学，馆藏著录本身不能证其确为上古人所作。 [[25]](#note-25)


<a id="event-26"></a>

26. **诸子·道家续录。** 同列后出政论和养生、清静一系作品；志总三十七家、九百九十三篇。 [[26]](#note-26)


<a id="event-27"></a>

27. **道家小序。** 追溯出自史官，称其熟知古今得失、务本清静谦下，亦批评以虚静排去礼学仁义的极端。 [[27]](#note-27)


<a id="event-28"></a>

28. **诸子·阴阳家。** 列阴阳历时、五行、时令一类著作。小序举羲和授时为本，肯定观察天时，反对泥于小数、废人事而任鬼神。 [[28]](#note-28)


<a id="event-29"></a>

29. **诸子·法家。** 列法术、刑赏等书。小序从理官解释其起源，以信赏必罚辅礼为长，以苛刑伤恩和废教化为弊。 [[29]](#note-29)


<a id="event-30"></a>

30. **诸子·名家。** 诸书讨论名分与辩论，小序用孔子正名解释其政治功能，批评以细碎诡辩扰乱名实。 [[30]](#note-30)


<a id="event-31"></a>

31. **诸子·墨家。** 书目与墨学诸支相见。小序从清庙旧职解释节用、兼爱、尚贤、明鬼、非命、尚同，批评其教条化。 [[31]](#note-31)


<a id="event-32"></a>

32. **诸子·纵横家。** 列行人与游说各书，小序重使者奉命而能临事专对，亦批评以诈谋废信。 [[32]](#note-32)


<a id="event-33"></a>

33. **诸子·杂家。** 目录并列兼采诸家的著述，小序以兼容儒、墨、名、法、通察国事为长，以漫无归准为短。 [[33]](#note-33)


<a id="event-34"></a>

34. **诸子·农家。** 列稼穑仓廪等作品，以农官劝耕桑足衣食为长，也批评取消职分、君臣同耕的主张。 [[34]](#note-34)


<a id="event-35"></a>

35. **诸子·小说家。** 收街谈、传闻、寓言等小道著作。班固说不可依以任大事，却无须全部废弃，乡野意见有可采者。 [[35]](#note-35)


<a id="event-36"></a>

36. **诸子总计与九流之说。** 记录一百八十九家四千三百二十四篇。班固将十类中九类视为可观，说明诸家出自衰周不同处境，各持一端，可参照经籍取长补短。 [[36]](#note-36)


<a id="event-37"></a>

37. **诗赋·第一组赋。** 从屈原、唐勒、宋玉等名下作品以及其他赋家条推见楚辞与汉赋的馆藏次序，本组总二十家。 [[37]](#note-37)


<a id="event-38"></a>

38. **诗赋·第二组赋。** 录多家汉代辞赋作品和数目，以原标名、篇数及附识对读，目录合二十一家。 [[38]](#note-38)


<a id="event-39"></a>

39. **诗赋·第三组赋。** 这一组收二十五家，题名、作者官称、篇数为不同著录信息，分行照录。 [[39]](#note-39)


<a id="event-40"></a>

40. **诗赋·杂赋。** 按物类或主题列无明确作者或杂出的作品，总十二家二百三十三篇。 [[40]](#note-40)


<a id="event-41"></a>

41. **诗赋·歌诗及篇籍总计。** 目录录宗庙、巡狩、边地及各国歌诗，末计歌诗二十八家并总赋、诗各组。本志统计兼有诗、赋及歌谱性质材料。 [[41]](#note-41)


<a id="event-42"></a>

42. **诗赋小序。** 志述列国聘问引诗、失意写赋、汉赋好华丽的变化，记扬雄重讽谏与节制的评论，又述武帝乐府采歌谣可观风俗。 [[42]](#note-42)


<a id="event-43"></a>

43. **兵书·兵权谋。** 目录以总体谋略为一类，列《吴孙子》《齐孙子》等古兵书及篇图数，保留时代著录。 [[43]](#note-43)


<a id="event-44"></a>

44. **兵书·兵形势。** 本类书目与附图同录。小序以军队行动快慢及组织变化说明“形势”这一汉代目录概念。 [[44]](#note-44)


<a id="event-45"></a>

45. **兵书·兵阴阳。** 军中占候、时日、方位等著作同列为兵阴阳，计家数、篇数及图数。类别体现当时知识编排。 [[45]](#note-45)


<a id="event-46"></a>

46. **兵书·兵技巧及合计。** 列古代兵备、器械和技艺类书目；计算本类与四类总数，同时保留删合及图卷记录。 [[46]](#note-46)


<a id="event-47"></a>

47. **兵书小序。** 志以司马掌军为兵书源头，述春秋战国以来军事著作及汉初整理、武帝时杨仆访佚，到成帝时任宏分四类校勘。 [[47]](#note-47)


<a id="event-48"></a>

48. **数术·天文。** 目录列太史星占、日月五星、彗星等记述；小序重天象记录又指出专靠占候的局限。总数及书名只反映当时馆藏。 [[48]](#note-48)


<a id="event-49"></a>

49. **数术·历谱。** 包括历式、日月五星相会与世谱年代。小序说历法用于定四时、节气与历日，也是古人解释灾祥的工具。 [[49]](#note-49)


<a id="event-50"></a>

50. **数术·五行。** 收五行与阴阳禁忌、月令占候著作，列家卷总数；古人依次序解释吉凶属于目录所述方法。 [[50]](#note-50)


<a id="event-51"></a>

51. **数术·蓍龟。** 收卜筮书及卦具，附小序解释重大疑事求卜、戒反复烦渎。卦具的数量与书卷单位分开。 [[51]](#note-51)


<a id="event-52"></a>

52. **数术·杂占。** 题目涉及梦、雨旱、农牧与各类征兆，目录以杂占统摄，附总计十八家。 [[52]](#note-52)


<a id="event-53"></a>

53. **数术·形法及合计。** 形法书按天地形势、城郭形状、动物及人体特征等分类。数术总论说官守中断导致文献及传人都不全，录六种的总数。 [[53]](#note-53)


<a id="event-54"></a>

54. **方技·医经。** 列《黄帝内经》《外经》等古医籍。小序概述经络、诊病和治疗配合等古代医学观念，重视医者能否理解病情。 [[54]](#note-54)


<a id="event-55"></a>

55. **方技·经方。** 经方目录以旧药方、病类与饮食条为主。小序论药物性味、调剂和使用不当的后果，是古代文献叙录。 [[55]](#note-55)


<a id="event-56"></a>

56. **方技·房中。** 列古代房中文献。小序将情欲与节制联结，认为失度伤身，这里照述编目价值判断。 [[56]](#note-56)


<a id="event-57"></a>

57. **方技·神仙。** 收导引、养生、神仙一类著作。小序认为持守性命在先，若专求奇术、委弃事务会生欺罔。 [[57]](#note-57)


<a id="event-58"></a>

58. **方技小结与六略总计。** 方技分类出于古代养生、诊疗等官守，举岐伯、扁鹊、仓公。全志末总列六略、三十八种、五百九十六家、一万三千二百六十九卷，照录原单位，不据分项重算佚书。 [[58]](#note-58)

### 1. 汉家访书、校书与《七略》

[返回正文第1条](#event-1)

<a id="hs030-p001"></a>

**[《汉书·艺文志》P001](../../sources/摘录/汉书-卷030-艺文志.md#p001)** · [仓内TXT L6128—L6128](../../sources/本地分卷/汉书/汉书-卷030.md#L6128)

> 昔仲尼沒而微言絕，七十子喪而大義乖。故春秋分為五，詩分為四，易有數家之傳。戰國從衡，真偽分爭，諸子之言紛然殽亂。至秦患之，乃燔滅文章，以愚黔首。漢興，改秦之敗，大收篇籍，廣開獻書之路。迄孝武世，書缺簡脫，禮壞樂崩，聖上喟然而稱曰：「朕甚閔焉！」於是建藏書之策，置寫書之官，下及諸子傳說，皆充祕府。至成帝時，以書頗散亡，使謁者陳農求遺書於天下。詔光祿大夫劉向校經傳諸子詩賦，步兵校尉任宏校兵書，太史令尹咸校數術，侍醫李柱國校方技。每一書已，向輒條其篇目，撮其指意，錄而奏之。會向卒，哀帝復使向子侍中奉車都尉歆卒父業。歆於是總群書而奏其七略，故有輯略，有六藝略，有諸子略，有詩賦略，有兵書略，有術數略，有方技略。今刪其要，以備篇籍。

### 3. 易类小序

[返回正文第3条](#event-3)

<a id="hs030-p003"></a>

**[《汉书·艺文志》P003](../../sources/摘录/汉书-卷030-艺文志.md#p003)** · [仓内TXT L6143—L6143](../../sources/本地分卷/汉书/汉书-卷030.md#L6143)

> 《易》曰：「宓戲氏仰觀象於天，俯觀法於地，觀鳥獸之文，與地之宜，近取諸身，遠取諸物，於是始作八卦，以通神明之德，以類萬物之情。」至於殷、周之際，紂在上位，逆天暴物，文王以諸侯順命而行道，天人之占可得而效，於是重易六爻，作上下篇。孔氏為之彖、象、繫辭、文言、序卦之屬十篇。故曰易道深矣，人更三聖，世歷三古。及秦燔書，而易為筮卜之事，傳者不絕。漢興，田和傳之。訖于宣、元，有施、孟、梁丘、京氏列於學官，而民間有費、高二家之說。劉向以中古文易經校施、孟、梁丘經，或脫去「無咎」、「悔亡」，唯費氏經與古文同。

> 《易》曰：「河出圖，雒出書，聖人則之。」故書之所起遠矣，至孔子篹焉，上斷於堯，下訖于秦，凡百篇，而為之序，言其作意。秦燔書禁學，濟南伏生獨壁藏之。漢興亡失，求得二十九篇，以教齊魯之間。訖孝宣世，有歐陽、大小夏侯氏，立於學官。古文尚書者，出孔子壁中。武帝末，魯共王壞孔子宅，欲以廣其宮，而得古文尚書及禮記、論語、孝經凡數十篇，皆古字也。共王往入其宅，聞鼓琴瑟鍾磬之音，於是懼，乃止不壞。孔安國者，孔子後也，悉得其書，以考二十九篇，得多十六篇。安國獻之。遭巫蠱事，未列于學官。劉向以中古文校歐陽、大小夏侯三家經文，酒誥脫簡一，召誥脫簡二。率簡二十五字者，脫亦二十五字，簡二十二字者，脫亦二十二字，文字異者七百有餘，脫字數十。書者，古之號令，號令於眾，其言不立具，則聽受施行者弗曉。古文讀應爾雅，故解古今語而可知也。

### 14. 春秋小序

[返回正文第14条](#event-14)

<a id="hs030-p014"></a>

**[《汉书·艺文志》P014](../../sources/摘录/汉书-卷030-艺文志.md#p014)** · [仓内TXT L6228—L6228](../../sources/本地分卷/汉书/汉书-卷030.md#L6228)

> 古之王者世有史官，君舉必書，所以慎言行，昭法式也。左史記言，右史記事，事為春秋，言為尚書，帝王靡不同之。周室既微，載籍殘缺，仲尼思存前聖之業，乃稱曰：「夏禮吾能言之，杞不足徵也；殷禮吾能言之，宋不足徵也。文獻不足故也，足則吾能徵之矣。」以魯周公之國，禮文備物，史官有法，故與左丘明觀其史記，據行事，仍人道，因興以立功，就敗以成罰，假日月以定曆數，藉朝聘以正禮樂。有所褒諱貶損，不可書見，口授弟子，弟子退而異言。丘明恐弟子各安其意，以失其真，故論本事而作傳，明夫子不以空言說經也。春秋所貶損大人當世君臣，有威權勢力，其事實皆形於傳，是以隱其書而不宣，所以免時難也。及末世口說流行，故有公羊、穀梁、鄒、夾之傳。四家之中，公羊、穀梁立於學官，鄒氏無師，夾氏未有書。

### 20. 六书、六体与汉代字书

[返回正文第20条](#event-20)

<a id="hs030-p020"></a>

**[《汉书·艺文志》P020](../../sources/摘录/汉书-卷030-艺文志.md#p020)** · [仓内TXT L6272—L6272](../../sources/本地分卷/汉书/汉书-卷030.md#L6272)

> 《易》曰：「上古結繩以治，後世聖人易之以書契，百官以治，萬民以察，蓋取諸夬。」「夬，揚於王庭」，言其宣揚於王者朝廷，其用最大也。古者八歲入小學，故周官保氏掌養國子，教之六書，謂象形、象事、象意、象聲、轉注、假借，造字之本也。漢興，蕭何草律，亦著其法，曰：「太史試學童，能諷書九千字以上，乃得為史。又以六體試之，課最者以為尚書御史史書令史。吏民上書，字或不正，輒舉劾。」六體者，古文、奇字、篆書、隸書、繆篆、蟲書，皆所以通知古今文字，摹印章，書幡信也。古制，書必同文，不知則闕，問諸故老，至於衰世，是非無正，人用其私。故孔子曰：「吾猶及史之闕文也，今亡矣夫！」蓋傷其浸不正。史籀篇者，周時史官教學童書也，與孔氏壁中古文異體。蒼頡七章者，秦丞相李斯所作也；爰歷六章者，車府令趙高所作也；博學七章者，太史令胡母敬所作也：文字多取史籀篇，而篆體復頗異，所謂秦篆者也。是時始造隸書矣，起於官獄多事，苟趨省易，施之於徒隸也。漢書，閭里書師合蒼頡、爰歷、博學三篇，斷六十字以為一章，凡五十五章，并為蒼頡篇。武帝時司馬相如作凡將篇，無復字。元帝時黃門令史游作急就篇，成帝時將作大匠李長作元尚篇，皆蒼頡中正字也。凡將則頗有出矣。至元始中，徵天下通小學者以百數，各令記字於庭中。揚雄取其有用者以作訓纂篇，順續蒼頡，又易蒼頡中重復之字，凡八十九章。臣復續揚雄作十二章，凡一百二章，無復字，六藝群書所載略備矣。蒼頡多古字，俗師失其讀，宣帝時徵齊人能正讀者，張敞從受之，傳至外孫之子杜林，為作訓故，并列焉。

### 42. 诗赋小序

[返回正文第42条](#event-42)

<a id="hs030-p042"></a>

**[《汉书·艺文志》P042](../../sources/摘录/汉书-卷030-艺文志.md#p042)** · [仓内TXT L6598—L6598](../../sources/本地分卷/汉书/汉书-卷030.md#L6598)

> 傳曰：「不歌而誦謂之賦，登高能賦可以為大夫。」言感物造耑，材知深美，可與圖事，故可以為列大夫也。古者諸侯卿大夫交接鄰國，以微言相感，當揖讓之時，必稱詩以諭其志，蓋以別賢不肖而觀盛衰焉。故孔子曰「不學詩，無以言」也。春秋之後，周道浸壞，聘問歌詠不行於列國，學詩之士逸在布衣，而賢人失志之賦作矣。大儒孫卿及楚臣屈原離讒憂國，皆作賦以風，咸有惻隱古詩之義。其後宋玉、唐勒，漢興枚乘、司馬相如，下及揚子雲，競為侈麗閎衍之詞，沒其風諭之義。是以揚子悔之，曰：「詩人之賦麗以則，辭人之賦麗以淫。如孔氏之門人用賦也，則賈誼登堂，相如入室矣，如其不用何！」自孝武立樂府而采歌謠，於是有代趙之謳，秦楚之風，皆感於哀樂，緣事而發，亦可以觀風俗，知薄厚云。詩賦為五種。

### 47. 兵书小序

[返回正文第47条](#event-47)

<a id="hs030-p047"></a>

**[《汉书·艺文志》P047](../../sources/摘录/汉书-卷030-艺文志.md#p047)** · [仓内TXT L6663—L6663](../../sources/本地分卷/汉书/汉书-卷030.md#L6663)

> 兵家者，蓋出古司馬之職，王官之武備也。洪範八政，八曰師。孔子曰為國者「足食足兵」，「以不教民戰，是謂棄之」，明兵之重也。《易》曰「古者弦木為弧，剡木為矢，弧矢之利，以威天下」，其用上矣。後世燿金為刃，割革為甲，器械甚備。下及湯武受命，以師克亂而濟百姓，動之以仁義，行之以禮讓，司馬法是其遺事也。自春秋至於戰國，出奇設伏，變詐之兵並作。漢興，張良、韓信序次兵法，凡百八十二家，刪取要用，定著三十五家。諸呂用事而盜取之。武帝時，軍政楊僕捃摭遺逸，紀奏兵錄，猶未能備。至于孝成，命任宏論次兵書為四種。

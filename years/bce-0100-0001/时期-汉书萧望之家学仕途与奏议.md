# 汉书萧望之家学仕途与奏议

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **萧望之家世和经学师承。** 萧氏世代务农，望之独好学，治齐诗，从后仓近十年，又向太常受业、师事白奇，从夏侯胜问《论语》礼服，为京师儒士所称。 [[1]](#note-1)


<a id="event-2"></a>

2. **拒搜见霍光与抱关任职。** 丙吉荐萧望之等见霍光。霍光遭上官桀等谋害后，来者须除兵、受搜而被挟持。望之拒搜，入见引周公礼士以谏；同辈王仲翁等任大将军属吏，望之独未获任，后以策问甲科守小苑东门。仲翁显贵，临门讥望之，语跨下行。 [[2]](#note-2)


<a id="event-3"></a>

3. **各从其志。** 承上段，王仲翁讥望之不肯随众、反守苑门，望之答各从其志。 [[3]](#note-3)


<a id="event-4"></a>

4. **累及弟罪，魏相复用。** 弟犯法使他失去宿卫资格，回郡任吏。御史大夫魏相任他为属，后以察廉为大行治礼丞。 [[4]](#note-4)


<a id="event-5"></a>

5. **地节三年雨雹论霍氏。** 霍光死后霍氏掌兵并在宫中宿卫。地节三年夏京师雨雹，望之以鲁季氏专权为比，劝宣帝亲理政事、广选腹心、考核公卿。宣帝令宋畸问状后擢其为谒者；由他分等考察上书者，屡升至丞相司直。霍氏伏法后他更得任用。 [[5]](#note-5)


<a id="event-6"></a>

6. **乌孙约婚与少主召还。** 乌孙昆弥翁归靡曾请由元贵靡为嗣并娶汉少主，望之不赞成。神爵二年朝廷仍令常惠送少主；未出塞，翁归靡死，狂王自立，常惠请暂留敦煌并赴乌孙责约。望之再议罢婚，朝廷召少主归；后来乌孙分立大小昆弥，汉未再送少主。 [[6]](#note-6)


<a id="event-7"></a>

7. **反常平仓与轻丞相受诘。** 望之不赞成耿寿昌常平仓，又以盗贼、饥乏及日月失光言三公之责。宣帝认为他轻视年老的丙吉，令人诘问，望之免冠置对。 [[7]](#note-7)


<a id="event-8"></a>

8. **下迁太子太傅。** 丞相司直奏望之怠慢使者、待丞相不逊、私使御史吏治家交易，并请逮治。宣帝诏陈其失，不愿交法吏，改任太子太傅、交原印，嘱以正道作师范。 [[8]](#note-8)


<a id="event-9"></a>

9. **黄霸升相与望之讲授太子。** 望之降后由黄霸接任御史大夫，丙吉死后黄霸升相；霸死后由于定国继任。望之未得相位，任太傅时以《论语》、礼服授太子。 [[9]](#note-9)


<a id="event-10"></a>

10. **建议中书不用宦官而遭忤。** 宣帝重法律，弘恭、石显久掌中书，与史高相协。萧望之认为中书是政本，武帝因后庭游宴以宦者任事，非旧制，应更用士人，惹恭显及史高反对。元帝初不遽变动，刘更生出任宗正。 [[10]](#note-10)


<a id="event-11"></a>

11. **郑朋以讦奏求附望之。** 望之、周堪荐名儒时，郑朋奏史高遣客在郡国谋私，又讥许、史子弟。周堪奏使他待诏金马门；郑朋致书称颂望之，以管仲、晏婴和周、召相比较，求得重用，又常折指史高等人。 [[11]](#note-11)


<a id="event-12"></a>

12. **萧伋续爵与朝廷遣祭。** 有司请绝爵邑，元帝加恩令长子萧伋嗣关内侯。元帝在世时每岁遣使祭望之墓，望之八子中萧育、萧咸、萧由后来任大官。 [[12]](#note-12)


<a id="event-13"></a>

13. **萧育刚猛治事与淳于长案。** 萧育因父任起家，王凤赏其材，历使匈奴及地方官。任茂陵令时为考课落后的郭舜求情，受召问即欲去官，次日反拜司隶校尉。后来历刺史及九卿，任右扶风平梁子政等，因与淳于长交厚而免。 [[13]](#note-13)


<a id="event-14"></a>

14. **南郡平盗与执金吾终官。** 哀帝以萧育素有威信，令其治南郡水盗，赐金且不拘细文。南郡盗息，萧育一度病归，又拜光禄大夫、执金吾，终于官。 [[14]](#note-14)


<a id="event-15"></a>

15. **萧育、陈咸、朱博早交。** 萧育严猛，升少免多；与陈咸、朱博交好，人以“蕭、朱結綬，王、貢彈冠”比朋辈引进。陈咸起最早，朱博原为亭长，经荐后来居先至宰相；萧、朱后来有隙，传以此叹交情难终。 [[15]](#note-15)


<a id="event-16"></a>

16. **萧咸治郡与出使。** 萧咸由丞相史荐为茂材，又任县令、两国内史、数郡太守，屡以政绩赐金增秩。曾免官复起，为越骑校尉等并使匈奴，最终任大司农。 [[16]](#note-16)


<a id="event-17"></a>

17. **萧由免复与江夏治盗。** 萧由历汉使、令、都尉、太守，有治名，任定陶令曾忤当时的定陶王刘欣而去。哀帝死后复官，平江夏贼得增秩；元始明堂辟雍大朝，曾召大鸿胪而病不及赞礼，最后任中散大夫。萧氏子弟数人为二千石。 [[17]](#note-17)


<a id="event-18"></a>

18. **班固论师傅之亲与谗构。** 班固惜萧望之以师傅受重，谋议外泄后被宦官诬构；称他学术立身、刚直不挠、足辅国，堪称社稷之臣。 [[18]](#note-18)

> 先是烏孫昆彌翁歸靡因長羅侯常惠上一書，願以漢外孫元貴靡為嗣，得復尚少主，結婚內附，畔去匈奴。詔下公卿議，望之以為烏孫絕域，信其美言，萬里結婚，非長策也。天子不聽。神爵二年，遣長羅侯惠使送公主配元貴靡。未出塞，翁歸靡死，其兄子狂王背約自立。惠從塞下上書，願留少主敦煌郡。惠至烏孫，責以負約，因立元貴靡，還迎少主。詔下公卿議，望之復以為「不可。烏孫持兩端，亡堅約，其效可見。前少主在烏孫四十餘年，恩愛不親密，邊境未以安，此已事之驗也。今少主以元貴靡不得立而還，信無負於四夷，此中國之大福也。少主不止，繇役將興，其原起此。」天子從其議，徵少主還。後烏孫雖分國兩立，以元貴靡為大昆彌，漢遂不復與結婚。

[返回正文第8条](#event-8)

<a id="hs078-p013"></a>

**[《汉书·萧望之传》P013](../../拆分史书/汉书/卷078.md#p013)** · [仓内TXT L9066—L9066](../../拆分史书/汉书/卷078.md#part-1-L9066)

> 初，宣帝不甚從儒術，任用法律，而中書宦官用事。中書令弘恭、石顯久典樞機，明習文法，亦與車騎將軍高為表裏，論議常獨持故事，不從望之等。恭、顯又時傾仄見詘。望之以為中書政本，宜以賢明之選，自武帝游宴後庭，故用宦者，非國舊制，又違古不近刑人之義，白欲更置士人，繇是大與高、恭、顯忤。上初即位，謙讓重改作，議久不定，出劉更生為宗正。

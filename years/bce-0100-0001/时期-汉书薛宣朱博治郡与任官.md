# 汉书薛宣朱博治郡与任官

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **薛宣起自吏员。** 薛宣是东海郯人，由廷尉、司农的基层职务发迹。琅邪太守赵贡识其治才，察廉；后来经举荐历任县令，以熟文法为御史中丞。 [[1]](#note-1)


<a id="event-2"></a>

2. **历治临淮陈留和左冯翊。** 薛宣多论政务，举劾与荐升分明；出任临淮、陈留太守，治理陈留盗乱，入代理左冯翊一年后实授。 [[2]](#note-2)


<a id="event-3"></a>

3. **分别劝退高陵、栎阳二令。** 薛宣先礼待两令，继而暗得其赃证。对阳湛用密函劝其自处；对自恃名儒、轻慢上官的谢游明发檄文，列其取财及苛扰情事，二人都解印辞去。 [[3]](#note-3)


<a id="event-4"></a>

4. **调换薛恭尹赏以称才。** 频阳交通要冲多盗，原县令薛恭缺少理民经验；粟邑易治，让熟悉吏务的尹赏转频阳、薛恭转粟邑，两县均治。薛宣借孟公绰典故勉励因材任职。 [[4]](#note-4)


<a id="event-5"></a>

5. **令县长吏自行处理。** 薛宣得知属县吏民有罪，先约见县长吏通知，使其自理。声称是要保留令长治理职责，不夺其名，诸县官既感恩又戒惧。 [[5]](#note-5)


<a id="event-6"></a>

6. **王立案与送葬。** 池阳狱掾王立获荐廉吏，县查出是其妻独收坐牢人家贿金，王立并不知情，却自杀以明志。薛宣命在棺上标写府属职位，许熟识王立的府吏送葬。 [[6]](#note-6)


<a id="event-7"></a>

7. **冬至令张扶归休。** 冬至依令休吏，贼曹掾张扶仍留曹治事。薛宣劝他依旧例回家，与妻儿、邻里共享节日，部属以为允当。 [[7]](#note-7)


<a id="event-8"></a>

8. **务实节用与迁少府。** 薛宣仪态雍容，心思细密，连办公笔砚也筹划节费。地方清静，迁少府后仍办事有条理。 [[8]](#note-8)


<a id="event-9"></a>

9. **代张禹为相。** 薛宣任丞相、封高阳侯，辟用早年知遇他的赵贡二子。他在相府定财物诉讼不足万钱不移书的例，部属批评其琐细，成帝也以其经术浅而轻视他。 [[9]](#note-9)


<a id="event-10"></a>

10. **复爵而坐淳于长罢。** 翟方进念薛宣旧恩，任相后荐其熟悉制度、先前罪过较轻。薛宣复封高阳侯并给事中、视尚书事，后来因与定陵侯淳于长友善罢归。 [[10]](#note-10)


<a id="event-11"></a>

11. **两弟与后母服制。** 弟薛明、薛修均任显官，后母常随薛修。母死后薛宣对弟弟持满三年丧有异议，薛修仍依服制终丧，兄弟由此不和。 [[11]](#note-11)


<a id="event-12"></a>

12. **过彭城不亲教薛惠。** 薛宣见薛惠所治县邮亭桥梁失修，留数日也不指示吏治。经属吏来问，他解释法令可学，能否胜任各有资材。 [[12]](#note-12)


<a id="event-13"></a>

13. **敬武长公主和薛况被杀。** 公主曾与薛宣成婚，薛宣卒后请葬延陵。薛况私归，逢赦留京并与公主私通；吕宽案发后王莽并究薛况，使公主饮药自尽，薛况被枭首。公主斥王氏专权，王莽对太后称其暴病。 [[13]](#note-13)


<a id="event-14"></a>

14. **朱博传题。** 卷内叙事由薛氏转入朱博，以下记其由地方吏至宰相的经历。 [[14]](#note-14)


<a id="event-15"></a>

15. **朱博以亭长起家。** 杜陵朱博家贫，少任亭长、功曹，勇于捕搏且好交游，与萧育、陈咸相友。由太常掾察廉后辗转为京兆属吏，任督邮而能职。 [[15]](#note-15)


<a id="event-16"></a>

16. **变名为陈咸营救。** 陈咸泄露省中语被收狱，朱博离职扮作医者入狱，查明案情后再易名奔走举证，助陈咸免死，以此出名。 [[16]](#note-16)


<a id="event-17"></a>

17. **王凤辟入幕府。** 成帝继位后，王凤用陈咸为长史。陈咸荐朱博、萧育入幕，朱博历令三县、理长安，迁冀州刺史。 [[17]](#note-17)


<a id="event-18"></a>

18. **在冀州分类处置陈诉。** 刺史行部时，从事招集数百人拦道，试其应变。朱博当车分别告知申诉渠道，使人迅速散去，后查知是老从事有意安排，将其杀死。 [[18]](#note-18)


<a id="event-19"></a>

19. **在琅邪改变属官作风。** 朱博罢去以称病待慰问为惯例的府吏，让主簿训练大儒赣遂行吏礼，规定衣服尺度并撤议曹。他以奉律令为务，排斥属吏空谈圣王之道。 [[19]](#note-19)


<a id="event-20"></a>

20. **督姑幕游徼追捕。** 姑幕八人当廷报仇逃亡，部吏几请赴县，朱博先责本县当自办，专令游徼王卿追捕；得五人后即加嘉勉，并许县里逐次捕获余党。 [[20]](#note-20)


<a id="event-21"></a>

21. **与薛宣比较左冯翊治术。** 朱博代理左冯翊一年后实授。传称其文理逊于薛宣，而多权变、敢于诛杀，也能将重罪宽贷，属吏因而尽力。 [[21]](#note-21)


<a id="event-22"></a>

22. **用尚方禁并宽治受赂吏。** 朱博借面疤问明尚方禁旧事，释嫌用其访察盗贼和隐奸。又让收贿的府功曹自行写清赃数，确认无隐后削去书录，令其自新留任。 [[22]](#note-22)


<a id="event-23"></a>

23. **大司农降犍为太守。** 朱博任大司农岁余坐小法左迁犍为，以厚结若儿兄弟作反间，袭杀屡次寇盗的若儿。 [[23]](#note-23)


<a id="event-24"></a>

24. **试断疑狱取信法吏。** 朱博迁山阳后病免，又入为廷尉。以自己为武吏当面请法吏拟出疑难旧案，判断十中八九，令属吏折服；传以此说明他每到新任先示不可欺。 [[24]](#note-24)


<a id="event-25"></a>

25. **三公改制数度往复。** 何武建议分三公职，成帝使大司马有印绶官属、改御史大夫为大司空。朱博以旧制监察及升迁有序为由请复御史大夫，获准；哀帝末年又改丞相为大司徒、恢复大司空，确切时间须与本纪和百官表对勘。 [[25]](#note-25)


<a id="event-26"></a>

26. **俭处家室而好士。** 朱博饮食简约，不好酒色游宴，却广纳宾客，荐举愿仕者，有时甚至援助报仇之人。班固以此说明他的声名与后来败亡都和结交方式相关。 [[26]](#note-26)


<a id="event-27"></a>

27. **附傅氏求尊号及朱博自杀。** 傅喜等拒从傅太后尊号之议，朱博与傅晏合作，代孔光为丞相而让还部分食邑。后与赵玄奏夺傅喜、何武爵，哀帝查出傅氏授意，令彭宣等及群臣议罪。赵玄减死、傅晏削户，朱博召下狱前自杀。 [[27]](#note-27)


<a id="event-28"></a>

28. **传末赞题。** 底本单列“贊”字，以下是卷末总评。 [[28]](#note-28)


<a id="event-29"></a>

29. **评薛宣朱博器局与结交。** 班固并举二人由小吏升相。认为薛宣原为能吏、晚以苛察失名；朱博进取借势，先后附王氏、丁傅，终因欺罔被诘而饮药。 [[29]](#note-29)

[返回正文第3条](#event-3)

> 始高陵令陽湛、櫟陽令謝游皆貪猾不遜，持郡短長，前二千石數案不能竟。及宣視事，詣府謁，宣設酒飯與相對，接待甚備。已而陰求其罪臧，具得所受取。宣察湛有改節敬宣之效，乃手自牒書，條其姦臧，封與湛曰：「吏民條言君如牒，或議以為疑於主守盜。馮翊敬重令，又念十金法重，不忍相暴章。故密以手書相曉，欲君自圖進退，可復伸眉於後。即無其事，復封還記，得為君分明之。」湛自知罪臧皆應記，而宣辭語溫潤，無傷害意。湛即時解印綬付吏，為記謝宣，終無怨言。而櫟陽令游自以大儒有名，輕宣。宣獨移書顯責之曰：「告櫟陽令：吏民言令治行煩苛，適罰作使千人以上；賊取錢財數十萬，給為非法；賣買聽任富吏，賈數不可知。證驗以明白，欲遣吏考案，恐負舉者，恥辱儒士，故使掾平鐫令。孔子曰：『陳力就列，不能者止。』令詳思之，方調守。」游得檄，亦解印綬去。

### 25. 三公改制数度往复

[返回正文第25条](#event-25)

<a id="hs083-p031"></a>

**[《汉书·薛宣朱博传》P031](../../拆分史书/汉书/卷083.md#p031)** · [仓内TXT L9255—L9255](../../拆分史书/汉书/卷083.md#part-1-L9255)

> 初，漢興襲秦官，置丞相、御史大夫、太尉。至武帝罷太尉，始置大司馬以冠將軍之號，非有印綬官屬也。及成帝時，何武為九卿，建言「古者民樸事約，國之輔佐必得賢聖，然猶則天三光，備三公官，各有分職。今末俗文弊，政事煩多，宰相之材不能及古，而丞相獨兼三公之事，所以久廢而不治也。宜建三公官，定卿大夫之任，分職授政，以考功效。」其後上以問師安昌侯張禹，禹以為然。時曲陽侯王根為大司馬票騎將軍，而何武為御史大夫。於是上賜曲陽侯根大司馬印綬，置官屬，罷票騎將軍官，以御史大夫何武為大司空，封列侯，皆增奉如丞相，以備三公官焉。議者多以為古今異制，漢自天下之號下至佐史皆不同於古，而獨改三公，職事難分明，無益於治亂。是時御史府吏舍百餘區井水皆竭；又其府中列柏樹，常有野烏數千棲宿其上，晨去暮來，號曰「朝夕烏」，烏去不來者數月，長老異之。後二歲餘，朱博為大司空，奏言「帝王之道不必相襲，各繇時務。高皇帝以聖德受命，建立鴻業，置御史大夫，位次丞相，典正法度，以職相參，總領百官，上下相監臨，歷載二百年，天下安寧。今更為大司空，與丞相同位，未獲嘉祐。故事，選郡國守相高第為中二千石，選中二千石為御史大夫，任職者為丞相，位次有序，所以尊聖德，重國相也。今中二千石未更御史大夫而為丞相，權輕，非所以重國政也。臣愚以為大司空官可罷，復置御史大夫，遵奉舊制。臣願盡力，以御史大夫為百僚率。」哀帝從之，乃更拜博為御史大夫。會大司馬喜免，以陽安侯丁明為大司馬衛將軍，置官屬，大司馬冠號如故事。後四歲，哀帝遂改丞相為大司徒，復置大司空、大司馬焉。

> 初，哀帝祖母定陶太后欲求稱尊號，太后從弟高武侯傅喜為大司馬，與丞相孔光、大司空師丹共持正議。孔鄉侯傅晏亦太后從弟，諂諛欲順指，會博新徵用為京兆尹，與交結，謀成尊號，以廣孝道。繇是師丹先免，博代為大司空，數燕見奏封事，言「丞相光志在自守，不能憂國；大司馬喜至尊至親，阿黨大臣，無益政治。」上遂罷喜遣就國，免光為庶人，以博代光為丞相，封陽鄉侯，食邑二千戶。博上書讓曰：「故事封丞相不滿千戶，而獨臣過制，誠慚懼，願還千戶。」上許焉。傅太后怨傅喜不已，使孔鄉侯晏風丞相，令奏免喜侯。博受詔，與御史大夫趙玄議，玄言「事已前決，得無不宜？」博曰：「已許孔鄉侯有指。匹夫相要，尚相得死，何況至尊？博唯有死耳！」玄即許可。博惡獨斥奏喜，以故大司空氾鄉侯何武前亦坐過免就國，事與喜相似，即并奏：「喜、武前在位，皆無益於治，雖已退免，爵土之封非所當得也。請皆免為庶人。」上知傅太后素常怨喜，疑博、玄承指，即召玄詣尚書問狀。玄辭服，有詔左將軍彭宣與中朝者雜問。宣等劾奏：「博宰相，玄上卿，晏以外親封位特進，股肱大臣，上所信任，不思竭誠奉公，務廣恩化，為百寮先，皆知喜、武前已蒙恩詔決，事更三赦，博執左道，虧損上恩，以結信貴戚，背君鄉臣，傾亂政治，姦人之雄，附下罔上，為臣不忠不道；玄知博所言非法，枉義附從，大不敬；晏與博議免喜，失禮不敬。臣請詔謁者召博、玄、晏詣廷尉詔獄。」制曰：「將軍、中二千石、二千石、諸大夫、博士、議郎議。」右將軍蟜望等四十四人以為「如宣等言，可許。」諫大夫龔勝等十四人以為「春秋之義，姦以事君，常刑不舍。魯大夫叔孫僑如欲顓公室，譖其族兄季孫行父於晉，晉執囚行父以亂魯國，春秋重而書之。今晏放命圮族，干亂朝政，要大臣以罔上，本造計謀，職為亂階，宜與博、玄同罪，罪皆不道。」上減玄死罪三等，削晏戶四分之一，假謁者節召丞相詣廷尉詔獄。博自殺，國除。

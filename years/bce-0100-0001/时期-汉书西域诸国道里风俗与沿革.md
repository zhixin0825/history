# 汉书西域诸国道里风俗与沿革

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **西域范围与河源说。** 本传以武帝时开始通使为起点，按后来的情况说西域由三十六国分为五十余国。记其南北山脉、东西关隘，并汇述葱岭、于阗的水流入蒲昌海后潜行积石的古代河源说。 [[1]](#note-1)


<a id="event-2"></a>

2. **南北两条交通线。** 出玉门、阳关后，南路沿南山北麓经鄯善、莎车，越葱岭至大月氏、安息。北路则经车师前王庭沿北山至疏勒，越葱岭通大宛、康居及奄蔡。 [[2]](#note-2)


<a id="event-3"></a>

3. **日逐王辖西域。** 诸国多有城郭、农田和畜养业，与匈奴、乌孙习俗有别。匈奴日逐王设置僮仆都尉，驻焉耆、危须、尉犁之间，向各国征收赋税。 [[3]](#note-3)


<a id="event-4"></a>

4. **秦长城的西端。** 篇首回顾周衰以后诸戎杂居泾渭一带，又叙秦统一后击退北方部众、修筑长城，指出西界不过临洮。 [[4]](#note-4)


<a id="event-5"></a>

5. **通西域与河西经营。** 由张骞通使及霍去病战事，叙先置酒泉、迁民和分设河西四郡。又说伐大宛后贡使增加，汉从敦煌往盐泽设亭，在轮台、渠犁置田卒，由使者校尉主管接济外使。 [[5]](#note-5)


<a id="event-6"></a>

6. **郑吉与西域都护。** 宣帝先使人护南道。郑吉迎日逐王来降后兼护北道，匈奴的僮仆都尉罢去。篇首把二人封侯连叙于神爵二年，具体封日从功臣表另核。都护治乌垒，领屯田，察西域诸国并相机安抚或出兵。 [[6]](#note-6)


<a id="event-7"></a>

7. **戊己校尉与乌贪訾离。** 元帝时在车师前王庭重置戊己校尉屯田。东蒲类王兹力支率一千七百余人来降，另划车师后国以西土地安置。 [[7]](#note-7)


<a id="event-8"></a>

8. **诸国志的资料范围。** 本传以宣、元以后单于称藩、西域交通趋密，解释土地、山川、王侯、户数及里程资料逐渐详细。 [[8]](#note-8)


<a id="event-9"></a>

9. **婼羌与去胡来王。** 婼羌在大路西南，王号去胡来王，四百五十户。居民随畜逐水草，倚且末、鄯善供谷，山有铁，可自制兵器。 [[9]](#note-9)


<a id="event-10"></a>

10. **鄯善國。** 以下记鄯善國的地理、人口、设官及往来。 [[10]](#note-10)


<a id="event-11"></a>

11. **鄯善地理民生。** 鄯善即旧楼兰，治扞泥城，共一千五百七十户。沙盐地少田，多养骆驼，有玉石和水泽草木，田谷仰赖旁国。 [[11]](#note-11)


<a id="event-12"></a>

12. **赵破奴攻楼兰、姑师。** 楼兰、姑师扼路袭汉使，武帝派赵破奴、王恢出兵，赵破奴以轻骑先到，俘楼兰王、击破姑师，二人受封，汉亭障继伸至玉门。 [[12]](#note-12)


<a id="event-13"></a>

13. **楼兰两面遣质。** 汉、匈奴相继施压，楼兰各送一子为质。李广利伐宛时楼兰参与遮断后使，任文奉诏捕王来问；王以小国两属自保答辩，获准归国。 [[13]](#note-13)


<a id="event-14"></a>

14. **楼兰王室与汉使冲突。** 征和元年王死后，在汉质子因已受宫刑未能归立。继任者死后，在匈奴质子先归立为尝归。楼兰承接送使负担又屡受侵扰，随后助匈奴遮杀汉使，王弟尉屠耆来汉陈状。 [[14]](#note-14)


<a id="event-15"></a>

15. **自鄯善西行。** 鄯善扼交通要冲，西至且末七百二十里。作者说明且末以西各国多种谷蓄畜，以下集中记录不相同的地方。 [[15]](#note-15)


<a id="event-16"></a>

16. **且末國。** 以下记且末國的地理、人口、设官及往来。 [[16]](#note-16)


<a id="event-17"></a>

17. **且末城与西路。** 记王城、二百三十户与官属，北邻尉犁，南通小宛，西行两千里达精绝，有葡萄等果品。 [[17]](#note-17)


<a id="event-18"></a>

18. **小宛國。** 以下记小宛國的地理、人口、设官及往来。 [[18]](#note-18)


<a id="event-19"></a>

19. **小宛在南偏道。** 王住扜零城，百五十户，东接婼羌，位于南方偏远处，主道不经此地。 [[19]](#note-19)


<a id="event-20"></a>

20. **精絕國。** 以下记精絕國的地理、人口、设官及往来。 [[20]](#note-20)


<a id="event-21"></a>

21. **精绝里程与隘道。** 王治精绝城，四百八十户，设都尉、将与译长。往戎卢需四日，地势狭隘，西通抒弥。 [[21]](#note-21)


<a id="event-22"></a>

22. **戎盧國。** 以下记戎盧國的地理、人口、设官及往来。 [[22]](#note-22)


<a id="event-23"></a>

23. **戎卢王城与邻国。** 治卑品城，二百四十户，东小宛、南婼羌、西渠勒，远离南路交通干线。 [[23]](#note-23)


<a id="event-24"></a>

24. **抒彌國。** 以下记抒彌國的地理、人口、设官及往来。 [[24]](#note-24)


<a id="event-25"></a>

25. **抒弥户口及别名。** 王治抒弥城，三千三百四十户、二万四十人，设侯、将、都尉等。南邻渠勒，西到于阗，传又记后来称宁弥。 [[25]](#note-25)


<a id="event-26"></a>

26. **渠勒國。** 以下记渠勒國的地理、人口、设官及往来。 [[26]](#note-26)


<a id="event-27"></a>

27. **渠勒地理。** 王治鞬都城，三百一十户。东戎卢、西婼羌、北抒弥，东北可到都护治所。 [[27]](#note-27)


<a id="event-28"></a>

28. **于闐國。** 以下记于闐國的地理、人口、设官及往来。 [[28]](#note-28)


<a id="event-29"></a>

29. **于阗水系和玉石。** 治西城，三千三百户，产玉。书中以于阗附近为两向水系之分，西流注西海，东流注盐泽，并列邻国。 [[29]](#note-29)


<a id="event-30"></a>

30. **皮山國。** 以下记皮山國的地理、人口、设官及往来。 [[30]](#note-30)


<a id="event-31"></a>

31. **皮山与南行岔路。** 王治皮山城，五百户，南接天笃，往西南进入罽宾、乌弋山离路线，西北通莎车。 [[31]](#note-31)


<a id="event-32"></a>

32. **烏秅國。** 以下记烏秅國的地理、人口、设官及往来。 [[32]](#note-32)


<a id="event-33"></a>

33. **乌秅山居与县度。** 乌秅在山间耕种，以积石筑屋，产小步马。西面县度是溪谷隔断的石山，行人需借绳索相引渡过。 [[33]](#note-33)


<a id="event-34"></a>

34. **西夜國。** 以下记西夜國的地理、人口、设官及往来。 [[34]](#note-34)


<a id="event-35"></a>

35. **西夜与子合。** 西夜王号子合王，治呼犍谷，三百五十户；居民逐水草，作者将蒲犁、依耐、无雷并列为相近类型，并记子合产玉。 [[35]](#note-35)


<a id="event-36"></a>

36. **蒲犁國。** 以下记蒲犁國的地理、人口、设官及往来。 [[36]](#note-36)


<a id="event-37"></a>

37. **蒲犁与寄田。** 治蒲犁谷，六百五十户，扼莎车、疏勒、无雷之间。风俗与子合相同，在莎车寄田。 [[37]](#note-37)


<a id="event-38"></a>

38. **依耐國。** 以下记依耐國的地理、人口、设官及往来。 [[38]](#note-38)


<a id="event-39"></a>

39. **依耐缺谷。** 依耐百二十五户，南接子合，习俗相通，本地少谷而寄田疏勒、莎车；传列诸地里程。 [[39]](#note-39)


<a id="event-40"></a>

40. **無雷國。** 以下记無雷國的地理、人口、设官及往来。 [[40]](#note-40)


<a id="event-41"></a>

41. **无雷城及习俗。** 治无雷城，千户七千人，北邻捐毒、西接大月氏；服装近乌孙，风俗近子合。 [[41]](#note-41)


<a id="event-42"></a>

42. **難兜國。** 以下记難兜國的地理、人口、设官及往来。 [[42]](#note-42)


<a id="event-43"></a>

43. **难兜的人口和矿产。** 难兜五千户、八千胜兵，属罽宾。种谷果，产金银铜铁，制造兵器的方式与邻国相近。 [[43]](#note-43)


<a id="event-44"></a>

44. **罽賓國。** 以下记罽賓國的地理、人口、设官及往来。 [[44]](#note-44)


<a id="event-45"></a>

45. **罽宾的辖属与路线。** 王治循鲜城，人口、兵员较多，超出都护直辖，其东可往乌秅，东北通难兜，西向与两个大国接壤。 [[45]](#note-45)


<a id="event-46"></a>

46. **塞人迁徙。** 记匈奴破月氏后，月氏西向大夏，塞王南下罽宾；休循、捐毒等亦被说成旧塞种分支。 [[46]](#note-46)


<a id="event-47"></a>

47. **罽宾物产和交易。** 罽宾水土温润，产稻、谷果和多种木材；居民擅雕、织绣，市用金银币，两面为骑马和人面，又有大象、珊瑚等。 [[47]](#note-47)


<a id="event-48"></a>

48. **罽宾王更替与两度杀使。** 武帝初通罽宾，乌头劳多杀汉使。后文忠与阴末赴合谋杀其继王、立阴末赴，阴末赴又囚赵德并杀随使，元帝终于断绝来往。 [[48]](#note-48)


<a id="event-49"></a>

49. **乌弋山离国位置。** 此为不属都护的大国，距长安一万二千二百里，东邻罽宾、西通犁靬、条支。 [[49]](#note-49)


<a id="event-50"></a>

50. **条支及西海传闻。** 条支临西海，湿热种稻，安息将其视为属国外域。记大鸟、幻术和弱水、西王母传闻，并明确说安息长者也未见。 [[50]](#note-50)


<a id="event-51"></a>

51. **乌弋的币制与南道终点。** 乌弋气候物产多似罽宾，有狮等异兽，钱币以人头、骑马为文。汉使罕至，本传视之为南路尽头，转向可至安息。 [[51]](#note-51)


<a id="event-52"></a>

52. **安息國。** 以下记安息國的地理、人口、设官及往来。 [[52]](#note-52)


<a id="event-53"></a>

53. **安息的市场和文字。** 安息不属都护，所领城邑众多，商旅用车船往来，文书横写。银币两面铸王、夫人像，王死改铸。 [[53]](#note-53)


<a id="event-54"></a>

54. **安息与汉初通使。** 武帝始遣使至安息，安息王派骑兵至东界迎接，又遣本国使者来汉，献大鸟卵与犁靬幻术艺人。 [[54]](#note-54)


<a id="event-55"></a>

55. **大月氏國。** 以下记大月氏國的地理、人口、设官及往来。 [[55]](#note-55)


<a id="event-56"></a>

56. **大月氏王庭、户口与物产。** 王治监氏城，不属都护，记户十万、口四十万；钱货、风土与安息相似，出单峰骆驼。 [[56]](#note-56)


<a id="event-57"></a>

57. **大月氏西迁与小月氏。** 大月氏原游牧在敦煌、祁连间，遭冒顿进击、老上杀其王，遂经大宛西制大夏。部分未移走的靠近南山羌，称小月氏。 [[57]](#note-57)


<a id="event-58"></a>

58. **大夏城邑和五翕侯。** 大夏各城本有小长，月氏西来后使其臣服并负责供使。休密、双靡、贵霜、肸顿、离附五翕侯均属月氏，逐一记治城和里程。 [[58]](#note-58)


<a id="event-59"></a>

59. **康居國。** 以下记康居國的地理、人口、设官及往来。 [[59]](#note-59)


<a id="event-60"></a>

60. **康居的冬夏驻地。** 冬居乐越匿、夏驻蕃内，记十二万户及六十万人，风俗与月氏相似，不属汉都护而向东羁事匈奴。 [[60]](#note-60)


<a id="event-61"></a>

61. **郅支西依康居与遭击灭。** 宣帝时匈奴诸单于相争，郅支后来杀汉使、西依康居。甘延寿、陈汤最终率兵入康居杀郅支，本段把战事明系元帝建昭三年。 [[61]](#note-61)


<a id="event-62"></a>

62. **奄蔡与北方大泽。** 奄蔡约在康居西北两千里，习俗相近，能骑射者众多；所临大泽被作者推测为北海。 [[62]](#note-62)


<a id="event-63"></a>

63. **康居五小王。** 列苏薤、附墨、窳匿、罽、奥鞬五王的城市，并比较各地距都护、阳关的里程；五王均属康居。 [[63]](#note-63)


<a id="event-64"></a>

64. **大宛國。** 以下记大宛國的地理、人口、设官及往来。 [[64]](#note-64)


<a id="event-65"></a>

65. **大宛王城与酿酒。** 王治贵山城，有六万户、三十万人，与康居、月氏相接。常以葡萄为酒，富者藏酒数十年，马喜苜蓿。 [[65]](#note-65)


<a id="event-66"></a>

66. **大宛别邑与汗血马。** 大宛有七十余别邑，盛产好马；汗血马为天马之后是传述的说法。 [[66]](#note-66)


<a id="event-67"></a>

67. **两次伐宛与善马协议。** 汉以金马求马不成，使者被杀，李广利两次远征。宛人杀毋寡、献马，汉军立昧蔡；昧蔡遭杀后蝉封继立，恢复遣子、岁献天马，汉使带回葡萄、苜蓿。 [[67]](#note-67)


<a id="event-68"></a>

68. **大宛到安息的风俗。** 各地语言虽异仍可沟通，重商贾且妇女意见受尊重。原无丝、漆，铁兵铸作由降留者传入，所得汉金银多作器用。 [[68]](#note-68)


<a id="event-69"></a>

69. **西域接待汉匈使节的变化。** 叙乌孙至安息原对持匈奴凭信的使者供给优先，汉使须自购粮畜；呼韩邪入朝之后，对汉的礼敬增加。 [[69]](#note-69)


<a id="event-70"></a>

70. **桃槐國。** 以下记桃槐國的地理、人口、设官及往来。 [[70]](#note-70)


<a id="event-71"></a>

71. **桃槐户口。** 桃槐王地距长安一万一千零八十里，记七百户、五千人、可用兵千人。 [[71]](#note-71)


<a id="event-72"></a>

72. **休循國。** 以下记休循國的地理、人口、设官及往来。 [[72]](#note-72)


<a id="event-73"></a>

73. **休循的居地和来源。** 休循在葱岭西鸟飞谷，三百五十八户，迁牧逐水草，服俗近乌孙，被视为故塞种。 [[73]](#note-73)


<a id="event-74"></a>

74. **捐毒國。** 以下记捐毒國的地理、人口、设官及往来。 [[74]](#note-74)


<a id="event-75"></a>

75. **捐毒的邻接与迁牧。** 王治衍敦谷，三百八十户，南依葱岭、西通休循、北接乌孙，居民循水草而居，为旧塞种。 [[75]](#note-75)


<a id="event-76"></a>

76. **莎車國。** 以下记莎車國的地理、人口、设官及往来。 [[76]](#note-76)


<a id="event-77"></a>

77. **莎车官职和矿石。** 治莎车城，二千三百三十九户，置辅国侯、将、都尉、译长，西通疏勒，西南至蒲犁，山有铁及青玉。 [[77]](#note-77)


<a id="event-78"></a>

78. **万年被杀与冯奉世讨莎车。** 莎车无嗣，请立乌孙公主之子万年。万年被旧王弟呼屠徵杀害，汉使亦死；冯奉世调诸国兵平乱，另立莎车王，回朝拜光禄大夫。 [[78]](#note-78)


<a id="event-79"></a>

79. **疏勒國。** 以下记疏勒國的地理、人口、设官及往来。 [[79]](#note-79)


<a id="event-80"></a>

80. **疏勒的位置与市场。** 王治疏勒城，千五百一十户，阛阓交易发达，向西可通大月氏、大宛、康居。 [[80]](#note-80)


<a id="event-81"></a>

81. **尉頭國。** 以下记尉頭國的地理、人口、设官及往来。 [[81]](#note-81)


<a id="event-82"></a>

82. **尉头山路和风俗。** 尉头三百户，与疏勒之间山道不通，前往捐毒另有捷路，服装近乌孙，畜牧随水草。 [[82]](#note-82)


<a id="event-83"></a>

### 1. 西域范围与河源说

[返回正文第1条](#event-1)

<a id="hs096-p001"></a>

**[《汉书·西域传》P001](../../sources/摘录/汉书-卷096-西域传.md#p001)** · [仓内TXT L9949—L9949](../../sources/本地分卷/汉书/汉书-卷096.md#L9949)

> 西域以孝武時始通，本三十六國，其後稍分至五十餘，皆在匈奴之西，烏孫之南。南北有大山，中央有河，東西六千餘里，南北千餘里。東則接漢，厄以玉門、陽關，西則限以蔥嶺。其南山，東出金城，與漢南山屬焉。其河有兩原：一出蔥嶺出，一出于闐。于闐在南山下，其河北流，與蔥嶺河合，東注蒲昌海。蒲昌海，一名鹽澤者也，去玉門、陽關三百餘里，廣袤三四百里。其水亭居，冬夏不增減，皆以為潛行地下，南出於積石，為中國河云。

> 征和元年，樓蘭王死，國人來請質子在漢者，欲立之。質子常坐漢法，下蠶室宮刑，故不遣。報曰：「侍子，天子愛之，不能遣。其更立其次當立者。」樓蘭更立王，漢復責其質子，亦遣一子質匈奴。後王又死，匈奴先聞之，遣質子歸，得立為王。漢遣使詔新王，令入朝，天子將加厚賞。樓蘭王后妻，故繼母也，謂王曰：「先王遣兩子質漢皆不還，奈何欲往朝乎？」王用其計，謝使曰：「新立，國未定，願待後年入見天子。」然樓蘭國最在東垂，近漢，當白龍堆，乏水草，常主發導，負水儋糧，送迎漢使，又數為吏卒所寇，懲艾不便與漢通。後復為匈奴後間，數遮殺漢使。其弟尉屠耆降漢，具言狀。

> 初，貳師將軍李廣利擊大宛，還過杅彌，杅彌遣太子賴丹為質於龜茲。廣利責電茲曰：「外國皆臣屬於漢，龜茲何以得受杅彌質？」即將賴丹入至京師。昭帝乃用桑弘羊前議，以杅彌太子賴丹為校尉，將軍田輪台，輪台與渠犁地皆相連也。龜茲貴人姑翼謂其王曰：「賴丹本臣屬吾國，今佩漢印綬來，迫吾國而田，必為害。」王即殺賴丹，而上書謝漢，漢未能征。

### 109. 姑翼伏诛及龟兹王夫妇来朝

[返回正文第109条](#event-109)

> 宣帝時，長羅侯常惠使烏孫還，便宜發諸國兵，合五萬人攻龜茲，責以前殺校尉賴丹。龜茲王謝曰：「乃我先王時為貴人姑翼所誤，我無罪。」執姑翼詣惠，惠斬之。時烏孫公主遣女來至京師學鼓琴，漢遣侍郎樂奉送主女，過龜茲。龜茲前遣人至烏孫求公主女，未還。會女過龜茲，龜茲王留不遣，復使使報公主，主許之。後公主上書，願令女比宗室入朝，而龜茲王絳賓亦受其夫人，上書言得尚漢外孫為昆弟，願與公主女俱入朝。元康元年，遂來朝賀。王及夫人皆賜印綬。夫人號稱公主，賜以車騎旗鼓，歌吹數十人，綺繡雜繒琦珍凡數千萬。留且一年，厚贈送之。後數來朝賀，樂漢衣服制度，歸其國，治宮室，作檄道周衛，出入傳呼，撞鐘鼓，如漢家儀。外國胡人皆曰：「驢非驢，馬非馬，若龜茲王，所謂騾也。」絳賓死，其子丞德自謂漢外孫，成、哀帝時往來尤數，漢遇之亦甚親密。

### 152. 赞语兼论富庶、远略与耗损

[返回正文第152条](#event-152)

<a id="hs096-p170"></a>

**[《汉书·西域传》P170](../../sources/摘录/汉书-卷096-西域传.md#p170)** · [仓内TXT L10118—L10118](../../sources/本地分卷/汉书/汉书-卷096.md#L10118)

> 遭值文、景玄默，養民五世，天下殷富，財力有餘，士馬強盛。故能睹犀布、玳瑁則建珠崖七郡，感枸醬、竹杖則開牂柯、越巂，聞天馬、蒲陶則通大宛、安息。自是之後，明珠、文甲、通犀、翠羽之珍盈於後宮，薄梢、龍文、魚目、汗血之馬充於黃門，巨像、師子、猛犬、大雀之群食於外囿。殊方異物，四面而至。於是廣開上林，穿昆明池，營千門萬戶之宮，立神明通天之台，興造甲乙之帳，落以隨珠和璧，天子負黼依，襲翠被，馮玉幾，而處其中。設酒池肉林以饗四夷之客，作《巴俞》都盧、海中《碭極》、漫衍魚龍、角抵之戲以觀視之。及賂遺贈送，萬里相奉，師旅之費，不可勝計。至於用度不足，乃榷酒酤，管鹽鐵，鑄白金，造皮幣，算至車船，租及六畜。民力屈，財力竭，因之以凶年，寇盜並起，道路不通，直指之使始出，衣繡杖斧，斷斬於郡國，然後勝之。是以末年遂棄輪台之地，而下哀痛之詔，豈非仁聖之所悔哉！且通西域，近有龍堆，遠則蔥嶺，身熱、頭痛、縣度之厄。淮南、杜欽、揚雄之論，皆以為此天地所以界別區域，絕外內也。《書》曰「西戎即序」，禹即就而序之，非上威服致其貢物也。

> 西域諸國，各有君長，兵眾分弱，無所統一，雖屬匈奴，不相親附。匈奴能得其馬畜旃罽，而不能統率與之進退。與漢隔絕，道裡又遠，得之不為益，棄之不為損。盛德在我，無取於彼。故自建武以來，西域思漢威德，鹹樂內屬。唯其小邑鄯善、車師，界迫匈奴，尚為所拘。而其大國莎車、于闐之屬，數遣使置質於漢，願請屬都護。聖上遠覽古今，因時之宜，羈縻不絕，辭而未許。雖大禹之序西戎，周公之讓白雉，太宗之卻走馬，義兼之矣，亦何以尚茲！

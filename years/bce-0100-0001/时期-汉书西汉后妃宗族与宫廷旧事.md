# 汉书西汉后妃宗族与宫廷旧事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **外戚兴衰与夫妇之礼。** 篇首以涂山、末喜、妲己和褒姒等兴亡故事说明后妃外家可能助成或危害王朝，援经论夫妇人伦，也指出子姓繁盛仍无从预知结局。 [[1]](#note-1)


<a id="event-2"></a>

2. **皇太后、皇后及后宫秩位。** 汉承秦号，帝母、祖母与嫡妻的称号各异。武帝增设婕妤等，元帝增设昭仪，传按禄秩、爵比列诸等级，并说较低位者葬司马门外。 [[2]](#note-2)


<a id="event-3"></a>

3. **高祖呂皇后。** 以下为高祖呂皇后的传记。 [[3]](#note-3)


<a id="event-4"></a>

4. **吕家从征与吕公去世。** 吕后曾辅佐刘邦，兄吕泽、吕释之皆从征受封，与吕公共三侯。汉王四年吕公去世。 [[4]](#note-4)


<a id="event-5"></a>

5. **孝惠張皇后。** 以下为孝惠張皇后的传记。 [[5]](#note-5)


<a id="event-6"></a>

6. **张皇后及惠帝立嗣。** 鲁元公主与张敖之女被选为惠后。吕太后因张后无子，令其假称有孕，将宫人生子冒认为皇后出，杀生母，立其子为嗣。 [[6]](#note-6)


<a id="event-7"></a>

7. **少帝被废及张后退居。** 前少帝出言怨太后被幽杀，吕后改立刘弘。诸吕败后少帝等因被视为非惠帝子而遭诛，张后独退北宫，文帝后元元年去世。 [[7]](#note-7)


<a id="event-8"></a>

8. **高祖薄姬。** 以下为高祖薄姬的传记。 [[8]](#note-8)


<a id="event-9"></a>

9. **薄姬入魏、再入汉。** 薄姬由母送入魏王豹宫。传把魏豹另择立场与许负相术相联；魏亡后薄姬入汉织室，后被刘邦召置后宫。 [[9]](#note-9)


<a id="event-10"></a>

10. **薄姬受幸及往代。** 旧伴管、赵二人先得幸，叙及旧约引刘邦召薄姬。她生刘恒，恒封代王后吕后未扣留她，得随子前往代国。 [[10]](#note-10)


<a id="event-11"></a>

11. **迎代王、尊薄太后。** 诛吕后大臣认为薄家仁善，迎代王，是为文帝。尊其母为皇太后，封薄昭，追尊外祖父母并官置园邑、赏赐外家。 [[11]](#note-11)


<a id="event-12"></a>

12. **孝文竇皇后。** 以下为孝文竇皇后的传记。 [[12]](#note-12)


<a id="event-13"></a>

13. **窦姬误入代宫。** 吕后分宫人给诸侯王，窦姬欲往赵以便近家，因名籍误置而去代，受代王宠幸；生馆陶公主，惠帝七年生刘启。 [[13]](#note-13)


<a id="event-14"></a>

14. **窦皇后母子受册。** 代王原后及其四子相继病死，刘启以诸子中年长者被立太子，窦姬为后、嫖为公主。少子刘武封代，后来改梁。 [[14]](#note-14)


<a id="event-15"></a>

15. **追封窦后父母。** 窦后父母早葬观津，薄太后命追封并置二百家园邑，以薄太后父园仪制奉守。 [[15]](#note-15)


<a id="event-16"></a>

16. **窦广国寻亲。** 窦广国幼年遭掠卖，幸免于山岸崩塌，到长安以童年记忆自证为皇后弟。周勃等为外戚择有节者相处，以防重现吕氏专权。 [[16]](#note-16)


<a id="event-17"></a>

17. **窦家封侯与窦婴平吴楚。** 窦后患病失明，景帝继位后尊其为太后，封广国、彭祖。吴楚乱时窦婴以大将军立功，封魏其侯。 [[17]](#note-17)


<a id="event-18"></a>

18. **窦太后崇黄老及崩年。** 窦太后好黄老，景帝及窦氏从学。仓内原文写“元光六年”，与武帝本纪建元六年及“后景帝六岁”不符，释读按两证注明。 [[18]](#note-18)


<a id="event-19"></a>

19. **孝景薄皇后。** 以下为孝景薄皇后的传记。 [[19]](#note-19)


<a id="event-20"></a>

20. **薄皇后废居及去世。** 薄家女由薄太后配刘启，景帝即位为后，无子无宠，后来被废，最终葬平望亭南。 [[20]](#note-20)


<a id="event-21"></a>

21. **孝景王皇后。** 以下为孝景王皇后的传记。 [[21]](#note-21)


<a id="event-22"></a>

22. **臧儿与王夫人入太子家。** 臧儿先嫁王仲又嫁田氏。长女原为金氏妇，后入太子宫生三女一男。男为刘彻，当刘荣初立为太子时，封胶东王。 [[22]](#note-22)


<a id="event-23"></a>

23. **馆陶改与王夫人结亲。** 馆陶公主欲嫁女给太子而为栗姬所拒，转与王夫人约婚，屡向景帝攻讦栗姬。景帝托栗姬照看诸子遭拒，心怀不满。 [[23]](#note-23)


<a id="event-24"></a>

24. **废刘荣、立王后和刘彻。** 王夫人暗令催奏立栗姬为后，景帝怒杀奏者，废刘荣为临江王。后来王夫人立为后，刘彻为太子，王信受侯封。 [[24]](#note-24)


<a id="event-25"></a>

25. **王后姐妹的子女。** 王后女弟儿姁同入太子家，早卒，四子皆王；王后的三个女儿为平阳、南宫、隆虑公主。 [[25]](#note-25)


<a id="event-26"></a>

26. **尊王太后与王田两家爵赏。** 武帝即位尊母，尊外祖母臧儿为平原君，封田蚡、田胜；田蚡后来入相，王仲、臧儿各有园邑奉葬。 [[26]](#note-26)


<a id="event-27"></a>

27. **访王后旧女及太后去世。** 武帝得韩嫣告知，亲往接同母姊入宫，厚加赏赐，号修成君。传又记其子依势横行，王太后元朔三年崩。 [[27]](#note-27)


<a id="event-28"></a>

28. **孝武陳皇后。** 以下为孝武陳皇后的传记。 [[28]](#note-28)


<a id="event-29"></a>

29. **陈皇后出身。** 陈皇后为馆陶长公主与陈午之女。她的曾祖陈婴先从项羽、后归汉受封堂邑侯。 [[29]](#note-29)


<a id="event-30"></a>

30. **陈皇后巫蛊案与废黜。** 馆陶曾助刘彻立储，陈氏为妃后立后。无子、卫子夫得宠后发生楚服巫蛊案，牵连多人被诛，陈后被收玺退长门宫。 [[30]](#note-30)


<a id="event-31"></a>

31. **陈午、陈须及废后结局。** 陈午卒后陈须承侯，馆陶寡居私近董偃。公主后去世，陈须与兄弟因财产、淫乱事触法自杀，陈后再后数年卒。 [[31]](#note-31)


<a id="event-32"></a>

32. **孝武衛皇后。** 以下为孝武衛皇后的传记。 [[32]](#note-32)


<a id="event-33"></a>

33. **卫子夫入宫及立后。** 卫子夫原为平阳公主家歌者，武帝见后召入。再次晋见怀孕，兄弟入侍，元朔元年生刘据，于是册后。 [[33]](#note-33)


<a id="event-34"></a>

34. **卫青、霍去病和亲族功封。** 卫青征匈奴受长平侯、三子亦侯；卫后姊子霍去病以功侯并位大司马骠骑，卫青为大司马大将军，后娶平阳公主。 [[34]](#note-34)


<a id="event-35"></a>

35. **刘据立储与卫后巫蛊之死。** 卫后立后七年刘据为太子。江充治巫蛊时，刘据与后发兵杀江充，败走；皇后被收策玺后自杀。宣帝后来追谥并改葬。 [[35]](#note-35)


<a id="event-36"></a>

36. **孝武李夫人。** 以下为孝武李夫人的传记。 [[36]](#note-36)


<a id="event-37"></a>

37. **李延年歌与李夫人入宫。** 武帝听李延年歌，平阳公主转荐其妹。李夫人入宫生昌邑王，早亡；武帝崩后霍光循旧意追尊其配食。 [[37]](#note-37)


<a id="event-38"></a>

38. **李夫人拒以病容见帝。** 夫人遮面托付子弟，解释以容貌受宠者一旦失色易被遗忘，故要保全武帝对亲族的怜念。其卒以后礼葬，兄弟后来得官爵。 [[38]](#note-38)


<a id="event-39"></a>

39. **少翁致神传说及悼亡诗赋。** 少翁借灯烛帷帐布置使武帝远观似李夫人之影，传录武帝哀思所作诗歌，并引悼赋。此传与其他文本所指亡者不同。 [[39]](#note-39)


<a id="event-40"></a>

40. **悼李夫人赋正文。** 从容美早逝、新宫不归写起，以幽墓、秋落和梦见又失描绘亡魂渐远、思念如水的哀痛。 [[40]](#note-40)


<a id="event-41"></a>

41. **悼赋尾声。** 尾声压缩年华骤陨、亲人哀泣、稚子失怙等意象，慨叹亡人赴幽冥不再回宫。 [[41]](#note-41)


<a id="event-42"></a>

42. **李家结局。** 追叙李季涉后宫罪、李广利降匈奴最终累及家族；两案分别跨年。 [[42]](#note-42)


<a id="event-43"></a>

43. **孝武鉤弋趙婕妤。** 以下为孝武鉤弋趙婕妤的传记。 [[43]](#note-43)


<a id="event-44"></a>

44. **钩弋夫人的早年。** 望气传说称武帝到河间召一名拳手女子，亲手展开其手而宠幸。其父曾受宫刑为中黄门。 [[44]](#note-44)


<a id="event-45"></a>

45. **刘弗陵出生、将立为储。** 婕妤生刘弗陵，传以十四月怀孕比尧；后因原太子败、诸王不宜而拟立年少弗陵，又虑母少专权。原“元始三年”与武帝年号不合。 [[45]](#note-45)


<a id="event-46"></a>

46. **钩弋死、昭帝立及追尊。** 本传说婕妤于甘泉受责忧死，后立刘弗陵、命霍光辅政。昭帝为亡母起云陵，追尊外祖并具体赐予外家。 [[46]](#note-46)


<a id="event-47"></a>

47. **孝昭上官皇后。** 以下为孝昭上官皇后的传记。 [[47]](#note-47)


<a id="event-48"></a>

48. **上官桀受知与遗诏辅政。** 上官桀以持盖及侍疾被武帝赏识，由厩令至太仆。武帝病时以桀、霍光等辅少主；桀以捕反者莽通旧功受封。 [[48]](#note-48)


<a id="event-49"></a>

49. **上官氏借盖主之力入宫。** 上官安、霍光联姻。安借丁外人向盖长公主求助，将幼女送入昭帝后宫，先为婕妤后为皇后。 [[49]](#note-49)


<a id="event-50"></a>

50. **上官安骄纵及合谋败亡。** 安因后父身份封侯升将，屡请厚报丁外人不获，与上官桀、长公主、燕王等合谋反霍光，事泄族诛；皇后幼小又是霍氏外孙，获免。 [[50]](#note-50)


<a id="event-51"></a>

51. **霍光求上官后专宠。** 霍光想使外孙女独得宠并有子；近侍太医以昭帝病为由限制内幸，传记衣带禁令。 [[51]](#note-51)


<a id="event-52"></a>

52. **衛太子史良娣。** 以下为衛太子史良娣的传记。 [[52]](#note-52)


<a id="event-53"></a>

53. **史良娣入卫太子宫。** 列太子正妃、良娣、孺子三等。史氏鲁人，元鼎四年入为良娣，生史皇孙刘进，后来是宣帝祖母。 [[53]](#note-53)


<a id="event-54"></a>

54. **史家封侯与史高辅政。** 宣帝后来即位，史高、史曾、史玄及史高之子丹因旧恩或功劳封侯。史高最终辅元帝，史家封爵有先后。 [[54]](#note-54)


<a id="event-55"></a>

55. **史皇孫王夫人。** 以下为史皇孫王夫人的传记。 [[55]](#note-55)


<a id="event-56"></a>

56. **王翁须生宣帝及获追尊。** 王翁须太始中入史皇孙家，征和二年生宣帝，巫蛊后家人子遇害。宣帝即位后追尊、改葬母亲。 [[56]](#note-56)


<a id="event-57"></a>

57. **查访宣帝外祖母。** 朝廷靠任宣等审问乡里、亲族，认得王媼及失散的外家，给外祖母号博平君，封两舅并迁其家入京。 [[57]](#note-57)


<a id="event-58"></a>

58. **外祖父母追封与合葬。** 王迺始本始四年已病卒，后来赐谥、置邑守墓；博平君去世后朝廷将二人合葬并调整奉守。 [[58]](#note-58)


<a id="event-59"></a>

59. **孝宣許皇后。** 以下为孝宣許皇后的传记。 [[59]](#note-59)


<a id="event-60"></a>

60. **许广汉际遇与许后早年。** 许广汉误取马鞍受宫刑，后因官事再受处分。刘病已住掖庭时，经许广汉将女配予皇曾孙；宣帝即位后立为皇后，广汉先号昌成君。 [[60]](#note-60)


<a id="event-61"></a>

61. **许后园陵及许氏封爵。** 许后谥恭哀葬杜南。刘奭立太子以后许广汉封平恩侯，许舜、许延寿随后因宣帝旧恩封侯。 [[61]](#note-61)


<a id="event-62"></a>

62. **孝宣霍皇后。** 以下为孝宣霍皇后的传记。 [[62]](#note-62)


<a id="event-63"></a>

63. **霍成君入宫立后。** 许后被谋害后，霍显为女准备入宫器物，促霍光送女，成君获立。 [[63]](#note-63)


<a id="event-64"></a>

64. **霍皇后待遇、涉太子案及廢死。** 对照许后与霍后生活排场，记霍显谋毒太子未成。霍氏败后霍皇后废处宫中，多年后徙云林馆而自杀。 [[64]](#note-64)


<a id="event-65"></a>

65. **霍氏四侯。** 霍光及兄霍去病各因军功获爵，宣帝因霍光又侯霍山、霍云，合称四侯。 [[65]](#note-65)


<a id="event-66"></a>

66. **孝宣王皇后。** 以下为孝宣王皇后的传记。 [[66]](#note-66)


<a id="event-67"></a>

67. **王奉光家与王婕妤。** 王奉光之家世代有侯爵经历，宣帝民间时与其相识。奉光女婚姻屡未成，后在宣帝宫为婕妤。 [[67]](#note-67)


<a id="event-68"></a>

68. **王皇后养太子与历代太后。** 宣帝择无子的谨慎王婕妤为后，养许后之子，并封其父。王后后历元帝、成帝，被尊为皇太后、太皇太后。 [[68]](#note-68)


<a id="event-69"></a>

69. **孝元王皇后。** 以下为孝元王皇后的传记。 [[69]](#note-69)


<a id="event-70"></a>

70. **王政君及王氏外家。** 王皇后为成帝母，外家十侯、五大司马，详细事件见《元后传》。 [[70]](#note-70)


<a id="event-71"></a>

71. **孝成許皇后。** 以下为孝成許皇后的传记。 [[71]](#note-71)


<a id="event-72"></a>

72. **元帝择许嘉女配太子。** 元帝念许后早死，择许嘉女为太子妃，派亲近侍从送迎；许妃先在东宫颇得宠。 [[72]](#note-72)


<a id="event-73"></a>

73. **许嘉与王凤并辅政。** 成帝时许嘉和王凤分别居车骑、大将军，杜钦建议王凤以尊礼待许嘉。王凤日亲许氏退，许嘉免而就国。 [[73]](#note-73)


<a id="event-74"></a>

74. **削减许后宫用度。** 许后懂书史，长期得宠；太后及帝舅忧绝嗣，劉向、谷永借灾异分析后宫，成帝削其支用，许后上疏。 [[74]](#note-74)


<a id="event-75"></a>

75. **许后自陈宫内支用。** 许后以谦辞自陈，随后具体解释支用、封赠已受限制，指出宫中原例及官吏越分阻抑的顾虑。 [[75]](#note-75)


<a id="event-76"></a>

76. **许后申辩用度旧例。** 她说尚贵时官吏亦多掣肘，今支用再限更无可诉，说明私府取给及历来宫中支用惯例。 [[76]](#note-76)


<a id="event-77"></a>

77. **许后向成帝请酌定。** 她愿减车驾与若干支出，乞保旧例中的服用赠予，不使约束失去人情，并将意见完全交给皇帝。 [[77]](#note-77)


<a id="event-78"></a>

78. **成帝的答诏。** 过渡句，点明以下皇帝答书采用刘向、谷永对灾异和后宫之说。 [[78]](#note-78)


<a id="event-79"></a>

79. **答书借日食论后宫与等级。** 以日为王者象，以阴掩阳为失序，列《春秋》日食及其政治解读，转以天象要求约束后宫。 [[79]](#note-79)


<a id="event-80"></a>

80. **答书列白气、日食等象。** 成帝写建始以来天象、地震及居处的对应意义，并训戒后宫妾媵；这一系列为古代灾异解释。 [[80]](#note-80)


<a id="event-81"></a>

81. **答书举《书》并申诫内廷。** 援《尚书》高宗听谏和敬刑之语，允许皇后分条经大长秋奏报，同时申令后宫协助安静节理。 [[81]](#note-81)


<a id="event-82"></a>

82. **许后失势与废黜。** 灾异先后被归咎王凤或许氏。赵氏得宠后，许后姊等被控祝诅，涉案者受罚，许后失后位。 [[82]](#note-82)


<a id="event-83"></a>

83. **许家恢复祀典与许后被赐死。** 成帝先因念平恩侯旧恩恢复归葬、奉祭；后查淳于长与许后私通交通案，赐许后药自杀。 [[83]](#note-83)


<a id="event-84"></a>

84. **孝成班婕妤。** 以下为孝成班婕妤的传记。 [[84]](#note-84)


<a id="event-85"></a>

85. **班婕妤入宫与辞同辇。** 成帝初选入不久得宠并失幼子。成帝欲同辇，她引图中贤王旁有名臣、末代君旁有嬖女为鉴退让。 [[85]](#note-85)


<a id="event-86"></a>

86. **李平获宠及班婕妤自辩。** 班婕妤荐李平，帝赐其姓卫。赵氏姐妹兴后班氏被控祝诅，她以天命及鬼神不受非礼自辩，获帝信任。 [[86]](#note-86)


<a id="event-87"></a>

87. **班氏退长信宫作赋。** 班婕妤为避赵氏迫害，请往长信供养太后，退东宫后作赋自伤。 [[87]](#note-87)


<a id="event-88"></a>

88. **自悼赋由初宠写失望。** 从感先世之德入宫、蒙帝眷顾写至盛宠自警和处境变迁，以昔日光荣反衬。 [[88]](#note-88)


<a id="event-89"></a>

89. **自悼赋写退居自谨。** 用白日移光比失宠，感恩未因谗获罪，愿终身侍长信及死后归葬陵旁。 [[89]](#note-89)


<a id="event-90"></a>

90. **自悼赋尾声写空宫。** 宫门关闭、尘草生、帷灯暗，罗素声和风声反衬无人来御；反复抒发独处长夜之寂。 [[90]](#note-90)


<a id="event-91"></a>

91. **班婕妤奉守成帝园陵。** 成帝去世后班婕妤从事奉守陵园，自己去世后亦葬其中，传未给卒年。 [[91]](#note-91)

<a id="event-94"></a>

94. **赵昭仪宠幸与昭阳宫。** 赵后宠稍衰，其妹受宠为昭仪。铺写昭阳宫金玉珍宝的装饰，并说姐妹专宠十余年无后。 [[94]](#note-94)

<a id="event-96"></a>

96. **王莽废赵后并促其自杀。** 哀帝死后王莽奉太后意将赵氏先降成帝后、退北宫，后再贬庶人、令奉园，自杀；告词以伤害皇嗣为由。 [[96]](#note-96)

<a id="event-99"></a>

99. **傅太后谋立定陶王。** 元帝崩后傅氏随儿到定陶并抚养孙刘欣。成帝无子，刘欣和中山王入朝时，傅太后结纳赵氏、王根促其入储。 [[99]](#note-99)


<a id="event-100"></a>

100. **傅丁尊号的几次变化。** 初时可定期入宫，师丹反对董宏请加号。后来哀帝使王太后先尊傅、丁，之后再晋名号，制度有别于一次册立。 [[100]](#note-100)


<a id="event-101"></a>

101. **傅氏亲族侯爵。** 列堂弟傅喜、傅晏、傅商及同母弟郑氏一家的侯爵，并叙追封、奉后关系。 [[101]](#note-101)


<a id="event-102"></a>

102. **傅太后尊后用事及崩。** 傅氏得尊号后与成帝母冲突，并借祝诅案致旧敌冯太后死；她元寿元年崩，合葬渭陵。 [[102]](#note-102)


<a id="event-103"></a>

<a id="event-104"></a>

104. **丁姬与定陶王室。** 丁氏属丁宽后裔，原以姬侍刘康。傅太后意在亲族张氏，后来丁姬生刘欣，哀帝朝被尊，其亲族获侯。 [[104]](#note-104)


<a id="event-105"></a>

105. **掘冢后的二次议处。** 王莽又据桂宫火、棺椁火解为显警，续请改梓宫和衣敛为较低规格。掘改工程耗时，引及众官门生及劳力。 [[105]](#note-105)


<a id="event-106"></a>

106. **孝哀傅皇后。** 以下为孝哀傅皇后的传记。 [[106]](#note-106)


<a id="event-107"></a>

107. **傅皇后立废。** 傅家本以宗亲婚姻使傅女配刘欣，入太子宫后为妃，哀帝即位后立后。王莽秉政，废傅后，没入亲族而遣归园，傅后自杀。 [[107]](#note-107)

<a id="event-110"></a>

110. **冯参受封与幼王继位。** 定陶王立太子时成帝封中山王舅冯参；是年刘兴卒，幼子继位有病，由冯太后照料并屡行祷告。 [[110]](#note-110)

111. **中山衛姬。** 以下为中山衛姬的传记。 [[111]](#note-111)


<a id="event-112"></a>

112. **卫姬家世入中山。** 卫子豪一家已有显贵外戚，成帝视卫氏为多子吉祥，选其小女配无子的中山孝王刘兴。 [[112]](#note-112)


<a id="event-113"></a>

113. **卫氏被诛与卫姬晚年。** 王宇私下谋求使卫姬来朝，事泄后莽诛宇并清除卫氏亲属。卫姬未杀，王莽代汉时贬为家人，后卒葬中山。 [[113]](#note-113)

115. **王莽为女求平帝后位。** 王莽采霍光旧事，设奏议和推让使女获选。传记定礼、置奉养和莽自重婚亲的经过。 [[115]](#note-115)


<a id="event-116"></a>

116. **孝平后失国拒辱。** 平帝死后，王莽摄政尊女为太后，代汉改为定安公太后。她以汉室旧恩为念，拒绝改嫁，至新室败亡为下段情境。 [[116]](#note-116)

### 1. 外戚兴衰与夫妇之礼

[返回正文第1条](#event-1)

<a id="hs097-p001"></a>

**[《汉书·外戚传》P001](../../sources/摘录/汉书-卷097-外戚传.md#p001)** · [仓内TXT L10121—L10121](../../sources/本地分卷/汉书/汉书-卷097.md#L10121)

>  自古受命帝王及繼體守文之君，非獨內德茂也，蓋亦有外戚之助焉。夏之興也以塗山，而桀之放也用末喜；殷之興也以有娀又有榇，而紂之滅也嬖妲己；周之興也以姜嫄及太任、太姒，而幽王之禽也淫褒姒。故易基乾坤，詩首關雎，書美釐降，春秋譏不親迎。夫婦之際，人道之大倫也。禮之用，唯昏姻為兢兢。夫樂調而四時和，陰陽之變，萬物之統也，可不慎與！人能弘道，末如命何。甚哉妃匹之愛，君不能得之臣，父不能得之子，況卑下乎！既驩合矣，或不能成子姓，成子姓矣，而不能要其終，豈非命也哉！孔子罕言命，蓋難言之。非通幽明之變，惡能識乎性命！

> 初，上即位，數遣使者求外家，久遠，多似類而非是。既得王媼，令太中大夫任宣與丞相御史屬雜考問鄉里識知者，皆曰王嫗。嫗言名妄人，家本涿郡蠡吾平鄉。年十四嫁為同鄉王更得妻。更得死，嫁為廣望王迺始婦，產子男無故、武，女翁須。翁須年八九歲時，寄居廣望節侯子劉仲卿宅，仲卿謂迺始曰：「予我翁須，自養長之。」媼為翁須作縑單衣，送仲卿家。仲卿教翁須歌舞，往來歸取冬夏衣。居四五歲，翁須來言「邯鄲賈長兒求歌舞者，仲卿欲以我與之。」媼即與翁須逃走，之平鄉。仲卿載迺始共求媼，媼惶急，將翁須歸，曰：「兒居君家，非受一錢也，奈何欲予它人？」仲卿詐曰：「不也。」後數日，翁須乘長兒車馬過門，呼曰：「我果見行，當之柳宿。」媼與迺始之柳宿，見翁須相對涕泣，謂曰：「我欲為汝自言。」翁須曰：「母置之，何家不可以居？自言無益也。」媼與迺始還求錢用，隨逐至中山盧奴，見翁須與歌舞等比五人同處，媼與翁須共宿。明日，迺始留視翁須，媼還求錢，欲隨至邯鄲。媼歸，糶買未具，迺始來歸曰：「翁須已去，我無錢用隨也。」因絕至今，不聞其問。賈長兒妻貞及從者師遂辭：「往二十歲，太子舍人侯明從長安來求歌舞者，請翁須等五人。長兒使遂送至長安，皆入太子家。」及廣望三老更始、劉仲卿妻其等四十五人辭，皆驗。宣奏王媼悼后母明白，上皆召見，賜無故、武爵關內侯，旬月間，賞賜以鉅萬計。頃之，制詔御史賜外祖母號為博平君，以博平、蠡吾兩縣戶萬一千為湯沐邑。封舅無故為平昌侯，武為樂昌侯，食邑各六千戶。

### 99. 傅太后谋立定陶王

[返回正文第99条](#event-99)

<a id="hs097-p125"></a>

**[《汉书·外戚传》P125](../../sources/摘录/汉书-卷097-外戚传.md#p125)** · [仓内TXT L10245—L10245](../../sources/本地分卷/汉书/汉书-卷097.md#L10245)

> 元帝崩，傅昭儀隨王歸國，稱定陶太后。後十年，恭王薨，子代為王。王母曰丁姬。傅太后躬自養視，既壯大，成帝無繼嗣。時中山孝王在。元延四年，孝王及定陶王皆入朝。傅太后多以珍寶賂遺趙昭儀及帝舅票騎將軍王根，陰為王求漢嗣。皆見上無子，欲豫自結為久長計，更稱譽定陶王。上亦自器之，明年，遂徵定陶王立為太子，語在哀紀。月餘，天子立楚孝王孫景為定陶王，奉恭王後。太子議欲謝，少傅閻崇以為「春秋不以父命廢王父命，為人後之禮不得顧私親，不當謝。」太傅趙玄以為當謝，太子從之。詔問所以謝狀，尚書劾奏玄，左遷少府，以光祿勳師丹為太傅。詔傅太后與太子母丁姬自居定陶國邸。下有司議皇太子得與傅太后、丁姬相見不，有司奏議不得相見。頃之，成帝母王太后欲令傅太后、丁姬十日一至太子家，成帝曰：「太子丞正統，當共養陛下，不得復顧私親。」王太后曰：「太子小，而傅太后抱養之，今至太子家，以乳母恩耳，不足有所妨。」於是令傅太后得至太子家。丁姬以不小養太子，獨不得。

> 贊曰：易著吉凶而言謙盈之效，天地鬼神至于人道靡不同之。夫女寵之興，繇至微而體至尊，窮富貴而不以功，此固道家所畏，禍福之宗也。序自漢興，終于孝平，外戚後庭色寵著聞二十有餘人，然其保位全家者，唯文、景、武帝太后及邛成后四人而已。至如史良娣、王悼后、許恭哀后身皆夭折不辜，而家依託舊恩，不敢縱恣，是以能全。其餘大者夷滅，小者放流，烏呼！鑒茲行事，變亦備矣。

# 汉书谷永杜邺奏议及仕履

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **谷永家世与少时仕履。** 谷永字子云，父谷吉送还匈奴侍子被郅支杀害。谷永由长安小史起家，建昭间经繁延寿征用举为太常丞，多次上书论政。 [[1]](#note-1)


<a id="event-2"></a>

2. **与杜钦同居策第上等。** 数十应策者中谷永、杜钦列上第，成帝将两人文字给后宫看，又曾在赐许皇后书中采用谷永的进言。 [[2]](#note-2)


<a id="event-3"></a>

3. **拔为光禄大夫与谢王凤。** 谷永暗为王凤游说，且对策有才，升光禄大夫。他致书谢王凤荐拔、不听谗言，以豫让等报知己自况，王凤益厚待之。 [[3]](#note-3)


<a id="event-4"></a>

4. **免安定太守而入王音幕。** 谷永在远郡怕遭王音排挤，称病免职，后经王音奏请入幕，先任营军司马，再得转长史。 [[4]](#note-4)


<a id="event-5"></a>

5. **以金火星象劝王音。** 谷永劝王音辅政时举贤去恶不避亲仇，又拿太白、荧惑位置和亮度解释将相可能失和，主张修德用士。王音仍不平，荐他作护苑使者。 [[5]](#note-5)


<a id="event-6"></a>

6. **王商示警与后来的召还。** 传称太后和诸舅苦于难频谏，借谷永之口进言。此次帝怒欲追，成都侯王商暗告速去，追至规定地点未及；次年谷永被召为太中大夫，继迁光禄大夫给事中。 [[6]](#note-6)


<a id="event-7"></a>

7. **评谷永学术与政治立场。** 传说谷永经书博通而不及刘向父子和扬雄深入，最长天官与京氏《易》，四十余疏多论帝身、后宫；皇帝知其党王氏，未甚亲任。 [[7]](#note-7)


<a id="event-8"></a>

8. **升大司农、免官及改名。** 北地任上逾年，成都侯王商卒，王根荐谷永入为大司农。病逾三月即被免，数月后卒。他原名并，为避与反者樊并同名改称永。 [[8]](#note-8)


<a id="event-9"></a>

9. **杜邺传题。** 底本单列杜邺姓名，以下叙其学问、任职和论丁傅之权。 [[9]](#note-9)


<a id="event-10"></a>

10. **张敞外孙与张氏学问。** 杜邺祖父父亲以功为守，家徙茂陵；幼孤，母是张敞女，成人从张敞子张吉学，承其家书，以孝廉为郎。 [[10]](#note-10)


<a id="event-11"></a>

11. **劝和王音王商和仕履。** 王谭卒后成都侯王商领城门兵，杜邺以周召相辅等例劝王音共享政议，二人由此亲密。王商辅政时用其为主簿，荐侍御史；哀帝时任凉州刺史数年病免。 [[11]](#note-11)


<a id="event-12"></a>

12. **同置大司马、日食与荐直言。** 傅、丁两家当权，傅太后侄辈郑业亦封侯。元寿元年正月拟同时拜傅晏、丁明为两大司马将军，临拜有日食，韦育荐杜邺应直言诏。 [[12]](#note-12)


<a id="event-13"></a>

13. **杜邺卒及五行志互见。** 杜邺尚未授职便病卒。傅、丁朝民间行筹及谷永关于私田、天文、关门飞牡的说法可与《五行志》互看。 [[13]](#note-13)


<a id="event-14"></a>

14. **从学传给张竦与杜林。** 杜邺从张吉受学，又教张吉遗孤张竦。其子杜林好古，建武中历任显官至大司空，以正文字尤精，世称杜公。 [[14]](#note-14)


<a id="event-15"></a>

15. **班固辨三人进言之势。** 班固说成帝朝王氏权重过于哀帝丁傅，故论议各受处境限制。称谷永进三七灾戒为忠，也批评他阿附、离间及借星象求取相合。 [[15]](#note-15)

> 音用從舅越親輔政，威權損於鳳時。永復說音曰：「將軍履上將之位，食膏腴之都，任周召之職，擁天下之樞，可謂富貴之極，人臣無二，天下之責四面至矣，將何以居之？宜夙夜孳孳，執伊尹之彊德，以守職匡上，誅惡不避親愛，舉善不避仇讎，以章至公，立信四方。篤行三者，乃可以長堪重任，久享盛寵。太白出西方六十日，法當參天，今已過期，尚在桑榆之間，質弱而行遲，形小而光微。熒惑角怒明大，逆行守尾。其逆，常也；守尾，變也。意豈將軍忘湛漸之義，委曲從順，所執不彊，不廣用士，尚有好惡之忌，蕩蕩之德未純，方與將相大臣乖離之萌也？何故始襲司馬之號，俄而金火並有此變？上天至明，不虛見異，唯將軍畏之慎之，深思其故，改求其路，以享天意。」音猶不平，薦永為護菀使者。

> 與車騎將軍王音善。平阿侯譚不受城門職，後薨，上閔悔之，乃復令譚弟成都侯商位特進，領城門兵，得舉吏如將軍府。鄴見音前與平阿有隙，即說音曰：「鄴聞人情，恩深者其養謹，愛至者其求詳。夫戚而不見殊，孰能無怨？此棠棣、角弓之詩所為作也。昔秦伯有千乘之國，而不能容其母弟，春秋亦書而譏焉。周召則不然，忠以相輔，義以相匡，同己之親，等己之尊，不以聖德獨兼國寵，又不為長專受榮任，分職於陝，並為弼疑。故內無感恨之隙，外無侵侮之羞，俱享天祐，兩荷高名者，蓋以此也。竊見成都侯以特進領城門兵，復有詔得舉吏如五府，此明詔所欲寵也。將軍宜承順聖意，加異往時，每事凡議，必與及之，指為誠發，出於將軍，則孰敢不說諭？昔文侯寤大鴈之獻而父子益親，陳平共壹飯之篹而將相加驩，所接雖在楹階俎豆之間，其於為國折衝厭難，豈不遠哉！竊慕倉唐、陸子之義，所白声內，唯深察焉。」音甚嘉其言，由是與成都侯商親密，二人皆重鄴。後以病去郎。商為大司馬衛將軍，除鄴主簿，以為腹心，舉侍御史。哀帝即位，遷為涼州刺史。鄴居職寬舒，少威嚴，數年以病免。

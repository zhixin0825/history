# 汉书赵充国辛庆忌的边政与家族

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **赵充国的家世与军事学习。** 赵充国字翁孙，陇西上邽人，迁金城令居。从六郡良家子中以骑射入羽林，少学兵法，熟悉边地诸部。 [[1]](#note-1)


<a id="event-2"></a>

2. **武都平氐与晋后将军。** 昭帝时平定武都氐，迁中郎将，先屯上谷，后领水衡。又击匈奴，获西祁王，进后将军，兼领水衡如旧。 [[2]](#note-2)


<a id="event-3"></a>

3. **定策封侯与备匈奴。** 赵充国参与拥立宣帝，封营平侯。本始中以蒲类将军击匈奴，后又根据降者告警率军屯守边郡，单于未入边。 [[3]](#note-3)


<a id="event-4"></a>

4. **安国行羌、诸部结盟与反叛。** 义渠安国转报先零求渡湟水放牧，赵充国弹劾。元康三年诸豪释仇盟誓，赵充国据旧事及狼何借兵疑其与匈奴联络。朝廷再遣安国，安国杀诸豪和部众，促使本已归附者反叛攻边；安国带兵失利，退令居报告，明记神爵元年春。 [[4]](#note-4)


<a id="event-5"></a>

5. **渡河、持重与坚壁。** 赵充国在金城渡河，告诫士卒勿逐可能是诱兵的游骑。他见对方未据要地，认为其失先机；自己以警戒、坚营、抚爱部下为主，虽遭挑战仍守。 [[5]](#note-5)


<a id="event-6"></a>

6. **释雕库以分诸羌。** 雕库先来通报先零将反，仍因族人混在先零而被留作人质。赵充国释其归去，宣布区分有罪者与未附者，并列捕斩罪首的赏格，希望分解联盟。 [[6]](#note-6)


<a id="event-7"></a>

7. **辛武贤请先出击罕部。** 朝廷已大调各地兵马。辛武贤称边郡驻军牵制耗损，建议在入冬前合击鲜水一带的罕等部，夺其畜产再还。 [[7]](#note-7)


<a id="event-8"></a>

8. **赵充国与公卿各议先后。** 赵充国等从载粮困难、山险与北塞空虚反对远追，认为先零首乱，应先攻先零、招抚胁从。多数公卿以为罕等部仍能助先零，主张先拆其援。 [[8]](#note-8)


<a id="event-9"></a>

9. **朝廷任许延寿与辛武贤。** 宣帝任许延寿为强弩将军、辛武贤为破羌将军，起初嘉许武贤建议，另以玺书责问赵充国。 [[9]](#note-9)


<a id="event-10"></a>

10. **玺书以边费责迟进。** 宣帝说秋季尚可争取水草，拖到冬天则羌藏险中、汉士受冻，加上粮草高价和运输重负，追问为何不早决。 [[10]](#note-10)


<a id="event-11"></a>

11. **诏定七月掣动诸部。** 玺书列各军人数和粮期，命辛武贤由鲜水以北进兵，并令赵充国协同前进，期望分散对方。这里记诏中部署。 [[11]](#note-11)


<a id="event-12"></a>

12. **玺书援五星太白。** 诏以五星、太白的方位作有利兆头，催赵充国进军。属当时政治占候的说法。 [[12]](#note-12)


<a id="event-13"></a>

13. **赵充国奉答诏。** 赵充国以任将在外须顾全国家为由，先谢罪，再陈为什么初议不可行。 [[13]](#note-13)


<a id="event-14"></a>

14. **不宜先加兵于未犯法者。** 奏说皇帝前有明诏，答应不攻未犯的罕部。先零和煎巩据险候机，若舍首乱者反攻未犯罪者，会使汉失信且同时得罪两方。 [[14]](#note-14)


<a id="event-15"></a>

15. **以守待敌及分离其联盟。** 引兵法论以逸待劳，指出抽空酒泉、敦煌守军的风险；先零也疑罕等可能背约，汉可利用其相互猜疑。 [[15]](#note-15)


<a id="event-16"></a>

16. **先零为首，待后再议其余。** 赵充国自陈年老而受重恩，只反复计较国家利害。主张先治先零；其余及至正月仍不服再议出兵。 [[16]](#note-16)


<a id="event-17"></a>

17. **请皇帝裁决。** 赵充国以当前出兵缺少利益作结，请君主审察。 [[17]](#note-17)


<a id="event-18"></a>

18. **先零退湟水与罕部请服。** 先零望军弃辎重，湟水渡处险窄。赵充国缓进，避免使败军回身死战；史载溺死、降斩及收获。入罕地令勿损民居作物，罕部知汉守诺而通款。 [[18]](#note-18)


<a id="event-19"></a>

19. **秋病、催战与拟屯田。** 宣帝闻赵充国有病，给他加派副手并催十二月出战。赵充国见降者多，想留兵屯田，儿子担心再次抗诏有罪。他仍决定为国陈说。 [[19]](#note-19)


<a id="event-20"></a>

20. **奏边费与慎战。** 奏明确对比前线每月耗费粮、盐、草数量，忧转输长期不止与其他边警骤起，故主张以谋瓦解而勿重举兵。 [[20]](#note-20)


<a id="event-21"></a>

21. **屯田人数、粮用与边道。** 赵充国估计临羌至浩亹可耕公地，提出罢部分骑兵、留一万余人屯守，降低月粮耗用，修桥路、沟渠、亭障并运输已伐木料。 [[21]](#note-21)


<a id="event-22"></a>

22. **宣帝问见效期限。** 宣帝追问按留田方案何时可以结束用兵，命赵充国详细估算再奏。 [[22]](#note-22)


<a id="event-23"></a>

23. **以全取胜与已有归降。** 赵充国从知彼欲保亲戚、土地及性命说起，称先零失良牧地、部众愿降，可待其日渐离散，以全力取胜。 [[23]](#note-23)


<a id="event-24"></a>

24. **屯田十二便。** 赵充国把留田利益分项奏上，兼及兵粮、居民耕作、节费、漕运和桥亭修治、守御及牵制对方；以草料耗费说明骑兵长期留驻的成本。 [[24]](#note-24)


<a id="event-25"></a>

25. **宣帝再问何时定局。** 皇帝追问期月是不是当年冬，又担心罢兵招致袭扰、使罕等部因旧日恐惧重新投向先零，请复奏。 [[25]](#note-25)


<a id="event-26"></a>

26. **赵充国答远至来春。** 他估计先零余众饥冻失地，远则来春可望离散。屯田军足以守边并保护农业，邻部渐归，少量寇盗尚难即禁；若轻率劳师则徒费内地，并损防备匈奴、乌桓的力量。 [[26]](#note-26)


<a id="event-27"></a>

27. **议者渐从与两策并行。** 赞成屯田者逐次增多，魏相愿任赵充国之策。宣帝最终一面准留田，一面遣许延寿等出击；诸路获得降众与斩获后，独留赵充国屯田。 [[27]](#note-27)


<a id="event-28"></a>

28. **浩星赐劝归功他将。** 浩星赐劝赵充国让功给出击诸将，既避免争功又不失原议。赵不愿因保一时声誉而隐瞒军事判断，遂据实陈奏，宣帝认可。 [[28]](#note-28)


<a id="event-29"></a>

29. **荐护羌校尉与后来验证。** 赵充国认为辛汤醉后不宜典羌，建议改任其兄临众，获准。后来辛汤复出，以醉辱激起反叛，传以应验赵氏之言。 [[29]](#note-29)


<a id="event-30"></a>

30. **赵卬因泄禁语获罪。** 辛武贤与赵卬在军中谈及赵充国替张安世说情。后来辛武贤告赵卬泄省中语，赵卬获罪自杀，保留原文所见案由。 [[30]](#note-30)


<a id="event-31"></a>

31. **去职、赵充国卒与侯国传承。** 赵充国退休仍常受询边谋，甘露二年卒，谥壮。侯爵传后世，赵岑因冒充嗣子获罪除爵，元始间再封功臣后。 [[31]](#note-31)


<a id="event-32"></a>

32. **麒麟阁画像与扬雄奉诏。** 赵充国的画像与霍光等列于未央宫。成帝因西羌有警追念他，命扬雄面对画像作颂。 [[32]](#note-32)


<a id="event-33"></a>

33. **扬雄颂赵充国。** 颂歌由宣帝命讨先零起，写将军以兵威兼安抚、定计平羌、班师，以周宣王良将和《雅》诗作比。 [[33]](#note-33)


<a id="event-34"></a>

34. **赵充国徙居与辛武贤晚年。** 赵充国为后将军并迁杜陵。辛武贤归军七年后再任破羌将军，行到敦煌未继续出兵，召还之前已经病卒。 [[34]](#note-34)


<a id="event-35"></a>

35. **辛庆忌青年从军与元帝仕历。** 辛庆忌凭父任，随常惠屯乌孙，在交战中立功，后又屯焉耆。元帝初起用，历金城长史与校尉、张掖及酒泉太守。 [[35]](#note-35)


<a id="event-36"></a>

36. **庆忌为执金吾而免，王凤举荐。** 赵、辛两家旧隙发展为相杀，庆忌因子杀赵氏而贬。王凤称他任边郡有功、仁勇持重，荐他复入朝。 [[36]](#note-36)


<a id="event-37"></a>

37. **何武论储帅与庆忌任用。** 何武以贤将居朝能预消外患以及天下虽安不可忘战为论，称辛庆忌足任将帅，劝朝廷预先储备将才。 [[37]](#note-37)


<a id="event-38"></a>

38. **辛庆忌品性与后嗣。** 庆忌恭俭，惟喜好车马。承平时亦受邻国敬畏，老卒官上。三子各任军事或郡守，宗族多人到二千石。 [[38]](#note-38)


<a id="event-39"></a>

39. **辛氏诸子因吕宽案遇祸。** 王莽曾想拉拢辛氏，辛茂却不屈事甄氏。辛通子与卫氏宗亲相善，吕宽案发后王莽追治交结，辛氏牵连败亡。 [[39]](#note-39)


<a id="event-40"></a>

40. **赞论西北将领。** 班固列西北所出的战国、秦汉名将，举李氏、苏氏、赵氏、辛氏等，以边地习武与通晓邻部风俗说明当地多将材。 [[40]](#note-40)

### 4. 安国行羌、诸部结盟与反叛

[返回正文第4条](#event-4)

<a id="hs069-p005"></a>

**[《汉书·赵充国辛庆忌传》P005](../../sources/摘录/汉书-卷069-赵充国辛庆忌传.md#p005)** · [仓内TXT L8616—L8616](../../sources/本地分卷/汉书/汉书-卷069.md#L8616)

> 是時，光祿大夫義渠安國使行諸羌，先零豪言願時渡湟水北，逐民所不田處畜牧。安國以聞。充國劾安國奉使不敬。是後，羌人旁緣前言，抵冒渡湟水，郡縣不能禁。元康三年，先零遂與諸羌種豪二百餘人解仇交質盟詛。上聞之，以問充國，對曰：「羌人所以易制者，以其種自有豪，數相攻擊，勢不壹也。往三十餘歲，西羌反時，亦先解仇合約攻令居，與漢相距，五六年乃定。至征和五年，先零豪封煎等通使匈奴，匈奴使人至小月氏，傳告諸羌曰：『漢貳師將軍眾十餘萬人降匈奴。羌人為漢事苦。張掖、酒泉本我地，地肥美，可共擊居之。』以此觀匈奴欲與羌合，非一世也。間者匈奴困於西方，聞烏桓來保塞，恐兵復從東方起，數使使尉黎、危須諸國，設以子女貂裘，欲沮解之。其計不合。疑匈奴更遣使至羌中，道從沙陰地，出鹽澤，過長阬，入窮水塞，南抵屬國，與先零相直。臣恐羌變未止此，且復結聯他種，宜及未然為之備。」後月餘，羌侯狼何果遣使至匈奴藉兵，欲擊鄯善、敦煌以絕漢道。充國以為「狼何，小月氏種，在陽關西南，勢不能獨造此計，疑匈奴使已至羌中，先零、罕、腾乃解仇作約。到秋馬肥，變必起矣。宜遣使者行邊兵豫為備，敕視諸羌，毋令解仇，以發覺其謀。」於是兩府復白遣義渠安國行視諸羌，分別善惡。安國至，召先零諸豪三十餘人，以尤桀黠，皆斬之。縱兵擊其種人，斬首千餘級。於是諸降羌及歸義羌侯楊玉等恐怒，亡所信鄉，遂劫略小種，背畔犯塞，攻城邑，殺長吏。安國以騎都尉將騎三千屯備羌，至浩亹，為虜所擊，失亡車重兵器甚眾。安國引還，至令居，以聞。是歲，神爵元年春也。

### 5. 渡河、持重与坚壁

[返回正文第5条](#event-5)

<a id="hs069-p007"></a>

**[《汉书·赵充国辛庆忌传》P007](../../sources/摘录/汉书-卷069-赵充国辛庆忌传.md#p007)** · [仓内TXT L8618—L8618](../../sources/本地分卷/汉书/汉书-卷069.md#L8618)

> 充國至金城，須兵滿萬騎，欲渡河，恐為虜所遮，即夜遣三校銜枚先渡，渡輒營陳，會明，畢，遂以次盡渡。虜數十百騎來，出入軍傍。充國曰：「吾士馬新倦，不可馳逐。此皆驍騎難制，又恐其為誘兵也。擊虜以殄滅為期，小利不足貪。」令軍勿擊。遣騎候四望骥中，亡虜。夜引兵上至落都，召諸校司馬，謂曰：「吾知羌虜不能為兵矣。使虜發數千人守杜四望骥中，兵豈得入哉！」充國常以遠斥候為務，行必為戰備，止必堅營壁，尤能持重，愛士卒，先計而後戰。遂西至西部都尉府，日饗軍士，士皆欲為用。虜數挑戰，充國堅守。捕得生口，言羌豪相數責曰：「語汝亡反，今天子遣趙將軍來，年八九十矣，善為兵。今請欲一鬥而死，可得邪！」

### 6. 释雕库以分诸羌

[返回正文第6条](#event-6)

**[《汉书·赵充国辛庆忌传》P009](../../sources/摘录/汉书-卷069-赵充国辛庆忌传.md#p009)** · [仓内TXT L8620—L8620](../../sources/本地分卷/汉书/汉书-卷069.md#L8620)

> 初，罕、腾豪靡當兒使弟雕庫來告都尉曰先零欲反，後數日果反。雕庫種人頗在先零中，都尉即留雕庫為質。充國以為亡罪，乃遣歸告種豪：「大兵誅有罪者，明白自別，毋取并滅。天子告諸羌人，犯法者能相捕斬，除罪。斬大豪有罪者一人，賜錢四十萬，中豪十五萬，下豪二萬，大男三千，女子及老小千錢，又以其所捕妻子財物盡與之。」充國計欲以威信招降罕腾及劫略者，解散虜謀，徼極乃擊之。

> 臣聞兵以計為本，故多算勝少算。先零羌精兵今餘不過七八千人，失地遠客，分散飢凍。罕、腾、莫須又頗暴略其羸弱畜產，畔還者不絕，皆聞天子明令相捕斬之賞。臣愚以為虜破壞可日月冀，遠在來春，故曰兵決可期月而望。竊見北邊自敦煌至遼東萬一千五百餘里，乘塞列隧有吏卒數千人，虜數大眾攻之而不能害。今留步士萬人屯田，地勢平易，多高山遠望之便，部曲相保，為塹壘木樵，校聯不絕，便兵弩，飭鬥具。烽火幸通，勢及并力，以逸待勞，兵之利者也。臣愚以為屯田內有亡費之利，外有守禦之備。騎兵雖罷，虜見萬人留田為必禽之具，其土崩歸德，宜不久矣。從今盡三月，虜馬羸瘦，必不敢捐其妻子於他種中，遠涉河山而來為寇。又見屯田之士精兵萬人，終不敢復將其累重還歸故地。是臣之愚計，所以度虜且必瓦解其處，不戰而自破之冊也。至於虜小寇盜，時殺人民，其原未可卒禁。臣聞戰不必勝，不苟接刃；攻不必取，不苟勞眾。誠令兵出，雖不能滅先零，亶能令虜絕不為小寇，則出兵可也。即今同是而釋坐勝之道，從乘危之勢，往終不見利，空內自罷敝，貶重而自損，非所以視蠻夷也。又大兵一出，還不可復留，湟中亦未可空，如是，繇役復發也。且匈奴不可不備，烏桓不可不憂。今久轉運煩費，傾我不虞之用以澹一隅，臣愚以為不便。校尉臨眾幸得承威德，奉厚幣，拊循眾羌，諭以明詔，宜皆鄉風。雖其前辭嘗曰「得亡效五年」，宜亡它心，不足以故出兵。臣竊自惟念，奉詔出塞，引軍遠擊，窮天子之精兵，散車甲於山野，雖亡尺寸之功，媮得避慊之便，而亡後咎餘責，此人臣不忠之利，非明主社稷之福也。臣幸得奮精兵，討不義，久留天誅，罪當萬死。陛下寬仁，未忍加誅，今臣數得孰計。愚臣伏計孰甚，不敢避斧鉞之誅，昧死陳愚，唯陛下省察。

> 贊曰：秦漢已來，山東出相，山西出將。秦將軍白起，郿人；王翦，頻陽人。漢興，郁郅王圍、甘延壽，義渠公孫賀、傅介子，成紀李廣、李蔡，杜陵蘇建、蘇武，上邽上官桀、趙充國，襄武廉褒，狄道辛武賢、慶忌，皆以勇武顯聞。蘇、辛父子著節，此其可稱列者也，其餘不可勝數。何則？山西天水、隴西、安定、北地處勢迫近羌胡，民俗修習戰備，高上勇力鞍馬騎射。故《秦詩》曰：「王于興師，修我甲兵，與子皆行。」其風聲氣俗自古而然，今之歌謠慷慨，風流猶存耳。

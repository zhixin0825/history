# 汉书赵广汉张敞等地方政事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **赵广汉早仕与处置杜建。** 赵广汉起于郡吏、州从事，以廉洁、明敏而礼遇士人著称，由察举逐步升至京辅都尉、代理京兆尹。昭帝去世时，杜建负责修建平陵上部，仍纵宾客作恶，不听警告。广汉顶住请托，预先斥退企图劫囚的宗族宾客，将杜建弃市。 [[1]](#note-1)


<a id="event-2"></a>

2. **治颍川豪族。** 调任颍川太守后，他处死原、褚大族的首恶，郡中震动。传以大族宗党、宾客原先横暴难治，说明严办的背景。 [[2]](#note-2)


<a id="event-3"></a>

3. **告密投筩与豪族结怨。** 颍川豪族联姻、吏民结党，他泄露供词使之互怨，又用缿筩收匿名告发，删去真名而托称出自豪族子弟。告讦使大族离散、盗贼易捕，其声威传至匈奴。这是本传所记的短期治效和手法。 [[3]](#note-3)


<a id="event-4"></a>

4. **推功于吏与严察负职。** 任二千石时，他谦和接士，乐将成绩归于属吏，因而能尽用其才；有人负职，他先行告诫，不改才逮捕查办。 [[4]](#note-4)


<a id="event-5"></a>

5. **钩距问情与解苏回之危。** 以先问狗、羊、牛价再问马价为例，说明广汉如何旁敲侧问、互校实情。长安少年尚在商议劫人即被捕；苏回被劫时，他派襲奢劝释人质，二人投降。广汉厚待囚徒，并在处死前预备殓葬。 [[5]](#note-5)


<a id="event-6"></a>

6. **界亭致问。** 界亭亭长托湖都亭长转达问候，来人未提，广汉却能说出，并令其复谢。传用此说明他洞察部属动静。 [[6]](#note-6)


<a id="event-7"></a>

7. **给捕盗狱吏定秩。** 广汉奏请长安游徼、狱吏秩百石，使其稍自重，不敢枉法拘人。京兆素有治名，他认为左冯翊、右扶风同治长安，限于辖界而难全面禁奸。 [[7]](#note-7)


<a id="event-8"></a>

8. **搜霍禹之第。** 霍光在时广汉事奉霍光；光死后广汉察知上意，自率长安吏搜霍禹家私屠私酤，毁门器。霍皇后向宣帝哭诉，宣帝暗中嘉许。传将他重用进取少吏、敢犯贵近与后来的败亡相联系。 [[8]](#note-8)


<a id="event-9"></a>

9. **苏贤、荣畜案及搜丞相府。** 因私卖酒的门客而迁怒蘇賢，骑士不到屯所一案牵连广汉，他蒙赦贬秩；又借他法杀榮畜，遭人上书。地节三年七月魏相傅婢死，广汉借此威胁魏相，率吏卒入相府收奴婢、讯问夫人。覆验称婢因魏相责笞，出至亲属处才死。萧望之奏劾，另计杀无辜、断狱不实等罪；数万吏民请救，广汉仍被腰斩。侍婢死亡与本传未标年月的后续处刑须区分。 [[9]](#note-9)


<a id="event-10"></a>

10. **京兆吏民追思。** 本传在结局后仍肯定广汉于京兆廉明、能抑豪强，使普通居民安业，百姓以歌谣追念。 [[10]](#note-10)


<a id="event-11"></a>

11. **尹翁归分目。** 下文转叙尹翁归事迹。 [[11]](#note-11)


<a id="event-12"></a>

12. **尹翁归管市拒豪。** 尹翁归少年孤苦，熟悉狱文，善击剑。霍氏宾客原可持兵入平阳市斗殴；他任市吏拒收赠送，市人及霍客都畏其法。 [[12]](#note-12)


<a id="event-13"></a>

13. **田延年察识尹翁归。** 田延年选旧吏，翁归自称兼有文武才能，获任卒史。延年见其查案有实，改署督邮分治汾南；此后他由察举历任县尉、都内令、弘农都尉。 [[13]](#note-13)


<a id="event-14"></a>

14. **于定国未便请托。** 尹翁归任东海太守前辞别廷尉于定国；于欲荐同乡，谈了一天却不敢引见，说贤吏不可干以私求。 [[14]](#note-14)


<a id="event-15"></a>

15. **治理东海与处置许仲孙。** 他分县登记吏民优劣及罪名，掌握在秋冬会课或出巡时查办豪猾的时机；到任后处死历任太守难制的许仲孙，以警郡人。 [[15]](#note-15)


<a id="event-16"></a>

16. **右扶风按籍捕盗。** 守右扶风一年后转正，选择廉平、疾恶的吏员任要职，分县掌握案情、追索盗贼。对弱小稍宽，对豪强严急；役使罪人按限铡草，督责严厉，传也记有自杀者，治盗考课则居三辅之首。 [[16]](#note-16)


<a id="event-17"></a>

17. **尹翁归卒与赐金祭祀。** 尹翁归执政虽用刑，朝中廉慎谦退。在任数年病死，无遗财。宣帝诏美其廉平，为其子赐黄金百斤奉祭。传把卒写在元康四年，宣帝纪给赐金记八月。 [[17]](#note-17)


<a id="event-18"></a>

18. **尹氏子弟与田延年知人。** 翁归三子均任郡守，少子岑至后将军。与翁归同受选的閎孺也以治行升广陵相，本传由此称许田延年识人。 [[18]](#note-18)


<a id="event-19"></a>

19. **韩延寿分目。** 下文转叙韩延寿事迹。 [[19]](#note-19)


<a id="event-20"></a>

20. **魏相以韩义死谏荐其子。** 燕王刘旦谋反，郎中韩义强谏遇害。昭帝征贤良文学，魏相以赏善惩恶为本，以比干为喻，建议褒用韩义之子；霍光从之，韩延寿由谏大夫任淮阳太守，又徙颍川。 [[20]](#note-20)


<a id="event-21"></a>

21. **调解颍川告讦风气。** 韩延寿见赵广汉治颍川留下告讦积怨，遍询乡老疾苦，与之议定婚丧祭礼，令学官弟子示范，禁售替代丧葬礼器的虚饰物。徙东郡后，黄霸因其旧政而治。 [[21]](#note-21)


<a id="event-22"></a>

22. **礼教互察与责己。** 修学官、行乡社礼和讲武，公开赋役期限，置正、五长，借礼教及里伍互察防盗。他厚待属吏，部下负约时反自责，或有自杀、自刎得救者，延寿遣医救治并优恤其家。 [[22]](#note-22)


<a id="event-23"></a>

23. **门卒进谏免骑吏。** 骑吏因见父亲而车前迟到；门卒引《孝经》辩明缘由，延寿认错，后来任用这位原为诸生的门卒。传记其在东郡三年断狱锐减。 [[23]](#note-23)


<a id="event-24"></a>

24. **高陵兄弟争田。** 代理左冯翊转正后，他出巡高陵，因兄弟争田而闭门自省；县吏乡老也自系待罪。兄弟经宗族劝责后请互让，延寿开门会见并表彰悔改，传以此说明教化与恩信。 [[24]](#note-24)


<a id="event-25"></a>

25. **韩氏子孙与奢僭之戒。** 韩延寿临刑令三子去官为戒。孙威再出仕至将军，也能以恩信得士力，最终因奢僭被诛。 [[25]](#note-25)


<a id="event-26"></a>

26. **张敞分目。** 下文转叙张敞事迹。 [[26]](#note-26)


<a id="event-27"></a>

27. **张敞谏昌邑王与山阳仕履。** 张敞出身地方吏，至太仆丞，昌邑王即位后他以未褒辅臣而先迁昌邑小辇为失，上书切谏。王被废后，张敞历豫州刺史、太中大夫、函谷关都尉，后为山阳太守，适逢宣帝疑忌退居昌邑的刘贺。 [[27]](#note-27)


<a id="event-28"></a>

28. **请往胶东平盗。** 勃海、胶东连年不登，群盗攻击官府、劫夺囚徒和列侯。张敞以山阳治绩自陈，求任难地，奉命任胶东相、赐金三十斤，又请允许仿三辅考绩赏罚立功吏。 [[28]](#note-28)


<a id="event-29"></a>

29. **胶东悬赏捕盗。** 张敞公开悬赏，准盗众相捕斩以赎罪，为有功吏请授县令，群盗由此解散、互相缉斩，国中平定。 [[29]](#note-29)


<a id="event-30"></a>

30. **谏王太后游猎。** 胶东王太后频出游猎，张敞用叶阳后和樊姬以克己影响君主的例子，加以礼法，劝太后为国人表率。奏后太后停止出猎。 [[30]](#note-30)


<a id="event-31"></a>

31. **代守京兆与查长安群盗。** 黄霸入守京兆数月不称、回颍川，张敞由胶东相代理京兆尹。查得盗首外表如富厚长者，赦其旧罪、任为吏，令他们酒聚时用赭标记同伙；当日捕数百人，审实依法处分，长安市场盗窃大减。 [[31]](#note-31)


<a id="event-32"></a>

32. **张敞与赵广汉治法比较。** 张敞赏罚迅速，也会因事通融；情报网络和破获隐奸不及广汉，却以《春秋》学辅助政事、表用贤良。传以此解释他何以最终免遭刑戮。 [[32]](#note-32)


<a id="event-33"></a>

33. **久治京兆与画眉。** 京兆辖京城，责任尤繁，历官快速失位，只有赵广汉和张敞任期较久。张敞议政多获采纳，日常仪态却随便，又给妻画眉被奏。他以闺房私事应答，皇帝爱其才、未深究，其终未登高位。 [[33]](#note-33)


<a id="event-34"></a>

34. **絮舜案与免京兆。** 张敞因杨恽获罪被劾，宣帝起初压下免奏。属吏絮舜以他将去职而拒办，私称“五日京兆”；张敞急责办人取致死之罪，将舜弃市。其家趁使者巡察上诉。皇帝先发原免奏以让他自行脱身，敞交印后亡命。案牵杨恽旧案，免官从《通鉴》次年编次。 [[34]](#note-34)


<a id="event-35"></a>

35. **复用冀州与搜广川宫。** 数月后朝廷召敞，敞自陈枉法杀舜，仍获任冀州刺史。他领郡国吏搜王宫捕盗党刘调等，陈首门外，劾广川王。皇帝只削王户，冀州盗渐息；他后任太原太守，转正后郡中清理。 [[35]](#note-35)


<a id="event-36"></a>

36. **元帝拟用张敞而张敞卒。** 元帝即位后郑朋荐张敞傅辅太子，萧望之评他能理繁剧、材不宜师傅。元帝欲召为左冯翊时张敞病死，有怨于他的太原吏家刺杀其子璜。三子曾至都尉。 [[36]](#note-36)


<a id="event-37"></a>

37. **张武以文法治梁。** 弟张武被任梁相，私下以勒御难驯之马比喻刑法治理梁国；柱后惠文是秦狱法吏冠名。张敞由此预许其能，张武到任后果有治绩。 [[37]](#note-37)


<a id="event-38"></a>

38. **张竦文学与家系。** 张敞孙张竦在王莽时任郡守、封侯，博学文雅胜祖父，政绩不及。竦死后传称敞无后。 [[38]](#note-38)


<a id="event-39"></a>

39. **王尊分目。** 下文转叙王尊。 [[39]](#note-39)


<a id="event-40"></a>

40. **王尊由牧羊至狱吏。** 王尊早年孤苦牧羊，自学文书，十三岁求任狱小吏。太守赏其熟悉诏令，补书佐、监狱；一度辞去学习经书，再治狱，历刺史从事、盐官长，数陈便宜。 [[40]](#note-40)


<a id="event-41"></a>

41. **王尊治美阳案。** 王尊于初元中由举直言升县令，代理槐里兼美阳。女子告继子强以己为妻并笞打，王尊验得供辞，称此为律条无成文的重恶，令骑吏射杀。月有正月，具体年不详。 [[41]](#note-41)


<a id="event-42"></a>

42. **安定任内处豪与遭免。** 皇帝幸雍过虢，王尊供应得法而升安定太守。他令县吏革贪扶弱，以贤任用；郡掾张辅在狱中数日死，查有大量奸赃。王尊威慑当地豪强，但朝廷后来以残暴免官。 [[42]](#note-42)


<a id="event-43"></a>

43. **护羌粮道受围。** 王尊再起任护羌军转运校尉，羌众断粮道围军，他率千余骑突战。战功未及申报，先因擅离部署坐罪，遇赦归家。传无具体年份。 [[43]](#note-43)


<a id="event-44"></a>

44. **九折坂上的忠孝自许。** 经涿郡太守推荐复任，升益州刺史。王尊到王阳曾因险而退的九折坂，令驭者向前，自言王阳以孝保身，自己以忠赴险。治益州两年，又经郑宽中举荐为东平相。 [[44]](#note-44)


<a id="event-45"></a>

45. **东平相与王争礼。** 东平王恃亲骄纵，王尊持诏先退，归舍用食后才再致诏，又阻王私自驾小车、当面讥王。诸语使王稍折服，王母终以王尊威逼失臣礼告之，他被免为庶人，后经王凤荐复官。 [[45]](#note-45)


<a id="event-46"></a>

46. **王尊清南山群盗与再获劾。** 南山盗群久捕不得，王凤荐王尊行京兆尹事，短期内平盗，转正后任京兆三年。后因轻慢持诏使者、大量系囚等事被劾。郭赐告兄被杀的叙述续下行。 [[46]](#note-46)


<a id="event-47"></a>

47. **郭赐告讼与王尊免官。** 续叙郭赐告许仲家杀其兄而吏不敢捕；王尊回朝却奏地方强弱各得其分、宽政行。《通鉴》作御史大夫张忠奏其暴虐自饰，吏民亦有人惜其免。 [[47]](#note-47)


<a id="event-48"></a>

48. **东郡金堤水患与奖赏。** 河水浸金堤，王尊率吏民祭河伯并留守堤上，吏民一度逃避，唯主簿流泪侍立；传记水势回退。乡老奏闻，朝廷核验后奖其临险安民，增秩赐金。《成帝纪》另载建始四年金堤实决，王尊据《通鉴》在该年刚以他职行京兆尹事，传中护堤应属后期。 [[48]](#note-48)


<a id="event-49"></a>

49. **王尊身后与子王伯。** 王尊在东郡数年卒官，吏民记念。其子王伯也为京兆尹，因柔弱不能胜任被免。 [[49]](#note-49)


<a id="event-50"></a>

50. **王章分目。** 下文转叙京兆尹王章。 [[50]](#note-50)


<a id="event-51"></a>

51. **王章直言与王凤案。** 王章以文学升谏大夫，元帝朝与陈咸议论石显，被石显陷害免官；成帝再次起用，任京兆尹。虽受王凤推荐，他仍借日食劝帝改用忠贤之臣，成帝一度采纳却没有罢王凤，王章终被定以大逆。详见《元后传》。 [[51]](#note-51)


<a id="event-52"></a>

52. **王章卧牛衣。** 未仕困病时，王章卧牛衣而泣，与妻告别，其妻以他才为京中人不及，责他在困境中不自奋。 [[52]](#note-52)


<a id="event-53"></a>

53. **王章死狱与妻子迁合浦。** 王章任京兆时准备上书，妻反劝他知足并念及牛衣时困境；他仍上奏，被系廷尉狱。女儿听到点囚数不足推知父亡，次日果实；家属被迁合浦。 [[53]](#note-53)


<a id="event-54"></a>

54. **王商为王章家请归。** 王凤死后，成都侯王商继辅政，为王章家属请归原郡。家属在合浦采珠致富，泰山太守萧育使其得赎故田宅。传以辅政易人标先后，未标还籍的确年。 [[54]](#note-54)


<a id="event-55"></a>

55. **王章与三王。** 王章任京兆二年，传称无辜遭刑，人以为冤。京兆三王之另一人王骏为王阳子，另有本传。 [[55]](#note-55)


<a id="event-56"></a>

56. **六吏政声与各自得失。** 班固引“前有趙、張，後有三王”，辨刘向、冯商、扬雄各自所作传序。详评赵广汉察奸、韩延寿移风而失于劾上，尹翁归公洁，张敞儒雅任法，王尊文武俱长而跅弛好言，王章刚直而未度势，终于妻子流离。 [[56]](#note-56)

### 9. 苏贤、荣畜案及搜丞相府

[返回正文第9条](#event-9)

<a id="hs076-p011"></a>

**[《汉书·赵尹韩张两王传》P011](../../sources/摘录/汉书-卷076-赵尹韩张两王传.md#p011)** · [仓内TXT L8959—L8959](../../sources/本地分卷/汉书/汉书-卷076.md#L8959)

> 初，廣漢客私酤酒長安巿，丞相史逐去客。客疑男子蘇賢言之，以語廣漢。廣漢使長安丞按賢，尉史禹故劾賢為騎士屯霸上，不詣屯所，乏軍興。賢父上書訟罪，告廣漢，事下有司覆治。禹坐要斬，請逮捕廣漢。有詔即訊，辭服，會赦，貶秩一等。廣漢疑其邑子榮畜教令，後以它法論殺畜。人上書言之，事下丞相御史，案驗甚急。廣漢使所親信長安人為丞相府門卒，令微司丞相門內不法事。地節三年七月中，丞相傅婢有過，自絞死。廣漢聞之，疑丞相夫人妒殺之府舍。而丞相奉齋酎入廟祠，廣漢得此，使中郎趙奉壽風曉丞相，欲以脅之，毋令窮正己事。丞相不聽，按驗愈急。廣漢欲告之，先問太史知星氣者，言今年當有戮死大臣，廣漢即上書告丞相罪。制曰：「下京兆尹治。」廣漢知事迫切，遂自將吏卒突入丞相府，召其夫人跪庭下受辭，收奴婢十餘人去，責以殺婢事。丞相魏相上書自陳：「妻實不殺婢。廣漢數犯罪法不伏辜，以詐巧迫脅臣相，幸臣相寬不奏。願下明使者治廣漢所驗臣相家事。」事下廷尉治罪，實丞相自以過譴笞傅婢，出至外弟乃死，不如廣漢言。司直蕭望之劾奏：「廣漢摧辱大臣，欲以劫持奉公，逆節傷化，不道。」宣帝惡之，下廣漢廷尉獄，又坐賊殺不辜，鞠獄故不以實，擅斥除騎士乏軍興數罪。天子可其奏。吏民守闕號泣者數萬人，或言「臣生無益縣官，願代趙京兆死，使得牧養小民。」廣漢竟坐要斬。

### 56. 六吏政声与各自得失

[返回正文第56条](#event-56)

<a id="hs076-p063"></a>

**[《汉书·赵尹韩张两王传》P063](../../sources/摘录/汉书-卷076-赵尹韩张两王传.md#p063)** · [仓内TXT L9011—L9011](../../sources/本地分卷/汉书/汉书-卷076.md#L9011)

> 贊曰：自孝武置左馮翊、右扶風、京兆尹，而吏民為之語曰：「前有趙、張，後有三王。」然劉向獨序趙廣漢、尹翁歸、韓延壽，馮商傳王尊，揚雄亦如之。廣漢聰明，下不能欺，延壽厲善，所居移風，然皆訐上不信，以失身墮功。翁歸抱公絜己，為近世表。張敞衎衎，履忠進言，緣飾儒雅，刑罰必行，縱赦有度，條教可觀，然被輕惰之名。王尊文武自將，所在必發，譎詭不經，好為大言。王章剛直守節，不量輕重，以陷刑戮，妻子流遷，哀哉！

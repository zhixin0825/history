# 汉书近臣受宠与进退

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

<a id="event-1"></a>

1. **历朝近幸与本篇列目。** 以高祖籍孺、惠帝闳孺为早例，说明便嬖影响宫人服饰以及公卿请托。继列各帝主要近幸；景、昭、宣三朝人物虽亲近，受宠程度较低。张彭祖以宣帝旧游封侯，谨慎无过，却被小妻毒死，国除。 [[1]](#note-1)


<a id="event-2"></a>

2. **邓通分传。** 分传标题。以下叙汉文帝近臣邓通。 [[2]](#note-2)


<a id="event-3"></a>

3. **文帝因梦召用邓通。** 邓通本是掌船的黄头郎，文帝在渐台按梦中衣带的样子寻人，因邓与“登”音近，更加高兴。邓通谨慎，少交外人，渐获重赐，官上大夫。 [[3]](#note-3)


<a id="event-4"></a>

4. **赐严道铜山铸钱。** 有人预言邓通将饿死，文帝认为自己足以给他财富，于是赐蜀郡严道铜山，许他自行铸钱，邓氏所铸广为通行。作者并称邓通并无荐贤等特别功业。 [[4]](#note-4)


<a id="event-5"></a>

5. **吮痈故事与太子怀恨。** 文帝患痈，邓通常为吮吸。文帝询问至亲，邓通答为太子。太子按父命尝试却面有难色，后知道邓通常如此做，因羞而怨。 [[5]](#note-5)


<a id="event-6"></a>

6. **景帝即位后邓通免官、财产没收。** 景帝即位后邓通先免职；后来被告越界私铸，查核后家财尽没，仍欠巨额。长公主的赠物也被收去，只能借给衣食，邓通最后寄人家而死。 [[6]](#note-6)


<a id="event-7"></a>

7. **赵谈等二人附传。** 附传标题。以下附记赵谈、北宫伯子。 [[7]](#note-7)


<a id="event-8"></a>

8. **赵谈与北宫伯子得亲近。** 赵谈以占察气象受宠，北宫伯子以厚道爱人见亲，两人均不及邓通。 [[8]](#note-8)


<a id="event-9"></a>

9. **韩嫣分传。** 分传标题。以下叙武帝近臣韩嫣。 [[9]](#note-9)


<a id="event-10"></a>

10. **自胶东旧学至上大夫。** 韩嫣是弓高侯頹当之孙，与刘彻为胶东王时同学相亲，刘彻入太子宫后更受亲近。武帝即位谋图北边，韩嫣熟悉军务，又善骑射，遂官上大夫。 [[10]](#note-10)


<a id="event-11"></a>

11. **江都王误认副车而受辱。** 江都王随猎，见韩嫣乘副车驰过，以为皇帝而在道旁伏拜，却未被理会。他向太后哭诉并愿自退为宿卫，以此反讥韩嫣，太后遂记恨。 [[11]](#note-11)


<a id="event-12"></a>

12. **太后赐韩嫣死。** 韩嫣入出永巷无禁，有人把奸事报给太后。太后令使者赐死，武帝求情未能免。 [[12]](#note-12)


<a id="event-13"></a>

13. **韩说附传。** 附传标题。以下补叙韩嫣之弟韩说。 [[13]](#note-13)


<a id="event-14"></a>

14. **韩说军功与巫蛊中的结局。** 韩说亦受宠，以军功获案道侯爵，巫蛊案中被太子一方所杀。其子韩增封龙雒侯，后官大司马、车骑将军，另一卷有专传。 [[14]](#note-14)


<a id="event-15"></a>

15. **李延年分传。** 分传标题。以下叙善歌制乐的李延年。 [[15]](#note-15)


<a id="event-16"></a>

16. **李延年制郊乐、家族获宠及覆亡。** 李延年出于倡家，受腐刑后在狗监服事。其妹李夫人受宠；武帝起天地祭祀，司马相如等写颂歌，李延年制作新声付诸演唱。妹生昌邑王后，延年为协律都尉，后因弟李季犯事和李夫人已死而遭族诛。 [[16]](#note-16)


<a id="event-17"></a>

17. **卫青、霍去病兼以军功进身。** 作者称此后近幸大多出自外戚。卫青、霍去病虽受宠，也有实际战功可凭。 [[17]](#note-17)


<a id="event-18"></a>

18. **石显分传。** 分传标题。以下并叙弘恭和石显。 [[18]](#note-18)


<a id="event-19"></a>

19. **弘恭、石显入中书。** 两人少时受腐刑，任中黄门，由选拔入中尚书。宣帝朝弘恭熟法令成例，善请奏，任中书令，石显任仆射；弘恭死后由石显接任。 [[19]](#note-19)


<a id="event-20"></a>

20. **石显受元帝委任和排斥异议者。** 元帝多病，认为石显久任而无外党，令诸事经他奏决。萧望之等请中书改用士人，反受排挤。传把萧望之自杀、周堪与刘更生被废，以及张猛、京房、陈咸、贾捐之、苏建诸案放在一起叙述，实际各有先后。 [[20]](#note-20)


<a id="event-21"></a>

21. **石显结交牢梁、五鹿充宗。** 牢梁与五鹿充宗是石显党友，依附者容易获官。民间以印多、绶带长的歌谣讽刺三人用权。 [[21]](#note-21)


<a id="event-22"></a>

22. **石显处理冯逡、冯野王的进用。** 石显原想结交冯家，荐冯逡近侍；冯逡直言他专权，被皇帝斥回郎官。后来冯野王考选才行居首，石显却以其为昭仪兄长、易招徇私议论为由劝元帝勿任御史大夫。 [[22]](#note-22)


<a id="event-23"></a>

23. **石显借开宫门预防弹劾。** 他先获得皇帝准许夜归开门，再故意晚归。有人告他假传诏命，皇帝反给他看奏书；他借机称受群臣忌妒并假请退职，得到更加厚重的赏赐。 [[23]](#note-23)


<a id="event-24"></a>

24. **以推举贡禹消除舆论怀疑。** 石显怕学者因萧望之之死责难他，主动亲礼、举荐以明经著节闻名的贡禹。人们见贡禹一路任至御史大夫，有人遂不再信他谗害望之。 [[24]](#note-24)


<a id="event-25"></a>

25. **淳于长分传。** 分传标题。以下叙成帝外戚淳于长。 [[25]](#note-25)


<a id="event-26"></a>

26. **侍王凤病而受用。** 淳于长凭太后外甥身份为黄门郎，王凤病时日夜侍奉，王凤临终托付他。成帝赏识其孝谨，使其历任校尉、水衡都尉、卫尉等职。 [[26]](#note-26)


<a id="event-27"></a>

27. **助立赵皇后、以罢昌陵议获爵。** 太后嫌赵飞燕出身低，淳于长居中传话促成立后。成帝以其先谏罢劳民的昌陵工程为公开授爵理由，先赐关内侯、后来封定陵侯；他受赏赐和外地馈遗极多，生活奢纵。 [[27]](#note-27)


<a id="event-28"></a>

28. **收许后财物和王莽揭发。** 淳于长与被废许后之姊许靡私通并纳为小妻。许后求为婕妤，他收重礼后诳称为她谋左皇后。王莽借侍王根病揭发他图代王根并与许氏交通之事，太后令上报，成帝先罢官、遣就国。 [[28]](#note-28)


<a id="event-29"></a>

29. **王立代言、淳于长死狱。** 淳于长通过王融赠宝给王立，王立替他说情，皇帝起疑。王立令儿子自杀灭口，淳于长被捕入洛阳狱，供出侮慢许后与谋立左皇后，因大逆死狱中。亲族及交结者受到处分，王莽接任王根。 [[29]](#note-29)


<a id="event-30"></a>

30. **淳于长与张放的亲幸程度。** 作者说淳于长虽因外亲得亲近，仍不如富平侯张放，后者常同成帝寝处并微行出入。 [[30]](#note-30)


<a id="event-31"></a>

31. **董贤分传。** 分传标题。以下叙哀帝近臣董贤。 [[31]](#note-31)


<a id="event-32"></a>

32. **董贤得宠与董氏受恩。** 董贤由太子舍人入帝宫，哀帝认出其人，拜黄门郎，渐至驸马都尉、侍中。断袖故事写哀帝不愿惊醒同睡的董贤。皇帝还恩及董氏及姻亲，修宅、预赐葬具和营茔，又将武库兵器和上方珍宝赐给董家。 [[32]](#note-32)


<a id="event-33"></a>

33. **孔光礼迎董贤而得赏。** 哀帝令董贤私往孔光家，孔光懂得皇帝用意，盛装出迎拜送，不敢用同僚平等的礼节。皇帝知道后高兴，给孔光兄长的两个儿子授予近侍官。 [[33]](#note-33)


<a id="event-34"></a>

34. **董家议亲与王闳劝止谈禅让。** 董恭欲为董宽信求娶萧咸之女，萧咸觉“允执其中”含尧舜禅让之意，惧董氏过盛，婉拒其亲。宴饮时哀帝笑问要效尧禅舜，王闳以宗庙天下应传子孙进谏，哀帝不喜，后来不再使他侍宴。 [[34]](#note-34)


<a id="event-35"></a>

35. **朱诩收葬、两家在东汉初后事。** 董贤旧吏朱诩收葬其尸，后被王莽另寻罪名杀死；诩子朱浮在建武显达。王闳新莽时任地方官，王莽败后退官，光武帝因赞王闳在乱中受人敬重而提拔其子。 [[35]](#note-35)


<a id="event-36"></a>

36. **篇末赞语标题。** 编排小题，以下为班固赞。 [[36]](#note-36)


<a id="event-37"></a>

37. **班固议近幸与西汉政权失衡。** 班固认为帝王也会钟爱男性近幸，以董贤父子并居高位而不得善终为例。作者再把哀、平间继嗣、辅臣和宫廷失衡归责于私相授官，援引孔子“损者三友”作结。 [[37]](#note-37)

> 董賢字聖卿，雲陽人也。父恭，爲御史，任賢爲太子舍人。哀帝立，賢隨太子官爲郎。二歲餘，賢傳漏在殿下，爲人美麗自喜，哀帝望見，説其儀貌，識而問之，曰：「是舍人董賢邪？」因引上與語，拜爲黃門郎，由是始幸。問及其父爲雲中侯，即日徵爲霸陵令，遷光祿大夫。賢寵愛日甚，爲駙馬都尉侍中，出則參乘，入御左右，旬月間賞賜累巨萬，貴震朝廷。常與上臥起。嘗晝寢，偏藉上袖，上欲起，賢未覺，不欲動賢，乃斷袖而起。其恩愛至此。賢亦性柔和便辟，善爲媚以自固。每賜洗沐，不肯出，常留中視醫藥。上以賢難歸，詔令賢妻得通引籍殿中，止賢廬，若吏妻子居官寺捨。又召賢女弟以爲昭儀，位次皇后，更名其捨爲椒風，以配椒房雲。昭儀及賢與妻旦夕上下，並侍左右。賞賜昭儀及賢妻亦各千萬數。遷賢父爲少府，賜爵關內侯，食邑，復徙爲衛尉。又以賢妻父爲將作大匠，弟爲執金吾。詔將作大匠爲賢起大第北闕下，重殿洞門，木土之功窮極技巧，柱檻衣以綈錦。下至賢家僮僕皆受上賜，及武庫禁兵，上方珍寶。其選物上弟盡在董氏，而乘輿所服乃其副也。及至東園秘器，珠襦玉柙，豫以賜賢，無不備具。又令將作爲賢起塚塋義陵旁，內爲便房，剛柏題湊，外爲徼道，周垣數里，門闕罘罳甚盛。

> 是時，成帝外家王氏衰廢，唯平阿侯譚子去疾，哀帝爲太子時爲庶子得幸，及即位，爲侍中、騎都尉。上以王氏亡在位者，遂用舊恩親近去疾，復進其弟閎爲中常侍，閎妻父蕭咸，前將軍望之子也，久爲郡守，病免，爲中郎將。兄弟並列，賢父恭慕之，欲與結婚姻。閎爲賢弟駙馬都尉寬信求咸女爲婦，咸惶恐不敢當，私謂閎曰：「董公爲大司馬，冊文言『允執其中』，此乃堯禪舜之文，非三公故事，長老見者，莫不心懼。此豈家人子所能堪邪！」閎性有知略，聞咸言，心亦悟，乃還報恭，深達咸自謙薄之意。恭歎曰：「我家何用負天下，而爲人所畏如是！」意不説。後上置酒麒麟殿，賢父子親屬宴飲，王閎兄弟侍中、中常侍皆在側。上有酒所，從容視賢笑，曰「吾欲法堯禪舜，何如？」閎進曰：「天下乃高皇帝天下，非陛下之有也。陛下承宗廟，當傳子孫於亡窮。統業至重，天子亡戲言！」上默然不説，左右皆恐。於是遣閎出，後不得復侍宴。

> 賢所厚吏沛硃詡自劾去大司馬府，買棺衣收賢屍葬之。王莽聞之而大怒，以它罪擊殺詡。詡子浮建武中貴顯，至大司馬、司空，封侯。而王閎王莽時爲牧守，所居見紀，莽敗乃去官。世祖下詔曰：「武王克殷，表商容之閭，閎修善謹敕，兵起，吏民獨不爭其頭首。今以閎子補吏。」至墨綬卒官。蕭咸外孫云。

> 贊曰：柔曼之傾意，非獨女德，蓋亦有男色焉。觀籍、閎、鄧、韓之徒非一，而董賢之寵尤盛，父子並爲公卿，可謂貴重人臣無二矣。然進不由道，位過其任，莫能有終，所謂愛之適足以害之者也。漢世衰於元、成，壞於哀、平。哀、平之際，國多釁矣。主疾無嗣，弄臣爲輔，鼎足不強，棟干微撓。一朝帝崩，奸臣擅命，董賢縊死，丁、傅流放，辜及母后，奪位幽廢，咎在親便嬖，所任非仁賢。故仲尼著「損者三友」，王者不私人以官，殆爲此也。

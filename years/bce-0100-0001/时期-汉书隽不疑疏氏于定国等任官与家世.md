# 汉书隽不疑疏氏于定国等任官与家世

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **雋不疑的籍贯与经学。** 雋不疑字曼倩，勃海人。研习《春秋》，任郡文学，出仕辞让皆遵礼，闻名州郡。 [[1]](#note-1)


<a id="event-2"></a>

2. **雋不疑发现刘泽谋反。** 昭帝即位后，齐孝王孙刘泽结豪杰，意欲先杀青州刺史。不疑发觉，捕得其党，擢京兆尹并受钱百万。其母问平反救出多少人，因之或喜或绝食，故本传称其严而不残。 [[2]](#note-2)


<a id="event-3"></a>

3. **冒名者被验明，不疑谢婚归老。** 昭帝与霍光赞不疑通经明义。不疑婉拒霍光以女相妻，后病免家居而终。继任京兆尹的赵广汉称自己禁奸可取，论朝堂事远不及不疑。受审者是居湖、以卜筮为业的夏阳人，听故太子舍人称其相似而起冒名之心，被腰斩。传载成方遂及张延年两名。 [[3]](#note-3)


<a id="event-4"></a>

4. **疏广传分目。** 由雋不疑转叙下一位传主疏广，并在本节叙其从子疏受。 [[4]](#note-4)


<a id="event-5"></a>

5. **疏广从经师入太子宫。** 疏广字仲翁，东海兰陵人，通《春秋》，在家聚徒，曾任博士、太中大夫。宣帝立太子，丙吉为太傅，疏广任少傅；丙吉迁御史大夫，疏广继为太傅。 [[5]](#note-5)


<a id="event-6"></a>

6. **疏受应对有礼而为少傅。** 疏广的侄子疏受字公子，以贤良为太子家令。宣帝到太子宫，他应对、上寿皆得体，遂从家令升少傅。传在师傅并任时以“父子”称叔侄。 [[6]](#note-6)


<a id="event-7"></a>

7. **疏广反对许舜监护太子家。** 外祖许广汉请令其弟许舜监护太子家。疏广认为国储宜选天下英俊，已有师傅官属，不宜让外家专亲。宣帝赞同，魏相亦推许，疏广愈获敬重；叔侄相随为傅，时人荣之。 [[7]](#note-7)


<a id="event-8"></a>

8. **疏广以赐金与故旧共饮。** 疏广返乡后卖金设酒食，宴请族亲故旧。后辈托长者劝其置田宅；疏广答已有衣食可自给的田庐，财多足以损贤志、长愚过、起众怨，愿与乡里同享天子养老之赐。叔侄皆寿终。 [[8]](#note-8)


<a id="event-9"></a>

9. **于定国传分目。** 以下叙于定国及其父于公、子于永。 [[9]](#note-9)


<a id="event-10"></a>

10. **于公断狱平允而生祠。** 于定国字曼倩，东海郯人。父于公做县狱吏、郡决曹，平心办案，受其裁决者没有怨言，郡人在他生时立祠。 [[10]](#note-10)


<a id="event-11"></a>

11. **东海孝妇案及传说中的旱雨。** 孝妇年轻守寡无子，长期奉养婆母。婆母自缢后，其女控告孝妇杀人，妇在讯问中自诬服罪。于公据素行力争，抱案卷哭于府而辞，太守仍处死孝妇。传以三年旱与后任太守祭墓即雨申说枉狱，这是叙事中的归因。 [[11]](#note-11)


<a id="event-12"></a>

12. **于定国由狱吏入朝。** 于定国承父学，任郡决曹和廷尉史，参与审反狱，历侍御史、御史中丞。昌邑王入朝后，他曾上书谏。宣帝即位，霍光超擢当初谏王者，于定国升光禄大夫平尚书事，后历水衡都尉、廷尉。 [[12]](#note-12)


<a id="event-13"></a>

13. **于定国学经而慎刑。** 于定国持经受业，以下士礼节敬学者。决疑用法重审慎、哀鳏寡、疑罪从轻，朝论常据张释之为比。传又记能多饮而不乱，治冬月请谳仍清明；作廷尉十八岁后迁御史大夫。 [[13]](#note-13)


<a id="event-14"></a>

14. **于定国的相职与元帝责问。** 于定国代黄霸为丞相、封西平侯。元帝继位后敬重旧臣；于定国与陈万年并位，及贡禹接任，意见渐有争驳。关东灾民入关，元帝诏责大臣吏治不良、冤狱不理、荐举失实、灾田催税，告知已发粮赐衣并命条陈得失。于定国谢罪。 [[14]](#note-14)


<a id="event-15"></a>

15. **永光元年因灾请退。** 元帝因春霜夏寒、日光青暗，又闻东方父子相弃，命公卿报实并议救灾。于定国自劾还印，元帝答灾有所由、责任仍在君身，命察守相、治纲纪。定国坚请，赐安车驷马及金六十斤还家，数年后七十余岁卒谥安。 [[15]](#note-15)


<a id="event-16"></a>

16. **于永折节与于氏后嗣。** 于永少嗜酒，年近三十转而修行。官历有侍中中郎将、长水校尉，袭侯后任光禄勋、御史大夫。经选择娶宣帝长女馆陶公主刘施；成帝方有意拜相而他先卒，子恬承爵，传评恬行薄。 [[16]](#note-16)


<a id="event-17"></a>

17. **于公自期后代有显官。** 乡人修巷门时，于公请加高加宽以容驷马高盖车，自信慎狱积阴德、子孙将显。传以儿子定国、孙子于永官位和家族传侯照应。 [[17]](#note-17)


<a id="event-18"></a>

18. **薛广德传分目。** 下节传主为薛广德。 [[18]](#note-18)


<a id="event-19"></a>

19. **薛广德传授《鲁诗》并任御史大夫。** 薛广德字长卿，沛郡相人。以《鲁诗》在楚国教授，龚胜、龚舍皆从其学。萧望之赏识荐入朝，任博士并参与石渠议经，迁谏大夫、长信少府和御史大夫。 [[19]](#note-19)


<a id="event-20"></a>

20. **平当传分目。** 下节传主为平当。 [[20]](#note-20)


<a id="event-21"></a>

21. **平当由礼官起家，经术论灾。** 平当字子思，祖父因资财从下邑徙平陵。他由大行治礼丞及大鸿胪文学历任县长令，以明经为博士、给事中，习用经术分析灾异及政事得失，立论接近萧望之、匡衡。 [[21]](#note-21)


<a id="event-22"></a>

22. **巡察幽州流民及迁调。** 出使幽州，他荐奖安集流民得力的地方官，请暂放勃海盐池限制以救急，十一使中考绩最佳。后迁丞相司直，因法贬刺史，复朝为太中大夫并历长信少府、大鸿胪、光禄勋。底本刺史所辖作“逆方”。 [[22]](#note-22)


<a id="event-23"></a>

23. **平当病重辞封而卒。** 哀帝征召平当，历光禄大夫、光禄勋、御史大夫而至丞相，冬仅赐关内侯。次年帝召欲封列侯，他因病不应，明言不可为留爵给子孙而起受印后就死，乃乞休。哀帝未许，赐牛酒问疾，一月余平当卒。其子平晏后来为大司徒、封防乡侯；传以韦、平两族父子皆居宰相高位为异。 [[23]](#note-23)


<a id="event-24"></a>

24. **彭宣传分目。** 下节传主为彭宣。卷072另有谏大夫鲍宣本传。 [[24]](#note-24)


<a id="event-25"></a>

25. **彭宣历官及因藩国姻亲被罢。** 彭宣字子佩，淮阳阳夏人，随张禹习《易》，由博士、东平太傅经荐为右扶风、廷尉，因籍贯为王国人出守太原；又入朝为大司农、光禄勋、右将军。哀帝改他为左将军，随后希望让丁、傅外戚执兵，以其王国籍贯和子娶淮阳王女为由收印，赐金车，以关内侯归家。 [[25]](#note-25)


<a id="event-26"></a>

26. **卷末赞语分目。** 以下是合论各位传主的赞语。 [[26]](#note-26)


<a id="event-27"></a>

27. **赞语论出仕、致仕和守节。** 班固称雋不疑用经而能临事决断、疏广知足全身、于氏父子怜弱平狱、薛广德荣归，认为平当知耻、彭宣知险而退，不同于患得患失之人。仓内本作“於安國”，所指仍是于定国。 [[27]](#note-27)

### 11. 东海孝妇案及传说中的旱雨

[返回正文第11条](#event-11)

<a id="hs071-p014"></a>

**[《汉书·隽疏于薛平彭传》P014](../../拆分史书/汉书/卷071.md#p014)** · [仓内TXT L8720—L8720](../../拆分史书/汉书/卷071.md#part-1-L8720)

> 東海有孝婦，少寡，亡子，養姑甚謹，姑欲嫁之，終不肯。姑謂鄰人曰：「孝婦事我勤苦，哀其亡子守寡。我老，久累丁壯，奈何？」其後姑自經死，姑女告吏：「婦殺我母」。吏捕孝婦，孝婦辭不殺姑。吏驗治，孝婦自誣服。具獄上府，于公以為此婦養姑十餘年，以孝聞，必不殺也。太守不聽，于公爭之，弗能得，乃抱其具獄，哭於府上，因辭疾去。太守竟論殺孝婦。郡中枯旱三年。後太守至，卜筮其故，於公曰：「孝婦不當死，前太守強斷之，咎黨在是乎？」於是太守殺牛自祭孝婦塚，因表其墓，天立大雨，歲孰。郡中以此大敬重于公。

> 定國少學法於父，父死，後定國亦為獄中、郡決曹，補廷尉史，以選與御史中丞從事治反者獄，以材高舉侍御史，遷御史中丞。會昭帝崩，昌邑王征即位，行淫亂，定國上書諫。後王廢，宣帝立，大將軍光領尚書事，條奏群臣諫昌邑王者皆超遷。定國由是為光祿大夫，平尚書事，甚見任用。數年，遷水衡都尉，超過廷尉。

### 14. 于定国的相职与元帝责问

**[《汉书·隽疏于薛平彭传》P017](../../拆分史书/汉书/卷071.md#p017)** · [仓内TXT L8723—L8723](../../拆分史书/汉书/卷071.md#part-1-L8723)

> 甘露中，代黃霸為丞相，封西平侯。三年，宣帝崩，元帝立，以定國任職舊臣，敬重之。時陳萬年為御史大夫，與定國並位八年，論議無所拂。後貢禹代為御史大夫，數處駁議，定國明習政事，率常丞相議可。然上始即位，關東連年被災害，民流入關，言事者歸咎於大臣。上於是數以朝日引見丞相、御史，入受詔，條責以職事，曰：「惡吏負賊，妄意良民，至亡辜死。或盜賊發，吏不亟追而反系亡家，後不敢復告，以故浸廣。民多冤結，州郡不理，連上書者交於闕廷。二千石選舉不實，是以在位多不任職。民田有災害，吏不肯除，收趣其租，以故重困。關東流民饑寒疾疫，已詔吏轉漕，虛倉廩開府臧相振救，賜寒者衣，至春猶恐不贍。今丞相、御史將欲何施以塞此咎？悉意條狀，陳朕過失。」定國上書謝罪。

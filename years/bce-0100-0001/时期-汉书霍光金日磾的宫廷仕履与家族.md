# 汉书霍光金日磾的宫廷仕履与家族

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **霍去病识父，霍光入侍。** 霍去病与霍光同父异母。霍去病成年才得知父亲是霍中孺，出兵经过河东时相认，赡养父亲并把弟弟带入长安。去病卒后，霍光历内廷职，随侍谨慎二十余年。 [[1]](#note-1)


<a id="event-2"></a>

2. **武帝定储托孤。** 卫太子败亡后，武帝选钩弋所生幼子，赐霍光周公负成王图。后元二年病中明示立幼、以周公之事付光，霍光、金日磾、上官桀、桑弘羊受命辅政。次日皇太子继位为昭帝，政事由霍光决断。 [[2]](#note-2)


<a id="event-3"></a>

3. **擒何罗的功与遗诏。** 传回顾莽何罗、重合侯通反事。武帝留下封书，命死后依此前功劳封霍光、金日磾和上官桀。侍中王忽怀疑三人自贵，其父王莽受霍光责问后毒杀忽；此王莽为武帝时卫尉。 [[3]](#note-3)


<a id="event-4"></a>

4. **霍光举止与符玺郎。** 霍光平日沉静，进止有常。宫中惊扰时掌符玺郎坚持不能擅交御玺，光认为守职可敬，次日给他加秩。 [[4]](#note-4)


<a id="event-5"></a>

5. **上官氏婚姻与丁外人求封。** 霍光之女嫁上官安，女儿所生的孙女经鄂邑盖主入宫立后，安得将军与侯爵。上官父子为盖主宠近丁外人求封与求官皆不获准，因而与霍光、盖主的关系生变。 [[5]](#note-5)


<a id="event-6"></a>

6. **燕王诈书攻霍光。** 盖主、上官父子、桑弘羊与燕王旦共谋，趁霍光休沐，以燕王名义奏劾出行僭礼、幕府擅增校尉，拿苏武与长史的奖任作对比，想引群臣罢光。昭帝不交下议处。 [[6]](#note-6)


<a id="event-7"></a>

7. **伏杀与废立之谋被破。** 上官等不再公开毁光，改谋使盖主置酒杀光，废昭帝迎燕王。案发，诸人及其宗族受诛，燕王与盖主自杀。昭帝此后继续委政于霍光，传称其间国用民生好转。 [[7]](#note-7)


<a id="event-8"></a>

8. **霍氏任官及宣帝初委政。** 子侄和女婿在宿卫、军队与宫廷占多处要职。宣帝即位后霍光提出还政，皇帝礼让，政务仍先报霍光。 [[8]](#note-8)


<a id="event-9"></a>

9. **霍禹继侯与霍家骄盛。** 霍禹袭爵，霍显扩陵修宅、用乘舆式车饰，并与霍光所信的冯子都通奸。霍氏子弟出猎、负朝请及内眷往来宫中皆渐失法度。 [[9]](#note-9)


<a id="event-10"></a>

10. **魏相近侍与封事绕过尚书。** 霍光死后宣帝亲政，魏相得进，许氏和金安上也可进入省中。霍山仍领尚书，皇帝允吏民密奏不经尚书，使霍氏不能阻截。 [[10]](#note-10)


<a id="event-11"></a>

11. **许皇后遇害与霍氏兵权被收。** 倒叙霍显唆使淳于衍毒死许后、霍光未揭发及霍成君入宫。霍光死后消息渐露，宣帝外调霍氏女婿，令霍禹名为大司马而去兵权，并改任宫卫。 [[11]](#note-11)


<a id="event-12"></a>

12. **霍禹称病，任宣劝解。** 霍禹因亲族离权而怨。旧属任宣指出过去霍光掌杀生、官吏被诛、亲近者僭越，现在皇帝亲戚得用本属形势所宜，不该怨恨；霍禹后来复视事。 [[12]](#note-12)


<a id="event-13"></a>

13. **霍显向子侄吐露毒杀。** 霍山指责魏相改变霍光时的法令，也承认魏相廉正。民间已有毒杀传言，霍显终告诉霍山等实情；家人怕诛，开始谋求先发。 [[13]](#note-13)


<a id="event-14"></a>

14. **张章告发早期谋议。** 石夏用天象论霍家可能有祸，张赦主张藉太后杀魏相及平恩侯并废帝。张章告发，官府曾拘捕又奉诏停追；霍氏因恐毒杀再发而加紧联络。 [[14]](#note-14)


<a id="event-15"></a>

15. **霍氏谋反败露。** 霍家在惧祸中谋以太后名义动手、废帝而立霍禹。传也记录梦兆等附会。霍云、霍山、范明友自杀，霍禹、霍显等被处死，霍后被废，牵连甚广。 [[15]](#note-15)


<a id="event-16"></a>

16. **徐生预警与曲突徙薪。** 徐福早劝及时约束霍氏，未被采纳。事后有人举改灶移薪可预防起火，指出献预防策者宜受奖，徐福因此获帛、后为郎。 [[16]](#note-16)


<a id="event-17"></a>

17. **芒刺在背的说法。** 宣帝初谒高庙，霍光陪乘使他畏惧如芒刺在背，张安世代后转为自在。民间后来用这件事解释霍氏祸根，传把它标为俗语。 [[17]](#note-17)


<a id="event-18"></a>

18. **护墓与霍阳复封。** 成帝时置百家守霍光墓。平帝元始二年封霍光从祖一支的后人霍阳为博陆侯千户。 [[18]](#note-18)


<a id="event-19"></a>

19. **金日磾传题。** 下文从休屠王之子归汉写金日磾和后裔。 [[19]](#note-19)


<a id="event-20"></a>

20. **养马入侍及受宠。** 帝出观马，金日磾容貌持重、所养马肥，牵马经过时又不窥后宫。武帝亲问其来历，任马监，后迁近侍；贵戚有怨，帝愈优待之。 [[20]](#note-20)


<a id="event-21"></a>

21. **母图像与金日磾杀长子。** 武帝嘉其母教，母死后绘像甘泉，日磾见之而拜泣。长子幼为武帝宠儿，长成后因与宫人嬉狎被日磾杀死。武帝先怒而后听明原因，哀痛而敬其为人。 [[21]](#note-21)


<a id="event-22"></a>

22. **托孤、延期袭封与卒。** 金日磾侍奉持礼，不愿女入后宫。武帝托孤时自处霍光之副。虽有遗命封秺侯，因帝年幼起初不受；辅政一年多病重，方在病榻受印，旋卒谥敬。 [[22]](#note-22)


<a id="event-23"></a>

23. **金赏、金建及秺侯后嗣。** 兄弟少年同侍昭帝，金赏因袭侯佩两绶，霍光用先帝功封之约拒为金建破例。宣帝时赏任太仆，与霍氏女离异以免坐，后来无子国除；元始间改封金建孙金当承祀。 [[23]](#note-23)


<a id="event-24"></a>

24. **金伦一支兴起。** 随日磾入汉的弟弟金伦早死；日磾近支至孙转衰，金伦之子金安上则显贵受封。 [[24]](#note-24)


<a id="event-25"></a>

25. **金安上先后获爵。** 金安上为侍中，参与揭露楚王延寿反谋，得关内侯。霍家谋反时阻其亲属入禁门，获都成侯，官至卫尉，死后谥敬。 [[25]](#note-25)


<a id="event-26"></a>

26. **金敞历仕与病中托弟。** 金安上诸子任近官。金敞获元帝宠，元帝死后免按例入陵园，留侍成帝。他敢犯颜直言，临终托弟金岑，皇帝授岑主客，并用其子金涉。 [[26]](#note-26)


<a id="event-27"></a>

27. **金涉、金参、金饶官历。** 金涉以明经和俭节得称，历侍中、奉车都尉至长信少府。金参曾使匈奴并历校尉郡守，金饶为越骑校尉。 [[27]](#note-27)


<a id="event-28"></a>

28. **金钦受用及入平帝师友。** 金钦以明经入太子宫，哀帝时与族弟掌事，又护办傅太后丧事，历郡守。平帝时入任京兆，和孔光分任选立的师友，后封都成侯。 [[28]](#note-28)


<a id="event-29"></a>

29. **继绝、上尊母礼争与金钦死。** 王莽在诛卫氏后组织公卿听宗伯讲承嗣礼。金钦、金当获封续绝，关于母亲应否获太夫人待遇引发争执。甄邯奏劾，金钦被召诣狱自杀，金汤另封都成侯，金遵后来也获用。 [[29]](#note-29)


<a id="event-30"></a>

30. **班固总论霍光与金日磾。** 班固赞霍光托孤、惩乱与废立时持节，责他包庇妻子毒杀而致覆族。又赞金日磾亡国入汉后靠谨敬立功，金氏数世近侍；末叙赐金姓与休屠祭天金人相连的说法。 [[30]](#note-30)

### 1. 霍去病识父，霍光入侍

[返回正文第1条](#event-1)

<a id="hs068-p001"></a>

**[《汉书·霍光金日磾传》P001](../../sources/摘录/汉书-卷068-霍光金日磾传.md#p001)** · [仓内TXT L8564—L8564](../../sources/本地分卷/汉书/汉书-卷068.md#L8564)

> 霍光字子孟，票騎將軍去病弟也。父中孺 東平陽人也，以縣吏給事平陽侯家，與侍者衞少兒私通而生去病。中孺吏畢歸家，娶婦生光，因絕不相聞。乆之，少兒女弟子夫得幸於武帝，立爲皇后，去病以皇后姊子貴幸。旣壯大，迺自知父爲霍中孺，未及求問。會爲票騎將軍擊匈奴，道出河東，河東太守郊迎，負弩矢先驅，至平陽傳舍，遣吏迎霍中孺。中孺趨入拜謁，將軍迎拜，因跪曰：「去病不早自知爲大人遺體也。」中孺扶服叩頭，曰：「老臣得託命將軍，此天力也。」去病大爲中孺買田宅奴婢而去。還，復過焉，迺將光西至長安，時年十餘歲，任光爲郎，稍遷諸曹侍中。去病死後，光爲奉車都尉光祿大夫，出則奉車，入侍左右，出入禁闥二十餘年，小心謹慎，未甞有過，甚見親信。

> 征和二年，衞太子爲江充所敗，而燕王旦、廣陵王胥皆多過失。是時上年老，寵姬鈎弋趙倢伃有男，上心欲以爲嗣，命大臣輔之。察羣臣唯光任大重，可屬社稷。上迺使黃門畫者畫周公負成王朝諸侯以賜光。後元二年春，上游五柞宮，病篤，光涕泣問曰：「如有不諱，誰當嗣者？」上曰：「君未諭前畫意邪？立少子，君行周公之事。」光頓首讓曰：「臣不如金日磾。」日磾亦曰：「臣外國人，不如光。」上以光爲大司馬大將軍，日磾爲車騎將軍，及太僕上官桀爲左將軍，搜粟都尉桑弘羊爲御史大夫，皆拜卧內牀下，受遺詔輔少主。明日，武帝崩，太子襲尊號，是爲孝昭皇帝。帝年八歲，政事壹決於光。

### 9. 霍禹继侯与霍家骄盛

### 29. 继绝、上尊母礼争与金钦死

[返回正文第29条](#event-29)

<a id="hs068-p046"></a>

**[《汉书·霍光金日磾传》P046](../../sources/摘录/汉书-卷068-霍光金日磾传.md#p046)** · [仓内TXT L8609—L8609](../../sources/本地分卷/汉书/汉书-卷068.md#L8609)

> 時王莽新誅平帝外家衞氏，召明禮少府宗伯鳳入說爲人後之誼，白令公卿、將軍、侍中、朝臣並聽，欲以內厲平帝而外塞百姓之議。欽與族昆弟秺侯當俱封。初，當曾祖父日磾傳子節侯賞，而欽祖父安上傳子夷侯常，皆亡子，國絕，故莽封欽、當奉其後。當母南即莽母功顯君同產弟也。當上南大行爲太夫人。欽因緣謂當：「詔書陳日磾功，亡有賞語。當名爲以孫繼祖也，自當爲父、祖父立廟。賞故國君，使大夫主其祭。」時甄邯在旁，庭叱欽，因劾奏曰：「欽幸得以通經術，超擢侍帷幄，重蒙厚恩，封襲爵號，知聖朝以世有爲人後之誼。前遭故定陶太后背本逆天，孝哀不獲厥福，迺者呂寬、衞寶復造姦謀，至於反逆，咸伏厥辜。太皇太后懲艾悼懼，逆天之咎，非聖誣法，大亂之殃，誠欲奉承天心，遵明聖制，專壹爲後之誼，以安天下之命，數臨正殿，延見羣臣，講習禮經。孫繼祖者，謂亡正統持重者也。賞見嗣日磾，後成爲君，持大宗重，則禮所謂『尊祖故敬宗』，大宗不可以絕者也。欽自知與當俱拜同誼，即數揚言殿省中，敎當云云。當即如其言，則欽亦欲爲父明立廟而不入夷侯常廟矣。進退異言，頗惑衆心，亂國大綱，開禍亂原，誣祖不孝，罪莫大焉。尤非大臣所宜，大不敬。秺侯當上母南爲太夫人，失禮不敬。」莽白太后，下四輔、公卿、大夫、博士、議郎，皆曰：「欽宜以時即罪。」謁者召欽詣詔獄，欽自殺。邯以綱紀國體，亡所阿私，忠孝尤著，益封千戶。更封長信少府涉子右曹湯爲都成侯。湯受封日，不敢還歸家，以明爲人後之誼。益封之後，莽復用欽弟遵，封侯，歷九卿位。

### 30. 班固总论霍光与金日磾

[返回正文第30条](#event-30)

<a id="hs068-p047"></a>

**[《汉书·霍光金日磾传》P047](../../sources/摘录/汉书-卷068-霍光金日磾传.md#p047)** · [仓内TXT L8610—L8610](../../sources/本地分卷/汉书/汉书-卷068.md#L8610)

> 贊曰：霍光以結髮內侍，起於階闥之閒，確然秉志，誼形於主。受襁褓之託，任漢室之寄，當廟堂，擁幼君，摧燕王，仆上官，因權制敵，以成其忠。處廢置之際，臨大節而不可奪，遂匡國家，安社稷。擁昭立宣，光爲師保，雖周公、阿衡，何以加此！然光不學亡術，闇於大理，陰妻邪謀，立女爲后，湛溺盈溢之欲，以增顛覆之禍，死財三年，宗族誅夷，哀哉！昔霍叔封於晉，晉即河東，光豈其苗裔乎？金日磾夷狄亡國，羈虜漢庭，而以篤敬寤主，忠信自著，勒功上將，傳國後嗣，世名忠孝，七世內侍，何其盛也！本以休屠作金人爲祭天主，故因賜姓金氏云。

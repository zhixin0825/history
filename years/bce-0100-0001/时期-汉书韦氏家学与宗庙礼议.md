# 汉书韦氏家学与宗庙礼议

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **韦孟诗谏楚王戊的前事。** 韦贤字长孺，鲁国邹人。先人韦孟原居彭城，傅楚元王交、夷王郢客及其后王戊。因王戊放纵而作诗谏，后来辞官迁邹，又作一诗。诗是否韦孟本人作，见本节末。 [[1]](#note-1)


<a id="event-2"></a>

2. **谏诗一｜由豕韦至汉受命。** 追叙豕韦受爵、辅商出征，与大彭相继有功；周赧王听谗后韦国绝，周室失去号令诸侯的能力。家族衰落迁彭城，诗人一代在暴秦以耕自养；收以天眷而汉受命。 [[2]](#note-2)


<a id="event-3"></a>

3. **谏诗二｜楚元王及夷王承统。** 颂汉征定四方，高帝封弟于楚，命作者任傅。元王恭俭惠民、纳辅弼；夷王负责继业，诗借天命无常告诫守宗祀应尊贤用士。 [[3]](#note-3)


<a id="event-4"></a>

4. **谏诗三｜楚王务猎和轻慢老臣。** 指斥王戊不思危惧继祖，只乐犬马游猎，废农耗民；扩苑、信谄，不能辨佞人与耿直老臣，既轻祖先又不惧封国被削。 [[4]](#note-4)


<a id="event-5"></a>

5. **谏诗四｜帝室亲厚与法度。** 王是汉家亲属，尤应朝夕修德名。天子察下土，群司执法无私，有过通常由近及远加以纠正，宗亲身份不能解除这些责任。 [[5]](#note-5)


<a id="event-6"></a>

6. **谏诗五｜悔过近黄发。** 不鉴往事会让危局日深，覆败并非一朝形成。以秦穆公悔过用老成而得霸为例，叹年岁向老、楚王仍不亲近黄发。 [[6]](#note-6)


<a id="event-7"></a>

7. **在邹诗引语。** 以下另录归居邹地时的诗。 [[7]](#note-7)


<a id="event-8"></a>

8. **在邹诗一｜年老自念退位。** 自叙年老鄙陋，怕留恋官位而玷污清肃朝廷的贤俊之列。 [[8]](#note-8)


<a id="event-9"></a>

9. **在邹诗二｜获天子许归。** 向天子请退，蒙天子念年齿、许悬车。自言仍望楚王醒悟，始迁入鲁。 [[9]](#note-9)


<a id="event-10"></a>

10. **在邹诗三｜迁邹安居。** 离开祖祢旧土还回首，同行者背负满路，抵邹后剪茅盖堂筑墙，众人合力安置居处。 [[10]](#note-10)


<a id="event-11"></a>

11. **在邹诗四｜思楚与喜邹鲁礼乐。** 虽归仍梦在楚君侧争议辅政，醒后身在异土、念祖流泪。转述孔子遗风和邹鲁礼义弦诵，自己与从者在这里获得安慰。 [[11]](#note-11)


<a id="event-12"></a>

12. **卒于邹和诗作归属异说。** 韦孟在邹地去世。传别载一种说法，以为两诗是其子孙追述先意所作。 [[12]](#note-12)


<a id="event-13"></a>

13. **韦贤以师儒入相并首开相退。** 自韦孟五世至韦贤。韦贤善《礼》《尚书》而专授《诗》，历博士、给事中，授昭帝诗，累至大鸿胪。昭帝无子，参加宣帝继统之议而得关内侯。后来代蔡义为相、封扶阳侯，地节三年年老致仕，赐金与第，从此有丞相致仕之例。八十二卒谥节。 [[13]](#note-13)


<a id="event-14"></a>

14. **近代家世与传经高于留金。** 列长子方山、次子弘、次子舜、少子玄成的职守。玄成同样由明经为丞相，邹鲁因以满籯黄金反衬教子一经。 [[14]](#note-14)


<a id="event-15"></a>

15. **韦玄成继学而礼遇贫士。** 韦玄成字少翁，以父任为郎及常侍骑。遇贫旧步行便让部从下车载送，更敬贫贱者，因名誉和通经迁谏大夫、大河都尉。 [[15]](#note-15)


<a id="event-16"></a>

16. **韦玄成佯狂让爵。** 韦弘任太常丞案多，被父催辞却未辞，后因庙事下狱。韦贤病中拒定嗣，门人宗家冒传其令立玄成。玄成佯狂不受召，丞相史劝说明高义，友人侍郎章请免强夺其志。公卿劾无病，宣帝令勿劾而受爵，重其节，任河南太守；韦弘也复有官历。 [[16]](#note-16)


<a id="event-17"></a>

17. **杨恽案免官及酎祭失爵。** 韦玄成任未央卫尉、太常，因与杨恽交厚而在杨恽被诛时免官。后来入孝惠庙遇雨路泥泞，未乘驷车而骑马至门，被劾降关内侯，因贬父爵作诗自责。 [[17]](#note-17)


<a id="event-18"></a>

18. **自责诗一｜豕韦先祖受命。** 韦玄成追述祖先豕韦在商封侯、安国有功，车服仪节有常，恩泽传世；用祖德及合礼车服作为自责的尺度。 [[18]](#note-18)


<a id="event-19"></a>

19. **自责诗二｜楚傅辅两代而去国。** 写韦孟谨慎辅元、夷二王，嗣王放纵后迁邹，五世至祖先的忠廉传统在韦贤节侯身上再显。 [[19]](#note-19)


<a id="event-20"></a>

20. **自责诗三｜称父德、致仕与朝仪。** 称节侯辅佐昭宣、教导五伦，老退赐金、赐宅。有扶阳封国，又因皇帝礼遇留朝谋政，诗强调其朝会驾驭、衣冠与仪容可为四方表式。 [[20]](#note-20)


<a id="event-21"></a>

21. **自责诗四｜嗣爵本属兄长，自招贬黜。** 封土本当由兄嗣，诗再称兄长礼让，并责自己朝会失肃、怠于车服而获罪；与传中家族内定玄成经过可对读。 [[21]](#note-21)


<a id="event-22"></a>

22. **自责诗五｜警后人严慎朝仪。** 叹显爵由己败、惭辱无可委，借问答激励向高德努力；自陈重复有过而伤家声，告各方诸侯谨守礼服、车乘和威仪。 [[22]](#note-22)


<a id="event-23"></a>

23. **事淮阳王、论石渠与复相复爵。** 宣帝爱通政法的淮阳憲王刘钦，顾念太子幼失母没有易储，欲以礼让之臣劝导淮阳王，任玄成为中尉。未就国时玄成诏与萧望之等议经于石渠。元帝初历少府、太子太傅、御史大夫，永光间代于定国为相、复扶阳侯，作另一诗戒后代。 [[23]](#note-23)


<a id="event-24"></a>

24. **复爵诗一｜回顾车服获罪。** 先赞守德君子恭谨服仪，再自责不及他们，荒怠车服以致从高位跌落。 [[24]](#note-24)


<a id="event-25"></a>

25. **复爵诗二｜再任九卿三公所受恩。** 天子未弃，复任九列，韦玄成以夙夜尽职回报；天子再升之三公，又赐旧爵。 [[25]](#note-25)


<a id="event-26"></a>

26. **复爵诗三｜念前人仍怀谨惧。** 往日再临旧阶使其思先人而流泪；称同官祝贺，也有人不理解首相勤劳难尽。今惟恐复坠，职位超其所料，退意未尝忘。 [[26]](#note-26)


<a id="event-27"></a>

27. **复爵诗四｜戒子孙保位不忝先祖。** 告后人禄命无常，享位当静敬，出会慎仪；勿学其先过，自己失而复得只是幸运，后人宜敬慎庇汉室。 [[27]](#note-27)


<a id="event-28"></a>

28. **韦玄成卒，获许从父墓归葬。** 传称居相七年，持重逊父、文采过之。建昭三年薨谥共侯，临终因侍使自陈父子之恩，请从自己所居杜陵归葬父墓获准。 [[28]](#note-28)


<a id="event-29"></a>

29. **扶阳侯后嗣及同族仕宦。** 韦宽、韦育、韦沈依次承爵，至韦贤玄孙绝国。方山子韦安世有公卿名望而病终；韦弘子韦赏以故定陶王师受哀帝厚待，任大司马车骑将军，得关内侯及邑，传称八十余寿终。宗族二千石者十余。 [[29]](#note-29)


<a id="event-30"></a>

30. **历帝庙、郡国庙和寝园规模。** 概述高祖令诸王都立太上皇庙、惠帝定高帝太祖、景帝定孝文太宗、宣帝定武帝世宗。又列郡国六十八处辖地合庙百六十七、合京畿共百七十六，寝、庙、便殿各有日月时祭，月游衣冠。包括诸帝外若干后、王和太子，合三十寝园，岁上食二万余，卫士四万余，祝宰乐人一万余。 [[30]](#note-30)


<a id="event-31"></a>

31. **祭祀频率议及两太后寝园。** 议者以清静敬神、数祭反渎，请停日月间祀及衣冠出游、改四时庙祭，帝没有改。次年韦玄成请依礼不复修孝文、孝昭二太后寝园，获准。 [[31]](#note-31)


<a id="event-32"></a>

32. **匡衡因帝梦祷告，仍持郡国无庙。** 韦玄成死、匡衡继相后，元帝患病梦祖宗怪罢郡庙，楚孝王也有梦。匡衡反对复立：京师可亲祭，远郡吏卑不能独承，连歉也增加耗费。祷文请若违礼由自身受咎，帝能康复。 [[32]](#note-32)


<a id="event-33"></a>

33. **匡衡对已毁诸庙行告谢之礼。** 祷辞以五行人亲五属说明五庙与合祭，辨太上皇非受命且亲尽、后妃亲祭递减。虽帝愿病中恢复，匡衡与中朝称据六艺不当为复祭立文，以己承过、求帝祉寿。诸庙告文相同。 [[33]](#note-33)


<a id="event-34"></a>

34. **元帝崩后裁祠，成帝再复太上皇。** 匡衡以恢复寝庙未能祈福为由，保留卫思后等亲未尽之园，罢惠景庙、太上皇及若干后妃寝祠。篇中追叙高后曾禁擅议庙园、元帝撤令；成帝无嗣，河平元年九月复太上皇寝庙园，昭灵后等并食，复申禁擅议。 [[34]](#note-34)


<a id="event-35"></a>

35. **刘歆解释祭祀递减及昭穆。** 据《春秋外传》日祭、月祀、时享、岁贡、终王，认为远亲减频而德可益尊；祖孙隔代同昭穆，孫居王父之位，主张圣人礼因情而无须毁庙。评贡禹起议后太上皇及惠景废失礼。原文并列祭礼名称。 [[35]](#note-35)


<a id="event-36"></a>

36. **王莽请毁皇考庙与变更二陵县。** 追本始元年仅给悼园奉邑三百家、元康元年加皇考尊号、立庙并置奉明县。平帝时王莽与平晏等认为宣帝已入继昭帝，尊生父另庙会成为两统；区分开国受命者与承宗者，奏毁皇高祖考廟奉明园、罢两太后陵为县，获准。本传只记元始中。 [[36]](#note-36)


<a id="event-37"></a>

37. **班彪论礼书缺佚与议制多变。** 班彪说汉承秦火后学术断缺，制度随时。贡禹毁庙、匡衡改郊兆、何武定三公后皆反复，因礼文不全、古今不同、各执一说；综览众议称刘歆学博而谨。 [[37]](#note-37)

> 後歲餘，玄成薨，匡衡為丞相。上寢疾，夢祖宗譴罷郡國廟，上少弟楚孝王亦夢焉。上詔問衡，議欲復之，衡深言不可。上疾久不平，衡惶恐，禱高祖、孝文、孝武廟曰：「嗣曾孫皇帝恭承洪業，夙夜不敢康寧，思育休烈，以章祖宗之盛功。故動作接神，必因古聖之經。往者有司以為前因所幸而立廟，將以繫海內之心，非為尊祖嚴親也。今賴宗廟之靈，六合之內莫不附親，廟宜一居京師，天子親奉，郡國廟可止毋修。皇帝祗肅舊禮，尊重神明，即告于祖宗而不敢失。今皇帝有疾不豫，乃夢祖宗見戒以廟，楚王夢亦有其序。皇帝悼懼，即詔臣衡復修立。謹案上世帝王承祖禰之大義，皆不敢不自親。郡國吏卑賤，不可使獨承。又祭祀之義以民為本，間者歲數不登，百姓困乏，郡國廟無以修立。禮，凶年則歲事不舉，以祖禰之意為不樂，是以不敢復。如誠非禮義之中，違祖宗之心，咎盡在臣衡，當受其殃，大被其疾，隊在溝瀆之中。皇帝至孝肅慎，宜蒙祐福。唯高皇帝、孝文皇帝、孝武皇帝省察，右饗皇帝之孝，開賜皇帝眉壽亡疆，令所疾日瘳，平復反常，永保宗廟，天下幸甚！」

### 33. 匡衡对已毁诸庙行告谢之礼

[返回正文第33条](#event-33)

<a id="hs073-p036"></a>

**[《汉书·韦贤传》P036](../../sources/摘录/汉书-卷073-韦贤传.md#p036)** · [仓内TXT L8859—L8859](../../sources/本地分卷/汉书/汉书-卷073.md#L8859)

> 又告謝毀廟曰：「往者大臣以為在昔帝王承祖宗之休典，取象於天地，天序五行，人親五屬，天子奉天，故率其意而尊其制。是以禘嘗之序，靡有過五。受命之君躬接于天，萬世不墮。繼烈以下，五廟而遷，上陳太祖，間歲而祫，其道應天，故福祿永終。太上皇非受命而屬盡，義則當遷。又以為孝莫大於嚴父，故父之所尊子不敢不承，父之所異子不敢同。禮，公子不得為母信，為後則於子祭，於孫止，尊祖嚴父之義也。寢日四上食，園廟間祠，皆可亡修。皇帝思慕悼懼，未敢盡從。惟念高皇帝聖德茂盛，受命溥將，欽若稽古，承順天心，子孫本支，陳錫亡疆。誠以為遷廟合祭，久長之策，高皇帝之意，乃敢不聽？即以令日遷太上、孝惠廟，孝文太后、孝昭太后寢，將以昭祖宗之德，順天人之序，定無窮之業。今皇帝未受茲福，乃有不能共職之疾。皇帝願復修承祀，臣衡等咸以為禮不得。如不合高皇帝、孝惠皇帝、孝文皇帝、孝武皇帝、孝昭皇帝、孝宣皇帝、太上皇、孝文太后、孝昭太后之意，罪盡在臣衡等，當受其咎。今皇帝尚未平，詔中朝臣具復毀廟之文。臣衡中朝臣咸復以為天子之祀義有所斷，禮有所承，違統背制，不可以奉先祖，皇天不祐，鬼神不饗。六藝所載，皆言不當，無所依緣，以作其文。事如失指，罪乃在臣衡，當深受其殃。皇帝宜厚蒙祉福，嘉氣日興，疾病平復，永保宗廟，與天亡極，群生百神，有所歸息。」諸廟皆同文。

### 35. 刘歆解释祭祀递减及昭穆

**[《汉书·韦贤传》P041](../../sources/摘录/汉书-卷073-韦贤传.md#p041)** · [仓内TXT L8864—L8864](../../sources/本地分卷/汉书/汉书-卷073.md#L8864)

> 歆又以為「禮，去事有殺，故《春秋外傳》曰：『日祭，月祀，時享，歲貢，終王。』祖禰則日祭，曾高則月祀，二祧則時享，壇墠則歲貢，大禘則終王。德盛而游廣，親親之殺也；彌遠則彌尊，故禘為重矣。孫居王父之處，正昭穆，則孫常與祖相代，此遷廟之殺也。聖人於其祖，出於情矣，禮無所不順，故無毀廟。自貢禹建迭毀之議，惠、景及太上寢園廢而為虛，失禮意矣。」

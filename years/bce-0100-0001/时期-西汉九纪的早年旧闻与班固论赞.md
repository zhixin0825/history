# 西汉｜九纪中的早年旧闻与班固论赞

[本世纪目录](README.md) · [全部世纪](../README.md)

本页收录不能系到单一年度的早年叙事、跨年回顾及班固论赞，所涉皇帝的确年史事从各卷去向查阅。

<a id="event-1"></a>

1. **班固赞惠帝宽仁。** 篇末称惠帝亲厚宗室、尊重宰相，优待刘肥、刘如意，能听叔孙通与曹参的劝说。班固赞其宽仁，又为吕太后损害其德行而惋惜。 [[1]](#note-1)

<a id="event-2"></a>

2. **班固论惠帝与吕后时期休养。** 篇末说秦末战乱后，君臣希望减少干预，惠帝少事、高后在内廷理政，刑罚较少，百姓专务耕作，衣食增多。 [[2]](#note-2)

<a id="event-3"></a>

3. **班固赞文帝俭德。** 篇末以文帝不增宫苑舆服、不作百金露台、霸陵用瓦器、以德怀柔赵佗、对匈奴避免深入征讨、礼纳袁盎等为例，称其俭朴仁厚，重教化，民生富足、案件减少。 [[3]](#note-3)

<a id="event-4"></a>

4. **班固论景帝承文帝之业。** 班固以秦末法密刑严反衬汉初休养，认为文帝恭俭、景帝承续，历数十年而改变风俗，把文景与周成康并举。 [[4]](#note-4)

<a id="event-5"></a>

5. **班固赞武帝制度而惜民力。** 班固说高祖平乱，文、景养民，古礼制度尚多缺。武帝表章六经、举才、兴太学，建立郊祀封禅、改革历法和礼乐、绍周后，其制度为子孙留下基础；最后用假设语指出，若兼有文景恭俭以养民，其成就会更高。 [[5]](#note-5)

<a id="event-6"></a>

6. **班固赞昭帝与霍光的休养。** 篇末以周成王信周公比昭帝信霍光，回顾武帝后人口耗损、减徭薄赋、汉匈关系缓和，以及举荐贤良文学、盐铁会议后撤酒榷，称昭帝谥号相称。 [[6]](#note-6)

<a id="event-7"></a>

7. **掖庭抚养与民间生活。** 朝廷命掖庭抚养皇曾孙，并由宗正列入宗籍。张贺顾念戾太子旧恩，用私钱供养他、让他读书，成年后又帮他娶许广汉之女。皇曾孙从澓中翁学《诗》，也斗鸡跑马、遍游三辅，熟悉民情和官吏得失。篇末说他身有异相、居处发光，向哪家买饼，那家生意便好起来，都是传闻。 [[7]](#note-7)

<a id="event-8"></a>

8. **班固总评宣帝一朝。** 赞语称宣帝赏罚信实、考核名实，使政务、文学、法理及工艺各得其用；又认为他在匈奴内乱时处置得当，促成单于称藩，把宣帝与殷宗、周宣王相比。这是史家总评。 [[8]](#note-8)

<a id="event-9"></a>

9. **元帝出身与劝用儒士。** 刘奭是许皇后所生，幼年随父在民间，八岁立太子。他性情宽柔、喜儒学，见宣帝重用文法吏且杨恽、盖宽饶因言获罪，乘闲陈说宽刑用儒。 [[9]](#note-9)

<a id="event-10"></a>

10. **宣帝答太子并一度考虑易储。** 宣帝说汉家制度并用王道、霸道，批评拘泥古制者不适当世。他更喜好淮阳王的察法之才，也一度动易储之念，终因不忘许氏微贱时相依而未改。 [[10]](#note-10)

<a id="event-11"></a>

11. **班固评元帝才艺和政事。** 班固据亲族旧闻称元帝多才、能鼓琴吹箫及制曲；即位任儒臣，贡、薛、韦、匡相继执政。作者批评他拘文少决，也称其宽厚恭俭、诏令温雅。 [[11]](#note-11)

<a id="event-12"></a>

12. **刘骜早年与太子地位。** 刘骜生于太子宫，幼得宣帝喜爱。元帝即位后立他为太子，《元帝纪》系于初元二年前47年。刘骜一度绕驰道赴召，元帝因其守礼特许横穿；后来他因酒宴受冷落，史丹维护，加上宣帝旧恩，保住储位。 [[12]](#note-12)

<a id="event-13"></a>

13. **班固论成帝与王氏权势。** 班固据亲族见闻赞成帝仪态持重、博览容谏，指出他沉溺酒色、赵氏乱宫、外家专权；将王莽篡位追溯到自建始起王氏渐掌权柄。 [[13]](#note-13)

### 12. 刘骜早年与太子地位

[返回正文第12条](#event-12)

<a id="hs010-l860"></a>

**[《汉书·成帝纪》P001](../../拆分史书/汉书/卷010.md#p001)** · [仓内TXT L860](../../拆分史书/汉书/卷010.md#part-1-L860)

> 孝成皇帝，元帝太子也。母曰王皇后，元帝在太子宮生甲觀畫堂，為世嫡皇孫。宣帝愛之，字曰太孫，常置左右。年三歲而宣帝崩，元帝即位，帝為太子。壯好經書，寬博謹慎。初居桂宮，上嘗急召，太子出龍樓門，不敢絕馳道，西至直城門，得絕乃度，還入作室門。上遲之，問其故，以狀對。上大說，乃著令，令太子得絕馳道云。其後幸酒，樂燕樂，上不以為能。而定陶恭王有材藝，母傅昭儀又愛幸，上以故常有意欲以恭王為嗣。賴侍中史丹護太子家，輔助有力，上亦以先帝尤愛太子，故得無廢。

### 13. 班固论成帝与王氏权势

**[《汉书·成帝纪》P137](../../拆分史书/汉书/卷010.md#p137)** · [仓内TXT L996](../../拆分史书/汉书/卷010.md#part-1-L996)

> 贊曰：臣之姑充後宮為婕妤，父子昆弟侍帷幄，數為臣言成帝善修容儀，升車正立，不內顧，不疾言，不親指，臨朝淵嘿，尊嚴若神，可謂穆穆天子之容者矣！博覽古今，容受直辭。公卿稱職，奏議可述。遭世承平，上下和睦。然湛于酒色，趙氏亂內，外家擅朝，言之可為於邑。建始以來，王氏始執國命，哀、平短祚，莽遂篡位，蓋其威福所由來者漸矣！

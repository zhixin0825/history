汉初十月岁首，古史整年对应不是逐日公历换算；前200年页的冬十月不直接等于现代历前200年10月。项氏等人的战功、归附和初封分开，见[卷007授爵核对](../../meta/考证/史记-卷007-纪年与异说.md#封赏)。高祖晚年及死后的原庙、八子后叙见[卷008考证](../../meta/考证/史记-卷008-纪年与异说.md)。

前194、190、181、180年页尚只接住本卷材料及必要背景，惠帝、高后的其他事件仍待下一卷等继续汇入；未写年份不设空页。

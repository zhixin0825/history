**汉武帝太初四年**

<a id="sj017-audience"></a>
## 梁王刘襄、长沙王刘庸入朝

**刘襄和刘庸在本年来到朝廷。** 刘襄是梁孝王刘武的孙子，刘庸是长沙王刘发之子。两人的封国仍在继续，不因现有年表在这一年收笔，就写成王国灭亡或他们当年去世。[原文与说明](#sj017-note)

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e026"></a>
### 昌武一支无后除国

昌武侯充国去世，没有后人承爵，封国撤销。 [原文与说明](#sj020-e026-n)

<a id="sj020-e119"></a>
### 首承外石侯

首开始记外石侯元年，接续吴阳一支。 [原文与说明](#sj020-e119-n)

<a id="sj021"></a>
## 王子分邑与侯国的接续

<a id="sj021-r113-e02"></a>
**繁安侯爵由后人接续。** 刘壽接续繁安侯爵，侯统进入新的一代。 [原文与说明](#sj021-r113-e02-n)

<a id="sj021-r160-e02"></a>
**皋虞侯爵由后人接续。** 刘定接续皋虞侯爵，侯统进入新的一代。 [原文与说明](#sj021-r160-e02-n)

<a id="sj020-note"></a>
### 卷020｜原格、互见与采用的年线

[完整原文](../../sources/摘录/史记-卷020-建元以来侯者年表.md) · [逐格去向](../../meta/记录/史记-卷020-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷020-纪年与异说.md)。初封、增邑、继承与任官分开；月日未明不补，谥号为后称，国除不一律等于处死。

<a id="sj020-e026-n"></a>
**昌武一支无后除国：** [R010 昌武](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r010)。依据汉表太初元年嗣、四年薨的任期归年，属于连续侯统推算；史表将死亡记太初元年。两种记法择一主线，不能两年各死一次。 互校：[漢書/卷017](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7017)。

<a id="sj020-e119-n"></a>
**首承外石侯：** [R057 北石](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r057)。只给侯籍元年，不据此确定吴阳的卒日。


<a id="sj017-note"></a>
[卷017太初四年末行](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0101)记梁三十六、长沙二十八来朝；长沙年数沿史记本表，其元年与汉书有一年差，见[前127年](bce-0127.md#sj017-kings-note)。同年不等于同日，未列月日不补造。

表序说“高祖以来至太初”是本卷覆盖边界，原表末年没有记来朝的国也不等于已灭。城阳栏末行空白照存，不为整齐填一个数字后说它出自原文；篇末唐代司马贞的[述赞](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#p005)是后世评论，不是本年新发生的一项政治行动。

<a id="sj021-note"></a>
## 卷021补入的原格与采用年线

[全卷原文](../../sources/摘录/史记-卷021-建元以来王子侯者年表.md) · [逐格去向](../../meta/记录/史记-卷021-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷021-纪年与异说.md)。月日原字保留；古史年条不直接换算同号公历日。爵号、人名及父系有分歧者见同号说明，不把今侯译作当年初封。

<a id="sj021-r113-e02-n"></a>
**繁安侯爵由后人接续：** [R113 繁安](../../sources/摘录/史记-卷021-建元以来王子侯者年表.md#r113)。史太初四年寿嗣；汉元封四年守嗣，后列寿汉而无确年，可能非同一代。保留两种谱系口径，不强认寿就是守，也不删史明年。 本项原格为太初4年条。 两表整行原字见[史汉互校](../../meta/记录/史记-卷021-史汉逐行互校.md#r113)。

> 三。一。四年，今侯壽元年。

<a id="sj021-r160-e02-n"></a>
**皋虞侯爵由后人接续：** [R160 皋虞](../../sources/摘录/史记-卷021-建元以来王子侯者年表.md#r160)。正文同时采用汉表该继侯名，原史异名另存。史元鼎元年建初封、四年处嗣；汉元封元年建封、太初四年定嗣。取汉表前110年封、前101年嗣的连续明年线；处／定及两套年份原字保留。 本项原格为元鼎4年条（按原栏对应前113年，正文暂取前101年）。 两表整行原字见[史汉互校](../../meta/记录/史记-卷021-史汉逐行互校.md#r160)。

> 三。元年五月丙午，侯劉建元年。三。四年，今侯處元年。

1. **梁王刘襄、长沙王刘庸入朝。** 刘襄和刘庸在本年来到朝廷。 刘襄是梁孝王刘武的孙子，刘庸是长沙王刘发之子。两人的封国仍在继续，不因现有年表在这一年收笔，就写成王国灭亡或他们当年去世。 [[1]](#note-1)

2. **昌武一支无后除国。** 昌武侯充国去世，没有后人承爵，封国撤销。 [[2]](#note-2)

4. **繁安侯爵由后人接续。** 刘壽接续繁安侯爵，侯统进入新的一代。 [[4]](#note-4)

<a id="sj021-r160-e02"></a>

<a id="event-5"></a>

5. **皋虞侯爵由后人接续。** 刘定接续皋虞侯爵，侯统进入新的一代。 [[5]](#note-5)

<a id="sj024"></a>
<a id="大宛良马运来又作西极天马歌"></a>

<a id="event-6"></a>

6. **征大宛的汉军带回良马，朝廷制作《西极天马》之歌。** 歌辞把远来的天马与皇帝的威德相连，称颂越过流沙、使四夷宾服的功业。 [[6]](#note-6)

<a id="sj049-li-guangli-event"></a>

7. **李广利征大宛归来，受封海西侯。** 他以贰师将军领军远征，归来后获得侯爵。李延年等此前已遭族诛，李广利在外免祸；武帝后来怜惜李夫人一家的叙述，与这次封赏相联系。此前出师、征宛经过与归后受侯是不同阶段。 [[7]](#sj049-li-guangli-note)

### 6. 征大宛的汉军带回良马，朝廷制作《西极天马》之歌

[返回正文第6条](#event-6)

**[卷024 P007](../../sources/摘录/史记-卷024-乐书.md#p007)**

> 又嘗得神馬渥洼水中，復次以為太一之歌。歌曲曰：「太一貢兮天馬下，霑赤汗兮沫流赭。騁容與兮跇萬里，今安匹兮龍為友。」後伐大宛得千里馬，馬名蒲梢，次作以為歌。歌詩曰：「天馬來兮從西極，經萬里兮歸有德。承靈威兮降外國，涉流沙兮四夷服。」中尉汲黯進曰：「凡王者作樂，上以承祖宗，下以化兆民。今陛下得馬，詩以為歌，協於宗廟，先帝百姓豈能知其音邪？」上默然不說。丞相公孫弘曰：「黯誹謗聖制，當族。」

**[P120](../../sources/摘录/史记-卷027-天官书.md#p120)**

> 漢之興，五星聚于東井。平城之圍，月暈參、畢七重。諸呂作亂，日蝕，晝晦。吳楚七國叛逆，彗星數丈，天狗過梁野；及兵起，遂伏尸流血其下。元光、元狩，蚩尤之旗再見，長則半天。其後京師師四出，誅夷狄者數十年，而伐胡尤甚。越之亡，熒惑守鬬；朝鮮之拔，星茀于河戍；兵征大宛，星茀招搖：此其犖犖大者。若至委曲小變，不可勝道。由是觀之，未有不先形見而應隨之者也。

## 归年与考证

<a id="sj024-note"></a>
<a id="卷024音乐史事的互见与归年"></a>
#### 卷024｜音乐史事的互见与归年

[卷024 P007](../../sources/摘录/史记-卷024-乐书.md#p007)“后伐大宛”及后首天马歌，与[《汉书·武帝纪》太初四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-93d6387fadaa45)春“获汗血马来，作西极天马之歌”相接；[《汉书·礼乐志》天马第十](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7022.md#ref-97b9f4baad0781)后曲亦注太初四年诛宛王、获宛马作。两首歌分别与[前113年渥洼得马](bce-0113.md#sj024-note)和本年伐宛所得相连，不合并为同一首、同一次得马。

《乐书》记马名蒲梢，并用简短四句叙后首歌；汉志同题歌辞更长，不能用汉志全文覆盖本卷的短本后宣称原文完全一致。歌中四夷服、归有德等属于帝国自我赞颂，不等于已据此证成所有邻国同时臣服。紧接歌词的汲黯、公孙弘争论不归本年，原因见[前121年公孙弘卒年核对](bce-0121.md#sj024-note)。

《天官书》[P120](../../sources/摘录/史记-卷027-天官书.md#p120)“兵征大宛”与这段前后战争互见，但“星茀招搖”在《汉书》中仅有“太初中”的范围。其原文和未定年说明已合在[前104年出兵注7](bce-0104.md#note-7)，不把获马年当作观星年，也不在此另立第二场相同的征宛战争。

**昌武一支无后除国：** [R010 昌武](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r010)。依据汉表太初元年嗣、四年薨的任期归年，属于连续侯统推算；史表将死亡记太初元年。两种记法择一主线，不能两年各死一次。 互校：[漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-eb7af22c1f2ee3)。

<a id="sj017-note"></a>
[卷017太初四年末行](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0101)记梁三十六、长沙二十八来朝；长沙年数沿史记本表，其元年与汉书有一年差，见[前127年](bce-0127.md#sj017-kings-note)。同年不等于同日，未列月日不补造。

表序说“高祖以来至太初”是本卷覆盖边界，原表末年没有记来朝的国也不等于已灭。城阳栏末行空白照存，不为整齐填一个数字后说它出自原文；篇末唐代司马贞的[述赞](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#p005)是后世评论，不是本年新发生的一项政治行动。

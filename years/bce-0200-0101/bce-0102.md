# 公元前102年｜重登泰山修封，泗水由刘贺绍封

[← 公元前103年](bce-0103.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前101年 →](bce-0101.md)

**汉武帝太初三年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，并补王国继承；不表示武帝当年的战争、税政和全国史事都已收齐。跨年回叙不当成同年新事。

<a id="sj012-102-1"></a>
## 海上求仙仍无验证

**武帝再次到海上考察方士宣称的神人，结果还是没有确切证据。** 有方士提出建「五城十二楼」迎神，皇帝同意设祠；朝廷仍愿为可能出现的仙人花费人力，但记录的结局始终是没有见到可验证的神仙。

**他又往被称作东泰山的地方视察。** 实地看山势远比传闻低小，便让祠官祭祀，没有在当地照计划举行封禅。随后回到泰山修封，在石闾增加禅祭。仪式上出现的「五年之礼」，表示既有修封周期，不等于每一步都与五年前完全相同。

**本段史料：** [卷012 P028](../../sources/摘录/史记-卷012-孝武本纪.md#p028)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-6fec42df0ff6c5)。《汉书》太初三年春东巡、夏四月修封泰山禅石闾；「明年」在这里也有建筑和年号混淆，见考证。

<a id="sj017-sishui"></a>
## 刘贺承接兄长，泗水国得以延续

**刘贺以刘商之子的身份绍封泗水。** 兄长刘安世去世、没有后嗣，王国改由弟弟继续奉祀。这里的“绍封”不是刘贺征服了另一片新地，也不是一个儿子接替父亲的同样故事。[原文与说明](#sj017-note)

<a id="sj017-note"></a>
[汉书诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7014.md#ref-d6bc4b0605e101)明记太初三年“戴王贺以思王子绍封”；[卷017前103年原格](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0103)却把两王元年并写且称安世子。采用汉书年次及《五宗世家》的兄弟关系，原文分歧留在[前103年注](bce-0103.md#sj017-note)，不在两年各封一次。卷017本年前102年行只有数字和标点，并不等于其他史料没有可补的事件。泗水刘贺与后来昌邑同名王分清。

<a id="sj018-note"></a>
### 卷018｜原格、异年与本页采用

**逐格定位：** <a id="sj018-r103-wu"></a>[R103](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r103)。

本页按原格中明确年号、承袭次序及互见材料分别定位；未载月份的不补日期，元年也不一律倒推父亲死年。侯爵与所任中央官职不是同一继承关系。

**R103：** 史表在武帝栏先计“七，罪绝”，与汉表景帝中三年嗣、在位十四年的任期相接，暂系元光元年即前134年，未得确月；原侯名生，汉表作王，继承链另有差。续封史表睢阳张广、汉表睢陵张广国，两表都系元光三年；承爵张昌均为元鼎二年。末案史表太初三年，汉表太初二年，本页暂沿前102年并保留前103年异说。正文不把父祖谱系和各总任期硬拼为完全一致，亦不把“乏祠”扩成一次已详知过程的渎神谋反案。

互校：[《汉书》高惠高后文功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-86f4e38b8f88a8) · [《史记》三家注卷018](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7018.md#ref-4c51d8fd802c9c)。

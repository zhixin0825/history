# 公元前102年｜重登泰山修封，泗水由刘贺绍封

[← 公元前103年](bce-0103.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前101年 →](bce-0101.md)

**汉武帝太初三年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，并补王国继承；不表示武帝当年的战争、税政和全国史事都已收齐。跨年回叙不当成同年新事。

1. **武帝巡海上与东泰山，回泰山修封。** 武帝再次到海上考察方士宣称的神人，结果还是没有确切证据。有方士提出建「五城十二楼」迎神，皇帝同意设祠；朝廷仍愿为可能出现的仙人花费人力，但记录的结局始终是没有见到可验证的神仙。实地看山势远比传闻低小，便让祠官祭祀，没有在当地照计划举行封禅。随后回到泰山修封，在石闾增加禅祭。仪式上出现的「五年之礼」，表示既有修封周期，不等于每一步都与五年前完全相同。四月，武帝东巡回到泰山，重修封礼，又在石闾行禅礼。 [[1]](#note-1)

   《汉书》太初三年春东巡、夏四月修封泰山禅石闾；「明年」在这里也有建筑和年号混淆，见考证。

<a id="sj017-sishui"></a>
<a id="刘贺承接兄长泗水国得以延续"></a>

<a id="event-3"></a>

2. **刘贺承接兄长，泗水国得以延续。** 刘贺以刘商之子的身份绍封泗水。 兄长刘安世去世、没有后嗣，王国改由弟弟继续奉祀。这里的“绍封”不是刘贺征服了另一片新地，也不是一个儿子接替父亲的同样故事。 [[2]](#note-3)

11. **儿单于去世，呴犁湖继立。** 儿单于准备亲攻受降城，途中病死。因其子年少，匈奴另立乌维之弟、原右贤王呴犁湖。 [[11]](#sj110-note-12)

12. **汉筑塞外城障，匈奴入边。** 徐自为筑五原塞外城障，路博德筑居延。徐自为从五原出塞筑亭障，韩说与卫伉屯守近处，路博德负责居延泽防务。匈奴攻入定襄、云中，并侵酒泉、张掖。匈奴掳杀居民并毁五原塞外城障；右贤王另袭酒泉、张掖，汉将任文赴援，夺回其所掳。 [[12]](#note-13)

<a id="sj123-event-15"></a>

13. **李广利增兵再出敦煌，第二次征大宛。** 汉军增加兵员、粮秣与转运力量，李广利率军再次出敦煌。途中进兵与大宛盟约属于此役，确日未载。汉军于太初四年春回到京师。 [[13]](#note-15)

<a id="hs-event-21"></a>

# 公元前103年｜祭牲调整，泗水王刘安世短暂承继

[← 公元前104年](bce-0104.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前102年 →](bce-0102.md)

**汉武帝太初二年**

本页保留《孝武本纪》的宗庙、郊祭与制度主线，另补王国继承；不表示武帝当年的战争、税政和全国史事都已收齐。跨年回叙不当成同年新事。

<a id="sj012-103-1"></a>
## 减少一部分祭祀用马

**有司反映雍五畤祭祀供品不够完备，建议增加合规的牲品和食物。** 朝廷在若干名山川的例行祭祀中，以木制的马替代活马驹；但祭五帝或皇帝亲自郊祭的情形，仍可能使用真马。

**这是祭品的分场合调整，不是天下禁止杀马，也不是所有祭祀从此一律改用木马。** 祭祀活动越来越制度化，细部成本和例外条件也要说明清楚。

**本段史料：** [卷012 P027](../../sources/摘录/史记-卷012-孝武本纪.md#p027)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-f240ee266468fc)。卷012用「其明年」承太初元年，《汉书》太初二年可作年次对照，祭牲限制按原文。

<a id="sj017-sishui"></a>
## 刘安世元年，又因无后面临继承问题

**刘安世承接父亲刘商，却很快去世，没有儿子继位。** 这一支泗水国没有因此永久消失，朝廷后来改让他的弟弟刘贺承接。父王、长子、次子的关系必须分清，不能把刘贺写成刘安世的儿子。[原文与说明](#sj017-note)

<a id="sj017-audience"></a>
**中山王刘昆侈本年入朝。** 本表计九年，采用汉书的前110年元年则为八年；保留来朝年，不修改原表数字来掩盖继承年差。[原格与说明](#sj017-note)

<a id="sj017-note"></a>
[卷017前103年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0103)同格写安世元年、即戴王贺元年及“安世子”；[五宗世家](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7059.md#ref-6053f5a62c25f9)却明确贺是安世弟，[汉书诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7014.md#ref-6948e938c34036)又记安世太初二年嗣、一年无后，贺太初三年以思王商子绍封。正文采用兄弟关系与汉书的前103—102年顺序，原格的不同亲缘与同年写法保留，不无声改造原文。世家传本文字“十一年卒”同样不能拿来强造安世十余年的在位。

刘贺正式绍封接[前102年](bce-0102.md#sj017-sishui)；这位泗水王刘贺不是后来昌邑王、海昏侯刘贺。中山在位计数的一年差见[前112—110年继承说明](bce-0112.md#sj017-note)，来朝未记月份，不能借祭五畤的叙次替它定日。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e028"></a>
### 襄城侯战死

襄城侯随浞野侯赵破奴出征，在战斗中死亡。他的终局与赵破奴被俘同属一次战败，并非另有一次太初年间相似战争。 [原文与说明](#sj020-e028-n)

<a id="sj020-e097"></a>
### 石庆去世

丞相石庆去世，牧丘侯籍随后由子辈接续。 [原文与说明](#sj020-e097-n)

<a id="sj020-e122"></a>
### 涉都侯无后除国

涉都侯嘉去世，没有后人承爵，封国终止。 [原文与说明](#sj020-e122-n)

<a id="sj020-e137"></a>
### 涅阳侯最无后除国

最去世，没有承爵者，涅阳侯国终止。 [原文与说明](#sj020-e137-n)

<a id="sj020-e143"></a>
### 赵破奴全军失利，被匈奴俘获

浞野侯赵破奴再次出击匈奴，兵败被俘，侯国撤销。襄城侯在同次战事中战死；失陷、战死和失爵三种结果不可互换。 [原文与说明](#sj020-e143-n)

<a id="sj020-e144"></a>
### 公孙贺任丞相，复封葛绎侯

公孙贺出任丞相，重新取得列侯身份，封为葛绎侯。他前112年丢失的南奅爵位与本次新封分开。 [原文与说明](#sj020-e144-n)

# 公元前104年（汉武帝太初元年）

<a id="reading-start"></a>


[← 公元前105年](bce-0105.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前103年 →](bce-0103.md)

[读本年史料](#本年相关史料) · [归年与异说详解](../../meta/考证/前0104年-史料与归年说明.md)

朝廷继续举行泰山礼仪，柏梁台火灾后又启动建章宫工程。夏五月，历法和官名等制度一同调整；秋天，李广利率军向大宛进发。中央的改制、远方的战争与诸侯王侯家的承续，都在这一年继续展开。

<a id="event-1"></a>
<a id="sj012-104-1"></a>

1. **冬十一月，武帝在泰山明堂祭祀上帝。** 冬十月，武帝前往泰山。十一月甲子朔旦，他在明堂祭祀上帝；朝廷把这次冬至与岁时更新联系起来，祭辞称颂天道周而复始。皇帝此前已经举行过泰山封禅，这次是在既有礼制上的继续举行。 [[1]](#note-1)

<a id="event-2"></a>

2. **十一月乙酉，柏梁台失火。** 长安的柏梁台发生火灾。这座高台兴建于元鼎年间，毁坏后，朝廷开始考虑另建规模更大的宫殿。火灾也给方士提供了进言的机会，他们以古帝王和越地风俗解释灾后应当如何营建。 [[2]](#note-2)

<a id="event-3"></a>

3. **十二月，祭高里、望祠蓬莱，春回甘泉受计。** 武帝亲往高里祭后土，又来到渤海岸边，望祀传说中的蓬莱神山。他仍希望求得神仙消息，派往海上的人却没有带来确实结果。春天返回后，因柏梁台已毁，他在甘泉接受郡国上报的政务账目；此后甘泉也营建诸侯朝见时居住的邸舍。 [[3]](#note-3)

<a id="event-4"></a>

4. **二月，开始兴建建章宫。** 武帝采纳了灾后另建大宫的意见，命人兴建建章宫。工程规划追求“千门万户”的规模，前殿拟高过未央宫，又在北面营建太液池，在池中仿造蓬莱、方丈、瀛洲等海中神山。神明台、井干楼及彼此相连的通道，也属于这座宫殿宏大的建筑构想。 [[4]](#note-4)

<a id="event-5"></a>
<a id="sj012-104-2"></a>
<a id="sj026"></a>

5. **夏五月，改历，以正月为岁首。** 朝廷正式修订历法，把沿用的十月岁首改为正月岁首，改称太初元年；同时崇尚黄色，制度取数用五，调整官名、印章和音律。大行令在这一年改称大鸿胪，负责朝廷接待和有关礼仪。公孙卿、壶遂、司马迁等参加改历议论，唐都分定天区和星宿距离，巴郡人落下闳承担历算；邓平等也参加比算、校候，朝廷最后采用邓平所造的八十一分历法。 [[5]](#note-5)

<a id="event-6"></a>

6. **朝廷派公孙敖在塞外修筑受降城。** 改历之际，北边的经营仍在继续。朝廷派因杅将军公孙敖率人到塞外修筑受降城，以此扩展边地据点。 [[6]](#note-6)

<a id="event-7"></a>

7. **秋八月，李广利率军西征大宛。** 武帝出巡安定，又派贰师将军李广利征发天下被谪罚的民众，向西攻打大宛。远征从这一年开始，此后的行军、受挫与再次出兵还将延续数年。与此同时，丁夫人、洛阳人虞初等方术人士为朝廷施行诅咒匈奴和大宛的祠术。 《大宛列传》记汉先遣车令持重金求贰师善马，因拒绝、毁金马及使团遭截杀，武帝转而兴兵。 [[7]](#note-7)

<a id="event-8"></a>

8. **蝗群从东方飞到敦煌。** 这一年蝗灾大起，史书记载蝗群从东方一直飞至敦煌。汉军正向西远征，河西一带也受到这场灾害的影响。 [[8]](#note-8)

<a id="event-9"></a>
<a id="sj017-sishui"></a>

9. **泗水王刘商去世，刘安世接续王位。** 泗水王刘商去世。他是常山王刘舜的儿子，在常山王国被废、重新分封以后取得泗水封号。儿子刘安世接续王位，泗水王国继续存在；刘安世的元年从下一年起记。 [[9]](#note-9)

<a id="event-10"></a>
<a id="sj017-audience"></a>

10. **六安王刘庆来朝。** 六安王刘庆来到朝廷。他是胶东王刘寄的儿子，早已另受六安封国；这次是诸侯王入朝，并非重新受封。 [[10]](#note-10)

<a id="event-11"></a>
<a id="sj020"></a>
<a id="sj020-e025"></a>

11. **赵充国继承昌武侯爵。** 昌武侯一支由赵充国承接。其父赵安稽原是归汉的匈奴王，后来又从军立功、增加封邑；如今侯爵转到儿子手中，继续在赵家传承。这里的赵充国是赵安稽之子，与后来以平羌著称的营平侯赵充国不是同一人。 [[11]](#note-11)

<a id="event-12"></a>
<a id="sj020-e076"></a>

12. **路博德失去符离侯爵。** 路博德曾以右北平太守从军击匈奴，后来又担任伏波将军参与平定南越。这一年，他因知悉儿子犯逆不道罪而获罪，失去侯爵，符离侯国被撤销。 [[12]](#note-12)

<a id="event-13"></a>
<a id="sj020-e107"></a>

13. **海常侯苏弘去世，封国终止。** 苏弘曾任伏波司马，因擒获南越王建德的军功获封海常侯。他在这一年去世，没有继承人，侯国随之终止。 [[13]](#note-13)

<a id="event-14"></a>
<a id="sj020-e121"></a>

14. **蓹儿侯辕终古去世，封国终止。** 辕终古原以军卒身份斩获东越徇北将军，凭军功受封蓹儿侯。这一年他去世，没有人接续侯爵，侯国被撤销。 [[14]](#note-14)

<a id="event-15"></a>
<a id="sj020-e130"></a>

15. **騠兹侯稽谷姑去世，封国终止。** 稽谷姑原是小月氏的王，率众归汉以后受封騠兹侯。这一年他去世，没有继承人，侯国终止。 [[15]](#note-15)

<a id="event-16"></a>
<a id="sj021"></a>
<a id="sj021-r026-e03"></a>

16. **宜成侯刘福因杀弟被处死。** 宜成侯刘福是菑川懿王后裔，承接刘偃一支的侯爵。他因杀害弟弟，被判处弃市，宜成侯国也被撤销。 [[16]](#note-16)

<a id="event-17"></a>
<a id="sj021-r038-e02"></a>

17. **阴城侯刘苍去世，继承人因罪不得接爵。** 阴城侯刘苍是赵敬肃王的儿子。他去世以后，原本可以接爵的嗣子有罪，未能继承侯位，阴城侯国因此中断。 [[17]](#note-17)

<a id="event-18"></a>
<a id="sj021-r089-e02"></a>

18. **攸舆侯刘则因劫夺死罪囚被处死。** 攸舆侯刘则出自长沙定王一支。他因劫夺死罪囚犯而被判处弃市，侯国被撤销。 [[18]](#note-18)

<a id="event-19"></a>
<a id="sj021-r090-e03"></a>

19. **荼陵侯去世，无人继承侯爵。** 出自长沙定王一支的荼陵侯去世，没有继承人，侯国终止。这个侯国从刘欣传到后一代，在本年结束了爵位传承。 [[19]](#note-19)

<a id="sj111-event-20"></a>

20. **卫伉入长平侯嗣爵年表。** 太初元年，长平侯一系开始记录卫伉的嗣侯年。父卫青早在元封五年去世，原侯国并非本年新封。 [[20]](#note-20)

<a id="sj122-event-21"></a>

21. **王溫舒在发兵征宛时获罪自杀。** 发兵征大宛时，王溫舒藏匿受征属吏華成，又被告发收员骑钱等，罪至族而自杀。两弟及两婚家各坐他罪。 [[21]](#note-21)

<a id="hs-event-22"></a>

22. **临蔡侯孙都｜获罪。** 表载临蔡侯孙都一支本年载相关罪案及处分。表中所载事项为因罪案击番禺夺人虏掠，死。 [[22]](#hs-note-22)

<a id="hs-event-23"></a>

23. **涅阳康侯最｜去世。** 表载涅阳康侯最一支本年记载去世。表中所载事项为去世，无继承人。 [[23]](#hs-note-23)

<a id="hs-event-24"></a>

24. **宜春侯卫伉｜承爵。** 表载宜春侯卫伉一支本年记载侯位承袭。表中所载事项为承爵获封，五年阑入宫，未处肉刑，服城旦劳役。 [[24]](#hs-note-24)

<a id="hs-event-25"></a>

25. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[25]](#hs-note-25)

### 4. 二月，开始兴建建章宫

[返回正文第4条](#event-4)

<a id="hs006-l489-e4"></a>

**[《汉书·武帝纪》P171](../../sources/摘录/汉书-卷006-武帝纪.md#p171)** · [仓内TXT L489](../../sources/本地分卷/汉书/汉书-卷006.md#L489)

<a id="sj028-p097"></a>

**[《史记·封禅书》P097](../../sources/摘录/史记-卷028-封禅书.md#p097)** · [三家注](../../sources/史记三家注/卷028.md#p97)

> 於是作建章宮，度爲千門萬戶。前殿度高未央。其東則鳳闕，高二十餘丈。其西則唐中，數十里虎圈。其北治大池，漸臺高二十餘丈，命曰太液池，中有蓬萊、方丈、瀛洲、壺梁，象海中神山龜魚之屬。其南有玉堂、壁門、大鳥之屬。乃立神明臺、井幹樓，度五十丈，輦道相屬焉。

**本卷归年说明：** 《汉书·武帝纪》太初元年二月起建章宫，建筑详述属本篇。


**[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-ad72d01a4cd96b)：**

> 二月，起建章宮。

《史记·孝武本纪》有关营建的原文：

> 勇之乃曰：「越俗有火災，復起屋必以大，用勝服之。」於是作建章宮，度為千門萬戶。前殿度高未央，其東則鳳闕，高二十餘丈。其西則唐中，數十里虎圈。其北治大池，漸臺高二十餘丈，名曰泰液池，中有蓬萊、方丈、瀛洲、壺梁，象海中神山龜魚之屬。其南有玉堂、璧門、大鳥之屬。乃立神明臺、井幹樓，度五十餘丈，輦道相屬焉。

**说明：** “起”是开始兴建；后书连叙的殿阁形制和工程规划，不全当作本年已经完工。

### 5. 夏五月，改历，以正月为岁首

# 公元前104年（汉武帝太初元年）

[← 公元前105年](bce-0105.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前103年 →](bce-0103.md)

[读本年史料](#本年相关史料) · [归年与异说详解](../../meta/考证/前0104年-史料与归年说明.md)

朝廷继续举行泰山礼仪，柏梁台火灾后又启动建章宫工程。夏五月，历法和官名等制度一同调整；秋天，李广利率军向大宛进发。中央的改制、远方的战争与诸侯王侯家的承续，都在这一年继续展开。

<a id="event-1"></a>
<a id="sj012-104-1"></a>

1. **冬十一月，武帝在泰山明堂祭祀上帝。** 冬十月，武帝前往泰山。十一月甲子朔旦，他在明堂祭祀上帝；朝廷把这次冬至与岁时更新联系起来，祭辞称颂天道周而复始。皇帝此前已经举行过泰山封禅，这次是在既有礼制上的继续举行。 [[1]](#note-1)

<a id="event-2"></a>

2. **十一月乙酉，柏梁台失火。** 长安的柏梁台发生火灾。这座高台兴建于元鼎年间，毁坏后，朝廷开始考虑另建规模更大的宫殿。火灾也给方士提供了进言的机会，他们以古帝王和越地风俗解释灾后应当如何营建。 [[2]](#note-2)

<a id="event-3"></a>

3. **十二月，祭高里、望祠蓬莱，春回甘泉受计。** 武帝亲往高里祭后土，又来到渤海岸边，望祀传说中的蓬莱神山。他仍希望求得神仙消息，派往海上的人却没有带来确实结果。春天返回后，因柏梁台已毁，他在甘泉接受郡国上报的政务账目；此后甘泉也营建诸侯朝见时居住的邸舍。 [[3]](#note-3)

<a id="event-4"></a>

4. **二月，开始兴建建章宫。** 武帝采纳了灾后另建大宫的意见，命人兴建建章宫。工程规划追求“千门万户”的规模，前殿拟高过未央宫，又在北面营建太液池，在池中仿造蓬莱、方丈、瀛洲等海中神山。神明台、井干楼及彼此相连的通道，也属于这座宫殿宏大的建筑构想。 [[4]](#note-4)

<a id="event-5"></a>
<a id="sj012-104-2"></a>
<a id="sj026"></a>

5. **夏五月，改历，以正月为岁首。** 朝廷正式修订历法，把沿用的十月岁首改为正月岁首，改称太初元年；同时崇尚黄色，制度取数用五，调整官名、印章和音律。大行令在这一年改称大鸿胪，负责朝廷接待和有关礼仪。公孙卿、壶遂、司马迁等参加改历议论，唐都分定天区和星宿距离，巴郡人落下闳承担历算；邓平等也参加比算、校候，朝廷最后采用邓平所造的八十一分历法。 [[5]](#note-5)

<a id="event-6"></a>

6. **朝廷派公孙敖在塞外修筑受降城。** 改历之际，北边的经营仍在继续。朝廷派因杅将军公孙敖率人到塞外修筑受降城，以此扩展边地据点。 [[6]](#note-6)

<a id="event-7"></a>

7. **秋八月，李广利率军西征大宛。** 武帝出巡安定，又派贰师将军李广利征发天下被谪罚的民众，向西攻打大宛。远征从这一年开始，此后的行军、受挫与再次出兵还将延续数年。与此同时，丁夫人、洛阳人虞初等方术人士为朝廷施行诅咒匈奴和大宛的祠术。 [[7]](#note-7)

<a id="event-8"></a>

8. **蝗群从东方飞到敦煌。** 这一年蝗灾大起，史书记载蝗群从东方一直飞至敦煌。汉军正向西远征，河西一带也受到这场灾害的影响。 [[8]](#note-8)

<a id="event-9"></a>
<a id="sj017-sishui"></a>

9. **泗水王刘商去世，刘安世接续王位。** 泗水王刘商去世。他是常山王刘舜的儿子，在常山王国被废、重新分封以后取得泗水封号。儿子刘安世接续王位，泗水王国继续存在；刘安世的元年从下一年起记。 [[9]](#note-9)

<a id="event-10"></a>
<a id="sj017-audience"></a>

10. **六安王刘庆来朝。** 六安王刘庆来到朝廷。他是胶东王刘寄的儿子，早已另受六安封国；这次是诸侯王入朝，并非重新受封。 [[10]](#note-10)

<a id="event-11"></a>
<a id="sj020"></a>
<a id="sj020-e025"></a>

11. **赵充国继承昌武侯爵。** 昌武侯一支由赵充国承接。其父赵安稽原是归汉的匈奴王，后来又从军立功、增加封邑；如今侯爵转到儿子手中，继续在赵家传承。这里的赵充国是赵安稽之子，与后来以平羌著称的营平侯赵充国不是同一人。 [[11]](#note-11)

<a id="event-12"></a>
<a id="sj020-e076"></a>

12. **路博德失去符离侯爵。** 路博德曾以右北平太守从军击匈奴，后来又担任伏波将军参与平定南越。这一年，他因知悉儿子犯逆不道罪而获罪，失去侯爵，符离侯国被撤销。 [[12]](#note-12)

<a id="event-13"></a>
<a id="sj020-e107"></a>

13. **海常侯苏弘去世，封国终止。** 苏弘曾任伏波司马，因擒获南越王建德的军功获封海常侯。他在这一年去世，没有继承人，侯国随之终止。 [[13]](#note-13)

<a id="event-14"></a>
<a id="sj020-e121"></a>

14. **蓹儿侯辕终古去世，封国终止。** 辕终古原以军卒身份斩获东越徇北将军，凭军功受封蓹儿侯。这一年他去世，没有人接续侯爵，侯国被撤销。 [[14]](#note-14)

<a id="event-15"></a>
<a id="sj020-e130"></a>

15. **騠兹侯稽谷姑去世，封国终止。** 稽谷姑原是小月氏的王，率众归汉以后受封騠兹侯。这一年他去世，没有继承人，侯国终止。 [[15]](#note-15)

<a id="event-16"></a>
<a id="sj021"></a>
<a id="sj021-r026-e03"></a>

16. **宜成侯刘福因杀弟被处死。** 宜成侯刘福是菑川懿王后裔，承接刘偃一支的侯爵。他因杀害弟弟，被判处弃市，宜成侯国也被撤销。 [[16]](#note-16)

<a id="event-17"></a>
<a id="sj021-r038-e02"></a>

17. **阴城侯刘苍去世，继承人因罪不得接爵。** 阴城侯刘苍是赵敬肃王的儿子。他去世以后，原本可以接爵的嗣子有罪，未能继承侯位，阴城侯国因此中断。 [[17]](#note-17)

<a id="event-18"></a>
<a id="sj021-r089-e02"></a>

18. **攸舆侯刘则因劫夺死罪囚被处死。** 攸舆侯刘则出自长沙定王一支。他因劫夺死罪囚犯而被判处弃市，侯国被撤销。 [[18]](#note-18)

<a id="event-19"></a>
<a id="sj021-r090-e03"></a>

19. **荼陵侯去世，无人继承侯爵。** 出自长沙定王一支的荼陵侯去世，没有继承人，侯国终止。这个侯国从刘欣传到后一代，在本年结束了爵位传承。 [[19]](#note-19)

## 本年相关史料

<a id="note-1"></a>

### 1. 冬十一月，武帝在泰山明堂祭祀上帝

[返回正文第1条](#event-1)

**[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)：**

> 太初元年冬十月，行幸泰山。十一月甲子朔旦，冬至，祀上帝于明堂。

《史记·孝武本纪》另记：

> 其後二歲，十一月甲子朔旦冬至，推歷者以本統。天子親至泰山，以十一月甲子朔旦冬至日祠上帝明堂，每修封禪。

> 其贊饗曰：「天增授皇帝泰元神筴，周而復始。皇帝敬拜泰一。」

**说明：** 保留两书所记的古历月日，不把它改写成已经用现代天文学独立验证的合朔、冬至时刻。首次封泰山见[前110年](bce-0110.md)。

<a id="note-2"></a>

### 2. 十一月乙酉，柏梁台失火

[返回正文第2条](#event-2)

**[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)：**

> 乙酉，柏梁臺災。

《史记·孝武本纪》另记：

> 十一月乙酉，柏梁災。

《汉书·武帝纪》元鼎二年条所记建台背景：

> 春，起柏梁臺。

**说明：** 本年十一月承接上一条冬至记事；台毁与下一条春回甘泉、二月起建章宫分别叙述。

<a id="note-3"></a>

### 3. 十二月，祭高里、望祠蓬莱，春回甘泉受计

[返回正文第3条](#event-3)

**[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)：**

> 十二月，禪高里，祠后土。東臨勃海，望祠蓬萊。春還，受計于甘泉。

《史记·孝武本纪》另记：

> 十二月甲午朔，上親禪高里，祠后土。臨渤海，將以望祠蓬萊之屬，冀至殊庭焉。

> 上還，以柏梁災故，朝受計甘泉。

> 其後天子又朝諸侯甘泉，甘泉作諸侯邸。

同篇叙求仙：

> 東至海上，考入海及方士求神者，莫驗，然益遣，冀遇之。

**说明：** 求仙无验而继续遣人的叙述见同篇前后文；“其后”营诸侯邸是相连的后续，不据此另定当月完工。

<a id="note-4"></a>

### 4. 二月，开始兴建建章宫

[返回正文第4条](#event-4)

**[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)：**

> 二月，起建章宮。

《史记·孝武本纪》有关营建的原文：

> 勇之乃曰：「越俗有火災，復起屋必以大，用勝服之。」於是作建章宮，度為千門萬戶。前殿度高未央，其東則鳳闕，高二十餘丈。其西則唐中，數十里虎圈。其北治大池，漸臺高二十餘丈，名曰泰液池，中有蓬萊、方丈、瀛洲、壺梁，象海中神山龜魚之屬。其南有玉堂、璧門、大鳥之屬。乃立神明臺、井幹樓，度五十餘丈，輦道相屬焉。

**说明：** “起”是开始兴建；后书连叙的殿阁形制和工程规划，不全当作本年已经完工。

### 5. 夏五月，改历，以正月为岁首

[返回正文第5条](#event-5)

**[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)：**

> 夏五月，正曆，以正月為歲首。色上黃，數用五，定官名，協音律。

《史记·孝武本纪》：

> 夏，漢改歷，以正月為歲首，而色上黃，官名更印章以五字。因為太初元年。

《史记·历书》：

> 至今上即位，招致方士唐都，分其天部；而巴落下閎運算轉曆，然後日辰之度與夏正同。

> 十一月甲子朔旦冬至已詹，其更以七年為太初元年。

《汉书·律历志上》：

> 至武帝元封七年，漢興百二歲矣，大中大夫公孫卿、壺遂、太史令司馬遷等言「曆紀壞廢，宜改正朔」。

> 乃選治曆鄧平及長樂司馬可、酒泉候宜君、侍郎尊及與民間治曆者，凡二十餘人，方士唐都、巴郡落下閎與焉。

> 乃詔遷用鄧平所造八十一分律曆，罷廢尤疏遠者十七家，復使校曆律昏明。

> 陵渠奏狀，遂用鄧平曆，以平爲太史丞。

《汉书·百官公卿表》：

> 典客，秦官，掌諸歸義蠻夷，有丞。景帝中六年更名大行令，武帝太初元年更名大鴻臚。

**说明：** “七年”据古注为元封七年。十一月冬至礼与夏五月颁历各依原年条安放；《历书》的历元和76行四分法表，另有模型、岁名及后补层次问题。详见[本年归年说明](../../meta/考证/前0104年-史料与归年说明.md#太初与历元)。

《天官书》列汉代天数家：“星則唐都，氣則王朔，占歲則魏鮮”（[P121](../../sources/摘录/史记-卷027-天官书.md#p121)）。这可补唐都的专业背景，不能证明王朔、魏鲜也参加本年的改历，更不据其并列给三人同时定生卒或任职年。

### 7. 秋八月，李广利率军西征大宛

[返回正文第7条](#event-7)

**[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)：**

> 秋八月，行幸安定。遣貳師將軍李廣利發天下謫民西征大宛。

《史记·孝武本纪》：

> 是歲，西伐大宛。蝗大起。丁夫人、雒陽虞初等以方祠詛匈奴、大宛焉。

**说明：** 本条记出兵及相关方术活动，后续战况不提前挤入本年；虞初之名的雒／洛为字样差别。

《天官书》[P120](../../sources/摘录/史记-卷027-天官书.md#p120)另作“兵征大宛，星茀招搖”；《汉书·天文志》只定为“太初中”（[互校H009](../../sources/摘录/史记-卷027-纪年互校.md#h009)）。相关星象没有单一年次，留在此注作为战争互见，不把它写成本年出兵日的观测，也不移到[前101年获马](bce-0101.md#sj024-note)并再记一次。

### 12. 路博德失去符离侯爵

[返回正文第12条](#event-12)

**[《史记·建元以来侯者年表》符离栏](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r034)：**

> 太初元年，侯路博德有罪，國除。

《汉书·景武昭宣元成功臣表》邳离栏：

> 四年六月丁卯封，十五年，太初元年，坐見知子犯逆不道罪免。

同表功状记：

> 以右北平太守從票騎將軍擊左王，得重，會期，虜首萬二千七百人，侯，千六百戶。

《汉书·武帝纪》元鼎五年伐南越条：

> 遣伏波將軍路博德出桂陽，下湟水；

**说明：** 采用两表同系太初元年的失侯记录；史表称符离、汉表称邳离。汉表补明案由，不能扩大成路博德本人举兵或被处死。

### 13. 海常侯苏弘去世，封国终止

[返回正文第13条](#event-13)

**[《史记·建元以来侯者年表》海常栏](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r056)：**

> 太初元年，侯弘死，無後，國除。

《汉书·景武昭宣元成功臣表》：

海常苏弘的功状栏：

> 以伏波司馬得南越王建德侯。

> 七月乙酉封，七年，太初元年薨，亡後。

**说明：** 始封七月不是本年死亡月份，死亡仍只确年。

### 14. 蓹儿侯辕终古去世，封国终止

[返回正文第14条](#event-14)

**[《史记·建元以来侯者年表》蓹儿栏](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r060)：**

> 太初元年，終古死，無後，國除。

《汉书·景武昭宣元成功臣表》：

蓹儿辕终古的功状栏：

> 以軍卒斬東越徇北將軍侯。

> 閏月癸卯封，六年，太初元年薨，亡後。

### 15. 騠兹侯稽谷姑去世，封国终止

[返回正文第15条](#event-15)

**[《史记·建元以来侯者年表》騠兹栏](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r069)：**

> 太初元年，侯稽谷姑薨，無後，國除。

《汉书·景武昭宣元成功臣表》：

騠兹稽谷姑的功状栏：

> 以小月氏右苴王將衆降，侯，千九百戶。

> 四年十一月丁未封，三年，太初元年薨，亡後。

**说明：** 此为归汉王侯，不从“小月氏”名号推画现代疆界。

### 16. 宜成侯刘福因杀弟被处死

[返回正文第16条](#event-16)

**[《史记·建元以来王子侯者年表》宜成栏](../../sources/摘录/史记-卷021-建元以来王子侯者年表.md#r026)：**

> 元年，侯福坐殺弟，棄市，國除。

《汉书·王子侯表》宜成栏：

宜成刘偃的属列：

> 菑川懿王子。

> 元鼎元年，侯福嗣，十二年，太初元年，坐殺弟棄市。

**说明：** 史汉两表均支持太初元年杀弟被诛；“弃市”是刑罚，不与普通死亡合并。

### 17. 阴城侯刘苍去世，继承人因罪不得接爵

[返回正文第17条](#event-17)

**[《汉书·王子侯表》阴城栏](https://zh.wikisource.org/wiki/漢書/卷015)：**

> 六月甲午封，十七年，太初元年薨。嗣子有罪，不得代。

《史记·建元以来王子侯者年表》异文：

> 元年，侯蒼有罪，國除。

**说明：** 史表置于元封元年栏，汉表记太初元年父死、嗣子有罪。本条从汉表区分父死与嗣子不得代，史表前110年及案情差别详见[侯籍异年](../../meta/考证/前0104年-史料与归年说明.md#侯籍异年)。

### 18. 攸舆侯刘则因劫夺死罪囚被处死

[返回正文第18条](#event-18)

**[《史记·建元以来王子侯者年表》攸舆栏](../../sources/摘录/史记-卷021-建元以来王子侯者年表.md#r089)：**

> 元年，侯則篡死罪，棄市，國除。

《汉书·王子侯表》：

攸舆刘则的属列：

**说明：** “篡死罪囚”指劫夺死罪囚，不能译为篡位。

### 19. 荼陵侯去世，无人继承侯爵

<a id="真定王刘平来到朝廷"></a>

<a id="event-1"></a>

1. **真定王刘平来到朝廷。** 刘平在本年入朝。 他是常山王刘舜的儿子，常山原国遭撤分后，另以真定王号继续受封。此次赴朝与早年的封王不是同一件事，也不是恢复整个旧常山国。 [[1]](#note-1)

<a id="sj019-r056-e04"></a>

<a id="event-2"></a>

2. **犁侯延因不出所应承担的马匹，被处斩，封国撤销。** [[2]](#note-2)

<a id="sj020"></a>
<a id="军政受封与侯国的接续"></a>

<a id="event-3"></a>

3. **当时承众利侯。** 当时开始记众利侯元年，接伊即轩这一支的爵位。 [[3]](#note-3)

<a id="sj020-e091"></a>
<a id="龙亢侯广德失国"></a>


<a id="event-4"></a>

4. **龙亢侯广德失国。** 广德受到处罚，龙亢侯国终止。 [[4]](#note-4)

<a id="sj020-e092"></a>
<a id="韩延年失去成安侯爵"></a>


<a id="event-5"></a>

5. **韩延年失去成安侯爵。** 成安侯韩延年任太常时获罪，失去侯爵。 [[5]](#note-5)

<a id="sj020-e133"></a>
<a id="胜承瓡讘侯"></a>


<a id="event-6"></a>

6. **胜承瓡讘侯。** 胜开始记瓡讘侯元年，接续前任归附所建立的爵位。 [[6]](#note-6)

<a id="sj020-e135"></a>
<a id="几侯出使朝鲜获罪"></a>


<a id="event-7"></a>

7. **几侯出使朝鲜获罪。** 几侯奉使朝鲜后，被以谋反处置，身死，侯国撤销。 [[7]](#note-7)

<a id="sj021"></a>
<a id="王子分邑与侯国的接续"></a>

<a id="sj021-r053-e02"></a>

<a id="event-8"></a>

8. **州鄉侯爵由后人接续。** 刘惠接续州鄉侯爵，侯统进入新的一代。 [[8]](#note-8)

<a id="sj021-r092-e02"></a>

<a id="event-9"></a>

9. **安眾侯爵由后人接续。** 刘山拊接续安眾侯爵，侯统进入新的一代。 [[9]](#note-9)

<a id="sj021-r104-e02"></a>

<a id="event-10"></a>

10. **臨樂侯爵由后人接续。** 刘建接续臨樂侯爵，侯统进入新的一代。 [[10]](#note-10)

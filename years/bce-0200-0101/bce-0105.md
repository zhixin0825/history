# 公元前105年｜真定王刘平入朝

**汉武帝元封六年**

<a id="sj017-audience"></a>
## 真定王刘平来到朝廷

**刘平在本年入朝。** 他是常山王刘舜的儿子，常山原国遭撤分后，另以真定王号继续受封。此次赴朝与早年的封王不是同一件事，也不是恢复整个旧常山国。[原文与说明](#sj017-note)

<a id="sj019"></a>
## 封侯、承袭与侯国的变化

<a id="sj019-r056-e04"></a>
犁侯延因不出所应承担的马匹，被处斩，封国撤销。 [原文与说明](#sj019-r056-e04-n)


<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e078"></a>
### 当时承众利侯

当时开始记众利侯元年，接伊即轩这一支的爵位。 [原文与说明](#sj020-e078-n)

<a id="sj020-e091"></a>
### 龙亢侯广德失国

广德受到处罚，龙亢侯国终止。 [原文与说明](#sj020-e091-n)

<a id="sj020-e092"></a>
### 韩延年失去成安侯爵

成安侯韩延年任太常时获罪，失去侯爵。 [原文与说明](#sj020-e092-n)

<a id="sj020-e133"></a>
### 胜承瓡讘侯

胜开始记瓡讘侯元年，接续前任归附所建立的爵位。 [原文与说明](#sj020-e133-n)

<a id="sj020-e135"></a>
### 几侯出使朝鲜获罪

几侯奉使朝鲜后，被以谋反处置，身死，侯国撤销。 [原文与说明](#sj020-e135-n)

<a id="sj021"></a>
## 王子分邑与侯国的接续

<a id="sj021-r053-e02"></a>
**州鄉侯爵由后人接续。** 刘惠接续州鄉侯爵，侯统进入新的一代。 [原文与说明](#sj021-r053-e02-n)

<a id="sj021-r092-e02"></a>
**安眾侯爵由后人接续。** 刘山拊接续安眾侯爵，侯统进入新的一代。 [原文与说明](#sj021-r092-e02-n)

<a id="sj021-r104-e02"></a>
**臨樂侯爵由后人接续。** 刘建接续臨樂侯爵，侯统进入新的一代。 [原文与说明](#sj021-r104-e02-n)

## 本年相关史料

### 卷020｜原格、互见与采用的年线

<a id="sj020-e091-n"></a>
**龙亢侯广德失国：** [R045 龍亢](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r045)。本表元封六年“有罪诛”；汉表另叙酎金、免爵及不同任期，关于死刑与年次均不一致。正文只取共同支持的受罚失国，暂置史表明确年，不能把处死当作无争议事实。 互校：[漢書/卷017](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7017)。

<a id="sj020-e092-n"></a>
**韩延年失去成安侯爵：** [R046 成安](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r046)。汉表细称滞留外国文书、乏兴，赎为城旦；史表只称有罪。补细节不写成被处死。 互校：[漢書/卷017](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7017)。

<a id="sj020-e133-n"></a>
**胜承瓡讘侯：** [R071 瓡讘](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r071)。史表元封六年；汉表相关格的“六月”与在位年数难以完全相合，暂据史表明年，不静默改原文。 互校：[漢書/卷017](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7017)。

<a id="sj020-e135-n"></a>
**几侯出使朝鲜获罪：** [R072 幾](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r072)。史表元封六年；汉表封后六年及“格死”不同，年次与死法均留异说。不凭“谋反”两个字复原一场未经记载的复国战争。 互校：[漢書/卷017](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7017)。

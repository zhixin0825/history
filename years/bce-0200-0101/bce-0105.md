[← 公元前106年](bce-0106.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前104年 →](bce-0104.md)

**汉武帝元封六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj017-audience"></a>
<a id="真定王刘平来到朝廷"></a>

<a id="event-1"></a>

1. **真定王刘平来到朝廷。** 刘平在本年入朝。 他是常山王刘舜的儿子，常山原国遭撤分后，另以真定王号继续受封。此次赴朝与早年的封王不是同一件事，也不是恢复整个旧常山国。 [[1]](#note-1)

<a id="sj019-r056-e04"></a>

<a id="event-2"></a>

2. **犁侯延因不出所应承担的马匹，被处斩，封国撤销。** [[2]](#note-2)

<a id="sj020"></a>
<a id="军政受封与侯国的接续"></a>

<a id="sj020-e078"></a>
<a id="当时承众利侯"></a>


<a id="event-3"></a>

3. **当时承众利侯。** 当时开始记众利侯元年，接伊即轩这一支的爵位。 [[3]](#note-3)

<a id="sj020-e091"></a>
<a id="龙亢侯广德失国"></a>


<a id="event-4"></a>

4. **龙亢侯广德失国。** 广德受到处罚，龙亢侯国终止。 [[4]](#note-4)

<a id="sj020-e092"></a>
<a id="韩延年失去成安侯爵"></a>


<a id="event-5"></a>

5. **韩延年失去成安侯爵。** 成安侯韩延年任太常时获罪，失去侯爵。 [[5]](#note-5)

<a id="sj020-e133"></a>
<a id="胜承瓡讘侯"></a>


<a id="event-6"></a>

6. **胜承瓡讘侯。** 胜开始记瓡讘侯元年，接续前任归附所建立的爵位。 [[6]](#note-6)

<a id="sj020-e135"></a>
<a id="几侯出使朝鲜获罪"></a>


<a id="event-7"></a>

7. **几侯出使朝鲜获罪。** 几侯奉使朝鲜后，被以谋反处置，身死，侯国撤销。 [[7]](#note-7)

<a id="sj021"></a>
<a id="王子分邑与侯国的接续"></a>

<a id="sj021-r053-e02"></a>

<a id="event-8"></a>

8. **州鄉侯爵由后人接续。** 刘惠接续州鄉侯爵，侯统进入新的一代。 [[8]](#note-8)

<a id="sj021-r092-e02"></a>

<a id="event-9"></a>

9. **安眾侯爵由后人接续。** 刘山拊接续安眾侯爵，侯统进入新的一代。 [[9]](#note-9)

<a id="sj021-r104-e02"></a>

<a id="event-10"></a>

10. **臨樂侯爵由后人接续。** 刘建接续臨樂侯爵，侯统进入新的一代。 [[10]](#note-10)

<a id="sj110-event-11"></a>

11. **乌维去世，儿单于继立。** 乌维死后，其子乌师庐继位，因年轻被称为儿单于。 [[11]](#note-11)

<a id="sj111-event-12"></a>

12. **郭昌出兵击昆明，未成而被夺印。** 昆明反抗汉廷，拔胡将军郭昌出兵讨伐，未获功，被夺去将印。后来汉再遣使，仍遭阻截，未能从西南通往大夏。 [[12]](#note-12)

<a id="sj123-event-13"></a>

13. **江都翁主刘细君出嫁乌孙。** 乌孙以千匹马聘汉女。汉遣江都王刘建女刘细君赴乌孙，乌孙王昆莫以她为右夫人。 [[13]](#note-13)

<a id="hs-event-14"></a>

14. **幸回中与建首山宫。** 元封六年冬武帝去回中，春兴建首山宫。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **河东祀后土及赦赐。** 三月武帝到河东祭后土，诏称首山出珍物、后土祭有神光，赦汾阴死罪以下，并赐天下贫民每人布帛一匹。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **平乐馆角抵。** 夏季京师百姓到上林平乐馆看角抵。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **秋旱与蝗。** 秋季大旱并发生蝗灾。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **黎顷侯召奴｜获罪。** 表载黎顷侯召奴一支本年载相关罪案及处分。表中所载事项为因罪案不出持马，被腰斩。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **衆利侯伊即轩｜承爵。** 表载衆利侯伊即轩一支本年记载侯位承袭。表中所载事项为侯当时承爵。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **成安侯韩延年｜获罪。** 表载成安侯韩延年一支本年载相关罪案及处分。表中所载事项为因罪案为太常行大行令事留外国书一月，乏兴，入谷赎，未处肉刑，服城旦劳役。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **元封六年秋蝗。** [[22]](#hs-note-22)

### 11. 乌维去世，儿单于继立

[返回正文第11条](#sj110-event-11)

<a id="hs094-l9808-e11"></a>

**[《汉书·匈奴传》P050](../../sources/摘录/汉书-卷094-匈奴传.md#p050)** · [仓内TXT L9808](../../sources/本地分卷/汉书/汉书-卷094.md#L9808)

> 烏維單于立十歲死，子詹師廬立，年少，號為兒單于。是歲，元封六年也。自是後，單于益西北。左方兵直雲中，右方兵直酒泉、敦煌。

**互校说明** 元封六年；儿单于名本传“詹師廬”，与其后的呴犁湖分人。

<a id="hs094-l9809-e11"></a>

**[《汉书·匈奴传》P051](../../sources/摘录/汉书-卷094-匈奴传.md#p051)** · [仓内TXT L9809](../../sources/本地分卷/汉书/汉书-卷094.md#L9809)

> 兒單于立，漢使兩使，一人弔單于，一人弔右賢王，欲以乖其國。使者入匈奴，匈奴悉將致單于。單于怒而悉留漢使。漢使留匈奴者前後十餘輩，而匈奴使來漢，亦輒留之相當。

**互校说明** 接儿单于新立，两使遭扣从《通鉴》及既有系年；历次留使数为汇叙。

<a id="sj110-p049"></a>

**[《资治通鉴》卷二十一乌师庐即位](../../sources/本地分卷/资治通鉴/资治通鉴-卷021.md#L299)**

# 公元前106年｜南巡天柱山，再赴泰山行明堂礼

[← 公元前107年](bce-0107.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前105年 →](bce-0105.md)

**汉武帝元封五年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，并补诸侯朝见和王统衔接；不表示武帝当年的战争、税政和全国史事都已收齐。跨年回叙不当成同年新事。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj012-106-1"></a>
<a id="沿江淮巡礼给天柱山南岳名号"></a>

<a id="event-1"></a>

1. **冬季皇帝由南郡、江陵转往江淮地区，登潜山天柱山行礼，称为南岳；随后沿江而下，经寻阳、枞阳、彭蠡，北到琅邪及海上。** 所经名山大川都受祭祀，巡行路线同时反映汉廷加强对各地的仪式性联系。 [[1]](#note-1)

<a id="event-2"></a>

2. **这不意味着五岳永远没有变动，也不是说皇帝亲自测定了每座山的现代地理位置。** 当时名号与后代五岳固定配置有变迁。 [[2]](#note-2)

   以本纪元封五年南巡与《汉书》互校。

<a id="sj012-106-2"></a>
<a id="明堂新礼制完成第一次使用"></a>

<a id="event-3"></a>

3. **明堂新礼制完成第一次使用。** 皇帝来到泰山下的奉高，在[前109年兴建的明堂](bce-0109.md#hs006-l467-e14)行祭礼。济南人公玉带所献的「黄帝明堂图」中是一座四面通敞、茅覆的殿，周围有水与廊道，皇帝由名叫昆仑的入口入内。祀泰一和五帝时，把高祖神位并列相配，另为后土设祭位；随后再次登泰山举行秘密祭祀。 [[3]](#note-3)

<a id="event-4"></a>

4. **明堂是政礼结合的建筑，不是经验证确实建自黄帝时代的建筑复制品。** 此前拟建长安明堂未成，与如今奉高明堂不是同一座；建造与本年使用分开记述。 [[4]](#note-4)

   《汉书》元封五年记高祖配祭与朝诸侯，宫室设计以传本所述当时图样为材料。

<a id="sj017-audience"></a>
<a id="鲁王济北王到泰山朝见"></a>

<a id="event-5"></a>

5. **鲁王刘光、济北王刘胡在泰山朝见皇帝。** 这次原表明确写出地点，和只记“来朝”的年份不同。朝见可与本年的东巡相接，但不能由此推定两王跟随进入了所有秘密祭祀环节。[原格与说明](#sj017-note) [[5]](#note-5)

<a id="sj017-jiaodong"></a>
<a id="胶东进入刘通平的纪年"></a>

<a id="event-6"></a>

6. **胶东进入刘通平的纪年。** 刘通平接续刘贤，开始新的王年。 他是胶东康王刘寄的孙子；六安王刘庆则是刘寄的另一个儿子，属于他的叔辈。两个封国即使都由刘寄后人统治，也不能把同一代与下一代混在一起。 [[6]](#note-6)

<a id="sj020"></a>
<a id="军政受封与侯国的接续"></a>

<a id="sj020-e013"></a>
<a id="卫青去世长平侯传给卫伉"></a>


<a id="event-7"></a>

7. **卫青去世，长平侯传给卫伉。** 大将军卫青去世，长平侯爵由儿子卫伉承接。卫伉此前失去的是自己的宜春侯爵，此后承接父亲的长平，是另一条爵位线。 [[7]](#note-7)

<a id="sj020-e072"></a>
<a id="漯阴侯苏无后除国"></a>


<a id="event-8"></a>

8. **漯阴侯苏无后除国。** 苏去世，没有承爵者，漯阴国撤销。 [[8]](#note-8)

<a id="sj021"></a>
<a id="王子分邑与侯国的接续"></a>

<a id="sj021-r087-e02"></a>

<a id="event-9"></a>

9. **易侯爵由后人接续。** 刘種接续易侯爵，侯统进入新的一代。 [[9]](#note-9)

<a id="sj021-r114-e03"></a>

<a id="event-10"></a>

10. **柳侯爵由后人接续。** 刘自為接续柳侯爵，侯统进入新的一代。 [[10]](#note-10)

<a id="hs-event-11"></a>

11. **设十三州刺史并求茂材异等。** 初划十三州刺史部。诏以难驾之马也能驰千里、负俗之士亦能建功为例，要求州郡察访足任将相、远国使节的非常人才。 [[11]](#hs-note-11)

### 卷017｜地点明确的朝见与胶东异名

[卷017前106年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0106)鲁二十三、济北四十六“朝泰山”，胶东“戴王通平元年”；[汉书诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7014.md#ref-9c10e399354e30)亦作通平。前王刘贤在元狩三年起十四年，继承在本年，不据一句元年补造确日葬礼。

[《五宗世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7059.md#ref-1b02c8584103a3)在刘贤后写“子庆为王”，与年表通平不合。本页从两表采用通平，同时保留世家异名，绝不因此把仍在六安的叔辈刘庆写成又接胶东、或猜出一次没有史料的改名。戴王为后谥，不是本年新授的完整当时称号。

<a id="sj020-e013-n"></a>
**卫青去世，长平侯传给卫伉：** [R005 長平](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r005)。死亡依武帝纪元封五年；本表、汉恩泽表却把卫伉嗣元年记太初元年前104年。父卒与嗣元年有两年差，本年只叙明确父卒与家爵后由卫伉接续，不据该差补造制度上必须等两年才继承的过程，也不推迟卫青死年。 互校：[漢書/卷006](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-f5cd1f393be1d5) · [史記/卷111](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7111.md#ref-8327e62f4eaa05) · [漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-0edb796b284cfb)。

<a id="sj020-e072-n"></a>
**漯阴侯苏无后除国：** [R030 漯陰](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r030)。按所引原格的明确年次接入；原书没有提供的月份、动机及细节不增补。

<a id="sj021-r087-e02-n"></a>
**易侯爵由后人接续：** [R087 易](../../sources/摘录/史记-卷021-建元以来王子侯者年表.md#r087)。史王子号空白，汉明赵敬肃王子，正文据互见辨宗支，原空不填；四月庚辰／甲辰异。 本项原格为元封5年条。 两表整行原字见[史汉互校](../../meta/记录/史记-卷021-史汉逐行互校.md#r087)。

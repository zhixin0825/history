# 公元前106年｜南巡天柱山，再赴泰山行明堂礼

[← 公元前107年](bce-0107.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前105年 →](bce-0105.md)

**汉武帝元封五年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，并补诸侯朝见和王统衔接；不表示武帝当年的战争、税政和全国史事都已收齐。跨年回叙不当成同年新事。

<a id="sj012-106-1"></a>
<a id="沿江淮巡礼给天柱山南岳名号"></a>
### 沿江淮巡礼，给天柱山南岳名号

<a id="event-1"></a>

1. **冬季皇帝由南郡、江陵转往江淮地区，登潜山天柱山行礼，称为南岳；随后沿江而下，经寻阳、枞阳、彭蠡，北到琅邪及海上。** 所经名山大川都受祭祀，巡行路线同时反映汉廷加强对各地的仪式性联系。 [[1]](#note-1)

<a id="event-2"></a>

2. **这不意味着五岳永远没有变动，也不是说皇帝亲自测定了每座山的现代地理位置。** 当时名号与后代五岳固定配置有变迁。 [[2]](#note-2)

   **本段史料：** [卷012 P024](../../sources/摘录/史记-卷012-孝武本纪.md#p024)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-f63b52ae515a70)。以本纪元封五年南巡与《汉书》互校。

<a id="sj012-106-2"></a>
<a id="明堂新礼制完成第一次使用"></a>
### 明堂新礼制完成第一次使用

<a id="event-3"></a>

3. **皇帝来到泰山下的奉高，依济南人公玉带所献的「黄帝明堂图」修建明堂。** 图中是一座四面通敞、茅覆的殿，周围有水与廊道，皇帝由名叫昆仑的入口入内。祀泰一和五帝时，把高祖神位并列相配，另为后土设祭位；随后再次登泰山举行秘密祭祀。 [[3]](#note-3)

<a id="event-4"></a>

4. **明堂是政礼结合的建筑，不是经验证确实建自黄帝时代的建筑复制品。** 此前拟建长安明堂未成，与如今奉高明堂不是同一座；建造与本年使用分开记述。 [[4]](#note-4)

   **本段史料：** [卷012 P024](../../sources/摘录/史记-卷012-孝武本纪.md#p024)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-cbe1ca549725cc)。《汉书》元封五年记高祖配祭与朝诸侯，宫室设计以传本所述当时图样为材料。

<a id="sj017-audience"></a>
<a id="鲁王济北王到泰山朝见"></a>
### 鲁王、济北王到泰山朝见

<a id="event-5"></a>

5. **鲁王刘光、济北王刘胡在泰山朝见皇帝。** 这次原表明确写出地点，和只记“来朝”的年份不同。朝见可与本年的东巡相接，但不能由此推定两王跟随进入了所有秘密祭祀环节。[原格与说明](#sj017-note) [[5]](#note-5)

<a id="sj017-jiaodong"></a>
<a id="胶东进入刘通平的纪年"></a>
### 胶东进入刘通平的纪年

<a id="event-6"></a>

6. **刘通平接续刘贤，开始新的王年。** 他是胶东康王刘寄的孙子；六安王刘庆则是刘寄的另一个儿子，属于他的叔辈。两个封国即使都由刘寄后人统治，也不能把同一代与下一代混在一起。 [[6]](#note-6)

<a id="军政受封与侯国的接续"></a>
### 军政、受封与侯国的接续
<a id="sj020-e013"></a>
<a id="卫青去世长平侯传给卫伉"></a>
### 卫青去世，长平侯传给卫伉

<a id="event-7"></a>

7. **卫青去世，长平侯传给卫伉。** 大将军卫青去世，长平侯爵由儿子卫伉承接。卫伉此前失去的是自己的宜春侯爵，此后承接父亲的长平，是另一条爵位线。 [[7]](#note-7)

### 卷017｜地点明确的朝见与胶东异名

[卷017前106年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0106)鲁二十三、济北四十六“朝泰山”，胶东“戴王通平元年”；[汉书诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7014.md#ref-9c10e399354e30)亦作通平。前王刘贤在元狩三年起十四年，继承在本年，不据一句元年补造确日葬礼。

[《五宗世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7059.md#ref-1b02c8584103a3)在刘贤后写“子庆为王”，与年表通平不合。本页从两表采用通平，同时保留世家异名，绝不因此把仍在六安的叔辈刘庆写成又接胶东、或猜出一次没有史料的改名。戴王为后谥，不是本年新授的完整当时称号。

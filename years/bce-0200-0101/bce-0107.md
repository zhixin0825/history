# 公元前107年｜回中道修通，皇帝由边道巡行

[← 公元前108年](bce-0108.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前106年 →](bce-0106.md)

**汉武帝元封四年**

本页记录《孝武本纪》涉及的宗庙、郊祭、方士与制度变化；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，卷十二的跨年回叙不当成同年新事。

<a id="sj012-107-1"></a>
<a id="边道巡行"></a>

<a id="event-1"></a>

1. **武帝再往雍地祭祀，并巡察回中道、萧关和鸣泽一带。** 这一段行程连接关中与北方边地，既是出巡，也为祭祀、行政和军政展示提供通道。 [[1]](#note-1)

   《孝武本纪》只简记「通回中道，巡之」及返程，不能凭一句话推断回中道所有路段都是本年首次开凿或已经按现代工程标准完工。

   《汉书》元封四年记冬十月经回中道的路线。

<a id="sj018-wudi"></a>
<a id="功臣后裔的承爵与失国"></a>


<a id="event-2"></a>

2. **酂侯萧寿成任太常期间，因祭祀牲畜不合规定被撤去侯爵。** 祭祀职事的失误也可能使功臣后人失国。 [[2]](#note-2)

   阳平侯杜相夫在太常等职事中，因擅自役使乐舞人员、违规出关等问题获罪，失去侯爵。

<a id="sj020"></a>
<a id="军政受封与侯国的接续"></a>

<a id="sj020-e021"></a>
<a id="平津侯因郡守任内失职获罪"></a>


<a id="event-3"></a>

3. **平津侯因郡守任内失职获罪。** 平津侯担任山阳太守时，没有遣送朝廷诏令征召的吏员，获罪失侯。 [[3]](#note-3)

<a id="sj020-e083"></a>
<a id="周子南君由买接续"></a>


<a id="event-4"></a>

4. **周子南君由买接续。** 周后封爵开始由买接续。这是奉祀前代的世系安排，与北征军功授爵并非同一种理由。 [[4]](#note-4)

<a id="sj020-e128"></a>
<a id="平州一支无后而终"></a>


<a id="event-5"></a>

5. **平州一支无后而终。** 平州侯唊去世，没有继承人，封国终止。 [[5]](#note-5)

<a id="sj020-e129"></a>
<a id="稽谷姑封騠兹侯"></a>


<a id="event-6"></a>

6. **稽谷姑封騠兹侯。** 小月氏的稽谷姑率众归汉，受封騠兹侯。 [[6]](#note-6)

<a id="sj020-e131"></a>
<a id="王恢封浩侯随后因矫制失爵"></a>


<a id="event-7"></a>

7. **王恢封浩侯，随后因矫制失爵。** 中郎将王恢因捕车师王的军功受封浩侯，不久又因在酒泉擅用皇帝命令且造成危害，被判当死，赎罪后失爵。 [[7]](#note-7)

<a id="sj020-e132"></a>
<a id="扜者封瓡讘侯"></a>


<a id="event-8"></a>

8. **扜者封瓡讘侯。** 小月氏王扜者带一千骑归附，受封瓡讘侯。 [[8]](#note-8)

<a id="sj020-e134"></a>
<a id="朝鲜王子受封几侯"></a>


<a id="event-9"></a>

9. **朝鲜王子受封几侯。** 朝鲜王子在汉军围城时归降，侯籍列为本年受封几侯。降汉过程在前108年战争中，授爵另记。 [[9]](#note-9)

<a id="sj020-e136"></a>
<a id="最因路人之功封涅阳侯"></a>


<a id="event-10"></a>

10. **最因路人之功封涅阳侯。** 相路人归降后死于途中，其子最受封涅阳侯。受封者和途中去世者是父子，不是一个人死后又归降。 [[10]](#note-10)

<a id="sj021"></a>
<a id="王子分邑与侯国的接续"></a>

<a id="sj021-r023-e03"></a>

<a id="event-11"></a>

11. **劇魁侯爵由后人接续。** 刘德接续劇魁侯爵，侯统进入新的一代。 [[11]](#note-11)

<a id="sj021-r047-e02"></a>

<a id="event-12"></a>

12. **畢梁侯一支因案失国。** 畢梁侯一支因案失去侯爵，侯国被撤销。 [[12]](#note-12)



<a id="sj059-jiaodong-xian-event"></a>

13. **胶东哀王刘贤去世，刘通平承接王国。** 刘贤自前120年开始记元年，在位十四年而卒。其子刘通平继承，下一年前106年开始记新王元年。 [[13]](#sj059-jiaodong-xian-note)

<a id="sj103-event-14"></a>

14. **关东流民众多，议迁实边，石庆请退后复职。** 《史记》《汉书》均把流民问题系于元封四年。公卿请将流民徙边，武帝查问议事者，石庆自责请归印，受责后继续视事。 [[14]](#note-14)

<a id="sj110-event-15"></a>

15. **王乌、杨信先后赴匈奴交涉。** 汉使王乌依匈奴礼入单于帐；随后杨信拒绝放下符节，在帐外与单于议以太子入汉为质，单于未允。 [[15]](#note-15)

<a id="sj110-event-16"></a>

16. **匈奴使者死于长安，汉使路充国被扣。** 王乌报告单于称愿入汉，汉为他营建馆舍。匈奴使者在长安病死，路充国送丧，单于怀疑汉害使者，将路充国扣留。 [[16]](#note-16)

<a id="sj110-event-17"></a>

17. **郭昌、赵破奴屯朔方以东。** 匈奴侵边后，朝廷任郭昌为拔胡将军，与浞野侯赵破奴屯朔方以东，加强防备。 [[17]](#note-17)

<a id="hs-event-18"></a>

18. **夏季大旱，民多中暑身亡。** 夏季大旱，许多百姓中暑而死。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **繁安夷侯忠一支爵位承袭。** 元封四年，安侯守继承侯爵。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **从票侯赵破奴｜改封。** 表载从票侯赵破奴一支本年爵号或封邑改易。表中所载事项为因匈河将军击楼兰，封浞野侯。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **将梁侯杨仆｜获罪。** 表载将梁侯杨仆一支本年载相关罪案及处分。表中所载事项为因罪案为将军击朝鲜畏懦，入竹两万个，赎未处肉刑，服城旦劳役。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **騠兹侯稽谷姑｜受封。** 《汉书》侯籍列騠兹侯稽谷姑本年受封，所引月份、干支依表保留。 [[22]](#hs-note-22)

<a id="hs-event-23"></a>

23. **浩侯王恢｜受封。** 《汉书》侯籍列浩侯王恢本年受封，所引月份、干支依表保留。 [[23]](#hs-note-23)

<a id="hs-event-24"></a>

24. **瓡讘侯杆者｜受封。** 《汉书》侯籍列瓡讘侯杆者本年受封，所引月份、干支依表保留。 [[24]](#hs-note-24)

<a id="hs-event-25"></a>

25. **平津献侯公孙弘｜获罪。** 表载平津献侯公孙弘一支本年载相关罪案及处分。表中所载事项为因罪案为山阳太守诏令徵钜野令史成不遣，未处肉刑，服城旦劳役。 [[25]](#hs-note-25)

<a id="hs-event-26"></a>

26. **周子南君姬嘉｜承爵。** 表载周子南君姬嘉一支本年记载侯位承袭。表中所载事项为君置承爵。 [[26]](#hs-note-26)

<a id="hs-event-27"></a>

27. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[27]](#hs-note-27)

**周子南君由买接续：** [R041 周子南君](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r041)。汉表名置；保存异名，不补未载的改名日。 互校：[漢書/卷018](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-a80de90659f7da)。

<a id="sj020-e128-n"></a>
**平州一支无后而终：** [R066 平州](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r066)。史表明记元封三年封、四年薨，原一可按不计死亡年合；[《汉书·景武昭宣元成功臣表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-bbb33bca559f42)封四年薨的四却可能是任期数，不能说也明系元封四年死亡。正文暂依史表前107年，另存任期异读，不再造第二次死亡。 互校：[漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-38eaa063ca2c1b)。

<a id="sj020-e129-n"></a>
**稽谷姑封騠兹侯：** [R069 騠茲](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r069)。原号若苴王／右苴王、授爵丁卯／丁未有差。小月氏不能与张骞远使的大月氏直接等同。 互校：[漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-334ced0d45a29d)。

<a id="sj020-e131-n"></a>
**王恢封浩侯，随后因矫制失爵：** [R070 浩](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r070)。战功接前108年车师战线；本表本年正月受封、四月除国，明说封凡三月，[《汉书·景武昭宣元成功臣表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-6767b4080621d0)却说一月。格首一只是涉及一个古史年条，不能译为执爵一年。两表都有当死而赎的层次，不写已被处死。 互校：[漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-f41ed59d8cdcb0) · [漢書/卷096上](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7096%E4%B8%8A.md#ref-0d6d895ae5e1c8)。

<a id="sj020-e132-n"></a>
**扜者封瓡讘侯：** [R071 瓡讘](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r071)。原文人数是文本记数；国名字形、姓名异写保留，不以冷僻字猜现代族名。 互校：[漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-73c1dc05584045)。

<a id="sj020-e136-n"></a>
**最因路人之功封涅阳侯：** [R073 涅陽](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r073)。本表元封四年，汉表接朝鲜降侯元封三年；本文暂循史表侯籍年，不使父亲途中之死也后移。与高祖时吕胜的涅阳一支无从按同爵号合为一家。 互校：[漢書/卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-08f3289a1407ef) · [史記/卷115](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7115.md#ref-393801126c7f85)。

**劇魁侯爵由后人接续：** [R023 劇魁](../../sources/摘录/史记-卷021-建元以来王子侯者年表.md#r023)。墨／黑、昭／招异。史元封元年昭嗣、四年德嗣，前127至110年差17；汉却把招嗣置元狩元年、同时记父十七年。采用史表可连贯的前110、107年，保留汉字。 本项原格为元封4年条。 两表整行原字见[史汉互校](../../meta/记录/史记-卷021-史汉逐行互校.md#r023)。

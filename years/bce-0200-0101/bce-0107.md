# 公元前107年｜回中道修通，皇帝由边道巡行

[← 公元前108年](bce-0108.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前106年 →](bce-0106.md)

**汉武帝元封四年**

本页记录《孝武本纪》涉及的宗庙、郊祭、方士与制度变化；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，卷十二的跨年回叙不当成同年新事。

<a id="sj012-107-1"></a>
## 边道巡行

**武帝再往雍地祭祀，并巡察回中道、萧关和鸣泽一带。** 这一段行程连接关中与北方边地，既是出巡，也为祭祀、行政和军政展示提供通道。

《孝武本纪》只简记「通回中道，巡之」及返程，不能凭一句话推断回中道所有路段都是本年首次开凿或已经按现代工程标准完工。

**本段史料：** [卷012 P023](../../sources/摘录/史记-卷012-孝武本纪.md#p023)；[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)。《汉书》元封四年记冬十月经回中道的路线。

<a id="sj018-wudi"></a>
## 功臣后裔的承爵与失国

酂侯萧寿成任太常期间，因祭祀牲畜不合规定被撤去侯爵。祭祀职事的失误也可能使功臣后人失国。 [R015](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r015)

阳平侯杜相夫在太常等职事中，因擅自役使乐舞人员、违规出关等问题获罪，失去侯爵。 [R111](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r111)

<a id="sj018-note"></a>
### 卷018｜原格、异年与本页采用

**逐格定位：** <a id="sj018-r015-wu"></a>[R015](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r015) · <a id="sj018-r111-wu"></a>[R111](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r111)。

本页按原格中明确年号、承袭次序及互见材料分别定位；未载月份的不补日期，元年也不一律倒推父亲死年。侯爵与所任中央官职不是同一继承关系。

**R015：** 萧胜失爵史表明系元朔二年，汉表以景中二年嗣、在位二十一年及“不斋祠宗庙”叙述，计数与史表明年不尽合；本轮采用史表前127年，不再按任期另造前一年免爵。萧庆元狩三年绍封，亦见《汉书·武帝纪》；萧寿成元狩六年承、元封四年失爵沿史表。汉表的任期数字不能在未校历前强换成另一独立死日。

**R111：** 史表末句涉及“与乐令无可当郑舞人擅繇不如令，阑出函谷关”，文字断读有疑，正文只取违法役使祭乐人员与出关两项可辨要旨，不将“无可当”猜成人名。史表元封四年、汉表元封三年且详记“以令隶为之”与出关相接，本轮暂系前107年，前108年留为异说，不发生两次相同免爵。行首长修、后封阳平不可混称。

互校：[《汉书》高惠高后文功臣表](https://zh.wikisource.org/wiki/漢書/卷016) · [《史记》三家注卷018](https://zh.wikisource.org/wiki/史記三家註/卷018)。

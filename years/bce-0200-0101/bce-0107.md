# 公元前107年｜回中道修通，皇帝由边道巡行

[← 公元前108年](bce-0108.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前106年 →](bce-0106.md)

**汉武帝元封四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj012-107-1"></a>
<a id="边道巡行"></a>

<a id="event-1"></a>

1. **武帝再往雍地祭祀，并巡察回中道、萧关和鸣泽一带。** 这一段行程连接关中与北方边地，既是出巡，也为祭祀、行政和军政展示提供通道。 [[1]](#note-1)

   《孝武本纪》只简记「通回中道，巡之」及返程，不能凭一句话推断回中道所有路段都是本年首次开凿或已经按现代工程标准完工。

   《汉书》元封四年记冬十月经回中道的路线。

<a id="sj018-wudi"></a>
<a id="功臣后裔的承爵与失国"></a>


<a id="event-2"></a>

2. **酂侯萧寿成任太常期间，因祭祀牲畜不合规定被撤去侯爵。** 祭祀职事的失误也可能使功臣后人失国。 [[2]](#note-2)

   阳平侯杜相夫在太常等职事中，因擅自役使乐舞人员、违规出关等问题获罪，失去侯爵。

<a id="sj020"></a>
<a id="军政受封与侯国的接续"></a>

<a id="sj020-e021"></a>
<a id="平津侯因郡守任内失职获罪"></a>


<a id="event-3"></a>

<a id="hs-event-25"></a>

3. **平津侯后人公孙度因任郡守获罪。** 平津侯因郡守任内失职获罪。平津侯担任山阳太守时，没有遣送朝廷诏令征召的吏员，获罪失侯。平津献侯公孙弘一支，为山阳太守诏令徵钜野令史成不遣，未处肉刑，服城旦劳役。 [[3]](#note-3)

<a id="sj020-e083"></a>
<a id="周子南君由买接续"></a>


<a id="event-4"></a>

<a id="hs-event-26"></a>

4. **周子南君由买接续。** 周后封爵开始由买接续。这是奉祀前代的世系安排，与北征军功授爵并非同一种理由。周子南君姬嘉一支，君置承爵。 [[4]](#note-4)

<a id="sj020-e128"></a>
<a id="平州一支无后而终"></a>


<a id="event-5"></a>

5. **平州一支无后而终。** 平州侯唊去世，没有继承人，封国终止。 [[5]](#note-5)

<a id="sj020-e129"></a>
<a id="稽谷姑封騠兹侯"></a>


<a id="event-6"></a>

<a id="hs-event-22"></a>

6. **稽谷姑归汉受封騠兹侯。** 小月氏的稽谷姑率众归汉，受封騠兹侯。《汉书》侯籍列騠兹侯稽谷姑本年受封，所引月份、干支依表保留。 [[6]](#note-6)

<a id="sj020-e131"></a>
<a id="王恢封浩侯随后因矫制失爵"></a>


<a id="event-7"></a>

<a id="hs-event-23"></a>

7. **王恢封浩侯，因矫制失爵。** 王恢封浩侯，随后因矫制失爵。中郎将王恢因捕车师王的军功受封浩侯，不久又因在酒泉擅用皇帝命令且造成危害，被判当死，赎罪后失爵。《汉书》侯籍列浩侯王恢本年受封，所引月份、干支依表保留。 [[7]](#note-7)

<a id="sj020-e132"></a>
<a id="扜者封瓡讘侯"></a>


<a id="event-8"></a>

<a id="hs-event-24"></a>

8. **扜者归汉受封瓡讘侯。** 小月氏王扜者带一千骑归附，受封瓡讘侯。《汉书》侯籍列瓡讘侯杆者本年受封，所引月份、干支依表保留。 [[8]](#note-8)

<a id="sj020-e134"></a>
<a id="朝鲜王子受封几侯"></a>


<a id="event-9"></a>

9. **朝鲜王子受封几侯。** 朝鲜王子在汉军围城时归降，侯籍列为本年受封几侯。降汉过程在前108年战争中，授爵另记。 [[9]](#note-9)

<a id="sj020-e136"></a>
<a id="最因路人之功封涅阳侯"></a>


<a id="event-10"></a>

10. **最因路人之功封涅阳侯。** 相路人归降后死于途中，其子最受封涅阳侯。受封者和途中去世者是父子，不是一个人死后又归降。 [[10]](#note-10)

<a id="sj021"></a>
<a id="王子分邑与侯国的接续"></a>

<a id="sj021-r023-e03"></a>

<a id="event-11"></a>

11. **劇魁侯爵由后人接续。** 刘德接续劇魁侯爵，侯统进入新的一代。 [[11]](#note-11)

<a id="sj021-r047-e02"></a>

<a id="event-12"></a>

12. **畢梁侯一支因案失国。** 畢梁侯一支因案失去侯爵，侯国被撤销。 [[12]](#note-12)

<a id="sj059-jiaodong-xian-event"></a>

13. **胶东哀王刘贤去世，刘通平承接王国。** 刘贤自前120年开始记元年，在位十四年而卒。其子刘通平继承，下一年前106年开始记新王元年。 [[13]](#sj059-jiaodong-xian-note)

<a id="sj103-event-14"></a>

14. **关东流民众多，议迁实边，石庆请退后复职。** 关东出现大量流民。公卿请将流民迁往边地，武帝查问议事者。丞相石庆自责，请交还印绶，受武帝责备后继续视事。 [[14]](#note-14)

<a id="sj110-event-15"></a>

<a id="sj110-event-16"></a>

15. **汉匈互遣使者，交涉反复受阻。** 王乌、杨信先后赴匈奴交涉。汉使王乌依匈奴礼入单于帐；随后杨信拒绝放下符节，在帐外与单于议以太子入汉为质，单于未允。匈奴使者死于长安，汉使路充国被扣。王乌报告单于称愿入汉，汉为他营建馆舍。匈奴使者在长安病死，路充国送丧，单于怀疑汉害使者，将路充国扣留。 [[15]](#note-15)

<a id="sj110-event-17"></a>

16. **郭昌、赵破奴屯朔方以东。** 匈奴侵边后，朝廷任郭昌为拔胡将军，与浞野侯赵破奴屯朔方以东，加强防备。 [[16]](#note-17)

<a id="hs-event-18"></a>

17. **夏季大旱，民多中暑身亡。** 夏季大旱，许多百姓中暑而死。 [[17]](#hs-note-18)

<a id="hs-event-19"></a>

18. **繁安夷侯忠一支爵位承袭。** 元封四年，安侯守继承侯爵。 [[18]](#hs-note-19)

<a id="hs-event-20"></a>

19. **从票侯赵破奴｜改封。** 表载从票侯赵破奴一支本年爵号或封邑改易。表中所载事项为因匈河将军击楼兰，封浞野侯。 [[19]](#hs-note-20)

<a id="hs-event-21"></a>

20. **将梁侯杨仆｜获罪。** 表载将梁侯杨仆一支本年载相关罪案及处分。表中所载事项为因罪案为将军击朝鲜畏懦，入竹两万个，赎未处肉刑，服城旦劳役。 [[20]](#hs-note-21)

<a id="hs-event-27"></a>

21. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[21]](#hs-note-27)

> 元封四年，關東流民二百萬口，無名數者四十萬，公卿議欲請徙流民於邊以適之。上以爲慶老謹，不能與其議，乃賜丞相告歸，而案御史大夫以下議爲請者。慶慙不任職，上書曰：「臣幸得待罪丞相，疲駑無以輔治。城郭倉廩空虛，民多流亡，罪當伏斧質，上不忍致法。願歸丞相侯印，乞骸骨歸，避賢者路。」

<a id="hs046-l7508-e14"></a>

**[《汉书·万石卫直周张传》P012](../../拆分史书/汉书/卷046.md#p012)** · [仓内TXT L7508](../../拆分史书/汉书/卷046.md#part-1-L7508)

> 上報曰：「閒者，河水滔陸，泛濫十餘郡，隄防勤勞，弗能陻塞，朕甚憂之。是故巡方州，禮嵩嶽，通八神，以合宣房。濟淮江，歷山濵海，問百年民所疾苦。惟吏多私，徵求無已，去者便，居者擾，故爲流民法，以禁重賦。乃者封泰山，皇天嘉況，神物並見。朕方荅氣應，未能承意，是以切比閭里，知吏姦邪。委任有司，然則官曠民愁，盜賊公行。往年覲明堂，赦殊死，無禁錮，咸自新，與更始。今流民愈多，計文不改，君不繩責長吏，而請以興徙四十萬口，搖蕩百姓，孤兒幼年未滿十歲，無罪而坐率，朕失望焉。今君上書言倉庫城郭不充實，民多貧，盜賊衆，請入粟爲庶人。夫懷知民貧而請益賦，動危之而辭位，欲安歸難乎？君其反室！」

### 卷018｜原格、异年与本页采用

**逐格定位：** <a id="sj018-r015-wu"></a>[R015](../../拆分史书/史记/卷018.md#r015) · <a id="sj018-r111-wu"></a>[R111](../../拆分史书/史记/卷018.md#r111)。

本页按原格中明确年号、承袭次序及互见材料分别定位；未载月份的不补日期，元年也不一律倒推父亲死年。侯爵与所任中央官职不是同一继承关系。

**R015：** 萧胜失爵史表明系元朔二年，汉表以景中二年嗣、在位二十一年及“不斋祠宗庙”叙述，计数与史表明年不尽合；本轮采用史表前127年，不再按任期另造前一年免爵。萧庆元狩三年绍封，亦见《汉书·武帝纪》；萧寿成元狩六年承、元封四年失爵沿史表。汉表的任期数字不能在未校历前强换成另一独立死日。

**R111：** 史表末句涉及“与乐令无可当郑舞人擅繇不如令，阑出函谷关”，文字断读有疑，正文只取违法役使祭乐人员与出关两项可辨要旨，不将“无可当”猜成人名。史表元封四年、汉表元封三年且详记“以令隶为之”与出关相接，本轮暂系前107年，前108年留为异说，不发生两次相同免爵。行首长修、后封阳平不可混称。

互校：[《汉书》高惠高后文功臣表](../../拆分史书/汉书/卷016.md#part-1-text) · [《史记》三家注卷018](../../拆分史书/史记/卷018.md#part-2-text)。

### 卷020｜原格、互见与采用的年线

[完整原文](../../拆分史书/史记/卷020.md) · [逐格去向](../../拆分史书/史记/卷020.md) · [纪年与异说](../../拆分史书/史记/卷020.md#kao-dd656ec25a)。初封、增邑、继承与任官分开；月日未明不补，谥号为后称，国除不一律等于处死。

<a id="sj020-e128-n"></a>
**平州一支无后而终：** [R066 平州](../../拆分史书/史记/卷020.md#r066)。史表明记元封三年封、四年薨，原一可按不计死亡年合；[《汉书·景武昭宣元成功臣表》](../../拆分史书/汉书/卷017.md#part-1-text)封四年薨的四却可能是任期数，不能说也明系元封四年死亡。正文暂依史表前107年，另存任期异读，不再造第二次死亡。 互校：[漢書/卷017](../../拆分史书/汉书/卷017.md#part-1-text)。

<a id="sj020-e129-n"></a>
**稽谷姑封騠兹侯：** [R069 騠茲](../../拆分史书/史记/卷020.md#r069)。原号若苴王／右苴王、授爵丁卯／丁未有差。小月氏不能与张骞远使的大月氏直接等同。 互校：[漢書/卷017](../../拆分史书/汉书/卷017.md#part-1-text)。

<a id="sj020-e131-n"></a>

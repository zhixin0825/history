# 公元前108年｜朝鲜战争与旱灾，胶西王国无后而除

[← 公元前109年](bce-0109.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前107年 →](bce-0107.md)

**汉武帝元封三年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补王国更替；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，跨年回叙不当成同年新事。

<a id="sj012-108-1"></a>
## 朝鲜战事与祀灵星

**汉军征朝鲜，朝鲜王右渠被杀，汉廷在原地设郡。** 同年出现干旱，公孙卿说黄帝封禅之后也曾「乾封三年」，因此旱不一定是坏事。武帝接受了把祀灵星加强的建议。

**战争结果、干旱和方士解释是三件不同性质的事。** 不能因同年出现，就断言封禅必然造成旱灾，或某项祭祀令雨水恢复。

**本段史料：** [卷012 P022](../../sources/摘录/史记-卷012-孝武本纪.md#p022)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-c016038282df01)。《汉书》元封三年记朝鲜平定，卷012记旱情和尊祀灵星；先秦黄帝传说不可当作确年气候数据。

<a id="sj017-jiaoxi"></a>
## 胶西王刘端去世，王国被撤销

**刘端在位四十七年后去世，没有儿子承接，胶西改为郡。** 他是七国之乱后受封的景帝之子，与当年参加叛乱的前胶西王刘卬不是一人。王国结束是本年的事件，不把他过去多年与官吏的冲突都安排在死前几日。[原文与说明](#sj017-note)

<a id="sj017-chengyang"></a>
**城阳由刘武开始新的王年。** 父亲刘义之死已在前109年，刘武继承的是刘章一支的城阳，不是梁孝王复生。[原文与说明](#sj017-note)

<a id="sj017-audience"></a>
**鲁王刘光、清河王刘义入朝。** 清河刘义来自文帝的代王一支，与刚去世的城阳刘义是两个人。这里若只写姓名、不交代封国，便容易误认为死人又来朝。[原文与说明](#sj017-note)

<a id="sj017-note"></a>
[卷017前108年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0108)胶西无后除国、城阳慧王武元年、鲁清河来朝；[五宗世家](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7059.md#ref-7636a9f5d55627)与[汉书诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7014.md#ref-0a721b69fe7f8a)补刘端的父系及四十七年结局。于／於王是谥号写法，不把字形改成另一位国君。城阳刘武也常见惠王写法，元年用于定位，不以谥号推定本人已经去世。来朝月份未明。

## 军政、受封与侯国的接续

<a id="sj020-e106"></a>
### 杨仆因朝鲜战争失利被免

杨仆在朝鲜战争中因军队损失等责任被追究，失去将梁侯爵，降为庶人。 [原文与说明](#sj020-e106-n)

<a id="sj020-e123"></a>
### 赵破奴攻楼兰、车师，复封浞野侯

赵破奴领军进入西域，先捕得楼兰王，再攻破车师。曾受楼兰阻拦的汉使王恢参与军事行动。赵破奴因功恢复列侯身份，这次封号为浞野，不是原来的从骠。 [原文与说明](#sj020-e123-n)

<a id="sj020-e124"></a>
### 朝鲜战争中的归降与刺王

汉军围攻朝鲜，各方选择逐渐分裂。将领唊、相韩阴等先后降汉；尼谿相参使人杀死右渠，向汉方归附。相路人也先降，却死在途中，后来由儿子最承受奖赏。 [原文与说明](#sj020-e124-n)

<a id="sj020-e125"></a>
### 唊封平州侯

朝鲜将领唊向汉归降，受封平州侯。 [原文与说明](#sj020-e125-n)

<a id="sj020-e126"></a>
### 韩阴封荻苴侯

朝鲜相韩阴在汉军围攻时归降，受封荻苴侯。 [原文与说明](#sj020-e126-n)

<a id="sj020-e127"></a>
### 参封澅清侯

朝鲜尼谿相参使人杀右渠、归降，受封澅清侯。 [原文与说明](#sj020-e127-n)

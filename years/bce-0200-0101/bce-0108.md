# 公元前108年｜朝鲜战争与旱灾，胶西王国无后而除

[← 公元前109年](bce-0109.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前107年 →](bce-0107.md)

**汉武帝元封三年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补王国更替；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，跨年回叙不当成同年新事。

<a id="朝鲜战事与祀灵星"></a>
### 朝鲜战事与祀灵星

<a id="event-1"></a>

1. **汉军征朝鲜，朝鲜王右渠被杀，汉廷在原地设郡。** 同年出现干旱，公孙卿说黄帝封禅之后也曾「乾封三年」，因此旱不一定是坏事。武帝接受了把祀灵星加强的建议。 [[1]](#note-1)

<a id="event-2"></a>

2. **战争结果、干旱和方士解释是三件不同性质的事。** 不能因同年出现，就断言封禅必然造成旱灾，或某项祭祀令雨水恢复。 [[2]](#note-2)

   **本段史料：** [卷012 P022](../../sources/摘录/史记-卷012-孝武本纪.md#p022)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-c016038282df01)。《汉书》元封三年记朝鲜平定，卷012记旱情和尊祀灵星；先秦黄帝传说不可当作确年气候数据。

<a id="sj017-jiaoxi"></a>
<a id="胶西王刘端去世王国被撤销"></a>
### 胶西王刘端去世，王国被撤销

<a id="event-3"></a>

3. **刘端在位四十七年后去世，没有儿子承接，胶西改为郡。** 他是七国之乱后受封的景帝之子，与当年参加叛乱的前胶西王刘卬不是一人。王国结束是本年的事件，不把他过去多年与官吏的冲突都安排在死前几日。 [[3]](#note-3)

<a id="sj017-chengyang"></a>

<a id="event-4"></a>

4. **城阳由刘武开始新的王年。** 父亲刘义之死已在前109年，刘武继承的是刘章一支的城阳，不是梁孝王复生。 [[4]](#note-4)

<a id="sj017-audience"></a>

<a id="event-5"></a>

5. **鲁王刘光、清河王刘义入朝。** 清河刘义来自文帝的代王一支，与刚去世的城阳刘义是两个人。这里若只写姓名、不交代封国，便容易误认为死人又来朝。 [[5]](#note-5)

### 赵破奴攻楼兰、车师，复封浞野侯

<a id="event-7"></a>

7. **赵破奴领军进入西域，先捕得楼兰王，再攻破车师。** 曾受楼兰阻拦的汉使王恢参与军事行动。赵破奴因功恢复列侯身份，这次封号为浞野，不是原来的从骠。 [[7]](#note-7)

### 朝鲜战争中的归降与刺王

<a id="event-8"></a>

8. **汉军围攻朝鲜，各方选择逐渐分裂。** 将领唊、相韩阴等先后降汉；尼谿相参使人杀死右渠，向汉方归附。相路人也先降，却死在途中，后来由儿子最承受奖赏。 [[8]](#note-8)

> 左將軍已并兩軍，即急擊朝鮮。朝鮮相路人、相韓陰、尼谿相參、將軍王唊相與謀曰：「始欲降樓船，樓船今執，獨左將軍并將，戰益急，恐不能與，（戰）王又不肯降。」陰、唊、路人皆亡降漢。路人道死。元封三年夏，尼谿相參乃使人殺朝鮮王右渠來降。王險城未下，故右渠之大臣成巳又反，復攻吏。左將軍使右渠子長降、相路人之子最告諭其民，誅成巳，以故遂定朝鮮，為四郡。封參為澅清侯，陰為荻苴侯，唊為平州侯，長［降］為幾侯。最以父死頗有功，為溫陽侯。

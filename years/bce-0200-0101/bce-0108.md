# 公元前108年｜朝鲜战争与旱灾，胶西王国无后而除

[← 公元前109年](bce-0109.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前107年 →](bce-0107.md)

**汉武帝元封三年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补王国更替；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，跨年回叙不当成同年新事。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj012-108-1"></a>
<a id="朝鲜战事与祀灵星"></a>

<a id="event-1"></a>

1. **朝鲜战事与祀灵星。** 汉军征朝鲜，朝鲜王右渠被杀，汉廷在原地设郡。 同年出现干旱，公孙卿说黄帝封禅之后也曾「乾封三年」，因此旱不一定是坏事。武帝接受了把祀灵星加强的建议。 右渠死后成巳仍在王险抵抗，汉军经右渠与路人的儿子劝谕城中居民，诛成巳后才完成平定。 [[1]](#note-1)

<a id="event-2"></a>

2. **战争结果、干旱和方士解释是三件不同性质的事。** 不能因同年出现，就断言封禅必然造成旱灾，或某项祭祀令雨水恢复。 [[2]](#note-2)

   《汉书》元封三年记朝鲜平定，卷012记旱情和尊祀灵星；先秦黄帝传说不可当作确年气候数据。

<a id="sj017-jiaoxi"></a>
<a id="胶西王刘端去世王国被撤销"></a>

<a id="event-3"></a>

3. **刘端在位四十七年后去世，没有儿子承接，胶西改为郡。** 他是七国之乱后受封的景帝之子，与当年参加叛乱的前胶西王刘卬不是一人。王国结束是本年的事件，不把他过去多年与官吏的冲突都安排在死前几日。 [[3]](#note-3)

<a id="sj017-chengyang"></a>

<a id="event-4"></a>

4. **城阳由刘武开始新的王年。** 父亲刘义之死已在前109年，刘武继承的是刘章一支的城阳，不是梁孝王复生。 [[4]](#note-4)

<a id="sj017-audience"></a>

<a id="event-5"></a>

5. **鲁王刘光、清河王刘义入朝。** 清河刘义来自文帝的代王一支，与刚去世的城阳刘义是两个人。这里若只写姓名、不交代封国，便容易误认为死人又来朝。 [[5]](#note-5)

<a id="sj020"></a>
<a id="军政受封与侯国的接续"></a>

<a id="sj020-e106"></a>
<a id="杨仆因朝鲜战争失利被免"></a>


<a id="event-6"></a>

6. **杨仆因朝鲜战争失利被免。** 杨仆在朝鲜战争中因军队损失等责任被追究，失去将梁侯爵，降为庶人。 [[6]](#note-6)

<a id="sj020-e123"></a>
<a id="赵破奴攻楼兰车师复封浞野侯"></a>

<a id="event-7"></a>

7. **赵破奴攻楼兰、车师，复封浞野侯。** 赵破奴领军进入西域，先捕得楼兰王，再攻破车师。 曾受楼兰阻拦的汉使王恢参与军事行动。赵破奴因功恢复列侯身份，这次封号为浞野，不是原来的从骠。 参与此役的王恢亦以军功封浩侯。亭障延至玉门是随后建设。 [[7]](#note-7)

<a id="sj020-e124"></a>
<a id="朝鲜战争中的归降与刺王"></a>

<a id="event-8"></a>

8. **朝鲜战争中的归降与刺王。** 汉军围攻朝鲜，各方选择逐渐分裂。 将领唊、相韩阴等先后降汉；尼谿相参使人杀死右渠，向汉方归附。相路人也先降，却死在途中，后来由儿子最承受奖赏。 [[8]](#note-8)

<a id="sj020-e125"></a>
<a id="唊封平州侯"></a>


<a id="event-9"></a>

9. **唊封平州侯。** 朝鲜将领唊向汉归降，受封平州侯。 [[9]](#note-9)

<a id="sj020-e126"></a>
<a id="韩阴封荻苴侯"></a>


<a id="event-10"></a>

10. **韩阴封荻苴侯。** 朝鲜相韩阴在汉军围攻时归降，受封荻苴侯。 [[10]](#note-10)

<a id="sj020-e127"></a>
<a id="参封澅清侯"></a>


<a id="event-11"></a>

11. **参封澅清侯。** 朝鲜尼谿相参使人杀右渠、归降，受封澅清侯。 [[11]](#note-11)

<a id="sj021"></a>
<a id="王子分邑与侯国的接续"></a>

<a id="sj021-r086-e02"></a>

<a id="event-12"></a>

12. **象氏侯爵由后人接续。** 刘安德接续象氏侯爵，侯统进入新的一代。 [[12]](#note-12)

<a id="sj111-event-13"></a>

13. **荀彘因擅拘杨仆被处死。** 朝鲜战事结束后，左将军荀彘因擅自拘捕楼船将军杨仆被处死。杨仆的军法处分另见本年原条。 [[13]](#sj111-note-13)

<a id="sj028-event-14"></a>

14. **汉廷在泰山下兴建明堂。** 汉廷于泰山下建明堂，传文说奉高汶上采用公玉带所献图；元封五年行礼另有记年。 [[14]](#note-14)

<a id="sj122-event-15"></a>

15. **杜周由御史中丞出任廷尉。** 杜周以候伺上意治狱，曾任御史中丞，元封三年任廷尉，诏狱渐多。 [[15]](#note-15)

<a id="sj130-event-16"></a>

16. **司马迁继任太史令，整理官府藏书。** 据《太史公自序》所述父卒与改历间隔，通常系在元封三年。司马迁得以整理石室、金匮所藏的史籍。 [[16]](#note-16)

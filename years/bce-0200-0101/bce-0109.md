1. **皇帝亲临瓠子，官员一起背柴堵口。** **时间：元封二年，封禅后次年** · 事件 [[1]](#note-1)

   瓠子决口已延续二十多年，梁、楚地区屡受歉收之害。朝廷派汲仁、郭昌征人数万重新堵口。皇帝祭万里沙、回祠泰山后亲临决口，把白马、玉璧沉入河中，命将军以下的随行官员背柴填塞。东郡此前烧草，柴料不足，便取淇园竹子制楗，配合草、土石堵口。沉祭属于当时祭河活动，不作为工程成功的物理解释。


<a id="sj-029-L2887-01"></a>
<a id="2-瓠子歌与宣房宫"></a>

<a id="event-2"></a>

2. **瓠子歌与宣房宫。** **时间：同次堵口** · 文献 [[2]](#note-2)

   皇帝来到决口处，感叹堵口困难，作歌叙述水患、求神及缺少材料的处境。书中保存了两段歌辞。工程终于堵住决口，又在上面建宣房宫，并引导黄河北流。


<a id="孝武本纪所补的祭祀与方士记事"></a>
<a id="sj012-109-1"></a>
<a id="东莱求仙未果皇帝转到黄河工地"></a>

<a id="event-3"></a>

3. **东莱求仙未果，皇帝转到黄河工地。** 春天，公孙卿说在东莱见过神人。 武帝到缑氏、东莱一带等候，结果仍只听到所谓脚印，没有亲见仙人。随后又遇旱情，祭祀名山；返程到瓠子决口处，亲临塞河。 [[3]](#note-3)

<a id="event-4"></a>

4. **这次塞河并非第一次治水。** 决口早在元光三年前132年已经存在，前一次修堵屡败。此次皇帝让臣下背柴填口，继续组织工程，形成新水道；本页原有《河渠书》所记施工与《瓠子歌》仍保留。 [[4]](#note-4)

   本纪卷012与原页卷029并读，不重新记一回平行的治水故事。

<a id="sj012-109-2"></a>
<a id="通天台等宫观又被提出"></a>

<a id="event-5"></a>

5. **公孙卿说仙人喜欢高楼，武帝便在长安和甘泉增设或修建宫观、通天台等候神设施。** 甘泉宫中出现九茎芝草的报告后，朝廷宣布赦令，还把塞河与建台一起当作得到天意的征兆。 [[5]](#note-5)

<a id="event-6"></a>

6. **越巫、鸡卜也被纳入宫廷的祭祀活动。** 这类新的祭法和建设耗费持续增加，但文献没有逐项给出可核的成本与财政统计。 [[6]](#note-6)

   《汉书》元封二年记通天台、飞廉观、芝草与赦令；其他建筑的精确建设月日留待核。

<a id="sj017-succession"></a>

7. **城阳王刘义去世，儿子刘武承接，下一年列元年。** 刘义是前一代城阳王刘延之子；他的儿子刘武也不是早已去世的梁孝王刘武。同名人物须沿不同父系和封国辨认。 [[7]](#note-7)

<a id="event-8"></a>

8. **淄川王刘遗开始记元年，接续刘建。** 刘建的在位结束与刘遗的继承相接，不把这个“元年”误读成淄川国历史上第一次建立。 [[8]](#note-8)

10. **秋季，杨仆和荀彘分路出兵朝鲜。** 杨仆领楼船军，荀彘为左将军；战争延续到次年，两军将帅之间也逐渐产生嫌隙。 随后杨仆先抵王险，遭右渠击退；荀彘在浿水以西的初战也未能打开局面。两传将初战接在出师之后，《资治通鉴》把这段放在下一年。 [[10]](#note-10)

<a id="sj028-event-11"></a>

11. **元封二年冬武帝郊雍五帝。** 武帝冬十月到雍郊祀五帝，还拜太一。赞辞以德、寿、信三星解释祀礼。 [[11]](#note-11)

<a id="sj115-event-12"></a>

12. **涉何出使朝鲜，杀裨王后遭袭身亡。** 右渠拒绝接受谕令，汉使涉何在边界杀害护送自己的裨王长，返汉报功并获授官。朝鲜出兵报复，杀死涉何。 [[12]](#note-12)

<a id="sj116-event-13"></a>

13. **滇王降汉，朝廷置益州郡并保留滇王。** 汉军由巴蜀出兵，先击灭劳𣹰、靡莫，再进逼滇。滇王归降并请设官，朝廷设益州郡，同时赐滇王印，仍让他统领部众。 [[13]](#note-13)

<a id="hs-event-14"></a>

14. **泰山下兴建明堂。** 秋季在泰山脚下兴建明堂，与前次封禅及明堂朝仪分别看。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[15]](#hs-note-15)

**[《史记·封禅书》P090](../../sources/摘录/史记-卷028-封禅书.md#p090)** · [三家注](../../sources/史记三家注/卷028.md#p90)

<a id="sj029-later-irrigation"></a>
### 卷029跨年总叙｜各地灌渠并非本年一齐完工

本卷接着概述各地官员争相谈水利：朔方、西河、河西、酒泉引黄河及山谷水灌田；关中辅渠、灵轵以及汝南、九江、东海、泰山下的工程，分别利用当地河泽。书中概括这些工程各有万余顷的灌田，小渠和山路多得不能尽说，而最著名的仍是宣房。

**[《史记·河渠书》P013](../../sources/摘录/史记-卷029-河渠书.md#p013)**

> 自是之後，用事者爭言水利。朔方、西河、河西、酒泉皆引河及川谷以溉田；而關中輔渠、靈軹引堵水；汝南、九江引淮；東海引鉅定；泰山下引汶水：皆穿渠為溉田，各萬餘頃。佗小渠披山通道者，不可勝言。然其著者在宣房。


“自是之后”是篇章收束，不宜强作每一项目的开工年份。[前111年儿宽请开六辅渠](bce-0111.md#sj029-six-aux-event)已有汉志明确年次，早于本年。其他地区在本段没有各自的确切起讫年；不编造全国同年新增灌田总数，也不把梁楚暂时获安写成黄河以后永久无灾。

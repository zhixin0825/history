# 公元前110年｜大军北巡后登泰山，封禅并改元

[← 公元前111年](bce-0111.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前109年 →](bce-0109.md)

**汉武帝元封元年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补王国更替和朝见；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，跨年回叙不当成同年新事。

[本年相关史料](#sources-start)

<a id="sj012-110-1"></a>
<a id="冬季北巡先展示军威"></a>

<a id="event-1"></a>

1. **冬季北巡，先展示军威。** 武帝率大军向北巡视朔方一带，经过黄帝冢所在的桥山，向匈奴展示军威。 北巡及祭黄帝冢之后，转回甘泉，为泰山封禅作准备。有人解释说黄帝虽有墓却成仙，墓中只葬衣冠；这只是当时解释神话与墓葬冲突的说辞。 [[1]](#note-1)

<a id="event-2"></a>

2. **不应把军事行军直接写成已经与匈奴决战获胜。** 本年是勒兵、威示与往返巡察，实际战事要依另卷记载。 [[2]](#note-2)

   《汉书》元封元年十月记北巡勒兵；本纪把祭黄帝冢接在封禅的准备过程。

<a id="sj012-110-2"></a>
<a id="礼制争论未决皇帝自己决定怎么封禅"></a>

<a id="event-3"></a>

3. **礼制争论未决，皇帝自己决定怎么封禅。** 武帝邀请儒生和方士讨论封禅，却发现各家礼节互不相同。 儒生引经据典，方士谈黄帝得仙，朝廷甚至练习射牛等礼仪。皇帝嫌建议矛盾、无法执行，最后罢去许多儒生拟议，自己择用一部分程序。 [[3]](#note-3)

<a id="event-4"></a>

4. **先到嵩高礼祭，继往泰山、海上。** 随从声称听到山中呼万岁，因而封三百户为崇高邑奉祀；海边寻找仙人毫无确证，公孙卿说见巨人脚印，皇帝仍继续派人找。 [[4]](#note-4)

   「万岁声」「巨人迹」明确作随从和方士陈述，不作史书已证异象。

<a id="sj012-110-3"></a>
<a id="四月封泰山禅肃然山"></a>

<a id="event-5"></a>

5. **四月到奉高，武帝先在泰山下东侧依礼设封，再与侍中奉车子侯上山，山顶仪式高度保密；次日在肃然山举行禅礼。** 封禅是祀天祀地相联系的典礼，不是普通的郊游，也不代表儒臣最初所有方案都被采纳。 [[5]](#note-5)

<a id="event-6"></a>

6. **回来以后，皇帝下诏赦罪、赐牛酒、优待高龄孤寡，并免除部分所经县当年租税。** 礼毕还继续沿海北巡，奉车子侯在途中突然死亡。武帝随后把此年定为元封元年，官员以得鼎和封禅解释年号。封禅叙述中的光云属当时报告，不可改作现代确认的天气神迹。 [[6]](#note-6)

   《汉书》元封元年四月与诏令有互见，奖赏适用对象及范围据两书保留差异；不同于从此天下全免税。

<a id="sj012-110-4"></a>
<a id="当年秋季有天象报道"></a>

<a id="event-7"></a>

7. **秋天有人观察到彗状星体，记录其经过东井与三台一带。** 朝廷望气者有人把它解释成皇帝封禅获得「德星」回应。天象报告和政治解释须分层；不能从祝辞中直接推出真实的天体性质或祸福。 [[7]](#note-7)

   本纪的「茀」与《汉书》元封元年彗星互见；星官名词按史料保留。

<a id="sj017-qi"></a>
<a id="齐王刘闳去世封国没有继承人"></a>

<a id="event-8"></a>

8. **武帝的儿子刘闳去世，齐国因无后而被撤销。** 他在前117年与刘旦、刘胥一同受封，只在位八年。这里结束的是武帝之子的齐国，前127年旧齐王刘次昌的终局已经过去十余年，不可合为同一位齐王。 [[8]](#note-8)

<a id="sj017-zhongshan"></a>

<a id="event-9"></a>

9. **中山王刘昆侈开始记元年。** 本页沿汉书王表安排；史记表提前一年，其父刘昌在位长短也有差别，见前两年相关注，不重复继位。 [[9]](#note-9)

<a id="sj017-audience"></a>

<a id="event-10"></a>

10. **城阳王刘义、真定王刘平本年入朝。** 年表没有把地点具体写作泰山，不能仅因为皇帝同年封禅，就断定他们在山顶参加秘密仪式。 [[10]](#note-10)

<a id="sj030-pingzhun-event"></a>

31. **桑弘羊统筹均输，并在京师设置平准。** 地方各官自行采购容易相互抬价，远道实物税也有运费超过物值的问题。朝廷因此扩大均输，按物产调运，京师集中收受货物，贵卖贱买，期望减轻价格剧烈波动、限制巨商之利。早期均输已有前史，不称本年从无到有。 [[31]](#sj030-pingzhun-note)

<a id="sj030-grain-event"></a>

### 1. 武帝率大军向北巡视朔方一带，经过黄帝冢所在的桥山，向匈奴展示军威

[返回正文第1条](#event-1)

**[《漢書》卷006](../../sources/本地分卷/汉书/汉书-卷006.md#L457)**

> 元封元年冬十月，詔曰：「南越、東甌咸伏其辜，西蠻北夷頗未輯睦，朕將巡邊垂，擇兵振旅，躬秉武 節，置十二部將軍，親帥師焉。」行自雲陽，北歷上郡、西河、五原，出長城，北登單于臺，至朔方，臨北河。勒兵十八萬騎，旌旗徑千餘里，威震匈奴。遣使者告 單于曰：「南越王頭已縣於漢北闕矣。單于能戰，天子自將待邊；不能，亟來臣服。何但亡匿幕北寒苦之地為！」匈奴讋焉。還，祠黃帝於橋山，乃歸甘泉。

**[《史記》卷012](../../sources/本地分卷/史记/史记-卷012.md#L738)**

> 其來年冬，上議曰：「古者先振兵澤旅，然後封禪。」乃遂北巡朔方，勒兵十餘萬，還祭黃帝冢橋山，澤兵須如。上曰：「吾聞黃帝不死，今有冢，何也？」或對曰：「黃帝已僊上天，群臣葬其衣冠。」即至甘泉，為且用事泰山，先類祠泰一。

### 3. 武帝邀请儒生和方士讨论封禅，却发现各家礼节互不相同

[返回正文第3条](#event-3)

**[《史記》卷012](../../sources/本地分卷/史记/史记-卷012.md#L739)**

> 自得寶鼎，上與公卿諸生議封禪。封禪用希曠絕，莫知其儀禮，而群儒采封禪尚書、周官、王制之望祀射牛事。齊人丁公年九十餘，曰：「封者，合不死之名也。秦皇帝不得上封。陛下必欲上，稍上即無風雨，遂上封矣。」上於是乃令諸儒習射牛，草封禪儀。數年，至且行。天子既聞公孫卿及方士之言，黃帝以上封禪，皆致怪物與神通，欲放黃帝以嘗接神僊人蓬萊士，高世比德於九皇，而頗采儒術以文之。群儒既以不能辯明封禪事，又牽拘於詩書古文而不敢騁。上為封祠器示群儒，群儒或曰「不與古同」，徐偃又曰「太常諸生行禮不如魯善」，周霸屬圖封事，於是上絀偃、霸，盡罷諸儒弗用。

### 5. 四月到奉高，武帝先在泰山下东侧依礼设封，再与侍中奉车子侯上山，山顶仪式高度保密；次日在肃然山举行禅礼

[返回正文第5条](#event-5)

**[《史記》卷012](../../sources/本地分卷/史记/史记-卷012.md#L742)**

> 四月，還至奉高。上念諸儒及方士言封禪人人殊，不經，難施行。天子至梁父，禮祠地主。乙卯，令侍中儒者皮弁薦紳，射牛行事。封泰山下東方，如郊祠泰一之禮。封廣丈二尺，高九尺，其下則有玉牒書，書祕。禮畢，天子獨與侍中奉車子侯上泰山，亦有封。其事皆禁。明日，下陰道。丙辰，禪泰山下阯東北肅然山，如祭后土禮。天子皆親拜見，衣上黃而盡用樂焉。江淮閒一茅三脊為神藉。五色土益雜封。縱遠方奇獸蜚禽及白雉諸物，頗以加祠。兕旄牛犀象之屬弗用。皆至泰山然後去。封禪祠，其夜若有光，晝有白雲起封中。

### 6. 回来以后，皇帝下诏赦罪、赐牛酒、优待高龄孤寡，并免除部分所经县当年租税

<a id="sj030-pingzhun-note"></a>

### 31. 桑弘羊统筹均输，并在京师设置平准

[返回正文第31条](#sj030-pingzhun-event)

**[《史记·平准书》P047](../../sources/摘录/史记-卷030-平准书.md#p047)**

> 其明年，元封元年，卜式貶秩為太子太傅。而桑弘羊為治粟都尉，領大農，盡代僅筦天下鹽鐵。弘羊以諸官各自市，相與爭，物故騰躍，而天下賦輸或不償其僦費，乃請置大農部丞數十人，分部主郡國，各往往縣置均輸鹽鐵官，令遠方各以其物貴時商賈所轉販者為賦，而相灌輸。置平準于京師，都受天下委輸。召工官治車諸器，皆仰給大農。大農之諸官盡籠天下之貨物，貴即賣之，賤則買之。如此，富商大賈無所牟大利，則反本，而萬物不得騰踴。故抑天下物，名曰「平準」。天子以為然，許之。於是天子北至朔方，東到太山，巡海上，并北邊以歸。所過賞賜，用帛百餘萬匹，錢金以巨萬計，皆取足大農。

> 至甘泉凡周行萬八千里云先是桑𢎞羊為治粟都尉

### 太史公对货币、财政与事势的总论

以下为跨年背景或篇末评论，不计作本年新发生的编号事件。

<a id="sj030-author-p050"></a>

**太史公论财政变迁**

太史公从农工商交换与货币起源说起，承认上古细节已难考；安定时期重学校礼义、以农业为本，事变频繁时政策往往反转。《禹贡》式贡赋因地而异，汤武因时改变；管仲借轻重与山海之利助齐称霸，魏用李克尽地力，战国竞逐富强，贫富与强弱分化。秦统一后以黄金、半两钱为上下币，珠玉龟贝银锡多作器饰宝藏；内外不断兴事，男女劳作仍不足供用。作者把这种财政不足解释为事势相激而成，劝读者从政策与需求的连续变化理解，而非仅惊怪于钱粮耗尽。

**[《史记·平准书》P050](../../sources/摘录/史记-卷030-平准书.md#p050)**

> 太史公曰：農工商交易之路通，而龜貝金錢刀布之幣興焉。所從來久遠，自高辛氏之前尚矣，靡得而記云。故書道唐虞之際，詩述殷周之世，安寧則長庠序，先本絀末，以禮義防于利；事變多故而亦反是。是以物盛則衰，時極而轉，一質一文，終始之變也。禹貢九州，各因其土地所宜，人民所多少而納職焉。湯武承獘易變，使民不倦，各兢兢所以為治，而稍陵遲衰微。齊桓公用管仲之謀，通輕重之權，徼山海之業，以朝諸侯，用區區之齊顯成霸名。魏用李克，盡地力，為彊君。自是以後，天下爭於戰國，貴詐力而賤仁義，先富有而後推讓。故庶人之富者或累巨萬，而貧者或不厭糟糠；有國彊者或并群小以臣諸侯，而弱國或絕祀而滅世。以至於秦，卒并海內。虞夏之幣，金為三品，或黃，或白，或赤；或錢，或布，或刀，或龜貝。及至秦，中一國之幣為（三）［二］等，黃金以溢名，為上幣；銅錢識曰半兩，重如其文，為下幣。而珠玉、龜貝、銀錫之屬為器飾寶藏，不為幣。然各隨時而輕重無常。於是外攘夷狄，內興功業，海內之士力耕不足糧馕，女子紡績不足衣服。古者嘗竭天下之資財以奉其上，猶自以為不足也。無異故云，事勢之流，相激使然，曷足怪焉。

这是篇末总论，不是前110年一次奏议；“李克”照底本，不静默改为食货志另见的“李悝”。秦币二／三等保留括校符号，不把金属名目直接转换成现代货币本位理论。

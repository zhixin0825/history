# 公元前110年｜大军北巡后登泰山，封禅并改元

[← 公元前111年](bce-0111.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前109年 →](bce-0109.md)

**汉武帝元封元年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补王国更替和朝见；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，跨年回叙不当成同年新事。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj012-110-1"></a>
<a id="冬季北巡先展示军威"></a>

<a id="event-1"></a>

1. **冬季北巡，先展示军威。** 武帝率大军向北巡视朔方一带，经过黄帝冢所在的桥山，向匈奴展示军威。 北巡及祭黄帝冢之后，转回甘泉，为泰山封禅作准备。有人解释说黄帝虽有墓却成仙，墓中只葬衣冠；这只是当时解释神话与墓葬冲突的说辞。 [[1]](#note-1)

<a id="event-2"></a>

2. **不应把军事行军直接写成已经与匈奴决战获胜。** 本年是勒兵、威示与往返巡察，实际战事要依另卷记载。 [[2]](#note-2)

   《汉书》元封元年十月记北巡勒兵；本纪把祭黄帝冢接在封禅的准备过程。

<a id="sj012-110-2"></a>
<a id="礼制争论未决皇帝自己决定怎么封禅"></a>

<a id="event-3"></a>

3. **礼制争论未决，皇帝自己决定怎么封禅。** 武帝邀请儒生和方士讨论封禅，却发现各家礼节互不相同。 儒生引经据典，方士谈黄帝得仙，朝廷甚至练习射牛等礼仪。皇帝嫌建议矛盾、无法执行，最后罢去许多儒生拟议，自己择用一部分程序。 [[3]](#note-3)

<a id="event-4"></a>

4. **先到嵩高礼祭，继往泰山、海上。** 随从声称听到山中呼万岁，因而封三百户为崇高邑奉祀；海边寻找仙人毫无确证，公孙卿说见巨人脚印，皇帝仍继续派人找。 [[4]](#note-4)

   「万岁声」「巨人迹」明确作随从和方士陈述，不作史书已证异象。

<a id="sj012-110-3"></a>
<a id="四月封泰山禅肃然山"></a>

<a id="event-5"></a>

5. **四月到奉高，武帝先在泰山下东侧依礼设封，再与侍中奉车子侯上山，山顶仪式高度保密；次日在肃然山举行禅礼。** 封禅是祀天祀地相联系的典礼，不是普通的郊游，也不代表儒臣最初所有方案都被采纳。 [[5]](#note-5)

<a id="event-6"></a>

6. **回来以后，皇帝下诏赦罪、赐牛酒、优待高龄孤寡，并免除部分所经县当年租税。** 封禅后，武帝坐泰山东北的旧明堂，随后继续沿海北巡。奉车子侯在途中突然死亡。奉高汶上的新明堂于[前109年兴建](bce-0109.md#hs006-l467-e14)。武帝随后把此年定为元封元年，官员以得鼎和封禅解释年号。封禅叙述中的光云属当时报告，不可改作现代确认的天气神迹。 [[6]](#note-6)

   《汉书》元封元年四月与诏令有互见，奖赏适用对象及范围据两书保留差异；不同于从此天下全免税。

<a id="sj012-110-4"></a>
<a id="当年秋季有天象报道"></a>

<a id="event-7"></a>

7. **秋天有人观察到彗状星体，记录其经过东井与三台一带。** 朝廷望气者有人把它解释成皇帝封禅获得「德星」回应。天象报告和政治解释须分层；不能从祝辞中直接推出真实的天体性质或祸福。 [[7]](#note-7)

   本纪的「茀」与《汉书》元封元年彗星互见；星官名词按史料保留。

<a id="sj017-qi"></a>
<a id="齐王刘闳去世封国没有继承人"></a>

<a id="event-8"></a>

8. **武帝的儿子刘闳去世，齐国因无后而被撤销。** 刘闳年少，没有儿子，在前117年与刘旦、刘胥同日受封，到本年为在位第八年。齐王国撤销，改归汉郡。这里结束的是武帝之子的齐国，前127年旧齐王刘次昌的终局已经过去十余年，二人不能混同。[[8]](#note-8)

<a id="sj017-zhongshan"></a>

<a id="event-9"></a>

9. **中山王刘昆侈开始记元年。** 本页沿汉书王表安排；史记表提前一年，其父刘昌在位长短也有差别，见前两年相关注，不重复继位。 [[9]](#note-9)

<a id="sj017-audience"></a>

<a id="event-10"></a>

10. **城阳王刘义、真定王刘平本年入朝。** 年表没有把地点具体写作泰山，不能仅因为皇帝同年封禅，就断定他们在山顶参加秘密仪式。 [[10]](#note-10)

<a id="军政受封与侯国的接续"></a>

<a id="sj020-e108"></a>
<a id="东越内部分裂余善被杀"></a>


<a id="event-14"></a>

14. **东越内部分裂，余善被杀。** 汉军进攻东越时，当地王侯、将领的选择不一。繇王居服与吴阳、原建成侯合作，杀死余善归汉；多军弃军投降。汉军士卒辕终古斩东越徇北将军，黄同则因斩西于王而立功。每项战功对应不同对象，不能把各行“斩余善”都当成独立的一次处死。 东越徇北将军曾据险击败楼船军若干部队。其后汉军进展及余善被杀同为这一轮战事。 吴阳曾奉汉命劝谕余善，未能说服；随后率本邑七百人攻越军，并同居股、敖合谋。 [[14]](#note-14)

<a id="sj020-e109"></a>
<a id="韩说复封按道侯"></a>


<a id="event-15"></a>

15. **韩说复封按道侯。** 韩说先前因酎金失爵，今因横海军讨东越的功劳，再封按道侯。新爵并非龙额爵从未中断的继续。 [[15]](#note-15)

<a id="sj020-e110"></a>
<a id="吴阳封外石侯"></a>


<a id="event-16"></a>

16. **吴阳封外石侯。** 吴阳原是东越衍侯，协助繇王杀余善，获汉廷外石侯爵。 [[16]](#note-16)

<a id="sj020-e111"></a>
<a id="黄同封下鄜侯"></a>


<a id="event-17"></a>

17. **黄同封下鄜侯。** 原瓯骆左将黄同因斩西于王受封下鄜侯。 [[17]](#note-17)

<a id="sj020-e112"></a>
<a id="刘福封缭嫈侯"></a>


<a id="event-18"></a>

18. **刘福封缭嫈侯。** 校尉刘福随韩说讨东越立功，受封缭嫈侯。 [[18]](#note-18)

<a id="sj020-e113"></a>
<a id="辕终古封蓹儿侯"></a>


<a id="event-19"></a>

19. **辕终古封蓹儿侯。** 士卒辕终古斩东越徇北将军，凭战功从军中进入列侯行列。 [[19]](#note-19)

<a id="sj020-e114"></a>
<a id="原东越建成侯改受开陵侯"></a>


<a id="event-20"></a>

20. **原东越建成侯改受开陵侯。** 与繇王合作杀余善的建成侯，获得汉廷开陵侯爵。 [[20]](#note-20)

<a id="sj020-e115"></a>
<a id="孙都因捕吕嘉封临蔡侯"></a>


<a id="event-21"></a>

21. **孙都因捕吕嘉封临蔡侯。** 孙都原在南越为郎，因前一年番禺失守后参与捕得吕嘉，本年受封临蔡侯。 [[21]](#note-21)

<a id="sj020-e116"></a>
<a id="居服封东成侯"></a>


<a id="event-22"></a>

22. **居服封东成侯。** 繇王居服因杀余善归汉，受封东成侯一万户。 [[22]](#note-22)

<a id="sj020-e117"></a>
<a id="多军封无锡侯"></a>


<a id="event-23"></a>

23. **多军封无锡侯。** 东越将军多军放弃所部、向汉归降，受封无锡侯。 [[23]](#note-23)

<a id="sj020-e118"></a>
<a id="嘉因父亲归附封涉都侯"></a>


<a id="event-24"></a>

24. **嘉因父亲归附封涉都侯。** 嘉因父亲此前交城归附而受封涉都侯。父亲弃曾任南海守，在汉军抵达时率城邑归附；这项行动不移写成儿子亲自完成。 [[24]](#note-24)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-32"></a>

30. **儿宽由左内史升任御史大夫，卜式改任太子太傅。** 新任御史大夫由管理地方行政转入中央，卜式则改任辅导太子的职务。 [[30]](#note-32)

<a id="sj030-pingzhun-event"></a>

31. **桑弘羊统筹均输，并在京师设置平准。** 地方各官自行采购容易相互抬价，远道实物税也有运费超过物值的问题。朝廷因此扩大均输，按物产调运，京师集中收受货物，贵卖贱买，期望减轻价格剧烈波动、限制巨商之利。早期均输已有前史，不称本年从无到有。 [[31]](#sj030-pingzhun-note)

<a id="sj030-grain-event"></a>

32. **入粟奖复、均输与官营筹财使仓储、国家供用转充。** 本卷称山东年漕粮增至六百万石，太仓、甘泉仓充满，并记均输帛五百万匹；桑弘羊获爵与黄金二百斤。所谓“民不益赋”应放回原书语境，不能因此否认盐铁价差、财产征算、输粟和征役等负担。 [[32]](#sj030-grain-note)

<a id="sj030-drought-event"></a>

33. **小旱求雨时，卜式以“烹弘羊，天乃雨”讥刺官府逐利。** 他主张国家应靠租税维持，不应让官吏开店谋利。这是对政策的激烈批评，并非已经执行的刑罚，更不是编者认可的降雨因果。 [[33]](#sj030-drought-note)

**卷030背景阅读：** [太史公对货币、财政与事势的总论](#sj030-author)（跨年材料，不计本年新事）。

<a id="sj052-zichuan-jian-event"></a>

34. **菑川靖王刘建去世，儿子刘遗承位。** 刘建从元光六年前129起元，至元封元年本年共二十王年；刘遗下一年前109起元，后续三十五/三十六年的异数另依汉表明确继年核对。 [[34]](#sj052-zichuan-jian-note)

<a id="sj110-event-35"></a>

35. **武帝遣郭吉向单于传话，郭吉被留。** 武帝北巡示威后，命郭吉向单于传话，要其出战或臣服。单于处死引见者，扣留郭吉并将他迁往北海。 [[35]](#note-35)

<a id="sj111-event-36"></a>

36. **霍嬗去世，冠军侯国撤销。** 霍去病之子霍嬗在元封元年去世，谥哀，无子，冠军侯国撤销。 [[36]](#note-36)

<a id="sj114-event-37"></a>

<a id="sj130-event-38"></a>

38. **司马谈滞留周南，临终嘱司马迁续修史书。** 武帝首次封禅时，司马谈没有随行。司马迁从西南奉使回来，在河洛间见到病重的父亲。司马谈嘱他继任太史后整理天下旧闻与本朝人物事迹。 [[38]](#note-38)

### 太史公对货币、财政与事势的总论

以下为跨年背景或篇末评论，不计作本年新发生的编号事件。

<a id="sj030-author-p050"></a>

**太史公论财政变迁**

太史公从农工商交换与货币起源说起，承认上古细节已难考；安定时期重学校礼义、以农业为本，事变频繁时政策往往反转。《禹贡》式贡赋因地而异，汤武因时改变；管仲借轻重与山海之利助齐称霸，魏用李克尽地力，战国竞逐富强，贫富与强弱分化。秦统一后以黄金、半两钱为上下币，珠玉龟贝银锡多作器饰宝藏；内外不断兴事，男女劳作仍不足供用。作者把这种财政不足解释为事势相激而成，劝读者从政策与需求的连续变化理解，而非仅惊怪于钱粮耗尽。

**[《史记·平准书》P050](../../sources/摘录/史记-卷030-平准书.md#p050)**

> 太史公曰：農工商交易之路通，而龜貝金錢刀布之幣興焉。所從來久遠，自高辛氏之前尚矣，靡得而記云。故書道唐虞之際，詩述殷周之世，安寧則長庠序，先本絀末，以禮義防于利；事變多故而亦反是。是以物盛則衰，時極而轉，一質一文，終始之變也。禹貢九州，各因其土地所宜，人民所多少而納職焉。湯武承獘易變，使民不倦，各兢兢所以為治，而稍陵遲衰微。齊桓公用管仲之謀，通輕重之權，徼山海之業，以朝諸侯，用區區之齊顯成霸名。魏用李克，盡地力，為彊君。自是以後，天下爭於戰國，貴詐力而賤仁義，先富有而後推讓。故庶人之富者或累巨萬，而貧者或不厭糟糠；有國彊者或并群小以臣諸侯，而弱國或絕祀而滅世。以至於秦，卒并海內。虞夏之幣，金為三品，或黃，或白，或赤；或錢，或布，或刀，或龜貝。及至秦，中一國之幣為（三）［二］等，黃金以溢名，為上幣；銅錢識曰半兩，重如其文，為下幣。而珠玉、龜貝、銀錫之屬為器飾寶藏，不為幣。然各隨時而輕重無常。於是外攘夷狄，內興功業，海內之士力耕不足糧馕，女子紡績不足衣服。古者嘗竭天下之資財以奉其上，猶自以為不足也。無異故云，事勢之流，相激使然，曷足怪焉。

这是篇末总论，不是前110年一次奏议；“李克”照底本，不静默改为食货志另见的“李悝”。秦币二／三等保留括校符号，不把金属名目直接转换成现代货币本位理论。

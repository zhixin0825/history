# 公元前110年｜大军北巡后登泰山，封禅并改元

[← 公元前111年](bce-0111.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前109年 →](bce-0109.md)

**汉武帝元封元年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补王国更替和朝见；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，跨年回叙不当成同年新事。

<a id="sj012-110-1"></a>
## 冬季北巡，先展示军威

**武帝率大军向北巡视朔方一带，经过黄帝冢所在的桥山，向匈奴展示军威。** 北巡及祭黄帝冢之后，转回甘泉，为泰山封禅作准备。有人解释说黄帝虽有墓却成仙，墓中只葬衣冠；这只是当时解释神话与墓葬冲突的说辞。

**不应把军事行军直接写成已经与匈奴决战获胜。** 本年是勒兵、威示与往返巡察，实际战事要依另卷记载。

**本段史料：** [卷012 P016](../../sources/摘录/史记-卷012-孝武本纪.md#p016)；[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)。《汉书》元封元年十月记北巡勒兵；本纪把祭黄帝冢接在封禅的准备过程。

<a id="sj012-110-2"></a>
## 礼制争论未决，皇帝自己决定怎么封禅

**武帝邀请儒生和方士讨论封禅，却发现各家礼节互不相同。** 儒生引经据典，方士谈黄帝得仙，朝廷甚至练习射牛等礼仪。皇帝嫌建议矛盾、无法执行，最后罢去许多儒生拟议，自己择用一部分程序。

**先到嵩高礼祭，继往泰山、海上。** 随从声称听到山中呼万岁，因而封三百户为崇高邑奉祀；海边寻找仙人毫无确证，公孙卿说见巨人脚印，皇帝仍继续派人找。

**本段史料：** [卷012 P016](../../sources/摘录/史记-卷012-孝武本纪.md#p016)、[卷012 P017](../../sources/摘录/史记-卷012-孝武本纪.md#p017)；[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)。「万岁声」「巨人迹」明确作随从和方士陈述，不作史书已证异象。

<a id="sj012-110-3"></a>
## 四月封泰山、禅肃然山

**四月到奉高，武帝先在泰山下东侧依礼设封，再与侍中奉车子侯上山，山顶仪式高度保密；次日在肃然山举行禅礼。** 封禅是祀天祀地相联系的典礼，不是普通的郊游，也不代表儒臣最初所有方案都被采纳。

**回来以后，皇帝下诏赦罪、赐牛酒、优待高龄孤寡，并免除部分所经县当年租税。** 礼毕还继续沿海北巡，奉车子侯在途中突然死亡。武帝随后把此年定为元封元年，官员以得鼎和封禅解释年号。封禅叙述中的光云属当时报告，不可改作现代确认的天气神迹。

**本段史料：** [卷012 P018](../../sources/摘录/史记-卷012-孝武本纪.md#p018)；[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)。《汉书》元封元年四月与诏令有互见，奖赏适用对象及范围据两书保留差异；不同于从此天下全免税。

<a id="sj012-110-4"></a>
## 当年秋季有天象报道

**秋天有人观察到彗状星体，记录其经过东井与三台一带。** 朝廷望气者有人把它解释成皇帝封禅获得「德星」回应。天象报告和政治解释须分层；不能从祝辞中直接推出真实的天体性质或祸福。

**本段史料：** [卷012 P019](../../sources/摘录/史记-卷012-孝武本纪.md#p019)；[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)。本纪的「茀」与《汉书》元封元年彗星互见；星官名词按史料保留。

<a id="sj017-qi"></a>
## 齐王刘闳去世，封国没有继承人

**武帝的儿子刘闳去世，齐国因无后而被撤销。** 他在前117年与刘旦、刘胥一同受封，只在位八年。这里结束的是武帝之子的齐国，前127年旧齐王刘次昌的终局已经过去十余年，不可合为同一位齐王。[原文与说明](#sj017-note)

<a id="sj017-zhongshan"></a>
**中山王刘昆侈开始记元年。** 本页沿汉书王表安排；史记表提前一年，其父刘昌在位长短也有差别，见前两年相关注，不重复继位。

<a id="sj017-audience"></a>
**城阳王刘义、真定王刘平本年入朝。** 年表没有把地点具体写作泰山，不能仅因为皇帝同年封禅，就断定他们在山顶参加秘密仪式。[原文与说明](#sj017-note)

## 军政、受封与侯国的接续

<a id="sj020-e108"></a>
### 东越内部分裂，余善被杀

汉军进攻东越时，当地王侯、将领的选择不一。繇王居服与吴阳、原建成侯合作，杀死余善归汉；多军弃军投降。汉军士卒辕终古斩东越徇北将军，黄同则因斩西于王而立功。每项战功对应不同对象，不能把各行“斩余善”都当成独立的一次处死。 [原文与说明](#sj020-e108-n)

<a id="sj020-e109"></a>
### 韩说复封按道侯

韩说先前因酎金失爵，今因横海军讨东越的功劳，再封按道侯。新爵并非龙额爵从未中断的继续。 [原文与说明](#sj020-e109-n)

<a id="sj020-e110"></a>
### 吴阳封外石侯

吴阳原是东越衍侯，协助繇王杀余善，获汉廷外石侯爵。 [原文与说明](#sj020-e110-n)

<a id="sj020-e111"></a>
### 黄同封下鄜侯

原瓯骆左将黄同因斩西于王受封下鄜侯。 [原文与说明](#sj020-e111-n)

<a id="sj020-e112"></a>
### 刘福封缭嫈侯

校尉刘福随韩说讨东越立功，受封缭嫈侯。 [原文与说明](#sj020-e112-n)

<a id="sj020-e113"></a>
### 辕终古封蓹儿侯

士卒辕终古斩东越徇北将军，凭战功从军中进入列侯行列。 [原文与说明](#sj020-e113-n)

<a id="sj020-e114"></a>
### 原东越建成侯改受开陵侯

与繇王合作杀余善的建成侯，获得汉廷开陵侯爵。 [原文与说明](#sj020-e114-n)

<a id="sj020-e115"></a>
### 孙都因捕吕嘉封临蔡侯

孙都原在南越为郎，因前一年番禺失守后参与捕得吕嘉，本年受封临蔡侯。 [原文与说明](#sj020-e115-n)

<a id="sj020-e116"></a>
### 居服封东成侯

繇王居服因杀余善归汉，受封东成侯一万户。 [原文与说明](#sj020-e116-n)

<a id="sj020-e117"></a>
### 多军封无锡侯

东越将军多军放弃所部、向汉归降，受封无锡侯。 [原文与说明](#sj020-e117-n)

<a id="sj020-e118"></a>
### 嘉因父亲归附封涉都侯

嘉因父亲此前交城归附而受封涉都侯。父亲弃曾任南海守，在汉军抵达时率城邑归附；这项行动不移写成儿子亲自完成。 [原文与说明](#sj020-e118-n)

**嘉因父亲归附封涉都侯：** [R065 涉都](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r065)。汉表子名喜，本表嘉；“父弃”按人名与官职分读，不译成父亲抛弃南海太守职位。原表只明确儿子元封元年受封，父亲交城属此前南越战争的背景，不能由子受封年反定父亲同年归附。 互校：[漢書/卷017](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7017) · [史記/卷113](https://zh.wikisource.org/wiki/%E5%8F%B2%E8%A8%98/%E5%8D%B7113)。

<a id="sj020-e142-n"></a>
**霍嬗的终局互见：** [R023 冠軍](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r023)。本页泰山巡行的奉车子侯即霍嬗。史表元鼎栏六加元封元年终局，从前116至前110年含首尾为7，可与[《汉书·外戚恩泽侯表》](https://zh.wikisource.org/wiki/漢書/卷018)七年薨相接。数字可解释不代表出生年已知；本纪同事不再另记一次死亡，也不以暴病作现代医学诊断。 互校：[史記/卷111](https://zh.wikisource.org/wiki/%E5%8F%B2%E8%A8%98/%E5%8D%B7111)。

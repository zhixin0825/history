# 公元前111年｜南越平定，南方祭法与乐舞进入汉廷

[← 公元前112年](bce-0112.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前110年 →](bce-0110.md)

**汉武帝元鼎六年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补诸侯来朝与王统互见；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，跨年回叙不当成同年新事。

<a id="sj012-111-1"></a>
<a id="南越局势改变以后宫廷又吸收新祭法"></a>

<a id="event-1"></a>

1. **南越局势改变以后，宫廷又吸收新祭法。** 汉军平定南越，朝廷在原有政权区域置郡。 南越人勇之称越俗祭鬼灵验，武帝因此允许越巫设越祝祠，并采用鸡卜等办法。这些是新纳入汉廷的祭祀实践，不能把勇之声称的「先王活到一百六十岁」作为已核实的寿命。 [[1]](#note-1)

<a id="event-2"></a>

   **归年说明：**《孝武本纪》用“是时既灭南越”交代背景，没有给勇之建议的确切月日；本页承接灭南越后叙事，不据此断定这项祭祀必在本年正式建立。


2. **李延年又凭音乐受到皇帝注意。** 宫廷认为祭天地也应有乐，遂增设歌舞，制作或改用箜篌、瑟等器物，祭礼声势扩大。卷十二将它们紧接在南越平定后，不能说南越人直接发明了所有这些乐器。 [[2]](#note-2)

   《汉书》元鼎六年记南越平定；《孝武本纪》卷012写李延年、越祝为相近阶段，具体月日未核定。

<a id="sj012-111-2"></a>
<a id="公孙卿又以仙人足迹解释没有见到仙人"></a>

<a id="event-3"></a>

3. **公孙卿又以仙人足迹解释没有见到仙人。** 公孙卿称在缑氏城发现神人的脚印，皇帝亲往查看。 武帝曾问他会不会像少翁、栾大一样骗人；公孙卿却说仙人本来不求皇帝，皇帝要多等几年。各郡国因而修治道路、宫观和祠庙迎驾。 [[3]](#note-3)

   这段在传本写作先后、具体年次上有回叙，暂作为通向元封东巡的前情，不将其每次对话系于前111年的某个月。

   以《汉书》元封元年的缑氏、嵩高巡礼互参，不能据卷012相邻文本机械定月。

4. **济北王刘胡、六安王刘庆来到朝廷。** 刘庆是胶东王刘寄之子，六安又是一支另封王国，不是已经被撤销的刘安淮南国照原样恢复。[原格与说明](#sj017-note) [[4]](#note-4)

5. **中山王刘昌的短暂在位结束。** 刘昌去世，儿子刘昆侈承接中山。 本页采用汉书王表的两年在位安排，把死亡归在本年，刘昆侈元年接下一年。史记另有早一年的次序，明确留在注中，不把两套日期拼成两次死亡。[原格与说明](#sj017-note) [[5]](#note-5)

<a id="event-6"></a>

6. **番禺失守，南越的统治结束。** 汉军攻破番禺，南越王建德和相吕嘉出逃后被捕。路博德、杨仆分别统领伏波、楼船军；苏弘捕得建德，原南越郎孙都参与取得吕嘉。南越内部也有将领、地方官与王族转向汉方，战胜、捕获和归附共同成为封侯理由。 杨仆先破寻陕、石门并攻番禺东南面，路博德在西北布营、用印招降，天亮城中降汉。建德和吕嘉夜间乘船西逃，随后被追获。 零陵与夜郎方向的几路军队尚未抵达，朝廷已经平定南越，随后分置九郡。 [[6]](#note-6)

10. **赵光封随桃侯。** 南越苍梧王赵光向汉归附，获得随桃侯爵。 [[10]](#note-10)

13. **雲侯爵由后人接续。** 刘歲發接续雲侯爵，侯统进入新的一代。 [[13]](#note-13)



<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-15"></a>

14. **卜式出任御史大夫。** 东越举兵与汉军出师见[本年东越条](#sj114-p006)。 他在任内批评官营铁器价高、质差和强卖，以及船算妨碍商运；武帝对此不悦，次年改任太子太傅。 [[14]](#note-15)

<a id="sj029-six-aux-event"></a>

15. **儿宽提议开六辅渠，灌溉郑国渠旁较高处的田地。** 《汉书·沟洫志》把这件事明确放在元鼎六年。皇帝以农业为根本，要求利用沟渠、陂泽备旱，并议减内史稻田过重的租额。本年记的是提议与诏令，不添一条没有记载的竣工日。 [[15]](#sj029-six-aux-note)

<a id="sj110-event-16"></a>

16. **公孙贺、赵破奴分道出塞，均未接敌。** 平南越后，汉遣公孙贺从九原向浮苴井、赵破奴由令居向匈河水推进，两路均未遇匈奴即撤回。 [[16]](#note-16)

<a id="sj114-event-17"></a>

17. **余善举兵，武帝遣诸军讨东越。** 番禺失守后，杨仆请转兵东越，武帝起先不许，命各校留屯。余善得知汉军留在境旁后举兵攻杀汉官，刻武帝玺自立。武帝命韩说、杨仆、王温舒等分路讨伐。 《通鉴》卷二十记王溫舒从梅嶺出兵，所击为余善东越。 [[17]](#note-17)

<a id="sj116-event-18"></a>

18. **汉军转平且兰，置牂柯郡并封夜郎王。** 南越已平，原拟赴南越的八校回师，汉在南夷置牂柯郡。夜郎侯入朝获封为王；随后所见另有越嶲、沈犂、汶山、武都诸郡。 [[18]](#note-18)

> 漢連兵三歲，誅羌，滅南越，番禺以西至蜀南者置初郡十七，且以其故俗治，毋賦稅。南陽、漢中以往郡，各以地比給初郡吏卒奉食幣物，傳車馬被具。而初郡時時小反，殺吏，漢發南方吏卒往誅之，閒歲萬餘人，費皆仰給大農。大農以均輸調鹽鐵助賦，故能贍之。然兵所過縣，為以訾給毋乏而已，不敢言擅賦法矣。

新郡十七是跨年前后总叙，不能把南越、西南及东越各阶段一并算作本年新置；不赋新郡与内地负担供养并存。

### 6. 番禺失守，南越的统治结束

**[《史记·南越尉佗列传》P010](../../sources/摘录/史记-卷113-南越尉佗列传.md#p010)** · [三家注](../../sources/史记三家注/卷113.md#p10)

> 元鼎六年冬，樓船將軍將精卒先陷尋陝，破石門，得越船粟，因推而前，挫越鋒，以數萬人待伏波。伏波將軍將罪人，道遠，會期後，與樓船會乃有千餘人，遂俱進。樓船居前，至番禺。建德、嘉皆城守。樓船自擇便處，居東南面；伏波居西北面。會暮，樓船攻敗越人，縱火燒城。越素聞伏波名，日暮，不知其兵多少。伏波乃爲營，遣使者招降者，賜印，復縱令相招。樓船力攻燒敵，反驅而入伏波營中。犂旦，城中皆降伏波。呂嘉、建德已夜與其屬數百人亡入海，以船西去。伏波又因問所得降者貴人，以知呂嘉所之，遣人追之。以其故校尉司馬蘇弘得建德，封爲海常侯；越郎都稽得嘉，封爲臨蔡侯。

**本卷归年说明：** 年号传统配年前111；秦汉以十月为岁首，对应现代历法的年号段并不等同同号公元年。本传连记捕获、封爵，捕吕嘉在本年；临蔡侯正式封爵前110另有侯表纪日。

[卷017前111年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0111)济北四十一、六安十一来朝，中山已经记“康王昆侈元年”；[汉书诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7014.md#ref-a87f53b85abf3a)则将刘昌元鼎五年起二年薨、刘昆侈元封元年起算，故本轮采用前112—111年刘昌、前110年刘昆侈的连续线。原因是汉表对前后两代起讫都给出年号，与史记“一年／即年薨”分歧明确；不是宣称已完成所有版本校勘。史记原格仍见[前112年注](bce-0112.md#sj017-note)，继王记在[前110年](bce-0110.md#sj017-zhongshan)。

《天官书》[P120](../../sources/摘录/史记-卷027-天官书.md#p120)概述“越之亡，熒惑守鬬”。《汉书·天文志》作“元鼎中，熒惑守南斗”，下接吕嘉杀王及太后、汉军灭其国（[互校H007](../../sources/摘录/史记-卷027-纪年互校.md#h007)），据此把“越”先与本页南越终局互见，不将之直接改成东越。天象仅有“元鼎中”的范围，不能因战争终局在本年就把守斗观测定在本年；原字“鬬”与三家注本“斗”分层保留。

# 公元前111年｜南越平定，南方祭法与乐舞进入汉廷

[← 公元前112年](bce-0112.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前110年 →](bce-0110.md)

**汉武帝元鼎六年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补诸侯来朝与王统互见；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，跨年回叙不当成同年新事。

<a id="南越局势改变以后宫廷又吸收新祭法"></a>

<a id="event-1"></a>

1. **南越局势改变以后，宫廷又吸收新祭法。** 汉军平定南越，朝廷在原有政权区域置郡。 南越人勇之称越俗祭鬼灵验，武帝因此允许越巫设越祝祠，并采用鸡卜等办法。这些是新纳入汉廷的祭祀实践，不能把勇之声称的「先王活到一百六十岁」作为已核实的寿命。 [[1]](#note-1)

<a id="event-2"></a>

   **归年说明：**《孝武本纪》用“是时既灭南越”交代背景，没有给勇之建议的确切月日；本页承接灭南越后叙事，不据此断定这项祭祀必在本年正式建立。


2. **李延年又凭音乐受到皇帝注意。** 宫廷认为祭天地也应有乐，遂增设歌舞，制作或改用箜篌、瑟等器物，祭礼声势扩大。卷十二将它们紧接在南越平定后，不能说南越人直接发明了所有这些乐器。 [[2]](#note-2)

   《汉书》元鼎六年记南越平定；《孝武本纪》卷012写李延年、越祝为相近阶段，具体月日未核定。

<a id="sj012-111-2"></a>
<a id="公孙卿又以仙人足迹解释没有见到仙人"></a>

<a id="event-3"></a>

3. **公孙卿又以仙人足迹解释没有见到仙人。** 公孙卿称在缑氏城发现神人的脚印，皇帝亲往查看。 武帝曾问他会不会像少翁、栾大一样骗人；公孙卿却说仙人本来不求皇帝，皇帝要多等几年。各郡国因而修治道路、宫观和祠庙迎驾。 [[3]](#note-3)

   这段在传本写作先后、具体年次上有回叙，暂作为通向元封东巡的前情，不将其每次对话系于前111年的某个月。

   以《汉书》元封元年的缑氏、嵩高巡礼互参，不能据卷012相邻文本机械定月。

6. **番禺失守，南越的统治结束。** 汉军攻破番禺，南越王建德和相吕嘉出逃后被捕。路博德、杨仆分别统领伏波、楼船军；苏弘捕得建德，原南越郎孙都参与取得吕嘉。南越内部也有将领、地方官与王族转向汉方，战胜、捕获和归附共同成为封侯理由。 杨仆先破寻陕、石门并攻番禺东南面，路博德在西北布营、用印招降，天亮城中降汉。建德和吕嘉夜间乘船西逃，随后被追获。 零陵与夜郎方向的几路军队尚未抵达，朝廷已经平定南越，本纪随后总列九郡，其中儋耳、珠崖的专门系年见[前110年《地理志》条](bce-0110.md#hs028-l6092-e52)。 楼船军先陷寻陕、破石门，后伏波与楼船两军会围番禺。夜间火攻和招降后，吕嘉、赵建德退入海上而被擒。 [[6]](#note-6)

<a id="sj114-event-17"></a>

17. **余善举兵，武帝遣诸军讨东越。** 番禺失守后，杨仆请转兵东越，武帝起先不许，命各校留屯。余善得知汉军留在境旁后举兵攻杀汉官，刻武帝玺自立。武帝命韩说、杨仆、王温舒等分路讨伐。 《通鉴》卷二十记王溫舒从梅嶺出兵，所击为余善东越。 [[17]](#note-17)

<a id="sj116-event-18"></a>

18. **汉军转平且兰，置牂柯郡并封夜郎王。** 南越已平，原拟赴南越的八校回师，汉在南夷置牂柯郡。夜郎侯入朝获封为王；随后所见另有越嶲、沈犂、汶山、武都诸郡。 南越平后，汉军从会军计划中转击且兰；邛、莋与冉駹等营置由此展开。 [[18]](#note-18)

> 是時既滅南越，越人勇之乃言「越人俗信鬼，而其祠皆見鬼，數有效。昔東甌王敬鬼，壽至百六十歲。後世謾怠，故衰秏」。乃令越巫立越祝祠，安臺無壇，亦祠天神上帝百鬼，而以雞卜。上信之，越祠雞卜始用焉。

**卷030补证**

**[《史记·平准书》P046](../../sources/摘录/史记-卷030-平准书.md#p046)**

> 漢連兵三歲，誅羌，滅南越，番禺以西至蜀南者置初郡十七，且以其故俗治，毋賦稅。南陽、漢中以往郡，各以地比給初郡吏卒奉食幣物，傳車馬被具。而初郡時時小反，殺吏，漢發南方吏卒往誅之，閒歲萬餘人，費皆仰給大農。大農以均輸調鹽鐵助賦，故能贍之。然兵所過縣，為以訾給毋乏而已，不敢言擅賦法矣。

新郡十七是跨年前后总叙，不能把南越、西南及东越各阶段一并算作本年新置；不赋新郡与内地负担供养并存。

#### 卷022｜将相表互见与异说

**原行四栏：** 大事：十二月，東越反。；相位：二；将位：故龍镪侯韓說為橫海將軍，出會稽；樓船將軍楊僕出豫章；中尉王溫舒出會稽：皆破東越。；御史：御史大夫式。

互校：[《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0111) · [《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-cf366ffc448aaf) · [卷022纪年与异说](../../meta/考证/史记-卷022-纪年与异说.md)。原表数字与空栏照存，未作独立古历日换算。

# 公元前111年｜南越平定，南方祭法与乐舞进入汉廷

[← 公元前112年](bce-0112.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前110年 →](bce-0110.md)

**汉武帝元鼎六年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补诸侯来朝与王统互见；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，跨年回叙不当成同年新事。

<a id="sj012-111-1"></a>
## 南越局势改变以后，宫廷又吸收新祭法

**汉军平定南越，朝廷在原有政权区域置郡。** 南越人勇之称越俗祭鬼灵验，武帝因此允许越巫设越祝祠，并采用鸡卜等办法。这些是新纳入汉廷的祭祀实践，不能把勇之声称的「先王活到一百六十岁」作为已核实的寿命。

**李延年又凭音乐受到皇帝注意。** 宫廷认为祭天地也应有乐，遂增设歌舞，制作或改用箜篌、瑟等器物，祭礼声势扩大。卷十二将它们紧接在南越平定后，不能说南越人直接发明了所有这些乐器。

**本段史料：** [卷012 P015](../../sources/摘录/史记-卷012-孝武本纪.md#p015)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-0f9fcb307ef982)。《汉书》元鼎六年记南越平定；《孝武本纪》卷012写李延年、越祝为相近阶段，具体月日未核定。

<a id="sj012-111-2"></a>
## 公孙卿又以仙人足迹解释没有见到仙人

**公孙卿称在缑氏城发现神人的脚印，皇帝亲往查看。** 武帝曾问他会不会像少翁、栾大一样骗人；公孙卿却说仙人本来不求皇帝，皇帝要多等几年。各郡国因而修治道路、宫观和祠庙迎驾。

这段在传本写作先后、具体年次上有回叙，暂作为通向元封东巡的前情，不将其每次对话系于前111年的某个月。

**本段史料：** [卷012 P015](../../sources/摘录/史记-卷012-孝武本纪.md#p015)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-2100d719f1f9dc)。以《汉书》元封元年的缑氏、嵩高巡礼互参，不能据卷012相邻文本机械定月。

<a id="sj017-audience"></a>
## 济北、六安两王入朝

**济北王刘胡、六安王刘庆来到朝廷。** 刘庆是胶东王刘寄之子，六安又是一支另封王国，不是已经被撤销的刘安淮南国照原样恢复。[原格与说明](#sj017-note)

<a id="sj017-zhongshan"></a>
## 中山王刘昌的短暂在位结束

**刘昌去世，儿子刘昆侈承接中山。** 本页采用汉书王表的两年在位安排，把死亡归在本年，刘昆侈元年接下一年。史记另有早一年的次序，明确留在注中，不把两套日期拼成两次死亡。[原格与说明](#sj017-note)

<a id="sj017-note"></a>
[卷017前111年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0111)济北四十一、六安十一来朝，中山已经记“康王昆侈元年”；[汉书诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7014.md#ref-a87f53b85abf3a)则将刘昌元鼎五年起二年薨、刘昆侈元封元年起算，故本轮采用前112—111年刘昌、前110年刘昆侈的连续线。原因是汉表对前后两代起讫都给出年号，与史记“一年／即年薨”分歧明确；不是宣称已完成所有版本校勘。史记原格仍见[前112年注](bce-0112.md#sj017-note)，继王记在[前110年](bce-0110.md#sj017-zhongshan)。

## 军政、受封与侯国的接续

<a id="sj020-e099"></a>
### 番禺失守，南越的统治结束

汉军攻破番禺，南越王建德和相吕嘉出逃后被捕。路博德、杨仆分别统领伏波、楼船军；苏弘捕得建德，原南越郎孙都参与取得吕嘉。南越内部也有将领、地方官与王族转向汉方，战胜、捕获和归附共同成为封侯理由。 [原文与说明](#sj020-e099-n)

<a id="sj020-e100"></a>
### 毕取封膫侯

南越将毕取归汉，受封膫侯。 [原文与说明](#sj020-e100-n)

<a id="sj020-e101"></a>
### 杨仆封将梁侯

楼船将军杨仆在攻南越时冲击敌阵、迫退对方，因功封将梁侯。 [原文与说明](#sj020-e101-n)

<a id="sj020-e102"></a>
### 史定封安道侯

揭阳令史定得知汉军到来，控制本地后归附，受封安道侯。 [原文与说明](#sj020-e102-n)

<a id="sj020-e103"></a>
### 赵光封随桃侯

南越苍梧王赵光向汉归附，获得随桃侯爵。 [原文与说明](#sj020-e103-n)

<a id="sj020-e104"></a>
### 监居翁封湘成侯

桂林监居翁在番禺失守后，劝说瓯骆部众归附，因功封湘成侯。 [原文与说明](#sj020-e104-n)

<a id="sj020-e105"></a>
### 苏弘封海常侯

苏弘以伏波军司马捕得南越王建德，受封海常侯。 [原文与说明](#sj020-e105-n)

# 公元前112年｜甘泉祭泰一，栾大终因诳惑被诛

[← 公元前113年](bce-0113.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前111年 →](bce-0111.md)

**汉武帝元鼎五年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补王国纪年；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，跨年回叙不当成同年新事。

<a id="sj012-112-1"></a>
<a id="冬至亲祀泰一祭天礼仪重新排序"></a>

<a id="event-1"></a>

1. **冬至亲祀泰一，祭天礼仪重新排序。** 冬十一月辛巳朔旦冬至，武帝在甘泉正式亲祭泰一。 泰一坛居上、五帝坛在周围，祭日月和诸神各有牲品、方位、祝辞与服色；祠官把宝鼎和天文历数写进祝词，称天命循环、皇帝奉天受命。 [[1]](#note-1)

<a id="event-2"></a>

2. **原先分散的方士建议，至此成为由国家投入人力财物的公开礼仪。** 部分官员声称祭坛有光、有黄气升天，史事可以确认为官员这样报告，不能据此说神灵经科学证实出现。 [[2]](#note-2)

   本纪日干支“辛已”与《汉书》辛巳校读；古历十一月冬至不等于现代同号公历年份的一天。

<a id="sj012-112-2"></a>
<a id="准备征南越同时揭穿栾大的说法"></a>

<a id="event-3"></a>

3. **准备征南越，同时揭穿栾大的说法。** 南越边事日渐紧张，朝廷祭旗祈战，把日月、北斗和升龙画到灵旗上。 同时，栾大寻访师父的种种说法逐渐露出破绽。朝廷派人暗中跟随，发现他并未见到所称仙人，便将他处死。 [[3]](#note-3)

<a id="event-4"></a>

4. **军事祈祷与实际军事行动要分开。** 这一年南越王相吕嘉举兵，汉军发动征讨；南越被平定是下一年的事。 汉廷命伏波将军路博德从桂阳、楼船将军杨仆从豫章进兵。 另有两名归义越侯从零陵出发，驰义侯调发夜郎兵循牂柯江东下，约会于番禺。 东越王余善请出八千人从征，却停兵揭扬，暗中联络南越。 这次征发引起且兰反抗，汉使与犍为太守被杀。 [[4]](#note-4)

   《汉书》元鼎五年九月“欒大坐誣罔要斬”，战事结局在元鼎六年。

<a id="sj017-zhongshan"></a>
<a id="中山开始刘昌元年"></a>

<a id="event-5"></a>

5. **中山开始刘昌元年。** 刘昌接续刘胜，进入新的在位纪年。 父亲的去世已在[前113年二月](bce-0113.md#sj017-zhongshan)，不是本年另一场死亡。刘昌这一代延续时间很短，但具体卒年在两种年表中不同，不能用其中一种元年任意倒推另一种年数。 [[5]](#note-5)

<a id="sj017-audience"></a>

<a id="event-6"></a>

6. **广川王刘齐本年入朝。** 表只载来朝，不把他加入甘泉祭泰一、栾大案或南越军事的具体决策。 [[6]](#note-6)

10. **酎金检查使一批旧侯失爵。** 公孙贺的南奅、韩说的龙额、卫不疑的阴安、卫登的发干、赵破奴的从骠、敞屠洛的湘成，以及次公的膫侯，都在酎金检查中被撤销。失去侯国并不等于当场处死；其中几人后来还会复封。 [[10]](#note-10)

<a id="sj020-e088"></a>
<a id="南越内变韩千秋与摎乐死事"></a>

<a id="event-11"></a>

11. **南越内变，韩千秋与摎乐死事。** 南越内附汉廷的安排引起冲突，吕嘉等杀死国王、太后与汉使，拥立术阳侯建德为王。 汉派去的韩千秋所部败没，韩千秋、摎乐死事；他们的儿子随后因父功受封。 武帝原拟派庄参，庄参说若讲和几人就够，若用兵二千不足。韩千秋与樛乐率军入越，吕嘉拥立赵建德后，南越军在离番禺不远处击灭这支前军。 汉廷命楊僕为楼船将军，征讨南越。 [[11]](#note-11)

<a id="sj020-e089"></a>
<a id="摎广德承父功封龙亢侯"></a>


<a id="event-12"></a>

12. **摎广德承父功封龙亢侯。** 广德因父亲摎乐击南越而死的功劳，受封龙亢侯。领兵战死的是父亲，儿子的爵位属于对家属的报偿。 [[12]](#note-12)

<a id="sj020-e090"></a>
<a id="韩延年承父功封成安侯"></a>


<a id="event-13"></a>

13. **韩延年承父功封成安侯。** 韩千秋之子延年受封成安侯，原因同样是父亲在对南越行动中死事，而非儿子重打一场相同的仗。 [[13]](#note-13)

#### 卷024｜音乐史事的互见与归年

[卷024 P006](../../sources/摘录/史记-卷024-乐书.md#p006)保存甘泉太一经常祭仪：正月上辛、自昏至明、僮男女七十人歌唱，并列春青阳、夏朱明、秋西暤、冬玄冥。此处与[本页冬十一月冬至亲祀泰一](#sj012-112-1)互见，但“正月上辛”的常仪不等于该次十一月朔旦冬至之日，不能挪到同一天。

[《汉书·礼乐志》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7022.md#ref-c21c9b4b0e79ce)也记甘泉上辛、七十人俱歌及昏祠至明，所列四时歌第三至第六篇有西顥等异字；《乐书》原字照存。祭坛流星、神光保留为当时所记的祠祀景象和瑞应解释。十九章与李延年编乐的跨年范围另见[前140年注](bce-0140.md#sj024-note)。

<a id="sj030-tour-frontiers"></a>

### 巡行筹供、边郡与借养马的跨年安排

河东、陇西、萧关巡行及后土、太一、封禅筹备并非同年一趟；主线仍按各本纪及已有年页分开。

以下为跨年背景或篇末评论，不计作本年新发生的编号事件。

<a id="sj030-tour-frontiers-p041"></a>

**巡行、地方供给与边地借养马**

皇帝巡郡国时，有太守因突然接驾、无法供应而自杀，北地官员又因新秦中缺少亭候守备受惩。随后鼓励百姓在边县畜牧，官府借出母马，约三年归还并按所生马匹的一成缴纳，同时给予免受告缗追究等优惠，以充实新秦中。

**[《史记·平准书》P041](../../sources/摘录/史记-卷030-平准书.md#p041)**

> 其明年，天子始巡郡國。東度河，河東守不意行至，不辨，自殺。行西踰隴，隴西守以行往卒，天子從官不得食，隴西守自殺。於是上北出蕭關，從數萬騎，獵新秦中，以勒邊兵而歸。新秦中或千里無亭徼，於是誅北地太守以下，而令民得畜牧邊縣，官假馬母，三歲而歸，及息什一，以除告緡，用充仞新秦中。

本卷把河东、陇西、萧关串叙；帝纪的巡行跨前113、112年，不能强造一条同日路线。三岁、息什一是借养安排，不称为年息10%的普通现金贷款。

<a id="sj030-tour-frontiers-p042"></a>

**封禅筹备的地方负担**

取得宝鼎、建立后土与太一祭祠以后，公卿讨论封禅，各郡国预先整治道路桥梁、修旧宫；驰道沿县准备官储和供具，等候皇帝可能到来。

**[《史记·平准书》P042](../../sources/摘录/史记-卷030-平准书.md#p042)**

> 既得寶鼎，立后土、太一祠，公卿議封禪事，而天下郡國皆豫治道橋，繕故宮，及當馳道縣，縣治官儲，設供具，而望以待幸。

后土、太一与得鼎各有分年条，前113、112年至110年逐步推进；本段记地方准备的扩散，不把“等待巡幸”改成皇帝确已走遍所有准备地区。

<a id="sj030-tour-frontiers-p043"></a>

**南越、西羌、屯田与供马**

南越反叛、西羌侵边时，朝廷动员大批南方楼船卒、三河以西骑兵，又派人过河筑令居，开设边郡田官，征发戍卒耕守。修路运粮远达数千里，都要大农供应。兵器不足便发武库、工官储备；军马短缺、政府又缺钱，便令封君和一定秩级以上官员按差等向亭供应马匹，按年检查繁殖。

**[《史记·平准书》P043](../../sources/摘录/史记-卷030-平准书.md#p043)**

> 其明年，南越反，西羌侵邊為桀。於是天子為山東不贍，赦天下［囚］，因南方樓船卒二十餘萬人擊南越，數萬人發三河以西騎擊西羌，又數萬人度河筑令居。初置張掖、酒泉郡，而上郡、朔方、西河、河西開田官，斥塞卒六十萬人戍田之。中國繕道餽糧，遠者三千，近者千餘里，皆仰給大農。邊兵不足，乃發武庫工官兵器以贍之。車騎馬乏絕，縣官錢少，買馬難得，乃著令，令封君以下至三百石以上吏，以差出牝馬天下亭，亭有畜牸馬，歲課息。

本段涉及前112—111年及前后边郡建设，不能把张掖、酒泉所有置郡说统一为一次；六十万是书中边屯规模概述，不并入单路攻南越军数。《史记》牝马与汉志牡马异字影响繁殖制度解释，分别保留。

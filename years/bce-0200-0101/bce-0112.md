# 公元前112年｜甘泉祭泰一，栾大终因诳惑被诛

[← 公元前113年](bce-0113.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前111年 →](bce-0111.md)

**汉武帝元鼎五年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补王国纪年；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，跨年回叙不当成同年新事。

<a id="sj012-112-1"></a>
## 冬至亲祀泰一，祭天礼仪重新排序

**冬十一月辛巳朔旦冬至，武帝在甘泉正式亲祭泰一。** 泰一坛居上、五帝坛在周围，祭日月和诸神各有牲品、方位、祝辞与服色；祠官把宝鼎和天文历数写进祝词，称天命循环、皇帝奉天受命。

**原先分散的方士建议，至此成为由国家投入人力财物的公开礼仪。** 部分官员声称祭坛有光、有黄气升天，史事可以确认为官员这样报告，不能据此说神灵经科学证实出现。

**本段史料：** [卷012 P014](../../sources/摘录/史记-卷012-孝武本纪.md#p014)；[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)。本纪日干支“辛已”与《汉书》辛巳校读；古历十一月冬至不等于现代同号公历年份的一天。

<a id="sj012-112-2"></a>
## 准备征南越，同时揭穿栾大的说法

**南越边事日渐紧张，朝廷祭旗祈战，把日月、北斗和升龙画到灵旗上。** 同时，栾大寻访师父的种种说法逐渐露出破绽。朝廷派人暗中跟随，发现他并未见到所称仙人，便将他处死。

**军事祈祷与实际军事行动要分开。** 这一年南越王相吕嘉举兵，汉军发动征讨；南越被平定是下一年的事。

**本段史料：** [卷012 P015](../../sources/摘录/史记-卷012-孝武本纪.md#p015)；[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)。《汉书》元鼎五年九月“欒大坐誣罔要斬”，战事结局在元鼎六年。

<a id="sj017-zhongshan"></a>
## 中山开始刘昌元年

**刘昌接续刘胜，进入新的在位纪年。** 父亲的去世已在[前113年二月](bce-0113.md#sj017-zhongshan)，不是本年另一场死亡。刘昌这一代延续时间很短，但具体卒年在两种年表中不同，不能用其中一种元年任意倒推另一种年数。[原文与说明](#sj017-note)

<a id="sj017-audience"></a>
**广川王刘齐本年入朝。** 表只载来朝，不把他加入甘泉祭泰一、栾大案或南越军事的具体决策。[原文与说明](#sj017-note)

<a id="sj017-note"></a>
### 卷017｜刘昌与刘昆侈的一年差

[卷017前112年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0112)作“哀王昌元年，即年薨”，次年前111年记刘昆侈元年；[汉书诸侯王表](https://zh.wikisource.org/wiki/漢書/卷014)则记刘昌二年薨、刘昆侈元封元年即前110年始。本轮采用汉书的连续王统，刘昌之死承接[前111年](bce-0111.md#sj017-zhongshan)，刘昆侈元年在[前110年](bce-0110.md#sj017-zhongshan)；史记两格原文和世家“一年卒”的异说保留，不让刘昌死两次，也不宣称已证明是哪一版本抄错。

广川来朝同见本年原格。后谥哀王、康／穅王均不提前理解为本人受位时自称。

## 功臣后裔的承爵与失国

**九月，朝廷因列侯所献宗庙酎祭黄金不合规定，大批夺爵。** 《汉书·武帝纪》所报一百零六人，是当年被处理列侯的总记数，不仅指高祖功臣后裔。下列名单只列本卷可逐项定位的家族；它不是全国一百零六人的完整名册。[史料说明](#sj018-note)

**同年还发生了正常承爵、续封和别的刑案。** 戴侯蒙承爵、靳石封江邹，与酎金免侯不能混为一批；丁义失国则另有方士案件的背景。

本页按原格中明确年号、承袭次序及互见材料分别定位；未载月份的不补日期，元年也不一律倒推父亲死年。侯爵与所任中央官职不是同一继承关系。

**R017：** 元朔五年承、元鼎五年酎金免见两表。周坚、周亚夫都是周勃之子，但分支与封国不同，不能凭共同父系合并继承。

**R021：** 本行有显著年差：史表婴齐元光元年、山柎元光四年；汉表婴齐元光三年嗣、在位二十年，山柎元鼎四年嗣，次年因酎金免。本文暂采用汉表前132→113→112的连续世次，理由是明确承年与长任期能相互衔接；不是按书名或数量投票。史表前134、131两元年完整保留于源文及本注，不再各封一位同名侯。武儒／武虎为初侯异名。

**R028：** 汉表国名阳信、新侯名谈，史表作新阳、谭，按吕清／青一支的连续承袭相认；这里不是后来其他同封阳信者。

**R030：** 汁方／汁防为国名异写。原格“终侯”不证明雍桓本年死亡；有明确记录的是撤爵。

**R042：** 国名汉表作敬市；谷沿阎泽赤一支承袭辨认。失爵不是本年又初封。

**R051：** 元光六年则元年、元鼎五年酎金免沿两表。行首阿陵与后来的南侯是先后国号；本轮同时修正文帝栏误分类，郭欧文三年元年在史表本来就有，不是仅由汉表补出。

**R057：** 元鼎二年承、五年免。原行有历代军功和职官，不因唐尊继承便把唐厉的战功都算到他身上。

**R059：** 建元元年三月、元狩三年、元鼎五年依次为承爵、换代与免爵，不把末项带回最早的元年。“安侯”是辟方的后谥，不是他另封了一个安侯国。

**R060：** 丁义元鼎二年嗣、五年弃市见两表。史表“坐言五利侯不道”、汉表“坐为栾大言”用语不同；《孝武本纪》说明丁义是推荐栾大者。正文据此说明其言事与方士有关，不能颠倒成丁义揭发栾大反遭迫害，也不补不存在的言辞原文。五利是栾大所得称号之一，不另造一名与乐通侯无关的方士。

**R067：** 建元元年嗣、元鼎五年免。父系与侯国用于辨认同名者，不能与中山王一生接成一条履历。

**R077：** 吕德建元六年、宜成元光元年，两年之间换代不代表同一人改名；宜成／宜城为异写，元鼎五年免侯明确。

**R083：** 元狩二年、元鼎五年分别明载。史表在千秋以前写“不得，千秋父”，表示资料残缺，汉表另以安为前代；本文不凭旁边十二、七等数补出一个姓名、卒日俱全的中间侯。

**R086：** 石在汉表作古；元狩三年、元鼎四年、五年依次为两次承爵与免爵。清侯一支最初来自空中，不与王吸家清阳／清河侯合并。

**R093：** 这里的阏氏是侯国名，非匈奴后妃称号。冯遗的遗腹子身份属于前代，不可在本年重叙成刚出生便受免。

**R099：** 陆梁／陆量为异写；原行受长沙王节制的初封背景仍在前198年，不能据旧功状推定武帝时全部行政关系毫无变化。

**R105：** 睢／雎为异写。史表元鼎五年酎金除，所读汉表网页却作元狩五年，与该格的任期以及同批酎金记载不能全合；正文采用史表前112年，保存这一字差而不另造一次前118年免侯。不是因恰有大规模清洗，就把其他明确不在本年的案件全部移来凑数。

**R117：** 建元四年贤元年、元鼎五年失国。与吕后、刘章等政治往事没有仅凭同姓可建立的联系，未补家族支线。

**R124：** 史表舜元光五年，汉表元光二年，前任终根任期及后来的在位数也不全合；本轮暂取史表前130年起算，元鼎五年失国不变。单父圣／单右车等初侯异名已在初封注交代，不据“父”字拆出另一代。

**R129：** 元鼎四年何元年、五年免侯。初侯刘广是刘仲之子、刘濞之弟，不能把他们同名或同族的诸王逐一替代成本侯。

**R134：** 史表在则以后直接列广宗元光五年、元鼎元年酎金；汉表在两者之间列许周元光五年嗣三年、广宗元朔二年嗣十五年、元鼎五年免。本文暂采用汉表前130周→前127广宗→前112失国的完整世次，史表省去周及前116年免的异说保留，不另造第二位同名广宗。“壮／严”是国名异写。

**R136：** 刘申汉表作由，建元元年、元朔二年及元鼎五年分别记录。桃侯刘舍曾任丞相，但与开封侯陶舍家不同；因初侯获赐刘姓，这支也不能自动接成皇子一系。

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e070"></a>
### 下摩侯开始伊即轩一代

下摩侯爵由伊即轩接续，侯籍进入新一代。 [原文与说明](#sj020-e070-n)

<a id="sj020-e081"></a>
### 酎金检查使一批旧侯失爵

公孙贺的南奅、韩说的龙额、卫不疑的阴安、卫登的发干、赵破奴的从骠、敞屠洛的湘成，以及次公的膫侯，都在酎金检查中被撤销。失去侯国并不等于当场处死；其中几人后来还会复封。 [原文与说明](#sj020-e081-n)

<a id="sj020-e088"></a>
### 南越内变，韩千秋与摎乐死事

南越内附汉廷的安排引起冲突，吕嘉等杀死国王、太后与汉使，拥立术阳侯建德为王。汉派去的韩千秋所部败没，韩千秋、摎乐死事；他们的儿子随后因父功受封。 [原文与说明](#sj020-e088-n)

<a id="sj020-e089"></a>
### 摎广德承父功封龙亢侯

广德因父亲摎乐击南越而死的功劳，受封龙亢侯。领兵战死的是父亲，儿子的爵位属于对家属的报偿。 [原文与说明](#sj020-e089-n)

<a id="sj020-e090"></a>
### 韩延年承父功封成安侯

韩千秋之子延年受封成安侯，原因同样是父亲在对南越行动中死事，而非儿子重打一场相同的仗。 [原文与说明](#sj020-e090-n)

<a id="sj020-e093"></a>
### 渠复累封昆侯

属国大且渠渠复累参加对匈奴战争，因军功受封昆侯。 [原文与说明](#sj020-e093-n)

<a id="sj020-e094"></a>
### 驹几封骐侯

属国骑兵驹几参与捕获单于兄长的行动，因功封骐侯。 [原文与说明](#sj020-e094-n)

<a id="sj020-e095"></a>
### 任破胡封梁期侯

属国都尉任破胡间道出兵，捕获匈奴方面人员，因军功封梁期侯。 [原文与说明](#sj020-e095-n)

<a id="sj020-e096"></a>
### 石庆任丞相，封牧丘侯

石庆出任丞相，受封牧丘侯。受赏的理由既包括自己的职任，也提到父亲万石君石奋一家的谨慎德行。 [原文与说明](#sj020-e096-n)

1. **汉武帝访求周后，封嘉为周子南君。** 汉武帝巡视河南、返回洛阳时，询问当地耆老，找到被认为是周室后裔的嘉，封为周子南君，使其继续奉祀周的先人。所给封地三十里，地位比列侯。 [[1]](#note-1)

   这是周朝灭亡很久以后的汉代安排，虽然写在《周本纪》篇末，也必须放回汉代，不能附成前249年秦灭周的同时措施。

### 11. 朝廷从渥洼得到一匹异马，把它视作祥瑞，制作《天马》之歌

[返回正文第11条](#event-11)

> 又嘗得神馬渥洼水中，復次以為太一之歌。歌曲曰：「太一貢兮天馬下，霑赤汗兮沫流赭。騁容與兮跇萬里，今安匹兮龍為友。」後伐大宛得千里馬，馬名蒲梢，次作以為歌。歌詩曰：「天馬來兮從西極，經萬里兮歸有德。承靈威兮降外國，涉流沙兮四夷服。」中尉汲黯進曰：「凡王者作樂，上以承祖宗，下以化兆民。今陛下得馬，詩以為歌，協於宗廟，先帝百姓豈能知其音邪？」上默然不說。丞相公孫弘曰：「黯誹謗聖制，當族。」

<a id="卷024音乐史事的互见与归年"></a>
#### 卷024｜音乐史事的互见与归年

[卷024 P007](../../sources/摘录/史记-卷024-乐书.md#p007)渥洼得神马与前首天马歌，据[《汉书·武帝纪》元鼎四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-c68dbb3ba6f061)秋“马生渥洼水中，作宝鼎、天马之歌”暂采用本年。汉志所录歌辞与《乐书》字句不全同；“神”“太一贡”等属于当时的瑞应解释与歌词，原文赤汗也保留为歌辞描写。

[《汉书·礼乐志》天马第十](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7022.md#ref-7f0cb51b92cd55)首曲下注“元狩三年马生渥洼水中作”，即前120年，与本纪的前113年不同。正文采用本纪明确系年的事件，另保留早七年的异年，不在两年各编一匹确定相同的渥洼神马。P007后半伐宛、蒲梢及西极歌另归[前101年](bce-0101.md#sj024-note)；汲黯、公孙弘对话的冲突见[前121年](bce-0121.md#sj024-note)，不在本年重现已卒的公孙弘。


**追加核读：** [通鉴卷019](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7019.md#ref-bebbbb88056b4e)明确将渥洼马、李延年制乐与汲黯谏歌编在前120年；[考异卷01](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91%E8%80%83%E7%95%B0-%E5%8D%B701.md#ref-8642e852dedf34)提出的复原仍有推测语气。本页继续暂取汉武帝纪前113年的得马线，[前120年异说入口](bce-0120.md#sj024-alternative)只作互见，不再献一次马；[采用线与文本补核](../../meta/考证/史记-卷024-天马纪年与文本层次补核.md#通鉴考异)保留两种编年的证据及界限。

### 《孝武本纪》所补的祭祀与方士记事

<a id="sj012-113-1"></a>
<a id="汾阴立后土祠祭天之外还要祭地"></a>
### 汾阴立后土祠，祭天之外还要祭地

**武帝到雍祭五畤，再到汾阴，十一月甲子在汾阴脽上立后土祠。** 祭天已有既定的礼制，朝廷认为地祇也应受皇帝亲祭，因而设立五坛并议定黄犊、服色与瘗埋程序。祭毕巡至洛阳，寻找周室后人封为周子南君。

这是礼制扩张和旧王朝祭祀的连接：一面礼敬天地，一面把周后纳入汉朝封爵制度；本页原有周子南君与引文锚点继续保留。

**本段史料：** [卷012 P010](../../sources/摘录/史记-卷012-孝武本纪.md#p010)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-818ea8412d40e5)。《汉书》元鼎四年十一月后土祠；周后材料既见本卷又见原有卷004。

<a id="sj012-113-2"></a>
<a id="栾大说自己可以联系仙人"></a>
### 栾大说自己可以联系仙人

**胶东宫人栾大经乐成侯引荐，说海上仙人可以带来长生药、黄金，甚至帮助堵塞黄河。** 武帝先试他所说的小法，随后封他为五利将军、乐通侯，赐多枚印信，还把卫长公主嫁给他。栾大提出的条件，是「使者」必须尊贵，仙人才愿意接见。

**皇帝几乎把方士当作通向神灵的外交使节。** 栾大随即出海或往泰山寻师，却拿不出可靠验证。最终他因虚妄受到惩处，结局须接前112年，不能把受宠当成求仙成功。

**本段史料：** [卷012 P011](../../sources/摘录/史记-卷012-孝武本纪.md#p011)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-15bd1a80f77a2f)。《汉书》元鼎四年夏封栾大，次年元鼎五年九月诛。

<a id="sj012-113-3"></a>
<a id="汾阴后土祠旁又报告发现宝鼎"></a>
### 汾阴后土祠旁又报告发现宝鼎

**六月，巫锦在后土祠旁挖得一只纹饰特殊的鼎。** 官府上报，皇帝派人查是否作伪，再安排礼祭与迎鼎。到长安后，公卿把它解释为天下统一、古圣受命的象征；公孙卿借机谈黄帝封禅与升仙。

**这和前三年「汾水得鼎」的报道分开。** 鼎的出现与是否真是上古九鼎，不是一回事；公孙卿的黄帝故事是他的游说，不是能直接证实的上古实录。

**本段史料：** [卷012 P012](../../sources/摘录/史记-卷012-孝武本纪.md#p012)、[卷012 P013](../../sources/摘录/史记-卷012-孝武本纪.md#p013)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-0885091313c799)。宝鼎六月份归元鼎四年，公孙卿论说是此后铺展，不把整段黄帝成仙写成当前史实。

<a id="sj017-zhongshan"></a>
<a id="二月中山王刘胜去世"></a>
### 二月，中山王刘胜去世

**刘胜去世，儿子刘昌接续中山王国。** 他是景帝之子、赵王刘彭祖的兄弟。王位将继续传承，不能因为在位四十二年结束，就把中山国也写成同日废除。[原文与说明](#sj017-note)

<a id="sj017-sishui"></a>
<a id="秋刘商被封为泗水王"></a>
### 秋，刘商被封为泗水王

**常山王刘舜的儿子刘商另得泗水王号。** 兄长刘勃被废以后，朝廷仍让刘舜的其他儿子受封，刘平得真定、刘商得泗水，延续一部分宗室奉祀与封国安排。[原文与说明](#sj017-note)

<a id="sj017-successions"></a>
**河间进入刘缓的元年，刘义则在清河继续原来的王年。** 前者接续父亲刘基，后者由代迁来，不是同一种继承。刘平在真定本行也列元年，其受封采用前一年主线，不再重封。[原文与说明](#sj017-note)

# 公元前114年｜常山王国继承出事，代王迁往清河

[← 公元前115年](bce-0115.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前113年 →](bce-0113.md)

**汉武帝元鼎三年**

本页在原有《孝武本纪》主线中补入诸侯王更替与迁国；不表示当年全国史事已全部收齐。纪年分歧保留在对应注内。

<a id="sj012-114-1"></a>
## 常山王舜死后，继承问题引发废迁

**常山王刘舜去世后，其子刘勃继立，又因罪被废徙房陵。** 王室争执涉及侍疾、居丧行为和财产分配，长子刘棁告发新王及王后，朝廷派人查办。刘勃在位只有数月，常山国便被撤销。[原文与说明](#sj017-note)

**朝廷随后另封刘舜之子刘平为真定王。** 被废的是刘勃，并不表示刘舜所有后嗣都失去受封机会；另一个儿子刘商受封泗水的主叙见下一年。这些安排也为五岳所在郡县的调配提供了背景。[原文与说明](#sj017-note)

《孝武本纪》把常山王犯罪迁徙、封弟延祀和五岳郡辖压缩在同一处，不能让人误认为这年皇帝一次性实施了全部后续安排。

**本段史料：** [卷012 P007](../../sources/摘录/史记-卷012-孝武本纪.md#p007)；[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)。本纪元鼎三年记刘舜死、子嗣废迁；泗水刘商在本纪元鼎四年有明确封立条，但汉书王表另作二年，不能说所有篇章一致。

<a id="sj017-qinghe"></a>
## 代王刘义迁为清河王

**刘义由代迁到清河，原代地改为太原郡。** 他仍是同一位国王，只是封国改变；此后清河栏沿用他先前的在位年数，不从这次转封重新算一位新人的元年。[原文与说明](#sj017-note)

<a id="sj017-succession"></a>
## 楚国的新王与河间的终局

**刘纯接续刘注，楚国进入新王纪年；河间王刘基则在本年去世。** 河间随后由其子刘缓承接，下一年列新王元年。中山王刘胜、长沙王刘庸本年另有入朝记录，和两国的继承分别处理。[原文与说明](#sj017-note)

<a id="sj017-note"></a>
### 卷017｜废国、迁国和初封的异年

[卷017前114年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0114)包括楚纯元年、河间王薨、常山舜薨子继、代徙清河、太原郡及中山长沙来朝。楚父子见[楚元王世家](https://zh.wikisource.org/wiki/史記/卷050)，常山案见[五宗世家](https://zh.wikisource.org/wiki/史記/卷059)，迁清河与封真定见[通鉴卷二十元鼎三年](https://zh.wikisource.org/wiki/資治通鑑/卷020)。刘勃不等于早年由衡山迁济北的刘勃，刘棁也不混为已经继位的太子。控告、法司请求与皇帝改废分开，不把家族告发一律当作无争议的内幕。

**真定：** 汉书王表、通鉴系前114年封刘平；本表前113年记元年，五宗世家亦作四年。正文沿通鉴写本年封，下一年作计年互见，不重复授封。**泗水：** 本表本年写初置、郯为都，下一年记刘商元年；武帝纪、通鉴亦明确前113年封，汉书王表却作前115年。保留本年栏目先导与地理信息，正式封王采用[前113年](bce-0113.md#sj017-sishui)，不说初置格已证明本年完成授印、赴国。

河间继承者本表作授、汉书表作缓，正文用刘缓，非两人。刘义迁国采用本年明确记载，前113年“二十”沿旧年数不另迁一次。年表前114年中山来朝仍为刘胜；不能因次年死讯而在本年提前换成刘昌。

<a id="sj018-wudi"></a>
## 功臣后裔的承爵与失国

垣侯皋柔任汝南太守时，因征收赋税涉及不用赤侧钱的问题获罪，失去侯爵。 [R038](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r038)

郸侯周中居在太常任上，因有关钱制的职事获罪，被剥夺侯爵。 [R063](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r063)

<a id="sj018-note"></a>
### 卷018｜原格、异年与本页采用

**逐格定位：** <a id="sj018-r038-wu"></a>[R038](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r038) · <a id="sj018-r063-wu"></a>[R063](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r063)。

本页按原格中明确年号、承袭次序及互见材料分别定位；未载月份的不补日期，元年也不一律倒推父亲死年。侯爵与所任中央官职不是同一继承关系。

**R038：** 史表皋柔，汉表皇柔；承爵均为建元二年。除爵史表元鼎三年，汉表元鼎二年且记论为鬼薪，暂沿本卷前114年并保留前115年异说。这里是官员征赋与钱制执行问题，不等于全国百姓只要不用某种钱就一律处死；也不能用钱制推测替换表文的明确年次。

**R063：** 史表元鼎三年仅说太常有罪；汉表作周仲居，并详记应收赤侧钱而不收、论完城旦。此人是蒯成侯周绁的后裔，不能同汝南太守、垣侯皋柔合为一件案子。

互校：[《汉书》高惠高后文功臣表](https://zh.wikisource.org/wiki/漢書/卷016) · [《史记》三家注卷018](https://zh.wikisource.org/wiki/史記三家註/卷018)。

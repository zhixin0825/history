# 公元前114年｜常山王国继承出事，代王迁往清河

[← 公元前115年](bce-0115.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前113年 →](bce-0113.md)

**汉武帝元鼎三年**

本页在原有《孝武本纪》主线中补入诸侯王更替与迁国；不表示当年全国史事已全部收齐。纪年分歧保留在对应注内。

<a id="常山王舜死后继承问题引发废迁"></a>

<a id="event-1"></a>

1. **常山王刘舜去世后，刘勃继立，又因罪被废徙房陵。** 刘舜的长子刘棁因母亲不受宠，向来被冷落。舜病重时，宠姬多在旁侍病，王后修却因嫉妒常回住处，太子勃不亲尝药，也不留宿侍候，直到舜死后母子才来。舜死后，刘棁仍未分得财物；有郎官劝诸子与棁分财，王后和太子不听，勃继王以后也不照恤他。刘棁向来视丧的汉使告发母子不侍病，又指太子父死六日即出丧舍、私通、饮酒博戏击筑、与女子驾车环城及入牢视囚。朝廷遣大行张骞查验，刘勃藏匿证人，还抗拒追捕、笞掠相关人员，擅放汉所疑囚。公卿请诛，武帝以王后素无行、刘勃无良师傅而不忍，批准废后废王，勃与家属迁房陵。在位仅数月，常山国绝。 [[1]](#note-1)

<a id="event-2"></a>

2. **朝廷随后另封刘舜之子刘平为真定王。** 被废的是刘勃，并不表示刘舜所有后嗣都失去受封机会；另一个儿子刘商受封泗水的主叙见下一年。这些安排也为五岳所在郡县的调配提供了背景。 [[2]](#note-2)

   《孝武本纪》把常山王犯罪迁徙、封弟延祀和五岳郡辖压缩在同一处，不能让人误认为这年皇帝一次性实施了全部后续安排。

   本纪元鼎三年记刘舜死、子嗣废迁；泗水刘商在本纪元鼎四年有明确封立条，但汉书王表另作二年，不能说所有篇章一致。

<a id="sj017-qinghe"></a>
<a id="代王刘义迁为清河王"></a>

<a id="event-3"></a>

3. **刘义由代迁到清河，原代地改为太原郡。** 他仍是同一位国王，只是封国改变；此后清河栏沿用他先前的在位年数，不从这次转封重新算一位新人的元年。 [[3]](#note-3)

<a id="sj017-succession"></a>
<a id="楚国的新王与河间的终局"></a>

<a id="event-4"></a>

4. **刘纯接续刘注，楚国进入新王纪年；河间王刘基则在本年去世。** 河间随后由其子刘缓承接，下一年列新王元年。中山王刘胜、长沙王刘庸本年另有入朝记录，和两国的继承分别处理。 [[4]](#note-4)

18. **周居任太常获罪，蒯成一支失侯。** 元鼎三年，周居任太常时获罪，侯国撤除。《汉书》名仲居，补记因未依法收赤侧钱而论完城旦。 [[18]](#note-18)

### 卷017｜废国、迁国和初封的异年

[卷017前114年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0114)包括楚纯元年、河间王薨、常山舜薨子继、代徙清河、太原郡及中山长沙来朝。楚父子见[楚元王世家](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7050.md#ref-9e676d45cbd249)，常山案见[五宗世家](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7059.md#ref-42b6c2a53523c0)，迁清河与封真定见[通鉴卷二十元鼎三年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7020.md#ref-4a7aae43a8340f)。刘勃不等于早年由衡山迁济北的刘勃，刘棁也不混为已经继位的太子。控告、法司请求与皇帝改废分开，不把家族告发一律当作无争议的内幕。

**真定：** 汉书王表、通鉴系前114年封刘平；本表前113年记元年，五宗世家亦作四年。正文沿通鉴写本年封，下一年作计年互见，不重复授封。**泗水：** 本表本年写初置、郯为都，下一年记刘商元年；武帝纪、通鉴亦明确前113年封，汉书王表却作前115年。保留本年栏目先导与地理信息，正式封王采用[前113年](bce-0113.md#sj017-sishui)，不说初置格已证明本年完成授印、赴国。

河间继承者本表作授、汉书表作缓，正文用刘缓，非两人。刘义迁国采用本年明确记载，前113年“二十”沿旧年数不另迁一次。年表前114年中山来朝仍为刘胜；不能因次年死讯而在本年提前换成刘昌。

### 卷018｜原格、异年与本页采用

**逐格定位：** <a id="sj018-r038-wu"></a>[R038](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r038) · <a id="sj018-r063-wu"></a>[R063](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r063)。

**R063：** 史表元鼎三年仅说太常有罪；汉表作周仲居，并详记应收赤侧钱而不收、论完城旦。此人是蒯成侯周绁的后裔，不能同汝南太守、垣侯皋柔合为一件案子。

互校：[《汉书》高惠高后文功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-e684fd4e25e65b) · [《史记》三家注卷018](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7018.md#ref-0083fac9c40a02)。

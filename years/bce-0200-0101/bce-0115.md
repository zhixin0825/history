# 公元前115年｜柏梁台兴建，楚王去世，鲁代两王入朝

[← 公元前116年](bce-0116.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前114年 →](bce-0114.md)

**汉武帝元鼎二年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，并补诸侯王材料；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，卷十二的跨年回叙不当成同年新事。

<a id="sj012-115-1"></a>
## 高台成为求仙祭祀的一部分

**春季，朝廷开始兴建柏梁台。** 武帝时期方士屡称神灵喜欢高处与特别的宫室，柏梁、甘泉等处后来不断被用于祠祀和迎神活动。

原书「其后则又作柏梁、铜柱、承露仙人掌」把多处工程连写，并不能证明柏梁、承露盘在本年一起完成。这里只把《汉书》明确系于元鼎二年的柏梁台开工记在此年，其余未定年设施留到相关说明。

**本段史料：** [卷012 P008](../../sources/摘录/史记-卷012-孝武本纪.md#p008)；[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)。《汉书》元鼎二年春「起柏梁台」；起是动工，不是竣工验收。

<a id="sj012-115-background"></a>
## 少翁显神与伪书事件的未定年前情

**方士少翁声称能够使已故王夫人和灶鬼的影像出现，得到皇帝宠信。** 他被授予文成将军，建议在宫中布置神祠，又谈到以丹砂、祭祀和特殊宫室求神。后来皇帝发现他拿给人的“天书”带有伪造痕迹，少翁被诛；皇帝仍未停止听取其他方士的建议。

**少翁进见、死亡并无足够依据全部系于本年。** 这段放在柏梁台等祭祀工程附近作为前后未定年的关联故事，不能拿页面年份冒充每一个动作的发生时间。[卷012 P008](../../sources/摘录/史记-卷012-孝武本纪.md#p008) · [未定年考证](../../meta/考证/史记-卷012-纪年与异说.md#少翁李少君公孙卿与神仙证据)

<a id="sj017-chu"></a>
## 楚王刘注去世

**刘注在位十四年后去世，儿子刘纯承接楚国。** 下一年开始刘纯元年，仍沿楚元王刘交的后裔相传，不是新立另一个与旧楚国无关的王室。[原文与说明](#sj017-note)

<a id="sj017-audience"></a>
**鲁王刘光、代王刘义入朝。** 刘义下一年将迁王清河，本年赴朝与后来迁国分别记录，不推定这次已经完成迁治。[原文与说明](#sj017-note)

<a id="sj017-note"></a>
### 卷017｜楚王继承与泗水的异年

[卷017前115年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0115)楚王薨、鲁代来朝；刘注、刘纯父系参[《楚元王世家》](https://zh.wikisource.org/wiki/史記/卷050)。刘纯后来时期的后叙不回填为即位前已经发生。

[汉书诸侯王表](https://zh.wikisource.org/wiki/漢書/卷014)泗水初封写元鼎二年，本表却在前114年列初置、前113年记刘商元年。两表年数亦不能完全互合。本轮不在本页另造一次封王，采用与常山废国过程相接的[前114—113年说明](bce-0114.md#sj017-note)，把汉书本年异说留在这里，待历谱与版本专题校核。

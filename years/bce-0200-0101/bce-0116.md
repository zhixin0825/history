# 公元前116年｜汾水得鼎，济东王因杀人被废

[← 公元前117年](bce-0117.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前115年 →](bce-0115.md)

**汉武帝元鼎元年**

本页保留《孝武本纪》的祠祭主线，并补诸侯王案件与朝见；不表示本年全部军政史事已经收齐。

<a id="sj012-116-1"></a>
## 第一条得鼎记录

**朝廷记录在汾水附近得到一只鼎。** 鼎在传统叙述中象征王权与天下统一；朝廷随后多次利用「宝鼎」解释祭祀和年号。

**这件事不能同前113年汾阴后土祠旁得鼎合并。** 《汉书》先有元鼎元年「得鼎汾水上」，三年后又记后土祠旁得鼎。卷十二以祭祀故事连续铺陈，容易给人只有一次发现的印象。

**本段史料：** [卷012 P012](../../sources/摘录/史记-卷012-孝武本纪.md#p012)；[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)。《汉书》元鼎元年、元鼎四年分记两条；是否物件相同或传写叠加，单凭纪文不可裁断，暂按两个独立报道处理。

<a id="sj017-jidong"></a>
## 刘彭离的暴行被告发，济东国被撤销

**刘彭离被追究夜间抢掠杀人的案件，最后废为平民、迁往上庸。** 他是梁孝王刘武之子。案情记载，他与奴仆、亡命者结伴出行夺财杀人，民众因此不敢夜行；被害人的儿子向朝廷上书，案件进入中央处理。[原文与说明](#sj017-note)

**有司请求处死刘彭离，皇帝改为废王迁徙。** 济东不再另立新王，土地改为大河郡。爵位不能阻止追究，但皇帝仍在死刑与废黜之间作了不同选择。[原文与说明](#sj017-note)

<a id="sj017-audience"></a>
**广川王刘齐入朝。** 此人是刘越之子、广川缪王，不是齐国国君；“齐”在这里是个人名字。[原文与说明](#sj017-note)

<a id="sj017-note"></a>
### 卷017｜济东案件与广川来朝

[卷017前116年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0116)济东二十九年剽攻杀人、迁上庸、改大河郡；[《梁孝王世家》](https://zh.wikisource.org/wiki/史記/卷058)补告发、有司请诛、皇帝改废及民间恐惧。世家称所杀发觉百余人，为传世记数，不改写成现代逐案审计所得；也不把此前多年暴行全压为本年几天发生。

广川来朝只有年份，没有议事内容，不说他专程参与济东案审判。原汾水得鼎及锚点继续保留。

<a id="sj018-wudi"></a>
## 功臣后裔的承爵与失国

堂邑侯陈季须在母亲长公主丧期未结束时，因私通及兄弟争财等事受到追究，依法当死，最后自杀，侯国撤销。 [R010](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r010)

貰侯倩因杀人被判弃市，侯国撤销。 [R034](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r034)

邔侯黄遂因案失去侯爵，封国撤销。 [R125](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r125)

<a id="sj018-note"></a>
### 卷018｜原格、异年与本页采用

**逐格定位：** <a id="sj018-r010-wu"></a>[R010](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r010) · <a id="sj018-r034-wu"></a>[R034](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r034) · <a id="sj018-r125-wu"></a>[R125](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r125)。

本页按原格中明确年号、承袭次序及互见材料分别定位；未载月份的不补日期，元年也不一律倒推父亲死年。侯爵与所任中央官职不是同一继承关系。

**R010：** 季须元光六年嗣、元鼎元年终局见两表。长公主死亡是本案的前提，不由短格反推精确卒日；“兄弟争财”不补写为已经查清的财产数额和各方责任。

**R034：** 元朔五年倩元年、元鼎元年杀人弃市沿史表；汉表名字作猜。初侯姓名本卷与汉表差别较大，本文沿已核同一侯统，不据初名“吕”把他强接为吕后族人。

**R125：** 元朔五年嗣、元鼎元年免两表相合，罪由却不同：史表说向官府卖宅而故意抬高价格，汉表说抢公主马并处城旦。正文只取因案免侯，不把相差很大的两说合成他连续犯了两桩罪。

互校：[《汉书》高惠高后文功臣表](https://zh.wikisource.org/wiki/漢書/卷016) · [《史记》三家注卷018](https://zh.wikisource.org/wiki/史記三家註/卷018)。

# 公元前116年｜汾水得鼎，济东王因杀人被废

[← 公元前117年](bce-0117.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前115年 →](bce-0115.md)

**汉武帝元鼎元年**

本页保留《孝武本纪》的祠祭主线，并补诸侯王案件与朝见；不表示本年全部军政史事已经收齐。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj012-116-1"></a>
<a id="第一条得鼎记录"></a>

<a id="event-1"></a>

1. **朝廷记录在汾水附近得到一只鼎。** 鼎在传统叙述中象征王权与天下统一；朝廷随后多次利用「宝鼎」解释祭祀和年号。 [[1]](#note-1)

<a id="event-2"></a>

2. **这条得鼎报道与前113年汾阴后土祠旁得鼎分列。** 《汉书》先有元鼎元年「得鼎汾水上」，三年后又记后土祠旁得鼎。卷十二以祭祀故事连续铺陈。本页保留两条报道的位置，不仅凭分年就断定它们必是两只不同的鼎。 [[2]](#note-2)

   《汉书》元鼎元年、元鼎四年分记两条；是否物件相同或传写叠加，单凭纪文不可裁断，暂按两个独立报道处理。

<a id="sj017-jidong"></a>
<a id="刘彭离的暴行被告发济东国被撤销"></a>

<a id="event-3"></a>

3. **济东王刘彭离因抢掠杀人受追究，被废徙上庸。** 刘彭离被追究夜间抢掠杀人的案件，最后废为平民、迁往上庸。 他是梁孝王刘武之子。案情记载，他与奴仆、亡命者结伴出行夺财杀人，民众因此不敢夜行；被害人的儿子向朝廷上书，案件进入中央处理。 [[3]](#note-3)

<a id="event-4"></a>

4. **有司请求处死刘彭离，皇帝改为废王迁徙。** 济东不再另立新王，土地改为大河郡。爵位不能阻止追究，但皇帝仍在死刑与废黜之间作了不同选择。 [[4]](#note-4)

<a id="sj017-audience"></a>

<a id="event-5"></a>

5. **广川王刘齐入朝。** 此人是刘越之子、广川缪王，不是齐国国君；“齐”在这里是个人名字。 [[5]](#note-5)

   貰侯倩因杀人被判弃市，侯国撤销。

   邔侯黄遂因案失去侯爵，封国撤销。

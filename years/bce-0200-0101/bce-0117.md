### 四月乙巳，刘闳、刘旦、刘胥各得王国

<a id="event-1"></a>

1. **皇子刘闳为齐王，刘旦为燕王，刘胥为广陵王。** 齐、燕先前都曾因旧王获罪或无后而改为郡，广陵则承接江都被撤销后的地区。如今重新封王，授予的是武帝自己的儿子，不是让旧王的子孙恢复原有身份。 [[1]](#note-1)

<a id="event-2"></a>

2. **封王之前，朝廷对皇子应该作王还是列侯有过反复议论。** 霍去病上疏请早定皇子位号，群臣提出立三人为王；皇帝一度要求再议列侯安排，群臣仍以亲属与名位秩序为由请求封王。三位皇子受封，是这一组请议和诏命的结果。 [[2]](#note-2)

   这说明削弱旧的大王国，与另封亲近皇子可以同时进行。新王国的出现并不等于恢复高祖初年诸侯在军政上的全部权力。

<a id="sj017-chengyang"></a>
<a id="城阳新王开始计年河间与常山两王入朝"></a>
### 城阳新王开始计年，河间与常山两王入朝

<a id="event-3"></a>

3. **刘义继承城阳，开始记元年。** 父亲刘延的去世已见前一年，本年不再重复；代地也有一位刘义，二人不得混同。 [[3]](#note-3)

<a id="event-4"></a>

4. **河间王刘基、常山王刘舜入朝。** 河间的姓名在本表作堪、其他材料作基；朝见不是新授封国，不把两王与本年三位皇子凑成同批五王。 [[4]](#note-4)

# 公元前118年｜城阳王刘延去世，齐燕广陵的新封国尚在筹划阶段

<a id="城阳王刘延去世"></a>

<a id="event-1"></a>

1. **刘延在本年去世，儿子刘义接续城阳王统。** 他是刘喜之子，城阳一支由刘章传下来；父亲曾迁王淮南又回城阳，刘延承接的是复置以后的城阳国。新王刘义的元年见下一年。 [[1]](#note-1)

<a id="sj017-audience"></a>

<a id="event-2"></a>

2. **年表同时记有刘延和淄川王刘建来朝。** 刘延本年有来朝和去世两条，不据此推定两事同月或同日；淄川的刘建也不是已经在江都案中去世的同名国王。 [[2]](#note-2)

<a id="event-11"></a>

11. **李蔡死后，庄青翟由太子少傅转任丞相。** [[11]](#note-11)

<a id="sj030-wuzhu-event"></a>

12. **朝廷停用半两钱，行五铢钱。** 本卷说三铢轻钱易被作伪，因而请郡国改铸五铢、设置周郭防磨。帝纪将本次改革明记元狩五年；后来的上林三官集中铸币另是一轮制度变化。 [[12]](#sj030-wuzhu-note)

<a id="sj109-event-13"></a>

13. **李敢接任郎中令。** 李广死后，李敢接掌郎中令。官表在元狩五年列此官任，前一年的随军立功另有本条。 [[13]](#note-13)

<a id="sj028-event-14"></a>

14. **《资治通鉴》载武帝病鼎湖而后幸甘泉。** 武帝病重，上郡巫由游水發根引荐至甘泉。传文称帝病愈后到甘泉。寿宫仪节与该巫见闻为跨年叙事。 [[14]](#note-14)

<a id="sj117-event-15"></a>

15. **司马相如卒于茂陵，所忠取回议封禅遗书。** 病免家居茂陵的司马相如去世。武帝遣所忠访求遗稿，妻子交付相如生前嘱咐呈奏的《封禅书》。卒年暂取元狩五年（前118），本传未明书年月。 [[15]](#note-15)

<a id="sj120-event-16"></a>

16. **汲黯出任淮阳太守。** 五铢改铸后楚地盗铸尤多，武帝召汲黯守淮阳。汲黯愿留朝进谏，武帝说只需借他声望卧治该郡。 [[16]](#note-16)

<a id="hs-event-17"></a>

17. **为牡马定价。** 天下缺马，官府将公马定价为每匹二十万钱。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **迁奸猾吏民到边地。** 把被朝廷指为奸猾的官吏和百姓迁到边境。 [[18]](#hs-note-18)

> 天子病鼎湖甚，巫醫無所不致，不愈。游水發根言上郡有巫，病而鬼神下之。上召置祠之甘泉。及病，使人問神君。神君言曰：「天子無憂病。病少愈，彊與我會甘泉。」於是病愈，遂起，幸甘泉，病良已。

### 15. 司马相如卒于茂陵，所忠取回议封禅遗书

### 16. 汲黯出任淮阳太守

> 會更五銖錢，民多盜鑄錢，楚地尤甚。上以爲淮陽，楚地之郊，乃召拜黯爲淮陽太守。黯伏謝不受印，詔數彊予，然後奉詔。詔召見黯，黯爲上泣曰：「臣自以爲填溝壑，不復見陛下，不意陛下復收用之。臣常有狗馬病，力不能任郡事，臣願爲中郎，出入禁闥，補過拾遺，臣之願也。」上曰：「君薄淮陽邪？吾今召君矣。顧淮陽吏民不相得，吾徒得君之重，卧而治之。」

**R107：** 栾说／乐说、愿之／愿的异写按既有侯统辨认。建元元年嗣、元狩五年铸白金弃市与汉表相合。白金属于本时期特殊货币制度，不能拿前175年民间铸铜钱的政策推成他当然不犯法，也不泛称从此一切铸钱永久同罚。

**R133：** 建元三年承、元狩五年免见两表；汉表另记隶臣等处分。正文不由同年另有李蔡案便把所有细节未经核对合并，也不把“神道壖”解释为整个陵墓被盗。

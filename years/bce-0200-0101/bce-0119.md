# 公元前119年｜白鹿皮币与白金发行，祥瑞牵动财政

[← 公元前120年](bce-0120.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前118年 →](bce-0118.md)

**汉武帝元狩四年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补诸侯来朝；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，卷十二的跨年回叙不当成同年新事。

<a id="sj012-119-1"></a>
## 财政需要和祭祀象征放到一起

**朝廷面临边战及迁民费用，主管官员请求用银锡铸造白金、用白鹿皮制作币券，以增加财源。** 鹿皮被借作「瑞应」的材料，币值并非自然来自鹿皮本身，而是由国家制度规定。

《孝武本纪》将白鹿皮币和白金提前摆在白麟叙述旁，容易让读者误以为与元狩元年同年。这里用《汉书·武帝纪》元狩四年的明确记载安放，并保留传本叙次问题。

**本段史料：** [卷012 P007](../../sources/摘录/史记-卷012-孝武本纪.md#p007)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-a63de248f1e2e2)。《汉书》元狩四年冬有司建议造白金及皮币；只是建议与施行的叙述分层，不推算实际增收。

<a id="sj027-long-star"></a>
## 四月，西北方出现长星

**四月，西北方出现带有长芒的星象。** 这次长星与此前建元六年所记的长星相隔多年。古人把这种形态称为“蚩尤旗”，并联想到对外征伐；这只是当时的占星解释。 [原文与说明](#sj027-long-star-note)

<a id="sj017-audience"></a>
## 楚、济东两王入朝

**楚王刘注、济东王刘彭离来到朝廷。** 两国继续履行朝见联系；刘彭离后来的杀人案在本年尚不能当作已结案事件。[原格与说明](#sj017-note)

<a id="sj017-note"></a>
[卷017前119年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0119)楚十、济东二十六来朝。通鉴同年叙皮币须用于王侯朝觐聘享的荐璧，但不提供这两位国君各自实际购买、使用皮币的账目，正文不从一般制度推断每一人的具体支出。济东终局另见[前116年](bce-0116.md#sj017-jidong)。

<a id="sj018-wudi"></a>
## 功臣后裔的承爵与失国

杜衍侯王定国因罪失去侯爵，封国撤销。 [R078](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r078)

绳侯周平任太常时，因没有修缮园陵有关建筑而被免侯。 [R100](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r100)

<a id="sj018-note"></a>
### 卷018｜原格、异年与本页采用

**逐格定位：** <a id="sj018-r078-wu"></a>[R078](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r078) · <a id="sj018-r100-wu"></a>[R100](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r100)。

本页按原格中明确年号、承袭次序及互见材料分别定位；未载月份的不补日期，元年也不一律倒推父亲死年。侯爵与所任中央官职不是同一继承关系。

**R078：** 史表元狩四年，汉表元狩五年并记坐杀人、完城旦，失国差一年；正文暂沿史表前119年，留前118年异说，不再另判一次。初侯王翳与继者王定国不是同一人，其他燕赵诸王的定国同名也不能混入。

**R100：** 史表不缮治园陵，汉表不缮园屋；元狩四年失爵相合。侯平承爵的元年原表明说“不得元”，不为完成年表而倒推出一个确年；本年只能定位罪案。周平属于周苛后裔，不是周勃的平曲侯一支。

互校：[《汉书》高惠高后文功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-6b63b46521fd99) · [《史记》三家注卷018](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7018.md#ref-b36894bcf1179d)。

## 军政、受封与侯国的接续

<a id="sj020-e024"></a>
### 赵安稽随骠骑将军增封

赵安稽以昌武侯身份随霍去病击左贤王部，获得增封。归降受爵与后来战功相接，不能只用出身判断他一直属于哪一方。 [原文与说明](#sj020-e024-n)

<a id="sj020-e060"></a>
### 路博德封符离侯

右北平太守路博德随霍去病远征，按期与主力会合并获军功，封符离侯。 [原文与说明](#sj020-e060-n)

<a id="sj020-e061"></a>
### 复陆支以归义王军功封侯

原为匈奴归义因淳王的复陆支随霍去病作战，以较少兵力获胜，受封壮侯。 [原文与说明](#sj020-e061-n)

<a id="sj020-e062"></a>
### 伊即轩封众利侯

原匈奴归义楼剸王伊即轩随霍去病作战，亲自持剑交锋，受封众利侯。 [原文与说明](#sj020-e062-n)

<a id="sj020-e063"></a>
### 敞屠洛封湘成侯

匈奴符离王敞屠洛降汉，受封湘成侯。 [原文与说明](#sj020-e063-n)

<a id="sj020-e064"></a>
### 卫山封义阳侯

北地都尉卫山随霍去病击匈奴左王部，获敌王等军功，受封义阳侯。 [原文与说明](#sj020-e064-n)

<a id="sj020-e065"></a>
### 董荼吾封散侯

匈奴都尉董荼吾归汉，取得散侯爵。 [原文与说明](#sj020-e065-n)

<a id="sj020-e066"></a>
### 延年封臧马侯

匈奴王延年归汉，受封臧马侯。 [原文与说明](#sj020-e066-n)

<a id="sj020-e068"></a>
### 高不识因虚增首级失侯

宜冠侯高不识因为把实际没有的斩获列入军功，被判当斩，赎罪后失侯。 [原文与说明](#sj020-e068-n)

<a id="sj020-e139"></a>
### 漠北出兵后，霍去病再获增封

霍去病率军深入漠北，与匈奴左贤王部作战，又增加封邑。本表在侯功中连写击左右贤王，应与卫青、霍去病分别进军的战线合读，不把两位主将的敌手混作一军。 [原文与说明](#sj020-e139-n)

<a id="sj027-long-star-note"></a>
### 四月长星的原文与纪年

《汉书·五行志》（[互校H014](../../sources/摘录/史记-卷027-纪年互校.md#h014)）：

> 元狩四年四月，長星又出西北，是時伐胡尤甚。

《天官书》[P120](../../sources/摘录/史记-卷027-天官书.md#p120)作“元光、元狩，蚩尤之旗再見”，本卷[P089](../../sources/摘录/史记-卷027-天官书.md#p089)则释其形如彗而后曲。第二次据《汉书》明确取元狩四年四月；此前[前135年八月](bce-0135.md#sj027-long-star)为另一条记录。“旗”的古代命名不等于已认定现代天体种类，战争与天象没有在这里被写成因果。详[两次长星及元光异文](../../meta/考证/史记-卷027-纪年与异说.md#蚩尤旗)。

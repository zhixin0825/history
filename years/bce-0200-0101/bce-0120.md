# 公元前120年｜胶东由刘贤承接，济北与中山两王入朝

[← 公元前121年](bce-0121.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前119年 →](bce-0119.md)

**汉武帝元狩三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj017-jiaodong"></a>
<a id="胶东进入刘贤的纪年"></a>

<a id="event-1"></a>

1. **刘贤承接父亲刘寄留下的胶东王国，开始记元年。** 他的弟弟刘庆已另封六安王，兄弟各得王号，并不表示六安原本就是从胶东领土直接切出来的。刘庆初封的异年说明见下，不把同一封王记成两次。 [[1]](#note-1)

<a id="sj017-audience"></a>

<a id="event-2"></a>

2. **济北王刘胡、中山王刘胜入朝。** 本次赴朝各处在其不同的在位年数，不是汉廷在本年又封了两位新王。 [[2]](#note-2)

<a id="sj019"></a>
<a id="封侯承袭与侯国的变化"></a>

<a id="sj019-r090-e02"></a>

<a id="event-3"></a>

3. **偃开始记盖侯元年。** 这一支此前由王信受封，承袭世次有不同记载。 [[3]](#note-3)

<a id="sj020"></a>
<a id="军政受封与侯国的接续"></a>

<a id="sj020-e020"></a>
<a id="平津侯由后人承接"></a>


<a id="event-4"></a>

4. **平津侯由后人承接。** 公孙弘之子开始记平津侯元年，延续父亲的封国。 [[4]](#note-4)

<a id="sj020-e046"></a>
<a id="赵不虞因虚报边事被夺爵"></a>


<a id="event-5"></a>

5. **赵不虞因虚报边事被夺爵。** 赵不虞担任定襄都尉时，关于匈奴战事上报不实，获罪失去随城侯爵。 [[5]](#note-5)

<a id="sj020-e057"></a>
<a id="扁訾封煇渠侯"></a>


<a id="event-6"></a>

6. **扁訾封煇渠侯。** 匈奴王扁訾归汉后，侯籍记为本年初封煇渠。此前随浑邪部众归附的背景，不是本年又发生一次浑邪王投降。 [[6]](#note-6)

<a id="sj020-e058"></a>
<a id="乌犁封河綦侯"></a>


<a id="event-7"></a>

7. **乌犁封河綦侯。** 匈奴右王乌犁随浑邪归附，受封河綦侯。此前的投降与本年表列封授分开。 [[7]](#note-7)

<a id="sj020-e059"></a>
<a id="稠雕封常乐侯"></a>


<a id="event-8"></a>

8. **稠雕封常乐侯。** 匈奴大当户稠雕随浑邪归汉，取得常乐侯爵。 [[8]](#note-8)

<a id="sj021"></a>
<a id="王子分邑与侯国的接续"></a>

<a id="sj021-r018-e02"></a>

<a id="event-9"></a>

9. **平望侯爵由后人接续。** 刘楚人接续平望侯爵，侯统进入新的一代。 [[9]](#note-9)

<a id="sj021-r054-e02"></a>

<a id="event-10"></a>

10. **成平侯一支因案失国。** 成平侯礼因强取财物等案失去侯爵，后来又因欺谩受罚。 [[10]](#note-10)

<a id="sj021-r058-e02"></a>

<a id="event-11"></a>

11. **榮簡侯一支因案失国。** 荣简侯骞因谋杀案受追究，遇赦免死而失去侯爵。 [[11]](#note-11)

<a id="sj021-r094-e02"></a>

<a id="event-12"></a>

12. **利鄉侯一支因案失国。** 利鄉侯一支因案失去侯爵，侯国被撤销。 [[12]](#note-12)

<a id="sj021-r096-e02"></a>

<a id="event-13"></a>

13. **東平侯一支因案失国。** 东平侯庆因与姊妹私通的案件失侯；他在狱中死亡。 [[13]](#note-13)

<a id="sj021-r116-e02"></a>

<a id="event-14"></a>

14. **牟平侯爵由后人接续。** 刘奴接续牟平侯爵，侯统进入新的一代。 [[14]](#note-14)

<a id="sj021-r122-e02"></a>

<a id="event-15"></a>

15. **柳宿侯爵由后人接续。** 刘蘇接续柳宿侯爵，侯统进入新的一代。 [[15]](#note-15)

<a id="sj021-chongling-xiongqu"></a>

<a id="event-16"></a>

16. **舂陵侯爵由后人接续。** 刘熊渠接续舂陵侯爵，侯统进入新的一代。 [[16]](#note-16)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-17"></a>

17. **张汤由廷尉升任御史大夫。** 匈奴同年进入右北平与定襄，边事与中枢的人事升迁同时进行。 [[17]](#note-17)

<a id="sj030-relief-event"></a>

18. **水灾地区劝种宿麦、奖励贷贫，迁民安置又需国家持续供给。** 仓储赈济、富户借贷仍不足时，朝廷向关西等地区迁民并给予衣食产业。下一古历年冬的汇报记迁民七十二万五千口；这是一段累计过程，不在两年各记一次同规模迁徙。 [[18]](#sj030-relief-note)

<a id="sj030-kunming-event"></a>

19. **朝廷征发谪吏开凿昆明池。** 反复征发、买复与买爵影响可用人手，故又让有关人员任职、出马或参加工程。本次是帝纪明确记载的开池，后文因水战扩修不能另当作第一次开凿。 [[19]](#sj030-kunming-note)

<a id="hs-event-20"></a>

20. **东方出现孛星，五月赦天下。** 春季记东方有孛星，五月大赦。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **封萧何曾孙萧庆。** 本纪记萧庆此年封列侯。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **匈奴侵右北平和定襄。** 秋季匈奴入右北平、定襄，杀掠千余人。 [[22]](#hs-note-22)

<a id="hs-event-23"></a>

23. **减少三郡戍卒。** 陇西、北地、上郡的戍卒减少一半。 [[23]](#hs-note-23)

<a id="hs-event-24"></a>

24. **酇文终侯萧何｜绍封。** 表载酇文终侯萧何一支本年接续了原有封爵。表中所载事项为共侯庆因何曾孙接续封爵，二千四百户。 [[24]](#hs-note-24)

<a id="hs-event-25"></a>

25. **成敬侯董渫｜获罪。** 表载成敬侯董渫一支本年载相关罪案及处分。表中所载事项为因罪案为济南太守与城阳王女通，受耐刑后罚作鬼薪。 [[25]](#hs-note-25)

<a id="hs-event-26"></a>

26. **安国武侯王陵｜承爵。** 表载安国武侯王陵一支本年记载侯位承袭。表中所载事项为侯定承爵。 [[26]](#hs-note-26)

<a id="hs-event-27"></a>

27. **柏至靖侯许盎｜承爵。** 表载柏至靖侯许盎一支本年记载侯位承袭。表中所载事项为侯福承爵。 [[27]](#hs-note-27)

<a id="hs-event-28"></a>

28. **清简侯室中同｜承爵。** 表载清简侯室中同一支本年记载侯位承袭。表中所载事项为共侯古承爵。 [[28]](#hs-note-28)

<a id="hs-event-29"></a>

29. **故安节侯申屠嘉｜改封。** 表载故安节侯申屠嘉一支本年爵号或封邑改易。表中所载事项为侯臾改封。 [[29]](#hs-note-29)

<a id="hs-event-30"></a>

30. **周阳懿侯田胜｜获罪。** 表载周阳懿侯田胜一支本年载相关罪案及处分。表中所载事项为因罪案当归轵侯宅不与，失爵。 [[30]](#hs-note-30)

<a id="hs-event-31"></a>

31. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[31]](#hs-note-31)

# 公元前120年｜胶东由刘贤承接，济北与中山两王入朝

[← 公元前121年](bce-0121.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前119年 →](bce-0119.md)

**汉武帝元狩三年**

<a id="sj017-jiaodong"></a>
## 胶东进入刘贤的纪年

**刘贤承接父亲刘寄留下的胶东王国，开始记元年。** 他的弟弟刘庆已另封六安王，兄弟各得王号，并不表示六安原本就是从胶东领土直接切出来的。刘庆初封的异年说明见下，不把同一封王记成两次。[原文与说明](#sj017-note)

<a id="sj017-audience"></a>
**济北王刘胡、中山王刘胜入朝。** 本次赴朝各处在其不同的在位年数，不是汉廷在本年又封了两位新王。[原文与说明](#sj017-note)

<a id="sj019"></a>
## 封侯、承袭与侯国的变化

<a id="sj019-r090-e02"></a>
偃开始记盖侯元年。这一支此前由王信受封，承袭世次有不同记载。 [原文与说明](#sj019-r090-e02-n)


<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e020"></a>
### 平津侯由后人承接

公孙弘之子开始记平津侯元年，延续父亲的封国。 [原文与说明](#sj020-e020-n)

<a id="sj020-e046"></a>
### 赵不虞因虚报边事被夺爵

赵不虞担任定襄都尉时，关于匈奴战事上报不实，获罪失去随城侯爵。 [原文与说明](#sj020-e046-n)

<a id="sj020-e057"></a>
### 扁訾封煇渠侯

匈奴王扁訾归汉后，侯籍记为本年初封煇渠。此前随浑邪部众归附的背景，不是本年又发生一次浑邪王投降。 [原文与说明](#sj020-e057-n)

<a id="sj020-e058"></a>
### 乌犁封河綦侯

匈奴右王乌犁随浑邪归附，受封河綦侯。此前的投降与本年表列封授分开。 [原文与说明](#sj020-e058-n)

<a id="sj020-e059"></a>
### 稠雕封常乐侯

匈奴大当户稠雕随浑邪归汉，取得常乐侯爵。 [原文与说明](#sj020-e059-n)

<a id="sj019-note"></a>
### 卷019｜本年侯籍与异说

[完整原表](../../sources/摘录/史记-卷019-惠景间侯者年表.md) · [逐格去向](../../meta/记录/史记-卷019-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷019-纪年与异说.md)。原格的承侯元年不一律等于前任死年；未载月日不补，谥号是后称，国除也不一律等于处死。

<a id="sj019-r090-e02-n"></a>
**蓋｜[R090原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r090)：** 此处暂按史表元狩三年前120年“侯偃元年”。[《汉书·外戚恩泽侯表》](https://zh.wikisource.org/wiki/漢書/卷018)却记王信后为元光三年前132年顷侯充嗣，再有侯受嗣。两表是姓名、世次和嗣年同时不同，不能拼为已证实的王信—充—偃—受连续世系；正文“接续”只指侯统一支，不保证偃是王信直接之子。


<a id="sj017-note"></a>
[卷017前120年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0120)胶东哀王贤元年、济北三十二及中山三十五来朝；[汉书诸侯王表](https://zh.wikisource.org/wiki/漢書/卷014)与[《五宗世家》](https://zh.wikisource.org/wiki/史記/卷059)辨父子及六安另封。哀王是刘贤的后谥，不能认为他本年即死亡；刘寄之死由武帝纪明确放前121年，不虚构本年确日葬礼。原表没有给两个来朝行程的细节。

**六安刘庆初封：**《汉书·武帝纪》《通鉴》在本年记立六安，史记本表、汉书王表和五宗世家则明系元狩二年前121年，两表还给出七月日。主叙采用前一年明确初封记录，见[前121年原文与取舍](bce-0121.md#sj017-luan-note)，本页保留另一年次而不再造第二次授王。两表丙子／壬子不同，也未强选唯一公历日期。

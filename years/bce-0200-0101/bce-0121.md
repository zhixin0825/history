<a id="sj017-jiangdu"></a>
<a id="淮南案的追查延伸到江都"></a>

<a id="event-1"></a>

1. **淮南案的追查延伸到江都，刘建自杀，王国被撤销为广陵郡。** 淮南、衡山事发以后，案情牵涉江都王刘建私造兵器等活动；他曾派人用钱打通关系，想结束调查，仍未成功。公卿请求逮捕治罪，皇帝改派大臣到王国审讯。所追究的不只兵器：刘建还常佩父亲旧将军印，载天子旌旗出行；父亲去世未葬时，他在服丧处与父亲宠姬淖姬私通，又被控信巫祝、祷祠妄言及与姊妹乱伦。刘建承认所控过犯，随后自杀。 [[1]](#note-1)

<a id="event-2"></a>

2. **这不是江都军已经公开起兵的一场大战。** 传世叙述保留的是获知谋划、私备兵器、调查和死亡的过程。上一年淮南、衡山王国被撤销以后，汉廷继续处理与其有关系的诸侯。 [[2]](#note-2)

<a id="sj017-jiaodong"></a>
<a id="胶东王刘寄去世留下两位受重视程度不同的儿子"></a>

<a id="event-3"></a>

3. **胶东王刘寄去世，朝廷另行安排两个儿子的封国。** 淮南谋反前，刘寄略闻消息，暗制楼车、箭镞等攻守装备，等候事变；追案时供辞把他牵出。他与武帝关系亲近，因而伤惧发病而死。长子刘贤的母亲不受宠，少子刘庆的母亲得宠；刘寄偏爱少子，却在忧惧中不敢提出改立。朝廷最终让长子承胶东、少子另得六安，兄弟各有封国。 [[3]](#note-3)

<a id="sj017-luan"></a>
<a id="七月刘庆取得六安王号"></a>

<a id="event-4"></a>

4. **七月，刘庆取得六安王号。** 朝廷另建六安国，封胶东王刘寄的儿子刘庆为王。 刘庆不是接替刘安做“淮南王”，国号和所取支系已经改变。旧淮南王室退出以后，朝廷仍能选择另一支刘氏子弟主持部分地区。 [[4]](#note-4)

<a id="sj017-audience"></a>

<a id="event-5"></a>

5. **鲁王刘光、代王刘义、长沙王刘庸入朝。** 三人各自的王统和本年行程，与江都案、六安建国分别记录，不把所有活动都压在七月同一天。 [[5]](#note-5)

18. **浑邪王率众降汉、受封。** 匈奴浑邪王杀死改变主意的休屠王，率部归汉。 霍去病奉命接应，浑邪王受封漯阴侯。 迎接、赏赐与供给降众也形成持续开支，《平准书》把这一面与军事胜利并记。 汲黯先谏勿斩长安令，继谏勿因边关私输法论死和降众交易的商人五百余，武帝未从。 归降与移民开销骤增时，卜式出钱二十万给河南太守赈济徙民。 [[18]](#note-18)

#### 卷024｜音乐史事的互见与归年

[卷024 P007](../../sources/摘录/史记-卷024-乐书.md#p007)在渥洼及大宛两首天马歌之后，连写汲黯谏用歌于宗庙、公孙弘请诛汲黯。本页[公孙弘春三月去世](#sj020-e019)已有明确年条；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-5542bb5df3802e)同载元狩二年三月戊寅弘薨。渥洼得马本纪列元鼎四年前113年，礼乐志首曲注却列元狩三年前120年；大宛得马作歌两篇汉书均系太初四年前101年。这几条候选年次全晚于弘卒，不能在前113或101年再让公孙弘上朝请族汲黯。

汉纪元狩二年夏另有余吾水中生马的报告，但它同样列于本年三月弘卒之后，地名也不是渥洼。本轮不凭“水中得马”相似就强定为同一事，以挪动年份消除冲突。对话全文保留，具体发生年及传本文字的来历暂未闭合；[前113年](bce-0113.md#sj024-note)、[前101年](bce-0101.md#sj024-note)只编有明确年月线索的作歌事项，不把这段对话当作已定年的朝会记录。

<a id="sj017-case-note"></a>
<a id="1江都之死罪名与广陵"></a>
#### 1｜江都之死、罪名与广陵

[卷017前121年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0121)江都栏“反，自杀，国除为广陵郡”；[《五宗世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7059.md#ref-e7fd1ba409cdb4)详记与淮南相近、担心被吞并而备兵，案发后行贿及审讯，还列多项宫廷罪状。正文区分案情与已经发动的战争，不从一个“反”字创造实际会战；私生活指控保留原文入口，不补戏剧化情节。史记计在位七年，汉书王表作六年，均不能再造一个额外刘建。

<a id="sj017-luan-note"></a>
<a id="2六安初封的异年干支都城疑文"></a>
#### 2｜六安初封的异年、干支、都城疑文

[卷017本年淮南旧栏](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0121)记七月丙子、刘庆胶东王子，另有“以故陈为都”；[汉书诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7014.md#ref-fe792c86427f1f)同系元狩二年，日作七月壬子，称胶东康王少子。《五宗世家》也明确“以元狩二年”封六安。正文采用这组具体初封记录的本年七月，但干支不强选为无争议定日。

[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-6e7af29a992018)与[《通鉴》卷十九](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7019.md#ref-9f04e64fdef9f8)则在元狩三年前120年记立六安，属于另一年次，已在[前120年注](bce-0120.md#sj017-note)互见，不能说各书完全一致，更不在两年各封一次。“陈”与六安地理的对应仍须校核，正文不据疑文确认新都位置。表国栏只是借用原淮南位置，不说明刘安旧地完整、原样交给刘庆。

刘寄死亡由武帝纪元狩二年明确记“胶东王寄薨”；父亲的偏爱和未定储位据五宗世家，属传世家内叙述，不证明病因可用现代医学确诊。刘贤开始记元年在下一年。鲁、代、长沙三格均明确来朝，代王义此时尚未迁清河，迁国另见[前114年](bce-0114.md)。

<a id="淮南案的追查延伸到江都"></a>
### 淮南案的追查延伸到江都

<a id="event-1"></a>

1. **江都王刘建受到追查，最终自杀，王国被撤销为广陵郡。** 淮南、衡山事发以后，案情牵涉他私造兵器等活动；刘建曾派人用钱打通关系，想结束调查，仍未成功。公卿请求逮捕治罪，皇帝改派大臣到王国审讯，刘建承认所控过犯，随后自杀。 [[1]](#note-1)

<a id="event-2"></a>

2. **这不是江都军已经公开起兵的一场大战。** 传世叙述保留的是获知谋划、私备兵器、调查和死亡的过程。上一年淮南、衡山王国被撤销以后，汉廷继续处理与其有关系的诸侯。 [[2]](#note-2)

<a id="sj017-jiaodong"></a>
<a id="胶东王刘寄去世留下两位受重视程度不同的儿子"></a>
### 胶东王刘寄去世，留下两位受重视程度不同的儿子

<a id="event-3"></a>

3. **刘寄在本年去世，胶东的继承需要重新安排。** 长子刘贤的母亲不受宠，少子刘庆的母亲得宠，刘寄原本更倾向幼子，却没有公开落实改立。朝廷最终让长子承胶东、少子另得六安，兄弟没有在同一个王国中同时称王。 [[3]](#note-3)

<a id="sj017-luan"></a>
<a id="七月刘庆取得六安王号"></a>
### 七月，刘庆取得六安王号

<a id="event-4"></a>

4. **朝廷另建六安国，封胶东王刘寄的儿子刘庆为王。** 刘庆不是接替刘安做“淮南王”，国号和所取支系已经改变。旧淮南王室退出以后，朝廷仍能选择另一支刘氏子弟主持部分地区。 [[4]](#note-4)

<a id="sj017-audience"></a>

<a id="event-5"></a>

5. **鲁王刘光、代王刘义、长沙王刘庸入朝。** 三人各自的王统和本年行程，与江都案、六安建国分别记录，不把所有活动都压在七月同一天。 [[5]](#note-5)

### 军政、受封与侯国的接续
<a id="sj020-e138"></a>
<a id="霍去病两次进军河西又接收浑邪降众"></a>
### 霍去病两次进军河西，又接收浑邪降众

<a id="event-8"></a>

8. **霍去病两次进军河西，又接收浑邪降众。** 霍去病春、夏两次深入河西，攻至祁连一带，获增封；随后又接应浑邪王部众，另获奖励。出征、受降与增邑先后发生，不能把它们统统压成冠军侯首次受封的一天。 [[8]](#note-8)

<a id="sj020-e019"></a>
<a id="公孙弘去世"></a>
### 公孙弘去世

<a id="event-9"></a>

9. **公孙弘去世。** 丞相公孙弘在春三月去世。他留下的平津侯爵由后人传承，丞相职位却不是家族私产。 [[9]](#note-9)

<a id="sj020-e043"></a>
<a id="公孙敖因误期失侯"></a>
### 公孙敖因误期失侯

<a id="event-10"></a>

10. **公孙敖因误期失侯。** 公孙敖带兵与霍去病约定会合，却未按期赶到，被判当斩；赎罪后为庶人，合骑侯国撤销。 [[10]](#note-10)

<a id="sj020-e044"></a>
<a id="张骞也因误期失爵"></a>
### 张骞也因误期失爵

<a id="event-11"></a>

11. **张骞也因误期失爵。** 张骞领兵出征未能按期会合，受军法追究，赎免死罪而失去博望侯爵。封侯不久便失爵，与此后继续出使是不同阶段。 [[11]](#note-11)

<a id="sj020-e047"></a>
<a id="公孙戎奴擅自出兵隐瞒而失爵"></a>
### 公孙戎奴擅自出兵、隐瞒而失爵

<a id="event-12"></a>

12. **公孙戎奴任郡守时，出兵击匈奴而没有如实报告，被撤销从平侯爵。** [[12]](#note-12)

<a id="sj020-e050"></a>
<a id="郝贤因取戍卒财物虚报而失侯"></a>
### 郝贤因取戍卒财物、虚报而失侯

<a id="event-13"></a>

13. **郝贤收取戍卒财物，又有欺瞒行为，因而失去众利侯爵。** [[13]](#note-13)

<a id="sj020-e052"></a>
<a id="高不识封宜冠侯"></a>
### 高不识封宜冠侯

<a id="event-14"></a>

14. **高不识封宜冠侯。** 高不识原为匈奴归附者，任校尉随霍去病再次出征，受封宜冠侯。 [[14]](#note-14)

<a id="sj020-e053"></a>
<a id="仆多封煇渠侯"></a>
### 仆多封煇渠侯

<a id="event-15"></a>

15. **仆多封煇渠侯。** 仆多出身匈奴归附部众，以校尉随霍去病作战，获王等军功封煇渠侯，后又随征增封。 [[15]](#note-15)

<a id="sj020-e054"></a>
<a id="赵破奴封从骠侯"></a>
### 赵破奴封从骠侯

<a id="event-16"></a>

16. **赵破奴封从骠侯。** 赵破奴以司马跟随霍去病，多次深入匈奴地域、俘获王子及骑将，受封从骠侯。 [[16]](#note-16)

<a id="sj020-e055"></a>
<a id="呼毒尼封下摩侯"></a>
### 呼毒尼封下摩侯

<a id="event-17"></a>

17. **呼毒尼封下摩侯。** 匈奴王呼毒尼归汉，受封下摩侯，列侯名单因吸收降人继续扩充。 [[17]](#note-17)

<a id="sj020-e056"></a>
<a id="浑邪王率众降汉受封"></a>
### 浑邪王率众降汉、受封

<a id="event-18"></a>

18. **匈奴浑邪王杀死改变主意的休屠王，率部归汉。** 霍去病奉命接应，浑邪王受封漯阴侯。 [[18]](#note-18)

<a id="sj020-e067"></a>
<a id="潦侯无后而终"></a>
### 潦侯无后而终

<a id="event-19"></a>

19. **潦侯无后而终。** 煖訾去世，没有承爵者，潦侯国被撤销。 [[19]](#note-19)

<a id="sj020-e153"></a>
<a id="休屠王之子金日磾随归降人群入汉"></a>
### 休屠王之子金日磾随归降人群入汉

<a id="event-20"></a>

20. **休屠王之子金日磾随归降人群入汉。** 浑邪王部归汉时，休屠王没有顺利参与归降，遭到杀害；其子日磾与母亲、弟弟被收入汉官府，日磾起初养马。后来他凭谨慎勤勉进入宫中，逐渐获得武帝信任。 [[20]](#note-20)

<a id="sj021"></a>
<a id="王子分邑与侯国的接续"></a>
### 王子分邑与侯国的接续
<a id="sj021-r088-e02"></a>

<a id="event-21"></a>

21. **洛陵侯一支因案失国。** 洛陵侯一支因杀人案失去封国。 [[21]](#note-21)

<a id="sj021-r108-e02"></a>

<a id="event-22"></a>

22. **千鍾侯一支因案失国。** 千鍾侯一支因没有遣使履行秋季朝觐要求而失去侯爵。 [[22]](#note-22)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-23"></a>

23. **公孙弘死后，李蔡由御史大夫转任丞相。** 河西战事由霍去病以骠骑将军身份出击，公孙敖另路从北地出兵，张骞、李广由右北平出兵；各路军队的胜败与奖惩并不相同。 [[23]](#note-23)

#### 卷024｜音乐史事的互见与归年

[卷024 P007](../../sources/摘录/史记-卷024-乐书.md#p007)在渥洼及大宛两首天马歌之后，连写汲黯谏用歌于宗庙、公孙弘请诛汲黯。本页[公孙弘春三月去世](#sj020-e019)已有明确年条；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-5542bb5df3802e)同载元狩二年三月戊寅弘薨。渥洼得马本纪列元鼎四年前113年，礼乐志首曲注却列元狩三年前120年；大宛得马作歌两篇汉书均系太初四年前101年。这几条候选年次全晚于弘卒，不能在前113或101年再让公孙弘上朝请族汲黯。

汉纪元狩二年夏另有余吾水中生马的报告，但它同样列于本年三月弘卒之后，地名也不是渥洼。本轮不凭“水中得马”相似就强定为同一事，以挪动年份消除冲突。对话全文保留，具体发生年及传本文字的来历暂未闭合；[前113年](bce-0113.md#sj024-note)、[前101年](bce-0101.md#sj024-note)只编有明确年月线索的作歌事项，不把这段对话当作已定年的朝会记录。

<a id="sj017-luan-note"></a>
<a id="2六安初封的异年干支都城疑文"></a>
#### 2｜六安初封的异年、干支、都城疑文

[卷017本年淮南旧栏](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0121)记七月丙子、刘庆胶东王子，另有“以故陈为都”；[汉书诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7014.md#ref-fe792c86427f1f)同系元狩二年，日作七月壬子，称胶东康王少子。《五宗世家》也明确“以元狩二年”封六安。正文采用这组具体初封记录的本年七月，但干支不强选为无争议定日。

[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-6e7af29a992018)与[《通鉴》卷十九](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7019.md#ref-9f04e64fdef9f8)则在元狩三年前120年记立六安，属于另一年次，已在[前120年注](bce-0120.md#sj017-note)互见，不能说各书完全一致，更不在两年各封一次。“陈”与六安地理的对应仍须校核，正文不据疑文确认新都位置。表国栏只是借用原淮南位置，不说明刘安旧地完整、原样交给刘庆。

刘寄死亡由武帝纪元狩二年明确记“胶东王寄薨”；父亲的偏爱和未定储位据五宗世家，属传世家内叙述，不证明病因可用现代医学确诊。刘贤开始记元年在下一年。鲁、代、长沙三格均明确来朝，代王义此时尚未迁清河，迁国另见[前114年](bce-0114.md)。

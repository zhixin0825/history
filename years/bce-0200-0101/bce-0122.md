# 公元前122年｜获麟被称瑞应，淮南与衡山两王国终结

[← 公元前123年](bce-0123.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前121年 →](bce-0121.md)

**汉武帝元狩元年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，并补淮南、衡山两案及诸侯来朝；不表示武帝当年的战争、税政和全国史事都已收齐。古月沿原史料，跨年回叙不当成同年新事。

[本年相关史料](#sources-start)

<a id="sj012-122-1"></a>
<a id="一角兽被解释成吉兆"></a>

<a id="event-1"></a>

1. **一角兽被解释成吉兆。** 武帝冬十月到雍祭祀，得到一只被称作白麟的动物。 臣下将它解释为天帝嘉奖，祭礼因此增加牲品，朝廷把这一瑞应用于政治宣传。 [[1]](#note-1)

<a id="event-2"></a>

2. **此时还不能把所谓「一角兽」当成已由现代动物学确认的麒麟。** 后人解释「元狩」年号时常说因获麟改元，存本也追叙先前各次年号的由来；这是后来的整理，不应假设建元、元光、元狩一开始就按现代固定年号制度全部公布。 [[2]](#note-2)

   《汉书》元狩元年记冬十月获白麟；卷012在白鹿皮币后写「其明年获兽」，叙次与白金皮币的确年不合，依汉书、食货志拆开。

<a id="sj017-huainan"></a>
<a id="淮南内部的告发把谋划送到了中央"></a>

<a id="event-3"></a>

3. **淮南内部的告发，把谋划送到了中央。** 刘安的家族矛盾与谋反调查相互交织。 长子不害不得宠，不害之子刘建又怨太子刘迁，派人告发太子谋害汉使的计划。朝廷继续追查，刘安和刘迁一度想召来王国高级官员、杀人后发兵，却迟疑不决，没有成功发动。 [[3]](#note-3)

<a id="event-4"></a>

4. **伍被向官吏交代谋划，太子、王后和有关宾客被捕。** 官吏搜查王宫及相关器物，朝廷命宗正持节处理刘安。使者尚未抵达，刘安已经自杀。王后荼、太子迁及被认定参与者遭处死，淮南国被撤销。 追查中又显出田蚡早年收淮南王财物及谈及继位的旧事。田蚡已经死去，武帝称若田蚡仍在，罪将及族。 [[4]](#note-4)

<a id="sj017-hengshan"></a>
<a id="衡山王室的继承争斗也转成大案"></a>

<a id="event-5"></a>

5. **衡山王室的继承争斗也转成大案。** 刘赐想废太子刘爽、改立刘孝，兄弟争位引出相互告发。 刘爽派人控告刘孝制造兵器等事；追查淮南案的官吏又在刘孝家找到涉案人。刘孝为求免罪，转而自告参与谋划的人员，使案件继续扩大。 [[5]](#note-5)

<a id="event-6"></a>

6. **朝廷准备逮捕刘赐，刘赐自杀，衡山国被撤销。** 王后、王子等也受牵连处死。刘安和刘赐是刘长的儿子，文帝时重新得到封国；到了这一年，两支王国同时结束。 [[6]](#note-6)

<a id="sj017-audience"></a>

<a id="event-7"></a>

7. **赵王刘彭祖本年入朝。** 这是另一国栏的独立活动，不能因同年并列就认定他参加了淮南、衡山的谋划。 [[7]](#note-7)

<a id="sj018-wudi"></a>
<a id="功臣后裔的承爵与失国"></a>


<a id="event-8"></a>

8. **淮南、衡山案件牵连到一些功臣后人，但本年每个侯国的变化并非都由谋反案引起。** 承爵、受审、被杀以及爵位撤销，仍要按各条记录分别看。 两王案追究党羽时，丞相公孙弘病中自责，请退还侯印。武帝不许，赐假和礼物，公孙弘病愈后复职。 [[8]](#note-8)

   | 变化 | 本年记事 |
   |---|---|
   | 刑案 | 阳陵侯傅偃被认定参与淮南王的谋反活动，遭诛，封国撤销。傅宽的这支侯爵由此终止。 |
   | 刑案 | 平棘侯薛穰曾收受淮南王财物、向他称臣。旧事虽发生于赦令以前，后来奉诏追问时的欺瞒仍使他失去侯爵。 |
   | 刑案 | 安平侯鄂但因与淮南王刘安、其女刘陵有关的案件被判弃市，侯国撤销。 |
   | 承爵 | 张指接续安丘侯爵。 |
   | 终局 | 繁侯安国被人杀害，这支侯国由此终止。 |
   | 刑案 | 高梁侯一支因诈称皇帝诏命、向衡山王索取金钱的案件失国。 |

18. **李蔡出任御史大夫。** 他此前已凭边功封乐安侯，如今进入中央中枢。 [[18]](#note-19)

<a id="sj049-liuju-crown-event"></a>

19. **皇子刘据被立为太子。** 他是卫皇后的儿子，生于前128年；母亲立后七年，刘据正式成为继承人。皇后的身份、儿子的立储和卫氏亲属此前获军功受侯，分别构成这一家族地位上升的不同环节。 石庆从沛守转任太子太傅。 [[19]](#sj049-liuju-crown-note)

<a id="sj110-event-20"></a>

20. **匈奴骑兵入上谷。** 匈奴骑兵侵入上谷，数百人遇害。这是赵信降匈奴后的次年边事。 [[20]](#note-20)

### 3. 刘安的家族矛盾与谋反调查相互交织

[返回正文第3条](#event-3)

**[《史記》卷118（节录）](../../sources/本地分卷/史记/史记-卷118.md#L6295)**

> 於是廷尉以王孫建辭連淮南王太子遷聞。上遣廷尉監因拜淮南中尉，逮捕太子。至淮南，淮南王聞，與太子謀召相、二千石，欲殺而發兵。召相，相至；內史以出為解。中尉曰：「臣受詔使，不得見王。」王念獨殺相而內史中尉不來，無益也，即罷相。王猶豫，計未決。

**[《史記》卷118（节录）](../../sources/本地分卷/史记/史记-卷118.md#L6292)**

> 王有孽子不害，最長，王弗愛，王、王后、太子皆不以為子兄數。不害有子建，材高有氣，常怨望太子不省其父；又怨時諸侯皆得分子弟為侯，而淮南獨二子，一為太子，建父獨不得為侯。建陰結交，欲告敗太子，以其父代之。太子知之，數捕系而榜笞建。建具知太子之謀欲殺漢中尉，即使所善壽春莊芷以元朔六年上書於天子曰：「毒藥苦於口利於病，忠言逆於耳利於行。今淮南王孫建，材能高，淮南王王后荼、荼子太子遷常疾害建。建父不害無罪，擅數捕系，欲殺之。今建在，可徵問，具知淮南陰事。」書聞，上以其事下廷尉，廷尉下河南治。

> 淮南、衡山謀反，治黨與方急。弘病甚，自以爲無功而封，位至丞相，宜佐明主填撫國家，使人由臣子之道。今諸侯有畔逆之計，此皆宰相奉職不稱，恐竊病死，無以塞責。乃上書曰：「臣聞天下之通道五，所以行之者三。曰君臣，父子，兄弟，夫婦，長幼之序，此五者天下之通道也。智，仁，勇，此三者天下之通德，所以行之者也。故曰『力行近乎仁，好問近乎智，知恥近乎勇』。知此三者，則知所以自治；知所以自治，然後知所以治人。天下未有不能自治而能治人者也，此百世不易之道也。今陛下躬行大孝，鑒三王，建周道，兼文武，厲賢予祿，量能授官。今臣弘罷駑之質，無汗馬之勞，陛下過意擢臣弘卒伍之中，封爲列侯，致位三公。臣弘行能不足以稱，素有負薪之病，恐先狗馬填溝壑，終無以報德塞責。願歸侯印，乞骸骨，避賢者路。」天子報曰：「古者賞有功，襃有德，守成尚文，遭遇右武，未有易此者也。朕宿昔庶幾獲承尊位，懼不能寧，惟所與共爲治者，君宜知之。蓋君子善善惡惡，君宜知之，君若謹行，常在朕躬。君不幸罹霜露之病，何恙不已，迺上書歸侯，乞骸骨，是章朕之不德也。今事少間，君其省思慮，一精神，輔以醫藥。」因賜告牛酒雜帛。居數月，病有瘳，視事。

### 卷017｜两案的原格、追查与结局

[卷017前122年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0122)记刘安、刘赐反而自杀，赵王来朝。过程参[《淮南衡山列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7118.md#ref-1fffc82347a812)与[通鉴卷十九元狩元年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7019.md#ref-8f0adfb3d85450)。谋划、准备、拟杀官员与实际起兵要分开；本页不把两案改写成两场已经展开的大规模战役。供词、史家对人物动机的概述也不都当作独立验证的现场记录。

刘安的宾客策划和刘赐王室矛盾有多年发展，不把长篇回叙全部定在本年。传世记载称两案连引数万人死，为文献所报，不作现代司法名册统计。伍被投案与随后被诛是不同阶段；其劝谏和谋划建议同在一篇，不简单写成完全无涉或一直赞成两种单一形象。

刘赐先王庐江，后迁衡山；表三十二年从迁衡山另计，刘安四十三年从最初受封计，不能比较数字便说二人不同时封王。原衡山王刘勃早已迁济北、去世，不能与本案刘赐混同。下一年江都案及六安另封见[前121年](bce-0121.md)。

本页按原格中明确年号、承袭次序及互见材料分别定位；未载月份的不补日期，元年也不一律倒推父亲死年。侯爵与所任中央官职不是同一继承关系。

**R005：** 史表写“坐与淮南王谋反，国除”，汉表明确“谋反诛”。与本年淮南案合读，不能把同案被追究者都写成已经领兵起事。

**R007：** “其十年为丞相”按武帝起算为元光四年，前131年；《通鉴》同年田蚡死后薛泽为相可核，不能误算为元光六年。元朔四年穰元年、元狩元年免侯分别记录。赦前受财与诏问欺瞒是不同法律环节，不省去“在赦前”而只写他被当作新起兵者处死；汉表记免，未记此案处死。

**R062：** 史表详写与陵通、致淮南王书称臣尽力，汉表简写与淮南王安通；均系元狩元年。这里区分传世案情与刑罚结果，不擅补书信全文或说他已经亲率军队叛汉。

**R094：** 承袭、国号或年次的完整取舍见[本行武帝核对](../../meta/记录/史记-卷018-武帝逐格核对.md#r094-wu)。

**R098：** 史表写“为人所杀”，汉表同事，不能改成皇帝依法处死或认定他参加淮南谋反。汉表行名、人名与史表差别较多，本文用既有繁侯一支定位，不随意补安国的姓或凶手。

**R137：** 元光三年勃承爵两表可互见；末案史表写勃当死而病死，汉表在勃后另列郦平并记免。共同可支持的是元狩元年诈诏取金及失国，正文不把勃与平合成同名人，也不未经证据把两书不同结局写成两个人同案双双死亡。原表缺漏的世代与年次留作专考。

互校：[《汉书》高惠高后文功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-9a935b95e10870) · [《史记》三家注卷018](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7018.md#ref-0f97cb20d9c4e4)。

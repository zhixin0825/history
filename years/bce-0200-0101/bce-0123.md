### 城阳王刘延、广川王刘齐来到朝廷

<a id="event-1"></a>

1. **刘延、刘齐在本年分别入朝。** 城阳这一支来自刘章，刘延接续父亲刘喜；广川的刘齐则是景帝之子刘越的后嗣。朝见使地方王室与中央保持往来，但短短一条记录没有留下具体议题、行程或赏赐。 [[1]](#note-1)

### 赵信降匈奴，苏建败归失爵

<a id="event-3"></a>

3. **赵信降匈奴，苏建败归失爵。** 卫青再次北征，赵信与苏建所部遭遇匈奴主力而溃败。赵信带余众降匈奴；苏建独自逃回，被判当斩，赎免后降为庶人、失去侯国。两人的退路与最后处置并不相同。 [[3]](#note-3)

<a id="sj020-e016"></a>
<a id="随军将领再次增封"></a>
### 随军将领再次增封

<a id="event-4"></a>

4. **随军将领再次增封。** 岸头侯张次公、合骑侯公孙敖随大将军出征，分别获增加封邑。增封是在原侯爵上的奖励，并不是另立两个同名侯国。 [[4]](#note-4)

<a id="sj020-e040"></a>
<a id="张骞封博望侯"></a>
### 张骞封博望侯

<a id="event-5"></a>

5. **张骞封博望侯。** 张骞随军熟悉水草、行军条件，又有此前远使大夏的功劳，受封博望侯。出使绝域的经历在封侯以前，不能把多年羁留和归程都塞进本年。 [[5]](#note-5)

<a id="sj020-e041"></a>
<a id="霍去病封冠军侯"></a>
### 霍去病封冠军侯

<a id="event-6"></a>

6. **霍去病封冠军侯。** 霍去病以剽姚校尉随卫青北征，率精骑深入匈奴军后，获得俘斩，受封冠军侯。初出战场的军功，使他迅速取得独立领兵的地位。 [[6]](#note-6)

<a id="sj020-e042"></a>
<a id="郝贤封众利侯"></a>
### 郝贤封众利侯

<a id="event-7"></a>

7. **郝贤封众利侯。** 上谷太守郝贤多次随卫青出征，以获首虏千级以上的军功封众利侯。 [[7]](#note-7)

<a id="sj021"></a>
<a id="王子分邑与侯国的接续"></a>
### 王子分邑与侯国的接续

<a id="event-8"></a>

**诸侯王的子弟陆续分得侯邑；成为列侯和继承整个王国是不同的安排。** 各支受封与后来的传爵、失国分别记年。 [原编读注](#note-8)

<a id="sj021-r134-e01"></a>

<a id="event-9"></a>

8. **終弋侯一支受封。** 衡山王賜子刘廣置受封为終弋侯。 [[8]](#note-9)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-10"></a>

9. **卫青两次从定襄出击，诸将分为中、左、后、前、右及强弩各部。** 赵信所部败后降匈奴，苏建军败而本人逃回；两人的结局不同。 [[9]](#note-10)

<a id="sj030-military-rank-event"></a>

10. **六月，朝廷议设武功赏官，把买爵、赎罪与军需筹资联系起来。** 连年出兵与赏赐耗去旧藏，有司建议以武功爵吸收财物，并允许有关爵级者试补吏、减罪。军功奖励与财力进入官场的渠道由此交织，司马迁同时批评官职选任受到损耗。 [[10]](#sj030-military-rank-note)

<a id="sj030-military-rank-note"></a>

### 10. 六月，朝廷议设武功赏官，把买爵、赎罪与军需筹资联系起来

[返回正文第10条](#sj030-military-rank-event)

**[《史记·平准书》P009](../../sources/摘录/史记-卷030-平准书.md#p009)**

> 其後四年，而漢遣大將將六將軍，軍十餘萬，擊右賢王，獲首虜萬五千級。明年，大將軍將六將軍仍再出擊胡，得首虜萬九千級。捕斬首虜之士受賜黃金二十餘萬斤，虜數萬人皆得厚賞，衣食仰給縣官；而漢軍之士馬死者十餘萬，兵甲之財轉漕之費不與焉。於是大農陳藏錢經秏，賦稅既竭，猶不足以奉戰士。有司言：「天子曰『朕聞五帝之教不相復而治，禹湯之法不同道而王，所由殊路，而建德一也。北邊未安，朕甚悼之。日者，大將軍攻匈奴，斬首虜萬九千級，留蹛無所食。議令民得買爵及贖禁錮免減罪』。請置賞官，命曰武功爵。級十七萬，凡直三十餘萬金。諸買武功爵官首者試補吏，先除；千夫如五大夫；其有罪又減二等；爵得至樂卿：以顯軍功。」軍功多用越等，大者封侯卿大夫，小者郎吏。吏道雜而多端，則官職秏廢。

**[《汉书》互校 ann123](../../sources/摘录/史记-卷030-汉书互校.md#ann123)**

> 六月，詔曰：「朕聞五帝不相復禮，三代不同法，所繇殊路而建德一也。蓋孔子對定公以徠遠，哀公以論 臣，景公以節用，非期不同，所急異務也。今中國一統而北邊未安，朕甚悼之。日者大將軍巡朔方，征匈奴，斬首虜萬八千級，諸禁錮及有過者，咸蒙厚賞，得免減 罪。今大將軍仍復克獲，斬首虜萬九千級，受爵賞而欲移賣者，無所流貤。其議為令。」有司奏請置武功賞官，以寵戰士。

“级十七万、凡直三十余万金”的价格结构与爵级解释并非无争议，详见本卷数量核对，不据此编出确定价目表。

#### 卷018｜原格、异年与本页采用

**逐格定位：** <a id="sj018-r041-wu"></a>[R041](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r041)。

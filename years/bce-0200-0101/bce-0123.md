**汉武帝元朔六年**

<a id="sj017-audience"></a>
## 城阳王刘延、广川王刘齐来到朝廷

**刘延、刘齐在本年分别入朝。** 城阳这一支来自刘章，刘延接续父亲刘喜；广川的刘齐则是景帝之子刘越的后嗣。朝见使地方王室与中央保持往来，但短短一条记录没有留下具体议题、行程或赏赐。[原文与说明](#sj017-note)

## 军政、受封与侯国的接续

<a id="sj020-e015"></a>
### 赵信降匈奴，苏建败归失爵

卫青再次北征，赵信与苏建所部遭遇匈奴主力而溃败。赵信带余众降匈奴；苏建独自逃回，被判当斩，赎免后降为庶人、失去侯国。两人的退路与最后处置并不相同。 [原文与说明](#sj020-e015-n)

<a id="sj020-e016"></a>
### 随军将领再次增封

岸头侯张次公、合骑侯公孙敖随大将军出征，分别获增加封邑。增封是在原侯爵上的奖励，并不是另立两个同名侯国。 [原文与说明](#sj020-e016-n)

<a id="sj020-e040"></a>
### 张骞封博望侯

张骞随军熟悉水草、行军条件，又有此前远使大夏的功劳，受封博望侯。出使绝域的经历在封侯以前，不能把多年羁留和归程都塞进本年。 [原文与说明](#sj020-e040-n)

<a id="sj020-e041"></a>
### 霍去病封冠军侯

霍去病以剽姚校尉随卫青北征，率精骑深入匈奴军后，获得俘斩，受封冠军侯。初出战场的军功，使他迅速取得独立领兵的地位。 [原文与说明](#sj020-e041-n)

<a id="sj020-e042"></a>
### 郝贤封众利侯

上谷太守郝贤多次随卫青出征，以获首虏千级以上的军功封众利侯。 [原文与说明](#sj020-e042-n)

<a id="sj021"></a>
## 王子分邑与侯国的接续

诸侯王的子弟陆续分得侯邑；成为列侯和继承整个王国是不同的安排。各支受封与后来的传爵、失国分别记年。

<a id="sj021-r134-e01"></a>
**終弋侯一支受封。** 衡山王賜子刘廣置受封为終弋侯。 [原文与说明](#sj021-r134-e01-n)

<a id="sj018-note"></a>
### 卷018｜原格、异年与本页采用

**逐格定位：** <a id="sj018-r041-wu"></a>[R041](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r041)。

本页按原格中明确年号、承袭次序及互见材料分别定位；未载月份的不补日期，元年也不一律倒推父亲死年。侯爵与所任中央官职不是同一继承关系。

**R041：** 此为芒侯一行后来复封为张侯的耏氏支系，不是毛泽一支的张侯；申承侯以后至元朔六年的免爵另成一事。罪状细节未载，不补写公主与他的私人争执。

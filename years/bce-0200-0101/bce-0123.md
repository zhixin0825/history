<a id="event-1"></a>

1. **城阳王刘延、广川王刘齐来到朝廷。** 刘延、刘齐在本年分别入朝。 城阳这一支来自刘章，刘延接续父亲刘喜；广川的刘齐则是景帝之子刘越的后嗣。朝见使地方王室与中央保持往来，但短短一条记录没有留下具体议题、行程或赏赐。 [[1]](#note-1)

3. **赵信降匈奴，苏建败归失爵。** 卫青再次北征，赵信与苏建所部遭遇匈奴主力而溃败。赵信带余众降匈奴；苏建独自逃回，被判当斩，赎免后降为庶人、失去侯国。两人的退路与最后处置并不相同。 [[3]](#note-3)

<a id="sj020-e016"></a>
<a id="随军将领再次增封"></a>


<a id="event-4"></a>

4. **随军将领再次增封。** 岸头侯张次公、合骑侯公孙敖随大将军出征，分别获增加封邑。增封是在原侯爵上的奖励，并不是另立两个同名侯国。 [[4]](#note-4)

<a id="sj020-e040"></a>
<a id="张骞封博望侯"></a>


<a id="event-5"></a>

5. **张骞封博望侯。** 张骞随军熟悉水草、行军条件，又有此前远使大夏的功劳，受封博望侯。出使绝域的经历在封侯以前，不能把多年羁留和归程都塞进本年。 [[5]](#note-5)

<a id="sj020-e041"></a>
<a id="霍去病封冠军侯"></a>


<a id="event-6"></a>

6. **霍去病封冠军侯。** 霍去病以剽姚校尉随卫青北征，率精骑深入匈奴军后，获得俘斩，受封冠军侯。初出战场的军功，使他迅速取得独立领兵的地位。 霍去病的母亲卫少儿是卫皇后的姐姐；他与舅父卫青及卫青三子的侯爵，合为卫氏枝属五支。骠骑将军的任命则在以后。 [[6]](#note-6)

<a id="sj020-e042"></a>
<a id="郝贤封众利侯"></a>


<a id="event-7"></a>

7. **郝贤封众利侯。** 上谷太守郝贤多次随卫青出征，以获首虏千级以上的军功封众利侯。 [[7]](#note-7)

**诸侯王的子弟陆续分得侯邑；成为列侯和继承整个王国是不同的安排。** 各支受封与后来的传爵、失国分别记年。 [原编读注](#note-8)

<a id="sj021-r134-e01"></a>

<a id="event-9"></a>

8. **終弋侯一支受封。** 衡山王賜子刘廣置受封为終弋侯。 [[8]](#note-9)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-10"></a>

9. **卫青两次从定襄出击，诸将分为中、左、后、前、右及强弩各部。** 赵信所部败后降匈奴，苏建军败而本人逃回；两人的结局不同。 李广以郎中令任后将军随军，所部未获可受封的军功。 [[9]](#note-10)

<a id="sj030-military-rank-event"></a>

10. **六月，朝廷议设武功赏官，把买爵、赎罪与军需筹资联系起来。** 连年出兵与赏赐耗去旧藏，有司建议以武功爵吸收财物，并允许有关爵级者试补吏、减罪。军功奖励与财力进入官场的渠道由此交织，司马迁同时批评官职选任受到损耗。 [[10]](#sj030-military-rank-note)

<a id="sj103-event-11"></a>

11. **石建去世，李广接任郎中令。** 《史记》《汉书》的石氏传写石建在父亲去世一年多后亦死。《汉书·李广传》把李广接任置于元朔六年出定襄以前。《将相名臣年表》同年已称李广为郎中令，确切月日未见。 [[11]](#note-11)

<a id="sj118-event-12"></a>

12. **庄芷代淮南王孙刘建上书，案情牵及太子刘迁。** 刘建知道太子曾谋杀汉中尉，借同乡庄芷向武帝上书。廷尉转交河南审理，审卿又通过丞相公孙弘追索旧怨，刘建供词牵及刘迁及党羽。《汉书》将庄芷记作严正。 [[12]](#note-12)

<a id="sj118-event-13"></a>

13. **衡山王刘赐经过淮南，与刘安暂释嫌隙。** 衡山王过淮南，刘赐与刘安暂解旧嫌，约定为起事做准备；刘赐上书称病，获准免朝。 [[13]](#note-13)

<a id="sj118-event-14"></a>

14. **刘赐请废刘爽立刘孝，衡山储位争执进入官府。** 衡山王刘赐请求改立太子。刘爽遣白嬴去长安反告刘孝，白嬴未奏即因淮南事被捕；刘赐又告刘爽，朝廷将案下交沛郡。 [[14]](#note-14)

<a id="hs-event-15"></a>

15. **芒侯耏跖｜获罪。** 表载芒侯耏跖一支本年载相关罪案及处分。表中所载事项为因罪案尚南宫公主不敬，失爵。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **江阳康侯苏息｜承爵。** 表载江阳康侯苏息一支本年记载侯位承袭。表中所载事项为侯雕承爵。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **合骑侯公孙敖｜增封。** 表载合骑侯公孙敖一支本年获增食邑。表中所载事项为从大将军，益封，九千五百户。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **博望侯张骞｜受封。** 《汉书》侯籍列博望侯张骞本年受封，所引月份、干支依表保留。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **衆利侯郝贤｜受封。** 《汉书》侯籍列衆利侯郝贤本年受封，所引月份、干支依表保留。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **冠军景桓侯霍去病｜受封。** 《汉书》侯籍列冠军景桓侯霍去病本年受封，所引月份、干支依表保留。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[21]](#hs-note-21)

### 3. 赵信降匈奴，苏建败归失爵

[返回正文第3条](#event-3)

<a id="hs006-l394-e3"></a>

**[《汉书·武帝纪》P076](../../sources/摘录/汉书-卷006-武帝纪.md#p076)** · [仓内TXT L394](../../sources/本地分卷/汉书/汉书-卷006.md#L394)

> 前將軍趙信軍敗，降匈奴。右將軍蘇建亡軍，獨身脫還，贖為庶人。

<a id="sj110-p035-e3"></a>

**[《史记·匈奴列传》P035](../../sources/摘录/史记-卷110-匈奴列传.md#p035)** · [三家注](../../sources/史记三家注/卷110.md#p35)

> 而漢亦亡兩將軍，軍三千餘騎。右將軍建得以身脫，而前將軍翕侯趙信兵不利，降匈奴。趙信者，故胡小王，降漢，漢封爲翕侯，以前將軍與右將軍并軍分行，獨遇單于兵，故盡沒。單于旣得翕侯，以爲自次王，用其姊妻之，與謀漢。信教單于益北絕幕，以誘罷漢兵，徼極而取之，無近塞。單于從其計。

**本卷归年说明：** “亡兩將軍”指两将所部损失，苏建本人归汉。赵信再次投匈奴及其建议与该战相续，不详受任确日。

<a id="sj111-p006-e3"></a>

**[《史记·卫将军骠骑列传》P006](../../sources/摘录/史记-卷111-卫将军骠骑列传.md#p006)** · [三家注](../../sources/史记三家注/卷111.md#p6)

> 右將軍建、前將軍信并軍三千餘騎，獨逢單于兵，與戰一日餘，漢兵且盡。前將軍故胡人，降爲翕侯，見急，匈奴誘之，遂將其餘騎可八百，犇降單于。右將軍蘇建盡亡其軍，獨以身得亡去，自歸大將軍。大將軍問其罪正閎、長史安、議郎周霸等：「建當云何？」霸曰：「自大將軍出，未嘗斬裨將。今建弃軍，可斬以明將軍之威。」閎、安曰：「不然。兵法『小敵之堅，大敵之禽也』。今建以數千當單于數萬，力戰一日餘，士盡，不敢有二心，自歸。自歸而斬之，是示後無反意也。不當斬。」大將軍曰：「青幸得以肺腑待罪行間，不患無威，而霸說我以明威，甚失臣意。且使臣職雖當斬將，以臣之尊寵而不敢自擅專誅於境外，而具歸天子，天子自裁之，於是以見爲人臣不敢專權，不亦可乎？」軍吏皆曰「善」。遂囚建詣行在所。入塞罷兵。

**本卷归年说明：** 失军、赵信降敌、苏建主动归军及朝廷最终裁决为相接阶段，不把军官建议写成已经执行。

<a id="sj111-p007-e3"></a>

**[《史记·卫将军骠骑列传》P007](../../sources/摘录/史记-卷111-卫将军骠骑列传.md#p007)** · [三家注](../../sources/史记三家注/卷111.md#p7)

> 是歲，失兩將軍軍，亡翕侯，軍功不多，故大將軍不益封。右將軍建至，天子不誅，赦其罪，贖爲庶人。

**本卷归年说明：** 武帝免苏建死刑后准赎，卫青本人没有追加封邑。

<a id="sj111-p033"></a>

**[《史记·卫将军骠骑列传》P033](../../sources/摘录/史记-卷111-卫将军骠骑列传.md#p033)** · [三家注](../../sources/史记三家注/卷111.md#p33)

**本卷归年说明：** 失军与降敌不是苏建的同一行动，降者赵信；苏建返汉受处分。

### 6. 霍去病封冠军侯

[返回正文第6条](#event-6)

<a id="sj111-p007-e6"></a>

**[《史记·卫将军骠骑列传》P007](../../sources/摘录/史记-卷111-卫将军骠骑列传.md#p007)** · [三家注](../../sources/史记三家注/卷111.md#p7)

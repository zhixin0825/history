### 雷被的控告使淮南王受追究

<a id="event-1"></a>

1. **淮南属官雷被向中央告状，朝廷开始追查刘安阻挠出征等事。** 雷被曾与太子刘迁比剑，伤到太子，双方因此结怨；他请求随军击匈奴，却失去官职，后来逃到长安上书。朝廷调查以后，有司提出严厉处置，武帝没有批准处死、废王，最后削去淮南两县。 [[1]](#note-1)

<a id="event-2"></a>

2. **刘安仍保有王位，但与朝廷之间的紧张没有消失。** 这次削地不是两年后淮南国终结的那次案件；把两个阶段合在一起，会看不出控告、审理和最后覆亡之间的变化。 [[2]](#note-2)

<a id="sj017-audience"></a>

<a id="event-3"></a>

3. **胶东王刘寄、常山王刘舜入朝。** 他们都是景帝之子，本次朝见与淮南案并列在同一年，不表示两人也被削国。 [[3]](#note-3)

### 击破右贤王后，卫青和苏建增封

<a id="event-8"></a>

8. **击破右贤王后，卫青和苏建增封。** 卫青率军击破匈奴右贤王部，增加三千户封邑；苏建这次以游击将军从征，也获增封。卫青在这轮出兵中升为大将军，所辖部队的将领相继受赏。 [[8]](#note-8)

<a id="sj020-e006"></a>

### 亲阳侯月氏被处死

<a id="event-9"></a>

9. **亲阳侯月氏被处死。** 月氏被以逃亡之罪处斩，亲阳侯国撤销。 [[9]](#note-9)

<a id="sj020-e008"></a>

### 若阳侯猛被处死

<a id="event-10"></a>

10. **若阳侯猛被处死。** 猛被以逃亡之罪处斩，若阳侯国撤销。 [[10]](#note-10)

<a id="公孙弘以丞相身份封平津侯"></a>
### 公孙弘以丞相身份封平津侯

<a id="event-11"></a>

11. **公孙弘以丞相身份封平津侯。** 公孙弘由儒生进入朝廷，历任重要官职，出任丞相并封平津侯。封侯的理由不只战功，也包括皇帝对丞相职任的褒奖。 [[11]](#note-11)

<a id="sj020-e030"></a>
<a id="公孙贺封南奅侯"></a>
### 公孙贺封南奅侯

<a id="event-12"></a>

12. **公孙贺封南奅侯。** 公孙贺以骑将军随卫青击匈奴、俘获敌王，受封南奅侯。多年以后他还会任丞相，那个新职和新侯号不能提前。 [[12]](#note-12)

<a id="event-13"></a>

<a id="event-14"></a>

<a id="sj020-e037"></a>

### 卫伉封宜春侯

<a id="event-19"></a>

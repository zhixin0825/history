**汉武帝元朔五年**

<a id="sj017-huainan"></a>
## 雷被的控告使淮南王受追究

**淮南属官雷被向中央告状，朝廷开始追查刘安阻挠出征等事。** 雷被曾与太子刘迁比剑，伤到太子，双方因此结怨；他请求随军击匈奴，却失去官职，后来逃到长安上书。朝廷调查以后，有司提出严厉处置，武帝没有批准处死、废王，最后削去淮南两县。[原文与说明](#sj017-note)

**刘安仍保有王位，但与朝廷之间的紧张没有消失。** 这次削地不是两年后淮南国终结的那次案件；把两个阶段合在一起，会看不出控告、审理和最后覆亡之间的变化。[原文与说明](#sj017-note)

<a id="sj017-audience"></a>
**胶东王刘寄、常山王刘舜入朝。** 他们都是景帝之子，本次朝见与淮南案并列在同一年，不表示两人也被削国。[原文与说明](#sj017-note)

## 军政、受封与侯国的接续

<a id="sj020-e012"></a>
### 击破右贤王后，卫青和苏建增封

卫青率军击破匈奴右贤王部，增加三千户封邑；苏建这次以游击将军从征，也获增封。卫青在这轮出兵中升为大将军，所辖部队的将领相继受赏。 [原文与说明](#sj020-e012-n)

<a id="sj020-e006"></a>
### 亲阳侯月氏被处死

月氏被以逃亡之罪处斩，亲阳侯国撤销。 [原文与说明](#sj020-e006-n)

<a id="sj020-e008"></a>
### 若阳侯猛被处死

猛被以逃亡之罪处斩，若阳侯国撤销。 [原文与说明](#sj020-e008-n)

<a id="sj020-e018"></a>
### 公孙弘以丞相身份封平津侯

公孙弘由儒生进入朝廷，历任重要官职，出任丞相并封平津侯。封侯的理由不只战功，也包括皇帝对丞相职任的褒奖。 [原文与说明](#sj020-e018-n)

<a id="sj020-e030"></a>
### 公孙贺封南奅侯

公孙贺以骑将军随卫青击匈奴、俘获敌王，受封南奅侯。多年以后他还会任丞相，那个新职和新侯号不能提前。 [原文与说明](#sj020-e030-n)

<a id="sj020-e031"></a>
### 公孙敖封合骑侯

公孙敖以护军都尉多次随军，参加深入右贤王庭的行动，因军功封合骑侯。 [原文与说明](#sj020-e031-n)

<a id="sj020-e032"></a>
### 李蔡封乐安侯

李蔡以轻车将军从征，因战功封乐安侯；李广的亲族关系与其本人军功是两层事实。 [原文与说明](#sj020-e032-n)

<a id="sj020-e033"></a>
### 韩说封龙额侯

韩说以都尉随卫青作战，因俘获敌王等军功封龙额侯。 [原文与说明](#sj020-e033-n)

<a id="sj020-e034"></a>
### 赵不虞封随城侯

赵不虞以校尉多次从征，在攻取险地时先登，获得随城侯爵。 [原文与说明](#sj020-e034-n)

<a id="sj020-e035"></a>
### 公孙戎奴封从平侯

公孙戎奴以校尉参加深入右贤王部的行动，在登山进攻中立功，受封从平侯。 [原文与说明](#sj020-e035-n)

<a id="sj020-e036"></a>
### 李朔封涉轵侯

李朔以校尉多次随卫青出征，深入右贤王庭，俘获敌王及阏氏等，受封涉轵侯。 [原文与说明](#sj020-e036-n)

<a id="sj020-e037"></a>
### 卫伉封宜春侯

卫青之子卫伉因父亲的军功受封宜春侯。这是功及子弟的奖赏，不能给孩子编造亲自率军获胜的经历。 [原文与说明](#sj020-e037-n)

<a id="sj020-e038"></a>
### 卫不疑封阴安侯

卫青之子卫不疑因父亲的军功受封阴安侯。这是功及子弟的奖赏，不能给孩子编造亲自率军获胜的经历。 [原文与说明](#sj020-e038-n)

<a id="sj020-e039"></a>
### 卫登封发干侯

卫青之子卫登因父亲的军功受封发干侯。这是功及子弟的奖赏，不能给孩子编造亲自率军获胜的经历。 [原文与说明](#sj020-e039-n)

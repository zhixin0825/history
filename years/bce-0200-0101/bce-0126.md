<a id="event-52"></a>

16. **公孙弘由左内史升任御史大夫。** 他还没有成为丞相；在北方，匈奴入侵代郡，代太守友遇害。 前任张欧因老病告退。 [[16]](#note-52)

<a id="sj049-wangtaihou-death-event"></a>

17. **六月庚午，王皇太后去世。** 武帝的母亲王氏去世后，与景帝合葬阳陵。其母臧儿先嫁王仲、后嫁田氏：王信是王太后的同父兄，田蚡、田胜是她的同母异父弟，三人先后受侯；她本人死亡与这些亲属此前获得爵位、园邑奉祀是不同事件。 [[17]](#sj049-wangtaihou-death-note)

<a id="sj112-event-53"></a>

18. **朝廷罢沧海郡，边事转重朔方。** 公孙弘认为西南夷、沧海和朔方同时经营耗费太重，请停止。朱买臣等陈说朔方可守，他于是改请停止沧海及西南夷方向的经营，把力量集中在朔方。武帝采纳，春罢沧海郡。 [[18]](#note-53)

<a id="sj122-event-54"></a>

19. **张汤升任廷尉。** 张汤由中大夫迁廷尉，奏讞疑狱，任用文学与刀笔吏。 [[19]](#note-54)

<a id="sj123-event-55"></a>

20. **张骞结束首次出使，归汉受任。** 匈奴单于继位内乱，张骞和堂邑父及张骞的胡妻趁机逃回。张骞拜太中大夫，堂邑父为奉使君。张骞陈报大宛、大月氏、大夏、康居等地见闻。 [[20]](#note-55)

<a id="hs-event-56"></a>

21. **三月以教化为由大赦。** 诏书申明刑罚和教化各有作用，并宣布大赦。 [[21]](#hs-note-56)

<a id="hs-event-57"></a>

22. **匈奴攻代与雁门。** 夏季匈奴入代杀太守，又入雁门，杀掠千余人。 [[22]](#hs-note-57)

<a id="hs-event-58"></a>

23. **五据侯曜丘受封。** 济北式王子五据侯曜丘受封。 [[23]](#hs-note-58)

<a id="hs-event-59"></a>

24. **蓼夷侯孔聚｜获罪。** 表载蓼夷侯孔聚一支本年载相关罪案及处分。表中所载事项为因罪案为太常衣冠道桥坏不得度，失爵。 [[24]](#hs-note-59)

<a id="hs-event-60"></a>

25. **昌武靖信侯单究｜获罪。** 表载昌武靖信侯单究一支本年载相关罪案及处分。表中所载事项为因罪案伤人二旬内死，被处死。 [[25]](#hs-note-60)

<a id="hs-event-61"></a>

26. **容城携侯徐卢｜承爵。** 表载容城携侯徐卢一支本年记载侯位承袭。表中所载事项为侯光承爵。 [[26]](#hs-note-61)

<a id="hs-event-62"></a>

27. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[27]](#hs-note-62)

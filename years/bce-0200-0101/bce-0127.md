<a id="正月允许诸侯把封邑分给其他子弟"></a>
### 正月，允许诸侯把封邑分给其他子弟

<a id="event-1"></a>

1. **朝廷允许诸侯王提出分封子弟的名单与土地，由皇帝审定名号。** 过去王位主要由嫡嗣承接，其他子弟未必得到土地。主父偃向武帝提出，让他们以恩惠名义分得侯邑，比直接大规模削地更不易激起反抗，又能逐渐缩小大王国。 [[1]](#note-1)

<a id="event-2"></a>

2. **梁、城阳两国想为同母兄弟分邑，得到准许。** 这项措施后来通常称为推恩令。名义是王室内部照顾亲属，实际也让越来越多的封邑进入由朝廷确认的秩序；不是准许各王不经批准随意把土地送出。 [[2]](#note-2)

<a id="sj017-yan"></a>
<a id="燕王刘定国被追究燕国被撤销"></a>
### 燕王刘定国被追究，燕国被撤销

<a id="event-3"></a>

3. **燕王刘定国因杀害地方官及王室失伦等案受追究，最终自杀。** 被害者的亲属上书告发，主父偃也参与揭发，公卿请求诛王，皇帝准许。王死后没有另立继承人，燕国改入中央管辖。 [[3]](#note-3)

<a id="sj017-qi"></a>
<a id="齐王被逼入绝境主父偃随后也获罪"></a>
### 齐王被逼入绝境，主父偃随后也获罪

<a id="event-4"></a>

4. **主父偃到齐国任相，紧迫查办齐王刘次昌后宫的案件。** 供词牵涉齐王，刘次昌恐惧而饮药自杀。齐王无后，王国被撤销。 [[4]](#note-4)

<a id="event-5"></a>

5. **主父偃没有因齐国归汉而免于追究。** 赵王刘彭祖另告他收受诸侯财物。主父偃承认受财，却否认逼王自杀；武帝本来不想处死他，公孙弘认为不诛不足以向天下交代，最后主父偃及家族遭诛。封国收归中央、查案者被追责，是同一政治过程中的不同结果。 [[5]](#note-5)

<a id="sj017-succession"></a>
<a id="江都长沙由新一代接掌另有两王入朝"></a>
### 江都、长沙由新一代接掌，另有两王入朝

<a id="event-6"></a>

6. **江都刘建、长沙刘庸开始新的王年。** 父辈的去世已在[前128年](bce-0128.md#sj017-three-kings)记录。刘建是江都王刘非之子，不能与淄川王刘建或已故燕灵王刘建混为一人。 [[6]](#note-6)

<a id="event-7"></a>

7. **胶西王刘端、梁王刘襄入朝。** 冬季朝廷又赐淮南、淄川两王几杖，免去入朝要求。这些来朝和优免记录与废国案各有对象，并不意味着所有诸侯同时受到同一种待遇。 [[7]](#note-7)

### 1. 朝廷允许诸侯王提出分封子弟的名单与土地，由皇帝审定名号

[返回正文第1条](#event-1)

**[卷017表序P003](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#p003)**

> 漢定百年之閒，親屬益疏，諸侯或驕奢，忕邪臣計謀為淫亂，大者叛逆，小者不軌于法，以危其命，殞身亡國。天子觀於上古，然後加惠，使諸侯得推恩分子弟國邑，故齊分為七，趙分為六，梁分為五，淮南分三，及天子支庶子為王，王子支庶為侯，百有餘焉。吳楚時，前后諸侯或以適削地，是以燕、代無北邊郡，吳、淮南、長沙無南邊郡，齊、趙、梁、楚支郡名山陂海咸納於漢。諸侯稍微，大國不過十餘城，小侯不過數十里，上足以奉貢職，下足以供養祭祀，以蕃輔京師。而漢郡八九十，形錯諸侯閒，犬牙相臨，秉其阸塞地利，彊本干，弱枝葉之勢，尊卑明而萬事各得其所矣。

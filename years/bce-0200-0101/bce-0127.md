<a id="正月允许诸侯把封邑分给其他子弟"></a>

<a id="event-1"></a>

1. **正月，允许诸侯把封邑分给其他子弟。** 朝廷允许诸侯王提出分封子弟的名单与土地，由皇帝审定名号。 过去王位主要由嫡嗣承接，其他子弟未必得到土地。主父偃向武帝提出，让他们以恩惠名义分得侯邑，比直接大规模削地更不易激起反抗，又能逐渐缩小大王国。 [[1]](#note-1)

<a id="event-2"></a>

2. **梁、城阳两国请求为同母兄弟分邑，得到准许。** 这道诏书明确把其他诸侯王的分邑请求也交由皇帝审定。主父偃首次献策的时间另有异说，见[王子侯表考证](../../meta/考证/史记-卷021-纪年与异说.md#推恩)。 [[2]](#note-2)

<a id="sj017-yan"></a>
<a id="燕王刘定国被追究燕国被撤销"></a>

<a id="event-3"></a>

3. **燕王刘定国被追究，燕国被撤销。** 刘定国是刘泽之孙、燕康王刘嘉之子。《荆燕世家》指述其在位时与父姬生子、夺弟妻为姬、与三个女儿失伦，又记肥如令郢人等告发后，刘定国使谒者另借罪名捕杀郢人灭口。郢人的兄弟随后上书，主父偃也参与揭发；公卿以败坏人伦等理由请求处死，皇帝批准，刘定国自杀，燕国改入中央管辖。前情各有先后而未详确年，本篇元朔元年与本纪元朔二年的年差也保留在同号注。 [[3]](#note-3)

<a id="sj017-qi"></a>
<a id="齐王被逼入绝境主父偃随后也获罪"></a>

<a id="event-4"></a>

4. **主父偃任齐相查办后宫案，齐王刘次昌恐惧自杀、无后国除。** 齐厉王的母亲是纪太后，她选自己弟弟的女儿为齐王后，齐王却不喜爱这位纪氏女。纪太后想加强娘家的宠幸与地位，让自己的长女纪翁主进入王宫整顿后宫，阻止别的女子亲近齐王，迫使他转爱纪氏女。篇中记齐王反而与亲姊纪翁主私通。这是传记叙述及后案的指控背景，不能另作已经独立核实的宫闱事实。翁主是诸侯王女的称呼，古注解释其随母家称纪，并不因此把她认作纪氏家的外甥女。 齐地宦官徐甲入侍汉皇太后；这位太后是武帝的母亲王氏，不是齐国纪太后。她疼爱女儿修成君，修成君是她前嫁金氏所生，并非刘氏皇女。修成君有女名娥，太后想把外孙女嫁给诸侯。徐甲自请去齐，说一定让齐王上书求娶，太后高兴派他前往。齐人主父偃知道此事，也托徐甲：若婚事成了，请说自己的女儿愿进齐王后宫。徐甲抵齐，委婉提出婚议，纪太后大怒：“王已经有王后，后宫也全备。徐甲原是齐国穷人，困窘才做宦者进汉宫，不曾有益，反要乱我王家！主父偃又是什么人，竟想让女儿入宫！”徐甲无话可答，回报汉太后说齐王愿娶娥，但有一项妨碍，恐怕会像燕王。篇中以燕王与子女、兄弟关系内的淫乱案件、近来获罪死去并失国，解释徐甲为何用燕案触动太后；具体亲属关系应同《荆燕世家》对读，不能把含混短语自行扩写成另一个案件。太后于是说，不要再提嫁女去齐。主TXT“事浸潯［不得］聞於天子”保留‘不得’补字，注本也写不得；汉传则说事情渐渐传到皇帝处，两种见证相反，不能默默统一。主父偃也由此与齐结怨。婚议缺少独立年月，只能作为齐案前情，不凭‘燕王新死’另造确年。 主父偃正受皇帝宠信、掌权，便进言说：“齐都临淄有十万户，市场租税千金，人众富足，比长安还大；这样的地方，非天子的亲弟、爱子不该封王，而今齐王同天子的亲属关系越来越疏。”又趁从容谈话说，吕后时齐曾想反叛，吴楚之乱时齐孝王也几乎作乱，如今听说齐王与姊私通。于是皇帝任他为齐相，让他整治、查明这些事情。主父偃到齐后，紧急审讯曾替齐王通往姊姊纪翁主处的后宫宦官，让他们的供词、证言都牵连齐王。王年少，害怕犯重罪被官吏拘执处死，就喝毒药自杀，身后没有继承人。人口、租额、旧日叛乱与宫闱行为，在此均是主父偃用来推动处置的陈述与查案材料，不写成编者逐项验证的事实。 本篇厉王名次景，年表、汉传作次昌；前131元年至本年共五个王年。上述家庭安排和求婚交涉是本案前情，原文没有给出各自确年。 主父偃到齐后还召来旧日亲友，分给五百金并与他们绝交。 [[4]](#note-4)

<a id="event-5"></a>

5. **主父偃没有因齐国归汉而免于追究。** 赵王刘彭祖见他一出使便使齐王国覆亡，害怕继续疏远皇室骨肉，告发他收受钱财及处置轻重失当。主父偃承认受财，否认逼王自杀；武帝原不欲处死他，公孙弘却说齐王忧惧而死、无后国入汉，不杀偃不足以满足天下要求交代的期待。最终主父偃及家族遭诛。赵王的动机、告发、偃的答辩与公孙弘的处置理由各有立场，不能把告发全变成编者独立核实的案情。 本传称減宣奉使治主父偃案。 [[5]](#note-5)

> 匈奴入上谷、漁陽，殺略吏民千餘人。遣將軍衛青、李息出雲中，至高闕，遂西至符離，獲首虜數千級。數河南地，置朔方、五原郡。

**互校说明** 底本“數河南地”原字照录，释义以同卷前后及《史记·匈奴列传》《资治通鉴》所见的略取河南地为据。

<a id="sj110-p031"></a>

**[《史记·匈奴列传》P031](../../sources/摘录/史记-卷110-匈奴列传.md#p031)** · [三家注](../../sources/史记三家注/卷110.md#p31)

> 其明年，衞青復出雲中以西至隴西，擊胡之樓煩、白羊王於河南，得胡首虜數千，牛羊百餘萬。於是漢遂取河南地，築朔方，復繕故秦時蒙恬所爲塞，因河爲固。漢亦弃上谷之什辟縣造陽地以予胡。是歲，漢之元朔二年也。

**本卷归年说明：** 卷111与汉纪同年；“河南”指河套地区。上谷造阳地与筑朔方是同段并记的不同边地措施。

**本卷归年说明：** 元朔二年兵事，河南是河套。李息出代可与上一年韩安国等战事分读。

<a id="sj112-p023"></a>

**[《史记·平津侯主父列传》P023](../../sources/摘录/史记-卷112-平津侯主父列传.md#p023)** · [三家注](../../sources/史记三家注/卷112.md#p23)

> 其後漢將歲以數萬騎出擊胡，及車騎將軍衛青取匈奴河南地，筑朔方。當是時，漢通西南夷道，作者數萬人，千里負擔饋糧，率十餘鐘致一石，散幣於邛僰以集之。數歲道不通，蠻夷因以數攻，吏發兵誅之。悉巴蜀租賦不足以更之，乃募豪民田南夷，入粟縣官，而內受錢於都內。東至滄海之郡，人徒之費擬於南夷。又興十萬餘人筑衛朔方，轉漕甚遼遠，自山東咸被其勞，費數十百巨萬，府庫益虛。乃募民能入奴婢得以終身復，為郎增秩，及入羊為郎，始於此。

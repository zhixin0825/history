# 公元前127年｜推恩分封子弟，燕齐两国又因王室案件被撤销

[← 公元前128年](bce-0128.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前126年 →](bce-0126.md)

**汉武帝元朔二年**

<a id="sj017-tui-en"></a>
## 正月，允许诸侯把封邑分给其他子弟

**朝廷允许诸侯王提出分封子弟的名单与土地，由皇帝审定名号。** 过去王位主要由嫡嗣承接，其他子弟未必得到土地。主父偃向武帝提出，让他们以恩惠名义分得侯邑，比直接大规模削地更不易激起反抗，又能逐渐缩小大王国。[原文与说明](#sj017-policy-note)

**梁、城阳两国想为同母兄弟分邑，得到准许。** 这项措施后来通常称为推恩令。名义是王室内部照顾亲属，实际也让越来越多的封邑进入由朝廷确认的秩序；不是准许各王不经批准随意把土地送出。[原文与说明](#sj017-policy-note)

<a id="sj017-yan"></a>
## 燕王刘定国被追究，燕国被撤销

**燕王刘定国因杀害地方官及王室失伦等案受追究，最终自杀。** 被害者的亲属上书告发，主父偃也参与揭发，公卿请求诛王，皇帝准许。王死后没有另立继承人，燕国改入中央管辖。[原文与说明](#sj017-cases-note)

<a id="sj017-qi"></a>
## 齐王被逼入绝境，主父偃随后也获罪

**主父偃到齐国任相，紧迫查办齐王刘次昌后宫的案件。** 供词牵涉齐王，刘次昌恐惧而饮药自杀。齐王无后，王国被撤销。[原文与说明](#sj017-cases-note)

**主父偃没有因齐国归汉而免于追究。** 赵王刘彭祖另告他收受诸侯财物。主父偃承认受财，却否认逼王自杀；武帝本来不想处死他，公孙弘认为不诛不足以向天下交代，最后主父偃及家族遭诛。封国收归中央、查案者被追责，是同一政治过程中的不同结果。[原文与说明](#sj017-cases-note)

<a id="sj017-succession"></a>
## 江都、长沙由新一代接掌，另有两王入朝

**江都刘建、长沙刘庸开始新的王年。** 父辈的去世已在[前128年](bce-0128.md#sj017-three-kings)记录。刘建是江都王刘非之子，不能与淄川王刘建或已故燕灵王刘建混为一人。[原文与说明](#sj017-kings-note)

**胶西王刘端、梁王刘襄入朝。** 冬季朝廷又赐淮南、淄川两王几杖，免去入朝要求。这些来朝和优免记录与废国案各有对象，并不意味着所有诸侯同时受到同一种待遇。[原文与说明](#sj017-kings-note)

## 军政、受封与侯国的接续

<a id="sj020-e002"></a>
### 赵信随军获增封

赵信随卫青击匈奴，因军功增加封邑。归汉时授爵与此后参加汉军作战所得的奖励是两次安排。 [原文与说明](#sj020-e002-n)

<a id="sj020-e005"></a>
### 月氏封亲阳侯

原为匈奴相的月氏归汉，受封亲阳侯。这里的爵位首先来自归附，不是已记有一场独立的攻城战。 [原文与说明](#sj020-e005-n)

<a id="sj020-e007"></a>
### 猛封若阳侯

原为匈奴相的猛归汉，受封若阳侯。这里的爵位首先来自归附，不是已记有一场独立的攻城战。 [原文与说明](#sj020-e007-n)

<a id="sj020-e009"></a>
### 卫青封长平侯

卫青率军夺取匈奴控制的河南地，取朔方一带，受封长平侯。这里的河南是黄河河套相关区域，不是今天的河南省。 [原文与说明](#sj020-e009-n)

<a id="sj020-e010"></a>
### 苏建封平陵侯

苏建以都尉随卫青出征，因军功封平陵侯。统军的将领之外，分部作战的军官也进入了封赏名单。 [原文与说明](#sj020-e010-n)

<a id="sj020-e011"></a>
### 张次公封岸头侯

张次公同样以都尉随卫青作战，封岸头侯。 [原文与说明](#sj020-e011-n)

<a id="sj017-policy-note"></a>
### 1｜推恩的实际内容与表序的时间跨度

[卷017表序P003](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#p003)概括百年间王国缩小；本年正月的具体诏令、梁城阳分邑与主父偃建言，见[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)及[《通鉴》卷十八](https://zh.wikisource.org/wiki/資治通鑑/卷018)。齐分诸国、淮南分三与梁分五，都在此诏以前；不能说所有分国都由前127年一道命令直接造成，也不能由制度目标断言每个侯国当年已经全部交割。

<a id="sj017-cases-note"></a>
### 2｜燕、齐两案的年代与叙述性质

[卷017前127年齐栏](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0127)只简记王薨无后；燕的终局则在[前128年原格](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0128)。本页采用《汉书·武帝纪》元朔二年秋及《通鉴》同年的燕案，齐案由通鉴与[《齐悼惠王世家》](https://zh.wikisource.org/wiki/史記/卷052)补过程。父后、姊等关系的控罪属于传世案情，本页不添未经核实的私生活细节；不以最终收地反推所有控罪必然真实，也不先验判为全部伪造。

<a id="sj017-kings-note"></a>
### 3｜继承与来朝

[卷017本年江都、胶西、梁栏](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0127)及[汉书诸侯王表长沙条](https://zh.wikisource.org/wiki/漢書/卷014)。长沙庸元年采用汉书，史记前128年和康／戴谥号差别留在前页。几杖、免朝由武帝纪明确列淮南与淄川补入，不能据表无文字便说本年没有此政策。

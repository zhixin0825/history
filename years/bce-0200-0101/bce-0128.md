# 公元前128年｜江都、鲁、长沙三位景帝之子去世

[← 公元前129年](bce-0129.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前127年 →](bce-0127.md)

**汉武帝元朔元年**

<a id="sj017-three-kings"></a>
## 十二月，江都王刘非去世

**江都王刘非去世，封国交到儿子刘建手中。** 刘非原受封汝南，七国之乱时参与军事，后来迁王江都。他与武帝同为景帝之子；现在承接江都的刘建，已是下一代。新王元年见下一年，不与父亲去世合成一次重新建立江都国。[原文与说明](#sj017-note)

**鲁王刘余、长沙王刘发也在本年去世。** 鲁国由刘光承接，长沙由刘庸承接。两位新王各自属于父亲的王国支系，不是从其他国调来同名的新封王。[原文与说明](#sj017-note)

<a id="sj017-chu"></a>
## 楚国进入刘注的纪年

**楚王刘注开始记元年，接续上一年去世的刘道。** 这支楚王世系来自高祖弟刘交，已经不同于汉初曾被迁到楚地的韩信。叙述后来楚王时，不能把几十年前韩信的兵权和封地原封不动套在他们身上。[原文与说明](#sj017-note)

<a id="sj017-audience"></a>
**济北王刘胡入朝。** 他是刘勃的儿子，沿父亲迁到济北后建立的这支王统在位，不是当年七国之乱中的济北王刘志。[原文与说明](#sj017-note)

<a id="sj017-note"></a>
[卷017前128年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0128)列楚注、鲁光、长沙庸元年及济北来朝；[《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006)、[《通鉴》卷十八元朔元年](https://zh.wikisource.org/wiki/資治通鑑/卷018)明记十二月江都非薨，本年鲁余、长沙发皆薨。这里按明确年条安排死亡。月表式元年不能一概倒推父王死于上一年：卷017鲁余薨在前129年、鲁光元年在本年，与本纪有一年差；长沙庸元年本表在本年，汉书王表在前127年，分别保留。

《史记》表称长沙新王为康王，汉书作戴王；正文采用姓名刘庸，不因此造两个继承人。济北刘胡本表称武王、汉书表称成王，亦仅为谥号异文。楚注、鲁光、长沙庸的母亲和童年，本格没有资料，不虚构早年经历。

本表燕栏“定国自杀，国除”虽系本年，《汉书·武帝纪》和《通鉴》明列元朔二年，主叙见[前127年](bce-0127.md#sj017-yan)，不让他死两次。

### 十二月，江都王刘非去世

<a id="event-1"></a>

1. **江都王刘非去世，封国交到儿子刘建手中。** 刘非原受封汝南，七国之乱时参与军事，后来迁王江都。他与武帝同为景帝之子；现在承接江都的刘建，已是下一代。新王元年见下一年，不与父亲去世合成一次重新建立江都国。 [[1]](#note-1)

<a id="event-2"></a>

2. **鲁王刘余、长沙王刘发也在本年去世。** 鲁国由刘光承接，长沙由刘庸承接。两位新王各自属于父亲的王国支系，不是从其他国调来同名的新封王。 [[2]](#note-2)

<a id="sj017-chu"></a>
<a id="楚国进入刘注的纪年"></a>
### 楚国进入刘注的纪年

<a id="event-3"></a>

3. **楚王刘注开始记元年，接续上一年去世的刘道。** 这支楚王世系来自高祖弟刘交，已经不同于汉初曾被迁到楚地的韩信。叙述后来楚王时，不能把几十年前韩信的兵权和封地原封不动套在他们身上。 [[3]](#note-3)

<a id="sj017-audience"></a>

<a id="event-4"></a>

4. **济北王刘胡入朝。** 他是刘勃的儿子，沿父亲迁到济北后建立的这支王统在位，不是当年七国之乱中的济北王刘志。 [[4]](#note-4)

<a id="event-7"></a>

7. **诸侯王的子弟陆续分得侯邑；成为列侯和继承整个王国是不同的安排。** 各支受封与后来的传爵、失国分别记年。 [[7]](#note-7)

<a id="sj021-r012-e01"></a>

<a id="event-13"></a>

13. **秩陽侯一支受封。** 江都易王子刘漣受封为秩陽侯。 [[13]](#note-13)

14. **睢陵侯一支受封。** 江都易王子刘定國受封为睢陵侯。 [[14]](#note-14)

<a id="sj022"></a>

15. **卫子夫被立为皇后。** 北边匈奴侵入辽西、渔阳和雁门，卫青从雁门出击，李息由代郡出兵。韩安国也曾领军守代，后来转屯渔阳。 [[15]](#note-15)

#### 卷022｜将相表互见与异说

《史记》表称长沙新王为康王，汉书作戴王；正文采用姓名刘庸，不因此造两个继承人。济北刘胡本表称武王、汉书表称成王，亦仅为谥号异文。楚注、鲁光、长沙庸的母亲和童年，本格没有资料，不虚构早年经历。

本表燕栏“定国自杀，国除”虽系本年，《汉书·武帝纪》和《通鉴》明列元朔二年，主叙见[前127年](bce-0127.md#sj017-yan)，不让他死两次。

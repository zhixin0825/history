# 公元前130年｜河间王刘德与淄川王刘志去世

**汉武帝元光五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj017-hejian"></a>
<a id="正月河间王刘德去世"></a>

<a id="event-1"></a>

1. **刘德在正月去世，河间王国随后由他的儿子承接。** 刘德是景帝之子，受封以后一直王河间。他在位时以好儒学、求古书见称，详见[河间学术与宾客](未定年-景帝五宗诸王家事.md#sj059-hejian-learning-event)。儿子继承以后，从下一年开始记新王元年。 [[1]](#note-1)

<a id="sj017-zichuan"></a>
<a id="淄川王刘志也去世了"></a>

<a id="event-2"></a>

2. **淄川王刘志也去世了。** 刘志去世，儿子刘建接续王位。 刘志出自齐悼惠王刘肥一支，最初受封济北，七国之乱时没有随叛军行动，后来迁王淄川。他在表中的三十五年，是从最初受封连续计算，并不是迁到淄川以后又过了三十五年。 [[2]](#note-2)

<a id="sj017-audience"></a>

<a id="event-3"></a>

3. **城阳王刘延入朝，河间栏也保留刘德来朝的一条记录。** 朝见与死亡并存，不代表同一天发生；冬十月在正月以前，未标月的朝见也不能仅凭排版安排在死后。 [[3]](#note-3)

**诸侯王的子弟陆续分得侯邑；成为列侯和继承整个王国是不同的安排。** 各支受封与后来的传爵、失国分别记年。 [原编读注](#note-6)

<a id="sj021-r001-e01"></a>

<a id="event-7"></a>

6. **茲侯一支受封。** 河閒獻王子刘明受封为茲侯。 [[6]](#note-7)

<a id="sj049-chen-deposed-event"></a>

7. **七月乙巳，陈皇后被废，退居长门宫。** 她涉嫌利用妇人媚道，事情败露后受到追查。楚服等人为皇后巫蛊祠祭、祝诅，被判大逆，牵连诛杀三百余人，楚服遭枭首。朝廷收回陈氏的皇后玺绶，令她退居长门宫；卫子夫到前128年才正式立后。 张汤奉使穷治巫蛊案所涉者。 [[7]](#sj049-chen-deposed-note)

<a id="sj054-event-8"></a>

8. **曹襄开始平阳侯元年。** 曹襄承接父亲曹时的爵位，本年为新侯元年。曹参一支继续传侯；曹襄娶卫长公主及生曹宗的未定年家事见[时期页](未定年-曹氏相政与平阳侯家事.md#sj054-event-6)。 [[8]](#sj054-note-8)

<a id="sj056-chenhe-case-event"></a>

9. **曲逆侯陈何被处弃市，陈氏侯国撤销。** 陈何到在侯二十三年，因掠夺他人妻子获罪，被判弃市，封国除去。后来陈掌以卫氏亲属身份请求续封，终未获准，见[未定年后续](未定年-陈平王陵与陈氏后续.md#event-4)。 [[9]](#sj056-chenhe-case-note)

<a id="sj059-fei-requests-war-event"></a>

10. **江都王刘非请求出击匈奴，未获准许。** 元光五年匈奴大举入边时，刘非再次请战，武帝没有允许。早年他曾随平吴楚出击，这次请求并不表示江都军已出塞。 [[10]](#sj059-fei-requests-war-note)

<a id="sj112-event-11"></a>

<a id="sj112-event-12"></a>

11. **公孙弘应策擢第，起为博士后迁左内史。** 公孙弘再被推举，武帝亲阅策文擢为首。菑川国坚持再次推举公孙弘。太常把他的对策列在下等，武帝阅策后改列第一，召见并任他为博士。公孙弘由博士任左内史。本年官表已列公孙弘为左内史。关于任命与对策相隔多久，列传的相对叙述和官表的年格须合读。 [[11]](#note-11)

<a id="sj117-event-13"></a>

12. **唐蒙正式通夜郎，发巴蜀治道，司马相如奉命晓谕。** 唐蒙奉命进入夜郎，与地方首领商定设置官吏，征发巴蜀吏卒运输、修路。部分人逃亡，军兴法施行后，巴蜀民众惊惧。武帝派司马相如责问唐蒙并发布文告。 [[12]](#note-13)

<a id="sj122-event-14"></a>

13. **趙禹与张汤议定律令。** 张汤任太中大夫后与趙禹修律，作见知等规定，要求相关吏互相监纠。 [[13]](#note-14)

<a id="hs-event-15"></a>

14. **七月大风拔木。** 七月大风拔起树木。 [[14]](#hs-note-15)

<a id="hs-event-16"></a>

<a id="hs-event-26"></a>

15. **秋季螟灾。** 八月有螟虫危害庄稼。元光五年秋螟。 [[15]](#hs-note-16)

<a id="hs-event-17"></a>

16. **征召通时务及古学之士。** 征召了解时务、通晓先圣学术的吏民，令途经各县供给饮食，并与上计人员同赴京师。 [[16]](#hs-note-17)

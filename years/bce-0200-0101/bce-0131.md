# 公元前131年｜齐国开始新王纪年，济东王入朝

[← 公元前132年](bce-0132.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前130年 →](bce-0130.md)

**汉武帝元光四年**

<a id="sj017-qi"></a>
## 齐王刘次昌元年

**齐国在刘寿去世后，进入其子刘次昌的纪年。** 这一支由齐悼惠王刘肥，经刘将闾、刘寿接下来；七国之乱后保存的齐王国，仍由这支刘氏治理。父亲去世和儿子元年分属相邻年条，不算两次王位更替。[原文与说明](#sj017-note)

<a id="sj017-audience"></a>
**济东王刘彭离入朝。** 他是梁孝王刘武的儿子，本次朝见发生在其在位第十四年；后来因杀人被废的案件不提前放入本年。[原文与说明](#sj017-note)

<a id="sj019"></a>
## 封侯、承袭与侯国的变化

| 侯国或家族 | 本年变化 | 史料 |
|---|---|---|
| <a id="sj019-r068-e04"></a>魏其 | 窦婴为灌夫争辩而与田蚡发生冲突，随后卷入查验先帝诏书的案件。他声称景帝曾留下特殊嘱托，朝廷却没有查到相应记录，最终以矫制等罪将他处以弃市，魏其侯国撤销。 | [说明](#sj019-r068-e04-n) |
| <a id="sj019-r072-e04"></a>建平 | 建平侯回去世，无人承爵，侯国终止。 | [说明](#sj019-r072-e04-n) |
| <a id="sj019-r076-e03"></a>新市 | 新市侯始昌被人杀害，侯国终止。 | [说明](#sj019-r076-e03-n) |
| <a id="sj019-r084-e03"></a>范陽 | 范阳侯德去世，无人承爵，封国终止。 | [说明](#sj019-r084-e03-n) |
| <a id="sj019-r085-e02"></a>翕 | 翕侯邯郸因往来行止没有向长信方面请示，被以不敬罪夺侯。 | [说明](#sj019-r085-e02-n) |
| <a id="sj019-r092-e02"></a>武安 | 梧接续武安侯田蚡的爵位。 | [说明](#sj019-r092-e02-n) |

## 本年相关史料

<a id="sj019-note"></a>
### 卷019｜本年侯籍与异说

[完整原表](../../sources/摘录/史记-卷019-惠景间侯者年表.md) · [逐格去向](../../meta/记录/史记-卷019-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷019-纪年与异说.md)。原格的承侯元年不一律等于前任死年；未载月日不补，谥号是后称，国除也不一律等于处死。

<a id="sj019-r068-e04-n"></a>
**魏其｜[R068原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r068)：** 据本表及[《魏其武安侯列传》](https://zh.wikisource.org/wiki/史記/卷107)。诏书真伪是当时案中争点，不把司法定性自动等同现代已独立验证；灌夫酒宴失礼、逮捕与窦婴终局是相连阶段，不都定为同一天。

<a id="sj019-r072-e04-n"></a>
**建平｜[R072原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r072)：** 暂按史表元光四年明年；汉表记回在位四年，从元光三年起算与此不合。保留任期冲突，不安排相邻几年重复死亡。

<a id="sj019-r076-e03-n"></a>
**新市｜[R076原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r076)：** “为人所杀”不等于朝廷处死，凶手与原因未详，不补为某项政治清洗。

<a id="sj019-r084-e03-n"></a>
**范陽｜[R084原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r084)：** 史表元光四年明记，汉表任期四年若从二年起算则较晚；保存数字差别，不借一方任期改写另一方原字。

<a id="sj019-r085-e02-n"></a>
**翕｜[R085原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r085)：** 长信与太后宫的制度关系见汉表注，不能把“行来”写成一次无据的军事叛乱。后来赵信的翕侯不是此人改名。

<a id="sj019-r092-e02-n"></a>
**武安｜[R092原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r092)：** 承侯元年不等于承接田蚡的丞相职位；丞相另由薛泽接任，本页原有任命。


<a id="sj017-note"></a>
[卷017前131年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0131)列“厉王次昌元年”与济东来朝；[《齐悼惠王世家》](https://zh.wikisource.org/wiki/史記/卷052)作次景，《汉书》及通鉴作次昌，正文沿后者，异名不拆成两王。厉王是死后评价，不能从谥号倒推这次继承已经附带某项定罪。刘寿之死见[前132年](bce-0132.md)，刘彭离的终局见[前116年](bce-0116.md)。

# 公元前131年｜齐国开始新王纪年，济东王入朝

[← 公元前132年](bce-0132.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前130年 →](bce-0130.md)

**汉武帝元光四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj017-qi"></a>
<a id="齐王刘次昌元年"></a>

<a id="event-1"></a>

1. **齐国在刘寿去世后，进入其子刘次昌的纪年。** 这一支由齐悼惠王刘肥，经刘将闾、刘寿接下来；七国之乱后保存的齐王国，仍由这支刘氏治理。父亲去世和儿子元年分属相邻年条，不算两次王位更替。 [[1]](#note-1)

<a id="sj017-audience"></a>

<a id="event-2"></a>

2. **济东王刘彭离入朝。** 他是梁孝王刘武的儿子，本次朝见发生在其在位第十四年；后来因杀人被废的案件不提前放入本年。 [[2]](#note-2)

<a id="sj020"></a>
<a id="军政受封与侯国的接续"></a>

<a id="sj020-e001"></a>
<a id="赵信封翕侯"></a>


<a id="event-3"></a>

3. **赵信封翕侯。** 原为匈奴相国的赵信归汉，受封翕侯。汉廷把归附者纳入列侯与军队体系，他后来还将随汉军向北作战。 [[3]](#note-3)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-4"></a>

4. **田蚡去世，薛泽接任丞相；张欧升任御史大夫。** 窦婴、灌夫的处置见[本年刑案条](#sj107-p023)。 [[4]](#note-4)

<a id="sj054-event-5"></a>

5. **平阳侯曹时去世。** 曹时为侯二十三年而卒，谥夷侯；儿子曹襄承爵，下一年开始新侯元年。其此前患病归国的确年没有记载，不把婚姻、疾病和死亡压成同日。 [[5]](#sj054-note-5)

<a id="sj107-event-6"></a>

6. **冬，灌夫及宗族获罪，窦婴在渭城弃市。** 灌夫获罪，连累宗族被诛。窦婴上书援引景帝遗诏，但宫中档案找不到副本，只有窦家封存的文书，遂被以矫诏论罪。列传还记他一度有望免死，后来又有诋毁他的言语传到皇帝耳中，十二月晦在渭城被处死。 [[6]](#note-6)

<a id="sj107-event-7"></a>

7. **田蚡死后，儿子承袭武安侯。** 田蚡死后由儿子续封武安侯。两书的侯表及列传对其名字有异写，后来失侯另归前126年。 [[7]](#note-7)

<a id="hs-event-8"></a>

8. **霜害、地震与赦令。** 四月霜冻伤草，五月地震，朝廷下大赦。 [[8]](#hs-note-8)

**魏其｜[R068原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r068)：** 本表和[《汉书·外戚恩泽侯表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-9ba26890d1c908)明系元光四年，正文沿[《通鉴》卷十八](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7018.md#ref-859b73c0e71b02)四年冬十二月晦于渭城被杀的年线。[《魏其武安侯列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7107.md#ref-9c98f1de3b698a)却写“五年十月”论灌夫及家属，随后十二月晦窦婴弃市；不能再声称列传与本年完全一致。前130年的另一年次在此留注，不另写第二次死亡。十月岁首下的十二月不直接换成同号公历月份。诏书真伪是当时案件争点，司法定性不等于现代已经独立验证。

<a id="sj019-r072-e04-n"></a>
**建平｜[R072原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r072)：** 暂按史表元光四年明年；汉表记回在位四年，从元光三年起算与此不合。保留任期冲突，不安排相邻几年重复死亡。

<a id="sj019-r076-e03-n"></a>
**新市｜[R076原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r076)：** “为人所杀”不等于朝廷处死，凶手与原因未详，不补为某项政治清洗。

<a id="sj019-r084-e03-n"></a>
**范陽｜[R084原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r084)：** 史表元光四年明记，汉表任期四年若从二年起算则较晚；保存数字差别，不借一方任期改写另一方原字。

<a id="sj019-r085-e02-n"></a>
**翕｜[R085原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r085)：** [《汉书·景武昭宣元成功臣表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-6a250187f753b1)如淳注长信宫为太后所居，颜师古明释“请，谒也”。因此“行来不请长信”释往来未朝谒太后；旧文译为向长信请示出行，现修正。史表景栏7、武帝栏9合为案年前16个年条，汉表“六年”仍是疑数，不由其改初封年。赵信后来封翕侯，属于另一人。

<a id="sj019-r092-e02-n"></a>
**武安｜[R092原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r092)：** 承侯元年不等于承接田蚡的丞相职位；丞相另由薛泽接任，本页原有任命。


<a id="sj017-note"></a>
[卷017前131年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0131)列“厉王次昌元年”与济东来朝；[《齐悼惠王世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7052.md#ref-2c7baedfaa2ee3)作次景，《汉书》及通鉴作次昌，正文沿后者，异名不拆成两王。厉王是死后评价，不能从谥号倒推这次继承已经附带某项定罪。刘寿之死见[前132年](bce-0132.md)，刘彭离的终局见[前116年](bce-0116.md)。

# 公元前131年｜齐国开始新王纪年，济东王入朝

[← 公元前132年](bce-0132.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前130年 →](bce-0130.md)

**汉武帝元光四年**

<a id="sj017-qi"></a>
## 齐王刘次昌元年

**齐国在刘寿去世后，进入其子刘次昌的纪年。** 这一支由齐悼惠王刘肥，经刘将闾、刘寿接下来；七国之乱后保存的齐王国，仍由这支刘氏治理。父亲去世和儿子元年分属相邻年条，不算两次王位更替。[原文与说明](#sj017-note)

<a id="sj017-audience"></a>
**济东王刘彭离入朝。** 他是梁孝王刘武的儿子，本次朝见发生在其在位第十四年；后来因杀人被废的案件不提前放入本年。[原文与说明](#sj017-note)

<a id="sj020"></a>
## 军政、受封与侯国的接续

<a id="sj020-e001"></a>
### 赵信封翕侯

原为匈奴相国的赵信归汉，受封翕侯。汉廷把归附者纳入列侯与军队体系，他后来还将随汉军向北作战。 [原文与说明](#sj020-e001-n)

<a id="sj022"></a>
## 朝廷人事与本年补记

**田蚡去世，薛泽接任丞相；张欧升任御史大夫。** 窦婴、灌夫一案也在这一阶段收束：灌夫家受到族诛，窦婴被弃市。宫廷中的姻亲关系与旧日战功，都没有使他们避开刑案。 [原文与说明](#sj022-note)

## 本年相关史料

<a id="sj022-note"></a>
### 卷022｜将相表互见与异说

[卷022 R076原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r076)。本行记地震、田蚡卒、薛泽相与御史“欧”；姓名据汉表补张欧。窦婴案将相表另放[前130年原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r077)，汉书武帝纪明确元光四年冬处死窦婴，本文暂归本年，前130年只留异年互见。田蚡卒月、薛泽任月在汉表分别三月、五月，不由同一摘要合成同日。十二月地动亦保留表文，不据别年的灾变补强。

**原行四栏：** 大事：十二月丁亥，地動。蚡卒。；相位：五。平棘侯薛澤為丞相。；将位：〔空白〕；御史：御史大夫歐。

互校：[《汉书·百官公卿表》](https://zh.wikisource.org/wiki/漢書/卷019) · [《汉书·武帝纪》](https://zh.wikisource.org/wiki/漢書/卷006) · [卷022纪年与异说](../../meta/考证/史记-卷022-纪年与异说.md)。原表数字与空栏照存，未作独立古历日换算。


<a id="sj020-note"></a>
### 卷020｜原格、互见与采用的年线

[完整原文](../../sources/摘录/史记-卷020-建元以来侯者年表.md) · [逐格去向](../../meta/记录/史记-卷020-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷020-纪年与异说.md)。初封、增邑、继承与任官分开；月日未明不补，谥号为后称，国除不一律等于处死。

<a id="sj020-e001-n"></a>
**赵信封翕侯：** [R001 翕](../../sources/摘录/史记-卷020-建元以来侯者年表.md#r001)。初封月份史表七月、汉表十月，均元光四年，不强行统一。史表元光栏3加元朔栏5，为前131年至前123年兵败以前的8个年条；[《汉书·景武昭宣元成功臣表》](https://zh.wikisource.org/wiki/漢書/卷017)却只记六年。原数与两表年次不能直接合，不因数字另造一次初封。赵信与卷019邯郸是不同翕侯。 互校：[漢書/卷017](https://zh.wikisource.org/wiki/%E6%BC%A2%E6%9B%B8/%E5%8D%B7017)。


<a id="sj019-note"></a>
### 卷019｜本年侯籍与异说

[完整原表](../../sources/摘录/史记-卷019-惠景间侯者年表.md) · [逐格去向](../../meta/记录/史记-卷019-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷019-纪年与异说.md)。原格的承侯元年不一律等于前任死年；未载月日不补，谥号是后称，国除也不一律等于处死。

<a id="sj019-r068-e04-n"></a>
**魏其｜[R068原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r068)：** 本表和[《汉书·外戚恩泽侯表》](https://zh.wikisource.org/wiki/漢書/卷018)明系元光四年，正文沿[《通鉴》卷十八](https://zh.wikisource.org/wiki/資治通鑑/卷018)四年冬十二月晦于渭城被杀的年线。[《魏其武安侯列传》](https://zh.wikisource.org/wiki/史記/卷107)却写“五年十月”论灌夫及家属，随后十二月晦窦婴弃市；不能再声称列传与本年完全一致。前130年的另一年次在此留注，不另写第二次死亡。十月岁首下的十二月不直接换成同号公历月份。诏书真伪是当时案件争点，司法定性不等于现代已经独立验证。

<a id="sj019-r072-e04-n"></a>
**建平｜[R072原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r072)：** 暂按史表元光四年明年；汉表记回在位四年，从元光三年起算与此不合。保留任期冲突，不安排相邻几年重复死亡。

<a id="sj019-r076-e03-n"></a>
**新市｜[R076原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r076)：** “为人所杀”不等于朝廷处死，凶手与原因未详，不补为某项政治清洗。

<a id="sj019-r084-e03-n"></a>
**范陽｜[R084原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r084)：** 史表元光四年明记，汉表任期四年若从二年起算则较晚；保存数字差别，不借一方任期改写另一方原字。

<a id="sj019-r085-e02-n"></a>
**翕｜[R085原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r085)：** [《汉书·景武昭宣元成功臣表》](https://zh.wikisource.org/wiki/漢書/卷017)如淳注长信宫为太后所居，颜师古明释“请，谒也”。因此“行来不请长信”释往来未朝谒太后；旧文译为向长信请示出行，现修正。史表景栏7、武帝栏9合为案年前16个年条，汉表“六年”仍是疑数，不由其改初封年。赵信后来封翕侯，属于另一人。

<a id="sj019-r092-e02-n"></a>
**武安｜[R092原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r092)：** 承侯元年不等于承接田蚡的丞相职位；丞相另由薛泽接任，本页原有任命。


<a id="sj017-note"></a>
[卷017前131年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0131)列“厉王次昌元年”与济东来朝；[《齐悼惠王世家》](https://zh.wikisource.org/wiki/史記/卷052)作次景，《汉书》及通鉴作次昌，正文沿后者，异名不拆成两王。厉王是死后评价，不能从谥号倒推这次继承已经附带某项定罪。刘寿之死见[前132年](bce-0132.md)，刘彭离的终局见[前116年](bce-0116.md)。

# 公元前133年｜武帝初到雍祭五畤，方士渐受宠

[← 公元前134年](bce-0134.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前132年 →](bce-0132.md)

**汉武帝元光二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj012-133-1"></a>
<a id="祭祀开始由皇帝亲自推动"></a>

<a id="event-1"></a>

1. **武帝到雍地，亲自祭祀五畤。** 五畤祭礼原有秦汉沿革，武帝不是从零发明这五座祭坛；此后定期郊祀成为他的政治日程。 [[1]](#note-1)

<a id="event-2"></a>

2. **一位被称作「神君」的长陵女子也受到宫中祭祀。** 传说她儿子死后自己悲痛异常，死后能借女巫宛若说话，信众上门祈求。宫廷设祠，皇帝听到声音而看不到神形；这是祠官、信众的叙述，不是编者可以确认的神灵现身。 [[2]](#note-2)

   雍祠有《汉书》元光二年冬十月可核；「神君」祠立的具体月日无从核定。

<a id="sj012-133-2"></a>
<a id="李少君的金丹与海上神山"></a>

<a id="event-3"></a>

<a id="event-4"></a>

3. **李少君言方术，武帝祭灶并遣人入海求仙。** 在武帝早年的求仙风气中，李少君声称懂得祭灶、炼金和延年之术。他以古铜器故事赢得皇帝信任，又说只要先祭灶得物、使丹砂化金、用金器饮食，就可能延寿、见蓬莱仙人、举行封禅。皇帝开始祭灶，派方士入海寻找蓬莱和安期生。李少君后来病死，武帝仍相信他是「化去」；求仙者没有带回能证实的仙人。李少君的进见、死亡与祭灶的各个阶段缺少可靠确年，只在此作早期背景，不写成全部发生在前133年。 [[3]](#note-3)

   这段为跨年叙述；原文没有把李少君一生精确系于元光二年，人物第一次集中出现时补前情。

<a id="sj012-133-3"></a>
<a id="泰一和各类神祠增加"></a>

<a id="event-5"></a>

4. **泰一和各类神祠增加。** 亳人薄忌提出泰一是最尊贵的天神，五帝是其辅助。 朝廷依他的主张在长安东南郊建祠，后来又叠加祭三一、黄帝、山川与其他神灵的办法。祭坛、牲品、巫祝逐渐有官方管理，也吸收许多民间提议。 [[4]](#note-5)

   这些做法并非在同一个月颁下的一整套新法。各建议递次提出，具体年份不明，暂放在早期祭祀主线并在考证说明。

   薄忌与郊祀的各项祭法在本纪为「其后」连续叙事，暂不逐条硬配年。

<a id="sj017-audience"></a>
<a id="楚中山长沙三王入朝代国又有继承"></a>

<a id="event-6"></a>

5. **楚王刘道、中山王刘胜、长沙王刘发入朝。** 三个来朝格分别保存，不推定三王是在雍祠五畤时一同陪祭。[原格与说明](#sj017-note) [[5]](#note-6)

<a id="event-7"></a>

6. **代王刘登去世，儿子刘义接位。** 刘登是刘参之子，属于文帝一支；刘义在下一年开始记元年，后来又迁王清河。此时只交代承接，不把后来的迁国提前。[原格与说明](#sj017-note) [[6]](#note-7)

10. **韩安国统摄马邑伏兵，李广、公孙贺、王恢、李息分别领军。** 汉军想借城邑交易诱单于深入，再合兵袭击；匈奴识破安排退出，伏击没有成功。王恢因不进兵被追究，最终死于狱案。 聂翁壹把死囚首级悬在马邑城上，冒充被杀的守城官吏，使单于相信有人献城。 单于见沿路牲畜无人照料，生疑攻烽燧，俘获的尉史说出汉军有埋伏。汉兵追至边塞，未能追及。 廷尉判王恢逗留挫军、当斩。田蚡托太后说情，武帝不允，王恢自杀。 [[10]](#note-11)

> 是時而李少君亦以祠灶、穀道、卻老方見上，上尊之。少君者，故深澤侯入以主方。匿其年及所生長，常自謂七十，能使物，卻老。其游以方遍諸侯。無妻子。人聞其能使物及不死，更饋遺之，常餘金錢帛衣食。人皆以為不治產業而饒給，又不知其何所人，愈信，爭事之。少君資好方，善為巧發奇中。嘗從武安侯飲，坐中有年九十餘老人，少君乃言與其大父游射處，老人為兒時從其大父行，識其處，一坐盡驚。少君見上，上有故銅器，問少君。少君曰：「此器齊桓公十年陳於柏寢。」已而案其刻，果齊桓公器。一宮盡駭，以少君為神，數百歲人也。

**[《史記》卷012](../../sources/本地分卷/史记/史记-卷012.md#L717)**

> 少君言於上曰：「祠灶則致物，致物而丹沙可化為黃金，黃金成以為飲食器則益壽，益壽而海中蓬萊僊者可見，見之以封禪則不死，黃帝是也。臣嘗游海上，見安期生，食臣棗，大如瓜。安期生僊者，通蓬萊中，合則見人，不合則隱。」於是天子始親祠灶，而遣方士入海求蓬萊安期生之屬，而事化丹沙諸藥齊為黃金矣。

<a id="sj030-frontiers"></a>

### 多方向扩张与筹财压力

以下为跨年背景或篇末评论，不计作本年新发生的编号事件。

<a id="sj030-frontiers-p007"></a>

**多方向用兵与筹资压力**

此后，东瓯、两越的事务使江淮供役增多；唐蒙、司马相如通西南的山路使巴蜀疲于运输；东方经营沧海郡也牵动燕齐。马邑设伏后，汉匈关系进一步恶化，边境战争不断。出征者携物，居者输送，生产与财货消耗，朝廷允许纳物补官、输财减罪，选任与法令因而改变，善于筹财的官员逐渐受重用。

**[《史记·平准书》P007](../../sources/摘录/史记-卷030-平准书.md#p007)**

> 自是之後，嚴助、朱買臣等招來東甌，事兩越，江淮之閒蕭然煩費矣。唐蒙、司馬相如開路西南夷，鑿山通道千餘里，以廣巴蜀，巴蜀之民罷焉。彭吳賈滅朝鮮，置滄海之郡，則燕齊之閒靡然發動。及王恢設謀馬邑，匈奴絕和親，侵擾北邊，兵連而不解，天下苦其勞，而干戈日滋。行者齎，居者送，中外騷擾而相奉，百姓抏獘以巧法，財賂衰秏而不贍。入物者補官，出貨者除罪，選舉陵遲，廉恥相冒，武力進用，法嚴令具。興利之臣自此始也。

这是跨年的支出清单。底本“彭吴贾灭朝鲜”句读、文字有疑，《汉书》作经营秽貊、朝鲜与沧海郡；不能写成此时已灭卫氏朝鲜，更不能把前108年的战争提前。

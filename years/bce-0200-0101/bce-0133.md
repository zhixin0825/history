# 公元前133年｜武帝初到雍祭五畤，方士渐受宠

[← 公元前134年](bce-0134.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前132年 →](bce-0132.md)

**汉武帝元光二年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补诸侯王来朝与代国衔接；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，卷十二的跨年回叙不当成同年新事。

<a id="祭祀开始由皇帝亲自推动"></a>
### 祭祀开始由皇帝亲自推动

<a id="event-1"></a>

1. **武帝到雍地，亲自祭祀五畤。** 五畤祭礼原有秦汉沿革，武帝不是从零发明这五座祭坛；此后定期郊祀成为他的政治日程。 [[1]](#note-1)

<a id="event-2"></a>

2. **一位被称作「神君」的长陵女子也受到宫中祭祀。** 传说她儿子死后自己悲痛异常，死后能借女巫宛若说话，信众上门祈求。宫廷设祠，皇帝听到声音而看不到神形；这是祠官、信众的叙述，不是编者可以确认的神灵现身。 [[2]](#note-2)

   **本段史料：** [卷012 P004](../../sources/摘录/史记-卷012-孝武本纪.md#p004)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-00cc7a942c3545)。雍祠有《汉书》元光二年冬十月可核；「神君」祠立的具体月日无从核定。

<a id="sj012-133-2"></a>
<a id="李少君的金丹与海上神山"></a>
### 李少君的金丹与海上神山

<a id="event-3"></a>

3. **在武帝早年的求仙风气中，李少君声称懂得祭灶、炼金和延年之术。** 他以古铜器故事赢得皇帝信任，又说只要先祭灶得物、使丹砂化金、用金器饮食，就可能延寿、见蓬莱仙人、举行封禅。 [[3]](#note-3)

<a id="event-4"></a>

4. **皇帝开始祭灶，派方士入海寻找蓬莱和安期生。** 李少君后来病死，武帝仍相信他是「化去」；求仙者没有带回能证实的仙人。李少君的进见、死亡与祭灶的各个阶段缺少可靠确年，只在此作早期背景，不写成全部发生在前133年。 [[4]](#note-4)

   **本段史料：** [卷012 P005](../../sources/摘录/史记-卷012-孝武本纪.md#p005)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-1e216d2d0c8912)。这段为跨年叙述；原文没有把李少君一生精确系于元光二年，人物第一次集中出现时补前情。

<a id="sj012-133-3"></a>
<a id="泰一和各类神祠增加"></a>
### 泰一和各类神祠增加

<a id="event-5"></a>

5. **亳人薄忌提出泰一是最尊贵的天神，五帝是其辅助。** 朝廷依他的主张在长安东南郊建祠，后来又叠加祭三一、黄帝、山川与其他神灵的办法。祭坛、牲品、巫祝逐渐有官方管理，也吸收许多民间提议。 [[5]](#note-5)

   这些做法并非在同一个月颁下的一整套新法。各建议递次提出，具体年份不明，暂放在早期祭祀主线并在考证说明。

   **本段史料：** [卷012 P006](../../sources/摘录/史记-卷012-孝武本纪.md#p006)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-18651457bb9185)。薄忌与郊祀的各项祭法在本纪为「其后」连续叙事，暂不逐条硬配年。

<a id="sj017-audience"></a>
<a id="楚中山长沙三王入朝代国又有继承"></a>
### 楚、中山、长沙三王入朝，代国又有继承

<a id="event-6"></a>

6. **楚王刘道、中山王刘胜、长沙王刘发入朝。** 三个来朝格分别保存，不推定三王是在雍祠五畤时一同陪祭。[原格与说明](#sj017-note) [[6]](#note-6)

<a id="event-7"></a>

7. **代王刘登去世，儿子刘义接位。** 刘登是刘参之子，属于文帝一支；刘义在下一年开始记元年，后来又迁王清河。此时只交代承接，不把后来的迁国提前。[原格与说明](#sj017-note) [[7]](#note-7)

#### 卷022｜将相表互见与异说

[卷022 R074原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r074)。将军分工据本表：韩安国护军、李广骁骑、公孙贺轻车、王恢将屯、李息材官。五人不是五个同号将军。“篡单于”读其袭取计划，不能写成已经擒获单于；汉纪有三十万之数，本文不据此推算各部精确配额。雍五畤祭祀接旧页。

**原行四栏：** 大事：帝初之雍，郊見五畤。；相位：三；将位：夏，御史大夫韓安國為護軍將軍，衛尉李廣為驍騎將軍，太僕公孫賀為輕車將軍，大行王恢為將屯將軍，太中大夫李息為材官將軍，篡單于馬邑，不合，誅恢。；御史：〔空白〕

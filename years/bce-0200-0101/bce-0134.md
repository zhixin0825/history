# 公元前134年｜再次征文学之士，公孙弘进入视野

[← 公元前135年](bce-0135.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前133年 →](bce-0133.md)

**汉武帝元光元年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补诸侯王来朝；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，卷十二的跨年回叙不当成同年新事。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj012-134-1"></a>
<a id="再开荐举与策问"></a>

<a id="event-1"></a>

1. **再开荐举与策问。** 窦氏去世的下一年，武帝征召公孙弘等通晓文献的士人。 朝廷又通过郡国选荐孝廉、策问贤良等办法招人。学术见解开始通过征辟、应对和官职影响实际政务。 [[1]](#note-1)

<a id="event-2"></a>

2. **公孙弘此时是应征者之一，不应写成已经执掌相权。** 《孝武本纪》这部分重视改革礼制的思想背景，并不提供完整的当年战事和官员任免。 [[2]](#note-2)

   《汉书》元光元年记孝廉荐举和董仲舒、公孙弘等策问；任相为后事。

<a id="sj017-audience"></a>
<a id="城阳胶东燕三王入朝"></a>

<a id="event-3"></a>

3. **城阳王刘延、胶东王刘寄、燕王刘定国来到朝廷。** 刘延、刘定国已分别接续父辈，刘寄则是景帝之子。表中的每个“来朝”都是这一年在位者的活动，不能一直沿用王国最初受封者的姓名。[原格与说明](#sj017-note) [[3]](#note-3)

<a id="sj018-wudi"></a>
<a id="功臣后裔的承爵与失国"></a>


<a id="event-4"></a>

4. **吕宜成接续吕德，承中水侯爵。** [[4]](#note-4)

   张敖后裔中原来的南宫侯一代因罪失爵，这支侯国再次中断。

<a id="sj108-event-5"></a>

5. **聂翁壹经王恢提出马邑诱敌计。** 汉廷刚与匈奴议和，雁门马邑的聂翁壹向大行王恢提出，可借对方仍信任边地、贪图城邑资财之机诱其来。正式出兵和布置伏击在下一年。 [[5]](#note-5)

## 本年相关史料

<a id="note-1"></a>

### 1. 窦氏去世的下一年，武帝征召公孙弘等通晓文献的士人

[返回正文第1条](#event-1)

**[《漢書》卷006](../../sources/本地分卷/汉书/汉书-卷006.md#L349)**

> 五月，詔賢良曰：「朕聞昔在唐虞，畫象而民不犯，日月所燭，莫不率俾。周之成康，刑錯不用，德及鳥 獸，教通四海。海外肅凫，北發渠搜，氐羌徠服。星辰不孛，日月不蝕，山陵不崩，川谷不塞；麟鳳在郊藪，河洛出圖書。嗚虖，何施而臻此與！今朕獲奉宗廟，夙 興以求，夜寐以思，若涉淵水，未知所濟。猗與偉與！何行而可以章先帝之洪業休德，上參堯舜，下配三王！朕之不敏，不能遠德，此子大夫之所睹聞也。賢良明於 古今王事之體，受策察問，咸以書對，著之於篇，朕親覽焉。」於是董仲舒、公孫弘等出焉。

**[《史記》卷012](../../sources/本地分卷/史记/史记-卷012.md#L714)**

> 後六年，竇太后崩。其明年，上徵文學之士公孫弘等。

**[《漢書》卷006](../../sources/本地分卷/汉书/汉书-卷006.md#L346)**

> 元光元年冬十一月，初令郡國舉孝廉各一人。

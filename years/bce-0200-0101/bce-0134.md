# 公元前134年｜再次征文学之士，公孙弘进入视野

[← 公元前135年](bce-0135.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前133年 →](bce-0133.md)

**汉武帝元光元年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补诸侯王来朝；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，卷十二的跨年回叙不当成同年新事。

### 再开荐举与策问

<a id="event-1"></a>

1. **窦氏去世的下一年，武帝征召公孙弘等通晓文献的士人。** 朝廷又通过郡国选荐孝廉、策问贤良等办法招人。学术见解开始通过征辟、应对和官职影响实际政务。 [[1]](#note-1)

<a id="event-2"></a>

2. **公孙弘此时是应征者之一，不应写成已经执掌相权。** 《孝武本纪》这部分重视改革礼制的思想背景，并不提供完整的当年战事和官员任免。 [[2]](#note-2)

   **本段史料：** [卷012 P003](../../sources/摘录/史记-卷012-孝武本纪.md#p003)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-a3e22c1914092e)。《汉书》元光元年记孝廉荐举和董仲舒、公孙弘等策问；任相为后事。

<a id="城阳胶东燕三王入朝"></a>
### 城阳、胶东、燕三王入朝

<a id="event-3"></a>

3. **城阳王刘延、胶东王刘寄、燕王刘定国来到朝廷。** 刘延、刘定国已分别接续父辈，刘寄则是景帝之子。表中的每个“来朝”都是这一年在位者的活动，不能一直沿用王国最初受封者的姓名。[原格与说明](#sj017-note) [[3]](#note-3)

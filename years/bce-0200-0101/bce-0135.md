# 公元前135年｜窦太皇太后去世，武帝开始转向

[← 公元前136年](bce-0136.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前134年 →](bce-0134.md)

**汉武帝建元六年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补诸侯王来朝；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，卷十二的跨年回叙不当成同年新事。

1. **五月，窦太皇太后去世。** 她长期偏好黄老、反对赵绾王臧推动的新礼制；她的死亡使此前被压住的一部分议题重新有了讨论空间。 她与文帝合葬霸陵，遗诏将东宫的金钱财物全部赐给女儿长公主刘嫖。 [[1]](#note-1)

   这不等于汉朝在这一日立即完成所谓「独尊儒术」。人才选拔、礼制变化和祭祀改革都还需要逐年推进。

   《史记》仅记“后六年，窦太后崩”，明确月份据《汉书》建元六年。

<a id="sj027-long-star"></a>
<a id="八月东方出现长星"></a>

<a id="event-2"></a>

2. **八月，东方出现带有长芒的星象。** 记载称光芒长达天际，三十日后消失。古人把这种形态称为“蚩尤旗”，并联想到对外征伐；这只是当时的占星解释。 卷118另载刘安听宾客以当年彗星类比吴楚兵事，因而积蓄财物、加紧治备。 [[2]](#note-2)

3. **胶西王刘端、赵王刘彭祖来到朝廷。** 两人都是景帝之子，但胶西是在七国之乱以后另封刘端，刘彭祖则从广川迁到赵。各自的在位年数不能直接当成在现有封国居住的年数。[原格与说明](#sj017-note) [[3]](#note-3)

9. **许昌免相以后，田蚡接任丞相，韩安国任御史大夫，庄青翟转任太子太傅。** 东南方面，闽越进攻南越，汉廷从豫章、会稽两路发兵；汉军未抵达，闽越内部已杀王郢并求降。 王恢从豫章、韩安国从会稽出兵。余善杀郢送首请罪后，武帝立无诸之孙丑为越繇王，继续奉闽越旧祀。 [[9]](#note-9)

<a id="sj108-event-10"></a>

10. **匈奴请和亲，武帝采纳韩安国的意见。** 匈奴来请和亲。王恢以往约屡背，主张发兵；韩安国指出深入远地会使人马疲敝，难以制约匈奴。多数朝臣支持韩安国，武帝准许和亲。 [[10]](#note-10)

<a id="sj113-event-11"></a>

11. **严助出使南越，赵胡送太子婴齐入汉宿卫。** 闽越罢兵后，武帝遣严助晓谕。赵胡感谢汉廷派兵，送婴齐入朝宿卫。赵胡本打算亲自入见，听从臣下劝阻，最后称病未行。 [[11]](#note-11)

<a id="sj114-event-12"></a>

12. **余善取得闽越实权，汉封为东越王。** 杀郢以后，余善受到部众拥护，自立为王。汉廷没有再出兵，随后册封他为东越王，与奉祀旧统的越繇王并立。 [[12]](#note-12)

<a id="sj116-event-13"></a>

13. **唐蒙出使南越，调查夜郎贸易路线。** 闽越事后王恢遣唐蒙晓谕南越。唐蒙由蜀枸酱获知夜郎、牂柯江与番禺的贸易路线，回汉询问蜀商，提出可从江道接近南越的主张。正式发役与通夜郎另见前130年。 [[13]](#note-13)

<a id="sj120-event-14"></a>

14. **汲黯由东海太守升为主爵都尉。** 汲黯治东海以清静任属吏，武帝闻治绩召为主爵都尉，列于九卿。 [[14]](#note-14)

<a id="sj121-event-15"></a>

15. **辽东高庙失火。** 二月乙未，辽东高庙失火。董仲舒著灾异说涉及此灾；同年四月高园便殿也失火。两处地点有别，奏稿案件的具体年份另存。 [[15]](#note-15)

> 秋八月，有星孛于東方，長竟天。

<a id="sj118-p014"></a>

**[《史记·淮南衡山列传》P014](../../sources/摘录/史记-卷118-淮南衡山列传.md#p014)** · [三家注](../../sources/史记三家注/卷118.md#p14)

> 建元六年，彗星見，淮南王心怪之。或說王曰：「先吴軍起時，彗星出長數尺，然尚流血千里。今彗星長竟天，天下兵當大起。」王心以爲上無太子，天下有變，諸侯並爭，愈益治器械攻戰具，積金錢賂遺郡國諸侯游士奇材。諸辨士爲方略者，妄作妖言，諂諛王，王喜，多賜金錢，而謀反滋甚。

**本卷归年说明：** 本传记刘安与宾客对星象的解释，《汉书·五行志》另记本年八月长星；天象名称和人物借题论兵分层处理。


**[互校H013](../../sources/摘录/史记-卷027-纪年互校.md#h013)**

> 八月，長星出于東方，長終天，三十日去。占曰：「是為蚩尤旗，見則王者征伐四方。」其後兵誅四夷，連數十年。

## 归年与考证

<a id="sj022-note"></a>
<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[卷022 R072原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r072)。太皇太后之死接本页原有叙事；将相表“孝景太后”指景帝窦皇后、武帝祖母，不是武帝王太后。六月癸巳任相与汉表合。闽越事本表记正月，汉纪只列于本年，未据此给唯一公历日；也不把此前前138年救东瓯再当作同一场战争。

**原行四栏：** 大事：正月，閩越王反。孝景太后崩。。昌免相。；相位：五。六月癸巳，武安侯田蚡為丞相。；将位：青翟為太子太傅。；御史：御史大夫安國。

互校：[《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0135) · [《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-d4f84a79dfad85) · [卷022纪年与异说](../../meta/考证/史记-卷022-纪年与异说.md)。原表数字与空栏照存，未作独立古历日换算。

<a id="八月长星的原文与纪年"></a>
#### 八月长星的原文与纪年

《汉书·五行志》（[互校H013](../../sources/摘录/史记-卷027-纪年互校.md#h013)）：

> 八月，長星出于東方，長終天，三十日去。占曰：「是為蚩尤旗，見則王者征伐四方。」其後兵誅四夷，連數十年。

《天官书》[P120](../../sources/摘录/史记-卷027-天官书.md#p120)作“元光、元狩，蚩尤之旗再見”，本卷[P089](../../sources/摘录/史记-卷027-天官书.md#p089)则释其形如彗而后曲。第一次据《汉书》明确年次取建元六年，不把《天官书》的“元光”静默改掉，也不在前134年再记一次同样天象。“旗”的古代命名不等于已认定现代天体种类，战争与天象没有在这里被写成因果。详[两次长星及元光异文](../../meta/考证/史记-卷027-纪年与异说.md#蚩尤旗)。

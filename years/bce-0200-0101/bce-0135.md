# 公元前135年｜窦太皇太后去世，武帝开始转向

[← 公元前136年](bce-0136.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前134年 →](bce-0134.md)

**汉武帝建元六年**

本页保留《孝武本纪》的宗庙、郊祭、方士与制度主线，另补诸侯王来朝；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，卷十二的跨年回叙不当成同年新事。

<a id="sj012-135-1"></a>
## 旧宫廷权力格局改变

**五月，窦太皇太后去世。** 她长期偏好黄老、反对赵绾王臧推动的新礼制；她的死亡使此前被压住的一部分议题重新有了讨论空间。

这不等于汉朝在这一日立即完成所谓「独尊儒术」。人才选拔、礼制变化和祭祀改革都还需要逐年推进。

**本段史料：** [卷012 P003](../../sources/摘录/史记-卷012-孝武本纪.md#p003)；[《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-e380dfdcd5dea2)。《史记》仅记“后六年，窦太后崩”，明确月份据《汉书》建元六年。

<a id="sj027-long-star"></a>
## 八月，东方出现长星

**八月，东方出现带有长芒的星象。** 记载称光芒长达天际，三十日后消失。古人把这种形态称为“蚩尤旗”，并联想到对外征伐；这只是当时的占星解释。 [原文与说明](#sj027-long-star-note)

<a id="sj017-audience"></a>
## 胶西与赵两王入朝

**胶西王刘端、赵王刘彭祖来到朝廷。** 两人都是景帝之子，但胶西是在七国之乱以后另封刘端，刘彭祖则从广川迁到赵。各自的在位年数不能直接当成在现有封国居住的年数。[原格与说明](#sj017-note)

<a id="sj017-note"></a>
[卷017前135年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0135)胶西二十、赵二十一来朝；封国转换见[《五宗世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7059.md#ref-5a1f0a84199253)及前154、152年既有年页。未记月日，不把来朝强定为赴窦太后丧礼，也不由同时出现而断言两人共同参与了某项礼制决策。

<a id="sj022-note"></a>
### 卷022｜将相表互见与异说

[卷022 R072原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r072)。太皇太后之死接本页原有叙事；将相表“孝景太后”指景帝窦皇后、武帝祖母，不是武帝王太后。六月癸巳任相与汉表合。闽越事本表记正月，汉纪只列于本年，未据此给唯一公历日；也不把此前前138年救东瓯再当作同一场战争。

**原行四栏：** 大事：正月，閩越王反。孝景太后崩。。昌免相。；相位：五。六月癸巳，武安侯田蚡為丞相。；将位：青翟為太子太傅。；御史：御史大夫安國。

<a id="sj027-long-star-note"></a>
### 八月长星的原文与纪年

《汉书·五行志》（[互校H013](../../sources/摘录/史记-卷027-纪年互校.md#h013)）：

> 八月，長星出于東方，長終天，三十日去。占曰：「是為蚩尤旗，見則王者征伐四方。」其後兵誅四夷，連數十年。

《天官书》[P120](../../sources/摘录/史记-卷027-天官书.md#p120)作“元光、元狩，蚩尤之旗再見”，本卷[P089](../../sources/摘录/史记-卷027-天官书.md#p089)则释其形如彗而后曲。第一次据《汉书》明确年次取建元六年，不把《天官书》的“元光”静默改掉，也不在前134年再记一次同样天象。“旗”的古代命名不等于已认定现代天体种类，战争与天象没有在这里被写成因果。详[两次长星及元光异文](../../meta/考证/史记-卷027-纪年与异说.md#蚩尤旗)。

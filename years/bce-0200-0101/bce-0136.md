# 公元前136年｜广川、清河与山阳换代，无后王国被撤销

[← 公元前137年](bce-0137.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前135年 →](bce-0135.md)

**汉武帝建元五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj017-deaths"></a>
<a id="八月广川王刘越清河王刘乘去世"></a>

<a id="event-1"></a>

1. **八月，广川王刘越、清河王刘乘去世。** 广川与清河两位景帝之子在八月去世，封国的后续却不同。 广川由刘越的儿子刘齐承继，清河王刘乘没有继承人，王国被撤销，土地转由汉廷直接管辖。 [[1]](#note-1)

<a id="event-2"></a>

2. **梁孝王的儿子、山阳王刘定也在本年去世，没有儿子继王。** 原梁国分出的山阳一支因此结束，土地改作郡。它与清河虽同为无后除国，却来自不同的王室支系。 [[2]](#note-2)

<a id="sj017-successions"></a>
<a id="梁国进入刘襄的纪年"></a>

<a id="event-3"></a>

3. **梁王刘襄开始记元年，接续上一年去世的父亲刘买。** 他是梁孝王的孙子，并非齐悼惠王刘肥之子、吕后末年率军西进的那位刘襄。广川新王刘齐也在本行开始计年；后来的谥号用于辨认人物，不表示他们此时已经去世。 [[3]](#note-3)

<a id="sj049-zanger-death-event"></a>

7. **四月，平原君臧儿去世。** 她是王皇太后之母、武帝的外祖母。死后从田氏葬长陵，置园邑奉祀，制度比照王仲的共侯园；具体置园日期未另外记载。 [[7]](#sj049-zanger-death-note)

<a id="hs-event-8"></a>

8. **设置五经博士。** 朝廷设五经博士。后来增设博士弟子有另年记载。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **五月大蝗。** 五月发生严重蝗灾。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **北平文侯张苍｜获罪。** 表载北平文侯张苍一支本年载相关罪案及处分。表中所载事项为因罪案临诸侯丧後，失爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **广阿懿侯任敖｜承爵。** 表载广阿懿侯任敖一支本年记载侯位承袭。表中所载事项为侯越人承爵。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **亚谷简侯卢它之｜承爵。** 表载亚谷简侯卢它之一支本年记载侯位承袭。表中所载事项为康侯漏承爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **正月日食记录。** 《五行志》载正月己巳日食，历日照原书。 [[14]](#hs-note-14)

**亞谷｜[R086原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r086)：** 正文采用[《汉书·景武昭宣元成功臣表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-684b4a291193e0)建元五年漏嗣，与景后元年种嗣、七年这一年链相接；史表建元元年名偏另存。其本栏11、25按史表年次可分，不把可算的数字移植到汉表年链中。古书姓名和起年的区别都保留，未称现代研究已定案。


<a id="sj017-note"></a>
[卷017前136年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0136)列广川缪王、梁平王元年及清河、山阳无后除国。[《汉书·武帝纪》建元五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-44dbb3151bebbd)明确八月刘越、刘乘皆薨；[汉书诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7014.md#ref-4988044a1cedeb)补广川新王名齐，系刘越之子。不能仅见本年“元年”，便把刘越之死倒推到前137年；受位当年起算与次年元年须逐人区分。

[《梁孝王世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7058.md#ref-0950eab1de409f)记刘定在位九年、无子除国，与山阳本格衔接。刘襄只在此交代继承，世家所述他后来与家人争执、被削八城，未明确落在本年，不因首次介绍就搬到这里。

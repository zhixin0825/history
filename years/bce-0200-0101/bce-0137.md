# 公元前137年｜梁王刘买去世，江都与常山两王入朝

[← 公元前138年](bce-0138.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前136年 →](bce-0136.md)

**汉武帝建元四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj017-liang"></a>
<a id="梁王刘买去世"></a>

<a id="event-1"></a>

1. **梁王刘买去世，梁国由下一代承接。** 他是梁孝王刘武的长子；父亲去世后，原梁国分为五个王国，刘买保有梁的王号。刘买在位七年，儿子刘襄继承，下一年开始记为新王元年。 [[1]](#note-1)

<a id="sj017-audience"></a>
<a id="江都王刘非常山王刘舜入朝"></a>

<a id="event-2"></a>

2. **江都王刘非和常山王刘舜来到朝廷。** 两人都是景帝之子，但刘非先封汝南、后来迁江都，刘舜则受封常山。年表保留的是本次朝见，不意味着两国在本年才建立。 [[2]](#note-2)

<a id="sj019"></a>
<a id="封侯承袭与侯国的变化"></a>

<a id="sj019-r091-e02"></a>

<a id="event-3"></a>

3. **相如接续塞侯直不疑的爵位。** [[3]](#note-3)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-4"></a>

4. **武强侯庄青翟出任御史大夫。** 他的侯爵、中央官位和后来转任太子太傅，是不同阶段的经历。 [[4]](#note-4)

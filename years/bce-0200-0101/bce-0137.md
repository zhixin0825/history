# 公元前137年｜梁王刘买去世，江都与常山两王入朝

[← 公元前138年](bce-0138.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前136年 →](bce-0136.md)

**汉武帝建元四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj017-liang"></a>
<a id="梁王刘买去世"></a>

<a id="event-1"></a>

1. **梁王刘买去世，梁国由下一代承接。** 他是梁孝王刘武的长子；父亲去世后，原梁国分为五个王国，刘买保有梁的王号。刘买在位七年，儿子刘襄继承，下一年开始记为新王元年。 [[1]](#note-1)

<a id="sj017-audience"></a>
<a id="江都王刘非常山王刘舜入朝"></a>

<a id="event-2"></a>

2. **江都王刘非和常山王刘舜来到朝廷。** 两人都是景帝之子，但刘非先封汝南、后来迁江都，刘舜则受封常山。年表保留的是本次朝见，不意味着两国在本年才建立。 [[2]](#note-2)

<a id="sj019"></a>
<a id="封侯承袭与侯国的变化"></a>

<a id="sj019-r091-e02"></a>

<a id="event-3"></a>

3. **相如接续塞侯直不疑的爵位。** [[3]](#note-3)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-4"></a>

4. **武强侯庄青翟出任御史大夫。** 他的侯爵、中央官位和后来转任太子太傅，是不同阶段的经历。 [[4]](#note-4)

<a id="sj113-event-5"></a>

5. **南越王赵佗去世，孙赵胡继位。** 赵佗去世，南越王位由孙子赵胡接续。《汉书》同记交接在建元四年。南越文王墓出土印章作赵眜，传世史籍称赵胡。 [[5]](#note-5)

<a id="hs-event-6"></a>

6. **赤风、旱与孛星。** 建元四年夏记颜色像血的风，六月有旱，九月东北出现孛星。三者按原纪并列。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **成敬侯董渫｜承爵。** 表载成敬侯董渫一支本年记载侯位承袭。表中所载事项为共侯罢军承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **临辕坚侯戚鳃｜承爵。** 表载临辕坚侯戚鳃一支本年记载侯位承袭。表中所载事项为侯贤承爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **谷阳定侯冯谿｜承爵。** 表载谷阳定侯冯谿一支本年记载侯位承袭。表中所载事项为侯偃承爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **塞侯直不疑｜承爵。** 表载塞侯直不疑一支本年记载侯位承袭。表中所载事项为康侯相如承爵。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **大理复称廷尉。** 武帝复用廷尉官名。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[12]](#hs-note-12)

1. **济川王刘明因杀属官被废。** 济川王刘明因杀害属官被废。刘明被剥夺王位，降为平民，迁往房陵。他是梁孝王刘武的儿子，原在梁分五国时取得济川。如今朝廷追究他杀害属官的案件，有司请求处死，皇帝没有批准死刑，但不再让他继续统治封国。济川的土地转入汉廷管辖。济川王刘明案的官名异记。王表所载中傅与[第1条](#event-1)为同一案。 [[1]](#note-1)

   封王所带来的地位，不代表可以不受中央司法追究。这一次处置也没有另立刘明的后人接王，而是结束这一支王国。

2. **中山王刘胜、代王刘登、长沙王刘发来到朝廷。** 三人分别属于景帝、文帝的子孙；同样称王，既有封国、亲缘和经历并不相同。本年的入朝是各自的在位活动，不是又一次受封。 [[2]](#note-2)

4. **闽越围攻东瓯，汉廷派严助持节调发会稽兵救援；军队尚未抵达，闽越先行撤围。** 东瓯随后请求内徙，其部众迁入江淮一带，原有地方王国与汉朝内地的关系由此改变。 朝议中田蚡反对救援，严助力主出兵。会稽太守拒绝调兵，严助持节斩一名司马，随后渡海出兵。 [[4]](#note-4)

<a id="sj108-event-5"></a>

5. **韩安国由北地都尉升为大农令。** 韩安国从梁国去官后被武帝起用，先做北地都尉；建元三年入朝任掌国家财政的大农令。 [[5]](#note-5)

<a id="hs-event-6"></a>

6. **平原河溢及饥荒。** 建元三年春，黄河在平原一带溢流，大饥荒中出现人相食的记载。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **移民茂陵受赐并作便门桥。** 徙居茂陵的民户每户获钱二十万、田两顷；本纪还记开始建造便门桥。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

9. **九月月末日食记载。** 九月丙子晦，史官记日食，日次按秦汉旧历。 [[9]](#hs-note-9)

<a id="hs-event-12"></a>

11. **戚圉侯季必｜承爵。** 表载戚圉侯季必一支本年记载侯位承袭。表中所载事项为侯信成承爵。 [[11]](#hs-note-12)

<a id="hs-event-13"></a>

12. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[12]](#hs-note-13)

14. **四月孛星由天纪至织女。** [[14]](#hs-note-15)

<a id="hs-event-16"></a>

15. **武帝微行始出、初置期门及其后扩建上林苑。** 建元三年，武帝开始微行出猎，侍从骑士因相约殿门得名期门。出猎后来屡扰周边百姓，武帝命吾丘寿王勘估土地以扩苑，拟以草田补偿；东方朔以南山物产、农民生计和驰猎安全直谏，获拜太中大夫给事中。 [[15]](#hs-note-16)

### 4. 闽越围攻东瓯，汉廷派严助持节调发会稽兵救援；军队尚未抵达，闽越先行撤围

[返回正文第4条](#event-4)

<a id="hs095-l9932-e4"></a>

**[《汉书·西南夷两粤朝鲜传》P029](../../拆分史书/汉书/卷095.md#p029)** · [仓内TXT L9932](../../拆分史书/汉书/卷095.md#part-1-L9932)

> 吳王子駒亡走閩粵，怨東甌殺其父，常勸閩粵擊東甌。建元三年，閩粵發兵圍東甌，東甌使人告急天子。天子問太尉田蚡，蚡對曰：「粵人相攻擊，固其常，不足以煩中國往救也。」中大夫嚴助詰蚡，言當救。天子遣助發會稽郡兵浮海救之，語具在《助傳》。漢兵未至，閩粵引兵去。東粵請舉國徙中國，乃悉與衆處江、淮之間。

**互校说明** 建元三年，篇末“東粵”联系前文指东瓯请迁。此事与元封元年东越之另一轮徙江淮分年。

<a id="hs064-l8342-e4"></a>

**[《汉书·严朱吾丘主父徐严终王贾传》P002](../../拆分史书/汉书/卷064.md#p002)** · [仓内TXT L8342](../../拆分史书/汉书/卷064.md#part-1-L8342)

> 建元三年，閩越舉兵圍東甌，東甌告急於漢。時武帝年未二十，以問太尉田蚡。蚡以爲越人相攻擊，其常事，又數反覆，不足煩中國往救也，自秦時棄不屬。於是助詰蚡曰：「特患力不能救，德不能覆，誠能，何故棄之？且秦舉咸陽而棄之，何伹越也！今小國以窮困來告急，天子不振，尚安所愬，又何以子萬國乎？」上曰：「太尉不足與計。吾新即位，不欲出虎符發兵郡國。」迺遣助以節發兵會稽。會稽守欲距法，不爲發。助迺斬一司馬，諭意指，遂發兵浮海救東甌。未至，閩越引兵罷。

**互校说明** 《通鉴考异》指出事发时田蚡已不为太尉，疑为误书或追称旧官；保留传文字形，围东瓯仍依建元三年。

<a id="hs050-l7684-e4"></a>

**[《汉书·张冯汲郑传》P017](../../拆分史书/汉书/卷050.md#p017)** · [仓内TXT L7684](../../拆分史书/汉书/卷050.md#part-1-L7684)

> 東粵相攻，上使黯往視之。至吳而還，報曰：「粵人相攻，固其俗，不足以辱天子使者。」

**互校说明** 以本纪建元三年闽越、东瓯事件互参；具体调兵使者是严助，汲黯之行本传只称往视事。

<a id="hs006-l334-e4"></a>

**[《汉书·武帝纪》P016](../../拆分史书/汉书/卷006.md#p016)** · [仓内TXT L334](../../拆分史书/汉书/卷006.md#part-1-L334)

> 閩越圍東甌，東甌告急。遣中大夫嚴助持節發會稽兵，浮海救之。未至，閩越走，兵還。

<a id="sj114-p002"></a>

**[《史记·东越列传》P002](../../拆分史书/史记/卷114.md#p002)** · [三家注](../../拆分史书/史记/卷114.md#part-2-p2)

> 至建元三年，閩越發兵圍東甌。東甌食盡，困，且降，乃使人告急天子。天子問太尉田蚡，蚡對曰：「越人相攻擊，固其常，又數反覆，不足以煩中國徃救也。自秦時弃弗屬。」於是中大夫莊助詰蚡曰：「特患力弗能救，德弗能覆；誠能，何故弃之？且秦舉咸陽而弃之，何乃越也！今小國以窮困來告急天子，天子弗振，當安所告愬？又何以子萬國乎？」上曰：「太尉未足與計。吾初即位，不欲出虎符發兵郡國。」乃遣莊助以節發兵會稽。會稽太守欲距不爲發兵，助乃斬一司馬，諭意指，遂發兵浮海救東甌。未至，閩越引兵而去。東甌請舉國徙中國，乃悉舉衆來，處江淮之間。

### 15. 武帝微行始出、初置期门及其后扩建上林苑

<a id="hs065-l8444-e16"></a>

**[《汉书·东方朔传》P007](../../拆分史书/汉书/卷065.md#p007)** · [仓内TXT L8444](../../拆分史书/汉书/卷065.md#part-1-L8444)

> 初，建元三年，微行始出，北至池陽，西至黃山，南獵長楊，東游宜春。微行常用飲酎已。八九月中，與侍中常侍武騎及待詔隴西北地良家子能騎射者期諸殿門，故有「期門」之號自此始。

**互校说明** 本传直书建元三年起微行并述期门名称由来，不以「始」强定以后历次出行。

<a id="hs065-l8444-e16-2"></a>

**[《汉书·东方朔传》P007](../../拆分史书/汉书/卷065.md#p007)** · [仓内TXT L8444](../../拆分史书/汉书/卷065.md#part-1-L8444)

> 於是上以為道遠勞苦，又為百姓所患，乃使太中大夫吾丘壽王與待詔能用算者二人，舉籍阿城以南，盩厔以東，宜春以西，提封頃畝，及其賈直，欲除以為上林苑，屬之南山。又詔中尉、左右內史表屬縣草田，欲以償鄠杜之民。吾丘壽王奏事，上大說稱善。

**互校说明** 《通鉴》卷017沿微行初出连叙勘地、直谏及扩苑；《考异》称此段多后续事而以初出统叙。互见《百官公卿表》确于建元三年初置期门；勘地、谏疏、扩苑不各硬定具体年日。

<a id="hs065-l8445-e16"></a>

**[《汉书·东方朔传》P008](../../拆分史书/汉书/卷065.md#p008)** · [仓内TXT L8445](../../拆分史书/汉书/卷065.md#part-1-L8445)

> 臣聞謙遜靜愨，天表之應，應之以福；驕溢靡麗，天表之應，應之以異。今陛下累郎臺，恐其不高也；弋獵之處，恐其不廣也。如天不為變，則三輔之地盡可以為苑，何必盩厔、鄠、杜乎！奢侈越制，天為之變，上林雖小，臣尚以為大也。

**互校说明** 《东方朔传》录谏疏第一层，以灾异论苑囿逾制。

<a id="hs065-l8446-e16"></a>

**[《汉书·东方朔传》P009](../../拆分史书/汉书/卷065.md#p009)** · [仓内TXT L8446](../../拆分史书/汉书/卷065.md#part-1-L8446)

> 夫南山，天下之阻也，南有江淮，北有河渭，其地從汧隴以東，商雒以西，厥壤肥饒。漢興，去三河之地，止霸產以西，都涇渭之南，此所謂天下陸海之地，秦之所以虜西戎兼山東者也。其山出玉石，金、銀、銅、鐵，豫章、檀、柘，異類之物，不可勝原，此百工所取給，萬民所卬足也。又有岻稻梨栗桑麻竹箭之饒，土宜薑芋，水多麴魚，貧者得以人給家足，無飢寒之憂。故酆鎬之間號為土膏，其賈畝一金。今規以為苑，絕陂池水澤之利，而取民膏腴之地，上乏國家之用，下奪農桑之業，棄成功，就敗事，損耗五穀，是其不可一也。且盛荊棘之林，而長養麋鹿，廣狐兔之苑，大虎狼之虛，又壞人冢墓，發人室廬，令幼弱懷土而思，耆老泣涕而悲，是其不可二也。斥而營之，垣而囿之，騎馳東西，車騖南北，又有深溝大渠，夫一日之樂不足以危無隄之輿，是其不可三也。故務苑囿之大，不恤農時，非所以彊國富人也。

**互校说明** 同一谏疏列举三不可。

<a id="hs065-l8447-e16"></a>

**[《汉书·东方朔传》P010](../../拆分史书/汉书/卷065.md#p010)** · [仓内TXT L8447](../../拆分史书/汉书/卷065.md#part-1-L8447)

> 夫殷作九巿之宮而諸侯畔，靈王起章華之臺而楚民散，秦興阿房之殿而天下亂。糞土愚臣，忘生觸死，逆盛意，犯隆指，罪當萬死，不勝大願，願陳泰階六符，以觀天變，不可不省。

**互校说明** 同一谏疏引殷、楚、秦往事为戒。

<a id="hs065-l8448-e16"></a>

**[《汉书·东方朔传》P011](../../拆分史书/汉书/卷065.md#p011)** · [仓内TXT L8448](../../拆分史书/汉书/卷065.md#part-1-L8448)

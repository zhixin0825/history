# 公元前138年｜济川王被废，梁国分支转入中央管辖

**汉武帝建元三年**

> 本页补入诸侯王年表可确年的王国事务，不表示本年全部军政史事已经收齐；古月不直接换成同号公历月。

<a id="sj017-jichuan"></a>
<a id="济川王刘明因杀害属官被废"></a>

<a id="event-1"></a>

1. **济川王刘明因杀害属官被废。** 刘明被剥夺王位，降为平民，迁往房陵。 他是梁孝王刘武的儿子，原在梁分五国时取得济川。如今朝廷追究他杀害属官的案件，有司请求处死，皇帝没有批准死刑，但不再让他继续统治封国。济川的土地转入汉廷管辖。 [[1]](#note-1)

   封王所带来的地位，不代表可以不受中央司法追究。这一次处置也没有另立刘明的后人接王，而是结束这一支王国。

<a id="sj017-audience"></a>
<a id="中山代长沙三王入朝"></a>

<a id="event-2"></a>

2. **中山王刘胜、代王刘登、长沙王刘发来到朝廷。** 三人分别属于景帝、文帝的子孙；同样称王，既有封国、亲缘和经历并不相同。本年的入朝是各自的在位活动，不是又一次受封。 [[2]](#note-2)

<a id="封侯承袭与侯国的变化"></a>

<a id="sj019-r074-e03"></a>

<a id="event-3"></a>

3. **明接续江阳侯一支。** [[3]](#note-3)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-4"></a>

4. **闽越围攻东瓯，汉廷派严助持节调发会稽兵救援；军队尚未抵达，闽越先行撤围。** 东瓯随后请求内徙，其部众迁入江淮一带，原有地方王国与汉朝内地的关系由此改变。 朝议中田蚡反对救援，严助力主出兵。会稽太守拒绝调兵，严助持节斩一名司马，随后渡海出兵。 [[4]](#note-4)

<a id="sj108-event-5"></a>

5. **韩安国由北地都尉升为大农令。** 韩安国从梁国去官后被武帝起用，先做北地都尉；建元三年入朝任掌国家财政的大农令。 [[5]](#note-5)

<a id="hs-event-6"></a>

6. **平原河溢及饥荒。** 建元三年春，黄河在平原一带溢流，大饥荒中出现人相食的记载。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **移民茂陵受赐并作便门桥。** 徙居茂陵的民户每户获钱二十万、田两顷；本纪还记开始建造便门桥。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **西北见孛星。** 秋七月，史官记西北出现孛星。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **九月月末日食记载。** 九月丙子晦，史官记日食，日次按秦汉旧历。 [[9]](#hs-note-9)

> 至建元三年，閩越發兵圍東甌。東甌食盡，困，且降，乃使人告急天子。天子問太尉田蚡，蚡對曰：「越人相攻擊，固其常，又數反覆，不足以煩中國徃救也。自秦時弃弗屬。」於是中大夫莊助詰蚡曰：「特患力弗能救，德弗能覆；誠能，何故弃之？且秦舉咸陽而弃之，何乃越也！今小國以窮困來告急天子，天子弗振，當安所告愬？又何以子萬國乎？」上曰：「太尉未足與計。吾初即位，不欲出虎符發兵郡國。」乃遣莊助以節發兵會稽。會稽太守欲距不爲發兵，助乃斬一司馬，諭意指，遂發兵浮海救東甌。未至，閩越引兵而去。東甌請舉國徙中國，乃悉舉衆來，處江淮之間。

**本卷归年说明：** 《汉书·严助传》亦载。田蚡当时已免太尉，本传称衔疑沿旧称。援兵未至、闽越撤围、东瓯内徙均是同一事件后段。

#### 卷022｜将相表互见与异说

[卷022 R069原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r069)。本表称“东瓯王广武侯望”率四万余人来降、处庐江郡；汉书武帝纪同年详记救围，严助传补举众内徙、处江淮之间。叙事采用两者可接的救援与内徙次序，数字保留为表的记数，不当作现代人口普查；江淮范围不缩成已核实的单一现代县。许昌相位“二”为续任。

<a id="卷017废王的罪名迁地与朝见"></a>
#### 卷017｜废王的罪名、迁地与朝见

[卷017前138年内容格](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0138)记“明杀中傅，废迁房陵”；[《汉书·武帝纪》建元三年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-a0a117ffd0224c)列太傅、中傅，迁地写防陵；[《梁孝王世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7058.md#ref-1011cad9404620)写射杀中尉、有司请诛而皇帝改废。正文取共同可确定的杀属官、废王和迁徙，官名差别留此，不相加成已经证明三个属官分别被杀。房／防陵为文本异写，不造两次迁徙。

年表前137年再写“为郡”，是前后相接的政治归属，不把废刘明重新发生一遍。来朝三格分别为中山十七、代二十四、长沙十八；姓名据各栏连续王统辨认，月份和会谈内容未载，不补造朝会言辞。

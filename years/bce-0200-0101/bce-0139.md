# 公元前139年｜赵绾王臧下狱，新礼制暂时中止

[← 公元前140年](bce-0140.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前138年 →](bce-0138.md)

**汉武帝建元二年**

本页原有《孝武本纪》的宗庙、郊祭与制度主线，本轮再补诸侯王来朝；不表示武帝当年的战争、税政和全国史事都已收齐。确年的事件据《汉书》核对，卷十二的跨年回叙不当成同年新事。

1. **太皇太后阻止赵绾、王臧。** 赵绾主张不再把政事上奏窦太皇太后，双方冲突终于爆发。 窦氏让人查赵绾、王臧的事，二人被下狱，最后死在狱中。丞相窦婴、太尉田蚡也被免职。 石建继任郎中令，石庆出任内史。 [[1]](#note-1)

<a id="event-2"></a>

2. **筹备中的明堂、巡狩、封禅等计划随之停顿。** 后来武帝仍不断恢复这些议题，但不能把他的后来成功直接提前到此时；也不能把案卷中针对赵、王的指控，当作后世已经独立证明的犯罪事实。 [[2]](#note-2)

   《史记》本段合叙建元初事，《汉书·武帝纪》明确将赵绾、王臧下狱系建元二年冬十月。

<a id="sj017-audience"></a>
<a id="楚鲁淮南清河四王入朝"></a>

3. **楚王刘道、鲁王刘余、淮南王刘安、清河王刘乘来到朝廷。** 四个王国分属不同支系，本年朝见不等于重新封立；刘安后来获罪的案件，也不能提前写成这次入朝已遭定罪。[原格与说明](#sj017-note) 淮南王刘安来朝时，太尉田蚡曾在霸上迎他，以武帝尚未立太子向刘安示意，刘安随后以财物馈赠。 《淮南衡山列传》记田蚡在霸上迎接刘安，谈到武帝若无太子时的继统，刘安随后厚赠财物。 [[3]](#note-3)

7. **赵绾获罪下狱后，窦婴与田蚡也分别失去丞相、太尉的职务，太尉官随之撤去。** 柏至侯许昌接掌丞相。朝廷还设置茂陵邑，为皇帝陵区安排居民与行政建置。 [[7]](#note-7)

<a id="sj049-weizifu-entry-event"></a>

8. **春，卫子夫从平阳公主家进入武帝后宫。** 她出身卑微，来自平阳侯邑，原是公主家的歌者。武帝即位数年无子，公主选十余名良家女子，装饰养在家中，等待进见。皇帝从霸上祓禊归来，经过公主家，对安排的美人都不满意；酒后歌者进前，他才独喜卫子夫。武帝起身更衣，子夫在掌衣车轩中侍候，得到宠幸。回席后皇帝欢喜，赐公主黄金千斤，公主遂请送子夫入宫。上车时，她拍子夫的背，嘱咐好好吃饭、自勉努力，将来贵了不要相忘。 [[8]](#sj049-weizifu-entry-note)

<a id="sj107-event-9"></a>

9. **灌夫醉后击窦甫，转任燕相。** 太仆灌夫与长乐卫尉窦甫饮酒失和，醉后击打窦甫。武帝担心窦太后加罪，调灌夫出任燕国相。 [[9]](#note-9)

[卷022 R068原行](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r068)。免相接本页赵绾、王臧案，不另造第二轮同案。许昌任相本表“二月乙未”，汉表作“三月乙未”，只取本年任相、不强定月份。赵绾在御史栏的姓名是该年度在职及结局线索，并不是他在入狱死后又一次受任。茂陵邑与陵墓全部完工也不同。

**原行四栏：** 大事：置茂陵。嬰免相。；相位：二月乙未，太常柏至侯許昌為丞相。蚡免太尉。罷太尉官。；将位：〔空白〕；御史：御史大夫趙綰。

互校：[《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0139) · [《汉书·武帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7006.md#ref-48e40a898d53f1) · [卷022纪年与异说](../../meta/考证/史记-卷022-纪年与异说.md)。原表数字与空栏照存，未作独立古历日换算。

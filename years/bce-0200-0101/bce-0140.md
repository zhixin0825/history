# 公元前140年｜新帝求贤，儒生开始进入朝廷

1. **武帝征贤良，议明堂、巡狩等礼。** 刘彻继位后，朝廷征求贤良方正、能够直言进谏的人。他倾向用儒家经典来谈礼制和政治。学者赵绾、王臧等因此得到重用，想在长安城南建立明堂，让诸侯依新的礼仪朝见，并讨论巡狩、封禅、历法与服色的改革。窦婴、田蚡参与荐举赵绾、王臧，并推动迎鲁申公、议明堂和令列侯返国。这些事还在草拟，并没有全部落地。窦太皇太后仍在宫中，偏好黄老之学，对儒臣所倡的新礼制不满。新皇帝有意改变方向，不代表已经能够绕开既有的权力关系。赵绾、王臧荐师，武帝礼聘申公，令与议明堂。 [[1]](#note-1)

   《汉书》建元元年还记征贤、减役与祠山川；本文只先吸纳卷012直接叙述的礼制争论，不把其他武帝政务冒充此卷全部内容。

2. **卫绾免相，窦婴、田蚡分任丞相与太尉。** 魏其侯窦婴出任丞相。武帝初年的新政由旧臣、外戚和新进官员共同参与，侯爵与相位并不是同一份任命。卫绾离开相位，窦婴任丞相，田蚡任太尉，牛抵任御史大夫。新政的推行同时伴随中枢换人。窦婴原有魏其侯爵，田蚡则是王太后的弟弟、皇帝的舅父。直不疑也因过免御史大夫。籍福劝田蚡让窦婴居相位，自己担任太尉，从而兼得让贤之名。 [[2]](#note-3)

<a id="event-4"></a>

3. **绰开始接续容成侯爵的纪年。** [[3]](#note-4)

<a id="sj107-event-6"></a>

4. **灌夫入朝任太仆。** 原先出任地方官的灌夫被召入朝，负责太仆之职。其转出为燕相另见次年。 [[4]](#note-6)

<a id="sj122-event-7"></a>

5. **内史寧成抵罪。** 武帝初寧成从中尉徙为内史，外戚多言其过，寧成被判髡钳。 [[5]](#note-7)

<a id="hs-event-8"></a>

<a id="hs-event-9"></a>

6. **朝廷大赦、行三铢钱并给予老人家庭优免。** 赦令、养老优免与三铢钱。春二月大赦天下，民每人进爵一级。八十岁老人免两算，九十岁免甲卒之役；开始推行三铢钱。九十岁老人家属获免役。四月己巳，皇帝说乡里按年龄、朝廷按爵位排列，提倡尊老；想尽孝的人会受公差和家贫所困。年九十以上已有给粥的制度，另令子或孙免役，使他能率妻妾供养老人。 [[6]](#hs-note-8)

<a id="hs-event-10"></a>

7. **常年修举山川之祭。** 五月诏说河海润泽千里，令祠官整修山川祭祀，列为每年常事，各处依礼举行。 [[7]](#hs-note-10)

<a id="hs-event-11"></a>

8. **赦免七国案家属。** 朝廷赦免因吴、楚七国之乱被收没入官的家属。“帑”在这里指连坐的家属。 [[8]](#hs-note-11)

<a id="hs-event-12"></a>

9. **减少卫士交接与赐苑马。** 秋七月诏说卫士轮换送迎原有两万人，裁减一万；撤出苑囿之马赐给贫民。 [[9]](#hs-note-12)

<a id="hs-event-13"></a>

10. **安阳侯周左车｜免爵或免官。** 表载安阳侯周左车一支本年载免除或失爵。表中所载事项为获罪，失爵。 [[10]](#hs-note-13)

<a id="hs-event-16"></a>

#### 卷024｜音乐史事的互见与归年

[卷024 P005](../../sources/摘录/史记-卷024-乐书.md#p005)以“今上即位”引入武帝一朝编乐，叙李延年次序声调、任协律都尉及十九章歌辞；它没有明记这些工作都完成于建元元年。这里接本页[武帝初年礼制讨论](#sj012-140-1)作跨年阅读入口，不把李延年任命、郊祀歌十九章、甘泉经常夜祠统统提前到本年。

[《汉书·礼乐志》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E6%BC%A2%E6%9B%B8-%E5%8D%B7022.md#ref-0e8b60f5ca9d09)分别列安世房中歌十七章、郊祀歌十九章；三家注《索隐》把本处十九章解释为安世房中乐，篇数与汉志有出入，不据注混成一套“安世十九章”。汉志十九章传本内还有太始三年前94年《象载瑜》的作歌注，提示现传曲章并非同年一次编成。《乐书》所谓五经家会讲，是释读歌辞的概述，不由此给每篇歌词加一个建元元年日期。

**R020：** 建元元年有罪免，罪名在本条未详。安阳是景帝时恢复这支所用封国，不把行首汾阴当作周左车始终所持国号。

**R053：** 承袭、国号或年次的完整取舍见[本行武帝核对](../../meta/记录/史记-卷018-武帝逐格核对.md#r053-wu)。

**R104：** 建元元年薨无后两表相合。短格没有死因，不借新帝登位推定政治谋杀。

**R107：** 承袭、国号或年次的完整取舍见[本行武帝核对](../../meta/记录/史记-卷018-武帝逐格核对.md#r107-wu)。

**R135：** 史表作建元元年“罪鬼薪”，汉表同年却记腰斩，两种刑罚不能平均拼成先刑役后处死。正文只取获罪失国，死亡与否暂不定；这个奚信不是另一氏族的淮阴侯韩信。

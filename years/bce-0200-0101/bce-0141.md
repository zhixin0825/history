# 公元前141年｜景帝去世，刘彻继位，王氏的两位弟弟受封

[← 公元前142年](bce-0142.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前140年 →](bce-0140.md)

**汉景帝后三年；刘彻本年继位，次年为建元元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="正月皇帝仍要求把人力用在农桑上"></a>

<a id="event-1"></a>

1. **正月，皇帝仍要求把人力用在农桑上。** 景帝下诏说，黄金珠玉饿时不能吃、冷时不能穿，各郡国应劝农桑，多种能供衣食的作物。 官吏若征发百姓或雇人替自己采金珠玉，要按赃盗治罪，主管二千石纵容也同罪。皇帝晚年的施政，仍把不妨农时和约束官吏放在重要位置。 [[1]](#note-1)

<a id="太子刚行冠礼便要接下皇位"></a>

<a id="event-2"></a>

2. **正月甲寅，刘彻举行冠礼；甲子，景帝死于未央宫。** 刘启从前元七年、中元六年到后元三年，共经历十六个在位年次。遗诏按等级赐爵、赐钱及车马金物，放宫人回家，并给予复免。 [[2]](#note-2)

<a id="event-3"></a>

3. **刘彻继为皇帝，窦氏成为太皇太后，王氏成为皇太后。** 新君虽然登位，上一代皇室长辈和功臣并未随之退出政治；接下来的任官与施政，仍要在这些关系中展开。 王皇太后之母臧儿得到平原君的尊号。刘彻为太子时所娶的陈氏也成为皇后；她是景帝姐姐刘嫖之女，刘嫖曾在刘彻获得储位时大力支持。 武帝初即位时，灌夫由代相一线转任淮阳太守。 武帝初以名将李广为未央卫尉，程不识为长乐卫尉。 《汲鄭列传》载汲黯由太子洗马转任谒者。 [[3]](#note-3)

<a id="二月葬阳陵三月封田氏兄弟"></a>

<a id="event-4"></a>

4. **二月癸酉，景帝葬于阳陵。** 从前153年地名调整、前152年营建陵邑募民，直到本年实际安葬，是多年相连的过程，不是皇帝死后才突然建起一处陵园。 [[4]](#note-4)

<a id="event-5"></a>

5. **三月，田蚡封武安侯，田胜封周阳侯。** 二人是王皇太后的同母弟弟，与先前已经封盖侯的王信应分清。封赏发生在新君即位后，但仍记在景帝后三年的年条里，不直接移到下一年。 [[5]](#note-5)

<a id="sj017-audience"></a>
<a id="胶东王刘寄本年来朝"></a>

<a id="event-6"></a>

6. **胶东王刘寄本年来朝。** 刘寄来到朝廷。 他是刘彻的兄弟；刘彻入储后，胶东在前148年改封给刘寄。此时来朝的胶东王不是已经继承帝位的刘彻。 [[6]](#note-6)

<a id="4天象与篇末评价"></a>
#### 4｜天象与篇末评价

本纪冬十月“日月皆（食）赤五日”、十二月雷、日色、行星和月行等原文，完整留在P017。文字中的校记、连续数日变色与日月食不可机械等同，不编造持续五天的现代天文学日食。

[P018—P019](../../sources/摘录/史记-卷011-孝景本纪.md#p018)分别为传本题作太史公曰的评论和司马贞述赞。前者讨论晁错削藩与后来主父偃之策，后者既赞农政刑制，又责周亚夫之死；这些是史家解释，不是本年新发生的诏令。详见[论赞与文本边界](../../meta/考证/史记-卷011-纪年与异说.md#文本与论赞)。

[卷017前141年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0141)胶东“八，来朝”，对应前148年始王的刘寄。没有月份，不能确定是赴景帝丧、参加刘彻即位典礼，还是此前的朝见；正文只记本年来朝，不由同年丧礼推定出行原因。

<a id="sj030-wenjing"></a>

### 景帝至武帝初年的财计背景

以下为跨年背景或篇末评论，不计作本年新发生的编号事件。

<a id="sj030-wenjing-p005"></a>

**景帝时期卖爵与宫苑扩张**

景帝时上郡以西发生旱灾，朝廷再次采用卖爵办法，并降低所需价额以招人参与；服刑者也可用输粮换取除罪。与此同时，马苑和供用的马匹增加，宫室、楼观、车马也逐渐增修，赈灾筹资与宫廷支出同时存在。

**[《史记·平准书》P005](../../sources/摘录/史记-卷030-平准书.md#p005)**

> 孝景時，上郡以西旱，亦復修賣爵令，而賤其價以招民；及徒復作，得輸粟縣官以除罪。益造苑馬以廣用，而宮室列觀輿馬益增修矣。

本段没有给旱灾的确年，《汉书》也只以“其后”连叙。置景帝末年页面的跨年附录，不把此事直接等同景帝纪任一场已知旱灾。

<a id="sj030-wenjing-p006"></a>

**文景积蓄、武帝初年的富足与兼并**

本卷回望武帝即位数年时的积蓄：除水旱灾年外，许多家庭能够自给，地方与京师仓库储粮充实，钱多到穿钱绳朽坏，陈粮甚至露积腐败。民间养马普遍，社会重视身份、礼义与名声。另一面却是富人兼并、豪强在乡里自行裁断，宗室和官僚竞相奢侈，住宅车服逾越等级；作者随即引出盛而转衰的判断。

**[《史记·平准书》P006](../../sources/摘录/史记-卷030-平准书.md#p006)**

> 至今上即位數歲，漢興七十餘年之閒，國家無事，非遇水旱之災，民則人給家足，都鄙廩庾皆滿，而府庫餘貨財。京師之錢累巨萬，貫朽而不可校。太倉之粟陳陳相因，充溢露積於外，至腐敗不可食。眾庶街巷有馬，阡陌之閒成群，而乘字牝者儐而不得聚會。守閭閻者食粱肉，為吏者長子孫，居官者以為姓號。故人人自愛而重犯法，先行義而後絀恥辱焉。當此之時，網疏而民富，役財驕溢，或至兼并豪黨之徒，以武斷於鄉曲。宗室有土公卿大夫以下，爭于奢侈，室廬輿服僭于上，無限度。物盛而衰，固其變也。

富足与兼并是同段两面，不据此宣布所有农户没有贫困。“七十余年”与“即位数岁”是回顾性的时段描述，不把这一幅社会图景全部归到武帝即位当年。

### 正月，皇帝仍要求把人力用在农桑上

<a id="event-1"></a>

1. **景帝下诏说，黄金珠玉饿时不能吃、冷时不能穿，各郡国应劝农桑，多种能供衣食的作物。** 官吏若征发百姓或雇人替自己采金珠玉，要按赃盗治罪，主管二千石纵容也同罪。皇帝晚年的施政，仍把不妨农时和约束官吏放在重要位置。 [[1]](#note-1)

<a id="太子刚行冠礼便要接下皇位"></a>
### 太子刚行冠礼，便要接下皇位

<a id="event-2"></a>

2. **正月甲寅，刘彻举行冠礼；甲子，景帝死于未央宫。** 刘启从前元七年、中元六年到后元三年，共经历十六个在位年次。遗诏按等级赐爵、赐钱及车马金物，放宫人回家，并给予复免。 [[2]](#note-2)

<a id="event-3"></a>

3. **刘彻继为皇帝，窦氏成为太皇太后，王氏成为皇太后。** 新君虽然登位，上一代皇室长辈和功臣并未随之退出政治；接下来的任官与施政，仍要在这些关系中展开。 [[3]](#note-3)

<a id="二月葬阳陵三月封田氏兄弟"></a>
### 二月葬阳陵，三月封田氏兄弟

<a id="event-4"></a>

4. **二月癸酉，景帝葬于阳陵。** 从前153年地名调整、前152年营建陵邑募民，直到本年实际安葬，是多年相连的过程，不是皇帝死后才突然建起一处陵园。 [[4]](#note-4)

<a id="event-5"></a>

5. **三月，田蚡封武安侯，田胜封周阳侯。** 二人是王皇太后的同母弟弟，与先前已经封盖侯的王信应分清。封赏发生在新君即位后，但仍记在景帝后三年的年条里，不直接移到下一年。 [[5]](#note-5)

<a id="sj017-audience"></a>
<a id="胶东王刘寄本年来朝"></a>
### 胶东王刘寄本年来朝

<a id="event-6"></a>

6. **刘寄来到朝廷。** 他是刘彻的兄弟；刘彻入储后，胶东在前148年改封给刘寄。此时来朝的胶东王不是已经继承帝位的刘彻。 [[6]](#note-6)

[《史记》功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7018.md#ref-5ea29c8fbaaf9d)与[《汉书》功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-c76a6ff65017ca)对读。普通承爵条按元年记载定位；无确月者不补日期，也不据子元年一律倒推父卒。后谥只用于辨认，不当作继位当时已经采用的称号。

[R024](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r024)：史表中六年绍封、后三年薨；汉表绍封后二年薨，约指后元年，存在两年差。正文暂取史表明确后三年；前143年只登记异说，不再写一次最死亡。费、巢是同一功臣行内的前后封号，不合成两个互不相干家族。

<a id="sj011-last-edict"></a>
<a id="1劝农诏的范围"></a>
#### 1｜劝农诏的范围

[《汉书》卷005后三年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7005.md#ref-7071d9db44954f)、[《通鉴》卷016](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7016.md#ref-f3751ec44edd13)。诏令针对官吏役使百姓采金珠玉等行为，不扩大为汉朝从此禁止一切金属开采和货币使用；官吏同罪是规定，不等于已取得全部查办名单。

<a id="sj011-succession"></a>
<a id="2死亡继位安葬与改元分开"></a>
#### 2｜死亡、继位、安葬与改元分开

[卷011 P017](../../sources/摘录/史记-卷011-孝景本纪.md#p017)、汉书与通鉴。甲寅冠、甲子死、二月癸酉葬，均留古月干支，不换成未经核准的现代日期。刘彻即位时“年十六”是古年龄记数，不能据此反推出生到日；建元元年从前140年开始。本卷011的范围止于景帝，后来卷012、017补入的武帝材料仍在各年页，不再把早期整理时的缺页提示当作当前进度。

本纪只简记宫人复免，汉书明言复终身，叙述仍限于获放宫人，不让全国人口都继承同样待遇。所赐户百钱、爵一级等也有不同对象，不能合成一份人人相同的赏单。末句“置阳陵”与各书明确葬年合读，不把它当成第二次营建整个阳陵。

<a id="3田氏与王信"></a>
#### 3｜田氏与王信

[《惠景间侯者年表》武安、周阳条](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7019.md#ref-25387e75f906ee)明确后三年三月；母系关系见[《外戚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7049.md#ref-f8f91f31b49105)。本年只是初封，不提前写他们此后的全部权势及结局。

<a id="4天象与篇末评价"></a>
#### 4｜天象与篇末评价

本纪冬十月“日月皆（食）赤五日”、十二月雷、日色、行星和月行等原文，完整留在P017。文字中的校记、连续数日变色与日月食不可机械等同，不编造持续五天的现代天文学日食。

[P018—P019](../../sources/摘录/史记-卷011-孝景本纪.md#p018)分别为传本题作太史公曰的评论和司马贞述赞。前者讨论晁错削藩与后来主父偃之策，后者既赞农政刑制，又责周亚夫之死；这些是史家解释，不是本年新发生的诏令。详见[论赞与文本边界](../../meta/考证/史记-卷011-纪年与异说.md#文本与论赞)。

<a id="sj017-note"></a>
<a id="5卷017的胶东来朝格"></a>
#### 5｜卷017的胶东来朝格

[卷017前141年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0141)胶东“八，来朝”，对应前148年始王的刘寄。没有月份，不能确定是赴景帝丧、参加刘彻即位典礼，还是此前的朝见；正文只记本年来朝，不由同年丧礼推定出行原因。

# 公元前142年｜饥岁不许拿粟喂马，景帝责贪吏、放宽入仕财产门槛

[← 公元前143年](bce-0143.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前141年 →](bce-0141.md)

**汉景帝后二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="粮食不足先限制对马匹的耗粮"></a>

<a id="event-1"></a>

1. **因收成不好，朝廷禁止内郡拿粟喂马，违令者的马匹收归官府。** 又停止专为马舂粟的做法。百姓缺粮时，不能照旧把可以供人食用的谷物大量用于养马。 [[1]](#note-1)

<a id="event-2"></a>

2. **役作徒隶改用较粗的七緵布衣，列侯中没有必要留京者被遣往封国。** 这些减省措施与年成不足一起记载，但具体节省了多少粮、布和官费，史书没有列出可以直接核算的账目。 [[2]](#note-2)

<a id="三月匈奴攻入雁门太守战死"></a>

<a id="event-3"></a>

3. **三月，匈奴攻入雁门，太守战死。** 雁门太守冯敬迎战匈奴而死，朝廷调车骑、材官增防。 本纪另有郅将军出击的简记，却未留下可据以复原的战役过程。面对边境战争，国家仍不得不动员兵员和资源。 [[3]](#note-3)

<a id="四月皇帝把民生困难指向官员失职"></a>

<a id="event-4"></a>

4. **四月，皇帝把民生困难指向官员失职。** 景帝再次要求劝农桑、少奢侈，并指出有些官吏把收贿当成交易，侵夺百姓。 县丞等长吏如果自己违法、与盗贼为伍，便辜负了职任。各地二千石应整顿所属官员，丞相将不奉职、耗乱者报告治罪。 [[4]](#note-4)

<a id="event-5"></a>

5. **五月，做官所需的财产资格从赀算十降到赀算四。** 皇帝认为，清廉者未必有多大家产，不能只让富而贪的人长期获利。这是降低一项入仕门槛，并非朝廷取消了所有出身、身份和财产限制。 [[5]](#note-5)

<a id="秋季大旱一些地方又有疫病"></a>

<a id="event-6"></a>

6. **秋季大旱，一些地方又有疫病。** 衡山、河东、云中等地记有民疫。 年初曾一日三震，秋季又遭旱灾。粮荒、疫病与兵役可能先后落到同一批居民身上，年页把这些压力同官员整顿一起保留。 [[6]](#note-6)

<a id="sj017-audience"></a>
<a id="齐济北燕三王入朝"></a>

<a id="event-7"></a>

7. **齐王刘寿、济北王刘胡、燕王刘定国本年来到朝廷。** 刘寿承父亲刘将闾的齐国，刘胡承父亲刘勃的济北，刘定国则承接刘嘉的燕国。三人不是七国之乱前那批同国名的旧王。 [[7]](#note-7)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-8"></a>

8. **武原侯不害因葬事超过法定规格而失侯。** 这一罪名说明侯爵身份也受丧葬制度约束，却不足以复原具体墓葬规模。 [[8]](#note-8)

**易｜[R083原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r083)：** 史表景后元二年，[《汉书·景武昭宣元成功臣表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7017.md#ref-c23eb5f812e579)后元三年，暂沿史表。147−142+1=6含死年；另一表147−141=6不含死年。两种算法均可解释六，但不能让两种明确死年变成一致，前141年异说保留，不死两次。

<a id="sj011-grain"></a>
<a id="1几条古语的解释边界"></a>
#### 1｜几条古语的解释边界

[卷011 P016](../../sources/摘录/史记-卷011-孝景本纪.md#p016)、[三家注](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7011.md#ref-1433bc222a1362)、[《汉书》卷005后二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7005.md#ref-90d8d2f128bafd)。索隐把“止马舂”解为停止人为马舂粟，本页采用这一解释，**不写成禁止马拉碓、废掉某种机械**。七緵布依古注解为粗布，不套现代纺织品等级。

汉书“禁内郡食马粟，没入之”的没收对象，颜师古注明确为“没入者，没入其马”。原页误写成没收粟，本轮改正为没收违令者的马匹。古注亦见王子今[《汉帝国“边郡”“内郡”社会结构与行政方式异同》第五节](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-cea14ceaf6553754.md#cite-2)所引，不把“之”凭邻近的粟字解释成粮食。

本纪“禁天下食不造岁”短句的对象及断句不清，原文完整留存，不臆译为一种特定食品禁令；“十月租长陵田”亦留古年条，不补未经核定的征租对象、税率。列侯就国依汉书冬十月，正文按措施分线讲，不假装本页排版已是逐日次序。

<a id="sj011-frontier"></a>
<a id="2不能仅凭姓氏让郅都再出现"></a>
#### 2｜不能仅凭姓氏让郅都再出现

[《通鉴》卷016后二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7016.md#ref-39a7e0712fd220)。本纪郅将军姓名未详，郅都在前述任官过程中已经死亡，本页不将二人直接等同。冯敬在这里是雁门太守，也不凭同名与更早御史大夫合成一人。粮禁主要针对内郡，不由此推断边军马匹全部停供。

<a id="sj011-employment"></a>
<a id="3诏令目标不等于已实现结果"></a>
#### 3｜诏令目标不等于已实现结果

汉书、通鉴四五月诏。赀算四是当时资格单位，不换算成现代财富门槛；诏中同时提市籍不得宦，不能只见减财产限制就说所有商人也取得任官资格。农桑、廉吏是宣示的目标，执行成效仍须其他证据，不能据诏文统计全国腐败已被消除。

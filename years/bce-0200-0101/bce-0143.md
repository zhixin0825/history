# 公元前143年｜诏令要求慎断疑案，周亚夫却在狱中绝食而死

[← 公元前144年](bce-0144.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前142年 →](bce-0142.md)

**汉景帝后元年**

## 正月，朝廷要求疑案逐级送审

**地方无法确定的案件，先交主管官员；仍不能判断的，再移送中央刑狱机关。** 经上报复核以后判断仍有不当，提出请示者不因此承担同样的失判责任。景帝希望办案者先存宽厚之心，不要因为怕担责就一味从重。[1](#sj011-doubts)

**三月赦天下、赐爵，夏季又大酺五日，允许百姓酤酒。** 同时，宫门卫兵主管恢复卫尉的旧名。中二千石、诸侯相所得爵级另有规定，并不是所有官民都受同一爵。[1](#sj011-doubts)

## 八月，卫绾成为丞相

**刘舍免相后，卫绾接任，直不疑为御史大夫。** 卫绾早因吴楚战功封建陵侯，这次是官职上升，不是第一次受封；直不疑也因先前战功获得塞侯爵位。[2](#sj011-ministers)

## 一顿御赐饭食，显露皇帝对周亚夫的不满

**景帝召周亚夫饮食，只给大块未切的肉，又不备筷子。** 周亚夫让侍者取箸，皇帝反问他是不是仍有不满足。周亚夫免冠谢罪，获准起身后急步出去；景帝目送，说这样怏怏不乐的人，不适合辅佐年轻的新君。[3](#sj011-yafu)

这只是传世故事里的一个场景，却接在废储争论、封侯分歧、离开相位之后，说明君臣间的嫌隙并没有随周亚夫退职而消失。

## 陪葬甲楯的案件，最后成了谋反审讯

**周亚夫的儿子购买官府制造的甲楯，准备给父亲作葬具。** 被雇用的人没有得到应付的钱，因怨告发，儿子的案件牵连到父亲。周亚夫被交给官吏审问，不肯回答，景帝又命送入廷尉狱。[3](#sj011-yafu)

**审讯者直接以谋反相责，周亚夫解释只是葬具。** 官吏竟回答，即便不想在地上谋反，也想在地下谋反，逼问越来越急。周亚夫最终五日不食，呕血而死。这位平定吴楚的主帅，没有死在战场，而死在朝廷刑狱中。[3](#sj011-yafu)

## 地震持续，梁国分出的幼王也去世

**五月，上庸一带地震持续二十二日，城墙受损。** 七月又有日食记录。济阴王刘不识在本年去世，他前一年才因梁国五分受封，不能因名字只出现两次便合成无关的两个人。[2](#sj011-ministers)

<a id="sj017-successions"></a>
## 城阳、梁两国进入新王纪年

**刘延接城阳，刘买接梁，分别开始元年。** 前者继父刘喜，后者继父刘武；两位父王的去世与梁五分已在前144年，本年不再另办一次相同分国。刘买在此前还曾受封乘氏侯，由侯进王是身份变化，不是两个人。[4](#sj017-note)

<a id="sj017-audience"></a>
**淄川王刘志、燕王刘定国、赵王刘彭祖本年来朝。** 三人都在原有王统中继续在位，表没有说明与周亚夫案件有关，不把他们编入审讯或请赦的过程。[4](#sj017-note)

<a id="sj018-wenjing"></a>
## 功臣侯家的承袭与兴废

**周勃的另一子坚获封平曲侯。** 周亚夫的狱死已见本页原有叙事；家族的奉祀后来改由坚接续，不把他与郦商之子、缪侯坚混成一个人。 [R017](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r017)

**王翳之子郢人恢复杜衍侯爵。** 前一代翕失爵后，朝廷改取开国功臣的另一子绍封。 [R078](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r078)

**陈始再度失去塞侯爵位。** 恢复封国只延续了很短时间，最终仍因罪中断。 [R008](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r008)

**彭侯武因罪失国。** 秦同一支在几代承袭后失去封爵。 [R088](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r088)

**吴房侯去疾因罪失国。** 从杨武传下的侯爵到此中断，具体案情没有在短表中展开。 [R089](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r089)

[R043](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r043)：角元年后接有罪国除，两表皆无更细日期。这里确定后元年承爵，后来失国作为相连后事说明，不假称已有同日判决。

[R089](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r089)：史表前有十四而后称后元年，景帝后元年为整个在位第十四年；它不是后元十四年。合计数用于交代此前岁数，本文采用明记后元年。

[R136](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r136)：刘舍免相、卫绾接任已在本页；桃侯家爵没有因此自动传给卫绾。

<a id="sj011-doubts"></a>
### 1｜一般审判原则与政治案件并存

[卷011 P015](../../sources/摘录/史记-卷011-孝景本纪.md#p015)、[《汉书》卷005后元年](https://zh.wikisource.org/wiki/漢書/卷005)、[《通鉴》卷016](https://zh.wikisource.org/wiki/資治通鑑/卷016)。疑狱逐级上谳与前145年诏令相接，不能因有宽刑诏就否认本年的政治狱案，也不能反过来认为诏令全无制度意义。前144年廷尉改大理，而诏文、列传仍习称廷尉，本页保留来源用语，不另造两套同时审案的同职机关。卫尉是景帝初曾改称中大夫令的宫门官，此时恢复旧名，不与御史大夫相混。

<a id="sj011-ministers"></a>
### 2｜官职、爵号和灾情

卫绾官位由本纪、通鉴核合，塞侯直不疑的初封见[卷019侯表](https://zh.wikisource.org/wiki/史記/卷019)。本纪任相时再写封建陵侯，不能与前151年初封重复计数。上庸连续震日和坏城是所报灾情，未据此计算现代震级；刘不识死亡未给病因，不附会为地震所致。

<a id="sj011-yafu"></a>
### 3｜免相与死亡隔了数年，谋反罪名不是证明

[《绛侯周勃世家》](https://zh.wikisource.org/wiki/史記/卷057)、汉书、通鉴。前147年是免相，本年才狱死，三家注中三年“死”校“免”的问题由此分开。甲楯五百为书中记数，葬具与可用于作战的器物究竟如何界定，文本没有提供足够实物证据；不能只因官吏控反就认定他确已组织叛乱，也不能无证据把购买官器全部说成毫无违法可能。

绝食、呕血、饭食试探与“反地下”的对白按传世叙事呈现，不冒称现场逐字笔录。本纪正文未展开此案，索隐述赞却明确提及，故以相关世家和编年底本补入实际年页，不让功臣的结局只剩一条评论。

<a id="sj017-note"></a>
### 4｜卷017元年、来朝与济阴除国

[卷017前143年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0143)城阳延、梁买元年及淄川、燕、赵来朝，归本页。济阴二年“薨，无后，国除”与[梁孝王世家](https://zh.wikisource.org/wiki/史記/卷058)“一年卒”记数不同；前144封、前143死的连续年条保留，不单凭一年、二年就假定存在两位刘不识或多活一年。继承、年次和实际满年时长不能混作同一种计数。

所读网页本行后半表格有列界异常，须用邻行王统与世家核合；“济阴除国”不因网页展平错位而移给另一国家。月日未载，不推定三王来朝与济阴丧事同日。

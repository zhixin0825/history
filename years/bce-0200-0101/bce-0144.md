# 公元前144年｜梁孝王死后分国为五，笞刑继续减轻并限定行刑办法

[← 公元前145年](bce-0145.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前143年 →](bce-0143.md)

**汉景帝中六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="冬十月梁王想留在京城景帝没有答应"></a>

<a id="event-1"></a>

1. **冬十月，梁王想留在京城，景帝没有答应。** 刘武入朝后请求留下，得到的仍是返回封国的命令。 他回梁以后心情郁郁。兄弟之间虽然没有因袁盎案彻底决裂，却也没有恢复早年的亲密。 [[1]](#note-1)

<a id="十二月一批中央官职改了名字"></a>

<a id="event-2"></a>

2. **十二月，一批中央官职改了名字。** 掌刑狱的廷尉改称大理，营建宫室的将作少府改称将作大匠，奉常改称太常。 长信詹事改长信少府，将行改大长秋，典客改大行，原大行改行人，治粟内史改大农，主爵中尉改都尉。另调整大内的秩级、设置左右内官。 [[2]](#note-2)

   不同职掌同时改名，并不意味着官员全部更换，也不等于同名的都尉都属于同一套军队机构。理解其职掌，比把一串官名当成一批新人物更重要。

<a id="四月梁王去世窦太后的悲痛又成了朝廷的难题"></a>

<a id="event-3"></a>

3. **四月，梁王刘武去世，窦太后的悲痛又成了朝廷的难题。** 刘武返国以后郁郁不乐。传说他北猎良山时，有人献上一头背上生足的牛，他以为不吉；后来患热病而死。窦太后极其悲痛，不愿进食，还责怪景帝害死弟弟。景帝忧惧，与长公主商议，决定把梁国分成五国，将刘武五个儿子全部立为王，五个女儿也各得汤沐邑。消息报给太后，她的情绪才有所缓和。传记称刘武死后藏府黄金尚有四十余万斤，其他财物相称。 《司马相如列传》以梁孝王卒为相如结束客梁、返回蜀地的转折。 [[3]](#note-3)

   | 梁孝王之子 | 本次安排 |
   |---|---|
   | 刘买 | 承继梁王 |
   | 刘明 | 济川王 |
   | 刘彭离 | 济东王 |
   | 刘定 | 山阳王 |
   | 刘不识 | 济阴王 |

   这既照顾了窦太后和梁王的后代，也把原来强大的一个梁国分为五份。亲情上的安抚与政治上的分割，在同一项决定中实现。

<a id="sj011-flogging"></a>
<a id="五月前后不只减笞数也约束怎样打"></a>

<a id="event-4"></a>

4. **五月前后，景帝再次减少笞刑。** 景帝再次减少笞刑：原三百下改二百，原二百下改一百。 前156年已经减过一次，但受刑者仍可能在打完以前死亡，皇帝要求继续调整。 [[4]](#note-4)

<a id="event-5"></a>

5. **刘舍、卫绾提出箠令，限定刑具尺寸、打击部位和执刑方式。** 箠须削平节部，不留下容易额外伤人的突节；行笞打臀，同一罪的笞刑执行完以前不得换人轮打。减少击数之外，还要防止行刑者用不受控制的办法增加伤害。 [[5]](#note-5)

<a id="边境仍在作战京城又换了一位严厉的中尉"></a>

<a id="event-6"></a>

6. **六月，匈奴进入雁门、上郡，夺取苑马，汉吏卒有二千人战死的记载。** 和亲没有完全制止边境冲突。李广在这一阶段任上郡太守，边将需要在兵力、消息都不充分的条件下作决定。 李广守上郡期间曾领百骑追索射手，遇见数千敌骑。他命从骑下马解鞍，使匈奴怀疑汉有大军伏在附近，匈奴最终退去。 [[6]](#note-6)

<a id="event-7"></a>

7. **郅都死后，京城宗室犯法增多，景帝召宁成为中尉。** 宁成效法郅都的严厉，却没有同样的廉洁，仍令宗室豪强畏惧。执法有威力与执法者本身没有问题，不能简单画等号。 [[7]](#note-7)

<a id="event-8"></a>

8. **城阳共王刘喜在本年去世，儿子刘延承继。** 刘喜从前176年元年至本年，合三十三个王年，包含迁淮南、复城阳两个阶段，不能另把淮南时长叠加。刘延下一年才起元年。春巡雍、雨雪或冰雹、七月日食等照原记录保留，不作为诸王死亡的神意解释。 [[8]](#note-8)

9. **陈贺之子最被封为巢侯，恢复家族奉祀。** 费侯偃失爵以后，这一支改由另一名子嗣接续。 [[9]](#note-9)

<a id="event-10"></a>

10. **郭延居被绍封为南侯。** 阿陵一支此前因罪中断，此次以新的国号恢复，不把原来获罪的胜客与延居混为一人。 [[10]](#note-10)

<a id="event-11"></a>

11. **舞阳侯它广被认定不是市人之子，因而失去继承资格，侯国撤销。** 朝廷认定的是爵位继承问题，史料不足以让编者独立断定真实生父。 [[11]](#note-11)

<a id="event-12"></a>

12. **海阳侯省去世，无后，封国终止。** 与舞阳的资格争议不同，此处只记没有可继承的后嗣。 [[12]](#note-12)

<a id="event-13"></a>

13. **发娄侯丁通再次因罪失爵。** 原表将复封、再失先后系在中五年和中六年；另一表任期不同，不能把两套数字相加为第三次处罚。 [[13]](#note-13)

<a id="event-14"></a>

14. **堂阳侯德因罪失国。** 这支从孙赤的战功起家，延续到本年才结束。 [[14]](#note-14)

<a id="event-15"></a>

15. **张侯舜因罪失国。** 他属于毛泽的一支，不是昭因七国战功复封的另一张侯。 [[15]](#note-15)

<a id="1刘武的死年与梁国五分"></a>
#### 1｜刘武的死年与梁国五分

[卷011 P014](../../sources/摘录/史记-卷011-孝景本纪.md#p014)、[《梁孝王世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7058.md#ref-759139d7dcf9cb)、[《通鉴》卷016中六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7016.md#ref-74b638082bf8a1)。本纪前六年提前写“梁楚二王皆薨”，本页用中六年的明确叙事；不在前151年再记一次。原本纪列四位新王却说梁分五，长子刘买承梁由世家、通鉴补齐。太后归罪皇帝是人物发言，不是已证明景帝直接杀弟。

<a id="2官名改换不是一次性从无到有"></a>
#### 2｜官名改换不是一次性从无到有

[《汉书》卷005中六年十二月](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7005.md#ref-586fa2020e28e9)及[《百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-section-2)解释职掌；本纪在本年稍后汇列这些改名。主爵的都尉与前148年郡尉改都尉是不同机构。长信少府服务太后宫，与将作大匠等不可仅凭少府字样合成一官。官员衣服车驾与秩级相称的五月诏亦见汉书，属于维护等级的配套安排，未写成现代公务服标准。

<a id="sj011-flogging-note"></a>
<a id="3箠令与改革效果"></a>
#### 3｜箠令与改革效果

[《汉书》卷023《刑法志》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7023.md#ref-22fd81ba385ba1)列两次减笞及箠令，卷005五月条与通鉴同年可互见。原文还给箠长五尺、根一寸、末半寸等尺寸；本页不未经尺度研究折算厘米。“毋得更人，毕一罪乃更人”按同一罪不轮换执刑者解释，不延伸为现代刑讯技术。刑法志称受笞者得以保全，随即又说酷吏仍用以立威，故不能宣称改革后全国再无伤亡和滥刑。

<a id="4巡行边事与未能确认的王号"></a>
#### 4｜巡行、边事与未能确认的王号

本纪二月己卯幸雍，通鉴二月乙卯，汉书则放冬十月；正文不造三次巡行。三月雨雹、雨雪也有异写，留在对应原文。边境入侵本纪八月，汉书、通鉴六月较详，采用后者；李广百骑解鞍疑兵的故事以“尝”回叙，未给确月，只作其任内事，不全部定在六月一日。

P014另称“汝南王”死亡，但旧汝南王刘非早已迁江都，不能仅凭这一孤称替他再造死亡年。原句在来源保存，归年暂不定。本纪“封四侯”未具名单，亦不猜补四个人。宁成任中尉的前情见通鉴及[《酷吏列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7122.md#ref-e27ef313ca6405)，不把他武帝时后续提前。

<a id="5卷017的封王月份与两王去世"></a>
#### 5｜卷017的封王月份与两王去世

[卷017前144年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0144)梁来朝、薨与四子初封，均接本页一组事件。四位新王列五月丙戌，《梁孝王世家》却说刘武六月死，《通鉴》采用四月；正文继续沿既有通鉴四月死亡、随后分封的主线，明确三种月次并不全合，不造另一场死亡来凑五月授封。刘买承梁列下一年元年，是受位与纪年衔接；前145年的四个分国提示不是四王已经提前受封。

城阳刘喜三十三年薨包括他先王城阳、迁淮南、再回城阳的连续经历，不能说本国始终由他连续统治而从未改置。儿子刘延元年接[前143年](bce-0143.md#sj017-successions)。本页说明所采用的编年，不宣称已完成原表全部错简与历谱的最终校定。

**汉景帝中五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="王号还在独立处理政务的空间却更小"></a>

<a id="event-1"></a>

1. **朝廷改诸侯国丞相为相，进一步限制国王亲自治国，国中官员由天子设置。** 此前已经裁减部分王国官署，这一阶段又缩减廷尉、少府、宗正、博士等机构和官员。七国战争没有马上取消所有王国，却逐步改变了国王与中央的权力关系。 [[1]](#note-1)

<a id="event-2"></a>

2. **皇子刘舜同时被立为常山王。** 封王和削减王国权力并不矛盾：名义上继续让宗室分守，实际政务则更多受中央约束。 [[2]](#note-2)

<a id="四五月外戚宗室和来降者分别封侯"></a>

<a id="event-3"></a>

3. **四五月间，王信及部分宗室受封为侯。** 王信终于被封为盖侯。他是王皇后的兄长，前几年周亚夫曾以无军功为由反对封他；如今亚夫已经离开相位，封赏得以落实。长公主之子陈蟜封隆虑侯，梁王之子刘买、刘明分别封乘氏侯、桓邑侯。 [[3]](#note-3)

<a id="event-4"></a>

4. **卢氏后人来降，受封亚谷侯。** 这个家族在高祖晚年逃往匈奴之后，又有人以归降者身份返回汉廷。其姓名在侯表、注释间有异写，先依亲属身份辨认，不为异名另造一人。 [[4]](#note-4)

<a id="六月赦罪九月要求官吏不要勉强定案"></a>

<a id="event-5"></a>

5. **六月赦罪，九月要求官吏不要勉强定案。** 六月，朝廷大赦、赐民爵一级。 九月又下诏指出，有些官吏收受财物、结成朋党，把苛刻当作明察，使无罪者遭难；有疑问的案件，甚至形式上勉强套得上法条、却不能使人心服的案件，都应上报复核。 [[5]](#note-5)

   这道诏令不是说遇到争议一律无罪，而是要求官吏不要为了结案而强行附会法条。下一年继续减笞、再下一年细化疑案移送，都沿着防止刑罚过当的问题推进。

<a id="水灾宫火与地震"></a>

<a id="event-6"></a>

6. **本年有大水，八月未央宫东阙失火，秋季又记地震。** 京城与地方受到的影响各不相同，材料没有给出足够数字，不把几条记录相加成一个全国损失总数。 [[6]](#note-6)

<a id="sj017-audience"></a>

<a id="event-7"></a>

7. **楚王刘道、胶东王刘寄、长沙王刘发本年来朝。** 刘寄接的是刘彻入储以后留下的胶东国，而非刘彻本人继续以王身份来朝。三个国栏各记本年活动，没有共同会谈记录。 [[7]](#note-7)

#### 1｜王国制度的总括与前次裁官分开

[卷011 P013](../../sources/摘录/史记-卷011-孝景本纪.md#p013)、[《汉书》卷005中五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7005.md#ref-4c6a8a64681ca3)、[《百官公卿表》诸侯王条](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-section-35)。本纪只记丞相改相，百官表另有“不得复治国，天子为置吏”及裁官总述。前147年御史官裁撤仍留原年，不能因总括又出现就算本年再撤一遍；后来的武帝、成帝改制也不全部提前。法定安排与各国实际执行程度，仍不是同一个证据问题。

<a id="sj011-five-hou"></a>
<a id="2封十侯不凭猜测补成十人"></a>
#### 2｜“封十侯”不凭猜测补成十人

[《惠景间侯者年表》景帝部分](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7019.md#ref-efa2f42638ec9b)明确列本年亚谷、隆虑、乘氏、桓邑、盖五项：亚谷四月丁巳，陈蟜五月丁丑，刘买、刘明五月丁卯，王信五月甲戌。本纪说十侯，三家注已讨论计数困难，本文只列能核的五项，不把前147年的匈奴降侯擅自搬来凑数。亚谷侯名在侯表作它父、注中作他之，留异写。

陈蟜初封在本纪前五年也出现，采用侯表的中五年，前152年只留异说。刘买、刘明本年为侯，下一年才分别承梁、王济川。栾布在侯表也记本年去世，属于此前七国将领的后续，未另给月日；没有把整张侯表和所有后嗣都算作本卷已整理完成。

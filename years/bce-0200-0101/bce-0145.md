# 公元前145年｜诸侯王的治国权继续收缩，疑案须上报复核

[← 公元前146年](bce-0146.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前144年 →](bce-0144.md)

**汉景帝中五年**

## 王号还在，独立处理政务的空间却更小

**朝廷改诸侯国丞相为相，进一步限制国王亲自治国，国中官员由天子设置。** 此前已经裁减部分王国官署，这一阶段又缩减廷尉、少府、宗正、博士等机构和官员。七国战争没有马上取消所有王国，却逐步改变了国王与中央的权力关系。[1](#sj011-kingdom-offices)

**皇子刘舜同时被立为常山王。** 封王和削减王国权力并不矛盾：名义上继续让宗室分守，实际政务则更多受中央约束。[1](#sj011-kingdom-offices)

## 四五月，外戚、宗室和来降者分别封侯

**王信终于被封为盖侯。** 他是王皇后的兄长，前几年周亚夫以无军功为由反对封他，如今周亚夫已经离开相位，这项封赏得以落实。长公主之子陈蟜封隆虑侯，梁王之子刘买、刘明分别封乘氏侯、桓邑侯。[2](#sj011-five-hou)

**故燕王卢绾的儿子来降，受封亚谷侯。** 这个家族在高祖晚年逃往匈奴之后，又有人以归降者身份返回汉廷。其姓名在侯表、注释间有异写，先依亲属身份辨认，不为异名另造一人。[2](#sj011-five-hou)

## 六月赦罪，九月要求官吏不要勉强定案

**六月，朝廷大赦、赐民爵一级。** 九月又下诏指出，有些官吏收受财物、结成朋党，把苛刻当作明察，使无罪者遭难；有疑问的案件，甚至形式上勉强套得上法条、却不能使人心服的案件，都应上报复核。[3](#sj011-review)

这道诏令不是说遇到争议一律无罪，而是要求官吏不要为了结案而强行附会法条。下一年继续减笞、再下一年细化疑案移送，都沿着防止刑罚过当的问题推进。

## 水灾、宫火与地震

**本年有大水，八月未央宫东阙失火，秋季又记地震。** 京城与地方受到的影响各不相同，材料没有给出足够数字，不把几条记录相加成一个全国损失总数。[3](#sj011-review)

<a id="sj017-audience"></a>
**楚王刘道、胶东王刘寄、长沙王刘发本年来朝。** 刘寄接的是刘彻入储以后留下的胶东国，而非刘彻本人继续以王身份来朝。三个国栏各记本年活动，没有共同会谈记录。[4](#sj017-note)

<a id="sj011-kingdom-offices"></a>
### 1｜王国制度的总括与前次裁官分开

[卷011 P013](../../sources/摘录/史记-卷011-孝景本纪.md#p013)、[《汉书》卷005中五年](https://zh.wikisource.org/wiki/漢書/卷005)、[《百官公卿表》诸侯王条](https://zh.wikisource.org/wiki/漢書/卷019#諸侯王)。本纪只记丞相改相，百官表另有“不得复治国，天子为置吏”及裁官总述。前147年御史官裁撤仍留原年，不能因总括又出现就算本年再撤一遍；后来的武帝、成帝改制也不全部提前。法定安排与各国实际执行程度，仍不是同一个证据问题。

<a id="sj011-five-hou"></a>
### 2｜“封十侯”不凭猜测补成十人

[《惠景间侯者年表》景帝部分](https://zh.wikisource.org/wiki/史記/卷019)明确列本年亚谷、隆虑、乘氏、桓邑、盖五项：亚谷四月丁巳，陈蟜五月丁丑，刘买、刘明五月丁卯，王信五月甲戌。本纪说十侯，三家注已讨论计数困难，本文只列能核的五项，不把前147年的匈奴降侯擅自搬来凑数。亚谷侯名在侯表作它父、注中作他之，留异写。

陈蟜初封在本纪前五年也出现，采用侯表的中五年，前152年只留异说。刘买、刘明本年为侯，下一年才分别承梁、王济川。栾布在侯表也记本年去世，属于此前七国将领的后续，未另给月日；没有把整张侯表和所有后嗣都算作本卷已整理完成。

<a id="sj011-review"></a>
### 3｜诏令与灾情

[《通鉴》卷016中五年](https://zh.wikisource.org/wiki/資治通鑑/卷016)与汉书。疑案上谳是古代复核办法，不称作与现代审判制度相同。大水、宫火、地震各有记载，不用来证明朝廷某项政策引发天谴。

<a id="sj017-note"></a>
### 4｜卷017来朝、刘舜封月与梁国先导栏

[卷017前145年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0145)三王来朝归本页。刘舜初王表记四月丁巳，本纪、汉书编年另系三月，正文保留本年封王而不强选唯一无争议日；前一年常山复置只是先导，不重复授命。

济川、济东、山阳、济阴四个分国栏在本年提前列出，正式五子分梁仍接[前144年](bce-0144.md#sj011-liang-death)。本年刘买、刘明受侯与下一年封王是不同爵位、不同步骤，不能把四个栏目提示与两次侯封拼成一批本年已经成立的五个王国。

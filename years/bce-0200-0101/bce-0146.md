# 公元前146年｜德阳宫营建，蝗灾与阳陵刑徒的赦免同见年条

[← 公元前147年](bce-0147.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前145年 →](bce-0145.md)

**汉景帝中四年**

## 三月，朝廷营建德阳宫

**德阳宫开始兴建。** 景帝已经有未央、长乐等宫室，仍增加新的建筑。德阳宫后来与景帝庙的关系，在古注中有特别解释；本年的短记不足以复原一套完整布局。[1](#note-palace)

## 大蝗之年，朝廷仍在管理马匹出关

**夏季发生蝗灾。** 卫绾又奏请限制高大、年轻马匹出关，把重要的畜力资源留在控制范围内。灾情、军马与国家物资管理，在这一年一同出现。[2](#note-law)

## 秋季，阳陵役作人员获得赦免安排

**朝廷对营建阳陵的刑徒作出赦免规定。** 相关条文又保留“死罪”“欲腐者许之”的内容，说明死罪、役作与受宫刑之间仍存在法律上的转换。文帝曾除肉刑、景帝又减笞，并不等于一切损伤身体的刑罚早已消失。[2](#note-law)

<a id="sj017-audience"></a>
**淮南王刘安、中山王刘胜、长沙王刘发本年来朝。** 刘安出自高祖之子刘长一支，另外两人是景帝之子。朝见没有具体月日和议事内容，不把三人安排成阳陵赦徒或马政限制的共同建言者。[3](#sj017-note)

**煮枣侯昌因罪失国。** 他承爵后不久即失去封邑，不能从短短两年就补出具体争位或谋反故事。 [R140](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r140)

[《史记》功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7018.md#ref-0357deeea2654a)与[《汉书》功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-8e2416932050b5)对读。普通承爵条按元年记载定位；无确月者不补日期，也不据子元年一律倒推父卒。后谥只用于辨认，不当作继位当时已经采用的称号。

[R069](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r069)：午元年之后“中绝”没有确年，列为以后未定年后事；不把它当作本年继位当天即被废。

<a id="note-palace"></a>
### 1｜德阳宫不直接套用后来同名建筑

[卷011 P012](../../sources/摘录/史记-卷011-孝景本纪.md#p012)、[三家注](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7011.md#ref-2f4c3ff524e958)。臣瓒据旧说解释为景帝自作之庙而称宫；正文只写本年营建，解释留注，不把它与东汉洛阳同名宫殿混为一个遗址。

<a id="note-law"></a>
### 2｜赦徒不等于无条件全部释放

[《汉书》卷005中四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7005.md#ref-827e79f4d915b0)详于本纪，所读网页作“赦徒作阳陵者死罪；欲腐者，许之”，其中断句及两类对象的精确关系仍须结合刑法材料考辨。本文不把这条扩为全国刑徒一律免刑，也不说宫刑已被取消。马匹限制原文给出高度、齿龄条件，保留于来源，不直接换算现代马种标准。年末附十月日食照旧年条阅读，未作公历转换。

<a id="sj017-note"></a>
### 3｜卷017三王来朝与常山栏目

[卷017前146年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0146)三个来朝格归本页，常山“复置”则是[前145年刘舜受封](bce-0145.md#sj011-kingdom-offices)的先导，不在本年又封一次。此前恒山、太原等国曾借用同一物理栏位，不能因横向位置相同就说所有国始终同疆。

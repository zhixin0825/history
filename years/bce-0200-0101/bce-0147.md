# 公元前147年｜周亚夫免相，王国机构继续削减，旱蝗接踵

[← 公元前148年](bce-0148.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前146年 →](bce-0146.md)

**汉景帝中三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="王国的官署被继续裁减"></a>

<a id="event-1"></a>

1. **冬十一月，朝廷撤去诸侯国的御史大夫一类官职。** 七国战争结束以后，中央并没有把原有王国机构原样保留。诸王还在，但能够比照中央设置的官署逐渐减少。 [[1]](#note-1)

<a id="event-2"></a>

2. **三月，皇子刘乘被封为清河王。** 裁减官署与分封皇子可以同时发生：争论的重点不只是有没有王国，还包括国王实际能处理多少政务。 [[2]](#note-2)

<a id="封不封外戚降王使丞相与皇帝越来越不合"></a>

<a id="event-3"></a>

3. **亚夫任相期间，曾反对无功封王信为侯。** 窦太后要求封景帝王皇后的兄长王信，景帝先以先帝未封南皮、章武作推辞。太后举窦长君生前未侯、死后儿子彭祖才封的遗憾，催促办理；景帝再问丞相。亚夫援引高祖非刘氏不得王、无功不得侯的誓约反对，景帝当时停止。这次争论没有独立确年，王信到前145年才实际受封。 [[3]](#note-3)

<a id="event-4"></a>

4. **匈奴首领来降，景帝要封侯以招徕后来者，周亚夫再次反对。** 亚夫认为徐卢等人背弃旧主，不应封赏，以免损害为臣守节的准则。景帝却要借封侯鼓励后来者来降，明确拒绝了他的意见，并把降人封侯。九月，周亚夫称病免相，桃侯刘舍接任。 [[4]](#note-4)

<a id="旱灾以后又出现蝗灾"></a>

<a id="event-5"></a>

5. **夏季旱，朝廷禁售酒；秋九月又有蝗灾。** 减少酿售酒与保护粮食有关，但禁令本身不能替代降雨或救济。同年四月地震、九月日食，还有彗星记录；年页不把它们仅当作政治人物遭遇的陪衬。 [[5]](#note-5)

<a id="sj017-audience"></a>
<a id="衡山燕代三王入朝"></a>

<a id="event-6"></a>

6. **衡山王刘赐、燕王刘定国、代王刘登入朝。** 刘赐曾经王庐江，刘定国和刘登则分别接续父亲的封国。国名相同或相近不等于前任国君仍在位，也不能把三人的朝见并作一次有完整议程的会议。 [[6]](#note-6)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-7"></a>

7. **郦商的另一子坚被封为缪侯，恢复家族奉祀。** 郦寄失爵以后，朝廷没有沿原位不加区分地传下，而是从另一子重新授爵。 [[7]](#note-7)

<a id="event-8"></a>

8. **甘泉侯嫖因罪失国。** 原表用景帝合计“十年”，对应前七年以后、中元三年，并不是另有一个中元十年。 [[8]](#note-8)

<a id="sj018-succession"></a>

<a id="event-9"></a>

9. **侯爵继续在各家传承。** 以下记录本年开始的侯年；继承家爵不等于同时承接父辈的中央官职。 [[9]](#note-9)

   | 侯籍一支 | 本年变化 |
   |---|---|
   | 潁陰 | 强接颍阴侯，续何一代。 |
   | 新陽 | 谭接新阳侯，续善一代；汉表名谈。 |
   | 襄平 | 纪相夫接襄平侯，续纪通一代。 |
   | 繁 | 安国接繁侯，续寄一代。 |
   | 宣平 | 生接宣平一支，续欧一代；汉表名王。 |
   | 開封 | 陶偃接开封侯，续陶青一代。 |

   [本段原文、异年及说明](#sj018-note)。

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-10"></a>

10. **刘舍接任丞相后，卫绾出任御史大夫。** 卫绾此前已在宫廷和军队任职，这次是中央官位的升迁，与后来成为丞相仍隔着数年。 [[10]](#note-10)

<a id="note-offices"></a>
<a id="1御史中丞与御史大夫"></a>
#### 1｜“御史中丞”与“御史大夫”

[卷011 P011、T001](../../sources/摘录/史记-卷011-孝景本纪.md#p011)、[《汉书》卷005](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7005.md#ref-16c4f0b4f0446d)、[《通鉴》卷016](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7016.md#ref-1bb50d9a1f0951)。本纪短本称御史中丞，汉书、通鉴称御史大夫，正文沿后者，不推为同年分两次撤去两套机关。刘乘在三家注本有方乘写法，不另作两位皇子。

<a id="note-yafu"></a>
<a id="2没有在本年把周亚夫写死"></a>
#### 2｜没有在本年把周亚夫写死

[三家注中三年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7011.md#ref-673e1eda7e1602)存周亚夫“死”校“免”，主见证却省掉整段。通过[《绛侯周勃世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7057.md#ref-382fdf2f674e7d)、汉书、通鉴可将本年免相与[前143年狱死](bce-0143.md)分开。降王人数在本纪作二人、详细叙事作徐卢等六人，侯表又分列诸人；此处只说一批首领，不把记数硬凑成同一队同日来降。王信实际受封另见前145年。

<a id="note-text"></a>
<a id="3补足短本不照抄明显矛盾"></a>
#### 3｜补足短本，不照抄明显矛盾

中三年补文还记东都门外驻军，具体事由未详，留在[来源T001](../../sources/摘录/史记-卷011-孝景本纪.md#t001)。所读汉书网页另有本年正月“皇太后崩”，但窦太后此后仍在，本纪也未记此事；不据这句另造窦氏或薄氏的确定死亡年。薄太皇太后已死于前155年，三者不得混同。旱、禁酤、蝗灾由汉书通鉴本年条补入。

<a id="sj017-note"></a>
<a id="4卷017的清河封王与临江异年"></a>
#### 4｜卷017的清河封王与临江异年

[卷017前147年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0147)衡山、燕、代来朝分别落实；清河刘乘三月丁巳与汉书王表丁酉有异，正文只用可共同支持的三月，不另算唯一公历日期。前一年清河都清阳的初置格，作为此次建国的地理提示，不假定王已在前148年到国。

临江刘荣案、死亡和改南郡，本表虽列在本年，仍归[前148年三月](bce-0148.md#sj017-note)的本纪、汉书、通鉴主线，不再处死同一人。与本年周亚夫免相一样，必须分别辨别职务变化、政治案件和后来死亡，而非照摘要中的一个字定年。

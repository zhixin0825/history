## 本年概述

被废的太子刘荣在京城自杀，窦太后追究经办案件的郅都。袁盎等遇刺后，线索指向梁国，文吏奉命往查，最后由田叔向景帝回奏。朝廷另封刘越、刘寄等诸侯王，处置一批列侯爵位。

## 临江王、梁国案与朝廷处置

<a id="三月被废的太子死在京城"></a>

<a id="event-2"></a>

1. **临江王刘荣自杀，窦太后追究郅都。** 三月，临江王刘荣因修宫侵入太宗庙旁的地界，被召到中尉府审讯。传记称，他在江陵北门祭行神后出发，上车时车轴折断，父老流泪说此去恐怕不能回来。受讯时，刘荣请求刀笔，想写信向父皇说明，郅都却不准属吏提供。窦婴让人私下送入，刘荣写完以后自杀。他死后葬于蓝田，又留下数万燕子衔土置冢的传说。窦太后对郅都怀恨，后来一定要治他的罪。郅都被免后又得到景帝起用，去守雁门，但最终仍未能逃过处死。审讯皇子、执行法律与皇室私情，发生了激烈冲突。 [[1]](#note-1)

2. **袁盎等遇刺，梁王涉案，田叔回奏。** 刘武宠信羊胜、公孙诡，听他们策划争取皇位，又怨袁盎等大臣阻止。他曾想修一条从梁通到长乐宫的甬道，便于直接朝见母亲，也遭反对。刘彻既已立为太子，刘武的希望更小，最后竟派人刺杀袁盎及其他议臣。追捕刺客的线索指向梁国，朝廷派田叔等前往调查。羊胜、公孙诡藏在王宫，梁相轩丘豹、内史韩安国等被迫全力搜查。韩安国哭谏，说连皇帝亲生的刘荣都不能保全，梁王更不能一直把希望寄托在太后庇护上。经轩丘豹、韩安国劝谏，刘武终于命二人自杀，交出尸体，又使韩安国经长公主向太后谢罪。田叔回京途中烧掉案卷，向景帝说明，若依法处置梁王，太后将无法承受。景帝接受了不再深究的办法，向太后说明主要责任在羊胜、公孙诡。梁王求朝时，茅兰教他改乘布车，只带两骑入关，藏于长公主园，把车骑留在关外。迎使找不到人，太后疑皇帝杀了儿子；刘武随后伏在阙下斧质前谢罪，母子兄弟相泣，随从才获召入。和解以后，景帝仍与弟弟疏远，不再同车同辇。田叔随后受命为鲁相。 [[2]](#note-3)

<a id="另一边封王与官制仍在推进"></a>

<a id="event-6"></a>

3. **刘越被封为广川王，刘寄被封为胶东王。** 刘彭祖已迁赵、刘彻已入储位，两个旧封国再交给别的皇子。七月，郡守改称太守，郡尉改称都尉；官名的改换不等于全国郡县当场全部换掉官员。 [[3]](#note-6)

<a id="event-7"></a>

4. **九月，楚、赵四位死于劝谏的官员之子获封。** 他们的父亲在前154年反对本国王举兵而死，这次封赏表彰的是当年对汉廷的立场。二月匈奴入燕，和亲再遭破坏；同年还改磔为弃市，取消原来的处死方式而保留死刑。 [[4]](#note-7)

<a id="sj017-audience"></a>
<a id="五位诸侯王来朝"></a>

<a id="event-8"></a>

5. **城阳王刘喜、淄川王刘志、赵王刘彭祖、河间王刘德、梁王刘武本年来朝。** 他们都已经受封，不是本年又初立五王。刘武入京谢罪的详细叙事可以与朝见互读，但年表本身没有给所有人的来朝月份，也没有说五王共同参与审理梁国案件。 [[5]](#note-8)

<a id="hs-event-14"></a>

6. **诸侯礼仪与丧葬规制。** 朝廷规定诸侯王、列侯及王国太傅相关谥、诔、册由不同礼官奏报，派使者吊祭、视丧并立嗣；国中治坟役民限三百人。 [[6]](#hs-note-14)

<a id="hs-event-16"></a>

7. **以弃市代替磔刑。** 朝廷改用弃市，诏令不再施行磔刑。 [[7]](#hs-note-16)

<a id="2暗杀案卷和皇室说辞"></a>
#### 2｜暗杀、案卷和皇室说辞

通鉴中二年与[《梁孝王世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7058.md#ref-c0e885b1937fef)。求嗣与婚姻、改储有关的前事跨前150年前后，刺杀、追查和谢罪也不是同一天。案情、销毁文书、对太后的解释均按传世叙事呈现；不因最终免罪就断言刘武不知情，也不把诸人私下对白称作独立证实的现场记录。鄒阳向王信求情、茅兰劝梁王入京谢罪等环节见原篇，可沿所链全文阅读。

<a id="note-policy"></a>
<a id="3四侯礼制与死刑变更"></a>
#### 3｜四侯、礼制与死刑变更

四臣为楚相张尚、太傅赵夷吾，赵相建德、内史王悍，见三家注本卷及汉书九月条；本页不猜其子所有异名。汉书二月另记诸侯丧葬由朝廷遣官视事、规定动员人数上限等，官号含后称，不能据“大鸿胪”一词把武帝改官名提前到本年。其死罪改称弃市不是废除死刑。四月彗星、九月甲戌日食依原条保存，不作刑案的天意说明。

#### 4｜卷017封王、来朝与刘荣异年

[卷017前148年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0148)五个来朝格归本页，胶东寄、广川越同列四月乙巳元年；前149年“复置”是预设栏位，不重复授封。清河“初置、都清阳”接[前147年刘乘封王](bce-0147.md#note-offices)，不把他提前一年到国。

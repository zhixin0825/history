# 公元前150年｜刘荣失去太子位，王氏立后，刘彻成为继承人

[← 公元前151年](bce-0151.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前149年 →](bce-0149.md)

**汉景帝前七年**

## 太子被废，母亲也失去翻身的机会

**景帝废刘荣为临江王。** 窦婴极力争辩，没有成功，称病免去太子太傅的职务；栗姬在失意中去世。前几年已经确定的储位，并没有挡住皇帝、后宫与长公主关系变化带来的重新选择。[1](#note-deposition)

**梁王刘武也曾希望继承皇位。** 窦太后偏爱幼子，提出过让梁王承继的意思，袁盎等大臣却坚持父子传承。梁王没有接过兄长的帝位，这种失望还会牵出后来的暗杀案。[2](#note-heir)

## 二月，周亚夫从军队统帅进入相位

**陶青免相，周亚夫接任丞相，同时撤销太尉一职。** 七国战争中的主帅进入文官首位，并不意味着他的意见都会被采纳。他也曾反对废刘荣，景帝逐渐对他产生不满。[3](#note-court)

## 四月，王氏为后，刘彻立为太子

**乙巳，王夫人被立为皇后；丁巳，胶东王刘彻被立为皇太子。** 景帝先定中宫，再定继承人，原来的胶东王位也随之空出。朝廷赐民中承父后者爵一级，公开庆贺这一安排。[2](#note-heir)

## 管京城治安的，是不肯迁就权贵的郅都

**郅都由济南太守调为中尉，整治长安秩序。** 他敢于直接进谏，不收私下请托与馈赠，执法不避列侯宗室，权贵因而既怕他又怨他，称他为“苍鹰”。此后临江王刘荣入京受审，便会落在他的职掌之内。[3](#note-court)

**春季，朝廷又赦免一批营建阳陵的徒隶。** 皇位继承、官员更替与陵区工程并行，不能只看宫廷故事而漏去普通役作人员的处境。[3](#note-court)

<a id="sj017-successions"></a>
## 楚王刘道元年，中山、梁、长沙三王来朝

**刘道接续父亲刘礼，开始楚王纪年。** 此后的刘注、刘纯一系沿刘道传下，不能与七国之乱中刘戊的败亡混为同一支在本年复位。[4](#sj017-note)

**中山王刘胜、梁王刘武、长沙王刘发本年来朝。** 刘武的储位期待在前文作为跨期背景，不能单凭一格来朝就确定所有劝说、争执都发生在这次行程中。[4](#sj017-note)

## 本年相关史料

<a id="note-deposition"></a>
### 1｜废刘荣的月份有异说

[卷011 P008](../../sources/摘录/史记-卷011-孝景本纪.md#p008)、[《汉书》卷005](https://zh.wikisource.org/wiki/漢書/卷005)、[《通鉴》卷016](https://zh.wikisource.org/wiki/資治通鑑/卷016)。本纪作冬，通鉴明确冬十一月己酉，汉书作春正月，正文不强写一致的月日，年次均为前七年。窦婴争储、栗姬去世由通鉴连接，未给栗姬添加确切死日和现代病名。

<a id="note-heir"></a>
### 2｜刘彻不是本年才由“彘”改名

本纪、汉书在前四年封胶东时已经写“彻”，本年“名彻”只是辨认新太子，不足以制造改名事件。王氏立后与刘彻立太子的干支分别保存，不合成同日。梁王求嗣的过程见通鉴中二年回叙及[《梁孝王世家》](https://zh.wikisource.org/wiki/史記/卷058)，在本页仅作当时储位竞争的背景，刺杀结果另见前148年。

<a id="note-court"></a>
### 3｜任相、免徒和郅都

P008与通鉴本年。周亚夫、郅都的后续不是任职当年的必然结果；郅都在上林阻止皇帝亲自冒险救贾姬的旧事，确年未明，可沿[《酷吏列传》](https://zh.wikisource.org/wiki/史記/卷122)回看，不写成本年新发生。阳陵赦徒没有明确人数，不扩大为全体徭役废除。冬十一月日食的校改符号留来源页，不自行历算。

<a id="sj017-note"></a>
### 4｜卷017两种身份转换

[卷017前150年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0150)汉栏废太子、临江栏刘荣元年同属一件事，表日作十一月乙丑，与通鉴己酉、汉书正月不同；仍只叙一次废立。胶东刘彻四月丁巳为太子与上文相合，不因此另造正式称帝。楚道元年、中山梁长沙来朝均落实本页；楚道父子链参[楚元王世家](https://zh.wikisource.org/wiki/史記/卷050)，月日未载不补。

1. **景帝废刘荣为临江王，立王皇后与太子刘彻。** 刘荣被废为临江王，栗姬失去翻身的机会。大行奏事毕，以“子以母贵，母以子贵”为理由，请给太子生母栗姬皇后名号。景帝反问这是不是他所该说的话，查办并诛杀大行，随后废刘荣为临江王。窦婴极力争辩，没有成功，称病免去太子太傅职务；栗姬越发怨恨，又不得见皇帝，失意后忧死。前几年确定的储位，没有挡住皇帝、后宫与长公主关系变化带来的重新选择。周亚夫也坚决反对废栗太子，景帝没有听从。窦太后希望梁王刘武接续皇位，袁盎等反对。栗太子被废以后，太后偏爱幼子，想以梁王为继承人。袁盎等向景帝陈说继统礼义，阻止这项主张。劝说中又以殷道传弟、周道传子以及宋宣公让弟引发后乱为例。太后后来不再提立弟，梁王辞归，并把受阻归怨于袁盎等人。四月，乙巳，王夫人被立为皇后；丁巳，胶东王刘彻被立为皇太子。景帝先定中宫，再定继承人，原来的胶东王位也随之空出。朝廷赐民中承父后者爵一级，公开庆贺这一安排。卫绾被召回担任太子太傅。 [[1]](#note-1)

<a id="二月周亚夫从军队统帅进入相位"></a>

<a id="event-3"></a>

2. **二月，周亚夫从军队统帅进入相位。** 陶青免相，周亚夫接任丞相，同时撤销太尉一职。从前154年平定吴楚到本年，传记计为五岁。亚夫曾坚决反对废刘荣，景帝逐渐对他不满；此后梁孝王每次朝见，也常在太后面前说他的短处。 [[2]](#note-3)

<a id="管京城治安的是不肯迁就权贵的郅都"></a>

<a id="event-5"></a>

3. **管京城治安的，是不肯迁就权贵的郅都。** 郅都由济南太守调为中尉，整治长安秩序。 他敢于直接进谏，不收私下请托与馈赠，执法不避列侯宗室，权贵因而既怕他又怨他，称他为“苍鹰”。此后临江王刘荣入京受审，便会落在他的职掌之内。 [[3]](#note-5)

<a id="event-6"></a>

4. **春季，朝廷又赦免一批营建阳陵的徒隶。** 皇位继承、官员更替与陵区工程并行，不能只看宫廷故事而漏去普通役作人员的处境。 [[4]](#note-6)

<a id="sj017-successions"></a>
<a id="楚王刘道元年中山梁长沙三王来朝"></a>

<a id="event-7"></a>

5. **楚王刘道开始元年。** 刘道接续父亲刘礼，开始楚王纪年。 此后的刘注、刘纯一系沿刘道传下，不能与七国之乱中刘戊的败亡混为同一支在本年复位。 [[5]](#note-7)

<a id="event-8"></a>

6. **中山王刘胜、梁王刘武、长沙王刘发本年来朝。** 十月，朝廷使者持节，带着御用四马到关下迎接刘武。刘武留京侍奉母亲，入宫同辇，外出同车，到上林苑射猎，侍从也得以列籍出入宫门。 [[6]](#note-8)

<a id="sj058-cite-024"></a>

**[《史记·梁孝王世家》P026](../../sources/摘录/史记-卷058-梁孝王世家.md#p026)**

> 蓋聞梁王西入朝，謁竇太后，燕見，與景帝俱侍坐於太后前，語言私說。太后謂帝曰：「吾聞殷道親親，周道尊尊，其義一也。安車大駕，用梁孝王為寄。」景帝跪席舉身曰：「諾。」罷酒出，帝召袁盎諸大臣通經術者曰：「太后言如是，何謂也？」皆對曰：「太后意欲立梁王為帝太子。」帝問其狀，袁盎等曰：「殷道親親者，立弟。周道尊尊者，立子。殷道質，質者法天，親其所親，故立弟。周道文，文者法地，尊者敬也，敬其本始，故立長子。周道，太子死，立適孫。殷道。太子死，立其弟。」帝曰：「於公何如？」皆對曰：「方今漢家法周，周道不得立弟，當立子。故春秋所以非宋宣公。宋宣公死，不立子而與弟。弟受國死，復反之與兄之子。弟之子爭之，以為我當代父後，即刺殺兄子。以故國亂，禍不絕。故春秋曰『君子大居正，宋之禍宣公為之』。臣請見太后白之。」袁盎等入見太后：「太后言欲立梁王，梁王即終，欲誰立？」太后曰：「吾復立帝子。」袁盎等以宋宣公不立正，生禍，禍亂後五世不絕，小不忍害大義狀報太后。太后乃解說，即使梁王歸就國。

**本卷说明：** 褚补中的继统论及宋国例证；具体问答未经别证，不写成逐字实录。安车大驾有以车驾代太后、景帝及作为身后讳语等解释，本文保持中性托付，不确定为太后死后这一时点。该话中的梁孝王用谥，也见后人追述层次。宋国刺杀说是褚补转述的论辩，不据此改写既有前710年华督弑殇公、迎冯的编年。

> 纪年：七；大事纪：廢太子榮為臨江王。四月丁巳，膠東王立為太子。青罷相。；相位：六月乙巳，太尉條侯亞夫為丞相。罷太尉官。；将位：五。遷為丞相。；御史大夫位：御史大夫舍。

废刘荣、立刘彻接本页旧事。周亚夫为相、罢太尉，本表六月乙巳，旧正文沿《孝景本纪》《通鉴》二月，月份存在实质差异；只是一场交接，不把六月再写成第二次任相。御史大夫舍为桃侯刘舍，区别周亚夫相位；他不是本年就取代亚夫为丞相，实际相位另在[前147年](bce-0147.md)。

<a id="1废刘荣的月份有异说"></a>
#### 1｜废刘荣的月份有异说

[卷011 P008](../../sources/摘录/史记-卷011-孝景本纪.md#p008)、[《汉书》卷005](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7005.md#ref-f7c4e7734c251b)、[《通鉴》卷016](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7016.md#ref-44dfd0ffee23be)。本纪作冬，通鉴明确冬十一月己酉，汉书作春正月，正文不强写一致的月日，年次均为前七年。窦婴争储、栗姬去世由通鉴连接，未给栗姬添加确切死日和现代病名。

<a id="note-heir"></a>
<a id="2刘彻不是本年才由彘改名"></a>
#### 2｜刘彻不是本年才由“彘”改名

本纪、汉书在前四年封胶东时已经写“彻”，本年“名彻”只是辨认新太子，不足以制造改名事件。王氏立后与刘彻立太子的干支分别保存，不合成同日。梁王求嗣的过程见通鉴中二年回叙及[《梁孝王世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7058.md#ref-e299fc91372ce7)，在本页仅作当时储位竞争的背景，刺杀结果另见前148年。

<a id="note-court"></a>
<a id="3任相免徒和郅都"></a>
#### 3｜任相、免徒和郅都

P008与通鉴本年。周亚夫、郅都的后续不是任职当年的必然结果；郅都在上林阻止皇帝亲自冒险救贾姬的旧事，确年未明，可沿[《酷吏列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7122.md#ref-30952ac937e68b)回看，不写成本年新发生。阳陵赦徒没有明确人数，不扩大为全体徭役废除。冬十一月日食的校改符号留来源页，不自行历算。

<a id="sj017-note"></a>
<a id="4卷017两种身份转换"></a>
#### 4｜卷017两种身份转换

[卷017前150年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0150)汉栏废太子、临江栏刘荣元年同属一件事，表日作十一月乙丑，与通鉴己酉、汉书正月不同；仍只叙一次废立。胶东刘彻四月丁巳为太子与上文相合，不因此另造正式称帝。楚道元年、中山梁长沙来朝均落实本页；楚道父子链参[楚元王世家](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7050.md#ref-278742d6e6cedb)，月日未载不补。

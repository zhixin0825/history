# 公元前151年｜薄皇后被废，王氏与栗姬争夺储位的局势加剧

**汉景帝前六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="一批将吏因功获封"></a>

<a id="event-1"></a>

1. **一批将吏因功获封。** 卫绾为建陵侯，江都相程嘉为建平侯，陇西太守公孙昆邪为平曲侯，赵相苏嘉为江阳侯，故将军栾布为俞侯。 其中有人在七国战争中立功，正式授爵与当年的作战并不必是同一年。完整姓名据卷019侯表补足；江陵／江阳、鄃／俞及苏息、浑邪等异写见注。 [[1]](#note-1)

<a id="九月薄氏失去皇后位"></a>

<a id="event-2"></a>

2. **九月，薄氏失去皇后位。** 薄皇后原由薄太皇太后安排，刘启做太子时便已娶她。 她没有得到景帝的宠爱，也没有儿子；薄太皇太后去世以后，这位皇后的地位更加孤立。本年九月，景帝将她废黜。 [[2]](#note-2)

<a id="长公主的婚姻选择牵动两位皇子的前途"></a>

<a id="event-3"></a>

3. **在前153至前150年之间，长公主的婚姻选择牵动两位皇子的前途。** 刘嫖想把女儿嫁给太子刘荣，栗姬没有答应。栗姬来自齐地，怨恨公主经常向景帝介绍美人，那些女子所得宠爱超过自己，便连结亲也拒绝。公主转向王夫人，后者同意让儿子刘彻与公主之女结亲。公主因被拒而恼怒，不断向景帝说栗姬的坏话，指称她在与贵夫人、幸姬相会时，叫侍者在别人背后诅祝、唾骂，使用邪媚之术。景帝因此对栗姬渐生不满。 [[3]](#note-3)

<a id="event-4"></a>

4. **废储以前，景帝的不满又被宫廷中的人推动。** 景帝有一次身体不适、心情不好，把已封王的儿子们托给栗姬，希望自己死后她善待他们；栗姬却生气不答，言语不逊，景帝把怒意藏在心里。长公主不断称赞刘彻，景帝也认为他贤能，又想到日入怀的梦兆，但尚未决定。王夫人知道栗姬失意，趁怒气未消，暗使人催大臣请求立栗姬为后，使这一请求成为景帝眼中的越分干预。相关计谋未能逐项定年；[大行被诛与刘荣实际被废](bce-0150.md#note-1)接入下一年主条。 [[4]](#note-4)

<a id="楚王去世宫苑道路仍有改动"></a>

<a id="event-5"></a>

5. **楚王刘礼去世，儿子刘道承接王位。** 刘礼在前154年平乱后受楚王，前153开始元年，至本年为三年；汉传从受王当年算则记四年，指同一人的一次死亡。后九月，驰道旁树木被砍伐，兰池一带另有种植安排；具体规模与用途，短条没有展开。 [[5]](#note-5)

<a id="sj017-successions"></a>
<a id="济北燕开始新王纪年楚与长沙两王来朝"></a>

<a id="event-6"></a>

6. **刘胡承济北、刘定国承燕，分别开始元年。** 两人的父亲刘勃、刘嘉已在前152年去世；新王不是从前争位失败的同名旧王复出。 [[6]](#note-6)

<a id="event-7"></a>

7. **楚王刘礼、长沙王刘发本年有来朝记录。** 刘礼的赴朝与去世分开理解，不能从同一格“来朝、薨”断言他死在朝会现场。 [[7]](#note-7)

#### 卷019｜本年侯籍与异说

[完整原表](../../sources/摘录/史记-卷019-惠景间侯者年表.md) · [逐格去向](../../meta/记录/史记-卷019-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷019-纪年与异说.md)。原格的承侯元年不一律等于前任死年；未载月日不补，谥号是后称，国除也不一律等于处死。

<a id="sj019-r001-e03-n"></a>
**便｜[R001原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r001)：** 依本格明确的年号或元年定位；无确月的，不由同年其他事件借用日期。

<a id="sj019-r035-e03-n"></a>
**陽信｜[R035原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r035)：** 只记有罪，不补成谋反或死刑。

<a id="sj019-r070-e01-n"></a>
**俞｜[R070原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r070)：** 接[本页既有事项](#note-hou)。俞侯栾布与本页所称“故将军布”是同一位受封者，本表补四月丁卯及击齐、平七国的军功。他早为彭越舍人，彭越被杀时仍敢祭哭，险被烹而以忠言获免；后来又参加对英布作战。这些是受封以前的经历，不在景帝本年重新发生。

<a id="sj019-r071-e01-n"></a>
**建陵｜[R071原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r071)：** 接[本页既有事项](#note-hou)。卫绾封建陵接本页同批授爵，表补四月丁卯及以中尉身份、击吴楚之功。吕后时宦官张泽的建陵侯国早已结束，两支不得串成父子。

<a id="sj019-r072-e01-n"></a>
**建平｜[R072原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r072)：** 接[本页既有事项](#note-hou)。江都相程嘉获建平侯，接本页已称“江都丞相嘉”的受封；表补四月丁卯及将军击吴楚的军功，不是另一位同年封侯的嘉。

<a id="sj019-r073-e01-n"></a>
**平曲｜[R073原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r073)：** 接[本页既有事项](#note-hou)。陇西太守公孙昆邪获平曲侯，接本页的浑邪。初封为四月己巳，不能借同批其他人的丁卯日期。他是后来太仆公孙贺的父亲，但本表后称官衔不等于公孙贺本年已经任太仆。

<a id="sj019-r074-e01-n"></a>
**江陽｜[R074原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r074)：** 接[本页既有事项](#note-hou)。赵相苏嘉获江阳侯，接本页原来简称赵丞相嘉、称江陵的记录。表补四月壬申，汉表名苏息；姓名、国号差别不拆成几位分别受封的赵相。

<a id="卷018本年侯籍异年与取舍"></a>
#### 卷018｜本年侯籍、异年与取舍

**原格定位：** <a id="sj018-r022-jing"></a>[R022](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r022) · <a id="sj018-r029-jing"></a>[R029](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r029) · <a id="sj018-r045-jing"></a>[R045](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r045) · <a id="sj018-r064-jing"></a>[R064](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r064) · <a id="sj018-r068-jing"></a>[R068](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r068) · <a id="sj018-r093-jing"></a>[R093](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r093) · <a id="sj018-r129-jing"></a>[R129](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r129)。

[《史记》功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7018.md#ref-5d3a15b7b00410)与[《汉书》功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-c7b01e71296934)对读。普通承爵条按元年记载定位；无确月者不补日期，也不据子元年一律倒推父卒。后谥只用于辨认，不当作继位当时已经采用的称号。

[R022](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r022)：成侯赤于景帝栏计六年后有罪失国，汉表从惠元年起计四十四年，指向本阶段。具体处分年月未独立记下；前145年复封节氏有明年。

[R064](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r064)：承侯与父卒分开；本轮只记表中景六年奉元年，不在缺少另列卒日时以继承元年代替张苍死亡日。

<a id="note-hou"></a>
<a id="1卫绾而非赵绾封侯不重复"></a>
#### 1｜卫绾而非赵绾，封侯不重复

[卷011 P007](../../sources/摘录/史记-卷011-孝景本纪.md#p007)、[《万石张叔列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7103.md#ref-e421290904c368)与三家注。原文“中尉（赵）绾”有校记，互见可确认为卫绾。本纪这一短条未给两个嘉及布的全名，本轮由卷019及汉书功臣表补为程嘉、苏嘉／苏息、栾布，不再以失名处理；卫绾后来任丞相时再称建陵侯，是已有爵号，不另造一次初封。

<a id="note-queen"></a>
<a id="2立后求婚和废储不是同一日"></a>
#### 2｜立后、求婚和废储不是同一日

[《汉书》卷005六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7005.md#ref-2509197d0ab2b4)、[《通鉴》卷016](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7016.md#ref-d8ba24aa358a48)、[《外戚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7049.md#ref-6386fe97b6f5a8)。九月废薄有年条；求婚、母妃竞争等属于通鉴放在本阶段的前后背景，没有完整月日，不全部定为九月。王夫人早先婚姻、入太子宫及梦日的传说另见外戚篇，梦日不作为择储有天命的证据。也不添加本纪未载的“金屋藏娇”对白或刘彻改名故事。

<a id="note-other"></a>
<a id="3梁王不能在这里提前去世"></a>
#### 3｜梁王不能在这里提前去世

P007写“梁楚二王皆薨”，但本卷中六年及[《梁孝王世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7058.md#ref-aac4435e2d0734)明确刘武死于[前144年](bce-0144.md)。本页只写可核的刘礼，不让刘武在前151年死后又参与后续政事。冬十二月雷与久雨见汉书，后九月砍树、殖兰池按本纪保留；它们不被解释为后位变化的预兆。

<a id="sj017-note"></a>
<a id="4卷017王统来朝与临江预设"></a>
#### 4｜卷017王统、来朝与临江预设

[卷017前151年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0151)楚来朝并薨、长沙来朝，以及济北胡、燕定国元年，均落实本页。济北王史表谥武、汉表谥成，人物同为刘勃之子，不分作二王；燕父子链亦据[汉书诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7014.md#ref-b1ae514172c69b)互校。

本行“复置临江”接[前150年刘荣被废为临江王](bce-0150.md#note-deposition)，不把刘荣提前一年迁封。王国栏位的准备、实际授王命和下一年年数不强视为同一个瞬间。

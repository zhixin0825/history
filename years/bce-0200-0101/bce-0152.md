# 公元前152年｜营建阳陵邑，招民迁入，刘彭祖迁为赵王

[← 公元前153年](bce-0153.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前151年 →](bce-0151.md)

**汉景帝前五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="从陵区改名走到营建城邑与招民"></a>

<a id="event-1"></a>

1. **从陵区改名，走到营建城邑与招民。** 正月，开始营建阳陵邑；春季又有阳陵、渭桥工程。 这里不只是皇帝身后的墓地，也要有居民、官吏和交通设施。五月前后，朝廷招募百姓迁入，并许给二十万钱。迁民成为经营陵邑的一部分。 [[1]](#note-1)

<a id="赵王国恢复匈奴继续和亲"></a>

<a id="event-2"></a>

2. **刘彭祖从广川迁为赵王。** 七国战争中刘遂败亡，赵旧地一度按郡管理，现在交给景帝的儿子。刘彭祖不是原叛王的复位，而是另一个宗室支系接管。 [[2]](#note-2)

<a id="event-3"></a>

3. **汉又遣公主嫁匈奴单于。** 和亲继续使用，但使者、嫁女与边境和平的持续时间并不是一回事。本年济北王刘勃也去世，上一年的迁封并没有延续很久。 [[3]](#note-3)

<a id="event-4"></a>

4. **江都发生自西而来的暴风，城墙受损。** 战后王国的日常处境也包含这类灾害，不只有朝廷的封王名单。 [[4]](#note-4)

<a id="sj017-yan"></a>
<a id="燕王刘嘉去世齐与淮南两王入朝"></a>

<a id="event-5"></a>

5. **刘嘉去世，燕国由儿子刘定国承接，下一年列新王元年。** 刘嘉是刘泽之子，继承以后在位二十六年。表与本纪的死年差别见注，本页不与前154年另记两次死亡。 [[5]](#note-5)

<a id="sj017-audience"></a>

<a id="event-6"></a>

6. **齐王刘寿、淮南王刘安本年来朝。** 刘寿是在七国战争后承接齐国的新王，刘安则已在文帝时受封淮南；两人的王年不同，不用同一数字强齐。 [[6]](#note-6)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-7"></a>

7. **陈始因罪失爵，博阳一支的侯国中断。** 汉表补说与谋杀人有关，后来虽遇赦，仍未保住侯位。 [[7]](#note-7)

<a id="event-8"></a>

8. **须昌侯不害因罪失国。** 他与同年开始承爵的清阳侯不害，以及在位的武原侯不害，各属不同家系。 [[8]](#note-8)

<a id="sj018-succession"></a>

<a id="event-9"></a>

9. **侯爵继续在各家传承。** 以下记录本年开始的侯年；继承家爵不等于同时承接父辈的中央官职。 曲逆陈何的父亲陈悝，在本传名陈恢；这里不另造两个简侯。 [[9]](#note-9)

   | 侯籍一支 | 本年变化 |
   |---|---|
   | 清陽 | 不害接清阳侯，续伉一代。 |
   | 曲逆 | 陈何接曲逆侯，续陈悝一代。 |
   | 新陽 | 善接新阳侯，续它一代。 |
   | 故市 | 谷接故市侯，续续一代。 |
   | 汾陽 | 胡接汾阳侯，续解一代。 |
   | 穀陵 | 解接谷陵侯，续卬一代；汉表名解中。 |

   [本段原文、异年及说明](#sj018-note)。

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-10"></a>

10. **前丞相、北平侯张苍在本年去世。** 他已退居相位十年，死后家爵继续传给后人，中央丞相职位则早已由申屠嘉、陶青先后接任。 [原格与说明](#sj022-note)。 [[10]](#note-10)

<a id="sj118-event-11"></a>

11. **济北王刘勃去世，谥为贞王。** 原衡山王刘勃在七国之乱后迁封济北。卷017本年济北栏记薨，本传载朝廷赐谥贞；刘胡下一年起记新王元年。 [[11]](#note-11)

<a id="hs-event-12"></a>

12. **清河定侯王吸｜承爵。** 表载清河定侯王吸一支本年记载侯位承袭。表中所载事项为哀侯不害承爵。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **曲逆献侯陈平｜承爵。** 表载曲逆献侯陈平一支本年记载侯位承袭。表中所载事项为侯何承爵。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **阳信胡侯吕青｜承爵。** 表载阳信胡侯吕青一支本年记载侯位承袭。表中所载事项为共侯善承爵。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **须昌贞侯赵衍｜免爵或免官。** 表载须昌贞侯赵衍一支本年载免除或失爵。表中所载事项为获罪，失爵。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **汾阳严侯靳强｜承爵。** 表载汾阳严侯靳强一支本年记载侯位承袭。表中所载事项为康侯胡承爵，十二年爵祀中止，不得状。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[17]](#hs-note-17)

#### 2｜王位与一个有异年的侯封

刘彭祖迁赵两书互见，刘勃之死及和亲由通鉴、汉书补充。本纪又称本年封长公主子蟜为隆虑侯，三家注在中五年据《惠景间侯者年表》列陈蟜为隆虑侯。采用较具体的初封表归[前145年](bce-0145.md)，本年只留异说，不为同人两次初封。见[本卷考证](../../meta/考证/史记-卷011-纪年与异说.md#异年)。

<a id="3卷017王薨改属与来朝"></a>
#### 3｜卷017王薨、改属与来朝

[卷017前152年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0152)济北勃、燕嘉皆薨，齐淮南来朝；赵彭祖与广川两栏互见同一次迁封，原广川改为信都郡。不能因为转到赵栏仍记四年，就说赵王国在四年前已经由他统治。

燕嘉死年《孝景本纪》提前接在前154年，史记本表、[汉书诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7014.md#ref-27e86ebe87ec45)则将其二十六年终局放本年、刘定国次年元年。采用连续王统可核合的后者，前154年旧注改留异说，不让刘嘉死后又两年在位。济北新王刘胡、燕定国均在[前151年](bce-0151.md#sj017-successions)承接。

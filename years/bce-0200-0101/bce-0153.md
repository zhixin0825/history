# 公元前153年｜刘荣立为太子，刘彻封胶东，关津重新查验

[← 公元前154年](bce-0154.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前152年 →](bce-0152.md)

**汉景帝前四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="春天出入关津重新需要凭证"></a>

<a id="event-1"></a>

1. **春天，出入关津重新需要凭证。** 朝廷恢复关津查验，来往须用传。 文帝曾以通关梁方便交通，七国战争以后，中央重新加强通行管理。这不是每条道路从此封闭，而是出入要经过查验。 [[1]](#note-1)

<a id="四月皇帝选择长子为继承人"></a>

<a id="event-2"></a>

2. **四月，皇帝选择长子为继承人。** 四月己巳，刘荣被立为皇太子，刘彻同时被封为胶东王。 刘荣的母亲是栗姬，因此后来常被称为栗太子。刘彻此时只是另一个受封的皇子，不能因为后来成为武帝，就把本年立储写成他的登场胜利。 [[2]](#note-2)

<a id="event-3"></a>

3. **六月大赦，七月临江王刘阏去世。** 临江王位由此空出，几年后被废的刘荣迁到这里；这两个临江王不是一个人在两年各死一次。 [[3]](#note-3)

<a id="战后继续调封陵邑也有了名称"></a>

<a id="event-4"></a>

4. **衡山王刘勃在七国战争中守住本国，被迁为济北王；庐江王刘赐则迁为衡山王。** 淮南王一度想响应吴，但其相得到兵权以后反而守城支持汉，使该国免于投入战争。王的意图与国中官员、军队的行动，并不总一致。 [[4]](#note-4)

<a id="event-5"></a>

5. **易阳改称阳陵，赵国的旧地另按邯郸郡管理。** 新设郡县、迁王及后来重封赵王，会接连改变河北的管辖关系。阳陵的改名则先于下一年的建邑募民，不能当作景帝已经入葬。 [[5]](#note-5)

<a id="sj017-successions"></a>
<a id="楚齐的新王开始纪年鲁王入朝"></a>

<a id="event-6"></a>

6. **刘礼在楚、刘寿在齐分别开始记元年。** 刘礼是楚元王刘交之子，原有平陆侯爵；刘寿接续父亲刘将闾。两人在上年战争后的承继，延续为本年的王统，不是已死的刘戊、刘将闾复位。 [[6]](#note-6)

<a id="event-7"></a>

7. **鲁王刘余本年来朝。** 他已由淮阳迁鲁；江都栏同时列刘非的新年数，承接旧汝南王的迁封，姓名没有改变。 [[7]](#note-7)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-8"></a>

8. **绛阳侯禄因擅自出界获罪，侯国撤销。** 汉表还记其被判司寇刑；爵位的丧失与刑罚是两个层次。 [[8]](#note-8)

<a id="event-9"></a>

9. **甯侯指也因出国界获罪失爵。** 原文没有给出他为何越界及具体路线，不能补成一场逃亡或叛乱。 [[9]](#note-9)

<a id="sj022-note"></a>
<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[本年原表R054](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r054) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0153)。

> 纪年：四；大事纪：立太子。；相位：三；将位：二。太尉亞夫。；御史大夫位：御史大夫蚡。

立太子接本页刘荣、刘彻的既有安排。御史大夫史表“蚡”、汉表“介”；田蚡在景帝时官历与此不合，汪越已指出疑为形讹，正文暂用“介”而不补未详姓氏，不把武帝初年的田蚡提前为本年御史。陶青“三”、周亚夫太尉“二”各自计任期。 参见[汪越《读史记十表》卷十](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%AE%80%E5%8F%B2%E8%A8%98%E5%8D%81%E8%A1%A8-%E5%8D%B7%E5%8D%81.md#ref-6194f77b536051)的逐项校读；所用古代考证与现今已经解决全部异说不是一回事。

[卷011 P005](../../sources/摘录/史记-卷011-孝景本纪.md#p005)、[《汉书》卷005](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7005.md#ref-8b5649a5df673c)、[《通鉴》卷016](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7016.md#ref-5551e1cfc7865a)。关津用传据汉书、通鉴春季，易阳改名据本纪后九月；“后九月”保留古历写法，不等于现代公历第二个九月。赵改郡沿本纪本年冬的归档，战争接收与法定建置不硬定同一日。其他书末附十月日食的年条位置暂留原出处，不自行推算现代日期。

<a id="note-heir"></a>
<a id="2两个皇子两任临江王"></a>
#### 2｜两个皇子、两任临江王

本纪夏“立太子”未写名字，汉书四月给出刘荣。刘彻为胶东王与后来前150年立为太子是不同阶段；前155年受封、此时去世的是刘阏，前148年自杀的是刘荣。

<a id="note-domains"></a>
<a id="3淮南诸王的战争前情"></a>
#### 3｜淮南诸王的战争前情

通鉴本年末回叙前154年淮南、庐江、衡山的选择，再述战后迁王。前情不算本年新起一次叛乱。刘勃、刘赐的亲缘和原封可回看[前164年分淮南](bce-0164.md)，新旧王号不能当作互不相干的四个人。

<a id="sj017-note"></a>
<a id="4卷017各国互见与授命元年的区别"></a>
#### 4｜卷017各国互见与授命、元年的区别

[卷017前153年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0153)楚礼、齐寿元年与[楚元王世家](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7050.md#ref-75064a4a27b686)、[齐悼惠王世家](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7052.md#ref-c49df1fa4e63cf)相接；鲁来朝归本页。衡山勃转济北、赐庐江转衡山、庐江改郡、临江阏于无后为郡，都按对应动作归本页，改国与废国分别处理。

汉栏刘荣立太子、胶东刘彻受封同系四月己巳；汉书王表胶东初封日作乙巳，正文保留本纪主线的己巳而明示差别，不强算为唯一现代日期。江都栏在本年又记六月乙亥刘非由汝南迁来，通鉴与旧年页将其放前154年战后；沿[前154年](bce-0154.md#note-settlement)只叙一次，本格作异年及计年互见。刘勃济北沿此前王年十二，刘赐衡山又记元年，是不同计数口径，不自动推出两人受封相差十一年。

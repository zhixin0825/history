# 公元前154年｜七国起兵，晁错被杀，汉以断粮和分路进攻平乱

[← 公元前155年](bce-0155.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前153年 →](bce-0153.md)

**汉景帝前三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj058-succession-promise-event"></a>

1. **七国起兵以前，景帝在宴饮中许诺将来传位梁王，窦婴提出反对。** 景帝尚未立太子，同弟弟饮酒时说，百年以后把帝位传给他。梁王口头辞谢，知道未必是确定的安排，心中仍喜，窦太后也高兴。宫中又传窦婴当面援引传子及嫡孙的继统原则反对，景帝沉默，太后不悦。 [[1]](#sj058-succession-promise-note)

<a id="削地的诏令碰上早已积累的怨恨"></a>

<a id="event-1"></a>

2. **削地的诏令，碰上早已积累的怨恨。** 晁错主张削减诸侯王的封地，认为吴王无论削与不削，最终都可能反叛，越早处理反而损害越小。楚王刘戊在薄太后丧服期间私通，遭削东海郡；赵王刘遂因过失被削常山郡，胶西也被追究、削地。吴王刘濞听说削会稽、豫章的议案已经确定，便与其他国相约起兵。薄太后前一年去世，服丧获罪的冬季接本古历年岁首。 刘濞先派应高口头游说胶西王刘卬，再亲赴胶西面约。 胶西群臣曾以事成后两个君主仍会争天下相谏，刘卬未从。 [[2]](#note-1)

<a id="event-2"></a>

3. **刘濞积聚力量并非始于本年。** 吴有铜盐之利，收纳亡命者，减轻国内负担以收人心；他的太子早年与当时还是皇太子的刘启博戏争执，被刘启击杀，吴王此后长期不朝。这些是起兵前的长期背景，不全部塞成本年正月新事。 [[3]](#note-2)

<a id="正月吴楚等七国相继举兵"></a>

<a id="event-3"></a>

4. **正月，吴楚等七国相继举兵。** 起兵者为吴、楚、赵、胶西、胶东、菑川、济南七国。楚相张尚、太傅赵夷吾劝刘戊不要起兵，刘戊不听，将两人杀死；吴楚联军越过淮水，向西攻梁，攻破棘壁。赵相建德、内史王悍也进谏，刘遂竟将两人烧杀，发兵屯本国西界，等待吴军一同西进，又向北联络匈奴。胶西、胶东、菑川围齐，济南响应。七国各有所在，并不是七位国王始终带着同一支军队行动。 吴军初议和周丘在下邳的行动见[本年吴军支线](#sj106-p012)。 刘濞从广陵出兵，遣使往闽越、东越。本篇记东越发兵相从。 刘濞致书诸王，称要诛晁错、保高庙，并开列军功和降军的赏格。 吴使同时向淮南、庐江、衡山寻求响应。淮南相掌兵后守城援汉，朝廷另派曲城侯救淮南；庐江王未应吴，衡山王坚守。 从军的列侯有人在长安借钱。其他放贷者担心东方封邑难保，无盐氏独出钱贷款，战后因利息积富。 [[4]](#note-3)

   | 战线 | 主要行动 |
   |---|---|
   | 吴楚—梁 | 吴楚攻梁，想由此向西逼近朝廷；梁国守城承受正面压力 |
   | 齐地 | 刘将闾一度与诸国相约，后来背约守齐；三国围临淄，济北未能发兵 |
   | 赵地 | 刘遂起兵，盼匈奴相助；汉另派郦寄攻赵，后来由栾布增援 |
   | 汉廷后方 | 窦婴屯荥阳，周亚夫出武关向洛阳，保护道路与关津 |

   济北王刘志也曾有响应之意，却被郎中令控制，不能出兵。因此最终称七国，不把有意响应而未能实际举兵者直接凑成第八国。

<a id="景帝牺牲晁错叛军却没有因此停止"></a>

<a id="event-4"></a>

5. **晁错与袁盎向来不和，袁盎入见，建议杀晁错、恢复被削土地，以息吴兵。** 皇帝采纳。丞相陶青、中尉陈嘉、廷尉张欧上奏指控晁错离间父子兄弟、主张自己守京而使皇帝亲征等，景帝批准，晁错被处死。 [[5]](#note-4)

<a id="event-5"></a>

6. **袁盎出使吴军，吴王却已不再接受简单撤兵。** 他拘住袁盎，准备迫其转变立场；袁盎最后在旧日受其恩惠者帮助下逃回。邓公从前线回来，指出诸王谋反已久，杀晁错不能使他们退兵，反而使忠言之士自危，景帝为此懊悔。 宗正德侯刘通先以宗亲身份入营宣诏。刘濞自称东帝，拒绝拜诏。 [[6]](#note-5)

<a id="周亚夫不急着救梁而先切断吴楚的粮道"></a>

<a id="event-6"></a>

7. **周亚夫让梁军牵制吴楚，汉军主力先切断敌军粮道。** 七国起兵后，景帝以中尉周亚夫为太尉。周勃传记亚夫自请让梁承受吴楚攻势、由汉军断其粮道；吴王濞传则说，他在淮阳问父亲的故客邓都尉，得到固守昌邑、委梁断粮的计策。梁王一再求救，景帝也下诏催救，亚夫仍按战场形势坚守，遣弓高侯等率轻骑截断淮、泗之间的后方粮道。梁国的韩安国、张羽等奋力守城，使吴楚短期内不能突破。 梁孝王守在睢阳；吴楚先攻棘壁时，传记称有数万人被杀。韩安国、张羽所部使敌军无法径自西进。战后梁军的斩获，被本传概括为与汉廷军队大体各半。 卫绾率河间兵参战，直不疑也以二千石身份将兵。 周亚夫途经洛阳，见当地游侠剧孟未加入诸王一方，才稍稍放心。 窦婴统兵屯荥阳，督察齐、赵战线，又荐袁盎、栾布，把所得赏金供军吏取用。 骁骑都尉李广在昌邑下夺旗立功，因接受梁王将军印，归来未得朝廷奖赏。 [[7]](#note-6)

<a id="event-7"></a>

8. **吴楚缺粮后转攻汉营，周亚夫仍坚守。** 汉营有一夜惊乱，士卒相互攻击，扰至太尉帐下，亚夫仍卧而不起，军中后来才安定。吴军饥饿，反复挑战，他始终不出。敌军佯攻东南，他判断真正攻击在西北，预先防备；吴楚攻不进去，又无粮补充，士卒渐散。等到敌军退走，亚夫才派精兵追击，联军崩溃。 [[8]](#note-7)

<a id="event-8"></a>

9. **刘濞败逃后被杀，楚王刘戊自杀，楚军投降。** 刘濞的最后去向，各篇分别记为丹徒、东越或东瓯。周勃传记他率数千人逃保丹徒，汉军尽收降兵，并悬千金购其首；一个多月后，越人斩首来报。汉军三月已取得主要胜利，赵地仍在抵抗。诸将这时才认可太尉的谋划，梁王却因先前未获救援而与亚夫有隙。亚夫归来后，朝廷恢复太尉官。 二月景帝的[讨吴诏](#sj106-p015)另见同年。 [[9]](#note-8)

<a id="齐赵的结局是另外两条战线"></a>

<a id="event-9"></a>

10. **齐国守城经历动摇，路中大夫传回援军消息后被杀，解围后齐王仍自杀。** 吴楚以诛晁错、安宗庙号召，齐地四国响应并想拉齐王入伙；齐孝王刘将闾迟疑守城，遭三国合围。围急时齐曾暗中通谋，约未定，派去告急的路中大夫回来了。他奉天子命令齐坚守，却被城外围兵挡住；三国将领强迫他盟誓，要求说汉军已败，齐应速降，否则被屠。他假意答应，到城下见齐王却高呼：汉发百万兵，太尉周亚夫已破吴楚，正来救齐，一定坚守！将领遂杀他。百万是传信中的说法，不是核定实到兵数。齐王和大臣听到汉讯，决意不降。围军攻临淄三个月未能攻下。栾布、平阳侯曹奇等赶到，击破围军、解齐围，胶西、胶东、菑川王各自带兵归国；栾布等后来听说齐曾同叛国谋划，又准备转攻齐，刘将闾恐惧饮药自杀。胶西刘卬退国后向弓高侯请罪，仍不能免；胶东刘雄渠、菑川刘贤、济南刘辟光也被诛，诸国地归汉。 胶西王以诛错辩解，弓高侯韩颓当以未奉诏、无虎符而擅发兵诘问，宣读诏书后，刘卬自杀。 [[10]](#note-9)

<a id="event-10"></a>

11. **栾布平定齐地后转兵攻赵，引水灌邯郸。** 汉廷先派曲周侯郦寄攻赵，刘遂退守邯郸，史传记相持七个月。吴楚败于梁，不能西来，匈奴听到败讯也不肯入边。栾布会合攻赵军，引水灌城；城破后刘遂自杀，邯郸投降，赵幽王一支的王统断绝。吴楚迅速失败与赵城坚持较久，是同一场战争中的不同节奏；“七月”是围城时长，未给破城确日。 [[11]](#note-10)

<a id="平乱以后不是把所有王国一律取消"></a>

<a id="event-11"></a>

12. **平乱以后，齐楚续封，刘志迁王菑川，吴国则没有续立。** 景帝想让德侯之子续吴、楚元王之子刘礼续楚。窦太后责吴王年长却带头作乱，不许续吴，准许续楚。当时刘礼任宗正，已有平陆侯爵，被立为楚王，奉楚元王宗庙，后来谥文王。景帝认为齐王起初守汉，是受逼迫才与叛国有谋，便让刘寿接续齐国。刘志从济北迁王菑川；齐篇称他坚守、未与诸侯合谋，汉传却记他起初曾通谋、后来没有发兵，因此免诛。刘寿下一年开始记元年，刘志则继续原王年，不因迁国重新计算。皇子刘端受封胶西、刘胜受封中山，刘余由淮阳迁鲁，刘非由汝南迁江都，承接原吴地。刘非时年十五，勇健有力，曾请战并获将军印出击吴军，因战功又获赐天子旌旗。旧反王的宗支、没有实际出兵的王及景帝诸子，得到不同处置。 [[12]](#note-11)

<a id="event-12"></a>

13. **王国的实际权力也开始收缩。** 朝廷加强对任官和政务的控制，后续几年继续裁减官署、改变相位名号。郡制与王国仍并存，七国之乱的结果不是立刻改成一个从此再无诸侯的国家。 [[13]](#note-12)

24. **六月乙巳，窦婴以平定吴楚的军功封魏其侯。** 他是窦氏外戚，喜好任侠，七国起兵时以大将军屯荥阳，抵御吴楚七国；战后因军功封侯。此前受封的章武侯窦广国、南皮侯窦彭祖，加上窦婴，构成窦氏三支列侯。 [[24]](#sj049-douying-marquis-note)

25. **平阳侯曹奇去世。** 曹奇为侯七年而卒，谥简侯，儿子曹时承接；曹时元年列在下一年。曹奇本年参加解齐围，不足据此认定他的死亡是阵亡。 [[25]](#sj054-note-24)

<a id="sj106-event-26"></a>

26. **吴军出兵之初，两项建议未获采纳。** 田禄伯请求分兵，吴太子担心独掌一路兵马可能引起新的变乱，刘濞没有答应。少将桓将军又主张先争洛阳和敖仓，吴国老将认为这一谋议不足以应付全局，刘濞也没有采用。 [[26]](#note-26)

<a id="sj106-event-27"></a>

27. **周丘夺取下邳，吴王败后退兵。** 下邳人周丘逃亡至吴，素被刘濞轻视。吴王发兵时，他借得符节，返回下邳杀县令，招集地方豪吏和兵众，继而北略。听说吴王败走，他引军返回下邳，途中发背疽而死。 [[27]](#note-27)

<a id="sj106-event-28"></a>

28. **二月，景帝下诏处置叛军。** 吴军败走后，景帝以诏书历数吴王和同盟诸王的罪状，宣布自己素服避正殿，要求将军勉励部下，并定俘斩赏罚及违诏处置。 [[28]](#note-28)

<a id="sj107-event-29"></a>

29. **灌孟战死，灌夫冲入吴军。** 太尉周亚夫所部将领灌何征召灌孟，灌夫率千人随父从军。灌孟战死后，灌夫放弃随丧归去的机会，带少数敢从者突入吴军，负重伤而回。太尉制止他再次出击。这是同一场七国战争中灌夫得名的经过。 [[29]](#note-29)

#### 卷050篇末附读：贤者、命令与所任之人

<a id="sj050-cite-024"></a>

**[卷050 P010完整原字与白话](../../sources/摘录/史记-卷050-楚元王世家.md#p010)**

> 太史公曰：國之將興，必有禎祥，君子用而小人退。國之將亡，賢人隱，亂臣貴。使楚王戊毋刑申公，遵其言，趙任防與先生，豈有篡殺之謀，為天下僇哉？賢人乎，賢人乎！非質有其內，惡能用之哉？甚矣，「安危在出令，存亡在所任」，誠哉是言也！

**白话：** 太史公说：一个国家将要兴盛，必会出现吉祥的征兆，君子得到任用，小人退下；一个国家将要灭亡，贤能的人退隐，作乱的臣子却尊贵起来。假使楚王刘戊没有处罚申公，而是听从他的话；假使赵王任用防与先生，又怎么会有篡乱杀戮的图谋，使自己被天下人诛戮、羞辱呢？贤人啊，贤人！一个人的内心如果本来没有敬重贤能的根底，又怎么能真正任用贤人？“安定或危险，取决于发出怎样的命令；存续或灭亡，取决于任用怎样的人。”这话真是深切而可信！这里保存的是史家的兴亡判断，“祯祥”不是本项目证实的超自然预兆。申公名培，所受是胥靡劳役刑，并没有在这次处罚中被杀。防与先生的具体遭遇，本篇及《汉书》都没有展开，古注也承认缺少事迹，因此不能替他编出一次有年月、有对白的拒谏。

**本卷辨析：** 篇末史论作为楚赵败亡的附读，不作为本年新发生的政令。申公受刑是劳役，不等于被处死；防与先生在本篇与汉传都无详细拒谏经过，索隐也承认未见，故不补年、地点与对白。

> 漢已平吳楚，孝景帝欲以德侯子續吳，以元王子禮續楚。竇太后曰：「吳王，老人也，宜為宗室順善。今乃首率七國，紛亂天下，柰何續其後！」不許吳，許立楚後。是時禮為漢宗正。乃拜禮為楚王，奉元王宗廟，是為楚文王。

**白话：** 汉廷平定吴楚以后，景帝想让德侯的儿子延续吴国王统，让楚元王的儿子刘礼延续楚国。窦太后说：“吴王已经是老人，本来应该成为宗室中顺从朝廷、行为良善的榜样；如今却带头率领七国，使天下纷乱，怎么还可以延续他的王统！”她不准续立吴王，却同意给楚国立后。那时刘礼在汉朝做宗正，主管宗室事务。朝廷于是拜他为楚王，让他奉祀楚元王的宗庙，后来称楚文王。德侯刘广是吴王刘濞的弟弟，所以拟议的是让吴王侄辈承统，并非复立刘濞本人；本篇没有写出拟立者的名字。刘礼则是刘交之子、刘戊的叔父辈，已有平陆侯爵，与被杀的楚王刘戊不是父子。

> 【索隱述贊】漢封同姓，楚有令名。既滅韓信，王於彭城。穆生置醴，韋孟作程。王戊棄德，與吳連兵。太后命禮，為楚罪輕。文襄繼立，世挺才英。如何趙遂，代殞厥聲！興亡之兆，所任宜明。

**白话：** 唐代司马贞的述赞说：汉朝分封同姓宗室，楚国原有美好的名声。韩信的楚王国被撤去以后，刘交受封，以彭城为都；“灭韩信”在这里压缩的是罢其楚王国，不能读成韩信已经在此时被杀。楚元王为不爱饮酒的穆生另备甜醴，韦孟作诗规劝楚王、示以准则，都是尊重师傅和儒者的往事。楚王刘戊却抛弃德行，与吴国连兵作乱。太后同意让刘礼承楚，述赞把这解释为楚国的罪责较吴为轻。文王、襄王等相继为王，后代也不断有才俊挺出。为何到了赵王刘遂，却使一支宗族的声名败落！兴亡的征兆，应当从任用什么人看清。穆生去楚、韦孟谏诗均没有在本篇注明确年；这里说明唐赞用典，不能把他们一概安排在前154年才受礼、作诗或离楚。

### 27. 周丘夺取下邳，吴王败后退兵

[返回正文第27条](#sj106-event-27)

<a id="hs035-l7038-e27"></a>

**[《汉书·荆燕吴传》P025](../../sources/摘录/汉书-卷035-荆燕吴传.md#p025)** · [仓内TXT L7038](../../sources/本地分卷/汉书/汉书-卷035.md#L7038)

> 王專并將其兵，未度淮，諸賓客皆得為將、校尉、行間候、司馬，獨周丘不用。周丘者，下邳人，亡命吳，酤酒無行，王薄之，不任。周丘乃上謁，說王曰：「臣以無能，不得待罪行間。臣非敢求有所將也，願請王一漢節，必有以報。」王乃予之。周丘得節，夜馳入下邳。下邳時聞吳反，皆城守。至傳舍，召令入戶，使從者以罪斬令。遂召昆弟所善豪吏告曰：「吳反兵且至，屠下邳不過食頃。今先下，家室必完，能者封侯至矣。」出乃相告，下邳皆下。周丘一夜得三萬人，使人報吳王，遂將其兵北略城邑。比至城陽，兵十餘萬，破城陽中尉軍。聞吳王敗走，自度無與共成功，即引兵歸下邳。未至，癰發背死。

### 28. 二月，景帝下诏处置叛军

[返回正文第28条](#sj106-event-28)

<a id="hs035-l7039-e28"></a>

**[《汉书·荆燕吴传》P026](../../sources/摘录/汉书-卷035-荆燕吴传.md#p026)** · [仓内TXT L7039](../../sources/本地分卷/汉书/汉书-卷035.md#L7039)

> 二月，吳王兵既破，敗走，於是天子制詔將軍：「蓋聞為善者天報以福，為非者天報以殃。高皇帝親垂功德，建立諸侯，幽王、悼惠王絕無後，孝文皇帝哀憐加惠，王幽王子遂，悼惠王子卬等，令奉其先王宗廟，為漢藩國，德配天地，明並日月。而吳王濞背德反義，誘受天下亡命罪人，亂天下幣，稱疾不朝二十餘年。有司數請濞罪，孝文皇帝寬之，欲其改行為善。今乃與楚王戊、趙王遂、膠西王卬、濟南王辟光、菑川王賢、膠東王雄渠約從謀反，為逆無道，起兵以危宗廟，賊殺大臣及漢使者，迫劫萬民，伐殺無罪，燒殘民家，掘其丘壟，甚為虐暴。而卬等又重逆無道，燒宗廟，鹵御物，朕甚痛之。朕素服避正殿，將軍其勸士大夫擊反虜。擊反虜者，深入多殺為功，斬首捕虜比三百石以上皆殺，無有所置。敢有議詔及不如詔者，皆要斬。」

> 二月中，吳王兵旣破，敗走，於是天子制詔將軍曰：「蓋聞爲善者，天報之以福；爲非者，天報之以殃。高皇帝親表功德，建立諸侯，幽王、悼惠王絕無後，孝文皇帝哀憐加惠，王幽王子遂、悼惠王子卬等，令奉其先王宗廟，爲漢藩國，德配天地，明並日月。吳王濞倍德反義，誘受天下亡命辠人，亂天下幣，稱病不朝二十餘年，有司數請濞罪，孝文皇帝寬之，欲其改行爲善。今乃與楚王戊、趙王遂、膠西王卬、濟南王辟光、菑川王賢、膠東王雄渠約從反，爲逆無道，起兵以危宗廟，賊殺大臣及漢使者，迫劫萬民，夭殺無罪，燒殘民家，掘其丘冢，甚爲暴虐。今卬等又重逆無道，燒宗廟，鹵御物，朕甚痛之。朕素服避正殿，將軍其勸士大夫擊反虜。擊反虜者，深入多殺爲功，斬首捕虜比三百石以上者皆殺之，無有所置。敢有議詔及不如詔者，皆要斬。」

### 29. 灌孟战死，灌夫冲入吴军

[返回正文第29条](#sj107-event-29)

<a id="hs052-l7792-e29"></a>

**[《汉书·窦田灌韩传》P015](../../sources/摘录/汉书-卷052-窦田灌韩传.md#p015)** · [仓内TXT L7792](../../sources/本地分卷/汉书/汉书-卷052.md#L7792)

> 吳楚反時，潁陰侯灌嬰為將軍，屬太尉，請孟為校尉。夫以千人與父俱。孟年老，潁陰侯彊請之，鬱鬱不得意，故戰常陷堅，遂死吳軍中。漢法，父子俱，有死事，得與喪歸。夫不肯隨喪歸，奮曰：「願取吳王若將軍頭以報父仇。」於是夫被甲持戟，募軍中壯士所善願從數十人。及出壁門，莫敢前。獨兩人及從奴十餘騎馳入吳軍，至戲下，所殺傷數十人。不得前，復還走漢壁，亡其奴，獨與一騎歸。夫身中大創十餘，適有萬金良藥，故得無死。創少瘳，又復請將軍曰：「吾益知吳壁曲折，請復往。」將軍壯而義之，恐亡夫，乃言太尉，太尉召固止之。吳軍敗，夫以此名聞天下。

**互校说明** 本传写功臣灌婴任将，既有年页据《史记》名灌何。灌婴早卒；字样留异。

**[《史记·魏其武安侯列传》P011](../../sources/摘录/史记-卷107-魏其武安侯列传.md#p011)** · [三家注](../../sources/史记三家注/卷107.md#p11)

> 吳楚反時，潁陰侯灌何爲將軍，屬太尉，請灌孟爲校尉。夫以千人與父俱。灌孟年老，潁陰侯彊請之，鬱鬱不得意，故戰常陷堅，遂死吳軍中。軍法，父子俱從軍，有死事，得與喪歸。灌夫不肯隨喪歸，奮曰：「願取吳王若將軍頭，以報父之仇。」於是灌夫被甲持戟，募軍中壯士所善願從者數十人。及出壁門，莫敢前。獨二人及從奴十數騎馳入吳軍，至吳將麾下，所殺傷數十人。不得前，復馳還，走入漢壁，皆亡其奴，獨與一騎歸。夫身中大創十餘，適有萬金良藥，故得無死。夫創少瘳，又復請將軍曰：「吾益知吳壁中曲折，請復徃。」將軍壯義之，恐亡夫，乃言太尉，太尉乃固止之。吳已破，灌夫以此名聞天下。

**本卷归年说明：** 同一场七国之乱的一支军中个案；本传灌何，汉传作灌婴，《索隐》以世代辨其误，卷095及侯表可互见。

#### 2｜控罪、处刑与战争原因不能混为一层

[《袁盎晁错列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7101.md#ref-f3a61ca0da0b35)、[卷011 P004](../../sources/摘录/史记-卷011-孝景本纪.md#p004)及[《通鉴》卷016](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7016.md#ref-a31b935d701a2d)。处死晁错是实际政治处置，奏章列罪是当时官府说法，不能据批准就认定他确有谋反。晁错父亲此前劝阻无效、自杀，是传记中的前情；本页不据它给出一个未载的本年死日。景帝懊悔也不证明袁盎因此被当场罢杀，袁盎的结局另在前148年。

#### 3｜梁守、断粮与吴楚败亡

[《绛侯周勃世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7057.md#ref-91de9965255471)、[《梁孝王世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7058.md#ref-f3253ed08a6d8b)、通鉴。周亚夫出武关、经蓝田的路径是绕开险阻、保后路，不等于汉军已经丢失函谷关；断粮与梁国固守共同作用，不能只归功于一个人。原文吴军二十余万、楚众等为史书记数，未作现代兵力核算；不假称已独立核定所有战斗日。

《天官书》[P120](../../sources/摘录/史记-卷027-天官书.md#p120)：

> 吳楚七國叛逆，彗星數丈，天狗過梁野；及兵起，遂伏尸流血其下。

“及兵起”应与前兆叙述分开。彗星在[前157年九月](bce-0157.md#sj027-comet-note)、[前155年](bce-0155.md#note-other)已有明确相关年条；《汉书·天文志》把“天狗下梁野”放在文帝后元一段，而非景帝前三年（[互校H005—H006](../../sources/摘录/史记-卷027-纪年互校.md#h005)）。此处只补史家的战争回顾，不在本年虚增彗星和天狗，也不把“伏尸流血”当作预言的验证。天狗具体接年、不同彗星是否同指，见[考证](../../meta/考证/史记-卷027-纪年与异说.md#七国与前兆)。

# 公元前154年｜七国起兵，晁错被杀，汉以断粮和分路进攻平乱

[← 公元前155年](bce-0155.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前153年 →](bce-0153.md)

**汉景帝前三年**

## 削地的诏令，碰上早已积累的怨恨

**晁错主张削减诸侯王的封地，认为吴王无论削与不削，最终都可能反叛，越早处理反而损害越小。** 楚、赵、胶西先被追究过失、削去部分郡县，吴王刘濞听说削会稽、豫章的议案也已定，便与其他国相约起兵。[1](#note-revolt)

**刘濞积聚力量并非始于本年。** 吴有铜盐之利，收纳亡命者，减轻国内负担以收人心；他的太子早年与当时还是皇太子的刘启博戏争执，被刘启击杀，吴王此后长期不朝。这些是起兵前的长期背景，不全部塞成本年正月新事。[1](#note-revolt)

## 正月，吴楚等七国相继举兵

**起兵者为吴、楚、赵、胶西、胶东、菑川、济南七国。** 吴楚联军越过淮水，向西进攻梁国；胶西、胶东、菑川围齐，济南也举兵响应；赵王在北方相约匈奴，等待援助。七国各有所在，并不是七位国王始终带着同一支军队行动。[1](#note-revolt)

| 战线 | 主要行动 |
|---|---|
| 吴楚—梁 | 吴楚攻梁，想由此向西逼近朝廷；梁国守城承受正面压力 |
| 齐地 | 刘将闾一度与诸国相约，后来背约守齐；三国围临淄，济北未能发兵 |
| 赵地 | 刘遂起兵，盼匈奴相助；汉另派郦寄攻赵，后来由栾布增援 |
| 汉廷后方 | 窦婴屯荥阳，周亚夫出武关向洛阳，保护道路与关津 |

济北王刘志也曾有响应之意，却被郎中令控制，不能出兵。因此最终称七国，不把有意响应而未能实际举兵者直接凑成第八国。[1](#note-revolt)

## 景帝牺牲晁错，叛军却没有因此停止

**晁错与袁盎向来不和，袁盎入见，建议杀晁错、恢复被削土地，以息吴兵。** 皇帝采纳。丞相陶青、中尉陈嘉、廷尉张欧上奏指控晁错离间父子兄弟、主张自己守京而使皇帝亲征等，景帝批准，晁错被处死。[2](#note-chao)

**袁盎出使吴军，吴王却已不再接受简单撤兵。** 他拘住袁盎，准备迫其转变立场；袁盎最后在旧日受其恩惠者帮助下逃回。邓公从前线回来，指出诸王谋反已久，杀晁错不能使他们退兵，反而使忠言之士自危，景帝为此懊悔。[2](#note-chao)

## 周亚夫不急着救梁，而先切断吴楚的粮道

**梁王一再求救，皇帝也催周亚夫，周亚夫仍守在昌邑一带，不与吴楚主力正面决战。** 他派轻兵断绝淮、泗之间的粮路，让梁国牵住敌军。梁国的韩安国、张羽等人奋力守城，使吴楚短期内不能突破。[3](#note-war)

**吴楚缺粮后转攻汉营，周亚夫仍坚守。** 敌军佯攻东南，他判断真正攻击在西北，预先防备；吴楚攻不进去，又无粮补充，士卒渐散。汉军随后追击，联军崩溃。[3](#note-war)

**刘濞逃到东越后被杀，楚王刘戊在败局中自杀。** 汉军三月已取得主要胜利，但赵地尚在抵抗，不能把所有战线都压成同一天结束。[3](#note-war)

## 齐、赵的结局，是另外两条战线

**胶西等国攻临淄三月不下，朝廷援军到来后，叛王各自回国。** 胶西王刘卬向弓高侯韩颓当请罪，仍不能免死；胶东、菑川、济南诸王也被诛，相关国地收归汉。齐王刘将闾担心自己曾参与密谋被追究，虽然守城没有降叛军，最后仍自杀；汉廷以齐城守住为由，让其子承王。[4](#note-qi-zhao)

**栾布平定齐地后转兵攻赵，引水灌邯郸。** 赵城被破，刘遂自杀。匈奴见汉已取胜，终究没有出兵救赵。吴楚迅速失败与赵城坚持较久，是同一场战争中的不同节奏。[4](#note-qi-zhao)

## 平乱以后，不是把所有王国一律取消

**刘礼接续楚国，刘寿接续齐国；刘志从济北迁王菑川。** 皇子刘端受封胶西，刘胜受封中山；刘余由淮阳迁鲁，刘非由汝南迁江都。旧反王的支系、没有真正出兵的王，以及景帝自己的儿子，得到不同处置。[5](#note-settlement)

**王国的实际权力也开始收缩。** 朝廷加强对任官和政务的控制，后续几年继续裁减官署、改变相位名号。郡制与王国仍并存，七国之乱的结果不是立刻改成一个从此再无诸侯的国家。[5](#note-settlement)

### 卷022｜将相表互见与异说

> 纪年：三；大事纪：吳楚七國反，發兵擊，皆破之。皇子端為膠西王，勝為中山王。；相位：二。置太尉官。；将位：中尉條侯周亞夫。為太尉，擊吳楚；曲周侯酈寄為將軍，擊趙；竇嬰為大將軍，屯滎陽，欒布為將軍，擊齊。；御史大夫位：〔空〕

七国起兵、平乱、刘端与刘胜封王均接本页既有分战线叙事。将位周亚夫太尉主吴楚、郦寄击赵、窦婴屯荥阳、栾布击齐是不同任务，不能照四个人名制造四次七国之乱。郦寄与灌婴不混，窦婴的“大将军”也不自动意味着夺去周亚夫全部指挥权。

### 卷018｜本年侯籍、异年与取舍

**原格定位：** <a id="sj018-r030-jing"></a>[R030](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r030) · <a id="sj018-r032-jing"></a>[R032](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r032) · <a id="sj018-r041-jing"></a>[R041](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r041) · <a id="sj018-r044-jing"></a>[R044](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r044) · <a id="sj018-r058-jing"></a>[R058](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r058) · <a id="sj018-r061-jing"></a>[R061](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r061) · <a id="sj018-r075-jing"></a>[R075](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r075) · <a id="sj018-r085-jing"></a>[R085](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r085) · <a id="sj018-r091-jing"></a>[R091](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r091) · <a id="sj018-r094-jing"></a>[R094](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r094) · <a id="sj018-r114-jing"></a>[R114](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r114) · <a id="sj018-r128-jing"></a>[R128](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r128) · <a id="sj018-r130-jing"></a>[R130](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r130) · <a id="sj018-r132-jing"></a>[R132](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r132) · <a id="sj018-r138-jing"></a>[R138](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r138)。

[《史记》功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7018.md#ref-0d7626a90756ee)与[《汉书》功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-27839dcfd101d2)对读。普通承爵条按元年记载定位；无确月者不补日期，也不据子元年一律倒推父卒。后谥只用于辨认，不当作继位当时已经采用的称号。

[R044](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r044)：魏其闲在汉表名简。七支侯家分别见原格，不能把他们直接拼成七国之乱的“七王”，也没有材料证明每人都亲自领兵参加同一场战役。

[R061](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r061)：审平之死在汉表前一年，史表本年；此处用“因反罪失国”概述本卷位置，死亡异年另留，不把他列作已证实的吴楚前线将领。

[R085](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r085)：猗氏差继后无后而终，汉表记一年薨。承位在本年明确，去世无独立月日，作为紧接的后事说明；不把谥号“顷”误解为已经在受封时去世。

[R041](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r041)：芒行早期把跖、昭贯写，汉表分出两代；本次只把确定的昭随周亚夫作战、复封张侯放本年。已故张侯毛泽一支仍另列R141，不能合国即合人。

[R132](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r132)：史表三年卬元年，汉表二年卯嗣；五年解继，两表同有该年。未取得足够依据抹平差别，正文暂从本卷三年，汉表另一说保存，不在前155年重复承位。

<a id="note-revolt"></a>
### 1｜本纪简文与相关列传互校

主见证[卷011 P004](../../sources/摘录/史记-卷011-孝景本纪.md#p004)已经记有七国起兵、诛晁错及战后封王；战争经过另核[《吴王濞列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7106.md#ref-95639471c70d0d)、[《通鉴》卷016](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7016.md#ref-1ac97edcfe8f45)。吴太子死亡的确年未在这组材料定出，作为此前怨恨，不新造出生、博戏日。晁错“削亦反，不削亦反”是政策判断，不是已证明战争不可避免的定律。

<a id="note-chaocuo"></a>
<a id="note-chao"></a>
### 2｜控罪、处刑与战争原因不能混为一层

[《袁盎晁错列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7101.md#ref-f3a61ca0da0b35)、[卷011 P004](../../sources/摘录/史记-卷011-孝景本纪.md#p004)及[《通鉴》卷016](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7016.md#ref-a31b935d701a2d)。处死晁错是实际政治处置，奏章列罪是当时官府说法，不能据批准就认定他确有谋反。晁错父亲此前劝阻无效、自杀，是传记中的前情；本页不据它给出一个未载的本年死日。景帝懊悔也不证明袁盎因此被当场罢杀，袁盎的结局另在前148年。

<a id="note-war"></a>
### 3｜梁守、断粮与吴楚败亡

[《绛侯周勃世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7057.md#ref-91de9965255471)、[《梁孝王世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7058.md#ref-f3253ed08a6d8b)、通鉴。周亚夫出武关、经蓝田的路径是绕开险阻、保后路，不等于汉军已经丢失函谷关；断粮与梁国固守共同作用，不能只归功于一个人。原文吴军二十余万、楚众等为史书记数，未作现代兵力核算；不假称已独立核定所有战斗日。

<a id="note-qi-zhao"></a>
### 4｜七国名单与没有出兵的济北

[《齐悼惠王世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7052.md#ref-a15ed7450e5781)称“三国兵共围齐”；[《吴王濞列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7106.md#ref-8ee96b513df927)前段却明列胶西为首、胶东、菑川、济南共同围临淄，后段又称“三王”，并列胶西、胶东、菑川。因此，正文沿三国围齐的叙述，同时保留济南是否直接参加围城的记载差异，不能把四国说判作无据。齐王将闾自杀、其子刘寿承继，见齐世家与[《汉书》卷005](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7005.md#ref-fc261553d442d3)；诸王具体死法不一，不能一律统称战死。

<a id="note-settlement"></a>
### 5｜分国、迁王和王国制度分阶段

[卷011 P004](../../sources/摘录/史记-卷011-孝景本纪.md#p004)已列七国反王及战后改封，正文再与相关年表、世家核对。刘端胶西、刘胜中山、刘余鲁、刘非江都与其前封区分。王国相位、官员任命的制度主线见[前145年](bce-0145.md#sj011-kingdom-offices)的详细说明，不把后续裁官全提前成本年一天。

本纪本年另记“燕王薨”，与两种王表刘嘉在位二十六年、前152年死不合；本轮采用[前152年](bce-0152.md#sj017-yan)王统，原先本页仅在注中笼统列燕王去世，现改为明确异年，不能两年各死一次。冬十月日食另有记载；“十月”属于古年条位置，未换算现代公历。

<a id="sj017-note"></a>
### 6｜卷017逐国对接

[卷017前154年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0154)七国的“反诛／为郡”接上文各战线，不把短格的“诛”全译成同一种刑罚。济北志迁淄川、淮阳余迁鲁、胶西端与中山胜新封，接战后安排；史表六月乙亥与汉书王表乙巳有异，刘志迁淄川在汉表记次年，均保留而不强选唯一日。

河间、广川、梁来朝补本页。齐将闾之死及刘寿承位虽不在本行新增文字中，既有详叙仍保留，不能因表只连续计数而删除。下一年楚礼、齐寿元年接续本年的受位；刘非迁江都本表放前153年，正文仍按通鉴的战后主线留本年，次年不再重迁。

## 卷023｜礼制沿革与本页史事互见

[Y006原文](../../sources/摘录/史记-卷023-礼书.md#y006)。卷023正文六国畔逆原字保存；本年七国名单仍据本纪、吴王濞列传等，含胶东而不含齐。所见正义列六国漏胶东，又以齐城守释七，不能据此修改已核七国。诛晁错未止兵的次序不因本篇压缩而改变。

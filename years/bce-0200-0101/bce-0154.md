# 公元前154年｜七国起兵，晁错被杀，汉以断粮和分路进攻平乱

**汉景帝前三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj058-succession-promise-event"></a>

1. **七国起兵以前，景帝在宴饮中许诺将来传位梁王，窦婴提出反对。** 景帝尚未立太子，同弟弟饮酒时说，百年以后把帝位传给他。梁王口头辞谢，知道未必是确定的安排，心中仍喜，窦太后也高兴。宫中又传窦婴当面援引传子及嫡孙的继统原则反对，景帝沉默，太后不悦。 [[1]](#sj058-succession-promise-note)

<a id="削地的诏令碰上早已积累的怨恨"></a>

<a id="event-1"></a>

2. **削地的诏令，碰上早已积累的怨恨。** 晁错主张削减诸侯王的封地，认为吴王无论削与不削，最终都可能反叛，越早处理反而损害越小。楚王刘戊在薄太后丧服期间私通，遭削东海郡；赵王刘遂因过失被削常山郡，胶西也被追究、削地。吴王刘濞听说削会稽、豫章的议案已经确定，便与其他国相约起兵。薄太后前一年去世，服丧获罪的冬季接本古历年岁首。 [[2]](#note-1)

<a id="event-2"></a>

3. **刘濞积聚力量并非始于本年。** 吴有铜盐之利，收纳亡命者，减轻国内负担以收人心；他的太子早年与当时还是皇太子的刘启博戏争执，被刘启击杀，吴王此后长期不朝。这些是起兵前的长期背景，不全部塞成本年正月新事。 [[3]](#note-2)

<a id="正月吴楚等七国相继举兵"></a>

<a id="event-3"></a>

4. **正月，吴楚等七国相继举兵。** 起兵者为吴、楚、赵、胶西、胶东、菑川、济南七国。楚相张尚、太傅赵夷吾劝刘戊不要起兵，刘戊不听，将两人杀死；吴楚联军越过淮水，向西攻梁，攻破棘壁。赵相建德、内史王悍也进谏，刘遂竟将两人烧杀，发兵屯本国西界，等待吴军一同西进，又向北联络匈奴。胶西、胶东、菑川围齐，济南响应。七国各有所在，并不是七位国王始终带着同一支军队行动。 [[4]](#note-3)

   | 战线 | 主要行动 |
   |---|---|
   | 吴楚—梁 | 吴楚攻梁，想由此向西逼近朝廷；梁国守城承受正面压力 |
   | 齐地 | 刘将闾一度与诸国相约，后来背约守齐；三国围临淄，济北未能发兵 |
   | 赵地 | 刘遂起兵，盼匈奴相助；汉另派郦寄攻赵，后来由栾布增援 |
   | 汉廷后方 | 窦婴屯荥阳，周亚夫出武关向洛阳，保护道路与关津 |

   济北王刘志也曾有响应之意，却被郎中令控制，不能出兵。因此最终称七国，不把有意响应而未能实际举兵者直接凑成第八国。

<a id="景帝牺牲晁错叛军却没有因此停止"></a>

<a id="event-4"></a>

5. **晁错与袁盎向来不和，袁盎入见，建议杀晁错、恢复被削土地，以息吴兵。** 皇帝采纳。丞相陶青、中尉陈嘉、廷尉张欧上奏指控晁错离间父子兄弟、主张自己守京而使皇帝亲征等，景帝批准，晁错被处死。 [[5]](#note-4)

<a id="event-5"></a>

6. **袁盎出使吴军，吴王却已不再接受简单撤兵。** 他拘住袁盎，准备迫其转变立场；袁盎最后在旧日受其恩惠者帮助下逃回。邓公从前线回来，指出诸王谋反已久，杀晁错不能使他们退兵，反而使忠言之士自危，景帝为此懊悔。 [[6]](#note-5)

<a id="周亚夫不急着救梁而先切断吴楚的粮道"></a>

<a id="event-6"></a>

7. **周亚夫让梁军牵制吴楚，汉军主力先切断敌军粮道。** 七国起兵后，景帝以中尉周亚夫为太尉。周勃传记亚夫自请让梁承受吴楚攻势、由汉军断其粮道；吴王濞传则说，他在淮阳问父亲的故客邓都尉，得到固守昌邑、委梁断粮的计策。梁王一再求救，景帝也下诏催救，亚夫仍按战场形势坚守，遣弓高侯等率轻骑截断淮、泗之间的后方粮道。梁国的韩安国、张羽等奋力守城，使吴楚短期内不能突破。 梁孝王守在睢阳；吴楚先攻棘壁时，传记称有数万人被杀。韩安国、张羽所部使敌军无法径自西进。战后梁军的斩获，被本传概括为与汉廷军队大体各半。 [[7]](#note-6)

<a id="event-7"></a>

8. **吴楚缺粮后转攻汉营，周亚夫仍坚守。** 汉营有一夜惊乱，士卒相互攻击，扰至太尉帐下，亚夫仍卧而不起，军中后来才安定。吴军饥饿，反复挑战，他始终不出。敌军佯攻东南，他判断真正攻击在西北，预先防备；吴楚攻不进去，又无粮补充，士卒渐散。等到敌军退走，亚夫才派精兵追击，联军崩溃。 [[8]](#note-7)

<a id="event-8"></a>

9. **刘濞败逃后被杀，楚王刘戊自杀，楚军投降。** 刘濞的最后去向，各篇分别记为丹徒、东越或东瓯。周勃传记他率数千人逃保丹徒，汉军尽收降兵，并悬千金购其首；一个多月后，越人斩首来报。汉军三月已取得主要胜利，赵地仍在抵抗。诸将这时才认可太尉的谋划，梁王却因先前未获救援而与亚夫有隙。亚夫归来后，朝廷恢复太尉官。 [[9]](#note-8)

<a id="齐赵的结局是另外两条战线"></a>

<a id="event-9"></a>

10. **齐国守城经历动摇，路中大夫传回援军消息后被杀，解围后齐王仍自杀。** 吴楚以诛晁错、安宗庙号召，齐地四国响应并想拉齐王入伙；齐孝王刘将闾迟疑守城，遭三国合围。围急时齐曾暗中通谋，约未定，派去告急的路中大夫回来了。他奉天子命令齐坚守，却被城外围兵挡住；三国将领强迫他盟誓，要求说汉军已败，齐应速降，否则被屠。他假意答应，到城下见齐王却高呼：汉发百万兵，太尉周亚夫已破吴楚，正来救齐，一定坚守！将领遂杀他。百万是传信中的说法，不是核定实到兵数。齐王和大臣听到汉讯，决意不降。围军攻临淄三个月未能攻下。栾布、平阳侯曹奇等赶到，击破围军、解齐围，胶西、胶东、菑川王各自带兵归国；栾布等后来听说齐曾同叛国谋划，又准备转攻齐，刘将闾恐惧饮药自杀。胶西刘卬退国后向弓高侯请罪，仍不能免；胶东刘雄渠、菑川刘贤、济南刘辟光也被诛，诸国地归汉。 [[10]](#note-9)

<a id="event-10"></a>

11. **栾布平定齐地后转兵攻赵，引水灌邯郸。** 汉廷先派曲周侯郦寄攻赵，刘遂退守邯郸，史传记相持七个月。吴楚败于梁，不能西来，匈奴听到败讯也不肯入边。栾布会合攻赵军，引水灌城；城破后刘遂自杀，邯郸投降，赵幽王一支的王统断绝。吴楚迅速失败与赵城坚持较久，是同一场战争中的不同节奏；“七月”是围城时长，未给破城确日。 [[11]](#note-10)

<a id="平乱以后不是把所有王国一律取消"></a>

<a id="event-11"></a>

12. **平乱以后，齐楚续封，刘志迁王菑川，吴国则没有续立。** 景帝想让德侯之子续吴、楚元王之子刘礼续楚。窦太后责吴王年长却带头作乱，不许续吴，准许续楚。当时刘礼任宗正，已有平陆侯爵，被立为楚王，奉楚元王宗庙，后来谥文王。景帝认为齐王起初守汉，是受逼迫才与叛国有谋，便让刘寿接续齐国。刘志从济北迁王菑川；齐篇称他坚守、未与诸侯合谋，汉传却记他起初曾通谋、后来没有发兵，因此免诛。刘寿下一年开始记元年，刘志则继续原王年，不因迁国重新计算。皇子刘端受封胶西、刘胜受封中山，刘余由淮阳迁鲁，刘非由汝南迁江都，承接原吴地。刘非时年十五，勇健有力，曾请战并获将军印出击吴军，因战功又获赐天子旌旗。旧反王的宗支、没有实际出兵的王及景帝诸子，得到不同处置。 [[12]](#note-11)

<a id="event-12"></a>

13. **王国的实际权力也开始收缩。** 朝廷加强对任官和政务的控制，后续几年继续裁减官署、改变相位名号。郡制与王国仍并存，七国之乱的结果不是立刻改成一个从此再无诸侯的国家。 [[13]](#note-12)

> 是時上未置太子也。上與梁王燕飲，嘗從容言曰：「千秋萬歲後傳於王。」王辭謝。雖知非至言，然心內喜。太后亦然。

> 褚先生曰：臣為郎時，聞之於宮殿中老郎吏好事者稱道之也。竊以為令梁孝王怨望，欲為不善者，事從中生。今太后，女主也，以愛少子故，欲令梁王為太子。大臣不時正言其不可狀，阿意治小，私說意以受賞賜，非忠臣也。齊如魏其侯竇嬰之正言也，何以有後禍？景帝與王燕見，侍太后飲，景帝曰：「千秋萬歲之後傳王。」太后喜說。竇嬰在前，據地言曰：「漢法之約，傳子適孫，今帝何以得傳弟，擅亂高帝約乎！」於是景帝默然無聲。太后意不說。

**本卷说明：** 明确标为褚少孙据宫中老郎吏所闻的补说；其对迎合太后之大臣的批评，不署为司马迁。

> 三年正月乙巳，赦天下。長星出西方。天火燔雒陽東宮大殿城室。吳王濞、楚王戊、趙王遂、膠西王卬、濟南王辟光、菑川王賢、膠東王雄渠反，發兵西鄉。天子為誅晁錯，遣袁盎諭告，不止，遂西圍梁。上乃遣大將軍竇嬰、太尉周亞夫將兵誅之。六月乙亥。赦亡軍及楚元王子藝等與謀反者。封大將軍竇嬰為魏其侯。立楚元王子平陸侯禮為楚王。立皇子端為膠西王，子勝為中山王。徙濟北王志為菑川王，淮陽王餘為魯王，汝南王非為江都王。齊王將廬、燕王嘉皆薨。

**[卷050 P004完整原字与白话](../../sources/摘录/史记-卷050-楚元王世家.md#p004)**

> 王戊立二十年，冬，坐為薄太后服私姦，削東海郡。

**白话：** 本篇记刘戊在位二十年时，冬季因为在薄太后丧服期间私通而获罪，东海郡被削去。

**本卷辨析：** 薄太后卒在前155六月；这里接前154古历岁首冬，不能读作薄太后尚未死亡的前155冬。史表本年是戊21年，汉传把20年获罪与21年春起兵分叙；史记这里的年数和冬月搭配存疑。汉传削东海、薛，史记此处只记东海；不混成互无差别的同一原句。古注“服舍”指服丧居处，不足以确定通奸对象。

**[卷050 P009完整原字与白话](../../sources/摘录/史记-卷050-楚元王世家.md#p009)**

#### 卷050篇末附读：贤者、命令与所任之人

<a id="sj050-cite-024"></a>

**[卷050 P010完整原字与白话](../../sources/摘录/史记-卷050-楚元王世家.md#p010)**

> 太史公曰：國之將興，必有禎祥，君子用而小人退。國之將亡，賢人隱，亂臣貴。使楚王戊毋刑申公，遵其言，趙任防與先生，豈有篡殺之謀，為天下僇哉？賢人乎，賢人乎！非質有其內，惡能用之哉？甚矣，「安危在出令，存亡在所任」，誠哉是言也！

**白话：** 太史公说：一个国家将要兴盛，必会出现吉祥的征兆，君子得到任用，小人退下；一个国家将要灭亡，贤能的人退隐，作乱的臣子却尊贵起来。假使楚王刘戊没有处罚申公，而是听从他的话；假使赵王任用防与先生，又怎么会有篡乱杀戮的图谋，使自己被天下人诛戮、羞辱呢？贤人啊，贤人！一个人的内心如果本来没有敬重贤能的根底，又怎么能真正任用贤人？“安定或危险，取决于发出怎样的命令；存续或灭亡，取决于任用怎样的人。”这话真是深切而可信！这里保存的是史家的兴亡判断，“祯祥”不是本项目证实的超自然预兆。申公名培，所受是胥靡劳役刑，并没有在这次处罚中被杀。防与先生的具体遭遇，本篇及《汉书》都没有展开，古注也承认缺少事迹，因此不能替他编出一次有年月、有对白的拒谏。

**本卷辨析：** 篇末史论作为楚赵败亡的附读，不作为本年新发生的政令。申公受刑是劳役，不等于被处死；防与先生在本篇与汉传都无详细拒谏经过，索隐也承认未见，故不补年、地点与对白。

> 初，元王敬禮申公等，穆生不耆酒，元王每置酒，常為穆生設醴。及王戊即位，常設，後忘設焉。穆生退曰：「可以逝矣！醴酒不設，王之意怠，不去，楚人將鉗我於市。」稱疾臥。申公、白生強起之曰：「獨不念先王之德與？今王一旦失小禮，何足至此！」穆生曰：「易稱『知幾其神乎！幾者動之微，吉凶之先見者也。君子見幾而作，不俟終日。』先王之所以禮吾三人者，為道之存故也；今而忽之，是忘道也。忘道之人，胡可與久處！豈為區區之禮哉？」遂謝病去。申公、白生獨留。

**白话：** 楚元王尊重申公等人，知道穆生不爱饮酒，每逢设宴便专备甜醴。刘戊起初照办，后来忘了。穆生认为这显示楚王敬贤之心衰退，若不离开，将来会被加刑示众，遂称病。申公、白生劝他念先王恩德，不必因一时礼数疏失离去。穆生引用《易》说明应见微知著：先王尊重他们，是尊重他们所守之道；如今忽略，是忘道，不是少了一杯酒的小事。于是辞去，申公、白生独留。

**互校说明：** 这是刘戊在位期间、七国之乱以前的未定年前情。此处补唐赞典故，不把穆生受醴、离楚精确归前154。

#### 2｜控罪、处刑与战争原因不能混为一层

[《袁盎晁错列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7101.md#ref-f3a61ca0da0b35)、[卷011 P004](../../sources/摘录/史记-卷011-孝景本纪.md#p004)及[《通鉴》卷016](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7016.md#ref-a31b935d701a2d)。处死晁错是实际政治处置，奏章列罪是当时官府说法，不能据批准就认定他确有谋反。晁错父亲此前劝阻无效、自杀，是传记中的前情；本页不据它给出一个未载的本年死日。景帝懊悔也不证明袁盎因此被当场罢杀，袁盎的结局另在前148年。

<a id="3梁守断粮与吴楚败亡"></a>
#### 3｜梁守、断粮与吴楚败亡

[《绛侯周勃世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7057.md#ref-91de9965255471)、[《梁孝王世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7058.md#ref-f3253ed08a6d8b)、通鉴。周亚夫出武关、经蓝田的路径是绕开险阻、保后路，不等于汉军已经丢失函谷关；断粮与梁国固守共同作用，不能只归功于一个人。原文吴军二十余万、楚众等为史书记数，未作现代兵力核算；不假称已独立核定所有战斗日。

《天官书》[P120](../../sources/摘录/史记-卷027-天官书.md#p120)：

> 吳楚七國叛逆，彗星數丈，天狗過梁野；及兵起，遂伏尸流血其下。

“及兵起”应与前兆叙述分开。彗星在[前157年九月](bce-0157.md#sj027-comet-note)、[前155年](bce-0155.md#note-other)已有明确相关年条；《汉书·天文志》把“天狗下梁野”放在文帝后元一段，而非景帝前三年（[互校H005—H006](../../sources/摘录/史记-卷027-纪年互校.md#h005)）。此处只补史家的战争回顾，不在本年虚增彗星和天狗，也不把“伏尸流血”当作预言的验证。天狗具体接年、不同彗星是否同指，见[考证](../../meta/考证/史记-卷027-纪年与异说.md#七国与前兆)。

#### 4｜七国名单与没有出兵的济北

[《齐悼惠王世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7052.md#ref-a15ed7450e5781)称“三国兵共围齐”；[《吴王濞列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7106.md#ref-8ee96b513df927)前段却明列胶西为首、胶东、菑川、济南共同围临淄，后段又称“三王”，并列胶西、胶东、菑川。因此，正文沿三国围齐的叙述，同时保留济南是否直接参加围城的记载差异，不能把四国说判作无据。齐王将闾自杀、其子刘寿承继，见齐世家与[《汉书》卷005](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7005.md#ref-fc261553d442d3)；诸王具体死法不一，不能一律统称战死。

#### 5｜分国、迁王和王国制度分阶段

[卷011 P004](../../sources/摘录/史记-卷011-孝景本纪.md#p004)已列七国反王及战后改封，正文再与相关年表、世家核对。刘端胶西、刘胜中山、刘余鲁、刘非江都与其前封区分。王国相位、官员任命的制度主线见[前145年](bce-0145.md#sj011-kingdom-offices)的详细说明，不把后续裁官全提前成本年一天。

本纪本年另记“燕王薨”，与两种王表刘嘉在位二十六年、前152年死不合；本轮采用[前152年](bce-0152.md#sj017-yan)王统，原先本页仅在注中笼统列燕王去世，现改为明确异年，不能两年各死一次。冬十月日食另有记载；“十月”属于古年条位置，未换算现代公历。

<a id="6卷017逐国对接"></a>
#### 6｜卷017逐国对接

[卷017前154年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0154)七国的“反诛／为郡”接上文各战线，不把短格的“诛”全译成同一种刑罚。济北志迁淄川、淮阳余迁鲁、胶西端与中山胜新封，接战后安排；史表六月乙亥与汉书王表乙巳有异，刘志迁淄川在汉表记次年，均保留而不强选唯一日。

河间、广川、梁来朝补本页。齐将闾之死及刘寿承位虽不在本行新增文字中，既有详叙仍保留，不能因表只连续计数而删除。下一年楚礼、齐寿元年接续本年的受位；刘非迁江都本表放前153年，正文仍按通鉴的战后主线留本年，次年不再重迁。

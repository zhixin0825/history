# 公元前155年｜六位皇子封王，申屠嘉去世，晁错权势上升

[← 公元前156年](bce-0156.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前154年 →](bce-0154.md)

**汉景帝前二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="冬十二月男子二十岁开始登记服役"></a>

<a id="event-1"></a>

1. **冬十二月，男子二十岁开始登记服役。** 朝廷规定，男子年满二十开始傅籍。 这把适龄男子纳入服役登记，关系到国家可以征调的人力。登记与每个人立即离乡赴某一边塞，仍是两回事。 [[1]](#note-1)

<a id="三月景帝把六个儿子封为王"></a>

<a id="event-2"></a>

2. **三月，景帝把六个儿子封为王。** 刘德为河间王，刘阏为临江王，刘余为淮阳王，刘非为汝南王，刘彭祖为广川王，刘发为长沙王。 广川、长沙两王随后就国。汉廷一面警惕已有的大国，一面继续让皇子分守地方，并未准备立即取消所有诸侯王国。 [[2]](#note-2)

<a id="event-3"></a>

3. **四月壬午，太皇太后薄氏去世。** 她是文帝的母亲、景帝的祖母。窦皇太后仍在世，不能把两位太后混为同一人。 她葬于南陵。吕后已与高祖同茔于长陵，薄氏因而另有陵区，靠近儿子文帝的霸陵；南陵此前已在营建，死亡与始置陵园并非同一年。 [[3]](#note-3)

<a id="六月丞相想治晁错的罪却没能得到皇帝支持"></a>

<a id="event-4"></a>

4. **六月，申屠嘉准备追究晁错，晁错先入宫说明。** 晁错受宠，常单独入见，推动更改法令；申屠嘉却感到自己说话越来越不管用。 晁错为了出入方便，在衙署南面另开一道门，触及太上皇庙外的围地。申屠嘉抓住此事，准备奏请处死晁错；晁错提前得讯，夜里入宫说明。 [[4]](#note-4)

<a id="event-5"></a>

5. **景帝替晁错辩护，说那里不是庙内的围墙，而且开门出于自己的许可。** 申屠嘉退朝后深感挫败，回家呕血而死。八月，陶青接任丞相，晁错升为御史大夫。主张削藩的官员离权力中心更近了。 [[5]](#note-5)

<a id="祖先功劳仍能影响后人的待遇"></a>

<a id="event-6"></a>

6. **祖先功劳仍能影响后人的待遇。** 萧何的孙子受封武陵侯。 早年追随高祖的功臣家族，到了景帝时期仍是朝廷需要安置的一部分。梁国则凭窦太后宠爱，获得大量赏赐，招揽宾客，修宫苑、广城池，已经成为不能忽视的大国。 [[6]](#note-6)

<a id="event-7"></a>

7. **秋季，汉与匈奴继续和亲，衡山一带遭到大雹。** 本年又有彗星和行星运行的记录，灾情与天象都保留来源，不拿它们证明下一年的叛乱是天命注定。 [[7]](#note-7)

<a id="sj017-audience"></a>
<a id="楚济北赵梁四王入朝"></a>

<a id="event-8"></a>

8. **楚、济北、赵、梁四王入朝。** 刘戊、刘志、刘遂、刘武本年来朝。 四位已有封国的王，与本年六位新封皇子分别记述；其中有的后来叛汉，有的支持朝廷，不能从同时入朝推定已经形成共同立场。 [[8]](#note-8)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-9"></a>

9. **阳都侯安成因罪失国。** 从丁复传下的这一支封爵，到景帝二年中断。 [[9]](#note-9)

<a id="sj018-succession"></a>

<a id="event-10"></a>

10. **侯爵继续在各家传承。** 以下记录本年开始的侯年；继承家爵不等于同时承接父辈的中央官职。 [[10]](#note-10)

    | 侯籍一支 | 本年变化 |
    |---|---|
    | 費 | 偃接费侯，续常一代。 |
    | 阿陵 | 胜客接阿陵侯，续欧一代；汉表将“胜”连于谥号，名客。 |
    | 壯 | 恢接壮侯，续许倩一支。 |

### 6. 萧何的孙子受封武陵侯

[返回正文第6条](#event-6)

**[互校H006](../../sources/摘录/史记-卷027-纪年互校.md#h006)**

> 孝景元年正月癸酉，金、水合於婺女。占曰：「為變謀，為兵憂。婺女，粵也，又為齊。」其七月乙丑，金、木、水三合於張。占曰：「外內有兵與喪，改立王公。張，周地，今之河南也，又為楚。」其二年七月丙子，火與水晨出東方，因守斗。占曰：「其國絕祀。」至其十二月，水、火合於斗。占曰：「為淬，不可舉事用兵，必受其殃。」一曰：「為北軍，用兵舉事大敗。斗，吳也，又為粵。」是歲彗星出西南。其三月，立六皇子為王，淮陽、汝南、河間、臨江、長沙、廣川。其三年，吳、楚、膠西、膠東、淄川、濟南、趙七國反。吳、楚兵先至攻梁，膠西、膠東、淄川三國攻圍齊。漢遣大將軍周亞夫等戍止河南，以候吳楚之敝，遂敗之。吳王亡走粵，粵攻而殺之。平陽侯敗三國之師于齊，咸伏其辜，齊王自殺。漢兵以水攻趙城，城壞，王自殺。六月，立皇子二人、楚元王子一人為王，王膠西、中山、楚。徙濟北為淄川王，淮陽為魯王，汝南為江都王。七月，兵罷。天狗下，占為：「破軍殺將。狗又守禦類也，天狗所降，以戒守禦。」吳、楚攻梁，梁堅城守，遂伏尸流血其下。

**[P120](../../sources/摘录/史记-卷027-天官书.md#p120)**

> 漢之興，五星聚于東井。平城之圍，月暈參、畢七重。諸呂作亂，日蝕，晝晦。吳楚七國叛逆，彗星數丈，天狗過梁野；及兵起，遂伏尸流血其下。元光、元狩，蚩尤之旗再見，長則半天。其後京師師四出，誅夷狄者數十年，而伐胡尤甚。越之亡，熒惑守鬬；朝鮮之拔，星茀于河戍；兵征大宛，星茀招搖：此其犖犖大者。若至委曲小變，不可勝道。由是觀之，未有不先形見而應隨之者也。

<a id="3人名工程前情与行政疑句"></a>
#### 3｜人名、工程前情与行政疑句

萧何孙在本纪、汉书纪作系，功臣表及传有嘉，古注已指出差异，本页不为一人另建两次受封。梁王宫苑、招宾客是通鉴在本年介绍的长期背景，不都算本年开工；待[前154年](bce-0154.md)入战局时接读。冰雹“五寸、深二尺”为史书记数，不换成未经验证的现代灾情数据。

P003末“置南陵及内史、祋祤为县”有断句与归年问题。三家注据地理、百官材料区别文帝时南陵与景帝时内史分置、祋祤置县；正文不写出“内史县”或让南陵重新建一次。详[本卷考证](../../meta/考证/史记-卷011-纪年与异说.md#疑名与制度)。

《汉书·天文志》在“其二年”条下记“是歲彗星出西南”（[互校H006](../../sources/摘录/史记-卷027-纪年互校.md#h006)），与景帝前二年的本纪记载同属本年。《天官书》[P120](../../sources/摘录/史记-卷027-天官书.md#p120)把彗星、天狗与后来七国兵起合述，是跨年回顾；[前157年九月](bce-0157.md#sj027-comet-note)又有另一条彗星记录，不把两条混成前154年同一次观测。

#### 4｜卷017的国栏、封日与朝见

[卷017前155年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0155)四个来朝格均归本页，六皇子同列三月甲寅，临江名作阏于，与本纪简称阏同人。上一年各国初置栏是本次封王的先导，不在前156年再立六王；广川都信都、临江都江陵属相应国的地理提示，不证明所有人同日到达。

本行又列分楚置鲁、中山都卢奴，实际刘余迁鲁、刘胜封中山沿[前154年](bce-0154.md#note-settlement)。不能把预设栏位提前写成当年已授王印。各王来朝没有月份，不安排他们同时参与六王册封礼。

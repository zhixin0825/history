# 公元前156年｜景帝承接文帝旧业，恢复田租并继续减笞

[← 公元前157年](bce-0157.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前155年 →](bce-0155.md)

**汉景帝前元年**

> 刘启在前157年已即帝位，本年开始景帝纪年。汉初十月岁首，冬十月在本年正月以前；以下保留古月，不直接换作同号公历月份。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="十月追颂先帝议定庙乐"></a>

<a id="event-1"></a>

1. **十月，景帝要求制作昭德之舞，表彰文帝。** 景帝要求制作昭德之舞，表彰文帝的教化与施政。 诏书历数放宽关津、去诽谤之罪、改刑、赈济老人孤独、减省服御与出宫人等措施，要求把这些功德传给后世。 [[1]](#note-1)

<a id="event-2"></a>

2. **申屠嘉等上议：高祖有开国之功，文帝有治民之德。** 高皇帝庙作为太祖之庙，文帝庙作为太宗之庙，郡国诸侯都应奉祀，并有明确的荐献、乐舞安排。景帝批准。追尊先帝，也是在说明新皇帝准备继承什么样的统治原则。 [[2]](#note-2)

<a id="正月允许百姓搬到适宜生产的地方"></a>

<a id="event-3"></a>

3. **正月，允许百姓搬到适宜生产的地方。** 连年收成不足，有的地方狭窄贫瘠，另一些地方有水土却未充分开垦。 朝廷允许愿意迁徙的百姓前往土地宽广、适合农桑畜养之处。减轻饥荒不能只靠发一纸安民诏，也要给人寻找生计的机会。 [[3]](#note-3)

<a id="四五月赦罪和亲又恢复征收田租"></a>

<a id="event-4"></a>

4. **四月乙卯，朝廷大赦，随后赐民爵一级，遣御史大夫陶青到代地与匈奴议和。** 代地受到匈奴侵扰，和亲是应对边事的一种办法，并不表示此后不会再有战争。 [[4]](#note-4)

<a id="event-5"></a>

5. **五月，田租按三十取一征收。** 文帝此前曾免田租，这次是重新征收，但只取旧十五税一的一半。对百姓而言，不能简单说又在免税基础上减了一半；对国家而言，则重新得到一项稳定收入。 [[5]](#note-5)

<a id="宽刑的诏令还要落实到受刑者身上"></a>

<a id="event-6"></a>

6. **朝廷把五百笞降为三百，把三百笞降为二百。** 文帝废除部分肉刑以后，替代的重笞仍会致人死亡；景帝这次减少击数，是继续修正文帝改革中的问题，而不是原样重发前167年的诏令。 [[6]](#note-6)

<a id="event-7"></a>

7. **一批在太子宫服务过的官员进入要职。** 周仁任郎中令，张欧任廷尉，刘礼任宗正，晁错任内史。晁错由此更接近皇帝决策，后来削减诸侯封地的方案也将由他积极推动。 [[7]](#note-7)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-8"></a>

8. **肥如侯奴去世，无后，侯国撤销。** 这支从蔡寅的军功起家，到新帝元年结束，并不因此成为新帝清洗功臣的证据。 [[8]](#note-8)

<a id="sj018-succession"></a>

<a id="event-9"></a>

9. **侯爵继续在各家传承。** 以下记录本年开始的侯年；继承家爵不等于同时承接父辈的中央官职。 [[9]](#note-9)

   | 侯籍一支 | 本年变化 |
   |---|---|

   | 平皋 | 刘光接平皋侯，续刘远一代。 |
   | 甯 | 指开始记甯侯元年，续连一代。 |
   | 陸梁 | 冉接陆梁侯，续庆忌一代。 |

   [本段原文、异年及说明](#sj018-note)。

### 6. 朝廷把五百笞降为三百，把三百笞降为二百

[返回正文第6条](#event-6)

**[《漢書》卷023](../../sources/本地分卷/汉书/汉书-卷023.md#L5016)**

> 景帝元年，下詔曰：「加笞與重罪無異，幸而不死，不可為人。其定律：笞五百曰三百，笞三百曰二百。」猶尚不全。至中六年，又下詔曰：「加笞者，或至死而笞未畢，朕甚憐之。其減笞三百曰二百，笞二百曰一百。」又曰：「笞者，所以教之也，其定箠令。」丞相劉舍、御史大夫衛綰請：「笞者，箠長五尺，其本大一寸，其竹也，末薄半寸，皆平其節。當笞者笞臀。毋得更人，畢一罪乃更人。」自是笞者得全，然酷吏猶以為威。死刑既重，而生刑又輕，民易犯之。

[《汉书》卷023《刑法志》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7023.md#ref-c258d796a1a21d)

#### 卷022｜将相表互见与异说

[本年原表R051](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r051) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0156)。

> 纪年：孝景元年；大事纪：立孝文皇帝廟，郡國為太宗廟。；相位：七。置司徒官。；将位：〔空〕；御史大夫位：〔空〕

文帝太宗庙、郡国庙制接本页原诏。相位“七”是申屠嘉任期，“置司徒官”为本格单见、官制有疑；不据此断言景帝已采用成帝、哀帝以后的大司徒制度，亦不推造第一任司徒姓名。 参见[汪越《读史记十表》卷十](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%AE%80%E5%8F%B2%E8%A8%98%E5%8D%81%E8%A1%A8-%E5%8D%B7%E5%8D%81.md#ref-d30c7cebc24d8a)的逐项校读；所用古代考证与现今已经解决全部异说不是一回事。

#### 卷019｜本年侯籍与异说

[完整原表](../../sources/摘录/史记-卷019-惠景间侯者年表.md) · [逐格去向](../../meta/记录/史记-卷019-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷019-纪年与异说.md)。原格的承侯元年不一律等于前任死年；未载月日不补，谥号是后称，国除也不一律等于处死。

<a id="sj019-r058-e02-n"></a>
**弓高｜[R058原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r058)：** 史表景元年列侯则元年，但前154年战事仍由韩颓当领军；[《汉书·高惠高后文功臣表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-2319dacb69410d)缺中间嗣侯年名，元朔五年又将“则嗣、薨、无后”相连。故本格只保存侯统分歧，不认定韩颓当前156年已死，也不以整朝16年等于则已证实的任期。

<a id="1保留卷010旧事校正本卷的月份压缩"></a>
#### 1｜保留卷010旧事，校正本卷的月份压缩

[卷010 P041](../../sources/摘录/史记-卷010-孝文本纪.md#p041)、[《汉书》卷005元年十月](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7005.md#ref-c5241be72d632a)及[《通鉴》卷015](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7015.md#ref-ccd20ddb0061a3)都把庙乐诏议放在冬十月；[卷011 P002](../../sources/摘录/史记-卷011-孝景本纪.md#p002)接在五月减租后。本页沿原有十月，不再造五月第二次立庙。原`sj010-temple`锚点保留。追颂中的旧政仍归文帝各年，庙号不是文帝在世自称。

所据卷010“除（肉）［宫］刑”校记继续留在[刑制说明](../../meta/考证/史记-卷010-纪年与异说.md#刑制)，不单凭颂辞宣布宫刑已经绝迹。本卷“令群臣无朝贺”原句保留在P002，适用场合未明，不扩成景帝从此取消一切朝仪。

<a id="2元年的减笞与中六年的箠令分开"></a>
#### 2｜元年的减笞与中六年的箠令分开

[《汉书》卷023《刑法志》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7023.md#ref-c258d796a1a21d)及通鉴元年条。原有减笞事实和锚点保留；[前144年](bce-0144.md#sj011-flogging)还有进一步减笞及刑具、行刑规则，不能全部提前。本页只列法定变化，不由笞数减少推出确切死亡率。

<a id="sj011-policy"></a>
<a id="3迁民和亲与半租"></a>
#### 3｜迁民、和亲与半租

[卷011 P002](../../sources/摘录/史记-卷011-孝景本纪.md#p002)、汉书元年正月及四五月、通鉴元年五月“复收民田半租，三十而税一”。本纪“除田半租”必须与文帝免租及复收的上下文合读。田租并非所有赋役，迁民的准许也不等于已核得实际迁徙人数。汉书网页的使者名有异写，通鉴与下一年相位记录可核陶青，正文采用陶青。

<a id="4身世与登场不重复计年"></a>
#### 4｜身世与登场不重复计年

[卷011 P001](../../sources/摘录/史记-卷011-孝景本纪.md#p001)的刘启身世回指[前179年立太子](bce-0179.md#sj010-family)，[前157年继位](bce-0157.md)也已有正文。本卷“三男”与《外戚世家》“四男”不硬拼，正文只用刘恒、窦氏之子的可核身份。新官任职由通鉴元年补充，不把晁错的一生和所有奏议都塞入本年。

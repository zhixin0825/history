# 公元前157年｜文帝遗诏缩短丧礼，刘启继承皇帝位

[← 公元前158年](bce-0158.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前156年 →](bce-0156.md)

**汉文帝后七年；刘启本年继位，次年为景帝元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="六月文帝去世留下不愿久扰百姓的遗诏"></a>

<a id="event-1"></a>

1. **六月己亥，刘恒死于未央宫。** 从代王入继，到前元十六年、后元七年，他已统治二十三个年次。前一卷的远接结语在这里与本卷实际终局合上，不再另造一次死亡。 [[1]](#note-1)

<a id="event-2"></a>

2. **遗诏认为死亡是自然之理，不应为了死者破坏生者的生活。** 厚葬容易耗尽家产，长期服丧又会使父子长幼受寒暑、饮食与日常祭祀受限。皇帝要求天下吏民在诏到以后哭临三日便释服，不必停止嫁娶、祭祀、饮酒和吃肉。 [[2]](#note-2)

<a id="event-3"></a>

3. **宫中直接负责丧事的人另有较细的规则。** 不必赤足，绖带不过三寸，不用布蒙车和兵器，不征发百姓到宫殿哭丧；宫中只在早晚各举哀十五声，礼毕即止。下棺以后，按大功十五日、小功十四日、纤七日依次服丧，之后释服。对不同人群的规定不能全部缩成一句“全国只丧三日”。 [[3]](#note-3)

<a id="event-4"></a>

4. **霸陵山川仍旧，夫人以下至少使等宫人获准归去。** 皇帝不希望借自己的死亡继续扩大陵园改造和宫廷拘束，但安葬仍须有实际工程和守备。 [[4]](#note-4)

<a id="葬事仍动员军士并由三名将军分工"></a>

<a id="event-5"></a>

5. **葬事仍动员军士，并由三名将军分工。** 文帝临终前嘱咐太子，一旦有急难，周亚夫确实可以担当统兵之任。文帝去世后，亚夫任车骑将军，属国悍任将屯将军，郎中令武任复土将军。朝廷调发近县现有军卒一万六千、内史卒一万五千，分别办理守备、安葬、覆土等事。 文帝也叮嘱刘启善待卫绾。 [[5]](#note-5)

<a id="event-6"></a>

6. **乙巳葬于霸陵，群臣上尊号孝文皇帝；丁未，太子刘启继为皇帝。** 薄太后尊为太皇太后，窦皇后成为皇太后。新君接位在本年，改用景帝元年的年条则从下一古历年开始。 刘启做太子时，薄太后已选本家女子为其妃；他继位以后，这位薄氏成为皇后。 这一时期，窦婴由文帝时的吴相旧臣转任詹事。 景帝初即位，李广由陇西都尉调任骑郎将。 文帝的近臣邓通在景帝继位后被免职，归家居住。 [[6]](#note-6)

<a id="sj017-changsha"></a>

<a id="event-7"></a>

7. **长沙靖王吴产也在本年去世，无子，王国撤除。** 高祖以后仅存的吴氏王国传了数代，到此结束；其后长沙再封给宗室，是另一阶段。年表另记他本年来朝，未给月份，不据此断言来朝、去世和文帝丧事都在同一天。 [[7]](#note-7)

<a id="sj027-comet"></a>
<a id="九月西方出现彗星"></a>

<a id="event-8"></a>

8. **九月，西方出现彗星。** 景帝继位后，西方出现一颗有长芒的彗星。 记载说其根部在尾、箕方向，末端指向虚、危，延及天汉，十六日后不再可见。它与三年后七国起兵的联系，是后来的占验解释，不是本年已有叛乱爆发。 [[8]](#note-8)

<a id="event-9"></a>

9. **文帝曾想建露台，听工匠估价百金，便放弃。** 他拿这笔费用与十户中等家庭的产业相比，觉得奉用先帝留下的宫室已足，不必再为自己造台。他常穿绨衣，又要求慎夫人的衣裳不拖地、帷帐不绣花，以示俭朴。 [[9]](#note-9)

<a id="event-10"></a>

10. **霸陵的安排也强调少用贵重装饰、不起高坟。** 陵内用瓦器，不以金银铜锡为饰，并尽量保持原来的山川。这里讲的是传世的节葬要求，不是说地下墓室、外藏设施和实际丧葬工程都不存在。 [[10]](#note-10)

<a id="event-11"></a>

11. **有时他宁愿以宽容和羞愧感代替立即惩罚。** 吴王称病不朝，文帝赐几杖；袁盎等进谏尖锐，仍能被接纳；张武等受贿被察觉，皇帝反从御府赐钱，希望使其惭愧，而没有交给官吏办罪。这些例子是本纪对德化的说明，不意味着他对所有违法、叛乱都如此处置。 [[11]](#note-11)

    南越复约见[前179年](bce-0179.md#sj010-nanyue)，匈奴和战见前166、162、158年。已经有可靠年次的事仍在原年，不因总评又出现一次就全部搬到这里。

[本年原表R050](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r050) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0157)。 另核[四库本卷022考证](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E9%9B%86%E8%A7%A3%20%28%E5%8F%B8%E9%A6%AC%E9%81%B7%2C%20%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29-%E5%8D%B7022.md#ref-c9e678abdab9eb)。

> 纪年：七；大事纪：六月己亥，孝文皇帝崩。丁未，太子立。民出臨三日，葬霸陵。；相位：六；将位：中尉亞夫為車騎將軍，郎中令張武為復土將軍，屬國捍為將屯將軍。詹事戎奴為車騎將軍，侍太后。；御史大夫位：〔空〕

文帝去世、刘启即位、民临三日及霸陵安葬接原故事；三日适用群体仍按遗诏细分。本表另记“詹事戎奴为车骑将军，侍太后”，本纪没有这一句，四库本考证据同年已有周亚夫任车骑而疑为传写错误。本页只留原格与疑说，不把戎奴任命写成已经独立核实的第四项丧事军职，也不把戎奴与亚夫冒认同人。表“张武”与本纪简称“武”同属复土将军互见；不把后来任中尉的张武事迹全部塞来。

#### 卷019｜本年侯籍与异说

[完整原表](../../sources/摘录/史记-卷019-惠景间侯者年表.md) · [逐格去向](../../meta/记录/史记-卷019-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷019-纪年与异说.md)。原格的承侯元年不一律等于前任死年；未载月日不补，谥号是后称，国除也不一律等于处死。

<a id="sj019-r001-e02-n"></a>
**便｜[R001原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r001)：** 依本格明确的年号或元年定位；无确月的，不由同年其他事件借用日期。

<a id="sj019-r059-e02-n"></a>
**襄成｜[R059原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r059)：** 汉表作释之，暂按相同侯统位置识别；继者元年不自动确定韩婴的卒月。

<a id="sj019-r061-e01-n"></a>
**章武｜[R061原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r061)：** 古史仍记文帝后元七年，不能据表栏标题把六月封赏都称为文帝亲自颁下。窦广国早年经历见前179年，不在本年重新失散相认。

<a id="sj019-r062-e01-n"></a>
**南皮｜[R062原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r062)：** 两爵均属新帝初年的外戚封赏，非同一人受两国；本年受封与多年以前的外家生活分开。

#### 卷018｜本年侯籍、异年与取舍

[《史记》功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7018.md#ref-38c95ee74b2477)与[《汉书》功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-74b478eb2df200)对读。普通承爵条按元年记载定位；无确月者不补日期，也不据子元年一律倒推父卒。后谥只用于辨认，不当作继位当时已经采用的称号。

<a id="1保留卷009远接的原有落点"></a>
#### 1｜保留卷009远接的原有落点

[卷009 P045](../../sources/摘录/史记-卷009-吕太后本纪.md#p045) · [卷010 P038—P040](../../sources/摘录/史记-卷010-孝文本纪.md#p038)。前元十六年与后元七年共二十三个年次，不是文帝另建名为“二十三年”的年号；死亡、谥号与继位各有相对日期，未折算公历。旧锚点和前卷引用继续可用。

<a id="sj010-funeral"></a>
<a id="2三日与三十六日不是同一人群的一套矛盾规定"></a>
#### 2｜三日与三十六日，不是同一人群的一套矛盾规定

[卷010 P038](../../sources/摘录/史记-卷010-孝文本纪.md#p038) · [《汉书》卷004末年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-eaf961da0111a7) · [《通鉴》卷十五](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7015.md#ref-7eab629ecd2616)。面向天下吏民的三日释服，与直接承办丧礼者下棺后的十五、十四、七日分级服制，分别说明；“大红小红”等为所据见证用字，正文按大功小功的礼制服名解释。遗诏中称天下安宁、靡有兵革是概括性言辞，不能抵消本卷已经记过的边战。

<a id="sj010-burial"></a>
<a id="3节葬仍有工程死与继位仍分日"></a>
#### 3｜节葬仍有工程，死与继位仍分日

[卷010 P039—P040](../../sources/摘录/史记-卷010-孝文本纪.md#p039) · 汉书、通鉴同年。乙巳安葬由互见补足，本纪在该日写上尊号；丁未刘启继位，不挪到前156年再即位一次。郎中令武、属国悍在本段只有简名，不擅补全名、倒填所有履历。两项征发是所记两组，不能各自扩大成全国全部葬役人数。

<a id="sj010-retrospect-note"></a>
<a id="4长期总评不能假装是逐年账册"></a>
#### 4｜长期总评不能假装是逐年账册

[卷010 P037](../../sources/摘录/史记-卷010-孝文本纪.md#p037)总述宫室苑囿服御无所增，与正文修五帝庙等并存，应理解其对宫廷生活节制的评价，不能当成二十三年每一类建筑投资均为零的统计结论。露台、慎夫人、吴王几杖和张武受贿未单给年，不强归早年或本年。传世“不治坟”也不证明霸陵没有墓葬设施；本页不将文学描写冒充主墓室发掘后的清单。

太史公肯定文帝教化，并称改正服、封禅之意因谦让未成；司马贞另作索隐述赞。两者都可读，但不是本年新发生的政令。[卷010 P042—P043](../../sources/摘录/史记-卷010-孝文本纪.md#p042) · [论赞说明](../../meta/考证/史记-卷010-纪年与异说.md#论赞)。

<a id="5卷017的长沙来朝终局与异名"></a>
#### 5｜卷017的长沙来朝、终局与异名

[卷017前157年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0157)长沙二十一年“来朝，薨，无后，国除”，汉书异姓诸侯王表则称靖王产，在位二十二年。本页按[前178年所定口径](bce-0178.md#sj017-note)称吴产，原页吴著及史表著的写法保留为异名；两表都把终局落在文帝后七年，不为一个字制造另一个君主。无后指封国继承问题，不能推论吴氏一切生物学后裔都已绝灭。随后刘发受封长沙见[前155年](bce-0155.md#note-register)，是另一支新王统。
<a id="sj027-comet-note"></a>
<a id="6九月彗星及与七国战争的距离"></a>
#### 6｜九月彗星及与七国战争的距离

《汉书·五行志》（[互校H011](../../sources/摘录/史记-卷027-纪年互校.md#h011)）：

> 文帝後七年九月，有星孛于西方，其本直尾、箕，末指虛、危，長丈餘，及天漢，十六日不見。

《汉书·景帝纪》（[互校H017](../../sources/摘录/史记-卷027-纪年互校.md#h017)）在继位之后、元年年条之前也记“九月，有星孛于西方”。古史整年仍属文帝后七年，景帝元年始于下一年。本条是《天官书》[P120](../../sources/摘录/史记-卷027-天官书.md#p120)七国回顾的相关记录之一，但不能断言它就是“彗星數丈”唯一所指；[前155年](bce-0155.md#note-other)另有彗星，均不并成[前154年](bce-0154.md#note-war)新天象。

# 公元前158年｜细柳军守令不让皇帝驰入，旱蝗又迫使朝廷赈济

[← 公元前159年](bce-0159.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前157年 →](bce-0157.md)

**汉文帝后六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="冬季匈奴两路入边汉在边地与京畿同时布防"></a>

<a id="event-1"></a>

1. **冬季，匈奴两路入边，汉在边地与京畿同时布防。** 匈奴分别进入上郡、云中，所报每路三万骑，烽火传至甘泉、长安。令免屯飞狐，苏意屯句注，张武屯北地；京畿则由河内守周亚夫任将军屯细柳，刘礼屯霸上，祝兹侯所部屯棘门。朝廷既要守边，也担心敌骑继续深入首都附近。 [[1]](#note-1)

<a id="sj010-xiliu"></a>
<a id="皇帝能直入霸上棘门却被细柳军拦在营外"></a>

<a id="event-2"></a>

2. **文帝亲自劳军，在霸上、棘门直接驰入，将领随骑迎送。** 到细柳，先行车骑却被挡住。军中吏士披甲，刀刃出鞘，弓弩张满；先驱虽称天子将到，军门都尉仍按将军令拒入，说军中听将军之令，不能仅凭天子将到的口头通报开门。皇帝随后亲到，也不得径入。 [[2]](#note-2)

<a id="event-3"></a>

3. **皇帝派使者持节传达劳军之意，才得以进入细柳。** 周亚夫命开营门，又要求车骑不得在军中奔驰。文帝放慢车速前行，见亚夫披甲持兵，拱手行礼。亚夫自称甲胄之士不行常拜礼，请用军礼相见。文帝改容，扶轼俯身致敬，并使人传达敬劳之意。离营后，他称细柳是真正的军队，另外两营如同儿戏，将领容易被袭俘，亚夫却不可轻犯，称善良久。 [[3]](#note-3)

<a id="event-4"></a>

4. **一个多月后，匈奴退去，汉也罢军，周亚夫被任为中尉。** 三支京畿驻军撤防，亚夫转任掌管京师守卫的中尉。 [[4]](#note-4)

<a id="夏四月旱灾与蝗灾接踵而至"></a>

<a id="event-5"></a>

5. **夏四月，发生旱蝗，朝廷减省用度、开仓赈济。** 文帝令诸侯不必入贡，开放山泽，削减服御、狗马和郎吏员额。 宫廷先减少一部分耗用，再开仓赈济贫民。百姓还获准出售爵位，以便取得生活所需；这不是宣布人人可以买卖实任官职。 [[5]](#note-5)

<a id="sj017-audience"></a>

<a id="event-6"></a>

6. **淮南王刘安、梁王刘武、长沙王吴产本年来朝。** 三条记录与免贡诏分开理解：免去贡输不自动等于从此禁止国王来朝，也不能由年度并列便认定三人是在四月诏令以后到达。 [[6]](#note-6)

<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[本年原表R049](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r049) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0158)。

> 纪年：六；大事纪：匈奴三萬人入上郡，二萬人入雲中。；相位：五；将位：以中大夫令免為車騎將軍，軍飛狐，故楚相蘇意為將軍，軍句注；。將軍張武屯北地；河內守周亞夫為將軍，軍細柳；宗正劉禮軍霸上；祝茲侯徐厲軍棘門：以備胡。數月，胡去，亦罷。；御史大夫位：〔空〕

上郡三万、云中两万是两路来犯兵数，沿原叙事不相加为单一战场实测人数。表中刘礼、苏意等与本纪、通鉴的姓名异写各依原注辨别，军飞狐、句注、北地与近京细柳、霸上、棘门分开。原格“令免”的读法及姓名异写留待进一步校核，不误读成当年免去一名车骑将军；诸军数月后罢，不编确切撤军日。

<a id="sj010-158-war"></a>
<a id="1原本纪的军队部署"></a>
#### 1｜原本纪的军队部署

[卷010 P035](../../sources/摘录/史记-卷010-孝文本纪.md#p035) · [《汉书》卷004后六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-2e1c34a880a083) · [《通鉴》卷十五](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7015.md#ref-94f53c78e6c1a5)。令勉／令免等用字有异，正文取汉书、通鉴；徐厉姓名虽见互见军记，却与侯表前173年已列后嗣的记录相冲突，详本页卷019注，正文暂不确定个人名。两支三万骑是史书记数，不凭相加就认定全部匈奴军力六万。数月罢军与其后升中尉分开，不把新官提前安在劳军之初。

<a id="sj010-158-discipline"></a>
<a id="2细柳的完整场景来自互见"></a>
#### 2｜细柳的完整场景来自互见

本纪只有屯细柳、备胡，没有完整劳军对白；这里据通鉴及[《史记》卷057《绛侯周勃世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7057.md#ref-9d39e5e998eeaa)补足，未宣称该世家已经整卷整理。周亚夫为周勃之子，此前任河内守；父亲前180年夺北军，与儿子本年治军是不同事件。持节、营令和军礼构成故事的关键，不能只剩下“敢抗皇命”一句。

<a id="sj010-158-famine"></a>
<a id="3天灾减省与卖爵的边界"></a>
#### 3｜天灾、减省与卖爵的边界

[卷010 P036](../../sources/摘录/史记-卷010-孝文本纪.md#p036)概写天下旱蝗，月份取汉书、通鉴夏四月。开仓、减省、弛山泽有明文，实际覆盖人数和灾后产量未记，不把政策命令写成饥荒已全面消除。民得卖爵针对爵制中的身份与权益，不直接等同官署职位买卖。

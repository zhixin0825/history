# 公元前158年｜细柳军守令不让皇帝驰入，旱蝗又迫使朝廷赈济

[← 公元前159年](bce-0159.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前157年 →](bce-0157.md)

**汉文帝后六年**

## 冬季，匈奴两路入边，汉在边地与京畿同时布防

**匈奴分别进入上郡、云中，所报每路三万骑，烽火传至甘泉、长安。** 令免屯飞狐，苏意屯句注，张武屯北地；京畿由周亚夫屯细柳、刘礼屯霸上，祝兹侯所部屯棘门。朝廷既要守边，也担心敌骑继续深入首都附近。[1](#sj010-158-war)

<a id="sj010-xiliu"></a>
## 皇帝能直入霸上、棘门，却被细柳军拦在营外

**文帝亲自劳军，在霸上、棘门直接驰入，将领随骑迎送。** 到细柳，先行车骑却被挡住。守门官说，军中听将军之令，不能仅凭天子将到的口头通报开门。[2](#sj010-158-discipline)

**皇帝到门前也不能立即进入，只得派使者持节传达劳军之意。** 周亚夫这才命开营门，又要求车骑不得在军中奔驰。文帝放慢车速前行，见到披甲持兵的周亚夫；周亚夫表示甲胄之士不行跪拜，要以军礼相见。皇帝改容致敬，离营后称赞这才是真正能防备突然袭击的将军。[2](#sj010-158-discipline)

**匈奴退去，汉也罢军，周亚夫被任为中尉。** 这次主要是布防与劳军，没有记录周亚夫在细柳打败一支已冲进长安的匈奴军队。[1](#sj010-158-war)

## 夏四月，旱灾与蝗灾接踵而至

**文帝令诸侯不必入贡，开放山泽，削减服御、狗马和郎吏员额。** 宫廷先减少一部分耗用，再开仓赈济贫民。百姓还获准出售爵位，以便取得生活所需；这不是宣布人人可以买卖实任官职。[3](#sj010-158-famine)

<a id="sj017-audience"></a>
**淮南王刘安、梁王刘武、长沙王吴产本年来朝。** 三条记录与免贡诏分开理解：免去贡输不自动等于从此禁止国王来朝，也不能由年度并列便认定三人是在四月诏令以后到达。[4](#sj017-note)

<a id="sj010-158-war"></a>
### 1｜原本纪的军队部署

[卷010 P035](../../sources/摘录/史记-卷010-孝文本纪.md#p035) · [《汉书》卷004后六年](https://zh.wikisource.org/wiki/漢書/卷004) · [《通鉴》卷十五](https://zh.wikisource.org/wiki/資治通鑑/卷015)。令勉／令免等用字有异，正文取汉书、通鉴；徐厉姓名虽见互见军记，却与侯表前173年已列后嗣的记录相冲突，详本页卷019注，正文暂不确定个人名。两支三万骑是史书记数，不凭相加就认定全部匈奴军力六万。数月罢军与其后升中尉分开，不把新官提前安在劳军之初。

<a id="sj010-158-discipline"></a>
### 2｜细柳的完整场景来自互见

本纪只有屯细柳、备胡，没有完整劳军对白；这里据通鉴及[《史记》卷057《绛侯周勃世家》](https://zh.wikisource.org/wiki/史記/卷057)补足，未宣称该世家已经整卷整理。周亚夫为周勃之子，此前任河内守；父亲前180年夺北军，与儿子本年治军是不同事件。持节、营令和军礼构成故事的关键，不能只剩下“敢抗皇命”一句。

<a id="sj010-158-famine"></a>
### 3｜天灾、减省与卖爵的边界

[卷010 P036](../../sources/摘录/史记-卷010-孝文本纪.md#p036)概写天下旱蝗，月份取汉书、通鉴夏四月。开仓、减省、弛山泽有明文，实际覆盖人数和灾后产量未记，不把政策命令写成饥荒已全面消除。民得卖爵针对爵制中的身份与权益，不直接等同官署职位买卖。

<a id="sj017-note"></a>
### 4｜卷017的三国来朝

[卷017前158年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0158)淮南七、梁二十一、长沙二十年来朝，名单按连续王统识别。吴产在史表作著，承位年的差别见[前178年](bce-0178.md#sj017-note)，不再创造第二位长沙王。

# 公元前159年｜一年三次出巡，往返陇西、雍与代

[← 公元前160年](bce-0160.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前158年 →](bce-0158.md)

**汉文帝后五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **正月，文帝到陇西；三月到雍；七月又到代地。** 从西北到北方，皇帝多次离开长安，继续巡行已经熟悉的区域。所用年条没有写明每次出巡的全部目的、沿途政策和停留日数，不能把三次行程都自动解释成大战之前的军事侦察。 [[1]](#note-1)

<a id="sj017-audience"></a>

<a id="event-2"></a>

2. **楚王刘戊、城阳王刘喜、济南王刘辟光、胶西王刘卬本年来朝。** 刘喜已经从淮南迁回城阳，另外三位以后虽都卷入七国之乱，本年条仍只记朝见，不先写成来京共谋反叛。 [[2]](#note-2)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-3"></a>

3. **高京侯周成因谋反罪下狱，死在狱中，侯国被撤销。** 他原先是以父亲周苛守荥阳、拒降死事的功劳受封；周苛的旧功与儿子的案件必须分开。 [[3]](#note-3)

<a id="sj018-succession"></a>

<a id="event-4"></a>

4. **侯爵继续在各家传承。** 以下记录本年开始的侯年；继承家爵不等于同时承接父辈的中央官职。 [[4]](#note-4)

   | 侯籍一支 | 本年变化 |
   |---|---|
   | 槁 | 安接槁侯，续应一代。 |
   | 東陽 | 安国接东阳侯，续殷一代。 |
   | 邔 | 明接邔侯，续荣盛一代。 |

   [本段原文、异年及说明](#sj018-note)。

#### 1｜按实际记载保留简短年度页

[《汉书》卷004后五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-cd8b30845ab6e7)与[《通鉴》卷十五后五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7015.md#ref-eb08d42496fdca)均记三次巡行。卷010没有单列本年，此处补编年底本中的有年事件，不因内容短就虚构劝农、减税或征战细节。次年匈奴入边另见下一页，不能用后来事件倒推本年每一次决策的动机。

<a id="sj017-note"></a>
<a id="2四王来朝不等于同行巡边"></a>
#### 2｜四王来朝不等于同行巡边

[卷017前159年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0159)楚十六、城阳十八、济南六、胶西六年来朝，月份和地点未记，不把他们随意安排为皇帝每次出巡的同行人员。城阳年数包括迁封以前的统治，不据十八年倒推它中间从未被改为郡。

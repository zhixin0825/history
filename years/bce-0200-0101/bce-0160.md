# 公元前160年｜日食之后大赦，一批官奴婢获得庶人身份

[← 公元前161年](bce-0161.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前159年 →](bce-0159.md)

**汉文帝后四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="四月日食五月颁布赦令"></a>

<a id="event-1"></a>

1. **四月丙寅晦，发生日食；五月，朝廷大赦天下。** 汉代年条往往把天象与随后政令相接，这里保留二者的时间关系，不把日食本身当作某项政治决策对错的证明。 [[1]](#note-1)

<a id="event-2"></a>

2. **官府所属奴婢获免为庶人，文帝又出巡雍地。** 身份变化是具体的行政措施，不能因为同年没有大规模宫廷争斗就略去。 [[2]](#note-2)

<a id="sj017-audience"></a>

<a id="event-3"></a>

3. **济北王刘志、燕王刘嘉、赵王刘遂本年来朝。** 三人在各自国栏都有记录，没有具体月日与会谈内容，不能给他们编出共同请求赦免的奏议。 [[3]](#note-3)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-4"></a>

4. **共侯商去世，无后，侯国终止。** 初侯卢罢师一支的爵位传了数代，到这时中断。 [[4]](#note-4)

<a id="sj018-succession"></a>

<a id="event-5"></a>

5. **侯爵继续在各家传承。** 以下记录本年开始的侯年；继承家爵不等于同时承接父辈的中央官职。 其中平阳侯曹奇是曹窋之子；父亲卒于前一年，承爵与本年侯元年相接。 [[5]](#note-5)

   | 侯籍一支 | 本年变化 |
   |---|---|
   | 平陽 | 曹奇接平阳侯，续曹窋一代。 |
   | 南安 | 千秋接南安侯，续戎一代。 |
   | 故市 | 续接故市侯，续毋害一代。 |
   | 絳陽 | 禄接绛阳侯，续勃齐一代。 |
   | 須昌 | 不害接须昌侯，续福一代。 |

   [本段原文、异年及说明](#sj018-note)。

<a id="sj058-return19-event"></a>

6. **梁王结束留京，返回封国。** 刘武在此前连续入朝后留京，本年返梁；这是同段行程的结束。 [[6]](#sj058-return19-note)

<a id="hs-event-7"></a>

7. **平阳懿侯曹参｜承爵。** 表载平阳懿侯曹参一支本年记载侯位承袭。表中所载事项为简侯竒承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **敬市侯阎泽赤｜承爵。** 表载敬市侯阎泽赤一支本年记载侯位承袭。表中所载事项为戴侯续承爵。 [[8]](#hs-note-8)

<a id="1免官奴婢不是取消所有奴婢身份"></a>
#### 1｜免官奴婢不是取消所有奴婢身份

[《汉书》卷004后四年](../../拆分史书/汉书/卷004.md#part-1-text) · [《通鉴》卷十五后四年](../../拆分史书/资治通鉴/卷015.md#text)。官奴婢免庶见汉书，原条没有逐人名单和地方执行细节，不声称同时解放了所有私人奴婢。大赦仍有当时法令语境，不能据“天下”推定任何罪名都毫无例外。古历晦日不换为未经核定的现代日期。

<a id="sj017-note"></a>
<a id="2三王来朝"></a>
#### 2｜三王来朝

[卷017前160年](../../拆分史书/史记/卷017.md#y0160)济北五、燕十八、赵二十年来朝。赵遂是刘友之子，燕嘉是刘泽之子，济北志是刘肥之子，名字与封国均按连续王统辨认；原表计年不作皇帝在位年使用。

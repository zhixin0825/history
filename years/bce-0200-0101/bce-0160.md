# 公元前160年｜日食之后大赦，一批官奴婢获得庶人身份

[← 公元前161年](bce-0161.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前159年 →](bce-0159.md)

**汉文帝后四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="四月日食五月颁布赦令"></a>

<a id="event-1"></a>

1. **四月丙寅晦，发生日食；五月，朝廷大赦天下。** 汉代年条往往把天象与随后政令相接，这里保留二者的时间关系，不把日食本身当作某项政治决策对错的证明。 [[1]](#note-1)

<a id="event-2"></a>

2. **官府所属奴婢获免为庶人，文帝又出巡雍地。** 身份变化是具体的行政措施，不能因为同年没有大规模宫廷争斗就略去。 [[2]](#note-2)

<a id="sj017-audience"></a>

<a id="event-3"></a>

3. **济北王刘志、燕王刘嘉、赵王刘遂本年来朝。** 三人在各自国栏都有记录，没有具体月日与会谈内容，不能给他们编出共同请求赦免的奏议。 [[3]](#note-3)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-4"></a>

4. **共侯商去世，无后，侯国终止。** 初侯卢罢师一支的爵位传了数代，到这时中断。 [[4]](#note-4)

<a id="sj018-succession"></a>

<a id="event-5"></a>

5. **侯爵继续在各家传承。** 以下记录本年开始的侯年；继承家爵不等于同时承接父辈的中央官职。 其中平阳侯曹奇是曹窋之子；父亲卒于前一年，承爵与本年侯元年相接。 [[5]](#note-5)

   | 侯籍一支 | 本年变化 |
   |---|---|
   | 平陽 | 曹奇接平阳侯，续曹窋一代。 |
   | 南安 | 千秋接南安侯，续戎一代。 |
   | 故市 | 续接故市侯，续毋害一代。 |
   | 絳陽 | 禄接绛阳侯，续勃齐一代。 |
   | 須昌 | 不害接须昌侯，续福一代。 |

   [本段原文、异年及说明](#sj018-note)。

<a id="1免官奴婢不是取消所有奴婢身份"></a>
#### 1｜免官奴婢不是取消所有奴婢身份

[《汉书》卷004后四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-1090bdc16e709c) · [《通鉴》卷十五后四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7015.md#ref-3308dbfe8dd610)。官奴婢免庶见汉书，原条没有逐人名单和地方执行细节，不声称同时解放了所有私人奴婢。大赦仍有当时法令语境，不能据“天下”推定任何罪名都毫无例外。古历晦日不换为未经核定的现代日期。

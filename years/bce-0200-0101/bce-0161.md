# 公元前161年｜文帝再到代地，匈奴更换单于

[← 公元前162年](bce-0162.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前160年 →](bce-0160.md)

**汉文帝后三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="二月皇帝前往旧日封地"></a>

<a id="event-1"></a>

1. **二月，皇帝前往旧日封地。** 文帝再次出巡代地。 这是他称帝以后多次往返的北方地区，但本年已读年条没有详列每项军政安排，不能只因皇帝到了边地，就补成一场亲征。 [[1]](#note-1)

<a id="匈奴老上单于死军臣单于继位"></a>

<a id="event-2"></a>

2. **匈奴老上单于死，军臣单于继位。** 老上单于去世，由其子军臣接位。 汉与匈奴上一年刚重新确定和亲，协议面对的政治环境又有了变化。是否继续履行、怎样约束边地部众，仍须从后续行动判断。 [[2]](#note-2)

<a id="sj017-dai"></a>
<a id="刘登接续代国四位诸侯王入朝"></a>

<a id="event-3"></a>

3. **刘登开始记代王元年，接续上一年去世的刘参。** 这支王室是文帝自己的儿孙，不是早年降匈奴的韩王信一支。代国在北方的延续，也不等于疆域和行政安排一直不变。 [[3]](#note-3)

<a id="sj017-audience"></a>

<a id="event-4"></a>

4. **齐王刘将闾、济北王刘志、济南王刘辟光、梁王刘武本年来朝。** 前三位都是刘肥之子，梁王则是文帝之子；同来朝不代表四人后来会采取相同政治立场。 传记又记此次留京，至次年前160年才回封国。 [[4]](#note-4)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-5"></a>

5. **信武侯靳亭因役使侯国百姓超过法定限额而失侯。** 父亲靳歙的军功并不使侯家可以不受限制地使用封国内的人力。 [[5]](#note-5)

<a id="event-6"></a>

6. **祝阿侯成也因同类“事国人过律”的罪名失国。** 两案都反映了侯爵权益与国家法令之间的界限，但具体被役使人数、时日没有记明。 [[6]](#note-6)

<a id="sj018-succession"></a>

<a id="event-7"></a>

7. **侯爵继续在各家传承。** 以下记录本年开始的侯年；继承家爵不等于同时承接父辈的中央官职。 [[7]](#note-7)

   | 侯籍一支 | 本年变化 |
   |---|---|
   | 廣平 | 薛泽开始记广平一支的侯年。 |
   | 博陽（陳濞） | 陈始接陈濞一支的博阳侯爵；汉表转列塞。 |
   | 陸梁 | 庆忌接陆梁侯，续桑一代。 |

   [本段原文、异年及说明](#sj018-note)。

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-8"></a>

8. **朝廷设置谷口邑。** 这是行政建置的短记，现有材料没有展开迁民人数和具体营城经过。 [原格与说明](#sj022-note)。 [[8]](#note-8)

<a id="sj054-event-9"></a>

9. **平阳侯曹窋去世。** 曹窋为侯二十九年而卒，谥静侯；侯表另写靖侯。爵位传给儿子曹奇，新侯元年接下一年。 [[9]](#sj054-note-9)

<a id="sj096-event-10"></a>

10. **申屠嘉正式受封故安侯。** 申屠嘉已于前162年拜相。《汉书》功臣侯表列文帝后元三年四月丁巳封故安侯。 [[10]](#note-10)

#### 2｜代王元年与四个来朝格

[卷017前161年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0161)代恭王登元年及齐、济北、济南、梁来朝；父子链见[梁孝王世家](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7058.md#ref-8fd82d4a13c487)代王附叙。刘参死亡仍在[前162年](bce-0162.md)，不由新元年再记一次死亡。朝见月份未载，也未证明四王在代地而非京城见皇帝。

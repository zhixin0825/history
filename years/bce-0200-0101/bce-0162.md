<a id="夏季往返多次的使者终于带回和议"></a>

<a id="event-1"></a>

1. **夏季，往返多次的使者终于带回和议。** 汉与匈奴连年相攻，云中、辽东尤其受到侵扰，吏民和牲畜损失严重。 文帝派使者反复传话，单于也遣当户答谢，双方重新约为兄弟、放下部分旧争端。文帝颁诏说明，久结仇怨、连年动兵，两边都难安生，和亲从今年重新确立。 [[1]](#note-1)

<a id="event-2"></a>

2. **六月，代王刘参去世。** 他早先王太原，后来接代地，与皇帝出巡的旧封地长期相连。本年皇帝也曾赴雍的棫阳宫。 [[2]](#note-2)

<a id="八月张苍离任文帝没有让窦广国做丞相"></a>

<a id="event-3"></a>

3. **八月，张苍离任，文帝没有让窦广国做丞相。** 张苍免相后，文帝觉得窦广国有才有德，却担心天下认为自己偏私皇后弟弟。 最后选择御史大夫申屠嘉，任为丞相。封故安侯的异年见[封侯条](bce-0161.md#sj096-p015)。申屠嘉曾以张强弩的材官随高祖作战，为人廉直，不接受私下请托。 [[3]](#note-3)

<a id="event-4"></a>

4. **新相把宠臣邓通的无礼当作必须追究的朝廷问题。** 邓通在皇帝身边态度怠慢，申屠嘉奏事后批评，退朝又发文召他到相府。邓通脱冠赤足、叩头谢罪，仍被斥为大不敬。文帝最后派持节使者把他召回，才使事情停住。 此事未详月日。另见[申屠嘉相期阅读](时期-张苍等汉相的仕历与逸事.md#note-5)。 [[4]](#note-4)

5. **周亚夫被封为条侯，接续周勃一家的奉祀。** 哥哥周胜之已经失爵，皇帝从周勃其他儿子中选择继承者。众人推举当时任河内守的亚夫，认为他最贤。传记回叙初封以前一则没有确年的相面故事：许负预言，他三岁后为侯、侯八岁为将相、此后九岁饿死；亚夫认为哥哥、侄子本应承侯，对此质疑，许负便指着他通入口中的纹理作答。 [[5]](#note-5)

### 4. 新相把宠臣邓通的无礼当作必须追究的朝廷问题

[返回正文第4条](#event-4)

<a id="sj096-p016"></a>

**[《史记·张丞相列传》P016](../../sources/摘录/史记-卷096-张丞相列传.md#p016)** · [三家注](../../sources/史记三家注/卷096.md#p16)

> 是時太中大夫鄧通方隆愛幸，賞賜累巨萬。文帝嘗燕飲通家，其寵如是。是時丞相入朝，而通居上傍，有怠慢之禮。丞相奏事畢，因言曰：「陛下愛幸臣，則富貴之；至於朝廷之禮，不可以不肅！」上曰：「君勿言，吾私之。」罷朝坐府中，嘉爲檄召鄧通詣丞相府，不來，且斬通。通恐，入言文帝。文帝曰：「汝第往，吾今使人召若。」通至丞相府，免冠，徒跣，頓首謝。嘉坐自如，故不爲禮，責曰：「夫朝廷者，高皇帝之朝廷也。通小臣，戲殿上，大不敬，當斬。吏今行斬之！」通頓首，首盡出血，不解。文帝度丞相已困通，使使者持節召通，而謝丞相曰：「此吾弄臣，君釋之。」鄧通旣至，爲文帝泣曰：「丞相幾殺臣。」

<a id="sj010-162-peace"></a>
<a id="1这是复约不是历史上第一次和亲"></a>
#### 1｜这是复约，不是历史上第一次和亲

[卷010 P034](../../sources/摘录/史记-卷010-孝文本纪.md#p034) · [《通鉴》卷十五后二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7015.md#ref-cfe6103e0f6056)。诏称“始于今年”指本次协议，不抹去前此多次和亲，也不保证下一任单于绝不进攻。云中、辽东“郡万余人”等为文献所报，不据它推算整个边境的精确总损失。

<a id="sj010-162-chancellor"></a>
<a id="2亲族顾虑与维护相权"></a>
#### 2｜亲族顾虑与维护相权

相位调整及邓通故事用通鉴同年补入。文帝担心偏私是其所述考虑，并不能由此证明全部人事从无亲疏；邓通在相府受斥没有被写成实际遭斩。张苍关于历法、水德的意见仍在前166—165年，不因后来离职便抹去其早年作用。相府冲突没有独立日次，不能让它与八月任命必为同一天。

<a id="卷026正式免相与此前失势分开"></a>
### 卷026｜正式免相与此前失势分开

[《历书》P010](../../sources/摘录/史记-卷026-历书.md#p010)的“自黜”回接[前165年土德议论](bce-0165.md#sj026-note)；本页八月的正式免相仍依本纪、将相表和《通鉴》的既有年线，不提前三年。《张丞相列传》把“自绌，谢病称老”与任用中候犯法、受责、病免依次叙述，不能把其中每一阶段都压成本年同日，也不能将文帝改历不成全归于一次免官。见[文帝说明](../../meta/考证/史记-卷026-纪年与异说.md#文帝)。

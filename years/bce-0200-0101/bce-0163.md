<a id="reading-start"></a>

<a id="冬十月新垣平被告发处死"></a>
### 冬十月，新垣平被告发、处死

<a id="event-1"></a>

1. **有人上书指出，新垣平所说的祥瑞和望气都是欺诈。** 朝廷交官吏审治，新垣平被处死、夷三族。去年献杯促成的改元已经实行，方士本人却失去信任。 [[1]](#note-1)

<a id="event-2"></a>

2. **文帝此后不再热心亲自推动改正朔、服色及鬼神之事。** 渭阳、长门的祭祀仍由祠官按时负责，皇帝不再照原先的热情前往。方士获罪不等于一切国家祭祀同时被废。 [[2]](#note-2)

<a id="三月惠帝皇后张氏去世"></a>
### 三月，惠帝皇后张氏去世

<a id="event-3"></a>

3. **这位早年由吕后安排嫁给惠帝的皇后，在文帝朝结束一生。** 她在前191年立后、与少帝继承故事有直接关系；后来的政权更替没有使她在前180年就一同被杀。 [[3]](#note-3)

<a id="皇帝向大臣追问土地人口没有巨变为何百姓缺粮"></a>
### 皇帝向大臣追问：土地人口没有巨变，为何百姓缺粮

<a id="event-4"></a>

4. **连续歉收，加上水旱、疫病，使朝廷再次面对民食不足。** 文帝要求丞相、列侯、二千石官吏和博士讨论，是政事失当、无用费用太多，还是人们离农、酿酒养畜耗粮过度。他承认自己尚未弄明白原因，要求众人不要隐瞒有助百姓的意见。 [[4]](#note-4)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>
### 功臣侯家的承袭与兴废

<a id="event-5"></a>

5. **棘蒲侯陈武去世，封国未能传给嗣子奇。** 奇早年已经因谋反获罪，父亲的死亡与儿子失去继承资格在这里汇合；不是父子本年一同起兵、被杀。 [R031](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r031) [[5]](#note-5)

<a id="event-6"></a>

6. **龙侯坚被夺爵，侯国终止。** 他在吕后时承接陈署一支，如今失去了原来的封邑。 [R097](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r097) [[6]](#note-6)

<a id="sj018-succession"></a>

<a id="event-7"></a>

7. **侯爵继续在各家传承。** 以下记录本年开始的侯年；继承家爵不等于同时承接父辈的中央官职。 [[7]](#note-7)

   | 侯籍一支 | 本年变化 | 原格 |
   |---|---|---|
   | 肥如 | 奴接肥如侯，续成一代。 | [R037](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r037) |
   | 磨 | 灶接磨侯，续釐一代；汉表国名历。 | [R082](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r082) |

<a id="1方士案与求粮食政策不是同一条因果"></a>
#### 1｜方士案与求粮食政策不是同一条因果

[卷010 P033](../../sources/摘录/史记-卷010-孝文本纪.md#p033) · [《汉书》卷004后元年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-df03932ab77403) · [《通鉴》卷十五](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7015.md#ref-c80c18d9ddafee)。本纪概记欺诈事觉，汉书另带谋反罪名；不能据该罪名添写一场实际发动的方士兵变。夷三族这一处置，与前179年除收孥的诏令并列，说明不能把后者泛化为所有案件永无株连。

求助百姓诏中的各项粮荒原因是皇帝提出的疑问，未获本段数据检验；正文不把其中任何一项写成已确定的全国歉收原因。张皇后死亡由汉书、通鉴补入，用于延续既有人物，不补未记载的死因。

<a id="卷026所谓作乱与停止改制"></a>
### 卷026｜所谓作乱与停止改制

[《历书》P010](../../sources/摘录/史记-卷026-历书.md#p010)称新垣平“后作乱”，本页仍从《孝文本纪》《汉书》《通鉴》写气神欺诈案发与夷族，不仅凭这个概称另造一场武装叛乱。“废不复问”指文帝不再积极过问相应改正朔、服色与神明之议；已有五帝祭祀仍由祠官按时办理，不扩大为此后汉朝全面废历、废祭。见[文帝诸事](../../meta/考证/史记-卷026-纪年与异说.md#文帝)。

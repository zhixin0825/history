1. **四月，文帝亲祭新庙，讨论更大的礼制安排。** 皇帝到渭阳五帝庙亲行郊祀，礼仪采用赤色。 新垣平得到上大夫地位和厚赏。博士、诸生受命从经典中整理《王制》，议巡狩、封禅，长门道北又建五帝坛。皇帝对方术和礼制的期待，正在相互推动。 [[1]](#note-1)

2. **朝廷重分齐、淮南旧地，列侯等受封为王。** 五月，刘肥尚在世的六个儿子分别受王号：杨虚侯刘将闾王齐，安都侯刘志王济北，朸侯刘辟光王济南，武城侯刘贤王菑川，平昌侯刘卬王胶西，白石侯刘雄渠王胶东。齐文王刘则前一年无后而国除，中央没有把全境重新交给一人，而是分予同支宗室；加上已经存在的城阳，合为七王，城阳此时在位的是刘喜。封王月日的本纪、汉表异记见同号原文。刘喜从淮南回为城阳王；刘长尚在世的三个儿子刘安、刘勃、刘赐，分别王淮南、衡山、庐江。父亲在前174年被废、死于途中，四子在前172年先获侯爵，现在其中三人由侯进王；刘长亦被追尊为淮南厉王。这批新王大多已有侯爵，并不是突然从无名之人变成国君。刘将闾原阳虚侯、刘志安都侯、刘贤武城侯、刘雄渠白石侯、刘卬平昌侯、刘辟光扐侯；刘安原阜陵侯、刘勃安阳侯、刘赐阳周侯。表又列淄川都剧、胶西都宛、胶东都即墨，作为王国驻地的提示；各人何日实际到国，不能从这些简格一律推出。 [[2]](#note-2)

3. **新垣平以玉杯及得鼎预言劝设祭。** 九月，新垣平先让人把玉杯送到宫阙，再告诉皇帝有宝玉之气正在到来。果然有人献杯，上刻延寿字样，使他的预言看起来得到验证。他还宣称太阳会在一天中再次居中，文帝更加相信他的说法，宣布明年改元，赐天下大酺。周鼎将从汾阴出现的预言，又使朝廷派人临河建庙等待。寻鼎与改元没有立刻带来稳定的祥瑞政治，新垣平的欺诈很快将在下一古历年暴露。 [[3]](#note-5)

<a id="sj010-164-ritual"></a>
<a id="1尚赤不等于所有制度已经整体换新"></a>
#### 1｜尚赤不等于所有制度已经整体换新

[卷010 P032](../../sources/摘录/史记-卷010-孝文本纪.md#p032) · [《通鉴》卷十五十六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7015.md#ref-9581ac7aea71f8)。亲祀、奖方士、编礼议封禅分别记述；议论不是正式封禅已经举行，赤色使用也不能推出岁首已经由十月改成其他月份。

<a id="sj010-164-kings"></a>
<a id="2后十六年是后来到了前元十六年"></a>
#### 2｜“后十六年”是后来到了前元十六年

[卷010 P024](../../sources/摘录/史记-卷010-孝文本纪.md#p024)在六年案后远接此事，明确回本年，而不是从前174年再减十六年。五月及九位王的名单用[《汉书》卷004](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-c55bc7db907048)、通鉴核对。四子侯封与三子王封属于两个阶段，人数不同不等于同一次封赏漏记一人。刘喜前169年迁淮南、本年还城阳也只写成同一人的迁封，不造两个城阳王。

[卷017前164年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0164)九王同列四月丙寅，与本纪、汉书五月不同；正文沿既有五月，原日不强换成唯一公历日期。前165年各国初置及刘喜徙城阳在表中先列，本年又以十三年承接，是分栏、连续计数与实际授命的层次，不重办两次分封。刘喜不在新封九王之内；后来所谓“齐分七”须把已存在的城阳一支计入，不把六与七当成作者误数。旧爵号、剧／宛／即墨沿表保存，现代位置与全境界线不据此推定。

<a id="sj010-164-jade"></a>
<a id="3献杯与改元按两年拆开"></a>
#### 3｜献杯与改元按两年拆开

[卷010 P033](../../sources/摘录/史记-卷010-孝文本纪.md#p033)把得杯写在“十七年”，汉书、通鉴明确本年九月献杯、议明年改元，采用后者。日再中的文字属于方术叙事，不能当作太阳真的倒行的观测结论；汾阴建庙是行动，周鼎确已出土则没有在此发生。下一年后元年仍只是一年，不在年表额外增加一个重复的十七年。

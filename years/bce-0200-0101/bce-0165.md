# 公元前165年｜黄龙报告使土德说翻身，新垣平进入朝廷

[← 公元前166年](bce-0166.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前164年 →](bce-0164.md)

**汉文帝前十五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="春季成纪报有黄龙"></a>

<a id="event-1"></a>

1. **春季，成纪报有黄龙。** 朝廷收到成纪出现黄龙的报告，文帝重新召见公孙臣，任为博士。 原先被张苍驳回的土德之说取得机会，公孙臣与诸生开始草拟改历、服色等事项。报告引发了真实的政策讨论，不等于所有主张立刻全部施行。 [[1]](#note-1)

<a id="event-2"></a>

2. **四月，皇帝到雍，第一次在那里亲自郊见五帝，并大赦天下。** 对一些已经中断的名山大川祭祀，也命官员按时恢复。皇帝愿意亲临，并要求礼官不要以担心他劳苦为由不作建议。 [[2]](#note-2)

<a id="九月直言进策仍是进身的机会"></a>

<a id="event-3"></a>

3. **九月，直言进策仍是进身的机会。** 诸侯王、公卿、郡守奉命举荐贤良、能直言极谏者，皇帝亲自策问。 晁错名列高第，升中大夫，又提出削弱诸侯及更改法令的多项建议。文帝赏识他的才干，但并没有把建议尽数接受。 [[3]](#note-3)

<a id="望气者提出长安东北还应新建五帝庙"></a>

<a id="event-4"></a>

4. **望气者提出，长安东北还应新建五帝庙。** 赵人新垣平以望气之术进见，说东北有五彩神气。 皇帝听从建议，营建渭阳五帝庙。新垣平又把周鼎重现、玉英将至等祥瑞与皇帝的礼制事业联系起来，他在朝廷中的影响逐渐扩大。 [[4]](#note-4)

<a id="sj017-successions"></a>

<a id="event-5"></a>

5. **齐王刘则与河间王刘福在本年去世，均无子继位，两个王国被撤除。** 刘福刚接续上一年去世的父亲刘辟强，便结束在位；父子并非同年同时死亡。齐地随后如何重新分封，成为下一年的重要安排。 [[5]](#note-5)

<a id="sj017-audience"></a>

<a id="event-6"></a>

6. **燕王刘嘉、梁王刘武本年入朝。** 梁王已经由淮阳迁来，原淮阳王号不能继续用于本次朝见；燕王也不是早年的刘泽。 [[6]](#note-6)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-7"></a>

7. **强侯服因罪失爵，侯国撤销。** 短表没有留下完整罪情，不能把附近年份的淮南、济北案件移给他。 [[7]](#note-7)

<a id="event-8"></a>

8. **侯爵继续在各家传承。** 以下记录本年开始的侯年；继承家爵不等于同时承接父辈的中央官职。 [[8]](#note-8)

   | 昌 | 通接昌侯，续卢卿一支。 |
   | 共 | 商接共侯，续党一代；汉表名高。 |

<a id="sj010-165"></a>
<a id="1祥瑞礼仪与改制草案分开"></a>
#### 1｜祥瑞、礼仪与改制草案分开

[卷010 P030—P031](../../sources/摘录/史记-卷010-孝文本纪.md#p030) · [《通鉴》卷十五](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7015.md#ref-06833d436a00c9)。正文写收到黄龙报告，不断言现代已经证实这种动物出现；公孙臣被任命、举行雍祭、新庙营造则是文本所记的行动。土德草议不直接等于全国已换历；文帝后来的封禅意向也未实现。

晁错策问与新垣平进见是不同渠道，不把方术、经术与官员选拔混成一件事。齐、河间两王的死亡没有记病因，不能因与祥瑞相邻而附会为祭祀灵验或政治谋杀。

<a id="sj017-note"></a>
<a id="2无后除国来朝与分国先导"></a>
#### 2｜无后除国、来朝与分国先导

[卷017前165年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0165)齐则、河间福终局归本页，燕梁来朝分别保留；刘福父系见[楚元王世家](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7050.md#ref-7154ed8978e7a9)的河间附叙。衡山、庐江、城阳、济北、济南、淄川、胶西、胶东各格初置／复置，以及刘喜徙回城阳，是下一阶段分国的先导，正式诸王安排沿[前164年五月](bce-0164.md#sj010-164-kings)，不能照格位提前又封九王。淄川都剧、胶西都宛、胶东都即墨的原表地理信息随次年王国一并说明。

### 卷026｜黄龙报告与张苍自黜

[《历书》P010](../../sources/摘录/史记-卷026-历书.md#p010)的黄龙见成纪、改历议论接本页原事，仍以报告、任博士和草拟制度为可叙行动，不把瑞异当成现代独立确证。篇中“张苍自黜”，与[《张丞相列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7096.md#ref-016078b79ee5c3)“由此自绌，谢病称老”相接；列传随后另写所任中候犯法而被责，才说病免。此处不能简化为本年即正式罢相，实际免相仍见[前162年](bce-0162.md#sj026-note)。

新垣平进见、作渭阳庙按《孝文本纪》《汉书·文帝纪》及《通鉴》仍在本页；《封禅书》接语“其明年”与该主线有出入，不能凭一句接语把全部事项顺延。见[文帝归年与异文](../../meta/考证/史记-卷026-纪年与异说.md#文帝)。

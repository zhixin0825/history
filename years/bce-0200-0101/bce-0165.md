1. **成纪报黄龙，文帝郊祀五帝，后议立五帝庙。** 春季，成纪报有黄龙。朝廷收到成纪出现黄龙的报告，文帝重新召见公孙臣，任为博士。原先被张苍驳回的土德之说取得机会，公孙臣与诸生开始草拟改历、服色等事项。报告引发了真实的政策讨论，不等于所有主张立刻全部施行。四月，对一些已经中断的名山大川祭祀，也命官员按时恢复。皇帝愿意亲临，并要求礼官不要以担心他劳苦为由不作建议。望气者提出，长安东北还应新建五帝庙。赵人新垣平以望气之术进见，说东北有五彩神气。皇帝听从建议，营建渭阳五帝庙。新垣平又把周鼎重现、玉英将至等祥瑞与皇帝的礼制事业联系起来，他在朝廷中的影响逐渐扩大。 [[1]](#note-1)

<a id="九月直言进策仍是进身的机会"></a>

<a id="event-3"></a>

2. **九月，直言进策仍是进身的机会。** 诸侯王、公卿、郡守奉命举荐贤良、能直言极谏者，皇帝亲自策问。 晁错名列高第，升中大夫，又提出削弱诸侯及更改法令的多项建议。文帝赏识他的才干，但并没有把建议尽数接受。 [[2]](#note-3)

<a id="sj017-successions"></a>

<a id="event-5"></a>

3. **齐王刘则、河间王刘福去世，两个王国撤除。** 河间王刘福接替父亲刘辟强后去世。齐王刘则也在本年去世。两位国王均无子，齐国、河间国被撤除。 [[3]](#note-5)

<a id="sj017-audience"></a>

<a id="event-6"></a>

4. **燕王刘嘉、梁王刘武本年入朝。** 梁王已经由淮阳迁来，原淮阳王号不能继续用于本次朝见；燕王也不是早年的刘泽。 [[4]](#note-6)

<a id="sj010-165"></a>
<a id="1祥瑞礼仪与改制草案分开"></a>
#### 1｜祥瑞、礼仪与改制草案分开

[卷010 P030—P031](../../拆分史书/史记/卷010.md#p030) · [《通鉴》卷十五](../../拆分史书/资治通鉴/卷015.md#text)。正文写收到黄龙报告，不断言现代已经证实这种动物出现；公孙臣被任命、举行雍祭、新庙营造则是文本所记的行动。土德草议不直接等于全国已换历；文帝后来的封禅意向也未实现。

晁错策问与新垣平进见是不同渠道，不把方术、经术与官员选拔混成一件事。齐、河间两王的死亡没有记病因，不能因与祥瑞相邻而附会为祭祀灵验或政治谋杀。

<a id="2无后除国来朝与分国先导"></a>
#### 2｜无后除国、来朝与分国先导

[卷017前165年](../../拆分史书/史记/卷017.md#y0165)齐则、河间福终局归本页，燕梁来朝分别保留；刘福父系见[楚元王世家](../../拆分史书/史记/卷050.md#part-1-text)的河间附叙。衡山、庐江、城阳、济北、济南、淄川、胶西、胶东各格初置／复置，以及刘喜徙回城阳，是下一阶段分国的先导，正式诸王安排沿[前164年五月](bce-0164.md#sj010-164-kings)，不能照格位提前又封九王。淄川都剧、胶西都宛、胶东都即墨的原表地理信息随次年王国一并说明。

<a id="卷026黄龙报告与张苍自黜"></a>
### 卷026｜黄龙报告与张苍自黜

[《历书》P010](../../拆分史书/史记/卷026.md#p010)的黄龙见成纪、改历议论接本页原事，仍以报告、任博士和草拟制度为可叙行动，不把瑞异当成现代独立确证。篇中“张苍自黜”，与[《张丞相列传》](../../拆分史书/史记/卷096.md#part-1-text)“由此自绌，谢病称老”相接；列传随后另写所任中候犯法而被责，才说病免。此处不能简化为本年即正式罢相，实际免相仍见[前162年](bce-0162.md#sj026-note)。

新垣平进见、作渭阳庙按《孝文本纪》《汉书·文帝纪》及《通鉴》仍在本页；《封禅书》接语“其明年”与该主线有出入，不能凭一句接语把全部事项顺延。见[文帝归年与异文](../../拆分史书/史记/卷026.md#kao-52578ba700-90d341e56)。

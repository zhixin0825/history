<a id="冬季边境战火逼近关中"></a>
### 冬季，边境战火逼近关中

<a id="event-1"></a>

1. **匈奴大举进入朝那、萧关一线，北地都尉卬战死，大量人口、牲畜被掳。** 骑兵一度到彭阳、回中，焚烧回中宫，烽火传到雍、甘泉。过去恢复和亲，没有阻止这次深入进攻。 [[1]](#note-1)

<a id="event-2"></a>

2. **汉在陇西、北地、上郡分路布防，又在渭北集中车骑。** 周舍、张武负责近畿部队，文帝亲自慰劳、整顿军纪，赏赐将士。他想自己率兵迎击，群臣反对也不听，最后薄太后坚决阻拦，他才放弃。 [[2]](#note-2)

<a id="event-3"></a>

3. **张相如等奉命出战，匈奴停留一月有余后退去。** 汉军追出边塞，并没有取得足以改变全局的大规模斩获。危机暂时过去，不能把敌军撤离写成汉军已经歼灭来犯主力。 [[3]](#note-3)

<a id="冯唐借旧将故事指出朝廷用将的问题"></a>
### 冯唐借旧将故事，指出朝廷用将的问题

<a id="event-4"></a>

4. **文帝与年老的郎官冯唐谈到廉颇、李牧，冯唐却说，皇帝即使得到这样的将领，也未必会用。** 他以云中守魏尚为例：魏尚把军市收入和私钱用来犒劳士卒，使边地有备，却因上报战功的首级数差六而被削爵罚作。若事事以文书差错重罚，前线将领便难以放手负责。 [[4]](#note-4)

<a id="event-5"></a>

5. **文帝接受批评，命冯唐持节赦魏尚，恢复他为云中守。** 这次处置显示，皇帝的宽容不只是笼统赞语，也有在具体军政案件中改变决定的例子。 [[5]](#note-5)

<a id="春季祠官不应只把福归给皇帝"></a>
### 春季，祠官不应只把福归给皇帝

<a id="event-6"></a>

6. **文帝增加祭坛礼物，却要求祠官不要只为自己祈福。** 他认为百姓若不能一同受益，皇帝独享祭祀所求的好处，反而加重自身的失德。礼仪规模增加与不专求个人福祉，在这道诏令中同时存在。[卷010 P029](../../sources/摘录/史记-卷010-孝文本纪.md#p029)。 [[6]](#note-6)

<a id="event-7"></a>

7. **公孙臣提出汉应当土德，改正朔、服色；张苍则坚持水德。** 公孙臣以黄龙出现作为土德将兴的征兆，丞相张苍认为不合现行十月岁首、尚黑的制度，请求罢去其议。明年成纪的黄龙报告，将使这场争论重新展开。[卷010 P030](../../sources/摘录/史记-卷010-孝文本纪.md#p030)。 [[7]](#note-7)

<a id="sj017-hejian"></a>
<a id="河间王刘辟强去世燕王入朝"></a>
### 河间王刘辟强去世，燕王入朝

<a id="event-8"></a>

8. **刘辟强去世，儿子刘福继承河间。** 刘辟强是赵幽王刘友之子，文帝初年从赵地分出河间给他；这次是王位在父子之间承接，不是河间立即废国。刘福元年与无后终局在下一年。 [[8]](#note-8)

<a id="sj017-audience"></a>

<a id="event-9"></a>

9. **燕王刘嘉本年来朝。** 未记月日，不将此行推定为燕国已经出兵帮助关中防御，或参加公孙臣的改制讨论。 [[9]](#note-9)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>
### 功臣侯家的承袭与兴废

<a id="event-10"></a>

10. **曲城侯捷恢复爵位。** 他曾因罪失侯，现在重新获得封邑，恢复的仍是同一个人的爵位，不是又有一名同名开国功臣。 [R038](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r038) [[10]](#note-10)

<a id="event-11"></a>

11. **禾成侯渐去世，无后，封国终止。** 这支原本出自公孙耳的军功，至此没有可接续的嗣侯。 [R108](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r108) [[11]](#note-11)

<a id="event-12"></a>

12. **期思侯贲赫也去世，无后而除国。** 他早年是英布的属官，因向汉廷告发英布而受封；死后的奉祀继承不能与早年的告发案重复算作新事。 [R131](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r131) [[12]](#note-12)

<a id="sj010-fengtang"></a>
<a id="2具体事例不等于全部制度已放权"></a>
#### 2｜具体事例不等于全部制度已放权

冯唐、魏尚故事据通鉴同年，所引李牧旧事是劝说背景，不把赵国军功全部归本年。皇帝恢复魏尚，不能扩大为全国军队从此一律自行决定赏罚、不受中央约束。河间王刘辟强同年死亡亦见通鉴，下一年刘福死亡与王国撤除另记。

水德、土德是当时解释政权与制度的框架，不是自然规律；黄龙是否实际出现与因报告而任命博士、讨论改制，是两种不同性质的材料。

[卷017前166年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0166)燕来朝、河间十三薨，与[楚元王世家](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7050.md#ref-8174fa6780fc48)附河间王统相接。下一年刘福元年不用于另推本年未知的具体死日；今后的河间献王刘德属于景帝之子一支，不与刘辟强父子合并。

<a id="卷026公孙臣上书的阅读位置与异年"></a>
### 卷026｜公孙臣上书的阅读位置与异年

[《历书》P010](../../sources/摘录/史记-卷026-历书.md#p010)概述文帝时的土德之议，没有独立年号。本页保留公孙臣与张苍辩论的既有位置，接《孝文本纪》十四年段；[《通鉴》十四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7015.md#ref-edb1ba045f5ff6)却以“初”字回叙，不能把它当成上书一定始于本年的确证。

《封禅书》在“朕即位十三年”诏后连写公孙臣上书，又说“后三岁”黄龙见；《汉书·郊祀志》先由十三年下接“明年”，再写公孙臣，复说“明年”黄龙见。诸文层次与相对年数不完全一致。本轮不再另造一条前167年上书；本页是争论的阅读入口，实际初议暂留文帝中期、黄龙报告之前。前165年任博士和前162年免相另在实际年页。见[文帝诸事](../../meta/考证/史记-卷026-纪年与异说.md#文帝)。

# 公元前167年｜缇萦救父推动废肉刑，重笞却带来新的伤害

[← 公元前168年](bce-0168.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前166年 →](bce-0166.md)

**汉文帝前十三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="春夏之间祭祀也要顾及百姓"></a>

<a id="event-1"></a>

1. **二月，皇帝亲耕、皇后亲桑的礼仪进一步制定。** 粮食供宗庙、丝帛供祭服，把王朝祭祀与农业生产的关系公开表现出来。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏季，文帝撤去秘祝。** 遇到灾祥时，这类祝官把过失向下转移；皇帝认为百官有错，应由自己承担，不能把责任推给臣民。撤掉这一做法，不妨碍国家继续举行其他祭祀。 [[2]](#note-2)

<a id="sj010-tiying"></a>
<a id="一个女儿随父赴京请求用自己换父亲改过的机会"></a>

<a id="event-3"></a>

3. **缇萦随父淳于意赴京，向皇帝上书。** 齐太仓令淳于意因案被押送长安，五个女儿不能替他摆脱牢狱。 临行时，他怨没有儿子，紧要关头无人相助。小女儿缇萦却哭着跟去，向皇帝上书。 [[3]](#note-3)

<a id="event-4"></a>

4. **她没有只说父亲不该受罚，而是指出：人死不能复生，身体被残毁也无法复原。** 就算以后愿意改过，也已没有完整生活的机会。她愿没入官府为婢，换取父亲免受刑伤、重新做人的可能。文帝为之动容，五月下诏除肉刑，并要求有替代办法和按年限免役的规则。 [[4]](#note-4)

<a id="不再割鼻斩足并不等于实际处罚都更轻"></a>

<a id="event-5"></a>

5. **不再割鼻斩足，并不等于实际处罚都更轻。** 张苍、冯敬提出替代刑。 黥刑改为髡钳、城旦舂等劳役，劓刑改笞三百，斩左足改笞五百；原当斩右足等情形则改为弃市。服役者另定逐级减等、到期免为庶人的办法，逃亡或再犯者又有例外。皇帝批准了这套安排。 [[5]](#note-5)

<a id="event-6"></a>

6. **残毁身体的刑名减少了，极重的笞击却仍能夺命，有的罪更直接改成死刑。** 这不是诏书希望给人自新的本意就能自动避免的结果。以后的景帝还须继续降低笞数、规范执行；那些是后来的改革，不能算本年已完成。 [[6]](#note-6)

<a id="六月免去田租"></a>

<a id="event-7"></a>

7. **六月，免去田租。** 文帝认为耕作是天下之本，再免田地所出的租税，并赐孤寡布帛絮。 前一年只是减半，现在变为免田租。农户其他赋役并未因为这一项诏令全部消失。 [[7]](#note-7)

<a id="sj017-audience"></a>

<a id="event-8"></a>

8. **楚王刘戊本年来朝。** 这是他在位第八年的活动，后来起兵的结局另在前154年，不从后事倒推这次朝见已经带有反叛计划。 [[8]](#note-8)

<a id="note-6"></a>

### 6. 残毁身体的刑名减少了，极重的笞击却仍能夺命，有的罪更直接改成死刑

[返回正文第6条](#event-6)

**[《漢書》卷023](../../sources/本地分卷/汉书/汉书-卷023.md#L5015)**

> 丞相張蒼、御史大夫馮敬奏言：「肉刑所以禁姦，所由來者久矣。陛下下明詔，憐萬民之一有過被刑者終身不息，及罪人欲改行為善而道亡繇至，於盛德，臣等所不及也。臣謹議請定律曰：諸當完者，完為城旦舂；當黥者，髡鉗為城旦舂；當劓者，笞三百；當斬左止者，笞五百；當斬右止，及殺人先自告，及吏坐受賕枉法，守縣官財物而即盜之，已論命復有笞罪者，皆棄市。罪人獄已決，完為城旦舂，滿三歲為鬼薪白粲。鬼薪白粲一歲，為隸臣妾。隸臣妾一歲，免為庶人。隸臣妾滿二歲，為司寇。司寇一歲，及作如司寇二歲，皆免為庶人。其亡逃及有罪耐以上，不用此令。前令之刑城旦舂歲而非禁錮者，如完為城旦舂歲數以免。臣昧死請。」制曰：「可。」是後，外有輕刑之名，內實殺人。斬右止者又當死。斬左止者笞五百，當劓者笞三百，率多死。

**[《漢書》卷023](../../sources/本地分卷/汉书/汉书-卷023.md#L5016)**

> 景帝元年，下詔曰：「加笞與重罪無異，幸而不死，不可為人。其定律：笞五百曰三百，笞三百曰二百。」猶尚不全。至中六年，又下詔曰：「加笞者，或至死而笞未畢，朕甚憐之。其減笞三百曰二百，笞二百曰一百。」又曰：「笞者，所以教之也，其定箠令。」丞相劉舍、御史大夫衛綰請：「笞者，箠長五尺，其本大一寸，其竹也，末薄半寸，皆平其節。當笞者笞臀。毋得更人，畢一罪乃更人。」自是笞者得全，然酷吏猶以為威。死刑既重，而生刑又輕，民易犯之。

#### 2｜上书、诏令与实施条款

[卷010 P026](../../sources/摘录/史记-卷010-孝文本纪.md#p026) · [《汉书》卷023《刑法志》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7023.md#ref-15e33099c7ab78) · [通鉴卷十五](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7015.md#ref-5f47e4226adb6b)。本纪称淳于公，通鉴明名意；其医术生涯未在这里全部展开。缇萦请求为婢不等于诏后确实被没为婢，不把请求当执行结果，也不编确定出生年龄。

“肉刑”在本次改革有具体对象，不能泛化为所有身体刑、死刑、刑讯全被废。宫刑是否包括在内、后出诏颂“除宫刑”的问题另见[刑制考证](../../meta/考证/史记-卷010-纪年与异说.md#刑制)。

<a id="sj010-167-effect"></a>
<a id="3宽刑之名与重笞的后果"></a>
#### 3｜宽刑之名与重笞的后果

《刑法志》明确指出斩右足者改死，笞三百、五百者多死，评价外有轻刑之名而实际杀人。这里保留这一不同观察面，不只重复颂德；没有以“率多死”计算未经统计的死亡率。后续首次减笞见[前156年](bce-0156.md#sj010-flogging)，进一步减笞与箠令见[前144年](bce-0144.md)。

<a id="4免的是田租"></a>
#### 4｜免的是田租

[卷010 P027](../../sources/摘录/史记-卷010-孝文本纪.md#p027)，月份从汉书、通鉴六月。不能据此声称朝廷放弃全部税收、各地农户再无劳役，亦不能仅凭诏令计算收入增长。

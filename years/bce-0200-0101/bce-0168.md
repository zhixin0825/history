# 公元前168年｜堵黄河决口，放宽关津，入粟换爵与减租并行

**汉文帝前十二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj-029-L2880-01"></a>
<a id="冬十二月黄河在酸枣决口"></a>

<a id="event-1"></a>

1. **冬十二月，黄河在酸枣决口。** 黄河在酸枣决口，水向东冲坏金堤，波及东郡。 东郡大规模征发人员堵口，既要面对水害，也承担抢险工役。 [[1]](#note-1)

<a id="春季宫人与过关旅客的处境有了变化"></a>

<a id="event-2"></a>

2. **二月，惠帝留下的后宫美人获准出宫嫁人；三月，放宽关津的通行限制，不再要求有关通行文书。** 首都与远方之间的人员往来减少了一道束缚。正月还赐诸侯王女封邑，各二千户。 [[2]](#note-2)

<a id="想使农业值得投入先给粮食找销路"></a>

<a id="event-3"></a>

3. **想使农业值得投入，先给粮食找销路。** 晁错向皇帝解释，农民整年耕作、又负担官府和家族事务，遭灾或急征时，可能低价卖粮、借高利贷，甚至卖田与家人。 他建议允许有余粮者向边地输粟，按数量授爵或赎罪，让粮食能换来有吸引力的回报。 [[3]](#note-3)

<a id="event-4"></a>

4. **文帝实行入粟边地授爵，又听取晁错继续充实地方仓储、适时减免田租的建议。** 诏书承认，多年劝农之后，田地没有明显增加开垦，一遇歉收百姓仍挨饿；本年再减田租一半。派使者慰劳三老、孝悌力田和廉吏，同时询问百姓不便之处。 [[4]](#note-4)

<a id="sj017-audience"></a>
<a id="齐赵河间三王入朝"></a>

<a id="event-5"></a>

5. **齐、赵、河间三王入朝。** 刘则、刘遂、刘辟强本年来朝。 刘遂与刘辟强为兄弟，各自王赵、河间；不能把两国来朝合成同一人的两条重复记录。淮南、梁两栏同时开始使用迁王后的新位置，是上年调整的延续。 [[5]](#note-5)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-6"></a>

6. **阳义侯胜去世，无后，侯国被撤销。** 本年终局与文七年承爵相接，不另将受封与死亡合成同一天。 [[6]](#note-6)

#### 2｜补充政务与政策效果的区别

[《汉书》卷004十二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-d24dd71cc14612) · [《通鉴》卷十五十二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7015.md#ref-68cb053efb4733)。这些条目补足本纪未单列的本年，并为[卷010 P027](../../sources/摘录/史记-卷010-孝文本纪.md#p027)下一年免田租提供前情。景帝追颂的通关梁、出美人也有了明确落点，不把追颂本身当作新发命令。

# 公元前168年｜堵黄河决口，放宽关津，入粟换爵与减租并行

[← 公元前169年](bce-0169.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前167年 →](bce-0167.md)

**汉文帝前十二年**

<a id="sj-029-L2880-01"></a>
## 冬十二月，黄河在酸枣决口

**黄河在酸枣决口，水向东冲坏金堤，波及东郡。** 东郡大规模征发人员堵口，既要面对水害，也承担抢险工役。[1](#sj010-river)

## 春季，宫人与过关旅客的处境有了变化

**二月，惠帝留下的后宫美人获准出宫嫁人；三月，放宽关津的通行限制，不再要求有关通行文书。** 首都与远方之间的人员往来减少了一道束缚。正月还赐诸侯王女封邑，各二千户。[2](#sj010-168-policy)

## 想使农业值得投入，先给粮食找销路

**晁错向皇帝解释，农民整年耕作、又负担官府和家族事务，遭灾或急征时，可能低价卖粮、借高利贷，甚至卖田与家人。** 他建议允许有余粮者向边地输粟，按数量授爵或赎罪，让粮食能换来有吸引力的回报。[2](#sj010-168-policy)

**文帝实行入粟边地授爵，又听取晁错继续充实地方仓储、适时减免田租的建议。** 诏书承认，多年劝农之后，田地没有明显增加开垦，一遇歉收百姓仍挨饿；本年再减田租一半。派使者慰劳三老、孝悌力田和廉吏，同时询问百姓不便之处。[2](#sj010-168-policy)

<a id="sj017-audience"></a>
## 齐、赵、河间三王入朝

**刘则、刘遂、刘辟强本年来朝。** 刘遂与刘辟强为兄弟，各自王赵、河间；不能把两国来朝合成同一人的两条重复记录。淮南、梁两栏同时开始使用迁王后的新位置，是上年调整的延续。[3](#sj017-note)

<a id="sj018-wenjing"></a>
## 功臣侯家的承袭与兴废

**阳义侯胜去世，无后，侯国被撤销。** 本年终局与文七年承爵相接，不另将受封与死亡合成同一天。 [R127](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r127)

<a id="sj010-river"></a>
### 1｜原有河渠条目及出处保留

[《史记》卷029《河渠书》旧摘录](../../sources/摘录/史记-条目原文.md#ref-sj-2880) · [《通鉴》卷015原定位](../../sources/摘录/史记-条目原文.md#ref-tj015-176-180)。旧文的归年依据不变：《河渠书》写“汉兴三十九年，孝文时”，《通鉴》系文帝十二年冬十二月。原锚点保留，未把秦汉古历十二月换算为公历同月；不是新增另一场同地决口。

<a id="sj010-168-policy"></a>
### 2｜补充政务与政策效果的区别

[《汉书》卷004十二年](https://zh.wikisource.org/wiki/漢書/卷004) · [《通鉴》卷十五十二年](https://zh.wikisource.org/wiki/資治通鑑/卷015)。这些条目补足本纪未单列的本年，并为[卷010 P027](../../sources/摘录/史记-卷010-孝文本纪.md#p027)下一年免田租提供前情。景帝追颂的通关梁、出美人也有了明确落点，不把追颂本身当作新发命令。

晁错关于农商生活的长篇对比是政策论证，不是全国随机抽样调查；“上从之”证明有实施行动，不能保证边仓已经达到其设想的五年储粮。除关传有具体制度边界，不译成现代所有边境口岸、税费与出入限制全被取消。此次只是减本年田租一半，不提前到全面免除田租。

<a id="sj017-note"></a>
### 3｜来朝与转封计数

[卷017前168年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0168)三王来朝及刘喜淮南元年、刘武梁十一年。迁封实际过程沿[前169年](bce-0169.md#sj017-note)，本行是新栏位接续，不是又发生一轮换国。来朝月份未载，不据此认定三王一起参与酸枣堵河或讨论入粟授爵。

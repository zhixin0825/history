# 公元前168年｜堵黄河决口，放宽关津，入粟换爵与减租并行

**汉文帝前十二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="冬十二月黄河在酸枣决口"></a>

<a id="event-1"></a>

1. **冬十二月，黄河在酸枣决口。** 黄河在酸枣决口，水向东冲坏金堤，波及东郡。 东郡大规模征发人员堵口，既要面对水害，也承担抢险工役。 [[1]](#note-1)

<a id="春季宫人与过关旅客的处境有了变化"></a>

<a id="event-2"></a>

2. **二月，惠帝留下的后宫美人获准出宫嫁人；三月，放宽关津的通行限制，不再要求有关通行文书。** 首都与远方之间的人员往来减少了一道束缚。正月还赐诸侯王女封邑，各二千户。 [[2]](#note-2)

<a id="想使农业值得投入先给粮食找销路"></a>

<a id="event-3"></a>

3. **想使农业值得投入，先给粮食找销路。** 晁错向皇帝解释，农民整年耕作、又负担官府和家族事务，遭灾或急征时，可能低价卖粮、借高利贷，甚至卖田与家人。 他建议允许有余粮者向边地输粟，按数量授爵或赎罪，让粮食能换来有吸引力的回报。 [[3]](#note-3)

<a id="event-4"></a>

4. **文帝实行入粟边地授爵，又听取晁错继续充实地方仓储、适时减免田租的建议。** 诏书承认，多年劝农之后，田地没有明显增加开垦，一遇歉收百姓仍挨饿；本年再减田租一半。派使者慰劳三老、孝悌力田和廉吏，同时询问百姓不便之处。 [[4]](#note-4)

<a id="sj017-audience"></a>
<a id="齐赵河间三王入朝"></a>

<a id="event-5"></a>

5. **齐、赵、河间三王入朝。** 刘则、刘遂、刘辟强本年来朝。 刘遂与刘辟强为兄弟，各自王赵、河间；不能把两国来朝合成同一人的两条重复记录。王表本年列刘喜淮南元年，刘武正式迁梁另见本页第10条。 [[5]](#note-5)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-6"></a>

6. **阳义侯胜去世，无后，侯国被撤销。** 本年终局与文七年承爵相接，不另将受封与死亡合成同一天。 [[6]](#note-6)

### 4. 文帝实行入粟边地授爵，又听取晁错继续充实地方仓储、适时减免田租的建议

[返回正文第4条](#event-4)

<a id="hs024-l5051-e4"></a>

**[《汉书·食货志》P015](../../sources/摘录/汉书-卷024-食货志.md#p015)** · [仓内TXT L5051](../../sources/本地分卷/汉书/汉书-卷024.md#L5051)

<a id="hs024-l5051-e4-2"></a>

**[《汉书·食货志》P015](../../sources/摘录/汉书-卷024-食货志.md#p015)** · [仓内TXT L5051](../../sources/本地分卷/汉书/汉书-卷024.md#L5051)

> 乃下詔賜民十二年租稅之半。

**互校说明** 明言十二年，《文帝纪》编年与此相合。

<a id="hs004-l215-e4"></a>

**[《汉书·文帝纪》P049](../../sources/摘录/汉书-卷004-文帝纪.md#p049)** · [仓内TXT L215](../../sources/本地分卷/汉书/汉书-卷004.md#L215)

> 詔曰：「道民之路，在於務本。朕親率天下農，十年于今，而野不加辟，歲一不登，民有飢色，是從事焉尚寡，而吏未加務也。吾詔書數下，歲勸民種樹，而功未興，是吏奉吾詔不勤，而勸民不明也。且吾農民甚苦，而吏莫之省，將何以勸焉？其賜農民今年租稅之半。」

> 纪年：十二；大事纪：河決東郡金隄。徙淮陽王為梁王。；相位：九；将位：〔空〕；御史大夫位：〔空〕

东郡金堤决口接本页黄河酸枣决口的既有记载，两个地理层次不拆成两场同年无关洪灾。淮阳王刘武迁梁在本表系文十二年，与本篇[第10条](#note-10)采用的年份相同。[前169年](bce-0169.md#note-2)保留《通鉴》及卷017淮阳旧栏连叙的异年材料。张苍“九”仍为相位。

<a id="2补充政务与政策效果的区别"></a>
#### 2｜补充政务与政策效果的区别

[《汉书》卷004十二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-d24dd71cc14612) · [《通鉴》卷十五十二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7015.md#ref-68cb053efb4733)。这些条目补足本纪未单列的本年，并为[卷010 P027](../../sources/摘录/史记-卷010-孝文本纪.md#p027)下一年免田租提供前情。景帝追颂的通关梁、出美人也有了明确落点，不把追颂本身当作新发命令。

晁错关于农商生活的长篇对比是政策论证，不是全国随机抽样调查；“上从之”证明有实施行动，不能保证边仓已经达到其设想的五年储粮。除关传有具体制度边界，不译成现代所有边境口岸、税费与出入限制全被取消。此次只是减本年田租一半，不提前到全面免除田租。

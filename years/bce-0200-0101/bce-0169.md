# 公元前169年｜梁怀王卒，晁错提出让边民定居守边

**汉文帝前十一年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="皇帝再到代地梁国却在同年换王"></a>

<a id="event-1"></a>

1. **文帝出巡代地，梁王刘揖去世。** 冬十一月，刘恒出巡代地，正月返回。六月，梁王刘揖因坠马而死，没有儿子继位。他生前喜好诗书，受到文帝特别宠爱。贾谊建议重新安排文帝亲子掌握的封国，使它们足以牵制东方的大国，而不是徒有王号、地小力弱。 [[1]](#note-1)

<a id="event-2"></a>

2. **城阳王刘喜迁为淮南王，朝廷商议加强梁国。** 文帝在这一时期将城阳王刘喜迁为淮南王。贾谊建议扩大梁国，以牵制东方诸侯。淮阳王刘武后来[迁封梁国](bce-0168.md#event-10)。 [[2]](#note-2)

<a id="sj017-audience"></a>

<a id="event-3"></a>

3. **刘揖、刘武、代王刘参本年又分别见于来朝记录。** 刘揖的来朝与死亡不是同日事实；刘武以淮阳王身份入朝，次年正式徙梁。 [[3]](#note-3)

<a id="边境告急晁错不赞成只靠远方轮戍"></a>

<a id="event-4"></a>

<a id="event-5"></a>

4. **晁错论边地募民久居与耕战之策。** 边境告急，晁错不赞成只靠远方轮戍。匈奴侵扰狄道，太子家令晁错上言兵事。他强调地形、士卒训练和器械必须互相适合；远方军队赶来时敌人往往已经退去，留军耗费很大，撤军又给对方可乘之机。晁错建议招募愿意长期定居塞下的家庭，先备住屋、田器、衣粮，再让他们耕作和守卫。还要择好官吏，组织邻里互助与训练，使居民既有自己的家业，也有共同防守的动力。文帝同意招民徙边，晁错又继续强调选址、水源、婚丧和救病等安居条件。 [[4]](#note-4)

<a id="1补缺中的王国和边防主线"></a>
#### 1｜补缺中的王国和边防主线

[《通鉴》卷十五十一年](../../拆分史书/资治通鉴/卷015.md#text) · [《汉书》卷004](../../拆分史书/汉书/卷004.md#part-1-text)。长篇建言按要旨叙述，招募获准与每一项理想安排已在所有边城落实不是一回事；不说轮戍制本年即被全国取消。

刘喜先为城阳王、本年迁淮南，前164又回城阳；与刘长的三个儿子分王，是一连串封国调整。贾谊对大诸侯的风险判断不是对未来七国之乱的精确预言；本人“后岁余”死亡的跨期文字不借本段位置直接算作本年死。

<a id="sj017-note"></a>
<a id="2卷017的迁封改属与来朝"></a>
#### 2｜卷017的迁封、改属与来朝

[卷017前169年](../../拆分史书/史记/卷017.md#y0169)城阳喜迁淮南、原城阳郡属齐，梁胜来朝无后薨，淮阳武来朝迁梁、淮阳为郡，代参来朝。胜与揖沿[前178年异名说明](bce-0178.md#sj017-note)识别为同一人；三次朝见未给月份，不排成确定的临终共同宴会。原城阳回归齐的阶段性归属不等于永不复国，前164年刘喜还城阳另记。

下一行[前168年](../../拆分史书/史记/卷017.md#y0168)列刘喜淮南元年，刘武梁十一年并明言“徙梁年”。前者从淮南王年重起，后者沿刘武自初封的总年数；依卷058及《汉书》，将刘武正式徙梁置于[前168年](bce-0168.md#note-10)。

# 公元前169年｜梁怀王卒，晁错提出让边民定居守边

[← 公元前170年](bce-0170.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前168年 →](bce-0168.md)

**汉文帝前十一年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="皇帝再到代地梁国却在同年换王"></a>

<a id="event-1"></a>

1. **文帝出巡代地，梁王刘揖去世。** 冬十一月，刘恒出巡代地，正月返回。六月，梁王刘揖因坠马而死，没有儿子继位。他生前喜好诗书，受到文帝特别宠爱。贾谊建议重新安排文帝亲子掌握的封国，使它们足以牵制东方的大国，而不是徒有王号、地小力弱。 [[1]](#note-1)

<a id="event-2"></a>

2. **城阳王刘喜迁为淮南王，朝廷商议加强梁国。** 贾谊建议扩大梁国以牵制东方诸侯。《通鉴》把刘武迁梁并叙于本年，正式徙梁依本传与《汉书》系[次年](bce-0168.md#event-10)。刘喜徙淮南暂从《史记》王表城阳旧栏及《通鉴》；《汉书·高五王传》系次年。 [[2]](#note-2)

<a id="sj017-audience"></a>

<a id="event-3"></a>

3. **刘揖、刘武、代王刘参本年又分别见于来朝记录。** 刘揖的来朝与死亡不是同日事实；刘武以淮阳王身份入朝，次年正式徙梁。 [[3]](#note-3)

<a id="边境告急晁错不赞成只靠远方轮戍"></a>

<a id="event-4"></a>

4. **边境告急，晁错不赞成只靠远方轮戍。** 匈奴侵扰狄道，太子家令晁错上言兵事。 他强调地形、士卒训练和器械必须互相适合；远方军队赶来时敌人往往已经退去，留军耗费很大，撤军又给对方可乘之机。 [[4]](#note-4)

<a id="event-5"></a>

5. **晁错建议招募愿意长期定居塞下的家庭，先备住屋、田器、衣粮，再让他们耕作和守卫。** 还要择好官吏，组织邻里互助与训练，使居民既有自己的家业，也有共同防守的动力。文帝同意招民徙边，晁错又继续强调选址、水源、婚丧和救病等安居条件。 [[5]](#note-5)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-6"></a>

6. **周勃在本年去世，谥武侯。** 他曾取得北军、参与迎立文帝，又经历退相和下狱，获赦后以绛侯身份终老。儿子胜之接家爵，侯表从下一年起计元年。 [[6]](#note-6)

### 5. 晁错建议招募愿意长期定居塞下的家庭，先备住屋、田器、衣粮，再让他们耕作和守卫

[返回正文第5条](#event-5)

**[《資治通鑑》卷015](../../sources/本地分卷/资治通鉴/资治通鉴-卷015.md#L125)**

> 選常居者家室田作且以備之以便為之髙城深塹(因/山)
> (川地形之便/而為之城塹)要害之處通川之道調立城邑毋下千家
> (師古曰調謂筭度之也總計城邑/之中令有千家以上也調徒釣翻)先為室屋具田器乃
> 募民免罪拜爵(謂有罪者免其罪無/罪者拜爵以勸其徙)復其家(謂民之欲/往者復除)
> (其家征役/復方目翻)予冬夏衣稟食能自給而止(師古曰初徙之/時縣官且稟給)
> (其衣食於後能自供贍/乃止也予讀曰與下同)塞下之民禄利不厚不可使久
> 居危難之地(難乃/旦翻)胡人入驅而能止其所驅者以其半
> 予之(孟康曰謂胡入為寇驅收中國能奪得之者以半/予之師古曰孟説非也言胡人入為寇驅畧漢人)
> (及畜産也人能止得其所/驅者令其本主以半賞之)縣官為贖(張晏曰得漢人官/為贖也師古曰張)

[《通鉴》卷十五十一年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7015.md#ref-fac261f227cc40) · [《汉书》卷004](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-13a577dbedb950)。长篇建言按要旨叙述，招募获准与每一项理想安排已在所有边城落实不是一回事；不说轮戍制本年即被全国取消。

#### 2｜卷017的迁封、改属与来朝

[卷017前169年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0169)城阳喜迁淮南、原城阳郡属齐，梁胜来朝无后薨，淮阳武来朝迁梁、淮阳为郡，代参来朝。胜与揖沿[前178年异名说明](bce-0178.md#sj017-note)识别为同一人；三次朝见未给月份，不排成确定的临终共同宴会。原城阳回归齐的阶段性归属不等于永不复国，前164年刘喜还城阳另记。

# 公元前171年｜春季大旱，城阳与淮阳两王入朝

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **春季发生大旱。** 已读年条没有进一步给出受灾州郡、饥民数字或特定救济诏令，因此本页只保留确有记载的灾情，不把别年减租、开仓的措施移来填空。 [[1]](#note-1)

<a id="sj017-audience"></a>

<a id="event-2"></a>

2. **城阳王刘喜、淮阳王刘武本年来朝。** 两个国名相近而世系不同：刘喜是刘章之子、刘肥之孙；刘武是文帝之子，后来才迁王梁。不能把城阳、淮阳都写成刘武的封地。 [[2]](#note-2)

<a id="功臣侯家的承袭与兴废"></a>

<a id="sj018-succession"></a>

<a id="event-3"></a>

3. **侯爵继续在各家传承。** 以下记录本年开始的侯年；继承家爵不等于同时承接父辈的中央官职。 [[3]](#note-3)

   | 侯籍一支 | 本年变化 |
   |---|---|
   | 汝陰 | 夏侯灶接汝阴侯，承夏侯婴家爵。 |
   | 蓼 | 臧接蓼侯，续孔聚一支。 |
   | 新陽 | 它接新阳侯，续义一代。 |
   | 南安 | 戎接南安侯，续宣虎一支。 |
   | 斥丘 | 晁接斥丘侯，续唐厉一支。 |
   | 平州 | 马童接平州侯，续它人一代；不是中水侯吕马童。 |
   | 博陽（周聚） | 鸱接博阳侯，续周聚一支；不是陈濞一行的后代。 |

   [本段原文、异年及说明](#sj018-note)。

## 归年与考证

<a id="sj022-note"></a>
<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[本年原表R036](../../拆分史书/史记/卷022.md#r036) · [《汉书·百官公卿表》](../../拆分史书/汉书/卷019.md#part-3-ws019-bce-0171)。

> 纪年：九；大事纪：溫室鐘自鳴。以芷陽鄉為霸陵。；相位：六；将位：〔空〕；御史大夫位：御史大夫敬。

“温室钟自鸣”按传世记事保存为异常声响报告，不把它的自然成因或政治预兆写成已证。芷阳乡为霸陵是地名安排，文帝尚在世，不能写成本年葬霸陵。御史大夫敬即冯敬，起任采用[前173年汉表](bce-0173.md#sj022-note)，本年只留史表异年。 参见[汪越《读史记十表》卷十](../../拆分史书/读史记十表/异本/讀史記十表-卷十.md)的逐项校读；所用古代考证与现今已经解决全部异说不是一回事。

#### 1｜文字简短，不等于可以补造细节

[《汉书》卷004九年](../../拆分史书/汉书/卷004.md#part-1-text)与[《通鉴》卷十四九年](../../拆分史书/资治通鉴/卷014.md#text)均有春大旱。《孝文本纪》没有单列这一年，按项目编年底本补入；未把“未写救济”解释为朝廷一定没有救济，也不据此断言当年全国毫无其他政事。

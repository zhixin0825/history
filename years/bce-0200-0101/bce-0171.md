# 公元前171年｜春季大旱，城阳与淮阳两王入朝

**汉文帝前九年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **春季发生大旱。** 已读年条没有进一步给出受灾州郡、饥民数字或特定救济诏令，因此本页只保留确有记载的灾情，不把别年减租、开仓的措施移来填空。 [[1]](#note-1)

<a id="sj017-audience"></a>

<a id="event-2"></a>

2. **城阳王刘喜、淮阳王刘武本年来朝。** 两个国名相近而世系不同：刘喜是刘章之子、刘肥之孙；刘武是文帝之子，后来才迁王梁。不能把城阳、淮阳都写成刘武的封地。 [[2]](#note-2)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>

<a id="sj018-succession"></a>

<a id="event-3"></a>

3. **侯爵继续在各家传承。** 以下记录本年开始的侯年；继承家爵不等于同时承接父辈的中央官职。 [[3]](#note-3)

   | 侯籍一支 | 本年变化 |
   |---|---|
   | 汝陰 | 夏侯灶接汝阴侯，承夏侯婴家爵。 |
   | 蓼 | 臧接蓼侯，续孔聚一支。 |
   | 新陽 | 它接新阳侯，续义一代。 |
   | 南安 | 戎接南安侯，续宣虎一支。 |
   | 斥丘 | 晁接斥丘侯，续唐厉一支。 |
   | 平州 | 马童接平州侯，续它人一代；不是中水侯吕马童。 |
   | 博陽（周聚） | 鸱接博阳侯，续周聚一支；不是陈濞一行的后代。 |

   [本段原文、异年及说明](#sj018-note)。

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-4"></a>

4. **芷阳乡改称霸陵。** 文帝仍在世，名称的安排先于后来实际安葬。宫中另有温室的钟自行鸣响的报告，留下的是当时的异常声响记事。 [原格与说明](#sj022-note)。 [[4]](#note-4)

## 归年与考证

<a id="sj022-note"></a>
<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[本年原表R036](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r036) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0171)。

> 纪年：九；大事纪：溫室鐘自鳴。以芷陽鄉為霸陵。；相位：六；将位：〔空〕；御史大夫位：御史大夫敬。

“温室钟自鸣”按传世记事保存为异常声响报告，不把它的自然成因或政治预兆写成已证。芷阳乡为霸陵是地名安排，文帝尚在世，不能写成本年葬霸陵。御史大夫敬即冯敬，起任采用[前173年汉表](bce-0173.md#sj022-note)，本年只留史表异年。 参见[汪越《读史记十表》卷十](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%AE%80%E5%8F%B2%E8%A8%98%E5%8D%81%E8%A1%A8-%E5%8D%B7%E5%8D%81.md#ref-0331f092ea2c89)的逐项校读；所用古代考证与现今已经解决全部异说不是一回事。

#### 1｜文字简短，不等于可以补造细节

[《汉书》卷004九年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-f259fbe74d3c96)与[《通鉴》卷十四九年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7014.md#ref-295d86bdb724d4)均有春大旱。《孝文本纪》没有单列这一年，按项目编年底本补入；未把“未写救济”解释为朝廷一定没有救济，也不据此断言当年全国毫无其他政事。

# 公元前172年｜刘长四子封侯，贾谊担心旧怨变成新患

[← 公元前173年](bce-0173.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前171年 →](bce-0171.md)

**汉文帝前八年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="夏季朝廷给淮南王的儿子以封爵"></a>

<a id="event-1"></a>

<a id="event-2"></a>

1. **文帝封刘长诸子，贾谊劝止扩大其权力。** 夏季，朝廷给淮南王的儿子以封爵。刘长的四个儿子被封为列侯。父亲两年前被废、死在迁徙途中，孩子们现在重新得到爵邑。这个阶段只是封侯，还不是后来恢复淮南、衡山、庐江三个王国。贾谊反对继续给他们扩大势力。他认为皇帝如此尊奉罪王之子，反会使天下疑心前案处分不当；孩子长大也可能怀念父仇。贾谊借历史上的复仇故事说明风险，刘恒没有采纳其阻止封赏的意见。 [[1]](#note-1)

<a id="sj017-audience"></a>
<a id="齐燕河间三王入朝"></a>

<a id="event-3"></a>

2. **齐王刘则、燕王刘嘉、河间王刘辟强本年来朝。** 三人分别继承或分得高祖后裔的封国。河间与赵同出刘友一支，并不是同一个王国有两位同时在位的王。 [[2]](#note-3)

3. **太仆、汝阴侯夏侯婴去世。** 汝阴侯夏侯婴去世。他从沛县时代为刘邦驾车，曾在彭城败后保全刘盈、鲁元，文帝入京时又参与宫廷交接。爵位留给后人，太仆的中央职务却不随家爵自动传下。太仆婴去世。参见本年的官职变动原句。 [[3]](#note-4)

<a id="1四子封侯与三子封王分开"></a>
#### 1｜四子封侯与三子封王分开

[《汉书》卷004八年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-6716f20c87973f) · [《通鉴》卷十四八年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7014.md#ref-03fdf758796d9b)。这项补记连接[卷010 P024](../../sources/摘录/史记-卷010-孝文本纪.md#p024)六年废王与十六年立王；到前164年是在世三子分王，不能把人数不同写成文本自相矛盾，也不从本条推定后来每一个人的死日。

贾谊的意见是对未来的预测，不证明四子本年已经合谋报仇。同年东方长星另有记载，作为天象保存，不与封爵强建因果。

# 公元前173年｜限制擅捕贵戚，淮南王之死仍被人传唱

[← 公元前174年](bce-0174.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前172年 →](bce-0172.md)

**汉文帝前七年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="十月不得擅自征捕特定身份的人"></a>

<a id="event-1"></a>

1. **十月，不得擅自征捕特定身份的人。** 朝廷限制官吏自行征捕列侯太夫人、夫人、诸侯王子和二千石官员。 这些人并未被宣布永不受审，而是处置他们须受更高层级的控制。四月又行大赦。 [[1]](#note-1)

<a id="一首歌使皇帝想起死去的弟弟"></a>

<a id="event-2"></a>

2. **一首歌，使皇帝想起死去的弟弟。** 民间传唱兄弟不相容的歌，拿一尺布、一斗粟作比，讥刺文帝与刘长。 刘恒听了很不舒服。上一年免死废王、押送途中死亡的结果，并不因为朝廷宣布处分有据就不再受到议论。 [[2]](#note-2)

<a id="event-3"></a>

3. **六月，未央宫东阙的罘罳发生火灾。** 现有年条没有给出死伤数字，不能把它说成一次烧毁整座宫殿的大火。 [[3]](#note-3)

<a id="sj017-audience"></a>
<a id="赵梁淮阳代四王入朝"></a>

<a id="event-4"></a>

4. **赵、梁、淮阳、代四王入朝。** 刘遂、刘揖、刘武、刘参分别来到朝廷。 刘遂是已故赵王刘友之子，其余三人是文帝的儿子。刘武此时王淮阳、刘参王代，不能沿初封名号把他们的位置交换。 [[4]](#note-4)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-5"></a>

5. **鄢陵侯庆去世，无人继承侯爵，封国撤销。** 朱濞的军功曾使封爵传给庆，到这一代才中断，不能写成朝廷因罪诛灭全家。 [[5]](#note-5)

   | 穀陵 | 熊接谷陵侯，续冯溪一支；汉表国名谷阳。 |

10. **四月丙子，朝廷开始设置南陵。** 这里后来是文帝之母薄太后的葬地，文帝本人的陵墓则为霸陵；陵地与陵邑的经营先后，另有不同记载。 [[10]](#note-10)

<a id="event-11"></a>

11. **冯敬从典客升任御史大夫。** 他后来还会与张苍共同提出肉刑的替代办法，任职的前后次序因此可以相互核读。 [原格与说明](#sj022-note)。 [[11]](#note-11)

本格四月丙子“初置南陵”与《汉书·地理志》的文帝七年相合，但《孝景本纪》二年又有“置南陵”即[前155年](bce-0155.md)。南陵属薄太后葬地，不能与文帝霸陵混作一墓。四库本考证已举两处差异；可能涉及陵地经营与置县层次，现有材料不把这种解释定为已证。本表把冯敬列在[前171年](bce-0171.md#sj022-note)，汉表却在本年由典客迁御史，且其后申屠嘉前164年接任，采用汉表连贯线；不是冯敬在两年分别第一次担任御史。 参见[汪越《读史记十表》卷十](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%AE%80%E5%8F%B2%E8%A8%98%E5%8D%81%E8%A1%A8-%E5%8D%B7%E5%8D%81.md#ref-7326110f74d690)的逐项校读；所用古代考证与现今已经解决全部异说不是一回事。

[《汉书》卷004七年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-7dbb52d8f6dca2) · [《通鉴》卷十四七年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7014.md#ref-fcf89e6648ab33)。与[卷010 P024](../../sources/摘录/史记-卷010-孝文本纪.md#p024)的淮南案接读。限制擅捕不是人人同样适用的新程序，不能用它概括为普遍的人身保护；歌谣是文本所载社会批评，不代表全部民众意见都一致。罘罳为宫门相关设施，其具体形制不在此强作复原。

# 公元前173年｜限制擅捕贵戚，淮南王之死仍被人传唱

[← 公元前174年](bce-0174.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前172年 →](bce-0172.md)

**汉文帝前七年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="十月不得擅自征捕特定身份的人"></a>

<a id="event-1"></a>

1. **十月，不得擅自征捕特定身份的人。** 朝廷限制官吏自行征捕列侯太夫人、夫人、诸侯王子和二千石官员。 这些人并未被宣布永不受审，而是处置他们须受更高层级的控制。四月又行大赦。 [[1]](#note-1)

<a id="一首歌使皇帝想起死去的弟弟"></a>

<a id="event-2"></a>

2. **一首歌，使皇帝想起死去的弟弟。** 民间传唱兄弟不相容的歌，拿一尺布、一斗粟作比，讥刺文帝与刘长。 刘恒听了很不舒服。上一年免死废王、押送途中死亡的结果，并不因为朝廷宣布处分有据就不再受到议论。 [[2]](#note-2)

<a id="event-3"></a>

3. **六月，未央宫东阙的罘罳发生火灾。** 现有年条没有给出死伤数字，不能把它说成一次烧毁整座宫殿的大火。 [[3]](#note-3)

<a id="sj017-audience"></a>
<a id="赵梁淮阳代四王入朝"></a>

<a id="event-4"></a>

4. **赵、梁、淮阳、代四王入朝。** 刘遂、刘揖、刘武、刘参分别来到朝廷。 刘遂是已故赵王刘友之子，其余三人是文帝的儿子。刘武此时王淮阳、刘参王代，不能沿初封名号把他们的位置交换。 [[4]](#note-4)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-5"></a>

5. **鄢陵侯庆去世，无人继承侯爵，封国撤销。** 朱濞的军功曾使封爵传给庆，到这一代才中断，不能写成朝廷因罪诛灭全家。 [[5]](#note-5)

<a id="sj018-succession"></a>

<a id="event-6"></a>

   | 穀陵 | 熊接谷陵侯，续冯溪一支；汉表国名谷阳。 |

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-10"></a>

10. **四月丙子，朝廷开始设置南陵。** 这里后来是文帝之母薄太后的葬地，文帝本人的陵墓则为霸陵；陵地与陵邑的经营先后，另有不同记载。 [[10]](#note-10)

<a id="event-11"></a>

<a id="hs-event-21"></a>

11. **冯敬任御史大夫，靓任典客。** 冯敬从典客升任御史大夫。他后来还会与张苍共同提出肉刑的替代办法，任职的前后次序因此可以相互核读。[原格与说明](#sj022-note)。冯敬任御史大夫，表列典客靓。参见本年的官职变动原句。 [[11]](#note-11)

<a id="sj022-note"></a>
<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[本年原表R034](../../拆分史书/史记/卷022.md#r034) · [《汉书·百官公卿表》](../../拆分史书/汉书/卷019.md#part-3-ws019-bce-0173)。 另核[四库本卷022考证](../../拆分史书/史记/异本/史記集解%20%28司馬遷,%20四庫全書本%29-卷022.md#ref-9fcff229aa774d)。

> 纪年：七；大事纪：四月丙子，初置南陵。；相位：四；将位：〔空〕；御史大夫位：〔空〕

本格四月丙子“初置南陵”与《汉书·地理志》的文帝七年相合，但《孝景本纪》二年又有“置南陵”即[前155年](bce-0155.md)。南陵属薄太后葬地，不能与文帝霸陵混作一墓。四库本考证已举两处差异；可能涉及陵地经营与置县层次，现有材料不把这种解释定为已证。本表把冯敬列在[前171年](bce-0171.md#sj022-note)，汉表却在本年由典客迁御史，且其后申屠嘉前164年接任，采用汉表连贯线；不是冯敬在两年分别第一次担任御史。 参见[汪越《读史记十表》卷十](../../拆分史书/读史记十表/异本/讀史記十表-卷十.md)的逐项校读；所用古代考证与现今已经解决全部异说不是一回事。

#### 卷019｜本年侯籍与异说

<a id="sj019-r050-e01-n"></a>
**波陵｜[R050原格](../../拆分史书/史记/卷019.md#r050)：** 史表三月甲寅，[《汉书·高惠高后文功臣表》](../../拆分史书/汉书/卷016.md#part-1-text)国名沶陵、三月丙寅，保留月日异文。史表初封至文十二年死亡的跨度为5年；汉表“十二年薨”的计数解释另见[前168年注](bce-0168.md#sj019-r050-e02-n)。未详军功家世不补。

<a id="sj019-r051-e01-n"></a>
**南𨜓｜[R051原格](../../拆分史书/史记/卷019.md#r051)：** 本格未给姓氏，不把封号当姓名；南𨜓在汉表另有字形。后来“坐后父故”被夺一等、降关内侯，只知在文帝时而无确年，不放到授爵同日。该短句的亲缘指向也不足以另写一段确定宫廷婚姻。

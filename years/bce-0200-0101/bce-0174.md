# 公元前174年｜刘长被废徙，死于途中，汉匈重谈和亲

[← 公元前175年](bce-0175.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前173年 →](bce-0173.md)

**汉文帝前六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="淮南王的特权和越界终于变成一场大案"></a>

<a id="event-1"></a>

1. **淮南王的特权和越界，终于变成一场大案。** 刘长在封国内自行发令、排斥汉廷所置官员，又采用近似天子的仪制。 薄昭奉命写信规劝没有奏效。后来有人揭发他与柴武之子奇等谋划起兵，并向闽越、匈奴求援，朝廷召他到长安审处。 [[1]](#note-1)

<a id="event-2"></a>

2. **大臣主张弃市，刘恒免弟弟死罪，却废其王位，迁往蜀地。** 袁盎提醒，过去纵容很久，突然如此打击，性情刚烈的刘长可能死在路上。刘恒说只是要暂时使他受苦，随后还会恢复待遇。 [[2]](#note-2)

<a id="event-3"></a>

3. **刘长终究没有到达安置地点。** 押送车辆到了雍，打开时发现他已死。皇帝悲痛，追究沿途没有查看、供食和侍奉的人员，按列侯礼安葬，置守冢户。免死的诏令，并没有使被废的王活着度过迁徙。 [[3]](#note-3)

<a id="汉与匈奴各自责备边臣仍恢复交涉"></a>

<a id="event-4"></a>

4. **汉与匈奴各自责备边臣，仍恢复交涉。** 冒顿来书愿意放下旧争端、恢复兄弟之约，也夸示自己在西方的战果。 汉方回复，右贤王的旧事已在赦前，不必再深究，但要求匈奴约束属下。书信往来暂时缓和边境，不表示双方已不再争夺边地。 [[4]](#note-4)

<a id="event-5"></a>

5. **此后冒顿去世，稽粥继为老上单于。** 汉送宗室女子和亲，中行说被强派随行，到匈奴后投向单于，成为其亲信。反秦战争时已经出现的旧一代单于退场，汉朝面对新的对手。 [[5]](#note-5)

<a id="sj017-chu"></a>
<a id="楚国进入刘戊元年"></a>

<a id="event-6"></a>

6. **刘戊开始记楚王元年，接续上一年去世的刘郢客。** 楚王统与淮南的废国是两条不同线索；楚国没有因为同年淮南案便被一并撤销。 [[6]](#note-6)

### 3. 刘长终究没有到达安置地点

[返回正文第3条](#event-3)

<a id="sj101-p004"></a>

**[《史记·袁盎晁错列传》P004](../../sources/摘录/史记-卷101-袁盎晁错列传.md#p004)** · [三家注](../../sources/史记三家注/卷101.md#p4)

> 淮南王至雍，病死，聞，上輟食，哭甚哀。盎入，頓首請罪。上曰：「以不用公言至此。」盎曰：「上自寬，此徃事，豈可悔哉！且陛下有高世之行者三，此不足以毀名。」上曰：「吾高世行三者何事？」盎曰：「陛下居代時，太后嘗病，三年，陛下不交睫，不解衣，湯藥非陛下口所嘗弗進。夫曾參以布衣猶難之，今陛下親以王者脩之，過曾參孝遠矣。夫諸呂用事，大臣專制，然陛下從代乘六乘傳馳不測之淵，雖賁育之勇不及陛下。陛下至代邸，西向讓天子位者再，南面讓天子位者三。夫許由一讓，而陛下五以天下讓，過許由四矣。且陛下遷淮南王，欲以苦其志，使改過，有司衞不謹，故病死。」於是上乃解，曰：「將奈何？」盎曰：「淮南王有三子，唯在陛下耳。」

**本卷归年说明：** 本傳記袁盎進慰。劉長死於遷徙途中，是否直接餓死按《淮南衡山列傳》互讀，封其子為王另在前164年。

<a id="sj010-chang"></a>
<a id="1案情死法与后面的十六年"></a>
#### 1｜案情、死法与后面的“十六年”

[卷010 P024](../../sources/摘录/史记-卷010-孝文本纪.md#p024) · [《汉书》卷004六年十一月](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-89aa1a7f0304d3) · [《通鉴》卷十四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7014.md#ref-1c7e62bfade896)。有司关于谋反、交结外援的控词与实际废徙分别呈现；本纪作行病死，通鉴详写愤恚不食死，两者不硬合为唯一现代死因。严道、邛邮／邛都的地名断句也不凭一句话确定现代押送终点。

本纪接“后十六年”追尊及立三子为王，是后来前元十六年、[前164年](bce-0164.md)，不是从前174再推十六年到前158。此前还另有[前172年封四子侯](bce-0172.md)，三次安排不能合成同一天。

#### 2｜边事补充的范围

通鉴将复约、冒顿死亡及老上初立接本年。单于来书所称灭月氏、并二十六国是自述功业，不能据此宣布各地征服和人口均已独立核实。本页只取继位和外交主线，中行说后来长期与汉使辩论的全部材料不强放在随行当日。冬十月桃李开花的记录另见汉书，为物候记载，不作淮南案的预兆。

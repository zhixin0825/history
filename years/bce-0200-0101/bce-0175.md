# 公元前175年｜四铢钱准民铸造，吴国与邓通的铜源更显重要

[← 公元前176年](bce-0176.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前174年 →](bce-0174.md)

**汉文帝前五年**

## 四月，朝廷开放铸钱

**改造四铢钱，废去禁止民间私铸的有关法令。** 贾谊警告，铸钱利润会引诱人掺杂作弊、离农采铜，各地用轻重钱的方法又不同；若管得太严，官吏劳于查办，若放任，又难统一。皇帝没有采用他要求朝廷控制铜源的建议。[1](#sj010-money)

**掌握铜山的人，由此更容易积聚财富。** 邓通获赐蜀严道铜山，吴王刘濞利用豫章铜山，并以海盐取得收入，吴、邓钱广泛流通。政策允许铸钱，并不表示每个普通农户都有同等的条件参与。[1](#sj010-money)

## 代地再次合并到一个王手中

**刘武由代王迁为淮阳王，刘参由太原王迁为代王，取得原代地。** 前178年新分出的两个王国因而重新调整。皇子的王号随地盘变化，不能一直用第一次受封的名号指代其后来所在。[1](#sj010-money)

<a id="sj017-chu"></a>
## 楚王刘郢客去世

**刘郢客在位四年后去世，儿子刘戊接续楚国。** 郢客承接的是父亲刘交的楚王国；刘戊的元年在下一年，后来七国之乱的结局不提前放到这次继承中。[2](#sj017-note)

## 本年相关史料

<a id="sj010-money"></a>
### 1｜本纪未单列的货币与封国记事

依据[《汉书》卷004五年](https://zh.wikisource.org/wiki/漢書/卷004)、[《通鉴》卷十四五年](https://zh.wikisource.org/wiki/資治通鑑/卷014)。二月地震亦见同年。四铢是钱的标称重量，半两铭文与实际重量不能仅看名称混同；高祖以来轻钱、物价变化在通鉴为前情，不把此前“米石万钱”硬写成本年粮价。

吴、邓的铸钱优势是相关时期形成的局面，文本“是时”不提供每次赐铜山、开矿的准确日期。贾谊的风险分析是进言，不能把所有预期弊害直接当成已统计验证的结果。两王迁封采用通鉴本年；[卷017前177](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0177)、[前176](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0176)分别预列、续记这项变化，保留异年而不另造第二轮相同迁封。

<a id="sj017-note"></a>
### 2｜楚王郢与郢客

[卷017前175年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0175)楚栏“四，薨”；[楚元王世家](https://zh.wikisource.org/wiki/史記/卷050)记郢客四年卒、子戊立。表简名郢与世家郢客合为同一人，夷王为后谥，不倒造授谥时即生效的元年称号。月日未明，不把死亡附会为铸钱政策或迁王导致。

<a id="sj018-forfeitures"></a>
## 张不疑因谋杀案失侯，另有家族因继承资格而中断

**留侯张不疑与门下大夫共谋杀害原楚国内史，被判当死，后来赎免死罪、改服城旦之役，侯国撤销。** 这是张良之子自己的案情，不能用父亲的功劳替代对后代的处理，也不能把“赎”误写成仍完整保有侯爵。[留R013](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r013)

**涅阳一支的成被认定不是初侯吕胜的儿子，不能承侯，封国因此终止。** 现有材料记的是官府对继承资格的认定，不等于现代已独立证实全部血缘关系。[涅阳R072](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r072)

**高胡的程承侯后又去世，无后而除国。** 这与因罪被罚、被否定父子身份的案件不同；即使都以“国除”作结，也不能统一写成被皇帝杀害。[高胡R065](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r065)

<a id="sj018-zhouxie"></a>
**蒯成侯周绁在本年去世，儿子昌接爵，后来又因罪失去封国。** 父亲从沛起兵、危急时不离刘邦的功劳，并不使继承者永久免于处分；后案没有明确发生年，不能全压到本年。[蒯成R063](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r063)

<a id="sj018-note"></a>
### 卷018｜十三项表年记录及两处不确定的前后关系

留侯案与[《留侯世家》](https://zh.wikisource.org/wiki/史記/卷055)明确孝文五年相合，保留谋杀、当死、赎为城旦和国除的不同层次。高胡同年嗣又无后，未载确日；九家普通承爵与高胡初继、蒯成父卒子继不合计为同一批初封大会。

涅阳吕胜／吕腾的父卒年在史、汉表有四年、五年之差，本页只确定继承资格被否定和侯国中断这一阶段，不在相邻两年各记一次父死。平棘辟强的罪案在史表文六年、[汉书功臣表](https://zh.wikisource.org/wiki/漢書/卷016)文五年，当前采用汉表把承爵后受鬼薪刑、失国放在本年，史表的高后八年起算及次年刑案保留异年；没有证据证明他曾连续两次获得、失去同一个侯爵。

周绁卒年由[《傅靳蒯成列传》](https://zh.wikisource.org/wiki/史記/卷098)明确孝文五年，名字本表惞、传绁等异写仍属同一人。昌继后“有罪绝”没有确年，暂列在本卷未定年后事，不把它用旁边的“五年”强行定位。汾阴一支意的后续失爵也在之后，不能把含元年的整格一概读成本年案情。

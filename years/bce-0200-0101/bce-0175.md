# 公元前175年｜四铢钱准民铸造，吴国与邓通的铜源更显重要

[← 公元前176年](bce-0176.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前174年 →](bce-0174.md)

**汉文帝前五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="四月朝廷开放铸钱"></a>

<a id="event-1"></a>

1. **四月，朝廷开放铸钱。** 改造四铢钱，废去禁止民间私铸的有关法令。 贾谊警告，铸钱利润会引诱人掺杂作弊、离农采铜，各地用轻重钱的方法又不同；若管得太严，官吏劳于查办，若放任，又难统一。皇帝没有采用他要求朝廷控制铜源的建议。 [[1]](#note-1)

<a id="event-2"></a>

2. **掌握铜山的人，由此更容易积聚财富。** 邓通获赐蜀严道铜山，吴王刘濞利用豫章铜山，并以海盐取得收入，吴、邓钱广泛流通。政策允许铸钱，并不表示每个普通农户都有同等的条件参与。 [[2]](#note-2)

<a id="代地再次合并到一个王手中"></a>

<a id="event-3"></a>

3. **刘武由代王迁为淮阳王，刘参由太原王迁为代王，取得原代地。** 前178年新分出的两个王国因而重新调整。皇子的王号随地盘变化，不能一直用第一次受封的名号指代其后来所在。 [[3]](#note-3)

<a id="sj017-chu"></a>
<a id="楚王刘郢客去世"></a>

<a id="event-4"></a>

4. **刘郢客在位四年后去世，儿子刘戊接续楚国。** 郢客承接的是父亲刘交的楚王国；刘戊的元年在下一年，后来七国之乱的结局不提前放到这次继承中。 [[4]](#note-4)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-5"></a>

5. **张不疑与门下大夫共谋杀害原楚国内史，被判死罪，赎免后改服城旦之役，留侯国撤销。** 张良的功劳没有使继承人免于处分；赎免死罪也没有保住原来的侯爵。 [[5]](#note-5)

<a id="event-6"></a>

6. **涅阳的继承人被认定不是初侯吕胜之子，不能承爵；高胡侯程则继位后去世，无后而除国。** 一个关系到继承资格，一个关系到没有后嗣，不是两场相同的谋反案。 [[6]](#note-6)

<a id="event-7"></a>

7. **萧则重新得到武阳侯爵。** 萧延改封酂以后，萧遗曾承爵而无后，朝廷改以萧遗的弟弟萧则续封；开国相国的家族由另一支继续奉祀。 [[7]](#note-7)

<a id="event-8"></a>

8. **蒯成侯周绁去世，儿子昌接爵。** 周绁曾在刘邦兵败时不肯离去；昌后来却因罪失侯，具体失爵年份没有留下。 [[8]](#note-8)

[《史记》功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7018.md#ref-42e1be97b76365)与[《汉书》功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-8f86681caec521)对读。普通承爵条按元年记载定位；无确月者不补日期，也不据子元年一律倒推父卒。后谥只用于辨认，不当作继位当时已经采用的称号。

[R015](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r015)：汉表写延文元年更酂、二年薨，遗嗣一年无后，文五年则绍封；[《汉书》卷039](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7039.md#ref-9dc63d598a5040)也按延—遗—则相接。史表却把延计十九年、遗元年置后四年、则置后五年，与汉表相差很大。本稿取文五年明确绍封及家系，不给延、遗各补未经独立核定的卒日；前160、159年只登记原表另一年次，不重封。

[R073](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r073)：平棘辟强的承侯、鬼薪刑与失国，汉表系文五年，史表系六年且将元年提前到高后八年。本稿以汉表本年为案情阅读位置，不造第二位辟强；鬼薪是刑罚，不写成已被处死。

[R063](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r063)：周绁死年据[《傅靳蒯成列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7098.md#ref-eae1f5f2b191fa)“孝文五年卒”。昌后来失侯只有相对先后，登记为未定年后事，不把整格都压成本年。

[R072](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r072)：吕胜／吕腾为史汉异名；判定“非子”是官府继承资格说法，非现代血缘鉴定。高胡程同格嗣与无后，未补月日。

<a id="1本纪未单列的货币与封国记事"></a>
#### 1｜本纪未单列的货币与封国记事

依据[《汉书》卷004五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-276c617e185a51)、[《通鉴》卷十四五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7014.md#ref-f3847f1465a82d)。二月地震亦见同年。四铢是钱的标称重量，半两铭文与实际重量不能仅看名称混同；高祖以来轻钱、物价变化在通鉴为前情，不把此前“米石万钱”硬写成本年粮价。

吴、邓的铸钱优势是相关时期形成的局面，文本“是时”不提供每次赐铜山、开矿的准确日期。贾谊的风险分析是进言，不能把所有预期弊害直接当成已统计验证的结果。两王迁封采用通鉴本年；[卷017前177](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0177)、[前176](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0176)分别预列、续记这项变化，保留异年而不另造第二轮相同迁封。

1. **灌婴去世，张苍继任丞相。** 冬十二月，灌婴任相后不久便去世，其后的正月由张苍接任。汉初十月岁首，这两个日期仍在同一古历年。张苍博通书籍，尤其熟悉律历，将在后来的正朔、五德之争中发挥作用。灌婴去世，张苍继相。参见本年的官职变动原句。 [[1]](#note-1)

<a id="已经交兵就国的周勃仍没能避开牢狱"></a>

<a id="event-2"></a>

<a id="event-3"></a>

2. **周勃下狱，获赦并恢复爵邑。** 周勃因披甲见守尉而被告谋反，遭逮捕审问。就国一年多以后，每逢河东守、尉巡县到绛，他恐惧遭诛，自己披甲、令家人持兵相见。有人上书告反，廷尉把案子下到长安方面，逮捕审理。周勃不知怎样置辩，狱吏又加羞辱；他以千金贿赂狱吏，对方在木牍背面写下以公主为证，教他援引嫁给儿子胜之的文帝之女作证。薄太后为周勃说情，文帝派持节使者赦免，恢复爵邑。周勃此前把增封所得与赏赐尽给薄昭，案情紧急时，薄昭转告薄太后。太后也认为无反事，见文帝来朝，便拿冒絮头巾掷他，质问周勃手握帝玺、统北军时尚未反，退居小县反会谋反吗？文帝称官吏正要查验后释出，随即赦免。周勃出狱感叹，自己曾统百万军，却不知狱吏如此尊贵。 [[2]](#note-2)

<a id="年轻的贾谊离开长安"></a>

<a id="event-4"></a>

3. **年轻的贾谊离开长安。** 皇帝一度考虑重用贾谊，旧臣却批评他年轻好权、要扰乱制度。 贾谊最终被派为长沙王太傅。河东守季布也曾被召来又罢去，他当面责问皇帝为何因一人赞誉就召、因一人诋毁就退，刘恒一时难以回答。 [[3]](#note-4)

<a id="sj017-chengyang"></a>
<a id="刘喜承接城阳王国"></a>

<a id="event-5"></a>

4. **刘喜开始记元年，继承父亲刘章的城阳王位。** 刘章前一年去世，儿子接续这支齐悼惠王后裔的封国。以后刘喜还有迁王淮南、再回城阳的经历，本年不提前完成。 [[4]](#note-5)

<a id="event-7"></a>

6. **菌侯胜因罪失去侯国。** 他承接的是张平的开国封爵；短表没有留下可以重构的审讯过程。 [[6]](#note-7)

<a id="sj010-supplement"></a>
<a id="1补缺并不等于原本纪本年无事"></a>
#### 1｜补缺并不等于原本纪本年“无事”

本纪从前177年跳向前174年，没有单列本年。这里依[《通鉴》卷十四四年](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7014.md#ref-0aa55560e43e80)、[《汉书》卷004](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-a396dd97950d9b)补入；冬十二月在本古历年的正月以前，不另跨到第五年任张苍。

周勃案采用告发、逮捕、审讯、赦免的实际阶段，不先认定谋反指控属实。顾成庙营建、宗室复免亦见同年。齐悼惠王诸子的授侯名单在本轮据两张侯表补核：史记现存九行，汉书另列杨丘刘安，共十人，不能继续把“七子”当作已核齐的全名单。贾谊、季布的相应谈话按传世叙事归属，不将文学对话当现代庭审记录。

<a id="sj017-note"></a>
<a id="2城阳元年与两王迁封的异年"></a>
#### 2｜城阳元年与两王迁封的异年

[卷017前176年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0176)城阳共王喜元年与[齐悼惠王世家](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7052.md#ref-288bb33a23052e)父子承继相合。太原参改代王、武转淮阳在本表前177—176两行分写，《通鉴》则明系前175年。继续沿[前175年既有主线](bce-0175.md#sj010-money)记一轮迁封，此处只存不同系年，不让两兄弟连年重复走同一路线。“实居太原”说明新代王名号与驻地关系，也不据此造一次未记的独立迁都。

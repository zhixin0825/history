# 公元前176年｜灌婴去世，张苍为相，周勃下狱又获赦

[← 公元前177年](bce-0177.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前175年 →](bce-0175.md)

**汉文帝前四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="冬十二月灌婴去世"></a>

<a id="event-1"></a>

1. **冬十二月，灌婴去世。** 灌婴任相后不久便去世，其后的正月由张苍接任。 汉初十月岁首，这两个日期仍在同一古历年。张苍博通书籍，尤其熟悉律历，将在后来的正朔、五德之争中发挥作用。 [[1]](#note-1)

<a id="已经交兵就国的周勃仍没能避开牢狱"></a>

<a id="event-2"></a>

2. **已经交兵就国的周勃，仍没能避开牢狱。** 河东守尉到绛地巡行时，周勃常披甲、让家人持兵迎见，因为他一直怕被捕杀。 后来有人以谋反告发，廷尉逮捕审讯。周勃在狱中恐惧，不知怎样答辩，还遭狱吏侮辱；他花钱求人相助，又以公主婚姻关系求得转圜。 [[2]](#note-2)

<a id="event-3"></a>

3. **薄太后指出，他掌握北军和玺信时都未反叛，怎会回到小县才反。** 皇帝最后赦免周勃，恢复爵邑。功高而退并没有使其自动安全，朝廷定罪与有权者恐惧相互推动。 [[3]](#note-3)

<a id="年轻的贾谊离开长安"></a>

<a id="event-4"></a>

4. **年轻的贾谊离开长安。** 皇帝一度考虑重用贾谊，旧臣却批评他年轻好权、要扰乱制度。 贾谊最终被派为长沙王太傅。河东守季布也曾被召来又罢去，他当面责问皇帝为何因一人赞誉就召、因一人诋毁就退，刘恒一时难以回答。 [[4]](#note-4)

<a id="sj017-chengyang"></a>
<a id="刘喜承接城阳王国"></a>

<a id="event-5"></a>

5. **刘喜开始记元年，继承父亲刘章的城阳王位。** 刘章前一年去世，儿子接续这支齐悼惠王后裔的封国。以后刘喜还有迁王淮南、再回城阳的经历，本年不提前完成。 [[5]](#note-5)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-6"></a>

6. **河阳侯信因拖欠他人债务逾六个月，被夺侯国。** 这条处分与兵变无关，不能将所有“国除”都写成谋反。 [[6]](#note-6)

<a id="event-7"></a>

7. **菌侯胜因罪失去侯国。** 他承接的是张平的开国封爵；短表没有留下可以重构的审讯过程。 [[7]](#note-7)

<a id="sj018-succession"></a>

<a id="event-8"></a>

8. **侯爵继续在各家传承。** 以下记录本年开始的侯年；继承家爵不等于同时承接父辈的中央官职。 [[8]](#note-8)

   | 侯籍一支 | 本年变化 |
   |---|---|
   | 絳陽 | 勃齐接绛阳侯，续华无害一支。 |
   | 臺 | 才接台侯，续戴野一支；汉表名午。 |
   | 辟陽 | 审平承接被刘长杀死的审食其的辟阳侯爵。 |
   | 廣阿 | 但接广阿侯，续竟一代。 |
   | 戚 | 班开始记戚侯元年；汉表本年作瑕。 |

   [本段原文、异年及说明](#sj018-note)。

<a id="sj019-t001-176"></a>

<a id="event-9"></a>

9. **同批受封的还有杨丘侯刘安，也是齐悼惠王刘肥之子。** 他与淮南王刘长之子、后来封阜陵侯的刘安不是同一人。 [[9]](#note-9)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-10"></a>

10. **安丘侯张说率军由代地出击匈奴。** 北方军事行动并未因丞相更替停下来；表中没有留下这次出击的兵数与战果，不能借用后来的战事补足。 [原格与说明](#sj022-note)。 [[10]](#note-10)

<a id="1补缺并不等于原本纪本年无事"></a>
#### 1｜补缺并不等于原本纪本年“无事”

本纪从前177年跳向前174年，没有单列本年。这里依[《通鉴》卷十四四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7014.md#ref-0aa55560e43e80)、[《汉书》卷004](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-a396dd97950d9b)补入；冬十二月在本古历年的正月以前，不另跨到第五年任张苍。

周勃案采用告发、逮捕、审讯、赦免的实际阶段，不先认定谋反指控属实。顾成庙营建、宗室复免亦见同年。齐悼惠王诸子的授侯名单在本轮据两张侯表补核：史记现存九行，汉书另列杨丘刘安，共十人，不能继续把“七子”当作已核齐的全名单。贾谊、季布的相应谈话按传世叙事归属，不将文学对话当现代庭审记录。

<a id="2城阳元年与两王迁封的异年"></a>
#### 2｜城阳元年与两王迁封的异年

[卷017前176年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0176)城阳共王喜元年与[齐悼惠王世家](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7052.md#ref-288bb33a23052e)父子承继相合。太原参改代王、武转淮阳在本表前177—176两行分写，《通鉴》则明系前175年。继续沿[前175年既有主线](bce-0175.md#sj010-money)记一轮迁封，此处只存不同系年，不让两兄弟连年重复走同一路线。“实居太原”说明新代王名号与驻地关系，也不据此造一次未记的独立迁都。

# 公元前176年｜灌婴去世，张苍为相，周勃下狱又获赦

[← 公元前177年](bce-0177.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前175年 →](bce-0175.md)

**汉文帝前四年**

## 冬十二月，灌婴去世

**灌婴任相后不久便去世，其后的正月由张苍接任。** 汉初十月岁首，这两个日期仍在同一古历年。张苍博通书籍，尤其熟悉律历，将在后来的正朔、五德之争中发挥作用。[1](#sj010-supplement)

## 已经交兵就国的周勃，仍没能避开牢狱

**河东守尉到绛地巡行时，周勃常披甲、让家人持兵迎见，因为他一直怕被捕杀。** 后来有人以谋反告发，廷尉逮捕审讯。周勃在狱中恐惧，不知怎样答辩，还遭狱吏侮辱；他花钱求人相助，又以公主婚姻关系求得转圜。[1](#sj010-supplement)

**薄太后指出，他掌握北军和玺信时都未反叛，怎会回到小县才反？** 皇帝最后赦免周勃，恢复爵邑。功高而退并没有使其自动安全，朝廷定罪与有权者恐惧相互推动。[1](#sj010-supplement)

## 年轻的贾谊离开长安

**皇帝一度考虑重用贾谊，旧臣却批评他年轻好权、要扰乱制度。** 贾谊最终被派为长沙王太傅。河东守季布也曾被召来又罢去，他当面责问皇帝为何因一人赞誉就召、因一人诋毁就退，刘恒一时难以回答。[1](#sj010-supplement)

<a id="sj017-chengyang"></a>
## 刘喜承接城阳王国

**刘喜开始记元年，继承父亲刘章的城阳王位。** 刘章前一年去世，儿子接续这支齐悼惠王后裔的封国。以后刘喜还有迁王淮南、再回城阳的经历，本年不提前完成。[2](#sj017-note)

## 本年相关史料

<a id="sj010-supplement"></a>
### 1｜补缺并不等于原本纪本年“无事”

本纪从前177年跳向前174年，没有单列本年。这里依[《通鉴》卷十四四年](https://zh.wikisource.org/wiki/資治通鑑/卷014)、[《汉书》卷004](https://zh.wikisource.org/wiki/漢書/卷004)补入；冬十二月在本古历年的正月以前，不另跨到第五年任张苍。

周勃案采用告发、逮捕、审讯、赦免的实际阶段，不先认定谋反指控属实。顾成庙营建、宗室复免与齐悼惠王七子封侯也见汉书同年，未有完整名日的项目不在此猜补。贾谊、季布的相应谈话按传世叙事归属，不将文学对话当现代庭审记录。

<a id="sj017-note"></a>
### 2｜城阳元年与两王迁封的异年

[卷017前176年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0176)城阳共王喜元年与[齐悼惠王世家](https://zh.wikisource.org/wiki/史記/卷052)父子承继相合。太原参改代王、武转淮阳在本表前177—176两行分写，《通鉴》则明系前175年。继续沿[前175年既有主线](bce-0175.md#sj010-money)记一轮迁封，此处只存不同系年，不让两兄弟连年重复走同一路线。“实居太原”说明新代王名号与驻地关系，也不据此造一次未记的独立迁都。

<a id="sj018-forfeitures"></a>
## 河阳侯因欠债被夺爵，菌侯也失去了封国

**河阳侯信因拖欠他人债务超过六个月，被剥夺爵位，侯国撤销。** 他承接的是陈涓开国所得的爵邑，记录中的处置不是战败、反叛，也不能无证据扩大成汉朝所有欠债者都一律同罚。[河阳R039](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r039)

**菌侯胜同年因罪失国。** 本表只有简略罪称，汉表另有谋反的定性；现有短格不足以复原一场已经发动的战役，本文只记朝廷的处罚结果。[菌R143](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r143)

<a id="sj018-succession"></a>
## 五家侯籍换代，审食其的儿子仍能承侯

| 侯国 | 本年开始计年的继承人 | 原格 |
|---|---|---|
| 绛阳 | 勃齐，接华无害一支 | [R055](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r055) |
| 台 | 才，接戴野一支 | [R058](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r058) |
| 辟阳 | 审平，接前一年被刘长杀死的审食其 | [R061](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r061) |
| 广阿 | 但，接任竟一代 | [R115](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r115) |
| 戚 | 班，承接季必一支；两表的中间世代有差别 | [R133](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r133) |

**审食其死于淮南王之手，辟阳爵位却没有随即被朝廷撤销。** 个人遭杀与封国无人承继或被依法撤爵是不同过程，审平的后续不能只凭父亲的遭遇推定。

<a id="sj018-note"></a>
### 卷018｜七格落实与戚侯谱系的缺代问题

河阳、菌两项失国及五家承侯均有原格，姓名沿各家继承识别，不由同名将广阿但、棘阳但混作一人。任竟的元年在前177、但在本年，短任期也不等于已知父亲死因。灌婴死亡与张苍任相分别接本页旧事，[颍阴R019](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r019)、[北平R064](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r064)不再生成平行的相位年表。

[汉书功臣表](https://zh.wikisource.org/wiki/漢書/卷016)戚侯一支在文帝元年先记一任惠侯，到文帝四年再有新侯；史表却在季必之后直接接四年班元年。本文把本年确有新一代侯起算的共同点保留，前任与姓名不能仅据一表硬定为父子。汉表中间世代与相关异字留在综合考证，不能把可能缺代修补为一段确定的死亡、改名故事。

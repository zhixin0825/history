# 公元前177年｜周勃就国，淮南王杀人，济北王乘北边告急起兵

[← 公元前178年](bce-0178.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前176年 →](bce-0176.md)

**汉文帝前三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="列侯还在拖延皇帝让丞相先作榜样"></a>

<a id="event-1"></a>

1. **列侯还在拖延，皇帝让丞相先作榜样。** 文帝指出，列侯就国的诏令仍未尽行，有人借故不走；丞相是自己最重视的大臣，应率先行动。周勃再次免相，回绛地就国，灌婴接任丞相。原太尉职位撤去，事务归丞相。 [[1]](#note-1)

<a id="四月刘章去世刘长在长安杀了审食其"></a>

<a id="event-2"></a>

2. **四月，刘章去世，刘长在长安杀了审食其。** 城阳王刘章去世，距离封王不过一年。 另一位宗室淮南王刘长入朝，却亲自去袭击辟阳侯审食其，再令随从魏敬杀死他。 [[2]](#note-2)

<a id="event-3"></a>

3. **刘长把这场杀戮说成替母报仇。** 他的母亲早年因赵王旧案入狱，生下他后自杀；他一直怨恨审食其当初没有力争救母。杀人后刘长到宫门谢罪，文帝顾念兄弟和他的身世，赦而不治。袁盎警告，诸侯被过度纵容终会生患，没有使皇帝改变处置。 [[3]](#note-3)

<a id="五月以后匈奴入河套南部皇帝巡视旧地"></a>

<a id="event-4"></a>

4. **五月以后，匈奴入河套南部，皇帝巡视旧地。** 右贤王进入河南降地，侵害边民及依附汉的保塞人群。 文帝到甘泉，命灌婴率边骑前往高奴应对，又留材官守长安。匈奴退去后，皇帝由高奴转往太原，看望旧臣、赐里民牛酒，免晋阳、中都三年田租，停留十余日。 [[4]](#note-4)

<a id="刘兴居趁机反叛准备进攻荥阳"></a>

<a id="event-5"></a>

5. **刘兴居乘北边用兵之机在济北起兵，准备进攻荥阳。** 兄刘章已经去世，匈奴大举入边，汉廷多发兵，让丞相灌婴出击，文帝亲赴太原。刘兴居以为皇帝要亲自对匈奴作战，便发兵反叛；本篇把这同兄弟未得到原许赵、梁全境、觉得功劳受削联系起来。帝闻讯停丞相等进兵，返回长安，另使棘蒲侯柴武讨济北，令祁侯部队守荥阳。刘兴居战败被俘后自杀，详下一组。 [[5]](#note-5)

<a id="event-6"></a>

6. **七月皇帝回长安，先宣布及时自定、带军城归降的吏民可赦。** 八月济北军败，刘兴居被俘后自杀，其他跟随者再次获赦。去年一同获封的兄弟，刘章本年去世，刘兴居则在起兵失败后自杀，经历并不相同。 [[6]](#note-6)

<a id="sj017-kings"></a>
<a id="燕国进入刘嘉元年吴王也有来朝记录"></a>

<a id="event-7"></a>

7. **燕王刘嘉开始元年。** 刘嘉接续前一年去世的父亲燕敬王刘泽，开始燕王纪年，后来谥为康王。 [[7]](#note-7)

<a id="event-8"></a>

8. **吴王刘濞本年入朝。** 淮南王刘长的来朝已经与上文杀审食其一事连接；两个国栏各有记录，却不能说两王在长安一同参与了杀人行动。 [[8]](#note-8)

11. **棘蒲侯陈武统兵应对济北局势，多位将领分别领兵、驻守。** 卢卿、卢罢师、鸱、将夜等也分别领兵，祁侯贺屯荥阳。 [原格与说明](#sj022-note)。 [[11]](#note-11)

<a id="sj102-event-12"></a>

12. **张释之因袁盎举荐进入文帝视野。** 张释之久为骑郎，想辞官还家，袁盎荐他任谒者。他向文帝谈秦亡汉兴，随后任谒者仆射。文帝在上林苑有意破格提拔善答的虎圈啬夫，张释之以秦任苛察吏为戒，帝采纳，转任张释之为公车令。张释之此后拦住未在司马门下车的太子和梁王，升为中大夫，继而历任中郎将、廷尉。 [[12]](#note-12)

<a id="sj102-event-13"></a>

13. **张释之按律裁定犯跸及高庙盗环两案。** 文帝车驾在中渭桥受惊，廷尉张释之依犯跸之律判罚金，解释加刑会损害法律的信用，文帝同意。其后有人盗高庙玉环，文帝欲族诛，张释之奏判弃市，又用长陵一抔土作假设，指出加重刑罚将抹去罪的轻重差等，文帝与太后议后接受裁定。 [[13]](#note-13)

### 12. 张释之因袁盎举荐进入文帝视野

<a id="sj102-p000"></a>

**[《史记·张释之冯唐列传》P000](../../sources/摘录/史记-卷102-张释之冯唐列传.md#p000)** · [三家注](../../sources/史记三家注/卷102.md#p0)

> 中郎將袁盎知其賢，惜其去，乃請徙釋之補謁者。釋之旣朝畢，因前言便宜事。文帝曰：「卑之，毋甚高論，令今可施行也。」於是釋之言秦漢之閒事，秦所以失而漢所以興者久之。文帝稱善，乃拜釋之爲謁者僕射。

**本卷归年说明：** 《通鑑》卷014按文帝前元三年敘薦任；前十歲是本傳追敘，不能反推唯一始任年。

<a id="sj102-p001"></a>

**[《史记·张释之冯唐列传》P001](../../sources/摘录/史记-卷102-张释之冯唐列传.md#p001)** · [三家注](../../sources/史记三家注/卷102.md#p1)

> 釋之從行，登虎圈。上問上林尉諸禽獸簿，十餘問，尉左右視，盡不能對。虎圈嗇夫從旁代尉對上所問禽獸簿甚悉，欲以觀其能口對響應無窮者。文帝曰：「吏不當若是邪？尉無賴！」乃詔釋之拜嗇夫爲上林令。釋之久之前曰：「陛下以絳侯周勃何如人也？」上曰：「長者也。」又復問：「東陽侯張相如何如人也？」上復曰：「長者。」釋之曰：「夫絳侯、東陽侯稱爲長者，此兩人言事曾不能出口，豈斆此嗇夫諜諜利口捷給哉！且秦以任刀筆之吏，吏爭以亟疾苛察相高，然其敝徒文具耳，無惻隱之實。以故不聞其過，陵遲而至於二世，天下土崩。今陛下以嗇夫口辯而超遷之，臣恐天下隨風靡靡，爭爲口辯而無其實。且下之化上疾於景響，舉錯不可不審也。」文帝曰：「善。」乃止不拜嗇夫。

**本卷归年说明：** 《通鑑》卷014將此段接在薦舉後；無獨立月日。

**[《史记·张释之冯唐列传》P002](../../sources/摘录/史记-卷102-张释之冯唐列传.md#p002)** · [三家注](../../sources/史记三家注/卷102.md#p2)

> 上就車，召釋之參乘，徐行，問釋之秦之敝。具以質言。至宮，上拜釋之爲公車令。

**本卷归年说明：** 承虎圈後，與《通鑑》卷014同段連敘。

### 13. 张释之按律裁定犯跸及高庙盗环两案

[返回正文第13条](#sj102-event-13)

<a id="sj102-p005"></a>

**[《史记·张释之冯唐列传》P005](../../sources/摘录/史记-卷102-张释之冯唐列传.md#p005)** · [三家注](../../sources/史记三家注/卷102.md#p5)

> 頃之，上行出中渭橋，有一人從穚下走出，乘輿馬驚。於是使騎捕，屬之廷尉。釋之治問。曰：「縣人來，聞蹕，匿橋下。久之，以爲行已過，即出，見乘輿車騎，即走耳。」廷尉奏當一人犯蹕，當罰金。文帝怒曰：「此人親驚吾馬，吾馬賴柔和，令他馬，固不敗傷我乎？而廷尉乃當之罰金！」釋之曰：「法者天子所與天下公共也。今法如此而更重之，是法不信於民也。且方其時，上使立誅之則已。今旣下廷尉，廷尉，天下之平也，一傾而天下用法皆爲輕重，民安所錯其手足？唯陛下察之。」良久，上曰：「廷尉當是也。」

**本卷归年说明：** 《通鑑》卷014於廷尉授任後接敘犯蹕案，兩案古籍都無月日。

<a id="1多线事件及异文"></a>
#### 1｜多线事件及异文

[卷010 P019—P023](../../sources/摘录/史记-卷010-孝文本纪.md#p019) · [《汉书》卷004三年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-1530e28970413a) · [通鉴卷十四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7014.md#ref-acea6c02f93a5c)。十一月诏、周勃离任、十二月灌婴任相按互见分述，不把任命合成同一天。十、十一月晦的日食见汉书通鉴，月份是古历。

本纪济北主将作棘蒲侯陈武，汉书、通鉴作柴武；正文不用一处异名拼出两场征讨。原文八万五千骑、十万征济北等为文本所报，不当现代精确兵力统计。河南是黄河以南的河套相关地域，不是现代河南省；对保塞人群不沿用贬抑的族群措辞。

刘长杀审食其的前情属于高祖时期，具体身世不全系本年；前174年的废王案另记。刘章只记薨，死因不明，不补疾病或谋杀说。张释之任廷尉、桥下惊马按法罚金等互见在通鉴本年展开，属于本纪总评所说听谏的背景，不假称卷010已详载全部案例。

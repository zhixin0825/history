# 公元前178年｜陈平去世，刘恒亲耕、求直言，又重分六个王国

[← 公元前179年](bce-0179.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前177年 →](bce-0177.md)

**汉文帝前二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="冬季换相列侯被要求回到封地"></a>

<a id="event-1"></a>

1. **冬季换相，列侯被要求回到封地。** 十月陈平去世，十一月周勃再次任丞相。 朝廷要求列侯到自己的封国，不要长住京城、靠远地输送供养；在中央任官或奉诏留京者，派嗣子去。功臣与地方的关系，被纳入新的安排。 陈平谥献侯，其后家爵由陈买一支续承；生前自警、太史公论与唐代述赞在同号注分层附读，不作为本年新发生的事件。 周勃前次辞相一年多后，陈平去世，他因而再次任相。 [[1]](#note-1)

<a id="event-2"></a>

2. **十一月晦日发生日食，刘恒下诏求直言、减少徭费。** 他要求大臣指出施政过失，举荐贤良方正者；又撤去卫将军统辖的这支军队，把太仆多余的马给传置使用。边防未废，减少的是另外一部分警卫与养马开支。 [[2]](#note-2)

<a id="正月皇帝到籍田亲耕"></a>

<a id="event-3"></a>

3. **正月，皇帝到籍田亲耕。** 刘恒率先耕作，田中出产用于宗庙祭祀。 他希望以此劝农，不让朝廷只在诏书里要求百姓务本。贾谊所说积谷不足、灾荒与边急会使国家陷入困境，也是当时劝农论议的重要背景。 [[3]](#note-3)

<a id="sj017-six-kings"></a>
<a id="三月宗室六人封王"></a>

<a id="event-4"></a>

4. **三月，宗室六人封王，刘章、刘兴居由侯升王。** 赵王刘遂的弟弟刘辟强封河间，齐地城阳郡给刘章、济北郡给刘兴居；皇子刘武、刘参、刘揖分别封代、太原、梁。其中刘武与太子刘启同出窦氏，刘揖是文帝最幼的儿子。诛吕之初，大臣曾许给刘章赵地、刘兴居梁地；文帝得知二人原想拥齐王，降低对他们功劳的评价，只割两郡给他们，二人因而自觉失职夺功。 [[4]](#note-4)

<a id="event-5"></a>

5. **河间以乐成为都，太原以晋阳为都，两国从原来的大王国中分出。** 王国分设不必与实际君主到国同日完成，章、兴居原先的朱虚侯、东牟侯身份也不另算为新人物。 [[5]](#note-5)

<a id="五月不要把百姓一句话轻率治成大罪"></a>

<a id="event-6"></a>

6. **五月，不要把百姓一句话轻率治成大罪。** 文帝废去诽谤妖言之罪的有关规定。 他认为禁言会使臣下不敢说真话，自己也听不到过失；百姓相互诅咒、欺骗，官吏又动辄上纲为大逆、诽谤，不应轻易置人于死。 [[6]](#note-6)

<a id="event-7"></a>

7. **九月，朝廷给郡国守相制作铜虎符、竹使符，并减本年田租一半。** 一面整顿授权与传命，一面实际减轻农民当年应交的田租。燕王刘泽也在本年去世。 刘泽迁燕到第二年而卒，谥敬王，儿子刘嘉继承；刘嘉的新王元年接下一年。 [[7]](#note-7)

<a id="sj017-successions"></a>
<a id="楚齐和长沙接续王统"></a>

<a id="event-8"></a>

8. **刘郢客接楚，刘则接齐，各自开始新王纪年。** 他们分别承接前一年去世的刘交、刘襄。楚的郢客在年表简写为郢；齐的刘则后来无后而终，本年不能提前把齐国撤销。 [[8]](#note-8)

<a id="event-9"></a>

9. **长沙由吴产接续，吴氏异姓王统继续延续。** 本页采用《汉书》王表的本年承继；《史记》记作次年靖王著元年，保留异年异名而不另造两王。 [[9]](#note-9)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-10"></a>

10. **阏氏侯一支由遗恢复封爵。** 他的父亲它在高祖末年死亡时被记为无后，遗其实是遗腹子；现在得到爵位，不是到文帝时才出生。 [[10]](#note-10)

<a id="event-11"></a>

11. **煮枣的爵位重新授给初封者的儿子。** 早先一位嗣子因罪不能接爵，此次绍封者在史表名武，汉表名式。 [[11]](#note-11)

<a id="sj018-succession"></a>

<a id="event-12"></a>

12. **侯爵继续在各家传承。** 以下记录本年开始的侯年；继承家爵不等于同时承接父辈的中央官职。 [[12]](#note-12)

    | 侯籍一支 | 本年变化 |
    |---|---|
    | 廣嚴 | 胜接广严侯，续召欧一支。 |
    | 平州 | 福接平州侯，续昭涉掉尾一支。 |

    [本段原文、异年及说明](#sj018-note)。

    本卷与本页已叙事项的互见，以及未能确年的后事，合见[卷019史料说明](#sj019-note)。

<a id="sj101-event-14"></a>

14. **袁盎阻文帝驰下霸陵，又调整慎夫人座次。** 文帝欲乘车从霸陵驰下陡坡，中郎将袁盎策马并车，执辔劝止。一次皇帝往上林时，袁盎将慎夫人的席位退开，解释皇后与妾礼位有别，又以戚夫人的遭遇为戒。文帝接受解释，慎夫人赐袁盎五十斤金。 [[14]](#note-14)

#### 1｜月次、日食与法令边界

[卷010 P013—P018](../../sources/摘录/史记-卷010-孝文本纪.md#p013) · [《通鉴》卷十三二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7013.md#ref-502261983e984d)。陈平死亡和周勃复相分在十、十一月，本纪合写不证明同日。所据本纪另有“十二月望，日又食”，汉书、通鉴没有同样的第二条，文字有疑，正文不把它当成另一次已校定日食。天象罪己是当时的解释，非自然现象与人事的科学因果。

亲耕不等于全国恢复农业已经完成；本年减租与前167年免田租不是同一诏令。去诽谤妖言有明确语境，不译为现代一切言论绝对免责；高后前187年曾去妖言令，与本次再提的关系留待制度考察，不伪造一个未见于材料的全面恢复禁令年月。铜虎符、竹使符不凭一句话画成全部行政程序。

<a id="2卷017的六王封月地理与继承"></a>
#### 2｜卷017的六王封月、地理与继承

[卷017前178年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0178)把六王初封统一列二月乙卯，本纪、[汉书文帝纪](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-07ff0bb0117120)及通鉴为三月，正文保留既有三月；元年与授命日不强称无异说。梁王史表作胜，本纪、汉书作揖，仍识为同一位文帝子，不造两人。[前179年原格](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0179)的河间乐成、太原晋阳及初置国栏作为本次分国的先导，不能凭横向排版提前另封一次。

楚郢客、齐则的继承与[楚元王世家](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7050.md#ref-7c4e24bc5608a7)、[齐悼惠王世家](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7052.md#ref-f28682e4a2f475)合读。琅邪改郡是刘泽前179年迁燕的后续，不另产生一次迁王；刘泽死于本年，刘嘉元年另见下一年。

长沙采用[汉书异姓诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7013.md#ref-99c32541561fda)文帝二年“靖王产嗣”，共二十二年到前157年；史表前177年“靖王著元年”、二十一年亦到前157年。两表姓名、起年不同，死亡终点相接，暂以汉表的承继顺序记本年，不擅造受位后改名或在位空缺。

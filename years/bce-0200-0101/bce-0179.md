# 公元前179年条｜刘恒安定新朝，除收孥相坐，立太子与皇后

[← 公元前180年](bce-0180.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前178年 →](bce-0178.md)

**汉文帝前元年**

> 冬十月为古历岁首，紧接上一页后九月刘恒即位，不是现代公历前179年10月才开始施政。以下保留古月，不逐日换算。

## 冬季，先安排封国、相位和迎立者

**十月庚戌，刘泽由琅邪迁王燕，刘友之子刘遂接回赵王名号。** 燕国交给参与议立的宗室，赵国回到被吕后饿死的刘友一支。此前吕氏占去的齐、楚故地也陆续归还。[1](#sj009-restoration)

**刘恒谒高庙，又派薄昭回代地迎接母亲。** 中央随后调整相位：周勃任右丞相，陈平改左丞相，灌婴接太尉。新君并未立即排斥拥立自己的旧臣，而是先承认他们的功劳与位置。[2](#sj010-court)

**诛吕功臣得到增户、赐金，刘揭封阳信侯。** 周勃所得最多，增万户、金五千斤；陈平、灌婴各增三千户；刘章、纪通、刘兴居各增二千户。诏书把灌婴停军、夺北军及诛吕产列成新朝的功劳依据。[2](#sj010-court)

<a id="sj017-lu"></a>
**张敖与鲁元公主的儿子张偃失去鲁王名位，张氏改以侯爵延续。** 吕后在世时，他凭外孙身份受王号；吕后去世、政局更换以后，原来那套封王安排被撤去。文帝初年又以封侯保留张氏的奉祀，并不是张偃与少帝诸王一同被杀。[7](#sj017-note)

## 十二月，罪犯的无罪家人不应一并没官

**刘恒要求重议牵连父母、妻子、兄弟姐妹的收孥相坐法令。** 有司起初认为，连累家人能使犯罪者顾忌，沿用旧法比较稳妥。皇帝却说，官吏不能教人向善，又拿不正当的法惩罚无罪者，反而是在害民。经过再议，有司同意废去有关律令。[3](#sj010-law)

## 正月定储，三月立窦氏为皇后

**大臣请求立太子，刘恒先提出应否在宗室贤者中选择。** 他提到叔父楚王刘交、堂兄吴王刘濞、弟弟淮南王刘长；有司则坚持继承以子、延续高祖安排。最终刘启被立为太子，薄昭封轵侯，天下承父后者各赐爵一级。[4](#sj010-family)

**薄太后主张立太子母窦氏为皇后，朝廷照办。** 窦氏的弟弟广国年幼时被掳卖、多次易主，得知姐姐显贵后上书自陈；核实后与兄长长君同居长安。周勃等担心新外戚重演诸吕，给他们选择有节行的师友，不让骤得富贵变成骄纵的凭借。[4](#sj010-family)

**赈赐鳏寡孤独、贫困者与年长者，也成为这一年的政务。** 八十岁以上者按月给米肉酒，九十以上再给帛絮，并安排官员送达、巡察。宋昌因在代地力劝入京封壮武侯，随从人员获得升迁。[4](#sj010-family)

## 安抚旧臣与外家，周勃却主动退了一步

**曾随高祖入蜀、汉中的六十八名列侯各增三百户，旧官也分等增邑。** 赵兼为周阳侯、驷钧为清郭侯，秋又封蔡兼为樊侯。军事旧臣、先帝旧吏、诸王外家都在这次安定名分的安排中。[卷010 P011](../../sources/摘录/史记-卷010-孝文本纪.md#p011)。

**八月，周勃称病辞相，陈平独任丞相。** 有人提醒周勃，功劳大、奖赏重，又久居最高位置，可能招来危险。皇帝也渐熟悉政务，不再只是初入京时的谦让姿态。退相暂时减少了紧张，并未使周勃永远远离政治风波。[5](#sj010-boping)

## 南越恢复使者往来，不用一场战争解决帝号争端

**刘恒替赵佗在真定的亲属、祖墓作安排，再派陆贾出使。** 他愿放下此前冲突、恢复通使，承认岭南由南越自行治理，同时要求赵佗不要与汉以两个皇帝的名义相争。赵佗在对汉书信中改称臣，恢复奉贡关系。[6](#sj010-nanyue)

**楚王刘交、齐王刘襄也在本年去世。** 河南守吴公则被召为廷尉，推荐二十余岁的洛阳人贾谊入朝；贾谊倡议改正朔、服色、官名礼乐，刘恒还没有全盘实行。[《通鉴》卷十三元年](https://zh.wikisource.org/wiki/資治通鑑/卷013)。

## 本年相关史料

<a id="sj009-restoration"></a>
### 1｜原卷009册立记录保留

[卷009 P041](../../sources/摘录/史记-卷009-吕太后本纪.md#p041)曾把刘遂册立放在迎刘恒前；[卷010 P005—P006](../../sources/摘录/史记-卷010-孝文本纪.md#p005)、通鉴列元年十月，汉书则把燕赵迁立及归地置十二月。继续沿既有通鉴十月主线，不重复册立，旧锚点保留。

<a id="sj010-court"></a>
### 2｜相位与赏功不强并一日

[卷010 P006—P007](../../sources/摘录/史记-卷010-孝文本纪.md#p006)。本纪十月辛亥接调相，《通鉴》十一月辛巳，正文只称随后调整；高庙、迎母、颁赏各为步骤。所报金数、封户为诏书记数，不是已核实到账的财政账目；诏书对诛吕的定性是新君宣布的正当性理由。

<a id="sj010-law"></a>
### 3｜不等于废尽所有连坐

[卷010 P008](../../sources/摘录/史记-卷010-孝文本纪.md#p008) · [《汉书》卷023](https://zh.wikisource.org/wiki/漢書/卷023)。后者把除收孥概系文帝二年，本纪、文帝纪和通鉴为元年十二月，沿本纪年条，留异年。诏的对象是罪犯无罪家属受牵连、没官，不抹去后来大逆等案仍见族诛的记录。[刑制考证](../../meta/考证/史记-卷010-纪年与异说.md#刑制)。

<a id="sj010-family"></a>
### 4｜立储、立后与救济

[卷010 P009—P010](../../sources/摘录/史记-卷010-孝文本纪.md#p009) · [《汉书》卷004](https://zh.wikisource.org/wiki/漢書/卷004) · 通鉴元年。吴王是堂兄，不是同父兄长；讨论宗室贤者不等于已决定废弃父子继承。窦广国旧事是此前经历，不能全归本年；养老数量及配送责任取互见，年龄与爵制不套现代福利制度。

<a id="sj010-boping"></a>
### 5｜周勃第一次免相

[卷010 P012](../../sources/摘录/史记-卷010-孝文本纪.md#p012)与通鉴八月辛未。前178年复相、前177年就国是后续两次变化，不能只看“免相”两字便合并。吴公荐贾谊等补充不表示相关列传已全卷处理。

<a id="sj010-nanyue"></a>
### 6｜篇末总评中的有年事件

[卷010 P037](../../sources/摘录/史记-卷010-孝文本纪.md#p037)概述赵佗称臣，依通鉴本年展开。对汉称臣、去帝号是外交名分安排，不据此断言南越已并为汉郡或内部所有仪制都立即取消。四月齐楚地震、山崩水出及拒受千里马的补记亦见通鉴本年；数字与灾异不用于证明新君得失天命。

<a id="sj017-note"></a>
### 7｜卷017十一格的去向：张偃、燕赵及预列国栏

[卷017前179年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0179)鲁栏“九，废为侯”补[张偃条](#sj017-lu)；[《张耳陈馀列传》篇末](https://zh.wikisource.org/wiki/史記/卷089)将大臣废鲁王接在高后死后，继记文帝即位复封张偃为侯，称南宫侯；[汉书异姓诸侯王表](https://zh.wikisource.org/wiki/漢書/卷013)亦在高后八年记废。故正文交代从前180年政局更换到文帝初的衔接，不断言废王必发生在本年某月，更不安排两次相同废黜。后封的具体侯名、日期及与其他侯表条目的对应仍待专考，正文只写所能共同支持的王转侯与延续奉祀，不用一个侯号制造另一位张氏后人。

齐襄薨接本页年末王统，琅邪、燕两格是刘泽同一次迁封，赵遂接[原册立注](#sj009-restoration)。城阳、济北、河间、太原、梁五个初置／复置格为下一年分封的栏目先导，乐成、晋阳保留作地理说明，具体诸王授命及二月／三月之差见[前178年](bce-0178.md#sj017-note)。不能仅凭这些格位断定全部王国已在本年同日建成并就国。

代栏“十八，为文帝”是王统转入帝统的衔接，实际入京即位仍在[前180年后九月](bce-0180.md#sj008-heng)，不在文帝元年重演登基。纪元起点、受位、封国调整与后来的谥号分层处理。

<a id="sj018-restorations"></a>
## 新皇帝重排功臣封爵，樊氏和萧氏没有一并消失

**樊哙的另一位儿子市人被封回舞阳，继续家族的祭祀与爵位。** 前一年被诛的是吕媭之子樊伉，新受封的市人不是同一个人死而复生。新朝既清除吕氏，又以另一支子嗣恢复开国功臣的封国。[舞阳R018](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r018)

**萧何夫人同的侯爵被罢，原筑阳侯萧延改封为酂侯。** 萧延在吕后时已经受爵，本年只是换回父亲原来的国号，并非第一次成为侯。史表把同的处置写作“有罪”，汉书传记只说罢同、更封延；正文不据一个短语为她增添未经记载的具体罪案。[酂R015](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r015)

**张偃由鲁王转为侯的安排，也进入了功臣侯籍。** 本表在宣平侯张敖一行下写“以故鲁王为南宫侯”，与列传互见。它接续的是前一年废鲁王后的处理，不是张偃再获得一次鲁王号。[宣平R103](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r103)

<a id="sj018-note"></a>
### 卷018｜九家承爵、三项恢复调整与相位互见

上表实际为九家承爵，标题所称数量以此九项为准；清阳、曲周、费、貰、曲城、河阳、安国、厌次、柏至均有本年元年。曲城后面“有罪绝”不是在元年马上失爵，后续有具体年次再分别说明；厌次贺的失国在史、汉两表年次不同，也不由本年元年推定同年判刑。

萧氏关系据[《汉书·萧何曹参传》](https://zh.wikisource.org/wiki/漢書/卷039)及[汉书功臣表](https://zh.wikisource.org/wiki/漢書/卷016)：同为夫人、禄母，延为少子。史表的“同，禄弟”与这一关系不合，原字留在源文，本页采用表传较明确的女性身份。延后来在位年数与子孙起年又有差别，不用一条“十九年”抹去对照材料。

张偃的南宫侯称号在卷018与卷089相合，较卷017只写“废为侯”多一层信息；与其他侯表中张氏诸人、侯号的精确对应仍保留待核，未据此新增一个未经辨认的张氏国君。厌次父名本表元顷、汉表爰类，柏至许温／许盎、曲城蛊逢／虫达等仍按行次与继承识别，不把异字分别登记为两家。

[绛R017](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r017)的周勃右相、[颍阴R019](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r019)灌婴太尉与[曲逆R009](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r009)陈平独相，都接本页旧政务，不重复任官。煮枣初封者史表在本年仍有一个纯计数格，与汉表惠七年死不合，正文沿[前188年](bce-0188.md#sj018-zhuzao)已说明的终局；次年前178年再封子式／武另记。

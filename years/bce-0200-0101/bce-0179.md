# 公元前179年条｜刘恒安定新朝，除收孥相坐，立太子与皇后

[← 公元前180年](bce-0180.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前178年 →](bce-0178.md)

**汉文帝前元年**

> 冬十月为古历岁首，紧接上一页后九月刘恒即位，不是现代公历前179年10月才开始施政。以下保留古月，不逐日换算。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="冬季先安排封国相位和迎立者"></a>

<a id="event-1"></a>

1. **十月庚戌，刘泽由琅邪迁王燕，刘友之子刘遂接回赵王名号。** 燕国交给参与议立的宗室，赵国回到被吕后幽禁断食而死的刘友一支。吕后死亡和诸吕被诛是前一古历年的前情。刘泽迁燕以后，琅邪归还齐国；城阳、济南诸郡也归齐，楚国旧地陆续恢复。城阳与济北另立为王国，是下一年的分封安排。 [[1]](#note-1)

<a id="event-2"></a>

2. **刘恒谒高庙，又派薄昭回代地迎接母亲。** 中央随后调整相位：周勃任右丞相，陈平改左丞相，灌婴接太尉。新君并未立即排斥拥立自己的旧臣，而是先承认他们的功劳与位置。 陈平先称病，向新帝说明高祖时己功多、诛吕时周勃功多，愿让右相；周勃位次第一，陈平为第二。 [[2]](#note-2)

<a id="event-3"></a>

3. **诛吕功臣得到增户、赐金，刘揭封阳信侯。** 周勃所得最多，增万户、金五千斤；陈平、灌婴各增三千户；刘章、纪通、刘兴居各增二千户。诏书把灌婴停军、夺北军及诛吕产列成新朝的功劳依据。 陈平除了三千户，也获金千斤。 [[3]](#note-3)

<a id="sj017-lu"></a>

<a id="event-4"></a>

4. **张敖与鲁元公主的儿子张偃失去鲁王名位，张氏改以侯爵延续。** 吕后在世时，他凭外孙身份受王号；吕后去世、政局更换以后，原来那套封王安排被撤去。文帝初年又以封侯保留张氏的奉祀，并不是张偃与少帝诸王一同被杀。 [[4]](#note-4)

<a id="十二月罪犯的无罪家人不应一并没官"></a>

<a id="event-5"></a>

5. **十二月，罪犯的无罪家人不应一并没官。** 刘恒要求重议牵连父母、妻子、兄弟姐妹的收孥相坐法令。 有司起初认为，连累家人能使犯罪者顾忌，沿用旧法比较稳妥。皇帝却说，官吏不能教人向善，又拿不正当的法惩罚无罪者，反而是在害民。经过再议，有司同意废去有关律令。 [[5]](#note-5)

<a id="正月定储三月立窦氏为皇后"></a>

<a id="event-6"></a>

6. **正月，刘启被立为太子。** 大臣请求立太子，刘恒先提出应否在宗室贤者中选择。 他提到叔父楚王刘交、堂兄吴王刘濞、弟弟淮南王刘长；有司则坚持继承以子、延续高祖安排。最终刘启被立为太子，天下承父后者各赐爵一级。同在文帝元年，薄昭受封轵侯，食邑万户。他是薄太后之弟，曾从代地到长安核实迎立之意，又以车骑将军迎接太后。 刘恒原先的代王后在他入继帝位以前已死，所生四个儿子又先后病死；窦姬之子刘启因而是当时尚存皇子中年最长者。 [[6]](#note-6)

<a id="event-7"></a>

7. **三月，窦氏被立为皇后。** 薄太后主张立太子母窦氏为皇后，朝廷照办，女儿刘嫖为长公主。立后初期，失散的弟弟窦广国上书求认亲。他字少君，四五岁时家贫被人劫卖，辗转十余家，后来在宜阳替主人入山烧炭。一百多人同宿岸下，岸崩，只有他脱险；他占卜自信将显达，随主人到长安，得知新皇后姓窦、家在观津，又记得自己小时候同姐姐采桑坠落，便据此上书。皇后禀告文帝，召见核问，广国又说姐姐西行时曾在传舍与他告别，讨来洗头水为他洗沐，讨饭给他吃。窦后抱着他大哭，左右侍从也伏地陪泣。朝廷厚赐田宅金钱，安置他和哥哥窦长君等亲属居长安。周勃、灌将军等担心新外戚重演诸吕，认为自己与国家的安危将系于这两人，于是给他们选有节行的长者作师友同住。兄弟由此退让守礼，不敢因骤得尊贵而骄人。 [[7]](#note-7)

<a id="event-8"></a>

8. **赈赐鳏寡孤独、贫困者与年长者，也成为这一年的政务。** 八十岁以上者按月给米肉酒，九十以上再给帛絮，并安排官员送达、巡察。宋昌因在代地力劝入京封壮武侯，随从人员获得升迁。 [[8]](#note-8)

<a id="安抚旧臣与外家周勃却主动退了一步"></a>

<a id="event-9"></a>

9. **列侯、旧官获增邑，部分外家受封。** 曾随高祖入蜀、汉中的六十八名列侯各增三百户，旧官也分等增邑。 赵兼为周阳侯、驷钧为清郭侯，秋又封蔡兼为樊侯。军事旧臣、先帝旧吏、诸王外家都在这次安定名分的安排中。 [[9]](#note-9)

<a id="event-10"></a>

10. **八月，周勃称病辞相，陈平独任丞相。** 在此前首次右相任内，文帝曾问一年决狱数、钱谷收支，周勃都不知道，汗湿背脊；陈平答应分别问廷尉、治粟内史。皇帝追问宰相管什么，他说明应上辅天子顺四时、下育万物，外镇抚诸侯四方，内使百姓亲附，并使百官各尽其职。退朝后周勃责他未先教自己，陈平反问岂能不知职任、又岂能遇问长安盗贼数便勉强作答。问答未载月日；后来又有人提醒周勃功高赏厚而久居尊位的风险，他于是称病免相，陈平独任。 劝者又具体指出，周勃诛吕、立代王，威震天下，如今厚赏尊位都已得到，久居恐有祸。周勃听后恐惧，辞交相印，获得准许。 [[10]](#note-10)

<a id="南越恢复使者往来不用一场战争解决帝号争端"></a>

<a id="event-11"></a>

11. **南越恢复使者往来，不用一场战争解决帝号争端。** 刘恒替赵佗在真定的亲属、祖墓作安排，再派陆贾出使。 他愿放下此前冲突、恢复通使，承认岭南由南越自行治理，同时要求赵佗不要与汉以两个皇帝的名义相争。赵佗在对汉书信中改称臣，恢复奉贡关系。 [[11]](#note-11)

<a id="event-12"></a>

12. **楚王刘交、齐王刘襄也在本年去世。** 刘交自高祖六年受楚，至今首尾二十三年；太子辟非先卒，由任宗正、受封上邳侯的儿子郢客接楚，下一年记夷王元年。河南守吴公则被召为廷尉，推荐二十余岁的洛阳人贾谊入朝；贾谊倡议改正朔、服色、官名礼乐，刘恒还没有全盘实行。 [[12]](#note-12)

<a id="sj018-wenjing"></a>
<a id="功臣侯家的承袭与兴废"></a>


<a id="event-13"></a>

13. **樊哙的另一子市人恢复舞阳侯爵。** 前一年因吕氏亲缘被诛的是樊伉，继承爵位的市人是另一人。新朝没有让开国功臣樊氏的奉祀随诛吕一并断绝。 [[13]](#note-13)

<a id="event-14"></a>

14. **萧何夫人同被罢侯，原筑阳侯萧延改封为酂侯。** 萧延在吕后时已经受爵，本年是改接父亲旧封。萧氏因此继续列侯，而不是萧何本人重新受封。 [[14]](#note-14)

<a id="sj050-cite-016"></a>

**[卷050 P007完整原字与白话](../../sources/摘录/史记-卷050-楚元王世家.md#p007)**

> 趙王劉遂者，其父高祖中子，名友，謚曰「幽」。幽王以憂死，故為「幽」。高后王呂祿於趙，一歲而高后崩。大臣誅諸呂呂祿等，乃立幽王子遂為趙王。

**白话：** 赵王刘遂的父亲名叫刘友，是高祖的儿子之一，谥号幽王。本篇用“忧死”解释“幽”这个谥号；与《汉书》及前面吕后本纪合读，他是在吕后召入长安、加以幽禁断食的情况下死去，并非只因普通忧愁病死。吕后后来把吕禄封为赵王，过了一年吕后去世。互校本纪与将相年表，吕禄受赵在高后七年、前181，吕后去世和诛吕在次年、前180；“一岁”不能译成受封与吕后死亡都在同一年。大臣诛杀吕禄等诸吕以后，恢复刘友一支，让刘友的儿子刘遂做赵王。此段略过中间刘恢等赵王的更换，是为介绍刘遂追述家世，不能当作赵国各王的完整连续名单。刘遂册立沿年表及文帝本纪的元年十月年条，接前179；诛吕则在前180，两者跨古历岁首。

**本卷辨析：** 刘友在前181被幽禁断食而死；吕禄同年受赵，次年前180吕后去世、诸吕被诛。“一岁”读作过了一年。受赵的高后七年见[吕后本纪P027](../../sources/摘录/史记-卷009-吕太后本纪.md#p027)及[将相表R026](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r026)；诸侯王表把吕禄元年列在前180，应区别受王与王年。这里只作新立刘遂的家世前情，前179元年十月采用史表与文帝本纪；吕后本纪放在迎帝前的异年另保留于前180旧注。

#### 卷025｜文帝拒议远征的在位期互见

[《律书》P009—P010](../../sources/摘录/史记-卷025-律书.md#p009)记将军陈武等请征南越、朝鲜，文帝以战争即使获胜也会耗损百姓为由拒绝，转而强调边防、通使和休息。这段只说“历至孝文即位”，没有独立年次；本页是文帝朝的阅读入口，**不据此认定本次廷议发生于前元年**。末尾粟价、无内外徭和老者嬉游也是治世概赞，不作前179年全国逐项统计。

本页原有陆贾通南越是有据的前元年史事，见[《南越列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7113.md#ref-0bc20cc559f467)；不能由二者都主张息兵，就合成同一天的一场会议。《朝鲜列传》又分秦辽东外徼、汉初修故塞及惠高后时约卫满为外臣等阶段，详见[原传](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7115.md#ref-cb702e2ade3025)，不把议兵者的概括推成当时各地政治地理的完整实录。

陈武与陈平分人；[《孝文本纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7010.md#ref-dc1f3493287bbb)文三年的棘蒲侯陈武，与[《汉书·文帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-b0a5453808ff0b)同一征济北位置的柴武互见，不能仅凭姓陈把他并为丞相陈平，亦不能借前177年明记的军职给本次议兵补一个日期。文帝时期另有对匈奴用兵，所拒的远征主张不等于整个在位期完全无军役或战事。

#### 1｜原卷009册立记录保留

[卷009 P041](../../sources/摘录/史记-卷009-吕太后本纪.md#p041)曾把刘遂册立放在迎刘恒前；[卷010 P005—P006](../../sources/摘录/史记-卷010-孝文本纪.md#p005)、通鉴列元年十月，汉书则把燕赵迁立及归地置十二月。继续沿既有通鉴十月主线，不重复册立，旧锚点保留。

<a id="sj010-court"></a>
<a id="2相位与赏功不强并一日"></a>
#### 2｜相位与赏功不强并一日

[卷010 P006—P007](../../sources/摘录/史记-卷010-孝文本纪.md#p006)。本纪十月辛亥接调相，《通鉴》十一月辛巳，正文只称随后调整；高庙、迎母、颁赏各为步骤。所报金数、封户为诏书记数，不是已核实到账的财政账目；诏书对诛吕的定性是新君宣布的正当性理由。

<a id="sj010-law"></a>
<a id="3不等于废尽所有连坐"></a>
#### 3｜不等于废尽所有连坐

[卷010 P008](../../sources/摘录/史记-卷010-孝文本纪.md#p008) · [《汉书》卷023](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7023.md#ref-73e14d3801c12f)。后者把除收孥概系文帝二年，本纪、文帝纪和通鉴为元年十二月，沿本纪年条，留异年。诏的对象是罪犯无罪家属受牵连、没官，不抹去后来大逆等案仍见族诛的记录。[刑制考证](../../meta/考证/史记-卷010-纪年与异说.md#刑制)。

<a id="sj010-family"></a>
<a id="4立储立后与救济"></a>
#### 4｜立储、立后与救济

[卷010 P009—P010](../../sources/摘录/史记-卷010-孝文本纪.md#p009) · [《汉书》卷004](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7004.md#ref-4a9e6856b95f9a) · 通鉴元年。吴王是堂兄，不是同父兄长；讨论宗室贤者不等于已决定废弃父子继承。窦广国旧事是此前经历，不能全归本年；养老数量及配送责任取互见，年龄与爵制不套现代福利制度。

<a id="sj010-boping"></a>
<a id="5周勃第一次免相"></a>
#### 5｜周勃第一次免相

[卷010 P012](../../sources/摘录/史记-卷010-孝文本纪.md#p012)与通鉴八月辛未。前178年复相、前177年就国是后续两次变化，不能只看“免相”两字便合并。吴公荐贾谊等补充不表示相关列传已全卷处理。

<a id="sj010-nanyue"></a>
<a id="6篇末总评中的有年事件"></a>
#### 6｜篇末总评中的有年事件

[卷010 P037](../../sources/摘录/史记-卷010-孝文本纪.md#p037)概述赵佗称臣，依通鉴本年展开。对汉称臣、去帝号是外交名分安排，不据此断言南越已并为汉郡或内部所有仪制都立即取消。四月齐楚地震、山崩水出及拒受千里马的补记亦见通鉴本年；数字与灾异不用于证明新君得失天命。

<a id="sj017-note"></a>
<a id="7卷017十一格的去向张偃燕赵及预列国栏"></a>
#### 7｜卷017十一格的去向：张偃、燕赵及预列国栏

[卷017前179年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0179)鲁栏“九，废为侯”补[张偃条](#sj017-lu)；[《张耳陈馀列传》篇末](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7089.md#ref-ae89aaad6f553e)将大臣废鲁王接在高后死后，继记文帝即位复封张偃为侯，称南宫侯；[汉书异姓诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7013.md#ref-3022cf391974db)亦在高后八年记废。故正文交代从前180年政局更换到文帝初的衔接，不断言废王必发生在本年某月，更不安排两次相同废黜。后封的具体侯名、日期及与其他侯表条目的对应尚待专考，正文只写所能共同支持的王转侯与延续奉祀，不用一个侯号制造另一位张氏后人。

齐襄薨接本页年末王统，琅邪、燕两格是刘泽同一次迁封，赵遂接[原册立注](#sj009-restoration)。城阳、济北、河间、太原、梁五个初置／复置格为下一年分封的栏目先导，乐成、晋阳保留作地理说明，具体诸王授命及二月／三月之差见[前178年](bce-0178.md#sj017-note)。不能仅凭这些格位断定全部王国已在本年同日建成并就国。

代栏“十八，为文帝”是王统转入帝统的衔接，实际入京即位仍在[前180年后九月](bce-0180.md#sj008-heng)，不在文帝元年重演登基。纪元起点、受位、封国调整与后来的谥号分层处理。

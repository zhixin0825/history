# 公元前180年｜吕后去世，诸吕被诛，少帝也被废杀，刘恒入继

[← 公元前181年](bce-0181.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前179年条 →](bce-0179.md)

**高后八年；皇帝弘被废杀，刘恒本年即位**

> 本页按汉初古史整年对应归档，十月在正月以前。“后九月”为闰月表达，不直接换成公历九月。诛吕的庚申究竟系八月还是九月，两书有分歧，详下注；叙事不合并夺军、杀吕产、清洗族属和废杀皇帝这几个阶段。

## 冬十月，燕王改姓吕；春夏继续封赏

**吕台之子吕通被立为燕王，他的弟弟吕庄成为东平侯。** 前一年的燕王刘建死亡、幼子被杀，至此由吕氏接下王国名号。[1](#sj009-last-regency)

**四月，张侈、张寿受封，帮助年幼的鲁王张偃。** 张偃已失去父亲张敖和母亲鲁元公主，太后把张敖前姬所生的两子分别封为新都侯、乐昌侯，借同父兄弟扶助他。张释获建陵侯，吕荣获祝兹侯，宫中令丞一批人又受关内侯、食邑五百户的赏赐。[1](#sj009-last-regency)

**江、汉发生洪水，万余家流离。** 前185年的水患不是此后唯一一次灾害。南方周灶军也受暑湿、疫病所困，未能顺利越岭进攻南越。[1](#sj009-last-regency)

<a id="sj009-lastwords"></a>
## 七月，吕后临终要求诸吕守住军队

**吕后病重，让吕禄以赵王兼上将军身份掌北军，吕产居南军。** 她提醒两人，非刘氏封王使大臣不满，自己死后皇帝年少，局势容易有变；务必掌兵守宫，不要因为送丧而落入别人控制。[2](#sj009-death-note)

**七月辛巳，吕后去世，遗诏大赦并按等级赐金。** 诸侯王各千金，将相列侯及郎吏依秩受赐；吕产为相国，吕禄女被立为皇后。安葬以后，左丞相审食其改为皇帝太傅。宫廷权位表面上有所安排，但大臣、宗室与诸吕之间的信任已经十分脆弱。[2](#sj009-death-note)

## 八月，齐王刘襄先动兵，灌婴却不肯替吕氏打齐

**刘章通过吕氏妻子获知宫中消息，暗中联络哥哥齐王刘襄。** 他希望齐军向西，自己和刘兴居在京配合，诛吕以后拥立齐王。齐相召平反对无朝廷符验的发兵，派兵看守王宫，魏勃却骗取兵权，反过来包围相府，召平自杀。齐王于是重组将相、动员全国兵力。[3](#sj009-qi-note)

**齐国还用计取得了琅邪王刘泽的军队。** 祝午以请老将主持大计为由，把刘泽请到临淄扣留，合并琅邪兵。刘泽又以入京帮助齐王争帝位为说辞，才获准离开。争夺吕氏权力的刘氏诸王之间，也有欺骗、扣留和利益竞争。[3](#sj009-qi-note)

**吕产派灌婴讨齐，灌婴到荥阳却停下。** 他判断若替吕氏击破齐国，反会增强吕氏的实力，便派人与齐及其他诸侯联络，约定共同对付诸吕。齐军停在西界等待，吕产、吕禄既怕外军，也怕京中的周勃、刘章，未能迅速决定怎样动手。[4](#sj009-armies-note)

## 太尉并不能直接领兵，先要让吕禄交出印信

**周勃名义上是太尉，却不能进入北军主持军事。** 陈平、周勃扣住病中的曲周侯郦商，利用他的儿子郦寄与吕禄的友谊，让郦寄去劝吕禄：交出将印，和大臣盟约，然后回赵国为王，外面的齐兵自然会退。[4](#sj009-armies-note)

**吕禄相信有和平退场的可能，吕氏内部却意见不一。** 姑母吕媭大怒，认为一旦放弃军队，吕氏便无处容身，把珠玉宝器倒在堂下，不肯替别人守财。郦寄的保证最终并没有变成对吕禄的实际保护。[4](#sj009-armies-note)

<a id="sj009-northarmy"></a>
## 庚申，周勃取得北军，刘章转入未央宫

**平阳侯曹窋听见贾寿向吕产报告灌婴与齐楚联络的消息，赶去通知陈平、周勃。** 负责符节的纪通持节假传，帮助周勃进入北军；郦寄和典客刘揭再次催吕禄交印，称这是皇帝的命令。吕禄把印交给刘揭，离开军营。[5](#sj009-coup-date)

**周勃命士卒表态：为吕氏右袒，为刘氏左袒。** 士卒都左袒，北军由此听命周勃。但南军仍在，夺到一处军营并不等于京城局势已经全部决定。[5](#sj009-coup-date)

**陈平召刘章协助，周勃又派人堵住殿门，不让吕产进入。** 吕产还不知道北军已经易手，来到未央宫后徘徊不进。周勃仍怕不能取胜，没有立即公开宣布全面诛吕，而是命刘章带千余人急入宫“卫帝”。[5](#sj009-coup-date)

<a id="sj009-purge"></a>
## 吕产被杀以后，行动扩大为诛灭族属

**刘章在宫廷中攻击吕产，追至郎中府的厕所将他杀死。** 少帝随后派持节使者慰劳刘章，刘章想拿走符节，使者不肯；他便与使者同车，借节信进入长乐，杀卫尉吕更始，然后回北军报功。[6](#sj009-purge-note)

**周勃确认吕产已死，才放手派人搜捕诸吕。** 清洗不只针对两名掌兵者，还波及男女老幼。次日辛酉，吕禄被杀，吕媭遭笞杀，又派人杀燕王吕通，废去张偃的鲁王号。并不是所有遇害者都分别记有参与军事行动的证据。[6](#sj009-purge-note)

**壬戌，审食其恢复左丞相；戊辰，济川王太暂迁为梁王。** 刘章去告齐国罢兵，灌婴也从荥阳撤军。这些短暂安排发生在另选皇帝以前，虽很快被改变，仍是局势变化的一部分。[7](#sj009-interim)

## 诛吕之后，大臣又决定不要留下原来的皇帝

**他们声称少帝及梁、淮阳、恒山诸王都不是惠帝亲生，应该另立。** 同一段谋议里，他们又担心，既然已杀尽诸吕，若保留这些由吕后扶立的孩子，孩子长大后可能向他们报复。血统指控与参与者自身的安全考虑，在这里同时出现。[8](#sj009-lineage)

**刘襄没有成为皇帝，淮南王刘长也未获选。** 齐王虽是高祖长孙，大臣担心他的母家驷氏又形成强大的外戚；刘长年少，也被认为母家不宜。最后大家选择仍在世的高祖之子刘恒，强调他年长、仁孝，薄氏亲族谨慎温和。[8](#sj009-lineage)

<a id="sj009-accession"></a>
## 后九月，刘恒到长安，入宫仍遇到守卫阻拦

**刘恒没有立即相信邀请。** 他先派薄昭探问，又让宋昌察看长安的局势。到了渭桥，大臣迎接，周勃要私下交谈，宋昌要求有公事就公开说；刘恒仍把正式商议留到代邸。[9](#sj008-heng)

**后九月晦己酉，群臣到代邸奉上玺符，刘恒推让后接受帝位。** 刘兴居与滕公夏侯婴先入宫，宣告少帝不当立，劝卫士放下兵器，将少帝载往少府。他们对新君报告宫中已经清理妥当。[9](#sj008-heng)

**刘恒当晚入未央宫，端门仍有十名持戟者拦住。** 守卫说天子还在里面，问来人凭什么进入；周勃又去劝说，守卫才弃兵退去。新君随后任宋昌镇抚南北军，张武主持殿中，接掌实际的宫廷防卫。[9](#sj008-heng)

**当夜，少帝弘及梁王太、淮阳王武、恒山王朝被分别杀死。** 先前动用“卫帝”名义打击吕产的联盟，最后也清除了他们名义上保护的皇帝。刘恒继位的过程，既有请尊与推让，也有军队移交、宫门对峙及对幼主诸王的杀戮。[8](#sj009-lineage) [9](#sj008-heng)

## 本年相关史料

<a id="sj009-last-regency"></a>
### 1｜年初封赏、洪灾与苍犬故事

[卷009 P028—P030](../../sources/摘录/史记-卷009-吕太后本纪.md#p028) · [《通鉴》卷十三八年](https://zh.wikisource.org/wiki/資治通鑑/卷013)。吕通是吕台之子，张侈张寿为张敖前姬子，不改变张偃是鲁元公主子的关系。关内侯与列侯有别，不因同段都称侯便合成同一爵制。江汉万余家水患见通鉴，不能与前185年数字混成一场灾害。

三月祓祭归途中见苍犬、被解释为刘如意作祟，及吕后腋伤，属本纪P029的神异与患病叙事。这里保留为传说，不据此认定鬼魂致病或追作现代疾病诊断。周灶军湿热疫病、太后死后撤军为通鉴次年回叙，本页只接其跨年后果，未另定返军日。

<a id="sj009-death-note"></a>
### 2｜遗诏、相国与皇后

[卷009 P031—P032](../../sources/摘录/史记-卷009-吕太后本纪.md#p031)。临终嘱守军与反对吕氏封王的白马盟相呼应，是人物所担心的危险，不是每一位大臣早已订好统一作战计划的证据。吕产任相国在本纪、通鉴为本年遗诏，《汉书》卷003七年已有任相国记载，差别留注，不造两次互不相干的任命。审食其改太傅、免左相、复左相结合读，不按三个句子造三次罢免。

<a id="sj009-qi-note"></a>
### 3｜齐相召平如何死

[卷009 P033](../../sources/摘录/史记-卷009-吕太后本纪.md#p033)简写齐王杀相，转指齐王事；[卷052《齐悼惠王世家》](https://zh.wikisource.org/wiki/史記/卷052)详写魏勃骗取兵权、召平自杀，通鉴采用后者，本页亦然。刘泽被留和获释的过程同据详细互见，不写成琅邪军自愿无条件送给齐王。齐王告诸侯的书信是政治宣言，其中分齐、杀王等控诉可和各年核对，不把所有动机仅靠书信定案。

<a id="sj009-armies-note"></a>
### 4｜归印游说与所谓谋乱

[卷009 P034—P036](../../sources/摘录/史记-卷009-吕太后本纪.md#p034)。本纪说诸吕有作乱意图又迟疑，灌婴等也以此解释自己的选择；本文记录所见行动，未编出一场已经发动、步骤完备的“吕氏篡汉战争”。郦寄在父亲受胁迫下游说吕禄，其保证不能当作后来双方确实履行过的和平协议。幼王留京而未就国，与吕禄吕产实际领军分开。

<a id="sj009-coup-date"></a>
### 5｜庚申：八月还是九月

[卷009 P038—P039](../../sources/摘录/史记-卷009-吕太后本纪.md#p038)和[《汉书》卷003](https://zh.wikisource.org/wiki/漢書/卷003)系八月庚申，所据[《通鉴》卷十三](https://zh.wikisource.org/wiki/資治通鑑/卷013)却系九月庚申。本页以庚申、辛酉等相对次序叙述，编年串联暂随通鉴，**不声称月份已统一，也不未经历算给出唯一公历日期**。纪通掌节、吕禄交印、士卒左袒都是实际接管的不同步骤，不因周勃已有太尉号便写成他一直控制北军。

<a id="sj009-purge-note"></a>
### 6｜清洗范围及皇帝曾经的作用

[卷009 P039—P040](../../sources/摘录/史记-卷009-吕太后本纪.md#p039)。刘章借皇帝使者的节信杀吕更始，说明这一阶段仍在利用少帝权威；族属随后被普遍搜捕，不能全称作战斗中击毙的军人。日餔、大风与吕产逃入吏厕是本纪叙事细节，不据此绘制未经地理核验的宫中战斗图。

<a id="sj009-interim"></a>
### 7｜刘太的短暂迁梁与刘遂册立异年

[卷009 P041](../../sources/摘录/史记-卷009-吕太后本纪.md#p041)的济川王太迁梁照录为本年短暂安排，因此被杀时称梁王。它同时写立刘遂为赵王，通鉴则明确列在文帝前元年冬十月庚戌，采用[前179年条](bce-0179.md)，此处留异年，不重复册立一次。刘章报齐罢兵、灌婴返军分别保留。

<a id="sj009-lineage"></a>
### 8｜血统指控没有变成编者的确定结论

[卷009 P042、P044](../../sources/摘录/史记-卷009-吕太后本纪.md#p042)把“非真孝惠子”置于群臣密议中，同时明写他们担心日后遭报复。此前张皇后养子并不自动证明孩子不是惠帝之子；本页只称群臣如此主张，不写成已用独立材料查明他们都姓吕。反过来，现有文本也不足以逐一证成生父，相关疑问保留在[考证](../../meta/考证/史记-卷009-纪年与异说.md#少帝与血统)。

<a id="sj008-heng"></a>
### 9｜原有迎立记录与实际交权

[卷008 P070](../../sources/摘录/史记-卷008-高祖本纪.md#p070)原有落点、锚点保留；[卷009 P043—P044](../../sources/摘录/史记-卷009-吕太后本纪.md#p043)及通鉴补足过程。宦者令在本纪作张泽、通鉴作张释，不未经核校便与同年建陵侯确认为同一人，正文称官职即可。后九月即位在前180年，文帝前元年为前179年；翌日、翌年古史年条的边界不直接等同公历年界。

卷末“二十三年崩”远接刘恒死亡，另落[前157年](bce-0157.md)，不是这次入宫之后立即去世。太史公对惠帝、高后时期民生休息的整体评价，与以上宫廷暴力分层阅读，见[本卷论赞](../../meta/考证/史记-卷009-纪年与异说.md#论赞)。

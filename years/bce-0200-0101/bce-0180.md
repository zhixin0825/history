# 公元前180年｜吕后去世，诸吕被诛，少帝也被废杀，刘恒入继

[← 公元前181年](bce-0181.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前179年条 →](bce-0179.md)

**高后八年；皇帝弘被废杀，刘恒本年即位**

> 本页按汉初古史整年对应归档，十月在正月以前。“后九月”为闰月表达，不直接换成公历九月。诛吕的庚申究竟系八月还是九月，两书有分歧，详下注；叙事不合并夺军、杀吕产、清洗族属和废杀皇帝这几个阶段。

[本年相关史料](#sources-start)

<a id="冬十月燕王改姓吕春夏继续封赏"></a>

<a id="event-1"></a>

1. **冬十月，吕通被立为燕王。** 吕台之子吕通被立为燕王，他的弟弟吕庄在同年成为东平侯。 前一年的燕王刘建死亡、幼子被杀，至此由吕氏接下王国名号。 [[1]](#note-1)

<a id="event-2"></a>

2. **四月，张侈、张寿受封，帮助年幼的鲁王张偃。** 张偃已失去父亲张敖和母亲鲁元公主，太后把张敖前姬所生的两子分别封为新都侯、乐昌侯，借同父兄弟扶助他。张释获建陵侯，吕荣获祝兹侯，宫中令丞一批人又受关内侯、食邑五百户的赏赐。 [[2]](#note-2)

<a id="event-3"></a>

3. **江、汉发生洪水，万余家流离。** 前185年的水患不是此后唯一一次灾害。南方周灶军也受暑湿、疫病所困，未能顺利越岭进攻南越。 高后去世后，这路军队撤回。 [[3]](#note-3)

<a id="sj009-lastwords"></a>
<a id="七月吕后临终要求诸吕守住军队"></a>

<a id="event-4"></a>

4. **七月，吕后临终要求诸吕守住军队。** 吕后病重，让吕禄以赵王兼上将军身份掌北军，吕产居南军。 她提醒两人，非刘氏封王使大臣不满，自己死后皇帝年少，局势容易有变；务必掌兵守宫，不要因为送丧而落入别人控制。 [[4]](#note-4)

<a id="event-5"></a>

5. **七月辛巳，吕后去世，遗诏大赦并按等级赐金。** 诸侯王各千金，将相列侯及郎吏依秩受赐；吕产为相国，吕禄女被立为皇后。吕后葬入长陵陵区，与高祖同茔。安葬以后，左丞相审食其改为皇帝太傅。宫廷权位表面上有所安排，但大臣、宗室与诸吕之间的信任已经十分脆弱。 [[5]](#note-5)

<a id="八月齐王刘襄先动兵灌婴却不肯替吕氏打齐"></a>

<a id="event-6"></a>

6. **八月，齐王刘襄在弟弟刘章的联络下动员兵力。** 吕后死后，吕禄为上将军、吕产为相国，聚兵留京；本篇称诸吕有变乱之谋。刘章通过吕禄之女、自己的妻子获知消息，暗中通知兄长，想让齐军西进，自己与刘兴居内应，诛吕后立齐王为帝。刘襄同舅父驷钧、郎中令祝午、中尉魏勃密谋。齐相召平派卒围守王宫，魏勃骗他说：齐王没有汉廷虎符却想发兵，相君围王做得对，请把看守部队交给自己。召平信了，魏勃取得兵权后却转围相府。召平叹道，道家所谓“当断不断，反受其乱”，正是自己的遭遇，遂自杀。齐王任驷钧为相、魏勃为将军、祝午为内史，征发全国军队。 [[6]](#note-6)

<a id="event-7"></a>

7. **齐国用计取得琅邪王刘泽的军队，刘泽又借拥齐之说脱身。** 祝午告诉刘泽，齐王年少、不熟悉战争，愿把全国交给曾随高帝作战的老将刘泽；齐王不敢离开军队，所以请他到临淄商议，并率齐军向西平乱。刘泽信以为真赶来，却被齐王、魏勃留住，祝午另征发琅邪全军并入齐军。刘泽不能返国，转而对齐王说：悼惠王是高帝长子，推下来齐王是嫡长孙，应当继位；大臣迟疑，而自己在刘氏宗族年龄最长，正在等自己决计，留在齐无用，不如让自己入关。齐王相信，增备车辆送他离开。这是两边为取兵、脱身作出的政治说辞。《荆燕世家》则说刘泽主动与齐合谋，到梁后还兵守西界，自己急驰长安；古注已指出两传分别突出本国之功，两种叙法并存。 [[7]](#note-7)

<a id="event-8"></a>

8. **齐军攻济南并致书诸侯，灌婴奉命讨齐却驻兵荥阳。** 刘泽离开后，齐军向西进攻吕国占有的济南。刘襄给诸侯王写信，声称：“高帝平定天下，让儿子和宗族亲属封王，让悼惠王治理齐国。悼惠王死后，惠帝派留侯张良立我为齐王。惠帝死后，吕太后掌权，年纪大了，听任吕氏擅自废弃高帝所立的王，又杀三位赵王，灭掉梁、燕、赵的王统来封诸吕，把齐分成四块。忠臣进谏，她却受蒙蔽而不听。如今太后死了，皇帝年幼，还不能治理天下，本须倚靠大臣诸侯。诸吕又擅自提高自己的官位，聚兵树威，胁迫列侯忠臣，假托皇帝命令号令天下，使宗庙处于危险之中。我现在率军入关，要诛杀那些不该称王的人。”这封信是一方为发兵申明的政治理由，三赵之死、分齐与各次废立有各自年代，不全部变成此次新发生的事件；“分齐四”按索隐是济南、琅邪、城阳与余下齐国。 汉廷听说齐军西进，吕产派大将军灌婴往东迎击。灌婴到了荥阳，判断：“诸吕带兵留在关中，想危害刘氏而自立；如果我击破齐国回报，反而是给吕氏增加力量。”于是停兵荥阳，派使者告诉齐王和其他诸侯，与他们联合，等待吕氏行动时共同诛除。齐王听到消息，向西夺回原济南郡，也把军队驻在齐国西部边界，等待约定中的行动。灌婴的判断和吕产下达的任务不同，不能把停军简单写成汉廷已共同决定支持齐王称帝。 吕产、吕禄既怕外军，也怕京中的周勃、刘章，未能迅速决定怎样行动。 [[8]](#note-8)

<a id="太尉并不能直接领兵先要让吕禄交出印信"></a>

<a id="event-9"></a>

9. **太尉并不能直接领兵，先要让吕禄交出印信。** 周勃名义上是太尉，却不能进入北军主持军事。 陈平、周勃扣住病中的曲周侯郦商，利用他的儿子郦寄与吕禄的友谊，让郦寄去劝吕禄：交出将印，和大臣盟约，然后回赵国为王，外面的齐兵自然会退。 周勃传同时概括吕禄为上将军、吕产为相国，太尉不得入军、丞相不得任事；危刘的判断是该传对政局的叙述，具体夺军仍按此页原事。 [[9]](#note-9)

<a id="event-10"></a>

10. **吕禄相信有和平退场的可能，吕氏内部却意见不一。** 姑母吕媭大怒，认为一旦放弃军队，吕氏便无处容身，把珠玉宝器倒在堂下，不肯替别人守财。郦寄的保证最终并没有变成对吕禄的实际保护。 [[10]](#note-10)

<a id="sj009-northarmy"></a>
<a id="庚申周勃取得北军刘章转入未央宫"></a>

<a id="event-11"></a>

11. **庚申，周勃进入北军，吕禄交出将印。** 平阳侯曹窋听见贾寿向吕产报告灌婴与齐楚联络的消息，赶去通知陈平、周勃。 负责符节的纪通持节假传，帮助周勃进入北军；郦寄和典客刘揭再次催吕禄交印，称这是皇帝的命令。吕禄把印交给刘揭，离开军营。 [[11]](#note-11)

<a id="event-12"></a>

12. **周勃命士卒表态：为吕氏右袒，为刘氏左袒。** 士卒都左袒，北军由此听命周勃。但南军仍在，夺到一处军营并不等于京城局势已经全部决定。 [[12]](#note-12)

<a id="event-13"></a>

13. **陈平召刘章协助，周勃又派人堵住殿门，不让吕产进入。** 吕产还不知道北军已经易手，来到未央宫后徘徊不进。周勃仍怕不能取胜，没有立即公开宣布全面诛吕，而是命刘章带千余人急入宫“卫帝”。 [[13]](#note-13)

<a id="sj009-purge"></a>
<a id="吕产被杀以后行动扩大为诛灭族属"></a>

<a id="event-14"></a>

14. **刘章诛杀吕产，又借符节杀吕更始。** 刘章在宫廷中攻击吕产，追至郎中府的厕所将他杀死。 少帝随后派持节使者慰劳刘章，刘章想拿走符节，使者不肯；他便与使者同车，借节信进入长乐，杀卫尉吕更始，然后回北军报功。 [[14]](#note-14)

<a id="event-15"></a>

15. **周勃确认吕产已死，才放手派人搜捕诸吕。** 清洗不只针对两名掌兵者，还波及男女老幼。次日辛酉，吕禄被杀，吕媭遭笞杀，又派人杀燕王吕通，废去张偃的鲁王号。并不是所有遇害者都分别记有参与军事行动的证据。 孝惠张皇后被留居北宫，没有随吕氏遭杀。 陈平传以“本谋”概括其谋划作用，与周勃掌兵和宗室、大臣分头行动合看。 《酷吏列传》称吕氏败后侯封家被捕。 [[15]](#note-15)

<a id="event-16"></a>

16. **壬戌，审食其恢复左丞相；戊辰，济川王太暂迁梁，齐军与灌婴军随后撤回。** 刘章去通知齐国罢兵。灌婴在荥阳听说魏勃原先劝齐发兵，召来责问，称其教齐王反。魏勃答：一家着火，哪来得及先告诉家长再救火！随即退立，腿抖战栗，像害怕得不能说话，没再作答。灌婴仔细看他，笑说人们称魏勃勇敢，其实不过庸人，能做什么，便放他离去。这些安排与撤兵发生在选立新帝过程中，梁王号虽然很快又变，仍须保留其短暂阶段。 [[16]](#note-16)

<a id="诛吕之后大臣又决定不要留下原来的皇帝"></a>

<a id="event-17"></a>

17. **诛吕之后，大臣又决定不要留下原来的皇帝。** 他们声称少帝及梁、淮阳、恒山诸王都不是惠帝亲生，应该另立。 同一段谋议里，他们又担心，既然已杀尽诸吕，若保留这些由吕后扶立的孩子，孩子长大后可能向他们报复。血统指控与参与者自身的安全考虑，在这里同时出现。 [[17]](#note-17)

<a id="event-18"></a>

18. **刘襄没有成为皇帝，淮南王刘长也未获选。** 齐王虽为高祖长孙，已经到长安的刘泽与大臣议论，却把齐王母家驷钧说成暴戾的“虎而冠者”，担心刚除吕氏，又出现强大的驷氏外家。他们称代王母家薄氏是君子长者，刘恒又是在世高帝儿子中年最长者；按亲子名分立他顺，认为其为人善良又能让大臣安心。刘长年少，也被议论者认为母家不宜，最终决定迎立刘恒。刘泽先前借拥齐之说离开齐国，最终在议立中却支持代王；这些人品评语是议立者表达的理由。 [[18]](#note-18)

<a id="sj010-welcome"></a>
<a id="代地先有一场争论迎立会不会是陷阱"></a>

<a id="event-19"></a>

19. **代地先有一场争论：迎立会不会是陷阱。** 张武等提醒刘恒，长安的大臣都是久经战阵、熟悉权谋的旧将。 他们刚在京城流血，现在以拥立为名来请代王，未必可以轻信，不如称病观察。中尉宋昌却认为，刘氏已得天下人心，宗室封国互相牵制，百姓也习惯了汉的政令；大臣即使想自立，也未必能让部众和诸侯共同服从。 [[19]](#note-19)

<a id="event-20"></a>

20. **刘恒与薄太后商议，仍派薄昭先去核实。** 薄昭回报可信，他才让宋昌参乘、张武等随行。在高陵休息时，又派宋昌先赴长安察看。这不是只靠一封邀请，就放心把自己交到新掌权者手里。 《孝文本纪》记刘恒与薄太后议而未定，卜得大横，随后遣薄昭核实迎立之意。 [[20]](#note-20)

<a id="sj009-accession"></a>
<a id="后九月刘恒到长安入宫仍遇到守卫阻拦"></a>

<a id="event-21"></a>

21. **后九月，刘恒抵达渭桥，大臣前来迎接。** 到了渭桥，大臣迎接，周勃要私下交谈，宋昌要求有公事就公开说。 刘恒把正式商议留到代邸，并非周勃在桥边奉上玺符以后，所有仪式就已结束。 [[21]](#note-21)

<a id="event-22"></a>

22. **后九月晦己酉，群臣到代邸奉上玺符，刘恒推让后接受帝位。** 刘兴居与滕公夏侯婴先入宫，宣告少帝不当立，劝卫士放下兵器，将少帝载往少府。他们对新君报告宫中已经清理妥当。 刘恒入继以后，母亲薄氏由代王太后改尊皇太后。 陈平传把诛吕、迎立文帝与审食其免相连叙；审食其不继续占有新朝左右丞相的位置。 [[22]](#note-22)

<a id="event-23"></a>

23. **刘恒当晚入未央宫，端门仍有十名持戟者拦住。** 守卫说天子还在里面，问来人凭什么进入；周勃又去劝说，守卫才弃兵退去。新君随后任宋昌镇抚南北军，张武主持殿中，接掌实际的宫廷防卫。 [[23]](#note-23)

<a id="event-24"></a>

24. **当夜，少帝弘及梁王太、淮阳王武、恒山王朝被分别杀死。** 先前动用“卫帝”名义打击吕产的联盟，最后也清除了他们名义上保护的皇帝。刘恒继位的过程，既有请尊与推让，也有军队移交、宫门对峙及对幼主诸王的杀戮。 [[24]](#note-24)

<a id="event-25"></a>

25. **新帝同夜颁布大赦，赐民爵一级，女子每百户给牛酒，准许大酺五日。** 诏书将新朝建立解释为将相诛吕、保全刘氏宗庙的结果，同时向普通民众宣布恩惠。庆贺新帝的诏令与旧帝被杀的过程，都在这一夜的叙事中，不能只保留其中一面。 [[25]](#note-25)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-26"></a>

26. **张苍在朝廷担任御史大夫。** 他此前有掌计、出任淮南相的经历；朝廷在迎立新君之外，也需要继续安排相职和监察官。 [原格与说明](#sj022-note)。 文帝即位时，曹窋被免去御史大夫官职，仍保留平阳侯爵；官职交接没有改变曹氏的家爵。 [[26]](#note-26)

<a id="sj095-event-27"></a>

27. **曲周侯郦商去世。** 郦商在高后八年去世，谥景，儿子郦寄承袭。前179年的曲周侯元年另依侯表。 [[27]](#note-27)

<a id="sj105-event-28"></a>

28. **临淄人淳于意从阳庆学医。** 临淄人淳于意年轻时爱好医术，高后八年改从元里的公乘阳庆。阳庆让他放下旧方，传授诊病、判断病势和药论等医书。淳于意后来任齐太仓长，这一官职的始年没有记载。 [[28]](#note-28)

<a id="hs-event-29"></a>

29. **张释卿与中官获封。** 封中谒者张释卿为列侯，其他中官及宦者令、丞受关内侯爵并有食邑。 [[29]](#hs-note-29)

<a id="hs-event-30"></a>

30. **安国武侯王陵｜承爵。** 表载安国武侯王陵一支本年记载侯位承袭。表中所载事项为哀侯忌承爵。 [[30]](#hs-note-30)

<a id="hs-event-31"></a>

31. **安平敬侯鄂秋｜承爵。** 表载安平敬侯鄂秋一支本年记载侯位承袭。表中所载事项为顷侯应承爵。 [[31]](#hs-note-31)

<a id="hs-event-32"></a>

32. **建成侯吕种｜获罪。** 表载建成侯吕种一支本年载相关罪案及处分。表中所载事项为反，诛。 [[32]](#hs-note-32)

<a id="hs-event-33"></a>

33. **建陵侯张释寺人｜免爵或免官。** 表载建陵侯张释寺人一支本年载免除或失爵。表中所载事项为失爵。 [[33]](#hs-note-33)

<a id="hs-event-34"></a>

34. **表载丞相变更，张苍任御史大夫。** 表载丞相变更，张苍任御史大夫。参见本年的官职变动原句。 [[34]](#hs-note-34)

### 1. 吕台之子吕通被立为燕王，他的弟弟吕庄在同年成为东平侯

<a id="3齐相召平如何死"></a>
#### 3｜齐相召平如何死

[卷009 P033](../../sources/摘录/史记-卷009-吕太后本纪.md#p033)简写齐王杀相，转指齐王事；[卷052《齐悼惠王世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7052.md#ref-f256977c844f47)详写魏勃骗取兵权、召平自杀，通鉴采用后者，本页亦然。刘泽被留和获释的过程同据详细互见，不写成琅邪军自愿无条件送给齐王。齐王告诸侯的书信是政治宣言，其中分齐、杀王等控诉可和各年核对，不把所有动机仅靠书信定案。

<a id="sj009-armies-note"></a>
<a id="4归印游说与所谓谋乱"></a>
#### 4｜归印游说与所谓谋乱

[卷009 P034—P036](../../sources/摘录/史记-卷009-吕太后本纪.md#p034)。本纪说诸吕有作乱意图又迟疑，灌婴等也以此解释自己的选择；本文记录所见行动，未编出一场已经发动、步骤完备的“吕氏篡汉战争”。郦寄在父亲受胁迫下游说吕禄，其保证不能当作后来双方确实履行过的和平协议。幼王留京而未就国，与吕禄吕产实际领军分开。

<a id="sj009-coup-date"></a>
<a id="5庚申八月还是九月"></a>
#### 5｜庚申：八月还是九月

[卷009 P038—P039](../../sources/摘录/史记-卷009-吕太后本纪.md#p038)和[《汉书》卷003](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7003.md#ref-efadd6a1094fbf)系八月庚申，所据[《通鉴》卷十三](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7013.md#ref-23d028773ba1ca)却系九月庚申。本页以庚申、辛酉等相对次序叙述，编年串联暂随通鉴，**不声称月份已统一，也不未经历算给出唯一公历日期**。纪通掌节、吕禄交印、士卒左袒都是实际接管的不同步骤，不因周勃已有太尉号便写成他一直控制北军。

<a id="sj009-purge-note"></a>
<a id="6清洗范围及皇帝曾经的作用"></a>
#### 6｜清洗范围及皇帝曾经的作用

[卷009 P039—P040](../../sources/摘录/史记-卷009-吕太后本纪.md#p039)。刘章借皇帝使者的节信杀吕更始，说明这一阶段仍在利用少帝权威；族属随后被普遍搜捕，不能全称作战斗中击毙的军人。日餔、大风与吕产逃入吏厕是本纪叙事细节，不据此绘制未经地理核验的宫中战斗图。

<a id="sj009-interim"></a>
<a id="7刘太的短暂迁梁与刘遂册立异年"></a>
#### 7｜刘太的短暂迁梁与刘遂册立异年

[卷009 P041](../../sources/摘录/史记-卷009-吕太后本纪.md#p041)的济川王太迁梁照录为本年短暂安排，因此被杀时称梁王。它同时写立刘遂为赵王，通鉴则明确列在文帝前元年冬十月庚戌，采用[前179年条](bce-0179.md)，此处留异年，不重复册立一次。刘章报齐罢兵、灌婴返军分别保留。

<a id="sj009-lineage"></a>
<a id="8血统指控没有变成编者的确定结论"></a>
#### 8｜血统指控没有变成编者的确定结论

[卷009 P042、P044](../../sources/摘录/史记-卷009-吕太后本纪.md#p042)把“非真孝惠子”置于群臣密议中，同时明写他们担心日后遭报复。此前张皇后养子并不自动证明孩子不是惠帝之子；本页只称群臣如此主张，不写成已用独立材料查明他们都姓吕。反过来，现有文本也不足以逐一证成生父，相关疑问保留在[考证](../../meta/考证/史记-卷009-纪年与异说.md#少帝与血统)。

<a id="sj008-heng"></a>
<a id="9原有迎立记录与实际交权"></a>
#### 9｜原有迎立记录与实际交权

[卷008 P070](../../sources/摘录/史记-卷008-高祖本纪.md#p070)原有落点、锚点保留；[卷009 P043—P044](../../sources/摘录/史记-卷009-吕太后本纪.md#p043)及通鉴补足过程。宦者令在本纪作张泽、通鉴作张释，不未经核校便与同年建陵侯确认为同一人，正文称官职即可。后九月即位在前180年，文帝前元年为前179年；翌日、翌年古史年条的边界不直接等同公历年界。

卷末“二十三年崩”远接刘恒死亡，另落[前157年](bce-0157.md)，不是这次入宫之后立即去世。太史公对惠帝、高后时期民生休息的整体评价，与以上宫廷暴力分层阅读，见[卷009论赞](../../meta/考证/史记-卷009-纪年与异说.md#论赞)。

<a id="sj010-accession-note"></a>
<a id="10卷010补入的劝进试探与即位夜诏"></a>
#### 10｜卷010补入的劝进、试探与即位夜诏

[卷010 P001—P004](../../sources/摘录/史记-卷010-孝文本纪.md#p001)从代地议论开始，补张武的疑虑、宋昌的三项理由、派薄昭及高陵再察的过程。宋昌所谓天授、卜得大横之兆属于人物解释与占卜叙事，不能当作未来已被独立证明；代邸关于弘等生父的说法仍是同一政治阵营的主张，不因两本纪都写就成为两份独立证据。

卷首前196年封代的回顾仍链接[实际年页](bce-0196.md#sj008-eleven)，都中都与此前晋阳的用字差别在[卷010考证](../../meta/考证/史记-卷010-纪年与异说.md#即位与年次)保留，不凭两处地名补出一次未经确年的迁都。即位夜赦民、赐爵、牛酒和大酺由本纪原诏补入，其对诛吕的定性是新君宣布的正当性理由，不取消旧页保留的清洗过程。

<a id="sj018-fankang"></a>
<a id="樊伉因母族被诛郦商在同年去世"></a>
### 樊伉因母族被诛，郦商在同年去世

**舞阳侯樊伉也遭到诛杀。** 他是樊哙与吕媭的儿子，母亲属于吕氏，因而在这次清洗中受到牵连。侯表概称“坐吕氏诛”，没有另记他亲自发动了哪一场军事行动；不能把被杀本身当成已经证明他参加了篡位计划。[R018](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r018)

**病中的郦商在本年去世。** 他的儿子郦寄刚刚参与劝吕禄交印，随后承接父亲的爵位，下一古历年开始记侯元年。郦商因病被人利用、郦寄参与夺军、父亲去世与儿子承爵，是相连但不同的几个步骤。[R016](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r016) · [《樊郦滕灌列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7095.md#ref-25c7dd2183205b)

<a id="sj018-succession"></a>
**安国侯忌和安平侯应本年开始新的侯年。** 前者承接王陵一支，后者接鄂君一支；二人并不是因本年诛吕才分别创建两个全新的侯国。[安国R059](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r059) · [安平R062](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r062)

<a id="sj018-note"></a>
<a id="卷018族诛继承与平棘的异年"></a>
#### 卷018｜族诛、继承与平棘的异年

樊伉的终局据侯表及樊哙传，樊哙本人已在[前189年](bce-0189.md#sj018-fankuai)去世；文帝又封樊哙另一子市人，见[前179年](bce-0179.md)。三代人物与母族分别辨认，不让父亲在本年再次被杀。郦商之死列传明记“是岁商卒”，故可归诛吕本年；不是只由郦寄元年倒推。

[建成R012](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r012)末句诛吕禄、灭吕氏与上文同事，仍保留清洗并非仅限掌兵者的叙述。曹窋、纪通、陈平、周勃、灌婴、夏侯婴在当年的行动已经各有正文，不因他们在侯表另占一行而重讲一场夺军或迎立。

[平棘R073](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r073)把辟强元年列在高后八年，文六年又记受鬼薪刑；[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-897767b5ecbafd)则将承爵与该案都系文五年。两表对任期不合，本轮保留史表本年起算的原格，不据它制造第二位辟强或一场有确定日子的受爵礼；实际罪案另在[前175—174年说明](bce-0175.md#sj018-note)登记所取年线。未知父亲卒年、承爵日也不补造。

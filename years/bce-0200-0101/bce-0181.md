# 公元前181年｜刘友饿死、刘恢自杀，刘恒拒绝迁赵

[← 公元前182年](bce-0182.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前180年 →](bce-0180.md)

**高后七年；皇帝弘在位**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="正月赵王刘友被召来却得不到食物"></a>

<a id="event-1"></a>

1. **正月，赵王刘友被召来，却得不到食物。** 刘友的吕氏王后因不受宠，向太后告发他准备将来攻打吕氏。 吕后把刘友召到长安，关在邸中，不予接见，命卫士围守、断绝饮食。有人偷偷给他送食，也被逮捕治罪。 [[1]](#note-1)

<a id="event-2"></a>

2. **丁丑，刘友终于被饿死，按平民礼葬在长安民冢附近。** 在传世的歌辞里，他责备强迫婚姻、谗言与无人相救，也后悔自己未能早作决断。这位前194年从淮阳迁到赵国的皇子，至此结束了统治。 [[2]](#note-2)

<a id="event-3"></a>

3. **同月又发生日食，白昼昏暗，吕后认为这是冲着自己来的。** 天象是所记现象，太后的不安则是当事人的解释，不必把两者直接连成天谴已获证实。 [[3]](#note-3)

<a id="sj009-kingdoms"></a>
<a id="二月刘恢迁赵吕产取得梁地"></a>

<a id="event-4"></a>

4. **二月，刘恢迁赵，吕产取得梁地。** 原梁王刘恢被迁为赵王，吕产从吕王迁为梁王。 吕产没有去封国，继续留京任帝太傅。梁地后来改称吕，原先的吕国又改称济川；同一个“吕国”名称在这里已不能始终指向同一片地方。 [[4]](#note-4)

<a id="event-5"></a>

5. **七月，平昌侯太被立为济川王。** 他是以惠帝子名义登记的幼子，原是侯，这时进入王的行列。幼王的封国与本人是否亲自到国治理，也应分开理解。 [[5]](#note-5)

<a id="event-6"></a>

6. **齐国的琅邪郡则划给刘泽，立为琅邪王。** 刘泽出自刘氏宗族，又娶吕媭的女儿，是诸吕的姻亲。太后希望以封王安抚他、减少自己身后可能出现的抵抗，刘氏与吕氏并不是所有关系都截然分开。 《荆燕世家》把田生的运作作为封王前情：刘泽曾赠他二百金，过了两年催问；田生到长安借大宅，让儿子结交大谒者张卿，再陈列侯规格的帷帐供具设宴。席间他先称吕氏助高祖有功、太后年高而诸吕势弱，劝张卿暗示大臣请封诸吕，许以万户侯前景，又以迟不进言可能招祸相逼。张卿果然促成请求并得赐千金，分出一半给田生，田生拒受，转说刘氏将军刘泽尚有不满，分十余县封王、让他喜去，反能巩固诸吕。太后采纳，刘泽与田生急赴封国，出关后追使已来不及留下他。故事中吕产、吕王、王代的称谓与分封纪年有冲突，两个相对时长也不能当成本年内的日历；原话和异说留在同号注。 [[6]](#note-6)

<a id="六月刘恢不堪控制自杀而死"></a>

<a id="event-7"></a>

7. **六月，刘恢不堪控制，自杀而死。** 吕后让吕产的女儿做赵王后，她带来的吕氏从官控制王府，监视刘恢。 王所宠爱的女子又被王后派人毒杀。刘恢作歌悼念，悲愤自杀。太后认为他为了妇人放弃宗庙，不让他的后嗣继承赵国。 [[7]](#note-7)

<a id="event-8"></a>

8. **代王刘恒没有接受迁赵的安排。** 太后本想再从高祖儿子中选一人接赵王，刘恒推辞，表示愿守代地边境。陈平、吕产等转而上请封吕禄为赵王，太后批准，并追尊吕禄之父吕释之为赵昭王。 [[8]](#note-8)

<a id="宫中的宴席与将相交往也带着权力的紧张"></a>

<a id="event-9"></a>

9. **吕后末年的宴会上，刘章以耕田歌示警，并按军法杀死逃酒的吕氏成员。** 朱虚侯刘章当时二十岁，身体强健，愤慨刘氏宗室不能得到应有职权。有一次他入侍吕太后宴饮，太后叫他管理酒宴。他自请说：“我是将门之后，请准我按照军法管理饮酒。”太后答应。饮到兴浓时，他上前敬饮、歌舞，随后提出为太后唱耕田歌。太后把他当晚辈孩子看待，笑说：“想来只有你父亲懂种田；你生来就是王子，怎么会懂？”刘章回答自己懂，太后便让他说。他唱道：“深耕土地，密密播种；苗长起来，要使它疏开；不是本来种下的，就把它锄掉。”吕后默不作声。过了一会儿，一个吕氏成员醉后逃离酒席，刘章追上去拔剑杀了他，回来报告：“有一个逃酒的人，我恭谨地执行军法，把他斩了。”太后和左右的人大惊，但她已准许用军法，无法因此治罪，只得结束宴会。从此诸吕害怕刘章，连大臣也依靠他，刘氏的势力有所增强。这是带有威慑意味的言行叙述；本段没有独立年月，沿既有前181年条作为吕后末年的相关叙事，不用二十岁强算生年。 [[9]](#note-9)

<a id="event-10"></a>

10. **陆贾则劝陈平与周勃加深合作。** 平时政事靠丞相，危局用兵靠将领，若两人能互相信任，便不容易被各个击破。陈平、周勃彼此厚赠设宴，关系更密切，为下一年的联合行动积累了条件。 [[10]](#note-10)

<a id="九月燕王刘建死儿子也没能继位"></a>

<a id="event-11"></a>

11. **九月，燕王刘建死，儿子也没能继位。** 刘建去世后，吕后派人杀掉他与美人所生的儿子，燕国以无后为由被撤除。 下一古历年冬十月，燕王名号将给吕台之子吕通。死亡、杀子与改封是接续的步骤，不是同一件事。 [[11]](#note-11)

<a id="event-12"></a>

12. **汉同时向南越出兵，命周灶率军进攻。** 北方也有匈奴侵狄道、掳去二千余人的记录。宫中斗争没有停止边境战争，后来南征受阻及撤军仍须接着读。 [[12]](#note-12)

[完整原表](../../sources/摘录/史记-卷019-惠景间侯者年表.md) · [逐格去向](../../meta/记录/史记-卷019-逐格核对.md) · [纪年与异说](../../meta/考证/史记-卷019-纪年与异说.md)。原格的承侯元年不一律等于前任死年；未载月日不补，谥号是后称，国除也不一律等于处死。

<a id="sj019-r007-e02-n"></a>
**梧｜[R007原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r007)：** 依本格明确的年号或元年定位；无确月的，不由同年其他事件借用日期。

<a id="sj019-r010-e02-n"></a>
**沛｜[R010原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r010)：** [《汉书·外戚恩泽侯表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7018.md#ref-33b29c177fe1c6)明系高后七年更封不其；史表在末段写“一，为不其侯”，只表示最后阶段，不据裸数字另造一次迁封。

<a id="sj019-r017-e02-n"></a>
**昌平｜[R017原格](../../sources/摘录/史记-卷019-惠景间侯者年表.md#r017)：** 接[本页既有事项](#sj009-kingdoms)。太由侯进王接本页济川王安排；史表称吕王，是旧吕国改名济川的称号层次，不让太与吕产成为同一人。

<a id="1刘友的罪名歌辞与日食"></a>
#### 1｜刘友的罪名、歌辞与日食

[卷009 P022—P023](../../sources/摘录/史记-卷009-吕太后本纪.md#p022) · [《通鉴》卷十三高后七年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7013.md#ref-2a67e24f654bbd)。谋攻吕氏出自王后的告发，原文本身称其为谗，不能据告发另造一场已经筹备充分的军事叛乱。歌辞是传世作品，不当成全部宫中对话的独立证据；日食不解释为上天认可或反对某一政权的证明。

《天官书》[P120](../../sources/摘录/史记-卷027-天官书.md#p120)把“諸呂作亂，日蝕，晝晦”连述；本页本纪正月的明年条与《汉书·五行志》“七年正月己丑晦，日有食之，既”互证（[互校H010](../../sources/摘录/史记-卷027-纪年互校.md#h010)）。日食仍在高后七年，次年[诛吕政变](bce-0180.md)另叙，不因《天官书》压缩回顾便移成高后八年的观测。“明年应”属于古代灾异论。

<a id="sj008-hui"></a>
<a id="2保留原有迁赵记录分清封国变化"></a>
#### 2｜保留原有迁赵记录，分清封国变化

[卷008 P070](../../sources/摘录/史记-卷008-高祖本纪.md#p070)及[卷009 P024](../../sources/摘录/史记-卷009-吕太后本纪.md#p024)与旧页同事，原锚点保留。“赵共王”是后来称号，刘恢、刘友是两个兄弟。刘太封济川在通鉴七月丁巳，不能让本纪同段所有改封都共用二月。齐之济南所建的旧吕国与梁改称的新吕国分开；本轮不尝试无据复原逐县边界。刘泽妻是吕媭女，不能因此认定他在后来的所有争端中必站吕氏一边。

<a id="sj009-hui-death"></a>
<a id="3谁接赵王以及没有再发生的封王"></a>
#### 3｜谁接赵王，以及没有再发生的封王

[卷009 P025、P027](../../sources/摘录/史记-卷009-吕太后本纪.md#p025)。刘恢四章歌在本纪没有给出正文，不替他创作四首。刘恒只是被提出迁赵，并未接受，不列一任“赵王刘恒”。吕禄在不同段落有胡陵侯、武信侯等称谓，保留于考证，不凭称号差别造出两个人或未经确年的迁侯仪式。张敖之死原本纪夹在本年，按通鉴已归[前182年](bce-0182.md#sj009-zhangao)，本页不重复记死。

#### 4｜宴中杀人与陈平周勃的结交

[《通鉴》卷十三七年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7013.md#ref-d4b8ef1f86d9c8)及[《史记》卷052](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7052.md#ref-785a9ac32d5af0)。这是补充下一年政变的前情，未把相关世家列传整卷算作已完成；月份未明，不因排在六月之后便认作同月。刘章把军法用在宴饮中，是故事记载的做法，不代表所有宫宴普遍允许杀死离席者。陆贾所得礼物的金额、奴婢和车马数为文本记数，不作现代财产估值。

### 武强、龙、阳义三支传爵，义陵无后除国

**武强侯婴接续庄不识，龙侯坚接续陈署，阳义侯贺接续灵常。** 三家均从本年起记后任侯的年数，前任参与开国战争的经历仍留在原来的年份或初封前情里，不把军功移给继承人。[武强R033](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r033) · [龙R097](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r097) · [阳义R127](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r127)

**义陵侯种在本年去世，没有继承人，侯国被撤销。** 这一支原由长沙柱国吴程受封，已经传过一代；无后除国与同年别处发生的政治杀戮不是一类证据。[R102](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r102)

<a id="卷018王陵卒年的依据与两位由侯进王者"></a>
#### 卷018｜王陵卒年的依据与两位由侯进王者

[安国R059](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r059)高后栏先列王陵七年，八年忌元年；[《陈丞相世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7056.md#ref-7d15a764f0e302)又记免相后七年卒。当前按表中一代结束、下一代起年相接，把王陵终局放在本年，并不据“七年”推算精确月日，也不说通鉴本年另有同样一条明记。这里采用的是侯籍年链，不是每见子元年就无条件减一年；史料的计年口径仍须与明确卒年区别。

义陵原表明写七年薨、无后、国除，且说相关谥号失载，不给吴种补造一个谥号。龙／龙阳、阳义／阳羡、种／重等异字参[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-8ff26d910d1019)，均沿前后侯统识别。

[建成—胡陵R012](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r012)的吕禄进赵王及父亲追尊，接上文同一安排，末尾诛灭吕氏另在前180年。[营陵R113](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r113)刘泽封琅邪王在史表系六年，汉表和通鉴七年，正文仍取本页；侯国结束在这两例中都是升王，不称遭罪削爵。

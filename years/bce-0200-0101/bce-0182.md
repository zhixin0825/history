# 公元前182年｜吕嘉被废，吕产接王位，刘兴居进入宿卫

[← 公元前183年](bce-0183.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前181年 →](bce-0181.md)

**高后六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="冬季吕国从侄子转到叔父手中"></a>

<a id="event-1"></a>

<a id="hs-event-15"></a>

1. **吕嘉失去吕王位，吕产改王吕。** 冬十月，吕后以吕嘉骄恣为由废其王位。十一月，改立吕台的弟弟吕产为吕王，吕国由侄转叔。 [[1]](#note-1)

<a id="刘氏宗室也继续在长安取得位置"></a>

<a id="event-2"></a>

2. **刘氏宗室也继续在长安取得位置。** 刘兴居受封东牟侯，进入宿卫。 他是刘章的弟弟、齐王刘襄的兄弟，二人在宫中与齐国之间形成联系。吕后死后，刘章起兵诛吕、刘兴居参与清宫，都有这一在京身份作为基础。 [[2]](#note-2)

<a id="event-3"></a>

3. **宣平侯张敖去世，被追谥鲁元王。** 他的儿子张偃早已是鲁王，女儿又是惠帝皇后。张敖的死使年幼张偃失去父亲，加上此前母亲鲁元公主已经去世，太后后来将再封张家兄弟辅助他。 [[3]](#note-3)

<a id="四月赦罪钱币与边防另有变化"></a>

<a id="event-4"></a>

4. **四月赦罪，钱币与边防另有变化。** 四月，朝廷大赦；本年又行五分钱。 匈奴进攻狄道、阿阳，北边并未因为和亲就完全安定。朝廷也提高长陵令秩、修筑长陵一带设施。 [[4]](#note-4)

<a id="sj019"></a>
<a id="封侯承袭与侯国的变化"></a>

<a id="sj019-r020-e02"></a>

<a id="event-5"></a>

<a id="hs-event-13"></a>

5. **乐平侯胜接续卫无择侯爵。** 胜接续乐平侯卫无择的爵位。乐平简侯衞毋择一支，共侯胜承爵。 [[5]](#note-5)

<a id="sj019-r029-e01"></a>

<a id="event-6"></a>

<a id="hs-event-14"></a>

6. **吕通受封锤侯。** 吕通以吕台之子的身份先封锤侯，还不是后来接替刘建王统的燕王。吕通一支，封。 [[6]](#note-6)

   本卷与本页已叙事项的互见，以及未能确年的后事，合见[卷019史料说明](#sj019-note)。

<a id="sj098-event-7"></a>

<a id="hs-event-9"></a>

7. **靳亭接续信武侯爵。** 信武侯靳歙上年去世，儿子靳亭本年开始记信武侯元年。信武肃侯靳歙一支，侯亭承爵。 [[7]](#note-7)

<a id="hs-event-8"></a>

8. **昼间见星记载。** 本年春，纪文记昼间见星。 [[8]](#hs-note-8)

<a id="hs-event-10"></a>

9. **阳都敬侯丁复｜承爵。** 表载阳都敬侯丁复一支本年记载侯位承袭。表中所载事项为趮侯甯承爵。 [[9]](#hs-note-10)

<a id="hs-event-11"></a>

10. **东武贞侯郭蒙｜承爵。** 表载东武贞侯郭蒙一支本年记载侯位承袭。表中所载事项为侯它承爵。 [[10]](#hs-note-11)

<a id="hs-event-12"></a>

11. **杜衍严侯王翥｜承爵。** 表载杜衍严侯王翥一支本年记载侯位承袭。表中所载事项为共侯福承爵。 [[11]](#hs-note-12)

<a id="hs-event-16"></a>

12. **壶关侯武｜进爵。** 表载壶关侯武一支本年升爵。表中所载事项为为淮阳王。 [[12]](#hs-note-16)

#### 1｜废与立分月

[卷009 P021](../../sources/摘录/史记-卷009-吕太后本纪.md#p021)连写十月废嘉立产；[《通鉴》卷十三六年](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7013.md#ref-234a2b2299f0b7)区分十一月立产，本页依后者。骄恣是太后公布的废王理由，未据此杜撰吕嘉私生活细节。刘兴居本年侯封与刘章前186年受封分开。

<a id="卷018宣平侯的终局与营陵升王异年"></a>
#### 卷018｜宣平侯的终局与营陵升王异年

[宣平R103](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r103)高后六年侯籍终止，接本页张敖之死；原格“信平”按宣平一支互见，不造另一位同年死亡的张氏侯。子偃为鲁王已在前187年，本格把先后事件压在一起，不能以父死再安排一次封鲁王。

[营陵R113](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r113)把刘泽成为琅邪王写在高后六年，汉书功臣表及通鉴则系七年。主叙仍在[前181年](bce-0181.md#sj009-kingdoms)，本年保存另一系年，不在两年各立一次。侯国“除”在这里是因进封为王而结束，不是获罪失去全部身份。

五家承侯按原表元年，姓名与[《汉书》功臣表](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-23d0d58b5b39cc)对读；甯／宁、王翳／王翥等不拆成新人物。短格没有交代每家前任具体卒月，也没有证明五位继承人同日面见太后，正文不补这类场景。

2. **淮南王刘长本年来朝。** 他是高祖之子，这时仍保有淮南王位；文帝时获罪迁徙的结局尚在多年以后，不能因同名同国便提前讲成这次入朝已被废。 [[2]](#note-2)

<a id="八月淮阳王强去世武接位"></a>
### 八月，淮阳王强去世，武接位

<a id="event-3"></a>

3. **朝廷让壶关侯武接替淮阳王。** 强、武都是以惠帝子名义登记在皇室中的人物。武由侯进王，后来也会留在长安，卷末清洗少帝诸王时再次出现。 [[3]](#note-3)

<a id="九月加强北方驻防"></a>
### 九月，加强北方驻防

<a id="event-4"></a>

4. **河东、上党的骑兵被调到北地驻守，戍卒实行按年更替的安排。** 一面与南越交战，一面维持北方防线，说明这一时期相对休息并不是完全没有边事。 [[4]](#note-4)

> 纪年：五；大事纪：八月，淮陽王薨，以其弟壺關侯武為淮陽王。令戍卒歲更。；相位：七。五；将位：二；御史大夫位：〔空〕

刘强死亡、刘武接淮阳与岁更戍卒都接本页原事。表“令戍卒岁更”没有说同年已由所有郡县同步完成全部交接，不擅定统一出发日或轮换人数。相位陈平七、审食其五，太尉周勃二，属于原表任期线，不据此消除周勃起任异年。

### 奚涓之母去世，鲁侯国终止；靳歙也走到生命终点

**承接战死儿子奚涓功劳的鲁侯母亲在本年去世，没有继承人，侯国撤销。** 她的受封体现了朝廷对死事功臣家属的报偿，死后却没有永远延续下去。这处鲁侯国与张偃所封的鲁王不能混作同一爵位。[R047](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r047)

**信武侯靳歙也在本年去世。** 从早年跟随刘邦，到统车骑参加陈豨、英布战争，他经历了开国前后的多条战线；儿子靳亭承接爵位，表中元年列在下一年。[R002](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r002) · [《傅靳蒯成列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7098.md#ref-92bc05defa293a)

<a id="卷018鲁母终局靳歙死年与承爵"></a>
#### 卷018｜鲁母终局、靳歙死年与承爵

鲁母姓名本表作疵、汉表作底，采用同一人，初封在前201年。无后是侯爵无人承接，不意味着奚氏一切后人绝灭，也不凭本行制造张偃鲁王在本年被废。靳歙死年由列传明确“高后五年卒”，表中高后五年止计、六年亭元年与之相接；汉表初封格中的任期数字不完全一致，未以一个总年数推翻明记的卒年。

五项承侯均有本年元年，原文未逐一写父亲的具体死日。陈禄与萧禄虽然同名、都属功臣家，父系和侯国不同；周闲／周简等字形按[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-79fc1bafdf2c28)互见，不据新名另添一个初封过程。诸侯来朝、边事与这些家族变动并列，不推定它们由同一诏令统一实施。

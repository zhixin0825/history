# 公元前183年｜赵佗称帝攻长沙，淮阳王位换了人

[← 公元前184年](bce-0184.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前182年 →](bce-0182.md)

**高后五年；皇帝弘在位**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="春天南越与汉的关系进一步恶化"></a>

<a id="event-1"></a>

1. **春天，南越与汉的关系进一步恶化。** 赵佗自称南越武帝，出兵攻长沙，击破数县后退去。 前一年对关市与铁器的限制没有只停留在口头争执，边境已经发生军事冲突。 [[1]](#note-1)

<a id="sj017-audience"></a>

<a id="event-2"></a>

2. **淮南王刘长本年来朝。** 他是高祖之子，这时仍保有淮南王位；文帝时获罪迁徙的结局尚在多年以后，不能因同名同国便提前讲成这次入朝已被废。 [[2]](#note-2)

<a id="八月淮阳王强去世武接位"></a>

<a id="event-3"></a>

3. **八月，淮阳王强去世，武接位。** 朝廷让壶关侯武接替淮阳王。 强、武都是以惠帝子名义登记在皇室中的人物。武由侯进王，后来也会留在长安，卷末清洗少帝诸王时再次出现。 [[3]](#note-3)

<a id="九月加强北方驻防"></a>

<a id="event-4"></a>

4. **九月，加强北方驻防。** 河东、上党的骑兵被调到北地驻守，戍卒实行按年更替的安排。 一面与南越交战，一面维持北方防线，说明这一时期相对休息并不是完全没有边事。 [[4]](#note-4)

<a id="sj098-event-5"></a>

5. **信武侯靳歙去世。** 信武侯靳歙去世，谥肃侯。靳歙曾随汉平三秦、击楚、定江陵，后来也参与讨伐陈豨、英布。 [[5]](#note-5)

<a id="hs-event-6"></a>

6. **堂邑安侯陈婴｜承爵。** 表载堂邑安侯陈婴一支本年记载侯位承袭。表中所载事项为共侯禄承爵。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **海阳齐信侯摇母余｜承爵。** 表载海阳齐信侯摇母余一支本年记载侯位承袭。表中所载事项为康侯建承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **柳丘齐侯戎赐｜承爵。** 表载柳丘齐侯戎赐一支本年记载侯位承袭。表中所载事项为侯安国承爵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **魏其严侯周止｜承爵。** 表载魏其严侯周止一支本年记载侯位承袭。表中所载事项为侯简承爵。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

#### 3｜淮南来朝与淮阳元年

[卷017前183年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0183)淮南十四年来朝，淮阳“五，无嗣”。下一行[前182年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0182)才列武元年，与本纪本年八月接位是即位、纪年层次的差别，不在下一年再立一次。淮南与淮阳仅名字相近，不是同一国；这位惠帝子的武也不是文帝之子、后来梁孝王刘武。

<a id="sj018-deaths"></a>
<a id="奚涓之母去世鲁侯国终止靳歙也走到生命终点"></a>
### 奚涓之母去世，鲁侯国终止；靳歙也走到生命终点

**承接战死儿子奚涓功劳的鲁侯母亲在本年去世，没有继承人，侯国撤销。** 她的受封体现了朝廷对死事功臣家属的报偿，死后却没有永远延续下去。这处鲁侯国与张偃所封的鲁王不能混作同一爵位。[R047](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r047)

[靳歙去世](#sj098-p008)已有同号正文与引文。侯籍原格见[R002](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r002)。

<a id="卷018鲁母终局靳歙死年与承爵"></a>
#### 卷018｜鲁母终局、靳歙死年与承爵

鲁母姓名本表作疵、汉表作底，采用同一人，初封在前201年。无后是侯爵无人承接，不意味着奚氏一切后人绝灭，也不凭本行制造张偃鲁王在本年被废。靳歙死年由列传明确“高后五年卒”，表中高后五年止计、六年亭元年与之相接；汉表初封格中的任期数字不完全一致，未以一个总年数推翻明记的卒年。

五项承侯均有本年元年，原文未逐一写父亲的具体死日。陈禄与萧禄虽然同名、都属功臣家，父系和侯国不同；周闲／周简等字形按[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-79fc1bafdf2c28)互见，不据新名另添一个初封过程。诸侯来朝、边事与这些家族变动并列，不推定它们由同一诏令统一实施。

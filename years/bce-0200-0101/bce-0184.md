# 公元前184年｜前少帝被废杀，恒山王义改名弘继位

[← 公元前185年](bce-0185.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前183年 →](bce-0183.md)

**高后四年；年中更换皇帝，未改元**

## 宫中皇帝长大，开始追问自己的身世

**少帝得知自己不是张皇后亲生，又听说生母已遭杀害，表示长大后要有所改变。** 吕后担心他日后报复，将他禁闭在永巷，对外宣称皇帝病重，不让左右见他。[1](#sj009-depose)

**她随后以久病昏乱、不能奉宗庙为由，向群臣提出更换皇帝。** 群臣奉诏。少帝先被废位，继而被幽杀；这不是一次正常的父子继承。[1](#sj009-depose)

## 五月，义成为皇帝弘

**五月丙辰，恒山王义入继帝位，改名弘。** 他原名山，先封襄城侯，前186年继恒山王，现又成为皇帝。朝廷仍按高后四年记年，没有因新君登位另称元年。轵侯朝则接替恒山王位。[2](#sj009-hong)

## 封侯继续扩大到吕氏女性与其他宗族成员

**四月，吕后的妹妹吕媭被封为临光侯。** 同年还封吕他为俞侯、吕胜为赘其侯、吕更始为滕侯、吕忿为吕城侯，以及五位诸侯国丞相。女性亲属也取得侯爵，并不只通过丈夫的名位参与政治。[3](#sj009-hou)

**南边的贸易限制开始引发紧张。** 汉限制与南越关市及铁器往来，赵佗认为这是长沙王要借朝廷削弱南越。他的不满将在下一年转为称帝和对长沙作战。[4](#sj009-nanyue)

<a id="sj009-depose"></a>
### 1｜收养、怨言和血统是不同问题

[卷009 P018—P019](../../sources/摘录/史记-卷009-吕太后本纪.md#p018) · [《汉书》卷003四年](https://zh.wikisource.org/wiki/漢書/卷003)。张皇后收养太子的前情已放前188年的继承背景，不把立后、收养、生母被杀都搬到本年。非皇后亲生并不能推出非惠帝亲生；前180年的另一种指控另作史料辨析。病重昏乱是废帝诏给出的理由，不能以诏书当现代诊断。

<a id="sj009-hong"></a>
### 2｜山、义、弘的连续身份

[卷009 P014—P015、P019](../../sources/摘录/史记-卷009-吕太后本纪.md#p014)。本纪详细列改名，汉书有概括写弘的情况，正文保留同一人的升迁次序。太后称制导致不改元，是本纪的解释，不表示新帝没有名义上的皇帝地位。卷009此处另写置太尉、周勃任之，与通鉴前189年相冲突，沿前189年主线，不伪造本年复职。

<a id="sj009-hou"></a>
### 3｜侯封名单的限度

[卷009 P017](../../sources/摘录/史记-卷009-吕太后本纪.md#p017)只称五位诸侯丞相而未列姓名，本页不猜补。吕媭的月日可由通鉴四月丙申核合，其余不自动共用同一天。二月刘太封平昌／昌平侯的称号异文见通鉴，后续王济川见前181年。

<a id="sj009-nanyue"></a>
### 4｜编年底本补充

[《通鉴》卷十三四年](https://zh.wikisource.org/wiki/資治通鑑/卷013)。贸易限制的具体物项与范围尚需相关列传进一步核对；本页只叙所读条目，不把赵佗猜测长沙王操纵的说法当作已证实的朝廷内幕。

<a id="sj018-forfeiture"></a>
## 棘丘失爵，衍与鄢陵两家由后人承接

**棘丘侯襄被剥夺爵位，降为士伍，原侯国撤销。** 原表把这项处置系在高后四年，具体罪由没有记下。开国军功并没有使他获得不可撤销的终身保障。[R050](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r050)

<a id="sj018-succession"></a>
**衍侯由山接翟盱，鄢陵侯由庆接朱濞，本年各开始新侯年。** 两家仍在传爵，和棘丘的降为无爵身份是不同变化；继承人的元年也不能直接替代前任的确切死日。[衍R122](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r122) · [鄢陵R142](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r142)

<a id="sj018-note"></a>
### 卷018｜棘丘异年与太尉互见

棘丘在[汉书功臣表](https://zh.wikisource.org/wiki/漢書/卷016)另系高后元年，与本表四年有差；正文暂采用本卷明列四年，另一年次登记在此，不在前187年再安排一次相同夺爵。士伍表示降为无爵的普通身份，不能把这个词本身译成被处死或必然流放。

[绛R017](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r017)也记本年周勃为太尉，与本页旧注中卷009同一记法；《绛侯周勃世家》、通鉴系前189年，采用线不变。吕媭封临光的事与儿子樊伉已持舞阳侯爵并行，不因夫妻、母子同属一族便合并爵位。

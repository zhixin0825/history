# 公元前184年｜前少帝被废杀，恒山王义改名弘继位

[← 公元前185年](bce-0185.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前183年 →](bce-0183.md)

**高后四年；年中更换皇帝，未改元**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="宫中皇帝长大开始追问自己的身世"></a>

<a id="event-1"></a>

1. **少帝得知自己不是张皇后亲生，又听说生母已遭杀害，表示长大后要有所改变。** 吕后担心他日后报复，将他禁闭在永巷，对外宣称皇帝病重，不让左右见他。 [[1]](#note-1)

<a id="event-2"></a>

2. **她随后以久病昏乱、不能奉宗庙为由，向群臣提出更换皇帝。** 群臣奉诏。少帝先被废位，继而被幽杀；这不是一次正常的父子继承。 [[2]](#note-2)

<a id="五月义成为皇帝弘"></a>

<a id="event-3"></a>

3. **五月丙辰，恒山王义入继帝位，改名弘。** 他原名山，先封襄城侯，前186年继恒山王，现又成为皇帝。朝廷仍按高后四年记年，没有因新君登位另称元年。轵侯朝则接替恒山王位。 [[3]](#note-3)

<a id="封侯继续扩大到吕氏女性与其他宗族成员"></a>

<a id="event-4"></a>

4. **封侯继续扩大到吕氏女性与其他宗族成员。** 四月，吕后的妹妹吕媭被封为临光侯。 同年还封吕他为俞侯、吕胜为赘其侯、吕更始为滕侯、吕忿为吕城侯，以及五位诸侯国丞相。女性亲属也取得侯爵，并不只通过丈夫的名位参与政治。 [[4]](#note-4)

<a id="event-5"></a>

5. **南边的贸易限制开始引发紧张。** 汉限制与南越关市及铁器往来，赵佗认为这是长沙王要借朝廷削弱南越。他的不满将在下一年转为称帝和对长沙作战。 [[5]](#note-5)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-6"></a>

6. **曹窋接任御史大夫。** 他是曹参之子、平阳侯，但侯爵的继承与中央官职的任命并非同一件事；任敖离任以后才由他接掌这一职务。 [原格与说明](#sj022-note)。 惠帝时任中大夫是他的较早职任。 [[6]](#note-6)

<a id="1收养怨言和血统是不同问题"></a>
#### 1｜收养、怨言和血统是不同问题

[卷009 P018—P019](../../sources/摘录/史记-卷009-吕太后本纪.md#p018) · [《汉书》卷003四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7003.md#ref-3149b981b73aed)。张皇后收养太子的前情已放前188年的继承背景，不把立后、收养、生母被杀都搬到本年。非皇后亲生并不能推出非惠帝亲生；前180年的另一种指控另作史料辨析。病重昏乱是废帝诏给出的理由，不能以诏书当现代诊断。

<a id="sj009-hong"></a>
<a id="2山义弘的连续身份"></a>
#### 2｜山、义、弘的连续身份

[卷009 P014—P015、P019](../../sources/摘录/史记-卷009-吕太后本纪.md#p014)。本纪详细列改名，汉书有概括写弘的情况，正文保留同一人的升迁次序。太后称制导致不改元，是本纪的解释，不表示新帝没有名义上的皇帝地位。卷009此处另写置太尉、周勃任之，与通鉴前189年相冲突，沿前189年主线，不伪造本年复职。

### 棘丘失爵，衍与鄢陵两家由后人承接

**棘丘侯襄被剥夺爵位，降为士伍，原侯国撤销。** 原表把这项处置系在高后四年，具体罪由没有记下。开国军功并没有使他获得不可撤销的终身保障。[R050](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r050)

<a id="sj018-succession"></a>
**衍侯由山接翟盱，鄢陵侯由庆接朱濞，本年各开始新侯年。** 两家仍在传爵，和棘丘的降为无爵身份是不同变化；继承人的元年也不能直接替代前任的确切死日。[衍R122](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r122) · [鄢陵R142](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r142)

#### 卷018｜棘丘异年与太尉互见

棘丘在[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-68ab1c20ec6667)另系高后元年，与本表四年有差；正文暂采用本卷明列四年，另一年次登记在此，不在前187年再安排一次相同夺爵。士伍表示降为无爵的普通身份，不能把这个词本身译成被处死或必然流放。

[绛R017](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r017)也记本年周勃为太尉，与本页旧注中卷009同一记法；《绛侯周勃世家》、通鉴系前189年，采用线不变。吕媭封临光的事与儿子樊伉已持舞阳侯爵并行，不因夫妻、母子同属一族便合并爵位。

1. **夏季，江水、汉水泛滥，四千余家流离。** 江水、汉水泛滥，四千余家受水患而流离。 这类灾害没有在《吕太后本纪》的短年条里展开，却直接影响普通人的居住和生计。 [[1]](#note-1)

<a id="event-2"></a>

2. **秋季，伊水、洛水与汝水泛滥。** 伊水、洛水又记一千六百余家受灾，汝水八百余家。 不同河流、地区有各自记录，不能把所有数字直接相加为毫无重复的全国受灾总户数。 [[2]](#note-2)

<a id="sj017-audience"></a>
<a id="齐王刘襄长沙王吴右入朝"></a>

<a id="event-3"></a>

3. **齐王刘襄、长沙王吴右入朝。** 刘襄和吴右本年来朝。 前者已经接续父亲刘肥，后者接续吴回；这不是早年刘肥险遭毒杀的那次宴会，也不是长沙初王吴芮仍在赴朝。 [[3]](#note-3)

<a id="sj009-water"></a>
<a id="1无事的范围"></a>
#### 1｜“无事”的范围

[卷009 P016](../../sources/摘录/史记-卷009-吕太后本纪.md#p016)仅“三年，无事”；[《汉书》卷003三年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7003.md#ref-49d1298c7f80ff)和[《通鉴》卷十三](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7013.md#ref-849295ce93330e)保存洪灾，通鉴还列伊洛、汝水分项。本页不是为填满年份编故事，而是补入其他来源明确系年的事件。“流民／流家”的具体损毁程度和人员死亡数未明，不转写成同等数量人口全部死亡。

同年还有“星昼见”的天象记录，原文未确定本页可采用的现代天体身份，不用它解释水灾成因或宫廷政治。

<a id="sj017-note"></a>
<a id="2来朝是本纪短年条以外的记录"></a>
#### 2｜来朝是本纪短年条以外的记录

[卷017前185年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0185)齐四年、长沙二年均写来朝；两位当时在位者沿各自王统识别，吴右／若异名见[前186年注](bce-0186.md#sj017-note)。月份、赏赐、会谈未载，不把本纪“无事”当成不存在这两次活动，也不由洪灾推定他们是专程请求赈济。

### 有的降爵，有的恢复：侯国并非只会父子相传

**故城侯开方被降为关内侯；任侯张越因隐匿应处死罪的人，被免为庶人。** 两人都失去原来的列侯封国，但一个仍有爵，另一个降到无爵身份，法律后果不能笼统合写成全部处死。[故城R048](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r048) · [任R049](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r049)

**柏至侯许温恢复原有封爵，深泽侯赵将夜也在本表列出复封。** 这说明失爵并非一概永不恢复；深泽后来还会中断，其复杂年数与汉表不完全相合，见注。[柏至R076](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r076) · [深泽R075](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r075)

<a id="sj018-note"></a>
<a id="卷018深泽的二三年与留侯继承"></a>
#### 卷018｜深泽的二、三年与留侯继承

深泽在[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-a6b0dbaf8ac628)记高后二年复封，史表三年，又接“一年绝”，文帝十四年再复封。本文暂按本卷将三年的复封置此，同时说明两表在这次复封年和后续经历上均有差别；“一年绝”不足以确定一项新的确月刑案，也不能与汉表“二年薨”混成同一人先死再复封。相关无法唯一归年的中断在综合考证单列。

柏至两表都列三年恢复，前次失爵在高后元、二年有差，已见[前186年](bce-0186.md#sj018-note)。张不疑元年两表相合，但张良卒年仍沿[前189年](bce-0189.md#sj018-note)通鉴主线，表计数较晚的异年保留，不虚构中间三年由何人代侯的过程。其余元年没有死亡月日，不给各家编定同日承袭仪式。

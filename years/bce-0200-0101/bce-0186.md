# 公元前186年｜吕嘉继王，刘章入宿卫，恒山王位再次更换

[← 公元前187年](bce-0187.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前185年 →](bce-0185.md)

**高后二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="冬十一月吕台去世吕嘉继承吕国"></a>

<a id="event-1"></a>

1. **冬十一月，吕台去世，吕嘉继承吕国。** 第一位在世受封的吕王吕台去世，谥肃王，其子吕嘉接位。 新建立的吕氏王国也开始按父子传承，但吕嘉能否保住王位，仍取决于太后的决定。 [[1]](#note-1)

<a id="sj009-liuzhang"></a>
<a id="五月刘章封朱虚侯留在长安宿卫"></a>

<a id="event-2"></a>

2. **五月，刘章封朱虚侯，留在长安宿卫。** 刘章是齐王刘肥之子、现任齐王刘襄的弟弟。 他受封朱虚侯，入京宿卫，又娶吕禄的女儿。这样一位刘氏宗室，既是宫中武力的一员，又是吕家的女婿；后来的政变并不是两个家族之间毫无交错的简单对阵。 [[2]](#note-2)

<a id="event-3"></a>

<a id="hs-event-15"></a>

3. **刘郢客受封上邳侯，任宗正。** 楚王之子刘郢客也封上邳侯。对宗室的封赏与诸吕得势同时进行，并非所有刘氏人物在这一阶段都被排除。刘郢客任宗正。参见本年的官职变动原句。 [[3]](#note-3)

<a id="七月恒山王不疑死襄城侯山接位"></a>

<a id="event-4"></a>

4. **七月，恒山王不疑死，襄城侯山接位。** 不疑去世后，他的弟弟山迁为恒山王，改名义。 再过两年，这位新王将被选为皇帝。现在仍是幼王之间的继承，不把以后的弘帝名号提前当作又一个人。 [[4]](#note-4)

<a id="sj017-changsha"></a>
<a id="长沙换代吴氏继续在位"></a>

<a id="event-5"></a>

5. **吴回去世，长沙由其子接续。** 长沙王吴回去世，由儿子接续吴氏王位。 [[5]](#note-5)

<a id="朝位钱币和灾害也写在同一年"></a>

<a id="event-6"></a>

<a id="hs-event-8"></a>

6. **陈平核定列侯功次与朝位，朝廷行八铢钱。** 朝廷整理列侯功次与朝会座次，将议定结果藏于高庙。对功臣的政治排序不只依赖临时口头评价，还要成为可传给后嗣的名位安排。本年又行八铢钱。高后命陈平核定列侯功次。高后二年，命丞相陈平详定列侯功次，完成后存宗庙，副本留有司。 [[6]](#note-6)

<a id="event-7"></a>

7. **正月地震，羌道、武都道山崩；六月晦日发生日食。** 灾异有具体记载，却不能因此断定它预示某位王即将死亡。 [[7]](#note-7)

<a id="hs-event-9"></a>

8. **酇文终侯萧何｜受封。** 表载酇文终侯萧何一支本年有始封记载。表中所载事项为封何夫人禄母同为侯。 [[8]](#hs-note-9)

<a id="hs-event-10"></a>

9. **筑阳侯萧延｜改封。** 表载筑阳侯萧延一支本年爵号或封邑改易。表中所载事项为定侯延因何少子封。 [[9]](#hs-note-10)

<a id="hs-event-11"></a>

10. **赤泉严侯杨喜｜复封。** 表载赤泉严侯杨喜一支本年恢复先前中断的封爵。表中所载事项为复封。 [[10]](#hs-note-11)

<a id="hs-event-12"></a>

11. **深泽齐侯赵将夕｜复封。** 表载深泽齐侯赵将夕一支本年恢复先前中断的封爵。表中所载事项为复封。 [[11]](#hs-note-12)

<a id="hs-event-13"></a>

12. **周吕令武侯吕泽｜去世。** 表载周吕令武侯吕泽一支本年记载去世。表中所载事项为去世，谥曰肃。 [[12]](#hs-note-13)

<a id="hs-event-14"></a>

13. **昌平侯大｜受封。** 《汉书》侯籍列昌平侯大本年受封，所引月份、干支依表保留。 [[13]](#hs-note-14)

<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[本年原表R021](../../拆分史书/史记/卷022.md#r021) · [《汉书·百官公卿表》](../../拆分史书/汉书/卷019.md#part-3-ws019-bce-0186)。

> 纪年：二；大事纪：十二月，呂王台薨，子嘉代立為呂王。行八銖錢。；相位：四。平。二。食其。；将位：〔空〕；御史大夫位：平陽侯曹窋為御史大夫。。

吕台之死本格系十二月，本页依据本纪、通鉴系冬十一月，保留异月，不在十一、十二月死两次。八铢钱的施行接本页既有钱币条。史表曹窋任御史在本年，汉表在高后四年即[前184年](bce-0184.md#sj022-note)，采用汉表与任敖三年任期相接的线索；“四，平；二，食其”分别为陈平、审食其任期。

<a id="sj009-succession"></a>
<a id="1不能按文字先后倒置月份"></a>
#### 1｜不能按文字先后倒置月份

[卷009 P015](../../拆分史书/史记/卷009.md#p015)先说恒山继位，再说十一月吕台死；[《通鉴》卷十三二年](../../拆分史书/资治通鉴/卷013.md#text)分别定位冬十一月、秋七月。十月岁首，吕台之死在本古历年较前，不疑死在较后。二人不是同一个王国的前后君主。

<a id="sj009-title"></a>
<a id="2朱虚侯的年次"></a>
#### 2｜朱虚侯的年次

卷009 P013放在元年，通鉴二年五月丙申明确列刘郢客、刘章封侯，采用后者，不在两年各封一次。刘章妻来自吕氏，不能仅凭她后来提供消息就推论所有女眷立场相同。

<a id="sj009-other"></a>
<a id="3补充纪事的出处"></a>
#### 3｜补充纪事的出处

[《汉书》卷003二年](../../拆分史书/汉书/卷003.md#part-1-text)有功次诏、地震、山崩、日食与八铢钱。钱重是制度名称，不表示已经逐枚检验出土钱币重量；也不从发行一条推算物价变化。具体古月干支未折算公历。

<a id="sj017-note"></a>
<a id="4卷017三个继承格与后叙"></a>
#### 4｜卷017三个继承格与后叙

[卷017前186年](../../拆分史书/史记/卷017.md#y0186)分别记吕嘉十一月癸亥、恒山义七月癸巳和长沙共王右元年。前一年吕台、不疑格里的“薨”压缩后续，仍回本页，不让两人前187年已死又在本年死一次。义格末句“立为帝”接[前184年](bce-0184.md#sj009-hong)，不是他本年即皇帝位。

[汉书异姓诸侯王表](../../拆分史书/汉书/卷013.md#part-1-text)恒山继承作十月癸丑，正文沿本纪、通鉴七月，异月留注；长沙新王在汉表作“共王若嗣”，本表作右，按同一王统位置保留异名，不拆成两人，也不猜一个改名日期。两表都把此继承放高后二年；前任具体死月未载，不补造。

<a id="sj018-xiao"></a>
<a id="萧何之子无后夫人与另一个儿子分别受封"></a>
### 萧何之子无后，夫人与另一个儿子分别受封

**萧禄无子而去世以后，吕后让萧何的夫人同承接酂侯，又把少子萧延封为筑阳侯。** 同是萧禄的母亲；这项安排使开国相国的家族祭祀与封爵不因长子无后而立即断绝。两人有各自的爵号，不能说同一侯国同时出现了两位同名的男性继承人。[原格与取舍](#sj018-note)

<a id="sj018-restoration"></a>
**赤泉侯杨喜和桃侯刘襄恢复封爵，柏至侯许温则在表中记为失爵。** 前两位不是获得第二次独立军功才新建同名国，而是恢复先前中断的爵位；柏至后来也会复封，具体罪情没有明文。[赤泉R079](../../拆分史书/史记/卷018.md#r079) · [桃R136](../../拆分史书/史记/卷018.md#r136) · [柏至R076](../../拆分史书/史记/卷018.md#r076)

<a id="sj018-note"></a>
<a id="卷018同的亲缘萧延的初封和失爵年差"></a>
#### 卷018｜同的亲缘、萧延的初封和失爵年差

[酂R015](../../拆分史书/史记/卷018.md#r015)本年写“懿侯同元年，同祿弟”，与[汉书功臣表](../../拆分史书/汉书/卷016.md#part-1-text)明确的“何夫人、祿母同”不同；[《汉书·萧何曹参传》](../../拆分史书/汉书/卷039.md#part-1-text)也说封何夫人同、少子延，文帝元年罢同而更封延为酂。正文采用表传能共同核合的母亲身份，史表原字完整保留，不改作两位不同的同。

筑阳初封在汉表明系本年，文帝元年是萧延改封酂，不再当成第一次获侯。史表把筑阳延的元年接文帝初，其在位年数与后世袭爵年差很大，另列综合考证，不据父子一串数字补造空缺的任期。萧禄之死的具体月日未载，正文只说明受封的前因，不将本年同的元年等同于母子同日交爵。

杨喜复封两表相合；桃侯前次失爵在史表为前187、汉表为前188，复封仍在高后初接回，未让刘襄死而复生。柏至失爵史表高后二年、汉表高后元年，暂沿本年，复封在前185年；许温／许盎的异名不另造两人。深泽复封汉表在本年，史表次年，主叙见[前185年](bce-0185.md#sj018-note)。张良卒年由两表计数指向本年、通鉴却系前189，仍见[前189年异说](bce-0189.md#sj018-note)，本年不再写一次死亡。

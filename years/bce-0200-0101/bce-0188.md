# 公元前188年｜惠帝去世，幼主继位，吕后开始临朝称制

[← 公元前189年](bce-0189.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前187年 →](bce-0187.md)

**汉惠帝七年；少帝本年继位**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sj017-audience"></a>
<a id="诸侯来朝齐国进入刘襄元年"></a>

<a id="event-1"></a>

1. **楚王刘交、吴王刘濞、淮南王刘长、燕王刘建、赵王刘友、梁王刘恢本年来朝。** 各国仍由已经受封的王在位，不能因为皇帝后来去世，就把这些未标月的朝见全部认定为参加丧礼。 [[1]](#note-1)

<a id="event-2"></a>

2. **齐国开始记刘襄元年，承接上一年去世的刘肥。** 刘襄是高祖的孙子；此后在诸吕之乱中西进的齐王就是他，不是父亲刘肥重新带兵。 [[2]](#note-2)

<a id="八月刘盈去世留下年幼的继承人"></a>

<a id="event-3"></a>

3. **八月，刘盈去世，留下年幼的继承人。** 八月戊寅，惠帝死于未央宫，朝廷大赦。 高祖的成年儿子做了七年皇帝，接下来的皇帝却仍年幼，如何控制宫廷与军队成为眼前最紧迫的问题。 [[3]](#note-3)

<a id="继承前情张皇后与太子的关系"></a>

<a id="event-4"></a>

4. **继承前情｜张皇后与太子的关系。** 张皇后没有亲生儿子，太子由她收养。 本纪将这一安排追叙为吕后主持：取后宫美人的孩子，以皇后之子名义抚养，其生母被杀。立后在[前191年](bce-0191.md)，收养及立储的具体年月未记；此处只交代新帝为何以张皇后之子的身份继位。 吕后曾想尽办法使张皇后亲自生子，始终未成，才转向这一冒称亲生的办法。 [[4]](#note-4)

<a id="吕氏掌军的建议出现在惠帝的丧事中"></a>

<a id="event-5"></a>

5. **吕氏掌军的建议，出现在惠帝的丧事中。** 侍中张辟彊向丞相提出，应先让太后安心。 他是张良之子，当时十五岁。他把吕后哭而无泪解释为忧惧：皇帝没有成年儿子，她担心将相控制不住。解决办法是让吕台、吕产、吕禄带兵，诸吕入宫参与政事，以此换取双方平安。 [[5]](#note-5)

<a id="event-6"></a>

6. **丞相采用这项建议，吕后转而安心。** 宫中的亲族安排与军队关系更紧密，后来的诸吕权势由此进一步加强。但握有头衔、实际领兵和能够调动卫士，并不是完全相同的事情。 [[6]](#note-6)

<a id="九月葬安陵太子正式接位"></a>

<a id="event-7"></a>

7. **九月辛丑，惠帝安葬于安陵，太子继为皇帝，谒见高庙。** 吕后以皇太后身份临朝称制。下一年开始使用高后元年的年次，诏令主要由太后发出；皇帝的名位并没有因此在形式上消失。 [[7]](#note-7)

<a id="sj049-liuqibirth-event"></a>

8. **窦姬在代国生下刘启。** 她来自清河观津，早先作为良家女子入宫侍吕太后。太后分赐宫人，每王五人，窦姬想去离家近的赵国，请掌遣送的宦官把她列入赵队，宦官却忘记而误列代队。名单奏准后，她哭泣怨恨、不肯上路，经劝迫才启程。到了代国，刘恒特别宠爱她，她先已生女嫖，此时又生刘启，后来还有一子刘武。入宫与分遣的各年未详，刘启出生则有惠帝七年的明确记载。 [[8]](#sj049-liuqibirth-note)

<a id="sj009-huidi"></a>
<a id="1哭泣与掌军"></a>
#### 1｜哭泣与掌军

[卷009 P009—P010](../../sources/摘录/史记-卷009-吕太后本纪.md#p009) · [《通鉴》卷十二惠帝七年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7012.md#ref-af752f9fa177b7)。太后忧惧是张辟彊在叙事中的解释，不是现代心理测量。“帝无壮子”意为没有成年儿子，不能译成根本没有儿子；也不能把他提出的所有安排都视作保存完整、可逐项核日期的任命诏令。

<a id="sj009-adoption"></a>
<a id="2不是皇后亲生不等于不是惠帝之子"></a>
#### 2｜不是皇后亲生，不等于不是惠帝之子

[卷009 P018](../../sources/摘录/史记-卷009-吕太后本纪.md#p018)回述张氏养子，[《汉书》卷003](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7003.md#ref-7e7ea11ad9b412)也记取后宫美人子。生母被杀、假为有身等属于传世宫廷叙事，独立证据有限。这里仅说明继承安排，不把前180年群臣后来提出的“非真孝惠子”指控提前作为已查明的血统事实。来源未在本段写前少帝个人名，正文只用少帝辨别。

<a id="sj009-regency"></a>
<a id="3即位与元年"></a>
#### 3｜即位与元年

[卷009 P010](../../sources/摘录/史记-卷009-吕太后本纪.md#p010)。前188年继位、前187年高后元年分开。太后称制不是在朝代之外另建一个吕氏国家；后来的封吕诸王另在对应年条展开。

<a id="sj017-note"></a>
<a id="4来朝新王元年与表中预设国栏"></a>
#### 4｜来朝、新王元年与表中预设国栏

[卷017前188年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0188)楚、吴、淮南、燕、赵、梁六栏记来朝，齐栏记襄元年，对应本页新增衔接。刘肥死亡已在[前189年](bce-0189.md#sj009-ministers)，本年不再死一次。

同一行的“初置鲁、常山、吕、复置淮阳”是随后封王的栏目提示；具体张偃、不疑、吕台、强的授王在[前187年](bce-0187.md)。不能把所有初置格改写为四位国君已经在本年同日到国，亦不能因后来的血统指控而提前说这批孩子没有任何惠帝之子的当时身份。

<a id="sj018-succession"></a>
<a id="樊伉承舞阳猗氏甘泉也开始新侯年"></a>
### 樊伉承舞阳，猗氏、甘泉也开始新侯年

**樊伉继承父亲樊哙的舞阳侯爵，本年开始计元年。** 他的母亲吕须是吕后的妹妹，因此这位樊氏继承人与吕家有直接亲缘；后来政治清洗中遭遇的危险，不能在本年提前当作已经发生。[R018](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r018)

**猗氏由交接续陈鸱，甘泉由莫摇接续王竟。** 爵位传给后人，原有侯国继续存在；甘泉这一行在汉表称景侯，新侯名又作真粘，仍须按前后任关系识别，而非另立两位同年承侯者。[猗氏R085](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r085) · [甘泉R139](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r139)

<a id="sj018-zhuzao"></a>
**煮枣一支则没有顺利传爵。** 据《汉书》的明确年条，初封者革朱在本年去世，继承人因罪不能承侯，爵位一度中断；文帝时再从家族另封。史表在位数字较长，与这个年次有差，见注。[R140](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r140)

<a id="sj018-note"></a>
<a id="卷018三家承爵与两项异年"></a>
#### 卷018｜三家承爵与两项异年

樊哙死于前189年，《樊郦滕灌列传》明确惠六年，详见[前页新增条](bce-0189.md#sj018-fankuai)；樊伉本年元年不再制造一次父卒。吕须后来封临光侯，是另一人的爵位，不能写成她与儿子共持一份舞阳侯爵。

[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-c0d941cb6f74dc)煮枣行明记惠七年卒、嗣子有罪不得代，文二年再以朱子式绍封；史表名赤，文元栏仍计“一”，再于文二年记武。当前采用汉表明确的死亡与中断过程，在前179年只留数字分歧，不让同一人死两次。赤／革朱、武／式的异名保留。

桃侯刘襄的第一次失爵，汉表系本年，史表却系下一年高后元年；正文暂按[前187年](bce-0187.md#sj018-note)原表年线叙述，本页只登记另一年次，不增第二次失爵。史料没有说明具体罪名，不根据当年皇帝死亡与宫廷争议猜测案情。

# 公元前189年｜王陵、陈平分任丞相，齐王刘肥与张良去世

[← 公元前190年](bce-0190.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前188年 →](bce-0188.md)

**汉惠帝六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="十月朝廷改由左右丞相主持"></a>

<a id="event-1"></a>

1. **十月，朝廷改由左右丞相主持。** 王陵为右丞相，陈平为左丞相。 曹参去世后，中枢不再由他一人任相国，转由两位旧臣分担。王陵日后将因反对封吕氏为王失去相权，陈平则选择另一种应对方式。 [[1]](#note-1)

<a id="event-2"></a>

2. **长安城成之后，诸侯在京会集朝贺。** 这既是首都工程完成后的礼仪活动，也是地方封国与中央维系名分的场合。 [[2]](#note-2)

<a id="齐国换王留侯也离世"></a>

<a id="event-3"></a>

3. **齐王刘肥去世，其子刘襄继承齐王位。** 刘肥是惠帝的兄长，几年前献出城阳才平安离京；新齐王是高祖的孙子。刘襄的弟弟刘章、刘兴居后来在长安任宿卫，将把齐国与宫中政局直接连接起来。 [[3]](#note-3)

<a id="event-4"></a>

4. **夏季，张良去世。** 这位曾参与楚汉谋划、又在太子问题上帮助吕后的人，退出了新朝政治。周勃在本年的编年记录中出任太尉，但头衔本身并不保证后来能直接进入军营指挥士卒。 [[4]](#note-4)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-5"></a>

5. **周勃恢复太尉职位，继续进入中央的军事决策层。** 左右丞相的交接之外，将军与朝廷的关系也在调整；这次任命的异年见同号说明。 [原格与说明](#sj022-note)。 [[5]](#note-5)

## 归年与考证

<a id="sj022-note"></a>
<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[本年原表R018](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r018) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0189)。

> 纪年：六；大事纪：七月，齊悼惠王薨。立太倉、西市。；相位：一。十月己巳，安國侯王陵為右丞相。曲逆侯陳平為左丞相。；将位：堯抵罪。；御史大夫位：廣阿侯任敖為御史大夫。

王陵右相、陈平左相接本页十月交接；史表十月“己巳”与汉表“己丑”不同，正文不靠一个干支差别另造第二次任命。史表本年列赵尧抵罪、任敖接御史，汉表却以任敖起任于[前187年](bce-0187.md#sj022-note)，三年后曹窋接任，较能连贯；本年不据史格强立无异说的御史交接。汉表同时记周勃复任太尉，与史表[前184年](bce-0184.md#sj022-note)冲突，原格两存。

### 曹窋接平阳，阳陵等国也换了侯

**十月，曹窋开始记平阳侯元年。** 父亲曹参已经去世，曹窋接下家族爵邑，却没有同时继任相国；中央相权由上文王陵、陈平承担。阳陵、昌武和土军的承侯也在本年列出。

<a id="sj018-fankuai"></a>
**舞阳侯樊哙在本年去世。** 他经历了反秦、楚汉以及高祖晚年的边地战争，也曾在刘邦临终时被下令处死、由陈平改为押送，最后获吕后释放、恢复爵邑。他的儿子樊伉接爵，侯籍元年列在下一年；樊哙本人并未活到前180年的诛吕之变。[《樊郦滕灌列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7095.md#ref-3c2ba2b7476a7a) · [舞阳R018](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r018)

<a id="卷018两相一太尉及张良卒年的不同记法"></a>
#### 卷018｜两相、一太尉及张良卒年的不同记法

[安国R059](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r059)王陵惠六年右相与本页相合；[曲逆R009](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r009)陈平却提前列惠五年左相，沿通鉴六年十月，不在两年各任一次。[绛R017](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r017)高后四年太尉，与[《绛侯周勃世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7057.md#ref-fa58edd00ada4b)及通鉴惠六年任太尉不同，仍沿原主线，差别也回链[前184年](bce-0184.md)，不编一场无据的罢免复职。

[留侯R013](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r013)高后前三年列不疑元年，高后栏先计张良二年；[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-b9abd7fc064059)也记初封十六年薨、不疑高后三年嗣，指向张良前186年去世。通鉴明记本年夏卒，《留侯世家》的“后八年卒”又涉及起算问题。正文保留既有前189年通鉴主线，前186年只存异年，前185年登记不疑表元年，不把同一个张良再写死一次；也不宣称这一卒年已获所有版本一致支持。

四家侯位承继均有明确元年，没有具体月份的三家不借平阳十月补齐。单宁、单究等姓名差别继续由侯国、前后任与原格相认，不从谥号猜未载生年。樊哙死年则有列传明文惠六年，接位与表中次年元年分列；回顾其获释只是前195年的经历，不写成本年再入狱一次。

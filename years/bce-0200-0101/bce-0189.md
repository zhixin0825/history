# 公元前189年｜王陵、陈平分任丞相，齐王刘肥与张良去世

[← 公元前190年](bce-0190.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前188年 →](bce-0188.md)

**汉惠帝六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="十月朝廷改由左右丞相主持"></a>

<a id="event-1"></a>

1. **十月，朝廷改由左右丞相主持。** 王陵为右丞相，陈平为左丞相。 曹参去世后，中枢不再由他一人任相国，转由两位旧臣分担。王陵日后将因反对封吕氏为王失去相权，陈平则选择另一种应对方式。 任命接本年十月；曹参去世在上一古历年，不能因陈平传连叙而在这里再记一次死亡。 [[1]](#note-1)

<a id="event-2"></a>

2. **长安城成之后，诸侯在京会集朝贺。** 这既是首都工程完成后的礼仪活动，也是地方封国与中央维系名分的场合。 [[2]](#note-2)

<a id="齐国换王留侯也离世"></a>

<a id="event-3"></a>

3. **齐王刘肥去世，其子刘襄继承齐王位。** 刘肥从高祖六年前201封齐至本年，首尾记十三年；他是惠帝的兄长，几年前曾献城阳求得平安归国。刘襄本年承位，下一年才记哀王元年；其弟刘章、刘兴居后来入京宿卫，把齐国同宫廷政局连接起来。 [[3]](#note-3)

<a id="event-4"></a>

4. **夏季，张良去世。** 这位曾参与楚汉谋划、又在太子问题上帮助吕后的人，退出了新朝政治。周勃在本年的编年记录中出任太尉，但头衔本身并不保证后来能直接进入军营指挥士卒。 张良谥文成侯，子张不疑承侯。 [[4]](#note-4)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-5"></a>

5. **惠帝六年，周勃恢复太尉职位。** 朝廷重新设置太尉，周勃由列侯再入中央任职。 [原格与说明](#sj022-note)。 [[5]](#note-5)

<a id="sj054-event-6"></a>

<a id="hs-event-11"></a>

6. **曹窋接续曹参的平阳侯爵。** 曹窋开始平阳侯元年。曹参去世后由儿子曹窋承侯，本年十月起记新侯元年；这与上一年父卒、子承是同一传爵的相接阶段。平阳懿侯曹参一支，靖侯窋承爵。 [[6]](#sj054-note-6)

<a id="sj095-event-7"></a>

7. **舞阳侯樊哙去世。** 汉惠帝六年，舞阳侯樊哙去世，谥武。其子樊伉承袭，下一古历年开始记新侯元年。 [[7]](#note-7)

<a id="sj098-event-8"></a>

<a id="hs-event-12"></a>

8. **傅宽之子继任阳陵侯。** 阳陵侯傅宽上年去世，其子接续阳陵侯爵。阳陵景侯傅宽一支，顷侯清承爵。 [[8]](#note-8)

<a id="hs-event-9"></a>

9. **允许卖爵，并令未嫁女子缴五算。** 朝廷允许民众卖爵；十五岁至三十岁仍未成婚的女子被征五算。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **建长安西市并整修敖仓。** 朝廷兴建长安西市，并整修敖仓。 [[10]](#hs-note-10)

<a id="hs-event-13"></a>

11. **昌武靖信侯单究｜承爵。** 表载昌武靖信侯单究一支本年记载侯位承袭。表中所载事项为惠侯如意承爵。 [[11]](#hs-note-13)

<a id="hs-event-14"></a>

12. **土军式侯宣义｜承爵。** 表载土军式侯宣义一支本年记载侯位承袭。表中所载事项为孝侯莫如承爵。 [[12]](#hs-note-14)

#### 卷022｜将相表互见与异说

[本年原表R018](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r018) · [《汉书·百官公卿表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%88%86%E5%8D%B7/%E6%B1%89%E4%B9%A6/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0189)。

> 纪年：六；大事纪：七月，齊悼惠王薨。立太倉、西市。；相位：一。十月己巳，安國侯王陵為右丞相。曲逆侯陳平為左丞相。；将位：堯抵罪。；御史大夫位：廣阿侯任敖為御史大夫。

王陵右相、陈平左相接本页十月交接；史表十月“己巳”与汉表“己丑”不同，正文不靠一个干支差别另造第二次任命。史表本年列赵尧抵罪、任敖接御史，汉表却以任敖起任于[前187年](bce-0187.md#sj022-note)，三年后曹窋接任，较能连贯；本年不据史格强立无异说的御史交接。汉表同时记周勃复任太尉，与史表[前184年](bce-0184.md#sj022-note)冲突，原格两存。

#### 卷018｜两相、一太尉及张良卒年的不同记法

[安国R059](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r059)王陵惠六年右相与本页相合；[曲逆R009](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r009)陈平却提前列惠五年左相，沿通鉴六年十月，不在两年各任一次。[绛R017](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r017)高后四年太尉，与[《绛侯周勃世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7057.md#ref-fa58edd00ada4b)及通鉴惠六年任太尉不同，仍沿原主线，差别也回链[前184年](bce-0184.md)，不编一场无据的罢免复职。

[留侯R013](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r013)高后前三年列不疑元年，高后栏先计张良二年；[汉书功臣表](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-b9abd7fc064059)也记初封十六年薨、不疑高后三年嗣，指向张良前186年去世。通鉴明记本年夏卒，《留侯世家》的“后八年卒”又涉及起算问题。正文保留既有前189年通鉴主线，前186年只存异年，前185年登记不疑表元年，不把同一个张良再写死一次；也不宣称这一卒年已获所有版本一致支持。

四家侯位承继均有明确元年，没有具体月份的三家不借平阳十月补齐。单宁、单究等姓名差别继续由侯国、前后任与原格相认，不从谥号猜未载生年。樊哙死年则有列传明文惠六年，接位与表中次年元年分列；回顾其获释只是前195年的经历，不写成本年再入狱一次。

# 公元前190年｜长安城成，曹参去世，沛宫设为高祖原庙

[← 公元前191年](bce-0191.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前189年 →](bce-0189.md)

**汉惠帝五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="正月再征人筑城九月宣布城成"></a>

<a id="event-1"></a>

1. **正月再征人筑城，九月宣布城成。** 长安六百里内的男女再次被征发，所报人数十四万五千，三十日罢役。 此前已分段修筑，本年继续完成。九月，长安城成，朝廷赐民每户爵一级。 [[1]](#note-1)

<a id="event-2"></a>

<a id="hs-event-14"></a>

2. **夏季大旱，江河少水。** 夏季发生大旱，江河水少，有些溪谷断流。冬季又曾记有雷声、桃李开花、枣树结果的反常现象。城市施工和百姓生活所处的自然条件，并不总是平稳。夏大旱、河流少水。 [[2]](#note-2)

<a id="八月曹参去世"></a>

<a id="event-3"></a>

3. **八月己丑，曹参死于相位。** 他接萧何以后，以守住既定约束、减少政令扰动为主要做法。下一古历年改设左右丞相，王陵、陈平分别出任，汉廷的中枢安排又将变化。 曹参谥懿侯，儿子曹窋接续平阳侯爵；其侯元年在下一年记载。汉相任期前后约三年。 [[3]](#note-3)

<a id="沛县把高祖的一次归乡变成长期奉祀"></a>

<a id="event-4"></a>

4. **沛县把高祖的一次归乡，变成长期奉祀。** 沛宫被设为高祖原庙，旧日歌儿负责供奉乐舞。 为纪念刘邦归沛时的悲喜，当年教习歌曲的一百二十名少年被安排为乐人，以后缺额继续补足。一次乡里宴饮，转成持续的祭祀和纪念。 [[4]](#note-4)

   返乡、击筑唱大风和复免丰沛仍见[前195年](bce-0195.md#sj008-dafeng)，不在这里重新发生。

<a id="sj017-audience"></a>
<a id="吴燕两王入朝"></a>

<a id="event-5"></a>

5. **吴王刘濞、燕王刘建来到朝廷。** 刘濞是高祖兄长一支的后辈，刘建则是高祖的儿子。异地的王国仍与皇帝保持朝觐往来。 [[5]](#note-5)

<a id="sj019"></a>
<a id="封侯承袭与侯国的变化"></a>

<a id="sj019-r003-e01"></a>

<a id="event-6"></a>

<a id="hs-event-13"></a>

6. **刘到封平都侯。** 六月乙亥，他原是齐方将领，汉三年转向刘邦一方；这次是给早年归附和定齐之功授爵。《汉书》侯籍列平都孝侯刘到本年受封，所引月份、干支依表保留。 [[6]](#note-6)

<a id="sj098-event-7"></a>

7. **阳陵侯傅宽去世。** 傅宽曾随汉定三秦、攻齐、屯代，惠帝五年去世，谥景侯。侯表到次年才列继承人的元年。 [[7]](#note-7)

<a id="hs-event-8"></a>

<a id="hs-event-15"></a>

8. **冬雷与桃李开花、枣树结实。** 冬十月，书载雷声以及桃李开花、枣树结实。惠帝时桃李开花与枣实。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

<a id="sj054-cite-059"></a>

**[《史记·曹相国世家》P018](../../sources/摘录/史记-卷054-曹相国世家.md#p018)**

> 太史公曰：曹相國參攻城野戰之功所以能多若此者，以與淮陰侯俱。及信已滅，而列侯成功，唯獨參擅其名。參為漢相國，清靜極言合道。然百姓離秦之酷後，參與休息無為，故天下俱稱其美矣。

**白话附读：** 太史公说：曹参攻城、野战的功劳之所以这么多，是因为他曾同淮阴侯韩信一道作战。韩信被灭以后，在因功成就的列侯中，曹参独享显赫声名。曹参担任汉相国，奉行清静，极其合于道；百姓经历秦政酷烈之后，他使人民得以休息，不再多加作为，所以天下都称赞他的美政。这里是史家解释战功和政治声望的回顾，不能把独擅其名理解为否认其他功臣存在，也不把无为解释成相府没有任何行政工作。

**本卷说明：** 司马迁篇末评论，作为曹参一生的回顾附读，不是前190年的另一政令。

<!-- /sj054-cite-059 -->

<a id="sj054-cite-060"></a>

**[《史记·曹相国世家》Z001](../../sources/摘录/史记-卷054-曹相国世家.md#z001)**

> 【索隱述贊】曹參初起，為沛豪吏。始從中涓，先圍善置。執珪執帛，攻城掠地。衍氏既誅，昆陽失位。北禽夏說，東討田溉。剖符定封，功無與二。市獄勿擾，清淨不事。尚主平陽，代享其利。

**白话附读：** 司马贞的述赞说：曹参起初是沛县有势力的吏员，以中涓跟从起兵，早年攻围善置；历受执珪、执帛等爵，攻城取地。衍氏的反抗者受到讨伐，昆阳敌军败失阵地；向北攻夏说，向东讨田既，剖符定封，战功卓著。治理时不苛扰刑狱、市场，以清静少事为要。平阳侯后人又娶公主，爵禄代代相承。赞中主本田溉与正文田既、注本田旣不同，译文从所赞同一人物理解；昆阳失位承战事，不说曹参在昆阳丢官。尚主指曹时、曹襄等后裔，不能改成曹参本人娶了平阳公主。功无与二是赞颂语，不另行推翻萧何功臣位次居首的记载。

**本卷说明：** 唐司马贞述赞，与司马迁篇本文另层。主TXT先围／执珪／掠地／田溉和注本先图／执圭／略地／田旣的原字分存。

#### 卷024｜音乐史事的互见与归年

[卷024 P004](../../sources/摘录/史记-卷024-乐书.md#p004)概述高祖死后沛县四时歌舞宗庙，接本页[沛宫原庙旧记录](#sj008-yuanmiao)。[《高祖本纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7008.md#ref-a149f9ee4c1266)明确惠帝五年以沛宫为原庙、百二十歌儿改习吹乐并补缺；[《汉书·礼乐志》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7022.md#ref-4c26ea1fd2e4bb)也记惠帝时以沛宫为原庙，歌儿习吹相和、常以百二十人为员。因此《乐书》的死后概述与本页有据的设置连读，不在高祖卒年前195年又安排一次同样的惠帝原庙改设。

“孝惠、孝文、孝景无所增更”是本卷对沿习旧乐的概括；汉志仍记惠帝二年备箫管、更名安世乐，以及文帝四时舞、景帝改武德为昭德等事。不能把一句概括扩写为三朝任何音乐名称、仪式或舞制都从未变动。这里仅作对读，不称汉书礼乐志整卷已经编入。

#### 4｜两国来朝；纠正阶段稿多出的梁王

[卷017前190年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0190)只有吴、燕明确记来朝，梁栏仅“七”。阶段稿误添梁王刘恢，现据[固定原表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7017.md#ref-370ca5935fbccb)和[三家注卷017](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7017.md#ref-20fc18becf9280)撤回；撤回无据增写，不等于证明梁王本年绝不可能来朝。

下一古历年十月的城成朝贺另见[前189年](bce-0189.md#sj009-capital)，不能因为两个相邻年份都有“诸侯”，便断言同一场合重复发生或全体名单完全一致。燕王刘建不是后来江都、淄川的同名王；本年两位国王来朝的月份仍未载。

#### 卷018｜死亡、官职和侯位各有起点

傅宽死年据[《傅靳蒯成列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7098.md#ref-c26ff470862e2d)“孝惠五年卒”，不是由儿子元年机械倒算。[平阳R001](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r001)以惠帝五年结束曹参一代、六年十月列窋元年，与本页八月曹参卒相接，仍只记一次死亡。

四家承爵的姓名沿原表，繁侯新名在汉表有惸等异字，当前不另造改名仪式。陈平行写“其五年为左丞相”，但[通鉴](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7012.md#ref-00aacdf00a5755)明确安排在[前189年十月](bce-0189.md#sj009-ministers)，故本页不再先任一次左相；诸侯来朝及原庙旧事也不因本卷增补而改动。

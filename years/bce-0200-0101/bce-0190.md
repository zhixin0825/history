# 公元前190年｜长安城成，曹参去世，沛宫设为高祖原庙

[← 公元前191年](bce-0191.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前189年 →](bce-0189.md)

**汉惠帝五年**

## 正月再征人筑城，九月宣布城成

**长安六百里内的男女再次被征发，所报人数十四万五千，三十日罢役。** 此前已分段修筑，本年继续完成。九月，长安城成，朝廷赐民每户爵一级。[1](#sj009-complete)

**夏季发生大旱，江河水少，有些溪谷断流。** 冬季又曾记有雷声、桃李开花、枣树结果的反常现象。城市施工和百姓生活所处的自然条件，并不总是平稳。[1](#sj009-complete)

## 八月，曹参去世

**八月己丑，曹参死于相位。** 他接萧何以后，以守住既定约束、减少政令扰动为主要做法。下一古历年改设左右丞相，王陵、陈平分别出任，汉廷的中枢安排又将变化。[2](#sj009-caocan)

## 沛县把高祖的一次归乡，变成长期奉祀

**沛宫被设为高祖原庙，旧日歌儿负责供奉乐舞。** 为纪念刘邦归沛时的悲喜，当年教习歌曲的一百二十名少年被安排为乐人，以后缺额继续补足。一次乡里宴饮，转成持续的祭祀和纪念。[3](#sj008-yuanmiao)

返乡、击筑唱大风和复免丰沛仍见[前195年](bce-0195.md#sj008-dafeng)，不在这里重新发生。

<a id="sj017-audience"></a>
## 吴、燕两王入朝

**吴王刘濞、燕王刘建来到朝廷。** 刘濞是高祖兄长一支的后辈，刘建则是高祖的儿子。异地的王国仍与皇帝保持朝觐往来。[4](#sj017-note)

<a id="sj019"></a>
## 封侯、承袭与侯国的变化

<a id="sj019-r003-e01"></a>
六月乙亥，刘到受封平都侯，食邑千户。他原是齐方将领，汉三年转向刘邦一方；这次是给早年归附和定齐之功授爵。 [原文与说明](#sj019-r003-e01-n)

### 卷024｜音乐史事的互见与归年

[卷024 P004](../../sources/摘录/史记-卷024-乐书.md#p004)概述高祖死后沛县四时歌舞宗庙，接本页[沛宫原庙旧记录](#sj008-yuanmiao)。[《高祖本纪》](https://zh.wikisource.org/wiki/史記/卷008)明确惠帝五年以沛宫为原庙、百二十歌儿改习吹乐并补缺；[《汉书·礼乐志》](https://zh.wikisource.org/wiki/漢書/卷022)也记惠帝时以沛宫为原庙，歌儿习吹相和、常以百二十人为员。因此《乐书》的死后概述与本页有据的设置连读，不在高祖卒年前195年又安排一次同样的惠帝原庙改设。

“孝惠、孝文、孝景无所增更”是本卷对沿习旧乐的概括；汉志仍记惠帝二年备箫管、更名安世乐，以及文帝四时舞、景帝改武德为昭德等事。不能把一句概括扩写为三朝任何音乐名称、仪式或舞制都从未变动。这里仅作对读，不称汉书礼乐志整卷已经编入。

### 卷022｜将相表互见与异说

[本年原表R017](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r017) · [《汉书·百官公卿表》](https://zh.wikisource.org/wiki/漢書/卷019b)。

> 纪年：五；大事纪：為高祖立廟於沛城成，置歌兒一百二十人。八月乙丑，參卒。；相位：四；将位：〔空〕；御史大夫位：〔空〕

沛县高祖庙、歌儿一百二十人与曹参之死均接本页既有事件，不把歌儿当作本年新编的常备战兵。曹参卒日史表“乙丑”、汉表“己丑”异字，保留两见；没有历算结论，不给出一个声称已统一的公历日期。

<a id="sj009-complete"></a>
### 1｜竣工年采用汉书明确年条

[卷009 P008](../../sources/摘录/史记-卷009-吕太后本纪.md#p008)概写“五年六年城就”，[《汉书》卷002五年九月](https://zh.wikisource.org/wiki/漢書/卷002)明确城成，采用前190年；次年朝贺与此相连，不再造一次整体竣工。男女人数为记数，未确认与前192年征役是否同一批人。物候与旱灾依通鉴、汉书分别保存，不拿来验证政治吉凶。

<a id="sj009-caocan"></a>
### 2｜相国终局

[《通鉴》卷十二惠帝五年](https://zh.wikisource.org/wiki/資治通鑑/卷012)。此前任内做法见前193年，不将三年的行政实践都写成临死时才开始。

<a id="sj008-yuanmiao"></a>
### 3｜保留卷008原有原庙记录

[卷008 P069](../../sources/摘录/史记-卷008-高祖本纪.md#p069)明记惠帝五年、沛宫、一百二十歌儿及补额，未给月份。[前191年渭北原庙](bce-0191.md)出于复道问题，地点、来由不同。保留旧锚点及事件，不因添加筑城、曹参便撤掉沛宫材料；乐人数不是现存实名名册。

<a id="sj017-note"></a>
### 4｜两国来朝；纠正阶段稿多出的梁王

[卷017前190年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0190)只有吴、燕明确记来朝，梁栏仅“七”。阶段稿误添梁王刘恢，现据[固定原表](https://zh.wikisource.org/w/index.php?title=史記/卷017&oldid=2607010)和[三家注卷017](https://zh.wikisource.org/wiki/史記三家註/卷017)撤回；撤回无据增写，不等于证明梁王本年绝不可能来朝。

下一古历年十月的城成朝贺另见[前189年](bce-0189.md#sj009-capital)，不能因为两个相邻年份都有“诸侯”，便断言同一场合重复发生或全体名单完全一致。燕王刘建不是后来江都、淄川的同名王；本年两位国王来朝的月份仍未载。

## 阳陵侯傅宽去世，四家侯国开始新纪年

**傅宽在本年去世。** 他早年随刘邦入汉、定三秦，后来参与齐地战争，受封阳陵后还承担过中央和地方职务。爵位由儿子接续，侯籍到下一年才列新元年。[R005](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r005)

<a id="sj018-note"></a>
### 卷018｜死亡、官职和侯位各有起点

傅宽死年据[《傅靳蒯成列传》](https://zh.wikisource.org/wiki/史記/卷098)“孝惠五年卒”，不是由儿子元年机械倒算。[平阳R001](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r001)以惠帝五年结束曹参一代、六年十月列窋元年，与本页八月曹参卒相接，仍只记一次死亡。

四家承爵的姓名沿原表，繁侯新名在汉表有惸等异字，当前不另造改名仪式。陈平行写“其五年为左丞相”，但[通鉴](https://zh.wikisource.org/wiki/資治通鑑/卷012)明确安排在[前189年十月](bce-0189.md#sj009-ministers)，故本页不再先任一次左相；诸侯来朝及原庙旧事也不因本卷增补而改动。

# 公元前191年｜张氏成为皇后，挟书律被废，长安工程继续

[← 公元前192年](bce-0192.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前190年 →](bce-0190.md)

**汉惠帝四年**

## 十月，吕后安排亲上加亲的婚姻

**刘盈立张氏为皇后。** 张氏是鲁元公主与张敖的女儿，也就是刘盈姐姐的女儿。吕后希望用这层婚姻进一步巩固皇室与自己女儿一家的关系。[1](#sj009-empress)

## 三月，皇帝行冠礼，朝廷减少部分禁令

**刘盈举行冠礼，大赦天下，并省去妨害吏民的法令，废除挟书律。** 此前对收藏书籍的限制由此发生变化。正月又举荐孝悌、力田之人，给予复免，表明朝廷并未停止处理一般政务。[2](#sj009-laws)

**长安城的建设仍在推进。** 按本纪概述，到这一阶段已完成相当部分，最后城成还在下一年。[3](#sj009-wall)

## 为了减少出行清道，又牵出宗庙礼制问题

**刘盈常往长乐宫朝见母亲，清道扰民，便修复道来往。** 叔孙通指出，这条通道跨在高祖衣冠每月出游的路线之上，礼制不合。皇帝原想拆掉，叔孙通转而建议在渭北另立原庙、调整衣冠出游安排，朝廷采纳。[2](#sj009-laws)

同年长乐宫鸿台、未央宫凌室与织室先后记有火灾。它们是不同地点的记录，不合成一次全城大火。[2](#sj009-laws)

<a id="sj017-audience"></a>
## 四位诸侯王入朝

**楚王刘交、齐王刘肥、淮南王刘长、赵王刘友本年来朝。** 淮南、赵已换成高祖子弟，不再是英布和张敖。王国名字延续，掌权者却可能已经改变。[4](#sj017-note)

### 卷022｜将相表互见与异说

[本年原表R016](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r016) · [《汉书·百官公卿表》](https://zh.wikisource.org/wiki/漢書/卷019b)。

> 纪年：四；大事纪：三月甲子，赦，無所復作。；相位：三；将位：〔空〕；御史大夫位：〔空〕

三月甲子赦令接本页冠礼及减禁令；“无所复作”按所用原年条解释赦后的处置，不泛化成汉朝此后永久免除全部徭役。相位“三”仍为曹参的第三个任期年。



<a id="sj009-empress"></a>
### 1｜立后与后来养子分开

[卷009 P018](../../sources/摘录/史记-卷009-吕太后本纪.md#p018)回叙张皇后无子、取后宫美人子；[《汉书》卷002四年十月壬寅](https://zh.wikisource.org/wiki/漢書/卷002)给出立后年次。收养、立太子与杀生母的故事未各给年，作为前188年继承背景处理，不都定成本年婚礼同时发生。本纪此处不载皇后个人名字，正文只称张氏。

<a id="sj009-laws"></a>
### 2｜法令、复道与原庙

[《通鉴》卷十二惠帝四年](https://zh.wikisource.org/wiki/資治通鑑/卷012)。废挟书律不等于秦焚书损失已恢复，更不等于从此没有一切言论和文本限制。渭北原庙是本年复道争议的结果，与[前190年沛宫原庙](bce-0190.md)地点不同，不合成同一建筑的两个开工年。司马光批评叔孙通“人主无过举”的评论是宋人评语，不是皇帝当时说的话。

<a id="sj009-wall"></a>
### 3｜分期筑城

[卷009 P008](../../sources/摘录/史记-卷009-吕太后本纪.md#p008)“四年就半”是概括，不据它计算精确工程完成率、墙体长度或用工日数。

<a id="sj017-note"></a>
### 4｜卷017四个来朝格；纠正阶段稿多出的梁王

[卷017前191年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0191)楚、齐、淮南、赵分别记来朝，梁栏只有“六”，没有“来朝”。阶段稿误把梁王刘恢加入名单，本轮对照[固定原表](https://zh.wikisource.org/w/index.php?title=史記/卷017&oldid=2607010)及[三家注卷017](https://zh.wikisource.org/wiki/史記三家註/卷017)改正。这里撤回的是本项目无原文支持的增写，不是断言梁王本年绝不可能入朝。

格中没有来朝月份，不将四人全部安插进张皇后立后或惠帝冠礼的现场。赵王刘友已从淮阳迁赵，梁王刘恢尚未迁赵，两兄弟的名号不能混用；本次修订保留原有正文和所有明确锚点。

<a id="sj018-succession"></a>
## 周昌等功臣的侯爵传到下一代

**周昌一支开始以开方记侯年，表中转列建平。** 周昌曾以御史大夫守住朝廷的法度，又在赵地保护刘如意；继承人得到侯爵，并不是同时接掌他曾任的御史大夫或赵相职位。[R020](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r020)

**新阳、武原、义陵三处侯籍也换了在位者。** 新阳由臣接续吕清一支，武原由寄接续卫胠，义陵由种接续吴程。最后一支原与长沙国的军政有关，不能因为都列入汉的功臣表就抹去各自不同的政治关系。[新阳R028](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r028) · [武原R081](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r081) · [义陵R102](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r102)

<a id="sj018-note"></a>
### 卷018｜四项承侯的定位

四格均明记惠帝四年新元年，参[汉书功臣表](https://zh.wikisource.org/wiki/漢書/卷016)的嗣侯记录。建平国名在汾阴行中另起，本文不把它说成周昌与开方同日各获一个新侯国；具体迁封手续原格未详。义陵初封者吴程／吴郢、继者种／重的异写保留，未知卒月不倒推。新阳的臣与宁陵吕臣同名，尚无足够材料合并，二者分国叙述。

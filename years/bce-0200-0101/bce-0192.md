# 公元前192年｜大批民众修长安城，吕后没有因冒顿来书开战

<a id="春季与六月分批征人营筑长安"></a>

<a id="event-1"></a>

1. **春季与六月，分批征人营筑长安。** 春天，长安六百里以内的男女被征来筑城，所报人数十四万六千，三十日后停役。 六月又征诸侯王、列侯所属徒隶二万人继续工程。首都的防卫和城市建设，仍需要大量人力，并不是休养生息就从此没有徭役。 [[1]](#note-1)

<a id="匈奴的挑衅引出战与和的争论"></a>

<a id="event-2"></a>

2. **匈奴的挑衅，引出战与和的争论。** 冒顿给吕后写来带侮辱意味的书信，吕后愤怒，召集将相商议。 樊哙提出愿带十万人横行匈奴境内，季布当面反对：高祖平城被围时大军尚且难解，如今伤病未复，不能再凭一句豪言把天下拖入战争。 [[2]](#note-2)

<a id="event-3"></a>

3. **吕后接受劝阻，派使者回信、赠送车马，继续和亲。** 朝廷又以宗室女为公主嫁单于。这次交涉没有演变成一次由吕后发动的大规模北伐。 [[3]](#note-3)

<a id="event-4"></a>

4. **五月，摇被立为东海王，都东瓯。** 摇和无诸的先世都追溯到勾践，秦并天下时其地曾置闽中郡，地方首领被降为君长；二人后来率越人助诸侯灭秦，又助汉击项羽。无诸已在汉五年受立为闽越王，本年朝廷再按高帝时的越人功劳，认定摇有功而民众亲附，立他为东海王，都东瓯，俗称东瓯王。同年南越王赵佗称臣奉贡，京城都厩发生火灾。 [[4]](#note-4)

### 2. 冒顿给吕后写来带侮辱意味的书信，吕后愤怒，召集将相商议

[返回正文第2条](#event-2)

<a id="hs094-l9773-e2"></a>

**[《汉书·匈奴传》P015](../../sources/摘录/汉书-卷094-匈奴传.md#p015)** · [仓内TXT L9773](../../sources/本地分卷/汉书/汉书-卷094.md#L9773)

> 孝惠、高后時，冒頓寖驕，乃為書，使使遺高后曰：「孤僨之君，生於沮澤之中，長於平野牛馬之域，數至邊境，願遊中國。陛下獨立，孤僨獨居。兩主不樂，無以自虞，願以所有，易其所無。」高后大怒，召丞相平及樊噲、季布等，議斬其使者，發兵而擊之。樊噲曰：「臣願得十萬眾，橫行匈奴中。」問季布，布曰：「噲可斬也！前陳豨反於代，漢兵三十二萬，噲為上將軍，時匈奴圍高帝於平城，噲不能解圍。天下歌之曰：『平城之下亦誠苦！七日不食，不能彀弩。』今歌吟之聲未絕，傷痍者甫起，而噲欲搖動天下，妄言以十萬眾橫行，是面謾也。且夷狄譬如禽獸，得其善言不足喜，惡言不足怒也。」

**互校说明** 所说“孝惠、高后時”为宽泛时段，《通鉴》置孝惠三年；此条收来书与是否出兵之议。

<a id="hs037-l7113-e2"></a>

**[《汉书·季布栾布田叔传》P002](../../sources/摘录/汉书-卷037-季布栾布田叔传.md#p002)** · [仓内TXT L7113](../../sources/本地分卷/汉书/汉书-卷037.md#L7113)

> 孝惠時，為中郎將。單于嘗為書嫚呂太后，太后怒，召諸將議之。上將軍樊噲曰：「臣願得十萬眾，橫行匈奴中。」諸將皆阿呂太后，以噲言為然。布曰：「樊噲可斬也。夫以高帝兵三十餘萬，困於平城，噲時亦在其中。今噲奈何以十萬眾橫行匈奴中，面謾！且秦以事胡，陳勝等起。今瘡痍未瘳，噲又面諛，欲搖動天下。」是時殿上皆恐，太后罷朝，遂不復議擊匈奴事。

**互校说明** 《资治通鉴》系在惠帝三年，和前200年平城的回叙分别处理。

<a id="sj110-p014-e2"></a>

**[《史记·匈奴列传》P014](../../sources/摘录/史记-卷110-匈奴列传.md#p014)** · [三家注](../../sources/史记三家注/卷110.md#p14)

> 冒頓乃爲書遺高后，妄言。高后欲擊之，諸將曰：「以高帝賢武，然尚困於平城。」

**本卷归年说明：** 《通鉴》系惠帝三年。《汉书》列樊哙、季布对答，本传概言诸将。


<a id="sj100-p001"></a>

**[《史记·季布栾布列传》P001](../../sources/摘录/史记-卷100-季布栾布列传.md#p001)** · [三家注](../../sources/史记三家注/卷100.md#p1)

> 孝惠時，爲中郎將。單于嘗爲書嫚呂后，不遜，呂后大怒，召諸將議之。上將軍樊噲曰：「臣願得十萬衆，橫行匈奴中。」諸將皆阿呂后意，曰「然」。季布曰：「樊噲可斬也！夫高帝將兵四十餘萬衆，困於平城，今噲奈何以十萬衆橫行匈奴中，面欺！且秦以事於胡，陳勝等起。于今創痍未瘳，噲又面諛，欲搖動天下。」是時殿上皆恐，太后罷朝，遂不復議擊匈奴事。

<a id="射阳侯去世另外几家功臣由后人承爵"></a>
### 射阳侯去世，另外几家功臣由后人承爵

**曾在鸿门帮助刘邦的项伯，如今已经姓刘、名缠，在本年去世。** 他的继承人雎又因获罪未能承接，射阳侯国终止。此前楚、汉的身份转换并没有保住这支爵位永久传下去。[R014](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r014)

**酂侯由萧禄接续，另外七家也开始新的侯年。** 同在一年出现的承爵不是同一次重新论军功，更不能据排列先后推定各家的丧事发生在同一天。

<a id="sj018-note"></a>
<a id="卷018明确死年与元年格的区别"></a>
#### 卷018｜明确死年与元年格的区别

射阳格明写惠帝三年卒，[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-eb4762e05d4313)亦以同年记缠薨、嗣子雎有罪不得代；本表子名作睢，属于异写，不另造两个儿子。罪名与具体处置日没有记下，不补写为谋反或同日处死。

其余八家以承侯元年定位，前任死时未必就在本年，未由数字倒推一场有确日的葬礼。吕则格末“有罪”与后来的吕禄封胡陵相接，具体时序留[高后元年](bce-0187.md)的说明；不让同一吕则在本年及高后时各被废一次。萧禄之后“同”的亲缘涉及表文分歧，另在[前186年](bce-0186.md)处理，不凭史表“弟”字先把家族女性写成男性。

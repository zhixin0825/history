### 春季与六月，分批征人营筑长安

<a id="event-1"></a>

1. **春天，长安六百里以内的男女被征来筑城，所报人数十四万六千，三十日后停役。** 六月又征诸侯王、列侯所属徒隶二万人继续工程。首都的防卫和城市建设，仍需要大量人力，并不是休养生息就从此没有徭役。 [[1]](#note-1)

<a id="匈奴的挑衅引出战与和的争论"></a>
### 匈奴的挑衅，引出战与和的争论

<a id="event-2"></a>

2. **冒顿给吕后写来带侮辱意味的书信，吕后愤怒，召集将相商议。** 樊哙提出愿带十万人横行匈奴境内，季布当面反对：高祖平城被围时大军尚且难解，如今伤病未复，不能再凭一句豪言把天下拖入战争。 [[2]](#note-2)

<a id="event-3"></a>

3. **吕后接受劝阻，派使者回信、赠送车马，继续和亲。** 朝廷又以宗室女为公主嫁单于。这次交涉没有演变成一次由吕后发动的大规模北伐。 [[3]](#note-3)

<a id="event-4"></a>

4. **五月，摇被立为东海王，都东瓯。** 他在秦亡时跟随诸侯作战，在越人中有基础；汉通过承认地方首领的王号维系东南关系。同年南越王赵佗称臣奉贡，京城都厩则发生火灾。 [[4]](#note-4)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-5"></a>

5. **蜀地湔氐起兵，汉军出兵镇压。** 首都在征人筑城的同时，远在西南的统治也仍需军队维持；这条简记没有留下统帅、兵力与战斗经过。 [原格与说明](#sj022-note)。 [[5]](#note-5)

#### 2｜外交和地方补充

冒顿书信、樊哙与季布争论依《通鉴》三年条；书信具体传递过程没有独立逐日记录，不补婚约女子姓名。季布用来贬斥匈奴的用语属于当时发言，正文不接受为对民族的评价。东海王及南越奉贡见汉书同年；摇的旧日军功是受封理由，不全部发生在本年。蜀湔氐同年反抗后被平定的短条也见通鉴，材料未详，不补战斗经过。

<a id="射阳侯去世另外几家功臣由后人承爵"></a>
### 射阳侯去世，另外几家功臣由后人承爵

**曾在鸿门帮助刘邦的项伯，如今已经姓刘、名缠，在本年去世。** 他的继承人雎又因获罪未能承接，射阳侯国终止。此前楚、汉的身份转换并没有保住这支爵位永久传下去。[R014](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r014)

**酂侯由萧禄接续，另外七家也开始新的侯年。** 同在一年出现的承爵不是同一次重新论军功，更不能据排列先后推定各家的丧事发生在同一天。

<a id="卷018明确死年与元年格的区别"></a>
#### 卷018｜明确死年与元年格的区别

射阳格明写惠帝三年卒，[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-eb4762e05d4313)亦以同年记缠薨、嗣子雎有罪不得代；本表子名作睢，属于异写，不另造两个儿子。罪名与具体处置日没有记下，不补写为谋反或同日处死。

其余八家以承侯元年定位，前任死时未必就在本年，未由数字倒推一场有确日的葬礼。吕则格末“有罪”与后来的吕禄封胡陵相接，具体时序留[高后元年](bce-0187.md)的说明；不让同一吕则在本年及高后时各被废一次。萧禄之后“同”的亲缘涉及表文分歧，另在[前186年](bce-0186.md)处理，不凭史表“弟”字先把家族女性写成男性。

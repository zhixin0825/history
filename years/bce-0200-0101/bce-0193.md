# 公元前193年｜刘肥献城阳脱险，萧何去世，曹参接任

[← 公元前194年](bce-0194.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前192年 →](bce-0192.md)

**汉惠帝二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="十月的一场家宴变成齐王的危机"></a>

<a id="event-1"></a>

1. **十月的一场家宴，变成齐王的危机。** 楚王刘交、齐王刘肥来到京城，刘盈以兄长之礼招待刘肥。 在吕后面前饮酒时，他让刘肥坐上位，像普通家庭里的兄弟一样相处。吕后发怒，准备毒酒让齐王敬寿；刘盈也起身取杯，要一同祝酒，吕后怕伤到儿子。 [[1]](#note-1)

<a id="event-2"></a>

2. **刘肥察觉不对，装醉离席，得知酒中有毒后十分害怕。** 齐内史劝他，太后亲生的只有惠帝和鲁元公主，而齐国有七十余城，不如献出城阳郡，供公主取得汤沐邑的赋税收入。刘肥接受，汉传还记以公主为王太后的尊号安排。吕后高兴，重新设宴，准许他回齐。这个礼仪称号不能改写成刘肥与鲁元的亲生母子关系；惠帝起身同祝寿，原典也没有明说他已知毒酒而故意救兄。 [[2]](#note-2)

<a id="七月萧何死曹参入京接任相国"></a>

<a id="event-3"></a>

3. **七月，萧何死，曹参入京接任相国。** 萧何病重时，刘盈亲自探望，询问谁能接替他。萧何说知臣莫如主；皇帝提到曹参，他便叩头赞同，说死而无憾。两人早年相善，任将相后虽有隔阂，萧何临终仍只推曹参。七月辛未，萧何去世，谥文终侯；癸巳，原在齐国为相的曹参被任为汉相国。曹参听到死讯便命舍人准备行装，说将入朝为相，随后果被召；临别告诫后任齐相，把刑狱、市场视为特别托付，切勿苛扰。被问是否没有更大政务时，他解释两处兼容善恶，若穷治而使奸人无容身之处，反会生事。萧何平日买田宅常取偏僻之处，不修华美墙屋，说后代贤则学俭，不贤亦免遭势家夺产；这是生平家训附叙，不是本年新置产。 [[3]](#note-3)

<a id="event-4"></a>

4. **曹参接任后，没有急着改动萧何留下的法令安排。** 他偏用稳重少文饰的官吏，排斥苛细求名的人，强调守住既定制度，让百姓少受折腾。这与宫廷中围绕王位和尊卑的紧张同时存在，并不互相抵消。 其相齐问儒、聘盖公及相汉期间的饮客、和歌、曹窋进谏等，分别见[任期故事](未定年-曹氏相政与平阳侯家事.md)；这些故事都没有可以单独落在本年的确日。 [[4]](#note-4)

<a id="event-5"></a>

5. **地方也有灾情：陇西地震，夏季干旱。** 同年合阳侯刘仲去世，他是高祖的兄长、曾经的代王。 [[5]](#note-5)

<a id="sj017-changsha"></a>
<a id="长沙由吴回接续王位"></a>

<a id="event-6"></a>

6. **长沙开始记吴回元年，吴氏的异姓王国继续保留。** 前一位吴臣已结束统治，王统由吴回承接。其他异姓功臣王先后失势，并不意味着长沙在同一时刻也被撤销。 [[6]](#note-6)

<a id="sj019"></a>
<a id="封侯承袭与侯国的变化"></a>

<a id="sj019-r002-e01"></a>

<a id="event-7"></a>

7. **四月庚子，长沙国丞相利苍受封轪侯，食邑七百户。** 他以王国丞相的身份进入汉廷侯籍，官职与可以传给后人的爵位并非一回事。 [[7]](#note-7)

#### 1｜宴饮、毒酒与献郡

[卷009 P007](../../sources/摘录/史记-卷009-吕太后本纪.md#p007) · [《汉书》卷002二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7002.md#ref-c1925cd46fb7a8)。献城阳与准归在两书可互见，毒酒场景依本纪叙述。公主所受“王太后／太后”尊号特殊，不等于刘肥改认妹妹为生母；政治称号不能改写血缘。内史原文仅称“士”，本页不用它猜出完整姓名。

#### 2｜丞相与灾情是编年底本补充

[《通鉴》卷十二惠帝二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7012.md#ref-329387fbfc8650)。这些材料说明司马迁篇末休息、少扰民的评价有怎样的政治背景，本页与两篇世家的整卷读本相接，具体范围见各卷核验记录。曹参任内的“不改约束”是持续做法，未把全部饮酒、父子问政故事强定在上任当日。所谓兰陵井中见龙另属神异记载，不与地震、干旱共同解释为神意。

#### 3｜长沙继承与楚齐来朝互见

[卷017前193年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0193)楚、齐来朝归本页十月同一事件，不重复宴饮；长沙“哀王回元年”与[汉书异姓诸侯王表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7013.md#ref-b70d0bef5a7c18)“哀王回嗣”同年。哀王为后谥，不解释成本年已死；元年也不提供受位、前王死亡的确日，未据相邻数字补造一场有日期的丧礼。

<a id="汲侯由武承接"></a>
### 汲侯由武承接

**公上不害的侯爵由武接续，本年开始新的侯年。** 前任是在高祖晚年凭讨代地的军功受封，武承接的是已经建立的爵邑，并非本年又新设一个同名侯国。[汲R118](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r118)

<a id="sj018-note"></a>
<a id="卷018侯位传承与中央相位不是同一种继任"></a>
#### 卷018｜侯位传承与中央相位不是同一种继任

[平阳R001](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r001)惠帝二年为相国与本页曹参接萧何同事；[酂R015](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r015)萧禄元年却在下一年。曹参接的是中央官职，萧禄承的是父亲的侯爵，不能把二者混成曹参继承酂侯。萧何死年另有[《萧相国世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7053.md#ref-cffc622629a77f)明确惠帝二年相合。

[合阳R095](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r095)以“二”结束刘仲的惠帝朝计年，再追叙儿子刘濞为吴王及父亲谥号；吴王受位早在前195年，本页不重封一次。汲侯武承爵的具体月日与父亲死亡日未载，不据元年强推确日。

# 公元前194年｜如意被杀，刘友迁赵，惠帝受到沉重打击

[← 公元前195年](bce-0195.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前193年 →](bce-0193.md)

**汉惠帝元年**

> 本页按汉初古史年条归档。十二月在本年正月之前，不能直接读成现代公历前194年12月。

## 十二月，惠帝暂时离开，赵王就被杀了

**刘盈把异母弟弟刘如意接到宫里，吃住都带在身边，吕后一直找不到机会下手。** 一天清晨，皇帝出去射猎，年幼的如意没有早起。吕后得知他独处，派人送去毒酒。天亮以后刘盈返回，弟弟已经死亡。此前赵相周昌拒绝送王入京、刘盈亲迎保护，都没有最终保住他。[1](#sj009-005-note)

**淮阳王刘友随即迁为赵王。** 赵国仍由刘邦的儿子统治，但原先围绕如意安排的保护和继承已经结束。刘友以后在赵的处境，接见[前181年](bce-0181.md)。[2](#sj008-son)

## 戚夫人遭残害，刘盈无法接受母亲的做法

**被囚的戚夫人遭到严重残害，吕后称她为“人彘”，又让惠帝前去观看。** 刘盈问明眼前的人是谁以后大哭，随后患病。他托人告诉母亲，这不是人应做出的事，自己无法继续治理天下。此后的传世叙事把他的饮酒、少理政事与这次打击联系起来。[3](#sj009-006-note)

**夏季，朝廷追谥吕后的长兄吕泽为令武侯。** 吕泽生前为将，两个儿子吕台、吕产已经分别有郦侯、交侯之爵；吕家的地位并非全从吕后称制以后才出现。[3](#sj009-006-note)

## 皇帝的家庭遇到危机，首都工程仍在进行

**正月，开始营筑长安城西北一带的城墙。** 宫殿早已逐步建成，城市外围的营筑还要继续。后来的大规模征役与竣工分别见前192、190年，不是本年一次施工就全部完成。[4](#sj009-city-note)

<a id="sj019"></a>
## 封侯、承袭与侯国的变化

<a id="sj019-r001-e01"></a>
九月，长沙王之子吴浅受封便侯，食邑二千户。长沙王国仍由吴氏承袭，王子另受侯爵，形成王国以外的一支封邑。 [原文与说明](#sj019-r001-e01-n)

### 1｜召入京和被害分年

[卷009 P004—P005](../../sources/摘录/史记-卷009-吕太后本纪.md#p004) · [《通鉴》卷十二，惠帝元年](https://zh.wikisource.org/wiki/資治通鑑/卷012)。周昌被召、如意入京与惠帝保护见前195年；本年十二月发生毒杀。具体行动沿本纪及通鉴的叙事，不拿其他后出故事的缢杀版本拼成两次死亡，亦不补公历确日。

<a id="sj008-son"></a>
### 2｜原有刘友迁王记录

[卷008 P070](../../sources/摘录/史记-卷008-高祖本纪.md#p070)与[卷009 P005](../../sources/摘录/史记-卷009-吕太后本纪.md#p005)同事合并，旧锚点保留。高祖本纪“吕太后时”包括惠帝朝，不等于高后元年前187年；“幽”是后来谥号，此时只称赵王。

<a id="sj009-006-note"></a>
### 3｜戚夫人案的月次与惠帝的病期

[卷009 P006](../../sources/摘录/史记-卷009-吕太后本纪.md#p006)。本纪在夏季追谥吕泽之后接戚夫人案，《通鉴》则连在十二月如意被杀之后。本页保留本年，戚案不另定月份。书中一年多不能起、不听政是跨时概述，不能推出刘盈以后再没有朝会、诏令、问相等活动，更不能凭文字给他作现代医学诊断。

<a id="sj009-city-note"></a>
### 4｜筑城的开端

[卷009 P008](../../sources/摘录/史记-卷009-吕太后本纪.md#p008)概述三年至五六年筑城；[《汉书》卷002元年](https://zh.wikisource.org/wiki/漢書/卷002)、通鉴已记本年开工。采用分期工程解释，不把概述中的“三年”当成此前绝无施工的断言。

<a id="sj018-succession"></a>
## 成、高苑、清三处侯国由后人承接

**开国将领的爵位开始转到下一代手中。** 董渫一支的成侯由赤接续，高苑由得接续丙倩，清侯由圣接续空中。三人的侯年都从本年起算，原来因反秦、楚汉战争取得的封邑由此继续传承，而不是三人又各完成一遍父辈的军功。

<a id="sj018-note"></a>
### 卷018｜承爵元年不是重新册封功臣

三格均在惠帝元年开始记后任侯的王年；父系和前爵由本行侯功、初封及[汉书功臣表](https://zh.wikisource.org/wiki/漢書/卷016)核对。这里只记承爵及新元年，不反推三位前任均在本年同日死亡，也不补未载的丧礼。高苑／高宛、丙倩／丙猜的字形差别仍见原表，不另造两个侯国和两位功臣。

1. **吕后毒杀刘如意、残害戚夫人，刘友迁王赵。** 十二月，刘盈把异母弟弟刘如意接到宫里，吃住都带在身边，吕后一直找不到机会下手。一天清晨，皇帝出去射猎，年幼的如意没有早起。吕后得知他独处，派人送去毒酒。天亮以后刘盈返回，弟弟已经死亡。此前赵相周昌拒绝送王入京、刘盈亲迎保护，都没有最终保住他。淮阳王刘友随即迁为赵王。赵国仍由刘邦的儿子统治，但原先围绕如意安排的保护和继承已经结束。刘友以后在赵的处境，接见[前181年](bce-0181.md)。戚夫人遭残害，刘盈无法接受母亲的做法。被囚的戚夫人遭到严重残害，吕后称她为“人彘”，又让惠帝前去观看。刘盈问明眼前的人是谁以后大哭，随后患病。他托人告诉母亲，这不是人应做出的事，自己无法继续治理天下。此后的传世叙事把他的饮酒、少理政事与这次打击联系起来。 [[1]](#note-1)

<a id="event-4"></a>

2. **夏季，朝廷追谥吕后的长兄吕泽为令武侯。** 吕泽生前为将，两个儿子吕台、吕产已经分别有郦侯、交侯之爵；吕家的地位并非全从吕后称制以后才出现。 [[2]](#note-4)

<a id="皇帝的家庭遇到危机首都工程仍在进行"></a>

<a id="event-5"></a>

3. **正月，开始营筑长安城西北一带的城墙。** 宫殿早已逐步建成，城市外围的营筑还要继续。后来的大规模征役与竣工分别见前192、190年，不是本年一次施工就全部完成。 [[3]](#note-5)

4. **长沙王之子吴浅受封便侯。** 九月，长沙王国仍由吴氏承袭，王子另受侯爵，形成王国以外的一支封邑。《汉书》侯籍列便顷侯吴浅本年受封，所引月份、干支依表保留。 [[4]](#note-6)

<a id="sj054-event-7"></a>

5. **诸侯国相国改称丞相。** 朝廷取消诸侯国设相国的制度，曹参因此由齐相国改为齐丞相。这是官称调整，相齐的任期继续计算。 [[5]](#sj054-note-7)

<a id="hs-event-8"></a>

6. **许以购爵赎死并赐户爵。** 朝廷允许有罪者购买三十级爵以赎死，并另按户赐爵一级。 [[6]](#hs-note-8)

<a id="hs-event-9"></a>

7. **成敬侯董渫｜承爵。** 表载成敬侯董渫一支本年记载侯位承袭。表中所载事项为康侯赤承爵。 [[7]](#hs-note-9)

<a id="hs-event-10"></a>

8. **高宛制侯丙猜｜承爵。** 表载高宛制侯丙猜一支本年记载侯位承袭。表中所载事项为简侯得承爵。 [[8]](#hs-note-10)

<a id="hs-event-11"></a>

9. **清简侯室中同｜承爵。** 表载清简侯室中同一支本年记载侯位承袭。表中所载事项为顷侯圣承爵。 [[9]](#hs-note-11)

<a id="hs-event-13"></a>

10. **刘泽任卫尉。** 刘泽任卫尉。参见本年的官职变动原句。 [[10]](#hs-note-13)

[卷009 P006](../../拆分史书/史记/卷009.md#p006)。本纪在夏季追谥吕泽之后接戚夫人案，《通鉴》则连在十二月如意被杀之后。本页保留本年，戚案不另定月份。书中一年多不能起、不听政是跨时概述，不能推出刘盈以后再没有朝会、诏令、问相等活动，更不能凭文字给他作现代医学诊断。

<a id="成高苑清三处侯国由后人承接"></a>
### 成、高苑、清三处侯国由后人承接

**开国将领的爵位开始转到下一代手中。** 董渫一支的成侯由赤接续，高苑由得接续丙倩，清侯由圣接续空中。三人的侯年都从本年起算，原来因反秦、楚汉战争取得的封邑由此继续传承，而不是三人又各完成一遍父辈的军功。

<a id="卷018承爵元年不是重新册封功臣"></a>
#### 卷018｜承爵元年不是重新册封功臣

三格均在惠帝元年开始记后任侯的王年；父系和前爵由本行侯功、初封及[汉书功臣表](../../拆分史书/汉书/卷016.md#part-1-text)核对。这里只记承爵及新元年，不反推三位前任均在本年同日死亡，也不补未载的丧礼。高苑／高宛、丙倩／丙猜的字形差别仍见原表，不另造两个侯国和两位功臣。

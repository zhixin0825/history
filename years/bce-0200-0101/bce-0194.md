# 公元前194年｜如意被杀，刘友迁赵，惠帝受到沉重打击

[← 公元前195年](bce-0195.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前193年 →](bce-0193.md)

**汉惠帝元年**

> 本页按汉初古史年条归档。十二月在本年正月之前，不能直接读成现代公历前194年12月。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="十二月惠帝暂时离开赵王就被杀了"></a>

<a id="event-1"></a>

1. **十二月，惠帝暂时离开，赵王就被杀了。** 刘盈把异母弟弟刘如意接到宫里，吃住都带在身边，吕后一直找不到机会下手。 一天清晨，皇帝出去射猎，年幼的如意没有早起。吕后得知他独处，派人送去毒酒。天亮以后刘盈返回，弟弟已经死亡。此前赵相周昌拒绝送王入京、刘盈亲迎保护，都没有最终保住他。 [[1]](#note-1)

<a id="event-2"></a>

2. **淮阳王刘友随即迁为赵王。** 赵国仍由刘邦的儿子统治，但原先围绕如意安排的保护和继承已经结束。刘友以后在赵的处境，接见[前181年](bce-0181.md)。 [[2]](#note-2)

<a id="戚夫人遭残害刘盈无法接受母亲的做法"></a>

<a id="event-3"></a>

3. **戚夫人遭残害，刘盈无法接受母亲的做法。** 被囚的戚夫人遭到严重残害，吕后称她为“人彘”，又让惠帝前去观看。 刘盈问明眼前的人是谁以后大哭，随后患病。他托人告诉母亲，这不是人应做出的事，自己无法继续治理天下。此后的传世叙事把他的饮酒、少理政事与这次打击联系起来。 [[3]](#note-3)

<a id="event-4"></a>

4. **夏季，朝廷追谥吕后的长兄吕泽为令武侯。** 吕泽生前为将，两个儿子吕台、吕产已经分别有郦侯、交侯之爵；吕家的地位并非全从吕后称制以后才出现。 [[4]](#note-4)

<a id="皇帝的家庭遇到危机首都工程仍在进行"></a>

<a id="event-5"></a>

5. **正月，开始营筑长安城西北一带的城墙。** 宫殿早已逐步建成，城市外围的营筑还要继续。后来的大规模征役与竣工分别见前192、190年，不是本年一次施工就全部完成。 [[5]](#note-5)

<a id="sj019"></a>
<a id="封侯承袭与侯国的变化"></a>

<a id="sj019-r001-e01"></a>

<a id="event-6"></a>

6. **九月，长沙王之子吴浅受封便侯，食邑二千户。** 长沙王国仍由吴氏承袭，王子另受侯爵，形成王国以外的一支封邑。 [[6]](#note-6)

<a id="sj054-event-7"></a>

7. **诸侯国相国改称丞相。** 朝廷取消诸侯国设相国的制度，曹参因此由齐相国改为齐丞相。这是官称调整，相齐的任期继续计算。 [[7]](#sj054-note-7)

#### 卷022｜将相表互见与异说

> 纪年：孝惠元年；大事纪：趙隱王如意死。始作長安城西北方。除諸侯丞相為相。；相位：十三；将位：〔空〕；御史大夫位：〔空〕

刘如意遇害、长安城工程均已有叙事。“除诸侯丞相为相”在本表列惠帝元年，但《孝景本纪》中五年及《汉书》官制记载在[前145年](bce-0145.md)；吕后时仍可见“齐丞相”称号，四库本考证据此质疑本格。正文不在本年提前宣布一次已经确证的全国改名，原格仍保存；王国相与中央相国也不混为一职。相位“十三”承接萧何在高祖时代的任期，并非惠帝十三年。

<a id="成高苑清三处侯国由后人承接"></a>
### 成、高苑、清三处侯国由后人承接

**开国将领的爵位开始转到下一代手中。** 董渫一支的成侯由赤接续，高苑由得接续丙倩，清侯由圣接续空中。三人的侯年都从本年起算，原来因反秦、楚汉战争取得的封邑由此继续传承，而不是三人又各完成一遍父辈的军功。

<a id="卷018承爵元年不是重新册封功臣"></a>
#### 卷018｜承爵元年不是重新册封功臣

三格均在惠帝元年开始记后任侯的王年；父系和前爵由本行侯功、初封及[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-c3e3957026c4a9)核对。这里只记承爵及新元年，不反推三位前任均在本年同日死亡，也不补未载的丧礼。高苑／高宛、丙倩／丙猜的字形差别仍见原表，不另造两个侯国和两位功臣。

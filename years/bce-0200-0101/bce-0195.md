**汉高帝十二年；刘盈本年继位，次年称惠帝元年**

> 十月岁首，冬十月在本页春季以前。月份、干支按古史保留，不声称已经逐日换算成公历。

## 本年概述

刘邦击败黥布，改封随军有功的刘濞为吴王，回程经过沛县。北方卢绾被讨，樊哙中途被换，周勃继续平燕。刘邦病重去世后，惠帝继位，吕后囚戚夫人并召赵王刘如意。

## 平黥布与卢绾，吴、燕易王

<a id="十月黥布兵败刘邦回到沛县"></a>

<a id="event-1"></a>

<a id="event-4"></a>

1. **黥布兵败，刘濞因平乱继王故荆地。** 十月，刘邦在蕲西会甀击破黥布。二十岁的骑将刘濞以沛侯随征，齐王刘肥与曹参率军十二万会师。黥布渡淮，先后败于洮水南北，在鄱阳一带被杀。曹参回师平定竹邑、相、萧、留。陈平以护军中尉随征陈豨、黥布，屡献计增封，部分计策未传。陈豨也在这年败亡，代地渐平。荆王刘贾先前在黥布叛乱中遇害，刘邦以兄长刘仲之子刘濞为吴王，令其领故荆地三郡五十三城，受印时告诫他同姓一家，切勿作乱。 [[1]](#note-1)

<a id="sj008-dafeng"></a>

<a id="event-2"></a>

<a id="event-3"></a>

2. **刘邦过沛与故旧饮宴，为沛、丰定免役。** 刘邦回程经过沛县，召故人、父老、子弟饮酒。他选一百二十名少年练歌，酒酣时击筑而唱：“大风起兮云飞扬，威加海内兮归故乡，安得猛士兮守四方！”随后起舞，流下眼泪。已经当了皇帝，他念着的仍有故乡与如何守住天下。沛县获得长期复免，丰邑却差点被旧怨排除。刘邦宣布沛为汤沐邑，百姓世世免服相关徭赋。他留了十余日，父老继续挽留，送到县西后又设宴三日。众人替丰邑求同样待遇，他还记着雍齿当年据丰反自己；父老再请，才答应丰与沛同样复免。 [[2]](#note-2)

<a id="二月老朋友卢绾也成为讨伐对象"></a>

<a id="event-6"></a>

<a id="event-7"></a>

<a id="hs-event-28"></a>

3. **卢绾为汉所讨，陈平、周勃接替樊哙。** 二月，陈豨的降将供出燕王与叛军来往，朝廷召卢绾，他称病不来。辟阳侯审食其前去迎接、核问，又带回可疑消息。刘邦认定卢绾有反意，派樊哙等出兵，赦免燕地被牵连的吏民，并立皇子刘建为燕王。本纪还说，燕地六百石以上官吏及离开卢绾来归的人分别获赐爵一级。卢绾在边塞等待，陈平与周勃换下樊哙。卢绾带数千人停在塞外，希望皇帝病好后再解释。刘邦病中又听到对樊哙的指控，命陈平带周勃驰驿代将，并就地斩樊哙。两人途中想到樊哙旧功、吕氏姻亲关系及皇帝可能悔怒，决定只囚送长安，留给皇帝自处；未到军营便筑坛持节召来樊哙，反绑押入槛车。周勃接军平定燕地各反县；这是一次更换统帅，没有当场诛杀或赦免樊哙。周勃以相国职号代将，攻蓟俘抵、偃、陉、弱、施，屠浑都，又在上兰、沮阳破燕军，追至长城，平上谷十二县、右北平十六县、辽西辽东合二十九县、渔阳二十二县。战后归来，高祖已经去世，他转而以列侯事惠帝。传记在此另总计其跟从高帝的战功：所得相国一人、丞相二人，将军与二千石各三人；另自领兵破军二、下城三，定五郡七十九县，得丞相与大将各一人。高帝子刘建立燕王。 [[3]](#note-6)

## 高帝晚年政令及巡祭

<a id="十二月为旧王和先辈安排守冢户"></a>

<a id="event-5"></a>

4. **十二月，为旧王和先辈安排守冢户。** 十二月，刘邦返长安后，下令给秦始皇、陈涉、魏安釐王、齐湣王、赵悼襄王及魏公子无忌等人安排守冢户，免去守冢户其他徭役。朝廷又赦免被陈豨、赵利胁迫的代地吏民。 [[4]](#note-5)

   同一位统治者一面镇压现实中的叛乱，一面保存旧王、旧英雄的祭葬，不必把两项措施讲成互相排斥的态度。

<a id="sj053-shanglin-event"></a>

5. **萧何替百姓请求耕种上林空地，被拘禁后获释。** 刘邦平布回师，百姓拦路告萧何压价强买田宅。皇帝把诉状交给萧何，讥讽他也懂得从民取利，让他自己解释。萧何随后请开放上林苑闲地给百姓耕种。皇帝指责他收商人财物、讨好百姓，把他交廷尉加械囚禁。数日后，王姓卫尉进谏：为民请便本是宰相职责；皇帝连年在外时，萧何掌关中却不乘机谋利，怎会如今贪商人之金？秦因皇帝听不到过错而亡，李斯把过失揽给自己，也不值得效法。刘邦不悦，当天仍遣持节使者赦出萧何。萧何赤足谢罪，皇帝又自称拘他是要百姓知道自己的过错；这是获释后的说辞，不据此认定入狱本是示过计划。 [[5]](#sj053-shanglin-note)

<a id="sj047-gaozu-confucius-event"></a>

6. **刘邦经过鲁地，用太牢祭孔子。** 在高帝晚年的行程中，祭孔被记作皇帝亲自尊礼这一学统的行动。用太牢表示祭品礼等，不能据此推定当时孔庙已经完全等同后世规模。 《儒林列传》补记申公当时以弟子身份随师在鲁南宫见高祖。 [[6]](#sj047-gaozu-confucius-note)

<a id="hs001-event-26"></a>

7. **高帝颁诏回顾开国酬功并告谕诸侯。** 三月，高帝列举分封王侯、赐宅及免除开国从军者赋役等措施，称自己有功必赏，并宣告将与天下共同讨伐擅自举兵反叛者。 [[7]](#hs001-note-26)

8. **刘邦病重安排后事，死于长乐宫。** 刘邦征黥布时中箭，回程病势加重。吕后请来医生，刘邦以命在天为由拒医、赏金遣去。吕后问萧何之后可用何人，刘邦说曹参可继任，王陵虽直率仍需陈平辅佐，周勃厚重少文，可安刘氏。四月甲辰，刘邦死于长乐宫，吕后与审食其暂未发丧。丁未公布死讯大赦，卢绾得知后出亡匈奴。同在燕地旧局解体之际，卫满聚众出辽东塞，东渡浿水。 [[8]](#note-9)

9. **葬高帝，刘盈即位赐爵减租，陈平改任。** 五月，葬长陵，刘盈即皇帝位。五月丙寅安葬，己巳刘盈即位。群臣为刘邦议功，奉上高皇帝尊号，以太祖纪开国之功；郡国诸侯按命设庙、岁时祭祀。后世习称“高祖”，不能因此把尊号、庙号和本纪篇名当作完全同一种名目。新皇帝继承的，不只是皇位，也是一批分布各地的兄弟封国。刘肥为齐王，刘盈为皇帝，刘如意为赵王，刘恒为代王，刘恢为梁王，刘友为淮阳王，刘长为淮南王，刘建为燕王。楚国由叔父刘交掌握，吴国有堂兄刘濞，非刘氏的长沙王则是吴芮之子吴臣。此后刘友、刘恢迁王赵，刘恒即帝位，各回对应年页，不提前塞入本年。高帝死后，陈平先入宫奏事，改任郎中令。陈平押送樊哙途中闻高帝死，怕吕后、吕媭进谗发怒，乘驿先行。虽遇使者命与灌婴屯荥阳，他受诏后仍立即入宫，在高帝丧前痛哭奏事；吕后让他休息，他坚持求留宫宿卫，于是任郎中令，傅教惠帝。樊哙送到后获赦，恢复爵邑。惠帝即位后普赐爵并减租宽刑。惠帝按品秩、年资分别赐爵或钱，奖励助丧和治陵者，恢复田租十五取一，对高年幼童、宗室及有爵者另行宽处。 [[9]](#note-13)

10. **吕后囚戚夫人召赵王，惠帝亲自保护刘如意。** 吕后在刘邦贫贱时已经嫁给他，生刘盈和鲁元公主。汉王时期戚姬受宠，生下如意，又常随刘邦到关东；吕后多留守，渐与丈夫疏远。戚姬力争自己的儿子代太子，吕后则得到大臣及张良帮助，刘盈才保住位置。婚姻前事见[前209年](../bce-0300-0201/bce-0209.md#sj008-liuji)，夺嫡的已编部分见[前197年](bce-0197.md)。本年高帝破布回师、病势转重，仍想易储。张良进谏不被听取，因病不视事，叔孙通援古今冒死争执，高帝表面答应。宴会上，太子身后跟着四位八十多岁、须眉皓白、衣冠整肃的人，自报名为东园公、角里先生、绮里季、夏黄公。高帝惊问，寻访多年为何逃我却从我儿；四人答，帝轻士善骂，太子仁孝恭敬爱士，天下人愿为之死，所以前来。帝请他们始终调护太子。四人祝寿退去，帝指给戚夫人看，说太子羽翼已成、难以更动，吕后以后将真正居于她之上。他让戚夫人楚舞，自己唱鸿雁高飞千里、羽翼成而横绝四海、纵有缴矰也无所施的楚歌；戚夫人泣，帝起身，宴会结束。张良先招四人，由此帮助刘盈稳住了太子之位。高祖死后，吕后将戚夫人囚在永巷，又召赵王如意。使者去了三次，赵相周昌都拒绝送王，说高祖将幼王托付给自己，不能任其入京遇害。吕后先召周昌到长安，去掉这层保护，再次召赵王。刘盈亲自到霸上迎接弟弟，带进宫中，一同起居饮食。他知道母亲怀怒，尽力不让如意独处。暂时的保护阻住了吕后的行动，却未能阻止下一古历年十二月的毒杀。[前194年后续](bce-0194.md) [[10]](#note-15)

    吕氏也不是到高祖死后才参与军政。吕后的长兄吕泽、次兄吕释之都做过将领；吕泽已死，两个儿子吕台、吕产分别有郦侯、交侯之爵，吕释之为建成侯。吕后本人此前参与对韩信、彭越的处置，见[前196年](bce-0196.md)。这些是进入新局势时已有的关系，不全是本年新发生的封赏。

<a id="sj049-boji-dai-event"></a>

11. **高祖死后，薄姬获准出宫，随子刘恒到代国。** 吕太后把戚夫人等高祖曾宠爱的女子幽禁宫中，不许外出。薄姬因与高祖少见，得以离宫，成为代王太后；弟弟薄昭也随她赴代。刘恒已在上一年封代王，这次改变的是母亲与舅父的居处。 [[11]](#sj049-boji-dai-note)

<a id="sj055-event-20"></a>

12. **高帝去世后，吕后劝张良进食。** 张良此前学习辟谷、导引，以求轻身退世。高帝去世，吕后感激他保太子的谋助，强劝他说，人生如白驹过隙般短暂，何必这样苦自己；张良无奈，勉强进食。 [[12]](#sj055-note-20)

<a id="hs-event-31"></a>

13. **叔孙通复任奉常，表列廷尉育。** 叔孙通复任奉常，表列廷尉育。参见本年的官职变动原句。 [[13]](#hs-note-31)

## 爵赏和南海王

<a id="三月桃侯刘襄的战功得到兑现"></a>

<a id="event-8"></a>

14. **三月，桃侯刘襄的战功得到兑现。** 三月丁巳，刘襄被封为桃侯。 他出自项氏亲族，获赐刘姓，先前从汉作战；功臣表把击黥布的功劳与这次封侯相连。这是《项羽本纪》篇末后叙的原有条目，远在项羽死亡以后才落实。 [[14]](#note-8)

<a id="sj097-event-23"></a>

15. **郦疥承父功封高梁侯。** 高祖思念郦食其，因其父出使诸侯、说齐的功劳，封曾多次带兵的郦疥为高梁侯。两表均记丙寅，史表三月、汉表二月。 [[15]](#note-23)

<a id="sj098-event-24"></a>

16. **周緤定封蒯成侯。** 刘邦将周緤的封地改定在蒯成，撤去原食邑。 [[16]](#note-24)

<a id="hs001-event-25"></a>

17. **汉廷册立南武侯织为南海王。** 高帝下诏，以南武侯织是越人后裔，立为南海王。本条记册命，受封地望与实际管辖范围另有不同解释。 [[17]](#hs001-note-25)

<a id="hs-event-29"></a>

18. **德哀侯广受封。** 本表记德哀侯广受封。 [[18]](#hs-note-29)

<a id="hs-event-30"></a>

#### 卷024｜音乐史事的互见与归年

[卷024 P004](../../sources/摘录/史记-卷024-乐书.md#p004)的高祖过沛、令小儿歌唱，接本页[击筑唱大风](#sj008-dafeng)，不是另一场归乡宴。[《高祖本纪》十二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7008.md#ref-69037ada455150)明载三句歌辞及百二十歌儿；《乐书》“三侯之章”原字照存，三家注《索隐》训侯为语辞，以本歌有三“兮”解释“三侯”。

同段“高祖崩，令沛得以四时歌舞宗庙”是死后安排的压缩概述，没有独立诏令日。高祖死后郡国立庙岁时祠与惠帝五年前190年沛宫改原庙、歌儿补额是两个阶段；后者依本纪明确年次接[前190年既有记录](bce-0190.md#sj024-note)。不把两项都定为四月甲辰当天颁下，也不将死后的奉祀带回本年十月宴饮。

<a id="卷018末批二十侯承爵与跨年军功"></a>
#### 卷018｜末批二十侯、承爵与跨年军功

二十个十二年初封行均已列出，桃侯与旧叙事合并；五个承爵、蒯成封邑确定及刘濞进王分别处理。六月仍属高祖十二年年条，但新帝已在五月继位，不能把全部授爵归作刘邦临终下令。母亲、儿子承死者功和爵位传承有别：郦疥是因父功初封，不是郦食其曾在本年先受高梁侯再传给儿子。

[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-6c28e2328d3e19)与本表有单父圣／单右车、黄极中／黄极忠、冷／泠耳、王周／王虞人、谷陵／谷阳、壮／严、甘泉／景、阳义／阳羡等差别；沿各行功状和继承对应，不每见异字就新增一个受封者。原表没有给赤的姓，不从后代或同乡推填。郦疥三月／二月丙寅差别保留，未作公历换算。

英布战争中的靳歙、庄不识、华无害、卫胠等已封将领，及周聚、灵常、冷耳、王周、刘襄的履历，都是这场从[前196年](bce-0196.md#sj008-yingbu)延续到本年的战争的一部分；无确月的分军不强排成同一天。贲赫告发和其宗族遇害是封侯以前的过程，不能把十二月授爵日同时当作告发、起兵、灭族的日期。

陈豨终局与[阳夏R025](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r025)、[禾成R108](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r108)的归功互见；沿本页汉军平定的主线，不为樊哙、周勃、公孙耳分别制造一次斩首。卢绾战事中的陈仓、张平以及温疥功格“定卢奴／卢绾”，也不提前到六至八年受封时再打一遍。

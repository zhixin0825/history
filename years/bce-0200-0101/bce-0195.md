# 公元前195年｜刘邦唱大风归沛，病中平燕，死后刘盈继位

[← 公元前196年](bce-0196.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前194年 →](bce-0194.md)

**汉高帝十二年；刘盈本年继位，次年称惠帝元年**

> 十月岁首，冬十月在本页春季以前。月份、干支按古史保留，不声称已经逐日换算成公历。

## 十月，黥布兵败，刘邦回到沛县

**刘邦击破黥布主力，命别将继续追击。** 黥布渡淮退往江南，在洮水南北又接连败北，最后在鄱阳一带被杀。汉军北方的讨伐也有结果，陈豨在当城被斩，代地的主要抵抗逐步平定。[1](#sj008-finalwar)

<a id="sj008-dafeng"></a>
**刘邦回程经过沛县，召故人、父老、子弟饮酒。** 他选一百二十名少年练歌，酒酣时击筑而唱：“大风起兮云飞扬，威加海内兮归故乡，安得猛士兮守四方！”随后起舞，流下眼泪。已经当了皇帝，他念着的仍有故乡与如何守住天下。[2](#sj008-pei)

**沛县获得长期复免，丰邑却差点被旧怨排除。** 刘邦宣布沛为汤沐邑，百姓世世免服相关徭赋。他留了十余日，父老继续挽留，送到县西后又设宴三日。众人替丰邑求同样待遇，他还记着雍齿当年据丰反自己；父老再请，才答应丰与沛同样复免。[2](#sj008-pei)

**荆王刘贾已经败亡，刘邦改立侄子刘濞为吴王。** 刘濞是刘仲的儿子，新吴国承接原荆国的一部分政治空间。刘邦此前与兄长“谁更会治产业”的玩笑，并没有让兄长这一支从此退出王国体系。[1](#sj008-finalwar)

## 十二月，为旧王和先辈安排守冢户

**刘邦返长安后，下令照料一些已经断绝后嗣的陵墓。** 秦始皇有二十家守冢，陈涉、魏安釐王、齐湣王、赵悼襄王各十家，魏公子无忌五家。朝廷也再次赦免被陈豨、赵利胁迫参与的代地吏民。[3](#sj008-yangraves)

同一位统治者一面镇压现实中的叛乱，一面保存旧王、旧英雄的祭葬，不必把两项措施讲成互相排斥的态度。

## 二月，老朋友卢绾也成为讨伐对象

**陈豨的降将供出燕王与叛军来往，朝廷召卢绾，他称病不来。** 辟阳侯审食其前去迎接、核问，又带回可疑消息。刘邦认定卢绾有反意，派樊哙等出兵，赦免燕地被牵连的吏民，并立皇子刘建为燕王。[4](#sj008-luwan)

**卢绾带数千人停在边塞，希望皇帝病好后再解释。** 他曾是刘邦最亲近的旧友之一，却已不敢直接入朝。樊哙后来又被召回问罪，周勃接管对燕军事；这些换将不是樊哙与周勃同时各自受命处置同一支部队的简单重复。[4](#sj008-luwan)

## 三月，桃侯刘襄的战功得到兑现

**三月丁巳，刘襄被封为桃侯。** 他出自项氏亲族，获赐刘姓，先前从汉作战；功臣表把击黥布的功劳与这次封侯相连。这是《项羽本纪》篇末后叙的原有条目，远在项羽死亡以后才落实。[5](#grant-note)

## 病重以后，皇后问谁能接着主持朝政

**刘邦征黥布时中了流矢，回程以后病势加重。** 吕后请来医生，医生说还有治疗的可能，他却以自己从布衣取天下、命在天为由拒绝，赏金遣走。无论当时究竟能否治愈，拒医是这段传世记载明确保留的行动。[6](#sj008-illness)

**吕后问萧何以后用谁，刘邦依次提到曹参、王陵、陈平和周勃。** 曹参可以接萧何；王陵较直率，陈平可以辅佐；周勃厚重少文，可以承担安定刘氏的职责。这里是病中讨论以后的人事，不是这些人已经在本年依次接任丞相。[6](#sj008-illness)

## 四月，刘邦死后先秘不发丧

**四月甲辰，刘邦死于长乐宫，死讯没有马上公开。** 吕后与审食其担心旧日诸将不服少主，商议是否应先行清除。郦将军听说后警告：外面握兵的陈平、灌婴、樊哙、周勃等一旦听说朝廷要杀诸将，可能联合反攻，反而立即危及国家。[7](#sj008-death)

**这项清洗计划没有实行，丁未公布死讯并大赦。** 皇帝已经死去，军队与朝廷却不能靠一纸命令就稳住；及时放弃扩大杀戮，是这段继承叙事的关键转折。卢绾得知刘邦死讯，终于逃入匈奴，不再等待入朝解释的机会。[7](#sj008-death)

## 五月，葬长陵，刘盈即皇帝位

**五月丙寅安葬，己巳刘盈即位。** 群臣为刘邦议功，奉上高皇帝尊号，以太祖纪开国之功；郡国诸侯按命设庙、岁时祭祀。后世习称“高祖”，不能因此把尊号、庙号和本纪篇名当作完全同一种名目。[8](#sj008-succession)

**新皇帝继承的，不只是皇位，也是一批分布各地的兄弟封国。** 本卷列出八子：刘肥为齐王，刘盈为皇帝，刘如意为赵王，刘恒为代王，刘恢为梁王，刘友为淮阳王，刘长为淮南王，刘建为燕王。此后刘友、刘恢迁王赵，刘恒后来即帝位，分别回到对应年页，不提前塞入本年。[9](#sj008-family)

## 本年相关史料

<a id="sj008-finalwar"></a>
### 1｜黥布、陈豨与刘濞

[卷008 P061—P062](../../sources/摘录/史记-卷008-高祖本纪.md#p061) · [《通鉴》卷十二](https://zh.wikisource.org/wiki/資治通鑑/卷012)。起兵在前196，主力败与追杀在本年；会甀、蕲西等地理记述不未经考证判成两个不同的大会战。陈豨之死本纪归樊哙，《通鉴》归周勃，正文用汉军行动，归功差别留注，不各造一次斩首。刘濞以原荆地建吴，不能把秦汉吴地、会稽郡及整个现代江浙等同。

<a id="sj008-pei"></a>
### 2｜歌沛、复免与旧怨

[卷008 P061](../../sources/摘录/史记-卷008-高祖本纪.md#p061)。大风歌为本纪所载古代诗作，少年一百二十及停留日数均为文本记数。复免的具体赋役类别不能不辨制度便译成现代意义的一切税费永久为零；“魂魄思沛”是刘邦所说的怀乡话，不当作灵魂存在的证明。其后沛宫原庙另见[前190年](bce-0190.md)。

<a id="sj008-yangraves"></a>
### 3｜守冢对象及数量

[卷008 P063](../../sources/摘录/史记-卷008-高祖本纪.md#p063)。本段不证明所列诸王墓址已经现代考古逐一确认，也不把“绝无后”扩大为他们生物意义的所有后裔都灭绝；这里关系到奉祀与守冢户的安排。十一月返长安、十二月诏令分开。

<a id="sj008-luwan"></a>
### 4｜通谋供词与对燕战争

[卷008 P063、P065、P067](../../sources/摘录/史记-卷008-高祖本纪.md#p063) · [《通鉴》卷十二](https://zh.wikisource.org/wiki/資治通鑑/卷012)。卢绾称病、朝廷遣迎、告发和军事讨伐分别叙述，不直接把全部供词当作未经争议的内幕。樊哙被拘、周勃代军由《通鉴》相关回叙补足；出逃在刘邦死亡后，不提前到二月。

<a id="grant-note"></a>
### 5｜桃侯初封的旧记录

[卷007 P044](../../sources/摘录/史记-卷007-项羽本纪.md#p044) · [卷018桃条及T1](../../sources/摘录/史记-卷007-项羽本纪.md#t1)：“十二年三月丁巳，安侯刘襄元年。”同条“项氏亲也，赐姓”未另定日期，不让赐姓自动继承初封日。此人不是齐王刘襄；既有条目、出处与锚点完整保留。

<a id="sj008-illness"></a>
### 6｜临终人事意见的性质

[卷008 P064](../../sources/摘录/史记-卷008-高祖本纪.md#p064)。不把医生的“可治”解释成现代诊断，不为病因追加确证。本段关于周勃安刘的语言可能承载成书后的回看，作为传世言辞呈现，不用来独立证明人物真实预见前180年政变。

<a id="sj008-death"></a>
### 7｜秘丧与未实行的诛将计划

[卷008 P066—P067](../../sources/摘录/史记-卷008-高祖本纪.md#p066)。四日不发丧与甲辰至丁未是古书计日口径，不简单判作算错。“郦将军”所指及各军实际人数不靠这段劝说全数恢复；计划没有实行，不能在年表里增加一次“吕后尽诛诸将”。

<a id="sj008-succession"></a>
### 8｜死亡、安葬与继位各有日期

[卷008 P068、P071](../../sources/摘录/史记-卷008-高祖本纪.md#p068) · [《通鉴》卷十二](https://zh.wikisource.org/wiki/資治通鑑/卷012)。五月由编年底本补，丙寅葬、己巳即位，不把四月死日直接写成三事同日。刘盈次年才称惠帝元年。太史公的三代忠敬文循环解释及司马贞索隐述赞另见[本卷考证](../../meta/考证/史记-卷008-纪年与异说.md#论赞)。

<a id="sj008-family"></a>
### 9｜八子与晚出的称号

[卷008 P070](../../sources/摘录/史记-卷008-高祖本纪.md#p070)中母系明列刘盈出吕后、刘如意出戚夫人、刘恒出薄太后；其余不在这里补猜母名。悼惠、隐、共、幽、厉等为后谥，正文上面的王号表用于辨认本年人物。刘友迁赵见[前194](bce-0194.md)，刘恢迁赵见[前181](bce-0181.md)，刘恒称帝见[前180](bce-0180.md)。

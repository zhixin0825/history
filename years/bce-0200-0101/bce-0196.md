# 公元前196年｜韩信、彭越被杀，黥布起兵，宗室接管更多封国

**汉高帝十一年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="北方战事尚未结束皇子刘恒被立为代王"></a>

<a id="event-1"></a>

1. **陈豨部将继续在曲逆、聊城、马邑等地抵抗。** 汉将郭蒙与齐军击败侯敞、张春等部，周勃从太原进军，攻破马邑。刘邦围东垣月余，攻下后下令处死先前辱骂自己的人，赦免其他守军；东垣改名真定。 刘泽也以将军参加讨伐，擒获王黄，受封营陵侯；这项封爵已经列在[本年旧侯籍](#sj018-grants)，与陈豨本人次年败亡分开。 齐军中的曹参以齐相国身份击破张春军。 周勃部斩陈豨将乘马絺，在楼烦破韩王信、陈豨、赵利军，俘宋最、雁门守圂，又得云中守遬、丞相箕肆、将勋，定雁门十七县、云中十二县。 [[1]](#note-1)

<a id="event-2"></a>

2. **赵山以北另作安排，刘恒被立为代王，都晋阳。** 这是前一位代王刘仲弃国以后新的宗室部署。此时的刘恒只是分守北边的皇子，还不是文帝。 [[2]](#note-2)

<a id="正月淮阴侯韩信在长乐宫被杀"></a>

<a id="event-3"></a>

3. **正月，淮阴侯韩信在长乐宫被杀。** 韩信留在关中，没有随皇帝征陈豨，后来遭到告发。 吕后与萧何以庆贺陈豨已被平定为由，把韩信召入宫中；韩信入宫后被捕，在长乐钟室处死，家族也受到诛杀。 [[3]](#note-3)

   这位曾经统兵平魏、赵、齐、助灭楚的大将，前201年先失楚王之位，如今又以谋反罪失去性命。朝廷对他的处理和“谋反”指控是否全都可信，是两个必须分开的问题。

<a id="sj053-xiangguo-event"></a>

4. **韩信被诛以后，萧何升为相国，召平却劝他辞让厚赏。** 刘邦听到消息，下令增封萧何五千户，给五百士卒、一名都尉作护卫。众人祝贺，原秦东陵侯召平却表示忧虑：皇帝在外劳苦，萧何守内而无战阵之险，却获增封置卫，未必只是宠爱，也可能是韩信案后加深的疑忌。召平劝辞让增封、用私人家财助军，萧何照办，皇帝很高兴。召平在秦亡后成为平民，贫而在长安城东种瓜，瓜美而得东陵瓜之名；这是他的此前经历，不以本年倒定种瓜之始。 [[4]](#sj053-xiangguo-note)

<a id="event-4"></a>

5. **同一阶段，另一位韩王信也战死。** 柴武在参合斩杀投向匈奴的韩国宗室韩王信。这是边地战事中的死亡，不是长乐宫韩信案的第二种版本。 [[5]](#note-4)

<a id="彭越先被废徙随后又遭诛族"></a>

<a id="event-5"></a>

6. **彭越被指谋反，遭废位迁徙。** 刘邦征陈豨时，梁王彭越没有亲自前来。 朝廷后来以谋反指控逮捕他，废为庶人，准备迁到蜀地。彭越途中向吕后求情，事情却没有因此缓和。 [[6]](#note-5)

<a id="event-6"></a>

7. **吕后认为留下这样一位有军事能力的人终成后患，把他带回洛阳。** 在新的告发与审议之后，彭越被处死、夷三族。原来的梁国改由皇子刘恢承接，另立刘友为淮阳王。功臣王失势以后，地方政治空间更多转到宗室手中。 [[7]](#note-6)

<a id="七月黥布公开举兵"></a>

<a id="event-7"></a>

8. **七月，黥布公开举兵。** 韩信、彭越接连遇害，让黥布越来越害怕。他私下聚集兵力、观察诸郡县，有人把情况告到朝廷。黥布见事已泄，正式起兵，向东攻击荆国。刘贾迎战失败，退走富陵，被布军杀死；黥布又渡淮攻楚，刘交退避到薛。 [[8]](#note-7)

<a id="event-8"></a>

9. **刘邦仍然亲自出征，皇子刘长被安排为新的淮南王。** 黥布原以为皇帝年老、厌战，不会亲来，结果未能如愿。双方的决战和追杀接在下一古历年，不把七月起兵与十月败亡压成一天。 皇帝病中一度想派太子率军。已为太子所招的四位高士劝建成侯：太子胜也不能高过太子，败则获罪；旧日勇将如狼，太子如羊，未必肯尽力，戚夫人与如意又日夜在帝侧，更添被废之险。他们请吕后乘间哭劝：黥布勇而善兵，太子不能使诸将服从，皇帝虽病，也应卧辎车护军，为妻子儿女自强。吕后照说，帝自认小子不足遣，决定亲征。群臣送到灞上，病重的张良勉到曲邮，劝勿与剽悍楚兵争锋，另请太子为将军监关中兵。皇帝让张良卧病辅导太子，叔孙通任太傅，张良代理少傅事务。 [[9]](#note-8)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-9"></a>

10. **周勃担任太尉，参加代地作战。** 高祖十一年，朝廷任周勃为太尉；他统兵参与讨伐陈豨等代地势力。 [原格与说明](#sj022-note)。 [[10]](#note-9)

<a id="sj053-self-taint-event"></a>

11. **征黥布期间，萧何又听从宾客劝告，借侵取田宅败坏自己的名声。** 刘邦在军中，屡派人问他在做什么；萧何照旧安抚百姓、拿出财物助军。宾客却说，相国功位已无可加，初入关中以来一直深得民心，如今还不断获民拥护，皇帝可能怕他摇动关中；不如多买土地，压价赊取、借取民财自污。萧何照做，刘邦得知后很高兴。这是战争期间的连续故事，独立月日不明；皇帝回师后的百姓告状与请苑案接下一年。 [[11]](#sj053-self-taint-note)

<a id="sj096-event-12"></a>

12. **赵尧以击陈豨功封江邑侯。** 赵尧继周昌为御史大夫，随军讨陈豨有功，封江邑侯。史、汉功臣侯表月份各异，同年只计一次受封。 [[12]](#note-12)

<a id="sj096-event-13"></a>

13. **任敖因守上党获封广阿侯。** 陈豨反后，任敖以守上党有功，汉十一年二月丁亥封广阿侯，食邑一千八百户。 [[13]](#note-13)

<a id="sj097-event-14"></a>

14. **五月，汉册立赵佗为南越王，陆贾前往授印。** 高祖诏立赵佗为南越王。陆贾带着印绶前往，责其以越俗箕坐见汉使，又说明称臣通使的利害。赵佗改以礼相见，受印称臣。陆贾还报，任太中大夫。 [[14]](#note-14)

<a id="sj106-event-15"></a>

15. **高祖兄子刘濞封为沛侯。** 刘仲之子刘濞在高祖十一年十二月癸巳封为沛侯。后来他从高祖讨黥布，次年由侯进为吴王。 [[15]](#note-15)

<a id="sj097-p009"></a>

> 及高祖時，中國初定，尉他平南越，因王之。高祖使陸賈賜尉他印爲南越王。陸生至，尉他魋結箕倨見陸生。陸生因進說他曰：「足下中國人，親戚昆弟墳墓在真定。今足下反天性，弃冠帶，欲以區區之越與天子抗衡爲敵國，禍且及身矣。且夫秦失其政，諸侯豪桀並起，唯漢王先入關，據咸陽。項羽倍約，自立爲西楚霸王，諸侯皆屬，可謂至彊。然漢王起巴蜀，鞭笞天下，劫略諸侯，遂誅項羽滅之。五年之間，海內平定，此非人力，天之所建也。天子聞君王王南越，不助天下誅暴逆，將相欲移兵而誅王，天子憐百姓新勞苦，故且休之，遣臣授君王印，剖符通使。君王宜郊迎，北面稱臣，迺欲以新造未集之越，屈彊於此。漢誠聞之，掘燒王先人冢，夷滅宗族，使一偏將將十萬衆臨越，則越殺王降漢，如反覆手耳。」

**本卷归年说明：** 《汉书·高帝纪下》高帝十一年五月记立赵佗为南越王、使陆贾授玺绶。

<a id="sj097-p010"></a>

**[《史记·郦生陆贾列传》P010](../../sources/摘录/史记-卷097-郦生陆贾列传.md#p010)** · [三家注](../../sources/史记三家注/卷097.md#p10)

> 於是尉他迺蹶然起坐，謝陸生曰：「居蠻夷中久，殊失禮義。」因問陸生曰：「我孰與蕭何、曹參、韓信賢？」陸生曰：「王似賢。」復曰：「我孰與皇帝賢？」陸生曰：「皇帝起豐沛，討暴秦，誅彊楚，爲天下興利除害，繼五帝三皇之業，統理中國。中國之人以億計，地方萬里，居天下之膏腴，人衆車轝，萬物殷富，政由一家，自天地剖泮未始有也。今王衆不過數十萬，皆蠻夷，崎嶇山海間，譬若漢一郡，王何迺比於漢！」尉他大笑曰：「吾不起中國，故王此。使我居中國，何渠不若漢？」迺大說陸生，留與飲數月。曰：「越中無足與語，至生來，令我日聞所不聞。」賜陸生橐中裝直千金，他送亦千金。陸生卒拜尉他爲越王，令稱臣奉漢約。歸報，高祖大悅，拜賈爲太中大夫。

**本卷归年说明：** 发使及册立系高帝十一年五月，留饮数月与使臣回汉授职各无明月。

#### 卷018｜本年侯籍、战事前后和异名

二十个十一年初封行、强侯章承爵，以及[淮阴R040](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r040)的韩信被诛，都有本页去向。韩信死只接原叙事，不再新增另案。表里十二月在正月之前，慎阳栾说初封所写十二月，与详传正月诛韩信的顺序有问题；本文记录本年受封及告发理由，不擅将二者拼成无争议的具体日历，原日留表待考。

[萧何R015](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r015)的九年任相国与[《萧相国世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7053.md#ref-0a10ce88db20fc)十一年明确年次不同，采用后者，将厚赏、召平劝辞让、出私财相接。告发与处罚、官方认定的谋反与现代独立证明仍分层；不因为告发者得侯便替所有案情作真实性保证。

从[信武R002](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r002)、[武原R081](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r081)等可知，早已受封者也继续参加陈豨战事，封侯不是军旅生涯同时终止。公孙耳格将斩陈豨合在履历中，本纪、通鉴终局在下一年；不因他本年受封便提前认定陈豨已死。郦商、周勃、樊哙等旧将的既有战线仍保留，不另造同名部队。

姓名和官称照[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-ec3f16ce79e90e)互见：栾说／乐说、公孙耳的异写、临辕／临辕相关字形、宁陵吕臣与早期楚将同名等，未经进一步证据不合并人物。杜恬格“死事”与后代起年不足以定死日；不在本年制造一场无记载的廷尉战死。昭涉为复姓的用法按名录保留，不把“涉掉尾”拆出几个无据人名。

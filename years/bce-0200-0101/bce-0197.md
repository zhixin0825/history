# 公元前197年｜太上皇去世，陈豨反代，刘邦又亲征北方

[← 公元前198年](bce-0198.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前196年 →](bce-0196.md)

**汉高帝十年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="年初诸王来朝随后皇室举行丧礼"></a>

<a id="event-1"></a>

1. **十月，淮南、梁、燕、荆、楚、齐、长沙等国的王来到长乐宫朝见。** 首都宫殿与朝会礼仪已把各封国之主置于皇帝面前，但各王仍在地方拥有军队和地盘，朝见并不等于诸侯问题已永久解决。 [[1]](#note-1)

<a id="event-2"></a>

2. **五月，太上皇在栎阳宫去世；七月安葬，楚王、梁王来送葬。** 朝廷赦免栎阳囚徒，又把丽邑改称新丰。皇帝虽然住在长安，父亲的居处及相关祭葬仍与栎阳一带相连。此处沿《通鉴》的死葬安排，本纪与汉书的异月见注。 《汉书》还记八月命各诸侯王在国都立太上皇庙。 [[2]](#note-2)

<a id="皇太子的人选开始让朝廷紧张"></a>

<a id="event-3"></a>

3. **刘邦偏爱戚夫人的儿子刘如意，想用他替代刘盈。** 周昌等大臣反对，认为已经确立的太子不能轻易更换。刘邦也担心自己死后如意不安全，改让被吕后、大臣敬重的周昌出任赵相，希望由他保护赵王。 在这段争储过程中，吕后年长而渐受疏远，戚夫人的宠爱成为刘如意屡被考虑立储的重要背景。 在这场争储过程中，吕后派亲属强请张良出计，张良先说天下安定后的骨肉宠爱之争，百人如己也难改变；受再三催促，才建议招来皇帝多年求而不得的四位高士。四人年老、厌恶帝轻侮士人，隐山不肯屈节；若太子亲书、谦辞厚礼、安车遣辩士恳请，奉为上客，时时随太子入朝，皇帝见到便会增加对太子的重视。吕后依计迎来四人，客于建成侯家。此后四人参与保全太子：十一年阻止他出将，十二年又随他入宴。 [[3]](#note-3)

   这条继承争论是理解晚年与死后政局的前情，未在本年形成废立结果。

<a id="九月陈豨在赵代举兵"></a>

<a id="event-4"></a>

4. **九月，陈豨在赵、代举兵。** 原来受信任、掌握边兵的陈豨，因朝廷追查宾客而越来越不安。 太上皇去世后召他入朝，他称病不来，随后与王黄等起兵，劫掠赵、代。刘邦宣布当地吏民并非都参与谋反，赦免受胁迫的人，自己带兵东征。 [[4]](#note-4)

<a id="event-5"></a>

5. **到邯郸以后，他不先追究所有失城官员，而是急着找人带兵。** 地方报失城、要求杀守尉，刘邦问他们是否真的反叛；得知并非如此，就认为只是兵力不足。他还把当地选出的将领封为千户侯，以尽快争取赵地人心。 刘邦还在赵地访得乐毅之孙乐叔，封他在乐乡，号华成君。 [[5]](#note-5)

<a id="event-6"></a>

6. **对陈豨的将领，刘邦又改用财物招降。** 听说对方许多将领先前经商，他大量许金，确实吸引了一批人倒戈。战争不仅靠战阵，也靠拆散对方的合作。 [[6]](#note-6)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-7"></a>

7. **赵尧接任御史大夫。** 他原来掌符玺文书，现在进入辅助丞相、参与监察的重要职位；他接替的是已经转任赵相的周昌。 [原格与说明](#sj022-note)。 [[7]](#note-7)

<a id="sj028-event-8"></a>

8. **高祖批准县与里社常祀。** 有司请县于春及岁末以羊豕祀社稷，民里社各自筹措祭费，高祖准许。 [[8]](#note-8)

<a id="hs-event-9"></a>

9. **赵尧任御史大夫，宣义任廷尉。** 赵尧任御史大夫，宣义任廷尉。参见本年的官职变动原句。 [[9]](#hs-note-9)

### 3. 刘邦偏爱戚夫人的儿子刘如意，想用他替代刘盈

[返回正文第3条](#event-3)

<a id="hs097-l10125-e3"></a>

**[《汉书·外戚传》P005](../../sources/摘录/汉书-卷097-外戚传.md#p005)** · [仓内TXT L10125](../../sources/本地分卷/汉书/汉书-卷097.md#L10125)

> 後漢王得定陶戚姬，愛幸，生趙隱王如意。太子為人仁弱，高祖以為不類己，常欲廢之而立如意，「如意類我」。戚姬常從上之關東，日夜啼泣，欲立其子。呂后年長，常留守，希見，益疏。如意且立為趙王，留長安，幾代太子者數。賴公卿大臣爭之，及叔孫通諫，用留侯之策，得無易。

**互校说明** 《通鉴》卷012于高祖十年叙易储之议，卷076《叔孙通传》明确此年进谏；本传合记多次争议。

<a id="hs040-l7232-e3"></a>

**[《汉书·张陈王周传》P020](../../sources/摘录/汉书-卷040-张陈王周传.md#p020)** · [仓内TXT L7232](../../sources/本地分卷/汉书/汉书-卷040.md#L7232)

> 上欲廢太子，立戚夫人子趙王如意。大臣多爭，未能得堅決也。呂后恐，不知所為。或謂呂后曰：「留侯善畫計，上信用之。」呂后乃使建成侯呂澤劫良，曰：「君常為上謀臣，今上日欲易太子，君安得高枕而臥？」良曰：「始上數在急困之中，幸用臣策；今天下安定，以愛欲易太子，骨肉之間，雖臣等百人何益！」呂澤彊要曰：「為我畫計。」良曰：「此難以口舌爭也。顧上有所不能致者四人。四人年老矣，皆以上嫚厉士，故逃匿山中，義不為漢臣。然上高此四人。今公誠能毋愛金玉璧帛，令太子為書，卑辭安車，因使辨士固請，宜來。來，以為客，時從入朝，令上見之，則一助也。」於是呂后令呂澤使人奉太子書，卑辭厚禮，迎此四人。四人至，客建成侯所。

**互校说明** 此为争太子位过程，参前196四人止太子将兵、前195随太子入宴；《留侯世家》诸侯号与吕氏侯表称建成侯释之相参，保留本传「建成侯呂澤」。

<a id="hs042-l7360-e3"></a>

**[《汉书·张周赵任申屠传》P007](../../sources/摘录/汉书-卷042-张周赵任申屠传.md#p007)** · [仓内TXT L7360](../../sources/本地分卷/汉书/汉书-卷042.md#L7360)

<a id="sj008-ten"></a>
<a id="1太公死葬与来朝者姓名"></a>
#### 1｜太公死葬与来朝者姓名

[卷008 P056](../../sources/摘录/史记-卷008-高祖本纪.md#p056)记七月崩；[《汉书·高帝纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7001.md#ref-c0cda7e0a63cd4)也记七月太上皇崩，它五月记的是太上皇后崩，不能误引为父亲五月去世。[《通鉴》卷十二](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7012.md#ref-08df2302442f8c)则明确五月太上皇崩、七月葬，正文沿既有通鉴主线，保留本纪与汉书的差别，不再声称两书都支持五月死、七月葬。此为本轮交叉核对时更正旧注的引文归属；不是新增另一次太公死亡。新丰改名随本纪同年，未另推定日。

本纪十月来朝名单仍写“长沙王吴芮”，而[《通鉴》卷十一汉五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7011.md#ref-f1427803a9e9bc)已记吴芮去世。正文只写长沙王，按卷017王统此时为吴臣，不让吴芮亲自再朝汉。本纪“春夏无事”只是编年记录的简写，不能据它否定别书所记五月丧事或整个社会的活动。

<a id="sj008-chenxi"></a>
<a id="2八月九月与动员细节"></a>
#### 2｜八月、九月与动员细节

[卷008 P057](../../sources/摘录/史记-卷008-高祖本纪.md#p057)记八月反、九月征；《通鉴》把正式举兵与亲征接在九月。正文采用编年底本，原月次差别留此，不另造两次陈豨之乱。邯郸失城、选将封户由《通鉴》补，许金招降两书互见。不能因为皇帝以商人出身判断可招降，就当作商人群体必然唯利是图的普遍事实。

<a id="3太子问题是补充背景不是本卷已经全文展开"></a>
#### 3｜太子问题是补充背景，不是本卷已经全文展开

本纪卷008末年详记病中问后事，却略写此前废立争论；本页以《通鉴》相关年条连接，未把卷055《留侯世家》、卷099等整卷算作已完成。后续的商山四皓等叙事不在这里强定同年。

#### 4｜卷017的来朝名单与提前写入的终局

[卷017前197年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0197)楚、齐、荆、淮南、燕、梁、长沙七国来朝，分别对应刘交、刘肥、刘贾、英布、卢绾、彭越、吴臣，接本页首段；不是同名旧王再次出现。淮南、梁格又连写“反，诛”，属于往后结局的压缩：彭越案及英布起兵见[前196年](bce-0196.md#sj008-pengyue)，英布最终败亡见[前195年](bce-0195.md#sj008-finalwar)，不全提到本年。

代栏“复置代，都中都”是该栏开始重新记代国的提示；刘恒的具体封王在[前196年](bce-0196.md#sj008-eleven)。中都与本纪晋阳有都城记载差异，不能仅靠这一格另造刘恒本年先受封、次年再受封的过程。

<a id="阳河开始新一任侯的纪年"></a>
### 阳河开始新一任侯的纪年

**安国接续阳河侯籍，开始记元年。** 这位侯的个人名叫安国，不是上一轮已经受封的安国侯王陵；国名与人名相同，不能据此合并两个家族。[原格](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r069)

<a id="卷018陈豨起兵与侯籍的两条时间线"></a>
#### 卷018｜陈豨起兵与侯籍的两条时间线

[阳夏R025](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r025)把十年八月反、与王黄等略代、自立为王和后来被杀连写。起兵接本页，死亡仍在[前195年](bce-0195.md#sj008-finalwar)；灵丘与当城、斩将归功的差别不能靠重复杀人解决。[阳河R069](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r069)本年安国元年是承爵，不是再次初置侯国；初封者在汉表名其石，未知卒日不由元年倒算。

赵尧在周昌出任赵相的安排中提出办法，并接替其中央官职，是[江邑R112](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r112)回述的受赏前情；本表未将每步都给出确日。正文沿本页周昌调任主线，赵尧的正式侯爵到[前196年](bce-0196.md#sj018-grants)，不把提出计策、迁官、封侯缩成同日。

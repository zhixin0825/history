**汉高帝九年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="与匈奴讲和也把关中人口充实起来"></a>
### 与匈奴讲和，也把关中人口充实起来

<a id="event-1"></a>

1. **冬季，汉以民间女子冠以公主名号，与匈奴缔结婚约。** 刘敬受命前往，落实和亲。实际送出的不是鲁元公主，上一年的提议和这次执行并不完全相同。 [[1]](#note-1)

<a id="event-2"></a>

2. **刘敬回来后，又建议迁东方强族入关中。** 关中虽地势便利，却经历战乱、人口不足；东方六国旧族仍有动员能力。十一月，齐田氏、楚昭屈景怀等大族与豪杰被迁入关中，给田宅，使中央所在地增加人口，也把可能在东方起兵的势力移到朝廷附近。 [[2]](#note-2)

<a id="貫高承担谋刺责任赵王仍失去了封国"></a>
### 貫高承担谋刺责任，赵王仍失去了封国

<a id="event-3"></a>

3. **柏人旧案被告发，貫高和张敖一并受审。** 同谋中有人自杀，貫高却坚持活下来说明赵王不知情。他遭到严酷刑讯，仍只承认计划出于自己一伙，没有把责任推到张敖身上。 [[3]](#note-3)

<a id="event-4"></a>

4. **朝廷免张敖死罪，却废他为宣平侯，改以刘如意为赵王。** 皇帝派人私下核问，确认貫高始终说明张敖未参与。貫高得知旧主脱险后仍自杀。一个没有被证明参与谋刺的诸侯王，也没有因此保住政治地位。 [[4]](#note-4)

<a id="未央宫成皇帝拿自己的家业向父亲开玩笑"></a>
### 未央宫成，皇帝拿自己的“家业”向父亲开玩笑

<a id="event-5"></a>

5. **刘邦在未央前殿设宴，诸侯和群臣参加。** 他端起玉杯向太上皇祝酒，说父亲过去常嫌他不治产业、不如二兄勤力，现在看，他与二兄谁挣下的家业更大？满殿大笑、呼万岁。 [[5]](#note-5)

   新宫既是朝廷办公和朝会的场所，也是显示皇帝地位的场所。前一年萧何关于壮丽足以重威的解释，到此成了眼前可以看见的秩序。

<a id="sj017-audience"></a>

<a id="event-6"></a>

6. **诸侯王年表还分别列出楚王刘交、齐王刘肥、淮南王英布、梁王彭越本年来朝。** 这是各王仍在位时的朝见；后来彭越、英布的终局不能提前放进这场年度往来。年表没有说明四人都在同一场未央宴中，故与宴话分层阅读。 [[6]](#note-6)

## 归年与考证

<a id="sj022"></a>

<a id="sj022-note"></a>
<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[本年原表R009](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r009) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0198)。

> 纪年：九；大事纪：未央宮成，置酒前殿，太上皇輦上坐，帝奉玉卮上壽，曰：「始常以臣不如仲力，今臣功孰與仲多？」太上皇笑，殿上稱萬歲。徙齊田，楚昭、屈、景于關中。；相位：九。遷為相國。；将位：〔空〕；御史大夫位：御史大夫昌為趙丞相。

未央宫宴与迁徙齐、楚豪族接本页原文。相位“九，迁为相国”与《汉书》本表有同样栏位，但《萧相国世家》及汉书官制说明把更相国系高祖十一年，现有主叙沿[前196年](bce-0196.md)，不在两年各升一次。周昌为赵相本格早于本页沿通鉴的[前197年](bce-0197.md)一岁，保留表位、以保护刘如意的详细叙事为阅读主线。



<a id="sj008-nine"></a>
<a id="1迁徙大族的政策"></a>
#### 1｜迁徙大族的政策

[卷008 P054](../../sources/摘录/史记-卷008-高祖本纪.md#p054) · [《通鉴》卷十二，高帝九年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7012.md#ref-9ce891e48bb94f)。本纪列楚昭、屈、景、怀、齐田氏；《通鉴》补刘敬建议、十一月及给田宅、十余万口。数量为史书记数，不能证明列出的每一家、每个人都实际迁到同一点；“强本弱末”是政策解释，不自动等于成功消除了反抗。和亲背景与迁民建议相连，作为补充，不把它假称卷008原有完整条文。

<a id="sj008-zhao"></a>
<a id="2不能把谋刺罪名直接转给张敖"></a>
#### 2｜不能把谋刺罪名直接转给张敖

[卷008 P054](../../sources/摘录/史记-卷008-高祖本纪.md#p054)只概述案发、夷族和废王；[《张耳陈馀列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7089.md#ref-3850dae762de4d)、[《通鉴》卷十二](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7012.md#ref-bed56560ebe6c4)保存张敖不赞同、貫高不攀引及审讯过程，故正文采用详细叙事。也不因本纪写“夷三族”就抹去貫高最后获赦而自尽这一不同层次。刘如意此前代王、此时赵王的迁封，不能与刘仲、后来刘恒的代王身份混同。旧文“赵敖”是以国称人，正文统一辨认为张耳之子张敖，不造另一位姓赵的国王。

<a id="sj008-weiyang"></a>
<a id="3未央宴话"></a>
#### 3｜未央宴话

[卷008 P055](../../sources/摘录/史记-卷008-高祖本纪.md#p055)。本纪在九年记宫成与朝会，采用本年位置；与七年长乐宫、八年未央营建分开。父子宴语是传世叙事中的回忆，不据“无赖”古义描写推断现代违法身份，也不将“家业”作为皇帝私人净资产统计。

<a id="sj017-note"></a>
<a id="4卷017的废王异年与四王来朝"></a>
#### 4｜卷017的废王异年与四王来朝

[卷017前199年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0199)在张敖四年格写“废”，下一行[前198年](../../sources/摘录/史记-卷017-汉兴以来诸侯王年表.md#y0198)列刘如意元年。本文仍依本纪、汉书与通鉴将审讯、废王置九年正月，与前199年谋刺分开；原表的异年明确保存，不重演一次废黜。前198年楚、齐、淮南、梁四个来朝格都归本页，数字为各王在位计数，不与皇帝年数相加。

<a id="sj018-grants"></a>
<a id="战死者的儿子长沙的属臣也进入侯籍"></a>
### 战死者的儿子、长沙的属臣，也进入侯籍

**周成因父亲周苛的功劳受封高京侯。** 周苛参加反秦、入汉，后来以御史大夫守荥阳，拒降而死。父亲已经死在前204年，本年的授爵是给后人的报偿，不是周苛重新从荥阳归来。

**长沙王所辖的地方，也有受皇帝诏命为列侯的人。** 陆梁侯须毋可以自行设置属吏，却仍受长沙王节制；义陵侯吴程则原有长沙柱国身份。这类侯国与直接在中央任官的将相，政治位置并不完全相同。

<a id="sj018-note"></a>
<a id="卷018正文采用与尚存的异年异名"></a>
#### 卷018｜正文采用与尚存的异年、异名

上述八项各有原格。其中宣平侯表四月与旧主线九年正月废王不完全同月，保留为处置和侯籍记年的不同记法，未证明精确的分阶段日程，不把它们写成两次废赵王。张耳巨鹿救围、失常山、再王赵仍在前207—202年原页。周苛死亡仍回[前204年](../bce-0300-0201/bce-0204.md#sj007-chenggao-loss)，儿子正式授侯只记本年。

[酂侯R015](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r015)把“九年，为相国”放本年，但[《萧相国世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7053.md#ref-2897d1b60aaea3)明确在十一年韩信被诛以后授相国。沿[前196年](bce-0196.md)主线，不本年先授、两年后无说明地再授。官名不能从一条摘要覆盖较详的事件链。

[芒侯R041](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r041)记昭本年有罪失国，[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-8bf34d0d5d2446)则区分六年耏跖初封、九年昭接续，后来失爵及七国时复封。本轮没有证据把这两条完全抹平，暂不据本格另造一个确定的本年废侯案件；昭参加七国战争后复封仍在前154年。吕台封郦、邓弱失载和这些未定项都保留去向，不以空缺猜出父卒日、罪名或另一场战争。

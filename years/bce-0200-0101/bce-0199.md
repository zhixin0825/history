# 公元前199年｜刘邦东征余部，柏人的伏兵

[← 公元前200年条](bce-0200.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前198年 →](bce-0198.md)

**汉高帝八年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="兵还在打新的宫殿已经建起来"></a>

<a id="event-1"></a>

1. **刘邦向东进攻韩王信的余部，战场在东垣一带。** 前一年平城脱围并没有使北方问题结束。十二月，他从东垣返回；地方兵众与朝廷的冲突仍将延续。 卷118补记刘邦回经赵国时，赵王张敖献美人；美人有孕，张敖另置住所。 [[1]](#note-1)

<a id="event-2"></a>

2. **未央宫营建与君臣问答的异年记载。** 《史记·高祖本纪》把营建与争论系在汉八年，《汉书》和《资治通鉴》系于汉七年。事件见[前200年返长安](bce-0200.md#event-7)，本处保留《史记》的原有入口和异年。 [[2]](#note-2)

<a id="柏人的伏兵没有等到皇帝住宿"></a>

<a id="event-3"></a>

3. **赵相貫高等人在途中藏下刺客，刘邦却没有留下。** 皇帝经过柏人，本来准备住宿，后来又离去，谋刺未能实行。这批赵臣先前因刘邦对赵王不敬而愤怒；赵王张敖本人并不赞同他们的计划。 [[3]](#note-3)

<a id="event-4"></a>

4. **代王刘仲则弃国回到洛阳，被降为合阳侯。** 皇帝亲属接手边地，也不能保证就能守住。刘仲失去王位之后，代地与北方防务仍待重新安排。 [[4]](#note-4)

<a id="三月杨武获封吴房侯"></a>

<a id="event-5"></a>

5. **三月辛卯，杨武因为此前战功被封为吴房侯。** 他曾参加项羽最后一战，与其他四人合验遗体分功。战斗已经过去，正式授爵在本年的功臣表中才有明确记载。 [[5]](#note-5)

<a id="平城之后汉开始另寻对匈奴的办法"></a>

<a id="event-6"></a>

6. **平城之后，汉开始另寻对匈奴的办法。** 刘敬建议用婚姻与往来缓和边境，刘邦却没有真的送出鲁元公主。 刘敬认为新定天下、士卒疲惫，难以立即武服匈奴，主张嫁长公主、厚赠财物。吕后坚决反对把唯一的女儿送去，刘邦没有照原方案实行。和亲实际执行的下一阶段，接见[前198年](bce-0198.md)。 [[6]](#note-6)

<a id="sj091-event-7"></a>

7. **英布到洛阳朝见。** 高祖八年，淮南王英布曾到洛阳朝见。 《高帝纪》又记九月刘邦从洛阳回京，淮南王、梁王、赵王、楚王同往。 [[7]](#note-7)

<a id="sj028-event-8"></a>

8. **高祖诏郡国县立灵星祠。** 有人引周祠后稷为说，高祖诏郡国县立灵星祠，按岁时用牛奉祭。 [[8]](#note-8)

<a id="hs001-event-9"></a>

9. **朝廷规定阵亡士卒送回原县安葬。** 十一月，下令用小棺收殓随军身亡的士卒并送回原县。县里另给衣衾棺具、用少牢祭告，由长吏监葬。 [[9]](#hs001-note-9)

<a id="hs001-event-10"></a>

10. **平城吏卒获终身免役，朝廷规定冠服和商人禁限。** 三月刘邦前往洛阳，赐随军到平城与守城邑者终身免役。又规定公乘及以上才可戴刘氏冠，并限制坐贩商人使用锦绣葛苎、毛织衣料、携兵器和乘骑。 [[10]](#hs001-note-10)

<a id="hs001-event-11"></a>

11. **赦免罪行尚未发觉的官吏。** 八月，高帝赦免有罪而尚未被发觉的官吏。 [[11]](#hs001-note-11)

<a id="hs-event-12"></a>

12. **高祖功臣列侯的本年封授。** 《汉书》功臣表列本年各位受封者的功状和侯籍日次。与既有《史记》同年侯籍合看；旧时战功、正式封爵和后代承爵依原表分别阅读。 [[12]](#hs-note-12)

### 6. 刘敬建议用婚姻与往来缓和边境，刘邦却没有真的送出鲁元公主

[返回正文第6条](#event-6)

<a id="sj099-p005"></a>

**[《史记·刘敬叔孙通列传》P005](../../sources/摘录/史记-卷099-刘敬叔孙通列传.md#p005)** · [三家注](../../sources/史记三家注/卷099.md#p5)

> 高帝罷平城歸，韓王信亡入胡。當是時，冐頓爲單于，兵彊，控弦三十萬，數苦北邊。上患之，問劉敬。劉敬曰：「天下初定，士卒罷於兵，未可以武服也。冐頓殺父代立，妻羣母，以力爲威，未可以仁義說也。獨可以計久遠子孫爲臣耳，然恐陛下不能爲。」上曰：「誠可，何爲不能！顧爲奈何？」劉敬對曰：「陛下誠能以適長公主妻之，厚奉遺之，彼知漢適女送厚，蠻夷必慕以爲閼氏，生子必爲太子。代單于。何者？貪漢重幣。陛下以歲時漢所餘彼所鮮數問遺，因使辯士風諭以禮節。冐頓在，固爲子壻；死，則外孫爲單于。豈嘗聞外孫敢與大父抗禮者哉？兵可無戰以漸臣也。若陛下不能遣長公主，而令宗室及後宮詐稱公主，彼亦知，不肯貴近，無益也。」高帝曰：「善。」

**本卷归年说明：** 本篇从白登归来接议婚，《资治通鉴》另把建议系于高帝八年秋九月段，实际缔约接前198年。

#### 卷018｜十九项封授、一个承侯记录与不能提前的战争

本表十九个八年初封／降侯格和貰方山的承侯都在上表，吴房与合阳接旧正文不重记。原表“后九月”独立保留，非通常九月的笔误。人物名字与[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-b0dc3682f2a226)有将夜／将夕等异文，未据表中简略姓名擅补家世。

温疥的“从曹咎军”由汉表“从破曹咎军”互校，不能翻成他始终隶属楚将曹咎；卢奴／卢绾的疑文不据字面制造一次本年攻城。[陈署格](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r097)“斩曹咎”与[前203年曹咎自杀](../bce-0300-0201/bce-0203.md#sj007-caojiu)不同，本文用参加击破其军，不让曹咎在本年再死一次。陈错、卫胠侯功中陈豨、英布的后事，分别见[前197—195年](bce-0197.md#sj008-chenxi)；功劳摘要和受封年不是同一时间栏。

[合阳R095](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r095)与高祖本纪均系八年，通鉴提前置七年，仍从既有八年主线，前页已经撤回重复初封代王的表述。刘仲六年曾封代王，字仲与本名喜是同一皇兄，不另造两代王。周苛、纪成的战死功由儿子承接，各有不同战场，不因“死事”二字相同便合成一个家族。

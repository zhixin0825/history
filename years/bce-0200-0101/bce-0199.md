**汉高帝八年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="兵还在打新的宫殿已经建起来"></a>

<a id="event-1"></a>

<a id="event-4"></a>

1. **刘邦攻韩王信余部，刘仲弃代降侯。** 刘邦东攻韩王信余部，十二月自东垣返回。回经赵国时赵王张敖献一名女子，女子有孕后被另置住所。匈奴在北边施压，代王刘仲弃国回洛阳，被降为合阳侯。 [[1]](#note-1)

<a id="event-2"></a>

2. **萧何建未央宫，因宫室壮丽被刘邦责问。** 萧何主持营建未央宫，修筑台阙、前殿、武库和粮仓。刘邦回长安后，见宫室壮丽，责问何以营造过度。萧何说天子以四海为家，宫室须有足以彰显威重的规模，刘邦接受了这个解释。 [[2]](#note-2)

<a id="柏人的伏兵没有等到皇帝住宿"></a>

<a id="event-3"></a>

3. **赵相貫高等人在途中藏下刺客，刘邦却没有留下。** 皇帝经过柏人，本来准备住宿，后来又离去，谋刺未能实行。这批赵臣先前因刘邦对赵王不敬而愤怒；赵王张敖本人并不赞同他们的计划。 [[3]](#note-3)

<a id="三月杨武获封吴房侯"></a>

<a id="event-5"></a>

4. **三月辛卯，杨武因为此前战功被封为吴房侯。** 他曾参加项羽最后一战，与其他四人合验遗体分功。战斗已经过去，正式授爵在本年的功臣表中才有明确记载。 [[4]](#note-5)

<a id="平城之后汉开始另寻对匈奴的办法"></a>

<a id="event-6"></a>

5. **平城之后，汉开始另寻对匈奴的办法。** 刘敬建议用婚姻与往来缓和边境，刘邦却没有真的送出鲁元公主。 刘敬认为新定天下、士卒疲惫，难以立即武服匈奴，主张嫁长公主、厚赠财物。吕后坚决反对把唯一的女儿送去，刘邦没有照原方案实行。和亲实际执行的下一阶段，接见[前198年](bce-0198.md)。 [[5]](#note-6)

<a id="sj091-event-7"></a>

6. **英布到洛阳朝见。** 淮南王英布到洛阳朝见刘邦。刘邦离开洛阳回京时，淮南王、梁王、赵王、楚王一同随行。 [[6]](#note-7)

<a id="sj028-event-8"></a>

7. **高祖诏郡国县立灵星祠。** 有人引周祠后稷为说，高祖诏郡国县立灵星祠，按岁时用牛奉祭。 [[7]](#note-8)

<a id="hs001-event-9"></a>

<a id="hs001-event-10"></a>

8. **平城战后，朝廷安葬阵亡士卒并优免从军者。** 朝廷规定阵亡士卒送回原县安葬。十一月，下令用小棺收殓随军身亡的士卒并送回原县。县里另给衣衾棺具、用少牢祭告，由长吏监葬。平城吏卒获终身免役，朝廷规定冠服和商人禁限。三月刘邦前往洛阳，赐随军到平城与守城邑者终身免役。又规定公乘及以上才可戴刘氏冠，并限制坐贩商人使用锦绣葛苎、毛织衣料、携兵器和乘骑。 [[8]](#hs001-note-9)

<a id="hs001-event-11"></a>

9. **赦免罪行尚未发觉的官吏。** 八月，高帝赦免有罪而尚未被发觉的官吏。 [[9]](#hs001-note-11)

<a id="hs-event-12"></a>

10. **高祖功臣列侯的本年封授。** 《汉书》功臣表列本年各位受封者的功状和侯籍日次。与既有《史记》同年侯籍合看；旧时战功、正式封爵和后代承爵依原表分别阅读。 [[10]](#hs-note-12)

<a id="hs-event-13"></a>

11. **高祖八年朔旦冬至异历。** 世经记高祖八年十一月朔旦冬至，三统历乙巳，殷历丙午。 [[11]](#hs-note-13)

### 5. 平城之后，汉开始另寻对匈奴的办法

[返回正文第5条](#event-6)

<a id="hs043-l7406-e6"></a>

**[《汉书·郦陆朱刘叔孙传》P016](../../拆分史书/汉书/卷043.md#p016)** · [仓内TXT L7406](../../拆分史书/汉书/卷043.md#part-1-L7406)

> 高帝罷平城歸，韓王信亡人胡。當是時，冒頓單于兵強，控弦四十萬騎，數若北邊。上患之，問敬。敬曰：「天下初定，士卒罷於兵革，未可以武服也。冒頓殺人父代立，妻群母，以力為威，未可以仁義說也。獨可以計久遠子孫為臣耳，然陛下恐不能為。」上曰：「誠可，何為不能！顧為奈何？」敬曰：「陛下誠能以適長公主妻單于，厚奉遺之，彼知漢女送厚，蠻夷必慕，以為閼氏，生子必為太子，代單于。何者？貪漢重幣。陛下以歲時漢所餘彼所鮮數問遺，使辯士風喻以禮節。冒頓在，固為子婿；死，外孫為單于。豈曾聞孫敢與大父亢禮哉？可毋戰以漸臣也。若陛下不能遣長公主，而令宗室及後宮詐稱公主，彼亦知不肯貴近，無益也。」高帝曰：「善。」欲遣長公主。呂後泣曰：「妾唯以一太子、一女，奈何棄之匈奴！」上竟不能遣長公主，而取家人子為公主，妻單于。使敬往結和親約。

<a id="sj099-p005"></a>

**[《史记·刘敬叔孙通列传》P005](../../拆分史书/史记/卷099.md#p005)** · [三家注](../../拆分史书/史记/卷099.md#part-2-p5)

> 高帝罷平城歸，韓王信亡入胡。當是時，冐頓爲單于，兵彊，控弦三十萬，數苦北邊。上患之，問劉敬。劉敬曰：「天下初定，士卒罷於兵，未可以武服也。冐頓殺父代立，妻羣母，以力爲威，未可以仁義說也。獨可以計久遠子孫爲臣耳，然恐陛下不能爲。」上曰：「誠可，何爲不能！顧爲奈何？」劉敬對曰：「陛下誠能以適長公主妻之，厚奉遺之，彼知漢適女送厚，蠻夷必慕以爲閼氏，生子必爲太子。代單于。何者？貪漢重幣。陛下以歲時漢所餘彼所鮮數問遺，因使辯士風諭以禮節。冐頓在，固爲子壻；死，則外孫爲單于。豈嘗聞外孫敢與大父抗禮者哉？兵可無戰以漸臣也。若陛下不能遣長公主，而令宗室及後宮詐稱公主，彼亦知，不肯貴近，無益也。」高帝曰：「善。」

**本卷归年说明：** 本篇从白登归来接议婚，《资治通鉴》另把建议系于高帝八年秋九月段，实际缔约接前198年。

#### 卷018｜十九项封授、一个承侯记录与不能提前的战争

本表十九个八年初封／降侯格和貰方山的承侯都在上表，吴房与合阳接旧正文不重记。原表“后九月”独立保留，非通常九月的笔误。人物名字与[汉书功臣表](../../拆分史书/汉书/卷016.md#part-1-text)有将夜／将夕等异文，未据表中简略姓名擅补家世。

温疥的“从曹咎军”由汉表“从破曹咎军”互校，不能翻成他始终隶属楚将曹咎；卢奴／卢绾的疑文不据字面制造一次本年攻城。[陈署格](../../拆分史书/史记/卷018.md#r097)“斩曹咎”与[前203年曹咎自杀](../bce-0300-0201/bce-0203.md#sj007-caojiu)不同，本文用参加击破其军，不让曹咎在本年再死一次。陈错、卫胠侯功中陈豨、英布的后事，分别见[前197—195年](bce-0197.md#sj008-chenxi)；功劳摘要和受封年不是同一时间栏。

[合阳R095](../../拆分史书/史记/卷018.md#r095)与高祖本纪均系八年，通鉴提前置七年，仍从既有八年主线，前页已经撤回重复初封代王的表述。刘仲六年曾封代王，字仲与本名喜是同一皇兄，不另造两代王。周苛、纪成的战死功由儿子承接，各有不同战场，不因“死事”二字相同便合成一个家族。

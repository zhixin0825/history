# 公元前200年条｜新朝礼仪已立，皇帝却被围在平城

[← 公元前201年](../bce-0300-0201/bce-0201.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前199年 →](bce-0199.md)

**汉高帝七年**

> 本页按汉七年对应前200年的古史整年口径归档。冬十月在正月以前，不能直接读成公历前200年10月。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="冬十月朝会不再容许诸将随意争功"></a>

<a id="event-1"></a>

1. **冬十月，朝会不再容许诸将随意争功。** 长乐宫的朝贺，按叔孙通制定的仪式举行。 诸侯、大臣按官位依次入殿，侍卫执兵列立，敬酒也有固定次序；违礼者被带走。过去饮酒争功、拔剑击柱的随意气氛，被分明的皇帝与臣下等级代替。 [[1]](#note-1)

   这套礼仪并非完全重造，既采古礼，也采用秦仪。刘邦表示自己到这时才真正体会到皇帝的尊贵。

<a id="讨韩王信从连胜走进包围"></a>

<a id="event-2"></a>

2. **刘邦北征，在铜鞮击败韩王信的军队。** 韩王信退往匈奴，曼丘臣、王黄又拥立赵利为王，联合败兵和匈奴骑兵继续抵抗。汉军屡胜追进，却遇严寒大雪，不少士兵冻伤手指。 周勃功录还记降霍人、在武泉北破胡骑，转攻铜鞮，降太原六城，在晋阳城下破韩王信所联合的骑兵并取晋阳；此前后各战按本次北征阶段对读，不补日次。 [[2]](#note-2)

<a id="event-3"></a>

3. **匈奴有意让使者看见老弱与瘦畜，刘邦低估了对方。** 刘敬回来提醒，这恰恰可能是诱敌；汉军已经出动，皇帝不听，反把他拘禁。主力尚未全部赶到时，刘邦先到平城，冒顿出骑兵把他围在白登，内外不能相救送粮，困了七日。 [[3]](#note-3)

<a id="event-4"></a>

4. **这一年还记下环绕参、毕的七重月晕。** 观测的确切日子没有留下，不能从“七重”倒推出围城一定持续七日。 [[4]](#note-4)

<a id="event-5"></a>

5. **脱围靠交涉与军事戒备一起完成。** 陈平设法向阏氏送重礼，请她劝冒顿；匈奴一方又因约定援军未到而生疑，最后放开一角。汉军持强弩护着皇帝出围，与大军会合后撤回，樊哙留下继续平定代地。 本篇只明记使单于阏氏而解围，并说计策保密、世莫得闻；古注以献美人相威胁的说法没有被当作确定经过。 周勃此役的相连功状还列在硰石破敌、追北八十里，取楼烦三城，在平城城下击胡骑，所部当驰道立功；这是一段北征回顾，不等于所有动作都发生于解围之后。 [[5]](#note-5)

<a id="返程后朝廷继续收拢北边和首都"></a>

<a id="event-6"></a>

6. **刘邦释放刘敬，承认没有听取他的警告。** 此后任其参与边事，陈平也因脱围之功改封曲逆。原已受封代王的刘仲仍面对北方压力；他弃国降侯的年次另见下一年及本页说明，不在本年再初封一次。 回军南过曲逆时，刘邦登城见房舍壮盛，问得秦时三万余户、战后今见五千户，遂将该县尽给陈平食邑，除去原户牖封邑；户籍减少不全等于人口死亡。 [[6]](#note-6)

<a id="event-7"></a>

7. **二月，皇帝经赵、洛阳回到长安，丞相以下迁来办公。** 从前202年决定入都关中，到宫室可用、朝仪实施、中央官署迁治，是一个持续数年的过程。 张敖进食相迎却受刘邦责骂，赵午、贯高等私谋行刺。张敖拒绝参与，次年柏人设刺另见[前199年](bce-0199.md#note-3)。 萧何营治未央宫，立东阙、北阙、前殿、武库、太仓。刘邦见宫室壮丽，一度责其过度，后接受萧何的解释。朝廷自栎阳徙都长安，置宗正掌宗族事务；夏四月皇帝又往洛阳。 [[7]](#note-7)

<a id="原有功臣封侯记录"></a>

<a id="event-8"></a>

8. **十月癸亥，刘它被封为平皋侯。** 他原属项氏，前一年以砀郡长归汉并获赐刘姓。本年的封爵与前一年归附分开。 [[8]](#note-8)

<a id="event-9"></a>

9. **正月己酉，吕马童、王翳、杨喜分别封中水侯、杜衍侯、赤泉侯。** 三人都参与项羽最后一战、取得遗体并分功；战争发生在汉五年，正式初封则在汉七年。 [[9]](#note-9)

<a id="event-10"></a>

10. **吕胜也在本年封为涅阳侯，但月日未明。** 另一位分功者杨武的封侯在下一年，不因本纪把五人合写就认作同日。 [[10]](#note-10)

<a id="sj050-gengjie-event"></a>

11. **十月，刘信受封羹颉侯，侯号还带着长嫂家的一段旧怨。** 刘信是高祖早逝长兄刘伯的儿子，也曾随军击韩王信。刘邦微时常带客人到长嫂家吃饭，嫂子厌烦，假装羹已吃完，刮敲锅子赶走宾客；刘邦发现锅里仍有羹，从此记恨。称帝后，他封了兄弟，偏把侄子留下；太上皇开口，他才说并非忘记，只嫌嫂子待人不厚道，随后给刘信封侯。这个封号的笑谈是受封以前的家事，不能把当年刮锅的场景也定在本年十月。 [[11]](#sj050-gengjie-note)

<a id="sj091-event-12"></a>

12. **英布到陈朝见。** 高祖七年，淮南王英布曾到陈朝见，具体月份无载。 [[12]](#note-12)

<a id="hs001-event-13"></a>

13. **皇子刘如意被立为代王。** 高帝立戚夫人所生的刘如意为代王。此是他首次封代，九年改封赵王另有年条；刘喜弃代的年次有两种记载。 [[13]](#hs001-note-13)

<a id="hs001-event-14"></a>

14. **郎中重罪须奏请，生育者免役两年。** 郎中如犯耐刑及以上之罪，须先奏请。百姓生育，免役两年。 [[14]](#hs001-note-14)

<a id="hs-event-15"></a>

15. **高祖功臣列侯的本年封授。** 《汉书》功臣表列本年各位受封者的功状和侯籍日次。与既有《史记》同年侯籍合看；旧时战功、正式封爵和后代承爵依原表分别阅读。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **叔孙通任奉常。** 叔孙通任奉常。参见本年的官职变动原句。 [[16]](#hs-note-16)

> 漢七年，長樂宮成，諸侯羣臣皆朝十月。儀：先平明，謁者治禮，引以次入殿門，廷中陳車騎步卒衞宮，設兵張旗志。傳言「趨」。殿下郎中俠陛，陛數百人。功臣列侯諸將軍軍吏以次陳西方，東鄉；文官丞相以下陳東方，西鄉。大行設九賔，臚句傳。於是皇帝輦出房，百官執職傳警，引諸侯王以下至吏六百石以次奉賀。自諸侯王以下莫不振恐肅敬。至禮畢，復置法酒。諸侍坐殿上皆伏抑首，以尊卑次起上壽。觴九行，謁者言「罷酒」。御史執法舉不如儀者輙引去。竟朝置酒，無敢讙譁失禮者。於是高帝曰：「吾迺今日知爲皇帝之貴也。」迺拜叔孫通爲太常，賜金五百斤。

**本卷归年说明：** 列传明记汉七年十月。前一古历年已开始制礼；本篇此时称太常，《汉书》作奉常，官名异写见本卷考证。

**[《史记·刘敬叔孙通列传》P014](../../sources/摘录/史记-卷099-刘敬叔孙通列传.md#p014)** · [三家注](../../sources/史记三家注/卷099.md#p14)

### 3. 匈奴有意让使者看见老弱与瘦畜，刘邦低估了对方

[返回正文第3条](#event-3)

<a id="hs001-p079-e3"></a>

**[《汉书·高帝纪》P079](../../sources/摘录/汉书-高帝纪.md#p079)** · [仓内TXT L81](../../sources/本地分卷/汉书/汉书-卷001.md#L81)

> 遂至平城，為匈奴所圍，七日，

**对读说明：** 平城、白登属于同一次围困。两百科“白登之围”取前200，按古历汉七年年页保存冬十月。

<a id="sj110-p012-e3"></a>

**[《史记·匈奴列传》P012](../../sources/摘录/史记-卷110-匈奴列传.md#p012)** · [三家注](../../sources/史记三家注/卷110.md#p12)

> 於是冒頓詳敗走，誘漢兵。漢兵逐擊冒頓，冒頓匿其精兵，見其羸弱，於是漢悉兵，多步兵，三十二萬，北逐之。高帝先至平城，步兵未盡到，冒頓縱精兵四十萬騎圍高帝於白登，七日，漢兵中外不得相救餉。匈奴騎，其西方盡白馬，東方盡青駹馬，北方盡烏驪馬，南方盡騂馬。

**本卷归年说明：** 各色马及号称兵力依传文保留，非独立核点兵数；七日见纪传。


<a id="sj099-p004-e3"></a>

**[《史记·刘敬叔孙通列传》P004](../../sources/摘录/史记-卷099-刘敬叔孙通列传.md#p004)** · [三家注](../../sources/史记三家注/卷099.md#p4)

> 漢七年，韓王信反，高帝自往擊之。至晉陽，聞信與匈奴欲共擊漢，上大怒，使人使匈奴。匈奴匿其壯士肥牛馬，但見老弱及羸畜。使者十輩來，皆言匈奴可擊。上使劉敬復徃使匈奴，還報曰：「兩國相擊，此宜夸矜見所長。今臣往，徒見羸瘠老弱，此必欲見短，伏奇兵以爭利。愚以爲匈奴不可擊也。」是時漢兵已踰句注，二十餘萬兵已業行。上怒，罵劉敬曰：「齊虜！以口舌得官，今迺妄言沮吾軍。」械繫敬廣武。

**本卷归年说明：** 韩国旧王族韩王信，不同于淮阴侯；降马邑在前201年，汉七年记高祖亲征与使匈奴。

> 高祖兄弟四人，長兄伯，伯蚤卒。始高祖微時，嘗辟事，時時與賓客過巨嫂食。嫂厭叔，叔與客來，嫂詳為羹盡，櫟釜，賓客以故去。已而視釜中尚有羹，高祖由此怨其嫂。及高祖為帝，封昆弟，而伯子獨不得封。太上皇以為言，高祖曰：「某非忘封之也，為其母不長者耳。」於是乃封其子信為羹頡侯。

**白话：** 高祖兄弟四人，长兄刘伯很早就去世了。高祖还没有显达时，早年曾因事躲避，常带着宾客到大嫂家吃饭。大嫂嫌这个小叔子总带客人来；等他和客人到了，便假装锅里的羹已经吃光，用勺子刮敲锅边发出声响，宾客因此告辞。过后高祖查看，锅里明明还有羹，从此怨恨大嫂。等他当了皇帝，兄弟们都得到封爵，只有大哥的儿子没有份。太上皇为此向他开口，高祖回答：“我并不是忘了封他，只是他的母亲待人不厚道。”于是才封侄子刘信为羹颉侯，连侯号也带上了当年刮锅停羹的旧怨。这段家庭笑谈交代封号由来，不能抹去侯表另记的随军功劳。

**本卷辨析：** 前事只交代封号来由：高祖微时刮锅赶客无确年。侯表只记七年中，汉传L7048进一步记七年十月，作为本年授侯月次；不把侄子刘信同韩王信或淮阴侯韩信合为一人。

<a id="4卷018本年十二个初封格与跨年互见"></a>
#### 4｜卷018本年十二个初封格与跨年互见

平皋、涅阳、中水、杜衍、赤泉五项与本页旧封侯记录合并，分别见[R067](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r067)、[R072](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r072)、[R077—R079](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r077)；不重复授爵。吕胜／吕腾、王翳／王翥、许温／许盎以及林挚的简名，参[汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-4b0865f33c97f8)留异文。阳河十月、十一月甲子的差别不强定；没有月日者不借旁行的正月己酉补齐。

[陈平行R009](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r009)以曲逆为总行名，通鉴明记七年回师改封，故在本页加明国名，六年侯籍起算不改成七年才第一次得爵。[樊哙R018](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r018)的“相国三月”是任职三个月的表述，不据此造本年三月单独一场授相国礼。

[刘仲R095](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r095)把封代王明确放六年正月，弃国降侯放八年；通鉴将弃代接在七年。本轮撤回旧页“刘仲本年才被立代王”的写法，初封不重复，弃代主叙仍沿[前199年](bce-0199.md#sj008-eight)既有本纪年线，七年异说在此保留。羹颉侯刘信与韩王信、淮阴侯韩信是三人，封号所附家庭旧怨只作此前背景，不编造确年冲突。

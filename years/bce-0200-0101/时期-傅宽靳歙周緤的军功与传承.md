# 秦末至西汉｜傅宽靳歙周緤的军功与传承（时期阅读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷098完整读本](../../sources/摘录/史记-卷098-傅靳蒯成列传.md) · [纪年与异说](../../meta/考证/史记-卷098-纪年与异说.md)

列传中仅见相对先后、无独立纪年和属于论赞的文字，在此接读。史事有年者可由本卷读本到对应年页。

<a id="event-1"></a>

1. **傅宽从横阳起兵及早期楚战。** 傅宽从横阳随刘邦，任舍人；后来驻待怀受爵，在敖下所部斩骑将，又增食邑。 [[1]](#note-1)

<a id="event-2"></a>

2. **傅宽入齐、任相及屯代。** 傅宽曾随曹参攻博，后任齐右丞相，转为齐相国；在代地由相国转丞相，继续领兵屯守。 [[2]](#note-2)

<a id="event-3"></a>

3. **靳歙反秦时受临平君号，后来略梁。** 靳歙以中涓随刘邦自宛朐起，战亳南、开封东北受临平君号；彭城败后又率军平王武等、略梁、破邢说。 [[3]](#note-3)

<a id="event-4"></a>

4. **靳歙往来赵梁、攻楚及军功总计。** 靳歙率军在河内、赵地与楚汉前线多处作战，曾截楚运道、攻项冠及项悍。本传另总计其开国前后斩获和降服城邑官员的人数。 [[4]](#note-4)

<a id="event-5"></a>

5. **周緤参乘从沛，楚汉相持时不离高祖。** 周緤随刘邦自沛起，入汉定三秦后食池阳，楚汉相持时经历断甬道、渡平阴、会襄国等事，一直不改其心。 [[5]](#note-5)

<a id="event-6"></a>

6. **周昌因罪失去承袭的蒯成侯爵。** 周緤子周昌袭侯后获罪，侯国被撤。 [[6]](#note-6)

<a id="event-7"></a>

7. **两篇史评分别回看三侯。** 司马迁称傅宽与靳歙多立战功、未遭困辱，又赞周緤深受信任、忧主心切。司马贞以军功和忠节写述赞。 [[7]](#note-7)

### 4. 靳歙往来赵梁、攻楚及军功总计

[返回正文第4条](#event-4)

[《史记·傅靳蒯成列传》P006](../../sources/摘录/史记-卷098-傅靳蒯成列传.md#p006) · [三家注p6](../../sources/史记三家注/卷098.md#p6)

> 別之河內，擊趙將賁郝軍朝歌，破之，所將卒得騎將二人，車馬二百五十匹。從攻安陽以東，至棘蒲，下七縣。別攻破趙軍，得其將司馬二人，候四人，降吏卒二千四百人。從攻下邯鄲。別下平陽，身斬守相，所將卒斬兵守、郡守各一人，降鄴。從攻朝歌、邯鄲，及別擊破趙軍，降邯鄲郡六縣。還軍敖倉，破項籍軍成臯南，擊絕楚饟道，起滎陽至襄邑。破項冠軍魯下。略地東至繒、郯、下邳，南至蘄、竹邑。擊項悍濟陽下。

[《史记·傅靳蒯成列传》P007](../../sources/摘录/史记-卷098-傅靳蒯成列传.md#p007) · [三家注p7](../../sources/史记三家注/卷098.md#p7)

> 凡斬首九十級，虜百三十二人；別破軍十四，降城五十九，定郡、國各一，縣二十三；得王、柱國各一人，二千石以下至五百石三十九人。

**归年说明：** 成皋在楚汉诸传另见，同名地点的军功难逐战定年；[陈下破楚](../bce-0300-0201/bce-0202.md#sj098-p006-e25)、江陵定南郡及陈地捕楚王分别入[前202年](../bce-0300-0201/bce-0202.md#sj098-p006)与[前201年](../bce-0300-0201/bce-0201.md#sj098-p006-e2)。

### 5. 周緤参乘从沛，楚汉相持时不离高祖

[返回正文第5条](#event-5)

[《史记·傅靳蒯成列传》P009](../../sources/摘录/史记-卷098-傅靳蒯成列传.md#p009) · [三家注p9](../../sources/史记三家注/卷098.md#p9)

> 蒯成侯緤者，沛人也，姓周氏。常爲高祖參乘，以舍人從起沛。至霸上，西入蜀、漢，還定三秦，食邑池陽。東絕甬道，從出度平陰，遇淮陰侯兵襄國，軍乍利乍不利，終無離上心。以緤爲信武侯，食邑三千三百戶。

**归年说明：** 侯表和本传分载早期从军、始列侯年、定封蒯成等，本传早期信武侯号的授时未明。不得与靳歙的信武侯爵合为一人。

### 7. 两篇史评分别回看三侯

[返回正文第7条](#event-7)

[《史记·傅靳蒯成列传》P012](../../sources/摘录/史记-卷098-傅靳蒯成列传.md#p012) · [三家注p12](../../sources/史记三家注/卷098.md#p12)

> 太史公曰：陽陵侯傅寬、信武侯靳歙皆高爵，從高祖起山東，攻項籍，誅殺名將，破軍降城以十數，未嘗困辱，此亦天授也。蒯成侯周緤操心堅正，身不見疑，上欲有所之，未嘗不垂涕，此有傷心者然，可謂篤厚君子矣。

[《史记·傅靳蒯成列传》P013](../../sources/摘录/史记-卷098-傅靳蒯成列传.md#p013) · [三家注p13](../../sources/史记三家注/卷098.md#p13)

> 索隱述贊曰：陽陵、信武，結髮從漢。動叶人謀，功實天贊。定齊破項，我軍常冠，蒯成委質，夷險不亂。主上稱忠，人臣扼腕。

**归年说明：** 分别保留司马迁与司马贞的判断；两段属于全卷论赞。

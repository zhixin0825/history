# 秦末至汉初｜刘敬叔孙通的进言与制礼（时期阅读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷099完整读本](../../拆分史书/史记/卷099.md) · [纪年与异说](../../拆分史书/史记/卷099.md#kao-eef320959b)

列传中仅见相对先后、无独立纪年和属于论赞的文字，在此接读。史事有年者可由本卷读本到对应年页。

<a id="event-1"></a>

1. **叔孙通早年受秦征召，归汉后因时用人。** 叔孙通在秦先作待诏博士；归汉后改穿楚式短衣，并先向汉王举荐能作战者。汉王任他为博士，号稷嗣君。 [[1]](#note-1)

<a id="event-2"></a>

2. **长乐朝仪从征儒、拒聘到试演。** 叔孙通为约束朝廷宴饮失仪而请制定新朝仪，采古礼兼秦仪。鲁地两名儒者拒绝参与，余人跟随西行，和朝廷治学者及弟子演习，经高帝试观后再教群臣。 [[2]](#note-2)

<a id="event-3"></a>

3. **叔孙通在惠帝时逐步整定汉礼。** 叔孙通任太常时陆续整定汉礼；惠帝一次春游离宫，他倡议采当令樱桃祭献宗庙，开后续荐果之例。 [[3]](#note-3)

<a id="event-4"></a>

4. **司马迁、司马贞评论建都与制礼。** 司马迁以裘、椽之喻说明立国赖众才，称刘敬之议关系长治，叔孙通因时制礼。司马贞回顾建都、朝仪、和亲与安太子四端。 [[4]](#note-4)

> 叔孫通者，薛人也。秦時以文學徵，待詔博士。

> 叔孫通儒服，漢王憎之；迺變其服，服短衣，楚製，漢王喜。

[《史记·刘敬叔孙通列传》P009](../../拆分史书/史记/卷099.md#p009) · [三家注p9](../../拆分史书/史记/卷099.md#part-2-p9)

> 叔孫通之降漢，從儒生弟子百餘人，然通無所言進，專言諸故羣盜壯士進之。弟子皆竊罵曰：「事先生數歲，幸得從降漢，今不能進臣等，專言大猾，何也？」叔孫通聞之，迺謂曰：「漢王方蒙矢石爭天下，諸生寧能鬬乎？故先言斬將搴旗之士。諸生且待我，我不忘矣。」漢王拜叔孫通爲博士，號稷嗣君。

**归年说明：** 秦初任待诏博士无年。归汉可接[前205年](../bce-0300-0201/bce-0205.md#sj099-p007-e15)，改服、荐人与受号无独立月日。

### 2. 长乐朝仪从征儒、拒聘到试演

[返回正文第2条](#event-2)

[《史记·刘敬叔孙通列传》P010](../../拆分史书/史记/卷099.md#p010) · [三家注p10](../../拆分史书/史记/卷099.md#part-2-p10)

> 高帝悉去秦苛儀法，爲簡易。羣臣飲酒爭功，醉或妄呼，拔劔擊柱，高帝患之。叔孫通知上益厭之也，說上曰：「夫儒者難與進取，可與守成。臣願徵魯諸生，與臣弟子共起朝儀。」高帝曰：「得無難乎？」叔孫通曰：「五帝異樂，三王不同禮。禮者，因時世人情爲之節文者也。故夏、殷、周之禮所因損益可知者，謂不相復也。臣願頗采古禮與秦儀雜就之。」上曰：「可試爲之，令易知，度吾所能行爲之。」

[《史记·刘敬叔孙通列传》P011](../../拆分史书/史记/卷099.md#p011) · [三家注p11](../../拆分史书/史记/卷099.md#part-2-p11)

> 於是叔孫通使徵魯諸生三十餘人。魯有兩生不肯行，曰：「公所事者且十主，皆靣諛以得親貴。今天下初定，死者未葬，傷者未起，又欲起禮樂。禮樂所由起，積德百年而後可興也。吾不忍爲公所爲。公所爲不合古，吾不行。公徃矣，無汙我！」叔孫通笑曰：「若真鄙儒也，不知時變。」

[《史记·刘敬叔孙通列传》P012](../../拆分史书/史记/卷099.md#p012) · [三家注p12](../../拆分史书/史记/卷099.md#part-2-p12)

> 遂與所徵三十人西，及上左右爲學者與其弟子百餘人爲綿蕞野外。習之月餘，叔孫通曰：「上可試觀。」上旣觀，使行禮，曰：「吾能爲此。」迺令羣臣習隷，會十月。

**归年说明：** 制仪与试演在[前202年即位仪号](../bce-0300-0201/bce-0202.md#sj099-p010)之后，至[汉七年十月长乐朝会](bce-0200.md#sj099-p013)以前。《资治通鉴》将此过程置[汉六年](../bce-0300-0201/bce-0201.md#sj099-p010)，本传只说练习月余。

### 3. 叔孙通在惠帝时逐步整定汉礼

[返回正文第3条](#event-3)

[《史记·刘敬叔孙通列传》P016](../../拆分史书/史记/卷099.md#p016) · [三家注p16](../../拆分史书/史记/卷099.md#part-2-p16)

> 及稍定漢諸儀法，皆叔孫生爲太常所論著也。

[《史记·刘敬叔孙通列传》P018](../../拆分史书/史记/卷099.md#p018) · [三家注p18](../../拆分史书/史记/卷099.md#part-2-p18)

> 孝惠帝曾春出游離宮，叔孫生曰：「古者有春嘗果，方今櫻桃孰，可獻，願陛下出，因取櫻桃獻宗廟。」上迺許之。諸果獻由此興。

**归年说明：** 惠帝即位及复任太常接[前195年](bce-0195.md#sj099-p016)；“曾春”没有绝对年，前段[立原庙](bce-0191.md#sj099-p017)的年份不移作献果之年。

### 4. 司马迁、司马贞评论建都与制礼

[返回正文第4条](#event-4)

[《史记·刘敬叔孙通列传》P019](../../拆分史书/史记/卷099.md#p019) · [三家注p19](../../拆分史书/史记/卷099.md#part-2-p19)

> 太史公曰：語曰「千金之裘，非一狐之腋也；臺榭之榱，非一木之枝也；三代之際，非一士之智也」。信哉！夫高祖起微細，定海內，謀計用兵，可謂盡之矣。然而劉敬脫輓輅一說，建萬世之安，智豈可專邪！叔孫通希世度務，制禮進退，與時變化，卒爲漢家儒宗。「大直若詘，道固委蛇」，蓋謂是乎？

[《史记·刘敬叔孙通列传》P020](../../拆分史书/史记/卷099.md#p020) · [三家注p20](../../拆分史书/史记/卷099.md#part-2-p20)

> 索隱述贊曰：厦藉衆幹，裘非一狐。委輅獻說，緜蕝陳書。皇帝始貴，車駕西都。旣安太子，又和匈奴。奉春、稷嗣，其功可圖。

**归年说明：** 论赞为回看生平，无独立史事纪年。

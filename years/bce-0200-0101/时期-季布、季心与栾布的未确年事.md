<a id="event-1"></a>

1. **曹丘生宣扬一诺。** 季布本来戒窦长君不与曹丘生往来。曹丘生借楚人之谚解释自己能为季布扬名，两人见面之后反成宾主。传中没有给相见的年份。 [[1]](#note-1)

<a id="event-2"></a>

2. **季心任侠与关中声名。** 季心逃吴、事袁丝、礼遇后辈及任中司马，是一段未依年月分列的生平。袁丝即袁盎，可与卷101所记季心、剧孟互读。 [[2]](#note-2)

<a id="event-3"></a>

3. **栾布早年由梁、齐至燕。** 栾布与平民时的彭越相交，穷困佣于齐，又被掠卖至燕。臧荼为燕王与后来的反败各有独立年据，栾布受荐为都尉和任将的年月未载。 [[3]](#note-3)

<a id="event-4"></a>

4. **栾布报恩怨与燕齐立社。** 文帝时栾布曾任燕相，景帝时复相燕；文帝前元十四年将兵御匈奴已有年页。初任、复任的具体年月以及立社时间未明。 [[4]](#note-4)

<a id="event-5"></a>

5. **司马迁与司马贞评季布、栾布。** 太史公并写忍辱保身与临鼎赴义。索隐述赞重述季布之诺、拒樊哙和栾布哭彭越，是唐代司马贞赞语。 [[5]](#note-5)

## 本期相关史料

<a id="note-1"></a>

### 1. 曹丘生宣扬一诺

[返回正文第1条](#event-1)

[《史记·季布栾布列传》P003](../../sources/摘录/史记-卷100-季布栾布列传.md#p003) · [三家注p3](../../sources/史记三家注/卷100.md#p3)

> 楚人曹丘生，辯士，數招權顧金錢。事貴人趙同等，與竇長君善。季布聞之，寄書諫竇長君曰：「吾聞曹丘生非長者，勿與通。」及曹丘生歸，欲得書請季布。竇長君曰：「季將軍不說足下，足下無徃。」固請書，遂行。使人先發書，季布果大怒，待曹丘。曹丘至，即揖季布曰：「楚人諺曰『得黃金百斤，不如得季布一諾』，足下何以得此聲於梁楚閒哉？且僕楚人，足下亦楚人也。僕游揚足下之名於天下，顧不重邪？何足下距僕之深也！」季布迺大說，引入，留數月，爲上客，厚送之。季布名所以益聞者，曹丘揚之也。

### 2. 季心任侠与关中声名

[返回正文第2条](#event-2)

[《史记·季布栾布列传》P004](../../sources/摘录/史记-卷100-季布栾布列传.md#p004) · [三家注p4](../../sources/史记三家注/卷100.md#p4)

> 季布弟季心，氣蓋關中，遇人恭謹，爲任俠，方數千里，士皆爭爲之死。嘗殺人，亡之吳，從袁絲匿。長事袁絲，弟畜灌夫、籍福之屬。嘗爲中司馬，中尉郅都不敢不加禮。少年多時時竊籍其名以行。當是時，季心以勇，布以諾，著聞關中。

<a id="note-3"></a>

### 3. 栾布早年由梁、齐至燕

[返回正文第3条](#event-3)

[《史记·季布栾布列传》P006](../../sources/摘录/史记-卷100-季布栾布列传.md#p006) · [三家注p6](../../sources/史记三家注/卷100.md#p6)

> 欒布者，梁人也。始梁王彭越爲家人時，嘗與布游。窮困，賃傭於齊，爲酒人保。數歲，彭越去之巨野中爲盜，而布爲人所略賣，爲奴於燕。爲其家主報仇，燕將臧荼舉以爲都尉。臧荼後爲燕王，以布爲將。

<a id="note-4"></a>

### 4. 栾布报恩怨与燕齐立社

[返回正文第4条](#event-4)

[《史记·季布栾布列传》P008](../../sources/摘录/史记-卷100-季布栾布列传.md#p008) · [三家注p8](../../sources/史记三家注/卷100.md#p8)

> 孝文時，爲燕相，至將軍。布迺稱曰：「窮困不能辱身下志，非人也；富貴不能快意，非賢也。」於是嘗有德者厚報之，有怨者必以法滅之。

[《史记·季布栾布列传》P008](../../sources/摘录/史记-卷100-季布栾布列传.md#p008) · [三家注p8](../../sources/史记三家注/卷100.md#p8)

> 復爲燕相。燕齊之間皆爲欒布立社，號曰欒公社。

<a id="note-5"></a>

### 5. 司马迁与司马贞评季布、栾布

[返回正文第5条](#event-5)

[《史记·季布栾布列传》P010](../../sources/摘录/史记-卷100-季布栾布列传.md#p010) · [三家注p10](../../sources/史记三家注/卷100.md#p10)

> 太史公曰：以項羽之氣，而季布以勇顯於楚，身屨典軍搴旗者數矣，可謂壯士。然被刑戮，爲人奴而不死，何其下也！彼必自負其材，故受辱而不羞，欲有所用其未足也，故終爲漢名將。賢者誠重其死。夫婢妾賤人感慨而自殺者，非能勇也，其計畫無復之耳。欒布哭彭越，趣湯如歸者，彼誠知所處，不自重其死。雖徃古烈士，何以加哉！

[《史记·季布栾布列传》P011](../../sources/摘录/史记-卷100-季布栾布列传.md#p011) · [三家注p11](../../sources/史记三家注/卷100.md#p11)

> 索隱述贊曰：季布、季心，有聲梁、楚。百金然諾，十萬致距。出守河東，股肱是與。欒布哭越，犯禁見虜。赴鼎非冤，誠知所處。

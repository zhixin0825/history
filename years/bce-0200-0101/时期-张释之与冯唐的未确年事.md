# 秦汉之际与西汉｜张释之与冯唐的未确年事（时期阅读）

<a id="event-1"></a>

1. **张释之为骑郎而久未迁调。** 张释之依家资入仕，与兄同居，久任骑郎没有得到选调。文帝前元三年有廷尉任命的年据；骑郎始年仍不明。 [[1]](#note-1)

<a id="event-2"></a>

2. **周亚夫与山都侯赏识张廷尉。** 本传写周亚夫、王恬开赏识张释之持议公平。以职官和侯爵核对，三人并列的称衔难以放进同一个确年。 [[2]](#note-2)

<a id="event-3"></a>

3. **景帝初张释之谢罪与王生结袜。** 文帝去世、景帝即位可定在前157年；张释之称病、采纳王生之策谢罪只见相对先后，结袜一事也没有确年。 [[3]](#note-3)

<a id="event-4"></a>

4. **张释之出相淮南及其子张挚。** 景帝即位一年有余，张释之转任淮南相。传说久而卒，未记年份。张挚官至大夫，免后不再出仕。 [[4]](#note-4)

<a id="event-5"></a>

5. **冯唐家世与初任郎官。** 冯唐祖父为赵人，父迁代，汉兴后全家迁安陵。冯唐因孝得名，为文帝中郎署长，初任未见确年。 [[5]](#note-5)

<a id="event-6"></a>

6. **冯唐相楚、免官与冯遂。** 景帝即位后冯唐任楚相，后来免官。本传与《汉书》在即位前的年数有异，任免没有独立年据。武帝举荐年高的冯唐时，转而任冯遂为郎；本传说冯遂与太史公相善。 [[6]](#note-6)

<a id="event-7"></a>

7. **司马迁与司马贞合评张、冯。** 太史公并论张释之不阿君意、冯唐善论任将。司马贞用宫门、犯跸、盗环及魏尚复职等事概括全传。 [[7]](#note-7)

> 釋之恐，稱病。欲免去，懼大誅至；欲見謝，則未知何如。用王生計，卒見謝，景帝不過也。

> 王生者，善爲黃老言，處士也。嘗召居廷中，三公九卿盡會立，王生老人，曰「吾韤解」，顧謂張廷尉：「爲我結韤！」釋之跪而結之。旣已，人或謂王生曰：「獨奈何廷辱張廷尉，使跪結韤？」王生曰：「吾老且賤，自度終無益於張廷尉。張廷尉方今天下名臣，吾故聊辱廷尉，使跪結韤，欲以重之。」諸公聞之，賢王生而重張廷尉。

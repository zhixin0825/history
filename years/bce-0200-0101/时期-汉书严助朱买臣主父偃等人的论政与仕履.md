# 汉书严助朱买臣主父偃等人的论政与仕履

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **严助对策得擢与武帝近臣。** 严助是会稽吴人，父为严夫子或属其从族。郡举贤良，百余人对策唯他得擢中大夫。武帝集朱买臣、司马相如、东方朔等善文者使与大臣辩事，公孙弘开东阁延贤。相如多称疾，东方朔、枚皋常诙谐，严助和吾丘寿王较受实任。 [[1]](#note-1)


<a id="event-2"></a>

2. **越地山水与难治。** 刘安说越人熟舟水、借溪竹为险，汉军不识地势，地图寸数不能尽显实际阻隔。即使得地也难郡县，纵有名义朝贡也不供中国实际用度，不宜一不从令就征，引兵无休。 [[2]](#note-2)


<a id="event-3"></a>

3. **歉收与南征疾病。** 连续歉收和蝗灾使百姓卖爵、赘子，元气未复；远军越岭曳船，风土暑湿致疫，交锋前已会伤亡。先前简忌用兵、处降众上淦及后来再反时舟师疫死过半是旧例，底本在姓名处保留异字及夹注。 [[3]](#note-3)


<a id="event-4"></a>

4. **战后凶年之说。** 刘安把征役愁苦同阴阳灾年联系，称海内无警时不应使兵曝死、边民早闭晚开；灾年原因是疏中采用的观念。 [[4]](#note-4)


<a id="event-5"></a>

5. **越地可守而难深入。** 刘安据淮南旧日边吏消息，称岭水险，不利运粮，越军大举先需在边境积谷造船，可加强边防以应付；汉军深进反受暑湿病害，俘取全越也抵不回损失。 [[5]](#note-5)


<a id="event-6"></a>

6. **招抚与续封的办法。** 疏引用闽越内讧的道路消息，建议愿内附者迁居待之，不然恢复其王侯作屏藩，以印绶安抚。若兵入山林，退则人复聚，留则宫外民耕织馈运并伤，逃亡和盗贼增多。王弟名及死讯仅为奏疏里的传闻。 [[6]](#note-6)


<a id="event-7"></a>

7. **秦攻越与盘桓之祸。** 刘安举屠睢、监禄开渠而秦军久屯、被越军击败，征戍使百姓离散，秦末乱因之加剧；引《老子》和《周易》高宗三年克鬼方劝慎兵。 [[7]](#note-7)


<a id="event-8"></a>

8. **劝以德保内而少兴兵。** 即使取得越王首级，士卒不归仍是损失。刘安说四海资源足奉朝廷，宜修德使民安，不应以十万将士办使者可办之事。 [[8]](#note-8)


<a id="event-9"></a>

9. **严助向淮南陈说停兵与外交。** 严助称兵应慎用但足以禁暴，指闽越杀亲、并邻及侵犯会稽等危险。汉将只屯界示威未战，对方已内部分裂、余善被推杀王，请天子决定继位。南越王称病而遣婴齐入侍，于是汉自称全南越、不伤士卒。 [[9]](#note-9)


<a id="event-10"></a>

10. **刘安称谢，与严助结交。** 刘安以汤与周文王事褒武帝，自谦狂言而蒙使者教告。严助由此私结淮南王后归，武帝也喜欢此次回复。 [[10]](#note-10)


<a id="event-11"></a>

11. **严助出守归朝与作文。** 严助说往日贫而见辱，请为会稽守。几年少问讯，武帝书责，令以《春秋》作答，勿用游说手法。严助请献三年政绩，得留侍中，遇奇事即应诏作文章赋颂。 [[11]](#note-11)


<a id="event-12"></a>

12. **淮南案牵连严助。** 刘安来朝厚赠严助，私相议论。反案牵连时，帝欲从宽，张汤以腹心近臣私通诸侯不诛无以禁后，终把严助处弃市。送礼旧事不并归伏诛年。 [[12]](#note-12)


<a id="event-13"></a>

13. **朱买臣分目。** 以下记朱买臣的早年、仕历及张汤案。 [[13]](#note-13)


<a id="event-14"></a>

14. **樵薪读书和故妻。** 吴人朱买臣字翁子，贫而好读书，卖柴度日，路上常诵歌。妻劝不止而求去，他说年五十将富贵，妻不信。后来故妻同新夫扫墓，见他饥寒仍给饮食。 [[14]](#note-14)


<a id="event-15"></a>

15. **严助荐朱买臣与朔方之议。** 朱买臣随上计吏至长安，上书久无答，困至乞食。严助荐他，武帝喜其说《春秋》及楚辞，擢中大夫、同侍中。公孙弘反对费力筑朔方，帝命朱买臣辩之；后来买臣坐事免官再待诏。 [[15]](#note-15)


<a id="event-16"></a>

16. **出守会稽与东越方略。** 朱买臣从东越王转移险要处所提出海路进兵，武帝命他任会稽守，备船、军粮、水战装备等候诏发，以富贵当归故乡比此任。 [[16]](#note-16)


<a id="event-17"></a>

17. **著旧衣归郡邸报恩。** 朱买臣怀郡印、衣旧衣到郡邸，同旧识食后印露，轻慢者见印连忙谒拜。归乡见前妻夫妻修路，接养园中；前妻后来自缢，他给其夫钱安葬，又报答旧日有恩者。 [[17]](#note-17)


<a id="event-18"></a>

18. **随韩说破东越。** 任会稽一年多奉命同横海将军韩说等击破东越，后征主爵都尉、列九卿。本句安排列任事相对年与下文张汤案不合，须另校。 [[18]](#note-18)


<a id="event-19"></a>

19. **朱买臣与张汤的旧怨及死。** 朱买臣免官后任丞相长史，怨张汤曾深治严助，张汤代理相务又轻折买臣，买臣不礼。后来买臣等告张汤，张汤自杀，买臣亦被诛，其子山拊历守郡及右扶风。 [[19]](#note-19)


<a id="event-20"></a>

20. **吾丘寿王分目。** 以下记吾丘寿王治郡、禁弩之辩及宝鼎释义。 [[20]](#note-20)


<a id="event-21"></a>

21. **从董仲舒及复官。** 吾丘寿王少以格五受召，跟董仲舒学《春秋》。侍中中郎因法去职，求养马、守塞皆不准，再请论击匈奴，对问得当而复任郎。 [[21]](#note-21)


<a id="event-22"></a>

22. **独领东郡及武帝责问。** 东郡盗起，吾丘寿王任都尉而不另置太守。武帝责他原在御前机敏，今兼两职四千石仍失治，寿王谢罪并陈状；此未载确年。 [[22]](#note-22)


<a id="event-23"></a>

23. **公孙弘提议禁民持弓弩。** 吾丘寿王回朝任光禄大夫、侍中。公孙弘称盗贼持弩少能拒多，若只持短兵便易被众吏制伏，故请禁止百姓挟弓弩。寿王受命论议。 [[23]](#note-23)


<a id="event-24"></a>

24. **从秦亡辨禁兵不足止乱。** 寿王称兵用于止暴，周衰弱肉强食才武器愈巧，秦焚书聚权、毁兵而民仍持农具相攻，严刑不止盗。故君主应务教化，不单恃禁防。 [[24]](#note-24)


<a id="event-25"></a>

25. **禁弩不能止恶且妨礼与备。** 寿王引初生设弧矢、《论语》孔子执射及《诗》列射礼，指恶人不畏重刑，禁弓反去善民自备，既未除盗又坏古礼，盗在地方长吏失政。 [[25]](#note-25)


<a id="event-26"></a>

26. **公孙弘服难。** 帝拿寿王奏难问公孙弘，弘理屈而服。 [[26]](#note-26)


<a id="event-27"></a>

27. **主父偃分目。** 以下记主父偃上书、推恩徙陵及齐案。 [[27]](#note-27)


<a id="event-28"></a>

28. **主父偃从困游到上书。** 临菑人主父偃学纵横术、经史百家，为齐儒所排，齐燕赵中山均困窘。入关求见卫将军，经荐不理，最后晨上书暮获召。书九事、八讲律令、一劝勿攻匈奴；本传「元光元年」和《通鉴》所取召见年另辨。 [[28]](#note-28)


<a id="event-29"></a>

29. **不避死陈直策。** 主父偃先说君不恶切谏而见广，臣不避诛而敢直，愿皇帝宽宥察其计。 [[29]](#note-29)


<a id="event-30"></a>

30. **从秦攻匈奴论转输和征役之害。** 秦统一后不听李斯反对，派蒙恬夺河南、使民戍河。匈奴移徙难制，又得地不生五谷；长期调粮，传说海郡到边塞三十钟只至一石，耕织不起军需，民困死而反。 [[30]](#note-30)


<a id="event-31"></a>

31. **军费与边将离心。** 主父偃称即使俘单于也不足偿长役之费，积怨愈多；边户困苦、将官相疑，可致如赵佗、章邯各谋其私。劝明主细察命令与用人。 [[31]](#note-31)


<a id="event-32"></a>

32. **立后、告燕事及主父偃自述。** 传说卫后册立及发刘定国案有主父偃功。位贵后诸臣畏而馈千金，他以早年遭弃和不愿困死自辩，说不能五鼎而食也要五鼎被烹。 [[32]](#note-32)


<a id="event-33"></a>

33. **赵王告发与诛主父偃。** 赵王见燕事先发、怕朝廷侍臣害赵，趁主父偃出京告他收诸侯财。偃认受财而否认迫齐王自杀；帝原欲免死，公孙弘称不诛不能释天下之疑，遂族诛。 [[33]](#note-33)


<a id="event-34"></a>

34. **孔车独葬主父偃。** 旧客多而败后无人照料，唯孔车收葬，武帝以此称其长者。葬日未详。 [[34]](#note-34)


<a id="event-35"></a>

35. **徐乐分目。** 以下引徐乐所奏的土崩瓦解之论。 [[35]](#note-35)


<a id="event-36"></a>

36. **徐乐上书。** 徐乐燕地无终人，下文存其谏疏。 [[36]](#note-36)


<a id="event-37"></a>

37. **穷乡布衣陈涉得众。** 陈涉无财、名望、官号、土地，却一呼百应，因为百姓困怨、君上不恤、风俗政令乱；这是土崩之例。 [[37]](#note-37)


<a id="event-38"></a>

38. **七国权重而败。** 吴楚等王有兵甲和土地，却未能取得境外助力，文景之德未衰、百姓安俗，乱不能外扩，是瓦解之例。 [[38]](#note-38)


<a id="event-39"></a>

39. **辨社稷安危的两种局面。** 真正土崩时布衣也能起事，大势未坏则再强的叛军也会被擒，君上须区分而观察治安根基。 [[39]](#note-39)


<a id="event-40"></a>

40. **关东歉收与治未发之患。** 关东数年饥困，加上边事使民不安而易动。徐乐劝从朝廷先治未发，若能恢复良俗便可安游无宿忧、使远方归服，用仁厚求王虽未成仍可保安。 [[40]](#note-40)


<a id="event-41"></a>

41. **严安分目。** 以下引严安从风俗、征伐和郡权陈谏。 [[41]](#note-41)


<a id="event-42"></a>

42. **严安由丞相史上书。** 临菑人严安以故丞相史身份陈奏。 [[42]](#note-42)


<a id="event-43"></a>

43. **消费竞奢败俗及制度之防。** 援邹衍说政教文质应救时弊。车宫衣食声色互相夸耀，使民离本逐末、诈取犯禁。劝限制贫富相耀，使人恬安，盗贼、刑罚减少，最终阴阳时令和顺是疏中设想。 [[43]](#note-43)


<a id="event-44"></a>

44. **周室衰弱及战国兵戈。** 严安称周成康刑置不用，后王室衰、五霸暂扶，霸业绝则强吞弱、田常篡齐、六卿分晋、战国连年，百姓受困。 [[44]](#note-44)


<a id="event-45"></a>

45. **秦过强而亡于穷兵。** 秦统一拆城销兵，若薄赋省役有望久安，实际重刻法而任佞巧，北命蒙恬、南令屠睢和监禄开渠，苦转输、留戍、病饥；赵佗继续镇越。始皇死而陈胜吴广、武臣张耳等并发，无世袭势力仍各据地。这是严安以周弱与秦强皆须因时变化的论证。 [[45]](#note-45)


<a id="event-46"></a>

46. **当时远征与外郡过强。** 严安以南夷、夜郎、羌僰、薉和匈奴各处战事称人臣一时之利。远役难久，广郡兼多城与甲兵，郡守过重，遇变可害宗室；应鉴齐晋、秦的不同灭亡方式。 [[46]](#note-46)


<a id="event-47"></a>

47. **严安任骑马令。** 任命在上书之后，传未明年月。 [[47]](#note-47)


<a id="event-48"></a>

48. **终军分目。** 以下记终军少年入仕、答政议及使南越。 [[48]](#note-48)


<a id="event-49"></a>

49. **终军少学而擢谒者。** 济南人终军字子云，少善辩作文，十八选博士弟子。辞太守到长安上书，帝异其文，使为谒者给事中。 [[49]](#note-49)


<a id="event-50"></a>

50. **以内附和军功说德威。** 终军称诗乐同颂君功，引东瓯内附、闽王伏罪、南越获救、漠北及浑邪归降作政治形势的合叙，劝明刑举贤、明制度、修封禅；这些战事跨年，不能据此倒作同年。 [[50]](#note-50)


<a id="event-51"></a>

51. **仪制完成与白鱼献瑞。** 终军以周至成王方定制比汉德积盛，天以异兽示享，再举武王渡河白鱼入舟，劝改纪元、更新名号、封禅。 [[51]](#note-51)


<a id="event-52"></a>

52. **用异象猜度远人来附。** 终军说六鶂逆飞和白鱼顺舟各表政象，麟同角与木众枝内合象同源无外，预测异俗将从汉礼服；是奏中祥瑞解法。 [[52]](#note-52)


<a id="event-53"></a>

53. **终军进对与元狩名。** 帝以对为异，传说因改元狩；随后边地有人降，当时以为终军占验。段中援引部分较后军事，应用帝纪和年号异说互校。 [[53]](#note-53)


<a id="event-54"></a>

54. **辨徐偃矫制鼓铸。** 徐偃巡行擅令胶东、鲁冶铁盐，张汤认为应死，徐偃以古使臣出疆便宜辩护。终军说天下统一王者无外，附近各郡能给盐铁，冶具迟到不能救春耕，屡请不许仍矫制求名。徐偃词屈，终军请交御史，帝采纳。 [[54]](#note-54)


<a id="event-55"></a>

55. **终军弃繻与持节再出关。** 赴长安时拒留返程半符，后来任谒者持节东出，关吏认出当年的弃繻生。巡郡陈奏便利，武帝赞许。 [[55]](#note-55)


<a id="event-56"></a>

56. **请出使匈奴并迁谏大夫。** 终军称素无军功却食宿卫禄，请随使入匈奴、陈说利害。武帝问其内容，赏其答而升谏大夫；这里并未记他确实出行。 [[56]](#note-56)


<a id="event-57"></a>

57. **王褒分目。** 以下记蜀士王褒奏颂、侍太子及出使。 [[57]](#note-57)


<a id="event-58"></a>

58. **宣帝征文士、兴协律及蜀地作诗。** 宣帝效武帝征文士，九江被公、刘向等入朝，魏相荐赵定龚德鼓琴。益州刺史王襄请王褒作《中和》等诗，选何武等按《鹿鸣》习唱；传至太学后宣帝召见、赐帛。 [[58]](#note-58)


<a id="event-59"></a>

59. **王褒受召写圣主得贤臣颂。** 王褒为刺史作诗颂并作传，刺史荐其异才。召至后帝命述明主得贤臣之意。 [[59]](#note-59)


<a id="event-60"></a>

60. **颂辞自谦。** 王褒以粗衣淡食难语丝棉太牢自比，称生于穷巷、见闻有限仍愿陈实情。 [[60]](#note-60)


<a id="event-61"></a>

61. **巧工利器以喻君得士。** 颂以钝器苦工、干将利剑，庸御驾驽马与良驭良骥对照；得具易有成，明主待贤而省力，举周公礼贤、齐桓庭燎揽士为证。 [[61]](#note-61)


<a id="event-62"></a>

62. **贤臣待明主。** 王褒举伊尹、太公、百里奚、宁戚未遇时困顿，遇明主方能荐谏授任、显业传后。以龙虎风云、鸿儒才臣聚朝及《易》《诗》说明贤人因合适处境而出。 [[62]](#note-62)


<a id="event-63"></a>

63. **君臣相得、垂拱而治。** 贤主与俊士彼此借重，如风载羽、鱼游巨壑，政治举措因而通行，远国来献、福祥具至；可恬淡无为全寿，无须仿彭祖或王子乔、赤松子远世求仙。 [[63]](#note-63)


<a id="event-64"></a>

64. **颂及神仙缘帝好。** 宣帝喜方术，所以王褒颂也用神仙例说明有贤不必求仙。 [[64]](#note-64)


<a id="event-65"></a>

65. **宣帝辩歌赋有用。** 王褒等常随猎，在宫馆作歌赋，帝品第赏帛。有人以为淫靡，宣帝说大的近《诗》，小的可悦耳目仍有讽谕与博物，胜倡优博戏。王褒后为谏大夫。 [[65]](#note-65)


<a id="event-66"></a>

66. **为太子读奇文。** 太子病而不乐善忘，武帝以后这一代朝廷命王褒等入宫诵新奇或自作文字，平复后归。太子还让后宫诵王褒《甘泉》《洞箫》二颂。 [[66]](#note-66)


<a id="event-67"></a>

67. **赴益州祭金马碧鸡。** 方士称益州宝物可由祭礼求致，宣帝遣王褒赴祭。他病死路上，帝怜惜；奉命和具体卒日未明同日。 [[67]](#note-67)


<a id="event-68"></a>

68. **贾捐之分目。** 以下记贾捐之议珠崖及因石显获罪。 [[68]](#note-68)


<a id="event-69"></a>

69. **贾捐之元帝初上疏。** 贾捐之是贾谊曾孙，字君房，元帝初进言政事、待诏金马门。 [[69]](#note-69)


<a id="event-70"></a>

70. **儋耳珠崖设废、屡乱与廷问。** 武帝时海南置儋耳珠崖，十六县逾二万户，传以吏酷、民反解释数次诛守再举兵。昭帝废儋耳并珠崖；宣帝、元帝连有反乱。朝议大举，贾捐之反对，王商奉命问其如何保先帝旧疆。 [[70]](#note-70)


<a id="event-71"></a>

71. **谢有直言之机会。** 贾捐之称有幸处明朝得言无讳，愿尽所见。 [[71]](#note-71)


<a id="event-72"></a>

72. **以古德治反对强拓。** 贾捐之说尧舜禹声教至四海而不强不愿归者，殷周名君疆域不必广大，越裳来献也非兵威。秦贪外虚内，终于二世天下反。 [[72]](#note-72)


<a id="event-73"></a>

73. **文帝节俭与武帝远征对比。** 举文帝退千里马、薄租轻役，不事声色；再举武帝因仓帑有积大量征伐，西通安息、东置乐浪玄菟、南拓海疆，税刑与专卖大增仍不济，百姓死伤、妇儿无依，内外生乱，是奏者劝止兵的对照。 [[73]](#note-73)


<a id="event-74"></a>

74. **关东流离与珠崖用兵风险。** 贾捐之称关东饥民离城、妻子离散，应优先救济。珠崖远、药虫湿气损兵，珠犀各方亦有，抛却并不损威。所说骆越人负面习惯出自奏疏，不可一概归于当地人。 [[74]](#note-74)


<a id="event-75"></a>

75. **以羌役花费估量珠崖。** 较近的羌役尚使大司农钱尽、动少府私藏，更远的征珠崖可徒伤人且无实功，故宜撤郡救关东。 [[75]](#note-75)


<a id="event-76"></a>

76. **杨兴与贾捐之交互求进。** 贾捐之讥石显而渐疏，想荐友杨兴为京兆，杨兴称其可替五鹿充宗为尚书令。贾捐之列先前荐贤、阻宦官入庙等事自证，杨兴劝先与石显通意。 [[76]](#note-76)


<a id="event-77"></a>

77. **同作荐石显、杨兴章。** 二人拟荐石显有礼守职，拟赐爵任其兄弟；又以六位名臣的专长比杨兴，称可试京兆尹。 [[77]](#note-77)


<a id="event-78"></a>

78. **石显告发、杂治及罪状。** 石显闻计划告帝，阳平侯王禁与石显共审，指二人相荐谋大位、泄省中语、欺罔，援经书求依法定罪。 [[78]](#note-78)


<a id="event-79"></a>

79. **贾捐之伏法及杨兴后来复用。** 贾捐之弃市，杨兴减死、髡钳服役，成帝时复做到部刺史。 [[79]](#note-79)


<a id="event-80"></a>

80. **班固总评远征之议及被诛者。** 赞称古来已有胡越之患，汉征伐至盛，刘安、主父偃、严安、贾捐之的奏议有切处，故详录。对世称公孙弘排偃、张汤陷助、石显谮捐之，班固又从他们求权和交私责任评其死。 [[80]](#note-80)

### 2. 越地山水与难治

[返回正文第2条](#event-2)

<a id="hs064-p005"></a>

**[《汉书·严朱吾丘主父徐严终王贾传》P005](../../拆分史书/汉书/卷064.md#p005)** · [仓内TXT L8345—L8345](../../拆分史书/汉书/卷064.md#part-1-L8345)

> 臣聞越非有城郭邑里也，處谿谷之閒，篁竹之中，習於水鬬，便於用舟，地深昧而多水險，中國之人不知其埶阻而入其地，雖百不當其一。得其地，不可郡縣也；攻之，不可暴取也。以地圖察其山川要塞，相去不過寸數，而間獨數百千里，阻險林叢弗能盡著。視之若易，行之甚難。天下賴宗廟之靈，方內大寧，戴白之老不見兵革，民得夫婦相守，父子相保，陛下之德也。越人名爲藩臣，貢酎之奉，不輸大內，一卒之用不給上事。自相攻擊而陛下發兵救之，是反以中國而勞蠻夷也。且越人愚戇輕薄，負約反覆，其不用天子之法度，非一日之積也。壹不奉詔，舉兵誅之，臣恐後兵革無時得息也。

**[《汉书·严朱吾丘主父徐严终王贾传》P006](../../拆分史书/汉书/卷064.md#p006)** · [仓内TXT L8346—L8346](../../拆分史书/汉书/卷064.md#part-1-L8346)

> 間者，數年歲比不登，民待賣爵贅子以接衣食，。賴陛下德澤振救之，得毋轉死溝壑。四年不登，五年復蝗，民生未復。今發兵行數千里，資衣糧，入越地，輿轎而隃領，拕舟而入水，行數百千里，夾以深林叢竹，水道上下擊石，林中多蝮蛇猛獸，。夏月暑時，歐泄霍亂之病相隨屬也，曾未施兵接刃，死傷者必衆矣。前時南海王反，陛下先臣使將軍間忌將兵擊之，作簡忌，此本作間，轉寫字誤省耳。以其軍降，處之上淦。後復反，會天暑多雨，樓船卒水居擊櫂，未戰而疾死者過半。親老涕泣，孤子謕號，破家散業，迎尸千里之外，裹骸骨而歸。悲哀之氣數年不息，長老至今以爲記。曾未入其地而禍已至此矣。

### 5. 越地可守而难深入

[返回正文第5条](#event-5)

<a id="hs064-p008"></a>

**[《汉书·严朱吾丘主父徐严终王贾传》P008](../../拆分史书/汉书/卷064.md#p008)** · [仓内TXT L8348—L8348](../../拆分史书/汉书/卷064.md#part-1-L8348)

> 不習南方地形者，多以越爲人衆兵彊，能難邊城。淮南全國之時，多爲邊吏，臣竊聞之，與中國異。限以高山，人迹所絕，車道不通，天地所以隔外內也。其入中國必下領水，之山峭峻，漂石破舟，不可以大船載食糧下也。越人欲爲變，必先田餘干界中，積食糧，迺入伐材治船。邊城守候誠謹，越人有入伐材者，輒收捕，焚其積聚，雖百越，柰邊城何！且越人緜力薄材，不能陸戰，又無車騎弓弩之用，然而不可入者，以保地險，而中國之人不能其水土也。臣聞越甲卒不下數十萬，所以入之，五倍迺足，輓車奉饟者，不在其中。南方暑溼，近夏癉熱，暴露水居，蝮蛇蠚生，疾癘多作，兵未血刃而病死者什二三，雖舉越國而虜之，不足以償所亡。

### 7. 秦攻越与盘桓之祸

[返回正文第7条](#event-7)

<a id="hs064-p010"></a>

**[《汉书·严朱吾丘主父徐严终王贾传》P010](../../拆分史书/汉书/卷064.md#p010)** · [仓内TXT L8350—L8350](../../拆分史书/汉书/卷064.md#part-1-L8350)

> 臣聞長老言，秦之時甞使尉屠睢擊越，又使監祿鑿渠通道。越人逃入深山林叢，不可得攻。留軍屯守空地，曠日引乆，士卒勞倦，越出擊之。秦兵大破，迺發適戍以備之。當此之時，外內騷動，百姓靡敝，行者不還，往者莫反，皆不聊生，亡逃相從，羣爲盜賊，於是山東之難始興。此老子所謂「師之所處，荊棘生之」者也。兵者凶事，一方有急，四面皆從。臣恐變故之生，姦邪之作，由此始也。《周易》曰：「高宗伐鬼方，三年而克之。」鬼方，小蠻夷；高宗，殷之盛天子也。以盛天子伐小蠻夷，三年而後克，言用兵之不可不重也。

### 8. 劝以德保内而少兴兵

[返回正文第8条](#event-8)

<a id="hs064-p011"></a>

**[《汉书·严朱吾丘主父徐严终王贾传》P011](../../拆分史书/汉书/卷064.md#p011)** · [仓内TXT L8351—L8351](../../拆分史书/汉书/卷064.md#part-1-L8351)

### 9. 严助向淮南陈说停兵与外交

[返回正文第9条](#event-9)

<a id="hs064-p014"></a>

**[《汉书·严朱吾丘主父徐严终王贾传》P014](../../拆分史书/汉书/卷064.md#p014)** · [仓内TXT L8354—L8354](../../拆分史书/汉书/卷064.md#part-1-L8354)

> 助諭意曰：「今者大王以發屯臨越事上書，陛下故遣臣助告王其事。王居遠，事薄遽，不與王同其計。朝有闕政，遺王之憂，陛下甚恨之。夫兵固凶器，明主之所重出也，然自五帝三王禁暴止亂，非兵，未之聞也。漢爲天下宗，操殺生之柄，以制海內之命，危者望安，亂者卬治。今越閩王狼戾不仁，殺其骨肉，離其親戚，所爲甚多不義，又數舉兵侵陵百越，并兼鄰國，以爲暴彊，陰計竒策，入燔尋陽樓船，欲招會稽之地，以踐句踐之迹。今者，邊又言閩王率兩國擊南越。陛下爲萬民安危乆遠之計，使人諭告之曰：『天下安寧，各繼世撫民，禁毋敢相并。』有司疑其以虎狼之心，貪據百越之利，或於逆順，不奉明詔，則會稽、豫章必有長患。且天子誅而不伐，焉有勞百姓苦士卒乎？故遣兩將屯於境上，震威武，揚聲鄉。屯曾未會，天誘其衷，閩王隕命，輒遣使者罷屯，毋後農時。南越王甚嘉被惠澤，蒙休德，願革心易行，身從使者入謝。有狗馬之病，不能勝服，故遣太子嬰齊入侍；病有瘳，願伏北闕，望大廷，以報盛德。閩王以八月舉兵於冶南，士卒罷倦，三王之衆相與攻之，因其弱弟餘善以成其謀。至今國空虛，遣使者上符節，請所立，不敢自立，以待天子之明詔。此一舉，不挫一兵之鋒，不用一卒之死，而閩王伏辜，南越被澤，威震暴王，義存危國，此則陛下深計遠慮之所出也。事效見前，故使臣助來諭王意。」

> 故兵法曰：「興師十萬，日費千金。」秦常積衆數十萬人，雖有覆軍殺將，係虜單于，適足以結怨深讎，不足以償天下之費。夫匈奴行盜侵𢿛，所以爲業，天性固然。上自虞夏殷周，固不程督，禽獸畜之，不比爲人。夫不上觀虞夏殷周之統，而下循近世之失，此臣之所以大恐，百姓所疾苦也。且夫兵乆則變生，事苦則慮易。使邊境之民靡敝愁苦，將吏相疑而外市，故尉佗、章邯得成其私，而秦政不行，權分二子，此得失之效也。故周書曰：「安危在出令，存亡在所用。」願陛下孰計之而加察焉。

**[《汉书·严朱吾丘主父徐严终王贾传》P068](../../拆分史书/汉书/卷064.md#p068)** · [仓内TXT L8408—L8408](../../拆分史书/汉书/卷064.md#part-1-L8408)

### 72. 以古德治反对强拓

**[《汉书·严朱吾丘主父徐严终王贾传》P087](../../拆分史书/汉书/卷064.md#p087)** · [仓内TXT L8427—L8427](../../拆分史书/汉书/卷064.md#part-1-L8427)

> 臣聞堯舜，聖之盛也，禹入聖域而不優，故孔子稱堯曰「大哉」，韶曰「盡善」，禹曰「無間」。以三聖之德，地方不過數千里，被流沙，東漸于海，朔南暨聲教，迄于四海，欲與聲教則治之，不欲與者不彊治也。故君臣歌德，含氣之物各德其宜。武丁、成王，殷、周之大仁也，然地東不過江、黃，西不過氐、羌，南不過蠻荊，北不過朔方。是以頌聲並作，視聽之類咸樂其生，越裳氏重九譯而獻，此非兵革之所能致。及其衰也，南征不還，齊桓捄其難，孔子定其文。以至乎秦，興兵遠攻，貪外虛內，務欲廣地，不慮其害。然地南不過閩越，北不過太原，而天下潰畔，禍卒在於二世之末，長城之歌至今未絕。

### 73. 文帝节俭与武帝远征对比

[返回正文第73条](#event-73)

<a id="hs064-p088"></a>

**[《汉书·严朱吾丘主父徐严终王贾传》P088](../../拆分史书/汉书/卷064.md#p088)** · [仓内TXT L8428—L8428](../../拆分史书/汉书/卷064.md#part-1-L8428)

> 賴聖漢初興，為百姓請命，平定天下。至孝文皇帝，閔中國未安，偃武行文，則斷獄數百，民賦四十，丁男三年而一事。時有獻千里馬者，詔曰：「鸞旗在前，屬車在後，吉行日五十里，師行二十里，朕乘千里之馬，獨先安之？」於是還馬，與道里費，而下詔曰：「朕不受獻也，其令四方毋求來獻。」當此之時，逸游之樂絕，奇麗之賂塞，鄭衛之倡微矣。夫後官盛色則賢者隱處，佞人用事則諍臣杜口，而文帝不行，故諡為孝文，廟稱太宗。至孝武皇帝元狩六年，太倉之粟紅腐而不可食，都內之錢貫朽而不可挍。乃探平城之事，錄冒頓以來數為邊害，籍兵厲馬，因富民以攘服之。西連諸國至于安息，東過碣石以玄菟、樂浪為郡，比卻匈奴萬里，更起營塞，制南海以為八郡，則天下斷獄萬數，民賦數百，造鹽鐵酒榷之利以佐用度，猶不能足。當此之時，寇賊並起，軍旅數發，父戰死於前，子鬥傷於後，女子乘亭鄣，孤兒號於道，老母寡婦飲泣巷哭，遙設虛祭，想魂乎萬里之外。淮南王盜寫虎符，陰聘名士，關東公孫勇等詐為使者，是皆廓地泰大，征伐不休之故也。

> 捐之數召見，言多納用。時中書令石顯用事，捐之數短顯，以故不得官，後稀復見。而長安令楊興新以材能得幸，與捐之相善。捐之欲得召見，謂興曰：「京兆尹缺，使我得見，言君蘭，京兆尹可立得。」興曰：「縣官嘗言興瘉薛大夫，我易助也。君房下筆，言語妙天下，使君房為尚書令，勝五鹿充宗遠甚。」捐之曰：「令我得代充宗，君蘭為京兆，京兆郡國首，尚書百官本，天下真大治，士則不隔矣。捐之前言平恩侯可為將軍，期思侯並可為諸曹，皆如言；又薦謁者滿宣，立為冀州刺史；言中謁者不宜受事，宦者不宜入宗廟，立止。相薦之信，不當如是乎！」興曰：「我復見，言君房也。」捐之復短石顯。興曰：「顯鼎貴，上信用之。今欲進，弟從我計，且與合意，即得入矣。」

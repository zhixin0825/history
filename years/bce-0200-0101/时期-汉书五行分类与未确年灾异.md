# 汉书五行分类与未确年灾异

[本世纪目录](README.md) · [全部世纪](../README.md)

此处连读各志的制度沿革、学术分类与未详年次的史事；整段原文和已系年节录均可由卷内读本查阅。


<a id="event-1"></a>

1. **《洪范》的五行与汉代灾异之学。** 引《易》的天象、河图洛书，接《洪范》九畴和水火木金土的特性。汉代从董仲舒治《公羊》讲到刘向、刘歆等人，学派说法并不一致，正文保留各家所署。 [[1]](#note-1)


<a id="event-2"></a>

2. **木曲直与成公时雨木冰。** 《传》将田猎、饮食、出入失节与夺农时归入木失曲直；解释木为东方和威仪。成公时枝木结冰，刘歆用上下阴阳阻隔解释，形成志书所举例证。 [[2]](#note-2)


<a id="event-3"></a>

3. **火炎上与法统。** 废法、斥功臣、杀太子及妾代妻被列为火失炎上的政治解释。说明火属南方、以光明比君主南面明治。 [[3]](#note-3)


<a id="event-4"></a>

4. **春秋诸庙宫室和齐周火灾。** 御廪、齐国、西宫、成周宣榭及鲁新宫的火灾分别被董仲舒、刘向和三传解释。宣榭又有藏乐器与讲武建筑两解，《公羊》区分人火与天火。 [[4]](#note-4)


<a id="event-5"></a>

5. **宋、郑、陈、鲁等国火灾。** 宋逐华弱、伯姬遇火，郑铸刑书，陈国火与四国同灾各有政治阐释；鲁雉门、两观和庙社灾则被联系建筑、礼制僭越及前代之戒。 [[5]](#note-5)


<a id="event-6"></a>

6. **西汉早中期宫室、宗庙及冶铸异象。** 由赵丛台、未央凌室与织室，写到东阙、高园及辽东高庙；太初柏梁台和征和涿郡铁官又各有背景。淮南等案是志书所举后验，火灾先后逐条看年款。 [[6]](#note-6)


<a id="event-7"></a>

7. **昭帝至平帝的庙殿门阙失火。** 燕南门、孝文庙、中山太上皇庙、杜陵、皇考庙及各宫门失火并列；数条补充本纪所无确日或存在干支差。《志》后附废后、外戚与陵庙礼的解释。 [[7]](#note-7)


<a id="event-8"></a>

8. **土稼穑与鲁庄公大水。** 土被比作宫室、夫妇和宗亲的内政。庄公时无麦禾可由水灾读起，诸儒又把它依五行解释成内乱妨害农业。 [[8]](#note-8)


<a id="event-9"></a>

9. **金从革、石言与石鸣。** 把穷兵、劳民、侵边归于金不从革。晋石言的故事记师旷劝政，天水山石鸣后附苏令起事；后事有“逾年”叙法，不和石鸣混为同年。 [[9]](#note-9)


<a id="event-10"></a>

10. **水润下与春秋洪灾。** 志以废祀、逆时解释失润下，依鲁桓、庄、宣、成、襄诸公条举鲁、宋等地水灾。董仲舒、刘向连到弑君、夫人、用兵等多套解释。 [[10]](#note-10)


<a id="event-11"></a>

11. **高后至成帝的洪灾。** 高后各年汉中、南郡和伊洛汝水灾独列；文帝后元三年连雨、蓝田与燕地受灾。永光五年多郡洪水和建始三年三辅、十九郡国雨灾，志另联系宗庙及郊祀调整。 [[11]](#note-11)


<a id="event-12"></a>

12. **五事、貌不恭与灾异分类。** 貌、言、视、听、思心为五事。志把失貌配慢侮狂恣及久雨，说明妖、孽、祸、痾、眚祥之别，并述夏侯始昌至夏侯胜等传授《五行传》的线索。 [[12]](#note-12)


<a id="event-13"></a>

13. **礼仪失态及楚、晋征事。** 从晋厉公视远步高和楚屈瑕举止论败亡，又记晋惠公受命、郤锜乞师、成肃公受社和苦成叔宴饮，诸人以失敬预论祸福。 [[13]](#note-13)


<a id="event-14"></a>

14. **聘会时的容貌、礼位及应对。** 孙文子登阶、蔡景侯受享、公子裯居丧和楚令尹仪态等事并见；单子、蔡太子、魏舒乃至邾鲁执玉均以礼者身份、神态与国政议论。 [[14]](#note-14)


<a id="event-15"></a>

15. **恒雨、雨雪与雷电。** 刘歆专说大雨，刘向连大水；隐公的雷雨和骤雪两家对节令位置解释不同。汉则分别记始元元年久雨、建始三年和四年久雨。 [[15]](#note-15)


<a id="event-16"></a>

16. **服饰象征与冠式。** 申生偏衣、金玦和子臧鹬冠是《左传》事例。昌邑仄注冠、成帝微行的随从服式属较晚宫廷，时代范围可辨，确日不可补。 [[16]](#note-16)


<a id="event-17"></a>

17. **鸡与鼠的故事。** 周景王雄鸡断尾、黄龙元年雌鸡变化以及鼷鼠啮郊牛按类附会。燕宫黄鼠在本志后再见，按同一案辨；建始长安冢树聚鼠为另事。 [[17]](#note-17)


<a id="event-18"></a>

18. **屋、门损坏。** 鲁大室屋坏、吴城门倒和大船覆均被归入金沴木，霍禹与董贤宅门自坏仅给时段，志以事前警戒评论其结局。 [[18]](#note-18)


<a id="event-19"></a>

19. **言不从与僭越。** 志引《传》解释言而失理所致久旱，并以《史记》周单襄公评晋齐大夫、晋穆侯给仇与成师命名论出言和名分。 [[19]](#note-19)


<a id="event-20"></a>

20. **春秋辞令与礼器。** 郑曼满求卿，齐、宋、晋使相应对，赵文子议国政、楚公子围仪礼、周王向籍谈问典及孔丘卒鲁公致诔，都是由言辞和礼法观察政治的案例。 [[20]](#note-20)


<a id="event-21"></a>

21. **恒阳、大旱与大雩。** 刘向以大旱比恒阳，并区分因旱而常行或特书的大雩。僖、宣、襄、昭、定诸公的祈雨有动兵、强臣、失礼等各家解释，昭二十五年一月内两次属重旱。 [[21]](#note-21)


<a id="event-22"></a>

22. **鲁春秋不雨。** 庄公筑台年和僖、文各年无雨记月不同，多给雨期的起点、终点或恢复。诸家用劳役、盟会、战争讨论失政。 [[22]](#note-22)


<a id="event-23"></a>

23. **汉代旱蝗与征役背景。** 惠帝、文帝、景帝及武帝元光至征和各旱列年；昭帝始元、宣帝本始及神爵、成帝永始仍分别记。志在许多条后缀征战、营造或兵役作为当时政情。 [[23]](#note-23)


<a id="event-24"></a>

24. **春秋与汉代童谣。** 晋伐虢、申生改葬、鲁昭公出奔等用童谣解释后事。元帝和成帝时的长安童谣把民间语言连到宫廷，用原有时段，不能从预言对象推定歌谣之日。 [[24]](#note-24)


<a id="event-25"></a>

25. **麋、熊、犬豕等异事。** 载鲁多麋、昌邑闻熊、宋逐狂狗、吕后见苍狗及齐、赵、长安的其他动物异状。叙述含传闻和象征判断，和本年政治事故分开。 [[25]](#note-25)


<a id="event-26"></a>

26. **宝圭、石、白毛与门牡。** 周王子朝沉圭与秦客遇神平行，昭帝泰山大石传说另有石旁文字。天空白毛、九鼎震、长安及函谷门牡亡皆属不同年和类型。 [[26]](#note-26)


<a id="event-27"></a>

27. **视不明与暖冬。** 解释待事不察为失视，并以恒暖、疾忧附配；桓、成、襄无冰，三传有周历季节及阴阳、礼法理解。 [[27]](#note-27)


<a id="event-28"></a>

28. **汉无冰、霜不杀草与商周祥异。** 武帝元狩六年、昭帝始元二年各有冬不结冰记载。与鲁霜不杀草、商太戊桑谷共生、高宗雉雊和鲁李梅结实的故事比较。 [[28]](#note-28)


<a id="event-29"></a>

29. **花果失时、树木与雨草。** 惠帝时桃李开花枣结实，上林树另泛称昭帝时。元帝王氏墓树、刺史毁社树、哀帝零陵树及元平不同年间的雨草各记其地或特征。 [[29]](#note-29)


<a id="event-30"></a>

30. **羽虫之孽与鸟类传说。** 鲁鸲鹆来巢、楚群乌争斗、燕宫乌鹊斗、昌邑王殿前水鸟、泰山鸟巢焚烧、大射礼飞雉与天水燕雀，志以阴阳和殿廷政治解其所见。 [[30]](#note-30)


<a id="event-31"></a>

31. **井中似羊、生儿、雨赤。** 季桓子井中器物和宋生女故事作先秦案例。惠帝宜阳雨血、哀帝湖陵雨血仅是原书记载的颜色或名称。 [[31]](#note-31)


<a id="event-32"></a>

32. **听不聪与反常降雪。** 志以偏听、下情闭塞解释失谋，配恒寒。桓、僖、昭的大雪分记，并以周月与今月的换算、鲁国夫人关系等说辨其反常。 [[32]](#note-32)


<a id="event-33"></a>

33. **西汉雨雪、结冰与冻害。** 录文帝六月大雪、景帝中六年三月雪及武帝元狩元年、元鼎二三年之雪冰；元帝及成帝条多记厚度、死鸟和冻馁，并附史家归因。 [[33]](#note-33)


<a id="event-34"></a>

34. **霜杀草木、大雹。** 鲁定公霜杀菽、元光霜、永光双记录，与鲁、汉雹灾分列。地节山阳济阴冰雹伤人，其后叙霍案不宜反用来给冰雹定月。 [[34]](#note-34)


<a id="event-35"></a>

35. **鼓妖、殿异声与无云雷。** 晋文公将殡故事在前，哀帝时朱博、赵玄受策的钟声由李寻、扬雄解释为鼓妖，另录秦二世无云雷。受策与罢相、获罪依据各自原证。 [[35]](#note-35)


<a id="event-36"></a>

36. **鱼与蛙类异象。** 秦河鱼上行，武帝蛙蟆群斗，成帝信都雨鱼及北海见鱼是不同事件；志以鱼和阴或国中动乱相连。 [[36]](#note-36)


<a id="event-37"></a>

37. **春秋螽蜚与民赋。** 从鲁桓、庄至哀诸公的虫害，多联系军旅、苛敛、田赋和初税亩；解释虫名、是否食谷及季节与后世政治判断分读。 [[37]](#note-37)


<a id="event-38"></a>

38. **西汉蝗、螟。** 逐条纪景帝、武帝和元始二年虫灾，有飞至敦煌及遍天下等范围。征讨、开郡、王莽秉政是记载所附时代背景。 [[38]](#note-38)


<a id="event-39"></a>

39. **猪异、二水相斗与赤渭。** 齐襄公狩猎见豕和燕宫豕毁灶是故事层。谷洛两水涨冲、秦武王和昭王时渭水变赤各有年，刘向以火水相害解释。 [[39]](#note-39)


<a id="event-40"></a>

40. **思心不睿、恒风与退飞。** 将不宽不明的思虑比恒风，举六鹢后退飞过宋解释风。当时占说与后记政变分别阅读。 [[40]](#note-40)


<a id="event-41"></a>

41. **暴风雨和雷击。** 文帝时寿春、吴地、彭城灾及昭帝时蓟风拔树各自系年。鲁夷伯庙遭雷与鄢陵战的月晦讨论，着重“震”和“晦”的读法。 [[41]](#note-41)


<a id="event-42"></a>

42. **螟害与祭牛异事。** 鲁隐庄和文帝后六年螟害连民利或征役；宣公卜郊牛、秦孝文王条及梁孝王田猎所献牛分属不同时代。秦孝文王五年的称年本身有问题。 [[42]](#note-42)


<a id="event-43"></a>

43. **钟、宴及气象感应。** 周景王铸钟、宋元公宴饮的声音或言行由史家作戒；燕宫黄鼠故事重出，另载成帝时赤黄云风。后接以《易》论纳贤与闻善的解释。 [[43]](#note-43)


<a id="event-44"></a>

44. **先秦地震与岐山崩。** 周幽王时三川地震、川竭岐山崩，以及鲁文、襄、昭、哀各年地震被不同作者附会。周三川与崩岐山是同一灾异叙事的相联现象。 [[44]](#note-44)


<a id="event-45"></a>

45. **汉地震、沙麓梁山和山壅水。** 陇西、征和地震与先秦沙麓、梁山崩按例连排。武都、齐楚山水和成帝犍为、岷山多处崩裂另有明白年、月与损失记录。 [[45]](#note-45)


<a id="event-46"></a>

46. **君不建、恒阴与昌邑王。** 皇极释作君得其中，由射礼谈阳气和上下。昌邑新君时久阴，夏侯胜据《洪范》进谏；天气、谏言与受命废立不是同一种证据。 [[46]](#note-46)


<a id="event-47"></a>

47. **蜮、肃慎楛矢与龙的旧闻。** 由鲁庄蜮谈南越传说，孔子释陈庭受箭的隼牵出周初朝贡。《史记》夏廷龙与《左传》郑龙斗各属其原叙故事。 [[47]](#note-47)


<a id="event-48"></a>

48. **井龙、蛇斗与白马。** 惠二年兰陵井龙、郑门蛇斗、文公时蛇自泉宫出和武帝太始赵蛇故事分别。宋国白马被染尾鬣是宠臣争物的政治案例。 [[48]](#note-48)


<a id="event-49"></a>

49. **马异、巨人和人物性别变化传闻。** 秦马异、吴马生角、汉大厩马异各按文献的形态与日期；“绥和三年”无该年号。长狄、临洮巨人与魏国人变化皆应按志书所述例证阅读。 [[49]](#note-49)


<a id="event-50"></a>

50. **晚汉人事奇闻、惊走与传筹。** 从豫章、方与、广牧的异常故事和长安双头婴儿写到九岁小女、王褒闯禁与西王母筹。口述和祭祀活动与事后政治解释分开。 [[50]](#note-50)


<a id="event-51"></a>

51. **春秋日食：隐、桓、庄、僖。** 各条从《春秋》年月记法出发，董仲舒、刘向、刘歆或三传用宿度、朔晦、昼夜与列国强弱解释；同一公内继承年号只在连贯序列中取用。 [[51]](#note-51)


<a id="event-52"></a>

52. **春秋日食：文、宣、成。** 日食有干支和朔日明确者，也有只载月与日的条。解释常涉及楚、晋、周与大夫执权，附叙之战仍回其各自纪年。 [[52]](#note-52)


<a id="event-53"></a>

53. **春秋日食：襄公多次记录。** 襄公条常有连续两月日食，按月、干支及朔晦逐条分辨。分野与各年所配政事随诸家而异。 [[53]](#note-53)


<a id="event-54"></a>

54. **士文伯论日食与三务。** 昭公七年日食，士文伯答晋侯用岁、时、日、月、星、辰合察，拒绝把一度应验当通则。最后归到择人、因民、从时和慎政。 [[54]](#note-54)


<a id="event-55"></a>

55. **日食：昭、定、哀及春秋总数。** 晚春秋继续以不同分野和时日讨论日食，末统计三十六次。谷梁、公羊、左氏对朔晦及二日的数法不一致。 [[55]](#note-55)


<a id="event-56"></a>

56. **汉初日食：高帝、惠帝、高后。** 汉三年同见十、十一月条，另录九年既食与惠七年两记；高后二、七年各异。志的宿度和政治占语与实际可见性考证分别看。 [[56]](#note-56)


<a id="event-57"></a>

57. **汉代日食：武帝各年号。** 由建元、元光接至元朔、元狩、元鼎、元封、太始和征和。各原条照录星宿度数、亏缺形状、朔晦及可观测时段。 [[57]](#note-57)


<a id="event-58"></a>

58. **汉代日食：昭帝、宣帝。** 始元和元凤日食之后有宣帝地节及五凤条。五凤四年辛丑，《宣帝纪》作晦，此志作朔，月相异文并读。 [[58]](#note-58)


<a id="event-59"></a>

59. **汉代日食：元帝至成帝阳朔。** 永光、建昭接到成帝建始、河平和阳朔。建始三年条还记当夜地震，谷永、刘向的进说为政治解释。 [[59]](#note-59)


<a id="event-60"></a>

60. **汉代日食：永始至平帝与总计。** 永始、元延至哀平各年日食逐条保留。志末总计说十二世二百一十二年、五十三食；仓内正文实列五十四条。李勇的研究也按五十四条统计，区别可见、无食和日出前等情况。 [[60]](#note-60)


<a id="event-61"></a>

61. **重月、日色及历占。** 成帝重月、元帝失光与河平日赤各有先后。刘向、刘歆及京房分别用朓、仄慝、君臣缓急和日色占论说明。 [[61]](#note-61)


<a id="event-62"></a>

62. **鲁庄公与成帝两次“星陨如雨”。** 董仲舒、刘向及刘歆对“雨”是比喻还是同时降雨有不同说法。谷永把永始二年星陨与古例、外戚和奢侈相联系；元延元年另有星陨。 [[62]](#note-62)


<a id="event-63"></a>

63. **春秋及西汉的彗孛长星。** 文公北斗、昭公大辰、哀公东方的记录接到汉高帝以来。各项有不同星区与月份；兵灾、国政、后宫故事属后附解释。 [[63]](#note-63)


<a id="event-64"></a>

64. **陨石与退鹢统计。** 宋陨石五与六鹢退飞并见，诸说按风、阴阳和人事解释。由惠至平的陨石分别列地点、数目和声音，志末合计十一记。 [[64]](#note-64)

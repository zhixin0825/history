# 汉书公孙弘卜式兒宽的任官议论

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **公孙弘早年由狱吏学经。** 公孙弘是菑川国薛人。年轻时曾当狱吏，获罪丢官，贫困时在海边养猪，四十多岁才攻读《春秋》及杂说。 [[1]](#note-1)


<a id="event-2"></a>

2. **武帝初征和出使匈奴。** 武帝初年求贤良文学，六十岁的公孙弘应征为博士，出使匈奴，回报未合皇帝意旨。 [[2]](#note-2)


<a id="event-3"></a>

3. **首次去官归乡。** 武帝发怒，认为公孙弘不能胜任。公孙弘遂移文称病，免职还乡。 [[3]](#note-3)


<a id="event-4"></a>

4. **元光五年再举。** 菑川国再荐公孙弘。他以旧任未被认可为由请改荐，国人坚持，他才到太常应皇帝策问。 [[4]](#note-4)


<a id="event-5"></a>

5. **制策问古治、灾变与治法。** 武帝问古人只以服饰标耻而能使民不犯、使阴阳和及远人归心，今天可以怎样做到。再问天人、吉凶的根源、禹汤水旱及仁义礼智应怎样用于国政。 [[5]](#note-5)


<a id="event-6"></a>

6. **公孙弘答辞。** 以下是公孙弘的应试答文。 [[6]](#note-6)


<a id="event-7"></a>

7. **治民八端与信用。** 他说尧舜身正而以信用待民，末世重刑厚赏仍不止奸。提出量才任官、去空谈和无用器、爱惜民力民时、进有德功之臣、赏罚相称；法、赏罚都须合于礼义。 [[7]](#note-7)


<a id="event-8"></a>

8. **气和与天地感应。** 君上施和德，百姓和合，继而心、气、形、声逐层相通。他用这一观念解释风雨五谷、无早夭及祥瑞远服，将它们当作至和的表现。 [[8]](#note-8)


<a id="event-9"></a>

9. **仁义礼智及治术。** 仁为无私利众，义在明是非，礼在尊卑进退有度，智见于执政能权衡利害、使远近真情上达。这些都用于治理，失其要则君主受蒙蔽而官政失序。 [[9]](#note-9)


<a id="event-10"></a>

10. **答禹水汤旱。** 公孙弘称洪水见于尧，禹受命治水；汤时的旱归为桀暴政的余效。进而主张天德无私，顺之则和、逆之则生害。 [[10]](#note-10)


<a id="event-11"></a>

11. **进疏论周公之治。** 公孙弘讥今吏邪、政弊令疲，引周公治国一年有变、三年成化、五年定。武帝反问他怎比周公；他称不敢比才，认为习性与利益可以改变，而且只一年才变还嫌慢。 [[11]](#note-11)


<a id="event-12"></a>

12. **奉使西南与任左内史。** 巴蜀困于通西南夷，武帝遣公孙弘调查。他回奏此事无用，帝未从。公孙弘善陈论据而少公开顶撞，又熟文法、借儒术释政，得帝信任，在一岁中至左内史。 [[12]](#note-12)


<a id="event-13"></a>

13. **与汲黯请间及当廷争辩。** 公孙弘常让汲黯先陈意见，再补充说明，奏事多获采纳。后来公孙弘入朝反背公卿原议顺从上旨，汲黯面斥其不忠；他把评价归于知不知己，武帝接受。 [[13]](#note-13)


<a id="event-14"></a>

14. **谈议节俭与侍奉继母。** 他谈笑多闻，常说人君应扩大胸襟、臣下要奉行节俭。侍养继母谨孝，继母卒，他守丧三年。 [[14]](#note-14)


<a id="event-15"></a>

15. **任御史及论取舍边郡。** 任左内史数年后迁御史大夫。公孙弘忧西南夷、东方苍海与北边朔方耗损国力；在朱买臣等列朔方十利时不能诘难，遂请罢西南夷、苍海，专力朔方，武帝允诺。 [[15]](#note-15)


<a id="event-16"></a>

16. **汲黯质问三公布被。** 汲黯质疑厚禄三公用布被是邀名。公孙弘承认有饰名之嫌，以管仲僭奢、晏婴节用仍能治齐，说明上下取法不同，并称汲黯敢说实话；武帝反嘉其谦让。 [[16]](#note-16)


<a id="event-17"></a>

17. **开东阁待士与报怨。** 公孙弘自徒步至相位后建客馆，开东阁接士参议，自己只一肉粗米饭，禄多给故旧宾客。传另称他外宽内忌，与主父偃被杀、董仲舒出相胶西都有关。 [[17]](#note-17)


<a id="event-18"></a>

18. **两王案中病请退。** 淮南、衡山案追治方急时公孙弘病重，认为诸侯有反谋是大臣失职，以五种人伦和仁智勇劝自治，求还侯印退休。武帝慰留、准假并赐礼物，数月后他病愈复职。 [[18]](#note-18)


<a id="event-19"></a>

19. **公孙弘卒及相府后事。** 传合计他担任御史大夫和丞相六年，年八十卒于相位。其后诸相不用其客馆，后改作厩库、车库和官奴婢屋。诸相里只有石庆同样善终于位，其他多因罪被诛。 [[19]](#note-19)


<a id="event-20"></a>

20. **公孙度接侯获罪。** 弘子公孙度继封，为山阳太守十余年，朝廷征钜野令史成，度扣住不遣，因罪服城旦。 [[20]](#note-20)


<a id="event-21"></a>

21. **平帝时赐爵公孙氏后。** 元始中朝廷恢复功臣后裔封赏，诏赞弘以相侯之位仍用布被、吃粗饭、以禄养客，并以关内侯、三百户赐现为嫡继者。本传只书元始中。 [[21]](#note-21)


<a id="event-22"></a>

22. **卜式分传题签。** 本篇转录河南卜式由畜牧到入仕的经过。 [[22]](#note-22)


<a id="event-23"></a>

23. **卜式畜牧自立并助弟。** 卜式以耕牧为生，弟长成便把田宅财物全让给他，自取百余羊入山。十余年发展到千余头并再置田宅，弟先后耗掉产业，他又数次分财救济。 [[23]](#note-23)


<a id="event-24"></a>

24. **献半家财助汉与公孙弘拒议。** 汉与匈奴用兵时，卜式愿出半家财，又拒求官和申冤的猜测，称义者出力、有财者助军。公孙弘认为此举反常、不足作法，武帝没有答复，数年后遣返卜式。 [[24]](#note-24)


<a id="event-25"></a>

25. **浑邪归降后以钱济徙民。** 浑邪等归降后耗费加剧，民众大批徙转、全仰官给。卜式又拿二十万钱给河南太守赈济。武帝认出他，给四百人的外徭复免，他推还；朝廷任他为中郎，赐爵左庶长和田十顷，布告以劝助用。 [[25]](#note-25)


<a id="event-26"></a>

26. **牧羊、治县与相齐。** 武帝以看护上林羊群使卜式就中郎。羊群肥息，卜式以时作息、除害群比治民，由此出任缑氏、成皋令，办漕考最，获任齐王太傅，后转齐相。 [[26]](#note-26)


<a id="event-27"></a>

27. **儿宽分传题签。** 本篇转写治《尚书》、历任左内史和御史大夫的儿宽。 [[27]](#note-27)


<a id="event-28"></a>

28. **儿宽受书与寒中勤学。** 儿宽千乘人，学《尚书》，从欧阳生、孔安国受业。贫而替同门供杂役，又受雇耕作，随身带经读诵。射策后为掌故，进至廷尉文学卒史。 [[28]](#note-28)


<a id="event-29"></a>

29. **为张汤撰奏决疑。** 廷尉属吏先嫌儒生不通实务，遣儿宽去北地检畜。归后他写成此前两遭驳回的疑奏，张汤用为掾，帝当即准奏。张汤后来使其以古义决疑狱，拜御史后又荐用；武帝向儿宽问经，擢中大夫、迁左内史。 [[29]](#note-29)


<a id="event-30"></a>

30. **开六辅渠与宽征得民心。** 儿宽任左内史重劝农、缓刑和择厚吏，奏修六辅渠、定用水规程。收租常借贷宽限，遭逢军需一度考课最下；百姓怕他去任，驾牛车或负担来交租，反使其考最。 [[30]](#note-30)


<a id="event-31"></a>

31. **御史任九年卒。** 褚大起初以为朝廷征他将授御史大夫，闻儿宽任官而笑；廷议封禅才自认不及。儿宽能顺君意而少规谏，被下属轻视，任御史大夫九年死于官。 [[31]](#note-31)


<a id="event-32"></a>

32. **赞武、宣两朝的用人。** 班固以三人出身及武帝广求文武才论际遇，历列经术、治狱、文辞、军略等方面人物，又列宣帝崇经兴选、治民与将相之名臣，以两朝各成其业相比较。 [[32]](#note-32)

### 7. 治民八端与信用

[返回正文第7条](#event-7)

<a id="hs058-p007"></a>

**[《汉书·公孙弘卜式兒宽传》P007](../../sources/摘录/汉书-卷058-公孙弘卜式兒宽传.md#p007)** · [仓内TXT L8125—L8125](../../sources/本地分卷/汉书/汉书-卷058.md#L8125)

> 臣聞上古堯舜之時，不貴爵賞而民勸善，不重刑罰而民不犯，躬率以正而遇民信也；末世貴爵厚賞而民不勸，深刑重罰而姦不止，其上不正，遇民不信也。夫厚賞重刑未足以勸善而禁非，必信而已矣。是故因能任官，則分職治；去無用之言，則事情得；不作無用之器，即賦斂省；不奪民時，不妨民力，則百姓富；有德者進，無德者退，則朝廷尊；有功者上，無功者下，則群臣逡；罰當罪，則姦邪止；賞當賢，則臣下勸：凡此八者，治民之本也。故民者，業之即不爭，理得則不怨；有禮則不暴，愛之則親上，此有天下之急者也。故法不遠義，則民服而不離；和不遠禮，則民親而不暴。故法之所罰，義之所去也；和之所賞，禮之所取也。禮義者，民之所服也，而賞罰順之，則民不犯禁矣。故畫衣冠，異章服，而民不犯者，此道素行也。

### 8. 气和与天地感应

[返回正文第8条](#event-8)

<a id="hs058-p008"></a>

**[《汉书·公孙弘卜式兒宽传》P008](../../sources/摘录/汉书-卷058-公孙弘卜式兒宽传.md#p008)** · [仓内TXT L8126—L8126](../../sources/本地分卷/汉书/汉书-卷058.md#L8126)

### 9. 仁义礼智及治术

[返回正文第9条](#event-9)

<a id="hs058-p009"></a>

**[《汉书·公孙弘卜式兒宽传》P009](../../sources/摘录/汉书-卷058-公孙弘卜式兒宽传.md#p009)** · [仓内TXT L8127—L8127](../../sources/本地分卷/汉书/汉书-卷058.md#L8127)

> 初梁相褚大通五經，爲博士，時寬爲弟子。及御史大夫缺，徵褚大，大自以爲得御史大夫。至洛陽，聞兒寬爲之，褚大笑。及至，與寬議封禪於上前，大不能及，退而服曰：「上誠知人。」寬爲御史大夫，以稱意任職，故乆無有所匡諫於上，官屬易之。居位九歲，以官卒。

### 32. 赞武、宣两朝的用人

**[《汉书·公孙弘卜式兒宽传》P039](../../sources/摘录/汉书-卷058-公孙弘卜式兒宽传.md#p039)** · [仓内TXT L8157—L8157](../../sources/本地分卷/汉书/汉书-卷058.md#L8157)

> 贊曰：公孫弘、卜式、兒寬皆以鴻漸之翼困於燕爵，遠迹羊豕之間，非遇其時，焉能致此位乎？是時，漢興六十餘載，海內艾安，府庫充實，而四夷未賔，制度多闕。上方欲用文武，求之如弗及，始以蒲輪迎枚生，見主父而歎息。群士慕嚮，異人並出。卜式拔於芻牧，弘羊擢於賈豎，衞青奮於奴僕，日磾出於降虜，斯亦曩時版築飯牛之明已。漢之得人，於茲爲盛，儒雅則公孫弘、董仲舒、兒寬，篤行則石建、石慶，質直則汲黯、卜式，推賢則韓安國、鄭當時，定令則趙禹、張湯，文章則司馬遷、相如，滑稽則東方朔、枚臯，應對則嚴助、朱買臣，歷數則唐都、洛下閎，協律則李延年，運籌則桑弘羊，奉使則張騫、蘇武，將率則衞青、霍去病，受遺則霍光、金日磾，其餘不可勝紀。是以興造功業，制度遺文，後世莫及。孝宣承統，纂修洪業，亦講論六蓺，招選茂異，而蕭望之、梁丘賀、夏侯勝、韋玄成、嚴彭祖、尹更始以儒術進，劉向、王裦以文章顯，將相則張安世、趙充國、魏相、丙吉、于定國、杜延年，治民則黃霸、王成、龔遂、鄭弘、召信臣、韓延壽、尹翁歸、趙廣漢、嚴延年、張敞之屬，皆有功迹見述於世。參其名臣，亦其次也。

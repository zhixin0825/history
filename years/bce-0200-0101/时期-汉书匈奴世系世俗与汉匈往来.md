此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **匈奴的传说世系和游牧生活。** 作者以淳维为祖，将山戎、獫允、薰粥连在北方族群叙事中；逐水草畜牧、少习骑射、以口头约束为政。尊壮健、收继婚等均为汉代史家的习俗记录，传说世系不可当作确证。 [[1]](#note-1)


<a id="event-2"></a>

2. **周人与诸戎的早期关系。** 公刘、古公亶父的迁居，西伯伐畎夷、武王逐戎，铺叙周与戎的边界。《诗》所述獫狁之患与宣王命将、修朔方，分别用来表现王室衰落和中兴。 [[2]](#note-2)


<a id="event-3"></a>

3. **幽王之死与春秋戎狄事。** 申侯、畎戎杀幽王，平王东迁、秦襄公列为诸侯。此后叙山戎攻齐燕、齐桓公救燕，以及周襄王为王子带和翟众逐出，晋文公诛带迎王；传中的间年数字须对照各年原典。 [[3]](#note-3)


<a id="event-4"></a>

4. **秦晋扩张与戎胡分布。** 晋文公驱诸狄至西河、圜洛，秦穆公用由余服西戎。传按陇西、泾漆北、晋燕北列分散各部，各有君长，尚未统一。 [[4]](#note-4)


<a id="event-5"></a>

5. **战国诸边与秦蒙恬北逐。** 魏绛和戎后叙赵并代、韩赵魏灭智氏和魏地归秦，秦分阶段取义渠，赵胡服骑射、燕秦开破东胡，各国建塞置郡；李牧守赵北及秦收河南、通直道、渡河筑塞均有不同年代。秦所置县数与本纪有异。 [[5]](#note-5)


<a id="event-6"></a>

6. **头曼退北与秦末归旧塞。** 头曼受蒙恬压迫北徙。蒙恬死后秦民撤离边地，匈奴逐渐复越黄河到故塞；句中十余年是叙事间隔。 [[6]](#note-6)


<a id="event-7"></a>

7. **冒顿从月氏逃归和取位。** 头曼欲改立幼子，把冒顿送月氏为质而加以攻伐，冒顿夺马归、掌万人。传用鸣镝试部众的残酷故事解释冒顿杀头曼、自立。 [[7]](#note-7)


<a id="event-8"></a>

8. **冒顿击东胡并逐月氏。** 冒顿容让索马、索阏氏，到东胡求边界无人地才拒绝出兵。灭东胡后西逐月氏、南取河南故地，并在汉楚相争之际攻燕代。 [[8]](#note-8)


<a id="event-9"></a>

9. **世系可考从冒顿始。** 作者承认自淳维至头曼无法排定世次，冒顿扩张以后，部众、官号和承继才较可叙。 [[9]](#note-9)


<a id="event-10"></a>

10. **单于称号与左右官属。** 称单于为攣鞮氏，解释撑犁、孤涂、屠耆，列左右官号、世袭贵族、二十四长和更下属官。单于庭与左右部各有活动地域。 [[10]](#note-10)


<a id="event-11"></a>

11. **岁时会祭、刑法和军中赏罚。** 正月小会、五月祭龙城、秋课人畜，连写刑罚、日月祭、葬礼及战斗赏取。作者从逐利与保存战力解释部众聚散，属于史家的观察。 [[11]](#note-11)


<a id="event-12"></a>

12. **冒顿北服诸部。** 传列渾窳、屈射、丁零、隔昆等北方诸国归服，称冒顿由此得贵人拥戴；末一国名在TXT有疑字。 [[12]](#note-12)


<a id="event-13"></a>

13. **韩王信降与白登之围。** 韩王信降后，匈奴南下；高帝亲征，受冒顿佯败所诱，先到平城被围。传记说阏氏劝解、援军失期，围开一角，汉军脱困，后议和亲。 [[13]](#note-13)


<a id="event-14"></a>

14. **高帝年间侵边、陈豨及和亲。** 韩王信等继续骚扰，陈豨和他谋攻代，樊哙复收边县；刘敬奉宗室女为阏氏、岁输财物。后又有燕王卢绾部众出塞归匈奴。 [[14]](#note-14)


<a id="event-15"></a>

15. **中行说戒依赖汉物。** 中行说以旃裘、乳酪适于草原，劝单于维持本部供给，不因喜爱汉物而受制；又教授记录人口畜产的方法。 [[15]](#note-15)


<a id="event-16"></a>

16. **汉与单于书仪异式。** 汉用尺一牍问安，中行说让匈奴改用更长牍、印封，增天地日月的称辞，以显示对等或更高的声势。 [[16]](#note-16)


<a id="event-17"></a>

17. **中行说与汉使辩俗。** 中行说将壮者食美解释为保卫亲族，以收继稳定宗族，批评汉礼和耕战之分；又以秋入农田威胁汉使只须按约确保物资量质。 [[17]](#note-17)


<a id="event-18"></a>

18. **文帝十四年萧关与京畿戒备。** 单于军自朝那、萧关入，杀北地都尉，焚回中宫，侦骑至雍甘泉。文帝命近京及边境诸将分兵，追敌出塞无所获；随后又多次互使议和。 [[18]](#note-18)


<a id="event-19"></a>

19. **文帝末北边驻防和景帝议和。** 军臣入上郡、云中，汉军分屯边镇与细柳等京畿营地，数月后解严。景帝时赵王刘遂与匈奴相通，赵败后匈奴没有配合再入，景帝重修和亲、关市照旧。 [[19]](#note-19)


<a id="event-20"></a>

20. **伊稚斜初年连入汉边。** 新单于立后，匈奴入代杀郡守、再入雁门；下一年复攻代、定襄、上郡。右贤王也因汉取河南筑朔方反复侵边。 [[20]](#note-20)


<a id="event-21"></a>

21. **定襄出师的残复文。** 此行与前段开头几乎相同，止于“得……”，作为TXT复出和残文保留，勿另立军役。 [[21]](#note-21)


<a id="event-22"></a>

22. **漠南无王庭与汉的屯田。** 匈奴远去漠北，汉从朔方以西引渠置田官，以吏卒和屯田逐步控制新的沿河区域。 [[22]](#note-22)


<a id="event-23"></a>

23. **漠北战损、和亲议与任敞被留。** 双方人员和马匹均损失甚大。单于听赵信求和，丞相长史任敞欲改定外臣礼，出使被留，汉匈互扣使者；霍去病死后大军较久未深入。 [[23]](#note-23)


<a id="event-24"></a>

24. **伊稚斜死，乌维继位。** 传明书元鼎三年伊稚斜死，子乌维立；又概叙武帝巡狩、后来集中出兵两越，汉匈一段时间不大举交锋。 [[24]](#note-24)


<a id="event-25"></a>

25. **杨信出使与互扣使节。** 传并列汉经营朝鲜、河西、大夏与乌孙的背景。杨信求以单于太子入质，单于拒改变旧约，互扣使者持续。 [[25]](#note-25)


<a id="event-26"></a>

26. **句黎湖侵塞、欲截宛军而死。** 匈奴破汉亭障、入多郡，任文所部夺回部分俘获。单于闻李广利破大宛拟加阻拦而未动，传随后称其冬病死。 [[26]](#note-26)


<a id="event-27"></a>

27. **先贤掸改任日逐王。** 左大将为左贤王，死后其子先贤掸未承左贤王，改为日逐王，单于以亲子为左贤王。 [[27]](#note-27)


<a id="event-28"></a>

28. **李广利覆军至武帝去世。** 汉损失大军后暂不再度出击，及武帝崩。长期远战也损耗匈奴人口财力，双方重新考虑和亲。 [[28]](#note-28)


<a id="event-29"></a>

29. **壶衍鞮初立与诸王分裂。** 新单于试探和亲。左贤王、右谷蠡王谋携众投汉或借乌孙；盧屠王揭发却受治罪，两王遂不再赴龙城集会。 [[29]](#note-29)


<a id="event-30"></a>

30. **卫律弃议筑城并放还苏武、马宏。** 匈奴入代之后忧汉来攻，卫律先谋引井藏粮，因众议作罢。继提议送回不肯降的苏武、马宏求通好，传用相对年数连叙。 [[30]](#note-30)


<a id="event-31"></a>

31. **瓯脱王被俘与张掖之战。** 匈奴四队侵边，汉获瓯脱王，匈奴闻恐北退，后又屯守受降城外。卫律去世后部内思和；右贤王、犁汙王犯张掖为汉所破，郭忠受封。 [[31]](#note-31)


<a id="event-32"></a>

32. **范明友由击匈奴改取乌桓。** 匈奴入五原，又因乌桓发单于墓欲攻乌桓。赵充国反对干预，霍光任范明友出兵，遇匈奴撤走便转击乌桓。出兵与封赏跨年。 [[32]](#note-32)


<a id="event-33"></a>

33. **乌孙告急与五将出师。** 匈奴索汉公主不遂，入侵夺地。昭帝末议救未定，宣帝时乌孙再请兵。汉本始二年征调，次年五军出塞，常惠护乌孙兵从西入。 [[33]](#note-33)


<a id="event-34"></a>

34. **匈奴经战事和远徙而衰。** 此行接上文残句，记远徙死亡无数，匈奴损耗而怨乌孙。 [[34]](#note-34)


<a id="event-35"></a>

35. **匈奴反击乌孙及诸部乘虚。** 单于攻乌孙归途中逢大雪，死者众；丁令、乌桓、乌孙分从北、东、西攻。传又续叙汉兵乘势及匈奴渐求和。 [[35]](#note-35)


<a id="event-36"></a>

36. **继位初谋和、谋寇与西嗕归降。** 新单于废旧阏氏，旧阏氏一系反对和亲，谋入近塞但为汉识破；汉减外城以休民。匈奴有饥馑，秋又有西嗕部众归汉。 [[36]](#note-36)


<a id="event-37"></a>

37. **车师争夺、丁令侵扰和单于终年。** 汉与西域城郭诸国先得车师、设屯，匈奴屡争。又被丁令侵掠；神爵二年单于集兵近塞，汉据降人情报守九郡，单于病退并遣使请和，未及得报而死。 [[37]](#note-37)


<a id="event-38"></a>

38. **握衍朐鞮初政、胜之献见与日逐王降。** 握衍朐鞮恢复和亲、任都隆奇并肃清旧臣。稽侯狦奔岳家，先贤掸率数万归汉，归德侯是后来所封，薄胥堂继任日逐王。 [[38]](#note-38)


<a id="event-39"></a>

39. **握衍朐鞮失众自杀。** 握衍诛先贤掸两弟、强立奥鞬王致部属离散，又遭乌桓攻东；左地贵人立稽侯狦为呼韩邪，握衍朐鞮不获弟援而自杀。传系神爵四年。 [[39]](#note-39)


<a id="event-40"></a>

40. **薄胥堂称屠耆单于。** 呼韩邪回庭后立兄为左谷蠡王；都隆奇和右贤王拥薄胥堂为屠耆，冬袭呼韩邪取庭，据此再建左右王。 [[40]](#note-40)


<a id="event-41"></a>

41. **左伊秩訾王入汉后拒归。** 曾劝呼韩邪事汉的左伊秩訾王受谗而归汉，获关内侯。竟宁朝见时单于道歉请还，他以不敢事二主辞谢。 [[41]](#note-41)


<a id="event-42"></a>

42. **昭君之子和呼韩邪的诸子。** 昭君为宁胡阏氏，生伊屠智牙师。传写呼韩邪建始二年死，并列两阏氏所生诸子，以明后续传位争议。 [[42]](#note-42)


<a id="event-43"></a>

43. **复株絫立储与昭君再婚。** 新单于遣子入侍，任兄弟分掌左右王位，收继昭君，生云及当于居次两女。 [[43]](#note-43)


<a id="event-44"></a>

44. **搜谐遣子与车牙继立。** 搜谐遣子入侍、以且莫车为左贤王，赴元延二年朝会前在塞外病死，车牙继位。 [[44]](#note-44)


<a id="event-45"></a>

45. **搜谐遣子句的残复文。** 此行为上段开头复出，文字中断，照录而不另立年事。 [[45]](#note-45)


<a id="event-46"></a>

46. **车牙死与乌珠留继立。** 车牙立后遣子入侍，任囊知牙斯为左贤王。绥和元年车牙死，囊知牙斯继为乌珠留。 [[46]](#note-46)


<a id="event-47"></a>

47. **夏侯藩求张掖对面地。** 以省塞上戍边军费为由请单于献地，自称奉诏。两次使行后单于拒绝，称西边诸王仰山材、先父之地不可让，并奏报汉廷。 [[47]](#note-47)


<a id="event-48"></a>

48. **夏侯藩改任与侍子递换。** 汉认为夏侯藩擅称诏，遇赦免死而徙济南。次年侍子死归葬，另遣稽留昆入侍；两事不硬合于最初使行年。 [[48]](#note-48)


<a id="event-49"></a>

49. **平帝朝匈奴贵族与亲属入侍。** 单于先后遣同母兄等入侍；王莽为示新政远人归附，促昭君女须卜居次云入侍太后并厚赏。 [[49]](#note-49)


<a id="event-50"></a>

50. **乌桓皮布税争端。** 汉诏罢乌桓交匈奴皮布税，匈奴拘酋、乌桓反击，后匈奴杀掠且收赎不还人。事为改印前积怨之一，卷无具体年。 [[50]](#note-50)


<a id="event-51"></a>

51. **以护送乌桓为名陈兵塞下。** 传把求地、收税和改印合为关系日坏的原因；单于遣万骑至朔方，以护送乌桓人为名陈兵。 [[51]](#note-51)


<a id="event-52"></a>

52. **咸归而被贬、登代助。** 咸归庭自陈被迫受号，单于降其官。其在新朝的侍子助死，王莽改以登为顺单于。 [[52]](#note-52)


<a id="event-53"></a>

53. **北塞由安定转为疲敝。** 传概括宣帝以来边区生聚，王莽乱其盟约而与匈奴交战，长期屯军与侵扰使边地荒空。 [[53]](#note-53)


<a id="event-54"></a>

54. **王莽扣须卜当夫妇谋另立。** 舆遣使进献后，王莽迫须卜当及云至长安，立当为单于拟用兵支持，未成，当卒。另以女嫁当子奢，王莽败时云、奢皆死。 [[54]](#note-54)


<a id="event-55"></a>

55. **班固总论战、和两策。** 赞语从经书边防观念起，略举刘敬、樊哙、季布、贾谊、晁错等，认为当时各论有偏，欲观长期强弱变化。 [[55]](#note-55)


<a id="event-56"></a>

56. **班固评刘敬与文帝和亲。** 作者认为白登后时宜和亲，继而写和亲未阻侵扰，文帝亲习备战并与冯唐论将作为反证。 [[56]](#note-56)


<a id="event-57"></a>

57. **班固驳董仲舒厚利、质子之议。** 董仲舒主张厚利、盟誓与质子共维和议；作者比对武帝战损、边地得失及互扣使节，认为不能依赖给赐应付长期防御。 [[57]](#note-57)


<a id="event-58"></a>

58. **班固评宣帝借匈奴内争恢复和好。** 赞称宣帝承武帝后军事声势，适逢北方内乱而抚绥呼韩邪，接纳入侍，认为其后边境长期相对安静。 [[58]](#note-58)


<a id="event-59"></a>

59. **班固评王莽启衅和侯应保塞。** 作者视王莽易制与杀侍子为破坏和亲，赞萧望之客礼、侯应留边备，并以咸仍攻汉质疑质子和厚赂的约束。 [[59]](#note-59)


<a id="event-60"></a>

60. **篇末以外服和守边作结。** 赞主张远近用不同的政治礼制，接受主动来贡并备守边境。其对匈奴的贬语是汉代史家立场，保留在原文中。 [[60]](#note-60)

<a id="note-1"></a>

### 1. 匈奴的传说世系和游牧生活

[返回正文第1条](#event-1)

<a id="hs094-p001"></a>

**[《汉书·匈奴传》P001](../../拆分史书/汉书/卷094.md#p001)** · [仓内TXT L9759—L9759](../../拆分史书/汉书/卷094.md#part-1-L9759)

> 匈奴，其先夏后氏之苗裔，曰淳維。唐虞以上有山戎、獫允、薰粥，居于北邊，隨草畜牧而轉移。其畜之所多則馬、牛、羊，其奇畜則橐佗、驢、执、駃騠、騊駼、驒奚。逐水草遷徙，無城郭常居耕田之業，然亦各有分地。無文書，以言語為約束。兒能騎羊，引弓射鳥鼠，少長則射狐菟，肉食。士力能彎弓，盡為甲騎。其俗，寬則隨畜田獵禽獸為生業，急則人習戰攻以侵伐，其天性也。其長兵則弓矢，短兵則刀鋋。利則進，不利則退，不羞遁走。苟利所在，不知禮義。自君王以下咸食畜肉，衣其皮革，被旃裘。壯者食肥美，老者飲食其餘。貴壯健，賤老弱。父死，妻其後母；兄弟死，皆取其妻妻之。其俗有名不諱而無字。

> 單于有太子，名曰冒頓。後有愛閼氏，生少子，頭曼欲廢冒頓而立少子，乃使冒頓質於月氏。冒頓既質，而頭曼急擊月氏。月氏欲殺冒頓，冒頓盜其善馬，騎亡歸。頭曼以為壯，令將萬騎。冒頓乃作鳴鏑，習勒其騎射，令曰：「鳴鏑所射而不悉射者斬。」行獵獸，有不射鳴鏑所射輒斬之。已而，冒頓以鳴鏑自射善馬，左右或莫敢射，冒頓立斬之。居頃之，復以鳴鏑自射其愛妻，左右或頗恐，不敢射，復斬之。頃之，冒頓出獵，以鳴鏑射單于善馬，左右皆射之。於是冒頓知其左右可用，從其父單于頭曼獵，以鳴鏑射頭曼，其左右皆隨鳴鏑而射殺頭曼，盡誅其後母與弟及大臣不聽從者。於是冒頓自立為單于。

> 漢使或言匈奴俗賤老，中行說窮漢使曰：「而漢俗屯戍從軍當發者，其親豈不自奪溫厚肥美齎送飲食行者乎？」漢使曰：「然。」說曰：「匈奴明以攻戰為事，老弱不能鬥，故以其肥美飲食壯健以自衛，如此父子各得相保，何以言匈奴輕老也？」漢使曰：「匈奴父子同穹廬臥。父死，妻其後母；兄弟死，盡妻其妻。無冠帶之節，闕庭之禮。」中行說曰：「匈奴之俗，食畜肉，飲其汁，衣其皮；畜食草飲水，隨時轉移。故其急則人習騎射，寬則人樂無事。約束徑，易行；君臣簡，可久。一國之政猶一體也。父兄死，則妻其妻，惡種姓之失也。故匈奴雖亂，必立宗種。今中國雖陽不取其父兄之妻，親屬益疏則相殺，至到易姓，皆從此類也。且禮義之敝，上下交怨，而室屋之極，生力屈焉。夫力耕桑以求衣食，築城郭以自備，故其民急則不習戰攻，緩則罷於作業。嗟土室之人，顧無喋喋佔佔，冠固何當！」自是之後，漢使欲辯論者，中行說輒曰：「漢使毋多言，顧漢所輸匈奴繒絮米糱，令其量中，必善美而已，何以言為乎？且所給備善則已，不備善而苦惡，則候秋孰，以騎馳蹂乃稼穡也。」日夜教單于候利害處。

### 57. 班固驳董仲舒厚利、质子之议

[返回正文第57条](#event-57)

<a id="hs094-p141"></a>

**[《汉书·匈奴传》P141](../../拆分史书/汉书/卷094.md#p141)** · [仓内TXT L9899—L9899](../../拆分史书/汉书/卷094.md#part-1-L9899)

> 仲舒親見四世之事，猶復欲守舊文，頗增其約。以為「義動君子，利動貪人，如匈奴者，非可以仁義說也。獨可說以厚利，結之於天耳。故與之厚利以沒其意，與盟於天以堅其約，質其愛子以累其心，匈奴雖欲展轉，奈失重利何，奈欺上天何，奈殺愛子何。夫賦斂行賂不足以當三軍之費，城郭之固無以異於貞士之約，而使邊城守境之民父兄緩帶，稚子咽哺，胡馬不窺於長城，而羽檄不行於中國，不亦便於天下乎！」察仲舒之論，考諸行事，乃知其未合於當時，而有闕於後世也。當孝武時，雖征伐克獲，而士馬物故亦略相當；雖開河南之野，建朔方之郡，亦棄造陽之北九百餘里。匈奴人民每來降漢，單于亦輒拘留漢使以相報復，其桀驁尚如斯，安肯以愛子而為質乎？此不合當時之言也。若不置質，空約和親，是襲孝文既往之悔，而長匈奴無已之詐也。夫邊城不選守境武略之臣，脩障隧備塞之具，厲長戟勁弩之械，恃吾所以待邊寇。而務賦斂於民，遠行貨賂，割剝百姓，以奉寇讎。信甘言，守空約，而幾胡馬之不窺，不已過乎！

<a id="note-60"></a>

### 60. 篇末以外服和守边作结

[返回正文第60条](#event-60)

<a id="hs094-p144"></a>

**[《汉书·匈奴传》P144](../../拆分史书/汉书/卷094.md#p144)** · [仓内TXT L9902—L9902](../../拆分史书/汉书/卷094.md#part-1-L9902)

> 夫規事建議，不圖萬世之固，而媮恃一時之事者，未必以經遠也。若乃征伐之功，秦漢行事，嚴尤論之當矣。故先王度土，中立封畿，分九州，列五服，物土貢，制外內，或脩刑政，或詔文德，遠近之勢異也。是以春秋內諸夏而外夷狄。夷狄之人貪而好利，被髮左衽，人面獸心。其與中國殊章服，異習俗，飲食不同，言語不通，辟居北垂寒露之野，逐草隨畜，射獵為生，隔以山谷，雍以沙幕，天地所以絕外內也。是故聖王禽獸畜之，不與約誓，不就攻伐；約之則費賂而見欺，攻之則勞師而詔寇。其地不可耕而食也，其民不可臣而畜也，是以外而不內，疏而不戚，政教不及其人，正朔不加其國；來則懲而御之，去則備而守之。其慕義而貢獻，則接之以禮讓，羈靡不絕，使曲在彼，蓋聖王制御蠻夷之常道也。

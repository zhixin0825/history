# 汉书卫氏霍氏的家世军旅与后人

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **卫青及其母兄姊。** 卫青字仲卿，县吏郑季与平阳侯家僮卫媪所生。异姓同母兄姊甚多；子夫从公主家入宫，青等随母冒姓卫。曹寿是平阳公主丈夫。 [[1]](#note-1)


<a id="event-2"></a>

2. **牧羊受辱与徒囚相面。** 少归父家牧羊，父家儿子把他当奴，不以兄弟待。钳徒说他将封侯，他笑说求免笞骂已足。 [[2]](#note-2)


<a id="event-3"></a>

3. **元朔五年击右贤王与封赏。** 卫青率各将夜抵右贤王营，王逃，汉获裨王、人畜。至塞卫青被拜大将军并益邑，三子封侯。他辞说小儿无功，武帝随后也奖公孙敖、韩说、公孙贺、李蔡等将校。秋有匈奴再入代郡。 [[3]](#note-3)


<a id="event-4"></a>

4. **霍去病小目。** 以下详霍去病早年、出征与封赏。 [[4]](#note-4)


<a id="event-5"></a>

5. **霍去病以票姚校尉受封。** 母卫少儿、父霍仲孺，因皇后亲缘十八岁侍中。随卫青率少数骑兵深入得众多俘斩，诏封冠军侯；同诏又赏郝贤、孟己。郝贤封号的版本有异。 [[5]](#note-5)


<a id="event-6"></a>

6. **武帝亲断苏建，卫青赠王夫人亲属。** 赵信降、苏建败，卫青未增侯邑，苏建获赎免。甯乘认为卫青尊重靠卫后，劝他以受赐金祝宠妃王夫人的亲人。卫青实言其经过，武帝官甯乘为东海都尉。 [[6]](#note-6)


<a id="event-7"></a>

7. **霍军漠北诏赏、卫军无增封。** 诏称霍去病越漠擒王、封狼居胥禅姑衍、临瀚海，获增五千八百户。路博德、卫山、复陆支、伊即靬等封侯，破奴安稽益邑，李敢等赐关内侯；卫青未增，部将中常惠与遂成得赏。 [[7]](#note-7)


<a id="event-8"></a>

8. **同设大司马及返回马数。** 两军出塞官私马共十四万，回塞不满三万。朝廷设大司马，卫青和霍去病同任，等秩。卫青宾客多改事霍去病，唯任安不去。 [[8]](#note-8)


<a id="event-9"></a>

9. **霍去病无暇成家与待士异同。** 霍去病尚勇寡言，不欲拘古兵法，更称边患未平何以为家；被赞另一方面仍有余粮弃置、缺粮时自戏蹴鞠的批评。卫青仁厚喜士，退让取悦于上而才名不著。 [[9]](#note-9)


<a id="event-10"></a>

10. **霍去病卒及子嬗。** 元狩六年卒，谥景桓，发玄甲军列阵送葬至茂陵，冢象祁连。子霍嬗嗣为侯，随武帝泰山封禅去世，无子除国。 [[10]](#note-10)


<a id="event-11"></a>

11. **战后长期不大举伐胡的解释。** 漠北战后到卫青死历十四年，本文归因无多马且汉军在两越、朝鲜、羌与西南各方用兵。 [[11]](#note-11)


<a id="event-12"></a>

12. **卫青尚平阳长公主。** 曹寿病归侯国后，公主在侍左右劝说下，经皇后转请，武帝命卫青尚主。后两人合葬，冢象庐山。 [[12]](#note-12)


<a id="event-13"></a>

13. **卫青军功及将属总计。** 班固合计其七次出击、斩捕五万余、河套建郡与总封户数，数其三子、属将封侯，并提示李广、张骞等有专传。 [[13]](#note-13)


<a id="event-14"></a>

14. **李息小目。** 以下补李息军历。 [[14]](#note-14)


<a id="event-15"></a>

15. **李息三次为将。** 先事景帝，后为材官将军军马邑、出代、从卫青出朔方，三度为将而无功，后来常任大行。 [[15]](#note-15)


<a id="event-16"></a>

16. **公孙敖小目。** 以下补敖的军功、夺爵与晚年。 [[16]](#note-16)


<a id="event-17"></a>

17. **公孙敖屡从征及晚岁案。** 以郎事景帝。出代败后赎为庶人，从卫青击右贤王得侯，再随出定襄。河西失期失侯。后为因杅将军筑受降城，再战余吾失军、下狱且曾诈死逃亡，传谓后牵于妻巫蛊而灭族。 [[17]](#note-17)


<a id="event-18"></a>

18. **李沮小目。** 以下为强弩将军李沮。 [[18]](#note-18)


<a id="event-19"></a>

19. **李沮两任强弩将军。** 云中人，初事景帝，后从左内史领强弩将军，次年再任。 [[19]](#note-19)


<a id="event-20"></a>

20. **张次公小目。** 以下为岸头侯张次公。 [[20]](#note-20)


<a id="event-21"></a>

21. **张次公封侯及军职。** 从卫青得封，王太后死后为将入卫北军，次年又随军，后坐法去侯。 [[21]](#note-21)


<a id="event-22"></a>

22. **赵信小目。** 以下为两度转所事的赵信。 [[22]](#note-22)


<a id="event-23"></a>

23. **赵信由匈奴来汉又降归。** 匈奴相国到汉受封翕侯，后来为前将军，军败后投回匈奴。 [[23]](#note-23)


<a id="event-24"></a>

24. **赵食其小目。** 以下补赵食其与李广的东道案。 [[24]](#note-24)


<a id="event-25"></a>

25. **赵食其斩获、赐爵与失期。** 主爵都尉从卫青获首；元狩三年赐关内侯金。次年为右将军走东道失路，由当斩赎为庶人。 [[25]](#note-25)


<a id="event-26"></a>

26. **郭昌小目。** 以下补拔胡将军郭昌。 [[26]](#note-26)


<a id="event-27"></a>

27. **郭昌屯朔方及击昆明。** 郭昌从军，由太中大夫于元封四年进拔胡将军屯朔方，后来击昆明失利夺印。 [[27]](#note-27)


<a id="event-28"></a>

28. **荀彘小目。** 以下为攻朝鲜的左将军荀彘。 [[28]](#note-28)


<a id="event-29"></a>

29. **荀彘出征朝鲜及得罪。** 早以御术见识而任侍中，屡从卫青，元封三年出击朝鲜，终因擅拘楼船将军获诛。 [[29]](#note-29)


<a id="event-30"></a>

30. **霍去病军功合计。** 六次击匈奴，其中四次为将军，总计斩获十一万余级，河西纳降使西边少寇；列总增封户数及属将侯数。 [[30]](#note-30)


<a id="event-31"></a>

31. **路博德小目。** 以下为伏波将军路博德。 [[31]](#note-31)


<a id="event-32"></a>

32. **路博德军功俸爵和边屯。** 右北平守从霍去病受封，后以伏波将军平南越并益邑，坐法失爵，任强弩都尉屯居延而死。 [[32]](#note-32)


<a id="event-33"></a>

33. **赵破奴小目。** 以下为从票侯、浞野侯赵破奴。 [[33]](#note-33)


<a id="event-34"></a>

34. **赵破奴受封、败降、逃归及族诛。** 早去匈奴后还汉，为霍去病部司马。受封从票侯后以酎金失爵，攻匈河未遇敌，击楼兰后另封浞野。深入左部战败被俘，后同子安国逃回，终因巫蛊被族。 [[34]](#note-34)


<a id="event-35"></a>

35. **卫霍两家不同后运。** 卫青以后卫氏枝属数人为侯，二十四年间各夺爵。征和太子败，卫氏遂遭祸；霍去病之弟霍光后来贵盛。 [[35]](#note-35)


<a id="event-36"></a>

36. **班固录卫青谈将臣职分。** 苏建劝卫青延揽士大夫。卫青以窦婴、田蚡广交宾客遭武帝忌为戒，视招贤黜不肖为君权，臣以奉守法职为要。班固说霍去病也有相近看法。 [[36]](#note-36)

### 3. 元朔五年击右贤王与封赏

[返回正文第3条](#event-3)

<a id="hs055-p006"></a>

**[《汉书·卫青霍去病传》P006](../../拆分史书/汉书/卷055.md#p006)** · [仓内TXT L7955—L7955](../../拆分史书/汉书/卷055.md#part-1-L7955)

> 元朔五年春，令青將三萬騎出高闕，衛尉蘇建為遊擊將軍，左內史李沮為彊弩將軍，太僕公孫賀為騎將軍，代相李蔡為輕車將軍，皆領屬車騎將軍，俱出朔方。大行李息、岸頭侯張次公為將軍，俱出右北平。匈奴右賢王當青等兵，以為漢兵不能至此，飲醉，漢兵夜至，圍右賢王。右賢王驚，夜逃，獨與其愛妾一人騎數百馳，潰圍北去。漢輕騎校尉郭成等追數百里，弗得，得右賢裨王十餘人，眾男女萬五千餘人，畜數十百萬，於是引兵而還。至塞，天子使使者持大將軍印，即軍中拜青為大將軍，諸將皆以兵屬，立號而歸。上曰：「大將軍青躬率戎士，師大捷，獲匈奴王十有餘人，益封青八千七百戶。」而封青子伉為宜春侯，子不疑為陰安侯，子登為發干侯。青固謝曰：「臣幸得待罪行間，賴陛下神靈，軍大捷，皆諸校力戰之功也。陛下幸已益封臣青，臣青子在繈褓中，未有勤勞，上幸裂地封為三侯，非臣待罪行間所以勸士力戰之意也。伉等三人何敢受封！」上曰：「我非忘諸校功也，今固且圖之。」乃詔御史曰：「護軍都尉公孫敖三從大將軍擊匈奴，常護軍傅校獲王，封敖為合騎侯。都尉韓說從大軍出窴渾，至匈奴右賢王庭，為戲下搏戰獲王，封說為龍哣侯。騎將軍賀從大將軍獲王，封賀為南窌侯。輕車將軍李蔡再從大將軍獲王，封蔡為樂安侯。校尉李朔、趙不虞、公孫戎奴各三從大將軍獲王，封朔為陟軹侯，不虞為隨成侯，戎奴為從平侯。將軍李沮、李息及校尉豆如意、中郎將綰皆有功，賜爵關內侯。沮、息、如意食邑各三百戶。」其秋，匈奴入代，殺都尉。

### 5. 霍去病以票姚校尉受封

[返回正文第5条](#event-5)

<a id="hs055-p010"></a>

**[《汉书·卫青霍去病传》P010](../../拆分史书/汉书/卷055.md#p010)** · [仓内TXT L7959—L7959](../../拆分史书/汉书/卷055.md#part-1-L7959)

> 霍去病，大將軍青姊少兒子也。其父霍仲孺先與少兒通，生去病。及衛皇后尊，少兒更為詹事陳掌妻。去病以皇后姊子，年十八為侍中。善騎射，再從大將軍。大將軍受詔，予壯士，為票姚校尉，與輕勇騎八百直棄大將軍數百里赴利，斬捕首虜過當。於是上曰：「票姚校尉去病斬首捕虜二千二十八級，得相國、當戶，斬單于大父行藉若侯產，捕季父羅姑比，再冠軍，以二千五百戶封去病為冠軍侯。上谷太守郝賢四從大將軍，捕首虜千三百級，封賢為終利侯。騎士孟已有功，賜爵關內侯，邑二百戶。」

### 6. 武帝亲断苏建，卫青赠王夫人亲属

# 汉书司马相如辞赋与著述

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **景帝近侍与客梁作赋。** 司马相如成都人，少爱读书击剑，本名犬子，因慕蔺相如改名。以家资入郎，任景帝武骑常侍；帝不爱辞赋，他称病去官，客居梁孝王门下，同邹阳、枚乘、严忌等往来，数年后作《子虚赋》。 [[1]](#note-1)


<a id="event-2"></a>

2. **梁王卒后客临邛。** 梁孝王卒，相如返蜀，贫无产业。旧交临邛令王吉招他住都亭，故意天天礼谒。他起初相见，继而谢病，王吉越装得郑重。 [[2]](#note-2)


<a id="event-3"></a>

3. **文君夜奔与临邛酒家。** 卓王孙、程郑因县令礼遇而设宴。相如弹琴，卓氏新寡女文君窥见心悦，夜里投奔相如。成都家贫，二人返临邛卖车骑开酒肆，文君当垆，相如洗器。卓王孙不堪受辱又经宗族劝解，分给女儿僮仆、钱与嫁资，两人遂归成都置田宅。 [[3]](#note-3)


<a id="event-4"></a>

4. **武帝读赋与三位假托人物。** 蜀人杨得意任狗监，向读《子虚赋》的武帝说明作者尚在世。相如奉召，自请改作天子游猎赋，以子虚为楚国夸说、乌有先生为齐国诘难、亡是公为天子礼义，借虚构的园猎盛观收归节俭讽谏。 [[4]](#note-4)


<a id="event-5"></a>

5. **子虚使齐归来答问。** 楚使子虚与齐王出猎后，去见乌有先生和亡是公。他说获物不多，却乐在能以楚国云梦之大反过来应对齐王的夸耀。 [[5]](#note-5)


<a id="event-6"></a>

6. **齐王海滨校猎。** 子虚叙齐王出千车万骑，士卒猎网漫山，猎获后问楚王与己孰胜。子虚自称只常随楚王游内苑，连诸侯后苑都未遍观，藉谦辞引出楚地广泽。 [[6]](#note-6)


<a id="event-7"></a>

7. **云梦山泽物产。** 子虚称云梦已方九百里，却还是楚七泽之一小者。赋铺陈高山、丹赭金玉、陂池泉流与各方物产，给珍木、香草、鱼鳖、禽兽和异兽各列栖地，以层层并列夸饰云梦之富。 [[7]](#note-7)


<a id="event-8"></a>

8. **楚王乘舆弋猎。** 楚王先让善战之士徒手格兽，再驾役四马的玉舆、张珠旗执弓戟，车未尽放即踏兽驰射。车骑迅如雷电、所获覆盖野地，正是子虚夸逞铺陈的顶点之一。 [[8]](#note-8)


<a id="event-9"></a>

9. **郑女侍游的服饰。** 郑地美人披细缯纱绡，褶层下曳兰蕙，上拂翠羽车盖。长带薄衣随车摇曳，人物装束与车饰彼此映衬，若神女幻影。 [[9]](#note-9)


<a id="event-10"></a>

10. **蕙圃射禽与清池游船。** 随从在蕙圃、金堤射翡翠、鸳禽、白鹄和鹤雁。疲时乘画船，张羽盖，采钓水产，鼓吹歌唱；舟声惊动群鱼，水石交击之响被夸为雷霆。 [[10]](#note-10)


<a id="event-11"></a>

11. **止猎登台与楚胜齐。** 楚王击鼓燃火止猎，整列车骑，登阳云台安静自持，待调好饮食才进。子虚用这一幕对比齐王终日逐兽、不下车进食，断言齐不如楚。 [[11]](#note-11)


<a id="event-12"></a>

12. **乌有先生责子虚饰侈。** 乌有先生说齐王是礼遇远使而非夸富，问楚是想闻其国风。子虚只夸云梦和纵乐，把君王的过失彰示于人；若事并未有，则更有损使者信用。随后又自夸齐国海泽珍多而有所顾忌。 [[12]](#note-12)


<a id="event-13"></a>

13. **亡是公论贡礼与封疆。** 亡是公批评两方竞逐苑囿之大。贡币的本意是诸侯述职，画封疆为使人知约束；齐越界交肃慎、出海围猎失义。君臣、诸侯应遵礼，不能以奢淫扬名。 [[13]](#note-13)


<a id="event-14"></a>

14. **上林八川与急流。** 赋由齐楚转到天子上林，以山水极端界定方向。灞浐、泾渭等八水各流，穿林过泽，在隘口冲击崖石，形成旋瀑和漫流，继铺列水中生物与洲浦之盛。 [[14]](#note-14)


<a id="event-15"></a>

15. **上林山林、香草与原隰。** 九嵕、南山等峻峰与巨木深林连绵，沟谷相通，继以平野、近水高地。其上密植诸种芳草，香气弥漫；散布高低的地面成为苑囿景观的一部分。 [[15]](#note-15)


<a id="event-16"></a>

16. **南北异候与珍兽。** 赋说日出东沼、日落西坡，上林广大至不可见边。南边严冬仍滋长，出象犀等兽；北边盛夏也冻裂地面，有麒麟、橐驼及各种异马。南暖北寒是表现苑囿包举四方的夸张。 [[16]](#note-16)


<a id="event-17"></a>

17. **山谷别馆与神仙陈设。** 离宫、高廊、辇道跨山谷，楼堂叠高，宫屋奇巧到仿佛接星虹。作者再写青龙、仙人、醴泉与穿庭水流，兼列宫馆旁各色瑰石，使工巧与神怪相映。 [[17]](#note-17)


<a id="event-18"></a>

18. **果木繁生与林风。** 果树布满宫苑、丘陵和平原，翠叶朱花相照；又列楠檀等大树，高拔合抱，枝叶交缠。树木承风摇曳，发声与颜色一并铺写。 [[18]](#note-18)


<a id="event-19"></a>

19. **猿猴飞鼠在巨木间。** 各种猿猴、飞鼠栖在树间，鸣叫交错，从枝杪、绝梁和榛林轻捷跃行，倏忽远去。 [[19]](#note-19)


<a id="event-20"></a>

20. **行宫设施随处具备。** 如上所述的景地数百千处，皇帝可往来游宿。各地自有厨房、宫人及百官备具，游幸时不必挪移宫中人事器具。 [[20]](#note-20)


<a id="event-21"></a>

21. **冬天大猎与皇家阵势。** 暮秋入冬，天子大猎，乘象饰车、列彩旗，御者和参乘随行，车骑从四路围猎。赋把江河山岳譬作围障和军楼，铺写穿山涉地、徒手搏兽和驰逐的盛大阵势。 [[21]](#note-21)


<a id="event-22"></a>

22. **回旋察猎与纵辔射禽。** 车驾先放慢观看部伍进退、将帅变换，接着疾驰捕禽兽。箭未发已择其可食处，放箭即中，转写驾御与射技之精。 [[22]](#note-22)


<a id="event-23"></a>

23. **凌空追猎神禽。** 猎游夸到乘风上浮，与神同行，追逐玄鹤、孔鸾、凤凰与传说异鸟；这是赋中想象的腾跃。 [[23]](#note-23)


<a id="event-24"></a>

24. **归车巡观猎获。** 驰尽远道后车驾回头，历台观至细柳一带，看将士勤劳并均分猎获。被车马人众蹂践或惊惧困死的禽兽遍野，显示校猎的耗损。 [[24]](#note-24)


<a id="event-25"></a>

25. **台上置酒与诸方乐舞。** 游兴渐尽后在高台置酒，悬大钟、列翠旗，古舞与四方乐曲竞奏，千人倡万人和，震动山谷。歌工和俳优相接，表现游宴声色之繁。 [[25]](#note-25)


<a id="event-26"></a>

26. **青琴宓妃之美。** 再以青琴、宓妃等绝俗女子写仪态容色，写其薄绢异服、香气、皓齿长眉和含情顾盼。 [[26]](#note-26)


<a id="event-27"></a>

27. **天子罢猎并开禁恤贫。** 酒酣时天子忽觉奢侈会贻害后嗣，设辞自省，罢饮罢猎。命有司开可耕园地、拆墙填沟，使山泽可通；去禁令、空馆舍、发仓救贫和存问孤寡，回头修仁政。 [[27]](#note-27)


<a id="event-28"></a>

28. **改游六艺与教化。** 改着朝服法驾，在六艺九经的比喻中行仁义、读诗书礼易、登明堂清庙，听臣下论政。不再竞逐真实禽兽，四海闻风趋义，刑可闲置。 [[28]](#note-28)


<a id="event-29"></a>

29. **以诸侯园猎为戒。** 终日逐兽使身体、车马、军士与府库受损，而百姓不得恩惠。齐楚国土有限却用近乎全境为苑，使民无地可耕，这是诸侯僭用天子乐游会累及百姓的理由。 [[29]](#note-29)


<a id="event-30"></a>

30. **齐楚使者认错。** 两位虚构辩者变色离席，自称见识浅陋，感谢亡是公开导。宴猎议论在此结束。 [[30]](#note-30)


<a id="event-31"></a>

31. **相如因赋授郎与传文删取。** 武帝读赋后任相如为郎。编者指出云梦、上林的山水禽兽铺写多夸饰，现有传文只收足以归于讽谏、节俭的内容。 [[31]](#note-31)


<a id="event-32"></a>

32. **檄告巴蜀太守与四方形势。** 檄书以朝廷安内后威服匈奴、西域朝贡、东处闽越、南越太子入朝等宣示声威，说明南夷、西僰既有意归附，出使才须克服山川险远。下文解释原定少量护使用兵和复除征发之意，责地方加派。 [[32]](#note-32)


<a id="event-33"></a>

33. **勉边民赴难并追责逃役。** 檄书称边郡征士闻烽即赴、尽职者传爵于子孙，用与这些人同为编户的义理勉巴蜀民。又说逃亡、自杀危害父母名誉、伤国家事，将其归于缺乏教化。 [[33]](#note-33)


<a id="event-34"></a>

34. **布告各县与问责地方。** 皇帝所遣使者宣告发卒本意，指出逃避及地方教诲失职。正值农时，相如已在近县宣话，令太守速传各县，使远处山谷居民也能知晓。 [[34]](#note-34)


<a id="event-35"></a>

35. **持节西使与邛莋通道。** 相如回报后，唐蒙发卒修路两年未成，多死而费巨。邛、莋等闻南夷受赏，愿内附请置吏。相如以西部接蜀、旧设郡县建议通西，拜中郎将持节，带王然于等及礼物赴任，受故乡隆礼，卓氏也增分女财。邛莋等请内附，扩展边关，通山道，架孙水之桥，回奏获帝嘉悦。 [[35]](#note-35)


<a id="event-36"></a>

36. **借蜀老设难以讽天子。** 蜀长老和大臣多说开西南无益。相如已经倡议此事，难以直谏，故设辞由蜀老发难、使者答辩，一方面讽谏，一方面说明天子使意。 [[36]](#note-36)


<a id="event-37"></a>

37. **二十七位父老问疲民开边。** 设辞中的乡老称对外保持联系即足，三郡修夜郎道已历数年，军民疲敝还要继续向西，忧使者办不成。又问周秦以来本不曾尽收西方，为何舍民力追求远地。 [[37]](#note-37)


<a id="event-38"></a>

38. **使者先驳父老前提。** 虚构的使者认为完全不通也意味着巴蜀不进文明，反对仅从旁观者所见判断大事。他说行期紧迫，先讲大概。 [[38]](#note-38)


<a id="event-39"></a>

39. **非常事业与先忧后安。** 使者称异乎常人的心志和事业才能得到非常之功，百姓起初恐惧，成事后方见安定。 [[39]](#note-39)


<a id="event-40"></a>

40. **以大禹劳身治水为比。** 以洪水使民迁徙与夏禹疏通江河、亲身劳瘁为例，论事业既可让当世忧劳，又可给后代持久安宁，因此声名不绝。 [[40]](#note-40)


<a id="event-41"></a>

41. **兼容远人和照拂未被泽者。** 使者说贤君不能只循旧俗取悦当世，援《诗》言王土王臣，以普遍施恩为责任。今国内既受恩，远方风俗尚殊者，也应使获治理和安宁。 [[41]](#note-41)


<a id="event-42"></a>

42. **预言将封泰山。** 使者借忧勤而后安乐之理，预言汉可登泰山、禅梁父，上比五帝、下越三王；父老的局部眼光，好比捕鸟人还在低泽张望，不见鸟早飞远。 [[42]](#note-42)


<a id="event-43"></a>

43. **蜀老接受使者说辞。** 笔下父老自觉失其进言立场，称颂汉德，即使百姓劳苦也愿先作表率，然后迟疑而退。 [[43]](#note-43)


<a id="event-44"></a>

44. **使事受金免官复召。** 有人上书指相如出使受金，他因此失官；一年多后复被召为郎。传未明受金、免官或复召的月日。 [[44]](#note-44)


<a id="event-45"></a>

45. **相如性情与从猎进谏。** 相如口吃而擅写，有消渴病；与卓氏成婚后家富，常托病闲居，不竞官位。见武帝在长杨亲逐野兽，乘随行时进疏。 [[45]](#note-45)


<a id="event-46"></a>

46. **自击猛兽可能妨碍车驾。** 才力非常者人兽都有，猛兽可能猝然冲近属车，车驾无法及时回转、随从无法施技，连枯木朽株都可能成为险阻，犹如敌人突然起于车轮之下。 [[46]](#note-46)


<a id="event-47"></a>

47. **清道尚有险，野猎更不可恃。** 道路清理过尚有马衔折、车止等意外，何况高草山丘。天子身系天下，不能因一时捕猎快意而忽略万一的险变。 [[47]](#note-47)


<a id="event-48"></a>

48. **以垂堂谚劝防患。** 明智者察祸于事前。相如用千金之家不坐危堂垂檐下为喻，提醒天子尤其不应在小便之事上轻身取险。 [[48]](#note-48)


<a id="event-49"></a>

49. **宜春过宫作吊赋。** 武帝认可猎谏。回驾经过宜春宫时，相如奏赋吊秦二世，由实见景物转论二世失国。 [[49]](#note-49)


<a id="event-50"></a>

50. **吊二世赋的景物与亡国。** 赋从曲江、南山、长阪、竹林写到凭吊秦二世，指其行己不谨、听谗不悟而亡宗庙，使墓荒芜、魂无所归依。 [[50]](#note-50)


<a id="event-51"></a>

51. **园令献《大人赋》。** 相如任守文帝陵园之令。他察觉武帝好神仙，续成并献《大人赋》。山泽中形貌枯瘦的仙人不足以写帝王游仙，因此改作更广大宏丽的神游。 [[51]](#note-51)


<a id="event-52"></a>

52. **大人轻身腾空。** 大人厌居中州之逼，彩霞、彗星和虹霓皆为旌旗，乘应龙、赤螭、青虬，队车如电飞腾。这是赋中神游的启行。 [[52]](#note-52)


<a id="event-53"></a>

53. **召神相从与南游。** 穿过少阳太阴求真人，在摇光排布神队，使五帝前导、太一回后，又命诸神分列护驾、扫清气氛，向南游历。 [[53]](#note-53)


<a id="event-54"></a>

54. **历神境见西王母。** 帝舆过尧舜旧山，入雷室鬼谷，越江涉沙、经弱水，令灵娲和冯夷奏乐，又斥风伯雨师。进帝宫、登昆仑见穴居的白首西王母，反问若长生仅如彼，即活万世亦不足喜。 [[54]](#note-54)


<a id="event-55"></a>

55. **出北极独游无极。** 游车转过不周幽都，食朝霞、芝英。再越雷电与云雾，留下骑队冲出北际，直到天地似已无形、视听无从，乘虚远飞，超然独存。 [[55]](#note-55)


<a id="event-56"></a>

56. **武帝闻赋生神游之意。** 武帝很喜欢《大人赋》，听后想驾凌云气、游于天地之际。叙述显示赋文所起的实际效果。 [[56]](#note-56)


<a id="event-57"></a>

57. **封禅遗书论历代受命。** 文章起自天地生民，历数至秦的旧君，称七十二君名可道而多数湮灭，以是否顺善来说明帝业的存亡。 [[57]](#note-57)


<a id="event-58"></a>

58. **由唐周旧统称汉德符瑞。** 追述典籍所能知的尧舜、后稷、公刘、文王与周家治业，称清楚易守的制度可以传后。复铺述汉帝政教、武功、归附和甘谷、龟龙祥瑞，反问比周跃鱼之瑞更盛，何可仍不行封禅。 [[58]](#note-58)


<a id="event-59"></a>

59. **设大司马劝行封禅。** 遗书用大司马发言，劝武帝既有德与符命，可告成中岳、祭天地以福百姓。并请掌故具陈典仪，令文士修饰记述，使盛事获得足以永传的文字。 [[59]](#note-59)


<a id="event-60"></a>

60. **设天子从议并发为颂。** 文中设想天子同意，从多方求议，汇总所闻符瑞与德泽，以下用颂体铺陈。 [[60]](#note-60)


<a id="event-61"></a>

61. **甘露时雨润育嘉禾。** 颂称上天降云雨甘露，滋润田土，使万物繁生、一茎多穗，作为功德的征象。 [[61]](#note-61)


<a id="event-62"></a>

62. **名山望君前来。** 颂由普遍润物转称万物慕君，名山留有显位等待帝王亲至，向天子发出前往封禅的劝请。 [[62]](#note-62)


<a id="event-63"></a>

63. **白质黑文瑞兽。** 颂写苑囿中白质黑纹、仪容温穆的瑞兽，认为它忽然出现如同虞舜受天命的祥征。 [[63]](#note-63)


<a id="event-64"></a>

64. **冬郊所见麒麟。** 颂说冬十月帝车赴灵畤行郊礼，麒麟来游而受神福，称三代以前也少见这样瑞征。 [[64]](#note-64)


<a id="event-65"></a>

65. **黄龙因德而升。** 颂以色采光明的黄龙显世为德盛、受命的象征，并说可见于旧传。 [[65]](#note-65)


<a id="event-66"></a>

66. **托祥瑞劝登封。** 各种符章无须直言，依物类寄意，目的是劝说帝王登山行封。 [[66]](#note-66)


<a id="event-67"></a>

67. **安存仍须戒惧。** 结尾说天人相应仍须戒惧，兴盛时考虑衰落，安时念危。以汤武庄敬和舜行大礼时警省收束。 [[67]](#note-67)


<a id="event-68"></a>

68. **传末列未收著述。** 本传不采致平陵侯书、与五公子相难及草木书篇，只收在公卿间流传显著的文章。 [[68]](#note-68)


<a id="event-69"></a>

69. **司马迁与扬雄论赋。** 赞语引司马迁认为辞赋虽多夸饰而归意节俭，可与《诗》讽谏相比；扬雄认为奢美铺写多而末尾的规谏太少，等于久久奏郑卫之音，结尾才奏雅乐。两种赋论分开。 [[69]](#note-69)

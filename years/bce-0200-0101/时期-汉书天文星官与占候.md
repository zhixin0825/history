# 汉书天文星官与占候

[本世纪目录](README.md) · [全部世纪](../README.md)

此处连读各志的制度沿革、学术分类与未详年次的史事；整段原文和已系年节录均可由卷内读本查阅。


<a id="event-1"></a>

1. **志序：星官及灾异。** 志将星官、行星运行、日月食、晕虹和云气归为天文，称有118名、783颗，并把天象和政事相应解释成阴阳感应。星表统计与政治解释分读。 [[1]](#note-1)


<a id="event-2"></a>

2. **紫宫、北斗与附属星官。** 天极、紫宫被视为天帝正宫；北斗各部分分别用来在昏、半夜、平旦建时。文昌六官、三台和辅星拟将相君臣，杓旁又列招摇、盾与囚牢，把星位明暗用于占验。 [[2]](#note-2)


<a id="event-3"></a>

3. **东宫苍龙。** 心宿以大星为天王、房宿作天府与车马。角、亢、氐、尾、箕还有王庭、宗庙、疫病、君臣等比拟，摄提以斗杓所指建时。 [[3]](#note-3)


<a id="event-4"></a>

4. **南宫朱鸟。** 太微中外分列帝座、执法、门与藩卫，轩辕主女主。东井、舆鬼连水和祠事，柳、七星、张、翼配朱鸟部位，轸车掌风，星入星官可被解释为兵、火或粮灾。 [[4]](#note-4)


<a id="event-5"></a>

5. **西宫咸池与白虎。** 咸池称五帝车舍。奎沟、娄聚、胃仓、昴旄头、毕罕车，昴毕之间为天街。参宿作白虎形，旁列天厕、天矢、狼弧、南极老人等，后者在秋分向南候见。 [[5]](#note-5)


<a id="event-6"></a>

6. **北宫玄武与天汉。** 虚、危旁为羽林军、北落及司寇。营室又称离宫阁道，天河中列王梁、天横；南斗为庙，牵牛为牲，河鼓三星拟将帅，婺女北列织女。 [[6]](#note-6)


<a id="event-7"></a>

7. **岁星盈缩与甘、石异说。** 岁星配木、春、仁与貌，超越预期舍位称盈、落后称缩。甘氏和石氏各把方位与彗、天枪、天棓等形象相配，计出现期限与国土得失；两家名称、形态及期限不宜混作同一观察。 [[7]](#note-7)


<a id="event-8"></a>

8. **荧惑及其逆行、停留。** 荧惑配火和夏，用留宿月数、逆行、回环与进退推论战争、疆土、丧疫。正文另存以出现、隐没判兵起兵散的说法。 [[8]](#note-8)


<a id="event-9"></a>

9. **太白与军象。** 太白配西金与秋，以和太阳相对位置判断盈缩；日出方位、早晚、出入前后、明暗、高低和光芒各用于推测进退、胜败。与荧惑并见另有军忧和偏师的说法。 [[9]](#note-9)


<a id="event-10"></a>

10. **辰星与太白合离。** 辰星和太白同出、相背、相抵或上下绕行，分别用于判断有无交战及主客得失。占者还测行星间距，拿参、心、奎、狼等恒星作目视颜色的比对。 [[10]](#note-10)


<a id="event-11"></a>

11. **辰星与填星各自占法。** 辰星配北水、冬与听，填星配中央土、信与思。占法按出没迟早、舍位久暂及前移后退判断寒暖、军事、土地或人事。 [[11]](#note-11)


<a id="event-12"></a>

12. **五星聚合、相掩与星色。** 同舍为合、相陵为斗，按行星配对、间距与月掩加以占断。三、四、五星聚会、星体大小与色芒各有政治解释，按期运行则被视作丰年。 [[12]](#note-12)


<a id="event-13"></a>

13. **星官分野与地上灾变。** 将维星、句星等连到地震、水灾、山崩及兵事。又以宿度、干支和列国方位分配地上分野，各家配属并不相同；秦晋等占太白的说法连着战国与边地观念。 [[13]](#note-13)


<a id="event-14"></a>

14. **岁星十二位置：寅至未。** 先分行星早见为盈、晚见为缩，再按太岁顺行由寅到未，分别比较石氏、甘氏与《太初历》的星名、所居宿和出见月份。 [[14]](#note-14)


<a id="event-15"></a>

15. **岁星十二位置：申至丑。** 由涒滩、作詻到赤奋若继续对列三家，含《尔雅》异名。志末以各观察时段星行盈缩不同解释诸家宿位差，并说其他四星亦有相似问题。 [[15]](#note-15)


<a id="event-16"></a>

16. **逆行和月食是不是常行。** 志说早历不计逆行，甘、石已记荧惑与太白逆行，又拿可推算的望日月食作对照；班固沿政治和刑德解释其何以常见，仍把它们看作失度而非理想正行。 [[16]](#note-16)


<a id="event-17"></a>

17. **异星、四方与星空密度。** 国皇、昭明及东南西北的五残、六贼、司诡、咸汉按颜色、位置、形状而辨。又记四隅之星、烛星和似云似星的归邪，并解释星数和天河所象征的水土人气。 [[17]](#note-17)


<a id="event-18"></a>

18. **天鼓、天狗及流星样异象。** 依声响、明暗和在空中形状区分天鼓、天狗、格泽、蚩尤旗、旬始、枉矢和长庚，兼记星陨成石与景星。从形态描述中分开随附的兵灾祥应。 [[18]](#note-18)


<a id="event-19"></a>

19. **太阳黄道、日影与月之九行。** 由冬夏至、春秋分的太阳位置和八尺表实测影长解释寒暑。月行按黄道及周围八道分说，晦朔用于定月位；又记月临箕、轸、毕与风雨的传统占法。 [[19]](#note-19)


<a id="event-20"></a>

20. **日晕和日食军占。** 据晕的厚薄、方向、环抱、颜色及盘旋先后分客主强弱。日食则按食亏方位和复明所在联系分野，属于所记占法。 [[20]](#note-20)


<a id="event-21"></a>

21. **望云与辨军气。** 按仰望、平望、登高分别说可察距离，记不同地区的云气颜色、行人车骑形状与阵势。又包括海旁楼台样蜃气、庆云、重雾和田畴、城郭乃至牲畜的盛衰观察。 [[21]](#note-21)


<a id="event-22"></a>

22. **雷电气象及地表物候。** 以阳气解释雷电和霓虹的季节，列地震、山崩、川塞、泽竭及城门、民俗、车服、仓庾、鱼鸟等异象供观察。 [[22]](#note-22)


<a id="event-23"></a>

23. **候岁：年首、风雨、音声与至日。** 冬至、腊次日、正旦和立春分别用作常候，按风向、日间时段、雨量和音声占年成。冬至以炭、物候和晷影互校；末列三十年、百年和五百年变纪。 [[23]](#note-23)


<a id="event-24"></a>

24. **春秋战国天象总述与秦末。** 回顾春秋日食彗孛和《春秋》所记争乱，志把列国竞兵与候星之兴相连。秦始皇至二世天象仍以回顾性段落书写；未以概称十五年给各彗星硬加单年。 [[24]](#note-24)


<a id="event-25"></a>

25. **楚汉至高帝：聚东井、太白与高帝崩。** 枉矢与项羽救巨鹿合议，五星聚东井与刘邦受降合议；另有汉三年太白、七年参毕月晕、十二年荧惑守心。引文之外的受命、胜败附会归占说。 [[25]](#note-25)


<a id="event-26"></a>

26. **惠帝、文帝天裂与诸星。** 惠二年记东北天裂，和后来的吕氏政变相连是志书解释。后元二年记天欃，后元六年有边战及东井合星，接叙后元七年文帝崩和另数次行星位置。 [[26]](#note-26)


<a id="event-27"></a>

27. **景帝初年：五星、七国和鲁国。** 婺女、张、斗一带合星附越、齐、河南及吴楚等分野。七国之乱、平乱置王和罢兵有独立记年，志又用娄、奎和东井的观测附会鲁王封国及宫火。 [[27]](#note-27)


<a id="event-28"></a>

28. **景帝中后年：合星、彗蓬和疫灾。** 中元至后元先后记东井与觜觿、房心间多种变化。中三年所附梁孝王继嗣及袁盎案是跨年叙事。梁孝王等去世只有中六年明文；后元元年另记地震和疫病。 [[28]](#note-28)


<a id="event-29"></a>

29. **武帝建元彗孛与高园之火。** 建元三年记两次孛星，志后牵合诸王末路、地震和陈后废黜。六年荧惑守舆鬼，并叙宗庙火和窦太后崩，彼此有独立年条可核。 [[29]](#note-29)


<a id="event-30"></a>

30. **武帝元光客星与边事。** 元光元年六月客星在房；志连写次年军备，与史籍马邑之谋的月、地点表述不同。天星尽摇仅称元光中，候星者解释为劳民。 [[30]](#note-30)


<a id="event-31"></a>

31. **武帝元鼎至太初占异。** 太白入天苑有明确元鼎五年；荧惑守斗、星孛河戍与招摇只记年号范围。南越、朝鲜和大宛用兵是编者用来对照的后事。 [[31]](#note-31)


<a id="event-32"></a>

32. **昭帝始元与元凤天象。** 梁成恢和吴莫如观察蓬星、太白、荧惑及燕宫流星，以此解释上官氏及燕王变乱。其后元凤四、五年有明确客星和烛星日期，募少年、筑城乃可单归的政事。 [[32]](#note-32)


<a id="event-33"></a>

33. **昭帝元平与昌邑废立。** 正月黑云、二月大星西行和牂云、三月流星入紫宫分别记录；附占文认为兵事、辅臣摄权或国丧。志把废昌邑连到四月，与本纪废黜月份须对读。 [[33]](#note-33)


<a id="event-34"></a>

34. **宣帝本始、地节与黄龙天象。** 本始记辰星早见及被月所犯，地节记月掩荧惑、客星及楚王、霍氏案，黄龙元年客星入紫宫后接宣帝崩。罪案和天象可看各自主条。 [[34]](#note-34)


<a id="event-35"></a>

35. **元帝初元观星、海溢与关东饥。** 记南斗、卷舌客星和西北彗星；海溢、关东灾及谢君男案另有明文年次。西羌战事在文中属事后占验，按战事本证另读。 [[35]](#note-35)


<a id="event-36"></a>

36. **成帝建始、河平流星与合星。** 文昌流星经过紫宫，后叙王凤、王商。又记荧惑犯岁星、月掩填星和三星同近，接载旱荒、流民、夜郎王歆被杀等；志中王商之死与本传措辞不同。 [[36]](#note-36)


<a id="event-37"></a>

37. **成帝阳朔、永始、元延天象。** 月犯心、飞星、树状火气与日下群星陨落并列，各有己见的星占。樊并、苏令两案在明年接述，与永始二年本身的天象分读；元延星陨另于永始所记时次。 [[37]](#note-37)


<a id="event-38"></a>

38. **绥和天象与淳于长、翟方进、成帝。** 志以入北斗流星附淳于长案，以荧惑守心附翟方进自杀。成帝崩记“二月丙戌”，本纪作三月丙戌，须保留差别。 [[38]](#note-38)


<a id="event-39"></a>

39. **哀帝白气、彗星、改号与董贤。** 建平元年白气称天狗，志联系数年后西王母传筹。建平二年彗星后叙夏贺良改号、复旧。元寿元年岁星犯右执法后叙董贤自杀，月份与本纪和《百官表》互见。 [[39]](#note-39)

### 16. 逆行和月食是不是常行

[返回正文第16条](#event-16)

<a id="hs026-p016"></a>

**[《汉书·天文志》P016](../../sources/摘录/汉书-卷026-天文志.md#p016)** · [仓内TXT L5325—L5325](../../sources/本地分卷/汉书/汉书-卷026.md#L5325)

> 古曆五星之推，亡逆行者，至甘氏、石氏經，以熒惑、太白為有逆行。夫曆者，正行也。古人有言曰：「天下太平，五星循度，亡有逆行。日不食朔，月不食望。」夏氏日月傳曰：「日月食盡，主位也；不盡，臣位也。」星傳曰：「日者德也，月者刑也，故曰日食修德，月食修刑。」然而曆紀推月食，與二星之逆亡異。熒惑主內亂，太白主兵，月主刑。自周室衰，亂臣賊子師旅數起，刑罰失中，雖其亡亂臣賊子師旅之變，內臣猶不治，四夷猶不服，兵革猶不寢，刑罰猶不錯，故二星與月為之失度，三變常見；及有亂臣賊子伏尸流血之兵，大變乃出。甘、石氏見其常然，因以為紀，皆非正行也。《詩》云：「彼月而食，則惟其常；此日而食，于何不臧？」詩傳曰：「月食非常也，比之日食猶常也，日食則不臧矣。」謂之小變，可也；謂之正行，非也。故熒惑必行十六舍，去日遠而顓恣。太白出西方，進在日前，氣盛乃逆行。及月必食於望，亦誅盛也。

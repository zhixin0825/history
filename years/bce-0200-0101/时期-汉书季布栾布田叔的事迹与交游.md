# 汉书季布栾布田叔的事迹与交游

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **曹丘生传播季布一诺。** 曹丘生惯靠豪门牟利，季布劝窦长君勿与往来。曹丘生仍求推荐信来访，以楚人称黄金百不及季布一诺为开场，愿替他扬名。季布改怒为喜，以上客礼待，名气因而更广。 [[1]](#note-1)


<a id="event-2"></a>

2. **季心尚勇而恭谨。** 季心武勇震动关中，待人谦恭，侠士愿为他效死。他杀人后投奔袁盎，以长辈礼相事，以弟辈看待灌夫、籍福等，任中司马时郅都也尊重他。兄弟分别以信用、武勇著名。 [[2]](#note-2)


<a id="event-3"></a>

3. **栾布小传。** 本行是栾布的分传题签，下段转入其早年、为彭越哭祭及燕齐仕历。 [[3]](#note-3)


<a id="event-4"></a>

4. **栾布年少失身与哭祭彭越。** 栾布早与彭越交游，后被掠为燕奴，替主人报仇后被臧荼举用。汉平臧荼，彭越赎栾布作梁大夫。彭越被诛并悬首，栾布使齐归来，在首级下复命祭哭，被捕。他临死论述彭越破楚之功，指出汉未证实反迹而杀功臣将使群臣自危。刘邦赦免并拜都尉。 [[4]](#note-4)


<a id="event-5"></a>

5. **栾布辅燕、获封与燕齐纪念。** 文帝时栾布任燕相而至将军。富贵后对有德者报恩，有怨者则借法律处置。吴楚之乱中立功，后封鄃侯，再任燕相。燕齐之间百姓为他立栾公社。 [[5]](#note-5)


<a id="event-6"></a>

6. **田叔小传。** 本行是田叔的分传题签，接下去记其在赵任官及汉廷仕历。 [[6]](#note-6)


<a id="event-7"></a>

7. **田叔出身与入赵王府。** 田叔出自齐田氏，籍贯赵陉城，好剑，学习黄老，待人廉直而好侠，经赵相赵午推荐给赵王张敖任郎中。 [[7]](#note-7)


<a id="event-8"></a>

8. **田叔为孟舒申辩。** 文帝问谁有长者之风。田叔向他推荐因边事免官的孟舒，举随张敖请罪明其重义，又解释守云中时是士兵自愿死战，并非孟舒逼迫疲兵出击。文帝重新起用孟舒；本传只说文帝初政，未写确年。 [[8]](#note-8)


<a id="event-9"></a>

9. **田叔促使鲁王亲自偿还所取财物。** 百姓控告鲁王夺财，田叔公开责打为首者，称百姓不应告其君。鲁王惭愧，想让相国还款；田叔坚持由王自行偿付，否则名声好处会全归于相。 [[9]](#note-9)


<a id="event-10"></a>

10. **田叔陪猎而使鲁王减少出游。** 鲁王打猎总让田叔入馆休息。田叔坚持也在苑外露坐，理由是王在外风吹日晒，自己不该独自休息，鲁王因此减少出游。 [[10]](#note-10)


<a id="event-11"></a>

11. **田叔死后田仁辞谢重金。** 田叔数年后死在任上，鲁王以百金祭祀。少子田仁拒收，以免损害父亲清名。 [[11]](#note-11)


<a id="event-12"></a>

12. **田仁历官与巫蛊案获罪。** 田仁勇壮，为卫将军舍人，多次随军出击，后任郎中，曾做到二千石、丞相长史并失官。其后巡视三河、奏绩受赏，任京辅都尉，再转司直。戾太子起兵时，田仁负责城门，太子得脱，田仁以放纵反者遭族诛。前半仕途不随末句统一定年。 [[12]](#note-12)


<a id="event-13"></a>

13. **班固评季布、栾布、田叔。** 班固称季布受辱而忍活是等待发挥才能，认为轻易自杀不等于勇。栾布哭祭彭越、田叔追随受狱的张敖，又是知道该为何事冒死的义举。 [[13]](#note-13)

> 辯士曹丘生數招權顧金錢，事貴人趙談等，與竇長君善。布聞，寄書諫長君曰：「吾聞曹丘生非長者，勿與通。」及曹丘生歸，欲得書請布。竇長君曰：「季將軍不說足下，足下無往。」固請書，遂行。使人先發書，布果大怒，待曹丘。曹丘至，則揖布曰：「楚人諺曰『得黃金百，不如得季布諾』，足下何以得此聲梁楚之間哉？且僕與足下俱楚人，使僕游揚足下名於天下，顧不美乎？何足下距僕之深也！」布乃大說。引入，留數月，為上客，厚送之。布名所以益聞者，曹丘揚之也。

### 4. 栾布年少失身与哭祭彭越

[返回正文第4条](#event-4)

<a id="hs037-p008"></a>

**[《汉书·季布栾布田叔传》P008](../../拆分史书/汉书/卷037.md#p008)** · [仓内TXT L7119—L7119](../../拆分史书/汉书/卷037.md#part-1-L7119)

> 欒布，梁人也。彭越為家人時，嘗與布游，窮困，賣庸於齊，為酒家保。數歲別去，而布為人所略，賣為奴於燕。為其主家報仇，燕將臧荼舉以為都尉。荼為燕王，布為將。及荼反，漢擊燕，虜布。梁王彭越聞之，乃言上，請贖布為梁大夫。使於齊，未反，漢召彭越責以謀反，夷三族，梟首雒陽，下詔有收視者輒捕之。布還，奏事彭越頭下，祠而哭之。吏捕以聞。上召布罵曰：「若與彭越反邪？吾禁人勿收，若獨祠而哭之，與反明矣。趣亨之。」方提趨湯，顧曰：「願一言而死。」上曰：「何言？」布曰：「方上之困彭城，敗滎陽、成皋間，項王所以不能遂西，徒以彭王居梁地，與漢合從苦楚也。當是之時，彭王壹顧，與楚則漢破，與漢則楚破。且垓下之會，微彭王，項氏不亡。天下已定，彭王剖符受封，亦欲傳之萬世。今漢壹徵兵於梁，彭王病不行，而疑以為反。反形未見，以苛細誅之，臣恐功臣人人自危也。今彭王已死，臣生不如死，請就亨。」上乃釋布，拜為都尉。

### 8. 田叔为孟舒申辩

[返回正文第8条](#event-8)

<a id="hs037-p014"></a>

**[《汉书·季布栾布田叔传》P014](../../拆分史书/汉书/卷037.md#p014)** · [仓内TXT L7125—L7125](../../拆分史书/汉书/卷037.md#part-1-L7125)

> 孝文帝初立，召叔問曰：「公知天下長者乎？」對曰：「臣何足以知之！」上曰：「公長者，宜知之。」叔頓首曰：「故雲中守孟舒，長者也。」是時孟舒坐虜大入雲中免。上曰：「先帝置孟舒雲中十餘年矣，虜常一入，孟舒不能堅守，無故士卒戰死者數百人。長者固殺人乎？」叔叩頭曰：「夫貫高等謀反，天子下明詔，趙有敢隨張王者罪三族，然孟舒自髡鉗，隨張王，以身死之，豈自知為雲中守哉！漢與楚相距，士卒罷敝，而匈奴冒頓新服北夷，來為邊寇，孟舒知士卒罷敝，不忍出言，士爭臨城死敵，如子為父，以故死者數百人，孟舒豈敺之哉！是乃孟舒所以為長者。」於是上曰：「賢哉孟舒！」復召以為雲中守。

> 贊曰：以項羽之氣，而季布以勇顯名楚，身履軍搴旗者數矣，可謂壯士。及至困厄奴僇，苟活而不變，何也？彼自負其材，受辱不羞，欲有所用其未足也，故終為漢名將。賢者誠重其死。夫婢妾賤人，感概而自殺，非能勇也，其畫無俚之至耳。欒布哭彭越，田叔隨張敖，赴死如歸，彼誠知所處，雖古烈士，何以加哉！

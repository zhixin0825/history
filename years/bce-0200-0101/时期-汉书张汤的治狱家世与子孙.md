# 汉书张汤的治狱家世与子孙

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **张汤儿时审鼠。** 张汤是杜陵人，父为长安丞。守家时鼠盗肉，父杖责他；张汤掘熏捕鼠，连同残肉以勘验、笔录、讯鞫、定罪程序办理。父见文辞似老狱吏，往后教他撰写案牍。 [[1]](#note-1)


<a id="event-2"></a>

2. **由长安吏入政。** 父死后任长安吏，曾倾力伺奉下狱的周阳侯，侯出狱后引他交结显贵。甯成以张汤谙练能办事向上推荐，调他为茂陵尉，管理营作方中之事。 [[2]](#note-2)


<a id="event-3"></a>

3. **田蚡荐举、皇后狱与定律。** 田蚡征张汤为相府史，荐为侍御史。张汤彻查陈皇后巫蛊党与而得升，随后同赵禹制定严密律令，约束失职之吏。赵禹孤立奉公，张汤则善驾驭人物，从早年结商人到列九卿后接纳名士。 [[3]](#note-3)


<a id="event-4"></a>

4. **援经决狱和引荐属吏。** 武帝方重经术，张汤请令通《尚书》《春秋》的博士弟子任廷尉属官，协审疑律。他先揣皇帝态度再立判例；遇责有时称贤属意见本应听取，受赏时又推事功给属吏。这使他的荐举和用人名声显著。 [[4]](#note-4)


<a id="event-5"></a>

5. **治淮南等王狱与御史升迁。** 张汤追穷淮南、衡山和江都事。武帝本想释放严助和伍被，张汤以伍被参与谋划、严助是近臣却私交藩王为由力争处死，帝从之。他因善安排人事、得武帝信任而长期重用，迁御史大夫另据官表。 [[5]](#note-5)


<a id="event-6"></a>

6. **国用不足及财政诸策。** 用兵、收降、灾荒和流徙使国库空虚，张汤迎合武帝之意，参与白金、五铢、盐铁及告缗等分期举措，压制富商兼并，且善从文法构罪。朝奏常到日晚，大政多取决于他，官营兴作还未得利而吏已侵渔，官民多归怨。其病时帝至住所探视。 [[6]](#note-6)


<a id="event-7"></a>

7. **商人田甲责张汤。** 田甲是商人，张汤为小吏时曾受其财助，显达后田甲仍指斥他在行义方面的缺失，传称有烈士风范。 [[7]](#note-7)


<a id="event-8"></a>

8. **御史任期总叙。** 回顾张汤居御史大夫七年后败亡，下面展开与之相连的案情。 [[8]](#note-8)


<a id="event-9"></a>

9. **李文、鲁谒居和盗宗庙钱。** 李文为御史中丞，窥求张汤罪状。张汤亲吏鲁谒居使人匿名告李，事下张汤而李被处死，张汤掩饰自己知情。赵王因盐铁之争及旧怨查谒居事。又遇人盗掘孝文园瘗钱，张汤原约同丞相谢罪却欲归责对方。谒居等细案持续发酵。 [[9]](#note-9)


<a id="event-10"></a>

10. **三长史构陷及张汤自杀。** 朱买臣、王朝、边通从前官高，做长史后常受汤折辱，遂向丞相说张汤想代相，并劾他泄露奏事给商人田信以分利。减宣也上奏谒居事，武帝派使责问；赵禹明告帝希望他自行处置。张汤上书称遭三长史所陷，自杀。 [[10]](#note-10)


<a id="event-11"></a>

11. **张安世分传题签。** 以下转入张汤子张安世的仕历及后裔。 [[11]](#note-11)


<a id="event-12"></a>

12. **记三箧亡书。** 安世字子孺，以父任为郎，因善书入尚书官署，勤于职事。武帝赴河东丢了三箧书，安世能据记忆写出，旧书购得后校对无遗，遂被擢尚书令、后迁光禄大夫。 [[12]](#note-12)


<a id="event-13"></a>

13. **辅佐霍光与受封富平。** 昭帝时霍光看重安世篤行。上官氏父子、桑弘羊等伏诛以后，霍光派安世作右将军兼光禄勋辅政；后来昭帝以辅政宿卫之功封他为富平侯。 [[13]](#note-13)


<a id="event-14"></a>

14. **霍氏覆亡与安世谨避。** 霍禹得大司马虚名而实际兵权被收，岁余谋反族诛。安世孙女敬因是霍氏外属妇而应连坐，安世忧惧，帝赦敬。安世执机密，重大决策后常称病离开、待公开诏令再派人问，迹象上尽量避名。 [[14]](#note-14)


<a id="event-15"></a>

15. **匿名荐士、不许私谢。** 受荐者来谢，安世因私谢与公荐不合而拒绝往来；有人自诉功高不迁，他也不肯因请托立办，后来此人自获升迁。幕府长史劝多引人才，安世表示君主明察，臣自修而已。 [[15]](#note-15)


<a id="event-16"></a>

16. **宽隐郎官过失。** 有郎醉后在殿上溺尿，安世称或是洒水而不欲成罪；又有郎与官婢私通，安世斥告者报怨，把处置转给官署奴仆。传借此说明他替郎官隐过的办事方式。 [[16]](#note-16)


<a id="event-17"></a>

17. **延寿出守及复归太仆。** 安世父子显贵而不自安，为儿子延寿求外任，帝先派任北地太守；一年多后怜安世老，复召延寿任左曹、太仆。官表所见迁出前职与本传所任边郡有待互考。 [[17]](#note-17)


<a id="event-18"></a>

18. **张贺保护皇曾孙及封赠。** 卫太子事败，安世为其兄张贺求得免死，以宫刑留命。张贺任掖庭令照顾刘病已，教读《诗》并出财为他迎娶许氏。宣帝即位后欲报故恩，安世推辞，改置守冢三十家；后来追谥张贺、封所养张彭祖为阳都侯，赐其孤孙张霸关内侯。安世自辞禄，朝廷把未受的钱另藏。 [[18]](#note-18)


<a id="event-19"></a>

19. **谨俭持家而获宣帝亲信。** 安世虽食邑万户，身穿粗衣，妻亲自纺织，家中数百僮仆经营产业并各有手艺，积微成富，家产胜霍光。皇帝外尊惮霍光，内心却更亲安世。 [[19]](#note-19)


<a id="event-20"></a>

20. **张延寿分传题签。** 以下转录承袭父爵的张延寿。 [[20]](#note-20)


<a id="event-21"></a>

21. **延寿辞厚租、徙国平原。** 延寿在袭侯前历九卿。袭后主封邑陈留、别邑魏郡，所得租巨，屡以功德不足请减，又托弟彭祖陈情。帝称许而合一国于平原，户数不变而收入减半。延寿死谥爱，本传记子勃继任并为散骑、谏大夫。 [[21]](#note-21)


<a id="event-22"></a>

22. **张勃分传题签。** 以下为延寿继承人张勃，表名另有异文。 [[22]](#note-22)


<a id="event-23"></a>

23. **荐陈汤而削户。** 元帝初命列侯举茂材，张勃荐陈汤，因陈汤获罪减封二百户，死谥缪。陈汤后来在西域立功，世人因此说张勃有知人之明。子张临嗣侯。 [[23]](#note-23)


<a id="event-24"></a>

24. **张临分传题签。** 以下叙承接富平侯的张临。 [[24]](#note-24)


<a id="event-25"></a>

25. **张临以桑霍为戒。** 张临谦俭，登宫殿常想到桑、霍败亡。临终分财宗族故旧，令薄葬、不起坟。生前尚敬武公主，子张放袭侯。 [[25]](#note-25)


<a id="event-26"></a>

26. **张放分传题签。** 以下叙成帝近臣张放。 [[26]](#note-26)


<a id="event-27"></a>

27. **张放婚礼、宿卫和微行。** 成帝欲仿武帝与近臣游乐，张放以公主子聪敏受宠。他迎娶许嘉女，皇帝赐第宅、御用服饰，供给优厚。任侍中、中郎将，监平乐屯兵，仪比将军，常随帝微服至甘泉、长杨、五柞，在长安走马斗鸡。 [[27]](#note-27)


<a id="event-28"></a>

28. **外戚告发与群臣劾张放。** 成帝诸舅妒张放恩宠，太后因此归咎其怂恿荒游。丞相薛宣、御史翟方进列他纵容奴从暴行、妨碍使者捕人、令党徒伤人和攻击乐府官寺等事，称不宜继续宿卫，请免官遣还封国。 [[28]](#note-28)


<a id="event-29"></a>

29. **反复出入和成帝崩后死亡。** 张放先为北地都尉，很快复入；太后再使出天水属国，永始、元延有多次日食而久未回。为母疾召还，继出任河东都尉，再任侍中光禄大夫。被翟方进再劾后由帝赐钱遣国，成帝崩后张放悲泣而死。 [[29]](#note-29)


<a id="event-30"></a>

30. **出击乌桓与张霍两家盛衰。** 张千秋、霍禹皆以中郎将从范明友击乌桓。霍光试问行军形势，千秋能画地成图、禹只说见于文书，光叹霍衰张兴。霍氏覆亡后，张氏子孙仍多在内朝任职，堪与金氏和外戚相比。 [[30]](#note-30)


<a id="event-31"></a>

31. **张纯分传题签。** 以下叙张放嗣子张纯。 [[31]](#note-31)


<a id="event-32"></a>

32. **张纯在新莽保爵，东汉改封。** 张纯持身恭俭，熟谙汉制旧事，虽经王莽未失爵。入建武后升至大司空，并改以富平旧属之乡为封地，号武始侯。改封与终于位三公各有先后。 [[32]](#note-32)


<a id="event-33"></a>

33. **张氏三迁与返杜陵。** 张汤本居杜陵；张安世一支曾随武、昭、宣三朝陵区迁居，前后三迁而最终回杜陵。 [[33]](#note-33)


<a id="event-34"></a>

34. **史家评议题签。** 本卷传叙结束，以下是班固的合论。 [[34]](#note-34)


<a id="event-35"></a>

35. **张氏得保富平。** 冯商称张汤与留侯同祖，太史公未言，编传存疑。班固说汉侯多而富平传世久；张汤虽严酷遇祸，荐贤是家声所凭，安世持盈有道，张贺扶养曾孙的旧恩也有助于后世。 [[35]](#note-35)

### 4. 援经决狱和引荐属吏

[返回正文第4条](#event-4)

<a id="hs059-p004"></a>

**[《汉书·张汤传》P004](../../拆分史书/汉书/卷059.md#p004)** · [仓内TXT L8162—L8162](../../拆分史书/汉书/卷059.md#part-1-L8162)

> 是時，上方鄉文學，湯決大獄，欲傅古義，乃請博士弟子治《尚書》、《春秋》，補廷尉史，平亭疑法。奏讞疑，必奏先為上分別其原，上所是，受而著讞法廷尉挈令，揚主之明。奏事即譴，湯摧謝，鄉上意所便，必引正監掾史賢者，曰：「固為臣議，如上責臣，臣弗用，愚抵此。」罪常釋。間即奏事，上善之，曰：「臣非知為此奏，乃監、掾、史某所為。」其欲薦吏，揚人之善、解人之過如此。所治即上意所欲罪，予監吏深刻者；即上意所欲釋，予監吏輕平者。所治即豪，必舞文巧詆；即下戶羸弱，時口言「雖文致法，上裁察。」於是往往釋湯所言。湯至於大吏，內行修，交通賓客飲食，於故人子弟為吏及貧昆弟，調護之尤厚，其造請諸公，不避寒暑。是以湯雖文深意忌不專平，然得此聲譽。而深刻吏多為爪牙用者，依於文學之士。丞相弘數稱其美。

> 河東人李文，故嘗與湯有隙，已而為御史中丞，薦數從中文事有可以傷湯者，不能為地。湯有所愛史魯謁居，知湯弗平，使人上飛變告文奸事，事下湯，湯治論殺文，而湯心知謁居為之。上問：「變事從跡安起？」湯陽驚曰：「此殆文故人怨之。」謁居病臥閭里主人，湯自往視病，為謁居摩足，趙國以冶鑄為業，王數訟鐵官事，湯常排趙王。趙王求湯陰事。謁居嘗案趙王，趙王怨之，並上書告：「湯大臣也，史謁居有病，湯至為摩足，疑與為大奸。」事下延尉。謁居病死，事連其弟，弟繫導官。湯亦治它囚導官，見謁居弟，欲陰為之，而陽不省。謁居弟不知而怨湯，使人上書，告湯與謁居謀，共變李文。事下減宣。宣嘗與湯有隙，及得此事，窮竟其事，未奏也。會人有盜發孝文園瘞錢，丞相青翟朝，與湯約俱謝，至前，湯念獨丞相以四時行園，當謝，湯無與也，不謝。丞相謝，上使御史案其事。湯欲致其文丞相見知，丞相患之。三長史皆害湯，欲陷之。

### 10. 三长史构陷及张汤自杀

[返回正文第10条](#event-10)

> 始，長史硃買臣素怨湯，語在其傳。王朝，齊人，以術至右內史。邊通學短長，剛暴人也。官至濟南相。故皆居湯右，已而失官，守長史，詘體於湯。湯數行丞相事，知此三長史素貴，常陵折之。故三長史合謀曰：「始湯約與君謝，已而賣君；今欲劾君以宗廟事，此欲代君耳。吾知湯陰事。」使吏捕案湯左田信等，曰湯且欲為請奏，信輒先知之，居物致富，與湯分之。及它奸事。事辭頗聞。上問湯曰：「吾所為，賈人輒知，益居其物，是類有以吾謀告之者。」湯不謝，又陽驚曰：「固宜有。」減宜亦奏謁居事。上以湯懷詐面欺，使使八輩簿責湯。湯具自道無此，不服。於是上使趙禹責湯。禹至，讓湯曰：「君何不知分也！君所治，夷滅者幾何人矣！今人言君皆有狀，天子重致君獄，欲令君自為計，何多以對為？」湯乃為書謝曰：「湯無尺寸之功，起刀筆吏，陛下幸致位三公，無以塞責。然謀陷湯者，三長史也。」遂自殺。

> 初，安世長子千秋與霍光子禹俱為中郎將，將兵隨度遼將軍范明友擊烏桓。還，謁大將軍光，問千秋戰鬥方略，山川形勢，千秋口對兵事，畫地成圖，無所忘失。光復問禹，禹不能記，曰：「皆有文書。」光由是賢千秋，以禹為不材，歎曰：「霍氏世衰，張氏興矣！」及禹誅滅，而安世子孫相繼，自宣、元以來為侍中、中常侍、諸曹散騎、列校尉者凡十餘人。功臣之世，唯有金氏、張氏，親近寵貴，比於外戚。

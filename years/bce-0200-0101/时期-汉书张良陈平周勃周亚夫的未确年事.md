# 汉书张良陈平周勃周亚夫的未确年事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **五世相韩与张良求报。** 张良字子房，祖父张开地相韩三王，父张平相韩二王，悼惠王二十三年死，二十年后秦灭韩。张良少未仕韩，却为报五世相韩之恩，宁不葬弟，散家财募刺客。 [[1]](#note-1)


<a id="event-2"></a>

2. **下邳圯上授书与匿项伯。** 老者在桥上故意掉鞋，命张良取回并跪献；几次约见故意先至，张良终于半夜先到，得授一编，称读后可为王者师，并说十三年后济北谷城山下黄石即自己。张良认出所授为太公兵法，时常诵习。在下邳任侠，也收匿杀人逃亡的项伯。 [[2]](#note-2)


<a id="event-3"></a>

3. **劝用疑兵和乘隙破秦。** 张良引兵从刘邦破韩十余城，击杨熊，经宛到武关。到嶢关时他劝先虚张旗帜、按五万人备食，使郦食其以重宝诱秦将。秦将愿同袭咸阳，他又指出士卒未必从将，宜趁其松懈进击。汉军乘势破秦，在蓝田再战，入咸阳受子婴降。 [[3]](#note-3)


<a id="event-4"></a>

4. **多病而专画策。** 张良因多病，未独自统兵，常为刘邦谋划，间或随军。 [[4]](#note-4)


<a id="event-5"></a>

5. **导引与辟谷。** 张良随高帝入关后因病练导引、辟谷，闭门一年有余。 [[5]](#note-5)


<a id="event-6"></a>

6. **张良自足而欲从赤松子。** 张良随高帝击代、用奇计下马邑，参与立萧相国等；传只著关乎存亡之策。张良说已由平民到封万户、为帝师，志愿已足，欲从赤松子游。高帝崩，吕后以白驹过隙劝他恢复饮食。六年后张良卒，谥文成。 [[6]](#note-6)


<a id="event-7"></a>

7. **取黄石与伏腊祭祀。** 张良称在圯上受书十三年后随高帝过济北，果得黄石，珍宝祭祀，死后合葬。后人伏、腊上墓亦祭此石，这是传中承接老父授书的记事。 [[7]](#note-7)


<a id="event-8"></a>

8. **陈平少贫好学。** 陈平是阳武户牖乡人，贫而爱读书、治黄老，哥哥陈伯耕田使他专心求学。嫂嫌他不事生产、出言奚落，陈伯闻后把妻休弃。 [[8]](#note-8)


<a id="event-9"></a>

9. **张负嫁孙与陈平分社肉。** 张负见陈平虽住陋巷，常有长者来访，执意把前五任丈夫均早死的孙女嫁给他，借以聘礼及饮宴之资，嘱其善待陈平兄嫂。陈平经济宽裕、交游渐广；在社祭中分肉均平，自比若宰天下也能公平。 [[9]](#note-9)


<a id="event-10"></a>

10. **事楚受赏及脱身渡河。** 陈平归项羽、随入关破秦受卿爵，后领在楚的魏客降殷王，拜都尉受金。汉又攻下殷，项羽欲诛平殷的人。陈平交还金印、独自逃走，船夫疑他藏有金玉，见他脱衣帮撑船才停止劫杀念头。 [[10]](#note-10)


<a id="event-11"></a>

11. **劝立韩信及初受户牖。** 韩信破齐遣使求假王，刘邦怒骂，陈平以足暗示，刘邦醒悟改而厚待来使，遣张良立韩信为真王；陈平此阶段受户牖乡，以谋助终灭楚。 [[11]](#note-11)


<a id="event-12"></a>

12. **随征及六出奇计。** 陈平作为护军中尉曾随击臧荼、陈豨、黥布；本传总说他六出奇计，每次益封，若干谋略未传。 [[12]](#note-12)


<a id="event-13"></a>

13. **王陵初不从汉与母死。** 王陵是沛县豪侠，刘邦微时兄事之。刘邦起兵后王陵聚数千人居南阳，汉兵还击项羽才归。项羽扣王陵母招降，王母令使者劝儿子一心事汉，自刎，项羽怒而烹尸。王陵因迟归又善高祖旧仇雍齿，较晚封安国侯。 [[13]](#note-13)


<a id="event-14"></a>

14. **陈平与审食其分相。** 王陵退后陈平调右、审食其为左。审食其曾在彭城败后陪吕后为质，因从破楚封侯，受吕后宠，任相后主要监宫，百官也经他决事。 [[14]](#note-14)


<a id="event-15"></a>

15. **吕须谗陈平。** 吕须常借旧日逮樊哙事诋陈平饮酒戏妇、不治职事。陈平听后更加放纵，吕后反而喜，当面告诉陈平不必害怕吕须的毁谤。 [[15]](#note-15)


<a id="event-16"></a>

16. **诛吕迎文帝与周陈分相。** 吕后时陈平暂顺其立诸吕为王。吕后死后陈平与周勃合计诛诸吕，迎立文帝。审食其一度被免又被举为相；陈平认为诛吕周勃功大，辞上位，周勃任右丞相居首，陈平任左，获赐金千斤及益邑三千户。 [[16]](#note-16)


<a id="event-17"></a>

17. **陈平答宰相所主并独相。** 文帝询狱案数与财谷出纳，周勃无以答，陈平说应分别问廷尉与治粟内史，宰相应辅君治理并使百官各得其职。周勃羞惭又责陈平未早教，陈平答不应强答具体数目。周勃后辞相，陈平独相。 [[17]](#note-17)


<a id="event-18"></a>

18. **陈平自戒阴谋与陈掌续封不成。** 陈平认为自己用阴谋太多，有违道家所禁，后世失侯便难再起。曾孙陈掌虽因卫氏亲戚而贵，仍未取回封爵。 [[18]](#note-18)


<a id="event-19"></a>

19. **周勃家世与微时生计。** 周勃先世为卷人，后来迁沛。他早年织薄曲而生，常在丧事吹箫，服材官时能拉强弓。 [[19]](#note-19)


<a id="event-20"></a>

20. **周勃起沛至入秦。** 周勃以中涓从沛公，随攻胡陵、方与、丰、砀、下邑，受爵五大夫。继战章邯、东阿、濮阳、定陶、雍丘等地。项梁死后刘邦以武安侯任砀郡长，命周勃为襄贲令；后率攻成武、长社、颍阳等，经南阳、武关、嶢关、蓝田而达咸阳。 [[20]](#note-20)


<a id="event-21"></a>

21. **汉中还定三秦与封绛。** 封汉王后，刘邦赐周勃威武侯，入汉中升将军，回军定三秦受怀德食邑，多战表现居首；围取废丘，继战益已、上邽，守嶢关、敖仓，追项籍，楚亡后定泗水、东海二十二县。又随高帝击臧荼，剖符食绛八千二百八十户。 [[21]](#note-21)


<a id="event-22"></a>

22. **出代对韩王信与匈奴。** 周勃击降霍人，至武泉破胡骑，再破韩王信军于铜鞮、晋阳、硰石，收太原六城、楼烦三城，在平城下与胡骑交战，所部战功多。后当太尉。 [[22]](#note-22)


<a id="event-23"></a>

23. **周勃平燕与统计战功。** 周勃替樊哙帅军，夺蓟，俘获卢绾将相，在上兰、沮阳破敌追到长城，定上谷、右北平、辽东、渔阳各县。传末总列周勃随高帝及独立统军俘获官员、破军拔城之数。 [[23]](#note-23)


<a id="event-24"></a>

24. **木强敦厚而少文饰。** 高帝认为周勃敦厚可托大事。周勃不好经籍文辞，召说士时直催其快说，足见其质朴少文饰。 [[24]](#note-24)


<a id="event-25"></a>

25. **胜之失爵与亚夫为条侯。** 周勃文帝十一年死，谥武，子胜之嗣侯，因杀人死而国除。许负曾相时任河内守的亚夫，言将得侯、贵为将相，最终饿死，亚夫以亲兄有嗣且尊贵何以饿死相问。后来胜之获罪，文帝选周勃诸子贤者为条侯，众推亚夫。 [[25]](#note-25)


<a id="event-26"></a>

26. **亚夫升相与争废栗太子。** 平乱后太尉继续设置，周亚夫后任丞相。反对废栗太子后渐被景帝疏远，梁孝王朝见也向太后说他的短处。 [[26]](#note-26)


<a id="event-27"></a>

27. **举高帝约制止封王信。** 窦太后要封皇后兄王信，借窦长君生前未封为憾敦促景帝；周亚夫援非刘不王、无功不侯之约，认为王信无功不可封，皇帝暂止。 [[27]](#note-27)


<a id="event-28"></a>

28. **宫中赐肉与皇帝疑忌。** 景帝赐亚夫未切大肉而不置箸，亚夫叫尚席取箸；被皇帝笑问，免冠谢而趋出。景帝认为他怏怏不平，难以辅佐少君。 [[28]](#note-28)


<a id="event-29"></a>

29. **续绛侯后及王信受封的异序。** 朝廷另封周勃子周坚为平曲侯续祭，周建德继封，曾为太子太傅，因酎金及后罪失官失国。本篇将王信封盖排在亚夫饿死后，与《侯表》异序；平帝元始二年复封周勃玄孙之子周恭为绛侯，千户。 [[29]](#note-29)


<a id="event-30"></a>

30. **班固论张良、陈平、王陵与周勃。** 班固记张良外貌温柔与智勇名声不同，又感圯上受书之异及数次助高祖脱困。陈平从社祭起志、经魏楚纠纷成汉谋臣，全身于吕后朝；王陵廷争辞退各守其志。周勃由质朴布衣成为扶刘重臣；高祖临终判断陈平有智、王陵戆直、周勃可安刘氏，后来如言。 [[30]](#note-30)

> 居頃之，上益明習國家事，朝而問右丞相勃曰：「天下一歲決獄幾何？」勃謝不知。問「天下錢穀一歲出入幾何？」勃又謝不知。汗出洽背，媿不能對。上亦問左丞相平。平曰：「各有主者。」上曰：「主者為誰乎？」平曰：「陛下即問決獄，責廷尉；問錢穀，責治粟內史。」上曰：「苟各有主者，而君所主何事也？」平謝曰：「主臣！陛下不知其駑下，使待罪宰相。宰相者，上佐天子理陰陽，順四時，下遂萬物之宜，外填撫四夷諸侯，內親附百姓，使卿大夫各得任其職也。」上稱善。勃大慚，出而讓平曰：「君獨不素教我乎！」平笑曰：「君居其位，獨不知其任邪？且陛下即問長安盜賊數，又欲彊對邪？」於是絳侯自知其能弗如平遠矣。居頃之，勃謝病請免相，而平顓為丞相。

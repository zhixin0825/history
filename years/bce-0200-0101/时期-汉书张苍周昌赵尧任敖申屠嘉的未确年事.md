# 汉书张苍周昌赵尧任敖申屠嘉的未确年事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **张苍由秦御史归沛公。** 张苍为阳武人，爱文书、音律和历数，在秦掌管柱下的方书，获罪逃归。刘邦过阳武时张苍以客随攻南阳，一度当斩，王陵见他身躯高大肥白，替他说情赦免，遂随军西入武关。 [[1]](#note-1)


<a id="event-2"></a>

2. **张苍平赵、相代赵及定北平侯。** 陈馀逐张耳，张耳归汉，张苍代守常山，随韩信攻赵并获陈馀。赵平后，相代备边，再相赵王张耳与其子张敖，后又徙代。燕王臧荼反，张苍以代相从平，有功封北平侯，食一千二百户。 [[2]](#note-2)


<a id="event-3"></a>

3. **张苍掌计、相淮南与御史大夫。** 张苍先任计相，改以列侯掌上计四年。萧何在相府，借重他熟悉秦图籍、郡国户籍账册和算律历的经验，让他总领各地呈报的行政统计。英布反，刘长立为淮南王，张苍为其相，传后纪累年迁御史大夫。 [[3]](#note-3)


<a id="event-4"></a>

4. **张苍任相、历议及死。** 底本载正月甲午张苍以御史大夫任相，又节写他罢改历之议、见黄龙后退黜、新垣平受宠而获罪，文帝此后罢议。下一行以纪事式载置阳陵邑、张苍卒。「丞相」在卒条是旧衔，详文见下列张苍事。 [[4]](#note-4)


<a id="event-5"></a>

5. **周昌、周苛从沛。** 分传题为周昌。他与堂兄周苛原为秦泗水卒史，刘邦破泗水守监后同来效力，各任职志和客，随沛公入关破秦。刘邦称汉王，周苛为御史大夫、周昌为中尉。 [[5]](#note-5)


<a id="event-6"></a>

6. **周昌直言，廷争不可废太子。** 周昌以强直著称。刘邦与戚姬同坐时追上急退的周昌，骑在他项上问自己何等君主，周昌直斥如桀、纣，高帝虽笑却忌惮。高帝拟以如意替刘盈，周昌口吃仍当庭坚持不奉诏。吕后在东侧室旁听，后来跪谢他保全太子。 [[6]](#note-6)


<a id="event-7"></a>

7. **赵尧劝以周昌保护如意。** 十岁的如意为赵王，刘邦担忧死后其不能自存。方与公先看出刀笔吏赵尧可接周昌的官。赵尧建议选吕后、太子和群臣都畏敬的强相，只有周昌合适。周昌哭称是贬逐，刘邦知道是降调却托付私忧，遂使周昌相赵。继而高帝任赵尧御史大夫，赵尧原有军功，又因讨陈豨功受封江邑侯。 [[7]](#note-7)


<a id="event-8"></a>

8. **赵王遇害、周昌后嗣及赵尧贬黜。** 高帝死后吕后屡召赵王，周昌托疾不遣。吕后先召走周昌，再召如意，如意到长安一月多被毒死。周昌谢病不朝，过三年去世谥悼。传至孙周意因罪除国，景帝复封孙周左车为安阳侯，亦以罪除。赵尧事惠帝终其在位，高后元年因曾为如意谋划而被治罪，改用任敖为御史大夫。 [[8]](#note-8)


<a id="event-9"></a>

9. **任敖护吕后、逐鹿守上党及后代。** 分传题为任敖。他在沛为狱吏，刘邦避吏时吕后被拘受慢待，任敖击伤经办狱吏。汉起任御史并守丰，东击楚升上党守，陈豨反时因坚守而封广阿侯一千八百户。高后时任御史大夫，三年免，文帝初去世谥懿。曾孙任越人任太常，因祭酒变酸有不敬罪而除国。 [[9]](#note-9)


<a id="event-10"></a>

10. **御史交替及张苍定律历。** 任敖之后曹窋为御史大夫，助诛诸吕，后免，张苍自淮南相继任并参与拥立文帝，文帝四年接替灌婴为相。汉初公卿多由军吏出身，张苍在掌计时整理历律，因刘邦十月到霸上而沿秦以十月为岁首，按水德尚黑；又校音律、律令及工艺尺度。在相位上完成，后世汉律历归源于他。 [[10]](#note-10)


<a id="event-11"></a>

11. **张苍长报王陵救命恩。** 张苍对安国侯王陵有父子般的礼敬，王陵死后，他任丞相仍在休假日先探视王陵夫人进奉饮食，才回自己家。 [[11]](#note-11)


<a id="event-12"></a>

12. **张苍的家族身量、晚年及著作。** 其父不足五尺，张苍及儿子各八尺左右，孙张类六尺多。免相后牙落而饮乳，家中妻妾以百计，曾怀孕者不再亲近，百余岁死。著书十八篇，论阴阳与律历。 [[12]](#note-12)


<a id="event-13"></a>

13. **申屠嘉由军功至丞相。** 分传题为申屠嘉。梁人，以能脚踏强弩的材官从击项羽，历队率、都尉及淮阳守。文帝元年访曾以二千石从高祖者，二十四人获关内侯食邑，申屠嘉食五百户。十六年升御史大夫。张苍免，文帝担心任皇后弟窦广国会被视为偏私，改用申屠嘉为相，因旧食邑封故安侯。 [[13]](#note-13)


<a id="event-14"></a>

14. **申屠嘉追究宠臣邓通失礼。** 申屠嘉清正不受私谒，邓通受文帝巨赏，其殿上怠慢激起丞相追责。申屠嘉召来免冠赤足的邓通，以高帝朝廷不容臣下嬉戏宣布当斩。邓通磕头出血仍未获原谅，文帝估计教训已足，遣持节使者召回并代为谢过。 [[14]](#note-14)


<a id="event-15"></a>

15. **历任丞相及传赞。** 申屠嘉死后，陶青、刘舍及武帝时许昌、薛泽、庄青翟、赵周先后以列侯相汉，班固评其谨慎守职而无显功。「評論」之后的赞称张苍善律历而仍行颛顼历，周昌质直，任敖以旧恩进用，申屠嘉刚毅守节却少辅政学术，和萧何、曹参、陈平有别。 [[15]](#note-15)

> 嘉為人廉直，門不受私謁。是時，太中大夫鄧通方愛幸，賞賜累巨萬。文帝常燕飲通家，其寵如是。是時，嘉入朝而通居上旁，有怠慢之禮。嘉奏事畢，因言曰：「陛下幸愛群臣則富貴之，至於朝廷之禮，不可以不肅！」上曰：「君勿言，吾私之。」罷朝坐府中，嘉為檄召通詣丞相府，不來，且斬通。通恐，入言上。上曰：「汝第往，吾今使人召若。」通至丞相府，免冠，徒跣，頓首謝嘉。嘉坐自如，弗為禮，責曰：「夫朝廷者，高皇帝之朝廷也，通小臣，戲殿上，大不敬，當斬。史今行斬之！」通頓首，首盡出血，不解。上度丞相已困通，使使持節召通，而謝丞相：「此語弄臣，君釋之。」鄧通既至，為上泣曰：「丞相幾殺臣。」

# 汉书张释之冯唐汲黯郑当时的未确年事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **论秦弊后任公车令。** 张释之陪乘，就秦政弊端据实作答，文帝回宫任他为公车令。 [[1]](#note-1)


<a id="event-2"></a>

2. **司马门举劾太子与梁王。** 太子和梁王乘车不在宫门下车，张释之止之并劾不敬。文帝向太后请罪，待薄太后使人赦后才得入，随后擢释之。 [[2]](#note-2)


<a id="event-3"></a>

3. **霸陵谈墓藏。** 文帝在霸陵望邯郸道，听慎夫人鼓瑟，想到用坚石筑椁。张释之说墓中若有令人贪求之物，封得再严也会被发掘，因敢言受重用。 [[3]](#note-3)


<a id="event-4"></a>

4. **景帝初张释之谢罪。** 文帝死、景帝继立后，释之担心当年宫门执法获追究，听王生之计入见谢罪，景帝未再责。 [[4]](#note-4)


<a id="event-5"></a>

5. **王生请廷尉结带。** 黄老处士王生让张释之当众替他系衣物，以此突显名臣肯为低微老人屈身，时人认为王生有意为之扬名。 [[5]](#note-5)


<a id="event-6"></a>

6. **出相淮南及子张挚。** 张释之事景帝一年多，终因旧事出为淮南相，年老病死。儿子张挚官至大夫，一直未能容于时俗，免后不再仕。 [[6]](#note-6)


<a id="event-7"></a>

7. **冯唐传题。** 以下为冯唐，主要叙其对文帝论用将及为魏尚辨白。 [[7]](#note-7)


<a id="event-8"></a>

8. **文帝问李齐廉颇李牧。** 冯唐祖父为赵人，家迁代又至安陵，以孝入郎。文帝念赵将李齐，冯唐说李齐不及廉颇李牧，并直言即使得此二将，文帝也未必能用。 [[8]](#note-8)


<a id="event-9"></a>

9. **景帝武帝时冯唐。** 景帝用冯唐为楚相。武帝求贤时冯唐已九十多岁，不能就任，改授其子冯遂为郎；段尾补说魏尚籍贯。 [[9]](#note-9)


<a id="event-10"></a>

10. **汲黯传题。** 以下叙汲黯以严直见惮，历任地方和中央官职。 [[10]](#note-10)


<a id="event-11"></a>

11. **汲黯的家世和初职。** 汲氏先人受卫君宠，世为卿大夫。汲黯藉父任为太子洗马，以严正见畏。 [[11]](#note-11)


<a id="event-12"></a>

12. **越事、河内火灾与赈民。** 受命察越事，汲黯到吴后回报此事不必劳使。察河内火灾时发现水旱后饥荒更急，便持节发仓，自劾矫制，武帝释其罪；下文写因直言外任。 [[12]](#note-12)


<a id="event-13"></a>

13. **东海治绩与主爵都尉。** 汲黯学黄老，把事务托付所选丞史，只责大要；虽病多静卧，东海治效显著，武帝召入任主爵都尉。 [[13]](#note-13)


<a id="event-14"></a>

14. **汲黯的性情与交游。** 汲黯傲岸，常当面责人，许多士不亲附；又尚游侠气节，慕傅伯、袁盎，与灌夫、郑当时及刘弃疾相善，屡因面谏不能久居一职。 [[14]](#note-14)


<a id="event-15"></a>

15. **对田蚡只揖与朝上切谏。** 相田蚡待中二千石不礼，汲黯只揖不拜。武帝谈治道时，汲黯又直指帝内欲多却外示仁义，朝臣为他担心。 [[15]](#note-15)


<a id="event-16"></a>

16. **严助代请病告。** 汲黯病久，严助代请休假，并说他常任职守并无过人之处，辅幼主保社稷却会坚守到不为人夺志，武帝赞同。 [[16]](#note-16)


<a id="event-17"></a>

17. **武帝对汲黯以礼相待。** 武帝见卫青、公孙弘有时仪态随意，见汲黯却须冠服；一回未冠，宁躲帐后让别人替他批奏。 [[17]](#note-17)


<a id="event-18"></a>

18. **张汤更令时的对问。** 张汤任廷尉时更定法令，汲黯在帝前当面质问，下段接写其话。 [[18]](#note-18)


<a id="event-19"></a>

19. **责更高祖约束。** 汲黯说廷尉应安国富民而使监狱少人，责张汤专更旧令、深文苛细，恐使百姓畏惧。 [[19]](#note-19)


<a id="event-20"></a>

20. **和亲、儒术与深文。** 武帝用兵招怀，汲黯主休息与和亲，批评公孙弘用儒说迎合、张汤等以深文陷人。帝益信弘、汤，汲黯之见日疏。 [[20]](#note-20)


<a id="event-21"></a>

21. **卫青受揖。** 卫青因军功和外戚地位尊贵，汲黯仍以平辈礼相处，认为有揖客反足以增其威望。卫青反而更加敬重并咨询政事。 [[21]](#note-21)


<a id="event-22"></a>

22. **军功以后意见不用。** 武帝数次对匈奴用兵得功，汲黯的和亲主张愈不获采用。 [[22]](#note-22)


<a id="event-23"></a>

23. **公孙弘和张汤后来居上。** 汲黯先为九卿，弘、汤从小吏升至与他同列，后来显贵，甚至汲黯旧属也有位过他的，引出下文积薪之讥。 [[23]](#note-23)


<a id="event-24"></a>

24. **积薪之语。** 汲黯比任官如叠柴，后来者居上。武帝以他少学、话日益过甚作答。 [[24]](#note-24)


<a id="event-25"></a>

25. **出治淮阳及逆料张汤。** 五铢改铸后楚地盗铸多，武帝以汲黯有威重，命治理淮阳。汲黯赴任前劝李息揭露张汤奸弊，李息不敢。张汤败后李息获罪；汲黯治郡清明，以诸侯相秩卒于任。 [[25]](#note-25)


<a id="event-26"></a>

26. **汲黯卒后亲族。** 帝使汲黯的弟弟和儿子得官，外甥司马安以精于仕途至九卿，牵及兄弟显达；并及同乡显达者和卫地士人仍服汲黯。 [[26]](#note-26)


<a id="event-27"></a>

27. **郑当时传题。** 以下为郑当时，字庄，传以其好客荐士及仕途起落相连。 [[27]](#note-27)


<a id="event-28"></a>

28. **郑君不肯名项籍。** 郑当时先人曾事项羽，项羽死后归汉。高祖令旧属直呼项籍之名，郑君独拒，受逐，至文帝时死。 [[28]](#note-28)


<a id="event-29"></a>

29. **好黄老而交天下长者。** 郑当时救张羽有名，做景帝太子舍人时休假便置马遍访宾朋。他喜黄老，虽少且官小，结交多是名重的长辈。 [[29]](#note-29)


<a id="event-30"></a>

30. **由郡国入朝及降秩。** 郑当时由鲁中尉经济南太守、江都相至右内史；武安侯与魏其侯争议时受贬为詹事，后任大司农。 [[30]](#note-30)


<a id="event-31"></a>

31. **郑庄待客与荐士。** 来客不问贵贱都让入门。家不经营产业，以俸禄款待，赠品止于食物；把所闻善言及时上报，并称所举的低阶属吏有才过己。 [[31]](#note-31)


<a id="event-32"></a>

32. **察河、僦运逋负和晚年。** 郑当时奉命勘决河，帝以行旅轻便称之。郑当时在朝常趋和；国用日费，任大司农时付宾客办理僦运而多亏欠，司马安揭发。郑贬庶人后复仕，卒于汝南太守任。 [[32]](#note-32)


<a id="event-33"></a>

33. **宾客离散与身后无财。** 汲黯与郑当时曾同列九卿，俱曾废退，门客渐少。郑死后家中无余财。 [[33]](#note-33)


<a id="event-34"></a>

34. **翟公题门。** 翟公任廷尉时宾客塞门，官废后门庭可张网捕雀。复位后题门，以生死、贫富、贵贱揭出交情的深浅。 [[34]](#note-34)


<a id="event-35"></a>

35. **四人各得名的缘由。** 班固总举张释之守法、冯唐谈将、汲黯直谏、郑庄荐士。末引扬雄以文帝礼遇周亚夫反问冯唐之说，认为冯唐言出有所感。 [[35]](#note-35)

### 8. 文帝问李齐廉颇李牧

[返回正文第8条](#event-8)

<a id="hs050-p012"></a>

**[《汉书·张冯汲郑传》P012](../../拆分史书/汉书/卷050.md#p012)** · [仓内TXT L7679—L7679](../../拆分史书/汉书/卷050.md#part-1-L7679)

> 馮唐，祖父趙人也。父徙代。漢興徙安陵。唐以孝著，為郎中署長，事文帝。帝輦過，問唐曰：「父老何自為郎？家安在？」具以實言。文帝曰：「吾居代時，吾尚食監高祛數為我言趙將李齊之賢，戰於鉅鹿下。吾每飲食，意未嘗不在鉅鹿也。父老知之乎？」唐對曰：「齊尚不如廉頗、李牧之為將也。」上曰：「何已？」唐曰：「臣大父在趙時，為官帥將，善李牧。臣父故為代相，善李齊，知其為人也。」上既聞廉頗、李牧為人，良說，乃拊髀曰：「嗟乎！吾獨不得廉頗、李牧為將，豈憂匈奴哉！」唐曰：「主臣！陛下雖有廉頗、李牧，不能用也。」上怒，起入禁中。良久，召唐讓曰：「公眾辱我，獨亡間處虖？」唐謝曰：「鄙人不知忌諱。」

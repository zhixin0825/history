# 汉书循吏治郡教化与水利

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **从汉初清静到文景循吏。** 篇首称萧何、曹参因秦政之弊而宽简，惠帝、高后以少扰安民，文景时吴公、文翁等以廉平和躬行教化为循吏先例。 [[1]](#note-1)


<a id="event-2"></a>

2. **武帝朝以经术治吏事。** 外战与内改法度使民力疲困，纯以教化见称者少。董仲舒、公孙弘、儿宽能经学也晓文法，分别用其学理处置行政事务。 [[2]](#note-2)


<a id="event-3"></a>

3. **昭帝朝议盐铁。** 霍光辅幼主，面对长期征战后的虚耗，起初因循旧制。始元元凤间征文学问疾苦，罢酒类专卖而盐铁之议仍在。 [[3]](#note-3)


<a id="event-4"></a>

4. **宣帝考课守相与良吏。** 宣帝在霍光死后亲理政事，考察守相言行，主张少调动太守，奖赏有成效者。篇首区别能任刑罚的地方官和以富民养民见称的王成等人。 [[4]](#note-4)


<a id="event-5"></a>

5. **文翁分传。** 小题引入蜀郡守文翁。 [[5]](#note-5)


<a id="event-6"></a>

6. **文翁选吏赴京求学。** 文翁在景帝末任蜀郡守，选张叔等小吏入京从博士习经或学律令，减省本郡开支备礼，毕业者回蜀后授较重的职务。 [[6]](#note-6)


<a id="event-7"></a>

7. **成都设学官。** 文翁招县里子弟入学，免更役，分等补吏或作孝弟力田。巡县带诸生使其传达教令，蜀人渐重入学；本传将天下郡国立学校追溯至此。 [[7]](#note-7)


<a id="event-8"></a>

8. **蜀人祀文翁。** 文翁终老于蜀，吏民建祠岁祭；作者把巴蜀重文归于长期教化。 [[8]](#note-8)


<a id="event-9"></a>

9. **王成分传。** 小题引入胶东相王成。 [[9]](#note-9)


<a id="event-10"></a>

10. **黄霸分传。** 小题引入黄霸。 [[10]](#note-10)


<a id="event-11"></a>

11. **黄霸早岁习律为吏。** 黄霸曾以入钱、入粟求官，受同胞有罪牵累后再出。任会计簿书清楚，以廉被察举，后任河南太守丞，断议合律也合人情。 [[11]](#note-11)


<a id="event-12"></a>

12. **严法下黄霸独持宽和。** 昭帝年幼，霍光诛上官桀、燕王一党后继续武帝重刑，官吏多以严酷见能，黄霸在这种风气下以宽和获名。 [[12]](#note-12)


<a id="event-13"></a>

13. **黄霸下狱、释出及治颍川。** 宣帝召黄霸任廷尉正，他决疑狱持平。代理丞相长史时因未劾夏侯胜入狱，反跟他学《尚书》，获释后以荐举为扬州刺史，再升颍川太守。 [[13]](#note-13)


<a id="event-14"></a>

14. **代理京兆、回颍川与受奖。** 黄霸代理京兆尹时因征发和军马问题遭降秩，仍遣治颍川。宣帝表彰其奉诏教化、救济和狱少重罪，赐爵、金并增秩，后来迁东宫、御史。 [[14]](#note-14)


<a id="event-15"></a>

15. **黄霸入相与张敞谏虚饰。** 五凤三年黄霸继丙吉入相，治民之长未尽施于相位。他误以张敞家飞出的鶡雀为祥瑞；张敞上奏反对以样式繁苛的教条诱导郡吏造假，帝采纳。 [[15]](#note-15)


<a id="event-16"></a>

16. **黄霸荐史高未被采纳。** 黄霸举史高为太尉。宣帝称太尉职久并于相，相宜本职教化清狱，择将相由皇帝，诘其越职。黄霸谢罪不复请议，传仍推许其治民。 [[16]](#note-16)


<a id="event-17"></a>

17. **黄霸卒与子孙承爵。** 黄霸任相至甘露三年卒，谥定侯。子赏、孙辅及后人传承侯爵，王莽时终绝；史高后来另任大司马。 [[17]](#note-17)


<a id="event-18"></a>

18. **黄霸婚事与徙居。** 传记黄霸早岁听相者评乡巫之女将富贵，娶之终身。为丞相之后举家徙杜陵。 [[18]](#note-18)


<a id="event-19"></a>

19. **朱邑分传。** 小题引入朱邑。 [[19]](#note-19)


<a id="event-20"></a>

20. **桐乡小吏至大司农。** 朱邑为桐乡啬夫时爱民少责罚，存问老人孤寡。由郡吏举贤良，任北海太守以治行征为大司农，厚故旧而不徇私请。 [[20]](#note-20)


<a id="event-21"></a>

21. **张敞劝朱邑举人。** 张敞写信，以陈平赖魏无知、韩信赖萧何说明荐人之要，请不拘伊吕式的大才。朱邑多举荐，禄赐助亲族乡里，自家少蓄财。 [[21]](#note-21)


<a id="event-22"></a>

22. **朱邑葬在桐乡。** 朱邑爱故吏地桐乡，遗命葬在那里，称百姓祭奉会比后世子孙周到。乡人果为营墓立祠。 [[22]](#note-22)


<a id="event-23"></a>

23. **龚遂分传。** 小题引入龚遂。 [[23]](#note-23)


<a id="event-24"></a>

24. **龚遂谏昌邑王刘贺。** 龚遂屡以经义和亡国之鉴劝刘贺远群小，选通经者陪侍而不被久用。刘贺废后昌邑诸臣多诛，龚遂及王阳因屡谏减死；王阳即他传所称王吉。 [[24]](#note-24)


<a id="event-25"></a>

25. **龚遂任渤海太守并安抚。** 面对灾荒和盗起，龚遂请宽缓处置。入郡遣还迎兵，分别持农具和持械者，许解散还田，开仓贷贫并用良吏安抚。 [[25]](#note-25)


<a id="event-26"></a>

26. **劝农桑、畜养与弃械。** 龚遂定各户种植养畜的办法，劝民卖剑刀买牛犊，督春耕秋收，积聚增，讼狱渐息。 [[26]](#note-26)


<a id="event-27"></a>

27. **入朝问治与任水衡。** 王生劝龚遂把治郡的成绩归于朝廷，龚遂当面再明言是王生教他。宣帝以龚遂年长改拜水衡都尉，任王生为丞；龚遂终于职上。 [[27]](#note-27)


<a id="event-28"></a>

28. **召信臣分传。** 小题引入召信臣。 [[28]](#note-28)


<a id="event-29"></a>

29. **召信臣任县长和太守。** 召信臣明经入仕，历谷阳、上蔡与零陵，病归后被征任谏大夫，再出守南阳。 [[29]](#note-29)


<a id="event-30"></a>

30. **南阳兴水利与定用水章程。** 召信臣察水源、凿沟渠、置水门以扩灌，刻石规定分水，抑奢劝农，乡人称召父。刺史上报民富得赏，后迁河南太守。 [[30]](#note-30)


<a id="event-31"></a>

31. **召信臣任少府与省用。** 竟宁中召信臣入为少府，奏省僻远宫室修设、演戏和兵器什物，也停以温室方式催长冬菜供御，后来老年卒官。 [[31]](#note-31)

### 4. 宣帝考课守相与良吏

[返回正文第4条](#event-4)

<a id="hs089-p004"></a>

**[《汉书·循吏传》P004](../../sources/摘录/汉书-卷089-循吏传.md#p004)** · [仓内TXT L9548—L9548](../../sources/本地分卷/汉书/汉书-卷089.md#L9548)

> 及至孝宣，繇仄陋而登至尊，興于閭閻，知民事之谡難。自霍光薨後始躬萬機，厲精為治，五日一聽事，自丞相已下各奉職而進。及拜刺史守相，輒親見問，觀其所繇，退而考察所行以質其言，有名實不相應，必知其所以然。常稱曰：「庶民所以安其田里而亡歎息愁恨之心者，政平訟理也。與我共此者，其唯良二千石乎！」以為太守，吏民之本也，數變易則下不安，民知其將久，不可欺罔，乃服從其教化。故二千石有治理效，輒以璽書勉厲，增秩賜金，或爵至關內侯，公卿缺則選諸所表以次用之。是故漢世良吏，於是為盛，稱中興焉。若趙廣漢、韓延壽、尹翁歸、嚴延年、張敞之屬，皆稱其位，然任刑罰，或抵罪誅。王成、黃霸、朱邑、龔遂、鄭弘、召信臣等，所居民富，所去見思，生有榮號，死見奉祀，此廩廩庶幾德讓君子之遺風矣。

### 13. 黄霸下狱、释出及治颍川

[返回正文第13条](#event-13)

<a id="hs089-p014"></a>

**[《汉书·循吏传》P014](../../sources/摘录/汉书-卷089-循吏传.md#p014)** · [仓内TXT L9558—L9558](../../sources/本地分卷/汉书/汉书-卷089.md#L9558)

> 會宣帝即位，在民間時知百姓苦吏急也，聞霸持法平，召以為廷尉正，數決疑獄，庭中稱平。守丞相長史，坐公卿大議廷中知長信少府夏侯勝非議詔書大不敬，霸阿從不舉劾，皆下廷尉，繫獄當死。霸因從勝受尚書獄中，再隃冬，積三歲乃出，語在勝傳。勝出，復為諫大夫，令左馮翊宋畸舉霸賢良。勝又口薦霸於上，上擢霸為揚州刺史。三歲，宣帝下詔曰：「制詔御史：其以賢良高第揚州刺史霸為潁川太守，秩比二千石，居官賜車蓋，特高一丈，別駕主簿車，緹油屏泥於軾前，以章有德。」

> 竟寧中，徵為少府，列於九卿，奏請上林諸離遠宮館稀幸御者，勿復繕治共張，又奏省樂府黃門倡優諸戲，及宮館兵弩什器減過泰半。太官園種冬生蔥韭菜茹，覆以屋廡，晝夜然蘊火，待溫氣乃生，信臣以為此皆不時之物，有傷於人，不宜以奉供養，及它非法食物，悉奏罷，省費歲數千萬。信臣年老以官卒。

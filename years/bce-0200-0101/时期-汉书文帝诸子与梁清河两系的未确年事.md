# 汉书文帝诸子与梁清河两系的未确年事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **文帝四子。** 窦后生景帝和梁孝王刘武。别的嫔御生刘参与刘揖。 [[1]](#note-1)


<a id="event-2"></a>

2. **梁孝王传题。** 以下为刘武始封于代、徙淮阳及徙梁后的行事。 [[2]](#note-2)


<a id="event-3"></a>

3. **历次入朝与兄终弟及之语。** 刘武多次入朝，文帝崩后仍如此。景帝酒中表示死后可传位给弟弟，窦太后欢喜；窦婴以正统传子相谏，刘武虽辞谢而心喜。 [[3]](#note-3)


<a id="event-4"></a>

4. **梁的地势、战功及宫苑。** 叛乱次年汉立太子。梁兼至亲、军功和封地丰厚，刘武受太后优待，扩建睢阳与东苑，置宫室复道、拟用天子仪卫，招纳四方游士并聚兵械珍宝。建设经历一段时期。 [[4]](#note-4)


<a id="event-5"></a>

5. **最后入朝与梁王死。** 刘武最后一次入朝，求留未获准。回国不乐，见异牛心恶，后来病热而卒。所叙月份须与本纪互校。 [[5]](#note-5)


<a id="event-6"></a>

6. **梁府余财。** 刘武死后库中尚存大量黄金，传文以同等规模形容其他财宝。 [[6]](#note-6)


<a id="event-7"></a>

7. **代孝王传题。** 以下转叙刘参与他在代、清河一系的后裔。 [[7]](#note-7)


<a id="event-8"></a>

8. **刘参、刘登至清河王。** 刘参由太原迁代，并得收复太原，仍都晋阳，共三次入朝。儿子刘登、孙刘义相继为代王；朝廷为拓关塞、以常山为屏障，将刘义从代迁到清河，继任者为刘汤、刘年。 [[8]](#note-8)


<a id="event-9"></a>

9. **刘年与女弟则。** 冀州刺史追奏刘年从太子时就与妹妹则私通，刘年即位后则生子，本段最后的引号由下段接续。 [[9]](#note-9)


<a id="event-10"></a>

10. **则送子入宫及刘年废。** 女婿不肯养王子，则把孩子送府。国相限制通行，刘年令叔父往来接应多年；最终朝廷废年为庶人，迁房陵，给小邑俸养。 [[10]](#note-10)


<a id="event-11"></a>

11. **刘如意继代孝王。** 元始二年，王莽请立废王刘年弟之子刘如意为广宗王，以续代孝王刘参之祀；改朝后国绝。 [[11]](#note-11)


<a id="event-12"></a>

12. **梁怀王传题。** 以下区分最初居梁的刘揖及后入主的刘武。 [[12]](#note-12)


<a id="event-13"></a>

13. **梁怀王坠马与刘武继梁。** 文帝幼子刘揖喜好诗书，深得帝爱，坠马早亡而无嗣，梁国被撤。次年另让刘武徙王于梁。 [[13]](#note-13)


<a id="event-14"></a>

14. **济川王明杀中尉。** 济川王刘明射杀国中尉，朝臣请诛，帝改废迁房陵，济川封国撤除。 [[14]](#note-14)


<a id="event-15"></a>

15. **梁旁支四国绝。** 刘武的非嫡长支系四王均未能把王位传给下一代。 [[15]](#note-15)


<a id="event-16"></a>

16. **梁平王后宫亲属。** 刘襄生母是陈太后，父亲的生母是李太后。任后是刘襄所宠的王后，争尊之事与这几重亲属关系有关。 [[16]](#note-16)


<a id="event-17"></a>

17. **任后夺膑尊。** 刘武生前命子孙保存贵重膑尊。任后坚持要它，刘襄强取以赠；刘襄母子与李太后也屡有龃龉。 [[17]](#note-17)


<a id="event-18"></a>

18. **犴反告发梁王。** 睢阳人犴反为父报仇杀人，被追捕后披露刘襄与祖母争器。地方官也知梁王宫中事，藉此牵出审治，朝廷削地而保留其王爵。 [[18]](#note-18)


<a id="event-19"></a>

19. **梁太傅请限刘立。** 鸿嘉间刘立屡犯法，太傅请限制出宫、撤出车马兵杖及限制财物私赠。朝廷准奏，刘立仍数次伤人。 [[19]](#note-19)


<a id="event-20"></a>

20. **刘立对园子行淫。** 园子是荒王的妹妹、刘立舅任宝之妻。任宝警告园子也是刘立的姑辈，刘立仍与之通奸。 [[20]](#note-20)


<a id="event-21"></a>

21. **谷永请宽梁王。** 梁相禹奏刘立怨怼朝廷，查案牵出淫乱。有司请诛，谷永据礼制与春秋书法，主张为宗室隐私留余地，帝未处死刘立。 [[21]](#note-21)


<a id="event-22"></a>

22. **梁王又杀伤属吏。** 元延间刘立因怨杀相属、睢阳丞等，又灭口、殴人、谋劫死囚。有司再请诛，朝廷削五县。 [[22]](#note-22)


<a id="event-23"></a>

23. **廷尉与大鸿胪讯梁王。** 建平间刘立再杀人，廷尉赏、大鸿胪由持节讯问，向傅、相、中尉追究其屡蒙宽宥、不念改过的事实。 [[23]](#note-23)


<a id="event-24"></a>

24. **刘立免冠服罪。** 刘立把自己的恶行归因于幼孤、内廷狎习和属吏不善辅导，惧而请得自新；朝廷处置仍留余地。 [[24]](#note-24)


<a id="event-25"></a>

25. **赞语论梁僭侈。** 班固把梁之富盛归于亲属所得的膏腴地与汉初积累，批评刘武恃宠、车服僭越。异牛与忧卒相连是传文的解释。 [[25]](#note-25)

### 21. 谷永请宽梁王

[返回正文第21条](#event-21)

<a id="hs047-p034"></a>

**[《汉书·文三王传》P034](../../拆分史书/汉书/卷047.md#p034)** · [仓内TXT L7562—L7562](../../拆分史书/汉书/卷047.md#part-1-L7562)

> 積數歲，永始中，相禹奏立對外家怨望，有惡言。有司案驗，因發淫亂事，奏立禽獸行，請誅。太中大夫谷永上疏曰：「臣聞『禮，天子外屏，不欲見外』也。是故帝王之意，不窺人閨門之私，聽聞中冓之言。春秋為親者諱。《詩》云『戚戚兄弟，莫遠具爾』。今梁王年少，頗有狂病，始以惡言按驗，既亡事實，而發閨門之私，非本章所指。王辭又不服，猥強劾立，傅致難明之事，獨以偏辭成罪斷獄，亡益於治道。汙衊宗室，以內亂之惡披布宣揚於天下，非所以為公族隱諱，增朝廷之榮華，昭聖德之風化也。臣愚以為王少，而父同產長，年齒不倫；梁國之富，足以厚聘美女，招致妖麗；父同產亦有恥辱之心。案事者乃驗問惡言，何故猥自發舒？以三者揆之，殆非人情，疑有所迫切，過誤失言，文吏躡尋，不得轉移。萌牙之時，加恩勿治，上也。既已案驗舉憲，宜及王辭不服，詔廷尉選上德通理之吏，更審考清問，著不然之效，定失誤之法，而反命於下吏，以廣公族附疏之德，為宗室刷汙亂之恥，甚得治親之誼。」天子由是寢而不治。

### 23. 廷尉与大鸿胪讯梁王

[返回正文第23条](#event-23)

<a id="hs047-p036"></a>

**[《汉书·文三王传》P036](../../拆分史书/汉书/卷047.md#p036)** · [仓内TXT L7564—L7564](../../拆分史书/汉书/卷047.md#part-1-L7564)

> 哀帝建平中，立復殺人。天子遣廷尉賞、大鴻臚由持節即訊。至，移書傅、相、中尉曰：「王背策戒，誖暴妄行，連犯大辟，毒流吏民。比比蒙恩，不伏重誅，不思改過，復賊殺人。幸得蒙恩，丞相長史、大鴻臚丞即問。王陽病抵讕，置辭驕嫚，不首主令，與背畔亡異。丞相、御史請收王璽綬，送陳留獄。明詔加恩，復遣廷尉、大鴻臚雜問。今王當受詔置辭，恐復不首實對。書曰：『至于再三，有不用，我降爾命。』傅、相、中尉皆以輔正為職，『虎兕出於匣，龜玉毀於匱中，是誰之過也？』書到，明以誼曉王。敢復懷詐，罪過益深。傅、相以下，不能輔導，有正法。」

### 24. 刘立免冠服罪

**[《汉书·文三王传》P037](../../拆分史书/汉书/卷047.md#p037)** · [仓内TXT L7565—L7565](../../拆分史书/汉书/卷047.md#part-1-L7565)

> 立惶恐，免冠對曰：「立少失父母，孤弱處深宮中，獨與宦者婢妾居，漸漬小國之俗，加以質性下愚，有不可移之姿。往者傅相亦不純以仁誼輔翼立，大臣皆尚苛刻，刺求微密。讒臣在其間，左右弄口，積使上下不和，更相脐伺。宮殿之裏，毛氂過失，亡不暴陳。當伏重誅，以視海內，數蒙聖恩，得見貰赦。今立自知賊殺中郎曹將，冬月迫促，貪生畏死，即詐僵仆陽病，徼幸得踰於須臾。謹以實對，伏須重誅。」時冬月盡，其春大赦，不治。

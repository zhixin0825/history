# 汉书景帝十三子的宫廷与封国后事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **景帝诸子母系。** 十四子中武帝由王皇后所生，其余十三子分出自栗姬、程姬、贾夫人、唐姬和王夫人五系；两个王氏按纪传区分。 [[1]](#note-1)


<a id="event-2"></a>

2. **河间献王小目。** 以下为刘德治学、献雅乐和河间世系。 [[2]](#note-2)


<a id="event-3"></a>

3. **河间王刘德收书立学。** 刘德景帝前二年受封，乐求先秦真书，给献书者精抄副本和金帛而收藏原本。所录《周官》等古文为经传说记，设毛诗、左氏春秋博士，亲行儒礼，吸引山东诸儒。 [[3]](#note-3)


<a id="event-4"></a>

4. **河间王献雅乐对策。** 武帝时入朝献雅乐，答三雍宫及三十多项策问，以道术推论，文约而指明。 [[4]](#note-4)


<a id="event-5"></a>

5. **河间刘元罪案及废死。** 刘元纳他国故姬，刺史的案子涉及七人被迫自杀。先削二县，后因杀少史留贵之母被废徙房陵。他在迁地又因乘朱轮、殴妻受查，病死。案发、废和卒各有先后。 [[5]](#note-5)


<a id="event-6"></a>

6. **复封刘良和哀帝增户。** 成帝立刘元之弟上郡库令刘良续祀。刘良仿献王之行，尽礼守母丧，哀帝旌表并增一万户。其子刘尚后继，王莽时代绝。 [[6]](#note-6)


<a id="event-7"></a>

7. **临江哀王小目。** 以下是先封临江的刘阏。 [[7]](#note-7)


<a id="event-8"></a>

8. **临江闵王小目。** 以下是景帝原太子刘荣，由废储迁王临江。 [[8]](#note-8)


<a id="event-9"></a>

9. **鲁恭王小目。** 以下为刘余及鲁国传世。 [[9]](#note-9)


<a id="event-10"></a>

10. **刘余迁鲁与好尚。** 先封淮阳，七国之乱平后迁鲁。好治宫苑、畜狗马，晚年喜声乐，少好辞文，口吃难言。 [[10]](#note-10)


<a id="event-11"></a>

11. **鲁王先后与哀帝续封。** 刘余后传光、庆忌、劲、晳。刘光早好声乐车马，暮年吝财。晳无后而绝；哀帝复封顷王子郚乡侯刘闵，至王莽又绝。 [[11]](#note-11)


<a id="event-12"></a>

12. **坏孔宅得古文经。** 刘余欲就孔子旧宅增广宫室，传称闻钟磬琴瑟声便不敢续拆，从壁中发现古文经传。 [[12]](#note-12)


<a id="event-13"></a>

13. **江都易王小目。** 以下为刘非迁江都，及其次代江都王的败亡。 [[13]](#note-13)


<a id="event-14"></a>

14. **刘非参战有功迁江都。** 先封汝南。反吴时年十五请率兵，获将军印，平乱后王吴旧地，获赐天子旗。元光间又请击匈奴未获准，平日好武力、宫馆及游士；后子刘建继位。 [[14]](#note-14)


<a id="event-15"></a>

15. **刘建从太子时的奸杀。** 刘建强留梁蚡女并杀梁蚡，官府因赦未治。父丧未葬又淫父故姬并与同父女弟徵臣私通。淮阳侯母令荼恬告发，廷尉反判收钱代告者弃市。恭太后写信阻徵臣返江都。 [[15]](#note-15)


<a id="event-16"></a>

16. **鲁恭太后斥刘建。** 太后提醒徵臣莫返，见刘建使者吉，哭劝刘建以燕齐诸国为鉴；吉转达后反受刘建责打并被斥退。 [[16]](#note-16)


<a id="event-17"></a>

17. **江都宫游溺死事件。** 刘建故意翻覆小船，四女落水两人死亡；风天又使两郎入波，船覆后临视而令不得救。 [[17]](#note-17)


<a id="event-18"></a>

18. **刘建宫内虐杀与祝诅。** 列刘建虐杀、凌辱姬妾无辜三十五人。恐被告，遂同成光使越婢降神诅咒皇帝，并向属官怨言朝使再来便不独死。 [[18]](#note-18)


<a id="event-19"></a>

19. **江都制兵器印绶并通越。** 刘建得知淮南、衡山设谋，恐被并吞，暗置官号、兵械、印玺符节和地图，结越繇王闽侯互助。淮南案曾牵连他，试图以金钱断案。 [[19]](#note-19)


<a id="event-20"></a>

20. **江都事发与撤国。** 刘建佩父印用天子旗，又有意先发。朝廷杂按查获僭拟物证，群臣议以谋反论。有诏就地讯问，刘建自杀，成光等弃市，故地入广陵郡。 [[20]](#note-20)


<a id="event-21"></a>

21. **平帝时为江都续后。** 断绝百余年后，王莽以继绝为名，立盱眙侯子刘宫奉江都易王刘非之祀。刘宫王号有广陵、广川、广世三记，分别见本传、《平帝纪》《诸侯王表》。王莽篡位后国绝。 [[21]](#note-21)


<a id="event-22"></a>

22. **胶西于王小目。** 以下为景帝之子刘端，区别于参加叛乱的刘卬。 [[22]](#note-22)


<a id="event-23"></a>

23. **刘端悖戾与削胶西。** 刘端封胶西后狎昵少年，因宫闱奸事诛杀，屡违汉法。皇帝不忍诛，仅从公卿削地；刘端使仓储腐坏而不理，并薄卫从、易名外游。 [[23]](#note-23)


<a id="event-24"></a>

24. **胶西王排抑汉廷之官。** 相及二千石依法管国，刘端便罗织罪名乃至毒害；若迎合王令，又遭汉法追究，胶西虽小，被除伤的长官却很多。 [[24]](#note-24)


<a id="event-25"></a>

25. **赵敬肃王小目。** 以下为刘彭祖由广川徙赵及宗支。 [[25]](#note-25)


<a id="event-26"></a>

26. **刘彭祖擅权压制汉相。** 刘彭祖由广川迁赵，善伪饰而多内宠子孙。故意套取二千石失言作把柄以挟制，或告讦使之得罪，遂擅国政，让使者垄断商业、获利逾租税。 [[26]](#note-26)


<a id="event-27"></a>

27. **赵王喜作官吏亲巡。** 不热衷宫室祠祭，自请督盗贼，夜随走卒巡邯郸。过往使客因他险诈不敢留。 [[27]](#note-27)


<a id="event-28"></a>

28. **江充告发赵太子丹。** 刘丹为江充告发淫乱劫盗，下魏郡诏狱。刘彭祖请击胡赎罪被拒，刘丹后获释；赵王又托公主请恢复储位，也未获准。 [[28]](#note-28)


<a id="event-29"></a>

29. **刘彭祖卒与赵王世系。** 刘彭祖纳淖姬生淖子。征和元年死后，武帝以淖子多欲不宜治国，选择评价平实的武始侯刘昌。后传刘尊，因无子改立弟刘高，再传刘充、刘隐，至莽而绝。 [[29]](#note-29)


<a id="event-30"></a>

30. **平干王一支及除国。** 武帝另封刘彭祖幼子刘偃。刘元继立后侵杀奴婢，又逼十六人殉死。大鸿胪禹举《春秋》义反对其子继承，朝廷从议除国。 [[30]](#note-30)


<a id="event-31"></a>

31. **中山靖王小目。** 以下为刘胜及在武帝朝的宗藩申诉。 [[31]](#note-31)


<a id="event-32"></a>

32. **立中山王与武帝初削藩争论。** 刘胜于七国平后立，中枢忧王国兵地过强，频奏过恶。诸王则自称是帝室藩屏，被小吏搜索微过、逼属官证王，心多怨愤。 [[32]](#note-32)


<a id="event-33"></a>

33. **刘胜以乐触悲。** 高渐离击筑、雍门子微吟能感动荆轲和孟尝君，比自己久结忧思，遇音乐便流泪。 [[33]](#note-33)


<a id="event-34"></a>

34. **众口积毁的力量。** 喣气可漂山、蚊声可成雷，说明众人积聚能害人。文王被囚、孔子遭厄是拟例；刘胜在远方缺人引言，怕细毁积成大祸。 [[34]](#note-34)


<a id="event-35"></a>

35. **谗蔽使君主不得闻。** 日月本能照远微，云尘却能蔽其光。以此比谗言使君主不能听到远藩的实情。 [[35]](#note-35)


<a id="event-36"></a>

36. **以骨肉之亲向武帝申诉。** 所依社稷的鼠也不轻灌逐，诸侯既为骨肉当受容护。群臣结党使宗亲疏散如冰消，引忠臣受害及《诗》写忧。 [[36]](#note-36)


<a id="event-37"></a>

37. **赵王与中山王异议。** 刘胜好酒色，儿子众多，指兄长代吏事不似王；彭祖则责他纵乐而不能佐朝养民。 [[37]](#note-37)


<a id="event-38"></a>

38. **中山后世与前后广德。** 中山王位由昌、昆侈、辅、福、循传续。绝嗣后另有成帝时刘云客王广德、哀帝时刘广汉王广平。元始二年立刘伦为广德王，本段称续靖王之祀，广川惠王段与《诸侯王表》均另记为续惠王一支。 [[38]](#note-38)


<a id="event-39"></a>

39. **长沙定王小目。** 以下为唐姬之子刘发及其王统。 [[39]](#note-39)


<a id="event-40"></a>

40. **唐姬生刘发与封长沙。** 唐姬原为程姬侍者，代程姬夜侍景帝而孕。母亲微贱不得宠，刘发受封于偏远卑湿的长沙。 [[40]](#note-40)


<a id="event-41"></a>

41. **长沙世系和刘建德削国。** 刘发后传刘庸、刘鮒鮈、刘建德等；刘建德焚猎害民并诬告内史，撤中尉、削八县。刘旦无后，元帝立弟刘宗，后传刘鲁人，莽时绝。 [[41]](#note-41)


<a id="event-42"></a>

42. **广川惠王小目。** 以下为刘越及后代刘齐、刘去一系。 [[42]](#note-42)


<a id="event-43"></a>

43. **广川刘齐讼狱无治而死。** 刘越去世后刘齐继，刘齐因幸臣逃亡受告，又多告发吏而查无实据，反被劾大不敬。愿以击匈奴赎罪，尚未成行便病死，有司请除国。 [[43]](#note-43)


<a id="event-44"></a>

44. **刘去受封及王宫杀两姬。** 武帝为兄续祀重立刘齐太子刘去。刘去好经书技艺及成庆画像，仿造长剑衣裳。昭信得宠后两姬被疑通谋，受逼讯而死，连从婢亦被杀，尸又遭烧。 [[44]](#note-44)


<a id="event-45"></a>

45. **昭信为后后诋毁陶望卿。** 刘去使昭信为王后，陶望卿、崔脩成分别管织物和宫巷。昭信诬望卿取衣僭越、与人私通，引刘去起疑并当众作歌讥她。 [[45]](#note-45)


<a id="event-46"></a>

46. **望卿被刑逼投井及后续灭口。** 昭信再陈诬告，刘去等逼辱望卿致其投井，昭信毁其尸并令诸姬观看，后又杀望卿妹妹都。 [[46]](#note-46)


<a id="event-47"></a>

47. **昭信又诬榮爱并相继杀人。** 榮爱被昭信指有私，投井获救后受拷而自诬，终被刘去残害至死。昭信排挤得幸者，共十四人受害。 [[47]](#note-47)


<a id="event-48"></a>

48. **昭信专宠并幽闭诸姬。** 昭信以整肃宫禁为由闭诸姬舍、钥归于后。刘去为众姬写愁歌，歌毕仍禁闭；唯昭信侄女能常见，昭信与王外出博饮。 [[48]](#note-48)


<a id="event-49"></a>

49. **刘去案历赦后再发及结局。** 回叙刘去杀师，官府由倡优闯宫及陶氏母子被害追查。本始三年有司杂讯，群臣以赦前重恶仍请求处斩；宣帝不忍杀王，改废迁上庸，途中刘去自杀，昭信弃市。 [[49]](#note-49)


<a id="event-50"></a>

50. **广川复立与再被废。** 宣帝立屡谏刘去的兄长刘文。继嗣刘海阳因宫室淫画、逼人私通并谋杀而于甘露四年废迁。元始二年又立襄隄侯子刘瘉为广德王；《平帝纪》和《王子侯表》作伦，《诸侯王表》作榆。奉谁后及嗣子刘赤的纪年，纪传表所述有别。 [[50]](#note-50)


<a id="event-51"></a>

51. **胶东康王小目。** 以下为刘寄及胶东、六安后世。 [[51]](#note-51)


<a id="event-52"></a>

52. **刘寄牵连淮南事与两个儿子的王国。** 景中二年立；略闻淮南谋反私造备战工具，案辞牵出，忧病而死。朝廷令长子刘贤续胶东，另封少子刘庆六安，以下兼列刘贤胶东后裔。 [[52]](#note-52)


<a id="event-53"></a>

53. **六安庆及后嗣。** 刘庆后传子刘禄、刘定、刘光、刘育，至王莽绝。 [[53]](#note-53)


<a id="event-54"></a>

54. **清河哀王小目。** 以下为王夫人所生刘乘。 [[54]](#note-54)


<a id="event-55"></a>

55. **常山宪王小目。** 以下为少子刘舜及常山、真定、泗水支系。 [[55]](#note-55)


<a id="event-56"></a>

56. **刘舜封常山与刘勃继。** 刘舜为景帝幼子，景中五年始封，纵恣屡犯禁而多得宽宥，死后刘勃继位。 [[56]](#note-56)


<a id="event-57"></a>

57. **争议王丧及刘勃废徙。** 孽长子刘棁不得父爱与财物，举告王后修、嗣王不侍疾及服丧无礼。武帝遣张骞核验，刘勃隐证又擅纵囚，朝廷以无良傅而免死，携家废徙房陵。 [[57]](#note-57)


<a id="event-58"></a>

58. **常山撤国及真定泗水分封。** 刘勃为王数月而废。诏称王后与诸姬不和、嫡庶彼此指控，另立刘平于真定、刘商于泗水。真定传偃、由、雍、普、阳，止于王莽。 [[58]](#note-58)


<a id="event-59"></a>

59. **泗水王继嗣与遗腹子。** 刘商传安世，无子而立弟刘贺。刘贺遗腹子刘煖曾未获上报，昭帝经太后奏请立其为王并处罚相、内史。后传刘骏、刘靖。 [[59]](#note-59)


<a id="event-60"></a>

60. **班固评景帝诸王。** 借鲁哀公深宫不知忧惧之语，说明诸王纵情违法与富贵处境有关，独以河间献王的学行近于高雅不群。 [[60]](#note-60)

### 3. 河间王刘德收书立学

[返回正文第3条](#event-3)

<a id="hs053-p003"></a>

**[《汉书·景十三王传》P003](../../拆分史书/汉书/卷053.md#p003)** · [仓内TXT L7836—L7836](../../拆分史书/汉书/卷053.md#part-1-L7836)

> 河間獻王德以孝景前二年立，修學好古，實事求是。從民得善書，必為好寫與之，留其真，加金帛賜以招之。繇是四方道術之人不遠千里，或有先祖舊書，多奉以奏獻王者，故得書多，與漢朝等。是時，淮南王安亦好書，所招致率多浮辯。獻王所得書皆古文先秦舊書，周官、尚書、禮、禮記、孟子、老子之屬，皆經傳說記，七十子之徒所論。其學舉六藝，立毛氏詩、左氏春秋博士。修禮樂，被服儒術，造次必於儒者。山東諸儒者從而游。

### 4. 河间王献雅乐对策

[返回正文第4条](#event-4)

<a id="hs053-p004"></a>

**[《汉书·景十三王传》P004](../../拆分史书/汉书/卷053.md#p004)** · [仓内TXT L7837—L7837](../../拆分史书/汉书/卷053.md#part-1-L7837)

> 膠東康王寄以孝景中二年立，二十八年薨。淮南王謀反時，寄微聞其事，私作兵車鏃矢，戰守備，備淮南之起。及吏治淮南事，辭出之。寄於上最親，意自傷，發病而死，不敢置後。於是上聞寄有長子賢，母無寵，少子慶，母愛幸，寄常欲立之，為非次，因有過，遂無所言。上憐之，立賢為膠東王，奉康王祀，而封慶為六安王，王故衡山地。膠東王賢立十五年薨，諡為哀王。子戴王通平嗣，二十四年薨。子頃王音嗣，五十四年薨。子共王授嗣，十四年薨。子殷嗣，王莽時絕。

### 57. 争议王丧及刘勃废徙

[返回正文第57条](#event-57)

<a id="hs053-p065"></a>

**[《汉书·景十三王传》P065](../../拆分史书/汉书/卷053.md#p065)** · [仓内TXT L7898—L7898](../../拆分史书/汉书/卷053.md#part-1-L7898)

> 初，憲王有不愛姬生長男梲，梲以母無寵故，亦不得幸於王。王后脩生太子勃。王內多，所幸姬生子平、子商，王后稀得幸。及憲王疾甚，諸幸姬侍病，王后以妒媢不常在，輒歸舍。醫進藥，太子勃不自嘗藥，又不宿留侍疾。及王薨，王后、太子乃至。憲王雅不以梲為子數，不分與財物。郎或說太子、王后，令分梲財，皆不聽。太子代立，又不收恤梲。梲怨王后及太子。漢使者視憲王喪，梲自言憲王病時，王后、太子不侍，及薨，六日出舍，太子勃私姦、飲酒、博戲、擊筑，與女子載馳，環城過市，入獄視囚。天子遣大行騫驗問，逮諸證者，王又匿之。吏求捕，勃使人致擊笞掠，擅出漢所疑囚。有司請誅勃及憲王后脩。上曰：「脩素無行，使梲陷之罪。勃無良師傅，不忍致誅。」有司請廢勿王，徙王勃以家屬處房陵，上許之。

> 贊曰：昔魯哀公有言：「寡人生於深宮之中，長於婦人之手，未嘗知憂，未嘗知懼。」信哉斯言也！雖欲不危亡，不可得已。是故古人以宴安為鴆毒，亡德而富貴，謂之不幸。漢興，至于孝平，諸侯王以百數，率多驕淫失道。何則？沈溺放恣之中，居勢使然也。自凡人猶繫于習俗，而況哀公之倫乎！夫唯大雅，卓爾不群，河間獻王近之矣。

# 汉书楚元王世系与刘向刘歆的仕履学术

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **刘交早年学诗。** 楚元王刘交字游，是高祖同父的幼弟，爱读书且多才艺。曾和鲁人穆生、白生、申公同从荀卿弟子浮丘伯学《诗》，秦焚书时各自离去。 [[1]](#note-1)


<a id="event-2"></a>

2. **刘交随刘邦起兵。** 高祖长兄刘伯早死，次兄刘仲与审食其照料父亲；刘交随刘邦等找景驹，遇项梁后同奉楚怀王。刘交随军取南阳、入武关、战蓝田，在霸上封文信君，后来入汉中、定三秦并灭项籍。高祖称帝后，刘交同卢绾侍奉起居并传达机密；高祖堂兄刘贾则多次独当一军。 [[2]](#note-2)


<a id="event-3"></a>

3. **羹颉侯来由。** 刘邦微贱时带客人到长嫂家，长嫂刮锅诈称羹尽，宾客散后刘邦发现锅中仍有羹，因而记恨。后来朝廷先封其他亲属，刘信独未得侯；太上皇问及，高祖以长嫂待人不厚作答，七年十月封刘信羹颉侯。 [[3]](#note-3)


<a id="event-4"></a>

4. **鲁诗与元王诗。** 刘交聘穆生、白生、申公为中大夫。吕后时遣刘郢客与申公在长安随浮丘伯完成学业；文帝因申公精通《诗》任为博士。申公传《鲁诗》，刘交亦编《诗》传，称《元王诗》，世有传本。 [[4]](#note-4)


<a id="event-5"></a>

5. **楚夷王与景帝封楚王子。** 刘郢客在吕后时任宗正、封上邳侯。刘交的太子刘辟非先死，刘交死后由刘郢客承继，号楚夷王；申公失去博士职，随他回楚任中大夫。楚夷王死后刘戊承位。文帝厚待刘交子，景帝又封刘礼、刘富、刘岁、刘埶、刘调等五人为侯。 [[5]](#note-5)


<a id="event-6"></a>

6. **穆生见微而去。** 刘交知道穆生不爱酒，宴飨总设甜醴酒。刘戊继位后一度仍设，后来忘了，穆生于是称病。申公、白生以为小失礼不足告退，穆生引《易》知见事变于未萌，指出设醴体现君主尊道，忘醴意味着忘道，遂独自离去。 [[6]](#note-6)


<a id="event-7"></a>

7. **刘戊应吴反汉。** 刘戊在薄太后服丧期间私通，遭削地便与吴王通信。他惩罚劝谏的申、白，使着赭衣在市中舂米，又威胁先杀促其回头的叔父刘富，刘富携母入京。削地书到后刘戊杀张尚、赵夷吾，随吴西攻梁，破棘壁；周亚夫断粮，士卒困乏，吴王逃走，刘戊自杀，楚军投降。 [[7]](#note-7)


<a id="event-8"></a>

8. **楚文王一支至延寿伏罪。** 吴楚被平定后，景帝以刘礼奉楚元王后，王位经刘道、刘注、刘纯传至刘延寿。延寿料武帝子广陵王刘胥有望继统，使后母同母弟赵何齐娶刘胥女，准备乘乱发兵并致书刘胥。赵何齐父告发，官署取得实供，刘延寿自杀，封国被撤。 [[8]](#note-8)


<a id="event-9"></a>

9. **刘富由休侯改封红侯。** 刘富先避楚入京，刘戊起兵后他仍被连坐免侯、除属籍；后经查明曾多次劝谏，改封红侯。与窦太后有亲的太夫人愿留京避乱，获准；刘辟彊等四子在京奉养、入朝任官，太夫人死后赐葬地。红侯爵传至曾孙无后而绝。 [[9]](#note-9)


<a id="event-10"></a>

10. **刘辟彊及霍光纳用宗室。** 刘辟彊字少卿，爱读《诗》善属文，武帝时从二千石议论居宗室首位，平素清静不愿为官。昭帝即位后有人以诸吕当权疏斥宗室而灭为戒劝霍光，霍光欲用刘德，得知其父仍在，任八旬刘辟彊为光禄大夫、摄长乐卫尉，后迁宗正，数月卒。 [[10]](#note-10)


<a id="event-11"></a>

11. **刘德从武帝召见至封侯。** 刘德字路叔，习黄老，武帝召见称他千里马。昭帝时参与治刘泽及上官氏、盖主案。惧盛满而辞娶霍光女，后因责盖主孙谭，被御史揣摩霍光意旨弹劾罢官。霍光得知后复起他摄青州刺史，复任宗正参与立宣帝，封关内侯。地节间正式封阳城侯，家族多人由此得官宿卫。 [[11]](#note-11)


<a id="event-12"></a>

12. **刘德行恕与身后承祀。** 刘德代理京兆尹时多平反，以超过百万的家财赈亲宾，认为聚富易受怨。子刘向获铸伪金死罪，他为子申诉；适逢刘德死，大鸿胪据此请不给谥也不立嗣，帝仍赐谥缪侯、为立继承人。子孙庆忌、刘岑任显官，至王莽败后绝。 [[12]](#note-12)


<a id="event-13"></a>

13. **刘更生入朝与伪金案。** 刘向原名更生，十二岁以父荫任辇郎，成年为谏大夫，与王褒等献辞赋。因幼读父自淮南案得的方书，称黄白可成，奉命主持尚方铸造而无验，被劾死罪；其兄安民愿入一半封户赎罪，刘更生逾冬得减死。朝廷后召其受《穀梁》并在石渠论五经，历任郎中、散骑谏大夫等职。 [[13]](#note-13)


<a id="event-14"></a>

14. **元帝初朝争与首次免官。** 元帝任萧望之、周堪领尚书，他们荐刘更生，与金敞同心辅政，欲罢外戚许、史及宦官弘恭、石显。议泄后刘更生和周堪下狱，萧、周、刘均被免。地震、客星后望之受关内侯，周、刘被召，因恭、显奏仅任中郎。刘更生忧诸人再受谗，使外亲上书。 [[14]](#note-14)


<a id="event-15"></a>

15. **外亲上奏举前朝四臣。** 奏文说望之等忠正，反受勋戚诋毁，地震在古义表示执政势盛，不该责三人。以季布获赦为名将、儿宽逢韩说救谏任御史大夫、董仲舒免死成儒宗、夏侯胜复起以直闻为例，说明有过之人还可为国所用。 [[15]](#note-15)


<a id="event-16"></a>

16. **萧望之死与刘更生再封事。** 恭、显请查外戚书信，供出刘更生，朝廷交韦玄成、贡禹及廷尉审理，以其排斥近亲、教人上变为由免为庶人。萧望之令子申冤，又被迫到狱答辩而自杀。元帝擢用周堪与弟子张猛，两人仍遭诋毁，刘更生再上密奏。 [[16]](#note-16)


<a id="event-17"></a>

17. **密奏自明进言之义。** 刘更生称曾以宗室为九卿而未能恪奉法，又蒙赦免，看到灾异接连发生，虽身在田间且怕越职，仍应以忠臣与骨肉之义进言。 [[17]](#note-17)


<a id="event-18"></a>

18. **以舜、周文武论和政。** 舜任九官，贤臣互让，朝野相和。周文王聚贤、崇让息讼，武王、周公继政使内臣及诸侯和睦；以《清庙》及诸篇《周颂》说明古人把丰收和上天降福解释为和气所致。 [[18]](#note-18)


<a id="event-19"></a>

19. **厉幽之衰与诗中灾象。** 刘更生用《诗》里群小相附、君子被谗、日月蚀、山川改易及失时繁霜，描写厉、幽时是非颠倒。他把这些异象解释为朝廷不和、贤愚易位的结果。 [[19]](#note-19)


<a id="event-20"></a>

20. **东周灾异与周室衰微。** 厉王出奔、幽王被杀，祭伯出奔后尹氏世掌政，诸侯背周。《春秋》二百四十二年所载日食、地震、星变、火灾、鸟兽异状、时令倒错、水旱饥虫等被刘更生与弑君亡国并举。后叙晋攻周、郑伤桓王、戎拘使、齐助卫朔与王室争位，说明周室不能复振。 [[20]](#note-20)


<a id="event-21"></a>

21. **当朝朋党与灾异。** 刘更生把和气祥瑞与乖气异变视为古今通义，批评朝中贤邪不分、相互谗告、文书交错，权门以亲属、附从者操纵毁誉。以从衰周之迹而求太平犹如倒行追人作比，并指出自初元到上奏已六年，灾异密过所引《春秋》。 [[21]](#note-21)


<a id="event-22"></a>

22. **决疑与坚持任贤。** 刘更生认为君主狐疑才使谗言得售，借《易》否泰说明君子与小人进退关系；用尧、成王任贤与鲁定公、秦始皇退贤对举。善令既出应像出汗不可收回，任贤应如心坚不移，而当朝恰好命令易反、贤者易退、佞人难去。 [[22]](#note-22)


<a id="event-23"></a>

23. **分辨荐贤与朋党。** 孔子与弟子相互称誉，禹、稷、皋陶彼此汲引，都以忠国为本。刘更生借飞龙、拔茅卦象说明贤者理当引同道；当朝谄佞则以朋党求压贤，灾异在他的解释中是事先警戒。 [[23]](#note-23)


<a id="event-24"></a>

24. **请远佞开正路。** 刘更生以舜四放和孔子两观之诛说明圣人能断，建议元帝比较尧周的任贤与秦鲁的退贤，放逐奸佞、解除狐疑、分明是非；因所陈涉及宗亲与政争，密封奏上。 [[24]](#note-24)


<a id="event-25"></a>

25. **周堪和张猛左迁。** 恭、显读奏后更加怨恨。夏寒、日光青暗，许史等把责任推给周堪与张猛。元帝欲得杨兴助言，杨兴察帝心转称宜厚赏而夺实权；诸葛丰也批评周、张。元帝虽免诸葛丰，仍把周堪左迁河东太守、张猛贬槐里令。 [[25]](#note-25)


<a id="event-26"></a>

26. **复召周堪、张猛及二人结局。** 宣帝陵阙失火、晦日食，元帝责问昔日归咎周张者。诏举周堪在河东颇有政声，召为光禄大夫领尚书，张猛也获召。石显与其党控制奏事；周堪失语而卒，张猛被谗自杀，刘更生作《疾谗》等八篇感悼，废居十多年。 [[26]](#note-26)


<a id="event-27"></a>

27. **刘向复起、校书与《洪范五行传论》。** 成帝即位后石显失势，刘更生复出，改名向，领三辅都水，迁光禄大夫。见王凤兄弟权重，借奉诏校阅秘藏，取《洪范》箕子说五行休咎之义，串联上古至秦汉灾异，撰十一篇讽谏。皇帝知其忠，仍由王氏掌权。 [[27]](#note-27)


<a id="event-28"></a>

28. **谏昌陵由三统发论。** 昌陵工程多年难成且奢，刘向引《易》安不忘危、孔子论天命，指出王朝须存前二代之统，天命不久留一姓。又举高祖纳刘敬之说徙都关中，自知德不如周而藉秦形势，说明国祚终取决于为政。 [[28]](#note-28)


<a id="event-29"></a>

29. **张释之说孝文薄葬。** 文帝在霸陵称石椁可牢固，张释之答若墓中有可欲之物，封若南山仍会被盗；如无珍藏，不需石椁。文帝醒悟，薄葬不起大坟。 [[29]](#note-29)


<a id="event-30"></a>

30. **历述古帝古贤墓制。** 刘向引《易》古以薪覆死者，不封树，后有棺椁。列黄帝、尧、舜、禹、成汤、文武周公、秦穆公、樗里子葬地各制，说明古先君相虑及长远，贤臣孝子遵命薄葬。 [[30]](#note-30)


<a id="event-31"></a>

31. **周公、孔子、季札的葬礼。** 周公薄葬武王，孔子为辨母墓作四尺小坟，雨坏时说古不修墓；季札子死于齐返吴路上，衣以时服、就地低封，孔子称合礼。宋桓司马作石椁为孔子所非，《吕氏春秋》亦主张薄葬。 [[31]](#note-31)


<a id="event-32"></a>

32. **秦陵奢藏而遭祸之说。** 刘向以吴王闔闾及秦诸王厚葬被发为戒，描述始皇陵的高坟、石椁、人膏灯、水银与珍宝，以及宫人与工匠之死。奏疏说秦末周章兵至、项籍焚烧宫宇，又有牧童寻羊失火的说法，借此论厚葬难保。 [[32]](#note-32)


<a id="event-33"></a>

33. **宫室与陵制的奢俭得失。** 刘向认为厚德深智之君葬薄，厚藏高坟反易被掘；以《斯干》赞周宣王更作俭宫和鲁庄公侈饰宗庙、后嗣再绝对照。 [[33]](#note-33)


<a id="event-34"></a>

34. **《列女传》《新序》《说苑》。** 刘向认为宫内是风教起点，因赵、卫等越礼，采历代贤妃、贞妇与嬖宠致乱的例子作《列女传》八篇，又选旧传故事成《新序》《说苑》共五十篇，多次进谏。成帝认可其用心。 [[34]](#note-34)


<a id="event-35"></a>

35. **与陈汤论危刘并以史谏权臣。** 成帝无嗣、王氏执政，刘向对陈汤说明自己蒙三朝之恩，有责极谏。密奏举田氏取齐、六卿分晋、鲁三家逐君、周尹氏乱政，论人臣世执威福之患，又以秦昭王逐穰侯得存与秦二世任赵高而亡互证。 [[35]](#note-35)


<a id="event-36"></a>

36. **列举王氏占据权位。** 刘向引吕产、吕禄兼兵政而终诛，指出王氏一姓已有二十三人乘朱轮华毂，尚书、卿、州牧与郡守多出其门，荐附己者、排宗室贤人，以周公自比却有管蔡之萌，势超前代外戚。 [[36]](#note-36)


<a id="event-37"></a>

37. **以王氏墓柱异象为警。** 刘向列昭帝时石立、柳起与宣帝即位，又举王氏先祖墓地梓柱抽枝生根，把它视作外家势将取代宗室的征兆。他说政权转移也不合皇太后在刘氏宗庙中的利益，并举宣帝不给舅父实权以保全他们。 [[37]](#note-37)


<a id="event-38"></a>

38. **建议收外戚政权及任中垒校尉。** 刘向主张亲信宗室、令外戚归家保爵，兼保王氏门第与刘氏社稷，又从《易》论密谋。成帝召见，答说会思量，随后任刘向中垒校尉。 [[38]](#note-38)


<a id="event-39"></a>

39. **元延灾异与再谏。** 刘向为人简易廉静，昼读夜观星，有时通宵。传文合举东井彗星、岷山崩堵江为他进谏的由头，奏文先引舜、周公及《诗》说贤君常以先朝败亡为戒。 [[39]](#note-39)


<a id="event-40"></a>

40. **日食密度与历朝异象。** 刘向比较《春秋》、汉初至竟宁及成帝即位约二十年间日食的密度，又以夏桀、纣、暴秦及项籍的异象对照汉初五星聚井、惠昭无后、昌邑被废与宣帝兴起。他以灾异和政治相应为论，也举殷高宗、周成王自省免祸。 [[40]](#note-40)


<a id="event-41"></a>

41. **请当面指图与宗室枝叶说。** 刘向说东井孛星及摄提、紫宫等天象严重，图表难尽其意，请面陈。成帝屡召而未用所陈。刘向常以枝叶护根为喻，指出外家专政、同姓疏远危及刘氏社稷。 [[41]](#note-41)


<a id="event-42"></a>

42. **刘向未迁与三子。** 因为素得信任，刘向屡为宗室进言，直指王氏。成帝多次想擢他为九卿，皆遭有位者与丞相御史阻持。他任列大夫三十多年，七十二岁卒。三子刘伋治《易》官至太守，刘赐为九卿丞早死，刘歆最有名。 [[42]](#note-42)


<a id="event-43"></a>

43. **刘歆校书并续成《七略》。** 刘歆字子骏，善《诗》《书》和属文，成帝时任黄门郎，河平间随父校秘藏，涉经传、诸子、诗赋、术数、方技。父卒后任中垒校尉；哀帝初经王莽荐升侍中等职，主持五经校理并分类编为《七略》。 [[43]](#note-43)


<a id="event-44"></a>

44. **刘歆治左氏并争立学官。** 父子本同治《易》，刘向又受《穀梁》。刘歆校书遇古文《左氏传》，从尹咸、翟方进问大义，以传解经，使章句义理完备。他以左丘明亲见孔子胜于后出的传闻，刘向仍持《穀梁》说。刘歆欲立左氏、毛诗、逸礼、古文尚书为学官，博士有人拒绝对论，遂移书责问。 [[44]](#note-44)


<a id="event-45"></a>

45. **移书追述汉兴经籍散传。** 刘歆说周衰礼坏，孔子整理诸经，身后微言大义逐渐失传，秦禁书杀儒。汉初叔孙通仅略定礼仪，惠帝才除挟书律，文帝遣晁错受书于伏生。武帝初各地才较多出现经师，数家拼合也距全经已远。 [[45]](#note-45)


<a id="event-46"></a>

46. **古文出壁与私家所传。** 刘歆说鲁恭王拆孔宅得古文，孔安国因巫蛊未能施行；《左传》等旧书长期藏秘府，成帝整理后方与学官本相校，鲁、赵、胶东所传也有印证。现时只守零散章句，会使国家礼典无从查考。 [[46]](#note-46)


<a id="event-47"></a>

47. **责博士拒讲与主张并立。** 刘歆认为哀帝尊重学界，才遣近臣试论左氏；博士拒不试讲，这是堵塞微学。古书有内外证验，主张如宣帝增立多家博士那样，即使义理互异也宜并存，免学派偏废。 [[47]](#note-47)


<a id="event-48"></a>

48. **三郡出守及平帝时的复起。** 诸儒不满，龚胜请退，师丹奏刘歆改乱旧章。哀帝答他在广道术，刘歆仍求外任，先后出守河内、五原、涿郡，病免后再起。哀帝死、王莽执政时被太后留用，历中垒校尉、羲和、京兆尹，治明堂辟雍受封红休侯，并考订律历成《三统历谱》。 [[48]](#note-48)


<a id="event-49"></a>

49. **改名与出任新朝国师。** 刘歆于建平元年改名刘秀、字颖叔。王莽代汉后任其为国师，此后事迹见《王莽传》。 [[49]](#note-49)


<a id="event-50"></a>

50. **班固赞刘向父子的经术。** 班固举孟荀、董仲舒、司马迁、刘向、扬雄为博通而能补益世事者。赞洪范论发明天人之说，七略分判百家，三统历谱推算日月五星，并感慨刘向对厚陵与外戚的警谏。 [[50]](#note-50)

> 臣聞舜命九官，濟濟相讓，和之至也。眾賢和於朝，則萬物和於野。故簫韶九成，而鳳皇來儀；擊石拊石，百獸率舞。四海之內，靡不和寧。及至周文，開基西郊，雜遝眾賢，罔不肅和，崇推讓之風，以銷分爭之訟。文王既沒，周公思慕，歌詠文王之德，其《詩》曰：「於穆清廟，肅雍顯相；濟濟多士，秉文之德。」當此之時，武王、周公繼政，朝臣和於內，萬國驩於外，故盡得其驩心，以事其先祖。其《詩》曰：「有來雍雍，至止肅肅，相維辟公，天子穆穆。」言四方皆以和來也。諸侯和於下，天應報於上，故周頌曰「降福穰穰」，又曰「飴我釐麰」。釐麰，麥也，始自天降。此皆以和致和，獲天助也。

### 19. 厉幽之衰与诗中灾象

> 下至幽、厲之際，朝廷不和，轉相非怨，詩人疾而憂之曰：「民之無良，相怨一方。」眾小在位而從邪議，歙歙相是而背君子，故其《詩》曰：「歙歙訿訿，亦孔之哀！謀之其臧，則具是違；謀之不臧，則具是依！」君子獨處守正，不橈眾枉，勉彊以從王事則反見憎毒讒愬，故其《詩》曰：「密勿從事，不敢告勞，無罪無辜，讒口嗷嗷！」當是之時，日月薄蝕而無光，其《詩》曰：「朔日辛卯，日有蝕之，亦孔之醜！」又曰：「彼月而微，此日而微，今此下民，亦孔之哀！」又曰：「日月鞠凶，不用其行；四國無政，不用其良！」天變見於上，地變動於下，水泉沸騰，山谷易處。其《詩》曰：「百川沸騰，山冢卒崩，高岸為谷，深谷為陵。哀今之人，胡憯莫懲！」霜降失節，不以其時，其《詩》曰：「正月繁霜，我心憂傷；民之訛言，亦孔之將！」言民以是為非，甚眾大也。此皆不和，賢不肖易位之所致也。

> 由此觀之，和氣致祥，乖氣致異；祥多者其國安，異眾者其國危，天地之常經，古今之通義也。今陛下開三代之業，招文學之士，優游寬容，使得並進。今賢不肖渾殽，白黑不分，邪正雜糅，忠讒並進。章交公車，人滿北軍。朝臣舛午，膠戾乘剌，更相讒愬，轉相是非。傳授增加，文書紛糾，前後錯繆，毀譽渾亂。所以營或耳目，感移心意，不可勝載。分曹為黨，往往群朋，將同心以陷正臣。正臣進者，治之表也；正臣陷者，亂之機也。乘治亂之機，未知孰任，而災異數見，此臣所以寒心者也。夫乘權藉勢之人，子弟鱗集於朝，羽翼陰附者眾，輻湊於前，毀譽將必用，以終乖離之咎。是以日月無光，雪霜夏隕，海水沸出，陵谷易處，列星失行，皆怨氣之所致也。夫遵衰周之軌跡，循詩人之所刺，而欲以成太平，致雅頌，猶卻行而求及前人也。初元以來六年矣，案春秋六年之中，災異未有稠如今者也。夫有春秋之異，無孔子之救，猶不能解紛，況甚於春秋乎？

### 22. 决疑与坚持任贤

[返回正文第22条](#event-22)

<a id="hs036-p023"></a>

**[《汉书·楚元王传》P023](../../拆分史书/汉书/卷036.md#p023)** · [仓内TXT L7070—L7070](../../拆分史书/汉书/卷036.md#part-1-L7070)

> 原其所以然者，讒邪並進也。讒邪之所以並進者，由上多疑心，既已用賢人而行善政，如或譖之，則賢人退而善政還。夫執狐疑之心者，來讒賊之口；持不斷之意者，開群枉之門。讒邪進則眾賢退，群枉盛則正士消。故易有否泰。小人道長，君子道消，君子道消，則政日亂，故為否。否者，閉而亂也。君子道長，小人道消，小人道消，則政日治，故為泰。泰者，通而治也。《詩》又云「雨雪麃麃，見晛聿消」，與易同義。昔者鯀、共工、驩兜與舜、禹雜處堯朝，周公與管、蔡並居周位，當是時，迭進相毀，流言相謗，豈可勝道哉！帝堯、成王能賢舜、禹、周公而消共工、管、蔡，故以大治，榮華至今。孔子與季、孟偕仕於魯，李斯與叔孫俱宦於秦，定公、始皇賢季、孟、李斯而消孔子、叔孫，故以大亂，污辱至今。故治亂榮辱之端，在所信任；信任既賢，在於堅固而不移。《詩》云「我心匪石，不可轉也」。言守善篤也。《易》曰「渙汗其大號」。言號令如汗，汗出而不反者也。今出善令，未能踰時而反，是反汗也；用賢未能三旬而退，是轉石也。《論語》曰：「見不善如探湯。」今二府奏佞諂不當在位，歷年而不去。故出令則如反汗，用賢則如轉石，去佞則如拔山，如此望陰陽之調，不亦難乎！

> 是以群小窺見間隙，緣飾文字，巧言醜詆，流言飛文，譁於民間。故《詩》云：「憂心悄悄，慍于群小。」小人成群，誠足慍也。昔孔子與顏淵、子貢更相稱譽，不為朋黨；禹、稷與皋陶傳相汲引，不為比周。何則？忠於為國，無邪心也。故賢人在上位，則引其類而聚之於朝，《易》曰「飛龍在天，大人聚也」；在下位，則思與其類俱進，《易》曰「拔茅茹以其彙，征吉」。在上則引其類，在下則推其類，故湯用伊尹，不仁者遠，而眾賢至，類相致也。今佞邪與賢臣並在交戟之內，合黨共謀，違善依惡，歙歙訿訿，數設危險之言，欲以傾移主上。如忽然用之，此天地之所以先戒，災異之所以重至者也。

### 40. 日食密度与历朝异象

> 謹案春秋二百四十二年，日蝕三十六，襄公尤數，率三歲五月有奇而壹食。漢興訖竟寧，孝景帝尤數，率三歲一月而一食。臣向前數言日當食，今連三年比食。自建始以來，二十歲間而八食，率二歲六月而一發，古今罕有。異有小大希稠，占有舒疾緩急，而聖人所以斷疑也。《易》曰：「觀乎天文，以察時變。」昔孔子對魯哀公，並言夏桀、殷紂暴虐天下，故曆失則攝提失方，孟陬無紀，此皆易姓之變也。秦始皇之末至二世時，日月薄食，山陵淪亡，辰星出於四孟，太白經天而行，無雲而雷，枉矢夜光，熒惑襲月，谪火燒宮，野禽戲廷，都門內崩，長人見臨洮，石隕于東郡，星孛大角，大角以亡。觀孔子之言，考暴秦之異，天命信可畏也。及項籍之敗，亦孛大角。漢之入秦，五星聚于東井，得天下之象也。孝惠時，有雨血，日食於衝，滅光星見之異。孝昭時，有泰山臥石自立，上林僵柳復起，大星如月西行，眾星隨之，此為特異。孝宣興起之表，天狗夾漢而西，久陰不雨者二十餘日，昌邑不終之異也。皆著於漢紀。觀秦、漢之易世，覽惠、昭之無後，察昌邑之不終，視孝宣之紹起，天之去就，豈不昭昭然哉！高宗、成王亦有雊雉拔木之變，能思其故，故高宗有百年之福，成王有復風之報。神明之應，應若景嚮，世所同聞也。

> 昔唐虞既衰，而三代迭興，聖帝明王，累起相襲，其道甚著。周室既微而禮樂不正，道之難全也如此。是故孔子憂道之不行，歷國應聘。自衛反魯，然後樂正，雅頌乃得其所；修易，序書，制作春秋，以紀帝王之道。及夫子沒而微言絕，七十子終而大義乖。重遭戰國，棄籩豆之禮，理軍旅之陳，孔氏之道抑，而孫吳之術興。陵夷至于暴秦，燔經書，殺儒士，設挾書之法，行是古之罪，道術由是遂滅。漢興，去聖帝明王遐遠，仲尼之道又絕，法度無所因襲。時獨有一叔孫通略定禮儀，天下唯有易卜，未有它書。至孝惠之世，乃除挾書之律，然公卿大臣絳、灌之屬咸介冑武夫，莫以為意。至孝文皇帝，始使掌故朝錯從伏生受尚書。尚書初出于屋壁，朽折散絕，今其書見在，時師傳讀而已。詩始萌牙。天下眾書往往頗出，皆諸子傳說，猶廣立於學官，為置博士。在漢朝之儒，唯賈生而已。至孝武皇帝，然後鄒、魯、梁、趙頗有詩、禮、春秋先師，皆起於建元之間。當此之時，一人不能獨盡其經，或為雅，或為頌，相合而成。泰誓後得，博士集而讀之。故詔書稱曰：「禮壞樂崩，書缺簡脫，朕甚閔焉。」時漢興已七八十年，離於全經，固已遠矣。

### 46. 古文出壁与私家所传

> 及魯恭王壞孔子宅，欲以為宮，而得古文於壞壁之中，逸禮有三十九，書十六篇。天漢之後，孔安國獻之，遭巫蠱倉卒之難，未及施行。及春秋左氏丘明所修，皆古文舊書，多者二十餘通，臧於祕府，伏而未發。孝成皇帝閔學殘文缺，稍離其真，乃陳發祕臧，校理舊文，得此三事，以考學官所傳，經或脫簡，傳或間編。傳問民間，則有魯國柏公、趙國貫公、膠東庸生之遺學與此同，抑而未施。此乃有識者之所惜閔，士君子之所嗟痛也。往者綴學之士不思廢絕之闕，苟因陋就寡，分文析字，煩言碎辭，學者罷老且不能究其一藝。信口說而背傳記，是末師而非往古，至於國家將有大事，若立辟雍封禪巡狩之儀，則幽冥而莫知其原。猶欲保殘守缺，挾恐見破之私意，而無從善服義之公心，或懷妒嫉，不考情實，雷同相從，隨聲是非，抑此三學，以尚書為備，謂左氏為不傳春秋，豈不哀哉！

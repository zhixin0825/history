# 汉书武帝诸子的封国与宫廷前事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **武帝诸子及母系。** 卫后生刘据，赵婕妤生昭帝，王夫人生齐王闳，李姬生燕王旦和广陵王胥，李夫人生昌邑王髆。李夫人与李姬为两人。 [[1]](#note-1)


<a id="event-2"></a>

2. **戾太子分目。** 以下记刘据早年、巫蛊案及追谥。 [[2]](#note-2)


<a id="event-3"></a>

3. **刘据出生、立储与婚配。** 武帝二十九岁得刘据，立禖祠，命东方朔、枚皋作祝。刘据七岁立储，学《公羊》《穀梁》，冠后获博望苑结客，接纳不同学说。元鼎四年纳史良娣，后生史皇孙刘进。 [[3]](#note-3)


<a id="event-4"></a>

4. **江充借治巫蛊陷太子。** 武帝高年多疑，卫后失宠，江充与太子有隙，怕帝死后被诛，借巫蛊构陷。公孙贺父子、两公主及卫伉已受牵连而死。 [[4]](#note-4)


<a id="event-5"></a>

5. **太子一家伤亡及葬地。** 刘据三男一女，女嫁平舆侯嗣子。太子败时家人遇害，卫后、史良娣葬长安南，史皇孙及王夫人、皇女孙葬广明，另二皇孙随太子葬湖。 [[5]](#note-5)


<a id="event-6"></a>

6. **齐怀王分目。** 以下记刘闳册封及身后。 [[6]](#note-6)


<a id="event-7"></a>

7. **燕刺王分目。** 以下为刘旦封燕及两次谋反案。 [[7]](#note-7)


<a id="event-8"></a>

8. **坐求宿卫及削地。** 刘旦成年就国，博学术数，好倡优游猎并招客。长兄遭巫蛊、齐王早死，他自以应立为储，求入宿卫，武帝下其使于狱，又因其藏亡命削三县，后立少子。 [[8]](#note-8)


<a id="event-9"></a>

9. **刘旦闻昭帝立、增封后结谋。** 刘旦嫌讣书封小，遣人借问礼察武帝死因、即位者及年岁，又请郡国立武帝庙，只获报闻。霍光加赐钱邑，他愤称应得帝位，同刘长刘泽谋以先帝给过整兵权为借口。 [[9]](#note-9)


<a id="event-10"></a>

10. **昭帝识诈及第二次废立计划。** 昭帝十四识燕奏为诈，更信霍光；燕王与上官等转谋废帝，通书许封上官桀。燕相虑京中诸人难成、成也反噬，刘旦自恃兄长身份，援前日冒称太子者获响应，命臣下整装。 [[10]](#note-10)


<a id="event-11"></a>

11. **燕宫灾异与占候。** 传列虹连宫井、豕毁灶、乌鹊斗、鼠舞、宫门自闭、火风流星；燕王惊病祭两水，吕广占将有围城杀臣，细目参《五行志》。 [[11]](#note-11)


<a id="event-12"></a>

12. **燕王后裔及广阳王系。** 宣帝封刘庆、刘贤为侯，立原太子刘建为广阳王，后刘舜、刘璜、刘嘉承嗣。王莽废藩时，刘嘉因献符命特受扶美侯，赐姓王。 [[12]](#note-12)


<a id="event-13"></a>

13. **广陵厉王分目。** 以下记刘胥、广陵及高密诸王。 [[13]](#note-13)


<a id="event-14"></a>

14. **刘胥好力而未继统。** 刘胥好游猎和倡乐，能举鼎、搏熊豕。传把其举止少法度与不得为帝嗣相连。 [[14]](#note-14)


<a id="event-15"></a>

15. **巫祝、楚王案及重起祝诅。** 刘胥以昭帝幼而无子，令女巫李女须托武帝神言求帝位。昭帝去世、刘贺征而又废、宣帝继位等时都以为巫言应、继续祈祝。延寿案因儿女联姻和书馈牵连到他，诏不治。闻立新太子一度止，后来刘宝削侯、与王姬私通被诛，国相请夺射陂田济贫，他再祝诅。 [[15]](#note-15)


<a id="event-16"></a>

16. **祝诅案和刘胥自缢。** 刘胥以赤枣白叶、池赤鱼死、鼠舞为恶兆。案发，他毒杀巫及宫人灭口，受使者讯问承罪，回殿置酒与子女诀别，作黄泉歌并嘱薄葬，以绶自缢，两妾随死。诸子赦为庶人，刘胥谥厉，广陵国除。 [[16]](#note-16)


<a id="event-17"></a>

17. **广陵两度复国。** 元帝复立刘胥子刘霸，传给刘意、刘护，护无子国除。成帝再立刘霸子刘守，后刘宏嗣，王莽时代终。 [[17]](#note-17)


<a id="event-18"></a>

18. **高密王系。** 刘弘本始元年以刘胥少子封高密，后刘章、刘宽、刘慎相继，到王莽时终。 [[18]](#note-18)


<a id="event-19"></a>

19. **昌邑哀王分目。** 以下记刘髆封王及刘贺进退。 [[19]](#note-19)


<a id="event-20"></a>

20. **龚遂以灾异规劝刘贺。** 在昌邑，刘贺见无头白犬、熊、大鸟，又见席上血，龚遂劝从《诗》审行而非徒惧凶兆；即位后贺梦积蝇矢，龚遂以青蝇谗言劝远故旧、亲旧臣子孙，自己宜先逐，仍不被听。 [[20]](#note-20)


<a id="event-21"></a>

21. **张敞察废昌邑王。** 宣帝元康二年命张敞察来客并密行。张敞奏叙接任后守门、市买、巡察，地节四年入见时记其相貌、痿病、妻子数，试以枭鸟探意，判其清狂不慧，又奏遣刘髆旧歌舞人。宣帝因奏认为其不足忌；各次巡视与回奏异时。 [[21]](#note-21)


<a id="event-22"></a>

22. **刘贺削户及病亡。** 扬州刺史告其同孙万世私议废帝时何不拒出宫、诛霍光，另有预言改王豫章的话。官请逮捕，帝削户三千。数年后去世，本段未给削地确年。 [[22]](#note-22)


<a id="event-23"></a>

23. **候嗣者去世，刘贺一支国除。** 豫章太守列刘充国、刘奉亲接连亡故，援舜对有罪宗亲不置嗣的故事请绝，朝议采纳。 [[23]](#note-23)


<a id="event-24"></a>

24. **班固借巫蛊反思久兵。** 赞以建元蚩尤旗、夺河南、置朔方同太子生长于多年用兵相连，认为巫蛊祸不能尽归江充；又举秦长期用兵反自焚及「止戈为武」说明武在禁暴。末称田千秋指出冤情，遏乱顺人心；灾异属史家解释。 [[24]](#note-24)

### 9. 刘旦闻昭帝立、增封后结谋

[返回正文第9条](#event-9)

<a id="hs063-p018"></a>

**[《汉书·武五子传》P018](../../sources/摘录/汉书-卷063-武五子传.md#p018)** · [仓内TXT L8310—L8310](../../sources/本地分卷/汉书/汉书-卷063.md#L8310)

> 帝崩，太子立，是為孝昭帝，賜諸侯王璽書。旦得書，不肯哭，曰：「璽書封小。京師疑有變。」遣幸臣壽西長、孫縱之、王孺等之長安，以問禮儀為名。王孺見執金吾廣意，問：「帝崩所病？立者誰子？年幾歲？」廣意言：「待詔五莋宮，宮中言雚言帝崩，諸將軍共立太子為帝，年八九歲，葬時不出臨。」歸以報王。王曰：「上棄群臣，無語言，蓋主又不得見，甚可怪也。」復遣中大夫至京師上書言：「竊見孝武皇帝躬聖道，孝宗廟，慈愛骨肉，和集兆民，德配天地，明並日月，威武洋溢，遠方執寶而朝，增郡數十，斥地且倍，封泰山，禪梁父，巡狩天下，遠方珍物陳於太廟，德甚休盛，請立廟郡國。」奏報聞。時大將軍霍光秉政，褒賜燕王錢三千萬，益封萬三千戶。旦怒曰：「我當為帝，何賜也！」遂與宗室中山哀王子劉長、齊孝王孫劉澤等結謀，詐言以武帝時受詔，得職吏事，修武備，備非常。

> 始，昭帝時，胥見上年少無子，有覬欲心。而楚地巫鬼，胥迎女巫李女須，使下神祝詛。女須泣曰：「孝武帝下我。」左右皆伏。言「吾必令胥為天子」。胥多賜女須錢，使禱巫山。會昭帝崩，胥曰：「女須良巫也！」殺牛塞禱。及昌邑王征，復使巫祝詛之。後王廢，胥浸信女須等，數賜予錢物。宣帝即位，胥曰：「太子孫何以反得立？」復令女須祝詛如前。又胥女為楚王延壽後弟婦，數相饋遺，通私書。後延壽坐謀反誅，辭連及胥。有詔勿治，賜胥黃金前後五千斤，它器物甚眾。胥又聞漢立太子，謂姬南等曰：「我終不得立矣。」乃止不詛。後胥子南利侯寶坐殺人奪爵，還歸廣陵，與胥姬左修奸。事發覺，繫獄，棄市。相勝之奏奪王射陂草田以賦貧民，奏可。胥復使巫祝詛如前。

### 20. 龚遂以灾异规劝刘贺

<a id="hs063-p041"></a>

**[《汉书·武五子传》P041](../../sources/摘录/汉书-卷063-武五子传.md#p041)** · [仓内TXT L8333—L8333](../../sources/本地分卷/汉书/汉书-卷063.md#L8333)

> 初，賀在國時，數有怪。嘗見白犬，高三尺，無頭，其頸以下似人，而冠方山冠。後見熊，左右皆莫見。又大鳥飛集宮中。王知，惡之，輒以問郎中令遂。遂為言其故，語在《五行志》。王卬天歎曰：「不祥何為數來！」遂叩頭曰：「臣不敢隱忠，數言危亡之戒，大王不說。夫國之存亡，豈在臣言哉？願王內自揆度。大王誦《詩》三百五篇，人事浹，王道備，王之所行中《詩》一篇何等也？大王位為諸侯王，行污於庶人，以存難，以亡易，宜深察之。」後又血污王坐席，王問遂，遂叫然號曰：「宮空不久，祅祥數至。血者，陰憂象也。宜畏慎自省。」賀終不改節。居無何，征。既即位，後王夢青蠅之矢積西階東，可五六石，以屋版瓦覆，發視之，青蠅矢也。以問遂，遂曰：「陛下，之《詩》不雲乎？『營營青蠅，至於籓；愷悌君子，毋信讒言。』陛下左側讒人眾多，如是青蠅惡矣。宜進先帝大臣子孫親近以為左右。如不忍昌邑故人，信用讒諛，必有凶咎。願詭禍為福，皆放逐之。臣當先逐矣。」賀不用其言，卒至於廢。

### 21. 张敞察废昌邑王

[返回正文第21条](#event-21)

<a id="hs063-p042"></a>

**[《汉书·武五子传》P042](../../sources/摘录/汉书-卷063-武五子传.md#p042)** · [仓内TXT L8334—L8334](../../sources/本地分卷/汉书/汉书-卷063.md#L8334)

> 大將軍光更尊立武帝曾孫，是為孝宣帝。即位，心內忌賀，元康二年遣使者賜山陽太守張敞璽書曰：「制詔山陽太守：其謹備盜賊，察往來過客。毋下所賜書！」敞於是條奏賀居處，著其廢亡之效，曰：「臣敞地節三年五月視事，故昌邑王居故宮，奴婢在中者百八十三人，閉大門，開小門，廉吏一人為領錢物市買，朝內食物，它不得出入。督盜一人別主徼循，察往來者。以王家錢取卒，迾宮清中備盜賊。臣敞數遣丞吏行察。四年九月中，臣敞入視居處狀，故王年二十六七，為人青黑色，小目，鼻末銳卑，少鬚眉，身體長大，疾痿，行步不便。衣短衣大褲，冠惠文冠，佩玉環，簪筆持牘趨謁。臣敞與坐語中庭，閱妻子奴婢。臣敞欲動觀其意，即以惡鳥感之，曰：『昌邑多梟。』故王應曰：『然。前賀西至長安，殊無梟。復來，東至濟陽，乃復聞梟聲。』臣敞閱至子女持轡，故王跪曰：『持轡母，嚴長孫女也。』臣敞故知執金吾嚴延年字長孫，女羅紨，前為故王妻。察故王衣服言語跪起，清狂不惠。妻十六人，子二十二人，其十一人男，十一人女。昧死奏名籍及奴婢財物簿。臣敞前書言：『昌邑哀王歌舞者張修等十人，無子，又非姬，但良人，無官名，王薨當罷歸。太傅豹等擅留，以為哀王園中人，所不當得為，請罷歸。』故王聞之曰：『中人守園，疾者當勿治，相殺傷者當勿法，欲令亟死，太守奈何而欲罷之？』其天資喜由亂亡，終不見仁義，如此。後丞相御史以臣敞書聞，奏可。皆以遣。」上由此知賀不足忌。

<a id="note-24"></a>

### 24. 班固借巫蛊反思久兵

[返回正文第24条](#event-24)

<a id="hs063-p047"></a>

**[《汉书·武五子传》P047](../../sources/摘录/汉书-卷063-武五子传.md#p047)** · [仓内TXT L8339—L8339](../../sources/本地分卷/汉书/汉书-卷063.md#L8339)

> 贊曰：巫蠱之禍，豈不哀哉！此不唯一江充之辜，亦有天時，非人力所致焉。建元六年，蚩尤之旗見，其長竟天。後遂命將出征，略取河南，建置朔方。其春，戾太子生。自是之後，師行三十年，兵所誅屠夷滅死者不可勝數。及巫蠱事起，京師流血，殭屍數萬，太子子父皆敗。故太子生長於兵，與之終始，何獨一嬖臣哉！秦始皇即位三十九年，內平六國，外攘四夷，死人如亂麻，暴骨長城之下，頭盧相屬於道，不一日而無兵。由是山東之難興，四方潰而逆秦。秦將吏外畔，賊臣內發，亂作蕭牆，禍成二世。故曰「兵猶火也，弗戢必自焚」，信矣。是以倉頡作書，「止」「戈」為「武」。聖人以武禁暴整亂，止息兵戈，非以為殘而興縱之也。《易》曰：「天子所助者順也，人之所助者信也；君子履信思順，自天祐之，吉無不利也。」故車千秋指明蠱情，章太子之冤。千秋材知未必能過人也，以其銷惡運，遏亂原，因衰激極，道迎善氣，傳得天人之祐助云。

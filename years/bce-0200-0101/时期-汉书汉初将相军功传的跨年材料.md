# 汉书汉初将相军功传的跨年材料

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **樊哙出身及芒砀旧事。** 樊哙是沛县人，以宰狗为生，后来与刘邦一起藏匿在芒砀山泽之间。 [[1]](#note-1)


<a id="event-2"></a>

2. **随沛公反秦，累功受爵。** 陈胜起兵后，萧何、曹参叫樊哙迎回刘邦，推为沛公。樊哙作近侍，攻胡陵、方与，从丰、沛到薛、砀屡退秦军。此后随军打濮阳、阳城、户牖、成武、开封等地，记载把先登、断敌和俘斩作为论功依据，爵位由国大夫、列大夫升到五大夫、卿，并受号贤成君。他又参与截断河津、攻南阳、宛城、武关，抵达霸上。文末分别列斩首、俘虏和投降士卒，三者有别。 [[2]](#note-2)


<a id="event-3"></a>

3. **受封临武侯、回定三秦及楚汉战功。** 项羽屠咸阳、立刘邦为汉王，樊哙先封临武侯，再以郎中入汉中。汉军回来定三秦，樊哙在白水、雍南、好畤等地作战，由郎中骑将升将军，防守引水攻废丘时功居首，得到杜地樊乡。又攻楚军及鲁梁诸地，彭城败后楚夺回先前诸县。他退至荥阳，增邑平阴二千户、守广武；乘项羽东引下阳夏，围陈破楚军，最后屠胡陵。 [[3]](#note-3)


<a id="event-4"></a>

4. **从平燕、取韩信、讨代与卢绾。** 刘邦称帝后给樊哙加邑八百户。樊哙参加平臧荼、在陈地拘楚王韩信，改封舞阳侯，剖将封符分执以凭世袭。继而讨韩王信、陈豨、曼丘臣及其胡人同党，在代地捕斩多名将吏，所斩韩信为韩王，与先被拘的楚王有别。卢绾反后樊哙以相国破燕军，最终定食五千四百户。末尾区分随军功与独领军功，列破军、下城、定郡县和获官人数。 [[4]](#note-4)


<a id="event-5"></a>

5. **樊哙闯禁中劝帝见大臣。** 樊哙娶吕后之妹吕须，有子樊伉，诸将中与吕氏最亲。刘邦病时独与宦官在内，群臣不敢见。樊哙破门推开，借想起豐沛起兵与警惕秦赵高劝刘邦纳群臣议事，刘邦笑着起身。 [[5]](#note-5)


<a id="event-6"></a>

6. **舞阳侯的历次断绝和续封。** 惠帝六年樊哙死，谥武，子樊伉嗣。吕须封临光侯，吕氏当政时权重，吕后死后与樊伉同被诛。文帝使樊哙庶子市人继封，谥荒侯；子佗广继六年，被控是其母与荒侯弟所生，送吏免爵。平帝元始二年以樊哙玄孙之子樊章继封千户。 [[6]](#note-6)


<a id="event-7"></a>

7. **郦商起兵立功。** 分传题为郦商。郦商是高阳人，陈胜起兵时聚得数千青年，后率四千人在岐归沛公。攻长社先登获封信成君，随攻缑氏、断渡口、破洛阳东秦军、定南阳诸县，又别军取旬关，向西定汉中。 [[7]](#note-7)


<a id="event-8"></a>

8. **郦商从汉灭楚并定燕代。** 刘邦称王后以郦商为陇西都尉，另部定北地，破章邯别将，获武城食邑六千户。击楚得梁相国印并增四千，继续攻胡陵。称帝后郦商平臧荼，战龙脱、易下，升右丞相、持剖符食涿郡。定上谷、代郡、雁门并取赵相国印，回来统太上皇卫。随后讨陈豨、攻东垣和英布，改食曲周五千一百户。传末列独立统军破敌、所得郡县和官员。 [[8]](#note-8)


<a id="event-9"></a>

9. **郦寄诱吕禄交北军。** 郦商历事惠帝、吕后，吕后死时已病。其子郦寄字况，与北军将领吕禄交好，诸臣扣其父，迫使他诱吕禄出游，周勃遂控制北军而诛诸吕。郦商当年死谥景，传载郦寄继侯和时人讥为卖友。 [[9]](#note-9)


<a id="event-10"></a>

10. **郦寄围赵与曲周侯后嗣。** 七国之乱，郦寄围赵七个月未克，栾布平齐后来援，赵遂灭。景帝中二年，郦寄因想娶平原君之姊下狱失爵，改封其弟郦坚为缪侯继郦商。玄孙郦终根官太常，因巫蛊被诛。平帝元始间对一百多名高祖功臣之后授关内侯食邑。 [[10]](#note-10)


<a id="event-11"></a>

11. **夏侯婴与刘邦旧交。** 分传题为夏侯婴。夏侯婴原在沛县马厩驾车送客，常与亭长刘邦长谈。刘邦玩闹中弄伤他，经人告发，夏侯婴作证包庇，覆审时被关逾年、笞数百下，终于保全刘邦。 [[11]](#note-11)


<a id="event-12"></a>

12. **夏侯婴起兵奉车及攻秦。** 刘邦谋入沛，夏侯婴以县令史充使，夺沛后任太仆掌车。随军招降泗水监平，在雍丘、东阿、濮阳、开封、曲遇、洛阳等地用车疾攻，爵升执帛、执圭，后调滕令仍驾车从征蓝田等地。刘邦称汉王，夏侯婴封昭平侯，再任太仆，随入蜀汉。 [[12]](#note-12)


<a id="event-13"></a>

13. **彭城败退救两儿，随汉再振。** 彭城大败后，夏侯婴将后来成为惠帝与鲁元公主的两儿载上车。刘邦怕马累且追兵紧，反复将孩子踢下，夏侯婴始终重新抱上，护送至丰。刘邦在荥阳募散卒复振，给夏侯婴食沂阳；夏侯婴随攻下邑、陈地，定楚后加食兹氏。 [[13]](#note-13)


<a id="event-14"></a>

14. **征燕代、平城脱围和定封。** 夏侯婴参加平臧荼及捕楚王韩信，改食汝阴。征韩王信时败晋阳胡骑、深入平城，被围七日；汉使厚赠冒顿之妻，围开一处，夏侯婴故意缓行并张满弩向外警戒，终于脱困。此后攻句注北、平城南，又讨陈豨和英布，屡次增邑后最终定食汝阴六千九百户。 [[14]](#note-14)


<a id="event-15"></a>

15. **历事四朝、迎代王及滕公孙氏。** 夏侯婴从沛县起兵一直为刘邦太仆，惠帝、吕后感念他救惠帝与鲁元，赐近宫第一等北宅，连读下行称「近我」。吕后死后他与东牟侯入宫废少帝，再以帝王仪仗迎代王刘恒，仍任太仆，文帝时卒谥文。曾孙夏侯颇娶平阳公主，因与父亲侍婢私通自杀失封。夏侯婴曾任滕令所以称滕公，后裔又因孙公主从母家姓而改孙。 [[15]](#note-15)


<a id="event-16"></a>

16. **灌婴出身与破秦初功。** 分传题为灌婴。灌婴在睢阳贩丝帛，项梁被章邯所杀后以中涓从刘邦。攻成武、杠里、开封、曲遇和洛阳东，南破秦守齮，西入武关、战蓝田，由七大夫进执帛、得宣陵君号，至霸上又得执圭和昌文君号。 [[16]](#note-16)


<a id="event-17"></a>

17. **灌婴自汉中归，受命统骑兵。** 刘邦称汉王，以灌婴为郎中，后升中谒者，随下栎阳、降塞王、围废丘、降殷王，在定陶南破龙且、项佗军而获昌文侯及杜平乡食邑。彭城败后退守雍丘，破王武、收外黄，因楚骑众，汉军想起用前秦骑士李必、骆甲；两人请以亲信为主将，刘邦遂任灌婴主骑、李骆为左右校尉，在荥阳东大破楚骑，继断楚饷道，迎韩信军后升御史大夫。 [[17]](#note-17)


<a id="event-18"></a>

18. **助韩信平齐，南进击楚。** 汉三年灌婴食杜平乡；率骑归韩信破历下、取临淄，获华毋伤、田光，追田横并斩田吸，随后在假密战龙且、擒周兰。韩信据齐取得王号后，灌婴下鲁北、薛、下相，渡淮到广陵，再北击项声等，下下邳、寿春、彭城及其附近各县，与刘邦会合并在陈地破项羽军，加二千五百户。定齐和击龙且属于前后接续的战程。 [[18]](#note-18)


<a id="event-19"></a>

19. **征韩王信、陈豨及英布。** 灌婴从征韩王信，别降楼烦以北六县，破武泉及晋阳胡骑，合掌诸国车骑在硰石取胜，又被困平城。讨陈豨时在曲逆击杀其丞相侯敞并下诸县、东垣。英布反，灌婴先发连破其别将和上柱国、大司马军，追至淮上，颍阴食邑最终五千户；传文另列合军与别将的战绩。 [[19]](#note-19)


<a id="event-20"></a>

20. **傅宽从攻秦楚，定齐受封。** 分传题为傅宽。傅宽由魏五大夫骑将加入刘邦，随战安阳、杠里、开封、曲遇等地。汉王封共德君，入汉中任右骑将，定三秦获食雕阴，后来赐通德侯，再击楚将项冠、周兰、龙且而加邑。归韩信破历下齐军，又从曹参攻博，定齐后剖符为阳陵侯二千六百户，为齐右丞相备守，五年后升齐相国。 [[20]](#note-20)


<a id="event-21"></a>

21. **傅宽驻代及阳陵侯除国。** 讨陈豨时傅宽从周勃，以相国代樊哙参加进攻，一月后徙代相国统兵驻守，又任丞相领屯军。惠帝五年死谥景；曾孙傅偃以谋反伏诛，国除。 [[21]](#note-21)


<a id="event-22"></a>

22. **靳歙从军、平陇西和守荥阳。** 分传题为靳歙。靳歙自宛朐从军，攻济阳、李由、开封东、蓝田北，封临平君；汉王封建武侯、任骑都尉。回定三秦，另破章平、下陇西六县，彭城败后退保雍丘，攻王武、邢说等，攻下荥阳东楚军，食四千二百户。 [[22]](#note-22)


<a id="event-23"></a>

23. **靳歙下赵与江陵，战代及世系。** 靳歙另击河内朝歌及赵地，降赵国将吏、下邯郸和平阳、邺等地，再攻成皋、断楚饷、击楚将、赴陈。又下江陵、俘江陵王、定南郡，随赴陈取楚王韩信，剖符为信武侯。以后从征韩王信、击陈豨和英布，定食五千三百户，末列功级与所得。高后五年卒谥肃，子靳亭继承，后以罪除国。 [[23]](#note-23)


<a id="event-24"></a>

24. **周惞从起沛及阻高祖亲征。** 底本题名和正文作周惞，自沛县起兵便侍从刘邦，在蜀汉、三秦与荥阳间常任参乘，因战局不论利钝始终随主，被封信武侯。刘邦欲亲征陈豨，他哭谏，说秦并天下尚不用君主屡次亲征；刘邦以为出自爱护，特许他入殿门不疾趋。 [[24]](#note-24)


<a id="event-25"></a>

25. **周氏先后改封与爵位断绝。** 高帝十二年徙封，底本作「糨城侯」，旧文另见蒯成侯和周緤。文帝五年死谥贞，子周昌继嗣而以罪除国，景帝复封其子周应为鄲侯，谥康。周仲居以太常获罪，再除国。 [[25]](#note-25)


<a id="event-26"></a>

26. **班固论出身、时势和郦寄。** 赞引用孔子说杂色牛所生犊若红而角正可作祭牲，喻士的才用无关门第。樊哙、夏侯婴、灌婴以屠宰、驾车、贩帛发身，因逢其时而立功福及子孙。班固辨郦寄在父被挟持之际保全君亲、安定汉室，不当以唯利忘义的卖友看待。 [[26]](#note-26)

> 項籍死，漢王即皇帝位，以噲有功，益食邑八百戶。其秋，燕王臧荼反，噲從攻虜荼，定燕地。楚王韓信反，噲從至陳，取信，定楚。更賜爵列侯，與剖符，世世勿絕，食舞陽，號為舞陽侯，除前所食。以將軍從攻反者韓王信於代。自霍人以往至雲中，與絳侯等共定之，益食千五百戶。因擊陳狶與曼丘臣軍，戰襄國，破柏人，先登，降之定清河、常山凡二十七縣，殘東垣，遷為左丞相。破得綦母印、尹潘軍於無終、廣昌。破豨別將胡人王黃軍代南，因擊韓信軍參合。軍所將卒斬韓信，擊豨胡騎橫谷，斬將軍趙既，虜代丞相馮梁、守孫奮、大將王黃、將軍大將一人、太僕解福等十人。與諸將共定代鄉邑七十三。後燕王盧綰反，噲以相國擊綰，破其丞相抵薊南，定燕縣十八，鄉邑五十一。益食千三百戶，定食舞陽五千四百戶。從，斬首百七十六級，虜二百八十七人。別，破軍七，下城五，定郡六，縣五十二，得丞相一人，將軍十三人，二千石以下至三百石十二人。

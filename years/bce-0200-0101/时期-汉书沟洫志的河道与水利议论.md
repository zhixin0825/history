# 汉书沟洫志的河道与水利议论

[本世纪目录](README.md) · [全部世纪](../README.md)

此处连读各志的制度沿革、学术分类与未详年次的史事；整段原文和已系年节录均可由卷内读本查阅。


<a id="event-1"></a>

1. **禹治洪水及黄河水道。** 志文据《禹贡》讲禹因地选交通方式，疏通山川湖泽，辨九州、定贡赋。黄河从积石、龙门经华阴、砥柱、盟津到大伾，受高差影响多冲决，继分渠北行、汇为九河入海。这是经传中的治水地理。 [[1]](#note-1)


<a id="event-2"></a>

2. **鸿沟及各地旧渠。** 从荥阳引河水入鸿沟，连济、汝、淮、泗，交通宋、郑等地；楚、吴、齐及蜀也有分水和通航渠道，李冰在蜀治水、开成都二江。通航之外可灌田。 [[2]](#note-2)


<a id="event-3"></a>

3. **西门豹与史起治邺异说。** 西门豹任邺令素有声誉，史起却说邺受田多是田差，漳水就在旁而未引，不能以此效法。史起出任邺令，引漳灌田，民谣赞盐碱地长稻粱。本志把引漳功归史起。 [[3]](#note-3)


<a id="event-4"></a>

4. **郑国渠兴建及完成。** 韩国劝秦兴大渠以牵制东伐。秦发现郑国使命后拟杀他，郑国以渠成同时有利于秦为辩，秦让他完工。志称引泾、循北山东入洛，泥水改良盐碱地并使关中增产。始议、发现用间和竣工不指定同日或同年。 [[4]](#note-4)


<a id="event-5"></a>

5. **瓠子决口和第一次堵塞。** 元光年间瓠子决口，水入钜野、淮、泗。汲黯与郑当时堵口屡败。田蚡食邑在河以北，决口北岸受灾较轻，他以决河是天意反对硬堵，工程长期停顿。 [[5]](#note-5)


<a id="event-6"></a>

6. **郑当时议开漕渠。** 旧漕道循渭水九百余里，需约半年。郑当时建议自长安沿南山开渠，约三百里达河，运输时间可减半，沿渠田也可受灌。徐伯测线，征发数万人，三年后通航并逐渐灌田。 [[6]](#note-6)


<a id="event-7"></a>

7. **番系开汾河渠及其结局。** 番系估算，汾河与黄河引水能改造五千顷弃地，每年得谷二百万石，减少砥柱航运损失。朝廷征卒试行，因河势改移和水利不足，田产连种子也收不回，最终停止官营。 [[7]](#note-7)


<a id="event-8"></a>

8. **褒斜陆路与漕运设想。** 张汤考察从褒、斜两水间转运的提议。张卬任汉中太守并组织开道，新路较平直，实际水路湍急多石，未能用来漕运。 [[8]](#note-8)


<a id="event-9"></a>

9. **龙首渠与井渠施工。** 严熊建议临晋引洛灌溉。沟岸易坍，于是改挖深井、在井底横通水路，穿过商颜山。工程延续十余年才有部分通水，尚未得到所预期的产量。 [[9]](#note-9)


<a id="event-10"></a>

10. **第二章引语。** “一曰”承前引出另一章《瓠子歌》。 [[10]](#note-10)


<a id="event-11"></a>

11. **各地灌溉扩展。** 西北朔方、西河、河西、酒泉，关中的灵轵、成国、湋渠及淮河、东海、泰山等地皆记引水灌田。段中为工程群概叙，田亩数为志书统计。 [[11]](#note-11)


<a id="event-12"></a>

12. **白公开渠。** 太始二年赵中大夫白公请在谷口引泾，至栎阳注入渭水，名白渠。志载全长约二百里、灌田四千五百余顷，民歌称含泥泾水既灌田又肥田。 [[12]](#note-12)


<a id="event-13"></a>

13. **延年建议黄河北移。** 齐人延年认为可借西北高东南低的地势，把河引经北方，再东注海，以同时减洪灾和边防负担。武帝称其思虑深，却认为禹旧道难轻改。 [[13]](#note-13)


<a id="event-14"></a>

14. **屯氏河、郭昌改渠与灵鸣犊口。** 黄河曾在馆陶北决，屯氏河成为分流，东北经多郡入海。宣帝地节年间郭昌截直数处弯道；元帝永光五年清河灵鸣犊口决，屯氏河断流。三次变化分读。 [[14]](#note-14)


<a id="event-15"></a>

15. **冯逡与许商争论复浚。** 冯逡指出分流中断后单河难泄洪，主张复浚屯氏河并改贝丘弯道；许商实地验看后以易泛溢、财用不足，不同意当时施工。 [[15]](#note-15)


<a id="event-16"></a>

16. **王莽时治河众议。** 关并主张留出历史洪泛带，张戎主张停止上游引水以加速输沙，韩牧建议尽量恢复九河，王横从海浸和河徙推定另经西山麓北出；桓谭主张核验、筹费再动工。志称这些建议当时未实施。 [[16]](#note-16)


<a id="event-17"></a>

17. **班固总结河患与国计。** 班固引用禹治水的旧说，说明黄河在四渎中地位突出、治水牵涉国家利害，故记录各时期利弊和异议。 [[17]](#note-17)

> 成帝初，清河都尉馮逡奏言：「郡承河下流，與兗州東郡分水為界，城郭所居尤卑下，土壤輕脆易傷。頃所以闊無大害者，以屯氏河通，兩川分流也。今屯氏河塞，靈鳴犢口又益不利，獨一川兼受數河之任，雖高增隄防，終不能泄。如有霖雨，旬日不霽，必盈溢。靈鳴犢口在清河東界，所在處下，雖令通利，猶不能為魏郡、清河減損水害。禹非不愛民力，以地形有勢，故穿九河，今既滅難明，屯氏河不流行七十餘年，新絕未久，其處易浚。又其口所居高，於以分殺水力，道里便宜，可復浚以助大河泄暴水，備非常。又地節時郭昌穿直渠，後三歲，河水更從故第二曲間北可六里，復南合。今其曲勢復邪直貝丘，百姓寒心，宜復穿渠東行。不豫修治，北決病四五郡，南決病十餘郡，然後憂之，晚矣。」事下丞相、御史，白博士許商治尚書，善為算，能度功用。遣行視，以為屯氏河盈溢所為，方用度不足，可且勿浚。

### 16. 王莽时治河众议

**[《汉书·沟洫志》P031](../../拆分史书/汉书/卷029.md#p031)** · [仓内TXT L6125—L6125](../../拆分史书/汉书/卷029.md#part-1-L6125)

> 王莽時，徵能治河者以百數，其大略異者，長水校尉平陵關並言：「河決率常於平原、東郡左右，其地形下而土疏惡。聞禹治河時，本空此地，以為水猥，盛則放溢，少稍自索，雖時易處，猶不能離此。上古難識，近察秦漢以來，河決曹、衛之域，其南北不過百八十里者，可空此地，勿以為官亭民室而已。」大司馬史長安張戎言：「水性就下，行疾則自刮除成空而稍深。河水重濁，號為一石水而六斗泥。今西方諸郡，以至京師東行，民皆引河、渭山川水溉田。春夏乾燥，少水時也，故使河流遲，貯淤而稍淺；雨多水暴至，則溢決。而國家數隄塞之，稍益高於平地，猶築垣而居水也。可各順從其性，毋復灌溉，則百川流行，水道自利，無溢決之害矣。」御史臨淮韓牧以為「可略於禹貢九河處穿之，縱不能為九，但為四五，宜有益。」大司空掾王橫言：「河入勃海，勃海地高於韓牧所欲穿處。往者天嘗連雨，東北風，海水溢，西南出，浸數百里，九河之地已為海所漸矣。禹之行河水，本隨西山下東北去。周譜云定王五年河徙，則今所行非禹之所穿也。又秦攻魏，決河灌其都，決處遂大，不可復補。宜卻徙完平處，更開空，使緣西山足乘高地而東北入海，乃無水災。」沛郡桓譚為司空掾，典其議，為甄豐言：「凡此數者，必有一是。宜詳考驗，皆可豫見，計定然後舉事，費不過數億萬，亦可以事諸浮食無產業民。空居與行役，同當衣食；衣食縣官，而為之作，乃兩便，可以上繼禹功，下除民疾。」王莽時，但崇空語，無施行者。

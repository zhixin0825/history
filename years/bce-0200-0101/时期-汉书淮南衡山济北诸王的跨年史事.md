# 汉书淮南衡山济北诸王的跨年史事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **刘长之母死于赵狱牵连。** 刘长是高帝幼子，母本赵王张敖的美人，高帝路过赵国临幸后怀孕，张敖另筑外舍。贯高案发，连赵王家属美人一并下狱，她说怀帝子，刘邦正怒赵，无暇查理。弟赵兼借审食其请吕后代奏，吕后妒而不言，审食其也不强争。生下刘长后她怨愤自杀，高帝得子后悔，命吕后抚养，葬母于其家乡真定。 [[1]](#note-1)


<a id="event-2"></a>

2. **刘长王淮南，杀审食其而获赦。** 英布反后高帝以少子刘长王淮南。他幼年依吕后，惠帝、高后时受宠，暗恨审食其。文帝朝因亲近多不守法，文帝宽免。文帝三年入朝，他用锤击倒审食其再令从人杀之，自首列举其不救母、不阻杀刘如意母子、不阻吕氏封王三罪。文帝悯其情并以亲故赦免。 [[2]](#note-2)


<a id="event-3"></a>

3. **刘长回国任意施政，薄昭举文帝的宽惠。** 刘长因朝廷上下惧其气势，归国不用汉法、用天子的清道警戒和命令称式。文帝先自责谕，继令舅父薄昭致书。薄昭先肯定刘长原有的天资，随后逐一指出文帝愿为他置换侯邑、赦擅杀列侯、容其自择高官、不许他降为布衣，厚待如此，他应奉法修贡。 [[3]](#note-3)


<a id="event-4"></a>

4. **薄昭指出淮南王八种危险行为。** 高帝以霜露征战、身受创伤换来千里封土与臣属，薄昭劝刘长修身奉祀，不忘创业。责他舍土求让名而不孝，不能守父业而不贤，先母后父而不义，逆令不顺，节行凌兄无礼，滥刑不仁，重游侠而轻王位为不智，轻学妄行而欠审慎，八者皆取亡之道。 [[4]](#note-4)


<a id="event-5"></a>

5. **薄昭以宗亲伏法为鉴，劝刘长自劾。** 薄昭以管蔡、齐桓、秦始皇和汉初诸王惩处说明宗亲也不能免。各级吏员对收容来亡者有明确职责，相不能置身事外，否则汉会拘王并治其亲属宾客。他代拟请罪文，劝王趁早低头换上和下寿，祸发如出箭便不可收。 [[5]](#note-5)


<a id="event-6"></a>

6. **刘长四子封侯、追谥及三国分立。** 文帝八年封刘长四幼子安、勃、赐、良为侯。传载民歌以尺布斗粟讥兄弟不相容，文帝以历代诛放骨肉为公说明，迁城阳王刘喜至淮南故地、追谥厉王并置园；相关年代见本文系年。十六年刘喜返城阳，刘安王淮南、刘勃王衡山、刘赐王庐江，各分一块故国，刘良早死无后。 [[6]](#note-6)


<a id="event-7"></a>

7. **淮南王刘安的著作与朝见。** 刘安好书琴、不好游猎，企求以不张扬的惠政安抚百姓。招数千宾客与方术士，作内书二十一篇、众多外书及八卷中篇，后者论神仙与炼金术、二十余万言。武帝喜文，又敬诸父辩博，回书使司马相如等审稿。刘安入朝献内篇，武帝珍藏，又命他迅速作《离骚传》，刘安还献颂德和长安都国颂，君臣常谈到傍晚。 [[7]](#note-7)


<a id="event-8"></a>

8. **田蚡迎刘安议储、彗星与王室权力。** 刘安初入朝，旧交田蚡在霸上以无太子、刘安仁义近宗劝他自期继位，得厚赂。建元六年见彗，宾客以七国战前彗星诱其疑将大乱，刘安储兵具散财笼络郡国。爱女刘陵善辩，被遣侦察京师、结内侍。元朔二年赐几杖免朝；刘安怕太子妻泄密，授意太子刘迁疏离，终使妇归。后荼、刘迁、刘陵专权夺产滥押。 [[8]](#note-8)


<a id="event-9"></a>

9. **雷被出逃，刘安削地后备叛更急。** 雷被比剑误伤太子，后请从军击匈奴，被王斥退，走长安陈诉。太子迟不应捕，汉查及刘安，王与太子预谋遇捕便刺使者、杀中尉发兵。汉中尉宏先就地问案，朝廷最终免死和废王，仅削两县，刘安引以为耻。刘安更听无皇子之谣，与左吴等读图部署，认为宫车晏驾后必有诸王争位，不愿屈事年少诸王。 [[9]](#note-9)


<a id="event-10"></a>

10. **预作兵变器具，伍被告官后事发。** 伍被先以七国前鉴劝止，刘安惧案情泄露仍作玺印符节、设想刺卫青并迫公孙弘屈服，又拟假报宫火杀高官、假报南越入兵为征兵口实。朝廷逮太子时，王召群臣而仅相到，遂止杀相。太子自刭未死，伍被到官自首全告，王后、太子和宾客被收，谋反器具为证，数千牵连者按罪轻重惩治。 [[10]](#note-10)


<a id="event-11"></a>

11. **衡山后宫亲属与卫庆案。** 衡山刘赐原后乘舒生刘爽、刘无采、刘孝，另有徐来、厥姬及其子女。刘赐与兄刘安有嫌，也结宾客防被吞并。元光六年刘赐因方士卫庆求进天子而逼其认死罪，内史退案，刘赐告内史不成，又因侵田坏坟，有司请捕；武帝改为替王设置二百石以上官员。刘赐愤而与奚慈等罗致知兵法、星占的人。 [[11]](#note-11)


<a id="event-12"></a>

12. **衡山储位内斗及谋反准备。** 乘舒死后徐来继后，厥姬谗称徐来毒害乘舒。太子伤徐来兄、斥妹刘无采私通，多人结怨并获王笞。元朔四年后养母被伤，王疑太子，病时又信太子幸灾之谗欲立刘孝。徐来想用王宠舞者污孝而立己子刘广，太子欲私徐来平怨又被告，反斥孝和无采后遭囚。王给刘孝印、财，招枚赫、陈喜造兵车箭矢、假印，以防刘安成功后兼吞衡山，企图据江淮。 [[12]](#note-12)


<a id="event-13"></a>

13. **济北后嗣及传赞。** 刘勃由衡山徙济北，合前后王年十四而死，子刘胡五十四年而终，孙刘宽因私通父妾、祝诅天子受召，自刎，济北末改北安县归泰山。赞援《诗》，批评淮南、衡山父子有大国而不守藩职，且把部分原因归为王下臣属、地方风习。 [[13]](#note-13)

**[《汉书·淮南衡山济北王传》P001](../../sources/摘录/汉书-卷044-淮南衡山济北王传.md#p001)** · [仓内TXT L7422—L7422](../../sources/本地分卷/汉书/汉书-卷044.md#L7422)

> 淮南厲王長，高帝少子也，其母故趙王張敖美人。高帝八年，從東垣過趙，趙王獻美人，厲王母也，幸，有身。趙王不敢內宮，為築外宮舍之。及貫高等謀反事覺，并逮治王，盡捕王母兄弟美人，繫之河內。厲王母亦繫，告吏曰：「日得幸上，有子。」吏以聞，上方怒趙，未及理厲王母，厲王母弟趙兼因辟陽侯言呂后，呂后妒，不肯白，辟陽侯不強爭。厲王母已生厲王，恚。即自殺。吏奉厲王詣上，上悔，令呂后母之，而葬其母真定。真定，厲王母家縣也。

### 2. 刘长王淮南，杀审食其而获赦

[返回正文第2条](#event-2)

<a id="hs044-p002"></a>

**[《汉书·淮南衡山济北王传》P002](../../sources/摘录/汉书-卷044-淮南衡山济北王传.md#p002)** · [仓内TXT L7423—L7423](../../sources/本地分卷/汉书/汉书-卷044.md#L7423)

> 十一年，淮南王布反，上自將擊滅布，即立子長為淮南王。王早失母，常附呂后，孝惠、呂后時以故得幸無患，然常心怨辟陽侯，不敢發。及孝文初即位，自以為最親，驕蹇，數不奉法。上寬赦之。三年，入朝，甚橫。從上入苑獵，與上同輦，常謂上「大兄」。厲王有材力，力扛鼎，乃往請辟陽侯。辟陽侯出見之，即自袖金椎椎之，命從者刑之。馳詣闕下，肉袒而謝曰：「臣母不當坐趙時事，辟陽侯力能得之呂后，不爭，罪一也。趙王如意子母無罪，呂后殺之，辟陽侯不爭，罪二也。呂后王諸呂，欲以危劉氏，辟陽侯不爭，罪三也。臣謹為天下誅賊，報母之仇，伏闕下請罪。」文帝傷其志，為親故不治，赦之。

### 4. 薄昭指出淮南王八种危险行为

[返回正文第4条](#event-4)

<a id="hs044-p004"></a>

**[《汉书·淮南衡山济北王传》P004](../../sources/摘录/汉书-卷044-淮南衡山济北王传.md#p004)** · [仓内TXT L7426—L7426](../../sources/本地分卷/汉书/汉书-卷044.md#L7426)

> 夫大王以千里為宅居，以萬民為臣妾，此高皇帝之厚德也。高帝蒙霜露，沬風雨，赴矢石，野戰次城，身被創痍，以為子孫成萬世之業，艱難危苦甚矣。大王不思先帝之艱苦，日夜怵惕，修身正行，養犧牲，豐潔粢盛，奉祭祀，以無忘先帝之功德，而欲屬國為布衣，甚過。且夫貪讓國土之名，輕廢先帝之業，不可以言孝。父為之基，而不能守，不賢。不求守長陵，而求之真定，先母後父，不誼。數逆天子之令，不順。言節行以高兄，無禮。幸臣有罪，大者立斷，小者肉刑，不仁。貴布衣一劍之任，賤王侯之位，不知。不好學問大道，觸情妄行，不詳。此八者，危亡之路也，而大王行之。棄南面之位，奮諸、賁之勇，常出入危亡之路，臣之所見，高皇帝之神必不廟食於大王之手，明白。

### 7. 淮南王刘安的著作与朝见

[返回正文第7条](#event-7)

<a id="hs044-p010"></a>

**[《汉书·淮南衡山济北王传》P010](../../sources/摘录/汉书-卷044-淮南衡山济北王传.md#p010)** · [仓内TXT L7437—L7437](../../sources/本地分卷/汉书/汉书-卷044.md#L7437)

> 淮南王安為人好書，鼓琴，不喜弋獵狗馬馳騁，亦欲以行陰德拊循百姓，流名譽。招致賓客方術之士數千人，作為內書二十一篇，外書甚眾，又有中篇八卷，言神仙黃白之術，亦二十餘萬言。時武帝方好藝文，以安屬為諸父，辯博善為文辭，甚尊重之。每為報書及賜，常召司馬相如等視草乃遣。初，安入朝，獻所作內篇，新出，上愛祕之。使為離騷傳，旦受詔，日食時上。又獻頌德及長安都國頌。每宴見，談說得失及方技賦頌，昏莫然後罷。

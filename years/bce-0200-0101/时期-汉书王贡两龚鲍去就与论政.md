# 汉书王贡两龚鲍去就与论政

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **伯夷叔齐与隐士之义。** 以武王灭商迁鼎和伯夷、叔齐饿于首阳开篇。周虽被称有盛德，孔子仍嘉许二人不损志、不辱身；孟子说闻伯夷之风足以化贪为廉、使怯者立志，影响可以历久。 [[1]](#note-1)


<a id="event-2"></a>

2. **商山四皓从刘盈入见。** 秦时园公、绮里季、夏黄公、甪里先生居商雒避乱。高帝征而不至，吕后依张良计请太子卑辞厚礼以安车迎。他们随太子见帝，被高帝敬为客，增强刘盈的地位。由留侯本传可详其过程。 [[2]](#note-2)


<a id="event-3"></a>

3. **郑子真不屈，严君平卜肆授《老子》。** 谷口郑子真拒王凤礼聘。严君平在成都市占卜，借答占教人以孝、顺、忠，每日够百钱便闭肆讲《老子》，宗老庄著书十余万言。扬雄少从其学，后告益州牧李强可以礼见而不可屈致；李强会后果然没有开口请他出仕。君平九十余岁仍守其业。 [[3]](#note-3)


<a id="event-4"></a>

4. **逸民与以礼进退的仕者。** 商山四皓、郑子真、严君平均未仕，作者认为他们能激励世俗；转入王吉、贡禹与楚两龚虽仕而以礼进退的材料。 [[4]](#note-4)


<a id="event-5"></a>

5. **王吉传分目。** 以下由逸民转叙曾任昌邑中尉的王吉。 [[5]](#note-5)


<a id="event-6"></a>

6. **王吉进入昌邑并止王游猎。** 王吉字子阳，琅琊皋虞人，少习经，举孝廉为郎，历若卢右丞、云阳令，举贤良为昌邑中尉。王好无节制地游猎，王吉因而上疏。 [[6]](#note-6)


<a id="event-7"></a>

7. **陈驰驱扰农并引甘棠典故。** 王吉以师行日三十里、吉行五十里对照，指出王去方与半日跑二百里，使民废耕修道、牵马。引《诗》及召公不夺农时、树下听事、百姓爱护甘棠的故事。 [[7]](#note-7)


<a id="event-8"></a>

8. **劝勿以田猎损身与废学。** 列车马奔驰、交叱执辔和雾露尘沙、冬冷夏热，认为不读书而疲于驰驱，损害身体、寿命与仁义修养。 [[8]](#note-8)


<a id="event-9"></a>

9. **以从师习古和导养代驰猎。** 建议随明师学唐虞、殷周治道，读书改变德行，休息时舒展、步行、吐纳养神；以尧舜和王子乔、赤松子的长寿观念激励昌邑王。 [[9]](#note-9)


<a id="event-10"></a>

10. **提醒昌邑王兼有子臣之责。** 王吉说皇帝哀思未怠，未以游猎宫苑自娱；昌邑王于宗属至亲、朝位是臣，须尽亲爱与臣义，稍有违失传到朝廷，有害封国。 [[10]](#note-10)


<a id="event-11"></a>

11. **昌邑王厚赐而依旧放纵。** 刘贺自知王吉忠谏，赐牛肉、酒、干肉，却继续游猎放纵。王吉仍屡谏，虽非治民官而受国人敬重。底本赐令作“中慰”。 [[11]](#note-11)


<a id="event-12"></a>

12. **重新起用为益州刺史与谏官。** 王吉复出为益州刺史，病去后征为博士、谏大夫。宣帝沿武帝旧制，宫室车服比昭帝盛，外戚许、史、王氏显贵；皇帝亲政用能吏，王吉陈利弊。 [[12]](#note-12)


<a id="event-13"></a>

13. **质疑官吏只重考期簿书。** 明主愿受谏而难逢，王吉责公卿没有建立长策，只忙办文书、守期会、听讼狱，难以奠太平之基。 [[13]](#note-13)


<a id="event-14"></a>

14. **慎选左右与出使之人。** 教化由近及远，宫中行为终会传遍天下；近臣可以规正君身，奉使者可以布德，故两处选人皆须谨慎，以文王多士为证。 [[14]](#note-14)


<a id="event-15"></a>

15. **邻家枣树与王吉休妻复妻。** 王妻取邻树垂进自家院的枣，王吉知后休妻；邻人欲伐树，乡里制止又劝复其妻，因此生出谣语。传用此见其自持峻厉。 [[15]](#note-15)


<a id="event-16"></a>

16. **王吉、贡禹同征，王吉死途中。** 两人志向取舍相同，世说王阳入位、贡公弹冠。元帝初征两人，王吉年高，病卒于赴京途中，帝遣人吊祭。 [[16]](#note-16)


<a id="event-17"></a>

17. **王骏经学、京兆政绩及升御史。** 王吉兼通五经，令其子王骏学梁丘《易》。王骏经陈咸、匡衡举荐，历谏大夫等，因父戒王国官而辞赵内史，出任幽州刺史及司隶，劾免匡衡。久任少府后试京兆尹，与王尊、王章并称三王；谷永先举有实绩的薛宣，薛宣升相后王骏接御史大夫，死后翟方进继任。王骏妻卒不复娶。 [[17]](#note-17)


<a id="event-18"></a>

18. **王崇因东平案贬秩，后为大司空。** 王骏子王崇历郡守、刺史。建平三年自河南太守为御史大夫，因安成侯夫人放与己有姻亲而上疏辩救，哀帝责其徇私，下迁大司农，后历卫尉、左将军。平帝即位前后继彭宣任大司空、封扶平侯，又避王莽辞职就国，被傅婢毒死，侯国除。 [[18]](#note-18)


<a id="event-19"></a>

19. **王氏三代清廉与服用之辨。** 王吉至王崇世以廉洁著名，官位日高而才能名声渐不及上代。家用车马服饰鲜明，但没有金银锦绣，不积财，一离官即衣布吃粗粮，世人服其廉又惊其华，传有王阳能作黄金之语。 [[19]](#note-19)


<a id="event-20"></a>

20. **贡禹传分目。** 以下叙与王吉同征的贡禹。 [[20]](#note-20)


<a id="event-21"></a>

21. **贡禹早年任官及自免。** 贡禹字少翁，琅邪人，经学与洁行知名，曾任博士、凉州刺史，病免；举贤良为河南令，因公事受上府责，免冠谢后以不肯再戴此冠为由辞官。 [[21]](#note-21)


<a id="event-22"></a>

22. **贡禹任谏大夫与饥年奏议。** 元帝刚即位征贡禹为谏大夫，虚心问政。当时歉收、郡国困窘，遂上论节用。 [[22]](#note-22)


<a id="event-23"></a>

23. **贡禹所举古代节用约束。** 称古代宫女马匹有数，宫墙朴素，稀少苑囿与民共用。取十一之税，不另大兴役戍，所役日有限，畿外按职贡献，借此标举家给人足。 [[23]](#note-23)


<a id="event-24"></a>

24. **以汉初节俭反观君臣竞奢。** 称高、文、景宫女和厩马少，文帝衣帛履革、器无雕金。后世君臣竞争僭用，服饰甚至难辨君臣，仍像鲁昭公一样不自知。 [[24]](#note-24)


<a id="event-25"></a>

25. **列宫廷和园陵支出弊端。** 贡禹以齐三服官、蜀广汉金银器、织室及厩马所费反衬灾民相食。追责武帝后宫扩增及霍光厚葬、安置宫女于陵，认为到昭、宣仍沿旧制，奢妾厚葬之风因上而下。 [[25]](#note-25)


<a id="event-26"></a>

26. **请省御用、宫女和苑地。** 请减乘舆器用三分之二，留二十名贤宫女，遣无子园女归，裁厩马，只留城南田猎场；把其他苑地还给贫民，以《诗》强调在灾年应主动自减。 [[26]](#note-26)


<a id="event-27"></a>

27. **元帝分次采用减省建议。** 诏减太仆食粮的马、水衡食肉的兽，省宜春下苑给贫民，又停角抵和齐三服官，贡禹迁光禄大夫。传把有关措施连叙，本纪与《通鉴》可见分年。 [[27]](#note-27)


<a id="event-28"></a>

28. **贡禹自叙贫老求归。** 说自己旧日家产不满万钱，为应征卖田，受两次任官厚俸、御医和赏赐。八十一岁耳目日衰，只一十二岁子，恐死在离家三千里外，求生还故里。 [[28]](#note-28)


<a id="event-29"></a>

29. **元帝慰留，贡禹迁御史大夫。** 元帝以伯夷之廉、史鱼之直比贡禹，愿继续问政，并表示能料理其家，令慎疾。其后迁长信少府；陈万年卒后接御史大夫。 [[29]](#note-29)


<a id="event-30"></a>

30. **请延迟儿童口钱征收年龄。** 贡禹说武帝对外用兵加征口钱，儿童三岁就纳税，困户甚至生子即杀，因请七岁换齿起出口钱，二十岁纳算赋。 [[30]](#note-30)


<a id="event-31"></a>

31. **主张废金钱和采铸，鼓励务农。** 认为矿铁吏卒动员十万以上，加深粮供压力；开矿伐木在其灾异解释中可影响水旱。又批评盗铸获刑、商贾厚利而农民负谷槁税及私派，遂主张不用钱币，布帛谷物交租、领俸，约束市场、归农。 [[31]](#note-31)


<a id="event-32"></a>

32. **建议减宫卫、免官奴婢并替戍。** 主张离宫与长乐宫卫减过半，指出官奴婢十余万费用甚大，请免为庶人、发给廪粮，替关东之戍守北边亭塞。 [[32]](#note-32)


<a id="event-33"></a>

33. **禁止近臣之家经商牟利。** 贡禹建议诸曹、侍中以上家人不得私贩与民争利，发现即免官削爵，不许复仕。 [[33]](#note-33)


<a id="event-34"></a>

34. **以文帝与武帝制度对照官风。** 称文帝尚廉、禁商贾赘婿及赃吏任官，无赎罪制度，断狱少。武帝财用不足转行赎罪、入谷补吏，促使地方重文簿欺上与苛暴威下，俗尚财利，贡禹以此追究社会价值倒置。 [[34]](#note-34)


<a id="event-35"></a>

35. **建议实举廉士，严惩官吏贪赃。** 主张除赎罪，守相选举失实或有赃不能只免官，以改变利害。用孔子无位而道为天下所用说明帝王可兴教化，又以西周成康以来难复太平归咎舍法任私、弃仁从奢。 [[35]](#note-35)


<a id="event-36"></a>

36. **劝节用择贤并放出陵女。** 请纪念高祖创业、遵文帝俭约，修身选贤，远佞惩奸，遣出园陵女子，减倡乐和奢华器物，并使百姓安农，望与古王比治。 [[36]](#note-36)


<a id="event-37"></a>

37. **采纳延口钱、罢宫馆与减卫。** 帝准七岁始出口钱，裁少到的上林宫馆，减建章、甘泉与诸侯王庙卫卒。其余未全从；贡禹又倡罢郡国庙、定亲尽迭毁，生前未行。 [[37]](#note-37)


<a id="event-38"></a>

38. **贡禹任御史大夫数月而卒。** 朝廷赐钱百万、以子为郎，子后做到东郡都尉。元帝随后追思其议，罢郡国庙并议定宗庙迭毁，由韦玄成本传详述。 [[38]](#note-38)


<a id="event-39"></a>

39. **楚两龚传分目。** 以下叙龚胜、龚舍，合称楚两龚。 [[39]](#note-39)


<a id="event-40"></a>

40. **龚胜、龚舍的共同声名。** 龚胜字君宾、龚舍字君倩，楚人相友并以名节著称。都少好学通经；胜做郡吏，舍初未仕。 [[40]](#note-40)


<a id="event-41"></a>

41. **哀帝召龚胜及其所举人才。** 楚王礼聘龚舍为常侍，舍求辞复学。龚胜以王国人未由孝廉补宿卫，辗转作尉、丞、县令。何武、阎崇推荐，哀帝召为谏大夫；龚胜荐龚舍、甯寿、侯嘉，又争取以车迎贤，有人应诏、有人病辞。 [[41]](#note-41)


<a id="event-42"></a>

42. **龚胜反对奢刑和董贤乱制。** 劝因贫、盗、薄俗、灾异而俭、省刑、宽赋，承王吉贡禹思路。任谏官二年余历丞相司直、光禄大夫，短暂守右扶风，转回给事中；因指董贤破坏制度而忤帝意。 [[42]](#note-42)


<a id="event-43"></a>

43. **龚胜与夏侯常争复惠景庙。** 稍后众议复孝惠、孝景之庙，龚胜强调依礼，夏侯常称礼可变；二人冲突，常斥他以异议沽取清名，犹如申徒狄。 [[43]](#note-43)


<a id="event-44"></a>

44. **二人获劾贬秩，龚胜谢病。** 先前夏侯常转闻高陵子杀母，龚胜上言；追核时常称出自平民且曾劝勿言。龚胜自劾与常争讼，两人被降一等。哀帝仍赐赏，任胜子为侍郎；胜以病不赴勃海太守，半年后免。 [[44]](#note-44)


<a id="event-45"></a>

45. **龚胜再召后卧病请归。** 哀帝又召为光禄大夫，龚胜常卧病，让儿子屡奏乞归，恰遇哀帝去世。 [[45]](#note-45)


<a id="event-46"></a>

46. **龚胜和邴汉按韩福旧例退休。** 邴汉历京兆尹、太中大夫，王莽掌权后与龚胜同求归。诏用昭帝礼送韩福旧例，沿路给酒肉、每岁问赐，命各荐一亲属为郎，并记邴氏侄曼容官不过六百石便自辞。 [[46]](#note-46)


<a id="event-47"></a>

47. **龚舍由病辞谏官、博士至归里。** 龚舍再三称病。哀帝令使者在楚拜他为太山太守，他说天下为王者之家，就在自家受印。数月辞归，抵京兆边上再称病，交太守印，授光禄大夫仍不起，终于遣归。 [[47]](#note-47)


<a id="event-48"></a>

48. **乡官以师礼敬两龚，龚舍卒。** 龚舍通五经、讲《鲁诗》。两龚在乡里时，新到长吏都以师礼来访。龚舍六十八岁在王莽居摄中去世，未载哪一年。 [[48]](#note-48)


<a id="event-49"></a>

49. **王莽再聘龚胜，龚胜绝食而死。** 王莽篡汉后遣五威将帅问候，次年聘讲学祭酒，龚胜称病。再有太子师友祭酒、上卿车马禄礼，使者欲强加印绶；他以不事二姓责问自己，交代薄葬，不再进食，十四日卒，年七十九。门人百余服丧，来吊老父以香薰膏灯自损惜之，后在彭城廉里表其门。 [[49]](#note-49)


<a id="event-50"></a>

50. **鲍宣传分目。** 以下论出仕直谏的鲍宣，并附诸末世清士。 [[50]](#note-50)


<a id="event-51"></a>

51. **鲍宣历官与任豫州牧被免。** 鲍宣字子都，渤海高城人，由乡啬夫、守县丞及功曹举孝廉，数因疾去。王商召荐，哀帝初受何武荐，任谏大夫、豫州牧，郭钦奏其干预地方署吏听讼及出行乘传违制，被免，数月复为谏大夫。 [[51]](#note-51)


<a id="event-52"></a>

52. **傅氏争尊号与鲍宣进谏。** 傅太后欲与王太后并尊并爵其亲，孔光、师丹、何武、傅喜因争议与失其意先后去职，丁傅势起，董贤显贵。鲍宣以直言少文入谏。 [[52]](#note-52)


<a id="event-53"></a>

53. **哀帝宽容鲍宣。** 皇帝把鲍宣视为有名的儒臣，没有以直谏治罪。 [[53]](#note-53)


<a id="event-54"></a>

54. **再奏从日食与白虹论进退。** 鲍宣先肯定哀帝避正殿、征直言、用孔光及逐孙息，认为人心欢悦。又以二月白虹干日、阴而不雨为当时民怨未解的天象解释。 [[54]](#note-54)


<a id="event-55"></a>

55. **再劾董贤受赏营第。** 说董贤靠容貌谀言显达，耗府库合并三第、拆暴室，役使官家人力，太官供其聚会。真欲保全他父子，应免而就国，退回乘舆器用。 [[55]](#note-55)


<a id="event-56"></a>

56. **请尽免孙息并复用故臣。** 鲍宣认为孙宠、息夫躬连就国都不当，建议免去侯爵，重新征何武、师丹、彭宣、傅喜，让百姓看到政策改易。 [[56]](#note-56)


<a id="event-57"></a>

57. **请求面见陈词。** 鲍宣说离省门很近却两年未获察问，小臣很难自达，愿在短暂面见中竭陈所思。 [[57]](#note-57)


<a id="event-58"></a>

58. **何武彭宣重返高位，鲍宣任司隶。** 哀帝闻灾异后部分采纳，征何武、彭宣，二人一月内复为高官。鲍宣拜司隶；哀帝改司隶校尉为司隶，秩比司直。 [[58]](#note-58)

<a id="event-62"></a>

62. **薛方以巢由作比辞征。** 薛方曾为郡掾祭酒，拒征。王莽送安车，他托使者以尧舜礼待隐者巢父许由自比，王莽悦而不强求。薛方家授经，著诗赋。 [[62]](#note-62)


<a id="event-63"></a>

63. **郭钦、蒋诩避居摄之政。** 郭钦任丞相司直劾鲍宣、薛修，又因奏董贤被左迁，平帝时任南郡太守。兖州刺史蒋诩也以廉正闻。到王莽居摄二人辞官闭户，卒于家。 [[63]](#note-63)


<a id="event-64"></a>

64. **曹竟拒爵并死于赤眉入长安。** 栗融、禽庆、苏章、曹竟俱儒生，不仕王莽。更始朝召曹竟为丞相并欲封侯取信众人，他不受爵。赤眉欲迫其降，曹竟持剑格拒而死。 [[64]](#note-64)


<a id="event-65"></a>

65. **光武征薛方，褒前朝士人后裔。** 世祖即位后召薛方，他在途中病故。两龚与鲍宣子孙获朝廷褒表，有做到大官者；具体征召与褒录日期本传未载。 [[65]](#note-65)


<a id="event-66"></a>

66. **赞语衡量出处与经世。** 班固用《易》说仕隐语默各有得失，因怀禄失节常见而重清节。认为大率能自治而不善治人，王吉、贡禹才高于龚鲍。嘉龚胜守死善道、薛方守正而不拘小信，认为郭钦、蒋诩遁世清洁远胜纪逡、两唐。 [[66]](#note-66)

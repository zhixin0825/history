# 汉书石氏家行与卫绾直不疑周仁张欧的仕履

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **石奋入侍高祖。** 石奋的父亲原是赵人，亡国后移居温县。高祖出兵路过河内，看中十五岁的小吏石奋，接其家入关，将他姐姐纳入后宫，任他为近侍。 [[1]](#note-1)


<a id="event-2"></a>

2. **石奋父子称万石。** 石奋少有经术，以谨厚积功，文帝时入选为太子太傅。景帝疏远这位旧傅，改派为诸侯相。石奋和四个儿子俱至二千石，遂称万石君。 [[2]](#note-2)


<a id="event-3"></a>

3. **万石君的礼与家教。** 退居的石奋过宫门下车，见天子之马凭轼，着朝服接见做小吏的子孙。后辈犯错时他搁筷不食，家人相责并由长辈谢罪后才恢复平常。 [[3]](#note-3)


<a id="event-4"></a>

4. **石建事父与进言。** 石建年老仍亲洗父亲的贴身便器与内衣。向武帝奏事时，屏退旁人才直言，朝会中反倒好像口拙。 [[4]](#note-4)


<a id="event-5"></a>

5. **石庆里门失礼。** 石庆醉归未下车。石奋拒食，责其倚官威使乡里老人避让。宗族袒身代过后才宽宥，石氏子弟此后入里门便趋步回家。 [[5]](#note-5)


<a id="event-6"></a>

6. **石奋卒与石建居丧。** 石奋去世，石建哀恸，扶杖方可起行，过了一年多也去世。 [[6]](#note-6)


<a id="event-7"></a>

7. **奏牍漏笔。** 石建见奏牍的马字少一笔，便怕因差错得罪。小事体现其谨畏的程度。 [[7]](#note-7)


<a id="event-8"></a>

8. **数马与治齐。** 石庆驾车时先逐一数过才回答六匹马。任齐相时，齐人敬慕其家风；传文以无为而治记其政绩，并记当地为他立祠。 [[8]](#note-8)


<a id="event-9"></a>

9. **石庆傅太子与拜相。** 立太子后，沛守石庆出任太子太傅，后任御史大夫。赵周因酎金去职，石庆接任丞相封牧丘侯；当时朝廷用兵与巡祀交杂，政务多由各指定大臣承担。 [[9]](#note-9)


<a id="event-10"></a>

10. **石庆去世及家门衰落。** 传称石庆谨严而少宏略，卒谥恬侯。子石德先袭爵，后任太常，以法免而封国除。石氏此前多人任职，此后渐以罪退出官场。 [[10]](#note-10)


<a id="event-11"></a>

11. **卫绾传题。** 以下叙卫绾由驾车伎士进身、为相及去职。 [[11]](#note-11)


<a id="event-12"></a>

12. **文帝属托卫绾。** 卫绾凭车技入官，谨厚自守，未参加尚为太子的景帝所召酒宴；文帝临终嘱景帝善待他，继位后的卫绾仍勉力守职。 [[12]](#note-12)


<a id="event-13"></a>

13. **景帝试问与赐剑。** 景帝在上林召卫绾同乘并追问旧事。卫绾不自夸，也如实说自己已有先帝所赐之剑，由此见其质实。 [[13]](#note-13)


<a id="event-14"></a>

14. **卫绾让功与击吴楚。** 卫绾替属官担责、让功他将，先任河间王太傅。吴楚起兵时率河间兵应战，因战功任中尉，后来封建陵侯。 [[14]](#note-14)


<a id="event-15"></a>

15. **卫绾任太子太傅至丞相。** 废栗太子时景帝暂遣卫绾休假，令郅都查办栗氏；立胶东王后用绾为太子太傅，又迁御史大夫、代刘舍为相。传文说他长于尽职而少所建白。 [[15]](#note-15)


<a id="event-16"></a>

16. **卫绾免官与爵绝。** 景帝死、武帝立之后，卫绾以未能纠察景帝病中多有无罪获刑者而免相；死谥哀侯，子卫信因酎金失国。 [[16]](#note-16)


<a id="event-17"></a>

17. **直不疑传题。** 下一段改叙直不疑，“直”为姓。 [[17]](#note-17)


<a id="event-18"></a>

18. **偿金与自持。** 同舍人误拿金子离去，直不疑替受害者买金赔偿。真相大白后，对方羞惭；直不疑后来听到不实毁谤，也不加辩争。 [[18]](#note-18)


<a id="event-19"></a>

19. **学老氏而不显迹。** 直不疑守现成政务规程，不张扬治理痕迹和名声。卒谥信侯，爵传至孙直彭祖，因酎金被除。 [[19]](#note-19)


<a id="event-20"></a>

20. **周仁传题。** 以下为以医术进见、以慎密受亲近的周仁。 [[20]](#note-20)


<a id="event-21"></a>

21. **郎中令周仁。** 周仁祖籍任城，以医术服事太子，从舍人累迁。景帝刚即位，拜郎中令。 [[21]](#note-21)


<a id="event-22"></a>

22. **守密受宠与退职。** 周仁故着污敝衣裤，出入帝寝而不泄内廷之事。被问及旁人时请君主自行察看；虽受宠赐，常推让少取，病免后受俸归家。 [[22]](#note-22)


<a id="event-23"></a>

23. **张欧传题。** 张欧字叔，本卷又以张叔称之。 [[23]](#note-23)


<a id="event-24"></a>

24. **任御史大夫而宽厚。** 张欧是安丘侯张说少子，凭刑名之学侍太子，景帝时居九卿，武帝时接替韩安国。尽量不苛劾，能恕则恕，对明确不能放过的案牍则依法处理。 [[24]](#note-24)


<a id="event-25"></a>

25. **请退归阳陵。** 张欧年老病重而请退，天子仍给上大夫俸，子孙也有显官。 [[25]](#note-25)


<a id="event-26"></a>

26. **赞语论谨厚。** 班固用讷言敏行称石奋、卫绾、直不疑和张欧，又指出石建暗洗衣物和周仁故意污秽受到君子讥议。 [[26]](#note-26)

> 孝景季年，萬石君以上大夫祿歸老于家，以歲時爲朝臣。過宮門闕必下車趨，見路馬必軾焉。子孫爲小吏，來歸謁，萬石君必朝服見之，不名。子孫有過失，不誚讓，爲便坐，對案不食。然後諸子相責，因長老肉袒固謝罪，改之，迺許。子孫勝冠者在側，雖燕必冠，申申如也。僮僕訢訢如也，唯謹。上時賜食於家，必稽首俯伏而食，如在上前。其執喪，哀戚甚。子孫遵敎，亦如之。萬石君家以孝謹聞乎郡國，雖齊魯諸儒質行，皆自以爲不及也。

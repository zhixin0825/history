# 汉书礼乐制度与郊庙歌辞

[本世纪目录](README.md) · [全部世纪](../README.md)

此处连读各志的制度沿革、学术分类与未详年次的史事；整段原文和已系年节录均可由卷内读本查阅。


<a id="event-1"></a>

1. **六经之用，礼节人情。** 六经所归相同，礼乐关系最急。人有喜怒哀乐，圣人能节制而不能消灭，故依天地设礼乐来正情性、立人伦、节众事。 [[1]](#note-1)


<a id="event-2"></a>

2. **婚姻、乡饮、丧祭、朝觐。** 各类礼分别约束夫妇、长幼、亲属与君臣的关系，用哭踊和歌舞表达哀乐。作者把礼、乐、行政、刑罚互相配合视为完成王道。 [[2]](#note-2)


<a id="event-3"></a>

3. **礼辨外在礼位，乐通内在人情。** 乐使人亲和，礼使人有敬有别；辞受跪拜表现敬意，诗歌钟弦表现和亲。孔子用玉帛、钟鼓的反问说明仪器不是礼乐的全部；篇末区别能创制和能绍述。 [[3]](#note-3)


<a id="event-4"></a>

4. **礼制因时损益及秦末散亡。** 历代应据旧礼因时增减，至太平逐步完备。周综合前代，制度细密；后世诸侯害怕被约束，删废篇籍，又逢秦灭学，礼制残缺。 [[4]](#note-4)


<a id="event-5"></a>

5. **叔孙通制定汉初朝仪。** 草创之际仍命叔孙通厘定君臣礼位，高祖由新朝会体会天子的尊贵，令叔孙通任奉常；他去世时仪制尚不齐备。 [[5]](#note-5)


<a id="event-6"></a>

6. **王吉论礼制及地方治理。** 王吉不满官吏只求簿书断狱，临时穿凿，无可世守的礼义标准；请同儒生述旧礼、明王制，以望风俗寿考如古。宣帝没有采纳，王吉因病去职。 [[6]](#note-6)


<a id="event-7"></a>

7. **王莽与东汉明堂辟雍，汉礼文献散逸。** 志以王莽为宰衡时兴辟雍对照光武营立明堂、辟雍及明帝亲祀、养三老五更，又称学校不备，礼化未洽。叔孙通礼仪与律令同藏而失传，河间献王汇辑五百余篇；作者批评当时以士礼推天子礼时解释纷歧。 [[7]](#note-7)


<a id="event-8"></a>

8. **乐深入人心。** 音乐能使民心趋善、易改变风俗，是先王重视乐教的理由。 [[8]](#note-8)


<a id="event-9"></a>

9. **声乐感人及雅颂节情。** 忧细、舒放、激烈、正直、和顺、放纵的音声各有不同感应。雅颂以度数礼仪合节，使刚不怒、柔不怯、阴阳各得其分，用以引导善心。 [[9]](#note-9)


<a id="event-10"></a>

10. **古乐传说及周官乐教。** 作者从黄帝咸池列至周公勺，依各舞题解释功德象征，说明夏殷乐多亡、周诗与乐器较具。周时任师瞽等人练习，并以乐教民。 [[10]](#note-10)


<a id="event-11"></a>

11. **王官失守、雅郑纷争与古乐听感。** 周衰有怨诗、逾礼，孔子回鲁正雅颂。诸侯、陪臣僭越以致俗乐盛，作者以由余去戎、孔子去鲁和魏文侯爱郑卫新声为例，辨悦耳的新声与用于政教的古乐。 [[11]](#note-11)


<a id="event-12"></a>

12. **宗庙乐的次序、房中乐及安世乐。** 叔孙通借秦乐人制庙乐，降神嘉至、帝入永至、上供登歌、神飨休成、礼成永安各有环节。唐山夫人所作房中祠乐用楚声，惠帝二年命乐府令夏侯宽备箫管、更名安世乐。 [[12]](#note-12)


<a id="event-13"></a>

13. **各帝庙舞及昭容礼容。** 武德舞象诛乱；舜招、周舞改名文始、五行；文帝作四时，景帝采武德为昭德，宣帝采昭德为盛德。乐舞入场近君无乐、退出奏昭容或礼容，志称多沿秦旧。 [[13]](#note-13)


<a id="event-14"></a>

14. **沛中歌童、武帝扩兴乐府与郊祀十九章。** 高祖过沛作歌，由一百二十歌童习唱；惠帝以沛宫为原庙，仍使习歌吹。武帝整甘泉太一、汾阴后土郊祭，采赵代秦楚之歌，李延年调律，相如等作文；童男女七十人由昏至明歌祀。两套组歌与“始设乐府”的制度问题须分别考察。 [[14]](#note-14)


<a id="event-15"></a>

15. **安世房中歌十七章题。** 以下十七段为安世房中歌，按TXT次序分章释读，颂辞的史事暗示另由本纪、列传核定。 [[15]](#note-15)


<a id="event-16"></a>

16. **安世一：大孝备矣。** 四面陈悬器，乐满宫庭，羽旄翠旌与云气相映。歌颂用盛礼显孝与光德。 [[16]](#note-16)


<a id="event-17"></a>

17. **安世二：七始华始。** 歌众肃然唱和，迎神来宴，继而以细齐之音送神；祭事已成，敬思仍随幽远天象。 [[17]](#note-17)


<a id="event-18"></a>

18. **安世三：我定历数。** 祭者自述定历数、严斋戒、施教、立祖庙并敬尊先亲，声称孝德远及四方。 [[18]](#note-18)


<a id="event-19"></a>

19. **安世四：王侯秉德。** 王侯守德、近臣恭敬，皇帝有孝德而克成大功，抚安天下；属颂礼用语。 [[19]](#note-19)


<a id="event-20"></a>

20. **安世五：海内有姦。** 写东北扰乱，皇帝抚军，武臣奉命平乱以安燕国。诗未给事件精确年款，不能只凭“燕国”坐实某次案件。 [[20]](#note-20)


<a id="event-21"></a>

21. **安世六：大海荡荡。** 以江流归海和崇山滋养百草为兴，称百姓怀念高贤，所贵在有德。 [[21]](#note-21)


<a id="event-22"></a>

22. **安世七：安其所。** 祝百姓安居乐业、世代相继，以飞龙升天写祝祷的神话意象，称贤者能乐民。 [[22]](#note-22)


<a id="event-23"></a>

23. **安世八：丰草葽。** 丰草女萝旋有衰荣，歌认为成就教德并使其广被无穷，比个人或草木之长更可珍惜。 [[23]](#note-23)


<a id="event-24"></a>

24. **安世九：雷震震。** 以雷电和明德相映，赞治理务本、施泽广远，祝众人相保、世享长寿。 [[24]](#note-24)


<a id="event-25"></a>

25. **安世十：都荔、桂华。** 芳草桂华、四龙车与羽旄铺陈祭仪，孝奏光如日月，祈孝道、礼文世传。 [[25]](#note-25)


<a id="event-26"></a>

26. **安世十一：冯冯翼翼。** 祭者肃敬承天，以长久照明四极、惠及人民为祝愿，期来福永长。 [[26]](#note-26)


<a id="event-27"></a>

27. **安世十二：硙硙即即。** 仪仗行列整备，歌咏孝道、安抚边远、各方致福，祈终无兵革。 [[27]](#note-27)


<a id="event-28"></a>

28. **安世十三：嘉荐芳矣。** 芳洁祭品献神，神享后德声传播；歌把有德说成封侯守国的长道，并祈保天福。 [[28]](#note-28)


<a id="event-29"></a>

29. **安世十四：皇皇鸿明。** 歌颂公侯休德、承天和享乐有节，以其仪行为百姓表率。 [[29]](#note-29)


<a id="event-30"></a>

30. **安世十五：浚则师德。** 主礼者深法有德之人，下民因而繁殖，旧有令名与恭谨仪容皆被赞咏。 [[30]](#note-30)


<a id="event-31"></a>

31. **安世十六：孔容之常。** 颂庄敬温良可承帝明，使下民安乐、子孙续其光，献芳洁祭品祈长寿。 [[31]](#note-31)


<a id="event-32"></a>

32. **安世十七：承帝明德。** 以高山为典型，以云泽普施比惠民，祈下民安乐并受福无疆。 [[32]](#note-32)


<a id="event-33"></a>

33. **郊祀歌十九章题。** 现传郊祀组歌含武帝一朝多个时期的作品；一些章末注明后世改辞或前事年代。 [[33]](#note-33)


<a id="event-34"></a>

34. **郊祀一：练时日。** 择日备芳草祭品，神驾龙车下临，风雨相随；众乐整、敬献牲酒，夜祀至旦，愿神留享降福。 [[34]](#note-34)


<a id="event-35"></a>

35. **郊祀二：帝临。** 颂中坛祭帝、四方顺从，天地清和、文事兴而武备暂息；以后土媪神滋养、黄色礼服作意象。 [[35]](#note-35)


<a id="event-36"></a>

36. **郊祀三：青阳。** 赞春雷发而草木复萌，恩泽及细小生灵与胎幼，群生繁衍，祝春祥。附题标作邹子乐。 [[36]](#note-36)


<a id="event-37"></a>

37. **郊祀四：朱明。** 夏气长养万物，桐木繁茂、开花结实、田作渐成。祭者肃雍以报时令，愿神庇佑传世。附题标邹子乐。 [[37]](#note-37)


<a id="event-38"></a>

38. **郊祀五：西顥。** 从秋气肃杀、谷实垂颖引申到除奸、绥服四方，并强调敬感与正心。附题标邹子乐。 [[38]](#note-38)


<a id="event-39"></a>

39. **郊祀六：玄冥。** 冬令降霜、虫蛰草落，也写收谷、整肃风俗、复朴守信与望祭五岳。附题标邹子乐。 [[39]](#note-39)


<a id="event-40"></a>

40. **郊祀七：惟泰元及匡衡改辞。** 歌颂至上神、地神分理四时日月与阴阳五行，愿祭品乐舞使神享、凶灾消。建始元年题记称匡衡奏改“鸾路龙鳞”为“涓选休成”。 [[40]](#note-40)


<a id="event-41"></a>

41. **郊祀八：天地及匡衡改辞。** 紫坛祭天地，童舞八佾，牲献、金石丝竹与宫、角、徵、羽、商应律，愿神久留享献。题记称匡衡又奏改“黼绣周张”为“肃若旧典”，本条不另记年。 [[41]](#note-41)


<a id="event-42"></a>

42. **郊祀九：日出入。** 诗叹日月运行无穷、四时与人寿不相应，转以六龙神驾为所乐，呼神兽訾黄下临。 [[42]](#note-42)


<a id="event-43"></a>

43. **郊祀十一：天门。** 天门开广，神车降临，玉梢舞、日月光和众星照祭室。歌反复表示主祭敬意，祈降吉祥、施福四方。 [[43]](#note-43)


<a id="event-44"></a>

44. **郊祀十二：景星。** 歌并举星象、从汾脽出的鼎、雅声与酒牲，以天布施、地化成为丰年之祥。题作元鼎五年，与《武帝纪》《史记·封禅书》汾阴祠旁得鼎归年有异。 [[44]](#note-44)


<a id="event-45"></a>

45. **郊祀十四：后皇。** 写后土祭坛、玄黄之服及冀州物生，祝各方安居、亿兆蒙福。 [[45]](#note-45)


<a id="event-46"></a>

46. **郊祀十五：华鳞鳞。** 灵根、神车、招摇旌旗和甘露庆云连成神出神入的一场祭仪；设酒让神安坐，祈福施及汾水、大河及众人。 [[46]](#note-46)


<a id="event-47"></a>

47. **郊祀十六：五神。** 五方之神受请齐临，椒兰玉璧相伴，饮享毕，灵车昂然返回；祝福泽如雨。 [[47]](#note-47)


<a id="event-48"></a>

48. **郊祀十七：朝陇首。** 巡陇首观西界得白麟，颂祥应和对外威德；元狩元年题记把作歌与幸雍获麟相连。 [[48]](#note-48)


<a id="event-49"></a>

49. **郊祀十八：象载瑜。** 写祥禽、甘露灵泉和蓬莱仙境，祝降福无极。题记说太始三年东海获赤雁作，本纪名《朱雁之歌》。 [[49]](#note-49)


<a id="event-50"></a>

50. **郊祀十九：赤蛟。** 赤蛟神驾、华盖六龙、椒浆和灵光表现众神享祭及其离坛，祈寿考和平、恩泽遍满天下。 [[50]](#note-50)


<a id="event-51"></a>

51. **其他巡幸福应不列郊庙。** 本志说其他巡狩所谓福应没有编入郊庙乐，故略而不列。 [[51]](#note-51)


<a id="event-52"></a>

52. **河间献王献雅乐及志的郊庙批评。** 献王搜集雅乐，上献后由太乐官保存、学习和补列，却不常实际演奏。作者更以殷周雅颂详咏祖先与有功男女为范本，批评汉庙乐虽声律谐美，少咏祖宗事功。 [[52]](#note-52)


<a id="event-53"></a>

53. **王禹、宋嘱所传雅乐及平当复兴之议。** 成帝时宋嘱等以师承上书，平当等考验并主张归雅乐官继续。平当称河间献王所得雅乐虽列于太乐及学校，公卿久不理解内容，只有在位者提倡才能使微学得弘。 [[53]](#note-53)


<a id="event-54"></a>

54. **东汉世势与补办学校礼乐。** 作者认为人民恢复生业、刑政趋平以后，须以贤良治理，使民富足，且渐以学校礼乐教化；现存古代仪节可作为补订依据。 [[54]](#note-54)


<a id="event-55"></a>

55. **三代礼制损益与汉代久缺。** 借孔子论夏殷周礼制因承损益，感叹汉代仍未成全国礼乐，回顾贾谊、董仲舒、王吉、刘向诸人反复论议。 [[55]](#note-55)

### 2. 婚姻、乡饮、丧祭、朝觐

**[《汉书·礼乐志》P002](../../拆分史书/汉书/卷022.md#p002)** · [仓内TXT L4917—L4917](../../拆分史书/汉书/卷022.md#part-1-L4917)

> 人性有男女之情，妒忌之別，為制婚姻之禮；有交接長幼之序，為制鄉飲之禮；有哀死思遠之情，為制喪祭之禮；有尊尊敬上之心，為制朝覲之禮。哀有哭踊之節，樂有歌舞之容，正人足以副其誠，邪人足以防其失。故婚姻之禮廢，則夫婦之道苦，而淫辟之罪多；鄉飲之禮廢，則長幼之序亂，而爭鬥之獄蕃；喪祭之禮廢，則骨肉之恩薄，而背死忘先者眾；朝聘之禮廢，則君臣之位失，而侵陵之漸起。故孔子曰：「安上治民，莫殒於禮；移風易俗，莫殒於樂。」禮節民心，樂和民聲，政以行之，刑以防之。禮樂政刑四達而不誖，則王道備矣。

> 王者必因前王之禮，順時施宜，有所損益，即民之心，稍稍制作，至太平而大備。周監於二代，禮文尤具，事為之制，曲為之防，故稱禮經三百，威儀三千。於是教化浹洽，民用和睦，災害不生，禍亂不作，囹圄空虛，四十餘年。孔子美之曰：「郁郁乎文哉！吾從周。」及其衰也，諸侯踰越法度，惡禮制之害己，去其篇籍。遭秦滅學，遂以亂亡。

### 9. 声乐感人及雅颂节情

[返回正文第9条](#event-9)

<a id="hs022-p012"></a>

**[《汉书·礼乐志》P012](../../拆分史书/汉书/卷022.md#p012)** · [仓内TXT L4929—L4929](../../拆分史书/汉书/卷022.md#part-1-L4929)

> 夫民有血氣心知之性，而無哀樂喜怒之常，應感而動，然後心術形焉。是以纖微虍瘁一作「衰」之音作，而民思憂；闡諧嫚易之音作，而民康樂；麤厲猛奮之音作，而民剛毅；廉直正誠之音作，而民肅敬；寬裕和順之音作，而民慈愛；流辟邪散之音作，而民淫亂。先王恥其亂也，故制雅頌之聲，本之情性，稽之度數，制之禮儀，合生氣之和，導五常之行，使之陽而不散，陰而不集，剛氣不怒，柔氣不懾，四暢交於中，而發作於外，皆安其位而不相奪也，足以感動人之善心而，不使邪氣得接焉，是先王立樂之方也。

### 10. 古乐传说及周官乐教

[返回正文第10条](#event-10)

<a id="hs022-p013"></a>

**[《汉书·礼乐志》P013](../../拆分史书/汉书/卷022.md#p013)** · [仓内TXT L4930—L4930](../../拆分史书/汉书/卷022.md#part-1-L4930)

> 王者未作樂之時，因先王之樂以教化百姓，說樂其俗，然後改作，以章功德。《易》曰：「先王以作樂崇德，殷薦之上帝，以配祖考。」昔黃帝作咸池，顓頊作六莖，帝嚳作五英，堯作大章，舜作招，禹作夏，湯作濩，武王作武，周公作勺。勺，言能勺先祖之道也。武，言以功定天下也。濩，言救民也。夏，大承二帝也。招，繼堯也。大章，章之也。五英，英華茂也。六莖，及根莖也。咸池，備矣。自夏以往，其流不可聞已，殷頌猶有存者。周詩既備，而其器用張陳，周官具焉。典者自卿大夫師瞽以下，皆選有道德之人，朝夕習業，以教國子。國子者，卿大夫之子弟也。皆學歌九德，誦六詩，習六舞、五聲、八音之和。故帝舜命夔曰：「女典樂，教冑子，直而溫，寬而栗，剛而無虐，簡而無敖。詩言志，歌詠言，聲依詠，律和聲，八音克諧。」此之謂也。又以外賞諸侯德盛而教尊者。其威儀足以充目，音聲足以動耳，詩語足以感心，故聞其音而德和，省其詩而志正，論其數而法立。是以薦之郊廟則鬼神饗，作之朝廷則群臣和，立之學官則萬民協。聽者無不虛己竦神，說而承流，是以海內遍知上德，被服其風，光煇日新，化上遷善，而不知所以然，至於萬物不夭，天地順而嘉應降。故《詩》曰：「鐘鼓鍠鍠，磬管鏘鏘，降福穰穰。」《書》云：「擊石拊石，百獸率舞。」鳥獸且猶感應，而況於人乎？況於鬼神乎？故樂者，聖人之所以感天地，通神明，安萬民，成性類者也。然自雅頌之興，而所承衰亂之音猶在，是謂淫過凶嫚之聲，為設禁焉。世衰民散，小人乘君子，心耳淺薄，則邪勝正。故書序「殷紂斷棄先祖之樂，乃作淫聲，用變亂正聲，以說婦人。」樂官師瞽抱其器而奔散，或適諸侯，或入河海。夫樂本情性，浹肌膚而臧骨髓，雖經乎千載，其遺風餘烈尚猶不絕。至春秋時，陳公子完奔齊。陳，舜之後，招樂存焉。故孔子適齊聞招，三月不知肉味，曰「不圖為樂之至於斯！」美之甚也。

> 高祖廟奏武德、文始、五行之舞；孝文廟奏昭德、文始、四時、五行之舞；孝武廟奏盛德、文始、四時、五行之舞。武德舞者，高祖四年作，以象天下樂己行武以除亂也。文始舞者，曰本舜招舞也，高祖六年更名曰文始，以示不相襲也。五行舞者，本周舞也，秦始皇二十六年更名曰五行也。四時舞者，孝文所作，以明示天下之安和也。蓋樂己所自作，明有制也；樂先王之樂，明有法也。孝景采武德舞以為昭德，以尊大宗廟。至孝宣，采昭德舞為盛德，以尊世宗廟。諸帝廟皆常奏文始、四時、五行舞云。高祖六年又作昭容樂、禮容樂。昭容者，猶古之昭夏也，主出武德舞。禮容者，主出文始、五行舞。舞人無樂者，將至至尊之前不敢以樂也；出用樂者，言舞不失節，能以樂終也。大氐皆因秦舊事焉。

### 52. 河间献王献雅乐及志的郊庙批评

[返回正文第52条](#event-52)

<a id="hs022-p057"></a>

**[《汉书·礼乐志》P057](../../拆分史书/汉书/卷022.md#p057)** · [仓内TXT L4992—L4992](../../拆分史书/汉书/卷022.md#part-1-L4992)

> 是時，河間獻王有雅材，亦以為治道非禮樂不成，因獻所集雅樂。天子下大樂官，常存肄之，歲時以備數，然不常御，常御及郊廟皆非雅聲。然詩樂施於後嗣，猶得有所祖述。昔殷周之雅頌，乃上本有娀、姜原，镨、稷始生，玄王、公劉、古公、大伯、王季、姜女、大任、太姒之德，乃及成湯、文、武受命，武丁、成、康、宣王中興，下及輔佐阿衡、周、召、太公、申伯、召虎、仲山甫之屬，君臣男女有功德者，靡不褒揚。功德既信美矣，褒揚之聲盈乎天地之間，是以光名著於當世，遺譽垂於無窮也。今漢郊廟詩歌，未有祖宗之事，八音調均，又不協於鐘律，而內有掖庭材人，外有上林樂府，皆以鄭聲施於朝廷。

### 53. 王禹、宋嘱所传雅乐及平当复兴之议

> 至成帝時，謁者常山王禹世受可間樂，能說其義，其弟子宋嘱等上書言之，下大夫博士平當等考試。當以為「漢承秦滅道之後，賴先帝聖德，博受兼聽，修廢官，立大學，河間獻王聘求幽隱，修興雅樂以助化。時，大儒公孫弘、董仲舒等皆以為音中正雅，立之大樂。春秋鄉射，作於學官，希闊不講。故自公卿大夫觀聽者，但聞鑑鎗，不曉其意，而欲以風諭眾庶，其道無由。是以行之百有餘年，德化至今未成。今嘱等守習孤學，大指歸於興助教化。衰微之學，興廢在人。宜領屬雅樂，以繼絕表微。孔子曰：『人能弘道，非道弘人。』河間區區，不國藩臣，以好學修古，能有所存，民到于今稱之，況於聖主廣被之資，修起舊文，放鄭近雅，述而不作，信而好古，於以風示海內，揚名後世，誠非小功小美也。」事下公卿，以為久遠難分明，當議復寢。

# 汉书窦婴田蚡灌夫韩安国的未确年事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **窦婴家世及詹事。** 窦婴字王孙，出文帝窦后的从兄一支，家世观津而喜宾客，先为吴相，景帝继位后为詹事。 [[1]](#note-1)


<a id="event-2"></a>

2. **窦婴屯荥阳与封魏其侯。** 吴楚反，景帝令窦婴以大将军守荥阳，监齐赵军情。他举荐袁盎、栾布，赐金都留给部下取用。平乱后封魏其侯，与条侯周亚夫齐重。 [[2]](#note-2)


<a id="event-3"></a>

3. **窦婴为栗太子傅及退朝。** 窦婴由立栗太子而任傅，废太子时力争无效，退居蓝田。梁人高遂劝他恐会触怒两宫祸及妻子，窦婴复朝请。 [[3]](#note-3)


<a id="event-4"></a>

4. **田蚡小目。** 以下由窦婴转叙田蚡及二人关系。 [[4]](#note-4)


<a id="event-5"></a>

5. **田蚡早年侍窦婴而渐显。** 田蚡生于长陵，是王皇后同母弟。窦婴显贵时，他以小郎之礼侍奉，至景帝晚年才凭口辩与家势迁中大夫。 [[5]](#note-5)


<a id="event-6"></a>

6. **窦婴任相，田蚡任太尉。** 田蚡礼数延攬名士而谋高位。籍福劝让窦婴为丞相，自己居同等尊位的太尉。籍福同时警告窦婴若不能容人，将因过多诋毁而去位。 [[6]](#note-6)


<a id="event-7"></a>

7. **新政与窦太后击退儒臣。** 窦婴、田蚡举赵绾、王臧，迎申公，拟设明堂，整礼制、就国等。外戚列侯多不愿，窦太后亦尊黄老。赵绾建议不必向东宫奏事，太后以新垣平相比，逐两人，罢窦婴、田蚡两职。 [[7]](#note-7)


<a id="event-8"></a>

8. **窦太后卒后田蚡再居权位。** 田蚡免官后仍藉王太后通进。窦太后死，许昌、庄青翟因治丧免职，田蚡任丞相、韩安国任御史大夫，士人诸侯多趋附田蚡。 [[8]](#note-8)


<a id="event-9"></a>

9. **田蚡相权与奢侈。** 田蚡认为藉皇帝亲戚身份仍须以礼折服诸侯，却占用奏事时间、荐人骤至高位，招武帝责问。又求官地扩宅、宴以相礼自尊，蓄积田园、珍物、妇女。 [[9]](#note-9)


<a id="event-10"></a>

10. **窦婴失势，灌夫不去。** 窦太后死后窦婴疏远无权，名士渐辞，唯灌夫仍亲厚。 [[10]](#note-10)


<a id="event-11"></a>

11. **灌夫小目。** 以下详灌夫出身、战功与讼狱。 [[11]](#note-11)


<a id="event-12"></a>

12. **灌猛死而灌夫突入吴军。** 父张孟随灌氏得官并改姓，吴楚反时随太尉所部作战而死。灌夫不肯随丧回乡，带少数勇士突入吴营，重伤而返；太尉禁再出战，平乱后灌夫名闻天下。 [[12]](#note-12)


<a id="event-13"></a>

13. **灌夫由郎中将转代相。** 灌氏侯举荐灌夫任郎中将。以法去职后居长安，获诸公推举再任代相。 [[13]](#note-13)


<a id="event-14"></a>

14. **灌夫的任侠性格。** 刚直而酒后放任，不肯面谀；凌辱权贵却谦礼贫贱之士，也常当众举荐低位者，因此声誉大。 [[14]](#note-14)


<a id="event-15"></a>

15. **灌氏宗族的乡里势力。** 不务文学而喜任侠，交豪强，蓄大量田财宾客，宗族横行颍川。当地童谣把颍水清浊与灌氏安危相连。 [[15]](#note-15)


<a id="event-16"></a>

16. **窦婴与灌夫相交。** 两人均失势退居，窦婴倚灌夫排击趋利旧交，灌夫也托窦婴结交宗室列侯，彼此推重，亲若父子。 [[16]](#note-16)


<a id="event-17"></a>

17. **田蚡失约赴窦氏宴。** 灌夫虽守丧，仍替田蚡约访窦家。窦家通宵治席，田蚡日中未至，经催才缓行。灌夫席间劝舞不得便出言伤人，窦婴从旁解和。 [[17]](#note-17)


<a id="event-18"></a>

18. **田蚡求田未获。** 田蚡托籍福向窦婴求城南田，窦婴拒绝，灌夫更骂籍福。籍福本想补救，田蚡得知实情后却自诉曾救窦婴之子，愤怒加深。 [[18]](#note-18)


<a id="event-19"></a>

19. **淮南王旧交与事后追责。** 田蚡早为太尉时在霸上迎淮南王刘安，以武帝无太子暗示刘安继位，因而受厚贿。至刘安谋反败，武帝说田蚡如尚在将被族诛。 [[19]](#note-19)


<a id="event-20"></a>

20. **韩安国小目。** 以下叙韩安国仕梁、守边及在汉中枢。 [[20]](#note-20)


<a id="event-21"></a>

21. **韩安国助梁守吴兵。** 在梁任中大夫，师邹田生学韩非杂说。吴楚之乱，与张羽扼梁东界；张羽力战，韩安国持重，吴军不能越梁。 [[21]](#note-21)


<a id="event-22"></a>

22. **为梁仪卫事开解。** 梁孝王车驾僭侈引景帝不悦，韩安国通过长公主有意强调 梁守御的功劳，说明仪卫多取于帝赐，并称梁王思亲。太后告景帝，复见梁使厚赐，韩安国因此结于汉廷。 [[22]](#note-22)


<a id="event-23"></a>

23. **死灰复燃与宽待田甲。** 韩安国坐法入狱，被田甲讥辱。待梁内史出缺，韩安国起为二千石，田甲出逃。韩安国迫使他回官，却笑而宽待。 [[23]](#note-23)


<a id="event-24"></a>

24. **窦太后指定韩安国为内史。** 梁王欲请以宠臣公孙诡任内史，太后最终使诏任韩安国。 [[24]](#note-24)


<a id="event-25"></a>

25. **从和亲到马邑之议。** 马邑豪强聂壹通过王恢，请乘边境相亲伺机设伏。武帝以虽馈厚而寇边未止发问群臣；提议与实施分别归年。 [[25]](#note-25)


<a id="event-26"></a>

26. **王恢主战。** 以昔全代尚能守边为比，认为汉统一、输粮备边却仍遭侵，原因是边敌未感威慑，主张出兵。 [[26]](#note-26)


<a id="event-27"></a>

27. **韩安国引高祖、文帝为鉴。** 举高祖白登缺粮脱险后仍和亲，文帝聚重兵而难有所获终于复约，认为不宜以君主忿怒或宿兵损国。 [[27]](#note-27)


<a id="event-28"></a>

28. **王恢论时宜而主战。** 以礼乐因时更易，解释高帝休民时不报宿怨；如今边民士卒不断伤亡，情形不同。 [[28]](#note-28)


<a id="event-29"></a>

29. **韩安国论深入无益。** 改常须有大益。匈奴逐草水而来去迅捷，无固定城郭，久驻使汉边郡不能农织，负担不对称。 [[29]](#note-29)


<a id="event-30"></a>

30. **王恢以秦西戎故事主威服。** 秦穆公乘时扩土，蒙恬北进沿河据守。王恢认为现今汉强，少部兵亦可速取利。 [[30]](#note-30)


<a id="event-31"></a>

31. **韩安国指出远征消耗。** 以逸待劳、凭实击虚为上，兵远必衰，譬如强弩之末。仓促长驱面临补给和地势之患，若无奇策，深入不利。 [[31]](#note-31)


<a id="event-32"></a>

32. **王恢说拟引敌近边。** 王恢以明镜不能藏形比把握要旨，声明拟顺单于所欲引至边地，并非远征深追。 [[32]](#note-32)


<a id="event-33"></a>

33. **韩安国荐贤与失相。** 好利而举荐壶遂、臧固等有廉行之士。田蚡卒后韩安国代理相事坠车跛足，武帝改用薛泽，他免官痊愈后复任中尉。 [[33]](#note-33)


<a id="event-34"></a>

34. **卫青破龙城与韩安国守渔阳。** 韩安国迁卫尉，卫青破龙城。次年韩安国屯渔阳，由俘讯误判敌已远去、因农事请罢屯；胡复入，他守壁战伤，因而被责向东屯右北平。 [[34]](#note-34)


<a id="event-35"></a>

35. **韩安国忧愧病卒。** 卫青等因功日贵，安国日疏且守御失利。不能罢归，东徙后郁郁，数月呕血而死。 [[35]](#note-35)


<a id="event-36"></a>

36. **壶遂参与改历。** 壶遂与太史公司马迁等定历，做到詹事，以笃行见称，武帝本想任相而壶遂病卒。 [[36]](#note-36)


<a id="event-37"></a>

37. **班固总赞各人得失。** 窦婴、田蚡以外戚重，灌夫靠战功显。班固论三人性格与冲突，认为籍福无法救其败，叹韩安国坠失机缘、忧死，并反问王恢因首倡马邑而服罪是否可归命数。 [[37]](#note-37)

### 6. 窦婴任相，田蚡任太尉

<a id="hs052-p009"></a>

**[《汉书·窦田灌韩传》P009](../../sources/摘录/汉书-卷052-窦田灌韩传.md#p009)** · [仓内TXT L7786—L7786](../../sources/本地分卷/汉书/汉书-卷052.md#L7786)

> 蚡新用事，卑下賓客，進名士家居者貴之，欲以傾諸將相。上所填撫，多蚡賓客計策。會丞相綰病免，上議置丞相、太尉。藉福說蚡曰：「魏其侯貴久矣，素天下士歸之。今將軍初興，未如，即上以將軍為相，必讓魏其。魏其為相，將軍必為太尉。太尉、相尊等耳，有讓賢名。」蚡乃微言太后風上，於是乃以嬰為丞相，蚡為太尉。藉福賀嬰，因弔曰：「君侯資性喜善疾惡，方今善人譽君侯，故至丞相；然惡人眾，亦且毀君侯。君侯能兼容，則幸久；不能，今以毀去矣。」嬰不聽。

<a id="note-9"></a>

### 9. 田蚡相权与奢侈

[返回正文第9条](#event-9)

<a id="hs052-p012"></a>

**[《汉书·窦田灌韩传》P012](../../sources/摘录/汉书-卷052-窦田灌韩传.md#p012)** · [仓内TXT L7789—L7789](../../sources/本地分卷/汉书/汉书-卷052.md#L7789)

> 蚡為人貌侵，生貴甚。又以為諸侯王多長，上初即位，富於春秋，蚡以肺附為相，非痛折節以禮屈之，天下不肅。當是時，丞相入奏事，語移日，所言皆聽。薦人或起家至二千石，權移主上。上乃曰：「君除吏盡未？吾亦欲除吏。」嘗請考工地益宅，上怒曰：「遂取武庫！」是後乃退。召客飲，坐其兄蓋侯北鄉，自坐東鄉，以為漢相尊，不可以兄故私橈。由此滋驕，治宅甲諸第，田園極膏腴，市買郡縣器物相屬於道。前堂羅鐘鼓，立曲旃；後房婦女以百數。諸奏珍物狗馬玩好，不可勝數。

> 安國曰：「不然。臣聞用兵者以飽待饑，正治以待其亂，定舍以待其勞。故接兵覆眾，伐國墮城，常坐而役敵國，此聖人之兵也。且臣聞之，衝風之衰，不能起毛羽；彊弩之末，力不能入魯縞。夫盛之有衰，猶朝之必莫也。今將卷甲輕舉，深入長敺，難以為功；從行則迫脅，衡行則中絕，疾則糧乏，徐則後利，不至千里，人馬乏食。兵法曰：『遺人獲也。』意者有它繆巧可以禽之，則臣不知也；不然，則未見深入之利也。臣故曰勿擊便。」

### 33. 韩安国荐贤与失相

> 安國為人多大略，知足以當世取舍，而出於忠厚。貪耆財利，然所推舉皆廉士賢於己者。於梁舉壺遂、臧固，至它，皆天下名士，士亦以此稱慕之，唯天子以為國器。安國為御史大夫五年，丞相蚡薨。安國行丞相事，引墮車，蹇。上欲用安國為丞相，使使視，蹇甚，乃更以平棘侯薛澤為丞相。安國病免，數月，瘉，復為中尉。

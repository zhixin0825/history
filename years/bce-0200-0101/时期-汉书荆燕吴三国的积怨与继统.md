# 汉书荆燕吴三国的积怨与继统

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **刘贾随汉还定三秦。** 荆王刘贾是高帝同祖父的年长堂兄，何时起兵未详。汉元年以将军平定塞地，随汉军向东攻击项籍。 [[1]](#note-1)


<a id="event-2"></a>

2. **刘泽分目。** 下文转叙从营陵侯进为琅邪、燕王的刘泽。 [[2]](#note-2)


<a id="event-3"></a>

3. **刘泽官郎中及封营陵侯。** 刘泽是高祖较远的同宗兄弟，汉三年任郎中，十一年以将军参加击陈豨、攻王黄，封营陵侯。 [[3]](#note-3)


<a id="event-4"></a>

4. **田生借张卿推动吕产与刘泽封王。** 田生献计得到刘泽资财后还齐，两年后入长安，借儿子与吕后亲信张卿交接，以侯家规模设宴，说太后有意王吕产而不便开口，张卿可先请而获利。吕产得为王，田生不受赏，又让张卿建议分十余县给刘泽以结宗室。刘泽又是吕须女婿，遂得封琅邪王，得田生劝告速离京，追使未赶上。 [[4]](#note-4)


<a id="event-5"></a>

5. **燕王三世与营陵侯续绝。** 刘泽王燕二年去世，谥敬。刘嘉承袭，传文作九年而卒，后由刘定国继位。定国与父亲姬妾、弟妻和自己的女儿有乱伦行为，杀县令郢人灭口；郢人昆弟再次上告，公卿请诛，他自杀，燕国撤销。哀帝封刘泽远裔归生续营陵侯，更始时归生死于兵乱。 [[5]](#note-5)


<a id="event-6"></a>

6. **吴王濞分目。** 下文转叙吴王刘濞及七国之乱。 [[6]](#note-6)


<a id="event-7"></a>

7. **刘仲失代与刘濞立吴。** 高祖哥哥刘仲当代王时因匈奴来攻弃国，贬为合阳侯。刘濞先封沛侯，二十岁为骑将[随高祖击英布](bce-0195.md#event-1)。刘贾无嗣，高祖忧吴、会稽轻悍，册立刘濞为吴王，领三郡五十三城。高祖事后看他面貌，想到未来东南生乱，戒他同宗不可反；刘濞叩头应允。 [[7]](#note-7)


<a id="event-8"></a>

8. **吴以铜盐富国。** 惠帝、高后时诸侯休养百姓，吴国利用豫章铜山招亡命者私铸钱，又煮海盐，财用充足而不向百姓收赋。 [[8]](#note-8)


<a id="event-9"></a>

9. **吴太子被击杀与刘濞蓄众。** 吴太子和皇太子博戏争道，被棋盘击死。刘濞不满尸身被送回，遣回长安葬，以病为由不朝。朝廷拘吴使追究，一使者陈说过度追逼会生变，文帝赦遣诸使，赐刘濞几杖、免朝。吴仍凭铜盐免赋，为代役者付钱，礼遇贤才、赏赐闾里、保护逃人，日久形成可调用的支持。 [[9]](#note-9)


<a id="event-10"></a>

10. **朝错主张削藩及楚赵胶西受削。** 朝错任太子家令时已请削吴，文帝不罚。景帝即位后任御史大夫，朝错认为刘濞铸钱聚亡命，早削则虽反而祸小。景帝三年冬赦楚王服丧期间私通的死罪，削东海郡；赵王因罪失常山郡，胶西因卖爵违法被削六县。 [[10]](#note-10)


<a id="event-11"></a>

11. **赞语论宗室屏藩与削藩。** 班固称刘贾因汉初需要镇守江淮才得王，刘泽借田生动吕氏获得王位而传三代；刘濞得山海所产而薄敛得众，乱端起于其子与太子的冲突。赞中据此解释古代限制诸侯封土及不得封山海，又叹朝错为国远虑却先受罪。 [[11]](#note-11)

### 4. 田生借张卿推动吕产与刘泽封王

[返回正文第4条](#event-4)

<a id="hs035-p007"></a>

**[《汉书·荆燕吴传》P007](../../拆分史书/汉书/卷035.md#p007)** · [仓内TXT L7019—L7019](../../拆分史书/汉书/卷035.md#part-1-L7019)

> 高后時，齊人田生游乏資，以畫奸澤。澤大說之，用金二百斤為田生壽。田生已得金，即歸齊。二歲，澤使人謂田生曰：「弗與矣。」田生如長安，不見澤，而假大宅，令其子求事呂后所幸大謁者張卿。居數月，田生子請張卿臨，親脩具。張卿往，見田生帷帳具置如列侯。張卿驚。酒酣，乃屏人說張卿曰：「臣觀諸侯邸第百餘，皆高帝一切功臣。今呂氏雅故本推轂高帝就天下，功至大，又有親戚太后之重。太后春秋長，諸呂弱，太后欲立呂產為呂王，王代。呂后又重發之，恐大臣不聽。今卿最幸，大臣所敬，何不風大臣以聞太后，太后必喜。諸呂以王，萬戶侯亦卿之有。太后心欲之，而卿為內臣，不急發，恐過及身矣。」張卿大然之，乃風大臣語太后。太后朝，因問大臣。大臣請立呂產為呂王。太后賜張卿千金，張卿以其半進田生。田生弗受，因說之曰：「呂產王也，諸大臣未大服。今營陵侯澤，諸劉長，為大將軍，獨此尚觖望。今卿言太后，裂十餘縣王之，彼得王喜，於諸呂王益固矣。」張卿入言之。又太后女弟呂須女亦為營陵侯妻，故遂立營陵侯澤為琅邪王。琅邪王與田生之國，急行毋留。出關，太后果使人追之。已出，即還。

### 9. 吴太子被击杀与刘濞蓄众

[返回正文第9条](#event-9)

<a id="hs035-p013"></a>

**[《汉书·荆燕吴传》P013](../../拆分史书/汉书/卷035.md#p013)** · [仓内TXT L7025—L7025](../../拆分史书/汉书/卷035.md#part-1-L7025)

> 孝文時，吳太子入見，得侍皇太子飲博。吳太子師傅皆楚人，輕悍，又素驕。博爭道，不恭，皇太子引博局提吳太子，殺之。於是遣其喪歸葬吳。吳王慍曰：「天下一宗，死長安即葬長安，何必來葬！」復遣喪之長安葬。吳王由是怨望，稍失藩臣禮，稱疾不朝。京師知其以子故，驗問實不病，諸吳使來，輒繫責治之。吳王恐，所謀滋甚。及後使人為秋請，上復責問吳使者。使者曰：「察見淵中魚，不祥。今吳王始詐疾，反覺，見責急，愈益閉，恐上誅之，計乃無聊。唯上與更始。」於是天子皆赦吳使者歸之，而賜吳王几杖，老，不朝。吳得釋，其謀亦益解。然其居國以銅鹽故，百姓無賦。卒踐更，輒予平賈。歲時存問茂材，賞賜閭里。它郡國吏欲來捕亡人者，頌共禁不與。如此者三十餘年，以故能使其眾。

### 10. 朝错主张削藩及楚赵胶西受削

[返回正文第10条](#event-10)

<a id="hs035-p014"></a>

**[《汉书·荆燕吴传》P014](../../拆分史书/汉书/卷035.md#p014)** · [仓内TXT L7026—L7026](../../拆分史书/汉书/卷035.md#part-1-L7026)

> 朝錯為太子家令，得幸皇太子，數從容言吳過可削。數上書說之，文帝寬，不忍罰，以此吳王日益橫。及景帝即位，錯為御史大夫，說上曰：「昔高帝初定天下，昆弟少，諸子弱，大封同姓，故孽子悼惠王王齊七十二城，庶弟元王王楚四十城，兄子王吳五十餘城。封三庶孽，分天下半。今吳王前有太子之隙，詐稱病不朝，於古法當誅。文帝不忍，因賜几杖，德至厚也。不改過自新，乃益驕恣，公即山鑄錢，煮海為鹽，誘天下亡人謀作亂逆。今削之亦反，不削亦反。削之，其反亟，禍小；不削之，其反遲，禍大。」三年冬，楚王來朝，錯因言楚王戊往年為薄太后服，私姦服舍，請誅之。詔赦，削東海郡。及前二年，趙王有罪，削其常山郡。膠西王卬以賣爵事有姦，削其六縣。

### 11. 赞语论宗室屏藩与削藩

> 贊曰：荊王王也，由漢初定，天下未集，故雖疏屬，以策為王，鎮江淮之間。劉澤發於田生，權激呂氏，然卒南面稱孤者三世。事發相重，豈不危哉！吳王擅山海之利，能薄斂以使其眾，逆亂之萌，自其子興。古者諸侯不過百里，山海不以封，蓋防此矣。朝錯為國遠慮，禍反及身。「毋為權首，將受其咎」，豈謂錯哉！

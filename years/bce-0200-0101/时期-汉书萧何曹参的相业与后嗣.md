# 汉书萧何曹参的相业与后嗣

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **沛吏萧何照应刘邦。** 萧何精熟文法，在沛县掌吏务，多次借官中事务照应刘邦。刘邦赴咸阳服役，其他人送三钱，萧何独送五钱。他办泗水郡的文书考核第一，秦御史欲推荐他，萧何力辞。 [[1]](#note-1)


<a id="event-2"></a>

2. **劝就封汉中与进韩信。** 项羽违背先入关者王其地的约定，利用巴蜀道险及秦迁民的情势封刘邦为汉王，并立秦降将分守三秦阻挡他。刘邦一度欲攻项羽，萧何劝以汤武能屈能伸为法，暂赴汉中，抚民求贤，动员巴蜀，回定三秦。刘邦任萧何为相，萧何举荐韩信，汉王拜韩信为大将军。 [[2]](#note-2)


<a id="event-3"></a>

3. **田宅务俭。** 萧何选田宅于僻远处，不大修垣屋。他认为子孙贤明可以效法节俭，若不贤，也可免遭势家夺产。 [[3]](#note-3)


<a id="event-4"></a>

4. **酂侯世系与多次复封。** 萧何卒谥文终，子萧禄无后，吕后封萧何夫人同和其幼子萧延，文帝改以萧延为酂侯。萧延子萧遗无子，弟萧则承爵而坐罪。景帝重封萧嘉，萧胜后来被免；武帝复封萧庆，萧寿成以太常牲体瘦获罪；宣帝求得萧何后十二人，封其中萧建世，孙萧获因使奴杀人获刑。成帝再封萧喜，其支传至王莽败亡时断绝。 [[4]](#note-4)


<a id="event-5"></a>

5. **曹参篇题。** 由萧何及其后嗣转入曹参传。 [[5]](#note-5)


<a id="event-6"></a>

6. **起沛至受封戚公。** 曹参原是沛县狱掾，以中涓从刘邦，攻击胡陵、方与、薛及反附魏的丰邑；再战碭东、下邑、轅戚、亢父、东阿、濮阳、定陶、雍丘，雍丘破李由。项梁死后刘邦为砀郡长，曹参获执帛、号建成君，又迁戚公。 [[6]](#note-6)


<a id="event-7"></a>

7. **西向破秦。** 曹参跟随刘邦攻成武、成阳、杠里和开封，在曲遇击败杨熊，升执珪；再经阳武、轘辕、缑氏、尸地，在阳城及宛俘南阳守齮，夺武关、嶢关，昼夜攻蓝田，最后至咸阳灭秦。 [[7]](#note-7)


<a id="event-8"></a>

8. **定三秦与彭城进退。** 刘邦封曹参为建成侯，入汉中后升为将军，从还定三秦，在好畤等处攻章平，守景陵时挫其来军。曹参参与围废丘，后以中尉出临晋关，攻河内、定陶、彭城；汉兵败后又在雍丘、外黄、燕、衍氏、昆阳、武强等地战斗，终还荥阳。 [[8]](#note-8)


<a id="event-9"></a>

9. **破魏、赵并定齐。** 曹参代理左丞相，随韩信获魏王豹、定五十二县，斩赵相夏说。韩信打井陉时曹参另围戚公并追斩。后来攻齐破历下、取临淄，收济北，随韩信在上假密破龙且、俘周兰，合计得七十县；韩信赴会攻楚，曹参留齐平定余部。 [[9]](#note-9)


<a id="event-10"></a>

10. **征战功籍。** 传文总计曹参攻下两国、一百二十二县，俘两王、三相、六将及大莫囂、郡守、司马、候、御史各一。 [[10]](#note-10)


<a id="event-11"></a>

11. **请盖公而清静治齐。** 惠帝元年撤诸侯国相国之制，曹参改称齐丞相。齐初定而齐王年少，诸儒议论不一；曹参礼请胶西盖公，让出正堂安置他，采黄老清静之说，相齐九年，百姓安定。 [[11]](#note-11)


<a id="event-12"></a>

12. **入相前嘱勿扰狱市。** 萧何一死，曹参即料朝廷将命他入相，果然被召。临行告诫继任齐相，狱讼与市集本能兼容不同人，治理不宜扰察太过，使违法者无处容身而激成事变。 [[12]](#note-12)


<a id="event-13"></a>

13. **一遵萧何约束。** 曹参与萧何早年相善，显贵后有隙，但萧何临终仍推荐他。曹参接任后沿用旧章，挑选谨厚少文的吏员，斥去苛察求名者；以醇酒款留来客，借醉阻止他们争言政事。 [[13]](#note-13)


<a id="event-14"></a>

14. **相府宽待属吏细过。** 近后园的吏舍常有饮酒歌声，随从盼曹参亲自查责，曹参反而设酒同唱；日常见人小过就遮盖，府中因而少有纷争。 [[14]](#note-14)


<a id="event-15"></a>

15. **向惠帝申说守成。** 惠帝疑曹参轻视自己，私令其子曹窋归问。曹参责打儿子并使速回侍，惠帝承认是自己授意。曹参请惠帝比较高帝与今上、萧何与自己，主张创业者所立法令已经齐备，君臣各守其职即可。 [[15]](#note-15)


<a id="event-16"></a>

16. **平阳侯后嗣。** 曹窋袭侯，吕后时任御史大夫。曾孙曹襄为将击匈奴，其子曹宗有罪论处城旦。哀帝复封曹本始二千户，王莽时本始死；子曹宏归汉，建武中获封平阳侯。传文追计至此共八侯。 [[16]](#note-16)


<a id="event-17"></a>

17. **赞萧曹同心。** 班固说萧曹原都是秦的文书吏，汉兴后萧何以诚信谨慎掌机要，曹参与韩信征伐。二人因民苦秦而更始，同心安定天下，在韩信、黥布覆灭之后仍以重臣功名泽及子孙。 [[17]](#note-17)

> 孝惠二年，何薨，諡曰文終侯。子祿嗣，薨，無子。高后乃封何夫人同為酇侯，小子延為筑陽侯。孝文元年，罷同，更封延為酇侯。薨，子遺嗣。薨，無子。文帝復以遺弟則嗣，有罪免。景帝二年，制詔御史：「故相國蕭何，高皇帝大功臣，所與為天下也。今其祀絕，朕甚憐之。其以武陽縣戶二千封何孫嘉為列侯。」嘉，則弟也。薨，子勝嗣，後有罪免。武帝元狩中，復下詔御史：「以酇戶二千四百封何曾孫慶為酇侯，布告天下，令明知朕報蕭相國德也。」慶，則子也。薨，子壽成嗣，坐為太常儀牲瘦免。宣帝時，詔丞相御史求問蕭相國後在者，得玄孫建世等十二人，復下詔以酇戶二千封建世為酇侯。傳子至孫獲，坐使奴殺人減死論。成帝時，復封何玄孫之子南讀長喜為酇侯。傳子至曾孫，王莽敗乃絕。

> 漢二年，拜為假左丞相，入屯兵關中。月餘，魏王豹反，以假丞相別與韓信東攻魏將孫速東張，大破之。因攻安邑，得魏將王襄。擊魏王於曲陽，追至東垣，生獲魏王豹。取平陽，得豹母妻子，盡定魏地，凡五十二縣。賜食邑平陽。因從韓信擊趙相國夏說軍於鄔東，大破之，斬夏說。韓信與故常山王張耳引兵下井陘，擊成安君陳餘，而令參還圍趙別將戚公於鄔城中。戚公出走，追斬之。乃引兵詣漢王在所。韓信已破趙，為相國，東擊齊，參以左丞相屬焉。攻破齊歷下軍，遂取臨淄。還定濟北郡，收著、漯陰、平原、鬲、盧。已而從韓信擊龍且軍於上假密，大破之，斬龍且，虜亞將周蘭。定齊郡，凡得七十縣。得故齊王田廣相田光，其守相許章，及故將軍田既。韓信立為齊王，引兵東詣陳，與漢王共破項羽，而參留平齊未服者。

### 11. 请盖公而清静治齐

[返回正文第11条](#event-11)

<a id="hs039-p022"></a>

**[《汉书·萧何曹参传》P022](../../拆分史书/汉书/卷039.md#p022)** · [仓内TXT L7200—L7200](../../拆分史书/汉书/卷039.md#part-1-L7200)

> 孝惠元年，除諸侯相國法，更以參為齊丞相。參之相齊，齊七十城。天下初定，悼惠王富於春秋，參盡召長老諸先生，問所以安集百姓。而齊故諸儒以百數，言人人殊，參未知所定。聞膠西有蓋公，善治黃老言，使人厚幣請之。既見蓋公，蓋公為言治道貴清靜而民自定，推此類具言之。參於是避正堂，舍蓋公焉。其治要用黃老術，故相齊九年，齊國安集，大稱賢相。

### 12. 入相前嘱勿扰狱市

[返回正文第12条](#event-12)

<a id="hs039-p023"></a>

**[《汉书·萧何曹参传》P023](../../拆分史书/汉书/卷039.md#p023)** · [仓内TXT L7201—L7201](../../拆分史书/汉书/卷039.md#part-1-L7201)

> 蕭何薨，參聞之，告舍人趣治行，「吾且入相。」居無何，使者果召參。參去，屬其後相曰：「以齊獄市為寄，慎勿擾也。」後相曰：「治無大於此者乎？」參曰：「不然。夫獄市者，所以并容也，今君擾之，姦人安所容乎？吾是以先之。」

> 始參微時，與蕭何善，及為宰相，有隙。至何且死，所推賢唯參。參代何為相國，舉事無所變更，壹遵何之約束。擇郡國吏長大，訥於文辭，謹厚長者，即召除為丞相史。吏言文刻深，欲務聲名，輒斥去之。日夜飲酒。卿大夫以下吏及賓客見參不事事，來者皆欲有言。至者，參輒飲以醇酒，度之欲有言，復飲酒，醉而後去，終莫得開說，以為常。

> 參子窋為中大夫。惠帝怪相國不治事，以為「豈少朕與？」乃謂窋曰：「女歸，試私從容問乃父曰：『高帝新棄群臣，帝富於春秋，君為相國，日飲，無所請事，何以憂天下？』然無言吾告女也。」窋既洗沐歸，時間，自從其所諫參。參怒而笞之二百，曰：「趣入侍，天下事非乃所當言也。」至朝時，帝讓參曰：「與窋胡治乎？乃者我使諫君也。」參免冠謝曰：「陛下自察聖武孰與高皇帝？」上曰：「朕乃安敢望先帝！」參曰：「陛下觀參孰與蕭何賢？」上曰：「君似不及也。」參曰：「陛下言之是也。且高皇帝與蕭何定天下，法令既明具，陛下垂拱，參等守職，遵而勿失，不亦可乎？」惠帝曰：「善。君休矣！」

# 汉书蒯通伍被江充息夫躬的未确年事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **蒯通以相术暗示韩信三分天下。** 蒯通先借观面只能封侯、观背则贵不可言暗示背汉。继分析汉困荥阳成皋、楚锐气也受塞地和饷粮限制，战争胜负系在韩信，以观时势为由劝他兼存楚汉，鼎足三分，凭齐、燕赵、淮泗制两军之后，以得民为由吸引诸侯，不要失天时。 [[1]](#note-1)


<a id="event-2"></a>

2. **以交友、功高震主为鉴，韩信拒策。** 韩信以汉恩不可背为由拒绝。蒯通举张耳与陈馀昔友而后相残、文种立功仍遭勾践杀害，指出人心难测，韩信功威之盛又使楚汉都疑。他次日后再说决断重于空有谋计，机会难遇易失。韩信既不忍背汉，又相信大功足保齐，拒其议。蒯通怕受祸，装疯作巫。 [[2]](#note-2)


<a id="event-3"></a>

3. **蒯通为曹参上客，荐隐士与存说。** 曹参相齐悼惠王礼请蒯通。田荣曾挟迫士人起兵，东郭先生和梁石君被迫跟从，田荣败后羞而隐。蒯通借里妇被误逐、邻妇假借讨火揭明狗夺肉的办法，说明可借合适话头说贤；问曹参娶妇择守节者还是急嫁者，再说两隐士不求仕才可贵。曹参礼为上宾。蒯通整理战国游说及己说八十一首为《雋永》。与齐人安其生交好，项羽未能用他们的计，两人不受其封。 [[3]](#note-3)


<a id="event-4"></a>

4. **伍被在淮南宾客间居首。** 分传题伍被。楚人，有说是伍子胥之后，以才为淮南中郎。刘安好术学礼士，引英俊数百，伍被居首。 [[4]](#note-4)


<a id="event-5"></a>

5. **伍被屡谏刘安，陈说汉廷未乱。** 他以伍子胥预言姑苏台游鹿为喻，警告淮南宫将荒，刘安拘其父母三月。再召时伍被称圣人先知征兆，文王能因天心而动。汉礼制政纲尚在、商货流通、西南东南臣服或朝贡、开广长榆朔方且匈奴受创，在他看来可谓治世，刘安听而发怒。 [[5]](#note-5)


<a id="event-6"></a>

6. **论卫青将才并举吴国兵败为戒。** 伍被引黄义和曹梁见闻，颂卫青有礼爱卒、善骑善令、勇而身先，并与兵同休饮、以赐物赏士。刘安蔑视公卿，伍被说除非先除卫青才有起事机会。吴富盐铜、能结诸邦仍败死，为逆众失时；刘安说控成皋、轘辕、伊阙、武关并凭三川可召兵，伍被仍说只见其祸。 [[6]](#note-6)


<a id="event-7"></a>

7. **刘建被治，伍被论秦亡与当世形势。** 刘安怕内情泄而欲发兵西向，如无响应即回略衡山。伍被说占舟浦城戍抵南郡、通会稽强越只可延日，能率兵的近臣多已入狱。刘安举陈胜吴广小众起、天下响应反驳，伍被列秦焚书任刑、转运、筑长城、徐福入海不归、尉佗留南越、阿房宫和戍役严重流失民心；陈吴才得乘其隙。汉今为一统，政令有威且有卫青，淮南兵远少于当年吴楚，不能同秦末相比。末以箕子《麦秀》悲殷、孟子论纣早自绝为戒，忧刘安将身死东宫，流泪而起。 [[7]](#note-7)


<a id="event-8"></a>

8. **伍被献伪诏之计，自首仍被诛。** 刘安再问能否取侥幸，伍被提出伪造移徙豪强、有罪者、富户赴朔方及逮各王太子宠臣的文书，煽动居民和诸侯恐惧以求起事。王暂以为可却欲径发。败露后伍被自告，武帝本念他屡称汉朝之美欲不诛，廷尉张汤说出谋无赦，伍被被杀。 [[8]](#note-8)


<a id="event-9"></a>

9. **江齐与赵太子反目，改名入朝告发。** 分传题江充，字次倩，邯郸人，本名江齐。他的妹妹嫁给太子丹，他因而获敬肃王赏识，成为上客。太子疑江齐告密，追捕不获，系杀江氏父兄；江齐逃入关改名江充，告丹和亲姊、王妾私通，结豪恶为盗。朝廷围王宫捕太子入魏郡狱，赵王彭祖请以率勇士击匈奴赎子罪，武帝不许，丹终于败废。 [[9]](#note-9)


<a id="event-10"></a>

10. **江充以布衣冠服见武帝并监察三辅。** 江充穿原有的纱襌服、曲裾、步摇冠和羽缨入见，仪貌雄健，谈政合武帝意。自请使匈奴，答应因敌情灵活行事，回朝任绣衣使者，察三辅盗寇及奢僭，奏没贵戚车马、令其赴北军，移文光禄勋系统和门卫执行。近臣求以钱代罚获允，按秩共输数千万，武帝视江充为忠直守法。 [[10]](#note-10)


<a id="event-11"></a>

11. **江充禁驰道，升水衡都尉后免。** 馆陶长公主称有太后诏在驰道，江充说诏仅给公主，没入随从车骑。后来太子家使也走驰道，太子请江充宽免，江充照奏，武帝称扬，江充威震京师。升水衡都尉后宗族知友得其助，久后获罪免官。 [[11]](#note-11)


<a id="event-12"></a>

12. **息夫躬籍贯和受业。** 分传题息夫躬，字子微，河内河阳人，少为博士弟子学《春秋》，广览典籍，容貌壮伟使人觉异。 [[12]](#note-12)


<a id="event-13"></a>

13. **息夫躬借东平王案受封。** 息夫躬凭同郡傅晏结交，和免职的孙宠进书同待诏。哀帝初病，中山王太后及冯参因被告祝诅而自杀，实情未明。无盐危山有石立，息夫躬孙宠借祥异捏造东平王刘云和后祝诅，利用伍宏出入宫中的医技编说会毒弑，与右师谭因宋弘上告。刘云、王后、伍宏等被诛；孙宠、谭、宋弘、躬得官。哀帝欲封宠臣董贤，声称告案经董贤而闻，三人各封千户，谭得关内侯。王嘉疑其狱，反对封董贤等并指出息夫二人有倾邪才，触怒皇帝。 [[13]](#note-13)


<a id="event-14"></a>

14. **息夫躬诋公卿，提议引漕入长安。** 息夫躬近幸后数论事无所回避，贬王嘉畏缩、贾延软弱，公孙禄和鲍宣外直而不懂政，称若边敌入、京师被围，这些臣僚不会应变。他又拟效秦郑国渠，按地势查水、扩灌溉。哀帝使持节掌三辅水务，他测量拟穿长安城让漕舟直达太仓附近，因议论不可成而止。 [[14]](#note-14)


<a id="event-15"></a>

15. **借灾异议整军与拜授丁、傅。** 息夫躬援荧惑守心、太白芒、河鼓星异和民间传符谣，认为将有兵变，建议将军察边整武、斩郡守示威以厌灾。王嘉主以政行和诚善应异，反对游说者牵合星历、渲染外患，以秦穆公误听为戒。帝未纳王嘉，命军官举知兵者并整器，拜傅晏大司马卫将军，丁明改大司马骠骑将军。 [[15]](#note-15)


<a id="event-16"></a>

16. **息夫躬预著绝命辞。** 待诏时息夫躬担心危言得祸，写辞借阴云、猛禽、网、箭、丛棘、断羽写困境，称虽忘身进忠，却反陷受冤，求天察、叹无处可往，想到漫游远处而不可归。传认为数年后死亡与辞意相应。 [[16]](#note-16)


<a id="event-17"></a>

17. **班固评口辩害邦与历代谗祸。** 赞援孔子恶利口，称蒯通一说害齐局而免死是幸，伍被在危国为谋主又未能终忠，论诛有因。又列鲁隐公、晋厉公、楚太子建、夫差、春申君、屈原、秦二世、宋太子痤等遭阴谋进谗，连到江充造巫蛊、息夫诬东平王，指出身疏可陷至亲、事小足覆大国。 [[17]](#note-17)

### 1. 蒯通以相术暗示韩信三分天下

[返回正文第1条](#event-1)

<a id="hs045-p003"></a>

**[《汉书·蒯伍江息夫传》P003](../../sources/摘录/汉书-卷045-蒯伍江息夫传.md#p003)** · [仓内TXT L7456—L7456](../../sources/本地分卷/汉书/汉书-卷045.md#L7456)

> 蒯通知天下權在信，欲說信令背漢，乃先微感信曰：「僕嘗受相人之術，相君之面，不過封侯，又危而不安；相君之背，貴而不可言。」信曰：「何謂也？」通因請間，曰：「天下初作難也，俊雄豪桀建號壹呼，天下之士雲合霧集，魚鱗雜襲，飄至風起。當此之時，憂在亡秦而已。今劉、項分爭，使人肝腦塗地，流離中野，不可勝數。漢王將數十萬眾，距鞏、雒，岨山河，一日數戰，無尺寸之功，折北不救，敗滎陽，傷成皋，還走宛、葉之間，此所謂智勇俱困者也。楚人起彭城，轉鬥逐北，至滎陽，乘利席勝，威震天下，然兵困於京、索之間，迫西山而不能進，三年於此矣。銳氣挫於嶮塞，砕食盡於內藏，百姓罷極，無所歸命。以臣料之，非天下賢聖，其勢固不能息天下之禍。當今之時，兩主縣命足下。足下為漢則漢勝，與楚則楚勝。臣願披心腹，墮肝膽，效愚忠，恐足下不能用也。方今為足下計，莫若兩利而俱存之，參分天下，鼎足而立，其勢莫敢先動。夫以足下之賢聖，有甲兵之眾，據彊齊，從燕、趙，出空虛之地以制其後，因民之欲，西鄉為百姓請命，天下孰敢不聽！足下按齊國之故，有淮泗之地，懷諸侯以德，深拱揖讓，則天下君王相率而朝齊矣。蓋聞『天與弗取，反受其咎；時至弗行，反受其殃。』願足下孰圖之。」

### 7. 刘建被治，伍被论秦亡与当世形势

[返回正文第7条](#event-7)

<a id="hs045-p010"></a>

**[《汉书·蒯伍江息夫传》P010](../../sources/摘录/汉书-卷045-蒯伍江息夫传.md#p010)** · [仓内TXT L7470—L7470](../../sources/本地分卷/汉书/汉书-卷045.md#L7470)

> 後漢逮淮南王孫建，繫治之。王恐陰事泄，謂被曰：「事至，吾欲遂發。天下勞苦有間矣，諸侯頗有失行，皆自疑，我舉兵西鄉，必有應者；無應，即還略衡山。勢不得不發。」被曰：「略衡山以擊盧江，有尋陽之船，守下雉之城，結九江之浦，絕豫章之口，強弩臨江而守，以禁南郡之下，東保會稽，南通勁越，屈強江淮間，可以延歲月之壽耳，未見其福也。」王曰：「左吳、趙賢、朱驕如皆以為什八九成，公獨以為無福，何？」被曰：「大王之群臣近幸素能使眾者，皆前繫詔獄，餘無可用者。」王曰：「陳勝、吳廣無立錐之地，百人之聚，起於大澤，奮臂大呼，天下嚮應，西至於戲而兵百二十萬。今吾國雖小，勝兵可得二十萬，公何以言有禍無福？」被曰：「臣不敢避子胥之誅，願大王無為吳王之聽。往者秦為無道，殘賊天下，殺術士，燔詩書，滅聖跡，棄禮義，任刑法，轉海濱之粟，致于西河。當是之時，男子疾耕不足於糧餽，女子紡績不足於蓋形。遣蒙恬築長城，東西數千里。暴兵露師，常數十萬，死者不可勝數，僵尸滿野，流血千里。於是百姓力屈，欲為亂者十室而五。又使徐福入海求仙藥，多齎珍寶，童男女三千人，五種百工而行。徐福得平原大澤，止王不來。於是百姓悲痛愁思，欲為亂者十室而六。又使尉佗踰五嶺，攻百越，尉佗知中國勞極，止王南越。行者不還，往者莫返，於是百姓離心瓦解，欲為亂者十室而七。興萬乘之駕，作阿房之宮，收太半之賦，發閭左之戍。父不寧子，兄不安弟，政苛刑慘，民皆引領而望，傾耳而聽，悲號仰天，叩心怨上，欲為亂者，十室而八。客謂高皇帝曰：『時可矣。』高帝曰：『待之，聖人當起東南。』間不一歲，陳、吳大呼，劉、項並和，天下嚮應，所謂蹈瑕釁，因秦之亡時而動，百姓願之，若枯旱之望雨，故起於行陳之中，以成帝王之功。今大王見高祖得天下之易也，獨不觀近世之吳楚乎！當今陛下臨制天下，壹齊海內，氾愛蒸庶，布德施惠。口雖未言，聲疾雷震；令雖未出，化馳如神。心有所懷，威動千里；下之應上，猶景嚮也。而大將軍材能非直章邯、楊熊也。王以陳勝、吳廣論之，被以為過矣。且大王之兵眾不能什分吳楚之一，天下安寧又萬倍於秦時。願王用臣之計。臣聞箕子過故國而悲，作麥秀之歌，痛紂之不用王子比干之言也。故孟子曰，紂貴為天子，死曾不如匹夫。是紂先自絕久矣，非死之日天去之也。今臣亦竊悲大王棄千乘之君，將賜絕命之書，為群臣先，身死于東宮也。」被因流涕而起。

### 8. 伍被献伪诏之计，自首仍被诛

> 哀帝初即位，皇后父特進孔鄉侯傅晏與躬同郡，相友善，躬繇是以為援，交游日廣。先是，長安孫寵亦以游說顯名，免汝南太守，與躬相結，俱上書，召待詔。是時哀帝被疾，始即位，而人有告中山孝王太后祝詛上，太后及弟宜鄉侯馮參皆自殺，其罪不明。是後無鹽危山有石自立，開道。躬與寵謀曰：「上亡繼嗣，體久不平，關東諸侯，心爭陰謀。今無鹽有大石自立，聞邪臣託往事，以為大山石立而先帝龍興。東平王雲以故與其后日夜祠祭祝詛上，欲求非望。而后舅伍宏反因方術以醫技得幸，出入禁門。霍顯之謀將行於杯杓，荊軻之變必起於帷幄。事勢若此，告之必成；發國姦，誅主讎，取封侯之計也。」躬、寵乃與中郎右師譚，共因中常侍宋弘上變事告焉。上惡之，下有司案驗，東平王雲、雲后謁及伍宏等皆坐誅。上擢寵為南陽太守，譚穎川都尉，弘、躬皆光祿大夫左曹給事中。是時侍中董賢愛幸，上欲侯之，遂下詔云：「躬、寵因賢以聞，封賢為高安侯，寵為方陽侯，躬為宜陵侯，食邑各千戶。賜譚爵關內侯，食邑。」丞相王嘉內疑東平獄事，爭不欲侯賢等，語在嘉傳。嘉固言董賢泰盛，寵、躬皆傾覆有佞邪材，恐必撓亂國家，不可任用。嘉以此得罪矣。

# 汉书西南两粤朝鲜的风俗与沿革

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **西南诸部及其生活方式。** 作者依巴蜀西南的方向及聚落类型，列夜郎、滇、邛都、巂昆明、徙莋、冉駹和白马等，分说耕聚、逐畜迁徙与诸君长。 [[1]](#note-1)


<a id="event-2"></a>

2. **庄蹻王滇及秦汉通道。** 传称楚遣庄蹻从长江上游进入滇池，秦夺巴、黔中使其不能回楚，他留滇从俗为王。秦通五尺道置吏，汉初收回边防，巴蜀商人仍往来。 [[2]](#note-2)


<a id="event-3"></a>

3. **唐蒙通夜郎、相如通西夷及减撤。** 建元六年唐蒙奉使南越，由蜀枸酱知道牂柯江能通番禺，遂建议从夜郎通南越后侧。武帝先后遣唐蒙、相如，置官郡、发卒开道。交通长期不成而耗费甚大，公孙弘建议把力量转到北边，暂撤西夷组织。 [[3]](#note-3)


<a id="event-4"></a>

4. **滇降、置益州郡与赐印。** 汉使借灭越及攻南夷之威招滇。劳深、靡莫屡犯汉使，元封二年汉击二部而临滇，滇王归降、请求置吏，仍以王印治理本部，汉置益州郡。 [[4]](#note-4)


<a id="event-5"></a>

5. **铁器禁运、赵佗称帝与汉军撤退。** 吕后禁铁器关市，赵佗疑长沙图并南越，自尊号并攻边。周灶所部因暑湿大疫未能越岭，吕后死后撤兵；赵佗又以财物和军力扩大对旁部的影响。 [[5]](#note-5)


<a id="event-6"></a>

6. **景帝时仍通使。** 陆贾返报之后汉与南越通使延续。传称赵佗在境内仍私用旧帝号，对汉使则依诸侯王礼。 [[6]](#note-6)


<a id="event-7"></a>

7. **严助出使与太子入宿卫。** 严助谕赵胡，赵胡遣太子婴齐入宿卫，本拟赴汉，后听臣下所惧称病不来。十余年后赵胡病重，太子归国，赵胡死谥文王。 [[7]](#note-7)


<a id="event-8"></a>

8. **婴齐继位与立储。** 婴齐收藏先王帝玺，请立在汉所娶樛氏为后及子兴为嗣。本人惧受汉法管束称病，另遣子次公宿卫，身后谥明王。 [[8]](#note-8)


<a id="event-9"></a>

9. **闽越与东瓯勾践传系及两次封立。** 无诸、摇相传出自勾践，秦并为闽中郡，秦末佐吴芮及汉。汉高帝五年复立无诸，惠帝三年立摇，两次授王分年。 [[9]](#note-9)


<a id="event-10"></a>

10. **余善持两端与杨仆请转兵。** 余善请从征南越，中途以风浪为辞并暗通吕嘉；番禺平后杨仆请乘势攻东越，武帝惜兵力，令诸校待命。 [[10]](#note-10)


<a id="event-11"></a>

11. **卫满越浿水而王朝鲜。** 燕曾经营真番、朝鲜，秦属辽东外徼，汉沿浿水设界。卢绾亡匈奴后，卫满聚人东渡，渐兼真番、朝鲜旧部和中原亡人，定都王险。 [[11]](#note-11)


<a id="event-12"></a>

12. **卫满受约为外臣。** 辽东太守约卫满护塞，不阻近邻君长入汉朝见，朝廷批准；卫满由此扩张势力，真番、临屯服属。 [[12]](#note-12)


<a id="event-13"></a>

13. **班固议四方经营。** 赞将西南、两越、朝鲜用兵归于唐蒙等臣倡议，国力富盛故能成功，但已甚劳民。末又以文帝怀柔赵佗作对照。 [[13]](#note-13)

> 南夷君長以十數，夜郎最大。其西，靡莫之屬以十數，滇最大。自滇以北，君長以十數，邛都最大。此皆椎結，耕田，有邑聚。其外，西自桐師以東，北至葉榆，名爲巂、昆明、編發，隨畜移徙，亡常處，亡君長，地方可數千里。自巂以東北，君長以十數，徙、莋都最大。自莋以東北，君長以十數，冉駹最大。其俗，或土著，或移徙。在蜀之西。自駹以東北，君長以十數，白馬最大，皆氐類也。此皆巴、蜀西南外蠻夷也。

> 始楚威王時，使將軍莊蹻將兵循江上，略巴、黔中以西。莊蹻者，楚莊王苗裔也。蹻至滇池，方三百里，旁平地肥饒數千里，以兵威定屬楚。欲歸報，會秦擊奪楚巴、黔中郡，道塞不通，因乃以其衆王滇，變服，從其俗以長之。秦時嘗破，略通五尺道，諸此國頗置吏焉。十余歲，秦滅。及漢興，皆棄此國而關蜀故徼。巴、蜀民或竊出商賈，取其莋馬、僰僮、旄牛，以此巴、蜀殷富。

### 3. 唐蒙通夜郎、相如通西夷及减撤

[返回正文第3条](#event-3)

<a id="hs095-p003"></a>

**[《汉书·西南夷两粤朝鲜传》P003](../../拆分史书/汉书/卷095.md#p003)** · [仓内TXT L9906—L9906](../../拆分史书/汉书/卷095.md#part-1-L9906)

> 建元六年，大行王恢擊東粵，東粵殺王郢以報。恢因兵威使番陽令唐蒙風曉南粵。南粵食蒙蜀枸醬，蒙問所從來，曰：「道西北牂柯江，江廣數里，出番禺城下。」蒙歸至長安，問蜀賈人，獨蜀出枸醬，多持竊出市夜郎。夜郎者，臨牂柯江，江廣百余步，足以行船。南粵以財物役屬夜郎，西至桐師，然亦不能臣使也。蒙乃上書說上曰：「南粵王黃屋左纛，地東西萬餘里，名爲外臣，實一州主。今以長沙、豫章往，水道多絕，難行。竊聞夜郎所有精兵可得十萬，浮船牂柯，出不意，此制粵一奇也。誠以漢之強，巴、蜀之饒，通夜郎道，爲置吏，甚易。」上許之。乃拜蒙以郎中將，將千人，食重萬餘人，從巴苻關入，遂見夜郎侯多同。厚賜，諭以威德，約爲置吏，使其子爲令。夜郎旁小邑皆貪漢繒帛，以爲漢道險，終不能有也，乃且聽蒙約。還報，乃以爲犍爲郡。發巴、蜀卒治道，自僰道指牂柯江。蜀人司馬相如亦言西夷邛、莋可置郡。使相如以郎中將往諭，皆如南夷，爲置一都尉，十餘縣，屬蜀。當是時，巴、蜀西郡通西南夷道，載轉相餉。數歲，道不通，士罷餓餧，離暑濕，死者甚衆。西南夷又數反，發兵興擊，耗費亡功。上患之，使公孫弘往視問焉。還報，言其不便。及弘爲御史大夫，時方築朔方，據河逐胡，弘等因言西南夷爲害，可且罷，專力事匈奴。上許之，罷西夷，獨置南夷兩縣一都尉，稍令犍爲自保就。

> 使王然於以粵破及誅南夷兵威風諭滇王入朝。滇王者，其衆數萬人，其旁東北勞深、靡莫皆同姓相杖，未肯聽。勞、莫數侵犯使者吏卒。元封二年，天子發巴、蜀兵擊滅勞深、靡莫，以兵臨滇。滇王始首善，以故弗誅。滇王離西夷，滇舉國降，請置吏入朝，於是以爲益州郡，賜滇王王印，復長其民。西南夷君長以百數，獨夜郎、滇受王印。滇，小邑也，最寵焉。

### 11. 卫满越浿水而王朝鲜

[返回正文第11条](#event-11)

<a id="hs095-p036"></a>

> 朝鮮王滿，燕人。自始燕時，嘗略屬真番、朝鮮，爲置吏築障。秦滅燕，屬遼東外徼。漢興，爲遠難守，復修遼東故塞，至浿水爲界，屬燕。燕王盧綰反，入匈奴，滿亡命，聚党千餘人，椎結蠻夷服而東走出塞，渡浿水，居秦故空地上下障，稍伇屬真番、朝鮮蠻夷及故燕、齊亡在者王之，都王險。

> 贊曰：楚、粵之先，曆世有土。及周之衰，楚地方五千里，而勾踐亦以粵伯。秦滅諸侯，唯楚尚有滇王。漢誅西南夷，獨滇復寵。及東粵滅國遷衆，繇王居股等猶爲萬戶侯。三方之開，皆自好事之臣。故西南夷發于唐蒙、司馬相如，兩粵起嚴助、硃買臣，朝鮮由涉何。遭世富盛，動能成功，然已勤矣。追觀太宗填撫尉佗，豈古所謂「招攜以禮，懷遠以德」者哉！

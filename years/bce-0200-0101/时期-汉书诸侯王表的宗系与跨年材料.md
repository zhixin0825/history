# 汉书诸侯王表的宗系与跨年材料

[本世纪目录](README.md) · [全部世纪](../README.md)

这里按原卷保留表序、栏头、谱系和无法确系单一年度的材料。确年原句由各卷去向连接对应年份。


<a id="event-1"></a>

1. **表序｜周室封国维系王权。** 班固说周从前代取法，分五等爵位、设封国，用宗亲和贤人屏护王室。《诗》所说藩、屏、翰、城都是这种比喻。周室衰落后仍受诸侯维护，直至周赧王为庶人而死，天下长时间没有新的共主。 [[1]](#note-1)


<a id="event-2"></a>

2. **表序｜秦废封国以后。** 秦凭地利和用兵兼并诸侯，废弃封建制度，让宗室子弟没有封地。班固认为秦既无同姓襄助，又无藩翼，陈胜、吴广以木棒起事后，刘邦和项羽得以迅速消灭秦朝。 [[2]](#note-2)


<a id="event-3"></a>

3. **表序｜汉初同姓九国。** 汉惩戒秦的孤立，封百余功臣为列侯，并扩大同姓王国。燕、代至辽阳，齐、赵沿河济，梁、楚邻龟蒙，荆吴、淮南、长沙各据大区。天子直辖十五郡。诸侯过强有弊，班固也承认它们在高后与文帝交接时有支持汉室的一面。 [[3]](#note-3)


<a id="event-4"></a>

4. **表序｜从分国、削地到推恩。** 文帝据贾谊主张分齐、赵，景帝用晁错之策削藩，武帝用主父偃的推恩令，让诸王分封子弟。七国之乱后减诸侯官属，淮南、衡山案后有左官律、附益法；王仍食税租，国政转归朝廷。 [[4]](#note-4)


<a id="event-5"></a>

5. **表序｜宗藩衰弱与王莽篡位。** 班固认为哀、平时宗藩与皇室关系渐远，未能制衡王莽。王莽凭太后权势和伊尹、周公之名发号施令，诸王争着交出玺绶。这里是作者总结诸侯强弱的政治得失。 [[5]](#note-5)


<a id="event-6"></a>

6. **高祖系｜表头。** 按王国、谥号、亲属、始封与多代后嗣追列。相邻代的嗣年与上一代死亡可能跨年。 [[6]](#note-6)


<a id="event-7"></a>

7. **高祖系合计与文帝系表头。** 总数列高祖系王及随父列的吴王，再换文帝系。各代仍按谥号、亲属、始封和继嗣列记。 [[7]](#note-7)


<a id="event-8"></a>

8. **文帝系合计与景帝系表头。** 文帝本系三人，并附列当时随父一支的诸王。以下换景帝系，仍区分始封和后嗣。 [[8]](#note-8)


<a id="event-9"></a>

9. **景帝系合计与武帝系表头。** 景帝本系十四人，附随父等合十九人。以下换武帝系。 [[9]](#note-9)


<a id="event-10"></a>

10. **武帝系合计与宣帝系表头。** 武帝本系四人，六安、真定、泗水、平干随父计，共八人。以下换宣帝系。 [[10]](#note-10)


<a id="event-11"></a>

11. **宣帝系合计与元帝系表头。** 宣帝本系四人，计入燕继绝与高密随父共六人。以下换元帝系。 [[11]](#note-11)


<a id="event-12"></a>

12. **表末｜元帝系与续封。** 本表末列元帝系王与广陵恢复，并总结成、哀、平诸朝续绝的河间、广德、定陶、广平、东平、中山、广世、广宗等王国。总目与各分支合读。 [[12]](#note-12)

### 1. 表序｜周室封国维系王权

**[《汉书·诸侯王表》P001](../../拆分史书/汉书/卷014.md#p001)** · [仓内TXT L1330—L1330](../../拆分史书/汉书/卷014.md#part-1-L1330)

> 昔周監於二代，三聖制法，立爵五等，封國八百，同姓五十有餘。周公、康叔建於魯、衞，各數百里；太公於齊，亦五侯九伯之地。詩載其制曰：「介人惟藩，大師惟垣。大邦惟屏，大宗惟翰。懷德惟寧，宗子惟城。母俾城壞，毋獨斯畏。」所以親親賢賢，襃表功德，關諸盛衰，深根固本，為不可拔者也。故盛則周、邵相其治，致刑錯；衰則五伯扶其弱，與共守。自幽、平之後，日以陵夷，至虖阸`䧢河洛之閒，分為二周，有逃責之臺，被竊鈇之言。然天下謂之共主，彊大弗之敢傾。歷載八百餘年，數極德盡，旣於王赧，降為庶人，用天年終。號位已絕於天下，尚猶枝葉相持，莫得居其虛位，海內無主三十餘年。

### 3. 表序｜汉初同姓九国

[返回正文第3条](#event-3)

<a id="hs014-p003"></a>

**[《汉书·诸侯王表》P003](../../拆分史书/汉书/卷014.md#p003)** · [仓内TXT L1332—L1332](../../拆分史书/汉书/卷014.md#part-1-L1332)

> 漢興之初，海內新定，同姓寡少，懲戒亡秦孤立之敗，於是剖裂疆土，立二等之爵。功臣侯者百有餘邑，尊王子弟，大啟九國。自鴈門以東，盡遼陽，為燕、代。常山以南，太行左轉，度河、濟，漸于海，為齊、趙。穀、泗以往，奄有龜、蒙，為梁、楚。東帶江、湖，薄會稽，為荊吳。北界淮瀕，略廬、衡，為淮南。波漢之陽，亘九嶷，為長沙。諸侯比境，周帀三垂，外接胡越。天子自有三河、東郡、潁川、南陽，自江陵以西至巴蜀，北自雲中至隴西，與京師內史凡十五郡，公主、列侯頗邑其中。而藩國大者夸州兼郡，連城數十，宮室百官同制京師，可謂撟抂過其正矣。雖然，高祖創業，日不暇給，孝惠享國又淺，高后女主攝位，而海內晏如，亡狂狡之憂，卒折諸呂之難，成太宗之業者，亦賴之於諸侯也。

### 4. 表序｜从分国、削地到推恩

[返回正文第4条](#event-4)

<a id="hs014-p004"></a>

**[《汉书·诸侯王表》P004](../../拆分史书/汉书/卷014.md#p004)** · [仓内TXT L1333—L1333](../../拆分史书/汉书/卷014.md#part-1-L1333)

> 然諸侯原本以大，末流濫以致溢，小者淫荒越法，大者睽孤橫逆，以害身喪國。故文帝采賈生之議分齊、趙，景帝用鼂錯之計削吳、楚。武帝施主父之冊，下推恩之令，使諸侯王得分戶邑以封子弟，不行黜陟，而藩國自析。自此以來，齊分為七趙分為六，梁分為五，淮南分為三。皇子始立者，大國不過十餘城。長城、燕、代雖有舊名，皆亡南北邊矣。景遭七國之難，抑損諸侯，減黜其官。武有衡山、淮南之謀，作左官之律，設附益之法，諸侯惟得衣食稅租，不與政事。

# 汉书货殖仕业与各地商利

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **先王的等级、四民与取用之节。** 篇首先描绘理想的等级制度，衣食、居丧和礼器均有差等；因地授业、按时取材，使草木禽兽繁育，不误农业。作者引《易》《管子》，称士农工商各从同业习得知识、彼此交易供足，再以礼德克制竞利。 [[1]](#note-1)


<a id="event-2"></a>

2. **周衰与礼制僭越。** 诸侯大夫擅用高于其身份的宫室雕饰、舞列和乐章。作者认为这种风气通行后，本业农业渐少，商旅居多，虽有货财却出现谷物不足。 [[2]](#note-2)


<a id="event-3"></a>

3. **桓文以后财富与法度失衡。** 礼制崩解之后，奢货新器及迎合时尚可以牟利；大者夺国，小者兼并成家。富户奢靡而贫民缺衣，编户虽同列却因财力悬殊互为主仆。作者把失衡追溯到上层教化和法度失效，借下文财主事迹考察世变。 [[3]](#note-3)


<a id="event-4"></a>

4. **计然富越和范蠡择时治产。** 勾践在会稽失败后听从范蠡和计然，按丰歉、旱涝反向储备物品，国富后养士报吴。范蠡离越易名，至齐称鸱夷子皮，在交通便利的陶自称朱公，择人任时，多次积财又济亲友。仓内本开头作“蕩蠡”，下文另作“范蠡”。 [[4]](#note-4)


<a id="event-5"></a>

5. **子贡以财通诸侯。** 子贡曾在曹、鲁间经营，财货冠孔门弟子，带随从和束帛往来诸侯，受敌国之礼。列传用贫而自守的颜回作对照，转引孔子对子贡不安天命、常能料中行情的评论。 [[5]](#note-5)


<a id="event-6"></a>

6. **白圭经营的进退。** 魏文侯时，白圭专察时势，与市场取舍相反，以节衣食、和僮仆同甘苦积聚资本。作者引用他自比名相、兵家、法家，称判断、取舍和坚守都须有相应能力。 [[6]](#note-6)


<a id="event-7"></a>

7. **猗顿、郭纵分别致富。** 猗顿靠盐业起家，邯郸郭纵则经营冶铸；财富均被比作王者。 [[7]](#note-7)


<a id="event-8"></a>

8. **乌氏蠃与戎王畜产交易。** 乌氏蠃由畜牧获利，以珍奇丝织品与戎王来往，换得大批牲畜。始皇令他按封君待遇定期入朝。仓内本作“蠃”，《史记》有关版本作“倮”。 [[8]](#note-8)


<a id="event-9"></a>

9. **巴寡妇清守朱砂业。** 清承袭家族的丹砂资源，以财富自卫。秦始皇以贞妇礼遇她，为她筑怀清台；本文未记筑台年月。 [[9]](#note-9)


<a id="event-10"></a>

10. **封邑收入与各业规模之比。** 作者用平均每户二百钱估算侯租，以年息二成估算民间经营收益，再列畜产、鱼池、果树、桑麻、竹漆和城郊良田的规模。数字用于说明哪些大宗产业约比千户侯收入。 [[10]](#note-10)


<a id="event-11"></a>

11. **都会经营规模与利率。** 俗谚比较农、工、商可以致富的速度；本文列酒醋、粮谷、畜产屠宰、舟车木竹、纺织、盐鱼、钱贷等都会行业的规模和收益。末句分别概估牙人、不同经营商贩的可比规模。 [[11]](#note-11)


<a id="event-12"></a>

12. **卓氏由赵迁蜀后经营铁业。** 秦破赵后徙卓氏于蜀。别的迁户设法求近，卓氏夫妇却主动求往临邛，理由是沃地能种芋、当地织布便于交易。他们用铁山冶铸、连通滇蜀市场，渐富至童仆数百，田池射猎近于诸侯。 [[12]](#note-12)


<a id="event-13"></a>

13. **程郑在蜀经商冶铸。** 同是自东方迁来的程郑以冶铸经营，并同椎髻人群交易，财力可比卓氏。 [[13]](#note-13)


<a id="event-14"></a>

14. **罗裒藉权贵经营巴蜀。** 成帝、哀帝之间罗裒由替平陵石氏经营起家，数年积财千万；向曲阳侯、定陵侯输送厚礼，借权势收回赊贷并独取盐井收益，自此财势更强。 [[14]](#note-14)


<a id="event-15"></a>

15. **宛孔氏因迁徙经营冶铸。** 秦灭魏后迁善冶铁的孔氏到南阳。他们经营冶铸、水田与跨地贸易，看似交游豪阔，实能获利，南阳商人效其作风。 [[15]](#note-15)


<a id="event-16"></a>

16. **鲁丙氏勤俭经营。** 丙氏靠铁冶致富，家人仍勤于收集生产资料、借贷和各地交易。作者以他们为例解释邹鲁部分人为何由经学转向逐利。 [[16]](#note-16)


<a id="event-17"></a>

17. **刀间用豪奴、临淄姓伟继起。** 刀间优待他人忌惮的强悍奴仆，使其经营鱼盐、交结郡守国相，所得厚利也让他们富足；传文再述成、哀之际临淄大户姓伟。 [[17]](#note-17)


<a id="event-18"></a>

18. **师史凭洛阳交通经营长途运输。** 洛阳交通连通数地，师史组织百余车辆到各郡国经营，以长期行商和保持周转致富，同行也引此为荣。 [[18]](#note-18)


<a id="event-19"></a>

19. **张长叔、薛子促获王莽任用。** 师史衰落后，洛阳张长叔和薛子促财富继起。王莽任二人为纳言士，企图仿效武帝起用擅长财利者，本文认为期望的收益未实现。 [[19]](#note-19)


<a id="event-20"></a>

20. **任氏窖存粮食和整饬家业。** 秦亡时任氏先人先藏仓粮。楚汉相持荥阳、农事中断而米价暴涨，先前争抢的金玉转到任氏手中。其后任家崇尚田畜、选用优质物品，依家规节用并受地方尊重。 [[20]](#note-20)


<a id="event-21"></a>

21. **桥桃由边塞拓展增加畜产。** 边塞扩展时，桥桃积聚许多马、牛、羊和粟。段落没有写明哪一次开塞及财富积累年月。 [[21]](#note-21)


<a id="event-22"></a>

22. **关中富户与王孙卿任京司市师。** 列举早晚不同时期的关中富户。王孙卿以财结交才士豪杰，王莽任其为京司市师；传用汉朝的司东市令解释新官掌管的事务。 [[22]](#note-22)


<a id="event-23"></a>

23. **篇末区别民生经营与垄断犯禁。** 作者承认农事、食品、磨刀和畜医等普通行业也能逐步积富，却批评富商独占山川矿渔，兼与国家争利、压制编户生业，更谴责盗墓和非法攫财。这是班固对经济秩序和风俗的判断。 [[23]](#note-23)

### 1. 先王的等级、四民与取用之节

[返回正文第1条](#event-1)

<a id="hs091-p001"></a>

**[《汉书·货殖传》P001](../../sources/摘录/汉书-卷091-货殖传.md#p001)** · [仓内TXT L9637—L9637](../../sources/本地分卷/汉书/汉书-卷091.md#L9637)

> 昔先王之制，自天子、公、侯、卿、大夫、士至於皂隸、抱關、擊还者，其爵祿、奉養、宮室、車服、棺槨、祭祀、死生之制各有差品，小不得僭大，賤不得逾貴。夫然，故上下序而民志定。於是辯其土地、川澤、丘陵、衍沃、原隰之宜，教民種樹畜養；五穀六畜及至魚鱉、鳥獸、雚蒲、材干、器械之資，所以養生送終之具，靡不皆育。育之以時，而用之有節。草木未落，斧斤不入於山林；豺獺未祭，罝網不佈於野澤；鷹隼未擊，矰弋不施於徯隧。既順時而取物，然猶山不茬薛，澤不伐夭，蟓魚麛卵，咸有常禁。所以順時宣氣，蕃阜庶物，蓄足功用，如此之備也。然後四民因其土宜，各任智力，夙興夜寐，以治其業，相與通功易事，交利而俱贍，非有征發期會，而遠近咸足。故《易》曰「後以財成輔相天地之宜，以左右民」，「備物致用，立成器以為天下利，莫大乎聖人」。此之謂也《管子》雲古之四民不得雜處。士相與言仁誼於閒宴，工相與議技巧於官府，商相與語財利於市井，農相與謀稼穡於田野，朝夕從事，不見異物而遷焉。故其父兄之教不肅而成，子弟之學不勞而能，各安其居而樂其業，甘其食而美其服，雖見奇麗紛華，非其所習，辟猶戎翟之與於越，不相入矣。是以欲寡而事節，財足而不爭。於是在民上者，道之以德，齊之以禮，故民有恥而且敬，貴誼而賤利。此三代之所以直道而行，不嚴而治之大略也。

### 3. 桓文以后财富与法度失衡

[返回正文第3条](#event-3)

<a id="hs091-p003"></a>

**[《汉书·货殖传》P003](../../sources/摘录/汉书-卷091-货殖传.md#p003)** · [仓内TXT L9639—L9639](../../sources/本地分卷/汉书/汉书-卷091.md#L9639)

> 陵夷至乎桓、文之後，禮誼大壞，上下相冒，國異政，家殊俗，嗜欲不制，僭差亡極。於是商通難得之貨，工作亡用之器，士設反道之行，以追時好而取世資。偽民背實而要名，姦夫犯害而求利，篡弒取國者為王公，圉奪成家者為雄桀。禮誼不足以拘君子，刑戮不足以威小人。富者木土被文錦，犬馬余肉粟，而貧者短褐不完，含菽飲水。其為編戶齊民，同列而以財力相君，雖為僕虜，猶亡慍色。故夫飾變詐為奸軌者，自足乎一世之間；守道循理者，不免於饑寒之患。其教自上興，由法度之無限也。故列其行事，以傳世變雲。

### 4. 计然富越和范蠡择时治产

[返回正文第4条](#event-4)

<a id="hs091-p004"></a>

**[《汉书·货殖传》P004](../../sources/摘录/汉书-卷091-货殖传.md#p004)** · [仓内TXT L9640—L9640](../../sources/本地分卷/汉书/汉书-卷091.md#L9640)

> 昔粵王勾踐困於會稽之上，乃用蕩蠡、計然。計然曰：「知斗則修備，時用則知物，二者形則萬貨之情可得見矣。故旱則資舟，水則資車，物之理也。」推此類而修之，十年國富，厚賂戰士，遂報強吳，刷會稽之恥。范蠡歎曰：「計然之策，十用其五而得意。既以施國，吾欲施之家。」乃乘扁舟，浮江湖，變名姓，適齊為鴟夷子皮，之陶為硃公。以為陶天下之中，諸侯四通，貨物所交易也，乃治產積居，與時逐而不責於人。故善治產者，能擇人而任時。十九年之間三致千金，再散分與貧友昆弟。後年衰老，聽子孫修業而息之，遂至巨萬。故言富者稱陶硃。

**[《汉书·货殖传》P024](../../sources/摘录/汉书-卷091-货殖传.md#p024)** · [仓内TXT L9660—L9660](../../sources/本地分卷/汉书/汉书-卷091.md#L9660)

> 此其章章尤著者也。其餘郡國富民兼業顓利，以貨賂自行，取重於鄉里者，不可勝數。故秦楊以田農而甲一州，翁伯以販脂而傾縣邑，張氏以賣醬而隃侈，質氏以灑削而鼎食，濁氏以胃脯而連騎，張裡以馬醫而擊鐘，皆越法矣。然常循守事業，積累贏利，漸有所起。至於蜀卓，宛孔，齊之刀間，公擅山川銅鐵魚鹽市井之入，運其籌策，上爭王者之利，下錮齊民之業，皆陷不軌奢僭之惡。又況掘塚搏掩，犯奸成富，曲叔、稽發、雍樂成之徒，猶夏齒列，傷化敗俗，大亂之道也。

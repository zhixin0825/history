# 汉书贾山邹阳枚乘路温舒的书奏与交游

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **贾山家学。** 颍川人贾山随祖父贾祛学，博览书牍而非专治一经，曾在颍阴侯府做骑从。 [[1]](#note-1)


<a id="event-2"></a>

2. **文帝时论治乱。** 贾山借秦朝盛亡论治乱，传题此疏为《至言》。 [[2]](#note-2)


<a id="event-3"></a>

3. **以近事切谏。** 贾山自称甘冒杀身祸尽言，愿以秦近在眼前的败亡提醒君主。 [[3]](#note-3)


<a id="event-4"></a>

4. **秦以奢侈亡后嗣。** 赋役繁重，服役罪人与群盗遍地，一闻陈胜起事便应。离宫、阿房、驰道、骊山墓极尽华侈，后人却无屋栖、无路走、无坟葬。贾山说秦兼并有力而礼义不足。 [[4]](#note-4)


<a id="event-5"></a>

5. **纳谏方可知过。** 肥地能育种，仁君能养士。夏商末贤士进谏死；周文王容得上下献力。史记过、乐诵箴、士传言以及百姓商旅议论都能使君主知过。亲礼三老、设辅弼谏士用以示孝防骄、从善。 [[5]](#note-5)


<a id="event-6"></a>

6. **秦一君耗天下而期万世。** 秦并六国，自信郡县长城强固。贾山以周取民有度对照始皇耗全国财力劳力供自己，以号称始皇、二世乃至万世对照身后顷刻天下反。 [[6]](#note-6)


<a id="event-7"></a>

7. **秦人不敢言与文王得士。** 始皇杀直言者，以致左右只说秦功过尧舜汤武。引《诗》说明文王敬贤用才所以安邦。 [[7]](#note-7)


<a id="event-8"></a>

8. **君臣间的礼敬。** 君主尊亲大臣，探病临丧、吊哭服丧并暂去酒肉乐舞。以礼相见才能使臣下尽心效力，留下好名声。 [[8]](#note-8)


<a id="event-9"></a>

9. **勿以贤良方正从猎。** 举贤曾使天下期待德治，文帝却又选他们作猎从。贾山担忧朝廷废弛，诸侯仿效。 [[9]](#note-9)


<a id="event-10"></a>

10. **文帝初政与兴学议。** 数其节膳省卫、减贡、以马充传置、以地给农、赈贫养老、赦徒宽刑，称民心归附。愿少猎，在夏历二月定明堂、建太学，使宴游有节，贤臣议政。二月是建议，不是已实行的日期。 [[10]](#note-10)


<a id="event-11"></a>

11. **铸钱与淮南王诸谏。** 放开铸钱后，贾山以货币关联富贵权柄，反对由民掌握；又为淮南王辩护、举柴唐之子为戒。贾山受诘不受罚，传末另记其后重禁铸钱。 [[11]](#note-11)


<a id="event-12"></a>

12. **邹阳小目。** 以下叙邹阳游吴、梁及进谏。 [[12]](#note-12)


<a id="event-13"></a>

13. **邹阳从吴与吴王称疾。** 齐人邹阳与严忌、枚乘同入吴，以辞辩知名。吴王因太子死怨朝廷，称疾不朝并暗有谋议，邹阳借秦、边患及诸藩的故事婉谏。 [[13]](#note-13)


<a id="event-14"></a>

14. **从秦亡与边患论王国孤立。** 秦临危时各郡不救，起兵者遂能撼关中。邹阳列诸王各有心事、北胡南越及汉军调动的可能情势，警告吴若妄图举事易遭孤立。 [[14]](#note-14)


<a id="event-15"></a>

15. **游士愿为吴王竭虑。** 蛟龙动而云雨至，圣王修德而游士慕义来归。他称自己可入各王门下，远来吴是敬重吴王，愿吴王听察志意。 [[15]](#note-15)


<a id="event-16"></a>

16. **将士众多不及一名贤谋。** 百鸷不如一鹗，赵、淮南虽有许多勇士，也不能免幽王、厉王遭祸。决策有失，勇士不足挽救。 [[16]](#note-16)


<a id="event-17"></a>

17. **凭汉初及文帝史事戒吴。** 列文帝入继处置宗藩、济北失败、淮南王获罪；再举高祖烧栈道、灌废丘、克楚，警告汉廷能制关中山东。 [[17]](#note-17)


<a id="event-18"></a>

18. **吴王不采。** 吴王未接受邹阳的进言。 [[18]](#note-18)


<a id="event-19"></a>

19. **邹阳等离吴入梁。** 梁孝王礼士，邹阳、枚乘、严忌看出吴王不能劝阻，转投梁。 [[19]](#note-19)


<a id="event-20"></a>

20. **遭梁近臣谗害下狱。** 邹阳有智略而不苟合，羊胜、公孙诡嫉恨进谗，梁王下之狱将杀，故有狱中上书。 [[20]](#note-20)


<a id="event-21"></a>

21. **忠心未必见信。** 举荆轲与为秦谋长平的卫先生，以古人号称感天却不能取信君主比自己竭忠而受疑。 [[21]](#note-21)


<a id="event-22"></a>

22. **献玉获刑与忠臣之祸。** 借献璧者与李斯遭刑提醒梁王，箕子佯狂、接舆避世乃避祸，又感叹自己始能体会比干及子胥的遭际。 [[22]](#note-22)


<a id="event-23"></a>

23. **知己与相识久暂。** 以白头如新、倾盖如故说知人。樊於期、王奢以身报知己，苏秦、白圭得礼遇后，谗言也不能改君主的信任。 [[23]](#note-23)


<a id="event-24"></a>

24. **劝勿偏听而能兼观。** 列司马喜、范雎见嫉，百里奚、甯戚以才见用，孔墨遭谗等，告诫众口有销金蚀骨之力。秦用由余、齐用子臧，志合则可超越亲疏族属。 [[24]](#note-24)


<a id="event-25"></a>

25. **诚心礼士。** 表忠臣墓、封比干后代是尊贤善政。晋文、齐桓能用旧敌，成功在仁厚诚信。 [[25]](#note-25)


<a id="event-26"></a>

26. **既用其谋不应诛其人。** 列商鞅、文种功成而遇害，说明贤士避位。若君主诚心与人共穷达，士自然愿效力，荆轲、要离的故事不足尽其意。 [[26]](#note-26)


<a id="event-27"></a>

27. **明珠暗投与引见之道。** 珍珠凭空投向路人也会惹疑，弯木经引荐加工反可成器。寒士有才忠而无人引见，难达君前。 [[27]](#note-27)


<a id="event-28"></a>

28. **君主须在近臣圈外察士。** 以秦王信内侍而险遭荆轲行刺，周文王遇吕尚而用之，对照唯亲是信与独立取人。 [[28]](#note-28)


<a id="event-29"></a>

29. **勿使贤愚混处。** 若君主困于内廷谄言，令牛骥同槽，士人难以自展，正是鲍焦愤世的缘由。 [[29]](#note-29)


<a id="event-30"></a>

30. **有节士不屈从权势。** 曾子避胜母里、墨子避朝歌，都是避污之节。使清高士人靠取悦谄徒进身，只会令他们退处山林。 [[30]](#note-30)


<a id="event-31"></a>

31. **梁王释邹阳。** 梁王读书后立即释放邹阳，最后以为上客。 [[31]](#note-31)


<a id="event-32"></a>

32. **梁求嗣、修甬道与袁盎遇刺。** 羊胜、公孙诡谋梁王继汉，又求修直通长乐宫的甬道。袁盎反对，后为梁刺客所杀，汉遣使追案。邹阳因先反对梁王密谋而遭谗。 [[32]](#note-32)


<a id="event-33"></a>

33. **梁王请邹阳解罪。** 羊胜、公孙诡死后，梁王向邹阳谢过并赠金请他找化解之策。老谋士王先生举茅焦冒险谏秦始皇的故事说明困难，约他问计后回来。 [[33]](#note-33)


<a id="event-34"></a>

34. **王长君为梁案转圜。** 邹阳依指点入长安见王长君，警告若穷治梁案，太后将迁怨新贵，愿他以舜宽象、鲁季友缓追庆父劝帝宽亲。王长君进言，韩安国又见长公主，梁王终未被追罪。 [[34]](#note-34)


<a id="event-35"></a>

35. **为济北王请免。** 济北未实际出兵响应吴，战后仍惧获罪。公孙玃劝梁王以济北弱小、自守而牵制吴为由代陈于朝。济北王未被治罪，徙菑川。 [[35]](#note-35)


<a id="event-36"></a>

36. **枚乘小目。** 以下叙枚乘仕吴、梁，及其子枚皋。 [[36]](#note-36)


<a id="event-37"></a>

37. **枚乘为吴王郎中。** 淮阴人枚乘字叔，初任吴王郎中，闻吴王心怨谋反便上书。 [[37]](#note-37)


<a id="event-38"></a>

38. **护全宗国在民心。** 举舜、禹、汤、武以小地得天下，认为关键在王道和民心，请吴王容他直谏。 [[38]](#note-38)


<a id="event-39"></a>

39. **一线悬重可以改危为安。** 以细线悬重将断喻谋反危于累卵，断后无从挽回；改念犹如反掌，可以立即保全。 [[39]](#note-39)


<a id="event-40"></a>

40. **止事应断根源。** 畏影疾走反使踪迹更多，釜汤欲凉当除薪火，皆说要停止致祸之事。养由基百步射叶本领虽高，仍不能代替审察根本缘由。 [[40]](#note-40)


<a id="event-41"></a>

41. **祸福积渐，须防于初。** 滴水穿石、绳断木、幼木容易拔除。积德或背义，初不见变化而终有成败，请吴王早改。 [[41]](#note-41)


<a id="event-42"></a>

42. **枚乘等入梁。** 吴王不听，枚乘等离去从梁孝王游。 [[42]](#note-42)


<a id="event-43"></a>

43. **汉吴强弱不可同日而语。** 秦凭地利众势而兼六国。汉兼有秦与六国之地众，吴王不能凭谗臣之计逞强。 [[43]](#note-43)


<a id="event-44"></a>

44. **劝吴王知足归保国土。** 将吴攻汉比飞虫触群牛、腐肉就利剑，建议利用天子已诛晁错的台阶收兵。吴已有富库、粮仓、台池和险固之地，可以自保。 [[44]](#note-44)


<a id="event-45"></a>

45. **吴军已受制约。** 若再迟疑，朝廷将从江上袭都、断粮，梁又坚守；淮南、齐赵等未能成援，吴军虽出远地却受制营前。进兵方案多是劝说中的预判。 [[45]](#note-45)


<a id="event-46"></a>

46. **景帝召枚乘任弘农都尉。** 平乱后枚乘知名，景帝召而用为弘农都尉。枚乘乐与当世俊杰相游，不乐做郡吏，托病离职。 [[46]](#note-46)


<a id="event-47"></a>

47. **枚乘返梁及归淮阴。** 梁宾客多善赋，枚乘尤出众。梁孝王去世后，枚乘回故乡淮阴。 [[47]](#note-47)


<a id="event-48"></a>

48. **武帝征枚乘，病卒途中。** 武帝早闻其名，即位后遣安车蒲轮礼征，枚乘卒于途中。朝廷寻访其能文之子，后访得庶子枚皋。 [[48]](#note-48)


<a id="event-49"></a>

49. **枚皋小目。** 以下叙枚皋仕汉及辞赋。 [[49]](#note-49)


<a id="event-50"></a>

50. **枚皋从梁至京并受知遇。** 枚皋字少孺，母为枚乘小妻。在梁以书进官，后出使遭谗，家属被没官。逃到长安遇赦，上书自陈身世；因赋得赏，任郎使匈奴。以诙谐近幸，未如严助等得显官。 [[50]](#note-50)


<a id="event-51"></a>

51. **枚皋文学与侍从题材。** 枚皋随巡狩、封禅、塞河及游宴诸事，应诏作赋极快。相如作得慢而质精。枚皋自嫌像俳优，嘲东方朔亦自嘲；传称可读百二十篇，此外多嬉谑之作。 [[51]](#note-51)


<a id="event-52"></a>

52. **路温舒小目。** 以下叙路温舒学律及反苛狱。 [[52]](#note-52)


<a id="event-53"></a>

53. **牧羊读书后入官学律。** 路温舒字长君，钜鹿东里人。牧羊时截蒲写书，做狱吏后学律而擅断疑案，升决曹史，兼学《春秋》，举孝廉任县丞获罪而复为郡吏。 [[53]](#note-53)


<a id="event-54"></a>

54. **宣帝初路温舒上疏。** 昭帝元凤中廷尉光用温舒处理诏狱。昭帝死、昌邑王被废、宣帝初立，温舒上书尚德缓刑。 [[54]](#note-54)


<a id="event-55"></a>

55. **乱后兴治应施新恩。** 举齐桓、晋文、汉文帝祸后兴治、尊贤轻刑；再举霍光奉武帝遗命废无德之君而立宣帝，天命评价是上书立场。 [[55]](#note-55)


<a id="event-56"></a>

56. **秦狱吏遗弊和刑讯逼供。** 秦以狱吏为贵、恶谏而亡。温舒说法吏以苛刻为明，为自保而逼囚作供、锻炼案牍使上司深信；死者不能复生，断肢无从续接，故断狱尤须慎重。谚语以画地置狱、刻木为吏形容痛厌。 [[56]](#note-56)


<a id="event-57"></a>

57. **宽法刑、开言路。** 以凤凰择地、山川能纳污比君主容谏，请废诽谤之罚，开切谏之路，省法宽刑，革除苛狱。 [[57]](#note-57)


<a id="event-58"></a>

58. **宣帝嘉纳并迁职。** 温舒的建议得到宣帝赞许，迁广阳私府长。 [[58]](#note-58)


<a id="event-59"></a>

59. **请出使与临淮治绩。** 举文学高第任右扶风丞，主动请赴匈奴，经范明友、杜延年问状后暂回原官；后迁临淮太守，有异政，卒于任。传未给各事独立年次。 [[59]](#note-59)


<a id="event-60"></a>

60. **温舒历数之说及后代。** 从祖辈学历数天文，以“三七”预警；谷永亦据类似观念立说，王莽后来将之附会为代汉符命。子孙相继任牧守。 [[60]](#note-60)


<a id="event-61"></a>

61. **班固总赞贾邹枚路。** 用臧孙达有后比拟，以为贾山、邹阳、枚乘陈言正直而免祸；路温舒辞顺意诚，故其后代成世家。 [[61]](#note-61)

> 夫布衣韋帶之士，脩身於內，成名於外，而使後世不絕息。至秦則不然。貴爲天子，富有天下，賦斂重數，百姓任罷，赭衣半道，群盜滿山，使天下之人戴目而視，傾耳而聽。一夫大謼，天下嚮應者，陳勝是也。秦非徒如此也，起咸陽而西至雍，離宮三百，鍾鼓帷帳，不移而具。又爲阿房之殿，殿高數十仞，東西五里，南北千步，從車羅騎，四馬騖馳，旌旗不橈。爲宮室之麗至於此，使其後世曾不得聚廬而託處焉。爲馳道於天下，東窮燕齊，南極吳楚，江湖之上，瀕海之觀畢至。道廣五十步，三丈而樹，厚築其外，隱以金椎，樹以青松。爲馳道之麗至於此，使其後世曾不得邪徑而託足焉。死葬乎驪山，吏徒數十萬人，曠日十年。下徹三泉合采金石，冶銅錮其內，桼塗其外，被以珠玉，飾以翡翠，中成觀游，上成山林。爲葬薶之侈至於此，使其後世曾不得蓬顆蔽冢而託葬焉。秦以熊羆之力，虎狼之心，蠶食諸侯，并吞海內，而不篤禮義，故天殃已加矣。臣昧死以聞，願陛下少留意而詳擇其中。

### 5. 纳谏方可知过

[返回正文第5条](#event-5)

<a id="hs051-p005"></a>

**[《汉书·贾邹枚路传》P005](../../拆分史书/汉书/卷051.md#p005)** · [仓内TXT L7715—L7715](../../拆分史书/汉书/卷051.md#part-1-L7715)

> 臣聞忠臣之事君也，言切直則不用而身危，不切直則不可以明道，故切直之言，明主所欲急聞，忠臣之所以蒙死而竭知也。地之磽者，雖有善種，不能生焉；江皐河瀕，雖有惡種，無不猥大。昔者夏商之季世，雖關龍逢、箕子、比干之賢，身死亡而道不用。文王之時，豪俊之士皆得竭其智，芻蕘採薪之人皆得盡其力，此周之所以興也。故地之美者善養禾，君之仁者善養士。雷霆之所擊，無不摧折者；萬鈞之所壓，無不糜滅者。今人主之威，非特雷霆也；埶重，非特萬鈞也。開道而求諫，和顏色而受之，用其言而顯其身，士猶恐懼而不敢自盡，又迺況於縱欲恣行暴虐，惡聞其過乎！震之以威，壓之以重，則雖有堯舜之智，孟賁之勇，豈有不摧折者哉？如此，則人主不得聞其過失矣；弗聞，則社稷危矣。古者聖王之制，史在前書過失，工誦箴諫，瞽誦詩諫，公卿比諫，士傳言諫過，庶人謗於道，商旅議於市，然後君得聞其過失也。聞其過失而改之，見義而從之，所以永有天下也。天子之尊，四海之內，其義莫不爲臣。然而養三老於大學，親執醬而餽，執爵而酳，祝䭇在前，祝鯁在後，公卿奉杖，大夫進履，舉賢以自輔弼，求脩正之士使直諫。故以天子之尊，尊養三老，視孝也；立輔弼之臣者，恐驕也；置直諫之士者，恐不得聞其過也；學問至於芻蕘者，求善無饜也；商人庶人誹謗己而改之，從善無不聽也。

> 昔者，秦政力并萬國，富有天下，破六國以爲郡縣，築長城以爲關塞。秦地之固，大小之埶，輕重之權，其與一家之富，一夫之彊，胡可勝計也！然而兵破於陳涉，地奪於劉氏者，何也？秦王貪狼暴虐，殘賊天下，窮困萬民，以適其欲也。昔者，周蓋千八百國，以九州之民養千八百國之君，用民之力不過歲三日，什一而籍，君有餘財，民有餘力，而頌聲作。秦皇帝以千八百國之民自養，力罷不能勝其役，財盡不能勝其求。一君之身耳，所以自養者馳騁弋獵之娛，天下弗能供也。勞罷者不得休息，飢寒者不得衣食，亡罪而死刑者無所告訴，人與之爲怨，家與之爲讎，故天下壞也。秦皇帝身在之時，天下已壞矣，而弗自知也。秦皇帝東巡狩，至會稽、琅邪，刻石著其功，自以爲過堯舜統；縣石鑄鍾虡，篩土築阿房之宮，自以爲萬世有天下也。古者聖王作謚，三四十世耳，雖堯舜禹湯文武絫世廣德以爲子孫基業，無過二三十世者也。秦皇帝曰死而以謚法，是父子名號有時相襲也，以一至萬，則世世不相復也，故死而號曰始皇帝，其次曰二世皇帝者，欲以一至萬也。秦皇帝計其功德，度其後嗣，世世無窮，然身死纔數月耳，天下四面而攻之，宗廟滅絕矣。

> 秦皇帝居滅絕之中而自不知者何也？天下莫敢告也。其所以莫敢告者何也？亡養老之義，亡輔弼之臣，亡進諫之士，縱恣行誅，退誹謗之人，殺直諫之士，是以道諛媮合苟容，比其德則賢於堯舜，課其功則賢於湯武，天下已潰而莫之告也。詩曰：「匪言不能，胡此畏忌，聽言則對，譖言則退。」此之謂也。又曰：「濟濟多士，文王以寧。」天下未甞亡士也，然而文王獨言以寧者何也？文王好仁則仁興，得士而敬之則士用，用之有禮義。

### 56. 秦狱吏遗弊和刑讯逼供

[返回正文第56条](#event-56)

<a id="hs051-p061"></a>

**[《汉书·贾邹枚路传》P061](../../拆分史书/汉书/卷051.md#p061)** · [仓内TXT L7771—L7771](../../拆分史书/汉书/卷051.md#part-1-L7771)

> 臣聞秦有十失，其一尚存，治獄之吏是也。秦之時，羞文學，好武勇，賤仁義之士，貴治獄之吏；正言者謂之誹謗，遏過者謂之妖言。故盛服先生不用於世，忠良切言皆鬱於胷，譽諛之聲日滿於耳；虛美熏心，實禍蔽塞。此乃秦之所以亡天下也。方今天下賴陛下恩厚，亡金革之危，飢寒之患，父子夫妻戮力安家，然太平未洽者，獄亂之也。夫獄者，天下之大命也，死者不可復生，𢇍者不可復屬。書曰：「與其殺不辜，寧失不經。」今治獄吏則不然，上下相敺，以刻爲明；深者獲公名，平者多後患。故治獄之吏皆欲人死，非憎人也，自安之道在人之死。是以死人之血流離於市，被刑之徒比肩而立，大辟之計歲以萬數，此仁聖之所以傷也。太平之未洽，凡以此也。夫人情安則樂生，痛則思死。棰楚之下，何求而不得？故囚人不勝痛，則飾辭以視之；吏治者利其然，則指道以明之；上奏畏卻，則鍛練而周內之。蓋奏當之成，雖咎繇聽之，猶以爲死有餘辜。何則？成練者衆，文致之罪明也。是以獄吏專爲深刻，殘賊而亡極，媮爲一切，不顧國患，此世之大賊也。故俗語曰：「畫地爲獄，議不入；刻木爲吏，期不對。」此皆疾吏之風，悲痛之辭也。故天下之患，莫深於獄；敗法亂正，離親塞道，莫甚乎治獄之吏。此所謂一尚存者也。

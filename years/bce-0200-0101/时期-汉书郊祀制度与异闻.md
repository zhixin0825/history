# 汉书郊祀制度与异闻

[本世纪目录](README.md) · [全部世纪](../README.md)

此处连读各志的制度沿革、学术分类与未详年次的史事；整段原文和已系年节录均可由卷内读本查阅。


<a id="event-1"></a>

1. **祀、巫祝与社稷起源。** 祭祀用来事祖示孝、敬神通明。男性称觋，女性称巫，祝熟悉山川仪节，宗掌牲器坛场、族姓；官有分工，以防亵慢。少昊以后神民无分，颛顼复以重司天、黎司地。句龙以治水土为社神，烈山氏子柱以殖谷为稷神，均是古传。 [[1]](#note-1)


<a id="event-2"></a>

2. **虞书所载巡狩和五岳。** 舜校天象和历日，祭上帝、六宗、山川、群神，颁瑞给四岳及诸牧。四方巡狩分别以二、五、八、十一月为次，并统一时日、度量衡、五礼音乐，定五年一巡。这里是志引《虞书》的制度叙述。 [[2]](#note-2)


<a id="event-3"></a>

3. **夏商求神、周礼与祀权。** 孔甲好鬼神反失所祐；商汤更定社稷，太戊、武丁遇桑谷、雉鸣之异而修德，后王怠慢。周公辅成王制礼，后稷配天、文王配上帝；天子祀天下，诸侯祀封内，大夫有五祀、士庶仅祀先亲。各自祀权防止任意逾礼。 [[3]](#note-3)


<a id="event-4"></a>

4. **秦襄公作西畤。** 幽王败而平王东徙，秦助周后受诸侯之列；居西自认祀少昊，在西畤以三牲祭白帝。 [[4]](#note-4)


<a id="event-5"></a>

5. **秦文公鄜畤与陈宝祠。** 文公猎汧渭后择居。TXT段间有“文公／薨黃蛇”疑字，仍可辨史敦以黄蛇为征，因建鄜畤。另传雍有早期畤，不见于经，保留存疑。陈仓陈宝祭所的光、鸣、雉和石为志书传闻。 [[5]](#note-5)


<a id="event-6"></a>

6. **秦都雍及德、宣二公之祀。** 德公卜都雍，扩大祭祀，鄜畤用众多牲牢，作伏祠并磔狗祓灾。宣公随后在渭南作密畤祠青帝；这些祠各有本纪或年表可互见。 [[6]](#note-6)


<a id="event-7"></a>

7. **穆公之梦、管仲阻封禅、秦纳夷吾。** 志称穆公病后自述奉上帝命平晋乱。齐桓公在葵丘会盟后以九合诸侯自许，管仲列传说中的封禅诸王与天瑞礼物，指出当下无祥瑞，桓公罢议。秦纳夷吾及多次干预晋国是另事，与会盟可能异年。 [[7]](#note-7)


<a id="event-8"></a>

8. **苌弘、季氏与秦畤沿革。** 周灵王时苌弘尝托物怪召诸侯，周终衰、苌弘后被晋人杀。孔子批评鲁季氏越礼祀泰山。秦灵公立吴阳上下畤分别祭黄帝、炎帝，獻公信雨金之瑞立栎阳畦畤；太史儋合离之说保留作旧传。 [[8]](#note-8)


<a id="event-9"></a>

9. **九鼎异说与周祀终止。** 志并录九鼎入秦、早在周显王时沉泗两说。赧王死、秦灭东周与秦统一各属不同年份，九鼎去向不宜从其一断成确证。 [[9]](#note-9)


<a id="event-10"></a>

10. **秦以水德定正朔服色。** 秦人以黄帝、夏、商、周各属一德的传说论秦当水德。故更河为德水，岁首十月、色黑、数六、音大吕、治尚法，皆为该政权的制度和自我解释。 [[10]](#note-10)


<a id="event-11"></a>

11. **始皇封禅与暴风雨。** 始皇东巡祠峄山，询齐鲁儒生，又嫌议论不一，黜儒后南登泰山立石，沿北道下，禅梁父。礼参雍上帝祀，所藏文书保密；途中遇风雨、儒生讥评另属叙事。 [[11]](#note-11)


<a id="event-12"></a>

12. **齐地八神祠。** 东巡沿海行礼，又求仙。八神为天、地、兵、阴、阳、月、日、四时主，各有祭所与牲具。一说太公开设，传文亦说起始不明。 [[12]](#note-12)


<a id="event-13"></a>

13. **五德和三神山传说。** 邹衍用阴阳五德显于诸侯，秦采用其说；燕齐方士托形解、鬼神而起。又称齐威宣、燕昭遣人入海求蓬莱、方丈、瀛洲。有不死药、金银宫阙与风浪阻船等神话，非已抵达的实录。 [[13]](#note-13)


<a id="event-14"></a>

14. **秦海上求仙、二世巡礼及儒生批评。** 始皇遣童男女入海，次年复东游，后到碣石查问方士，最后经会稽、沿海而死沙丘。秦二世复东巡并附刻前刻，秦末叛起后被弑。儒者以风雨讥始皇封禅，末段是史论；“後三年”“後五年”须与《秦始皇本纪》所列行程校读。 [[14]](#note-14)


<a id="event-15"></a>

15. **秦统一后的山川与诸神祀典。** 迁都地域变化使五岳、四渎相对在东。崤东、华西名山川祭时、祭物各有规定，咸阳近水可以比祀；雍诸星与风雨众祠、陈宝、各畤所用牲色木制车马、三年郊祭及远方民祀各别。秘祝被解释为遇灾移过于下。 [[15]](#note-15)


<a id="event-16"></a>

16. **高祖起兵的祭仪与传说。** 斩蛇传说以赤、白帝子解释所见；丰沛起兵祭枌榆社、蚩尤、以牲血衅鼓旗，十月至霸上与正式受汉王封是相接前后，汉仍十月为岁首而旗色尚赤。 [[16]](#note-16)


<a id="event-17"></a>

17. **汉立北畤、承秦祀法、设长安巫祠。** 刘邦认为秦祭四帝应补第五，设黑帝北畤，复秦祠官太祝太宰，令县置公社，旧山川依时祭。统一后修枌榆社、置长安蚩尤与各地巫，各有负责神祠；秦中所祭为二世。 [[17]](#note-17)


<a id="event-18"></a>

18. **灵星、县稷与里社。** 借周祀后稷故事扩地方灵星祀，用牛；高祖十年又准县于春二月及腊以羊猪祭稷，民里社自酌，两种制度不混。 [[18]](#note-18)


<a id="event-19"></a>

19. **文帝除秘祝与接管山川常祀。** 文帝十三年废移过的秘祝。齐、淮南废国后，原诸侯辖内名山川由中央太祝按时致礼；地方以后复立王时不能只凭本志倒推祭权。岁熟后增雍畤车乘、河水诸祀玉、坛具。 [[19]](#note-19)


<a id="event-20"></a>

20. **土德之议与文帝亲郊雍。** 公孙臣以秦水汉土、黄龙为祥请改历服，张苍则持水德，初罢其说。成纪见黄龙报告后召公孙臣为博士，本文接述请定夏郊与文帝四月亲祭五畤。 [[20]](#note-20)


<a id="event-21"></a>

21. **新垣平营渭阳五庙与长门祭坛。** 新垣平称长安东北有五色神气，建议渭阳建五帝一屋、各有殿门之庙。次年帝亲郊，赏其财并令博士摘《六经》议《王制》。长门因“若见五人”设五帝坛，仍属祭祀传述。 [[21]](#note-21)


<a id="event-22"></a>

22. **玉杯、后元改年及新垣平伏诛。** 新垣平安排献刻延寿杯、称日再中，应验后改以后元元年纪年并大酺，又想借河通泗求周鼎。遭告发后被诛族，文帝不再亲郊；次年边患、后续歉收另记，景帝祠祀多循旧未增。 [[22]](#note-22)


<a id="event-23"></a>

23. **武帝建元礼议、初郊雍与神君。** 赵绾王臧拟明堂、巡狩、改历服，窦太后反对，二人被按自杀，所议多废；太后死后再征士、亲郊。另述乳死女子降神，其祭从民间入宫，传称有声无形。 [[23]](#note-23)


<a id="event-24"></a>

24. **李少君及亳忌的泰一祀。** 少君自称老而善方，以旧铜器等故事获信，主张祠灶、炼金、用金器益寿并求蓬莱；其死后武帝仍信为化去。亳人谬忌提泰一与五帝主从及八通神路，长安东南设祠，后加三一与诸方士祠；与元鼎年间甘泉亲祠分读。 [[24]](#note-24)


<a id="event-25"></a>

25. **雍郊获兽与五岳入汉郡。** 有司以一角兽为麟荐雍，赐白金。濟北王献泰山近邑并获补地，常山国因王案撤而留真定奉祀，国郡疆域调整使五岳皆在中央所领郡。 [[25]](#note-25)


<a id="event-26"></a>

26. **少翁受宠伏诛、寿宫与三元名称。** 少翁号文成将军，传自帷中招亡宠姬和灶鬼，以象神车服与甘泉台室为手段，终因伪造牛腹帛书被诛。少翁所招亡人和事年有异，后文“文成死明年”不得机械倒排。武帝病后从上郡巫言置寿宫神君、记录“画法”。年号建、光、狩的解释是有司追述瑞应。 [[26]](#note-26)


<a id="event-27"></a>

27. **汾阴初立后土祠与访周后。** 武帝认为所亲郊天而不祀地不合礼，司马谈、宽舒议圆丘五坛、黄犊瘗祭和黄衣。汾阴立祠、帝亲拜，随后至荥阳经洛阳，诏封周后奉祀。与翌年后土祠旁得鼎有别。 [[27]](#note-27)


<a id="event-28"></a>

28. **栾大通过荐举受封。** 胶东王后经乐成侯荐同少翁师的栾大。栾大以炼金、塞河、仙药诱人，求贵待、亲属和信印，先演相击之棋。武帝授将军多号和六印、封乐通侯、妻卫长公主，助长海滨求仙之风。 [[28]](#note-28)


<a id="event-29"></a>

29. **汾阴得鼎、求蓬莱与泰一议。** 汾阴巫锦得无铭异鼎，官吏查问后献，武帝对祥瑞仍问缘由，群臣用泰帝、黄帝、禹九鼎传说议神鼎，最后收藏。海滨方士又求望气；秋郊时有人请让皇帝亲郊泰一。 [[29]](#note-29)


<a id="event-30"></a>

30. **公孙卿以宝鼎推冬至与封禅。** 公孙卿由私路进鼎札，以朔日冬至为历数回返，称申公所授黄帝封禅升天故事可比武帝，并叙鼎湖、乌号的传说由来。他获拜郎候神，此神话与可纪年任命各自分读。 [[30]](#note-30)


<a id="event-31"></a>

31. **甘泉坛式与首次亲郊泰一。** 宽舒仿亳忌祠坛立三陔，五帝坛环列，牲器、日月及祝宰服色各有所别。十一月辛巳朔冬至武帝亲郊泰一，同时保留朝日夕月之礼；群臣以光气为祥，议太祝常领并定间年亲郊。 [[31]](#note-31)


<a id="event-32"></a>

32. **伐南越灵旗、栾大被诛和郊乐。** 南征前告泰一，以日月北斗龙饰灵旗，太史指所伐国；栾大言见其师不验被诛。次冬公孙卿以缑氏仙迹请求等待，郡国修路宫祠。灭南越后李延年因音乐进见，公卿议郊祭用乐舞。 [[32]](#note-32)


<a id="event-33"></a>

33. **北巡示兵、桥山祭祀及议礼。** 先北巡朔方勒兵，祭桥山黄帝冢，释兵归甘泉类祭泰一；所谓衣冠冢系答语。群儒采《尚书》等而不得封禅详仪，丁公、方士提供异议，武帝终于罢徐偃、周霸等，自定礼。 [[33]](#note-33)


<a id="event-34"></a>

34. **中岳、东海和初行泰山封禅。** 先到缑氏太室，有万岁声传闻，增祠禁山木，立泰山石；续东巡祀八神，方士报告巨迹与老者。四月先祭梁父地主，按仪射牛，在泰山东下封土藏玉牒，皇帝与奉车子侯登顶行密仪，次日肃然山禅祀后土。 [[34]](#note-34)


<a id="event-35"></a>

35. **封后明堂受贺、改元、海巡与星变。** 封禅后坐原有明堂，宣布元封，令诸侯治邸。武帝再到海上，奉车子侯病卒，继续沿边返甘泉。东井、三能见彗星，官以之解释帝德，是当时说法。 [[35]](#note-35)


<a id="event-36"></a>

36. **次年祭雍、东莱候神、瓠子塞决及越祠。** 次冬郊雍后拜泰一，祝辞有德星等。来春再访东莱，无所见；旱时祷万里沙，返回亲临瓠子塞河。越巫祠与鸡卜由勇之以越俗说服武帝，提及两越都已平，仅能作时间上限线索。 [[36]](#note-36)


<a id="event-37"></a>

37. **甘泉起馆通天、报芝与尊祠灵星。** 公孙卿以仙喜住楼，促建长安与甘泉诸馆、通天台。房中生芝与塞河相联系，其后伐朝鲜又旱，以黄帝“乾封”解释，诏祠灵星。“乾封三年”不是元封纪年。 [[37]](#note-37)


<a id="event-38"></a>

38. **回中巡视、修封与明堂的营建和使用。** 武帝郊雍、开回中道、出萧关祭后土。次次南巡经灊山号南岳，渡江经名山水，四月至奉高修封。公玉带献图后汶上营明堂在元封二年，元封五年修封用之；本段先述工程，后说实际祭礼，不以相邻倒系一时。 [[38]](#note-38)


<a id="event-39"></a>

39. **太初元年明堂祭、柏梁灾与改历。** 明堂冬至祠上帝、柏梁灾、高里禅礼、求仙等相次，火灾后甘泉受计，依建议兴建建章宫、作太液池与神明台。夏行太初历，以正月为首、色黄、五字印章；同年出兵大宛及蝗灾，方祭诅敌反映当时风俗。 [[39]](#note-39)


<a id="event-40"></a>

40. **雍祠换木马、东巡与周期修封。** 雍畤增熟牲牢，平时改木马、亲临仍可用真马。巡海求仙无效，仍按五城十二楼之说建候神馆称“明年”。东泰山简礼而不封，回泰山修礼加石闾禅；其后再修封并祭恒山。所谓十三岁遍五岳四渎为过程总说。 [[40]](#note-40)


<a id="event-41"></a>

41. **后期修封、外祀与祭官制度。** 相隔五年的泰山修封、琅邪及海滨祈神，附雍县声光与陨石之说。志称方士终无验，武帝未尽断绝。六类祠由太祝岁领，路经之祀与方士私祠另列。甘泉后土与泰山制度频率不同，昭帝未亲巡祭。 [[41]](#note-41)


<a id="event-42"></a>

42. **宣帝尊世宗与亲祀之议。** 即位数年后追尊武帝庙为世宗，巡视所至郡国设庙；白鹤五色雁、神光钟声等记为祥瑞诏由。霍光辅政时帝较少出祭，后诏陈十余年未亲奉上帝，表明拟恢复。 [[42]](#note-42)


<a id="event-43"></a>

43. **宣帝祭泰畤、后土及山川常礼。** 宣帝正月到甘泉，三月到河东祠后土，以神爵祥瑞改元，并令四时祭江海雒水。各岳、渎祭所与频次不同，派持节使者礼祭。 [[43]](#note-43)


<a id="event-44"></a>

44. **宣帝诸祠、方术求神与美阳鼎辨。** 南郡白虎、四宝及多处山川星辰皆入祀；王褒奉使求金马碧鸡。刘更生献炼金秘方，尝试失败获论，张敞劝斥方士。美阳鼎依铭文判为周王赐臣而非无铭大鼎之类，帝同意不荐宗庙。 [[44]](#note-44)


<a id="event-45"></a>

45. **宣帝神爵至黄龙年的巡祀与祥瑞。** 详叙祋祤凤凰、玉宝、步寿宫，后又有甘露、凤凰、上林殿，与五凤、甘露、黄龙诸年郊祀及两次甘泉朝单于。须依《宣帝纪》逐条，与志用“间岁”相对年相校，不将所有祥瑞列作一次。 [[45]](#note-45)


<a id="event-46"></a>

46. **元帝礼制沿旧至庙议。** 数次亲祭泰畤、后土和雍畤，过境赐爵牛酒、免租赦罪。贡禹倡议罢不合古礼的庙，韦玄成议罢部分郡国庙、园寝，元帝病时又恢复。后至哀、平仍反复。 [[46]](#note-46)


<a id="event-47"></a>

47. **匡衡、张谭议南北郊并撤旧坛。** 他们以祭天南、祭地北和天随王都解释移甘泉、汾阴于长安，也要减远途危险、徭费。八人愿沿旧，五十人引经赞成，皇帝裁从。之后匡衡主张先质后文，停紫坛华饰、女乐与石坛等，又请罢雍畤和陈宝。 [[47]](#note-47)


<a id="event-48"></a>

48. **成帝亲祀南郊与清理杂祠。** 首次南郊赦有关县和京师官府耐罪囚徒。所审六百八十三处留二百零八、罢四百七十五，另列雍诸旧祠与汉初以来多朝所立，方士使者等七十余人遣还。 [[48]](#note-48)


<a id="event-49"></a>

49. **匡衡免与刘向主张守祖祠。** 匡衡因事免，民间争议兴。初迁郊时甘泉大风损竹宫和树木一事，志在此追叙；刘向举陈宝历代现身次数与旧祠惯例，认为不能以有争议的经说废祖制。 [[49]](#note-49)


<a id="event-50"></a>

50. **成帝因无嗣复旧祀、谷永杜邺反对。** 王太后以未见皇孙而恢复甘泉、汾阴、雍及陈宝诸祀。谷永指出长生方伪、以各朝故事比拟，皇帝称许；杜邺则从俭祭、阴阳方位和巡祀风险出发，建议复长安南北郊，两人的目标和论据各有侧重。 [[50]](#note-50)


<a id="event-51"></a>

51. **成、哀间南北郊的往复。** 成帝死后皇太后诏恢复长安南北郊。哀帝生病，广征方士、恢复七百余神祠；后又借太皇太后诏恢复甘泉及汾阴，使有司代祭。L5257“明年”按《哀帝纪》建平三年校，不取即位次年。 [[51]](#note-51)


<a id="event-52"></a>

52. **平帝元始五年议郊，天地合离祭祀。** 王莽引孝配天、祖妣配祀及前朝多次迁郊，奏复长安南北郊；宣称孟春合祭、冬至夏至分祀，定各帝后、用牲器乐与朝日夕月的规矩。奏中具体回顾年次与前文各异，作为回顾证词另记。 [[52]](#note-52)


<a id="event-53"></a>

53. **六宗、五方群神与官社官稷。** 王莽否定六宗为天地四方之间的解释，取易卦日月雷风山泽，按五方列帝神、星象、风雨，改地祇等名并建兆畤。又主张立官稷，禹配官社、后稷配官稷，徐州按岁进五色土；二议接元始改礼，独立具体日期欠明。 [[53]](#note-53)


<a id="event-54"></a>

54. **新莽方术祭祀与班氏总赞。** 王莽称帝后二年，从苏乐建八风台、按五方种谷求仙；末年多至千余祠，牲物不足以鸡犬替换。班氏赞述汉初制礼、文武正朔服色争议，比较五德相胜与相生，末赞谷永反对方术祠祭。 [[54]](#note-54)

> 齊人公孫卿曰：「今年得寶鼎，其冬辛巳朔旦冬至，與黃帝時等。」卿有札書曰：「黃帝得寶鼎冕候，問於鬼臾區，鬼臾區對曰：『黃帝得寶鼎神策，是歲己酉朔旦冬至，得天之紀，終而復始。』於是黃帝迎日推策，後率二十歲復朔旦冬至，凡二十推，三百八十年，黃帝僊登于天。」卿因所忠欲奏之。所忠視其書不經，疑其妄言，謝曰：「寶鼎事已決矣。尚何以為！」卿因嬖人奏之。上大說，乃召問卿。對曰：「受此書申公，申公已死。」上曰：「申公何人也？」卿曰：「齊人，與安期生通，受黃帝言，無書，獨有此鼎書。曰『漢興復當黃帝之時。』曰『漢之聖者，在高祖之孫且曾孫也。寶鼎出而與神通，封禪。封禪七十二王，唯黃帝得上泰山封。』申公曰：『漢帝亦當上封禪，封禪則能僊登天矣。黃帝萬諸侯，而神靈之封君七千。天下名山八，而三在蠻夷，五在中國。中國華山、首山、太室山、泰山、東萊山，此五山黃帝之所常游，與神會。黃帝且戰且學僊，患百姓非其道，乃斷斬非鬼神者。百餘歲然後得與神通。黃帝郊雍上帝，宿三月。鬼臾區號大鴻，死葬雍，故鴻冢是也。其後黃帝接萬靈明庭。明庭者，甘泉也。所謂寒門者，谷口也。黃帝采首山銅，鑄鼎於荊山下。鼎既成，有龍垂胡敘下迎黃帝。黃帝上騎，群臣後宮從上龍七十餘人，龍乃去。餘小臣不得上，乃悉持龍敘，龍敘拔，墯，墯黃帝之弓。百姓卬望黃帝既上天，乃抱其弓與龍敘號，故後世因名其處曰鼎湖，其弓曰烏號。』」於是天子曰：「嗟乎！誠得如黃帝，吾視去妻子如脫屣耳。」拜卿為郎，使東候神於太室。

# 汉书郦生陆贾朱建刘敬叔孙通的论议

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **狂生郦食其择主。** 郦食其为陈留高阳人，好读书而穷困，只做里门看守，当地贤豪却不敢使唤他。陈胜、项梁等起时，各路过高阳的将领多拘泥小礼、自以为是，他便藏而不见。听说沛公轻慢人却有大略，他托同里的骑士自荐，不因刘邦侮辱儒冠而退却。 [[1]](#note-1)


<a id="event-2"></a>

2. **郦疥因父功得封。** 郦商出兵击英布有功，刘邦评功又忆郦食其，封多次领军的儿子郦疥为高梁侯，后改食武阳。郦遂继，第三世郦平获罪除国。 [[2]](#note-2)


<a id="event-3"></a>

3. **陆贾从高祖出使诸侯。** 分传题陆贾。他是楚人，作为宾客从高祖定天下，以口才著名，常受命出使。 [[3]](#note-3)


<a id="event-4"></a>

4. **马背得天下须用文德固守。** 陆贾常引诗书，刘邦说江山由马上取得。陆贾指出用武得天下仍须用文德守成，举夫差、智伯穷武亡国与秦任刑法不变为鉴。刘邦命他论秦所以亡、汉所以得以及古代成败，他著十二篇，每篇均被称善，传为《新语》。 [[4]](#note-4)


<a id="event-5"></a>

5. **陆贾避吕氏退居好畤。** 吕太后意欲封吕氏为王，忌惮能言之人，陆贾托病归好畤。将越地赠物变卖，五子每人给二百金谋生，自己车马、侍从、乐器相随在各处轮住，留给身亡时所住之家车骑、宝剑等，免得长久拖累儿子。 [[5]](#note-5)


<a id="event-6"></a>

6. **陆贾促将相合作并再使南越。** 吕氏专权，陆贾见忧虑的右相陈平，指出治时重相、危时重将，两者协作可止权力分裂，劝其交好太尉周勃。两人交赠宴饮、联合削弱吕氏，后来诛吕、立文帝，陆贾有功，并受陈平钱、车、奴婢相赠。文帝又遣陆贾使南越，劝赵佗去帝王仪制，称制改同诸侯；详见《南越传》，陆贾寿终。 [[6]](#note-6)


<a id="event-7"></a>

7. **朱建劝英布勿叛。** 分传题朱建。他是楚人，先做英布相，获罪离职后再事英布，劝英布不要反。英布听梁父侯的计策而反，败死后高帝知朱建曾谏，给平原君号、迁家长安。 [[7]](#note-7)


<a id="event-8"></a>

8. **朱建拒谒辟阳侯、后经陆贾相助救他。** 朱建善辩而廉直，本不愿从亲吕后的辟阳侯审食其。母亲死后无钱办丧，陆贾劝审食其厚赙，列侯亦相继送礼。惠帝欲杀审食其时，朱建拒绝临狱相见，转而说惠帝幸臣闳籍孺，说明若不求释便可能被吕后报复，闳籍孺由此说动惠帝。诸吕覆灭时审食其仍免诛，传归其全于陆贾、朱建谋画。 [[8]](#note-8)


<a id="event-9"></a>

9. **审食其被杀，朱建以死止祸。** 文帝时淮南王刘长杀审食其。文帝欲调查朱建为审食其谋划的事，朱建以为自死可以免祸及诸子，自刎。文帝闻之惜，称本无杀意，任其子中大夫。其子出使匈奴因单于失礼而骂，死在匈奴。 [[9]](#note-9)


<a id="event-10"></a>

10. **娄敬劝定都关中。** 分传题娄敬，齐人。汉五年赴陇西戍守经洛阳，由虞将军引见，依原服而不换华服。娄敬说明周先祖数代累德才居天下中心，衰世失势难制诸侯；汉取天下用兵多、伤亡大，情势有别。宜都山河四塞而田肥的关中，可保根本并制东方。群臣因周享国久而倾向洛阳，经张良赞成都关中，刘邦当日西行，赐娄敬刘姓，任郎中、号奉春君。原文有关公刘、太王的三个方框仍保留。 [[10]](#note-10)


<a id="event-11"></a>

11. **刘敬识伏兵，白登围解后获封。** 韩王信反并通匈奴，高帝遣使刺探，多信匈奴显露的老弱。刘敬指其示弱系诱兵，汉已过句注，高帝怒将他拘广武。果在平城白登被围七天，脱围后谢罪赦刘敬，惩此前说可进兵的使者，令刘敬为关内侯、号建信侯，食二千户。 [[11]](#note-11)


<a id="event-12"></a>

12. **叔孙通秦廷答陈胜之变。** 分传题为叔孙通，薛人，以文学征待诏博士。陈胜起，秦二世问诸生，言反请发兵者触怒帝，叔孙通假称只几名盗贼、郡县足制，二世反而赐物任博士。他回去告诉同列险些落虎口，逃回已归楚的薛地。 [[12]](#note-12)


<a id="event-13"></a>

13. **叔孙通由楚降汉，先荐武士。** 项梁到薛，叔孙通从他。项梁败死，转从怀王；怀王徙长沙后留事项王。汉二年刘邦入彭城，他归汉，换去刘邦厌恶的儒服，穿楚短衣。弟子不满他只举荐勇士，他解释此时争天下需能斩将夺旗者，安定后还会荐诸生。他受博士号稷嗣君。 [[13]](#note-13)


<a id="event-14"></a>

14. **建议制朝仪，召鲁儒习练。** 叔孙通参与皇帝即位仪式。秦仪废后群臣饮争、击柱，叔孙通以儒者可守成、礼随人情与时代调整，建议参采古礼和秦仪，使皇帝容易施行。两鲁生以治平不足、其事过诸主而拒，叔孙通仍带三十余鲁生及从学者在野外用绳茅临时标示礼位，练习月余，刘邦看罢令群臣演习以待十月。 [[14]](#note-14)


<a id="event-15"></a>

15. **叔孙通任太傅，直谏勿换太子。** 九年叔孙通为太子太傅；高帝欲以刘如意易储，他用晋献公立奚齐、秦不早定扶苏而灭亡为鉴，称刘盈仁孝、吕后共艰难，愿先死谏。高帝说是玩笑，叔孙通说储位是天下根本不可戏。随后高帝又见张良招来的四皓随太子入见，遂无易储之意。 [[15]](#note-15)


<a id="event-16"></a>

16. **由复道建原庙，并举樱桃荐新。** 惠帝即位，叔孙通复任奉常，定园陵宗庙仪。皇帝常东朝长乐宫扰民，筑复道，叔孙通说不可从高帝祭道上方跨过，路既为百姓所见，建议在渭北增建原庙并以先帝衣冠按月游，惠帝下诏照办。叔孙通又以古有春季尝新果，请取熟樱桃献庙，传称诸果荐新由此兴。 [[16]](#note-16)


<a id="event-17"></a>

17. **传赞五士的得失。** 赞说高祖用兵定天下也仰赖文士的才识。刘敬自役夫成安都之功，叔孙通由军中立一代礼；郦食其待明主仍免不了鼎镬，朱建曾拒审食其却未坚持原则、以身殉之。陆贾退避诸吕、联系平勃，于国有功且保身名，班固最推重他。 [[17]](#note-17)

> 漢七年，韓王信反，高帝自往擊。至晉陽，聞信與匈奴欲擊漢，上大怒，使人使匈奴。匈奴匿其壯士肥牛馬，徒見其老弱及羸畜。使者十蜚來，皆言匈奴易擊。上使劉敬復往使匈奴，還報曰：「兩國相擊，此宜誇矜見所長。今臣往，徒見羸胔老弱，此必欲見短，伏奇兵以爭利。愚以為匈奴不可擊也。」是時漢兵以逾句注，三十餘萬眾，兵已業行。上怒，罵敬曰：「齊虜！以舌得官，乃今妄言沮吾軍！」械系敬廣武。遂往，至平城，匈奴果出奇兵圍高帝白登，七日然後得解。高帝至廣武，赦敬，曰：「吾不用公言，以困平城。吾已斬先使十輩言可擊者矣。」乃封敬二千戶，為關內侯，號建信侯。

> 九年，高帝徙通為太子太傅。十二年，高帝欲以趙王如意易太子，通諫曰：「昔者晉獻公以驪姬故，廢太子，立奚齊，晉國亂者數十年，為天下笑。秦以不早定扶蘇，故亥詐立，自使滅祀，此陛下所親見。今太子仁孝，天下皆聞之；呂後與陛下攻苦食啖，其可背哉！陛下必欲廢適而立少，臣願先伏誅，以頸血污地。」高帝曰：「公罷矣，吾特戲耳。」通曰：「太子天下本，本壹搖天下震動，奈何以天下戲！」高帝曰：「吾聽公。」及上置酒，見留侯所招客從太子入見，上遂無易太子志矣。

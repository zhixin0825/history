# 汉书酷吏治狱与地方治理

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **法令与教化。** 篇首引孔子、老子批评严密法令治标，仍指出危乱中刚健严厉的官员有应急之用，最终以少讼为治事目标。 [[1]](#note-1)


<a id="event-2"></a>

2. **从汉初宽简到晁错被杀。** 开国宽法而民安，吕后时侯封凌辱宗室功臣，吕氏败后侯封家族被诛；景帝用晁错，七国起兵以错为名，晁错最终被处死。 [[2]](#note-2)


<a id="event-3"></a>

3. **郅都分传。** 小题引入郅都。 [[3]](#note-3)


<a id="event-4"></a>

4. **郅都谏阻景帝亲救贾姬。** 野猪进入贾姬所在厕所，景帝欲亲救。郅都以宗庙太后所系为重劝阻，贾姬无伤，景帝和太后均赐金给郅都。 [[4]](#note-4)


<a id="event-5"></a>

5. **郅都惩办济南豪姓。** 郅都任济南守，杀瞷氏首恶以压制其三百余家宗族的势力，一郡秩序得治，周边守令也忌其威。 [[5]](#note-5)


<a id="event-6"></a>

6. **郅都不收私信和馈赠。** 传赞郅都勇毅公廉，不开私书，不收馈赠或听私请，自认应舍家庭而尽官守。 [[6]](#note-6)


<a id="event-7"></a>

7. **临江王案与郅都之死。** 郅都不让刘荣得刀笔，窦婴私给，刘荣留信自杀。窦太后使郅都免官；景帝再用为雁门太守，郅都曾为匈奴所惮，最终太后仍以刘荣事责之，郅都被诛。 [[7]](#note-7)


<a id="event-8"></a>

8. **甯成治宗室。** 甯成少吏时凌长官，掌下属严急。为济南都尉能抗郅都，二人相知；郅都死后甯成任中尉，严治宗室，廉洁不及郅都。 [[8]](#note-8)


<a id="event-9"></a>

9. **甯成坐法而归为豪强。** 武帝初甯成任内史，因外戚揭短受髡钳，作伪传出关。归乡借田转租役使众人，遇赦后积财，以任侠和掌官吏短处显威。 [[9]](#note-9)


<a id="event-10"></a>

10. **周阳由分传。** 小题引入周阳由。 [[10]](#note-10)


<a id="event-11"></a>

11. **周阳由枉法徇喜怒。** 周阳由借宗亲入仕，所爱曲法求生，所恶借法诛灭；为守、尉皆压制同官。后与河东守胜屠公争权相告，守自杀，他被弃市。 [[11]](#note-11)


<a id="event-12"></a>

12. **酷吏模式扩散。** 篇中以甯成、周阳由之后官事日繁，民知巧避法律，说明许多官吏改循同样章法。 [[12]](#note-12)


<a id="event-13"></a>

13. **赵禹分传。** 小题引入赵禹。 [[13]](#note-13)


<a id="event-14"></a>

14. **赵禹与张汤定条法。** 赵禹曾事周亚夫，虽廉却被认为用法深。武帝时以文法进用，与张汤定见知等律令，使官吏依法相互监督纠举。 [[14]](#note-14)


<a id="event-15"></a>

15. **赵禹的治法与免归。** 赵禹拒宾客私谒，照现行法办案，通常不另掘属吏阴罪。早年曾号严急，后因同辈愈严而显平，晚任燕相、坐罪免归，寿终在家。 [[15]](#note-15)


<a id="event-16"></a>

16. **义纵分传。** 小题引入义纵。 [[16]](#note-16)


<a id="event-17"></a>

17. **义纵由群盗入官。** 义纵曾与张次公为盗，经医者姐姐与太后关系得任。任县令敢办贵戚，以捕修成子仲获迁河内都尉，继严击郡中豪族。 [[17]](#note-17)


<a id="event-18"></a>

18. **甯成为关都尉与义纵治南阳。** 公孙弘以甯成过暴劝勿用作郡守，帝任关都尉。义纵迁南阳后查办甯氏，甯成等奔亡；朱强、杜周在南阳获用见段末。 [[18]](#note-18)


<a id="event-19"></a>

19. **义纵任定襄太守。** 屡发北征扰乱定襄，义纵调守该郡。他把探视重囚的亲友定为解脱死囚之罪，与重囚同日处死四百余人。 [[19]](#note-19)


<a id="event-20"></a>

20. **义纵与王温舒任京官及义纵死。** 京师多案时以义纵为右内史、王温舒中尉。义纵刑严却不想朝廷扰民而阻杨可告缗，先因道路失修遭帝怨，终由杜式按阻法弃市。 [[20]](#note-20)


<a id="event-21"></a>

21. **王温舒分传。** 小题引入王温舒。 [[21]](#note-21)


<a id="event-22"></a>

22. **王温舒暗持部下重罪以治盗。** 王温舒由治狱受张汤拔擢为御史，任广平都尉时选强悍吏执其罪状，放任捕盗，稍退缩则诛；因此以强治知名，迁守河内。 [[22]](#note-22)


<a id="event-23"></a>

23. **王温舒大治河内狱。** 私马传驿供急奏，逮豪猾株连千余家，大案族诛、小也判死，财没偿赃。传借他嫌冬月短说其嗜杀。 [[23]](#note-23)


<a id="event-24"></a>

24. **王温舒前后任中尉。** 王温舒在中尉任延旧治，受义纵掣肘；张汤败后为廷尉，尹齐有罪后复任中尉。他在关中重用熟悉的强吏，并以告发治案，对势家屈从。 [[24]](#note-24)


<a id="event-25"></a>

25. **王温舒罢免与通天台役。** 讨东越归后因议不合免；见武帝将造通天台，建议重新核查逃役人，得众补工，因而拜少府。此后数有去复。 [[25]](#note-25)


<a id="event-26"></a>

26. **尹齐分传。** 小题引入尹齐。 [[26]](#note-26)


<a id="event-27"></a>

27. **尹齐为中尉获罪。** 尹齐出身刀笔，事张汤严于捕盗。任中尉时豪恶吏避匿，良吏不能办事，他因政事多废获罪；后在淮阳任都尉，卒后仇家欲毁尸。 [[27]](#note-27)


<a id="event-28"></a>

28. **杨仆分传。** 小题引入杨仆。 [[28]](#note-28)


<a id="event-29"></a>

29. **杨仆出征南越、东越。** 杨仆曾督关东盗贼，以敢击见用。南越反，任楼船将军有功封侯；将再讨东越，武帝以冒计战功等罪责之，仍令出兵，段末交代失侯病死。 [[29]](#note-29)


<a id="event-30"></a>

30. **咸宣分传。** 小题引入咸宣。 [[30]](#note-30)


<a id="event-31"></a>

31. **咸宣以深文治案。** 卫青荐用咸宣，后升御史办主父偃及淮南反狱，以深文致罪者多。任内史等职细管簿籍财物，属吏动辄受重法；段末记其终局。 [[31]](#note-31)


<a id="event-32"></a>

32. **田广明分传。** 小题引入田广明。 [[32]](#note-32)


<a id="event-33"></a>

33. **田广明捕公孙勇与胡倩一党。** 胡倩假冒光禄大夫行诈，田广明发兵收捕。公孙勇另在圉遭魏不害、江德、苏昌等识破，捕者有赏，段末还记四人相约共事。 [[33]](#note-33)


<a id="event-34"></a>

34. **田广明战败还军与自杀。** 田广明曾击益州、任左冯翊，参与宣帝定策后封昌水侯。以祁连将军出击匈奴未到目标，另有军中私奸，受杜延年追责自杀，兄田云中亦有罪。 [[34]](#note-34)


<a id="event-35"></a>

35. **田延年分传。** 小题引入田延年。 [[35]](#note-35)


<a id="event-36"></a>

36. **田延年参加废立。** 田延年由霍光幕府出守河东，任用尹翁归等惩豪强。任大司农后以强硬态度促公卿就废昌邑王表态，因定策封阳成侯。 [[36]](#note-36)


<a id="event-37"></a>

37. **严延年分传。** 小题引入严延年。 [[37]](#note-37)


<a id="event-38"></a>

38. **严延年劾霍光与田延年。** 严延年初仕御史，劾霍光废立擅权而奏被搁置；再劾田延年持兵犯乘舆于审理中反被追责，亡命后遇赦。 [[38]](#note-38)


<a id="event-39"></a>

39. **严延年收治涿郡高氏。** 两高氏庇护为盗宾客，官吏畏惮。严延年责掾属赵绣不应藏重劾，以死刑治案，由此显威。 [[39]](#note-39)


<a id="event-40"></a>

40. **严延年任河南太守。** 严延年重用严刑摧折强豪，对穷弱涉罪则曲解条文求免，对欺压平民的豪家则设法入罪，官民难测其轻重。 [[40]](#note-40)


<a id="event-41"></a>

41. **短悍精明而多杀。** 严延年厚待尽职吏属、善作狱文，死刑常在冬月集中执行，河南称屠伯。传同时记其法令严行及杀戮之多。 [[41]](#note-41)


<a id="event-42"></a>

42. **张敞劝少杀与黄霸对照。** 张敞劝旧友严延年缓刑，严延年认为河南豪恶不锄不行。邻郡黄霸用宽政而受褒奖，严延年不服。 [[42]](#note-42)


<a id="event-43"></a>

43. **尹赏分传。** 小题引入尹赏。 [[43]](#note-43)


<a id="event-44"></a>

44. **尹赏由县吏升迁。** 尹赏历楼烦、粟邑及频阳诸职，因残害免官后又由御史荐为郑令。 [[44]](#note-44)


<a id="event-45"></a>

45. **尹赏整治长安。** 成帝末期长安多报仇、劫掠，尹赏署县令获便宜处置权，修狱挖坑并捕大批被列为恶少者拘杀、示众，也选容少数以督捕。 [[45]](#note-45)


<a id="event-46"></a>

46. **尹赏江夏与京畿任职。** 尹赏治江夏盗与吏民，多杀被免，南山盗起又起用为右辅都尉，迁执金吾，于三辅声威重。 [[46]](#note-46)


<a id="event-47"></a>

47. **尹赏遗戒与后人。** 尹赏死前称酷残免官尚可能因功再起，软弱不任却难复，训示诸子。四子皆至郡守，长子尹立官京兆尹。 [[47]](#note-47)


<a id="event-48"></a>

48. **篇末赞小题。** 转录以“贊”引出史家总论。 [[48]](#note-48)


<a id="event-49"></a>

49. **班固衡量诸酷吏。** 赞依次评郅都抗直、张汤揣上而能治、赵禹守法、杜周少言迎合，认为有廉有污、施为各异且都以禁奸见知，并说明张汤、杜周有专传。 [[49]](#note-49)

> 孔子曰：「導之以政，齊之以刑，民免而無恥；導之以德，齊之以禮，有恥且格。」老氏稱：「上德不德，是以有德；下德不失德，是以無德。法令滋章，盜賊多有。」信哉是言也！法令者，治之具，而非制治清濁之原也。昔天下之罔嘗密矣，然不軌愈起，其極也，上下相遁，至於不振。當是之時，吏治若救火揚沸，非武健嚴酷，惡能勝其任而媮快乎？言道德者，溺於職矣。故曰：「聽訟吾猶人也，必也使無訟乎！」「下士聞道大笑之。」非虛言也。

**[《汉书·酷吏传》P008](../../拆分史书/汉书/卷090.md#p008)** · [仓内TXT L9589—L9589](../../拆分史书/汉书/卷090.md#part-1-L9589)

[返回正文第8条](#event-8)

<a id="hs090-p009"></a>

**[《汉书·酷吏传》P009](../../拆分史书/汉书/卷090.md#p009)** · [仓内TXT L9590—L9590](../../拆分史书/汉书/卷090.md#part-1-L9590)

<a id="note-9"></a>

### 9. 甯成坐法而归为豪强

[返回正文第9条](#event-9)

<a id="hs090-p010"></a>

**[《汉书·酷吏传》P010](../../拆分史书/汉书/卷090.md#p010)** · [仓内TXT L9591—L9591](../../拆分史书/汉书/卷090.md#part-1-L9591)

**[《汉书·酷吏传》P046](../../拆分史书/汉书/卷090.md#p046)** · [仓内TXT L9627—L9627](../../拆分史书/汉书/卷090.md#part-1-L9627)

# 汉书食货制度与财计议论

[本世纪目录](README.md) · [全部世纪](../README.md)

此处连读各志的制度沿革、学术分类与未详年次的史事；整段原文和已系年节录均可由卷内读本查阅。


<a id="event-1"></a>

1. **食、货与立政之本。** 食指可供食用的谷物，货指衣料、钱币等可流通物资。班固从农具和市场说起，追叙尧舜授时、禹定土贡，以财能够聚人养民，归结到城郭、井田、市肆、学校及士农工商分业。 [[1]](#note-1)


<a id="event-2"></a>

2. **井田的尺度与共作。** 六尺为步，百步为亩；逐层汇成一井。方一里九百亩，八家各有私田，并合耕公田，余地作居所。守望、疾病救助与共同承担力役是这套安排的社会目标。 [[2]](#note-2)


<a id="event-3"></a>

3. **授田、赋税和农桑。** 田按地力及休耕年数分三等，余夫和工商户另有受田比例，山泽原陵依地利调整。赋供军役及府库，税供祭祀、官俸等。二十受田、六十归田；杂种五谷、勤耘抢收，桑蚕、菜蔬和家畜补充衣食。 [[3]](#note-3)


<a id="event-4"></a>

4. **乡里划分与四季生活。** 五家成邻，累计至乡；庠序分别教化行礼。春出冬入以配时防盗，里胥邻长督人往来，年长者免负薪。妇女同巷夜绩，节省灯火、互相习艺，也以歌咏诉说不平。 [[4]](#note-4)


<a id="event-5"></a>

5. **学制、采诗与储粮考绩。** 八岁习书计长幼之节，十五习礼乐，再逐级选送造士，同才以射分次。春行人振木铎采诗，交乐官校音传闻天子。作者以不误农时、公私并举和三年积一岁之储说明富民能成教化，再用累考储粮解释“太平”理想。 [[5]](#note-5)


<a id="event-6"></a>

6. **周衰与鲁初税亩。** 班固把恶吏破坏田界、滥役失信和公田荒废相连，借《春秋》记鲁宣公按实有田亩征税一事，表达对改变旧田制的批评。 [[6]](#note-6)


<a id="event-7"></a>

7. **李悝的尽地力与平籴。** 李悝估算方百里可耕地和勤惰所致产差，又用五口之家租、食、衣、祭祀算例说明农户结余不足。谷贵伤民、贱伤农，故丰年分等收购、歉年按灾情平价发卖，用有余补不足；史文说魏实行后国富。 [[7]](#note-7)


<a id="event-8"></a>

8. **商鞅至秦统一的财政。** 商鞅破井田开阡陌，以农战奖赏使秦强盛；班固亦指出贫富与兼并扩大。始皇并天下后，造作、远征、租赋和戍役消耗人力财物，作者将之与秦末溃叛相连。 [[8]](#note-8)


<a id="event-9"></a>

9. **汉初饥荒、租赋与复苏。** 秦汉战争毁业，汉初曾因饥荒允许卖子、赴蜀汉就食，贵人也经历车马短缺。高祖减省禁令，田租十五取一，按俸禄与国费用度征赋；山泽市肆等收入分别供各自奉养。惠帝、吕后时生产渐复，文帝节俭，贾谊担忧弃本逐末。 [[9]](#note-9)


<a id="event-10"></a>

10. **贾谊劝储粮。** 贾谊以仓廪和礼节相连，认为物产有时而消费无度，奢侈及脱离农业使公私储积不足。旱灾或边急一旦并发，官府无粮救济，弱者挨饿，强者可乘乱生事；粮足则攻守备具，故主张让游食者返农。 [[10]](#note-10)


<a id="event-11"></a>

11. **文帝亲耕籍田。** 文帝受到贾谊奏议触动，开放籍田并亲耕以劝农。下文另引晁错，不把两篇奏章当作同一诏令。 [[11]](#note-11)


<a id="event-12"></a>

12. **晁错论积贮与谷帛。** 圣王开生财途径，靠备荒而非替民耕织。汉的田地、人力和山泽尚有可用，饥寒却足以破坏治理。金玉轻便而不能直接救饥寒，粟帛需长期劳动且不可或缺；作者借此主张贵谷，薄赋、扩仓。 [[12]](#note-12)


<a id="event-13"></a>

13. **晁错论农困商富。** 五口农家要服役、接待丧病又遇临时征敛，生产有限，迫于灾害可能贱卖产品、借高利贷甚至鬻田卖子。富商借储物差价获利，又能交结贵人，形成兼并与流亡。 [[13]](#note-13)


<a id="event-14"></a>

14. **晁错提出入粟授爵赎罪。** 法律贵农贱商与现实农贫商富相悖，晁错提出官府把粟作为奖惩媒介，让有余者入粟换爵或赎罪，使国用、农价、民赋三方面改善。并以军马免役和守城必须储谷说明实物军备的重要。 [[14]](#note-14)


<a id="event-15"></a>

15. **边地入粟、减租、免租。** 文帝采纳入粟塞下，以六百石授上造，依粮额升爵。晁错再建议边粮足五岁再输郡县、郡县足一年便可赦免农租。其后文帝十二年减半，十三年免田租，三事各自分读。 [[15]](#note-15)


<a id="event-16"></a>

16. **景帝复征半租及文景之富。** 景帝二年恢复征收半租，按三十税一。西部旱灾后再用减价售爵与入粟抵罪，并兴苑马。作者陈列府库、粮仓、牛马充足状况，同时指出富豪兼并、乡里逞势与贵族奢侈已滋长。 [[16]](#note-16)


<a id="event-17"></a>

17. **武帝前期耗费与董仲舒进言。** 董仲舒劝关中及时种冬麦，又以古代薄税与秦的兼并、高租、徭戍、盐铁管制对比，主张限名田、宽民力、减弱奴婢主人的特权。此段汇录建议与后果，未给每一奏议确年。 [[17]](#note-17)


<a id="event-18"></a>

18. **富民侯与赵过代田。** 武帝晚年转重农事，封相为富民侯、任赵过为搜粟都尉。代田沿亩开甽、来年互换沟垄，耨草覆根以耐风旱。赵过改器具、用耦犁、教官民并试种，缺牛则用人牵，推广于三辅及边郡。 [[18]](#note-18)


<a id="event-19"></a>

19. **耿寿昌近籴、海租与常平仓。** 昭帝后流民渐还，宣帝丰收反使谷价过低。耿寿昌建议近地购粮以减少关东转漕、增海租；萧望之质疑支出、鱼产和劳役，皇帝未采纳。后来设边郡常平仓，以价低时加价购入、价高时降价卖出，并赏爵。 [[19]](#note-19)


<a id="event-20"></a>

20. **元帝赈灾并一度裁罢官营。** 志先述即位后水灾、次年齐饥，续述取消盐铁及其他官营、减宫卫、角抵、织造和禁苑，减关中戍卒、转谷赈贷。制度裁省与灾害分别定位，后来只复置盐铁。 [[20]](#note-20)


<a id="event-21"></a>

21. **成帝永始水灾。** 成帝时战少而储备不足，永始二年梁国、平原连年水灾，志称人相食，主管刺史守相获免。 [[21]](#note-21)


<a id="event-22"></a>

22. **哀帝限田限奴婢议。** 师丹认为豪富并兼须略设上限。孔光、何武拟按身份限地和奴婢数，三年后超额没入，市价一度下跌，但丁傅及权贵不便，诏令暂缓，最终未实行。 [[22]](#note-22)


<a id="event-23"></a>

23. **王莽改边疆名分与王田制度。** 平帝死后王莽摄政而称帝，易单于印、贬钩町王的举措激起边境怨争；大规模征兵转输扰民。又将田改称王田、奴婢改称私属，禁买卖，令少口多田之家分出余田；制度反复、吏得乘隙。 [[23]](#note-23)


<a id="event-24"></a>

24. **王田松禁与新莽末年饥馑。** 禁令实行后民困，王莽又允许买卖王田、私属，但戍边摊派、灾荒、谷贵持续。末年群盗、战争与饥饿俱重，开仓赈贷、煮木作酪、设官给粮都未能阻止大批流民饿死，史文又记其诏归咎灾数。 [[24]](#note-24)


<a id="event-25"></a>

25. **周的币制传统与管仲轻重论。** 志传周太公定金、圜钱和布帛规格，退而用之齐；至管仲以岁收、政令解释物价差，认为富商趁民急逐利，应由政令和储备调节。上古细节无详凭，观点保留为志书追述。 [[25]](#note-25)


<a id="event-26"></a>

26. **周景王铸大钱与秦币二等。** 单穆公以大小币相权说明兼行可以济民、废轻强重会使民失资，周景王不听。秦统一后定黄金为上币，铜钱文半两，珍珠玉贝等视为器用宝藏。 [[26]](#note-26)


<a id="event-27"></a>

27. **汉初货币与文帝再许私铸。** 汉初钱重而改民铸荚钱，货物遭囤积，价格上涨；高祖以重税和衣车限制压抑商人，惠帝、高后放宽而商人子孙仍不得仕。文帝五年改四铢并开放私铸。 [[27]](#note-27)


<a id="event-28"></a>

28. **贾谊论私铸及收铜七利。** 掺铅铁造钱有巨利，重刑也难禁；地方钱轻重不同，严整则苛，放任则乱，采铜还夺农时。贾谊建议官府统收铜，减少伪钱刑狱、导民归农，以调钱价、限兵器来源、掌握弃用与赐予，并据此推论七项好处。 [[28]](#note-28)


<a id="event-29"></a>

29. **边地开拓、征伐与武帝前期用度。** 东瓯、两越、西南夷、沧海郡、马邑等若干边事先后征发。卫青取河南地后营朔方，巴蜀修路和远供军粮尤其费。国家以入粟、货币支付和撤减部分经略来调度财力。 [[29]](#note-29)


<a id="event-30"></a>

30. **武功爵与司法趋严。** 远征赏赐、死伤及辎重使大司农用度见绌，有司建议卖爵、赎免并设武功爵。公孙弘、张汤用事，见知和废格之狱兴；淮南、衡山、江都案又牵连众多，作者对比朝廷求贤的声名与司法严急。 [[30]](#note-30)


<a id="event-31"></a>

31. **浑邪王归汉的财政代价。** 霍去病两度出塞获胜，浑邪王率数万众来降，汉动用三万辆车迎接并厚赏军民。志以年度费用表现归降安置的负担。 [[31]](#note-31)


<a id="event-32"></a>

32. **水利转漕、边马和降众供给。** 此前黄河决口，番系想开渠道减漕，郑当时另开直渠，朔方也兴灌溉；长期耗人耗财。战马、牧卒与降众供给进一步加重开支，使皇帝削膳、撤车马并出禁府财物。 [[32]](#note-32)


<a id="event-33"></a>

33. **水灾、赈济与迁民。** 山东水灾后先开仓、再劝富户借给贫民，仍不足便迁民关西及新秦中，给衣食、产业，派使者分部照应。志将迁徙作为历年财政负担，兼批富商乘急得利。 [[33]](#note-33)


<a id="event-34"></a>

34. **白鹿皮币、白金三品与三铢。** 公卿借财政缺用和铜钱轻薄议新币。白鹿皮加彩缘作朝聘礼券；银锡白金按龙、马、龟有三等，官府另销半两而铸三铢，处死盗铸者。币种与后来郡国五铢分读。 [[34]](#note-34)


<a id="event-35"></a>

35. **理盐铁与买复后的征发。** 东郭咸阳、孔仅自营盐铁出身，进入大农分理盐铁；桑弘羊以心计见用。买爵、免役导致可征之人少，朝廷令有关爵者任吏或出马，旧吏去上林伐棘修池。 [[35]](#note-35)


<a id="event-36"></a>

36. **漠北军费与郡国五铢。** 卫青、霍去病大举出击，军马损失和赏支巨大，部分将士未及时得禄。有司以三铢太轻易作伪，建议郡国铸五铢并设外郭以防磨取。 [[36]](#note-36)


<a id="event-37"></a>

37. **盐铁征榷与算缗。** 大农以山泽之产佐国赋，招民出用、官供盐具，私煮盐铸铁没器物并加刑。公卿又请恢复对车船商资的征算，要求申报，重罚隐瞒并奖告发。 [[37]](#note-37)


<a id="event-38"></a>

38. **卜式、均输与告缗实行。** 卜式独愿入财，朝廷奖官爵田以为倡；孔仅、桑弘羊继续掌会计铸造及逐步试置均输。大举赦私铸难以取缔，朝廷遣人巡察；颜异因被认定“腹非”而死。富户多不肯输财，告缗行而扩大。 [[38]](#note-38)


<a id="event-39"></a>

39. **赤仄与上林三官集中铸币。** 郡国杂铸后，京师用一当五的赤仄钱，白金后来废行。赤仄也因取巧贬价而撤，转由上林三官铸钱，旧铜统一交收，私铸成本提高。此为多次改革的连续叙事。 [[39]](#note-39)


<a id="event-40"></a>

40. **告缗没产与国家经营。** 杨可告缗导致大批财物、田宅、奴婢没入，杜周治案。水衡后来掌上林，扩大昆明池、制造楼船并营柏梁台。没收田由诸官耕种，奴婢分派苑囿，另征“株送徒”，入财补郎影响选官。 [[40]](#note-40)


<a id="event-41"></a>

41. **关东赈济、巡郡与封禅准备。** 连年河灾饥荒，准灾民往江淮就食并调巴蜀粟；下一阶段皇帝巡行，河东与陇西守因供备不力自杀，北地边备亦受追究。得鼎后太一、后土之祠相继立，地方为拟议封禅治道路宫馆。 [[41]](#note-41)


<a id="event-42"></a>

42. **南越、西羌、初郡与军费。** 南越及边羌军事同时需兵马粮饷，朝廷增戍田并令差出牡马。卜式以愿击越获褒，酎祭查金则使大批列侯失爵。他为御史后批评官营铁器价高质恶和船税。新设郡暂从旧俗而由邻地供吏卒，后续叛扰仍动用大农养兵。 [[42]](#note-42)


<a id="event-43"></a>

43. **桑弘羊扩均输、立平准。** 元封元年卜式改任太子太傅，桑弘羊总理盐铁、征调，让郡国以便于转输的物产纳赋，设置部丞；京师平准接受委输，贵卖贱买。北巡、封禅及东行耗用物资皆取给大农。 [[43]](#note-43)


<a id="event-44"></a>

44. **入粟补官、卜式论官营。** 桑弘羊倡入粟补吏与赎罪，按量给复除并转粮急处；志称仓实、布帛充足，弘羊获奖。遇旱时卜式痛斥官府列市逐利，后文所记弘羊任御史大夫在武帝病重时。 [[44]](#note-44)


<a id="event-45"></a>

45. **盐铁会议及桑弘羊的结局。** 昭帝六年问贤良文学疾苦，会者反对盐铁、榷酒、均输，桑弘羊以边防与用度反驳，议后罢酒榷。弘羊后来卷入上官桀集团案，获诛，两次记事分年。 [[45]](#note-45)


<a id="event-46"></a>

46. **元帝复盐铁、贵谷罢钱议。** 志概说宣至平朝大体保持货政，仍记元帝短暂停盐铁、贡禹建议停采铸改以谷帛收支，反对者以钱易分计，建议未行。五铢累计量是志书总计；称元狩五年三官初铸，与本志前文郡国先铸、后改三官的层次有出入。 [[46]](#note-46)


<a id="event-47"></a>

47. **居摄改铸与新朝宝货。** 王莽居摄造大钱五十、契刀五百及金错刀五千，与五铢并行；称帝后以刘字有金刀为由废刀与五铢，改以品类繁多的宝货。 [[47]](#note-47)


<a id="event-48"></a>

48. **宝货的尺度和价目。** 钱六、银二、龟四、贝五、布十，再加黄金，持有、成色及尺度各有限制，合志所称五物、六名、二十八品。钱布以含锡的铜铸，带外郭；不够品等不得作宝货，元龟须交大卜取直。 [[48]](#note-48)


<a id="event-49"></a>

49. **宝货不行及简化。** 市场仍私用五铢，莽惩治持旧钱非议井田者，百姓又因买卖田人与造钱触法。最后暂只行小钱直一和大钱五十，搁置龟贝布。 [[49]](#note-49)


<a id="event-50"></a>

50. **五均司市、工商税与借贷。** 王莽依刘歆泉府说在长安、洛阳等地设五均。对荒田、不植之宅与无业人设负担，山泽取利与工商按净利抽十分一。官定时价、收购滞销品，高价时平价卖，祭丧可赊，治业可贷且限息。 [[50]](#note-50)


<a id="event-51"></a>

51. **酒榷与五均六斡的弊端。** 鲁匡为官营酒立论，列原料、税利和零售单元。主管官任富商督诸筦，空簿、吏商合谋逐利，莽又以生活必需为由增禁，百姓仍受侵害。 [[51]](#note-51)


<a id="event-52"></a>

52. **天凤改货布、货泉及大钱限期。** 天凤元年重申金银龟贝，停旧大小钱，货布直二十五货泉，货泉一枚直一。旧大钱准暂按一并行有限期；连番改币使财产折损，告举、官奴婢及相坐之制牵连多人。 [[52]](#note-52)


<a id="event-53"></a>

> 洪範八政，一曰食，二曰貨。食謂農殖嘉穀可食之物，貨謂布帛可衣，及金刀龜貝，所以分財布利通有無者也。二者，生民之本，興自神農之世。「斲木為耜，煣木為耒，耒鲈之利以教天下」，而食足；「日中為市，致天下之民，聚天下之貨，交易而退，各得其所」，而貨通。食足貨通，然後國實民富，而教化成。黃帝以下「通其變，使民不倦」。堯命四子以「敬授民時」，舜命后稷以「黎民祖飢」，是為政首。禹平洪水，定九州，制土田，各因所生遠近，賦入貢棐，楙遷有無，萬國作乂。殷周之盛，詩書所述，要在安民，富而教之。故易稱「天地之大德曰生，聖人之大寶曰位；何以守位曰仁，何以聚人曰財。」財者，帝王所以聚人守位，養成群生，奉順天德，治國安民之本也。故曰：「不患寡而患不均，不患貧而患不安；蓋均亡貧，和亡寡，安亡傾。」是以聖王域民，築城郭以居之，制廬井以均之，開市肆以通之，設庠序以教之；士農工商，四民有業。學以居位曰士，闢土殖穀曰農，作巧成器曰工，通財鬻貨曰商。聖王量能授事，四民陳力受職，故朝亡廢官，邑亡敖民，地亡曠土。

### 14. 晁错提出入粟授爵赎罪

[返回正文第14条](#event-14)

<a id="hs024-p014"></a>

**[《汉书·食货志》P014](../../sources/摘录/汉书-卷024-食货志.md#p014)** · [仓内TXT L5050—L5050](../../sources/本地分卷/汉书/汉书-卷024.md#L5050)

> 今法律賤商人，商人已富貴矣；尊農夫，農夫已貧賤矣。故俗之所貴，主之所賤也；吏之所卑，法之所尊也。上下相反，好惡乖迕，而欲國富法立，不可得也。方今之務，莫若使民務農而已矣。欲民務農，在於貴粟；貴粟之道，在於使民以粟為賞罰。今募天下入粟縣官，得以拜爵，得以除罪。如此，富人有爵，農民有錢，粟有所渫。夫能入粟以受爵，皆有餘者也；取於有餘，以供上用，則貧民之賦可損，所謂損有餘補不足，令出而民利者也。順於民心，所補者三：一曰主用足，二曰民賦少，三曰勸農功。今令民有車騎馬一匹者，復卒三人。車騎者，天下武備也，故為復卒。神農之教曰：「有石城十仞，湯池百步，帶甲百萬，而亡粟，弗能守也。」以是觀之，粟者，王者大用，政之本務。令民入粟受爵至五大夫以上，乃復一人耳，此其與騎馬之功相去遠矣。爵者，上之所擅，出於口而亡窮；粟者，民之所種，生於地而不乏。夫得高爵與免罪，人之所甚欲也。使天下入粟於邊，以受爵免罪，不過三歲，塞下之粟必多矣。

# 汉书高祖五子的宫廷与宗支

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **高皇帝八子。** 高祖八子的母亲各异：吕后生惠帝，曹夫人生刘肥，薄姬生文帝，戚夫人生刘如意，赵姬生刘长，其余三子刘友、刘恢、刘建出于别的姬妾。刘长另有传。 [[1]](#note-1)


<a id="event-2"></a>

2. **赵幽王刘友。** 刘友先王淮阳，刘如意死后迁赵。他疏远吕氏王后，宠爱其他姬妾；王后诬告他将来攻吕，太后便召其至长安，幽闭不供饮食，私送食物的臣下亦获罪。歌中自诉被迫娶吕氏、蒙谗、不得救，托苍天报仇，最终饿死，以平民礼葬。 [[2]](#note-2)


<a id="event-3"></a>

3. **赵王刘遂应吴楚之乱。** 晁错以过削赵常山，刘遂与吴楚合谋，焚杀劝谏的赵相建德与内史王悍，屯兵西界并联络匈奴。郦寄围其国都邯郸，吴楚战败后匈奴也不肯助赵；栾布从齐来会师，引水毁城，刘遂自杀。景帝褒奖两死臣，封其子为侯。 [[3]](#note-3)


<a id="event-4"></a>

4. **燕灵王刘建。** 卢绾逃往匈奴后由刘建继为燕王。刘建死后，吕太后杀死其美人所生之子，燕灵王一支因而绝嗣。 [[4]](#note-4)


<a id="event-5"></a>

5. **齐悼惠王九子为王。** 刘肥共有九子先后封王，分别是齐王刘襄、刘将闾，城阳王刘章，济北王刘兴居、刘志，济南王刘辟光，菑川王刘贤，胶西王刘卬，胶东王刘雄渠。 [[5]](#note-5)


<a id="event-6"></a>

6. **齐哀王刘襄与吕后分齐。** 刘襄于惠帝六年承袭。吕太后执政后割济南给吕台为奉邑，封刘章、刘兴居为朱虚侯、东牟侯，令宿卫长安；吕禄女嫁给刘章。又割琅邪封刘泽。赵王刘友幽死后，三赵王已废，吕氏三王擅权。 [[6]](#note-6)


<a id="event-7"></a>

7. **朱虚侯以军法行酒。** 刘章恼恨刘氏不掌权，请按军法主持宴饮。他借讲农事说非同种的苗应铲除，吕后默然；又追斩擅自退出的吕氏一人。吕后已许可行军法，不能治罪，此后吕氏惮他，大臣也有所依倚。 [[7]](#note-7)


<a id="event-8"></a>

8. **朱虚侯密告齐王。** 吕后死后，吕禄领兵、吕产为相，传文称二人欲作乱。刘章借吕禄女婿身份得知消息，密告刘襄起兵西进；刘章、刘兴居拟在内与大臣呼应，诛吕后推刘襄为帝。 [[8]](#note-8)


<a id="event-9"></a>

9. **刘章先斩吕产。** 刘章与周勃、陈平等共诛诸吕，刘章先斩吕产，随后诸吕尽被诛，刘泽也从齐地赶到长安。 [[9]](#note-9)


<a id="event-10"></a>

10. **魏勃折于灌婴与早年求见曹参。** 齐罢兵后，灌婴追问魏勃策动举兵，魏勃以邻家失火不待呼告便救解释，继而畏惧发抖，灌婴因此轻视而遣罢。其父曾以琴见秦帝。魏勃少时无门路，日扫齐相舍人门外，终于见曹参，由舍人获荐于刘肥、任内史；刘襄即位后权逾齐相。 [[10]](#note-10)


<a id="event-11"></a>

11. **城阳王世次。** 刘章与刘兴居同日由侯封王，死后子刘喜继位；刘喜由城阳迁淮南又返城阳，以下依次是刘延、刘义、刘武、刘顺、刘恢、刘景、刘云。刘云无子，成帝复立其兄刘俚，城阳一支到王莽时绝。 [[11]](#note-11)


<a id="event-12"></a>

12. **封济北而刘兴居起兵败亡。** 大臣开始曾许刘章赵地、刘兴居梁地；文帝知二人原欲拥刘襄，改以齐两郡封王。刘章死后匈奴入边，灌婴出军，文帝到太原；刘兴居以为文帝将亲征，乘机起兵。文帝罢北伐回京，遣棘蒲侯柴将军击破，刘兴居被俘后自杀。 [[12]](#note-12)


<a id="event-13"></a>

13. **纪氏后宫争宠。** 纪太后以弟女为刘次昌王后，又使长女纪翁主治理后宫、阻止其他妃嫔亲近齐王，欲使王专宠纪氏女，结果刘次昌和姐姐私通。 [[13]](#note-13)


<a id="event-14"></a>

14. **修成君女议婚未成。** 皇太后欲把非刘氏之女修成君的女儿娥嫁给诸侯，宦者徐甲请赴齐撮合；主父偃也想把女儿送入齐宫。纪太后斥退，徐甲回报时借燕王因乱伦而死之事暗示齐宫问题，皇太后叫停婚议，话渐闻于皇帝，主父偃自此与齐结怨。 [[14]](#note-14)


<a id="event-15"></a>

15. **城阳、菑川与刘肥墓祭。** 刘肥子孙存续的只剩城阳与菑川。菑川临齐，武帝把临菑以东刘肥墓园的产业划给菑川，使其奉祀。 [[15]](#note-15)


<a id="event-16"></a>

16. **菑川继世与刘终古被削地。** 刘志以后由刘建、刘遗、刘终古相继。五凤间刺史揭发刘终古令爱奴同王家女眷、宫婢性交，亲临观看，且弃不能分辨父亲的孩子。丞相御史指出其搅乱诸侯法定的后宫名分，请逮捕，诏削四县。刘终古后刘尚、刘横、刘交、刘永依次嗣王，至王莽时绝。 [[16]](#note-16)


<a id="event-17"></a>

17. **赞齐国之大与诸侯权力变化。** 汉初同姓子弟少，鉴于秦无藩辅而亡，广封同姓，齐是最大封国之一。诸侯初能自置群官，只有丞相由朝廷选任；吴楚之乱后逐渐削权，设左官、附益、阿党等法，诸侯只得租税衣食，贫者甚至坐牛车。 [[17]](#note-17)

> 章年二十，有氣力，忿劉氏不得職。嘗入侍燕飲，高后令章為酒吏。章自請曰：「臣，將種也，請得以軍法行酒。」高后曰：「可。」酒酣，章進歌舞，已而曰：「請為太后言耕田。」高后兒子畜之，笑曰：「顧乃父知田耳，若生而為王子，安知田乎？」章曰：「臣知之。」太后曰：「試為我言田意。」章曰：「深耕穊種，立苗欲疏；非其種者，鉏而去之。」太后默然。頃之，諸呂有一人醉，亡酒，章追，拔劍斬之，而還報曰：「有亡酒一人，臣謹行軍法斬之。」太后左右大驚。業已許其軍法，亡以罪也。因罷酒。自是後，諸呂憚章，雖大臣皆依朱虛侯。劉氏為彊。

> 齊有宦者徐甲，入事漢皇太后。皇太后有愛女曰脩成君，脩成君非劉氏子，太后憐之。脩成君有女娥，太后欲嫁之於諸侯。宦者甲乃請使齊，必令王上書請娥。皇太后大喜，使甲之齊。時主父偃知甲之使齊以取后事，亦因謂甲：「即事成，幸言偃女願得充王後宮。」甲至齊，風以此事。紀太后怒曰：「王有后，後宮備具。且甲，齊貧人，及為宦者入事漢，初無補益，乃欲亂吾王家！且主父偃何為者？乃欲以女充後宮！」甲大窮，還報皇太后曰：「王已願尚娥，然事有所害，恐如燕王。」燕王者，與其子昆弟姦，坐死。故以燕感太后。太后曰：「毋復言嫁女齊事。」事寖淫聞於上。主父偃由此與齊有隙。

> 志立三十五年薨，是為懿王。子靖王建嗣，二十年薨。子頃王遺嗣，三十五年薨。子思王終古嗣。五鳳中，青州刺史奏終古使所愛奴與八子及諸御婢姦，終古或參與被席，或白晝使羸伏，犬馬交接，終古親臨觀。產子，輒曰：「亂不可知，使去其子。」事下丞相御史，奏終古位諸侯王，以令置八子，秩比六百石，所以廣嗣重祖也。而終古禽獸行，亂君臣夫婦之別，悖逆人倫，請逮捕。有詔削四縣。二十八年薨。子考王尚嗣，五年薨。子孝王橫嗣，三十一年薨。子懷王交嗣，六年薨。子永嗣，王莽時絕。

> 贊曰：悼惠之王齊，最為大國。以海內初定，子弟少，激秦孤立亡藩輔，故大封同姓，以填天下。時諸侯得自除御史大夫群卿以下眾官，如漢朝，漢獨為置丞相。自吳楚誅後，稍奪諸侯權，左官附益阿黨之法設。其後諸侯唯得衣食租稅，貧者或乘牛車。

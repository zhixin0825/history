# 秦汉官制沿革与百官公卿表

[本世纪目录](README.md) · [全部世纪](../README.md)

这里按原卷保留表序、栏头、谱系和无法确系单一年度的材料。确年原句由各卷去向连接对应年份。


<a id="event-1"></a>

1. **上古传说至秦汉官制。** 表序从伏羲至少昊的龙、火、云、鸟名官讲起，继述传说中的唐虞官司与周六卿。三公可参预全政；另有以司马、司徒、司空为三公的说法。战国异制，秦定皇帝与百官，汉随时损益。班固以王莽仿古改官而民不安作结。 [[1]](#note-1)


<a id="event-2"></a>

2. **百官职掌。** 下列官名兼记秦制来源、汉代更名、属官和官秩。 [[2]](#note-2)


<a id="event-3"></a>

3. **前后左右将军。** 汉承秦制，按需要任前、后、左、右将军，掌兵及外部军事，设秩千石长史。 [[3]](#note-3)


<a id="event-4"></a>

4. **卫尉。** 卫尉掌宫门和屯卫，景帝先改中大夫令、后复名卫尉。各宫也可有卫尉，职掌大略相同，非每宫常设。 [[4]](#note-4)


<a id="event-5"></a>

5. **太仆。** 太仆主管车辆、御马、马厩和牧苑，下辖车府、骑马等署；中太仆专供太后车马。家马、挏马与路軨见太初年改置。 [[5]](#note-5)


<a id="event-6"></a>

6. **中尉、执金吾。** 中尉巡察京师，太初改称执金吾，统辖中垒、武库、船署等官及部分京辅兵吏。 [[6]](#note-6)


<a id="event-7"></a>

7. **中二千石官秩。** 太常至执金吾这一组正官秩为中二千石，丞秩千石。这里的官秩是制度等级。 [[7]](#note-7)


<a id="event-8"></a>

8. **太子师傅与属官。** 太子太傅、少傅为东宫师傅，属官包括门大夫、庶子、先马和舍人。 [[8]](#note-8)


<a id="event-9"></a>

9. **将行与大长秋。** 秦官将行在景帝时改名大长秋，可任用内廷宦者，也可用士人。 [[9]](#note-9)


<a id="event-10"></a>

10. **二千石官秩。** 从太子太傅到右扶风，正官秩二千石，属丞六百石。 [[10]](#note-10)


<a id="event-11"></a>

11. **京师城门、北军及其他校尉。** 城门校尉掌京城门防；中垒、屯骑、步兵、越骑、长水、胡骑、射声、虎贲各有兵种和守卫职责。表以八校尉总举，另明胡骑非常设。 [[11]](#note-11)


<a id="event-12"></a>

12. **都尉、侍中及各种加官。** 奉军、驸马都尉分掌御车及副马。侍中、中常侍得入禁中，诸曹领尚书事务，散骑陪乘，给事中备顾问。这里多为加授在本官之外的名号。 [[12]](#note-12)


<a id="event-13"></a>

13. **二十等爵。** 从公士到彻侯列二十级。关内侯居十九，彻侯居二十；彻侯避武帝名讳也称通侯、列侯，封国设相与家丞等。 [[13]](#note-13)


<a id="event-14"></a>

14. **关都尉、农都尉及属国都尉。** 关都尉为秦官；农都尉与属国都尉属于武帝设置，段中只说明时期。 [[14]](#note-14)


<a id="event-15"></a>

15. **县、道、国、邑及乡亭。** 以万户区分县令、县长及其秩级；丞尉为长吏，斗食、佐史是较低阶的属吏。乡有教化、断讼收税及巡察分工，亭有长。列侯食县、太后皇后公主食邑及有边族之道各有称名，卷末列总数。 [[15]](#note-15)


<a id="event-16"></a>

16. **任免表的年月与官名列。** 原始表按年列相国、太尉、御史大夫和各卿、京畿诸官。TXT把多行栏题摊平；列位与空格见仓内完整见证。 [[16]](#note-16)

> 易敘宓羲、神農、黃帝作敎化民，而傳述其官，以為宓羲龍師名官，神農火師火名，黃帝雲師雲名，少昊鳥師鳥名。自顓頊以來，為民師而命以民事，有重黎、句芒、祝融、后土、蓐收、玄冥之官，然已上矣。書載唐虞之際，命羲和四子順天文，授民時；咨四岳，以舉賢材，揚側陋；十有二牧，柔遠能邇；禹作司空，平水土；棄作后稷，播百穀；禼作司徒，敷五敎；咎繇作士，正五刑；垂作共工，利器用；�作朕虞，育草木鳥獸；伯夷作秩宗，典三禮；夔典樂，和神人；龍作納言，出入帝命。夏、殷亡聞焉，周官則備矣。天官冢宰，地官司徒，春官宗伯，夏官司馬，秋官司冦，冬官司空，是為六卿，各有徒屬職分，用於百事。太師、太傅、太保，是為三公，蓋參天子，坐而議政，無不緫統，故不以一職為官名。又立三少為之副，少師、少傅、少保，是為孤卿，與六卿為九焉。記曰三公無官，言有其人然后充之，舜之於堯，伊尹於湯，周公、召公於周，是也。或說司馬主天，司徒主人，司空主土，是為三公。四岳謂四方諸侯。自周衰，官失而百職亂，戰國並爭，各變異。秦兼天下，建皇帝之號，立百官之職。漢因循而不革，明簡易，隨時宜也。其後頗有所改。王莽篡位，慕從古官，而吏民弗安，亦多虐政，遂以亂亡。故略表舉大分，以通古今，備溫故知新之義云。

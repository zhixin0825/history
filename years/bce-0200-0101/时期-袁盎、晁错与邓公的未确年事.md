# 秦汉之际与西汉｜袁盎、晁错与邓公的未确年事（时期阅读）

<a id="event-1"></a>

1. **袁盎的家世及任吕禄舍人。** 袁盎一支由楚迁安陵，吕后时袁盎任吕禄舍人，文帝即位后经兄长推荐为中郎；迁家及任舍人的具体年分未见。 [[1]](#note-1)

<a id="event-2"></a>

2. **赵同参乘与袁盎进谏。** 赵同屡得宠，袁种劝袁盎当众争辩。文帝让赵同下车的一次出行未具年月。 [[2]](#note-2)

<a id="event-3"></a>

3. **袁盎任陇西都尉、齐相与吴相。** 袁盎在文帝朝由中央转地方。任吴相时采纳袁种之计，获吴王善待；其后出使时得到旧属救助，前后两段以七国起兵为界。 [[3]](#note-3)

<a id="event-4"></a>

4. **袁盎谏申屠嘉广纳士言。** 两人相遇与谈话可限于申屠嘉任相之后、文帝去世之前；没有可独立核定的年分。 [[4]](#note-4)

<a id="event-5"></a>

5. **袁盎与晁错的旧怨及初次案验。** 传先写二人互相回避，再写晁错任御史大夫后案验袁盎受吴王财物、袁盎获赦为平民。起兵后晁错又提出治袁盎；初案在晁错就职后、起兵前。 [[5]](#note-5)

<a id="event-6"></a>

6. **袁盎退居与结交剧孟。** 相楚以后袁盎因病免职，与乡里往来，推重剧孟和季心有急可托。病免及剧孟过访的年月未载。 [[6]](#note-6)

<a id="event-7"></a>

7. **晁错从张恢习刑名与受伏生《尚书》。** 晁错早年研习申、商刑名，入太常为掌故，奉文帝诏从伏生受《尚书》，又先后为太子舍人、门大夫、家令。文帝前元十五年策问升中大夫，具体任职和受经年月不能由这一年倒定。 [[7]](#note-7)

<a id="event-8"></a>

8. **邓公建元中被举与邓章。** 邓公景帝时论杀晁错，后在武帝建元中起复为九卿，一年后称病辞官。传只说建元中，未指哪次征召。他的儿子邓章以黄老言闻名。 [[8]](#note-8)

<a id="event-9"></a>

9. **司马迁与司马贞合评两人。** 太史公并评袁盎的仁心善说及晁错擅权更令，写两人的成名与败亡。司马贞述赞另就直谏、尊主、家危国泰作概括。 [[9]](#note-9)

### 4. 袁盎谏申屠嘉广纳士言

[返回正文第4条](#event-4)

[《史记·袁盎晁错列传》P009](../../拆分史书/史记/卷101.md#p009) · [三家注p9](../../拆分史书/史记/卷101.md#part-2-p9)

> 盎告歸，道逢丞相申屠嘉，下車拜謁，丞相從車上謝袁盎。袁盎還，愧其吏，乃之丞相舍上謁，求見丞相。丞相良久而見之。盎因跪曰：「願請閒。」丞相曰：「使君所言公事，之曹與長史掾議，吾且奏之；即私邪，吾不受私語。」袁盎即跪說曰：「君爲丞相，自度孰與陳平、絳侯？」丞相曰：「吾不如。」袁盎曰：「善，君即自謂不如。夫陳平、絳侯輔翼高帝，定天下，爲將相，而誅諸呂，存劉氏；君乃爲材官蹶張，遷爲隊率，積功至淮陽守，非有奇計攻城野戰之功。且陛下從代來，每朝，郎官上書疏，未嘗不止輦受其言，言不可用置之，言可受採之，未嘗不稱善。何也？則欲以致天下賢士大夫。上日聞所不聞，明所不知，日益聖智；君今自閉鉗天下之口而日益愚。夫以聖主責愚相，君授禍不久矣。」丞相乃再拜曰：「嘉鄙野人，乃不知，將軍幸教。」引入與坐，爲上客。

### 6. 袁盎退居与结交剧孟

[返回正文第6条](#event-6)

[《史记·袁盎晁错列传》P013](../../拆分史书/史记/卷101.md#p013) · [三家注p13](../../拆分史书/史记/卷101.md#part-2-p13)

> 嘗上書有所言，不用。袁盎病免居家，與閭里浮沈，相隨行，鬬雞走狗。雒陽劇孟嘗過袁盎，盎善待之。安陵富人有謂盎曰：「吾聞劇孟博徒，將軍何自通之？」盎曰：「劇孟雖博徒，然母死，客送葬車千餘乘，此亦有過人者。且緩急人所有。夫一旦有急叩門，不以親爲解，不以存亡爲辭，天下所望者，獨季心、劇孟耳。今公常從數騎，一旦有緩急，寧足恃乎！」罵富人，弗與通。諸公聞之，皆多袁盎。

<a id="note-7"></a>

### 7. 晁错从张恢习刑名与受伏生《尚书》

[返回正文第7条](#event-7)

[《史记·袁盎晁错列传》P015](../../拆分史书/史记/卷101.md#p015) · [三家注p15](../../拆分史书/史记/卷101.md#part-2-p15)

> 鼂錯者，潁川人也。學申商刑名於軹張恢先所，與雒陽宋孟及劉禮同師。以文學爲太常掌故。

[《史记·袁盎晁错列传》P016](../../拆分史书/史记/卷101.md#p016) · [三家注p16](../../拆分史书/史记/卷101.md#part-2-p16)

> 錯爲人陗直刻深。孝文帝時，天下無治尚書者，獨聞濟南伏生故秦博士，治尚書，年九十餘，老不可徵，乃詔太常使人往受之。太常遣錯受尚書伏生所。還，因上便宜事，以書稱說。詔以爲太子舍人、門大夫、家令。以其辯得幸太子，太子家號曰「智囊」。數上書孝文時，言削諸侯事及法令可更定者。書數十上，孝文不聽，然奇其材，遷爲中大夫。當是時，太子善錯計策，袁盎諸大功臣多不好錯。

### 9. 司马迁与司马贞合评两人

[返回正文第9条](#event-9)

[《史记·袁盎晁错列传》P021](../../拆分史书/史记/卷101.md#p021) · [三家注p21](../../拆分史书/史记/卷101.md#part-2-p21)

> 太史公曰：袁盎雖不好學，亦善傅會，仁心爲質，引義忼慨。遭孝文初立，資適逢世。時以變易，及吳楚一說，說雖行哉，然復不遂。好聲矜賢，竟以名敗。鼂錯爲家令時，數言事不用；後擅權，多所變更。諸侯發難，不急匡救，欲報私讎，反以亡軀。語曰「變古亂常，不死則亡」，豈錯等謂邪！

[《史记·袁盎晁错列传》P022](../../拆分史书/史记/卷101.md#p022) · [三家注p22](../../拆分史书/史记/卷101.md#part-2-p22)

> 索隱述贊曰：袁絲公直，亦多附會。攬轡見重，却席翳賴。鼂錯建策，屢陳利害。尊主卑臣，家危國泰。悲彼二子，名立身敗！

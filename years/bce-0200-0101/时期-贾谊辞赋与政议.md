# 西汉文帝时期｜贾谊辞赋与政议（时期阅读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷084完整读本](../../拆分史书/史记/卷084.md) · [纪年与异说](../../拆分史书/史记/卷084.md#kao-d49339c615)

本页随文帝初年的入朝、长沙谪居与梁王傅时期合读。可归年的召为博士、出傅长沙、《鵩鸟赋》纪时、淮南四子封侯和梁王坠马由年页进入。宣室召见、历次奏疏及贾谊身后家事在本页按相对先后阅读。

<a id="event-1"></a>

1. **贾谊在洛阳以文章知名，受河南守吴公赏识。** 贾谊十八岁时能诵《诗》、善作文，在郡里有名，河南守吴公召入门下。吴公后来任廷尉，荐贾谊入朝。前179年可定位受召，少年以才学知名是此前经历。 参见[前179年受召](bce-0179.md#note-12)。 [[1]](#note-1)

<a id="event-2"></a>

2. **贾谊赴长沙时渡湘，以赋吊屈原。** 贾谊把遭贬与屈原失意相照。赋先写鸾凤藏、鸱枭飞与骏马负盐车，借贤者失位哀吊屈原；结辞又以凤凰见德才下、神龙深潜自珍劝贤人择君，追问何必独留故都。这是文学中的劝说，也是贾谊借古自况。出傅长沙采用《资治通鉴》前176年，前177及更早的推定见卷084考证。 参见[前176年出傅长沙](bce-0176.md#note-4)。 [[2]](#note-2)

<a id="event-3"></a>

3. **《鵩鸟赋》以祸福相倚和造化无穷自宽。** 贾谊在长沙见鵩入舍，赋以问答写对去留、生死的惧疑，反观吴越兴亡、李斯显达后遇刑、傅说由刑徒为相，以见祸福反转，又以天地为炉、万物为铜，写顺化而不固执。赋序与「單閼」可与前174年互读，其中鸟的应答是作者设言。 参见[前174年](bce-0174.md#note-13)。 [[3]](#note-3)

<a id="event-4"></a>

4. **文帝在宣室召见贾谊，贾谊改作梁怀王太傅。** 文帝受祭胙后在宣室问鬼神之本，贾谊答至夜半，文帝移席近听。传文接写改任梁傅。《通鉴》文帝六年叙其上疏已称梁太傅，本传则在前174年鵩鸟之后说「後歲餘」。前173年是按赋作后一年有余推得的一说。两书的相对次序难以合定召见和授职的具体年份。 [[4]](#note-4)

<a id="event-5"></a>

5. **贾谊进言约束大诸侯。** 部分诸侯国兼有数郡，贾谊认为不合古制，应逐步削弱其规模，曾多次上疏。淮南厉王四子封侯及相关谏言可归前172年，但列传没有给每次削藩上疏的年月。《汉书》还保留较长的奏疏，与本文简叙互参。 参见[前172年淮南厉王四子封侯](bce-0172.md#note-2)。 [[5]](#note-5)

<a id="event-6"></a>

6. **梁怀王死后，贾谊自责去世，后代仍见于传。** 刘揖在前169年坠马而死，无后。贾谊自责为傅无状，哭泣一年多而死，年三十三。由这一时距可推到约前168年，文献未独记卒年或月份。后传记武帝时有两位孙子任郡守，贾嘉与司马迁通书，昭帝时列九卿，均缺独立任官年次。 参见[前169年梁怀王卒](bce-0169.md#note-1)。 [[6]](#note-6)

<a id="event-7"></a>

7. **太史公读屈贾辞赋，留下对去留与生死的两重反思。** 司马迁访长沙水滨，想见屈原而悲。读贾谊的吊文，他也思考屈原何不游仕他国；读《鵩鸟赋》之后，又因其等量生死、轻看去就而怅然自失。唐人司马贞的述赞则以「百年之後」的吊湘照应屈原一生。 [[7]](#note-7)

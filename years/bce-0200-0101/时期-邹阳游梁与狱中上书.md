# 西汉文景时期｜邹阳游梁与狱中上书（时期阅读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷083完整读本](../../拆分史书/史记/卷083.md) · [纪年与异说](../../拆分史书/史记/卷083.md#kao-1396aaec18)

邹阳离吴游梁的背景在文、景之际，遭谗入狱、呈书、获释只有相对顺序。梁案追查另可系年。狱中书征引古人事迹和寓言，随论说原段读。

<a id="reading-start"></a>

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **邹阳由吴入梁，遭梁王近臣进谗。** 齐人邹阳与枚乘、庄忌等先后往来吴、梁。他反对梁王亲信的谋议，羊胜等在梁孝王前进谗，邹阳因而入狱。梁国养士见[同世纪时期页](未定年-梁孝王宫苑与梁平王家事.md#sj058-palaces-note)，入狱的具体年月未见原书。 [[1]](#note-1)

<a id="event-2"></a>

2. **邹阳从狱中上书，诉说尽忠仍受猜疑。** 邹阳以荆轲、卫先生和卞和、李斯等为例，请梁王设身处地看忠心遭疑、遭刑的处境。白虹、太白等感应为书中设论，旧事的细节还可和不同传本互看。 [[2]](#note-2)

<a id="event-3"></a>

3. **以知己互信反对偏听。** 邹阳说交往多久并不能保证彼此相知，真正信任来自志义相合。他以苏秦、白圭受谤仍获礼遇，与孔子、墨翟遭排挤对照，劝梁王广听公断。史例在《汉书》另有子冉、子臧等人名异文。 [[3]](#note-3)

<a id="event-4"></a>

4. **以任用旧敌与杀功臣说明君臣之信。** 晋文公和齐桓公能任用旧日敌手，秦、越则分别用了商鞅、文种的计策，又杀了他们。邹阳请求君主在困厄与显达时都诚待士人，使人愿为国尽力。 [[4]](#note-4)

<a id="event-5"></a>

5. **明珠暗投与曲木成器比喻引荐得失。** 明珠无故投到路人面前，会让人按剑起疑；盘曲木材经人加工，却能制成君王器物。邹阳借这一对比劝梁王独立听事，从近臣之外察访人才，并指出若以富贵要求士人改节，有才者只会退隐。 [[5]](#note-5)

<a id="event-6"></a>

6. **梁王释放邹阳，后来重用他。** 梁王读过上书，释放邹阳，后来以他为上客。《汉书》另记梁案追查时，梁王请他入长安，经王长君转圜，见[前148年梁案同号史料](bce-0148.md#note-5)。此处的下狱和获释没有独立年份。 [[6]](#note-6)

<a id="event-7"></a>

7. **司马迁与司马贞评狱中书。** 司马迁认为邹阳辞锋虽急，却以贴切的例子表现受谗者的遭际，且能在危险中坚持自己的判断。司马贞的述赞回顾狱中进言与后来受器重。 [[7]](#note-7)

# 时期阅读｜韩王信、卢绾与陈豨未确年事

> 本页保留传记前事、未确年轶闻与评论。确年史事在相应年页同号史料。

[本页相关史料](#sources-start)

<a id="event-1"></a>

1. **卢绾与刘邦同里，从沛起兵。** 卢绾与刘邦同里，两家长辈交好，传称两人同日出生；长大又同学相亲，乡人两次庆贺。刘邦未起兵时避吏，卢绾常随侍；自沛起兵后随入汉中，后来以将军、太尉从征。他出入刘邦内室，赏赐和亲近程度非一般大臣可比，获封长安侯。 [[1]](#note-1)

<a id="event-2"></a>

2. **张胜转为联络匈奴，范齐往来陈豨。** 本段以陈豨反及燕从东北出兵引出张胜、臧衍和范齐的活动。陈豨发难在汉十年九月，随后燕使往返的月份无明文，且延续到朝廷取得降将口供以前。| [[2]](#note-2)

<a id="event-3"></a>

3. **卢绾被征讨，逃匈奴后病亡年不明。** 卢绾在前195高祖死后入匈奴，受封东胡卢王，居岁余而死。“岁余”可供估计，缺少另有年条或月日。| [[3]](#note-3)

<a id="event-4"></a>

4. **太史公论异姓王与陈豨。** 司马迁认为韩王信和卢绾凭一时局势与权谋成为异姓王，内遭怀疑，外倚匈奴，最终走投无路。他又说陈豨慕魏公子之名，任边将后厚待宾客，却因遭疑而受诱起兵；以谋划和人事之难结论。 [[4]](#note-4)

<a id="event-5"></a>

5. **索隐述赞。** 述赞并叙韩氏远裔由汉中起身、改封北地、后裔归汉和卢绾受宠、成为燕王、终于匈奴。它压缩世次与结果，应结合前文与侯表阅读。 [[5]](#note-5)

### 1. 卢绾与刘邦同里，从沛起兵

[返回正文第1条](#event-1)

**[《史记·韩信卢绾列传》P007](../../拆分史书/史记/卷093.md#p007)** · [三家注p7](../../拆分史书/史记/卷093.md#part-2-p7)

> 盧綰者，豐人也，與高祖同里。盧綰親與高祖太上皇相愛，及生男，高祖、盧綰同日生，里中持羊酒賀兩家。及高祖、盧綰壯，俱學書，又相愛也。里中嘉兩家親相愛，生子同日，壯又相愛，復賀兩家羊酒。高祖爲布衣時，有吏事辟匿，盧綰常隨出入上下。及高祖初起沛，盧綰以客從，入漢中爲將軍，常侍中。從東擊項籍，以太尉常從，出入卧內，衣被飲食賞賜，羣臣莫敢望，雖蕭曹等，特以事見禮，至其親幸，莫及盧綰。綰封爲長安侯。長安，故咸陽也。

<a id="note-2"></a>

### 2. 张胜转为联络匈奴，范齐往来陈豨

[返回正文第2条](#event-2)

**[《史记·韩信卢绾列传》P009](../../拆分史书/史记/卷093.md#p009)** · [三家注p9](../../拆分史书/史记/卷093.md#part-2-p9)

> 漢十一年秋，陳豨反代地，高祖如邯鄲擊豨兵，燕王綰亦擊其東北。當是時，陳豨使王黃求救匈奴。燕王綰亦使其臣張勝於匈奴，言豨等軍破。張勝至胡，故燕王臧茶子衍出亡在胡，見張勝曰：「公所以重於燕者，以習胡事也。燕所以久存者，以諸侯數反，兵連不決也。今公爲燕欲急滅豨等，已盡，次亦至燕，公等亦且爲虜矣。公何不令燕且緩陳豨而與胡和？事寬，得長王燕；即有漢急，可以安國。」張勝以爲然，迺私令匈奴助豨等擊燕。燕王綰疑張勝與胡反，上書請族張勝。勝還，具道所以爲者。燕王寤，迺詐論他人，脫勝家屬，使得爲匈奴間，而陰使范齊之陳豨所，欲令久亡，連兵勿決。

<a id="note-3"></a>

### 3. 卢绾被征讨，逃匈奴后病亡年不明

[返回正文第3条](#event-3)

**[《史记·韩信卢绾列传》P010](../../拆分史书/史记/卷093.md#p010)** · [三家注p10](../../拆分史书/史记/卷093.md#part-2-p10)

> 漢十二年，東擊黥布，豨常將兵居代，漢使樊噲擊斬豨。其裨將降，言燕王綰使范齊通計謀於豨所。高祖使使召盧綰，綰稱病。上又使辟陽侯審食其、御史大夫趙堯往迎燕王，因驗問左右。綰愈恐，閉匿，謂其幸臣曰：「非劉氏而王，獨我與長沙耳。往年春，漢族淮陰，夏，誅彭越，皆呂后計。今上病，屬任呂后。呂后婦人，專欲以事誅異姓王者及大功臣。」迺遂稱病不行。其左右皆亡匿。語頗泄，辟陽侯聞之，歸具報上，上益怒。又得匈奴降者，降者言張勝亡在匈奴，爲燕使。於是上曰：「盧綰果反矣！」使樊噲擊燕。燕王綰悉將其宮人家屬騎數千居長城下，候伺，幸上病愈，自入謝。四月，高祖崩，盧綰遂將其衆亡入匈奴，匈奴以爲東胡盧王。綰爲蠻夷所侵奪，常思復歸。居歲餘，死胡中。

<a id="note-4"></a>

### 4. 太史公论异姓王与陈豨

[返回正文第4条](#event-4)

**[《史记·韩信卢绾列传》P019](../../拆分史书/史记/卷093.md#p019)** · [三家注p19](../../拆分史书/史记/卷093.md#part-2-p19)

> 太史公曰：韓信、盧綰非素積德累善之世，徼一時權變，以詐力成功，遭漢初定，故得列地，南面稱孤。內見疑彊大，外倚蠻貊以爲援，是以日疏自危，事窮智困，卒赴匈奴，豈不哀哉！陳豨，梁人，其少時數稱慕魏公子；及將軍守邊，招致賔客而下士，名聲過實。周昌疑之，疵瑕頗起，懼禍及身，邪人進說，遂陷無道。於戲悲夫！夫計之生孰成敗於人也深矣！

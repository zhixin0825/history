# 高惠高后文功臣侯籍与跨年记载

[本世纪目录](README.md) · [全部世纪](../README.md)

这里按原卷保留表序、栏头、谱系和无法确系单一年度的材料。确年原句由各卷去向连接对应年份。


<a id="event-1"></a>

1. **文景以后侯家盛衰与宣帝复家。** 到文帝、景帝前后数代，流民归来、人口繁衍，大侯增至三四万户，小国户口也加倍。部分侯家后代忘记先人创业的艰苦，骄逸而触法，导致自身丧命、侯国丧失，也有子孙断绝。作者认为到武帝后元已几无遗留，又说法网有转密的一面。宣帝体恤旧功，打开宗庙档案，命官寻找子孙，许多已是雇佣者或庸保；给他们复除徭役或赋役，有人再赐金帛，用来彰显中兴。 [[1]](#note-1)


<a id="event-2"></a>

2. **杜业请接续开国功臣之后。** 成帝再过问功臣后人时，多支仅存一线。杜业举唐虞、夏商、周初封建和周成王赏念武王旧臣为例，强调承认旧功、延续宗祀是继绝世的德政。他说燕、齐国祀与周并传，支庶能因祖辈功劳续爵；汉代功臣也有割符世爵与山河之誓，而一百余年后续封者已尽，子孙穷困失散、祖墓无人祭。成帝已下诏寻访，数年尚未核实，杜业担心议者以难落实为由搁置，因此建议无法尽复时先择功劳最大的。文末接叙萧何后人获绍封，具体年次须对照表中萧氏世系。 [[2]](#note-2)


<a id="event-3"></a>

3. **续录旧表的范围。** 到哀帝、平帝时，朝廷继续查求曹参、周勃等功臣的后人，班固认为有合宜之处。本表承续旧记，追究各家侯爵的始末，列出始封功次，主体初封范围到文帝，后嗣事迹延至后代。 [[3]](#note-3)


<a id="event-4"></a>

4. **高祖功臣表。** 高祖功臣表的段题。初封人物在这一段归类，后嗣、改封与追录可跨到其他帝纪。 [[4]](#note-4)


<a id="event-5"></a>

5. **表的栏位。** 本段表头依次列出封国或爵号、谥号、姓名、受侯理由与户数、始封以及子孙数代承袭。TXT将表格摊成纵列，“六世”等单行标记并入相应家支；空栏和功次数字没有纪年含义。 [[5]](#note-5)


<a id="event-6"></a>

### 2. 杜业请接续开国功臣之后

[返回正文第2条](#event-2)

<a id="hs016-p003"></a>

**[《汉书·高惠高后文功臣表》P003](../../拆分史书/汉书/卷016.md#p003)** · [仓内TXT L2219—L2219](../../拆分史书/汉书/卷016.md#part-1-L2219)

> 降及孝成，復加卹問，稍益衰微，不絕如綫。善乎，杜業之納說也！曰：「昔唐以萬國致時雍之政，虞、夏以之多羣后饗共己之治。湯法三聖，殷氏太平。周封八百，重譯來賀。是以內恕之君樂繼絕世，隆名之主安立亡國，至於不及下車，德念深矣。成王察牧野之克，顧羣后之勤，知其恩結於民心，功光于王府也，故追述先父之志，錄遺老之策，高其位，大其㝢，愛敬飭盡，命賜備厚。大孝之隆，於是為至。至其沒也，世主歎其功，無民而不思。所息之樹且猶不伐，況其廟乎？是以燕、齊之祀與周並傳，子繼弟及，歷載不墮。豈無刑辟，繇祖之竭力，故支庶賴焉。迹漢功臣，亦皆割符世爵，受山河之誓，存以著其號，亡以顯其魂，賞亦不細矣。百餘年間而襲封者盡，或絕失姓，或乏無主，朽骨孤於墓，苗裔流於道，生為愍隷，死為轉屍。以往況今，甚可悲傷。聖朝憐閔，詔求其後，四方忻忻，靡不歸心。出入數年而不省察，恐議者不思大義，設言虛亡，則原德掩息，遴柬布章，非所以視化勸後也。三人為衆，雖難盡繼，宜從尤功。」於是成帝復紹蕭何。

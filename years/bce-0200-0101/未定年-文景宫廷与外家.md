# 西汉文景前后｜宫廷与外家（未定年）

[本世纪目录](README.md) · [全部时间目录](../README.md) · [纪年与异说](../../meta/考证/史记-卷049-纪年与异说.md)

**时间精度：有上下限的时期材料与后世评议。** 本页以高祖去世后至景帝去世（前195—前141）为主要阅读范围，收录在这一阶段无法逐项确年的亲属奉养、追尊、园邑与宫廷处境。窦太后的黄老取向、王氏母家的追尊与园寝等延及武帝初年，各组另说明范围；臧儿前136年去世后的园寝办理未明年月。早年家世只作此前背景。已能确年的生育、立后、封王、封侯、迁国与死亡仍在各年页。

1. **文帝即位后，薄氏父母获得追尊，魏氏亲属受到照顾。** 薄太后之母此前已死，葬栎阳北；父亲追尊灵文侯，在会稽设三百户园邑，长、丞以下官吏守冢，寝庙依礼奉食祭祀。栎阳北的灵文侯夫人园采用相同制度。薄太后早失父母，对曾奉养自己的母家魏氏亲人按亲疏给予复免、尊显和赏赐。薄氏实际封侯的一支是薄昭，死者追尊的侯号与在世列侯分别看待。 [[1]](#sj049-bo-family-note)

<a id="sj049-dou-parents-event"></a>

2. **窦氏立后以后，薄太后命人为她的父母设园奉祀。** 窦氏父母早已去世，葬在观津。朝廷追尊父亲为安成侯、母亲为安成夫人，在清河安排二百户园邑，由长、丞守护，依薄氏灵文园的制度办理。这里追尊的是死者，未给这一整套办理的独立年月。 [[2]](#sj049-dou-parents-note)

<a id="sj049-wendi-consorts-event"></a>

3. **文帝在位时，窦皇后因病失明，慎夫人与尹姬受宠。** 慎夫人来自邯郸，两人都没有儿子。皇后的病与后宫宠爱变化未给确年；这里的尹姬属于文帝宫廷。 [[3]](#sj049-wendi-consorts-note)

<a id="sj049-dou-huanglao-event"></a>

4. **窦太后长期尊重黄帝、老子的学说。** 她要求皇帝、太子以及窦氏家人阅读黄老著作、尊奉其术，宫廷教育因而深受她的偏好影响。这种取向后来进入新礼制与用人方向的争论，延续到武帝初年。 [[4]](#sj049-dou-huanglao-note)

<a id="sj049-wang-children-event"></a>

5. **王氏姐妹都入刘启宫中，儿女后来分封不同王国与公主邑。** 臧儿把长女送入太子宫后，又送小女王儿姁入宫。儿姁生刘越、刘寄、刘乘、刘舜四子，较早去世，四子后来都封王；王太后则生刘彻以及平阳、南宫、隆虑三公主。景帝可核的十四子中，刘彻承继皇位，其余十三子为王。入宫、生育、亲母死亡与各次分封有不同先后，不能以一个总数代替每人的年月。 [[5]](#sj049-wang-children-note)

<a id="sj049-wang-parents-event"></a>

6. **王仲获得共侯的追尊，臧儿身后也有园邑奉祀。** 王太后的父亲王仲早死，葬槐里，后来追尊共侯，设二百户园邑。母亲臧儿去世后从后夫田氏葬长陵，园寝制度比照共侯园。二人分别是死者追尊和奉祀，不与王信、田蚡、田胜三名在世列侯合并计数。 [[6]](#sj049-wang-parents-note)

### 1. 文帝即位后，薄氏父母获得追尊，魏氏亲属受到照顾

[返回正文第1条](#sj049-bo-family-event)

<a id="sj049-cite-025"></a>

**[《史记·外戚世家》P009](../../sources/摘录/史记-卷049-外戚世家.md#p009)**

> 薄太后母亦前死，葬櫟陽北。於是乃追尊薄案為靈文侯，會稽郡置園邑三百家，長丞已下吏奉守冢，寢廟上食祠如法。而櫟陽北亦置靈文侯夫人園，如靈文侯園儀。薄太后以為母家魏王後，早失父母，其奉薄太后諸魏有力者，於是召復魏氏，［及尊］賞賜各以親疏受之。薄氏侯者凡一人。

**本卷说明：** 范围为文帝入继以后的薄太后在世时期，前180—前155；主文未给各项追尊、园邑与召赏的独立年。三家注p9“薄父”“及尊”与主TXT“薄案”“［及尊］”均留原字。

### 2. 窦氏立后以后，薄太后命人为她的父母设园奉祀

[返回正文第2条](#sj049-dou-parents-event)

<a id="sj049-cite-033"></a>

**[《史记·外戚世家》P012](../../sources/摘录/史记-卷049-外戚世家.md#p012)**

> 竇皇后親蚤卒，葬觀津。於是薄太后乃詔有司，追尊竇后父為安成侯，母曰安成夫人。令清河置園邑二百家，長丞奉守，比靈文園法。

**本卷说明：** 下限窦氏前179立后，上限下诏人薄太后前155去世；不把追尊误作父母在世受封。

### 5. 王氏姐妹都入刘启宫中，儿女后来分封不同王国与公主邑

[返回正文第5条](#sj049-wang-children-event)

<a id="sj049-cite-044"></a>

**[《史记·外戚世家》P019](../../sources/摘录/史记-卷049-外戚世家.md#p019)**

> 先是臧兒又入其少女兒姁，兒姁生四男。

**本卷说明：** 姐妹入宫早于刘彻前156出生，四子陆续封王另见各年页；死亡只记“早卒”，不能由儿子封王年倒定。“林虑”为主文传本字，汉传L10151作隆虑，索隐指出东汉避讳改名。

<!-- /sj049-cite-044 -->

<a id="sj049-cite-045"></a>

**[《史记·外戚世家》P025](../../sources/摘录/史记-卷049-外戚世家.md#p025)**

> 景帝十三男，一男為帝，十二男皆為王。而兒姁早卒，其四子皆為王。王太后長女號日平陽公主，次為南宮公主，次為林慮公主。

**本卷说明：** 原文“十三男／十二王”与《五宗世家》列景帝诸王及《汉书》景十三王传相冲突。实际名单为德、阏于、余、非、彭祖、发、端、胜、荣、越、寄、乘、舜13王，加武帝为14子，原数不默改。

<!-- /sj049-cite-045 -->

<a id="sj049-cite-114"></a>

**互见原文：[出处L4511](../../sources/本地分卷/史记/史记-卷059.md#L4511)**

> 孝景皇帝子凡十三人為王，而母五人，同母者為宗親。栗姬子曰榮、德、閼于。程姬子曰餘、非、端。賈夫人子曰彭祖、勝。唐姬子曰發。王夫人兒姁子曰越、寄、乘、舜。

### 6. 王仲获得共侯的追尊，臧儿身后也有园邑奉祀

[返回正文第6条](#sj049-wang-parents-event)

<a id="sj049-cite-060"></a>

**[《史记·外戚世家》P026](../../sources/摘录/史记-卷049-外戚世家.md#p026)**

> 王仲蚤死，葬槐裏，追尊為共侯，置園邑二百家。

**本卷说明：** 本篇未独立记追尊年；汉传L10152把追尊接在田蚡至丞相之后，然而同段臧儿前136卒在田蚡前135为相以前，显示这里只按亲属主题总叙，不能将园寝次序强排为一条精确年链。臧儿死亡本身另据武帝纪归前136。

# 未定年｜景帝五宗诸王家事

[本世纪目录](README.md) · [全部世纪](../README.md)

**时间范围：** 景帝诸子在位期间及下一代。封王、去世、废国有确年者另见各年；长期嗜好、官吏处境、宫中纠纷不据受封年倒填发生日期。

<a id="reading-start"></a>

[相关史料](#sources-start)

<a id="sj059-five-mothers-event"></a>

1. **景帝封王诸子分属五位母亲。** 栗姬生刘荣、刘德、刘阏于；程姬生刘余、刘非、刘端；贾夫人生刘彭祖、刘胜；唐姬生刘发；王夫人儿姁生刘越、刘寄、刘乘、刘舜。这十三人先后为藩王，另加后来即位的武帝，景帝共有十四子。儿姁是武帝母王皇后的妹妹，是另一位王夫人。 [[1]](#sj059-five-mothers-note)

<a id="sj059-hejian-learning-event"></a>

2. **河间王刘德好儒学，日常言行也依儒者之道。** 刘德受封河间后，衣着、居处和日常行为都遵儒家规范，崤山以东许多儒生前来从游。他搜求古书，为献书者精抄好本、另加金帛，留下原本；四方献书和讲学的人随之聚集。他所藏多为先秦古文经传，还立毛诗、左氏春秋博士。他入朝献雅乐，回答三雍宫及诏策三十余事，文辞简约、主旨明白。后出的杜业奏议另传武帝问五策，听到回答后不快，加以诘难，又以汤、文从小国兴起的话勉励他；献王领会其中意味，归国纵酒听乐而终。 [[2]](#sj059-hejian-learning-note)

<a id="sj059-lu-lives-event"></a>

3. **鲁王刘余和儿子刘光的嗜好，随人生阶段改变。** 刘余喜欢营建宫室苑囿、狗马，晚年爱音乐，不喜欢辞辩，且有口吃。他的儿子刘光承位以后，最初也好音乐车马，晚年却转而吝啬，唯恐财物不足。 [[3]](#sj059-lu-lives-note)

<a id="sj059-jiangdu-life-event"></a>

4. **江都王刘非好武力、宫观与豪杰。** 刘非喜欢有气力的武士，营造宫观，招徕四方豪杰，生活骄奢。 [[4]](#sj059-jiangdu-life-note)

<a id="sj059-jiaoxi-abuse-event"></a>

5. **胶西王刘端多次侵害宫人和官员，削地以后又弃置政务。** 刘端性情凶暴，传文又记他患阴痿，与妇人接近后往往病数月。他宠爱一少年，任为郎；这人后来与后宫私通，刘端杀他，又杀其子及母。公卿屡请治其罪，皇帝以兄弟之亲宽免；两次削地、去其大半以后，刘端愤怒，不肯整理财产，府库漏坏，巨额财物腐朽，也不搬移，甚至禁官吏收租赋。他撤去宿卫、闭宫门，只留一门出游，时常易名换服往别国。相与二千石如果依法治理，他便搜罪告发，甚至设计下药毒杀无罪者；如果顺王而行，又会受汉法惩处。胶西虽小，传文说被他杀伤的二千石甚多。 [[5]](#sj059-jiaoxi-abuse-note)

<a id="sj059-zhao-officials-event"></a>

6. **赵王刘彭祖以迎奉、记录失言和告发控制中央所置官吏。** 刘彭祖熟悉法律、擅长诡辩，外貌卑恭，内心刻深。每逢汉廷相与二千石来到，他穿黑布衣亲迎、打扫住处，又故意设疑难话题，记录对方触犯忌讳的失言。官员要依法治事，他就拿记录胁迫，不从便告发，或诬以营私。传文以五十余年为王总括，说二千石无能任满两年，重者死、轻者受刑，久而无人敢管。他派人到县，由王家独占商人买卖的居间议价并从中取利，收入超过通常租税，家多金钱，却又散给宠姬诸子。他后来纳江都王刘非旧宠、曾与刘建私通的淖姬，非常宠爱。 [[6]](#sj059-zhao-officials-note)

<a id="sj059-zhao-police-event"></a>

7. **彭祖亲巡盗贼，其太子丹又因江充告发被废。** 彭祖不热衷宫室或求福禨祥，却喜欢吏事，上书请亲督国中盗贼，常夜随走卒巡视邯郸。使者过客觉得他险诈，不敢久留。另一件未确年的家事是太子丹与宾客江充结怨，江充告发其亲属间乱伦，丹被废，赵另立太子。 [[7]](#sj059-zhao-police-note)

<a id="sj059-zhongshan-zhao-event"></a>

8. **中山与赵两位同母兄弟，对王者职责各有说法。** 中山王刘胜爱酒色，传文记子孙支属一百二十余人。他批评哥哥刘彭祖身为王却代官吏治事，说王应每日听音乐、享声色；彭祖反过来斥刘胜只顾淫乐，不助天子抚养百姓，不足称藩臣。 [[8]](#sj059-zhongshan-zhao-note)

<a id="sj059-guangchuan-qi-event"></a>

9. **广川王刘齐与臣桑距结怨，双方接连向朝廷告发。** 刘齐起初宠信桑距，后来桑距获罪，王想杀他；桑距逃亡，刘齐拘捕其宗族。桑距怨恨，上书告齐与同母姊妹乱伦；此后齐又屡次告汉公卿及幸臣所忠等。案情有相互报复的背景。 [[9]](#sj059-guangchuan-qi-note)

<a id="sj059-changsha-dance-event"></a>

10. **长沙王刘发以小舞诉说封地狭小，留下求地的传说。** 后出的应劭说，诸王入朝时奉诏轮流祝寿歌舞，长沙王只张袖稍举手，左右笑他笨拙。景帝问，他借“国小地狭，不足回旋”回答；故事说，皇帝于是把武陵、零陵、桂阳归属长沙。 [[10]](#sj059-changsha-dance-note)

### 2. 河间王刘德好儒学，日常言行也依儒者之道

[返回正文第2条](#sj059-hejian-learning-event)

**归年与释读：** 这是在位期间的风尚，不能只归受封当年。求书、博士、献乐、三十余事据汉传；五策与归纵酒的故事则为集解转引杜业奏议，二者不是同一份现场记录，朝见与转变未得确年。不据后出奏议确定死亡医学原因或武帝的真实内心。

<a id="sj059-cite-009"></a>

**[《史记·五宗世家》P002](../../sources/摘录/史记-卷059-五宗世家.md#p002)**

> 好儒學，被服造次必於儒者。山東諸儒多從之游。

**本卷说明：** 被服造次不只穿儒衣，也指平日实行。藏书细节须以另引汉传为据。

<!-- /sj059-cite-009 -->

<a id="sj059-cite-070"></a>

**[《汉书·景十三王传》河间求书与儒学](../../sources/本地分卷/汉书/汉书-卷053.md#L7836)**

> 河間獻王德以孝景前二年立，修學好古，實事求是。從民得善書，必為好寫與之，留其真，加金帛賜以招之。繇是四方道術之人不遠千里，或有先祖舊書，多奉以奏獻王者，故得書多，與漢朝等。是時，淮南王安亦好書，所招致率多浮辯。獻王所得書皆古文先秦舊書，周官、尚書、禮、禮記、孟子、老子之屬，皆經傳說記，七十子之徒所論。其學舉六藝，立毛氏詩、左氏春秋博士。修禮樂，被服儒術，造次必於儒者。山東諸儒者從而游。

<!-- /sj059-cite-070 -->

<a id="sj059-cite-071"></a>

**[《汉书·景十三王传》献雅乐与对策](../../sources/本地分卷/汉书/汉书-卷053.md#L7837)**

> 武帝時，獻王來朝，獻雅樂，對三雍宮及詔策所問三十餘事。其對推道術而言，得事之中，文約指明。

**本卷说明：** 没有给出这次朝见的确年，不能自动并到刘德所有来朝记录中的任一条。

<!-- /sj059-cite-071 -->

<a id="sj059-cite-072"></a>

**[《集解》转引《汉名臣奏》杜业说](../../sources/史记三家注/卷059.md#p2)**

> 〔集解〕漢名臣奏：「杜業奏曰『河閒獻王經術通明，積德累行，天下雄俊衆儒皆歸之。孝武帝時，獻王朝，被服造次必於仁義。問以五策，獻王輙對無窮。孝武帝艴然難之，謂獻王曰：「湯以七十里，文王百里，王其勉之。」王知其意，歸即縱酒聽樂，因以終』。」

**本卷说明：** 后出杜业奏议经裴骃集解转引，称问五策、武帝以汤文小国勉王使其知意，归纵酒而终；汉传本篇却记问三十余事、文约指明。二者不是同一份现场记录，不据此把刘德定为因饮酒死亡或把武帝猜忌定作已证事实。

### 5. 胶西王刘端多次侵害宫人和官员，削地以后又弃置政务

[返回正文第5条](#sj059-jiaoxi-abuse-event)

**归年与释读：** 这些官员遭害的记载未列逐人年名，故作为长期处境叙述。身体疾病与暴行同见于传文，不等于疾病必然造成残暴；“其子母”代词所指也未获足够证据，不据宽译建立确定谱系。

<a id="sj059-cite-030"></a>

**[《史记·五宗世家》P013](../../sources/摘录/史记-卷059-五宗世家.md#p013)**

> 端為人賊戾，又陰痿，一近婦人，病之數月。而有愛幸少年為郎。為郎者頃之與後宮亂，端禽滅之，及殺其子母。數犯上法，漢公卿數請誅端，天子為兄弟之故不忍，而端所為滋甚。有司再請削其國，去太半。端心慍，遂為無訾省。府庫壞漏盡，腐財物以巨萬計，終不得收徙。令吏毋得收租賦。端皆去衛，封其宮門，從一門出游。數變名姓，為布衣，之他郡國。

**本卷说明：** 其子母的代词关系未获古注明确说明，保留“又杀其子及母”的宽译，不据此给郎的母亲或私生子建立确定谱系。

<a id="sj059-cite-031"></a>

**[《史记·五宗世家》P014](../../sources/摘录/史记-卷059-五宗世家.md#p014)**

<a id="sj059-zhao-officials-note"></a>

### 6. 赵王刘彭祖以迎奉、记录失言和告发控制中央所置官吏

[返回正文第6条](#sj059-zhao-officials-event)

**归年与释读：** 迎官、设问、记录失言与告发是长期生平；纳淖姬更在江都王父子相关事件之后，不倒填到刘彭祖迁赵当年。

<a id="sj059-cite-036"></a>

**[《史记·五宗世家》P017](../../sources/摘录/史记-卷059-五宗世家.md#p017)**

> 彭祖為人巧佞卑諂，足恭而心刻深。好法律，持詭辯以中人。彭祖多內寵姬及子孫。相、二千石欲奉漢法以治，則害於王家。是以每相、二千石至，彭祖衣皁布衣，自行迎，除二千石舍，多設疑事以作動之，得二千石失言，中忌諱，輒書之。二千石欲治者，則以此迫劫；不聽，乃上書告，及汙以姦利事。彭祖立五十餘年，相、二千石無能滿二歲，輒以罪去，大者死，小者刑，以故二千石莫敢治。而趙王擅權，使使即縣為賈人榷會，入多於國經租稅。以是趙王家多金錢，然所賜姬諸子，亦盡之矣。彭祖取笔江都易王寵姬王建所盜與姦淖姬者為姬，甚愛之。

**本卷说明：** TXT取笔与三家注、汉传取故不同；原引保留笔，白话据语义释原江都宠姬。五十余年也不等于给每次官员遭害虚造年次。

<!-- /sj059-cite-036 -->

<a id="sj059-cite-078"></a>

**[《汉书·景十三王传》淖姬](../../sources/本地分卷/汉书/汉书-卷053.md#L7867)**

> 彭祖取江都易王寵姬，王建所姦淖姬者，甚愛之，生一男，號淖子。

**本卷说明：** 与三家注主文取故对读，主TXT取笔照存；此处只证入赵对象，后世嗣位故事另属汉传范围。

<a id="sj059-zhao-police-note"></a>

### 7. 彭祖亲巡盗贼，其太子丹又因江充告发被废

[返回正文第7条](#sj059-zhao-police-event)

**归年与释读：** 史篇作与其女及同母姊，汉传作女弟及同母姊；不得将两种文字相加造更多对象。告发背景、罪状与后果分别保存，本篇未载确年。

<a id="sj059-cite-037"></a>

**[《史记·五宗世家》P018](../../sources/摘录/史记-卷059-五宗世家.md#p018)**

> 彭祖不好治宮室、禨祥，好為吏事。上書願督國中盜賊。常夜從走卒行徼邯鄲中。諸使過客以彭祖險陂，莫敢留邯鄲。

<!-- /sj059-cite-037 -->

<a id="sj059-cite-038"></a>

**[《史记·五宗世家》P019](../../sources/摘录/史记-卷059-五宗世家.md#p019)**

> 其太子丹與其女及同產姊姦，與其客江充有卻。充告丹，丹以故廢。趙更立太子。

**本卷说明：** 告发背景、罪状与后果分别叙述；本篇无确年，不把江充后来在武帝朝的所有事件移进同一年度。

<a id="sj059-cite-082"></a>

**[《汉书·景十三王传》太子丹案异文](../../sources/本地分卷/汉书/汉书-卷053.md#L7866)**

**本卷说明：** 此处汉传作“女弟及同产姊”，史篇作“其女及同产姊”；分别保留文字，不将两种对象名单相加。其余案件续事见完整汉传，本条不另据之虚定日期。

### 8. 中山与赵两位同母兄弟，对王者职责各有说法

[返回正文第8条](#sj059-zhongshan-zhao-event)

**归年与释读：** 二人的相互指摘表达各自理想，不直接当作成文汉法；“子枝属”也不只等于亲生儿子数。

<a id="sj059-cite-041"></a>

**[《史记·五宗世家》P020](../../sources/摘录/史记-卷059-五宗世家.md#p020)**

> 勝為人樂酒好內，有子枝屬百二十餘人。常與兄趙王相非，曰：「兄為王，專代吏治事。王者當日聽音樂聲色。」趙王亦非之，曰：「中山王徒日淫，不佐天子拊循百姓，何以稱為藩臣！」

**本卷说明：** 主文子枝属不只等于亲生儿子数，汉传子字口径另存。

### 9. 广川王刘齐与臣桑距结怨，双方接连向朝廷告发

**归年与释读：** 各项罪状按告发记录呈现。所忠是姓名，不是泛指忠臣；汉传作乘距，与桑距保留异名。“同产”在此释同母姊妹，不增加受指控的男性亲属。

<a id="sj059-cite-052"></a>

**本卷说明：** 原文与同产奸，汉传同文，白话取同母姊妹之指控，不扩增男性兄弟为受指控对象。

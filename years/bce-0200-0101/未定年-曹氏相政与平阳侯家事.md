# 未定年｜曹氏相政与平阳侯家事

[前201年相齐](../bce-0300-0201/bce-0201.md) · [前193年入汉相](bce-0193.md) · [前190年曹参卒](bce-0190.md) · [本世纪目录](README.md) · [全部世纪](../README.md)

本页第1条限曹参相齐时期（前201—前193），第2—4条限相汉时期（前193—前190）。第5、6条另读曹时、曹襄生前未定年的家事，不把婚姻、生子、患病安在承侯元年或死亡当年。各条有相对范围，没有足够证据补成某月某日。

<a id="reading-start"></a>

[本页相关史料](#sources-start)

<a id="sj054-event-1"></a>

1. **曹参问儒、聘盖公，以清静之术安齐。** 齐有七十城，齐王刘肥尚年轻，曹参遍召长老、儒者询问依齐俗安定百姓的办法；数百儒者各执一说，使他难以决断。他听说胶西盖公善黄老学，派人厚礼迎请。盖公讲治道贵清静、民自安定，并详说其意；曹参让出正堂给他居住，施政大体采用黄老之术。相齐九年，齐国安定，人们称他为贤相。这是一段任期内的渐进选择。 [[1]](#sj054-note-1)

<a id="sj054-event-2"></a>

2. **曹参择质朴厚重之吏，用酒止住纷纷进言。** 他挑选郡国中不善修饰文辞、为人厚重的长者，召为丞相史，斥退苛刻深文、追求声名的人。卿大夫、属吏和宾客见他常饮酒，想来劝说；人一到，他便以醇酒相劝，稍见对方要开口，又接着劝饮，直到客人喝醉离开，终究未能陈言。 [[2]](#sj054-note-2)

<a id="sj054-event-3"></a>

3. **相舍后园与吏舍相和歌，细过不加张扬。** 吏舍靠近相舍后园，饮酒歌呼声常传过来。随从厌恶而不能禁止，便请曹参游园，盼他听见后查办；曹参却设坐取酒，也唱起来，与对方相和。他平时见人有细小过失，常加以遮护，府中因此少事。 [[3]](#sj054-note-3)

<a id="sj054-event-4"></a>

4. **曹窋受命谏父，惠帝亲自询问守成之意。** 曹窋当时任中大夫。惠帝怀疑曹参轻视自己，暗命他趁休沐回家，问父亲为何高帝新丧、皇帝年少，自己却只饮酒而不请示政事，并嘱不得泄露授意。曹窋依言进谏，曹参发怒，笞他二百，叫他赶快回宫侍奉，勿议天下事。后来惠帝在朝堂责问，承认由自己授意。曹参免冠谢罪，先问惠帝与高帝谁更英明勇武，再问自己与萧何谁更贤能；惠帝都认为不及前人。曹参遂说，高帝、萧何已经定天下、明法令，如今君主安然主持，臣下守职，遵循而不失，不也很好？惠帝认可，让他退下。 [[4]](#sj054-note-4)

<a id="sj054-event-5"></a>

5. **曹时尚平阳公主，患病后归国。** 曹奇之子曹时娶平阳公主，生子曹襄；后来曹时患癞病，返回封国。这些家事发生在他生前不同阶段，确切年日未明。平阳公主后来的婚姻另见[武帝宫廷与外家](未定年-武帝宫廷与外家.md)。 [[5]](#sj054-note-5)

<a id="sj054-event-6"></a>

6. **曹襄尚卫长公主，生子曹宗。** 曹襄是曹时与平阳公主之子，娶卫长公主，生子曹宗；婚礼和曹宗出生的确年未明。曹襄侯元年见[前130年](bce-0130.md)，去世、曹宗承接见[前115年](bce-0115.md)。 [[6]](#sj054-note-6)

**[《史记·曹相国世家》P009](../../sources/摘录/史记-卷054-曹相国世家.md#p009)**

> 參之相齊，齊七十城。天下初定，悼惠王富於春秋，參盡召長老諸生，問所以安集百姓，如齊故［俗］諸儒以百數，言人人殊，參未知所定。聞膠西有蓋公，善治黃老言，使人厚幣請之。既見蓋公，蓋公為言治道貴清靜而民自定，推此類具言之。參於是避正堂，舍蓋公焉。其治要用黃老術，故相齊九年，齊國安集，大稱賢相。

**本卷说明：** 齐相九年是整个前201—前193任期，篇首惠帝元年只管改官称一句。主TXT故［俗］的补字、注本“如齐故俗。诸儒”句读分存。

### 4. 曹窋受命谏父，惠帝亲自询问守成之意

[返回正文第4条](#sj054-event-4)

<a id="sj054-cite-044"></a>

**[《史记·曹相国世家》P015](../../sources/摘录/史记-卷054-曹相国世家.md#p015)**

> 參子窋為中大夫。惠帝怪相國不治事，以為「豈少朕與」？乃謂窋曰：「若歸，試私從容問而父曰：『高帝新棄群臣，帝富於春秋，君為相，日飲，無所請事，何以憂天下乎？』然無言吾告若也。」窋既洗沐歸，窋侍，自從其所諫參。參怒，而笞窋二百，曰：「趣入侍，天下事非若所當言也。」至朝時，惠帝讓參曰：「與窋胡治乎？乃者我使諫君也。」參免冠謝曰：「陛下自察聖武孰與高帝？」上曰：「朕乃安敢望先帝乎！」曰：「陛下觀臣能孰與蕭何賢？」上曰：「君似不及也。」參曰：「陛下言之是也。且高帝與蕭何定天下，法令既明，今陛下垂拱，參等守職，遵而勿失，不亦可乎？」惠帝曰：「善。君休矣！」

**本卷说明：** 少朕按索隐“以我为不足”释轻视，古注另有嫌皇帝年少一说；窋中大夫不得提前译为御史。二百笞原数照记，不假补刑具、执行日或伤势。

## 归年与考证

齐相九年按前201至前193首尾计，汉相三年按前193七月至前190八月的任职时段理解。家事各按人物一生范围阅读，不能仅凭篇末相接便造出共同年代。[任期与侯年核对](../../meta/记录/史记-卷054-任期与侯年核对.md)

# 未定年｜梁孝王宫苑与梁平王家事

[本世纪目录](README.md) · [全部世纪](../README.md)

**时间范围：** 文景时期至梁孝王前144年去世；梁平王家事在元朔年间（前129—124）及原文十四年（推前123）等异年框架内。各条分述，不把两代王混为同一人。

<a id="reading-start"></a>

[相关史料](#sources-start)

<a id="sj058-palaces-event"></a>

1. **梁国在文景时期逐渐形成庞大的宫苑、兵器和宾客网络。** 刘武因窦太后宠爱而屡得赏赐，七国之乱中的战功又增重其地位。梁处富庶之地，北界泰山、西至高阳，四十多城多为大县。孝王扩睢阳、营东苑，宫殿与平台以复道相接；传记称东苑方三百余里、扩城七十里、复道三十余里。他获赐天子旌旗，出入警跸，千乘万骑随从，驰猎排场近似天子。羊胜、公孙诡、邹阳等游士来归；公孙诡初见获千金，后来为中尉，号公孙将军。梁制造弩弓矛数十万，府库金钱近百巨万，珠玉宝器被说比京师更多。后代地理书还留下筑城时击鼓领唱、应节下杵的传说，所歌称睢阳曲。 [[1]](#sj058-palaces-note)

<a id="sj058-vessel-case-event"></a>

2. **梁平王与祖母争夺罍樽，告发使王后被诛、王国削地。** 梁平王刘襄的母亲是陈太后，父亲刘买的母亲李太后则是他的亲祖母。孝王遗下一件值千金的罍樽，嘱后代珍藏，不得送人；任王后想要，李太后允许她随意取其他巨额财物，唯独不许动罍樽。刘襄仍开库赐给任后。汉使来到时，李太后想申诉，王与任后闭门阻止，争门夹伤她的手指。传文又指李太后与食官长、郎中尹霸等私通，王后夫妇据此使人威胁，她便作罢。她病死时，任后不探病、不服丧。后来睢阳人类犴反为报父仇，杀死与淮阳太守门客同车的仇人后逃亡；太守责梁官，官府追捕并拘其亲属。类犴反便借所知宫中隐事告王，也想牵连知情的长吏。朝廷查实争樽等事，公卿请废王；武帝责李太后行为不检、梁王缺乏良师傅，终于削梁八城、枭任后首于市，传称梁尚余十城。 [[2]](#sj058-vessel-case-note)

<a id="sj058-palaces-note"></a>

### 1. 梁国在文景时期逐渐形成庞大的宫苑、兵器和宾客网络

[返回正文第1条](#sj058-palaces-event)

**归年与释读：** 营建、积财与招客持续多年，起讫日未能独立确认。原传“方三百余里”、城与复道长度、武备及金钱数量分别照录，不折作已核实的现代面积和资产。睢阳曲见古注转引后代地理书，属于营建传说。

<a id="sj058-cite-020"></a>

**[《史记·梁孝王世家》P005](../../拆分史书/史记/卷058.md#p005)**

> 其後梁最親，有功，又為大國，居天下膏腴地。地北界泰山，西至高陽，四十餘城，皆多大縣。

<!-- /sj058-cite-020 -->

<a id="sj058-cite-021"></a>

**[《史记·梁孝王世家》P006](../../拆分史书/史记/卷058.md#p006)**

> 孝王，竇太后少子也，愛之，賞賜不可勝道。於是孝王筑東苑，方三百餘里。廣睢陽城七十里。大治宮室，為複道，自宮連屬於平臺三十餘里。得賜天子旌旗，出從千乘萬騎。東西馳獵，擬於天子。出言蹕，入言警。招延四方豪桀，自山以東游說之士。莫不畢至，齊人羊勝、公孫詭、鄒陽之屬。公孫詭多奇邪計，初見王，賜千金，官至中尉，梁號之曰公孫將軍，梁多作兵器弩弓矛數十萬，而府庫金錢且百巨萬，珠玉寶器多於京師。

**本卷说明：** 本段无施工确年；索隐对苑方三百余里的夸大即有辨析。公孙诡之任官是梁国官，不是中央另一位同姓将军。

<!-- /sj058-cite-021 -->

<a id="sj058-cite-059"></a>

**[《索隐》东苑方三百余里](../../拆分史书/史记/卷058.md#part-2-p5)**

> 〔索隱〕蓋言其奢，非實辭。或者梁國封域之方。

**本卷说明：** 古注已有夸言或封域范围两解，不作核实的苑墙测绘。

<!-- /sj058-cite-059 -->

<a id="sj058-cite-060"></a>

**[《索隐》引《太康地理记》筑城歌](../../拆分史书/史记/卷058.md#part-2-p5)**

> 太康地理記云：「城方十三里，梁孝王築之，鼓倡節杵而後下和之者，稱睢陽曲。今踵以爲故，所以樂家有睢陽曲，蓋釆其遺音也。」

**本卷说明：** 后代地理书把筑城号子与睢阳曲相连，是后出叙事的声音记忆，不据以补确切营建年或复原乐谱。

### 2. 梁平王与祖母争夺罍樽，告发使王后被诛、王国削地

[返回正文第2条](#sj058-vessel-case-event)

**归年与释读：** 起笔“十四年”与后文“元朔中”不能直接合为一年。孝王遗物、争樽、李太后病死、杀仇告发与判决也有前后，不压为一天；故放时期页。削八城、余十城为史篇原数，与汉传不同，均见下引。

<a id="sj058-cite-042"></a>

**[《史记·梁孝王世家》P016](../../拆分史书/史记/卷058.md#p016)**

> 梁平王襄十四年，母曰陳太后。共王母曰李太后。李太后，親平王之大母也。而平王之后姓任，曰任王后。任王后甚有寵於平王襄。初，孝王在時，有罍樽，直千金。孝王誡後世，善保罍樽，無得以與人。任王后聞而欲得罍樽。平王大母李太后曰：「先王有命，無得以罍樽與人。他物雖百巨萬，猶自恣也。」任王后絕欲得之。平王襄直使人開府取罍樽，賜任王后。李太后大怒，漢使者來，欲自言，平王襄及任王后遮止，閉門，李太后與爭門，措指，遂不得見漢使者。李太后亦私與食官長及郎中尹霸等士通亂，而王與任王后以此使人風止李太后，李太后內有淫行，亦已。後病薨。病時，任后未嘗請病；薨，又不持喪。

**本卷说明：** 平王前136元年，十四年推前123；后文却明记元朔中（前129—124）。元朔中不能无说明改元狩。婆孙关系、任后与陈太后两人各明。

<!-- /sj058-cite-042 -->

<a id="sj058-cite-043"></a>

**[《史记·梁孝王世家》P017](../../拆分史书/史记/卷058.md#p017)**

> 元朔中，睢陽人類犴反者，人有辱其父，而與淮陽太守客出同車。太守客出下車，類犴反殺其仇於車上而去。淮陽太守怒，以讓梁二千石。二千石以下求反甚急，執反親戚。反知國陰事，乃上變事，具告知王與大母爭樽狀。時丞相以下見知之，欲以傷梁長吏，其書聞天子。天子下吏驗問，有之。公卿請廢襄為庶人。天子曰：「李太后有淫行，而梁王襄無良師傅，故陷不義。」乃削梁八城，梟任王后首于市。梁餘尚有十城。

**本卷说明：** 本篇梁削八余十，汉传削五余八；本篇淮阳太守与汉传其他地名、人名异字各存。类犴反是告发者姓名，反不作此处谋反动词。

<!-- /sj058-cite-043 -->

<a id="sj058-cite-066"></a>

**[《汉书·文三王传》梁宫案异叙](../../拆分史书/汉书/卷047.md#part-1-L7558)**

> 元朔中，睢陽人犴反，人辱其父，而與睢陽太守客俱出同車。犴反殺其仇車上，亡去。睢陽太守怒，以讓梁二千石。二千石以下求反急，執反親戚。反知國陰事，乃上變告梁王與大母爭尊狀。時相以下具知之，欲以傷梁長吏，書聞。天子下吏驗問，有之。公卿治，奏以為不孝，請誅王及太后。天子曰：「首惡失道，任后也。朕置相吏不逮，無以輔王，故陷不誼，不忍致法。」削梁王五縣，奪王太后湯沐成陽邑，梟任后首于市，中郎胡等皆伏誅。梁餘尚有八城。

**本卷说明：** 汉传犴反、睢阳太守与本篇类犴反、淮阳太守不同；又奏请诛王及太后、削五县、夺陈太后成阳邑并诛中郎胡等，较本篇请废襄、削八城余十城有所出入。保留两套叙述，不合成一项判决。

# 汉武帝时期｜宫廷与外家（未定年）

[本世纪目录](README.md) · [全部时间目录](../README.md) · [纪年与异说](../../拆分史书/史记/卷049.md#kao-7a6c192d94)

**时间精度：有上下限的时期材料与后世评议。** 本页收录武帝前141即位至前87去世之间不能逐项确年的宫廷故事、外家关系，以及与这些材料相连的史家议论。范围跨越两个世纪，文件置于武帝即位所在世纪，并连接后一个世纪。各组另列可知上下限，排列只供阅读，不证明实际先后；晚年钩弋之死仅置前91—前87范围。司马迁、褚少孙、唐代司马贞的论说另明作者，尤其不把唐赞编作汉代事件。

<a id="sj049-author-preface-event"></a>

1. **司马迁以婚姻、外家与命运讨论帝王政治。** 他追溯夏商周的后妃传说，认为创业与守成不仅靠君德，也有外家相助；以《易》的乾坤、《诗》的《关雎》、《书》的帝女下嫁和《春秋》亲迎之礼说明夫妇为人伦大事，又把夫妇和谐与阴阳、四时、万物生成相联系。与此同时，他承认相爱不能由君父强迫，有子孙也未必能善终，因而感叹命难言。这是汉代史家的篇首议论，所举兴亡归因和天命观分别作为他的解释保存。 [[1]](#sj049-author-preface-note)

<a id="sj049-weizifu-recalled-event"></a>

2. **初入宫一年多，卫子夫才再次受到武帝宠幸。** 她一直没有再被召见，直到皇帝选择不再留用的宫人遣归，才有机会哭着请求出宫。武帝怜惜她，再次召幸，此后怀孕，宠爱与地位逐步上升；卫长君、卫青兄弟被召为侍中。这是前139入宫以后的过程，第一次有孕与后来生下刘据分别看待。 [[2]](#sj049-weizifu-recalled-note)

<a id="sj049-chen-dispute-event"></a>

3. **陈皇后与卫子夫争宠，失位后又引出两位公主的争论。** 陈氏得知卫子夫大受宠爱，愤怒到数次几乎死去，武帝也愈加不满。她为求子曾付医生钱九千万，始终没有孩子。前130被废以后，母亲刘嫖多次责备平阳公主：皇帝没有自己的帮助便不能立，如今却抛弃女儿，为什么不自重而背弃根本？平阳公主回答，是没有儿子才废后。这些求医、争宠和被废后的责问有不同先后，故事本身没有逐项日历。 [[3]](#sj049-chen-dispute-note)

<a id="sj049-wangli-consorts-event"></a>

4. **卫皇后年长以后，赵地王夫人、中山李夫人先后受宠。** 赵地王夫人生刘闳，后来为齐王。刘闳将要封王时，王夫人患病，武帝探问她希望儿子封在哪里；她起初辞让，继而希望封在洛阳。武帝以洛阳为武库、敖仓所在的天下要冲、汉朝大都会，先帝以来没有皇子封王于此，另提齐国背海、城郭大、田地丰饶，她便用手拍头，称谢说十分有幸。王夫人去世，武帝悲痛，派太中大夫明奉璧追赐齐王太后号。后来中山李夫人得宠，生刘髆，后来为昌邑王。另一位李姬生刘旦、刘胥，分别为燕王、广陵王，她未受宠，在忧愁中去世。三位女子不得合为一人；生育、受宠及死亡年月未详，诸王受封另见前117与前97年。[[4]](#sj049-wangli-consorts-note)

<a id="sj049-li-family-event"></a>

5. **李夫人去世后，李延年兄弟也遭族诛，李广利一度在外免祸。** 李延年原为歌唱艺人，以音乐得武帝宠爱，任协律。兄弟后来因奸罪受族诛；这段传记把清洗与长兄李广利任贰师将军、出征大宛相联系，说他在外而未受诛。李广利回朝以后另在前101年受封海西侯。李夫人死亡与李延年案的先后按原篇保留，具体发生年不能据这一段确定。 [[5]](#sj049-li-family-note)

<a id="sj049-yin-xing-event"></a>

6. **李夫人去世以后，尹婕妤、邢夫人等受到宠爱。** 尹氏位号为婕妤，邢氏号娙娥，俗称娙何；褚氏所述位号以娙何比中二千石、容华比二千石、婕妤比列侯，并说皇后常从婕妤中升立；这是爵秩类比与升迁惯例，不是人人依次自动成为皇后。她们受宠的具体年份未详，尹婕妤也不是文帝朝的尹姬。 [[6]](#sj049-yin-xing-note)

<a id="sj049-xiucheng-event"></a>

7. **武帝即位后，亲自到长陵迎回母亲与金王孙所生的女儿。** 韩嫣告诉皇帝，太后另有女儿住在长陵，武帝问为何不早言，先遣人查访，确认后亲自出发。持旄旗的骑士先导，车骑清道出横城门，赶到小市西的里巷，突然打开关闭的里门，直抵金家，以武骑围宅，防止她逃离。群臣入内呼唤，家人惊恐，她藏在床下，被扶出拜见。武帝下车流泪，称她“大姊”，问为何藏得如此深，命副车载回长乐宫，沿路命宫门登记引见名籍，准其通行入谒。太后问皇帝从何处劳累回来，他说在长陵找到姐姐，令她拜见；母女相认，双双哭泣。武帝奉酒祝寿，赐姊钱千万、奴婢三百人、公田百顷和甲第，太后谢称让皇帝破费。平阳、南宫、隆虑三公主也奉召来见，姐姐受号修成君。她另有一子一女，儿子称修成子仲，因太后怜爱而骄横，欺压官民；女儿的婚配对象，原篇与古注各有不同称谓。这是褚少孙转述钟离生的旧闻，迎姊与后辈行为不是同一次事件。 [[7]](#sj049-xiucheng-note)

<a id="sj049-wei-repute-event"></a>

8. **卫氏显贵以后，亲属身份与民间评价一同变化。** 褚少孙记卫伉作为侯世子，常在宫中侍从而受宠，并引民歌劝人不必因生男而喜、生女而怒，只看卫子夫便能使一家如此显贵。歌中的“霸天下”是对权势的夸张，不是另有卫氏取代汉朝；卫伉侍从之事没有确年。 [[8]](#sj049-wei-repute-note)

<a id="sj049-pingyang-weiqing-event"></a>

9. **平阳公主再择丈夫时，接受了与卫青结婚的建议。** 她与左右商量长安列侯中谁适合做夫婿，众人都推大将军。公主笑说，卫青本是自己家里的人，曾骑马随从、听命出入，怎么能成为丈夫？侍从回答，他的姐姐已是皇后，三子都为侯，富贵震动天下，还有谁更合适？公主同意，先告诉卫皇后，再由皇后转告武帝，武帝于是下诏成婚。褚补以公主寡居作背景，婚期未详。 褚少孙据此感叹男子可如龙变化，引蛇化为龙不改纹、家化为国不改姓，认为得时富贵会遮去旧日缺陷，贫贱出身不该继续成为负累。 [[9]](#sj049-pingyang-weiqing-note)

<a id="sj049-yin-xing-story-event"></a>

10. **尹夫人请求见邢夫人，武帝先让另一女子冒名来见。** 两人同时受宠，皇帝原令不得相见。尹氏求见，武帝答应，先让另一夫人盛装，由数十名侍从陪同而来。尹氏立即说不是邢夫人本人；问她何以知道，她答其身貌不足以配人主。武帝才令真正的邢夫人穿旧衣、独自走来。尹氏远望便认定这才是真人，随即低头流泪，悲伤自觉不及。褚补用“美女入室，恶女之仇”概括这一场景，说美女进屋便成为容貌不美者的仇敌，呈现的是故事中人以容貌争宠的压力。 褚少孙又以洗澡要在去垢而不必江海、良马要在善跑而不必骐骥为比，说士重知道、不必世代贤显，女子重贞正美好、不必出自贵族；他再引女子入室见妒、士人入朝见嫉的格言，提出与篇本文门第论不同的看法。 [[10]](#sj049-yin-xing-story-note)

<a id="sj049-yan-suwei-event"></a>

11. **前91至前87年之间，燕王刘旦请求入京宿卫，触怒武帝。** 卫太子刘据败亡以后，新太子尚未确定，刘旦上书求亲自入长安宿卫。武帝把奏书掷在地上，斥责儿子在燕赵长成，生出了争位、不肯谦让的心意，随即派人斩其使者于宫阙下。遇害的是使者，刘旦此后仍在燕国；他后来在昭帝朝的两次谋反分见前86、前80年。[[11]](#sj049-yan-suwei-note)

<a id="sj049-gouyi-death-event"></a>

12. **武帝晚年决定幼子继承的过程中，钩弋夫人受到谴责而死。** 这一传述在前91至前87年的范围内：武帝居甘泉宫，命画工画周公负成王的图像，左右由此知道他想立少子。数日后，他责罚钩弋夫人；夫人摘下簪珥叩头，皇帝命送掖庭狱，她回顾时又被喝令快走，并被告知不能活。她死在云阳宫，使者夜间带棺安葬、封土标识；篇中还写暴风扬尘与百姓感伤。后来武帝问外间议论，左右说人们不解，既然将立其子，为何除其母。他以主少母壮、母后可能骄纵、放纵淫乱而无人约束为理由，举吕后为鉴。这是褚少孙保留的解释与辩护；他又赞扬武帝为后世深虑，声称生过子女的诸母无不被谴死。该概论没有可核的完整名单，不据它把所有后宫女子都改记为处死。 [[12]](#sj049-gouyi-death-note)

<a id="sj049-later-praise-event"></a>

13. **唐代司马贞从礼制与后妃德行总结这一卷。** 述赞以乾坤、日月、河洲和轩辕星象比喻夫妇之道，赞太任、太姒、有娀、姜嫄，再概括吕后掌权、窦后尊黄老，批评其后因宠爱而立妃、内廷缺少稳定之主。这些是唐代注家的韵语评议，另附在汉代材料之后阅读。 [[13]](#sj049-later-praise-note)

### 5. 李夫人去世后，李延年兄弟也遭族诛，李广利一度在外免祸

[返回正文第5条](#sj049-li-family-event)

### 7. 武帝即位后，亲自到长陵迎回母亲与金王孙所生的女儿

**[《史记·外戚世家》P036](../../拆分史书/史记/卷049.md#p036)**

> 褚先生曰：臣為郎時，問習漢家故事者鐘離生。曰：王太后在民閒時所生（子）［一］女者，父為金王孫。王孫已死，景帝崩後，武帝已立，王太后獨在。而韓王孫名嫣素得幸武帝，承閒白言太后有女在長陵也。武帝曰：「何不蚤言！」乃使使往先視之，在其家。武帝乃自往迎取之。蹕道，先驅旄騎出橫城門，乘輿馳至長陵。當小市西入里，里門閉，暴開門，乘輿直入此里，通至金氏門外止，使武騎圍其宅，為其亡走，身自往取不得也。即使左右群臣入呼求之。家人驚恐，女亡匿內中床下。扶持出門，令拜謁。武帝下車泣曰：「嚄！大姊，何藏之深也！」詔副車載之，迴車馳還，而直入長樂宮。行詔門著引籍，通到謁太后。太后曰：「帝倦矣，何從來？」帝曰：「今者至長陵得臣姊，與俱來。」顧曰：「謁太后！」太后曰：「女某邪？」曰：「是也。」太后為下泣，女亦伏地泣。武帝奉酒前為壽，奉錢千萬，奴婢三百人，公田百頃，甲第，以賜姊。太后謝曰：「為帝費焉。」於是召平陽主、南宮主、林慮主三人俱來謁見姊，因號曰修成君。有子男一人，女一人。男號為修成子仲，女為諸侯王王后。此二子非劉氏，以故太后憐之。修成子仲驕恣，陵折吏民，皆患苦之。

> 上居甘泉宮，召畫工圖畫周公負成王也。於是左右群臣知武帝意欲立少子也。後數日，帝譴責鉤弋夫人。夫人脫簪珥叩頭。帝曰：「引持去，送掖庭獄！」夫人還顧，帝曰：「趣行，女不得活！」夫人死雲陽宮。時暴風揚塵，百姓感傷。使者夜持棺往葬之，封識其處。其後帝閒居，問左右曰：「人言云何？」左右對曰：「人言且立其子，何去其母乎？」帝曰：「然。是非兒曹愚人所知也。往古國家所以亂也，由主少母壯也。女主獨居驕蹇，淫亂自恣，莫能禁也。女不聞呂后邪？」故諸為武帝生子者，無男女，其母無不譴死，豈可謂非賢聖哉！昭然遠見，為後世計慮，固非淺聞愚儒之所及也。謚為「武」，豈虛哉！

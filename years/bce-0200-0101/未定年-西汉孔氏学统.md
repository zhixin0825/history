# 西汉｜孔氏学统与后世纪念（未定年）

[本世纪目录](README.md) · [全部时间目录](../README.md) · [孔子及后裔纪年](../../拆分史书/史记/卷047.md#kao-c0f550d22d)

**时间精度：未定年与分期传述。** 本页集中无逐年记载的孔氏汉代官历、孔里孔庙传承和司马迁访古之论。惠帝、武帝只给活动时期，不能由寿数和世次倒算各人生卒。墓地和学统的形成追溯孔子身后，其后两百余年的延续不全压在孔子卒年或高帝祭孔年。

<a id="sj047-shrine-event"></a>

1. **孔子墓地与故居逐渐成为孔氏和儒者的祭祀、讲礼场所。** 孔子去世以后，弟子和鲁人有一百多家居墓旁，称孔里；鲁地按时祭祀，儒者在此讲礼、习乡饮和大射。墓域、故居以及所藏衣冠琴车书籍，使纪念持续到汉代。这里概述两百余年的传承，不把后世建筑和礼俗全回置前479。 [[1]](#sj047-shrine-note)

<a id="sj047-hui-event"></a>

2. **汉惠帝时期，孔子襄任博士，后来任长沙太守。** 本篇称他是孔鲋之弟，年五十七，形容高九尺六寸；官职次序有记，实际任命年与死亡年没有交代。惠帝时期可作时代范围，不能把一生都压在惠帝元年。 [[2]](#sj047-hui-note)

<a id="sj047-wu-event"></a>

3. **孔忠、孔武之后，孔安国进入汉武帝时期的博士与地方官体系。** 子襄生忠，忠生武，武生延年、安国；安国任博士，后来官至临淮太守，较早去世，又有子卬、孙驩。这是一条无逐年任免的世系官历，不能由“今皇帝”或“早卒”反算具体生卒。 [[3]](#sj047-wu-note)

<a id="sj047-sima-event"></a>

4. **司马迁到鲁访孔庙，把所见礼器与持续的尊孔传统相连。** 他读孔氏之书而向往其人，看到庙堂车服礼器、儒生按时习礼，流连难去。他比较众多君王贤者身后声名易衰，而孔子布衣传十余世仍受学者尊崇，天子王侯谈六艺也以其为准，因而称为至圣。这是汉代史家的观察和评价，不是孔子卒年已经形成的全民公论。 [[4]](#sj047-sima-note)

### 1. 孔子墓地与故居逐渐成为孔氏和儒者的祭祀、讲礼场所

<a id="sj047-cite-104"></a>

**[《史记·孔子世家》P078](../../拆分史书/史记/卷047.md#p078)**

> 弟子及魯人往從冢而家者百有餘室，因命曰孔里。魯世世相傳以歲時奉祠孔子冢，而諸儒亦講禮鄉飲大射於孔子冢。孔子冢大一頃。故所居堂弟子內，後世因廟藏孔子衣冠琴車書，至于漢二百餘年不絕。

### 3. 孔忠、孔武之后，孔安国进入汉武帝时期的博士与地方官体系

[返回正文第3条](#sj047-wu-event)

<a id="sj047-cite-111"></a>

**[《史记·孔子世家》P084](../../拆分史书/史记/卷047.md#p084)**

> 子襄生忠，年五十七。忠生武，武生延年及安國。安國為今皇帝博士，至臨淮太守，蚤卒。安國生卬，卬生驩。

**本卷说明：** “今皇帝”为史家所处汉武帝；若讨论文本形成层次，不以一句相对称谓冒作记录于哪一年。

<a id="sj047-sima-note"></a>

### 4. 司马迁到鲁访孔庙，把所见礼器与持续的尊孔传统相连

[返回正文第4条](#sj047-sima-event)

<a id="sj047-cite-112"></a>

**[《史记·孔子世家》P085](../../拆分史书/史记/卷047.md#p085)**

> 太史公曰：《詩》有之：「高山仰止，景行行止。」雖不能至，然心鄉往之。余讀孔氏書，想見其為人。適魯，觀仲尼廟堂車服禮器，諸生以時習禮其家，余祗回留之不能去云。天下君王至於賢人衆矣，當時則榮，沒則已焉。孔子布衣，傳十餘世，學者宗之。自天子王侯，中國言六藝者折中於夫子，可謂至聖矣！

**本卷说明：** 太史公评论单列作者层次；唐代述赞另附前479丧事同号注，不充为汉代当时之言。

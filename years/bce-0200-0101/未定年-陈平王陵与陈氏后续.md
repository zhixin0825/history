# 楚汉至武帝时期｜陈平、王陵与陈氏后续（未定年）

[汉代世纪目录](README.md) · [全部时间目录](../README.md) · [纪年与异说](../../拆分史书/史记/卷056.md#kao-984157a56f)

**时间精度：各组分别给出相对次序或时期，不能合成一个同时发生的年段。** 王陵母的事在王陵归汉以后、楚汉战争期间；吕媭与陈平的故事在高后任相期间；陈平自警在其生前，而陈掌求续封属于武帝时陈氏失侯后的后续。已有确年的归汉、任相、死亡和除国仍回各年页。

<a id="reading-start"></a>

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **楚汉战争中，王陵母亲以死促使儿子坚守汉方。** 王陵率兵归汉后，项羽把他的母亲留在军中，王陵的使者一到，就让她向东坐在尊位，想借母子之情招回王陵。她私下哭着嘱咐使者：汉王是长者，叫王陵好好事奉，不要为了自己有二心；随即伏剑而死，项羽发怒又烹其尸。事件在[前205年归汉](../bce-0300-0201/bce-0205.md)之后、[前202年楚亡](../bce-0300-0201/bce-0202.md)以前，未详年月。 [[1]](#note-1)

<a id="event-2"></a>

2. **高后执政时，陈平以饮酒嬉戏应对吕媭进谗。** 吕媭因樊哙曾被拘捕而怨陈平，指他为相不治事、每日饮醇酒与妇女嬉戏。陈平听说，反而加甚；吕后暗喜，当面告诫不要畏惧吕媭，只看陈平与自己的关系。吕后引用的轻视妇女之语是传中当事人的话，不能成为对妇女的一般判断。本组限于陈平在高后朝任相期间，前187—前180，不把未载月年的故事全放在迁右相当天。 [[2]](#note-2)

<a id="event-3"></a>

3. **陈平生前曾担忧隐秘谋划会殃及后代。** 他自言多用阴谋，有违道家禁忌，即使家世以后废绝也无可奈何。这是陈平的自我警惕，原文只说“始”，没有说话年份，亦未说就在临终。陈平卒于[前178年](bce-0178.md#note-1)，这句话属于此前，不能凭后代国除证明报应。 [[3]](#note-3)

<a id="event-4"></a>

4. **陈氏失侯以后，陈掌求续封未成。** 陈平曾孙陈掌因与卫氏相亲而贵，想续陈氏封爵，最终没有实现。曲逆侯陈何的刑案与国除在[前130年](bce-0130.md)，求续封未载确年，不能视为国除同日。陈掌与卫氏的亲属身份存在注、传差异，原说同存于同号注。 [[4]](#note-4)

## 本期相关史料
<a id="note-1"></a>

### 1. 楚汉战争中，王陵母亲以死促使儿子坚守汉方

[返回正文第1条](#event-1)

<a id="sj056-cite-028"></a>

**[《史记·陈丞相世家》P018](../../拆分史书/史记/卷056.md#p018)**

> 項羽取陵母置軍中，陵使至，則東鄉坐陵母，欲以招陵。陵母既私送使者，泣曰：「為老妾語陵，謹事漢王。漢王，長者也，無以老妾故，持二心。妾以死送使者。」遂伏劍而死。項王怒，烹陵母。

**本卷说明：** 母亲自杀后项王再烹，是两个相继动作；东向坐按尊位读。只限归汉后、楚亡前的战争阶段，不借月表某月给她定死日。

<a id="note-2"></a>

### 2. 高后执政时，陈平以饮酒嬉戏应对吕媭进谗

[返回正文第2条](#event-2)

<a id="sj056-cite-036"></a>

**[《史记·陈丞相世家》P022](../../拆分史书/史记/卷056.md#p022)**

> 呂嬃常以前陳平為高帝謀執樊噲，數讒曰：「陳平為相非治事，日飲醇酒，戲婦女。」陳平聞，日益甚。呂太后聞之，私獨喜。面質呂嬃於陳平曰：「鄙語曰『兒婦人口不可用』，顧君與我何如耳。無畏呂嬃之讒也。」

**本卷说明：** 此段置于陈平右相之后，属于高后任相阶段而未载确年；“儿妇人口不可用”是吕后的言辞，不作作者的普遍断语。正文只叙进谗、加甚及回应，不从“非治事”推成陈平官职已被正式撤除。“面质吕媭于陈平”在白话保守写成吕后当面对陈平谈及谗言，不另确定吕媭本人也列席。

<a id="note-3"></a>

### 3. 陈平生前曾担忧隐秘谋划会殃及后代

[返回正文第3条](#event-3)

<a id="sj056-cite-050"></a>

**[《史记·陈丞相世家》P027](../../拆分史书/史记/卷056.md#p027)**

> 始陳平曰：「我多陰謀，是道家之所禁。吾世即廢，亦已矣，終不能復起，以吾多陰禍也。」

**本卷说明：** “始”是回溯生前，不等于明记临终。自述的道家禁忌、阴祸与家世废绝是伦理解释，不当作已验证的因果律。

<a id="note-4"></a>

### 4. 陈氏失侯以后，陈掌求续封未成

[返回正文第4条](#event-4)

<a id="sj056-cite-051"></a>

**[《史记·陈丞相世家》P027](../../拆分史书/史记/卷056.md#p027)**

> 然其後曾孫陳掌以衛氏親貴戚，願得續封陳氏，然終不得。

**本卷说明：** 本篇只称卫氏亲，徐广注[本段p26](../../拆分史书/史记/卷056.md#part-2-p26)称卫青子婿；[卫将军骠骑列传L6090](../../拆分史书/史记/卷111.md#part-1-L6090)却记卫少儿原与陈掌通。少儿为卫青姊，不能把两说拼成同一个确定的翁婿关系。求续封未载年，不强落元光五年。

<!-- /sj056-cite-051 -->

<a id="sj056-parallel-057"></a>

**[史记卷111 L6090互证](../../拆分史书/史记/卷111.md#part-1-L6090)**

> 少兒故與陳掌通，上召貴掌。

这是本纪年段中的既往关系与显贵，不是陈掌求续封的确年；与徐广卫青子婿之说分列。

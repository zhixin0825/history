# 公元前300—201年

[← 上一个已有内容的世纪](../bce-0400-0301/README.md) · [全部世纪](../README.md) · [项目首页](../../README.md) · [下一个已有内容的世纪 →](../bce-0200-0101/README.md)

本目录覆盖100年，现有 **98张年度正文**。卷007补入前205—203年的楚汉战争及前201年的项氏授爵；本世纪前246—201年条已连续成页，前217年仍明确保留本纪“无事”，不编造事件填空。其他已有年页和史料入口不变。

秦汉古历年条不等于公历全年：前206年文件对应汉元年，其中冬十月秦降按公历年界通常属前207年，见[说明](../../meta/考证/史记-卷006-纪年与异说.md#秦历与年页)。卷007整卷去向与跨年取舍见[记录](../../meta/记录/史记-卷007-引文去向.md)。

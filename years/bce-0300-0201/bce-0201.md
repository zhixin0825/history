# 公元前201年｜韩信被捕降侯，刘氏王国扩张，北边又起危机

**汉高帝六年**

> 冬十月、十二月在本古历年的正月以前；年页沿传统整年对应，不将古月直接当成同号公历月。

<a id="以巡游为名拿住楚王韩信"></a>
### 以巡游为名，拿住楚王韩信

<a id="event-1"></a>

1. **有人告韩信谋反，刘邦不愿立即打一场硬仗。** 诸将主张发兵，陈平却提醒：楚军精锐，韩信又善用兵，公开讨伐会把他逼入备战。于是朝廷宣布皇帝将游云梦，在陈地会见诸侯，等楚王前来迎驾。 [[1]](#note-1)

<a id="event-2"></a>

2. **十二月，韩信来会，被武士捆上了车。** 韩信把逃到楚地的钟离眛首级带来，希望消除疑忌，仍未能免祸。刘邦以有人告反为答，将他押回。后来韩信被解除楚王身份，降为淮阴侯，留在中央的控制之下。 [[2]](#note-2)

<a id="event-3"></a>

3. **田肯趁机劝皇帝把齐地交给亲近的宗室。** 他把关中、齐国都看作足以自成强势的地区，认为齐不宜再给没有亲缘保证的人。刘邦接受并赏金。拿住一位诸侯王之后，朝廷还要解决谁来接管其土地的问题。 [[3]](#note-3)

<a id="楚被分开皇弟皇子陆续成为王"></a>
### 楚被分开，皇弟、皇子陆续成为王

<a id="event-4"></a>

4. **刘贾为荆王，刘交为楚王，刘肥为齐王。** 韩信原来的楚地被分成荆、楚两部分，分别给宗室刘贾和皇弟刘交；刘邦的长子刘肥统齐地。原来依功臣军队建立的王国，逐步换成由刘氏亲属掌握。 [[4]](#note-4)

<a id="event-5"></a>

5. **韩王信则迁到北方，承担边防。** 这位韩王是韩国宗室，不是刚降侯的韩信。迁治太原后，他选择以马邑为治所；离匈奴近，压力也很快到来。 [[5]](#note-5)

<a id="论功封侯项氏亲属仍有出路"></a>
### 论功封侯，项氏亲属仍有出路

<a id="event-6"></a>

6. **朝廷与功臣剖符定封，原来参加战争的人获得较稳定的爵邑。** 这是战后重新安排功劳与土地的一部分，不能把每位列侯的正式授爵都倒放到垓下胜利当天。[卷008 P050](../../sources/摘录/史记-卷008-高祖本纪.md#p050)。 [[6]](#note-6)

<a id="event-7"></a>

7. **正月丙午，项伯被封为射阳侯，获赐刘姓。** 项伯名缠，曾在楚任左尹，在鸿门事件中保护刘邦；他没有因为是项氏亲属便被诛杀，而成为汉的列侯。 [[7]](#note-7)

<a id="event-8"></a>

8. **项它以砀郡长身份归汉，获赐刘姓。** 他后来被称为平皋侯，正式授爵却在下一古历年；归附、赐姓与封侯是可以分开的步骤。 [[8]](#note-8)

<a id="五月父子之礼改为皇室之礼"></a>
### 五月，父子之礼改为皇室之礼

<a id="event-9"></a>

9. **刘邦照旧每五日拜见父亲，太公的家令却觉得不妥。** 皇帝是天下之主，父亲虽尊，礼制上却还是臣；让皇帝像普通儿子那样行拜，会造成君臣名分的冲突。 [[9]](#note-9)

<a id="event-10"></a>

10. **太公执帚迎门、退着行走，刘邦赶紧扶住，随后尊父为太上皇。** 这样既保留父亲的尊位，也不必把普通家庭的父子礼直接套在朝廷。提出办法的家令得到赏金。 [[10]](#note-10)

<a id="九月韩王信以马邑降匈奴"></a>
### 九月，韩王信以马邑降匈奴

<a id="event-11"></a>

11. **匈奴围攻马邑，韩王信频繁遣使求和，汉廷却怀疑他有二心。** 朝廷派兵救援，又责问他的交涉。韩王信害怕被杀，最后带马邑归附匈奴。冒顿随即南下，越句注、攻太原，逼到晋阳。 [[11]](#note-11)

    边地问题由一座城的救援，转成汉廷与匈奴、叛离诸侯的正面战争。刘邦下一年亲征，将陷入平城之围。

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-12"></a>

12. **张苍担任计相，负责汇总、核理各地的计簿。** 他后来才会成为中央丞相；眼下萧何仍居相位。朝廷也设置大市，把咸阳的名号改称长安，战后的行政与城市经营继续展开。 [原格与说明](#sj022-note)。 [[12]](#note-12)

## 归年与考证

<a id="sj022-note"></a>
<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[本年原表R006](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r006) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0201)。

> 纪年：六；大事纪：尊太公為太上皇。劉仲為代王。立大市。更命咸陽曰長安。；相位：六。封為酇侯。張蒼為計相。；将位：〔空〕；御史大夫位：〔空〕

萧何酂侯的受封接本页功臣论赏，任丞相与封侯不是一事。计相的“相”也不等于张苍此时已取代萧何成为中央丞相；《索隐》释为掌天下计簿、上计之官。尊太上皇、刘仲封代沿既有叙事；立大市和更咸阳为长安为本格补记，行政名号不直接等于首都全部宫署已同时迁完。

<a id="1捕韩信与田肯之说"></a>
#### 1｜捕韩信与田肯之说

[卷008 P049—P050](../../sources/摘录/史记-卷008-高祖本纪.md#p049) · [《通鉴》卷十一，高帝六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7011.md#ref-7a2d0ed57bcbc2)。本纪从十二月概述告反与拘捕，《通鉴》将告发、决定游云梦置十月，实际会陈置十二月。告发和政治拘捕可以确定为史书记载的行动，不把其罪名直接写成已独立证明的谋反事实。钟离眛的结局由互见补足；田肯所说“百二”“十二”是形势论，不换算精确战力。

<a id="卷016跨年互见月表提前记载的两项后事"></a>
### 卷016跨年互见｜月表提前记载的两项后事

**韩王信北迁：**[月表汉五年正月韩栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0202-01)写“韩王信徙王代，都马邑”，但[汉书P075](../../sources/摘录/汉书-高帝纪.md#p075)在六年正月列迁太原、都晋阳，《通鉴》六年再记韩王信请以马邑为治所而获准。正文沿本页[封王与两个韩信](#sj008-kings)的年链，区分朝廷划地、初定治所与请求迁马邑；表的五年原格保留于[前202年注](bce-0202.md#sj016-m01-note)，不在两年安排两次相同北迁。表称“王代”与韩王在太原以北所受地也不直接等同其他刘氏代国。

**钟离眛的终局：**[月表汉五年九月楚栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0202-09)写韩信得钟离眛、斩首以闻；[《淮阴侯列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7092.md#ref-6610526bb6d130)与[《通鉴》卷十一六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7011.md#ref-c91c2df65197d7)却把此事接在云梦之会前，详写钟离眛自刭，韩信持首求见后被拘。主叙仍归本页[十二月会陈](#sj008-arrest)，自杀与后来持首不合写成韩信当面亲斩；不能让钟离眛五年死过、六年再死一次。眛、昧及所用月表网页“辚”的字形分别保留，不另造三人。

这两条只是卷016的异年材料承接，不把月表的起讫延长成已存在第91个月，也不宣称《淮阴侯列传》《韩信卢绾列传》已整卷处理。

<a id="功臣封侯军功之外谋划粮饷和保护家属也要计算"></a>
### 功臣封侯：军功之外，谋划、粮饷和保护家属也要计算

**大功臣先受封以后，尚未得封的将领仍不断争功。** 张良提醒刘邦，他们不只嫌赏赐少，还怕皇帝按旧日恩怨处置人。刘邦于是把自己一直不喜欢、却立有功劳的雍齿封为侯，让其他人看到旧怨未必挡住受赏。[原文与取舍](#sj018-note)

**萧何的位次在曹参之前，也不是没有争议。** 有人强调曹参亲冒矢石、攻城略地；鄂君则指出，刘邦屡次败走以后，关中仍能供兵供粮，正是萧何留下了可以重新作战的根本。刘邦采纳，把萧何列首位，鄂君也因举明其功而封安平侯。位次、食邑多少和受封先后并不是同一个排名。[原文与取舍](#sj018-note)

上述66个侯籍行的高祖六年记录全部列入，包括韩信降侯、射阳已有授爵的互见，不等于新增加66位此前无爵的人。月日逐项沿[卷018 R001—R066](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r001)，不把先十二月、后正月的古历顺序误当公历倒置。仅有“六年中”的不补月份。食邑户数、侯第在原格完整保留，不据户数复原疆界，也不把谥号提前当作受封当日称谓。

[《留侯世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7055.md#ref-b8b753745e5c7d)六年正月封张良及封雍齿，[《萧相国世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7053.md#ref-19d325d389cf86)萧曹争功、鄂君进言补本页封赏过程。话语是传世叙事，不是现场逐字记录；“众将谋反”是张良解释他们忧惧的言辞，不能据此为每个未封军吏登记一项已查实谋反罪。封位、论功及后来增邑不是一次会议中同时完成的每个动作。

**陈平国号：** 本表以最后较著名的曲逆为行名，在六年列初封；[通鉴七年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7011.md#ref-d6e629de26e688)记平城回军经过曲逆，才更封。前后不写成六年、七年各新造同一侯国。**芒侯：** 汉表区分初封耏跖及后来昭，史表一行接写；当前只采用本年有芒侯授封的共同事实，昭的后续仍单列待核身份。**鲁侯：** [汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-e5cfc1abc3afdc)补奚涓及母底，本表母名疵，名异不拆成两位受封母亲；战死的具体年月未载，不定为授封当天。

诸侯行名、姓名及军职有异文：清阳／清河、武儒／武虎、孔藂／孔聚、蛊逢／虫达、元顷／爰类、沛嘉／工师喜、庄／严避讳字等，均在[本卷考证](../../meta/考证/史记-卷018-纪年与异说.md)保留，不靠猜测补全未记姓氏。貰侯“吕”与汉表傅胡害差别较大，保留双方原文，不直接把他接入吕后家系。魏其周定／周止不是窦婴；两个博阳也不合并。

侯功中的击陈豨、英布、燕王卢绾，以及长期出任相职，另在实际对应年或明确的跨期说明处理，不倒放到六年以前。表称灌婴等“杀项籍”与前202年自刎、分得尸体的详叙互见；朱轸格“虏章邯”、丁复格龙且所在也不推翻既有详记而制造第二次死亡。此处的人物介绍只是受封前情，不重新统计一遍既有战役。

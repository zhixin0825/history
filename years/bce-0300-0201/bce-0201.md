# 公元前201年｜韩信被捕降侯，刘氏王国扩张，北边又起危机

[← 公元前202年](bce-0202.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前200年条 →](../bce-0200-0101/bce-0200.md)

**汉高帝六年**

> 冬十月、十二月在本古历年的正月以前；年页沿传统整年对应，不将古月直接当成同号公历月。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="以巡游为名拿住楚王韩信"></a>

<a id="event-1"></a>

1. **刘邦采纳陈平建议，宣布将巡游会诸侯。** 有人告楚王韩信反，诸将主张赶快发兵，高帝没有采纳。陈平先问告书是否已为人知、韩信是否知情，又问汉军精锐与统将能否胜过楚军、韩信，刘邦均答不能。陈平认为贸然发兵会催使韩信应战，建议借天子巡狩会诸侯之名，假游云梦、会诸侯于陈。陈在楚国西界，韩信若以为只是出游而来郊迎，便可趁机拘捕。刘邦同意并遣使通知诸侯。 [[1]](#note-1)

<a id="event-2"></a>

2. **十二月，韩信来会，被武士捆上了车。** 韩信把逃到楚地的钟离眛首级带来，希望消除疑忌，仍未能免祸。刘邦以有人告反为答，将他押回。后来韩信被解除楚王身份，降为淮阴侯，留在中央的控制之下。 《陈丞相世家》还记韩信被缚后喊天下已定、自己本该遭烹，高帝则喝令噤声并指称谋反已明。皇帝的断言仍是拘捕现场的言辞；回到洛阳以后，才接赦为淮阴侯和功臣定封。 [[2]](#note-2)

<a id="event-3"></a>

3. **田肯趁机劝皇帝把齐地交给亲近的宗室。** 他把关中、齐国都看作足以自成强势的地区，认为齐不宜再给没有亲缘保证的人。刘邦接受并赏金。拿住一位诸侯王之后，朝廷还要解决谁来接管其土地的问题。 [[3]](#note-3)

<a id="楚被分开皇弟皇子陆续成为王"></a>

<a id="event-4"></a>

4. **韩信的旧楚地分为荆、楚，刘氏宗亲陆续成为王。** 高祖诸子尚幼，兄弟有限，朝廷既论将军刘贾的军功，也选择能够镇守天下的宗族子弟。刘贾受封荆王，掌淮东五十二城；皇弟刘交受封楚王，掌淮西三十六城，定都彭城。刘交字游，皇兄刘仲也封代王。另封齐王的刘肥是高祖长庶子，母亲曹氏在篇中称“外妇”；他取得七十城，能说齐地语言的人划归齐王。古注一说按齐地语音、名物辨别，一说使说齐话的流亡者返齐。原来依功臣军队建立的王国，逐步换成由刘氏亲属掌握；荆国城县数的异文见同号注。 刘肥受齐王封，曹参为齐相国，辅佐治理齐地。 [[4]](#note-4)

<a id="event-5"></a>

5. **韩王信则迁到北方，承担边防。** 这位韩王是韩国宗室，不是刚降侯的韩信。迁治太原后，他选择以马邑为治所；离匈奴近，压力也很快到来。 [[5]](#note-5)

<a id="论功封侯项氏亲属仍有出路"></a>

<a id="event-6"></a>

6. **朝廷与功臣剖符定封，萧何的食邑和位次引起争论。** 曹参于十二月甲申定封平阳侯，剖符许以世袭，食平阳一万零六百三十户，撤换此前食邑；他先前的建成侯号、平阳食邑与正式定封分开。战后论功持续一年多，刘邦认为萧何功最大，封为酂侯，食邑较多。亲冒矢石的将领不服，说自己打过几十乃至上百仗，萧何只持文墨、不曾作战，为什么居上？刘邦用打猎作比：追取走兽的是猎狗，发现踪迹、指明所在的是人；诸将是功狗，萧何是功人，又有举宗数十人相从之功，众人不再争。议位次时，大家又主张受七十处伤的曹参第一。鄂君指出，刘邦几次失军败走，萧何却不待诏令就补兵，屡在前线困乏时送来数万人；粮食不绝，关中又始终保全，留下重整根本。刘邦采纳，列萧何第一，许其带剑穿鞋上殿、入朝不趋；鄂君也因举明功劳受封安平侯。其后叙及萧何父子兄弟十余人获食邑，萧何再增二千户，以报早年比别人多送钱二的旧助。授爵、定食邑、排位次与增封，经过了先后不同的商议和安排。 陈平与皇帝剖符，正式为户牖侯；他辞功，指出没有魏无知推荐就不能进用，刘邦因此再赏魏无知。王陵因早先不肯从汉、又与雍齿友善而较晚受封；审食其以从侍吕后及破楚后的功劳封辟阳侯。 正月，张良因运筹帷帐、决胜千里之功得封。高帝让他在齐地自择三万户，张良只愿取当初与刘邦相遇的留，称那是天授与侥幸合计，不敢受三万户，遂为留侯。留侯所得封邑为万户。高帝又在洛阳南宫看到未受赏的将领聚议，张良提醒他，这些人担心爵土不足分、旧过遭诛；张良问高帝平生最恨谁，高帝答雍齿。张良便劝先封这位屡使皇帝难堪而有功的人，让众人看到连雍齿也可保全受赏。高帝置酒封雍齿，催丞相、御史定功，诸将才安心。侯表记雍齿三月获封二千五百户。 周勃也于正月丙午剖符定封为绛侯。本传记食绛八千一百八十户，侯表与汉传另有不同户数。 [[6]](#note-6)

<a id="event-7"></a>

7. **正月丙午，项伯被封为射阳侯，获赐刘姓。** 项伯名缠，曾在楚任左尹，在鸿门事件中保护刘邦；他没有因为是项氏亲属便被诛杀，而成为汉的列侯。 [[7]](#note-7)

<a id="event-8"></a>

8. **项它以砀郡长身份归汉，获赐刘姓。** 他后来被称为平皋侯，正式授爵却在下一古历年；归附、赐姓与封侯是可以分开的步骤。 [[8]](#note-8)

<a id="五月父子之礼改为皇室之礼"></a>

<a id="event-9"></a>

9. **刘邦拜见父亲的礼仪引出君臣名分之争。** 刘邦照旧每五日拜见父亲，太公的家令却觉得不妥。 皇帝是天下之主，父亲虽尊，礼制上却还是臣；让皇帝像普通儿子那样行拜，会造成君臣名分的冲突。 [[9]](#note-9)

<a id="event-10"></a>

10. **五月，刘邦尊父亲为太上皇。** 太公执帚迎门、退着行走，刘邦赶紧扶住，随后尊父为太上皇。 这样既保留父亲的尊位，也不必把普通家庭的父子礼直接套在朝廷。提出办法的家令得到赏金。 [[10]](#note-10)

<a id="九月韩王信以马邑降匈奴"></a>

<a id="event-11"></a>

11. **九月，韩王信以马邑降匈奴。** 匈奴围攻马邑，韩王信频繁遣使求和，汉廷却怀疑他有二心。 朝廷派兵救援，又责问他的交涉。韩王信害怕被杀，最后带马邑归附匈奴。冒顿随即南下，越句注、攻太原，逼到晋阳。 [[11]](#note-11)

    边地问题由一座城的救援，转成汉廷与匈奴、叛离诸侯的正面战争。刘邦下一年亲征，将陷入平城之围。

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-12"></a>

12. **张苍担任计相，负责汇总、核理各地的计簿。** 他后来才会成为中央丞相；眼下萧何仍居相位。朝廷也设置大市，把咸阳的名号改称长安，战后的行政与城市经营继续展开。 [原格与说明](#sj022-note)。 [[12]](#note-12)

<a id="sj099-event-13"></a>

13. **叔孙通征鲁儒试行新朝仪。** 高帝不满朝臣宴饮争功失仪，接受叔孙通采古礼、兼秦仪制定朝礼的提议。叔孙通征召鲁儒，有二人不肯同行。叔孙通带其余儒者与弟子等在野外排演，高帝试观后令群臣练习，以待岁首朝会。 [[13]](#note-13)

<a id="sj028-event-14"></a>

14. **诏令管理丰地枌榆社并在长安祠蚩尤。** 汉初天下既定后，高祖命御史令丰县谨治枌榆社，依时祭祀，并命祝官在长安设蚩尤祠。 [[14]](#note-14)

<a id="hs001-event-15"></a>

15. **冬十月，朝廷下令县邑筑城。** 《高帝纪》记汉六年冬十月令各县、邑修筑自己的城墙。此处记的是颁令，未列各地何时完工。 [[15]](#hs001-note-15)

<a id="hs-event-16"></a>

16. **周吕令武侯吕泽｜受封。** 《汉书》侯籍列周吕令武侯吕泽本年受封，所引月份、干支依表保留。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **建成康侯吕释之｜受封。** 《汉书》侯籍列建成康侯吕释之本年受封，所引月份、干支依表保留。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **郦商任卫尉、公上不害任太仆。** 郦商任卫尉、公上不害任太仆。参见本年的官职变动原句。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **朝廷更名文始舞。** 高祖六年为旧舞改名文始。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **高祖作昭容乐、礼容乐。** 昭容用于武德舞退出，礼容用于文始及五行舞退出。 [[20]](#hs-note-20)

### 6. 朝廷与功臣剖符定封，原来参加战争的人获得较稳定的爵邑

**[《汉书·萧何曹参传》P006](../../sources/摘录/汉书-卷039-萧何曹参传.md#p006)** · [仓内TXT L7184](../../sources/本地分卷/汉书/汉书-卷039.md#L7184)

<a id="hs039-l7185-e6"></a>

**[《汉书·萧何曹参传》P007](../../sources/摘录/汉书-卷039-萧何曹参传.md#p007)** · [仓内TXT L7185](../../sources/本地分卷/汉书/汉书-卷039.md#L7185)

> 列侯畢已受封，奏位次，皆曰：「平陽侯曹參身被七十創，攻城略地，功最多，宜第一。」上已橈功臣多封何，至位次未有以復難之，然心欲何第一。關內侯鄂千秋時為謁者，進曰：「群臣議皆誤。夫曹參雖有野戰略地之功，此特一時之事。夫上與楚相距五歲，失軍亡眾，跳身遯者數矣，然蕭何常從關中遣軍補其處。非上所詔令召，而數萬眾會上乏絕者數矣。夫漢與楚相守滎陽數年，軍無見糧，蕭何轉漕關中，給食不乏。陛下雖數亡山東，蕭何常全關中待陛下，此萬世功也。今雖無曹參等百數，何缺於漢？漢得之不必待以全。柰何欲以一旦之功而加萬世之功哉！蕭何當第一，曹參次之。」上曰：「善。」於是乃令何第一，賜帶劍履上殿，入朝不趨。上曰：「吾聞進賢受上賞，蕭何功雖高，待鄂君乃得明。」於是因鄂千秋故所食關內侯邑二千戶，封為安平侯。是日，悉封何父母兄弟十餘人，皆食邑。乃益封何二千戶，「以嘗繇咸陽時何送我獨贏錢二也」。

### 卷016跨年互见｜月表提前记载的两项后事

**韩王信北迁：**[月表汉五年正月韩栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0202-01)写“韩王信徙王代，都马邑”，但[汉书P075](../../sources/摘录/汉书-高帝纪.md#p075)在六年正月列迁太原、都晋阳，《通鉴》六年再记韩王信请以马邑为治所而获准。正文沿本页[封王与两个韩信](#sj008-kings)的年链，区分朝廷划地、初定治所与请求迁马邑；表的五年原格保留于[前202年注](bce-0202.md#sj016-m01-note)，不在两年安排两次相同北迁。表称“王代”与韩王在太原以北所受地也不直接等同其他刘氏代国。

**钟离眛的终局：**[月表汉五年九月楚栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0202-09)写韩信得钟离眛、斩首以闻；[《淮阴侯列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7092.md#ref-6610526bb6d130)与[《通鉴》卷十一六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7011.md#ref-c91c2df65197d7)却把此事接在云梦之会前，详写钟离眛自刭，韩信持首求见后被拘。主叙仍归本页[十二月会陈](#sj008-arrest)，自杀与后来持首不合写成韩信当面亲斩；不能让钟离眛五年死过、六年再死一次。眛、昧及所用月表网页“辚”的字形分别保留，不另造三人。

这两条只是卷016的异年材料承接，不把月表的起讫延长成已存在第91个月，也不宣称《淮阴侯列传》《韩信卢绾列传》已整卷处理。

#### 卷018｜本年封授的层次、姓名与跨年履历

上述66个侯籍行的高祖六年记录全部列入，包括韩信降侯、射阳已有授爵的互见，不等于新增加66位此前无爵的人。月日逐项沿[卷018 R001—R066](../../sources/摘录/史记-卷018-高祖功臣侯者年表.md#r001)，不把先十二月、后正月的古历顺序误当公历倒置。仅有“六年中”的不补月份。食邑户数、侯第在原格完整保留，不据户数复原疆界，也不把谥号提前当作受封当日称谓。

[《留侯世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7055.md#ref-b8b753745e5c7d)六年正月封张良及封雍齿，[《萧相国世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7053.md#ref-19d325d389cf86)萧曹争功、鄂君进言补本页封赏过程。话语是传世叙事，不是现场逐字记录；“众将谋反”是张良解释他们忧惧的言辞，不能据此为每个未封军吏登记一项已查实谋反罪。封位、论功及后来增邑不是一次会议中同时完成的每个动作。

**陈平国号：** 本表以最后较著名的曲逆为行名，在六年列初封；[通鉴七年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7011.md#ref-d6e629de26e688)记平城回军经过曲逆，才更封。前后不写成六年、七年各新造同一侯国。**芒侯：** 汉表区分初封耏跖及后来昭，史表一行接写；当前只采用本年有芒侯授封的共同事实，昭的后续仍单列待核身份。**鲁侯：** [汉书功臣表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7016.md#ref-e5cfc1abc3afdc)补奚涓及母底，本表母名疵，名异不拆成两位受封母亲；战死的具体年月未载，不定为授封当天。

诸侯行名、姓名及军职有异文：清阳／清河、武儒／武虎、孔藂／孔聚、蛊逢／虫达、元顷／爰类、沛嘉／工师喜、庄／严避讳字等，均在[本卷考证](../../meta/考证/史记-卷018-纪年与异说.md)保留，不靠猜测补全未记姓氏。貰侯“吕”与汉表傅胡害差别较大，保留双方原文，不直接把他接入吕后家系。魏其周定／周止不是窦婴；两个博阳也不合并。

侯功中的击陈豨、英布、燕王卢绾，以及长期出任相职，另在实际对应年或明确的跨期说明处理，不倒放到六年以前。表称灌婴等“杀项籍”与前202年自刎、分得尸体的详叙互见；朱轸格“虏章邯”、丁复格龙且所在也不推翻既有详记而制造第二次死亡。此处的人物介绍只是受封前情，不重新统计一遍既有战役。

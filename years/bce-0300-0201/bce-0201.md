# 公元前201年｜韩信被捕降侯，刘氏王国扩张，北边又起危机

[← 公元前202年](bce-0202.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前200年条 →](../bce-0200-0101/bce-0200.md)

**汉高帝六年**

> 冬十月、十二月在本古历年的正月以前；年页沿传统整年对应，不将古月直接当成同号公历月。

## 以巡游为名，拿住楚王韩信

**有人告韩信谋反，刘邦不愿立即打一场硬仗。** 诸将主张发兵，陈平却提醒：楚军精锐，韩信又善用兵，公开讨伐会把他逼入备战。于是朝廷宣布皇帝将游云梦，在陈地会见诸侯，等楚王前来迎驾。[1](#sj008-arrest)

**十二月，韩信来会，被武士捆上了车。** 韩信把逃到楚地的钟离眛首级带来，希望消除疑忌，仍未能免祸。刘邦以有人告反为答，将他押回。后来韩信被解除楚王身份，降为淮阴侯，留在中央的控制之下。[1](#sj008-arrest)

**田肯趁机劝皇帝把齐地交给亲近的宗室。** 他把关中、齐国都看作足以自成强势的地区，认为齐不宜再给没有亲缘保证的人。刘邦接受并赏金。拿住一位诸侯王之后，朝廷还要解决谁来接管其土地的问题。[1](#sj008-arrest)

## 楚被分开，皇弟、皇子陆续成为王

**刘贾为荆王，刘交为楚王，刘肥为齐王。** 韩信原来的楚地被分成荆、楚两部分，分别给宗室刘贾和皇弟刘交；刘邦的长子刘肥统齐地。原来依功臣军队建立的王国，逐步换成由刘氏亲属掌握。[2](#sj008-kings)

**韩王信则迁到北方，承担边防。** 这位韩王是韩国宗室，不是刚降侯的韩信。迁治太原后，他选择以马邑为治所；离匈奴近，压力也很快到来。[2](#sj008-kings)

## 论功封侯，项氏亲属仍有出路

**朝廷与功臣剖符定封，原来参加战争的人获得较稳定的爵邑。** 这是战后重新安排功劳与土地的一部分，不能把每位列侯的正式授爵都倒放到垓下胜利当天。[卷008 P050](../../sources/摘录/史记-卷008-高祖本纪.md#p050)。

**正月丙午，项伯被封为射阳侯，获赐刘姓。** 项伯名缠，曾在楚任左尹，在鸿门事件中保护刘邦；他没有因为是项氏亲属便被诛杀，而成为汉的列侯。[3](#sj007-grants)

**项它以砀郡长身份归汉，获赐刘姓。** 他后来被称为平皋侯，正式授爵却在下一古历年；归附、赐姓与封侯是可以分开的步骤。[4](#sj007-xiangta)

## 五月，父子之礼改为皇室之礼

**刘邦照旧每五日拜见父亲，太公的家令却觉得不妥。** 皇帝是天下之主，父亲虽尊，礼制上却还是臣；让皇帝像普通儿子那样行拜，会造成君臣名分的冲突。[5](#sj008-taishang)

**太公执帚迎门、退着行走，刘邦赶紧扶住，随后尊父为太上皇。** 这样既保留父亲的尊位，也不必把普通家庭的父子礼直接套在朝廷。提出办法的家令得到赏金。[5](#sj008-taishang)

## 九月，韩王信以马邑降匈奴

**匈奴围攻马邑，韩王信频繁遣使求和，汉廷却怀疑他有二心。** 朝廷派兵救援，又责问他的交涉。韩王信害怕被杀，最后带马邑归附匈奴。冒顿随即南下，越句注、攻太原，逼到晋阳。[6](#sj008-mayi)

边地问题由一座城的救援，转成汉廷与匈奴、叛离诸侯的正面战争。刘邦下一年亲征，将陷入平城之围。

## 本年相关史料

<a id="sj008-arrest"></a>
### 1｜捕韩信与田肯之说

[卷008 P049—P050](../../sources/摘录/史记-卷008-高祖本纪.md#p049) · [《通鉴》卷十一，高帝六年](https://zh.wikisource.org/wiki/資治通鑑/卷011)。本纪从十二月概述告反与拘捕，《通鉴》将告发、决定游云梦置十月，实际会陈置十二月。告发和政治拘捕可以确定为史书记载的行动，不把其罪名直接写成已独立证明的谋反事实。钟离眛的结局由互见补足；田肯所说“百二”“十二”是形势论，不换算精确战力。

<a id="sj008-kings"></a>
### 2｜封王与两个韩信

[卷008 P050—P051](../../sources/摘录/史记-卷008-高祖本纪.md#p050) · [《通鉴》卷十一](https://zh.wikisource.org/wiki/資治通鑑/卷011)。楚王韩信降淮阴侯，韩国宗室韩王信迁太原，完全是两个人。刘肥“七十余城”“能齐言者”属本纪的地域概括，不精确画成以方言调查划定的边界；诸王封地沿原文大区，不套现代省界。

<a id="sj007-grants"></a>
### 3｜项伯旧记录

[卷007 P044](../../sources/摘录/史记-卷007-项羽本纪.md#p044) · [卷018互校T1](../../sources/摘录/史记-卷007-项羽本纪.md#t1)射阳条：“六年正月丙午，侯项缠元年。赐姓刘氏。”项伯、项缠不是两位受封者；[鸿门旧事](bce-0206.md#sj007-hongmen)不再计一次。

<a id="sj007-xiangta"></a>
### 4｜项它先归汉、后封侯

[卷018平皋条](https://zh.wikisource.org/wiki/史記/卷018)记六年以砀郡长初从、赐刘姓，七年十月癸亥初封。后者见[前200年页](../bce-0200-0101/bce-0200.md)，不借用授爵日给本年的归附定日。

<a id="sj008-taishang"></a>
### 5｜尊太上皇

[卷008 P048](../../sources/摘录/史记-卷008-高祖本纪.md#p048)给出父子礼的故事；《通鉴》明系六年五月。不能因本纪把这段放在六年开头，就移到捕韩信之前。家令姓名未记，对话按传世叙述，不作现场逐字记录。

<a id="sj008-mayi"></a>
### 6｜马邑与平城分年

[卷008 P051](../../sources/摘录/史记-卷008-高祖本纪.md#p051)将马邑、平城接在七年，《通鉴》明确六年九月马邑降，七年亲征与被围，正文据此分开；不是韩王信在两年各投降一次。卷008未详写冒顿早年，本页不由战事回推其童年确年。

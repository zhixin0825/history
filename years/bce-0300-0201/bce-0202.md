# 公元前202年｜项羽败亡，刘邦称帝，新朝开始安排天下

[← 公元前203年](bce-0203.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前201年 →](bce-0201.md)

**汉五年**

> 冬十月、十一月、十二月在本古历年正月以前，未作逐日公历换算。垓下胜利、称帝、封王、迁都和诸侯反抗分阶段写，不把“天下定”当成所有问题已经解决。

<a id="sj007-guling"></a>
<a id="冬十月追击楚军反在固陵吃了败仗"></a>

<a id="event-1"></a>

1. **冬十月，追击楚军反在固陵吃了败仗。** 刘邦追到阳夏以南、再进固陵，却没等到韩信和彭越。 原约会合的援军没有来，楚军反击，大破汉军，刘邦又得挖深沟、筑高垒自守。项羽虽居劣势，仍不是随便一追就会崩溃。 [[1]](#note-1)

<a id="event-2"></a>

2. **张良劝他先讲清战后的利益。** 韩信、彭越各有军队和期待，不能仅靠催促。刘邦许楚破以后，自陈以东至海给韩信，睢阳以北至谷城给彭越。两人才答应进军。 [[2]](#note-2)

<a id="event-3"></a>

3. **十一月，刘贾围寿春，楚大司马周殷倒戈。** 刘贾奉命南渡淮水，又派人秘密招引周殷。周殷反楚，协助攻取九江，迎黥布兵；韩信由齐南下，彭越和其他部队也到，最后共同逼向垓下。项羽面对的是协调利益以后形成的多路联军，而不只是刘邦自己的一军。 韩信率兵离齐会战时，曹参留在齐地，平定尚未服从的地方。 [[3]](#note-3)

<a id="sj007-gaixia"></a>
<a id="十二月垓下从野战转成重围"></a>

<a id="event-4"></a>

4. **十二月，韩信等在垓下击败楚军。** 韩信居前，两翼与后阵配合，才把楚军打败。 韩信最初交战不利后退，孔将军、费将军所领两翼投入，楚军转为不利，韩信再乘势反击。刘邦与绛侯等军在后，联军由此取得决战胜利。 回看此前楚汉战场，周勃功状还记转击项籍、攻曲逆而功居最，回守敖仓、追击项羽；曲逆又有曲遇异写，这些回叙没有独立确年，不能都说成垓下当日新战。 [[4]](#note-4)

<a id="event-5"></a>

5. **楚军兵少食尽，营垒被围，夜里四面传来楚歌。** 项羽惊疑汉已尽得楚地，起身在帐中饮酒，悲歌感叹力量与时运，虞在旁相和，左右都流泪。 [[5]](#note-5)

<a id="event-6"></a>

6. **最后一夜，项羽带八百余骑突围南走。** 天明汉军才发觉，灌婴带骑兵追赶。渡淮后只剩百余人跟上；阴陵问路又被田间老人指错方向，陷入沼泽，追兵进一步逼近。 [[6]](#note-6)

<a id="东城最后的快战改变不了败局"></a>

<a id="event-7"></a>

7. **东城最后的快战，改变不了败局。** 身边只剩二十八骑，项羽仍要证明自己没有输在用兵。 他对部下说，起兵八年、经历七十余战，如今是天要亡他，愿再痛快打一次让大家看看。随后分队突击、杀将、叱退追者，又聚拢余骑。 [[7]](#note-7)

   最后仍能勇猛作战，并不等于能恢复粮食、盟友和已经被打散的主力。个人的近身战能力与整场战争的胜负，在这里分得很清楚。

<a id="sj007-wujiang"></a>
<a id="乌江边项羽没有上船"></a>

<a id="event-8"></a>

8. **乌江边，项羽没有上船。** 亭长备船劝他回江东，项羽却不肯渡。 他想到当初带八千江东子弟西行，如今无人随还，即使父老愿意再拥他为王，自己也无颜相见。他将骓马赠给亭长，令余骑下马，以短兵作最后抵抗。 [[8]](#note-8)

<a id="event-9"></a>

9. **项羽多处负伤，认出吕马童，随后自刎。** 他提到汉悬赏自己的首级，愿送故人这份好处。王翳取得首级，杨喜、吕马童、吕胜、杨武也各取得部分遗体，合验后分功。正式封侯则在以后，分见[前200](../bce-0200-0101/bce-0200.md)、[前199](../bce-0200-0101/bce-0199.md)年，不全在死亡当日。 [[9]](#note-9)

<a id="鲁最后投降韩信的军队也被刘邦接管"></a>

<a id="event-10"></a>

10. **刘邦出示项羽首级，鲁地投降。** 楚地大多归汉，鲁仍不肯降。 刘邦本拟屠鲁，后来因鲁人坚持为旧主守节，改为出示项羽首级，鲁父老才投降。项羽以旧日鲁公身份的礼仪葬于谷城，刘邦为他发哀而去。 项羽死后，周勃向东定泗水、东海两郡二十二县，随后守洛阳、栎阳，获赐与颍阴侯灌婴共食钟离；这段战后安排不另给月日。 [[10]](#note-10)

<a id="event-11"></a>

11. **项氏旁支没有被一概清算，刘邦却迅速拿回盟友的兵权。** 项伯等后来得到封爵、有人获赐刘姓。刘邦回到定陶，驰入齐王韩信的军营，接管其军队。结束对楚作战，并不代表原来各部将领可以继续完全独立地掌握军事力量。 [[11]](#note-11)

<a id="sj008-emperor"></a>
<a id="正月重新分王二月才正式称帝"></a>

<a id="event-12"></a>

12. **正月，韩信迁为楚王，彭越被立为梁王。** 韩信由齐王迁为楚王，彭越被立为梁王。 刘邦以韩信熟悉楚地风俗为由，把他迁到淮北、都下邳；彭越获得魏故地，都定陶。原韩王信继续王韩，都阳翟，黥布、臧荼等也保有王号。 韩信迁楚、齐地暂为郡以后，曹参交还汉丞相印。 [[12]](#note-12)

<a id="event-13"></a>

13. **诸侯将相请刘邦采用高于王的称号，二月甲午，他在氾水之阳即帝位。** 群臣强调，土地既已分定，若汉王与诸侯仍同称王，便缺少明确上下名分。刘邦经过推辞，终于接受。吕氏成为皇后，刘盈由王太子转为皇太子，已故母亲被追尊为昭灵夫人。 [[13]](#note-13)

<a id="event-14"></a>

14. **吴芮从衡山王转为长沙王，都临湘。** 朝廷以他率百越助灭秦，以及其部将梅鋗曾帮助刘邦入武关等功劳说明这项安排。各王的封地、名号与实际占领范围并非完全同步，不能以同一份名单假定一日内全部交割。 [[14]](#note-14)

<a id="临江还在抵抗五月让一批士卒回家"></a>

<a id="event-15"></a>

15. **临江王不肯降，卢绾、刘贾奉命进攻。** 围攻持续数月，临江王最终投降，后被处死于洛阳。项羽已经死亡，长江中游仍有最后的旧楚王国需要另行处理。 刘贾带来九江兵，共尉死后临江转为南郡；本篇连写这一结局，本纪所说的数月围攻仍须展开理解。 [[15]](#note-15)

<a id="event-16"></a>

16. **五月，兵士罢归，朝廷宣布战后复免。** 留在关中的诸侯子有十二年复免，回乡者减半，并给一年食粮。流亡山泽、脱离户籍的百姓可以回本县、恢复旧爵田宅；因饥饿卖身者获免为庶人。朝廷也要求地方官按规定照顾有军功者，不以笞辱和拖延阻碍安置。 [[16]](#note-16)

<a id="sj008-nangong"></a>
<a id="南宫宴上刘邦问自己为什么赢"></a>

<a id="event-17"></a>

17. **南宫宴上，刘邦问自己为什么赢。** 高起、王陵先把答案归于肯与人分享利益。 他们并没有只奉承皇帝温厚，反而说刘邦待人傲慢，项羽有时更仁爱；区别在于刘邦能将攻得的地盘和好处给立功者，项羽却疑贤害功，不肯把成果分出去。 [[17]](#note-17)

<a id="event-18"></a>

18. **刘邦说自己胜在能用三个人。** 运筹决胜不如张良，安定后方、供粮抚民不如萧何，统率大军不如韩信；但他能用这些人，项羽却连一个范增也不能用。这是新皇帝在胜利后的自我解释，同时说明他怎样向功臣界定自己的领导地位。 [[18]](#note-18)

<a id="sj008-capital"></a>
<a id="不长留洛阳而往关中建都"></a>

<a id="event-19"></a>

19. **娄敬、张良劝刘邦在关中建都。** 齐人娄敬路过洛阳，劝刘邦不要把自己当成继承周代太平的成王。 天下刚经过多年争战，诸侯未必稳服，关中有山河险固、土地和秦留下的条件，比地处四面的洛阳更适合控制局势。张良赞同，强调关中向东供应、顺流出兵的便利。 朝臣多出自崤函以东，主张洛阳东有成皋、西有崤黾、背河向伊洛，足恃其固。张良逐一回应：洛阳腹地才数百里，土薄、四面受敌；关中东凭崤函、西接陇蜀，南有巴蜀富饶、北有苑囿牧利，沃野千里，三面可守、一面制诸侯。诸侯安定时，河渭及陆路转输可向西供给京师；有变时，也能顺流输送粮物。这才是他所说的金城与天府。皇帝当日定下西行之计。 [[19]](#note-19)

<a id="event-20"></a>

20. **刘邦决定西入关中，娄敬获赐刘姓、号奉春君。** 六月又大赦。建都决定发生于本年，长乐、未央宫及官署迁治仍是后来逐步落实的工程，不在宣布迁都的一天全部建成。 [[20]](#note-20)

<a id="七月又出征燕国卢绾得到王位"></a>

<a id="event-21"></a>

21. **七月，刘邦出兵讨伐燕王臧荼。** 燕王臧荼反叛，向代地进攻，刘邦亲自领兵讨伐。 九月，臧荼被俘。诸将推举太尉卢绾接任燕王，刘邦这位旧友也由功臣进入诸侯王之列；樊哙等继续处理代地战事。 陈平以护军中尉从征，其职任没有因楚亡而立即结束。 周勃以将军随征，在易下破燕军，所部当驰道作战而记功。 [[21]](#note-21)

<a id="sj016-succession"></a>

<a id="event-22"></a>

22. **赵王张耳、长沙王吴芮去世，王国随后由儿子承接。** 张敖承赵、吴臣承长沙，不能只看本纪后来的诸王名单，就以为仍是起初那一批人在位。 [[22]](#note-22)

<a id="event-23"></a>

23. **另一位降将利几因害怕朝廷召集登记而反叛。** 他原为项羽部将，楚败后降汉、在颍川获封，后来看到列侯被召，担心自身处境。刘邦亲征，利几败走；原文未记本次已经捕杀，不能补上一个没有根据的死亡结果。 [[23]](#note-23)

**卷030背景阅读：** [汉初钱币与财计：高祖至惠帝、高后](#sj030-early)（跨年材料，不计本年新事）。

<a id="sj041-event-24"></a>

24. **汉朝复立无诸为闽越王。** 无诸与摇率越人参与诸侯灭秦，项羽主持分封时没有立他们为王，二人后来又助汉。汉五年，朝廷复立无诸为闽越王，使统治闽中旧地，都东冶。摇另在惠帝三年获得东海王号，见[前192年](../bce-0200-0101/bce-0192.md#event-4)，两次册封不混为一件。 [[24]](#sj041-note-24)

<a id="sj030-early"></a>

### 汉初钱币与财计：高祖至惠帝、高后

从战后经济读本年罢兵、复业的背景；未明确给年的制度沿革不另设假年条。

以下为跨年背景或篇末评论，不计作本年新发生的编号事件。

<a id="sj030-early-p001"></a>

**战后匮乏与汉初钱币**

汉初承接秦末战争留下的破败：壮年男子出征，老弱转运粮食，生产繁重而财力匮乏，连皇帝也凑不齐同色的四匹驾马，有些将相乘牛车，普通人缺少储蓄。朝廷认为秦钱太重、不便使用，允许民间铸钱，同时简省禁令；逐利者却积压财货、控制市场，粮食和马价大涨。文中记米一石达万钱、马一匹达百金，以表现当时短缺与价格失序。

**[《史记·平准书》P001](../../sources/摘录/史记-卷030-平准书.md#p001)**

> 漢興，接秦之獘，丈夫從軍旅，老弱轉糧馕，作業劇而財匱，自天子不能具鈞駟，而將相或乘牛車，齊民無藏蓋。於是為秦錢重難用，更令民鑄錢，一黃金一斤，約法省禁。而不軌逐利之民，蓄積餘業以稽市物，物踴騰糶，米至石萬錢，馬一匹則百金。

这是汉初多年的总叙，不把粮价、驾马困难和所有币制变化都定为前202年同一天；“一黄金一斤”保留底本，不能据此制造一条足够明确的铜钱兑换率。

<a id="sj030-early-p002"></a>

**抑商规定与国家、皇室收入的区分**

天下大体平定以后，高祖限制商人穿丝衣、乘车，并加重他们的租税，以压低其社会地位。惠帝、吕后时部分限制放宽，但市井商人子孙仍受不得任官的限制。官吏俸禄与官府支出靠向民间征收维持；山川、园池、市场等收入，则分属皇帝或封君的私人奉养，不全并入国家常用经费。东方粮食输往京师供官府使用，每年当时不过数十万石。

**[《史记·平准书》P002](../../sources/摘录/史记-卷030-平准书.md#p002)**

> 天下已平，高祖乃令賈人不得衣絲乘車，重租稅以困辱之。孝惠、高后時，為天下初定，復弛商賈之律，然市井之子孫亦不得仕宦為吏。量吏祿，度官用，以賦於民。而山川園池市井租稅之入，自天子以至于封君湯沐邑，皆各為私奉養焉，不領於天下之經費。漕轉山東粟，以給中都官，歲不過數十萬石。

制度沿革跨高祖、惠帝、高后数朝，放在战后背景附录。“山东”指关隘以东的广大区域，不等于今日山东省；“私奉养”是原书对财政归属的划分，不替古代建立现代预算科目。

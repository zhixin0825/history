# 公元前202年｜项羽败亡，刘邦称帝，新朝开始安排天下

[← 公元前203年](bce-0203.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前201年 →](bce-0201.md)

**汉五年**

> 冬十月、十一月、十二月在本古历年正月以前，未作逐日公历换算。垓下胜利、称帝、封王、迁都和诸侯反抗分阶段写，不把“天下定”当成所有问题已经解决。

## 本年概述

汉军在固陵失利后与韩信、彭越约定分地，合兵在垓下击败楚军。项羽从垓下突围，至乌江自刎。刘邦于氾水之阳即帝位，陆续重定诸王封国，后来听从娄敬、张良之议入关中。

## 垓下决战与楚军败亡

<a id="sj007-guling"></a>
<a id="冬十月追击楚军反在固陵吃了败仗"></a>

<a id="event-1"></a>

<a id="event-2"></a>

1. **汉军固陵失利，刘邦同意分地召韩信、彭越。** 冬十月，刘邦追到阳夏以南、再进固陵，却没等到韩信和彭越。原约会合的援军没有来，楚军反击，大破汉军，刘邦又得挖深沟、筑高垒自守。项羽虽居劣势，仍不是随便一追就会崩溃。张良劝他先讲清战后的利益。韩信、彭越各有军队和期待，不能仅靠催促。刘邦许楚破以后，自陈以东至海给韩信，睢阳以北至谷城给彭越。两人才答应进军。 [[1]](#note-1)

<a id="event-3"></a>

2. **十一月，刘贾围寿春，楚大司马周殷倒戈。** 刘贾奉命南渡淮水，又派人秘密招引周殷。周殷反楚，协助攻取九江，迎黥布兵；韩信由齐南下，彭越和其他部队也到，最后共同逼向垓下。项羽面对的是协调利益以后形成的多路联军，而不只是刘邦自己的一军。 韩信率兵离齐会战时，曹参留在齐地，平定尚未服从的地方。 [[2]](#note-3)

<a id="sj095-event-25"></a>

3. **汉军取阳夏，并在陈地重创楚军。** 汉王追楚时攻下阳夏，樊哙所部记俘楚将周氏部卒四千。灌婴本传同样载在陈下击破楚军。阳夏和陈下是固陵、垓下前后叙事中的不同地点，不以一段行军履历合成一场战斗。 [[3]](#note-25)

<a id="sj007-gaixia"></a>
<a id="十二月垓下从野战转成重围"></a>

<a id="event-4"></a>

<a id="event-5"></a>

4. **垓下楚军败被围，夜闻四面楚歌。** 十二月，韩信率军居前，在垓下接战后稍退。孔将军、费将军率两翼进击，韩信乘势反攻，刘邦、绛侯等列阵在后，联军击败楚军。周勃此前还曾攻曲逆、守敖仓并追击楚军，各战具年未详。项羽营兵少粮尽，夜闻四面楚歌，惊疑汉已尽有楚地，起身饮酒悲歌，虞在一旁相和，左右皆泣。 [[4]](#note-4)

<a id="event-6"></a>

<a id="东城最后的快战改变不了败局"></a>

<a id="event-7"></a>

<a id="sj007-wujiang"></a>
<a id="乌江边项羽没有上船"></a>

<a id="event-8"></a>

<a id="event-9"></a>

5. **项羽从垓下突围，经东城至乌江自刎。** 项羽连夜带八百余骑突围。天明汉军发觉，灌婴率骑追赶。渡淮后随从只剩百余，至阴陵又被田父指错路，陷入泽中。到东城得二十八骑，项羽说是天要亡他，非用兵不善，分队突击、杀将后再聚部众。乌江亭长备舟劝他渡江，项羽因江东八千子弟无人随还，自称无颜见父老，便赠骓马给亭长，令从者下马短兵相斗。他负伤后认出吕马童，提到汉悬赏自己的首级，随后自刎。王翳得其首级，杨喜、吕马童、吕胜、杨武各得部分遗体，合验分功。诸人的正式封侯分见[前200年](../bce-0200-0101/bce-0200.md)与[前199年](../bce-0200-0101/bce-0199.md)。 [[5]](#note-6)

   最后仍能勇猛作战，并不等于能恢复粮食、盟友和已经被打散的主力。个人的近身战能力与整场战争的胜负，在这里分得很清楚。

<a id="鲁最后投降韩信的军队也被刘邦接管"></a>

<a id="event-10"></a>

6. **刘邦出示项羽首级，鲁地投降。** 楚地大多归汉，鲁仍不肯降。 刘邦本拟屠鲁，后来因鲁人坚持为旧主守节，改为出示项羽首级，鲁父老才投降。项羽以旧日鲁公身份的礼仪葬于谷城，刘邦为他发哀而去。 项羽死后，周勃向东定泗水、东海两郡二十二县，随后守洛阳、栎阳，获赐与颍阴侯灌婴共食钟离；这段战后安排不另给月日。 围鲁之际鲁人尚讲诵习礼乐，司马迁借此写当地孔门遗风。 [[6]](#note-10)

<a id="event-11"></a>

7. **项氏旁支没有被一概清算，刘邦却迅速拿回盟友的兵权。** 项伯等后来得到封爵、有人获赐刘姓。刘邦回到定陶，驰入齐王韩信的军营，接管其军队。结束对楚作战，并不代表原来各部将领可以继续完全独立地掌握军事力量。 《高帝纪》在这里还记此前被楚军掳去的百姓获准归家。 [[7]](#note-11)

## 汉帝即位、封国与经营关中

<a id="sj008-emperor"></a>
<a id="正月重新分王二月才正式称帝"></a>

<a id="event-12"></a>

8. **正月，韩信迁为楚王，彭越被立为梁王。** 韩信由齐王迁为楚王，彭越被立为梁王。 刘邦以韩信熟悉楚地风俗为由，把他迁到淮北、都下邳；彭越获得魏故地，都定陶。原韩王信继续王韩，都阳翟，黥布、臧荼等也保有王号。 韩信迁楚、齐地暂为郡以后，曹参交还汉丞相印。 [[8]](#note-12)

<a id="event-13"></a>

9. **诸侯将相请刘邦采用高于王的称号，二月甲午，他在氾水之阳即帝位。** 群臣强调，土地既已分定，若汉王与诸侯仍同称王，便缺少明确上下名分。刘邦经过推辞，终于接受。吕氏成为皇后，刘盈由王太子转为皇太子，已故母亲被追尊为昭灵夫人。 [[9]](#note-13)

<a id="event-14"></a>

10. **吴芮从衡山王转为长沙王，都临湘。** 朝廷以他率百越助灭秦，以及其部将梅鋗曾帮助刘邦入武关等功劳说明这项安排。各王的封地、名号与实际占领范围并非完全同步，不能以同一份名单假定一日内全部交割。 [[10]](#note-14)

<a id="临江还在抵抗五月让一批士卒回家"></a>

<a id="event-15"></a>

11. **临江王不肯降，卢绾、刘贾奉命进攻。** 围攻持续数月，临江王最终投降，后被处死于洛阳。项羽已经死亡，长江中游仍有最后的旧楚王国需要另行处理。 刘贾带来九江兵，共尉死后临江转为南郡；本篇连写这一结局，本纪所说的数月围攻仍须展开理解。 [[11]](#note-15)

<a id="event-16"></a>

12. **五月，兵士罢归，朝廷宣布战后复免。** 留在关中的诸侯子有十二年复免，回乡者减半，并给一年食粮。流亡山泽、脱离户籍的百姓可以回本县、恢复旧爵田宅；因饥饿卖身者获免为庶人。朝廷也要求地方官按规定照顾有军功者，不以笞辱和拖延阻碍安置。 诏令还区分军吏士卒的授爵和晋级，并要求地方官尽快落实有军功者应得的田宅。 [[12]](#note-16)

<a id="sj008-nangong"></a>
<a id="南宫宴上刘邦问自己为什么赢"></a>

<a id="event-17"></a>

<a id="event-18"></a>

13. **刘邦在洛阳南宫论胜负与用人。** 南宫宴上，刘邦问自己为什么赢。高起、王陵先把答案归于肯与人分享利益。他们并没有只奉承皇帝温厚，反而说刘邦待人傲慢，项羽有时更仁爱；区别在于刘邦能将攻得的地盘和好处给立功者，项羽却疑贤害功，不肯把成果分出去。刘邦说自己胜在能用三个人。运筹决胜不如张良，安定后方、供粮抚民不如萧何，统率大军不如韩信；但他能用这些人，项羽却连一个范增也不能用。这是新皇帝在胜利后的自我解释，同时说明他怎样向功臣界定自己的领导地位。 [[13]](#note-17)

<a id="sj008-capital"></a>
<a id="不长留洛阳而往关中建都"></a>

<a id="event-19"></a>

<a id="event-20"></a>

14. **娄敬、张良劝都关中，刘邦西入关。** 娄敬、张良劝刘邦在关中建都。齐人娄敬路过洛阳，劝刘邦不要把自己当成继承周代太平的成王。天下刚经过多年争战，诸侯未必稳服，关中有山河险固、土地和秦留下的条件，比地处四面的洛阳更适合控制局势。张良赞同，强调关中向东供应、顺流出兵的便利。朝臣多出自崤函以东，主张洛阳东有成皋、西有崤黾、背河向伊洛，足恃其固。张良逐一回应：洛阳腹地才数百里，土薄、四面受敌；关中东凭崤函、西接陇蜀，南有巴蜀富饶、北有苑囿牧利，沃野千里，三面可守、一面制诸侯。诸侯安定时，河渭及陆路转输可向西供给京师；有变时，也能顺流输送粮物。这才是他所说的金城与天府。皇帝当日定下西行之计。刘邦决定西入关中，娄敬获赐刘姓、号奉春君。六月又大赦。建都决定发生于本年，长乐、未央宫及官署迁治仍是后来逐步落实的工程，不在宣布迁都的一天全部建成。 [[14]](#note-19)

<a id="sj041-event-24"></a>

15. **汉朝复立无诸为闽越王。** 无诸与摇率越人参与诸侯灭秦，项羽主持分封时没有立他们为王，二人后来又助汉。汉五年，朝廷复立无诸为闽越王，使统治闽中旧地，都东冶。摇另在惠帝三年获得东海王号，见[前192年](../bce-0200-0101/bce-0192.md#event-4)，两次册封不混为一件。 [[15]](#sj041-note-24)

<a id="sj100-event-26"></a>

16. **季布亡命获赦，丁公归汉被诛。** 项羽败亡后，刘邦悬赏搜捕曾屡次困住他的楚将季布，并以三族相威胁。季布经濮阳周氏藏匿和朱家营救，滕公夏侯婴进言后得到赦免，出任郎中。丁公曾在彭城西放走刘邦，楚亡后却被刘邦以不忠于项羽为由处斩，示警后来臣下。 [[16]](#note-26)

<a id="hs001-event-27"></a>

17. **正月，刘邦追尊长兄为武哀侯。** 刘邦追尊已经去世的兄伯，称武哀侯。吕后时期再议尊为武哀王，另见当年。 [[17]](#hs001-note-27)

<a id="hs001-event-28"></a>

18. **正月，刘邦下令赦天下殊死以下。** 刘邦说战事八年未能停息，百姓受苦，既然天下大局已定，便下令赦免殊死以下的罪犯。 [[18]](#hs001-note-28)

<a id="hs001-event-29"></a>

19. **后九月，迁诸侯子入关中并整治长乐宫。** 后九月，汉廷迁诸侯的子弟入关中，并开始整治长乐宫。宫成及官署迁治在后来。 [[19]](#hs001-note-29)

## 燕乱、利几反叛及诸王去世

<a id="七月又出征燕国卢绾得到王位"></a>

<a id="event-21"></a>

<a id="hs-event-30"></a>

20. **刘邦平定臧荼之叛，以卢绾为燕王。** 七月，燕王臧荼反叛，向代地进攻，刘邦亲自领兵讨伐。九月，臧荼被俘。诸将推举太尉卢绾接任燕王，刘邦这位旧友也由功臣进入诸侯王之列；樊哙等继续处理代地战事。陈平以护军中尉从征，其职任没有因楚亡而立即结束。周勃以将军随征，在易下破燕军，所部当驰道作战而记功。卢绾改封燕王，王恬启等列官。参见本年的官职变动原句。 [[20]](#note-21)

<a id="sj016-succession"></a>

<a id="event-22"></a>

21. **赵王张耳、长沙王吴芮去世，王国随后由儿子承接。** 张敖承赵、吴臣承长沙，不能只看本纪后来的诸王名单，就以为仍是起初那一批人在位。 [[21]](#note-22)

<a id="event-23"></a>

22. **另一位降将利几因害怕朝廷召集登记而反叛。** 他原为项羽部将，楚败后降汉、在颍川获封，后来看到列侯被召，担心自身处境。刘邦亲征，利几败走；原文未记本次已经捕杀，不能补上一个没有根据的死亡结果。 [[22]](#note-23)

> 已而問婁敬，婁敬說曰：「陛下都洛陽，豈欲與周室比隆哉？」上曰：「然。」婁敬曰：「陛下取天下與周室異。周之先自后稷，堯封之邰，積德累善十有餘世。公劉避桀居豳。太王以狄伐故，去豳，杖馬箠居岐，國人爭隨之。及文王爲西伯，斷虞芮之訟，始受命，呂望、伯夷自海濵來歸之。武王伐紂，不期而會孟津之上八百諸侯，皆曰紂可伐矣，遂滅殷。成王即位，周公之屬傅相焉，迺營成周洛邑，以此爲天下之中也，諸侯四方納貢職，道里均矣，有德則易以王，無德則易以亡。凡居此者，欲令周務以德致人，不欲依阻險，令後世驕奢以虐民也。及周之盛時，天下和洽，四夷鄉風，慕義懷德，附離而並事天子，不屯一卒，不戰一士，八夷大國之民莫不賔服，効其貢職。及周之衰也，分而爲兩，天下莫朝，周不能制也。非其德薄也，而形勢弱也。今陛下起豐擊沛，收卒三千人，以之徑徃而卷蜀漢，定三秦，與項羽戰滎陽，爭成臯之口，大戰七十，小戰四十，使天下之民肝腦塗地，父子暴骨中野，不可勝數，哭泣之聲未絕，傷痍者未起，而欲比隆於成康之時，臣竊以爲不侔也。且夫秦地被山帶河，四塞以爲固，卒然有急，百萬之衆可具也。因秦之故，資甚美膏腴之地，此所謂天府者也。陛下入關而都之，山東雖亂，秦之故地可全而有也。夫與人鬬，不搤其肮，拊其背，未能全其勝也。今陛下入關而都，案秦之故地，此亦搤天下之肮而拊其背也。」

#### 4｜请尊、即位与王国名单

卷008 P041从正月请尊接甲午即位，未明确另起月份；《汉书》《通鉴》为二月甲午，正文采用后者。韩信迁楚、彭越立梁为正月安排，吴芮长沙为二月。黥布淮南王前203年已立，张耳本年死后才有张敖（本纪称赵敖）；本纪将人物合列，不能写成同一日新立全部诸王。梅鋗助武关的前事仍归前207年。高祖本纪临江王称驩，汉书、通鉴称共尉，正文按末代临江王作为同事互见，区别其父共敖。

<a id="5战后政策与胜者解释"></a>
#### 5｜战后政策与胜者解释

[卷008 P044—P046](../../拆分史书/史记/卷008.md#p044)。复免对象、役种与年限按诏令辨别，不能扩大成全国所有人一律免税十二年。流亡回籍、自卖者复庶、官吏不得笞辱的细节来自汉书五月诏，明确为补充。南宫宴是史书保存的胜者解释，不能仅凭刘邦自述证明只有一个成功原因；娄敬未受赐姓前用原姓，受赐之后称刘敬。

<a id="6臧荼的月份"></a>
#### 6｜臧荼的月份

卷008 P047写十月，而《汉书》《通鉴》记七月反、九月俘，正文采用可连贯的后者，不另在汉六年十月又造一次燕王之乱。利几只记败走，没有捕杀结果。赵、长沙两王的继承由《通鉴》补充，用于校正后文沿用旧王姓名的问题。

<a id="卷015表末的前瞻项羽终局与汉统一"></a>
#### 卷015表末的前瞻｜项羽终局与汉统一

[《六国年表》前207年末行](../../拆分史书/史记/卷015.md#y0207)末句“寻诛羽，天下属汉”，已经超出表格最后一年的范围，概括的是楚汉战争以项羽失败、汉取得天下告终的后事。本句与本页既有的项羽终局、刘邦称帝诸条互见，不另造一次项羽死亡；也不把“寻”理解为项羽在秦二世三年即遭诛杀。其前句子婴投降、项羽入关杀子婴的承接见[前206年页](bce-0206.md#sj015-0207-forward)。

<a id="卷016逐月互见与取舍"></a>
### 卷016｜逐月互见与取舍

<a id="sj016-m12-note"></a>
<a id="十二月项羽与临江的终局"></a>
#### 十二月｜项羽与临江的终局

[本月原格](../../拆分史书/史记/卷016.md#m0202-12)项栏“诛籍”归[垓下](#sj007-gaixia)至[乌江](#sj007-wujiang)，正月汉栏“杀项籍”不另造死亡。临江栏“汉虏驩”归本页临江抵抗及[异名说明](#sj008-founding-note)；本纪记围攻数月，月表压在十二月，正文不强定与垓下同日完成。其父共敖已在[前204年](bce-0204.md#sj016-linjiang)去世。十、十一月纯计月格不覆盖其他史书记载的固陵与会师。

<a id="sj016-m01-note"></a>
<a id="正月分王改郡与一项提前记载"></a>
#### 正月｜分王、改郡与一项提前记载

[本月原格](../../拆分史书/史记/卷016.md#m0202-01)项栏韩信迁楚、齐栏四郡、魏栏复置梁国与[正月王国安排](#sj008-emperor)合读；四郡名原格未载，不凭后来的州郡地理倒填。衡山栏迁王长沙、原河南栏分临江为长沙，接吴芮转封；原临江栏南郡则是战后归属。后栏名仅是沿用位置，不是申阳的河南国迁到长沙。

九江栏“淮南国”、原常山栏“赵国”、燕栏“燕国”是王国延续及版面衔接，不写成三位国君本月都重新即位。汉栏“杀项籍，天下平”概括终局，与十二月同事，且不否定本年燕、临江等后续抵抗。韩栏“韩王信徙王代，都马邑”与汉书六年的迁北安排不同，本页仅存原表异年，主叙接[前201年](bce-0201.md#sj016-forward)，不在两年迁两次。

<a id="sj016-m02-note"></a>
<a id="二月称帝与王国名号"></a>
#### 二月｜称帝与王国名号

[本月原格](../../拆分史书/史记/卷016.md#m0202-02)汉栏二月甲午即帝位，与[既有称帝条](#sj008-emperor)同日；地点表作定陶，本纪、汉书作氾水之阳，可能涉及区域与具体地名层次，本轮不据两个名称造两次登极。

梁栏彭越“始”较汉书正月封王晚一月，仍采用[正月安排](#sj008-founding-note)，保留表位；原河南栏吴芮为长沙王与本页二月转封合并，原衡山栏“属淮南国”另保留为领土归属简记，不能据此证明衡山全境逐城交割已完成。重复“为为”原字保留在源表。

<a id="sj016-m06-note"></a>
<a id="六月皇帝入关"></a>
#### 六月｜皇帝入关

[本月汉栏](../../拆分史书/史记/卷016.md#m0202-06)接[娄敬、张良议都与西行](#sj008-capital)。入关、决定都关中、后来的宫室竣工及官署迁治是不同阶段，不把工程均提前至此月。

<a id="sj016-m07-note"></a>
<a id="七月张耳与吴芮去世"></a>
#### 七月月表所载的张耳与吴芮之卒

[本月原常山／赵及原河南／长沙两格](../../拆分史书/史记/卷016.md#m0202-07)均在七月列卒，八月列嗣王；[《汉书·异姓诸侯王表》](../../拆分史书/汉书/卷013.md#part-1-L1262)则书张耳五年十二月乙丑、吴芮六月。[《汉书·高帝纪》](../../拆分史书/汉书/卷001.md#part-1-L66)二月即帝位前的劝进文已列赵王张敖，黄一农据此指出张耳七月卒有冲突。正文沿列传暂系五年，附[两王继承条](#sj016-succession)与[卷089考证](../../拆分史书/史记/卷089.md#kao-e76505c622)。景王为张耳谥号，文王为吴芮谥号，不是两位新登场的同名君王；其国、其子的衔接与本年朝廷建国安排分别处理。

<a id="sj016-m08-note"></a>
<a id="八月张敖吴臣计月与皇帝征燕"></a>
#### 八月｜张敖、吴臣计月与皇帝征燕

[本月原格](../../拆分史书/史记/卷016.md#m0202-08)张敖、吴臣开始计月，接[父卒子继](#sj016-succession)。表明载“耳子”“芮子”，旧正文“赵敖”在此明确为张敖；不能把国名称谓另当一个姓氏人物。吴臣“成王”同属后谥，不倒推出当时已经去世。

汉栏八月自将诛燕与汉书七月反、九月虏的起讫相接，保留作期间军事行动，不因本表八月便删除七月反叛的明确记载。

<a id="sj016-m09-note"></a>
<a id="九月臧荼被俘与钟离眛异年"></a>
#### 九月｜臧荼被俘与钟离眛异年

[本月原格](../../拆分史书/史记/卷016.md#m0202-09)燕栏“反汉，虏荼”压缩叛乱和结局，仍按七月反、九月俘分述。楚栏韩信得钟离眛“斩之以闻”与列传、通鉴六年云梦前的叙述不同，主叙接[前201年](bce-0201.md#sj016-forward)，本页不造第二次杀将。“鍾離辚”等字形在原格保留，详注区分自杀与随后持首求见。

<a id="sj016-m09b-note"></a>
<a id="后九月卢绾接燕"></a>
#### 后九月｜卢绾接燕

[本月燕栏](../../拆分史书/史记/卷016.md#m0202-09b)“燕王卢绾始，汉太尉”接本页征燕后的议立；汉书九月议立、表后九月开始计月有差别，正文不虚构一个两书全同的确日。卢绾不是新出现在世界上的人物，此前寿春、袭楚粮道等活动仍在原年。至此月表90个月份位置结束，后续捕韩信、迁韩王信继续在下一年页。

<a id="sj030-early"></a>

### 汉初钱币与财计：高祖至惠帝、高后

从战后经济读本年罢兵、复业的背景；未明确给年的制度沿革不另设假年条。

以下为跨年背景或篇末评论，不计作本年新发生的编号事件。

<a id="sj030-early-p001"></a>

**战后匮乏与汉初钱币**

汉初承接秦末战争留下的破败：壮年男子出征，老弱转运粮食，生产繁重而财力匮乏，连皇帝也凑不齐同色的四匹驾马，有些将相乘牛车，普通人缺少储蓄。朝廷认为秦钱太重、不便使用，允许民间铸钱，同时简省禁令；逐利者却积压财货、控制市场，粮食和马价大涨。文中记米一石达万钱、马一匹达百金，以表现当时短缺与价格失序。

**[《史记·平准书》P001](../../拆分史书/史记/卷030.md#p001)**

> 漢興，接秦之獘，丈夫從軍旅，老弱轉糧馕，作業劇而財匱，自天子不能具鈞駟，而將相或乘牛車，齊民無藏蓋。於是為秦錢重難用，更令民鑄錢，一黃金一斤，約法省禁。而不軌逐利之民，蓄積餘業以稽市物，物踴騰糶，米至石萬錢，馬一匹則百金。

这是汉初多年的总叙，不把粮价、驾马困难和所有币制变化都定为前202年同一天；“一黄金一斤”保留底本，不能据此制造一条足够明确的铜钱兑换率。

<a id="sj030-early-p002"></a>

**抑商规定与国家、皇室收入的区分**

天下大体平定以后，高祖限制商人穿丝衣、乘车，并加重他们的租税，以压低其社会地位。惠帝、吕后时部分限制放宽，但市井商人子孙仍受不得任官的限制。官吏俸禄与官府支出靠向民间征收维持；山川、园池、市场等收入，则分属皇帝或封君的私人奉养，不全并入国家常用经费。东方粮食输往京师供官府使用，每年当时不过数十万石。

**[《史记·平准书》P002](../../拆分史书/史记/卷030.md#p002)**

> 天下已平，高祖乃令賈人不得衣絲乘車，重租稅以困辱之。孝惠、高后時，為天下初定，復弛商賈之律，然市井之子孫亦不得仕宦為吏。量吏祿，度官用，以賦於民。而山川園池市井租稅之入，自天子以至于封君湯沐邑，皆各為私奉養焉，不領於天下之經費。漕轉山東粟，以給中都官，歲不過數十萬石。

制度沿革跨高祖、惠帝、高后数朝，放在战后背景附录。“山东”指关隘以东的广大区域，不等于今日山东省；“私奉养”是原书对财政归属的划分，不替古代建立现代预算科目。

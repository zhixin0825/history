# 公元前202年｜项羽败亡，刘邦称帝，新朝开始安排天下

[← 公元前203年](bce-0203.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前201年 →](bce-0201.md)

**汉五年**

> 冬十月、十一月、十二月在本古历年正月以前，未作逐日公历换算。垓下胜利、称帝、封王、迁都和诸侯反抗分阶段写，不把“天下定”当成所有问题已经解决。

### 冬十月，追击楚军反在固陵吃了败仗

<a id="event-1"></a>

1. **刘邦追到阳夏以南、再进固陵，却没等到韩信和彭越。** 原约会合的援军没有来，楚军反击，大破汉军，刘邦又得挖深沟、筑高垒自守。项羽虽居劣势，仍不是随便一追就会崩溃。[卷007 P039](../../sources/摘录/史记-卷007-项羽本纪.md#p039) · [卷008 P039](../../sources/摘录/史记-卷008-高祖本纪.md#p039)。 [[1]](#note-1)

<a id="event-2"></a>

2. **张良劝他先讲清战后的利益。** 韩信、彭越各有军队和期待，不能仅靠催促。刘邦许楚破以后，自陈以东至海给韩信，睢阳以北至谷城给彭越。两人才答应进军。[卷007 P039](../../sources/摘录/史记-卷007-项羽本纪.md#p039)。 [[2]](#note-2)

<a id="event-3"></a>

3. **十一月，刘贾围寿春，楚大司马周殷倒戈。** 周殷带九江方面军队来会，韩信由齐南下，彭越和其他部队也到，最后共同逼向垓下。项羽面对的是协调利益以后形成的多路联军，而不只是刘邦自己的一军。[卷007 P039](../../sources/摘录/史记-卷007-项羽本纪.md#p039) · [《通鉴》卷十一](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7011.md#ref-0166492b044405)。 [[3]](#note-3)

<a id="sj007-gaixia"></a>
<a id="十二月垓下从野战转成重围"></a>
### 十二月，垓下从野战转成重围

<a id="event-4"></a>

4. **韩信居前，两翼与后阵配合，才把楚军打败。** 韩信最初交战不利后退，孔将军、费将军所领两翼投入，楚军转为不利，韩信再乘势反击。刘邦与绛侯等军在后，联军由此取得决战胜利。[卷008 P040](../../sources/摘录/史记-卷008-高祖本纪.md#p040)。 [[4]](#note-4)

<a id="event-5"></a>

5. **楚军兵少食尽，营垒被围，夜里四面传来楚歌。** 项羽惊疑汉已尽得楚地，起身在帐中饮酒，悲歌感叹力量与时运，虞在旁相和，左右都流泪。[卷007 P040](../../sources/摘录/史记-卷007-项羽本纪.md#p040)。 [[5]](#note-5)

<a id="event-6"></a>

6. **最后一夜，项羽带八百余骑突围南走。** 天明汉军才发觉，灌婴带骑兵追赶。渡淮后只剩百余人跟上；阴陵问路又被田间老人指错方向，陷入沼泽，追兵进一步逼近。[卷007 P041](../../sources/摘录/史记-卷007-项羽本纪.md#p041)。 [[6]](#note-6)

<a id="东城最后的快战改变不了败局"></a>
### 东城最后的快战，改变不了败局

<a id="event-7"></a>

7. **身边只剩二十八骑，项羽仍要证明自己没有输在用兵。** 他对部下说，起兵八年、经历七十余战，如今是天要亡他，愿再痛快打一次让大家看看。随后分队突击、杀将、叱退追者，又聚拢余骑。[卷007 P041](../../sources/摘录/史记-卷007-项羽本纪.md#p041)。 [[7]](#note-7)

   最后仍能勇猛作战，并不等于能恢复粮食、盟友和已经被打散的主力。个人的近身战能力与整场战争的胜负，在这里分得很清楚。

<a id="sj007-wujiang"></a>
<a id="乌江边项羽没有上船"></a>
### 乌江边，项羽没有上船

<a id="event-8"></a>

8. **亭长备船劝他回江东，项羽却不肯渡。** 他想到当初带八千江东子弟西行，如今无人随还，即使父老愿意再拥他为王，自己也无颜相见。他将骓马赠给亭长，令余骑下马，以短兵作最后抵抗。[卷007 P042](../../sources/摘录/史记-卷007-项羽本纪.md#p042)。 [[8]](#note-8)

<a id="event-9"></a>

9. **项羽多处负伤，认出吕马童，随后自刎。** 他提到汉悬赏自己的首级，愿送故人这份好处。王翳取得首级，杨喜、吕马童、吕胜、杨武也各取得部分遗体，合验后分功。正式封侯则在以后，分见[前200](../bce-0200-0101/bce-0200.md)、[前199](../bce-0200-0101/bce-0199.md)年，不全在死亡当日。[卷007 P042](../../sources/摘录/史记-卷007-项羽本纪.md#p042)。 [[9]](#note-9)

<a id="鲁最后投降韩信的军队也被刘邦接管"></a>
### 鲁最后投降，韩信的军队也被刘邦接管

<a id="event-10"></a>

10. **楚地大多归汉，鲁仍不肯降。** 刘邦本拟屠鲁，后来因鲁人坚持为旧主守节，改为出示项羽首级，鲁父老才投降。项羽以旧日鲁公身份的礼仪葬于谷城，刘邦为他发哀而去。[卷007 P043](../../sources/摘录/史记-卷007-项羽本纪.md#p043)。 [[10]](#note-10)

<a id="event-11"></a>

11. **项氏旁支没有被一概清算，刘邦却迅速拿回盟友的兵权。** 项伯等后来得到封爵、有人获赐刘姓。刘邦回到定陶，驰入齐王韩信的军营，接管其军队。结束对楚作战，并不代表原来各部将领可以继续完全独立地掌握军事力量。[卷007 P044](../../sources/摘录/史记-卷007-项羽本纪.md#p044) · [卷008 P040](../../sources/摘录/史记-卷008-高祖本纪.md#p040)。 [[11]](#note-11)

<a id="sj008-emperor"></a>
<a id="正月重新分王二月才正式称帝"></a>
### 正月重新分王，二月才正式称帝

<a id="event-12"></a>

12. **韩信由齐王迁为楚王，彭越被立为梁王。** 刘邦以韩信熟悉楚地风俗为由，把他迁到淮北、都下邳；彭越获得魏故地，都定陶。原韩王信继续王韩，都阳翟，黥布、臧荼等也保有王号。[卷008 P042](../../sources/摘录/史记-卷008-高祖本纪.md#p042) · [《通鉴》卷十一正月](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7011.md#ref-a6bc2907fdffea)。 [[12]](#note-12)

<a id="event-13"></a>

13. **诸侯将相请刘邦采用高于王的称号，二月甲午，他在氾水之阳即帝位。** 群臣强调，土地既已分定，若汉王与诸侯仍同称王，便缺少明确上下名分。刘邦经过推辞，终于接受。吕氏成为皇后，刘盈由王太子转为皇太子，已故母亲被追尊为昭灵夫人。[卷008 P041](../../sources/摘录/史记-卷008-高祖本纪.md#p041) · [《汉书》高帝纪五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7001.md#ref-c54524ae6d7901)。 [[13]](#note-13)

<a id="event-14"></a>

14. **吴芮从衡山王转为长沙王，都临湘。** 朝廷以他率百越助灭秦，以及其部将梅鋗曾帮助刘邦入武关等功劳说明这项安排。各王的封地、名号与实际占领范围并非完全同步，不能以同一份名单假定一日内全部交割。[卷008 P042](../../sources/摘录/史记-卷008-高祖本纪.md#p042)。 [[14]](#note-14)

<a id="临江还在抵抗五月让一批士卒回家"></a>
### 临江还在抵抗，五月让一批士卒回家

<a id="event-15"></a>

15. **临江王不肯降，卢绾、刘贾奉命进攻。** 围攻持续数月，临江王最终投降，后被处死于洛阳。项羽已经死亡，长江中游仍有最后的旧楚王国需要另行处理。[卷008 P043](../../sources/摘录/史记-卷008-高祖本纪.md#p043)。 [[15]](#note-15)

<a id="event-16"></a>

16. **五月，兵士罢归，朝廷宣布战后复免。** 留在关中的诸侯子有十二年复免，回乡者减半，并给一年食粮。流亡山泽、脱离户籍的百姓可以回本县、恢复旧爵田宅；因饥饿卖身者获免为庶人。朝廷也要求地方官按规定照顾有军功者，不以笞辱和拖延阻碍安置。[卷008 P044](../../sources/摘录/史记-卷008-高祖本纪.md#p044) · [《汉书》五年五月诏](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7001.md#ref-d36f24b1a631a6)。 [[16]](#note-16)

<a id="sj008-nangong"></a>
<a id="南宫宴上刘邦问自己为什么赢"></a>
### 南宫宴上，刘邦问自己为什么赢

<a id="event-17"></a>

17. **高起、王陵先把答案归于肯与人分享利益。** 他们并没有只奉承皇帝温厚，反而说刘邦待人傲慢，项羽有时更仁爱；区别在于刘邦能将攻得的地盘和好处给立功者，项羽却疑贤害功，不肯把成果分出去。[卷008 P045](../../sources/摘录/史记-卷008-高祖本纪.md#p045)。 [[17]](#note-17)

<a id="event-18"></a>

18. **刘邦说自己胜在能用三个人。** 运筹决胜不如张良，安定后方、供粮抚民不如萧何，统率大军不如韩信；但他能用这些人，项羽却连一个范增也不能用。这是新皇帝在胜利后的自我解释，同时说明他怎样向功臣界定自己的领导地位。[卷008 P045](../../sources/摘录/史记-卷008-高祖本纪.md#p045)。 [[18]](#note-18)

<a id="sj008-capital"></a>
<a id="不长留洛阳而往关中建都"></a>
### 不长留洛阳，而往关中建都

<a id="event-19"></a>

19. **齐人娄敬路过洛阳，劝刘邦不要把自己当成继承周代太平的成王。** 天下刚经过多年争战，诸侯未必稳服，关中有山河险固、土地和秦留下的条件，比地处四面的洛阳更适合控制局势。张良赞同，强调关中向东供应、顺流出兵的便利。[卷008 P046](../../sources/摘录/史记-卷008-高祖本纪.md#p046) · [《通鉴》卷十一](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7011.md#ref-4b1e1072068e3f)。 [[19]](#note-19)

<a id="event-20"></a>

20. **刘邦决定西入关中，娄敬获赐刘姓、号奉春君。** 六月又大赦。建都决定发生于本年，长乐、未央宫及官署迁治仍是后来逐步落实的工程，不在宣布迁都的一天全部建成。[卷008 P046](../../sources/摘录/史记-卷008-高祖本纪.md#p046)。 [[20]](#note-20)

<a id="七月又出征燕国卢绾得到王位"></a>
### 七月又出征燕国，卢绾得到王位

<a id="event-21"></a>

21. **燕王臧荼反叛，向代地进攻，刘邦亲自领兵讨伐。** 九月，臧荼被俘。诸将推举太尉卢绾接任燕王，刘邦这位旧友也由功臣进入诸侯王之列；樊哙等继续处理代地战事。[卷008 P047](../../sources/摘录/史记-卷008-高祖本纪.md#p047) · [《通鉴》卷十一七、九月条](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7011.md#ref-4a4762d01c5359)。 [[21]](#note-21)

<a id="sj016-succession"></a>

<a id="event-22"></a>

22. **七月，赵王张耳、长沙王吴芮去世，王国随后由儿子承接。** 张敖承赵、吴臣承长沙，不能只看本纪后来的诸王名单，就以为仍是起初那一批人在位。[《通鉴》卷十一](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7011.md#ref-e9ebb19c65f660) · [月表卒月](#sj016-m07-note) · [八月新王计月](#sj016-m08-note)。 [[22]](#note-22)

<a id="event-23"></a>

23. **另一位降将利几因害怕朝廷召集登记而反叛。** 他原为项羽部将，楚败后降汉、在颍川获封，后来看到列侯被召，担心自身处境。刘邦亲征，利几败走；原文未记本次已经捕杀，不能补上一个没有根据的死亡结果。[卷008 P047](../../sources/摘录/史记-卷008-高祖本纪.md#p047)。 [[23]](#note-23)

## 归年与考证

<a id="sj022"></a>

<a id="sj022-note"></a>
<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[本年原表R005](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r005) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0202)。

> 纪年：五；大事纪：冬，破楚垓下，殺項籍。春，王踐皇帝位定陶。。入都關中。；相位：五。罷太尉官。；将位：四。後九月，綰為燕王。；御史大夫位：〔空〕

垓下、项羽终局、称帝及定都均为本页原事件。相位“五”仍数萧何在相任期，“罢太尉官”是官制事项；将位“四”仍为卢绾，不能把它误接成萧何当过太尉。卢绾封燕的后九月接本页已有议立与月表，不用本表创造第二次封王。



<a id="1固陵垓下与军阵"></a>
#### 1｜固陵、垓下与军阵

[卷007 P039—P040](../../sources/摘录/史记-卷007-项羽本纪.md#p039) · [卷008 P039—P040](../../sources/摘录/史记-卷008-高祖本纪.md#p039)。冬十月固陵、十一月会军、十二月垓下据《通鉴》串联；许地与实际封地交割分开。卷008记韩信前阵三十万、楚约十万、斩首八万，均属史书所报，不能当作独立点名册计算歼灭率。孔、费将军以及柴将军的简称不据此补未经核定的全名；皇帝、淮阴侯在战阵中是后称，不提前授号。

<a id="2虞东城与乌江"></a>
#### 2｜虞、东城与乌江

[卷007 P040—P042](../../sources/摘录/史记-卷007-项羽本纪.md#p040)未写虞自刎，也未给其和歌全文，正文不从戏曲补造。东城快战、乌江自刎与卷008概称“追杀项羽东城”存在叙事详细程度和地理用语差异，沿原有详细叙事，不让项羽死两次，也不据简写宣布某一现代遗址已确定。[终局考证](../../meta/考证/史记-卷007-纪年与异说.md#终局)。八百、百余、二十八、八千及“天亡我”按各自话语层次理解。

<a id="3旧的封侯去向不删除"></a>
#### 3｜旧的封侯去向不删除

[卷007 P042、P044](../../sources/摘录/史记-卷007-项羽本纪.md#p042) · [卷018核对T1](../../sources/摘录/史记-卷007-项羽本纪.md#t1)：项伯初封前201；项它前201归汉、前200初封；吕马童、王翳、杨喜、吕胜前200；杨武前199；刘襄桃侯前195。玄武侯可靠对应尚未定，留考证，不把后来授爵全压成项羽死日，也不让赐姓自动继承封侯日。

<a id="sj008-founding-note"></a>
<a id="4请尊即位与王国名单"></a>
#### 4｜请尊、即位与王国名单

卷008 P041从正月请尊接甲午即位，未明确另起月份；《汉书》《通鉴》为二月甲午，正文采用后者。韩信迁楚、彭越立梁为正月安排，吴芮长沙为二月。黥布淮南王前203年已立，张耳本年死后才有张敖（本纪称赵敖）；本纪将人物合列，不能写成同一日新立全部诸王。梅鋗助武关的前事仍归前207年。高祖本纪临江王称驩，汉书、通鉴称共尉，正文按末代临江王作为同事互见，区别其父共敖。

<a id="5战后政策与胜者解释"></a>
#### 5｜战后政策与胜者解释

[卷008 P044—P046](../../sources/摘录/史记-卷008-高祖本纪.md#p044)。复免对象、役种与年限按诏令辨别，不能扩大成全国所有人一律免税十二年。流亡回籍、自卖者复庶、官吏不得笞辱的细节来自汉书五月诏，明确为补充。南宫宴是史书保存的胜者解释，不能仅凭刘邦自述证明只有一个成功原因；娄敬未受赐姓前用原姓，受赐之后称刘敬。

<a id="6臧荼的月份"></a>
#### 6｜臧荼的月份

卷008 P047写十月，而《汉书》《通鉴》记七月反、九月俘，正文采用可连贯的后者，不另在汉六年十月又造一次燕王之乱。利几只记败走，没有捕杀结果。赵、长沙两王的继承由《通鉴》补充，用于校正后文沿用旧王姓名的问题。

<a id="sj006-066-endnote"></a>
<a id="卷006结语与本卷接合"></a>
#### 卷006结语与本卷接合

[卷006 P066](../../sources/摘录/史记-卷006-秦始皇本纪.md#p066)“后五年，天下定于汉”，以汉五年为阶段终点。卷007的项羽终局与本轮卷008称帝后的安排都在本页，旧锚点保留。“天下定”不表示从此再无战争；当年的臧荼、利几已经说明，胜利后的统治仍需不断处理军队与诸侯。

司马迁对项羽功业与败亡的评价、司马贞的后附述赞仍见[卷007 P045—P046](../../sources/摘录/史记-卷007-项羽本纪.md#p045)，不与南宫宴中刘邦本人的发言混为同一作者观点。

<a id="sj015-0207-forward"></a>
<a id="卷015表末的前瞻项羽终局与汉统一"></a>
#### 卷015表末的前瞻｜项羽终局与汉统一

[《六国年表》前207年末行](../../sources/摘录/史记-卷015-六国年表.md#y0207)末句“寻诛羽，天下属汉”，已经超出表格最后一年的范围，概括的是楚汉战争以项羽失败、汉取得天下告终的后事。本句与本页既有的项羽终局、刘邦称帝诸条互见，不另造一次项羽死亡；也不把“寻”理解为项羽在秦二世三年即遭诛杀。其前句子婴投降、项羽入关杀子婴的承接见[前206年页](bce-0206.md#sj015-0207-forward)。

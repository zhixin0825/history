# 公元前203年｜成皋和齐地改变战局，汉增封盟友，鸿沟议和又起追兵

[← 公元前204年](bce-0204.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前202年 →](bce-0202.md)

**汉四年**

> 十月、十一月是古历本年开端，在正月、二月以前。楚汉在广武相持，汉有敖仓和后方补给，楚的粮食与盟友逐渐减少。

## 本年概述

汉军破曹咎，楚汉在广武对峙，项羽以刘太公相胁，刘邦列项羽罪状后中箭。韩信取齐、败龙且，受封齐王。双方议以鸿沟分界，项羽东归，刘邦随后改变西归打算。

## 广武对峙与成皋战局

1. **汉军大破曹咎、夺回成皋，项羽回师。** 冬十月，汉军连续挑战、辱骂，终于引出曹咎。他原受命固守成皋，忍了五六日后动怒，率军渡汜水。士卒渡到一半，汉军进攻，大破楚军，取得其物资。曹咎、司马欣自杀，汉复取成皋、驻广武，利用敖仓粮食。项羽在睢阳闻败，急忙回来救援。汉军正围钟离眛于荥阳东，见项羽到来，退向险阻。项羽救了眼前的部下，却未能把汉从敖仓、成皋赶走，两军继续在广武相守。 [[1]](#note-1)

2. **项羽以刘太公相胁，经项伯劝阻后作罢。** 太公被拿来威胁，刘邦仍不低头。项羽把太公置于高俎上，声称将要烹杀。楚粮道受彭越袭击，项羽想用刘邦的父亲逼对手屈服。刘邦却援引二人受命怀王时的兄弟盟约，说自己的父亲也是项羽的父亲，若真烹杀，请分一杯羹。项伯劝杀太公无益于战局，只会增加祸患，项羽终于作罢。家属仍留楚军作筹码，没有在这次威胁中被杀。 [[2]](#note-3)

3. **广武对峙，刘邦列举项羽罪状，中箭后劳军。** 项羽想以两人的决斗结束战争，刘邦却说宁斗智，不斗力。壮丁苦于军旅、老弱疲于转输，双方长期消耗。楚军勇士出阵，屡被汉军善射者楼烦射杀；项羽亲自披甲持戟出来，楼烦又因其叱喝退回。刘邦当面列举十条罪状，把战争说成对项羽背约行为的讨伐。从不许自己王关中、假命杀宋义，到新安杀降、擅分诸侯、逐杀义帝，他还将焚掠秦宫、掘始皇陵的指控列在其中，强调自己无须亲自与之比武。项羽被激怒，伏弩射中刘邦胸部。刘邦摸着脚说只是中了脚趾，勉强出面慰劳士卒。张良担心军心动摇、楚乘胜追击，强劝他起身。后来病势加重，他退到成皋养伤。 [[3]](#note-5)

<a id="刘邦短暂回栎阳再回广武"></a>

<a id="event-12"></a>

4. **刘邦短暂回栎阳，再回广武。** 伤好以后，刘邦回关中存问父老、设宴，并在栎阳市枭示司马欣的首级。 停留四日后，他重新回到广武；关中继续增兵，彭越、田横在梁地反复断楚粮路。中箭不曾立即使刘邦退出长期战争。 [[4]](#note-12)

## 齐地战争与诸王受封

5. **韩信取齐，郦食其遇害，龙且战死。** 韩信进攻齐国，毁掉了郦食其已经谈成的和议。十月，汉军袭破历下、逼临淄，田广认为郦食其出卖自己，将他烹杀，退高密向楚求援。项羽派龙且来救齐。曹参隶韩信，攻历下、取临淄，再平济北，攻著、漯阴、平原、鬲、卢。龙且没有采用持久坚守之策，选择与韩信决战。十一月，两军隔潍水布阵。韩信以沙囊截流，先渡河佯败，诱楚军追来，再放水隔断楚军，反击杀龙且。灌婴等追击，俘获田广，齐地逐步被汉控制。曹参也从韩信在上假密参加破龙且之战，俘得将军周兰。田横一度自立为齐王继续抵抗，败后投奔彭越。他与田光、田既等人的抵抗被分别击破。楚既失去龙且的援军，也失去牵制韩信的齐地力量。曹参参与平齐，合计取得七十余县，田光、许章、胶东将军田既等也为汉军所获。 [[5]](#note-8)

<a id="sj008-zhanger"></a>

<a id="event-11"></a>

6. **十一月，张耳被汉立为赵王。** 张耳被汉立为赵王。 前两年他先被陈馀赶走，投奔刘邦，又与韩信一道击败赵军；现在重新取得王号。此次赵王名义来自汉，不是前206年项羽给他的常山王原封不动延续。 [[6]](#note-11)

<a id="二月立韩信为齐王七月又立黥布为淮南王"></a>

<a id="event-13"></a>

<a id="event-14"></a>

7. **韩信受封齐王，拒绝联合楚国。** 二月，韩信被立为齐王。韩信请求临时的齐王名义，刘邦最后给了正式王号。他以齐地多变、近楚为理由请“假王”。刘邦起初大怒，张良、陈平提醒不能逼韩信反向，应承认其实际地位。二月，张良带印立韩信为齐王，并征其兵击楚。陈平随后先得户牖乡食邑，正式剖符为侯与再更封曲逆仍在后来的年条。武涉来替项羽游说，韩信拒绝联合楚、三分天下。武涉警告汉王想吞并一切，楚亡后便会轮到韩信；韩信却强调在楚不受重用、在汉能带兵施展计策，不愿背弃厚待自己的人。 [[7]](#note-13)

<a id="sj008-huainan"></a>

<a id="event-15"></a>

8. **七月，黥布被立为淮南王。** 他先前是项羽所封的九江王，后来反楚、败退归汉；汉重新给他王号，使他带兵参加此后的联合作战。封王和下一年从九江方向会师垓下，不是同一时刻。 [[8]](#note-15)

## 鸿沟议和与追楚决策

<a id="sj007-honggou"></a>
<a id="九月鸿沟划界刘邦接回父亲和妻子"></a>

<a id="event-16"></a>

<a id="event-17"></a>

9. **楚汉议和以鸿沟为界，侯公受封。** 九月，陆贾先去请求释放太公未成，侯公继续谈，最终促成和约。汉粮多、楚兵疲粮竭，双方约鸿沟西属汉、东属楚。项羽放回太公、吕后等家属，汉军欢呼。侯公获平国君号，却没有成为刘邦经常接见的人。刘邦肯定其辩才可以倾动国家，同时与他保持距离。和议不仅有两王的决定，也有两次使者交涉的过程。 [[9]](#note-16)

<a id="event-18"></a>

10. **项羽已经解兵东归，刘邦却改变了西归打算。** 张良、陈平认为，汉已得天下大半，诸侯多附，楚军正疲，不应放走对手。刘邦接受追击建议；到下一年固陵，他还会因援军未到再败一次。 [[10]](#note-18)

## 宫廷、军政与赋役

<a id="sj049-boji-liuheng-event"></a>

11. **汉四年，薄姬得汉王宠幸，生下刘恒。** 魏国战败后，薄姬进入织室。刘邦后来见到她，将她召入后宫；她一年多未得宠幸。管夫人、赵子儿与薄姬少时相约，谁先得宠都不要忘记旧交。二人先得宠，在成皋台谈起旧约，刘邦问明缘由，当日召薄姬侍寝。薄姬说自己梦见苍龙伏在腹上，刘邦以为是贵兆。薄姬随后生刘恒，后来很少再见刘邦。刘恒后来封代王，最终成为汉文帝。 [[11]](#sj049-boji-liuheng-note)

<a id="hs001-event-20"></a>

12. **八月，汉开始征收算赋。** 八月，汉开始征收按人口计算的算赋。 [[12]](#hs001-note-20)

<a id="hs001-event-21"></a>

13. **北貉、燕人出骑兵助汉。** 北貉、燕人派骑兵来助汉军。 [[13]](#hs001-note-21)

<a id="hs001-event-22"></a>

14. **汉王下令收殓军士并将遗体送回家中。** 汉王下令为战死军士准备衣衾、棺木，由官吏收殓并递送遗体回乡。 [[14]](#hs001-note-22)

<a id="hs-event-23"></a>

15. **周昌由中尉任御史大夫。** 周昌由中尉任御史大夫。参见本年的官职变动原句。 [[15]](#hs-note-23)

<a id="hs-event-24"></a>

16. **高祖作武德舞。** 高祖四年作武德舞，以表现行武除乱。 [[16]](#hs-note-24)

<a id="hs-event-25"></a>

17. **临泗侯吕公去世。** 吕公于汉王四年去世，后来吕后临朝时追尊其为吕宣王。 [[17]](#hs-note-25)

**本卷说明：** 《汉书·外戚传》L10135明说“汉王四年”，又说“岁中生文帝”，归前203不是由后来的年龄倒算；前205被俘、前204魏豹死不随本段一起平移。长期“其后希见”只是后续概述。

## 归年与考证

<a id="sj022"></a>

<a id="sj022-note"></a>
<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[本年原表R004](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r004) · [《汉书·百官公卿表》](../../sources/%E6%9C%AC%E5%9C%B0%E5%88%86%E5%8D%B7/%E6%B1%89%E4%B9%A6/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0203)。

> 纪年：四；大事纪：使韓信別定齊及燕，太公自楚歸，與楚界洪渠。；相位：四；将位：三。周苛守滎陽，死。；御史大夫位：御史大夫汾陰侯周昌。

定齐、燕归汉、太公归还与鸿沟议和接本页原故事。“洪渠”与常称鸿沟为同一和议线，不另造第二条国界。将位把御史大夫周苛的死事附在卢绾任期数字后，不能把周苛改任太尉；死亡仍用[前204年](bce-0204.md#sj022-note)的详细叙事。御史大夫周昌为接任者，汉表亦系高帝四年；表的接任栏与死事实际年份分开。



<a id="1曹咎龙且与跨年回叙"></a>
#### 1｜曹咎、龙且与跨年回叙

[卷007 P035—P037](../../sources/摘录/史记-卷007-项羽本纪.md#p035) · [卷008 P034—P035](../../sources/摘录/史记-卷008-高祖本纪.md#p034)。两篇叙次均有回接，《通鉴》将项羽东征置前一年九月、曹咎败本年十月、龙且败十一月。本页沿这个次序，前204年失成皋、本年复取分开。[年次对照](../../meta/考证/史记-卷007-纪年与异说.md#成皋)。卷007另列“长史翳”，其与董翳归汉后经历的联系未明，正文只取两篇及通鉴可共同核合的曹咎、司马欣，不造返楚日期。

<a id="2谁逃到彭越那里"></a>
#### 2｜谁逃到彭越那里

卷008 P034写“齐王广奔彭越”，卷007相关叙事及《汉书》四年十一月、《通鉴》则区别田广被俘、田横败后投彭越。正文采用详细的后者，不让田广在被俘后无解释地又奔彭越。张耳立王由汉书十一月及卷008“其明年”共同定位，区别前206年的常山王。

<a id="3王号授印及淮南王的月份"></a>
#### 3｜王号、授印及淮南王的月份

韩信的“因自立”是卷007简述，卷008及列传、通鉴有请假王、正式授印程序，正文保留详细过程。淮阴侯是后称，不提前安在攻齐时。卷008将黥布立王接在垓下会军段附近，《汉书》明系四年七月，故放本年；原文阅读单元P039跨年，不能全部继承固陵战的汉五年。

<a id="4广武控诉射伤与死后示众"></a>
#### 4｜广武控诉、射伤与死后示众

[卷008 P037—P038](../../sources/摘录/史记-卷008-高祖本纪.md#p037)。十罪是刘邦争取正当性的战争言辞，特别“掘始皇冢”等指控，不仅因出现在控诉中就认定每项细节已获独立证实。摸足、劳军为传世叙事，非现场逐字纪录。司马欣此前汜水自杀，栎阳枭首是后续示众，不是另一次处死。潍水截流战法同样依所用文本，不声称已作现代水文验证。

<a id="5家属和议与年末决策"></a>
#### 5｜家属、和议与年末决策

[卷007 P033、P038—P039](../../sources/摘录/史记-卷007-项羽本纪.md#p033)。太公受胁但未死，所以可以后来归还；侯公平国君也不等于诸侯王。追击决策在四年末，固陵、垓下在汉五年，分见[前202年](bce-0202.md)。相持中的未定月对话不因排在十月后，就一概定为同月。

### 卷016｜逐月互见与取舍

<a id="sj016-m12-note"></a>
<a id="十二月齐地暂作郡"></a>
#### 十二月｜齐地暂作郡

<a id="sj016-m02-note"></a>
<a id="二月韩信的王号"></a>
#### 二月｜韩信的王号

[本月齐、汉两格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0203-02)同指汉立韩信王齐，与本页请假王、张良持印的详细过程合并，不记两次封王。齐王韩信与表中韩栏连续在位的韩王信须区分，后续迁楚见[前202年](bce-0202.md#sj008-emperor)。

<a id="sj016-m03-note"></a>
<a id="三月周苛死亡的异年"></a>
#### 三月｜周苛死亡的异年

[本月项、汉两格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0203-03)写周苛入楚及死；本纪详叙被俘拒降，汉书、通鉴系汉三年六月，正文仍归[前204年荥阳陷落](bce-0204.md#sj007-chenggao-loss)。这里的“入楚”不能擅译成周苛自愿投降后被杀，也不在本年再处死同一人。

#### 四月｜荥阳脱困、魏豹之死再见

# 公元前203年｜成皋和齐地改变战局，汉增封盟友，鸿沟议和又起追兵

[← 公元前204年](bce-0204.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前202年 →](bce-0202.md)

**汉四年**

> 十月、十一月是古历本年开端，在正月、二月以前。楚汉在广武相持，汉有敖仓和后方补给，楚的粮食与盟友逐渐减少。

### 冬十月，曹咎没有守住项羽的交代

<a id="event-1"></a>

1. **汉军连续挑战、辱骂，终于引出曹咎。** 他原受命固守成皋，忍了五六日后动怒，率军渡汜水。士卒渡到一半，汉军进攻，大破楚军，取得其物资。曹咎、司马欣自杀，汉复取成皋、驻广武，利用敖仓粮食。[卷007 P037](../../sources/摘录/史记-卷007-项羽本纪.md#p037) · [卷008 P035](../../sources/摘录/史记-卷008-高祖本纪.md#p035) · [《通鉴》卷十](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91%20%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29-%E5%8D%B7010.md#ref-2d0b015fc0ae1c)。 [[1]](#note-1)

<a id="event-2"></a>

2. **项羽在睢阳闻败，急忙回来救援。** 汉军正围钟离眛于荥阳东，见项羽到来，退向险阻。项羽救了眼前的部下，却未能把汉从敖仓、成皋赶走，两军继续在广武相守。[卷007 P037](../../sources/摘录/史记-卷007-项羽本纪.md#p037)。 [[2]](#note-2)

<a id="太公被拿来威胁刘邦仍不低头"></a>
### 太公被拿来威胁，刘邦仍不低头

<a id="event-3"></a>

3. **项羽把太公置于高俎上，声称将要烹杀。** 楚粮道受彭越袭击，项羽想用刘邦的父亲逼对手屈服。刘邦却援引二人受命怀王时的兄弟盟约，说自己的父亲也是项羽的父亲，若真烹杀，请分一杯羹。[卷007 P033](../../sources/摘录/史记-卷007-项羽本纪.md#p033)。 [[3]](#note-3)

<a id="event-4"></a>

4. **项伯劝杀太公无益于战局，只会增加祸患，项羽终于作罢。** 家属仍留楚军作筹码，没有在这次威胁中被杀。[卷007 P033](../../sources/摘录/史记-卷007-项羽本纪.md#p033)。 [[4]](#note-4)

<a id="从邀战变成列罪刘邦在广武中箭"></a>
### 从邀战变成列罪，刘邦在广武中箭

<a id="event-5"></a>

5. **项羽想以两人的决斗结束战争，刘邦却说宁斗智，不斗力。** 壮丁苦于军旅、老弱疲于转输，双方长期消耗。楚军勇士出阵，屡被汉军善射者楼烦射杀；项羽亲自披甲持戟出来，楼烦又因其叱喝退回。[卷007 P034](../../sources/摘录/史记-卷007-项羽本纪.md#p034)。 [[5]](#note-5)

<a id="event-6"></a>

6. **刘邦当面列举十条罪状，把战争说成对项羽背约行为的讨伐。** 从不许自己王关中、假命杀宋义，到新安杀降、擅分诸侯、逐杀义帝，他还将焚掠秦宫、掘始皇陵的指控列在其中，强调自己无须亲自与之比武。项羽被激怒，伏弩射中刘邦胸部。[卷008 P037](../../sources/摘录/史记-卷008-高祖本纪.md#p037)。 [[6]](#note-6)

<a id="event-7"></a>

7. **刘邦摸着脚说只是中了脚趾，勉强出面慰劳士卒。** 张良担心军心动摇、楚乘胜追击，强劝他起身。后来病势加重，他退到成皋养伤。[卷007 P034](../../sources/摘录/史记-卷007-项羽本纪.md#p034) · [卷008 P037](../../sources/摘录/史记-卷008-高祖本纪.md#p037)。 [[7]](#note-7)

<a id="sj007-longju"></a>
<a id="十一月龙且败死田广被俘张耳再得王位"></a>
### 十一月，龙且败死，田广被俘，张耳再得王位

<a id="event-8"></a>

8. **韩信进攻齐国，毁掉了郦食其已经谈成的和议。** 十月，汉军袭破历下、逼临淄，田广认为郦食其出卖自己，将他烹杀，退高密向楚求援。项羽派龙且来救齐。[《通鉴》卷十](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91%20%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29-%E5%8D%B7010.md#ref-dcc76222afabb1)。 [[8]](#note-8)

<a id="event-9"></a>

9. **龙且没有采用持久坚守之策，选择与韩信决战。** 十一月，两军隔潍水布阵。韩信以沙囊截流，先渡河佯败，诱楚军追来，再放水隔断楚军，反击杀龙且。灌婴等追击，俘获田广，齐地逐步被汉控制。[卷007 P035前半](../../sources/摘录/史记-卷007-项羽本纪.md#p035) · [卷008 P034](../../sources/摘录/史记-卷008-高祖本纪.md#p034) · [《通鉴》卷十](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91%20%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29-%E5%8D%B7010.md#ref-815d093b8d810d)。 [[9]](#note-9)

<a id="event-10"></a>

10. **田横一度自立为齐王继续抵抗，败后投奔彭越。** 他与田光、田既等人的抵抗被分别击破。楚既失去龙且的援军，也失去牵制韩信的齐地力量。[《通鉴》卷十](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91%20%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29-%E5%8D%B7010.md#ref-4b03bb8c50b9b1)。 [[10]](#note-10)

<a id="sj008-zhanger"></a>

<a id="event-11"></a>

11. **张耳被汉立为赵王。** 前两年他先被陈馀赶走，投奔刘邦，又与韩信一道击败赵军；现在重新取得王号。此次赵王名义来自汉，不是前206年项羽给他的常山王原封不动延续。[卷008 P029](../../sources/摘录/史记-卷008-高祖本纪.md#p029) · [《汉书》高帝纪四年十一月](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7001.md#ref-955075f97120b1)。 [[11]](#note-11)

<a id="刘邦短暂回栎阳再回广武"></a>
### 刘邦短暂回栎阳，再回广武

<a id="event-12"></a>

12. **伤好以后，刘邦回关中存问父老、设宴，并在栎阳市枭示司马欣的首级。** 停留四日后，他重新回到广武；关中继续增兵，彭越、田横在梁地反复断楚粮路。中箭不曾立即使刘邦退出长期战争。[卷008 P038—P039](../../sources/摘录/史记-卷008-高祖本纪.md#p038)。 [[12]](#note-12)

<a id="二月立韩信为齐王七月又立黥布为淮南王"></a>
### 二月立韩信为齐王，七月又立黥布为淮南王

<a id="event-13"></a>

13. **韩信请求临时的齐王名义，刘邦最后给了正式王号。** 他以齐地多变、近楚为理由请“假王”。刘邦起初大怒，张良、陈平提醒不能逼韩信反向，应承认其实际地位。二月，张良带印立韩信为齐王，并征其兵击楚。[卷008 P036](../../sources/摘录/史记-卷008-高祖本纪.md#p036) · [《通鉴》卷十](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91%20%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29-%E5%8D%B7010.md#ref-8ffc24b7743a42)。 [[13]](#note-13)

<a id="event-14"></a>

14. **武涉来替项羽游说，韩信拒绝联合楚、三分天下。** 武涉警告汉王想吞并一切，楚亡后便会轮到韩信；韩信却强调在楚不受重用、在汉能带兵施展计策，不愿背弃厚待自己的人。[卷007 P035](../../sources/摘录/史记-卷007-项羽本纪.md#p035) · [卷008 P036](../../sources/摘录/史记-卷008-高祖本纪.md#p036)。 [[14]](#note-14)

<a id="sj008-huainan"></a>

<a id="event-15"></a>

15. **七月，黥布被立为淮南王。** 他先前是项羽所封的九江王，后来反楚、败退归汉；汉重新给他王号，使他带兵参加此后的联合作战。封王和下一年从九江方向会师垓下，不是同一时刻。[《汉书》四年七月](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7001.md#ref-09470d903fcec0) · [卷008 P039](../../sources/摘录/史记-卷008-高祖本纪.md#p039)。 [[15]](#note-15)

<a id="sj007-honggou"></a>
<a id="九月鸿沟划界刘邦接回父亲和妻子"></a>
### 九月，鸿沟划界，刘邦接回父亲和妻子

<a id="event-16"></a>

16. **陆贾先去请求释放太公未成，侯公继续谈，最终促成和约。** 汉粮多、楚兵疲粮竭，双方约鸿沟西属汉、东属楚。项羽放回太公、吕后等家属，汉军欢呼。[卷007 P038](../../sources/摘录/史记-卷007-项羽本纪.md#p038) · [卷008 P039](../../sources/摘录/史记-卷008-高祖本纪.md#p039)。 [[16]](#note-16)

<a id="event-17"></a>

17. **侯公获平国君号，却没有成为刘邦经常接见的人。** 刘邦肯定其辩才可以倾动国家，同时与他保持距离。和议不仅有两王的决定，也有两次使者交涉的过程。[卷007 P038](../../sources/摘录/史记-卷007-项羽本纪.md#p038)。 [[17]](#note-17)

<a id="event-18"></a>

18. **项羽已经解兵东归，刘邦却改变了西归打算。** 张良、陈平认为，汉已得天下大半，诸侯多附，楚军正疲，不应放走对手。刘邦接受追击建议；到下一年固陵，他还会因援军未到再败一次。[卷007 P039](../../sources/摘录/史记-卷007-项羽本纪.md#p039) · [卷008 P039](../../sources/摘录/史记-卷008-高祖本纪.md#p039)。 [[18]](#note-18)

## 归年与考证

<a id="sj022"></a>

<a id="sj022-note"></a>
<a id="卷022将相表互见与异说"></a>
#### 卷022｜将相表互见与异说

[本年原表R004](../../sources/摘录/史记-卷022-汉兴以来将相名臣年表.md#r004) · [《汉书·百官公卿表》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E6%B1%89%E4%B9%A6-%E5%8D%B7019-%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%939347363-%E5%AE%8C%E6%95%B4%E8%AF%BB%E6%9C%AC.md#ws019-bce-0203)。

> 纪年：四；大事纪：使韓信別定齊及燕，太公自楚歸，與楚界洪渠。；相位：四；将位：三。周苛守滎陽，死。；御史大夫位：御史大夫汾陰侯周昌。

定齐、燕归汉、太公归还与鸿沟议和接本页原故事。“洪渠”与常称鸿沟为同一和议线，不另造第二条国界。将位把御史大夫周苛的死事附在卢绾任期数字后，不能把周苛改任太尉；死亡仍用[前204年](bce-0204.md#sj022-note)的详细叙事。御史大夫周昌为接任者，汉表亦系高帝四年；表的接任栏与死事实际年份分开。



<a id="1曹咎龙且与跨年回叙"></a>
#### 1｜曹咎、龙且与跨年回叙

[卷007 P035—P037](../../sources/摘录/史记-卷007-项羽本纪.md#p035) · [卷008 P034—P035](../../sources/摘录/史记-卷008-高祖本纪.md#p034)。两篇叙次均有回接，《通鉴》将项羽东征置前一年九月、曹咎败本年十月、龙且败十一月。本页沿这个次序，前204年失成皋、本年复取分开。[年次对照](../../meta/考证/史记-卷007-纪年与异说.md#成皋)。卷007另列“长史翳”，其与董翳归汉后经历的联系未明，正文只取两篇及通鉴可共同核合的曹咎、司马欣，不造返楚日期。

<a id="2谁逃到彭越那里"></a>
#### 2｜谁逃到彭越那里

卷008 P034写“齐王广奔彭越”，卷007相关叙事及《汉书》四年十一月、《通鉴》则区别田广被俘、田横败后投彭越。正文采用详细的后者，不让田广在被俘后无解释地又奔彭越。张耳立王由汉书十一月及卷008“其明年”共同定位，区别前206年的常山王。

<a id="3王号授印及淮南王的月份"></a>
#### 3｜王号、授印及淮南王的月份

韩信的“因自立”是卷007简述，卷008及列传、通鉴有请假王、正式授印程序，正文保留详细过程。淮阴侯是后称，不提前安在攻齐时。卷008将黥布立王接在垓下会军段附近，《汉书》明系四年七月，故放本年；原文阅读单元P039跨年，不能全部继承固陵战的汉五年。

<a id="4广武控诉射伤与死后示众"></a>
#### 4｜广武控诉、射伤与死后示众

[卷008 P037—P038](../../sources/摘录/史记-卷008-高祖本纪.md#p037)。十罪是刘邦争取正当性的战争言辞，特别“掘始皇冢”等指控，不仅因出现在控诉中就认定每项细节已获独立证实。摸足、劳军为传世叙事，非现场逐字纪录。司马欣此前汜水自杀，栎阳枭首是后续示众，不是另一次处死。潍水截流战法同样依所用文本，不声称已作现代水文验证。

<a id="5家属和议与年末决策"></a>
#### 5｜家属、和议与年末决策

[卷007 P033、P038—P039](../../sources/摘录/史记-卷007-项羽本纪.md#p033)。太公受胁但未死，所以可以后来归还；侯公平国君也不等于诸侯王。追击决策在四年末，固陵、垓下在汉五年，分见[前202年](bce-0202.md)。相持中的未定月对话不因排在十月后，就一概定为同月。

<a id="卷016逐月互见与取舍"></a>
### 卷016｜逐月互见与取舍

<a id="sj016-m11-note"></a>
<a id="十一月龙且田广与张耳"></a>
#### 十一月｜龙且、田广与张耳

[本月项、齐、原常山三格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0203-11)分别归[潍水战局](#sj007-longju)、[张耳赵王](#sj008-zhanger)。月表“击杀广”与[汉书P056](../../sources/摘录/汉书-高帝纪.md#p056)“虏齐王广”有别，正文保持败后被俘，不由这一孤立简记定其死亡日；田横投彭越仍是另一人的经历。十月表只有数字与空位，不等于否定其他史书记载的袭齐、成皋作战。

<a id="sj016-m12-note"></a>
<a id="十二月齐地暂作郡"></a>
#### 十二月｜齐地暂作郡

[本月齐栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0203-12)“属汉，为郡”说明田氏政权被击败后的归属，接[平齐](#sj007-longju)，与二月封韩信为王是相继阶段。原格没有给出所有郡名和界线，不自行补成一张全境行政区划。

<a id="sj016-m02-note"></a>
<a id="二月韩信的王号"></a>
#### 二月｜韩信的王号

[本月齐、汉两格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0203-02)同指汉立韩信王齐，与本页请假王、张良持印的详细过程合并，不记两次封王。齐王韩信与表中韩栏连续在位的韩王信须区分，后续迁楚见[前202年](bce-0202.md#sj008-emperor)。

<a id="sj016-m03-note"></a>
<a id="三月周苛死亡的异年"></a>
#### 三月｜周苛死亡的异年

[本月项、汉两格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0203-03)写周苛入楚及死；本纪详叙被俘拒降，汉书、通鉴系汉三年六月，正文仍归[前204年荥阳陷落](bce-0204.md#sj007-chenggao-loss)。这里的“入楚”不能擅译成周苛自愿投降后被杀，也不在本年再处死同一人。

<a id="sj016-m04-note"></a>
<a id="四月荥阳脱困魏豹之死再见"></a>
#### 四月｜荥阳脱困、魏豹之死再见

[本月汉栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0203-04)“王出荥阳。豹死”与表三年七八月及本纪、汉书的年次不合。仍沿[前204年五月出城和魏豹结局](bce-0204.md#sj007-jixin)，保留[月表三年异月注](bce-0204.md#sj016-m08-note)。本轮未证明具体错简形成过程，但可以排除把同一魏豹连杀两次的机械编年；成皋另一场北逃也不与此互相替代。

<a id="sj016-m07-note"></a>
<a id="七月淮南封王"></a>
#### 七月｜淮南封王

[本月九江旧栏与汉栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0203-07)同指[英布为淮南王](#sj008-huainan)。由九江到淮南是称号与封国安排的变化，前一年身归汉不等于当时已经得到此号，后续会兵垓下也不提前到本月。

<a id="sj016-m09-note"></a>
<a id="九月太公吕后归还"></a>
#### 九月｜太公、吕后归还

[本月汉栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0203-09)接[鸿沟和议](#sj007-honggou)，不是二人第一次进入编年。获释与项羽东归、汉决定追击彼此相接，实际固陵、垓下跨汉五年，不能因该年表末省略而把全战事压进九月。

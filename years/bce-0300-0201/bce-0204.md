# 公元前204年（汉三年）

<a id="公元前204年荥阳粮断刘邦两次脱险项羽被迫东西奔走"></a>
<a id="reading-start"></a>

[本年相关史料](#本年相关史料)

汉军北破赵、招燕，正面却在荥阳、成皋接连受困。刘邦依靠北方兵源重新集军，彭越等人在楚后方断粮袭城，使项羽不得不往来救应；战局从一座城的得失，逐渐扩展为兵力与粮道的争夺。

本页依汉三年古历先后编排，冬十月在正月以前；未载确月的事项按有据的战事相承接入。

<a id="event-1"></a>

<a id="北路进展使汉还有回旋余地"></a>

1. **冬十月，韩信、张耳在井陉击破赵军。** 韩信在前一年攻破魏国、击败代军之后，与张耳率军东出井陉，进攻赵国。陈馀把主力集中在井陉口，李左车劝他另出奇兵切断汉军粮道，正面坚守，等远道而来的汉军自行困乏；陈馀却认为己方兵多，不愿避战。韩信得知此计未被采用，才继续前进。他先遣轻骑隐蔽在山旁，又使一军背水列阵，自己与张耳出战，随后佯弃旗鼓，退入水边军阵。赵军离营追逐，汉军伏骑趁机冲入赵营，把赵旗换成汉军赤旗。赵军久战不能取胜，回望营中已遍是汉旗，以为后方尽失，队伍遂乱。汉军乘势夹击，陈馀战死，赵王歇被俘，北方战局由此改变。 韩信、张耳出井陉时，曹参另奉命回围邬城的戚将军，追斩出逃者，然后率军到敖仓会汉王；不能把这支分军也安排在井陉同一阵中。 [[1]](#note-1)

<a id="event-2"></a>

2. **十月晦日发生日食。** 十月甲戌晦，发生日食。 [[2]](#note-2)

<a id="event-3"></a>

3. **井陉战后，韩信礼待李左车，遣使招徕燕国。** 赵军败后，韩信悬赏求生擒李左车。李左车被缚来后，韩信解去他的束缚，以师礼相待，询问下一步怎样攻燕、齐。李左车指出，汉军虽声威正盛，士卒却已疲惫，若立即顿兵燕国坚城之下，久攻不克，反会暴露弱处；不如先安定赵地、抚恤遗孤，让军队休息，再借破赵之威派使者劝燕归附。韩信采纳，燕国随之服从。赵地却并未从此无事：楚军仍屡次渡河袭击，韩信、张耳一边往来救援、安定城邑，一边向刘邦输送兵力。刘邦后来在荥阳、成皋失利时能够北渡接军，正有这片北方战场作为依托。 [[3]](#note-3)

<a id="event-4"></a>

4. **十二月，黥布战败后与随何一道归汉。** 刘邦先前派随何去争取九江王黥布。黥布与项羽已有嫌隙，听从劝说后起兵攻楚，项羽便派项声、龙且迎击。黥布不能取胜，只得与随何从小路离开九江，十二月来到汉军。刘邦分给他一部分兵，两人一道收集散卒，行至成皋。黥布带来的，是本人转向汉方及可以重新组织的力量；九江原地并没有随着他的到来便完整交给汉军。 [[4]](#note-4)

<a id="event-5"></a>

5. **荥阳粮道受扰，张良阻止刘邦复立六国后人。** 楚军屡夺汉军取敖仓粮食的甬道，荥阳渐缺粮。郦食其建议复立六国后人为王，以牵制楚国，刘邦一度同意，并命人刻印。张良回来时刘邦正在吃饭，他借筷子说明复国的困难。项羽尚未被制服，刘邦无从照搬汤、武分封灭国后嗣的办法，也还不能停战休兵、散粮赈民。六国后人复立之后，追随汉军的游士可能各自回去侍奉故主，诸王还可能屈从楚国。刘邦听罢吐出口中的饭，命人销毁印信，取消计划。荥阳相持也使当地难以耕种，粮价上涨，宣曲任氏借积粮获利。 [[5]](#note-5)

<a id="event-6"></a>

6. **刘邦交给陈平重金，着手离间楚君臣。** 刘邦另向陈平问计。陈平认为，项羽所依靠的骨干不过范增、钟离昧、龙且、周殷等人，若设法使君臣彼此猜疑，楚军便会从内部受损。刘邦于是拿出黄金四万斤，让陈平自行使用，不追问每笔出入。陈平把财物用于楚营的反间活动，散布有功将领得不到封赏、想联合汉军另分土地的说法，使项羽对身边将领逐渐生疑。粮道上的压力尚未解除，汉方先试图拆散维持楚军战力的关系。 进言时，陈平也直陈两方长短：项羽礼贤而吝于爵邑，刘邦少礼而厚赏，吸引来的士人各有偏向；他劝兼取长处，仍指出刘邦侮人妨碍有廉节者归附。 [[6]](#note-6)

<a id="event-7"></a>

<a id="四月项羽断粮进逼范增却离开楚军"></a>

7. **夏四月，荥阳受围，范增离开楚军后病死。** 项羽围攻荥阳，汉军缺粮，刘邦提出议和，愿以荥阳为界，西面归汉。项羽原想接受，范增却主张趁汉军困顿赶紧攻城，不能放过刘邦。楚使到汉营时，汉方依陈平计准备盛宴，汉王见面后佯作吃惊，说原以为来的是亚父范增的使者，既然是项王的使者，便撤去好饭，换上粗食。使者回报后，项羽怀疑范增私通汉军，逐渐削夺他的权力。范增愤怒求退，项羽准许；他尚未到彭城，背上发疽而死。荥阳并未因此解围，楚军却失去了一位重要谋臣。 [[7]](#note-7)

<a id="sj007-jixin"></a>
<a id="event-8"></a>

<a id="五月纪信假降刘邦从西门脱身"></a>

8. **五月，纪信假降，刘邦从荥阳西门脱身。** 荥阳形势日益危急，纪信提出假装汉王投降，为刘邦争取出城的空隙。陈平在夜里把二千余名女子放出东门，楚军从四面攻击她们；纪信随后乘汉王的车，张起黄屋左纛，宣称粮食已尽、汉王投降。楚军呼喊万岁，纷纷到城东观看。刘邦趁其注意力转移，带数十骑从西门逃走，退往成皋。项羽见到纪信，追问真正的汉王在哪里，得知已经离去，便将纪信烧杀。 [[8]](#note-8)

<a id="event-9"></a>

9. **汉军留守荥阳，周苛、枞公杀死魏豹。** 刘邦离城后，周苛、枞公、魏豹及韩王信等仍留守荥阳，不能跟随出走的将卒也留下来继续抵抗。魏豹原是西魏王，曾离汉归楚，前一年兵败被韩信俘获，押到荥阳。周苛、枞公担心这样反复转换阵营的人不能共守危城，商议后将他杀死。汉王已经脱险，城中守军的处境却没有因此改善。 [[9]](#note-9)

<a id="event-10"></a>

<a id="刘邦绕往宛叶彭越从另一边牵制楚军"></a>

10. **刘邦入关收兵，接受辕生分散楚军的计策。** 刘邦先到成皋，再进入关中收集兵力，准备重新东进。辕生劝他不要只沿荥阳正面反复硬攻：若从武关出到宛、叶之间，项羽势必向南追来；汉军便可坚守不战，让荥阳、成皋一线暂得休息，也让韩信有时间稳定河北、联络燕齐。等楚军需要防备的方向增多、兵力分散，刘邦再回到荥阳，便比在一个方向上承受全部压力有利。刘邦采纳了这项迂回部署。 [[10]](#note-10)

<a id="event-11"></a>

11. **刘邦出军宛、叶，与黥布收兵而不决战。** 刘邦依计由武关出军，在宛、叶之间活动，与黥布一道收拢兵员。项羽听说汉王在宛，果然率兵南下，刘邦却守住营垒，不与他交战。汉军这次行动的目的，是迫使楚军改变方向、分散防备，而不是在宛地立即求一次决胜；黥布归汉后，也在这次共同收兵中重新积聚力量。 [[11]](#note-11)

<a id="event-12"></a>

12. **五月，彭越在下邳击破楚军，杀死薛公。** 同在五月，彭越渡过睢水，在下邳与楚将项声、薛公交战，击败楚军并杀死薛公。彭越此前在汉军彭城败后丢失所取城邑，却仍带兵在河上、梁地往来，袭扰楚军后方。如今他又在东面取胜，项羽便不能只追着南边的刘邦行动，必须回顾另一处战场。 [[12]](#note-12)

<a id="event-13"></a>

13. **项羽东击彭越，刘邦击破终公，重回成皋。** 项羽派终公留守成皋，自己向东攻打彭越。刘邦抓住楚军主力东移的时机，从南边引军北上，击败终公，再次驻进成皋。南面的坚守、东面的袭扰和汉王的回军开始互相配合：项羽在一处取胜或进兵，另一处便可能失守，成皋也因此反复成为双方争夺的要地。 [[13]](#note-13)

<a id="sj007-chenggao-loss"></a>
<a id="event-14"></a>

<a id="六月荥阳失守刘邦又从成皋北逃"></a>

14. **六月，荥阳陷落，周苛、枞公被杀，韩王信被俘。** 项羽击退彭越，听说刘邦又回到成皋，立即率军西返，攻破仍由汉军守将抵抗的荥阳，生擒周苛。他许诺让周苛做上将军、封三万户，想使其为己效力；周苛拒绝，反劝项羽赶快降汉，直言他不是汉王的对手。项羽将周苛烹杀，又杀枞公，俘获韩王信，随即进围成皋。刘邦五月逃出之后留下的荥阳守军，到这时才走向终局。 [[14]](#note-14)

<a id="event-15"></a>

15. **刘邦与滕公从成皋脱身，北渡黄河。** 成皋再次遭围，刘邦又一次离开受困的城池。这回他只与滕公夏侯婴共乘一车，从玉门出去，向北渡过黄河，夜宿小修武。五月的脱险靠纪信在荥阳东门假降，这次则发生在成皋受围以后；汉王离开后，楚军取得成皋，但汉军仍在巩一线阻击，使楚军未能一路向西推进。 [[15]](#note-15)

<a id="event-16"></a>

16. **刘邦晨入修武军营，取得张耳、韩信的军队。** 第二天清晨，刘邦自称汉王使者，驰入张耳、韩信的营垒。二人还没有起身，他便进入卧处，取得印信兵符，召集诸将，重新安排指挥；韩信、张耳起来后，才知道汉王亲自到了。刘邦接管两人的军队，让张耳继续巡守、收集赵地兵力，又任韩信为相国，征集赵地尚未出发的兵进攻齐国。北方新得的兵力被重新调向汉王正面，而韩信的任务也由平赵转入向齐发展。 [[16]](#note-16)

<a id="sj016-linjiang"></a>
<a id="event-17"></a>

<a id="七月临江王共敖去世"></a>

17. **七月，共敖去世，其后由子共尉继承临江王位。** 七月，临江王共敖去世，其后由子共尉继承王位。共敖原是楚柱国，灭秦后受封临江，以江陵为都；如今临江转由下一代执掌。后来汉军进攻临江时，面对的在位者已经是共尉，而不是当初受封的父亲。 [[17]](#note-17)

<a id="event-18"></a>

18. **七月，大角一带出现孛星。** 七月，大角星附近出现孛星。 [[18]](#note-18)

<a id="event-19"></a>

<a id="暂不渡河决战改由别军袭楚粮食"></a>

19. **八月，刘邦准备复战，郑忠劝他坚守待机。** 得到韩信的军队后，刘邦军势重新振作，八月又准备与楚军交战。郎中郑忠劝他先修高营垒、深挖壕沟，不要急着正面决战，刘邦听从了。正面的军队暂守，另一路兵则可以渡河去袭击楚军的粮食和后方，让项羽在不能速战的同时，还得分兵维持供应。 [[19]](#note-19)

<a id="event-20"></a>

20. **刘贾、卢绾渡河烧楚积粮，彭越攻下梁地十七城。** 刘邦派刘贾、卢绾率二万步卒、数百骑兵，从白马津渡河进入楚地，协助彭越焚烧积聚的粮草，破坏楚军供应。楚军来攻刘贾时，他便坚守不出，与彭越互相支援。彭越同时在梁地攻取城邑，拿下睢阳、外黄等十七城。这里的牵制不只是占住一座城，而是使项羽的后方与粮运不断受到威胁。 [[20]](#note-20)

<a id="event-21"></a>

21. **九月，项羽留下曹咎守成皋，自己东击彭越。** 九月，项羽再次向东去平定梁地，留下大司马曹咎等人守成皋。他叮嘱曹咎，汉军即使前来挑战，也不可出战，只须阻住刘邦东进，自己十五日内便能平定梁地回来会合。曹咎与司马欣从前曾帮助项梁，项羽对他们有旧日信任；但这次留守的任务，首先是守住隘口，避免在主力不在时与汉军决战。 [[21]](#note-21)

<a id="sj007-waihuang"></a>
<a id="event-22"></a>

<a id="一名少年使外黄免遭杀戮"></a>

22. **项羽攻下外黄，一名少年劝止杀戮。** 外黄抵抗数日后投降，项羽仍大怒，命十五岁以上男子都到城东，准备将他们坑杀。县令舍人的十三岁儿子出面劝说：外黄先前是受彭越强迫才暂且降服，等候项王到来；如今归降还全部被杀，东面十余城听到后，谁还敢开门？项羽接受了这个劝告，赦免外黄本将被杀的男子。军队继续东到睢阳时，沿途城邑听说此事，纷纷争先归降。 [[22]](#note-22)

<a id="event-23"></a>

23. **刘邦想退守巩洛，郦食其劝他谋取敖仓。** 刘邦一度想放弃成皋以东，退驻巩、洛抵抗楚军。郦食其以粮食为立足之本来劝他：敖仓长年承受天下转运，仍藏有大量粮食；楚军虽攻破荥阳，却没有把敖仓牢牢守住，主力又已东去，汉若自行后退，反而失去可争的有利条件。他建议重新进兵，收取荥阳、据住敖仓，并利用成皋等关隘、渡口约束楚军，向诸侯显示汉仍能掌握形势。刘邦采纳，重新筹划进取敖仓。退守巩洛的打算就此改变，汉军重新以争取粮仓和关隘为进兵目标。 [[23]](#note-23)

<a id="event-24"></a>

<a id="齐国接受了游说汉军却仍在路上"></a>

24. **郦食其说齐罢兵，韩信却没有停下东进。** 郦食其又提出，燕、赵既已归汉，齐国仍有田氏宗族与山河屏障，强攻未必能迅速解决，不如让他奉汉王命令去劝齐王田广归附。刘邦同意。田广听从游说，与汉议和，撤去历下原用来防备汉军的重兵戒备，并留郦食其饮酒。韩信东进途中，听说齐国已被说服，本想停止；蒯彻却问他，汉王既然命他击齐，是否另有命令要他停兵，又以郦食其说下七十余城的功劳相激。韩信听从，仍继续前进。 [[24]](#note-24)

<a id="event-25"></a>

25. **刘泽在汉王军中担任郎中。** 后来成为琅邪王、燕王的刘泽，此时只是宗室远属中的从军郎中。营陵侯爵要到高祖十一年参加陈豨战争后才取得。 [[25]](#note-25)

<a id="sj053-bao-event"></a>

26. **鲍生劝萧何把能作战的家人送到前线。** 汉王与项羽在京、索间相持，屡派使者慰劳留守丞相。鲍生认为汉王在外劳苦，这些问候也可能包含疑虑，便劝萧何让子孙兄弟中能作战者全赴军中。萧何依从，汉王很高兴；疑忌的解释出自这次劝说，不另作已颁布的监控命令。 [[26]](#sj053-bao-note)

<a id="sj095-event-27"></a>

27. **灌婴的功状在汉三年再次记杜平乡食邑。** 灌婴传前段已记封昌文侯、食杜平乡，汉三年又记以列侯食该邑。原文没有说明是重申还是另有授命，沿同一食邑读。 [[27]](#note-27)

<a id="sj098-event-28"></a>

28. **靳歙在汉三年受赐食邑四千二百户。** 靳歙传将授邑接在荥阳东破楚军之后。此前他在彭城败后据雍丘，曾另军攻梁。 [[28]](#note-28)

### 1. 冬十月，韩信、张耳在井陉击破赵军

> 漢遣耳與韓信擊破趙井陘，斬餘泜水上，追殺趙王歇襄國。

**互校说明** 井陉从汉三年冬十月，按仓内古历年页归前204；换算现代年可落前205年末。

**[《汉书·韩彭英卢吴传》P007](../../sources/摘录/汉书-卷034-韩彭英卢吴传.md#p007)** · [仓内TXT L6951](../../sources/本地分卷/汉书/汉书-卷034.md#L6951)

> 信、耳以兵數萬，欲東下井陘擊趙。趙王、成安君陳餘聞漢且襲之，聚兵井陘口，號稱二十萬。廣武君李左車說成安君曰：「聞漢將韓信涉西河，虜魏王，禽夏說，新喋血閼與。今乃輔以張耳，議欲以下趙，此乘勝而去國遠鬥，其鋒不可當。臣聞『千里餽糧，士有飢色；樵蘇後爨，師不宿飽。』今井陘之道，車不得方軌，騎不得成列，行數百里，其勢糧食必在後。願足下假臣奇兵三萬人，從間道絕其輜重；足下深溝高壘勿與戰。彼前不得鬥，退不得還，吾奇兵絕其後，野無所掠鹵，不至十日，兩將之頭可致戲下。願君留意臣之計，必不為二子所禽矣。」成安君，儒者，常稱義兵不用詐謀奇計，謂曰：「吾聞兵法『什則圍之，倍則戰。』今韓信兵號數萬，其實不能，千里襲我，亦以罷矣。今如此避弗擊，後有大者，何以距之？諸侯謂吾怯，而輕來伐我。」不聽廣武君策。

> 信使間人窺知其不用，還報，則大喜，乃敢引兵遂下。未至井陘口三十里，止舍。夜半傳發，選輕騎二千人，人持一赤幟，從間道萆山而望趙軍，戒曰：「趙見我走，必空壁逐我，若疾入，拔趙幟，立漢幟。」令其裨將傳餐，曰：「今日破趙會食。」諸將皆嘸然，陽應曰：「諾。」信謂軍吏曰：「趙已先據便地壁，且彼未見大將旗鼓，未肯擊前行，恐吾阻險而還。」乃使萬人先行，出，背水陳。趙兵望見大笑。平旦，信建大將旗鼓，鼓行出井陘口，趙開壁擊之，大戰良久。於是信、張耳棄鼓旗，走水上軍，復疾戰。趙空壁爭漢鼓旗，逐信、耳。信、耳已入水上軍，軍皆殊死戰，不可敗。信所出奇兵二千騎者，候趙空壁逐利，即馳入趙壁，皆拔趙旗幟，立漢赤幟二千。趙軍已不能得信、耳等，欲還歸壁，壁皆漢赤幟，大驚，以漢為皆已破趙王將矣，遂亂，遁走。趙將雖斬之，弗能禁。於是漢兵夾擊，破虜趙軍，斬成安君泜水上，禽趙王歇。

> 食其未行，張良從外來謁。漢王方食，曰：「子房前！客有為我計橈楚權者。」其以酈生語告，曰：「於子房何如？」良曰：「誰為陛下畫此計者？陛下事去矣。」漢王曰：「何哉？」張良對曰：「臣請藉前箸為大王籌之。」曰：「昔者湯伐桀而封其後於杞者，度能制桀之死命也。今陛下能制項籍之死命乎？」曰：「未能也。」「其不可一也。武王伐紂封其後於宋者，度能得紂之頭也。今陛下能得項籍之頭乎？」曰：「未能也。」「其不可二也。武王入殷，表商容之閭，釋箕子之拘，封比干之墓。今陛下能封聖人之墓，表賢者之閭，式智者之門乎？」曰：「未能也。」「其不可三也。發鉅橋之粟，散鹿臺之錢，以賜貧窮。今陛下能散府庫以賜貧窮乎？」曰：「未能也。」「其不可四矣。殷事已畢，偃革為軒，倒置干戈，覆以虎皮，以示天下不復用兵。今陛下能偃武行文，不復用兵乎？」曰：「未能也。」「其不可五矣。休馬華山之陽，示以無所為。今陛下能休馬無所用乎？」曰：「未能也。」「其不可六矣。放牛桃林之陰，以示不復輸積。今陛下能放牛不復輸積乎？」曰：「未能也。」「其不可七矣。且天下游士離其親戚，棄墳墓，去故舊，從陛下游者，徒欲日夜望咫尺之地。今復六國，立韓、魏、燕、趙、齊、楚之後，天下游士各歸事其主，從其親戚，反其故舊墳墓，陛下與誰取天下乎？其不可八矣。且夫楚唯無彊，六國立者復橈而從之，陛下焉得而臣之？誠用客之謀，陛下事去矣。」漢王輟食吐哺，罵曰：「豎儒，幾敗而公事！」令趣銷印。

> 酈生因曰：「臣聞知天之天者，王事可成；不知天之天者，王事不可成。王者以民人爲天，而民人以食爲天。夫敖倉，天下轉輸久矣，臣聞其下迺有藏粟甚多，楚人拔滎陽，不堅守敖倉，迺引而東，令適卒分守成臯，此乃天所以資漢也。方今楚易取而漢反却，自奪其便，臣竊以爲過矣。且兩雄不俱立，楚漢久相持不決，百姓騷動，海內搖蕩，農夫釋耒，工女下機，天下之心未有所定也。願足下急復進兵，收取滎陽，據敖倉之粟，塞成臯之險，杜大行之道，距蜚狐之口，守白馬之津，以示諸侯効實形制之勢，則天下知所歸矣。方今燕、趙已定，唯齊未下。今田廣據千里之齊，田間將二十萬之衆，軍於歷城，諸田宗彊，負海阻河濟，南近楚，人多變詐，足下雖遣數十萬師，未可以歲月破也。臣請得奉明詔說齊王，使爲漢而稱東藩。」上曰：「善。」

**本卷归年说明：** 汉三年秋依本篇起语。敖仓、成皋与诸关津是这次进言的形势和部署，具体攻守另见本页与前203年。

### 24. 郦食其说齐罢兵，韩信却没有停下东进

<a id="hs043-l7385-e24"></a>

**[《汉书·郦陆朱刘叔孙传》P004](../../sources/摘录/汉书-卷043-郦陆朱刘叔孙传.md#p004)** · [仓内TXT L7385](../../sources/本地分卷/汉书/汉书-卷043.md#L7385)

> 乃從其畫，复守敖倉，而使食其說齊王，曰：「王知天下之所歸乎？」曰：「不知也。」曰：「知天下之所歸，則齊國可得而有也；若不知天下之所歸，即齊國未可保也。」齊王曰：「天下何歸？」食其曰：「天下歸漢。」齊王曰：「先生何以言之？」曰：「漢王与項王戮力西面擊秦，約先入咸陽者王之，項王背約不与，而王之漢中。項王遷殺義帝，漢王起蜀漢之兵擊三秦，出關而責義帝之負處，收天下之兵，立諸侯之后。降城即以侯其將，得賂則以分其士，与天下同其利，豪英賢材皆樂為之用。諸侯之兵四面而至，蜀漢之粟方船而下。項王有背約之名，殺義帝之負；于人之功無所記，于人之罪無所忘；戰胜而不得其賞，拔城而不得其封；非項氏莫得用事；為人刻印，玩而不能授；攻城得賂，積財而不能賞。天下畔之，賢材怨之，而莫為之用。故天下之士歸于漢王，可坐而策也。夫漢王發蜀漢，定三秦；涉西河之外，授上党之兵；下井陘，誅成安君；破北魏，舉三十二城：此黃帝之兵，非人之力，天之福今。今已据敖倉之粟，塞成皋之險，守白馬之津，杜太行之厄，距飛狐之口，天下后服者先亡矣。王疾下漢王，齊國社稷可得而保也；不下漢王，危亡可立而待也。」田廣以為然，乃听食其，罷歷下兵守戰備，与食其日縱酒。

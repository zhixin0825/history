##### 卷022｜将相表互见与异说
[本年原表R002](../../拆分史书/史记/卷022.md#r002) · [《汉书·百官公卿表》](../../拆分史书/汉书/卷019.md#part-3-ws019-bce-0205)。

> 纪年：二；大事纪：春，定塞、翟、魏、河南、韓、殷國。夏，伐項籍，至彭城。立太子。還據滎陽。；相位：二。守關中。；将位：一。太尉長安侯盧綰。；御史大夫位：〔空〕

塞、翟归附在前206年已经发生，本格以二年春总括东进，不另记第二次投降。魏豹是先归汉、随伐楚而后反汉，韩国的韩王信与攻魏的大将韩信分开。相位的“守关中”是萧何的后方职责；将位以卢绾太尉起数，侯号作为辨人称谓，不由此倒推封爵的确日。

##### 2｜齐、赵及反复归降
田荣并三齐前206，陈馀复赵前205初。北击田荣，本纪概称二年冬，《通鉴》正月，正文沿编年底本；田广立齐由同书四月条定位。魏豹、司马欣的先归汉再附楚分开，不因人物重新出现就当成两个人。卷008把塞、翟、河南归降合在二年概述，前206已写塞翟归汉，不重复改旗。

##### 3｜彭城、兵数与家属

##### 4｜苑囿、社稷与年条的范围
[卷008 P023、P027、P029](../../拆分史书/史记/卷008.md#p023)。本轮补苑囿开放、奖降、郡制、章平、祭祀及太子守栎阳。开放供田不等于所有园林当年已全部改成耕地；万户奖励是政策所许，不是每位将领已获实收户数。郡名与秦原行政区重叠，是恢复、改置和实际控制的叙述，不称各郡此前从未存在。

卷008三年开头回写魏豹被俘，正文仍从年表、《通鉴》放二年九月；后面的攻赵、张耳立赵王分别见前204、203年。随何出使、黥布起事、败退归汉亦不全部挤进一个月。萧何征兵“老弱未傅”保留非常征发性质，不擅算统一年龄或儿童人数。军费、人口、徭役的细节仅依所用材料，不将本卷阅读完成等同于所有制度研究已解决。

#### 卷026｜北畤的年次与汉初沿秦历
[《历书》P009](../../拆分史书/史记/卷026.md#p009)只概称“汉兴”，以刘邦“北畤待我而起”说明其水德解释。增立北畤按[《史记·封禅书》汉二年](../../拆分史书/史记/卷028.md#part-1-text)及[《汉书·郊祀志上》二年](../../拆分史书/汉书/卷025.md#part-1-text)归入本页，未由“汉兴”直接当成前202年称帝之日；相关段落把东击项籍、还关与祭祀相接，月份不从相邻军事叙述硬定。

卷026概称汉初沿秦正朔服色；卷028又说刘邦起兵尚赤，汉书还见“外黑内赤”。这些是不同层面的制度与象征记述，不抹平成汉初处处只有一种颜色，更不因北畤祀黑帝便断言其五德理论全无异说。见[秦汉说明](../../拆分史书/史记/卷026.md#kao-52578ba700-b924bae33)。

汉军一面经营关中，一面联合诸侯东征，却在彭城遭到项羽重创。刘邦退到荥阳重整兵力，依靠关中输送兵粮，再派韩信向北攻魏、代，楚汉相持的战线逐渐形成。

## 本年概述

项羽北伐齐国，刘邦以义帝遇害号召诸侯，率联军入彭城，旋被楚军击败。汉军在荥阳重整，转派韩信渡河平魏、进兵代地。关中则继续定郡县、立太子并经营军粮。

## 关中立足与赵、齐、韩等地的战事

<a id="sj007-yidi"></a>
<a id="event-1"></a>

1. **冬十月，义帝遇害。** 项羽先前尊楚怀王熊心为义帝，随后又催他迁往郴县；到了本年冬十月，项羽暗中命人加害，义帝遇害。加害者和遇害地点在本纪中各有异文。反秦时各军共同借用的楚王名义，最终被主持分封的项羽清除。 [[1]](#note-1)

<a id="sj007-zhao"></a>
<a id="event-2"></a>

2. **陈馀夺回赵地，张耳投奔汉王。** 陈馀不满自己只封侯、张耳却成为常山王，派张同、夏说向齐王田荣求兵。他把齐国援军和自己三县的兵力合在一起，击败张耳，迎原代王赵歇回赵；张耳逃到刘邦处，受到厚待。赵歇感激陈馀，封他为代王，陈馀却因赵国初定而留在赵辅政，派夏说以相国身份镇守代地。昔日并肩复赵的张耳、陈馀，至此已成仇敌。 [[2]](#note-2)

<a id="event-3"></a>

3. **张良从韩地归汉，受封成信侯。** 张良从韩地走小路返回刘邦身边，被封为成信侯。他多病，通常不单独领军，主要为刘邦出谋划策，时常随侍。此前他在韩国与汉军之间往来，如今再次成为刘邦身边的重要谋臣。 [[3]](#note-3)

<a id="sj008-han-government"></a>
<a id="event-4"></a>

4. **刘邦出陕安抚父老，河南王申阳归降。** 刘邦前往陕县，安抚关中以外的父老，争取新得地区的支持。河南王申阳随后归降，原来的封国被改置为河南郡，汉的统治逐步向关外伸展。 [[4]](#note-4)

<a id="event-5"></a>

5. **十一月，韩王信取代郑昌为韩王。** 刘邦任用韩国宗室韩信为韩太尉，派他攻取韩地。韩信急攻项羽所立的韩王郑昌，迫使郑昌投降；十一月，刘邦立韩信为新的韩王，由他继续率韩兵随军作战。这里的韩王信，与统率汉军、后来击魏破赵的大将韩信，是两个人。 [[5]](#note-5)

<a id="event-6"></a>

6. **刘邦还都栎阳，经营关中与陇西。** 刘邦返回栎阳，诸将继续攻略并取得陇西。他规定，带领万人或一郡归降者，可以获封万户；又整修河上边塞，把秦原有的苑囿、园池开放给百姓耕种。军队向外争夺土地的同时，汉也开始安排新得地区的生产、防务与归附奖赏。 [[6]](#note-6)

7. **项羽攻齐，田荣死后田横复夺齐地。** 春正月，项羽在城阳击败齐王田荣，田荣逃到平原，被当地民众杀死。项羽恢复田假的齐王名号，继续向北进军，焚烧城郭房屋，杀害降卒，掳走老弱妇女。田荣虽死，楚军的破坏却激起齐人再次聚众反抗。田横反攻田假，齐地再度易主。田荣之弟田横继续抵抗楚军，并攻逐田假。田假逃回楚方，却被楚人杀死；前208年他曾逃楚获容留，这次复位、再败后的结局已不同。田横重新控制齐地，为随后拥立田广准备了力量。夏四月，田横在城阳收集数万散卒，拥立田荣之子田广为齐王，继续抵抗楚军。项羽虽然已经听到汉军东进，却仍想先平定齐地再回兵，连战不能尽下，因而给刘邦联合诸侯东征留下了机会。 [[7]](#note-7)

<a id="event-8"></a>

8. **汉军夺取北地，俘获章平。** 汉军攻下北地，俘获雍王章邯的弟弟章平。刘邦随后赦免罪人。关中各据点仍在逐一被消除，章邯本人则继续守在废丘。 [[8]](#note-8)

<a id="event-9"></a>

9. **二月，改立汉社稷，减免赋役并设置三老。** 二月癸未，刘邦命人撤去秦的社稷，改立汉社稷，并赐民爵位。蜀、汉百姓长期供给军需，免租税两年；关中从军者的家庭免除一年徭役。朝廷选年满五十、品行端正、能带领乡人向善者为乡三老，再从中选县三老，与县令、丞、尉一起处理教化之事，并免三老徭役、戍役，诏中又记十月赐酒肉。 [[9]](#note-9)

<a id="event-11"></a>

10. **三月，刘邦渡河，俘殷王并置河内郡。** 刘邦从临晋渡过黄河，西魏王魏豹带兵归附并跟随汉军。汉军攻下河内，俘获殷王司马卬，在其地设置河内郡。军队继续到达脩武，再从平阴津南渡，向洛阳推进。 曹参以中尉出临晋关，至河内、取修武，再渡围津向东。 [[10]](#note-11)

<a id="event-12"></a>

11. **陈平离楚归汉，刘邦立即重用。** 此前殷王背楚，项羽以陈平为信武君，令他率原魏咎宾客击降殷，遣项悍授都尉、赐金二十镒；汉军后来又下殷，项羽要诛定殷将吏。陈平封好金印派人送还，持剑间行，渡河时见船夫疑他藏金欲杀，便脱衣助撑船，显出空身，才得脱险。到修武，经魏无知介绍、石奋引入，与数人同受赐食；他坚持所言不能过今日，刘邦与语大悦，当日授都尉、参乘并典护军。旧将不满刚来的楚逃卒监督资深将领，刘邦反而更加信任他。 [[11]](#note-12)

## 讨楚、彭城败退及荥阳重整

<a id="event-13"></a>

12. **董公劝举义帝之丧，刘邦号召诸侯讨楚。** 刘邦南渡平阴津，到洛阳一带时，新城三老董公拦住他，指出项羽杀害共同尊奉的义帝，可以成为讨楚的名义。刘邦采纳其议，为义帝发丧，袒露臂膀大哭，致哀三日，又派使者通知诸侯，共同讨伐杀害故主的项羽。战争由此多了一项能够号召反秦旧盟的政治理由。 [[12]](#note-13)

<a id="event-15"></a>

13. **彭越归汉，刘邦联军进入彭城。** 刘邦联合诸侯向楚都彭城进军，所报联军总数为五十六万。行至外黄时，彭越率三万兵归附，刘邦任他为魏相国，让他继续平定梁地。汉军进入彭城后，收取项羽的财物、美人，饮酒庆贺。 曹参在定陶击败龙且、项他，又从军取砀、萧、彭城。 [[13]](#note-15)

14. **项羽自齐回师，汉军在彭城败散后重整。** 项羽回师突袭，汉军在彭城大败。项羽把齐地战事交给诸将，亲率三万精兵，从鲁地经胡陵赶到萧县，清晨向东突击彭城，中午便大破汉军。溃兵挤入谷水、泗水，楚军又追至灵壁以东的睢水，大批汉兵被挤落水中。刘邦也遭到重围，最后趁西北风沙使楚军混乱，带数十骑突围。占得楚都的联军，短时间内就被打散。刘邦逃亡遇见子女，太公与吕后被俘。刘邦想经过沛县寻找家人，却未能找到。路上遇到儿子刘盈和女儿，便把他们带上车；楚军追得紧，他几次把孩子推下去，滕公夏侯婴又下车将他们抱回，最终保护二人逃脱。另一边，审食其陪太公、吕后走小路寻找刘邦，却遇上楚军，两人被项羽扣作人质。诸侯见汉败，重新倒向楚方。彭城败后，原来跟随汉军的诸侯纷纷离去。塞王司马欣、翟王董翳重新归楚，原殷王司马卬也死去。刘邦失去的不只是战场上的兵力，先前勉强聚合的联盟也随之瓦解。刘邦投奔吕泽，逐步收集败兵。吕后的哥哥周吕侯吕泽带兵驻在下邑，刘邦突围后前去投奔，逐渐收集散卒，在砀一带重新立足。汉军虽然在彭城大败，仍有地方部队和关中后方可以接应。在下邑，刘邦下马坐倚马鞍，问若把关东土地拿出来，谁可以共事。张良推荐三人：九江王黥布有勇而与项羽生隙，彭越联田荣反楚于梁，都应急遣使者相结；汉将韩信则能独当一面。刘邦若把东方土地用来结这三人，便有破楚的机会。 [[14]](#note-16)

<a id="event-20"></a>

15. **刘邦派随何争取九江王黥布。** 刘邦经过梁地到虞县，派谒者随何去游说九江王黥布，希望他起兵背楚，使项羽多一个需要顾忌的方向。黥布先前屡称病，不肯亲自随项羽作战，双方已有嫌隙；随何的任务，就是把这种嫌隙变成汉方的机会。 他也派人联络彭越。韩信后来受命击叛汉的魏豹，继而取得燕、代、齐、赵；这些逐年发展的战果，连同黥布、彭越的活动，最终促成破楚。 [[15]](#note-20)

<a id="event-21"></a>

16. **五月，汉军在荥阳重整，京索之战挡住楚军。** 刘邦退到荥阳后，败军陆续会合，韩信也收集部队赶来。萧何从关中征发尚未登记服役的老弱等人补充前线，汉军重新振作。在荥阳以南的京、索之间，汉军击败追来的楚军，使楚军未能越过荥阳直入关中。随后汉军修筑甬道，连接黄河，运取敖仓的粮食，开始建立长期相持所需的供应线。 曹参在彭城败后的返军途中，围取雍丘，击破外黄王武、燕县程处及衍氏柱天侯的反抗，又在昆阳击羽婴、追至叶，回攻武强而至荥阳。其自汉中以来的将军、中尉军历已跨汉元年、二年。 陈平也随败军退到荥阳，改任亚将，隶属韩国宗室韩王信，驻军广武。 [[16]](#note-21)

<a id="sj056-defense-event"></a>

17. **诸将指控陈平反复受金，魏无知与陈平分别答辩。** 周勃、灌婴等以外貌无实、盗嫂、屡换主人和受诸将金分配好坏处境相谗。刘邦先责魏无知，魏无知强调推荐的是有助战争胜负的谋才，尾生之信、孝己之孝若无助胜负，也未必适用。陈平则解释魏王不用其言、项王只信亲族，自己因汉王善用人而来；空身归汉，没有资用才收金，若计不可用，愿交还钱财辞去。刘邦道歉厚赐，授护军中尉，使尽护诸将。指控与答辩分开记，不能据“盗嫂”二字就认作查明的事实。 [[17]](#sj056-defense-note)

<a id="sj056-wangling-event"></a>

18. **王陵带南阳部众归汉。** 王陵原为沛县豪强，刘邦微时以兄事之；他少文、任气、好直言。刘邦起兵入咸阳之际，王陵自己聚集数千人驻南阳，尚不肯从；到汉王回军东攻项羽，才以部众属汉。他母亲被项羽拘持、伏剑明志的故事发生在此后的楚汉战争中，见[未定年叙事](../bce-0200-0101/未定年-陈平王陵与陈氏后续.md#event-1)。 [[18]](#sj056-wangling-note)

## 韩信渡河攻魏、进军代地

<a id="event-22"></a>

<a id="event-27"></a>

<a id="event-28"></a>

19. **魏豹反汉，韩信渡河攻魏并俘魏豹。** 魏豹借探亲离军，回国后反汉。西魏王魏豹向刘邦请求回去探望有病的亲人，获准离开荥阳。回到魏地后，他立即封锁黄河渡口，重新归附楚方。刘邦因此必须同时守住楚军正面，处理北侧盟友的反复。在此以前，魏豹称王后，薄姬的母亲魏媪将女儿送入魏宫。相传许负断言薄姬将生天子，魏豹听后暗自高兴；这一传述把他背汉、先持中立而后联楚的选择，与宫中的生子预言相连。刘邦劝降魏豹失败，派韩信、曹参、灌婴攻魏。刘邦派郦食其游说魏豹，许诺如果能使魏归汉，便封郦食其万户；魏豹没有接受。刘邦于是任韩信为左丞相，令他与曹参、灌婴共同攻魏。他询问魏军将领的情况，认为柏直、冯敬、项它分别难敌韩信、灌婴、曹参，决定进兵。曹参在东征返军后任假左丞相，先屯关中；过了一个多月才转入与韩信攻魏的部署。九月，魏豹重兵守在蒲阪，封锁临晋渡口。韩信在临晋陈列船只、增设疑兵，暗中从夏阳渡河，袭击安邑。魏豹急忙迎战，最终被俘，押送荥阳。汉军平定魏地，在河东、上党、太原等地区安排管辖，北进道路随之打开。魏宫的薄姬被送入汉方织室。她的父亲来自吴地，秦代与原魏王宗族女子魏媪相交而生下她，父亲早已死葬山阴；这些都是薄姬被俘以前的家世。曹参以假左丞相分军攻孙遬于东张，取安邑、得王襄，战魏豹于曲阳、追至武垣，生擒魏豹；又取平阳，俘其母、妻子儿女，合计定魏五十二城，受平阳食邑。魏王豹被俘后，原在魏宫的薄姬被送入汉的织室。 [[19]](#note-22)

<a id="event-29"></a>

20. **韩信请增兵三万，提出分路攻取北方。** 平定魏地后，韩信派人请求增兵三万，提出向北攻取燕、赵，向东进击齐国，再从南面切断楚军粮道。刘邦同意，派张耳与他同行。韩信由此准备从魏地转入北方战场，与刘邦在荥阳牵制项羽的战线互相配合。 [[20]](#note-29)

<a id="event-30"></a>

21. **后九月，韩信破代兵，擒获夏说。** 韩信北进，在阏与击败代兵，俘获镇守代地的相国夏说。汉军从魏、代战线取得的精兵，又被刘邦不断调往荥阳抗楚。北方进军和荥阳正面因此争用、补充着同一批军力。 曹参随韩信参加这一轮进攻，击败夏说所部。 [[21]](#note-30)

## 后方任置、饥荒与军政

<a id="event-23"></a>

22. **六月，刘邦还栎阳，立刘盈为太子。** 刘邦返回栎阳，于壬午日立儿子刘盈为太子，大赦罪人，让太子留守栎阳，并命在关中的诸侯子弟都到这里充当卫士。前线仍在相持，汉王已经开始安排继承及后方的守卫。 [[22]](#note-23)

<a id="event-24"></a>

23. **汉军水攻废丘，章邯自杀，关中继续改置郡县。** 汉军引水灌入废丘，城破后，雍王章邯自杀；这座从前一年围到本年的据点终于被拔除，废丘改名槐里。汉在平定后的关中地区调整郡县管辖，又命祠官按时祭祀天地、四方上帝与山川，征发关中士卒守卫边塞。 周勃的平三秦功录同有围废丘，又列破西县之丞、破盗巴军、攻上邽、东守峣关；这些是跨前206—205年阶段的相连军功，原段没有逐战确月。 [[23]](#note-24)

<a id="event-25"></a>

24. **关中大饥，刘邦准许百姓到蜀汉就食。** 关中发生严重饥荒，粮价高涨。米一斛值万钱，甚至出现人吃人的惨状；刘邦下令让百姓到蜀、汉地区寻找食粮。关中虽是汉军的重要后方，战争中的民生和供给仍十分困难。 [[24]](#note-25)

<a id="event-26"></a>

25. **秋八月，刘邦回荥阳，让萧何主持关中。** 刘邦返回荥阳，把关中的法令、户口、粮运和征兵交给萧何，命他辅佐太子，在栎阳主持政务。萧何设立宗庙、社稷、宫室与县邑，通常先奏准再施行；来不及逐项请示的事，可以先行处理，等刘邦回来再报告。刘邦屡次失军败走，萧何便从关中征兵补足缺额，组织转运供粮。稳定的关中政务成为汉军反复重整、继续对抗楚军的重要依靠。 [[25]](#note-26)

<a id="sj022"></a>
<a id="event-31"></a>

26. **年内，卢绾以太尉身份随军。** 卢绾以太尉身份跟随刘邦东击项羽，常在汉王身边，受到亲近信任。他与刘邦同乡，早年就相随，进入汉中时已经做了将军；如今继续在刘邦军中任职。 [[26]](#note-31)

<a id="sj026"></a>
<a id="event-32"></a>

27. **年内，刘邦增立北畤，补齐五帝祭祀。** 刘邦得知秦原有白、青、黄、赤四帝的祭所，便问：既然天有五帝，为什么只祭四帝？随后他下令增立祭黑帝的北畤，使五帝祭祀齐备。祭祀交给有司办理，他没有亲自前往；朝廷又召回秦时祝官，恢复太祝、太宰，沿用原有仪礼，并命各地按时祭祀有关神祇。 [[27]](#note-32)

> 絳侯、灌嬰等咸讒陳平曰：「平雖美丈夫，如冠玉耳，其中未必有也。臣聞平居家時，盜其嫂；事魏不容，亡歸楚；歸楚不中，又亡歸漢。今日大王尊官之，令護軍。臣聞平受諸將金，金多者得善處，金少者得惡處。平，反覆亂臣也，願王察之。」漢王疑之，召讓魏無知。無知曰：「臣所言者，能也；陛下所問者，行也。今有尾生、孝己之行而無益處於勝負之數，陛下何暇用之乎？楚漢相距，臣進奇謀之士，顧其計誠足以利國家不耳。且盜嫂受金又何足疑乎？」漢王召讓平曰：「先生事魏不中，遂事楚而去，今又從吾游，信者固多心乎？」平曰：「臣事魏王，魏王不能用臣說，故去事項王。項王不能信人，其所任愛，非諸項即妻之昆弟，雖有奇士不能用，平乃去楚。聞漢王之能用人，故歸大王。臣躶身來，不受金無以為資。誠臣計畫有可采者，顧大王用之；使無可用者，金具在，請封輸官，得請骸骨。」漢王乃謝，厚賜，拜為護軍中尉，盡護諸將。諸將乃不敢復言。

**本卷说明：** “盗嫂”与“受金”是诸将的指摘，魏无知辨能与行，陈平承认收金而解释资用，未作同样的盗嫂自认。[三家注p6](../../拆分史书/史记/卷056.md#part-2-p6)实际注释冠玉和孝己；尾生、请骸骨在主文中出现，本段古注没有另载其故事或词义专释，不能虚指已有注引。迁护军中尉接原护军职掌，未另造改朝。

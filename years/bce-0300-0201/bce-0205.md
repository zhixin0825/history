# 公元前205年（汉二年）

<a id="reading-start"></a>


[← 公元前206年条](bce-0206.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前204年 →](bce-0204.md)

[本年相关史料](#本年相关史料)

汉军一面经营关中，一面联合诸侯东征，却在彭城遭到项羽重创。刘邦退到荥阳重整兵力，依靠关中输送兵粮，再派韩信向北攻魏、代，楚汉相持的战线逐渐形成。

<a id="sj007-yidi"></a>
<a id="event-1"></a>

1. **冬十月，义帝遇害。** 项羽先前尊楚怀王熊心为义帝，随后又催他迁往郴县；到了本年冬十月，项羽暗中命地方诸王加害，义帝被杀在江中。反秦时各军共同借用的楚王名义，最终被主持分封的项羽清除。 [[1]](#note-1)

<a id="sj007-zhao"></a>
<a id="event-2"></a>

2. **陈馀夺回赵地，张耳投奔汉王。** 陈馀不满自己只封侯、张耳却成为常山王，派张同、夏说向齐王田荣求兵。他把齐国援军和自己三县的兵力合在一起，击败张耳，迎原代王赵歇回赵；张耳逃到刘邦处，受到厚待。赵歇感激陈馀，封他为代王，陈馀却因赵国初定而留在赵辅政，派夏说以相国身份镇守代地。昔日并肩复赵的张耳、陈馀，至此已成仇敌。 [[2]](#note-2)

<a id="event-3"></a>

3. **张良从韩地归汉，受封成信侯。** 张良从韩地走小路返回刘邦身边，被封为成信侯。他多病，通常不单独领军，主要为刘邦出谋划策，时常随侍。此前他在韩国与汉军之间往来，如今再次成为刘邦身边的重要谋臣。 [[3]](#note-3)

<a id="sj008-han-government"></a>
<a id="event-4"></a>

4. **刘邦出陕安抚父老，河南王申阳归降。** 刘邦前往陕县，安抚关中以外的父老，争取新得地区的支持。河南王申阳随后归降，原来的封国被改置为河南郡，汉的统治逐步向关外伸展。 [[4]](#note-4)

<a id="event-5"></a>

5. **十一月，韩王信取代郑昌为韩王。** 刘邦任用韩国宗室韩信为韩太尉，派他攻取韩地。韩信急攻项羽所立的韩王郑昌，迫使郑昌投降；十一月，刘邦立韩信为新的韩王，由他继续率韩兵随军作战。这里的韩王信，与统率汉军、后来击魏破赵的大将韩信，是两个人。 [[5]](#note-5)

<a id="event-6"></a>

6. **刘邦还都栎阳，经营关中与陇西。** 刘邦返回栎阳，诸将继续攻略并取得陇西。他规定，带领万人或一郡归降者，可以获封万户；又整修河上边塞，把秦原有的苑囿、园池开放给百姓耕种。军队向外争夺土地的同时，汉也开始安排新得地区的生产、防务与归附奖赏。 [[6]](#note-6)

<a id="event-7"></a>

7. **春正月，田荣败死，齐人继续反楚。** 项羽在城阳击败齐王田荣，田荣逃到平原，被当地民众杀死。项羽恢复田假的齐王名号，继续向北进军，焚烧城郭房屋，杀害降卒，掳走老弱妇女。田荣虽死，楚军的破坏却激起齐人再次聚众反抗。 [[7]](#note-7)

<a id="event-8"></a>

8. **汉军夺取北地，俘获章平。** 汉军攻下北地，俘获雍王章邯的弟弟章平。刘邦随后赦免罪人。关中各据点仍在逐一被消除，章邯本人则继续守在废丘。 [[8]](#note-8)

<a id="event-9"></a>

9. **二月，改立汉社稷，减免赋役并设置三老。** 二月癸未，刘邦命人撤去秦的社稷，改立汉社稷，并赐民爵位。蜀、汉百姓长期供给军需，免租税两年；关中从军者的家庭免除一年徭役。朝廷选年满五十、品行端正、能带领乡人向善者为乡三老，再从中选县三老，与县令、丞、尉一起处理教化之事，并免其徭役、戍役；每年十月还赐百姓酒肉。 [[9]](#note-9)

<a id="sj016-tianjia"></a>
<a id="event-10"></a>

10. **田横反攻田假，齐地再度易主。** 田荣之弟田横继续抵抗楚军，并攻逐田假。田假逃回楚方，却被楚人杀死；前208年他曾逃楚获容留，这次复位、再败后的结局已不同。田横重新控制齐地，为随后拥立田广准备了力量。 [[10]](#note-10)

<a id="event-11"></a>

11. **三月，刘邦渡河，俘殷王并置河内郡。** 刘邦从临晋渡过黄河，西魏王魏豹带兵归附并跟随汉军。汉军攻下河内，俘获殷王司马卬，在其地设置河内郡。军队继续到达脩武，再从平阴津南渡，向洛阳推进。 [[11]](#note-11)

<a id="event-12"></a>

12. **陈平离楚归汉，刘邦立即重用。** 陈平早先事魏，后来投楚，在项羽军中做过都尉；鸿门时，他仍是楚方的人。汉军攻下殷地后，项羽要追究原先平殷将吏的责任，陈平便封还金印，独自离楚。到脩武，他经魏无知介绍见到刘邦，谈话后立即被任为都尉、参乘，并负责监护诸将。旧将不满一个刚从楚军逃来的人反而居于自己之上，刘邦却愈加信任他。 [[12]](#note-12)

<a id="event-13"></a>

13. **董公劝举义帝之丧，刘邦号召诸侯讨楚。** 刘邦南渡平阴津，到洛阳一带时，新城三老董公拦住他，指出项羽杀害共同尊奉的义帝，可以成为讨楚的名义。刘邦采纳其议，为义帝发丧，袒露臂膀大哭，致哀三日，又派使者通知诸侯，共同讨伐杀害故主的项羽。战争由此多了一项能够号召反秦旧盟的政治理由。 [[13]](#note-13)

<a id="event-14"></a>

14. **夏四月，田横拥立田广，项羽滞留齐地。** 田横在城阳收集数万散卒，拥立田荣之子田广为齐王，继续抵抗楚军。项羽虽然已经听到汉军东进，却仍想先平定齐地再回兵，连战不能尽下，因而给刘邦联合诸侯东征留下了机会。 [[14]](#note-14)

<a id="event-15"></a>

15. **彭越归汉，刘邦联军进入彭城。** 刘邦联合诸侯向楚都彭城进军，所报联军总数为五十六万。行至外黄时，彭越率三万兵归附，刘邦任他为魏相国，让他继续平定梁地。汉军进入彭城后，收取项羽的财物、美人，饮酒庆贺。 [[15]](#note-15)

<a id="sj007-pengcheng"></a>
<a id="event-16"></a>

16. **项羽回师突袭，汉军在彭城大败。** 项羽把齐地战事交给诸将，亲率三万精兵，从鲁地经胡陵赶到萧县，清晨向东突击彭城，中午便大破汉军。溃兵挤入谷水、泗水，楚军又追至灵壁以东的睢水，大批汉兵被挤落水中。刘邦也遭到重围，最后趁西北风沙使楚军混乱，带数十骑突围。占得楚都的联军，短时间内就被打散。 [[16]](#note-16)

<a id="event-17"></a>

17. **刘邦逃亡遇见子女，太公与吕后被俘。** 刘邦想经过沛县寻找家人，却未能找到。路上遇到儿子刘盈和女儿，便把他们带上车；楚军追得紧，他几次把孩子推下去，滕公夏侯婴又下车将他们抱回，最终保护二人逃脱。另一边，审食其陪太公、吕后走小路寻找刘邦，却遇上楚军，两人被项羽扣作人质。 [[17]](#note-17)

<a id="event-18"></a>

18. **诸侯见汉败，重新倒向楚方。** 彭城败后，原来跟随汉军的诸侯纷纷离去。塞王司马欣、翟王董翳重新归楚，原殷王司马卬也死去。刘邦失去的不只是战场上的兵力，先前勉强聚合的联盟也随之瓦解。 [[18]](#note-18)

<a id="event-19"></a>

19. **刘邦投奔吕泽，逐步收集败兵。** 吕后的哥哥周吕侯吕泽带兵驻在下邑，刘邦突围后前去投奔，逐渐收集散卒，在砀一带重新立足。汉军虽然在彭城大败，仍有地方部队和关中后方可以接应。 [[19]](#note-19)

<a id="event-20"></a>

20. **刘邦派随何争取九江王黥布。** 刘邦经过梁地到虞县，派谒者随何去游说九江王黥布，希望他起兵背楚，使项羽多一个需要顾忌的方向。黥布先前屡称病，不肯亲自随项羽作战，双方已有嫌隙；随何的任务，就是把这种嫌隙变成汉方的机会。 [[20]](#note-20)

<a id="event-21"></a>

21. **五月，汉军在荥阳重整，京索之战挡住楚军。** 刘邦退到荥阳后，败军陆续会合，韩信也收集部队赶来。萧何从关中征发尚未登记服役的老弱等人补充前线，汉军重新振作。在荥阳以南的京、索之间，汉军击败追来的楚军，使楚军未能越过荥阳直入关中。随后汉军修筑甬道，连接黄河，运取敖仓的粮食，开始建立长期相持所需的供应线。 [[21]](#note-21)

<a id="event-22"></a>

22. **魏豹借探亲离军，回国后反汉。** 西魏王魏豹向刘邦请求回去探望有病的亲人，获准离开荥阳。回到魏地后，他立即封锁黄河渡口，重新归附楚方。刘邦因此必须同时守住楚军正面，处理北侧盟友的反复。 在此以前，魏豹称王后，薄姬的母亲魏媪将女儿送入魏宫。相传许负断言薄姬将生天子，魏豹听后暗自高兴；这一传述把他背汉、先持中立而后联楚的选择，与宫中的生子预言相连。 [[22]](#note-22)

<a id="event-23"></a>

23. **六月，刘邦还栎阳，立刘盈为太子。** 刘邦返回栎阳，于壬午日立儿子刘盈为太子，大赦罪人，让太子留守栎阳，并命在关中的诸侯子弟都到这里充当卫士。前线仍在相持，汉王已经开始安排继承及后方的守卫。 [[23]](#note-23)

<a id="event-24"></a>

24. **汉军水攻废丘，章邯自杀，关中继续改置郡县。** 汉军引水灌入废丘，城破后，雍王章邯自杀；这座从前一年围到本年的据点终于被拔除，废丘改名槐里。汉在平定后的关中地区调整郡县管辖，又命祠官按时祭祀天地、四方上帝与山川，征发关中士卒守卫边塞。 [[24]](#note-24)

<a id="event-25"></a>

25. **关中大饥，刘邦准许百姓到蜀汉就食。** 关中发生严重饥荒，粮价高涨。米一斛值万钱，甚至出现人吃人的惨状；刘邦下令让百姓到蜀、汉地区寻找食粮。关中虽是汉军的重要后方，战争中的民生和供给仍十分困难。 [[25]](#note-25)

<a id="event-26"></a>

26. **秋八月，刘邦回荥阳，让萧何主持关中。** 刘邦返回荥阳，把关中的法令、户口、粮运和征兵交给萧何，命他辅佐太子。来不及逐项请示的事，萧何可以先行处理，等刘邦回来再报告。稳定的关中政务与不断向前线输送兵粮，成为刘邦重新对抗楚军的重要依靠。 [[26]](#note-26)

<a id="event-27"></a>

27. **刘邦劝降魏豹失败，派韩信、曹参、灌婴攻魏。** 刘邦派郦食其游说魏豹，许诺如果能使魏归汉，便封郦食其万户；魏豹没有接受。刘邦于是任韩信为左丞相，令他与曹参、灌婴共同攻魏。他询问魏军将领的情况，认为柏直、冯敬、项它分别难敌韩信、灌婴、曹参，决定进兵。 [[27]](#note-27)

<a id="event-28"></a>

28. **九月，韩信渡河击魏，俘获魏豹。** 魏豹重兵守在蒲阪，封锁临晋渡口。韩信在临晋陈列船只、增设疑兵，暗中从夏阳渡河，袭击安邑。魏豹急忙迎战，最终被俘，押送荥阳。汉军平定魏地，在河东、上党、太原等地区安排管辖，北进道路随之打开。 魏宫的薄姬被送入汉方织室。她的父亲来自吴地，秦代与原魏王宗族女子魏媪相交而生下她，父亲早已死葬山阴；这些都是薄姬被俘以前的家世。 [[28]](#note-28)

<a id="event-29"></a>

29. **韩信请增兵三万，提出分路攻取北方。** 平定魏地后，韩信派人请求增兵三万，提出向北攻取燕、赵，向东进击齐国，再从南面切断楚军粮道。刘邦同意，派张耳与他同行。韩信由此准备从魏地转入北方战场，与刘邦在荥阳牵制项羽的战线互相配合。 [[29]](#note-29)

<a id="event-30"></a>

30. **后九月，韩信破代兵，擒获夏说。** 韩信北进，在阏与击败代兵，俘获镇守代地的相国夏说。汉军从魏、代战线取得的精兵，又被刘邦不断调往荥阳抗楚。北方进军和荥阳正面因此争用、补充着同一批军力。 [[30]](#note-30)

<a id="sj022"></a>
<a id="event-31"></a>

31. **年内，卢绾以太尉身份随军。** 卢绾以太尉身份跟随刘邦东击项羽，常在汉王身边，受到亲近信任。他与刘邦同乡，早年就相随，进入汉中时已经做了将军；如今继续在刘邦军中任职。 [[31]](#note-31)

<a id="sj026"></a>
<a id="event-32"></a>

32. **年内，刘邦增立北畤，补齐五帝祭祀。** 刘邦得知秦原有白、青、黄、赤四帝的祭所，便问：既然天有五帝，为什么只祭四帝？随后他下令增立祭黑帝的北畤，使五帝祭祀齐备。祭祀交给有司办理，他没有亲自前往；朝廷又召回秦时祝官，恢复太祝、太宰，沿用原有仪礼，并命各地按时祭祀有关神祇。 [[32]](#note-32)

### 2. 陈馀夺回赵地，张耳投奔汉王

[返回正文第2条](#event-2)

**[《资治通鉴》卷九](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7009.md#ref-dd7dc16214e307)：**

> 乃陰使張同、夏說說齊王榮曰：「項羽為天下宰不平，盡王諸將善地，徙故王於丑地。今趙王乃北居代，餘以為不可。聞大王起兵，不聽不義。願大王資餘兵擊常山，復趙王，請以趙為扞蔽！」齊王許之，遣兵從陳餘。

**[《资治通鉴》卷九](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7009.md#ref-56f92d46123221)：**

> 陳餘悉三縣兵，與齊兵共襲常山。常山王張耳敗，走漢，謁漢王於廢丘，漢王厚遇之。陳餘迎趙王於代，復為趙王。趙王德陳餘，立以為代王。陳餘為趙王弱，國初定，不之國，留傅趙王；而使夏說以相國守代。

**说明：** 月日未明，放在本年末总括人事，不当作后九月之后才发生的一次新任命。卢绾的长安侯号按原表保留作辨人称谓，不用它倒推封爵确日。原表的萧何守关中已归第26条，不另造一次任命；原表数字与旧栏目说明见[后台记录](../../meta/考证/前0205年-史料与归年说明.md#sj022-note)。

<a id="note-32"></a>
### 32. 年内，刘邦增立北畤，补齐五帝祭祀

[返回正文第32条](#event-32)

**[《史记·封禅书》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7028.md#ref-25bd68445d7c60)：**

> 二年，東擊項籍而還入關，問：「故秦時上帝祠何帝也？」對曰：「四帝，有白、青、黃、赤帝之祠。」高祖曰：「吾聞天有五帝，而有四，何也？」莫知其說。於是高祖曰：「吾知之矣，乃待我而具五也。」乃立黑帝祠，命曰北畤。有司進祠，上不親往。悉召故秦祝官，復置太祝、太宰，如其故儀禮。因令縣為公社。下詔曰：「吾甚重祠而敬祭。今上帝之祭及山川諸神當祠者，各以其時禮祠之如故。」

**《史记·历书》[P009](../../sources/摘录/史记-卷026-历书.md#p009)：**

> 漢興，高祖曰「北畤待我而起」，亦自以為獲水德之瑞。

**说明：** 封禅书、汉书郊祀志系于汉二年，月份未明，放在年内事项，不从“东击还关”硬定祭祀日。水德、沿秦正朔与汉初尚赤等说法的层次见[秦汉说明](../../meta/考证/史记-卷026-纪年与异说.md#秦汉)。

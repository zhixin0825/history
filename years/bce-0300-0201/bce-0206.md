# 公元前206年条｜鸿门宴后项羽分封十八王，刘邦从汉中东返

**汉元年；刘邦受封为汉王，尚未称帝**

> 本页按“汉元年＝前206年”的古史整年对应归档，不是公历一月至十二月的清单。开头冬十月秦降，按公历年界通常归前207年，紧接前页二世三年九月；其他古月也不直接换成同号公历月份。

## 本年概述

汉元年，刘邦先到关中，受子婴降，退驻霸上约法三章。项羽杀秦降卒，破关而入，刘邦经项伯斡旋从鸿门宴脱身。项羽焚掠咸阳后分封诸侯，刘邦到汉中就国，后来任韩信为大将，从故道回师击章邯，关东诸王也相继交兵。

## 秦降、项羽入关与鸿门宴

<a id="冬十月刘邦先到接受子婴投降"></a>

<a id="event-1"></a>

<a id="event-2"></a>

1. **刘邦受秦降入咸阳，听从劝告还军霸上。** 冬十月，刘邦到霸上，子婴在轵道旁交出秦的权柄。子婴乘白马素车、以组系颈，献皇帝玺符节。有人主张杀他，刘邦认为杀已降者不祥，将他交给官吏看管，没有当场处死。刘邦进入咸阳，又在樊哙、张良劝告下退回霸上。他被宫室、珍宝和妇女吸引，想留住秦宫。樊哙劝他还军，张良也指出，秦的无道才使刘邦得以入关，除残暴者当以朴素、吊民为本；刚入秦便享其奢乐，会继续助长暴政。他用忠言逆耳利于行、毒药苦口利于病劝刘邦听樊哙的话，刘邦才封存府库、还军霸上。古注所引另一版本还保存樊哙的长谏：先问刘邦想得天下还是做富家翁，再列秦宫帷帐、珠玉、钟鼓和千数妇女，指出这些正是秦亡的原因，请他速还军。将领们争取金帛财物时，萧何先收秦丞相、御史保存的律令和图籍文书。后来咸阳遭项羽等焚烧，汉方仍能借这些资料详知天下险要、户口多少、各地强弱及百姓疾苦。曹参也随沛公进入咸阳，结束这一段灭秦征程。周勃也随军进入咸阳。 [[1]](#note-1)

<a id="event-3"></a>

2. **十一月，刘邦召父老宣布约法三章，又让人与秦吏同行告谕县乡。** 杀人者死、伤人及盗抵罪，其余秦法废除，吏民各安原处。他声称前来除害，不是侵暴；秦人送牛羊酒食，他又以仓粮尚足、不愿劳费百姓为由推让。 [[2]](#note-3)

3. **项羽在新安杀秦降卒，带三名降将西进。** 诸侯军先前在秦地受辱，如今反过来奴役轻辱秦降卒。降卒私下担心留在关内的家属遭害，话传到项羽处。项羽与黥布、蒲将军商议，夜袭新安城南，杀降卒二十余万，只留下章邯、司马欣、董翳三将随军入秦。 [[3]](#note-4)

<a id="event-6"></a>

4. **秦关告急，项伯夜赴汉营，为刘邦斡旋。** 刘邦听从守关之议，想借关中的险固、财富和增兵扼住诸侯。项羽抵函谷关见关门闭，命当阳君等破关，进至戏西。曹无伤告称刘邦意图独王关中、以子婴为相并独占秦珍宝，打算藉此求封。范增见刘邦入关不急取财色，认为其志甚大，又以望气之说劝项羽早击。项羽实有兵四十万，号百万，刘邦实有兵十万，号二十万。项伯因受过张良救命之恩，入夜赶到汉营，劝张良一同走。张良不忍离开危急中的刘邦，先告知刘邦，并问他能否抵挡项羽。刘邦自认不敌，托张良请项伯相见，敬酒结亲，辩称守关是为防盗备变，已封存府库、登记吏民以待项羽。项伯约他明日亲来谢罪，回营又以刘邦先破秦有功劝项羽善待，项羽同意。 [[4]](#note-6)

<a id="event-12"></a>

5. **鸿门宴上项庄舞剑，樊哙入帐，刘邦脱身。** 刘邦带百余骑到鸿门谢罪，项羽当面说出告密者是曹无伤。宴中项羽、项伯东向，范增南向，刘邦北向，张良西向陪侍。范增屡示意杀刘邦，项羽未应，他便叫项庄舞剑，项伯也起舞，以身体遮护刘邦。张良出帐叫樊哙，樊哙持盾闯入。项羽问明身份，赐酒与彘肩，樊哙当场饮食，又以先入关之约责问为何轻信告密而欲杀有功之人。刘邦借如厕离席，樊哙同行。随项羽入关的都尉陈平奉命来召，樊哙劝刘邦径归。刘邦弃车骑马，与樊哙、夏侯婴、靳彊、纪信等由骊山、芷阳间道回营，随即处死曹无伤。张良估计他已抵达，才代献白璧、玉斗。项羽收下白璧，范增拔剑击碎玉斗。 [[5]](#note-10)

6. **咸阳遭到焚掠，项羽却想回东方。** 项羽西进，杀子婴、烧秦宫室，掠取财物和妇女。 子婴已经降汉，这不是再战被俘。有人劝项羽留关中，用山河土地成霸业，他却见宫殿已毁、又想回乡显贵，没有接受；说者讥楚人沐猴而冠，被烹杀。秦人失望，却不敢不服。 [[6]](#note-13)

## 十八王分封与诸王就国后的冲突

<a id="二月分封从先入关之约转向将相军功"></a>

<a id="event-14"></a>

<a id="event-15"></a>

7. **项羽尊怀王为义帝，以军功重定诸王封国。** 楚怀王坚持依照先入关之约行事。项羽尊怀王为义帝，仍主张按灭秦军功重定诸王封国。二月，刘邦分得巴、蜀、汉中，都南郑，项羽以巴蜀也属关中说明此举。刘邦原把黄金百镒、珍珠二斗赐给张良，张良悉数赠项伯，刘邦也托项伯向项羽请求汉中，得到应许。三位秦降将分据关中，项羽自称西楚霸王，领九郡，都彭城。 [[7]](#note-14)

8. **十八王分别得到了什么。** 以下十八王不含项羽本人，也不含义帝。地区、都城以本纪为主，并补入月表所列的代、无终、即墨；《晋书》追叙司马卬本为赵将、随诸侯伐秦，秦亡后封殷王，以河内为其所都地区；《史记》具体记都朝歌。这些是古地名和分封安排，不扩成现代行政边界，也不表示三月所有人已实际抵达。 [[8]](#note-16)

    | 翟王董翳 | 上郡；高奴 | 本纪以劝章邯降楚解释受封 |
    | 西魏王魏豹 | 河东；平阳 | 旧魏王迁往河东 |
    | 河南王申阳 | 河南；洛阳 | 张耳所亲，先下河南、迎楚于河上 |
    | 韩王成 | 韩地；阳翟 | 暂保王号，后来未获准就国 |

    | 衡山王吴芮 | 衡山地区；邾 | 率百越助诸侯、随军入关 |
    | 临江王共敖 | 南郡；江陵 | 义帝柱国，攻南郡有功 |
    | 辽东王韩广 | 辽东；无终（月表所列） | 旧燕王被迁走 |
    | 燕王臧荼 | 燕地；蓟 | 随楚救赵、入关 |

    田荣因不肯从楚攻秦及与项梁的旧怨，没有获封；陈馀有名望，却因弃印、不从入关，只得三县。梅鋗获十万户侯，不是十八王之一。未获满意安置者仍有自己的兵力，新分封并未消除这些地方实力。

<a id="四月各自就国刘邦由杜南入汉中"></a>

<a id="event-17"></a>

9. **四月，刘邦率军由杜南入蚀中，沿路烧绝栈道。** 项羽给刘邦三万士卒，楚和其他诸侯中愿意跟随者还有数万。 队伍从杜南进入蚀中，沿路烧绝栈道，既防追兵，也表示暂时无意东出。张良离开刘邦前提出的建议，与这次迁行合在一处实行。 曹参由建成君再受汉王所封建成侯，随至汉中后升为将军。 张良送行到褒中，获准回韩国；烧道也用来表明没有返还意图、使项羽安心。 周勃在汉王分封后获威武侯爵，随入汉中任将军。 [[9]](#note-17)

<a id="event-18"></a>

10. **义帝被催迁长沙郴县，韩成甚至不能回自己的封国。** 义帝近臣逐渐离散；韩成到彭城，先降侯再被杀。项羽另立郑昌拒汉。义帝的最终遇害另见[前205年](bce-0205.md#sj007-yidi)，不让本段所有后果共用四月。 [[10]](#note-18)

<a id="event-19"></a>

11. **燕地，韩广不肯迁往辽东，臧荼攻杀他于无终。** 原来的燕王与新燕王，因分封直接发生冲突。 [[11]](#note-19)

<a id="田荣兼并三齐彭越也在梁地反楚"></a>

<a id="event-20"></a>

<a id="event-21"></a>

12. **田荣并三齐，授彭越将军印以抗楚。** 田荣逐田都、杀田市，兼并三齐。田都败逃楚；田市虽受田荣阻止，仍因害怕项羽而赴胶东，田荣追到即墨将其杀死，自立齐王。济北王田安随后也被杀，田荣兼并三齐。彭越得授将军印，随后击败项羽派来的萧公角等。陈馀也向齐求援，准备复赵，实际击败张耳、迎赵歇回来见[前205年](bce-0205.md#sj007-zhao)。 [[12]](#note-20)

## 刘邦自汉中东返，争取关中

<a id="萧何追回韩信汉军八月东返"></a>

<a id="event-22"></a>

13. **萧何追回韩信，刘邦拜韩信为大将。** 南郑军中思乡逃亡，韩信也曾离开，被萧何追回并强力推荐。 刘邦正式拜他为大将。韩信认为士卒多来自东方，应该趁他们急切思归时使用，不要等到所有人安居下来、失去再战之心；先争三秦，才有机会再争天下。 [[13]](#note-22)

<a id="event-23"></a>

14. **八月，从故道回师，汉军在陈仓、好畤击败章邯。** 章邯退废丘，汉定大部分雍地，进至咸阳，并遣将略定陇西、北地、上郡。司马欣、董翳相继归降，但废丘直到下一年才被攻下。 刘贾也在这一阶段担任将军、攻定塞地，本篇随后概括他随汉王东击项籍；这里不把后来东征的每一步都压到八月。 曹参先攻下辩、故道、雍、斄，在好畤南破章平军，围好畤、取壤乡，再破壤乡东、高栎的三秦军。章平脱围逃走，曹参续破赵贲、内史保，东取咸阳，改名新城；守景陵二十日时击退章平等来攻，受宁秦食邑，又领兵围章邯于废丘。 周勃随还定三秦，获怀德食邑；其功录列攻槐里、好畤，击赵贲、内史保于咸阳，北攻漆、击章平与姚卬，西定汧，再取郿、频阳、围废丘。前两项功次记最，各子战不因合读便全定在八月。 [[14]](#note-23)

<a id="event-24"></a>

15. **张良的信使项羽先注意齐、梁，而不是全力西攻汉王。** 信称刘邦只想取原约的关中，又告齐赵梁谋楚的消息。项羽准备北击齐，征黥布同行，黥布称病，只派几千人，项羽因此不满。 张良先告诉项羽汉王已经烧断栈道、没有回意，再以田荣反楚之书移其注意；韩王成因张良从汉而被扣留、不得归国，是这轮往来的背景。 [[15]](#note-24)

<a id="event-25"></a>

16. **九月，薛欧、王吸由武关方向去迎太公、吕后，没有成功。** 汉军想利用南阳一带兵力接应，楚军在阳夏阻挡，家属仍未接回。 [[16]](#note-25)

<a id="sj016-commandery"></a>

<a id="event-26"></a>

17. **关中降国的土地开始转作汉的郡，燕地则被臧荼合并。** 塞、翟两王归降后，渭南、河上、上郡的归属得到记录；韩广败亡以后，原来分给他的辽东也归入臧荼的燕国。名义改属与军队能控制每个地方，仍是不同层次的事。[原格与说明](#sj016-m09-note) [[17]](#note-26)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-27"></a>

18. **萧何担任汉王的丞相，留守汉中，办理军队后方的政务。** 刘邦本人向东争夺关中，萧何留收巴蜀物资，安抚百姓、宣达政令，使军粮不断供给。周苛担任御史大夫。 [[18]](#note-27)

**卷005互见：**[P071](../../拆分史书/史记/卷005.md#p071)。刘邦受降、项羽杀降是不同人的不同阶段。汉书P023—P033全部主要事件、原文入口和旧锚点继续保留，新卷互见没有替代掉既有叙事。

<a id="sj015-0207-forward"></a>
<a id="卷015末行的跨年承接子婴投降与项羽入关"></a>
#### 卷015末行的跨年承接｜子婴投降与项羽入关

[《六国年表》前207年末行](../../拆分史书/史记/卷015.md#y0207)将“诸侯入秦，婴降，为项羽所杀”接在二世之死、子婴杀赵高之后，是将秦亡的后续结局压缩到表末。本站仍以本页已有的汉元年年条安放子婴投降、项羽入关及杀子婴，不在前207年九月重复发生一遍。汉元年冬十月紧接二世三年九月，按通常公历子婴投降仍在前207年；放在前206年页是既有古历年条的编排，并不是让两事相隔整整一年。末尾“寻诛羽，天下属汉”还须续接[前202年](bce-0202.md#sj015-0207-forward)，不能把项羽的最终失败也提前到秦亡之际。

<a id="卷016逐月互见与取舍"></a>
### 卷016｜逐月互见与取舍

<a id="sj016-m10-note"></a>
<a id="十月汉元年起点与诸侯西行"></a>
#### 十月｜汉元年起点与诸侯西行

[本月原格](../../拆分史书/史记/卷016.md#m0206-10)汉栏秦王降、入咸阳、退霸上接本页开头；此时是沛公，不提前称皇帝。项栏四十余万西至河南、赵栏张耳随楚、魏栏魏豹随项羽入关，说明从军背景，接[分封表](#sj007-kings)各人的受封缘由。行军记数不与后来鸿门四十万相加；古年条与公历差别见[原有说明](#sj015-0207-forward)。

<a id="sj016-m11-note"></a>
<a id="十一月新安与约法"></a>
#### 十一月｜新安与约法

[本月原格](../../拆分史书/史记/卷016.md#m0206-11)项栏归[新安杀降](#sj007-xinan)，汉栏归本页约法。表二十万与本纪二十余万是同事记数，不是两次杀戮；“诈坑”不据字面重建全部执行程序。

<a id="sj016-m12-note"></a>
<a id="十二月鸿门焚秦与预述分国"></a>
#### 十二月｜鸿门、焚秦与预述分国

[本月原格](../../拆分史书/史记/卷016.md#m0206-12)汉栏相见戏下归[鸿门](#sj007-hongmen)，项栏诛子婴焚咸阳归[焚秦条](#sj005-existing-b37c34d7f1)。楚分四、赵代、齐三、关中四、燕辽东、魏殷、韩河南各格，前瞻[下一阶段分封](#sj007-kings)，不把所有王国又在十二月独立封立一遍。网页“有纳”疑字照存，不据之另造事件。

<a id="sj016-m01-note"></a>
<a id="正月义帝霸王与分国栏位"></a>
#### 正月｜义帝、霸王与分国栏位

[本月二十位置](../../拆分史书/史记/卷016.md#m0206-01)先列尊怀王为义帝、项羽自立西楚霸王，再展开各分国，合读[十八王表](#sj007-kings)。三家注网页义帝计月“九”与主见证“一”不同，另在[全卷说明](../../拆分史书/史记/卷016.md#kao-af57f6d27a)保留。二十位置包含义帝、项羽，不能把“十八王”改成二十个受封王。

<a id="sj016-m02-note"></a>
<a id="二月十八王与义帝迁郴"></a>
#### 二月｜十八王与义帝迁郴

[本月原格](../../拆分史书/史记/卷016.md#m0206-02)逐王对应[正文十八王表](#sj007-kings)：刘邦、章邯、司马欣、董翳、魏豹、申阳、韩成、司马卬、赵歇、张耳、黥布、吴芮、共敖、韩广、臧荼、田市、田都、田安。英布、黥布为同一人；“故楚将”“故韩将”是表的概括，韩成实际在前208已立，不从这句另造身份。表把义帝徙江南郴系二月，本纪接四月就国以后；正文只确认本年被催迁，死于下一古历年，不宣称具体动身月已定。

<a id="sj016-m03-note"></a>
<a id="三月都城不是全员到达日期"></a>
#### 三月｜都城不是全员到达日期

[本月十九个都城格](../../拆分史书/史记/卷016.md#m0206-03)归[分封表](#sj007-kings)，项羽彭城另见正文。代、无终、即墨为本轮据表补入的三处；其余彭城、邾、江陵、六、襄国、临淄、博阳、南郑、废丘、栎阳、高奴、蓟、平阳、朝歌、阳翟、洛阳都与既有叙事对应。这里保存所列政治驻地，不证明十九位国君同月同时到达；尤其韩成未获准就国，韩广又拒迁，不能由“都”字抹去后续冲突。

<a id="sj016-m04-note"></a>
<a id="四月罢兵就国"></a>
#### 四月｜罢兵就国

[本月项栏](../../拆分史书/史记/卷016.md#m0206-04)接本页四月就国与刘邦入汉中，不再另起第二次分封。韩成、义帝的后续及各地战争不能全部继承四月。

<a id="sj016-m05-note"></a>
<a id="五月田都败逃"></a>
#### 五月｜田都败逃

[本月齐栏](../../拆分史书/史记/卷016.md#m0206-05)田荣击都、都降楚，归本页三齐变局。仍采用败逃楚，不与另篇“杀田都”强拼为先死后逃；异文见上文“新安、田都及跨年材料”。

<a id="sj016-m06-note"></a>
<a id="六月田市被杀田荣称王"></a>
#### 六月｜田市被杀，田荣称王

[本月齐、胶东两格](../../拆分史书/史记/卷016.md#m0206-06)同属田荣追杀田市、自己称王的过程。田市是田儋之子，不能与田都、田安互换；原“故齐相”补明田荣原先不是这次分封的王。

<a id="sj016-m07-note"></a>
<a id="七月田安韩成的终局"></a>
#### 七月｜田安、韩成的终局

[本月原格](../../拆分史书/史记/卷016.md#m0206-07)济北田安被杀与胶东属齐，接三齐合并；韩栏项羽诛成，接本页韩成未获就国、废侯再杀。两位死者分属不同战争与政治处置，不能因同月并列就合成同场事件。

<a id="sj016-m08-note"></a>
<a id="八月三秦燕辽东与郑昌"></a>
#### 八月｜三秦、燕辽东与郑昌

[本月原格](../../拆分史书/史记/卷016.md#m0206-08)雍、塞、翟三栏分别为废丘仍守、司马欣与董翳归降，合入八月东返，不能把围城当已经攻克。济北属齐为田安败后的归属；辽东韩广无终败亡接本页燕事，韩栏郑昌新王接项羽另立拒汉。还定三秦的五月／八月差别继续见S5。

<a id="sj016-m09-note"></a>
<a id="九月降国改郡与辽东归燕"></a>
#### 九月｜降国改郡与辽东归燕

[本月原格](../../拆分史书/史记/卷016.md#m0206-09)塞栏渭南、河上，翟栏上郡及辽东属燕，补[本页归属变化](#sj016-commandery)。表是政治归属的简记，不足以复原现代地图上的每条边界；下一年略定陇西、北地及废丘终局仍分别保留。九月薛欧王吸迎家属为汉书补充，不伪填成本格已有原文。

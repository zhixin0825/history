# 公元前206年条｜鸿门宴后项羽分封十八王，刘邦从汉中东返

[← 公元前207年条](bce-0207.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前205年 →](bce-0205.md)

**汉元年；刘邦受封为汉王，尚未称帝**

> 本页按“汉元年＝前206年”的古史整年对应归档，不是公历一月至十二月的清单。开头冬十月秦降，按公历年界通常归前207年，紧接前页二世三年九月；其他古月也不直接换成同号公历月份。

[本年相关史料](#sources-start)

<a id="冬十月刘邦先到接受子婴投降"></a>

<a id="event-1"></a>

1. **冬十月，刘邦先到，接受子婴投降。** 刘邦到霸上，子婴在轵道旁交出秦的权柄。 子婴乘白马素车、以组系颈，献皇帝玺符节。有人主张杀他，刘邦认为杀已降者不祥，将他交给官吏看管，没有当场处死。 [[1]](#note-1)

<a id="event-2"></a>

2. **刘邦进入咸阳，又在樊哙、张良劝告下退回霸上。** 他本被宫室、珍宝和妇女吸引，后来封存府库，没有长住秦宫。萧何则收取秦的图籍文书，为以后了解地形、人口和政务保存材料。 [[2]](#note-2)

<a id="event-3"></a>

3. **十一月，刘邦召父老宣布约法三章，又让人与秦吏同行告谕县乡。** 杀人者死、伤人及盗抵罪，其余秦法废除，吏民各安原处。他声称前来除害，不是侵暴；秦人送牛羊酒食，他又以仓粮尚足、不愿劳费百姓为由推让。 [[3]](#note-3)

<a id="sj007-xinan"></a>
<a id="项羽入关途中在新安杀掉大批秦降卒"></a>

<a id="event-4"></a>

4. **秦降卒遭诸侯军轻辱，不满消息传到项羽处。** 诸侯吏卒曾在秦受辱，如今反过来奴役、轻辱降卒。 降卒私下担心，如果不能入关、却被带到东方，留在秦地的父母妻子可能遭报复。这种不满又被报告给项羽。 [[4]](#note-4)

<a id="event-5"></a>

5. **项羽与黥布、蒲将军商议，决定杀普通降卒，只带三位将领继续入秦。** 楚军夜袭新安城南，杀降卒二十余万，章邯、司马欣、董翳得以保全。前一年的降约，没有给普通士兵带来同样的安全。 [[5]](#note-5)

<a id="函谷关被关闭曹无伤又送来告密"></a>

<a id="event-6"></a>

6. **函谷关被关闭，曹无伤又送来告密。** 刘邦听从守关建议，想靠关中财富、险固和增兵挡住诸侯。 项羽得知关门不开，大怒，命当阳君等破关，进到戏西。曹无伤又向项羽指控刘邦想王关中、任子婴为相、独占珍宝，自己则想从中求封。 [[6]](#note-6)

<a id="event-7"></a>

7. **范增劝项羽趁早击败刘邦。** 他认为刘邦入关不急取财色，显示志向更大，又用望气说加强判断。书中记项羽兵四十万、刘邦十万，号称则分别达百万、二十万；刘邦自己也承认不能正面相敌。 [[7]](#note-7)

<a id="项伯原想救张良却给刘邦带来转机"></a>

<a id="event-8"></a>

8. **项伯夜访张良，张良向刘邦转告消息。** 项伯夜到汉营，想叫张良一同离开。 项伯秦时杀过人，曾获张良帮助，因旧恩来报消息。张良不肯抛弃刘邦，先向他报告，刘邦便请项伯见面。 [[8]](#note-8)

<a id="event-9"></a>

9. **刘邦敬酒，约为婚姻，解释守关只是防盗防变。** 他声称封府库、登记吏民都是在等项羽。项伯答应代言，要求次日亲来谢罪；回到楚营，又以刘邦先破秦有功劝项羽善待，项羽同意接见。 [[9]](#note-9)

<a id="sj007-hongmen"></a>
<a id="鸿门宴舞剑闯帐与脱身"></a>

<a id="event-10"></a>

10. **鸿门宴中，项庄舞剑，项伯遮护刘邦。** 刘邦带百余骑前来，项羽直接说出告密者是曹无伤。 宴中项羽、项伯向东坐，范增向南，刘邦向北，张良面向西陪侍。范增反复示意动手，项羽不回应；他转让项庄舞剑谋杀，项伯也起身舞剑、用身体遮护。 [[10]](#note-10)

<a id="event-11"></a>

11. **张良出帐叫樊哙，樊哙持盾闯入。** 项羽问明身份，赐酒和彘肩，樊哙当场饮食，又援引先入关之约，责问为何功臣未赏、反听小人之言要杀他。项羽让他坐下，刘邦过后借如厕离席，叫樊哙同行。 [[11]](#note-11)

<a id="event-12"></a>

12. **刘邦没有回来辞行，张良留下送礼。** 楚都尉陈平奉命来召，樊哙劝刘邦不要再拘礼节。刘邦弃车队，自己骑马，与樊哙、夏侯婴、靳彊、纪信等经骊山、芷阳间道回军；张良估计他已安全抵达，才献白璧、玉斗。项羽收下，范增拔剑击碎玉斗。刘邦回营便杀曹无伤。 [[12]](#note-12)

<a id="sj005-existing-b37c34d7f1"></a>
<a id="咸阳遭到焚掠项羽却想回东方"></a>

<a id="event-13"></a>

13. **咸阳遭到焚掠，项羽却想回东方。** 项羽西进，杀子婴、烧秦宫室，掠取财物和妇女。 子婴已经降汉，这不是再战被俘。有人劝项羽留关中，用山河土地成霸业，他却见宫殿已毁、又想回乡显贵，没有接受；说者讥楚人沐猴而冠，被烹杀。秦人失望，却不敢不服。 [[13]](#note-13)

<a id="二月分封从先入关之约转向将相军功"></a>

<a id="event-14"></a>

14. **项羽尊怀王为义帝，主张按军功重新分封。** 楚怀王坚持“如约”，项羽却只给他义帝尊号，不听其命。 项羽强调灭秦的功劳来自自己和诸将，旧王只是起兵时借用的名号，因此要按从军、军功和关系重分天下，把不少旧王迁走。 [[14]](#note-14)

<a id="event-15"></a>

15. **二月，刘邦分得巴、蜀、汉中，三位秦降将分据关中。** 刘邦拿到巴、蜀、汉中，三位秦降将反而分据关中。 项羽以巴蜀也属于关中解释这一安排，使刘邦都南郑；自己称西楚霸王，王九郡、都彭城。 [[15]](#note-15)

<a id="sj007-kings"></a>
<a id="十八王分别得到了什么"></a>


<a id="event-16"></a>

16. **十八王分别得到了什么。** 以下十八王不含项羽本人，也不含义帝。地区、都城以本纪为主，并补入月表所列的代、无终、即墨；这些是古地名和分封安排，不扩成现代行政边界，也不表示三月所有人已实际抵达。 [[16]](#note-16)

    | 王号、人物 | 地区、都城 | 安排的关键 |
    |---|---|---|
    | 汉王刘邦 | 巴、蜀、汉中；南郑 | 先入关却未获关中，汉书计四十一县 |
    | 雍王章邯 | 咸阳以西；废丘 | 降约中已先许雍王名号 |
    | 塞王司马欣 | 咸阳以东至河；栎阳 | 曾帮助项梁，后带秦降军 |
    | 翟王董翳 | 上郡；高奴 | 本纪以劝章邯降楚解释受封 |
    | 西魏王魏豹 | 河东；平阳 | 旧魏王迁往河东 |
    | 河南王申阳 | 河南；洛阳 | 张耳所亲，先下河南、迎楚于河上 |
    | 韩王成 | 韩地；阳翟 | 暂保王号，后来未获准就国 |
    | 殷王司马卬 | 河内；朝歌 | 赵将，取得河内有功 |
    | 代王赵歇 | 代地；代（月表所列） | 旧赵王被迁走 |
    | 常山王张耳 | 赵地；襄国 | 有声望、随军入关，占原赵中心区域 |
    | 九江王黥布 | 九江地区；六 | 原当阳君，楚军作战突出 |
    | 衡山王吴芮 | 衡山地区；邾 | 率百越助诸侯、随军入关 |
    | 临江王共敖 | 南郡；江陵 | 义帝柱国，攻南郡有功 |
    | 辽东王韩广 | 辽东；无终（月表所列） | 旧燕王被迁走 |
    | 燕王臧荼 | 燕地；蓟 | 随楚救赵、入关 |
    | 胶东王田市 | 胶东；即墨（月表所列） | 旧齐王被迁走 |
    | 齐王田都 | 齐地；临淄 | 随楚救赵、入关 |
    | 济北王田安 | 济北；博阳 | 齐王建之孙，得数城后归项羽 |

    田荣因不肯从楚攻秦及与项梁的旧怨，没有获封；陈馀有名望，却因弃印、不从入关，只得三县。梅鋗获十万户侯，不是十八王之一。未获满意安置者仍有自己的兵力，新分封并未消除这些地方实力。

<a id="四月各自就国刘邦由杜南入汉中"></a>

<a id="event-17"></a>

17. **四月，刘邦率军由杜南入蚀中，沿路烧绝栈道。** 项羽给刘邦三万士卒，楚和其他诸侯中愿意跟随者还有数万。 队伍从杜南进入蚀中，沿路烧绝栈道，既防追兵，也表示暂时无意东出。张良离开刘邦前提出的建议，与这次迁行合在一处实行。 [[17]](#note-17)

<a id="event-18"></a>

18. **义帝被催迁长沙郴县，韩成甚至不能回自己的封国。** 义帝近臣逐渐离散；韩成到彭城，先降侯再被杀。项羽另立郑昌拒汉。义帝的最终遇害另见[前205年](bce-0205.md#sj007-yidi)，不让本段所有后果共用四月。 [[18]](#note-18)

<a id="event-19"></a>

19. **燕地，韩广不肯迁往辽东，臧荼攻杀他于无终。** 原来的燕王与新燕王，因分封直接发生冲突。 [[19]](#note-19)

<a id="田荣兼并三齐彭越也在梁地反楚"></a>

<a id="event-20"></a>

20. **田荣赶走田都，又追杀田市、田安。** 田都败逃楚；田市虽受田荣阻止，仍因害怕项羽而赴胶东，田荣追到即墨将其杀死，自立齐王，再杀济北王田安，兼并三齐。 [[20]](#note-20)

<a id="event-21"></a>

21. **田荣给彭越将军印，彭越击败项羽派来的萧公角等。** 陈馀也向齐求援，准备复赵，实际击败张耳、迎赵歇回来见[前205年](bce-0205.md#sj007-zhao)。 [[21]](#note-21)

<a id="萧何追回韩信汉军八月东返"></a>

<a id="event-22"></a>

22. **萧何追回韩信，刘邦拜韩信为大将。** 南郑军中思乡逃亡，韩信也曾离开，被萧何追回并强力推荐。 刘邦正式拜他为大将。韩信认为士卒多来自东方，应该趁他们急切思归时使用，不要等到所有人安居下来、失去再战之心；先争三秦，才有机会再争天下。 [[22]](#note-22)

<a id="event-23"></a>

23. **八月，从故道回师，汉军在陈仓、好畤击败章邯。** 章邯退废丘，汉定大部分雍地，进至咸阳，并遣将略定陇西、北地、上郡。司马欣、董翳相继归降，但废丘直到下一年才被攻下。 [[23]](#note-23)

<a id="event-24"></a>

24. **张良的信使项羽先注意齐、梁，而不是全力西攻汉王。** 信称刘邦只想取原约的关中，又告齐赵梁谋楚的消息。项羽准备北击齐，征黥布同行，黥布称病，只派几千人，项羽因此不满。 [[24]](#note-24)

<a id="event-25"></a>

25. **九月，薛欧、王吸由武关方向去迎太公、吕后，没有成功。** 汉军想利用南阳一带兵力接应，楚军在阳夏阻挡，家属仍未接回。 [[25]](#note-25)

<a id="sj016-commandery"></a>

<a id="event-26"></a>

26. **关中降国的土地开始转作汉的郡，燕地则被臧荼合并。** 塞、翟两王归降后，渭南、河上、上郡的归属得到记录；韩广败亡以后，原来分给他的辽东也归入臧荼的燕国。名义改属与军队能控制每个地方，仍是不同层次的事。[原格与说明](#sj016-m09-note) [[26]](#note-26)

<a id="sj022"></a>
<a id="朝廷人事与本年补记"></a>

<a id="event-27"></a>

27. **萧何担任汉王的丞相，留守汉中，办理军队后方的政务。** 刘邦本人向东争夺关中，后方的粮饷与行政由留守官员维持。周苛担任御史大夫。 [原格与说明](#sj022-note)。 [[27]](#note-27)

### 1. 刘邦到霸上，子婴在轵道旁交出秦的权柄

[返回正文第1条](#event-1)

**[《汉书》P023](../../sources/摘录/汉书-高帝纪.md#p023)**

> 元年冬十月，五星聚于東井。沛公至霸上。秦王子嬰素車白馬，係頸以組，封皇帝璽符節，降枳道旁。諸 將或言誅秦王，沛公曰：「始懷王遣我，固以能寬容，且人已服降，殺之不祥。」乃以屬吏。遂西入咸陽，欲止宮休舍，樊噲、張良諫，乃封秦重寶財物府庫，還軍 霸上。蕭何盡收秦丞相府圖籍文書。十一月，召諸縣豪桀曰：「父老苦秦苛法久矣，誹謗者族，耦語者棄市。吾與諸侯約，先入關者王之，吾當王關中。與父老約， 法三章耳：殺人者死，傷人及盜抵罪。餘悉除去秦法。吏民皆按堵如故。凡吾所以來，為父兄除害，非有所侵暴，毋恐！且吾所以軍霸上，待諸侯至而定要束耳。」 乃使人與秦吏行至縣鄉邑告諭之。秦民大喜，爭持牛羊酒食獻享軍士。沛公讓不受，曰：「倉粟多，不欲費民。」民又益喜，唯恐沛公不為秦王。

**[卷006 P065](../../sources/摘录/史记-卷006-秦始皇本纪.md#p065)**

> 子嬰為秦王四十六日，楚將沛公破秦軍入武關，遂至霸上，使人約降子嬰。子嬰即系頸以組，白馬素車，奉天子璽符，降軹道旁。沛公遂入咸陽，封宮室府庫，還軍霸上。

**[卷008 P016](../../sources/摘录/史记-卷008-高祖本纪.md#p016)**

#### S1｜秦降与约法

[《汉书》P023](../../sources/摘录/汉书-高帝纪.md#p023) · [卷008 P016](../../sources/摘录/史记-卷008-高祖本纪.md#p016)。古书记五星聚东井，按天象层保留，不作刘邦受天命的证明。受降十月、约法十一月据《通鉴》分开；宣布除秦法不等于一切秦行政实践当天消失。与秦吏共同告谕、拒受馈食是本卷补入的具体做法。

《天官书》[P120](../../sources/摘录/史记-卷027-天官书.md#p120)只说“漢之興，五星聚于東井”；《汉书·天文志》明确系于“漢元年十月”（[互校H003](../../sources/摘录/史记-卷027-纪年互校.md#h003)）。本页按汉元年古史年条收这一传统说法，不能改成刘邦前202年称帝时的新天象，也不能把本页标题直接换算成公历前206年十月。这里的“聚”是否相当于现代所谓五星严格合聚、记录年代是否与实算相符，均未做独立天文学复核；“受命之符”不进入事实判断。

同卷[P119](../../sources/摘录/史记-卷027-天官书.md#p119)的“西坑秦人，誅屠咸陽”与本页新安、咸阳两段合一；枉矢记录仍在[前207年巨鹿注](bce-0207.md#sj007-julu-note)，不随压缩叙述移到本年。

#### 三月｜都城不是全员到达日期

[本月十九个都城格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0206-03)归[分封表](#sj007-kings)，项羽彭城另见正文。代、无终、即墨为本轮据表补入的三处；其余彭城、邾、江陵、六、襄国、临淄、博阳、南郑、废丘、栎阳、高奴、蓟、平阳、朝歌、阳翟、洛阳都与既有叙事对应。这里保存所列政治驻地，不证明十九位国君同月同时到达；尤其韩成未获准就国，韩广又拒迁，不能由“都”字抹去后续冲突。

<a id="sj016-m04-note"></a>
<a id="四月罢兵就国"></a>
#### 四月｜罢兵就国

[本月项栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0206-04)接本页四月就国与刘邦入汉中，不再另起第二次分封。韩成、义帝的后续及各地战争不能全部继承四月。

<a id="sj016-m05-note"></a>
<a id="五月田都败逃"></a>
#### 五月｜田都败逃

[本月齐栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0206-05)田荣击都、都降楚，归本页三齐变局。仍采用败逃楚，不与另篇“杀田都”强拼为先死后逃；异文见上文“新安、田都及跨年材料”。

<a id="sj016-m06-note"></a>
<a id="六月田市被杀田荣称王"></a>
#### 六月｜田市被杀，田荣称王

[本月齐、胶东两格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0206-06)同属田荣追杀田市、自己称王的过程。田市是田儋之子，不能与田都、田安互换；原“故齐相”补明田荣原先不是这次分封的王。

<a id="sj016-m07-note"></a>
<a id="七月田安韩成的终局"></a>
#### 七月｜田安、韩成的终局

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0206-07)济北田安被杀与胶东属齐，接三齐合并；韩栏项羽诛成，接本页韩成未获就国、废侯再杀。两位死者分属不同战争与政治处置，不能因同月并列就合成同场事件。

<a id="sj016-m08-note"></a>
<a id="八月三秦燕辽东与郑昌"></a>
#### 八月｜三秦、燕辽东与郑昌

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0206-08)雍、塞、翟三栏分别为废丘仍守、司马欣与董翳归降，合入八月东返，不能把围城当已经攻克。济北属齐为田安败后的归属；辽东韩广无终败亡接本页燕事，韩栏郑昌新王接项羽另立拒汉。还定三秦的五月／八月差别继续见S5。

<a id="sj016-m09-note"></a>
<a id="九月降国改郡与辽东归燕"></a>
#### 九月｜降国改郡与辽东归燕

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0206-09)塞栏渭南、河上，翟栏上郡及辽东属燕，补[本页归属变化](#sj016-commandery)。表是政治归属的简记，不足以复原现代地图上的每条边界；下一年略定陇西、北地及废丘终局仍分别保留。九月薛欧王吸迎家属为汉书补充，不伪填成本格已有原文。

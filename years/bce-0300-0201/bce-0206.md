# 公元前206年条｜鸿门宴后项羽分封十八王，刘邦从汉中东返

[← 公元前207年条](bce-0207.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前205年 →](bce-0205.md)

**汉元年；刘邦受封为汉王，尚未称帝**

> 本页以“汉元年＝前206年”的古史整年对应归档，不是公历一月至十二月的清单。开头冬十月秦降，按公历年界通常归前207年；它紧接前页二世三年九月，不是再等一个公历年。其他古月也不直接换成同号公历月份。

## 冬十月，刘邦先到，接受子婴投降

**子婴在轵道旁交出秦的权柄。** 刘邦到霸上，子婴乘白马素车、以组系颈，交出皇帝玺、符、节。诸将有人主张杀他，刘邦认为杀降不祥，将其交吏看管，没有当场处死。[《汉书》P023](../../sources/摘录/汉书-高帝纪.md#p023) · [卷006 P065](../../sources/摘录/史记-卷006-秦始皇本纪.md#p065)。

**进咸阳以后，刘邦又退回霸上。** 他一度被宫室、珍宝、妇女吸引，樊哙、张良劝他不要留恋秦宫。刘邦封存府库后退军；萧何则收取秦的图籍文书，为以后了解地形、人口和政务留下资料。[《汉书》P023](../../sources/摘录/汉书-高帝纪.md#p023)。

**十一月，刘邦召父老，宣布约法三章。** 杀人者死，伤人及盗窃依法抵罪，其余秦法废除，官吏百姓各安原处。他把入关说成除害而非侵暴，又拒绝额外耗费百姓财物。这是在争取关中支持，不表示一切秦行政实践立即消失。[《汉书》P023](../../sources/摘录/汉书-高帝纪.md#p023) · [《通鉴》卷九](https://zh.wikisource.org/wiki/資治通鑑/卷009)。

## 项羽入关途中，在新安杀掉大批秦降卒

**秦军投降后，没有得到安全、平等的待遇。** 诸侯军中有些人曾到秦地服役、遭秦吏卒轻辱，如今趁胜反过来奴役、侮辱秦降卒。降卒私下议论：如果不能打进关中，又被带往东方，留在秦地的父母妻子怎么办？[卷007 P015](../../sources/摘录/史记-卷007-项羽本纪.md#p015)。

**项羽把这种不满看成危险，决定先下手。** 他与黥布、蒲将军商议，只带章邯、司马欣、董翳继续入秦，把普通降卒杀掉。楚军夜间在新安城南袭杀降卒，书中记人数为二十余万。前一页的受降，并没有保证普通士卒最后能活着回乡。[卷007 P015](../../sources/摘录/史记-卷007-项羽本纪.md#p015)。

## 十二月，函谷关被关闭，楚汉几乎立即开战

**刘邦想守住关中，项羽不肯被挡在关外。** 有人劝刘邦守函谷关、不纳诸侯军，刘邦采纳。项羽得知秦地已被刘邦控制，大怒，命当阳君等破关，进至戏西。刘邦的左司马曹无伤又向项羽告密，指控刘邦想做关中王、任子婴为相并独占珍宝。[《汉书》P024](../../sources/摘录/汉书-高帝纪.md#p024) · [卷007 P016](../../sources/摘录/史记-卷007-项羽本纪.md#p016)。

**范增劝项羽赶紧攻刘邦。** 他认为刘邦入关后一反往常，不急取财色，说明志向更大。此时所报项羽军四十万、刘邦军十万，刘邦也承认自己不足以正面对抗。范增还用望气说来加强劝说，但那是他的论据，不是天命已获证明。[卷007 P016—P017](../../sources/摘录/史记-卷007-项羽本纪.md#p016)。

## 项伯夜里救张良，却也给刘邦带来转机

**项伯原本只想让老朋友张良避祸。** 项伯是项羽的叔父，任楚左尹；秦时他杀人，张良曾救过他，所以连夜赶到汉营相告，想叫张良一同走。张良不肯丢下刘邦，先把事情报告给他。[卷007 P017](../../sources/摘录/史记-卷007-项羽本纪.md#p017)。

**刘邦请项伯入见，敬酒、约为婚姻，并解释自己没有背叛。** 他声称守关只是防盗、防变，封府库、登记吏民都是在等项羽。项伯答应转告，但要他次日亲自来谢罪；回营后，又劝项羽不要攻击先破秦、有大功的人。项羽同意接见。[卷007 P017](../../sources/摘录/史记-卷007-项羽本纪.md#p017)。

<a id="sj007-hongmen"></a>
## 鸿门宴：劝杀、舞剑、闯帐和脱身

**刘邦带百余骑赴宴，项羽当面说出了告密者曹无伤。** 项羽留他饮酒，项羽、项伯向东坐，范增向南，刘邦向北，张良在西侧陪侍。范增多次示意项羽动手，项羽不回应，他便让项庄借舞剑杀刘邦；项伯也起身舞剑，用身体遮护，使项庄找不到下手机会。[《汉书》P025](../../sources/摘录/汉书-高帝纪.md#p025) · [卷007 P018](../../sources/摘录/史记-卷007-项羽本纪.md#p018)。

**张良出帐找樊哙，樊哙持盾撞开卫士闯入。** 项羽问明身份后赐酒、赐彘肩，樊哙当场饮酒食肉，又以先入关之约和刘邦功劳劝说：功臣没有获赏，反因小人之言被杀，岂不是重走秦亡的老路？项羽让他坐下。过了一会儿，刘邦借如厕离席，叫樊哙同行。[卷007 P018](../../sources/摘录/史记-卷007-项羽本纪.md#p018)。

**刘邦没有再回席，张良留下送礼。** 楚都尉陈平奉命来召，樊哙劝刘邦不要再拘泥辞行礼节。刘邦弃下车队，自己骑马，与樊哙、夏侯婴、靳彊、纪信等由骊山、芷阳间道回军。张良估他已到，才向项羽献白璧、向范增献玉斗；项羽收下，范增却拔剑击碎玉斗。刘邦回营，立即杀了曹无伤。[卷007 P019](../../sources/摘录/史记-卷007-项羽本纪.md#p019)。

<a id="sj005-existing-b37c34d7f1"></a>
## 咸阳被焚，项羽仍想回东方

**几日后，项羽西进咸阳，杀子婴，烧秦宫室，掠取财物和妇女。** 子婴此前已降刘邦，这不是另一次交战中被俘。有人劝项羽留关中，利用山河险固、土地肥饶成就霸业；项羽见宫殿已毁，又想回乡显贵，没有接受。说者随后讥笑楚人“沐猴而冠”，被项羽烹杀。[《汉书》P026](../../sources/摘录/汉书-高帝纪.md#p026) · [卷006 P066](../../sources/摘录/史记-卷006-秦始皇本纪.md#p066) · [卷007 P020](../../sources/摘录/史记-卷007-项羽本纪.md#p020)。

## 二月，分封的依据从先入关变成从军功劳

**楚怀王只回答“如约”，项羽却另作安排。** 项羽尊怀王为义帝，随后对将相说，三年披坚执锐、灭秦定天下的是各位将相和自己的功劳，旧王只是起兵时暂借名号。因此，他把随军将领的战功和关系放在分封中心，迁走不少旧王。[卷007 P021](../../sources/摘录/史记-卷007-项羽本纪.md#p021)。

**刘邦得到巴、蜀、汉中，关中反而给了三位秦降将。** 项羽以巴蜀也属关中为解释，让刘邦为汉王、都南郑；章邯、司马欣、董翳分据三秦，挡住汉王向东的通道。自己则为西楚霸王，统九郡，都彭城。[《汉书》P027](../../sources/摘录/汉书-高帝纪.md#p027) · [卷007 P021](../../sources/摘录/史记-卷007-项羽本纪.md#p021)。

### 十八王分别得到了什么

以下十八王不包含项羽本人，也不包含只有尊号而未主持分封的义帝。地区和都城依本纪所列古名，不擅补现代行政边界。[卷007 P021](../../sources/摘录/史记-卷007-项羽本纪.md#p021)。

| 王号、人物 | 所得地区、都城 | 这次安排的关键 |
|---|---|---|
| 汉王刘邦 | 巴、蜀、汉中；南郑 | 先入关却未获关中，汉书计四十一县 |
| 雍王章邯 | 咸阳以西；废丘 | 秦降将；受降时已先许雍王名号 |
| 塞王司马欣 | 咸阳以东至河；栎阳 | 曾帮助项梁，后率秦降军 |
| 翟王董翳 | 上郡；高奴 | 本纪以劝章邯降楚说明其受封 |
| 西魏王魏豹 | 河东；平阳 | 旧魏王被迁至河东 |
| 河南王申阳 | 河南；洛阳 | 张耳所亲，先下河南、迎楚于河上 |
| 韩王成 | 原韩地；阳翟 | 保留旧王，但随后未获准就国 |
| 殷王司马卬 | 河内；朝歌 | 赵将，取河内有功 |
| 代王赵歇 | 代地；本段未明记都城 | 旧赵王被迁走 |
| 常山王张耳 | 赵地；襄国 | 有名望且随军入关，占据原赵王中心区域 |
| 九江王黥布 | 九江地区；六 | 当阳君，楚军中作战突出 |
| 衡山王吴芮 | 衡山地区；邾 | 率百越助诸侯，并随军入关 |
| 临江王共敖 | 南郡；江陵 | 义帝柱国，攻南郡有功 |
| 辽东王韩广 | 辽东；本段未明记都城 | 旧燕王被迁走 |
| 燕王臧荼 | 燕地；蓟 | 随楚救赵，又从入关 |
| 胶东王田市 | 胶东；本段未明记都城 | 旧齐王被迁走 |
| 齐王田都 | 齐地；临淄 | 随军救赵、入关 |

**未被满意安置的人，也有自己的军队。** 田荣因不肯随楚攻秦，又与项梁有矛盾，没有获封；陈馀虽有名望和赵地功劳，因弃印、不从入关，只得到三县。梅鋗因功获十万户侯，不是十八王之一。新的分封并未消除各地实力，只是重新安排了名号和土地。[卷007 P021](../../sources/摘录/史记-卷007-项羽本纪.md#p021)。

## 四月，各自就国，旧主的处境迅速恶化

**刘邦进入汉中，临行烧断栈道。** 张良离开前建议这样做，既防追兵，也让项羽以为汉王暂时无意东出。[《汉书》P028](../../sources/摘录/汉书-高帝纪.md#p028)。

**义帝被催着迁往长沙郴县，韩成则连就国机会也没有。** 项羽以古帝宜居上游为理由迁走义帝，其近臣逐渐离散。韩成被带到彭城，先废为侯，后来被杀；项羽另立郑昌为韩王，阻挡汉军。义帝迁走与后来遇害不是同一件事，最终杀害另接[汉二年冬十月](bce-0205.md#sj007-yidi)。[卷007 P022、P024](../../sources/摘录/史记-卷007-项羽本纪.md#p022)。

**臧荼夺取燕国，韩广不肯迁走，被杀在无终。** 藏在分封中的旧王、新王冲突，在燕地很快变成战争。[卷007 P022](../../sources/摘录/史记-卷007-项羽本纪.md#p022)。

## 齐地不接受三分，田荣重新把它打成一块

**田荣先赶走田都，又杀田市、田安。** 他拒绝让原齐王田市迁胶东，出兵击败田都，田都逃楚；田市害怕项羽，仍到胶东就国，田荣追到即墨将其杀死，随后自立齐王，再杀济北王田安，兼并三齐。[卷007 P023](../../sources/摘录/史记-卷007-项羽本纪.md#p023)。

**田荣还给彭越将军印，让他在梁地反楚。** 项羽派萧公角等进攻，却被彭越击败。陈馀也向齐求兵，准备夺回赵地；这条线的成事阶段见[下一年](bce-0205.md#sj007-zhao)，不因与齐乱写在同段便全归本年。[卷007 P023—P024](../../sources/摘录/史记-卷007-项羽本纪.md#p023)。

## 萧何追回韩信，刘邦出兵争三秦

**汉军思乡、逃亡不断，韩信也离开了。** 萧何亲自追赶并力荐，刘邦才正式拜他为大将。韩信主张利用士卒想回东方的愿望，先取三秦，再争天下。[《汉书》P029](../../sources/摘录/汉书-高帝纪.md#p029)。

**八月，汉军从故道回师，在陈仓、好畤等地击败雍军。** 章邯退守废丘，汉控制大部分雍地；司马欣、董翳后来相继降汉，但废丘未在本阶段攻下。这里的八月采用《通鉴》的编年，旧页所据汉书五月异说仍保留在下方。[《汉书》P030—P031](../../sources/摘录/汉书-高帝纪.md#p030) · [《通鉴》卷九](https://zh.wikisource.org/wiki/資治通鑑/卷009)。

**张良用信使项羽暂时把注意力转向齐、梁。** 他称刘邦只想取得原约的关中，不敢东进，又把齐、梁反楚及齐赵联合的消息转告项羽。项羽于是先准备北击齐，征黥布同行；黥布称病，只派部将带数千人，项羽因此怨恨他。[卷007 P024](../../sources/摘录/史记-卷007-项羽本纪.md#p024) · [《汉书》P032](../../sources/摘录/汉书-高帝纪.md#p032)。

**九月，薛欧、王吸受命从武关方向迎接刘邦家属，被楚军阻挡。** 太公、吕后没有顺利接回。[《汉书》P033](../../sources/摘录/汉书-高帝纪.md#p033)。

秦虽然灭亡，新的封国格局却已开始瓦解。下一年楚汉主力将在彭城直接交锋，而非分封后马上天下太平。

## 原文与出处

### S1｜秦降与约法

> 元年冬十月，五星聚于東井。沛公至霸上。秦王子嬰素車白馬，係頸以組，封皇帝璽符節，降軹道旁。

> 殺人者死，傷人及盜抵罪，餘悉除去秦法。

[《汉书》P023](../../sources/摘录/汉书-高帝纪.md#p023)。五星聚井按天象记载，不作为刘邦受天命的证明。正文把受降、退军和十一月约法分阶段，《通鉴》补出十一月，旧汉书材料仍在。

### S2｜鸿门的多书互见

[《汉书》P024—P025](../../sources/摘录/汉书-高帝纪.md#p024) · [卷007 P016—P019](../../sources/摘录/史记-卷007-项羽本纪.md#p016)。本轮从原有宴席骨架补入前夜接洽、项伯旧恩、席位、樊哙劝说、陈平传命、献礼和曹无伤结局。曹无伤说子婴为相是指控，不据此另造任相事件；婚约不等于已完婚；陈平此时仍为楚官。对白与四十万、十万兵数均按传世文本归属，不当作现代录音或点名册。所据卷007网页作“玉珪”，不隐去与通行“玉玦”的差别。

### S3｜十八王与实际控制

[卷007 P021—P024](../../sources/摘录/史记-卷007-项羽本纪.md#p021) · [《汉书》P027](../../sources/摘录/汉书-高帝纪.md#p027)。十八王与项羽分列，义帝尊号另列，陈馀三县、梅鋗侯爵不能混入王数。受封、获准就国、实际占领三者不同；古地区不直接套现代省界。各人获封的“因为”是本纪提供的政治解释，不证明背后只有这一种原因。

### S4｜萧何荐韩信

[《汉书》P029](../../sources/摘录/汉书-高帝纪.md#p029)。原有逃亡、追赶、推荐、拜大将四环节保留，不把后来齐王、楚王、淮阴侯的身份提前安在此时。

### S5｜还定三秦：本轮明确调整正文月次

旧页依[《汉书》P030](../../sources/摘录/汉书-高帝纪.md#p030)写五月；[《高祖本纪》](https://zh.wikisource.org/wiki/史記/卷008)及[《通鉴》卷九](https://zh.wikisource.org/wiki/資治通鑑/卷009)编八月。本轮为连接楚汉双方的同年顺序，正文采用《通鉴》八月，同时保留旧据，不把变更伪装成三书一致，也不在五月、八月各造一次回师。

### 卷007｜新安与跨年材料

[P015](../../sources/摘录/史记-卷007-项羽本纪.md#p015)与《通鉴》汉元年冬段合读，放在约法、进关的阶段，不沿章邯降约的上一年。二十余万为文本数量；“夜击坑”不扩写成已经复原的全部活埋程序。普通降卒被杀与三将保全是同一决定的两面。

[P022—P024](../../sources/摘录/史记-卷007-项羽本纪.md#p022)跨年回叙，义帝死、陈馀复赵及项羽杀田荣均由《通鉴》归汉二年，详见[本卷考证](../../meta/考证/史记-卷007-纪年与异说.md#跨年)。

## 卷006与卷005原有互见

<a id="sj006-065-note"></a>
**子婴在位数：**[卷006 P065](../../sources/摘录/史记-卷006-秦始皇本纪.md#p065)四十六日，与《李斯列传》三个月不直接相加。古历年界差别见[秦历与年页](../../meta/考证/史记-卷006-纪年与异说.md#秦历与年页)。

<a id="sj006-066-note"></a>
**烧的是秦宫室，不能擅改成已确认烧阿房宫：**[卷006 P066](../../sources/摘录/史记-卷006-秦始皇本纪.md#p066)与卷007同事；阿房未成、相关考古认识见[西安市文物局所载材料](https://wwj.xa.gov.cn/xwzx/wbzx/2005535230505029634.html)。本纪“火三月不灭”是史书记数；“后五年天下定于汉”接[前202年](bce-0202.md)，中间过程现在由前205—203年接读，仍不等于相关各卷已全部校完。

<a id="sj005-286-note"></a>
**旧卷005互见继续保留：**[P071](../../sources/摘录/史记-卷005-秦本纪.md#p071)。刘邦受降和项羽杀降不是同一行为。旧汉书P023—P033的各阶段及原文入口均继续保留，新增项羽材料并不覆盖刘邦线。

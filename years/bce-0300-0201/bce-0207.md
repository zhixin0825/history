> “汉元年冬十月”归在[前206年页](bce-0206.md)，紧接二世三年九月，不是又等一个公历年。子婴投降按公历年界通常归前207年，新安杀降亦按汉元年年条置于后一页。

## 本年概述

章邯攻赵，诸侯会兵巨鹿。项羽杀宋义接掌楚军，渡河解围，随后与章邯订降约。刘邦另由南阳向西取武关，进击蓝田。赵高逼死秦二世，子婴继位后诛赵高，秦亡在即。

2. **项羽杀宋义，接领救赵军。** 救赵军停在安阳，项羽与宋义争执进兵方略。救赵军停在安阳四十六日，统帅和次将的分歧越来越大。项羽主张立刻渡河，从外面进攻、配合巨鹿城中赵军。宋义却想让秦赵先耗尽力量，再乘疲进取，并说自己冲锋不及项羽，坐而运筹则强于项羽。宋义送儿子去齐国做相、饮酒宴会，士兵却在寒雨中挨饿。项羽指责等下去只会等来赵亡、秦强，统帅不能只顾私事。十一月，他晨见宋义，在帐中把宋义杀死，随即宣布对方谋反、自己奉楚王密令行事。军中先拥项羽代理统帅，楚王后来才予以承认。项羽派人追杀宋义之子宋襄，让桓楚回报楚王。怀王任他为上将军，当阳君、蒲将军都受其节制。项羽通过这次军中夺权取得指挥权，而不是自然继承叔父全部地位。 [[2]](#note-3)

3. **秦军围巨鹿，项羽渡河破秦，诸侯军归其节制。** 十月，章邯攻破邯郸，把当地居民迁往河内，并毁坏城郭。赵王歇与张耳转入巨鹿，秦军不只追击军队，也在破坏赵方原有据点。[原格与说明](#sj016-m10-note)秦军围攻巨鹿，项羽先遣两万援军渡河。围城的秦军有明确分工。赵王歇、张耳困在城中，陈馀在城外北方；王离等围城，章邯驻南方，经甬道送粮。项羽先遣当阳君、蒲将军带二万人渡河，初战有利，陈馀再请增援。项羽带全军渡河，毁船、破锅，只带三日粮。楚军连战，切断甬道，击败秦军，杀苏角、俘王离；涉闲拒降，自焚而死。诸侯原先观望，战后转而接受项羽指挥。秦军被击破后，项羽召见各路将领，他们不敢与之平起平坐。他开始成为不只限于楚军的统帅；章邯所部仍在，巨鹿胜利还不是全部秦军投降。 [[3]](#note-1)

4. **巨鹿解围后张耳责陈馀，收其印绶与部众。** 张耳责问陈馀，为什么坐拥军队而不来救自己。陈馀说贸然进攻只会使全军覆没，自己派出的五千人已经没有回来；张耳又怀疑前往催救的张黶、陈泽遭了陈馀毒手，不断追问。陈馀愤怒地交出将印，张耳最终接收了他的军队。陈馀离开时只带着少数亲近部下，转到河边、南皮一带活动。赵王歇后来留在赵地，张耳则随诸侯西进。两位旧友在巨鹿形成的裂痕，延续到秦亡后的封王与相互攻伐。[正月弃印](#sj016-m01-note) · [八月去向](#sj016-m08-note) [[4]](#note-10)

5. **司马欣劝章邯求退路，楚秦议降。** 司马欣在咸阳等了三日，没有见到赵高。秦军后退、二世责备章邯，章邯派司马欣入朝请示。司马欣感到不被信任，急忙绕开原路返回，赵高果然派人追赶。他回营劝章邯，打赢可能遭忌，打败又恐被杀，必须考虑退路。陈馀写信说降，议和未成时，楚军仍继续进攻。信中以白起、蒙恬为例，劝章邯联合诸侯、分享土地。章邯遣人秘密接洽，但协议未定；蒲将军渡三户，在漳南再败秦军，项羽又在污水一带大破秦军。军事压力始终没有停止。楚军也缺粮，项羽终于同意降约。两軍在洹水南殷虚会盟，章邯流泪诉说赵高的作为。项羽许他雍王名号，留在楚军中，由司马欣带秦降军作入关前锋。此时先许王号，后来分封再确定地盘，是一件事的前后阶段。 [[5]](#note-12)

6. **刘邦西进，遇郦食其，破秦将杨熊。** 刘邦在栗一带会合兵力，向昌邑推进时受阻。刘邦西进期间遇到彭越，又接收刚武侯约四千人的部队，并与魏将皇欣、魏申徒武蒲会合，进攻昌邑未克。两书对栗与昌邑之间几次用兵的先后记法有别。曹参随军在成武南击败东郡尉军，又击王离军于成阳南、杠里。周勃参与在成武攻东郡尉、击王离军，两战功录都写破敌；不把王离部将之战误作王离本人在这里被俘。在高阳，郦食其帮助他改变了攻取的方向。刘邦坐在床边，让两名女子替自己洗脚，郦食其不行跪拜礼，直言这样不足以礼待长者。刘邦起身整理衣服、道歉并请他上坐。郦食其建议取陈留秦仓积粟，事成后受号广野君，弟弟郦商带陈留兵加入。开封没有拿下，白马、曲遇两战却重创秦将杨熊。杨熊退往荥阳，被二世派使者处死。刘邦接着南攻颍阳，攻克后屠城，再借张良熟悉韩地，向轘辕一带推进。曹参参与开封围赵贲及曲遇击杨熊，俘获秦司马、御史各一人，升执珪爵。周勃功录另列攻开封先到城下立功、攻长社先登、攻颍阳。开封在该传被排在项梁死前，这里与本纪西进战事对读，不能由列序差另造一次已经确年的早期攻城。 [[6]](#note-15)

7. **刘邦取宛，收降南阳守，继续西行。** 截住另一支入关军，再向南阳找路。司马卬也想从赵地渡河入关，刘邦抢先控制平阴河津。他阻住这条渡口，自己转往南方，在洛阳以东作战却失利，于是回阳城整顿骑兵，再向南阳进攻，在犨以东击败郡守齮。曹参又从攻阳武、取轘辕和缑氏、绝河津，回击赵贲军于尸北；南下攻犨，与南阳守齮战于阳城郭东并冲破其阵。张良从韩地带兵跟从，协助攻下韩国十余城；韩王成留守阳翟，张良再随刘邦南下宛城、向武关推进。周勃参攻缑氏、截断河津，在尸乡北打赵贲，随后南攻南阳守齮；子战没有各自确日。南阳守退保宛城，刘邦本想绕过，张良劝他回头。前有强秦，后留坚城，容易腹背受敌。刘邦夜里改道，放低旗帜隐蔽行军，天亮时重新包围宛。郡守绝望想自杀，舍人陈恢先出城谈判。陈恢把“降而不死”当作打开西路的办法。宛有众多人口、积蓄和附属城邑，守军以为投降也是死，才会坚守；只要保全郡守、接收甲卒继续西进，其他城就更愿开门。刘邦采纳，封守为殷侯，给陈恢千户，随后取得更多城邑的归降。曹参随军取得宛、收服南阳守齮，平定南阳郡。经过丹水、胡阳一带，他又得到梅鋗的帮助。梅鋗是番君的别将，两军一起招降析、郦。刘邦还派魏人甯昌出使秦廷，等待消息；与此同时，北面的章邯已向项羽投降。 [[7]](#note-18)

8. **七月，申阳攻取河南地区，归附楚方。** 他取得这片地区、随后迎接诸侯军，为日后受封河南王积累了条件；此时还不能提前称他为已经分封就国的河南王。[原格与说明](#sj016-m07-note) [[8]](#note-22)

<a id="event-28"></a>

9. **刘邦不接受赵高先前分关中的提议，继续用交涉与武力推进。** 郦食其、陆贾受命说秦将，张良建议以利诱和疑兵使对方松懈。子婴方面派兵守峣关，刘邦绕关作战，在蓝田南北连续获胜。他同时禁止军队沿途掠夺，使秦人不再一味拒绝新来者。正式受降接在下一古历年条十月。 曹参先从军取峣关，又攻蓝田南面的秦军，夜击其北面，秦军大败。 张良劝刘邦不要只凭两万人硬攻强秦军，先扎营、准备五万人粮食、多张旗帜作疑兵，再遣郦食其以重财诱守将。秦将愿反秦合军西袭咸阳，刘邦想同意；张良提醒，将领愿降不代表士卒肯从，便趁守备松懈进攻，获胜后又向北战于蓝田。 周勃也参与破峣关、蓝田秦军。 [[9]](#note-28)

11. **赵高逼死二世，子婴继立后诛赵高。** 刘邦攻入武关，赵高再难掩饰局势。原先轻描淡写的“盗贼”逼近关中，赵高害怕被追究，称病不朝，与女婿咸阳令阎乐、弟弟赵成商议更换皇帝。曹参也随军进取武关。周勃也参与攻破武关。阎乐假称追捕盗贼，带兵突入望夷宫。二世在这里准备祭泾水，守卫、郎官宦者遭杀，近侍或逃或死，无法组织有效抵抗。二世不断求退，仍被逼自杀。求见丞相、做一郡之王、降万户侯、最后只求与妻子做平民，全被拒绝。阎乐称奉丞相命令，命兵前进；二世自杀，后以平民规格葬在宜春苑一带。九月，秦不再称帝，宗室子婴被立为秦王。赵高以秦地缩小、诸侯复立为由去帝号。子婴怀疑受玺时将遭加害，与儿子商议，称病不赴；赵高亲自来催，被子婴刺杀，家族受诛。 [[11]](#note-24)

> 宋義所遇齊使者高陵君顯見楚懷王曰：「宋義論武信君必敗，數日果敗。軍未戰先見敗徵，可謂知兵矣。」王召宋義與計事而說之，因以為上將軍；羽為魯公，為次將，范增為末將。諸別將皆屬，號卿子冠軍。北救趙，至安陽，留不進。秦三年，羽謂宋義曰：「今秦軍圍鉅鹿，疾引兵渡河，楚擊其外，趙應其內，破秦軍必矣。」宋義曰：「不然。夫搏牛之虻不可以破蝨。今秦攻趙，戰勝則兵罷，我承其敝；不勝，則我引兵鼓行而西，必舉秦矣。故不如先鬥秦、趙。夫擊輕銳，我不如公；坐運籌策，公不如我。」

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0207-04)项栏司马欣赴秦求援归[章邯困境](#sj006-061-note)；“赵高让之”是责备，与本纪不获接见等细节并读，不添一次已经面见皇帝的会谈。汉栏颍阳、韩地、断河津接[西路](#sj008-west)及本页南阳之前的截津行动。

<a id="sj016-m05-note"></a>
<a id="五月司马欣逃回"></a>
#### 五月｜司马欣逃回

[本月项栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0207-05)接[司马欣遭追、劝章邯转向](#sj006-061-note)。楚栏“二年一月”是该栏计月变化，不能把本行改成正月，更不是另立一位楚王。

<a id="sj016-m06-note"></a>
<a id="六月议降未成与南阳守战败"></a>
#### 六月｜议降未成与南阳守战败

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0207-06)项栏接[议降与继续进攻](#sj006-061-note)；汉栏败齮地写“阳城郭东”，本纪与[汉书P021](../../sources/摘录/汉书-高帝纪.md#p021)作犨东，正文沿较详的南阳行军线，异地保留，不因此让同一郡守重复经历完全相同的败逃。

<a id="sj016-m07-note"></a>
<a id="七月殷虚盟降南阳投降与申阳"></a>
#### 七月｜殷虚盟降、南阳投降与申阳

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0207-07)项栏章邯雍王归[殷虚降约](#sj006-061-note)，汉栏封齮接宛城谈降。韩栏申阳下河南、归楚补[申阳条](#sj016-shenyang)，迎楚与受封背景见[卷007 P021](../../sources/摘录/史记-卷007-项羽本纪.md#p021)。他在韩栏出现是借栏记事，不让申阳成为韩王；河南指古地区，不套现代全省。

<a id="sj016-m08-note"></a>
<a id="八月秦降军赵地与武关"></a>
#### 八月｜秦降军、赵地与武关

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0207-08)秦栏赵高杀二世接[望夷宫](#sj006-063-note)，项栏董翳司马欣领降军接[军队改编](#sj006-061-note)，不与七月投降重复计事。赵栏歇留国、陈馀居南皮接[张陈分道](#sj016-zhangchen)；汉栏武关仍接既有西路终段。死亡、改编和攻关没有同日证据。

<a id="sj016-m09-note"></a>
<a id="九月子婴与不战皆降的压缩"></a>
#### 九月｜子婴与“不战皆降”的压缩

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0207-09)秦栏接[子婴继立](#sj006-064-note)。汉栏“以留侯策，不战皆降”与本纪、汉书及[《留侯世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7055.md#ref-fd53b98dc6f4e0)所载蓝田作战不同，正文仍保留利诱、疑兵和战斗，不据短句删去战事；留侯是张良后称，不在本年提前正式封侯。受降另接汉元年十月。

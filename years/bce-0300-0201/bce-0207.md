# 公元前207年｜项羽破巨鹿、受秦降军，刘邦从曲折的西路进入关中

[← 公元前208年](bce-0208.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前206年条 →](bce-0206.md)

**秦二世三年；子婴继为秦王**

> “汉元年冬十月”归在[前206年页](bce-0206.md)，紧接二世三年九月，不是又等一个公历年。子婴投降按公历年界通常归前207年，新安杀降亦按汉元年年条置于后一页。

<a id="sj007-songyi"></a>
## 十一月，项羽杀掉上将军宋义

**救赵军停在安阳四十六日，统帅和次将的分歧越来越大。** 项羽主张立刻渡河，从外面进攻、配合巨鹿城中赵军。宋义却想让秦赵先耗尽力量，再乘疲进取，并说自己冲锋不及项羽，坐而运筹则强于项羽。[5](#sj007-julu-note)

**宋义送儿子去齐国做相、饮酒宴会，士兵却在寒雨中挨饿。** 项羽指责等下去只会等来赵亡、秦强，统帅不能只顾私事。十一月，他晨见宋义，在帐中把宋义杀死，随即宣布对方谋反、自己奉楚王密令行事。[5](#sj007-julu-note)

**军中先拥项羽代理统帅，楚王后来才予以承认。** 项羽派人追杀宋义之子宋襄，让桓楚回报楚王。怀王任他为上将军，当阳君、蒲将军都受其节制。项羽通过这次军中夺权取得指挥权，而不是自然继承叔父全部地位。[5](#sj007-julu-note)

## 巨鹿：先切断粮道，再击破围城军

**围城的秦军有明确分工。** 赵王歇、张耳困在城中，陈馀在城外北方；王离等围城，章邯驻南方，经甬道送粮。项羽先遣当阳君、蒲将军带二万人渡河，初战有利，陈馀再请增援。[5](#sj007-julu-note)

**项羽带全军渡河，毁船、破锅，只带三日粮。** 楚军连战，切断甬道，击败秦军，杀苏角、俘王离；涉闲拒降，自焚而死。[5](#sj007-julu-note)

**诸侯原先观望，战后转而接受项羽指挥。** 秦军被击破后，项羽召见各路将领，他们不敢与之平起平坐。他开始成为不只限于楚军的统帅；章邯所部仍在，巨鹿胜利还不是全部秦军投降。[1](#sj006-061-note) [5](#sj007-julu-note)

## 章邯为什么转而求和

**司马欣在咸阳等了三日，没有见到赵高。** 秦军后退、二世责备章邯，章邯派司马欣入朝请示。司马欣感到不被信任，急忙绕开原路返回，赵高果然派人追赶。他回营劝章邯，打赢可能遭忌，打败又恐被杀，必须考虑退路。[1](#sj006-061-note)

**陈馀写信说降，议和未成时，楚军仍继续进攻。** 信中以白起、蒙恬为例，劝章邯联合诸侯、分享土地。章邯遣人秘密接洽，但协议未定；蒲将军渡三户，在漳南再败秦军，项羽又在污水一带大破秦军。军事压力始终没有停止。[卷007 P013](../../sources/摘录/史记-卷007-项羽本纪.md#p013)。

**楚军也缺粮，项羽终于同意降约。** 两軍在洹水南殷虚会盟，章邯流泪诉说赵高的作为。项羽许他雍王名号，留在楚军中，由司马欣带秦降军作入关前锋。此时先许王号，后来分封再确定地盘，是一件事的前后阶段。[卷007 P014](../../sources/摘录/史记-卷007-项羽本纪.md#p014)。

<a id="sj008-west"></a>
## 西路并不顺利：昌邑两次未下，先靠陈留补充粮兵

**刘邦先攻东郡、到栗收兵，在昌邑又接连受挫。** 他遇到彭越，合兵攻秦失利，退到栗；又夺得刚武侯约四千人的部队，与魏将皇欣、魏申徒武蒲的军队再攻昌邑，仍没有攻下。西行不是一开始就不断开城受降。[《汉书》P019](../../sources/摘录/汉书-高帝纪.md#p019) · [卷008 P013](../../sources/摘录/史记-卷008-高祖本纪.md#p013)。

**在高阳，郦食其帮助他改变了攻取的方向。** 刘邦坐在床边，让两名女子替自己洗脚，郦食其不行跪拜礼，直言这样不足以礼待长者。刘邦起身整理衣服、道歉并请他上坐。郦食其建议取陈留秦仓积粟，事成后受号广野君，弟弟郦商带陈留兵加入。[《汉书》P020](../../sources/摘录/汉书-高帝纪.md#p020) · [卷008 P013](../../sources/摘录/史记-卷008-高祖本纪.md#p013)。

**开封没有拿下，白马、曲遇两战却重创秦将杨熊。** 杨熊退往荥阳，被二世派使者处死。刘邦接着南攻颍阳，攻克后屠城，再借张良熟悉韩地，向轘辕一带推进。[卷008 P013](../../sources/摘录/史记-卷008-高祖本纪.md#p013)。

## 截住另一支入关军，再向南阳找路

**司马卬也想从赵地渡河入关，刘邦抢先控制平阴河津。** 他阻住这条渡口，自己转往南方，在洛阳以东作战却失利，于是回阳城整顿骑兵，再向南阳进攻，在犨以东击败郡守齮。[卷008 P014](../../sources/摘录/史记-卷008-高祖本纪.md#p014)。

**南阳守退保宛城，刘邦本想绕过，张良劝他回头。** 前有强秦，后留坚城，容易腹背受敌。刘邦夜里改道，更换旗帜，天亮时重新包围宛。郡守绝望想自杀，舍人陈恢先出城谈判。[《汉书》P021](../../sources/摘录/汉书-高帝纪.md#p021) · [卷008 P014](../../sources/摘录/史记-卷008-高祖本纪.md#p014)。

**陈恢把“降而不死”当作打开西路的办法。** 宛有众多人口、积蓄和附属城邑，守军以为投降也是死，才会坚守；只要保全郡守、接收甲卒继续西进，其他城就更愿开门。刘邦采纳，封守为殷侯，给陈恢千户，随后取得更多城邑的归降。[《汉书》P021](../../sources/摘录/汉书-高帝纪.md#p021)。

**经过丹水、胡阳一带，他又得到梅鋗的帮助。** 梅鋗是番君的别将，两军一起招降析、郦。刘邦还派魏人甯昌出使秦廷，等待消息；与此同时，北面的章邯已向项羽投降。[卷008 P014](../../sources/摘录/史记-卷008-高祖本纪.md#p014)。

## 八月，皇帝面前连鹿与马都不能照实说

**赵高借献鹿试探群臣。** 他把鹿说成马，二世发笑，询问左右；有人沉默，有人附和，也有人说鹿。赵高暗中以法治罪坚持说鹿者，群臣更不敢直言。[2](#sj006-062-note)

**刘邦攻入武关，赵高再难掩饰局势。** 原先轻描淡写的“盗贼”逼近关中，赵高害怕被追究，称病不朝，与女婿咸阳令阎乐、弟弟赵成商议更换皇帝。[3](#sj006-063-note) · [《汉书》P022](../../sources/摘录/汉书-高帝纪.md#p022)。

<a id="sj005-existing-c1f231c997"></a>
## 望夷宫政变，二世求退为平民也没有用

**阎乐假称追捕盗贼，带兵突入望夷宫。** 二世在这里准备祭泾水，守卫、郎官宦者遭杀，近侍或逃或死，无法组织有效抵抗。[3](#sj006-063-note)

**二世不断求退，仍被逼自杀。** 求见丞相、做一郡之王、降万户侯、最后只求与妻子做平民，全被拒绝。阎乐称奉丞相命令，命兵前进；二世自杀，后以平民规格葬在宜春苑一带。[3](#sj006-063-note)

## 九月，子婴杀赵高，刘邦在蓝田击败秦军

**秦不再称帝，宗室子婴被立为秦王。** 赵高以秦地缩小、诸侯复立为由去帝号。子婴怀疑受玺时将遭加害，与儿子商议，称病不赴；赵高亲自来催，被子婴刺杀，家族受诛。[4](#sj006-064-note)

**刘邦不接受赵高先前分关中的提议，继续用交涉与武力推进。** 郦食其、陆贾受命说秦将，张良建议以利诱和疑兵使对方松懈。子婴方面派兵守峣关，刘邦绕关作战，在蓝田南北连续获胜。他同时禁止军队沿途掠夺，使秦人不再一味拒绝新来者。正式受降接在下一古历年条十月。[《汉书》P022](../../sources/摘录/汉书-高帝纪.md#p022) · [卷008 P015](../../sources/摘录/史记-卷008-高祖本纪.md#p015)。

## 原文与出处

### S1｜郦食其与陈留

[《汉书》P020](../../sources/摘录/汉书-高帝纪.md#p020) · [卷008 P013](../../sources/摘录/史记-卷008-高祖本纪.md#p013)。接见态度、攻陈留、郦商归附为同一过程，改礼并不等于其余军事行动从此全无暴力。颍阳屠城正是本卷明载，不能为维持“刘宽项暴”的整齐对比而漏掉。

### S2｜宛城谈降

[《汉书》P021](../../sources/摘录/汉书-高帝纪.md#p021) · [卷008 P014](../../sources/摘录/史记-卷008-高祖本纪.md#p014)。张良判断后患、陈恢谈判、守受封在同一叙事中保留；对话非现代逐字记录。原文还有“高武侯鳃、襄侯王陵降西陵”的疑难句，涉及人物识别与断句，留在来源与考证，不仅凭同名就把后来汉相王陵的首次归附定在此刻。

### S3｜武关、赵高与蓝田

[《汉书》P022](../../sources/摘录/汉书-高帝纪.md#p022) · [卷008 P015](../../sources/摘录/史记-卷008-高祖本纪.md#p015)。汉书先记八月攻武关，继记赵高杀二世；卷008先叙二世死、交涉，再写袭武关。采用既有汉书阶段安排，保留差别，不强拼到具体日的唯一顺序。两书在归降、诱敌、禁掠等方面互补，不把一段中未标月的每项行动都继承九月。

<a id="sj006-061-note"></a>
### 1｜巨鹿与章邯降楚分阶段

[卷006 P061](../../sources/摘录/史记-卷006-秦始皇本纪.md#p061) · [卷007 P012—P014](../../sources/摘录/史记-卷007-项羽本纪.md#p012) · [卷008 P015的回叙](../../sources/摘录/史记-卷008-高祖本纪.md#p015) · [《通鉴》卷八](https://zh.wikisource.org/wiki/資治通鑑/卷008)。司马欣的话为当事人判断，陈馀信中蒙恬等旧事有说降修辞，不覆盖各人原来结局；项羽接受和议也有自身缺粮因素。李斯之死仍见[前208年](bce-0208.md#sj006-060-note)，不在本年再死一次。

<a id="sj006-062-note"></a>
### 2｜指鹿为马

[卷006 P062](../../sources/摘录/史记-卷006-秦始皇本纪.md#p062)。沉默、言马、言鹿三类反应分别保留；不宣称传世场景已获出土材料逐项验证。[异说](../../meta/考证/史记-卷006-纪年与异说.md#沙丘继位)。

<a id="sj006-063-note"></a>
### 3｜望夷宫

[卷006 P063](../../sources/摘录/史记-卷006-秦始皇本纪.md#p063)。白虎梦、占梦与祭泾水为到宫前的叙事背景，不解释为真实预告；二世被迫自杀，不简化成赵高手刃。宫中战斗不扩造人数和日时。

<a id="sj006-064-note"></a>
### 4｜子婴与受降年界

[卷006 P064—P065](../../sources/摘录/史记-卷006-秦始皇本纪.md#p064)。亲缘说法不一，正文只称宗室；斋戒五日、在位四十六日不推出唯一公历受玺日。[古历归档](../../meta/考证/史记-卷006-纪年与异说.md#秦历与年页)。

<a id="sj007-julu-note"></a>
### 5｜宋义、巨鹿与楚军权力

[卷007 P009—P012](../../sources/摘录/史记-卷007-项羽本纪.md#p009) · [《通鉴》卷八](https://zh.wikisource.org/wiki/資治通鑑/卷008)。任命前208年、十一月杀将及追认前207年，不将整个长段压成同年。所谓宋义谋反、楚王阴令是项羽公布的理由，不能当作另有证据证明的密令。九战、三日粮、二万人、一当十、诸侯膝行依原文性质，不用来算精确战损。

<a id="sj008-west-note"></a>
### 6｜西进的失败与新人物

[卷008 P013—P015](../../sources/摘录/史记-卷008-高祖本纪.md#p013)。昌邑两次未下、洛阳东败、颍阳屠城与宛城宽降，都保留于同一条西路，不把结果已知的胜者行军写成直线。刚武侯、皇欣、魏申徒武蒲及甯昌名字沿所据文本，不补未核身份。彭越在昌邑参与战事，是其较早的有据活动，前206—205年梁地反楚是后续，不混成一次战斗。

**秦栏：** 赵高政变、二世自杀、子婴杀赵高及夷族，接[望夷宫注](#sj006-063-note)、[子婴注](#sj006-064-note)。表“二世兄子婴”的断句、亲属关系不能单凭省文裁定，正文仍称宗室子婴。“诸侯入秦、婴降、为项羽所杀”是把下一古历年条压入末格，主叙接[前206年承接注](bce-0206.md#sj015-0207-forward)；“寻诛羽，天下属汉”再前瞻到[前202年楚汉结局](bce-0202.md#sj015-0207-forward)。寻只表接续，绝不是项羽在秦亡同年即死。秦汉十月岁首使古年条与公历年界不齐，子婴向刘邦投降，按通常公历归前207年，本站按汉元年放前206页已有说明，不将页面名误当逐日公历换算。

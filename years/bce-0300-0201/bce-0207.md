**秦二世三年；子婴继为秦王**

> “汉元年冬十月”归在[前206年页](bce-0206.md)，紧接二世三年九月，不是又等一个公历年。子婴投降按公历年界通常归前207年，新安杀降亦按汉元年年条置于后一页。

### 十月，邯郸被毁，救赵的队伍陆续聚集

<a id="event-1"></a>

1. **章邯攻破邯郸，把当地居民迁往河内，并毁坏城郭。** 赵王歇与张耳转入巨鹿，秦军不只追击军队，也在破坏赵方原有据点。[原格与说明](#sj016-m10-note) [[1]](#note-1)

<a id="event-2"></a>

2. **田都脱离田荣，带齐军助楚救赵；燕国也派臧荼来援。** 稍后，齐王建的孙子田安取得济北部分城邑，又加入项羽；魏豹也参与救赵。各路将领的这些选择，后来成为项羽分封时论功和排斥他人的依据之一。[十月](#sj016-m10-note) · [十二月](#sj016-m12-note) [[2]](#note-2)

<a id="sj007-songyi"></a>
<a id="十一月项羽杀掉上将军宋义"></a>
### 十一月，项羽杀掉上将军宋义

<a id="event-3"></a>

3. **救赵军停在安阳四十六日，统帅和次将的分歧越来越大。** 项羽主张立刻渡河，从外面进攻、配合巨鹿城中赵军。宋义却想让秦赵先耗尽力量，再乘疲进取，并说自己冲锋不及项羽，坐而运筹则强于项羽。 [[3]](#note-3)

<a id="event-4"></a>

4. **宋义送儿子去齐国做相、饮酒宴会，士兵却在寒雨中挨饿。** 项羽指责等下去只会等来赵亡、秦强，统帅不能只顾私事。十一月，他晨见宋义，在帐中把宋义杀死，随即宣布对方谋反、自己奉楚王密令行事。 [[4]](#note-4)

<a id="event-5"></a>

5. **军中先拥项羽代理统帅，楚王后来才予以承认。** 项羽派人追杀宋义之子宋襄，让桓楚回报楚王。怀王任他为上将军，当阳君、蒲将军都受其节制。项羽通过这次军中夺权取得指挥权，而不是自然继承叔父全部地位。 [[5]](#note-5)

<a id="巨鹿先切断粮道再击破围城军"></a>
### 巨鹿：先切断粮道，再击破围城军

<a id="event-6"></a>

6. **围城的秦军有明确分工。** 赵王歇、张耳困在城中，陈馀在城外北方；王离等围城，章邯驻南方，经甬道送粮。项羽先遣当阳君、蒲将军带二万人渡河，初战有利，陈馀再请增援。 [[6]](#note-6)

<a id="event-7"></a>

7. **项羽带全军渡河，毁船、破锅，只带三日粮。** 楚军连战，切断甬道，击败秦军，杀苏角、俘王离；涉闲拒降，自焚而死。 [[7]](#note-7)

<a id="event-8"></a>

8. **救赵期间，另有一道被称为“枉矢”的流星状光迹向西流过的记录。** 这条天象记载没有确切月日，不作为楚军获胜的原因。 [[8]](#note-8)

<a id="event-9"></a>

9. **诸侯原先观望，战后转而接受项羽指挥。** 秦军被击破后，项羽召见各路将领，他们不敢与之平起平坐。他开始成为不只限于楚军的统帅；章邯所部仍在，巨鹿胜利还不是全部秦军投降。 [[9]](#note-9)

<a id="sj016-zhangchen"></a>
<a id="围城解除了张耳与陈馀的交情却破裂了"></a>
### 围城解除了，张耳与陈馀的交情却破裂了

<a id="event-10"></a>

10. **张耳责问陈馀，为什么坐拥军队而不来救自己。** 陈馀说贸然进攻只会使全军覆没，自己派出的五千人已经没有回来；张耳又怀疑前往催救的张黶、陈泽遭了陈馀毒手，不断追问。 [[10]](#note-10)

<a id="event-11"></a>

11. **陈馀愤怒地交出将印，张耳最终接收了他的军队。** 陈馀离开时只带着少数亲近部下，转到河边、南皮一带活动。赵王歇后来留在赵地，张耳则随诸侯西进。两位旧友在巨鹿形成的裂痕，延续到秦亡后的封王与相互攻伐。[正月弃印](#sj016-m01-note) · [八月去向](#sj016-m08-note) [[11]](#note-11)

<a id="章邯为什么转而求和"></a>
### 章邯为什么转而求和

<a id="event-12"></a>

12. **司马欣在咸阳等了三日，没有见到赵高。** 秦军后退、二世责备章邯，章邯派司马欣入朝请示。司马欣感到不被信任，急忙绕开原路返回，赵高果然派人追赶。他回营劝章邯，打赢可能遭忌，打败又恐被杀，必须考虑退路。 [[12]](#note-12)

<a id="event-13"></a>

13. **陈馀写信说降，议和未成时，楚军仍继续进攻。** 信中以白起、蒙恬为例，劝章邯联合诸侯、分享土地。章邯遣人秘密接洽，但协议未定；蒲将军渡三户，在漳南再败秦军，项羽又在污水一带大破秦军。军事压力始终没有停止。[卷007 P013](../../sources/摘录/史记-卷007-项羽本纪.md#p013)。 [[13]](#note-13)

<a id="event-14"></a>

14. **楚军也缺粮，项羽终于同意降约。** 两軍在洹水南殷虚会盟，章邯流泪诉说赵高的作为。项羽许他雍王名号，留在楚军中，由司马欣带秦降军作入关前锋。此时先许王号，后来分封再确定地盘，是一件事的前后阶段。[卷007 P014](../../sources/摘录/史记-卷007-项羽本纪.md#p014)。 [[14]](#note-14)

<a id="sj008-west"></a>
<a id="西路并不顺利昌邑两次未下先靠陈留补充粮兵"></a>
### 西路并不顺利：昌邑两次未下，先靠陈留补充粮兵

<a id="event-15"></a>

15. **刘邦先攻东郡、到栗收兵，在昌邑又接连受挫。** 他遇到彭越，合兵攻秦失利，退到栗；又夺得刚武侯约四千人的部队，与魏将皇欣、魏申徒武蒲的军队再攻昌邑，仍没有攻下。西行不是一开始就不断开城受降。[《汉书》P019](../../sources/摘录/汉书-高帝纪.md#p019) · [卷008 P013](../../sources/摘录/史记-卷008-高祖本纪.md#p013)。 [[15]](#note-15)

<a id="event-16"></a>

16. **在高阳，郦食其帮助他改变了攻取的方向。** 刘邦坐在床边，让两名女子替自己洗脚，郦食其不行跪拜礼，直言这样不足以礼待长者。刘邦起身整理衣服、道歉并请他上坐。郦食其建议取陈留秦仓积粟，事成后受号广野君，弟弟郦商带陈留兵加入。[《汉书》P020](../../sources/摘录/汉书-高帝纪.md#p020) · [卷008 P013](../../sources/摘录/史记-卷008-高祖本纪.md#p013)。 [[16]](#note-16)

<a id="event-17"></a>

17. **开封没有拿下，白马、曲遇两战却重创秦将杨熊。** 杨熊退往荥阳，被二世派使者处死。刘邦接着南攻颍阳，攻克后屠城，再借张良熟悉韩地，向轘辕一带推进。[卷008 P013](../../sources/摘录/史记-卷008-高祖本纪.md#p013)。 [[17]](#note-17)

<a id="截住另一支入关军再向南阳找路"></a>
### 截住另一支入关军，再向南阳找路

<a id="event-18"></a>

18. **司马卬也想从赵地渡河入关，刘邦抢先控制平阴河津。** 他阻住这条渡口，自己转往南方，在洛阳以东作战却失利，于是回阳城整顿骑兵，再向南阳进攻，在犨以东击败郡守齮。[卷008 P014](../../sources/摘录/史记-卷008-高祖本纪.md#p014)。 [[18]](#note-18)

<a id="event-19"></a>

19. **南阳守退保宛城，刘邦本想绕过，张良劝他回头。** 前有强秦，后留坚城，容易腹背受敌。刘邦夜里改道，更换旗帜，天亮时重新包围宛。郡守绝望想自杀，舍人陈恢先出城谈判。[《汉书》P021](../../sources/摘录/汉书-高帝纪.md#p021) · [卷008 P014](../../sources/摘录/史记-卷008-高祖本纪.md#p014)。 [[19]](#note-19)

<a id="event-20"></a>

20. **陈恢把“降而不死”当作打开西路的办法。** 宛有众多人口、积蓄和附属城邑，守军以为投降也是死，才会坚守；只要保全郡守、接收甲卒继续西进，其他城就更愿开门。刘邦采纳，封守为殷侯，给陈恢千户，随后取得更多城邑的归降。[《汉书》P021](../../sources/摘录/汉书-高帝纪.md#p021)。 [[20]](#note-20)

<a id="event-21"></a>

21. **经过丹水、胡阳一带，他又得到梅鋗的帮助。** 梅鋗是番君的别将，两军一起招降析、郦。刘邦还派魏人甯昌出使秦廷，等待消息；与此同时，北面的章邯已向项羽投降。[卷008 P014](../../sources/摘录/史记-卷008-高祖本纪.md#p014)。 [[21]](#note-21)

<a id="sj016-shenyang"></a>

<a id="event-22"></a>

22. **七月，申阳攻取河南地区，归附楚方。** 他取得这片地区、随后迎接诸侯军，为日后受封河南王积累了条件；此时还不能提前称他为已经分封就国的河南王。[原格与说明](#sj016-m07-note) [[22]](#note-22)

<a id="八月皇帝面前连鹿与马都不能照实说"></a>
### 八月，皇帝面前连鹿与马都不能照实说

<a id="event-23"></a>

23. **赵高借献鹿试探群臣。** 他把鹿说成马，二世发笑，询问左右；有人沉默，有人附和，也有人说鹿。赵高暗中以法治罪坚持说鹿者，群臣更不敢直言。 [[23]](#note-23)

<a id="event-24"></a>

24. **刘邦攻入武关，赵高再难掩饰局势。** 原先轻描淡写的“盗贼”逼近关中，赵高害怕被追究，称病不朝，与女婿咸阳令阎乐、弟弟赵成商议更换皇帝。 · [《汉书》P022](../../sources/摘录/汉书-高帝纪.md#p022)。 [[24]](#note-24)

<a id="sj005-existing-c1f231c997"></a>
<a id="望夷宫政变二世求退为平民也没有用"></a>
### 望夷宫政变，二世求退为平民也没有用

<a id="event-25"></a>

25. **阎乐假称追捕盗贼，带兵突入望夷宫。** 二世在这里准备祭泾水，守卫、郎官宦者遭杀，近侍或逃或死，无法组织有效抵抗。 [[25]](#note-25)

<a id="event-26"></a>

26. **二世不断求退，仍被逼自杀。** 求见丞相、做一郡之王、降万户侯、最后只求与妻子做平民，全被拒绝。阎乐称奉丞相命令，命兵前进；二世自杀，后以平民规格葬在宜春苑一带。 [[26]](#note-26)

<a id="九月子婴杀赵高刘邦在蓝田击败秦军"></a>
### 九月，子婴杀赵高，刘邦在蓝田击败秦军

<a id="event-27"></a>

27. **秦不再称帝，宗室子婴被立为秦王。** 赵高以秦地缩小、诸侯复立为由去帝号。子婴怀疑受玺时将遭加害，与儿子商议，称病不赴；赵高亲自来催，被子婴刺杀，家族受诛。 [[27]](#note-27)

<a id="event-28"></a>

28. **刘邦不接受赵高先前分关中的提议，继续用交涉与武力推进。** 郦食其、陆贾受命说秦将，张良建议以利诱和疑兵使对方松懈。子婴方面派兵守峣关，刘邦绕关作战，在蓝田南北连续获胜。他同时禁止军队沿途掠夺，使秦人不再一味拒绝新来者。正式受降接在下一古历年条十月。[《汉书》P022](../../sources/摘录/汉书-高帝纪.md#p022) · [卷008 P015](../../sources/摘录/史记-卷008-高祖本纪.md#p015)。 [[28]](#note-28)

[《汉书》P020](../../sources/摘录/汉书-高帝纪.md#p020) · [卷008 P013](../../sources/摘录/史记-卷008-高祖本纪.md#p013)。接见态度、攻陈留、郦商归附为同一过程，改礼并不等于其余军事行动从此全无暴力。颍阳屠城正是本卷明载，不能为维持“刘宽项暴”的整齐对比而漏掉。

#### 5｜宋义、巨鹿与楚军权力

[卷007 P009—P012](../../sources/摘录/史记-卷007-项羽本纪.md#p009) · [《通鉴》卷八](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7008.md#ref-e3afd4cbccf2d9)。任命前208年、十一月杀将及追认前207年，不将整个长段压成同年。所谓宋义谋反、楚王阴令是项羽公布的理由，不能当作另有证据证明的密令。九战、三日粮、二万人、一当十、诸侯膝行依原文性质，不用来算精确战损。

《天官书》[P119](../../sources/摘录/史记-卷027-天官书.md#p119)：

> 項羽救鉅鹿，枉矢西流，山東遂合從諸侯，西坑秦人，誅屠咸陽。

“枉矢西流”系于救巨鹿，未载独立月日。本卷[P091](../../sources/摘录/史记-卷027-天官书.md#p091)把枉矢形容为“大流星”“蛇行”，这里只保留流星状光迹的古代记录，不自行认定现代天体种类。救巨鹿与诸侯归附属于本年，新安杀降、咸阳焚掠则续在[汉元年前206年条](bce-0206.md#sj007-xinan)；短段不能压成同一天或同一古历年。《汉书》的“以乱伐乱”是后加的占验解释，见[互校H002](../../sources/摘录/史记-卷027-纪年互校.md#h002)。

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0207-09)秦栏接[子婴继立](#sj006-064-note)。汉栏“以留侯策，不战皆降”与本纪、汉书及[《留侯世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7055.md#ref-fd53b98dc6f4e0)所载蓝田作战不同，正文仍保留利诱、疑兵和战斗，不据短句删去战事；留侯是张良后称，不在本年提前正式封侯。受降另接汉元年十月。

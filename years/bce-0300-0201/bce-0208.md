# 公元前208年｜陈胜、项梁相继败亡，秦廷却又杀掉李斯

[← 公元前209年](bce-0209.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前207年 →](bce-0207.md)

**秦二世二年**

> 冬十月是古历年条的开端，本页不把它当作现代公历前208年10月。秦军一度连胜，反秦阵营不断重组；但秦廷内的清洗，使军队与朝廷的联系越来越危险。

## 冬季：陈胜的部下与政权接连受挫

<a id="sj-048-L4210-02"></a>
**十月，葛婴返陈后被杀。** 他先前另立襄强，后来又杀襄强、回陈报告，陈胜仍把他处死。杀襄强与葛婴自己的死亡分属不同月份，不是一件事。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4210) · [月表十月](../../sources/摘录/史记-条目原文.md#ref-sj-1492)。

<a id="sj-048-L4211-02"></a>
**十一月，周文在连续败退后自杀。** 前一年退出关中的周文在曹阳停留二三月，又遭章邯进攻，退到渑池十余日，再次战败后自杀。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4211) · [月表十一月](../../sources/摘录/史记-条目原文.md#ref-sj-1493)。

<a id="sj-048-L4214-02"></a>
**十二月，魏咎终于从陈回到魏地。** 周市在魏地活动，拒绝自己称王，坚持迎立魏国后人魏咎。经过反复请求，陈胜放魏咎回去，魏咎正式在魏地就位，周市任相。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4214) · [元年九月月表](../../sources/摘录/史记-条目原文.md#ref-sj-1491) · [本年十二月](../../sources/摘录/史记-条目原文.md#ref-sj-1494)。

<a id="sj-048-L4218-01"></a>
**秦军逼近陈，蔡赐、张贺先后战死。** 章邯进攻，蔡赐被杀；张贺与陈胜一方在陈西迎战，又被击败，张贺死亡，陈胜离开陈地。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4218) · [月表](../../sources/摘录/史记-条目原文.md#ref-sj-1494)。

<a id="sj-048-L4219-01"></a>
**腊月，陈胜在下城父被自己的车夫杀死。** 庄贾杀陈胜后降秦。陈胜后来葬在砀，谥为隐王，安葬与定谥未另有确日。首先举起反秦旗帜的首领死了，反抗却没有因此结束。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4219) · [月表十二月](../../sources/摘录/史记-条目原文.md#ref-sj-1494)。

<a id="sj-048-L4220-01"></a>
**吕臣组织苍头军，收复陈并杀庄贾。** 他从新阳起兵，重新夺回陈地，为陈胜报仇。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4220) · [月表十二月](../../sources/摘录/史记-条目原文.md#ref-sj-1494) · [端月](../../sources/摘录/史记-条目原文.md#ref-sj-1495)。

<a id="sj-048-L4221-02"></a>
**宋留得知陈胜死后退兵，最终投降仍被处死。** 沿途城邑重新归秦，不肯让他进入；宋留最后降秦，被送到咸阳车裂。收到死讯、退兵、投降与处刑是连续阶段，不全部硬定在腊月。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4221) · [月表](../../sources/摘录/史记-条目原文.md#ref-sj-1494)。

<a id="sj-048-L4223-01"></a>
**秦军再攻陈，吕臣又与黥布联合反击。** 秦左右校使吕臣一度退却，随后他与黥布等合兵，在青波击败秦军，再收陈地。这与先前苍头军杀庄贾是前后两次争夺，不合成一次。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4223)。

## 刘邦先丢丰邑，再去寻找新的靠山

**雍齿反丰，让刘邦连自己的根据地都拿不回来。** 冬十月，刘邦攻胡陵、方与，回丰击退围来的秦军，留雍齿守丰，自己向薛等地活动。十二月魏方来招，雍齿转为魏守丰；刘邦回攻未下，只能退回沛县，从此怨恨雍齿及跟他反叛的丰邑子弟。[《汉书》P012](../../sources/摘录/汉书-高帝纪.md#p012)。

<a id="sj-048-L4222-01"></a>
**秦嘉另立景驹，田儋不愿承认。** 端月，景驹被立为楚王；二月公孙庆出使齐国求兵，田儋认为陈胜生死未明，楚又没有先来商议，拒绝承认，并杀掉使者。反秦各部并不因为共同反秦就能相互信任。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4222) · [月表端月](../../sources/摘录/史记-条目原文.md#ref-sj-1495) · [二月](../../sources/摘录/史记-条目原文.md#ref-sj-1496)。

**刘邦投向景驹，途中遇见张良；后来又转入项梁体系。** 正月以后，他向景驹求兵攻丰，又在砀、下邑扩充队伍。四月项梁杀景驹、秦嘉，刘邦去见项梁，获得五千士卒与一批将领，终于攻下丰邑，雍齿逃往魏。[《汉书》P013](../../sources/摘录/汉书-高帝纪.md#p013)。

## 秦军连胜，楚军也在重新组织

<a id="sj-048-L4223-02"></a>
**六月，项梁等拥立楚怀王之孙心。** 刘邦到薛，与项梁等共同立这位正在民间的楚王后人，以“楚怀王”的名号凝聚人心。原页另列的同一拥立事件在此合并，旧锚点保留。[《汉书》P014](../../sources/摘录/汉书-高帝纪.md#p014) · [卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4223) · [月表六月](../../sources/摘录/史记-条目原文.md#ref-sj-1500)。

**章邯在临济击破齐魏援军，魏咎自杀。** 魏王求援，齐王田儋、周市等战败死亡。魏咎为城中民众谈定投降条件，随后自焚；田荣收集齐军余部退到东阿，章邯追围。项梁后来出兵击破章邯，救解东阿之围，楚军又乘势追击。[1](#sj006-059-note) · [《汉书》P014](../../sources/摘录/汉书-高帝纪.md#p014)。

**八月，刘邦、项羽在雍丘击败秦军，杀死李由。** 外黄没有攻下，战事继续向中原其他城邑展开。[《汉书》P015](../../sources/摘录/汉书-高帝纪.md#p015)。

**九月，项梁在定陶战死。** 他连续取胜后轻敌，宋义劝他谨慎，没有被采纳；秦廷增兵支持章邯，秦军夜袭，大破楚军，项梁死亡。正在攻陈留的刘邦、项羽听说后东退。[《汉书》P016](../../sources/摘录/汉书-高帝纪.md#p016) · [卷006 P059](../../sources/摘录/史记-卷006-秦始皇本纪.md#p059)。

## 楚怀王分派救赵与入关两路

**楚怀王把散开的兵权重新收拢。** 吕臣、项羽等部被收归统辖，刘邦任砀郡长，封武安侯，继续带砀郡兵。章邯击败项梁后北上围赵，楚方派宋义、项羽等北救赵。[《汉书》P016—P017](../../sources/摘录/汉书-高帝纪.md#p016)。

**刘邦得到向西入关的任务。** 怀王与诸将有“先入定关中者王之”的约定。项羽想向西报秦仇，楚方老将却认为，入关更需争取苦秦百姓，而不是一味报复，于是让刘邦收集陈胜、项梁散兵向西，让项羽北救赵。[《汉书》P018](../../sources/摘录/汉书-高帝纪.md#p018)。

## 秦廷内部：谏停工程，反而导致大臣下狱

**赵高让二世少见大臣，政事越来越由自己传达。** 他劝二世，年轻皇帝当面决断容易显露错误，不如深居宫中，由近臣办理。二世接受，公卿越来越难见到皇帝，而战事和征发并没有减少。[2](#sj006-060-note)

**冯去疾、李斯、冯劫请求减轻工役，却被追究别罪。** 三人指出反乱不断，与戍守、漕运、转输、工程、重税有关，建议暂停阿房宫和减少边戍输送。二世认为这是否定先帝事业、不能为自己尽忠，将他们交官吏治罪。冯去疾、冯劫自杀，李斯受审后被施五刑、腰斩，家族受诛。秦军仍在作战，朝廷内部却失去几名资深大臣。[2](#sj006-060-note)

## 补充史料与归年说明

<a id="sj006-059-note"></a>
### 1｜本纪压缩的战争，不能压成同一时间

[卷006 P059](../../sources/摘录/史记-卷006-秦始皇本纪.md#p059) · [《通鉴》卷八，二世二年](https://zh.wikisource.org/wiki/資治通鑑/卷008)。本纪一段合写周章、陈胜、项梁、魏咎及北围巨鹿；本页依月表、列传与现有《汉书》主线拆开。周文至戏与首次战败仍见前209年；陈胜实际死于庄贾之手，不能只依本纪“杀陈胜城父”写成章邯亲手或秦军当场斩杀；魏咎在项梁定陶败死之前已经覆亡。

东阿解围的编排也有细别：《汉书》在六月拥立之后连续叙救齐，《通鉴》明确放秋七月，正文仅作夏秋阶段，不强把同段全部归到六月。吕臣两度复陈的各月未全定；章邯北围赵与巨鹿决战跨到下一年，不提前写成赵王已被俘。

<a id="sj006-060-note"></a>
### 2｜李斯之死采用二世二年，不重复到三年

[卷006 P060—P061](../../sources/摘录/史记-卷006-秦始皇本纪.md#p060) · [卷087《李斯列传》](https://zh.wikisource.org/wiki/史記/卷087) · [《通鉴》卷八](https://zh.wikisource.org/wiki/資治通鑑/卷008)。本纪二年已写李斯“就五刑”，三年开头又写“冬，赵高为丞相，竟案李斯杀之”，年次有重复或错简问题。列传明记“二世二年七月”，《通鉴》也编在二年，因此正文归前208年；具体月与李由战死、案讯叙次仍有困难，本页不强排精确日程。不能因李斯最后谏诤，就抹去他此前参与政策及继承密谋的史书记载。

**汉代叙事的取舍：**楚方评刘邦宽大、项羽残酷是《汉书》用来解释任命的观点，保留其政治作用，不把胜者书写直接改成两人天生性格的定论。旧页《陈涉世家》锚点及《汉书》P012—P018主线保留，拥立楚怀王的重复条目合为一事。

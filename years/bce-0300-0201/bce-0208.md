# 公元前208年｜项梁聚兵又败亡，楚怀王重组军队，秦廷杀李斯

[← 公元前209年](bce-0209.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前207年 →](bce-0207.md)

**秦二世二年**

> 冬十月是古历年条的开端，不直接当作公历前208年10月。秦军一度连胜，反秦阵营不断重组；这一年项梁成为重要统帅，却又在定陶战死。

## 冬季：陈胜的部下与政权接连受挫

<a id="sj-048-L4210-02"></a>
**十月，葛婴返陈后被杀。** 他先前另立襄强，后来杀襄强、回陈报告，陈胜仍把他处死。杀襄强与葛婴自己的死亡分属不同月份。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4210) · [月表十月](../../sources/摘录/史记-条目原文.md#ref-sj-1492)。

<a id="sj-048-L4211-02"></a>
**十一月，周文在连续败退后自杀。** 前一年退出关中的周文在曹阳停留二三月，又遭章邯进攻，退到渑池十余日，再次战败后自杀。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4211) · [月表十一月](../../sources/摘录/史记-条目原文.md#ref-sj-1493)。

<a id="sj-048-L4214-02"></a>
**十二月，魏咎终于从陈回到魏地。** 周市拒绝自己称王，坚持迎立魏国后人魏咎。经过反复请求，陈胜放魏咎回去，魏咎正式在魏地就位，周市任相。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4214) · [元年九月月表](../../sources/摘录/史记-条目原文.md#ref-sj-1491) · [本年十二月](../../sources/摘录/史记-条目原文.md#ref-sj-1494)。

<a id="sj-048-L4218-01"></a>
**秦军逼近陈，蔡赐、张贺先后战死。** 蔡赐被杀，张贺与陈胜一方在陈西迎战，又被击败，张贺死亡，陈胜离开陈地。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4218) · [月表](../../sources/摘录/史记-条目原文.md#ref-sj-1494)。

<a id="sj-048-L4219-01"></a>
**腊月，陈胜在下城父被自己的车夫杀死。** 庄贾杀陈胜后降秦。陈胜后来葬在砀，谥为隐王，安葬与定谥未另有确日。他死了，反抗却没有因此结束。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4219) · [月表十二月](../../sources/摘录/史记-条目原文.md#ref-sj-1494)。

<a id="sj-048-L4220-01"></a>
**吕臣组织苍头军，收复陈并杀庄贾。** 他从新阳起兵，重新夺回陈地，为陈胜报仇。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4220) · [月表十二月](../../sources/摘录/史记-条目原文.md#ref-sj-1494) · [端月](../../sources/摘录/史记-条目原文.md#ref-sj-1495)。

<a id="sj-048-L4221-02"></a>
**宋留听说陈胜死后退兵，投降仍被处死。** 沿途城邑重新归秦，不让他进入；宋留最后降秦，被送到咸阳车裂。收死讯、退兵、投降和处刑是连续阶段，不全部定在腊月。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4221) · [月表](../../sources/摘录/史记-条目原文.md#ref-sj-1494)。

<a id="sj-048-L4223-01"></a>
**陈地还在反复争夺。** 秦左右校再攻陈，使吕臣一度退却。后来他与黥布等联合，在青波击败秦军，又收陈地。这与先前杀庄贾是两次前后相接的行动。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4223)。

## 项梁从江东出来，队伍越聚越大

<a id="sj007-liang-west"></a>
**召平带来一个并非真正来自陈王的任命。** 召平替陈胜攻广陵未下，听说陈王败走、秦军将至，便渡江假传陈王命令，拜项梁为楚上柱国，催他西进。项梁带着八千人渡江西行。[卷007 P004](../../sources/摘录/史记-卷007-项羽本纪.md#p004)。

**东阳的陈婴不肯自己称王，把部队带来归项梁。** 陈婴原是县里令史，向来谨慎守信。当地年轻人杀县令后，推他为首，队伍发展到二万人，又想拥他为王。陈婴母亲劝他：家里本来没有显赫背景，骤得大名不稳，不如依附一个有声望的人，成功仍能获封，失败也容易脱身。陈婴于是以项氏世代为楚将、在楚地有名望为由，说服众人归附项梁。[卷007 P004](../../sources/摘录/史记-卷007-项羽本纪.md#p004)。

**渡过淮水后，黥布、蒲将军也加入。** 到下邳时，项梁所统兵力已被记为六七万人。项氏军不是只有最初的吴中子弟，而是不断吸收其他起兵集团。[卷007 P004](../../sources/摘录/史记-卷007-项羽本纪.md#p004)。

## 刘邦丢掉丰邑，项梁则击败另一支楚军

**雍齿反丰，让刘邦连自己的根据地都拿不回来。** 冬十月，刘邦攻胡陵、方与，回丰击退围来的秦军，留雍齿守丰，自己向薛等地活动。十二月魏方来招，雍齿转为魏守丰；刘邦回攻未下，退回沛县，从此怨恨雍齿及跟他反叛的丰邑子弟。[《汉书》P012](../../sources/摘录/汉书-高帝纪.md#p012)。

<a id="sj-048-L4222-01"></a>
**秦嘉另立景驹，田儋不承认。** 端月，景驹被立为楚王；二月公孙庆使齐求兵，田儋认为陈胜生死未明，楚又未先来商议，拒绝承认，杀掉使者。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4222) · [月表端月](../../sources/摘录/史记-条目原文.md#ref-sj-1495) · [二月](../../sources/摘录/史记-条目原文.md#ref-sj-1496)。

**刘邦去投景驹，项梁却打掉了景驹、秦嘉这一支。** 刘邦正月以后向景驹求兵，途中遇张良，又在砀、下邑增兵。秦嘉在彭城东挡住项梁西进，项梁以他背陈王另立新王为由进攻。四月前后，秦嘉败退胡陵，回军再战而死，景驹逃到梁地后死去。项梁吞并他们的军队；刘邦转来见项梁，获增五千士卒和一批将领，终于攻回丰邑，雍齿逃魏。[《汉书》P013](../../sources/摘录/汉书-高帝纪.md#p013) · [卷007 P005](../../sources/摘录/史记-卷007-项羽本纪.md#p005)。

**对秦作战和内部处罚同样严酷。** 项梁所遣余樊君、朱鸡石与章邯军交战，余樊君战死，朱鸡石败归，随后被项梁处死。项羽另攻襄城，城中坚守，攻克后遭到大规模杀戮。项梁后来在薛召各路将领议事，刘邦也参加。[卷007 P005](../../sources/摘录/史记-卷007-项羽本纪.md#p005)。

## 六月，再立一位楚怀王

<a id="sj-048-L4223-02"></a>
**范增提醒项梁：大家归附项氏，还因为盼着恢复楚王后代。** 范增是居鄛人，年已七十，平素在家而喜欢谋划。他指出，陈胜没有拥立楚后却自行称王，失去了一项可以借用的号召。许多楚地将领来归项梁，正因为项氏是楚国旧将门，盼他重立楚后。[卷007 P006](../../sources/摘录/史记-卷007-项羽本纪.md#p006)。

**项梁等在民间找到正在牧羊的熊心，立为楚怀王。** 他是原楚怀王的孙子。刘邦在薛参与拥立，陈婴成为楚上柱国、封五县，陪同新王都盱台；项梁号武信君。用旧怀王的称号，是为了接住楚人对过去王室的感情。[《汉书》P014](../../sources/摘录/汉书-高帝纪.md#p014) · [卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4223) · [月表六月](../../sources/摘录/史记-条目原文.md#ref-sj-1500) · [卷007 P006](../../sources/摘录/史记-卷007-项羽本纪.md#p006)。

## 夏秋之间，齐楚先并肩，后来又为人事争执

**章邯在临济击败齐魏援军，魏咎自杀。** 齐王田儋、周市等战败死亡；魏咎为城中人谈定投降条件后自焚。田荣收余部退东阿，章邯追围。项梁与田荣、龙且等会军，大破秦军，解除东阿之围。[1](#sj006-059-note) · [《汉书》P014](../../sources/摘录/汉书-高帝纪.md#p014) · [卷007 P007](../../sources/摘录/史记-卷007-项羽本纪.md#p007)。

**田荣回齐逐王，再要求楚赵杀掉投奔他们的齐人。** 田假逃楚，田角、田闲留赵，田荣改立田儋之子田市。他提出，楚杀田假、赵杀田角田闲，自己才派兵继续助楚。项梁不愿杀害穷途来投的邻国君主，赵也不愿出卖来人，齐遂不再增兵助楚。[卷007 P007](../../sources/摘录/史记-卷007-项羽本纪.md#p007)。

**刘邦与项羽一同作战，并非城城顺利。** 两人攻下城阳后屠城，又在濮阳以东败秦；定陶攻不下，便向西略地。八月在雍丘大破秦军、杀李由，随后攻外黄和陈留，却都没有攻克。[《汉书》P015—P016](../../sources/摘录/汉书-高帝纪.md#p015) · [卷007 P007—P008](../../sources/摘录/史记-卷007-项羽本纪.md#p007)。

## 九月，项梁战死，楚王收回军权

**连续胜利使项梁轻敌，秦军却获得增援。** 宋义劝他警惕将骄卒惰，项梁不听，派宋义使齐。章邯得到增兵后夜袭定陶，大破楚军，项梁战死。刘邦、项羽正在攻陈留，听说败讯后与吕臣军一起东退：吕臣驻彭城东，项羽驻城西，刘邦驻砀。[《汉书》P016](../../sources/摘录/汉书-高帝纪.md#p016) · [卷007 P008](../../sources/摘录/史记-卷007-项羽本纪.md#p008)。

**楚怀王从盱台迁到彭城，把项羽、吕臣的军队收归直接统辖。** 吕臣为司徒，父吕青为令尹；刘邦任砀郡长、封武安侯，继续带砀郡兵。项梁死后，不是项羽自然继承叔父全部权力，楚怀王也在重新建立控制。[《汉书》P016](../../sources/摘录/汉书-高帝纪.md#p016) · [卷007 P010](../../sources/摘录/史记-卷007-项羽本纪.md#p010)。

**章邯北上攻赵，楚分出救赵和入关两路。** 赵王歇、张耳退入巨鹿，陈馀在北面的城外统兵；王离等围城，章邯在南面营建甬道、运送粮食。楚方面，高陵君显称赞宋义能预见项梁败局，楚王任宋义为上将军，项羽为鲁公、次将，范增为末将，共同救赵。[卷007 P009—P011](../../sources/摘录/史记-卷007-项羽本纪.md#p009) · [《汉书》P017](../../sources/摘录/汉书-高帝纪.md#p017)。

**刘邦则向西进军。** 怀王与诸将有“先入定关中者王之”的约定。项羽想向西报秦仇，楚方老将却认为入关更需要争取苦秦百姓，于是让刘邦收陈胜、项梁散兵向西，让项羽随宋义北救赵。救赵军在安阳停留、项羽杀宋义夺帅，接在[下一年](bce-0207.md#sj007-songyi)。[《汉书》P018](../../sources/摘录/汉书-高帝纪.md#p018)。

## 秦廷内部：劝停工程，反而导致下狱

**赵高让二世少见大臣，政事越来越由自己传达。** 他劝二世，年轻皇帝当面决断容易显露错误，不如深居宫中，由近臣办理。二世接受，公卿越来越难见到皇帝，征发和战争却没有减少。[2](#sj006-060-note)

**冯去疾、李斯、冯劫请求减轻工役，反被追究别罪。** 三人指出反乱与戍守、漕运、转输、工程和重税有关，建议停阿房、减边戍输送。二世认为这是否定先帝事业，将三人交官吏治罪。冯去疾、冯劫自杀，李斯被施五刑、腰斩，家族受诛。[2](#sj006-060-note)

## 补充史料与归年说明

<a id="sj006-059-note"></a>
### 1｜压缩的战争不能放成同一时间

[卷006 P059](../../sources/摘录/史记-卷006-秦始皇本纪.md#p059) · [《通鉴》卷八](https://zh.wikisource.org/wiki/資治通鑑/卷008)。本纪合写周章、陈胜、项梁、魏咎及北围巨鹿；此处依月表、列传和《汉书》分开。周文初败仍见前209年；陈胜实被庄贾杀，不写成章邯亲手斩杀；临济先于定陶。汉书在六月拥立后接救东阿，《通鉴》明系秋七月，正文用夏秋阶段，不让同段全部继承六月。吕臣两度复陈的月日未全定，巨鹿决战跨下一年。

<a id="sj006-060-note"></a>
### 2｜李斯不在两年各死一次

[卷006 P060—P061](../../sources/摘录/史记-卷006-秦始皇本纪.md#p060) · [卷087](https://zh.wikisource.org/wiki/史記/卷087) · [《通鉴》卷八](https://zh.wikisource.org/wiki/資治通鑑/卷008)。本纪二年“五刑”、三年又“案杀”有重复或错简问题；列传明记二世二年七月，《通鉴》也归二年，故仍放前208。与李由死讯、案讯叙次的困难继续保留，不补确日；晚期谏诤也不抹去李斯此前所参与的政策及密谋。

<a id="sj007-liang-note"></a>
### 3｜本卷补入的过程和不同说法

[卷007 P004—P011](../../sources/摘录/史记-卷007-项羽本纪.md#p004)。召平假命、陈婴母劝、兼并秦嘉、襄城屠杀、范增进言、齐楚索人之争、楚王收军都并入本年原事。召平行动处于闻陈王败后的阶段，不把它倒放到前209年项氏刚起兵时。襄城是“前使”的回叙，不能因写在诛朱鸡石之后就断定严格后于该事。

旧页概称“项梁杀景驹、秦嘉”，本轮改为秦嘉战死、景驹逃至梁地后死去，以保留卷007的区别，不假称两书逐字相同。卷007将召会薛接在确认陈王死之后，与六月拥立分阶段，不将全部会议内容写为同一天。楚南公“三户”是范增所引用的话，非已验证预言；宋义的话也是传世对话。

《汉书》以刘邦宽大、项羽残酷解释任务分配，有胜者叙事色彩，不能改写成两人天生性格的定论。旧《陈涉世家》锚点与汉书P012—P018原文入口均保留；项羽受鲁公号在本年任命阶段，后来以鲁公礼安葬不另造第二次受封。

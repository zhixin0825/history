# 公元前208年｜项梁聚兵又败亡，楚怀王重组军队，秦廷杀李斯

[← 公元前209年](bce-0209.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前207年 →](bce-0207.md)

**秦二世二年**

> 冬十月是古历年条的开端，不直接当作公历前208年10月。秦军一度连胜，反秦阵营不断重组；项梁成为重要统帅，却又在定陶战死。

<a id="冬季陈胜的部下与政权接连受挫"></a>
<a id="sj-048-L4210-02"></a>

<a id="event-1"></a>

1. **十月，葛婴返陈报告后被杀。** 他在东城另立襄强，得知陈胜称王又杀了襄强；回陈报告时，陈胜仍把他处死。杀襄强与葛婴自己的死亡分属前后两个月份。 [[1]](#note-1)

<a id="sj-048-L4211-02"></a>

<a id="event-2"></a>

2. **十一月，周文在连续败退后自杀。** 他在上一秦年退出关中，停驻曹阳二三个月，又被章邯追击打败；退到渑池十多天后，章邯再来进攻，大破其军。周文自刎，余部不再抵抗。 [[2]](#note-2)

<a id="audit-wuguang-tianzang"></a>

<a id="event-3"></a>

3. **荥阳久攻不下，田臧等先杀了统帅吴广。** 田臧等听说周文军已败，认为秦军随时会到，继续顿兵荥阳必会陷入败局，应留少量兵力围城，调全部精兵向西迎敌。他们又指责假王吴广骄傲、不懂用兵权变，不能同他商量，不除掉他就难以成功，遂假传陈王命令杀吴广，把首级送给陈胜。陈胜没有追究，反而遣使赐田臧楚令尹印，命他为上将。 [[3]](#note-3)

<a id="event-4"></a>

4. **田臧与李归先后战死，邓说、伍徐的队伍也被打散。** 田臧留下李归等围守荥阳，亲率精锐西向敖仓迎秦军，军败身死；章邯再攻荥阳城下的李归军，李归等也死。阳城人邓说驻郯，地名古注疑为郟，遭章邯别将击败，逃回陈；铚人伍徐驻许，又被章邯打败，残军同样奔陈。陈胜随后处死邓说。秦军逼近陈地以前，陈胜派出的几路力量已经接连瓦解。 [[4]](#note-4)

<a id="sj-048-L4214-02"></a>

<a id="event-5"></a>

5. **十二月，魏咎终于从陈回到魏地就位，周市为相。** 周市在齐地受挫、退回魏地后，想迎立魏国旧王族、原甯陵君魏咎；魏咎却留在陈胜那里，不能归国。魏地平定后，众人想改拥周市，他坚持不肯。请迎的使者来回五次，陈胜终于让魏咎归国。魏咎此前已有王号，到这时才在魏地就位，周市最终担任魏相。 [[5]](#note-5)

<a id="sj-048-L4218-01"></a>

<a id="event-6"></a>

6. **章邯进攻陈，蔡赐、张贺先后战死。** 秦军打败伍徐后继续进逼，上柱国房君蔡赐阵亡。章邯又攻击陈西的张贺军，陈胜亲自出城督战，楚军仍败，张贺被杀。陈胜随后离开陈地。 [[6]](#note-6)

<a id="sj-048-L4219-01"></a>

<a id="event-7"></a>

7. **腊月，陈胜返回途中，在下城父被车夫庄贾杀死。** 他先前往汝阴，回程到了下城父，庄贾杀主以降秦。陈胜后来葬在砀，谥为隐王，安葬与定谥未另记确日。他称王总共六个月；在位期间疏远故人、任用纠察者的回顾，以及汉、唐作者对首事与败亡的评论，见同号史料。陈胜死后，反秦战争仍在继续。 [[7]](#note-7)

<a id="sj-048-L4220-01"></a>

<a id="event-8"></a>

8. **吕臣组织苍头军，收复陈并杀庄贾。** 吕臣曾为陈胜近侍，后任将军。他在新阳起兵，部众以青色头巾相识，攻下陈，杀死庄贾，为陈胜报仇，使陈地重新归楚。 [[8]](#note-8)

<a id="sj-048-L4221-02"></a>

<a id="event-9"></a>

9. **宋留听到陈胜死讯，退至新蔡投降，仍被处死。** 他原奉命经略南阳、进武关；陈胜死后，南阳重新归秦，宋留不能入关，只得向东到新蔡，遇见秦军，率全军投降。秦方将他押送至咸阳，施以车裂示众。收死讯、失去进路、退兵、投降和处刑是连续阶段。 [[9]](#note-9)

<a id="sj-048-L4223-01"></a>

<a id="event-10"></a>

10. **吕臣一度失去陈，后来联黥布再度收复。** 秦左右校尉军又攻下陈，吕臣退走，收兵重新聚合，又与出自鄱地群盗、号当阳君的黥布军会合，在青波打败秦左右校军，再使陈地归楚。这是继杀庄贾之后的第二次复陈，同一阶段又接到项梁立楚怀王孙熊心。 [[10]](#note-10)

<a id="audit-zhao-succession"></a>
<a id="赵地也发生内乱武臣死后改立赵歇"></a>

<a id="event-11"></a>

11. **冬季，赵将李良袭击邯郸，杀死赵王武臣。** 张耳、陈馀得到消息，得以逃脱。他们收集散兵反击，打败李良；李良转而投奔章邯。前一年刚建立的赵政权，尚未在秦军进攻中覆亡，先经历了一次内部兵变。 [[11]](#note-11)

<a id="event-12"></a>

12. **正月，张耳、陈馀找到赵国旧王族后人赵歇，拥立为赵王，居信都。** 两人是外来者，需要借赵国旧王室的名义招集当地力量。到本年后段秦军北上时，退入巨鹿的赵王已经是赵歇，不再是前一年称王的武臣。 [[12]](#note-12)

<a id="项梁从江东出来队伍越聚越大"></a>
<a id="sj007-liang-west"></a>

<a id="event-13"></a>

13. **召平假传陈胜之命，项梁带兵渡江西行。** 召平带来一个并非真正来自陈王的任命。 召平替陈胜攻广陵未下，听说陈王败走、秦军将至，便渡江假传陈王命令，拜项梁为楚上柱国，催他西进。项梁带着八千人渡江西行。 [[13]](#note-13)

<a id="event-14"></a>

14. **东阳的陈婴不肯自己称王，把部队带来归项梁。** 陈婴原是县里令史，向来谨慎守信。当地年轻人杀县令后，推他为首，队伍发展到二万人，又想拥他为王。陈婴母亲劝他：家里本来没有显赫背景，骤得大名不稳，不如依附有声望的人，成功仍能获封，失败也容易脱身。陈婴于是以项氏世代为楚将、在楚地有名望为由，说服众人归附项梁。 [[14]](#note-14)

<a id="event-15"></a>

15. **渡过淮水后，黥布、蒲将军也加入。** 到下邳时，项梁所统兵力已被记为六七万人。项氏军不是只有最初的吴中子弟，而是不断吸收其他起兵集团。 [[15]](#note-15)

<a id="刘邦丢掉丰邑项梁则击败另一支楚军"></a>
<a id="sj008-feng"></a>

<a id="event-16"></a>

16. **刘邦击退围丰秦军，继续向薛进兵。** 刘邦先击退秦军，接着却丢掉了自己交给部下守的丰邑。 冬十月前后，他攻胡陵、方与后回丰，击败来围的监平，留雍齿守城，自己向薛进军。秦的郡守壮在薛战败，逃至戚，被刘邦的左司马取得并杀死。刘邦随后经亢父、方与继续活动。 曹参在这一阶段随军进击胡陵、方与，大败秦郡监军，向东攻薛并击薛城西的泗水守军，再取胡陵，转守方与；方与改投魏方后，又前往攻打。 周勃的起兵功状同记方与反叛后却敌，未另给这次小战月日，沿胡陵、方与战线对读。 [[16]](#note-16)

<a id="event-17"></a>

17. **十二月，周市用封侯和攻城威胁招降雍齿，雍齿转为魏守丰。** 刘邦回攻未下，又生了病，只得退回沛县。从此，他对雍齿和跟着反叛的丰邑子弟始终怀有怨气；多年后回乡复免时，还会记起此事。 曹参也参加攻丰，获赐七大夫爵；这项赏赐不等于当时已经攻下丰邑。 周勃也从攻丰。 [[17]](#note-17)

<a id="sj-048-L4222-01"></a>

<a id="event-18"></a>

18. **秦嘉另立景驹，公孙庆使齐求合兵，却被田儋杀死。** 秦嘉等听说陈胜军败出走，端月拥立景驹为楚王，率军到方与，准备攻击定陶城下秦军。二月，景驹一方派公孙庆去齐，希望合兵进攻；秦嘉此时已任上将军，实际掌握军队。田儋说，陈王虽败，生死未明，楚怎么能不先来商议便另立王？公孙庆反问，齐立王未曾问楚，楚为何必须问齐；况且楚首事，本应号令天下。田儋因此杀了公孙庆。[月表说明](#sj016-m02-note) [[18]](#note-18)

<a id="event-19"></a>

19. **刘邦去投景驹，在失败和夺城之间重新积聚兵力。** 他与东阳甯君一道活动，向西在萧附近作战失利，退回留地，再转攻砀，三日攻下，收兵到五六千人，继而取得下邑，又回头攻丰。途中张良加入；等听说项梁已到薛，刘邦带百余骑去求援。 曹参在砀东击败秦司马夷军，攻取砀、狐父及祁地善置，又从下邑以西进至虞地，攻击章邯的车骑。 张良原想投奔驻留的楚假王景驹，途中加入在下邳以西活动的刘邦军，被任为厩将。他屡用太公兵法进言，刘邦能够领会并采用；给别的人讲却不被理解，于是认为刘邦近乎天授，决定跟从。 周勃在这一阶段战砀东，回军留、萧，再取砀；攻下邑首先登城，获五大夫爵。其功录又列取蒙、虞，击章邯车骑记殿，定魏地，攻爰戚、东缗直到栗，并在啮桑先登；各项未独立记月，不都据本组月份定日。 [[19]](#note-19)

<a id="event-20"></a>

20. **项梁打掉景驹、秦嘉这一支，又给刘邦增兵。** 秦嘉在彭城东阻挡项梁，项梁以他背陈王、另立新王为由进攻。四月前后，秦嘉败退胡陵，还军再战而死，景驹逃至梁地后死去。项梁吞并其军队，给刘邦五千士卒和一批将领；刘邦终于攻回丰邑，雍齿逃魏。 [[20]](#note-20)

<a id="event-21"></a>

21. **对秦作战和内部处罚同样严酷。** 项梁所遣余樊君、朱鸡石与章邯军交战，余樊君战死，朱鸡石败归后被项梁处死。项羽另攻襄城，城中坚守，攻克后遭到大规模杀戮。项梁后来在薛召各路将领议事，刘邦也参加。 [[21]](#note-21)

<a id="六月再立一位楚怀王"></a>
<a id="sj-048-L4223-02"></a>

<a id="event-22"></a>

22. **范增劝项梁重立楚王后代。** 范增提醒项梁：大家归附项氏，还因为盼着恢复楚王后代。 范增是居鄛人，年已七十，平素在家而喜欢谋划。他指出，陈胜没有拥立楚后却自行称王，失去了一项可以借用的号召。许多楚地将领来归项梁，正因为项氏是楚国旧将门，盼他重立楚后。 [[22]](#note-22)

<a id="event-23"></a>

23. **六月，项梁等立熊心为楚怀王。** 项梁等在民间找到正在牧羊的熊心，立为楚怀王。 他是原楚怀王的孙子。刘邦在薛参与拥立，陈婴成为楚上柱国、封五县，陪同新王都盱台；项梁号武信君。用旧怀王的称号，是为了接住楚人对过去王室的感情。 [[23]](#note-23)

<a id="sj016-hancheng"></a>

<a id="event-24"></a>

24. **韩国旧王族的横阳君成也被拥立为韩王。** 张良劝项梁，既已立楚后，不妨再立有声望的韩国公子，扩大反秦盟友。项梁接受，韩成成为韩王，张良任韩司徒。两人率千余人向韩国故地发展，虽然一度取得几座城，却又被秦军夺回，只能在颍川一带来回活动。恢复王号，并不等于立即恢复整个旧韩国。[原格与说明](#sj016-m06-note) [[24]](#note-24)

<a id="夏秋之间齐楚先并肩后来又为人事争执"></a>

<a id="event-25"></a>

25. **夏秋之间，齐魏军败于临济，项梁、田荣等合兵救东阿。** 章邯在临济击败齐魏援军，魏咎自杀。 齐王田儋、周市等战败死亡；魏咎为城中人谈定投降条件后自焚。田荣收余部退东阿，章邯追围。项梁与田荣、龙且等会军，大破秦军，解除东阿之围。在临济败局以前，周市已往齐、楚求援；魏咎的弟弟魏豹则在败后走东阿，继续留在反秦阵营中。[四月求援](#sj016-m04-note) · [七月魏豹](#sj016-m07-note) 曹参攻爰戚、亢父时先登，升五大夫；北救东阿，又冲破章邯军阵，追敌到濮阳。 周勃在东阿城下破秦军，追至濮阳，又取甄城。 [[25]](#note-25)

<a id="event-26"></a>

26. **田荣回齐逐王，再要求楚赵杀掉投奔他们的齐人。** 田假逃楚，田角、田闲留赵，田荣改立田儋之子田市。他提出，楚杀田假、赵杀田角田闲，自己才派兵继续助楚。项梁不愿杀害穷途来投的邻国君主，赵也不愿出卖来人，齐遂不再增兵助楚。 [[26]](#note-26)

<a id="event-27"></a>

27. **刘邦与项羽一同作战，并非城城顺利。** 两人攻下城阳后屠城，又在濮阳以东败秦。秦军重整后依靠环城水障守濮阳，楚军转攻定陶，仍未攻下，便向西略地。八月在雍丘大破秦军、杀李由，随后攻外黄和陈留，也都没有攻克。 曹参参加攻定陶、取临济、南救雍丘，并在击败李由军时俘得秦军候一人。 周勃功录还记攻都关、定陶，袭宛朐而俘单父县令，夜取临济，攻张、前进至卷破敌，并在雍丘城下攻李由军；这些小战在功录中相连，未分别载明月份。 [[27]](#note-27)

<a id="sj016-rain"></a>

<a id="event-28"></a>

28. **从七月开始，连月的大雨伴随夏秋战事。** 军队不断移动、围城和救援时，还要面对阴雨天气。它与项梁后来战败处于同一时期，却不能只凭同年发生就认定是败因。 [[28]](#note-28)

<a id="sj016-weibao"></a>

<a id="event-29"></a>

29. **九月，魏豹自立为魏王。** 魏咎死后，魏的复国势力没有就此完全消失，王号由另一位魏国宗室继续维持。[原格与说明](#sj016-m09-note) [[29]](#note-29)

<a id="九月项梁战死楚王收回军权"></a>

<a id="event-30"></a>

30. **九月，章邯夜袭定陶，项梁战死。** 连续胜利使项梁轻敌，秦军却获得增援。 宋义劝他警惕将骄卒惰，项梁不听，派宋义使齐。章邯得到增兵后夜袭定陶，大破楚军，项梁战死。刘邦、项羽正在攻陈留，听说败讯后与吕臣军一起东退：吕臣驻彭城东，项羽驻城西，刘邦驻砀。 周勃随同退砀，其传以起沛至此计一岁二月；这个概数不直接换成现代十四个整月。 [[30]](#note-30)

<a id="event-31"></a>

31. **楚怀王从盱台迁到彭城，把项羽、吕臣的军队收归直接统辖。** 吕臣为司徒，父吕青为令尹；刘邦任砀郡长、封武安侯，继续带砀郡兵。项梁死后，不是项羽自然继承叔父全部权力，楚怀王也在重新建立控制。 曹参受执帛爵，号建成君，后来为戚公，仍属砀郡。 周勃在此阶段被授令职，本篇作虎贲令，另本作襄贲令、句盾令；随后以令从军平魏。 [[31]](#note-31)

<a id="event-32"></a>

32. **章邯北上攻赵，楚分出救赵和入关两路。** 这支秦军还包括长史司马欣、都尉董翳；他们的名字与章邯一同列入本年的追击记载。[卷015补核](#sj015-0208-note) 赵王歇、张耳退入巨鹿，陈馀在城外北方统兵；王离等围城，章邯在南面营建甬道、运送粮食。高陵君显称赞宋义能预见项梁败局，楚王任宋义为上将军，项羽为鲁公、次将，范增为末将，共同救赵。 [[32]](#note-32)

<a id="event-33"></a>

33. **刘邦则向西进军。** 怀王与诸将约“先入定关中者王之”。项羽想向西报秦仇，楚方老将却认为入关更需要争取苦秦百姓，于是让刘邦收陈胜、项梁散兵向西，让项羽随宋义北救赵。安阳停军、项羽杀宋义夺帅接在[下一年](bce-0207.md#sj007-songyi)。 [[33]](#note-33)

<a id="秦廷内部劝停工程反而导致下狱"></a>

<a id="event-34"></a>

34. **赵高让二世少见大臣，政事越来越由自己传达。** 他劝二世，年轻皇帝当面决断容易显露错误，不如深居宫中，由近臣办理。二世接受，公卿越来越难见到皇帝，征发和战争却没有减少。 [[34]](#note-34)

<a id="event-35"></a>

35. **冯去疾、李斯、冯劫请求减轻工役，反被追究别罪。** 三人指出反乱与戍守、漕运、转输、工程和重税有关，建议停阿房、减边戍输送。二世认为这是否定先帝事业，将三人交官吏治罪。冯去疾、冯劫自杀，李斯被施五刑、腰斩，家族受诛。 [[35]](#note-35)

<a id="sj056-entry-wei-event"></a>

36. **魏咎在临济时，陈平出仕为太仆，后来离魏。** 阳武户牖乡人陈平早年家贫好学，由哥哥陈伯耕田供其游学；嫂嫂讥他不治生计，陈伯因此逐妻。富人张负见他助丧勤谨、家虽僻陋而有长者来往，借给聘财、酒肉之资，把孙女嫁给他，交游由此更广。乡里社祭，他分肉公平，曾说有机会治理天下，也会如此。以上都是入仕前事，未有确年。魏咎归魏、在临济对秦作战期间，陈平辞兄随少年投魏，任太仆；进言不被采用，又遭谗言，便逃去。 [[36]](#sj056-entry-wei-note)

#### 在位六个月的回顾：旧友与用人

<a id="sj048-cite-025"></a>

**[本卷P019原字与完整白话](../../sources/摘录/史记-卷048-陈涉世家.md#p019)**

> 陳勝王凡六月。已為王，王陳。其故人嘗與庸耕者聞之，之陳，扣宮門曰：「吾欲見涉。」宮門令欲縛之。自辯數，乃置，不肯為通。陳王出，遮道而呼涉。陳王聞之，乃召見，載與俱歸。入宮，見殿屋帷帳，客曰：「夥頤！涉之為王沈沈者！」楚人謂多為夥，故天下傳之，夥涉為王，由陳涉始。客出入愈益發舒，言陳王故情。或說陳王曰：「客愚無知，顓妄言，輕威。」陳王斬之。諸陳王故人皆自引去，由是無親陳王者。陳王以朱房為中正，胡武為司過，主司群臣。諸將徇地，至，令之不是者，系而罪之，以苛察為忠。其所不善者，弗下吏，輒自治之。陳王信用之。諸將以其故不親附，此其所以敗也。

**本卷说明：** 本段是死亡叙事之后的在位回顾，涉及二世元年至二年的称王时段，不将所有故事定在腊月，也不当作死后事件。正文只用短句提示，完整白话与原文在此同号注配读；“此其所以败”属于本篇因果判断，不能排除具体战败及各地自立等其他因素。

**分层白话：** 陈胜称王总共六个月，都于陈。称王后，一个从前和他一起受雇耕田的朋友听说消息，来到陈，敲宫门说要见陈涉。守宫门的官吏想把他捆起来，他反复辩说旧交情，才被放开，却仍没人替他通报。陈胜出门时，这人拦住车驾，直接呼喊“涉”；陈胜听到后召见他，让他同乘车回宫。客人看见殿宇、帷帐，惊叹说：“真多呀，陈涉做王，宫室竟这样深广！”楚人把“多”叫“夥”，“夥涉为王”的话由此流传。客人出入宫中越发随便，常说陈胜从前的事情。有人进言，说他愚昧无知、专好妄言，会损伤君王威严。陈胜便杀了他，其他旧朋友也都自行离去，这些旧交从此没有人再亲近陈胜。

陈胜又任朱房为中正，胡武为司过，让他们监督群臣。诸将出外攻取地方，回来后若有行为不合二人心意，就被拘捕治罪；两人把苛刻纠察当成忠心。对于素来不喜欢的人，不交给司法官吏，自己便直接审治。陈胜相信并听任他们，诸将因此不肯亲附。本篇把这种用人和疏远旧交的做法列为失败原因。故事发生在跨二世元、二年的称王期间，原段写在死亡之后是回顾，既不是死后行动，也不能全部算作起兵前事。

**[本卷P020原字与完整白话](../../sources/摘录/史记-卷048-陈涉世家.md#p020)**

> 陳勝雖已死，其所置遣侯王將相竟亡秦，由涉首事也。

**分层白话：** 陈胜虽然已经死了，他设置、派遣的侯王将相最终推翻了秦。传记把这一结果追溯到陈涉首先起事，评价其发难之功。这里概括的是陈胜死后继续展开的亡秦过程，不是说秦在他遇害时已亡。汉代守冢与作者时代的奉祀另接[高祖祭祀对读](../bce-0200-0101/bce-0195.md#sj048-shouzhong-note)。

#### 唐代索隐序说：世家体例的争议

<a id="sj048-cite-027"></a>

**[本卷N001原字与完整白话](../../sources/摘录/史记-卷048-陈涉世家.md#n001)**

> 〔索隱〕勝立數月而死，無後，亦稱「系家」者，以其所遣王侯將相竟滅秦，爲首事故也。然時因擾攘起自匹夫，假託妖祥，一朝稱楚，曆年不永，勳業蔑如，繼之齊魯，曾何等級，可降爲列傳。

**分层白话：** 司马贞在篇首解释，陈胜称王数月便死，没有后嗣，却仍列为“世家”，理由在于他派出的诸侯王将相最终灭秦，自己又是首先发难的人。司马贞随后提出批评：陈胜乘天下扰攘，以平民起事，借妖异祥兆为号召，一朝称楚，延续时间很短，在他看来没有可与世家相称的长久功业；把这篇接在齐、鲁等世家之后，究竟属于什么等次？他主张可以降列“列传”。这是唐代注家对史书体例的评议，保留其先解释、后质疑的两层意思，不作为司马迁自述，更不把价值判断当作陈胜新发生的一件事。

#### 引贾谊论秦一：孝公与商君奠基

<a id="sj048-cite-029"></a>

**[本卷P022原字与完整白话](../../sources/摘录/史记-卷048-陈涉世家.md#p022)**

> 秦孝公據殽函之固，擁雍州之地，君臣固守，以窺周室。有席卷天下，包舉宇內，囊括四海之意，并吞八荒之心。當是時也，商君佐之，內立法度，務耕織，修守戰之備；外連衡而鬬諸侯。於是秦人拱手而取西河之外。

**本卷说明：** 这是汉代贾谊论秦的引文及白话，在陈胜结局同号注中作后世评论阅读，不作为二世二年发生的行动；跨代合叙和修辞比较均保留作者层次。

**分层白话：** 贾谊的议论先从秦孝公说起：孝公凭据崤山、函谷关的险固，拥有雍州之地，君臣固守根基，窥伺周王室，心怀席卷天下、包举宇内、囊括四海、并吞八荒的打算。当时商君辅佐他，对内建立法度，致力于耕田织布，修治防守和作战的装备；对外推行连横，让诸侯彼此争斗。这样，秦人就仿佛不费力气一般取得了西河以外的土地。这里从关塞、政令、生产与外交几方面描画秦的兴起，“拱手而取”是论说的修辞，不是说实际没有战争。

#### 引贾谊论秦二：秦扩张与诸侯合从失败

<a id="sj048-cite-030"></a>

**[本卷P023原字与完整白话](../../sources/摘录/史记-卷048-陈涉世家.md#p023)**

> 孝公既沒，惠文王、武王、昭王蒙故業，因遺策，南取漢中，西舉巴蜀，東割膏腴之地，收要害之郡。諸侯恐懼，會盟而謀弱秦。不愛珍器重寶肥饒之地，以致天下之士。合從締交，相與為一。當此之時，齊有孟嘗，趙有平原，楚有春申，魏有信陵：此四君者，皆明知而忠信，寬厚而愛人，尊賢而重士。約從連衡，兼韓、魏、燕、趙、宋、衛、中山之眾。於是六國之士有甯越、徐尚、蘇秦、杜赫之屬為之謀，齊明、周聚、陳軫、邵滑、樓緩、翟景、蘇厲、樂毅之徒通其意，吳起、孫臏、帶他、兒良、王廖、田忌、廉頗、趙奢之倫制其兵。嘗以什倍之地，百萬之師，仰關而攻秦。秦人開關而延敵，九國之師遁逃而不敢進。秦無亡矢遺鏃之費，而天下固已困矣。於是從散約敗，爭割地而賂秦。秦有餘力而制其獘，追亡逐北，伏尸百萬，流血漂櫓，因利乘便，宰割天下，分裂山河，彊國請服，弱國入朝。

**分层白话：** 孝公去世以后，惠文王、武王、昭王承接旧业，沿用既定策略，向南取得汉中，向西攻取巴蜀，向东割取肥沃之地，占有战略要郡。诸侯害怕，结盟商议削弱秦，不惜拿出珍贵器物、重宝和富饶土地，延揽天下人才，又合纵结交，联成一体。论说把齐孟尝君、赵平原君、楚春申君、魏信陵君并列，称他们明智忠信，宽厚爱人，尊敬贤者、重视士人；他们结成联盟，联合韩、魏、燕、赵、宋、卫、中山的兵众。为联盟筹谋的有甯越、徐尚、苏秦、杜赫，沟通各方意图的有齐明、周聚、陈轸、邵滑、楼缓、翟景、苏厉、乐毅，统率军队的有吴起、孙膑、带他、儿良、王廖、田忌、廉颇、赵奢。

这些国家曾凭十倍于秦的土地、百万军队，向高处的函谷关进攻。秦人打开关门迎敌，九国之师却退避逃走，不敢前进；秦似乎连一支箭、一枚箭头也没有损失，天下诸侯已经困顿。于是合纵瓦解、盟约破败，各国争着割地赂秦。秦乘其疲弱，用余力追击败军，使尸体遍野、血流漂盾，再利用有利形势宰割天下、分裂山河，强国求服，弱国入朝。这段把不同时代的四公子和谋士、将领聚在一幅对比图中，着重说明诸侯拥有人地之众仍不能制秦，不能把整张名单读成一次同时出征的参战名册。

#### 引贾谊论秦三：继世之业与始皇统治

<a id="sj048-cite-031"></a>

**[本卷P024原字与完整白话](../../sources/摘录/史记-卷048-陈涉世家.md#p024)**

> 施及孝文王、莊襄王，享國之日淺，國家無事。及至始皇，奮六世之餘烈，振長策而御宇內，吞二周而亡諸侯，履至尊而制六合，執敲樸以鞭笞天下，威振四海。南取百越之地，以為桂林、象郡，百越之君俛首系頸，委命下吏。乃使蒙恬北筑長城而守藩籬，卻匈奴七百餘里，胡人不敢南下而牧馬，士亦不敢貫弓而報怨。於是廢先王之道，燔百家之言，以愚黔首。墮名城，殺豪俊，收天下之兵聚之咸陽，銷鋒鍉，鑄以為金人十二，以弱天下之民。然後踐華為城，因河為池，據億丈之城，臨不測之谿以為固。良將勁弩，守要害之處，信臣精卒，陳利兵而誰何。天下已定，始皇之心，自以為關中之固，金城千里，子孫帝王萬世之業也。

**分层白话：** 到了孝文王、庄襄王，他们在位的时间都短，论说一笔带过为国家无事。及至始皇，奋发六世积累的功业，挥舞长鞭驾驭天下，吞并二周、消灭诸侯，登上至尊之位控制六合，以刑具鞭打天下，威势震动四海。他向南夺取百越之地，设桂林、象郡，使百越君长低头、颈系绳索，把命运交给秦的官吏；又令蒙恬向北筑长城作为屏障，击退匈奴七百余里，使胡人不敢南下牧马，勇士也不敢张弓报怨。

接着，他废去先王之道，焚烧诸子百家的著作，使百姓愚昧；毁坏名城，杀戮豪杰，收缴天下兵器集中到咸阳，熔毁锋刃，铸成十二个金属巨人，以削弱百姓的力量。然后把华山当城墙，把黄河当护城河，倚靠高得仿佛亿丈的险城，面对深不可测的山谷自固；以良将强弩守住要害，用可信的大臣和精锐士卒陈列利器，盘问过往的人。天下已经平定，始皇自以为关中有险固地势，千里如金城，可以让子孙世世代代做皇帝。全段把多代秦政和统治效果集中到始皇形象中，保留其夸张与论断，不把“七百余里”“亿丈”等当作本项目重新丈量的地理数据。

#### 引贾谊论秦四：陈涉起事与天下响应

<a id="sj048-cite-032"></a>

**[本卷P025原字与完整白话](../../sources/摘录/史记-卷048-陈涉世家.md#p025)**

> 始皇既沒，餘威振於殊俗。然而陳涉甕牖繩樞之子，甿隸之人，而遷徙之徒也。材能不及中人，非有仲尼、墨翟之賢，陶朱、猗頓之富也。躡足行伍之閒，俛仰仟佰之中，率罷散之卒，將數百之眾，轉而攻秦。斬木為兵，揭竿為旗，天下雲會響應，贏糧而景從，山東豪俊遂并起而亡秦族矣。

**本卷说明：** 主底本作“俛仰仟佰之中”，索隐以“仟佰”为千人、百人之长，白话据此解为在其手下周旋；注引《汉书》作“阡陌”，属于另一见证，未替换主字。

**分层白话：** 始皇死后，余威还震慑着风俗不同的边远地区。可是陈涉出身贫寒之家，住处以破瓮作窗、以绳索系门轴，是田间劳作、身份卑下而被征发迁徙的人。贾谊为突出力量反差，形容他的才能不及普通人，既没有孔子、墨翟那样的贤能，也没有陶朱公、猗顿那样的财富。他跻身兵卒行列，在千人、百人之长手下周旋，带着疲惫离散的士卒、几百人的部众，转而攻秦；砍木头当兵器，举竹竿当旗帜，天下人却像云聚、回声应和一样响应，背粮食、如影随形地跟从，崤山以东的豪杰遂一同兴起，最终灭掉秦皇室。这里贾谊贬低陈涉条件，是为了与下段秦的雄厚实力比较，不是本项目另作人物能力测定。

#### 引贾谊论秦五：力量悬殊与攻守异势

<a id="sj048-cite-033"></a>

**[本卷P026原字与完整白话](../../sources/摘录/史记-卷048-陈涉世家.md#p026)**

> 且天下非小弱也；雍州之地，殽函之固自若也。陳涉之位，非尊於齊、楚、燕、趙、韓、魏、宋、衛、中山之君也；鉏耰棘矜，非銛於句戟長鎩也；適戍之眾，非儔於九國之師也；深謀遠慮，行軍用兵之道，非及鄉時之士也。然而成敗異變，功業相反也。嘗試使山東之國與陳涉度長絜大，比權量力，則不可同年而語矣。然而秦以區區之地。致萬乘之權，抑八州而朝同列，百有餘年矣。然後以六合為家，殽函為宮。一夫作難而七廟隳，身死人手，為天下笑者，何也？仁義不施，而攻守之勢異也。

**分层白话：** 贾谊接着追问：秦所控制的天下并没有缩小、衰弱，秦所据雍州之地、崤山函谷的险固也仍然存在。陈涉的地位不比齐、楚、燕、赵、韩、魏、宋、卫、中山的君王尊贵，锄头、耰具、戟柄也不比钩戟长矛锋利；被征发戍守的队伍比不上九国大军，深谋远虑与行军用兵的本领，也赶不上从前那些人。可是胜败和功业竟完全倒转了。把山东诸侯同陈涉比较高下、权势和力量，原本远不能相提并论。秦从一块不大的土地起家，取得万乘之国的权势，压服八州，使原来的同列诸侯朝见自己，已经经营百余年；后来以六合为一家，以崤山函谷为宫墙，竟因一个人发难而七庙倾毁，君主死在别人手里，成为天下笑柄，原因究竟是什么？贾谊的结论是：秦没有施行仁义，而夺取天下与守住天下所处的形势已经不同。结论是汉代作者对秦亡的解释，不能当成陈胜起兵当天提出的政纲。

#### 四月｜并军、增兵与临济求救

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0208-04)项、汉两栏接[秦嘉景驹败亡及项梁增兵](#sj008-feng)，魏栏周市如齐楚求救已补在临济败局的前情。项栏入薛十余万与渡淮六七万为不同阶段的古书记数，不作精确增员核算；景驹死亡方式沿[较详本纪](#sj007-liang-note)。五月只有纪月数字与空栏，原格保留，不另造事件。

<a id="sj016-m06-note"></a>
<a id="六月复楚复韩与临济败局"></a>
#### 六月｜复楚、复韩与临济败局

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0208-06)楚、项、汉三栏同指[怀王拥立](#sj-048-L4223-02)，不重复三次；齐、魏栏同属临济战局，接[原注1](#sj006-059-note)。韩栏“韩王成始”补[韩成复国](#sj016-hancheng)，人物为韩国旧王族横阳君成，张良劝立及颍川游兵见[《留侯世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7055.md#ref-f12d1cd0e4f8b3)。不是后来荥阳守将韩王信，更不是大将韩信；此前已在本页出现的张良不再另造首次登场。

<a id="sj016-m07-note"></a>
<a id="七月陈婴连雨田假与魏豹"></a>
#### 七月｜陈婴、连雨、田假与魏豹

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0208-07)楚栏陈婴任柱国与[六月拥立段](#sj-048-L4223-02)互见，表系七月，本纪相接六月，授任月不强称无异说。项栏“大雨，三月不见星”与汉书自七月至九月连雨相合，补[本年天气](#sj016-rain)，不解释成天谴或精确气象统计。齐、汉栏的立田假、东阿救援、濮阳与城阳战事接夏秋主线；魏豹走东阿为[九月称王](#sj016-weibao)的前情。

<a id="sj016-m08-note"></a>
<a id="八月救东阿与雍丘"></a>
#### 八月｜救东阿与雍丘

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0208-08)项、齐栏救东阿与逐田假、立田市相连，汉栏雍丘杀李由接本页夏秋战事。[原注1](#sj006-059-note)保留六月／七月及本表八月的叙次差别，正文用阶段，不把东阿重复解围三次。项梁“有骄色”属于史书的人物解释。

<a id="sj016-m09-note"></a>
<a id="九月项梁败亡与魏豹"></a>
#### 九月｜项梁败亡与魏豹

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0208-09)楚、项、汉三栏接定陶败后迁彭城、退砀；齐栏田假与拒援是既有齐楚争执的延续，不能因再次出现就再逐田假一次。魏栏补[魏豹称王](#sj016-weibao)；“都平阳”先保留为表说，后来的前206年西魏封地仍另记，不仅凭一句便倒推当时全部疆界或移都日。

<a id="sj016-m09b-note"></a>
<a id="后九月分兵与授命"></a>
#### 后九月｜分兵与授命

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0208-09b)楚宋义、项羽鲁公次将、赵巨鹿受围、汉武安侯及先入关之约，合入本页年末重组与分兵，另接[翌年夺帅](bce-0207.md#sj007-songyi)。[汉书P016](../../sources/摘录/汉书-高帝纪.md#p016)也明确后九月，不将闰月吞入普通九月；册封、受命、实际到达战场不是同日。

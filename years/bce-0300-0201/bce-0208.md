# 公元前208年｜项梁聚兵又败亡，楚怀王重组军队，秦廷杀李斯

[← 公元前209年](bce-0209.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前207年 →](bce-0207.md)

**秦二世二年**

> 冬十月是古历年条的开端，不直接当作公历前208年10月。秦军一度连胜，反秦阵营不断重组；项梁成为重要统帅，却又在定陶战死。

<a id="冬季陈胜的部下与政权接连受挫"></a>
### 冬季：陈胜的部下与政权接连受挫
<a id="sj-048-L4210-02"></a>

<a id="event-1"></a>

1. **十月，葛婴返陈后被杀。** 他先前另立襄强，后来杀襄强、回陈报告，陈胜仍把他处死。杀襄强与葛婴自己的死亡分属不同月份。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4210) · [月表十月](../../sources/摘录/史记-条目原文.md#ref-sj-1492)。 [[1]](#note-1)

<a id="sj-048-L4211-02"></a>

<a id="event-2"></a>

2. **十一月，周文在连续败退后自杀。** 前一年退出关中的周文在曹阳停留二三月，又遭章邯进攻，退到渑池十余日，再次战败后自杀。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4211) · [月表十一月](../../sources/摘录/史记-条目原文.md#ref-sj-1493)。 [[2]](#note-2)

<a id="audit-wuguang-tianzang"></a>

<a id="event-3"></a>

3. **荥阳久攻不下，田臧等却先杀了自己的统帅吴广。** 听说周文军败，田臧认为秦军随时会到，应留下少量部队围城，主力西迎；他又指责吴广不懂用兵，不肯与他共谋，于是假传陈王命令杀吴广，把首级送给陈胜。陈胜没有追究，反而授田臧楚令尹印，命他为上将。 [[3]](#note-3)

<a id="event-4"></a>

4. **换将没有扭转战局。** 田臧留李归等守荥阳，自己带精兵到敖仓迎战，结果军败身死。章邯接着击破荥阳城外的李归军，李归等也死。邓说、伍徐的队伍随后相继被秦军打散，两人逃回陈，陈胜又把邓说处死。秦军逼近陈地以前，陈胜派出的几路力量已经接连瓦解。 [[4]](#note-4)

<a id="sj-048-L4214-02"></a>

<a id="event-5"></a>

5. **十二月，魏咎终于从陈回到魏地。** 周市拒绝自己称王，坚持迎立魏国后人魏咎。经过反复请求，陈胜放魏咎回去，魏咎正式在魏地就位，周市任相。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4214) · [元年九月月表](../../sources/摘录/史记-条目原文.md#ref-sj-1491) · [本年十二月](../../sources/摘录/史记-条目原文.md#ref-sj-1494)。 [[5]](#note-5)

<a id="sj-048-L4218-01"></a>

<a id="event-6"></a>

6. **秦军逼近陈，蔡赐、张贺先后战死。** 蔡赐被杀，张贺与陈胜一方在陈西迎战，又被击败，张贺死亡，陈胜离开陈地。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4218) · [月表](../../sources/摘录/史记-条目原文.md#ref-sj-1494)。 [[6]](#note-6)

<a id="sj-048-L4219-01"></a>

<a id="event-7"></a>

7. **腊月，陈胜在下城父被自己的车夫杀死。** 庄贾杀陈胜后降秦。陈胜后来葬在砀，谥为隐王，安葬与定谥未另有确日。他死了，反抗却没有因此结束。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4219) · [月表十二月](../../sources/摘录/史记-条目原文.md#ref-sj-1494)。 [[7]](#note-7)

<a id="sj-048-L4220-01"></a>

<a id="event-8"></a>

8. **吕臣组织苍头军，收复陈并杀庄贾。** 他从新阳起兵，重新夺回陈地，为陈胜报仇。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4220)。 [[8]](#note-8)

<a id="sj-048-L4221-02"></a>

<a id="event-9"></a>

9. **宋留听说陈胜死后退兵，投降仍被处死。** 沿途城邑重新归秦，不让他进入；宋留最后降秦，被送到咸阳车裂。收死讯、退兵、投降和处刑是连续阶段，不全部定在腊月。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4221) · [月表](../../sources/摘录/史记-条目原文.md#ref-sj-1494)。 [[9]](#note-9)

<a id="sj-048-L4223-01"></a>

<a id="event-10"></a>

10. **陈地还在反复争夺。** 秦左右校再攻陈，使吕臣一度退却。后来他与黥布等联合，在青波击败秦军，又收陈地。这与先前杀庄贾是两次前后相接的行动。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4223)。 [[10]](#note-10)

<a id="audit-zhao-succession"></a>
<a id="赵地也发生内乱武臣死后改立赵歇"></a>
### 赵地也发生内乱，武臣死后改立赵歇

<a id="event-11"></a>

11. **冬季，赵将李良袭击邯郸，杀死赵王武臣。** 张耳、陈馀得到消息，得以逃脱。他们收集散兵反击，打败李良；李良转而投奔章邯。前一年刚建立的赵政权，尚未在秦军进攻中覆亡，先经历了一次内部兵变。 [[11]](#note-11)

<a id="event-12"></a>

12. **正月，张耳、陈馀找到赵国旧王族后人赵歇，拥立为赵王，居信都。** 两人是外来者，需要借赵国旧王室的名义招集当地力量。到本年后段秦军北上时，退入巨鹿的赵王已经是赵歇，不再是前一年称王的武臣。 [[12]](#note-12)

<a id="项梁从江东出来队伍越聚越大"></a>
### 项梁从江东出来，队伍越聚越大
<a id="sj007-liang-west"></a>

<a id="event-13"></a>

13. **召平带来一个并非真正来自陈王的任命。** 召平替陈胜攻广陵未下，听说陈王败走、秦军将至，便渡江假传陈王命令，拜项梁为楚上柱国，催他西进。项梁带着八千人渡江西行。[卷007 P004](../../sources/摘录/史记-卷007-项羽本纪.md#p004)。 [[13]](#note-13)

<a id="event-14"></a>

14. **东阳的陈婴不肯自己称王，把部队带来归项梁。** 陈婴原是县里令史，向来谨慎守信。当地年轻人杀县令后，推他为首，队伍发展到二万人，又想拥他为王。陈婴母亲劝他：家里本来没有显赫背景，骤得大名不稳，不如依附有声望的人，成功仍能获封，失败也容易脱身。陈婴于是以项氏世代为楚将、在楚地有名望为由，说服众人归附项梁。[卷007 P004](../../sources/摘录/史记-卷007-项羽本纪.md#p004)。 [[14]](#note-14)

<a id="event-15"></a>

15. **渡过淮水后，黥布、蒲将军也加入。** 到下邳时，项梁所统兵力已被记为六七万人。项氏军不是只有最初的吴中子弟，而是不断吸收其他起兵集团。[卷007 P004](../../sources/摘录/史记-卷007-项羽本纪.md#p004)。 [[15]](#note-15)

<a id="刘邦丢掉丰邑项梁则击败另一支楚军"></a>
### 刘邦丢掉丰邑，项梁则击败另一支楚军
<a id="sj008-feng"></a>

<a id="event-16"></a>

16. **刘邦先击退秦军，接着却丢掉了自己交给部下守的丰邑。** 冬十月前后，他攻胡陵、方与后回丰，击败来围的监平，留雍齿守城，自己向薛进军。秦的郡守壮在薛战败，逃至戚，被刘邦的左司马取得并杀死。刘邦随后经亢父、方与继续活动。[《汉书》P012](../../sources/摘录/汉书-高帝纪.md#p012) · [卷008 P010](../../sources/摘录/史记-卷008-高祖本纪.md#p010)。 [[16]](#note-16)

<a id="event-17"></a>

17. **十二月，周市用封侯和攻城威胁招降雍齿，雍齿转为魏守丰。** 刘邦回攻未下，又生了病，只得退回沛县。从此，他对雍齿和跟着反叛的丰邑子弟始终怀有怨气；多年后回乡复免时，还会记起此事。[《汉书》P012](../../sources/摘录/汉书-高帝纪.md#p012) · [卷008 P010](../../sources/摘录/史记-卷008-高祖本纪.md#p010)。 [[17]](#note-17)

<a id="sj-048-L4222-01"></a>

<a id="event-18"></a>

18. **秦嘉另立景驹，田儋不承认。** 端月，景驹被立为楚王；二月公孙庆使齐求兵，田儋认为陈胜生死未明，楚又未先来商议，拒绝承认，杀掉使者。[卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4222) · [月表端月](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0208-01) · [二月](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0208-02)。秦嘉在二月已任上将军，掌握这一政权的军队；拥立者与名义上的楚王并不是同一人。[月表说明](#sj016-m02-note) [[18]](#note-18)

<a id="event-19"></a>

19. **刘邦去投景驹，在失败和夺城之间重新积聚兵力。** 他与东阳甯君一道活动，向西在萧附近作战失利，退回留地，再转攻砀，三日攻下，收兵到五六千人，继而取得下邑，又回头攻丰。途中张良加入；等听说项梁已到薛，刘邦带百余骑去求援。[《汉书》P013](../../sources/摘录/汉书-高帝纪.md#p013) · [卷008 P010](../../sources/摘录/史记-卷008-高祖本纪.md#p010)。 [[19]](#note-19)

<a id="event-20"></a>

20. **项梁打掉景驹、秦嘉这一支，又给刘邦增兵。** 秦嘉在彭城东阻挡项梁，项梁以他背陈王、另立新王为由进攻。四月前后，秦嘉败退胡陵，还军再战而死，景驹逃至梁地后死去。项梁吞并其军队，给刘邦五千士卒和一批将领；刘邦终于攻回丰邑，雍齿逃魏。[《汉书》P013](../../sources/摘录/汉书-高帝纪.md#p013) · [卷007 P005](../../sources/摘录/史记-卷007-项羽本纪.md#p005)。 [[20]](#note-20)

<a id="event-21"></a>

21. **对秦作战和内部处罚同样严酷。** 项梁所遣余樊君、朱鸡石与章邯军交战，余樊君战死，朱鸡石败归后被项梁处死。项羽另攻襄城，城中坚守，攻克后遭到大规模杀戮。项梁后来在薛召各路将领议事，刘邦也参加。[卷007 P005](../../sources/摘录/史记-卷007-项羽本纪.md#p005)。 [[21]](#note-21)

<a id="六月再立一位楚怀王"></a>
### 六月，再立一位楚怀王
<a id="sj-048-L4223-02"></a>

<a id="event-22"></a>

22. **范增提醒项梁：大家归附项氏，还因为盼着恢复楚王后代。** 范增是居鄛人，年已七十，平素在家而喜欢谋划。他指出，陈胜没有拥立楚后却自行称王，失去了一项可以借用的号召。许多楚地将领来归项梁，正因为项氏是楚国旧将门，盼他重立楚后。[卷007 P006](../../sources/摘录/史记-卷007-项羽本纪.md#p006)。 [[22]](#note-22)

<a id="event-23"></a>

23. **项梁等在民间找到正在牧羊的熊心，立为楚怀王。** 他是原楚怀王的孙子。刘邦在薛参与拥立，陈婴成为楚上柱国、封五县，陪同新王都盱台；项梁号武信君。用旧怀王的称号，是为了接住楚人对过去王室的感情。[《汉书》P014](../../sources/摘录/汉书-高帝纪.md#p014) · [卷048](../../sources/摘录/史记-条目原文.md#ref-sj-4223) · [月表六月](../../sources/摘录/史记-条目原文.md#ref-sj-1500) · [卷007 P006](../../sources/摘录/史记-卷007-项羽本纪.md#p006) · [卷008 P011](../../sources/摘录/史记-卷008-高祖本纪.md#p011)。 [[23]](#note-23)

<a id="sj016-hancheng"></a>

<a id="event-24"></a>

24. **韩国旧王族的横阳君成也被拥立为韩王。** 张良劝项梁，既已立楚后，不妨再立有声望的韩国公子，扩大反秦盟友。项梁接受，韩成成为韩王，张良任韩司徒。两人率千余人向韩国故地发展，虽然一度取得几座城，却又被秦军夺回，只能在颍川一带来回活动。恢复王号，并不等于立即恢复整个旧韩国。[原格与说明](#sj016-m06-note) [[24]](#note-24)

<a id="夏秋之间齐楚先并肩后来又为人事争执"></a>
### 夏秋之间，齐楚先并肩，后来又为人事争执

<a id="event-25"></a>

25. **章邯在临济击败齐魏援军，魏咎自杀。** 齐王田儋、周市等战败死亡；魏咎为城中人谈定投降条件后自焚。田荣收余部退东阿，章邯追围。项梁与田荣、龙且等会军，大破秦军，解除东阿之围。 · [《汉书》P014](../../sources/摘录/汉书-高帝纪.md#p014) · [卷007 P007](../../sources/摘录/史记-卷007-项羽本纪.md#p007)。在临济败局以前，周市已往齐、楚求援；魏咎的弟弟魏豹则在败后走东阿，继续留在反秦阵营中。[四月求援](#sj016-m04-note) · [七月魏豹](#sj016-m07-note) [[25]](#note-25)

<a id="event-26"></a>

26. **田荣回齐逐王，再要求楚赵杀掉投奔他们的齐人。** 田假逃楚，田角、田闲留赵，田荣改立田儋之子田市。他提出，楚杀田假、赵杀田角田闲，自己才派兵继续助楚。项梁不愿杀害穷途来投的邻国君主，赵也不愿出卖来人，齐遂不再增兵助楚。[卷007 P007](../../sources/摘录/史记-卷007-项羽本纪.md#p007)。 [[26]](#note-26)

<a id="event-27"></a>

27. **刘邦与项羽一同作战，并非城城顺利。** 两人攻下城阳后屠城，又在濮阳以东败秦。秦军重整后依靠环城水障守濮阳，楚军转攻定陶，仍未攻下，便向西略地。八月在雍丘大破秦军、杀李由，随后攻外黄和陈留，也都没有攻克。[《汉书》P015—P016](../../sources/摘录/汉书-高帝纪.md#p015) · [卷007 P007—P008](../../sources/摘录/史记-卷007-项羽本纪.md#p007) · [卷008 P011](../../sources/摘录/史记-卷008-高祖本纪.md#p011)。 [[27]](#note-27)

<a id="sj016-rain"></a>

<a id="event-28"></a>

28. **从七月开始，连月的大雨伴随夏秋战事。** 军队不断移动、围城和救援时，还要面对阴雨天气。它与项梁后来战败处于同一时期，却不能只凭同年发生就认定是败因。 [[28]](#note-28)

<a id="sj016-weibao"></a>

<a id="event-29"></a>

29. **九月，魏豹自立为魏王。** 魏咎死后，魏的复国势力没有就此完全消失，王号由另一位魏国宗室继续维持。[原格与说明](#sj016-m09-note) [[29]](#note-29)

<a id="九月项梁战死楚王收回军权"></a>
### 九月，项梁战死，楚王收回军权

<a id="event-30"></a>

30. **连续胜利使项梁轻敌，秦军却获得增援。** 宋义劝他警惕将骄卒惰，项梁不听，派宋义使齐。章邯得到增兵后夜袭定陶，大破楚军，项梁战死。刘邦、项羽正在攻陈留，听说败讯后与吕臣军一起东退：吕臣驻彭城东，项羽驻城西，刘邦驻砀。[《汉书》P016](../../sources/摘录/汉书-高帝纪.md#p016) · [卷007 P008](../../sources/摘录/史记-卷007-项羽本纪.md#p008)。 [[30]](#note-30)

<a id="event-31"></a>

31. **楚怀王从盱台迁到彭城，把项羽、吕臣的军队收归直接统辖。** 吕臣为司徒，父吕青为令尹；刘邦任砀郡长、封武安侯，继续带砀郡兵。项梁死后，不是项羽自然继承叔父全部权力，楚怀王也在重新建立控制。[《汉书》P016](../../sources/摘录/汉书-高帝纪.md#p016) · [卷007 P010](../../sources/摘录/史记-卷007-项羽本纪.md#p010)。 [[31]](#note-31)

<a id="event-32"></a>

32. **章邯北上攻赵，楚分出救赵和入关两路。** 这支秦军还包括长史司马欣、都尉董翳；他们的名字与章邯一同列入本年的追击记载。[卷015补核](#sj015-0208-note) 赵王歇、张耳退入巨鹿，陈馀在城外北方统兵；王离等围城，章邯在南面营建甬道、运送粮食。高陵君显称赞宋义能预见项梁败局，楚王任宋义为上将军，项羽为鲁公、次将，范增为末将，共同救赵。[卷007 P009—P011](../../sources/摘录/史记-卷007-项羽本纪.md#p009) · [《汉书》P017](../../sources/摘录/汉书-高帝纪.md#p017)。 [[32]](#note-32)

<a id="event-33"></a>

33. **刘邦则向西进军。** 怀王与诸将约“先入定关中者王之”。项羽想向西报秦仇，楚方老将却认为入关更需要争取苦秦百姓，于是让刘邦收陈胜、项梁散兵向西，让项羽随宋义北救赵。安阳停军、项羽杀宋义夺帅接在[下一年](bce-0207.md#sj007-songyi)。[《汉书》P018](../../sources/摘录/汉书-高帝纪.md#p018) · [卷008 P012](../../sources/摘录/史记-卷008-高祖本纪.md#p012)。 [[33]](#note-33)

<a id="秦廷内部劝停工程反而导致下狱"></a>
### 秦廷内部：劝停工程，反而导致下狱

<a id="event-34"></a>

34. **赵高让二世少见大臣，政事越来越由自己传达。** 他劝二世，年轻皇帝当面决断容易显露错误，不如深居宫中，由近臣办理。二世接受，公卿越来越难见到皇帝，征发和战争却没有减少。 [[34]](#note-34)

<a id="event-35"></a>

35. **冯去疾、李斯、冯劫请求减轻工役，反被追究别罪。** 三人指出反乱与戍守、漕运、转输、工程和重税有关，建议停阿房、减边戍输送。二世认为这是否定先帝事业，将三人交官吏治罪。冯去疾、冯劫自杀，李斯被施五刑、腰斩，家族受诛。 [[35]](#note-35)

#### 七月｜陈婴、连雨、田假与魏豹

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0208-07)楚栏陈婴任柱国与[六月拥立段](#sj-048-L4223-02)互见，表系七月，本纪相接六月，授任月不强称无异说。项栏“大雨，三月不见星”与汉书自七月至九月连雨相合，补[本年天气](#sj016-rain)，不解释成天谴或精确气象统计。齐、汉栏的立田假、东阿救援、濮阳与城阳战事接夏秋主线；魏豹走东阿为[九月称王](#sj016-weibao)的前情。

<a id="sj016-m08-note"></a>
<a id="八月救东阿与雍丘"></a>
#### 八月｜救东阿与雍丘

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0208-08)项、齐栏救东阿与逐田假、立田市相连，汉栏雍丘杀李由接本页夏秋战事。[原注1](#sj006-059-note)保留六月／七月及本表八月的叙次差别，正文用阶段，不把东阿重复解围三次。项梁“有骄色”属于史书的人物解释。

<a id="sj016-m09-note"></a>
<a id="九月项梁败亡与魏豹"></a>
#### 九月｜项梁败亡与魏豹

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0208-09)楚、项、汉三栏接定陶败后迁彭城、退砀；齐栏田假与拒援是既有齐楚争执的延续，不能因再次出现就再逐田假一次。魏栏补[魏豹称王](#sj016-weibao)；“都平阳”先保留为表说，后来的前206年西魏封地仍另记，不仅凭一句便倒推当时全部疆界或移都日。

<a id="sj016-m09b-note"></a>
<a id="后九月分兵与授命"></a>
#### 后九月｜分兵与授命

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0208-09b)楚宋义、项羽鲁公次将、赵巨鹿受围、汉武安侯及先入关之约，合入本页年末重组与分兵，另接[翌年夺帅](bce-0207.md#sj007-songyi)。[汉书P016](../../sources/摘录/汉书-高帝纪.md#p016)也明确后九月，不将闰月吞入普通九月；册封、受命、实际到达战场不是同日。

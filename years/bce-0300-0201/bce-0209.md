<a id="岁首的赦令与营建"></a>
### 岁首的赦令与营建
<a id="sj015-0209-amnesty"></a>

<a id="event-1"></a>

1. **二世元年开头，朝廷颁布大赦，又营建兔园。** 十月戊寅，秦廷大赦罪人；十一月又兴建兔园。岁首的大赦早于本年七月爆发的反秦起兵，不能说成朝廷已经在赦免后来参加陈胜军的人。 [[1]](#note-1)

<a id="年初二世强调自己承接始皇的事业"></a>
### 年初，二世强调自己承接始皇的事业

<a id="event-2"></a>

2. **赵高成为郎中令，二世重新安排宗庙礼制。** 二世增加始皇寝庙及山川祭祀，命群臣议定尊崇始皇庙。新的安排以始皇庙为帝者祖庙，按天子七庙的说法调整先王宗庙，皇帝又恢复自称“朕”。 [[2]](#note-2)

<a id="event-3"></a>

3. **春天，二世带李斯东巡，在始皇旧刻石上增加诏辞。** 他要向郡县显示新皇帝的威势，也担心旧碑只称“皇帝”，后人把始皇的功业算到继任者身上，于是补刻，明确旧功出于始皇。巡行涉及碣石、会稽、辽东等地，四月回到咸阳。 [[3]](#note-3)

<a id="宗室遭清洗阿房工程又恢复了"></a>
### 宗室遭清洗，阿房工程又恢复了

<a id="event-4"></a>

4. **二世和赵高担心旧臣、诸公子不服，展开清算。** 大臣、公子及近侍官员受到牵连；六名公子在杜被处死。将闾兄弟三人被囚内宫，接到赐死命令，要求知道罪名，未获解释，最后拔剑自杀。宗室恐惧，劝谏容易被当作诽谤，官员更不愿直言。 [[4]](#note-4)

<a id="event-5"></a>

5. **二世下令继续修阿房宫。** 始皇死时，工程劳力曾调往骊山葬事；二世认为放弃阿房就等于承认先帝兴工有错。他又征五万材士屯卫咸阳，教习射猎狗马禽兽。需要供养的人更多，郡县被要求转运粮草，运送者自带口粮，不得取食咸阳三百里内的谷物。 [[5]](#note-5)

<a id="登场前事陈胜原来也是替人耕作的人"></a>
### 登场前事｜陈胜原来也是替人耕作的人

<a id="event-6"></a>

6. **登场前事｜陈胜原来也是替人耕作的人。** 陈胜字涉，早年曾与人佣耕。史书用“苟富贵，无相忘”及燕雀鸿鹄的故事表现他的抱负。这是起兵以前的经历，不把未经确年的谈话另算作本年事件。[早年原文](../../sources/摘录/史记-条目原文.md#ref-sj-4206) · [原未定年记录](../../meta/考证/史记-未定年与跨年材料.md#sj-048-L4206-01)。 [[6]](#note-6)

<a id="sj-048-L4207-01"></a>

<a id="event-7"></a>

7. **九百名戍卒在大泽乡遇雨误期，陈胜、吴广谋划反抗。** 他们奉命去渔阳戍守，途中道路被阻。陈胜、吴广利用士卒对误期惩罚的恐惧，准备借扶苏、项燕的名义号召群众。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4207) · [月表七月](../../sources/摘录/史记-条目原文.md#ref-sj-1489)。 [[7]](#note-7)

<a id="sj-048-L4207-02"></a>

<a id="event-8"></a>

8. **他们有意制造“天意”的气氛。** 问卜后，陈胜把文字藏入鱼腹，吴广又在夜间仿狐鸣呼喊，让士卒相信陈胜将称王。这是参与者安排的造势，不是真有神明发出命令。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4207)。 [[8]](#note-8)

<a id="sj-048-L4208-01"></a>

<a id="event-9"></a>

9. **起事者杀掉押送军官，推陈胜、吴广为首。** 两名尉被杀后，陈胜为将军，吴广为都尉，队伍公开反秦。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4208)。 [[9]](#note-9)

<a id="sj-048-L4208-02"></a>

<a id="event-10"></a>

10. **队伍由大泽乡、蕲一路向陈推进。** 经过铚、酂、苦、柘、谯等地，陈胜又派葛婴向东。到陈时，所报兵力已增至战车六七百乘、骑兵千余、步卒数万，远不是最初九百人的规模。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4208)。 [[10]](#note-10)

<a id="sj-048-L4208-03"></a>

<a id="event-11"></a>

11. **陈县失守后，陈胜称王，号为“张楚”。** 陈守、陈令不在，守丞出战死亡；当地父老劝陈胜称王，军事反抗发展为公开与秦相争的政权。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4208) · [卷006 P058](../../sources/摘录/史记-卷006-秦始皇本纪.md#p058)。 [[11]](#note-11)

<a id="陈王分遣部队响应者也开始各自作主"></a>
### 陈王分遣部队，响应者也开始各自作主
<a id="sj-048-L4209-01"></a>

<a id="event-12"></a>

12. **吴广西进，武臣等北略赵地，邓宗前往九江。** 吴广代理王事，攻荥阳；武臣、张耳、陈馀向赵地发展。各郡县也有人杀长吏响应，陈胜难以直接统辖所有新起的力量。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4209) · [月表七月](../../sources/摘录/史记-条目原文.md#ref-sj-1489) · [八月](../../sources/摘录/史记-条目原文.md#ref-sj-1490)。 [[12]](#note-12)

<a id="sj-048-L4210-03"></a>

<a id="event-13"></a>

13. **荥阳没有轻易攻下。** 三川守李由守城，吴广长期进攻仍未奏效；陈胜又任上蔡人蔡赐为上柱国，任命的具体月份未另记。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4210) · [月表](../../sources/摘录/史记-条目原文.md#ref-sj-1491)。 [[13]](#note-13)

<a id="sj-048-L4210-01"></a>

<a id="event-14"></a>

14. **葛婴另立襄强，得知陈胜称王后又将他杀死。** 葛婴在东城另立襄强为楚王，后来杀襄强，准备返陈报告。月表把另立、杀襄强分在八、九月，葛婴自己被陈胜处死则在下一年十月。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4210) · [后续](bce-0208.md#sj-048-L4210-02)。 [[14]](#note-14)

<a id="sj-048-L4217-01"></a>

<a id="event-15"></a>

15. **秦嘉等人不接受陈胜派来的统帅。** 秦嘉等围攻郯，陈胜派武平君畔统领他们，秦嘉却自立为大司马，杀死武平君畔。这是起兵初期的回叙，不因为列传排得靠后，就改作后来发生。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4217)。 [[15]](#note-15)

<a id="sj-048-L4221-01"></a>

<a id="event-16"></a>

16. **宋留奉命走南阳、武关一线。** 陈胜最初让宋留平定南阳，再进武关；后来陈胜死讯传来，宋留才改变行动。退兵、投降、被杀见下一年，不提前写死陈胜。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4221) · [后续](bce-0208.md#sj-048-L4221-02)。 [[16]](#note-16)

<a id="八九月赵燕齐纷纷出现新王"></a>
### 八九月，赵、燕、齐纷纷出现新王
<a id="sj-048-L4212-01"></a>

<a id="event-17"></a>

17. **八月，武臣在赵地自立为王。** 张耳、陈馀辅佐他。陈胜愤怒，拘押武臣等人的家属；蔡赐劝他承认现实，不要再树新敌，陈胜才改为承认，并要求赵军向西攻秦。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4212) · [月表八月](../../sources/摘录/史记-条目原文.md#ref-sj-1490)。 [[17]](#note-17)

<a id="sj-048-L4212-02"></a>

<a id="event-18"></a>

18. **赵军没有立即向西。** 张耳、陈馀主张先扩展赵自己的地盘，武臣转而北略，让韩广去燕地。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4212) · [月表八月](../../sources/摘录/史记-条目原文.md#ref-sj-1490) · [九月](../../sources/摘录/史记-条目原文.md#ref-sj-1491)。 [[18]](#note-18)

<a id="sj-048-L4213-01"></a>

<a id="event-19"></a>

19. **九月，韩广在燕地称王。** 他起初担心母亲还在赵，后来仍接受拥立；母亲与家属随后获送到燕，几个步骤不擅自定在同一天。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4213) · [月表九月](../../sources/摘录/史记-条目原文.md#ref-sj-1491)。 [[19]](#note-19)

<a id="sj-048-L4214-01"></a>

<a id="event-20"></a>

20. **田儋在狄起兵，成为齐王。** 他与宗族力量夺取当地政权，向齐地发展。田儋是狄人，田氏宗族在当地有力量；田荣是他的从弟，田横又是田荣的弟弟。月表十月还有回顾文字，不表示田儋两个月各称王一次。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4214) · [月表九月](../../sources/摘录/史记-条目原文.md#ref-sj-1491) · [十月](../../sources/摘录/史记-条目原文.md#ref-sj-1492) · [亲属与纪月说明](#sj016-m09-note)。 [[20]](#note-20)

<a id="周文逼到关中秦廷却曾不肯听坏消息"></a>
### 周文逼到关中，秦廷却曾不肯听坏消息
<a id="sj-048-L4211-01"></a>

<a id="event-21"></a>

21. **九月前后，周文军到达戏，章邯以骊山刑徒迎击。** 周文自称熟悉兵事，受陈胜任用，沿途扩充队伍，推进到关中。秦来不及从附近县重新征兵，章邯提出赦免骊山刑徒、授予武器。周文战败退出关中，后来在曹阳、渑池继续败退。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4211) · [月表九月](../../sources/摘录/史记-条目原文.md#ref-sj-1491) · [卷006 P059](../../sources/摘录/史记-卷006-秦始皇本纪.md#p059)。 [[21]](#note-21)

<a id="event-22"></a>

22. **此前报反乱的使者，反而被二世交给官吏治罪。** 后来的使者便改称只是小股盗贼，地方官很快可以抓完，二世反而高兴。叛乱越发展，朝廷接收到的信息却越可能失真。 [[22]](#note-22)

<a id="九月项梁项羽夺取会稽郡的政权"></a>
### 九月，项梁、项羽夺取会稽郡的政权
<a id="sj007-wu"></a>

<a id="event-23"></a>

23. **会稽郡守也想起兵，却把项梁请到了自己面前。** 郡守通听说长江以西已经反秦，想让项梁和桓楚领兵。项梁说桓楚正在逃亡，只有自己的侄子项羽知道下落，借此让郡守召项羽入府。 [[23]](#note-23)

<a id="event-24"></a>

24. **项羽进府拔剑杀守，项梁拿走首级与印绶。** 府中人惊乱，项羽又杀死多人，压服其余人。项梁召集熟悉的豪强官吏，说明起兵之意，再派人招集下县，得到八千精兵。项梁自任会稽守，项羽为裨将，随后攻略所属县地。 [[24]](#note-24)

<a id="event-25"></a>

25. **过去办事的表现，此时成了挑选军官的依据。** 项梁把当地豪杰安排为校尉、候、司马；有人问为何没被任用，他指出此人先前办一件丧事时没有完成交办的工作。此前在吴中积累的人脉和识人经验，转成了组织军队的基础。 [[25]](#note-25)

    叔侄的出身、求学、避仇与观始皇经历，见[前210年登场前事](bce-0210.md#sj007-first)。起兵以后渡江西进、兼并其他队伍是下一阶段，不一律归在本年九月。

<a id="sj008-liuji"></a>
<a id="登场前事先认识还叫刘季的刘邦"></a>
### 登场前事：先认识还叫“刘季”的刘邦

<a id="event-26"></a>

26. **刘邦出身丰邑中阳里，成年后在秦做过泗水亭长。** 父亲被称为太公，母亲被称为刘媪。他平常不大经营家里的产业，喜欢饮酒，与同僚相处也不拘礼数，常向王媪、武负两家赊酒，年终又得到免债。他当亭长时以竹皮制冠，特地让部下去薛地加工，后来显贵仍常戴，形成所谓“刘氏冠”。 [[26]](#note-26)

<a id="event-27"></a>

27. **他也曾到咸阳服役，看见秦皇帝的排场，感叹“大丈夫当如此”。** 这次观看没有可靠的年份，更不能因为项羽曾看始皇巡行，就认定两人在同一条路上、同一天看见皇帝。 [[27]](#note-27)

<a id="event-28"></a>

28. **吕家婚姻起于一场宴会。** 吕公避仇来沛，与县令交好，地方官吏豪杰前去庆贺，萧何负责安排宾客。刘邦没有带钱，却报上万钱贺礼，得到吕公特别接待，还坦然坐上席。吕公喜欢相人，认为他前途不凡，酒后留下谈话，决定把女儿嫁给他。吕媪很不满意，但婚事还是成了；这位吕氏后来就是吕后。 [[28]](#note-28)

<a id="event-29"></a>

29. **一次押送刑徒，让亭长变成逃亡者。** 刘邦替县里押人去骊山，途中逃走的人越来越多。他估计走到目的地时也剩不了多少，便在丰西泽中饮酒，夜间放掉剩下的人，自己也决定逃走。十余名壮士愿意留下跟随，后来他在芒砀山泽藏身，逐渐吸引沛县子弟。 [[29]](#note-29)

    出生时母亲梦神、父亲见龙，醉卧时身上现龙，田间老父预言吕氏母子将贵，斩白蛇后出现“赤帝子”“白帝子”的解释，以及吕后借云气找到藏身的刘邦，都是开国叙事中的神异材料。它们在此保留为传说及声望形成的故事，不写成已经证实的超自然事实，也不由此制造刘邦的出生年或每一段亡命经历的确年。[《汉书》P001—P008](../../sources/摘录/汉书-高帝纪.md#p001) · [斩蛇互见P007](../../sources/摘录/汉书-高帝纪.md#p007) · [卷008 P001—P007](../../sources/摘录/史记-卷008-高祖本纪.md#p001)。

<a id="九月沛县从响应起事到推举沛公"></a>
### 九月，沛县从响应起事到推举沛公

<a id="event-30"></a>

30. **沛令想响应反秦，萧何、曹参建议召回流亡者。** 樊哙去找刘邦，刘邦身边已有几百人。等他们接近沛县，县令却害怕失控，关城并想杀萧何、曹参，两人翻城逃去投奔刘邦。[《汉书》P009—P010](../../sources/摘录/汉书-高帝纪.md#p009) · [卷008 P008—P009](../../sources/摘录/史记-卷008-高祖本纪.md#p008)。 [[30]](#note-30)

<a id="event-31"></a>

31. **刘邦向城中射入帛书，父老杀县令、开城迎接。** 众人要推他做县令，他起初推辞，认为天下已乱，领头的人选错会拖累整个地方。萧何、曹参等也不肯出面，最终刘邦被推为沛公，收集沛县子弟约三千人，形成公开反秦的地方武装。[《汉书》P010](../../sources/摘录/汉书-高帝纪.md#p010)。 [[31]](#note-31)

<a id="event-32"></a>

32. **起兵时举行祭祀，队伍使用赤色旗帜。** 他们在沛庭祠黄帝、祭蚩尤，以血涂鼓旗，随后向胡陵、方与进攻，再回守丰邑。从这时起，刘邦不再只是山泽中一个亡命的小吏，而是领兵争夺城邑的地方首领。[卷008 P009](../../sources/摘录/史记-卷008-高祖本纪.md#p009)。 [[32]](#note-32)

    沛县与吴中是各自起步的力量。齐、燕、魏等旧国也陆续复起，陈胜引发的反抗已经分成许多不能统一节制的队伍。[《汉书》P011](../../sources/摘录/汉书-高帝纪.md#p011) · [卷006 P058](../../sources/摘录/史记-卷006-秦始皇本纪.md#p058)。

### 7. 九百名戍卒在大泽乡遇雨误期，陈胜、吴广谋划反抗

[返回正文第7条](#event-7)

**[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4207)**

> 二世元年七月，發閭左適戍漁陽，九百人屯大澤鄉。陳勝、吳廣皆次當行，為屯長。會天大雨，道不通，度已失期。失期，法皆斬。陳勝、吳廣乃謀曰：「今亡亦死，舉大計亦死，等死，死國可乎？」陳勝曰：「天下苦秦久矣。吾聞二世少子也，不當立，當立者乃公子扶蘇。扶蘇以數諫故，上使外將兵。今或聞無罪，二世殺之。百姓多聞其賢，未知其死也。項燕為楚將，數有功，愛士卒，楚人憐之。或以為死，或以為亡。今誠以吾眾詐自稱公子扶蘇、項燕，為天下唱，宜多應者。」吳廣以為然。乃行卜。卜者知其指意，曰：「足下事皆成，有功。然足下卜之鬼乎！」陳勝、吳廣喜，念鬼，曰：「此教我先威眾耳。」乃丹書帛曰「陳勝王」，置人所罾魚腹中。卒買魚烹食，得魚腹中書，固以怪之矣。又彊令吳廣之次所旁叢祠中，夜篝火，狐鳴呼曰「大楚興，陳勝王」。卒皆夜驚恐。旦日，卒中往往語，皆指目陳勝。

<a id="补充史料与归年说明"></a>
### 补充史料与归年说明

<a id="sj006-054-note"></a>
<a id="1宗庙与二世年龄"></a>
#### 1｜宗庙与二世年龄

[卷006 P054](../../sources/摘录/史记-卷006-秦始皇本纪.md#p054)。二世元年二十一岁与篇末“立年十二”抵牾，保留异文。宗庙“自襄公已下轶毁”按庙制调整理解，不扩大为一切祖先祭祀全被废止。

<a id="sj006-055-note"></a>
<a id="2东巡与附刻"></a>
#### 2｜东巡与附刻

[卷006 P055](../../sources/摘录/史记-卷006-秦始皇本纪.md#p055)。始皇原刻各归原年；本年只新增附诏，行程叙次简略，不强拼每日路线。

<a id="sj006-056-note"></a>
<a id="3清洗"></a>
#### 3｜清洗

[卷006 P056](../../sources/摘录/史记-卷006-秦始皇本纪.md#p056)。六公子、将闾兄弟与《李斯列传》人数不直接相加作无重叠总数；哭诉和对话按传世叙事理解。

<a id="sj006-057-note"></a>
<a id="4阿房复工与粮运"></a>
#### 4｜阿房复工与粮运

[卷006 P057](../../sources/摘录/史记-卷006-秦始皇本纪.md#p057)。本年为葬事后的复工，不是再建另一座同名宫。五万材士、三百里限制不能用来算全国真实劳役总量。

<a id="sj006-058-note"></a>
<a id="5秦末压缩叙述"></a>
#### 5｜秦末压缩叙述

[卷006 P058—P059](../../sources/摘录/史记-卷006-秦始皇本纪.md#p058)。周章至戏初败依月表保留元年九月，最终败亡在二年十一月。魏咎在元年九月月表已有王号但仍在陈，返魏就位另见[前208年十二月](bce-0208.md#sj-048-L4214-02)。

“失期当斩”是陈涉篇对士卒处境的叙述，不能推广为秦律对任何徭役、天气和误期都只有斩刑。鱼腹书、狐鸣是人为造势；军队数字是史书所报，不是现代独立清点。

<a id="sj007-003-note"></a>
<a id="6会稽起兵"></a>
#### 6｜会稽起兵

[卷007 P003](../../sources/摘录/史记-卷007-项羽本纪.md#p003)，明确系二世元年九月；与汉书P011同事，在此合并，不另算一次项氏起兵。“江西”是长江以西，不是现代江西省；本纪只称会稽守通，其他史料名号另待互校，不冒称本段已给出完整姓名。原文“数十百人”不强算成一个准确死伤数；八千为所报精兵，不证明全郡人口或兵力只有八千。按丧事表现用人是本段明载细节，不杜撰其人姓名。

<a id="sj008-background-note"></a>
<a id="7刘邦前事名字与起兵仪式"></a>
#### 7｜刘邦前事、名字与起兵仪式

[卷008 P001—P009](../../sources/摘录/史记-卷008-高祖本纪.md#p001)。本卷称“字季”，没有在这里说明邦名的得名年月；正文统一称刘邦只是人物识别，不另造改名事件。亭长生活、咸阳观帝、婚姻、制冠、纵徒均为起兵以前的背景，不一律算前209年。郡县起兵是目前已有材料中可确年的主要登场；发现更早可靠事件时再调整阅读位置并保留锚点。

相貌、七十二黑子、龙现及老父相人是塑造开国君主的叙事，不证明看相可以预知命运。竹皮冠后来仍戴，是跨期习惯而非本年颁布冠服制度。吕氏子女在原文被称孝惠、鲁元是后称，未在早年就已有皇帝、公主身份。二三千人与汉书约三千相容，不机械求和。赤色旗帜、祭祀和衅鼓作为行动记述，与斩蛇解释分开。

卷008在二世二年开头回说周章至戏、诸国立王、项氏起吴，不将这些已经编在本年的事件再次搬到前208。起兵后胡陵、方与、丰之间的反复，连接下一古历年汉书详条，不制造只因两书都写一次就出现两次一模一样的进攻。

<a id="sj005-284-note"></a>

#### 卷005互见

#### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../sources/摘录/史记-卷015-六国年表.md#y0209)。

<a id="sj015-0209-qin-note"></a>
**秦栏：** 本格逐句有去向：十月戊寅大赦、十一月兔园见[本页开年条](#sj015-0209-amnesty)；阿房工程见[原注4](#sj006-057-note)，表十二月与本纪四月返京后再叙工程的次序不同，正文只说元年继续修建，保留不同月序，不给复工定唯一月日。“九月郡县皆反”是起兵扩大后的概括，不能覆盖[本页七月陈胜起兵](#sj006-058-note)；楚兵至戏、章邯反击接既有九月前后战事，曹阳、渑池败亡继续到前208。卫君角废为庶人补[本页卫终局](#sj015-0209-wei)，[《卫康叔世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-6b51c3663e50c0)角二十一年与表相合。

<a id="卷016逐月互见与取舍"></a>
### 卷016｜逐月互见与取舍

<a id="sj016-m07-note"></a>
<a id="七月起兵不是陈胜本人入关"></a>
#### 七月｜起兵不是陈胜本人入关

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0209-07)楚栏“楚隐王陈涉起兵入秦”归[大泽乡起兵](#sj-048-L4207-01)至[陈县称王](#sj-048-L4208-03)。隐王为后谥，起兵时未已有此号；“入秦”是压缩用语，不让陈胜本人七月进入咸阳。周文到戏仍在九月。

<a id="sj016-m08-note"></a>
<a id="八月葛婴与武臣各自立王"></a>
#### 八月｜葛婴与武臣各自立王

[本月原格](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0209-08)楚栏归[葛婴另立襄强](#sj-048-L4210-01)，赵栏归[武臣在邯郸称王](#sj-048-L4212-01)。襄强被杀是九月，葛婴被杀是下一古历年十月；三项不合为同日。

<a id="sj016-m09-note"></a>
<a id="九月多国起兵项梁封号与魏咎未归"></a>
#### 九月｜多国起兵、项梁封号与魏咎未归

[本月九栏](../../sources/摘录/史记-卷016-秦楚之际月表.md#m0209-09)秦、楚两栏周文至戏合入[同一战事](#sj-048-L4211-01)，楚栏杀襄强接[葛婴条](#sj-048-L4210-01)。齐、汉、燕分别接[田儋](#sj-048-L4214-01)、[刘邦](#sj008-liuji)、[韩广](#sj-048-L4213-01)；齐栏明确田儋、田荣、田横的亲属关系，已补正文，不把三个田氏人物混成一人。

项栏此月称“项梁号武信君”，但《项羽本纪》在次年立怀王后授号，正文仍沿[前208年拥立](bce-0208.md#sj-048-L4223-02)，本页[项氏起兵](#sj007-wu)不重授。魏栏“王咎始”紧接“咎在陈，不得归国”，王号与实际返魏分开，后者见[前208年十二月](bce-0208.md#sj-048-L4214-02)。空栏不是该国不存在史事，数字“二”仅为纪月。

# 公元前209年｜二世加紧清洗和工役，陈胜起兵，刘邦成为沛公

[← 公元前210年](bce-0210.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前208年 →](bce-0208.md)

**秦二世元年**

> 秦历十月岁首，本页按二世元年的传统年条归档；月份未经逐日公历换算。《陈涉世家》《秦楚之际月表》《汉书·高帝纪》原有内容与新增秦廷记载合读。

## 年初，二世强调自己承接始皇的事业

**赵高成为郎中令，二世重新安排宗庙礼制。** 二世增加始皇寝庙及山川祭祀，命群臣议定尊崇始皇庙。新的安排以始皇庙为帝者祖庙，按天子七庙的说法调整先王宗庙，皇帝又恢复自称“朕”。[1](#sj006-054-note)

**春天，二世带李斯东巡，在始皇旧刻石上增加诏辞。** 他要向郡县显示新皇帝的威势，也担心旧碑只称“皇帝”，后人会把始皇的功业算到继任者身上，于是下令补刻，明确旧功出于始皇。巡行涉及碣石、会稽、辽东等地，四月回到咸阳。[2](#sj006-055-note)

## 清洗宗室、官员，阿房工程又恢复了

**二世和赵高担心旧臣、诸公子不服，展开清算。** 大臣、公子及近侍官员受到牵连；六名公子在杜被处死。将闾兄弟三人被囚在宫中，接到赐死命令，要求知道自己的罪名，未获解释，最后拔剑自杀。宗室恐惧，劝谏又容易被当作诽谤，官员更不愿直言。[3](#sj006-056-note)

**四月回京后，二世下令继续修阿房宫。** 始皇死时，工程劳力曾调往骊山葬事；二世认为如果就此放弃阿房，就等于承认先帝兴工有错。他又征五万材士屯卫咸阳，教习射猎狗马禽兽。都城需要供养的人更多，郡县被要求转运粮草，运送者还要自带口粮，不得取食咸阳三百里内的谷物。[4](#sj006-057-note)

## 七月，戍卒从大泽乡走到陈县

<a id="backstory-sj-048-L4206-01"></a>
### 登场前事｜陈胜原来也是替人耕作的人

陈胜字涉，早年曾与人佣耕。史书用“苟富贵，无相忘”及燕雀鸿鹄的故事表现他的抱负。这里交代起兵以前的经历，不把未经确年的谈话另算作本年事件。[早年原文](../../sources/摘录/史记-条目原文.md#ref-sj-4206) · [原未定年记录](../../meta/考证/史记-未定年与跨年材料.md#sj-048-L4206-01)。

<a id="sj-048-L4207-01"></a>
**九百名戍卒在大泽乡遇雨误期，陈胜、吴广谋划反抗。** 他们原奉命去渔阳戍守，途中道路被阻。陈胜、吴广利用士卒对误期惩罚的恐惧，并准备借扶苏、项燕的名义号召群众。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4207) · [月表七月](../../sources/摘录/史记-条目原文.md#ref-sj-1489)。

<!-- backstory-end:sj-048-L4207-01 -->

<a id="sj-048-L4207-02"></a>
**他们有意制造“天意”的气氛。** 问卜之后，陈胜把文字藏入鱼腹，吴广又在夜间仿狐鸣呼喊，让士卒相信陈胜将称王。这是参与者安排的造势，不写成真有神明发出命令。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4207)。

<a id="sj-048-L4208-01"></a>
**起事者杀掉押送军官，推陈胜、吴广为首。** 两名尉被杀后，陈胜自立为将军，吴广为都尉，队伍公开反秦。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4208)。

<a id="sj-048-L4208-02"></a>
**队伍由大泽乡、蕲一路扩展，向陈推进。** 经过铚、酂、苦、柘、谯等地，陈胜又派葛婴向东。到陈时，所报兵力已经增至战车六七百乘、骑兵千余、步卒数万，远不是最初九百人的规模。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4208)。

<a id="sj-048-L4208-03"></a>
**陈县失守后，陈胜称王，号为“张楚”。** 陈守、陈令不在，守丞出战死亡；当地父老劝陈胜称王，于是建立新的政治名号。军事反抗由此发展成公开与秦相争的政权。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4208) · [卷006 P058](../../sources/摘录/史记-卷006-秦始皇本纪.md#p058)。

## 陈王分遣部队，响应者也开始各自作主

<a id="sj-048-L4209-01"></a>
**吴广西进，武臣等北略赵地，邓宗前往九江。** 吴广代理王事，攻打荥阳；武臣、张耳、陈馀向赵地发展。各郡县也有人杀长吏响应，陈胜难以直接统辖所有新起的力量。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4209) · [月表七月](../../sources/摘录/史记-条目原文.md#ref-sj-1489) · [八月](../../sources/摘录/史记-条目原文.md#ref-sj-1490)。

<a id="sj-048-L4210-03"></a>
**荥阳没有轻易攻下。** 三川守李由守城，吴广长期进攻仍未奏效；陈胜又任上蔡人蔡赐为上柱国，任命的具体月份未另记。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4210) · [月表](../../sources/摘录/史记-条目原文.md#ref-sj-1491)。

<a id="sj-048-L4210-01"></a>
**葛婴另立襄强，听到陈胜称王后又将他杀死。** 葛婴向东发展，在东城另立襄强为楚王；得知陈胜已称王，便杀襄强、准备返陈报告。月表把另立、杀襄强分在八、九月，葛婴自己后来被陈胜处死则在下一年十月，不能混作同一时刻。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4210) · [后续](bce-0208.md#sj-048-L4210-02)。

<a id="sj-048-L4217-01"></a>
**秦嘉等人不愿接受陈胜派来的统帅。** 秦嘉等围攻郯，陈胜派武平君畔统领他们，秦嘉却自立为大司马，杀死武平君畔。本条是起兵初期的回叙，不因为列传排得靠后，就移成更晚的事件。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4217)。

<a id="sj-048-L4221-01"></a>
**宋留奉命走南阳、武关一线。** 陈胜最初让宋留平定南阳，再进武关；后来陈胜死讯传来，宋留才改变行动。他的退兵、投降和被杀见下一年，不提前写死陈胜。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4221) · [后续](bce-0208.md#sj-048-L4221-02)。

## 八九月，赵、燕、齐纷纷出现新王

<a id="sj-048-L4212-01"></a>
**八月，武臣在赵地自立为王。** 张耳、陈馀辅佐他。陈胜听说后愤怒，拘押武臣等人的家属；蔡赐劝他承认现实，不要再树新敌，陈胜才改为承认，并要求赵军向西攻秦。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4212) · [月表八月](../../sources/摘录/史记-条目原文.md#ref-sj-1490)。

<a id="sj-048-L4212-02"></a>
**赵军没有照陈胜的要求立即向西。** 张耳、陈馀主张先扩展赵自己的地盘，武臣于是转向北略，让韩广去燕地。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4212) · [月表八月](../../sources/摘录/史记-条目原文.md#ref-sj-1490) · [九月](../../sources/摘录/史记-条目原文.md#ref-sj-1491)。

<a id="sj-048-L4213-01"></a>
**九月，韩广在燕地称王。** 他起初担心母亲还在赵，后来仍接受拥立；其母与家属随后才获送到燕，不把这几个步骤擅自定在同一天。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4213) · [月表九月](../../sources/摘录/史记-条目原文.md#ref-sj-1491)。

<a id="sj-048-L4214-01"></a>
**田儋在狄起兵，成为齐王。** 他与宗族力量夺取当地政权，向齐地发展。月表十月还有回顾性文字，不表示田儋在两个月各称王一次。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4214) · [月表九月](../../sources/摘录/史记-条目原文.md#ref-sj-1491) · [十月](../../sources/摘录/史记-条目原文.md#ref-sj-1492)。

## 周文逼到关中，秦廷却曾不肯听坏消息

<a id="sj-048-L4211-01"></a>
**九月前后，周文的军队到达戏，章邯以骊山刑徒迎击。** 周文自称熟悉兵事，受陈胜任用，沿途扩充队伍，推进到关中。秦一时来不及从附近县重新征兵，章邯提出赦免骊山刑徒、授予武器。周文战败退出关中，后来在曹阳、渑池继续败退。[原文](../../sources/摘录/史记-条目原文.md#ref-sj-4211) · [月表九月](../../sources/摘录/史记-条目原文.md#ref-sj-1491) · [卷006 P059](../../sources/摘录/史记-卷006-秦始皇本纪.md#p059)。

**此前报反乱的使者，反而被二世交给官吏治罪。** 后来的使者便改称只是小股盗贼，地方官很快可以抓完，二世反而高兴。叛乱越发展，朝廷接收到的信息却越可能失真。[5](#sj006-058-note)

## 登场前事：先认识还叫“刘季”的刘邦

刘邦是沛郡丰邑人，成年后做过泗水亭长，曾与吕公相识、娶吕氏；押送刑徒去骊山途中，又放走刑徒，自己逃入芒砀山泽。这些经历先于本年起兵，不能把所有故事都定在前209年。[《汉书》P001—P008](../../sources/摘录/汉书-高帝纪.md#p001)。

母亲梦神、斩白蛇后“赤帝子”的解释、所谓“东南有天子气”，均是开国叙事中的神异材料，保存为传说层，不写成已经证实的客观事件。[相关原文](../../sources/摘录/汉书-高帝纪.md#p007)。

## 九月：沛县从响应起事到推举沛公

**沛令想响应反秦，萧何、曹参建议召回流亡者。** 樊哙去找刘邦，刘邦身边已有几百人。等他们接近沛县，县令却害怕失控，关城并想杀萧何、曹参，两人翻城逃去投奔刘邦。[《汉书》P009—P010](../../sources/摘录/汉书-高帝纪.md#p009)。

**刘邦向城中射入帛书，父老杀县令、开城迎接。** 众人要推他做县令，他起初推辞，认为天下已乱，领头的人选错会拖累整个地方。萧何、曹参等也不肯出面，最终刘邦被推为沛公，收集沛县子弟约三千人，形成公开反秦的地方武装。[《汉书》P010](../../sources/摘录/汉书-高帝纪.md#p010)。

**同一阶段，项梁、项羽在吴地起兵，齐、燕、魏等旧国也陆续复起。** 刘邦不是反秦阵营里唯一的首领；陈胜号召引发的起事，已经分成许多难以统一节制的力量。[《汉书》P011](../../sources/摘录/汉书-高帝纪.md#p011) · [卷006 P058](../../sources/摘录/史记-卷006-秦始皇本纪.md#p058)。

## 补充史料与归年说明

<a id="sj006-054-note"></a>
### 1｜宗庙与二世年龄

[卷006 P054](../../sources/摘录/史记-卷006-秦始皇本纪.md#p054)。本纪正文称二世元年二十一岁，篇末世系却有“立年十二”的抵牾，不把后者无声改成已证实年龄。宗庙安排原文含“自襄公已下轶毁”，按庙制、尊始皇的语境理解，不扩大成秦消灭了一切祖先祭祀。

<a id="sj006-055-note"></a>
### 2｜二世巡行与附刻

[卷006 P055](../../sources/摘录/史记-卷006-秦始皇本纪.md#p055)。二世附诏是本年新增，始皇原刻各归原年，不误判“碑上有二世字样”就说明全部碑文作于本年。行程叙次简略，不强拼唯一每日路线。

<a id="sj006-056-note"></a>
### 3｜清洗

[卷006 P056](../../sources/摘录/史记-卷006-秦始皇本纪.md#p056)。六公子与将闾兄弟是本段所列；《李斯列传》另有人数、地点叙述，不能把不同版本相加作已知遇害总数。谏言、哭诉是传世文本叙事，不当作逐字现场笔录。

<a id="sj006-057-note"></a>
### 4｜阿房复工与粮运

[卷006 P057](../../sources/摘录/史记-卷006-秦始皇本纪.md#p057)。前212年是始皇时营建，本年是葬事后的复工，不是又建一座同名新宫。五万材士与三百里限制是原文记数，不能据此算出全国真实劳役总量。

<a id="sj006-058-note"></a>
### 5｜反秦与信息封闭

[卷006 P058—P059](../../sources/摘录/史记-卷006-秦始皇本纪.md#p058)。本纪把周章至戏、曹阳败亡等压在“二年冬”一段，月表、列传能分阶段定位，因此保留既有元年九月初败、二年十一月最终败亡，不静默挪掉旧记录。魏咎在元年九月月表已出现王号，但仍在陈不得归；实际返魏就位另在[前208年十二月](bce-0208.md#sj-048-L4214-02)，不因本纪概述便重复称王。

**“失期当斩”与神异叙事：**陈涉篇叙述士卒对失期的处境，不可推出秦律对一切徭役、任何天气、任何误期都只有斩刑。鱼腹书、狐鸣是人为造势；刘邦相关神异按传说处理。兵力、车数为史书所报，非现代独立清点。

<a id="sj005-284-note"></a>
### 卷005的概述互见

[卷005 P071](../../sources/摘录/史记-卷005-秦本纪.md#p071)把诸侯并起与二世三年终局合写。起兵本在二世元年，不能全部移到前207年。旧年页《陈涉世家》事件、早年背景及《汉书》沛县起兵线均保留并重排，重复概述不另计为新事。

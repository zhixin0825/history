# 公元前210年｜始皇死于巡途，沙丘密谋后胡亥继位

[← 公元前211年](bce-0211.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前209年 →](bce-0209.md)

**秦始皇三十七年；胡亥本年继位，次年称二世元年**

> 本页依秦始皇三十七年的古史年条归档。秦历十月岁首，行文中十月、十一月在七月以前，不是写反；这些月名没有直接换算成现代公历月份。

## 最后一次远行，从云梦走到会稽

**十月癸丑，秦始皇再次出巡。** 李斯随行，右丞相冯去疾留守。少子胡亥请求同行，得到允许。十一月到云梦，秦始皇向九疑山望祭舜，随后沿江东行，过丹阳、钱唐；因浙江水势不好，又向西绕行，从较窄处渡过。[1](#sj006-050-note)

**登会稽祭禹，又把秦的秩序刻在石上。** 会稽刻石再次追述统一和法度，并特别强调婚姻、男女秩序：批评有子改嫁，规定有关私通、逃嫁的责任。这些反映秦廷要宣示的伦理和权力要求，不是现代编者赞同的行为规范，也不是调查得出的全民实际生活。[1](#sj006-050-note)

## 徐市把多年求药不成，推给海里的大鱼

**皇帝回到海边，求仙仍未放下。** 他经吴、江乘渡江，沿海到琅邪。徐市等多年求药无功、花费很大，便声称有大鲛鱼阻路，请配善射者同去。秦始皇接受解释，命出海者携带捕巨鱼工具，自己也用连弩候鱼。[2](#sj006-051-note)

**到了之罘，他射杀了一条巨鱼。** 此前从琅邪北到荣成山没有见到大鱼，到了之罘才有所获；随后继续沿海向西。射鱼是这段记载中的行动，仙药是否存在则是另一回事。[2](#sj006-051-note)

<a id="event-1"></a>
## 沙丘病逝，消息没有立即公布

**到平原津时，秦始皇病了，后来病势加重。** 他写下盖玺的信，命扶苏到咸阳会丧、安葬。这封信已封好，留在兼管符玺的赵高手中，尚未交给使者。七月丙寅，秦始皇死于沙丘平台。[3](#sj006-052-note)

**李斯隐瞒死讯，车队照常接受奏事。** 他担心皇帝死在外面会引起诸公子和天下变动，于是不发丧，把棺载在辒凉车中，继续上食、收取奏章，由宦者假传车中批答。真正知道死讯的只是极少数人。[3](#sj006-052-note)

**赵高、李斯与胡亥改变了继承安排。** 按《史记》叙述，三人毁去给扶苏的封书，伪称始皇留下遗诏，立胡亥为太子；又写信指责扶苏、蒙恬，命他们死。扶苏收到命令后自杀，蒙恬的拒死、拘禁和最终死亡则还有后续过程，不能写成两人在使者到达同一刻一起被处死。[3](#sj006-052-note)

**返程靠鲍鱼掩盖尸臭。** 车队经井陉到九原，天气炎热，车中发臭，便让从官车载鲍鱼混淆气味，再经直道回咸阳。所谓鲍鱼在此是有强烈气味的腌鱼，不按现代菜单上的鲍贝理解。[3](#sj006-052-note)

## 回到咸阳，胡亥即位，始皇入葬骊山

**死讯终于公开，胡亥成为二世皇帝。** 九月，始皇葬入骊山。陵墓从早年即位时已开始营建，统一以后规模又扩大；这不是皇帝死后几个月才从零开始修成的陵墓。[4](#sj006-053-note)

**陵内装置与陪葬，史书写得极为奢大，也极为残酷。** 记载中有宫观百官、珍奇器物、机关弩，以水银模拟河海，顶上天文、地下地理，并用“人鱼膏”作灯烛。胡亥命无子后宫从死，死者很多；封藏时又把知道机关、宝藏的工匠留在墓内，没有放出，最后种植草木，使陵上如山。[4](#sj006-053-note)

## 本年相关史料

<a id="sj006-050-note"></a>
### 1｜末次巡行与会稽刻石

[卷006 P050](../../sources/摘录/史记-卷006-秦始皇本纪.md#p050)。刻辞的颂功、六国罪状、妇德及婚姻规范分层阅读；“有子而嫁，倍死不贞”等属于原文价值判断，正文不继承为对女性的现代评价。古路线、涉水次序照录，不补未经验证的现代里程或公历出发日。

<a id="sj006-051-note"></a>
### 2｜求药与射鱼

[卷006 P051](../../sources/摘录/史记-卷006-秦始皇本纪.md#p051)。梦见海神、博士解梦和恶神阻碍属于传说及方术解释，不能当成海神真的出现。古“大鲛鱼”“巨鱼”不足以在这里确定现代物种，不画出一条已经被科学鉴定的鲨鱼或鲸。

<a id="sj006-052-note"></a>
### 3｜死亡与继承：正文采用史记叙事，争议不隐藏

[卷006 P052](../../sources/摘录/史记-卷006-秦始皇本纪.md#p052) · [卷087《李斯列传》](https://zh.wikisource.org/wiki/史記/卷087)。本纪所引封书只明言“与丧会咸阳而葬”，**没有明文写“传位扶苏”**；不能把后世对其继承含义的理解冒充诏书原句。七月丙寅保留古历，不以未核定的换算日制造精确性。

北大汉简《赵正书》则叙述李斯、去疾请立胡亥，秦王答“可”，与沙丘诈立故事不同：[公开释文](https://zh.wikisource.org/wiki/趙正書)。该篇性质与历史可信度仍有争论；杨涛2024年研究把它解释为影射汉高祖改立太子的政治文本，[作者机构所载摘要](https://scholarship.libraries.rutgers.edu/esploro/outputs/acceptedManuscript/A-new-textual-study-of-the/991031933295804646)明确提示尚无一致意见。因此不宣称出土文本已彻底推翻《史记》，也不假装《史记》每句密谋对白已被独立证实。详见[沙丘继位](../../meta/考证/史记-卷006-纪年与异说.md#沙丘继位)。

<a id="sj006-053-note"></a>
### 4｜陵墓与葬仪

[卷006 P053](../../sources/摘录/史记-卷006-秦始皇本纪.md#p053)。早年开工的回叙已接到[前246年](bce-0246.md)，统一后“七十余万人”不能倒填到少年即位之初。“三泉”、水银河海、机关、人鱼膏、工匠被封等是文本描述，**不是本项目宣称主墓室已经发掘后逐项证实**。后宫从死的具体人数未列，工匠人数亦未列，不添加数字；“人鱼”不译成童话美人鱼。

# 公元前210年｜始皇死于巡途，沙丘密谋后胡亥继位

[← 公元前211年](bce-0211.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前209年 →](bce-0209.md)

**秦始皇三十七年；胡亥本年继位，次年称二世元年**

> 本页依秦始皇三十七年的古史年条归档。秦历十月岁首，十月、十一月在七月以前，不是写反；未将这些月名直接换算成现代公历月份。

## 最后一次远行，从云梦走到会稽

**十月癸丑，秦始皇再次出巡。** 李斯随行，右丞相冯去疾留守。少子胡亥请求同行，得到允许。十一月到云梦，秦始皇向九疑山望祭舜，随后沿江东行，过丹阳、钱唐；因浙江水势不好，又向西绕行，从较窄处渡过。[1](#sj006-050-note)

**登会稽祭禹，又把秦的秩序刻在石上。** 会稽刻石再次追述统一和法度，并特别强调婚姻、男女秩序：批评有子改嫁，规定有关私通、逃嫁的责任。这些是秦廷要宣示的要求，不是现代编者赞同的行为规范，也不是全民实际生活的调查。[1](#sj006-050-note)

<a id="sj007-first"></a>
## 围观车队的人里，有项梁和项羽

### 登场前事｜一个楚国将门的年轻人

项籍字羽，是下相人，出身于楚国将门。他的叔父项梁是楚将项燕的儿子。项羽年轻时学过文字、剑术，却都没有学到底；他认为剑术只能敌一个人，更想学能对付万人的兵法。项梁教他，他又只大略懂得意思，不肯继续深学。项羽身材高大、力气过人，吴中的年轻人已经有些畏惧他。[5](#sj007-002-note)

项梁此前曾牵涉栎阳的案件，托曹咎写信给司马欣，得到帮助；后来又因杀人，与项羽到吴中避仇。在当地办理徭役、丧事时，项梁经常主持事务，暗中按军事方式编组宾客和子弟，观察各人的才能。他还没有正式起兵，却已认识了一批可以组织起来的人。[5](#sj007-002-note)

**始皇过浙江时，叔侄二人一起观看，项羽竟说可以取而代之。** 项梁赶紧捂住他的嘴，警告这种话会招来灭族之祸，但也因此觉得这个侄子不同寻常。此刻的项羽还没有军队，更不是已经在公开反秦；下一年的形势会给叔侄另一个机会。[5](#sj007-002-note)

## 徐市把多年求药不成，推给海里的大鱼

**皇帝回到海边，求仙仍未放下。** 他经吴、江乘渡江，沿海到琅邪。徐市等多年求药无功、花费很大，便声称有大鲛鱼阻路，请配善射者同去。秦始皇接受解释，命出海者携带捕巨鱼工具，自己也用连弩候鱼。[2](#sj006-051-note)

**到了之罘，他射杀了一条巨鱼。** 此前从琅邪北到荣成山没有见到大鱼，到了之罘才有所获；随后继续沿海向西。射鱼是这段记载中的行动，仙药是否存在则是另一回事。[2](#sj006-051-note)

<a id="event-1"></a>
## 沙丘病逝，消息没有立即公布

**到平原津时，秦始皇病了，后来病势加重。** 他写下盖玺的信，命扶苏到咸阳会丧、安葬。这封信已封好，留在兼管符玺的赵高手中，尚未交给使者。七月丙寅，秦始皇死于沙丘平台。[3](#sj006-052-note)

**李斯隐瞒死讯，车队照常接受奏事。** 他担心皇帝死在外面会引起诸公子和天下变动，于是不发丧，把棺载在辒凉车中，继续上食、收取奏章，由宦者假传车中批答。真正知道死讯的只是极少数人。[3](#sj006-052-note)

**赵高、李斯与胡亥改变了继承安排。** 按《史记》叙述，三人毁去给扶苏的封书，伪称始皇留下遗诏，立胡亥为太子；又写信指责扶苏、蒙恬，命他们死。扶苏收到命令后自杀，蒙恬的拒死、拘禁和最终死亡则还有后续过程，不能写成两人同刻一起被处死。[3](#sj006-052-note)

**返程靠鲍鱼掩盖尸臭。** 车队经井陉到九原，天气炎热，车中发臭，便让从官车载鲍鱼混淆气味，再经直道回咸阳。所谓鲍鱼在此是有强烈气味的腌鱼，不按现代菜单上的鲍贝理解。[3](#sj006-052-note)

## 回到咸阳，胡亥即位，始皇入葬骊山

**死讯终于公开，胡亥成为二世皇帝。** 九月，始皇葬入骊山。陵墓从早年即位时已开始营建，统一以后规模又扩大；这不是皇帝死后几个月才从零开始修成的陵墓。[4](#sj006-053-note)

**陵内装置与陪葬，史书写得极为奢大，也极为残酷。** 记载中有宫观百官、珍奇器物、机关弩，以水银模拟河海，顶上天文、地下地理，并用“人鱼膏”作灯烛。胡亥命无子后宫从死，死者很多；封藏时又把知道机关、宝藏的工匠留在墓内，没有放出，最后种植草木，使陵上如山。[4](#sj006-053-note)

## 本年相关史料

<a id="sj006-050-note"></a>
### 1｜末次巡行与会稽刻石

[卷006 P050](../../sources/摘录/史记-卷006-秦始皇本纪.md#p050)。刻辞的颂功、六国罪状、妇德及婚姻规范分层阅读；“有子而嫁，倍死不贞”等属于原文价值判断，正文不继承为对女性的现代评价。路线、涉水次序照古地名，不补未经验证的现代里程或公历出发日。

<a id="sj006-051-note"></a>
### 2｜求药与射鱼

[卷006 P051](../../sources/摘录/史记-卷006-秦始皇本纪.md#p051)。梦海神、博士解梦、恶神阻碍属于传说及方术解释，不能当成海神真的出现。古“大鲛鱼”“巨鱼”不足以在这里确定现代物种。

<a id="sj006-052-note"></a>
### 3｜死亡与继承

[卷006 P052](../../sources/摘录/史记-卷006-秦始皇本纪.md#p052) · [卷087《李斯列传》](https://zh.wikisource.org/wiki/史記/卷087)。本纪所引封书只明言“与丧会咸阳而葬”，没有明文写“传位扶苏”；不把后世对其继承含义的理解冒充诏书原句。七月丙寅保留古历，不制造未经核定的现代日期。

北大汉简《赵正书》则叙述李斯、去疾请立胡亥，秦王答“可”，与沙丘诈立不同：[公开释文](https://zh.wikisource.org/wiki/趙正書)。文本性质与可信度仍有争论；杨涛2024年研究提出与汉高祖改立太子的政治议题相关的解释，[作者机构摘要](https://scholarship.libraries.rutgers.edu/esploro/outputs/acceptedManuscript/A-new-textual-study-of-the/991031933295804646)提示尚无一致意见。不宣称简本已彻底推翻《史记》，也不假装本纪密谋对白已被独立证实。[沙丘继位说明](../../meta/考证/史记-卷006-纪年与异说.md#沙丘继位)。

<a id="sj006-053-note"></a>
### 4｜陵墓与葬仪

[卷006 P053](../../sources/摘录/史记-卷006-秦始皇本纪.md#p053)。早年开工回叙已接[前246年](bce-0246.md)，统一后“七十余万人”不能倒填到少年即位之初。三泉、水银河海、机关、人鱼膏、工匠被封等是文本描述，不是主墓室已发掘后逐项证实的清单。后宫、工匠人数未列，不添加数字；“人鱼”不译成童话美人鱼。

<a id="sj007-002-note"></a>
### 5｜项羽首次登场与早年背景

[卷007 P001—P002](../../sources/摘录/史记-卷007-项羽本纪.md#p001)与[卷006会稽巡行](../../sources/摘录/史记-卷006-秦始皇本纪.md#p050)合读，将叔侄观巡放在三十七年。项梁狱事、杀人、迁吴、项羽求学属于在此以前的经历，具体年月及各事间隔未明，不一律记成前210年。本轮在已读材料中将这里作为项羽有据登场；前代谱系中被提名不等于参与事件。

本纪说起兵时二十四岁，是古年龄口径，未据此新增带确切日期的出生页；“力能扛鼎”是传世人物描写，不换算现代体能。项燕被王翦所戮与其他篇章的自杀、死年差别沿[卷006灭楚说明](../../meta/考证/史记-卷006-纪年与异说.md#灭楚的次序)保留，不再制造一次死亡。曹咎与司马欣的援助将在后来解释项氏对二人的信任，但不能把后来的任用提前放到本年。

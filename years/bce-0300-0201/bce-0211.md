# 公元前211年｜陨石刻字引来诛杀，秦又向榆中迁民

[← 公元前212年](bce-0212.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前210年 →](bce-0210.md)

**秦始皇三十六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **东郡陨石上出现咒语，附近居民遭到集体清算。** 年条先记“荧惑守心”，又记东郡有坠星落地成石，有人在石上刻“始皇帝死而地分”。秦始皇派御史追查，无人认罪，便把石旁居民全部杀死，并烧毁、销去石头。这是皇帝对不利言辞的回应，不能说陨石已经预告了后来秦亡。 [[1]](#note-1)

<a id="event-2"></a>

2. **朝廷命博士写诗，让乐人传唱。** 秦始皇对此不快，命博士写仙人、真人及自己巡游天下的诗，交给乐人歌唱演奏。他用另一套公开叙述，去回应威胁自身的说法。 [[2]](#note-2)

<a id="event-3"></a>

3. **北方继续迁民。** 本年又把三万家迁到北河榆中，赐爵一级。年条将这项安排接在占卜“游徙吉”之后；可作为行动记录的是迁民与赐爵，不能据此认定占卜确能预测吉凶。 [[3]](#note-3)

<a id="记载中的传说一块自己回来的璧"></a>


<a id="event-4"></a>

4. **记载中的传说｜一块“自己回来”的璧。** 秋天，使者夜过华阴平舒道，据称有人递来一块璧，请送给滈池君，并说“今年祖龙死”，随后消失。璧被带回后，又被说成是秦始皇八年前渡江沉下的旧璧。这个故事把还璧、预言与皇帝的不安联系起来；它作为史书中的神异叙事保存，不当作已验证的超自然事件，也不据它把始皇之死提前到本年。 [[4]](#note-4)

## 归年与考证

<a id="sj006-049-note"></a>
<a id="1三十六年年条"></a>
#### 1｜三十六年年条

[卷006 P049](../../sources/摘录/史记-卷006-秦始皇本纪.md#p049)。荧惑守心属于古天象记录，陨石刻字属于人为行为，还璧属于传说性叙事，三层不可混成同一种证据。原文“拜爵一级”接在迁民后，正文随原文关系阅读，但不扩展成全国每个居民本年都获爵。始皇死亡仍见[前210年](bce-0210.md)。

**秦栏：** 北河榆中迁民、授爵及东郡石文均与[本页原注](#sj006-049-note)互见。表作“耐徙三处”，《集解》又记处一作家；本纪的“三万家”是另一明确文本，不能静默把原表改作三万。表仅节“地分”，本纪详记“始皇帝死而地分”，是同一石文材料的详略，不造两块不同陨石。

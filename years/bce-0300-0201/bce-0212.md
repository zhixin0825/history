# 公元前212年｜阿房与直道大兴工役，咸阳诸生案牵出扶苏远行

[← 公元前213年](bce-0213.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前211年 →](bce-0211.md)

**秦始皇三十五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="一面修路一面另建大朝宫"></a>

<a id="event-1"></a>

1. **秦修筑九原到云阳的直道。** 为使道路较直地贯通，工程要开山填谷。这条道路意在联系北方与关中，不能据本年条断定它已经全线完成。 [[1]](#note-1)

<a id="sj-006-L0390-01"></a>

<a id="event-2"></a>

2. **秦始皇嫌咸阳人多、旧宫庭小，在渭南上林苑营建新朝宫。** 工程先做阿房前殿，规划中有通往南山、跨渭水连接咸阳的道路和复道，取象于天上的星宫秩序。宫尚未完成，原打算建成后再选好名字，“阿房”因营建地点而成为通称。 [[2]](#note-2)

<a id="event-3"></a>

3. **阿房与骊山都在大量征用劳力。** 本纪记七十余万人分去阿房、骊山，北山石材和蜀、楚木材被运来；又迁三万家到丽邑、五万家到云阳，复免十年。秦还在东海郡朐界立石，标作“秦东门”。大工程、物料输送与人口迁徙一起改变了关中及周边。 [[3]](#note-3)

<a id="皇帝住在哪里也成了不能说的秘密"></a>

<a id="event-4"></a>

4. **卢生把求不死药与隐藏皇帝行踪联系起来。** 他劝秦始皇不要让臣下知道住所，以免妨碍真人出现。秦始皇接受，甚至以“真人”自称，下令用复道、甬道联结咸阳附近二百七十处宫观，各处配置帷帐、钟鼓、宫人，泄露行在者处死。 [[4]](#note-4)

<a id="event-5"></a>

5. **一场泄密怀疑，导致侍从被集体杀死。** 秦始皇在梁山宫看见丞相车骑众多，表示不满；丞相听到传话后减少车骑。皇帝发现自己的话传了出去，追查无人承认，便把当时在旁者全部杀死。此后行踪更加隐秘，群臣接受决断则集中在咸阳宫。 [[5]](#note-5)

<a id="方士逃走后咸阳诸生遭到追查"></a>

<a id="event-6"></a>

6. **方士逃走后，咸阳诸生遭到追查。** 侯生、卢生逃走，秦始皇把怒火转向在咸阳的诸生。 两人批评皇帝独断、以刑杀立威，认为不值得继续替他求仙药，随后逃去。秦始皇听说后大怒，又对求药多年无成果、费用巨大的徐市等表示不满，命御史调查诸生。被调查者相互牵引，四百六十余人被判犯禁，在咸阳遭“坑”，另有更多人被谪往边地。 [[6]](#note-6)

<a id="event-7"></a>

7. **扶苏劝谏，被派到上郡。** 长子扶苏担心，天下刚统一，远方百姓尚未安定，对诵习孔子学说者一概重罚会使人心不安。秦始皇没有接受，命他到上郡监督蒙恬。这次安排使扶苏远离秦廷，成为后来继承危机的重要前情。 [[7]](#note-7)

## 归年与考证

<a id="sj006-046-note"></a>
<a id="1工程迁民与旧年表异说"></a>
#### 1｜工程、迁民与旧年表异说

[卷006 P046](../../sources/摘录/史记-卷006-秦始皇本纪.md#p046)。七十余万是原文合写阿房、骊山的劳役人数，不拆成两地各七十万，也不等同于本年新征且全部同时在工的现代统计。前殿东西五百步、南北五十丈、坐万人等为传世尺度与规划描述，不假称已经完成的实测建筑。

直道在本纪作“道九原抵云阳，堑山堙谷，直通之”，[《蒙恬列传》卷088](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7088.md#ref-0b5db79d39c667)则记自九原抵甘泉的工程“道未就”。本轮复核将原正文“修通”改为“修筑”，避免把修路记载写成当年全线竣工；这也不等于断言其后任何一段道路都不能通行。两篇终点称谓及工程完成范围仍需另行考察，不补一个无据的竣工日期。

保留旧出处：[本纪旧摘录](../../sources/摘录/史记-条目原文.md#ref-sj-390) · [《六国年表》](../../sources/摘录/史记-条目原文.md#ref-sj-1470) · [《通鉴》卷七](../../sources/摘录/史记-条目原文.md#ref-tj007-338-353)。年表二十八年已写“为阿房宫”，本纪与《通鉴》系三十五年；依后者归前212年，但不擅改原表。原锚点继续保留。

关于“未成”与火烧，参看[西安市文物局发布的2025年阿房宫考古收获](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-45c71de528ea50a9.md#cite-3)：考古所见支持区分未完成的阿房宫与咸阳被焚宫室。此为考古认识，不将杜牧的文学描写倒写成本年的施工实录。

<a id="sj006-047-note"></a>
<a id="2宫观微行与杀侍从"></a>
#### 2｜宫观、微行与杀侍从

[卷006 P047](../../sources/摘录/史记-卷006-秦始皇本纪.md#p047)。二百七十与前段“关中宫三百、关外四百余”范围不同，不当作同口径统计互相相加。方士关于真人、恶鬼、不死药的说法属于被记录的观念，不当成确有其物的事实；皇帝行踪隐秘也不等于政府从此没有任何办事场所。

<a id="sj006-048-note"></a>
<a id="3诸生案与扶苏"></a>
#### 3｜诸生案与扶苏

[卷006 P048](../../sources/摘录/史记-卷006-秦始皇本纪.md#p048)。本纪使用“诸生”，扶苏谏辞又提诵法孔子；不能把所有涉案者都断言为单一身份的儒生或全都是诈骗方士。“坑”的具体实施不能仅靠一个字确定为全部活埋。四百六十余是史书所报，不冒称出土遗骸统计。侯、卢有关“衡石量书”、每天必须处理一定文书量的议论留在原文，不能换算成皇帝每天阅读的现代字数，更不能把讥评当成客观心理测量。

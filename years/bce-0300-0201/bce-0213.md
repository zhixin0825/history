# 公元前213年｜一场分封争论，转成了焚书与禁言的命令

[← 公元前214年](bce-0214.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前212年 →](bce-0212.md)

**秦始皇三十四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **办案不公的官吏被谪去服役。** 秦把办案不公、以及经复核发现有故意或过失错案责任的官吏，罚去修长城或赴南越地区。边疆工程和驻防继续需要人力，处罚也成为补充劳役的一种办法。 [[1]](#note-1)

<a id="event-2"></a>

<a id="event-3"></a>

<a id="event-4"></a>

2. **秦廷宴议分封，李斯进议焚书获准。** 秦始皇在咸阳设宴，博士上前祝寿。周青臣称郡县制使天下安定，淳于越以殷周分封子弟功臣为例，劝效古制，以防权臣作乱。李斯以三代制度因时代而异反驳，又说诸生以私学评论朝廷法令，主张禁以古非今。秦始皇批准焚书。史官所藏秦史以外的诸国史书，以及民间《诗》《书》和百家语，须交地方守尉焚毁，博士官所掌除外。相聚谈《诗》《书》处弃市，以古非今者族诛，知情不报的官吏同罪。令下三十日仍留书者黥为城旦。医药、卜筮、种树书得以保留，学法令须以吏为师。 [[2]](#note-2)

## 归年与考证

<a id="sj006-044-note"></a>
<a id="1谪罚治狱吏"></a>
#### 1｜谪罚治狱吏

[卷006 P044](../../sources/摘录/史记-卷006-秦始皇本纪.md#p044)。原文“适治狱吏不直者，筑长城及南越地”很短，不能恢复具体案件、人数和役期。

<a id="sj006-045-note"></a>
<a id="2宴饮分封争论与焚书"></a>
#### 2｜宴饮、分封争论与焚书

[卷006 P045](../../sources/摘录/史记-卷006-秦始皇本纪.md#p045)。正文区分周青臣、淳于越、李斯三人的意见及最后“制曰可”，不把所有博士都写成一致赞成焚书。命令有对象和保留范围，不能改成秦在本年烧掉世间一切书；也不能由保存例外反推实际文化损失很小。所载刑罚是这一命令的文字，不概括成秦朝所有时代的一般刑律。与下一年的咸阳诸生案分开归年，不把“焚书坑儒”当作同日同一诏令。

# 公元前214年｜秦向南设置三郡，向北修塞徙民

[← 公元前215年](bce-0215.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前213年 →](bce-0213.md)

**秦始皇三十三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **南方征战扩大，桂林、象、南海三郡见于本年条。** 秦征发曾经逃亡的人、赘婿、商人等，进取陆梁地区，并以谪戍方式驻守新占领地。向南扩张不仅依靠打仗，也依靠把一批人长期留在当地。 [[1]](#note-1)

<a id="event-2"></a>

2. **北方从夺地转向置县、筑塞、安置人口。** 秦军在西北驱逐匈奴，从榆中沿河向东接到阴山，置三十四县，在河上筑城为塞。蒙恬又渡河进取高阙、阳山、北假一带，筑亭障，并把被迁徙的人安置在新县。 [[2]](#note-2)

<a id="event-3"></a>

3. **秦下禁祠令，西方出现明星。** 秦下令禁止某些祭祀。当年又有明星出现在西方。 [[3]](#note-3)

## 本年相关史料

<a id="note-1"></a>

### 1. 南方征战扩大，桂林、象、南海三郡见于本年条

[返回正文第1条](#event-1)

<a id="hs095-l9914-e1"></a>

**[《汉书·西南夷两粤朝鲜传》P011](../../拆分史书/汉书/卷095.md#p011)** · [仓内TXT L9914](../../拆分史书/汉书/卷095.md#part-1-L9914)

> 秦並天下，略定揚粵，置桂林、南海、象郡，以適徙民與粵雜處。

**互校说明** 本篇缺具体年月，秦始皇三十三年取《史记·秦始皇本纪》；岭南诸郡命名沿见证。

<a id="sj113-p000"></a>

**[《史记·南越尉佗列传》P000](../../拆分史书/史记/卷113.md#p000)** · [三家注](../../拆分史书/史记/卷113.md#part-2-p0)

> 秦時已并天下，略定楊越，置桂林、南海、象郡，以謫徙民，與越雜處十三歲。

**本卷归年说明：** 《秦始皇本纪》始皇三十三年明记置三郡与谪戍，本传的十三岁有不同理解，不据此倒算赵佗称王。


**[卷006 P043](../../拆分史书/史记/卷006.md#p043)**

> 三十三年，發諸嘗逋亡人、贅婿、賈人略取陸梁地，為桂林、象郡、南海，以適遣戍。西北斥逐匈奴。自榆中并河以東，屬之陰山，以為三十四縣，城河上為塞。又使蒙恬渡河取高闕、陽山、北假中，筑亭障以逐戎人。徙謫，實之初縣。禁不得祠。明星出西方。

[史料说明](#sj006-043-note)

<a id="note-2"></a>

### 2. 北方从夺地转向置县、筑塞、安置人口

[返回正文第2条](#event-2)

<a id="hs094-l9763-e2"></a>

**[《汉书·匈奴传》P005](../../拆分史书/汉书/卷094.md#p005)** · [仓内TXT L9763](../../拆分史书/汉书/卷094.md#part-1-L9763)

> 因河為塞，築四十四縣城臨河，徙適戍以充之。

**互校说明** 《秦始皇本纪》作三十四县，本传“四十四縣”；同一筑塞置县工程保留数字异传。

<a id="hs096-l9952-e2"></a>

**[《汉书·西域传》P004](../../拆分史书/汉书/卷096.md#p004)** · [仓内TXT L9952](../../拆分史书/汉书/卷096.md#part-1-L9952)

> 及秦始皇攘卻戎狄，築長城，界中國，然西不過臨洮。

**互校说明** 回溯秦长城向西至临洮；《秦始皇本纪》三十三年记蒙恬取地、设县、筑塞等。本传未记全线竣工年月。

<a id="sj110-p004"></a>

**[《史记·匈奴列传》P004](../../拆分史书/史记/卷110.md#p004)** · [三家注](../../拆分史书/史记/卷110.md#part-1-p4)

> 因河爲塞，築四十四縣城臨河，徙適戍以充之。而通直道，自九原至雲陽，因邊山險壍谿谷可繕者治之，起臨洮至遼東萬餘里。又度河據陽山北假中。

**本卷归年说明：** 次年筑河上城塞并进阳山、北假；卷006作三十四县，本传作四十四；直道另于始皇三十五年命修。


<a id="sj088-p001"></a>

**[《史记·蒙恬列传》P001](../../拆分史书/史记/卷088.md#p001)**

> 築長城，因地形，用制險塞，起臨洮，至遼東，延袤萬餘里。於是渡河，據陽山，逶蛇而北。

**本卷归年说明：** 卷006 P043三十三年明确记渡河取高阙、阳山、北假及筑亭障。卷088所说跨临洮至辽东是北边长城总体，不将整个工程的竣工系此一年。

**[卷006 P043](../../拆分史书/史记/卷006.md#p043)**

> 三十三年，發諸嘗逋亡人、贅婿、賈人略取陸梁地，為桂林、象郡、南海，以適遣戍。西北斥逐匈奴。自榆中并河以東，屬之陰山，以為三十四縣，城河上為塞。又使蒙恬渡河取高闕、陽山、北假中，筑亭障以逐戎人。徙謫，實之初縣。禁不得祠。明星出西方。

# 公元前214年｜秦向南设置三郡，向北修塞徙民

[← 公元前215年](bce-0215.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前213年 →](bce-0213.md)

**秦始皇三十三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **南方征战扩大，桂林、象、南海三郡见于本年条。** 秦征发曾经逃亡的人、赘婿、商人等，进取陆梁地区，并以谪戍方式驻守新占领地。向南扩张不仅依靠打仗，也依靠把一批人长期留在当地。 [[1]](#note-1)

<a id="event-2"></a>

2. **北方从夺地转向置县、筑塞、安置人口。** 秦军在西北驱逐匈奴，从榆中沿河向东接到阴山，置三十四县，在河上筑城为塞。蒙恬又渡河进取高阙、阳山、北假一带，筑亭障，并把被迁徙的人安置在新县。 [[2]](#note-2)

<a id="event-3"></a>

3. **年条另记禁祠和天象。** 本纪写“禁不得祠”，但没有说明禁令具体针对哪些对象；又记明星出现在西方。不能把前者扩写为全国一切祭祀都被禁止，也不把后者解释成边疆战争的吉凶证明。 [[3]](#note-3)

## 归年与考证

<a id="sj006-043-note"></a>
<a id="1南征北拓与迁民"></a>
#### 1｜南征、北拓与迁民

[卷006 P043](../../sources/摘录/史记-卷006-秦始皇本纪.md#p043)。这是本纪对本年政策、军事的集中记载，不表示南征全部从本年才开始、三郡全部地区已在同一日被有效控制。三十四县沿用本纪数字；不混同前221年三十六郡。象郡等的疆界另有考证问题，本页不用现代省界填满空白。贾人即商人，“赘婿”是征发类别，不借此推论当时每一位赘婿都实际出征。

# 公元前215年｜始皇巡碣石求仙，蒙恬北击匈奴

[← 公元前216年](bce-0216.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前214年 →](bce-0214.md)

**秦始皇三十二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **秦始皇到碣石，求仙与刻石一起进行。** 他命燕人卢生寻找传说中的羡门、高誓，又让韩终、侯公、石生寻找仙人与不死药。碣石刻石称颂平定诸侯、论功赏赐、使男女各安其业，并记拆毁城郭、疏通堤防、夷除险阻。 [[1]](#note-1)

<a id="event-2"></a>

2. **皇帝巡过北边，从上郡返回。** 卢生入海回来，呈上一份涉及鬼神谶言的图书，其中有“亡秦者胡也”一句。秦廷把这类说法与北方威胁联系起来，接着命蒙恬率军北击匈奴。 [[2]](#note-2)

<a id="event-3"></a>

3. **蒙恬取得河南地，秦把战线推向北方。** 所报出兵规模为三十万人，取得黄河以南相关地区。这里的“河南”不是现代河南省，而是北方战事中相对于黄河的地区；下一年还会继续渡河扩张和修筑防御设施。 [[3]](#note-3)

## 归年与考证

<a id="sj006-041-note"></a>
<a id="1碣石与方士"></a>
#### 1｜碣石与方士

[卷006 P041](../../sources/摘录/史记-卷006-秦始皇本纪.md#p041)。羡门、高誓是方士声称要找的人物，不是本页证实的不死仙人。刻石“黎庶无繇”等属颂功文字，不能据此断言秦已废除徭役。拆城、通防也没有提供全国完工清单。

<a id="sj006-042-note"></a>
<a id="2北伐与谶言的层次"></a>
#### 2｜北伐与谶言的层次

[卷006 P042](../../sources/摘录/史记-卷006-秦始皇本纪.md#p042)。本纪把“亡秦者胡”与出兵相接，是史书如何解释决策的材料，不证明谶言具有预知能力，更不能因后来胡亥即位就倒证预言真实。北伐有自身军事与边疆背景，不能断言一句谶语就是唯一原因；三十万为史书记数。

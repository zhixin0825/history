# 公元前216年｜腊改名嘉平，始皇微行时又遇袭扰

[← 公元前217年](bce-0217.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前215年 →](bce-0215.md)

**秦始皇三十一年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **腊祭改名为“嘉平”，朝廷赐米羊。** 十二月，秦把腊的名称改为嘉平，又按里赐给百姓六石米、两只羊。这里的受赐单位是“里”，不能直接改写成每家每户都得到这一份。 [[1]](#note-1)

<a id="event-2"></a>

2. **皇帝只带四名武士夜行，在兰池遇到危险。** 秦始皇在咸阳微行，夜里遭遇盗众，一度受困，同行武士击杀袭扰者。此后关中大搜二十日。这次夜行与前218年东巡时的博浪沙事件不是同一次袭击。 [[2]](#note-2)

<a id="event-3"></a>

3. **米价高达一石一千六百钱。** 米价有一石一千六百钱之数。 [[3]](#note-3)

## 归年与考证

<a id="sj006-040-note"></a>
<a id="1三十一年年条"></a>
#### 1｜三十一年年条

[卷006 P040](../../拆分史书/史记/卷006.md#p040)。十二月直接系改名腊祭；夜行、搜捕、米价虽同年条，未各自标明月日，不让整段无条件共用同一天。“微行”是减少公开仪仗、隐蔽出行，不替人物编造沿路谈话。

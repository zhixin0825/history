# 公元前218年｜始皇在博浪沙遇袭，仍继续巡行刻石

**秦始皇二十九年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **秦始皇东巡，在阳武博浪沙遇到袭击。** 他受到惊扰，追捕却没有找到袭击者，于是命天下大搜十日。秦已经统一，皇帝的巡行仍然会遇到敌意和危险。 [[1]](#note-1)

<a id="event-2"></a>

2. **出巡没有就此结束。** 秦始皇登之罘，刻立两篇颂辞，一篇追述讨伐六国，称秦是替百姓除害；另一篇强调法度、名分、官职与后世承继，还宣称兵革永息。皇帝最后到琅邪，再经过上党返回。 [[2]](#note-2)

## 归年与考证

<a id="sj006-037-note"></a>
<a id="1博浪沙"></a>
#### 1｜博浪沙

[卷006 P037](../../sources/摘录/史记-卷006-秦始皇本纪.md#p037)：“至阳武博狼沙中，为盗所惊。求弗得，乃令天下大索十日。”正文用通行写法“博浪沙”，引文保留“博狼沙”。本卷未在此指名张良；张良与力士、铁椎、误中副车的细节属于《留侯世家》等互见材料，本轮不伪称这些细节都出于本纪，也不凭本纪简句指定作案者及其早年行程。

<a id="sj006-038-note"></a>
<a id="2之罘两篇刻辞与返程"></a>
#### 2｜之罘两篇刻辞与返程

[卷006 P038](../../sources/摘录/史记-卷006-秦始皇本纪.md#p038)。两篇刻辞都系二十九年，但一篇称中春、一篇泛称春游，不据此排成两个已确日的登山行动。“永偃戎兵”等是政治颂辞，不因此删除随后北伐、南征的年条；也不是本年又进行了一次兼并六国战争。

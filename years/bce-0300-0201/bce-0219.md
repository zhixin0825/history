# 公元前219年｜始皇封禅泰山、巡海求仙，又到泗水寻找周鼎

[← 公元前220年](bce-0220.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前218年 →](bce-0218.md)

**秦始皇二十八年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="皇帝把统一的功业刻在山上"></a>

<a id="event-1"></a>

<a id="event-2"></a>

1. **秦始皇东巡，立峄山石并封禅泰山。** 皇帝把统一的功业刻在山上。秦始皇东巡，先到峄山，再登泰山。他与鲁地儒生商议封禅、祭祀山川，在峄山立石颂功，又登泰山举行封祭、在梁父举行禅祭。下山遇上暴风雨时，他在树下避雨，后来给那棵树封了“五大夫”的爵号。始皇由泰山南面登山立石，从北侧下山，在梁父行禅礼。刻石追叙统一天下，宣称朝廷建立法度、要后世遵守秩序。封禅的部分仪节保密。 [[1]](#note-1)

<a id="沿海来到琅邪修台迁民再次颂功"></a>

<a id="event-3"></a>

<a id="event-4"></a>

2. **秦始皇南下琅邪，筑台、迁户并立石。** 秦始皇沿勃海向东，经过黄、腄、成山、之罘，再南下琅邪。他喜欢琅邪，停留三个月，在那里修台，并迁入三万户百姓，给予十二年的复免。琅邪刻石把统一说成百姓普遍受益。刻辞颂扬统一计量和文字、重农、整顿风俗、分定官职，说人民安宁、没有兵革。王离、王贲、王绾、李斯等从臣还共同论述，称秦的郡县与统一号令优于从前诸侯各守封域、相互战争的局面。这些是皇帝及从臣的自我表述，不能直接当作全国生活状况的调查报告。 [[2]](#note-3)

<a id="徐市带童男童女出海"></a>

<a id="event-5"></a>

3. **徐市带童男童女出海。** 求仙从说法变成了实际征发。 齐人徐市等人称海上有蓬莱、方丈、瀛洲三座神山，有仙人居住，请带童男童女前往寻找。秦始皇批准，徐市带着数千童男童女入海。可以归入本年的是出海行动，不是仙山和仙人被证实存在。 [[3]](#note-5)

<a id="回程也没有直接回咸阳"></a>

<a id="event-6"></a>

4. **回程也没有直接回咸阳。** 到了彭城，秦始皇想从泗水找回周鼎。 他斋戒祈祷，派千人潜水搜寻，却没有找到。寻找周鼎与海上求仙是两件不同的事，不能合成一次出海探险。 [[4]](#note-6)

<a id="event-7"></a>

5. **经过湘山时，大风又打断渡水。** 秦始皇西南渡淮，前往衡山、南郡，沿江到湘山祠，险些因风不能渡。博士向他解释湘君与尧女、舜妻的传说后，他发怒，命三千刑徒砍伐湘山的树，使山上显露赤土。最后，他从南郡经武关返回。 [[5]](#note-7)

## 归年与考证

<a id="sj006-033-note"></a>
<a id="1峄山泰山与封禅"></a>
#### 1｜峄山、泰山与封禅

[卷006 P033](../../sources/摘录/史记-卷006-秦始皇本纪.md#p033)。泰山刻石中的“二十有六年”回顾统一，不将二十八年的刻石错挪到前221年。“五大夫”是爵号，不是原文说有五棵树；避雨及封树是传世记载，不补具体树种和现代遗址认定。

<a id="sj006-034-note"></a>
<a id="2琅邪及颂功文字"></a>
#### 2｜琅邪及颂功文字

[卷006 P034](../../sources/摘录/史记-卷006-秦始皇本纪.md#p034)。沿海次序按本纪古地名保留，不据此虚构每日路线。三月、三万户、十二岁复免为原文记数。“无战争”“天下和平”等属颂辞，不与后续实际征战混写；从臣名单为碑文所列，不由名单推定每人首次任职年。

<a id="sj006-035-note"></a>
<a id="3徐市出海"></a>
#### 3｜徐市出海

[卷006 P035](../../sources/摘录/史记-卷006-秦始皇本纪.md#p035)。底本文字为“徐巿”，通常也称徐福；不是“徐市”与“徐福”两个人各出海一次。此段未记抵达何处，不补写到达日本或建立某国。

<a id="sj006-036-note"></a>
<a id="4周鼎与湘山"></a>
#### 4｜周鼎与湘山

[卷006 P036](../../sources/摘录/史记-卷006-秦始皇本纪.md#p036)。求鼎结果是“弗得”。博士关于湘君的回答属于当时传说解释，不能反推尧舜时代的确切墓地。伐树与刑徒数照史书归属，不扩大成整个湘江流域森林均被砍光。

<a id="卷015八栏原表与本年互见"></a>
#### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../sources/摘录/史记-卷015-六国年表.md#y0219)。

<a id="sj015-0219-qin-note"></a>
**秦栏：** 巡琅邪、之衡山、经南郡返程与本页[琅邪](#sj006-034-note)、[周鼎与湘山](#sj006-036-note)合并；衡山不是把前段泰山改名。其余条目须分开：“为阿房宫”依本纪、通鉴明确年次主叙在[前212年](bce-0212.md#sj006-046-note)，这里保留提前七年的异年；“治驰道”“为太极庙”与[前220年](bce-0220.md#sj015-0220-note)工程组互见。“赐户三十，爵一级”没有交代赐物、三十的单位及所涉人群，既不改作三十万户，也不等同于本纪琅邪迁三万户。赐爵与前220赐爵是否同条移年仍待核，不另造一次已确的全国赐赏。

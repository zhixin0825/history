# 公元前220年｜皇帝出巡，宫殿和道路接着修

[← 公元前221年](bce-0221.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前219年 →](bce-0219.md)

**秦始皇二十七年**

> 本年年条较短，只按实际记载叙述出巡、宫殿、道路与赐爵，不为补足篇幅编造故事。仍按古史年条归档，未作秦历逐日换算。

[本年相关史料](#sources-start)

<a id="皇帝往陇西北地走了一趟"></a>
### 皇帝往陇西、北地走了一趟

<a id="event-1"></a>

1. **秦始皇巡行陇西、北地，经过鸡头山、回中。** 此次出行的记载很简略，没有交代每日路程、沿途会见及发言。本页保留古地名，不把未经核定的现代地点当成唯一正确位置。 [[1]](#note-1)

<a id="宫殿不只是另起一座还要用道路连起来"></a>
### 宫殿不只是另起一座，还要用道路连起来

<a id="event-2"></a>

2. **宫殿不只是另起一座，还要用道路连起来。** 秦在渭水南面建信宫，后来改名为极庙，取象于天极。又修道路从极庙通往骊山，营建甘泉前殿，以甬道从咸阳连接过去。宫殿与宫殿之间的交通，也是一部分工程。 [[2]](#note-2)

<a id="赐爵一级修治驰道"></a>
### 赐爵一级，修治驰道

<a id="event-3"></a>

3. **赐爵一级，修治驰道。** 朝廷赐爵一级，并修治驰道。赐爵不是授予同名官职，修路的记载也不等于全国驰道已经在本年一次全部完工；原文没有展开这次赐爵的适用范围及所有工程起止日。 [[3]](#note-3)

## 归年与考证

<a id="s1"></a>
<a id="s1陇西北地鸡头山与回中"></a>
#### S1｜陇西、北地、鸡头山与回中

[卷006 P032](../../sources/摘录/史记-卷006-秦始皇本纪.md#p032) · [《通鉴》固定版本第210—215行](../../sources/本地分卷/资治通鉴/资治通鉴-卷007.md#L210)。

> 二十七年，始皇巡隴西、北地，出雞頭山，過回中。

《通鉴》作“至鸡头山”，所引本纪作“出”；不据一字之差造两次巡行。胡三省地名注与秦代记事分开阅读。

<a id="s2"></a>
<a id="s2信宫极庙甘泉前殿与甬道"></a>
#### S2｜信宫、极庙、甘泉前殿与甬道

[卷006 P032](../../sources/摘录/史记-卷006-秦始皇本纪.md#p032) · [《通鉴》固定版本第216—224行](../../sources/本地分卷/资治通鉴/资治通鉴-卷007.md#L216)。

> 焉作信宮渭南，已更命信宮為極廟，象天極。自極廟道通酈山，作甘泉前殿。筑甬道，自咸陽屬之。

白话用通常写法“骊山”，引文保留“酈山”。“焉作”的句读照录所核网页，不据此宣称点校已经定论；本条没有工程预算及劳役总数。

<a id="s3"></a>
<a id="s3赐爵与驰道"></a>
#### S3｜赐爵与驰道

[卷006 P032](../../sources/摘录/史记-卷006-秦始皇本纪.md#p032) · [《通鉴》固定版本第219—224行](../../sources/本地分卷/资治通鉴/资治通鉴-卷007.md#L219)。

> 是歲，賜爵一級。治馳道。

《通鉴》写“治驰道于天下”，不是赐爵的逐字出处。旧样页的三组原文锚点与固定版本链接保留；本轮补入卷006阅读摘录，不宣称已与仓库整本TXT逐字校勘。原样页建立于2026-09-28。

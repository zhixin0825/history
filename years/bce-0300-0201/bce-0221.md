# 公元前221年｜天下打下来了，接下来怎么管？

[← 公元前222年](bce-0222.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前220年 →](bce-0220.md)

**秦王政二十六年／秦始皇二十六年**

> 齐国灭亡，秦王改称皇帝；接下来的问题是，要不要把刚打下来的地方再分给自己的儿子，以及各地究竟按谁的规矩办事。按古史“二十六年”归档，未将秦历逐日换成公历；未注明月份的小节不强排成严格的月内先后。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="齐军守着西边秦军却从燕地向南打来"></a>

<a id="event-1"></a>

1. **齐军守着西边，秦军却从燕地向南打来。** 齐的防守没能挡住王贲。 齐王建和相国后胜派兵守住西部边界，并与秦断绝往来。王贲却从燕地向南进攻，进入临淄，齐王投降。齐并非一点防备都没有，但原先的防守未能阻止这一路推进。 这一结局之前，后胜及赴秦宾客曾收受秦金，反劝齐离开合纵、专朝秦而不助诸国。君王后在世时的外交信用与海滨位置，曾使齐较少受兵；后来的外交孤立和战备不足则被视为亡国前因，但不能抹去秦本纪已记的西界守军。 [[1]](#note-1)

<a id="event-2"></a>

2. **齐王建被迁往共地，齐人怨其用客失察。** 齐王在投降以前得到过五百里封地的承诺，后来却被迁到共，最终饿死。这里交代他的结局，不把未注明日期的死亡强算为本年某月。 齐人又以松柏、客人为辞作歌，讥刺他听信受秦收买者；歌谣是亡国后的评价，不据此推定死亡的具体年月。 [[2]](#note-2)

<a id="王这个称号已经不够用了"></a>

<a id="event-3"></a>

3. **秦王要求用新名号表现统一。** 他把兼并六国解释成对背约、侵扰、谋刺等行为的惩罚，并要求大臣议定帝号。这是新政权为战争及统治提出的官方解释，不等于六国的全部责任已经由这些言辞得到独立证明。 [[3]](#note-3)

<a id="event-4"></a>

4. **大臣建议“泰皇”，秦王改成“皇帝”。** 他取“皇”，再加上古代的“帝”，合成新称号；皇帝的命令称“制”“诏”，自称“朕”。庄襄王被追尊为太上皇。 [[4]](#note-4)

<a id="event-5"></a>

5. **死后的评价，也不许由后人随意决定。** 秦始皇认为，让儿子评论父亲、臣子评论君主不合适，于是废除谥法，称自己为始皇帝，后世依次数为二世、三世，直到万世。这是他的制度安排与愿望，不是后来实际延续的世数。 [[5]](#note-5)

<a id="给儿子封国还是把地方直接管起来"></a>

<a id="event-6"></a>

6. **王绾建议分封皇子，镇守燕、齐、楚旧地。** 王绾担心远方难以控制，建议封皇子为王。 燕、齐、楚刚被征服，距离秦都又远；由皇帝自己的儿子坐镇，似乎是稳住远方的一种办法。 [[6]](#note-6)

<a id="event-7"></a>

7. **李斯认为，重新封国会重新产生战争。** 周朝封过许多同姓子弟，但几代以后亲属关系疏远，各国照样彼此攻打。他主张用国家赋税厚赏皇子、功臣，而不给他们独立封国。秦始皇采纳了这一意见：好不容易结束诸侯混战，不应再把诸侯体系重新建立起来。 [[7]](#note-7)

<a id="event-8"></a>

8. **地方由郡的官员管理。** 年条记全国分为三十六郡，郡置守、尉、监。郡县制度并非本年才出现，三十六也不是整个秦朝始终不变的郡数。 [[8]](#note-8)

<a id="以后不能各用各的一套规矩"></a>

<a id="event-9"></a>

9. **法度、计量、车辆轨距和文字都纳入共同规范。** 对百姓的称呼改为“黔首”，长短、轻重等衡量标准统一，车同轨、书同文字。地图上统一以后，办事的尺度也要统一；但政策被写入这一年，不等于各地在同一天全部落实，更不意味着此前各国文字完全不能相互理解。 [[9]](#note-9)

<a id="收集兵器把大户迁到咸阳"></a>

<a id="event-10"></a>

10. **各地兵器被集中，豪富人口被迁入都城。** 秦收取兵器，集中到咸阳，熔铸成钟架和十二个金属人像；又把天下豪富十二万户迁到咸阳，并举行大酺。这些措施既改变了兵器的分布，也改变了都城人口与财富的集中程度。 [[10]](#note-10)

<a id="event-11"></a>

11. **此前灭国时，诸侯宫廷的一部分已经陆续搬进秦都。** 秦每攻破一个诸侯国，便仿照其宫室在咸阳北阪营建，把取得的宫人、钟鼓放入其中。殿宇、复道和周阁连在一起，渭南还有宗庙、章台、上林。这里交代的是此前连续营建的背景，不说成所有宫殿都在本年新建。 [[11]](#note-11)

<a id="连颜色和岁首也要体现秦的说法"></a>

<a id="event-12"></a>

12. **连颜色和岁首，也要体现秦的说法。** 秦以水德解释自己取代周，崇尚黑色和数字六。 秦始皇接受五德相胜的说法，认为周属火，秦属能胜火的水，朝贺从十月初一开始，服饰旗帜尚黑，符节、冠制、车辆等许多规格用六为纪，还把黄河称作德水。他又把严峻用法与这套水德观念联系起来，长期不赦。 [[12]](#note-12)

    这种说法是当时的政治观念，不是自然规律；秦历十月岁首也提醒读者，不能把古书同号的年、月直接当成今天公历日期。

<a id="sj-086-L5420-01"></a>
<a id="统一之后的追捕"></a>


<a id="event-13"></a>

13. **统一之后的追捕。** 秦继续悬赏追捕与燕太子丹、荆轲有关的人。统一是这段叙事的时间锚点，追捕究竟持续多久，原文没有明确交代。 [[13]](#note-13)

## 归年与考证

原有样页的六组来源与锚点继续保留；本轮补入卷006分段摘录。引文是阅读摘录，未宣称与仓库整本TXT、中华书局点校本完成逐字校勘。《通鉴》固定版本保留音注与版心，正文、注家解释和现代编者说明不得混为一层。

<a id="s1"></a>
<a id="s1灭齐及齐王结局"></a>
#### S1｜灭齐及齐王结局

[卷006 P027](../../sources/摘录/史记-卷006-秦始皇本纪.md#p027)：“秦使將軍王賁從燕南攻齊，得齊王建。”

[《通鉴》固定版本第138—144行](../../sources/本地分卷/资治通鉴/资治通鉴-卷007.md#L138)补临淄投降、五百里承诺与“處之松柏之間，餓而死”。两书详细程度不同，不因一书未写便判为冲突；行军完整路线、兵力及伤亡无足够记载。紧接的“臣光曰”属于司马光评论。

<a id="s2"></a>
<a id="s2议帝号追尊与废谥"></a>
#### S2｜议帝号、追尊与废谥

[卷006 P028](../../sources/摘录/史记-卷006-秦始皇本纪.md#p028) · [《通鉴》固定版本第155—168行](../../sources/本地分卷/资治通鉴/资治通鉴-卷007.md#L155)。

> 去「泰」，著「皇」，采上古「帝」位號，號曰「皇帝」；他如議。

> 追尊莊襄王為太上皇。

> 朕為始皇帝。後世以計數，二世三世至于萬世，傳之無窮。

战事回顾属于诏令保存的自我说明，不另复制六国战争事件；史书中的对话不是有现代录音支持的逐字发言。

<a id="s3"></a>
<a id="s3分封之议"></a>
#### S3｜分封之议

[卷006 P030](../../sources/摘录/史记-卷006-秦始皇本纪.md#p030) · [《通鉴》固定版本第181—191行](../../sources/本地分卷/资治通鉴/资治通鉴-卷007.md#L181)。

> 諸侯初破，燕、齊、荊地遠，不為置王，毋以填之。請立諸子，唯上幸許。

> 今海內賴陛下神靈一統，皆為郡縣，諸子功臣以公賦稅重賞賜之，甚足易制。

“荆”指楚地，不是今天某个同名城市。李斯不是反对皇子、功臣获得一切赏赐，而是反对独立封国；秦王接受其议，不等于此后的中央与地方关系再无问题。

<a id="s4"></a>
<a id="s4郡县与统一规范"></a>
#### S4｜郡县与统一规范

[卷006 P031](../../sources/摘录/史记-卷006-秦始皇本纪.md#p031) · [《通鉴》固定版本第189—197行](../../sources/本地分卷/资治通鉴/资治通鉴-卷007.md#L189) · [第200行](../../sources/本地分卷/资治通鉴/资治通鉴-卷007.md#L200)。

> 分天下以為三十六郡，郡置守、尉、監。更名民曰「黔首」。

> 一法度衡石丈尺。車同軌。書同文字。

车同轨、书同文字在本纪明见，不冒称《通鉴》“一法度衡石丈尺”一句已经逐字包含它们。本纪接写的四至是概括性疆域描述，涉及后续北伐、南征的范围时，不据此认定前221年已全部实际控制。[卷005互见](#sj005-282-note)。

<a id="s5"></a>
<a id="s5兵器迁户与跨年营建"></a>
#### S5｜兵器、迁户与跨年营建

[卷006 P031](../../sources/摘录/史记-卷006-秦始皇本纪.md#p031) · [《通鉴》固定版本第197—209行](../../sources/本地分卷/资治通鉴/资治通鉴-卷007.md#L197)。

> 收天下兵，聚之咸陽，銷以為鐘鐻，金人十二，重各千石，置廷宮中。

> 徙天下豪富於咸陽十二萬戶。

> 秦每破諸侯，寫放其宮室，作之咸陽北阪上。

“兵”是兵器，不是士兵；金人不译成纯金雕像。千石与十二万户为原文数字，非独立统计；收缴率和实际迁入比例无可量化依据。“每破诸侯”明确属于持续多年的背景。

<a id="s6水德十月岁首与严法"></a>
#### S6｜水德、十月岁首与严法

[卷006 P029](../../sources/摘录/史记-卷006-秦始皇本纪.md#p029) · [《通鉴》固定版本第170—181行](../../sources/本地分卷/资治通鉴/资治通鉴-卷007.md#L170)。

> 朝賀皆自十月朔。衣服旄旌節旗皆上黑。數以六為紀。

> 於是急法，久者不赦。

岁首解释及胡三省注另为一层；不从本段推论十月岁首在秦历史上一定首次创设于本年，也不为原无月日的事件强行历算。

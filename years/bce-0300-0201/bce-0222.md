# 公元前222年｜燕、代最后的据点被攻下，秦继续进取江南

[← 公元前223年](bce-0223.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前221年 →](bce-0221.md)

**秦王政二十五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="sj-086-L5419-02"></a>

<a id="event-1"></a>

1. **燕王喜在辽东被俘。** 王贲率军继续攻燕，追到辽东，俘获燕王喜。燕国在都城蓟失守之后维持的最后据点也被打掉。这不是荆轲行刺当年的结局，而是又经过了数年的战争。 [[1]](#note-1)

<a id="event-2"></a>

2. **代王嘉也被俘，赵公族的另一支政权结束。** 王贲回军攻代，俘获代王嘉。前228年赵都陷落后建立的代政权，至此覆灭。 《赵世家》概括嘉王代六岁、秦破嘉后终灭赵而置郡。 [[2]](#note-2)

<a id="event-3"></a>

3. **秦军继续收取江南，设置会稽郡。** 王翦平定楚国江南地区，使当地越君归降，秦设置会稽郡。五月，朝廷举行大酺，允许聚饮庆贺。 [[3]](#note-3)

<a id="sj034-taishigong"></a>

### 太史公的论赞：燕亡后的历史回顾

以下为司马迁的作者论赞，不是前222年同时发生的事件。甘棠遗德与燕国长期存续在这里构成道德解释；“八九百岁”是概数，不能据此逆推精确封燕年。“于姬姓独后亡”也须结合诸侯国、附庸等不同口径阅读，不能抹去另有记载的卫君后续。CCDH“笆棠”等异字保留，白话依三家注作甘棠。

<a id="sj034-cite-098"></a>

**[《史记·燕召公世家》P035](../../sources/摘录/史记-卷034-燕召公世家.md#p035)**

> 太史公曰：召公奭可謂仁矣！笆棠且思之，況其人乎？燕（北）［外］迫蠻貉，內措齊、晉，崎嶇彊國之閒，最為弱小，幾滅者數矣。然社稷血食者八九百歲，於姬姓獨後亡，豈非召公之烈邪！

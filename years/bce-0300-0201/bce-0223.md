# 公元前223年｜楚王负刍被俘，楚国的抵抗走向终结

[← 公元前224年](bce-0224.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前222年 →](bce-0222.md)

**秦王政二十四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **王翦、蒙武攻破楚国，俘获负刍，秦将所得楚地纳入郡治。** 前一年秦军已重创楚军并不断夺城，本年楚王被俘，楚国王廷统治结束；“名为郡”表示统治形态改变，不能据此认定全部楚地只设一个楚郡。南方地域广大，秦军对江南、越地的推进仍延续到下一年，并非每个地方在同一天停止抵抗。 [[1]](#note-1)

<a id="event-2"></a>

2. **昌平君一支反秦势力的终局，属于这一阶段，但前后次序有争议。** 传世叙事还留下项燕拥立昌平君在淮南反秦、最终失败的另一条线索。它有助于理解为何“俘获一个楚王”未必就概括了全部战事；由于各篇的王位、死亡次序不一致，不把它改写成已经证实的逐月进程。 [[2]](#note-2)

## 归年与考证

<a id="sj006-025-note"></a>
<a id="1俘负刍的年份"></a>
#### 1｜俘负刍的年份

[卷006 P024—P025](../../sources/摘录/史记-卷006-秦始皇本纪.md#p024) · [《通鉴》卷七，二十四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7007.md#ref-0fdfd517584884)。采用《通鉴》明确的二十四年俘负刍，而不依本纪上一年“虏荆王”提前归年；这是一项具体编年取舍，不宣称各篇因此全部一致。

<a id="changping-note"></a>
<a id="2昌平君项燕之死"></a>
#### 2｜昌平君、项燕之死

本纪二十三年写项燕立昌平君，二十四年写“昌平君死，项燕遂自杀”；《通鉴》则把项燕战死置于二十三年。正文只把抵抗终局放在前224—223年的跨年阶段，**没有在两年各写一次项燕之死**，也不把本纪顺序当成已获现代研究一致确认的事实。详见[纪年与异说](../../meta/考证/史记-卷006-纪年与异说.md#灭楚的次序)。

# 公元前225年｜大梁被水攻，魏亡；秦军攻楚却遭重挫

[← 公元前226年](bce-0226.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前224年 →](bce-0224.md)

**秦王政二十二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **王贲引水灌大梁，魏王投降。** 王贲攻魏都大梁，引河沟水灌城。城坏后魏王假投降，秦占领魏地，把梁地以冶铁为业的孔氏迁往南阳。秦军也进逼齐国西部。 [[1]](#note-1)

<a id="event-2"></a>

2. **攻楚的秦军先胜后败。** 李信、蒙武分路进攻，起初取得一些战果，后来在城父一带会合时被楚军追击。楚军攻破两座营垒，杀死七名都尉，李信退回。秦王原来认为二十万人足够的方案，没有达到预期结果。 [[2]](#note-2)

<a id="event-3"></a>

3. **秦王重新请王翦出山。** 秦王亲自到频阳向王翦认错，请他领兵。王翦仍坚持需要六十万军队，得到同意后出征。他还反复要求田宅，向秦王表明自己所求是家产，而不是凭大军另起野心。王翦重新接手攻楚，在本纪与编年史中有跨年编排差异；下一年继续记其作战。 [[3]](#note-3)

<a id="1灭魏"></a>
#### 1｜灭魏

[卷006 P023](../../sources/摘录/史记-卷006-秦始皇本纪.md#p023) · [《通鉴》卷七，二十二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7007.md#ref-22bda2b44319cb)。本纪记城坏、王降及尽取其地，《通鉴》系春三月。水攻的持续天数、淹没人口及工程规模不凭这一段补写。

#### 2｜攻楚失败与重新用王翦

[《通鉴》卷七，二十一至二十三年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7007.md#ref-33377505cb80e7) · [《史记》卷073《白起王翦列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7073.md#ref-2ecf9026af250a) · [卷006 P024](../../sources/摘录/史记-卷006-秦始皇本纪.md#p024)。本纪把“复召王翦”放二十三年，《通鉴》在二十二年接叙复起、次年接战役，正文采用跨年过程，不让王翦两次重新出山。蒙武、蒙恬有互见异文，正文采用《通鉴》所示校改，不隐去原有差别。六十万、两壁、七都尉及反复请田宅均为传世记载，不据此证明人物每句言语有逐字现场记录。

**秦王政二十一年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="sj-086-L5419-01"></a>

<a id="event-1"></a>

1. **燕都失守，燕王靠杀太子求和。** 冬十月，秦军攻下蓟。燕王喜及太子丹带兵退向辽东，秦军继续追击。燕王随后杀掉太子丹，想献首求和，却没有因此结束秦的进攻。燕王在辽东继续统治，直到几年后才被俘。 [[1]](#note-1)

<a id="event-2"></a>

2. **王贲攻楚，王翦退出前线。** 秦的另一支军队由王贲率领攻打楚地，楚军失利，丢掉十余座城。秦王又谋划更大规模的攻楚，李信与王翦对所需兵力有很大分歧。秦王采用较少兵力的方案，王翦称病告老，回到家乡。这个决定的后果要到下一阶段才显现。 [[2]](#note-2)

<a id="event-3"></a>

3. **旧韩地反抗，昌平君迁往郢。** 新郑发生反抗，昌平君被迁往郢。同一年还有大雪，所记积雪深二尺五寸。前几年打下来的地区仍然可能反抗，六国的旧政治网络也并未完全消失。 [[3]](#note-3)

<a id="note-1"></a>

### 1. 燕都失守，燕王靠杀太子求和

[返回正文第1条](#event-1)

**[卷086旧记录](../../sources/摘录/史记-条目原文.md#ref-sj-5419)**

> 於是秦王大怒，益發兵詣趙，詔王翦軍以伐燕。十月而拔薊城。燕王喜、太子丹等盡率其精兵東保於遼東。秦將李信追擊燕王急，代王嘉乃遺燕王喜書曰：「秦所以尤追燕急者，以太子丹故也。今王誠殺丹獻之秦王，秦王必解，而社稷幸得血食。」其後李信追丹，丹匿衍水中，燕王乃使使斬太子丹，欲獻之秦。秦復進兵攻之。後五年，秦卒滅燕，虜燕王喜。

**[《通鉴》卷七](../../sources/摘录/史记-条目原文.md#ref-tj007-28-33)**

> 二十一年冬十月王翦拔薊(薊音/計)燕王及太子率其精¶
> 兵東保遼東李信急追之代王嘉遺燕王書(遺于/季翻)令殺¶
> 太子丹以獻丹匿衍水中(索隠曰衍/水在遼東)燕王使使斬丹欲¶
> 以獻王王復進兵攻之(復扶/又翻)　王賁伐楚(賁音奔翦/之子也)取¶
> 十餘城王問於將軍李信曰吾欲取荆(王父莊襄王諱/楚故謂楚為荆)¶
> 於將軍度用幾何人而足(度徒/洛翻)李信曰不過用二十萬¶

**[卷006 P022](../../sources/摘录/史记-卷006-秦始皇本纪.md#p022)**

> 二十一年，王賁攻（薊）［荊］。乃益發卒詣王翦軍，遂破燕太子軍，取燕薊城，得太子丹之首。燕王東收遼東而王之。王翦謝病老歸。新鄭反。昌平君徙於郢。大雨雪，深二尺五寸。

## 归年与考证

<a id="yan-note"></a>
<a id="1燕地战事"></a>
#### 1｜燕地战事

[卷086旧记录](../../sources/摘录/史记-条目原文.md#ref-sj-5419) · [《通鉴》卷七](../../sources/摘录/史记-条目原文.md#ref-tj007-28-33) · [卷006 P022](../../sources/摘录/史记-卷006-秦始皇本纪.md#p022)。冬十月定位攻取蓟，不让杀丹、献首等后续行动无条件继承同一天。彻底灭燕见[前222年](bce-0222.md)。

<a id="sj006-022-note"></a>
<a id="2楚地新郑昌平君与大雪"></a>
#### 2｜楚地、新郑、昌平君与大雪

[卷006 P022](../../sources/摘录/史记-卷006-秦始皇本纪.md#p022) · [《通鉴》卷七，二十一年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7007.md#ref-b1b48fd35556a3)。本纪“王贲攻（蓟）［荆］”有校改，依攻楚理解，不重复造一次由王贲攻蓟。李信、王翦的兵力争论由《通鉴》补入，二十万、六十万是史书所载数额。昌平君迁郢的动机原文未明，不直接写成在本年已经自立楚王；后事见前224—223年及[纪年讨论](../../meta/考证/史记-卷006-纪年与异说.md#灭楚的次序)。雪深沿用古单位，未换算成现代站点积雪纪录。

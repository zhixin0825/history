# 公元前227年｜荆轲行刺失败，秦军在易水击败燕代联军

[← 公元前228年](bce-0228.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前226年 →](bce-0226.md)

**秦王政二十年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="sj-086-L5418-01"></a>

<a id="event-1"></a>

1. **荆轲借献图接近秦王，行刺没有成功。** 燕太子丹担心秦军继续逼近，派荆轲入秦。荆轲通过秦王宠臣蒙嘉求见，进献地图时寻找机会动手。秦王避开袭击，随后拔剑反击；荆轲最终被杀，尸体又遭肢解示众。医官夏无且参与阻止，事后得到赏赐。 [[1]](#note-1)

<a id="event-2"></a>

2. **秦军随即把战争推向燕国。** 王翦、辛胜率军攻燕，燕与代出兵抵抗，双方在易水以西交战。秦军获胜；攻破燕都蓟以及燕王退往辽东，接在下一年，不能全部压缩成行刺当天的后果。 [[2]](#note-2)

<a id="sj015-0227-successions"></a>

<a id="event-3"></a>

3. **魏、代、楚各自开始新王的元年。** 魏王假、代王嘉、楚王负刍都在前一年取得王位，本年进入各自元年。代王嘉的统治承接赵国宗室的抵抗；楚王负刍则是在杀死哀王的政变后掌权，三条元年并不表示相同的继位过程。 [[3]](#note-3)

<a id="note-1"></a>

### 1. 荆轲借献图接近秦王，行刺没有成功

[返回正文第1条](#event-1)

<a id="sj034-cite-093"></a>

**[《史记·燕召公世家》P033](../../sources/摘录/史记-卷034-燕召公世家.md#p033)**

> 燕見秦且滅六國，秦兵臨易水，禍且至燕。太子丹陰養壯士二十人，使荊軻獻督亢地圖於秦，因襲刺秦王。秦王覺，殺軻，使將軍王翦擊燕。

**本卷说明：** 二十人是丹所养壮士的记数，不等于荆轲带二十人一同入秦殿行刺；行刺与秦军反击仍分本页两条，最后灭燕另见前222。



**[卷086《刺客列传》](../../sources/摘录/史记-条目原文.md#ref-sj-5418)**

> 遂至秦，持千金之資幣物，厚遺秦王寵臣中庶子蒙嘉。嘉為先言於秦王曰：「燕王誠振怖大王之威，不敢舉兵以逆軍吏，願舉國為內臣，比諸侯之列，給貢職如郡縣，而得奉守先王之宗廟。恐懼不敢自陳，謹斬樊於期之頭，及獻燕督亢之地圖，函封，燕王拜送于庭，使使以聞大王，唯大王命之。」秦王聞之，大喜，乃朝服，設九賓，見燕使者咸陽宮。荊軻奉樊於期頭函，而秦舞陽奉地圖柙，以次進。至陛，秦舞陽色變振恐，群臣怪之。荊軻顧笑舞陽，前謝曰：「北蕃蠻夷之鄙人，未嘗見天子，故振慴。願大王少假借之，使得畢使於前。」秦王謂軻曰：「取舞陽所持地圖。」軻既取圖奏之，秦王發圖，圖窮而匕首見。因左手把秦王之袖，而右手持匕首揕之。未至身，秦王驚，自引而起，袖絕。拔劍，劍長，操其室。時惶急，劍堅，故不可立拔。荊軻逐秦王，秦王環柱而走。群臣皆愕，卒起不意，盡失其度。而秦法，群臣侍殿上者不得持尺寸之兵；諸郎中執兵皆陳殿下，非有詔召不得上。方急時，不及召下兵，以故荊軻乃逐秦王。而卒惶急，無以擊軻，而以手共搏之。是時侍醫夏無且以其所奉藥囊提荊軻也。秦王方環柱走，卒惶急，不知所為，左右乃曰：「王負劍！」負劍，遂拔以擊荊軻，斷其左股。荊軻廢，乃引其匕首以擿秦王，不中，中桐柱。秦王復擊軻，軻被八創。軻自知事不就，倚柱而笑，箕踞以罵曰：「事所以不成者，以欲生劫之，必得約契以報太子也。」於是左右既前殺軻，秦王不怡者良久。已而論功，賞群臣及當坐者各有差，而賜夏無且黃金二百溢，曰：「無且愛我，乃以藥囊提荊軻也。」

**楚栏：** 负刍元年与“哀王庶兄”均有去向：元年见[本页](#sj015-0227-successions)，政变见[前228](bce-0228.md#sj015-0228-chu)。[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-a822b072369ef2)同称庶兄，注保留亲属关系，不只录元年而漏掉后半句。

**燕栏：** 刺秦及秦来伐与秦栏是同一因果链，不把两栏分别展开成两次行刺。

# 公元前228年｜邯郸陷落，赵王被俘，公子嘉退往代地

[← 公元前229年](bce-0229.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前227年 →](bce-0227.md)

**秦王政十九年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **赵都邯郸被攻下，赵王迁被俘。** 王翦、羌瘣继续进攻，秦取得赵国核心地区。秦军随后驻在中山，准备把兵锋转向燕国。赵国都城的陷落，是灭赵的重要节点，但赵公族仍在别处组织抵抗。 接替李牧等的赵怱所部溃败，齐将颜聚逃走，王迁遂降。 [[1]](#note-1)

<a id="event-2"></a>

2. **秦王回到出生的城市，清算母家旧怨。** 秦王到了邯郸，把自己幼年在赵时与母家有仇怨的人杀死。随后，他经过太原、上郡返回秦国。这个行程既是巡视新占领地，也包含对旧日私人仇怨的报复。 [[2]](#note-2)

<a id="event-3"></a>

3. **公子嘉在代地称王，继续联燕。** 赵公子嘉带着宗族数百人退到代，自立为代王，并与燕国合兵驻在上谷。秦要结束这支政权，还要再打几年。 赵国逃亡大夫共同拥立嘉。 [[3]](#note-3)

<a id="event-4"></a>

4. **秦王的母亲去世。** 此次去世的是秦王政的母太后，与此前的华阳、夏两位太后不同。年条还记大饥，未提供足以量化的范围和人口损失。 [[4]](#note-4)

<a id="sj015-0228-chu"></a>

<a id="event-5"></a>

5. **楚幽王去世，哀王继位两月余又被负刍党徒袭杀。** 幽王悍与继位的哀王犹为同母兄弟，哀王庶兄负刍的党徒发动袭击，拥立负刍。短期内君位数易，使楚王廷在秦军东进之际又遭内乱。 [[5]](#note-5)

<a id="sj015-0228-wei"></a>

<a id="event-6"></a>

6. **魏景湣王去世，王子假接位。** 秦军已经逼近东方各国的核心地区，魏也迎来新王。王假的元年从下一年开始，不能把两年各写成一次继承。 [[6]](#note-6)

<a id="sj043-cite-260"></a>

**[《史记·赵世家》P118](../../sources/摘录/史记-卷043-赵世家.md#p118)**

> 太史公曰。吾聞馮王孫曰：「趙王遷，其母倡也，嬖於悼襄王。悼襄王廢適子嘉而立遷。遷素無行，信讒，故誅其良將李牧，用郭開。」豈不繆哉！

**本卷说明：** **太史公引冯王孙之论：** 太史公引冯王孙之说，称王迁之母原为倡人，得悼襄王宠爱，悼襄王废嫡子嘉而立迁；迁素行不佳，听谗杀良将李牧、任郭开，作者斥其荒谬。这是太史公的引述与评断，母亲出身不能代替具体政治因果。随后交代确实的延续事件：秦俘迁后，赵亡臣共立嘉在代称王；六年后秦破代王嘉，才终结赵宗室政权并置郡。前228立代、前222灭代分别落页，评论附赵亡同号，不能将全部置于一年的“太史公曰”而漏叙。 评论与代国后续分层，母亲出身不代替杀将误政的具体因果。

<!-- /sj043-cite-260 -->

<a id="sj043-cite-263"></a>

**[《史记·赵世家》Z001](../../sources/摘录/史记-卷043-赵世家.md#z001)**

> 【索隱述贊】趙氏之系，與秦同祖。周穆平徐，乃封造父。帶始事晉，夙初有土。岸賈矯誅，韓厥立武。寶符臨代，卒居伯魯。簡夢翟犬，靈歌處女。胡服雖強，建立非所。頗、牧不用，王遷囚虜。

**本卷说明：** **唐代司马贞后出《索隐述赞》：** 唐代司马贞《索隐》述赞追叙赵与秦同祖，穆王平徐封造父，叔带开始事晋、赵夙始获封地；又循本篇孤儿异传称屠岸贾矫杀、韩厥立赵武，讲宝符取代、最终传位伯鲁一支、简子狄犬之梦、武灵王少女之歌，最后认为胡服虽强，继嗣安排失当，廉颇李牧不被用，王迁终被俘。它是唐人的篇末评赞，须标明后出层次，不算司马迁本文，也不把各句再次列为独立史事。 非司马迁原文，不另算亡国当年新事。

## 归年与考证

<a id="sj006-020-note"></a>

#### 1｜十九年年条

[卷006 P020](../../sources/摘录/史记-卷006-秦始皇本纪.md#p020) · [《通鉴》卷六，十九年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7006.md#ref-b267b1dcfbc7d9)。本纪“皆阬之”指向被清算者，正文写杀死，不未经刑罚考证一律增译为活埋。公子嘉终局见[前222年](bce-0222.md)；赵都失守与代政权被灭不能合成同一时间。

<a id="sj015-0228-note"></a>
<a id="卷015八栏原表与本年互见"></a>
#### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../sources/摘录/史记-卷015-六国年表.md#y0228)。

<a id="sj015-0228-qin-note"></a>
**秦栏：** 王翦破赵、赵王迁被俘和帝太后卒均在[本页原注](#sj006-020-note)，帝太后指政的母亲，不与夏太后、华阳太后混同。

<a id="sj015-0228-zhao-note"></a>
**赵栏：** 赵王迁被俘与秦栏合一，公子嘉自立代王接本页既有代地叙事；下一年元年不再造一次自立。

<a id="sj015-0228-chu-note"></a>
**楚栏：** 幽王卒、哀王立、负刍杀哀王已补[本页楚条](#sj015-0228-chu)。表称哀王郝，世家称猶（简体“犹”），正文用王号；表“三月”与[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-11f2b4e4251534)“立二月余”不能无条件解释成同一现代日历月份，正文仅说不久。另据《魏世家》景湣十五年补[本页魏王更替](#sj015-0228-wei)，承接前227王假元年。

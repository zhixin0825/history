# 公元前229年｜秦军围向邯郸，赵国临阵撤换主将

[← 公元前230年](bce-0230.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前228年 →](bce-0228.md)

**秦王政十八年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **秦从几路压向赵都。** 王翦统军从上地出发，经过井陉；杨端和率河内方面军队，羌瘣也参与攻赵。秦军逐渐逼近并包围邯郸，赵国的首都面临直接威胁。 [[1]](#note-1)

<a id="event-2"></a>

2. **赵国撤换李牧、司马尚，防线失去重要支撑。** 李牧与司马尚原本率兵抵御秦军。秦向赵王宠臣郭开送金，借他诋毁两人有反意。赵王命赵葱、颜聚代将；李牧不肯交出指挥权，随后被捕杀，司马尚也遭废黜。赵篇写赵怱及齐将颜聚为继任者。换将后的赵军溃败、颜聚出亡与邯郸失守是这次更换指挥的后果，随前228结局条详记，不在本年再完整发生一次。 [[2]](#note-2)

<a id="sj015-0229-wei"></a>

<a id="event-3"></a>

3. **卫君角进入元年。** 角从元君承接的统治继续维持在野王一带。本年是他的元年，距秦二世最终废除卫君仍有二十年。 这一元年属于现用年链，前241年已称君角的另一传统另有说明。 [[3]](#note-3)

# 公元前230年｜韩国被并入秦，旧地设为颍川郡

[← 公元前231年](bce-0231.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前229年 →](bce-0229.md)

**秦王政十七年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **内史腾攻下韩国，韩王安被俘。** 前一年还是接收韩国交出的南阳，本年秦军已经吞并韩国剩余领土。秦把取得的地区设为颍川郡，韩王原来统治的国家变成秦的行政区域。 此时距离张良的父亲、韩相张平去世已经二十年。 [[1]](#note-1)

<a id="event-2"></a>

2. **华阳太后去世，又有地震和饥荒。** 华阳太后曾是孝文王的夫人，并收庄襄王为子，是前一代王位继承中的重要人物。本年她去世。年条同时记地震及严重饥荒，不能只用灭韩一事概括当时人们面对的局势。 [[2]](#note-2)

<a id="sj015-0230-wei"></a>

<a id="event-3"></a>

3. **卫元君去世，角接任卫君。** 卫的统治者已经迁到野王，封国却尚未被正式废除。角承接君位，下一年开始他的元年；到秦统一六国时，这个小国的君统仍将继续存在。 本页沿年表与世家末年数的常用排法；另有君角更早在位的记载。 [[3]](#note-3)

<a id="sj043-zhao-famine-event"></a>

4. **赵国大饥，民间流传亡国忧惧的谣言。** 有人说赵哭秦笑，若不相信便看地上生毛；这是危机中的社会传言，不能当作自然现象已经预示胜负的证据。 [[4]](#sj043-zhao-famine-note)

<!-- /sj045-cite-092 -->

<a id="sj045-cite-093"></a>

**[《史记·韩世家》P035](../../sources/摘录/史记-卷045-韩世家.md#p035)**

> 太史公曰：韓厥之感晉景公，紹趙孤之子武，以成程嬰、公孫杵臼之義，此天下之陰德也。韓氏之功，於晉未睹其大者也。然與趙、魏終為諸侯十餘世，宜乎哉！

**本卷说明：** 太史公评论，非韩亡当年新增史事。保赵孤的德行解释源于另一传述，不能用来裁决经传下宫之难。白话：司马迁认为，韩厥感动晋景公、让赵武延续赵氏，成全了程婴、公孙杵臼的义举，是不显于外的善德；韩氏在晋的功业虽未见特别显赫，后来却能同赵魏成为诸侯、延续十余世，或许正与此相称。这是史家以德行解释家族兴起的评论，建立在救孤传述之上，不当作可由编年证明的因果定律。

<!-- /sj045-cite-093 -->

<a id="sj045-cite-094"></a>

**[《史记·韩世家》Z001](../../sources/摘录/史记-卷045-韩世家.md#z001)**

> 索隱述贊曰：韓氏之先，實宗周武。事微國小，春秋無語。後裔事晉，韓原是處。趙孤克立，智伯可取。旣徙平陽，又侵負黍。景趙據侯，惠文僭主。秦敗脩魚，魏會區鼠。韓非雖使，不禁狼虎。

**本卷说明：** 唐司马贞《索隐述赞》，主TXT没有此段，从仓内[三家注p33](../../sources/史记三家注/卷045.md#p33)另列Z001，不补进司马迁正文。白话：司马贞追述韩氏同周武王宗族、先世在韩原事晋，国小事迹不彰，后以保赵孤、取智伯而兴；又概括迁平阳、争负黍、列侯称王，遭秦败修鱼以及韩非出使仍不能止秦。赞中“景赵”“惠文”“魏会区鼠”等字句与正文有参差，按唐代后出文学概括保存，不据此改写每一场战役或会盟的国名。

# 公元前231年｜韩魏继续交地，秦开始登记男子年龄

[← 公元前232年](bce-0232.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前230年 →](bce-0230.md)

**秦王政十六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **秦派兵接收韩国南阳，魏国也献出土地。** 九月，秦派军队前去接收韩国交出的南阳地区，腾参与接管。交地暂时避免了这部分土地上的攻城，却没有使韩国摆脱后来被整体吞并的命运。 [[1]](#note-1)

<a id="event-2"></a>

2. **国家对人口的登记更加具体。** 秦开始命男子登记年龄，又设置丽邑。年龄登记关系到国家识别人力资源，但仅据这一条，不能断言秦的所有户籍或征役制度都从本年才开始。 [[2]](#note-2)

<a id="sj015-0231-zhao"></a>

<a id="event-3"></a>

3. **代地发生强烈地震。** 从乐徐以西到平阴一带，大量台屋墙垣倒塌，地面也出现长裂缝。这里是赵国北部代地的灾害，不能因为同页还记秦的政令，就改说成秦国境内的同一次地震。 原记台屋墙垣太半毁坏，地裂东西一百三十步。 [[3]](#note-3)

## 归年与考证

<a id="sj006-017-note"></a>
<a id="1十六年年条"></a>
#### 1｜十六年年条

[卷006 P017](../../sources/摘录/史记-卷006-秦始皇本纪.md#p017)：“九月，发卒受地韩南阳假守腾。初令男子书年。魏献地于秦。秦置丽邑。”其中“假守腾”与前句的句读涉及腾的职务及接管安排，正文只写参与接收，不据此杜撰由韩投秦的完整履历。秦代南阳不套用今天同名市界；“书年”按登记年龄解，不改成全国第一次人口普查。

<a id="sj015-0231-note"></a>
<a id="卷015八栏原表与本年互见"></a>
#### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../sources/摘录/史记-卷015-六国年表.md#y0231)。

<a id="sj015-0231-qin-note"></a>
**秦栏：** 置丽邑、派兵受韩南阳与[本页原注](#sj006-017-note)合并。

<a id="sj015-0231-wei-note"></a>
**魏栏：** 献城与本纪“魏献地于秦”互见，正文不凭表格增出未知城名、城数或新条约。

<a id="sj015-0231-han-note"></a>
**韩栏：** “秦来受地”与秦栏受南阳合一，不另列第二次交割。

<a id="sj015-0231-zhao-note"></a>
**赵栏：** “地大动”补[本页代地地震](#sj015-0231-zhao)。[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-43d73e02168b04)王迁五年及《通鉴》十六年给出代地、乐徐、平阴与损坏范围；采用古地名，不换算现代震级。前232本纪另有地动，不能只凭相邻年份自动合并。

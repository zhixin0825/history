# 公元前232年｜秦再次大举攻赵，燕太子丹逃回燕国

[← 公元前233年](bce-0233.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前231年 →](bce-0231.md)

**秦王政十五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **秦分兵进攻，赵仍在抵抗。** 秦大举出兵，一路进到邺，一路进到太原，并取得狼孟。赵将李牧在番吾迎战，击退秦军。年条还留下了一次地震的记录。 [[1]](#note-1)

<a id="sj-086-L5410-01"></a>

<a id="event-2"></a>

2. **太子丹从秦国逃回燕国。** 太子丹曾在赵国与秦王政相识，后来到秦国做人质，却没有得到他所期待的礼遇。他逃回燕国，开始寻找报复和抵抗秦国的办法。两人在赵国相识，是更早的经历，不是本年另一次会面。 [[2]](#note-2)

**[卷086《刺客列传》](../../拆分史书/史记/README.md#part-1-ref-sj-5410)**

> 居頃之，會燕太子丹質秦亡歸燕。燕太子丹者，故嘗質於趙，而秦王政生於趙，其少時與丹驩。及政立為秦王，而丹質於秦。秦王之遇燕太子丹不善，故丹怨而亡歸。歸而求為報秦王者，國小，力不能。其後秦日出兵山東以伐齊、楚、三晉，稍蠶食諸侯，且至於燕，燕君臣皆恐禍之至。太子丹患之，問其傅鞠武。武對曰：「秦地遍天下，威脅韓、魏、趙氏，北有甘泉、谷口之固，南有涇、渭之沃，擅巴、漢之饒，右隴、蜀之山，左關、殽之險，民眾而士厲，兵革有餘。意有所出，則長城之南，易水以北，未有所定也。柰何以見陵之怨，欲批其逆鱗哉！」丹曰：「然則何由？」對曰：「請入圖之。」

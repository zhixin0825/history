# 公元前233年｜李牧反击秦军，韩非出使后死于秦

[← 公元前234年](bce-0234.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前232年 →](bce-0232.md)

**秦王政十四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **秦军取得城邑，随后遭到李牧反击。** 秦军攻取宜安，赵方另记赤丽也被攻取。赵以李牧为大将军，在宜安、肥下一带击败秦军，桓齮退走。李牧因功受封武安君。平阳、武城的战事横跨两年，秦史所记战果与赵方反击见同号史料。 [[1]](#note-1)

<a id="sj-063-L4632-01"></a>

<a id="event-2"></a>

<a id="backstory-sj-063-L4620-01"></a>
<a id="登场前事韩非与李斯曾同学于荀卿"></a>

<a id="event-3"></a>

2. **韩非出使秦国，在狱中自杀。** 韩非来到秦国，却没有得到保全。秦王读到韩非的著作，希望见到他；韩国在秦的压力下派韩非出使，并表示愿意称臣。韩非到秦后，李斯、姚贾进言，认为他终究会替韩国打算。秦王将他交给官吏治罪，李斯又让人送药，韩非最终自杀。秦王后来派人赦免，已经来不及。韩非出自韩国公族，喜好刑名法术，擅长著书；他和李斯曾一起向荀卿学习，李斯自认为不如韩非。求学和早年写作在出使以前，确切年月未定。其背景已接在[前237年韩国与他商议应秦](bce-0237.md#event-3)之处，这里从出使结局回读此前经历。 [[2]](#note-2)

### 2. 韩非出使秦国，在狱中自杀

[返回正文第2条](#event-2)

**[卷063《老子韩非列传》](../../sources/摘录/史记-条目原文.md#ref-sj-4632)**

<a id="sj063-cite-035"></a>

> 人或傳其書至秦。秦王見《孤憤》、《五蠹》之書，曰：「嗟乎，寡人得見此人與之游，死不恨矣！」李斯曰：「此韓非之所著書也。」秦因急攻韓。韓王始不用非，及急，乃遣非使秦。秦王悅之，未信用。李斯、姚賈害之，毀之曰：「韓非，韓之諸公子也。今王欲并諸侯，非終為韓不為秦，此人之情也。今王不用，久留而歸之，此自遺患也，不如以過法誅之。」秦王以為然，下吏治非。李斯使人遺非藥，使自殺。韓非欲自陳，不得見。秦王後悔之，使人赦之，非已死矣。申子、韓子皆著書，傳於後世，學者多有。余獨悲韓子為說難而不能自脫耳。

[本卷完整读本 P024](../../sources/摘录/史记-卷063-老子韩非列传.md#p024)

**本卷说明：** 全文沿原有引文保留，末句余独悲属于司马迁第一人称感叹。韩非想自陈未得见与秦王后悔来不及，是传记所述；李斯、姚贾的动机也保持为该叙事的解释，不声称另有内心证据。秦本纪死云阳、韩世家王安五年与现用前233的年链差异见原同号说明。

<a id="sj006-015-note"></a>
<a id="1取城不能代替整场战局"></a>
#### 1｜取城不能代替整场战局

[卷006 P015](../../sources/摘录/史记-卷006-秦始皇本纪.md#p015) · [《通鉴》卷六，十四年](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7006.md#ref-abb38ddd7ca089)。《秦始皇本纪》十三年载桓齮攻平阳、杀扈辄，十四年又载桓齮定平阳、武城，不能将「定」径写成前233首次攻取。《赵世家》先在王迁二年记武城遭攻、扈辄援战而死，再于三年记秦攻赤丽、宜安及李牧在肥下却秦。《通鉴》在秦王政十三年即叙李牧败桓齮，十四年记秦取宜安、平阳、武城。正文依赵方年次叙反击，保留秦方「定」字及《通鉴》的编排。桓齮去向另有异说，见[卷081考证](../../meta/考证/史记-卷081-纪年与异说.md#扈辄败死李牧两却秦与赵亡)。

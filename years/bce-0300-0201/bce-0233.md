# 公元前233年｜李牧反击秦军，韩非出使后死于秦

[← 公元前234年](bce-0234.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前232年 →](bce-0232.md)

**秦王政十四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **秦军取得城邑，随后遭到李牧反击。** 桓齮继续攻赵，秦军攻取宜安、平阳、武城，并杀死赵军将领。赵方由李牧统兵抵抗，在宜安、肥下一带击败秦军，桓齮退回。夺到城池与随后遭遇败仗，是同一阶段的不同发展，不应只留前一半。 [[1]](#note-1)

<a id="sj-063-L4632-01"></a>

<a id="event-2"></a>

2. **韩非来到秦国，却没有得到保全。** 秦王读到韩非的著作，希望见到他；韩国在秦的压力下派韩非出使，并表示愿意称臣。韩非到秦后，李斯、姚贾进言，认为他终究会替韩国打算。秦王将他交给官吏治罪，李斯又让人送药，韩非最终自杀。秦王后来派人赦免，已经来不及。 [[2]](#note-2)

<a id="backstory-sj-063-L4620-01"></a>
<a id="登场前事韩非与李斯曾同学于荀卿"></a>

<a id="event-3"></a>

3. **登场前事｜韩非与李斯曾同学于荀卿。** 韩非出自韩国公族，喜好刑名法术，擅长著书。 他和李斯曾一起向荀卿学习，李斯自认为学问不及韩非。求学和早年写作在出使以前，确切年月未定；放在这里认识人物，不表示都发生于前233年。 [[3]](#note-3)

### 2. 韩非来到秦国，却没有得到保全

[返回正文第2条](#event-2)

**[卷063《老子韩非列传》](../../sources/摘录/史记-条目原文.md#ref-sj-4632)**

> 人或傳其書至秦。秦王見《孤憤》、《五蠹》之書，曰：「嗟乎，寡人得見此人與之游，死不恨矣！」李斯曰：「此韓非之所著書也。」秦因急攻韓。韓王始不用非，及急，乃遣非使秦。秦王悅之，未信用。李斯、姚賈害之，毀之曰：「韓非，韓之諸公子也。今王欲并諸侯，非終為韓不為秦，此人之情也。今王不用，久留而歸之，此自遺患也，不如以過法誅之。」秦王以為然，下吏治非。李斯使人遺非藥，使自殺。韓非欲自陳，不得見。秦王後悔之，使人赦之，非已死矣。申子、韓子皆著書，傳於後世，學者多有。余獨悲韓子為說難而不能自脫耳。

# 公元前234年｜桓齮击败赵军，赵将扈辄战死

[← 公元前235年](bce-0235.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前233年 →](bce-0233.md)

**秦王政十三年**

## 本年纪事

**赵军在平阳遭到重创。** 桓齮攻打赵国平阳，赵将扈辄战死，秦方所报战果为斩首十万人。此前几年不断的取城，发展成了又一次大规模杀伤。[1](#sj006-014-note)

**秦王前往河南，秦军继续攻赵。** 同一年，秦王到河南地区。年条又在十月记桓齮攻赵；正月还有彗星出现的记录。这些简短条目没有给出完整行程及两次军事行动的边界，不能自行补成逐日战报。[1](#sj006-014-note)

## 本年相关史料

<a id="sj006-014-note"></a>
### 1｜十三年年条

[卷006 P014](../../sources/摘录/史记-卷006-秦始皇本纪.md#p014)。扈辄在其他文本有异体写法；十万是史书记载的战果数字。“河南”是当时地域用语，不等于现代河南省的全部范围。秦军随后在宜安、肥下遭遇李牧反击，接见[前233年](bce-0233.md)，不把本次胜利延伸成此后每战必胜。

<a id="sj015-0234-note"></a>
### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../sources/摘录/史记-卷015-六国年表.md#y0234)。

<a id="sj015-0234-qin-note"></a>
**秦栏：** 平阳战败、扈辄死亡、斩首十万、继续东击及彗星与[本页原注](#sj006-014-note)合并。表秦栏却作“赵王之河南”，本纪作“王之河南”；正文保留本纪的秦王行程，表文作为人物主语异文单列，不能悄改原表赵为秦，更不能再凭它捏造一趟赵王赴河南的行程。

<a id="sj015-0234-zhao-note"></a>
**赵栏：** 败扈辄、斩首十万与秦栏同一战事；十万为古书记数，不把两栏重复相加为二十万。原格重复标点保留在来源层。

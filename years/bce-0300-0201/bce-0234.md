# 公元前234年｜桓齮击败赵军，赵将扈辄战死

[← 公元前235年](bce-0235.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前233年 →](bce-0233.md)

**秦王政十三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **赵军在平阳遭到重创。** 桓齮攻打赵国平阳，赵将扈辄战死，秦方所报战果为斩首十万人。此前几年不断的取城，发展成了又一次大规模杀伤。 赵篇把扈辄出战背景记为援救受秦攻打的武城。 [[1]](#note-1)

<a id="event-2"></a>

2. **秦王前往河南，秦军继续攻赵。** 同一年，秦王到河南地区。年条又在十月记桓齮攻赵；正月还有彗星出现的记录。这些简短条目没有给出完整行程及两次军事行动的边界，不能自行补成逐日战报。 [[2]](#note-2)

### 1. 赵军在平阳遭到重创

**[《史记·廉颇蔺相如列传》P024](../../拆分史书/史记/卷081.md#p024)**

> 後七年，秦破殺趙將扈輒於武遂城，斬首十萬。

<a id="sj043-cite-252"></a>

**[《史记·赵世家》P113](../../拆分史书/史记/卷043.md#p113)**

> 二年，秦攻武城，扈輒率師救之，軍敗，死焉。

**本卷说明：** 赵篇称秦攻武城、扈辄救援，秦篇重平阳战果；同一阶段合看，不虚增扈辄第二次战死。

## 归年与考证

<a id="sj006-014-note"></a>
<a id="1十三年年条"></a>
#### 1｜十三年年条

[卷006 P014](../../拆分史书/史记/卷006.md#p014)。扈辄在其他文本有异体写法；十万是史书记载的战果数字。“河南”是当时地域用语，不等于现代河南省的全部范围。秦军随后在宜安、肥下遭遇李牧反击，接见[前233年](bce-0233.md)，不把本次胜利延伸成此后每战必胜。

《天官书》回顾“秦始皇之時，十五年彗星四見”（[P118](../../拆分史书/史记/卷027.md#part-1-p118)），《汉书·天文志》作“十五年**間**彗星四見”（[互校H001](../../拆分史书/史记/卷027.md#part-2-h001)）。这是跨年概数，不是在始皇十五年另记四次彗星。本年天象仍依本纪自身年条；与[前240年](bce-0240.md#sj006-008-note)、[前238年](bce-0238.md#sj006-010-note)、[前234年](bce-0234.md#sj006-014-note)的关系及计次限制，见[考证](../../拆分史书/史记/卷027.md#kao-186d18aa61-f6127695e)。

<a id="sj015-0234-note"></a>
<a id="卷015八栏原表与本年互见"></a>
#### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../拆分史书/史记/卷015.md#y0234)。

<a id="sj015-0234-qin-note"></a>
**秦栏：** 平阳战败、扈辄死亡、斩首十万、继续东击及彗星与[本页原注](#sj006-014-note)合并。表秦栏却作“赵王之河南”，本纪作“王之河南”；正文保留本纪的秦王行程，表文作为人物主语异文单列，不能悄改原表赵为秦，更不能再凭它捏造一趟赵王赴河南的行程。

<a id="sj015-0234-zhao-note"></a>
**赵栏：** 败扈辄、斩首十万与秦栏同一战事；十万为古书记数，不把两栏重复相加为二十万。原格重复标点保留在来源层。

# 公元前235年｜吕不韦去世，吊丧的门客也受处罚

[← 公元前236年](bce-0236.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前234年 →](bce-0234.md)

**秦王政十二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **吕不韦退出朝廷以后，仍未能保住性命。** 他失去相位后，诸侯宾客和使者仍不断来往，秦王因此更加戒备，并命他与家属迁往蜀地。吕不韦在压力下饮毒而死，被私下安葬。曾经主持秦国大政的文信侯，至此走到终点。 [[1]](#note-1)

<a id="event-2"></a>

2. **参加吊丧也被视为政治问题。** 吕不韦的门客因籍贯、官秩及是否吊丧受到不同处罚，有的被驱逐，有的被夺爵迁徙。朝廷还宣布，以后主持国事而像嫪毐、吕不韦这样被认定“不道”的人，要照此处置其家门。 [[2]](#note-2)

<a id="event-3"></a>

3. **另一批旧案牵连者则得到赦复。** 秋天，先前因嫪毐案迁往蜀地的门客获准恢复。这个处置与惩罚吕不韦门客同时存在，不能把本年的政策概括成所有旧案一律加重。 [[3]](#note-3)

<a id="event-4"></a>

4. **从六月起持续干旱，到八月才下雨。** 年条最后记了一场跨月旱情。它的持续时间有记录，但没有足够数据估算减产比例或灾民总数。 [[4]](#note-4)

<a id="sj015-0235-chu"></a>

<a id="event-5"></a>

5. **秦与魏联合进攻楚国。** 秦征发四郡的军队，帮助魏国攻楚。吕不韦去世，并没有使秦停止经营东方的战争和联盟。 [[5]](#note-5)

<a id="sj015-0235-zhao"></a>

<a id="event-6"></a>

6. **赵王迁开始元年纪年。** 前一年已经发生的继承进入新王的元年；此时赵国仍保持王廷和军队，不能因后来亡国而提前把它写作秦的郡县。 [[6]](#note-6)

## 归年与考证

<a id="sj006-013-note"></a>
<a id="1十二年年条"></a>
#### 1｜十二年年条

[卷006 P013](../../sources/摘录/史记-卷006-秦始皇本纪.md#p013) · [《通鉴》卷六，十一、十二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7006.md#ref-3df3e9f1e31a7f)。迁蜀书信和饮毒由《通鉴》补足，本纪仅记死与窃葬。有关门客的“秦人六百石以上夺爵，迁；五百石以下不临，迁，勿夺爵”文字难以直接推演成无缺的量刑表；原文保留，不擅改“不临”为“临”。“复”不具体展开为每人的财产、官职都恢复原状。

<a id="卷015八栏原表与本年互见"></a>
#### 卷015｜八栏原表与本年互见

<a id="sj015-0235-qin-note"></a>
**秦栏：** 四郡兵助魏攻楚补[本页秦魏攻楚条](#sj015-0235-chu)，吕不韦卒及复嫪毐舍人与[原注](#sj006-013-note)合并。四郡未在表中具名，不补猜郡名。

<a id="sj015-0235-wei-note"></a>
**魏栏：** “秦助我击楚”与秦栏、楚栏合为一次战争，不再为魏方另列一次战役。

<a id="sj015-0235-zhao-note"></a>
**赵栏：** 赵王迁元年承接[前236年继立](bce-0236.md#sj015-0236-zhao)及[本页元年](#sj015-0235-zhao)。迁是人名，不是本行记赵王迁都。

<a id="sj015-0235-chu-note"></a>
**楚栏：** “秦、魏击我”与[本页战争](#sj015-0235-chu)合并；[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-97eb8dfc1ba144)幽王三年及《通鉴》十二年互证编年位置。

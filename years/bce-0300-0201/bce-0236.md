# 公元前236年｜王翦等分路攻赵，秦军夺取邺一带城邑

[← 公元前237年](bce-0237.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前235年 →](bce-0235.md)

**秦王政十一年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **秦军抓住赵国用兵于燕的时机，从不同方向攻入赵地。** 王翦、桓齮、杨端和参与进攻，取得九城。王翦又攻阏与、橑杨，桓齮进取邺、安阳。秦的推进不只是一次攻城，而是几路军队配合作战。 [[1]](#note-1)

<a id="event-2"></a>

2. **王翦调整参战人员。** 军队在作战过程中有过归并、遣返和选留人员的安排。留下继续从军的人经过挑选，不过原文涉及“斗食以下”“什推二人”的简略措辞，还不足以还原一套完整的秦军编制制度。 [[2]](#note-2)

<a id="sj015-0236-zhao"></a>

<a id="event-3"></a>

3. **赵悼襄王去世，王子迁继位。** 赵国一面与燕交战、一面遭秦进攻，年内又发生王位更替。迁接位以后，下一年开始他的元年。 [[3]](#note-3)

## 归年与考证

<a id="sj006-012-note"></a>
<a id="1分兵与选兵"></a>
#### 1｜分兵与选兵

[卷006 P012](../../sources/摘录/史记-卷006-秦始皇本纪.md#p012) · [《通鉴》卷六，十一年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7006.md#ref-abab9b8086db6d)。赵攻燕而秦乘机攻赵的衔接见《通鉴》。本纪“翦将十八日，军归斗食以下，什推二人从军取邺安阳，桓齮将”的句读及编制含义不完全清楚，保留原句，不将“十八日”扩大成整个战役只打十八天，也不直接换算出现代意义上的裁军比例。

<a id="sj015-0236-note"></a>
<a id="卷015八栏原表与本年互见"></a>
#### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../sources/摘录/史记-卷015-六国年表.md#y0236)。

<a id="sj015-0236-qin-note"></a>
**秦栏：** 王翦攻邺、阏与及九城与[本页战事](#sj006-012-note)合并。表把“吕不韦之河南”放本年，《通鉴》十年已经写免相、出就国，十一年写“就国岁余”；因此主线从[前237年免相出就封国](bce-0237.md#sj015-0237-note)，本年只保存不同编排，不制造第二次出封国。

<a id="sj015-0236-zhao-note"></a>
**赵栏：** 阏与、邺、九城与秦栏同事。[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-09bea019869c6e)悼襄九年及《通鉴》十一年还记悼襄王卒、迁继位，已补[本页继承](#sj015-0236-zhao)，接下一年元年。

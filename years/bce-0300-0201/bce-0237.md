# 公元前237年｜吕不韦免相，逐客令被收回

[← 公元前238年](bce-0238.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前236年 →](bce-0236.md)

**秦王政十年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

<a id="event-2"></a>

1. **嫪毐案余波，吕不韦免相，秦王迎回太后。** 嫪毐案继续震动朝廷，吕不韦被免相。吕不韦因嫪毐事件受到牵连，失去相位，离开朝廷前往河南封国。桓齮成为领兵将领，齐、赵也有人来秦置酒交往。朝廷内部发生清洗，国与国之间的交涉却还在继续。齐人茅焦劝秦王：正在争取天下，却背着放逐母亲的名声，会让诸侯离心。秦王接受劝说，将太后迎回咸阳，恢复她在甘泉宫的居处。 [[1]](#note-1)

<a id="event-3"></a>

2. **秦一度驱逐外来客卿，李斯劝阻成功。** 朝廷大规模搜查，并下令逐客。李斯上书说明这样会削弱秦国，秦王撤回了命令。李斯随后主张先向韩国施压，由此震慑其他国家，并受命赴韩。韩国担忧，与韩非商议应对；这不是说韩非本年已经死在秦国，他出使与遇害另见[前233年](bce-0233.md)。 此前，韩非出自韩国公族，喜刑名法术而归本黄老，有口吃，不长于当面游说，却善于著书。他与李斯曾同学于荀卿，李斯自认为不如他。 [[2]](#note-3)

<a id="event-4"></a>

3. **尉缭提出，用钱拆散诸侯的合作。** 来自大梁的尉缭提醒秦王，秦最应警惕的是几国突然合力。他建议花钱收买诸侯重臣，破坏各国谋划。秦王优待他并采用其策。尉缭后来想离开，秦王将他挽留，任为国尉；李斯也日益掌事。 [[3]](#note-4)

<a id="sj015-0237-chu"></a>

<a id="event-5"></a>

4. **楚幽王进入元年。** 考烈王去世和春申君遇害以后，楚国由幽王统治。本年是新王的元年，并不是春申君又遭一次杀害。 [[4]](#note-5)

<a id="sj046-jian-qin-event"></a>

5. **齐王建入朝秦国，秦王政在咸阳设宴。** 王建二十八年接前237，齐秦君主在秦都相见。本篇只记入朝与置酒，没有留下此次会谈的具体条件，不据后来亡齐反推本年已经签下不抵抗的承诺。 [[5]](#sj046-jian-qin-note)

**楚栏：** 幽王元年接[前238年继承](bce-0238.md#sj015-0238-chu)及[本页楚条](#sj015-0237-chu)。表作幽王“悼”，[《楚世家》](../../拆分史书/史记/卷040.md#part-1-text)与《通鉴》作“悍”；来源表保留悼字，正文以王号避免把他和早期楚悼王混同。

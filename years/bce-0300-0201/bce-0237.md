# 公元前237年｜吕不韦免相，逐客令被收回

[← 公元前238年](bce-0238.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前236年 →](bce-0236.md)

**秦王政十年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **嫪毐案继续震动朝廷，吕不韦被免相。** 吕不韦因嫪毐事件受到牵连，失去相位，离开朝廷前往河南封国。桓齮成为领兵将领，齐、赵也有人来秦置酒交往。朝廷内部发生清洗，国与国之间的交涉却还在继续。 [[1]](#note-1)

<a id="event-2"></a>

2. **太后从雍被迎回。** 齐人茅焦劝秦王：正在争取天下，却背着放逐母亲的名声，会让诸侯离心。秦王接受劝说，将太后迎回咸阳，恢复她在甘泉宫的居处。 [[2]](#note-2)

<a id="event-3"></a>

3. **秦一度驱逐外来客卿，李斯劝阻成功。** 朝廷大规模搜查，并下令逐客。李斯上书说明这样会削弱秦国，秦王撤回了命令。李斯随后主张先向韩国施压，由此震慑其他国家，并受命赴韩。韩国担忧，与韩非商议应对；这不是说韩非本年已经死在秦国，他出使与遇害另见[前233年](bce-0233.md)。 [[3]](#note-3)

<a id="event-4"></a>

4. **尉缭提出，用钱拆散诸侯的合作。** 来自大梁的尉缭提醒秦王，秦最应警惕的是几国突然合力。他建议花钱收买诸侯重臣，破坏各国谋划。秦王优待他并采用其策。尉缭后来想离开，秦王将他挽留，任为国尉；李斯也日益掌事。 [[4]](#note-4)

<a id="sj015-0237-chu"></a>

<a id="event-5"></a>

5. **楚幽王进入元年。** 考烈王去世和春申君遇害以后，楚国由幽王统治。本年是新王的元年，并不是春申君又遭一次杀害。 [[5]](#note-5)

## 归年与考证

<a id="sj006-011-note"></a>
<a id="1十年年条"></a>
#### 1｜十年年条

[卷006 P011](../../sources/摘录/史记-卷006-秦始皇本纪.md#p011)。逐客、止逐客、对韩施压和尉缭进言同在该年条，但具体月次未明。三十万金是尉缭方案中的估计，不是经核算的秦国实际支出。尉缭有关秦王相貌及“虎狼心”的话保留在引文与考证中：它是传世叙事中的人物评价，不是相貌可以证明性格的事实。吕不韦的死亡见[前235年](bce-0235.md)，不能在免相时提前写死。

<a id="sj015-0237-note"></a>
<a id="卷015八栏原表与本年互见"></a>
#### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../sources/摘录/史记-卷015-六国年表.md#y0237)。

<a id="sj015-0237-qin-note"></a>
**秦栏：** 吕不韦免相、齐赵来秦置酒、太后回咸阳及大索均见[本页原注](#sj006-011-note)，不重复造访秦与搜捕。《通鉴》把迎回太后接在前238年嫪毐案后；本站此条从本纪与表的明确十年位置，主叙仍在本页，不因互见在前238年再迎回一次。

<a id="sj015-0237-zhao-note"></a>
**赵栏：** 赵栏“入秦，置酒”与秦栏为同一往来；表未明说来者是赵王本人，不把“赵来”增译为已证实的国君亲访。

<a id="sj015-0237-chu-note"></a>
**楚栏：** 幽王元年接[前238年继承](bce-0238.md#sj015-0238-chu)及[本页楚条](#sj015-0237-chu)。表作幽王“悼”，[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-6d832830f4c38a)与《通鉴》作“悍”；来源表保留悼字，正文以王号避免把他和早期楚悼王混同。

<a id="sj015-0237-qi-note"></a>
**齐栏：** 齐栏“入秦，置酒”与秦栏合并；来者身份、宴会具体月日未详，不编造齐王与赵王同日到场。

**免相后的去处：**本页补吕不韦就河南封国，依据[《通鉴》卷六十年“免相，出就国”及十一年“就国岁余”](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7006.md#ref-107fb0ea888fdc)，与表前236年“之河南”的编排差异见[次年注](bce-0236.md#sj015-0236-qin-note)。

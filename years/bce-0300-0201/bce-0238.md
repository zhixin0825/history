# 公元前238年｜秦王行冠礼，嫪毐起兵失败

[← 公元前239年](bce-0239.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前237年 →](bce-0237.md)

**秦王政九年**

## 本年纪事

**秦王在雍行冠礼，嫪毐却试图调兵攻宫。** 四月，秦王住在雍；己酉日行冠礼、佩剑。嫪毐的阴谋暴露后，盗用秦王和太后的印玺，调动县卒、卫卒、官骑及自己的宾客等，准备攻击蕲年宫。秦王命昌平君、昌文君出兵，双方在咸阳交战，嫪毐战败逃走。[1](#sj006-010-note)

**镇压很快扩大为整批清算。** 朝廷悬赏捉拿嫪毐，活捉与杀死分别有赏。嫪毐及同党最终被捕，他被车裂示众，家族受牵连；二十名相关官员被枭首，一部分门客服刑，四千余家被夺爵迁往蜀地、房陵。参与平乱的人受赏，宦者也因参战获爵。[1](#sj006-010-note)

**对外作战没有停。** 秦军还攻打魏的垣、蒲阳，杨端和攻衍氏。年条另外记录彗星及反常寒冻，寒冷造成了死亡；这些与政变同列，并不构成天象导致政变的证据。[1](#sj006-010-note)

<a id="sj015-0238-chu"></a>
**楚考烈王去世，春申君在宫门遭到伏击。** 考烈王死后，李园抢先入宫，把伏兵安排在棘门内。春申君黄歇入宫时被杀，家属也受到诛杀；楚幽王接位。黄歇长期主持楚政，直到王位交替之际，原有权势也没有保住他的性命。 [原表与说明](#sj015-0238-note)

<a id="sj015-0238-han"></a>
**韩王安开始以元年纪年。** 他在前一年接位，本年进入新王的第一个纪年；秦仍在邻近的魏地继续用兵。 [原表与说明](#sj015-0238-note)

## 本年相关史料

<a id="sj006-010-note"></a>
### 1｜冠礼、政变与处罚

[卷006 P010](../../sources/摘录/史记-卷006-秦始皇本纪.md#p010)。冠礼在雍、战斗在咸阳，不能写成在同一座宫殿举行冠礼时当场交战。四千余家是原文量级；“家房陵”接在迁蜀之后，保留目的地叙述，不拿今天的省界解释秦代“蜀”的用法。太后被迁雍这一前情，结合下一年迎回咸阳的记载理解，不另造迁出日期。原文寒冻月份有“四／是”异文，见来源页。

<a id="sj015-0238-chu-note"></a>
**楚栏：** 李园杀春申君已补[本页楚条](#sj015-0238-chu)，同时据[《楚世家》](https://zh.wikisource.org/wiki/史記/卷040#楚考烈王)、[《春申君列传》](https://zh.wikisource.org/wiki/史記/卷078)交代考烈王卒、幽王立和宫门伏击。列传关于献有孕之妹、幽王生父的故事作为传世身世说，不据此断言已经独立查明血缘；李园的密谋动机也不扩大为唯一确证。

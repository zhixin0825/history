# 公元前238年｜秦王行冠礼，嫪毐起兵失败

[← 公元前239年](bce-0239.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前237年 →](bce-0237.md)

**秦王政九年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **秦王在雍行冠礼，嫪毐却试图调兵攻宫。** 四月，秦王住在雍；己酉日行冠礼、佩剑。嫪毐的阴谋暴露后，盗用秦王和太后的印玺，调动县卒、卫卒、官骑及自己的宾客等，准备攻击蕲年宫。秦王命昌平君、昌文君出兵，双方在咸阳交战，嫪毐战败逃走。 [[1]](#note-1)

<a id="event-2"></a>

2. **镇压很快扩大为整批清算。** 朝廷悬赏捉拿嫪毐，活捉与杀死分别有赏。嫪毐及同党最终被捕，他被车裂示众，家族受牵连；二十名相关官员被枭首，一部分门客服刑，四千余家被夺爵迁往蜀地、房陵。参与平乱的人受赏，宦者也因参战获爵。 [[2]](#note-2)

<a id="event-3"></a>

3. **对外作战没有停。** 秦军还攻打魏的垣、蒲阳，杨端和攻衍氏。年条另外记录彗星及反常寒冻，寒冷造成了死亡；这些与政变同列，并不构成天象导致政变的证据。 [[3]](#note-3)

<a id="sj015-0238-chu"></a>

<a id="event-4"></a>

4. **楚考烈王去世，子悍继位，春申君在宫门遇害。** 考烈王在位二十五年，子悍承位，为幽王。李园先入宫，在棘门内置伏；黄歇入宫被杀，家属亦遭诛杀。长期主持楚政的春申君，终未能在王位交接中保住权势与性命。 [[4]](#note-4)

<a id="sj015-0238-han"></a>

<a id="event-5"></a>

5. **韩王安开始以元年纪年。** 他在前一年接位，本年进入新王的第一个纪年；秦仍在邻近的魏地继续用兵。 [[5]](#note-5)

## 归年与考证

<a id="sj006-010-note"></a>
<a id="1冠礼政变与处罚"></a>
#### 1｜冠礼、政变与处罚

[卷006 P010](../../sources/摘录/史记-卷006-秦始皇本纪.md#p010)。冠礼在雍、战斗在咸阳，不能写成在同一座宫殿举行冠礼时当场交战。四千余家是原文量级；“家房陵”接在迁蜀之后，保留目的地叙述，不拿今天的省界解释秦代“蜀”的用法。太后被迁雍这一前情，结合下一年迎回咸阳的记载理解，不另造迁出日期。原文寒冻月份有“四／是”异文，见来源页。

《天官书》回顾“秦始皇之時，十五年彗星四見”（[P118](../../sources/摘录/史记-卷027-天官书.md#p118)），《汉书·天文志》作“十五年**間**彗星四見”（[互校H001](../../sources/摘录/史记-卷027-纪年互校.md#h001)）。这是跨年概数，不是在始皇十五年另记四次彗星。本年天象仍依本纪自身年条；与[前240年](bce-0240.md#sj006-008-note)、[前238年](bce-0238.md#sj006-010-note)、[前234年](bce-0234.md#sj006-014-note)的关系及计次限制，见[考证](../../meta/考证/史记-卷027-纪年与异说.md#秦十五年)。

**韩栏：** 韩王安元年已补[本页韩条](#sj015-0238-han)，继位在[前239年](bce-0239.md#sj015-0239-han)，据《通鉴》衔接。

<a id="sj015-0238-chu-note"></a>
**楚栏：** 李园杀春申君已补[本页楚条](#sj015-0238-chu)，同时据[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-78cdd921d4af91)、[《春申君列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7078.md#ref-702cc00f6a49c8)交代考烈王卒、幽王立和宫门伏击。列传关于献有孕之妹、幽王生父的故事作为传世身世说，不据此断言已经独立查明血缘；李园的密谋动机也不扩大为唯一确证。

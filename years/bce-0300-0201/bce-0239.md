# 公元前239年｜成蟜反叛败死，嫪毐获封长信侯

[← 公元前240年](bce-0240.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前238年 →](bce-0238.md)

**秦王政八年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **出征的王弟在屯留反叛。** 秦王的弟弟、长安君成蟜带兵攻赵，途中反叛，最终死于屯留。军中官吏遭到处决，当地居民被迁往临洮。牵连范围不止成蟜本人，还扩及军队与地方居民。 [[1]](#note-1)

<a id="event-2"></a>

2. **有人向东寻找粮食。** 年条记黄河鱼群大量上溯，又说车辆向东去找吃的。材料留下了粮食供应紧张的一个侧面，却没有说明迁行人数或完整范围。 [[2]](#note-2)

<a id="event-3"></a>

3. **嫪毐得到封地，权势迅速膨胀。** 嫪毐被封为长信侯，获得山阳等地，宫室、车马、服饰、苑囿享用优厚，还能左右政事。河西、太原一带又有土地划给他。这个依托宫廷取得权势的人，正在成为另一股重要力量。 [[3]](#note-3)

<a id="sj015-0239-han"></a>

<a id="event-4"></a>

4. **韩桓惠王去世，王子安接位。** 韩国王位由桓惠王传给安。次年才开始记韩王安元年，不能把承位和改元写成两次即位。 [[4]](#note-4)

<a id="1成蟜与嫪毐"></a>
#### 1｜成蟜与嫪毐

[卷006 P009](../../sources/摘录/史记-卷006-秦始皇本纪.md#p009)。成蟜段“将军壁死，卒屯留、蒲鹤反，戮其尸”的句读、人物及承接存在困难，保留原句，不杜撰一位名叫“壁”的将军或第二次独立兵变。嫪毐的早年及与太后的关系可由《吕不韦列传》继续互校；本页不据后来的结局倒造受封的具体内幕。“河鱼大上”也不是现代渔获量统计。

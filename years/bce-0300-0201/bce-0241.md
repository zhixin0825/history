# 公元前241年｜诸侯合兵攻秦，秦反击后迫卫东迁

[← 公元前242年](bce-0242.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前240年 →](bce-0240.md)

**秦王政六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **几国合兵，也没能制止秦的推进。** 诸侯联合进攻秦国，一度夺取寿陵；秦出兵迎击，联军随后退去。攻秦并不是从未取得局部战果，但这次行动仍未能逆转秦向东扩张的形势。 [[1]](#note-1)

<a id="event-2"></a>

2. **卫的统治者迁到野王。** 秦继续向卫地和东郡一带推进，卫君带着宗族迁居野王，依靠当地山地及魏国河内地区维持处境。卫此时失去重要旧地，但不能因此就写成卫的封国已经彻底消失。 [[2]](#note-2)

<a id="sj015-0241-wei"></a>

<a id="event-3"></a>

3. **秦还攻取了魏国朝歌。** 联军退去后，秦对魏、卫的推进继续进行；朝歌的失陷与濮阳被并入秦地、卫君迁居野王同见这一阶段的记载。 [[3]](#note-3)

<a id="sj015-0241-chu"></a>

<a id="event-4"></a>

4. **楚国把都城进一步迁向东面。** 楚考烈王离开陈，迁都寿春，并把新都继续称作郢。秦军已越来越接近原来的都城，楚廷试图借迁都拉开距离。 [[4]](#note-4)

## 归年与考证

<a id="sj006-007-note"></a>
<a id="1合纵与卫君身份"></a>
#### 1｜合纵与卫君身份

[卷006 P007](../../sources/摘录/史记-卷006-秦始皇本纪.md#p007)。本纪列韩、魏、赵、卫、楚；其他篇章及《通鉴》的联军名单不完全相同，正文不强凑唯一完整名单。更明显的问题是本纪称迁野王者为“其君角”：与《卫康叔世家》元君迁野王、后来君角继立的世次抵牾，正文只称卫君，不让角提前登场。相关原文和取舍见[卷006纪年与异说](../../meta/考证/史记-卷006-纪年与异说.md#卫君与合纵)。

<a id="sj015-0241-note"></a>
<a id="卷015八栏原表与本年互见"></a>
#### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../sources/摘录/史记-卷015-六国年表.md#y0241)。

<a id="sj015-0241-qin-note"></a>
**秦栏：** 五国攻秦并入[既有合纵条及注](#sj006-007-note)。参战名单有韩／燕／卫等互见差异，原表仅说五国，不能据它独自裁定全部名单。

<a id="sj015-0241-wei-note"></a>
**魏栏：** 朝歌失陷补[本页朝歌条](#sj015-0241-wei)，卫由濮阳迁野王合入[原注](#sj006-007-note)；[《通鉴》卷六](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7006.md#ref-8b40af342cbe57)分别明记二者。卫事借记魏栏不变成魏王迁都，元君也不改名为角。

<a id="sj015-0241-chu-note"></a>
**楚栏：** 楚考烈王迁寿春并继续称郢，已补[本页迁都条](#sj015-0241-chu)。[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-3a0ba26ca75b35)考烈二十二年与《通鉴》六年相合；新都沿旧都号，不表示返回白起攻破的旧郢。

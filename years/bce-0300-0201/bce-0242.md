# 公元前242年｜蒙骜取魏二十城，秦设置东郡

[← 公元前243年](bce-0243.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前241年 →](bce-0241.md)

**秦王政五年**

## 本年纪事

**秦把向东夺取的土地编成新郡。** 蒙骜进攻魏国，攻取酸枣、燕、虚、长平、雍丘、山阳等城，所报总数为二十城。秦随后设置东郡。战场上的夺城，由此接成了地方行政的扩张。[1](#sj006-006-note)

**冬季打雷。** 年条还记了一次冬雷。它在当时值得被记入国史，但不能仅凭这一条推出秦国全年气候异常，更不能将它解释成政权兴亡的征兆。[1](#sj006-006-note)

<a id="sj015-0242-wei"></a>
**魏景湣王进入元年，赵魏两国继续联络。** 魏国新王的纪年从本年开始；两国的相在柯会面结盟。秦不断向东夺城，使诸侯之间的联合仍然十分迫切。 [原表与说明](#sj015-0242-note)

<a id="sj015-0242-yan"></a>
**燕国攻赵，却损失了主将剧辛。** 燕王见赵国屡受秦军打击，派剧辛出兵，想趁其疲弱取利。赵将庞煖迎战，剧辛战败身死。剧辛早年在赵时与庞煖相识，后来才到燕国任职；熟悉对手并没有使他赢得这一仗。 [原表与说明](#sj015-0242-note)

## 本年相关史料

<a id="sj006-006-note"></a>
### 1｜取城与置郡

[卷006 P006](../../sources/摘录/史记-卷006-秦始皇本纪.md#p006)。“燕”是此处所列城名，不是说这一年灭掉燕国；“长平”也不能未经地理核查便认作前260年大战的同一战场。东郡设立不等于所有边界已能据这一段复原。

<a id="sj015-0242-note"></a>
### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../sources/摘录/史记-卷015-六国年表.md#y0242)。

<a id="sj015-0242-qin-note"></a>
**秦栏：** 蒙骜取二十城、置东郡已经并入[本页注1](#sj006-006-note)；酸枣是所列城邑之一，不把“酸枣二十城”误写为二十座都叫酸枣的城。

<a id="sj015-0242-wei-note"></a>
**魏栏：** “景湣王元年”承接[前243年继立](bce-0243.md#sj015-0243-wei)；秦取二十城与秦栏合并，元年不是另一次即位。景湣王名增／午有传本差异，[《魏世家》](https://zh.wikisource.org/wiki/史記/卷044#魏安釐王)及《通鉴》校记不同，正文仅用王号。

<a id="sj015-0242-zhao-note"></a>
**赵栏：** 赵相、魏相会柯结盟已入[本页赵魏条](#sj015-0242-wei)。“柯”在三家注本有“（鲁）柯”校记，不凭删补自行指定现代地点，也不编造两相姓名或盟书条款。

<a id="sj015-0242-yan-note"></a>
**燕栏：** “剧辛死于赵”补入[本页剧辛条](#sj015-0242-yan)。[《通鉴》卷六](https://zh.wikisource.org/wiki/資治通鑑/卷006)记庞煖杀剧辛，[《赵世家》](https://zh.wikisource.org/wiki/史記/卷043#趙悼襄王)记“禽其将剧辛”；采用败亡这一共同结局，未补死刑地点和具体日期。两人旧交属登场前事。

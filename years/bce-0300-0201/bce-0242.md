# 公元前242年｜蒙骜取魏二十城，秦设置东郡

[← 公元前243年](bce-0243.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前241年 →](bce-0241.md)

**秦王政五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **秦把向东夺取的土地编成新郡。** 蒙骜进攻魏国，攻取酸枣、燕、虚、长平、雍丘、山阳等城，所报总数为二十城。秦随后设置东郡。战场上的夺城，由此接成了地方行政的扩张。 [[1]](#note-1)

<a id="event-2"></a>

2. **冬季打雷。** 年条还记了一次冬雷。它在当时值得被记入国史，但不能仅凭这一条推出秦国全年气候异常，更不能将它解释成政权兴亡的征兆。 [[2]](#note-2)

<a id="sj015-0242-wei"></a>

<a id="event-3"></a>

3. **魏景湣王进入元年，赵魏两国继续联络。** 魏国新王的纪年从本年开始；两国的相在柯会面结盟。秦不断向东夺城，使诸侯之间的联合仍然十分迫切。 [[3]](#note-3)

<a id="sj015-0242-yan"></a>

<a id="event-4"></a>

4. **燕国攻赵，剧辛轻视旧交庞煖而战败身死。** 燕王见赵国屡受秦军打击、廉颇又已离去，想趁其疲弱取利。剧辛早年住在赵国，与庞煖相好，后来才到燕国任职；被问及能否攻赵时，他认为庞煖容易对付。燕王派他统军，赵以庞煖迎战，燕军大败，剧辛被杀，传世记载说赵军取得燕军二万人。 [[4]](#note-4)

## 归年与考证

<a id="sj006-006-note"></a>
<a id="1取城与置郡"></a>
#### 1｜取城与置郡

[卷006 P006](../../sources/摘录/史记-卷006-秦始皇本纪.md#p006)。“燕”是此处所列城名，不是说这一年灭掉燕国；“长平”也不能未经地理核查便认作前260年大战的同一战场。东郡设立不等于所有边界已能据这一段复原。

<a id="sj015-0242-note"></a>
<a id="卷015八栏原表与本年互见"></a>
#### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../sources/摘录/史记-卷015-六国年表.md#y0242)。

<a id="sj015-0242-qin-note"></a>
**秦栏：** 蒙骜取二十城、置东郡已经并入[本页注1](#sj006-006-note)；酸枣是所列城邑之一，不把“酸枣二十城”误写为二十座都叫酸枣的城。

<a id="sj015-0242-wei-note"></a>
**魏栏：** “景湣王元年”承接[前243年继立](bce-0243.md#sj015-0243-wei)；秦取二十城与秦栏合并，元年不是另一次即位。景湣王名增／午有传本差异，[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-8950c09a41d13a)及《通鉴》校记不同，正文仅用王号。

<a id="sj015-0242-zhao-note"></a>
**赵栏：** 赵相、魏相会柯结盟已入[本页赵魏条](#sj015-0242-wei)。“柯”在三家注本有“（鲁）柯”校记，不凭删补自行指定现代地点，也不编造两相姓名或盟书条款。

<a id="sj015-0242-yan-note"></a>
**燕栏：** “剧辛死于赵”补入[本页剧辛条](#sj015-0242-yan)。[《通鉴》卷六](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7006.md#ref-104d8cacd7a311)记庞煖杀剧辛，[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-d2aef54ae002c5)记“禽其将剧辛”；采用败亡这一共同结局，未补死刑地点和具体日期。两人旧交属登场前事。

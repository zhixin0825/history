# 公元前243年｜秦取畅、有诡，蝗灾与疫病接踵而来

[← 公元前244年](bce-0244.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前242年 →](bce-0242.md)

**秦王政四年**

## 本年纪事

**前一阶段的攻城结束，秦赵互遣质子回国。** 秦军攻下魏国的畅、有诡，三月罢兵。秦国留在赵国的质子回来，赵太子也获准返回赵国。双方交还质子，不等于此后不再交战。[1](#sj006-005-note)

**蝗虫蔽天，疫病流行；朝廷用爵位换取粮食。** 秋七月，蝗虫从东方飞来，遮蔽天空，又记疫病流行。朝廷允许百姓缴纳一千石粮食，换取一级爵位。粮食因此不仅是日常口粮，也成为国家募集资源的条件。[1](#sj006-005-note)

<a id="sj015-0243-wei"></a>
**魏国在同一年失去国君和信陵君。** 魏安釐王去世，景湣王继位；曾经率领联军击退秦军的信陵君无忌也在本年去世。他先前被撤去兵权，此后离开政事、沉湎饮酒的经历，是此前数年的过程，不是本年才突然发生。 [原表与说明](#sj015-0243-note)

## 本年相关史料

<a id="sj006-005-note"></a>
### 1｜四年年条

[卷006 P005](../../sources/摘录/史记-卷006-秦始皇本纪.md#p005)。保留“三月”“十月庚寅”的古历用语，不把它们直接改写成同号公历月日。“天下疫”不能据此换算出全国人口感染率；纳粟拜爵也不是出钱买官职。

<a id="sj015-0243-note"></a>
### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../sources/摘录/史记-卷015-六国年表.md#y0243)。

<a id="sj015-0243-qin-note"></a>
**秦栏：** 本格以七月记蝗灾，纳粟千石授爵一级与[原注](#sj006-005-note)同事。本纪作十月庚寅，《通鉴》卷六及其校记采用七月，正文随编年底本记秋七月；两种古历月数照录，未声称经过独立历算。千石是原书粮食量，不是官职售价。

<a id="sj015-0243-wei-note"></a>
**魏栏：** 信陵君无忌之死已补[本页魏条](#sj015-0243-wei)。[《魏世家》](https://zh.wikisource.org/wiki/史記/卷044#魏安釐王)以安釐王三十四年并记君、公子之死及景湣王继立；《通鉴》本年也记安釐王卒。列传的被罢兵权与沉湎酒色是此前过程，不当成另一组本年新事件。

<a id="sj015-0243-zhao-note"></a>
**赵栏：** “太子从质秦归”接[本页秦赵交换质子](#sj006-005-note)。[《赵世家》](https://zh.wikisource.org/wiki/史記/卷043#趙悼襄王)同年另叙秦留春平君、后遣归；其人与“太子”的对应尚不足凭同年判定，本页不把两名号强并。

<a id="sj015-0243-yan-note"></a>
**燕栏：** 取武遂、方城主叙依《通鉴》置[前244年](bce-0244.md#sj015-0244-zhao)，本格与《赵世家》则在悼襄二年。本页保存异年入口，不写成赵军连续两年各攻克同样两城。

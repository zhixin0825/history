# 公元前243年｜秦取畅、有诡，李牧攻燕取两城

[← 公元前244年](bce-0244.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前242年 →](bce-0242.md)

**秦王政四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **前一阶段的攻城结束，秦赵互遣质子回国。** 秦军攻下魏国的畅、有诡，三月罢兵。秦国留在赵国的质子回来，赵太子也获准返回赵国。秦王后来追述，赵曾派李牧赴秦订盟，因而遣返赵质子。同阶段春平君又曾被秦召来扣留。泄钧劝文信侯吕不韦，春平君得赵王宠信，郎中妒他，正合谋送来，预计秦会留人；秦若扣住，便绝赵而中郎中计，不如放春平、留平都，春平回赵得王信，王会厚割地赎平都。吕不韦答应放人，本篇没有接着证明赵确已割地。 [[1]](#note-1)

<a id="event-2"></a>

2. **蝗虫蔽天，疫病流行；朝廷用爵位换取粮食。** 秋七月，蝗虫从东方飞来，遮蔽天空，又记疫病流行。朝廷允许百姓缴纳一千石粮食，换取一级爵位。粮食因此不仅是日常口粮，也成为国家募集资源的条件。 [[2]](#note-2)

<a id="sj015-0243-wei"></a>

<a id="event-3"></a>

3. **魏国在同一年失去国君和信陵君。** 魏安釐王去世，景湣王继位；曾经率领联军击退秦军的信陵君无忌也在本年去世。他先前被撤去兵权，此后离开政事、沉湎饮酒的经历，是此前数年的过程，不是本年才突然发生。 [[3]](#note-3)

<a id="sj043-hangao-event"></a>

4. **赵修筑韩皋。** 悼襄王二年的末条记此城工，与春平君交涉并无明示因果。 [[4]](#sj043-hangao-note)

<a id="event-5"></a>

5. **李牧率赵军攻燕，取武遂、方城。** 此前他曾在赵国北部的代地、雁门驻守，防御匈奴的经历见[时期阅读](时期-廉蔺交谊与李牧守边.md#note-7)。此役另有前244年一说。 [[5]](#note-5)

### 1. 前一阶段的攻城结束，秦赵互遣质子回国

[返回正文第1条](#event-1)

**[卷006 P005](../../sources/摘录/史记-卷006-秦始皇本纪.md#p005)**

> 四年，拔暢、有詭。三月，軍罷。秦質子歸自趙，趙太子出歸國。十月庚寅，蝗蟲從東方來，蔽天。天下疫。百姓內粟千石，拜爵一級。

[史料说明](#sj006-005-note)

<a id="sj043-cite-243"></a>

**[《史记·赵世家》P110](../../sources/摘录/史记-卷043-赵世家.md#p110)**

> 秦召春平君，因而留之。泄鈞為之謂文信侯曰：「春平君者，趙王甚愛之而郎中之，故相與謀曰『春平君入秦，秦必留之』，故相與謀而內之秦也。今君留之，是絕趙而郎中之計中也。君不如遣春平君而留平都。春平君者言行信於王，王必厚割趙而贖平都。」文信侯曰：「善。」因遣之。

**本卷说明：** 春平君被留获释的故事与质子往返同阶段附读，但不强认春平君就是秦纪所称赵太子。主TXT“郎中之”脱妒字，[三家注p111](../../sources/史记三家注/卷043.md#p111)。

<!-- /sj043-cite-243 -->

**[《史记·秦始皇本纪》秦王统一后追述](../../sources/本地分卷/史记/史记-卷006.md#L364)**

> 趙王使其相李牧來約盟，故歸其質子。

**归年说明：** 秦王事后以秦赵盟约解释归还质子，称李牧为赵相。王政四年本纪与《六国年表》赵栏同记归质子，故在此互见。原文没有独立交代约盟日或李牧任相日。

## 归年与考证

<a id="sj006-005-note"></a>
<a id="1四年年条"></a>
#### 1｜四年年条

[卷006 P005](../../sources/摘录/史记-卷006-秦始皇本纪.md#p005)。保留“三月”“十月庚寅”的古历用语，不把它们直接改写成同号公历月日。“天下疫”不能据此换算出全国人口感染率；纳粟拜爵也不是出钱买官职。

<a id="sj015-0243-note"></a>
<a id="卷015八栏原表与本年互见"></a>
#### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../sources/摘录/史记-卷015-六国年表.md#y0243)。

<a id="sj015-0243-qin-note"></a>
**秦栏：** 本格以七月记蝗灾，纳粟千石授爵一级与[原注](#sj006-005-note)同事。本纪作十月庚寅，《通鉴》卷六及其校记采用七月，正文随编年底本记秋七月；两种古历月数照录，未声称经过独立历算。千石是原书粮食量，不是官职售价。

<a id="sj015-0243-wei-note"></a>
**魏栏：** 信陵君无忌之死已补[本页魏条](#sj015-0243-wei)。[《魏世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-1e6c35af22a70f)以安釐王三十四年并记君、公子之死及景湣王继立；《通鉴》本年也记安釐王卒。列传的被罢兵权与沉湎酒色是此前过程，不当成另一组本年新事件。

<a id="sj015-0243-zhao-note"></a>
**赵栏：** “太子从质秦归”接[本页秦赵交换质子](#sj006-005-note)。[《赵世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-d7283b47c76868)同年另叙秦留春平君、后遣归；其人与“太子”的对应尚不足凭同年判定，本页不把两名号强并。

<a id="sj015-0243-yan-note"></a>
**燕栏：** 与《燕召公世家》燕王喜十二年、《赵世家》赵悼襄王二年合读，主叙见[本页第5条](#note-5)。前244一说存[相邻年页](bce-0244.md#note-3)。

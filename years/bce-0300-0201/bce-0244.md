# 公元前244年｜蒙骜攻韩取城，秦国又遇大饥荒

[← 公元前245年](bce-0245.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前243年 →](bce-0243.md)

**秦王政三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **秦军先攻韩，又向魏进兵。** 蒙骜进攻韩国，取得十余座城。年条又记十月攻打魏国的畅、有诡；这两座城的攻下，接在下一年。另一位秦将王齮在本年去世。 [[1]](#note-1)

<a id="event-2"></a>

2. **战争之外，还有饥荒。** 同一年，秦国发生严重饥荒。原文没有说明灾荒范围及死伤，不能把“取得十三城”当成国内生活也同时改善的证明。 [[2]](#note-2)

<a id="sj015-0244-zhao"></a>

<a id="event-3"></a>

3. **赵悼襄王进入元年；赵军向燕国进兵。** 李牧率赵军攻下燕国的武遂、方城。李牧此前长期守卫赵国北边，先以严守营垒、保存人马的办法抵御匈奴，待军队准备充分才出击；这些守边经历早于本次攻燕，不能全排在这一年。 [[3]](#note-3)

## 归年与考证

<a id="sj006-004-note"></a>
<a id="1三年年条"></a>
#### 1｜三年年条

[卷006 P004](../../sources/摘录/史记-卷006-秦始皇本纪.md#p004)。完整年条含攻韩、王齮死、十月攻魏及大饥。古月保留原样；该段的行文次序不等于已经换算出的公历时间次序。畅、有诡的攻克见[前243年](bce-0243.md)，不将跨年战事压成一天。

<a id="sj015-0244-note"></a>
<a id="卷015八栏原表与本年互见"></a>
#### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../sources/摘录/史记-卷015-六国年表.md#y0244)。

<a id="sj015-0244-qin-note"></a>
**秦栏：** 蒙骜攻韩及王齮死见[本页原注](#sj006-004-note)。本纪、年表作十三城，《通鉴》三年作十二城，正文改用“十余城”保留共同范围，两种确数均存于注；不凭重复见证称已精确统计。

<a id="sj015-0244-han-note"></a>
**韩栏：** “秦拔我十三城”与秦栏为同一战役，不另计一场。十二／十三城的异文同上。

<a id="sj015-0244-zhao-note"></a>
**赵栏：** 表以本年为悼襄王偃元年。[《通鉴》卷六](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7006.md#ref-bcb34eb2b97168)二年条将赵孝成王卒、悼襄王立置[前245年](bce-0245.md#sj015-0245-zhao)，本页只承接元年。表前243燕栏及[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-7f5a194df0373b)悼襄二年记取武遂、方城，《通鉴》置本年，正文从编年底本，前243留回链。李牧守边背景也见《通鉴》本年追叙，不给早年抗匈奴另造精确年份。

# 公元前245年｜麃公攻卷，秦继续向东用兵

[← 公元前246年](bce-0246.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前244年 →](bce-0244.md)

**秦王政二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **麃公率军攻打卷。** 平定晋阳后，秦军的进攻没有停止。麃公带兵攻卷，所报战果为斩首三万人。国王仍年轻，对外作战继续由原有将领承担。 [[1]](#note-1)

<a id="sj015-0245-zhao"></a>

<a id="event-2"></a>

2. **赵王更替，廉颇离开赵国。** 赵孝成王去世，悼襄王继位。新王用乐乘代替廉颇领兵，廉颇不服，出兵攻击乐乘，随后出奔魏国。廉颇后来能否回赵、最终死于何地，是这一变故以后发生的事，不一并算入本年。 [[2]](#note-2)

## 归年与考证

<a id="sj006-003-note"></a>
<a id="1攻卷"></a>
#### 1｜攻卷

[卷006 P003](../../sources/摘录/史记-卷006-秦始皇本纪.md#p003)：“二年，麃公將卒攻卷，斬首三萬。”数字是史书所报战果，不当作现代独立统计；原文没有交代月份、攻城经过及双方总兵力，不补造。

<a id="sj015-0245-note"></a>
<a id="卷015八栏原表与本年互见"></a>
#### 卷015｜八栏原表与本年互见

[《六国年表》本年原行](../../sources/摘录/史记-卷015-六国年表.md#y0245)。本行只有在位年数，没有另列纪事；已核对各栏的连续数。原有本纪等来源的正文仍保留，不能因为年表简略而删掉其他史料。

为承接下一行赵悼襄王元年，赵孝成王卒、悼襄王立与廉颇出奔魏，另据[《通鉴》卷六秦王政二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7006.md#ref-9bfc44b3024e8d)补入[本页赵条](#sj015-0245-zhao)。同段随后追叙廉颇求复用、郭开阻挠、入楚及死亡，均非本年已确之事，本页没有把这些后事一起提前。

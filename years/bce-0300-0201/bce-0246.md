# 公元前246年｜少年秦王接手大国，蒙骜平定晋阳

[← 公元前247年](bce-0247.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前245年 →](bce-0245.md)

**秦王政元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **秦王还年少，朝政主要交给大臣。** 政在父亲庄襄王去世后继位，本年进入他的元年。他接手的秦国已经控制巴、蜀、汉中和大片三晋土地，也吞并了东西二周。文信侯吕不韦主持朝政，招集宾客游士；李斯在他门下做舍人，蒙骜、王齮、麃公等领兵。少年国王并不是从一个弱小国家起步，而是接过了一套已经持续扩张的国家和军队。 [[1]](#note-1)

<a id="event-2"></a>

2. **蒙骜平定晋阳的反抗。** 晋阳在新王即位之际发生反抗，蒙骜出兵将它平定。新占领地区并不因为划进秦的版图，就立即安定下来。 [[2]](#note-2)

<a id="sj-029-L2879-01"></a>

<a id="event-3"></a>

3. **郑国来劝秦修渠。** 韩国想让秦忙于大工程，暂时顾不上向东进攻，便派水工郑国劝说秦国引泾水，沿北山向东流入洛水，用来灌溉田地。秦接受了这一工程。发现郑国的使命、决定继续修渠和工程完成，都是后续阶段，不能一并算在本年。 [[3]](#note-3)

<a id="event-4"></a>

4. **陵墓工程的开端。** 秦王即位之初，骊山陵墓工程也已开始。此时的规模不能用后来统一天下以后征发的大批劳役倒填；两者相隔多年。 [[4]](#note-4)

#### 1｜继位与登场前事

<a id="sj029-pre-qin-context"></a>
### 卷029背景｜先秦各地水利，不是前246年同年建设

禹的叙事之后，本卷转述后世各地区的工程：荥阳以下引河为鸿沟，沟通宋、郑、陈、蔡、曹、卫及济、汝、淮、泗；楚地联系汉水、云梦与江淮，吴地联系三江五湖，齐地联系淄济。蜀守冰凿离堆、处理沫水水害，并在成都一带开通两江。书中概括这些水道可以通船，有余水时还用于灌溉；各地又从沿途分引小渠，数量多得不能逐一列举。

**[《史记·河渠书》P002](../../sources/摘录/史记-卷029-河渠书.md#p002)**

> 自是之後，滎陽下引河東南為鴻溝，以通宋、鄭、陳、蔡、曹、衛，與濟、汝、淮、泗會。于楚，西方則通渠漢水、雲夢之野，東方則通［鴻］溝江淮之閒。於吳，則通渠三江、五湖。於齊，則通菑濟之閒。於蜀，蜀守冰鑿離碓，辟沫水之害，穿二江成都之中。此渠皆可行舟，有餘則用溉浸，百姓饗其利。至于所過，往往引其水益用溉田疇之渠，以萬億計，然莫足數也。


本段只给地区与工程，没有统一开工年。李冰之名据[汉志H02](../../sources/摘录/史记-卷029-汉书互校.md#h02)及[古注A04](../../sources/摘录/史记-卷029-古注摘核.md#a04)说明；不把秦并蜀年直接当成李冰任职或治水之年。“万亿”只作极言众多，不造工程清册。

<a id="sj029-ye-dispute"></a>
#### 西门豹与史起：两种归功叙事

《史记》把引漳灌邺归给西门豹；《汉书》却叙魏襄王时史起批评西门豹未用漳水，并记史起兴利。两书并存，不默认它们说的是同一次开渠，也不强行认定先创后扩已经证实。

**[《史记·河渠书》P003](../../sources/摘录/史记-卷029-河渠书.md#p003)**

> 西門豹引漳水溉鄴，以富魏之河內。

**[《汉书》对应原文 H03](../../sources/摘录/史记-卷029-汉书互校.md#h03)**

> 魏文侯時，西門豹為鄴令，有令名。至文侯曾孫襄王時，與群臣飲酒，王為群臣祝曰：「今吾臣皆西門豹之為人臣也！」史起進曰：「魏氏之行田也以百畝，鄴獨二百畝，是田惡也。漳水在其旁，西門豹不知用，是不智也。知而不興，是不仁也。仁智豹未之盡，何足法也！」於是以史起為鄴令，遂引漳水溉鄴，以富魏之河內。民歌之曰：「鄴有賢令兮為史公，決漳水兮灌鄴旁，終古秽鹵兮生稻梁。」

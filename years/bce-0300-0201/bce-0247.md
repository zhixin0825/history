# 公元前247年｜秦军遭五国反击，庄襄王去世，公子政继位

[← 公元前248年](bce-0248.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前246年 →](bce-0246.md)

**秦庄襄王三年；政继位，次年称元年**

## 本年纪事

<a id="event-1"></a>
**秦攻取魏高都、汲，并在上党太原继续置郡。** 蒙骜与王龁分担不同进攻。本纪夹有“四年”括注，但庄襄王在位叙事及年表均止三年，不能照括注再造一个秦庄襄四年。[1](#sj005-279-note)

<a id="event-2"></a>
**魏无忌率五国兵在河外击败秦军。** 蒙骜受挫后撤。秦此时虽持续得地，诸侯联合仍能暂时扭转战场局面。[2](#sj005-280-note)

<a id="event-3"></a>
**五月丙午，庄襄王去世，公子政继位。** 新王就是后来的秦始皇，本纪称他此时十三岁。他接手的是不断向东扩张、也仍会遭反击的秦国；具体执政局势接[前246年](bce-0246.md)，不能将本年的继位与次年的元年写成两次登位。[3](#sj005-281-note)

## 本年相关史料

<a id="sj005-279-note"></a>
### 1｜攻魏与置郡

[卷005 P070](../../sources/摘录/史记-卷005-秦本纪.md#p070)。太原此前“定”与本年“初置郡”是军事取得和制度确立两种记录，不因同一地名便重复删除。四年括注问题沿[卷005考证](../../meta/考证/史记-卷005-纪年与异说.md)。

<a id="sj005-280-note"></a>
### 2｜五国击秦

[卷005 P070](../../sources/摘录/史记-卷005-秦本纪.md#p070)。这是一次联合反击，不由此宣称各国形成永久统一指挥。

<a id="sj005-281-note"></a>
### 3｜死亡、继位与年龄

[卷005 P070](../../sources/摘录/史记-卷005-秦本纪.md#p070)给五月丙午；[卷006 P001](../../sources/摘录/史记-卷006-秦始皇本纪.md#p001)补十三岁继位，与篇末[P078](../../sources/摘录/史记-卷006-秦始皇本纪.md#p078)互见。十三岁是史书年龄口径，不直接称现代十三周岁；古月、干支未换成现代日期。此时仍称秦王，不能以后来的始皇帝称号写成本年已经采用皇帝号。

<a id="sj015-0247-qinwei"></a>
### 卷015｜上党、太原与五国击秦

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0247)秦栏王齮击上党、置太原郡，与韩栏失上党并原第一事；秦魏两栏五国击秦并原第二事。[卷015三家注本](https://zh.wikisource.org/wiki/史記三家註/卷015)注明王齮一作王齕，沿既有王龁写法，不凭异字造新将领。河外是交战地点，已修正旧文“退到河外”这一可能误导；不据五国二字强填原文未列的全部成员名单。

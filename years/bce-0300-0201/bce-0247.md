# 公元前247年｜秦军遭五国反击，庄襄王去世，公子政继位

[← 公元前248年](bce-0248.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前246年 →](bce-0246.md)

**秦庄襄王三年；政继位，次年称元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦攻取魏高都、汲，并在上党太原继续置郡。** 蒙骜与王龁分担不同进攻。本纪夹有“四年”括注，但庄襄王在位叙事及年表均止三年，不能照括注再造一个秦庄襄四年。 [[1]](#note-1)

<a id="event-2"></a>

2. **魏无忌率五国兵在河外击败秦军。** 蒙骜受挫后撤。秦此时虽持续得地，诸侯联合仍能暂时扭转战场局面。 [[2]](#note-2)

<a id="event-3"></a>

3. **五月丙午，庄襄王去世，公子政继位。** 新王就是后来的秦始皇，本纪称他此时十三岁。他接手的是不断向东扩张、也仍会遭反击的秦国；具体执政局势接[前246年](bce-0246.md)，不能将本年的继位与次年的元年写成两次登位。 [[3]](#note-3)

### 1. 秦攻取魏高都、汲，并在上党太原继续置郡

[返回正文第1条](#event-1)

<a id="sj034-cite-083"></a>

**[《史记·燕召公世家》P032](../../sources/摘录/史记-卷034-燕召公世家.md#p032)**

> 秦置大原郡。

**本卷说明：** 以秦本纪庄襄王三年置太原为本页依据；本卷把它接在喜七年，作为相邻年汇叙留异。



**[卷005 P070](../../sources/摘录/史记-卷005-秦本纪.md#p070)**

> 莊襄王元年，大赦罪人，修先王功臣，施德厚骨肉而布惠於民。東周君與諸侯謀秦，秦使相國呂不韋誅之，盡入其國。秦不絕其祀，以陽人地賜周君，奉其祭祀。使蒙驁伐韓，韓獻成皋、鞏。秦界至大梁，初置三川郡。二年，使蒙驁攻趙，定太原。三年，蒙驁攻魏高都、汲，拔之。攻趙榆次、新城、狼孟，取三十七城。四月日食。（四年）王龁攻上黨。初置太原郡。魏將無忌率五國兵擊秦，秦卻於河外。蒙驁敗，解而去。五月丙午，莊襄王卒，子政立，是為秦始皇帝。

### 3. 五月丙午，庄襄王去世，公子政继位

[返回正文第3条](#event-3)

<a id="sj034-cite-084"></a>

**[《史记·燕召公世家》P032](../../sources/摘录/史记-卷034-燕召公世家.md#p032)**

> 九年，秦王政初即位。

**本卷说明：** 燕喜元年前254，九年算前246，正是秦王政元年；实际承位在前247年。原文“初即位”不可让秦王在两年各即位一次。



**[卷005 P070](../../sources/摘录/史记-卷005-秦本纪.md#p070)**

**[卷006 P001](../../sources/摘录/史记-卷006-秦始皇本纪.md#p001)**

> 秦始皇帝者，秦莊襄王子也。莊襄王為秦質子於趙，見呂不韋姬，悅而取之，生始皇。以秦昭王四十八年正月生於邯鄲。及生，名為政，姓趙氏。年十三歲，莊襄王死，政代立為秦王。

**[卷006 P001](../../sources/摘录/史记-卷006-秦始皇本纪.md#p001)**

> 呂不韋為相，封十萬戶，號曰文信侯。招致賓客游士，欲以并天下。李斯為舍人。蒙驁、王齮、麃公等為將軍。王年少，初即位，委國事大臣。

**[P078](../../sources/摘录/史记-卷006-秦始皇本纪.md#p078)**

## 归年与考证

<a id="sj005-279-note"></a>
<a id="1攻魏与置郡"></a>
#### 1｜攻魏与置郡

[卷005 P070](../../sources/摘录/史记-卷005-秦本纪.md#p070)。太原此前“定”与本年“初置郡”是军事取得和制度确立两种记录，不因同一地名便重复删除。四年括注问题沿[卷005考证](../../meta/考证/史记-卷005-纪年与异说.md)。

<a id="sj005-280-note"></a>
<a id="2五国击秦"></a>
#### 2｜五国击秦

[卷005 P070](../../sources/摘录/史记-卷005-秦本纪.md#p070)。这是一次联合反击，不由此宣称各国形成永久统一指挥。

<a id="sj005-281-note"></a>
<a id="3死亡继位与年龄"></a>
#### 3｜死亡、继位与年龄

[卷005 P070](../../sources/摘录/史记-卷005-秦本纪.md#p070)给五月丙午；[卷006 P001](../../sources/摘录/史记-卷006-秦始皇本纪.md#p001)补十三岁继位，与篇末[P078](../../sources/摘录/史记-卷006-秦始皇本纪.md#p078)互见。十三岁是史书年龄口径，不直接称现代十三周岁；古月、干支未换成现代日期。此时仍称秦王，不能以后来的始皇帝称号写成本年已经采用皇帝号。

<a id="sj015-0247-qinwei"></a>
<a id="卷015上党太原与五国击秦"></a>
#### 卷015｜上党、太原与五国击秦

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0247)秦栏王齮击上党、置太原郡，与韩栏失上党并原第一事；秦魏两栏五国击秦并原第二事。[卷015三家注本](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7015.md#ref-4d9ad3867afe28)注明王齮一作王齕，沿既有王龁写法，不凭异字造新将领。河外是交战地点，已修正旧文“退到河外”这一可能误导；不据五国二字强填原文未列的全部成员名单。

1. **蒙骜攻赵，秦取得榆次、新城、狼孟等三十七城。** 秦向赵境深入，同时定太原地区，为随后明确置郡创造条件。 [[1]](#note-1)

<a id="sj015-0248-chu-event"></a>

<a id="event-2"></a>

2. **春申君改封到吴地。** 春申君黄歇的封地改到吴地。他交还原有的淮北封地，改在江东受封；楚国都城仍不是因此搬到吴。 [[2]](#note-2)

<a id="sj043-yanlingjun-event"></a>

3. **延陵钧随廉颇助魏攻燕。** 延陵钧率师，跟从相国信平君廉颇出战，魏、赵在这一阶段共同对燕用兵。 [[3]](#sj043-yanlingjun-note)

> 二年，蒙驁攻趙，取三十七城。

**本卷归年说明：** 本传把攻赵与取三十七城合系庄襄王二年。

<a id="sj034-cite-082"></a>

**[《史记·燕召公世家》P032](../../sources/摘录/史记-卷034-燕召公世家.md#p032)**

> 七年，秦拔趙榆次三十七城，秦置大原郡。

**本卷说明：** 取榆次三十七城依前248；置太原郡在秦本纪另系前247，句中两项不一律移到同年。“大原”字形照存。



**[卷005 P070](../../sources/摘录/史记-卷005-秦本纪.md#p070)**

> 莊襄王元年，大赦罪人，修先王功臣，施德厚骨肉而布惠於民。東周君與諸侯謀秦，秦使相國呂不韋誅之，盡入其國。秦不絕其祀，以陽人地賜周君，奉其祭祀。使蒙驁伐韓，韓獻成皋、鞏。秦界至大梁，初置三川郡。二年，使蒙驁攻趙，定太原。三年，蒙驁攻魏高都、汲，拔之。攻趙榆次、新城、狼孟，取三十七城。四月日食。（四年）王龁攻上黨。初置太原郡。魏將無忌率五國兵擊秦，秦卻於河外。蒙驁敗，解而去。五月丙午，莊襄王卒，子政立，是為秦始皇帝。

## 归年与考证

<a id="sj005-278-note"></a>
<a id="sj005-278蒙骜攻赵秦取得榆次新城狼孟等三十七城"></a>
#### sj005-278｜蒙骜攻赵，秦取得榆次、新城、狼孟等三十七城。

[卷005 P070](../../sources/摘录/史记-卷005-秦本纪.md#p070)。

**说明：**本纪二年定太原、三年才列三十七城；六国年表二年列三十七城，暂依前248。相连日食本纪三年、年表二年也不一致，只注明两书年差，不新造两次可独立测算的日食。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0248-qin"></a>
<a id="卷015三十七城与日食的异年"></a>
#### 卷015｜三十七城与日食的异年

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0248)秦栏并本页原第一事；日食同格不能遗漏。秦本纪把三十七城及日食放在庄襄王三年、表在二年，本文沿既有前248年攻城主叙，日食暂在本注并列前248／247两年记录，未做天文回算，不写两场已定年日食。

<a id="sj015-0248-chu"></a>
<a id="卷015春申君改封到吴地"></a>
#### 卷015｜春申君改封到吴地

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0248)楚栏明记徙封吴。[《春申君列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7078.md#ref-fdce2a3f93d9c2)叙春申君以原淮北封地贴近齐为由，请将其献还楚王、改封江东，楚王同意；此处记黄歇封邑变更，不等于楚国本年迁都吴。

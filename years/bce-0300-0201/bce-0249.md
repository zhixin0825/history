# 公元前249年｜秦灭东周，周的两个小国都并入秦

**秦庄襄王元年**

> 本页按古史年条与传统公元对照归档；明确有争议的日期见对应说明。月份、干支未直接换算为公历日期；不以已有一条材料表示本年所有历史都已收齐。

## 本年纪事

<a id="event-1"></a>

1. **秦灭东周，周的两个小国都并入秦。** 秦庄襄王时，东周君与诸侯谋秦，秦派吕不韦进兵，夺取东周的土地。至此，东周、西周两个地方周国都被纳入秦，而非只是周天子换了一个居住地。

秦又为周君保留奉祀的安排，把阳人之地给他。王朝政治实体的结束，与旧族每一种祭祀从此完全消失，是不同问题。 [原文与说明](#note-1)

[补充史料与年次说明](#sj005-276-note)


<a id="event-2"></a>

2. **庄襄王赦罪并厚待亲族，蒙骜取韩地，秦置三川郡。** 蒙骜攻取成皋、荥阳，韩方又交出巩等地，秦势力逼近大梁方向；新郡把东方通路与洛阳周边纳入秦管辖。 [原文与说明](#sj005-277-note)

## 本年相关史料

<a id="note-1"></a>
<a id="sj004-249-1"></a>
### 1. 秦灭东周，周的两个小国都并入秦

[卷004 P081](../../sources/摘录/史记-卷004-周本纪.md#p081)。 卷004称“后七岁”，卷005庄襄王元年明列东周事，取前249。卷004末语“周既不祀”与卷005“秦不绝其祀，以阳人地赐周君”不能同时按最绝对字面解释。正文区分政治结束与后裔奉祀，把差别留在这里，不删一方原文。

## 补充史料与异说

<a id="sj005-276-note"></a>
### sj005-276｜同一事件的补充与取舍

[卷005 P070](../../sources/摘录/史记-卷005-秦本纪.md#p070)。

**说明：**庄襄元年灭东周与卷004同事，秦本纪又明记赐周君阳人地奉祀。政治国亡与宗族祭祀延续要分开，不能因灭国删除后裔安排。

<a id="sj005-277-note"></a>
### sj005-277｜庄襄王赦罪并厚待亲族，蒙骜取韩地，秦置三川郡。

[卷005 P070](../../sources/摘录/史记-卷005-秦本纪.md#p070)。

**说明：**年表有成皋、荥阳的异文，不把所有名字都当互不相同新增攻取。吕不韦任相并参与灭东周已在原条，不另写一遍。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0249-qinhan"></a>
### 卷015｜庄襄王元年、东周终局与三川郡

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0249)秦栏元年、蒙骜取成皋荥阳、置三川、吕不韦相、取东周，与韩栏失两城均分流至本页原两事。成皋、巩为本纪受地名单，成皋、荥阳为表的攻取名单，重叠地点合并，保留行动和地名差别，不把秦韩互见算两次同城陷落。

<a id="sj015-0249-lu"></a>
### 卷015｜“楚灭鲁、顷公迁卞”的异年

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0249)本格保留楚灭鲁、顷公迁卞、为家人、绝祀的原记。主叙已依[《鲁周公世家》](https://zh.wikisource.org/wiki/史記/卷033)顷公二年郢陷和二十四年灭鲁的年链归[前256年](bce-0256.md#sj015-0256-lu-event)。表内从前272元年数至本年前249为二十四年，是另一套完整的七年后移体系，不能只改结尾而保留错误年链。世家作迁下邑、后死于柯，未说死于本年；本项目不再造前249年第二次灭鲁，也不把“绝祀”直接等同末君本年死亡。

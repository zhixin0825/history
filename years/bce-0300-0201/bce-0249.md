# 公元前249年｜秦灭东周，周的两个小国都并入秦

[← 上一张已编年页：公元前250年](bce-0250.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前248年 →](bce-0248.md)

**秦庄襄王元年**

> 本页按古史年条与传统公元对照归档；明确有争议的日期见对应说明。月份、干支未直接换算为公历日期；不以已有一条材料表示本年所有历史都已收齐。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦灭东周，周的两个小国都并入秦。** 秦庄襄王时，东周君与诸侯谋秦，秦派吕不韦进兵，夺取东周的土地。至此，东周、西周两个地方周国都被纳入秦，而非只是周天子换了一个居住地。 [[1]](#note-1)

   秦又为周君保留奉祀的安排，把阳人之地给他。王朝政治实体的结束，与旧族每一种祭祀从此完全消失，是不同问题。

<a id="event-2"></a>

2. **庄襄王赦罪并厚待亲族，蒙骜取韩地，秦置三川郡。** 蒙骜攻取成皋、荥阳，韩方又交出巩等地，秦势力逼近大梁方向；新郡把东方通路与洛阳周边纳入秦管辖。 [[2]](#note-2)

<a id="sj043-yuecheng-yan-event"></a>

3. **代理相国的大将武襄君乐乘攻燕，包围燕都。** 武襄君是乐乘封号，此处“假相”是代理相国，不是代地之相。 [[3]](#sj043-yuecheng-yan-note)

<a id="sj046-queen-death-event"></a>

4. **君王后去世，齐国失去长期主持国事的人物。** 王建十六年沿现有王年接前249。此后后胜及使秦宾客对齐国外交的影响渐大，具体受金与放弃合纵的过程另在亡齐前因中回顾，不认为都在王后去世当天完成。 [[4]](#sj046-queen-death-note)

**本卷说明：** 本句“东（西）周”显示转录中的校异；西周终局与东周终局原已分年，仍沿前256/255与前249主线，不用一句把两者同年化。三川郡见本页另条。

> 莊襄王元年，大赦罪人，修先王功臣，施德厚骨肉而布惠於民。東周君與諸侯謀秦，秦使相國呂不韋誅之，盡入其國。秦不絕其祀，以陽人地賜周君，奉其祭祀。使蒙驁伐韓，韓獻成皋、鞏。秦界至大梁，初置三川郡。二年，使蒙驁攻趙，定太原。三年，蒙驁攻魏高都、汲，拔之。攻趙榆次、新城、狼孟，取三十七城。四月日食。（四年）王龁攻上黨。初置太原郡。魏將無忌率五國兵擊秦，秦卻於河外。蒙驁敗，解而去。五月丙午，莊襄王卒，子政立，是為秦始皇帝。

## 归年与考证

<a id="sj004-249-1"></a>
<a id="1-秦灭东周周的两个小国都并入秦"></a>
#### 1. 秦灭东周，周的两个小国都并入秦

[卷004 P081](../../sources/摘录/史记-卷004-周本纪.md#p081)。 卷004称“后七岁”，卷005庄襄王元年明列东周事，取前249。卷004末语“周既不祀”与卷005“秦不绝其祀，以阳人地赐周君”不能同时按最绝对字面解释。正文区分政治结束与后裔奉祀，把差别留在这里，不删一方原文。

### 补充史料与异说

<a id="sj005-276-note"></a>
<a id="sj005-276同一事件的补充与取舍"></a>
#### sj005-276｜同一事件的补充与取舍

[卷005 P070](../../sources/摘录/史记-卷005-秦本纪.md#p070)。

**说明：**庄襄元年灭东周与卷004同事，秦本纪又明记赐周君阳人地奉祀。政治国亡与宗族祭祀延续要分开，不能因灭国删除后裔安排。

<a id="sj005-277-note"></a>
<a id="sj005-277庄襄王赦罪并厚待亲族蒙骜取韩地秦置三川郡"></a>
#### sj005-277｜庄襄王赦罪并厚待亲族，蒙骜取韩地，秦置三川郡。

[卷005 P070](../../sources/摘录/史记-卷005-秦本纪.md#p070)。

**说明：**年表有成皋、荥阳的异文，不把所有名字都当互不相同新增攻取。吕不韦任相并参与灭东周已在原条，不另写一遍。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0249-qinhan"></a>
<a id="卷015庄襄王元年东周终局与三川郡"></a>
#### 卷015｜庄襄王元年、东周终局与三川郡

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0249)秦栏元年、蒙骜取成皋荥阳、置三川、吕不韦相、取东周，与韩栏失两城均分流至本页原两事。成皋、巩为本纪受地名单，成皋、荥阳为表的攻取名单，重叠地点合并，保留行动和地名差别，不把秦韩互见算两次同城陷落。

<a id="sj015-0249-lu"></a>
<a id="卷015楚灭鲁顷公迁卞的异年"></a>
#### 卷015｜“楚灭鲁、顷公迁卞”的异年

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0249)本格保留楚灭鲁、顷公迁卞、为家人、绝祀的原记。主叙已依[《鲁周公世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7033.md#ref-8d3e94cbc5a065)顷公二年郢陷和二十四年灭鲁的年链归[前256年](bce-0256.md#sj015-0256-lu-event)。表内从前272元年数至本年前249为二十四年，是另一套完整的七年后移体系，不能只改结尾而保留错误年链。世家作迁下邑、后死于柯，未说死于本年；本项目不再造前249年第二次灭鲁，也不把“绝祀”直接等同末君本年死亡。

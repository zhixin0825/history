<a id="本年纪事"></a>
<a id="event-1"></a>

1. **孝文王赦罪、褒功臣亲属，正式即位三日后去世。** 孝文王元年施行赦免，厚待先王功臣与亲戚，并放宽苑囿限制。除丧以后，十月己亥举行即位礼，辛丑即去世，庄襄王继立。 [[1]](#note-1)

<a id="sj043-lianpo-yan-event"></a>

2. **廉颇围燕见于赵国本年的记事，乐乘受封武襄君。** 赵篇将围燕列孝成十六年；燕篇在前一阶段战事叙述中连写围城、将渠求和与解围，可能是同一战争的后续，不能断言前251全部结束后本年又独立起围。 [[2]](#sj043-lianpo-yan-note)

<a id="sj055-event-3"></a>

3. **韩相张平去世。** 张平的父亲张开地先后相韩昭侯、宣惠王、襄哀王，他自己又相釐王、悼惠王。张氏父子两代，一共侍奉过五位韩君。张良是张平之子。 [[3]](#sj055-note-3)

<a id="event-4"></a>

4. **鲁仲连致书燕将，齐军收复聊城。** 齐军久攻聊城未下，鲁仲连把劝说的信送进城内。《史记》说守城燕将两难自杀，城中失去主将而乱，齐军于是取城。齐国想给鲁仲连爵位，他避居海上。聊城收复暂系本年，初陷与围城起始无确年。 [[4]](#note-4)

## 归年与考证

<a id="sj005-275-note"></a>
<a id="sj005-275孝文王赦罪褒功臣亲属正式即位三日后去世"></a>
#### sj005-275｜孝文王赦罪、褒功臣亲属，正式即位三日后去世。

[卷005 P069](../../sources/摘录/史记-卷005-秦本纪.md#p069)。

**说明：**“即位三日”指原文所记除丧后正式仪式到死，不把整个孝文王元年的所有政治安排都压成这三日。保留古历干支。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="卷015秦孝文王元年"></a>
#### 卷015｜秦孝文王元年

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0250)元年并入本页原叙，与[前251年昭襄王死、孝文王承位](bce-0251.md#event-1)相接。除丧后的即位礼、在位纪年和继承发生的时间分开处理，不能把元年写成又一次从未即位到即位。

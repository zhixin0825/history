1. **秦昭襄王去世，孝文王承位，楚遣春申君吊祭。** 昭王在位五十六年，新君尊母唐八子为唐太后并与先王合葬。韩王服丧服来吊，楚由春申君代表参加，其他各国也遣将相参与丧事。 [[1]](#note-1)

<a id="sj015-0251-jingbo-event"></a>

<a id="event-3"></a>

3. **楚柱国景伯去世。** 楚国柱国景伯去世。 [[3]](#note-3)

<a id="sj015-0251-yan-event"></a>

<a id="event-4"></a>

4. **燕国背约攻赵失利，最终由将渠出面求和。** 本条保存燕篇从出兵到求和的连续叙述，后续围城与解围有跨年问题，不能全断在本年。燕相栗腹先带五百金去赵国结好，回来却说赵国壮年多死于长平、孤儿还未长成，可以乘机攻打。昌国君乐间认为赵人习兵，极力反对；燕王仍自恃兵多，命栗腹攻鄗、卿秦攻代，自己又率偏军跟进。将渠抓住燕王佩绶，劝他不要背弃刚订的盟约，遭王脚踢仍哭谏。燕军被赵军击败，栗腹败死，乐间逃赵；其后廉颇追兵围燕。赵国只肯由将渠主持议和，燕王任他为相，才使赵军解围。 赵以尉文封相国廉颇为信平君。燕王曾问乐间二比一或五比一的兵力能否取胜，均遭否定，群臣却赞成；所出战车二千乘，卿秦后来为赵所俘。 [[4]](#note-4)

> 今王喜四年，秦昭王卒。燕王命相栗腹約歡趙，以五百金為趙王酒。還報燕王曰：「趙王壯者皆死長平，其孤未壯，可伐也。」王召昌國君樂閒問之。對曰：「趙四戰之國，其民習兵，不可伐。」王曰：「吾以五而伐一。」對曰：「不可。」燕王怒，群臣皆以為可。卒起二軍，車二千乘，栗腹將而攻鄗，卿秦攻代。唯獨大夫將渠謂燕王曰：「與人通關約交，以五百金飲人之王，使者報而反攻之，不祥，兵無成功。」燕王不聽，自將偏軍隨之。將渠引燕王綬止之曰：「王必無自往，往無成功。」王蹵之以足。將渠泣曰：「臣非以自為，為王也！」燕軍至宋子，趙使廉頗將，擊破栗腹於鄗。［樂乘］破卿秦（樂乘）於代。樂閒奔趙。廉頗逐之五百餘里，圍其國。燕人請和，趙人不許，必令將渠處和。燕相將渠以處和。趙聽將渠，解燕圍。

**本卷说明：** 此段CCDH以方括号校作“［乐乘］破卿秦（乐乘）于代”，三家注正文另作“破卿秦、乐乘于代”，而所引《战国策》又以乐乘为赵将。正文不把疑文直写成乐乘此时身为燕将，更不把乐间与乐乘混为一人。五倍、二千乘、五百余里保留为古书记数，不作已核实军事统计。

> 十五年，以尉文封相國廉頗為信平君。燕王令丞相栗腹約驤，以五百金為趙王酒，還歸，報燕王曰：「趙氏壯者皆死長平，其孤未壯，可伐也。」王召昌國君樂閒而問之。對曰：「趙，四戰之國也，其民習兵，伐之不可。」王曰：「吾以眾伐寡，二而伐一，可乎？」對曰：「不可。」王曰：「吾即以五而伐一，可乎？」對曰：「不可。」燕王大怒。群臣皆以為可。燕卒起二軍，車二千乘，栗腹將而攻鄗，卿秦將而攻代。廉頗為趙將，破殺栗腹，虜卿秦、樂閒。

**本卷说明：** 本篇称“虏卿秦、乐闲”，燕世家记乐闲去燕奔赵；正文分清卿秦被俘、乐闲奔赵的主线，并保留本篇异说。

#### sj005-274｜秦昭襄王去世，孝文王继位。

[卷005 P068](../../sources/摘录/史记-卷005-秦本纪.md#p068)。

**说明：**尊号与合葬不是唐八子本年才死；原文未给其死亡年。不据“五十六年”倒推精确出生日期。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0251-pingyuan"></a>
<a id="卷015平原君赵胜去世"></a>
#### 卷015｜平原君赵胜去世

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0251)赵栏与[《通鉴》卷六](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7006.md#ref-927f5f15be2228)同年互见。平原君是曾主持赵国政务、参与邯郸危局外交的赵胜，不能与同年其他国家的君主死亡混算。

<a id="sj015-0251-jingbo"></a>
<a id="卷015楚柱国景伯去世"></a>
#### 卷015｜楚柱国景伯去世

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0251)楚栏只记官号、姓名与死亡。本文不因同姓就把景伯与救赵的景阳或其他楚将并成同一个人，也不补未经证实的死因。

<a id="sj015-0251-yan"></a>
<a id="卷015燕攻赵失败栗腹败死"></a>
#### 卷015｜燕攻赵失败，栗腹败死

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0251)燕栏记攻赵失败、栗腹被杀；[《燕召公世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7034.md#ref-38075595a83ef0)和[《通鉴》卷六](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7006.md#ref-48e74257e18df6)补出燕对赵人口损失的判断、廉颇反击和将渠议和。长平惨败并不等于赵国此后已无战斗能力。栗腹之死依表，世家只在此明言败军，层次分别保留。

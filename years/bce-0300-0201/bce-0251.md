1. **秦昭襄王去世，孝文王继位。** 昭王在位五十六年；新君尊母唐八子为唐太后，将她与先王合葬。韩王服丧服前来吊祭，各国也派将相参与丧事。 [[1]](#note-1)

3. **楚柱国景伯去世。** 楚国柱国景伯去世。 [[3]](#note-3)

<a id="sj015-0251-yan-event"></a>

<a id="event-4"></a>

4. **燕攻赵失败，栗腹败死。** 燕相栗腹出使赵国后，认为赵国壮年男子多已死于长平，主张趁机进攻。燕王喜不听反对意见，出兵攻赵；赵将廉颇迎战，燕军大败，栗腹败死。赵军追击并围攻燕国，最后由燕臣将渠主持议和，赵军才撤退。 [[4]](#note-4)

## 归年与考证

<a id="sj005-274-note"></a>
<a id="sj005-274秦昭襄王去世孝文王继位"></a>
#### sj005-274｜秦昭襄王去世，孝文王继位。

[卷005 P068](../../sources/摘录/史记-卷005-秦本纪.md#p068)。

**说明：**尊号与合葬不是唐八子本年才死；原文未给其死亡年。不据“五十六年”倒推精确出生日期。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0251-pingyuan"></a>
<a id="卷015平原君赵胜去世"></a>
#### 卷015｜平原君赵胜去世

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0251)赵栏与[《通鉴》卷六](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7006.md#ref-927f5f15be2228)同年互见。平原君是曾主持赵国政务、参与邯郸危局外交的赵胜，不能与同年其他国家的君主死亡混算。

<a id="sj015-0251-jingbo"></a>
<a id="卷015楚柱国景伯去世"></a>
#### 卷015｜楚柱国景伯去世

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0251)楚栏只记官号、姓名与死亡。本文不因同姓就把景伯与救赵的景阳或其他楚将并成同一个人，也不补未经证实的死因。

<a id="sj015-0251-yan"></a>
<a id="卷015燕攻赵失败栗腹败死"></a>
#### 卷015｜燕攻赵失败，栗腹败死

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0251)燕栏记攻赵失败、栗腹被杀；[《燕召公世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7034.md#ref-38075595a83ef0)和[《通鉴》卷六](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7006.md#ref-48e74257e18df6)补出燕对赵人口损失的判断、廉颇反击和将渠议和。长平惨败并不等于赵国此后已无战斗能力。栗腹之死依表，世家只在此明言败军，层次分别保留。

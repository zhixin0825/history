# 公元前255年｜秦取得周的宝器，西周残余被迁

**秦昭王五十二年（周后事）**

> 本页按古史年条与传统公元对照归档；明确有争议的日期见对应说明。月份、干支未直接换算为公历日期；不以已有一条材料表示本年所有历史都已收齐。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦取得周的宝器，西周残余被迁。** 周的民众向东逃散，秦取得周室九鼎宝器，并把西周公迁到惮狐。王畿旧制度失去依托，人口迁徙、器物转移和宗室安置成为战争之后的又一阶段。 [[1]](#note-1)

<a id="sj015-0255-qin-event"></a>

<a id="event-2"></a>

2. **王稽被处死，出土秦简记范雎同年死。** 秦国河东守王稽因与诸侯交通获罪，被处死。睡虎地秦简《编年记》载王稽与张禄同年死，张禄即范雎，简文未记范雎死因。 [[2]](#note-2)

<a id="sj034-xiaowang-death-event"></a>

3. **燕孝王去世，儿子喜继承。** 孝王在位三年，喜从下一年开始元年，成为后来燕国的末代国君。 [[3]](#sj034-xiaowang-death-note)

<a id="sj043-yuanshi-event"></a>

4. **赵筑元氏、设上原县，收回郑安平封地。** 武阳君郑安平在本年去世，赵收其地。 [[4]](#sj043-yuanshi-note)

<a id="event-5"></a>

5. **范雎辞相，蔡泽继任。** 王稽获罪后，范雎因举荐之事愈感不安。燕人蔡泽此前游说诸侯多未受用，此时入秦劝范雎功成身退，范雎称病交还相印。秦昭王起用蔡泽。蔡泽任相数月后因有人毁谤、惧祸而辞，号纲成君；离任的确月和是否仍在本年均未见明文。 [[5]](#note-5)

<a id="1-秦取得周的宝器西周残余被迁"></a>
#### 1. 秦取得周的宝器，西周残余被迁

[卷004 P081](../../sources/摘录/史记-卷004-周本纪.md#p081)。 卷004在两君死亡后接叙，未再标年；卷005将“周民东亡、九鼎入秦”列在秦昭王五十二年，故此处归前255。惮狐迁置与宝器取得的具体日期未明，不推成同一日。有关某鼎失落的别种传说不在本段，不能凭印象替“九鼎”减成八鼎。

<a id="卷015王稽被处死与西周终局"></a>
#### 卷015｜王稽被处死与西周终局

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0255)秦栏一格两事：“取西周”与本页周室宝器、迁置及[前256年献地](bce-0256.md#event-1)衔接，不把赧王死亡再移一年；“王稽弃市”补本条。[《通鉴》卷六](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7006.md#ref-4dd324ca92aa28)记王稽为河东守、因与诸侯交通获罪，弃市是公开处死，不译为弃官。

<a id="sj015-0255-lu"></a>
<a id="卷015取鲁封鲁君于莒的异年材料"></a>
#### 卷015｜取鲁、封鲁君于莒的异年材料

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0255)楚栏记“取鲁，鲁君封于莒”。鲁国灭亡主叙依世家跨国锚点在[前256年](bce-0256.md#sj015-0256-lu-event)；本格保存取国后安置鲁君的材料。是否应理解为本年迁莒这一独立阶段，或年表对灭鲁的异年，材料不足以彻底裁定，因此不再编一场前255年的第二次灭国。

# 公元前256年｜秦收西周，赧王去世，楚国灭鲁

**周赧王五十九年**

> 本页按古史年条与传统公元对照归档；明确有争议的日期见对应说明。月份、干支未直接换算为公历日期；不以已有一条材料表示本年所有历史都已收齐。

## 本年纪事

<a id="event-1"></a>

1. **秦攻西周，西周君献城，赧王在同年去世。** 秦取得韩的阳城、负黍以后，西周害怕继续受压，转而与诸侯约从，计划从伊阙出兵，使秦不能与阳城相通。秦昭王派将军摎攻西周；西周君前往秦国认罪，献出三十六邑、三万人口，秦接受后又让他回周。

同年，周赧王去世，西周君也在这段结局中被记为去世。天子名号的承继至此中断，但另一个东周国尚未立即被灭，不能把周末各事全写作同一场战争、同一天结束。 [原文与说明](#note-1)

在攻西周之前，摎已向韩、赵两线用兵，本纪报韩国阳城、负黍被取，又取赵二十余县。西周约从要堵住秦往阳城的通道，是在秦连续得地的压力下作出的选择。

[补充史料与年次说明](#sj005-270-note)


<a id="sj015-0256-xinzhong-event"></a>
**韩魏楚救新中，秦军退兵。** 韩、魏、楚继续援救赵国的新中，秦军退兵。邯郸解围以后的联军行动仍在延续。 [原文与说明](#sj015-0256-xinzhong)

<a id="sj015-0256-lu-event"></a>
**楚灭鲁，鲁君失去国家。** 楚国攻灭鲁国，鲁顷公失去国家，后来被迁置，沦为普通人。鲁国作为诸侯国的政治统治至此结束。 [原文与说明](#sj015-0256-lu)

## 本年相关史料

<a id="note-1"></a>
<a id="sj004-256-1"></a>
### 1. 秦攻西周，西周君献城，赧王在同年去世

[卷004 P080](../../sources/摘录/史记-卷004-周本纪.md#p080) · [卷004 P081](../../sources/摘录/史记-卷004-周本纪.md#p081)。 本纪赧王五十九年、卷005秦昭王五十一年相接。三十六邑、三万人为原载，不是本项目按地图或户籍重新统计；阳城与负黍为两个地名。西周君是地方周国君主，赧王是周天子，身份不能合并。九鼎入秦与东周灭亡另归下一年及前249。

**说明：**本纪补将军摎此前攻韩阳城、负黍四万及攻赵二十余县、首虏九万；西周献三十六城三万人与卷004同事，不重复计两次献国。

<a id="sj015-0256-zhou"></a>
### 卷015｜周赧王去世

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0256)周栏记赧王卒，与本页原第一事合并。周赧王是周天子，西周君是地方周国君主，不混为一人。次年前255“取西周”保留为终局处置的另一表记，详见该页。

<a id="sj015-0256-xinzhong"></a>
### 卷015｜韩魏楚救新中，秦军退兵

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0256)魏韩楚三栏互见同一次援救；韩栏秦击阳城已在本页原第一事及卷005补注，故同格两事均有归宿。[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-ac5638ffb1784c)考烈王七年记救军到新中、秦兵去，与本年相合。新中与此前宁新中的名称关系不靠近字直接证明，保留原名。

<a id="sj015-0256-lu"></a>
### 卷015｜楚灭鲁，鲁君失去国家

[《鲁周公世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7033.md#ref-1034a6c856d3a2)记顷公二年郢陷、二十四年楚灭鲁：以郢陷前278年为跨国锚，顷公在位第二十四年对应前256。本文据此归年，现代[山东省民政厅兰陵沿革](https://mzt.shandong.gov.cn/art/2014/1/22/art_92440_7204594.html)也采用前256。卷015前255作取鲁、封君于莒，前249作灭鲁、迁卞为家人；此处保留这些不同阶段或异年的解释可能，不再分别编出三次灭鲁。迁莒、卞与世家下邑的地望、具体次序尚未裁定，世家亦未给顷公死于柯的确定年份。详见[鲁国末年考证](../../meta/考证/史记-卷015-前0286至0247纪年补核.md#鲁国末年)。

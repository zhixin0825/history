**周赧王五十八年**

> 本页按古史年条与传统公元对照归档；明确有争议的日期见对应说明。月份、干支未直接换算为公历日期；不以已有一条材料表示本年所有历史都已收齐。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **三晋拒秦，周的使节在大国之间重新选择接触对象。** 韩、赵、魏共同抗拒秦国。周派相国赴秦，却一度因判断秦势变轻而撤回行程。客人劝相国不能过早判断胜负，应尽快见秦王，以为秦探听东方局势作为新的用途。 [[1]](#note-1)

   这套办法还留下另一手：齐势若重，周仍有人维系齐国关系。秦最终信任周，发兵攻三晋。史书将派使、改行、说辞和秦的行动连续写下，但没有给出可据以还原每次会见日期的日程表。

<a id="event-2"></a>

2. **白起被贬后死去，魏楚援军使秦未能攻下邯郸。** 秦将白起削为士伍，拟迁阴密，随后命死；王龁、郑安平等仍围邯郸。魏无忌率军救赵，楚在春申君组织下遣景阳领援军，围城终于解除，秦军撤去，王龁转向汾地。秦未能把长平胜利直接变成灭赵。 [[2]](#note-2)

<a id="event-3"></a>

3. **秦在其他方向仍继续取城，宁新中改名安阳。** 张唐取郑，秦又在汾城一带增兵作战；本纪列斩首六千、晋楚溺死二万人。秦攻取宁新中后改其名，并记初作河桥。 [[3]](#note-3)

<a id="sj015-0257-yan-event"></a>

<a id="event-4"></a>

4. **燕孝王元年。** 燕国进入孝王时期。孝王是武成王之子，承续燕国王位。 [[4]](#note-4)

### 2. 白起被削为士伍，后来死去；秦围邯郸仍未成功

[返回正文第2条](#event-2)

<a id="sj034-cite-077"></a>

> 孝王元年，秦圍邯鄲者解去。



**[《史記》卷073](../../sources/本地分卷/史记/史记-卷073.md#L5070)**

> 秦王使王龁代陵將，八九月圍邯鄲，不能拔。楚使春申君及魏公子將兵數十萬攻秦軍，秦軍多失亡。武安君言曰：「秦不聽臣計，今如何矣！」秦王聞之，怒，彊起武安君，武安君遂稱病甐。應侯請之，不起。於是免武安君為士伍，遷之陰密。武安君病，未能行。居三月，諸侯攻秦軍急，秦軍數卻，使者日至。秦王乃使人遣白起，不得留咸陽中。武安君既行，出咸陽西門十里，至杜郵。秦昭王與應侯群臣議曰：「白起之遷，其意尚怏怏不服，有餘言。」秦王乃使使者賜之劍，自裁。武安君引劍將自剄，曰：「我何罪于天而至此哉？」良久，曰：「我固當死。長平之戰，趙卒降者數十萬人，我詐而盡阬之，是足以死。」遂自殺。武安君之死也，以秦昭王五十年十一月。死而非其罪，秦人憐之，鄉邑皆祭祀焉。

#### 1. 三晋拒秦，周的使节在大国之间重新选择接触对象

### 补充史料与异说

<a id="sj005-268-note"></a>
<a id="sj005-268白起被削为士伍后来死去秦围邯郸仍未成功"></a>
#### sj005-268｜白起被削为士伍，后来死去；秦围邯郸仍未成功。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**本纪只简记“有罪，死”，白起列传有更详争论与赐死经过。这里不冒称已完成全传动机判断，更不把本纪“有罪”当作本项目独立裁断。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj005-269-note"></a>
<a id="sj005-269秦在其他方向仍继续取城宁新中改名安阳"></a>
#### sj005-269｜秦在其他方向仍继续取城，宁新中改名安阳。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**邯郸退兵与其他取城不是同一尺度的胜负。宁新中之安阳不直接同现代安阳市画等号；“初作河桥”也不扩张为世界第一次架桥。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0257-handan"></a>
<a id="卷015邯郸解围与各国人物的分工"></a>
#### 卷015｜邯郸解围与各国人物的分工

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0257)四栏互见一场解围：秦将王龁、郑安平，魏无忌，楚春申君均入原第二事。[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-243240b6a43021)点名楚将景阳，[《春申君列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7078.md#ref-be50e4a52b14b8)以春申君为楚相概括救赵；不能以“春申君救赵”抹去实际将领，也不能据两种记法造两支彼此无关的楚军。秦栏所记还军取新中并本页第三事，次年援新中再见[前256年](bce-0256.md#sj015-0256-xinzhong-event)。

<a id="sj015-0257-yan"></a>
<a id="卷015燕孝王元年"></a>
#### 卷015｜燕孝王元年

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0257)列孝王元年。[《燕召公世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7034.md#ref-09626d850ef26c)记武成王卒、子孝王立，并将孝王元年与邯郸解围对应；世家武成王年数与本表差一年，本文据年表连续年位作元年阅读位置，不反推一个已无争议的父王卒日。

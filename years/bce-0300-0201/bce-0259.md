# 公元前259年｜长平后秦军再攻赵，公子政出生于邯郸

[← 公元前260年](bce-0260.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前258年 →](bce-0258.md)

**秦昭襄王四十八年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **长平以后，秦军分路推进，又一度停兵守上党。** 韩献垣雍；白起回去，王龁攻取皮牢，司马梗向北定太原，秦控制原韩上党。正月记罢兵后留守上党。 [[1]](#note-1)

<a id="event-2"></a>

2. **秦再发兵攻赵都邯郸，由五大夫陵指挥。** 此前停兵没有使战争结束，秦把攻势推向赵国都城，围城跨年持续。 本篇在围城阶段还记武垣令傅豹、王容、苏射率燕众反燕地，以及赵以灵丘封楚相春申君；两事没有独立年次，暂随围城相关记事附读。 [[2]](#note-2)

<a id="event-3"></a>

3. **正月，后来成为秦始皇的政出生于邯郸。** 他的父亲是正在赵国作质子的秦公子子楚，即后来的庄襄王；母亲此前在吕不韦家中，后嫁给子楚。这个孩子当时出生在赵，并不是出生于已经统一天下的秦宫。 [[3]](#note-3)

## 归年与考证

<a id="sj005-265-note"></a>
<a id="1长平后的推进与停兵"></a>
#### 1｜长平后的推进与停兵

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。本纪四十八年以十月到正月连记，古历年首不按现代公历月硬套。王龁与王齕为异写，司马梗不擅改成司马错。王年取舍沿[卷005考证](../../meta/考证/史记-卷005-纪年与异说.md)。

<a id="sj005-266-note"></a>
<a id="2发兵围邯郸"></a>
#### 2｜发兵围邯郸

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。同段又记“其十月”，月份与年条压缩有困难，本页按四十八年叙事阶段，不声称已换算围城第一天的现代日期。前面的停兵不是秦赵永久和解。

<a id="sj006-001-note"></a>
<a id="3出生与此前身世"></a>
#### 3｜出生与此前身世

[卷006 P001](../../sources/摘录/史记-卷006-秦始皇本纪.md#p001)：“以秦昭王四十八年正月生於邯鄲。”出生有明确王年，故放在本页，而非只在前246年即位背景中倒叙。父亲质赵、母亲改嫁是此前经历，原文没有在这里各定年月；母亲曾为吕不韦姬，也不能单凭这一句证明吕不韦就是政的生父。正月保留古历，不推断现代生日。

<a id="sj015-0259-regnal"></a>
<a id="卷015卷015本年王年位置"></a>
#### 卷015｜卷015本年王年位置

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0259)八栏本年均只有王年数，未再载围邯郸起兵或政出生。现有各条来自卷005、006，照旧保留；不能因本卷无纪事删掉其他来源的本年事实。

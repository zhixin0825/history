<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦取韩十城，叶阳君悝离秦赴封国途中去世。** 秦将五大夫贲攻韩得城；宗室公子悝被记为出之国、未到即卒，分别属于军事与人员去向。 [[1]](#note-1)

<a id="event-2"></a>

2. **韩国上党转向赵国，赵廷为是否受地展开争论。** 秦蚕食韩地、截断上党与韩本土的交通，韩守冯亭遣使献十七城，说吏民安于属赵、不愿属秦，请赵王裁定赏赐。孝成王大喜，问平阳君赵豹能否收地。赵豹答圣人最戒惧无故之利，王说这是人心怀德，赵豹却指出秦本欲坐收上党，韩不交秦，是把祸嫁赵；秦费力赵受利，即使强国也难从弱国取得这种无代价的利益，弱赵又怎能从强秦取得。秦有耕作、运粮和用兵之利，已步步蚕食韩地，政令严行，不宜争此地，务必不受。王反问，发百万军、历年攻城尚未必得一城，如今十七城送来，何等大利。赵豹退后，王又召平原君赵胜、赵禹，两人也以劳师经年难得一城、坐收十七城不可失为说，王从之，遣赵胜受地。赵胜向冯亭传令，以三座万户都封太守、三座千户都封县令，皆世世为侯，吏民爵增三级，能相安者各赐六金。冯亭垂泪不见，自称有三不义：受命守地不能死守，君命交秦却未听从，若再卖君主土地谋取食邑，便添第三不义。赵终发兵接收上党，廉颇驻长平；受地使秦韩争地转为秦赵直接冲突。 [[2]](#note-2)

<a id="sj015-0262-chu-event"></a>

<a id="event-3"></a>

3. **楚以州地与秦求和。** 楚考烈王元年，楚国把州地交给秦国以求和，黄歇继续辅佐楚王。连年失地之后，楚国仍需要与秦国交涉。 [[3]](#note-3)

**[《史记·秦本纪》昭王四十七年（P066节录）](../../sources/摘录/史记-卷005-秦本纪.md#p066)**

> 四十七年，秦攻韓上黨，上黨降趙，秦因攻趙，趙發兵擊秦，相距。

本纪将上党归赵的前因合叙于昭王四十七年；本页依《白起列传》四十五年另系前262年，不能把引文的“四十七年”直接当成本条日期。

**[《史记·白起王翦列传》昭王四十五年](../../sources/本地分卷/史记/史记-卷073.md#L5064)**

> 四十五年，伐韓之野王。野王降秦，上黨道絕。其守馮亭與民謀曰：「鄭道已絕，韓必不可得為民。秦兵日進，韓不能應，不如以上黨歸趙。趙若受我，秦怒，必攻趙。趙被兵，必親韓。韓趙為一，則可以當秦。」因使人報趙。趙孝成王與平陽君、平原君計之。平陽君曰：「不如勿受。受之，禍大於所得。」平原君曰：「無故得一郡，受之便。」趙受之，因封馮亭為華陽君。

[史料说明](#sj005-262-note)

<a id="sj043-cite-219"></a>

**[《史记·赵世家》P098](../../sources/摘录/史记-卷043-赵世家.md#p098)**

> 四年，王夢衣偏裻之衣，乘飛龍上天，不至而墜，見金玉之積如山。明日，王召筮史敢占之，曰：「夢衣偏裻之衣者，殘也。乘飛龍上天不至而墜者，有氣而無實也。見金玉之積如山者，憂也。」

**本卷说明：** **孝成王梦占传说：** 孝成王四年梦见自己穿左右不对称的衣服，乘飞龙上天却半途坠落，又见金玉堆积如山。次日筮史敢解释衣不全是残缺，乘龙不至是有气势而无实效，金玉如山反象征忧患。本篇用梦兆作为受上党、遭长平之祸的叙事伏笔，不能证明天命或把梦占当作战争原因。

<!-- /sj043-cite-219 -->

<a id="sj043-cite-220"></a>

**[《史记·赵世家》P099](../../sources/摘录/史记-卷043-赵世家.md#p099)**

> 後三日，韓氏上黨守馮亭使者至，曰：「韓不能守上黨，入之於秦。其吏民皆安為趙，不欲為秦。有城市邑十七，願再拜入之趙，財王所以賜吏民。」王大喜，召平陽君豹告之曰：「馮亭入城市邑十七，受之何如？」對曰：「聖人甚禍無故之利。」王曰：「人懷吾德，何謂無故乎？」對曰：「夫秦蠶食韓氏地，中絕不令相通，固自以為坐而受上黨之地也。韓氏所以不入於秦者，欲嫁其禍於趙也。秦服其勞而趙受其利，雖彊大不能得之於小弱，小弱顧能得之於彊大乎？豈可謂非無故之利哉！且夫秦以牛田之水通糧蠶食，上乘倍戰者，裂上國之地，其政行，不可與為難，必勿受也。」王曰：「今發百萬之軍而攻，踰年歷歲未得一城也。今以城市邑十七幣吾國，此大利也。」

**本卷说明：** [三家注p100](../../sources/史记三家注/卷043.md#p100)正义释“倍战”为力攻、“上乘”为天下第一，又以牛田作耕熟待收譬喻；正文保守译作耕作、运粮、用兵之利，不当数学倍增。

<!-- /sj043-cite-220 -->

<a id="sj043-cite-221"></a>

**[《史记·赵世家》P100](../../sources/摘录/史记-卷043-赵世家.md#p100)**

> 趙豹出，王召平原君與趙禹而告之。對曰：「發百萬之軍而攻，踰歲未得一城，今坐受城市邑十七，此大利，不可失也。」王曰：「善。」乃令趙勝受地，告馮亭曰：「敝國使者臣勝，敝國君使勝致命，以萬戶都三封太守，千戶都三封縣令，皆世世為侯，吏民皆益爵三級，吏民能相安，皆賜之六金。」馮亭垂涕不見使者，曰：「吾不處三不義也：為主守地，不能死固，不義一矣；入之秦，不聽主令，不義二矣；賣主地而食之，不義三矣。」趙遂發兵取上黨。廉頗將軍軍長平。

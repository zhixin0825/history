1. **秦取韩十城，叶阳君悝离秦赴封国途中去世。** 秦将五大夫贲攻韩得城；宗室公子悝被记为出之国、未到即卒，分别属于军事与人员去向。 [[1]](#note-1)

<a id="event-2"></a>

2. **韩国上党转向赵国，秦赵的直接冲突加剧。** 秦攻韩使上党难以继续与韩本土相接，当地转而归赵。赵的接收改变了秦韩战争的对象，秦随后与赵军争夺。 [[2]](#note-2)

<a id="sj015-0262-chu-event"></a>

<a id="event-3"></a>

3. **楚以州地与秦求和。** 楚考烈王元年，楚国把州地交给秦国以求和，黄歇继续辅佐楚王。连年失地之后，楚国仍需要与秦国交涉。 [[3]](#note-3)

### 2. 韩国上党转向赵国，秦赵的直接冲突加剧

[返回正文第2条](#event-2)

**[《史记·秦本纪》昭王四十七年（P066节录）](../../sources/摘录/史记-卷005-秦本纪.md#p066)**

> 四十七年，秦攻韓上黨，上黨降趙，秦因攻趙，趙發兵擊秦，相距。

本纪将上党归赵的前因合叙于昭王四十七年；本页依《白起列传》四十五年另系前262年，不能把引文的“四十七年”直接当成本条日期。

**[《史记·白起王翦列传》昭王四十五年](../../sources/本地分卷/史记/史记-卷073.md#L5064)**

> 四十五年，伐韓之野王。野王降秦，上黨道絕。其守馮亭與民謀曰：「鄭道已絕，韓必不可得為民。秦兵日進，韓不能應，不如以上黨歸趙。趙若受我，秦怒，必攻趙。趙被兵，必親韓。韓趙為一，則可以當秦。」因使人報趙。趙孝成王與平陽君、平原君計之。平陽君曰：「不如勿受。受之，禍大於所得。」平原君曰：「無故得一郡，受之便。」趙受之，因封馮亭為華陽君。

## 归年与考证

<a id="sj005-261-note"></a>
<a id="sj005-261秦取韩十城叶阳君悝离秦赴封国途中去世"></a>
#### sj005-261｜秦取韩十城，叶阳君悝离秦赴封国途中去世。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**本纪的悝与前291受封的公子悝相接，不把“出之国”解作新君被驱逐。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj005-262-note"></a>
<a id="sj005-262韩国上党转向赵国秦赵的直接冲突加剧"></a>
#### sj005-262｜韩国上党转向赵国，秦赵的直接冲突加剧。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**本纪把上党降赵同前260长平决战压在四十七年段中；依白起列传四十五年取野王、上党归赵的前因，另放前262。归降不是赵括接任当天才发生。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="卷015楚以州地与秦求和"></a>
#### 卷015｜楚以州地与秦求和

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0262)楚栏元年、秦取州、黄歇相合并阅读。[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-2a9280aea14e6c)作“纳州于秦以平”，[《通鉴》卷五](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7005.md#ref-15b0d9aefced21)校作夏州；本页沿纳地求和，不凭“秦取”把它写成另一次已有确证的攻城。新王承位与黄歇始任相见[前263年](bce-0263.md#sj015-0263-chu-event)。

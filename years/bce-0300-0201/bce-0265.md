<a id="event-1"></a>

1. **安国君成为太子，宣太后去世，魏冉退出秦廷。** 昭王前一位太子已死，安国君接续储位。同年宣太后葬芷阳郦山，穰侯离开秦都，前往陶邑。王室继承和执政集团都发生变化。 [[1]](#note-1)

<a id="sj015-0265-zhao-event"></a>

<a id="event-2"></a>

2. **新王治下，触龙说服太后以长安君为质，赵换得齐援。** 孝成王元年，秦攻赵取三城，太后掌政，齐要求长安君入质才救。太后拒绝，扬言再劝者唾其面。左师触龙求见，她怒待；触龙缓步入坐，自称足病不能疾行、久未进见，担心太后也不适，先问起居饮食。她说靠辇代步、靠粥进食，他说自己曾无食欲，勉强日行三四里后渐能进食、身体转好，她说不能如此，怒色稍解。触龙便请求让十五岁幼子舒祺补黑衣卫士，趁自己未死有所托付，太后允诺，笑问男子也爱幼子吗，他答更甚妇人。触龙又说太后爱燕后胜过长安君，她不认；他说父母爱子须计长远，送燕后时持踵哭泣，因远嫁而哀，祭祀却祝她不要返回，是愿她子孙相继为燕王。太后称是。他再问往前三世，赵国历代国君子孙封侯者还有谁能保持后继，其他诸侯又有谁；她说没有听说。触龙指出，并非君主子孙天生不好，而是位尊无功、奉厚无劳、重器过多，近者祸及身、远者及子孙。太后给长安君高位、膏腴地和珍器，却不让他及今立功，一旦太后去世，他何以托身赵国？这才是为他计短，不及替燕后谋远。太后终于说任其安排，备车百乘送长安君质齐，齐兵乃出，秦军退去；平原君仍在赵任相。 [[2]](#note-2)

<a id="sj015-0265-tiandan-event"></a>

<a id="event-3"></a>

3. **田单领赵军攻燕。** 赵国请齐将田单统兵攻燕，攻取中阳。 田单号安平君，又攻韩注人，亦取其城。 [[3]](#note-3)

<a id="sj015-0265-qiking-event"></a>

<a id="event-4"></a>

4. **齐襄王去世，王建承位。** 齐襄王去世，儿子建承位。新君年少，母亲君王后主持国政。 [[4]](#note-4)

<a id="event-5"></a>

5. **秦攻取韩少曲、高平。** 秦向韩国用兵，夺得少曲和高平。两地的攻取在范雎任相的第二年，韩国次年又在汾陉失地。 [[5]](#note-5)

<a id="sj043-cite-215"></a>

**[《史记·赵世家》P095](../../sources/摘录/史记-卷043-赵世家.md#p095)**

> 孝成王元年，秦伐我，拔三城。趙王新立，太后用事，秦急攻之。趙氏求救於齊，齊曰：「必以長安君為質，兵乃出。」太后不肯，大臣彊諫。太后明謂左右曰：「復言長安君為質者，老婦必唾其面。」左師觸龍言願見太后，太后盛氣而胥之。入，徐趨而坐，自謝曰：「老臣病足，曾不能疾走，不得見久矣。竊自恕，而恐太后體之有所苦也，故願望見太后。」太后曰：「老婦恃輦而行耳。」曰：「食得毋衰乎？」曰：「恃粥耳。」曰：「老臣閒者殊不欲食，乃彊步，日三四里，少益嗜食，和於身也。」太后曰：「老婦不能。」太后不和之色少解。左師公曰：「老臣賤息舒祺最少，不肖，而臣衰，竊憐愛之，願得補黑衣之缺以衛王宮，昧死以聞。」太后曰：「敬諾。年幾何矣？」對曰：「十五歲矣。雖少，願及未填溝壑而讬之。」太后曰：「丈夫亦愛憐少子乎？」對曰：「甚於婦人。」太后笑曰：「婦人異甚。」對曰：「老臣竊以為媼之愛燕后賢於長安君。」太后曰：「君過矣，不若長安君之甚。」左師公曰：「父母愛子則為之計深遠。媼之送燕后也，持其踵，為之泣，念其遠也，亦哀之矣。已行，非不思也，祭祀則祝之曰『必勿使反』，豈非計長久，為子孫相繼為王也哉？」太后曰：「然。」左師公曰：「今三世以前，至於趙主之子孫為侯者，其繼有在者乎？」曰：「無有。」曰：「微獨趙，諸侯有在者乎？」曰：「老婦不聞也。」曰：「此其近者禍及其身，遠者及其子孫。豈人主之子侯則不善哉？位尊而無功，奉厚而無勞，而挾重器多也。今媼尊長安君之位，而封之以膏腴之地，多與之重器，而不及今令有功於國，一旦山陵崩，長安君何以自讬於趙？老臣以媼為長安君之計短也，故以為愛之不若燕后。」太后曰：「諾，恣君之所使之。」於是為長安君約車百乘，質於齊，齊兵乃出。

**本卷说明：** 左师触龙据本篇原文，人名不讹作触詟；说辞的家庭比喻和功劳原则完整进入正文。

<!-- /sj043-cite-215 -->

<a id="sj043-cite-216"></a>

**[《史记·赵世家》P096](../../sources/摘录/史记-卷043-赵世家.md#p096)**

> 子義聞之，曰：「人主之子，骨肉之親也，猶不能持無功之尊，無勞之奉，而守金玉之重也，而況於予乎？」

**本卷说明：** **子义事后议论：** 子义听到此事感叹，即使国君的亲生子、骨肉至亲，也不能长保没有功劳的尊位、没有劳绩的俸禄和珍重金玉，何况自己这样的普通臣子。此为事后议论，依触龙事件同号附读，不另造一项当年政令。

## 本年纪事

<a id="event-1"></a>

1. **安国君成为太子，宣太后去世，魏冉退出秦廷。** 昭王前一位太子已死，安国君接续储位。同年宣太后葬芷阳郦山，穰侯离开秦都，前往陶邑。王室继承和执政集团都发生变化。 [原文与说明](#sj005-258-note)

<a id="sj015-0265-zhao-event"></a>
**新王治下，赵以质子换取齐援。** 赵孝成王元年，秦军攻取赵国三城，赵国向齐国求援。齐国要求长安君入齐作质子；赵太后起初不愿，在触龙劝说后答应，齐军于是出动，秦军退去。平原君在赵任相。 [原文与说明](#sj015-0265-zhao)

<a id="sj015-0265-tiandan-event"></a>
**田单领赵军攻燕。** 赵国请齐将田单统兵攻燕，攻取中阳。 [原文与说明](#sj015-0265-tiandan)

<a id="sj015-0265-qiking-event"></a>
**齐襄王去世，王建承位。** 齐襄王去世，儿子建承位。新君年少，母亲君王后主持国政。 [原文与说明](#sj015-0265-qiking)

## 本年相关史料

<a id="sj005-258-note"></a>
### sj005-258｜安国君成为太子，宣太后去世，魏冉退出秦廷。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**原文先十月太后薨后九月穰侯出陶，保留古历记法，不凭现代月份直排推一场确定宫变。逐年所系与有关列传还有差别，本文未把全部范雎活动提前补完。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0265-qin"></a>
### 卷015｜宣太后死、安国君成为太子

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0265)两事并入本页原第一事。原本纪所记九月、十月次序保留古历语境，不擅改成同年公历的连续日程。

<a id="sj015-0265-zhao"></a>
### 卷015｜新王治下，赵以质子换取齐援

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0265)赵栏元年、秦拔三城、平原君相均落实。惠文王卒和新君承位见[前266年](bce-0266.md#sj015-0266-zhaoking-event)，本年元年不重立。[《通鉴》卷五](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7005.md#ref-99cce5d364aea0)补太后执政、触龙进言和长安君质齐的过程；表中三城与长平后的失地不是一事。

<a id="sj015-0265-tiandan"></a>
### 卷015｜田单领赵军攻燕

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0265)燕栏称“齐田单拔中阳”，这里“齐”说明田单的身份来历。[《通鉴》卷五](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7005.md#ref-5d9d056b87257d)明说他领赵师，地名校作“中人”；[《燕召公世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7034.md#ref-114e1e1fee678a)作中阳。正文保留本表地名并注异文，不把借用将领写成已证实齐军作战。

<a id="sj015-0265-qiking"></a>
### 卷015｜齐襄王去世，王建承位

[《通鉴》卷五](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7005.md#ref-7fc08d3fbb7b0b)在本年记齐襄王死、子建承位，国政由君王后主持；卷015次年前264年开始王建元年。君王后即法章在莒避难时照顾他的太史敫之女，见[前283年](bce-0283.md#sj015-0283-qi-event)。

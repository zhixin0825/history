1. **秦助韩、魏、楚攻燕，燕惠王同年去世。** 秦助韩魏楚攻燕，并初置南阳郡。秦不仅直接攻邻国，也参与远方联盟战争；对南阳则进一步落实郡的设置。韩魏楚攻燕，楚出兵三万，燕惠王同时去世。楚援三晋的军队参与这一轮攻势，燕国则由武成王承继；战争与君位更换在同一年度相接，不能因此假定燕王战死。《赵世家》另一年次记燕将成安君公孙操弑其王；它与燕国记年的死亡入口合看，不能径认惠王死于这场外战。 [[1]](#note-1)

<a id="sj015-0272-han-event"></a>

<a id="event-3"></a>

2. **韩桓惠王元年。** 韩国进入桓惠王元年，继任者继续面对秦国压力。 [[2]](#note-3)

<a id="sj040-chu-hostage-prince-event"></a>

3. **楚与秦讲和，太子入秦为质，左徒随侍。** 楚王将继承人送秦，黄歇以左徒身份陪同，此后护太子归国的故事由这次质秦经历接起。 [[3]](#sj040-chu-hostage-prince-note)

<a id="sj043-zhang-south-event"></a>

4. **赵再改漳水河道，并封赵豹为平阳君。** 河道移到武平南面，与前278西迁不是同一次工程；本年又记河水泛溢、大潦。 [[4]](#sj043-zhang-south-note)

## 归年与考证

<a id="sj005-253-note"></a>
<a id="sj005-253秦助韩魏楚攻燕并初置南阳郡"></a>
#### sj005-253｜秦助韩魏楚攻燕，并初置南阳郡。

[卷005 P066](../../拆分史书/史记/卷005.md#p066)。

**说明：**前273编郡短句与本年“初置南阳郡”不能凭重复字眼删掉一方，也不自动视作同日，分别保留文献层次。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../拆分史书/史记/卷005.md#kao-c691f26620)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0272-war"></a>
<a id="卷015韩魏楚攻燕燕惠王去世"></a>
#### 卷015｜韩魏楚攻燕，燕惠王去世

[卷015本年八栏](../../拆分史书/史记/卷015.md#y0272)魏楚两栏记攻燕，与原秦本纪助战条合并。[《燕召公世家》](../../拆分史书/史记/卷034.md#part-1-text)与[《通鉴》卷五](../../拆分史书/资治通鉴/卷005.md#text)均把燕惠王终局、武成王承位接在这一阶段；楚栏附“鲁顷公元年”另见下条校年，不跟着战争硬定年。

<a id="sj015-0272-han"></a>
<a id="卷015韩桓惠王元年"></a>
#### 卷015｜韩桓惠王元年

[卷015本年八栏](../../拆分史书/史记/卷015.md#y0272)韩栏为桓惠王元年。这是年表纪元，不凭“元年”推定前王死亡与新王承位都发生在正月初一。

<a id="sj015-0272-lu"></a>
<a id="卷015鲁顷公元年的七年差"></a>
#### 卷015｜鲁顷公元年的七年差

[卷015本年八栏](../../拆分史书/史记/卷015.md#y0272)楚栏附记鲁顷公元年，与[《鲁周公世家》](../../拆分史书/史记/卷033.md#part-2-text)顷公二年郢陷相差七年。本文采用有郢陷和楚怀王卒两条跨国锚点可校的年链，主叙见[前279年](bce-0279.md#sj015-0279-lu-event)；本年不再立一次鲁君。

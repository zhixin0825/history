<a id="reading-event-1"></a>

1. **华阳之后，马犯借秦魏猜疑让魏替周筑城。** 秦破华阳之约以后，马犯想让魏国出力修城。他先对魏王说周王病重，以九鼎和自己的归附为诱饵，使魏派兵来周；又向秦王说魏不是戍周，而是要攻周，引秦在边境出兵。 [[1]](#reading-note-1)

   秦魏相疑以后，马犯再劝魏王：与其让诸侯怀疑，不如让这些兵替周筑城，掩去原先的企图。魏王同意，兵卒转而筑城。周王真病到什么程度、马犯最初打算怎样交鼎，不能由这套说辞直接坐实。

<a id="reading-event-2"></a>

2. **这段交涉的战场前因。** 白起率秦军在华阳击败以芒卯为将的军队，芒卯逃走，秦军俘获三晋方面的将领。魏军受重创，魏以南阳之地求和。马犯正利用秦魏在战后仍互相猜疑，才有了后面借兵修城的说辞。 赵篇另记赵、魏共同击秦，秦将白起在华阳获赵一名将军。 韩方的传述补出求援过程：赵、魏先攻韩华阳，韩多次向秦告急，秦却迟迟不出兵。韩相请患病的陈筮连夜去见穰侯魏冉；穰侯问是否情势紧急，他反说不急，解释韩若真被逼到绝境便会改投别国，如今还来请秦，正因尚能等待。穰侯由此意识到拖延会失去韩国，立即答应出兵，不必再让使者见秦王；援军八天赶至，打败华阳的赵魏军。 [[2]](#reading-note-2)

<a id="event-2"></a>

<a id="reading-event-3"></a>

3. **秦合编新得土地为郡，并安排南阳的迁居。** 本纪在昭王三十四年记与魏、韩、上庸相关的土地编制，以及免臣迁居南阳的安排。前面的攻城和受地，还需要转化为人员与管辖秩序。 [[3]](#reading-note-3)

<a id="sj043-oudai-event"></a>

4. **赵取得东胡欧代之地。** 惠文王二十六年的北边取地记未载具体将领。 [[4]](#sj043-oudai-note)

<a id="sj045-xi-death-event"></a>

5. **韩釐王去世，儿子桓惠王继位。** 釐王统治末年正逢华阳危机；新王在前272年开始以元年纪事，战争和王位承继分别交代。 [[5]](#sj045-xi-death-note)

<a id="sj044-cut-land-remonstrance-event"></a>

6. **苏代劝魏王停止以割地换安宁。** 华阳受创后，段干子主张献南阳求和。苏代指出，段干子想得相印，秦想得土地，让求相位的人决定割地、让求土地的人决定给谁相印，双方的私欲会使魏不断失地；抱柴救火，只会柴越多火越旺。魏王承认有理，却说事情既已开始不能改变。苏代再用博戏作比：有利才取，不利就停，国君决策不应反而不如赌者懂得止损。本篇没有记王终于采纳，因此不写成割地已被撤销。 [[6]](#sj044-cut-land-remonstrance-note)

> 四十二年，秦破華陽約。馬犯謂周君曰：「請令梁城周。」乃謂梁王曰：「周王病若死，則犯必死矣。犯請以九鼎自入於王，王受九鼎而圖犯。」梁王曰：「善。」遂與之卒，言戍周。因謂秦王曰：「梁非戍周也，將伐周也。王試出兵境以觀之。」秦果出兵。又謂梁王曰：「周王病甚矣，犯請後可而復之。今王使卒之周，諸侯皆生心，後舉事且不信。不若令卒為周城，以匿事端。」梁王曰：「善。」遂使城周。

> 二十三年，趙、魏攻我華陽。韓告急於秦，秦不救。韓相國謂陳筮曰：「事急，願公雖病，為一宿之行。」陳筮見穰侯。穰侯曰：「事急乎？故使公來。」陳筮曰：「未急也。」穰侯怒曰：「是可以為公之主使乎？夫冠蓋相望，告敝邑甚急，公來言未急，何也？」陳筮曰：「彼韓急則將變而佗從，以未急，故復來耳。」穰侯曰：「公無見王，請今發兵救韓。」八日而至，敗趙、魏於華陽之下。

**本卷说明：** 本篇釐二十三按295元年得273；赵篇惠文二十五得274，保留年差，合华阳主条。

> 魏將段干子請予秦南陽以和。蘇代謂魏王曰：「欲璽者段干子也，欲地者秦也。今王使欲地者制璽，使欲璽者制地，魏氏地不盡則不知已。且夫以地事秦，譬猶抱薪救火，薪不盡，火不滅。」王曰：「是則然也。雖然，事始已行，不可更矣。」對曰：「王獨不見夫博之所以貴梟者，便則食，不便則止矣。今王曰『事始已行，不可更』，是何王之用智不如用梟也？」

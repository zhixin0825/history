1. **白起取魏两城，楚则收东地兵十余万，夺回江旁十五邑。** 楚把收复城邑组织为郡，继续抵抗秦。秦在北面得城，南面新占地却仍受反攻，不能把前面的置郡当作此后控制已经完全稳定。 [[1]](#note-1)

<a id="sj015-0276-wei-event"></a>

<a id="event-2"></a>

2. **魏安釐王元年，公子无忌受封。** 魏国开始使用安釐王的纪年。魏王的弟弟公子无忌受封为信陵君；此人后来会在救赵和合纵攻秦中起重要作用。 [[2]](#note-2)

<a id="sj043-ji-event"></a>

3. **廉颇接替楼昌攻魏几，终于取城。** 楼昌先领军进攻未能攻下；十二月廉颇再攻，夺取几。 [[3]](#sj043-ji-note)

<a id="sj015-0276-wei"></a>
<a id="卷015魏安釐王元年公子无忌受封"></a>
#### 卷015｜魏安釐王元年，公子无忌受封

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0276)魏栏既有秦拔两城，也有新君元年和无忌封信陵君。取两城并原第一事；新君与封君见本条。[《魏世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-60b8825f94080f)、[《魏公子列传》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7077.md#ref-f3b4857d547d36)互见；无忌是安釐王异母弟，不是新设的独立诸侯王。

<a id="sj015-0276-chu"></a>
<a id="卷015楚国反击江旁失地"></a>
#### 卷015｜楚国反击江旁失地

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0276)楚栏与既有江旁反秦条合并。[《楚世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-0c607b15b8d631)说顷襄王收集东方军队，收复江旁十五邑作为郡以抗秦。这里是楚方的反攻，不因前277年秦置郡便默认当地从此稳定。

1. **白起攻取郢、焚夷陵王墓，楚王退保陈，秦设置南郡。** 楚军离散，顷襄王不再决战，王廷向东北迁到陈，旧都及周边编为秦郡。周君来秦，秦楚两王又会襄陵，战后仍有政治交涉；白起受封武安君。郢都失守并不等于楚国此时已灭亡。 [[1]](#note-1)

<a id="sj043-zhang-west-event"></a>

2. **赵把漳水改道到武平西面。** 惠文王二十一年的河道工程与后来二十七年改到武平南面分开记录。 [[2]](#sj043-zhang-west-note)

<a id="sj073-cite-003"></a>

**[《史记·白起王翦列传》P000](../../sources/摘录/史记-卷073-白起王翦列传.md#p000)**

> 攻楚，拔郢，燒夷陵，遂東至竟陵。

**本卷归年说明：** 白起率军攻取楚郢，秦置南郡；楚王迁陈是继后果，不另算一场楚都沦陷。

<a id="sj072-cite-007"></a>

**[《史记·穰侯列传》P004](../../sources/摘录/史记-卷072-穰侯列传.md#p004)**

**本卷归年说明：** 魏冉在相位支持白起攻楚，白起本人为前线将领，不因此虚造魏冉亲自拔郢。

## 归年与考证

<a id="sj005-246-note"></a>
<a id="sj005-246白起攻取郢秦设置南郡楚王离开旧都"></a>
#### sj005-246｜白起攻取郢，秦设置南郡，楚王离开旧都。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**本纪昭王二十九年系郢陷及白起封号，别篇封号有前后年差，保留本纪叙事，不为封号再造第二次郢陷。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0278-ying"></a>
<a id="卷015郢陷焚夷陵与楚王退陈"></a>
#### 卷015｜郢陷、焚夷陵与楚王退陈

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0278)秦楚两栏互见同一次郢陷，楚栏补焚夷陵、退陈。秦栏主见证作向东至“竟陵”，[卷015三家注本](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7015.md#ref-fb51b15c68a1f0)作“夷陵”，而焚楚陵另有[《楚世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-38ff094dc6249b)支持；保留异文，不以不同地名制造第二次都城陷落。

<a id="sj015-0278-yan"></a>
<a id="卷015燕惠王元年与此前承位"></a>
#### 卷015｜燕惠王元年与此前承位

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0278)列惠王元年；[《燕召公世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7034.md#ref-23393b71781caf)记昭王三十三年卒、惠王立，已结合[《通鉴》卷四](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-6f720690d93ef8)置[前279年的换将与齐复国](bce-0279.md#sj015-0279-tian-event)。本年只是新王年序，不再重复继位。

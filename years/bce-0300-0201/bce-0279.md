# 公元前279年｜田单收复齐国，秦赵会渑池，秦军攻楚

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **白起取楚鄢、邓、西陵，秦迁人入其地。** 秦先在楚都外围取得重要据点，又赦免罪人迁入，军事占领与人口迁徙结合。 [[1]](#note-1)

<a id="sj015-0279-mianchi-event"></a>

<a id="event-2"></a>

2. **秦赵在渑池会面。** 秦昭襄王与赵惠文王在渑池相会，蔺相如随赵王前往。席间秦王请赵王鼓瑟，蔺相如又争取秦王击缶，使赵国没有在礼仪上单方面受辱。赵国同时备兵，防备会见转为胁迫。 [[2]](#note-2)

<a id="sj015-0279-tian-event"></a>

<a id="event-3"></a>

3. **田单击败燕军，齐国收复失地。** 燕昭王去世，继位的惠王不信任乐毅，改用骑劫领军，乐毅转奔赵国。田单据守即墨，利用燕军换将后的不安反攻，击败燕军，骑劫战死。齐人乘势收复城邑，田单迎齐襄王回临淄。此前田单曾在安平给家人的车轴末端加铁护套，城破时得以逃到即墨；这段逃难经历使他逐渐受到守城者信任。 [[3]](#note-3)

<a id="sj015-0279-lu-event"></a>

<a id="event-4"></a>

4. **鲁国进入顷公时期。** 顷公名雠，是鲁文公的儿子，也是后来鲁国的末代国君。 [[4]](#note-4)

<a id="sj043-lianpo-qi-event"></a>

5. **廉颇继续率赵军攻齐。** 惠文王二十年的记事没有详列这次战果。 [[5]](#sj043-lianpo-qi-note)

<a id="sj005-245-note"></a>

#### sj005-245｜白起取楚鄢、邓，秦迁人入其地。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**本卷没有展开鄢城水攻细节，后续材料须核原文后补，不凭印象插入战术。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0279-mianchi"></a>
<a id="卷015秦赵在渑池会面"></a>
#### 卷015｜秦赵在渑池会面

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0279)赵栏记“黽池”、蔺相如随行，[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-4cedddfc7906c9)及[《廉颇蔺相如列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7081.md#ref-9a6fc890a064ae)作渑池之会。会中鼓瑟击缶的叙事和归国后的廉蔺交往是同一政治背景，不据叙事衔接断定全部发生在同一天。

<a id="sj015-0279-xiling"></a>
<a id="卷015秦取西陵及衝衛异文"></a>
#### 卷015｜秦取西陵及衝、衛异文

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0279)楚栏作“衝、西陵”，[卷015三家注本](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7015.md#ref-09b263e0cce242)作“衛、西陵”；[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-8351c97f6f114c)明确记白起拔西陵，[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-751ad6baa60edc)并记鄢、邓、西陵。正文沿有互见支持的鄢、邓、西陵，衝／衛保留在注内，不静默改来源或强定为另一座已识别城。

<a id="sj015-0279-tian"></a>
<a id="卷015田单击败燕军齐国收复失地"></a>
#### 卷015｜田单击败燕军，齐国收复失地

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0279)齐栏只简记杀骑劫。完整因果据[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-b4d7df325915d0)和[《田单列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7082.md#ref-fe58d91f4b103a)：燕昭王死、惠王换将、田单反击。田单出自齐国田氏旁支，原为临淄市掾；安平逃难至即墨是战乱期间前事，不把这些经历全部压到本年。

<a id="sj015-0279-lu"></a>
<a id="卷015鲁国进入顷公时期"></a>
#### 卷015｜鲁国进入顷公时期

[《鲁周公世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7033.md#ref-2dbb1345559933)记顷公二年秦拔郢；以郢陷前278年为锚，顷公元年应在本年。世家又记文公七年楚怀王死秦、文公二十三年卒，亦能衔接。卷015把元年列前272，晚七年；本项目采用有两条跨国事件相校的年链，详见[本段考证](../../meta/考证/史记-卷015-前0286至0247纪年补核.md#鲁国末年)。

<a id="卷023礼制沿革与本页史事互见"></a>
### 卷023｜礼制沿革与本页史事互见

[L006原文](../../sources/摘录/史记-卷023-礼书.md#l006)。卷023以鄢郢失守说明险阻不足恃；其中鄢、邓的攻取接本页白起攻楚，郢陷在下一年前278年。原卷论证是压缩回顾，不能把两座城均移到前278年，也不据若振槁倒造实际一日攻下的速度。

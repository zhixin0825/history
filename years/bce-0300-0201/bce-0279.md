# 公元前279年｜田单收复齐国，秦赵会渑池，秦军攻楚

## 本年纪事

<a id="event-1"></a>

1. **白起取楚鄢、邓、西陵，秦迁人入其地。** 秦先在楚都外围取得重要据点，又赦免罪人迁入，军事占领与人口迁徙结合。 [原文与说明](#sj005-245-note)

<a id="sj015-0279-mianchi-event"></a>
**秦赵在渑池会面。** 秦昭襄王与赵惠文王在渑池相会，蔺相如随赵王前往。席间秦王请赵王鼓瑟，蔺相如又争取秦王击缶，使赵国没有在礼仪上单方面受辱。赵国同时备兵，防备会见转为胁迫。 [原文与说明](#sj015-0279-mianchi)

<a id="sj015-0279-tian-event"></a>
**田单击败燕军，齐国收复失地。** 燕昭王去世，继位的惠王不信任乐毅，改用骑劫领军，乐毅转奔赵国。田单据守即墨，利用燕军换将后的不安反攻，击败燕军，骑劫战死。齐人乘势收复城邑，田单迎齐襄王回临淄。此前田单曾在安平给家人的车轴末端加铁护套，城破时得以逃到即墨；这段逃难经历使他逐渐受到守城者信任。 [原文与说明](#sj015-0279-tian)

<a id="sj015-0279-lu-event"></a>
**鲁国进入顷公时期。** 顷公名雠，是鲁文公的儿子，也是后来鲁国的末代国君。 [原文与说明](#sj015-0279-lu)

## 本年相关史料

<a id="sj005-245-note"></a>
### sj005-245｜白起取楚鄢、邓，秦迁人入其地。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**本卷没有展开鄢城水攻细节，后续材料须核原文后补，不凭印象插入战术。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0279-mianchi"></a>
### 卷015｜秦赵在渑池会面

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0279)赵栏记“黽池”、蔺相如随行，[《通鉴》卷四](https://zh.wikisource.org/wiki/資治通鑑/卷004)及[《廉颇蔺相如列传》](https://zh.wikisource.org/wiki/史記/卷081)作渑池之会。会中鼓瑟击缶的叙事和归国后的廉蔺交往是同一政治背景，不据叙事衔接断定全部发生在同一天。

<a id="sj015-0279-xiling"></a>
### 卷015｜秦取西陵及衝、衛异文

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0279)楚栏作“衝、西陵”，[卷015三家注本](https://zh.wikisource.org/wiki/史記三家註/卷015)作“衛、西陵”；[《楚世家》](https://zh.wikisource.org/wiki/史記/卷040)明确记白起拔西陵，[《通鉴》卷四](https://zh.wikisource.org/wiki/資治通鑑/卷004)并记鄢、邓、西陵。正文沿有互见支持的鄢、邓、西陵，衝／衛保留在注内，不静默改来源或强定为另一座已识别城。

<a id="sj015-0279-tian"></a>
### 卷015｜田单击败燕军，齐国收复失地

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0279)齐栏只简记杀骑劫。完整因果据[《通鉴》卷四](https://zh.wikisource.org/wiki/資治通鑑/卷004)和[《田单列传》](https://zh.wikisource.org/wiki/史記/卷082)：燕昭王死、惠王换将、田单反击。田单出自齐国田氏旁支，原为临淄市掾；安平逃难至即墨是战乱期间前事，不把这些经历全部压到本年。

<a id="sj015-0279-lu"></a>
### 卷015｜鲁国进入顷公时期

[《鲁周公世家》](https://zh.wikisource.org/wiki/史記/卷033)记顷公二年秦拔郢；以郢陷前278年为锚，顷公元年应在本年。世家又记文公七年楚怀王死秦、文公二十三年卒，亦能衔接。卷015把元年列前272，晚七年；本项目采用有两条跨国事件相校的年链，详见[本段考证](../../meta/考证/史记-卷015-前0286至0247纪年补核.md#鲁国末年)。

1. **秦从不同方向攻楚，司马错经蜀取黔中。** 秦调陇西兵，经蜀向楚地推进，夺取黔中，楚国又把汉北、上庸之地交给秦；秦还将获赦罪人迁南阳。南方扩张以既得蜀地为通路，而不是每次只从关中正面进军。 [[1]](#note-1)

<a id="event-2"></a>

2. **白起攻赵，取光狼城。** 本纪将这项北方行动与同年攻楚并列，秦军同时经营多条战线。 [[2]](#note-2)

<a id="sj015-0280-zhaowar-event"></a>

<a id="event-3"></a>

3. **秦赵战争及秦地震。** 秦地发生地震，城垣受损。原记没有列明受灾各城，也没有留下可据以换算的震级。 [[3]](#note-3)


<a id="sj033-wen-death-event"></a>

4. **鲁文公去世，儿子讎继位为顷公。** 此次承继暂系本年，另说见注。 [[4]](#sj033-wen-death-note)

### 1. 秦从不同方向攻楚，司马错经蜀取黔中

[返回正文第1条](#event-1)

**[《史记·秦本纪》昭王二十七年（P066节录）](../../sources/摘录/史记-卷005-秦本纪.md#p066)**

> 二十七年，錯攻楚。赦罪人遷之南陽。

中间白起攻赵一句另引于[第2条](#note-2)，此处续引攻楚之事：

> 又使司馬錯發隴西，因蜀攻楚黔中，拔之。

**[《史记·六国年表》前280年对应国别原格](../../sources/摘录/史记-卷015-六国年表.md#y0280)**

**楚**：

> 十九。秦擊我，與秦漢北及上庸地。

[史料说明](#sj005-243-note)

<a id="sj040-cite-196"></a>

**[《史记·楚世家》P092](../../sources/摘录/史记-卷040-楚世家.md#p092)**

> 十九年，秦伐楚，楚軍敗，割上庸、漢北地予秦。

**本卷说明：** 楚割上庸汉北与秦自蜀进军为同一年度多向战争；不能将秦取黔中一次性等同本段所有失地。

### 4. 鲁文公去世，儿子讎继位为顷公

[返回正文第4条](#sj033-wen-death-event)

<a id="sj033-cite-143"></a>

**[《史记·鲁周公世家》P093](../../sources/摘录/史记-卷033-鲁周公世家.md#p093)**

> 二十三年，文公卒，子讎立，是為頃公。

**归年：** 本篇记文公二十三年卒、子讎继为顷公。结合文公七年楚怀王死秦（前296年）和顷公二年郢陷（前278年），现有主线采用文公元年前302、二十三年前280、顷公元年前279的衔接。本条依这条年链暂系，并非独立铭文确证；《六国年表》另有相差七年的年链，仍保留其分歧。详见[战国鲁国的两套年链](../../meta/考证/史记-卷033-纪年与异说.md#late)。

<a id="sj005-244-note"></a>

#### sj005-244｜白起攻赵，取光狼城。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**本纪作“代光狼城”，地望字句保留于原文；不把同年所有秦军战果都归于司马错或都归白起。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0280-chu"></a>
<a id="卷015楚交出汉北上庸"></a>
#### 卷015｜楚交出汉北、上庸

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0280)楚栏的割地并入第一事，[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-ff9dfae58d59e6)顷襄王十九年与[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-002f6a8dbd4572)同年均有依据。与司马错黔中战事同一阶段，不将各方向部队全归一个将领。

<a id="sj015-0280-zhaowar"></a>
<a id="卷015秦赵战争及秦地震"></a>
#### 卷015｜秦赵战争及秦地震

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0280)秦、赵两栏同记斩首三万，属于同书相互对照，不能算两份独立统计；[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-ad41824d04c667)作二万。本页北线战争沿既有白起取光狼城条，数量保留为异文。秦栏另有“地动，坏城”，单独补下面地震，不误当战场攻城。

1. **秦取赵两城，并继续会见韩魏两王。** 秦王与韩王会新城，与魏王会新明邑。沿用城名并不意味着它们是同一个地方的两种写法。 [[1]](#note-1)

<a id="sj015-0282-flood-event"></a>

<a id="event-2"></a>

2. **魏国水灾与卫怀君纪年。** 魏国发生大水。卫国则进入怀君元年，与前一年嗣君去世、怀君承位相衔接。 [[2]](#note-2)

<a id="sj015-0282-flood"></a>
<a id="卷015魏国水灾与卫怀君纪年"></a>
#### 卷015｜魏国水灾与卫怀君纪年

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0282)魏栏一格兼“大水”及“卫怀君元年”，必须拆开理解。大水暂从本表归本年；卫国承位已随[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-07a5e3885b3ea4)置[前283年](bce-0283.md#sj015-0283-wei-event)，本年只开始元年，不再造一次即位。

<a id="sj015-0282-han"></a>
<a id="卷015秦韩在两周之间相会"></a>
#### 卷015｜秦韩在两周之间相会

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0282)韩栏“与秦会两周间”与本纪新城会韩王互见；两周指东周国、西周国相关地域，不是两个周朝时代。地点描述粒度不同，保留两种记法，不据此断言两场独立会议。原有秦魏新明邑会见照存。

<a id="sj015-0282-zhao"></a>
<a id="卷015秦取赵两城"></a>
#### 卷015｜秦取赵两城

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0282)赵栏与本页第一事、[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-b182a546d595e5)同年条合并。城名未列，不擅将下一年石城倒填进这两城。

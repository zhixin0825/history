1. **秦进逼魏都，燕赵援救后秦军撤退。** 秦先取魏安城，军队推进到大梁；燕、赵出兵救魏，秦未能继续占领而退。同年秦王两次会楚王，先鄢后穰，魏冉又被免相。 [[1]](#note-1)

<a id="sj015-0283-qi-event"></a>

<a id="event-2"></a>

2. **法章在莒承续齐国王位。** 齐湣王之子法章在莒被拥立，是为齐襄王。此前他改名躲在莒地太史敫家中做佣人，得到太史敫女儿照顾；王孙贾发动当地人杀死淖齿后，齐国旧臣寻得法章，拥立他继续抵抗燕军。 [[2]](#note-2)

<a id="sj015-0283-wei-event"></a>

<a id="event-3"></a>

3. **卫嗣君死，怀君承位。** 卫嗣君去世，儿子怀君承位。卫国此时已经很弱，君位仍在延续。 [[3]](#note-3)

## 归年与考证

<a id="sj005-240-note"></a>
<a id="sj005-240秦进逼魏都燕赵援救后秦军撤退"></a>
#### sj005-240｜秦进逼魏都，燕赵援救后秦军撤退。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**安城被取、到大梁、因救援而去，是一条完整战事，不能仅据“至大梁”写成魏都已陷落。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0283-qinwei"></a>
<a id="卷015围大梁与穰会的互见"></a>
#### 卷015｜围大梁与穰会的互见

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0283)秦楚两栏同记会穰，魏栏记安城被取、秦军到大梁而返，均补本页第一事。[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-965fa910bc58a4)此处会见作“秦、赵”，与年表及秦本纪的秦楚不同，暂据两篇互见保留秦楚，不能不说明便添造同年另一场秦赵穰会。

<a id="sj015-0283-qi"></a>
<a id="卷015法章在莒承续齐国王位"></a>
#### 卷015｜法章在莒承续齐国王位

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0283)列齐襄王法章元年。[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-3fd9333786ffb1)叙法章避难、淖齿被杀、齐臣拥立的过程；用本年作为元年阅读位置，不据此排定登位仪式的月日。

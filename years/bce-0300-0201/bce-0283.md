<a id="event-1"></a>

1. **秦进逼魏都，燕赵援救后秦军撤退。** 秦先取魏安城，军队推进到大梁；燕、赵出兵救魏，秦未能继续占领而退。同年秦王两次会楚王，先鄢后穰，魏冉又被免相。 [[1]](#note-1)

<a id="sj015-0283-qi-event"></a>

<a id="event-2"></a>

2. **法章在莒承续齐国王位。** 齐湣王之子法章此前改名，在莒太史敫家做佣人，得到敫女衣食照顾。王孙贾发动当地人诛淖齿。莒人与齐国旧臣寻求湣王子，法章怕被杀，过了些时日才敢表明身份。众人拥立他为襄王，守莒并告齐国中已有新王，维系继续抵抗燕军的城邑。 [[2]](#note-2)

<a id="sj015-0283-wei-event"></a>

<a id="event-3"></a>

3. **卫嗣君死，怀君承位。** 卫嗣君去世，儿子怀君承位。卫国此时已经很弱，君位仍在延续。 [[3]](#note-3)

<a id="sj043-suli-letter-event"></a>

4. **苏厉为齐上书赵王，赵中止这一轮与秦合攻齐的计划。** 秦与赵连年攻齐，齐人忧惧，苏厉劝赵不要只看眼前利益。他先以古之贤君为喻：即使德教、祭享未必特别优厚，仍可能遇甘露、时雨、丰收、无疫，众人赞美，贤主却继续深察。赵对秦无累积特殊恩德，对齐无深仇，秦并非真爱赵而憎齐，而想灭韩吞二周，以齐为饵招诸国；出兵胁魏赵、送质子示信、征韩兵威慑，表面施惠盟国，实际使韩空虚。情势不同而祸患可同，楚久受攻时中山亡，齐久受攻也会让韩亡；破齐的利要六国分享，灭韩、收二周、取周祭器却全归秦，赵算田地与功劳，所得岂能相比。苏厉又说韩失三川、魏失晋地，即使市朝未改，祸已临近；燕若尽取齐北，距沙丘钜鹿不到三百里，韩上党距邯郸百里，秦燕相接足以威胁赵。秦上郡近挺关、通榆中一千五百里，若从三郡攻赵上党，羊肠以西、句注以南便可能失守；越句注、截常山，再三百里通燕，代马胡犬不能东来、昆山玉不能出，三宝皆失。他提醒王，这些是久攻齐、随秦攻韩可能造成的后患。再论齐旧日相助：天下曾谋赵，燕秦约成将出兵，五国议分赵地，齐背五国约救赵，西阻秦兵，使秦去帝号求服，归高平根柔于魏、坙分先俞于赵。这样事赵本应是上交，却反遭罪，往后谁敢相信帮助赵有好结果？最后苏厉请王退出攻齐，使天下称赵有义、齐以社稷厚事赵，再由赵联合天下善秦，秦暴时又合天下制秦，便能掌握名望和制衡之权。赵王采纳，向秦辞谢，不参加这一轮攻齐。 [[4]](#sj043-suli-letter-note)

<a id="sj043-meet-yan-event"></a>

5. **赵王与燕王会面。** 惠文王十六年另记这次会见。紧随的廉颇取昔阳与前284年表既有取城条合读，不能据一年差再造一次攻陷。 [[5]](#sj043-meet-yan-note)

<a id="sj046-queen-family-event"></a>

6. **襄王时期后续附读｜君王后与父亲的关系。** 太史敫之女曾暗中给法章衣食并与他相爱，法章立后娶她为后，后来生王子建。太史敫认为女儿不经媒聘自嫁有辱家门，终身不肯见她；她仍尽女儿之礼。这是家族生平的合叙，婚立、建的出生及终身不见不都确指前283年。 [[6]](#sj046-queen-family-note)

<a id="event-7"></a>

7. **蔺相如奉和氏璧入秦。** 赵惠文王得到和氏璧，秦昭王提出用十五座城交换。赵王既怕交璧受骗，也怕拒绝招致秦兵，便派蔺相如奉璧赴秦。相如看出秦王没有交城的诚意，借口指示璧上的瑕疵取回玉璧，并派随从先经小路送回赵国。秦王仍依礼放相如回国，赵王任他为上大夫，秦赵最终均未交付所许的城与璧。 [[7]](#note-7)

<a id="sj005-240秦进逼魏都燕赵援救后秦军撤退"></a>
#### sj005-240｜秦进逼魏都，燕赵援救后秦军撤退。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**安城被取、到大梁、因救援而去，是一条完整战事，不能仅据“至大梁”写成魏都已陷落。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0283-qinwei"></a>
<a id="卷015围大梁与穰会的互见"></a>
#### 卷015｜围大梁与穰会的互见

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0283)秦楚两栏同记会穰，魏栏记安城被取、秦军到大梁而返，均补本页第一事。[《通鉴》卷四](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-965fa910bc58a4)此处会见作“秦、赵”，与年表及秦本纪的秦楚不同，暂据两篇互见保留秦楚，不能不说明便添造同年另一场秦赵穰会。

<a id="sj015-0283-qi"></a>
<a id="卷015法章在莒承续齐国王位"></a>
#### 卷015｜法章在莒承续齐国王位

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0283)列齐襄王法章元年。[《通鉴》卷四](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-3fd9333786ffb1)叙法章避难、淖齿被杀、齐臣拥立的过程；用本年作为元年阅读位置，不据此排定登位仪式的月日。

<a id="sj015-0283-wei"></a>
<a id="卷015卫嗣君死怀君承位"></a>
#### 卷015｜卫嗣君死，怀君承位

[《通鉴》卷四](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-a2209bba433167)把卫嗣君死、怀君立系本年，[《卫康叔世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-9982734bf83ef2)亦有父子承继关系。卷015在下一年始记怀君元年，见[前282年说明](bce-0282.md#sj015-0282-flood)。

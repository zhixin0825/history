1. **秦参与多国伐齐，联军在济西击败齐军。** 燕将乐毅统合联军，秦方由尉斯离领兵，与韩、魏、赵、燕一同行动。秦王同年又在宜阳会魏王、在新城会韩王，联军之间仍有各自谈判。 [[1]](#note-1)

<a id="sj015-0284-coalition-event"></a>

<a id="event-2"></a>

2. **济西战败后，燕军进入临淄。** 济西战败以后，燕军继续追击，进入齐都临淄，将齐国宝物、祭器运回燕国。齐湣王逃离国都，辗转到莒，后来被楚将淖齿杀死。齐国仍有城邑抵抗，王室也没有就此断绝。 [[2]](#note-2)

<a id="sj015-0284-land-event"></a>

<a id="event-3"></a>

3. **赵、楚分别夺取齐地。** 赵国夺取齐国的昔阳，楚国夺取齐国淮北地区。齐军主力失败后，邻国各有所得，燕军也并未独占全部战果。 [[3]](#note-3)

<a id="sj015-0284-zhoumeet-event"></a>

<a id="event-4"></a>

4. **秦、韩、魏在周地相会。** 秦王、魏王、韩王又在周王畿相会。各国结成联军之后，君主之间仍继续交涉。 [[4]](#note-4)

### 1. 秦参与多国伐齐，联军在济西击败齐军

[返回正文第1条](#event-1)

**[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)**

> 十三年，向壽伐韓，取武始。左更白起攻新城。五大夫禮出亡奔魏。任鄙為漢中守。十四年，左更白起攻韓、魏於伊闕，斬首二十四萬，虜公孫喜，拔五城。十五年，大良造白起攻魏，取垣，復予之。攻楚，取宛。十六年，左更錯取軹及鄧。冉免，封公子市宛，公子悝鄧，魏冉陶，為諸侯。十七年，城陽君入朝，及東周君來朝。秦以垣為蒲阪、皮氏。王之宜陽。十八年，錯攻垣、河雍，決橋取之。十九年，王為西帝，齊為東帝，皆復去之。呂禮來自歸。齊破宋，宋王在魏，死溫。任鄙卒。二十年，王之漢中，又之上郡、北河。二十一年，錯攻魏河內。魏獻安邑，秦出其人，募徙河東賜爵，赦罪人遷之。涇陽君封宛。二十二年，蒙武伐齊。河東為九縣。與楚王會宛。與趙王會中陽。二十三年，尉斯離與三晉、燕伐齊，破之濟西。王與魏王會宜陽，與韓王會新城。二十四年，與楚王會鄢，又會穰。秦取魏安城，至大梁，燕、趙救之，秦軍去。魏冉免相。二十五年，拔趙二城。與韓王會新城，與魏王會新明邑。二十六年，赦罪人遷之穰。侯冉復相。二十七年，錯攻楚。赦罪人遷之南陽。白起攻趙，取代光狼城。又使司馬錯發隴西，因蜀攻楚黔中，拔之。二十八年，大良造白起攻楚，取鄢、鄧，赦罪人遷之。二十九年，大良造白起攻楚，取郢為南郡，楚王走。周君來。王與楚王會襄陵。白起為武安君。三十年，蜀守若伐楚，取巫郡，及江南為黔中郡。三十一年，白起伐魏，取兩城。楚人反我江南。三十二年，相穰侯攻魏，至大梁，破暴鳶，斬首四萬，鳶走，魏入三縣請和。三十三年，客卿胡（傷）［陽］攻魏卷、蔡陽、長社，取之。擊芒卯華陽，破之，斬首十五萬。魏入南陽以和。三十四年，秦與魏、韓上庸地為一郡，南陽免臣遷居之。三十五年，佐韓、魏、楚伐燕。初置南陽郡。三十六年，客卿灶攻齊，取剛、壽，予穰侯。三十八年，中更胡（傷）［陽］攻趙閼與，不能取。四十年，悼太子死魏，歸葬芷陽。四十一年夏，攻魏，取邢丘、懷。四十二年，安國君為太子。十月，宣太后薨，葬芷陽酈山。九月，穰侯出之陶。四十三年，武安君白起攻韓，拔九城，斬首五萬。四十四年，攻韓南（郡）［陽］，取之。四十五年，五大夫賁攻韓，取十城。葉陽君悝出之國，未至而死。四十七年，秦攻韓上黨，上黨降趙，秦因攻趙，趙發兵擊秦，相距。秦使武安君白起擊，大破趙於長平，四十餘萬盡殺之。四十八年十月，韓獻垣雍。秦軍分為三軍。武安君歸。王龁將伐趙（武安）皮牢，拔之。司馬梗北定太原，盡有韓上黨。正月，兵罷，復守上黨。其十月，五大夫陵攻趙邯鄲。四十九年正月，益發卒佐陵。陵戰不善，免，王龁代將。其十月，將軍張唐攻魏，為蔡尉捐弗守，還斬之。五十年十月，武安君白起有罪，為士伍，遷陰密。張唐攻鄭，拔之。十二月，益發卒軍汾城旁。武安君白起有罪，死。龁攻邯鄲，不拔，去，還奔汾軍。二月餘攻晉軍，斬首六千，晉楚流死河二萬人。攻汾城，即從唐拔寧新中，寧新中更名安陽。初作河橋。

#### sj005-239｜秦参与多国伐齐，联军在济西击败齐军。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**原卷005只述秦方参与及济西之败；本次卷015已补燕军深入、湣王出奔及各国取地，田单复国见前279年，仍不等于卷080、082各传全文均已整理。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0284-coalition"></a>
<a id="卷015济西战败后燕军进入临淄"></a>
#### 卷015｜济西战败后，燕军进入临淄

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0284)五栏互见同一次联军伐齐。魏、韩所记西周会见另见下条。[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-9afb31036a0353)补乐毅进军及湣王遇害；不能把燕军单独深入写成全部五国军队同时占领齐都。

<a id="sj015-0284-land"></a>
<a id="卷015赵楚分别夺取齐地"></a>
#### 卷015｜赵、楚分别夺取齐地

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0284)赵栏“取齐昔阳”、楚栏“取齐淮北”分别落本条。楚参与局势与五国在济西的名单不完全相同，不给五国名单擅加第六国。昔阳、淮北依原名，不把淮北直接等同现代一座城市。

<a id="sj015-0284-zhoumeet"></a>
<a id="卷015秦韩魏在周地相会"></a>
#### 卷015｜秦、韩、魏在周地相会

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0284)魏、韩栏均记“与秦王会西周”；[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-a94958d365bffd)作三王“会于京师”。秦本纪另记宜阳会魏王、新城会韩王，本文保留各自地点，不无据把所有会见都证明为同一场。

1. **联军败齐于济西，燕取临淄，齐湣王遇害。** 秦参与多国伐齐，联军在济西击败齐军。燕将乐毅统合联军，秦方由尉斯离领兵，与韩、魏、赵、燕一同行动。秦王同年又在宜阳会魏王、在新城会韩王，联军之间仍有各自谈判。《赵世家》另在[前285年](bce-0285.md#sj043-cite-184)记乐毅率诸国攻齐取灵丘，次年才记齐王败走与燕取临淄。济西战败后，燕军进入临淄。燕军追击败走的齐湣王，夺取齐都宝物、祭器，并焚烧宫室宗庙。湣王先逃卫，卫君让出宫舍、以臣礼供应，却因他失礼而关系破裂；又到邹鲁仍显骄色，未获接纳，才走莒。楚将淖齿以援兵而来并任齐相，后来却杀湣王、取财地。燕军占据大片齐地，莒、即墨仍在抵抗，齐国王室没有就此断绝。赵篇十五年开头还记燕昭王到赵会见，作为这一阶段列国往来的互见。燕昭王赴济上劳军，封乐毅为昌国君。赵、楚分别夺取齐地。赵国夺取齐国的昔阳，楚国夺取齐国淮北地区。齐军主力失败后，邻国各有所得，燕军也并未独占全部战果。赵篇记这次取昔阳由廉颇领军，其年次列惠文十六年，与年表十五年相差一年。 [[1]](#note-1)

<a id="sj015-0284-zhoumeet-event"></a>

<a id="event-4"></a>

2. **秦、韩、魏在周地相会。** 秦王、魏王、韩王又在周王畿相会。各国结成联军之后，君主之间仍继续交涉。 [[2]](#note-4)

## 归年与考证

<a id="sj005-239-note"></a>
<a id="sj005-239秦参与多国伐齐联军在济西击败齐军"></a>
#### sj005-239｜秦参与多国伐齐，联军在济西击败齐军。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**原卷005只述秦方参与及济西之败；本次卷015已补燕军深入、湣王出奔及各国取地，田单复国见前279年，仍不等于卷080、082各传全文均已整理。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0284-coalition"></a>
<a id="卷015济西战败后燕军进入临淄"></a>
#### 卷015｜济西战败后，燕军进入临淄

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0284)五栏互见同一次联军伐齐。魏、韩所记西周会见另见下条。[《通鉴》卷四](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-9afb31036a0353)补乐毅进军及湣王遇害；不能把燕军单独深入写成全部五国军队同时占领齐都。

<a id="sj015-0284-land"></a>
<a id="卷015赵楚分别夺取齐地"></a>
#### 卷015｜赵、楚分别夺取齐地

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0284)赵栏“取齐昔阳”、楚栏“取齐淮北”分别落本条。楚参与局势与五国在济西的名单不完全相同，不给五国名单擅加第六国。昔阳、淮北依原名，不把淮北直接等同现代一座城市。

<a id="sj015-0284-zhoumeet"></a>
<a id="卷015秦韩魏在周地相会"></a>
#### 卷015｜秦、韩、魏在周地相会

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0284)魏、韩栏均记“与秦王会西周”；[《通鉴》卷四](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-a94958d365bffd)作三王“会于京师”。秦本纪另记宜阳会魏王、新城会韩王，本文保留各自地点，不无据把所有会见都证明为同一场。

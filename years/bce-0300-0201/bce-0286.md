<a id="event-1"></a>

1. **秦攻魏河内，魏献安邑，秦迁入新居民。** 秦让安邑原住民迁出，募民向河东迁徙并赐爵，也赦免部分罪人迁往当地。军队取地以后，以人口安排和行政措施巩固控制。 [[1]](#note-1)

<a id="event-2"></a>

2. **齐国灭宋，宋君逃亡后死于温。** 宋的覆亡改变东方强国格局，也引出后来多国共同攻齐。 在灭亡以前，宋君偃曾向齐、楚、魏扩张，传世记载称取齐五城、楚地三百里；具体各役年次未详。围绕他的亡国叙事又写到用装血皮囊“射天”、向进谏者放箭，诸侯因而以“桀宋”责之；这些责罪故事作为此前背景阅读，不一律编成本年发生的行动。 [[2]](#note-2)

<a id="sj015-0286-xiashan-event"></a>

<a id="event-3"></a>

3. **秦在夏山击败韩军。** 秦对魏用兵和受地的同时，也在夏山打败了韩国军队。 [[3]](#note-3)

<a id="sj038-cite-133"></a>

**[《史记·宋微子世家》P057](../../sources/摘录/史记-卷038-宋微子世家.md#p057)**

> 東敗齊，取五城；南敗楚，取地三百里；西敗魏軍，乃與齊、魏為敵國。盛血以韋囊，縣而射之，命曰「射天」。淫於酒婦人。群臣諫者輒射之。於是諸侯皆曰「桀宋」。「宋其復為紂所為，不可不誅」。告齊伐宋。王偃立四十七年，齊湣王與魏、楚伐宋，殺王偃，遂滅宋而三分其地。

**本卷说明：** 本段先概述此前未确年的扩张、奢暴及责罪故事，再述亡国，不把所有行为当作286一年的政令。主文偃47年、齐魏楚共灭杀王三分地；年表328元至286为43年，并记齐灭宋、宋王死魏温。正文沿已有年表主线，另一叙法留在本注。

<!-- /sj038-cite-133 -->

<a id="sj038-cite-138"></a>

**[司马贞《索隐述赞》Z001（后出评论）](../../sources/摘录/史记-卷038-宋微子世家.md#z001)**

> 【索隱述贊】殷有三仁，微箕紂親。一囚一去，不顧其身。頌美有客，書稱作賓。卒傳塚嗣，或敘彝倫。微仲之後，世載忠勤。穆亦能讓，實為知人。傷泓之役，有君無臣。偃號「桀宋」，天之棄殷。

**本卷说明：** 唐代司马贞对全卷的韵文总评。它回顾三仁、微仲、穆公、泓战与末宋，和本年灭国事实分层。

## 归年与考证

<a id="sj005-236-note"></a>
<a id="sj005-236秦攻魏河内魏献安邑秦迁入新居民"></a>
#### sj005-236｜秦攻魏河内，魏献安邑，秦迁入新居民。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**“魏献安邑”与数十年前卫鞅曾使安邑降不同，不合并为一次终局占领。泾阳君封宛又见同年，前291公子市封宛已有互见，保留为封邑记录差异或重申，不另写第二人。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj005-237-note"></a>
<a id="sj005-237齐国灭宋宋君逃亡后死于温"></a>
#### sj005-237｜齐国灭宋，宋君逃亡后死于温。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**秦本纪把齐破宋接昭王十九年，六国年表对应宋康王末年为前286，采用后者。宋君在魏、死温是逃亡结局，不据同句确定具体死日。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0286-qin"></a>
<a id="卷015魏交出安邑河内"></a>
#### 卷015｜魏交出安邑、河内

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0286)秦栏与原有秦攻河内、魏献安邑、迁民条合读，不另写第二次交地。安邑此前降秦与本年的土地和人口处置属于不同阶段；原表把河内也列入魏所纳之地。

<a id="sj015-0286-song"></a>
<a id="卷015齐灭宋及宋王的结局"></a>
#### 卷015｜齐灭宋及宋王的结局

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0286)魏栏记宋王死于魏地温，齐栏记灭宋；与本页第二事合并。[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-11bbfb2e60d0de)同年记宋王出奔魏、死于温。魏栏的位置不是说魏灭宋。

#### 卷015｜秦在夏山击败韩军

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0286)韩栏与[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-c5f61941575f48)同年互见。原文没有列出韩军将领、兵数或夏山的现代坐标，不增补猜测。

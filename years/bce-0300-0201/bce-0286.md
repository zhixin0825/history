# 公元前286年｜秦攻魏河内，魏献安邑，秦迁入新居民

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦攻魏河内，魏献安邑，秦迁入新居民。** 秦让安邑原住民迁出，募民向河东迁徙并赐爵，也赦免部分罪人迁往当地。军队取地以后，以人口安排和行政措施巩固控制。 [[1]](#note-1)

<a id="event-2"></a>

2. **齐国灭宋，宋君逃亡后死于温。** 宋的覆亡改变东方强国格局，也引出后来多国共同攻齐。 在灭亡以前，宋君偃曾向齐、楚、魏扩张，传世记载称取齐五城、楚地三百里；具体各役年次未详。围绕他的亡国叙事又写到用装血皮囊“射天”、向进谏者放箭，诸侯因而以“桀宋”责之；这些责罪故事作为此前背景阅读，不一律编成本年发生的行动。 攻宋时，秦王曾责韩聂损害自己所爱之国；苏代替齐辩称，齐并宋会使楚魏恐惧而西事秦，齐也需秦支持才能安定宋地，秦齐不应任由往来游士挑拨。秦王接受这一解释。齐随后又向楚淮北及三晋方向扩张，图并周称天子，邹鲁等泗上诸侯受压，诸国对齐的恐惧加深。 [[2]](#note-2)

<a id="sj015-0286-xiashan-event"></a>

<a id="event-3"></a>

3. **秦在夏山击败韩军。** 秦对魏用兵和受地的同时，也在夏山打败了韩国军队。 [[3]](#note-3)

<a id="sj043-hanxu-qi-event"></a>

4. **韩徐统赵军攻齐，王室公主也在此年去世。** 韩徐是本篇所记将名，公主姓名与婚配未详。 [[4]](#sj043-hanxu-qi-note)

<a id="sj038-cite-133"></a>

**[《史记·宋微子世家》P057](../../sources/摘录/史记-卷038-宋微子世家.md#p057)**

> 東敗齊，取五城；南敗楚，取地三百里；西敗魏軍，乃與齊、魏為敵國。盛血以韋囊，縣而射之，命曰「射天」。淫於酒婦人。群臣諫者輒射之。於是諸侯皆曰「桀宋」。「宋其復為紂所為，不可不誅」。告齊伐宋。王偃立四十七年，齊湣王與魏、楚伐宋，殺王偃，遂滅宋而三分其地。

**本卷说明：** 本段先概述此前未确年的扩张、奢暴及责罪故事，再述亡国，不把所有行为当作286一年的政令。主文偃47年、齐魏楚共灭杀王三分地；年表328元至286为43年，并记齐灭宋、宋王死魏温。正文沿已有年表主线，另一叙法留在本注。

<!-- /sj038-cite-133 -->

<a id="sj038-cite-138"></a>

**[司马贞《索隐述赞》Z001（后出评论）](../../sources/摘录/史记-卷038-宋微子世家.md#z001)**

> 【索隱述贊】殷有三仁，微箕紂親。一囚一去，不顧其身。頌美有客，書稱作賓。卒傳塚嗣，或敘彝倫。微仲之後，世載忠勤。穆亦能讓，實為知人。傷泓之役，有君無臣。偃號「桀宋」，天之棄殷。

**本卷说明：** 唐代司马贞对全卷的韵文总评。它回顾三仁、微仲、穆公、泓战与末宋，和本年灭国事实分层。

<!-- /sj044-cite-135 -->

<a id="sj046-cite-103"></a>

**[《史记·田敬仲完世家》P046](../../sources/摘录/史记-卷046-田敬仲完世家.md#p046)**

> 三十八年，伐宋。秦昭王怒曰：「吾愛宋與愛新城、陽晉同。韓聶與吾友也，而攻吾所愛，何也？」蘇代為齊謂秦王曰：「韓聶之攻宋，所以為王也。齊彊，輔之以宋，楚魏必恐，恐必西事秦，是王不煩一兵，不傷一士，無事而割安邑也，此韓聶之所禱於王也。」秦王曰：「吾患齊之難知。一從一衡，其說何也？」對曰：「天下國令齊可知乎？齊以攻宋，其知事秦以萬乘之國自輔，不西事秦則宋治不安。中國白頭游敖之士皆積智欲離齊秦之交，伏式結軼西馳者，未有一人言善齊者也，伏式結軼東馳者，未有一人言善秦者也。何則？皆不欲齊秦之合也。何晉楚之智而齊秦之愚也！晉楚合必議齊秦，齊秦合必圖晉楚，請以此決事。」秦王曰：「諾。」於是齊遂伐宋，宋王出亡，死於溫。齊南割楚之淮北，西侵三晉，欲以并周室，為天子。泗上諸侯鄒魯之君皆稱臣，諸侯恐懼。

**本卷说明：** 苏代用楚魏畏齐而亲秦劝秦容齐攻宋，秦可得安邑等属于说辞的利益推演；不把同年魏割安邑或后来诸侯破齐反写成已被说客精确预定。淮北、侵三晋、迫邹鲁是灭宋前后的扩张概述，非可逐日串成的单日行动。

<a id="sj005-236-note"></a>
<a id="sj005-236秦攻魏河内魏献安邑秦迁入新居民"></a>
#### sj005-236｜秦攻魏河内，魏献安邑，秦迁入新居民。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**“魏献安邑”与数十年前卫鞅曾使安邑降不同，不合并为一次终局占领。泾阳君封宛又见同年，前291公子市封宛已有互见，保留为封邑记录差异或重申，不另写第二人。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

#### 卷015｜魏交出安邑、河内

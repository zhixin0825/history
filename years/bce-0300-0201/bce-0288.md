<a id="event-1"></a>

1. **秦齐短暂称帝，一个多月后又去帝号。** 秦称西帝，齐称东帝，以更高名号相抗，随后恢复王号；吕礼来归秦，任鄙同年去世。 苏代从燕来劝齐王，先受号而不全面使用，观察诸侯是否接受秦；若天下厌秦，齐去号便可得人心。他又比较帝名与取宋的实际利益：两帝并立只会使秦受尊，随秦伐赵不如取宋，并以济西、淮北、陶、平陆牵制赵楚魏卫。名义尊秦而避免与秦争帝名，才便于齐利用空隙扩张。齐接受去号，至于诸侯都将服从、齐可成汤武之业，是说客的预期。 [[1]](#note-1)

<a id="sj015-0288-zhao-event"></a>

<a id="event-2"></a>

2. **秦军夺取赵国的一处城邑，年表称桂阳。** 《赵世家》主TXT写保阳，三家注本文写梗阳；与年表桂阳是否同一地，不能只凭近音便认定。 [[2]](#note-2)

<a id="sj043-dongshu-song-event"></a>

3. **董叔与魏国攻宋，赵又从魏取得河阳。** 本篇未说取得河阳一定是这次攻宋的分赃结果。 [[3]](#sj043-dongshu-song-note)

> 三十六年，王為東帝，秦昭王為西帝。蘇代自燕來，入齊，見於章華東門。齊王曰：「嘻，善，子來！秦使魏冉致帝，子以為何如？」對曰：「王之問臣也卒，而患之所從來微，願王受之而勿備稱也。秦稱之，天下安之，王乃稱之，無後也。且讓爭帝名，無傷也。秦稱之，天下惡之，王因勿稱，以收天下，此大資也。且天下立兩帝，王以天下為尊齊乎？尊秦乎？」王曰：「尊秦。」曰：「釋帝，天下愛齊乎？愛秦乎？」王曰：「愛齊而憎秦。」曰：「兩帝立約伐趙，孰與伐桀宋之利？」王曰：「伐桀宋利。」對曰：「夫約鈞，然與秦為帝而天下獨尊秦而輕齊，釋帝則天下愛齊而憎秦，伐趙不如伐桀宋之利，故願王明釋帝以收天下，倍約賓秦，無爭重，而王以其閒舉宋。夫有宋，衛之陽地危；有濟西，趙之阿東國危；有淮北，楚之東國危；有陶、平陸，梁門不開。釋帝而貸之以伐桀宋之事，國重而名尊，燕楚所以形服，天下莫敢不聽，此湯武之舉也。敬秦以為名，而後使天下憎之，此所謂以卑為尊者也。願王孰慮之。」於是齊去帝復為王，秦亦去帝位。

## 归年与考证

<a id="sj005-234-note"></a>
<a id="sj005-234秦王与齐王短暂称帝随后都去掉帝号"></a>
#### sj005-234｜秦王与齐王短暂称帝，随后都去掉帝号。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**不与秦王政前221正式用皇帝号相混。本纪把齐破宋接在十九年，实际上与此帝号事项相隔，宋亡另归前286。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0288-qin-note"></a>
<a id="卷015秦栏前288年"></a>
#### 卷015·秦栏｜前288年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0288)：“十九。十月為帝，十二月復為王。任鄙卒。”

称帝、复王与任鄙卒全归旧第一条。秦十月、十二月为原历月份，不换算公历。帝号不是前221“皇帝”制度已经统一实施。 [对应正文](#event-1)

<a id="sj015-0288-zhao-note"></a>
<a id="卷015赵栏前288年"></a>
#### 卷015·赵栏｜前288年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0288)：“十一。秦拔我桂陽。”

表作桂阳，[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-18f6f2fb694ba1)作杜阳；正文保留桂阳古名并在注记录异文，不凭“阳”字将两地无条件判同，也不移到汉代桂阳郡。

<a id="sj015-0288-qi-note"></a>
<a id="卷015齐栏前288年"></a>
#### 卷015·齐栏｜前288年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0288)：“三十六。為東帝二月，復為王。”

齐称东帝、复王归旧第一条；本表“二月”指称帝持续时间，而[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-4c20771dd8a353)作“二日”，两者有异文，正文只说短暂，不确定成整两个月或仅两天。 [对应正文](#event-1)

## 归年与考证

<a id="sj005-234-note"></a>
<a id="sj005-234秦王与齐王短暂称帝随后都去掉帝号"></a>
#### sj005-234｜秦王与齐王短暂称帝，随后都去掉帝号。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**不与秦王政前221正式用皇帝号相混。本纪把齐破宋接在十九年，实际上与此帝号事项相隔，宋亡另归前286。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0288-qin-note"></a>
<a id="卷015秦栏前288年"></a>
#### 卷015·秦栏｜前288年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0288)：“十九。十月為帝，十二月復為王。任鄙卒。”

称帝、复王与任鄙卒全归旧第一条。秦十月、十二月为原历月份，不换算公历。帝号不是前221“皇帝”制度已经统一实施。 [对应正文](#event-1)

<a id="sj015-0288-zhao-note"></a>
<a id="卷015赵栏前288年"></a>
#### 卷015·赵栏｜前288年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0288)：“十一。秦拔我桂陽。”

表作桂阳，[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-18f6f2fb694ba1)作杜阳；正文保留桂阳古名并在注记录异文，不凭“阳”字将两地无条件判同，也不移到汉代桂阳郡。

<a id="sj015-0288-qi-note"></a>
<a id="卷015齐栏前288年"></a>
#### 卷015·齐栏｜前288年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0288)：“三十六。為東帝二月，復為王。”

齐称东帝、复王归旧第一条；本表“二月”指称帝持续时间，而[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-4c20771dd8a353)作“二日”，两者有异文，正文只说短暂，不确定成整两个月或仅两天。 [对应正文](#event-1)

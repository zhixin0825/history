# 公元前290年｜魏韩割地予秦，魏重用芒卯

## 本年纪事

<a id="event-1"></a>

1. **城阳君和东周君来朝，秦王前往宜阳。** 秦继续接纳东方小国、封君的来朝。本纪同年还有垣、蒲阪、皮氏相关土地调整，说明占有与交换仍在进行。 [原文与说明](#sj005-232-note)

<a id="sj015-0290-qin-event"></a>

**魏向秦交出河东一片土地，史书记作四百里；韩也把武遂一带二百里土地交给秦。**秦在战争之外继续通过割地扩大控制。 [原文与说明](#sj015-0290-qin-note)

<a id="sj015-0290-wei-event"></a>

**魏国开始重用善于谋划的芒卯。**现存年表没有留下使他受重视的具体计策。 [原文与说明](#sj015-0290-wei-note)

## 本年相关史料

<a id="sj005-232-note"></a>
### sj005-232｜城阳君和东周君来朝，秦王前往宜阳。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**“秦以垣为蒲阪、皮氏”字句难以仅凭本段定清行政或换地关系，保留原句，不画成确定的县界改划图。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0290-qin-note"></a>
### 卷015·秦栏｜前290年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0290)：“十七。魏入河東四百里。”

魏入河东四百里与韩交武遂二百里，并见[《通鉴》卷四](https://zh.wikisource.org/wiki/資治通鑑/卷004)。里数按史书保留，不平方换算成“面积四百里”；更不能等同魏全部河东故地本年一次交完。

<a id="sj015-0290-wei-note"></a>
### 卷015·魏栏｜前290年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0290)：“六。芒卯以詐見重。”

芒卯因计谋受重用，原格不写具体诈术。《魏世家》相关说辞仍须另核，不把一条任用简记扩写成已定战功或奸诈品性。

<a id="sj015-0290-han-note"></a>
### 卷015·韩栏｜前290年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0290)：“六。與秦武遂地方二百里。”

武遂地方二百里与[魏韩割地](#sj015-0290-qin-event)合并；“与秦”是交付秦国，不能反译为秦归还韩国。

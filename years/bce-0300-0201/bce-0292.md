## 归年与考证

<a id="sj005-230-note"></a>
<a id="sj005-230秦取魏垣又归还另攻楚宛"></a>
#### sj005-230｜秦取魏垣又归还，另攻楚宛。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0292-qin-note"></a>
<a id="卷015秦栏前292年"></a>
#### 卷015·秦栏｜前292年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0292)：“十五。魏冉免相。”

魏冉免相从本表和[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-012f8f67fbf583)前292年，后者记托病免、烛寿接任。旧前291页据《秦本纪》相位条已改作异年互见；前291复相依《通鉴》，避免连续两年都无区别写同一次免相。

<a id="sj015-0292-chu-note"></a>
<a id="卷015楚栏前292年"></a>
#### 卷015·楚栏｜前292年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0292)：“七。迎婦秦。”

楚顷襄王从秦迎娶女子，[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-9dd6d578833cb2)同年记婚事；不可把联姻解释成怀王被扣与死亡已被楚人遗忘，更不能据司马光评论补出具体婚约。

<a id="sj015-0292-wan-variant"></a>
<a id="夺宛的国属与年次"></a>
#### 夺宛的国属与年次

旧页按《秦本纪》昭王十五年“攻楚，取宛”写前292年攻楚宛；卷015韩栏及[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-3cbfd2077acd33)却以前291年秦取韩宛相接。正文暂从后两种编年材料，归[前291年](bce-0291.md#sj015-0291-han-event)，本处完整保留前292／楚宛说，不以删去异文换取表面一致。

1. **白起在伊阙大败韩魏，秦又借胜势胁楚。** 秦取五城，俘公孙喜，记斩首二十四万，白起爵位继续升高。秦随即致书楚王，威胁率诸侯伐楚、要求楚整军决战；顷襄王忧惧，转谋与秦恢复和平。 [[1]](#note-1)

## 本年相关史料

<a id="note-1"></a>

### 1. 白起在伊阙击败韩魏联军，俘公孙喜

[返回正文第1条](#event-1)

<a id="sj073-cite-001"></a>

**[《史记·白起王翦列传》P000](../../拆分史书/史记/卷073.md#p000)**

> 攻韓、魏於伊闕，斬首二十四萬

**本卷归年说明：** 伊阙白起统军与魏冉荐白起相参，二十四万是《史记》所载，不同时计作另一场同年战争。

<!-- /sj073-cite-001 -->

<a id="sj072-cite-004"></a>

**[《史记·穰侯列传》P003](../../拆分史书/史记/卷072.md#p003)**

> 魏冉舉白起，使代向壽將而攻韓、魏，敗之伊闕，斬首二十四萬，虜魏將公孫喜。

**本卷归年说明：** 魏冉为荐举用将之人，伊阙前线统军与战果主要属白起，二十四万是本传数字。

<!-- /sj072-cite-004 -->

**[《史记·秦本纪》昭王十四年（P066节录）](../../拆分史书/史记/卷005.md#p066)**

> 十四年，左更白起攻韓、魏於伊闕，斬首二十四萬，虜公孫喜，拔五城。

[史料说明](#sj005-229-note)

<a id="sj040-cite-188"></a>

**[《史记·楚世家》P087](../../拆分史书/史记/卷040.md#p087)**

> 六年，秦使白起伐韓於伊闕，大勝，斬首二十四萬。秦乃遺楚王書曰：「楚倍秦，秦且率諸侯伐楚，爭一旦之命。願王之飭士卒，得一樂戰。」楚頃襄王患之，乃謀復與秦平。

**本卷说明：** 秦以伊阙胜韩魏之势威胁楚，非在伊阙又败楚军。

<!-- /sj040-cite-188 -->

<a id="sj045-cite-070"></a>

**[《史记·韩世家》P029](../../拆分史书/史记/卷045.md#p029)**

> 釐王三年，使公孫喜率周、魏攻秦。秦敗我二十四萬，虜喜伊闕。

**本卷说明：** 本篇将周、魏并列为公孙喜所率力量，既有秦韩魏主事继续保存；二十四万是原书战果数。

<!-- /sj045-cite-070 -->

<a id="sj044-cite-129"></a>

**[《史记·魏世家》P051](../../拆分史书/史记/卷044.md#p051)**

> 三年，佐韓攻秦，秦將白起敗我軍伊闕二十四萬。

**本卷说明：** 二十四万是韩魏联军败军的传世报数，不说成只有魏军阵亡二十四万。

## 归年与考证

<a id="sj005-229-note"></a>
<a id="sj005-229白起在伊阙击败韩魏联军俘公孙喜"></a>
#### sj005-229｜白起在伊阙击败韩魏联军，俘公孙喜。

[卷005 P066](../../拆分史书/史记/卷005.md#p066)。

**说明：**昭王十四年与白起列传相合。二十四万为传世战果，不宣称已经独立人口统计确认。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../拆分史书/史记/卷005.md#kao-c691f26620)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0293-qin-note"></a>
<a id="卷015秦栏前293年"></a>
#### 卷015·秦栏｜前293年

[本年原格](../../拆分史书/史记/卷015.md#y0293)：“十四。白起擊伊闕，斬首二十四萬。”

伊阙、二十四万归旧第一条。[《通鉴》卷四](../../拆分史书/资治通鉴/卷004.md#text)记韩公孙喜与魏军交战、白起获胜；首级数是史书记数，不作现代人口学核定。 [对应正文](#event-1)

<a id="sj015-0293-wei-note"></a>
<a id="卷015魏栏前293年"></a>
#### 卷015·魏栏｜前293年

[本年原格](../../拆分史书/史记/卷015.md#y0293)：“三。佐韓擊秦，秦敗我兵伊闕。”

魏援韩而被秦击败，与秦韩两栏同一[伊阙之战](#event-1)。

<a id="sj015-0293-han-note"></a>
<a id="卷015韩栏前293年"></a>
#### 卷015·韩栏｜前293年

[本年原格](../../拆分史书/史记/卷015.md#y0293)：“三。秦敗我伊闕，斬首二十四萬，虜將喜。”

喜即公孙喜，俘将及二十四万与[伊阙之战](#event-1)合并；不因两栏重复数字而算四十八万。

1. **白起在伊阙击败韩魏联军，俘公孙喜。** 秦取五城，本纪报斩首二十四万。这场大胜使秦对韩魏的压力显著增加，白起也继续升至更高爵位。 [[1]](#note-1)

## 归年与考证

<a id="sj005-229-note"></a>
<a id="sj005-229白起在伊阙击败韩魏联军俘公孙喜"></a>
#### sj005-229｜白起在伊阙击败韩魏联军，俘公孙喜。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**昭王十四年与白起列传相合。二十四万为传世战果，不宣称已经独立人口统计确认。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0293-qin-note"></a>
<a id="卷015秦栏前293年"></a>
#### 卷015·秦栏｜前293年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0293)：“十四。白起擊伊闕，斬首二十四萬。”

伊阙、二十四万归旧第一条。[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-141b0db61b6817)记韩公孙喜与魏军交战、白起获胜；首级数是史书记数，不作现代人口学核定。 [对应正文](#event-1)

<a id="sj015-0293-wei-note"></a>
<a id="卷015魏栏前293年"></a>
#### 卷015·魏栏｜前293年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0293)：“三。佐韓擊秦，秦敗我兵伊闕。”

魏援韩而被秦击败，与秦韩两栏同一[伊阙之战](#event-1)。

<a id="sj015-0293-han-note"></a>
<a id="卷015韩栏前293年"></a>
#### 卷015·韩栏｜前293年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0293)：“三。秦敗我伊闕，斬首二十四萬，虜將喜。”

喜即公孙喜，俘将及二十四万与[伊阙之战](#event-1)合并；不因两栏重复数字而算四十八万。

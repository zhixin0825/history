1. **向寿与白起分头攻韩，任鄙出守汉中。** 向寿取武始，白起攻新城；五大夫礼离秦奔魏，任鄙出任汉中守。同一年度里，用兵、人员流动与新郡管理同时展开。 [[1]](#note-1)

2. **魏军与秦军交战失利，战事在解一带。** [[2]](#note-2)

<a id="sj015-0294-qi-event"></a>

3. **齐国发生田甲劫持国君的变乱，孟尝君田文随后离开齐廷。** 现有短记不足以说明田文是否参与劫王。 [[3]](#note-3)

4. **赵把鄚、易给燕。** 惠文王五年的疆土交涉在主父死后记述，不能因此把惠文王元年重新从沙丘以后计算。 [[4]](#sj043-mo-yi-note)

## 归年与考证

<a id="sj005-228-note"></a>
<a id="sj005-228向寿与白起分头攻韩任鄙出守汉中"></a>
#### sj005-228｜向寿与白起分头攻韩，任鄙出守汉中。

[卷005 P066](../../sources/摘录/史记-卷005-秦本纪.md#p066)。

**说明：**本纪以白起为左更，白起列传对初任爵序更细，保留差别，不因官称异文造出两位白起。五大夫礼原名未详，不擅自改成别人的字。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0294-qin-note"></a>
<a id="卷015秦栏前294年"></a>
#### 卷015·秦栏｜前294年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0294)：“十三。任鄙為漢中守。”

任鄙为汉中守合入原有第一条；前288任鄙卒是后事，不提前到本年。 [对应正文](#event-1)

<a id="sj015-0294-wei-note"></a>
<a id="卷015魏栏前294年"></a>
#### 卷015·魏栏｜前294年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0294)：“二。與秦戰，我不利。”

魏败于秦按本格及[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-6e19c5938a06e8)补入，后者系地于解。与秦同年攻韩的武始、新城分开，不把不同对象战果混写。

<a id="sj015-0294-qi-note"></a>
<a id="卷015齐栏前294年"></a>
#### 卷015·齐栏｜前294年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0294)：“三十。田甲劫王，相薛文走。”

田甲劫王、薛文出走按本格保存；薛文即孟尝君田文。短记未给完整政变因果，不写成田文必是田甲同党，也不将此出走与前298离秦混为一次。

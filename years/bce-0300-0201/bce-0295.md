# 公元前295年｜赵国沙丘之变，魏韩新王元年

## 本年纪事

<a id="event-1"></a>

1. **楼缓被免，魏冉成为秦相，秦给楚粮食。** 魏冉即穰侯，后来在秦廷长期掌权。秦给楚五万石粟，与前一阶段战争和扣王并列，显示两国关系仍可转入新的安排。 [原文与说明](#sj005-227-note)

<a id="sj015-0295-wei-event"></a>

**魏国进入昭王元年，秦军在尉错率领下进攻魏国襄城。**新君继承王位时，对秦的军事压力并未减轻。 [原文与说明](#sj015-0295-wei-note)

<a id="sj015-0295-han-event"></a>

**韩国进入釐王咎的元年。**数年前被立为太子的咎，已在襄王去世后承接王位。 [原文与说明](#sj015-0295-han-note)

<a id="sj015-0295-zhao-event"></a>

**赵国发生沙丘之变。**公子章和田不礼试图夺权，肥义遇害。公子成、李兑起兵平乱，公子章败走主父宫。成、兑围宫，杀死公子章后，担心解除包围会被追究，便继续封锁。主父被困三个多月，最终饿死。赵惠文王仍在位，实际政务更多落入成、兑手中。 [原文与说明](#sj015-0295-zhao-note)

## 本年相关史料

<a id="sj005-227-note"></a>
### sj005-227｜楼缓被免，魏冉成为秦相，秦给楚粮食。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**五万石是原单位，不换算成已确认吨数。魏冉亲属与封邑已在其他段出现者按同人接续，不多造一个“侯冉”。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0295-qin-note"></a>
### 卷015·秦栏｜前295年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0295)：“十二。樓緩免。穰侯魏冉為丞相。”

楼缓免、魏冉任相与旧第一条合并；本格能明确本年相位更替，不以此宣称前300“魏冉为相”已无争议解决。 [对应正文](#event-1)

<a id="sj015-0295-wei-note"></a>
### 卷015·魏栏｜前295年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0295)：“魏昭王元年。秦尉錯來擊我襄。”

魏昭王元年承接[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-ff7e3ef529ee93)前296襄王卒、子遫立；秦尉错进攻襄城另补。尉错与客卿司马错的身份、官号不凭一个“错”字就作完全确定的合并。

<a id="sj015-0295-han-note"></a>
### 卷015·韩栏｜前295年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0295)：“韓釐王咎元年”

韩釐王咎元年承接[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-c189cdd4526aa3)前296韩襄王卒；咎在[前299立太子](bce-0299.md#sj015-0299-wei-event)已出现，本年不新造一次受立太子。

<a id="sj015-0295-zhao-note"></a>
### 卷015·赵栏｜前295年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0295)：“四。圍殺主父。與齊、燕共滅中山。”

一格两项：“围杀主父”按[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-dbee97d589b573)及[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-81a98c234a4913)展开为沙丘之变与围困后饿死；“与齐燕共灭中山”与旧[前296中山终局](bce-0296.md#event-3)异年，不写成灭而复灭，也不虚构已确证的两年分阶段战事。

<a id="sj015-0295-chu-note"></a>
### 卷015·楚栏｜前295年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0295)：“四。魯文公元年。”

“鲁文公”在[卷015三家注本](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7015.md#ref-bd89f30b64c8b9)注有“湣”异写，是鲁君称名及旧年链问题，不能当成春秋鲁文公重生。[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-b3c925d7465190)校刊本将鲁平公终局移前303，与此格前295元年不合。本页保留鲁文／湣公元年异说，不从楚栏另造楚国新君，也不强定一次前295的鲁君交替。

<a id="sj015-0295-qi-note"></a>
### 卷015·齐栏｜前295年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0295)：“二十九。佐趙滅中山。”

齐助赵灭中山与赵栏同一异年问题，主线沿[前296中山终局](bce-0296.md#event-3)，本页记录年表前295齐方互见。原表未说明这一年仅仅援军或善后，不以“联盟后续”强行调和。

1. **楼缓被免，魏冉成为秦相，秦给楚粮食。** 魏冉即穰侯，后来在秦廷长期掌权。秦给楚五万石粟，与前一阶段战争和扣王并列，显示两国关系仍可转入新的安排。 [[1]](#note-1)

<a id="sj015-0295-wei-event"></a>

<a id="event-2"></a>

2. **魏国进入昭王元年，秦军在尉错率领下进攻魏国襄城。** 新君继承王位时，对秦的军事压力并未减轻。 [[2]](#note-2)

<a id="sj015-0295-han-event"></a>

<a id="event-3"></a>

3. **韩国进入釐王咎的元年。** 数年前被立为太子的咎，已在襄王去世后承接王位。 [[3]](#note-3)

<a id="sj015-0295-zhao-event"></a>

<a id="event-4"></a>

4. **赵国发生沙丘之变，平乱者继续围困主父，终于酿成父子俱死。** 事变以前，李兑已劝肥义：公子章壮健而骄、党多欲大，田不礼残忍好杀，两人只顾利益不顾后患，必会暗谋冒险；肥义任重权大将首受其祸，不如称病，把政务交公子成，免作怨祸所集。肥义答，主父托王时命他不改法度、心虑，终生坚守，他已经再拜受命、书而存之；如今怕田不礼便弃命，是变节负托。贞忠要在患难时显露，宁保前言而不能保身，感谢李兑忠告却不能退。李兑泣称或许今年便是最后相见，随后屡见公子成备变。肥义又告诉信期，章与田表善实恶，不守父子君臣之分，内恃主父而外暴，伪令擅权并不难，自己忧得不寐忘食；今后凡召王者，必须先见肥义，由他先入挡险，无故后王才入，信期赞同。惠文王四年，主父旁观群臣朝王，见长子章郁郁向北称臣于弟，心怜，想分赵、令章在代为王，未决而止。主父与王游沙丘，分住两宫，章、田不礼率党羽作乱，假托主父令召王；肥义先入被杀，高信护王迎战。公子成、李兑从国都来，起四邑兵平乱。章败后逃入主父宫，主父开门容纳，成、兑遂围宫，杀章、田不礼及乱党，王室得定。公子成为相，号安平君，李兑为司寇；两人却怕因围主父而遭族诛，继续封锁，告宫人后出者灭族，迫侍从悉出。主父欲出不得，又断粮，捕雀雏充饥，三月有余饿死；成、兑确知他死，才发丧告诸侯。惠文王仍在位，成、兑专政。篇中又把乱源归于先立章、宠吴娃而改立何、后来怜章欲两王却犹豫不决，这一后妃与继嗣评断另标异说。 [[4]](#note-4)

**[《史记·赵世家》P075](../../sources/摘录/史记-卷043-赵世家.md#p075)**

> 李兌謂肥義曰：「公子章彊壯而志驕，黨眾而欲大，殆有私乎？田不禮之為人也，忍殺而驕。二人相得，必有謀陰賊起，一出身徼幸。夫小人有欲，輕慮淺謀，徒見其利而不顧其害，同類相推，俱入禍門。以吾觀之，必不久矣。子任重而勢大，亂之所始，禍之所集也，子必先患。仁者愛萬物而智者備禍於未形，不仁不智，何以為國？子奚不稱疾毋出，傳政於公子成？毋為怨府，毋為禍梯。」肥義曰：「不可，昔者主父以王屬義也，曰：『毋變而度，毋異而慮，堅守一心，以歿而世。』義再拜受命而籍之。今畏不禮之難而忘吾籍，變孰大焉。進受嚴命，退而不全，負孰甚焉。變負之臣，不容於刑。諺曰『死者復生，生者不愧』。吾言已在前矣，吾欲全吾言，安得全吾身！且夫貞臣也難至而節見，忠臣也累至而行明。子則有賜而忠我矣，雖然，吾有語在前者也，終不敢失。」李兌曰：「諾，子勉之矣！吾見子已今年耳。」涕泣而出。李兌數見公子成，以備田不禮之事。

**本卷说明：** 两段预警在沙丘以前，具体日期不明，作为本事前因。

**本卷说明：** 两段预警在沙丘以前，具体日期不明，作为本事前因。

> 主父及王游沙丘，異宮，公子章即以其徒與田不禮作亂，詐以主父令召王。肥義先入，殺之。高信即與王戰。公子成與李兌自國至，乃起四邑之兵入距難，殺公子章及田不禮，滅其黨賊而定王室。公子成為相，號安平君，李兌為司寇。公子章之敗，往走主父，主主開之，成、兌因圍主父宮。公子章死，公子成、李兌謀曰：「以章故圍主父，即解兵，吾屬夷矣。」乃遂圍主父。令宮中人「後出者夷」，宮中人悉出。主父欲出不得，又不得食，探爵鷇而食之，三月餘而餓死沙丘宮。主父定死，乃發喪赴諸侯。

**本卷说明：** 高信与信期名写有异，暂不强定；章败走主父是倒叙，不杀章两次。

韩釐王咎元年承接[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-c189cdd4526aa3)前296韩襄王卒；咎在[前299立太子](bce-0299.md#sj015-0299-wei-event)已出现，本年不新造一次受立太子。

<a id="sj015-0295-zhao-note"></a>
<a id="卷015赵栏前295年"></a>
#### 卷015·赵栏｜前295年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0295)：“四。圍殺主父。與齊、燕共滅中山。”

一格两项：“围杀主父”按[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-dbee97d589b573)及[《通鉴》卷四](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7004.md#ref-81a98c234a4913)展开为沙丘之变与围困后饿死；“与齐燕共灭中山”与旧[前296中山终局](bce-0296.md#event-3)异年，不写成灭而复灭，也不虚构已确证的两年分阶段战事。

<a id="sj015-0295-chu-note"></a>
<a id="卷015楚栏前295年"></a>
#### 卷015·楚栏｜前295年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0295)：“四。魯文公元年。”

“鲁文公”在[卷015三家注本](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7015.md#ref-bd89f30b64c8b9)注有“湣”异写，是鲁君称名及旧年链问题，不能当成春秋鲁文公重生。[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-b3c925d7465190)校刊本将鲁平公终局移前303，与此格前295元年不合。本页保留鲁文／湣公元年异说，不从楚栏另造楚国新君，也不强定一次前295的鲁君交替。

<a id="sj015-0295-qi-note"></a>
<a id="卷015齐栏前295年"></a>

齐助赵灭中山与赵栏同一异年问题，主线沿[前296中山终局](bce-0296.md#event-3)，本页记录年表前295齐方互见。原表未说明这一年仅仅援军或善后，不以“联盟后续”强行调和。

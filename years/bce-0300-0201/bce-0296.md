# 公元前296年｜联军进至盐氏，秦以土地同韩魏求和

## 本年纪事

<a id="event-1"></a>

1. **联军进至盐氏，秦以土地同韩魏求和。** 秦把河北相关土地及封陵用于和议，联军随后撤走；本纪又列彗星见。 [原文与说明](#sj005-224-note)

<a id="event-2"></a>

2. **楚怀王死于秦，遗体归楚安葬。** 他始终未能通过出逃回国。死亡、归葬同秦与各国讲和的时局相接，但不是因为同年列记便能确定二者直接交换。 [原文与说明](#sj005-225-note)

<a id="event-3"></a>

3. **赵国完成对中山的兼并，后续结局在不同年表中有差别。** 中山在多年的攻击后覆亡，其君逃出。此事作为秦本纪附记的东方局势，不能跟着昭王八年便提前到前299。 [原文与说明](#sj005-226-note)

<a id="sj015-0296-wei-han-accession"></a>

**魏襄王和韩襄王先后去世。**魏由儿子遫接位，称昭王；韩由太子咎接位，称釐王，两国都在次年起算新王元年。 [原文与说明](#sj015-0296-wei-han-accession-note)

## 本年相关史料

<a id="sj005-224-note"></a>
### sj005-224｜联军进至盐氏，秦以土地同韩魏求和。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**原句说“五国”却列齐韩魏赵宋中山六名，保存数目矛盾，不硬造精确五国名单。反攻从前298等阶段延续，本年是盐氏与归地的结果。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj005-226-note"></a>
### sj005-226｜赵国完成对中山的兼并，后续结局在不同年表中有差别。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**本纪仅称赵“破”中山，年表前295记与齐燕共灭；《赵世家》以惠文王三年灭中山，即前296，暂依后者，前295年表的齐燕合攻视为异年互见，不据两条不同系年虚构已确证的先灭国、后联盟两阶段。其君后死齐为未独立纪年的结局，不把出亡和死齐都硬定本年。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0296-qin-note"></a>
### 卷015·秦栏｜前296年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0296)：“十一。彗星見。復與魏封陵。”

彗星、归魏封陵接旧第一条；秦韩和议同处本轮联军退兵过程，不把封陵加在前298首次进军之日。 [对应正文](#event-1)

<a id="sj015-0296-han-note"></a>
### 卷015·韩栏｜前296年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0296)：“十六。（與齊魏擊秦）秦與我武遂和。”

与齐魏击秦及秦归武遂合入旧第一条；原格括号表示该见证的附记形式，来源照存。与前303失武遂相接，土地往返不是记录自相矛盾。 [对应正文](#event-1)

<a id="sj015-0296-chu-note"></a>
### 卷015·楚栏｜前296年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0296)：“三。懷王卒于秦，來歸葬。”

怀王死秦、归楚葬与旧第二条合并；其在秦扣留、出逃、死亡是前299、297、296不同阶段。 [对应正文](#event-2)

<a id="sj015-0296-wei-han-accession-note"></a>
### 衔接说明｜魏襄王和韩襄王先后去世

[《通鉴》卷四](https://zh.wikisource.org/wiki/資治通鑑/卷004)赧王十九年，卷015前295魏昭王、韩釐王元年互相衔接。

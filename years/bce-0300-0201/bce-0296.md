# 公元前296年｜联军进至盐氏，秦以土地同韩魏求和

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **联军进至盐氏，秦以土地同韩魏求和。** 秦把河北相关土地及封陵用于和议，联军随后撤走；本纪又列彗星见。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚怀王死于秦，遗体归楚安葬。** 他始终未能通过出逃回国。死亡、归葬同秦与各国讲和的时局相接，但不是因为同年列记便能确定二者直接交换。 [[2]](#note-2)

<a id="event-3"></a>

3. **赵国完成对中山的兼并，后续结局在不同年表中有差别。** 中山在多年的攻击后覆亡，其君逃出。此事作为秦本纪附记的东方局势，不能跟着昭王八年便提前到前299。 [[3]](#note-3)

<a id="sj015-0296-wei-han-accession"></a>

<a id="event-4"></a>

4. **魏襄王和韩襄王先后去世。** 魏由儿子遫接位，称昭王；韩由太子咎接位，称釐王，两国都在次年起算新王元年。 [[4]](#note-4)

## 本年相关史料

<a id="note-1"></a>

### 1. 联军进至盐氏，秦以土地同韩魏求和

[返回正文第1条](#event-1)

**[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)**

> 昭襄王元年，嚴君疾為相。甘茂出之魏。二年，彗星見。庶長壯與大臣、諸侯、公子為逆，皆誅，及惠文后皆不得良死。悼武王后出歸魏。三年，王冠。與楚王會黃棘，與楚上庸。四年，取蒲阪。彗星見。五年，魏王來朝應亭，復與魏蒲阪。六年，蜀侯煇反，司馬錯定蜀。庶長奐伐楚，斬首二萬。涇陽君質於齊。日食，晝晦。七年，拔新城。摢裏子卒。八年，使將軍羋戎攻楚，取新市。齊使章子，魏使公孫喜，韓使暴鳶共攻楚方城，取唐眛。趙破中山，其君亡，竟死齊。魏公子勁、韓公子長為諸侯。九年，孟嘗君薛文來相秦。奐攻楚，取八城，殺其將景快。十年，楚懷王入朝秦，秦留之。薛文以金受免。樓緩為丞相。十一年，齊、韓、魏、趙、宋、中山五國共攻秦，至鹽氏而還。秦與韓、魏河北及封陵以和。彗星見。楚懷王走之趙，趙不受，還之秦，即死，歸葬。十二年，樓緩免，穰侯魏冉為相。予楚粟五萬石。

## 归年与考证

<a id="sj005-224-note"></a>
<a id="sj005-224联军进至盐氏秦以土地同韩魏求和"></a>
#### sj005-224｜联军进至盐氏，秦以土地同韩魏求和。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**原句说“五国”却列齐韩魏赵宋中山六名，保存数目矛盾，不硬造精确五国名单。反攻从前298等阶段延续，本年是盐氏与归地的结果。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj005-226-note"></a>
<a id="sj005-226赵国完成对中山的兼并后续结局在不同年表中有差别"></a>
#### sj005-226｜赵国完成对中山的兼并，后续结局在不同年表中有差别。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**本纪仅称赵“破”中山，年表前295记与齐燕共灭；《赵世家》以惠文王三年灭中山，即前296，暂依后者，前295年表的齐燕合攻视为异年互见，不据两条不同系年虚构已确证的先灭国、后联盟两阶段。其君后死齐为未独立纪年的结局，不把出亡和死齐都硬定本年。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

#### 卷015·秦栏｜前296年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0296)：“十一。彗星見。復與魏封陵。”

彗星、归魏封陵接旧第一条；秦韩和议同处本轮联军退兵过程，不把封陵加在前298首次进军之日。 [对应正文](#event-1)

<a id="卷015韩栏前296年"></a>
#### 卷015·韩栏｜前296年

与齐魏击秦及秦归武遂合入旧第一条；原格括号表示该见证的附记形式，来源照存。与前303失武遂相接，土地往返不是记录自相矛盾。 [对应正文](#event-1)

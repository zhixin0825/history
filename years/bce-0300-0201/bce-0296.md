<a id="本年纪事"></a>
<a id="event-1"></a>

1. **联军进至盐氏，秦以土地同韩魏求和。** 联军进至盐氏，秦以河北相关土地及封陵向韩、魏求和，联军随后撤兵。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚怀王死于秦，秦送其丧回楚，楚秦断交。** 楚人像失去亲属一样悲悼，诸侯也因扣王至死之事认为秦不义。怀王死亡归本年，前299楚臣假报死讯只是迎太子的计策。 [[2]](#note-2)

<a id="event-3"></a>

3. **赵国完成对中山的兼并，后续结局在不同年表中有差别。** 中山在多年的攻击后覆亡，其君逃出。此事作为秦本纪附记的东方局势，不能跟着昭王八年便提前到前299。 赵经营灵寿，北境连贯，通代道路畅通。主父返国行赏、大赦，让百姓聚饮五日，封长子章为代安阳君，以田不礼为相。章骄奢、不服弟弟何为王，成为次年内乱的隐患。 《赵世家》另述赵将中山王迁往肤施，与其君逃出的记法分别标明，不能自行补成必然先逃再被迁的经过。 齐篇另记齐曾协助赵灭中山，具体出兵和行动未详，不据这一短句补出齐军独立攻城名单。 [[3]](#note-3)

<a id="sj015-0296-wei-han-accession"></a>

<a id="event-4"></a>

4. **魏襄王和韩襄王先后去世。** 魏由儿子遫接位，称昭王；韩由太子咎接位，称釐王，两国都在次年起算新王元年。 [[4]](#note-4)

#### sj005-226｜赵国完成对中山的兼并，后续结局在不同年表中有差别。

[卷005 P065](../../拆分史书/史记/卷005.md#p065)。

**说明：**本纪仅称赵“破”中山，年表前295记与齐燕共灭；《赵世家》以惠文王三年灭中山，即前296，暂依后者，前295年表的齐燕合攻视为异年互见，不据两条不同系年虚构已确证的先灭国、后联盟两阶段。其君后死齐为未独立纪年的结局，不把出亡和死齐都硬定本年。

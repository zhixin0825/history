# 公元前298年｜三国合攻函谷，楚赵开始新王元年

## 本年纪事

<a id="event-1"></a>

1. **田文离开秦国，楼缓出任丞相。** 秦相位的变化与多国关系相连。田文回到齐国后担任齐相，并非一直留秦到楚怀王死后才返齐。 [原文与说明](#sj005-222-note)

<a id="sj015-0298-wei-event"></a>

**齐、魏、韩联合进攻秦国，战线抵达函谷关。**这轮攻势延续数年，最终在前296年的和议中出现归还土地的结果。 [原文与说明](#sj015-0298-wei-note)

<a id="sj015-0298-zhao-event"></a>

**赵国进入惠文王元年，公子胜受封为平原君，并担任辅政职务。**父亲武灵王虽已传位，仍以“主父”的身份活动，赵国并非新王一人独掌所有事务。 [原文与说明](#sj015-0298-zhao-note)

<a id="sj015-0298-chu-event"></a>

**楚国在顷襄王横统治下开始新王元年，怀王仍被留在秦国。**秦军越过武关攻楚，取得十六座城，楚并未因另立国君而摆脱军事危机。 [原文与说明](#sj015-0298-chu-note)

## 本年相关史料

<a id="sj005-222-note"></a>
### sj005-222｜田文离开秦国，楼缓出任丞相。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**与年表田文前298返齐相接；楼缓在本纪同段，任相暂置此阶段，不借本纪十年重建田文第二次免相。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0298-wei-note"></a>
### 卷015·魏栏｜前298年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0298)：“二十一。與齊、韓共擊秦于函谷。河、渭絕一日。”

与韩齐共攻函谷归同一联军条；河、渭绝一日另作史书观察记载，不据一句证明黄河与渭河全流域同时永久断流或把它作为战争原因。

<a id="sj015-0298-han-note"></a>
### 卷015·韩栏｜前298年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0298)：“十四。與齊、魏共擊秦。”

与齐魏击秦合入[函谷联军](#sj015-0298-wei-event)，不重复计一支独立韩国战役。

<a id="sj015-0298-zhao-note"></a>
### 卷015·赵栏｜前298年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0298)：“趙惠文王元年。以公子勝為相，封平原君。”

惠文王元年承接[前299传位](bce-0299.md#sj015-0299-zhao-accession)。公子胜为武灵王之子、惠文王之弟，封平原君及任相据表；当时肥义亦辅王，不能据单一“相”字抹去其他官员。[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-1f9289a60a3593)本年也载封平原君。

<a id="sj015-0298-chu-note"></a>
### 卷015·楚栏｜前298年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0298)：“楚頃襄王元年。秦取我十六城”

顷襄王元年与前299迎立相接。秦取十六城据表及[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-4785cbaf18fd00)，后者解释为秦得知楚已有新王而进攻；“元年”不意味着怀王已死，他此时仍在秦。

<a id="sj015-0298-qi-note"></a>
### 卷015·齐栏｜前298年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0298)：“二十六。與魏、韓共擊秦。孟嘗君歸相齊。”

共同攻秦接[函谷联军](#sj015-0298-wei-event)，孟尝君归齐任相与原页离秦接续；不是从秦死亡后重新出现。正文补明回齐任相，鸡鸣狗盗故事另待相应列传完整处理。

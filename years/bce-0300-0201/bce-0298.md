<a id="本年纪事"></a>
<a id="event-1"></a>

1. **田文离开秦国，楼缓出任丞相。** 秦相位的变化与多国关系相连。田文回到齐国后担任齐相，并非一直留秦到楚怀王死后才返齐。 [[1]](#note-1)

<a id="sj015-0298-wei-event"></a>

<a id="event-2"></a>

2. **齐、魏、韩联合进攻秦国，战线抵达函谷关。** 这轮攻势延续数年，最终在前296年的和议中出现归还土地的结果。 [[2]](#note-2)

<a id="sj015-0298-zhao-event"></a>

<a id="event-3"></a>

3. **赵国进入惠文王元年，公子胜受封为平原君，并担任辅政职务。** 父亲武灵王虽已传位，仍以“主父”的身份活动，赵国并非新王一人独掌所有事务。 [[3]](#note-3)

<a id="sj015-0298-chu-event"></a>

<a id="event-4"></a>

4. **楚开始顷襄王横的元年，秦继续以兵索取楚地。** 怀王仍被扣在秦，秦因不能借他换地、楚又另立君而发怒，越武关大败楚军，本篇报斩首五万、取析等十五城，秦纪列十六城。楚并未因另立国君摆脱军事危机，城数异说保留在同号注。 [[4]](#note-4)

> 昭襄王元年，嚴君疾為相。甘茂出之魏。二年，彗星見。庶長壯與大臣、諸侯、公子為逆，皆誅，及惠文后皆不得良死。悼武王后出歸魏。三年，王冠。與楚王會黃棘，與楚上庸。四年，取蒲阪。彗星見。五年，魏王來朝應亭，復與魏蒲阪。六年，蜀侯煇反，司馬錯定蜀。庶長奐伐楚，斬首二萬。涇陽君質於齊。日食，晝晦。七年，拔新城。摢裏子卒。八年，使將軍羋戎攻楚，取新市。齊使章子，魏使公孫喜，韓使暴鳶共攻楚方城，取唐眛。趙破中山，其君亡，竟死齊。魏公子勁、韓公子長為諸侯。九年，孟嘗君薛文來相秦。奐攻楚，取八城，殺其將景快。十年，楚懷王入朝秦，秦留之。薛文以金受免。樓緩為丞相。十一年，齊、韓、魏、趙、宋、中山五國共攻秦，至鹽氏而還。秦與韓、魏河北及封陵以和。彗星見。楚懷王走之趙，趙不受，還之秦，即死，歸葬。十二年，樓緩免，穰侯魏冉為相。予楚粟五萬石。

## 归年与考证

<a id="sj005-222-note"></a>
<a id="sj005-222田文离开秦国楼缓出任丞相"></a>
#### sj005-222｜田文离开秦国，楼缓出任丞相。

[卷005 P065](../../拆分史书/史记/卷005.md#p065)。

**说明：**与年表田文前298返齐相接；楼缓在本纪同段，任相暂置此阶段，不借本纪十年重建田文第二次免相。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../拆分史书/史记/卷005.md#kao-c691f26620)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0298-wei-note"></a>
<a id="卷015魏栏前298年"></a>
#### 卷015·魏栏｜前298年

[本年原格](../../拆分史书/史记/卷015.md#y0298)：“二十一。與齊、韓共擊秦于函谷。河、渭絕一日。”

与韩齐共攻函谷归同一联军条；河、渭绝一日另作史书观察记载，不据一句证明黄河与渭河全流域同时永久断流或把它作为战争原因。

<a id="sj015-0298-han-note"></a>
<a id="卷015韩栏前298年"></a>
#### 卷015·韩栏｜前298年

[本年原格](../../拆分史书/史记/卷015.md#y0298)：“十四。與齊、魏共擊秦。”

与齐魏击秦合入[函谷联军](#sj015-0298-wei-event)，不重复计一支独立韩国战役。

<a id="sj015-0298-zhao-note"></a>
<a id="卷015赵栏前298年"></a>
#### 卷015·赵栏｜前298年

[本年原格](../../拆分史书/史记/卷015.md#y0298)：“趙惠文王元年。以公子勝為相，封平原君。”

惠文王元年承接[前299传位](bce-0299.md#sj015-0299-zhao-accession)。公子胜为武灵王之子、惠文王之弟，封平原君及任相据表；当时肥义亦辅王，不能据单一“相”字抹去其他官员。[《通鉴》卷三及校刊记](../../拆分史书/资治通鉴/卷003.md#text)本年也载封平原君。

<a id="sj015-0298-chu-note"></a>
<a id="卷015楚栏前298年"></a>
#### 卷015·楚栏｜前298年

[本年原格](../../拆分史书/史记/卷015.md#y0298)：“楚頃襄王元年。秦取我十六城”

顷襄王元年与前299迎立相接。秦取十六城据表及[《通鉴》卷三及校刊记](../../拆分史书/资治通鉴/卷003.md#text)，后者解释为秦得知楚已有新王而进攻；“元年”不意味着怀王已死，他此时仍在秦。

<a id="sj015-0298-qi-note"></a>
<a id="卷015齐栏前298年"></a>
#### 卷015·齐栏｜前298年

[本年原格](../../拆分史书/史记/卷015.md#y0298)：“二十六。與魏、韓共擊秦。孟嘗君歸相齊。”

共同攻秦接[函谷联军](#sj015-0298-wei-event)，孟尝君归齐任相与原页离秦接续；不是从秦死亡后重新出现。正文补明回齐任相，鸡鸣狗盗故事另待相应列传完整处理。

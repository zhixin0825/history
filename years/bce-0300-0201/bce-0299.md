<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦将芈戎攻楚新市，秦又取楚八城。** 本纪在昭王八九年交界处连续列秦军攻楚。王室封赏也有魏公子劲、韩公子长“为诸侯”的简记，没有进一步说明封国范围。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚怀王进入秦国，被秦扣留。** 两国此前还有黄棘会面和上庸交地，如今王本人被留下，楚秦关系发生严重转折。 [[2]](#note-2)

<a id="event-3"></a>

3. **孟尝君田文进入秦廷，出任秦相。** 薛文即田文，是靖郭君田婴之子，承继薛地，号孟尝君。他以招纳宾客闻名，这时被引入秦廷，任职没有持续很久。 [[3]](#note-3)

<a id="sj015-0299-wei-event"></a>

<a id="event-4"></a>

4. **齐王与魏王到韩国会面。** 韩国也在这一年确立公子咎为太子，日后的韩釐王由此进入储位。 [[4]](#note-4)

<a id="sj015-0299-qi-event"></a>

<a id="event-5"></a>

5. **泾阳君从齐国返回秦国。** [[5]](#note-5)

<a id="sj015-0299-zhao-accession"></a>

<a id="event-6"></a>

6. **赵武灵王把王位传给儿子何，自己改称主父。** 新王处理朝政，主父仍希望亲自经营北方和西方的军事事务，父子两套权力由此并存。 [[6]](#note-6)

<a id="sj015-0299-chu-accession"></a>

<a id="event-7"></a>

7. **楚怀王被扣后，楚国从齐国迎回太子横，拥立为王，即楚顷襄王。** 怀王尚在世，新君已开始承担国政。 [[7]](#note-7)

## 本年相关史料

<a id="note-1"></a>

### 1. 秦将芈戎攻楚新市，秦又取楚八城

[返回正文第1条](#event-1)

**[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)**

> 昭襄王元年，嚴君疾為相。甘茂出之魏。二年，彗星見。庶長壯與大臣、諸侯、公子為逆，皆誅，及惠文后皆不得良死。悼武王后出歸魏。三年，王冠。與楚王會黃棘，與楚上庸。四年，取蒲阪。彗星見。五年，魏王來朝應亭，復與魏蒲阪。六年，蜀侯煇反，司馬錯定蜀。庶長奐伐楚，斬首二萬。涇陽君質於齊。日食，晝晦。七年，拔新城。摢裏子卒。八年，使將軍羋戎攻楚，取新市。齊使章子，魏使公孫喜，韓使暴鳶共攻楚方城，取唐眛。趙破中山，其君亡，竟死齊。魏公子勁、韓公子長為諸侯。九年，孟嘗君薛文來相秦。奐攻楚，取八城，殺其將景快。十年，楚懷王入朝秦，秦留之。薛文以金受免。樓緩為丞相。十一年，齊、韓、魏、趙、宋、中山五國共攻秦，至鹽氏而還。秦與韓、魏河北及封陵以和。彗星見。楚懷王走之趙，趙不受，還之秦，即死，歸葬。十二年，樓緩免，穰侯魏冉為相。予楚粟五萬石。

### 6. 赵武灵王把王位传给儿子何，自己改称主父

[返回正文第6条](#event-6)

**[《史記》卷043](../../sources/本地分卷/史记/史记-卷043.md#L3898)**

> 二十七年五月戊申，大朝於東宮，傳國，立王子何以為王。王廟見禮畢，出臨朝。大夫悉為臣，肥義為相國，并傅王。是為惠文王。惠文王，惠后吳娃子也。武靈王自號為主父。

**[《史記》卷043](../../sources/本地分卷/史记/史记-卷043.md#L3899)**

> 主父欲令子主治國，而身胡服將士大夫西北略胡地，而欲從雲中、九原直南襲秦，於是詐自為使者入秦。秦昭王不知，已而怪其狀甚偉，非人臣之度，使人逐之，而主父馳已脫關矣。審問之，乃主父也。秦人大驚。主父所以入秦者，欲自略地形，因觀秦王之為人也。

### 7. 楚怀王被扣后，楚国从齐国迎回太子横，拥立为王，即楚顷襄王

[返回正文第7条](#event-7)

**[《史記》卷040](../../sources/本地分卷/史记/史记-卷040.md#L3722)**

> 楚大臣患之，乃相與謀曰：「吾王在秦不得還，要以割地，而太子為質於齊，齊、秦合謀，則楚無國矣。」乃欲立懷王子在國者。昭雎曰：「王與太子俱困於諸侯，而今又倍王命而立其庶子，不宜。」乃詐赴於齊，齊湣王謂其相曰：「不若留太子以求楚之淮北。」相曰：「不可，郢中立王，是吾抱空質而行不義於天下也。」或曰：「不然。郢中立王，因與其新王市曰『予我下東國，吾為王殺太子，不然，將與三國共立之』，然則東國必可得矣。」齊王卒用其相計而歸楚太子。太子橫至，立為王，是為頃襄王。乃告于秦曰：「賴社稷神靈，國有王矣。」

[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-fac3d5c4af9ce6)

#### sj005-219｜秦将芈戎攻楚新市，秦又取楚八城。

**说明：**八城与景快被杀在本纪合写，年表八城在前299、景缺之死前300，正文不把不同年次全部压成同战。两位公子受封以该段时期附记，不据一句断定一套新独立国君年表。

<a id="sj015-0299-qin-note"></a>
<a id="卷015秦栏前299年"></a>
#### 卷015·秦栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“八。楚王來，因留之。”

楚怀王入秦被留与旧第二条合并，采取秦楚两格及[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-7659ebe05e62b0)的前299年；《秦本纪》昭王十年为异年，不再于前297写一次入秦。 [对应正文](#event-2)

<a id="sj015-0299-wei-note"></a>
<a id="卷015魏栏前299年"></a>
#### 卷015·魏栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“二十。與齊王會于韓。”

齐魏两王会于韩国，与韩栏合并一次；不把“会于韩”误译成韩王出访齐魏。

<a id="sj015-0299-han-note"></a>
<a id="卷015韩栏前299年"></a>
#### 卷015·韩栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“十三。齊、魏王來。立咎為太子。”

齐魏王来并入[同次会面](#sj015-0299-wei-event)，立咎为太子也是此格独立信息；与前302太子婴为不同称名，不能无考证便解释成同一人改名。

<a id="sj015-0299-chu-note"></a>
<a id="卷015楚栏前299年"></a>
#### 卷015·楚栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“三十。王入秦。秦取我八城。”

怀王入秦归旧第二条，失八城归旧第一条。[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-48df0c8dddb85b)记怀王被迫割地而拒绝、秦将其扣留；楚人迎回太子横继位，次年才称顷襄王元年。

<a id="sj015-0299-qi-note"></a>
<a id="卷015齐栏前299年"></a>
#### 卷015·齐栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“二十五。涇陽君復歸秦。薛文入相秦。”

薛文即孟尝君田文，已在旧第三条；本次补泾阳君归秦。田文为田婴之子，继承薛封，早年宾客与继承故事不因本年入秦就全算本年发生。

# 公元前299年｜楚怀王被扣、顷襄王继位，赵武灵王传位

## 本年纪事

<a id="event-1"></a>

1. **秦将芈戎攻楚新市，秦又取楚八城。** 本纪在昭王八九年交界处连续列秦军攻楚。王室封赏也有魏公子劲、韩公子长“为诸侯”的简记，没有进一步说明封国范围。 [原文与说明](#sj005-219-note)

<a id="event-2"></a>

2. **楚怀王进入秦国，被秦扣留。** 两国此前还有黄棘会面和上庸交地，如今王本人被留下，楚秦关系发生严重转折。 [原文与说明](#sj005-220-note)

<a id="event-3"></a>

3. **孟尝君田文进入秦廷，出任秦相。** 薛文即田文，是靖郭君田婴之子，承继薛地，号孟尝君。他以招纳宾客闻名，这时被引入秦廷，任职没有持续很久。 [原文与说明](#sj005-221-note)

<a id="sj015-0299-wei-event"></a>

**齐王与魏王到韩国会面。**韩国也在这一年确立公子咎为太子，日后的韩釐王由此进入储位。 [原文与说明](#sj015-0299-wei-note)

<a id="sj015-0299-qi-event"></a>

**泾阳君从齐国返回秦国。** [原文与说明](#sj015-0299-qi-note)

<a id="sj015-0299-zhao-accession"></a>

**赵武灵王把王位传给儿子何，自己改称主父。**新王处理朝政，主父仍希望亲自经营北方和西方的军事事务，父子两套权力由此并存。 [原文与说明](#sj015-0299-zhao-accession-note)

<a id="sj015-0299-chu-accession"></a>

**楚怀王被扣后，楚国从齐国迎回太子横，拥立为王，即楚顷襄王。**怀王尚在世，新君已开始承担国政。 [原文与说明](#sj015-0299-chu-accession-note)

## 本年相关史料

<a id="sj005-219-note"></a>
### sj005-219｜秦将芈戎攻楚新市，秦又取楚八城。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**八城与景快被杀在本纪合写，年表八城在前299、景缺之死前300，正文不把不同年次全部压成同战。两位公子受封以该段时期附记，不据一句断定一套新独立国君年表。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj005-220-note"></a>
### sj005-220｜楚怀王进入秦国，被秦扣留。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**本纪写昭王十年相当前297，年表秦楚两栏都系前299，取年表；具体诱入经过以后与楚世家合并，不提前虚构会谈对白。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj005-221-note"></a>
### sj005-221｜孟尝君田文进入秦廷，出任秦相。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**年表前299入秦、前298返齐；本纪九年入相、十年免，与表有一年之差。金受免是本纪所传，不据本卷一句扩写鸡鸣狗盗全过程。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0299-qin-note"></a>
### 卷015·秦栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“八。楚王來，因留之。”

楚怀王入秦被留与旧第二条合并，采取秦楚两格及[《通鉴》卷三及校刊记](https://zh.wikisource.org/wiki/資治通鑑/卷003)的前299年；《秦本纪》昭王十年为异年，不再于前297写一次入秦。 [对应正文](#event-2)

<a id="sj015-0299-wei-note"></a>
### 卷015·魏栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“二十。與齊王會于韓。”

齐魏两王会于韩国，与韩栏合并一次；不把“会于韩”误译成韩王出访齐魏。

<a id="sj015-0299-han-note"></a>
### 卷015·韩栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“十三。齊、魏王來。立咎為太子。”

齐魏王来并入[同次会面](#sj015-0299-wei-event)，立咎为太子也是此格独立信息；与前302太子婴为不同称名，不能无考证便解释成同一人改名。

<a id="sj015-0299-chu-note"></a>
### 卷015·楚栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“三十。王入秦。秦取我八城。”

怀王入秦归旧第二条，失八城归旧第一条。[《通鉴》卷三及校刊记](https://zh.wikisource.org/wiki/資治通鑑/卷003)记怀王被迫割地而拒绝、秦将其扣留；楚人迎回太子横继位，次年才称顷襄王元年。

<a id="sj015-0299-qi-note"></a>
### 卷015·齐栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“二十五。涇陽君復歸秦。薛文入相秦。”

薛文即孟尝君田文，已在旧第三条；本次补泾阳君归秦。田文为田婴之子，继承薛封，早年宾客与继承故事不因本年入秦就全算本年发生。

<a id="sj015-0299-zhao-accession-note"></a>
### 衔接说明｜赵武灵王把王位传给儿子何，自己改称主父

[《通鉴》卷三及校刊记](https://zh.wikisource.org/wiki/資治通鑑/卷003)赧王十六年及[《赵世家》](https://zh.wikisource.org/wiki/史記/卷043)武灵王二十七年。承位在前299，惠文王元年在前298。

<a id="sj015-0299-chu-accession-note"></a>
### 衔接说明｜楚怀王被扣后，楚国从齐国迎回太子横，拥立为王，即楚顷襄王

[《通鉴》卷三及校刊记](https://zh.wikisource.org/wiki/資治通鑑/卷003)赧王十六年。前298为顷襄王元年，不能提前写怀王死亡。

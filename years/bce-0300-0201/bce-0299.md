1. **秦将芈戎攻楚新市，秦又取楚八城。** 本纪在昭王八九年交界处连续列秦军攻楚。王室封赏也有魏公子劲、韩公子长“为诸侯”的简记，没有进一步说明封国范围。 [[1]](#note-1)

<a id="event-2"></a>

<a id="sj015-0299-chu-accession"></a>

<a id="event-7"></a>

2. **楚怀王被秦扣留，楚迎太子横继位。** 楚怀王赴武关，被秦诱入咸阳扣留索地。秦昭王来书追叙黄棘盟、太子杀臣逃归，邀王面盟。昭雎劝楚自守、勿信秦，子兰却劝勿绝秦欢。怀王赴会，秦以将军假冒秦王，伏兵闭关，将他带往咸阳，令以藩臣礼朝章台。秦索巫、黔中，怀王要求先盟而拒先地，遂被留。楚臣从齐迎回太子横继位，拒绝让秦以怀王控制楚国。国内曾议另立庶子，昭雎反对，遂向齐假报怀王死讯。齐王想扣太子索淮北，有人还主张用杀太子或合诸国立太子威胁楚新君；齐相担忧楚若另立便只剩无用人质，又损义名，劝放归。太子回楚，立为顷襄王，楚向秦告已有新君。 [[2]](#note-2)

<a id="event-3"></a>

3. **孟尝君田文进入秦廷，出任秦相。** 薛文即田文，是靖郭君田婴之子，承继薛地，号孟尝君。他以招纳宾客闻名，这时被引入秦廷，任职没有持续很久。 [[3]](#note-3)

<a id="sj015-0299-wei-event"></a>

<a id="event-4"></a>

4. **齐王与魏王到韩国会面。** 韩国也在这一年确立公子咎为太子，日后的韩釐王由此进入储位。 在楚为质的蟣蝨最终未能返韩；关于这场争储的苏代说辞跨越人物与年份疑点，前300的前情附读保留各自层次。 [[4]](#note-4)

<a id="sj015-0299-qi-event"></a>

<a id="event-5"></a>

5. **泾阳君从齐国返回秦国。** [[5]](#note-5)

<a id="sj015-0299-zhao-accession"></a>

<a id="event-6"></a>

6. **赵武灵王把王位传给儿子何，自己改称主父。** 新王处理朝政，主父仍希望亲自经营北方和西方的军事事务，父子两套权力由此并存。 五月戊申，传位在东宫大会举行；何入庙行礼后临朝，诸大夫皆行臣礼，肥义兼相国与王傅。何为惠后吴娃之子，次年前298才起惠文王元年。 传位以后另有未确年事：主父想从云中、九原直向南袭秦，假扮使者入秦，亲察地形与秦昭王为人。秦王起初不知，后来见其体貌魁伟、气度非臣，遣人追赶，他已驰出关；查明是主父，秦人大惊。 [[6]](#note-6)

<a id="sj040-cite-183"></a>

**[《史记·楚世家》P084](../../sources/摘录/史记-卷040-楚世家.md#p084)**

> 秦昭王遺楚王書曰：「始寡人與王約為弟兄，盟于黃棘，太子為質，至驩也。太子陵殺寡人之重臣，不謝而亡去，寡人誠不勝怒，使兵侵君王之邊。今聞君王乃令太子質於齊以求平。寡人與楚接境壤界，故為婚姻，所從相親久矣。而今秦楚不驩，則無以令諸侯。寡人願與君王會武關，面相約，結盟而去，寡人之願也。敢以聞下執事。」楚懷王見秦王書，患之。欲往，恐見欺；無往，恐秦怒。昭雎曰：「王毋行，而發兵自守耳。秦虎狼，不可信，有并諸侯之心。」懷王子子蘭勸王行，曰：「柰何絕秦之驩心！」於是往會秦昭王。昭王詐令一將軍伏兵武關，號為秦王。楚王至，則閉武關，遂與西至咸陽，朝章臺，如蕃臣，不與亢禮。楚懷王大怒，悔不用昭子言。秦因留楚王，要以割巫、黔中之郡。楚王欲盟，秦欲先得地。楚王怒曰：「秦詐我而又彊要我以地！」不復許秦。秦因留之。

**本卷说明：** 昭雎与屈原劝止的不同传文在原既有注保留；假王、伏兵为本篇细节，不倒写正常对等会盟。

#### sj005-220｜楚怀王进入秦国，被秦扣留。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**本纪写昭王十年相当前297，年表秦楚两栏都系前299，取年表；具体诱入经过以后与楚世家合并，不提前虚构会谈对白。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj005-221-note"></a>
<a id="sj005-221孟尝君田文进入秦廷出任秦相"></a>
#### sj005-221｜孟尝君田文进入秦廷，出任秦相。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**年表前299入秦、前298返齐；本纪九年入相、十年免，与表有一年之差。金受免是本纪所传，不据本卷一句扩写鸡鸣狗盗全过程。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0299-qin-note"></a>
<a id="卷015秦栏前299年"></a>
#### 卷015·秦栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“八。楚王來，因留之。”

楚怀王入秦被留与旧第二条合并，采取秦楚两格及[《通鉴》卷三及校刊记](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-7659ebe05e62b0)的前299年；《秦本纪》昭王十年为异年，不再于前297写一次入秦。 [对应正文](#event-2)

<a id="sj015-0299-wei-note"></a>
<a id="卷015魏栏前299年"></a>
#### 卷015·魏栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“二十。與齊王會于韓。”

齐魏两王会于韩国，与韩栏合并一次；不把“会于韩”误译成韩王出访齐魏。

<a id="sj015-0299-han-note"></a>
<a id="卷015韩栏前299年"></a>
#### 卷015·韩栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“十三。齊、魏王來。立咎為太子。”

齐魏王来并入[同次会面](#sj015-0299-wei-event)，立咎为太子也是此格独立信息；与前302太子婴为不同称名，不能无考证便解释成同一人改名。

<a id="sj015-0299-chu-note"></a>
<a id="卷015楚栏前299年"></a>
#### 卷015·楚栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“三十。王入秦。秦取我八城。”

怀王入秦归旧第二条，失八城归旧第一条。[《通鉴》卷三及校刊记](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-48df0c8dddb85b)记怀王被迫割地而拒绝、秦将其扣留；楚人迎回太子横继位，次年才称顷襄王元年。

<a id="sj015-0299-qi-note"></a>
<a id="卷015齐栏前299年"></a>
#### 卷015·齐栏｜前299年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0299)：“二十五。涇陽君復歸秦。薛文入相秦。”

薛文即孟尝君田文，已在旧第三条；本次补泾阳君归秦。田文为田婴之子，继承薛封，早年宾客与继承故事不因本年入秦就全算本年发生。

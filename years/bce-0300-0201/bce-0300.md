1. **秦攻取楚新城，樗里疾去世，泾阳君到齐为质。** 秦在楚地继续推进；秦齐关系则以宗室质子维持。任相多年的樗里疾去世，政治人事也发生变化。 [[1]](#note-1)

<a id="sj015-0300-chu-event"></a>

<a id="event-2"></a>

2. **秦攻取楚襄城，景缺战死，楚太子又往齐为质求和。** 前一年重丘失利后，楚再遭重创，秦方记斩首三万，本篇记二万。怀王忧惧，将太子横送齐求和；城邑已被攻取与死伤数的异记分别说明。 [[2]](#note-2)

<a id="sj043-northward-event"></a>

3. **赵国再次攻中山，并扩大北方疆域。** 武灵王二十六年的拓地记为北至燕、代，西至云中、九原。 [[3]](#sj043-northward-note)

<a id="sj045-succession-event"></a>

4. **太子婴去世后，韩王室为储位争执，楚、秦也设法介入。** 公子咎与在楚国做人质的公子蟣蝨争当继承人。苏代劝韩咎顺着楚王想送蟣蝨回韩的愿望，让楚在雍氏旁造一座万户之城，迫韩出兵；韩咎若获命领军，便可合韩楚之兵拥送蟣蝨回国，争取让新太子听命于自己并获得两国封地。韩咎接受了这个计划，但游说所许的封赏并不等于已经实现。围雍氏与另一段伯婴争储说辞的确切年次、先后另有冲突，以下作为相关未定年故事附读。楚围雍氏时，韩向秦求援，秦未发兵而先派公孙昧来。公仲问秦是否真救，公孙昧说秦声言绕南郑、蓝田出兵，未必能及时接应；他以张仪先前对魏楚战争的计策作比：秦可以佯作援救，等双方消耗后夺地。如今韩若因等秦援而轻率出战，楚又知道秦不会真救，秦便可坐收胜负两头的好处：韩若胜楚，秦跟着乘胜制楚，在三川显示救韩之功后回国；韩若败，楚封锁三川，韩便无力解救。公孙昧又举司马庚屡往郢、甘茂会昭鱼等往来，说明秦楚可能另有安排，劝公仲先保韩和自身，尽快联齐楚，同时保留对秦关系；篇中接着说楚解围，但这些判断并非密约已获独立证实。另一段游说中，苏代又劝芈戎利用公叔伯婴害怕蟣蝨返韩的心理。第一步替韩向楚求质，借楚的答复让伯婴判断秦楚无意借蟣蝨干预储位，从而使韩亲近秦楚；秦楚再挟韩牵制魏，令魏不敢联齐，便可孤立齐国。第二步再替秦索取楚所留的韩质子；楚若拒绝，韩便怨楚，可以联齐魏围楚，迫楚转而倚重芈戎。这样芈戎既可借秦楚地位施惠于韩，也可让伯婴以国事相托。第一步“求质”究竟如何替换、原文是否脱“不”，仍按古注异解保留，不能把两次请求混成一件。原文这一段是否有脱字、是否倒叙到伯婴尚在世时，都未能确定，不能把已经说死的太子婴复活后继续争位。谋说所许结盟、封赏没有被逐一证明实现；最后蟣蝨未归、韩立咎为太子的结果接前299年。 [[4]](#sj045-succession-note)

### 4. 太子婴去世后，韩王室为储位争执，楚、秦也设法介入

[返回正文第4条](#sj045-succession-event)

<a id="sj045-cite-063"></a>

**[《史记·韩世家》P025](../../sources/摘录/史记-卷045-韩世家.md#p025)**

> 十二年，太子嬰死。公子咎、公子蟣蝨爭為太子。時蟣蝨質於楚。蘇代謂韓咎曰：「蟣蝨亡在楚，楚王欲內之甚。今楚兵十餘萬在方城之外，公何不令楚王筑萬室之都雍氏之旁，韓必起兵以救之，公必將矣。公因以韓楚之兵奉蟣蝨而內之，其聽公必矣，必以楚韓封公也。」韓咎從其計。

**本卷说明：** 襄王元年前311，十二年换算前300；不是唐昧败亡的十一年前301。苏代所提方案与实际成败分层；下段围雍氏有前后围之辨。

<!-- /sj045-cite-063 -->

<a id="sj045-cite-064"></a>

**[《史记·韩世家》P026](../../sources/摘录/史记-卷045-韩世家.md#p026)**

> 楚圍雍氏，韓求救於秦。秦未為發，使公孫昧入韓。公仲曰：「子以秦為且救韓乎？」對曰：「秦王之言曰『請道南鄭、藍田，出兵於楚以待公』，殆不合矣。」公仲曰：「子以為果乎？」對曰：「秦王必祖張儀之故智。楚威王攻梁也，張儀謂秦王曰：『與楚攻魏，魏折而入於楚，韓固其與國也，是秦孤也。不如出兵以到之，魏楚大戰，秦取西河之外以歸。』今其狀陽言與韓，其實陰善楚。公待秦而到，必輕與楚戰。楚陰得秦之不用也，必易與公相支也。公戰而勝楚，遂與公乘楚，施三川而歸。公戰不勝楚，楚塞三川守之，公不能救也。竊為公患之。司馬庚三反於郢，甘茂與昭魚遇於商於，其言收璽，實類有約也。」公仲恐，曰：「然則柰何？」曰：「公必先韓而後秦，先身而後張儀。公不如亟以國合於齊楚，齊楚必委國於公。公之所惡者張儀也，其實猶不無秦也。」於是楚解雍氏圍。

**本卷说明：** 雍氏与秦援说辞的未定年附读：[三家注p23](../../sources/史记三家注/卷045.md#p23)集解把本段看作前312年的前围，又把前段储争看作赧王十五年前300的后围；正义反对，认为本段仍属后围，只是追述张仪旧事。又有甘茂传秦昭新立时的围城记。本处保留争议，不把前315周篇未定年说辞、前312明确围城和本段机械数成三次都已确年的围城。全文白话：楚围雍氏，韩向秦求援。秦尚未发兵，派公孙昧入韩。公仲问秦是否真会救，公孙昧说秦口称从南郑、蓝田方向出兵，未必能与韩及时会合；又拿张仪旧计作比：楚攻梁时，张仪忧魏屈服楚会令韩也亲楚、孤立秦，建议佯作援救，让魏楚相战而秦取西河。如今秦表面助韩、暗中善楚，韩若因期待援军轻率开战，楚又知道秦不会真救，双方都会被推着作战；韩若胜楚，秦便跟着乘胜制楚、在三川张设救韩之功再回国；韩若败，楚便封锁三川而韩无力解救。公孙昧又以司马庚屡往郢、甘茂会昭鱼等作为秦楚疑有密约的迹象，劝公仲先保韩与自身，急与齐楚联合，同时不必彻底断秦。篇中以楚解围作结。这是使者的判断和游说，不是秦楚密约已被独立证实。

<!-- /sj045-cite-064 -->

<a id="sj045-cite-065"></a>

**[《史记·韩世家》P027](../../sources/摘录/史记-卷045-韩世家.md#p027)**

> 蘇代又謂秦太后弟羋戎曰：「公叔伯嬰恐秦楚之內蟣蝨也，公何不為韓求質子於楚？楚王聽入質子於韓，則公叔伯嬰知秦楚之不以蟣蝨為事，必以韓合於秦楚。秦楚挾韓以窘魏，魏氏不敢合於齊，是齊孤也。公又為秦求質子於楚，楚不聽，怨結於韓。韓挾齊魏以圍楚，楚必重公。公挾秦楚之重以積德於韓，公叔伯嬰必以國待公。」

**本卷说明：** 未定年附读：[三家注p24](../../sources/史记三家注/卷045.md#p24)以公叔伯婴为太子婴，若从此解，就与前段已死矛盾，故索隐说故事重复、文字倒置。正义又疑“楚王听入”脱“不”。这里完整保存两条解释，原字不改。全文白话：另一段说辞中，苏代劝秦太后弟芈戎利用韩公叔伯婴害怕秦楚送回蟣蝨的心理，替韩向楚求质；索隐将这一步解释为另派他人替换蟣蝨，让他归韩，而正义又认为下句“楚王听入”脱“不”，两种解释并不相同。说辞设想借楚的答复推动韩依附秦楚，挟韩牵制魏，令魏不敢合齐、使齐孤立。第二步再替秦向楚索取楚所留的韩质子，使其入秦；若楚拒绝，便激成韩怨楚、联齐魏围楚，使楚转而重视芈戎，从而让芈戎同时在秦楚韩之间取重。本文“楚王听入质子”与后句逻辑不顺，正义疑脱“不”；伯婴是否就是前段已死的太子婴、这段是否倒叙，古注也有解释。最终蟣蝨未能返韩，韩立咎为太子，齐魏两王来会。方案不等于各国已经逐项照做，储位结果与游说中的人物年次必须分开。

#### sj005-218｜秦攻取楚新城，樗里疾去世，泾阳君到齐为质。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**泾阳质齐本纪附六年，年表齐栏七年，暂依前300。楚将景快／景缺之死，本纪接九年八城，年表楚栏七年；此处先列年差，不凭近名另造两个相同被杀者。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0300-qin-note"></a>
<a id="卷015秦栏前300年"></a>
#### 卷015·秦栏｜前300年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0300)：“七。樗里疾卒。擊楚，斬首三萬。魏冉為相。”

樗里疾卒与既有条合并；三万与楚栏景缺、襄城相接，补入战事。表又记魏冉为相，而前295表／本纪明确楼缓免、魏冉任相，[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-d7866cf3ead5e8)本年却记楼缓接樗里疾。尚不能由短记重建魏冉一次确定的前300任相，故相位细节留疑，不覆盖前295主叙。

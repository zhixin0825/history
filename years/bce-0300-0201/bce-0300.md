1. **秦攻取楚新城，樗里疾去世，泾阳君到齐为质。** 秦在楚地继续推进；秦齐关系则以宗室质子维持。任相多年的樗里疾去世，政治人事也发生变化。 [[1]](#note-1)

<a id="event-2"></a>

2. **秦攻取楚襄城，景缺战死，楚太子又往齐为质求和。** 前一年重丘失利后，楚再遭重创，秦方记斩首三万，本篇记二万。怀王忧惧，将太子横送齐求和；城邑已被攻取与死伤数的异记分别说明。 [[2]](#note-2)

<a id="note-1"></a>

### 1. 秦攻取楚新城，樗里疾去世，泾阳君到齐为质

[返回正文第1条](#event-1)

**[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)**

> 昭襄王元年，嚴君疾為相。甘茂出之魏。二年，彗星見。庶長壯與大臣、諸侯、公子為逆，皆誅，及惠文后皆不得良死。悼武王后出歸魏。三年，王冠。與楚王會黃棘，與楚上庸。四年，取蒲阪。彗星見。五年，魏王來朝應亭，復與魏蒲阪。六年，蜀侯煇反，司馬錯定蜀。庶長奐伐楚，斬首二萬。涇陽君質於齊。日食，晝晦。七年，拔新城。摢裏子卒。八年，使將軍羋戎攻楚，取新市。齊使章子，魏使公孫喜，韓使暴鳶共攻楚方城，取唐眛。趙破中山，其君亡，竟死齊。魏公子勁、韓公子長為諸侯。九年，孟嘗君薛文來相秦。奐攻楚，取八城，殺其將景快。十年，楚懷王入朝秦，秦留之。薛文以金受免。樓緩為丞相。十一年，齊、韓、魏、趙、宋、中山五國共攻秦，至鹽氏而還。秦與韓、魏河北及封陵以和。彗星見。楚懷王走之趙，趙不受，還之秦，即死，歸葬。十二年，樓緩免，穰侯魏冉為相。予楚粟五萬石。

## 归年与考证

<a id="sj005-218-note"></a>
<a id="sj005-218秦攻取楚新城樗里疾去世泾阳君到齐为质"></a>
#### sj005-218｜秦攻取楚新城，樗里疾去世，泾阳君到齐为质。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**泾阳质齐本纪附六年，年表齐栏七年，暂依前300。楚将景快／景缺之死，本纪接九年八城，年表楚栏七年；此处先列年差，不凭近名另造两个相同被杀者。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0300-qin-note"></a>
<a id="卷015秦栏前300年"></a>
#### 卷015·秦栏｜前300年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0300)：“七。樗里疾卒。擊楚，斬首三萬。魏冉為相。”

樗里疾卒与既有条合并；三万与楚栏景缺、襄城相接，补入战事。表又记魏冉为相，而前295表／本纪明确楼缓免、魏冉任相，[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-d7866cf3ead5e8)本年却记楼缓接樗里疾。尚不能由短记重建魏冉一次确定的前300任相，故相位细节留疑，不覆盖前295主叙。

<a id="sj015-0300-chu-note"></a>
<a id="卷015楚栏前300年"></a>
#### 卷015·楚栏｜前300年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0300)：“二十九。秦取我襄城，殺景缺。”

秦取襄城、景缺死与[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-4de005647e986c)相合。旧页《秦本纪》“新城”作为该书见证保留，不把新城、襄城仅凭近义静默改为同一地。

<a id="sj015-0300-qi-note"></a>
<a id="卷015齐栏前300年"></a>
#### 卷015·齐栏｜前300年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0300)：“二十四。秦使涇陽君來為質。”

泾阳君到齐为质与原有第一条合并，次年前299归秦另列；质子身份不等于齐国已经控制全部秦政。 [对应正文](#event-1)

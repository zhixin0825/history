# 战国时期｜乐毅报燕王书与乐氏传承（时期阅读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷080完整读本](../../sources/摘录/史记-卷080-乐毅列传.md) · [纪年与异说](../../meta/考证/史记-卷080-纪年与异说.md)

本页按可见的事件先后或主题阅读。未载确年的轶事、书信和传承保留为时期材料，已定年事件由对应年页进入。

<a id="event-1"></a>

1. **乐氏在灵寿开基。** 魏文侯用乐羊攻中山，后以灵寿封他。乐羊葬于封地，其后人因而家居灵寿。魏克中山与赵最终并中山相隔数代，前者见[前406年](../bce-0500-0401/bce-0406.md#note-1)，后者见[前296年](bce-0296.md#note-3)。 [[1]](#note-1)

<a id="event-2"></a>

2. **乐毅由魏使成为燕臣。** 燕昭王要雪旧耻，礼待郭隗、广延人才。沙丘之变后，乐毅离赵赴魏，后来以魏使身份到燕，受燕王厚待，继而任燕亚卿。魏使来燕、委质任职的确年无载。 [[2]](#note-2)

<a id="event-3"></a>

3. **联军伐齐后的占领与失地。** 燕军入临淄后继续攻取齐城，莒、即墨长期抵抗；聊城是否也始终未下，各传不同。燕惠王换将后，乐毅奔赵，被封于观津。济西胜负与即墨反攻分别详见[前284年](bce-0284.md#note-1)、[前279年](bce-0279.md#note-3)。 [[3]](#note-3)

<a id="event-4"></a>

4. **燕惠王遣使责问，乐毅答书自明。** 燕军败后，惠王解释换将缘故，又责乐毅负昭王旧恩。乐毅在答书中追述昭王识拔自己和合兵破齐，举伍子胥的结局说明离燕避祸，表明自己要保全先王功名。发使与答书的日月无载。 [[4]](#note-4)

<a id="event-5"></a>

5. **父子重通燕国，乐毅晚年卒于赵。** 燕复封乐闲为昌国君，乐毅也再次往来燕、赵，获客卿礼遇，最后死于赵。重通是答书之后的结果，卒年无从确系。 [[5]](#note-5)

<a id="event-6"></a>

6. **乐闲、乐乘留赵与燕王喜的责书。** 栗腹攻赵败后，乐闲已入赵。燕王喜写信责他没有像箕子、商容一样继续谏诤，又说国中之事不当告邻国。乐闲、乐乘终留赵。出兵、围燕、封武襄君及后来的赵国换将各见已有年页，书信未另定年。 [[6]](#note-6)

<a id="event-7"></a>

7. **乐氏入齐与黄老师承。** 赵国将亡之际，乐瑕公和乐臣公避居高密。乐臣公讲习黄老，其学后来传给盖公，盖公为曹参所师。乐叔受汉高帝封的另一支另见[前197年](../bce-0200-0101/bce-0197.md#note-5)。黄老师承及蒯通、主父偃读书流泪的事各无确年。 [[7]](#note-7)

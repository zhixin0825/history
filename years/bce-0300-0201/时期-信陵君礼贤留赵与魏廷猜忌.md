# 战国晚期｜信陵君礼贤、留赵与魏廷猜忌（跨年及未定年）

[本世纪目录](README.md) · [全部世纪](../README.md) · [完整列传](../../sources/摘录/史记-卷077-魏公子列传.md) · [纪年考证](../../meta/考证/史记-卷077-纪年与异说.md)

本页连读无忌在魏、赵的交游、留赵及归国后遭谗的经历，兼收后世奉祠与访古。军事结果分别见[前257年邯郸解围](bce-0257.md#note-2)、[前247年河外败秦](bce-0247.md#note-2)，无忌卒见[前243年](bce-0243.md#note-3)，高祖设守冢户见[前195年](../bce-0200-0101/bce-0195.md#note-5)。

## 故事与因果

<a id="event-1"></a>

1. **门客汇集到魏公子门下。** 魏无忌接纳并礼待各等士人，四方来者争相归附，传称食客三千。传文称诸侯十余年不敢谋魏，以此形容公子的名望和门客之势。这一概称没有精确起止，魏国此期仍有与秦国交兵的记录。 [[1]](#note-1)

<a id="event-2"></a>

2. **博戏中看出边报虚实。** 魏王接到赵军将入境的烽报，公子据门客所知判断赵王只是打猎。确认消息传来后，魏王对无忌的消息渠道反生忌惮，不敢让他主持国政。 [[2]](#note-2)

<a id="event-3"></a>

3. **夷门迎侯嬴，访市中朱亥。** 公子虚车左位亲迎夷门守门人侯嬴，又应其所请入市看望屠者朱亥。侯嬴当众久立以观察公子，见其谦恭如故。侯嬴成为上客后再荐朱亥，公子几次拜访都不见他回谢，直到救赵用人时才听到缘由。 [[3]](#note-3)

<a id="event-4"></a>

4. **客劝无忌自抑，赵王未献五城。** 无忌矫命救赵后遣军回魏，自己留赵。赵王和平原君拟赠五城，门客直言夺兵虽对赵有功、对魏有负。无忌自责，依谦退之礼改由东阶上，赵王最终没有提出五城之封，另以鄗作其汤沐邑。魏也恢复以信陵供奉公子。 [[4]](#note-4)

<a id="event-5"></a>

5. **毛公、薛公从私交到劝归。** 无忌亲访混迹博徒和卖饮料人家的毛公、薛公，平原君起初以此为羞，听了无忌的批评后脱帽相谢并挽留。秦屡攻魏，魏王派使者请无忌返国，门客惧于禁令不敢劝说，毛、薛却以大梁和宗庙安危动之。两人都是留赵结识的处士，古注不载其个人名字。 [[5]](#note-5)

<a id="event-6"></a>

6. **秦国反间与无忌退处。** 河外败秦之后，秦国让晋鄙旧客向魏王毁谤公子，制造诸侯欲拥立无忌的假消息。魏王让别人接掌兵权，无忌遂称病退处，以长夜饮酒度日。 [[6]](#note-6)

<a id="event-7"></a>

7. **高祖奉祠、司马迁访夷门与唐代述赞。** 刘邦年轻时屡闻公子贤名，即位后每过大梁祭祀。司马迁经过大梁废墟，也访求过夷门，并称许无忌肯屈身结交隐士。司马贞的《索隐述赞》又以侯嬴、朱亥、毛公、薛公概括其礼士声名。 [[7]](#note-7)

### 1. 门客汇集到魏公子门下

> 公子爲人仁而下士，士無賢不肖皆謙而禮交之，不敢以其富貴驕士。士以此方數千里爭往歸之，致食客三千人。

> 且矯魏王令，奪晉鄙兵以救趙，於趙則有功矣，於魏則未爲忠臣也。

**归年说明：** 前257年解围与留赵的先后相承。辞五城、受鄗与复奉信陵缺乏各自确日。

### 6. 秦国反间与无忌退处

[返回正文第6条](#event-6)

[《史记·魏公子列传》P013](../../sources/摘录/史记-卷077-魏公子列传.md#p013) · [三家注p13](../../sources/史记三家注/卷077.md#p13)

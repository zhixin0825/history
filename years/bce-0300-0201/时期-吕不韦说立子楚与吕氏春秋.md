# 战国晚期｜吕不韦说立子楚与吕氏春秋（时期阅读）

本页按原传可见的先后和专题阅读。已知年份的事件在相应年页，未独立确年的叙事随原传先后附读。

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **阳翟经商与子楚留赵。** 吕不韦往来经商，积聚家财。子楚虽出于秦王室，在赵为质时资用窘迫，又因秦屡攻赵而受到冷遇。两人结识以前的经历没有独立确年。 [[1]](#note-1)

<a id="event-2"></a>

2. **吕不韦在邯郸结识子楚。** 吕不韦认为子楚有承继秦国的可能，主动结交。他看出华阳夫人没有儿子，子楚又久留赵国，便提出以资财和引荐替他争取成为嫡嗣。 [[2]](#note-2)

<a id="event-3"></a>

3. **华阳夫人收子楚为嗣。** 吕不韦把财物分用于子楚交游和拜访华阳夫人家属。夫人同安国君约定收子楚为嗣，吕不韦成为子楚的师傅。安国君受立为太子、子楚后来受立为太子各有年页，本段没有提供约立嫡嗣的年月。 [[3]](#note-3)

<a id="event-4"></a>

4. **赵姬与政的身世记载。** 子楚在邯郸同赵姬结为夫妇，后来赵姬生政。关于孕期与生父，两篇本传有不同写法。邯郸出生按《秦始皇本纪》接前259年。 [[4]](#note-4)

<a id="event-5"></a>

5. **宾客著书与一字千金故事。** 吕不韦招集宾客编书。八览、六论、十二纪汇为《吕氏春秋》，传说还公布于咸阳城门、征求一字之改。十二纪《序意》的秦八年题记可以入年，全书终稿、悬金示书日年未载。 [[5]](#note-5)

<a id="event-6"></a>

6. **嫪毐入侍并追随太后居雍。** 嫪毐进入太后身边，后来随太后迁居雍并取得权势。受封、举事、罢相分别见前239、238、237的既有年页；最初入侍和移居雍的日年无法单定。 [[6]](#note-6)

<a id="event-7"></a>

7. **司马迁与司马贞对吕不韦的评价。** 司马迁从嫪毐败亡回看吕不韦的声名。唐代司马贞则用韵语概括结识子楚、约立继嗣、居相位与编书等关键情节。 [[7]](#note-7)

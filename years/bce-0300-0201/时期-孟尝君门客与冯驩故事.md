# 战国中后期｜孟尝君养士、薛地债务与冯驩游说（跨期附读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷075完整对读](../../sources/摘录/史记-卷075-孟尝君列传.md) · [纪年与异说](../../meta/考证/史记-卷075-纪年与异说.md)

田文、冯驩和门客们的经历没有全套可靠公元年。本页以人物关系和故事次序整理，已确年的[前299年入秦](bce-0299.md#note-3)、[前298年离秦](bce-0298.md#note-1)与[前284年伐齐](bce-0284.md#note-1)仍在原年页，不因传奇故事而新建另一套时间线。

## 连续阅读

<a id="event-1"></a>

1. **田文五月五日生，不因迷信而被弃。** 田文以增加门高的反问说服父亲，母亲才没有因五月生子的俗信被处罚；故事不提供出生确年。 [[1]](#note-1)

<a id="event-2"></a>

2. **养门客不择贵贱，后果也有阴影。** 田文招致贤士与有罪流亡者，门客数千；夜宴一人误以为食物不等，竟羞愧自杀，不能只写对宾客的礼遇。 [[2]](#note-2)

<a id="event-3"></a>

3. **狗盗狐裘与鸡鸣出关。** 田文被秦囚、赖盗裘求情，夜赴函谷关，又仿鸡鸣开关脱险；这些细节属于史记旧传，不另造独立年月。 [[3]](#note-3)

<a id="event-4"></a>

4. **门客在赵杀人、毁县。** 因赵人讥笑田文身材，随行者杀数百人。严重暴力应与鸡鸣狗盗同样记述，不能因孟尝君名声而删略。 [[4]](#note-4)

<a id="event-5"></a>

5. **冯驩弹剑三求改善待遇。** 冯驩初入门贫困，先求有鱼食，再求车乘，第三次要求可顾家；“冯谖”是其异写。 [[5]](#note-5)

<a id="event-6"></a>

6. **薛地贫者焚债券，富者定偿还日期。** 冯驩把债户分为能与息和不能与息，前者订期，后者焚券；不是将所有借贷全免。 [[6]](#note-6)

<a id="event-7"></a>

7. **冯驩先游说秦，再逼齐王复相田文。** 冯驩利用秦齐竞争，诱秦以车金求田文，再以这件事劝齐王抢先恢复其相位与封邑。 [[7]](#note-7)

<a id="event-8"></a>

8. **宾客散而复聚，田文接受冯驩劝告。** 冯驩以集市晨暮人来人往为喻，让田文勿因失势时客散而拒绝他们重新归附。 [[8]](#note-8)

# 战国中晚期｜屈原放逐与楚辞（时期阅读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷084完整读本](../../sources/摘录/史记-卷084-屈原贾生列传.md) · [纪年与异说](../../meta/考证/史记-卷084-纪年与异说.md)

屈原任楚怀王左徒、为君拟令和作《离骚》的具体时间未见明载，顷襄王时迁逐与汨罗之死也无可核的确年。张仪入楚、怀王被扣及楚亡的确定年次见各年页。本页连读仕途、放逐和楚辞。

<a id="event-1"></a>

1. **屈平参议楚政，因上官大夫进谗而失宠。** 屈原名平，与楚王室同姓。怀王任他为左徒，内参国事，外应诸侯。奉命草拟法令时，他拒绝把未定的稿子交给上官大夫，对方告他居功，怀王于是疏远他。正义引王逸称上官大夫为靳尚，正文未署其名。 [[1]](#note-1)

<a id="event-2"></a>

2. **《离骚》用芳洁的物象写守正者的忧愤。** 屈原把被疑被谤的处境写入《离骚》，借帝喾、汤武、齐桓等旧事针砭时政，以芳物托清洁之志。列传拿它同《国风》《小雅》相较，称其辞约旨远。作品的写作、形成与本传组织方式，尚不足以逐年确定。 [[2]](#note-2)

<a id="event-3"></a>

3. **子兰与上官大夫再次进谗，顷襄王迁逐屈原。** 怀王在秦不得返后，楚人责难曾劝他赴会的子兰。屈原虽被放流，仍盼楚君觉悟、自己归朝。子兰使上官大夫向顷襄王毁谤屈原，顷襄王将他迁逐，古注记江南。前后遭疏与迁逐出于不同王朝，行程、年月只能按文献所载相对次序阅读。 参见[怀王被扣](bce-0299.md#note-2) · [顷襄王继位](bce-0299.md#note-7)。 [[3]](#note-3)

<a id="event-4"></a>

4. **渔父劝随世，屈原坚持守洁。** 泽畔渔父劝屈原随世变通，屈原以新沐弹冠、新浴振衣为喻，不肯让清白蒙污。传记中的问答与楚辞的表现相关，无法据之还原谈话的确日或证实渔父身份。 [[4]](#note-4)

<a id="event-5"></a>

5. **《怀沙》由初夏南行写到无人知己。** 赋从孟夏草木与南方幽境写起，以绳墨未改、凤凰被囚、玉石混量表现贤愚倒置，再从怀瑾握瑜转到自持仁义。结辞见沅、湘浩荡而前路幽蔽，以伯乐已死、无人评骏马写知己难逢。全赋见读本P011—P015，诗中地名、季节与譬喻没有逐年行程的精度。 [[5]](#note-5)

<a id="event-6"></a>

6. **屈原死于汨罗，楚辞继作者以赋见称。** 传记说屈原怀石死于汨罗，随后举宋玉、唐勒、景差等以辞赋知名。正义引五月五日和后世投米粽祭的说法，汨罗死亡有传文本事，前278年为常用推定，亦有前277年等异说。五月五日的纪念传统见后世材料。郢都陷落及楚最终灭亡各有独立年页。 参见[前278年郢都陷落](bce-0278.md#note-1) · [前223年秦灭楚](bce-0223.md#note-1)。 [[6]](#note-6)

# 战国晚期｜平原君宾客与虞卿谋议（未定年）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷076完整原文](../../拆分史书/史记/卷076.md) · [纪年考证](../../拆分史书/史记/卷076.md#kao-7685f253b3)

这些材料主要涉及赵惠文王至赵孝成王时期。宾客事迹、具体任免与部分谋议只可约略定位，六县之议另有传、鉴异次。可确年的[赵王更替](bce-0266.md#note-2)、[长平](bce-0260.md#note-1)、[赴楚求援](bce-0258.md#note-1)、[邯郸解围](bce-0257.md#note-2)及[赵胜去世](bce-0251.md#note-2)由既有年页承载。

<a id="reading-start"></a>

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **赵国公子赵胜两朝为相。** 赵胜是赵惠文王的弟弟，封于东武城，先后为惠文王与孝成王之相。三次离开相位，又三次复职。他喜好招揽宾客，来投者达数千人。此后他的子孙承袭封爵，最终随赵国败亡。由[前266年赵王更替](bce-0266.md#note-2)可进入其任相事迹。 [[1]](#note-1)

<a id="event-2"></a>

2. **赵胜杀嘲笑跛者的姬妾以留宾客。** 赵胜的一名姬妾在楼上嘲笑邻家跛者。对方到门前索要她的首级，赵胜起初应允却未实行。门客陆续离去过半，解释说士人认为他爱色而轻士。赵胜遂杀那名姬妾，亲自送其首级谢罪，门客又陆续回来。 [[2]](#note-2)

<a id="event-3"></a>

3. **公孙龙劝赵胜谢绝因信陵君之功加封。** 信陵君保全邯郸后，虞卿想据此为赵胜请封。公孙龙认为，赵胜原以宗室亲属身份受封，若把别人的军功用来加封自己，会混淆两种依据。他又指出虞卿成则可索谢，败亦可卖人情。赵胜听从公孙龙，没有同意请封。 [[3]](#note-3)

<a id="event-4"></a>

4. **公孙龙的坚白之辩与邹衍过赵。** 赵胜礼遇以坚白之辩闻名的公孙龙。邹衍经过赵国，以辨清类别、说明意旨来衡量辩论得失，公孙龙的论辩因而受到抑制。 [[4]](#note-4)

<a id="event-5"></a>

5. **虞卿穿草履携长柄笠游说赵王。** 虞卿以游说之士的身份去见赵孝成王，初见获赐黄金与白璧，再见即任上卿。其后在长平战局中参与赵廷议和，主张先争取楚、魏，以免赵国孤立。 [[5]](#note-5)

<a id="event-6"></a>

6. **赵郝、楼缓与虞卿争论六县和议。** 秦赵议和时，赵郝欲以六县求和，楼缓怕各国趁赵困敝瓜分赵地，也劝速割。虞卿认为，以秦军无力攻取的城池换取无法保证的和约，只会让秦愈强、赵地愈少。他主张用秦所求的六城结齐、再向秦取偿。赵王派虞卿赴齐；虞卿未回，秦使已到赵，楼缓离去，虞卿获封一城。 [[6]](#note-6)

<a id="event-7"></a>

7. **魏请合纵，虞卿说赵王应允。** 魏国提出和赵国合纵。虞卿先后指出魏与赵都有失算之处：同作一事，胜利时大国多得好处，失败时小国多担祸患。魏国愿冒风险，赵国却拒绝有利的结盟。赵王听从虞卿，同意与魏合纵。 [[7]](#note-7)

<a id="event-8"></a>

8. **虞卿困居大梁后著《虞氏春秋》。** 范雎借秦国之势追索魏齐。虞卿辞相，与魏齐一同逃离赵国，最后困在大梁。魏齐死后，虞卿不得志，著书论历代治国得失，世传《虞氏春秋》。 [[8]](#note-8)

## 传末附读

<a id="event-9"></a>

9. **传末司马迁论与唐代司马贞述赞。** 司马迁评赵胜虽是乱世佳公子，却未能察见受上党的长远代价。他又称虞卿料事精审，却因舍不得弃魏齐而陷于穷困，最后以著书见于后世。唐代司马贞另作述赞，将杀姬、李同出战、毛遂定盟与虞卿著书并举。 [[9]](#note-9)

### 5. 虞卿穿草履携长柄笠游说赵王

[返回正文第5条](#event-5)

**[《史记·平原君虞卿列传》P009（节录）](../../拆分史书/史记/卷076.md#p009)** · [三家注p9](../../拆分史书/史记/卷076.md#part-1-p9)

> 虞卿者，游說之士也。躡蹻檐簦說趙孝成王。一見，賜黃金百鎰，白璧一雙；再見，爲趙上卿，故號爲虞卿。

> 秦旣解邯鄲圍，而趙王入朝，使趙郝約事於秦，割六縣而媾。

### 7. 魏请合纵，虞卿说赵王应允

[返回正文第7条](#event-7)

**[《史记·平原君虞卿列传》P016（节录）](../../拆分史书/史记/卷076.md#p016)** · [三家注p16](../../拆分史书/史记/卷076.md#part-1-p16)

> 今魏以小國請其禍，而王以大國辭其福，臣故曰王過，魏亦過。竊以爲從便。」王曰：「善。」乃合魏爲從。

<a id="note-8"></a>

### 8. 虞卿困居大梁后著《虞氏春秋》

[返回正文第8条](#event-8)

**[《史记·平原君虞卿列传》P017（节录）](../../拆分史书/史记/卷076.md#p017)** · [三家注p17](../../拆分史书/史记/卷076.md#part-1-p17)

> 魏齊已死，不得意，乃著書，上採春秋，下觀近世，曰節義、稱號、揣摩、政謀，凡八篇。以刺譏國家得失，世傳之曰虞氏春秋。

**归年说明：** [《通鉴》卷005](../../拆分史书/资治通鉴/卷005.md#L436)把弃相与魏齐之死系于[前259年](bce-0259.md#note-4)，没有交代《虞氏春秋》写成之年。[《十二诸侯年表》表序](../../拆分史书/史记/卷014.md#part-2-p1)同记八篇，《汉书·艺文志》仓内[电子全文第6305行](../../史书/002-汉书/汉书-CCDH.txt)著录十五篇，书目所见篇数不为写作纪年。

### 9. 传末司马迁论与唐代司马贞述赞

[返回正文第9条](#event-9)

**[《史记·平原君虞卿列传》P018（节录）](../../拆分史书/史记/卷076.md#p018)** · [三家注p18](../../拆分史书/史记/卷076.md#part-1-p18)

> 虞卿料事揣情，爲趙畫策，何其工也！及不忍魏齊，卒困於大梁，庸夫且知其不可，況賢人乎？然虞卿非窮愁，亦不能著書以自見於後世云。

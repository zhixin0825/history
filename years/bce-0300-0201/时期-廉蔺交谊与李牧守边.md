# 战国晚期｜廉蔺交谊与李牧守边（未定年）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷081完整原文](../../sources/摘录/史记-卷081-廉颇蔺相如列传.md) · [纪年考证](../../meta/考证/史记-卷081-纪年与异说.md)

廉颇、蔺相如、赵奢与李牧的主要战事分别见原有年页。这里从赵惠文王时的缪贤前事读至赵国晚期的将领生平，多数情节只能判断发生在某次出使、授官或出奔前后。

<a id="reading-start"></a>

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **缪贤的亡燕之计与蔺相如早年。** 缪贤有罪，打算投奔曾在边地向自己示好的燕王。门下蔺相如认为燕王本因赵强且缪贤受宠才愿结交，如今出逃只会被捆送回赵。缪贤依言向赵王请罪，果然获赦。后来缪贤以此向赵王推荐蔺相如使秦。 [[1]](#note-1)

<a id="event-2"></a>

2. **蔺相如避让廉颇，廉颇负荆谢罪。** 相如在渑池会后升上卿。廉颇不平，扬言相见必辱之。相如在朝廷托病，在路上掉转车子，避开与廉颇当面争执。门客以为他怕廉颇，相如解释两人若内斗，强秦便会趁机加兵，所以先顾国家。廉颇闻言袒背负荆登门谢罪，两人成为生死之交。 [[2]](#note-2)

<a id="event-3"></a>

3. **赵奢追缴贵族赋税并主持国赋。** 赵奢任田部吏，依法追征平原君家的租税，处死其家九名管事。赵奢向平原君说明贵族坏法终会削弱赵国，也无从保护宗室。平原君转而荐举他，赵王任其治赋，府库因此充实。 [[3]](#note-3)

<a id="event-4"></a>

4. **赵奢以父亲的身份评赵括论兵。** 赵括年轻时谈论兵事，自以为无人能及。赵奢虽未能在辩论中驳倒儿子，仍认为他看轻战争的生死风险，不可领军。长平换将时，赵括母也从实际待人、待兵的差别劝赵王慎用赵括。父子论兵和母亲上书分属前事与[前260年](bce-0260.md#note-1)的临行进谏。 [[4]](#note-4)

<a id="event-5"></a>

5. **廉颇失势后旧客离去，复任后回归。** 廉颇退出长平战场后失势，宾客相继离开。等他重新为将，旧客又来。他本欲斥退，有人以市道交往为喻，直言宾客依随的是权势，得失之后本会分合。 [[5]](#note-5)

<a id="event-6"></a>

6. **廉颇奔魏后未能返赵，终老楚国。** 廉颇奔大梁后久居魏国。赵王有意复用，命使者试探其体力；廉颇当面吃饭、披甲上马，郭开却收买使者，谎称他频频如厕，赵王遂未召回。后来楚国秘密迎他为将，未立战功。廉颇怀念赵国士兵，终于死在寿春。 [[6]](#note-6)

<a id="event-7"></a>

7. **李牧守边用收保，去职后获召回。** 李牧在代、雁门长期守赵北边，遇敌先退守，保存百姓与牲畜。赵王一度认为他怯战，改派他人。继任者屡次接战失利，边地耕牧中断，赵王才重新起用李牧，准他仍按旧办法守边。 [[7]](#note-7)

<a id="event-8"></a>

8. **李牧复任后击退匈奴。** 李牧回边地继续休养士卒，随后整军反击来袭的匈奴，取得大胜。传文还记襜襤、东胡、林胡受到影响，并称此后十余年匈奴不敢靠近赵国边城。战果、兵力与年距均是列传所载。 [[8]](#note-8)

<a id="event-9"></a>

9. **司马迁评相如智勇，司马贞追述廉颇李牧之功。** 司马迁以交聘时相如敢承担杀身之险、回赵能顾全大局而礼让廉颇为其智勇。唐人司马贞的述赞把完璧、渑池、负荆和安边并列。两段评赞反映作者的取舍。 [[9]](#note-9)

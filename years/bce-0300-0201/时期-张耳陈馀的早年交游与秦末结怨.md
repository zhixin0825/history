# 战国末至汉初｜张耳陈馀的早年交游与秦末结怨（时期阅读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷089完整读本](../../sources/摘录/史记-卷089-张耳陈馀列传.md) · [纪年与异说](../../meta/考证/史记-卷089-纪年与异说.md)

秦灭魏后的避祸、赵燕间未确月日的轶事及太史公论在此合读。逐年史事从年页进入。

<a id="event-1"></a>

1. **张耳游于大梁、外黄，靠交游积累声望。** 张耳是大梁人，年轻时赶上魏公子无忌在世，曾做他的门客。张耳一度逃亡到外黄。当地一位富家女嫁给平庸男子，离开丈夫去投靠父亲的门客。那人认识张耳，劝她若要另择贤夫便跟随张耳。她依言请人办妥离婚，改嫁张耳。张耳当时离家在外，妻家厚加资助，他因而能招来远道而来的宾客。后来他入魏国任外黄县令，贤名更著。 [[1]](#note-1)

<a id="event-2"></a>

2. **陈馀游赵，与张耳结为深交。** 陈馀同是大梁人，喜欢儒学，屡次到赵地苦陉游历。富户公乘氏看重他的才干，把女儿嫁给他。陈馀较年轻，以事父之礼敬重张耳，两人约定可以为对方舍生。 [[2]](#note-2)

<a id="event-3"></a>

3. **秦灭魏后张耳、陈馀改名到陈县避祸。** 秦灭大梁时张耳家在外黄。刘邦还是布衣时曾随他交游，在那里住过几个月。灭魏过了数年，秦廷听说张、陈是魏国名士，悬赏千金捕张耳、五百金捕陈馀。两人改名逃到陈县，在里门当差谋生。陈馀有次遭里吏责打，张耳用脚提醒他忍住；事后拉他到桑树下，劝他不要因为眼前的小辱与一个里吏拼命。陈馀同意。秦廷仍在悬赏缉拿，二人反倒借看守里门的职务在里中传达命令。 [[3]](#note-3)

<a id="event-4"></a>

4. **张耳和陈馀在张楚起兵时受用。** 陈胜入陈后，张耳、陈馀进见，劝他先西攻而不要独王陈。陈胜仍称王，后来接受陈馀经略河北的建议，派武臣为将，张、陈随军。 [[4]](#note-4)

<a id="event-5"></a>

5. **燕军扣留武臣，无名养卒设辞劝还。** 韩广到燕被拥立为燕王。武臣与张、陈北略燕界，武臣轻装出行时被燕军扣住，燕将索要半个赵国，且杀多名使者。一个养卒自荐赴燕，反说张、陈也有称王之志，若燕杀武臣，二人就可分立并以报仇为名合攻燕。燕将信以为然，放走武臣，由这位养卒驾车送回。所谓张、陈盼望武臣被杀，是养卒的游说，并非二人的自白。 [[5]](#note-5)

<a id="event-6"></a>

6. **巨鹿解围后，司马迁和司马贞回看两友反目。** 巨鹿解围后，张耳与陈馀的裂痕继续扩大。司马迁追问何以困顿时许死、据国后反相攻灭；司马贞在篇首则认为张耳的封爵足与吴芮同列世家，篇末以述赞归纳旧交解印、势利结怨。 [[6]](#note-6)

<a id="event-7"></a>

7. **追随张敖的宾客及其子孙继续任官。** 张敖被赦后封宣平侯。汉廷看重随张敖入关的门客，有人出任诸侯相、郡守；传文又说这些门客的后辈到孝惠、高后、孝文、孝景间有人位至二千石。 [[7]](#note-7)

### 1. 张耳游于大梁、外黄，靠交游积累声望

[返回正文第1条](#event-1)

[《史记·张耳陈馀列传》P001](../../sources/摘录/史记-卷089-张耳陈馀列传.md#p001) · [三家注p1](../../sources/史记三家注/卷089.md#p1)

> 張耳者，大梁人也。其少時，及魏公子毋忌爲客。張耳嘗亡命游外黃。外黃富人女甚美，嫁庸奴，亡其夫，去抵父客。父客素知張耳，乃謂女曰：「必欲求賢夫，從張耳。」女聽，乃卒爲請決，嫁之張耳。張耳是時脫身游，女家厚奉給張耳，張耳以故致千里客。乃宦魏爲外黃令。名由此益賢。

**归年说明：** 魏无忌去世在[前243年](bce-0243.md#note-3)；既有年页可以限定从游在此前，张耳任外黄令的始年未详。

### 3. 秦灭魏后张耳、陈馀改名到陈县避祸

[返回正文第3条](#event-3)

[《史记·张耳陈馀列传》P003](../../sources/摘录/史记-卷089-张耳陈馀列传.md#p003) · [三家注p3](../../sources/史记三家注/卷089.md#p3)

> 秦之滅大梁也，張耳家外黃。高祖爲布衣時，嘗數從張耳游，客數月。秦滅魏數歲，已聞此兩人魏之名士也，購求有得張耳千金，陳餘五百金。張耳、陳餘乃變名姓，俱之陳，爲里監門以自食。兩人相對。里吏嘗有過笞陳餘，陳餘欲起，張耳躡之，使受笞。吏去，張耳乃引陳餘之桑下而數之曰　：「始吾與公言何如？今見小辱而欲死一吏乎？」陳餘然之。秦詔書購求兩人，兩人亦反用門者以令里中。

**归年说明：** 大梁陷落在[前225年](bce-0225.md#note-1)。悬赏在灭魏数年后，刘邦布衣时从游也无可独立定位的年月。

### 4. 张耳和陈馀在张楚起兵时受用

[返回正文第4条](#event-4)

[《史记·张耳陈馀列传》P004](../../sources/摘录/史记-卷089-张耳陈馀列传.md#p004) · [三家注p4](../../sources/史记三家注/卷089.md#p4)

> 陳涉起蘄，至入陳，兵數萬。張耳、陳餘上謁陳涉。涉及左右生平數聞張耳、陳餘賢，未嘗見，見即大喜。

[《史记·张耳陈馀列传》P005](../../sources/摘录/史记-卷089-张耳陈馀列传.md#p005) · [三家注p5](../../sources/史记三家注/卷089.md#p5)

> 陳中豪傑父老乃說陳涉曰：「將軍身被堅執銳，率士卒以誅暴秦，復立楚社稷，存亡繼絕，功德宜爲王。且夫監臨天下諸將，不爲王不可，願將軍立爲楚王也。」陳涉問此兩人，兩人對曰：「夫秦爲無道，破人國家，滅人社稷，絕人後世，罷百姓之力，盡百姓之財。將軍瞋目張膽，出萬死不顧一生之計，爲天下除殘也。今始至陳而王之，示天下私。願將軍毋王，急引兵而西，遣人立六國後，自爲樹黨，爲秦益敵也。敵多則力分，與衆則兵彊。如此野無交兵，縣無守城，誅暴秦，據咸陽以令諸侯。諸侯亡而得立，以德服之，如此則帝業成矣。今獨王陳，恐天下解也。」陳涉不聽，遂立爲王。

[《史记·张耳陈馀列传》P006](../../sources/摘录/史记-卷089-张耳陈馀列传.md#p006) · [三家注p6](../../sources/史记三家注/卷089.md#p6)

> 陳餘乃復說陳王曰：「大王舉梁、楚而西，務在入關，未及收河北也。臣嘗游趙，知其豪桀及地形，願請奇兵北略趙地。」於是陳王以故所善陳人武臣爲將軍，邵騷爲護軍，以張耳、陳餘爲左右校尉，予卒三千人，北略趙地。

**归年说明：** 这是二人从隐居入反秦政权的有年入口，见[前209年](bce-0209.md#note-11)。

<a id="note-5"></a>

### 5. 燕军扣留武臣，无名养卒设辞劝还

[返回正文第5条](#event-5)

[《史记·张耳陈馀列传》P013](../../sources/摘录/史记-卷089-张耳陈馀列传.md#p013) · [三家注p13](../../sources/史记三家注/卷089.md#p13)

> 韓廣至燕，燕人因立廣爲燕王。趙王乃與張耳、陳餘北略地燕界。趙王閒出，爲燕軍所得。燕將囚之，欲與分趙地半，乃歸王。使者往，燕輒殺之以求地。張耳、陳餘患之。有厮養卒謝其舍中曰：「吾爲公說燕，與趙王載歸。」舍中皆笑曰：「使者往十餘輩，輒死，若何以能得王？」乃走燕壁。燕將見之，問燕將曰：「知臣何欲？」燕將曰：「若欲得趙王耳。」曰：「君知張耳、陳餘何如人也？」燕將曰：「賢人也。」曰：「知其志何欲？」曰：「欲得其王耳。」趙養卒乃笑曰：「君未知此兩人所欲也。夫武臣、張耳、陳餘杖馬箠下趙數十城，此亦各欲南靣而王，豈欲爲卿相終己邪？夫臣與主豈可同日而道哉，顧其勢初定，未敢參分而王，且以少長先立武臣爲王，以持趙心。今趙地已服，此兩人亦欲分趙而王，時未可耳。今君乃囚趙王。此兩人名爲求趙王，實欲燕殺之，此兩人分趙自立。夫以一趙尚易燕，況以兩賢王左提右挈，而責殺王之罪，滅燕易矣。」燕將以爲然，乃歸趙王，養卒爲御而歸。

**归年说明：** 韩广称燕王已有[前209年](bce-0209.md#note-19)年据，武臣被杀另系[前208年](bce-0208.md#note-11)。扣留、返还夹于前后，无独立确月。

### 6. 巨鹿解围后，司马迁和司马贞回看两友反目

[返回正文第6条](#event-6)

[《史记·张耳陈馀列传》P000](../../sources/摘录/史记-卷089-张耳陈馀列传.md#p000) · [三家注p0](../../sources/史记三家注/卷089.md#p0)

> 〔索隱〕張耳、吳芮勢侔楚漢，位埒齊韓，俱懷從沛之心，咸享誓河之業，爵在列侯之上，家傳累代之基。長沙旣曰令終，趙王亦謂善始。並可列同世家焉。

[《史记·张耳陈馀列传》P030](../../sources/摘录/史记-卷089-张耳陈馀列传.md#p030) · [三家注p30](../../sources/史记三家注/卷089.md#p30)

> 太史公曰：張耳、陳餘，世傳所稱賢者；其賔客厮役，莫非天下俊桀，所居國無不取卿相者。然張耳、陳餘始居約時，相然信以死，豈顧問哉。及據國爭權，卒相滅亡，何鄉者相慕用之誠，後相倍之戾也！豈非以利交哉？名譽雖高，賔客雖盛，所由殆與大伯、延陵季子異矣。

[《史记·张耳陈馀列传》P031](../../sources/摘录/史记-卷089-张耳陈馀列传.md#p031) · [三家注p31](../../sources/史记三家注/卷089.md#p31)

> 索隱述贊曰：張耳、陳餘，天下豪俊。忘年羈旅，刎頸相信。耳圍鉅鹿，餘兵不進。張旣望深，陳乃去印。勢利傾奪，隙末成舋。

**归年说明：** [前207年交印](bce-0207.md#note-11)和[前204年井陉](bce-0204.md#note-1)仍在实年。篇首是司马贞《索隐》，篇末两段分别是司马迁和司马贞的评论。

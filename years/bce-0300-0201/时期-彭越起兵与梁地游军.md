# 秦末楚汉之际｜彭越起兵与梁地游军（时期阅读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷090完整读本](../../sources/摘录/史记-卷090-魏豹彭越列传.md) · [纪年与异说](../../meta/考证/史记-卷090-纪年与异说.md)

彭越初聚部众及梁地供粮的相关材料在此按先后阅读。昌邑合兵、魏豹归附与反汉、外黄归汉、垓下合兵和封梁皆随各年页。

<a id="event-1"></a>

1. **彭越在巨野泽观望反秦局势。** 彭越字仲，昌邑人，常在巨野泽捕鱼，也聚众为盗。陈胜、项梁相继起兵后，有少年劝他效法各路豪杰。彭越以两龙正在相争作比，决定暂等。比喻不提供确定年份，也没有明说两龙专指哪两人。 [[1]](#note-1)

<a id="event-2"></a>

2. **泽中少年推举彭越，部众逐渐增多。** 过了一年多，一百余名少年强请彭越为首。他约次日日出集合，迟到者处斩。仍有十余人晚到，最后一人近中午才来。彭越说不能全杀，只斩最后一人；众人起初当成虚言，他果真执行，又设坛祭告部众。众人震惧，服从其令。此后彭越略地、招收诸侯散兵，兵力增至千余。故事只给相对年距。 [[2]](#note-2)

<a id="event-3"></a>

3. **先在巨野泽收散兵，后逐步加入楚汉竞争。** 助刘邦攻昌邑未克后，彭越一度在巨野泽集聚魏国散卒。项羽回到东方时，彭越已有万余人尚无隶属；田荣反楚后，他带兵打击萧公角，随后在外黄率部归汉并任魏相国。 [[3]](#note-3)

<a id="event-4"></a>

4. **彭越夺取梁地城邑，供给汉军粮食。** 彭越从彭城败后退居河上，逐步在梁地往来截断楚军运输。本传又说取昌邑附近二十余城，获粮十余万斛供汉。 [[4]](#note-4)

<a id="event-5"></a>

5. **太史公与索隐评论魏豹和彭越。** 司马迁追问两人有谋略且一度称王，为什么在战败后受拘系而仍求生。司马贞的韵语以魏国灭亡和彭越从供粮功臣走到被诛收束。 [[5]](#note-5)

### 1. 彭越在巨野泽观望反秦局势

[返回正文第1条](#event-1)

[《史记·魏豹彭越列传》P004](../../sources/摘录/史记-卷090-魏豹彭越列传.md#p004) · [三家注p4](../../sources/史记三家注/卷090.md#p4)

> 彭越者，昌邑人也，字仲。常漁鉅野澤中，爲羣盜。陳勝、項梁之起，少年或謂越曰：「諸豪桀相立畔秦，仲可以來，亦效之。」彭越曰：「兩龍方鬬，且待之。」

**归年说明：** 陈胜在[前209年](bce-0209.md#note-7)起兵，项梁、项羽也在该年[会稽起事](bce-0209.md#note-24)。彭越是否在该年作答待考。

<a id="note-2"></a>

### 2. 泽中少年推举彭越，部众逐渐增多

[返回正文第2条](#event-2)

[《史记·魏豹彭越列传》P005](../../sources/摘录/史记-卷090-魏豹彭越列传.md#p005) · [三家注p5](../../sources/史记三家注/卷090.md#p5)

> 居歲餘，澤閒少年相聚百餘人，往從彭越，曰：「請仲爲長。」越謝曰：「臣不願與諸君。」少年彊請，乃許。與期旦日日出會，後期者斬。旦日日出，十餘人後，後者至日中。於是越謝曰：「臣老，諸君彊以爲長。今期而多後，不可盡誅，誅最後者一人。」令校長斬之。皆笑曰：「何至是？請後不敢。」於是越乃引一人斬之，設壇祭，乃令徒屬。徒屬皆大驚，畏越，莫敢仰視。乃行略地，收諸侯散卒，得千餘人。

**归年说明：** 此段只有“居歲餘”，可接后来[前207年助攻昌邑](bce-0207.md#note-15)，未给可独立钉定的起兵年月。

<a id="note-3"></a>

### 3. 先在巨野泽收散兵，后逐步加入楚汉竞争

[返回正文第3条](#event-3)

[《史记·魏豹彭越列传》P006](../../sources/摘录/史记-卷090-魏豹彭越列传.md#p006) · [三家注p6](../../sources/史记三家注/卷090.md#p6)

> 沛公之從碭北擊昌邑，彭越助之。昌邑未下，沛公引兵西。彭越亦將其衆居鉅野中，收魏散卒。項籍入關，王諸侯，還歸，彭越衆萬餘人毋所屬。漢元年秋，齊王田榮畔項王，漢乃使人賜彭越將軍印，使下濟陰以擊楚。楚命蕭公角將兵擊越，越大破楚軍。漢王二年春，與魏王豹及諸侯東擊楚，彭越將其兵三萬餘人歸漢於外黃。漢王曰：「彭將軍收魏地得十餘城，欲急立魏後。今西魏王豹亦魏王咎從弟也，真魏後。」乃拜彭越爲魏相國，擅將其兵，略定梁地。

**归年说明：** [前206年授印异说](bce-0206.md#note-21)与[前205年归汉](bce-0205.md#note-15)对应不同阶段。

<a id="note-4"></a>

### 4. 彭越夺取梁地城邑，供给汉军粮食

[返回正文第4条](#event-4)

[《史记·魏豹彭越列传》P007](../../sources/摘录/史记-卷090-魏豹彭越列传.md#p007) · [三家注p7](../../sources/史记三家注/卷090.md#p7)

> 漢王之敗彭城解而西也，彭越皆復亡其所下城，獨將其兵北居河上。漢王三年，彭越常往來爲漢游兵，擊楚，絕其後糧於梁地。漢四年冬，項王與漢王相距滎陽，彭越攻下睢陽、外黃十七城。項王聞之，乃使曹咎守成皐，自東收彭越所下城邑，皆復爲楚。越將其兵北走穀城。漢五年秋，項王之南走陽夏，彭越復下昌邑旁二十餘城，得穀十餘萬斛，以給漢王食。

**归年说明：** 正文中的“漢五年秋”若依一般汉年换算，晚于本传自己所述垓下和封王；《汉书·韩彭英卢吴传》此处省去“五年秋”，仍将攻城得粮叙在阳夏之后、固陵与垓下之前。暂按战中供粮阅读，未定到任何一秋。

<a id="note-5"></a>

### 5. 太史公与索隐评论魏豹和彭越

[返回正文第5条](#event-5)

[《史记·魏豹彭越列传》P011](../../sources/摘录/史记-卷090-魏豹彭越列传.md#p011) · [三家注p11](../../sources/史记三家注/卷090.md#p11)

> 太史公曰：魏豹、彭越雖故賤，然已席卷千里，南靣稱孤，喋血乘勝日有聞矣。懷畔逆之意，及敗，不死而虜囚，身被刑戮，何哉？中材已上且羞其行，況王者乎！彼無異故，智略絕人，獨患無身耳。得攝尺寸之柄，其雲蒸龍變，欲有所會其度，以故幽囚而不辭云。

[《史记·魏豹彭越列传》P012](../../sources/摘录/史记-卷090-魏豹彭越列传.md#p012) · [三家注p12](../../sources/史记三家注/卷090.md#p12)

> 索隱述贊曰：魏咎兄弟，因時而王。豹後屬楚，其國遂亡。仲起昌邑，歸漢外黃。往來聲援，再續軍糧。徵兵不往，葅醢何傷。

**归年说明：** 两段是不同作者的史评。彭越处置仍接[前196年](../bce-0200-0101/bce-0196.md#note-6)。

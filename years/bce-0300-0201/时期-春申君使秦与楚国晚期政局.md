# 战国晚期｜春申君使秦与楚国晚期政局（时期阅读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷078完整读本](../../sources/摘录/史记-卷078-春申君列传.md) · [纪年与异说](../../meta/考证/史记-卷078-纪年与异说.md)

本页由华阳战后读至楚考烈王晚年。上书的史事例证、赵使见珠履、兰陵任职及楚宫传闻多只能按先后或约略范围理解。已能归年的事件从对应年页进入。

<a id="event-1"></a>

1. **秦胜华阳后，黄歇入秦说止伐楚。** 华阳失利后，韩魏在秦的压力下屈服，秦拟借韩魏之力攻楚。黄歇上书，秦昭王接受亲楚的建议。此事由华阳与其后的楚秦交涉定位，黄歇抵秦、递交书信与秦停止原计划各无独立确日。 [[1]](#note-1)

<a id="event-2"></a>

2. **黄歇以秦已得之利和吴、智之败立论。** 黄歇先用两虎相斗与累棋将倾为喻，又数说秦在韩、魏已得的土地和威势。随后他以吴用越而伐齐、智伯借韩魏围赵为鉴，指出功业正在扩张时也可能因盟友反戈而难以收局。 [[2]](#note-2)

<a id="event-3"></a>

3. **黄歇推演攻楚的后果，提出亲楚方案。** 秦若借道韩魏，旧怨可能使秦军难返；若从随水右岸攻楚，所得多为山谷水泽。黄歇又设想齐魏趁秦楚相持夺肥地，劝秦联楚以制韩魏，再进而制齐。取地、进兵和迫使诸国屈服均为策辞中的假设。 [[3]](#note-3)

<a id="event-4"></a>

4. **战国公子争士，楚赵宾客以服饰较胜。** 诸侯养士形成声势，四君各以门客辅国。平原君使者访楚，试以玳瑁与珠玉夸耀，春申君上客皆穿珠履出见，使者反而羞惭。这则叙事没有使节到访的确年。 [[4]](#note-4)

<a id="event-5"></a>

5. **楚破鲁后，荀卿在兰陵任职。** 黄歇主持楚政期间，楚向北扩大控制，并以荀卿为兰陵令。兰陵任命和失官之间尚有时间跨度，取鲁、徙鲁君与最后灭鲁也有异年；灭鲁在既有[前256年页](bce-0256.md#note-3)合读。 [[5]](#note-5)

<a id="event-6"></a>

6. **朱英以秦军东进和陈地受压提醒楚廷。** 朱英认为秦对楚的进军条件发生了变化：旧有通道不好行军，魏土再失则陈地更加靠近秦军。楚东迁寿春以及秦置东郡、迁卫君各有年页，朱英说辞不再单列一个确年。 [[6]](#note-6)

<a id="event-7"></a>

7. **李园进妹的传闻与楚王位交接。** 列传把李园使妹妹入楚宫、其子被立为太子以及私蓄死士写成一段有因果的故事。最早筹谋年份和幽王血缘无可靠独立证据，篇末古注还举楚王其他子嗣。黄歇遇害和幽王承位已归[前238年](bce-0238.md#note-4)。 [[7]](#note-7)

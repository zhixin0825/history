# 李斯入秦与秦廷奏议｜时期阅读

[李斯列传原文与释读](../../sources/摘录/史记-卷087-李斯列传.md) · [纪年与异说](../../meta/考证/史记-卷087-纪年与异说.md) · [本世纪目录](README.md)

本页汇集登场前事、未确年轶事、奏议细读和史家评语。可确年史事沿文内入口进入统一编年。

<a id="reading-start"></a>

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **李斯由上蔡入秦。** 李斯年轻时做过郡吏，借厕鼠与仓鼠的处境思考如何择地立身。他从荀卿学成后，判断秦国最有可能让他施展所学，于是辞师西行。入秦与庄襄王去世的联系见[前247年](bce-0247.md#note-3)，具体学业年次无考。 [[1]](#note-1)

<a id="event-2"></a>

2. **李斯以宠极必衰自警。** 李由告归咸阳时，百官来向李斯祝寿。婚配使李氏与秦王室亲近，李斯自己却想起荀卿关于事物忌盛的告诫。这场宴会没有纪年。 [[2]](#note-2)

<a id="event-3"></a>

3. **宗室公子高请随葬骊山。** 公子高想逃亡，又怕族人同受牵连，便上书请求随始皇而死、葬在骊山脚下。二世答应并赐钱办丧葬。传文没有说这一决定与哪一场已知的清洗同日。 [[3]](#note-3)

<a id="event-4"></a>

4. **李斯《督责书》的四层说理及其后果。** 李斯先说重责可使臣下向君主尽力，再引申不害贬抑尧、禹的劳身，接着以必罚与险势为例，最后主张君主独断、排斥直谏。二世采纳后，重征重刑相继加深。这是[前208年上书](bce-0208.md#sj087-p020)的细读入口。 [[4]](#note-4)

<a id="event-5"></a>

5. **李斯狱书与三川守案。** 李斯反称七件事功为罪，试图以反语向二世自陈。赵高截住奏书，又使人假作官员复问，李斯不敢改口。李由死讯与李斯受刑的次第在各书有差；两人的结局均可由[前208年](bce-0208.md)进入对应史料。 [[5]](#note-5)

<a id="event-6"></a>

6. **史家如何评李斯的功业和终局。** 司马迁肯定李斯助秦并天下，也批评他在保爵、顺从重刑和改变继承安排上的取舍。司马贞述赞用两种鼠的处境回照他从小吏到显宦，再到死刑的轨迹。 [[6]](#note-6)

# 汉书张耳陈馀的交游与赵地争夺

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **张耳早年与外黄婚事。** 张耳是大梁人，年轻时给魏公子毋忌做过门客。逃亡到外黄时，一个富家女子厌恶丈夫而投奔父亲的旧客，听他指点请求解除原来的婚姻，改嫁张耳。女家对张耳资助优厚，张耳因而招来千里以外的宾客，后来做了外黄令。 [[1]](#note-1)


<a id="event-2"></a>

2. **陈馀与张耳结为生死之交。** 陈馀也是大梁人，喜好儒学，游历到赵地苦陉，娶当地公乘氏的女儿。陈馀年轻，像侍奉父亲一样对待张耳，两人立下生死相托的交情。 [[2]](#note-2)


<a id="event-3"></a>

3. **张陈避秦购捕。** 刘邦没有官职时曾跟从张耳游历。秦灭魏后悬赏捉拿张耳、陈馀，两人更改姓名到陈地做里门的看守。陈馀因小过挨打，张耳按住他叫他忍下，事后责问何必因小辱死在一个小吏手里，陈馀认错。 [[3]](#note-3)


<a id="event-4"></a>

4. **武臣北略赵地与范阳归降。** 张耳、陈馀请求夺取赵地。陈王派武臣率兵三千，二人为校尉，从白马渡河。他们向各县豪杰列举秦的戍役、横征和苛法，鼓动他们起兵，招集数万人。攻下十余城后，蒯通先说范阳令归降，又请武臣授侯印；赵地三十余城闻讯不战而下。 [[4]](#note-4)


<a id="event-5"></a>

5. **武臣自立赵王。** 到邯郸时，两人听说周章退兵、陈王部下有人因谗获罪，也怨恨自己只有校尉官。他们以控制赵地和躲避谗害为由劝武臣自立。武臣称赵王，任陈馀为大将军、张耳为丞相。 [[5]](#note-5)


<a id="event-6"></a>

6. **陈王承认赵王与赵军分略。** 陈王本欲灭武臣等人满门，听相国房君劝说，改拘其家属于宫中，封张敖为成都君，并遣使祝贺、催促赵军西攻。张耳、陈馀猜测楚灭秦后会攻赵，劝武臣占燕、代和河内以自保。武臣派韩广、李良、张黶分别向燕、常山、上党进军。 [[6]](#note-6)


<a id="event-7"></a>

7. **韩广王燕与赵王获释。** 燕人拥立韩广，武臣在燕境被捕，燕军扣王索取土地并杀来使。一名养卒说服燕将：张陈也想称王，杀武臣只会给两人分赵报复的理由。燕将放人，养卒亲自驾车和武臣回赵。 [[7]](#note-7)


<a id="event-8"></a>

8. **李良杀武臣与赵歇继立。** 李良受秦人诱降书，路遇武臣姐姐因失礼生怨，杀她后袭击邯郸，又杀武臣。张耳、陈馀因赵人通风报信逃脱，收集数万兵，听人劝告求得赵国后人赵歇，拥为赵王，立都信都。 [[8]](#note-8)


<a id="event-9"></a>

9. **张耳分封常山。** 赵歇回信都，张耳跟随项羽入关。项羽分封诸侯时顾及张耳旧日声名，分赵地立他为常山王，治信都，改其名为襄国。 [[9]](#note-9)


<a id="event-10"></a>

10. **高祖轻慢张敖与赵臣起谋。** 高祖从平城经过赵国，张敖按女婿礼亲进饭菜，高祖却傲慢辱骂。张耳旧客貫高、赵午想替君报辱，张敖咬指出血斥责，列举刘邦扶助其家复国之恩。赵臣于是相约自行承担谋刺罪责，不牵连张敖。 [[10]](#note-10)


<a id="event-11"></a>

11. **张敖降侯与赵客获录用。** 张敖获释后照旧与鲁元公主为婚，被封宣平侯。皇帝委任张敖宾客为诸侯相或郡守，详事见田叔传；惠帝至景帝间，赵客子孙也有人任二千石官。 [[11]](#note-11)


<a id="event-12"></a>

12. **鲁国与张氏后续封爵。** 惠帝时齐王献城阳郡奉鲁元公主。高后元年鲁元去世，后文叙张敖卒、张偃为鲁王以及年幼而获封侯辅佐的两位异母兄弟。高后死后三人被废，文帝又封张偃为南宫侯。后世张生获罪，武帝复封张偃后人又因不敬除国，平帝封张敖玄孙张庆忌为宣平侯续绝。 [[12]](#note-12)


<a id="event-13"></a>

13. **赞语论张陈聚散。** 赞语称两人门客多是俊杰，困顿时相许生死，掌权时却互争以至相亡，以此论古人何以耻于势利之交。 [[13]](#note-13)

### 4. 武臣北略赵地与范阳归降

[返回正文第4条](#event-4)

<a id="hs032-p006"></a>

**[《汉书·张耳陈馀传》P006](../../sources/摘录/汉书-卷032-张耳陈馀传.md#p006)** · [仓内TXT L6896—L6896](../../sources/本地分卷/汉书/汉书-卷032.md#L6896)

> 耳、餘復說陳王曰：「大王興梁、楚，務在入關，未及收河北也。臣嘗遊趙，知其豪桀，願請奇兵略趙地。」於是陳王許之，以所善陳人武臣為將軍，耳、餘為左右校尉，與卒三千人，從白馬渡河。至諸縣，說其豪桀曰：「秦為亂政虐刑，殘滅天下，北為長城之役，南有五領之戍，外內騷動，百姓罷敝，頭會箕斂以供軍費，財匱力盡，重以苛法，使天下父子不相聊。今陳王奮臂為天下倡始，莫不嚮應，家自為怒，各報其怨，縣殺其令丞，郡殺其守尉。今以張大楚，王陳，使吳廣、周文將卒百萬西擊秦。於此時而不成封侯之業者，非人豪也。夫因天下之力而攻無道之君，報父兄之怨而成割地之業，此一時也。」豪桀皆然其言。乃行收兵，得數萬人，號武信君。下趙十餘城，餘皆城守莫肯下。乃引兵東北擊范陽。范陽人蒯通說其令徐公降武信君，又說武信君以侯印封范陽令。語在通傳。趙地聞之，不戰下者三十餘城。

### 6. 陈王承认赵王与赵军分略

**[《汉书·张耳陈馀传》P008](../../sources/摘录/汉书-卷032-张耳陈馀传.md#p008)** · [仓内TXT L6898—L6898](../../sources/本地分卷/汉书/汉书-卷032.md#L6898)

### 7. 韩广王燕与赵王获释

[返回正文第7条](#event-7)

<a id="hs032-p009"></a>

**[《汉书·张耳陈馀传》P009](../../sources/摘录/汉书-卷032-张耳陈馀传.md#p009)** · [仓内TXT L6899—L6899](../../sources/本地分卷/汉书/汉书-卷032.md#L6899)

> 韓廣至燕，燕人因立廣為燕王。趙王乃與陳、餘北略地燕界。趙王間出，為燕軍所得。燕囚之，欲與分地。使者往，燕輒殺之，以固求地。耳、餘患之。有廝養卒謝其舍曰：「吾為二公說燕，與趙王載歸。」舍中人皆笑曰：「使者往十輩皆死，若何以能得王？」乃走燕壁。燕將見之，問曰：「知臣何欲？」燕將曰：「若欲得王耳。」曰：「君知張耳、陳餘何如人也？」燕將曰：「賢人也。」曰：「其志何欲？」燕將曰：「欲得其王耳。」趙卒笑曰；「君未知兩人所欲也。夫武臣、張耳、陳餘，杖馬箠下趙數十城，亦各欲南面而王。夫臣之與主，豈可同日道哉！顧其勢初定，且以長少先立武臣，以持趙心。今趙地已服，兩人亦欲分趙而王，時未可耳。今君囚趙王，念此兩人名為求王，實欲燕殺之，此兩人分趙而王。夫以一趙尚易燕，況以兩賢王左提右挈，而責殺王，滅燕易矣。」燕以為然，乃歸趙王。養卒為御而歸。

### 8. 李良杀武臣与赵歇继立

[返回正文第8条](#event-8)

<a id="hs032-p010"></a>

**[《汉书·张耳陈馀传》P010](../../sources/摘录/汉书-卷032-张耳陈馀传.md#p010)** · [仓内TXT L6900—L6900](../../sources/本地分卷/汉书/汉书-卷032.md#L6900)

> 李良已定常山，還報趙王，趙王復使良略太原。至石邑，秦兵塞井陘，未能前。秦將詐稱二世使使遺良書，不封，曰：「良嘗事我，得顯幸，誠能反趙為秦，赦良罪，貴良。」良得書，疑不信，之邯鄲益請兵。未至，道逢趙王姊，從百餘騎。良望見，以為王，伏謁道旁。王姊醉，不知其將，使騎謝良。良素貴，起，慚其從官。從官有一人曰：「天下叛秦，能者先立。且趙王素出將軍下，今女兒乃不為將軍下車，請追殺之。」良以得秦書，欲反趙，未決，因此怒，遣人追殺王姊，遂襲邯鄲。邯鄲不知，竟殺武臣。趙人多為耳、餘耳目者，故得脫出。收兵得數萬人。客有說耳、餘曰：「兩君羈旅，而欲附趙，難可獨立；趙後，輔以誼，可就功。」及求得趙歇，立為趙王，居信都。

### 12. 鲁国与张氏后续封爵

# 汉书陈胜项羽与楚地集团的未确年事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **篇中题签陈胜、吴广。** 这一部分先叙陈胜、吴广举兵及张楚始末，后接项籍。题签照TXT原字。 [[1]](#note-1)


<a id="event-2"></a>

2. **葛婴别立襄强，周市略魏。** 葛婴在东城立襄强，得知陈胜已为王后杀襄强回报，自己也被杀。陈胜派周市向魏地，吴广围荥阳不能下，并任上蔡房君蔡赐为上柱国。 [[2]](#note-2)


<a id="event-3"></a>

3. **陈胜称王后与故旧将领疏远。** 陈胜称王约六个月。旧日佣耕朋友到宫中，因随意说旧事被杀，其他故旧于是远离。所信朱防、胡武严查诸将，还私自办理案件，部众由此离心。本段以此解释张楚失败。 [[3]](#note-3)


<a id="event-4"></a>

4. **陈胜的身后影响与守冢。** 陈胜虽死，所派军政人员继续反秦。高祖时在砀设守冢者、维持祭祀，传末概称直到王莽败才绝。 [[4]](#note-4)


<a id="event-5"></a>

5. **篇中题签项籍。** 金戈章节由陈胜转到项籍。题签“项”字按TXT保存。 [[5]](#note-5)


<a id="event-6"></a>

6. **项籍家世。** 项籍字羽，下相人。起兵时本传作二十四岁，叔父项梁是楚将项燕之子。先世做楚将、封于项，故以项为氏。 [[6]](#note-6)


<a id="event-7"></a>

7. **项羽学兵与项梁在吴中聚众。** 项羽学书、剑均半途而废，称要学万人敌，兵法也只求大意。项梁曾靠曹咎疏通栎阳狱事，杀人后带项羽避居吴中，借承办徭役与丧礼来选人、组织宾客子弟。始皇巡会稽、渡浙江时，项羽在观巡人群中说可以取而代之，项梁赶紧捂住他的口，心里却因此看重他。项羽体高力大，吴中子弟也惧他。 [[7]](#note-7)


<a id="event-8"></a>

8. **项羽安葬及项氏旁支。** 汉王按鲁公礼葬项羽于谷城，不诛其旁支，项伯等四人后来封列侯、赐刘姓。封爵各有侯表年，不把本传连叙当同日。 [[8]](#note-8)


<a id="event-9"></a>

9. **班固赞引贾谊《过秦》。** 班固在论赞中先引贾谊的《过秦》，然后另论项羽。 [[9]](#note-9)


<a id="event-10"></a>

10. **《过秦》论商鞅辅秦孝公。** 贾谊认为秦握关中形胜，秦孝公纳商鞅，内定法令、发展耕织和军事，外用连横，故较易取河西。 [[10]](#note-10)


<a id="event-11"></a>

11. **《过秦》论秦势增长与诸侯合纵。** 孝公后数王继取汉中、巴蜀和东部要地。诸侯在四公子等人主持下招士连纵，但屡为秦瓦解而割地。贾谊为议论合举不同时代的人物，不应读为同出一役。 [[11]](#note-11)


<a id="event-12"></a>

12. **《过秦》转过秦末两代。** 孝文王、庄襄王在位不长，文章用简短过渡引出秦始皇。 [[12]](#note-12)


<a id="event-13"></a>

13. **《过秦》论始皇并天下后的控制。** 贾谊以南取越地、北筑长城、禁书销兵和设防关中概括秦始皇政策，指出秦自以为子孙可凭强大守备长保帝业。 [[13]](#note-13)


<a id="event-14"></a>

14. **《过秦》论陈胜应众起兵。** 始皇身后看似余威尚在，陈胜既无世族地位也无富智资源，却以戍卒发难，民间广泛响应，六国旧地的豪杰并起，秦因此覆灭。 [[14]](#note-14)


<a id="event-15"></a>

15. **《过秦》从攻守变化解释成败。** 贾谊以陈胜起事资源远弱于诸侯大军，却能亡秦作对比。秦取得天下靠进攻之势，统一后若不施仁义，则凭险与武力难以守成。 [[15]](#note-15)


<a id="event-16"></a>

16. **班固评项羽兴亡。** 班固录异相传说而惊叹项羽三年崛起，也批评他弃关中、逐义帝，以个人武力经营天下而不反省过失，最终仍自称天亡。这是史家判断，与乌江叙事并存。 [[16]](#note-16)

### 15. 《过秦》从攻守变化解释成败

[返回正文第15条](#event-15)

<a id="hs031-p060"></a>

**[《汉书·陈胜项籍传》P060](../../拆分史书/汉书/卷031.md#p060)** · [仓内TXT L6888—L6888](../../拆分史书/汉书/卷031.md#part-1-L6888)

> 且天下非小弱也；雍州之地，殽函之固，自若也。陳涉之位，不齒於齊、楚、燕、趙、韓、魏、宋、衛、中山之君；鉏耰棘矜，不敵於鉤戟長鎩；適戍之眾，不亢於九國之師；深謀遠慮，行軍用兵之道，非及曩時之士也。然而成敗異變，功業相反，何也？試使山東之國與陳涉度長絜大，比權量力，不可同年而語矣。然秦以區區之地，致萬乘之權，招八州而朝同列，百有餘年，然后以六合為家，殽函為宮。一夫作難而七廟墮，身死人手，為天下笑者，何也？仁誼不施，而攻守之勢異也。

> 周生亦有言，「舜蓋重童子」，項羽又重童子，豈其苗裔邪？何其興之暴也！夫秦失其政，陳涉首難，豪桀蜂起，相與並爭，不可勝數。然羽非有尺寸，乘勢拔起隴畝之中，三年，遂將五諸侯兵滅秦，分裂天下而威海內，封立王侯，政繇羽出，號為「伯王」，位雖不終，近古以來未嘗有也。及羽背關懷楚，放逐義帝，而怨王侯畔己，難矣。自矜功伐，奮其私智而不師古，始霸王之國，欲以力征經營天下，五年卒亡其國，身死東城，尚不覺寤，不自責過失，乃引「天亡我，非用兵之罪」，豈不謬哉！

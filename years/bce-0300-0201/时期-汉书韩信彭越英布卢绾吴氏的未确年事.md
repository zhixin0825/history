# 汉书韩信彭越英布卢绾吴氏的未确年事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **韩信贫困受食与跨下之辱。** 淮阴韩信未被举为官吏，也不会做买卖，常寄食于人；母死无钱葬，仍寻能容万家的高地。亭长妻嫌他来吃饭，提前做饭，韩信不再来。漂洗丝絮的妇人给他饭吃，又责他不必以回报相许。少年以刀剑相辱，他从对方胯下钻过，市人以为怯懦。 [[1]](#note-1)


<a id="event-2"></a>

2. **汉王夺修武兵与发韩信击齐。** 韩信、张耳往来抵御楚军。汉王脱出成皋，渡河至修武，清晨假称汉使入营，取印符更换军将，留张耳守赵，以韩信为相国，发赵地尚未征用的兵攻齐。 [[2]](#note-2)


<a id="event-3"></a>

3. **韩信归楚报漂母及任跨下少年。** 韩信赐漂母千金，给没有把恩德做到最后的亭长百钱，又任侮辱过自己的少年为中尉，向众将说明当年不愿为一时羞辱白死。 [[3]](#note-3)


<a id="event-4"></a>

4. **云梦诱捕与降淮阴侯。** 项王故将鍾離辚因与韩信相善来投；韩信巡县列兵，被告欲反。高祖用陈平计假游云梦来捕信，韩信惧祸，听人劝取鍾離辚首级。故将骂他后自刎，韩信持首赴陈仍被缚，感叹功臣兔死狗烹，至雒阳获赦降侯。 [[4]](#note-4)


<a id="event-5"></a>

5. **韩信称病与羞伍樊噲。** 韩信知高祖忌其能，称病不随朝，日渐怨望。樊噲虽恭敬相迎、自称下臣，韩信离去却感叹不得不与樊噲等同列。 [[5]](#note-5)


<a id="event-6"></a>

6. **高祖韩信论将兵与将将。** 高祖问能领兵多少，韩信称高祖至多领十万人，自己多多益办。高祖问为何仍被擒，韩信答其擅于统率将领，所以能擒自己。 [[6]](#note-6)


<a id="event-7"></a>

7. **韩信和陈豨私议响应。** 陈豨监代地边兵，向韩信告辞时，韩信与其并行，分析再三被告反会令高祖亲往，建议陈豨在外起事、由自己从内响应。传文未载这次私议的年。 [[7]](#note-7)


<a id="event-8"></a>

8. **陈豨反与淮阴侯被杀。** 陈豨反后，高祖亲征，韩信以病不从；传称韩信密遣人与陈豨联络，又图假赦官徒奴而发兵袭吕后和太子。舍人之弟告发，吕后与萧何假报陈豨已死，骗韩信入贺，斩于长乐宫钟室，夷三族。韩信临死悔不用蒯通。 [[8]](#note-8)


<a id="event-9"></a>

9. **蒯通获赦。** 高祖还师时听到韩信遗言，召蒯通想烹杀他；蒯通自辩后获释，完整说辞见蒯通传。 [[9]](#note-9)


<a id="event-10"></a>

10. **彭越分目。** 传文转叙梁王彭越。 [[10]](#note-10)


<a id="event-11"></a>

11. **彭越早年与观望秦末。** 彭越字仲，昌邑人，在鉅野泽捕鱼并做盗。陈胜起事时，有人劝效法，他认为两强方争，应先待形势。 [[11]](#note-11)


<a id="event-12"></a>

12. **彭越以军期整顿初从者。** 百余少年推彭越为首，约日出会合，十余人迟到。彭越仅斩最晚一人，设坛祭告，部下畏服，后来略地并收散卒至千余人。 [[12]](#note-12)


<a id="event-13"></a>

13. **彭越助攻昌邑、受印与归汉。** 彭越助沛公攻昌邑未下，仍居鉅野、收魏散卒。项羽分封后，彭越万人未有所属。田榮反楚之际，传称汉给予彭越将印，彭越击破萧公角。汉二年归汉外黄，率军三万余，汉王以魏豹为王，授彭越魏相国，令其自将定梁。 [[13]](#note-13)


<a id="event-14"></a>

14. **彭越断粮、攻掠与输粟。** 彭城败后彭越失去所下诸城，退到河上。其后作为汉游兵断楚梁地粮道，下十七城，项羽令曹咎留守、自行东收。彭越退穀城，待项羽南走，再取昌邑周边二十余城，以所得十余万斛粟给汉。 [[14]](#note-14)


<a id="event-15"></a>

15. **黥布分目。** 传文转叙黥布，即英布。 [[15]](#note-15)


<a id="event-16"></a>

16. **英布受黥、输驪山与逃亡。** 英布是六人，年轻时被相者说会受刑称王，后来确实坐黥。他输往驪山劳作，结交刑徒中的首领豪杰，率同伴逃往江中成群。 [[16]](#note-16)


<a id="event-17"></a>

17. **英布佐秦末起事、楚军救赵。** 英布投番君并娶其女，击秦军后率众归项梁，攻景驹、秦嘉有功，受封当阳君。项梁死后随宋义、项羽北救赵；项羽斩宋义，以英布先渡，后续楚军破秦军、降章邯。传以英布屡以少胜多解释诸侯服楚。 [[17]](#note-17)


<a id="event-18"></a>

18. **英布称病少助项羽。** 田榮反时英布只遣数千兵赴齐，彭城作战又托病不助。项羽虽责让，却因北有齐赵、西有汉，且仍惜英布之才而未攻他。 [[18]](#note-18)


<a id="event-19"></a>

19. **随何辩使淮南之功与英布剖符。** 刘邦席上折辱随何为腐儒，随何以二十人使淮南能奏效、数万军却难占淮南为证。刘邦以随何为护军中尉。英布剖符为淮南王，都六，领九江、庐江、衡山、豫章。 [[19]](#note-19)


<a id="event-20"></a>

20. **英布东破荆楚。** 英布估计高祖年老不能亲征，其他将领不足惧，先东击荆，杀刘贾、并其兵，又过淮击楚。楚分为三军，不听其阵势易各自溃逃的劝告，果然一军既败、其余散去。 [[20]](#note-20)


<a id="event-21"></a>

21. **卢绾分目。** 传文转叙燕王卢绾。 [[21]](#note-21)


<a id="event-22"></a>

22. **卢绾与高祖的早年交情。** 卢绾与高祖同里同日生，两家父辈相善，儿子长大后也亲密。卢绾随高祖避事举兵，入汉为将军，东征时为太尉并可出入寝所，受宠超过其他大臣，封长安侯。 [[22]](#note-22)


<a id="event-23"></a>

23. **卢绾讨燕与受封。** 卢绾与刘贾攻临江王，继而随高祖平臧荼。高祖想封他又怕群臣不平，诏选有功者，群臣荐卢绾，于是封燕王。其后因陈豨案受疑。 [[23]](#note-23)


<a id="event-24"></a>

24. **陈豨招客、受查与反汉。** 陈豨以边军归己、门客众多引赵相周昌疑惧，朝廷查不法多牵连陈豨，他暗通王黄等。高祖十年太上皇崩后召他，陈豨称病起兵，自立代王、劫掠赵代。高祖赦被胁者，亲征破其军。 [[24]](#note-24)


<a id="event-25"></a>

25. **张胜出使与卢绾暗结陈豨。** 卢绾从东北夹击陈豨，又令张胜出使匈奴。臧荼之子以陈豨败后汉必转攻燕说动张胜秘密借胡兵击燕。卢绾起初请治张胜家罪，知其用意后设法保全其家，让他为燕与匈奴通间，又暗遣范齐赴陈豨处使战局拖延。 [[25]](#note-25)


<a id="event-26"></a>

26. **卢绾家属降汉。** 高后时卢绾妻儿降汉，暂住燕邸。高后病重，虽拟设酒见面，终未见即崩，卢绾妻也病死。 [[26]](#note-26)


<a id="event-27"></a>

27. **卢绾孙受封恶谷侯。** 景帝时卢绾之孙它人以东胡王身份归降，封恶谷侯；该支传到其曾孙时因罪除国。 [[27]](#note-27)


<a id="event-28"></a>

28. **吴芮分目。** 传文转叙长沙王吴芮。 [[28]](#note-28)


<a id="event-29"></a>

29. **吴芮由番君而长沙王及王统终结。** 秦番阳令吴芮得民心，号番君，收英布为婿，率越人应秦末起事。其部将梅鋗助刘邦击析、郦，吴芮随诸侯入关，先为衡山王，后来因梅鋗从入武关有功获徙长沙。长沙王自吴芮传臣、回、右、差，文帝后七年无嗣除国。高祖以诏明定其忠，惠帝、高后时再封吴氏庶支。 [[29]](#note-29)


<a id="event-30"></a>

30. **赞语比较汉初异姓王。** 班固把开国八异姓王的功、权势和结局并观，称多因权变获封、继而相疑败亡。张耳得善终而其子失国，唯吴芮全其始终，五世后才因无嗣断绝，其支族还受恩泽。 [[30]](#note-30)

> 韓信，淮陰人也。家貧無行，不得推擇為吏，又不能治生為商賈，常從人寄食。其母死無以葬，乃行營高燥地，令傍可置萬家者。信從下鄉南昌亭長食，亭長妻苦之，乃晨炊蓐食。食時信往，不為具食。信亦知其意，自絕去。至城下釣，有一漂母哀之，飯信，竟漂數十日。信謂漂母曰：「吾必重報母。」母怒曰：「大丈夫不能自食，吾哀王孫而進食，豈望報乎！」淮陰少年又侮信曰：「雖長大，好帶刀劍，怯耳。」眾辱信曰：「能死，刺我；不能，出跨下。」於是信孰視，俛出跨下。一巿皆笑信，以為怯。

# 汉书魏豹田氏与韩王信的未确年事

[本世纪目录](README.md) · [全部世纪](../README.md)

此处收录本卷未详年次的谈话、交游、奏议和跨年材料。段组中的确年节录亦可从卷内读本进入年页。

[本期相关史料](#sources-start)


<a id="event-1"></a>

1. **魏氏公子与魏咎复立。** 魏豹是魏公子，哥哥魏咎原为甯陵君，亡国后为庶人而投陈胜。周市攻下魏地，拒绝齐赵拥立，坚持奉魏王之后，多次赴陈迎回魏咎立王。 [[1]](#note-1)


<a id="event-2"></a>

2. **田儋分目。** 传文转叙田儋及田榮、田橫兄弟。 [[2]](#note-2)


<a id="event-3"></a>

3. **田榮败死与田橫再起。** 项羽北伐，田榮兵败逃平原，被当地人杀死。项羽焚城屠掠，田橫重新聚兵反攻。汉军进入彭城后项羽回救，田橫趁两军相持复收齐地，立侄子田廣为王，自己主持政务。 [[3]](#note-3)


<a id="event-4"></a>

4. **田橫避居海岛与奉召。** 汉灭项籍、封彭越为梁王后，田橫率五百余人避居海岛。高帝恐齐人追随田橫而生变，赦罪召他；田橫惧郦商替兄报仇，初不肯来。皇帝明令郦商不得加害，又以王侯相许、出兵相迫，田橫方与两门客乘驿车入雒阳。 [[4]](#note-4)


<a id="event-5"></a>

5. **田橫自杀与王礼安葬。** 田橫在尸乡的驿舍以沐浴为由暂留，向门客说明自己既羞屈事汉王，又羞与郦食其的弟弟同列，随后自刎，遣客奉首。高帝赞其兄弟由平民而相继称王，擢两门客为都尉，以王礼葬田橫。 [[5]](#note-5)


<a id="event-6"></a>

6. **田橫门客殉死。** 两名门客在田橫墓旁挖穴自杀。高帝听说海岛上另有五百人，遣使召见，这些人听到田橫已死也自杀。传以此见田氏兄弟能赢得士人倾心。 [[6]](#note-6)


<a id="event-7"></a>

7. **韩王信分目。** 下文为韩襄王支系的韩王信，其人与淮阴侯韩信同名。 [[7]](#note-7)


<a id="event-8"></a>

8. **项梁立韩成与沛公得韩王信。** 韩王信是韩襄王庶支孙辈。项梁在拥怀王后册立韩国公子横阳城君，待项梁战死，韩成投奔怀王。刘邦攻阳城，遣张良略韩，得到信，任为韩将，带兵随入武关。 [[8]](#note-8)


<a id="event-9"></a>

9. **韩王信议东归与拜太尉。** 韩王信跟刘邦入汉中，以军士多为关东人、思归心切，建议乘士气向东。刘邦重取三秦时答应立信为王，先授韩太尉，让他略取韩地。 [[9]](#note-9)


<a id="event-10"></a>

10. **韩王信后世与韩增履历。** 韩王信随匈奴时生頹當，太子生嬰，两人入汉受封弓高、襄城两侯。頹當在吴楚之乱功最多，后世绝嗣；襄城侯后人坐不敬失爵。另支韩嫣受宠，弟韩说从军封侯，后来在太子巫蛊案中死，子兴坐诛，弟增复得其爵。韩增参与拥立宣帝、统兵伐匈奴，历任大司马车骑将军领尚书事，圆融自守而少建言；其侯爵后由支系续封，王莽败而绝。 [[10]](#note-10)


<a id="event-11"></a>

11. **赞语论旧国遗族兴亡。** 班固由周室衰微、秦并六国说到楚汉易代，称魏豹、韩王信与田氏兄弟虽为故国之后，却不能把王业传下去。田橫能得士死节仍不能自立，韩王信的后人又自弓高侯起贵显，赞语以这些兴亡追问天命与周世宗族余烈。 [[11]](#note-11)

### 4. 田橫避居海岛与奉召

[返回正文第4条](#event-4)

<a id="hs033-p015"></a>

**[《汉书·魏豹田儋韩王信传》P015](../../拆分史书/汉书/卷033.md#p015)** · [仓内TXT L6932—L6932](../../拆分史书/汉书/卷033.md#part-1-L6932)

> 漢滅項籍，漢王立為皇帝，彭越為梁王。橫懼誅，而與其徒屬五百餘人入海，居闯中。高帝聞之，以橫兄弟本定齊，齊人賢者多附焉，今在海中不收，後恐有亂，乃使使赦橫罪而召之。橫謝曰：「臣亨陛下之使酈食其，今聞其弟商為漢將而賢，臣恐懼，不敢奉詔，請為庶人，守海闯中。」使還報，高帝乃詔衛尉酈商曰：「齊王橫即至，人馬從者敢動搖者致族夷！」乃復使使持節具告以詔意，曰：「橫來，大者王，小者乃侯耳；不來，且發兵加誅。」橫乃與其客二人乘傳詣雒陽。

### 5. 田橫自杀与王礼安葬

<a id="hs033-p016"></a>

**[《汉书·魏豹田儋韩王信传》P016](../../拆分史书/汉书/卷033.md#p016)** · [仓内TXT L6933—L6933](../../拆分史书/汉书/卷033.md#part-1-L6933)

> 至尸鄉廄置，橫謝使者曰：「人臣見天子，當洗沐。」止留。謂其客曰：「橫始與漢王俱南面稱孤，今漢王為天子，而橫乃為亡虜，北面事之，其媿固已甚矣。又吾亨人之兄，與其弟併肩而事主，縱彼畏天子之詔，不敢動搖，我獨不媿於心乎？且陛下所以欲見我，不過欲壹見我面貌耳。陛下在雒陽，今斬吾頭，馳三十里間，形容尚未能敗，猶可知也。」遂自剄，令客奉其頭，從使者馳奏之高帝。高帝曰：「嗟乎，有以！起布衣，兄弟三人更王，豈非賢哉！」為之流涕，而拜其二客為都尉，發卒二千，以王者禮葬橫。

<a id="note-10"></a>

### 10. 韩王信后世与韩增履历

[返回正文第10条](#event-10)

<a id="hs033-p025"></a>

**[《汉书·魏豹田儋韩王信传》P025](../../拆分史书/汉书/卷033.md#p025)** · [仓内TXT L6942—L6942](../../拆分史书/汉书/卷033.md#part-1-L6942)

> 信之入匈奴，與太子俱，及至頹當城，生子，因名曰頹當。韓太子亦生子嬰。至孝文時，頹當及嬰率其眾降。漢封頹當為弓高侯，嬰為襄城侯。吳楚反時，弓高侯功冠諸將。傳子至孫，孫無子，國絕。嬰孫以不敬失侯。穨當孽孫嫣，貴幸，名顯當世。嫣弟說，以校尉擊匈奴，封龍哣侯。後坐酎金失侯，復以待詔為橫海將軍，擊破東越，封按道侯。太初中，為游擊將軍屯五原外列城，還為光祿勳，掘蠱太子宮，為太子所殺。子興嗣，坐巫蠱誅。上曰：「游擊將軍死事，無論坐者。」乃復封興弟增為龍镪侯。增少為郎，諸曹侍中光祿大夫，昭帝時至前將軍，與大將軍霍光定策立宣帝，益封千戶。本始二年，五將征匈奴，增將三萬騎出雲中，斬首百餘級，至期而還。神爵元年，代張安世為大司馬車騎將軍，領尚書事。增世貴，幼為忠臣，事三主，重於朝廷。為人寬和自守，以溫顏遜辭承上接下，無所失意，保身固寵，不能有所建明。五鳳二年薨，諡曰安侯。子寶嗣，亡子，國除。成帝時，繼功臣後，封增兄子岑為龍镪侯。薨，子持弓嗣。王莽敗，乃絕。

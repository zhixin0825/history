# 汉初异姓诸侯表的表序与月格

[本世纪目录](README.md) · [全部世纪](../README.md)

这里按原卷保留表序、栏头、谱系和无法确系单一年度的材料。确年原句由各卷去向连接对应年份。


<a id="event-1"></a>

1. **表序｜虞夏殷周与秦的取天下。** 班固先说《诗》《书》里的舜、禹受禅，积德数十年才即位；殷、周从契、稷到汤、武，经营十多代才放逐或杀掉前朝君主。秦从襄公发端，经文、穆到献、孝、昭、庄襄，蚕食诸侯百余年，始皇才并天下。用德与用兵，两条道路在作者笔下都经过长期积累。 [[1]](#note-1)


<a id="event-2"></a>

2. **表序｜秦的控制与汉的立业。** 班固说秦把周亡归咎于议论、诸侯争斗和外患，废封建五等、毁城熔兵、禁言焚书、抑制豪杰，却因而给崛起者机会。汉无一尺既有封土，提剑五年而为帝；在班固看来，孤立秦朝的瓦解比取代尚有根基的旧王朝容易。表追十八王，开端按月、统一后按年，到文帝时异姓王统结束。 [[2]](#note-2)


<a id="event-3"></a>

3. **表头｜国名与拆分提示。** “汉元年”是本表的纪年横轴。楚地分列衡山、临江、九江；赵、齐、燕、魏、韩附近也列分出的国。雍、塞、翟三栏均列“分关中”。相邻的国名和拆分语是展平表头，不能将国别并作一格。 [[3]](#note-3)


<a id="event-4"></a>

4. **汉元年三月｜纪月格。** 这一行只列月序和各栏纪月数。 [[4]](#note-4)


<a id="event-5"></a>

5. **十一月栏｜各国纪月。** 同列月数继续累计，有的国已转栏起算。 [[5]](#note-5)


<a id="event-6"></a>

6. **汉二年六月至七月｜纪月格。** 此段续列各国王年纪月。 [[6]](#note-6)


<a id="event-7"></a>

7. **汉三年一月至三月｜纪月格。** 各栏按其各自的国年接续。 [[7]](#note-7)


<a id="event-8"></a>

8. **汉三年五月至七月｜纪月格。** 表中这三行只续计月数，共敖卒的事实见本纪及下一格承位。 [[8]](#note-8)


<a id="event-9"></a>

9. **十二月至汉四年一月栏｜齐国表位。** 纯数字继续计月，汉四年一月行先标齐国一栏。 [[9]](#note-9)


<a id="event-10"></a>

10. **汉四年三月至五月｜纪月格。** 表各栏续计，未附封王、迁徙等行动。 [[10]](#note-10)

### 1. 表序｜虞夏殷周与秦的取天下

[返回正文第1条](#event-1)

<a id="hs013-p001"></a>

**[《汉书·异姓诸侯王表》P001](../../sources/摘录/汉书-卷013-异姓诸侯王表.md#p001)** · [仓内TXT L1093—L1093](../../sources/本地分卷/汉书/汉书-卷013.md#L1093)

> 昔詩書述虞夏之際，舜禹受䄠，積德累功，洽於百姓，攝位行政，考之于天，經數十年，然後在位。殷周之王，乃繇禼稷，脩仁行義，歷十餘世，至于湯武，然後放殺。秦起襄公，章文、繆，獻、孝、昭、嚴，稍蠶食六國，百有餘載，至始皇，迺并天下。以德若彼，用力如此其囏難也。

### 2. 表序｜秦的控制与汉的立业

[返回正文第2条](#event-2)

<a id="hs013-p002"></a>

**[《汉书·异姓诸侯王表》P002](../../sources/摘录/汉书-卷013-异姓诸侯王表.md#p002)** · [仓内TXT L1094—L1094](../../sources/本地分卷/汉书/汉书-卷013.md#L1094)

> 秦旣稱帝，患周之敗，以為起於處士橫議，諸侯力爭，四夷交侵，以弱見奪。於是削去五等，墮城銷刃，箝語燒書，內鋤雄俊，外攘胡粵，用壹威權，為萬世安。然十餘年閒，猛敵橫發乎不虞，適戍彊於五伯，閭閻偪於戎狄，嚮應㿊於謗議，奮臂威於甲兵。鄉秦之禁，適所以資豪桀而速自斃也。是以漢亡尺土之階，繇一劔之任，五載而成帝業。書傳所記，未甞有焉。何則？古世相革，皆承聖王之烈，今漢獨收孤秦之弊。鐫金石者難為功，摧枯朽者易為力，其埶然也。故據漢受命，譜十八王，月而列之，天下一統，迺以年數。訖于孝文，異姓盡矣。

# 战国时期｜田单守即墨与齐国复政（时期阅读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷082完整读本](../../sources/摘录/史记-卷082-田单列传.md) · [纪年与异说](../../meta/考证/史记-卷082-纪年与异说.md)

本页按可见的事件先后或主题阅读。未载确年的轶事、书信和传承保留为时期材料，已定年事件由对应年页进入。

<a id="event-1"></a>

1. **安平车败，田氏族人逃入即墨。** 燕军占齐过程中，田单所率族人因车轴有铁护件，安平陷落时脱逃到即墨。即墨原有守官战死，城中推田单领兵。破安平与推田单之间无确年可排。 [[1]](#note-1)

<a id="event-2"></a>

2. **燕国换将，即墨守军获得反攻机会。** 田单利用新燕王与乐毅的隔阂，散布乐毅有意据齐自立的消息。骑劫接替后燕军内部不安，田单终于得以反击。相关战事合读[前279年](bce-0279.md#note-3)。 [[2]](#note-2)

<a id="event-3"></a>

3. **城中祭祀与燕军毁墓的传述。** 守城时，田单借飞鸟聚食制造神师之说；又令燕军相信残害齐俘、掘毁坟墓会使城中恐惧。传文写燕军实际照做，城中却愈加悲愤。细节和先后主要来自本传，缺少独立年月。 [[3]](#note-3)

<a id="event-4"></a>

4. **田单同守军劳作，传话诈降。** 田单与兵士分担守城劳作，拿出食物犒劳；使者对外传出降意，又经城中富户送财给燕将，燕军于是松弛。 [[4]](#note-4)

<a id="event-5"></a>

5. **即墨破围后的还都与封赏。** 骑劫被击败，齐军追逐燕军，沿途城邑重归齐。齐襄王由莒返回临淄，田单受封安平君。此处为战事及封赏的合读入口，事件归[前279年](bce-0279.md#note-3)。 [[5]](#note-5)

<a id="event-6"></a>

6. **史家论兵与唐代述赞。** 司马迁借田单的作为讲用兵的奇正变化。司马贞述赞又以车轴、反间、群鸟和牛群为线索概括本传。赞与正文的数字表述各从原文。 [[6]](#note-6)

<a id="event-7"></a>

7. **画邑王蠋拒燕，齐亡臣赴莒。** 王蠋在画邑拒绝燕人的招降与胁迫，自尽守义。齐亡臣闻讯后前往莒地寻求湣王的儿子。莒人庇护并拥立法章的后续见[前283年](bce-0283.md#note-2)，王蠋自尽无独立确日。 [[7]](#note-7)

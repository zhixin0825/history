# 时期阅读｜田横入海与齐士去就

[本页相关史料](#sources-start)

<a id="event-1"></a>

1. **田儋兄弟和田齐宗族。** 田儋是狄人，出自战国齐王田氏。田荣是他的从弟，田横是田荣的弟弟。三人宗族强盛，善于聚集地方人士。 [[1]](#note-1)

<a id="event-2"></a>

2. **田横入海，高祖遣使招致。** 项羽败、刘邦即帝位、彭越为梁王后，田横惧诛，带五百余人居海岛。高祖怕齐人依附田横而生事，赦罪召他。田横以曾杀郦食其、不敢见其弟郦商为辞；高祖禁郦商等加害，再派使者告以归来可封王侯、不来将讨。田横带两位宾客乘驿车赴洛阳。 [[2]](#note-2)

<a id="event-3"></a>

3. **田横未到洛阳而死。** 距洛阳三十里，田横在尸乡驿站托称沐浴，向宾客说自己原和刘邦同为王，今事之为臣深觉耻辱，又愧对郦食其之弟；遂自杀，使宾客奉首送到洛阳。高祖为之感叹，授两客都尉，以王礼葬田横。此段有事件顺序和地点，缺少明确年号月日。 [[3]](#note-3)

<a id="event-4"></a>

4. **随从二客与海岛宾客。** 田横安葬后，两位随行宾客死于墓旁；高祖派人召岛上五百余人，传中说他们闻田横死也都自杀。作者借此表明田横兄弟得士之深；岛名与人数没有独立档案可以覆核。 [[4]](#note-4)

<a id="event-5"></a>

5. **太史公评蒯通与田横。** 司马迁认为蒯通之谋使齐局更乱、使韩信恃功，结果齐国与韩信俱亡；又记蒯通论战国权变、同安期生交游、曾拒项羽封赏而去。篇末称田横节操及宾客慕义，叹无人绘其形象。 [[5]](#note-5)

<a id="event-6"></a>

6. **索隐述赞。** 唐代述赞从秦末群起说到田儋死、田市被立、郦食其被杀及海岛宾客。“楚封王假”用语应与本传齐人立假、田假奔楚对看。 [[6]](#note-6)

### 2. 田横入海，高祖遣使招致

[返回正文第2条](#event-2)

<a id="hs001-p068-e2"></a>

**[《汉书·高帝纪》P068](../../sources/摘录/汉书-高帝纪.md#p068)** · [仓内TXT L70](../../sources/本地分卷/汉书/汉书-卷001.md#L70)

> 初，田橫歸彭越。項羽已滅，橫懼誅，與賓客亡入海。上恐其久為亂，遣使者赦橫，曰：「橫來，大者王，小者侯；不來，且發兵加誅。」

**对读说明：** 《汉书》以项羽已灭为前提。《资治通鉴》把田横事放在汉五年，现有《史记》考证保留前202年通行系年和月日未明之别。沿旧时期条补本纪文字。

**[《史记·田儋列传》P010](../../sources/摘录/史记-卷094-田儋列传.md#p010)** · [三家注p10](../../sources/史记三家注/卷094.md#p10)

> 後歲餘，漢滅項籍，漢王立爲皇帝，以彭越爲梁王。田橫懼誅，而與其徒屬五百餘人入海，居島中。高帝聞之，以爲田橫兄弟本定齊，齊人賢者多附焉，今在海中不收，後恐爲亂，迺使使赦田橫罪而召之。田橫因謝曰：「臣亨陛下之使酈生，今聞其弟酈商爲漢將而賢，臣恐懼，不敢奉詔，請爲庶人，守海島中。」使還報，高皇帝迺詔衞尉酈商曰：「齊王田橫即至，人馬從者敢動搖者致族夷！」迺復使使持節具告以詔商狀，曰：「田橫來，大者王，小者迺侯耳；不來，且舉兵加誅焉。」田橫迺與其客二人乘傳詣雒陽。

<a id="note-3"></a>

### 3. 田横未到洛阳而死

[返回正文第3条](#event-3)

<a id="hs001-p068-e3"></a>

**[《汉书·高帝纪》P068](../../sources/摘录/汉书-高帝纪.md#p068)** · [仓内TXT L70](../../sources/本地分卷/汉书/汉书-卷001.md#L70)

> 橫懼，乘傳詣雒陽，未至三十里，自殺。上壯其節，為流涕，發卒二千人，以王禮葬焉。

**对读说明：** 本纪也记未到洛阳三十里，发卒二千、王礼安葬。两宾客是在安葬后另死，不能把《史记》两次死亡并为同时。

**[《史记·田儋列传》P011](../../sources/摘录/史记-卷094-田儋列传.md#p011)** · [三家注p11](../../sources/史记三家注/卷094.md#p11)

> 未至三十里，至尸鄉廄置，橫謝使者曰：「人臣見天子當洗沐。」止留。謂其客曰：「橫始與漢王俱南面稱孤，今漢王爲天子，而橫迺爲亡虜而北面事之，其耻固已甚矣。且吾亨人之兄，與其弟併肩而事其主，縱彼畏天子之詔，不敢動我，我獨不媿於心乎？且陛下所以欲見我者，不過欲一見吾面貌耳。今陛下在洛陽，今斬吾頭，馳三十里閒，形容尚未能敗，猶可觀也。」遂自剄，令客奉其頭，從使者馳奏之高帝。高帝曰：「嗟乎，有以也夫！起自布衣，兄弟三人更王，豈不賢乎哉！」爲之流涕，而拜其二客爲都尉，發卒二千人，以王者禮葬田橫。

<a id="note-4"></a>

### 4. 随从二客与海岛宾客

[返回正文第4条](#event-4)

**[《史记·田儋列传》P012](../../sources/摘录/史记-卷094-田儋列传.md#p012)** · [三家注p12](../../sources/史记三家注/卷094.md#p12)

> 旣葬，二客穿其冢旁孔，皆自剄，下從之。高帝聞之，迺大驚，以田橫之客皆賢。吾聞其餘尚五百人在海中，使使召之。至則聞田橫死，亦皆自殺。於是迺知田橫兄弟能得士也。

<a id="note-5"></a>

### 5. 太史公评蒯通与田横

[返回正文第5条](#event-5)

**[《史记·田儋列传》P013](../../sources/摘录/史记-卷094-田儋列传.md#p013)** · [三家注p13](../../sources/史记三家注/卷094.md#p13)

> 太史公曰：甚矣蒯通之謀，亂齊驕淮陰，其卒亡此兩人！蒯通者，善爲長短說，論戰國之權變，爲八十一首。通善齊人安期生，安期生嘗干項羽，項羽不能用其筴。已而項羽欲封此兩人，兩人終不肯受，亡去。田橫之高節，賔客慕義而從橫死，豈非至賢！余因而列焉。無不善畫者，莫能圖，何哉？

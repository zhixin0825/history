# 战国后期｜范雎入秦、报恩报怨与蔡泽进退（时期附读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷079完整对读](../../拆分史书/史记/卷079.md) · [纪年与异说](../../拆分史书/史记/卷079.md#kao-f2f2de3a62)

本页随传阅读难以独立归年的人物往来、辩辞和史家议论。有关罢相、战役、治罪的具体时间沿既有年页可查。参看[前266年](bce-0266.md)、[前259年](bce-0259.md)、[前257年](bce-0257.md#note-2)、[前255年](bce-0255.md)与[前232年太子丹逃归](bce-0232.md#note-2)。

## 连续阅读

<a id="event-1"></a>

1. **使齐遭疑与受辱脱险。** 魏昭王使臣须贾带范雎赴齐，范雎因齐王馈赠被怀疑泄密，回魏遭国相魏齐笞辱，幸经守者、郑安平相救，改名张禄。 [[1]](#note-1)

<a id="event-2"></a>

2. **王稽载范雎入秦。** 郑安平引王稽见范雎。王稽以车载范雎过湖关，穰侯遣骑回头搜查时，范雎已先下车。 [[2]](#note-2)

<a id="event-3"></a>

3. **待命岁余后上书求见。** 范雎以赏功、授能为说，举名器曾为良工所失为比，请昭王当面听取可补国政的办法。 [[3]](#note-3)

<a id="event-4"></a>

4. **离宫相见与三次请教。** 范雎在离宫激昭王反思王权，昭王屏人长跪求教。范雎以吕尚、伍子胥等为例，请王允许他议及亲族及近臣。 [[4]](#note-4)

<a id="event-5"></a>

5. **远交近攻与秦韩形势。** 范雎反对借道韩魏远攻齐，主张远交近攻，先由中原枢纽牵制诸国。随后他分析韩国地势，进说分断交通迫韩。 [[5]](#note-5)

<a id="event-6"></a>

6. **私陈四贵与君臣权力。** 范雎指太后与穰侯等垄断发令、使臣、军功和人事，借齐国、赵国旧事警告昭王，推动秦王亲揽政权。 [[6]](#note-6)

<a id="event-7"></a>

7. **一件绨袍所见的旧恩旧怨。** 须贾送范雎绨袍才发觉对方是秦相，范雎列旧罪而免其死，离别时又当众羞辱他，并由此逼走魏齐。 [[7]](#note-7)

<a id="event-8"></a>

8. **范雎荐王稽和郑安平。** 范雎为报从前救助，推举王稽为河东守、郑安平为将，又散财还恩。郑安平后来降赵，王稽获罪，所荐二人牵动秦相的处境。 [[8]](#note-8)

<a id="event-9"></a>

9. **蔡泽问相，周游不遇。** 燕人蔡泽屡游诸侯不得用，求唐举看相而遭戏谑，后在赵被逐，过韩魏丢失炊具，听说范雎所荐二人获罪，遂入秦。 [[9]](#note-9)

<a id="event-10"></a>

10. **从功臣遭遇论进退。** 蔡泽由士人愿望说到商鞅、吴起、文种和白起的结局，以日中、月盈及亢龙有悔劝范雎归印让贤，范雎礼为上客。 [[10]](#note-10)

<a id="event-11"></a>

11. **蔡泽历事秦王，出使燕国。** 蔡泽交相印后号纲成君，历事秦王，后来使燕。卷079说三年后燕太子丹入质于秦。 [[11]](#note-11)

<a id="event-12"></a>

12. **司马迁和司马贞回看两人取相。** 司马迁讲游士的能力也须有时势，困厄可以发奋；司马贞述赞重述范雎起落和蔡泽因辩说而进。 [[12]](#note-12)

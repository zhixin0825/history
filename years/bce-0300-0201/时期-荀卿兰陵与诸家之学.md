# 战国中后期｜荀卿在齐楚、兰陵与诸家学说

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷074全篇释读](../../sources/摘录/史记-卷074-孟子荀卿列传.md) · [纪年考证](../../meta/考证/史记-卷074-纪年与异说.md)

这是思想活动的**跨期读本**，不冒充某一个公元前年。孟子、邹忌、邹衍、淳于髡、荀卿等并非同世同任；史书记载的访问、学派与著述先后有难辨处。

## 故事与观点

<a id="event-1"></a>

1. **慎到田骈环渊等继承黄老之学。** 各自著书阐发黄老思想，传本文不载他们生年或何日受召；与稷下学术流动同读。 [[1]](#note-1)

<a id="event-2"></a>

2. **荀卿三为祭酒、因谗适楚。** 荀卿作为稷下长者，几次被推举主持学事，受谗后赴楚。这不能从“三次”推导三个连年任期。 [[2]](#note-2)

<a id="event-3"></a>

3. **春申君死后，荀卿离职定居兰陵。** 春申君遇害与荀卿去职有因果联系，前238年只为他后续居兰陵提供事件参照，不是他的确卒年。 [[3]](#note-3)

<a id="event-4"></a>

4. **各派著书与公孙龙坚白之辩。** 赵国辩士公孙龙与魏李悝、楚尸子等属于学派叙述；不同于孔子门生中同名的人。 [[4]](#note-4)

<a id="event-5"></a>

5. **墨翟节用和守御，年代仍有异说。** 墨子擅长防守、主张节约，司马迁对是否与孔子同时代没有给出唯一结论。 [[5]](#note-5)

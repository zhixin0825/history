# 战国末至秦初｜荆轲在燕与高渐离后事（时期阅读）

本页按原传可见的先后和专题阅读。已知年份的事件在相应年页，未独立确年的叙事随原传先后附读。

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **荆轲的家世与早年游历。** 荆轲出自先世由齐迁卫的一支。在卫称庆卿，入燕后被称荆卿。他曾游说卫元君，未获任用；又在榆次与盖聂谈剑，在邯郸同鲁句践博戏。两次相遇的年月均无明确记载。 [[1]](#note-1)

<a id="event-2"></a>

2. **在燕市结识高渐离与田光。** 荆轲同燕市一位屠狗者及高渐离来往，以击筑、歌唱相和，也结交处士田光。太子丹后来听说荆轲，和这段燕地交游有关。 [[2]](#note-2)

<a id="event-3"></a>

3. **鞠武论秦，太子丹仍收留樊於期。** 太子丹逃归燕国后问计于鞠武。鞠武认为秦强燕弱，反对因私怨开衅；樊於期入燕后，他又主张设法联合别国，太子不愿驱逐来投的樊於期。樊於期奔燕缺少明文年月。 [[3]](#note-3)

<a id="event-4"></a>

4. **田光荐荆轲后去世。** 田光受太子丹礼遇，但自认年老，推荐荆轲。太子嘱他保密，他认为自己受到了怀疑，便将请托告诉荆轲，继而自尽。太子闻讯后说，嘱托保密并无让他以死取信之意。 [[4]](#note-4)

<a id="event-5"></a>

5. **太子丹的设想与秦军逼近。** 秦已灭韩并进逼赵国时，太子丹希望借曹沫故事迫使秦王归地，或给各国争取重新联兵的时机。赵王被俘后，燕国危机更急，太子催荆轲出使。各次问计不可一律标在同年同月。 [[5]](#note-5)

<a id="event-6"></a>

6. **樊於期死与秦舞阳随行。** 使秦的准备涉及樊於期之死。太子最初不肯伤害他，后来得知他已自尽，赶去痛哭。燕国另选秦舞阳为副，荆轲则没有等到原想同行的朋友。以上为出发前事，具体日年未详。 [[6]](#note-6)

<a id="event-7"></a>

7. **易水送别。** 知情的太子与宾客在易水为荆轲送别，高渐离击筑，荆轲歌唱。歌辞与送别情境见本传，行刺的确定年份另见前227年。 [[7]](#note-7)

<a id="event-8"></a>

8. **统一以后高渐离的结局。** 秦统一后，高渐离藏身宋子，后来因击筑受到注意，被秦始皇召见。传文说他试图袭击秦始皇，未能得手而被杀。藏身、召见和死亡的年月均未见明文。 [[8]](#note-8)

<a id="event-9"></a>

9. **鲁句践回忆与司马迁辨疑。** 鲁句践听说荆轲失败后追悔此前未能识人。司马迁辨驳太子丹获释的异象和荆轲伤到秦王的说法，并指出叙事来自与侍医夏无且有交往的人。 [[9]](#note-9)

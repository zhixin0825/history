# 蒙氏家世与秦末议论｜时期阅读

[蒙恬列传原文与释读](../../拆分史书/史记/卷088.md) · [纪年与异说](../../拆分史书/史记/卷088.md#kao-f9c7122edc) · [本世纪目录](README.md)

本页汇集登场前事、未确年轶事、奏议细读和史家评语。可确年史事沿文内入口进入统一编年。

<a id="reading-start"></a>

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **蒙氏由齐入秦。** 蒙骜出自齐地，入秦事昭王。其子蒙武也领兵，孙辈蒙恬、蒙毅分别成为外将和内臣。蒙恬曾经办理狱文等事务，年月不详。蒙骜、蒙武可确的战事已经并入各年。 [[1]](#note-1)

<a id="event-2"></a>

2. **蒙毅办赵高案，始皇后来赦免。** 赵高通晓狱法，获任中车府令，还给胡亥讲解断狱。他因罪被交蒙毅审理，蒙毅判死、除其籍，始皇看重赵高办事又赦免恢复官爵。传文用这段未确年的旧事交代[前210年](bce-0210.md#reading-note-9)的私人嫌隙。 [[2]](#note-2)

<a id="event-3"></a>

3. **司马迁把地脉之说转到劳民。** 司马迁从北边走过直道，观察长城、亭障和道路工程。他把秦初社会仍需休养与蒙恬承担大工程相对照，追问名将本应怎样进谏。唐代述赞进一步用“劳人”回应临终所说地脉。 [[3]](#note-3)

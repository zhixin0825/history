# 秦末至汉初｜郦食其陆贾朱建的出使与交游（时期阅读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷097完整读本](../../拆分史书/史记/卷097.md) · [纪年与异说](../../拆分史书/史记/卷097.md#kao-6dce9b9343)

列传中仅见相对先后、无独立纪年和属于论赞的文字，在此接读。史事有年者可由本卷读本到对应年页。

<a id="event-1"></a>

1. **郦食其读书为里吏，请同里骑士引见。** 郦食其家贫，任里监门吏。反秦起兵后，他先避开过境诸将，后来托刘邦麾下的同里骑士引见。 [[1]](#note-1)

<a id="event-2"></a>

2. **郦商领兵，郦食其往来诸侯。** 郦食其推荐弟弟郦商，使他带数千兵随沛公向西南夺取地方。郦食其自己经常担任说客，奔走出使诸侯。 [[2]](#note-2)

<a id="event-3"></a>

3. **陆贾随军出使，后来著《新语》。** 陆贾随高祖平天下，以辩才多次出使。统一之后，他与高祖辩论取天下与治天下的不同，奉命写十二篇，书名《新语》。 [[3]](#note-3)

<a id="event-4"></a>

4. **陆贾称病退居好畤。** 惠帝时吕太后主政，想让吕氏子弟称王，忌惮能言的大臣。陆贾自料无力争辩，就称病免官，见好畤田地好，安家在那里。他把出使南越所得的行装卖得千金，给五子各二百金，让他们经营生计。他自己乘安车四马，带歌舞、琴瑟等十名侍从和一把值百金的宝剑，与儿子们约好：自己到谁家，谁供应人马酒食，尽其所好，十天便换一家；死在哪一家，那家就得剑、车骑、侍从。他一年走访别的宾客大体不超过两三次，常见就不新鲜，不必久去烦扰人。 [[4]](#note-4)

<a id="event-5"></a>

5. **朱建曾任英布相，因劝止反叛获免。** 朱建是楚人，号平原君，做过淮南王英布的相，因罪离职，后来又侍奉英布。英布谋反时询问他，他劝阻；英布却听梁父侯而反。汉廷诛灭英布后，听说朱建曾劝阻、没有参与谋划，便免他一死。详情另见英布传。 [[5]](#note-5)

<a id="event-6"></a>

6. **审食其受陆贾劝说资助朱建母丧。** 朱建善辩、廉洁刚直，住在长安，不肯随便苟合讨好。受吕太后宠信而行为不正的辟阳侯审食其想结交他，他拒绝见面。朱建母亲死了，他因贫穷借贷置办丧服和用具。旧友陆贾叫他先发丧，转身向辟阳侯道贺。辟阳侯问别人死母何贺，陆贾说，从前朱建因义不肯交往，也有所顾念母亲；如今厚送丧礼，他将来会为你效死。辟阳侯送去百金，其他列侯贵人追随赠奠，总共五百金。 [[6]](#note-6)

<a id="event-7"></a>

7. **朱建通过闳籍孺救审食其出狱。** 有人在惠帝面前诋毁吕太后宠臣审食其。惠帝震怒，把他下狱欲杀；太后难于开口，诸臣也厌恶他的行为，想置他于死地。审食其求见朱建，朱建以案情紧急推辞，转去见惠帝宠幸的闳籍孺。他说，世人皆知闳籍孺为何受宠，如今道路上传言是他谗害太后宠臣，今天杀审食其，太后明天便可能发怒杀他；不如脱衣露臂，恳求惠帝放人，这样太后也欢喜，两位主上都宠信他，富贵就会加倍。闳籍孺害怕，照计求情，惠帝果然放人。审食其在狱中曾因朱建拒见而以为受背叛，大为恼怒，获释后得知原委才大吃一惊。 [[7]](#note-7)

<a id="event-8"></a>

8. **陆贾寿终，朱建之子出使匈奴。** 陆贾再使南越后寿终。朱建之子被召为中大夫，后来在匈奴因辱骂单于而死。 [[8]](#note-8)

<a id="event-9"></a>

9. **司马迁说明朱建材料来源，司马贞述赞。** 司马迁说自己与朱建之子交好，因此能详记其事。司马贞以述赞回顾郦食其取陈留、说齐与陆贾出使、著书。 [[9]](#note-9)

> 及陳勝、項梁等起，諸將徇地過高陽者數十人，酈生聞其將皆握齱好苛禮自用，不能聽大度之言，酈生乃深自藏匿。後聞沛公將兵略地陳留郊，沛公麾下騎士適酈生里中子也，沛公時時問邑中賢士豪俊。騎士歸，酈生見謂之曰：「吾聞沛公慢而易人，多大略，此真吾所願從游，莫爲我先。若見沛公，謂曰『臣里中有酈生，年六十餘，長八尺，人皆謂之狂生，生自謂我非狂生』。」騎士曰：「沛公不好儒，諸客冠儒冠來者，沛公輒解其冠，溲溺其中。與人言，常大罵。未可以儒生說也。」酈生曰：「弟言之。」騎士從容言如酈生所誡者。

**归年说明：** 反秦起事是背景，任里吏和说骑士的具体年月未见；正式相见及取陈留入[前207年](bce-0207.md#sj097-p002)。

> 陸賈者，楚人也。以客從高祖定天下，名爲有口辯士，居左右，常使諸侯。

[《史记·郦生陆贾列传》P011](../../拆分史书/史记/卷097.md#p011) · [三家注p11](../../拆分史书/史记/卷097.md#part-1-p11)

> 陸生時時前說稱詩書。高帝罵之曰：「迺公居馬上而得之，安事詩書！」陸生曰：「居馬上得之，寧可以馬上治之乎？且湯武逆取而以順守之，文武並用，長久之術也。昔者吳王夫差、智伯極武而亡；秦任刑法不變，卒滅趙氏。鄉使秦已并天下，行仁義，法先聖，陛下安得而有之？」高帝不懌而有慙色，迺謂陸生曰：「試爲我著秦所以失天下，吾所以得之者何，及古成敗之國。」陸生迺粗述存亡之徵，凡著十二篇。每奏一篇，高帝未嘗不稱善，左右呼萬歲，號其書曰「新語」。

[《史记·郦生陆贾列传》P023](../../拆分史书/史记/卷097.md#p023) · [三家注p23](../../拆分史书/史记/卷097.md#part-1-p23)

### 4. 陆贾称病退居好畤

[返回正文第4条](#event-4)

[《史记·郦生陆贾列传》P012](../../拆分史书/史记/卷097.md#p012) · [三家注p12](../../拆分史书/史记/卷097.md#part-1-p12)

> 孝惠帝時，呂太后用事，欲王諸呂，畏大臣有口者，陸生自度不能爭之，迺病免家居。以好畤田地善，可以家焉。有五男，迺出所使越得橐中裝賣千金，分其子，子二百金，令爲生產。陸生常安車駟馬，從歌舞鼔琴瑟侍者十人，寶劔直百金，謂其子曰：「與汝約：過汝，汝給吾人馬酒食，極欲，十日而更。所死家，得寶劔車騎侍從者。一歲中往來過他客，率不過再三過，數見不鮮，無久慁公爲也。」

**归年说明：** 本篇称孝惠帝时；欲王诸吕与吕后实际封王可以分别出现，不能由后二者倒推同一确年。

> 平原君朱建者，楚人也。故嘗爲淮南王黥布相，有辠去，後復事黥布。布欲反時，問平原君，平原君止之，布不聽而聽梁父侯，遂反。漢已誅布，聞平原君諫不與謀，得不誅。語在黥布語中。

### 6. 审食其受陆贾劝说资助朱建母丧

[返回正文第6条](#event-6)

[《史记·郦生陆贾列传》P016](../../拆分史书/史记/卷097.md#p016) · [三家注p16](../../拆分史书/史记/卷097.md#part-1-p16)

> 平原君爲人辯有口，刻廉剛直，家於長安。行不苟合，義不取容。辟陽侯行不正，得幸呂太后。時辟陽侯欲知平原君，平原君不肯見。及平原君母死，陸生素與平原君善，過之。平原君家貧，未有以發喪，方假貸服具，陸生令平原君發喪。陸生徃見辟陽侯，賀曰：「平原君母死。」辟陽侯曰：「平原君母死，何乃賀我乎？」陸賈曰：「前日君侯欲知平原君，平原君義不知君，以其母故。今其母死，君誠厚送喪，則彼爲君死矣。」辟陽侯乃奉百金往稅。列侯貴人以辟陽侯故，徃稅凡五百金。

**归年说明：** 丧事没有独立纪年；由前后叙次可读至惠帝时辟阳侯下狱。

### 7. 朱建通过闳籍孺救审食其出狱

[返回正文第7条](#event-7)

[《史记·郦生陆贾列传》P017](../../拆分史书/史记/卷097.md#p017) · [三家注p17](../../拆分史书/史记/卷097.md#part-1-p17)

> 辟陽侯幸呂太后，人或毀辟陽侯於孝惠帝，孝惠帝大怒，下吏，欲誅之。呂太后慙，不可以言。大臣多害辟陽侯行，欲遂誅之。辟陽侯急，因使人欲見平原君。平原君辭曰：「獄急，不敢見君。」迺求見孝惠幸臣閎籍孺，說之曰：「君所以得幸帝，天下莫不聞。今辟陽侯幸太后而下吏，道路皆言君讒，欲殺之。今日辟陽侯誅，旦日太后含怒，亦誅君。何不肉袒爲辟陽侯言於帝？帝聽君出辟陽侯，太后大驩。兩主共幸君，君貴富益倍矣。」於是閎籍孺大恐，從其計，言帝，果出辟陽侯。辟陽侯之囚，欲見平原君，平原君不見辟陽侯，辟陽侯以爲倍己，大怒。及其成功出之，迺大驚。

**归年说明：** 本段明确孝惠帝在位；与[前180年](../bce-0200-0101/bce-0180.md#sj097-p018)审食其未被诛不是一次获免。

# 前262—257年｜长平、邯郸与白起的结局（跨年连读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷073完整原文](../../sources/摘录/史记-卷073-白起王翦列传.md) · [纪年考证](../../meta/考证/史记-卷073-纪年与异说.md)

本页不是一场“长平之战”的扩充年页：前262上党归赵、前261相持、前260决战杀俘、前259议和、前258邯郸围攻和前257白起之死各有独立年页。串读的目的是把粮道、换将、联军救赵与君臣矛盾讲清，避免误记白起指挥邯郸失败。

## 跨年主线

<a id="event-1"></a>

1. **韩上党转赵，战争的地缘起点。** 韩国野王被秦占领、上党与本土交通受阻，冯亭说服赵接收上党，赵廷内部先有接受与否之争。 [前262年](bce-0262.md)是主事件所在年。 [[1]](#note-1)

<a id="event-2"></a>

2. **廉颇坚守与反间换将。** 长平相持，秦以反间促赵撤廉颇、换赵括；秦又秘密任白起为上将，分兵断粮。 [前261年](bce-0261.md)是主事件所在年。 [[2]](#note-2)

<a id="event-3"></a>

3. **赵括战死，降卒被诈杀。** 赵军因绝粮反复突围，赵括战死，幸存军卒归降后遭白起诈杀。杀降应独立记载，不能含糊说成“野战歼敌”。 [前260年](bce-0260.md)是主事件所在年。 [[3]](#note-3)

<a id="event-4"></a>

4. **苏代说范雎与秦暂罢兵。** 秦欲攻邯郸，苏代从白起功高威胁范雎相位说起，范雎劝王以地议和。秦与韩赵短暂休整，白起和范雎结怨。 [前259年](bce-0259.md)是主事件所在年。 [[4]](#note-4)

<a id="event-5"></a>

5. **邯郸久围不下，白起在杜邮赐死。** 王陵、王龁围邯郸遭楚魏援军反击。白起拒绝领军、被贬而赐剑自裁。邯郸败不是白起亲自领兵的败仗，但长平战后屠杀降卒是他本人的行为。 [前257年](bce-0257.md)是主事件所在年。 [[5]](#note-5)

# 战国中期｜魏冉的权势、须贾与苏代的劝兵（跨年及未定年）

[本世纪目录](README.md) · [全部世纪](../README.md) · [完整列传](../../拆分史书/史记/卷072.md) · [纪年考证](../../拆分史书/史记/卷072.md#kao-d2b05f3598)

本页把《穰侯列传》的政治权力和两次长篇外交劝说连起来读。已可定年的[前275年魏冉围梁](bce-0275.md#note-1)、[前271年取齐刚寿](bce-0271.md#note-1)、[前265年外戚失势](bce-0265.md#note-1)仍各在独立年页。它是跨期阅读，不把长篇策辞或死于陶的未定年事实挤进某年。

## 故事与因果

<a id="event-1"></a>

1. **魏冉拥立昭王与四次任相。** 魏冉依太后亲缘与自己的政治实力助昭王继位，随后数次出入相位。继位和反乱有可确定年条，所涉人事跨度较长；不重造一张“魏冉全部当政之年”年页。 [[1]](#note-1)

<a id="event-2"></a>

2. **须贾劝魏冉罢围大梁。** 魏军坚守大梁，须贾分析攻坚之险与纵横外交得失，魏冉采纳撤围。读这段不仅要看说客的话，也要分清此次围梁与之后对魏用兵是两回事。 [[2]](#note-2)

<a id="event-3"></a>

3. **苏代写信阻止魏冉借赵伐齐。** 苏代担心秦助赵攻齐，使赵更强、秦自己反受制，于是把韩赵魏的利害分层向魏冉解释。所谓秦增赵四万甲，是传述的计划，不是本页发生过的援军交割。 [[3]](#note-3)

<a id="event-4"></a>

4. **范雎批评越三晋攻齐与穰侯失势。** 范雎把魏冉拓封陶邑的战争指为偏私，又揭示外戚权力过重。说辞触发昭王削权，然而客卿灶攻齐与正式逐外戚不在同一个绝对年次。 [[4]](#note-4)

<a id="event-5"></a>

5. **退居陶邑与最终的无确年死事。** 本传只说魏冉在陶去世、秦收回封邑，没有可独立推定的确切公元前年。此处作人生结局阅读，不以失相当年直接认定死亡。 [[5]](#note-5)

# 战国晚期｜鲁仲连辩秦与聊城书（时期阅读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷083完整读本](../../sources/摘录/史记-卷083-鲁仲连邹阳列传.md) · [纪年与异说](../../meta/考证/史记-卷083-纪年与异说.md)

本页串读鲁仲连游赵、拒绝封赏及以书劝燕将。邯郸辩论、解围和聊城收复已有年度入口；早年、围城起点、辞爵与退隐保留可知的相对顺序。

<a id="reading-start"></a>

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **齐人鲁仲连以谋略闻名。** 鲁仲连擅长谋划，又愿保全自己不仕的操守。他在邯郸之围时已在赵国。少年折服田巴是古注所引的传闻，不能由故事里所涉国事倒推生年。 [[1]](#note-1)

<a id="event-2"></a>

2. **鲁仲连驳魏使的尊秦建议。** 新垣衍认为赵若拥戴秦昭王称帝，秦便会退兵。鲁仲连说，帝号将给秦干预列国官位和礼制的权力，魏君和魏臣也难免受制。魏使最终撤去建议。这场问答随[前258年围城条](bce-0258.md#note-1)合读，解围另见[前257年](bce-0257.md#note-2)。 [[2]](#note-2)

<a id="event-3"></a>

3. **平原君谢鲁仲连而未受封金。** 平原君一再派人请鲁仲连接受封赏，又设宴举金相酬。鲁仲连坚持排难解纷不取财，辞别平原君。随邯郸解围后的[前257年原条](bce-0257.md#note-2)读。 [[3]](#note-3)

<a id="event-4"></a>

4. **聊城久围，鲁仲连缚书送燕将。** 占据聊城的燕将怕回燕受诛，田单率齐兵久围未克。鲁仲连送书入城，认为死守会使燕将失去立功的机会，劝他权衡生死荣辱。送书和城陷见[前250年](bce-0250.md#note-4)，最初的攻占及围城起点另无可靠确年。 [[4]](#note-4)

<a id="event-5"></a>

5. **书中举归燕与归齐两策。** 鲁仲连指出燕军救兵不至，齐楚魏态势又已变化，孤守聊城难以长久。他建议燕将保存兵马回国图功，或投齐争取封赏，又用管仲和曹子受辱后立功的故事说明，保身与守义仍有回旋余地。两项出路都是信中设想。 [[5]](#note-5)

<a id="event-6"></a>

6. **燕将自尽，鲁仲连避爵隐居。** 燕将怕归国获罪，又担心归齐后遭辱，最后自尽。聊城因而陷落。田单提出封赏鲁仲连，他退隐海上。田单收城由前250年主条进入，退隐的具体时日无载。 [[6]](#note-6)

<a id="event-7"></a>

7. **史家以布衣折服卿相来评价鲁仲连。** 司马迁赞许鲁仲连在布衣地位仍敢向卿相直言。司马贞的述赞则突出他为人解纷、辞去利禄的选择。两段都属于评论。 [[7]](#note-7)

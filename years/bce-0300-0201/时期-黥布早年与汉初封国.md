# 时期阅读｜黥布早年与汉初封国

<a id="event-1"></a>

1. **黥刑、骊山服役与逃亡。** 黥布是六县人，姓英。少年时有人说他会先受刑再称王；后来他犯法被黥面，拿旧话自嘲，旁人反来笑他。他被发往骊山，在刑徒中结交头领，带同伴逃到江中聚众。相人之说在传中为后来的封王作铺垫。 [[1]](#note-1)

<a id="event-2"></a>

2. **随何论功与淮南王剖符。** 项羽死后，高祖宴中讥随何是无用的儒生。随何以二十人出使达到大军也难做到的成果反问，高祖改任他为护军中尉。传末补叙英布获淮南王符，都六，领九江、庐江、衡山、豫章；此为封国及功次叙事，宴会缺少明年。 [[2]](#note-2)

<a id="event-3"></a>

3. **太史公论英布的骤兴与覆亡。** 司马迁由春秋英、六二国联想到皋陶后裔，对英布世系用问辞；又写英布受刑而骤贵，曾在项氏屠杀中充当主力，终因受宠女子就医引发的猜忌而亡。杀人数是论赞的概括，世系和人物动机仍按传说与史家评价理解。 [[3]](#note-3)

<a id="event-4"></a>

4. **索隐述赞。** 唐代司马贞以短句重述黥刑、聚众、楚军战功、改投汉及贲赫告变。“受汉杖”与本传初见汉王受慢的叙事对读；述赞的褒贬属于后出文字。 [[4]](#note-4)

> 黥布者，六人也，姓英氏。秦時爲布衣。少年，有客相之曰：「當刑而王。」及壯，坐法黥。布欣然笑曰：「人相我當刑而王，幾是乎？」人有聞者，共俳笑之。布已論輸麗山，麗山之徒數十萬人，布皆與其徒長豪桀交通，迺率其曹偶，亡之江中爲羣盜。

### 2. 随何论功与淮南王剖符

[返回正文第2条](#event-2)

**[《史记·黥布列传》P010](../../拆分史书/史记/卷091.md#p010)** · [三家注p10](../../拆分史书/史记/卷091.md#part-1-p10)

> 項籍死，天下定，上置酒。上折隨何之功，謂何爲腐儒，爲天下安用腐儒。隨何跪曰：「夫陛下引兵攻彭城，楚王未去齊也，陛下發步卒五萬人，騎五千，能以取淮南乎？」上曰：「不能。」隨何曰：「陛下使何與二十人使淮南，至，如陛下之意，是何之功賢於步卒五萬人騎五千也。然而陛下謂何腐儒，爲天下安用腐儒，何也？」上曰：「吾方圖子之功。」迺以隨何爲護軍中尉。布遂剖符爲淮南王，都六，九江、廬江、衡山、豫章郡皆屬布。

<a id="note-3"></a>

### 3. 太史公论英布的骤兴与覆亡

[返回正文第3条](#event-3)

**[《史记·黥布列传》P018](../../拆分史书/史记/卷091.md#p018)** · [三家注p18](../../拆分史书/史记/卷091.md#part-1-p18)

> 太史公曰：英布者，其先豈春秋所見楚滅英、六，臯陶之後哉？身被刑法，何其拔興之暴也！項氏之所坑殺人以千萬數，而布常爲首虐。功冠諸侯，用此得王，亦不免於身爲世大僇。禍之興自愛姬殖，妒媢生患，竟以滅國！

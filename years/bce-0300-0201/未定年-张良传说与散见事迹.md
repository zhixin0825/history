# 未定年｜张良传说与散见事迹

[本世纪目录](README.md) · [全部世纪](../README.md) · [前218年首次有据的袭秦](bce-0218.md) · [前189年现行卒年条](../bce-0200-0101/bce-0189.md)

本页属于唯一编年目录 years/，用于保留不能独立确年的叙事及明确分层的史家论赞。目录位置以最早的下邳故事为起点，内容跨秦汉，不能理解为六条都发生在前300—201年。各段的相对前后、跨年回顾和后出评论在各自正文及同号注说明；实际有据之年仍回到原年页。

<a id="reading-start"></a>

<a id="正文"></a>

<a id="event-1"></a>

1. **袭秦以后、秦末起兵以前的下邳故事。** 张良有一次闲暇时在下邳圯桥上慢步闲游。一位穿粗布衣的老人来到他身边，鞋子落到桥下，回头对他说：“小子，下去把鞋拿来！”张良愕然，想打他；因为他年老，勉强忍住，下桥取鞋。老人又说：“替我穿上！”张良既然已经替他取鞋，便直身跪着替他穿上。老人伸脚受履，笑着离去。张良非常惊异，目送着他。老人走了约一里又回来，说：“这孩子可以教导。五天后的清晨，到这里与我相会。”张良觉得奇怪，跪着答应。 五天后天刚亮，张良前去，老人已经先到了，生气地说：“同老人约会，为什么迟到？”随后离去，叫他再过五天早来。又过五天，张良鸡鸣时就去，老人仍已先到，再次发怒问他为什么迟来，离去前又说：“再过五天，更早些来。”第三个五天，张良不到半夜便去了。过了一会儿，老人来到，高兴地说：“就应当这样。”老人拿出一编书，说：“读了这书，就能做王者的老师。十年以后，你会兴起；十三年以后，你会在济北见到我，谷城山下的黄石就是我。”说完便走，没有其他话，张良此后也未再见到老人本人。 第二天张良看那书，原来是《太公兵法》，他觉得不寻常，常常研习诵读。拾履、赴约、授书、预言与老人化黄石相互连缀，是传记保存的神异故事；“直堕”古注有故意掉落、正好掉落等解释，白话不替老人确定隐藏动机，也不以书名证明现存某部兵书确为周代太公亲撰。 张良住在下邳时，以任侠行事。项伯曾杀过人，投到张良那里隐藏。这里是秦时交往的前事，没有单独确年；后来鸿门前夜项伯来告急，才与这段旧交相接。 [[1]](#note-1)

<a id="event-2"></a>

2. **授书后十三年与身后的黄石祭祀。** 传记回到当初下邳圯桥上授给子房《太公兵法》的老人：在那以后十三年，张良随高帝经过济北，果然看见谷城山下的黄石，取回珍藏供奉。张良死后，黄石也放入墓中合葬；后来每逢伏日、腊日上坟，还要祭祀黄石。十三年承接的是最初授书，并不是张良死后又过十三年；“果见”又回扣老人的预言，是神异叙事内部的应验，不作为超自然事实获证。随高帝过济北与死后祭祀还分属两个时段，本文没有给出可独立核定的起讫年月。 [[2]](#note-2)

<a id="event-3"></a>

3. **进入关中以后、晚年求退的两段叙述。** 留侯随皇帝进入关中。他素来多病，便做导引、停止进食谷物，闭门不出一年多。这里讲古代人物的养生实践，不说明疗效；“岁余”是持续时间，本篇没有给出开始和结束的确年，不能把紧随迁都的叙次当成完整日期。 张良又说，家世相韩，韩亡后不惜万金报仇；如今凭三寸之舌为帝王师、封万户、列侯，已到平民能达到的最高地位，自己很满足，愿弃人间事，跟赤松子遨游，遂学辟谷、导引轻身。这是求退及求仙的自述；没有证据把一次正式辞官、入山旅行或养生疗效写成已经发生。 [[3]](#note-3)

<a id="event-4"></a>

4. **征代马邑与劝立相国的散记。** 张良曾随帝征代，在马邑城下出奇计，又参与劝立萧何为相国；他平日从容议天下事还有很多。传记认为不是决定天下存亡的事情，便未详细写出，但这几个已经写出的事项仍保留在这里。奇计具体内容未载，不能把它借作陈平白登解围的另一名字；古注“出奇计下马邑”的异本也不能自行确定它是哪年攻城。萧何拜相国已有前196年年页，本句仅是张良参与谋议的散见文字，并不足以给具体劝说补出月日。 [[4]](#note-4)

<a id="event-5"></a>

5. **太史公论授书、天意与形貌。** 太史公说：学者多说没有鬼神，却又谈论某些异物；像留侯所见的老人授书，也确实使人觉得奇怪。高祖多次脱离困境，张良常常有功劳，难道可以说全非天意吗？皇帝说过：“在帷帐中筹划，决胜于千里之外，我不如子房。”司马迁原以为这样的人应当身材魁梧、仪表奇伟，等见到画像，却发现他的容貌像美好的女子。孔子曾说，以容貌取人，在子羽身上看错了；留侯也可以这样说。 这是司马迁自己的议论：授书的惊异、天意的反问、刘邦的自述、看画像后的感想各有说话主体。“物”古注解释为精怪及药物，不能译成现代物质主义概念；画像是作者所见之图，也不等于作者曾亲见张良本人。 [[5]](#note-5)

<a id="event-6"></a>

6. **唐司马贞述赞。** 司马贞的赞辞说：留侯洒脱不拘，心中怀着亡韩的愤恨；祖父、父亲侍奉韩国五代君王，后来归从汉。替老人进履而得到教诲，运筹谋算被赞为神妙；横阳君既立为韩王，张良任申徒护卫韩国。到霸上时扶救危难，在固陵使纷乱的局势安定；人们把他列入三杰，论辩则推重他的八难。他愿随赤松子遨游，人生如白驹般短暂而难以挽留。可叹拥有这样雄才大略的人，竟并不是魁梧高大的形貌。赞中“进履宜假”这里暂按进履受教、获得相助的诗语理解，不能另造一场借鞋事件；全段属于唐代后出述赞，不冒充司马迁原论或张良卒年新事。 [[6]](#note-6)

### 1. 袭秦以后、秦末起兵以前的下邳故事

[返回正文第1条](#event-1)

<a id="sj055-cite-005"></a>

**[《史记·留侯世家》P003](../../拆分史书/史记/卷055.md#p003)**

> 良嘗間從容步游下邳圯上，有一老父，衣褐，至良所，直墮其履圯下，顧謂良曰：「孺子，下取履！」良鄂然，欲毆之。為其老，彊忍，下取履。父曰：「履我！」良業為取履，因長跪履之。父以足受，笑而去。良殊大驚，隨目之。父去里所，復還，曰：「孺子可敎矣。後五日平明，與我會此。」良因怪之，跪曰：「諾。」五日平明，良往。父已先在，怒曰：「與老人期，後，何也？」去，曰：「後五日早會。」五日雞鳴，良往。父又先在，復怒曰：「後，何也？」去，曰：「後五日復早來。」五日，良夜未半往。有頃，父亦來，喜曰：「當如是。」出一編書，曰：「讀此則為王者師矣。後十年興。十三年孺子見我濟北，穀城山下黃石即我矣。」遂去，無他言，不復見。旦日視其書，乃太公兵法也。良因異之，常習誦讀之。

**本卷说明：** 授书故事在袭秦、匿下邳之后；“后十年”起兵、“十三年”黄石是故事内的相对数，所起算日未明，见[第2条](#note-2)。三次五日约、两次迟到及第三次夜半前到均完整译出。神异层照存，并不据此实证老人身份或太公书的成书年代。

### 2. 授书后十三年与身后的黄石祭祀

[返回正文第2条](#event-2)

<a id="sj055-cite-041"></a>

**[《史记·留侯世家》P028](../../拆分史书/史记/卷055.md#p028)**

> 子房始所見下邳圯上老父與太公書者，後十三年從高帝過濟北，果見穀城山下黃石，取而葆祠之。留侯死，并葬黃石冢。每上冢伏臘，祠黃石。

**本卷说明：** “后十三年”回指始授书，不承上一段张良卒；见老人故事与“果见”的应验结构。过济北所取黄石合葬，只说明石与人同墓，不证明张良就葬于济北。三家注p22的沛县墓说另存，不能以传说解决今日墓址。

### 4. 征代马邑与劝立相国的散记

[返回正文第4条](#event-4)

<a id="sj055-cite-037"></a>

**[《史记·留侯世家》P026](../../拆分史书/史记/卷055.md#p026)**

> 留侯從上擊代，出奇計馬邑下，及立蕭何相國，所與上從容言天下事甚衆，非天下所以存亡，故不著。

**本卷说明：** “非天下所以存亡，故不著”只是作者未详写的理由，已有的马邑、相国与天下谈议仍完整译存。古注有“出奇计下马邑”异本，与城下设策不同；不认定为[前200白登](../bce-0200-0101/bce-0200.md)或任意别年战事。萧何相国可参[前196既有年页](../bce-0200-0101/bce-0196.md)，但张良的具体劝说无单独日期。

### 5. 太史公论授书、天意与形貌

[返回正文第5条](#event-5)

<a id="sj055-cite-043"></a>

**[《史记·留侯世家》P030](../../拆分史书/史记/卷055.md#p030)**

> 太史公曰：學者多言無鬼神，然言有物。至如留侯所見老父予書，亦可怪矣。高祖離困者數矣，而留侯常有功力焉，豈可謂非天乎？上曰：「夫運籌筴帷帳之中，決勝千里外，吾不如子房。」余以為其人計魁梧奇偉，至見其圖，狀貌如婦人好女。蓋孔子曰：「以貌取人，失之子羽。」留侯亦云。

**本卷说明：** 司马迁之论独立于张良晚年事件。对授书惊异与天意的反问照译，不能删成现代无神论结论；画像、美妇及子羽是作者认识与论人，不伪定作于张良死年。

### 6. 唐司马贞述赞

[返回正文第6条](#event-6)

<a id="sj055-cite-044"></a>

**[《史记·留侯世家》Z001](../../拆分史书/史记/卷055.md#z001)**

> 【索隱述贊】留侯倜儻，志懷憤惋。五代相韓，一朝歸漢。進履宜假，運籌神算。橫陽既立，申徒作扞。灞上扶危，固陵靜亂。人稱三傑，辯推八難。赤松願游，白駒難絆。嗟彼雄略，曾非魁岸。

**本卷说明：** 唐代司马贞后出述赞，与司马迁太史公曰分层。五世指先人所事韩君，千里运筹、三杰、八难均为回顾；“进履宜假”诗语有解释空间，未把假字硬译成借一双鞋的另一事件。

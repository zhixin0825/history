# 战国晚期｜魏国的危局与游说（未定年）

[本世纪目录](README.md) · [全部时间目录](../README.md) · [魏国纪年考证](../../meta/考证/史记-卷044-纪年与异说.md)

**时间精度：战国晚期，秦昭王及信陵君活动时期的数段无确年故事。** 中旗、唐雎只明言秦昭王，魏君名未单独说明；范痤、无忌则与信陵君活动相接。各段没有独立年号，不能仅因排列在安釐王十一年后就都算作前266年。信陵君劝保韩的长说提到秦宣太后去世等前事，但全篇写定和实际游说的时间仍不能由这些线索精确限定。本页依原篇次序阅读，不据次序编造各故事的绝对先后。

<a id="sj044-zhongqi-event"></a>

1. **中旗提醒秦王，弱国仍可能因共同恐惧而联合。** 秦昭王以今日韩魏不如从前强、如耳魏齐也不如孟尝芒卯能干，推断韩魏无力威胁秦，左右随声附和。中旗扶琴进言：智伯也曾最强，率韩魏围晋阳，以水攻赵时得意地说才明白水能亡国；韩魏却想到安邑、平阳同样可以被灌，便在车上用肘足暗通意思，后来倒戈灭智。秦不能只比较兵力强弱，忽略受威胁者会联合自保。秦王听后警惕。此事在秦昭王时期，具体年份未详。 [[1]](#sj044-zhongqi-note)

<a id="sj044-tangju-event"></a>

2. **唐雎劝秦及时救魏，否则魏会转向齐楚。** 齐楚合兵逼近魏都，魏使接连赴秦，援兵却迟迟不到。九十余岁的唐雎请命西行，向秦昭王指出：魏依附秦，是相信秦能作强援；秦若等到魏穷迫才救，魏可能已割地同齐楚讲和。那时秦既失掉东方的魏，又使齐楚更强，反而不利。秦王于是出兵，魏的局面得以安定。原篇没有独立年号，不能仅因排在安釐王十一年以后，就把这次战争确作前266年。 [[2]](#sj044-tangju-note)

<a id="sj044-fancuo-event"></a>

3. **范痤先拖延处死，再以信陵君自身的危险争取援救。** 赵国愿献七十里地，条件是魏杀前相范痤。魏王答应，使吏围住范痤。范痤爬上屋顶、骑在屋脊上，说若先杀人而赵反悔不给地，魏便无法追索，不如先定割地再动手；魏王认可。范痤趁机写信给信陵君，说强秦若也用土地向魏换取您的性命，又怎么办？信陵君向王进言，范痤遂获释。赵魏是否已完成土地交割，原文没有说。 [[3]](#sj044-fancuo-note)

<a id="sj044-xinchang-intro-event"></a>

4. **信陵君反对魏因受秦援助，就随秦灭韩。** 魏王想亲秦攻韩，收回旧地；公子无忌却认为这会消灭魏秦之间的缓冲。他先以秦太后忧死、穰侯被逐及兄弟失封等为例，质疑秦会因一次援救而长久保护魏。文中用“虎狼”等激烈比喻，是无忌游说时的批评，不能变成编者对某族的性格定论。此说未标确年；文内提到宣太后之死，说明不能简单附在前266年。 [[4]](#sj044-xinchang-intro-note)

<a id="sj044-xinchang-geography-event"></a>

5. **无忌认为韩国一亡，秦最容易攻击的就是魏。** 无忌形容韩国由一女子辅佐弱主，内乱又受外兵，若被秦魏夹灭，秦即据郑地逼近大梁。他比较进攻路线：攻赵若越山河、切过韩上党，可能再遭阏与的阻击；若循河内、背邺和朝歌而行，渡漳滏到邯郸郊外决战，又可能遇到智伯围晋阳那样的困局。攻楚若涉谷远行、攻冥阸险塞，路远且难；若走河外、背大梁，经上蔡、召陵向陈深入，也有风险。魏却近在秦可进军的方向，所以不能指望秦吞韩之后先去攻楚赵。 [[5]](#sj044-xinchang-geography-note)

<a id="sj044-xinchang-warning-event"></a>

6. **他把危险具体到河内、大梁和魏国南境。** 秦已有怀、茅、邢丘，再据河津就能威胁共、汲；得到郑地、垣雍，又可能借荥泽水攻大梁。魏使若在秦诋毁安陵氏，也会使魏南境更暴露。无忌回顾秦还远在河西、隔着山河周韩时，便已多次深入魏境，焚城台、毁园囿，夺去许多县邑；若吞韩后近到梁旁，魏失去屏障，祸患会更重。这里的水攻是预警，不是前225年秦灌大梁已经提前发生。 [[6]](#sj044-xinchang-warning-note)

<a id="sj044-xinchang-plan-event"></a>

7. **无忌提出保韩合纵、以援助换旧地的方案。** 从前楚魏互疑，韩又未加入；如今韩受兵多年，已看出秦的和议不能保其存亡，愿送质子到赵，担当前线抵抗。无忌劝魏接受楚赵之约，以存韩换回故地，无须劳民作战。再打通韩上党与共、宁、安成的通道、掌握出入赋税，魏可富国，韩则因依赖而不敢背离，卫、大梁、河外也较安全。他以不保韩将危及二周、安陵、楚赵卫齐作结；原文没有写王已批准全部方案，不能把设想变成既成的领土与税收制度。 [[7]](#sj044-xinchang-plan-note)

### 1. 中旗提醒秦王，弱国仍可能因共同恐惧而联合

[返回正文第1条](#sj044-zhongqi-event)

<a id="sj044-cite-150"></a>

**[《史记·魏世家》P057](../../sources/摘录/史记-卷044-魏世家.md#p057)**

> 秦昭王謂左右曰：「今時韓、魏與始孰彊？」對曰：「不如始彊。」王曰：「今時如耳、魏齊與孟嘗、芒卯孰賢？」對曰：「不如。」王曰：「以孟嘗、芒卯之賢，率彊韓、魏以攻秦，猶無柰寡人何也。今以無能之如耳、魏齊而率弱韓、魏以伐秦，其無柰寡人何亦明矣。」左右皆曰：「甚然。」中旗馮琴而對曰：「王之料天下過矣。當晉六卿之時，知氏最彊，滅范、中行，又率韓、魏之兵以圍趙襄子於晉陽，決晉水以灌晉陽之城，不湛者三版。知伯行水，魏桓子御，韓康子為參乘。知伯曰：『吾始不知水之可以亡人之國也，乃今知之。』汾水可以灌安邑，絳水可以灌平陽。魏桓子肘韓康子，韓康子履魏桓子，肘足接於車上，而知氏地分，身死國亡，為天下笑。今秦兵雖彊，不能過知氏；韓、魏雖弱，尚賢其在晉陽之下也。此方其用肘足之時也，願王之勿易也！」於是秦王恐。

**本卷说明：** 同号原文回顾前453晋阳灭智，不能把这一回顾写成本期第二次灭智。中旗身份不据名字补定官爵。

### 2. 唐雎劝秦及时救魏，否则魏会转向齐楚

[返回正文第2条](#sj044-tangju-event)

<a id="sj044-cite-151"></a>

**[《史记·魏世家》P058](../../sources/摘录/史记-卷044-魏世家.md#p058)**

> 齊、楚相約而攻魏，魏使人求救於秦，冠蓋相望也，而秦救不至。魏人有唐雎者，年九十餘矣，謂魏王曰：「老臣請西說秦王，令兵先臣出。」魏王再拜，遂約車而遣之。唐雎到，入見秦王。秦王曰：「丈人芒然乃遠至此，甚苦矣！夫魏之來求救數矣，寡人知魏之急已。」唐雎對曰：「大王已知魏之急而救不發者，臣竊以為用策之臣無任矣。夫魏，一萬乘之國也，然所以西面而事秦，稱東藩，受冠帶，祠春秋者，以秦之彊足以為與也。今齊、楚之兵已合於魏郊矣，而秦救不發，亦將賴其未急也。使之大急，彼且割地而約從，王尚何救焉？必待其急而救之，是失一東藩之魏而彊二敵之齊、楚，則王何利焉？」於是秦昭王遽為發兵救魏。魏氏復定。

**本卷说明：** 唐雎年龄为本篇所记。这里不与其他篇章同名者合并寿命，也不凭相邻条目给齐楚攻魏强定年。

### 3. 范痤先拖延处死，再以信陵君自身的危险争取援救

[返回正文第3条](#sj044-fancuo-event)

<a id="sj044-cite-152"></a>

**[《史记·魏世家》P059](../../sources/摘录/史记-卷044-魏世家.md#p059)**

> 趙使人謂魏王曰：「為我殺范痤，吾請獻七十里之地。」魏王曰：「諾。」使吏捕之，圍而未殺。痤因上屋騎危，謂使者曰：「與其以死痤市，不如以生痤市。有如痤死，趙不予王地，則王將柰何？故不若與先定割地，然後殺痤。」魏王曰：「善。」痤因上書信陵君曰：「痤，故魏之免相也，趙以地殺痤而魏王聽之，有如彊秦亦將襲趙之欲，則君且柰何？」信陵君言於王而出之。

**本卷说明：** 无确年事，保留魏安釐王、公子无忌活动时期，不把范痤与前362少梁被俘的公孙痤混为一人。

<a id="sj044-xinchang-geography-note"></a>

### 5. 无忌认为韩国一亡，秦最容易攻击的就是魏

[返回正文第5条](#sj044-xinchang-geography-event)

<a id="sj044-cite-155"></a>

**[《史记·魏世家》P062](../../sources/摘录/史记-卷044-魏世家.md#p062)**

> 今韓氏以一女子奉一弱主，內有大亂，外交彊秦魏之兵，王以為不亡乎？韓亡，秦有鄭地，與大梁鄴，王以為安乎？王欲得故地，今負彊秦之親，王以為利乎？

**本卷说明：** 主TXT“与大梁鄴”，三家注p61明校“鄴”当“鄰”；白话据邻近之义，原字符仍保留。“一女子奉一弱主”保留说辞概括，女子身份不补定。

<!-- /sj044-cite-155 -->

<a id="sj044-cite-156"></a>

**[《史记·魏世家》P063](../../sources/摘录/史记-卷044-魏世家.md#p063)**

> 秦非無事之國也，韓亡之後必將更事，更事必就易與利，就易與利必不伐楚與趙矣。是何也？夫越山踰河，絕韓上黨而攻彊趙，是復閼與之事，秦必不為也。若道河內，倍鄴、朝歌，絕漳滏水，與趙兵決於邯鄲之郊，是知伯之禍也，秦又不敢。伐楚，道涉谷，行三千里。而攻冥阸之塞，所行甚遠，所攻甚難，秦又不為也。若道河外，倍大梁，右（蔡左）［上蔡］、召陵，與楚兵決於陳郊，秦又不敢。故曰秦必不伐楚與趙矣，又不攻衛與齊矣。

**本卷说明：** 全段为无忌论证秦下一步选择的推测，不把假定路线逐条编成已发生战役。

### 6. 他把危险具体到河内、大梁和魏国南境

<a id="sj044-cite-157"></a>

**[《史记·魏世家》P064](../../sources/摘录/史记-卷044-魏世家.md#p064)**

> 夫韓亡之後，兵出之日，非魏無攻已。秦固有懷、茅、邢丘，城垝津以臨河內，河內共、汲必危；有鄭地，得垣雍，決熒澤水灌大梁，大梁必亡。王之使者出過而惡安陵氏於秦，秦之欲誅之久矣。秦葉陽、昆陽與舞陽鄰，聽使者之惡之，隨安陵氏而亡之，繞舞陽之北，以東臨許，南國必危，國無害（已）［乎］？

<a id="sj044-cite-158"></a>

### 7. 无忌提出保韩合纵、以援助换旧地的方案

[返回正文第7条](#sj044-xinchang-plan-event)

<a id="sj044-cite-159"></a>

**[《史记·魏世家》P066](../../sources/摘录/史记-卷044-魏世家.md#p066)**

> 異日者，從之不成也，楚、魏疑而韓不可得也。今韓受兵三年，秦橈之以講，識亡不聽，投質於趙，請為天下鴈行頓刃，楚、趙必集兵，皆識秦之欲無窮也，非盡亡天下之國而臣海內，必不休矣。是故臣願以從事王，王速受楚趙之約，（趙）［而］挾韓之質以存韓，而求故地，韓必效之。此士民不勞而故地得，其功多於與秦共伐韓，而又與彊秦鄰之禍也。

**本卷说明：** “韩则魏之县”是游说中的依附比喻，不是韩国真的被魏设置成县。

<!-- /sj044-cite-159 -->

<a id="sj044-cite-160"></a>

**[《史记·魏世家》P067](../../sources/摘录/史记-卷044-魏世家.md#p067)**

> 夫存韓安魏而利天下，此亦王之天時已。通韓上黨於共、甯，使道安成，出入賦之，是魏重質韓以其上黨也。今有其賦，足以富國。韓必德魏愛魏重魏畏魏，韓必不敢反魏，是韓則魏之縣也。魏得韓以為縣，衛、大梁、河外必安矣。今不存韓，二周、安陵必危，楚、趙大破，衛、齊甚畏，天下西鄉而馳秦入朝而為臣不久矣。

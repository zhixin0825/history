# 战国晚期｜苏代、苏厉与燕齐游说（未定年）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷069完整对读](../../sources/摘录/史记-卷069-苏秦列传.md) · [纪年异说](../../meta/考证/史记-卷069-纪年与异说.md)

苏代、苏厉不是苏秦的别名。对燕哙子之之乱、齐并宋与五国伐齐等可确战争，仍以统一逐年页为准：[前316年燕哙让位](../bce-0400-0301/bce-0316.md#note-2)和[前284年合兵伐齐](bce-0284.md#note-1)。本页容纳无确年或长篇政策主张。

## 故事与谋略（按传文逻辑，并非逐年确年表）

<a id="event-1"></a>

1. **苏代与燕哙、子之。** 苏代与燕相子之有姻亲，传文说其一句齐王不信任大臣的话影响燕哙，使燕哙更重子之乃至让位。确年政治事实见前316年，话语起作用的程度仍须多书互读。 [[1]](#note-1)

<a id="event-2"></a>

2. **齐攻宋时苏代致书燕昭王。** 苏代告诫燕王，助齐取宋将使齐更强，燕劳兵失利；又建议以表面尊齐、挑动秦齐矛盾的方式为日后伐齐创造形势。外交设想不是已发生战事。 [[2]](#note-2)

<a id="event-3"></a>

3. **燕联合攻齐的结果。** 燕昭王重新重用苏代，本篇概述破齐、齐湣王逃走。实际五国伐齐、济西大败齐军并进入临淄，应在前284主线分别阅读，不因本传“竟破齐”新造战争。 [[3]](#note-3)

<a id="event-4"></a>

4. **拆解秦向各国许地与威胁的策略。** 苏代给燕王分析秦以蜀汉水道压楚、宜阳压韩、黄河水道威魏，并对燕赵魏楚齐分别许以胶东、济西、叶蔡等地的说辞。这些条件句保留在此，不作为秦已征得各地的事实。 [[4]](#note-4)

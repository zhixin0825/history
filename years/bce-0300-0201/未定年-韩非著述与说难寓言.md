# 战国晚期｜韩非著述与《说难》寓言（未定年）

[本世纪目录](README.md) · [全部时间目录](../README.md)

**时间精度：** 韩非生前的谏书、著述及其中所引故事。写作年月不详；论辩中的古人和宋、郑、卫故事不另配事件年。《说难》在传记中的引用次序照存，韩非使秦及死亡另接前233年。

[本期相关史料](#sources-start)

<a id="sj063-hanfei-writings-event"></a>

1. **韩非屡谏不被采用，转而著书批评韩国用人和治政。** 他忧虑韩国日弱，多次上书，却不被韩王采用。他要求修明法制、掌握权势以御臣、富国强兵，反对把浮夸害政者置于有实绩者之上；又指责儒者以文乱法、游侠以武犯禁，平时养名士，危急才用甲士，使供养与任用脱节。他感叹廉直不容于邪臣，考察往古得失，写出《孤愤》《五蠹》《内外储》《说林》《说难》等十余万言。 [[1]](#sj063-hanfei-writings-note)

<a id="sj063-shuinan-intro-event"></a>

2. **《说难》把困难放在理解对方心意。** 引文先说，游说的艰难不只取决于知识、辩才或能否尽言；关键在于摸清所说之人的心思，使自己的话与之相合。 [[2]](#sj063-shuinan-intro-note)

<a id="sj063-name-profit-event"></a>

3. **求名、求利和内外不一，使同一套说辞产生相反效果。** 求高名者听厚利，可能觉得节操被贬而疏远说客；求厚利者听高名，可能嫌离实际太远而不纳。若实欲求利、表面慕名，说客谈名会被表面接纳、实际疏远，谈利则可能暗中见用、公开遭弃。 [[3]](#sj063-name-profit-note)

<a id="sj063-risks-event"></a>

4. **说客即使说对，也可能因泄密嫌疑、争功或触忤而获祸。** 谈及被隐藏的事、揭出贵人的过失、恩遇未深便尽言，都可能招险；建议成功可能不见记功，失败又可能被疑。知道君主计策的来历，可能妨碍他独揽功劳；探知公开行事背后的筹划，也可能招险。强劝其不肯做、阻止其不能停止的事，同样危险。谈贵者可被疑离间，谈微者可被疑出卖君主的权势；谈其所爱被看成借势，谈其所憎又像试探。言简可被责无知，言繁可被嫌拖延；顺着事情讲被责怯懦，纵论谋划又被斥粗野傲慢。 [[4]](#sj063-risks-note)

<a id="sj063-trust-event"></a>

5. **取得信任以后，才可能尽言利害、直指是非。** 文章先讲怎样顺着对方所尊重的事加以修饰、避开其羞耻，不因计策、勇断、力量等自负而迎面逼迫；谈相近之事、同行之人，也须顾及对方。即使尽忠，言辞仍避免直接冲撞排斥。等恩遇日深，深谋不被疑、争论不获罪，才可明确比较利害以成其功、指明是非以正其行，使君臣得以相互维持。 [[5]](#sj063-trust-note)

<a id="sj063-humble-entry-event"></a>

6. **伊尹、百里奚被作为卑屈求进的论例。** 文章以伊尹为庖、百里奚为俘说明，两位被称作圣人的人物，也要通过劳役自身、处于卑微地位来接近君主；有才之士不应把这类进身境遇视为羞耻。 [[6]](#sj063-humble-entry-note)

<a id="sj063-two-examples-event"></a>

7. **宋富人疑邻与郑武公伐胡，说明知与处知的距离。** 宋人家的墙被雨毁，儿子和邻居老人都提醒修补，否则会遭盗；夜里果然失财，主人却只夸儿子聪明，反疑邻人。另一故事说，郑武公先嫁女于胡君，又问可伐何国；关其思答胡可伐，反被武公以胡是兄弟之国为由杀掉。胡君于是相信郑亲近自己，放松戒备，终于被袭取。两人所言都对，却一被疑、一被杀；文章由此区分知道道理与善处其知。 [[7]](#sj063-two-examples-note)

<a id="sj063-mizi-event"></a>

8. **弥子瑕的余桃，表现宠爱改变以后评价如何翻转。** 弥子瑕原受卫君宠爱，母病时假托君命乘车出宫，虽依故事中的卫法可受刖足，卫君却称其孝；吃桃觉得甘甜，留下未尽者献君，又获称爱君。后来色衰爱弛，卫君反把私驾与余桃当作旧过。文章指出行为没有变，爱憎变了，所受褒贬就不同，因此进说须先察君心。 [[8]](#sj063-mizi-note)

<a id="sj063-dragon-event"></a>

9. **逆鳞之喻，以触犯君主禁忌作《说难》结尾。** 龙虽然可以驯近骑乘，喉下却有径尺逆鳞，触之就会被杀。作者以此比拟君主的不可触犯处，认为说客能避开它，才接近游说的成功。 [[9]](#sj063-dragon-note)

> 所說出於為名高者也，而說之以厚利，則見下節而遇卑賤，必棄遠矣。所說出於厚利者也。而說之以名高，則見無心而遠事情，必不收矣。所說實為厚利而顯為名高者也，而說之以名高，則陽收其身而實疏之；若說之以厚利，則陰用其言而顯棄其身。此之不可不知也。

### 4. 说客即使说对，也可能因泄密嫌疑、争功或触忤而获祸

[返回正文第4条](#sj063-risks-event)

<a id="sj063-cite-024"></a>

**[《史记·老子韩非列传》P018](../../sources/摘录/史记-卷063-老子韩非列传.md#p018)**

> 夫事以密成，語以泄敗。未必其身泄之也，而語及其所匿之事，如是者身危。貴人有過端，而說者明言善議以推其惡者，則身危。周澤未渥也而語極知，說行而有功則德亡，說不行而有敗則見疑，如是者身危。夫貴人得計而欲自以為功，說者與知焉，則身危。彼顯有所出事，迺自以為也故，說者與知焉，則身危。彊之以其所必不為，止之以其所不能已者，身危。故曰：與之論大人，則以為閒己；與之論細人，則以為粥權。論其所愛，則以為借資；論其所憎，則以為嘗己。徑省其辭，則不知而屈之；汎濫博文，則多而久之。順事陳意，則曰怯懦而不盡；慮事廣肆，則曰草野而倨侮。此說之難，不可不知也。

**本卷说明：** 德亡依索隐所引见忘义理解为功德不被记取。“彼显有所出事，迺自以为也故”字句有疑，注本另断句；索隐释争功，正义释营为，白话宽译为行事自有筹划、知其情由也有危险。古注借项羽、景帝、周亚夫为例，均是后人解释，不能放回韩非原作当作预知汉事。

### 7. 宋富人疑邻与郑武公伐胡，说明知与处知的距离

[返回正文第7条](#sj063-two-examples-event)

<a id="sj063-cite-030"></a>

**[《史记·老子韩非列传》P021](../../sources/摘录/史记-卷063-老子韩非列传.md#p021)**

> 宋有富人，天雨牆壞。其子曰「不築且有盜」，其鄰人之父亦云，暮而果大亡其財，其家甚知其子而疑鄰人之父。昔者鄭武公欲伐胡，迺以其子妻之。因問群臣曰：「吾欲用兵，誰可伐者？」關其思曰：「胡可伐。」迺戮關其思，曰：「胡，兄弟之國也，子言伐之，何也？」胡君聞之，以鄭為親己而不備鄭。鄭人襲胡，取之。此二說者，其知皆當矣，然而甚者為戮，薄者見疑。非知之難也，處知則難矣。

### 8. 弥子瑕的余桃，表现宠爱改变以后评价如何翻转

[返回正文第8条](#sj063-mizi-event)

<a id="sj063-cite-032"></a>

**[《史记·老子韩非列传》P022](../../sources/摘录/史记-卷063-老子韩非列传.md#p022)**

> 昔者彌子瑕見愛於衛君。衛國之法，竊駕君車者罪至刖。既而彌子之母病，人聞，往夜告之，彌子矯駕君車而出。君聞之而賢之曰：「孝哉，為母之故而犯刖罪！」與君游果園，彌子食桃而甘，不盡而奉君。君曰：「愛我哉，忘其口而念我！」及彌子色衰而愛弛，得罪於君。君曰：「是嘗矯駕吾車，又嘗食我以其餘桃。」故彌子之行未變於初也，前見賢而後獲罪者，愛憎之至變也。故有愛於主，則知當而加親；見憎於主，則罪當而加疏。故諫說之士不可不察愛憎之主而後說之矣。

**本卷说明：** 本段未名卫君，正文不自行改称卫灵公；所叙法令是寓言设定与原引，不据此编定卫国法制实施年。

### 太史公的总论与唐代述赞

以下为史家与唐代注者的评价，附在著述阅读之后；不是韩非生前新发生的事件，也不替评论确定写作年。

<a id="sj063-cite-037"></a>

**[《史记·老子韩非列传》P025](../../sources/摘录/史记-卷063-老子韩非列传.md#p025)**

> 太史公曰：老子所貴道，虛無，因應變化於無為，故著書辭稱微妙難識。莊子散道德，放論，要亦歸之自然。申子卑卑，施之於名實。韓子引繩墨，切事情，明是非，其極慘礉少恩。皆原於道德之意，而老子深遠矣。

**本卷说明：** 太史公说：老子所尊崇的道，以虚无为本，在无为中顺应变化，所以书中的言辞微妙难明。庄子铺陈道与德，放开议论，要旨也归于自然。申不害勤勉用力，把学说实行于名与实的关系。韩非用准绳来衡量事物，切合实际情形，辨明是非，但推到极处，却严酷苛刻，少有恩厚。这些学说都出于道与德的旨意，而老子的思想最为深远。 卑卑依集解、索隐释自勉励，不作卑鄙；惨礉指刻深用法。

<!-- /sj063-cite-037 -->

**[《史记·老子韩非列传》Z001](../../sources/摘录/史记-卷063-老子韩非列传.md#z001)**

> 〔索隱〕述贊曰：伯陽立教，清淨無爲。道尊東魯，迹竄西垂。莊蒙栩栩，申害卑卑。刑名有術，說難極知。悲彼周防，終亡李斯。

**本卷说明：** 司马贞赞道：伯阳立教，崇尚清静无为；其道受到东方鲁地的尊崇，行迹却隐向西方边地。蒙地的庄周栩栩自得，申不害勤勉从事；刑名之学有治术，《说难》穷尽思虑。可悲的是，韩非防范得如此周密，最终仍丧身于李斯之手。 此赞只见注本p27，主TXT未收；伯阳称号沿唐赞，不反改P001字聃。

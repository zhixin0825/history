<a id="本年纪事"></a>
<a id="event-1"></a>

1. **蜀侯煇反秦，司马错前往平定。** 同年庶长奂攻楚，本纪报斩首二万，并有日食昼晦的记录。秦同时处理西南统治与东面对楚战争。 [[1]](#note-1)

<a id="event-2"></a>

2. **齐、韩、魏等军队攻楚，唐昧败亡，楚失重丘。** 章子、公孙喜、暴鸢等率军攻楚方城，楚军受挫。本篇还列秦参与；秦另向楚用兵与联军攻势相关，但不能把各路战果都归一个将领。 [[2]](#note-2)

<a id="sj015-0301-han-event"></a>

<a id="event-3"></a>

3. **秦国夺取韩国的穰。** 韩国同年参加秦方攻楚，并不意味着它与秦之间已经没有战争与割地。 [[3]](#note-3)

<a id="sj015-0301-zhao-event"></a>

<a id="event-4"></a>

4. **赵国进攻中山，王室又有后妃去世与王子教育的记载。** 本篇记武灵王二十五年惠后卒，命周袑穿胡服辅导王子何。“惠后”在这里指谁，与后文吴娃及古注解释有矛盾，不无条件认作孟姚。 [[4]](#note-4)

<a id="sj015-0301-qi-accession"></a>

<a id="event-5"></a>

5. **齐宣王去世，儿子地继位，即齐湣王。** [[5]](#note-5)

### 1. 蜀侯煇反秦，司马错前往平定

[返回正文第1条](#event-1)

**[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)**

> 昭襄王元年，嚴君疾為相。甘茂出之魏。二年，彗星見。庶長壯與大臣、諸侯、公子為逆，皆誅，及惠文后皆不得良死。悼武王后出歸魏。三年，王冠。與楚王會黃棘，與楚上庸。四年，取蒲阪。彗星見。五年，魏王來朝應亭，復與魏蒲阪。六年，蜀侯煇反，司馬錯定蜀。庶長奐伐楚，斬首二萬。涇陽君質於齊。日食，晝晦。七年，拔新城。摢裏子卒。八年，使將軍羋戎攻楚，取新市。齊使章子，魏使公孫喜，韓使暴鳶共攻楚方城，取唐眛。趙破中山，其君亡，竟死齊。魏公子勁、韓公子長為諸侯。九年，孟嘗君薛文來相秦。奐攻楚，取八城，殺其將景快。十年，楚懷王入朝秦，秦留之。薛文以金受免。樓緩為丞相。十一年，齊、韓、魏、趙、宋、中山五國共攻秦，至鹽氏而還。秦與韓、魏河北及封陵以和。彗星見。楚懷王走之趙，趙不受，還之秦，即死，歸葬。十二年，樓緩免，穰侯魏冉為相。予楚粟五萬石。

## 归年与考证

<a id="sj005-216-note"></a>
<a id="sj005-216蜀侯煇反秦司马错前往平定"></a>
#### sj005-216｜蜀侯煇反秦，司马错前往平定。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**日食只保留古书见闻，不自行用天象反推战争的精确日。蜀侯煇与前几年蜀相壮不是同一人。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj005-217-note"></a>
<a id="sj005-217齐韩魏等军队击楚唐昧败亡"></a>
#### sj005-217｜齐、韩、魏等军队击楚，唐昧败亡。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**本纪列昭王八年段，年表楚栏为怀王二十八年即前301；仍按前301，唐昧不在前299再败一次。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0301-qin-note"></a>
<a id="卷015秦栏前301年"></a>
#### 卷015·秦栏｜前301年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0301)：“六。蜀反，司馬錯往誅蜀守煇，定蜀。日蝕，晝晦。伐楚。”

蜀反、诛煇、日食、伐楚归旧第一条；蜀守／蜀侯称谓保持各见证差别。[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-080d1a675f7256)校刊记转引天文考证质疑“昼晦”的年份，本页仍只说明旧记，未自行历算并移年，亦不以天象确定战争日期。 [对应正文](#event-1)

<a id="sj015-0301-wei-note"></a>
<a id="卷015魏栏前301年"></a>
#### 卷015·魏栏｜前301年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0301)：“十八。與秦擊楚。”

与韩、齐、秦联合击楚，合入[原页第二条](#event-2)；不同参战国互见，不另造一场魏独破唐昧。

<a id="sj015-0301-han-note"></a>
<a id="卷015韩栏前301年"></a>
#### 卷015·韩栏｜前301年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0301)：“十一。秦取我穰。與秦擊楚。”

与秦攻楚归[既有第二条](#event-2)；另补秦从韩取穰，不能因为同年共同攻楚就抹去秦韩之间仍有领土冲突。

<a id="sj015-0301-zhao-note"></a>
<a id="卷015赵栏前301年"></a>
#### 卷015·赵栏｜前301年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0301)：“二十五。趙攻中山。惠后卒。”

赵攻中山与惠后去世是同格两项，[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-c1469aea2c5b22)武灵王二十五年亦记之；不把惠后之死解释成此战必然原因。

<a id="sj015-0301-chu-note"></a>
<a id="卷015楚栏前301年"></a>
#### 卷015·楚栏｜前301年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0301)：“二十八。秦、韓、魏、齊敗我將軍唐眛於重丘。”

“唐眛”与唐昧为字形互见；地点重丘据表和[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-68a60163799687)补入旧第二条。《秦本纪》把相关段落接在昭王八年，不在前299再造一次唐昧战死。 [对应正文](#event-2)

<a id="sj015-0301-qi-note"></a>
<a id="卷015齐栏前301年"></a>
#### 卷015·齐栏｜前301年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0301)：“二十三。與秦擊楚，使公子將，大有功。”

齐军公子领兵与有功，只按表中简记保存；原页第二条另据秦本纪列章子等人，不未经证明把“公子”直接等同章子，或给各国贡献分数。 [对应正文](#event-2)

<a id="衔接说明齐宣王去世儿子地继位即齐湣王"></a>
#### 衔接说明｜齐宣王去世，儿子地继位，即齐湣王

[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-5de5b82a2bdd70)校刊记移置本年；下一年前300为湣王元年。卷015旧表将湣王元年提前至前323，本文保留两层年链。

### 卷023｜礼制沿革与本页史事互见

[L005原文](../../sources/摘录/史记-卷023-礼书.md#l005)。本年唐昧败亡已有完整事件。卷023垂涉、唐昧与荀子议兵垂沙、唐蔑为同一例证的异字；不另战一次。其后庄蹻起没有本段独立明年，不强写成前301年同日即起事，更不把王滇故事并为本年结局。

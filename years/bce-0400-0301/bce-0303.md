# 公元前303年｜秦取蒲阪，附记又说“为田开阡陌”

[← 公元前304年](bce-0304.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前302年 →](bce-0302.md)

**秦昭襄王四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦取得魏国蒲阪、晋阳、封陵，又夺取韩国武遂。** 秦在下一年把蒲阪归还魏国，各次交割分别保存。本年另有彗星的记载。 [[1]](#note-1)

<a id="event-2"></a>

2. **田地界限方面的措施，又一次见于秦的记录。** 《秦始皇本纪》篇末在昭襄王四年写“初为田开阡陌”。商鞅时代已有有关阡陌、田界的改革，这里的“初”不能不经辨析就推翻先前记载，或把商鞅本人移到本年继续执政。 [[2]](#note-2)

<a id="sj015-0303-chu-event"></a>

<a id="event-3"></a>

3. **齐、韩、魏联合攻楚，楚怀王把太子横送到秦国为质，请秦出兵。** 秦派客卿通领军救楚，来攻的联军退去。 [[3]](#note-3)

<a id="sj043-attack-zhongshan-event"></a>

4. **赵再攻中山。** 武灵王二十三年的记事未详列将领与所得城邑。 [[4]](#sj043-attack-zhongshan-note)

## 本年相关史料

<a id="note-1"></a>

### 1. 秦取得魏国蒲阪、晋阳、封陵，又夺取韩国武遂

[返回正文第1条](#event-1)

**[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)**

> 昭襄王元年，嚴君疾為相。甘茂出之魏。二年，彗星見。庶長壯與大臣、諸侯、公子為逆，皆誅，及惠文后皆不得良死。悼武王后出歸魏。三年，王冠。與楚王會黃棘，與楚上庸。四年，取蒲阪。彗星見。五年，魏王來朝應亭，復與魏蒲阪。六年，蜀侯煇反，司馬錯定蜀。庶長奐伐楚，斬首二萬。涇陽君質於齊。日食，晝晦。七年，拔新城。摢裏子卒。八年，使將軍羋戎攻楚，取新市。齊使章子，魏使公孫喜，韓使暴鳶共攻楚方城，取唐眛。趙破中山，其君亡，竟死齊。魏公子勁、韓公子長為諸侯。九年，孟嘗君薛文來相秦。奐攻楚，取八城，殺其將景快。十年，楚懷王入朝秦，秦留之。薛文以金受免。樓緩為丞相。十一年，齊、韓、魏、趙、宋、中山五國共攻秦，至鹽氏而還。秦與韓、魏河北及封陵以和。彗星見。楚懷王走之趙，趙不受，還之秦，即死，歸葬。十二年，樓緩免，穰侯魏冉為相。予楚粟五萬石。

## 归年与考证

<a id="sj005-214-note"></a>
<a id="1蒲阪与天象"></a>
#### 1｜蒲阪与天象

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。归年沿既有[卷005考证](../../meta/考证/史记-卷005-纪年与异说.md)，不补古书没有的围城经过或地理边界。

<a id="sj006-076-note"></a>
<a id="2田开阡陌"></a>
#### 2｜田开阡陌

[卷006 P076](../../sources/摘录/史记-卷006-秦始皇本纪.md#p076)：“立四年，初為田開阡陌。”按昭襄元年前306年，四年对应前303。与[前350年](bce-0350.md)商鞅时的田界措施分开保留；可能涉及继续推行、对象不同或文本年次问题，但原句不足以在这里确定哪一种解释。不把它无声改成年份相同的重复事件，也不补一个确定的全国土地所有制转换日。

<a id="sj015-0303-qin-note"></a>
<a id="卷015秦栏前303年"></a>
#### 卷015·秦栏｜前303年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0303)：“四。彗星見。”

彗星接原页第一条，与本年秦取城并列，不当作胜负或田制改革的原因。 [对应正文](#event-1)

<a id="sj015-0303-wei-note"></a>
<a id="卷015魏栏前303年"></a>
#### 卷015·魏栏｜前303年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0303)：“十六。秦拔我蒲阪、晉陽、封陵。”

原页仅列蒲阪，本格补晋阳、封陵，[《通鉴》卷三及校刊记](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-10eabe94c9a3ef)同列。此处晋阳仍按古名保留，不未经辨析一概等同赵都晋阳。 [对应正文](#event-1)

<a id="sj015-0303-han-note"></a>
<a id="卷015韩栏前303年"></a>
#### 卷015·韩栏｜前303年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0303)：“九。秦取武遂。”

武遂归入[本页取城条](#event-1)；前306还韩与本次取回不是矛盾材料，不删其中一环。

<a id="sj015-0303-chu-note"></a>
<a id="卷015楚栏前303年"></a>
#### 卷015·楚栏｜前303年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0303)：“二十六。太子質秦。”

楚太子横质秦，[《通鉴》卷三及校刊记](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-597c2495f1d837)记楚因齐韩魏来攻而向秦求救，秦客卿通率军援楚后联军退；质子与求援相联系。翌年太子杀秦大夫后逃归另有记载，不全挤入本年。

<a id="event-1"></a>

1. **昭襄王初年由严君疾为相，甘茂离秦。** 王位突然转移后，秦的辅政人选再次变化。甘茂在此卷被写为出之魏，后续列传对路线和最终所在有更细记载。 [[1]](#note-1)

<a id="sj015-0306-wei-event"></a>

<a id="event-2"></a>

2. **秦军围攻魏国皮氏，没有攻下便解除包围。** 秦在这一阶段也把武遂交还韩国，以和议调整与邻国的关系。 [[2]](#note-2)

<a id="sj040-chu-qihan-discussion-event"></a>

3. **怀王后半期的外交讨论，在亲秦与联齐韩之间反复。** 这段说辞含数年背景，不能确定为本年一次会议。齐王来信说楚抢先事秦会促韩魏燕赵也亲秦，反使楚孤立，主张尊周息民后合攻秦，许楚取武关蜀汉、据吴越江海之利，韩魏分取上党而西逼函谷。昭雎说此前东取越地不足洗雪秦辱，必须收回秦侵楚地；宜借齐韩支持抬高樗里疾，再让他替楚求地。韩畏武遂迫近先王墓、又怕三川上党河外受敌，而楚是其援，韩公子眛为齐相又连接齐韩；秦还武遂后，韩更当报楚。怀王一度接受，转亲齐韩。这是外交议论回顾越地，未给无疆死亡作确定纪年。 [[3]](#sj040-chu-qihan-discussion-note)

<a id="sj043-northwest-event"></a>

4. **赵武灵王向西北经略，并分遣使节联络五国。** 王略中山至宁葭，西巡胡地到榆中，林胡王献马。归后派楼缓使秦、仇液使韩、王贲使楚、富丁使魏、赵爵使齐，命代相赵固主管胡人、征集其兵。 [[4]](#sj043-northwest-note)

## 本年相关史料

<a id="note-1"></a>

### 1. 昭襄王初年由严君疾为相，甘茂离秦

[返回正文第1条](#event-1)

**[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)**

> 昭襄王元年，嚴君疾為相。甘茂出之魏。二年，彗星見。庶長壯與大臣、諸侯、公子為逆，皆誅，及惠文后皆不得良死。悼武王后出歸魏。三年，王冠。與楚王會黃棘，與楚上庸。四年，取蒲阪。彗星見。五年，魏王來朝應亭，復與魏蒲阪。六年，蜀侯煇反，司馬錯定蜀。庶長奐伐楚，斬首二萬。涇陽君質於齊。日食，晝晦。七年，拔新城。摢裏子卒。八年，使將軍羋戎攻楚，取新市。齊使章子，魏使公孫喜，韓使暴鳶共攻楚方城，取唐眛。趙破中山，其君亡，竟死齊。魏公子勁、韓公子長為諸侯。九年，孟嘗君薛文來相秦。奐攻楚，取八城，殺其將景快。十年，楚懷王入朝秦，秦留之。薛文以金受免。樓緩為丞相。十一年，齊、韓、魏、趙、宋、中山五國共攻秦，至鹽氏而還。秦與韓、魏河北及封陵以和。彗星見。楚懷王走之趙，趙不受，還之秦，即死，歸葬。十二年，樓緩免，穰侯魏冉為相。予楚粟五萬石。

### 3. 怀王后半期的外交讨论，在亲秦与联齐韩之间反复

[返回正文第3条](#sj040-chu-qihan-discussion-event)

<a id="sj040-cite-174"></a>

**[《史记·楚世家》P081](../../sources/摘录/史记-卷040-楚世家.md#p081)**

> 二十［六］年，齊湣王欲為從長，惡楚之與秦合，乃使使遺楚王書曰：「寡人患楚之不察於尊名也。今秦惠王死，武王立，張儀走魏，樗裏疾、公孫衍用，而楚事秦。夫樗裏疾善乎韓，而公孫衍善乎魏；楚必事秦，韓、魏恐，必因二人求合於秦，則燕、趙亦宜事秦。四國爭事秦，則楚為郡縣矣。王何不與寡人并力收韓、魏、燕、趙，與為從而尊周室，以案兵息民，令於天下？莫敢不樂聽，則王名成矣。王率諸侯并伐，破秦必矣。王取武關、蜀、漢之地，私吳、越之富而擅江海之利，韓、魏割上黨，西薄函谷，則楚之彊百萬也。且王欺於張儀，亡地漢中，兵銼藍田，天下莫不代王懷怒。今乃欲先事秦！願大王孰計之。」

**本卷说明：** 原二十［六］年与注本二十、索隐二十或二十一（309/308）不齐；相连昭雎辞已含307拔宜阳、306还武遂，故置306作为较晚背景后的未确年复合叙述，不宣称来书和对答全发生本年。齐湣称号另保留异链。

<!-- /sj040-cite-174 -->

<a id="sj040-cite-175"></a>

**[《史记·楚世家》P082](../../sources/摘录/史记-卷040-楚世家.md#p082)**

> 楚王業已欲和於秦，見齊王書，猶豫不決，下其議群臣。群臣或言和秦，或曰聽齊。昭雎曰：「王雖東取地於越，不足以刷恥；必且取地於秦，而後足以刷恥於諸侯。王不如深善齊、韓以重樗裏疾，如是則王得韓、齊之重以求地矣。秦破韓宜陽，而韓猶復事秦者，以先王墓在平陽，而秦之武遂去之七十里，以故尤畏秦。不然，秦攻三川，趙攻上黨，楚攻河外，韓必亡。楚之救韓，不能使韓不亡，然存韓者楚也。韓已得武遂於秦，以河山為塞，所報德莫如楚厚，臣以為其事王必疾。齊之所信於韓者，以韓公子眛為齊相也。韓已得武遂於秦，王甚善之，使之以齊、韓重樗裏疾，疾得齊、韓之重，其主弗敢棄疾也。今又益之以楚之重，樗里子必言秦，復與楚之侵地矣。」於是懷王許之，竟不合秦，而合齊以善韓。

**本卷说明：** 徐广明确指出宜阳怀22、归武遂23，非20；本段绝不能整个压到309。东取越地只作此前背景，不据此确定无疆死亡年。

## 归年与考证

<a id="sj005-211-note"></a>
<a id="sj005-211昭襄王初年由严君疾为相甘茂离秦"></a>
#### sj005-211｜昭襄王初年由严君疾为相，甘茂离秦。

[卷005 P065](../../sources/摘录/史记-卷005-秦本纪.md#p065)。

**说明：**“严君疾”与樗里疾通称之间依传世关系理解；本纪写甘茂魏行，其他传到齐等不能不加说明合成唯一旅程。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0306-qin-note"></a>
<a id="卷015秦栏前306年"></a>
#### 卷015·秦栏｜前306年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0306)：“秦昭襄王元年”

昭襄王元年与原页初政合并，实际继立在[前307年武王死后](bce-0307.md#event-2)。仅元年不重写第二次迎立。 [对应正文](#event-1)

<a id="sj015-0306-wei-note"></a>
<a id="卷015魏栏前306年"></a>
#### 卷015·魏栏｜前306年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0306)：“十三。秦擊皮氏，未拔而解。”

皮氏之围按本格补入；[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-9a310f6d123c8c)另记甘茂中止攻蒲阪、樗里子与魏和，地点与过程不强合成一城。核心结果是不克而退。

<a id="sj015-0306-han-note"></a>
<a id="卷015韩栏前306年"></a>
#### 卷015·韩栏｜前306年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0306)：“六。秦復與我武遂。”

归还武遂并入[本页秦魏韩交涉](#sj015-0306-wei-event)；前307城武遂与本次交还、前303再取分别保存。[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-56cfa7a9ae0859)把还地与甘茂之去相接，但不能据此裁定本年发生所有后续游说。

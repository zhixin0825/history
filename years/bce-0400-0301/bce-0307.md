1. **秦争夺宜阳，周国担心被楚当作秦的帮手。** 秦攻韩国宜阳，楚出兵救援。楚王又认为周在帮助秦，准备惩罚周。夹在大国之间的周国，即使没有能力主导战争，也可能因别人怎样判断其立场而受攻击。 [[1]](#note-1)

   苏代劝楚王，不要逼周入秦：不论周与秦亲疏，都先表示善待周，才有机会离间周秦关系，使周转向楚。他提出的是改变楚王态度的办法，原文没有接着记录楚军因此一定撤回。

   甘茂所率秦军终于攻下宜阳，本纪报斩首六万。秦军过河，修筑武遂，魏太子也来朝见，周国面临的压力因此更直接。

<a id="event-2"></a>

2. **武王因举鼎受伤去世，昭襄王从燕归秦继立。** 任鄙、乌获、孟说曾因力大受到重用；武王与孟说举鼎，伤及膑，八月死去，孟说一族受到处置。武王的魏后没有儿子，秦迎回在燕为质的异母弟。新君之母为楚人芈氏，后来称宣太后。 赵国曾派代相赵固到燕迎接公子稷，护送归秦。 [[2]](#note-2)

<a id="sj015-0307-zhao-event"></a>

<a id="event-3"></a>

3. **赵武灵王推行胡服骑射，先改变军备与服制，再说服宗亲和群臣。** 正月在信宫大会后，他与肥义讨论天下五日，北略中山至房子，再经代到无穷，西抵河、登黄华。他向楼缓说，先王依漳滏险阻扩南境、筑长城，取蔺和郭狼、败林人于荏，事业尚未完成；如今中山居腹心，北有燕、东有胡，西接林胡、楼烦、秦、韩，却缺强兵支援，须以适合骑射的胡服求变。楼缓赞成，群臣多反对。王又向肥义说明臣子既须有孝悌长幼之节，也须补君利民；自己要续简、襄事业，借胡翟地利，以较少劳力取得较多成果，却忧天下责骂。肥义答疑事无功、疑行无名，大德不必合俗，大功不必谋众，舜与有苗、禹入裸国都是因事权宜，不为纵欲；愚人连已成之事也未能明白，智者能察未形。王说并不疑胡服之效，只怕被笑，但狂人所乐可能是智者所哀，愚者所笑值得贤者细察，即使天下皆笑，也必取胡地、中山，遂先自己穿胡服。王遣王绁劝叔父公子成也穿胡服入朝，讲家听亲、国听君，政以利民为本、令行为上，推行政令须先取信贵者，此举为成事立功，不为私欲，望宗亲支持。公子成称病未朝，仍尽忠进言：华夏集才智、财物、圣贤仁义、诗书礼乐与技艺于一处，是远方效法归赴之地，改服会违古教、逆人心、使学者不安，望王重虑。王亲到其家，说明衣为便用、礼为便事，圣人因地因事制礼；瓯越剪发文身左衽，大吴黑齿文额，礼服虽异，求利相同，同一师承与礼制也会生不同习俗，不能只因不知或不同便疑而非之。叔父讲已有之俗，王讲如何制合宜之俗。赵东有河、薄洛却无舟楫，常山至代、上党接燕东胡、楼烦秦韩却无骑射；简子经营晋阳上党，襄子兼戎取代，中山曾倚齐掳赵民、引水围鄗，险使城陷，骑射近便上党、远报中山旧怨，不能因怕改服而忘旧耻。公子成再拜认错，受赐胡服，次日穿服入朝，朝廷遂发布新令。赵文、赵造、周袑、赵俊仍请守旧，王再答先王不同俗、帝王不相袭，伏羲神农重教，黄帝尧舜行诛而不私怒，三王随时制法；圣人可以不相袭而王，夏殷守礼仍亡，反古未必非、循礼不足自夸。奇服并非必有淫志，异俗并非没有贤士，邹鲁、吴越不能以衣俗论才。一般礼服可齐常民，不能限贤者；只按书驾车不能尽马性，按古法治今不能通变化，遂招募并教习骑射。 [[3]](#note-3)

<a id="sj044-crown-to-qin-event"></a>

4. **魏太子前往秦国朝见。** 本篇列旧“哀王十二年”，现接前307年的魏国纪事。朝秦与下一年秦攻皮氏不是同一行动，也不能据此推定太子姓名和在秦停留月数。 [[4]](#sj044-crown-to-qin-note)

> 王遂往之公子成家，因自請之，曰：「夫服者，所以便用也；禮者，所以便事也。聖人觀鄉而順宜，因事而制禮，所以利其民而厚其國也。夫翦發文身，錯臂左衽，甌越之民也。黑齒雕題，卻冠秫絀，大吳之國也。故禮服莫同，其便一也。鄉異而用變，事異而禮易。是以聖人果可以利其國，不一其用；果可以便其事，不同其禮。儒者一師而俗異，中國同禮而教離，況於山谷之便乎？故去就之變，智者不能一；遠近之服，賢聖不能同。窮鄉多異，曲學多辯。不知而不疑，異於己而不非者，公焉而眾求盡善也。今叔之所言者俗也，吾所言者所以制俗也。吾國東有河、薄洛之水，與齊、中山同之，無舟楫之用。自常山以至代、上黨，東有燕、東胡之境，而西有樓煩、秦、韓之邊，今無騎射之備。故寡人無舟楫之用，夾水居之民，將何以守河、薄洛之水；變服騎射，以備燕、三胡、秦、韓之邊。且昔者簡主不塞晉陽以及上黨，而襄主并戎取代以攘諸胡，此愚智所明也。先時中山負齊之彊兵，侵暴吾地，系累吾民，引水圍鄗，微社稷之神靈，則鄗幾於不守也。先王丑之，而怨未能報也。今騎射之備，近可以便上黨之形，而遠可以報中山之怨。而叔順中國之俗以逆簡、襄之意，惡變服之名以忘鄗事之丑，非寡人之所望也。」公字成再拜稽首曰：「臣愚，不達於王之義，敢道世俗之聞，臣之罪也。今王將繼簡、襄之意以順先王之志，臣敢不聽命乎！」再拜稽首。乃賜胡服。明日，服而朝。於是始出胡服令也。

#### 1. 秦争夺宜阳，周国担心被楚当作秦的帮手

[卷004 P071](../../sources/摘录/史记-卷004-周本纪.md#p071)。 本纪赧王八年；《秦本纪》将宜阳攻势分在武王三、四年，破城在前307。此处不把起兵、围城与破城都挤作一个日子。随后的借道、赴秦、两周互战及雍氏游说没有独立年号，另列未确年材料，不自动继承“八年”。

### 补充史料与异说

<a id="sj005-209-note"></a>
<a id="sj005-209同一事件的补充与取舍"></a>
#### sj005-209｜同一事件的补充与取舍

[卷005 P064](../../sources/摘录/史记-卷005-秦本纪.md#p064)。

**说明：**宜阳攻取结果来自秦本纪武王四年，原页周国担忧为同一战局另一侧；六万为本纪记数。

<a id="sj005-210-note"></a>
<a id="sj005-210武王因举鼎受伤去世昭襄王从燕归秦继立"></a>
#### sj005-210｜武王因举鼎受伤去世，昭襄王从燕归秦继立。

[卷005 P064](../../sources/摘录/史记-卷005-秦本纪.md#p064)。

**说明：**不得把举鼎传闻包装成医学确诊；“绝膑”原词保留。昭王回国与新年元年不混同，武王死年仍有继立而次年306为元年。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

#### 卷015·秦栏｜前307年

魏太子朝秦已见原页第一条后段，接通年表互见；本格无太子姓名，不与前313公子政自动并人。 [对应正文](#event-1)

#### 卷015·赵栏｜前307年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0307)：“十九。初胡服。”

“初胡服”与[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-ff6c5fd41c4228)、[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-578512ce2ee438)武灵王十九年胡服骑射相合。正文补足改革的军事目的与公子成反对后接受的过程，不写成从此全国服饰完全统一。

# 公元前307年｜秦破宜阳、武王去世；赵推行胡服骑射

**周赧王八年**

> 本页按古史年条与传统公元对照归档；明确有争议的日期见对应说明。月份、干支未直接换算为公历日期；不以已有一条材料表示本年所有历史都已收齐。

## 本年纪事

<a id="event-1"></a>

1. **秦争夺宜阳，周国担心被楚当作秦的帮手。** 秦攻韩国宜阳，楚出兵救援。楚王又认为周在帮助秦，准备惩罚周。夹在大国之间的周国，即使没有能力主导战争，也可能因别人怎样判断其立场而受攻击。

苏代劝楚王，不要逼周入秦：不论周与秦亲疏，都先表示善待周，才有机会离间周秦关系，使周转向楚。他提出的是改变楚王态度的办法，原文没有接着记录楚军因此一定撤回。 [原文与说明](#note-1)

甘茂所率秦军终于攻下宜阳，本纪报斩首六万。秦军过河，修筑武遂，魏太子也来朝见，周国面临的压力因此更直接。

[补充史料与年次说明](#sj005-209-note)


<a id="event-2"></a>

2. **武王因举鼎受伤去世，昭襄王从燕归秦继立。** 任鄙、乌获、孟说曾因力大受到重用；武王与孟说举鼎，伤及膑，八月死去，孟说一族受到处置。武王的魏后没有儿子，秦迎回在燕为质的异母弟。新君之母为楚人芈氏，后来称宣太后。 [原文与说明](#sj005-210-note)

<a id="sj015-0307-zhao-event"></a>

**赵武灵王推行胡服骑射。**他认为赵国与中山、北方诸部相邻，需要适合骑马和射箭的衣着、训练，便先与肥义商议，再劝服反对改革的公子成。公子成穿着胡服入朝后，新的命令才更容易推行。 [原文与说明](#sj015-0307-zhao-note)

## 本年相关史料

<a id="note-1"></a>
<a id="sj004-307-1"></a>
### 1. 秦争夺宜阳，周国担心被楚当作秦的帮手

[卷004 P071](../../sources/摘录/史记-卷004-周本纪.md#p071)。 本纪赧王八年；《秦本纪》将宜阳攻势分在武王三、四年，破城在前307。此处不把起兵、围城与破城都挤作一个日子。随后的借道、赴秦、两周互战及雍氏游说没有独立年号，另列未确年材料，不自动继承“八年”。

## 补充史料与异说

<a id="sj005-209-note"></a>
### sj005-209｜同一事件的补充与取舍

[卷005 P064](../../sources/摘录/史记-卷005-秦本纪.md#p064)。

**说明：**宜阳攻取结果来自秦本纪武王四年，原页周国担忧为同一战局另一侧；六万为本纪记数。

<a id="sj005-210-note"></a>
### sj005-210｜武王因举鼎受伤去世，昭襄王从燕归秦继立。

[卷005 P064](../../sources/摘录/史记-卷005-秦本纪.md#p064)。

**说明：**不得把举鼎传闻包装成医学确诊；“绝膑”原词保留。昭王回国与新年元年不混同，武王死年仍有继立而次年306为元年。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0307-qin-note"></a>
### 卷015·秦栏｜前307年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0307)：“四。拔宜陽城，斬首六萬。涉河，城武遂。”

拔宜阳、六万、渡河和城武遂全归既有第一条；与韩栏同一战争，不重复计战果。 [对应正文](#event-1)

<a id="sj015-0307-wei-note"></a>
### 卷015·魏栏｜前307年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0307)：“十二。太子往朝秦。”

魏太子朝秦已见原页第一条后段，接通年表互见；本格无太子姓名，不与前313公子政自动并人。 [对应正文](#event-1)

<a id="sj015-0307-han-note"></a>
### 卷015·韩栏｜前307年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0307)：“五。秦拔我宜陽，斬首六萬。”

与[原页宜阳之战](#event-1)合并。六万为同一古书记数在两栏重复，不能计为十二万。

<a id="sj015-0307-zhao-note"></a>
### 卷015·赵栏｜前307年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0307)：“十九。初胡服。”

“初胡服”与[《赵世家》](https://zh.wikisource.org/wiki/史記/卷043)、[《通鉴》卷三及校刊记](https://zh.wikisource.org/wiki/資治通鑑/卷003)武灵王十九年胡服骑射相合。正文补足改革的军事目的与公子成反对后接受的过程，不写成从此全国服饰完全统一。

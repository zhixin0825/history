## 归年与考证

<a id="sj005-208-note"></a>
<a id="1会韩王与攻宜阳"></a>
#### 1｜会韩王与攻宜阳

[卷005 P064](../../拆分史书/史记/卷005.md#p064)。“相韩”可涉辅相、外交等理解，不扩写成樗里疾正式辞秦、终身转任韩相；南公揭仅留姓名与死亡。归年沿[卷005取舍](../../拆分史书/史记/卷005.md#kao-c691f26620)，古月未直接换成公历月份。

<a id="sj006-075-note"></a>
<a id="2渭水赤三日"></a>
#### 2｜渭水赤三日

[卷006 P075](../../拆分史书/史记/卷006.md#p075)：“立三年，渭水赤三日。”武王元年前310年，三年为前308。原文没有把赤水的三日系到攻宜阳的具体行军日；两件事同年不意味着存在因果关系。所附十九岁即位留在世系说明，不推算出生月日。

<a id="sj015-0308-wei-note"></a>
<a id="卷015魏栏前308年"></a>
#### 卷015·魏栏｜前308年

[本年原格](../../拆分史书/史记/卷015.md#y0308)：“十一。與秦會應。”

秦魏会应为原页未列的会面；与韩王会临晋、甘茂出兵宜阳不同。应不与临晋混成一处。

<a id="sj015-0308-han-note"></a>
<a id="卷015韩栏前308年"></a>
#### 卷015·韩栏｜前308年

[本年原格](../../拆分史书/史记/卷015.md#y0308)：“四。與秦會臨晉。秦擊我宜陽。”

与原页会韩王及攻宜阳合并，本格补明会面地临晋；宜阳围攻前308开始、前307破城，不能全压成一年。[《通鉴》卷三及校刊记](../../拆分史书/资治通鉴/卷003.md#text)详记甘茂出兵前的魏秦交涉。 [对应正文](#event-1)

1. **秦正式设置丞相，樗里疾、甘茂分任。** 本纪以左右丞相说明两人的位置。同年张仪死于魏，他几次在秦魏间进退的经历到此结束。 [[1]](#note-1)

<a id="sj043-yetai-event"></a>

2. **武灵王出九门，建野台观察边境。** 王从台上眺望齐国、中山方向，巡察赵国东部形势。 [[2]](#sj043-yetai-note)

<a id="sj044-zhangyi-death-event"></a>

3. **张仪去世。** 他先在秦主持对外谋略，后来转入魏廷；本篇以旧“哀王十年”记其死亡，现接襄王时期的前309年。 [[3]](#sj044-zhangyi-death-note)

### 1. 秦正式设置丞相，樗里疾、甘茂分任

[返回正文第1条](#event-1)

<a id="sj071-cite-006"></a>

**[《史记·樗里子甘茂列传》P007](../../sources/摘录/史记-卷071-樗里子甘茂列传.md#p007)**

> 而以甘茂爲左丞相，以樗里子爲右丞相。

**本卷归年说明：** 这是武王时置左右丞相的同一人事事件，传文连写蜀叛乱与任官，不能倒换年份。

<!-- /sj071-cite-006 -->

**[卷005 P064](../../sources/摘录/史记-卷005-秦本纪.md#p064)**

> 武王元年，與魏惠王會臨晉。誅蜀相壯。張儀、魏章皆東出之魏。伐義渠、丹、犁。二年，初置丞相，摢裏疾、甘茂為左右丞相。張儀死於魏。三年，與韓襄王會臨晉外。南公揭卒，摢裏疾相韓。武王謂甘茂曰：「寡人欲容車通三川，窺周室，死不恨矣。」其秋，使甘茂、庶長封伐宜陽。四年，拔宜陽，斬首六萬。涉河，城武遂。魏太子來朝。武王有力好戲，力士任鄙、烏獲、孟說皆至大官。王與孟說舉鼎，絕臏。八月，武王死。族孟說。武王取魏女為后，無子。立異母弟，是為昭襄王。昭襄母楚人，姓羋氏，號宣太后。武王死時，昭襄王為質於燕，燕人送歸，得立。

## 归年与考证

<a id="sj005-207-note"></a>
<a id="sj005-207秦正式设置丞相樗里疾甘茂分任"></a>
#### sj005-207｜秦正式设置丞相，樗里疾、甘茂分任。

[卷005 P064](../../sources/摘录/史记-卷005-秦本纪.md#p064)。

**说明：**不把“初置丞相”解释为秦国从前完全没有辅政官员；它指本纪所写官名制度节点。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0309-qin-note"></a>
<a id="卷015秦栏前309年"></a>
#### 卷015·秦栏｜前309年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0309)：“二。初置丞相，樗里子、甘茂為丞相。”

樗里疾、甘茂任丞相并入既有第一条。初置丞相并非秦从此才有任何辅政大臣。 [对应正文](#event-1)

<a id="sj015-0309-wei-note"></a>
<a id="卷015魏栏前309年"></a>
#### 卷015·魏栏｜前309年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0309)：“十。張儀死。”

张仪死于本年与秦本纪旧条合并。[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-8744409511bb57)把“相魏一岁卒”连在前310年段末，校刊记又引《纪年》九年五月，存在前310／309差别。本项目暂取年表前309，其他年仅回指，不造两次死亡。 [对应正文](#event-1)

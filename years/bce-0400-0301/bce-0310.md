1. **武王与魏王会临晋，秦诛蜀相壮。** 张仪、魏章离秦赴魏；秦又对义渠、丹、犁用兵。新君上台后，外交人员与西方政策都在调整。 [[1]](#note-1)

<a id="sj015-0310-zhao-event"></a>

<a id="event-2"></a>

2. **赵武灵王迎娶吴广之女孟姚，十分宠爱她。** 她后来生下公子何，并被立为惠后；何就是后来承继王位的赵惠文王。 [[2]](#note-2)

## 本年相关史料

<a id="note-1"></a>

### 1. 武王与魏王会临晋，秦诛蜀相壮

[返回正文第1条](#event-1)

**[卷005 P064](../../sources/摘录/史记-卷005-秦本纪.md#p064)**

> 武王元年，與魏惠王會臨晉。誅蜀相壯。張儀、魏章皆東出之魏。伐義渠、丹、犁。二年，初置丞相，摢裏疾、甘茂為左右丞相。張儀死於魏。三年，與韓襄王會臨晉外。南公揭卒，摢裏疾相韓。武王謂甘茂曰：「寡人欲容車通三川，窺周室，死不恨矣。」其秋，使甘茂、庶長封伐宜陽。四年，拔宜陽，斬首六萬。涉河，城武遂。魏太子來朝。武王有力好戲，力士任鄙、烏獲、孟說皆至大官。王與孟說舉鼎，絕臏。八月，武王死。族孟說。武王取魏女為后，無子。立異母弟，是為昭襄王。昭襄母楚人，姓羋氏，號宣太后。武王死時，昭襄王為質於燕，燕人送歸，得立。

## 归年与考证

<a id="sj005-206-note"></a>
<a id="sj005-206武王与魏王会临晋秦诛蜀相壮"></a>
#### sj005-206｜武王与魏王会临晋，秦诛蜀相壮。

[卷005 P064](../../sources/摘录/史记-卷005-秦本纪.md#p064)。

**说明：**本纪称魏惠王，按魏王世系此时不能仍是早年惠王，正文用魏王；原字保留待同书王年互校。甘茂等任相不提前到元年。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0310-qin-note"></a>
<a id="卷015秦栏前310年"></a>
#### 卷015·秦栏｜前310年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0310)：“秦武王元年。誅蜀相壯。張儀、魏章皆出之魏。”

武王元年、诛蜀相壮及张仪魏章出魏均合入既有条。“出之魏”在[卷015三家注本](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7015.md#ref-f3e28219acfac4)有“死于魏”校字，不能据后者写两人本年都死。 [对应正文](#event-1)

<a id="sj015-0310-wei-note"></a>
<a id="卷015魏栏前310年"></a>
#### 卷015·魏栏｜前310年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0310)：“九。與秦會臨晉。”

临晋会面与秦方第一条合并；魏君采用魏襄王，与旧《秦本纪》“魏惠王”误称分层。 [对应正文](#event-1)

<a id="sj015-0310-zhao-note"></a>
<a id="卷015赵栏前310年"></a>
#### 卷015·赵栏｜前310年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0310)：“十六。吳廣入女，生子何，立為惠王后。”

吴广之女名孟姚，惠后、子何见[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-a2f5b5eb6669a9)与[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-0205f771603850)。一格压缩迎娶、诞子、立后三项，正文只把迎娶系本年，儿子后来出生、继位作后事说明，不凭短句确定生日。

1. **秦取楚召陵，蜀内部发生变乱，惠文王去世。** 丹、犁向秦称臣；蜀相壮杀蜀侯后归降。秦的西南征服并未结束当地权力冲突。惠文王死后，武王接位，韩、魏、齐、楚、越等仍与秦保持往来。 [[1]](#note-1)

<a id="sj015-0311-wei-event"></a>

<a id="event-2"></a>

2. **魏军围攻卫国。** 卫仍保有自己的君主与政治存在，但不断承受邻近大国的军事压力。 [[2]](#note-2)

<a id="sj015-0311-han-event"></a>

<a id="event-3"></a>

3. **韩国进入襄王元年，前一任宣惠王的统治结束，新的王年开始。** [[3]](#note-3)

<a id="sj040-zhangyi-chu-release-event"></a>

4. **怀王索张仪以报商於之欺，张仪入楚后借靳尚、郑袖脱身。** 秦愿割汉中一半和楚，怀王不要地而要张仪。张仪自恃与靳尚相善、靳尚能影响郑袖，主动赴楚，却被囚待杀。靳尚先以秦怒、诸侯轻楚劝王，又用秦将献美人土地、郑袖会失宠的说辞劝郑袖救仪。王终于释放并礼待张仪，接受其与秦婚亲的建议。张仪去后屈原从齐归，劝应诛仪，王追之不及。 [[4]](#sj040-zhangyi-chu-release-note)

### 1. 秦取楚召陵，蜀内部发生变乱，惠文王去世

[返回正文第1条](#event-1)

<a id="sj033-cite-141"></a>

**[《史记·鲁周公世家》P092](../../sources/摘录/史记-卷033-鲁周公世家.md#p092)**

> 平公十二年，秦惠王卒。

秦惠文王死亡提供鲁平公王年的跨国锚点；与前代在位数连推不能完全兼容。 [全卷考证](../../meta/考证/史记-卷033-纪年与异说.md)。

**[卷005 P062](../../sources/摘录/史记-卷005-秦本纪.md#p062)**

> 十四年，更為元年。二年，張儀與齊、楚大臣會齧桑。三年，韓、魏太子來朝。張儀相魏。五年，王游至北河。七年，樂池相秦。韓、趙、魏、燕、齊帥匈奴共攻秦。秦使庶長疾與戰修魚，虜其將申差，敗趙公子渴、韓太子奐，斬首八萬二千。八年，張儀復相秦。九年，司馬錯伐蜀，滅之。伐取趙中都、西陽十年，韓太子蒼來質。伐取韓石章。伐敗趙將泥。伐取義渠二十五城。十一年，摢裏疾攻魏焦，降之。敗韓岸門，斬首萬，其將犀首走。公子通封於蜀。燕君讓其臣子之。十二年，王與梁王會臨晉。庶長疾攻趙，虜趙將莊。張儀相楚。十三年，庶長章擊楚於丹陽，虜其將屈丐，斬首八萬；又攻楚漢中，取地六百里，置漢中郡。楚圍雍氏，秦使庶長疾助韓而東攻齊，到滿助魏攻燕。十四年，伐楚，取召陵。丹、犁臣，蜀相壯殺蜀侯來降。

**[卷005 P063](../../sources/摘录/史记-卷005-秦本纪.md#p063)**

> 惠王卒，子武王立。韓、魏、齊、楚、越皆賓從。

### 4. 怀王索张仪以报商於之欺，张仪入楚后借靳尚、郑袖脱身

[返回正文第4条](#sj040-zhangyi-chu-release-event)

<a id="sj040-cite-171"></a>

**[《史记·楚世家》P079](../../sources/摘录/史记-卷040-楚世家.md#p079)**

> 十八年，秦使使約復與楚親，分漢中之半以和楚。楚王曰：「願得張儀，不願得地。」張儀聞之，請之楚。秦王曰：「楚且甘心於子，柰何？」張儀曰：「臣善其左右靳尚，靳尚又能得事於楚王幸姬鄭袖，袖所言無不從者。且儀以前使負楚以商於之約，今秦楚大戰，有惡，臣非面自謝楚不解。且大王在，楚不宜敢取儀。誠殺儀以便國，臣之願也。」儀遂使楚。

**本卷说明：** 上庸六县、美人及媵歌者为靳尚游说郑袖的设想，本段没有证明全部已交割。

<!-- /sj040-cite-171 -->

<a id="sj040-cite-172"></a>

**[《史记·楚世家》P080](../../sources/摘录/史记-卷040-楚世家.md#p080)**

> 至，懷王不見，因而囚張儀，欲殺之。儀私於靳尚，靳尚為請懷王曰：「拘張儀，秦王必怒。天下見楚無秦，必輕王矣。」又謂夫人鄭袖曰：「秦王甚愛張儀，而王欲殺之，今將以上庸之地六縣賂楚，以美人聘楚王，以宮中善歌者為之媵。楚王重地，秦女必貴，而夫人必斥矣。夫人不若言而出之。」鄭袖卒言張儀於王而出之。儀出，懷王因善遇儀，儀因說楚王以叛從約而與秦合親，約婚姻。張儀已去，屈原使從齊來，諫王曰：「何不誅張儀？」懷王悔，使人追儀，弗及。

## 归年与考证

<a id="sj005-205-note"></a>
<a id="sj005-205秦取楚召陵蜀内部发生变乱惠文王去世"></a>
#### sj005-205｜秦取楚召陵，蜀内部发生变乱，惠文王去世。

[卷005 P062](../../sources/摘录/史记-卷005-秦本纪.md#p062) · [卷005 P063](../../sources/摘录/史记-卷005-秦本纪.md#p063)。

**说明：**蜀相壮杀侯与次年被秦诛分开；“皆宾从”是本纪概括，不能据此说列国都已降为秦郡。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0311-qin-note"></a>
<a id="卷015秦栏前311年"></a>
#### 卷015·秦栏｜前311年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0311)：“十四。蜀相殺蜀侯。”

蜀相杀蜀侯并入旧条，次年秦诛蜀相另见前310；不把被杀蜀侯与后来蜀侯煇无据并为一人。 [对应正文](#event-1)

<a id="sj015-0311-wei-note"></a>
<a id="卷015魏栏前311年"></a>
#### 卷015·魏栏｜前311年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0311)：“八。圍衛。”

魏围卫按格补入，不因卫国弱小便宣称此时已亡；“围”未记攻陷或城名，正文不加战果。

<a id="sj015-0311-han-note"></a>
<a id="卷015韩栏前311年"></a>
#### 卷015·韩栏｜前311年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0311)：“韓襄王元年”

韩襄王元年，前一年宣惠王治世结束与本年起算须区分。仅元年不再扩写一场没有材料的登基仪式。

<a id="卷015燕栏前311年"></a>
#### 卷015·燕栏｜前311年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0311)：“燕昭王元年”

昭王元年承接[前312迎立公子职](bce-0312.md#sj015-0312-yan-event)的暂定年链。表继续沿用哙的九年到前312，不能理解为已死的哙仍实际执政。

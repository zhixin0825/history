1. **秦楚战于丹阳、蓝田，韩魏趁楚败进军。** 秦将魏章在丹阳击败楚军，俘屈丐、逢侯丑等七十余将，斩甲士八万。秦继取汉中六百里，设汉中郡。楚军回攻秦，蓝田再败；韩、魏南下进至邓地，楚军闻后方告急才撤回。楚围雍氏时，樗里疾出兵援韩，随后东向攻齐；秦韩也曾合围楚将景座。魏受齐宋进攻时向韩冯、张仪求援，苏代向陈轸分析，秦、韩可能借救魏之名联合三国攻楚。他建议让楚割地给韩、请秦主持和解，使韩不战得地、秦可在三川显示权势，从而减轻楚国的军事压力。 [[1]](#note-1)

3. **燕昭王即位，礼待郭隗并延揽贤士。** 燕国内乱和齐军入侵后，燕昭王即位，欲厚礼招贤以重建燕国。郭隗劝昭王先厚待自己，让其他贤士看到燕王的诚意。昭王为他改建居所，以师礼相待；此后乐毅从魏、邹衍从齐、剧辛从赵先后来燕。昭王也抚恤死者家属和孤弱，与百姓同甘苦。 [[3]](#note-5)

**[《史记·田敬仲完世家》P043](../../拆分史书/史记/卷046.md#p043)**

> 蘇代謂田軫曰：「臣願有謁於公，其為事甚完，使楚利公，成為福，不成亦為福。今者臣立於門，客有言曰魏王謂韓馮、張儀曰：『煮棗將拔，齊兵又進，子來救寡人則可矣；不救寡人，寡人弗能拔。』此特轉辭也。秦、韓之兵毋東，旬餘，則魏氏轉韓從秦，秦逐張儀，交臂而事齊楚，此公之事成也。」田軫曰：「柰何使無東？」對曰：「韓馮之救魏之辭，必不謂韓王曰『馮以為魏』，必曰『馮將以秦韓之兵東卻齊宋，馮因摶三國之兵，乘屈丐之獘，南割於楚，故地必盡得之矣』。張儀救魏之辭，必不謂秦王曰『儀以為魏』，必曰『儀且以秦韓之兵東距齊宋，儀將摶三國之兵，乘屈丐之獘，南割於楚，名存亡國，實伐三川而歸，此王業也』。公令楚王與韓氏地，使秦制和，謂秦王曰『請與韓地，而王以施三川，韓氏之兵不用而得地於楚』。韓馮之東兵之辭且謂秦何？曰『秦兵不用而得三川，伐楚韓以窘魏，魏氏不敢東，是孤齊也』。張儀之東兵之辭且謂何？曰『秦韓欲地而兵有案，聲威發於魏，魏氏之欲不失齊楚者有資矣』。魏氏轉秦韓爭事齊楚，楚王欲而無與地，公令秦韓之兵不用而得地，有一大德也。秦韓之王劫於韓馮、張儀而東兵以徇服魏，公常執左券以責於秦韓，此其善於公而惡張子多資矣。」

**本卷说明：** “田轸”古注释陈轸；“秦逐张仪”索隐释逐为随，不是驱逐。“施三川”正义解释在天子之都张示迫胁，非这时已吞三川。本段与战局相接，并不独立证明游说日月。

#### 卷015·秦栏｜前312年

[本年原格](../../拆分史书/史记/卷015.md#y0312)：“十三。庶長章擊楚，斬首八萬。”

庶长章攻楚、八万战果与原有丹阳战条合并；“章”与《秦本纪》魏章互见，八万不与楚栏再相加。 [对应正文](#event-1)

<a id="sj015-0312-wei-note"></a>
<a id="卷015魏栏前312年"></a>
#### 卷015·魏栏｜前312年

[本年原格](../../拆分史书/史记/卷015.md#y0312)：“七。擊齊，虜聲子於濮。與秦擊燕。”

“与秦击燕”接原页援魏攻燕条，另补击齐、俘声子于濮。声子身份无更多可靠线索，不补其爵位或死亡。

<a id="sj015-0312-han-note"></a>
<a id="卷015韩栏前312年"></a>
#### 卷015·韩栏｜前312年

[本年原格](../../拆分史书/史记/卷015.md#y0312)：“二十一。我秦攻楚，圍景座。”

“我秦”按韩方与秦共同攻楚理解，景座为被围的楚方人物；本格没有记景座被俘或被杀，也不能把他与屈匄、唐昧并为一人。

<a id="sj015-0312-chu-note"></a>
<a id="卷015楚栏前312年"></a>
#### 卷015·楚栏｜前312年

[本年原格](../../拆分史书/史记/卷015.md#y0312)：“十七。秦敗我將屈饨。”

本网页“屈饨”与[卷015三家注本](../../拆分史书/史记/卷015.md#part-2-text)“屈匄”、《通鉴》屈丐等为字形差别。正文沿楚将屈丐（屈匄），不把屈饨另立为第二人；归[既有丹阳战条](#event-1)。

<a id="sj015-0312-yan-note"></a>
<a id="卷015燕栏前312年"></a>
#### 卷015·燕栏｜前312年

[本年原格](../../拆分史书/史记/卷015.md#y0312)：“九。燕人共立公子平。”

“共立公子平”与前314太子平死亡冲突。[《燕召公世家》及索隐](../../拆分史书/史记/卷034.md#part-2-text)的《索隐》引《纪年》、[《赵世家》](../../拆分史书/史记/卷043.md#part-1-text)的迎公子职及[《通鉴》卷三及校刊记](../../拆分史书/资治通鉴/卷003.md#text)校刊记均提示平／职混淆。正文采用燕昭王公子职，暂依本表及既有昭王元年前311的衔接，把迎立放本年；《纪年》另有前314迎立线索仍留待考，不把太子平死而复生。须区分引文与注家结论：《索隐》本人反而主张昭王名平，认为年表与《纪年》有误；本页取公子职，依的是《赵世家》及所读《通鉴》校刊记列钱穆、杨宽的处理，不冒称《索隐》也赞成职。

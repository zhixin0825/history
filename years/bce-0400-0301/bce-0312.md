<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦在丹阳大败楚军，俘屈丐等将，继而取汉中六百里置郡。** 秦将章统兵，楚有八万甲士被斩，屈丐、逢侯丑等七十余将被俘。秦随后取得汉中之地，设置汉中郡；战胜、占地与置郡是相接的步骤。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚围雍氏，秦出兵助韩，并参与东方各国战事。** 樗里疾助韩后向东攻齐，本纪又说“到满助魏攻燕”。秦一面与楚交战，一面以援助他国影响东方局势。 [[2]](#note-2)

<a id="sj015-0312-wei-event"></a>

<a id="event-3"></a>

3. **魏军进攻齐国，在濮俘获声子。** [[3]](#note-3)

<a id="sj015-0312-han-event"></a>

<a id="event-4"></a>

4. **韩国也加入秦方对楚战争，与秦军围攻楚方的景座。** 这次秦韩联合对楚用兵，同丹阳击败屈丐、所报斩首八万的战事相接。 [[4]](#note-4)

<a id="sj015-0312-yan-event"></a>

<a id="event-5"></a>

5. **燕国在战乱后重新拥立国君，公子职继位，即后来的燕昭王。** 新君面对的，是内乱和齐军入侵后需要重建的国家。 赵篇的说法是武灵王从韩国召来公子职，派乐池护送立为燕王；它与燕篇太子平一支及公子职身份、复国年份的说法并存，不能无声合成同一条无争议经历。 [[5]](#note-5)

<a id="sj034-zhaowang-recruit-event"></a>

6. **昭王礼待郭隗，逐步招揽贤士重建燕国。** 面对内乱与齐军入侵后的国家，昭王愿意厚待能够帮助恢复国力的人。郭隗建议先从自己做起，让其他贤士看到燕王的诚意；昭王为他改建居所，以师礼相待。乐毅从魏、邹衍从齐、剧辛从赵先后而来，燕王又慰问死者家属、照顾孤弱，与百姓同甘苦。这些是即位后延续一段时间的政策与招士，不是同年同日完成的行动。 [[6]](#sj034-zhaowang-recruit-note)

<a id="sj040-lantian-battle-event"></a>

7. **怀王再举全国之兵攻秦，蓝田又败，韩魏趁困进至邓。** 丹阳败后楚试图反击，第二次主战仍失利。韩、魏随即南袭楚境，逼近邓地，楚军闻后方告急才退回。 [[7]](#sj040-lantian-battle-note)

<a id="sj043-zhaohe-wei-event"></a>

8. **赵何率兵攻魏。** 武灵王十四年另有赵何攻魏的记录，未载战果。 [[8]](#sj043-zhaohe-wei-note)

<a id="sj045-xuanhui-death-event"></a>

9. **韩宣惠王去世，太子仓接位，是为襄王。** 这一年韩国刚同秦合作攻楚，王位也由父亲转到儿子；下一年前311才开始襄王元年的纪年。 [[9]](#sj045-xuanhui-death-note)

<a id="sj046-sudai-chenzhen-event"></a>

10. **这轮战争的游说附读｜苏代劝田轸用让地方案阻住秦韩东援魏。** 魏受齐宋进攻，向韩冯、张仪求救。苏代认为，拖住秦韩十余日，便可迫魏重新考虑依附齐楚。他向田轸解释两位说客的打算：先以救魏阻齐宋为名，合秦韩魏之兵，再乘屈丐败后攻楚夺地；张仪还把图三川说成秦王的事业。田轸可劝楚让地给韩，由秦主持和解，使韩不战得地、秦也能在三川显示权势，东征的理由就弱了。魏失去援兵，更须争取齐楚。苏代又留后手：即使秦韩仍听张仪、韩冯而出兵，这项不战可得地的方案仍可用来责问两王，使其感念田轸、反怨说客贪多。田轸在古注中释为陈轸；全段没有写各项建议已成交，不能把计划变成一串既成割地与联盟。 [[10]](#sj046-sudai-chenzhen-note)

> 燕昭王於破燕之後即位，卑身厚幣以招賢者。謂郭隗曰：「齊因孤之國亂而襲破燕，孤極知燕小力少，不足以報。然誠得賢士以共國，以雪先王之恥，孤之願也。先生視可者，得身事之。」郭隗曰：「王必欲致士，先從隗始。況賢於隗者，豈遠千里哉！」於是昭王為隗改筑宮而師事之。樂毅自魏往，鄒衍自齊往，劇辛自趙往，士爭趨燕。燕王噲死問孤，與百姓同甘苦。

> 蘇代謂田軫曰：「臣願有謁於公，其為事甚完，使楚利公，成為福，不成亦為福。今者臣立於門，客有言曰魏王謂韓馮、張儀曰：『煮棗將拔，齊兵又進，子來救寡人則可矣；不救寡人，寡人弗能拔。』此特轉辭也。秦、韓之兵毋東，旬餘，則魏氏轉韓從秦，秦逐張儀，交臂而事齊楚，此公之事成也。」田軫曰：「柰何使無東？」對曰：「韓馮之救魏之辭，必不謂韓王曰『馮以為魏』，必曰『馮將以秦韓之兵東卻齊宋，馮因摶三國之兵，乘屈丐之獘，南割於楚，故地必盡得之矣』。張儀救魏之辭，必不謂秦王曰『儀以為魏』，必曰『儀且以秦韓之兵東距齊宋，儀將摶三國之兵，乘屈丐之獘，南割於楚，名存亡國，實伐三川而歸，此王業也』。公令楚王與韓氏地，使秦制和，謂秦王曰『請與韓地，而王以施三川，韓氏之兵不用而得地於楚』。韓馮之東兵之辭且謂秦何？曰『秦兵不用而得三川，伐楚韓以窘魏，魏氏不敢東，是孤齊也』。張儀之東兵之辭且謂何？曰『秦韓欲地而兵有案，聲威發於魏，魏氏之欲不失齊楚者有資矣』。魏氏轉秦韓爭事齊楚，楚王欲而無與地，公令秦韓之兵不用而得地，有一大德也。秦韓之王劫於韓馮、張儀而東兵以徇服魏，公常執左券以責於秦韓，此其善於公而惡張子多資矣。」

**本卷说明：** “田轸”古注释陈轸；“秦逐张仪”索隐释逐为随，不是驱逐。“施三川”正义解释在天子之都张示迫胁，非这时已吞三川。本段与战局相接，并不独立证明游说日月。

<a id="卷015楚栏前312年"></a>
#### 卷015·楚栏｜前312年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0312)：“十七。秦敗我將屈饨。”

本网页“屈饨”与[卷015三家注本](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7015.md#ref-2fdb214bdb0b2e)“屈匄”、《通鉴》屈丐等为字形差别。正文沿楚将屈丐（屈匄），不把屈饨另立为第二人；归[既有丹阳战条](#event-1)。

<a id="sj015-0312-yan-note"></a>
<a id="卷015燕栏前312年"></a>
#### 卷015·燕栏｜前312年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0312)：“九。燕人共立公子平。”

“共立公子平”与前314太子平死亡冲突。[《燕召公世家》及索隐](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7034.md#ref-029da3771f83f9)的《索隐》引《纪年》、[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-4237c5277bd4e7)的迎公子职及[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-203b0331d4f29f)校刊记均提示平／职混淆。正文采用燕昭王公子职，暂依本表及既有昭王元年前311的衔接，把迎立放本年；《纪年》另有前314迎立线索仍留待考，不把太子平死而复生。须区分引文与注家结论：《索隐》本人反而主张昭王名平，认为年表与《纪年》有误；本页取公子职，依的是《赵世家》及所读《通鉴》校刊记列钱穆、杨宽的处理，不冒称《索隐》也赞成职。

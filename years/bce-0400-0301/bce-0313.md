1. **秦王与魏王会临晋，樗里疾俘赵将，公子通受封于蜀。** 秦同时在对楚外交上有所动作，张仪的具体游说见下条。受封蜀地的秦公子说明秦开始用宗室经营新占地。 赵篇记秦夺蔺，俘将军赵庄。 [[1]](#note-1)

<a id="event-2"></a>

2. **秦国介入魏国储位安排，促成公子政被立为太子。** [[2]](#note-2)

<a id="sj015-0313-chu-event"></a>

<a id="event-3"></a>

3. **张仪许商於六百里诱楚绝齐，兑现时却只认六里，楚秦由此交兵。** 秦欲伐齐，假称免张仪相而派其入楚；张仪宣称楚绝齐即可兼得土地、秦援和弱齐三利。怀王授相印、置酒庆贺，遣将受地。陈轸独吊，指出先绝齐必使楚孤立、受秦轻视，再怨秦会招两国兵，王不听。张仪返秦后装醉坠车，称病三月不出；怀王误以绝交尚不彻底，遣宋遗辱齐，齐遂毁楚符而合秦。张仪此时才告楚使只有六里，怀王怒欲攻秦；陈轸再劝割一名都给秦、联秦伐齐以补损，仍未被听。楚遂绝和西攻，秦亦出兵，下一年在丹阳决战。 [[3]](#note-3)

<a id="sj043-kings-handan-event"></a>

4. **楚王、魏王的行程经过邯郸。** 楚王、魏王途经赵国邯郸。 [[4]](#sj043-kings-handan-note)

> 十四年，更為元年。二年，張儀與齊、楚大臣會齧桑。三年，韓、魏太子來朝。張儀相魏。五年，王游至北河。七年，樂池相秦。韓、趙、魏、燕、齊帥匈奴共攻秦。秦使庶長疾與戰修魚，虜其將申差，敗趙公子渴、韓太子奐，斬首八萬二千。八年，張儀復相秦。九年，司馬錯伐蜀，滅之。伐取趙中都、西陽十年，韓太子蒼來質。伐取韓石章。伐敗趙將泥。伐取義渠二十五城。十一年，摢裏疾攻魏焦，降之。敗韓岸門，斬首萬，其將犀首走。公子通封於蜀。燕君讓其臣子之。十二年，王與梁王會臨晉。庶長疾攻趙，虜趙將莊。張儀相楚。十三年，庶長章擊楚於丹陽，虜其將屈丐，斬首八萬；又攻楚漢中，取地六百里，置漢中郡。楚圍雍氏，秦使庶長疾助韓而東攻齊，到滿助魏攻燕。十四年，伐楚，取召陵。丹、犁臣，蜀相壯殺蜀侯來降。

[史料说明](#sj015-0313-chu-note)

<a id="sj040-cite-166"></a>

**[《史记·楚世家》P076](../../sources/摘录/史记-卷040-楚世家.md#p076)**

> 十六年，秦欲伐齊，而楚與齊從親，秦惠王患之，乃宣言張儀免相，使張儀南見楚王，謂楚王曰：「敝邑之王所甚說者無先大王，雖儀之所甚願為門闌之廝者亦無先大王。敝邑之王所甚憎者無先齊王，雖儀之所甚憎者亦無先齊王。而大王和之，是以敝邑之王不得事王，而令儀亦不得為門闌之廝也。王為儀閉關而絕齊，今使使者從儀西取笔秦所分楚商於之地方六百里，如是則齊弱矣。是北弱齊，西德於秦，私商於以為富，此一計而三利俱至也。」懷王大悅，乃置相璽於張儀，日與置酒，宣言「吾復得吾商於之地」。群臣皆賀，而陳軫獨弔。懷王曰：「何故？」陳軫對曰：「秦之所為重王者，以王之有齊也。今地未可得而齊交先絕，是楚孤也。夫秦又何重孤國哉，必輕楚矣。且先出地而後絕齊，則秦計不為。先絕齊而後責地，則必見欺於張儀。見欺於張儀，則王必怨之。怨之，是西起秦患，北絕齊交。西起秦患，北絕齊交，則兩國之兵必至。臣故弔。」楚王弗聽，因使一將軍西受封地。

**本卷说明：** “取笔秦”注本作“取故秦”，只在释义校明；商於许地未成为实际交割。

<!-- /sj040-cite-166 -->

<a id="sj040-cite-167"></a>

**[《史记·楚世家》P077](../../sources/摘录/史记-卷040-楚世家.md#p077)**

> 張儀至秦，詳醉墜車，稱病不出三月，地不可得。楚王曰：「儀以吾絕齊為尚薄邪？」乃使勇士宋遺北辱齊王。齊王大怒，折楚符而合於秦。秦齊交合，張儀乃起朝，謂楚將軍曰：「子何不受地？從某至某，廣袤六里。」楚將軍曰：「臣之所以見命者六百里，不聞六里。」即以歸報懷王。懷王大怒，興師將伐秦。陳軫又曰：「伐秦非計也。不如因賂之一名都，與之伐齊，是我亡於秦，取償於齊也，吾國尚可全。今王已絕於齊而責欺於秦，是吾合秦齊之交而來天下之兵也，國必大傷矣。」楚王不聽，遂絕和於秦，發兵西攻秦。秦亦發兵擊之。

**本卷说明：** 装醉三月、宋遗辱齐与索地六里为同一骗局的后续，放在此役完整语境；秦楚实际大会战另归312。

## 归年与考证

<a id="sj005-202-note"></a>
<a id="sj005-202秦王与魏王会临晋樗里疾俘赵将公子通受封于蜀"></a>
#### sj005-202｜秦王与魏王会临晋，樗里疾俘赵将，公子通受封于蜀。

[卷005 P062](../../sources/摘录/史记-卷005-秦本纪.md#p062)。

**说明：**公子通封蜀本纪列十一年，六国年表列十二年，采用前313。秦攻赵所获将庄与相邻年表藺阳条对读，不重复成两次俘同将。“张仪相楚”保留本纪措辞，本轮另据《通鉴》在下条补其与楚绝齐的交涉，不将“相楚”理解为终身转任。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0313-qin-note"></a>
<a id="卷015秦栏前313年"></a>
#### 卷015·秦栏｜前313年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0313)：“十二。樗里子擊藺陽，虜趙將。公子繇通封蜀。”

蔺阳与赵栏蔺互见，虏赵将赵庄与原页攻蔺合并；“公子繇通封蜀”的繇、通如何断读须与《秦本纪》公子通相对，不凭网页连字另造“繇通”两字名人物。封侯与蜀后来反抗不是一件事。 [对应正文](#event-1)

<a id="sj015-0313-wei-note"></a>
<a id="卷015魏栏前313年"></a>
#### 卷015·魏栏｜前313年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0313)：“六。秦來立公子政為太子。與秦王會臨晉。”

秦介入魏国立太子并参加临晋会面，二事分别理解。原文“公子政”的人物名照留，不把他无据改作后来秦王政。

<a id="sj015-0313-zhao-note"></a>
<a id="卷015赵栏前313年"></a>
#### 卷015·赵栏｜前313年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0313)：“十三。秦拔我藺，虜將趙莊。”

秦取蔺、俘赵庄与[既有攻蔺条](#event-1)合并。赵将姓名不由本年倒推成前315英／泥的同一人。

<a id="sj015-0313-chu-note"></a>
<a id="卷015楚栏前313年"></a>
#### 卷015·楚栏｜前313年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0313)：“十六。張儀來相。”

张仪赴楚并获楚王授予相印，见《通鉴》；“来相”不是只有普通使节之意。[《通鉴》卷三及校刊记](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-bf3ac638a2e1db)本年详载张仪以商於六百里诱楚绝齐，楚先断交，后来受骗而向秦开战；“来相”不能据一句断成张仪终身改任楚相。

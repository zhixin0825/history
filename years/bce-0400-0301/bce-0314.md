<a id="note-1"></a>

### 1. 秦夺义渠二十五城，并向魏韩推进

[返回正文第1条](#event-1)

**[卷005 P062](../../sources/摘录/史记-卷005-秦本纪.md#p062)**

> 十四年，更為元年。二年，張儀與齊、楚大臣會齧桑。三年，韓、魏太子來朝。張儀相魏。五年，王游至北河。七年，樂池相秦。韓、趙、魏、燕、齊帥匈奴共攻秦。秦使庶長疾與戰修魚，虜其將申差，敗趙公子渴、韓太子奐，斬首八萬二千。八年，張儀復相秦。九年，司馬錯伐蜀，滅之。伐取趙中都、西陽十年，韓太子蒼來質。伐取韓石章。伐敗趙將泥。伐取義渠二十五城。十一年，摢裏疾攻魏焦，降之。敗韓岸門，斬首萬，其將犀首走。公子通封於蜀。燕君讓其臣子之。十二年，王與梁王會臨晉。庶長疾攻趙，虜趙將莊。張儀相楚。十三年，庶長章擊楚於丹陽，虜其將屈丐，斬首八萬；又攻楚漢中，取地六百里，置漢中郡。楚圍雍氏，秦使庶長疾助韓而東攻齊，到滿助魏攻燕。十四年，伐楚，取召陵。丹、犁臣，蜀相壯殺蜀侯來降。

## 归年与考证

<a id="sj005-201-note"></a>
<a id="sj005-201秦夺义渠二十五城并向魏韩推进"></a>
#### sj005-201｜秦夺义渠二十五城，并向魏韩推进。

[卷005 P062](../../sources/摘录/史记-卷005-秦本纪.md#p062)。

**说明：**义渠二十五城本纪接更元十年，年表在十一年；暂用前314。岸门以本纪十一年系；原文“斩首万”为战果记数，主将与归属有待别传细校，不用一句包揽所有西线吞并。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0314-zhou-note"></a>
<a id="卷015周栏前314年"></a>
#### 卷015·周栏｜前314年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0314)：“周赧王元年。。”

赧王元年承接[前315慎靓王死、延继位](bce-0315.md#event-1)。表双句号照存，不把“元年”误作又一次更换周王。

<a id="sj015-0314-qin-note"></a>
<a id="卷015秦栏前314年"></a>
#### 卷015·秦栏｜前314年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0314)：“十一。侵義渠，得二十五城。”

义渠二十五城与旧秦本纪条合并；二十五为表所载，不凭数字复原二十五座未经确定的现代城址。 [对应正文](#event-1)

<a id="sj015-0314-wei-note"></a>
<a id="卷015魏栏前314年"></a>
#### 卷015·魏栏｜前314年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0314)：“五。秦拔我曲沃，歸其人。走犀首岸門。”

一格两事：秦拔曲沃、归其人，与本页秦魏战争合并；“走犀首岸门”保留为旧表说法。[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-fa118e8aca1fa5)把岸门战写作秦败韩、韩太子入质，《秦本纪》也以韩相接，故正文采用秦攻韩岸门，不把犀首的身份争议变成确定的魏军战败。

<a id="sj015-0314-chu-note"></a>
<a id="卷015楚栏前314年"></a>
#### 卷015·楚栏｜前314年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0314)：“十五。魯平公元年。”

鲁平公元年在楚栏是借记鲁事。传世《鲁世家》与《六国表》有旧年链，[《通鉴》卷二](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-b9016410a53af3)所载校刊本改置景公卒、平公承位于前323；[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-98f4cf9fad0734)又移平公卒至前303。鲁君次牵涉整段年代，本页保存前314元年异说，暂不新增确定的即位事件。

<a id="sj015-0314-yan-note"></a>
<a id="卷015燕栏前314年"></a>
#### 卷015·燕栏｜前314年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0314)：“七。君噲及太子相子之皆死。”

按[《燕召公世家》及索隐](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7034.md#ref-7430c046aeb510)及[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-cc9a8f3cf00cb3)，燕内乱与齐国入侵相接，子之与哙死亡；《索隐》引《纪年》又说子之杀公子平。表“太子相子之”不连读成人名。前312“立公子平”与此相冲突，另见[前312年说明](bce-0312.md#sj015-0312-yan-note)。

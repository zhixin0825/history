# 公元前315年｜慎靓王去世，赧王延继位

[← 上一张已编年页：公元前316年](bce-0316.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前314年 →](bce-0314.md)

**周慎靓王六年／赧王继位**

> 本页按古史年条与传统公元对照归档；明确有争议的日期见对应说明。月份、干支未直接换算为公历日期；不以已有一条材料表示本年所有历史都已收齐。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **慎靓王去世，赧王延继位。** 慎靓王在位六年后去世，儿子延接位，即赧王。下一年开始赧王元年。 [[1]](#reading-note-1)

   赧王时代，“东周”“西周”又指周王畿内分立的两个小国，不只是今天把整个周朝分成西周、东周两个时代的用法。天子后来迁居西周，不能再把赧王与西周君当成同一人。

<a id="two-zhou-background"></a>
<a id="从考王分封到两周分治不是一年发生的事"></a>
### 从考王分封到两周分治，不是一年发生的事

<a id="reading-event-2"></a>

2. **周天子之外，王畿里逐渐形成了由周室支系统治的两个小国。** 考王封弟于河南，称西周桓公，继而传威公、惠公；威公又把少子封在巩，奉王，号东周惠公。这是跨越几代的分封与继承，不是说周天子同时在同一年改称这几个谥号。 [[2]](#reading-note-2)

   到赧王时，两周分别治理，天子迁居西周。此处的西周君、东周君与赧王必须分开，否则后文赴秦、献城、先后死亡就会互相矛盾。

<a id="heir"></a>
<a id="西周太子死后楚人想用土地影响继承"></a>
### 西周太子死后，楚人想用土地影响继承

<a id="reading-event-3"></a>

3. **西周武公的共太子死，五名庶子之间尚未决定由谁承继。** 司马翦劝楚王用土地资助公子咎，替他请求太子之位。左成反对直接押注：万一周不听，楚既显得失算，又会疏远周。 [[3]](#reading-note-3)

   左成建议先私下问清周君想立谁，再让司马翦替那个人争取楚地，使支持与周君本意一致。最后公子咎果然被立为太子。外交资助怎样影响小国继承，比简单说一句“楚立太子”更接近这段经过。

<a id="passage"></a>
<a id="秦想借道攻韩周两边都得罪不起"></a>
### 秦想借道攻韩，周两边都得罪不起

<a id="reading-event-4"></a>

4. **秦要经过两周之间进攻韩国，周既怕拒秦，又怕借道后被韩报复。** 史厌建议分别传话：先向韩公叔说，秦敢从这里走，是信任东周，韩不如送地、送质到楚以离间；再向秦说，韩强把地给周，正为制造周秦猜疑，周不敢不受。 [[4]](#reading-note-4)

   两头说辞意在使周取得韩地、又仍能向秦交代。这里写的是史厌提出的办法，不能把其中每一封地转让和质子交换都当成已经执行。

<a id="summons"></a>
<a id="西周君不愿赴秦打算用韩军部署作为借口"></a>
### 西周君不愿赴秦，打算用韩军部署作为借口

<a id="reading-event-5"></a>

5. **秦召西周君，西周君担心赴会，想找一个不直接拒绝秦王的理由。** 他让人向韩王说，秦召自己可能是要借道进攻韩的南阳；若韩先在那里出兵，周君便可据此向秦推辞。 [[5]](#reading-note-5)

   这番话把韩的安全与周君自己的出行绑在一起。原文没有接着证明秦果然要攻南阳，也没有说韩已经照做，正文不替游说者把猜测变成事实。

<a id="war"></a>
<a id="两周相战东周劝韩暂缓援救西周"></a>
### 两周相战，东周劝韩暂缓援救西周

<a id="reading-event-6"></a>

6. **东周与西周交战，韩国准备帮助西周。** 有人替东周劝韩王，西周保有天子旧国的名器重宝，韩不如暂不出兵：这样既可使东周感激，又能向急于求援的西周索取财物。 [[6]](#reading-note-6)

   这段展示援军怎样被当成谈判条件；并没有交代韩王最后是否按兵，也没有列出哪一件宝器已经归韩。

<a id="yongshi"></a>
<a id="雍氏被围苏代争取免出兵粮还让周取得高都"></a>
### 雍氏被围，苏代争取免出兵粮，还让周取得高都

<a id="reading-event-7"></a>

7. **楚围韩国雍氏，韩国向东周征甲兵和粮食，东周君因此忧虑。** 苏代去见韩相，说楚本想三个月攻下，已经五个月仍未能克，说明楚也疲惫；韩再四处征兵粮，反会让楚看出韩的困境。 [[7]](#reading-note-7)

   韩相愿停止征发，苏代又要求把高都给周。韩相发怒，苏代再解释：给地可使周更靠近韩，而秦会因此疏周，韩付出一处不大的地方便可能取得周的整个支持。韩相最后答应，周得到高都。

<a id="event-2"></a>

<a id="reading-event-8"></a>

8. **韩太子苍到秦为质，秦取得韩石章并击败赵将。** 秦与韩一面以质子维系关系，一面继续用兵；本纪又列败赵将泥。 [[8]](#reading-note-8)

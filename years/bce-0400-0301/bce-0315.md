# 公元前315年｜慎靓王去世，赧王延继位

[← 上一张已编年页：公元前316年](bce-0316.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前314年 →](bce-0314.md)

**周慎靓王六年／赧王继位**

> 本页按古史年条与传统公元对照归档；明确有争议的日期见对应说明。月份、干支未直接换算为公历日期；不以已有一条材料表示本年所有历史都已收齐。

## 本年纪事

<a id="event-1"></a>

1. **慎靓王去世，赧王延继位。** 慎靓王在位六年后去世，儿子延接位，即赧王。下一年开始赧王元年。

赧王时代，“东周”“西周”又指周王畿内分立的两个小国，不只是今天把整个周朝分成西周、东周两个时代的用法。天子后来迁居西周，不能再把赧王与西周君当成同一人。 [原文与说明](#note-1)

## 两周分治时期的补充阅读｜以下各事未能确年

> 这些材料只按本纪的相对叙述安排，不计为前315年的事件，也不是赧王继位以前的“登场前事”。它们发生在两周分治的背景下，先读清经过，待确年材料再归入相应年页。

<a id="two-zhou-background"></a>
### 从考王分封到两周分治，不是一年发生的事

**周天子之外，王畿里逐渐形成了由周室支系统治的两个小国。** 考王封弟于河南，称西周桓公，继而传威公、惠公；威公又把少子封在巩，奉王，号东周惠公。这是跨越几代的分封与继承，不是说周天子同时在同一年改称这几个谥号。

到赧王时，两周分别治理，天子迁居西周。此处的西周君、东周君与赧王必须分开，否则后文赴秦、献城、先后死亡就会互相矛盾。 [原文与说明](#sj004-undated-two-zhou-background)

<a id="heir"></a>
### 西周太子死后，楚人想用土地影响继承

**西周武公的共太子死，五名庶子之间尚未决定由谁承继。** 司马翦劝楚王用土地资助公子咎，替他请求太子之位。左成反对直接押注：万一周不听，楚既显得失算，又会疏远周。

左成建议先私下问清周君想立谁，再让司马翦替那个人争取楚地，使支持与周君本意一致。最后公子咎果然被立为太子。外交资助怎样影响小国继承，比简单说一句“楚立太子”更接近这段经过。 [原文与说明](#sj004-undated-heir)

<a id="passage"></a>
### 秦想借道攻韩，周两边都得罪不起

**秦要经过两周之间进攻韩国，周既怕拒秦，又怕借道后被韩报复。** 史厌建议分别传话：先向韩公叔说，秦敢从这里走，是信任东周，韩不如送地、送质到楚以离间；再向秦说，韩强把地给周，正为制造周秦猜疑，周不敢不受。

两头说辞意在使周取得韩地、又仍能向秦交代。这里写的是史厌提出的办法，不能把其中每一封地转让和质子交换都当成已经执行。 [原文与说明](#sj004-undated-passage)

<a id="summons"></a>
### 西周君不愿赴秦，打算用韩军部署作为借口

**秦召西周君，西周君担心赴会，想找一个不直接拒绝秦王的理由。** 他让人向韩王说，秦召自己可能是要借道进攻韩的南阳；若韩先在那里出兵，周君便可据此向秦推辞。

这番话把韩的安全与周君自己的出行绑在一起。原文没有接着证明秦果然要攻南阳，也没有说韩已经照做，正文不替游说者把猜测变成事实。 [原文与说明](#sj004-undated-summons)

<a id="war"></a>
### 两周相战，东周劝韩暂缓援救西周

**东周与西周交战，韩国准备帮助西周。** 有人替东周劝韩王，西周保有天子旧国的名器重宝，韩不如暂不出兵：这样既可使东周感激，又能向急于求援的西周索取财物。

这段展示援军怎样被当成谈判条件；并没有交代韩王最后是否按兵，也没有列出哪一件宝器已经归韩。 [原文与说明](#sj004-undated-war)

<a id="yongshi"></a>
### 雍氏被围，苏代争取免出兵粮，还让周取得高都

**楚围韩国雍氏，韩国向东周征甲兵和粮食，东周君因此忧虑。** 苏代去见韩相，说楚本想三个月攻下，已经五个月仍未能克，说明楚也疲惫；韩再四处征兵粮，反会让楚看出韩的困境。

韩相愿停止征发，苏代又要求把高都给周。韩相发怒，苏代再解释：给地可使周更靠近韩，而秦会因此疏周，韩付出一处不大的地方便可能取得周的整个支持。韩相最后答应，周得到高都。 [原文与说明](#sj004-undated-yongshi)

<a id="event-2"></a>

2. **韩太子苍到秦为质，秦取得韩石章并击败赵将。** 秦与韩一面以质子维系关系，一面继续用兵；本纪又列败赵将泥。 [原文与说明](#sj005-200-note)

<a id="sj004-315-1"></a>
### 1. 慎靓王去世，赧王延继位

<a id="sj004-undated-two-zhou-background"></a>
### 未确年说明｜从考王分封到两周分治，不是一年发生的事

[卷004 P064](../../sources/摘录/史记-卷004-周本纪.md#p064) · [卷004 P069](../../sources/摘录/史记-卷004-周本纪.md#p069)。 这组记事没有逐项年月，作为两周分治的制度背景展示，不计为前315年新分封。东周、西周在这里是两个地方政治实体，勿与时代分期同名混淆。

<a id="sj004-undated-heir"></a>
### 未确年说明｜西周太子死后，楚人想用土地影响继承

[卷004 P070](../../sources/摘录/史记-卷004-周本纪.md#p070)。 共太子是称号，本段没有交代私人名或确切死亡年；“五庶子”与前文周武王的兄弟不是同一代。继位的是当地周君的太子，不是周天子的太子。

<a id="sj004-undated-passage"></a>
### 未确年说明｜秦想借道攻韩，周两边都得罪不起

[卷004 P072](../../sources/摘录/史记-卷004-周本纪.md#p072)。 原段没有独立年号。段落在赧王八年之后，只能给出阅读顺序，不能把借道直接定成前307年与宜阳战役同一次行军。

<a id="sj004-undated-summons"></a>
### 未确年说明｜西周君不愿赴秦，打算用韩军部署作为借口

[卷004 P073](../../sources/摘录/史记-卷004-周本纪.md#p073)。 西周君与赧王不同；本条仅有外交动作及说辞，没有可可靠转换的公元年。

<a id="sj004-undated-war"></a>
### 未确年说明｜两周相战，东周劝韩暂缓援救西周

[卷004 P074](../../sources/摘录/史记-卷004-周本纪.md#p074)。 不把同名两周理解为西周王朝与东周王朝隔数百年相互作战。本段是地方周国的争端。

<a id="sj004-undated-yongshi"></a>
### 未确年说明｜雍氏被围，苏代争取免出兵粮，还让周取得高都

[卷004 P075](../../sources/摘录/史记-卷004-周本纪.md#p075)。 “期三月、今五月”是围城时长，不直接译成农历三月、五月。段首“王赧谓成君”是工作底本断裂短句，未据之补造一段赧王对成君的对话。雍氏多次被围，本轮不只因前后相邻就选某一次确年。

## 补充史料与异说

<a id="sj005-200-note"></a>
### sj005-200｜韩太子苍到秦为质，秦取得韩石章并击败赵将。

[卷005 P062](../../sources/摘录/史记-卷005-秦本纪.md#p062)。

**说明：**赵将名在本纪作泥，年表作英，身份差别保留，不凭异名造两场相同战争。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0315-zhao-note"></a>
### 卷015·赵栏｜前315年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0315)：“十一。秦敗我將軍英。”

“英”与原页《秦本纪》的“泥”为异名／异文线索，不能直接认作两个已知不同的赵将，也没有证据据此造两场同年败仗。相关战事仍归[原有第二条](#event-2)。

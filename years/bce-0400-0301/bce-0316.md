<a id="event-1"></a>

1. **司马错率秦军灭蜀，秦又取赵中都、西阳。** 蜀从遣使与秦往来的邻国，转入秦军控制之下；同年秦在赵地还有取城，两条战线应分辨阅读。 [[1]](#note-1)

<a id="event-2"></a>

2. **燕王哙把国政、名位与任官权交给子之。** 子之原已掌握政务；苏代又以齐王不肯信臣所以不能称霸相激，使哙愈加信任子之。鹿毛寿借尧让许由的故事劝王让国，声称可以既得美名又保实权。哙先交国政，随后听人以禹荐益、启夺位为例指出太子仍控制官员，便把三百石以上官员的印信一并交给子之。子之南面行王事，哙反居臣位，不再听政。 [[2]](#note-2)

## 本年相关史料

<a id="note-1"></a>

### 1. 司马错率秦军灭蜀，秦又取赵中都、西阳

[返回正文第1条](#event-1)

**[卷005 P062](../../sources/摘录/史记-卷005-秦本纪.md#p062)**

> 十四年，更為元年。二年，張儀與齊、楚大臣會齧桑。三年，韓、魏太子來朝。張儀相魏。五年，王游至北河。七年，樂池相秦。韓、趙、魏、燕、齊帥匈奴共攻秦。秦使庶長疾與戰修魚，虜其將申差，敗趙公子渴、韓太子奐，斬首八萬二千。八年，張儀復相秦。九年，司馬錯伐蜀，滅之。伐取趙中都、西陽十年，韓太子蒼來質。伐取韓石章。伐敗趙將泥。伐取義渠二十五城。十一年，摢裏疾攻魏焦，降之。敗韓岸門，斬首萬，其將犀首走。公子通封於蜀。燕君讓其臣子之。十二年，王與梁王會臨晉。庶長疾攻趙，虜趙將莊。張儀相楚。十三年，庶長章擊楚於丹陽，虜其將屈丐，斬首八萬；又攻楚漢中，取地六百里，置漢中郡。楚圍雍氏，秦使庶長疾助韓而東攻齊，到滿助魏攻燕。十四年，伐楚，取召陵。丹、犁臣，蜀相壯殺蜀侯來降。

<a id="note-2"></a>

### 2. 燕君把国政和名位让给子之

[返回正文第2条](#event-2)

<a id="sj069-cite-002"></a>

**[《史记·苏秦列传》P045](../../sources/摘录/史记-卷069-苏秦列传.md#p045)**

> 於是燕王專任子之，已而讓位，燕大亂。

**本卷归年说明：** 苏代所说“不信其臣”是传记所记说辞；本年的让国事件与《燕召公世家》属于同一事，不另增第二次让位。

<!-- /sj069-cite-002 -->

<a id="sj034-cite-063"></a>

**[《史记·燕召公世家》P022](../../sources/摘录/史记-卷034-燕召公世家.md#p022)**

> 鹿毛壽謂燕王：「不如以國讓相子之。人之謂堯賢者，以其讓天下於許由，許由不受，有讓天下之名而實不失天下。今王以國讓於子之，子之必不敢受，是王與堯同行也。」燕王因屬國於子之，子之大重。或曰：「禹薦益，已而以啟人為吏。及老，而以啟人為不足任乎天下，傳之於益。已而啟與交黨攻益，奪之。天下謂禹名傳天下於益，已而實令啟自取之。今王言屬國於子之，而吏無非太子人者，是名屬子之而實太子用事也。」王因收印自三百石吏已上而效之子之。子之南面行王事，而噲老不聽政，顧為臣，國事皆決於子之。

**本卷说明：** 本篇让国故事对应年表前316年。说客所用尧、许由、禹、益、启的论证属于战国政治故事，不据此修改上古时期的定论。三百石是此处官秩门槛，不解释为三百名官员。



<a id="sj034-cite-062"></a>

**[《史记·燕召公世家》P021](../../sources/摘录/史记-卷034-燕召公世家.md#p021)**

> 子之相燕，貴重，主斷。蘇代為齊使於燕，燕王問曰：「齊王奚如？」對曰：「必不霸。」燕王曰：「何也？」對曰：「不信其臣。」蘇代欲以激燕王以尊子之也。於是燕王大信子之。子之因遺蘇代百金，而聽其所使。

**本卷说明：** 这是让国前的游说背景，原段未独立标年；不因读在前316年便声称齐使到燕的具体日期已经确证。



**[卷005 P062](../../sources/摘录/史记-卷005-秦本纪.md#p062)**

#### 卷015·秦栏｜前316年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0316)：“九。擊蜀，滅之。取趙中都、西陽。”

灭蜀与夺赵中都、西阳并入既有第一条，分清西南和东方战线；[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-5ae0e895f1124d)记巴蜀互攻、秦决策及十月出兵，原表只短记结果，不据“灭”宣布蜀地从此再无统治反抗。 [对应正文](#event-1)

<a id="sj015-0316-zhao-note"></a>
<a id="卷015赵栏前316年"></a>
#### 卷015·赵栏｜前316年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0316)：“十。秦取我中都、西陽。”

秦取中都、西阳与[第一条](#event-1)合并，赵栏是同一事件的失地方记录；不加成四座城。

<a id="sj015-0316-yan-note"></a>
<a id="卷015燕栏前316年"></a>
#### 卷015·燕栏｜前316年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0316)：“五。君讓其臣子之國，顧為臣。”

让国与原有第二条合并，[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-4da2af55a9efd8)也列本年：哙交出吏员印绶，子之南面行王事，哙退居臣位。此为燕国政治权力转移，不能套入秦更元十一年。 [对应正文](#event-2)

1. **秦在修鱼击败韩赵军，张仪再次任秦相。** 秦俘获申差等将领，本纪还列韩太子奂、赵公子渴受败及斩首八万二千。联军的后撤没有终止各国在秦东面的作战。 败后，韩相公仲认为盟友不能依靠，建议经张仪与秦议和，送一座名城并整军随秦攻楚，以交一城换取秦停攻韩、韩秦共攻楚两项收益，韩王原已答应。楚王怕两国合兵，陈轸劝他只作大举救韩的姿态：戒备边境，让战车布满道路，遣厚礼使者，使韩相信援军将至；即使韩仍随秦攻楚，也会感激楚而不同心进军，若韩因而绝秦，秦又将怨韩而不急攻楚。楚照计声言愿为韩赴死，韩王便叫停公仲西行。公仲反复劝阻，说真正出兵攻韩的是秦，楚给的只是救援名义；韩楚既无兄弟关系，也无事先合谋，临受攻才来示救，正像陈轸的谋略；韩已答复秦却临时反悔，是轻欺强敌、相信别国谋臣，必将后悔。韩王仍断和，秦增兵来攻而楚援不到。这段外交说辞接在修鱼败后，随后岸门与送质分别见前314、315的异年记录，不把整串都算本年完成。 [[1]](#note-1)

<a id="sj015-0317-wei-event"></a>

<a id="event-2"></a>

2. **齐军在观泽击败魏、赵军队。** 魏、赵既要应付秦军，也面临东方齐国的压力。 [[2]](#note-2)

### 1. 秦在修鱼击败韩赵军，张仪再次任秦相

[返回正文第1条](#event-1)

**[卷005 P062](../../sources/摘录/史记-卷005-秦本纪.md#p062)**

> 十四年，更為元年。二年，張儀與齊、楚大臣會齧桑。三年，韓、魏太子來朝。張儀相魏。五年，王游至北河。七年，樂池相秦。韓、趙、魏、燕、齊帥匈奴共攻秦。秦使庶長疾與戰修魚，虜其將申差，敗趙公子渴、韓太子奐，斬首八萬二千。八年，張儀復相秦。九年，司馬錯伐蜀，滅之。伐取趙中都、西陽十年，韓太子蒼來質。伐取韓石章。伐敗趙將泥。伐取義渠二十五城。十一年，摢裏疾攻魏焦，降之。敗韓岸門，斬首萬，其將犀首走。公子通封於蜀。燕君讓其臣子之。十二年，王與梁王會臨晉。庶長疾攻趙，虜趙將莊。張儀相楚。十三年，庶長章擊楚於丹陽，虜其將屈丐，斬首八萬；又攻楚漢中，取地六百里，置漢中郡。楚圍雍氏，秦使庶長疾助韓而東攻齊，到滿助魏攻燕。十四年，伐楚，取召陵。丹、犁臣，蜀相壯殺蜀侯來降。

**[《史记·韩世家》P022](../../sources/摘录/史记-卷045-韩世家.md#p022)**

> 十六年，秦敗我修魚，虜得韓將鯁、申差於濁澤。韓氏急，公仲謂韓王曰：「與國非可恃也。今秦之欲伐楚久矣，王不如因張儀為和於秦，賂以一名都，具甲，與之南伐楚，此以一易二之計也。」韓王曰：「善。」乃警公仲之行，將西購於秦。楚王聞之大恐，召陳軫告之。陳軫曰：「秦之欲伐楚久矣，今又得韓之名都一而具甲，秦韓并兵而伐楚，此秦所禱祀而求也。今已得之矣，楚國必伐矣。王聽臣為之警四境之內，起師言救韓，命戰車滿道路，發信臣，多其車，重其幣，使信王之救己也。縱韓不能聽我，韓必德王也，必不為鴈行以來，是秦韓不和也，兵雖至，楚不大病也。為能聽我絕和於秦，秦必大怒，以厚怨韓。韓之南交楚，必輕秦；輕秦，其應秦必不敬：是因秦、韓之兵而免楚國之患也。」楚王曰：「善。」乃警四境之內，興師言救韓。命戰車滿道路，發信臣，多其車，重其幣。謂韓王曰：「不穀國雖小，已悉發之矣。願大國遂肆志於秦，不穀將以楚殉韓。」韓王聞之大說，乃止公仲之行。公仲曰：「不可。夫以實伐我者秦也，以虛名救我者楚也。王恃楚之虛名，而輕絕彊秦之敵，王必為天下大笑。且楚韓非兄弟之國也，又非素約而謀伐秦也。已有伐形，因發兵言救韓，此必陳軫之謀也。且王已使人報於秦矣，今不行，是欺秦也。夫輕欺彊秦而信楚之謀臣，恐王必悔之。」韓王不聽，遂絕於秦。秦因大怒，益甲伐韓，大戰，楚救不至韓。

**本卷说明：** 鯁又作䱸，申差为另一将；本篇濁澤，正义据年表疑当观泽，但齐魏观泽之战另有本页第2条，不据地名疑改把秦韩战与齐魏战合成一役。

## 归年与考证

<a id="sj005-197-note"></a>
<a id="sj005-197秦在修鱼击败韩赵军张仪再次任秦相"></a>
#### sj005-197｜秦在修鱼击败韩赵军，张仪再次任秦相。

[卷005 P062](../../sources/摘录/史记-卷005-秦本纪.md#p062)。

**说明：**从六国年表更元八年；本纪把战果连在七年攻秦之后。首级数与将名依本纪，年表有较略计数，未称独立统计已定。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0317-qin-note"></a>
<a id="卷015秦栏前317年"></a>
#### 卷015·秦栏｜前317年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0317)：“八。與韓、趙戰，斬首八萬。張儀復相。”

修鱼战及张仪复相与既有第一条合并；表记八万，本纪八万二千，均为各书所载数字，不能相加。 [对应正文](#event-1)

<a id="sj015-0317-wei-note"></a>
<a id="卷015魏栏前317年"></a>
#### 卷015·魏栏｜前317年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0317)：“二。齊敗我觀澤。”

与赵、齐栏的观泽之战合并；主语齐、受败者魏赵。此战与秦在修鱼击韩赵是不同战场。

<a id="sj015-0317-han-note"></a>
<a id="卷015韩栏前317年"></a>
#### 卷015·韩栏｜前317年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0317)：“十六。秦敗我脩魚，得將軍申差。”

修鱼写作脩鱼，秦军获申差并入[既有修鱼条](#event-1)。其他本子将被俘与浊泽相接，不能把每个地名都拼成同一天同一战斗地点。

<a id="sj015-0317-zhao-note"></a>
<a id="卷015赵栏前317年"></a>
#### 卷015·赵栏｜前317年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0317)：“九。與韓、魏擊秦。齊敗我觀澤。”

一格含两项：赵与韩魏攻秦归[修鱼及攻秦战局](#event-1)，齐败赵于观泽归[观泽条](#sj015-0317-wei-event)。本格并未说韩军也在观泽败于齐，不扩充参与国。

<a id="sj015-0317-qi-note"></a>
<a id="卷015齐栏前317年"></a>
#### 卷015·齐栏｜前317年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0317)：“七。敗魏、趙觀澤。”

与魏、赵栏指向同一[观泽之战](#sj015-0317-wei-event)，只增加齐方互见。

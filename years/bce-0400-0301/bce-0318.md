1. **多国联合攻秦，楚怀王为盟主，秦守住主要防线。** 乐池在这一时期任秦相。联军至函谷关后遭秦迎击，各国先后撤回，齐军最后退，未取得预期突破；下一年秦韩赵仍在修鱼交战。合纵说客姓名的行年争议另见同号注。 [[1]](#note-1)

<a id="sj015-0318-qi-event"></a>

<a id="event-2"></a>

2. **宋君偃采用王号。** 宋的实际承位早于本年，称王是在原有君位上改变名号。 [[2]](#note-2)

**[卷005 P062](../../拆分史书/史记/卷005.md#p062)**

> 十四年，更為元年。二年，張儀與齊、楚大臣會齧桑。三年，韓、魏太子來朝。張儀相魏。五年，王游至北河。七年，樂池相秦。韓、趙、魏、燕、齊帥匈奴共攻秦。秦使庶長疾與戰修魚，虜其將申差，敗趙公子渴、韓太子奐，斬首八萬二千。八年，張儀復相秦。九年，司馬錯伐蜀，滅之。伐取趙中都、西陽十年，韓太子蒼來質。伐取韓石章。伐敗趙將泥。伐取義渠二十五城。十一年，摢裏疾攻魏焦，降之。敗韓岸門，斬首萬，其將犀首走。公子通封於蜀。燕君讓其臣子之。十二年，王與梁王會臨晉。庶長疾攻趙，虜趙將莊。張儀相楚。十三年，庶長章擊楚於丹陽，虜其將屈丐，斬首八萬；又攻楚漢中，取地六百里，置漢中郡。楚圍雍氏，秦使庶長疾助韓而東攻齊，到滿助魏攻燕。十四年，伐楚，取召陵。丹、犁臣，蜀相壯殺蜀侯來降。

## 归年与考证

<a id="sj005-196-note"></a>
<a id="sj005-196多国联合攻秦秦守住了主要防线"></a>
#### sj005-196｜多国联合攻秦，秦守住了主要防线。

[卷005 P062](../../拆分史书/史记/卷005.md#p062)。

**说明：**本纪列韩赵魏燕齐并称率匈奴，传统合纵名单与各书不完全一致；以“多国”概括，不虚构统一指挥和兵数。年表把修鱼战列前317，不能把两年的交战压成一次。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../拆分史书/史记/卷005.md#kao-c691f26620)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0318-qin-note"></a>
<a id="卷015秦栏前318年"></a>
#### 卷015·秦栏｜前318年

[本年原格](../../拆分史书/史记/卷015.md#y0318)：“七。五國共擊秦，不勝而還。”

五国攻秦并入既有联军条；年表以魏、韩、赵、楚、燕五栏互见，[《通鉴》卷三及校刊记](../../拆分史书/资治通鉴/卷003.md#text)亦列此五国。《秦本纪》作韩赵魏燕齐并牵涉匈奴，名单差别仍留在原注，不把同一联军拆成六场战役。 [对应正文](#event-1)

<a id="sj015-0318-wei-note"></a>
<a id="卷015魏栏前318年"></a>
#### 卷015·魏栏｜前318年

[本年原格](../../拆分史书/史记/卷015.md#y0318)：“魏哀王元年。擊秦不勝。”

攻秦归入[同年联军条](#event-1)。“魏哀王元年”沿此前把惠王后元误接襄王的旧系统；[《魏世家·索隐》](../../拆分史书/史记/卷044.md#part-2-text)据《纪年》论惠王改元，[《通鉴》卷三及校刊记](../../拆分史书/资治通鉴/卷003.md#text)前319年明列惠王卒、襄王嗣立。因此正文从前318为魏襄王元年，不另设一位同时期魏哀王。

<a id="sj015-0318-han-note"></a>
<a id="卷015韩栏前318年"></a>
#### 卷015·韩栏｜前318年

[本年原格](../../拆分史书/史记/卷015.md#y0318)：“十五。擊秦不勝。”

本国参与攻秦而未获胜，与秦、魏及其余参与国同格互见，合并到[既有联军条](#event-1)，不按各栏重复计为独立战争。

# 公元前319年｜秦取鄢、楚城广陵，魏惠王去世

## 本年纪事

<a id="sj015-0319-han-event"></a>

**秦军取得鄢。**秦继续向东扩张，但这处城邑当时属韩还是属魏，现存记载并不一致。 [原文与说明](#sj015-0319-han-note)

<a id="sj015-0319-chu-event"></a>

**楚国修筑广陵城，经营东方的据点。** [原文与说明](#sj015-0319-chu-note)

<a id="sj015-0319-wei-accession"></a>

**魏惠王去世，儿子嗣继位，即魏襄王。**魏国早已迁都大梁，因而这些君主也常被称为梁王。 [原文与说明](#sj015-0319-wei-accession-note)

## 本年相关史料

<a id="sj015-0319-han-note"></a>
### 卷015·韩栏｜前319年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0319)：“十四。秦來擊我，取鄢。”

此格把鄢之战记在韩栏，[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-6e72fcc883d55f)却作“秦伐魏，取鄢”。正文采用两者共同支持的秦取鄢，不把归属争议隐去；不能因栏名就确定当地当时只属韩。

<a id="sj015-0319-chu-note"></a>
### 卷015·楚栏｜前319年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0319)：“十。城廣陵。”

楚怀王十年城广陵，原表仅记筑城，不补此时已建成何种水军基地、运河或现代城市规模。

<a id="sj015-0319-wei-accession-note"></a>
### 衔接说明｜魏惠王去世，儿子嗣继位，即魏襄王

[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-624dd1d30f4c73)慎靓王二年及[《魏世家·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-7806895926a528)惠王改元说；下一年前318采用襄王元年，而不照旧表再立一个魏哀王。

## 本年纪事

<a id="event-1"></a>

1. **秦王出游至北河。** 本纪仅记行程终点，没有另列在此举行的战役或分封，正文不借“游”字补造军事巡视细节。 [原文与说明](#sj005-195-note)

<a id="event-2"></a>
<a id="sj015-mengzi"></a>

2. **孟子来到魏国，与梁惠王谈仁义与治国；此事约在前320—319年，暂附于本年。** 孟子名轲，是邹人，早年向子思的门人求学，后来以仁义之说游说诸侯。梁惠王就是魏惠王。他问这位远来的长者能给自己的国家带来什么利益。孟子回答，君主应先谈仁义：如果国君、大夫和普通人都以争取自身利益为先，上下相争，国家就会陷入危险。在与惠王的谈话中，他还把治国落实到使百姓能够养生、送死，减少妨碍农事的征发，减轻刑罚和税敛等主张。 [2](#note-2)

<a id="sj015-0320-yan-event"></a>

**燕国开始使用燕王哙的元年。**哙是易王之子，已在上一年父亲去世后接位。 [原文与说明](#sj015-0320-yan-note)

<a id="sj015-0320-qi-event"></a>

**齐国从秦国迎娶女子，两国王室之间建立婚姻联系。** [原文与说明](#sj015-0320-qi-note)

<a id="sj015-0320-qi-accession"></a>

**齐威王去世，儿子辟疆接位，即齐宣王。** [原文与说明](#sj015-0320-qi-accession-note)

<a id="note-2"></a>
### 2｜孟子见梁惠王：旧表前336年与晚至魏说

**来源：**[卷015前336年魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0336)及[该年异年说明](bce-0336.md#sj015-mengzi-variant)；[《孟子·梁惠王上》第一、三、五章](https://zh.wikisource.org/wiki/孟子/梁惠王上)；[《史记》卷074开篇](https://zh.wikisource.org/wiki/史記三家註/卷074)；[《魏世家·索隐》惠王改元条](https://zh.wikisource.org/wiki/史記三家註/卷044)；[梁玉绳《史记志疑》卷十“孟子来”条](https://www.shidianguji.com/zh/book/NGJ892412000002866151907/chapter/1lqqusb38ejvm)。

**归年：**《六国年表》把“孟子来”放在旧魏惠王三十五年，即见证网页前336年行。但旧表把惠王改元误接成襄王元年，不能由这一王年直接确定孟子来魏的公元年。《孟子》记惠王回顾向西失地于秦、向南受辱于楚，这些事情不能都提前到前336年以前。梁玉绳据此主张来魏在惠王改元后十五、十六年间；按本项目暂取前334年为后元元年，换算为前320—319年。因此本页是有范围的阅读位置，尚未裁定首次见面恰在前320年；也不把《孟子》各章认作同日的谈话实录。具体年链及异说见[本批补核](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#孟子苏秦)。

**人物与文义：**“受业子思之门人”是《史记》所传的学统，不写成孟子亲受业于子思。正文不补出生年、来魏时的精确年龄或无独立年代的游国顺序。“何必曰利”针对上下争利的治国取向；孟子同时谈百姓生计，并非主张不问民生。惠王自述“长子死焉”与《史记》马陵太子申被俘的表述有差别，此处不据一句话另定太子申死亡日期。 [回正文](#sj015-mengzi)

### 卷015·周栏｜前320年

“北游戎地，至河上”补足原页北河行程表述；没有据此新增战役或巡边命令。 [对应正文](#event-1)

<a id="sj015-0320-yan-note"></a>
### 卷015·燕栏｜前320年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0320)：“燕王噲元年”

王哙元年；[《通鉴》卷二](https://zh.wikisource.org/wiki/資治通鑑/卷002)在前321记易王卒、子哙立，故先有承位，再有本年元年。与前323易王称王是不同事件。

<a id="sj015-0320-qi-note"></a>
### 卷015·齐栏｜前320年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0320)：“四。迎婦于秦。”

齐栏“迎妇于秦”表示齐方从秦迎娶女子；旧表王名错置，正文只称齐国，不借旧“湣王四年”证明是哪一位王在某月成婚。女方姓名、与秦王亲属关系均未载。

<a id="sj015-0320-qi-accession-note"></a>
### 衔接说明｜齐威王去世，儿子辟疆接位，即齐宣王

[《通鉴》卷三及校刊记](https://zh.wikisource.org/wiki/資治通鑑/卷003)校刊记把旧前333年条移到本年，承接项目已用的田齐君次校订；没有据此反改原表。

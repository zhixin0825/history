## 本年纪事

<a id="event-1"></a>

1. **韩、魏太子来朝，张仪转到魏国任相。** 秦与两国王室有直接往来；张仪的任职也不是自入秦后终身留在同一朝廷。 [原文与说明](#sj005-194-note)

<a id="event-2"></a>
<a id="sj015-zhen"></a>

2. **魏惠王与齐威王在甄会面，暂依古注所引魏后元十三年附于本年。** 这次会面接在两国先前的交涉之后，地点在另本作鄄。现存这条记录没有说明新的领土安排或会盟条款。 [2](#note-2)

<a id="sj015-0322-wei-event"></a>

**秦军再次取得魏国曲沃；此前交还给魏国的城邑又回到战争中。** [原文与说明](#sj015-0322-wei-note)

<a id="sj015-0322-zhao-event"></a>

**赵国与韩国在区鼠会面，两国在秦、魏压力之外也维持彼此交涉。** [原文与说明](#sj015-0322-zhao-note)

<a id="sj015-0322-tianying"></a>

**田婴受封于薛，号靖郭君。**他此前已参与齐国对魏战争和外交，薛后来成为其子田文经营宾客的重要基础。 [原文与说明](#sj015-0322-tianying-note)

<a id="note-2"></a>
### 2｜甄／鄄之会：原表旧年与《纪年》后元十三年

**来源：**[卷015前335年齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0335)；[《孟尝君列传·索隐》](https://zh.wikisource.org/wiki/史記三家註/卷075)；[《魏世家》](https://zh.wikisource.org/wiki/史記三家註/卷044)。

**归年：**原表把甄会放在旧齐宣王八年、前335年行，与把魏惠王误作将卒的年链相连。《孟尝君列传·索隐》引《纪年》“十三年会齐威王于鄄”，接在惠王后元十一年平阿会之后。按本项目采用的后元起点，十三年对应前322年，因此在本页暂系，并以魏惠王、齐威王称两国君主。《列传》正文说平阿会的“明年”再会甄，古注却为后元十一年、十三年，两者仍差一年；本页采古注分年，不将这个相对年次冲突隐去。也不沿旧《列传》“是岁梁惠王卒”在本年再造惠王去世。参见[前324年平阿会](bce-0324.md#sj015-pinga)及[本批君次说明](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#齐魏君次)。 [回正文](#sj015-zhen)

<a id="sj015-0322-qin-note"></a>
### 卷015·秦栏｜前322年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0322)：“三。張儀免相，相魏。”

张仪由秦转任魏相与原有第一条合并。[《通鉴》卷二](https://zh.wikisource.org/wiki/資治通鑑/卷002)并记秦以对魏战争促其亲秦；后续前317复相秦另存，不写成始终未离秦。 [对应正文](#event-1)

<a id="sj015-0322-wei-note"></a>
### 卷015·魏栏｜前322年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0322)：“十三。秦取曲沃。平周女化為丈夫。”

秦取曲沃据原表及[《通鉴》卷二](https://zh.wikisource.org/wiki/資治通鑑/卷002)补入；后者兼记取平周。原格“平周女化为丈夫”作为古代异象记载保留，本页不把它医学化为可以确证的性别转换，也不据此断言政治祸福。与前327归还曲沃、前314再次攻取分开。

<a id="sj015-0322-zhao-note"></a>
### 卷015·赵栏｜前322年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0322)：“四。與韓會區鼠。”

区鼠会面据赵栏补入；韩栏当年只有王年，不能因韩未重记便抹去赵方材料。地点只保留古名。

<a id="sj015-0322-tianying-note"></a>
### 衔接说明｜田婴受封于薛，号靖郭君

[《通鉴》卷二](https://zh.wikisource.org/wiki/資治通鑑/卷002)前322年；卷015主见证在前321另记，三家注表相应格缺此句。前321只保留异年回链，田文继嗣不强系受封同年。

<a id="event-1"></a>

1. **张仪与齐、楚大臣会于啮桑。** 秦相直接参加多国外交，战争并不是秦向东经营的唯一手段。 [[1]](#note-1)

<a id="sj015-0323-han-event"></a>

<a id="event-2"></a>

2. **韩国和燕国的君主先后采用王号。** 周天子仍在，但越来越多诸侯已用“王”来表示与其他强国并列的地位。 赵武灵王的传述却说自己没有相应实力，岂敢居王名，令国人只称“君”；本篇将此附在武灵八年，与其他相王年次不同。 [[2]](#note-2)

<a id="sj015-0323-chu-event"></a>

<a id="event-3"></a>

3. **昭阳在襄陵败魏取八邑，转攻齐后被陈轸劝退。** 陈轸本为秦使在齐，应齐王之请入楚营。他先问楚国功赏之制，指出昭阳官爵已高，无论再胜都难加封，却可能因败战失爵丧身。继以舍人画蛇争酒、先成者添足反失酒为喻，劝守住已有战功，退兵使齐感恩。昭阳接受，停止攻齐。 [[3]](#note-3)

### 1. 张仪与齐、楚大臣会于啮桑

[返回正文第1条](#event-1)

**[卷005 P062](../../拆分史书/史记/卷005.md#p062)**

> 十四年，更為元年。二年，張儀與齊、楚大臣會齧桑。三年，韓、魏太子來朝。張儀相魏。五年，王游至北河。七年，樂池相秦。韓、趙、魏、燕、齊帥匈奴共攻秦。秦使庶長疾與戰修魚，虜其將申差，敗趙公子渴、韓太子奐，斬首八萬二千。八年，張儀復相秦。九年，司馬錯伐蜀，滅之。伐取趙中都、西陽十年，韓太子蒼來質。伐取韓石章。伐敗趙將泥。伐取義渠二十五城。十一年，摢裏疾攻魏焦，降之。敗韓岸門，斬首萬，其將犀首走。公子通封於蜀。燕君讓其臣子之。十二年，王與梁王會臨晉。庶長疾攻趙，虜趙將莊。張儀相楚。十三年，庶長章擊楚於丹陽，虜其將屈丐，斬首八萬；又攻楚漢中，取地六百里，置漢中郡。楚圍雍氏，秦使庶長疾助韓而東攻齊，到滿助魏攻燕。十四年，伐楚，取召陵。丹、犁臣，蜀相壯殺蜀侯來降。

<a id="sj040-cite-160"></a>

**[《史记·楚世家》P073](../../拆分史书/史记/卷040.md#p073)**

> 六年，楚使柱國昭陽將兵而攻魏，破之於襄陵，得八邑。又移兵而攻齊，齊王患之。陳軫適為秦使齊，齊王曰：「為之柰何？」陳軫曰：「王勿憂，請令罷之。」即往見昭陽軍中，曰：「願聞楚國之法，破軍殺將者何以貴之？」昭陽曰：「其官為上柱國，封上爵執珪。」陳軫曰：「其有貴於此者乎？」昭陽曰：「令尹。」陳軫曰：「今君已為令尹矣，此國冠之上。臣請得譬之。人有遺其舍人一卮酒者，舍人相謂曰：『數人飲此，不足以遍，請遂畫地為蛇，蛇先成者獨飲之。』一人曰：『吾蛇先成。』舉酒而起，曰：『吾能為之足。』及其為之足，而後成人奪之酒而飲之，曰：『蛇固無足，今為之足，是非蛇也。』今君相楚而攻魏，破軍殺將，功莫大焉，冠之上不可以加矣。今又移兵而攻齊，攻齊勝之，官爵不加於此；攻之不勝，身死爵奪，有毀於楚：此為蛇為足之說也。不若引兵而去以德齊，此持滿之術也。」昭陽曰：「善。」引兵而去。

**本卷说明：** 始称柱国、说辞称已令尹，依文内层次保存；分酒画蛇为譬喻，不另作本年实事。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../拆分史书/史记/卷005.md#kao-c691f26620)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0323-qin-note"></a>
<a id="卷015秦栏前323年"></a>
#### 卷015·秦栏｜前323年

[本年原格](../../拆分史书/史记/卷015.md#y0323)：“二。相張儀與齊、楚會齧桑。”

啮桑之会与原有张仪条合并；[《通鉴》卷二](../../拆分史书/资治通鉴/卷002.md#text)明确参与者是张仪和齐、楚之相，不把三位相臣改成三国君主亲会。 [对应正文](#event-1)

<a id="sj015-0323-han-note"></a>
<a id="卷015韩栏前323年"></a>
#### 卷015·韩栏｜前323年

[本年原格](../../拆分史书/史记/卷015.md#y0323)：“十。君為王。”

与燕栏称王同年，[《通鉴》卷二](../../拆分史书/资治通鉴/卷002.md#text)也如此编排；《秦本纪》十三年句又有韩称王的不同相接，故本页以年表及《通鉴》的前323年为主。此为名号变化，不是新君继位。

<a id="sj015-0323-chu-note"></a>
<a id="卷015楚栏前323年"></a>
#### 卷015·楚栏｜前323年

[本年原格](../../拆分史书/史记/卷015.md#y0323)：“六。敗魏襄陵。”

襄陵之战的胜败方向为楚胜魏败，与早年魏、齐争夺襄陵分年保存；本格没有记楚将、兵数或确定割地。

<a id="sj015-0323-yan-note"></a>
<a id="卷015燕栏前323年"></a>
#### 卷015·燕栏｜前323年

[本年原格](../../拆分史书/史记/卷015.md#y0323)：“十。君為王。”

燕易王称王并入[韩、燕称王](#sj015-0323-han-event)，不是燕王哙即位；哙的元年在前320。

<a id="sj015-0323-qi-note"></a>
<a id="卷015齐栏前323年"></a>
#### 卷015·齐栏｜前323年

[本年原格](../../拆分史书/史记/卷015.md#y0323)：“齊湣王地元年”

旧表自本年起列“湣王地元年”，与田齐王年错置相连，不照抄成前323年齐湣王已执政。沿项目先前齐威王年链及[《通鉴》卷三及校刊记](../../拆分史书/资治通鉴/卷003.md#text)校刊记：齐威王卒暂置前320，齐宣王卒暂置前301，湣王由此承位、次年前300为元年。本段原表的湣王数字仍原样保存，与修订后的君称分层，详[本段君次补核](../../拆分史书/史记/卷015.md#kao-7788704a82-8875da123)。

<a id="sj034-suqin-liaison"></a>

### 称王段后所附苏秦赴齐传闻不等于本年事

本篇把苏秦与燕文公夫人私通、惧诛而赴齐作间的传闻接在易王称王之后，却未为此事另注年数。这里完整保留人物关系与出使动机的传统讲法，不把它写成前323年已证实的宫廷事件。苏秦活动年代仍依现有两套研究方案留异。

## 本年纪事

<a id="event-1"></a>

1. **张仪与齐、楚大臣会于啮桑。** 秦相直接参加多国外交，战争并不是秦向东经营的唯一手段。 [原文与说明](#sj005-193-note)

<a id="sj015-0323-han-event"></a>

**韩国和燕国的君主先后采用王号。**周天子仍在，但越来越多诸侯已用“王”来表示与其他强国并列的地位。 [原文与说明](#sj015-0323-han-note)

<a id="sj015-0323-chu-event"></a>

**楚军在襄陵击败魏军，魏国在南面又承受一次军事压力。** [原文与说明](#sj015-0323-chu-note)

## 本年相关史料

<a id="sj005-193-note"></a>
### sj005-193｜张仪与齐、楚大臣会于啮桑。

[卷005 P062](../../sources/摘录/史记-卷005-秦本纪.md#p062)。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj015-0323-qin-note"></a>
### 卷015·秦栏｜前323年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0323)：“二。相張儀與齊、楚會齧桑。”

啮桑之会与原有张仪条合并；[《通鉴》卷二](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-421d51206a5ff7)明确参与者是张仪和齐、楚之相，不把三位相臣改成三国君主亲会。 [对应正文](#event-1)

<a id="sj015-0323-han-note"></a>
### 卷015·韩栏｜前323年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0323)：“十。君為王。”

与燕栏称王同年，[《通鉴》卷二](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-f1a39fa0835238)也如此编排；《秦本纪》十三年句又有韩称王的不同相接，故本页以年表及《通鉴》的前323年为主。此为名号变化，不是新君继位。

<a id="sj015-0323-chu-note"></a>
### 卷015·楚栏｜前323年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0323)：“六。敗魏襄陵。”

襄陵之战的胜败方向为楚胜魏败，与早年魏、齐争夺襄陵分年保存；本格没有记楚将、兵数或确定割地。

<a id="sj015-0323-yan-note"></a>
### 卷015·燕栏｜前323年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0323)：“十。君為王。”

燕易王称王并入[韩、燕称王](#sj015-0323-han-event)，不是燕王哙即位；哙的元年在前320。

<a id="sj015-0323-qi-note"></a>
### 卷015·齐栏｜前323年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0323)：“齊湣王地元年”

旧表自本年起列“湣王地元年”，与田齐王年错置相连，不照抄成前323年齐湣王已执政。沿项目先前齐威王年链及[《通鉴》卷三及校刊记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7003.md#ref-02cdffe9a36e37)校刊记：齐威王卒暂置前320，齐宣王卒暂置前301，湣王由此承位、次年前300为元年。本段原表的湣王数字仍原样保存，与修订后的君称分层，详[本段君次补核](../../meta/考证/史记-卷015-前0326至0287纪年补核.md#qi-wei)。

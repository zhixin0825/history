1. **秦惠文王更元，并由张仪攻取陕。** 称王以后，秦把新的王年重新从元年计起；原来惠文君十三年后的下一年成为更元元年。张仪取陕后，原文还记把当地人交给魏。 [[1]](#note-1)

<a id="sj015-pinga"></a>

2. **田婴参与促成齐、韩、魏在平阿南会盟，暂系本年。** 田婴先出使韩、魏，随后两国君主与齐君会面，订盟后离去。田婴此前已在齐国任职并参与对魏作战，此时承担列国之间的交涉。 [[2]](#note-2)

### 1. 秦惠文王更元，并由张仪攻取陕

[返回正文第1条](#event-1)

**[卷005 P062](../../sources/摘录/史记-卷005-秦本纪.md#p062)**

> 十四年，更為元年。二年，張儀與齊、楚大臣會齧桑。三年，韓、魏太子來朝。張儀相魏。五年，王游至北河。七年，樂池相秦。韓、趙、魏、燕、齊帥匈奴共攻秦。秦使庶長疾與戰修魚，虜其將申差，敗趙公子渴、韓太子奐，斬首八萬二千。八年，張儀復相秦。九年，司馬錯伐蜀，滅之。伐取趙中都、西陽十年，韓太子蒼來質。伐取韓石章。伐敗趙將泥。伐取義渠二十五城。十一年，摢裏疾攻魏焦，降之。敗韓岸門，斬首萬，其將犀首走。公子通封於蜀。燕君讓其臣子之。十二年，王與梁王會臨晉。庶長疾攻趙，虜趙將莊。張儀相楚。十三年，庶長章擊楚於丹陽，虜其將屈丐，斬首八萬；又攻楚漢中，取地六百里，置漢中郡。楚圍雍氏，秦使庶長疾助韓而東攻齊，到滿助魏攻燕。十四年，伐楚，取召陵。丹、犁臣，蜀相壯殺蜀侯來降。

## 归年与考证

<a id="sj005-192-note"></a>
<a id="sj005-192秦惠文王更元并由张仪攻取陕"></a>
#### sj005-192｜秦惠文王更元，并由张仪攻取陕。

[卷005 P062](../../sources/摘录/史记-卷005-秦本纪.md#p062)。

**说明：**本纪将取陕接在十三年末，年表列更元元年，暂从前324。以后“二年”等都按更元计算，不能把战国秦的年表整体错开十三年。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。


<a id="2平阿会盟从旧表前336年转按魏后元十一年暂系"></a>
#### 2｜平阿会盟：从旧表前336年转按魏后元十一年暂系

**来源：**[卷015前336年齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0336)；[《孟尝君列传》开篇及索隐](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7075.md#ref-ae595ff98dfe20)；[《魏世家·索隐》惠王三十六年改元说](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-8982288a8a3330)。

**归年与君称：**原表在旧齐宣王七年、前336年行记“与魏会平阿南”。《孟尝君列传》正文还记韩君与田婴参与，却把齐、韩君名写成齐宣王、韩昭侯；同篇《索隐》明确指出威、宣二王文字错杂，并说《纪年》系此于梁惠王后元十一年。按本项目暂取前334年后元元年，十一年为前324年。本页暂采这条古注的年次，不把旧齐宣王七年平移为已无争议的年代，也不沿用与新年次冲突的韩昭侯称谓。平阿／东阿异文保留，不把地名强换成一个未经核定的现代县城。年次取舍集中见[齐魏君次补核](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#齐魏君次)；下一次甄会另见[前322年](bce-0322.md#sj015-zhen)。 [回正文](#sj015-pinga)

#### 卷015·秦栏｜前324年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0324)：“相張儀將兵取陝。初更元年”

取陕、更元并入原有第一条；不重复造第二次改元。称王在前325，更元从前324起算。 [对应正文](#event-1)

<a id="sj015-0324-wei-note"></a>
<a id="卷015魏栏前324年"></a>
#### 卷015·魏栏｜前324年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0324)：“十一。衛嗣君元年。”

魏栏借记卫国，不是魏君改元。[《通鉴》卷二](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-7bd0a23c35068d)把卫平侯去世、嗣君承位置前325，年表以前324为嗣君元年，两者可按承位／逾年改元相接。嗣君降号为“君”的记事在《通鉴》前320年，不能只据称号把全部降号过程提前。

<a id="sj015-0324-zhao-note"></a>
<a id="卷015赵栏前324年"></a>
#### 卷015·赵栏｜前324年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0324)：“二。城鄗。”

城鄗是修筑鄗城的简记，不能直接译成从无人居住开始新建；不补未经核定的现代边界和工程规模。《赵世家》写武灵王三年城鄗，相当前323，与本表二年差一年；本页暂依原表行归前324，未在前323重复安排修城。

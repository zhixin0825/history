# 公元前325年｜秦惠文君称王，赵国进入武灵王元年

**周显王44年**

> 本页按古史年条与传统公元对照归档；明确有争议的日期见对应说明。月份、干支未直接换算为公历日期；不以已有一条材料表示本年所有历史都已收齐。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦惠文君称王。** 秦惠文君正式称王。周天子的王号并没有因此消失，但诸侯已不再仅用旧的侯伯等名号来表现地位。 [[1]](#note-1)

<a id="sj015-0325-zhao-event"></a>

<a id="event-2"></a>

2. **赵国进入武灵王元年。** 年轻的国君雍承接父亲肃侯的统治，魏军在这一年击败赵将赵护；战斗地点和兵数没有留下明确记录。 阳文君赵豹为相。赵篇称梁襄王与太子嗣、韩宣王与太子仓来信宫朝见。武灵王未亲政时，置博闻之师三人、左右司过三人；亲政后先问先王重臣肥义，增加其秩，对国内八十岁的三老每月致礼。 [[2]](#note-2)

<a id="sj015-0325-wei-accession"></a>

<a id="event-3"></a>

3. **卫平侯去世，儿子继位，即卫嗣君。** [[3]](#note-3)

## 归年与考证

<a id="sj004-325-1"></a>
<a id="1-秦惠文君称王"></a>
#### 1. 秦惠文君称王

[卷004 P068](../../sources/摘录/史记-卷004-周本纪.md#p068)。 显王四十四年。本纪后句“其后诸侯皆为王”是总括诸侯相继称王的趋势，不表示魏、齐、楚等都在秦以后同一天第一次称王。

<a id="补充史料与异说"></a>
### 补充史料与异说

<a id="sj005-191-note"></a>
<a id="sj005-191同一事件的补充与取舍"></a>
#### sj005-191｜同一事件的补充与取舍

[卷005 P061](../../sources/摘录/史记-卷005-秦本纪.md#p061)。

**说明：**工作TXT作“魏君为王”，同书六国年表秦栏明确“君为王”，结合前后秦君王号处理，正文仍记秦惠文君称王；原字不静默改写。韩亦称王同句保留，不倒推韩所有文献中的早期王号。

<a id="sj015-0325-qin-note"></a>
<a id="卷015秦栏前325年"></a>
#### 卷015·秦栏｜前325年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0325)：“十三。四月戊午，君為王。”

与原页秦称王合并；四月戊午为古历原记，不直接换算为公历月日。[《通鉴》卷二](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-34d5c7af9073dd)亦载本年夏四月称王。下一年“初更元年”另在前324年，不把称王与改元挤作同日。 [对应正文](#event-1)

<a id="sj015-0325-han-note"></a>
<a id="卷015韩栏前325年"></a>
#### 卷015·韩栏｜前325年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0325)：“八。魏敗我韓舉。”

韩举之败按原表保留在本年；但前327年《赵世家》已记韩举战死桑丘，《韩世家·索隐》又引《纪年》称其赵将。姓名、国属和死／败尚有冲突，不能把死者再写成两年后领军，故不另立已定战事，参见[前327年异说](bce-0327.md#sj015-0327-hanju)；[《韩世家》及索隐](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7045.md#ref-436dc9c37ddf2e)。

<a id="sj015-0325-zhao-note"></a>
<a id="卷015赵栏前325年"></a>
#### 卷015·赵栏｜前325年

[本年原格](../../sources/摘录/史记-卷015-六国年表.md#y0325)：“趙武靈王元年。魏敗我趙護。”

武灵王元年与实际继位分开：[《通鉴》卷二](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-c36733f292f597)系肃侯卒、武灵王雍继位于前326年。本年仅是元年；魏败赵护依此格补入，不能把赵护、韩举直接合成同一人或同一场战役。

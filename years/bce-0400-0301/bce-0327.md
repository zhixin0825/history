# 公元前327年｜义渠君向秦称臣，秦归还魏国焦与曲沃

[← 上一张已编年页：公元前328年](bce-0328.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前326年 →](bce-0326.md)

**周显王四十二年；秦惠文君十一年；魏惠王后元八年；赵肃侯二十三年**

## 本年纪事

<a id="event-1"></a>
**秦在义渠置县，义渠君向秦称臣。** 前几年秦已出兵干预义渠内乱，此时又用县的形式加强控制，义渠君仍然存在。[1](#sj005-189-note)

<a id="event-2"></a>
**秦把焦、曲沃归还魏国。** 两国此前争夺过的城邑再度交割，魏收回这两处地方。[2](#note-2)

<a id="event-3"></a>
**秦把少梁改名夏阳。** 与义渠的设县、对魏的还地不同，这是一项已有城邑的更名。[3](#note-3)

## 本年相关史料

<a id="sj005-189-note"></a>
### 1｜县义渠与义渠君称臣

[卷005 P061](../../sources/摘录/史记-卷005-秦本纪.md#p061)惠文君十一年同段记“县义渠”“义渠君为臣”；[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0327)也记称臣。两种记载并存，不能仅凭置县二字宣布义渠君系已全灭；后来仍有继续征讨。此前秦庶长操出兵见[前331年](bce-0331.md#event-2)，本次原文没有说明县的具体范围和全部官吏设置。

<a id="note-2"></a>
### 2｜归魏焦、曲沃

[卷005 P061](../../sources/摘录/史记-卷005-秦本纪.md#p061)、[卷015本年秦、魏两栏](../../sources/摘录/史记-卷015-六国年表.md#y0327)、[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-63f793dc315e27)互见，合为一次交还，不按两国立场重复计事。前330年围焦、曲沃与前329年焦投降另在各年，本条未载归还条件，不补写赔款、人口迁移或永不再战的约定。

<a id="note-3"></a>
### 3｜少梁更名夏阳

[卷005 P061](../../sources/摘录/史记-卷005-秦本纪.md#p061)惠文君十一年：“更名少梁曰夏阳。”《张仪列传》把更名接在前一年的上郡交割之后，正文从秦本纪的明确年次；与[前328年第一注](bce-0328.md#sj005-188-note)合读，不造两次更名。

<a id="sj015-0327-hanju"></a>
### 4｜韩举桑丘之战的互见：年次、身份与结局待考

[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-a525706b21c56a)肃侯二十三年有“韩举与齐、魏战，死于桑丘”；[《韩世家》及《索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7045.md#ref-e1e6400823b9b0)却在后面的宣惠王八年记魏败韩举，并引《纪年》称韩举为赵将，提出先在赵、后来入韩的解释。后条与前325年的表行相接，不能不辨年代便把前327年写死的人物在两年后再写作败将。

这组记载的年次、国属及战死或战败问题尚须合核。本页保存《赵世家》的前327年位置和旧叙内容，未把未经裁定的“先赵后韩”拼成确定履历，也未另立本年已定的韩举阵亡事件。参见[本批人物与短记考证](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#人物与短记)。

<a id="sj015-0327-she"></a>
### 5｜宋太丘社亡、鼎沉泗水的异年

[《汉书·郊祀志上》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%BC%A2%E6%9B%B8-%E5%8D%B7025%E4%B8%8A.md#ref-a267443ec5579b)以“或曰”引宋太丘社亡、鼎沉泗水的故事，系在周显王四十二年，即本年；《六国年表》却在前336年秦栏记太丘社亡。两者作为同一组传闻的异年互见，原记及性质说明见[前336年第四注](bce-0336.md#note-4)，不另造一次前327年的社亡或鼎沉。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

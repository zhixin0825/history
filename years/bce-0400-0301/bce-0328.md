# 公元前328年｜张仪出任秦相，魏交出上郡十五县

[← 上一张已编年页：公元前329年](bce-0329.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前327年 →](bce-0327.md)

**周显王四十一年；秦惠文君十年；魏惠王后元七年；赵肃侯二十二年；楚怀王元年**

## 本年纪事

<a id="event-1"></a>
**秦军攻取蒲阳，张仪出任秦相，魏交出上郡十五县。** 秦军围攻魏国蒲阳，使守军投降。张仪参与这次行动，随后建议秦把蒲阳还给魏，又让公子繇到魏国作人质。

张仪转而对魏惠王说，秦对魏如此优厚，魏也应有回报。魏于是向秦交出上郡，秦惠文君任张仪为相。这位来自魏国的游说之士由此成为秦国决策中更重要的人物。[1](#sj005-188-note)

<details>
<summary>张仪登场前事：在楚受辱与入秦（未确年）</summary>

<a id="sj015-zhangyi-backstory"></a>
张仪是魏国人，学过游说之术，曾游说诸侯。一次跟随楚相饮酒，楚相的璧丢失，门客因为张仪贫困，便怀疑他偷了璧，把他抓来鞭打数百下。张仪始终不承认，最终获释。

他的妻子感叹，如果不读书游说，怎会受这种侮辱。张仪请妻子看看自己的舌头还在不在；妻子笑说还在，张仪便说：“足够了。”在出任秦相以前，他已经进入秦国，得到秦惠文君任用为客卿，参与对外谋划。[1](#sj005-188-note)

</details>

<a id="event-2"></a>
**秦军击败赵军，赵疵战死，蔺和离石被秦夺取。** 赵国西部又受到秦军进攻。[2](#note-2)

<a id="event-3"></a>
**楚怀王熊槐进入元年。** 他在前一年父亲楚威王去世后接位，新一轮楚王纪年由本年开始。[3](#note-3)

## 本年相关史料

<a id="sj005-188-note"></a>
### 1｜蒲阳、上郡与张仪任相

[卷005 P061](../../sources/摘录/史记-卷005-秦本纪.md#p061)惠文君十年记“张仪相秦。魏纳上郡十五县”；[卷015本年秦、魏两栏](../../sources/摘录/史记-卷015-六国年表.md#y0328)合记张仪相秦、秦围蒲阳降之、魏纳上郡。[《张仪列传》及三家注](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7070.md#ref-2f5adf91137564)十年条补出张仪参战、归还蒲阳、送公子繇为质、游说魏君及拜相经过。本纪、年表同年各句的排列不直接当成月日先后，正文依列传中连贯的行动次序展开。

**将领姓名：**原表写“公子桑围蒲阳”，列传写“公子华与张仪”，《集解》又记华一作革。正文保留秦军与张仪这部分共同叙事，异名在此并存，不把桑、华、革拆成三位已经确认的参战将领。

**土地与更名：**十五县为《秦本纪》所记数。列传把少梁也接在本次交地之后，并叙改名夏阳；本纪、年表则在前330年已记纳少梁，在前327年记少梁更名。本批分从相应编年条，不再造一次前328年重新交割少梁或提前更名。

**人物前事：**本传开篇提供张仪籍贯、楚相失璧、受笞、与妻子的问答及客卿身份，前事仅说明这些叙述早于此次任相，不等于同在前328年。苏秦、张仪同学，以及苏秦激怒、暗中资助他入秦的故事，涉及出土材料所揭示的行年冲突，未无条件编入此前经历；任相后向楚相发檄的故事也不能倒作早年事。参见[本批孟子、苏秦考证](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#孟子苏秦)。

<a id="note-2"></a>
### 2｜赵疵败死与秦取蔺、离石

[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-f24d8d7f51f830)肃侯二十二年先记张仪相秦，接记赵疵与秦战败、被秦杀于河西，秦取蔺、离石。秦惠文君十年与赵肃侯二十二年相合，故补在本年。未据此断定攻赵的秦将也是张仪，也不把河西这一名称在所有国别语境中强作同一地块。

<a id="note-3"></a>
### 3｜楚怀王元年

[卷015楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0328)列“楚怀王槐元年”；[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7040.md#ref-f2333c42353229)怀王元年同记张仪始相秦，与秦年条相合。承位在[前329年](bce-0329.md#event-3)，元年在本年，两者不混同。

<a id="sj015-0328-song"></a>
### 4｜齐栏附记宋君偃元年：待考

[卷015本年齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0328)寄列“宋君偃元年”，说的是宋国，不能据此另立齐君。[《宋微子世家》及三家注](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7038.md#ref-55cb70114dbaf2)旧叙为剔成在位四十一年，弟偃攻袭他，剔成败奔齐，偃自立；偃十一年才称王。该篇又说偃共立四十七年，《集解》指出年表为四十三年，已经存在年数冲突。《通鉴》的旧编年把承位放前329年、次年为元年。

钱穆另提出前338年幼年嗣位、前328年称王的方案。[出版方所列《先秦诸子系年》目录](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-da053dfead168247.md#cite-2)第九一、九九篇明确列出这两项主张；本次仅据可核的目录确认该说存在，不冒称已经逐页核过全篇论证。古注所见宋君先后亦有剔成、易城盱等异文，不能只沿一格元年把所有材料凑齐。

因此，本格保留旧继位故事、原表位置和已有异说，暂不把前328年写成已确定的兄弟政变、首次承位或称王之年，也不直接覆写到前338年。详见[本批人物与短记考证](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#人物与短记)。

**归年：**按本条注明的本纪、年表取舍；秦君纪年规则另见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

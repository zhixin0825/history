# 公元前329年｜秦渡河攻魏，魏趁楚丧取陉山

[← 上一张已编年页：公元前330年](bce-0330.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前328年 →](bce-0328.md)

**周显王四十年；秦惠文君九年；魏惠王后元六年；楚威王十一年**

## 本年纪事

<a id="event-1"></a>
**秦军渡过黄河，夺取魏国的汾阴、皮氏，又使焦投降。** 秦军在河西得地以后，继续向黄河另一侧推进。[1](#sj005-187-note)

<a id="event-2"></a>
**秦惠文君与魏惠王在应相会。** 两国在战争之外仍有会面与交涉。[2](#note-2)

<a id="event-3"></a>
**楚威王去世，魏国趁楚办丧事出兵。** 楚威王熊商的儿子熊槐接位，即楚怀王。魏国得知楚王去世，发兵攻楚，在陉山打败楚军并取走该地。[3](#note-3)

## 本年相关史料

<a id="sj005-187-note"></a>
### 1｜秦取汾阴、皮氏，围焦而降

[卷005 P061](../../sources/摘录/史记-卷005-秦本纪.md#p061)惠文君九年、[卷015秦、魏两栏](../../sources/摘录/史记-卷015-六国年表.md#y0329)互见，合为一组战事。秦栏另记围焦降之，《魏世家》也记秦取焦，与[前330年的围城记录](bce-0330.md#event-2)相衔接。

<a id="note-2"></a>
### 2｜秦魏会应

[卷005 P061](../../sources/摘录/史记-卷005-秦本纪.md#p061)、[卷015秦、魏两栏](../../sources/摘录/史记-卷015-六国年表.md#y0329)、[《魏世家》](https://zh.wikisource.org/wiki/史記三家註/卷044)均见“会应”，不分作秦方、魏方两次会议。

秦此时尚未正式称王，正文仍称惠文君；魏仍是惠王，原表的旧襄王六年按惠王后元六年理解。原文没有会议条款，不能补写确定的割地协议或未载的结盟誓词。应的地望也不在本条强定。

<a id="note-3"></a>
### 3｜楚威王卒、魏取陉山

[卷015本年楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0329)记“十一。魏败我陉山”；[《楚世家》](https://zh.wikisource.org/wiki/史記三家註/卷040)威王十一年补明威王卒、怀王立，以及魏闻楚丧伐楚取陉山的先后。[《魏世家》](https://zh.wikisource.org/wiki/史記三家註/卷044)旧襄王六年也记魏伐楚、败之陉山。战争和楚国君位交接合在此年叙述，怀王元年则接[前328年](bce-0328.md#event-3)。

所读《通鉴》网页把魏闻楚丧、取陉山部分置于方括号校补中；本条直接以两世家互见为据，不把网页现代补文冒称司马光原文。

**归年：**按秦、楚本纪世家与年表相互核对；秦君纪年规则另见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

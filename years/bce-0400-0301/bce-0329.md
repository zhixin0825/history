# 公元前329年｜秦渡河攻魏，魏趁楚丧取陉山

[← 上一张已编年页：公元前330年](bce-0330.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前328年 →](bce-0328.md)

**周显王四十年；秦惠文君九年；魏惠王后元六年；楚威王十一年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦军渡过黄河，夺取魏国的汾阴、皮氏，又使焦投降。** 秦军在河西得地以后，继续向黄河另一侧推进。 [[1]](#note-1)

<a id="event-2"></a>

2. **秦惠文君与魏惠王在应相会。** 两国在战争之外仍有会面与交涉。 [[2]](#note-2)

<a id="event-3"></a>

3. **楚威王去世，魏国趁楚办丧事出兵。** 楚威王熊商的儿子熊槐接位，即楚怀王。魏国得知楚王去世，发兵攻楚，在陉山打败楚军并取走该地。 [[3]](#note-3)

### 1. 秦军渡过黄河，夺取魏国的汾阴、皮氏，又使焦投降

[返回正文第1条](#event-1)

**[卷005 P061](../../sources/摘录/史记-卷005-秦本纪.md#p061)**

> 五年，陰晉人犀首為大良造。六年，魏納陰晉，陰晉更名寧秦。七年，公子卬與魏戰，虜其將龍賈，斬首八萬。八年，魏納河西地。九年，渡河，取汾陰、皮氏。與魏王會應。圍焦，降之。十年，張儀相秦。魏納上郡十五縣。十一年，縣義渠。歸魏焦、曲沃。義渠君為臣。更名少梁曰夏陽。十二年，初臘。十三年四月戊午，魏君為王，韓亦為王。使張儀伐取陜，出其人與魏。

**[卷015秦、魏两栏](../../sources/摘录/史记-卷015-六国年表.md#y0329)**

> 九。度河，取汾陰、皮氏。圍焦，降之。與魏會應。

**[卷015秦、魏两栏](../../sources/摘录/史记-卷015-六国年表.md#y0329)**

> 六。與秦會應。秦取汾陰、皮氏。

## 归年与考证

<a id="sj005-187-note"></a>
<a id="1秦取汾阴皮氏围焦而降"></a>
#### 1｜秦取汾阴、皮氏，围焦而降

[卷005 P061](../../sources/摘录/史记-卷005-秦本纪.md#p061)惠文君九年、[卷015秦、魏两栏](../../sources/摘录/史记-卷015-六国年表.md#y0329)互见，合为一组战事。秦栏另记围焦降之，《魏世家》也记秦取焦，与[前330年的围城记录](bce-0330.md#event-2)相衔接。


<a id="2秦魏会应"></a>
#### 2｜秦魏会应

[卷005 P061](../../sources/摘录/史记-卷005-秦本纪.md#p061)、[卷015秦、魏两栏](../../sources/摘录/史记-卷015-六国年表.md#y0329)、[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-1abb8d3776d8f2)均见“会应”，不分作秦方、魏方两次会议。

秦此时尚未正式称王，正文仍称惠文君；魏仍是惠王，原表的旧襄王六年按惠王后元六年理解。原文没有会议条款，不能补写确定的割地协议或未载的结盟誓词。应的地望也不在本条强定。


<a id="3楚威王卒魏取陉山"></a>
#### 3｜楚威王卒、魏取陉山

[卷015本年楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0329)记“十一。魏败我陉山”；[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7040.md#ref-33c3b188afbaa5)威王十一年补明威王卒、怀王立，以及魏闻楚丧伐楚取陉山的先后。[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-3836d949944aef)旧襄王六年也记魏伐楚、败之陉山。战争和楚国君位交接合在此年叙述，怀王元年则接[前328年](bce-0328.md#event-3)。

所读《通鉴》网页把魏闻楚丧、取陉山部分置于方括号校补中；本条直接以两世家互见为据，不把网页现代补文冒称司马光原文。

**归年：**按秦、楚本纪世家与年表相互核对；秦君纪年规则另见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

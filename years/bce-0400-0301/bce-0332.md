# 公元前332年｜魏以阴晋与秦讲和，赵决河水退齐魏军

**周显王三十七年；秦惠文君六年；赵肃侯十八年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **魏把阴晋交给秦，以此讲和；秦将阴晋改名宁秦。** 土地交割之后，秦用新名称标示这座城邑的归属变化。 [[1]](#note-1)

<a id="event-2"></a>

2. **齐、魏联合攻赵，赵国决开河水灌向来军。** 两国军队在水攻之后撤去。 [[2]](#note-2)

<a id="event-3"></a>

3. **韩、燕、卫的新君分别进入元年。** 韩国是后来称宣惠王的新君，燕国是后来称易王的新君，卫国是平侯；他们的承位接在前一年父亲去世之后。 [[3]](#note-3)

## 归年与考证

<a id="sj005-184-note"></a>
<a id="1魏纳阴晋秦更名宁秦"></a>
#### 1｜魏纳阴晋，秦更名宁秦

[卷005 P061](../../sources/摘录/史记-卷005-秦本纪.md#p061)惠文君六年记魏纳阴晋、更名宁秦；[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0332)补明“以阴晋为和”。更名不等于居民当年全部被迁走，原文没有这项人口信息。


<a id="2齐魏伐赵与赵国决河"></a>
#### 2｜齐魏伐赵与赵国决河

[卷015本年魏、赵、齐三栏](../../sources/摘录/史记-卷015-六国年表.md#y0332)分记魏伐赵、赵决河水、齐与魏伐赵，合为同一战事。[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-e6a0c888313a42)肃侯十八年及[《田齐世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7046.md#ref-d4dc083d1b7669)补出两国退兵。

《资治通鉴》所承旧叙把犀首、苏秦及六国合纵的破裂串入此战；这部分涉及苏秦行年的严重分歧，本条仅采用年表及两世家共同支持的齐魏攻赵、赵国水攻和退兵，不将未经重核的游说过程附会到前332年。参见[本批孟子、苏秦考证](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#孟子苏秦)。


<a id="3韩燕卫元年与王号"></a>
#### 3｜韩、燕、卫元年与王号

[卷015本年](../../sources/摘录/史记-卷015-六国年表.md#y0332)韩栏列“韩宣惠王元年”，燕栏列“燕易王元年”，魏栏寄列“卫平侯元年”。三项均接[前333年君位交接](bce-0333.md#event-3)，其中燕、卫交接的来源见该页[第四注](bce-0333.md#note-4)。

韩宣惠王、燕易王是后来的称谓。年表把韩、燕君正式称王另列在前323年；但[《秦本纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7005.md#ref-b7839ec629286d)惠文君十三年（前325）又写“韩亦为王”，《韩世家》则记宣惠王十一年，若从本年元年计算为前322年。韩君年次及《索隐》所引威侯名谥均须进一步辨明，不能隐去差异，宣布称王年份已唯一确定，更不能把本年“元年”改写成两国当年举行称王仪式。卫平侯属于卫国，并非魏国换君。

<a id="4燕初立时失十城的互见"></a>
#### 4｜燕初立时失十城的互见

[《燕世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7034.md#ref-fea4b4738f4698)还叙燕易王初立，齐国趁燕丧攻取十城，后由苏秦游说齐国归还；所读《通鉴》把这组叙事放在本年。它与苏秦旧行年密切相连，齐王称谓也有威、宣之误，本批未将十城的攻取、归还分别硬定为前332年新事件，相关旧记留此待核。

**归年：**按各条所据的秦、赵年次及新君元年对照；秦纪规则另见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj034-return-ten-cities"></a>

### 齐取燕十城及苏秦说还：沿旧故事留异

这段叙述燕国遭丧后受齐攻取十城，苏秦又游说齐国归还；“齐宣王”与现行齐威王、宣王年链冲突，苏秦行年也未统一。故保留故事和本篇旧系年，不在本年再增已确证的夺城、还城两条事实。

**[《史记·燕召公世家》P020](../../sources/摘录/史记-卷034-燕召公世家.md#p020)**

> 易王初立，齊宣王因燕喪伐我，取十城；蘇秦說齊，使復歸燕十城。

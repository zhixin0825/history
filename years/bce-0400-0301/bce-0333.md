# 公元前333年｜公孙衍任秦大良造，楚军在徐州打败齐军

[← 上一张已编年页：公元前334年](bce-0334.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前332年 →](bce-0332.md)

**周显王三十六年；秦惠文君五年；赵肃侯十七年；楚威王七年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **阴晋人公孙衍在秦国出任大良造。** 他又被称作犀首，来自魏国。秦国继续任用东方来人，使他们进入军政高层。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚军围攻齐国徐州取胜，田婴借张丑游说保住职位。** 田婴是孟尝君之父，因欺楚引发楚威王讨伐，楚胜后要求齐逐田婴。张丑却说齐败是田婴不用有功得民的田盼，改用不得大臣百姓拥护的申纪；若逐田婴，田盼复掌兵，齐军反更难对付。楚王接受，不再坚持逐婴。 [[2]](#note-2)

<a id="event-3"></a>

3. **韩国高门建成，昭侯去世。** 昭侯终究没有从新门出行。君位由他的儿子接续，即后来称韩宣惠王的新君。 [[3]](#note-3)

<a id="event-4"></a>

4. **燕文公、卫成侯相继去世，两国由后继者接位。** 燕文公的太子继位，后来谥为易王；卫成侯的儿子继位，后来谥为平侯。两国的新君元年都在次年。 [[4]](#note-4)

<a id="event-5"></a>

5. **赵国围攻魏国黄邑，没有攻下，又修筑长城。** 肃侯在位期间的边境攻守与防御工程继续进行。 [[5]](#note-5)

**[史记三家注](../../sources/史记三家注/卷045.md#p17)**

> 二十五年，旱，作高門。屈宜臼〔集解〕許慎曰：「屈宜臼，楚大夫，在魏也。」曰：「昭侯不出此門。何也？不時。吾所謂時者，非時日也，人固有利不利時。昭侯嘗利矣，不作高門。徃年秦拔宜陽，今年旱，昭侯不以此時卹民之急，而顧益奢，此謂『時絀舉嬴』。」〔集解〕徐廣曰：「時衰秏而作奢侈。」二十六年，高門成，昭侯卒，〔索隱〕按：紀年「鄭昭侯武薨，次威侯立。威侯七年，與邯鄲圍襄陵。五月，梁惠王會威侯于巫沙。十月，鄭宣王朝梁」，不見威侯之卒。下敗韓舉在威侯八年，而此系家即以爲宣惠王之年。又上有殺悼公，悼公又不知是誰之謚。則韓微小，國史失代系，故此文及系本不同，蓋亦不可復考。果不出此門。子宣惠王立。

## 归年与考证

<a id="sj005-183-note"></a>
<a id="1公孙衍任秦大良造"></a>
#### 1｜公孙衍任秦大良造

[卷005 P061](../../sources/摘录/史记-卷005-秦本纪.md#p061)、[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0333)均系惠文君五年。[《张仪列传》末附犀首传及《集解》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7070.md#ref-14724d026094cc)明说他是魏国阴晋人，姓公孙、名衍；司马彪解释犀首本是魏国官名。他后来在秦魏间的活动另随年叙述，不能把同场的公子卬等人物合为一人。


<a id="2楚齐徐州之战及张丑说辞"></a>
#### 2｜楚齐徐州之战及张丑说辞

[卷015本年楚、齐两栏](../../sources/摘录/史记-卷015-六国年表.md#y0333)互见“围齐于徐州”“楚围我徐州”，合为一战。[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7040.md#ref-201100463334b1)楚威王七年补出齐军战败、楚欲逐田婴和张丑的说辞；[《孟尝君列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7075.md#ref-83f4cd589f835e)也叙田婴遣张丑说楚。

原表齐国的王年仍属旧君次，正文不沿它把齐威王换成齐宣王。张丑关于田盼、申纪的评价是游说内容，不当作对两将能力的独立调查；徐州也不径直等同今天江苏省的徐州市。


<a id="3韩昭侯卒"></a>
#### 3｜韩昭侯卒

[卷015韩栏](../../sources/摘录/史记-卷015-六国年表.md#y0333)、[《韩世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7045.md#ref-8990dba2ae0d3a)都把高门建成、昭侯卒接在前一年旱灾营门之后；与[前334年屈宜臼劝诫](bce-0334.md#event-4)合读。

《韩世家》旧叙为昭侯二十六年、子宣惠王立；《索隐》又引《纪年》“郑昭侯武薨，次威侯立”，并指出韩君世系与名谥的缺失。正文沿现有年条保存这次君位交接，不据一项旧在位总数机械重排此前各年。后继君在前332年开始元年；韩君称王另有《秦本纪》前325年、《六国年表》前323年及《韩世家》宣惠王十一年等不齐的记载，详见[前332年第三注](bce-0332.md#note-3)。不能由“宣惠王立”的追称，把称王提前到承位当年。


<a id="4燕卫君位交接"></a>
#### 4｜燕、卫君位交接

[《燕世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7034.md#ref-894e9fd47cd06f)记文公二十九年卒、太子立为易王；[《卫世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7037.md#ref-5954e37a6f73db)记成侯二十九年卒、子平侯立。[卷015次年](../../sources/摘录/史记-卷015-六国年表.md#y0332)分别列燕易王、卫平侯元年，与本年承位相衔接。燕君称王同样是后事，《燕世家·索隐》明确说明“易王”系追书谥号。


<a id="5赵攻魏黄筑长城"></a>
#### 5｜赵攻魏黄、筑长城

[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-c21735834464a3)肃侯十七年：“围魏黄，不克。筑长城。”正文按此记攻城未成与筑城两事，未补长城的长度、走向，也不据两句相邻认定整个工程都环绕黄邑。

<a id="sj015-0333-diaoyin"></a>
<a id="6魏栏雕阴之败的异年"></a>
#### 6｜魏栏雕阴之败的异年

[卷015本年魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0333)作“二。秦败我彫阴”。但《秦本纪》把俘魏将龙贾的大战系在秦惠文君七年，即[前331年](bce-0331.md#event-1)；《魏世家》又在旧襄王五年、即前330年，记秦败龙贾军于雕阴。人名、地名和年次须合核，不能凭三个不同位置就造出三次龙贾败军。

本批沿已有秦本纪的前331年主述，原表前333年这一格作为异年出处保留，详见[前331年同号说明](bce-0331.md#sj005-185-note)、[本批秦魏战事考证](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#秦周与秦魏)。

**归年：**各条分别依秦、楚、赵年次与君位接续互校；秦君纪年规则另见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

# 公元前334年｜齐魏会徐州相王，周王向秦送祭胙

[← 上一张已编年页：公元前335年](bce-0335.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前333年 →](bce-0333.md)

**周显王三十五年；秦惠文君四年；魏惠王后元元年；赵肃侯十六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **周王向秦惠文君致送文、武祭胙。** 周王把祭祀周文王、周武王的祭肉送给秦惠文君，延续王室与秦国的礼仪往来。 [[1]](#note-1)

<a id="event-2"></a>

2. **齐威王与魏惠王在徐州相会，彼此承认王号。** 王号成为诸侯争取地位的重要手段。魏惠王重新从一年计起，这一年由此又称后元元年。 [[2]](#note-2)

<a id="event-3"></a>

3. **一位来自魏国的夫人到达秦国。** 秦国年条把她记作“魏夫人”，没有留下她的名字。 [[3]](#note-3)

<a id="event-4"></a>

4. **韩国旱灾之中，昭侯仍营建高大的宫门。** 屈宜臼批评这项工程：前一年宜阳刚被秦军攻破，现在又遇旱灾，国君应当先体恤百姓的急难，却反而增加奢侈。他说昭侯“走不出这道门”，所责怪的是国家困乏时大兴土木。 [[4]](#note-4)

<a id="event-5"></a>

5. **大戊午拦住赵肃侯，劝他顾惜农时。** 肃侯到大陵游览，从鹿门出行。大戊午上前扣马，提醒他正是农忙时节，一天耽误耕作，就可能影响日后的许多口粮。肃侯下车向他道歉。 [[5]](#note-5)

## 归年与考证

<a id="sj004-334-1"></a>
<a id="1周王致送文武祭胙"></a>
#### 1｜周王致送文武祭胙

[卷004 P068](../../sources/摘录/史记-卷004-周本纪.md#p068)系显王三十五年；[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0334)系秦惠文君四年。本纪追称惠王，秦的称王动作另见前325年。这是新君受赠的新一条记录，并非前360年秦孝公受胙的重复。

<a id="sj005-181-note"></a>
[卷005 P060](../../sources/摘录/史记-卷005-秦本纪.md#p060)“天子致文武胙”与卷004合为同事。本纪同年又记齐、魏为王，不能据此把秦王号一并提前。

<a id="sj005-182-note"></a>
<a id="2徐州相王与魏惠王后元"></a>
#### 2｜徐州相王与魏惠王后元

[卷005 P060](../../sources/摘录/史记-卷005-秦本纪.md#p060)记“齐、魏为王”；[卷015魏、齐两栏](../../sources/摘录/史记-卷015-六国年表.md#y0334)互记徐州相王。原表的“魏襄王元年”、齐宣王九年属于旧君次，正文改以仍在位的魏惠王、齐威王为主语。

[《魏世家·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-c6935a2dedd7dc)引《纪年》：“惠成王三十六年改元称一年，未卒也。”按已采用的前369年元年，第三十六年就是前334年；本年重新计作后元一年，而不是国君已卒、儿子襄王改元。魏较早使用王号与本次相互承认王号仍须分别理解，不把所有“王”字都算成一次新称王。详见[本批齐魏君次考证](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#齐魏君次)。


<a id="3魏夫人来秦"></a>
#### 3｜魏夫人来秦

[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0334)原文“魏夫人来”。它提供了夫人的来处和来到秦国的信息，未明言她的本名、父母、所生子女或婚仪经过，正文不借后世宫廷人物的身份补全这些空缺。


<a id="4旱灾与高门"></a>
#### 4｜旱灾与高门

[卷015韩栏](../../sources/摘录/史记-卷015-六国年表.md#y0334)、[《韩世家》及三家注](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7045.md#ref-8e466547ec9c79)昭侯二十五年互见。屈宜臼自释所谓“不时”不是择日吉凶，而是国家处境不利时反而奢侈，古语为“时诎举赢”。因此这段保留为政治劝诫，不把昭侯次年去世解释成已验证的预言。

《集解》引许慎称屈宜臼为在魏的楚大夫；史料没有交代本次进言的具体地点，不能另编他在韩国任职或当面入宫谏君的经历。高门建成、昭侯去世接见[前333年](bce-0333.md#event-3)。


<a id="5大戊午谏游"></a>
#### 5｜大戊午谏游

[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-a4710277dd2c6b)肃侯十六年。原话“一日不作，百日不食”是强调农时不可耽误的劝谏，不据此计算亩产或精确的粮食供应日数。

<a id="sj015-0334-suqin"></a>
<a id="6苏秦说燕原表年次待考"></a>
#### 6｜苏秦说燕：原表年次待考

[卷015燕栏](../../sources/摘录/史记-卷015-六国年表.md#y0334)记文公二十八年“苏秦说燕”。[《燕世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7034.md#ref-ceeb24a7c2ff5c)及《苏秦列传》的旧叙事，核心是劝燕、赵相互保护，使秦难以越过赵国进攻燕国，继而叙及苏秦受资助游说诸侯。

出土《战国纵横家书》使苏秦活动年代、与张仪的先后关系成为重要重审问题；[潘定武《苏秦行年试说》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-10ec5659fff42c4b.md#cite-2)仍主张较早的行年方案，不能误称此文赞成把苏秦全部后移。相对的晚期方案，可见蔡运章、蔡奉哲《战国纵横家书全注全译》的[出版社书介](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-7ae9f1efe1c3c719.md#cite-2)，采用苏秦晚于张仪、为燕昭王活动的解释；书介能证明该书取说，不能代替尚未逐篇核读的帛书和附录论证。

本格保留传世说辞内容与原系年，暂不写成前334年已经完成六国合纵。旧、新年次依据详见[本批孟子、苏秦考证](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#孟子苏秦)。

**归年：**按各条注明的本纪、年表与考证取舍；秦君纪年规则另见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj034-suqin-early-chain"></a>

### 苏秦、秦燕婚姻的旧系年与未定年背景

本篇把文公二十八年的资助苏秦、赴赵、合纵接在这里，随后记秦燕婚姻。正文暂不新增确定的“前334年苏秦合六国”事件；现有早期与晚期行年讨论继续保留。文公给车马金帛、苏秦为从长以及秦王嫁女燕太子的故事完整保存，婚姻的精确年份也未独立坐实。齐威王卒年不在本年、也不能按文公十九年直接挪到前343年；现有采用年前320年另见本卷考证。

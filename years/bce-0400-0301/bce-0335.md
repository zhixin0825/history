# 公元前335年｜秦惠文君行冠礼，秦军攻破韩邑宜阳

[← 上一张已编年页：公元前336年](bce-0336.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前334年 →](bce-0334.md)

**周显王三十四年；秦惠文君三年；赵肃侯十五年**

## 本年纪事

<a id="event-1"></a>
**秦惠文君举行冠礼。** 秦君完成了这项标志成年的礼仪。[1](#sj005-180-note)

<a id="event-2"></a>
**秦军攻破韩国的宜阳。** 韩国失去这一城邑，随后一年又遇到旱灾。[2](#note-2)

<a id="event-3"></a>
**赵肃侯开始修筑寿陵。** 陵墓工程在肃侯还在位时动工。[3](#note-3)

## 本年相关史料

<a id="sj005-180-note"></a>
### 1｜秦惠文君举行冠礼

[卷005 P060](../../sources/摘录/史记-卷005-秦本纪.md#p060)、[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0335)均系惠文君三年，原文为“王冠”。这是后来的王号追称，正式称王在前325年，不能因此提前十年。

<a id="note-2"></a>
### 2｜秦拔韩宜阳

[卷015本年秦、韩两栏](../../sources/摘录/史记-卷015-六国年表.md#y0335)分别记“拔韩宜阳”“秦拔我宜阳”，合为一事。[《韩世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7045.md#ref-35db44a66369cd)昭侯二十四年同记，次年旱灾与营高门接见[前334年](bce-0334.md#event-4)。本条不与前307年甘茂攻宜阳混成同一次战役；原文也未交代本次失城后的全部归属变化。[梁玉绳《史记志疑》卷十](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%AE%B0%E5%BF%97%E7%96%91-%E5%8D%B7%E4%B9%9D-%E8%AF%86%E5%85%B8%E9%A2%98%E5%8D%B7%E5%8D%81%EF%BC%88%E5%8E%9F%E7%AB%99%E5%BC%95%E6%96%87%EF%BC%89.md#ref-b09c59c2320c5c)曾因后世取宜阳的记载而疑“拔”当作“攻”；本页暂按秦、韩两格同记“拔”译为攻破，保留这一校字异说，不由短句推定连续占领到前307年。

韩昭侯前段年数与元年仍有不合，见[前批韩君考证](../../meta/考证/史记-卷015-前0366至0347纪年补核.md#韩君)。本次秦韩两栏及秦君年次可以互校，不将整条随韩旧元年机械移动。

<a id="note-3"></a>
### 3｜赵起寿陵

[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-eabea3c0fb2a83)肃侯十五年记“起寿陵”。肃侯元年前349年，十五年对应本年。同条所附“魏惠王卒”属于魏世系、后元混乱，未采用，不能连带据此宣称魏惠王已经去世。

<a id="sj015-0335-zhen"></a>
### 4｜齐魏会甄的异年去向

[卷015齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0335)记“八。与魏会于甄”；《魏世家》把这次会面系在惠王三十六年，并误接惠王卒。[《孟尝君列传·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7075.md#ref-e1a7bcdc907b83)引《纪年》却作惠王后元十三年“会齐威王于鄄”，与前条平阿会同在后元；“甄”“鄄”为所读文本的用字差异。

按前334年后元元年计算，后元十三年为前322年。这项有较强年次依据的异说使旧表前335年的归年不能直接成立；原位置留在本注，会面主述转见[前322年：齐魏会甄](bce-0322.md#sj015-zhen)，并注明列传“明年”与后元十一、十三年之间的差异。参见[前336年平阿会说明](bce-0336.md#sj015-0336-pinga)、[本批齐魏君次考证](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#齐魏君次)。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

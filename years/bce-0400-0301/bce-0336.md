# 公元前336年｜周王祝贺秦君，秦开始“行钱”

[← 公元前337年](bce-0337.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前335年 →](bce-0335.md)

**周显王三十三年；秦惠文君二年；赵肃侯十四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **周王派人祝贺秦惠文君。** 秦国更换国君以后，与周王室的礼仪往来继续。 [[1]](#note-1)

<a id="event-2"></a>

2. **秦开始推行一项记作“行钱”的货币措施。** 货币的行用由此成为秦国这一年的制度记事。 [[2]](#note-2)

<a id="传闻与异象"></a>

<a id="event-3"></a>

3. **有婴儿说“秦且王”的传闻。** 一个新生婴儿被传说开口说秦将称王。这是附有征兆意味的故事；此时秦君仍未正式称王。 [[3]](#note-3)

<a id="sj015-0336-she"></a>

<a id="event-4"></a>

4. **宋国太丘传出“社亡”的异闻。** 祭祀土地神的社主被说成失去了踪迹，后来又有把它同鼎沉泗水联系起来的说法。 [[4]](#note-4)

<a id="sj044-pingan-event"></a>

5. **魏、齐两国在平阿南会面。** 两国经过战争仍继续交涉。本篇把齐君写作宣王，依现行田齐年链此时应在威王时期，正文以齐王称之，保留名号差异。 [[5]](#sj044-pingan-note)

## 归年与考证

<a id="sj004-336-1"></a>
<a id="1周王祝贺"></a>
#### 1｜周王祝贺

[卷004 P068](../../sources/摘录/史记-卷004-周本纪.md#p068)系显王三十三年；[卷015本年周、秦两栏](../../sources/摘录/史记-卷015-六国年表.md#y0336)互见“贺秦”“天子贺”，合为一事。卷004追称“秦惠王”，正文用当时尚未正式称王的惠文君，不将称王提前。

<a id="sj005-179-note"></a>
[卷005 P060](../../sources/摘录/史记-卷005-秦本纪.md#p060)“惠文君二年天子贺”，与卷004同事，原锚点继续保留。

<a id="sj006-074-note"></a>
<a id="2行钱与婴儿传言"></a>
#### 2｜行钱与婴儿传言

[卷006 P074](../../sources/摘录/史记-卷006-秦始皇本纪.md#p074)：“立二年，初行錢。有新生嬰兒曰『秦且王』。”[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0336)也有“行钱”。沿惠文君元年前337年，对应本年。

“初”在秦国及其制度的记载语境中理解，不能扩大成整个中国首次使用货币。原文没有币形、币重、铸量或实施地区清单；婴儿说话也不作为可证实的预言。卷006所附十九岁即位属年龄口径，未据它推算确切生日。


<a id="sj015-0336-pinga"></a>
<a id="3齐魏平阿会原表归年与纪年异说"></a>
#### 3｜齐魏平阿会：原表归年与《纪年》异说

原表齐栏作“七。与魏会平阿南”。[《魏世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-1ab91ee5c1d39b)系惠王三十五年；[《孟尝君列传》及《索隐》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7075.md#ref-9bb2e641329fd5)另叙田婴出使韩、魏，与韩昭侯、魏惠王会齐王于“东阿南”，盟后离去。《索隐》却明确引《纪年》，说这次相会当在魏惠王**后元十一年**，地名作“平阿”，并指出齐威王、齐宣王称谓舛互。

按本项目暂取的前334年后元元年，后元十一年对应前324年，不能把原表前336年这一格直接化为已经考定的会盟日期；韩君称谓及平阿、东阿地名也须随同校核。原记在此保留，主述转见[前324年：平阿相会](bce-0324.md#sj015-pinga)，未另造一次前336年的齐魏会盟。参见[本批齐魏君次考证](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#齐魏君次)。


<a id="4宋太丘社亡"></a>
#### 4｜宋太丘“社亡”

[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0336)寄列“宋太丘社亡”，说的是宋国，不能写成秦国社坛的事件。[《封禅书》及《索隐》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7028.md#ref-7f0129c980ab25)保存“或曰”太丘社亡、鼎没于泗水彭城下的异闻；应劭释“亡”为陷入地下，《索隐》则释为“社主亡”。正文采用后一解释介绍传闻，不据此断言整个太丘陷没，也不把鼎沉泗水的传说定为本年已证之事。

[《汉书·郊祀志上》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E6%BC%A2%E6%9B%B8-%E5%8D%B7025%E4%B8%8A.md#ref-05a0af6edb7cd7)另把这组传闻系于周显王四十二年，即前327年，与年表显王三十三年相差九年。因此前336年只是按原表保存异闻的位置，日期仍有分歧；[前327年](bce-0327.md#sj015-0327-she)保留异年回链，不再添一次社亡或鼎沉。

<a id="sj015-0336-mengzi"></a>
<a id="sj015-mengzi-variant"></a>
<a id="5孟子问答的原表位置与后移"></a>
#### 5｜孟子问答的原表位置与后移

原表魏栏作“三十五。孟子来，王问利国，对曰：‘君不可言利。’”这一问答与梁惠王晚年的经历及魏国后元纪年有关，不能只沿旧魏王年放在前336年，也不宜改称孟子的早年补叙。主述和人物前事见[约前320年：孟子见梁惠王](bce-0320.md#sj015-mengzi)，归年分歧见[本批孟子、苏秦考证](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#孟子苏秦)。

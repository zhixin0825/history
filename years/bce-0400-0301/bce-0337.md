# 公元前337年｜四方来人朝秦，韩相申不害去世

**周显王三十二年；秦惠文君元年、赵肃侯十三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>
<a id="1楚韩赵和蜀的来人朝见秦新君"></a>

1. **楚、韩、赵和蜀的来人朝见秦新君。** 楚、韩、赵和蜀都有人来朝见秦的新君。惠文君开始自己的元年，秦继续同东方诸国以及西南的蜀地交往；蜀此时仍能遣人来秦。 [[1]](#note-1)

<a id="event-2"></a>
<a id="2韩相申不害去世"></a>

2. **韩相申不害去世。** 韩国的相申不害去世。他原是郑国地位较低的臣属，后来向韩昭侯进言，在[前351年](bce-0351.md#event-1)受任为相，主持国内政务并处理诸侯关系。传世记载总计他任相十五年，称其重整政教，使韩国的统治和军备有所改善。他的学说以黄老为根本，重视刑名，留下了称作《申子》的著作。 [[2]](#note-2)

<a id="申不害请仕与韩昭侯用人的未确年补叙"></a>
### 申不害请仕与韩昭侯用人的未确年补叙
<a id="sj015-shen-bushi"></a>
<a id="3为亲属求官时申不害也被自己的主张挡住"></a>

<a id="event-3"></a>

3. **为亲属求官时，申不害也被自己的主张挡住。** 申不害曾为一位同族兄长求官，韩昭侯没有答应，申不害露出不满。昭侯提醒他：自己向他学习，是为了治国；既然他教导任官要看功劳、按次序办理，现在又为私人的请求说情，究竟该听从他的办法，还是他的请托？申不害于是退避认错。 [[3]](#note-3)

   另一段故事说，昭侯有一条破旧的裤子，还叫人收好，近侍觉得不如赏给身边的人。昭侯回答，赏赐也要留给有功者，不能随手拿来取悦左右。两件小事都围绕同一个难题：君主能否在亲近者求情时，仍按自己认可的标准任官和赏赐。

## 归年与考证

<a id="sj005-178-note"></a>
<a id="1来秦者名单与惠文君元年"></a>
#### 1｜来秦者名单与惠文君元年

原有[卷005 P060](../../sources/摘录/史记-卷005-秦本纪.md#p060)记“惠文君元年，楚、韩、赵、蜀人来朝”；[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0337)作“秦惠文王元年。楚、韩、赵、蜀人来”。同一组来朝合叙，不因“人来”较简再补第二次使团。

原文没有说这些国君全部亲自抵秦，也未说明来人的人数和贡品，正文用各国来人，不写成四国君主同日会盟。蜀尚未被秦吞并，来朝不自动等于已成为秦的郡县。本年是孝公去世后新君的元年，称“惠文君”；年表的“惠文王”不意味着本年已完成称王。秦君年链原有依据见[卷005纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。


<a id="2申不害卒年不随韩国旧君年整段平移"></a>
#### 2｜申不害卒年不随韩国旧君年整段平移

卷015韩栏旧昭侯二十二年记“申不害卒”；[《韩世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7045.md#ref-723f0e223ae5e6)同作二十二年死，[《通鉴》显王三十二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-e15daaabbf2cc9)也将其卒置于本年。韩昭侯元年的链条已有未决差别，本页保留这条周王年定位与原表出处，不因调整旧昭侯元年，便将任相与死亡机械一起前移若干年。

[《老子韩非列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7063.md#ref-eb87bffddc28fb)记申不害京人、故郑之贱臣，任相“内修政教，外应诸侯，十五年”，学本黄老而主刑名，“著书二篇，号曰申子”。从本项目暂行的前351年任相到前337年卒，首尾为十五个纪年，与这个任期总数相容；不能据此精确算出任命月日或断定实足十五周年。京的具体地望、出生年及著书时间本条未详，正文不另补。

列传及韩世家的“国治兵强”“诸侯不来侵伐”是总结性褒语，同期仍有韩遭攻而求齐救的马陵前事，不能将它扩写成任内每一年都无外患的已核统计。著作两篇是史家的著录，也不等于已确认今天任何同名辑本逐字保存了原书。详见[人物与短记](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#人物与短记)。


<a id="3请仕从兄与藏敝裤的未确年故事"></a>
#### 3｜请仕从兄与藏敝裤的未确年故事

上述两段见[《通鉴》卷二显王十八年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-8cd70677a441ab)任相条后的补叙：申子请仕“从兄”，昭侯称“修功劳，视次第”；随后又叙昭侯藏“弊袴”，说必待有功者。本页在申不害去世处集中回顾，**不宣称它们发生在前337年，也不把任相条后接叙的故事全定为前351年当年**。藏敝裤仅按同类用人话题附读，不能据此推断它发生在申不害生前。这些故事展现的是任官和赏罚的原则冲突，不足以据此复原韩国官制的全部等级或任官流程。

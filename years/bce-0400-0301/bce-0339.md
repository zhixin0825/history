1. **秦魏在岸门交战，魏将魏错被俘。** 秦与魏在岸门交战，秦军俘获魏将魏错。魏前不久已失去公子卬，这一次又有将领落入秦军手中。 [[1]](#note-1)

<a id="event-2"></a>
<a id="2魏惠王立公子赫为太子"></a>

2. **魏惠王立公子赫为太子。** 魏惠王把公子赫立为太子。此前的太子申已在[马陵之战](bce-0341.md#sj-065-L4646-02)被齐军俘获，这次任命重新确定了魏国的储君。 [[2]](#note-2)

<a id="event-3"></a>
<a id="3楚威王开始以自己的君年记事"></a>

3. **楚威王开始以自己的君年记事。** 楚威王熊商在[前一年](bce-0340.md#event-4)父王去世后承位，这一年开始他的元年。楚国进入新君执政的阶段。 [[3]](#note-3)

## 归年与考证

<a id="1岸门雁门与秦孝公二十三二十四年的差别"></a>
#### 1｜岸门、雁门与秦孝公二十三、二十四年的差别

[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0339)记“二十三。与晋战岸门”。[《秦本纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7005.md#ref-fdcb78d815fa04)则在孝公二十四年记“与晋战雁门，虏其将魏错”。《索隐》引《纪年》“与魏战岸门”，并指出“雁门”恐为音近而误，秦与韩魏之战不当无端远推到北方雁门。雷学淇[《竹书纪年义证》卷三十九](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E7%AB%B9%E4%B9%A6%E7%BA%AA%E5%B9%B4%E4%B9%89%E8%AF%81-%E5%8D%B7%E4%B8%89%E5%8D%81%E5%85%AB-%E8%AF%86%E5%85%B8%E9%A2%98%E5%8D%B7%E4%B8%89%E5%8D%81%E4%B9%9D%EF%BC%88%E5%8E%9F%E7%AB%99%E5%BC%95%E6%96%87%EF%BC%89.md#ref-deea285c104ec9)也把两条视为同一战役。

本批以年表秦孝公二十三年暂归前339年，较详本纪的俘魏错信息合入正文；[前338年旧页](bce-0338.md#event-1)保留原锚点、孝公二十四年的异年说明及回链。**一年差仍在，不能把同一处战事写成前339年岸门、前338年雁门的两场胜仗。**秦本纪泛称“晋”的对手，在《索隐》所引《纪年》中明作魏，正文从较明的国名。

[《古本竹书纪年辑校》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%A4%E6%9C%AC%E7%AB%B9%E6%9B%B8%E7%B4%80%E5%B9%B4%E8%BC%AF%E6%A0%A1.md#ref-f5065f791c1c06)此条作“〈三十二年，〉与秦战岸门”，编者明注该年据六国表补入，不是古《纪年》独立保存的确年。不能将补入的旧魏三十二年重新按前369年元年换算，便宣称已由另一古本证实前338年。雷氏提出的周正、夏正解释也只作为一种说法，不冒称已经历算解决。详见[秦周与秦魏](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#秦周与秦魏)。

岸门的地望有古注与后世考订的分歧，正文暂不标现代县名。魏错只以本条可见的魏将身份叙写；未见他的早期经历，不因“错”字便与司马错、因将军身份便与犀首等人合并。


<a id="2公子赫的立储与旧魏年数"></a>
#### 2｜公子赫的立储与旧魏年数

卷015魏栏旧惠王三十二年记“公子赫为太子”；[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-0450955c188816)却在旧三十一年攻魏、迁梁叙事末记“以公子赫为太子”，相差一年。正文暂从年表本行安放立储，不能把世家段中所有战争、迁都与任命当作同日发生。

本次任命发生在太子申被俘之后，是材料可见的承接；公子赫此前的任职、确切生年及与后来魏君名字的关系，本条没有给出足以校定的资料，故不把他写成已经证实将于某年继位的襄王。魏君旧年链及更元问题见[齐魏君次](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#齐魏君次)。


<a id="3楚威王元年与上一年的承位分开"></a>
#### 3｜楚威王元年与上一年的承位分开

卷015楚栏明记“楚威王熊商元年”。[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-6094e5c1e21f39)在宣王三十年记父王卒、熊商立，已在前340年合叙。这里仅记新君元年，不另造一次死亡或接位，也不因为这一格只有君号就把楚威王任内所有未确年故事提前塞入本年。

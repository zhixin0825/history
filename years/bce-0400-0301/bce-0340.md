# 公元前340年｜卫鞅俘获魏公子卬，受封为商君

[← 公元前341年](bce-0341.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前339年 →](bce-0339.md)

**周显王二十九年；秦孝公二十二年、楚宣王三十年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>
<a id="1卫鞅借会盟俘获公子卬秦再败魏军"></a>

1. **卫鞅借会盟俘获公子卬，秦再败魏军。** 魏军在[马陵受挫](bce-0341.md#event-1)后，卫鞅劝秦孝公趁机进攻。他认为魏既能向西威胁秦，又能利用东方的土地和力量，秦若想扩大势力，就应当抓住魏刚吃败仗的机会。孝公采纳建议，让卫鞅率军攻魏，魏派公子卬领兵抵挡。 [[1]](#note-1)

   卫鞅与公子卬从前有过交情。两军相对时，他给公子卬写信，说彼此不忍相攻，不如见面盟誓、饮酒，约好罢兵，使秦魏安定。公子卬相信了这些话，前来赴会；盟誓之后饮酒时，卫鞅安排的伏兵突然出动，俘获公子卬，又乘机攻击魏军，取得大胜。

   魏惠王接连败于齐、秦，遣使向秦求和，让出河西土地。想到当初公叔曾推荐卫鞅而自己没有任用，他后悔没有听进那番话。卫鞅返秦后，获封十五邑，号商君；此后也就常被称作商鞅。

<a id="event-2"></a>
<a id="2齐赵会合后继续攻魏"></a>

2. **齐、赵会合后继续攻魏。** 齐国与赵国在博望会合，进攻魏国。魏在秦国方向受到打击的同时，还要应对东面、北面诸侯的进兵。 [[2]](#note-2)

<a id="event-3"></a>
<a id="3秦向南侵入楚境"></a>

3. **秦向南侵入楚境。** 秦又向南侵入楚国边境。楚的记事把这次进攻与卫鞅受封商君同记在楚宣王晚年。 [[3]](#note-3)

<a id="event-4"></a>
<a id="4楚宣王去世儿子熊商承位"></a>

4. **楚宣王去世，儿子熊商承位。** 楚宣王去世，儿子熊商继承君位，就是楚威王。宣王此前因兄长楚肃王无子而继位，如今君位传到了自己的儿子手中。 [[4]](#note-4)

## 归年与考证

<a id="sj005-175-note"></a>
<a id="1攻魏俘卬与封商君合为一组事件"></a>
#### 1｜攻魏、俘卬与封商君合为一组事件

原有[卷005 P057](../../sources/摘录/史记-卷005-秦本纪.md#p057)孝公二十二年记卫鞅击魏、虏公子卬、封列侯、号商君；[卷015本年秦、魏两格](../../sources/摘录/史记-卷015-六国年表.md#y0340)分别记“封大良造商鞅”与“秦商君伐我，虏我公子卬”。本次用[《商君列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7068.md#ref-f7e59469a71f01)补入劝战、诈约、俘将和破军经过，兑现旧注所留的互见入口，不另建第二次俘卬。

公子卬的有据前事限于他与卫鞅昔日相欢，未详其结交年份、官职升迁或年龄。不能与后来秦将同名公子卬无证认成一人。魏惠王后悔不用公叔之言，承接的是[卫鞅入秦前在魏任职、受荐未用](bce-0361.md#note-1)的旧事，不是本年又发生一次荐举。

正文暂沿秦孝公二十二年定位。[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-dcd241e85c49d0)在旧惠王三十一年合记秦、赵、齐伐魏及公子卬被俘；古注引《纪年》却有惠王二十九年九月秦卫鞅伐魏西鄙，按前369年元年对应前341年，而《商君列传·索隐》又称封鞅在惠王三十年，对应前340年。这些年次不能只改一个元年便全部自然相合。故不机械移走本条，也不为凑年数另造一次同样的诈约俘卬，详见[秦周与秦魏](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#秦周与秦魏)。

列传记魏割河西求和，又把去安邑、迁大梁接在此后；魏都迁移已在[前361年](bce-0361.md#sj015-0361-daliang)据另一组材料暂行安放，本页不再制造第二次迁都。这里割让河西的范围原文不详，不能说全部河西已一次尽入秦，从而删去后来继续割地的记载。封地原文“于、商十五邑”及其断句、地望亦有异说；正文只取十五邑与商君封号，不直接画定封地边界，更不将后来“商於六百里”无条件套入。原有[卷005纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)继续保留。


<a id="2齐赵会伐魏与博望地名"></a>
#### 2｜齐赵会伐魏与博望地名

卷015齐栏记“与赵会，伐魏”，[《田敬仲完世家·集解》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7046.md#ref-64af2d728e514a)徐广所引表文还保留“博望”二字，正文据此补明会合地。《通鉴》网页“会博望”是现代校刊据这条集解所补，不是独立发现的一份会盟记录。

《田世家》另有“三晋之王皆因田婴朝齐王于博望，盟而去”的概括，与这里齐赵会合伐魏的参加者、行动并不完全相同，不能凭相同地名把三晋国君全加进本次攻魏联军。博望的具体地望各有解释，本页不擅定在某一现代县境。《赵世家》又把赵伐魏及商君虏公子卬写在肃侯十一年，与本表本年的赵十年差一；这里保留异年，不复制一场完全相同的战役。


<a id="3楚世家补出的秦南侵"></a>
#### 3｜楚世家补出的秦南侵

[《楚世家》宣王三十年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-2f8d4a37ced0d8)：“秦封卫鞅于商，南侵楚。”本年原表楚栏只有“三十”，故作为世家补缺。原文未给攻城名、战果、兵数或具体领兵者，不据与封鞅同句就写成他带着刚胜魏的同一支军队转而南征。


<a id="4楚宣王卒与次年威王元年"></a>
#### 4｜楚宣王卒与次年威王元年

《楚世家》接“是年，宣王卒，子威王熊商立”；[《通鉴》显王二十九年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-df07bff423177d)亦记宣王卒、子威王商立。卷015本年宣王三十年、[前339年威王元年](bce-0339.md#event-3)前后衔接，正文把去世与当年承位写在此处，次年是新君元年，不重复举行一次继位。宣王承兄位的前事同见《楚世家》肃王十一年；未见足够材料补熊商即位前的具体任职。

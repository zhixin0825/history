1. **齐军攻魏救韩，孙膑用减灶引庞涓追赶。** 魏军进攻韩国，韩国向齐国求救。齐廷商量是早救还是晚救，田忌主张尽早出兵，孙膑却建议先让韩、魏互相消耗：如果立刻参战，齐就得替韩承受魏军的进攻；等韩国受困更深、魏军也疲惫时再出手，齐国才能掌握主动。齐暗中答应援助，韩国继续抵抗，接连作战失利以后，更加依靠齐国。 [[1]](#reading-note-1)

   齐军由田忌、田婴、田盼等领兵，孙膑负责筹划。田忌与孙膑此前已经在[桂陵之战](bce-0353.md#event-1)合作；田婴出自田氏，自齐威王时就在齐国任职。这次齐军仍朝魏都大梁方向进兵，迫使魏将庞涓离开韩国，回救本国。魏又大举征兵，派太子申领军迎战。

   孙膑判断魏军一向自信勇猛，又看不起齐兵，便让齐军的灶数逐日减少，造成士卒大量逃散的假象。庞涓追了三天，看到营灶越来越少，以为齐军已经溃散过半，于是把步兵留在后面，自己带轻锐部队加速追赶。

<a id="sj-065-L4646-02"></a>
<a id="2马陵伏弩发射庞涓死魏太子申被俘"></a>

<a id="reading-event-2"></a>

2. **马陵伏弩发射，庞涓死，魏太子申被俘。** 孙膑估计庞涓将在夜间到达马陵。那里道路狭窄，两旁地势便于藏兵，他让人在路旁设伏，又削去一棵大树的树皮，在露白处写下“庞涓死于此树之下”，约定夜里看到火光就一齐发射弩箭。 [[2]](#reading-note-2)

   庞涓果然夜间赶到，发现树上有字，便举火查看。字还没有读完，伏兵已从两旁射击，魏军顿时混乱。庞涓知道败局难挽，自杀身亡；齐军乘胜击破魏军，俘获太子申。魏失去将领和储君，东方战局的失败随后又给了秦进攻的机会。

<a id="reading-event-3"></a>

3. **太子申出征途中的劝阻。** 太子经过外黄时，当地一位称作徐子的人曾劝他：即使打赢，富贵也不过是继承魏国；一旦打败，却可能把魏国的前途一并输掉。太子一度想返回，驾车的人又说，出征后半途而返等同败逃；他终于继续前进。 徐子还提醒太子，盼望借战争邀功得利的人很多，即使太子想回，也未必由得自己；这正是驾车者随后阻止撤军的背景。 [[3]](#reading-note-3)

<a id="event-3"></a>
<a id="3秦的记事留下马生人的怪异传闻"></a>

<a id="reading-event-4"></a>

4. **秦的记事留下“马生人”的怪异传闻。** 秦国的记事还保存了一则异常生育的传闻，称马生下了人。原有叙述只有短短几字，未留下观察者或具体经过。 [[4]](#reading-note-4)

<a id="马陵以后未确年的田忌去国补叙"></a>
<a id="sj015-tianji"></a>
<a id="4田忌遭到构陷反击失利后离齐"></a>

<a id="reading-event-5"></a>

5. **马陵以后未确年的田忌去国补叙。** 田忌遭到构陷，反击失利后离齐。 田忌的战功没有使他免于国内的争斗。成侯邹忌与他不和，公孙阅替邹忌设计了一个圈套：派人拿着十金到市上占卜，假称自己是田忌的部下，说田忌三战三胜、声威天下，想做一件大事，问吉凶如何。随后又让人抓住占卜者，把这些话交到齐君面前，制造田忌谋反的嫌疑。 [[5]](#reading-note-5)

   田忌听到消息，率自己的徒众进攻齐地，要对付成侯，却未能得手，最后离开齐国，逃往楚国。朝廷里的争斗，把一位曾在对外战争中立功的将领逼到了国境之外。 田忌后来又有被宣王召回、恢复原职的记载；这是去国后的另一阶段，实际年份未详，不因本篇提前叙到便认作马陵前已复职。

> 二十八年
>
> ①魏龐涓伐韓。韓請救於齊。齊威王召大臣而謀曰：「蚤救孰與晚救？」成侯曰：「不如勿救。」田忌曰：「弗救則韓且折而入於魏，不如蚤救之。」孫臏曰：「夫韓、魏之兵未弊而救之。是吾代韓受魏之兵，顧反聽命於韓也。且魏有破國之志，韓見亡，必東面而愬於齊矣。吾因深結韓之親而晚承魏之弊，則可受重利而得尊名也。」王曰：「善。」乃陰許韓使而遣之。韓因恃齊，五戰不勝，而東委國於齊。
>
> 齊因起兵，使田忌、田嬰、田盼將之。孫子爲師，以救韓，直走魏都。龐涓聞之，去韓而歸。魏人大發兵，以太子申爲將，以禦齊師。孫子謂田忌曰：「彼三晉之兵素悍勇而輕齊，齊號爲怯。善戰者因其勢而利導之。《兵法》：『百里而趣利者蹶上將，五十里而趣利者軍半至。』」乃使齊軍入魏地爲十萬竈，明日爲五萬竈，又明日爲二萬竈。龐涓行三日，大喜曰：「我固知齊軍怯，入吾地三日，士卒亡者過半矣！」乃棄其步軍，與其輕銳倍日幷行逐之。孫子度其行，暮當至馬陵，馬陵道陿而旁多阻隘，可伏兵，乃斫大樹，白而書之曰：「龐涓死此樹下！」於是令齊師善射者萬弩夾道而伏，期日暮見火舉而俱發。龐涓果夜到斫木下，見白書，以火燭之，讀未畢，萬弩俱發，魏師大亂相失。龐涓自知智窮兵敗，乃自剄，曰：「遂成豎子之名！」齊因乘勝大破魏師，虜太子申。

## 归年与考证

<a id="sj005-174-note"></a>
<a id="1马陵只保留一场主述前341与前342两说并列"></a>
#### 1｜马陵只保留一场主述，前341与前342两说并列

原有[卷005 P056](../../sources/摘录/史记-卷005-秦本纪.md#p056)孝公二十一年“齐败魏马陵”，与[卷015本年魏、齐两格](../../sources/摘录/史记-卷015-六国年表.md#y0341)合入上述同一战役。魏栏记太子申被俘、将军庞涓被杀，齐栏记胜于马陵及将领名单；原来后加的一条简述不再复制整场战役，旧 event-1 与本注锚点均保留。

正文暂沿本纪秦孝公二十一年及[《通鉴》显王二十八年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-ffc24c32d6a08e)安放在前341年。**这些传世篇章可能有共同材料，不算多份独立同证。**[《魏世家》《田世家》《孟尝君列传》古注](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7075.md#ref-eeb9c22b023043)引《纪年》则有梁惠王二十八年、齐威王十四年战马陵，按本项目惠王前369年元年，前者为前342年；另一传引作二十七年十二月。[王政冬2017年考证](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-a2d786c99c82b927.md#cite-5)明确采用前342年，对二十七年十二月作文字校订，并推威王元年为前355年；王国维辑校则提出过周正与夏正换算的解释，不能把两种处理说成同一论证。前342年页已有[异年去向](bce-0342.md#sj015-maling-alt)，完整研究见[马陵与田忌](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#马陵与田忌)。

战端也有不同叙法：原有[卷065摘录](../../sources/摘录/史记-条目原文.md#ref-sj-4646)说“魏与赵攻韩”，《魏世家》说魏伐赵、赵求齐救，《田世家》又有赵、韩与魏相攻及南梁之难。《通鉴》取庞涓伐韩、韩请齐救的叙法。正文保留魏攻韩、齐出兵的共同主线；旧正文“魏、赵攻韩”的材料留在本注，不把相抵牾的记载连成一份同时成立的联军作战表。朝议中“成侯不如勿救”一说，古注还涉及邹忌卒年冲突，不能用它反证邹忌在这一年一定参议。

齐君在正文仍用齐威王。旧表和部分世家作“齐宣王二年”，属于本批继续纠正的齐君错位，不能照搬。田婴的有据前事为[《孟尝君列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7075.md#ref-6e1c6938d829ae)“自威王时任职用事”；本传称他威王少子、宣王庶弟，《索隐》已经质疑，故正文不据此定父子兄弟关系。田盼之名在各本又作田肦、田朌、田盻，本轮无注网页误形作“田馊”，原表保留所见文字，正文用常见的田盼；三家注引徐广对三人是否皆出征仍有询问，不据此另定一套无疑的统帅、副将层级。

<a id="note-2"></a>
<a id="2减灶伏击与太子申的劝返故事"></a>
#### 2｜减灶、伏击与太子申的劝返故事

原有[卷065“孙子吴起列传”摘录](../../sources/摘录/史记-条目原文.md#ref-sj-4646)和[《通鉴》卷二工作本摘录](../../sources/摘录/史记-条目原文.md#ref-tp002-153-157)的战术叙述全部归入同一场战役。卷065记灶数十万、五万、三万，《通鉴》末数二万；这些是叙事中的灶数与欺敌安排，不能直接拿来换算实际兵力、逃兵人数或兵员损失。“后十三岁”也不机械减成另一年，推翻上注所列的王年冲突。

[《孙子吴起列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7065.md#ref-56db5236a8e4b2)把庞涓的死写成兵败自刭，年表和其他篇章概称“杀”；正文从较详叙事写其自杀，不再添另一次齐将手刃。树上的字是伏击一方刻意所写，不是神谕。旧摘录末尾“世传其”缺宾语，本次所读完整网页作“世传其兵法”；不将补全字句悄悄回填旧摘录，也不由泛称“兵法”断言某个具体传本已经在本年刊行。

太子申遇外黄徐子的故事来自[《魏世家》旧惠王三十年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-655e443a5f5182)。这是附在同次马陵之役前的劝谏叙事，不把徐子的“百战百胜之术”理解成一套真的百战记录，也不为他杜撰仕官履历。太子申被俘的结局按年表、本纪世家系统保存，俘后下落原文未详。

<a id="note-3"></a>
<a id="3马生人是怪异记载不作生物学事实或战争原因"></a>
#### 3｜“马生人”是怪异记载，不作生物学事实或战争原因

卷015秦孝公二十一年格只记“马生人”。本页保存古人留下的异常传闻，不据四字认定发生了跨物种生育，不补婴儿形貌、具体地点或现代病名，也不将它解释为魏败或秦兴的预兆。

<a id="note-4"></a>
<a id="4田忌受构袭齐与出奔的顺序及地望异说"></a>
#### 4｜田忌受构、袭齐与出奔的顺序及地望异说

[卷015前344年齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0344)记“田忌袭齐，不胜”，[《田敬仲完世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7046.md#ref-a0ee8b523253f3)旧威王三十五年详叙公孙阅设卜问、田忌率徒袭临淄求成侯、不胜而奔；《索隐》却据《战国策》指出田忌是马陵之后被构、不得入齐，不是居齐很久后才出奔。[《孟尝君列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7075.md#ref-3e4e02887fb137)写“袭齐之边邑”，《索隐》认为比袭临淄的说法更合。正文取进攻齐地这一较宽表述，临淄、边邑各说都保留，未擅定攻城路线。

《通鉴》把构陷及奔楚接在马陵同年，并有现代增补“声威天下”四字；本页虽参考其楚国去向，却只采用“马陵以后”的相对顺序。邹忌的具体卒年、这些故事中的人物组合，古注本已有异议；这里展示传世的田忌去国叙事，不宣称相关对白、全部人物活动年已经校准。公孙阅在《索隐》引《战国策》又作公孙闳，不因此新造两个先后献策者。

本段是未确年补叙，**不定为前341年当年事，也不把旧齐威王三十五年机械后移若干年**。前344年旧格已有回链；田忌后来获召回的记载若再整理，须单独核其齐君名号与年代，不反向拿来替本段补出确定的离国年月。

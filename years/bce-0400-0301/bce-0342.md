# 公元前342年｜诸侯向秦致贺，公子少官率师赴逢泽会合

[← 公元前343年](bce-0343.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前341年 →](bce-0341.md)

**周显王二十七年；秦孝公二十年、赵肃侯八年**

## 本年纪事

<a id="event-1"></a>
### 1｜诸侯向秦致贺，少官带兵赴逢泽

诸侯向秦国致贺。秦孝公派公子少官率领军队，到逢泽与诸侯会合，随后朝见周天子。秦不仅在边境用兵，也以带兵参会、朝见王室的方式争取公开的外交地位。[原文与说明](#sj005-173-note)

<a id="event-2"></a>
### 2｜中山君担任魏相

魏国任用中山君为相。现存的记事以这个称号称呼他，没有留下本人的姓名，也没有说明任命时的具体交涉。[原文与说明](#note-2)

## 本年相关史料

<a id="sj005-173-note"></a>
### 1｜诸侯毕贺、逢泽会合与朝天子

原有[卷005 P055](../../sources/摘录/史记-卷005-秦本纪.md#p055)以孝公二十年连记三事；[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0342)作“诸侯毕贺。会诸侯于泽。朝天子”。三家注引徐广说明《纪年》作“逢泽”，与本纪地名相接。正文保留原有完整行程，不把表内较简的“会诸侯”另写成秦孝公又亲自率第二支军队前往。

少官在这里以秦公子的身份领兵出现，其更早经历没有可靠材料可补；不因同名便与别处公子互认。“诸侯毕贺”是史书总括，未列出全部到场国家和使者；“朝天子”也不等于周王在本年把天下交给秦。

本页暂沿本纪孝公二十年及原表所对应的前342年。[前344年周本纪“秦会诸侯于周”](bce-0344.md#note-1)与本条是否同次仍待核；所读《通鉴》网页少官一段从显王二十六年移至二十五年，是现代校刊调整，不能充作又一份独立年证。各条只保留各自材料，不据不同日期宣称发生过数次同规模的大会。详见[秦周与秦魏](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#秦周与秦魏)及原有[卷005纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。

<a id="note-2"></a>
### 2｜中山君相魏的身份与一年差

卷015魏栏旧惠王二十九年记“中山君为相”；[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-fb45dfab7f89d0)却把“中山君相魏”接在旧二十八年之下，与“齐威王卒”并写。两个旧年次相差一年，且齐威王去世一事已经确认不属于这一时期，不能整句照搬为前342年的君主死亡。

正文暂按卷015本行保存任相。《魏世家·索隐》把中山君置于魏曾攻取中山、使人镇守、中山后来复国的背景下，但没有给出这位任相者可据以确认的姓名；不将他无证认作魏文侯之弟、魏武侯本人或后来中山王的某一位。旧王年与史事分别核对，见[齐魏君次](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#齐魏君次)。

<a id="sj015-qi-accession"></a>
### 3｜旧表“齐宣王元年”不在本年重演

本行齐栏原为“齐宣王辟彊元年”。田齐桓公、威王的年链经过前批补核，威王元年尚有前356、前355两说，两个起点都不支持齐宣王在前342年接位。因此原表照存，年度正文仍处于齐威王时期，不为辟彊补造这一年的即位故事；也不将后续齐栏“二”“三”等继续当作已经核实的宣王年。前阶段君位交替见[前356年附记](bce-0356.md#sj015-0356-qi)，本批续核见[齐魏君次](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#齐魏君次)。

<a id="sj015-maling-alt"></a>
### 4｜马陵之战的前342年说，统一读前341年主述

[《田敬仲完世家·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7046.md#ref-65bc5e0924bc09)引《纪年》齐威王十四年田朌伐梁、战马陵；《魏世家》等古注又引梁惠王二十八年。按本项目魏惠王前369年元年，二十八年对应前342年。[王政冬《田庄子至齐威王间田齐诸君年代考》](https://www.fdgwz.org.cn/Web/Show/3072)明确采用前342年，并由此上推威王前355年元年。另一个传引作“二十七年十二月”，其历法解释和文字校订也有区别，不能假定各条天然一致。

本批为保持已有战役的唯一主述，暂从《秦本纪》孝公二十一年和《通鉴》显王二十八年的前341年安放：[齐军救韩、减灶、马陵伏击及魏太子申的结局](bce-0341.md#event-1)均在下一页，同号注完整列出两种年份。本页只提供异年去向，不另写第二场马陵之战；采用前342年的研究也不被说成全体学者已有一致结论。详见[马陵与田忌](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#马陵与田忌)。

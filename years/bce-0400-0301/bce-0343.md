# 公元前343年｜周王以伯命尊秦孝公，赵军进攻魏国首垣

**周显王二十六年；秦孝公十九年、赵肃侯七年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>
<a id="1周王以伯命尊秦孝公"></a>

1. **周王以伯命尊秦孝公。** 周显王向秦孝公致伯命，以王室的名义承认他在诸侯中的领袖地位。孝公执政以来，秦一面整顿国内政务，一面继续向东用兵，如今又取得周王给予的名分。 [[1]](#note-1)

<a id="event-2"></a>
<a id="2秦修筑武城另有从牡丘归来的记录"></a>

2. **秦修筑武城，另有从牡丘归来的记录。** 秦在武城修筑城防。秦的记事还留下一次从东方牡丘返回的行程，未详写途中经过。 [[2]](#note-2)

<a id="event-3"></a>
<a id="3赵公子刻带兵进攻首垣"></a>

3. **赵公子刻带兵进攻首垣。** 赵公子刻率军进攻魏国的首垣。赵军前一年刚攻取齐的高唐，这一年又在魏国方向采取军事行动。 [[3]](#note-3)

<a id="鲁君更替的未确年附记"></a>
### 鲁君更替的未确年附记
<a id="sj015-lu-jing"></a>
<a id="4康公之后儿子偃继承鲁国君位"></a>

<a id="event-4"></a>

4. **康公之后，儿子偃继承鲁国君位。** 鲁康公去世后，儿子偃继位，就是鲁景公。康公此前从父亲共公手里接过君位，景公又继承了这支鲁国公室；这次交替的具体年份仍有分歧。 [[4]](#note-4)

## 归年与考证

<a id="sj004-343-1"></a>
<a id="sj005-172-note"></a>
<a id="1周秦两格与两篇本纪合记一次致伯"></a>
#### 1｜周、秦两格与两篇本纪合记一次致伯

原有[卷004 P068](../../sources/摘录/史记-卷004-周本纪.md#p068)显王二十六年条及[卷005 P055](../../sources/摘录/史记-卷005-秦本纪.md#p055)孝公十九年条，均记天子致伯；[卷015本年周、秦两栏](../../sources/摘录/史记-卷015-六国年表.md#y0343)分别作“致伯秦”“天子致伯”。合为同一件授予名分的史事，所有旧引文入口保留在本注。

“伯”可以解释为方伯或霸主的名分，不等于周王把自己的王位交给秦孝公。前364年获周王赏赐的是秦献公，不能与本条合成同一人同一次册命。诸侯来贺及会合在《秦本纪》中接记于孝公二十年，见[前342年](bce-0342.md#event-1)；各书会朝年次详见[秦周与秦魏](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#秦周与秦魏)。


<a id="2武城与从东方牡丘来归分句保存"></a>
#### 2｜武城与“从东方牡丘来归”分句保存

卷015秦孝公十九年格全文为“城武城。从东方牡丘来归。天子致伯”。“城武城”是修筑城邑，本页不擅改成攻取武城。后句没有明写行程主语与出发缘由，正文仅保存从牡丘归来的记录，不补成孝公亲征齐国、攻灭牡丘或秦军已控制当地。

武城、牡丘的同名地望及此行与诸侯朝会的关系仍待考，不能从“东方”两字复原一条确定的进军路线。致伯已并入上条，不重复计数。


<a id="3首垣之役只记进攻未记攻克"></a>
#### 3｜首垣之役只记进攻，未记攻克

[《赵世家》肃侯七年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-0e8875f41a1ca3)：“公子刻攻魏首垣。”按肃侯前349年元年归本年，补入卷015赵栏仅记年数的空缺。“公子刻”是所见原文中的姓名、称谓，没有可靠的更早个人履历可补；本页不据“公子”擅定他是哪一位赵君之子。也不把“攻”升级为“拔”，或据首垣的字形改作另一座已知城邑。


<a id="4楚栏所附鲁景公元年及鲁国年链"></a>
#### 4｜楚栏所附鲁景公元年及鲁国年链

[卷015本年楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0343)作“二十七。鲁景公偃元年”。“二十七”仍是楚宣王的年数，后句寄记无独立栏的鲁国君年，不是楚国另立一位景王。[《鲁周公世家》及三家注](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7033.md#ref-41efc33e5eae49)记共公二十二年卒、子康公屯立，康公九年卒、子景公匽立；“匽”与“偃”的写法在本注并存。

若从原表前352年康公元年连数九年，景公前343年元年能够接上；但前批已经确认这一康公起点与更早共公年链尚有冲突，不能只取局部相合便宣布全部解决。《通鉴》又在前346年记康公卒、景公立，三家注所引皇甫谧“康公……终乙亥，景公元丙子”也构成另一组年次。所读现代《通鉴》网页还调整过共公卒年，不能把调整前后的鲁君年数混成一条无缺口的年链。

本页保存有据的父子承继故事，明确作为未确年附记，不在前346年和本年各造一次继位；与[前352年鲁康公注](bce-0352.md#sj015-0352-lu)衔接。详见[人物与短记](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#人物与短记)。

<a id="本年纪事"></a>
<a id="event-1"></a>
<a id="1秦在周地会合诸侯"></a>

1. **秦在周地会合诸侯。** 秦国在周地与诸侯会合。周王室的名分仍在诸侯交往中起作用，秦也借朝会进入了这一政治场合。 [[1]](#note-1)

   这条会合记录与[前342年秦公子少官赴逢泽](bce-0342.md#event-1)是否出于同一次活动，尚不能确定；少官率师及朝见天子的完整经过集中放在后页。[纪年说明](#note-1)

<a id="event-2"></a>
<a id="2赵军攻齐夺取高唐"></a>

2. **赵军攻齐，夺取高唐。** 赵军进攻齐国，攻下高唐。齐赵边境的城邑争夺仍在继续。 [[2]](#note-2)

## 归年与考证

<a id="sj004-344-1"></a>
<a id="1周地会合与逢泽会合的年次"></a>
#### 1｜周地会合与逢泽会合的年次

原有[卷004 P068](../../拆分史书/史记/卷004.md#p068)记显王二十五年“秦会诸侯于周”；[卷015本年周栏](../../拆分史书/史记/卷015.md#y0344)只记“诸侯会”。两者同在本年，合为一条短述，既不扩大成所有诸侯首次到场，也不从“会”字直接推定秦主持并控制整个联盟。

[《秦本纪》孝公二十年](../../拆分史书/史记/卷005.md#part-2-text)另记诸侯毕贺、秦使公子少官率师会诸侯于逢泽、朝天子，按秦君年对应前342年。[所读《通鉴》网页](../../拆分史书/资治通鉴/卷002.md#text)把少官率师一段加在本年，校刊记第三十五条却明确说明：此段原系显王二十六年，今据杨宽考订移入二十五年，并删除“于逢潭”三字。它是现代移条，不是又一份独立的前344年见证。

因此本页保留周本纪的日期与旧锚点，[前342年](bce-0342.md#sj005-173-note)保存少官行程主述，同会异年或不同活动的问题明示待考，不据几个不同的安放年份统计为三次已经证实的大会。详见[秦周与秦魏](../../拆分史书/史记/卷015.md#kao-988ad1bca4-71c6976f6)。


<a id="2高唐之役来自赵世家"></a>
#### 2｜高唐之役来自《赵世家》

[《赵世家》肃侯六年](../../拆分史书/史记/卷043.md#part-1-text)记“攻齐，拔高唐”，按肃侯前349年元年对应本年。卷015赵栏只记“六”，故此为世家补缺。“拔”可写攻取，但主将、围城多久及双方损失原文未载。

<a id="sj015-dan"></a>
<a id="3魏栏丹封名会保留疑文不编造封赏或大会"></a>
#### 3｜魏栏“丹封名会”保留疑文，不编造封赏或大会

[卷015本年魏栏](../../拆分史书/史记/卷015.md#y0344)原文为“二十七。丹封名会。丹，魏大臣”；《魏世家》集解（史记）徐广引年表也保留这句话。目前可以据注说明丹是魏臣，但“封名会”的文字和断句没有可靠的唯一解释。本页保存原格，不把它扩写成“魏王封丹为名会君”、丹主持会盟或某个已经确定的封邑；魏旧年数也不因本页照录而改作原文没有的数字。

<a id="sj015-tianji-old"></a>
<a id="4旧齐栏田忌袭齐转往马陵以后的未确年补叙"></a>
#### 4｜旧齐栏“田忌袭齐”转往马陵以后的未确年补叙

本轮无注本[卷015齐栏](../../拆分史书/史记/卷015.md#y0344)记“三十五。田忌袭齐，不胜”；所读三家注网页本年齐格仅留“三十五”，缺这句，不因此把已见原格删除。[《田敬仲完世家·索隐》](../../拆分史书/史记/卷046.md#part-2-text)指出田忌在马陵战后被构陷，与世家把出奔放在较早旧王年的叙法不合；《孟尝君列传》还把攻击地点写成齐的边邑。

田忌被陷、反击及离齐的故事，统一见[前341年页“马陵以后未确年的田忌去国补叙”](bce-0341.md#sj015-tianji)。这一链接只提供故事的阅读位置，**既不宣称它发生于前344年，也不把它硬定为马陵当年**。参见[马陵与田忌](../../拆分史书/史记/卷015.md#kao-988ad1bca4-3c82e160d)。

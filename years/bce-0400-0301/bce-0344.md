# 公元前344年｜秦在周地会合诸侯，赵军攻取高唐

[← 公元前345年](bce-0345.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前343年 →](bce-0343.md)

**周显王二十五年；秦孝公十八年、赵肃侯六年**

## 本年纪事

<a id="event-1"></a>
### 1｜秦在周地会合诸侯

秦国在周地与诸侯会合。周王室的名分仍在诸侯交往中起作用，秦也借朝会进入了这一政治场合。[原文与说明](#note-1)

这条会合记录与[前342年秦公子少官赴逢泽](bce-0342.md#event-1)是否出于同一次活动，尚不能确定；少官率师及朝见天子的完整经过集中放在后页。[纪年说明](#note-1)

<a id="event-2"></a>
### 2｜赵军攻齐，夺取高唐

赵军进攻齐国，攻下高唐。齐赵边境的城邑争夺仍在继续。[原文与说明](#note-2)

## 本年相关史料

<a id="note-1"></a>
<a id="sj004-344-1"></a>
### 1｜周地会合与逢泽会合的年次

原有[卷004 P068](../../sources/摘录/史记-卷004-周本纪.md#p068)记显王二十五年“秦会诸侯于周”；[卷015本年周栏](../../sources/摘录/史记-卷015-六国年表.md#y0344)只记“诸侯会”。两者同在本年，合为一条短述，既不扩大成所有诸侯首次到场，也不从“会”字直接推定秦主持并控制整个联盟。

[《秦本纪》孝公二十年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7005.md#ref-45e9436a2713b1)另记诸侯毕贺、秦使公子少官率师会诸侯于逢泽、朝天子，按秦君年对应前342年。[所读《通鉴》网页](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-45f4467483b054)把少官率师一段加在本年，校刊记第三十五条却明确说明：此段原系显王二十六年，今据杨宽考订移入二十五年，并删除“于逢潭”三字。它是现代移条，不是又一份独立的前344年见证。

因此本页保留周本纪的日期与旧锚点，[前342年](bce-0342.md#sj005-173-note)保存少官行程主述，同会异年或不同活动的问题明示待考，不据几个不同的安放年份统计为三次已经证实的大会。详见[秦周与秦魏](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#秦周与秦魏)。

<a id="note-2"></a>
### 2｜高唐之役来自《赵世家》

[《赵世家》肃侯六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-6686cb87f6d896)记“攻齐，拔高唐”，按肃侯前349年元年对应本年。卷015赵栏只记“六”，故此为世家补缺。“拔”可写攻取，但主将、围城多久及双方损失原文未载。

<a id="sj015-dan"></a>
### 3｜魏栏“丹封名会”保留疑文，不编造封赏或大会

[卷015本年魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0344)原文为“二十七。丹封名会。丹，魏大臣”；[《魏世家》集解](https://www.njmuseum.com/files/wshl/rbbook/gb/25/shiji/sj044.html)徐广引年表也保留这句话。目前可以据注说明丹是魏臣，但“封名会”的文字和断句没有可靠的唯一解释。本页保存原格，不把它扩写成“魏王封丹为名会君”、丹主持会盟或某个已经确定的封邑；魏旧年数也不因本页照录而改作原文没有的数字。

<a id="sj015-tianji-old"></a>
### 4｜旧齐栏“田忌袭齐”转往马陵以后的未确年补叙

本轮无注本[卷015齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0344)记“三十五。田忌袭齐，不胜”；所读三家注网页本年齐格仅留“三十五”，缺这句，不因此把已见原格删除。[《田敬仲完世家·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7046.md#ref-93973f21de4ca2)指出田忌在马陵战后被构陷，与世家把出奔放在较早旧王年的叙法不合；《孟尝君列传》还把攻击地点写成齐的边邑。

田忌被陷、反击及离齐的故事，统一见[前341年页“马陵以后未确年的田忌去国补叙”](bce-0341.md#sj015-tianji)。这一链接只提供故事的阅读位置，**既不宣称它发生于前344年，也不把它硬定为马陵当年**。参见[马陵与田忌](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#马陵与田忌)。

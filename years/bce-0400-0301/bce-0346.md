# 公元前346年｜赵肃侯朝周，卫国降低君号

<a id="reading-start"></a>

<a id="本年纪事"></a>
<a id="event-1"></a>
<a id="1赵肃侯朝见周天子"></a>

1. **赵肃侯朝见周天子。** 赵肃侯前往朝见周天子。赵国此前经历过公子争位和[公子范袭击邯郸](bce-0347.md#event-1)，如今国君又以诸侯身份参加对周王的朝礼。 [[1]](#note-1)

<a id="event-2"></a>
<a id="2卫国把国君的称号降为侯"></a>

2. **卫国把国君的称号降为侯。** 卫国进一步降低国君的称号，改称侯，服属于韩、赵、魏三国。昔日与周同姓的诸侯，在强邻之间已难以保持原有的地位。 [[2]](#note-2)

<a id="event-3"></a>
<a id="3齐国记有大夫牟辛被杀"></a>

3. **齐国记有大夫牟辛被杀。** 齐国杀了大夫牟辛。留下来的记事十分简短，没有交代他的罪名，也没有留下这次杀戮的经过。 [[3]](#note-3)

<a id="event-4"></a>
<a id="4秦的桃李在冬天开花"></a>

4. **秦的桃李在冬天开花。** 冬季，秦的桃树、李树开了花。古人把这件不合通常时节的现象记入了秦国的记事。 [[4]](#note-4)

## 归年与考证

<a id="1赵肃侯四年朝天子"></a>
#### 1｜赵肃侯四年朝天子

[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-32e61f810a00a4)连续记肃侯三年公子范袭邯郸、四年“朝天子”。按肃侯前349年元年，本条归前346年；[卷015本年赵栏](../../sources/摘录/史记-卷015-六国年表.md#y0346)只有“四”，朝周是从世家补出的史事。朝见的具体日期、携带的礼物与周王答辞均未详，不另造与秦、齐诸侯同场的大会。


<a id="2卫的贬号与附属于三晋"></a>
#### 2｜卫的贬号与附属于三晋

[《卫康叔世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-20402586582f3d)记成侯十六年“卫更贬号曰侯”；[《通鉴》卷二](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-8dea2dd288cc76)在显王二十三年记“卫更贬号曰侯，服属三晋”。正文沿这条周王年定位，保留卫降低君号及依附强邻两层意思，不把“服属”说成卫国在本年已经灭亡。

世家此前已有卫国势弱、依附三晋的叙述，“更”并不是说卫直到这一年才首次失势；也不能用本条反推春秋时期卫君一概不称侯。旁见卫成侯十一年公孙鞅入秦的旧年次另有错位，不能据此重排卫鞅已经写定的入秦史事。相关君年限制见[人物与短记](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#人物与短记)。


<a id="3牟辛与夫人的异文"></a>
#### 3｜“牟辛”与“夫人”的异文

[卷015本年齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0346)作“三十三。杀其大夫牟辛”，[《田敬仲完世家》三家注](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7046.md#ref-61f3daa937dc7c)同有这一条，徐广却注明“一作夫人”；《索隐》说其所见年表也作“夫人”，又引《纪年》齐桓公十一年杀君母、宣王八年杀王后作为可能的异文线索。**人物身份与事件归属都不能因此说成已经校定。**正文暂按本轮原表所见“牟辛”读法保存短记；不把三次杀戮强合为同一件，也不据“夫人”补出王后姓名和宫廷阴谋。

旧表“三十三”属于已知错位的齐威王年链，本页暂沿原表周王年保存这条材料，不能再称本年为齐威王三十三年。所读《通鉴》网页的“牟〔辛〕”中，“辛”是现代校刊据《田世家》所补，并非新增一份独立证据。齐威王元年的两说继续见[齐魏君次](../../meta/考证/史记-卷015-前0346至0327纪年补核.md#齐魏君次)。

<a id="sj006-073-note"></a>
<a id="4孝公十六年的冬花记录"></a>
#### 4｜孝公十六年的冬花记录

原有[卷006 P073](../../sources/摘录/史记-卷006-秦始皇本纪.md#p073)：“孝公立十六年。時桃李冬華。”沿孝公元年前361年的年链，十六年为前346。古历的冬季不能不经历算就限定为同号公历月份；“华”按开花理解，不把花写成已经成熟的果实。

原文没有具体地名、温度或开花范围，足以说明史书保留了季节反常的观察，不足以据此重建整个秦国一年的气候，更不能解释成战争或政变的预告。旧正文中的这一限制移入同号注，观察本身仍保留在正文。

<a id="sj015-0346-lu"></a>
<a id="5通鉴本年鲁康公卒的异年去向"></a>
#### 5｜《通鉴》本年鲁康公卒的异年去向

《通鉴》显王二十三年另记鲁康公卒、子景公偃立；卷015却在[前343年楚栏](bce-0343.md#sj015-lu-jing)附记“鲁景公偃元年”。这与前批鲁共公、康公起讫未决的年链相连，故本年不另写一次确定的鲁君更替；父子承继的补叙及各说统一放在该处。

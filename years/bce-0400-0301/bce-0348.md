# 公元前348年｜秦整赋役，韩君赴秦，赵魏会阴晋

**周显王二十一年；秦孝公十四年、赵肃侯二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>
<a id="1秦调整赋的征收"></a>

1. **秦调整赋的征收。** 秦在整县、田界措施之后，进一步处理赋的征收。这次“初为赋”的制度变动，接在卫鞅推动的行政与土地整顿之后。 [[1]](#note-1)

<a id="event-2"></a>
<a id="2韩昭侯到秦国"></a>

2. **韩昭侯到秦国。** 韩昭侯前往秦国。此前秦曾进攻韩国，韩国又卷入魏与诸侯之间的战争，如今仍以君主出访的方式处理对秦关系。 [[2]](#note-2)

<a id="event-3"></a>
<a id="3赵肃侯与魏惠王会于阴晋"></a>

3. **赵肃侯与魏惠王会于阴晋。** 赵肃侯与魏惠王在阴晋会面。继魏归还邯郸、赵国更换君主之后，两国继续维持君主之间的直接交往。 [[3]](#note-3)

## 归年与考证

<a id="sj005-171-note"></a>
<a id="sj005-171秦孝公十四年记初为赋"></a>
#### sj005-171｜秦孝公十四年记“初为赋”。

[卷005 P055](../../sources/摘录/史记-卷005-秦本纪.md#p055)与[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0348)同记孝公十四年“初为赋”，合并为旧条的另一重证据。

**说明：**“赋”在这里的具体课征范围须结合别书考释，本轮不把三个字译成一个确定百分比税率，也不称秦国此前全无征敛。

所读[《通鉴》网页校刊](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-c6c6043b8bb20c)认为是初征户赋，并把旧文“更为赋税法”改为“初为赋”；这是现代校订的解释，不能冒充本纪原文已经明载完整户税制度。故正文采用调整征收的概括，不直接宣布统一税率或全部税种在本年创立。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。


<a id="2昭侯如秦不等于已知一份臣服条约"></a>
#### 2｜昭侯如秦，不等于已知一份臣服条约

本表韩栏“十一。昭侯如秦”，[《韩世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7045.md#ref-8c575f644d2e5f)同记。正文按表内周显王二十一年保留此访，旧昭侯十一年不随君年起点重算便机械迁动。“如秦”只证明赴秦，原句未载割地、婚约或称臣的具体条件。


<a id="3赵魏会阴晋别书补入"></a>
#### 3｜赵魏会阴晋，别书补入

[《赵世家》肃侯二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7043.md#ref-2871b710c45bc6)记“与魏惠王遇于阴晋”，肃侯前349年元年，故归本年。卷015赵栏只有年数，这件事据世家补入。阴晋后来改称宁秦的记载属于秦惠文君时期，此处仍用当时原名，不把后年的改名提前。

<a id="sj015-0348-qi"></a>
<a id="4齐威王朝周的现代移年暂不另起一场确定朝见"></a>
#### 4｜齐威王朝周的现代移年，暂不另起一场确定朝见

所读《通鉴》网页在本年增置“齐威王来朝”，篇末校刊明说从周烈王六年移来。[前370年朝周条](bce-0370.md#event-1)及[既有田齐补核](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#田齐)已经采用田齐桓公田午的解释。仅凭网页移动，不能证明前370年与前348年一定各有一次相同故事，更不能默默把旧条删掉或重复计数。

本轮尚未找到足以独立锁定威王前348年朝周的证据，故保留这条移年异说，不写成又一场已确定的本年朝见。齐威王承位前后一年的差别，亦见[前356年附记](bce-0356.md#note-4)。

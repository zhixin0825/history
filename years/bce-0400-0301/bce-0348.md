# 公元前348年｜秦整赋役，韩君赴秦，赵魏会阴晋

[← 公元前349年](bce-0349.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前347年 →](bce-0347.md)

**周显王二十一年；秦孝公十四年、赵肃侯二年**

## 本年纪事

<a id="event-1"></a>

### 1｜秦调整赋的征收

秦在整县、田界措施之后，进一步处理赋的征收。这次“初为赋”的制度变动，接在卫鞅推动的行政与土地整顿之后。[原文与说明](#sj005-171-note)

<a id="event-2"></a>
### 2｜韩昭侯到秦国

韩昭侯前往秦国。此前秦曾进攻韩国，韩国又卷入魏与诸侯之间的战争，如今仍以君主出访的方式处理对秦关系。[原文与说明](#note-2)

<a id="event-3"></a>
### 3｜赵肃侯与魏惠王会于阴晋

赵肃侯与魏惠王在阴晋会面。继魏归还邯郸、赵国更换君主之后，两国继续维持君主之间的直接交往。[原文与说明](#note-3)

## 本年相关史料

<a id="sj005-171-note"></a>
### sj005-171｜秦孝公十四年记“初为赋”。

[卷005 P055](../../sources/摘录/史记-卷005-秦本纪.md#p055)与[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0348)同记孝公十四年“初为赋”，合并为旧条的另一重证据。

**说明：**“赋”在这里的具体课征范围须结合别书考释，本轮不把三个字译成一个确定百分比税率，也不称秦国此前全无征敛。

所读[《通鉴》网页校刊](https://zh.wikisource.org/wiki/資治通鑑/卷002)认为是初征户赋，并把旧文“更为赋税法”改为“初为赋”；这是现代校订的解释，不能冒充本纪原文已经明载完整户税制度。故正文采用调整征收的概括，不直接宣布统一税率或全部税种在本年创立。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="note-2"></a>
### 2｜昭侯如秦，不等于已知一份臣服条约

本表韩栏“十一。昭侯如秦”，[《韩世家》](https://zh.wikisource.org/wiki/史記三家註/卷045)同记。正文按表内周显王二十一年保留此访，旧昭侯十一年不随君年起点重算便机械迁动。“如秦”只证明赴秦，原句未载割地、婚约或称臣的具体条件。

<a id="note-3"></a>
### 3｜赵魏会阴晋，别书补入

[《赵世家》肃侯二年](https://zh.wikisource.org/wiki/史記三家註/卷043)记“与魏惠王遇于阴晋”，肃侯前349年元年，故归本年。卷015赵栏只有年数，这件事据世家补入。阴晋后来改称宁秦的记载属于秦惠文君时期，此处仍用当时原名，不把后年的改名提前。

<a id="sj015-0348-qi"></a>
### 4｜齐威王朝周的现代移年，暂不另起一场确定朝见

所读《通鉴》网页在本年增置“齐威王来朝”，篇末校刊明说从周烈王六年移来。[前370年朝周条](bce-0370.md#event-1)及[既有田齐补核](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#田齐)已经采用田齐桓公田午的解释。仅凭网页移动，不能证明前370年与前348年一定各有一次相同故事，更不能默默把旧条删掉或重复计数。

本轮尚未找到足以独立锁定威王前348年朝周的证据，故保留这条移年异说，不写成又一场已确定的本年朝见。齐威王承位前后一年的差别，亦见[前356年附记](bce-0356.md#note-4)。

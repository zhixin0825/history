# 公元前350年｜秦迁都咸阳、整县田界，赵成侯去世

**周显王十九年；秦孝公十二年、赵成侯二十五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>
<a id="1秦迁都咸阳改设大县并整理田界"></a>

1. **秦迁都咸阳，改设大县，并整理田界。** 秦孝公营建咸阳宫阙，把政治中心迁到咸阳。卫鞅主持的改革又把小乡邑聚合为较大的县，设置县令等官员；同时整顿田界，开阡陌，使土地与赋税安排相衔接。秦的东部势力也越过洛水。 [[1]](#note-1)

   这一组整顿还包括对父子兄弟同室起居设禁，以及统一斗、桶、权、衡、丈、尺等度量标准。营都、地方行政、家庭组织和土地制度相继进入同一轮改革。

<a id="event-2"></a>
<a id="2秦魏在彤会面"></a>

2. **秦魏在彤会面。** 秦、魏在彤地会面。虽然前几年两国围绕安邑、固阳等地连续用兵，交战双方仍继续通过会见处理关系。 [[2]](#note-2)

<a id="event-3"></a>
<a id="3赵成侯去世太子在争位中胜出"></a>

3. **赵成侯去世，太子在争位中胜出。** 赵成侯去世，公子绁与太子语争夺君位。公子绁失败，逃往韩国；太子语承位，即赵肃侯。 [[3]](#note-3)

## 归年与考证

<a id="sj005-170-note"></a>
<a id="sj005-170秦迁都咸阳改设大县并整理田界"></a>
#### sj005-170｜秦迁都咸阳，改设大县，并整理田界。

[卷005 P055](../../sources/摘录/史记-卷005-秦本纪.md#p055)记营咸阳、筑冀阙、迁都、并乡聚为县、“为田开阡陌”及“东地渡洛”；[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0350)补核并县与田界，合并旧条而不另起第二次改革。[《商君列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7068.md#ref-b3ca778c654c1d)接记同室禁令、县令丞和“平斗桶权衡丈尺”。

**说明：**本纪四十一县，六国年表与商君列传作三十一县，正文不择一数字伪称无异。“开阡陌”不在没有专题证据时直接等于某一种完整现代土地私有制度。

各项措施在《商君列传》中属于营咸阳后的整组叙事，本文按本纪孝公十二年的年位合述，不能据此说全国每一县、每一户都在同一天完成改制。斗桶等是原书记法，不据“平”补出本条未载的具体量值。迁都从何处起程，本纪只记“秦徙都之”，列传却作“自雍”；秦此前居栎阳的材料另见旧页，故正文不未经核实再增写一段从雍或栎阳出发的具体路线。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。


<a id="2遇彤只证明会见不能补出未载的盟约"></a>
#### 2｜遇彤只证明会见，不能补出未载的盟约

本表魏栏“与秦遇彤”，[《魏世家》旧惠王二十一年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-0a23254b34cf40)作“与秦会彤”，《通鉴》显王十九年亦有此条。正文沿周王年定位，并保留会、遇的同事异文；未给彤地强定现代精确坐标，也没有原文支持此时已经归还某一批魏城。旧魏王年不直接按新元年算术平移。


<a id="3成侯卒年与肃侯元年分开"></a>
#### 3｜成侯卒年与肃侯元年分开

[《赵世家》成侯二十五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7043.md#ref-44db8adbb3100f)记成侯卒及公子緤与太子争立；《索隐》引《世本》说肃侯名语。公子之名有緤、紲、諜等字形，正文用绁，不另造几名争位者。其父母、具体军队和争位经过均未详载。

按成侯前374年元年，二十五年为前350年；[本表次年](../../sources/摘录/史记-卷015-六国年表.md#y0349)接“赵肃侯元年”。因此本页写死亡与承位，前349年写新君元年后的行动，不再重复一次登位。[《通鉴》显王十九年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-2fb5b452b184f7)亦把成侯卒及争立系此年；网页对名字与太子承位的增补，不能全算作司马光原字。

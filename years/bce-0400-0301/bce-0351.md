<a id="1韩昭侯任用申不害为相"></a>

1. **韩昭侯任用申不害为相。** 申不害通过整顿行政、考核名实和修明法术来强化王权；传世记载称国内秩序因此改善，邻国一度不来侵扰。这是对其任相时期的概括，不能当成上任当天全部达成的结果，也不意味着韩国此后再没有遭受战争。 [[1]](#note-1)

   申不害是京人，原是郑国地位较低的臣属，研习黄老与刑名之学，后来向韩昭侯陈说自己的主张，被任为相，开始主持国内政务并应对诸侯。


<a id="event-2"></a>
<a id="2魏把邯郸还给赵两国在漳水上盟誓"></a>

2. **魏把邯郸还给赵，两国在漳水上盟誓。** 魏归还邯郸，与赵在漳水上会盟。从[前354年遭围](bce-0354.md#event-2)、[前353年陷城](bce-0353.md#event-1)到如今还城，赵终于重新获得都城。齐在桂陵的胜利只是这轮战争的一部分，城池归属经其后的交战与讲和才发生变化。 [[2]](#note-2)

<a id="event-3"></a>
<a id="3秦筑商塞卫鞅围固阳并使其降服"></a>

3. **秦筑商塞，卫鞅围固阳并使其降服。** 秦修筑商塞，卫鞅率军围攻魏的固阳，使守方降服。魏前一年刚记有加固固阳的工程，秦魏的边地争夺仍在继续。 [[3]](#note-3)

<a id="event-4"></a>
<a id="4秦又进攻赵的蔺地"></a>

4. **秦又进攻赵的蔺地。** 赵刚从魏手中收回邯郸，西面的蔺地又受到秦军进攻。对赵而言，与魏讲和没有使所有边境同时安定。 [[4]](#note-4)

## 归年与考证

<a id="1申不害任相的周王年与韩国旧君年"></a>
#### 1｜申不害任相的周王年与韩国旧君年

原有[卷063](../../拆分史书/史记/README.md#part-1-ref-sj-4618)、[卷045](../../拆分史书/史记/README.md#part-1-ref-sj-4042)、[卷015](../../拆分史书/史记/README.md#part-1-ref-sj-1338)和[《通鉴》](../../拆分史书/史记/README.md#part-1-ref-tj002-249-267)引文全部保留；新核[卷015本年韩栏](../../拆分史书/史记/卷015.md#y0351)为“八。申不害相”。《通鉴》显王十八年同样记韩昭侯以申不害为相，并补其郑国出身及所学。

[《韩世家》](../../拆分史书/史记/卷045.md#part-2-text)旧昭侯八年与本表同，但韩国君主的起讫有[尚待协调的年链](../../拆分史书/史记/卷015.md#kao-4a74cf511b-de578c773)。因此正文保留前351年任相，不用一个重算后的“八年”推翻已有周王年定位。书中“十五年，终申子之身，国治兵强”是后续任期总述，不能当作他本年一上任就已经达到的结果。


<a id="2魏赵两格是同一次还城与盟誓"></a>
#### 2｜魏赵两格是同一次还城与盟誓

本表魏栏“归赵邯郸”，赵栏“魏归邯郸，与魏盟漳水上”；[《赵世家》成侯二十四年](../../拆分史书/史记/卷043.md#part-1-text)与[《魏世家》旧惠王二十年](../../拆分史书/史记/卷044.md#part-1-text)互见。《通鉴》显王十八年也接还城、盟漳水两事。合写为一组交涉，不把“归”译成赵军又以武力攻克邯郸。盟约条文、交换条件及具体交城日未详。


<a id="3城商塞与围固阳都是本年秦栏的内容"></a>
#### 3｜城商塞与围固阳都是本年秦栏的内容

本表秦孝公十一年记“城商塞。卫鞅围固阳，降之”。“城商塞”是修筑防塞，“围固阳”是军事行动，两个动词不合成同一件工程，也不漏去前项。《秦本纪》在十年安邑与十二年咸阳之间未详记此年，故以年表补缺。商塞的名字不能证明卫鞅此时已经受封商君；本轮未复原其城墙线路。


<a id="4攻蔺来自赵世家补缺"></a>
#### 4｜攻蔺来自《赵世家》补缺

[《赵世家》成侯二十四年](../../拆分史书/史记/卷043.md#part-2-text)在还邯郸与盟漳水之后记“秦攻我蔺”，按成侯元年对应本年。卷015赵栏未载，故作为别书补入，不反向增写为年表原文。原句只说进攻，没有记攻克、割地或主将，本页不添其结果。

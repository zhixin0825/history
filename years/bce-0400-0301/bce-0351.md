# 公元前351年｜魏归还邯郸，申不害相韩，秦继续进兵

**周显王十八年；秦孝公十一年、赵成侯二十四年**

## 本年纪事

<a id="event-1"></a>
<a id="sj-063-L4618-01"></a>

### 1｜韩昭侯任用申不害为相

**时间：周显王十八年** · 事件

申不害原是郑国地位较低的臣属，研习黄老与刑名之学，后来向韩昭侯陈说自己的主张，被任为相，开始主持国内政务并应对诸侯。[原文与说明](#note-1)

[《史记》卷63 老子韩非列传](../../sources/摘录/史记-条目原文.md#ref-sj-4618) · [《史记》卷45 韩世家](../../sources/摘录/史记-条目原文.md#ref-sj-4042) · [《史记》卷15 六国年表](../../sources/摘录/史记-条目原文.md#ref-sj-1338) · [《资治通鉴》卷2](../../sources/摘录/史记-条目原文.md#ref-tj002-249-267)

<details><summary>归年依据、同书互见与待核问题</summary>

以明确周王年条和同书互见定位任命；《韩世家》与原表的旧昭侯八年照录，不因韩君起讫调整就把任命机械移年。后面的十五年执政综述分开，不提前当成本年已经完成的政绩。

</details>

<a id="event-2"></a>
### 2｜魏把邯郸还给赵，两国在漳水上盟誓

魏归还邯郸，与赵在漳水上会盟。从[前354年遭围](bce-0354.md#event-2)、[前353年陷城](bce-0353.md#event-1)到如今还城，赵终于重新获得都城。齐在桂陵的胜利只是这轮战争的一部分，城池归属经其后的交战与讲和才发生变化。[原文与说明](#note-2)

<a id="event-3"></a>
### 3｜秦筑商塞，卫鞅围固阳并使其降服

秦修筑商塞，卫鞅率军围攻魏的固阳，使守方降服。魏前一年刚记有加固固阳的工程，秦魏的边地争夺仍在继续。[原文与说明](#note-3)

<a id="event-4"></a>
### 4｜秦又进攻赵的蔺地

赵刚从魏手中收回邯郸，西面的蔺地又受到秦军进攻。对赵而言，与魏讲和没有使所有边境同时安定。[原文与说明](#note-4)

## 本年相关史料

<a id="note-1"></a>
### 1｜申不害任相的周王年与韩国旧君年

原有[卷063](../../sources/摘录/史记-条目原文.md#ref-sj-4618)、[卷045](../../sources/摘录/史记-条目原文.md#ref-sj-4042)、[卷015](../../sources/摘录/史记-条目原文.md#ref-sj-1338)和[《通鉴》](../../sources/摘录/史记-条目原文.md#ref-tj002-249-267)引文全部保留；新核[卷015本年韩栏](../../sources/摘录/史记-卷015-六国年表.md#y0351)为“八。申不害相”。《通鉴》显王十八年同样记韩昭侯以申不害为相，并补其郑国出身及所学。

[《韩世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7045.md#ref-8cfc0cc31e445c)旧昭侯八年与本表同，但韩国君主的起讫有[尚待协调的年链](../../meta/考证/史记-卷015-前0366至0347纪年补核.md#韩君)。因此正文保留前351年任相，不用一个重算后的“八年”推翻已有周王年定位。书中“十五年，终申子之身，国治兵强”是后续任期总述，不能当作他本年一上任就已经达到的结果。

<a id="note-2"></a>
### 2｜魏赵两格是同一次还城与盟誓

本表魏栏“归赵邯郸”，赵栏“魏归邯郸，与魏盟漳水上”；[《赵世家》成侯二十四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-8feb7d0b75aa23)与[《魏世家》旧惠王二十年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-3ab95d77792e84)互见。《通鉴》显王十八年也接还城、盟漳水两事。合写为一组交涉，不把“归”译成赵军又以武力攻克邯郸。盟约条文、交换条件及具体交城日未详。

<a id="note-3"></a>
### 3｜城商塞与围固阳都是本年秦栏的内容

本表秦孝公十一年记“城商塞。卫鞅围固阳，降之”。“城商塞”是修筑防塞，“围固阳”是军事行动，两个动词不合成同一件工程，也不漏去前项。《秦本纪》在十年安邑与十二年咸阳之间未详记此年，故以年表补缺。商塞的名字不能证明卫鞅此时已经受封商君；本轮未复原其城墙线路。

<a id="note-4"></a>
### 4｜攻蔺来自《赵世家》补缺

[《赵世家》成侯二十四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7043.md#ref-8fc4f257ad03d8)在还邯郸与盟漳水之后记“秦攻我蔺”，按成侯元年对应本年。卷015赵栏未载，故作为别书补入，不反向增写为年表原文。原句只说进攻，没有记攻克、割地或主将，本页不添其结果。

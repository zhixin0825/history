# 公元前352年｜卫鞅降安邑，魏韩在襄陵反击联军

[← 公元前353年](bce-0353.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前351年 →](bce-0351.md)

**周显王十七年；秦孝公十年、赵成侯二十三年**

## 本年纪事

<a id="event-1"></a>

### 1｜卫鞅以大良造率兵围安邑，使其降服

卫鞅升为大良造，率秦军围攻魏的安邑，使安邑降服。他在秦推行法令之外，也承担起对魏作战的指挥。[原文与说明](#sj005-169-note)

<a id="event-2"></a>
### 2｜魏借韩军击败襄陵联军，齐方求和

[前一年](bce-0353.md#event-2)，齐、宋、卫合兵围攻襄陵。魏惠王借助韩军击败这支联军，齐方经由楚将景舍向魏求和。魏在桂陵吃了败仗，仍能在别的战线上作出反击。[原文与说明](#note-2)

<a id="event-3"></a>
### 3｜魏修长城，加固固阳防守

魏修筑长城，并在固阳设置防御。西面秦军持续进攻，魏一面在东方作战，一面仍须经营边地的防守。[原文与说明](#note-3)

## 本年相关史料

<a id="sj005-169-note"></a>
### sj005-169｜卫鞅以大良造率兵围安邑，使其降服。

[卷005 P055](../../sources/摘录/史记-卷005-秦本纪.md#p055)记“十年，卫鞅为大良造，将兵围魏安邑，降之”；[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0352)互见，故是旧条增证，不另计一次攻城。

**说明：**原文只记围攻与降服，不能据此说安邑从此永久归秦。后来封爵“商君”尚未发生，正文用卫鞅及本条明记的大良造。魏都迁移另有[年代分歧](../../meta/考证/史记-卷015-前0366至0347纪年补核.md#魏都与战事)，因此本条不强写“秦攻陷仍为魏都的安邑”，也不把此次降服当作魏立即迁都的独立证据。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="note-2"></a>
### 2｜襄陵的围城与反击，不合并成桂陵同日的一场胜负

[原表魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0352)记“诸侯围我襄陵”。[《水经注》卷三十淮水](https://zh.wikisource.org/wiki/水經注/30)引《纪年》，分作惠成王十七年齐、宋、卫围襄陵，十八年魏“以韩师败诸侯师于襄陵”，齐侯使景舍求成。本项目惠王前369年元年的年链，恰对应前353—352年，故正文从[前页围城](bce-0353.md#event-2)接到本年的反击。原表保留旧魏十九年，不反改成伪原文。

所读[《通鉴》网页](https://zh.wikisource.org/wiki/資治通鑑/卷002)把宋、卫会师前移到显王十六年，并在十七年补反击，是现代校刊所作；本页依据的是上引古《纪年》的连续年次，不把这些增补字句冒充司马光原文。求成并不自动说明邯郸已经归赵，还城仍见[前351年](bce-0351.md#event-2)。

<a id="note-3"></a>
### 3｜筑长城、塞固阳

本表魏栏及[《魏世家》旧惠王十九年](https://zh.wikisource.org/wiki/史記/卷044)均记“筑长城，塞固阳”。正文以该周王年表行保存这项工程；长城的具体段落、总长度与“塞”所指设施，本轮不作超出原文的复原。固阳亦不仅凭同名就确定为今天的同名县。此条接[前351年秦围固阳](bce-0351.md#event-3)，但不能推断所有工程都在秦军到来前一日竣工。

<a id="sj015-0352-lu"></a>
### 4｜楚栏附记“鲁康公元年”，鲁国年链仍待校准

本表楚宣王十八年格兼记“鲁康公元年”，是把无独立栏的小国纪年寄在楚栏，**不是楚国另立一位康王**。[《鲁周公世家》及三家注](https://zh.wikisource.org/wiki/史記三家註/卷033)却记共公二十二年卒、康公九年卒；其年数与表内前376年共公元年、前352年康公元年的相距不完全吻合。前批已经将[鲁共公元年的冲突](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#晋鲁宋)单列，不能在这里未经整条复核便悄悄宣布解决。

所读《通鉴》现代校刊又把共公卒、子康公立移到前352年，是死亡承位而非次年改元的叙述。本页保存原格及世家的父子承继信息，不再补造一场无争议的前352年即位；康公名屯、毛等写法也保留为文献差别。

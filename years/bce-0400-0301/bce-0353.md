## 本年纪事

<a id="event-1"></a>
<a id="sj-065-L4645-01"></a>

### 1｜孙膑建议攻魏的空处，齐军在桂陵击败魏军

**时间：周显王十六年；桂陵之战** · 事件

魏围攻赵国，赵向齐求救。齐威王决定出兵，孙膑辞谢领军，由田忌为将，自己在车中出谋。他反对直接奔赵迎战，建议急攻魏都方向防备空虚的要处，迫使魏军回救。田忌采用这个办法。

**邯郸在这一轮战争中仍被魏军攻下。** 十月，邯郸降魏；魏军随后回师，与齐军在桂陵交战，遭到大败。齐军打赢了这场会战，却没有立即让邯郸回到赵手中；归还城池要等到[前351年的魏赵讲和](bce-0351.md#event-2)。[原文与说明](#note-1)

[《史记》卷65 孙子吴起列传](../../sources/摘录/史记-条目原文.md#ref-sj-4645) · [《资治通鉴》卷2（有标点工作本）](../../sources/摘录/史记-条目原文.md#ref-tp002-89-95)

<details><summary>归年依据、同书互见与待核问题</summary>

按《通鉴》显王十六年年条及《六国年表》、赵成侯二十二年互证定位。原有“魏军离开邯郸”的说法，结合“邯郸降”“魏拔邯郸”补明为陷城后的回师，不把孙膑计划中的解围目标直接写成已经实现的即时还城。各版本对桂陵与襄陵的先后、行军细节仍须分别核对，详见[同号说明](#note-1)。

</details>

<a id="backstory-sj-065-L4643-01"></a>

#### 登场前事｜孙膑：孙膑与庞涓同学兵法，在魏受刑

> 此前经历，确切年月未详；放在这里补叙，不表示发生于前353年。

本篇把孙膑记为阿、鄄之间人、孙武的后裔。孙膑曾同庞涓学习兵法；庞涓在魏做将军后将他召来，书中说庞涓因忌惮他的才能，用刑割去他的双足，并施黥刑，使他难以出头。

<a id="backstory-sj-065-L4644-01"></a>

#### 登场前事｜孙膑：孙膑秘密见齐使，被带回齐国

> 此前经历，确切年月未详；放在这里补叙，不表示发生于前353年。

齐国使者到魏国，孙膑以刑徒身份秘密求见。使者听过他的说法，暗中把他带回齐国；田忌随后待他为客。

[《史记》卷65 孙子吴起列传](../../sources/摘录/史记-条目原文.md#ref-sj-4644)

<details><summary>补叙依据</summary>

《孙子吴起列传》先叙在魏受刑、归齐与赛马，再以“其后魏伐赵”接入桂陵之役。保留前因，不给早年故事补年份。

古文这里只说齐使者“如梁”；这组前事没有独立年份。“梁”可能在后叙中指魏国，不能仅凭这一字就断定使者当时必在已经正式定都的大梁。本轮将旧文“到魏都大梁”改成“到魏国”，保留原锚点和事件关系；迁都材料的差别见[本批考证](../../meta/考证/史记-卷015-前0366至0347纪年补核.md#魏都与战事)。

#### 登场前事｜孙膑：田忌按孙膑安排赛马，两胜一负

> 此前经历，确切年月未详；放在这里补叙，不表示发生于前353年。

田忌常与齐国公子赛马下注。孙膑看出马分上、中、下三等，安排田忌以下等对对方上等、以上等对中等、以中等对下等，三场赢两场。田忌因而把他推荐给齐威王，威王问兵法后让他做军师。

<a id="event-2"></a>
### 2｜齐、宋、卫合兵围攻魏的襄陵

齐军的攻势还有襄陵这一条战线。宋、卫的军队与齐会合，共同围攻魏占有的襄陵。这条战线在[次年还有魏、韩的反击](bce-0352.md#event-2)。[原文与说明](#note-2)

<a id="event-3"></a>
### 3｜韩国进攻东周，夺取陵观、廪丘

韩军进攻东周，夺取陵观、廪丘两处土地。在[东西两个周国分立](bce-0367.md)以后，周王族的领地继续受到邻国侵夺；这次进攻没有使整个周王朝灭亡。[原文与说明](#note-3)

<a id="event-4"></a>
### 4｜楚在邯郸战争中取得睢濊之间的土地

楚出兵救赵后，又取得睢、濊两水之间的土地。楚的参与使魏需要应付南面的压力，也让楚在这一轮战争中扩展了自己的控制范围。[原文与说明](#note-4)

## 本年相关史料

<a id="note-1"></a>
### 1｜桂陵之胜与邯郸失守同时成立

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0353)魏栏“邯郸降。齐败我桂陵”，赵栏“魏拔邯郸”，齐栏“败魏桂陵”，三栏互证同一轮战争；[《赵世家》成侯二十二年](https://zh.wikisource.org/wiki/史記/卷043#趙成侯)亦连记陷城与魏败。[《田敬仲完世家》](https://zh.wikisource.org/wiki/史記/卷046)记“十月，邯郸拔”，然后齐败魏于桂陵，《通鉴》沿其年条安排。古十月不未经换算便作同号公历十月。

孙膑的计策与田忌的指挥，原有[卷065段](../../sources/摘录/史记-条目原文.md#ref-sj-4645)继续保留；“疾走大梁”是进兵魏都方向、攻其空虚的计策，不等于已经证实齐军正式包围并攻下大梁。既有前事、归齐和赛马三段仍在原锚点，不另补发生年。

魏在[前351年](bce-0351.md#event-2)才归还邯郸，因此不能把“围魏救赵”简化为齐军一动，邯郸立即脱围归赵。桂陵的战术叙述、襄陵战线的记载各有侧重；本页没有用一段故事推出魏全国主力尽灭或庞涓在此战阵亡。后者属于后来的马陵叙事，不前移到本年。

<a id="note-2"></a>
### 2｜襄陵之围为什么从本年开始

[《水经注》卷三十淮水](https://zh.wikisource.org/wiki/水經注/30)在渙水经襄邑处引《纪年》：“梁惠成王十七年，宋景㪨、卫公孙仓会齐师，围我襄陵。十八年，惠成王以韩师败诸侯师于襄陵。齐侯使楚景舍来求成。”本项目采用惠王前369年元年，故十七、十八年对应前353、352年。正文按这组连续年次写围城与反击；[原表前352年](../../sources/摘录/史记-卷015-六国年表.md#y0352)“诸侯围我襄陵”仍保存，并回链这段跨年战事。

宋将名字在传本中有㪨、善等写法，此处主述国别，不据字形差异另造两名统帅。《田世家》还把田忌南攻襄陵与邹忌的谋议串联；其叙次不能用来为每次会战补出确定日期。这里引的是《水经注》保存的古《纪年》文字，不是只照搬现代《通鉴》网页的增补。

<a id="note-3"></a>
### 3｜东周之地与邢丘、廪丘异文

本表韩栏记“伐东周，取陵观、廪丘”，[《韩世家》旧昭侯六年](https://zh.wikisource.org/wiki/史記三家註/卷045)却作“陵观、邢丘”；[《通鉴》显王十六年](https://zh.wikisource.org/wiki/資治通鑑/卷002)沿廪丘。正文保留编年底本的地名，异文列在本注，不把邢丘、廪丘又计为另外两次攻取。

韩国君年另有[起讫冲突](../../meta/考证/史记-卷015-前0366至0347纪年补核.md#韩君)，此役按周王年与表行保留，不能将昭侯旧六年机械前移。这里的东周是王族支系的小国，不等于“东周时代”的整个疆域。

<a id="note-4"></a>
### 4｜楚取地接在邯郸陷落之后

[《战国策·楚策一·邯郸之难》](https://ctext.org/zhan-guo-ce/han-dan-zhi-nan1/zh)在景舍出兵后接“邯郸拔，楚取睢濊之间”。本页以邯郸本年陷落作为阅读落点，承接[前354年救赵](bce-0354.md#event-3)，不把未记载的会战日期或州县边界补齐。相关原文亦可核[《绎史》卷一百十六所引《战国策》](https://zh.wikisource.org/wiki/繹史_(四庫全書本)/卷116)。地名原作睢、濊，后世有水名解释，正文不擅自替换成现代完整行政区域。

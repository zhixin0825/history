1. **魏取邯郸，孙膑用计助齐破魏于桂陵。** 孙膑出身阿、鄄之间，与庞涓同学兵法。庞涓任魏将后以嫉妒召来孙膑，借法令加以膑刑、黥刑。孙膑私见访魏的齐使，被秘密载回齐，受齐将田忌礼遇。田忌曾按孙膑的安排以下等马先对对方上等马，再以上等马对中等、中等对下等，两胜一负，得齐王千金，遂把孙膑荐给齐威王。本年，魏围赵，赵请齐救援。孙膑因受刑辞帅，齐以田忌为将、孙膑为军师。孙膑劝田忌攻魏要害，借此牵制攻赵魏军。楚也出兵救赵，并得到睢、濊之间的土地。十月，邯郸仍降魏，随后回师的魏军才在桂陵败于齐。邯郸到[前351年](bce-0351.md#event-2)魏赵讲和后才归还。 [[1]](#reading-note-1)

   他指出魏国精锐尽出，国内多是疲弱老幼，不如急趋大梁，占住要道，冲击其空虚之处。魏军必放开赵国回来自救，齐便可一举解赵之围、又使魏受挫。田忌采纳，魏军离开邯郸，与齐军战于桂陵而大败。

<a id="event-2"></a>
<a id="2齐宋卫合兵围攻魏的襄陵"></a>

<a id="reading-event-6"></a>

2. **齐、宋、卫合兵围攻魏的襄陵。** 齐军的攻势还有襄陵这一条战线。宋、卫的军队与齐会合，共同围攻魏占有的襄陵。这条战线在[次年还有魏、韩的反击](bce-0352.md#event-2)。 邹忌与田忌不和，公孙阅又劝邹忌提议让田忌统军：胜则显示自己的谋划，败则使政敌受制。于是攻襄陵在对外牵制魏国之外，又牵动齐廷内部争权。 [[2]](#reading-note-6)

<a id="event-3"></a>
<a id="3韩国进攻东周夺取陵观廪丘"></a>

<a id="reading-event-7"></a>

3. **韩国进攻东周，夺取陵观、廪丘。** 韩军进攻东周，夺取陵观、廪丘两处土地。在[东西两个周国分立](bce-0367.md)以后，周王族的领地继续受到邻国侵夺；这次进攻没有使整个周王朝灭亡。 [[3]](#reading-note-7)

> 其後魏伐趙，趙急，請救於齊。齊威王欲將孫臏，臏辭謝曰：「刑餘之人不可。」於是乃以田忌為將，而孫子為師，居輜車中，坐為計謀。田忌欲引兵之趙，孫子曰：「夫解雜亂紛糾者不控棬，救鬬者不搏撠，批亢擣虛，形格勢禁，則自為解耳。今梁趙相攻，輕兵銳卒必竭於外，老弱罷於內。君不若引兵疾走大梁，據其街路，衝其方虛，彼必釋趙而自救。是我一舉解趙之圍而收獘於魏也。」田忌從之，魏果去邯鄲，與齊戰於桂陵，大破梁軍。

**本卷说明：** 本段“魏果去邯郸”说魏军回救，不等于魏当即交还邯郸；正文第2条及前351年和议继续保留。公开转录[《孙膑兵法·擒庞涓》](../../meta/考证/史记065-两孙兵书与百科核对.md#qin-pangjuan)另记桂陵擒庞涓，与本篇桂陵不提庞涓、马陵自刭的材料有差别。本轮未据图版重校，也未找到可确证的释放年月，不补“前351释庞涓”以强行缝合。

## 归年与考证

<a id="note-1"></a>
<a id="1桂陵之胜与邯郸失守同时成立"></a>
#### 1｜桂陵之胜与邯郸失守同时成立

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0353)魏栏“邯郸降。齐败我桂陵”，赵栏“魏拔邯郸”，齐栏“败魏桂陵”，三栏互证同一轮战争；[《赵世家》成侯二十二年](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-df2261b20c1f5a)亦连记陷城与魏败。[《田敬仲完世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7046.md#ref-52f26e97ef7722)记“十月，邯郸拔”，然后齐败魏于桂陵，《通鉴》沿其年条安排。古十月不未经换算便作同号公历十月。

孙膑的计策与田忌的指挥，原有[卷065段](../../sources/摘录/史记-条目原文.md#ref-sj-4645)继续保留；“疾走大梁”是进兵魏都方向、攻其空虚的计策，不等于已经证实齐军正式包围并攻下大梁。既有前事、归齐和赛马三段仍在原锚点，不另补发生年。

魏在[前351年](bce-0351.md#event-2)才归还邯郸，因此不能把“围魏救赵”简化为齐军一动，邯郸立即脱围归赵。桂陵的战术叙述、襄陵战线的记载各有侧重；本页没有用一段故事推出魏全国主力尽灭或庞涓在此战阵亡。后者属于后来的马陵叙事，不前移到本年。

<a id="note-2"></a>
<a id="2襄陵之围为什么从本年开始"></a>
#### 2｜襄陵之围为什么从本年开始

[《水经注》卷三十淮水](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E6%B0%B4%E7%B6%93%E6%B3%A8-30.md#ref-695e585fb64f3a)在渙水经襄邑处引《纪年》：“梁惠成王十七年，宋景㪨、卫公孙仓会齐师，围我襄陵。十八年，惠成王以韩师败诸侯师于襄陵。齐侯使楚景舍来求成。”本项目采用惠王前369年元年，故十七、十八年对应前353、352年。正文按这组连续年次写围城与反击；[原表前352年](../../sources/摘录/史记-卷015-六国年表.md#y0352)“诸侯围我襄陵”仍保存，并回链这段跨年战事。

宋将名字在传本中有㪨、善等写法，此处主述国别，不据字形差异另造两名统帅。《田世家》还把田忌南攻襄陵与邹忌的谋议串联；其叙次不能用来为每次会战补出确定日期。这里引的是《水经注》保存的古《纪年》文字，不是只照搬现代《通鉴》网页的增补。

<a id="note-3"></a>
<a id="3东周之地与邢丘廪丘异文"></a>
#### 3｜东周之地与邢丘、廪丘异文

本表韩栏记“伐东周，取陵观、廪丘”，[《韩世家》旧昭侯六年](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7045.md#ref-dcd72801134a83)却作“陵观、邢丘”；[《通鉴》显王十六年](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-f415c136f1fbf1)沿廪丘。正文保留编年底本的地名，异文列在本注，不把邢丘、廪丘又计为另外两次攻取。

韩国君年另有[起讫冲突](../../meta/考证/史记-卷015-前0366至0347纪年补核.md#韩君)，此役按周王年与表行保留，不能将昭侯旧六年机械前移。这里的东周是王族支系的小国，不等于“东周时代”的整个疆域。

<a id="note-4"></a>
<a id="4楚取地接在邯郸陷落之后"></a>
#### 4｜楚取地接在邯郸陷落之后

[《战国策·楚策一·邯郸之难》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E6%88%98%E5%9B%BD%E7%AD%96-%E6%A5%9A%E7%AD%96%E4%B8%80-%E9%82%AF%E9%83%B8%E4%B9%8B%E9%9A%BE-%E5%A3%AB%E7%A4%BC%E5%B1%85%E6%9C%AC%EF%BC%88%E5%8E%9F%E7%AB%99%E5%BC%95%E6%96%87%EF%BC%89.md#ref-75b9d36fa79146)在景舍出兵后接“邯郸拔，楚取睢濊之间”。本页以邯郸本年陷落作为阅读落点，承接[前354年救赵](bce-0354.md#event-3)，不把未记载的会战日期或州县边界补齐。相关原文亦可核[《绎史》卷一百十六所引《战国策》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E7%B9%B9%E5%8F%B2%20%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29-%E5%8D%B7116.md#ref-f7676db55c99f8)。地名原作睢、濊，后世有水名解释，正文不擅自替换成现代完整行政区域。

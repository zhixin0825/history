1. **孙膑建议攻魏的空处，齐军在桂陵击败魏军。** **时间：周显王十六年；桂陵之战** · 事件 [[1]](#reading-note-1)

   魏围攻赵国，赵向齐求救。齐威王决定出兵，孙膑辞谢领军，由田忌为将，自己在车中出谋。他反对直接奔赵迎战，建议急攻魏都方向防备空虚的要处，迫使魏军回救。田忌采用这个办法。

<a id="reading-event-2"></a>

2. **邯郸在这一轮战争中仍被魏军攻下。** 十月，邯郸降魏；魏军随后回师，与齐军在桂陵交战，遭到大败。齐军打赢了这场会战，却没有立即让邯郸回到赵手中；归还城池要等到[前351年的魏赵讲和](bce-0351.md#event-2)。 [[2]](#reading-note-2)


<a id="reading-event-3"></a>

3. **本篇把孙膑记为阿、鄄之间人、孙武的后裔。** 孙膑曾同庞涓学习兵法；庞涓在魏做将军后将他召来，书中说庞涓因忌惮他的才能，用刑割去他的双足，并施黥刑，使他难以出头。 [[3]](#reading-note-3)


<a id="reading-event-4"></a>

4. **登场前事｜孙膑：孙膑秘密见齐使，被带回齐国。** 齐国使者到魏国，孙膑以刑徒身份秘密求见。使者听过他的说法，暗中把他带回齐国；田忌随后待他为客。 [[4]](#reading-note-4)


<a id="reading-event-5"></a>

5. **登场前事｜孙膑：田忌按孙膑安排赛马，两胜一负。** 田忌常与齐国公子赛马下注。孙膑看出马分上、中、下三等，安排田忌以下等对对方上等、以上等对中等、以中等对下等，三场赢两场。田忌因而把他推荐给齐威王，威王问兵法后让他做军师。 [[5]](#reading-note-5)

6. **齐、宋、卫合兵围攻魏的襄陵。** 齐军的攻势还有襄陵这一条战线。宋、卫的军队与齐会合，共同围攻魏占有的襄陵。这条战线在[次年还有魏、韩的反击](bce-0352.md#event-2)。 [[6]](#reading-note-6)

<a id="event-3"></a>

7. **韩国进攻东周，夺取陵观、廪丘。** 韩军进攻东周，夺取陵观、廪丘两处土地。在[东西两个周国分立](bce-0367.md)以后，周王族的领地继续受到邻国侵夺；这次进攻没有使整个周王朝灭亡。 [[7]](#reading-note-7)

<a id="event-4"></a>

8. **楚在邯郸战争中取得睢濊之间的土地。** 楚出兵救赵后，又取得睢、濊两水之间的土地。楚的参与使魏需要应付南面的压力，也让楚在这一轮战争中扩展了自己的控制范围。 [[8]](#reading-note-8)

> 其後魏伐趙，趙急，請救於齊。齊威王欲將孫臏，臏辭謝曰：「刑餘之人不可。」於是乃以田忌為將，而孫子為師，居輜車中，坐為計謀。田忌欲引兵之趙，孫子曰：「夫解雜亂紛糾者不控棬，救鬬者不搏撠，批亢擣虛，形格勢禁，則自為解耳。今梁趙相攻，輕兵銳卒必竭於外，老弱罷於內。君不若引兵疾走大梁，據其街路，衝其方虛，彼必釋趙而自救。是我一舉解趙之圍而收獘於魏也。」田忌從之，魏果去邯鄲，與齊戰於桂陵，大破梁軍。

### 4. 登场前事｜孙膑：孙膑秘密见齐使，被带回齐国

[返回正文第4条](#reading-event-4)

**登场前事：** 孙膑离魏入齐是桂陵之战以前的经历，具体年份未定，不当作本年新事。

**[《史记》卷65 孙子吴起列传](../../sources/摘录/史记-条目原文.md#ref-sj-4644)**

> 齊使者如梁，孫臏以刑徒陰見，說齊使。齊使以為奇，竊載與之齊。齊將田忌善而客待之。忌數與齊諸公子馳逐重射。孫子見其馬足不甚相遠，馬有上、中、下、輩。於是孫子謂田忌曰：「君弟重射，臣能令君勝。」田忌信然之，與王及諸公子逐射千金。及臨質，孫子曰：「今以君之下駟與彼上駟，取君上駟與彼中駟，取君中駟與彼下駟。」既馳三輩畢，而田忌一不勝而再勝，卒得王千金。於是忌進孫子於威王。威王問兵法，遂以為師。

## 归年与考证

<a id="note-1"></a>
<a id="1桂陵之胜与邯郸失守同时成立"></a>
#### 1｜桂陵之胜与邯郸失守同时成立

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0353)魏栏“邯郸降。齐败我桂陵”，赵栏“魏拔邯郸”，齐栏“败魏桂陵”，三栏互证同一轮战争；[《赵世家》成侯二十二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-df2261b20c1f5a)亦连记陷城与魏败。[《田敬仲完世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7046.md#ref-52f26e97ef7722)记“十月，邯郸拔”，然后齐败魏于桂陵，《通鉴》沿其年条安排。古十月不未经换算便作同号公历十月。

孙膑的计策与田忌的指挥，原有[卷065段](../../sources/摘录/史记-条目原文.md#ref-sj-4645)继续保留；“疾走大梁”是进兵魏都方向、攻其空虚的计策，不等于已经证实齐军正式包围并攻下大梁。既有前事、归齐和赛马三段仍在原锚点，不另补发生年。

魏在[前351年](bce-0351.md#event-2)才归还邯郸，因此不能把“围魏救赵”简化为齐军一动，邯郸立即脱围归赵。桂陵的战术叙述、襄陵战线的记载各有侧重；本页没有用一段故事推出魏全国主力尽灭或庞涓在此战阵亡。后者属于后来的马陵叙事，不前移到本年。

<a id="note-2"></a>
<a id="2襄陵之围为什么从本年开始"></a>
#### 2｜襄陵之围为什么从本年开始

[《水经注》卷三十淮水](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%B0%B4%E7%B6%93%E6%B3%A8-30.md#ref-695e585fb64f3a)在渙水经襄邑处引《纪年》：“梁惠成王十七年，宋景㪨、卫公孙仓会齐师，围我襄陵。十八年，惠成王以韩师败诸侯师于襄陵。齐侯使楚景舍来求成。”本项目采用惠王前369年元年，故十七、十八年对应前353、352年。正文按这组连续年次写围城与反击；[原表前352年](../../sources/摘录/史记-卷015-六国年表.md#y0352)“诸侯围我襄陵”仍保存，并回链这段跨年战事。

宋将名字在传本中有㪨、善等写法，此处主述国别，不据字形差异另造两名统帅。《田世家》还把田忌南攻襄陵与邹忌的谋议串联；其叙次不能用来为每次会战补出确定日期。这里引的是《水经注》保存的古《纪年》文字，不是只照搬现代《通鉴》网页的增补。

<a id="note-3"></a>
<a id="3东周之地与邢丘廪丘异文"></a>
#### 3｜东周之地与邢丘、廪丘异文

本表韩栏记“伐东周，取陵观、廪丘”，[《韩世家》旧昭侯六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7045.md#ref-dcd72801134a83)却作“陵观、邢丘”；[《通鉴》显王十六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-f415c136f1fbf1)沿廪丘。正文保留编年底本的地名，异文列在本注，不把邢丘、廪丘又计为另外两次攻取。

韩国君年另有[起讫冲突](../../meta/考证/史记-卷015-前0366至0347纪年补核.md#韩君)，此役按周王年与表行保留，不能将昭侯旧六年机械前移。这里的东周是王族支系的小国，不等于“东周时代”的整个疆域。

<a id="note-4"></a>
<a id="4楚取地接在邯郸陷落之后"></a>
#### 4｜楚取地接在邯郸陷落之后

[《战国策·楚策一·邯郸之难》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%88%98%E5%9B%BD%E7%AD%96-%E6%A5%9A%E7%AD%96%E4%B8%80-%E9%82%AF%E9%83%B8%E4%B9%8B%E9%9A%BE-%E5%A3%AB%E7%A4%BC%E5%B1%85%E6%9C%AC%EF%BC%88%E5%8E%9F%E7%AB%99%E5%BC%95%E6%96%87%EF%BC%89.md#ref-75b9d36fa79146)在景舍出兵后接“邯郸拔，楚取睢濊之间”。本页以邯郸本年陷落作为阅读落点，承接[前354年救赵](bce-0354.md#event-3)，不把未记载的会战日期或州县边界补齐。相关原文亦可核[《绎史》卷一百十六所引《战国策》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E7%B9%B9%E5%8F%B2%20%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29-%E5%8D%B7116.md#ref-f7676db55c99f8)。地名原作睢、濊，后世有水名解释，正文不擅自替换成现代完整行政区域。

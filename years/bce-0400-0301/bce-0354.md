# 公元前354年｜秦在元里胜魏，魏军围攻赵都邯郸

[← 公元前355年](bce-0355.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前353年 →](bce-0353.md)

**周显王十五年；秦孝公八年、赵成侯二十一年**

## 本年纪事

<a id="event-1"></a>

### 1｜秦军在元里打败魏军，取得少梁

秦、魏在元里交战，秦军获胜，取得少梁，战功记为斩首七千。去年两国君主曾在杜平会面，边境竞争却没有因此停止。[原文与说明](#sj005-168-note)

<a id="event-2"></a>
### 2｜魏军包围邯郸，战事直指赵国都城

魏惠王出兵攻赵，围住赵都邯郸。威胁已经到达赵国的政治中心，赵必须设法得到外援；这轮围城延续到[次年邯郸陷落和桂陵之战](bce-0353.md#sj-065-L4645-01)。[原文与说明](#note-2)

<a id="event-3"></a>
### 3｜楚出兵援赵，也计算自身得失

楚廷讨论如何应对邯郸危机。昭奚恤主张暂不救赵，让魏深入，从而消耗魏、赵两国；景舍却认为，完全不救会使魏没有后顾之忧，也可能使赵被迫转而联合魏对付楚。他建议出兵支援，却控制投入的规模。楚王接受这个办法，让景舍起兵救赵。[原文与说明](#note-3)

## 本年相关史料

<a id="sj005-168-note"></a>
### sj005-168｜秦与魏军在元里交战，秦方取得战果。

[卷005 P055](../../sources/摘录/史记-卷005-秦本纪.md#p055)记“八年，与魏战元里，有功”；[卷015本年秦、魏两格](../../sources/摘录/史记-卷015-六国年表.md#y0354)补出斩首七千及取少梁。两栏是一场交战的两面，不重复计作两役。七千为原记战功数，未另作独立人数核实；原条未署主将，不能把秦军一概交给卫鞅指挥。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="note-2"></a>
### 2｜围城、陷城与还城分属三个阶段

本表赵栏“魏围我邯郸”，与[《赵世家》成侯二十一年](https://zh.wikisource.org/wiki/史記/卷043#趙成侯)、[《魏世家》旧惠王十七年](https://zh.wikisource.org/wiki/史記/卷044)互见。[《通鉴》显王十五年](https://zh.wikisource.org/wiki/資治通鑑/卷002)也编在本年。沿赵君年与周王年衔接，前354年围城、前353年魏拔邯郸与齐败魏桂陵、[前351年魏归还邯郸](bce-0351.md#event-2)分别记述。采用魏惠王前369年元年后，不能把魏旧“十七年”单独换算，便将围城移到与赵年链冲突的位置。

<a id="note-3"></a>
### 3｜景舍救赵的理由来自《战国策》，年位据《通鉴》

[《战国策·楚策一·邯郸之难》](https://ctext.org/zhan-guo-ce/han-dan-zhi-nan1/zh)记昭奚恤、景舍的两种主张，以“楚因使景舍起兵救赵”收束；[《通鉴》显王十五年](https://zh.wikisource.org/wiki/資治通鑑/卷002)把楚王使景舍救赵接在魏围邯郸之后。正文沿这一编年位置，讨论过程按《战国策》说辞概述，不能据说辞复原一份会议逐字记录。

此处是前四世纪魏攻赵的邯郸之难，不能混入前257年楚救赵、信陵君窃符的另一轮邯郸战争。景舍的家世、年龄、此次统军人数均未见本条交代，不增补。楚取睢濊之间的后续战果接在[次年](bce-0353.md#event-4)。

<a id="本年纪事"></a>
<a id="event-1"></a>
<a id="1秦军在元里打败魏军取得少梁"></a>

1. **秦军在元里打败魏军，取得少梁。** 秦、魏在元里交战，秦军获胜，取得少梁，战功记为斩首七千。去年两国君主曾在杜平会面，边境竞争却没有因此停止。 [[1]](#note-1)

<a id="event-2"></a>
<a id="2魏军包围邯郸战事直指赵国都城"></a>

2. **魏军包围邯郸，战事直指赵国都城。** 魏惠王出兵攻赵，围住赵都邯郸。威胁已经到达赵国的政治中心，赵必须设法得到外援；这轮围城延续到[次年邯郸陷落和桂陵之战](bce-0353.md#sj-065-L4645-01)。 [[2]](#note-2)

<a id="event-3"></a>
<a id="3楚出兵援赵也计算自身得失"></a>

3. **楚出兵援赵，也计算自身得失。** 楚廷讨论如何应对邯郸危机。昭奚恤主张暂不救赵，让魏深入，从而消耗魏、赵两国；景舍却认为，完全不救会使魏没有后顾之忧，也可能使赵被迫转而联合魏对付楚。他建议出兵支援，却控制投入的规模。楚王接受这个办法，让景舍起兵救赵。 [[3]](#note-3)

## 归年与考证

<a id="sj005-168-note"></a>
<a id="sj005-168秦与魏军在元里交战秦方取得战果"></a>
#### sj005-168｜秦与魏军在元里交战，秦方取得战果。

[卷005 P055](../../sources/摘录/史记-卷005-秦本纪.md#p055)记“八年，与魏战元里，有功”；[卷015本年秦、魏两格](../../sources/摘录/史记-卷015-六国年表.md#y0354)补出斩首七千及取少梁。两栏是一场交战的两面，不重复计作两役。七千为原记战功数，未另作独立人数核实；原条未署主将，不能把秦军一概交给卫鞅指挥。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。


<a id="2围城陷城与还城分属三个阶段"></a>
#### 2｜围城、陷城与还城分属三个阶段

本表赵栏“魏围我邯郸”，与[《赵世家》成侯二十一年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-48a3768adc03a5)、[《魏世家》旧惠王十七年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-87343e94b10164)互见。[《通鉴》显王十五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-31d21aa5f9f6fe)也编在本年。沿赵君年与周王年衔接，前354年围城、前353年魏拔邯郸与齐败魏桂陵、[前351年魏归还邯郸](bce-0351.md#event-2)分别记述。采用魏惠王前369年元年后，不能把魏旧“十七年”单独换算，便将围城移到与赵年链冲突的位置。


<a id="3景舍救赵的理由来自战国策年位据通鉴"></a>
#### 3｜景舍救赵的理由来自《战国策》，年位据《通鉴》

[《战国策·楚策一·邯郸之难》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%88%98%E5%9B%BD%E7%AD%96-%E6%A5%9A%E7%AD%96%E4%B8%80-%E9%82%AF%E9%83%B8%E4%B9%8B%E9%9A%BE-%E5%A3%AB%E7%A4%BC%E5%B1%85%E6%9C%AC%EF%BC%88%E5%8E%9F%E7%AB%99%E5%BC%95%E6%96%87%EF%BC%89.md#ref-14bb8001f3e1c4)记昭奚恤、景舍的两种主张，以“楚因使景舍起兵救赵”收束；[《通鉴》显王十五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-5e562a92133c95)把楚王使景舍救赵接在魏围邯郸之后。正文沿这一编年位置，讨论过程按《战国策》说辞概述，不能据说辞复原一份会议逐字记录。

此处是前四世纪魏攻赵的邯郸之难，不能混入前257年楚救赵、信陵君窃符的另一轮邯郸战争。景舍的家世、年龄、此次统军人数均未见本条交代，不增补。楚取睢濊之间的后续战果接在[次年](bce-0353.md#event-4)。

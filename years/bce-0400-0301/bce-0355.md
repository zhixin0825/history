# 公元前355年｜秦魏会杜平，齐魏会猎，宋争黄池

[← 公元前356年](bce-0356.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前354年 →](bce-0354.md)

**周显王十四年；秦孝公七年、赵成侯二十年**

## 本年纪事

<a id="event-1"></a>

### 1｜秦孝公与魏惠王会于杜平

秦孝公与魏惠王在杜平会面。两国此前在少梁一带交战，此时仍保留君主直接往来的渠道。[原文与说明](#sj005-167-note)

<a id="event-2"></a>
### 2｜魏进攻黄池，宋又将它夺回

魏军进攻宋控制的黄池，宋随后重新夺取该地。黄池此前已在韩、宋争夺中易手，魏的介入又使这处城邑成为新的争夺目标。[原文与说明](#note-2)

<a id="event-3"></a>
### 3｜齐魏会猎，以及两种“国宝”的故事

齐、魏两国君主在郊野会猎。围绕这次会面，流传着齐威王与魏惠王比较国宝的故事。[原文与说明](#note-3)

魏惠王夸说自己有十枚大珠，珠光能照亮前后车乘。齐威王回答，自己的宝物是能够守边、治民的臣下：檀子守南城，盻子守高唐，黔夫守徐州，种首整顿盗贼。珠光只照车乘周围，贤臣却能使千里国土得到治理，魏惠王听后惭愧。[原文与说明](#note-3)

<a id="event-4"></a>
### 4｜魏送来建筑木材，赵用来修建檀台

魏向赵赠送称为“荣椽”的建筑木材，赵成侯用它营建檀台。此时魏、赵仍有礼物往来；[次年魏军围攻邯郸](bce-0354.md#event-2)，两国关系便进入战争。[原文与说明](#note-4)

## 本年相关史料

<a id="sj005-167-note"></a>
### sj005-167｜秦孝公与魏惠王会于杜平。

[卷005 P055](../../sources/摘录/史记-卷005-秦本纪.md#p055)记“七年，与魏惠王会杜平”。[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0355)秦、魏两栏互记同一会面，合为一事。

**说明：**本纪及表格没有给出可复原的盟约全文，不能将会面直接扩写为结成长期同盟。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="note-2"></a>
### 2｜黄池的往复，不是两个不同城邑

本表魏栏及[《魏世家》](https://zh.wikisource.org/wiki/史記/卷044)同记“侵宋黄池，宋复取之”。前357年韩栏“宋取我黄池”已见[前页](bce-0357.md)；这里接续宋占有后的魏宋争夺，不把“侵”自动译成长期占领整个宋国。正文不另补兵力、主将或围城时长。

<a id="note-3"></a>
### 3｜会猎表行与比宝说辞的证据强度不同

本表齐栏记“与魏会田于郊”，[《田敬仲完世家》](https://zh.wikisource.org/wiki/史記/卷046)于同一会猎下连述比宝，[《通鉴》显王十四年](https://zh.wikisource.org/wiki/資治通鑑/卷002)也保留该故事。本页按周显王十四年的表行暂置会面，**不以旧齐威王二十四年的数字来证明它就是新年链的某一精确君年**；[威王承位的一年差](bce-0356.md#note-4)仍在。

比宝是这次会面所附的说辞，不是另外发现一份前355年的宫廷财产清单。珠光、边防威慑与“道不拾遗”保留故事中的夸说性质，不视作经过测量的光照范围或全国犯罪统计。高唐守臣有“盻子”等写法，部分通行白文本缺其名前字；这里据《通鉴》保留盻子。

[《田世家·索隐》](https://zh.wikisource.org/wiki/史記三家註/卷046)还指出，《韩诗外传》把比宝说辞归于齐宣王，人物归属也有异传。本页依《史记》叙为齐威王的说辞，同时保留此分歧；它本身不足以为整条会猎另定公元年。

<a id="note-4"></a>
### 4｜荣椽与檀台

[《赵世家》成侯二十年](https://zh.wikisource.org/wiki/史記三家註/卷043)记“魏献荣椽，因以为檀台”，按成侯前374年元年为本年。《索隐》反对把荣椽当成地名，解释为可以作椽的良材；正文采用建筑材料之义，不据此添一笔魏割地。台址古注有不同地理指认，本轮未定精确位置，也无证据将赠木解释为诱使赵耗财的秘密计谋。

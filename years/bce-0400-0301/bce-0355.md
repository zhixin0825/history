# 公元前355年｜秦魏会杜平，齐魏会猎，宋争黄池

**周显王十四年；秦孝公七年、赵成侯二十年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>
<a id="1秦孝公与魏惠王会于杜平"></a>

1. **秦孝公与魏惠王会于杜平。** 秦孝公与魏惠王在杜平会面。两国此前在少梁一带交战，此时仍保留君主直接往来的渠道。 [[1]](#note-1)

<a id="event-2"></a>
<a id="2魏进攻黄池宋又将它夺回"></a>

2. **魏进攻黄池，宋又将它夺回。** 魏军进攻宋控制的黄池，宋随后重新夺取该地。黄池此前已在韩、宋争夺中易手，魏的介入又使这处城邑成为新的争夺目标。 [[2]](#note-2)

<a id="event-3"></a>
<a id="3齐魏会猎以及两种国宝的故事"></a>

3. **齐魏会猎，以及两种“国宝”的故事。** 齐、魏两国君主在郊野会猎。围绕这次会面，流传着齐威王与魏惠王比较国宝的故事。 [[3]](#note-3)

   魏惠王夸说自己有十枚大珠，珠光能照亮前后车乘。齐威王回答，自己的宝物是能够守边、治民的臣下：檀子守南城，盻子守高唐，黔夫守徐州，种首整顿盗贼。珠光只照车乘周围，贤臣却能使千里国土得到治理，魏惠王听后惭愧。

<a id="event-4"></a>
<a id="4魏送来建筑木材赵用来修建檀台"></a>

4. **魏送来建筑木材，赵用来修建檀台。** 魏向赵赠送称为“荣椽”的建筑木材，赵成侯用它营建檀台。此时魏、赵仍有礼物往来；[次年魏军围攻邯郸](bce-0354.md#event-2)，两国关系便进入战争。 [[4]](#note-4)

### 3. 齐魏会猎，以及两种“国宝”的故事

[返回正文第3条](#event-3)

**[史记三家注](../../sources/史记三家注/卷046.md#p30)**

> 威王二十三年，與趙王會平陸。二十四年，與魏王會田於郊。魏王問曰：「王亦有寶乎？」威王曰：「無有。」〔索隱〕案：韓嬰詩外傳以爲齊宣王，其說異也。梁王曰：「若寡人國小也，尚有徑寸之珠照車前後各十二乘者十枚，奈何以萬乘之國而無寶乎？」威王曰：「寡人之所以爲寶與王異。吾臣有檀子者，〔索隱〕檀子，齊臣。檀，姓；子，美稱，大夫皆稱子。肦子，田肦也。黔夫及種首皆臣名。事悉具戰國策也。使守南城，則楚人不敢爲寇東取，泗上十二諸侯〔索隱〕邾、莒、宋、魯之比。皆來朝。吾臣有肦子者，使守高唐，則趙人不敢東漁於河。吾吏有黔夫者，使守徐州，則燕人祭北門，趙人祭西門，〔集解〕賈逵曰：「齊之北門西門也。言燕、趙之人畏見侵伐，故祭以求福。」徙而從者七千餘家。吾臣有種首者，使備盜賊，則道不拾遺。將以照千里，豈特十二乘哉！」梁惠王慙，不懌而去。

<a id="note-4"></a>

### 4. 魏送来建筑木材，赵用来修建檀台

[返回正文第4条](#event-4)

**[史记三家注](../../sources/史记三家注/卷043.md#p51)**

> 十七年，成侯與魏惠王遇葛孽。〔集解〕徐廣曰：「在馬丘。年表曰十八年趙孟如齊。」十九年，與齊、宋會平陸，〔正義〕兗州縣也。平陸城與即古厥國。與燕會阿。〔正義〕括地志云：「故葛城一名依城，又名西阿城，在瀛州高陽縣西北五十里。以徐、兖二水並過其西，又徂經其北。曲曰阿，以齊有東阿，故曰西阿城。地理志云瀛州屬河閒，趙分也。」按：燕會趙即此地。二十年，魏獻榮椽，因以爲檀臺。〔集解〕徐廣曰：「襄國縣有檀臺。」〔索隱〕劉氏云「榮椽蓋地名，其中有一高處，可以爲臺」，非也。按：榮椽是良材，可爲椽，斲飾有光榮，所以魏獻之，故趙因用之以爲檀臺。〔正義〕鄭玄云：「榮，屋翼也。」說文云：「椽，榱也。屋梠之兩頭起者爲榮也。」括地志云：「檀臺在洺州臨洺縣北二里。」二十一年，魏圍我邯鄲。二十二年，魏惠王拔我邯鄲，齊亦敗魏於桂陵。〔正義〕括地志云：「故桂城在曹州乘氏縣東北二十一里，故老云此即桂陵也。」二十四年，魏歸我邯鄲，與魏盟漳水上。秦攻我藺。二十五年，成侯卒。公子緤與太子肅侯〔索隱〕系本云名語。爭立，緤敗，亡奔韓。

## 归年与考证

<a id="sj005-167-note"></a>
<a id="sj005-167秦孝公与魏惠王会于杜平"></a>
#### sj005-167｜秦孝公与魏惠王会于杜平。

[卷005 P055](../../sources/摘录/史记-卷005-秦本纪.md#p055)记“七年，与魏惠王会杜平”。[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0355)秦、魏两栏互记同一会面，合为一事。

**说明：**本纪及表格没有给出可复原的盟约全文，不能将会面直接扩写为结成长期同盟。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。


<a id="2黄池的往复不是两个不同城邑"></a>
#### 2｜黄池的往复，不是两个不同城邑

本表魏栏及[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-6b26d9292d7609)同记“侵宋黄池，宋复取之”。前357年韩栏“宋取我黄池”已见[前页](bce-0357.md)；这里接续宋占有后的魏宋争夺，不把“侵”自动译成长期占领整个宋国。正文不另补兵力、主将或围城时长。


<a id="3会猎表行与比宝说辞的证据强度不同"></a>
#### 3｜会猎表行与比宝说辞的证据强度不同

本表齐栏记“与魏会田于郊”，[《田敬仲完世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7046.md#ref-82915697b85476)于同一会猎下连述比宝，[《通鉴》显王十四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-dc740eb53a76f7)也保留该故事。本页按周显王十四年的表行暂置会面，**不以旧齐威王二十四年的数字来证明它就是新年链的某一精确君年**；[威王承位的一年差](bce-0356.md#note-4)仍在。

比宝是这次会面所附的说辞，不是另外发现一份前355年的宫廷财产清单。珠光、边防威慑与“道不拾遗”保留故事中的夸说性质，不视作经过测量的光照范围或全国犯罪统计。高唐守臣有“盻子”等写法，部分通行白文本缺其名前字；这里据《通鉴》保留盻子。

[《田世家·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7046.md#ref-92589689385839)还指出，《韩诗外传》把比宝说辞归于齐宣王，人物归属也有异传。本页依《史记》叙为齐威王的说辞，同时保留此分歧；它本身不足以为整条会猎另定公元年。


<a id="4荣椽与檀台"></a>
#### 4｜荣椽与檀台

[《赵世家》成侯二十年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7043.md#ref-6cf3a0a2bf0d9e)记“魏献荣椽，因以为檀台”，按成侯前374年元年为本年。《索隐》反对把荣椽当成地名，解释为可以作椽的良材；正文采用建筑材料之义，不据此添一笔魏割地。台址古注有不同地理指认，本轮未定精确位置，也无证据将赠木解释为诱使赵耗财的秘密计谋。

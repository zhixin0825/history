# 公元前356年｜赵国往来齐燕，秦国变法继续推进

[← 公元前357年](bce-0357.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前355年 →](bce-0355.md)

**周显王十三年；秦孝公六年、赵成侯十九年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>
<a id="1赵分别与齐宋和燕会面"></a>

1. **赵分别与齐、宋和燕会面。** 赵与齐、宋在平陆会面，又与燕在阿地相会。同一年里，赵既联系东面的齐、宋，也维持与北邻燕的往来。 [[1]](#note-1)

<a id="event-2"></a>
<a id="2鲁卫宋韩的君主到魏国"></a>

2. **鲁、卫、宋、韩的君主到魏国。** 鲁、卫、宋、韩的君主前往魏国朝会。魏仍是各国外交往来的重要中心；赵、齐等国彼此会面，并不意味着所有小国已经一致转向反魏。 [[2]](#note-2)

<a id="event-3"></a>
<a id="3卫鞅受任左庶长变法从议论走向持续推行"></a>

3. **卫鞅受任左庶长，变法从议论走向持续推行。** 从[前359年的议法](bce-0359.md)往后，秦的新法已经推行了一段时间。卫鞅得到左庶长的职位，在孝公支持下继续整顿政令。 [[3]](#note-3)

<a id="event-4"></a>

4. **这一阶段的新法，把户籍、农业与军功连在一起。** 民众按什伍编组，相互监督并承担连坐责任；耕织多者得到优待，一户有两名以上男子而不分户，便加倍课征。出战立功可以进爵、取得与等级相应的田宅待遇，私斗则受惩罚。宗室也不能仅凭血缘、不计军功便照旧享有特权。 [[4]](#note-4)

<a id="event-5"></a>

5. **变法时期的故事｜徙木兑现赏金。** 新令准备公布时，卫鞅担心民众不信。他在国都南门立一根大木，宣布搬到北门即可领十金。无人敢动，赏额便增加到五十金。终于有人搬木，卫鞅当即付给赏金，随后颁令。兑现眼前这一笔赏钱，是让百姓相信国家说出的赏罚会执行。 [[5]](#note-5)

<a id="event-6"></a>

6. **前357—356年间的君位交接｜田午之后，因齐继承齐国。** 田齐桓公田午去世，儿子因齐承位，后来称为齐威王。继[田侯剡和田午的君位更迭](bce-0375.md)之后，齐国由这一代君主继续经营；后来的田忌、孙膑等人，也将在他的朝廷中活动。 [[6]](#note-6)

<a id="event-7"></a>

7. **齐威王执政时期｜邹忌从谈琴谈到治国，后来任相封侯。** 邹忌以弹琴见齐威王，获留右室。王随后自弹，邹忌未细听便赞好，引得王放下琴、按剑质问。他解释，大弦宽和如君，小弦清明如臣，深按舒放如政令，大小相济如四时；再从琴音反复有序、不相妨害，讲到国政存亡。威王先嫌他轻率，又怀疑丝桐怎能谈治民，终于接受调琴与安民道理相通的解释。 [[7]](#note-7)

   邹忌初见三个月后受相印。淳于髡用五条隐语劝试：事君礼全则昌；猪脂润轴，轴孔为方的车轮仍不能转；胶合弓干不能长补裂隙；狐裘不可混补黄狗皮；车与琴瑟不校正便不能任用。邹忌分别答以谨记事君之礼、善处左右、亲附万民、择君子不杂小人、修法律督奸吏。淳于髡见其回答如回声，预言他不久获封；一年后邹忌封下邳、号成侯。这些是篇内的相对间隔，未据阅读位置推成精确任相或封侯年。

<a id="sj046-jimo-a-event"></a>

8. **威王时期未定年附读｜实查即墨与阿，才看清毁誉的来处。** 即墨大夫常遭批评，威王派人查看，却发现田野开辟、百姓足食、官府没有积压事务，原来他不肯花钱讨好王左右，于是封给万户。阿大夫常受称赞，实查却见田荒民困，赵攻甄、卫取薛陵时又不救不报；王认定他用钱买誉，将他与替他说好话的左右一同烹杀。这是一则以严刑和实绩考核说明治齐的故事；“九年”所在年链与所附战争互相错层，故事只作威王时期附读，不确认为前356年的一次考绩。 [[8]](#sj046-jimo-a-note)

> 騶忌子以鼓琴見威王，威王說而捨之右室。須臾，王鼓琴，騶忌子推戶入曰：「善哉鼓琴！」王勃然不說，去琴按劍曰：「夫子見容未察，何以知其善也？」騶忌子曰：「夫大弦濁以春溫者，君也；小弦廉折以清者，相也；攫之深，醳之愉者，政令也；鈞諧以鳴，大小相益，回邪而不相害者，四時也：吾是以知其善也。」王曰：「善語音。」騶忌子曰：「何獨語音，夫治國家而弭人民皆在其中。」王又勃然不說曰：「若夫語五音之紀，信未有如夫子者也。若夫治國家而弭人民，又何為乎絲桐之閒？」騶忌子曰：「夫大弦濁以春溫者，君也；小弦廉折以清者，相也；攫之深而捨之愉者，政令也；鈞諧以鳴，大小相益，回邪而不相害者，四時也。夫復而不亂者，所以治昌也；連而徑者，所以存亡也：故曰琴音調而天下治。夫治國家而弭人民者，無若乎五音者。」王曰：「善。」

**本卷说明：** 威王时期未确年故事，现有阅读入口并非断言初见在前356。大弦、小弦、按放与协调四时均是邹忌的政治比喻。

### 8. 威王时期未定年附读｜实查即墨与阿，才看清毁誉的来处

[返回正文第8条](#sj046-jimo-a-event)

<a id="sj046-cite-057"></a>

**[《史记·田敬仲完世家》P028](../../sources/摘录/史记-卷046-田敬仲完世家.md#p028)**

> 威王初即位以來，不治，委政卿大夫，九年之閒，諸侯并伐，國人不治。於是威王召即墨大夫而語之曰：「自子之居即墨也，毀言日至。然吾使人視即墨，田野辟，民人給，官無留事，東方以寧。是子不事吾左右以求譽也。」封之萬家。召阿大夫語曰：「自子之守阿，譽言日聞。然使使視阿，田野不辟，民貧苦。昔日趙攻甄，子弗能救。衛取薛陵，子弗知。是子以幣厚吾左右以求譽也。」是日，烹阿大夫，及左右嘗譽者皆并烹之。

**本卷说明：** 本段大治与二十余年诸侯不敢侵齐是概括赞语，不用来抹去已编年的齐国战争。具体赏罚数字为原传所报。

## 归年与考证

<a id="1平陆会与燕赵会阿"></a>
#### 1｜平陆会与燕赵会阿

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0356)赵栏记“与燕会阿。与齐、宋会平陆”，齐栏另记“与赵会平陆”；合并为两次会面，不把两栏的平陆重复计数。[《赵世家》成侯十九年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7043.md#ref-287e0cd0dfa127)与之相合。《正义》将燕赵会的阿解释为赵境西阿，与齐地东阿区别；正文不自行换成现代某城的精确会址。

原表把本年齐栏称为威王二十三年，属于漏代后的旧年链；下列交接附记说明为何正文只写“齐”，不据这一数字断定与会者已经是因齐。


<a id="2郑侯来并非郑国重新出现"></a>
#### 2｜“郑侯来”并非郑国重新出现

原表魏栏“鲁、卫、宋、郑侯来”，[《魏世家》惠王十五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-a788fe7627a003)作“鲁、卫、宋、郑君来朝”。[《韩世家·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7045.md#ref-8cdac8df40944b)说明韩迁都郑后又称郑，故正文把此处郑君解释为韩君，不复活前375年已亡的原郑国。徐广另引《纪年》“鲁共侯来朝”等，是古注保存的异文，未把全部字句与现行表格强合成一份与会名单。

本项目已采用魏惠王前369年元年；本年若换算为该年链，应为十四年。正文保留周显王十三年的表行定位，不因魏栏旧“十五年”便把所有来朝事件机械挪到前355年。


<a id="3前359年议法其后三年与左庶长"></a>
#### 3｜前359年议法、其后三年与左庶长

[《秦本纪》孝公三年段](../../sources/摘录/史记-卷005-秦本纪.md#p054)先记“卒用鞅法”，再接“居三年，百姓便之。乃拜鞅为左庶长”。本页沿前359年议法、其后三年的相对叙次，把左庶长与持续施法的阶段接在此处；原表秦孝公六年本身只有年数，不能冒充其中另有一条“商鞅始变法”的原文。

[《商君列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7068.md#ref-9f6400aa87310f)则把任左庶长放在“卒定变法之令”之前，详记什伍连坐、奖励耕战、分户与宗室军功等规定，并接徙木、太子犯法及“行之十年”。两篇叙事次序不完全相同，故本页不声称全部法令同日公布，也不把十年后的效果提前当成本年实况。徙木只有“令既具，未布”的相对位置，另标未确年；国都也不提前写成前350年才迁入的咸阳。赏金只保留原称，不折算现代币值。


<a id="4齐桓公田午的十八年十九年与威王元年"></a>
#### 4｜齐桓公田午的十八年、十九年与威王元年

[《魏世家·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-ed38a689943e15)引《纪年》有“齐幽公之十八年而威王立”；以本项目采用的田午前374年元年相接，可得前357年承位、前356年作威王元年的方案。[《田敬仲完世家·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7046.md#ref-0557b50856d889)又有“桓公十九年而卒”的解释。

[王政冬《田庄子至齐威王间田齐诸君年代考》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-a2d786c99c82b927.md#cite-7)第三节采用后一说，并结合其马陵纪年论证，排为田午前356年卒、威王前355年元年。该文不能被引作支持“前356年元年”的证据。本项目已采用补回田侯剡，不等于已经接受该文所有战年；此处把交接限于前357—356年间，保留一年差，不擅自重排整段战役。详见[既有田齐补核](../../meta/考证/史记-卷015-田齐前期君次补核.md)。


<a id="5邹忌的琴说相印与成侯封号"></a>
#### 5｜邹忌的琴说、相印与成侯封号

[《田敬仲完世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7046.md#ref-5d7a890a046582)记邹忌以琴见威王，“见三月而受相印”，淳于髡问答之后“居期，封以下邳，号曰成侯”。这些相对时段照原叙保留，不能在缺少可靠起点时换算成独立公元年月。[原表前358年](../../sources/摘录/史记-卷015-六国年表.md#y0358)“邹忌以鼓琴见威王”、[前357年](../../sources/摘录/史记-卷015-六国年表.md#y0357)“封邹忌为成侯”，分别挂在旧威王二十一、二十二年，已经与补齐田午后的君次冲突；两格均回链本段，不把琴说强放到田午仍在位时，也不把整组故事一律后移二十二年。

本次仅处理与这两格相接的琴说、受相和封侯；邹忌、田忌的后续冲突仍留到有据的后年，不作为此时已经发生的前事。

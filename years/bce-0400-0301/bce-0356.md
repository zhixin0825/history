# 公元前356年｜赵国往来齐燕，秦国变法继续推进

[← 公元前357年](bce-0357.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前355年 →](bce-0355.md)

**周显王十三年；秦孝公六年、赵成侯十九年**

## 本年纪事

<a id="event-1"></a>
### 1｜赵分别与齐、宋和燕会面

赵与齐、宋在平陆会面，又与燕在阿地相会。同一年里，赵既联系东面的齐、宋，也维持与北邻燕的往来。[原文与说明](#note-1)

<a id="event-2"></a>
### 2｜鲁、卫、宋、韩的君主到魏国

鲁、卫、宋、韩的君主前往魏国朝会。魏仍是各国外交往来的重要中心；赵、齐等国彼此会面，并不意味着所有小国已经一致转向反魏。[原文与说明](#note-2)

<a id="event-3"></a>
### 3｜卫鞅受任左庶长，变法从议论走向持续推行

从[前359年的议法](bce-0359.md)往后，秦的新法已经推行了一段时间。卫鞅得到左庶长的职位，在孝公支持下继续整顿政令。[原文与说明](#note-3)

**这一阶段的新法，把户籍、农业与军功连在一起。** 民众按什伍编组，相互监督并承担连坐责任；耕织多者得到优待，一户有两名以上男子而不分户，便加倍课征。出战立功可以进爵、取得与等级相应的田宅待遇，私斗则受惩罚。宗室也不能仅凭血缘、不计军功便照旧享有特权。[原文与说明](#note-3)

#### 变法时期的故事｜徙木兑现赏金

> 确切年份未详；此处帮助理解新法如何争取执行，不另计为前356年的一件确年事件。

新令准备公布时，卫鞅担心民众不信。他在国都南门立一根大木，宣布搬到北门即可领十金。无人敢动，赏额便增加到五十金。终于有人搬木，卫鞅当即付给赏金，随后颁令。兑现眼前这一笔赏钱，是让百姓相信国家说出的赏罚会执行。[原文与说明](#note-3)

## 本期人物与未确年补叙

<a id="sj015-0356-qi"></a>
### 前357—356年间的君位交接｜田午之后，因齐继承齐国

> 两种年链相差一年；此为跨年交接附记，不把承位之年与次年改元混成同一日期。

田齐桓公田午去世，儿子因齐承位，后来称为齐威王。继[田侯剡和田午的君位更迭](bce-0375.md)之后，齐国由这一代君主继续经营；后来的田忌、孙膑等人，也将在他的朝廷中活动。[原文与说明](#note-4)

<a id="sj015-zouji"></a>
### 齐威王执政时期｜邹忌从谈琴谈到治国，后来任相封侯

> 此组故事属于齐威王执政时期，具体年份未定；放在这里是人物阅读位置，不是把全部活动认定为前356年，也不是断定都在即位以前。

邹忌以弹琴求见齐威王。威王随后弹琴，邹忌借琴弦解释治国：大弦、小弦各有位置，却要彼此协调；君主、臣下和政令也应如此。威王起初不满，觉得谈音乐与治理百姓相距太远，后来接受了他的解释。[原文与说明](#note-5)

邹忌得到信任，受相印。淳于髡来试探他，用润滑车轴、胶合弓材、修补狐裘、校正车具和琴弦等比喻提出劝告。邹忌分别答以亲近君主、谨慎对待左右、与民相亲、选择贤人以及整顿法令官吏。淳于髡认为他能迅速理解言外之意，预言他不久会获封。此后，邹忌受封下邳，号成侯。[原文与说明](#note-5)

## 本年相关史料

<a id="note-1"></a>
### 1｜平陆会与燕赵会阿

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0356)赵栏记“与燕会阿。与齐、宋会平陆”，齐栏另记“与赵会平陆”；合并为两次会面，不把两栏的平陆重复计数。[《赵世家》成侯十九年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7043.md#ref-287e0cd0dfa127)与之相合。《正义》将燕赵会的阿解释为赵境西阿，与齐地东阿区别；正文不自行换成现代某城的精确会址。

原表把本年齐栏称为威王二十三年，属于漏代后的旧年链；下列交接附记说明为何正文只写“齐”，不据这一数字断定与会者已经是因齐。

<a id="note-2"></a>
### 2｜“郑侯来”并非郑国重新出现

原表魏栏“鲁、卫、宋、郑侯来”，[《魏世家》惠王十五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-a788fe7627a003)作“鲁、卫、宋、郑君来朝”。[《韩世家·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7045.md#ref-8cdac8df40944b)说明韩迁都郑后又称郑，故正文把此处郑君解释为韩君，不复活前375年已亡的原郑国。徐广另引《纪年》“鲁共侯来朝”等，是古注保存的异文，未把全部字句与现行表格强合成一份与会名单。

本项目已采用魏惠王前369年元年；本年若换算为该年链，应为十四年。正文保留周显王十三年的表行定位，不因魏栏旧“十五年”便把所有来朝事件机械挪到前355年。

<a id="note-3"></a>
### 3｜前359年议法、其后三年与左庶长

[《秦本纪》孝公三年段](../../sources/摘录/史记-卷005-秦本纪.md#p054)先记“卒用鞅法”，再接“居三年，百姓便之。乃拜鞅为左庶长”。本页沿前359年议法、其后三年的相对叙次，把左庶长与持续施法的阶段接在此处；原表秦孝公六年本身只有年数，不能冒充其中另有一条“商鞅始变法”的原文。

[《商君列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7068.md#ref-9f6400aa87310f)则把任左庶长放在“卒定变法之令”之前，详记什伍连坐、奖励耕战、分户与宗室军功等规定，并接徙木、太子犯法及“行之十年”。两篇叙事次序不完全相同，故本页不声称全部法令同日公布，也不把十年后的效果提前当成本年实况。徙木只有“令既具，未布”的相对位置，另标未确年；国都也不提前写成前350年才迁入的咸阳。赏金只保留原称，不折算现代币值。

<a id="note-4"></a>
### 4｜齐桓公田午的十八年、十九年与威王元年

[《魏世家·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-ed38a689943e15)引《纪年》有“齐幽公之十八年而威王立”；以本项目采用的田午前374年元年相接，可得前357年承位、前356年作威王元年的方案。[《田敬仲完世家·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7046.md#ref-0557b50856d889)又有“桓公十九年而卒”的解释。

[王政冬《田庄子至齐威王间田齐诸君年代考》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-a2d786c99c82b927.md#cite-7)第三节采用后一说，并结合其马陵纪年论证，排为田午前356年卒、威王前355年元年。该文不能被引作支持“前356年元年”的证据。本项目已采用补回田侯剡，不等于已经接受该文所有战年；此处把交接限于前357—356年间，保留一年差，不擅自重排整段战役。详见[既有田齐补核](../../meta/考证/史记-卷015-田齐前期君次补核.md)。

<a id="note-5"></a>
### 5｜邹忌的琴说、相印与成侯封号

[《田敬仲完世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7046.md#ref-5d7a890a046582)记邹忌以琴见威王，“见三月而受相印”，淳于髡问答之后“居期，封以下邳，号曰成侯”。这些相对时段照原叙保留，不能在缺少可靠起点时换算成独立公元年月。[原表前358年](../../sources/摘录/史记-卷015-六国年表.md#y0358)“邹忌以鼓琴见威王”、[前357年](../../sources/摘录/史记-卷015-六国年表.md#y0357)“封邹忌为成侯”，分别挂在旧威王二十一、二十二年，已经与补齐田午后的君次冲突；两格均回链本段，不把琴说强放到田午仍在位时，也不把整组故事一律后移二十二年。

本次仅处理与这两格相接的琴说、受相和封侯；邹忌、田忌的后续冲突仍留到有据的后年，不作为此时已经发生的前事。

2. **楚国一位名为黑的大臣前往秦国，迎接秦女到楚国成婚。** 秦、楚相邻，两国除军事往来，也通过婚姻建立联系。这次迎亲者是楚臣，迎接方向是从秦到楚。 [[2]](#reading-note-2)

<a id="reading-event-4"></a>

4. **魏、赵两国在鄗会面。** 两国在前一年已有葛孽之会，今年继续接触；现有记载没有留下本次谈判的具体内容。 [[4]](#reading-note-4)

<a id="reading-event-6"></a>

## 归年与考证

<a id="note-1"></a>
<a id="1君尹黑迎女秦的迎亲方向与身份范围"></a>
#### 1｜“君尹黑迎女秦”的迎亲方向与身份范围

[卷015本年楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0357)：“十三。君尹黑迎女秦。”本文据其楚栏位置与“迎女秦”解释为楚臣赴秦迎亲。原格“君尹”字样保留，不默改为“令尹”后再当作原文。

现代学术互见：Yiran Xu等[《Migration in Bronze Age southern China: multidisciplinary investigations of elite Chu burials in Jingzhou》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-4b03766ac1407719.md#cite-1)，*Antiquity* 96（2022），471—478页，475页把这条解释为楚宣王迎娶秦女、派任右尹的贵族接迎；张书豪[《论证补订与时地线索：试探〈墨子·非攻〉三篇与〈兼爱上、下〉的思想系谱》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-5f90f34adbe90474.md#cite-1)，119页也引本年此句，作为秦楚通婚互见。

本年落点有楚宣王十三年与原表相合。正文只取两国迎亲的共同核心，不由后世解释替这位秦女确定姓名、年龄或“秦孝公亲生女儿”，也不把考古研究推测的随行人员当成本次婚礼已有完整名单。名黑的楚臣在所读相关材料中缺少可确定的早年事迹，不补虚构履历。

<a id="note-2"></a>
<a id="2鄗会的参与国与惠王旧年"></a>
#### 2｜鄗会的参与国与惠王旧年

原表魏栏“十四。与赵会鄗”；[《魏世家》惠王十四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-eab2d94cf16087)同。《通鉴》传本有“魏、韩会于鄗”异文，[所读网页](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-2599ccb3111197)写“魏、〔赵〕（韩）会于鄗”，校刊记17列不同版本及《史记》互证。正文取魏、赵，不把它改成韩国另一场会面。

本年按周显王十二年归前357年。以项目已用的惠王前369年元年计，为惠王十三年；旧表“十四”仍保存。上一年[葛孽会](bce-0358.md#event-2)有《赵世家》成侯十七年另载，暂不合并为同一会面。

<a id="note-3"></a>
<a id="3黄池朱与韩昭侯纪年的错位"></a>
#### 3｜黄池、朱与韩昭侯纪年的错位

本年韩栏“二。宋取我黄池。魏取我朱”。[《韩世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7045.md#ref-23cc41fef96de9)：“二年，宋取我黄池。魏取朱。”依韩栏“我”及世家连文，本文将两处均作为韩国失地。旧“二”承接前358年昭侯元年，但昭侯在前362年已见外交活动；目前沿原表本年位置保留战事，不据修正君年把全部领土变化机械提前四年。

黄池之名在[前355年魏宋攻取](bce-0355.md)中还会出现，参加者与动作另有记载。本页不凭同一地名就编出两年之间已经确定的完整转手过程。

<a id="note-4"></a>
<a id="4赵孟的身份不作强解"></a>
#### 4｜赵孟的身份不作强解

本年赵栏“十八。赵孟如齐”。这里没有写赵孟的名、官职或来意，《赵世家》本年也未提供可直接对合的解释。本文保留原称与行动，不认定必为赵成侯、使者或某一位已知的春秋赵氏人物；“如齐”也不足以复原盟约、献地或朝贡项目。

<a id="note-5"></a>
<a id="sj015-0357-zouji-variant"></a>
<a id="5封邹忌为成侯的旧格有完整去向"></a>
#### 5｜封邹忌为成侯的旧格有完整去向

本年齐栏“二十二。封邹忌为成侯”。[《田敬仲完世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7046.md#ref-4a659012a0b5ec)将鼓琴、受相印、与淳于髡问答及“居期，封以下邳，号曰成侯”连叙，却没有为每一步给出独立的绝对年。

本格所据齐威王早起的旧年链已经有漏代问题，不能据此确定封侯发生于前357年。[前358年鼓琴旧格](bce-0358.md#sj015-0358-zouji-variant)及本格合并对应[威王时期的邹忌补叙](bce-0356.md#sj015-zouji)，作为未确年材料完整阅读，不两次重复任相、封侯。

田午去世与齐威王承位有前357、前356的一年分歧，见[相邻年页的交接附记](bce-0356.md)。本年不强写已经确定的田午死亡。原表周、秦、燕三栏仅列王年；魏、韩、赵、楚、齐五栏事件都已登记去向。

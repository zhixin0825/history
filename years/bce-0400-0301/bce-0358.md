1. **秦国在西山击败韩军。** 孝公在国内推动整顿的同时，也继续向东方邻国用兵。这一役留下了地点和胜负，没有留下双方兵力、统帅或具体作战经过。 此时韩国已由懿侯之子昭侯掌政；懿侯的卒年与昭侯起年在不同年链中并不一致，承继只作为这次战争以前的背景。 [[1]](#reading-note-2)

<a id="event-2"></a>
<a id="2赵成侯与魏惠王在葛孽会面"></a>

<a id="reading-event-3"></a>



<a id="reading-event-4"></a>

2. **赵成侯与魏惠王在葛孽相会。** 两国关系仍在战争、救援与外交接触之间变化，这次会面的结果未见明载。 [[2]](#reading-note-4)

## 归年与考证

<a id="note-1"></a>
<a id="1西山战事保留原表的周秦年条"></a>
#### 1｜西山战事保留原表的周、秦年条

[卷015本年韩栏](../../sources/摘录/史记-卷015-六国年表.md#y0358)：“韩昭侯元年。秦败我西山。”[《韩世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7045.md#ref-ed39a9df8bc969)也在昭侯元年记此役；[《通鉴》卷二显王十一年](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-fa8175d9b31d42)写“秦败韩师于西山”。本文沿周显王十一年、秦孝公四年的战事位置，暂归前358年。

秦败韩军的行为有多源互见，但韩君年次存在冲突。修订昭侯元年，不等于可以只凭“元年”二字把整个战役提前四年；本页明确保留目前归年依据，不假称其绝对日期已获独立出土材料验证。

<a id="note-2"></a>
<a id="2旧表昭侯元年不另写一次登位"></a>
#### 2｜旧表“昭侯元年”不另写一次登位

[《赵世家》成侯十三年](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-595e73a2999306)在[前362年](bce-0362.md#sj015-0362-han)已经记赵成侯与韩昭侯在上党相会；旧表到本年才立昭侯元年，与之不合。前363年网页《通鉴》的懿侯卒条又属于后人移入的校订，详见[终年说明](bce-0363.md#note-2)。本页不让已经执政的昭侯再次登位，也不造出两个同号昭侯。

<a id="note-3"></a>
<a id="3葛孽会来自赵世家"></a>
#### 3｜葛孽会来自赵世家

[《赵世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-3c4250aa629db8)：“十七年，成侯与魏惠王遇葛孽。”按成侯前374年元年，对应前358年。这是本年原表只列赵王年之外的补充；与[次年鄗会](bce-0357.md#event-2)分别有不同记载，不因参与者相同就并为同一事件。葛孽的精确地望、这两次会面的议题关系，当前未定。

<a id="note-4"></a>
<a id="sj015-0358-zouji-variant"></a>
<a id="4邹忌鼓琴见威王的旧系年与阅读去向"></a>
#### 4｜邹忌鼓琴见威王的旧系年与阅读去向

本年齐栏原文为“二十一。邹忌以鼓琴见威王”。[《田敬仲完世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7046.md#ref-43345ed920e4dc)叙邹忌由琴声谈君臣与政令，见王三个月后受相印。这个故事所用的齐君年链与田侯剡、田午的漏代问题相连，不能据旧格认定齐威王在前358年已经执政。[下一年旧表封成侯](bce-0357.md#note-5)也存在同类问题。

故事完整白话说明归在[前357—356年间君位交接之后的威王时期补叙](bce-0356.md#sj015-zouji)，明确为威王执政时期、独立年份未定。此处只登记原格与去向，不把它强定为前358年事实，也不按修订元年机械把全部齐格平移二十二年。

本年周、秦、魏、赵、楚、燕六栏只列王年；韩、齐两栏文字均已逐项处理，齐故事的日期待考不等于原文未读或遗失。

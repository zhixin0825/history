1. **卫鞅提出变法修刑、重耕战，孝公采纳其主张。** 甘龙、杜挚反对改旧制，卫鞅坚持重整法令，以农业生产与战功赏罚作为强国手段。随后试行新法遇到抵触，秦国继续推行。卫鞅任左庶长及新令落实另见[前356年](bce-0356.md#note-3)。 [[1]](#reading-note-1)

<a id="reading-event-2"></a>

2. **争论的要点是：要强国，能否改动祖先留下来的法令。** 甘龙认为沿用旧制，官吏熟悉、百姓安定；杜挚担心改制收益不足，宁可照旧。卫鞅则强调，不同时代可以用不同的办法治理国家，不能只因旧法传得久便一概照搬。孝公支持他把耕作、军功与赏罚结合起来的方向。 [[2]](#reading-note-2)

<a id="event-2"></a>
<a id="2魏国白昼出现坠星与声响"></a>

<a id="reading-event-3"></a>

<a id="reading-event-4"></a>

3. **魏国有白天星体坠落、伴随声响的记录。** 这是一条特殊天象的简短记载，尚不足以复原坠落地点、物体大小或造成的损害。 [[3]](#reading-note-3)

<a id="sj043-duanshi-event"></a>

4. **韩、魏、赵处置晋君封地。** 晋国衰亡之际，韩、魏、赵把晋君安置在端氏。端氏后来被夺，晋君迁往屯留。 [[4]](#sj043-duanshi-note)

## 归年与考证

<a id="sj005-166-note"></a>
<a id="sj005-166卫鞅提出变法修刑重耕战孝公采纳其主张"></a>
#### sj005-166｜卫鞅提出变法修刑、重耕战，孝公采纳其主张。

[卷005 P054](../../sources/摘录/史记-卷005-秦本纪.md#p054)。

**说明：**本纪明确以孝公三年系议法，又以“居三年”写后效。《商君列传》更详制度却不在每项措施旁给出公元年；本页不把全部制度强定在前359同日，更不把三年后结果记成当日成效。议法年与其后三年的后效是不同阶段，不能据此造出互不相干的两次人物入秦。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="note-1"></a>
<a id="1本年议法此后施行与后效分别说明"></a>
#### 1｜本年议法、此后施行与后效分别说明

[《秦本纪》孝公三年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7005.md#ref-0889caca6ab78e)：“卫鞅说孝公变法修刑，内务耕稼，外劝战死之赏罚……甘龙、杜挚等弗然，相与争之。卒用鞅法，百姓苦之；居三年，百姓便之。乃拜鞅为左庶长。”[《商君列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7068.md#ref-0c7903e74e79dd)保存更完整的甘龙、杜挚与卫鞅争论，却未给其中每次发言独立年月。

正文补其政见，不把对话当作逐字会议记录。人物只见本段政见时，未有可确证的早年经历可补；也不把甘龙或杜挚设成后来被杀的贵族首领。

《通鉴》显王十年把定令、徙木、太子犯法及多年后效果接写在同一大段，这是编年中兼叙后事的做法。此处维持前359年议法的主体，[前356年](bce-0356.md)接后续实施与后效，不把全部制度都压到今年，更不由“居三年”推出所有措施在同一日生效。

<a id="note-2"></a>
<a id="2坠星的旧表王年"></a>
#### 2｜坠星的旧表王年

[卷015本年魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0359)：“十二。星昼堕，有声。”[《魏世家》惠王十二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-0010298f4ab0ae)同。本文依周显王十年格归前359年；采用惠王前369年元年后，本年为十一年，旧“十二”不改作伪原文。现有短句没有报告陨石样本，不强定现代天文学分类。

<a id="note-3"></a>
<a id="3晋君端氏的后续记载不重复写成第一次灭晋"></a>
#### 3｜晋君端氏的后续记载不重复写成第一次灭晋

[《赵世家》成侯十六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-d4a433530ba6bb)另记：“与韩、魏分晋，封晋君以端氏。”本项目已在[前376年](bce-0376.md)以三家瓜分晋的余地、取消其独立地位为主体，古注及《纪年》另有屯留、端氏与末代晋君名号的不同系年。此处保留世家在本年安排的端氏线索，与[前349年](bce-0349.md#note-2)赵夺端氏、迁晋君于屯留的记载接读，不另讲一场已经确定的“晋国第二次灭亡”，也不把晋公族延续误作仍拥有完整诸侯国。

本年原表周、秦、韩、赵、楚、燕、齐七栏只列王年；卫鞅议法和晋君端氏线索都是本纪、世家互见，并非原格漏抄。

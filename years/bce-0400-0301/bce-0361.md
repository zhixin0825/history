# 公元前361年｜孝公颁求贤令，向能强秦的人许诺官位和土地

[← 公元前362年](bce-0362.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前360年 →](bce-0360.md)

> 当前页面整理已有史料，不表示这一年全部国家和全部史书均已覆盖。

**周显王八年；秦孝公元年；赵成侯十四年**

## 本年纪事

<a id="event-1"></a>

1. **孝公颁求贤令，向能强秦的人许诺官位和土地。** 孝公抚恤孤寡，招募战士，明示功赏，公开征求强国之计。他回顾穆公开土和近世内乱失地，要求扭转诸侯轻视秦的处境。东面魏在洛水、上郡构筑防线，楚也与秦接界，秦不是在没有竞争者的空地上扩张。

**卫鞅由此进入秦国。** 他听到求贤之令，西行经景监求见孝公。[原文与说明](#sj005-163-note)

**卫鞅的登场前事：** 他出自卫国公族的旁支，年轻时研究刑名之学，曾在魏相公叔座门下任中庶子。公叔座病重时，向魏惠王推荐卫鞅；见惠王没有采用的意思，又主张如果不用，就不要放他出境。公叔座随后把这些话告诉卫鞅，劝他赶快离开。卫鞅认为，惠王既不肯听推荐他的话，也未必会听杀他的话，因而没有立即逃走。公叔座死后，卫鞅听到秦孝公求贤，才转往秦国。[原文与说明](#note-1)

**求见孝公也经历了几次转折。** 卫鞅最初讲古代帝王的理想，未能打动孝公；转而讲如何增强现实国力，孝公才越来越有兴趣，与他谈了多日。卫鞅的才能由此有了施展机会。[原文与说明](#note-1)

<a id="event-2"></a>

2. **秦军向东围陕，向西攻击獂。** 孝公的求贤与军事行动并行，本纪记东围陕城、西杀獂王。两条战线分别存在，不连成一场贯通东西的大战。 [原文与说明](#sj005-164-note)

<a id="event-3"></a>
### 3｜魏国夺取赵国皮牢

**魏国进攻赵国，夺取皮牢。** 秦国开始新君执政，并没有使魏赵之间的土地争夺停下来。[原文与说明](#note-2)

<a id="event-4"></a>
<a id="sj015-0361-hanzhao"></a>
### 4｜韩、赵联合攻秦

**韩国与赵国共同进攻秦国。** 前一年赵成侯、韩昭侯曾在上党会面，今年两国又共同出兵，但史料没有留下两件事之间的具体决策过程，也没有明载本次攻秦的胜负。[原文与说明](#note-3)

<a id="event-5"></a>
### 5｜西方出现彗星

**这一年出现彗星，秦国的记录特别指出它见于西方。** 彗星与新君元年同见于记录，只说明古人把天象一并记下，不能据此解释孝公政治选择的原因。[原文与说明](#note-4)

<a id="event-6"></a>
<a id="sj015-0361-daliang"></a>
### 6｜魏国由安邑迁都大梁（暂系本年）

**魏国把都城从安邑迁到大梁。** 自此以后，“梁”也越来越常被用来称呼魏国，惠王因而又称梁惠王。魏国在黄河东西两侧的战争与经营仍将继续，迁都并不意味着当年就把原有西部土地全部放弃。[原文与说明](#note-5)

<a id="note-1"></a>
### 1｜卫鞅在魏前事与入秦时的多次求见

[《商君列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7068.md#ref-4c6cbfbb44a2d4)：“商君者，卫之诸庶孽公子也，名鞅，姓公孙氏……鞅少好刑名之学，事魏相公叔座为中庶子。”继叙病中荐才与劝杀、卫鞅未走，再接“公叔既死，公孙鞅闻秦孝公下令国中求贤者……乃遂西入秦，因孝公宠臣景监以求见孝公”。正文在人物入秦处补这些有据的此前经历；它们不是全部发生在前361年，也没有据此给卫鞅计算出生年。

列传随后区分几次相见：先说帝道、再说王道，再以霸道渐得认可，最后以强国之术与孝公长谈。本文保留由不合意到认可的过程，不将说辞当作逐字实录。景监的作用是引见，没有证据据此追加其早年官历。公叔座与其他传文中的公叔痤、公孙痤有异称；[少梁俘将](bce-0362.md#note-1)和此处病荐之间，没有足够材料补出“秦释放他以后”一段经过。

入秦与议法、任官、受封依相对进程分别阅读：[前359年](bce-0359.md)接议法，后来的变法与封商不搬到本年。

<a id="note-2"></a>
### 2｜皮牢的前362、361年异记

[卷015本年魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0361)：“十。取赵皮牢。”[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-92aa2c25a16700)惠王十年同记“伐取赵皮牢”。[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-c310ce03c9669f)却在成侯十三年即前362年接浍败记“取皮牢”。本文暂依年表格与魏世家置本年，赵世家的前一年异记留在同号说明，不再在前362年重复生成另一场取皮牢。

原表魏“十”与已采用惠王前369年元年相差一年；校订君年后本年为惠王九年。本文沿事件的周、秦年条位置，不将原格所有内容随数字整体平移。

<a id="note-3"></a>
### 3｜韩赵攻秦有明确赵君年

《赵世家》成侯十四年：“十四年，与韩攻秦。”对应前361年；成侯十三年上党会已经在前362年。本文只接出两国连续往来的事实，不把会面解释为已确证的秘密军事盟约。原表赵栏“十四”只列王年，攻秦来自世家补缺。

<a id="note-4"></a>
### 4｜彗星与卫燕元年：原表三栏逐项处理

卷015秦栏“秦孝公元年。彗星见西方”；魏世家惠王十年也有“彗星见”，没有给方向。正文合为本年彗星记录，不另算秦魏各见一颗不同彗星，也不推定其现代名称、轨道或精确日期。

<a id="sj015-0361-succession"></a>
魏栏同时记“卫成侯元年”，燕栏记“燕文公元年”。两君承位与父辈去世已经在[前362年](bce-0362.md#event-4)，本年记新君元年，不再重复一次登位。《卫康叔世家》又把公孙鞅入秦放在成侯十一年，与本纪、年表链不合，此处不据该数推迟卫鞅入秦十年。

本年周、韩、赵、楚、齐原格仅列王年；齐旧“十八”不能用作齐威王实际已在位十八年的证明。秦本纪列举东方君号有后称、错位，已在既有同号说明保留，不用一段局势介绍重定各国全表。

<a id="note-5"></a>
### 5｜迁大梁暂用惠王九年说，保留六年等异说

[《魏世家·集解》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-7af7a647cf05ba)引《纪年》：“梁惠成王九年四月甲寅，徙都大梁。”按本项目采用惠王前369年元年，九年对应前361年，本页暂据此安放迁都。古四月、甲寅原样保留，不直接换成公历某月某日。

同一《魏世家》正文把迁都接在惠王三十一年秦、赵、齐进攻之后，索隐还反对《纪年》的九年说；[《古本竹书纪年辑校》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%A4%E6%9C%AC%E7%AB%B9%E6%9B%B8%E7%B4%80%E5%B9%B4%E8%BC%AF%E6%A0%A1.md#ref-6c5d931988f145)收录《水经注》与《汉书》旧注的六年说，同时列明集解所引九年异文。六年按同一元年链对应前364年。两说不是同一日期的不同写法，当前不能声称已经排除其他系年。

本页采用早迁说，是依据可复查的《纪年》引文以及后续大梁活动的相容性；原世家把西部受秦压力、东部作战与迁都相接的整体因果，不能全部倒搬到前361年。此条不属于卷015本年格中的原文，待后续卷044整卷处理时继续检验，详见[本批魏都考证](../../meta/考证/史记-卷015-前0366至0347纪年补核.md#魏都与战事)。

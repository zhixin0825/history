# 公元前362年｜秦在少梁击败魏军，献公同年去世

[← 公元前363年](bce-0363.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前361年 →](bce-0361.md)

> 当前页面整理已有史料，不表示这一年全部国家和全部史书均已覆盖。

**周显王七年；秦献公二十三年；赵成侯十三年**

## 本年纪事

<a id="event-1"></a>

1. **秦在少梁击败魏军，献公同年去世。** 秦取得重要俘虏，随后献公的儿子孝公继位。后者继承的是已经恢复部分主动权、却仍面对魏国强势边防的国家。 [原文与说明](#sj005-162-note)

**被俘的魏将为公孙痤；秦方这次出兵又见庶长国领兵的记载。** 孝公接位后，将继续以争回失地、增强国家力量为目标。[原文与说明](#note-1)

<a id="event-2"></a>
### 2｜魏军在浍击败韩、赵

**同一年，魏国在浍一线击败韩国和赵国的军队。** 魏军西面败给秦国，在另一条战线上却仍能取胜，三晋间的联合和相互战争并未停止。[原文与说明](#note-2)

<a id="event-3"></a>
<a id="sj015-0362-han"></a>
### 3｜赵成侯与韩昭侯在上党会面

**赵成侯与韩昭侯在上党会面。** 昭侯在这时已经作为韩国君主参与外交，韩、赵继续维持联系。[原文与说明](#note-3)

<a id="event-4"></a>
### 4｜卫、燕更换君主

**卫声公去世，儿子成侯继位；燕桓公也在这一年去世，文公接位。** 两国的新君从[下一年](bce-0361.md#sj015-0361-succession)开始记元年。[原文与说明](#note-4)

<a id="event-5"></a>
### 5｜韩国连续降大雨

**韩国有持续三个月的大雨。** [原文与说明](#note-5)

## 本年相关史料

<a id="sj005-162-note"></a>
### sj005-162｜秦在少梁击败魏军，献公同年去世。

[卷005 P050](../../sources/摘录/史记-卷005-秦本纪.md#p050)。

**说明：**本纪俘将“公孙痤”，年表说虏魏太子，身份记法不同，正文不把两者当成两位同时获俘者。本纪献公二十四年卒与年表二十三年止、次年孝公元年不合，采用前362衔接；“已二十一岁”保留为本纪年龄。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="note-1"></a>
### 1｜少梁的俘虏与献公终年

[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0362)：“二十三。与魏战少梁，虏其太子”；魏栏“九。与秦战少梁，虏我太子”。[《秦本纪》](https://zh.wikisource.org/wiki/史記/卷005#秦獻公)与[《魏世家》](https://zh.wikisource.org/wiki/史記/卷044#魏惠王)均作公孙痤；[《通鉴》显王七年](https://zh.wikisource.org/wiki/資治通鑑/卷002)同样写获魏公孙痤。本文据这些叙事写俘将，保留年表“太子”异文，不替原表改字，也不凭异文多造一名被俘太子。

[《赵世家》成侯十三年](https://zh.wikisource.org/wiki/史記/卷043#趙成侯)：“秦献公使庶长国伐魏少梁，虏其太子、痤。”这一文本及其断句又有不同身份呈现，只据其中明确的领兵者补入庶长国。《魏世家》还接“取庞”，但句中取地的主语承接不够明白，本文保留此条互见，不据它另增一个明确的秦取城事件。

献公死亡原本纪作二十四年，年表却以二十三年为止、次年孝公元年；魏、燕世家把献公卒与这一年联系。本文维持既有前362年死亡、前361年孝公元年的衔接，二十一岁为古书年龄说，不换算成精确生日或周岁。

<a id="note-2"></a>
### 2｜韩、赵两栏合并为浍之役

原表韩栏“九。魏败我于浍”，赵栏“十三。魏败我于浍”。《魏世家》惠王九年也记“伐败韩于浍”，《赵世家》成侯十三年记“魏败我浍”。合并为同年浍之役，不因各国分别记败仗而重复计数。原表魏栏只记少梁，不表示魏国该年只打了一场仗。

所读《通鉴》网页在本年又补入公叔痤论赏长段，校刊记8明言来自《战国策·魏策一》。这段功劳分配说辞不是卷015原表文字，本页未把其中授田数字扩写为已独立核实的战后统计。

<a id="note-3"></a>
### 3｜昭侯在上党出现，不沿旧表再造元年

《赵世家》在成侯十三年接记：“成侯与韩昭侯遇上党。”本年归属取赵国相对年次。昭侯的继位与元年，卷015旧表拖到[前358年](bce-0358.md#note-2)，现代校订常提前；[前363年同项说明](bce-0363.md#note-2)已登记懿侯终年与既有君年链的一年差。正文只写本年有据的会面，不补未经记载的“密谋伐秦”或新君即位仪式。次年韩、赵攻秦另在[前361年](bce-0361.md#sj015-0361-hanzhao)。

<a id="note-4"></a>
### 4｜卫、燕的死亡与次年元年

[《卫康叔世家》](https://zh.wikisource.org/wiki/史記/卷037#衞聲公)：“声公十一年卒，子成侯遫立。”《通鉴》显王七年作成侯速，“遫／速”保留异写，正文不用姓名校订补出生平。[《燕召公世家》](https://zh.wikisource.org/wiki/史記/卷034#燕釐公、桓公)：“桓公十一年卒，文公立。是岁，秦献公卒。”本表前361年分别列卫成侯、燕文公元年，与今年承位可相衔接。

<a id="note-5"></a>
### 5｜“大雨三月”的读法

卷015韩栏在浍败之后又记“大雨三月”；[《韩世家》集解](https://zh.wikisource.org/wiki/史記三家註/卷045)在懿侯九年浍败下引徐广“大雨三月也”。本文读作大雨持续三个月，不改成公历三月某一天，也不推定全国相同降雨量。周、楚、燕、齐原表本年其余格只有王年。

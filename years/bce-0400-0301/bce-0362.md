## 归年与考证

<a id="sj005-162-note"></a>
<a id="sj005-162秦在少梁击败魏军献公同年去世"></a>
#### sj005-162｜秦在少梁击败魏军，献公同年去世。

[卷005 P050](../../sources/摘录/史记-卷005-秦本纪.md#p050)。

**说明：**本纪俘将“公孙痤”，年表说虏魏太子，身份记法不同，正文不把两者当成两位同时获俘者。本纪献公二十四年卒与年表二十三年止、次年孝公元年不合，采用前362衔接；“已二十一岁”保留为本纪年龄。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="note-1"></a>
<a id="1少梁的俘虏与献公终年"></a>
#### 1｜少梁的俘虏与献公终年

[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0362)：“二十三。与魏战少梁，虏其太子”；魏栏“九。与秦战少梁，虏我太子”。[《秦本纪》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7005.md#ref-4389c386926ef7)与[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-4d063b80bff5cd)均作公孙痤；[《通鉴》显王七年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-9de7128024bca6)同样写获魏公孙痤。本文据这些叙事写俘将，保留年表“太子”异文，不替原表改字，也不凭异文多造一名被俘太子。

[《赵世家》成侯十三年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-b494ac265e8c5b)：“秦献公使庶长国伐魏少梁，虏其太子、痤。”这一文本及其断句又有不同身份呈现，只据其中明确的领兵者补入庶长国。《魏世家》还接“取庞”，但句中取地的主语承接不够明白，本文保留此条互见，不据它另增一个明确的秦取城事件。

献公死亡原本纪作二十四年，年表却以二十三年为止、次年孝公元年；魏、燕世家把献公卒与这一年联系。本文维持既有前362年死亡、前361年孝公元年的衔接，二十一岁为古书年龄说，不换算成精确生日或周岁。

<a id="note-2"></a>
<a id="2韩赵两栏合并为浍之役"></a>
#### 2｜韩、赵两栏合并为浍之役

原表韩栏“九。魏败我于浍”，赵栏“十三。魏败我于浍”。《魏世家》惠王九年也记“伐败韩于浍”，《赵世家》成侯十三年记“魏败我浍”。合并为同年浍之役，不因各国分别记败仗而重复计数。原表魏栏只记少梁，不表示魏国该年只打了一场仗。

所读《通鉴》网页在本年又补入公叔痤论赏长段，校刊记8明言来自《战国策·魏策一》。这段功劳分配说辞不是卷015原表文字，本页未把其中授田数字扩写为已独立核实的战后统计。

<a id="note-3"></a>
<a id="3昭侯在上党出现不沿旧表再造元年"></a>
#### 3｜昭侯在上党出现，不沿旧表再造元年

《赵世家》在成侯十三年接记：“成侯与韩昭侯遇上党。”本年归属取赵国相对年次。昭侯的继位与元年，卷015旧表拖到[前358年](bce-0358.md#note-2)，现代校订常提前；[前363年同项说明](bce-0363.md#note-2)已登记懿侯终年与既有君年链的一年差。正文只写本年有据的会面，不补未经记载的“密谋伐秦”或新君即位仪式。次年韩、赵攻秦另在[前361年](bce-0361.md#sj015-0361-hanzhao)。

<a id="note-4"></a>
<a id="4卫燕的死亡与次年元年"></a>
#### 4｜卫、燕的死亡与次年元年

[《卫康叔世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-629f2414d371e9)：“声公十一年卒，子成侯遫立。”《通鉴》显王七年作成侯速，“遫／速”保留异写，正文不用姓名校订补出生平。[《燕召公世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7034.md#ref-67d15e13ea2909)：“桓公十一年卒，文公立。是岁，秦献公卒。”本表前361年分别列卫成侯、燕文公元年，与今年承位可相衔接。

<a id="note-5"></a>
<a id="5大雨三月的读法"></a>
#### 5｜“大雨三月”的读法

卷015韩栏在浍败之后又记“大雨三月”；[《韩世家》集解](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7045.md#ref-d63e030a2803b9)在懿侯九年浍败下引徐广“大雨三月也”。本文读作大雨持续三个月，不改成公历三月某一天，也不推定全国相同降雨量。周、楚、燕、齐原表本年其余格只有王年。

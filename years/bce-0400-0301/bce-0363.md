# 公元前363年｜秦攻少梁，赵国再次出兵救魏

[← 公元前364年](bce-0364.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前362年 →](bce-0362.md)

**周显王六年；秦献公二十二年；赵成侯十二年**

## 本年纪事

<a id="event-1"></a>
### 1｜秦军攻向少梁，赵国援助魏国

**秦国进攻魏国少梁，赵国出兵救魏。** 上一年秦军在石门获胜、赵国在石阿救魏之后，秦魏战争继续展开。少梁已成为秦魏争夺的重要据点，[下一年](bce-0362.md#event-1)，秦魏还会在少梁交战。[原文与说明](#note-1)

## 本年相关史料

<a id="note-1"></a>
### 1｜原表只列年数，世家补出少梁救援

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0363)均只有王年，没有事件文字。[《赵世家》成侯十二年](https://zh.wikisource.org/wiki/史記/卷043#趙成侯)却明记：“十二年，秦攻魏少梁，赵救之。”按成侯前374年元年，为前363年，故本页有实质史事，不是为凑连续年份而设空页。

前一年该书记“秦攻魏，赵救之石阿”；次年又记秦使庶长国伐魏少梁、俘人。三条有连续君年，本文分别保留各年行动；没有把本年的救援写成次年俘将战的完整战术过程，也不声称一次围城恰好持续整年。

<a id="note-2"></a>
### 2｜韩懿侯终局的旧年与校订年

[《韩世家》](https://zh.wikisource.org/wiki/史記/卷045#韓懿侯)以懿侯十二年记“懿侯卒，子昭侯立”；原表则到[前358年](bce-0358.md#note-2)才列昭侯元年。《赵世家》在[前362年](bce-0362.md#sj015-0362-han)已经写“成侯与韩昭侯遇上党”，与旧表昭侯元年明显不合。

所读[《通鉴》网页](https://zh.wikisource.org/wiki/資治通鑑/卷002)显王六年增加“韩懿侯薨，子昭侯武立”，校刊记7明确说是将旧显王十年的文字依近人考证移到本年，不能称作司马光原有的这一年条。前轮已采用懿侯前373年元年的暂行衔接，与十二年卒又存在一年差。本文先确定昭侯在前362年已经出现于外交活动，不用未闭合的君年算术强定本年死亡，更不在前358年让昭侯再次即位。

<a id="note-3"></a>
### 3｜宋君更替仍不据增补网页强定

同一《通鉴》网页把宋休公卒、桓公辟兵立移入本年，校刊记6明言是依近人考证移年、改名。卷015此前[前372年](bce-0372.md)的宋辟公元年、[前369年](bce-0369.md)的宋剔成元年，已经登记君次冲突。相关完整年链尚未独立复核，本页保留这个待考落点，不额外宣布一次确定的宋君更替。此项与韩国更替都不是原表前363年格中的文字。

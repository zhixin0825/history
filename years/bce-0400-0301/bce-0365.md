## 归年与考证

<a id="note-1"></a>
<a id="1仪台之役与不同君年"></a>
#### 1｜仪台之役与不同君年

[卷015本年魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0365)：“六。伐宋，取仪台。”[《魏世家》惠王六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-735d30b5917755)：“六年，伐取宋仪台。”[三家注](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-7c6defb3b46b9f)集解保存“义台”异写。

[《通鉴》卷二](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-64df2cb3067321)显王四年旧文记“魏伐宋”；网页将“取仪台”放入增补括号，篇末校刊记5说明补自《史记》有关材料。本文的夺取地点直接据卷015及魏世家，不把现代增补当作司马光原文。

本页沿用显王四年归前365年。按已采用的惠王前369年元年，本年为惠王五年；保留原表“六”作为旧年链，战事不因君年校正而自动移位。

<a id="note-2"></a>
<a id="2赵取卫甄与前370年伐齐甄应分别记载"></a>
#### 2｜赵取卫甄与前370年伐齐甄应分别记载

[《赵世家》成侯十年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-2e8512a5dbf7e3)：“十年，攻卫，取甄。”成侯前374年元年，对应前365年。该书成侯五年另记“伐齐于鄄”，卷015写作“甄”，已经归在[前370年](bce-0370.md)。两条的相对年份和交战对象都不同，当前不把它们合成一场战争，也不凭同名字形补造其间领土交割过程。

<a id="note-3"></a>
<a id="3其余七栏"></a>
#### 3｜其余七栏

本年原表只有魏栏记具体事件，周、秦、韩、赵、楚、燕、齐七栏均仅列王年。赵取甄是互见世家补入，未添加为原表伪原文。齐栏“十四”等旧数继续保留在来源表中，正文君次仍依[田齐前期补核](../../meta/考证/史记-卷015-田齐前期君次补核.md)。

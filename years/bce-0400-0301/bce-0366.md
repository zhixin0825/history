## 归年与考证

<a id="note-1"></a>
<a id="1宅阳会面与洛阴战事"></a>
#### 1｜宅阳会面与洛阴战事

[卷015本年原表](../../sources/摘录/史记-卷015-六国年表.md#y0366)：秦栏“十九。败韩、魏洛阴”；魏栏“五。与韩会宅阳”。[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-710f8fc9671da3)惠王五年连记“与韩会宅阳。城武堵。为秦所败”；[《韩世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7045.md#ref-9a262d6bc22139)懿侯五年也记宅阳会。

**地名：**《通鉴》显王三年旧文作“洛阳”；[所读网页](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-1c5353a8f897c4)以“洛〔阴〕（阳）”显示校订，篇末校刊记4说明依据《六国年表》改为洛阴。本文采用与卷015、魏世家集解互合的洛阴，不径说秦军此时已打到周王所在的洛阳。宅阳与洛阴是两个地名，史料没有给出会面、交战的月日顺序。

**纪年：**本页按周显王三年、秦献公十九年的年条归于前366年。项目已用魏惠王前369年元年，故本年为惠王四年；原表的“五”和《韩世家》的“五”仍照录，不能反过来取消前轮对魏、韩君次的校订，也不据单一君年把整场战争机械平移。参看[前轮韩魏考证](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#韩魏)。

<a id="note-2"></a>
<a id="2武都与武堵"></a>
#### 2｜武都与武堵

卷015魏栏接记“城武都”，《魏世家》作“城武堵”。正文用世家“武堵”，原表字样保持不动。当前证据不足以据“武都”两个字就认作后世陇南武都郡，也不能凭秦魏交战推定修城一定发生在战败以后。

<a id="note-3"></a>
<a id="3阿下之战来自赵世家"></a>
#### 3｜阿下之战来自赵世家

[《赵世家》成侯九年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-fa594894be6677)：“九年，与齐战阿下。”按本项目沿用的成侯前374年元年，为前366年；这是世家补入的史事，不是卷015赵栏原有文字。此前[前370年攻甄](bce-0370.md)、[前368年进抵长城](bce-0368.md)各有自己的年页，不重复算作本年行动。

<a id="note-4"></a>
<a id="4本年八栏的阅读范围"></a>
#### 4｜本年八栏的阅读范围

卷015周、秦、魏、韩、赵、楚、燕、齐八栏已逐格核对。除上列秦、魏事件外，其余原格只列王年；齐栏“十三”仍是旧威王年链，不能据此让齐威王提前执政。田午之前的漏代及现行君次见[田齐补核](../../meta/考证/史记-卷015-田齐前期君次补核.md)。

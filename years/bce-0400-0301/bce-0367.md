# 公元前367年｜韩赵分周，东西两个周国并立

[← 公元前368年](bce-0368.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已有年页：公元前364年 →](bce-0364.md)

**周显王二年；本表八栏只列王年**

## 本年纪事

<a id="event-1"></a>
### 1｜周公一支的争位，引来韩赵分地

**在韩、赵干预下，周公一支原有的领地分成东西两部分，形成东周、西周两个小国。** 这不是春秋结束后又重新发生一次周平王东迁，也不是周天子同时变成两个。[原文与说明](#note-1)

**此前的家族前情：** 周考王曾封弟弟于河南，让他接续周公职事。此后传到威公；威公死后，两个儿子争夺继承地位，少子一支得到外力支持，另立在巩地。两支君主都出自周王族，却与当时的周显王不属同一个职分。[原文与说明](#note-2)

**周天子保留王号，身边的土地和政治事务却越来越受这两个小国及外部强国牵制。** 分立后的“东周君”“西周君”不是周天子的另两个称号，后续朝聘、借兵与亡国记载应分别追踪。[原文与说明](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜表中只列数字，别书却有可归年的事件

[卷015本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0367)全为王年；[《赵世家》成侯八年](https://zh.wikisource.org/wiki/史記/卷043#趙成侯)明记“与韩分周以为两”，成侯前374年元年对应前367年。[《通鉴》卷二显王二年](https://zh.wikisource.org/wiki/資治通鑑/卷002)亦有分周条。原表不补伪原文，正式史事仍汇入这一张年份页。

攻周在成侯七年，已在[前368年](bce-0368.md#event-4)，与分周不是重复记同一动作。本文只沿这一明确相对年次，不为战争编造具体围城日、兵力或合约全文。

<a id="note-2"></a>
### 2｜天子、周公支系与两个惠公

[《周本纪》及三家注](https://zh.wikisource.org/wiki/史記三家註/卷004)在考王封弟以后连述桓公、威公、惠公和巩地分封；这是一段跨代后叙，不能全部放在考王封弟的同一年。本文以《赵世家》的分周君年确定主要落点。

有关另立者的亲属，部分旧注读为惠公的少子；[《韩非子·内储说下六微》](https://zh.wikisource.org/wiki/韓非子/內儲說下六微)却记周太子公子朝与弟公子根、君死后分国。辛德勇[《多余的周国之君》](https://finance.sina.com.cn/jjxw/2022-04-29/doc-imcwiwst4667146.shtml)结合《汉书·古今人表》及杨宽相关考证，支持两位惠公为威公两子。正文采用这一兄弟争位解释，旧注父子读法仍保留，不称所有版本一致。朝、根、班等名字的完整对应及威公死亡的绝对年，本轮没有另行定案。[本批考证](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#东西周)。

战国的两个周国与历史分期的“西周、东周”是两套含义；此时的天子仍是显王，不因分周便另造一次王朝更替。原文关于“奉王”的叙述也不足以复原每一项封国边界和实际政令权限。

<a id="note-3"></a>
### 3｜本年的雨金异年只作回链

《秦本纪》献公十八年所记雨金，按其年链对应本年；原有编年已用年表十七年即[前368年](bce-0368.md#sj005-160-note)作为主体，并保留差别。此页不另记第二次降物。

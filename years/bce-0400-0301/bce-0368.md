# 公元前368年｜齐魏赵交战，韩赵介入周国内争

[← 公元前369年](bce-0369.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前367年 →](bce-0367.md)

**周显王元年；秦献公十七年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **栎阳出现被记录为“雨金”的现象。** 古书以异常见闻的方式保存这件事。这里不把“金”未经分析就认作现代化学意义的黄金降雨。 《封禅书》记秦献公以雨金为祥瑞，于栎阳作畦畤祭白帝。 [[1]](#note-1)

<a id="event-2"></a>

2. **齐军进攻魏国，夺取观地。** 魏国刚经历争位和韩赵围攻，又受到东方齐国进攻。 [[2]](#note-2)

<a id="event-3"></a>

3. **赵军侵入齐国，推进到长城一带。** 齐国向魏取得土地时，也要应对来自赵国的军事压力。 [[3]](#note-3)

<a id="event-4"></a>

4. **赵、韩联合进攻周地，介入周公一支的内部争端。** 这场行动随后发展为分周，结局接到下一年。 [[4]](#note-4)

<a id="event-5"></a>

5. **周显王开始以元年纪事。** 他在前一年兄长烈王去世后承位；如今王室的名义地位仍在，周地内部却正在受诸侯干预。 [[5]](#note-5)

## 归年与考证

<a id="sj005-160-note"></a>
<a id="1雨金旧条与异年"></a>
#### 1｜“雨金”旧条与异年

[卷005 P050](../../sources/摘录/史记-卷005-秦本纪.md#p050)。本纪十八年与[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0368)十七年相差一年；年表还记四月至八月。仍用前368年主述，保留本纪对应前367年的差别，不在那里再写一次同样降物。此处现代物质来源未定，月份、干支未独立转换。


<a id="2取观与观津"></a>
#### 2｜取观与观津

卷015魏栏“齐伐我观”、齐栏“伐魏取观”为同役；[《通鉴》卷二显王元年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-62be2140eca9d4)写取观津。正文先用原表的观地，地名详略留注，不据一个津字扩造另一战役或未经考定的渡河路线。


<a id="3抵达长城不等于取得整条长城"></a>
#### 3｜抵达长城，不等于取得整条长城

卷015赵栏“侵齐，至长城”，齐栏也有赵来侵；[《赵世家》成侯七年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-bb5fdf19b380cd)同用至长城。《通鉴》所读校订页将旧“取”改作“至”。正文采用能共同支持的进抵，不写成整条齐长城被赵永久占领；原文也没有给出墙段长度和准确位置。


<a id="4攻周与分周是相邻两年的动作"></a>
#### 4｜攻周与分周是相邻两年的动作

《赵世家》成侯七年“与韩攻周”，八年“与韩分周以为两”，据本批成侯元年链分别归前368、367。《通鉴》校订页把威公卒、家族争立放在本年，其他整理对威公死亡年有不同安排；本页只主述有明确赵国君年的进攻，争立前情集中在[前367年](bce-0367.md#event-1)，不把威公的死亡硬定两次。


<a id="5显王元年"></a>
#### 5｜显王元年

卷015周栏“显王元年”接前369年既有的烈王死亡。周天子的显王与后来两个周国的惠公是不同身份，不把三个名号都看成天子轮番改号。

# 公元前369年｜韩赵围魏君，周烈王去世

[← 公元前370年](bce-0370.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前368年 →](bce-0368.md)

**周烈王七年（本纪年数有异）**

## 本年纪事

<a id="event-1"></a>
1. **烈王去世，弟弟扁继位，是为显王。** 以后显王任内的诸侯会见、赐胙与秦国地位上升，按这一继承接续，而不将后面全部推迟三年。[原文与说明](#note-1)

<a id="event-2"></a>
2. **秦献公时期，桃树冬季开花。** 本纪在献公十六年留下这条异常物候记录，没有把它解释成随后战争胜负的确定征兆。[原文与说明](#sj005-159-note)

<a id="event-3"></a>
3. **秦国发生大疫，又有日食记录。** 记载没有给出疫病种类和死亡人数；疫病、日食与冬桃开花各自保存，不直接构成同一因果解释。[原文与说明](#note-3)

<a id="event-4"></a>
4. **楚国开始按宣王良夫元年纪事。** 前一年肃王死后已经由弟弟良夫承位，本年是新君计年的起点。[原文与说明](#note-4)

<a id="event-5"></a>
5. **魏军在马陵击败韩军。** 这场魏韩交战的记载，与本年韩、赵介入魏国争位须分别阅读，短句没有说明两场战斗的确切先后。[原文与说明](#note-5)

<a id="event-6"></a>
<a id="sj015-zhuoze"></a>
### 6｜魏国争位引来韩、赵军队

**魏国大夫王错出奔韩国，公孙颀又劝韩国利用魏国的争位局面出兵。** 韩懿侯与赵成侯联合进攻，在浊泽击败魏军，把魏君罃包围起来。前一年武侯去世后的继承争执，至此变成几国共同参与的战争。[原文与说明](#note-6)

**韩、赵虽然同来，却想要不同的战后安排。** 赵方主张除去罃、改立公中缓，再割取土地；韩方则认为这样仍会留下魏国，不如将魏一分为二，使其不再成为强敌。双方没有谈拢，韩军夜间撤去，赵军也撤退，罃得以保住君位，成为后来所称的魏惠王。[原文与说明](#note-6)

## 本年相关史料

<a id="note-1"></a>
<a id="sj004-369-1"></a>
### 1｜保留烈王死亡的旧年次取舍

[卷004 P068](../../sources/摘录/史记-卷004-周本纪.md#p068)作烈王“十年”崩；卷015只列七年，下一年起显王元年。秦、魏等同步年条采用后者，前369为烈王七年终。原文“十年”保留，不以笼统“史记如此”拒绝处理同书矛盾。原事件1与显式锚点不删。

<a id="sj005-159-note"></a>
### 2｜冬桃开花的旧记录

[卷005 P050](../../sources/摘录/史记-卷005-秦本纪.md#p050)。原有事件2及出处保留；献公十六年沿现用秦年链归本年。古月、物候记录未独立复测，不把异常开花作为政治预兆的现代证据。

<a id="note-3"></a>
### 3｜疫病与日食

[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0369)“民大疫。日蚀”是此次增补；没有据“疫”指定传染病名称，也未换算人口损失。日食未独立历算，不照抄网页推算时刻为本项目计算结果。

<a id="note-4"></a>
### 4｜楚宣王元年

卷015楚栏与[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-9797826e10eed3)相接，父兄的死亡和继位过程见[前370年事件3](bce-0370.md#event-3)。此处肃王是宣王兄长，不将两王写成父子。

<a id="note-5"></a>
### 5｜本年的马陵不是孙膑败庞涓之战

卷015魏、韩两栏分别记败韩、魏败我马陵，是同一条战果；《韩世家》也以旧懿侯二年记此事。正文先沿本表前369年的编年位置保存，但韩国元年改订不等于已经核定该战的独立年月，不将全部战事随君年机械前移。

此战是魏胜韩，与前341年齐军击败魏军的著名马陵之战不同，不能混入孙膑、庞涓的故事。同名地点是否完全相同、以及与本年浊泽战事如何先后衔接，未由这几句短记确定。

<a id="note-6"></a>
### 6｜浊泽之战与魏惠王初立

[卷015赵栏](../../sources/摘录/史记-卷015-六国年表.md#y0369)“败魏涿泽，围惠王”、[《赵世家》成侯六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-107147c70481fc)及[《通鉴》烈王七年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7001.md#ref-498d9cddcedfa7)提供本年落点；[《魏世家》及三家注](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-58acb8794d040b)详载韩、赵两种处置方案。涿泽、浊泽等字样保留在来源，不另立两场围君之战。

《魏世家》劝韩的说辞称罃得到王错支持，集解引《纪年》又记王错出奔韩；正文按《通鉴》保留出奔，未给这一变化补出确切日期和秘密动机。《纪年》引文的取地名、围城主体及公中缓活动年次，与世家不是处处一致，详见[本批考证](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#韩魏)。

本批以武侯前370年卒、本年罃稳位并计元为主线，表内旧“惠王二年”仍保留。韩、赵分歧救了罃，是所传叙事对结果的解释，不当成所有参战者动机已获独立证明；太史公“无适子，其国可破”的评论留在史料层，不添成另一件本年事件。

<a id="sj015-0369-song"></a>
### 7｜宋剔成元年保留待核

本年齐栏“宋剔成元年”与[前372年宋辟公元年](bce-0372.md#sj015-0372-song)同属尚未完成的宋君年链问题。本批只登记原格与互见，不擅自确定剔成的身世、发动一次有确年的夺位，或把辟公与剔成无条件并为一人。

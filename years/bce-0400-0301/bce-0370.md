# 公元前370年｜齐桓公朝周，魏楚两国君主去世

[← 公元前371年](bce-0371.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前369年 →](bce-0369.md)

**周烈王六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **齐桓公田午到周王室朝见。** 当时周室衰弱，诸侯很少亲来，齐君的举动受到称许。名义上仍然共尊周王，与各国实际上自立其政并存。 [[1]](#note-1)

<a id="event-2"></a>

2. **赵军攻齐到鄄，随后又在怀地被魏军击败。** 这是同一年里不同方向的战争，不是把齐军与魏军都合成一支阻击赵国的军队。 [[2]](#note-2)

<a id="event-3"></a>

3. **楚肃王无子而卒，弟弟熊良夫继为宣王。** 肃王在位十一年，王位转到弟弟，下一年前369年开始宣王元年。 [[3]](#note-3)

<a id="event-4"></a>
<a id="sj015-0370-wei"></a>

4. **魏武侯去世，公子罃与公中缓争夺继承权，魏国陷入内争。** 武侯没有安排好明确的太子继承，两个争位者各自争取支持，邻国也开始寻找介入的机会。 [[4]](#note-4)

### 4. 魏武侯去世，公子罃与公中缓争夺继承权，魏国陷入内争

[返回正文第4条](#event-4)

**[史记三家注](../../sources/史记三家注/卷044.md#p27)**

> 惠王元年，初，武侯卒也，子罃與公中緩〔正義〕中音仲。争爲太子。公孫頎〔索隱〕音祈。自宋入趙，自趙入韓，謂韓懿侯〔索隱〕哀侯之子。曰：「魏罃與公中緩争爲太子，〔索隱〕按：紀年「武侯元年封公子緩。趙侯種、韓懿侯伐我，取蔡，而惠王伐趙，圍濁陽。七年，公子緩如邯鄲以作難」，是說此事矣。君亦聞之乎？今魏罃得王錯，〔集解〕徐廣曰：「汲冢紀年惠王二年，魏大夫王錯出奔韓也。」挾上黨，固半國也。因而除之，〔集解〕徐廣曰：「除，一作『倍』。」〔正義〕按：除，除魏罃及王錯也。破魏必矣，不可失也。」懿侯說，乃與趙成侯〔索隱〕系本云：「成侯名種。」合軍并兵以伐魏，戰于濁澤，〔集解〕徐廣曰：「長社有濁澤。」魏氏大敗，魏君圍。趙謂韓曰：「除魏君，立公中緩，割地而退，我且利。」韓曰：「不可。殺魏君，人必曰暴；割地而退，人必曰貪。不如兩分之。魏分爲兩，不彊於宋、衞，則我終無魏之患矣。」趙不聽。韓不說，以其少卒夜去。惠王之所以身不死，國不分者，二家謀不和也。若從一家之謀，則魏必分矣。故曰「君終無適子，其國可破也」。〔索隱〕此蓋古人之言及俗說，故云「故曰」。

[《魏世家·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-89ff9684b043c5)

## 归年与考证

<a id="1朝周者是田午不提前改成齐威王"></a>
#### 1｜朝周者是田午，不提前改成齐威王

[《通鉴》卷一烈王六年及校刊记31](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7001.md#ref-eb6e454e29ac8e)把旧文“威王”校作“桓公”。本项目上一批已据《纪年》及现代研究补回田侯剡，田午元年在前374年，故此时尚非齐威王。正文沿这套一致君次；源表本年齐栏的“九”仍属于旧威王年链，不反改原格。[田齐专题](../../meta/考证/史记-卷015-田齐前期君次补核.md) · [本批续核](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#田齐)。

朝见及其褒评有传世依据，却不足以证明所有诸侯绝对没有派使者；正文只写少见的亲朝，不把褒词量化成外交统计。


<a id="2鄄甄与怀地"></a>
#### 2｜鄄、甄与怀地

[卷015赵、齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0370)均记赵攻甄，赵栏又记魏败我怀；[《赵世家》成侯五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-e9c933b75581b5)与《通鉴》相接，鄄、甄写法另留原文。魏在怀地的战果不重复算入赵对齐之役，也不套用后来会盟于甄的日期。

《赵世家》同一君年又连记攻郑、取地与韩交换长子，发生在韩灭郑之后，其目标和叙次尚需专门辨析；本批不凭“郑”字让旧郑国复生，也不把未核交换细节强加到本表两个明确战事上。


<a id="3楚肃王死亡与宣王元年"></a>
#### 3｜楚肃王死亡与宣王元年

[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-22c52d67868591)肃王十一年卒、无子、弟良夫立，与《通鉴》同年相接；[前369年](bce-0369.md#event-4)才承接宣王元年。两兄弟与前381年楚悼王、吴起的终局分开。


<a id="4魏武侯不在前371370年各死一次"></a>
#### 4｜魏武侯不在前371、370年各死一次

[《魏世家·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-89ff9684b043c5)引《纪年》武侯二十六年卒。结合此前已采用的前395年元年，归前370年；所读《通鉴》校刊记32也把旧烈王五年卒条移到六年。张天翼《魏惠王前元纪年考——兼论魏武侯纪年问题》（2023年第21期）公开摘要同支持魏惠王于烈王七年即位；**本轮只取得该文检索摘要，未取得全文，不引用其未读论证**。详见[本批考证](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#韩魏)。

魏表本年“惠王元年”仍照录为旧系年，正文先写父死、争位，[前369年浊泽之战](bce-0369.md#sj015-zhuoze)与罃稳住君位另接后续。“惠王”作为后称用于识别人，不意味着他本年已经举行称王仪式；其称王与改元另待对应年代处理。

<a id="sj015-0370-han-variant"></a>
<a id="5韩庄侯元年只作异年入口"></a>
#### 5｜韩“庄侯元年”只作异年入口

卷015本年韩栏作“庄侯元年”，《韩世家·索隐》已说明其与懿侯的异称关系。本批实际继承在前374年、元年在前373年，见[前373年注5](bce-0373.md#note-5)，此处不另增加一位韩庄侯。

# 公元前370年｜齐桓公朝周，魏楚两国君主去世

[← 公元前371年](bce-0371.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前369年 →](bce-0369.md)

**周烈王六年**

## 本年纪事

<a id="event-1"></a>
1. **齐桓公田午到周王室朝见。** 当时周室衰弱，诸侯很少亲来，齐君的举动受到称许。名义上仍然共尊周王，与各国实际上自立其政并存。[原文与说明](#note-1)

<a id="event-2"></a>
2. **赵军攻齐到鄄，随后又在怀地被魏军击败。** 这是同一年里不同方向的战争，不是把齐军与魏军都合成一支阻击赵国的军队。[原文与说明](#note-2)

<a id="event-3"></a>
3. **楚肃王去世，弟弟良夫继位，是为楚宣王。** 肃王没有儿子继承，楚王位转到兄弟一支。[原文与说明](#note-3)

<a id="event-4"></a>
<a id="sj015-0370-wei"></a>
4. **魏武侯去世，公子罃与公中缓争夺继承权，魏国陷入内争。** 武侯没有安排好明确的太子继承，两个争位者各自争取支持，邻国也开始寻找介入的机会。[原文与说明](#note-4)

## 本年相关史料

<a id="note-1"></a>
### 1｜朝周者是田午，不提前改成齐威王

[《通鉴》卷一烈王六年及校刊记31](https://zh.wikisource.org/wiki/資治通鑑/卷001)把旧文“威王”校作“桓公”。本项目上一批已据《纪年》及现代研究补回田侯剡，田午元年在前374年，故此时尚非齐威王。正文沿这套一致君次；源表本年齐栏的“九”仍属于旧威王年链，不反改原格。[田齐专题](../../meta/考证/史记-卷015-田齐前期君次补核.md) · [本批续核](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#田齐)。

朝见及其褒评有传世依据，却不足以证明所有诸侯绝对没有派使者；正文只写少见的亲朝，不把褒词量化成外交统计。

<a id="note-2"></a>
### 2｜鄄、甄与怀地

[卷015赵、齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0370)均记赵攻甄，赵栏又记魏败我怀；[《赵世家》成侯五年](https://zh.wikisource.org/wiki/史記/卷043#趙成侯)与《通鉴》相接，鄄、甄写法另留原文。魏在怀地的战果不重复算入赵对齐之役，也不套用后来会盟于甄的日期。

《赵世家》同一君年又连记攻郑、取地与韩交换长子，发生在韩灭郑之后，其目标和叙次尚需专门辨析；本批不凭“郑”字让旧郑国复生，也不把未核交换细节强加到本表两个明确战事上。

<a id="note-3"></a>
### 3｜楚肃王死亡与宣王元年

[《楚世家》](https://zh.wikisource.org/wiki/史記/卷040)肃王十一年卒、无子、弟良夫立，与《通鉴》同年相接；[前369年](bce-0369.md#event-4)才承接宣王元年。两兄弟与前381年楚悼王、吴起的终局分开。

<a id="note-4"></a>
### 4｜魏武侯不在前371、370年各死一次

[《魏世家·索隐》](https://zh.wikisource.org/wiki/史記三家註/卷044)引《纪年》武侯二十六年卒。结合此前已采用的前395年元年，归前370年；所读《通鉴》校刊记32也把旧烈王五年卒条移到六年。张天翼《魏惠王前元纪年考——兼论魏武侯纪年问题》（2023年第21期）公开摘要同支持魏惠王于烈王七年即位；**本轮只取得该文检索摘要，未取得全文，不引用其未读论证**。详见[本批考证](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#韩魏)。

魏表本年“惠王元年”仍照录为旧系年，正文先写父死、争位，[前369年浊泽之战](bce-0369.md#sj015-zhuoze)与罃稳住君位另接后续。“惠王”作为后称用于识别人，不意味着他本年已经举行称王仪式；其称王与改元另待对应年代处理。

<a id="sj015-0370-han-variant"></a>
### 5｜韩“庄侯元年”只作异年入口

卷015本年韩栏作“庄侯元年”，《韩世家·索隐》已说明其与懿侯的异称关系。本批实际继承在前374年、元年在前373年，见[前373年注5](bce-0373.md#note-5)，此处不另增加一位韩庄侯。

## 归年与考证

<a id="1魏楚两栏是同一场取地战争"></a>
#### 1｜魏、楚两栏是同一场取地战争

[卷015本年魏、楚栏](../../拆分史书/史记/卷015.md#y0371)分别记伐楚取鲁阳、魏取我鲁阳；[《通鉴》卷一烈王五年](../../拆分史书/资治通鉴/卷001.md#text)同载。胜负只计一次，不据同格或同年关系补出未记的主将与月份。


<a id="2高安之战为世家增补"></a>
#### 2｜高安之战为世家增补

[《赵世家》成侯四年](../../拆分史书/史记/卷043.md#part-1-text)记“与秦战高安，败之”，据现用成侯前374年元年归本年。原表秦、赵栏只有年数，未记并不等于可以否定另一篇有明确年次的战事；但也不能据短句推定战场现代地望、伤亡或赵军已占领整个秦境。

<a id="sj015-0371-han-variant"></a>
<a id="3韩哀侯被杀不在本年再写一次"></a>
#### 3｜韩哀侯被杀不在本年再写一次

卷015韩栏“六。韩严杀其君”属于哀侯六年的旧年链。本批结合《韩世家·索隐》引《纪年》与现用魏武侯年次，已将死亡主述放在[前374年](bce-0374.md#sj015-han-ai)，此处保留异年回链。韩国在本年不再进行第二次同样的弑君与继承；“韩严”、韩山坚、严遂的关系仍见同页注4。

<a id="sj015-0371-wei-variant"></a>
<a id="4魏武侯终局另在下一年"></a>
#### 4｜魏武侯终局另在下一年

[《魏世家》](../../拆分史书/史记/卷044.md#part-2-text)将取鲁阳与武侯卒连在旧十六年条；所引《纪年》则记二十六年卒。沿本项目武侯前395年元年的校订，死亡落在[前370年](bce-0370.md#event-4)。本年取鲁阳有编年底本支持，仍保留本年，不能把同段每项事全部随君王卒年平移。[本批韩魏年次说明](../../拆分史书/史记/卷015.md#kao-3c39143f50-94ca5369c)。

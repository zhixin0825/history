# 公元前371年｜魏取楚鲁阳，赵秦战于高安

[← 公元前372年](bce-0372.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前370年 →](bce-0370.md)

**周烈王五年**

## 本年纪事

<a id="event-1"></a>
1. **魏军进攻楚国，夺取鲁阳。** 鲁阳是此次楚、魏争夺的城邑，不能因地名里有“鲁”字便把战事移成魏国攻打鲁国。[原文与说明](#note-1)

<a id="event-2"></a>
2. **赵军与秦军在高安交战，赵方取得胜利。** 赵国与魏、卫交兵之外，又在西面与秦发生冲突。[原文与说明](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜魏、楚两栏是同一场取地战争

[卷015本年魏、楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0371)分别记伐楚取鲁阳、魏取我鲁阳；[《通鉴》卷一烈王五年](https://zh.wikisource.org/wiki/資治通鑑/卷001)同载。胜负只计一次，不据同格或同年关系补出未记的主将与月份。

<a id="note-2"></a>
### 2｜高安之战为世家增补

[《赵世家》成侯四年](https://zh.wikisource.org/wiki/史記/卷043#趙成侯)记“与秦战高安，败之”，据现用成侯前374年元年归本年。原表秦、赵栏只有年数，未记并不等于可以否定另一篇有明确年次的战事；但也不能据短句推定战场现代地望、伤亡或赵军已占领整个秦境。

<a id="sj015-0371-han-variant"></a>
### 3｜韩哀侯被杀不在本年再写一次

卷015韩栏“六。韩严杀其君”属于哀侯六年的旧年链。本批结合《韩世家·索隐》引《纪年》与现用魏武侯年次，已将死亡主述放在[前374年](bce-0374.md#sj015-han-ai)，此处保留异年回链。韩国在本年不再进行第二次同样的弑君与继承；“韩严”、韩山坚、严遂的关系仍见同页注4。

<a id="sj015-0371-wei-variant"></a>
### 4｜魏武侯终局另在下一年

[《魏世家》](https://zh.wikisource.org/wiki/史記三家註/卷044)将取鲁阳与武侯卒连在旧十六年条；所引《纪年》则记二十六年卒。沿本项目武侯前395年元年的校订，死亡落在[前370年](bce-0370.md#event-4)。本年取鲁阳有编年底本支持，仍保留本年，不能把同段每项事全部随君王卒年平移。[本批韩魏年次说明](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#韩魏)。

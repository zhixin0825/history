# 公元前372年｜赵取卫七十三邑，又败于魏军

[← 公元前373年](bce-0373.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前371年 →](bce-0371.md)

**周烈王四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **赵成侯任用大戊午为相，赵军进攻卫国，取得七十三处乡邑。** 赵国继续向邻近的卫地扩张；原书把任相与战争同系本年，没有给出两事之间的具体月份。 [[1]](#note-1)

<a id="event-2"></a>

2. **魏军在北蔺击败赵军。** 赵国虽然对卫取得土地，却又在与魏国的交战中失利。 [[2]](#note-2)

<a id="event-3"></a>

3. **燕国进入桓公元年，卫国进入声公训元年。** 两国的前君死亡与继位已在前一年，元年不是又发生一次拥立。 [[3]](#note-3)

<a id="sj038-pi-accession-event"></a>

4. **宋辟公辟兵承接君位，开始纪元。** 休公田之后，辟兵承接宋君之位，称辟公；古注所引材料又称桓侯。本年暂沿年表的辟公元年，名字与谥号的差别保留在注中。 [[4]](#sj038-pi-accession-note)

## 归年与考证

<a id="1七十三是乡邑数不是现代县数"></a>
#### 1｜七十三是乡邑数，不是现代县数

[卷015赵栏](../../sources/摘录/史记-卷015-六国年表.md#y0372)记取卫都鄙七十三；[《赵世家》成侯三年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-fb63d2ed6383e1)另有太戊午为相，并称乡邑七十三。正文以便读写法大戊午，太、大字样保留在来源；不直接把乡邑换算成七十三个后世行政县，不推算未记的面积和人口。两事连记也不证明此战必由新相亲自领军。


<a id="2魏赵两栏同一战果"></a>
#### 2｜魏、赵两栏同一战果

卷015魏栏“败赵北蔺”、赵栏“魏败我蔺”，与《通鉴》烈王四年互见，作为一场战争记述，不加成两次赵军战败。北蔺、蔺的详略不用于虚构两处战场；本轮未核战术及兵力。


<a id="3燕卫的元年"></a>
#### 3｜燕、卫的元年

卷015燕栏明列桓公元年，魏栏兼记卫声公元年。各归实际国别，不当成魏国换君。前一年承继见[前373年注3](bce-0373.md#note-3)。

<a id="sj015-0372-song"></a>
<a id="4表中的宋辟公元年仍待考"></a>
#### 4｜表中的宋辟公元年仍待考

本年齐栏兼记“宋辟公元年”，前369年又有“宋剔成元年”；这与其他宋国材料中的休公、桓公辟兵及剔成一系不能未经校核就逐字相认。[《宋微子世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7038.md#ref-b2e69175f545a7)与[《通鉴》卷二的校订页](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7002.md#ref-0a9cbc952e9ab1)采用的年链也不同。本轮在正文第4条沿年表暂列辟公元年，**不是确认本年承位与全部晚宋年链均已定案**；休公前395或前385起的分歧，以及桓侯、剔成的世系仍须分开。详见[卷038纪年考证](../../meta/考证/史记-卷038-纪年与异说.md)。[本批待考范围](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#晋鲁宋)。

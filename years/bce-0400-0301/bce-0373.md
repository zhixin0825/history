# 公元前373年｜齐国接连受攻，燕卫更换君主

[← 公元前374年](bce-0374.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前372年 →](bce-0372.md)

**周烈王三年**

## 本年纪事

<a id="event-1"></a>
1. **燕军在林狐击败齐军，鲁军也攻入齐国阳关。** 齐国在不同方向受到进攻，未能阻止这些敌军。[原文与说明](#note-1)

<a id="event-2"></a>
2. **魏军进攻齐国，抵达博陵。** 这与燕、鲁的进军同见本年，原书却没有明确说三支军队受一个统帅指挥，不能当成已核实的统一联军。[原文与说明](#note-2)

<a id="event-3"></a>
3. **燕釐公和卫慎公先后见于本年的卒事记录。** 燕国由桓公承继，卫国由声公训承继；两位后继者的元年都接在下一年。[原文与说明](#note-3)

<a id="event-4"></a>
4. **赵国六月下雪。** 史书保留这项异常天气记录，没有给出本次降雪范围、积雪深度和收成损失。[原文与说明](#note-4)

<a id="event-5"></a>
5. **韩国进入懿侯若山元年。** 哀侯终局按本批采用的校订放在前374年，若山从本年开始计元。[原文与说明](#note-5)

## 本年相关史料

<a id="note-1"></a>
### 1｜燕、鲁的两项战事

[卷015本年燕、齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0373)分别记败齐林孤、鲁入阳关；[《通鉴》卷一烈王三年](https://zh.wikisource.org/wiki/資治通鑑/卷001)作林狐。正文采用林狐，原格“林孤”不改；这是地名字样差别，不另造第二次齐燕战斗。鲁君年代仍有未决，不据本条擅指必由某一鲁君亲征。

<a id="note-2"></a>
### 2｜“晋”与“鱄陵”

卷015齐栏作“晋伐到鱄陵”，《通鉴》对应写魏伐齐至博陵；此处正文用可辨的魏国，地名沿编年底本，原表仍保留晋、鱄陵。晉字在战国材料中有沿称三晋之一的用法，不能据它让前376年被废的晋君又率全国大军出征。现代地望未在本轮确定。

<a id="note-3"></a>
### 3｜死亡与次年元年

《通鉴》同年记燕僖侯卒、子桓侯立及卫慎侯卒、子声侯训立；[《燕召公世家》](https://zh.wikisource.org/wiki/史記/卷034)与[《卫康叔世家》](https://zh.wikisource.org/wiki/史記/卷037)的相关承继可互读。前372年表列燕桓公元年和卫声公元年，此页采用其前一年卒立的衔接。公、侯与釐、僖的称法分别保留于来源，不按称谓差别添两个人；未定具体死亡日，也不以正文排版确定两国死亡先后。

<a id="note-4"></a>
### 4｜六月雪为世家增补

[《赵世家》成侯二年](https://zh.wikisource.org/wiki/史記/卷043#趙成侯)记六月雨雪；以成侯前374年元年归本年。原表赵栏只有二，不把这项补文悄悄塞进原格。月份仍是古历月份。

<a id="note-5"></a>
### 5｜韩国纪年校订的后续

前374年哀侯被杀、若山承位的依据见[前页注4](bce-0374.md#note-4)及[本批考证](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#韩魏)。原表前370年的“庄侯元年”仍是另一套起点，不再在那里另立一位庄侯。采用此君次不等于将所有韩国战争整体平移三年。

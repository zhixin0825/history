### 5. 前一年夺位的田午开始以元年纪事

[返回正文第5条](#reading-event-10)

**[史记三家注](../../拆分史书/史记/卷046.md#part-2-p24)**

> 齊侯太公和立二年，和卒，〔集解〕徐廣曰：「伐魯，破之。」子桓公午立。〔索隱〕紀年「齊康公五年，田侯午生。二十二年，田侯剡立。後十年，齊田午弒其君及孺子喜而爲公」。春秋後傳亦云「田午弒田侯及其孺子喜而兼齊，是爲桓侯」。與此系家不同也。桓公午五年，秦、魏攻韓，韓求救於齊。齊桓公召大臣而謀〔索隱〕謂騶忌、段干朋。如戰國策威王二十六年邯鄲之役有此謀臣耳。又南梁之難在宣王二年，有騶子、田忌、孫臏之謀。戰國策又有張田。其辭前後交互，是記史者所取各異，故不同耳。曰：「蚤救之孰與晚救之？」騶忌曰：「不若勿救。」段干朋〔索隱〕段干，姓；朋，名也。戰國策作「段干綸」。曰：「不救，則韓且折而入於魏，不若救之。」田臣思〔索隱〕戰國策作「田期思」，紀年謂之徐州子期，蓋即田忌也。曰：「過矣君之謀也！秦、魏攻韓、楚，趙必救之，是天以燕予齊也。」桓公曰：「善」。乃陰告韓使者而遣之。韓自以爲得齊之救，因與秦、魏戰。楚、趙聞之，果起兵而救之。齊因起兵襲燕國，取桑丘。〔正義〕括地志云：「桑丘故城俗名敬城，在易州遂城縣。」爾時齊伐燕桑丘，魏、趙來救之。魏、趙世家並云「伐齊至桑丘」，皆是易州。

## 归年与考证

<a id="sj004-374-1"></a>
<a id="1太史儋会见的旧记录及冲突"></a>
#### 1｜太史儋会见的旧记录及冲突

[卷004 P067](../../拆分史书/史记/卷004.md#p067)烈王二年与《秦本纪》献公十一年同指本年。[旧卷063引文](../../拆分史书/史记/README.md#part-1-ref-sj-4611)又写孔子死后129年，与本年定位不合；[旧卷005引文](../../拆分史书/史记/README.md#part-1-ref-sj-319)保留明确君年。本页暂沿后者，不判定太史儋就是李耳。

其关于周秦离合“五百岁”、再合“七十岁”的话是所传预言，不拿秦后来统一倒验为当年准确预测。原`sj-063-L4611-01`、卷四与卷五锚点均保留，原有不同证据没有因为改为正常叙事而删掉。

<a id="sj005-158-note"></a>
**卷005互见：**[P050](../../拆分史书/史记/卷005.md#p050)保存同一会见。“合七十七岁”等文字有异，不由预言反推秦周全部历史必按这个数字运行。

<a id="note-2"></a>
<a id="2城栎阳不等于县栎阳"></a>
#### 2｜城栎阳不等于县栎阳

[卷015秦栏](../../拆分史书/史记/卷015.md#y0374)明记“县栎阳”；[前383年](bce-0383.md)是“城栎阳”。只补原书可分辨的工程与行政步骤，不推论所有后世县制职官本年已经齐备。

<a id="note-3"></a>
<a id="3元年与公子胜"></a>
#### 3｜元年与公子胜

卷015赵栏列成侯元年；[《赵世家》](../../拆分史书/史记/卷043.md#part-1-text)另记公子胜与成侯争立为乱。原句未在此交代公子胜的结局，正文不补杀、逃或被俘。也不与前386年公子朝争位合并。

<a id="note-4"></a>
<a id="4韩哀侯终局君年与人名都须分层"></a>
#### 4｜韩哀侯终局：君年与人名都须分层

[《韩世家·索隐》](../../拆分史书/史记/卷045.md#part-2-text)引《纪年》，在魏武侯二十二年关联的入郑、邑郑之后记“韩山坚贼其君哀侯而立韩若山”。结合武侯前395年元年的现用校订，采用前374年；所读[《通鉴》卷一校订页](../../拆分史书/资治通鉴/卷001.md#text)也明确把旧烈王五年条移到二年。该网页校刊记不是司马光原文，本页据各层证据作暂行安排。[详细依据](../../拆分史书/史记/卷015.md#kao-3c39143f50-94ca5369c)。

卷015和世家正文则用哀侯六年，折在前371年；本轮在那里留回链，不让哀侯两度被杀。世家作“韩严”，古注引“韩山坚”，又疑与严遂有关；《通鉴》叙严遂使刺客杀韩廆、连及抱住他的哀侯，是更具体但有传承问题的一说。正文采用共有的被杀、继承，不将这些姓名无证合为一人，也不把前397年聂政刺韩相的旧条搬来再发生一次。后继者懿侯、表中“庄侯”为异称，不能据此增一任君主。

<a id="5田午元年采用上一批补回的君次"></a>

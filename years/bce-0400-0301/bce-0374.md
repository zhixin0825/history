# 公元前374年｜韩哀侯遇害，秦在栎阳设县

[← 公元前375年](bce-0375.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前373年 →](bce-0373.md)

**周烈王二年；秦献公十一年**

## 本年纪事

<a id="sj-063-L4611-01"></a>
<a id="event-1"></a>
### 1｜周太史儋会见秦献公

**周太史儋来到秦国，向献公谈周、秦的离合。** 他的身份后来有不同传说，有人把他与老子相联系。此次会见的现用年次是秦献公十一年；身份及预言的界限见同号说明。[原文与说明](#sj004-374-1)

<a id="event-2"></a>
### 2｜秦在栎阳设县

**秦把栎阳设为县。** 前383年已经有城栎阳的工程记录，本年又有行政设置；营建城邑与设县是不同动作，不写成再次迁到一座刚刚出现的城。[原文与说明](#note-2)

<a id="event-3"></a>
### 3｜赵成侯元年，公子胜争位

**赵国开始按成侯种元年纪事，公子胜与他争夺君位，引起内乱。** 种在前一年父亲敬侯去世后承位，公族并没有一致服从新的安排。[原文与说明](#note-3)

<a id="event-4"></a>
<a id="sj015-han-ai"></a>
### 4｜韩哀侯被杀，若山继位

**韩哀侯遭到杀害，若山继承君位，是为韩懿侯。** 韩国刚吞并郑国不久，君位便又发生变更。凶手名称、宫廷冲突的经过以及此事的另一年次，见同号史料。[原文与说明](#note-4)

<a id="event-5"></a>
### 5｜齐国进入田午的元年

**前一年夺位的田午开始以元年纪事。** 这位田齐桓公与春秋时期的齐桓公小白相隔数百年，不是同一人再度执政。[原文与说明](#note-5)

## 本年相关史料

<a id="sj004-374-1"></a>
### 1｜太史儋会见的旧记录及冲突

[卷004 P067](../../sources/摘录/史记-卷004-周本纪.md#p067)烈王二年与《秦本纪》献公十一年同指本年。[旧卷063引文](../../sources/摘录/史记-条目原文.md#ref-sj-4611)又写孔子死后129年，与本年定位不合；[旧卷005引文](../../sources/摘录/史记-条目原文.md#ref-sj-319)保留明确君年。本页暂沿后者，不判定太史儋就是李耳。

其关于周秦离合“五百岁”、再合“七十岁”的话是所传预言，不拿秦后来统一倒验为当年准确预测。原`sj-063-L4611-01`、卷四与卷五锚点均保留，原有不同证据没有因为改为正常叙事而删掉。

<a id="sj005-158-note"></a>
**卷005互见：**[P050](../../sources/摘录/史记-卷005-秦本纪.md#p050)保存同一会见。“合七十七岁”等文字有异，不由预言反推秦周全部历史必按这个数字运行。

<a id="note-2"></a>
### 2｜城栎阳不等于县栎阳

[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0374)明记“县栎阳”；[前383年](bce-0383.md)是“城栎阳”。只补原书可分辨的工程与行政步骤，不推论所有后世县制职官本年已经齐备。

<a id="note-3"></a>
### 3｜元年与公子胜

卷015赵栏列成侯元年；[《赵世家》](https://zh.wikisource.org/wiki/史記/卷043#趙成侯)另记公子胜与成侯争立为乱。原句未在此交代公子胜的结局，正文不补杀、逃或被俘。也不与前386年公子朝争位合并。

<a id="note-4"></a>
### 4｜韩哀侯终局：君年与人名都须分层

[《韩世家·索隐》](https://zh.wikisource.org/wiki/史記三家註/卷045)引《纪年》，在魏武侯二十二年关联的入郑、邑郑之后记“韩山坚贼其君哀侯而立韩若山”。结合武侯前395年元年的现用校订，采用前374年；所读[《通鉴》卷一校订页](https://zh.wikisource.org/wiki/資治通鑑/卷001)也明确把旧烈王五年条移到二年。该网页校刊记不是司马光原文，本页据各层证据作暂行安排。[详细依据](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#韩魏)。

卷015和世家正文则用哀侯六年，折在前371年；本轮在那里留回链，不让哀侯两度被杀。世家作“韩严”，古注引“韩山坚”，又疑与严遂有关；《通鉴》叙严遂使刺客杀韩廆、连及抱住他的哀侯，是更具体但有传承问题的一说。正文采用共有的被杀、继承，不将这些姓名无证合为一人，也不把前397年聂政刺韩相的旧条搬来再发生一次。后继者懿侯、表中“庄侯”为异称，不能据此增一任君主。

<a id="note-5"></a>
### 5｜田午元年采用上一批补回的君次

[王政冬的年代考](https://www.fdgwz.org.cn/Web/Show/3072)说明田剡与田午的相接，既有[田齐考证](../../meta/考证/史记-卷015-田齐前期君次补核.md)已采用其前段方案。夺位主述在前375年，此处只接元年；原表本年齐栏“五”仍照录，不混入校订后的王年。

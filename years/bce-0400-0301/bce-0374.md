## 归年与考证

<a id="sj004-374-1"></a>
<a id="1太史儋会见的旧记录及冲突"></a>
#### 1｜太史儋会见的旧记录及冲突

[卷004 P067](../../sources/摘录/史记-卷004-周本纪.md#p067)烈王二年与《秦本纪》献公十一年同指本年。[旧卷063引文](../../sources/摘录/史记-条目原文.md#ref-sj-4611)又写孔子死后129年，与本年定位不合；[旧卷005引文](../../sources/摘录/史记-条目原文.md#ref-sj-319)保留明确君年。本页暂沿后者，不判定太史儋就是李耳。

其关于周秦离合“五百岁”、再合“七十岁”的话是所传预言，不拿秦后来统一倒验为当年准确预测。原`sj-063-L4611-01`、卷四与卷五锚点均保留，原有不同证据没有因为改为正常叙事而删掉。

<a id="sj005-158-note"></a>
**卷005互见：**[P050](../../sources/摘录/史记-卷005-秦本纪.md#p050)保存同一会见。“合七十七岁”等文字有异，不由预言反推秦周全部历史必按这个数字运行。

<a id="note-2"></a>
<a id="2城栎阳不等于县栎阳"></a>
#### 2｜城栎阳不等于县栎阳

[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0374)明记“县栎阳”；[前383年](bce-0383.md)是“城栎阳”。只补原书可分辨的工程与行政步骤，不推论所有后世县制职官本年已经齐备。

<a id="note-3"></a>
<a id="3元年与公子胜"></a>
#### 3｜元年与公子胜

卷015赵栏列成侯元年；[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-30e652db0bed76)另记公子胜与成侯争立为乱。原句未在此交代公子胜的结局，正文不补杀、逃或被俘。也不与前386年公子朝争位合并。

<a id="note-4"></a>
<a id="4韩哀侯终局君年与人名都须分层"></a>
#### 4｜韩哀侯终局：君年与人名都须分层

[《韩世家·索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7045.md#ref-a14407a6e75069)引《纪年》，在魏武侯二十二年关联的入郑、邑郑之后记“韩山坚贼其君哀侯而立韩若山”。结合武侯前395年元年的现用校订，采用前374年；所读[《通鉴》卷一校订页](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7001.md#ref-e6a69ca9580335)也明确把旧烈王五年条移到二年。该网页校刊记不是司马光原文，本页据各层证据作暂行安排。[详细依据](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#韩魏)。

卷015和世家正文则用哀侯六年，折在前371年；本轮在那里留回链，不让哀侯两度被杀。世家作“韩严”，古注引“韩山坚”，又疑与严遂有关；《通鉴》叙严遂使刺客杀韩廆、连及抱住他的哀侯，是更具体但有传承问题的一说。正文采用共有的被杀、继承，不将这些姓名无证合为一人，也不把前397年聂政刺韩相的旧条搬来再发生一次。后继者懿侯、表中“庄侯”为异称，不能据此增一任君主。

#### 5｜田午元年采用上一批补回的君次

[王政冬的年代考](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-a2d786c99c82b927.md#cite-8)说明田剡与田午的相接，既有[田齐考证](../../meta/考证/史记-卷015-田齐前期君次补核.md)已采用其前段方案。夺位主述在前375年，此处只接元年；原表本年齐栏“五”仍照录，不混入校订后的王年。

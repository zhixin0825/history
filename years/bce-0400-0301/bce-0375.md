# 公元前375年｜韩灭郑，田午夺取齐国君位

[← 公元前376年](bce-0376.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前374年 →](bce-0374.md)

**周烈王元年；秦献公十年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **户籍的登记与基层编组联系起来。** 秦献公十年记“为户籍相伍”，说明秦把登记的人户按伍组织起来。它发生在商鞅大规模改革以前，提醒读者：后来更严密的国家组织，并不是到商鞅出场才从零开始。 [[1]](#note-1)

<a id="event-2"></a>

2. **韩国灭掉郑国，随后把都城迁到郑地。** 郑康公统治终结，原郑国的政治中心转为韩国的都城。韩国此前夺取郑地、包围郑城的多次战争，至此发展成吞并；这不是前396年郑繻公被杀的重演。 [[2]](#note-2)

<a id="event-3"></a>

3. **赵敬侯去世，儿子种继承君位，是为赵成侯。** 新君很快面对公族争位，后续见下一年。 [[3]](#note-3)

<a id="event-4"></a>
<a id="sj015-0375-tianwu"></a>

4. **田午杀死田侯剡及孺子喜，夺取齐国君位。** 田和死后的田氏统治并非平顺地直接传到齐威王，中间先有田侯剡，现在又发生暴力夺位。田午后来称桓公，下一年开始计算他的元年。 [[4]](#note-4)

<a id="event-5"></a>

5. **周王室开始以烈王元年纪事，秦国又记下一次日食。** 周安王之死在前一年；新君改计元年与秦所见天象是两件不同的事。 [[5]](#note-5)

### 4. 田午杀死田侯剡及孺子喜，夺取齐国君位

[返回正文第4条](#event-4)

**[史记三家注](../../拆分史书/史记/卷046.md#part-2-p24)**

> 齊侯太公和立二年，和卒，〔集解〕徐廣曰：「伐魯，破之。」子桓公午立。〔索隱〕紀年「齊康公五年，田侯午生。二十二年，田侯剡立。後十年，齊田午弒其君及孺子喜而爲公」。春秋後傳亦云「田午弒田侯及其孺子喜而兼齊，是爲桓侯」。與此系家不同也。桓公午五年，秦、魏攻韓，韓求救於齊。齊桓公召大臣而謀〔索隱〕謂騶忌、段干朋。如戰國策威王二十六年邯鄲之役有此謀臣耳。又南梁之難在宣王二年，有騶子、田忌、孫臏之謀。戰國策又有張田。其辭前後交互，是記史者所取各異，故不同耳。曰：「蚤救之孰與晚救之？」騶忌曰：「不若勿救。」段干朋〔索隱〕段干，姓；朋，名也。戰國策作「段干綸」。曰：「不救，則韓且折而入於魏，不若救之。」田臣思〔索隱〕戰國策作「田期思」，紀年謂之徐州子期，蓋即田忌也。曰：「過矣君之謀也！秦、魏攻韓、楚，趙必救之，是天以燕予齊也。」桓公曰：「善」。乃陰告韓使者而遣之。韓自以爲得齊之救，因與秦、魏戰。楚、趙聞之，果起兵而救之。齊因起兵襲燕國，取桑丘。〔正義〕括地志云：「桑丘故城俗名敬城，在易州遂城縣。」爾時齊伐燕桑丘，魏、趙來救之。魏、趙世家並云「伐齊至桑丘」，皆是易州。

[《田敬仲完世家·索隐》](../../拆分史书/史记/卷046.md#part-2-text) · 王政冬《田庄子至齐威王间田齐诸君年代考》（王政冬：田莊子至齊威王間田齊諸君年代考-复旦大学出土文献与古文字研究中心）

## 归年与考证

<a id="sj006-072-note"></a>
<a id="1户籍相伍旧条目与锚点保留"></a>
#### 1｜户籍相伍：旧条目与锚点保留

[卷006 P072](../../拆分史书/史记/卷006.md#p072)：“十年，為戶籍相伍。”按献公元年前384年对应为前375。原文没有展开连坐条款、具体执行范围或处罚等级；不能直接把后来商鞅法的全部条文倒填成本年已经完成的制度，也不能由“为户籍”断言此前秦从无人口登记。


<a id="2郑国终局与韩国迁都"></a>
#### 2｜郑国终局与韩国迁都

[卷015韩栏](../../拆分史书/史记/卷015.md#y0375)记哀侯二年灭郑；[《韩世家》及索隐](../../拆分史书/史记/卷045.md#part-2-text)明记灭郑、因徙都郑，所引《纪年》系魏武侯二十一年，依本项目武侯前395年元年的校订同归前375年。《通鉴》烈王元年同载。迁都是灭郑之后的行动，未补无据的迁宫月日。

表称郑康公二十年灭、无后，是郑国国祀和统治终结的记法，不等于郑氏每个后裔均死。以后有些文献以“郑”称韩国，是国名与都邑语境的变化，不自动当成郑康公又复国。


<a id="3赵敬侯终局"></a>
#### 3｜赵敬侯终局

[《赵世家》敬侯十二年](../../拆分史书/史记/卷043.md#part-1-text)记卒、子成侯种立；《通鉴》同年记载。沿敬侯前386年元年，十二年归本年，前374年才列成侯元年。死亡不是原表赵栏“十二”之外已经写明的字句，来源层次分开。


<a id="4田午的夺位不能提前到前384年"></a>
#### 4｜田午的夺位不能提前到前384年

[《田敬仲完世家·索隐》](../../拆分史书/史记/卷046.md#part-2-text)引《纪年》记田侯剡之后，田午弑君及孺子喜而为公；王政冬《田庄子至齐威王间田齐诸君年代考》（王政冬：田莊子至齊威王間田齊諸君年代考-复旦大学出土文献与古文字研究中心）在钱穆、杨宽等考证基础上采用前384年田剡元年、前375年终局、前374年田午元年的衔接。本页沿上一批补回田剡的君次方案继续。

正文不再按旧表前384年立午、前378年立威王。孺子喜是否曾短暂受立、与诸人的完整亲属关系及具体杀害先后，不凭“及”字全部定案；不增加一场有确日的孺子登基。原表本年齐栏只有“四”，本条属于校勘后增补，不伪作原格文字。[君次依据](../../拆分史书/史记/卷015.md#kao-7a21144e4c) · [本批补核](../../拆分史书/史记/卷015.md#kao-3c39143f50-c9d060d8f)。


<a id="5两国不同性质的记事"></a>
#### 5｜两国不同性质的记事

卷015周栏“烈王元年”、秦栏“十。日蚀”分别对应。沿古史年条，不直接移用网页所引现代日食推算的公历时刻；本轮未独立历算。

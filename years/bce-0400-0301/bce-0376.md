# 公元前376年｜三家废晋君，周安王去世

[← 公元前377年](bce-0377.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前375年 →](bce-0375.md)

**周安王二十六年**

## 本年纪事

<a id="event-1"></a>
1. **安王去世，儿子喜继承周王位，是为烈王。** 新王的元年从下一年开始计算。[原文与说明](#note-1)

<a id="event-2"></a>
2. **魏、韩、赵废去晋君的诸侯身份，分取晋国剩下的土地。** 三家在前453年已经分掉智氏领地，前403年又获得周王承认为诸侯；这一次针对的是仍然保留名位和少量土地的晋国公室。卿族分地、获得诸侯名分与废晋君，是相隔多年的三个阶段。[原文与说明](#note-2)

<a id="event-3"></a>
3. **韩国进入哀侯元年。** 前一年文侯去世后，哀侯承位，如今与魏、赵共同处置晋国。[原文与说明](#note-3)

<a id="event-4"></a>
4. **赵军又进攻中山，在中人交战。** 前一年的房子之战之后，赵国与中山的战争仍在继续。[原文与说明](#note-4)

## 本年相关史料

<a id="note-1"></a>
<a id="sj004-376-1"></a>
### 1｜保留原来的王室继承

[卷004 P067](../../sources/摘录/史记-卷004-周本纪.md#p067)记安王二十六年崩；[《通鉴》卷一安王二十六年](https://zh.wikisource.org/wiki/資治通鑑/卷001)同记子烈王喜立。原事件及显式锚点保留，不将次年元年再写成一次继承。

<a id="note-2"></a>
### 2｜废晋与“绝无后”不能直接等同

[卷015前376年魏、韩、赵、齐四栏](../../sources/摘录/史记-卷015-六国年表.md#y0376)重复记三家灭晋、分晋；《通鉴》同年写废晋靖公为家人、分其地。正文采用后者的具体政治动作，不把“绝无后”扩大为所有晋公族遭灭族。前453、403年的既有事件不重复计算。

[《赵世家》](https://zh.wikisource.org/wiki/史記/卷043#趙成侯)又在成侯十六年记分晋、封晋君端氏，肃侯元年记夺端氏、徙屯留；[《晋世家·索隐》](https://zh.wikisource.org/wiki/史記三家註/卷039)所引《纪年》也保留晋君的后续。末代晋君的名号、迁徙与终局不是所有书一致，不能只凭本格便裁定其本年已经被杀。本轮先合入前376年的废君分地传统，后续异年不另编为已经确定的多次相同灭国。[本批考证](../../meta/考证/史记-卷015-前0376至0367纪年补核.md#晋鲁宋)。

《天官书》[P115](../../sources/摘录/史记-卷027-天官书.md#p115)‘三家分晉’是长期过程的概述；[《正义》](../../sources/摘录/史记-卷027-三家注对照.md#p115)以周安王二十六年解释，才与本年废晋分地相接。三家更早的分智氏地、受命诸侯仍各在原年，不按一句回顾压成同年；后注称韩文侯等，与本页所采用韩哀侯元年的年线不尽相合，详[本卷考证](../../meta/考证/史记-卷027-纪年与异说.md#政治回顾)。

<a id="note-3"></a>
### 3｜韩哀侯元年

卷015韩栏与[《韩世家》](https://zh.wikisource.org/wiki/史記/卷045)文侯十年卒、哀侯元年分晋相接。文侯终局已在[前377年](bce-0377.md)；此处不补即位日。哀侯的终局另有三年、六年两套对应，见[前374年](bce-0374.md#sj015-han-ai)。

<a id="note-4"></a>
### 4｜赵军在中人作战

《赵世家》敬侯十一年在分晋后记伐中山、又战中人；沿敬侯元年前386年的现用链条归本年。原表赵格只记分晋，这项属于世家增补，不改写成该格原文。交战胜负、兵数和具体月份未载，不补造。

<a id="sj015-0376-lu"></a>
### 5｜鲁共公元年暂不另立一次继承

本年楚栏兼记“鲁共公元年”。原表以鲁穆公前407年起算，但现代校订另有前383年穆公卒、前382年共公元年的安排；所读《通鉴》网页也明确把旧有穆公卒条移到前383年。鲁国整段君年仍需专题核定，不能把网页校改与司马光原文混同。本次保留本格及异年入口，**不新增一个已确定发生在前376年的鲁共公即位故事**。详见本批考证；此前鲁国年页未作整体平移。

# 公元前377年｜蜀取楚兹方，韩文侯去世

[← 公元前378年](bce-0378.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前376年 →](bce-0376.md)

## 本年纪事

<a id="event-1"></a>
**蜀军进攻楚国，夺取兹方。** 蜀不仅与秦争夺南郑，也沿另一方向与楚发生冲突。[1](#note-1)

<a id="event-2"></a>
**晋国进入静公俱酒元年。** 他承接父亲孝公的君位；在魏、韩、赵势力强大的局面中，晋公室仍短暂维持着自己的名号。[2](#note-2)

<a id="event-3"></a>
**韩文侯去世，儿子哀侯继位。** 韩国内部的君位继续父子相传，下一年起用新君元年纪事。[3](#note-3)

<a id="event-4"></a>
**赵军与中山在房子交战。** 魏国早先攻占中山，并没有使中山在此后的史籍中永久消失，赵国仍在这一方向作战。[4](#note-4)

## 本年相关史料

<a id="note-1"></a>
### 1｜楚栏“我”指楚国，不是秦国

[卷015楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0377)记蜀伐我兹方，[《资治通鉴》安王二十五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7001.md#ref-66dde8e59b7000)补为蜀伐楚、取兹方。正文合用其进攻对象与结果，不将它移回[前387年的南郑之争](bce-0387.md#event-1)，也不据同为蜀军就推出两场战争间有一条已确证的连续行军路线。兹方地望未另核。

<a id="note-2"></a>
### 2｜静公元年，不是魏国另换国君

本年魏栏列晋静公俱酒元年，前一年孝公死亡与实际承位在[前378年](bce-0378.md#event-4)。魏栏兼记晋公室，不能把静公当作魏武侯的继承者。此处沿现用年链接读，不由元年自动推出所有晋国余地已在本年分尽。

<a id="note-3"></a>
### 3｜韩文侯十年终局

[《韩世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7045.md#ref-2feda01fd9e461)记文侯十年卒、子哀侯立，《通鉴》同系本年；年表次年韩栏为哀侯元年。死亡与新纪年分开，国君没有因下一年表列元年再死一次。本批录表到前377止，后续仍须补前376年诸事。

<a id="note-4"></a>
### 4｜房子是地名，中山政权沿革另需考核

[《赵世家》敬侯十年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-9f3e1c87b13a41)记与中山战于房子；原表赵栏只列十，本次据世家增补，不改原格。房子是地名，不译作在民居之间交战；也不由这一条直接决定中山复国的具体年份与君主谱系。早期魏攻中山仍见[前406年](../bce-0500-0401/bce-0406.md#note-1)。

### 同年编排中的未定年材料

《通鉴》把子思荐苟变、批评卫君臣相互逢迎的数段话编在本年。这些话没有各自给出可独立校定的日期，且涉及子思活动年代的问题，本批不将它们新建为前377年的确定事件；后续须连同人物生平核读，不以不收本年正文等同于否定原文存在。

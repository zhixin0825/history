# 公元前378年｜三晋攻齐至灵丘，秦记“初行为市”

[← 公元前379年](bce-0379.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前377年 →](bce-0377.md)

## 本年纪事

<a id="sj015-0378-market"></a>
**秦把市场活动列入制度记事。** 献公七年有“初行为市”的记录，可以读作市场设置、运行方面的一项制度措施，不表示秦国此前没有交易。[1](#sj006-072-note)

<a id="event-2"></a>
**狄军在浍地击败魏军。** 魏国面对的对手不只有周围的诸侯国。[2](#note-2)

<a id="event-3"></a>
**魏、韩、赵共同攻齐，进抵灵丘。** 三晋在前380年进兵桑丘以后，又有一次向齐国施压的行动。[3](#note-3)

<a id="event-4"></a>
**晋孝公去世，儿子俱酒继位，是为静公。** 晋公室仍保有君位，三家受周王承认并不等于公室已经在那一年被废。[4](#note-4)

## 本年相关史料

<a id="sj006-072-note"></a>
### 1｜献公七年的原有市场条

[卷006 P072](../../sources/摘录/史记-卷006-秦始皇本纪.md#p072)：“献公立七年，初行为市。”沿献公元年前384年的王年对应，七年归前378。旧史料锚点保留；具体地点、官吏、税率、商品及施行月日不由短句补出，也不说成中国历史上第一个市场。

<a id="note-2"></a>
### 2｜翟、狄与浍

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0378)作“翟败我浍”，[《资治通鉴》安王二十四年](https://zh.wikisource.org/wiki/資治通鑑/卷001)作狄败魏师于浍。采用狄的通行字形，不把翟误作已知的个人将领；没有据此确定其部族首领或补入伤亡数字。

<a id="note-3"></a>
### 3｜三国重记同一联军，不将齐威王提前出场

本年魏、韩、赵栏与《通鉴》共同记进抵灵丘，合为一场联军行动，不按三个国格生成三次战争。

<a id="sj015-0378-qi-chronology"></a>
齐栏却列“齐威王因元年”及其强齐评论。该行属于《史记》漏田侯剡、又缩短田午年数后形成的旧纪年，正文不在本年写威王即位，也不把其后政绩倒搬到这里。原格保留，君次及证据见[专题考证](../../meta/考证/史记-卷015-田齐前期君次补核.md)。

<a id="note-4"></a>
### 4｜孝公终局与次年纪元

《通鉴》本年记孝公卒、子靖公俱酒立；年表[前377年魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0377)接晋静公元年。静、靖为同一晋君的称谓互见。沿现用传世年链接合，前377年只记纪元，不再重复一次死亡；晋国最终废君的其他纪年问题不由这一局部衔接全部解决。

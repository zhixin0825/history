# 公元前379年｜秦增设县，赵攻卫不克，齐康公去世

[← 公元前380年](bce-0380.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前378年 →](bce-0378.md)

## 本年纪事

<a id="event-1"></a>
**秦国在蒲、蓝田、善明氏设置县。** 秦在城邑经营之外继续调整地方行政组织。[1](#note-1)

<a id="event-2"></a>
**赵军袭击卫国，没有攻下。赵在这一年又攻取了魏国的黄城。** 不同方向的进攻，分别有不克与拔城的结果。[2](#note-2)

<a id="event-3"></a>
**齐康公去世，田氏收并他所保有的土地，吕氏公室最后留下的奉邑也消失了。** 田和获命时康公尚在，如今旧公室的残余地位才告终结；掌齐的田氏君主按本项目采用的君次仍为田剡。[3](#note-3)

## 本年相关史料

<a id="note-1"></a>
### 1｜三处设县，不等于秦县制从本年才出现

[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0379)作“初县蒲、蓝田、善明氏”。三处保留原名，善明氏不拆成未经记载的两县，也不将“初”扩大为全国首次有县。县界、官员及施行日期未详；此前[前390年县陕](bce-0390.md#event-2)仍是另一项地方记事。

<a id="note-2"></a>
### 2｜袭卫与拔黄城分开

本年赵栏及[《资治通鉴》安王二十三年](https://zh.wikisource.org/wiki/資治通鑑/卷001)记袭卫不克；[《赵世家》敬侯八年](https://zh.wikisource.org/wiki/史記/卷043#趙敬侯)另载拔魏黄城。后者由世家补入，不冒称同一原格有两场战事全文；两役的先后月份和主将不由句次推定。黄城也不因与更早齐军毁城同名就自动断定是同一城址。

<a id="note-3"></a>
### 3｜康公死亡与田氏受命相隔数年

[卷015齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0379)、[《田敬仲完世家》](https://zh.wikisource.org/wiki/史記/卷046)及《通鉴》同系康公终局于本年。“绝祀”在此保留为吕氏公室祭祀继承断绝的政治表述，不扩成姜姓后裔全部消失或民间不再祭太公。迁康公在[前391年](bce-0391.md)，田和命侯在[前386年](bce-0386.md)，本年不再进行一次同样的受封。

年表后续将齐威王元年提早到前378，正文不照此越过田剡、田午两代，见[田齐君次考证](../../meta/考证/史记-卷015-田齐前期君次补核.md)。

《天官书》[P115](../../sources/摘录/史记-卷027-天官书.md#p115)只概说‘田氏篡齊’；[《正义》](../../sources/摘录/史记-卷027-三家注对照.md#p115)把康公卒与田和并齐立侯压在同一句。本页仍区分[前386年田和受命](bce-0386.md)与本年旧齐公室终局，不因后注把田和受命重复移到康公死年。

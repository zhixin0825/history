1. **楚悼王去世，吴起在王尸旁遇害，肃王承位。** 悼王熊疑在位二十一年，死后由子臧继位，为肃王。反对吴起改革的宗室趁丧起事，吴起伏在楚王尸体上，仍遭射杀；新君接位后的处置另见原有史料。 [[1]](#reading-note-1)

   楚悼王死后，宗室大臣攻击吴起。吴起伏到王的尸体上，攻击者射刺他时也伤及王尸。新王继位、葬毕后，命令尹追究伤及王尸者，书中说受灭族处罚的有七十余家。


<a id="reading-event-2"></a>

2. **此前在楚｜改革为何触动宗室利益。** 吴起在魏失去信任后转往楚国，受到悼王重用。他整顿法令，裁撤不急需的官职，削减疏远公族的特权与供养，把资源转向作战的士卒。这些措施服务于强兵，却也损害了贵族的利益；支持他的楚王一死，反对者便乘机发难。[改革原文与界限](#sj015-wuqi-chu-note) [[2]](#reading-note-2)

<a id="本年补充纪事"></a>
<a id="event-1"></a>

<a id="reading-event-3"></a>

3. **后来成为秦孝公的公子出生。** 献公四年正月庚寅留下了他的出生记载，这与单凭成年后的年龄倒推不同。 [[3]](#reading-note-3)

<a id="sj015-0381-chu-zhao"></a>

<a id="reading-event-4"></a>

4. **赵国借助楚国兵力攻魏，取得棘蒲。** 魏齐此前为卫攻赵，赵又寻求南方楚国的援助，列国之间的合作与对抗继续转换。 [[4]](#reading-note-4)

### 1. 吴起伏在楚王尸体上，仍被作乱者杀死

[返回正文第1条](#reading-event-1)

**[《史记》卷65 孙子吴起列传](../../sources/摘录/史记-条目原文.md#ref-sj-4656)**

> 楚悼王素聞起賢，至則相楚。明法審令，捐不急之官，廢公族疏遠者，以撫養戰鬬之士。要在彊兵，破馳說之言從橫者。於是南平百越；北并陳蔡，卻三晉；西伐秦。諸侯患楚之彊。故楚之貴戚盡欲害吳起。及悼王死，宗室大臣作亂而攻吳起，吳起走之王尸而伏之。擊起之徒因射刺吳起，并中悼王。悼王既葬，太子立，乃使令尹盡誅射吳起而并中王尸者。坐射起而夷宗死者七十餘家。

**[《资治通鉴》卷1（有标点工作本）](../../sources/摘录/史记-条目原文.md#ref-tp001-195-197)**

> 二十一年
>
> ①楚悼王薨。貴戚大臣作亂，攻吳起；起走之王尸而伏之。擊起之徒因射刺起，並中王尸。旣葬，肅王卽位，使令尹盡誅爲亂者；坐起夷宗者七十餘家。

<a id="sj040-cite-147"></a>

**[《史记·楚世家》P066](../../sources/摘录/史记-卷040-楚世家.md#p066)**

> 二十一年，悼王卒，子肅王臧立。

**本卷说明：** 悼王二十一卒，子肃王臧立与吴起被杀政局同条，非吴起自己取得王位。

## 归年与考证

<details><summary>归年依据、同书互见与待核问题</summary>

按《通鉴》安王二十一年明确年条放置死亡与事后处罚；不把此前多年的改革都归于381年。楚悼王之子肃王臧承位，次年才记元年，见[前380年](bce-0380.md#event-3)。七十余家是史书的记数，本轮未取得可独立核对的名单。原有事件及史料锚点保留。

</details>

### 吴起在楚的背景，不把篇章概述都化成确年战功



[《孙子吴起列传》吴起段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7065.md#ref-d6395365906448)记入楚受任、明法审令、去冗官及削疏远公族，继以贵戚怨恨连接其结局。这里只补与遇害直接相关的任职背景，不把南平百越、北并陈蔡、西伐秦等概述全定在本年，也不将这几句当作重新记一次灭陈、灭蔡。其在鲁、魏的完整生平与具体归年仍须另核，本段不是全部吴起传记已经完成的标志。



<a id="sj015-0381-chu-zhao-note"></a>

### 敬侯六年的楚赵对魏行动



[《赵世家》敬侯六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-bc5e444a9bb9ae)记借兵楚伐魏、取棘蒲，按现行赵敬侯元年前386年归本年。原表赵栏只列六，新增文字来自世家，不回填成原格全文。它与楚王死亡、吴起遇害的月日先后未明；也未因同时有吴起任楚相的背景，就擅定此役主将必为吴起。前因可回读[前382年刚平之争](bce-0382.md#event-2)。

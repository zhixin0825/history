# 公元前382年｜秦地日食，齐魏为卫夺取刚平

[← 公元前383年](bce-0383.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前381年 →](bce-0381.md)

## 本年纪事

<a id="event-1"></a>
**秦地发生日食，白昼昏暗。** 这项天象被列入秦献公三年的记载。[1](#note-1)

<a id="event-2"></a>
**齐、魏为援助卫国进攻赵国，夺取刚平。** 赵国前一年以刚平为据点侵逼卫国，现在遭到两国反击。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜昼晦与“既”是史籍的观测表述

[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0382)记日食、昼晦；[《资治通鉴》安王二十年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7001.md#ref-fdf77e3ad226bc)作日有食之既。保留其全食表述的文本依据，但本轮未独立历算日期、食分和秦地可见范围，不补一个现代公历日。

<a id="note-2"></a>
### 2｜齐、魏是来攻的一方，卫国是受援者

[《赵世家》敬侯五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-00ae9a93b91235)明确“齐、魏为卫攻赵，取我刚平”。原表赵栏仅列五，本次由世家补入；不能误译为齐、魏、卫三军都已得到独立参战记载。城邑前因见[前383年](bce-0383.md#event-3)，此后赵借楚兵伐魏见[前381年](bce-0381.md#sj015-0381-chu-zhao)。

# 公元前383年｜秦营建栎阳，赵败于兔台又向卫施压

[← 公元前384年](bce-0384.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前382年 →](bce-0382.md)

## 本年纪事

<a id="event-1"></a>
**秦献公营建栎阳。** 秦的政治中心继续向东经营，后来的孝公求贤令也把父亲迁治栎阳当作恢复国势的一部分。[1](#sj005-156-note)

<a id="event-2"></a>
**魏军在兔台击败赵军。** 赵前一年曾救魏对抗齐国，本年却与魏发生交战，短期合作并未消除相互竞争。[2](#note-2)

<a id="event-3"></a>
**赵国修筑刚平，向卫国施加军事压力。** 经营据点与侵逼邻国连在一起，随后齐、魏又将为卫国出兵。[3](#note-3)

## 本年相关史料

<a id="sj005-156-note"></a>
### 1｜栎阳沿旧事件合入年表

[卷005 P050](../../sources/摘录/史记-卷005-秦本纪.md#p050)与[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0383)均记献公二年城栎阳。原段与锚点保留，不新增第二次筑城；史籍回顾的迁治与本条营建，不因此被细化为同一日完成的全部工程。[卷005纪年口径](../../meta/考证/史记-卷005-纪年与异说.md)。

<a id="note-2"></a>
### 2｜兔台一役与翌年刚平之争分开

[卷015赵栏](../../sources/摘录/史记-卷015-六国年表.md#y0383)、[《赵世家》敬侯四年](https://zh.wikisource.org/wiki/史記/卷043#趙敬侯)及[《资治通鉴》安王十九年](https://zh.wikisource.org/wiki/資治通鑑/卷001)互见。正文只补胜败，未以此反推统帅、伤亡或与[前384年救魏](bce-0384.md#event-3)之间发生过一场有据的毁约仪式。

<a id="note-3"></a>
### 3｜筑刚平及下一年的反攻

《赵世家》同年接“筑刚平以侵卫”，五年记齐魏为卫攻赵、取刚平，故本页补前因，后果在[前382年](bce-0382.md#event-2)。具体城址和两役的月日未详，不把兔台、刚平强认成同一地。

### 本年另有待核的鲁君年条

所读《通鉴》校订网页在此补鲁穆公卒、共公立，与本项目暂沿年表前407年穆公元年、前376年共公元年的链条不同。本批未再写一个确定的穆公死亡，相关问题继续见[前429年鲁君年数说明](../bce-0500-0401/bce-0429.md#note-2)；不能因见到不同年份就令同一国君死两次。

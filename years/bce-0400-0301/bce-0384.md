# 公元前384年｜秦献公止从死，田侯剡纪元，赵军救魏

[← 公元前385年](bce-0385.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前383年 →](bce-0383.md)

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦献公停止以人从死的制度。** 他在元年改变秦君丧葬中的殉人做法。与武公、穆公时期的记载连读，可以看到秦自身的制度转折。 [[1]](#note-1)

<a id="event-2"></a>

2. **田侯剡进入元年，接续田和在齐的统治。** 吕氏康公仍在海边保有奉邑，田氏的新君与旧公室的残余地位同时存在。 [[2]](#note-2)

<a id="event-3"></a>

3. **赵军赴廪丘救援魏国，击败齐军。** 前些年还发生过魏袭邯郸，赵、魏如今又为对付齐国而共同作战，各国关系并非固定不变。 [[3]](#note-3)

## 归年与考证

<a id="sj005-155-note"></a>
<a id="1止从死与献公元年"></a>
#### 1｜止从死与献公元年

[卷005 P050](../../sources/摘录/史记-卷005-秦本纪.md#p050)记献公元年止从死，[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0384)提供元年坐标。原有事件和锚点保留。此处说的是史书所记制度举措，不能扩大为此后境内再无任何杀殉。实际迎立在[前385年](bce-0385.md#event-1)。


<a id="2原表的桓公午不作本年新君"></a>
#### 2｜原表的桓公午不作本年新君

[卷015齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0384)写“田和子桓公午立”，原字不改；正文依据《纪年》与研究补入田剡。此处元年采用前385年承位、前384年计元的方案，不把田午后来的弑君、在位与威王登场都提前。依据见[田齐君次考证](../../meta/考证/史记-卷015-田齐前期君次补核.md)。


<a id="3敬侯三年救魏与更早廪丘之战不合并"></a>
#### 3｜敬侯三年救魏，与更早廪丘之战不合并

[《赵世家》敬侯三年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-72947a3c396b2e)明确救魏于廪丘、大败齐人，按前386年元年系本年；原表本格只列三，并未直接写出这一战。本次以世家补入，未重排整条赵君纪年。它不是[前405年田会反廪丘](../bce-0500-0401/bce-0405.md#event-2)及其后战争的重复记载，也不能由本次救援推出两国此后永久结盟。

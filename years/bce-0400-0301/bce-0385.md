# 公元前385年｜秦迎立献公，韩军俘宋君，田剡承齐

[← 公元前386年](bce-0386.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前384年 →](bce-0384.md)

## 本年纪事

<a id="event-1"></a>
**庶长改迎回献公，出子及其母在政变中被杀。** 献公是早先未能继位的灵公之子。庶长改从河西迎他回来，拥立为君，出子母子被杀，尸体被沉入水中。秦的君位又一次由大臣改变，继承转回灵公的后裔。[1](#sj005-154-note)

<a id="event-2"></a>
**魏国修筑安邑、王垣。** 除了向外出兵，魏也继续经营自己的城邑据点。[2](#note-2)

<a id="event-3"></a>
**韩军攻郑，取得阳城；又进攻宋国，抵达彭城，俘获宋君。** 韩国的军事行动同时压向郑、宋两个方向。[3](#note-3)

<a id="event-4"></a>
**齐军攻鲁取胜。同年，田和去世，田剡继承田氏在齐的君位。** 田和刚取得诸侯名分不久，田氏统治便转到下一任；继位者不是后来篡位的田午。[4](#note-4)

## 本年相关史料

<a id="sj005-154-note"></a>
### 1｜献公被迎立，不是曾经在位后复位

[卷005 P049](../../sources/摘录/史记-卷005-秦本纪.md#p049)、[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0385)及[《资治通鉴》安王十七年](https://zh.wikisource.org/wiki/資治通鑑/卷001)合读。旧事件与锚点保留；庶长改是人名，不读成庶长改变主意。灵公之子此前未能继位，故此次是迎立，不说成复位。献公元年在[前384年](bce-0384.md#event-1)，不再制造一次政变。

“数易君、三晋夺河西”是多年局势总结，不把全部失地记作本年一场败战。秦君元年及古历口径仍见[卷005考证](../../meta/考证/史记-卷005-纪年与异说.md)。

<a id="note-2"></a>
### 2｜安邑、王垣是两处城邑

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0385)作“城安邑、王垣”。这里只补营建，不推定安邑直到本年才成为魏的政治中心，也不把王垣误作国君私人宅墙。原格未详工期和完成程度。

<a id="note-3"></a>
### 3｜俘宋君可靠，宋君身份和继位年仍须区别

[《韩世家》文侯二年](https://zh.wikisource.org/wiki/史記/卷045)及本年韩栏记取阳城、至彭城、执宋君。正文沿这些共同记载，不把攻郑、攻宋合成同一处围城。

所读《通鉴》校订网页在本年补称被俘者宋悼公、国人立休公田；其校刊记25说明相关文字从旧本前396年移来，但未详列所据研究。本次不据此再写一个已经确定的宋君死亡或休公元年，也不机械沿表中前395年元年认定俘虏必为休公。两套年链见[前395年宋君说明](bce-0395.md#sj015-0395-song-note)，此处落实的是韩国俘获宋君这件事，身份仍保留待核。

<a id="note-4"></a>
### 4｜补回田侯剡，不把漏代接成父子直传

齐攻鲁、田和卒见[本年齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0385)。继承主述采用《索隐》所引《纪年》及现代研究补出的田侯剡，不采用本纪、通鉴从田和直接接田午的漏代安排。田和终局暂系前385，田剡元年接[前384年](bce-0384.md#event-2)；详细依据与异年界限集中见[田齐君次考证](../../meta/考证/史记-卷015-田齐前期君次补核.md)。原表次年“桓公午立”仍照录为另一文本见证。

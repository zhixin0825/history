# 公元前386年｜田和获命为诸侯，赵国定都邯郸

[← 公元前387年](bce-0387.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前385年 →](bce-0385.md)

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **周王正式命田和为诸侯。** 田氏在齐掌权已经很久，田和先迁出齐康公，又争取魏方居间说项，现在获得王室的名分承认。吕氏康公仍在海边保有奉邑，这次命侯并不是又发生一次逐君。 [[1]](#note-1)

<a id="event-2"></a>

<a id="event-3"></a>

2. **赵敬侯元年迁邯郸，挫败公子朝与魏军来袭。** 赵敬侯把政治中心迁到邯郸。年内，前君武公的儿子朝起兵作乱，失败后逃到魏国，又与魏军袭击邯郸，仍未成功。君位从武公一支转回烈侯之子章以后，赵国还须应对宗室内部的挑战与魏国干预。秦出公、韩文侯、赵敬侯分别进入元年。秦、韩的新君接续父亲，赵敬侯章则接续叔父武公，三国的继承关系并不相同。 [[2]](#note-2)

## 归年与考证

<a id="1命侯迁康公和康公死亡分开"></a>
#### 1｜命侯、迁康公和康公死亡分开

[卷015本年齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0386)与[《资治通鉴》安王十六年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7001.md#ref-12153707d6f9d6)均系田和获命于本年。迁康公已在[前391年](bce-0391.md#event-2)，求封见[前389年的暂行安排](bce-0389.md#note-3)，不把年表同格回叙当作又迁一次。田和受命也不是立即称王；康公终局另见[前379年](bce-0379.md#event-3)。

有关浊泽及命侯、纪元是否应分置前387、386年的研究方案，见[田齐君次考证](../../meta/考证/史记-卷015-田齐前期君次补核.md)。本页保留年表、通鉴共同采用的命侯坐标，不将一篇研究的所有重排无说明地套入。


<a id="2朝是赵国公子魏赵两栏不是两次袭城"></a>
#### 2｜朝是赵国公子，魏赵两栏不是两次袭城

[《赵世家》敬侯元年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-4093b694d1745b)记武公子朝作乱、出奔魏，并记始都邯郸；《通鉴》接出与魏袭邯郸不克。[卷015魏、赵栏](../../sources/摘录/史记-卷015-六国年表.md#y0386)分别记录袭击及内乱，合为一次有前后的事件。迁都与作乱的月日先后未明，不能据排列推定魏军是在迁都当天来袭。

朝为人名，武公是其父；敬侯章是烈侯之子，见[前387年继承说明](bce-0387.md#note-3)。不把朝另认作同年被废的赵君。


<a id="3元年承前一年受立魏武侯不重新即位"></a>
#### 3｜元年承前一年受立，魏武侯不重新即位

秦、韩、赵的新君元年见本年相应国栏，实际继承已在[前387年](bce-0387.md)。出公、出子为同一秦君。年表魏栏还列武侯元年，但本项目已采用[前395年武侯元年](bce-0395.md#event-2)、[前396年文侯卒](bce-0396.md#note-2)，故本页不再给魏武侯安排第二次首次即位；原表年数照录。

# 公元前387年｜秦蜀争南郑，秦韩赵更换君主

[← 上一张已编年页：公元前389年](bce-0389.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前386年 →](bce-0386.md)

> 秦、韩、赵君位衔接沿本项目当前传世年链。魏文侯的终局采用前396年，本年只保留另一纪年的回链，不再重复死亡。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦与蜀在南郑一带发生争夺。** 南方据点的控制并不稳固，双方都力图掌握这处通道。 [[1]](#note-1)

<a id="event-2"></a>

2. **秦惠公去世，年幼的出子继位。** 秦国在南方用兵的同时，国内也进入幼主接掌君位的阶段。 [[2]](#note-2)

<a id="event-3"></a>

3. **韩烈侯去世，儿子继位，是为文侯；赵武公去世，国人重新拥立烈侯的儿子章，是为敬侯。** 韩是父子承继，赵则把君位从烈侯的弟弟一支转回烈侯之子，后者并不是赵武公的儿子。 [[3]](#note-3)

<a id="sj044-wuxia-event"></a>

4. **魏秦在武下交战，记载中又有俘获将领识的片段。** 本篇把这场战争列在旧文侯三十八年，现按旧年链暂附前387。胜负与将领所属的语法不够清楚，详细异读留在同号注。它后面接写文侯卒，与已采用的前396年卒年不合；战争和君主卒年分别处理，不把同一人重新写死。 [[4]](#sj044-wuxia-note)

## 归年与考证

<a id="sj005-153-note"></a>
<a id="sj005-153南郑争夺的方向与时序"></a>
#### sj005-153｜南郑争夺的方向与时序

[卷005 P048](../../拆分史书/史记/卷005.md#p048)说伐蜀取南郑，[卷015本年秦栏](../../拆分史书/史记/卷015.md#y0387)却作“蜀取我南郑”。原页用中性争夺叙述，本次仍保留，并补充研究依据；旧锚点没有删除。

段渝《先秦蜀国的都城和疆域》提出秦先取南郑、蜀随后反攻收复的解释，依据之一是《华阳国志》所载后来蜀拥有褒汉地区。这给出了调和两条记载的历史地理理由，但两次行动的精确时间、是否必在同一年度完成，仍不是两句短文已经独立详记的事实。因此本页将该方案放在同号注，不无说明地新增两场细节齐备的战役。

更早筑南郑、南郑反秦各在原年页，不合并成本次争夺。[秦君纪年口径](../../拆分史书/史记/卷005.md#kao-c691f26620)。


<a id="2秦惠公死亡从原合写条目分出"></a>
#### 2｜秦惠公死亡从原合写条目分出

《秦本纪》惠公十三年及[《资治通鉴》安王十五年](../../拆分史书/资治通鉴/卷001.md#text)记惠公去世、出子接位，原页已含此事；本次只拆成独立阅读段，不计为新发现的一次死亡。出子出生年差异仍见[前389年旧注](bce-0389.md#sj005-152-note)，不根据年龄反造精确生日。


<a id="3韩赵死亡由世家和次年元年合读"></a>
#### 3｜韩、赵死亡由世家和次年元年合读

[《韩世家》](../../拆分史书/史记/卷045.md#part-1-text)记列侯十三年卒、子文侯立；[《赵世家》](../../拆分史书/史记/卷043.md#part-1-text)记武公十三年卒、立烈侯太子章。《通鉴》同系本年，年表下一年各起新君元年。列、烈及赵武公、武侯为称谓互见，不另造同年两位同号新君。

这一局部衔接没有独立重校整个赵氏年数与谱系；此处采用明确写出的“烈侯之子”，避免误说父死子继。前386年的新君纪元和赵公子朝后续行动，接续时须分别处理，不能都提前到本年。

<a id="sj015-0387-wei-shift"></a>
<a id="4魏文侯之死只回链不在本年再发生"></a>
#### 4｜魏文侯之死只回链，不在本年再发生

《魏世家》文侯三十八年终局及《通鉴》安王十五年把死亡放在本年，与《纪年》文侯五十年、武侯二十六年的体系不同。当前正文采用[前396年文侯卒](bce-0396.md#note-2)、[前395年武侯元年](bce-0395.md#event-2)，本页登记旧说，不再给武侯安排第二次首次继位。

《通鉴》接在本年下面的吴起与武侯游西河、与田文论功、受公叔排挤、入楚等，是包含“久之”的跨时段叙述，不能全当成本年新事。魏君年代调整也不自动给这些故事一律确定新的发生年；本轮已将这组故事完整编入[吴起在鲁魏任职时期页](未定年-吴起在鲁魏任职与轶事.md)，仍保留逐事未确年的界限。

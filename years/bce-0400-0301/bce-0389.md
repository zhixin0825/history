# 公元前389年｜秦侵阴晋，田和在浊泽寻求名分

[← 上一张已编年页：公元前390年](bce-0390.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前387年 →](bce-0387.md)

> 浊泽会盟暂沿年表的前389年阅读位置；参与者中的“魏文侯”与本项目采用的卒年冲突，正文不据此让已故国君再次出场，详注3。

## 本年纪事

<a id="event-1"></a>
1. **秦惠公的太子出生。** 这就是以后短暂在位的出子。父亲去世时他仍很年幼，后来的政变不能忽略这一继承背景。[1](#sj005-152-note)

<a id="event-2"></a>
2. **秦军侵入魏国的阴晋。** 秦魏争夺由武城等处继续向其他据点展开，边境压力并未消失。[2](#note-2)

<a id="event-3"></a>
3. **田和在浊泽会盟期间争取诸侯名分，并获得魏方为他向周王及诸侯转达请求。** 掌握齐国实权以后，田和还需要外部承认，才能把卿族掌政转化为得到认可的诸侯地位。[3](#note-3)

## 本年相关史料

<a id="sj005-152-note"></a>
### sj005-152｜秦惠公的太子出生

[卷005 P048](../../sources/摘录/史记-卷005-秦本纪.md#p048)与[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0389)合读。年表惠公十一年“太子生”，本纪十二年“子出子生”，相差一年。本页沿原取舍采用前389，不据此补公历生日，也不新建前388年再记一次出生。旧事件1及史料入口保留。

秦君年数及古历口径见[卷005纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。

<a id="note-2"></a>
### 2｜阴晋是魏地，不把“阴”遗漏后另读成一个国家

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0389)、[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-10776342286f46)及[《资治通鉴》安王十三年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7001.md#ref-15c1edea54b41d)同记秦侵阴晋。简条本身没有交代胜负、将领或兵数；关于吴起与秦军交战的其他叙事，不能未经互校便套成同年“多少人破多少人”的确定战果。

<a id="note-3"></a>
### 3｜浊泽会盟与魏文侯卒年冲突，不以换名掩平

[卷015齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0389)记与晋、卫会浊泽；[《田敬仲完世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7046.md#ref-1e0ed0d0eaceab)补田和求为诸侯、魏文侯遣使为请；《通鉴》又列楚人。它们支持田和求封及魏方居间这一共同过程，但有关与会人的称谓和完整名单不能全视为已经核定。

本批依据《纪年》及现代研究把魏文侯死亡放在[前396年](bce-0396.md#note-2)，于是“前389年魏文侯亲自会田和”不能再作确定正文。此处暂保留年表的会盟坐标，用魏方表达共同的政治关系；既不静默把文侯改成武侯，也不据这一处矛盾就将整场会盟强移到另一确年。具体人物与绝对日期的组合仍待专题核校。

[前391年迁出齐康公](bce-0391.md#event-2)、浊泽求封、后续前386年周王正式命田和为诸侯，各有不同性质。求得支持不等于已经在本年完成全部册命手续；楚、卫的参与也不据简记补出一份完整盟约。

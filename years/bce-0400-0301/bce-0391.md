# 公元前391年｜秦取韩六邑，田和迁齐康公于海上

[← 公元前392年](bce-0392.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前390年 →](bce-0390.md)

## 本年纪事

<a id="event-1"></a>
**秦军进攻韩国宜阳一带，夺取六座城邑。** 韩国在与郑、楚等国周旋之外，也承受着来自西面的军事压力。[1](#note-1)

<a id="event-2"></a>
**田和把齐康公迁到海边，只留一座城供他奉养先君的祭祀。** 田氏早已掌握齐国大权，如今进一步排除吕氏国君对政事的参与；康公尚有奉邑，田和却还要争取诸侯与周王对自己地位的承认。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜秦、韩两栏记同一战役

[卷015秦、韩栏](../../sources/摘录/史记-卷015-六国年表.md#y0391)互记秦伐韩宜阳、取六邑；[《韩世家》列侯九年](https://zh.wikisource.org/wiki/史記/卷045)及[《资治通鉴》安王十一年](https://zh.wikisource.org/wiki/資治通鑑/卷001)相合。六邑是原载数量，未给各邑名称；不把“伐宜阳”扩大成已证明宜阳主城同时陷落，也不移用前307年秦武王攻宜阳的将领和战果。

<a id="note-2"></a>
### 2｜迁出国君、请求名分和正式受命分开

[《田敬仲完世家》](https://zh.wikisource.org/wiki/史記/卷046)以康公十四年记田和迁康公于海上、食一城；《通鉴》同归本年。田和是此时田氏掌权者，不能因别处提到的田会、田常与他同姓，就合成同一人或同一次逐君。

年表在后面的前386年又将迁康公、田和列侯压在一格，正文不据压缩叙述把逐君重演一次。[前389年的浊泽求封](bce-0389.md#event-3)及后续前386年正式命侯，是相连但不同的阶段。海上暂写海边，不指定已经考定的岛屿或宫址；世家对康公好酒失政的评价留作其政治叙述背景，不当成独立证实的全部逐君原因。

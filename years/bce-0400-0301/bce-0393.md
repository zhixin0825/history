# 公元前393年｜魏伐郑筑酸枣，楚取负黍

[← 公元前394年](bce-0394.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前392年 →](bce-0392.md)

## 本年纪事

<a id="event-1"></a>
**魏军进攻郑国，并在酸枣筑城。** 出兵与城邑经营相连，使魏国在这一方向保持军事存在。[1](#note-1)

<a id="event-2"></a>
**楚军进攻韩国，夺取负黍。** 负黍前一年才从郑转归韩，如今又受到楚军进攻，城邑归属接连变化。[2](#note-2)

<a id="event-3"></a>
**晋烈公去世，儿子接位，是为孝公。** 韩、赵、魏已经成为诸侯，晋公室仍延续自己的君位，并未在三家受命时立即消失。[3](#note-3)

## 本年相关史料

<a id="note-1"></a>
### 1｜魏伐郑、城酸枣，不由国君纪年差别再造一役

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0393)列伐郑、城酸枣，[《资治通鉴》安王九年](https://zh.wikisource.org/wiki/資治通鑑/卷001)亦系魏伐郑于本年。正文暂沿这组编年记载保留事件位置，不因本批采用文侯前396年卒，就把本年战争整体平移；《通鉴》与年表的互见并不一定是两份独立证据。正文不称由已经去世的文侯亲征，原格的文侯三十二年仍照录。

[《魏世家》](https://zh.wikisource.org/wiki/史記/卷044)相对年条另接“败秦于注”；该战的绝对年与地点尚未在本批取得足够独立互证，不直接混为这次攻郑的同一战果。筑酸枣不擅推具体工期、驻军人数或现代县界。

<a id="note-2"></a>
### 2｜楚取负黍发生于归韩以后

[卷015楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0393)为悼王九年伐韩取负黍，承[前394年叛郑归韩](bce-0394.md#event-2)。这是本表给出的绝对年坐标；楚王整条年链的其他研究方案仍见[前408年注6](../bce-0500-0401/bce-0408.md#note-6)。不把楚军说成前一年发动郑境叛乱的一方，也不补原文没有的战斗经过。

<a id="note-3"></a>
### 3｜晋君终局采用当前传世年链

《通鉴》同年记晋烈公卒、子孝公倾立；[《晋世家》](https://zh.wikisource.org/wiki/史記/卷039)记烈公二十七年卒、子孝公颀立。按既有前419年烈公元年与本表次年孝公元年相接，终局暂放本年。倾、颀为所读见证的名号差别，不列成两个新君；晋君年数的其他重构未因本次衔接而全部解决。[前392年](bce-0392.md)只接元年。

# 公元前394年｜韩救鲁，负黍叛郑归韩

[← 公元前395年](bce-0395.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前393年 →](bce-0393.md)

## 本年纪事

<a id="event-1"></a>
**齐军进攻鲁国，攻取最邑，韩国出兵救鲁。** 鲁国受到的军事压力引来了外援，战事不再只是齐鲁两国之间的较量。[1](#note-1)

<a id="event-2"></a>
**郑国的负黍叛离郑国，重新归附韩国。** 这个曾经成为韩郑战场的地方，又一次改变所属；郑国在君位变动之后，仍要应对地方脱离。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜韩救鲁与齐取最，按两国栏位合读

[卷015韩、齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0394)分别记救鲁、伐鲁取最；[《资治通鉴》安王八年](https://zh.wikisource.org/wiki/資治通鑑/卷001)同载。所读网页校刊记援引旧版本及年表补“韩救鲁”，不是现代编辑另造一支援军。最是城邑名，不译成鲁国“最大”的城池。援军是否夺回最邑、齐军怎样撤退均未详，不写成已经确定的解围大胜。

<a id="note-2"></a>
### 2｜本年是叛附，次年还有楚军进攻

韩栏“郑负黍反”由[《郑世家》](https://zh.wikisource.org/wiki/史記/卷042)康公二年及《通鉴》补明复归韩。此前[前407年郑败韩于负黍](../bce-0500-0401/bce-0407.md#event-2)是一场战斗，不是本年的再次叛附；下一年[楚取负黍](bce-0393.md#event-2)又是外军进攻。三件事各有时间与行动者，不能因地名相同便删为一条。地方叛附的首领、谈判和具体日月没有据此补出。

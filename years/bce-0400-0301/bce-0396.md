# 公元前396年｜郑繻公遇害，魏文侯去世

[← 公元前397年](bce-0397.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前395年 →](bce-0395.md)

> 魏文侯的卒年采用依据《竹书纪年》重建的前396年；《史记》旧年链及《通鉴》前387年的另一安排在同号注中保留，原始年表数字不改。

## 本年纪事

<a id="event-1"></a>
**郑国驷子阳的党羽杀死繻公駘，拥立他的弟弟乙，是为康公。** 两年前子阳被国君处死，此后他的党羽转而袭击国君，郑国公室的内部冲突终于造成又一次君位变动。[1](#note-1)

<a id="event-2"></a>
<a id="sj015-0396-weiwen-death"></a>
**魏文侯去世，儿子击接掌魏国，是为武侯。** 击此前已参与围城、迁民和中山经营，现由承担军事任务的公子成为国君。魏国在文侯时期取得的诸侯名分、城邑与军事实力，也交到了下一代手中。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜被杀的执政与后来遇害的国君，分别归年

[卷015本年韩栏](../../sources/摘录/史记-卷015-六国年表.md#y0396)记郑相子阳之徒杀繻公；[《郑世家》](https://zh.wikisource.org/wiki/史記/卷042)系繻公二十七年，[《资治通鉴》安王六年](https://zh.wikisource.org/wiki/資治通鑑/卷001)并记立弟乙。正文采用《通鉴》的兄弟关系，与前422年繻公元年的现行链条衔接。

子阳本人被杀仍在[前398年](bce-0398.md#event-2)，不是到本年才死；[前397年](bce-0397.md#sj-086-L5399-01)原表括注的“郑人杀君”不再产生另一场相同政变。康公实际被立在此，次年只接元年；袭击的具体日月和参加者名单没有补造。

<a id="note-2"></a>
### 2｜采用文侯五十年、武侯二十六年的年代框架

[《魏世家》及三家注](https://zh.wikisource.org/wiki/史記三家註/卷044)保存两套在位数：本篇文侯三十八年卒、武侯十六年卒，《索隐》引《纪年》则分别为五十年、二十六年。按原表前424年文侯元年的旧链，终局落在前387年；这不是当前正文采用的年代。

胡平生[《安大简〈诗经〉“矦”为“魏风”说》](https://wxs.swu.edu.cn/info/1025/1484.htm)明确介绍方诗铭《中国历史纪年表》所用安排：文侯前445—396年、武侯前395—370年；马卫东、王政冬[《清华简〈繫年〉三晋伐齐考》](https://www.fdgwz.org.cn/Web/Show/1943)也讨论文侯五十年及另一种称侯改元计数。此处据《纪年》系年与现代研究采用前396年死亡、[前395年武侯元年](bce-0395.md#event-2)，不声称网页或简牍本身直接写有这些公元年份。

[前387年旧纪年回链](bce-0387.md#sj015-0387-wei-shift)只登记异年，不再写文侯又死一次。原表本年魏栏“二十九”及后续数字仍按见证保留；不能为了校正一个卒年，把所有仅按文侯相对年数系定的战争整体平移九年。每项史事须有自己的同步依据，尤其前389年浊泽会盟所称“魏文侯”，另在[该年注3](bce-0389.md#note-3)说明。

公子击的早年活动可回读[前412年](../bce-0500-0401/bce-0412.md#event-1)、[前408年](../bce-0500-0401/bce-0408.md#event-3)。此处只承接已经入编的前事，不把后来的吴起离魏等故事全部倒填到即位当年。

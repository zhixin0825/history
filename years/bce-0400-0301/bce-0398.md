# 公元前398年｜楚军围郑，郑国处死驷子阳

[← 公元前399年](bce-0399.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前397年 →](bce-0397.md)

## 本年纪事

<a id="event-1"></a>
**楚军击败郑军，进而包围郑国。** 前一年归还榆关，并没有使两国的军事冲突停止。[1](#note-1)

<a id="event-2"></a>
**郑国处死执政驷子阳。** 对外战争之外，郑国的内部权力关系也发生剧变；子阳与国君之间的冲突，后来还将引出党羽的报复。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜败郑军与围郑属于同一楚军行动

[卷015楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0398)列“败郑师，围郑”，[《资治通鉴》安王四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7001.md#ref-702c18063e3e09)同事。原文没有细列兵力、将领、攻城经过和郑都是否陷落，正文不把围攻擅写成已经灭郑；此前[前399年榆关](bce-0399.md#event-4)仍是独立交地事件。

<a id="note-2"></a>
### 2｜一位执政被杀，不是本年国君也被杀

[卷015韩、楚两栏](../../sources/摘录/史记-卷015-六国年表.md#y0398)都记郑杀子阳，合入同一事件；[《郑世家》繻公段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7042.md#ref-0f9b7c5b0eae94)明确“郑君杀其相子阳”，并把其党弑繻公另放在两年后的二十七年。不能将执政之死与国君之死压成同一天，也不把这位驷子阳与更早的子产、子驷、子孔混同。

《通鉴》将楚围郑与子阳被杀接写，但没有充分说明两者直接因果。正文不补“因战败被处死”“楚要求交出宰相”等无据缘由。本年二十五年与本项目繻公元年前422年的链条相接；后续政变仍待下一批，前397年表中的括注也不能自动制造第二次弑君。

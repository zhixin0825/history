<a id="event-1"></a>

1. **秦惠公、韩烈侯取、赵武公开始各自的新纪年。** 秦、韩是父子承继，赵则由烈侯的弟弟接掌；相近的元年背后，并非同一种亲属关系。 [[1]](#note-1)

<a id="event-2"></a>

2. **周王子定离开王畿，投奔晋地。** 王室仍有人选择到强卿掌权的地区寻求容身之处。 [[2]](#note-2)

<a id="event-3"></a>

3. **虢山崩塌，阻塞黄河。** 山体变化使河道受到堵塞；具体灾情并没有完整留下。 [[3]](#note-3)

<a id="event-4"></a>

4. **楚国把榆关归还郑国。** 这次交还地方与此前三晋攻楚、郑围阳翟，分别属于同一时期不同方向的互动。 [[4]](#note-4)

## 归年与考证

<a id="1死亡承位在前一年元年在本年"></a>
#### 1｜死亡、承位在前一年，元年在本年

[卷015秦、韩、赵栏](../../sources/摘录/史记-卷015-六国年表.md#y0399)列三位新君元年。[《资治通鉴》安王二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7001.md#ref-4dc5c7a2845d98)及韩、赵世家分别记前君死亡与接任，已合入[前400年](bce-0400.md#event-4)。烈、列以及赵武公、武侯为所读文本的称谓差别，不另造一组新君；此赵武公也不是早期赵武。


<a id="2王子定出奔不补无据的夺位动机"></a>
#### 2｜王子定出奔，不补无据的夺位动机

[卷015周栏](../../sources/摘录/史记-卷015-六国年表.md#y0399)与《通鉴》安王三年同记“王子定奔晋”。原文未说明他是安王的儿子还是王室其他支系，也未说明投奔三家中的哪一家，不把“晋”换成已确定的赵、魏目的地，不编造一场已证实的王位政变。


<a id="3灾害记录与地理精度"></a>
#### 3｜灾害记录与地理精度

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0399)、《魏世家》文侯二十六年及《通鉴》安王三年均记虢山崩、壅河。本文只补山崩阻河，不无据推成地震，亦不补坝高、淹没范围、死者数字或疏浚日期；“河”是黄河，不是本年有一条名为虢河的新河流。


<a id="4榆关按原名不配现代关城"></a>
#### 4｜榆关按原名，不配现代关城

[卷015楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0399)记“归榆关于郑”。此处只写交还，不认定已签订永久同盟，也不直接配为后世山海关。下一年楚再攻郑另有年条，不能因本年归地便删去后续战争。

# 公元前400年｜三晋伐楚，秦韩赵更换君主

[← 公元前401年](../bce-0500-0401/bce-0401.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前399年 →](bce-0399.md)

## 本年纪事

<a id="event-1"></a>
1. **秦简公去世，君位转交儿子惠公。** 灵公死后转入旁支的继承，在这里继续传给简公之子。这个惠公不能与春秋时期的同号秦君混同。[1](#sj005-151-note)

<a id="event-2"></a>
2. **魏、韩、赵联合进攻楚国，兵锋推进到乘丘。** 三家已取得周王承认，又共同对楚用兵。[2](#note-2)

<a id="event-3"></a>
3. **郑军包围韩地阳翟。** 韩与郑之间的争夺，延续了前些年的雍丘、负黍战事。[3](#note-3)

<a id="event-4"></a>
4. **韩景侯和赵烈侯去世，两国各自更换君主。** 韩由景侯之子取继位，是为烈侯；赵则由烈侯的弟弟接位，是为武公。[4](#note-4)

<a id="event-5"></a>
5. **魏文侯的孙子罃出生。** 他的父亲是公子击，后来成为魏武侯；罃则是更晚一代的魏惠王。祖父、父亲、儿子的君号不能混作同一人。[5](#note-5)

## 本年相关史料

<a id="sj005-151-note"></a>
### 1｜秦简公终局与原有纪年异说

[卷005 P047](../../sources/摘录/史记-卷005-秦本纪.md#p047)。本纪记简公十六年卒，年表前400为十五年、前399已是惠公元年；沿旧页采用前400，保留一年之差。《资治通鉴》安王二年也记简公卒、子惠公立。旧事件与锚点均保留，没有再添一位同号秦君。

[秦君纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不直接转换为同号公历月日。

<a id="note-2"></a>
### 2｜三晋来伐楚是一场联军行动

[卷015楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0400)作“三晋来伐我，至乘丘”；[《资治通鉴》安王二年](https://zh.wikisource.org/wiki/資治通鑑/卷001)明列魏、韩、赵。原表三家本格没有重复战争文字，不因此删去这次联军。乘、桑的异文见三家注及通鉴校文，正文采用乘丘，不由形近另造两处战果。

<a id="note-3"></a>
### 3｜围阳翟，不擅写城已陷落

[卷015韩栏](../../sources/摘录/史记-卷015-六国年表.md#y0400)及[《韩世家》景侯九年](https://zh.wikisource.org/wiki/史記/卷045#韓景侯)、通鉴同年都记郑围阳翟。原文未交代攻城结果和将领，也未说韩君死于围城；不因两件事相邻便补出战死因果。

<a id="note-4"></a>
### 4｜父子承继与兄弟承继不同

《韩世家》景侯九年卒、子列侯取立；[《赵世家》](https://zh.wikisource.org/wiki/史記/卷043#趙烈侯)记烈侯九年卒、弟武公立，通鉴同归本年。[前399年](bce-0399.md#event-1)只记新君元年。列、烈以及赵武公、武侯为相关文本称谓，不能因此再生出两次君位变动。

<a id="note-5"></a>
### 5｜太子罃是后来的称谓，不是魏文侯的亲生太子

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0400)作“太子罃生”；[《魏世家》文侯二十五年](https://zh.wikisource.org/wiki/史記/卷044#魏文侯)明确“子击生子罃”。据此补出两代父子关系，暂按该年条系出生，不倒推未经核实的生日，也不宣称婴儿当年已被立为文侯的太子。其后诸王在位年数的争议不由本条全部解决。

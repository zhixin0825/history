# 战国中期｜孟子、邹衍与稷下学士的思想活动

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷074全篇释读](../../拆分史书/史记/卷074.md) · [纪年考证](../../拆分史书/史记/卷074.md#kao-f1c133cded)

这是思想活动的**跨期读本**，不冒充某一个公元前年。孟子、邹忌、邹衍、淳于髡、荀卿等并非同世同任；史书记载的访问、学派与著述先后有难辨处。

## 故事与观点

<a id="event-1"></a>

1. **史家从“利”切入思想与政治。** 司马迁将私利与诸侯纷争关联，但这是他的价值判断，不是孟子本人回答梁惠王的所有内容。 [[1]](#note-1)

<a id="event-2"></a>

2. **孟轲游说齐梁，却难在重军功的时代获用。** 孟子提尧舜与三代德政，与商鞅、吴起、孙膑等以富国强兵见用的时代形成对照；游齐与游梁次第有纪年难题。 [[2]](#note-2)

<a id="event-3"></a>

3. **邹衍提出阴阳五德与赤县神州。** 邹衍从小事推极远之天地，提出赤县神州、九州与层层大海。这是古人的世界图景，不可当作实测地理。 [[3]](#note-3)

<a id="event-4"></a>

4. **邹衍游诸侯受到极高礼遇。** 齐、梁、赵、燕各有礼遇传说，人物王年跨度很大；司马迁借其受宠与孔孟的困顿对照。 [[4]](#note-4)

<a id="event-5"></a>

5. **淳于髡在梁惠王前两次不说话。** 淳于髡看出王忙着想马与声乐，不急于空谈，待王专心后才谈三日不倦。 [[5]](#note-5)

<a id="event-6"></a>

6. **齐王礼遇稷下学士。** 齐以列大夫身份、府宅礼贤，希望吸引各国著述之士，职位并非人人都为丞相。 [[6]](#note-6)

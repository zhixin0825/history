# 吴起在鲁魏任职与轶事｜逐事年份未定

[本世纪目录](README.md) · [全部世纪](../README.md) · [前381年楚国终局](bce-0381.md)

本页收吴起事鲁、事魏及离魏赴楚前的故事，时间跨文侯、武侯两朝，逐事年月未定；篇章叙次只用来保存明确的前后关系。齐攻鲁、魏伐秦的现有确年条目仍留原年，不以相似战端强配。楚国改革及遇害接[前381年](bce-0381.md#reading-event-1)。这里的人物故事含当事人攻讦与史家叙事，各层次在同号史料注明。

[本时期相关史料](#sources-start)

<a id="sj065-wuqi-event-1"></a>

1. **吴起事鲁，杀妻求将后击败齐军。** 吴起是卫国人，喜好用兵，曾向曾子学习，后来事奉鲁君。齐国攻鲁，鲁国想任用吴起为将，却因他的妻子是齐国人而怀疑他。吴起为了成就名声，竟杀死妻子，表明自己不亲附齐国。鲁国终于任他为将，他率军攻齐，大败齐军。 [[1]](#sj065-wuqi-note-1)

<a id="sj065-wuqi-event-2"></a>

2. **鲁人的指斥引起猜疑，吴起离鲁。** 鲁国有人向鲁君说吴起的坏话：“吴起是个猜忌残忍的人。他年轻时家有千金，出外求仕不成，把家产耗光了。同乡邻里笑他，他就杀了三十多个讥笑自己的人，出了卫国东门。与母亲告别时，他咬着自己的手臂发誓：‘不做卿相，便不再回卫国。’随后跟从曾子。过了一段时间，母亲去世，他始终不回。曾子鄙薄他，与他断绝关系。他才到鲁国学兵法以事鲁君。鲁君疑他，他便杀妻求将。鲁国是个小国，却有战胜强敌的名声，诸侯便会图谋鲁国。何况鲁、卫是兄弟之国，您用吴起，就是舍弃卫国。”鲁君疑惧，于是辞退吴起。 [[2]](#sj065-wuqi-note-2)

<a id="sj065-wuqi-event-3"></a>

3. **魏文侯任吴起为将，攻秦取五城。** 吴起听说魏文侯贤明，想去事奉。文侯问李克：“吴起为人怎样？”李克说：“他贪求而好色；但论用兵，即使司马穰苴也不能超过他。”魏文侯于是任他为将，攻秦，夺取五座城。 [[3]](#sj065-wuqi-note-3)

<a id="sj065-wuqi-event-4"></a>

4. **吴起与士卒同甘苦，亲自为病卒吮疽。** 吴起任将领，衣食与最普通的士卒相同，睡觉不铺席，行军不乘车骑马，自己包扎携带粮食，与士卒分担劳苦。有士卒患疽，吴起亲自为他吸吮疮处。士卒的母亲听说后哭了。有人问：“您的儿子只是个士卒，将军却亲自为他吮疽，您为何哭呢？”母亲说：“不是这样。往年吴公曾替他父亲吮疽，他父亲从此在战场上毫不退缩，终于死于敌手。现在吴公又为他的儿子这样做，我不知道儿子将死在哪里，因此才哭。” [[4]](#sj065-wuqi-note-4)

<a id="sj065-wuqi-event-5"></a>

5. **魏文侯任吴起为西河守。** 魏文侯认为吴起善于用兵，廉洁公平，能够充分得到士卒之心，于是任他为西河守，抵御秦国、韩国。 [[5]](#sj065-wuqi-note-5)

<a id="sj065-wuqi-event-6"></a>

6. **武侯赞山河险固，吴起劝修德政。** 魏文侯死后，吴起事奉其子武侯。武侯泛舟顺西河而下，到河中回望，对吴起说：“山河险固，真美啊，这是魏国的宝物！”吴起回答：“国家的凭借在德政，不在险要。昔日三苗之地左有洞庭、右有彭蠡，却不修德义，被禹灭掉。夏桀所居左有河济、右有太华，南有伊阙、北有羊肠，却施政不仁，被汤放逐。殷纣之国左有孟门、右有太行，北有常山、大河流经其南，却治政无德，被武王杀死。由此可见，关键在德，不在险。您若不修德政，船里的人也都能成为敌人。”武侯答：“说得好。” [[6]](#sj065-wuqi-note-6)

<a id="sj065-wuqi-event-7"></a>

7. **吴起与田文论功，承认国政所托不同。** 吴起任西河守，声名很大。魏国设置相位，任田文为相。吴起不高兴，问田文能否比较功劳，田文答应。吴起问：“统率三军，使士卒愿意效死，使敌国不敢图谋，您比我怎样？”田文答不如。又问：“治理百官、亲近万民、充实府库，您比我怎样？”仍答不如。再问：“守西河使秦军不敢东进，韩赵宾服，您比我怎样？”也答不如。吴起说：“这三方面您都在我之下，为何职位在我之上？”田文说：“君主年少，国人疑虑，大臣尚未归附，百姓不信服，这时候该把国政托付给您，还是托付给我？”吴起沉默很久，答：“该托付给您。”田文说：“这就是我地位在您之上的缘故。”吴起于是知道自己在这一点不如田文。 [[7]](#sj065-wuqi-note-7)

<a id="sj065-wuqi-event-8"></a>

8. **公叔设计婚议，吴起失去武侯信任而离魏。** 田文死后，公叔为相，娶魏公主为妻，却忌恨吴起。公叔的仆人说：“吴起很容易赶走。”公叔问办法，仆人说：“吴起清廉守节，又很看重名声。您先对武侯说：‘吴起是贤才，可您的国家小，又和强秦接壤，我私下担心他没有留下的意思。’武侯问怎么办，您便说：‘试着提出把公主嫁给他；有意留下必接受，无意留下必推辞，可以借此探测。’然后您请吴起一同回家，让公主发怒、轻慢您；吴起看见公主鄙视您，必会拒婚。”吴起见到公主轻贱魏相，果然辞谢武侯的婚议。武侯于是怀疑他，不再信任。吴起怕获罪，便离魏赴楚。 [[8]](#sj065-wuqi-note-8)

<a id="sj065-cite-016"></a>

<a id="sj065-cite-017"></a>

## 史家论说与唐代追赞｜不作本时期事件

太史公说：世人谈论军旅，都会说到《孙子》十三篇和吴起的兵法，这些书流传很多，所以我不再讨论它们，而记述这些人在行事中怎样运用其所学。俗语说，能实行的人不一定善于说，善于说的人不一定能实行。孙膑谋算庞涓，确实明智，却不能早些避免自己受刑的灾祸。吴起告诉魏武侯，地势不如德政可靠，到了楚国施政，却因刻暴少恩而丧命。可悲啊！主TXT“孙子十三篇，，世多有”有缺词，白话据三家注p14补出“吴起兵法”；这是司马迁的评价，不当作新发现的遇害原因定论。


<a id="sj065-cite-018"></a>

**[《史记·孙子吴起列传》P015](../../sources/摘录/史记-卷065-孙子吴起列传.md#p015)**

> 太史公曰：世俗所稱師旅，皆道孫子十三篇，，世多有，故弗論，論其行事所施設者。語曰：「能行之者未必能言，能言之者未必能行。」孫子籌策龐涓明矣，然不能蚤救患於被刑。吳起說武侯以形勢不如德，然行之於楚，以刻暴少恩亡其軀。悲夫！

**本卷说明：** 论说写在司马迁时代，不标成吴起在魏时发生的事件。主TXT“孙子十三篇，，世多有”有脱文，依注本补释《吴起兵法》，原字不改。

<a id="sj065-tang-review"></a>

### 唐代司马贞述赞

司马贞赞述说：孙子的兵法共有十三篇，宫中美女被斩，吴王因而得到良将；孙膑遭刖足之刑，却谋胜庞涓。吴起在魏辅政，在西河有贤能之名；到楚施行严酷之政，身死以后仍留下权谋的作用。赞中的“相魏”与正文未得相位、任西河守有张力，宜保留赞语而不据它另造一次任魏相；“死后留权”暂联系伏于王尸、使射中王尸者受诛的叙事来理解，不补具体持续施行的制度年数。



<a id="sj065-cite-019"></a>

**[《史记·孙子吴起列传》Z001](../../sources/摘录/史记-卷065-孙子吴起列传.md#z001)**

> 索隱述贊曰：孫子兵法，一十三篇。美人旣斬，良將得焉。刖孫臏脚，籌策龐涓。吳起相魏，西河稱賢；慘礉事楚，死後留權。

**本卷说明：** 唐代赞语单列；“相魏”不据以新增吴起任魏相一事，“死后留权”暂联系伏王尸与诛族结果，不写成吴起死后改革仍长期施行的定论。

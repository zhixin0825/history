# 战国中后期｜张仪、陈轸与犀首的外交游说（未定年与跨年附读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷070完整读本](../../sources/摘录/史记-卷070-张仪列传.md) · [纪年与异说](../../meta/考证/史记-卷070-纪年与异说.md)

本页只收《张仪列传》中未有确年或跨越数年、多国的游说、人物前事与后世评价。可定年者仍归已有[前316年秦取蜀](bce-0316.md#note-1)、[前313年楚绝齐](bce-0313.md#note-3)、[前312年秦楚战](bce-0312.md#note-1)等单一时间线，不能将外交威胁的假设路线当作发生过的战役。

## 依传文顺序附读

<a id="event-1"></a>

1. **楚相亡璧，张仪受辱。** 张仪被门下人冤为盗璧受杖责，仍说舌在便足以游说；这段传记轶事没有可靠绝对年月。 [[1]](#note-1)

<a id="event-2"></a>

2. **苏秦激张仪入秦的传统故事。** 苏秦故意让张仪蒙羞、暗给资源、促其入秦；马王堆出土材料后苏秦年次有争论，不把传统相会叙法压进某一公元前年。 [[2]](#note-2)

<a id="event-3"></a>

3. **伐蜀与伐韩的两种战略方案。** 张仪要取周室三川，司马错要先夺蜀国的土地与财富；秦王后来取蜀是可确年事实，双方长篇对话作为议论存此。 [[3]](#note-3)

<a id="event-4"></a>

4. **诱楚绝齐的商於六百里许诺。** 张仪以割商於诱楚绝齐；前313、312的真正外交与战争见已编年年页，张仪的长篇策论与史家叙述不可混成一场战争。 [[4]](#note-4)

<a id="event-5"></a>

5. **张仪连横游说韩齐赵燕。** 张仪对不同国君分别威吓秦兵压境、他国会投秦；这些外交说辞的对话与假设线路无确年，不把他威胁要攻的城邑误作已攻下。 [[5]](#note-5)

<a id="event-6"></a>

6. **陈轸与张仪在秦争宠。** 二人围绕秦楚关系互相指斥，陈轸后来奔楚、经过魏国；谗辞不能拿来证明谁确实受贿或背叛。 [[6]](#note-6)

<a id="event-7"></a>

7. **犀首公孙衍劝义渠。** 五国攻秦，犀首向义渠说明秦国忙于东方时才愿厚赂，传文还写义渠袭秦获胜；战事与前318已编年主线互读。 [[7]](#note-7)

<a id="event-8"></a>

8. **太史公的评价。** 司马迁认为张仪苏秦擅长倾危权变；这是后来的价值判断，不是可确年的历史事件。 [[8]](#note-8)

# 战国时期｜诸子活动与兵学传承（未定年）

[本世纪目录](README.md) · [全部时间目录](../README.md)

**时间精度：** 庄周的经历由梁惠王、齐宣王及楚威王时期定位；齐威王整理兵法属于另一位齐君的在位时期。故事和编书皆未获独立确年，各条不表示同年或先后。

<a id="reading-start"></a>

[本期相关史料](#sources-start)

<a id="sj063-zhuangzi-life-event"></a>

1. **庄周曾为漆园吏，著述借寓言陈说道理。** 庄周是蒙人，与梁惠王、齐宣王同时，曾做蒙地漆园的官吏。他广泛涉猎，思想归本老子，著书十余万字，多设寓言。传记把《渔父》《盗跖》《胠箧》概括为批评儒者、阐明老说，又指出畏累虚、亢桑子等是虚设言辞；他善于铺陈、分析和比拟，攻击儒墨，言论奔放，王公难以把他作为臣属之器任用。 [[1]](#sj063-zhuangzi-life-note)

<a id="sj063-zhuangzi-refuses-event"></a>

2. **楚威王厚礼聘相，庄周以牺牛之喻拒绝。** 楚王派人带厚礼迎请，许以国相，庄周却说，千金和卿相固然富贵，好比郊祭之牛，供养数年、披上绣衣送入太庙，到那时想做一头小猪也不可得。他宁可在污浊小沟中自在游玩，也不愿被君主束缚，便请使者离开，表示终身不仕以快心志。 [[2]](#sj063-zhuangzi-refuses-note)

<a id="sj064-military-book-event"></a>

3. **齐威王追论古司马兵法，把穰苴之法附入成书。** 在后来的田齐，威王用兵建立威势，被说大体效法穰苴，诸侯来朝。他又令大夫追溯讨论古司马兵法，将穰苴的兵法附入，因而有《司马穰苴兵法》之名。 [[3]](#sj064-military-book-note)

### 1. 庄周曾为漆园吏，著述借寓言陈说道理

[返回正文第1条](#sj063-zhuangzi-life-event)

<a id="sj063-cite-010"></a>

**[《史记·老子韩非列传》P009](../../sources/摘录/史记-卷063-老子韩非列传.md#p009)**

> 莊子者，蒙人也，名周。周嘗為蒙漆園吏，與梁惠王、齊宣王同時。其學無所不闚，然其要本歸於老子之言。故其著書十餘萬言，大抵率寓言也。作漁父、盜跖、胠篋，以詆訿孔子之徒，以明老子之術。畏累虛、亢桑子之屬，皆空語無事實。然善屬書離辭，指事類情，用剽剝儒、墨，雖當世宿學不能自解免也。其言洸洋自恣以適己，故自王公大人不能器之。

**本卷说明：** 蒙的现代地望有争议，古注引刘向为宋之蒙，正文不指定现代县市。梁惠王与齐宣王只是时代范围；通行前369—286不是本句给出的生卒。篇中人物与故事不能直接当作庄周亲历；对儒墨的评价保留为传记叙述。

<!-- /sj063-cite-010 -->

<a id="sj063-zhuangzi-refuses-note"></a>

### 2. 楚威王厚礼聘相，庄周以牺牛之喻拒绝

[返回正文第2条](#sj063-zhuangzi-refuses-event)

<a id="sj063-cite-011"></a>

**[《史记·老子韩非列传》P010](../../sources/摘录/史记-卷063-老子韩非列传.md#p010)**

> 楚威王聞莊周賢，使使厚幣迎之，許以為相。莊周笑謂楚使者曰：「千金，重利；卿相，尊位也。子獨不見郊祭之犧牛乎？養食之數歲，衣以文繡，以入大廟。當是之時，雖欲為孤豚，豈可得乎？子亟去，無污我。我寧游戲污瀆之中自快，無為有國者所羈，終身不仕，以快吾志焉。」

**本卷说明：** 只按楚威王时期收录。现用楚王链是前340承位、前339元年、前329卒；正义所说周显王三十年为威王元年背景，不能自动当聘相年。正义引《庄子》濮水神龟故事并明说与此传不同，作为异说互读，不另造第二次聘相。

<!-- /sj063-cite-011 -->

<a id="sj063-cite-012"></a>

**[正义所引《庄子》另一拒聘故事](../../sources/史记三家注/卷063.md#p9)**

> 〔正義〕莊子云：「莊子釣於濮水之上，楚王使大夫往，曰：『願以境內累莊子。』持竿不顧，曰：『吾聞楚有神龜，死二千歲矣，巾笥藏之廟堂之上。此龜寧死爲留骨而貴乎？寧生曳尾泥中乎？』大夫曰：『寧曳尾塗中。』莊子曰：『往矣，吾將曳尾於塗中。』」與此傳不同也。

**本卷说明：** 依实际注本保存二千岁原数，不改作别本数字；这里也不证明神龟寿命。

<a id="sj064-military-book-note"></a>

### 3. 齐威王追论古司马兵法，把穰苴之法附入成书

[返回正文第3条](#sj064-military-book-event)

<a id="sj064-cite-011"></a>

**[《史记·司马穰苴列传》P002](../../sources/摘录/史记-卷064-司马穰苴列传.md#p002)**

> 至常曾孫和，因自立為齊威王，用兵行威，大放穰苴之法，而諸侯朝齊。

**本卷说明：** 此段原字保留田和／威王错接，身份纠误见前386同号注。本条只讲后世齐威王的活动；现用因齐前356元年至前320卒为在位范围，不据任何一端推编书年。

<!-- /sj064-cite-011 -->

<a id="sj064-cite-012"></a>

**[《史记·司马穰苴列传》P003](../../sources/摘录/史记-卷064-司马穰苴列传.md#p003)**

> 齊威王使大夫追論古者司馬兵法而附穰苴於其中，因號曰司馬穰苴兵法。

**本卷说明：** 追论古者并附穰苴，说明编集层次，不能把所有古司马法文字都归为穰苴亲笔，也不能声称今存本逐字等同当时编本。

<a id="sj064-author-review"></a>

### 司马迁论兵法与唐代述赞

以下评价解释为何兵书不详载、人物列传仍须写；唐赞另标作者，不作为齐国当年的事件。

<a id="sj064-cite-013"></a>

**[《史记·司马穰苴列传》P004](../../sources/摘录/史记-卷064-司马穰苴列传.md#p004)**

> 太史公曰：余讀司馬兵法，閎廓深遠，雖三代征伐，未能竟其義，如其文也，亦少褒矣。若夫穰苴，區區為小國行師，何暇及司馬兵法之揖讓乎？世既多司馬兵法，以故不論，著穰苴之列傳焉。

**本卷说明：** 太史公说：我读《司马兵法》，觉得它宏阔深远，即使夏、商、周三代的征伐，也未能尽行其中的道理；若完全照书中所写来看，也有些过于褒扬。至于穰苴，只是为一个小国统兵作战，哪里有闲暇达到《司马兵法》所讲的揖让之礼呢？世间流传《司马兵法》的本子已经很多，所以我不再论述兵法，而写下穰苴的列传。 閎廓深远是史家评价；揖让代表理想礼法，不证明本次战事已全行古制。

<!-- /sj064-cite-013 -->

<a id="sj064-cite-014"></a>

**[《史记·司马穰苴列传》Z001](../../sources/摘录/史记-卷064-司马穰苴列传.md#z001)**

> 索隱述贊曰：燕侵河上，齊師敗績。嬰薦穰苴，武能威敵。斬賈以徇，三軍驚惕。我卒旣彊，彼寇退壁。法行司馬，實賴宗戚。

**本卷说明：** 司马贞赞道：燕军侵入河上，齐军战败；晏婴推荐穰苴，他的武略足以震慑敌人。斩杀庄贾、在军中示众，三军惊惧警醒。我方士卒已强，敌寇退去；司马之法得以推行，实有赖于宗族亲属的支持。 唐赞的宗戚只保留宗族关系的概括，不无据指定谁在何年采取何项支持行动。

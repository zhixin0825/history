# 战国中期｜苏秦合纵与洛阳游士经历（未定年）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷069完整对读](../../拆分史书/史记/卷069.md) · [纪年异说](../../拆分史书/史记/卷069.md#kao-a62216da23)

《史记》卷069汇集大段战国六国游说辞和家族逸事；世传苏秦年代与出土帛书解释存在分歧。本页只作按事理归拢的时期附读，不将“六国相印”“秦十五年不出关”当成某年已证事实。

## 故事与谋略（按传文逻辑，并非逐年确年表）

<a id="event-1"></a>

1. **求学失意与自修。** 苏秦洛阳出身，游说不遇，闭门研读“阴符”与揣摩之术。原传的典型游士成长故事没有可确年次；古注援其他版本的“锥刺股”也应单列。 [[1]](#note-1)

<a id="event-2"></a>

2. **从秦至燕赵的连纵倡议。** 本传说苏秦先向秦惠王献策未被重用，转赴赵又受奉阳君阻挠，后来获燕文侯资助赴赵，提出六国共同抗秦的谋划。各次访问是叙事相承，不能从篇中压成同一年。 [[2]](#note-2)

<a id="event-3"></a>

3. **争取韩、魏、齐、楚。** 苏秦按六国处境调整说辞：韩魏近秦恐反复失地，齐远秦有纵深，楚国幅员广却需阻秦自武关、黔中攻入。各国“同意”的回复是本传外交叙事的一环，须与各自年表互证。 [[3]](#note-3)

<a id="event-4"></a>

4. **衣锦还乡与纵约瓦解。** 苏秦过洛阳受周王迎劳，家人态度骤变，是传记名声故事；十五年不窥函谷的总断与实际战事不尽合。后文写齐魏伐赵，苏秦离赵后纵约尽解，显示盟约脆弱。 [[4]](#note-4)

<a id="event-5"></a>

5. **苏秦赴齐的反间及死事（纪年争议）。** 传统传文说他为燕谋齐，劝齐兴奢役民，遇刺后以反间诱凶，并在齐被害；帛书重定年论另定位其年代。这里完整保留传统叙事，不给其死亡杜撰确定年份。 [[5]](#note-5)

## 本年纪事

<a id="event-1"></a>

1. **郑军取宋师于嵒，宋国救援未成。**

春季，宋国向魋出兵救援被围军队，郑方悬赏捕他，向魋逃回。郑军随后控制嵒地宋师，俘获成讙、郜延，使争夺中的六邑空虚。 [1](#note-1)

<a id="event-2"></a>

2. **许元公去世，楚军攻陈。**

夏季，许男成去世，秋季下葬。楚国公子申在这一年又率军进攻陈国，吴楚争陈仍未终结。 [2](#note-2)

<a id="event-3"></a>

3. **鲁、晋、吴会于黄池，盟誓时争论先后。**

夏季，哀公与周室单平公、晋定公、吴王夫差会合于黄池。到秋季盟誓，吴、晋都要求居先，分别以周室亲属次序和盟主地位为理由，双方一度摆出整军相逼的姿态。会议终于举行，但盟誓顺序在不同传述中留下了相反结局。 [3](#note-3)

<a id="event-4"></a>

4. **越军趁吴王在北，攻入吴国。**

六月，越军分路攻吴。吴国留守的太子友等先派兵迎战，初战曾擒获越将；勾践主力到后再次交战，大败吴军，太子友、王孙弥庸等被俘，越军进入吴国。消息传至北方会盟的夫差军中，夫差为压住败讯，杀了七名报信者。 [4](#note-4)

<a id="event-5"></a>

5. **子服景伯抵制降等朝见要求，被吴拘走后获释。**

吴方想让哀公以较低地位朝见晋侯，子服景伯指出，这将改变鲁对吴、晋的贡赋关系，与吴召诸侯时的地位自相矛盾。吴方先停止要求，又将景伯拘走。到户牖，景伯以鲁国秋祭及自己世守的职务说明，拘一个使臣无损于鲁而只留恶名，太宰嚭因而劝吴王放人。 [5](#note-5)

<a id="event-6"></a>

6. **哀公会后返鲁，吴、越入冬议和。**

哀公会后回鲁。吴军归程中粮食紧缺，申叔仪向公孙有山氏求粮；吴王还动过攻宋的念头，太宰嚭认为即使获胜也守不住，吴军最终回国。冬季，吴与越议和。 [6](#note-6)

<a id="event-7"></a>

7. **晋军侵卫，陈国夏区夫被杀。**

晋国魏曼多率军侵卫。冬季，陈国夏区夫遭人杀害。 [7](#note-7)

<a id="event-8"></a>

8. **九月、十二月螽灾，冬季东方出现彗星。**

九月与十二月，鲁国分别记录螽灾。十一月，东方出现彗星。 [8](#note-8)

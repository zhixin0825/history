# 公元前402年｜周楚更换国君，赵烈侯停止赐歌者田

[← 公元前403年](bce-0403.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前401年 →](bce-0401.md)

**周威烈王二十四年。** 楚君年次暂沿传世年表，具体分歧见原注及注2。

## 本年纪事

<a id="event-1"></a>
1. **周威烈王去世，儿子骄继位，是为安王。** 王室的君位承继没有取消此前授予韩、赵、魏的诸侯名分。[1](#note-1)

<a id="event-2"></a>
2. **楚声王被杀，楚人拥立他的儿子，是为悼王。** 这场发生在楚国的君位危机，与周王室的正常承继分开。[2](#note-2)

<a id="event-3"></a>
3. **赵烈侯想重赏宠爱的歌者，终于在臣下劝说后收回赐田打算。** 烈侯向相国公仲连提出，给郑地来的两位歌者各赐万亩田。公仲连口头答应，却迟迟不办，后来索性称病不朝。番吾君建议他荐用人才，于是牛畜、荀欣、徐越相继入见：一人讲仁义王道，一人讲选贤任能，一人讲节财量功。烈侯转而任用三人，并通知相国停止赐田。[3](#note-3)

<a id="event-4"></a>
4. **燕国开始以僖公元年纪事。** 父亲湣公的死亡与新君实际承位已经在前一年发生。[4](#note-4)

## 本年相关史料

<a id="note-1"></a>
<a id="sj004-402-1"></a>
### 1｜周威烈王终局的原入口

[卷004 P066](../../sources/摘录/史记-卷004-周本纪.md#p066)及《资治通鉴》前402年记威烈王卒、子安王立。原先同条带到的楚声王遇害，现拆为事件2，旧锚点保留。楚声王积年与清华《繫年》的调整意见仍未在本轮整链重校，不能称所有先秦王年无异。

<a id="note-2"></a>
### 2｜楚声王之死不误作周安王被杀

[卷015楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0402)记声王六年“盗杀声王”；[《资治通鉴》同年](https://zh.wikisource.org/wiki/資治通鑑/卷001)续记楚人立其子悼王。“盗”只保留史书称谓，不能据此确定凶手姓名、集团及动机；不把父死子立与后来的吴起之死混在一起。新君元年接[前401年](bce-0401.md#event-1)，楚王年代的研究边界仍见[前408年注6](bce-0408.md#note-6)。

<a id="note-3"></a>
### 3｜三人所进不同，不能全算徐越一人的功劳

[卷015赵栏](../../sources/摘录/史记-卷015-六国年表.md#y0402)只写烈侯欲赐歌者田、徐越以仁义劝止。[《赵世家》烈侯段](https://zh.wikisource.org/wiki/史記/卷043#趙烈侯)详记公仲连拖延、番吾君荐士及牛畜、荀欣、徐越三次进说，其中讲仁义的是牛畜，徐越讲节财、量功。正文采用详文分工，不把年表的简写移植成三人都只讲同一件事。

烈侯随后任牛畜为师、荀欣为中尉、徐越为内史，并赐相国衣二袭。此处是同一段的收束，暂随年表七年定位；世家“为相四年”、多次追问、相隔一月等相对时间没有全部独立复算。万亩为原载数量，不换算现代面积，更不说这些土地已经实际交付后才收回。三人更早的生平未详，不为丰富人物而虚构籍贯和出生年。

<a id="note-4"></a>
### 4｜燕釐公元年

[卷015燕栏](../../sources/摘录/史记-卷015-六国年表.md#y0402)列釐公元年，承[前403年](bce-0403.md#event-2)。僖、釐的写法在同号说明中对应，不重复生成一次即位。

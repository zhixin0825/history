# 公元前403年｜周王命韩、赵、魏为诸侯

[← 公元前404年](bce-0404.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前402年 →](bce-0402.md)

**周威烈王二十三年。** 宋君年条暂沿现用年表，另一纪年重构见注3。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **周王正式命韩、赵、魏为诸侯。** 获得王命的是韩虔、赵籍、魏斯。三家此前早已在晋地取得实权，这次是周王室在名分上加以承认，不是说直到本年才第一次瓜分智氏土地；晋公室也没有在同一天被彻底废除。 赵并追尊献子为献侯。 烈侯时代另有公仲连荐贤的未确年故事。烈侯问可否使宠爱者显贵，相国答可使富，不可无功授贵；烈侯遂命给郑歌者枪、石各万亩田。公仲应诺而不办，一个月后烈侯从代归再问，他称未选到适当田地，又以病不朝。番吾君指出相国好善却任相四年未进贤，推荐牛畜、荀欣、徐越。公仲荐三人，仍说在择善田。牛畜以仁义王道劝君，荀欣讲选贤任能，徐越讲节财省用、察功德，三日相继进言，使烈侯悦服。烈侯主动止给歌者田，任三人分别为师、中尉、内史，赐相国衣二袭。 [[1]](#note-1)

<a id="event-2"></a>

2. **燕湣公去世，僖公继位。** 燕国的君位进入下一任统治者手中，僖公元年从次年开始。 [[2]](#note-2)

<a id="event-3"></a>

3. **宋国转入悼公购由的纪年。** 购由接续父亲昭公一系的君位，宋公室的传承与周围强国的兴起同时延续。 [[3]](#note-3)

<a id="hs-event-4"></a>

4. **周九鼎有震记录。** 《汉书》在本年记载周九鼎有震记录。 [[4]](#hs-note-4)

> 烈侯好音，謂相國公仲連曰：「寡人有愛，可以貴之乎？」公仲曰：「富之可，貴之則否。」烈侯曰：「然。夫鄭歌者槍、石二人，吾賜之田，人萬畝。」公仲曰：「諾。」不與。居一月，烈侯從代來，問歌者田。公仲曰：「求，未有可者。」有頃，烈侯復問。公仲終不與，乃稱疾不朝。番吾君自代來，謂公仲曰：「君實好善，而未知所持。今公仲相趙，於今四年，亦有進士乎？」公仲曰：「未也。」番吾君曰：「牛畜、荀欣、徐越皆可。」公仲乃進三人。及朝，烈侯復問：「歌者田何如？」公仲曰：「方使擇其善者。」牛畜侍烈侯以仁義，約以王道，烈侯逌然。明日，荀欣侍，以選練舉賢，任官使能。明日，徐越侍，以節財儉用，察度功德。所與無不充，君說。烈侯使使謂相國曰：「歌者之田且止。」官牛畜為師，荀欣為中尉，徐越為內史，賜相國衣二襲。

**本卷说明：** 以下任贤故事只知在烈侯时代，相国任职已四年；不据相邻六年栏断言发生于前403。

## 归年与考证

<a id="sj004-403-1"></a>
<a id="1三家受命与九鼎异象"></a>
#### 1｜三家受命与九鼎异象

[卷004 P065](../../sources/摘录/史记-卷004-周本纪.md#p065)、[卷015魏、韩、赵、楚四栏](../../sources/摘录/史记-卷015-六国年表.md#y0403)与[《资治通鉴》卷一开篇](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7001.md#ref-05209331501284)共同说明此次命侯。四个国格是同一事件的互见，不能生成四次册命。名字据《通鉴》开篇，韩景侯、赵烈侯、魏文侯为对应称谓，不另造三组受封者。

九鼎震动见本纪及年表周栏，原样保留为史书异象，不解释为神明对册封作出的实际裁判。司马光随后关于礼、名分的长论是后世史论，不是前403年新增的一道周王政令。

《通鉴》本年还有从智氏兴亡起的大段前情，相关事件继续读[前453年](bce-0453.md)、[前425—423年](bce-0425.md)、[前406年中山](bce-0406.md)及[前405年选相](bce-0405.md)。本批并未宣称《通鉴》开篇所有回叙均已逐段处理，其中吴起材料本轮已按各自前后关系编入[任职时期页](../bce-0400-0301/未定年-吴起在鲁魏任职与轶事.md)；其他未确年的礼贤材料仍依旧有说明。


<a id="2燕湣公终局与僖公元年"></a>
#### 2｜燕湣公终局与僖公元年

[《燕召公世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7034.md#ref-92a79330d7642e)记湣公三十一年卒、子釐公立；《通鉴》前403年同记。[卷015本年燕栏](../../sources/摘录/史记-卷015-六国年表.md#y0403)仅三十一，次年始列釐公元年。死亡及父子关系据世家、通鉴补，不伪称本格有全部叙事。僖、釐是称谓互见，不另造两位燕君。


<a id="3宋悼公元年的暂行坐标"></a>
#### 3｜宋悼公元年的暂行坐标

[卷015齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0403)记宋悼公元年；[《宋微子世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7038.md#ref-4c33596f1c229a)给出昭公之子购由。齐栏记宋事，不是齐国也立了一个悼公。

马卫东、王政冬[《清华简〈繫年〉三晋伐齐考》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-e0b861255be85172.md#cite-5)讨论宋悼公在位的不同重构，所取方案与本表元年相冲。本页暂保留年表坐标并醒目标示存疑，不据元年反造昭公确切卒日；宋景公原来的异年说明也不因此撤销。整条宋君年链须专题复核，不能从某一端点倒算即宣布各说统一。

# 公元前403年｜周王命韩、赵、魏为诸侯

[← 公元前404年](bce-0404.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前402年 →](bce-0402.md)

**周威烈王二十三年。** 宋君年条暂沿现用年表，另一纪年重构见注3。

## 本年纪事

<a id="event-1"></a>
1. **周王正式命韩、赵、魏为诸侯。** 获得王命的是韩虔、赵籍、魏斯。三家此前早已在晋地取得实权，这次是周王室在名分上加以承认，不是说直到本年才第一次瓜分智氏土地；晋公室也没有在同一天被彻底废除。[1](#note-1)

<a id="event-2"></a>
2. **燕湣公去世，僖公继位。** 燕国的君位进入下一任统治者手中，僖公元年从次年开始。[2](#note-2)

<a id="event-3"></a>
3. **宋国转入悼公购由的纪年。** 购由接续父亲昭公一系的君位，宋公室的传承与周围强国的兴起同时延续。[3](#note-3)

## 本年相关史料

<a id="note-1"></a>
<a id="sj004-403-1"></a>
### 1｜三家受命与九鼎异象

[卷004 P065](../../sources/摘录/史记-卷004-周本纪.md#p065)、[卷015魏、韩、赵、楚四栏](../../sources/摘录/史记-卷015-六国年表.md#y0403)与[《资治通鉴》卷一开篇](https://zh.wikisource.org/wiki/資治通鑑/卷001)共同说明此次命侯。四个国格是同一事件的互见，不能生成四次册命。名字据《通鉴》开篇，韩景侯、赵烈侯、魏文侯为对应称谓，不另造三组受封者。

九鼎震动见本纪及年表周栏，原样保留为史书异象，不解释为神明对册封作出的实际裁判。司马光随后关于礼、名分的长论是后世史论，不是前403年新增的一道周王政令。

《通鉴》本年还有从智氏兴亡起的大段前情，相关事件继续读[前453年](bce-0453.md)、[前425—423年](bce-0425.md)、[前406年中山](bce-0406.md)及[前405年选相](bce-0405.md)。本批并未宣称《通鉴》开篇所有回叙均已逐段处理，尤其未确年的礼贤、吴起等材料仍须按各自前后关系核编。

<a id="note-2"></a>
### 2｜燕湣公终局与僖公元年

[《燕召公世家》](https://zh.wikisource.org/wiki/史記/卷034)记湣公三十一年卒、子釐公立；《通鉴》前403年同记。[卷015本年燕栏](../../sources/摘录/史记-卷015-六国年表.md#y0403)仅三十一，次年始列釐公元年。死亡及父子关系据世家、通鉴补，不伪称本格有全部叙事。僖、釐是称谓互见，不另造两位燕君。

<a id="note-3"></a>
### 3｜宋悼公元年的暂行坐标

[卷015齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0403)记宋悼公元年；[《宋微子世家》](https://zh.wikisource.org/wiki/史記/卷038#宋昭公)给出昭公之子购由。齐栏记宋事，不是齐国也立了一个悼公。

马卫东、王政冬[《清华简〈繫年〉三晋伐齐考》](https://www.fdgwz.org.cn/Web/Show/1943)讨论宋悼公在位的不同重构，所取方案与本表元年相冲。本页暂保留年表坐标并醒目标示存疑，不据元年反造昭公确切卒日；宋景公原来的异年说明也不因此撤销。整条宋君年链须专题复核，不能从某一端点倒算即宣布各说统一。

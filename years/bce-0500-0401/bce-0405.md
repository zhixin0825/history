# 公元前405年｜魏文侯选相，齐廪丘转向赵国

[← 公元前406年](bce-0406.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前404年 →](bce-0404.md)

## 本年纪事

<a id="event-1"></a>
**魏文侯在魏成与翟璜之间选择宰相，向李克征询意见。** 李克没有直接替自己谋位，而是请国君看一个人平常亲近谁、富有时帮助谁、得势时推荐谁，以及困穷时仍不肯做什么、不肯拿什么。文侯听完，表示自己已有决定。[1](#note-1)

**翟璜听说魏成将被任用，十分不服。** 他向李克列举自己推荐西河守、西门豹、乐羊等人的功劳。李克则指出，魏成将大部分俸禄用于延揽子夏、田子方、段干木，文侯把这些人当作老师；衡量宰相不能只数谁推荐的办事者多。翟璜终于收回怨言，向李克致歉。[1](#note-1)

<a id="event-2"></a>
**齐国大夫田会据廪丘反叛，转而投靠赵国。** 地方城邑的归属变化把齐国内部争斗引向国与国之间；廪丘及其后的平阴战事，将成为三晋与齐国冲突的一环。[2](#note-2)

<a id="event-3"></a>
**齐宣公去世，儿子贷接掌君位，是为康公。** 吕氏公室虽仍有国君，田氏势力及其内部矛盾已经深刻影响齐政。[3](#note-3)

## 本年相关史料

<a id="note-1"></a>
### 1｜争论的是选相标准，不是李克与翟璜竞逐相位

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0405)简写“卜相，李克、翟璜争”。[《魏世家》选相段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-4d668a8908eca6)明确候选人为魏成与翟璜，李克是受咨询者，故按详文补全主语。李克、翟璜此前已在魏国参与用人议论，这里不将他们提及的全部荐举、守地及任官都定成本年新事；也不凭李克的名字擅自展开李悝变法的整套纪年。

《资治通鉴》把同一故事收在前403年的长篇前情中；本页暂依年表前405年的明确位置主述，不在前403年再选一次相。对话为传世政治叙事，不是现存逐字会议记录；魏文侯不同起算方案仍见[前424年注3](bce-0424.md#note-3)。

<a id="note-2"></a>
### 2｜田会、公孙会与廪丘，不另造两个叛乱者

[卷015齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0405)作“田会以廪丘反”。马卫东、王政冬[《清华简〈繫年〉三晋伐齐考》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-e0b861255be85172.md#cite-7)对读《纪年》佚文中的“公孙会以廪丘叛于赵”，以二名指同一人。此处据互见补其投赵，不据“田”姓便把他与田和并人。田氏内部每一派的成员与谋杀动机尚有研究分歧，不全部写成定论。

廪丘是本次争夺的城邑；它早先也曾变更归属，不能把不同时期的叛附都合成这一年。现代精确遗址、转投日期和兵数本轮未另核。后续东进见[前404年](bce-0404.md#event-2)。

<a id="note-3"></a>
### 3｜宣公终局与康公元年分开

[《齐太公世家》宣公段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7032.md#ref-fc79f72e3d946e)记宣公五十一年卒、子康公贷立，并接田会反廪丘；表中本年五十一，下一年康公元年。以此补终局，不因同格、同段而判断宣公死于叛乱，也不把田氏后来代齐的全部过程提前到本年。

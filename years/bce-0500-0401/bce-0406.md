# 公元前406年｜魏攻克中山，转入驻守

[← 公元前407年](bce-0407.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前405年 →](bce-0405.md)

> 本页将魏占中山的终局暂系前406年，与前408年的进攻分开；具体纪年依据见注1，不据此宣称中山诸次政权的关系已经定案。

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **魏将乐羊率军攻克中山，魏文侯让公子击经营这片新取得的地方。** 前面的进攻持续了一段时间，并不是出兵当天就完成占领；攻城以后，驻守与统治才成为新的问题。 [[1]](#note-1)

<a id="sj044-tianzifang-event"></a>

2. **未定年附读｜公子击问田子方，谁能傲人。** 在公子击经营中山的叙事之后，有一段没有独立年次的相遇：他在朝歌看见父亲的老师田子方，避车下拜，却未获还礼，于是问富贵者还是贫贱者可以傲人。田子方说，诸侯、大夫傲慢可能失去国、家；无位之士言不被听、行不被容，却可以转身离去，像脱鞋一样，不必依附某一位君主。公子击不快而去。这段话讲的是掌权者与游士所受约束不同，不是本年魏国多发生了一次外交争执。 [[2]](#sj044-tianzifang-note)

### 2. 未定年附读｜公子击问田子方，谁能傲人

[返回正文第2条](#sj044-tianzifang-event)

<a id="sj044-cite-021"></a>

**[《史记·魏世家》P012](../../sources/摘录/史记-卷044-魏世家.md#p012)**

> 子擊逢文侯之師田子方於朝歌，引車避，下謁。田子方不為禮。子擊因問曰：「富貴者驕人乎？且貧賤者驕人乎？」子方曰：「亦貧賤者驕人耳。夫諸侯而驕人則失其國，大夫而驕人則失其家。貧賤者，行不合，言不用，則去之楚、越，若脫屣然，柰何其同之哉！」子擊不懌而去。

**本卷说明：** 依篇内相邻关系在中山经营后附读，不断言会见在前406年。

## 归年与考证

<a id="1攻取终局与原有前408年条相接"></a>
#### 1｜攻取终局与原有前408年条相接

[《资治通鉴》卷一威烈王二十三年回叙](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7001.md#ref-b40d70d8c9851f)记文侯使乐羊攻克中山、以封子击；这一大段从智氏兴亡说起，不能把其中所有旧事都定在前403年。[《魏世家》文侯段](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-d9f584ce98916e)则在十七年合述伐中山、使子击守之，未将开始与结束逐年拆开。

张渭莲[《中山国史探索的疑议与新证》](../../meta/%E6%9D%A5%E6%BA%90/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-841c4e52347ea4cf.md#cite-3)梳理的传世时间线为前408年出兵、两年后魏灭中山。本页暂依此将攻取终局接在前406年；[前408年原注](bce-0408.md#note-3)关于攻、守跨年的说明继续有效。乐羊为这次出征的魏将，不能因后来有同姓名将乐毅就并作一人。

卷015[本年八栏](../../sources/摘录/史记-卷015-六国年表.md#y0406)只有王年数字，本页的故事是相关文献补入，不冒称原格有攻克记载。守地、封地的实际执行日及当地君主结局未详，不补兵力、伤亡或仪式；魏占中山也不等于中山此后永远不再出现。

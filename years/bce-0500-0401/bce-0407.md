# 公元前407年｜郑在负黍败韩；魏文侯礼贤及未定年附读

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **魏文侯向子夏学习经义，对段干木也十分敬重，经过其居处便凭轼致礼。** 礼遇士人是文侯治理魏国的一条重要线索，伴随着魏国不断扩大的军事行动。 传述还说，秦曾谋攻魏，却因魏君尊贤、上下和合而受到劝阻；这是文侯声誉形成过程的附读，没有独立年月。 [[1]](#note-1)

<a id="event-2"></a>

2. **郑军在负黍击败韩军。** 前一年韩取雍丘、郑整备城邑之后，两国的战争仍在继续。 [[2]](#note-2)

<a id="event-3"></a>

3. **齐国与郑国在西城会面，又进攻卫国，取得毌地。** 外交往来与对外战争并行，并不表示所有行动属于同一天的同一份盟约。 [[3]](#note-3)

<a id="event-4"></a>

4. **楚声王当、鲁穆公显开始以新君元年纪事。** 两人各自接续父亲的统治，楚、鲁并没有因此变成一个统一政权。 [[4]](#note-4)

<a id="sj044-ximenbao-event"></a>

5. **文侯时期未定年附读｜西门豹受任治理邺。** 魏文侯让西门豹治理邺，河内因此有治绩之名。任命的确切年份未明，与本页礼贤主题同读；这里只记录任官与治绩，不把后来的水利、破除河伯祭祀等故事都先补到这一年。 [[5]](#sj044-ximenbao-note)

## 归年与考证

<a id="1受经与致敬属于执政时期的活动不硬造首次拜师日"></a>
#### 1｜受经与致敬属于执政时期的活动，不硬造首次拜师日

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0407)记文侯十八年受经子夏、过段干木之闾常式；[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-d013e1daeb09ab)也概述其尊子夏、田子方、段干木。正文补文侯与两人的关系，不将“常”解释成只有本年发生过一次，也不把所有礼贤故事、李克任官和后来的吴起事迹都倒填成本年。

子夏名卜商，是孔子弟子；段干木是文侯礼敬的士人。本批按有年表记载的位置介绍二人，并未全面复核其一生最早登场；不把受经一句当作足以确定子夏晚年年龄、寿数或这年才首次到魏的依据。式通轼，指在车上凭轼行礼，不误作建筑门闾的动作。魏文侯起算方案的差别见[前424年](bce-0424.md#note-3)。


<a id="2负黍是韩郑同一场战事"></a>
#### 2｜负黍是韩、郑同一场战事

[卷015韩栏](../../sources/摘录/史记-卷015-六国年表.md#y0407)列景侯二年郑败韩于负黍；[《韩世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7045.md#ref-4fd1da7e2958de)与[《郑世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7042.md#ref-67c87b091f31f2)繻公十六年相接。不同国书的年数指同一年，不能据一个称二年、一个称十六年拆成两次战争。兵力、主将及战后和议未记，不补。


<a id="3西城会见与取毌分别记录"></a>
#### 3｜西城会见与取毌分别记录

[卷015齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0407)写与郑会西城、伐卫取毌；[《索隐》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7015.md#ref-96274c9722116a)释毌音馆。文字是毌，不以形近改成毋；现代地望未独立考定，不凭地名猜出条约内容或受攻国君的现场行动。


<a id="4楚鲁元年按原项目年表体系暂接"></a>
#### 4｜楚、鲁元年按原项目年表体系暂接

[卷015楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0407)并记楚声王当元年、鲁穆公元年，两国实际继承暂接[前408年注6](bce-0408.md#note-6)。亲属关系据各自世家，绝对年代仍保留此前楚、鲁年链的研究分歧；“元年”不意味着每位君主都恰在这个公历年度第一天即位。

# 公元前408年｜秦筑城征禾，魏扩张，韩郑交战

[← 公元前409年](bce-0409.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前407年 →](bce-0407.md)

> 秦、三晋等事件沿《六国年表》坐标；楚、鲁君位衔接另有整体纪年分歧，见注6。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦国开挖洛水一线沟堑，营建重泉，并开始实行以禾稼征租的安排。** 边境营建与国内征收都进入本年的记载。 [[1]](#note-1)

<a id="event-2"></a>

2. **魏军深入秦地，到达郑邑，回师时又修筑洛阴、合阳。** 魏方继续以战争和据点经营扩大控制范围。 [[2]](#note-2)

<a id="event-3"></a>

3. **魏国进攻中山，公子击参与这项北向经营，并与后来守中山的安排相接。** 这一过程不是一行年表文字所能容纳的单日战事。 [[3]](#note-3)

<a id="event-4"></a>

4. **韩景侯虔、赵烈侯籍开始以各自元年纪事。** 韩军进攻郑国，取得雍丘；郑国则营建京城邑，设法应对压力。 [[4]](#note-4)

<a id="event-5"></a>

5. **齐军取得鲁国的郕。** 鲁国继前些年的失地之后，又丧失一处城邑。 [[5]](#note-5)

<a id="event-6"></a>

6. **楚简王与鲁元公去世，两国各由儿子接掌。** 楚国由当继位，是为声王；鲁国由显继位，是为穆公。 [[6]](#note-6)

## 归年与考证

<a id="1工程与租禾在七年不是几套文字各建一次"></a>
#### 1｜工程与租禾在七年；不是几套文字各建一次

[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0408)记简公七年“塹洛，城重泉。初租禾”。《秦本纪》把工程紧接六年佩剑而未另标年，现按年表明列的七年移入，原[前409年入口](bce-0409.md#sj005-150-note)继续回链。

所读[三家注网页](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7015.md#ref-c1fe11d71e0184)在七、八年两行重复同样的工程、租禾句，正文不据网页重复再增一次前407年的建设；原文摘录以主见证的七年一条为准，重复现象在此登记，并未宣称所有古本同样重复。

“初租禾”据字面为以谷物征租的制度记载，不等于秦此前完全无赋税，更不能由四字推出具体税率、土地私有制成立日或全国财政数字。[卷006先君附记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7006.md#ref-c92923d57603f6)另称简公七年百姓初带剑，与前一年吏带剑分开保存；不据此推成现代意义的无条件武器自由。


<a id="2秦地郑邑与洛阴合阳"></a>
#### 2｜秦地郑邑与洛阴、合阳

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0408)、[《魏世家》文侯十七年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-75d60b54a7b906)记攻秦至郑而还、筑两邑。郑是本次秦境进军所至，不是同页被韩攻的东方郑国；营建两邑也不等于已经核明整个西河郡的建立程序、官制和边界。


<a id="3中山攻守的跨年过程与参与者"></a>
#### 3｜中山攻守的跨年过程与参与者

同年魏栏简记“擊守中山”，赵栏却写“魏使太子伐中山”；击是公子姓名，不应把“击守”读成两个没有主语的动词。世家也把太子击守中山、赵仓唐为傅接在同一段。这里只说明攻取及后续驻守的关联，不强断其在本年已全部结束，更不把赵仓唐当作同年另一个被立的中山王。

[张渭莲《中山国史探索的疑议与新证》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-841c4e52347ea4cf.md#cite-4)介绍前408年始攻、两年后攻灭的传统时间线，同时讨论中山诸次政权之间的分歧。因此本页记开始进攻，把完成占领和“守”的精确年次保留为后续核查，不从一格简记制造瞬间灭国。前414年武公条见[原页](bce-0414.md#event-3)。


<a id="4元年韩郑之战与地名京"></a>
#### 4｜元年、韩郑之战与地名京

[卷015韩、赵栏](../../sources/摘录/史记-卷015-六国年表.md#y0408)明列新君元年，承[前409年死亡、承位](bce-0409.md#event-3)。韩攻郑取雍丘与郑城京同见年表和[《郑世家》繻公十五年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7042.md#ref-aad4c682cecbf2)。京是具体城邑名，不把它直接译为郑国在本年新建一座国都。太子、公子、侯等称谓沿史书追称，不提前搬来前403年的正式册命。


<a id="5取鲁郕"></a>
#### 5｜取鲁郕

[卷015齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0408)作“取魯郕”。郕保留为地名，不因字形近似就改成没有名称的“取鲁城”。围攻过程、伤亡及当地归属的后续没有据此补造。


<a id="6楚鲁终局的当前年链与研究边界"></a>
#### 6｜楚、鲁终局的当前年链与研究边界

年表本年楚栏明确简王二十四年卒，[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-92d26e1e77d081)记子声王当立。鲁元公之死由[《鲁周公世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7033.md#ref-3e405bdefa83cb)的元公二十一年、子显立及年表下一年穆公元年衔接，未擅称本年原格直接写了两位君主死亡。

楚简王在位数与《系年》研究的不同方案、鲁悼公—元公的整条年链分歧，仍见[前432年](bce-0432.md#note-1)、[前429年](bce-0429.md#note-2)。本页暂按既有年表坐标安放共同史事，不能以这一年排列顺畅就声称考古已经确认两人同年去世；下一年的元年不再重复死亡。

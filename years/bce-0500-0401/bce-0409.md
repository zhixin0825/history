<a id="event-1"></a>

1. **秦国开始命官吏佩剑。** 这项安排被记入简公六年的政事。 [[1]](#note-1)

<a id="event-2"></a>

2. **魏军进攻秦国，修筑临晋、元里。** 魏在交战之外继续建立、巩固河边据点，秦魏争夺进入新的阶段。 [[2]](#note-2)

<a id="event-3"></a>

3. **韩武子与赵献侯相继去世，两家各由儿子接掌。** 韩氏由虔继承，赵氏由籍继承；景侯、烈侯是后来的称号，此时三家仍未正式得到周王册命。 [[3]](#note-3)

## 归年与考证

<a id="sj005-150-note"></a>
<a id="1佩剑与工程分年原入口保留"></a>
#### 1｜佩剑与工程分年：原入口保留

[卷005 P047](../../sources/摘录/史记-卷005-秦本纪.md#p047)写简公六年初令吏带剑，继叙塹洛、城重泉而未另给年份；[卷015](../../sources/摘录/史记-卷015-六国年表.md#y0409)把佩剑列六年，把两项工程列七年。因此本次把原页合写的工程移到[前408年事件1](bce-0408.md#event-1)，本页保留事件1和旧史料锚点，不造两次筑重泉。吏不直接扩大为全国每个人都在本年获准携带任何兵器；卷006百姓带剑的另一年次见下一页注1。


<a id="2魏伐秦与两处营建"></a>
#### 2｜魏伐秦与两处营建

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0409)作“十六。伐秦，築臨晉、元里”，[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-feea941df864f0)同记。次年又有深入秦地和营建洛阴、合阳，是有据的后续，不把四处工程都算成本年一日完成；原格未列统帅，不擅填吴起或其他名将。


<a id="3两家死亡由世家与元年位置衔接"></a>
#### 3｜两家死亡由世家与元年位置衔接

[《韩世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7045.md#ref-175d846c750e6f)记武子十六年卒、子景侯虔立；[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-b2398159864fc7)记献侯十五年卒、子烈侯籍立。年表本行韩十六、赵十五，次行各标新君元年，故将死亡、承位补入本年而在[前408年](bce-0408.md#event-4)接纪元。相继只是本年各自发生，不推定两人死亡的先后日；不在原始数字格中擅增原文。

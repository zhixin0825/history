# 公元前412年｜魏公子击围城迁民，齐军进攻鲁地

[← 公元前413年](bce-0413.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前411年 →](bce-0411.md)

## 本年纪事

<a id="event-1"></a>
**魏文侯之子击围攻繁、庞一带，并迁出当地居民。** 击逐渐承担魏国的军事行动，后来还将参与中山与秦地的经营。[1](#note-1)

<a id="event-2"></a>
**齐军进攻鲁国，又向莒、安阳等地用兵。** 鲁国面临的东面压力继续扩大。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜击是人名，出其民是行动

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0412)作“公子擊圍繁龐，出其民”；[《魏世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7044.md#ref-07a96af76e6e0d)同载文侯十三年条，所读标点分繁、庞。击是文侯之子、后来的魏武侯，不把“公子击”误作无名公子发起进攻。正文保留围城与迁民，不推定迁徙人数、目的地及繁庞的现代城址，也不把它与秦国前415年修庞仅凭一字相同强行合为一城。

<a id="note-2"></a>
### 2｜莒的政权与地名不能混为一谈

[卷015齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0412)为“伐魯、莒及安陽”。前431年已有楚灭莒记载，此处再出现莒，不足以直接证明同一个独立莒国已复国。正文以进攻鲁国及莒、安阳等地的中性表述接合，两处记载的政权归属仍需另核；不补复国年、国君姓名，也不把安阳自动等同于现代河南安阳市。[前431年灭莒说明](bce-0431.md#note-1)。

# 公元前414年｜秦简公、卫慎公纪元，中山武公执政

[← 公元前415年](bce-0415.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前413年 →](bce-0413.md)

> 本页沿《六国年表》的年度坐标，君主元年与国家最初建立不是同一概念。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦国进入简公元年。** 灵公之子未能继位，悼子接掌秦国；新的纪年承接前一年的君位转换。 [[1]](#note-1)

<a id="event-2"></a>

2. **卫国进入慎公元年。** 公子頹此前杀死亹而掌权。卫国君位又经历一次公室内部的强力争夺，仍未摆脱对强邻的依赖。 [[2]](#note-2)

<a id="event-3"></a>

3. **中山由武公执政。** 这支政权后来将成为魏国北向进攻的目标；它虽被记在赵氏年数旁，却不是赵国的新君。 [[3]](#note-3)

## 归年与考证

<a id="1秦简公元年"></a>
#### 1｜秦简公元年

[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0414)列秦简公元年，承[前415年灵公终局](bce-0415.md#event-1)。本纪的年数差异留在前页，不因有新君元年便把先前异说全部算作解决。


<a id="2卫国夺位与次年计元"></a>
#### 2｜卫国夺位与次年计元

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0414)列卫慎公元年；[《卫康叔世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-ba06d60c5d93cd)记亹在位十一年被公子頹杀死，頹为慎公，并称其父公子适、适为敬公之子。按本表前425年亹元年的链条，夺位在前415年前后，此处只简述前情，不把元年再当作一次弑君日期。表称亹悼公、世家称怀公之异已见[前425年注4](bce-0425.md#note-4)；不能因此另列两个同时在位的亹。


<a id="3初立不等于从此才有中山"></a>
#### 3｜“初立”不等于从此才有中山

[卷015赵栏](../../sources/摘录/史记-卷015-六国年表.md#y0414)为献侯十年“中山武公初立”；[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-2019dae2819afd)同载此年次。采用这一记录安排武公的阅读位置，不由“初立”推出整个中山国家就在本年首次建成。

[张渭莲《中山国史探索的疑议与新证》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-841c4e52347ea4cf.md#cite-5)讨论出土铭文与传世年表衔接的多种解释。旧注将武公与周王室谱系相联系，不能仅凭同号就确认其父祖，也不能据本格自动确定族属和国祚起点。正文不补未核实的私名、出生年与建都日；魏攻中山另接[前408年](bce-0408.md#event-3)。

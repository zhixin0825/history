# 公元前417年｜秦经营河边防御，魏再筑少梁

[← 公元前418年](bce-0418.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前415年 →](bce-0415.md)

## 本年纪事

<a id="event-1"></a>
**秦国在黄河岸边修筑城防、开挖沟堑。** 与魏争夺河边据点的同时，秦继续经营防御设施。[1](#note-1)

<a id="event-2"></a>
**魏国再次在少梁筑城。** 前两年的筑城与战斗之后，魏仍设法巩固这一据点。[2](#note-2)

<a id="event-3"></a>
**秦开始举行以君家女子名义嫁女于河神的仪式。** 这项祭祀安排与本年的河边工程分别记录。[3](#note-3)

## 本年相关史料

<a id="note-1"></a>
### 1｜河边的城与堑

[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0417)记“城塹河瀕”。“河”按该段秦魏地理背景指黄河；文字没有提供全线长度、竣工日或具体工法，不把它径改成后来的完整秦长城。

<a id="note-2"></a>
### 2｜复城少梁

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0417)记“復城少梁”，承[前419年初筑](bce-0419.md)及[前418年交战](bce-0418.md)。只说明再次筑城，不证明前一座城被彻底焚毁或重建已在本年全部竣工。

<a id="note-3"></a>
### 3｜“君主妻河”与女子的实际出身

同年秦栏作“初以君主妻河”。[《索隐》](https://zh.wikisource.org/wiki/史記三家註/卷015)解释为取其他女子充作君主，即以公主的名义嫁给河伯。正文依此不写成已确定由秦君亲生女儿出嫁，也不把“君主”误读成男性国君本人。原文没有详述女子身份、仪式步骤或最终下落，不拿西门豹故事补出一场沉河处死；神婚是当时的祭祀表述，不是河神真实存在的证明。

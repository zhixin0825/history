# 公元前419年｜魏在少梁筑城，晋烈公元年

[← 公元前420年](bce-0420.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前418年 →](bce-0418.md)

## 本年纪事

<a id="event-1"></a>
1. **魏在少梁筑城，引起秦军进攻。** 双方围绕秦晋间的重要据点展开争夺，战事随后继续。[1](#sj005-148-note)

<a id="event-2"></a>
2. **晋国进入烈公止元年。** 魏文侯干预前一年的动乱、扶立新君以后，晋仍保有自己的君位名号，但权力早已受到三家限制。[2](#note-2)

## 本年相关史料

<a id="sj005-148-note"></a>
### 1｜少梁筑城、交战、再筑城分年相接

[卷005 P046](../../sources/摘录/史记-卷005-秦本纪.md#p046)在秦灵公六年连记晋城少梁、秦击之；[卷015本年魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0419)明确魏城少梁，次年秦栏记与魏战，再下一年魏复城少梁。沿已有开战正文，接[前418年战斗](bce-0418.md)与[前417年再筑城](bce-0417.md#event-2)，不重复制造三场各自独立的战争，也不凭三年条目推出连续三整年没有停战。

本纪泛称晋，年表与魏世家具体指魏氏。这里不是秦、晋公室、魏三方同时互战；魏文侯元年体系的差别见[前424年注3](bce-0424.md#note-3)，不把年表“六年”无说明地套到其他起算方案。

<a id="note-2"></a>
### 2｜烈公元年与前一年实际被立

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0419)列晋烈公止元年。幽公遇害、止受立及父子／兄弟异说留在[前420年](bce-0420.md#note-1)，不再举行一次未载的拥立。秦君年数口径仍见[卷005纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。

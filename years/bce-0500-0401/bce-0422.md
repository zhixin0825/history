# 公元前422年｜秦设上下畤，郑繻公元年

[← 公元前423年](bce-0423.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前420年 →](bce-0420.md)

## 本年纪事

<a id="event-1"></a>
**秦灵公设置上畤、下畤，分别祭祀黄帝、炎帝。** 这两处祭所继续发展秦君祭祀诸帝的礼制。[1](#note-1)

<a id="event-2"></a>
**郑国开始以繻公駘元年纪事。** 韩军杀幽公以后，郑国仍保留自己的公室，由新君接续统治。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜祭所、祭祀对象与年次

[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0422)在灵公三年记“作上下畤”；[《封禅书》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7028.md#ref-3bf8ad7d4d397b)记上畤于吴阳祭黄帝、下畤祭炎帝。此处黄帝、炎帝是祭祀对象，不是两位在本年活动的上古帝王。畤是祭所，不能因后来历代祭祀同一神祇就把设施建造年份全部合并；具体址点未由本轮独立考古核定。

<a id="note-2"></a>
### 2｜繻公的父系存在两说

[卷015韩栏](../../sources/摘录/史记-卷015-六国年表.md#y0422)作“鄭立幽公子，為繻公，元年”；[《郑世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7042.md#ref-e0ed1dbc64ae86)却作幽公弟駘。两书共同支持幽公遇害后由繻公接续，却不能同时证明他既为幽公之弟又为其子。正文采用共同的继承关系，不编造谱系调和；实际被立仍见[前423年](bce-0423.md#event-1)。

# 公元前424年｜秦灵公元年，赵氏争位

[← 公元前425年](bce-0425.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前423年 →](bce-0423.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **秦国进入灵公元年，灵公之子、后来的献公也有了出生记载。** 灵公是在怀公被逼死后，由大臣从已故太子昭子一支拥立的新君。 [[1]](#note-1)

<a id="event-2"></a>

2. **赵桓子排斥浣，在代自立，但没能长久控制赵氏。** 襄子的继承安排因此被打断。桓子在位仅一年就死去，国人认为他夺位违背襄子本意，杀其子，又迎回浣。 [[2]](#note-2)

<a id="event-3"></a>

3. **韩氏由武子执掌，魏氏则由文侯治理，三支强卿各自延续本家的政治秩序。** 韩武子接续参与灭智的康子；魏文侯也称魏斯，其先世同样由晋卿发展起来。此时三家虽有独立行动的力量，正式获周王命为诸侯仍是后来的事。 [[3]](#note-3)

## 归年与考证

<a id="1灵公元年与献公出生"></a>
#### 1｜灵公元年与献公出生

[卷015秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0424)明列“秦靈公元年。生獻公”。出生暂据该格系年，不由后来的在位数倒推生日。献公是事后谥号，不表示婴儿已经做国君。[前425年](bce-0425.md#event-1)为实际拥立；前428年“生灵公”的父系疑点仍见[旧注](bce-0428.md#note-1)，不因本条相接便一并解决。


<a id="2夺位经过与复归纪元"></a>
#### 2｜夺位经过与复归纪元

[卷015赵栏](../../sources/摘录/史记-卷015-六国年表.md#y0424)为桓子元年，次年才标献侯元年；[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-1e18378f8cd003)记逐浣、自立于代、一年卒及复迎。此页按这一年度衔接整理桓子终局，夺位的确切起日与浣归来的月份未详。浣不是桓子的儿子，国人杀桓子之子与迎浣是不同人物的命运。


<a id="3韩武子元年魏文侯纪年与称侯不混算"></a>
#### 3｜韩武子元年、魏文侯纪年与称侯不混算

[卷015魏、韩栏](../../sources/摘录/史记-卷015-六国年表.md#y0424)并列魏文侯斯、韩武子元年。[《韩世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7045.md#ref-7641b4f9243a89)记康子卒、子武子代；本次不补未明载的康子死亡年份。武子不是韩氏早期受封韩原的同号祖先。

魏文侯不能据此确定为本年才开始掌政。[《魏世家》三家注](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7044.md#ref-c0f1199ea86da1)已经指出文侯在位三十八年与《纪年》五十年不同，斯／都及与桓子的代距也有异文。[马卫东、王政冬《清华简〈繫年〉三晋伐齐考》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-e0b861255be85172.md#cite-8)讨论前445年起算及称侯改元等解释；[李守奎相关研究](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-0bbfce83d39d89e0.md#cite-2)则讨论简王八年三家纪元与前后战争的关系。这些方案不能机械合为同一次即位，故正文只介绍此时的执政者，表的元年留注。也不将《楚世家》本年“始列为诸侯”直接替换[前403年周命](bce-0403.md)。

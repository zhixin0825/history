# 公元前425年｜秦怀公被逼死，赵氏旧年表承继附读

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **庶长朝和大臣围逼秦怀公，怀公自杀，灵公被立。** 怀公太子昭子早已死去，大臣于是立昭子之子为君。新君是怀公之孙，昭子本人并未正式在位。 [[1]](#note-1)

<a id="event-2"></a>

2. **周王室进入威烈王元年。** 午继承父亲考王后的新纪年从本年开始，王室依旧面对强卿掌握晋国实权的局面。 [[2]](#note-2)

<a id="event-3"></a>

3. **赵襄子卒，赵浣初掌赵氏。** 赵襄子想把家位归于未能承嗣的兄长伯鲁一支。伯鲁的儿子代成君周先死，襄子择周之子浣为嗣。襄子去世后，浣继立为献侯。襄子卒与浣初立的确年未定。 [[3]](#note-3)

<a id="event-4"></a>

4. **卫国由公子亹执政，开始计新君元年。** 亹此前杀掉昭公取得君位。国小势弱并没有消除公室内部的争夺。 [[4]](#note-4)

## 归年与考证

<a id="sj005-147-note"></a>
<a id="1秦怀公之死与灵公被立"></a>
#### 1｜秦怀公之死与灵公被立

[卷005 P045](../../sources/摘录/史记-卷005-秦本纪.md#p045)记怀公四年被围而自杀；[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0425)简写“庶長晁殺懷公”，两者描述同一政变，不另造一次死亡。朝、晁为所读见证的异写。灵公元年另见[前424年](bce-0424.md#event-1)，不把已故太子昭子增列为在位国君。保留旧锚点，归年口径见[卷005考证](../../meta/考证/史记-卷005-纪年与异说.md)。


<a id="2承位在前一年"></a>
#### 2｜承位在前一年

[卷015周栏](../../sources/摘录/史记-卷015-六国年表.md#y0425)列威烈王元年；考王死亡、午承位已见[前426年](bce-0426.md#event-1)，此处不再记一次即位。尚未发生[前403年的三家受命](bce-0403.md)。


<a id="3赵襄子终局浣初立与桓子夺位"></a>
#### 3｜赵襄子终局、浣初立与桓子夺位

[卷015赵栏](../../sources/摘录/史记-卷015-六国年表.md#y0425)为襄子三十三年卒；[《赵世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-27979d76a2e982)给出伯鲁—周—浣及襄子坚持传兄支的经过，继叙桓子逐浣、在代自立、一年卒、国人复迎浣。现在将襄子之死与浣初立放本年，桓子纪元见[前424年](bce-0424.md#event-2)，浣复立后的纪元见[前423年](bce-0423.md#event-2)。各阶段未获明确月日，不强定争位在某一天完成；《世本》等关于赵氏父系的异说并未因此解决。献侯为浣的后称，并不表示此时已获周天子封侯。


<a id="4卫亹的名号与实际夺位分开"></a>
#### 4｜卫亹的名号与实际夺位分开

[卷015魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0425)作“衛悼公亹元年”，[《卫康叔世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-d04562ae4c5588)则称杀昭公的公子亹为怀公。正文用人名以免与前455年的卫悼公黔混合。按前431年昭公元年与世家六年遇害相接，夺位应是前426年前后，不能因本年标元年又写一次杀君。卫国早期王年链仍有异说，此处只是现行体系下的衔接；魏栏不是在说魏国更换国君。

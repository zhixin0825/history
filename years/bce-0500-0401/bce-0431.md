# 公元前431年｜楚简王灭莒，卫昭公元年

[← 公元前432年](bce-0432.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前430年 →](bce-0430.md)

## 本年纪事

<a id="event-1"></a>
**楚国进入简王元年，并向北出兵灭莒。** 简王承接惠王时期的扩张方向，莒国成为楚军新的进攻目标。[1](#note-1)

<a id="event-2"></a>
**卫国进入昭公纠元年。** 敬公之子纠接掌君位，但卫国的力量已经很弱。在昭公时期，韩、赵、魏的影响进一步压在卫国之上，卫君须依附这些强大的邻近势力。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜简王元年与灭莒

[卷015本年楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0431)：「楚簡王仲元年。滅莒。」[《楚世家》简王段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-e2209d263195be)记「簡王元年，北伐滅莒」。正文沿这条相同的相对年次及本项目传统绝对年坐标；惠王死、子简王接位另在[前432年](bce-0432.md#event-1)，不重复记为本年初次承位。

名字「仲／中」分别保留于表、世家。北伐的路线、统帅、月份、莒君结局未载，不补造；后来史籍中仍出现莒地或攻莒的文字，也不自动等于本年灭国从未发生，须分别辨政权与地域。《系年》相关研究对楚王年数的讨论见[前432年注1](bce-0432.md#note-1)，本次未据此宣布楚简王完整年表已重定。

<a id="note-2"></a>
### 2｜魏栏所记的是卫昭公

[卷015本年魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0431)：「衛昭公元年。」[《卫康叔世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-f863e46ad70c24)给出敬公十九年卒、子昭公纠立，随后概括三晋强、卫如小侯而属之。死亡与承位暂接[前432年](bce-0432.md#event-2)，本年只记新君元年及相关时期背景。

三晋势力强盛不代表周天子已经在本年完成三家封侯；政治依附也不等于查得一份降低卫君爵位的诏命。卫君整套王年的前后分歧不在本次全部消除，更不能按表格列名把卫昭公误写成魏昭公。

# 公元前435年｜秦地六月降雪，并有日月食记载

[← 公元前437年](bce-0437.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前434年 →](bce-0434.md)

## 本年纪事

<a id="event-1"></a>
**秦地六月降雪。** 躁公八年留下了这项天气记载。[1](#note-1)

<a id="event-2"></a>
**本年又记有日食、月食。** 两项天象没有分别记下具体日期。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜“雨雪”是降雪，古六月不直接换成公历六月

[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0435)：「八。六月，雨雪。日、月蝕。」[三家注版相应年行](https://zh.wikisource.org/wiki/史記三家註/卷015)也保存这一文字。“雨”在此作动词，不译成已经同时发生大雨、暴雪两场灾害。六月沿古史年条保留；没有雪深、受灾范围或收成资料，不补出饥荒与损失数字。

<a id="note-2"></a>
### 2｜日食、月食分别处理

原格将降雪、日食、月食并记，但未逐项给出月日。本页不把日食和月食写成同一天发生，也不自动认定全部都在六月；未独立历算具体食相、可见范围或公历日期。

# 公元前442年｜秦躁公元年

[← 公元前443年](bce-0443.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前441年 →](bce-0441.md)

## 本年纪事

<a id="event-1"></a>
**秦国开始以躁公元年纪事。** 厉共公的儿子躁公接掌秦国，父亲去世与实际承位已见前一年，本年是新君纪年的开始。[1](#note-1)

<a id="event-2"></a>
**秦国有彗星出现的记载。** 这条天象没有留下月日。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜承位与元年分开

[卷015本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0442)列「秦躁公元年」。[《秦本纪》厉共公末年](https://zh.wikisource.org/wiki/史記/卷005#秦厲共公)记厉共公三十四年卒、子躁公立，主体已在[前443年](bce-0443.md#event-1)，此处不再增加一次继承。此后的南郑反秦见[前441年](bce-0441.md#event-2)。

<a id="note-2"></a>
### 2｜彗星来自卷006的秦先君附记

[卷006篇末秦先君附记](https://zh.wikisource.org/wiki/史記/卷006)记躁公「其元年，彗星見」。本次用卷015的元年坐标接入，不把它错接到上一条厉共公十年的彗星，也不把前443年的日食视作同一天象。位置、轨道和现代编号未经核定，不能据此判断是哪颗周期彗星。

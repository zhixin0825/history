1. **楚国攻灭杞国。** 两年前灭蔡之后，楚惠王又吞并了另一个旧诸侯国。杞君简公春刚接续出公不久，杞国的君位传承便在楚军进攻下中断。 此前阏路弑兄自立、哀公卒及出公卒，已按古代编年互证暂系[前471](bce-0471.md#sj036-qi-min-killed-event)、[前461](bce-0461.md#sj036-qi-ai-death-event)、[前449年](bce-0449.md#sj036-qi-chu-death-event)；相互冲突的在位数仍在各注说明。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚国与秦国讲和。** 楚一面继续向东扩展，一面缓和与秦的关系；这条和议与灭杞并记，但没有留下具体条件。 [[2]](#note-2)

<a id="sj040-chu-eastward-event"></a>

3. **楚势力向东延伸至泗水流域。** 越灭吴后，未能稳住江淮以北。楚惠王在位后期，楚势力逐渐伸向泗水一带。 [[3]](#sj040-chu-eastward-note)

## 归年与考证

<a id="1楚惠王四十四年灭杞"></a>
#### 1｜楚惠王四十四年灭杞

[卷015本年楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0445)：「四十四。滅杞。杞，夏之後。」[《陈杞世家》杞段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7036.md#ref-250baf79938b74)记出公死、子简公春立，继称「立一年，楚惠王之四十四年，滅杞」；[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-bdbc6cf2cb930c)同系惠王四十四年。正文采用楚惠王四十四年前445这一共同年次。简公“立一年”与从前487釐公卒向后相承的年链不合；[《七国统表》](../../sources/补充阅读/杞国末世纪年-正义与分纪摘录.md#qg-jian-four)已保存简公四年的旧有考订；本轮据此明示前448至445四年说，保留“一年”原字，详见[本卷王年核对](../../meta/记录/史记-卷036-王年与世系核对.md)。

本注所引晚世承继是灭国前的跨年背景，不是所有事都发生在前445年。“夏之后”是杞国的族源、祭祀传承叙述，不是独立验证的远古血缘。世家「杞后陈亡三十四年」有两种可比算法：依《十二诸侯年表》陈亡前479年至本年相隔34年；依经传陈亡前478年至本年相隔33年，首尾并数也可计34。单句不能独立裁定陈亡年，也不据此断定作者只采用某一种计数法。灭杞不等于所有杞人都遇害；统帅、战役日与简公下落未详，不补造。前一次灭蔡见[前447年](bce-0447.md#event-1)。


<a id="2秦楚讲和与向东扩展"></a>
#### 2｜秦楚讲和与向东扩展

[《楚世家》惠王段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-fbb408caa424fe)在四十四年灭杞后记「與秦平」，再总述楚向东扩地至泗上。讲和沿该年条整理；扩张概况不是一份全部完成于本年的城邑清单。和议不擅译成秦臣服于楚或已经确立永久军事同盟。

<a id="sj036-retrospect"></a>

### 全卷回顾与后出述赞（不作本年事件）

以下是作者对陈、杞及古代诸侯材料的取舍和评论，不是楚灭杞当年新发生的事情。

<a id="sj036-cite-092"></a>

**[《史记·陈杞世家》P029](../../sources/摘录/史记-卷036-陈杞世家.md#p029)**

> 杞小微，其事不足稱述。

**本卷说明：** “不足称述”是作者的材料取舍说明，不据它填补缺君和疑年。

<a id="sj036-cite-093"></a>

**[《史记·陈杞世家》P030](../../sources/摘录/史记-卷036-陈杞世家.md#p030)**

> 舜之後，周武王封之陳，至楚惠王滅之，有世家言。禹之後，周武王封之杞，楚惠王滅之，有世家言。契之後為殷，殷有本紀言。殷破，周封其後於宋，齊湣王滅之，有世家言。后稷之後為周，秦昭王滅之，有本紀言。皋陶之後，或封英、六，楚穆王滅之，無譜。伯夷之後，至周武王復封於齊，曰太公望，陳氏滅之，有世家言。伯翳之後，至周平王時封為秦，項羽滅之，有本紀言。垂、益、夔、龍，其後不知所封，不見也。右十一人者，皆唐虞之際名有功德臣也；其五人之後皆至帝王，餘乃為顯諸侯。滕、薛、騶，夏、殷、周之閒封也，小，不足齒列，弗論也。

**本卷说明：** 十一人、五人之后属于本篇分类。[《索隐》p29](../../sources/史记三家注/卷036.md#p29)指出伯翳与益可能同人，并说明舜、禹本身为帝王，稷、契、翳的后代成为帝王；原文计数不等于已经独立证明十一位互不相同的人物。

<a id="sj036-cite-094"></a>

**[《史记·陈杞世家》P031](../../sources/摘录/史记-卷036-陈杞世家.md#p031)**

> 周武王時，侯伯尚千餘人。及幽、厲之後，諸侯力攻相并。江、黃、胡、沈之屬，不可勝數，故弗采著于傳（上）［云］。

**本卷说明：** “千余”是史家对武王时的概括，江、黄、胡、沈等被略去是篇章范围说明，不推算为某年精确国数。

<a id="sj036-cite-095"></a>

**[《史记·陈杞世家》P032](../../sources/摘录/史记-卷036-陈杞世家.md#p032)**

> 太史公曰：舜之德可謂至矣！禪位於夏，而後世血食者歷三代。及楚滅陳，而田常得政於齊，卒為建國，百世不絕，苗裔茲茲，有土者不乏焉。至禹，於周則杞，微甚，不足數也。楚惠王滅杞，其後越王句踐興。

**本卷说明：** “其后”在这里可作禹之后裔的承续理解，这是本轮释读，并非已查到古注定论。可靠的时间边界是勾践[前473年灭吴](bce-0473.md)早于本年前445灭杞，不能读成杞亡以后勾践才兴起。

<a id="sj036-cite-096"></a>

**[《史记·陈杞世家》Z001](../../sources/摘录/史记-卷036-陈杞世家.md#z001)**

> 【索隱述贊】盛德之祀，必及百世。舜、禹餘烈，陳、杞是繼。媯滿受封，東樓纂系。閼路篡逆，夏姬淫嬖。二國衰微，或興或替。前並後虜，皆亡楚惠。句踐勃興，田和吞噬。蟬聯血食，豈其苗裔？

**本卷说明：** 此为唐代《索隐述赞》，与太史公论分层；文学顺序不构成各事先后的独立证据。

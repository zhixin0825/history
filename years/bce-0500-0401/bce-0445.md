# 公元前445年｜楚灭杞，秦楚讲和

[← 公元前447年](bce-0447.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前444年 →](bce-0444.md)

## 本年纪事

<a id="event-1"></a>
<a id="sj015-0445-qi"></a>
**楚国攻灭杞国。** 两年前灭蔡之后，楚惠王又吞并了另一个旧诸侯国。杞君简公春刚接续出公不久，杞国的君位传承便在楚军进攻下中断。[1](#note-1)

<a id="event-2"></a>
**楚国与秦国讲和。** 楚一面继续向东扩展，一面缓和与秦的关系；这条和议与灭杞并记，但没有留下具体条件。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜楚惠王四十四年灭杞

[卷015本年楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0445)：「四十四。滅杞。杞，夏之後。」[《陈杞世家》杞段](https://zh.wikisource.org/wiki/史記/卷036#杞)记出公死、子简公春立，继称「立一年，楚惠王之四十四年，滅杞」；[《楚世家》](https://zh.wikisource.org/wiki/史記/卷040#楚惠王)同系惠王四十四年。正文采用这一共同年次，不把世家「立一年」误记成简公已在位四年。

「夏之后」是杞国的族源、祭祀传承叙述，不是独立验证的远古血缘。世家「杞后陈亡三十四年」与本项目采用的陈亡年仍有计数差别，不能借此改动陈国旧年页。灭杞不等于所有杞人都遇害；统帅、战役日与简公下落未详，不补造。前一次灭蔡见[前447年](bce-0447.md#event-1)。

<a id="note-2"></a>
### 2｜秦楚讲和与向东扩展

[《楚世家》惠王段](https://zh.wikisource.org/wiki/史記/卷040#楚惠王)在四十四年灭杞后记「與秦平」，再总述楚向东扩地至泗上。讲和沿该年条整理；扩张概况不是一份全部完成于本年的城邑清单。和议不擅译成秦臣服于楚或已经确立永久军事同盟。

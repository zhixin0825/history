# 公元前449年｜越人赴秦迎女，燕成公元年

1. **越人来到秦国迎接女子，办理婚姻往来。** 这条远距离交往留下了记录，却没有交代女子的名字、她与秦君的关系或越方的婚配对象。 [[1]](#note-1)

<a id="event-2"></a>
<a id="sj015-0449-yan"></a>

2. **燕国开始以成公元年计事。** 前一年孝公去世，成公已继承君位，本年不重复记一次改立。 [[2]](#note-2)

<a id="sj036-qi-chu-death-event"></a>

3. **杞出公去世，简公承继。** 出公敕去世，儿子春承继君位，为简公。这次承继暂系本年；杞国此后仍延续数年，到前445年被楚国攻灭。 [[3]](#sj036-qi-chu-death-note)

<a id="sj041-event-4"></a>

4. **越王不寿被杀，翁承继君位。** 不寿在位十年后被杀，儿子翁接掌越国，古注所引称朱勾。沿前459年承位、次年前458年起元的年链，此事暂系本年。主文只写去世，古注保存了被杀的异文，未给杀人者姓名。 [[4]](#sj041-note-4)

## 归年与考证

<a id="1越人来迎女"></a>
#### 1｜越人来迎女

[《六国年表》本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0449)：「二十八。越人來迎女。」二十八为秦厉共公年数，「来」以秦为叙述中心。正文只叙婚姻往来，不擅定为秦公主嫁越王、太子婚礼，也不编造迎亲路线、聘礼数额及已经订立的军事联盟。


<a id="2燕成公纪元"></a>
#### 2｜燕成公纪元

[本年燕栏](../../sources/摘录/史记-卷015-六国年表.md#y0449)与[《燕召公世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7034.md#ref-93d5ce793f5a24)所记孝公十五年卒、成公立合读。死亡主述在[前450年](bce-0450.md#event-2)。

# 公元前449年｜越人赴秦迎女，燕成公元年

[← 公元前450年](bce-0450.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前448年 →](bce-0448.md)

## 本年纪事

<a id="event-1"></a>
<a id="sj015-0449-yue"></a>
**越人来到秦国迎接女子，办理婚姻往来。** 这条远距离交往留下了记录，却没有交代女子的名字、她与秦君的关系或越方的婚配对象。[1](#note-1)

<a id="event-2"></a>
<a id="sj015-0449-yan"></a>
**燕国开始以成公元年计事。** 前一年孝公去世，成公已继承君位，本年不重复记一次改立。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜越人来迎女

[《六国年表》本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0449)：「二十八。越人來迎女。」二十八为秦厉共公年数，「来」以秦为叙述中心。正文只叙婚姻往来，不擅定为秦公主嫁越王、太子婚礼，也不编造迎亲路线、聘礼数额及已经订立的军事联盟。

<a id="note-2"></a>
### 2｜燕成公纪元

[本年燕栏](../../sources/摘录/史记-卷015-六国年表.md#y0449)与[《燕召公世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7034.md#ref-93d5ce793f5a24)所记孝公十五年卒、成公立合读。死亡主述在[前450年](bce-0450.md#event-2)。

# 公元前450年｜蔡侯齐元年，燕孝公去世

[← 公元前451年](bce-0451.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前449年 →](bce-0449.md)

## 本年纪事

<a id="event-1"></a>
<a id="sj015-0450-cai"></a>
**蔡国进入侯齐元年。** 齐是元侯之子，父亲前一年去世以后已经接位；本年开始计算新君年数。[1](#note-1)

<a id="event-2"></a>
<a id="sj015-0450-yan"></a>
**燕孝公去世，成公接掌燕国。** 孝公在位十五年，成公元年接在下一年。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜蔡侯齐的名字与元年

[卷015本年楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0450)记「蔡侯齊元年」；[《管蔡世家》](https://zh.wikisource.org/wiki/史記/卷035#復蔡)作元侯卒、子侯齐立。齐为人名，蔡为国名，侯为称号；不把三个层次拆成另一个齐侯来统治蔡国。父亲终局见[前451年](bce-0451.md#event-2)。

<a id="note-2"></a>
### 2｜燕孝公十五年

[《燕召公世家》](https://zh.wikisource.org/wiki/史記/卷034#燕孝公)记孝公十五年卒、成公立；[本年燕栏](../../sources/摘录/史记-卷015-六国年表.md#y0450)为十五，下一年前449年成公元年。据此归本年终局，但现有短句未明确父子关系，正文不自行添入。

<a id="sj015-0450-song-note"></a>
### 宋昭公元年不在本年再发生一次

[本年齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0450)记「宋昭公元年」，承接前451年表列宋景公卒，构成后移十八年的同一组年数。本项目已在[前469年](bce-0469.md#event-3)记录景公之死、六卿拥立得；次年前468年为昭公元年的对照，亦见苏建洲[研究中的宋君年表](https://www.fdgwz.org.cn/Web/Show/2426)。本页只登记年表差别，不再写一次拥立得的政变。详见[前451年同事注](bce-0451.md#sj015-0451-song-note)。

<a id="sj015-0450-wei-note"></a>
### 卫敬公元年须连同前君的整条年代核对

[本年魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0450)列「衛敬公元年」；[《卫康叔世家》](https://zh.wikisource.org/wiki/史記/卷037)记悼公五年卒、子敬公弗立。但这条年数链承接前455年表列的卫悼公元年，与《左传》前469年已经拥立悼公不合。

本页保留敬公是悼公之子的传世承继信息及表列元年的位置，**不据尚未解决的年数链新写本年确定的悼公死亡、敬公即位**，也不凭简单减十四年就宣称整条卫国王年已校完。前君问题见[前455年注](bce-0455.md#sj015-0455-wei-note)。

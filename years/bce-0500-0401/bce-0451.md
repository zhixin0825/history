# 公元前451年｜秦筑南郑，蔡元侯去世

[← 公元前452年](bce-0452.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前450年 →](bce-0450.md)

## 本年纪事

<a id="event-1"></a>
<a id="sj015-0451-nanzheng"></a>
**秦国左庶长主持修筑南郑城。** 短记没有留下这位官员的姓名，也没有交代工程持续时间。[1](#note-1)

<a id="event-2"></a>
<a id="sj015-0451-cai"></a>
**蔡元侯去世，儿子齐继承君位。** 元侯在位六年；新君名齐，不是蔡国改成了齐国。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜左庶长城南郑

[《六国年表》本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0451)记厉共公二十六年「左庶長城南鄭」。据此叙述筑城，不由「城」推定本年首次发现该地、首次设县或已完成全部汉中地区的征服；未提供确切城址及工程尺寸。

<a id="note-2"></a>
### 2｜蔡元侯六年与后继元年

[《管蔡世家》](https://zh.wikisource.org/wiki/史記/卷035#復蔡)记「元侯六年卒，子侯齊立」。元侯元年在[前456年](bce-0456.md#sj015-0456-cai)，六年对应本年；卷015下一行前450年亦列蔡侯齐元年。死亡、承位和逾年纪元分开，不补确日或死因。

<a id="sj015-0451-song-note"></a>
### 宋景公卒年后移十八年的问题

[本年齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0451)记「宋景公卒」，但《左传》哀公二十六年已有冬十月景公去世、匿丧及改立得的完整过程，主体保留在[前469年](bce-0469.md#event-3)。本页不再安排第二次死亡。

现代研究也注意到这一年数链的错位。清华读书会[《〈清华大学藏战国竹简〉（贰）研读札记（二）》](https://www.fdgwz.org.cn/Web/Show/1760)讨论钱穆、杨宽对宋君年数的不同调整；苏建洲[《也论清华简〈系年〉“莫嚣昜为”》](https://www.fdgwz.org.cn/Web/Show/2426)所列对照表采用前469年景公四十八年、前468年昭公元年。本项目据经传明年及相关研究保留旧主述，不沿年表后移十八年；这不等于宋国后续各王年以及楚、晋对年都已一并校定。

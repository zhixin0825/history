1. **韩、魏、赵合力灭智伯。** [[1]](#note-1)

<a id="event-2"></a>

2. **晋阳被围已久，赵襄子面临败亡。** 在这以前，智伯向韩、魏、赵索取土地，韩、魏答应，赵氏拒绝；智伯便带韩、魏的军队攻赵，赵襄子退守晋阳。围城持续一年多，攻方引汾水灌城，城内连炊食也困难起来。 赵、智积怨还见于围郑传述：智伯醉后以酒灌击无恤，随臣请与他死斗，无恤以父亲选自己正因为能忍而制止；智伯归后又劝简子废无恤，简子不听。该事的出公年次与简襄承继有矛盾，先后背景可以附读，具体发生年仍待考。 在本篇前因中，四卿先分范、中行旧地，晋出公向齐鲁求援，反被四卿攻逐，奔齐途中死，智伯立昭公曾孙骄为晋懿公；这一君位年链另有异说。 水围只剩三版城墙未没，城中悬锅炊食、甚至易子而食，群臣多生外心，唯高共仍守臣礼。 [[2]](#note-2)

<a id="event-3"></a>

3. **赵襄子派人秘密联络韩、魏，两家转而与赵合谋，反攻智氏。** 韩康子、魏桓子与赵襄子共同打败智伯，结束晋阳之围，并瓜分智氏的土地。智氏从分地的强者变为被三家瓜分的对象，晋国内部的力量对比由此改变。 襄子遣相张孟同夜间秘密联络韩魏，反攻记于三月丙戌。 赵北有代，南得智地，势力一时强于韩魏；襄子还在百邑祭三神，令原过主管霍太山祠。 韩康子在本篇世系中承接贞子、简子、庄子等代，分得智氏土地后势力进一步扩大；这些先世承继不都发生于灭智之年。 [[3]](#note-3)

<a id="event-4"></a>

4. **战后赏功时，赵襄子特别奖赏在危急中始终恪守臣礼的高共。** 张孟同认为高共没有战功，不应居先；襄子却回答，晋阳最危险时众臣懈怠，只有高共始终不失臣礼，所以先赏他。 [[4]](#note-4)

   智氏败亡也成为豫让复仇故事的起点。相关材料仍沿原来的《刺客列传》入口阅读，未确年的后续行刺不全塞进这场战斗当天。


   [卷四互见与归年](#sj004-453-1) · [秦本纪互见](#sj005-140-note)

<a id="sj046-tianpan-lineage-event"></a>

5. **田盘经营齐国都邑，并与三晋往来。** 田常去世后，儿子田盘承继，称田襄子，相齐宣公；这些承继是本次三晋分智地之前的背景，卒年未另定。田盘让兄弟宗人担任各都邑大夫，并同韩赵魏通使，扩大田氏对齐国的控制。此后家族又经田白、田悼子等转至田和；各传世系有省略，不能从一串父子名倒排每代卒年，也不能把后来的齐军战事都写成田白亲自统率。 [[5]](#sj046-tianpan-lineage-note)

## 归年与考证

<a id="1三家灭智的共同年次及跨年的围城过程"></a>
#### 1｜三家灭智的共同年次，及跨年的围城过程

[卷015本年魏、韩、赵三栏](../../sources/摘录/史记-卷015-六国年表.md#y0453)分别记魏桓子、韩康子、赵襄子败智伯于晋阳，赵栏接三分其地。三格是同一行动的互见，不是三次分别灭智氏。

[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-e280284ca99292)补出索地、赵奔晋阳、围城岁余、引汾水灌城、密使韩魏与合谋反攻。所读本称使者张孟同；其他文本的张孟谈等写法保留作人物名称问题，不拆成两轮已经证实的秘密使团。世家并记城不浸者三版、城内饥困等细节，未据此计算现代水深、城内人口或死亡人数。

本项目沿年表及既有周、秦本纪互见，把最后灭智放前453年；分范、中行故地另见[前454年](bce-0454.md#event-1)。围城起点及晋出公末年的相互纪年还有分歧，不因结局年份可用就宣称全部过程已逐月复原。古书三月丙戌也未换算为公历日。


<a id="2高共受赏"></a>
#### 2｜高共受赏

[《赵世家》晋阳段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-15e413515baeed)在解围后记高共受赏、张孟同质疑及襄子作答。正文保留这段传世奖赏故事，不从中推出高共毫无其他贡献或其他臣下都已实际叛变。后接的神授竹书与祭祀属于另一文本层，不能当成预测战日已经验证的证据。

<a id="韩赵魏消灭智氏卷四互见"></a>
#### 韩赵魏消灭智氏｜卷四互见

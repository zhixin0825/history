# 公元前455年｜齐宣公元年

## 本年纪事

<a id="event-1"></a>
<a id="sj015-0455-qi"></a>
**齐国开始以宣公元年计事。** 前一年平公去世，他的儿子已经接位。齐国仍由姜姓君主承嗣，并不是到了这一年才第一次改为田氏君主。[1](#note-1)

## 本年相关史料

<a id="note-1"></a>
### 1｜宣公纪元及名字异文

[《六国年表》本年齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0455)作「齊宣公就匝元年」；[《齐太公世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7032.md#ref-f0cac0853c5808)称平公之子宣公积。正文只称宣公，把就匝、积两种写法留在本注，不凭不同名字再造一次继位。平公死亡见[前456年](bce-0456.md#sj015-0456-qi)。

<a id="sj015-0455-wei-note"></a>
### 卫悼公元年的另一套排年

[本年魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0455)记「衛悼公黔元年」。但《左传》哀公二十六年已经记卫人拒纳出公、另立悼公，本项目主述在[前469年事件2](bce-0469.md#event-2)。本页只登记相差十四年的纪元问题，不让卫悼公再被拥立一次。

[《卫康叔世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-36f6c4c96c051d)的出公后年数及悼公五年，也牵连下一位敬公的起年，须整体核查。这里不以移动一个元年便声称卫国整条年代已校定，更不把借魏栏保存的卫君称为魏国君主。

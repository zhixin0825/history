1. **秦置频阳县，晋一方取得武成。** 置县与边境失地在同年并见；秦的扩张并非只有进无退。 [[1]](#note-1)

<a id="event-2"></a>
<a id="sj015-0456-cai"></a>

2. **蔡国进入元侯元年。** 元侯承接父亲声侯留下的君位，前一年的死亡与继承不在本年重复叙述。 [[2]](#note-2)

<a id="event-3"></a>
<a id="sj015-0456-qi"></a>

3. **齐平公去世，儿子继位，是为齐宣公。** 平公在位二十五年；其统治时期齐国政权已受田氏控制，君位虽然继续在姜齐王族中传承，却不能由此看成田氏势力已经退出。 [[3]](#note-3)

## 归年与考证

<a id="sj005-139-note"></a>
<a id="sj005-139秦置频阳县晋一方取得武成"></a>
#### sj005-139｜秦置频阳县，晋一方取得武成。

[卷005 P043](../../sources/摘录/史记-卷005-秦本纪.md#p043)。

**说明：**本纪仍称“晋”，战国早段晋与三家称谓交错，不未核便给每次行动补上某一家独有统帅。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。


<a id="2蔡元侯纪元"></a>
#### 2｜蔡元侯纪元

[卷015本年楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0456)记「蔡元侯元年」。[《管蔡世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7035.md#ref-dc9705c270b610)记声侯卒、子元侯立，死亡主述见[前457年](bce-0457.md#sj015-0457-cai)。元侯本名未据现有材料补造。


<a id="3齐平公之死与宣公承位"></a>
#### 3｜齐平公之死与宣公承位

[《齐太公世家》平公段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7032.md#ref-cf80cc3286993e)记平公二十五年卒、子宣公积立；[卷015](../../sources/摘录/史记-卷015-六国年表.md#y0456)本年齐栏为平公二十五年，次年宣公元年。依此把死亡放在本年，不另造死亡日。田氏掌政是此前延续的背景，不等于本年又发生一次田氏夺权。

<a id="sj015-0456-jin-note"></a>
<a id="晋君忌与骄不能仅当作同人异名"></a>
#### 晋君「忌」与「骄」：不能仅当作同人异名

[卷015本年魏栏](../../sources/摘录/史记-卷015-六国年表.md#y0456)写「晉哀公忌元年」。[《晋世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7039.md#ref-cd596f2f7a5d9a)却说忌早死，智伯立的是忌之子骄；[《赵世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-fa3da502aa5e58)也称骄，但号懿公。两种名字在世家中是父子，不能不经校勘便说只是字形差异。

晋出公末年、四卿分地及新君初立在年表、晋世家、赵世家之间又有年次冲突。本页保留年表元年落点与人物问题，不新增一次已经确定发生于本年的出公死亡和册立；[前454年分地](bce-0454.md#note-1)与[前453年灭智](bce-0453.md#sj-086-L5391-01)分别处理，不用本行强行改写其他篇章的全部纪年。

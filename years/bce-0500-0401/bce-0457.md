# 公元前457年｜赵襄子元年、取代与秦绵诸之战

[← 上一张已编年页：公元前459年](bce-0459.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前456年 →](bce-0456.md)

<a id="本年纪事"></a>
<a id="sj015-0457-xiangzi"></a>

<a id="event-1"></a>

1. **赵襄子毋恤开始以元年纪事。** 晋卿赵简子鞅去世后，儿子毋恤继承赵氏权力。《六国年表》以本年为赵襄子元年；这时赵氏仍在晋的政治格局中，不可提前称为已经得到周天子正式承认的赵国诸侯。 [[1]](#note-1)

<a id="sj015-0457-dai"></a>

<a id="event-2"></a>

2. **赵襄子诱杀代王，赵氏取得代地。** 在父丧尚未除服期间，赵襄子到夏屋山一带邀请代王，暗中令侍从以盛食的金属器具杀死代王及随从，随后出兵占据代地。他的姐姐早已嫁给代王，闻变悲痛自杀。赵襄子把代地封给兄长伯鲁之子周，称代成君。具体行动持续多久不能从年表的单一年度栏推定。 [[2]](#note-2)

<a id="sj015-0457-mianzhu"></a>

<a id="event-3"></a>

3. **秦厉共公率军与绵诸交战。** 年表将此事列在厉共公二十年，未记战果，不能推断秦是否取得绵诸的全部领地。 [[3]](#note-3)

<a id="event-4"></a>
<a id="sj015-0457-cai"></a>

4. **蔡声侯去世，儿子继承君位，是为蔡元侯。** 声侯在位十五年，下一年才开始以元侯元年计事。 [[4]](#note-4)

## 归年与考证

<a id="1note-1-赵襄子元年"></a>
#### [[1]](#note-1) 赵襄子元年

**《史记》卷015《六国年表》·前457年赵栏** · [八栏原表](../../sources/摘录/史记-卷015-六国年表.md#y0457)

> 襄子。元年未除服

**《史记》卷043《赵世家》·赵简子去世及赵襄子继任** · [公开原文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-504d9629c4b19f)

> 晉出公十七年，簡子卒，太子毋卹代立，是爲襄子。

**说明：** 卷015晋出公元年前474，十七年对应前458，次年前457编襄子元年。世家同篇却在「襄子元年」之下记越围吴与楚隆出使；这件事在《左传》鲁哀公二十年（前475年）有明确记录，已经归入[前475年](bce-0475.md#note-3)，不重造为前457年的另一次围吴。详见[卷015纪年考证](../../meta/考证/史记-卷015-纪年与异说.md#前457年赵襄子元年与赵世家的围吴错置疑点)。



<a id="2note-2-杀代王取代地及分封"></a>
#### [[2]](#note-2) 杀代王、取代地及分封

**《史记》卷015《六国年表》·前457年赵栏** · [八栏原表](../../sources/摘录/史记-卷015-六国年表.md#y0457)

> 登夏屋，誘代王，以金斗殺代王。封伯魯子周為代成君。

**《史记》卷043《赵世家》·赵襄子取代** · [完整原文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-8cd602717602b2)

> 簡子旣葬，未除服，北登夏屋，請代王。使廚人操銅枓以食代王及從者，行斟，陰令宰人各以枓撃殺代王及從官，遂興兵平代地。

**说明：** 年表作「金斗」，世家作「铜枓」，器物字词与材质可能涉及异本或泛称，不直译为黄金器皿。《赵世家》又记襄子之姊已为代王夫人、闻讯摩笄自杀、封兄伯鲁子周；婚姻属于行动前的背景，不能误定为本年新婚。襄子元年归年依卷015，其与围吴记载的冲突已另存考证；不由一条叙事推定杀代王的精确日期。

<a id="4note-4-蔡声侯终局"></a>
#### [[4]](#note-4) 蔡声侯终局

[卷015本年楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0457)记「蔡聲侯卒」；[《管蔡世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7035.md#ref-bdb36719ec9cd3)记「聲侯十五年卒，子元侯立」。与前471年声侯元年及前456年元侯元年相接，本年只补死亡与承位。元侯本名、死亡原因及确切月日均不据此猜补。

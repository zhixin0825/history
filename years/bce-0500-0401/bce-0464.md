# 公元前464年｜晋军围郑，智伯与赵毋恤结怨

1. **赵毋恤领兵攻郑受智伯羞辱，回师后险失继承。** 晋军进攻郑国，赵毋恤代替患病的父亲赵简子领兵参战，却受到智伯羞辱。智伯就是荀瑶，赵、智两家此时都还是晋国卿族。智伯酒醉后把酒泼在毋恤身上，毋恤的属下想为他拼命。毋恤制止他们，表示父亲选自己为继承人，正是看重自己能忍受羞辱。这次攻郑中，晋军取得九邑，郑国又失去一批土地。回国后，智伯又向赵简子建议废掉毋恤，赵简子没有接受。智伯回国后劝赵简子废掉无恤，简子没有接受。无恤得以保持嗣位，此事加深了他与智伯的嫌隙。 [[1]](#reading-note-1)

2. **燕国进入孝公元年。** 前一年献公去世、孝公承位，至本年开始用新君年数计事。 [[2]](#reading-note-3)

## 归年与考证

<a id="note-1"></a>
<a id="1晋出公十一年与悼之四年"></a>
#### 1｜晋出公十一年与「悼之四年」

[《赵世家》简子段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7043.md#ref-41ba2fcc955003)明确以「晉出公十一年」起叙伐郑、简子病、毋恤领兵、智伯醉辱及建议废嗣。按本项目出公元年前474年，十一年对应前464年；[卷015本年赵栏](../../sources/摘录/史记-卷015-六国年表.md#y0464)亦记废嗣不成及结怨。

[《左传》篇末及正义卷60](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E5%82%B3%E6%AD%A3%E7%BE%A9-%E5%8D%B760.md#ref-c348a974027d7b)在哀公年条结束后另记「悼之四年」晋围郑、智伯与赵孟相恶。这是后续材料，不是哀公二十七年当年事。悼公元年采用前467或前466，会使四年分别落前464或前463；本页采用能与《赵世家》明确年次相接的前464暂述，保留另一换算，不在前463年重复制造同一冲突。

「太子」在这段指赵氏的继承人，不是晋国国君的太子。酒后冲突、回国建议和后来晋阳交战分阶段处理；毋恤、无恤等字形互见不另造人物。

<a id="sj015-0464-qi-note"></a>
<a id="齐救郑与中行文子的谈话不照表再演一次桐丘故事"></a>
#### 齐救郑与中行文子的谈话：不照表再演一次桐丘故事

[卷015本年韩、齐栏](../../sources/摘录/史记-卷015-六国年表.md#y0464)记驷桓子向齐求救、齐来援晋退，以及中行文子对田常说「乃今知所以亡」。但《左传》将齐援、晋退及这句谈话明确放在哀公二十七年的桐丘之役，已在[前468年事件3](bce-0468.md#event-3)完整叙述。

本页登记年表的另一落点，不据相同情节再补一场完整的齐救郑；也不因有这项错置疑点，就删除《赵世家》另具年次的围郑与赵氏储嗣冲突。两次晋郑军事行动与重复移录的细节，须分别判断。

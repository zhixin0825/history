# 公元前467年｜秦军攻取魏城

[← 公元前468年](bce-0468.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前466年 →](bce-0466.md)

## 本年纪事

<a id="event-1"></a>
<a id="sj015-0467-weicheng"></a>
**秦国一位庶长率军攻取魏城。** 庶长是领兵者的官称，现存短记没有留下他的姓名；不能因此把战事改说成秦攻陷了后来魏国的国都。[1](#note-1)

<a id="event-2"></a>
<a id="sj015-0467-comet"></a>
**天空出现彗星。** 这一观测没有月份和持续时间，不与三年前的记录直接合成同一次天象。[2](#note-2)

## 本年相关史料

<a id="note-1"></a>
### 1｜庶长攻取魏城

[《六国年表》前467年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0467)：「十。庶長將兵拔魏城。彗星見。」十为秦厉共公十年。[三家注本行](https://zh.wikisource.org/wiki/史記三家註/卷015)所收《集解》又记「拔」一作「捕」，正文采用主见证的「拔」作攻取理解。魏城的现代地望、所属范围和攻城细节，本轮未独立考定；官称庶长不增补为某位已知将领。

<a id="note-2"></a>
### 2｜彗星记录

与事件1共用[本年秦栏](../../sources/摘录/史记-卷015-六国年表.md#y0467)。两句同栏不等于战争与天象发生在同一天，更不构成天象导致战争的证据。前470年另有[彗星记录](bce-0470.md#sj015-0470-comet)，未做轨道回算，暂不判为同一颗彗星。

<a id="sj015-0467-lu-note"></a>
### 3｜鲁哀公之死：保留年表落点，不重复编造终局

[本年楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0467)另记「二十二。魯哀公卒」，下一行前466年才起鲁悼公元年。但[《鲁周公世家》](https://zh.wikisource.org/wiki/史記/卷033#魯哀公)把出奔、返鲁、死亡与子宁继立接在哀公二十七年段；[《左传正义》卷60](https://zh.wikisource.org/wiki/春秋左傳正義/卷60)还质疑返归有山氏而卒的叙事。

本项目已有[前468年出奔正文](bce-0468.md#event-4)与[终局异说](bce-0468.md#note-context-1)。本页登记年表的前467年说并回链，**不增加一次确定发生在本年的返鲁、死亡或再继位**；鲁悼公的统治状态另见前466年。楚栏借记鲁事，不是鲁哀公成为楚臣的证据。

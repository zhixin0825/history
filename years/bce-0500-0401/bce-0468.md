<a id="本年纪事"></a>
<a id="event-1"></a>

1. **鲁与越在平阳盟誓，商定邾田问题。** 春季，越派后庸来聘，讨论邾国田地，把边界定到骀上一带。二月，鲁、越在平阳盟誓，三桓都参与。季康子对这次受牵制的处境不满，提到若子贡在场或能避免，诸卿也谈到召回子贡。 [[1]](#note-1)

<a id="event-2"></a>

2. **季康子去世，哀公吊丧降低礼数。** 四月己亥，季康子去世。哀公前去吊丧，所用礼数有所降低，显示君臣关系仍然紧张。 [[2]](#note-2)

<a id="event-3"></a>

3. **晋攻郑，齐军来救，智伯撤回。** 荀瑶率晋军攻郑，驻桐丘。郑国驷弘向齐求援，陈恒先抚恤以往战死者的子弟，再领兵来救。齐军遇雨，郑使催促，陈恒亲自督军前进。荀瑶听闻后撤，仍遣人以陈国旧事向陈恒施压；流亡在齐的荀寅转述晋军将以轻车压齐阵的消息，陈恒表示不因敌众而退，荀寅随后反省自己发言失当。 [[3]](#note-3)

<a id="event-4"></a>

4. **哀公想借越国除三桓，最后出奔。** 哀公忧虑三桓势力，想借诸侯力量排除他们；三桓也担心国君动手。哀公在陵阪一带遇孟武伯，反复询问自己能否安然终老，未得答复。他又想借越伐鲁，八月到公孙有陉氏，随后出奔邾国，再赴越。鲁人处罚了公孙有山一方，国君与三桓的冲突以哀公出亡收场。 [[4]](#note-4)

### 3. 晋攻郑，齐军来救，智伯撤回

[返回正文第3条](#event-3)

> 晋荀瑶帅师伐郑，次于桐丘。郑驷弘请救于齐。齐师将兴，陈成子属孤子，三日朝。设乘车两马，系五邑焉。召颜涿聚之子晋，曰：“隰之役，而父死焉。以国之多难，未女恤也。今君命女以是邑也，服车而朝，毋废前劳。”乃救郑。及留舒，违穀七里，穀人不知。及濮，雨，不涉。子思曰：“大国在敝邑之宇下，是以告急。今师不行，恐无及也。”成子衣製，杖戈，立于阪上，马不出者，助之鞭之。知伯闻之，乃还，曰：“我卜伐郑，不卜敌齐。”使谓成子曰：“大夫陈子，陈之自出。陈之不祀，郑之罪也。故寡君使瑶察陈衷焉。谓大夫其恤陈乎？若利本之颠，瑶何有焉？”成子怒曰：“多陵人者皆不在，知伯其能久乎？”中行文子告成子曰：“有自晋师告寅者，将为轻车千乘，以厌齐师之门，则可尽也。”成子曰：“寡君命恒曰：‘无及寡，无畏众。’虽过千乘，敢辟之乎？将以子之命告寡君。”文子曰：“吾乃今知所以亡。君子之谋也，始衷终皆举之，而后入焉。今我三不知而入之，不亦难乎？”

### 《史记》所载哀公返鲁、去世与悼公继位，仍有争议。



《鲁周公世家》在出奔后接记国人迎哀公回来、卒于有山氏、子宁继位。《左传》本年明确叙述则止于出亡及处罚有山氏，孔颖达疏正因这点质疑《史记》的返归终局。本页保存世家的后续说法，但不把返鲁、卒地、卒日都当作已经统一核实的本年事实。 [补注1](#note-context-1)



<a id="context-2"></a>



### 篇末“悼公四年”及智伯败亡，是后事而非本年。



本年工作本末段转到鲁悼公四年的晋围郑，再讲赵襄子与智伯之间结怨，最后把线索延伸到智伯败亡。本项目把这一整段作为《左传》篇末后事保留在这里，不列入哀公二十七年的事件数量，也不提前把三家灭智写成前468年发生。 [补注2](#note-context-2)

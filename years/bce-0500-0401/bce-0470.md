## 本年纪事

<a id="event-1"></a>

1. **卫国多家合力逐辄，卫出公辗转求援于越。**

五月，卫侯辄与褚师比因宴席礼仪争执，此前夺邑、夺职、长期役使工匠也积下怨恨。褚师、公孙、公文、司寇、司徒等人联合拳弥起兵。拳弥劝卫侯暂避，辄最后到城鉏，希望借越国力量回国。他依靠祝史挥侵扰卫境，又让挥赴越求兵。 [1](#note-1)

<a id="event-2"></a>

2. **哀公从越归来，五梧宴会上与卿大夫争言。**

六月，哀公从越国返回，季康子、孟武伯到五梧迎接。孟武伯以“何肥也”讥讽为公驾车的郭重，季康子让孟武伯罚酒，哀公则借“食言多”反讥。宴席不欢而散，国君与大夫的隔阂加深。 [2](#note-2)

<a id="event-3"></a>
<a id="sj015-0470-comet"></a>

3. **天空出现彗星。** 本条没有可供确定月份和持续时间的记载。[3](#note-3)

<a id="event-4"></a>
<a id="sj015-0470-ying"></a>

4. **王子英出奔秦国。** 他离开楚国后投向秦国；为何出走、是否带有部众，以及秦国怎样安置他，尚无具体经过可述。[4](#note-4)

### [[1]](#note-1) 卫国多家合力逐辄，卫出公辗转求援于越。

**《左传》·哀公二十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/dac36d55ba97f526532c06d8bc2a005583bdb849/working-texts/zuozhuan-punctuated-years/years/bce-0470.md#L13-L13)

> 二十五年夏五月庚辰，卫侯出奔宋。卫侯为灵台于藉圃，与诸大夫饮酒焉。褚师声子袜而登席。公怒。辞曰：“臣有疾，异于人。若见之，君将之。是以不敢。”公愈怒。大夫辞之，不可。褚师出，公其手曰：“必断而足。”闻之，褚师与司寇亥乘曰：“今日幸而后亡。”公之入也，夺南氏邑，而夺司寇亥政。公使侍人纳公文懿子之车于池。

**《左传》·哀公二十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/dac36d55ba97f526532c06d8bc2a005583bdb849/working-texts/zuozhuan-punctuated-years/years/bce-0470.md#L15-L15)

> 初，卫人翦夏丁氏，以其帑赐彭封弥子。弥子饮公酒，纳夏戊之女，嬖，以为夫人。其弟期，大叔疾之从孙甥也，少畜于公，以为司徒。夫人宠衰，期得罪。公使三匠久。公使优狡盟拳弥，而甚近信之。故褚师比、公孙弥牟、公文要、司寇亥、司徒期因三匠与拳弥以作乱，皆执利兵，无者执斤。使拳弥入于公宫，而自大子疾之宫噪以攻公。鄄子士请御之。弥援其手曰：“子则勇矣，将若君何？不见先君乎？君何所不逞欲？且君尝在外矣，岂必不反。当今不可，众怒难犯，休而易间也。”乃出。将適蒲，弥曰：“晋无信，不可。”将適鄄，弥曰：“齐、晋争我，不可。”将適泠，弥曰：“鲁不足与，请適城鉏以鉤越，越有君。”乃適城鉏。弥曰：“卫盗不可知也，请速，自我始。”乃载宝以归。公为支离之卒，因祝史挥以侵卫。卫人病之。懿子知之，见子之，请逐挥。文子曰：“无罪。”懿子曰：“彼好专利而妄。夫见君之入也，将先道焉。若逐之，必出于南门而適君所。夫越新得诸侯，将必请师焉。”挥在朝，使吏遣诸其室。挥出信，弗内。五日，乃馆诸外里。遂有宠，使如越请师。

**说明：** 这是辄复位后再被逐，不是其父蒯聩再度遇害。席上穿袜只是导火线之一，不把复杂起事全归于一次饮酒争执。长段中的婚姻与赐邑是此前积怨。


<a id="note-2"></a>

### [[2]](#note-2) 哀公从越归来，五梧宴会上与卿大夫争言。

**《左传》·哀公二十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/dac36d55ba97f526532c06d8bc2a005583bdb849/working-texts/zuozhuan-punctuated-years/years/bce-0470.md#L17-L17)

> 六月，公至自越。季康子、孟武伯逆于五梧。郭重仆，见二子曰：“恶言多矣，君请尽之。”公宴于五梧。武伯为祝，恶郭重，曰：“何肥也！”季孙曰：“请饮彘也。以鲁国之密迩仇雠，臣是以不获从君，克免于大行，又谓重也肥。”公曰：“是食言多矣，能无肥乎？”饮酒不乐，公与大夫始有恶。

**说明：** “肥”“食言”是原文双关争语，不据之推断郭重健康状况；也不把这场不和直接写成已经发动的逐君兵变。

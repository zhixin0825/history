# 公元前471年（鲁哀公二十四年）

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **鲁军随晋攻齐，取得廪丘后撤回。** 四月，晋国向鲁求兵，借臧氏先人从军的往例，请臧氏参战。臧石率鲁军会合晋军，取得廪丘。军中准备继续推进，莱章反对再冒进，晋军遂回，并给臧石牛牲、就接待不周致歉。 [[1]](#note-1)

<a id="event-2"></a>

2. **越国再拘邾君，改立公子何。** 越人再次拘捕邾君益，带往越国，另立公子何。邾国内部与外部干预相互纠缠，君位再度更换。 [[2]](#note-2)

<a id="event-3"></a>

3. **哀公立公子荆之母为夫人，并立荆为太子。** 哀公想立宠爱的公子荆之母为夫人，命宗人衅夏献出仪礼。衅夏回答，迎娶夫人的旧礼虽有，直接将妾升为夫人却没有对应旧例。哀公仍然实行，并立荆为太子，国内由此出现不满。 [[3]](#note-3)

<a id="event-4"></a>

4. **哀公赴越，越方的婚姻、赐地安排受阻。** 闰月，哀公到越国，得到越太子適郢支持，越方准备与他结亲并给更多土地。公孙有山把消息告给季孙，季孙担忧，通过太宰嚭行贿，使这项安排停止。 [[4]](#note-4)

<a id="sj015-0471-qinwestern"></a>

<a id="event-5"></a>

5. **义渠向秦送财物，绵诸向秦求援。** 秦厉共公六年，义渠有人前来送财物，绵诸则请求秦国援助。两条消息只证明来往与请求，不能推断秦已实际出兵。 [[5]](#note-5)

<a id="event-6"></a>
<a id="sj015-0471-cai"></a>

6. **蔡国开始按声侯产元年计事。** 声侯是成侯之子，父亲去世及君位承接见[前472年](bce-0472.md#sj015-0472-cai)；本年只是新君纪年的开始。 [[6]](#note-6)

<a id="sj036-qi-min-killed-event"></a>

7. **杞湣公被弟弟阏路杀死。** 湣公维被弟弟阏路杀死，阏路夺取君位，为哀公。这次变乱暂系本年，翌年起哀公元年。 [[7]](#sj036-qi-min-killed-note)

### 1. 鲁军随晋攻齐，取得廪丘后撤回

[返回正文第1条](#event-1)

> 二十四年夏四月，晋侯将伐齐，使来乞师曰：“昔臧文仲以楚师伐齐，取穀。宣叔以晋师伐齐，取汶阳。寡君欲徼福于周公，愿乞灵于臧氏。”臧石帅师会之，取廪丘。军吏令缮，将进。莱章曰：“君卑政暴，往岁克敌，今又胜都。天奉多矣，又焉能进，是躗言也。役将班矣！”晋师乃还，饩臧石牛。大史谢之曰：“以寡君之在行，牢礼不度，敢展谢之。”

### 3. 哀公立公子荆之母为夫人，并立荆为太子

[返回正文第3条](#event-3)

> 公子荆之母嬖，将以为夫人，使宗人衅夏献其礼。对曰：“无之。”公怒曰：“女为宗司，立夫人，国之大礼也，何故无之？”对曰：“周公及武公娶于薛，孝、惠娶于商，自桓以下娶于齐，此礼也则有。若以妾为夫人，则固无其礼也。”公卒立之，而以荆为大子。国人始恶之。

<a id="1note-1-鲁军随晋攻齐取得廪丘后撤回"></a>
#### [[1]](#note-1) 鲁军随晋攻齐，取得廪丘后撤回。

**《左传》·哀公二十四年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0471.md#all-20261109-t001)

> 二十四年夏四月，晋侯将伐齐，使来乞师曰：“昔臧文仲以楚师伐齐，取穀。宣叔以晋师伐齐，取汶阳。寡君欲徼福于周公，愿乞灵于臧氏。”臧石帅师会之，取廪丘。军吏令缮，将进。莱章曰：“君卑政暴，往岁克敌，今又胜都。天奉多矣，又焉能进，是躗言也。役将班矣！”晋师乃还，饩臧石牛。大史谢之曰：“以寡君之在行，牢礼不度，敢展谢之。”

**说明：** 臧文仲、宣叔的旧役只是求援辞中援引，不再计本年。取得廪丘不等于晋已占领齐都。




<a id="2note-2-越国再拘邾君改立公子何"></a>
#### [[2]](#note-2) 越国再拘邾君，改立公子何。

**《左传》·哀公二十四年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0471.md#all-20261109-t002)

> 邾子又无道，越人执之以归，而立公子何。何亦无道。

**说明：** 传文以两人“无道”概括，并未提供本条全部具体罪行；正文不自添审判和杀戮细节。




<a id="3note-3-哀公立公子荆之母为夫人并立荆为太子"></a>
#### [[3]](#note-3) 哀公立公子荆之母为夫人，并立荆为太子。

**《左传》·哀公二十四年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0471.md#all-20261109-t003)

> 公子荆之母嬖，将以为夫人，使宗人衅夏献其礼。对曰：“无之。”公怒曰：“女为宗司，立夫人，国之大礼也，何故无之？”对曰：“周公及武公娶于薛，孝、惠娶于商，自桓以下娶于齐，此礼也则有。若以妾为夫人，则固无其礼也。”公卒立之，而以荆为大子。国人始恶之。

**说明：** 衅夏的答辞呈现当时的礼制依据，不当作适用于今天的婚姻规范。后来的悼公宁与本条太子荆不因继位顺序而强说是同名一人。




<a id="4note-4-哀公赴越越方的婚姻赐地安排受阻"></a>
#### [[4]](#note-4) 哀公赴越，越方的婚姻、赐地安排受阻。

**《左传》·哀公二十四年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0471.md#all-20261109-t004)

> 闰月，公如越，得大子適郢，将妻公，而多与之地。公孙有山使告于季孙。季孙惧，使因大宰嚭而纳赂焉，乃止。

**说明：** 原文只写安排及受阻，不把婚姻、领地许诺写成已经交割。“太宰嚭”在吴亡后的出现涉及不同史籍的人物终局传统，本页保留原称，未据后世处死伯嚭的说法静默删改本条。




<a id="5note-5-秦与义渠绵诸的两项往来"></a>
#### [[5]](#note-5) 秦与义渠、绵诸的两项往来

**《史记》卷015《六国年表》·前471年秦栏** · [逐栏原表](../../sources/摘录/史记-卷015-六国年表.md#y0471)

> 六。義渠來賂。綿諸乞援。

**说明：** 「六」为厉共公六年；「义渠来赂」和「绵诸乞援」分属不同对象与行动。原表没有交代义渠送的财物、绵诸所遭威胁及秦是否出兵；这些后续事实都不能补造。

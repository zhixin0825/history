<a id="本年纪事"></a>
<a id="event-1"></a>

1. **宋景曹去世，季康子派冉求吊葬。** 春季，宋景曹去世。季康子因鲁国有社稷之事不能亲往，派冉求吊丧、送葬，并以亲属关系致辞，赠送先人所留的马匹作仪仗之用。 [[1]](#note-1)

<a id="event-2"></a>

2. **晋军在犁丘击败齐军，俘获颜庚。** 六月，荀瑶率晋军攻齐，高无率齐军抵御。荀瑶以齐占英丘为出兵理由，表示已经奉君命并经宗庙卜问，不必临战再卜。壬辰，双方战于犁丘，齐军败，荀瑶亲自俘获颜庚。 [[2]](#note-2)

<a id="event-3"></a>

3. **鲁国遣叔青赴越，越国回聘。** 八月，叔青出使越国。越国随后派诸鞅来鲁，答复此次聘问，双方开始相互派遣使者。 [[3]](#note-3)

<a id="sj015-0472-chuqin"></a>

<a id="event-4"></a>

4. **楚人向秦送来财物。** 秦厉共公五年，楚人向秦送来财物。 [[4]](#note-4)

<a id="event-5"></a>
<a id="sj015-0472-cai"></a>

5. **蔡成侯去世，儿子产继承君位，是为蔡声侯。** 蔡国换了一位君主，仍继续存在；这不是早在春秋中期便已去世的蔡景侯再次死亡。 [[5]](#note-5)

### 2. 晋军在犁丘击败齐军，俘获颜庚

[返回正文第2条](#event-2)

> 夏六月，晋荀瑶伐齐。高无帅师御之。知伯视齐师，马骇，遂驱之，曰：“齐人知余旗，其谓余畏而反也。”及垒而还。将战，长武子请卜。知伯曰：“君告于天子，而卜之以守龟于宗祧，吉矣。吾又何卜焉？且齐人取我英丘，君命瑶，非敢燿武也，治英丘也。以辞伐罪足矣，何必卜？”壬辰，战于犁丘。齐师败绩，知伯亲禽颜庚。

<a id="1note-1-宋景曹去世季康子派冉求吊葬"></a>
#### [[1]](#note-1) 宋景曹去世，季康子派冉求吊葬。

**《左传》·哀公二十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0472.md#all-20261109-t001)

> 二十三年春，宋景曹卒。季康子使冉有吊，且送葬，曰：“敝邑有社稷之事，使肥与有职竞焉，是以不得助执绋，使求从舆人。曰，以肥之得备弥甥也，有不腆先人之产马，使求荐诸夫人之宰，其可以称旌繁乎？”

**说明：** 景曹不是宋景公，原文称夫人。这里保留她的称谓与季康子的致辞，不把同一“景”字误合成宋君本年去世。




<a id="2note-2-晋军在犁丘击败齐军俘获颜庚"></a>
#### [[2]](#note-2) 晋军在犁丘击败齐军，俘获颜庚。

**《左传》·哀公二十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0472.md#all-20261109-t002)

> 夏六月，晋荀瑶伐齐。高无帅师御之。知伯视齐师，马骇，遂驱之，曰：“齐人知余旗，其谓余畏而反也。”及垒而还。将战，长武子请卜。知伯曰：“君告于天子，而卜之以守龟于宗祧，吉矣。吾又何卜焉？且齐人取我英丘，君命瑶，非敢燿武也，治英丘也。以辞伐罪足矣，何必卜？”壬辰，战于犁丘。齐师败绩，知伯亲禽颜庚。

**说明：** 荀瑶又称知伯、智伯。原文关于马惊后前驱的细节保留在注中，不把其自述勇怯当作项目评定。




<a id="3note-3-鲁国遣叔青赴越越国回聘"></a>
#### [[3]](#note-3) 鲁国遣叔青赴越，越国回聘。

**《左传》·哀公二十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0472.md#all-20261109-t003)

> 秋八月，叔青如越，始使越也。越诸鞅来聘，报叔青也。

**说明：** 前474年为越始来，本年为鲁始使越，两个“始”分别有不同主体。




<a id="4note-4-秦厉共公五年楚人来赂"></a>
#### [[4]](#note-4) 秦厉共公五年楚人来赂

**《史记》卷015《六国年表》·前472年秦栏** · [逐栏原表](../../sources/摘录/史记-卷015-六国年表.md#y0472)

> 五。楚人來賂。

**说明：** 「五」承前指秦厉共公第五年；「来赂」的行为主体是楚人、接受地是秦国。只据表文记一次交往，不擅自说秦楚结盟或归附。本年[荀瑶伐齐](#event-2)由经传另记，是另一事件。



<a id="5note-5-蔡成侯之死年表景字的校勘"></a>
#### [[5]](#note-5) 蔡成侯之死：年表「景」字的校勘

[卷015本年楚栏](../../sources/摘录/史记-卷015-六国年表.md#y0472)原作「蔡景侯卒」。[《索隐》本行](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7015.md#ref-c66d68484d056c)明说「景」字误，应作「成侯」；[《管蔡世家》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7035.md#ref-b2ef2a83d98890)记「十九年，成侯卒，子聲侯產立」。本页据明确校勘及君系采用成侯，原表转录不改字。下一行前471年声侯元年只接新君计年，不再记一次父死子立；死亡月日与原因均未补造。

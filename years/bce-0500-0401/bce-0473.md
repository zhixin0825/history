# 公元前473年（鲁哀公二十二年）

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **越国送邾君益回国，太子革逃越。** 四月，长期在齐的邾隐公益逃到越国，控诉吴人曾拘父立子。越国将他送回邾，太子革转而逃往越国。 [[1]](#note-1)

<a id="event-2"></a>

2. **越国灭吴，夫差拒绝安置于甬东而自尽。** 十一月丁卯，长期受围的吴国灭亡。夫差退守姑苏，派公孙雄袒胸膝行求和，借当年会稽赦越请求宽免。勾践一度不忍，范蠡劝他不要放弃多年准备，亲自催兵，拒绝使者。越仍愿把夫差安置到甬东，使统领百家；夫差以自己已老、不能再侍奉他君为由拒绝，自缢而死。他死前表示无颜见伍员，以帛遮面；越人为他办理葬事。 [[2]](#note-2)

<a id="sj041-event-3"></a>

3. **灭吴以后，勾践渡淮会诸侯，贡周受伯命。** 越军北渡淮水，与齐、晋等诸侯会于徐州，向周贡物，受周元王赐胙、命为伯。勾践南返时，把淮上部分土地交给楚，将吴侵宋地还宋，又将泗水以东方百里给鲁；越由此在江淮东部取得霸主地位。会盟和分还土地是灭吴后的阶段，不能全等同于吴亡当日。功成以后范蠡离越、文种遇害及范蠡在齐、陶的后续，见[春秋末与战国初的未定年正文](未定年-春秋末与战国初.md)，不把这些多年经历都定为前473年。 [[3]](#sj041-note-3)

**[所核固定版本](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E9%AD%AF%E5%91%A8%E5%85%AC%E4%B8%96%E5%AE%B6.md#ref-fec4c013e86042)**

> 二十二年，越王句踐滅吳王夫差。

<a id="sj066-cite-044"></a>

**[《史记·伍子胥列传》P020](../../sources/摘录/史记-卷066-伍子胥列传.md#p020)**

> 吳王既誅伍子胥，遂伐齊。齊鮑氏殺其君悼公而立陽生。吳王欲討其賊，不勝而去。其後二年，吳王召魯衛之君會之橐皋。其明年，因北大會諸侯於黃池，以令周室。越王句踐襲殺吳太子，破吳兵。吳王聞之，乃歸，使使厚幣與越平。後九年，越王句踐遂滅吳，殺王夫差；而誅太宰嚭，以不忠於其君，而外受重賂，與己比周也。

**本卷说明：** 本篇“杀王夫差”与经传自缢、越世家自杀不同，正文沿较详的拒甬东而自尽。伯嚭被诛归因本篇不忠、外受贿、比周，但《左传》前471尚有太宰嚭活动，未能排除文本或人物问题，故不在正文定其本年必死，也不凭冲突擅造第二个伯嚭。

> 平公八年，越滅吳。

<!-- /sj032-supplement -->

<a id="sj041-cite-015"></a>

**[《史记·越王勾践世家》P011](../../sources/摘录/史记-卷041-越王勾践世家.md#p011)**

> 吳師敗，越遂復棲吳王於姑蘇之山。吳王使公孫雄肉袒膝行而前，請成越王曰：「孤臣夫差敢布腹心，異日嘗得罪於會稽，夫差不敢逆命，得與君王成以歸。今君王舉玉趾而誅孤臣，孤臣惟命是聽，意者亦欲如會稽之赦孤臣之罪乎？」句踐不忍，欲許之。范蠡曰：「會稽之事，天以越賜吳，吳不取。今天以吳賜越，越其可逆天乎？且夫君王蚤朝晏罷，非為吳邪？謀之二十二年，一旦而棄之，可乎？且夫天與弗取，反受其咎。『伐柯者其則不遠』，君忘會稽之蚯？」句踐曰：「吾欲聽子言，吾不忍其使者。」范蠡乃鼓進兵，曰：「王已屬政於執事，使者去，不者且得罪。」吳使者泣而去。句踐憐之，乃使人謂吳王曰：「吾置王甬東，君百家。」吳王謝曰：「吾老矣，不能事君王！」遂自殺。乃蔽其面，曰：「吾無面以見子胥也！」越王乃葬吳王而誅太宰嚭。

**本卷说明：** “谋之二十二年”可从前494会稽至前473包首尾计，不能当作勾践在位总数。原TXT“会稽之蚯”明显脱讹，三家注p10为“会稽之厄乎”，释义据完整句。伯嚭被杀与《左传》前471仍记太宰嚭干预越鲁婚事有冲突，不先写成死后复生，参本卷考证。

<a id="sj041-note-3"></a>

### 3. 灭吴以后，勾践渡淮会诸侯，贡周受伯命

[返回正文第3条](#sj041-event-3)

<a id="sj041-cite-016"></a>

**[《史记·越王勾践世家》P012](../../sources/摘录/史记-卷041-越王勾践世家.md#p012)**

> 句踐已平吳，乃以兵北渡淮，與齊、晉諸侯會於徐州，致貢於周。周元王使人賜句踐胙，命為伯。句踐已去，渡淮南，以淮上地與楚，歸吳所侵宋地於宋，與魯泗東方百里。當是時，越兵橫行於江、淮東，諸侯畢賀，號稱霸王。

**本卷说明：** 以灭吴后的相对先后暂附本年，不把“周元王赐胙”另当成勾践初次即位称王。徐州会盟、土地归还均未给独立日月；楚方面“越不能正江淮北、楚东侵”是另一叙述角度，不能把赠地与后来侵取说成完全同一次交割。

<a id="sj041-cite-017"></a>

**[《史记·越王勾践世家》P027](../../sources/摘录/史记-卷041-越王勾践世家.md#p027)**

> 太史公曰：禹之功大矣，漸九川，定九州，至于今諸夏艾安。及苗裔句踐，苦身焦思，終滅彊吳，北觀兵中國，以尊周室，號稱霸王。句踐可不謂賢哉！蓋有禹之遺烈焉。范蠡三遷皆有榮名，名垂後世。臣主若此，欲毋顯得乎！

**本卷说明：** 此为汉代司马迁篇末史论，评论禹、勾践与范蠡，保留作者层次；不计作前473年的新增历史行动。

<a id="sj067-cite-163"></a>

**[《史记·仲尼弟子列传》P046](../../sources/摘录/史记-卷067-仲尼弟子列传.md#p046)**

> 破吳三年，東向而霸。

**本卷说明：** 本篇三年后东向而霸仅作相对异说；现有主线把徐州会盟、周赐伯命等作为灭吴后阶段，不据三年另造前470年的确年称霸事件。

> 吳王既誅伍子胥，遂伐齊。齊鮑氏殺其君悼公而立陽生。吳王欲討其賊，不勝而去。其後二年，吳王召魯衛之君會之橐皋。其明年，因北大會諸侯於黃池，以令周室。越王句踐襲殺吳太子，破吳兵。吳王聞之，乃歸，使使厚幣與越平。後九年，越王句踐遂滅吳，殺王夫差；而誅太宰嚭，以不忠於其君，而外受重賂，與己比周也。

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **诸侯在廪丘商议援郑伐晋，后来撤军。** 春季齐国来召会，夏季诸侯在廪丘会合，为郑国商议伐晋。郑方后来辞谢，秋季各军返回，没有发展成这次计划中的大规模联合进攻。 [[1]](#note-1)

<a id="event-2"></a>

2. **吴公子庆忌回国求平越，遭吴人杀害。** 公子庆忌反复劝吴王改弦，未被接受，离吴居艾，后来到楚。听闻越军将攻吴，他于冬季请求回国，想通过改变国内用人、与越议和解决危机，却被吴人杀死。 [[2]](#note-2)

<a id="event-3"></a>

3. **越军围吴，赵无恤派人致意但未能援救。** 十一月，越军围吴。赵无恤想到父亲在黄池与吴所订盟约，又自知晋无力出救，减少饮食以示哀伤。家臣楚隆先到越营，请准进入吴国探问，再向夫差说明赵氏未能援救的处境。夫差答礼、赠珠，并询问史黯行事之道。 [[3]](#note-3)

<a id="event-4"></a>

4. **蜀人向秦送来财物。** 秦厉共公二年，蜀人向秦送来财物。 [[4]](#note-4)

<a id="sj015-0475-jinding"></a>

<a id="event-5"></a>

5. **晋定公去世，晋出公继承君位。** 晋定公午在位三十七年去世，儿子凿继位，是为晋出公，次年为出公元年。 [[5]](#note-5)

### 3. 越军围吴，赵无恤派人致意但未能援救

[返回正文第3条](#event-3)

> 十一月，越围吴，赵孟降于丧食。楚隆曰：“三年之丧，亲暱之极也。主又降之，无乃有故乎？”赵孟曰：“黄池之役，先主与吴王有质，曰：‘好恶同之。’今越围吴，嗣子不废旧业而敌之，非晋之所能及也，吾是以为降。”楚隆曰：“若使吴王知之，若何？”赵孟曰：“可乎？”隆曰：“请尝之。”乃往。先造于越军，曰：“吴犯间上国多矣，闻君亲讨焉，诸夏之人莫不欣喜，唯恐君志之不从。请入视之。”许之。告于吴王曰：“寡君之老无恤，使陪臣隆敢展谢其不共。黄池之役，君之先臣志父得承齐盟，曰：‘好恶同之。’今君在难，无恤不敢惮劳。非晋国之所能及也，使陪臣敢展布之。”王拜稽首曰：“寡人不佞，不能事越，以为大夫忧。拜命之辱。”与之一箪珠，使问赵孟曰：“句践将生忧寡人，寡人死之不得矣。”王曰：“溺人必笑，吾将有问也。史黯何以得为君子？”对曰：“黯也进不见恶，退无谤言。”王曰：“宜哉。”

**说明：** 此处赵孟是赵襄子无恤，不是其父赵鞅。使者慰问不等于晋军驰援。吴国尚在围困中，不能提前到本年灭亡。

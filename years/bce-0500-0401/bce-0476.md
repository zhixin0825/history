## 本年纪事

<a id="event-1"></a>

1. **越国侵楚以迷惑吴国，楚追军未能赶上。**

春季，越军侵楚，意在使吴误判其行动方向。夏季，楚公子庆、公孙宽追到冥地，没有追及越军便返回。 [1](#note-1)

<a id="event-2"></a>

2. **楚军进攻东夷，双方在敖盟誓。**

秋季，沈诸梁率楚军攻东夷，三夷的男女与楚军在敖地盟誓。 [2](#note-2)

<a id="event-3"></a>

3. **叔青因周敬王丧事赴京师。**

冬季，鲁国叔青到周京师，办理与敬王去世有关的丧事。 [3](#note-3)



<a id="sj015-0476-qin"></a>

4. **秦厉共公开始采用元年纪年。** 秦悼公之后，由其子厉共公继位；《六国年表》把本年列为厉共公元年。这里是编年表的起算年，不据此额外断言悼公恰好死于本年。 [4](#note-4)

<a id="note-1"></a>

### [[1]](#note-1) 越国侵楚以迷惑吴国，楚追军未能赶上。

**《左传》·哀公十九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/dac36d55ba97f526532c06d8bc2a005583bdb849/working-texts/zuozhuan-punctuated-years/years/bce-0476.md#L13-L13)

> 十九年春，越人侵楚，以误吴也。夏，楚公子庆、公孙宽追越师至冥，不及，乃还。

**说明：** “以误吴也”是传文明示的目的；不据此推算越军具体行程和吴国全部情报反应。


<a id="note-2"></a>

### [[2]](#note-2) 楚军进攻东夷，双方在敖盟誓。

**《左传》·哀公十九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/dac36d55ba97f526532c06d8bc2a005583bdb849/working-texts/zuozhuan-punctuated-years/years/bce-0476.md#L15-L15)

> 秋，楚沈诸梁伐东夷，三夷男女及楚师盟于敖。

**说明：** 三夷具体族群、地理范围未在本批独立核定，保留原称，不附会现代民族划分。


<a id="note-3"></a>

### [[3]](#note-3) 叔青因周敬王丧事赴京师。

**《左传》·哀公十九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/dac36d55ba97f526532c06d8bc2a005583bdb849/working-texts/zuozhuan-punctuated-years/years/bce-0476.md#L17-L17)

> 冬，叔青如京师，敬王崩故也。

**《春秋左传正义》卷六十·孔颖达疏：使者赴吊不足确定敬王卒年** · [所核固定版本](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E5%82%B3%E6%AD%A3%E7%BE%A9-%E5%8D%B760.md#ref-d6a8cc46e94052)

> 此「叔青如京師」，自為敬王崩。未知敬王何年崩也。

**说明：** 这条明确的是使者本年赴京，不足以单独证明敬王也正死于本年。《左传正义》疏即指出未知敬王何年崩，故不强列前476年为唯一卒年。

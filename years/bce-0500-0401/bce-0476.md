<a id="本年纪事"></a>
<a id="event-1"></a>

1. **越国侵楚以迷惑吴国，楚追军未能赶上。** 春季，越军侵楚，意在使吴误判其行动方向。夏季，楚公子庆、公孙宽追到冥地，没有追及越军便返回。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚军进攻东夷，双方在敖盟誓。** 秋季，沈诸梁率楚军攻东夷，三夷的男女与楚军在敖地盟誓。 [[2]](#note-2)

<a id="event-3"></a>

3. **叔青因周敬王丧事赴京师。** 冬季，鲁国叔青到周京师，办理与敬王去世有关的丧事。 [[3]](#note-3)

<a id="sj015-0476-qin"></a>

<a id="event-4"></a>

4. **秦厉共公开始采用元年纪年。** 秦悼公之后，由其子厉共公继位；《六国年表》把本年列为厉共公元年。这里是编年表的起算年，不据此额外断言悼公恰好死于本年。 [[4]](#note-4)

<a id="本年其他已整理纪事"></a>

<a id="event-5"></a>

5. **《六国年表》记周元王元年。** 《周本纪》记元王仁是周敬王之子，承接父亲的王位。敬王卒年与元王承位日期仍有异说。 [卷四互见与归年](#sj004-476-1) [[5]](#note-5)

<a id="sj-031-L2992-01"></a>
<a id="1-越军再次进攻吴国"></a>

<a id="event-6"></a>

6. **越军再次进攻吴国。** **时间：夫差二十年／鲁哀公十九年** · 事件 [[6]](#note-6)

   《吴世家》记越再伐吴，没有在这里详述战斗过程。


<a id="sj040-wu-chu-attack-event"></a>

7. **吴国在与齐晋争强的阶段，仍有向楚用兵的记载。** 夫差的声势曾及齐晋，惠王十三年又来攻楚；这一条按楚君年暂系本年，与经传同年越侵楚、楚攻东夷分别保存。 [[7]](#sj040-wu-chu-attack-note)

## 归年与考证

原文逐段保存。回叙、后事、占候与人物判断依同号说明区分。原工作本的缺字、网页残标不静默改写；明确共用一段的条目列出所有去向。



<a id="1note-1-越国侵楚以迷惑吴国楚追军未能赶上"></a>
#### [[1]](#note-1) 越国侵楚以迷惑吴国，楚追军未能赶上。

**《左传》·哀公十九年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0476.md#all-20261109-t001)

> 十九年春，越人侵楚，以误吴也。夏，楚公子庆、公孙宽追越师至冥，不及，乃还。

**说明：** “以误吴也”是传文明示的目的；不据此推算越军具体行程和吴国全部情报反应。




<a id="2note-2-楚军进攻东夷双方在敖盟誓"></a>
#### [[2]](#note-2) 楚军进攻东夷，双方在敖盟誓。

**《左传》·哀公十九年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0476.md#all-20261109-t002)

> 秋，楚沈诸梁伐东夷，三夷男女及楚师盟于敖。

**说明：** 三夷具体族群、地理范围未在本批独立核定，保留原称，不附会现代民族划分。




<a id="3note-3-叔青因周敬王丧事赴京师"></a>
#### [[3]](#note-3) 叔青因周敬王丧事赴京师。

**《左传》·哀公十九年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0476.md#all-20261109-t003)

> 冬，叔青如京师，敬王崩故也。

**《春秋左传正义》卷六十·孔颖达疏：使者赴吊不足确定敬王卒年** · [所核固定版本](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E5%82%B3%E6%AD%A3%E7%BE%A9-%E5%8D%B760.md#ref-d6a8cc46e94052)

> 此「叔青如京師」，自為敬王崩。未知敬王何年崩也。

**说明：** 这条明确的是使者本年赴京，不足以单独证明敬王也正死于本年。《左传正义》疏即指出未知敬王何年崩，故不强列前476年为唯一卒年。




<a id="4note-4-秦厉共公元年"></a>
#### [[4]](#note-4) 秦厉共公元年

**《史记》卷015《六国年表》·前476年秦栏** · [逐栏原表](../../sources/摘录/史记-卷015-六国年表.md#y0476)

> 厲共公元年。

**《史记》卷005《秦本纪》·悼公与厉共公继承** · [核对原文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7005.md#ref-a85a10d813d410)

> 秦悼公立十四年卒，子厲共公立。

**说明：** 年表给出本年元年，《秦本纪》给出父子继承，但不独立标出悼公死亡的公元年；两条并读，不把元年自动当成先君本年死亡。次年蜀人来赂见[前475年旧页](bce-0475.md#sj005-137-note)，不在此重复归年。

##### 敬王之丧与元王仁继位｜卷四互见

[《周本纪》P060](../../sources/摘录/史记-卷004-周本纪.md#p060)作敬王四十二年崩，按所用王年换算为前478；[《十二诸侯年表》前477年周栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0477)作四十三年崩。[本页第3条](#note-3)明确的是前476年叔青赴丧，孔颖达疏也说敬王确切卒年未知。本年另据《六国年表》写元王元年，承位时点随本纪异年保留。

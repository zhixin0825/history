<a id="本年纪事"></a>
<a id="event-1"></a>

1. **宋国杀皇瑗，后来恢复皇氏。** 春季，宋国杀皇瑗。宋公后来得知事情实情，恢复皇氏的族属安排，任皇缓为右师。 [[1]](#note-1)

<a id="event-2"></a>

2. **巴军围鄾，楚军将其击败。** 巴人攻楚，围鄾。楚王派公孙宁等率军迎战，三月在鄾击败巴军，封子国于析。出兵前是否再卜的讨论，围绕既有人选与能力展开。 [[2]](#note-2)

<a id="event-3"></a>

3. **石圃逐走卫君起，辄返回卫国。** 夏季，石圃驱逐卫君起，起逃往齐国。卫侯辄从齐返回，逐走石圃，恢复石魋与大叔遗的地位。 [[3]](#note-3)

<a id="event-4"></a>

4. **秦悼公去世，厉共公继位。** 本纪记悼公在位十四年，随后其子厉共公接立。前后数次君位与经传有年差，具体死亡仍按各条分别核对，不以一个累计式强行改齐。 [[4]](#note-4)

<a id="sj014-audit-0477-jing-note"></a>
<a id="卷014补核敬王卒年的不同传统"></a>
#### 卷014补核｜敬王卒年的不同传统

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0477)。周栏“四十三敬王崩”对应前477；《周本纪》另写四十二年卒，《左传》哀十九（前476）只记叔青赴京为敬王之丧，见[前476年第3条及注](bce-0476.md#note-3)。赴丧不等于当年才死，不能据此把三种在位数强行统一。[维基百科周敬王](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E7%BB%B4%E5%9F%BA%E5%8F%82%E8%80%83/%E5%91%A8%E6%95%AC%E7%8E%8B-84033437.md#%E6%A0%B8%E5%AF%B9%E8%8C%83%E5%9B%B4)同时列常用前476年和42／43／44年的材料。此处记录年表所系卒年，不在前476再写一次确定死亡。

<a id="sj014-audit-0477-terminal-note"></a>
<a id="卷014补核末行后年总数不是本年诸君共同去世"></a>
#### 卷014补核｜末行后年总数不是本年诸君共同去世

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0477)。末行鲁“十八／二十七卒”、齐“四／二十五卒”、晋“三十五／三十七卒”、楚“十二／五十七卒”、宋“四十／六十四卒”、蔡“十四／十九卒”、郑“二十四／三十八卒”、燕“十六／二十八卒”、吴“十九／二十三卒”，前数为表末年次，后数是表外终局的在位总数。不是九国国君都在前477或前476去世；不把跨年终局拆成一个伪造的前476年表行。各国后来的死亡应赴相应年页依独立史料核定，不能只以减法生成新事件。秦“十四卒”没有第二个更晚总数，和本页秦悼公死亡主述相接；卫君起元年、被逐及辄复入见第3条，陈、曹栏已空。

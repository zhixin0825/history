<a id="本年纪事"></a>
<a id="event-1"></a>

1. **太子疾借宴礼列罪，杀浑良夫。** 春季，卫侯新设虎幄，太子请求让浑良夫来参加初宴。良夫衣着、车马、执剑进食等被太子逐项指为过失，太子令将他牵出，以三罪为名杀死。 [[1]](#note-1)

<a id="event-2"></a>

2. **越军在笠泽击败吴军。** 三月，越攻吴，双方隔水列阵。勾践先让左右两翼在夜间交替鼓噪前进，引吴军分兵迎击，自己率中军悄悄渡水，突然攻击吴军中央，吴军大乱败退。吴国经过多年北上争强，军民已疲敝，越军由此进一步取得优势；围都直至灭国仍是此后几年的过程。 [[2]](#note-2)

<a id="event-3"></a>

<a id="event-6"></a>

3. **晋攻卫遇齐援，卫庄公被逐后死，卫屡易君。** 晋要求卫君赴会，随后攻卫，齐军救援使晋退兵。赵鞅以此前接待蒯聩的关系为由，要求卫君或太子来晋，卫方拒绝，还侮辱来使。六月，晋军围卫。齐国国观、陈瓘出兵来救，陈瓘向晋表明自己奉齐命不可退避，赵鞅以未卜与齐作战为由撤军。卫庄公被逐后短暂复入，最终遇害，君位数次更换。十月，晋军再攻卫，卫人逐庄公，与晋议和，立般师。十一月庄公从鄄回到卫国，般师离开。不久，石圃利用工匠、戎州人的怨恨起兵，庄公逃亡中跌伤，太子疾和公子青也受攻击。庄公躲进己氏家，想用璧换取性命，仍被杀。卫人再立般师。十二月齐军攻卫，又改立公子起，带走般师。 [[3]](#note-3)

<a id="event-4"></a>

4. **楚国七月灭陈，取其地设县。** 陈曾乘白公之乱侵楚，楚恢复后准备夺陈麦粮，议将后派武城尹出战。陈军失利，楚围城，七月己卯公孙朝灭陈；这次兼并在白公乱次年，不以本篇“是岁”将两事并年。 [[4]](#note-4)

    [卷四互见与归年](#sj004-478-1)

<a id="event-5"></a>

5. **楚国改变令尹人选。** 楚王与叶公为令尹人选占卜，先议子良，后来改卜子国并任用为令尹。 [[5]](#note-5)

<a id="event-7"></a>

6. **鲁、齐在蒙盟会，为礼仪先后发生争论。** 哀公与齐侯在蒙盟誓。齐侯稽首，鲁公只行拜礼，齐人不满，孟武伯则强调鲁公不应向诸侯行对天子的礼。会中孟武伯又询问执牛耳的旧例，决定自己承担。 [[6]](#note-7)

<a id="event-8"></a>

7. **宋国皇麇被捕，皇瑗逃晋后受召。** 皇瑗的儿子麇夺了兄长邑地赠友，兄长告发他想接纳流亡的桓氏。宋公查问时，相关大夫又有立嗣旧怨，没有为麇开脱，麇被捕。皇瑗逃往晋国，宋又把他召回。 [[7]](#note-8)

### 4. 楚国七月灭陈，取其地设县

[返回正文第4条](#event-4)

> 楚白公之乱，陈人恃其聚而侵楚。楚既宁，将取陈麦。楚子问帅于大师子穀与叶公诸梁。子穀曰：“右领差车与左史老，皆相令尹、司马以伐陈，其可使也。”子高曰：“率贱，民慢之，惧不用命焉。”子穀曰：“观丁父，鄀俘也，武王以为军率，是以克州，蓼，服随、唐，大启群蛮。彭仲爽，申俘也，文王以为令尹，实县申、息，朝陈、蔡，封畛于汝。唯其任也，何贱之有？”子高曰：“天命不謟。令尹有憾于陈，天若亡之，其必令尹之子是与，君盍舍焉？臣惧右领与左史有二俘之贱，而无其令德也。”王卜之，武城尹吉。使帅师取陈麦。陈人御之，败。遂围陈。

#### [[4]](#note-4) 楚国进攻陈国，七月灭陈。

> 楚白公之乱，陈人恃其聚而侵楚。楚既宁，将取陈麦。楚子问帅于大师子穀与叶公诸梁。子穀曰：“右领差车与左史老，皆相令尹、司马以伐陈，其可使也。”子高曰：“率贱，民慢之，惧不用命焉。”子穀曰：“观丁父，鄀俘也，武王以为军率，是以克州，蓼，服随、唐，大启群蛮。彭仲爽，申俘也，文王以为令尹，实县申、息，朝陈、蔡，封畛于汝。唯其任也，何贱之有？”子高曰：“天命不謟。令尹有憾于陈，天若亡之，其必令尹之子是与，君盍舍焉？臣惧右领与左史有二俘之贱，而无其令德也。”王卜之，武城尹吉。使帅师取陈麦。陈人御之，败。遂围陈。

**《左传》·哀公十七年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0478.md#all-20261109-t005)

> 秋七月己卯，楚公孙朝帅师灭陈。

**说明：** 观丁父、彭仲爽等由俘虏而被任用的故事，是选将讨论引用的旧例，不是本年新任官。此为陈最后被楚灭，不与昭公时灭陈后复国混同。

<a id="sj004-478-1"></a>
<a id="楚灭陈应与孔子之死分年卷四互见"></a>
##### 楚灭陈应与孔子之死分年｜卷四互见

[卷004 P059](../../sources/摘录/史记-卷004-周本纪.md#p059)。 《左传》哀公十七年记七月灭陈；不可因本纪同段就提前到前479，也不与楚在前598年的干预混成同一次灭陈。




<a id="5note-5-楚国改变令尹人选"></a>
#### [[5]](#note-5) 楚国改变令尹人选。

**《左传》·哀公十七年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0478.md#all-20261109-t006)

> 王与叶公枚卜子良以为令尹。沈尹朱曰：“吉，过于其志。”叶公曰：“王子而相国，过将何为？”他日，改卜子国而使为令尹。

**说明：** 原文记了卜问与改任，没有完整写出人事决策所有原因，不以吉凶直接解释政治成败。




<a id="6note-6-卫庄公被逐后短暂复入最终遇害君位数次更换"></a>
#### [[6]](#note-6) 卫庄公被逐后短暂复入，最终遇害，君位数次更换。

**《左传》·哀公十七年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0478.md#all-20261109-t007)

> 卫侯梦于北宫，见人登昆吾之观，被发北面而噪曰：“登此昆吾之虚，绵绵生之瓜。余为浑良夫，叫天无辜。”公亲筮之，胥弥赦占之，曰：“不害。”与之邑，置之，而逃奔宋。卫侯贞卜，其《繇》曰：“如鱼尾，衡流而方羊，裔焉大国，灭之将亡。阖门塞窦，乃自后逾。”

**《左传》·哀公十七年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0478.md#all-20261109-t008)

> 冬十月，晋复伐卫，入其郛。将入城，简子曰：“止。叔向有言曰，怙乱灭国者无后。”卫人出庄公而与晋平，晋立襄公之孙般师而还。十一月，卫侯自鄄入，般师出。

**《左传》·哀公十七年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0478.md#all-20261109-t009)

> 初，公登城以望，见戎州。问之，以告。公曰：“我，姬姓也，何戎之有焉？”翦之。公使匠久。公欲逐石圃，未及而难作。辛巳，石圃因匠氏攻公，公阖门而请，弗许。逾于北方而队，折股。戎州人攻之，大子疾、公子青逾从公。戎州人杀之。公入于戎州己氏。初，公自城上见己氏之妻发美，使髠之，以为吕姜髢。既入焉，而示之璧，曰：“活我，吾与女璧。”己氏曰：“杀女，璧其焉往？”遂杀之而取其璧。卫人复公孙般师而立之。十二月，齐人伐卫，卫人请平。立公子起，执般师以归，舍诸潞。

**说明：** 关于浑良夫的梦与卜辞是传文对结局的预叙，不作死因。庄公剪戎州、夺人妻发等为起事者旧怨；原文中的各轮逐立按顺序保留，不只说“卫庄公死，辄复位”，辄回国在次年。




<a id="7note-7-鲁齐在蒙盟会为礼仪先后发生争论"></a>
#### [[7]](#note-7) 鲁、齐在蒙盟会，为礼仪先后发生争论。

**《左传》·哀公十七年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0478.md#all-20261109-t010)

> 公会齐侯，盟于蒙，孟武伯相。齐侯稽首，公拜。齐人怒，武伯曰：“非天子，寡君无所稽首。”武伯问于高柴曰：“诸侯盟，谁执牛耳？”季羔曰：“鄫衍之役，吴公子姑曹；发阳之役，卫石魋。”武伯曰：“然则彘也。”

**说明：** 这是双方对于礼位的主张，不以项目口吻裁定某国天然高于另一国。




<a id="8note-8-宋国皇麇被捕皇瑗逃晋后受召"></a>
#### [[8]](#note-8) 宋国皇麇被捕，皇瑗逃晋后受召。

**《左传》·哀公十七年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0478.md#all-20261109-t011)

> 宋皇瑗之子麇，有友曰田丙，而夺其兄酁般邑以与之。酁般愠而行，告桓司马之臣子仪克。子仪克適宋，告夫人曰：“麇将纳桓氏。”公问诸子仲。初，子仲将以杞姒之子非我为子。麇曰：“必立伯也，是良材。”子仲怒，弗从。故对曰：“右师则老矣，不识麇也。”公执之。皇瑗奔晋，召之。

**说明：** 接纳桓氏是告发内容，原文不证明计划已经发动；皇瑗的死亡要到下一年再记。

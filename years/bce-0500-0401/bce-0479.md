## 本年概述

卫庄公遣使向周报告继位，先后出现臣族出奔及孔悝离卫。孔子卒，鲁哀公作诔，弟子为师服丧。楚国白公胜发动政变，杀子西、子期并劫持惠王；叶公入都反攻，惠王复位。

## 卫庄公告周与臣族去留

<a id="bce0479-event-1"></a>

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **卫国瞒成、褚师比出奔宋国，庄公向周室报告继位。** 春季，瞒成和褚师比离卫赴宋。卫庄公蒯聩派鄢武子向周室说明自己此前避居晋地、如今继守卫国，周王派单平公答复，承认其恢复禄位，并要求敬慎守职。 [[1]](#bce0479-note-1)

<a id="bce0479-event-2"></a>

<a id="event-3"></a>

2. **卫庄公送走孔悝，孔氏携神主离卫。** 六月，卫庄公在平阳宴饮孔悝，夜半送他离开。孔悝带母亲伯姬出行，派车返回西圃取神主，追赶者杀了载主之人。孔氏许公为迎取神主，射杀追者，取回神主；孔悝最终逃到宋国。 [[2]](#bce0479-note-2)

<a id="bce0479-event-3"></a>

<a id="event-7"></a>

3. **卫国再逐大叔遗，太子疾迫父王许杀浑良夫。** 卫庄公听信有关占梦的告发，逐走大叔遗。浑良夫又建议召回在外的君族，择可用者并取回先君器物，引起太子疾不满。太子携武装逼父王盟誓，请求杀良夫；庄公原曾许免他三死，双方约定以后再以罪处置。 [[3]](#bce0479-note-3)

## 孔子之卒与弟子服丧

<a id="bce0479-event-4"></a>

<a id="event-2"></a>

4. **孔子去世，鲁哀公作诔。** 夏季，孔子去世，葬在鲁城北泗水旁。哀公作诔称其为“尼父”，哀叹自己失去辅佐；子贡认为哀公生前未能用其道，死后的诔辞也有失礼。弟子为孔子服心丧，子贡后来在墓旁结庐守丧。 [[4]](#bce0479-note-4)

<a id="bce0479-chu"></a>

## 白公胜之乱

<a id="bce0479-event-5"></a>

<a id="event-4"></a>

<a id="event-5"></a>

<a id="event-6"></a>

5. **白公胜杀楚执政并劫惠王，叶公平乱使王复位。** 白公胜的父亲太子建流亡至郑，参与晋袭郑之谋，事泄被杀。白公曾随伍员避难吴国，[前487年](bce-0487.md#sj040-baigong-return-event)被子西召回楚，守边而聚死士。白公在[前483年](bce-0483.md#sj040-baigong-request-event)请伐郑。后来楚反而救郑，白公遂谋杀子西。吴攻慎，白公获胜后借献战备进入朝廷，杀子西、子期，劫持楚惠王。石乞劝白公杀惠王，白公未听，另谋拥立子闾；子闾拒绝后被杀。惠王逃至昭夫人处，叶公沈诸梁入都起兵，白公败亡，石乞也被处死。惠王复位，叶公暂理军政，安定后退回叶地。 [[5]](#bce0479-note-5)

### 5. 白公胜杀楚执政并劫惠王，叶公平乱使王复位

[返回正文第5条](#bce0479-event-5)

**政变细节** 《左传》记白公磨剑明言欲杀子西、与石乞招熊宜僚未成，圉公阳背惠王出逃，及白公自缢、石乞受烹前拒绝交代白公尸处。《楚世家》另记白公自立月余，惠王的随从与叶公共攻白公。

<a id="note-4"></a>

> 楚大子建之遇谗也，自城父奔宋。又辟华氏之乱于郑，郑人甚善之。又適晋，与晋人谋袭郑，乃求复焉。郑人复之如初。晋人使谍于子木，请行而期焉。子木暴虐于其私邑，邑人诉之。郑人省之，得晋谍焉。遂杀子木。其子曰胜，在吴。子西欲召之。叶公曰：“吾闻胜也诈而乱，无乃害乎。”子西曰：“吾闻胜也信而勇，不为不利，舍诸边竟，使卫藩焉。”叶公曰：“周仁之谓信，率义之谓勇。吾闻胜也好复言，而求死士，殆有私乎？复言，非信也。期死，非勇也。子必悔之。”弗从。召之使处吴竟，为白公。请伐郑。子西曰：“楚未节也。不然，吾不忘也。”他日，又请，许之。未起师。晋人伐郑，楚救之，与之盟。胜怒曰：“郑人在此，仇不远矣。”胜自厉剑，子期之子平见之，曰：“王孙何自厉也？”曰：“胜以直闻，不告女，庸为直乎？将以杀尔父。”平以告子西。子西曰：“胜如卵，余翼而长之。楚国第，我死，令尹、司马，非胜而谁？”胜闻之曰：“令尹之狂也，得死，乃非我。”子西不悛。胜谓石乞曰：“王与二卿士，皆五百人当之，则可矣。”乞曰：“不可得也。”曰：“市南有熊宜僚者，若得之，可以当五百人矣。”乃从白公而见之。与之言，说。告之故，辞。承之以剑，不动。胜曰：“不为利谄，不为威惕，不洩人言以求媚者，去之。”

> 伍胥既至宋，宋有華氏之亂，乃與太子建俱奔於鄭。鄭人甚善之。太子建又適晉，晉頃公曰：「太子既善鄭，鄭信太子。太子能為我內應，而我攻其外，滅鄭必矣。滅鄭而封太子。」太子乃還鄭。事未會，會自私欲殺其從者，從者知其謀，乃告之於鄭。鄭定公與子產誅殺太子建。建有子名勝。伍胥懼，乃與勝俱奔吳。到昭關，昭關欲執之。伍胥遂與勝獨身步走，幾不得脫。追者在後。至江，江上有一漁父乘船，知伍胥之急，乃渡伍胥。伍胥既渡，解其劍曰：「此劍直百金，以與父。」父曰：「楚國之法，得伍胥者賜粟五萬石，爵執珪，豈徒百金劍邪！」不受。伍胥未至吳而疾，止中道，乞食。至於吳，吳王僚方用事，公子光為將。伍胥乃因公子光以求見吳王。

<a id="sj066-cite-040"></a>

**[《史记·伍子胥列传》P021](../../sources/摘录/史记-卷066-伍子胥列传.md#p021)**

> 伍子胥初所與俱亡故楚太子建之子勝者，在於吳。吳王夫差之時，楚惠王欲召勝歸楚。葉公諫曰：「勝好勇而陰求死士，殆有私乎！」惠王不聽。遂召勝，使居楚之邊邑鄢，號為白公。白公歸楚三年而吳誅子胥。

> 白公勝既歸楚，怨鄭之殺其父，乃陰養死士求報鄭。歸楚五年，請伐鄭，楚令尹子西許之。兵未發而晉伐鄭，鄭請救於楚。楚使子西往救，與盟而還。白公勝怒曰：「非鄭之仇，乃子西也。」勝自礪劍，人問曰：「何以為？」勝曰：「欲以殺子西。」子西聞之，笑曰：「勝如卵耳，何能為也。」

> 楚大子建之遇谗也，自城父奔宋。又辟华氏之乱于郑，郑人甚善之。又適晋，与晋人谋袭郑，乃求复焉。郑人复之如初。晋人使谍于子木，请行而期焉。子木暴虐于其私邑，邑人诉之。郑人省之，得晋谍焉。遂杀子木。其子曰胜，在吴。子西欲召之。叶公曰：“吾闻胜也诈而乱，无乃害乎。”子西曰：“吾闻胜也信而勇，不为不利，舍诸边竟，使卫藩焉。”叶公曰：“周仁之谓信，率义之谓勇。吾闻胜也好复言，而求死士，殆有私乎？复言，非信也。期死，非勇也。子必悔之。”弗从。召之使处吴竟，为白公。请伐郑。子西曰：“楚未节也。不然，吾不忘也。”他日，又请，许之。未起师。晋人伐郑，楚救之，与之盟。胜怒曰：“郑人在此，仇不远矣。”胜自厉剑，子期之子平见之，曰：“王孙何自厉也？”曰：“胜以直闻，不告女，庸为直乎？将以杀尔父。”平以告子西。子西曰：“胜如卵，余翼而长之。楚国第，我死，令尹、司马，非胜而谁？”胜闻之曰：“令尹之狂也，得死，乃非我。”子西不悛。胜谓石乞曰：“王与二卿士，皆五百人当之，则可矣。”乞曰：“不可得也。”曰：“市南有熊宜僚者，若得之，可以当五百人矣。”乃从白公而见之。与之言，说。告之故，辞。承之以剑，不动。胜曰：“不为利谄，不为威惕，不洩人言以求媚者，去之。”

> 伍胥既至宋，宋有華氏之亂，乃與太子建俱奔於鄭。鄭人甚善之。太子建又適晉，晉頃公曰：「太子既善鄭，鄭信太子。太子能為我內應，而我攻其外，滅鄭必矣。滅鄭而封太子。」太子乃還鄭。事未會，會自私欲殺其從者，從者知其謀，乃告之於鄭。鄭定公與子產誅殺太子建。建有子名勝。伍胥懼，乃與勝俱奔吳。到昭關，昭關欲執之。伍胥遂與勝獨身步走，幾不得脫。追者在後。至江，江上有一漁父乘船，知伍胥之急，乃渡伍胥。伍胥既渡，解其劍曰：「此劍直百金，以與父。」父曰：「楚國之法，得伍胥者賜粟五萬石，爵執珪，豈徒百金劍邪！」不受。伍胥未至吳而疾，止中道，乞食。至於吳，吳王僚方用事，公子光為將。伍胥乃因公子光以求見吳王。

> 伍子胥初所與俱亡故楚太子建之子勝者，在於吳。吳王夫差之時，楚惠王欲召勝歸楚。葉公諫曰：「勝好勇而陰求死士，殆有私乎！」惠王不聽。遂召勝，使居楚之邊邑鄢，號為白公。白公歸楚三年而吳誅子胥。

**《史记·伍子胥列传》·原TXT第4681行** · [固定版本原文](../../sources/本地分卷/史记/史记-卷066.md#L4681)

> 白公勝既歸楚，怨鄭之殺其父，乃陰養死士求報鄭。歸楚五年，請伐鄭，楚令尹子西許之。兵未發而晉伐鄭，鄭請救於楚。楚使子西往救，與盟而還。白公勝怒曰：「非鄭之仇，乃子西也。」勝自礪劍，人問曰：「何以為？」勝曰：「欲以殺子西。」子西聞之，笑曰：「勝如卵耳，何能為也。」

**汇入说明：** 从宋、郑到吴，以及召胜归楚、请求伐郑，均是起事以前的回叙，不是在前479年数月内发生全部故事。列传说楚惠王欲召胜，随后‘归楚三年而吴诛子胥’，又接五年、四岁，不能据此硬定楚王纪年及胜归楚的确年；经传将决定归于子西。本批保留相对次序，不用有冲突的数字强算前487年。列传居鄢与经传居吴境也不未经地理核校便写成唯一精确地址。太子建遇害另在伍员出亡注中互见，不重复计数。

**前后关联：** [前522年第2条](../bce-0600-0501/bce-0522.md#event-3)

#### [[5]](#note-5) 白公乘献战备入朝，杀子西、子期，劫持楚惠王。

**《左传》·哀公十六年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0479.md#all-20261109-t006)

**《左传》·哀公十六年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0479.md#all-20261109-t007)

> 秋七月，杀子西、子期于朝，而劫惠王。子西以袂掩面而死。子期曰：“昔者吾以力事君，不可以弗终。”抉豫章以杀人而后死。石乞曰：“焚库弑王，不然不济。”白公曰：“不可。弑王不祥，焚库无聚，将何以守矣？”乞曰：“有楚国而治其民，以敬事神，可以得祥，且有聚矣，何患？”弗从。叶公在蔡，方城之外皆曰：“可以入矣。”子高曰：“吾闻之，以险徼幸者，其求无餍，偏重必离。”闻其杀齐管修也而后入。

**《左传》·哀公十六年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0479.md#all-20261109-t008)

> 白公欲以子闾为王。子闾不可，遂劫以兵。子闾曰：“王孙若安靖楚国，匡正王室，而后庇焉，启之愿也，敢不听从？若将专利以倾王室，不顾楚国，有死不能。”遂杀之，而以王如高府，石乞尹门。圉公阳穴宫，负王以如昭夫人之宫。叶公亦至，及北门，或遇之，曰：“君胡不胄？国人望君如望慈父母焉。盗贼之矢若伤君，是绝民望也。若之何不胄？”乃胄而进。又遇一人曰：“君胡胄？国人望君如望岁焉，日日以几。若见君面，是得艾也。民知不死，其亦夫有奋心。犹将旌君以徇于国，而又掩面以绝民望，不亦甚乎？”乃免胄而进。遇箴尹固，帅其属将与白公。子高曰：“微二子者，楚不国矣。弃德从贼，其可保乎？”乃从叶公。使与国人以攻白公。白公奔山而缢，其徒微之。生拘石乞而问白公之死焉，对曰：“余知其死所，而长者使余勿言。”曰：“不言将烹。”乞曰：“此事克则为卿，不克则烹，固其所也。何害？”乃烹石乞。王孙燕奔黄氏。沈诸梁兼二事，国宁，乃使宁为令尹，使宽为司马，而老于叶。

> 其後四歲，白公勝與石乞襲殺楚令尹子西、司馬子綦於朝。石乞曰：「不殺王，不可。」乃劫（之）王如高府。石乞從者屈固負楚惠王亡走昭夫人之宮。葉公聞白公為亂，率其國人攻白公。白公之徒敗，亡走山中，自殺。而虜石乞，而問白公尸處，不言將亨。石乞曰：「事成為卿，不成而亨，固其職也。」終不肯告其尸處。遂亨石乞，而求惠王復立之。

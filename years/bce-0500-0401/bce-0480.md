<a id="本年纪事"></a>
<a id="event-1"></a>

1. **成邑叛附齐国，孟武伯攻城未克。** 正月，成邑背离孟氏而附齐。孟武伯率军进攻，没有攻下，转而修筑输地城防。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚军攻吴，陈使在途中去世，副使仍奉尸完成使命。** 夏季，楚国子西、子期攻吴至桐汭。陈国派公孙贞子慰问吴国，使者到良地去世，副使芋尹盖准备奉遗体继续出使。吴方担心水涨、不便接待，劝其停止；芋尹盖援引使者途中死亡仍应完成国命的礼例，据理交涉，吴人最终接纳。 [[2]](#note-2)

<a id="event-3"></a>

3. **齐高无丕出奔北燕，郑国进攻宋国。** 五月，齐国高无丕出奔北燕。郑伯出兵伐宋。 [[3]](#note-3)

<a id="event-4"></a>

4. **鲁、齐修好，齐国归还成邑。** 秋季，陈瓘出使楚国途经卫，子路劝他改善与鲁的关系。冬季鲁与齐议和，子服景伯出使、子贡为副，劝成邑公孙宿不要因私利损害宗国，又向陈恒指出，齐要与鲁相好，就不应继续利用鲁的困难取地。齐国于是交回成邑，公孙宿带部下兵甲进入嬴地。 [[4]](#note-4)

<a id="event-5"></a>

5. **晋国先伐卫，冬季又伐郑；鲁国秋季举行大雩。** 秋季，鲁国举行大雩，晋国赵鞅出兵伐卫。冬季，晋侯又率军进攻郑国。 [[5]](#note-5)

<a id="event-6"></a>

6. **蒯聩潜入孔氏，逼孔悝支持，卫侯辄出走。** 蒯聩在戚时，通过浑良夫联系姊姊孔伯姬。闰月，二人化装进入孔氏住处，伯姬持戈在前，蒯聩等携兵迫孔悝盟誓，劫他登台。孔氏家老栾宁得知后带卫侯辄逃出，孔氏继承人遂被迫卷入君位更替。 [[6]](#note-6)

<a id="event-7"></a>

7. **子路赶回孔氏救主，在冲突中遇害。** 子路得知孔氏有难，迎面遇到正离开的子羔，仍坚持自己受其禄便应救其患。入门后，他要求释放孔悝，准备迫使蒯聩一方下台。蒯聩遣石乞、盂黡应敌，子路被击伤冠缨，重新结缨而死。孔悝一方最终立蒯聩为卫庄公。蒯聩想清算未曾迎接自己的旧臣，受到反抗威胁后才停止。 [[7]](#note-7)

<a id="event-8"></a>

8. **卫国公孟彄出奔齐国。** 冬季，卫国公孟彄出奔齐国。 [[8]](#note-8)

<a id="event-9"></a>

9. **齐平公驁元年，田氏继续掌握齐政。** 齐简公在上一年遇害后，他的弟弟驁继位，称齐平公。按《十二诸侯年表》，本年为齐平公元年。田常担任国相，实际控制齐国政务。 [[9]](#note-9)

<a id="sj014-audit-0480-song"></a>

<a id="event-10"></a>

10. **宋景公忧虑荧惑守心，子韦以君言解说天象。** 史书在本年记荧惑停留于心宿一带，宋景公担心祸患。子韦提出把灾祸转嫁于大臣、百姓或年成，景公都不接受；子韦于是称许他的言辞。 [[10]](#note-10)

> 十二年，初，孔圉文子取太子蒯聵之姊，生悝。孔氏之豎渾良夫美好，孔文子卒，良夫通於悝母。太子在宿，悝母使良夫於太子。太子與良夫言曰：「茍能入我國，報子以乘軒，免子三死，毋所與。」與之盟，許以悝母為妻。閏月，良夫與太子入，舍孔氏之外圃。昏，二人蒙衣而乘，宦者羅御，如孔氏。孔氏之老欒甯問之，稱姻妾以告。遂入，適伯姬氏。既食，悝母杖戈而先，太子與五人介，輿猳從之。伯姬劫悝於廁，彊盟之，遂劫以登臺。欒甯將飲酒，炙未熟，聞亂，使告仲由。召護駕乘車，行爵食炙，奉出公輒奔魯。

### 7. 子路赶回孔氏救主，在冲突中遇害

[返回正文第7条](#event-7)

**[《史记·卫康叔世家》P039](../../sources/摘录/史记-卷037-卫康叔世家.md#p039)**

> 仲由將入，遇子羔將出，曰：「門已閉矣。」子路曰：「吾姑至矣。」子羔曰：「不及，莫踐其難。」子路曰：「食焉不辟其難。」子羔遂出。子路入，及門，公孫敢闔門，曰：「毋入為也！」子路曰：「是公孫也？求利而逃其難。由不然，利其祿，必救其患。」有使者出，子路乃得入。曰：「太子焉用孔悝？雖殺之，必或繼之。」且曰：「太子無勇。若燔臺，必舍孔叔。」太子聞之，懼，下石乞、盂黶敵子路，以戈擊之，割纓。子路曰：「君子死，冠不免。」結纓而死。孔子聞衛亂，曰：「嗟乎！柴也其來乎？由也其死矣。」孔悝竟立太子蒯聵，是為莊公。

<a id="2note-2-楚军攻吴陈使在途中去世副使仍奉尸完成使命"></a>
#### [[2]](#note-2) 楚军攻吴，陈使在途中去世，副使仍奉尸完成使命。

**《左传》·哀公十五年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0480.md#all-20261109-t002)

> 夏，楚子西、子期伐吴，及桐汭。陈侯使公孙贞子吊焉，及良而卒，将以尸入。吴子使大宰嚭劳，且辞曰：“以水潦之不时，无乃廪然陨大夫之尸，以重寡君之忧。寡君敢辞上介。”芋尹盖对曰：“寡君闻楚为不道，荐伐吴国，灭厥民人。寡君使盖备使，吊君之下吏。无禄，使人逢天之慼，大命陨队，绝世于良，废日共积，一日迁次。今君命逆使人曰：‘无以尸造于门。’是我寡君之命委于草莽也。且臣闻之曰，事死如生，礼也。于是乎有朝聘而终，以尸将事之礼，又有朝聘而遭丧之礼。若不以尸将命，是遭丧而还也，无乃不可乎！以礼防民，犹或逾之。今大夫曰，死而弃之，是弃礼也。其何以为诸侯主？先民有言曰，无秽虐士。备使奉尸将命，苟我寡君之命达于君所，虽陨于深渊，则天命也。非君与涉人之过也。”吴人内之。

**说明：** 陈国在吴楚之间的立场按本条行为叙述，不把“吊吴”改写成陈已出军替吴作战。副使的礼论为当时说法，不是现代外交规则。

#### [[4]](#note-4) 鲁、齐修好，齐国归还成邑。

**获麟后续经·哀公十五年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0480.md#all-20261109-x007)

> 及齐平。

**《左传》·哀公十五年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0480.md#all-20261109-t003)

> 秋，齐陈瓘如楚。过卫，仲由见之，曰：“天或者以陈氏为斧斤，既斫丧公室，而他人有之，不可知也。其使终飨之，亦不可知也。若善鲁以待时，不亦可乎？何必恶焉？”子玉曰：“然，吾受命矣，子使告我弟。”

**《左传》·哀公十五年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0480.md#all-20261109-x007)

> 冬，及齐平。子服景伯如齐，子赣为介，见公孙成，曰：“人皆臣人，而有背人之心。况齐人虽为子役，其有不贰乎？子，周公之孙也。多飨大利，犹思不义。利不可得，而丧宗国，将焉用之？”成曰：“善哉，吾不早闻命。”陈成子馆客，曰：“寡君使恒告曰，寡人愿事君如事卫君。”景伯揖子赣而进之。对曰：“寡君之愿也。昔晋人伐卫，齐为卫故，伐晋冠氏，丧车五百，因与卫地，自济以西，禚、媚、杏以南，书社五百。吴人加敝邑以乱。齐因其病，取讙与阐。寡君是以寒心。若得视卫君之事君也，则固所愿也。”成子病之，乃归成。公孙宿以其兵甲入于嬴。

**《史记·鲁周公世家》·十五年：使齐、归地** · [所核固定版本](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E9%AD%AF%E5%91%A8%E5%85%AC%E4%B8%96%E5%AE%B6.md#ref-95ac4455700fa7)

> 十五年，使子服景伯、子貢爲介，適齊，齊歸我侵地。田常初相，欲親諸矦。

**说明：** 《鲁周公世家》十五年归侵地与此合并。公孙成、公孙宿同一人；陈瓘对子路所言与子贡入齐交涉是前后两个环节。

<a id="6note-6-蒯聩潜入孔氏逼孔悝支持卫侯辄出走"></a>
#### [[6]](#note-6) 蒯聩潜入孔氏，逼孔悝支持，卫侯辄出走。

**《左传》·哀公十五年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0480.md#all-20261109-t005)

> 卫孔圉取大子蒯聩之姊，生悝。孔氏之竖浑良夫，长而美，孔文子卒，通于内。大子在戚，孔姬使之焉。大子与之言曰：“苟使我入获国，服冕乘轩，三死无与。”与之盟。为请于伯姬。闰月，良夫与大子入，舍于孔氏之外圃。昏，二人蒙衣而乘，寺人罗御，如孔氏。孔氏之老栾宁问之，称姻妾以告。遂入，適伯姬氏。既食，孔伯姬杖戈而先，大子与五人介，舆豭从之。迫孔悝于厕，强盟之，遂劫以登台。栾宁将饮酒，炙未熟，闻乱，使告季子。召获驾乘车，行爵食炙，奉卫侯辄来奔。季子将入，遇子羔将出，曰：“门已闭矣。”季子曰：“吾姑至焉。”子羔曰：“弗及，不践其难。”季子曰：“食焉，不辟其难。”子羔遂出。子路入，及门，公孙敢门焉，曰：“无入为也。”季子曰：“是公孙也，求利焉而逃其难。由不然，利其禄，必救其患。”有使者出，乃入。曰：“大子焉用孔悝，虽杀之，必或继之。”且曰：“大子无勇，若燔台半，必舍孔叔。”大子闻之惧，下石乞、盂黡敌子路。以戈击之，断缨。子路曰：“君子死，冠不免。”结缨而死。孔子闻卫乱，曰：“柴也其来，由也死矣。”孔悝立庄公。庄公害故政，欲尽去之。先谓司徒瞒成曰：“寡人离病于外久矣，子请亦尝之。”归告褚师比，欲与之伐公，不果。

**同段共用：** [6](#note-6)、[7](#note-7)；覆盖统计仅计一段原文。

**《春秋左传正义》卷六十·杜注：十六年春条从告** · [所核固定版本](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E5%82%B3%E6%AD%A3%E7%BE%A9-%E5%8D%B760.md#ref-4aa055b1ad5fd9)

**引文层次：** 原注附于蒯聩入卫及卫侯辄来奔的十六年经下。用以对照十五年闰月的传文，不更改工作本。

**说明：** 同段接记子路之死，另列下一条并声明共用原文。《续经》将蒯聩入卫、辄来鲁系于次年正月，《左传》详叙在本年闰月；杜注解释“书此春，皆从告”。本页按行动叙事放本年，次年只作告录对照，不再发动第二次政变。

#### 卷014补核｜宋景公忧虑荧惑守心，子韦以君言解说天象。

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0480)。宋栏“三十七荧惑守心，子韦曰善”与《宋微子世家》三十七年互见。天象的道德感应和星移三度是古人解释，不能改写为现代天文学已证实君言改变行星运行。世家同段灭陈另有年差，主述仍见前478年。

《天官书》[P113](../../sources/摘录/史记-卷027-天官书.md#p113)把“於宋，子韋”列入天数传承，只补本条人物背景；这段列名不提供新的生卒、任官或预言日期，不能再制造一次荧惑守心。

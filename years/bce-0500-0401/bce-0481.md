## 本年纪事

<a id="event-1"></a>

1. **鲁人向西田猎，捕获被辨认为麟的异兽。**

春季，鲁人在大野西狩。叔孙氏车人鉏商捕获一只异兽，当时视为不祥，交给虞人。孔子看过后称它为麟，这只动物才被重新收取。 [1](#note-1)

<a id="event-2"></a>

2. **小邾射带句绎来奔，子路拒绝替他保证。**

小邾射带句绎邑投鲁，要求子路以个人信用作保证，便不再另行盟誓。季康子认为此举尊重子路，子路却表示，奉鲁命作战可以承担危险，替背离原君者认可其说则不能接受，遂辞。 [2](#note-2)

<a id="event-3"></a>

3. **陈氏与阚止争权，齐简公被拘于舒州。**

齐简公任用阚止，陈恒与其互相戒备。陈逆被捕后，陈氏醉杀守者救走他，矛盾进一步升级。陈豹把阚止准备清除陈氏的谈话传回族中，陈氏决定先动手，武装进入公宫。阚止反攻失败，逃走后被捕杀；陈恒最终将简公拘在舒州。 [3](#note-3)

<a id="event-4"></a>

4. **宋国向魋叛乱失败，向氏诸人相继离国。**

宋公与宠臣向魋互有图谋，宋公争取其兄向巢后，命军攻击桓氏。向魋先退入曹地叛乱，六月又因邑民反对而逃卫，向巢则奔鲁。司马牛交还自己的邑与圭，不愿卷入兄弟争斗，后来又辗转齐、吴等地；向魋在卫被索宝，最后投齐，陈成子给他次卿之位。 [4](#note-4)

<a id="event-5"></a>

5. **齐简公被杀，孔子请求鲁国讨齐，未获采纳。**

六月，齐简公壬在舒州被杀。孔子斋戒后多次请求伐齐，认为齐国内仍有不附陈氏者可为援助。哀公担心鲁弱齐强，又让他去告季孙，出兵没有实现。孔子退后说明，自己曾列大夫，不敢对此事全不进言。 [5](#note-5)

 [卷四互见与归年](#sj004-481-1)


<a id="event-6"></a>

6. **叔还、莒君去世，五月朔发生日食。**

庚戌，鲁国叔还去世。五月庚申朔发生日食；同季经文也记莒君狂去世。 [6](#note-6)

<a id="event-7"></a>

7. **晋国赵鞅率军攻卫。**

秋季，赵鞅率晋军进攻卫国。 [7](#note-7)

<a id="event-8"></a>

8. **孟懿子去世，孟氏与成邑的矛盾继续。**

孟孺子洩先前想在成邑养马，被成宰公孙宿拒绝，曾袭成不入，又鞭打成的使者。八月辛丑，孟懿子去世，成邑的人来奔丧，却被拒之门外，提出参与丧事也未获准。他们担心报复，不敢返回。 [8](#note-8)

<a id="event-9"></a>

9. **陈宗竖由楚返陈被杀，辕买出奔楚国。**

陈宗竖先逃楚，冬季又返回陈国，被陈人杀死。陈国辕买随后出奔楚国。 [9](#note-9)

<a id="event-10"></a>

10. **出现彗星，鲁国发生饥荒。**

冬季年条又记彗星及饥荒。 [10](#note-10)

**《左传》·哀公十四年** · [固定版本原文](https://github.com/zhixin0825/history/blob/dac36d55ba97f526532c06d8bc2a005583bdb849/working-texts/zuozhuan-punctuated-years/years/bce-0481.md#L63-L63)

> 宋桓魋之宠害于公。公使夫人骤请享焉，而将讨之。未及，魋先谋公，请以鞌易薄，公曰：“不可。薄，宗邑也。”乃益鞌七邑，而请享公焉。以日中为期，家备尽往。公知之，告皇野曰：“余长魋也。今将祸余，请即救。”司马子仲曰：“有臣不顺，神之所恶也，而况人乎？敢不承命。不得左师不可。请以君命召之。”左师每食击钟。闻钟声，公曰：“夫子将食。”既食，又奏。公曰：“可矣。”以乘车往，曰：“迹人来告曰：‘逢泽有介麇焉。’公曰：‘虽魋未来，得左师，吾与之田，若何？’君惮告子。野曰：‘尝私焉。’君欲速，故以乘车逆子。”与之乘，至，公告之故，拜不能起。司马曰：“君与之言。”公曰：“所难子者，上有天，下有先君。”对曰：“魋之不共，宋之祸也。敢不唯命是听。”司马请瑞焉，以命其徒攻桓氏。其父兄故臣曰：“不可。”其新臣曰：“从吾君之命。”遂攻之。子颀骋而告桓司马。司马欲入，子车止之，曰：“不能事君，而又伐国，民不与也，祗取死焉。”向魋遂入于曹以叛。

**《左传》·哀公十四年** · [固定版本原文](https://github.com/zhixin0825/history/blob/dac36d55ba97f526532c06d8bc2a005583bdb849/working-texts/zuozhuan-punctuated-years/years/bce-0481.md#L65-L65)

> 六月，使左师巢伐之，欲质大夫以入焉。不能。亦入于曹取质。魋曰：“不可。既不能事君，又得罪于民，将若之何？”乃舍之。民遂叛之。向魋奔卫。向巢来奔，宋公使止之，曰：“寡人与子有言矣，不可以绝向氏之祀。”辞曰：“臣之罪大，尽灭桓氏可也。若以先臣之故，而使有后，君之惠也。若臣则不可以入矣。”司马牛致其邑与珪焉，而適齐。向魋出于卫地，公文氏攻之，求夏后氏之璜焉。与之他玉，而奔齐，陈成子使为次卿。司马牛又致其邑焉，而適吴。吴人恶之而反。赵简子召之，陈成子亦召之。卒于鲁郭门之外，阬氏葬诸丘舆。

**说明：** 司马牛辗转及卒于鲁郭门等，是同段接述的后续，不能全算作本年有确月之事。宋已经灭曹，此处“入于曹”是据曹地而叛，不是曹国恢复独立。

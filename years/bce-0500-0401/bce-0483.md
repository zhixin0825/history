# 公元前483年（鲁哀公十二年）

> 第一轮白话整理。古历月日不直接等同公历月日；出处覆盖不等于逐句翻译或现代学术定本。

本页以《春秋》本经与《左传》对读。

## 本年纪事

<a id="event-1"></a>

1. **鲁国开始用田赋。**

正月，鲁国施行田赋，将前一年季氏筹划的征赋调整付诸实行。 [1](#note-1)

<a id="event-2"></a>

2. **昭公夫人孟子去世。**

五月甲辰，昭公夫人孟子去世。她出自吴国，鲁方没有按通常夫人丧礼全套办理赴告、反哭等程序。孔子参加吊丧后到季氏处，涉及丧服与拜礼的安排。 [2](#note-2)

<a id="event-3"></a>

3. **哀公会吴于橐皋，子贡拒绝重复盟誓。**

哀公在橐皋会吴，吴王让太宰嚭提出重申盟约。哀公不愿，子贡解释盟约若有效就不必日日重订，若可以随意更改，重复也没有意义。吴方最终没有举行这次再盟。 [3](#note-3)

<a id="event-4"></a>

4. **郧会后吴拘卫君，子贡交涉促其获释。**

卫国此前杀过吴使且姚，对赴会意见不一。秋季卫君到郧，哀公与卫君、宋国皇瑗订盟，却辞绝吴方的盟誓要求。吴人围住卫君住处，子服景伯请子贡带锦帛交涉。子贡指出，拘留卫君反而使愿意亲吴的人受挫，助长拒吴者，吴方才放卫君回国。 [4](#note-4)

<a id="event-5"></a>

5. **宋军攻郑国边邑，年末反被郑军包围。**

宋、郑之间原有约定不占的争议地，后来郑国安置宋国流亡公族并筑城。九月，宋向巢取钖，杀宋元公之孙，继续围嵒。十二月，郑国罕达来援，反将宋军围住，战局延续到下一年。 [5](#note-5)

<a id="event-6"></a>

6. **十二月记螽灾，孔子指出历法可能有误。**

十二月，鲁国出现螽灾记录。季孙询问孔子，孔子根据当时星象与昆虫蛰伏季节的关系，指出司历的安排可能出了问题。 [6](#note-6)

> 公会吴于橐皋。吴子使大宰嚭请寻盟。公不欲，使子贡对曰：“盟所以周信也，故心以制之，玉帛以奉之，言以结之，明神以要之。寡君以为苟有盟焉，弗可改也已。若犹可改，日盟何益？今吾子曰，必寻盟。若可寻也，亦可寒也。”乃不寻盟。

> 吳王既誅伍子胥，遂伐齊。齊鮑氏殺其君悼公而立陽生。吳王欲討其賊，不勝而去。其後二年，吳王召魯衛之君會之橐皋。其明年，因北大會諸侯於黃池，以令周室。越王句踐襲殺吳太子，破吳兵。吳王聞之，乃歸，使使厚幣與越平。後九年，越王句踐遂滅吳，殺王夫差；而誅太宰嚭，以不忠於其君，而外受重賂，與己比周也。

**汇入说明：** 列传用‘其后二年’接橐皋，笼统说召鲁、卫之君。经传分别记本年鲁会吴于橐皋，以及秋季卫侯会吴于郧。正文保留两场会议的具体经过，不把鲁、卫各自会吴都合并为同一次橐皋之会，也不据本篇相对年数倒改前484年伍员死亡。

### [4] 郧会后吴拘卫君，子贡交涉促其获释。

**《春秋》本经·哀公十二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/dac36d55ba97f526532c06d8bc2a005583bdb849/working-texts/zuozhuan-punctuated-years/years/bce-0483.md#L19-L19)

> 秋，公会卫侯、宋皇瑗于郧。

**《左传》·哀公十二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/dac36d55ba97f526532c06d8bc2a005583bdb849/working-texts/zuozhuan-punctuated-years/years/bce-0483.md#L35-L35)

> 吴征会于卫。初，卫人杀吴行人且姚而惧，谋于行人子羽。子羽曰：“吴方无道，无乃辱吾君，不如止也。”子木曰：“吴方无道，国无道，必弃疾于人。吴虽无道，犹足以患卫。往也！长木之毙，无不摽也。国狗之瘈，无不噬也。而况大国乎？”

**《左传》·哀公十二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/dac36d55ba97f526532c06d8bc2a005583bdb849/working-texts/zuozhuan-punctuated-years/years/bce-0483.md#L37-L37)

> 秋，卫侯会吴于郧。公及卫侯、宋皇瑗盟，而卒辞吴盟。吴人藩卫侯之舍。子服景伯谓子贡曰：“夫诸侯之会，事既毕矣，侯伯致礼，地主归饩，以相辞也[9]。今吴不行礼于卫，而藩其君舍以难之，子盍见大宰？”乃请束锦以行。语及卫故，大宰嚭曰：“寡君愿事卫君，卫君之来也缓，寡君惧，故将止之。”子贡曰：“卫君之来，必谋于其众。其众或欲或否，是以缓来。其欲来者，子之党也。其不欲来者，子之仇也。若执卫君，是堕党而崇仇也。夫堕子者得其志矣！且合诸侯而执卫君，谁敢不惧？堕党崇仇，而惧诸侯，或者难以霸乎。”大宰嚭说，乃舍卫侯。卫侯归，效夷言。子之尚幼，曰：“君必不免，其死于夷乎！执焉，而又说其言，从之固矣。”

**说明：** 传文所记卫君回国后学吴语及旁人的预言，不用来判断人物未来必然命运。工作本夹有网页标记“[9]”，逐段原文仍保留并提示，非本页新增引文编号。

<a id="event-1"></a>

1. **齐军逼近鲁都，冉求组织迎战。** 齐国为报鄎之役，国书、高无率军到清地。季康子向家宰冉求问策，冉求先建议守边，三家未能同意，便要求背城而战。鲁军分左右两部，冉求率左师、孟孺子洩率右师，老幼留守。交战时，冉求在樊迟推动下率众越沟，打入齐阵；右师却退败，孟之侧殿后，其他部伍也有死伤。齐军夜退，冉求请求追击，季孙没有答应。 康子问冉求是天生善战还是学来的，冉求说学于孔子，并称老师若被任用可以名实相称、安定百姓，又不贪封邑；若想召他，应先清除阻挠，不能再次有始无终。 [[1]](#note-1)

<a id="event-2"></a>

2. **陈国辕颇因侵用征敛所得而被逐。** 辕颇任司徒时，为公女出嫁征取田赋，把剩余财物做成自己的大器。国人驱逐他，他逃往郑国。途中族人早备食物接济，他问为何不早劝阻，族人回答怕劝了反而先被逐。 [[2]](#note-2)

<a id="event-3"></a>

3. **鲁、吴伐齐，在艾陵大败齐军。** 为回应春季郊战，哀公再次会吴伐齐。联军克博、到嬴，吴王安排各军迎战。五月甲戌，双方战于艾陵：吴军一翼击败高无，齐国书一度击败胥门巢，吴王本军增援后扭转战局。国书及数名齐将被俘，战利品交给鲁君；鲁后来将国书的首级装匣送还齐国。吴军北伐得胜，威势又及邹、鲁，夫差更加疏远伍员的谋划，却未因此消除越国在近旁积蓄力量的隐患。齐景公去世后，齐廷争权，新君软弱。北伐以前，伍员曾劝谏说，勾践每餐不兼两样美味，吊死问疾，正积蓄力量；越是吴的心腹之病，先图齐而不防越，实为失策。 [[3]](#note-3)

<a id="event-4"></a>

4. **伍员反对集中伐齐，出使归来后被命自尽。** 在吴向北用兵以前，越已经逐渐恢复财力和军备；逢同劝勾践隐蔽报仇意图，结齐、亲楚、附晋而厚事吴，等吴远征疲弊再动手。吴准备北上时，勾践带部众和礼物来朝，伯嚭等乐于接受。伍员警告越是近身大患，吴却信其虚浮欺诈的辞令而贪齐；即使破齐，也像得到石田，无处可用。他引《盘庚》对越轨不敬者不留后患的告诫，主张释齐先越，否则后悔无及，夫差没有听从。《越王勾践世家》还记吴王凯旋后责备伍员，伍员劝他不要欢喜，一度想自杀而被吴王制止。文种又借向吴贷粟试探其态度，夫差不顾伍员反对而允借。伯嚭与逢同共同进谗，称伍员怨君、谋乱。

   伍员奉使齐国，临行告诫儿子：自己多次进谏不用，已经看见吴国将亡，儿子与吴同亡没有益处；于是把他托付给齐国鲍氏，回来复命。伯嚭又以寄子为据，诬称伍员刚暴少恩、猜忌害人，因计谋不被采用而怨恨，强谏只是阻挠当权者、盼吴败以自证正确；又说他假称有病不肯从征，在内不得意便在外倚靠诸侯，自恃先王谋臣，宜及早处置。夫差回答，即使没有伯嚭的话，自己也已怀疑，便赐属镂剑命其自尽。

   他大笑着追述自己辅佐阖庐、拥立夫差的功劳，说夫差原曾许分半国而自己没有接受，如今却因谗言被诛，他嘱舍人在墓上种梓树，以后可制器用；又要求抉出自己的眼睛悬在吴东门，看越兵入城灭吴，随后割颈自杀。夫差听到遗言大怒，把尸体盛入革囊投入江中。吴国此后更加依赖伯嚭。 [[4]](#note-4)



<a id="event-5"></a>

5. **鲁国整修守备，滕隐公去世并下葬。** 秋季，季孙命鲁人修守备，担心齐国报复。七月辛酉，滕君虞母去世；十一月，滕国安葬隐公。 [[5]](#note-5)

<a id="event-6"></a>

6. **卫国大叔疾出奔宋国。** 卫国大叔疾先后卷入宋氏、孔氏婚姻冲突，孔圉曾打算攻打他，孔子出面阻止。后来大叔疾失去孔氏妻子，又有其他争端，遂离卫奔宋。卫国另立继承者，并重新安排孔氏婚姻。 [[6]](#note-6)

<a id="event-7"></a>

7. **鲁国召孔子，孔子从卫国回鲁。** 孔圉想借孔子意见处理自己与大叔疾的冲突，孔子表示未学军事，离开后准备出行。孔圉急忙挽留，强调自己所问是卫国之难。恰在这时鲁人带礼币来召，孔子遂回鲁。鲁国又因冉求的军功重新重视其师，归鲁便与此前郊战衔接起来。 这次归来距离既有前497离鲁，按首尾年数计为十四岁；卫孔文子再三挽留，终未能改变返鲁的结果。 [[7]](#note-7)

<a id="event-8"></a>

8. **季康子拟实行田赋，孔子没有赞成。** 季康子打算采用田赋，让冉求多次请教孔子。孔子没有给出赞同答复，私下对冉求说，赋取应从薄，若不知节制，即使改用田赋仍会不足；若要依法，则周公旧典仍可参照。季氏没有听从，下一年正式实行。 [[8]](#note-8)

<a id="sj014-audit-0484-qi"></a>

<a id="event-9"></a>

9. **齐简公元年。** 齐悼公在上一年遇害后，简公壬承位，本年开始简公纪年。 [[9]](#note-9)

### 1. 齐军逼近鲁都，冉求组织迎战

[返回正文第1条](#event-1)

> 十有一年春，齐国书帅师伐我。

> 十一年春，齐为鄎故，国书、高无帅师伐我，及清。季孙谓其宰冉求曰：“齐师在清，必鲁故也。若之何？”求曰：“一子守，二子从公禦诸竟。”季孙曰：“不能。”求曰：“居封疆之间。”季孙告二子。二子不可。求曰：“若不可，则君无出。一子帅师，背城而战。不属者，非鲁人也。鲁之群室，众于齐之兵车。一室敌车，优矣。子何患焉？二子之不欲战也宜，政在季氏。当子之身，齐人伐鲁而不能战，子之耻也，大不列于诸侯矣。”季孙使从于朝，俟于党氏之沟。武叔呼而问战焉。对曰：“君子有远虑，小人何知？”懿子强问之，对曰：“小人虑材而言，量力而共者也。”武叔曰：“是谓我不成丈夫也。”退而蒐乘，孟孺子洩帅右师，颜羽御，邴洩为右。冉求帅左师，管周父御，樊迟为右。季孙曰：“须也弱。”有子曰：“就用命焉。”季氏之甲七千，冉有以武城人三百为己徒卒。老幼守宫，次于雩门之外。五日，右师从之。公叔务人见保者而泣曰：“事充政重，上不能谋，士不能死，何以治民？吾既言之矣，敢不勉乎！”

> 师及齐师战于郊，齐师自稷曲。师不踰沟。樊迟曰：“非不能也，不信子也。请三刻而踰之。”如之，众从之。师入齐军。右师奔，齐人从之，陈瓘、陈庄涉泗。孟之侧后入以为殿，抽矢策其马曰：“马不进也。”林不狃之伍曰：“走乎！”不狃曰：“谁不如？”曰：“然则止乎？”不狃曰：“恶贤？”徐步而死。师获甲首八十，齐人不能师。宵，谍曰：“齐人遁。”冉有请从之三，季孙弗许。孟孺子语人曰：“我不如颜羽，而贤于邴洩。子羽锐敏，我不欲战而能默。洩曰：‘驱之。’”公为与其嬖僮汪锜乘，皆死，皆殡。孔子曰：“能执干戈以卫社稷，可无殇也。”冉有用矛于齐师，故能入其军。孔子曰：“义也。”

### 3. 鲁、吴伐齐，在艾陵大败齐军

[返回正文第3条](#event-3)

> 五月，公会吴伐齐。

> 甲戌，齐国书帅师及吴战于艾陵，齐师败绩，获齐国书。

> 为郊战故，公会吴子伐齐。五月克博，壬申，至于嬴。中军从王。胥门巢将上军，王子姑曹将下军，展如将右军。齐国书将中军，高无将上军，宗楼将下军。陈僖子谓其弟书：“尔死，我必得志。”宗子阳与闾丘明相厉也。桑掩胥御国子。公孙夏曰：“二子必死。”将战，公孙夏命其徒歌《虞殡》。陈子行命其徒具含玉。公孙挥命其徒曰：“人寻约，吴发短。”东郭书曰：“三战必死，于此三矣。”使问弦多以琴，曰：“吾不复见子矣。”陈书曰：“此行也，吾闻鼓而已，不闻金矣。”

> 甲戌，战于艾陵，展如败高子，国子败胥门巢。王卒助之，大败齐师。获国书、公孙夏、闾丘明、陈书、东郭书，革车八百乘，甲首三千，以献于公。将战，吴子呼叔孙曰：“而事何也？”对曰：“从司马。”王赐之甲剑铍，曰：“奉尔君事，敬无废命。”叔孙未能对，卫赐进曰：“州仇奉甲从君而拜。”公使大史固归国子之元，寘之新箧，褽之以玄，加组带焉。寘书于其上曰：“天若不识不衷，何以使下国？”

### 4. 伍员反对集中伐齐，出使归来后被命自尽

[返回正文第4条](#event-4)

> 吴将伐齐，越子率其众以朝焉，王及列士，皆有馈赂。吴人皆喜，唯子胥惧，曰：“是豢吴也夫！”谏曰：“越在我，心腹之疾也。壤地同而有欲于我。夫其柔服，求济其欲也，不如早从事焉。得志于齐，犹获石田也，无所用之。越不为沼，吴其泯矣。使医除疾，而曰‘必遗类焉’者，未之有也。《盘庚》之诰曰：‘其有颠越不共，则劓殄无遗育，无俾易种于兹邑。’是商所以兴也。今君易之，将以求大，不亦难乎？”弗听。使于齐，属其子于鲍氏，为王孙氏。反役，王闻之，使赐之属镂以死。将死，曰：“树吾墓槚，槚可材也，吴其亡乎！三年，其始弱矣。盈必毁，天之道也。”

<a id="sj066-cite-033"></a>

**[《史记·伍子胥列传》P018](../../sources/摘录/史记-卷066-伍子胥列传.md#p018)**

> 其後四年，吳王將北伐齊，越王句踐用子貢之謀，乃率其眾以助吳，而重寶以獻遺太宰嚭。太宰嚭既數受越賂，其愛信越殊甚，日夜為言於吳王。吳王信用嚭之計。伍子胥諫曰：「夫越，腹心之病，今信其浮辭詐偽而貪齊。破齊，譬猶石田，無所用之。且盤庚之誥曰：『有顛越不恭，劓殄滅之，俾無遺育，無使易種于茲邑。』此商之所以興。願王釋齊而先越；若不然，後將悔之無及。」而吳王不聽，使子胥於齊。子胥臨行，謂其子曰：「吾數諫王，王不用，吾今見吳之亡矣。汝與吳俱亡，無益也。」乃屬其子於齊鮑牧，而還報吳。

**本卷说明：** 子贡谋划见本篇，详与卷067同组互校；不从说客故事推出所有出使都在一个年。寄子主本点名鲍牧，而经传前487已记鲍牧死，正文只承同组《左传》的鲍氏，不令鲍牧复出。盘庚告诰是伍员用于劝谏的引证，不作为前484发生的商代事。

**《史记·伍子胥列传》·原TXT第4678行** · [固定版本原文](../../sources/本地分卷/史记/史记-卷066.md#L4678)

> 吳太宰嚭既與子胥有隙，因讒曰：「子胥為人剛暴，少恩，猜賊，其怨望恐為深禍也。前日王欲伐齊，子胥以為不可，王卒伐之而有大功。子胥恥其計謀不用，乃反怨望。而今王又復伐齊，子胥專愎彊諫，沮毀用事，徒幸吳之敗以自勝其計謀耳。今王自行，悉國中武力以伐齊，而子胥諫不用，因輟謝，詳病不行。王不可不備，此起禍不難。且嚭使人微伺之，其使於齊也，乃屬其子於齊之鮑氏。夫為人臣，內不得意，外倚諸侯，自以為先王之謀臣，今不見用，常鞅鞅怨望。願王早圖之。」吳王曰：「微子之言，吾亦疑之。」乃使使賜伍子胥屬鏤之劍，曰：「子以此死。」伍子胥仰天嘆曰：「嗟乎！讒臣嚭為亂矣，王乃反誅我。我令若父霸。自若未立時，諸公子爭立，我以死爭之於先王，幾不得立。若既得立，欲分吳國予我，我顧不敢望也。然今若聽諛臣言以殺長者。」乃告其舍人曰：「必樹吾墓上以梓，令可以為器；而抉吾眼縣吳東門之上，以觀越寇之入滅吳也。」乃自剄死。吳王聞之大怒，乃取子胥尸盛以鴟夷革，浮之江中。吳人憐之，為立祠於江上，因命曰胥山。

**汇入说明：** 扩写劝谏、托子、进谗、赐剑和尸体处置，仍与原来的同一次死亡合并。本篇把越国进献联系子贡谋划；本轮已完整对读《仲尼弟子列传》，其[五国游说故事](未定年-子贡游说五国.md)仍有未能统一的时序，不能把整套外交游说都写成已确认的幕后因果。列传托子具体说鲍牧，而现有经传前487年已记鲍牧被杀；正文只保留两书共同支持的鲍氏，不静默证明鲍牧仍活着。伯嚭所说伍员希望吴败是指控，不是伍员真实心理的定论。抉眼是临终要求，本篇未明确叙执行，正文不写成实际取出双眼；江上立祠的日期未明，见不定年材料。死亡归前484年依哀十一年，不将列传前后‘四年’机械套算。

<a id="sj066-author-review"></a>

## 司马迁评论｜不作伍员卒年的事件

太史公说：怨恨给人造成的祸害，真深重啊！即使君王，也不能把这样的怨毒施加于臣下，何况地位相同的人！假如伍子胥当初跟父亲伍奢一同死去，与蝼蚁有什么分别？他舍弃小节之义，洗雪大耻，名声留传后世，令人悲叹。他困在江边、沿路乞食时，心里何曾一刻忘记郢都？所以能够隐忍而成就功名，若非刚烈的丈夫，谁能做到？白公假如不是想自立为君，他的功业谋略，也会有说不尽的地方吧！末句是假设和评价，不是白公曾正式称王的新增记载。


<a id="sj066-cite-046"></a>

**[《史记·伍子胥列传》P024](../../sources/摘录/史记-卷066-伍子胥列传.md#p024)**

> 太史公曰：怨毒之於人甚矣哉！王者尚不能行之於臣下，況同列乎！向令伍子胥從奢俱死，何異螻蟻。棄小義，雪大恥，名垂於後世，悲夫！方子胥窘於江上，道乞食，志豈嘗須臾忘郢邪？故隱忍就功名，非烈丈夫孰能致此哉？白公如不自立為君者，其功謀亦不可勝道者哉！

**本卷说明：** 本文包含白公后事的回顾，作者时代晚于伍员与白公；置于此处仅供读传后阅读，不把司马迁论说定在前484。

<a id="sj066-tang-review"></a>

### 唐代司马贞述赞

司马贞赞述说：进谗的人没有止境，交相使四国陷入混乱。可叹伍氏，遭到这种凶恶的迫害；只有伍员忍住耻辱，立志报复冤仇。他助吴称霸、兴兵，攻楚追逐败军；鞭尸以雪耻，留下抉眼之言，德义也被抛弃。“四国”的具体所指，赞语没有逐一列明；末句“弃德”未明说主语，可联系吴王弃贤，也可联系怨毒之行损德，暂不判定为唯一解释。

<a id="sj066-cite-047"></a>

**[《史记·伍子胥列传》Z001](../../sources/摘录/史记-卷066-伍子胥列传.md#z001)**

> 索隱述贊曰：讒人罔極，交亂四國。嗟彼伍氏，被茲凶慝！員獨忍詬，志復冤毒。霸吳起師，伐楚逐北。鞭尸雪耻，抉眼弃德。

**本卷说明：** 唐赞为司马贞所作。四国未逐一列名，末句弃德主语未明，不据短赞另定一组战国外交事件或一项行为事实。

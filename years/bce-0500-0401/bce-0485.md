<a id="本年纪事"></a>
<a id="event-1"></a>

1. **邾君益逃鲁，继而逃齐。** 春季，邾隐公益来到鲁国避难，随后转往齐国。他与齐有外甥关系，齐成为其新的寄居处。 [[1]](#note-1)

<a id="event-2"></a>

2. **鲁、吴等联合攻齐，齐悼公遇害，吴舟师战败。** 哀公与吴王、邾君、郯君攻齐国南境，驻军鄎。此时齐国内发生弑君，齐悼公阳生死亡消息传到营中，吴王在军门外哭了三日。徐承率吴国舟师准备从海上攻入齐境，被齐军击败，吴军撤回；五月，哀公回鲁，齐国随后安葬悼公。 [[2]](#note-2)

<a id="event-3"></a>

3. **宋军攻郑，晋军攻齐。** 夏季，宋人继续攻郑。赵鞅率晋军进攻齐国，取犁、辕，破坏高唐外郭，军队到赖一带后返回。将士曾要求再次占卜，赵鞅认为已经作过决定，不必重占。 [[3]](#note-3)

<a id="event-4"></a>

4. **卫国公孟彄由齐返回。** 公孟彄从齐国回到卫国，结束这一阶段的流亡。 [[4]](#note-4)

<a id="event-5"></a>

5. **薛惠公去世，秋季下葬。** 夏季，薛伯夷去世；秋季，薛国安葬惠公。 [[5]](#note-5)

<a id="event-6"></a>

6. **吴国再次通知鲁国备战。** 秋季，吴使又到鲁国，要求准备军队。下一年鲁、吴将再度联合伐齐。 [[6]](#note-6)

<a id="event-7"></a>

7. **楚伐陈，季札救陈并与楚将议退。** 冬季，楚公子结率军攻陈。吴国季札带兵来救，对楚将指出，两国争取诸侯，却使百姓承受战事，提出退兵以结束当前冲突。双方没有在此发展成新的大会战。 [[7]](#note-7)

<a id="sj046-tianqi-succession-event"></a>

8. **田乞去世后，田常承接田氏地位，并在简公朝与阚止争权。** 本篇把田乞之卒列在悼公四年，现沿悼公前488年起元附于前485。田常后来与阚止同辅简公，借大斗贷出、小斗收回的粮食施予争取人心，齐人有归田氏的歌谣；御鞅劝简公在两强之间作选择，未获采纳。这些是承继后持续的权力竞争，不把直到前481年的冲突都压在本年。 [[8]](#sj046-tianqi-succession-note)

**《左传》·哀公十年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0485.md#all-20261109-t003)

> 夏，赵鞅帅师伐齐，大夫请卜之。赵孟曰：“吾卜于此起兵，事不再令，卜不袭吉，行也。”于是乎取犁及辕，毁高唐之郭，侵及赖而还。

<a id="sj014-audit-0485-qi-assassin-note"></a>
<a id="卷014补核齐悼公被杀与鲍子称谓"></a>
#### 卷014补核｜齐悼公被杀与鲍子称谓

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0485)。齐栏作“鲍子杀悼公”，《齐太公世家》亦如此；《左传》本年只记齐人弑君，而[前487年第6条](bce-0487.md#event-6)已经记鲍牧被杀。不得未经论证就把本年“鲍子”认定为已死的鲍牧再来弑君；主述保留齐悼公遇害，具体行为人差异留注。

<a id="sj014-audit-0485-wu-zixu-note"></a>
<a id="卷014补核伍子胥死的系年"></a>
#### 卷014补核｜伍子胥死的系年

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0485)。吴栏本年写“诛五员”，五员为伍员异写；经传详细叙事及现有主体在[前484年第4条](bce-0484.md#event-4)。《吴太伯世家》也在伐齐故事中连叙进谏、出使、寄子、赐剑；不以两年排列造两次自尽。

<a id="卷014补核孔子自陈来卫的年次"></a>
#### 卷014补核｜孔子自陈来卫的年次

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0485)。卫栏本年“孔子自陈来”，次年又记归鲁。《卫康叔世家》相接记自陈入卫、九年孔文子问兵及鲁迎仲尼。这里保留表与卫世家的年次，不把《孔子世家》复杂周游顺序都机械缩为前485一年，也不另造一次已确定的返卫。

## 本年纪事

<a id="event-1"></a>

1. **邾君益逃鲁，继而逃齐。**

春季，邾隐公益来到鲁国避难，随后转往齐国。他与齐有外甥关系，齐成为其新的寄居处。 [1](#note-1)

<a id="event-2"></a>

2. **鲁、吴等联合攻齐，齐悼公遇害，吴舟师战败。**

哀公与吴王、邾君、郯君攻齐国南境，驻军鄎。此时齐国内发生弑君，齐悼公阳生死亡消息传到营中，吴王在军门外哭了三日。徐承率吴国舟师准备从海上攻入齐境，被齐军击败，吴军撤回；五月，哀公回鲁，齐国随后安葬悼公。 [2](#note-2)

<a id="event-3"></a>

3. **宋军攻郑，晋军攻齐。**

夏季，宋人继续攻郑。赵鞅率晋军进攻齐国，取犁、辕，破坏高唐外郭，军队到赖一带后返回。将士曾要求再次占卜，赵鞅认为已经作过决定，不必重占。 [3](#note-3)

<a id="event-4"></a>

4. **卫国公孟彄由齐返回。**

公孟彄从齐国回到卫国，结束这一阶段的流亡。 [4](#note-4)

<a id="event-5"></a>

5. **薛惠公去世，秋季下葬。**

夏季，薛伯夷去世；秋季，薛国安葬惠公。 [5](#note-5)

<a id="event-6"></a>

6. **吴国再次通知鲁国备战。**

秋季，吴使又到鲁国，要求准备军队。下一年鲁、吴将再度联合伐齐。 [6](#note-6)

<a id="event-7"></a>

7. **楚伐陈，季札救陈并与楚将议退。**

冬季，楚公子结率军攻陈。吴国季札带兵来救，对楚将指出，两国争取诸侯，却使百姓承受战事，提出退兵以结束当前冲突。双方没有在此发展成新的大会战。 [7](#note-7)

> 吳王既誅伍子胥，遂伐齊。齊鮑氏殺其君悼公而立陽生。吳王欲討其賊，不勝而去。其後二年，吳王召魯衛之君會之橐皋。其明年，因北大會諸侯於黃池，以令周室。越王句踐襲殺吳太子，破吳兵。吳王聞之，乃歸，使使厚幣與越平。後九年，越王句踐遂滅吳，殺王夫差；而誅太宰嚭，以不忠於其君，而外受重賂，與己比周也。

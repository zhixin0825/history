<a id="本年纪事"></a>
<a id="event-1"></a>

1. **杞僖公下葬。** 二月，杞国安葬僖公。 [[1]](#note-1)

<a id="event-2"></a>

2. **宋军反包围郑军，在雍丘取胜。** 郑国许瑕向执政求邑，国内没有合适田邑可给，便获准到国外取地，率军围宋国雍丘。宋将皇瑗反过来包围郑军，逐日推进营垒，郑国来援也战败。二月甲戌，宋军控制了被围郑师，俘获郏张、郑罗等人。 [[2]](#note-2)

<a id="event-3"></a>

3. **齐国取消求吴攻鲁的请求，吴王却转向攻齐。** 齐方派公孟绰通知吴国，不再需要援军攻鲁。夫差答复，去年已经应请，如今又变更，自己将亲自进兵向齐问个明白。冬季，吴使来鲁，要求预备军队参加伐齐。 [[3]](#note-3)

<a id="event-4"></a>

4. **楚国攻陈，宋国再攻郑。** 夏季，楚军进攻已经靠向吴国的陈国。宋公则在雍丘获胜后继续进攻郑国。 [[4]](#note-4)

<a id="event-5"></a>

5. **吴国修邗沟，沟通江、淮水路。** 秋季，吴国修筑邗沟，将长江、淮河之间的水路联系起来。北上诸侯地区的交通条件因此成为吴国经营的一部分。 [[5]](#note-5)

<a id="event-6"></a>

6. **赵鞅议救郑，卜筮后没有出兵。** 晋国赵鞅准备救郑，请史赵、史墨、史龟解释卜兆，阳虎又用《周易》占筮。各人说法不同，但都未赞成与宋作战，晋方最终停止了这次援郑计划。 [[6]](#note-6)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **宋军灭曹，曹伯阳与公孙彊被带走后杀死。** 正月，宋军原准备从曹撤回，殿后的褚师子肥受到曹人辱骂，停住不走。宋公得知后命军队再攻，曹国终于被灭，曹伯阳和司城公孙彊被俘，带回后遭杀。 [[1]](#note-1)

<a id="event-2"></a>

<a id="event-5"></a>

2. **吴因邾事攻鲁，邾君归国后又被吴拘押。** 吴军为邾国攻鲁，鲁、吴在城下议和。吴国准备为邾出兵，流亡的叔孙辄主张攻鲁，公山不狃却反对趁私怨毁故国。三月吴军仍入鲁，经武城、东阳逼近泗水。鲁人准备夜袭吴王驻地，后因伤亡顾虑取消。双方议和时，子服景伯反对立即订城下之盟，主张再等吴军自退，未获接受。鲁、吴最后交换担保，订盟后吴军离开。邾君归国后又被吴拘押，太子革接掌政务。齐国请求吴再出兵攻鲁，鲁遂将邾君益送回。归国后，邾君又与国内发生冲突，吴派太宰子馀讨问，将他囚禁，以荆棘围住居处，让邾国大夫奉太子革掌政。 [[2]](#note-2)

<a id="event-3"></a>

3. **齐国取得讙、阐，又与鲁议和并迎季姬。** 齐悼公在鲁避难时，曾娶季康子的妹妹。即位后要迎她回齐，鲁方因季氏内部的关系没有交人，齐侯发怒。五月，鲍牧率齐军攻鲁，取得讙、阐。秋季两国修好、遣使临盟，齐国迎走季姬；十二月，齐又交回两邑。 [[3]](#note-3)

<a id="event-4"></a>

4. **齐悼公杀胡姬。** 六月，齐悼公听信胡姬仍属安孺子荼一党的告发，杀了胡姬。她此前曾负责送荼离开。 [[4]](#note-4)

<a id="event-6"></a>

5. **鲍牧被逐往潞，途中遭削弱随从后杀死。** 鲍牧向群公子谈到车马兵力，公子们向齐侯告发。齐侯让他到潞待查，出门后又逐次削减其可带走的财产、车乘；到了潞，鲍牧被拘回杀死。 [[5]](#note-6)

<a id="event-7"></a>

6. **杞僖公去世。** 十二月癸亥，杞君过去世，即杞僖公。 [[6]](#note-7)

<a id="sj040-baigong-return-event"></a>

7. **子西从吴召回白公胜，任他为巢大夫。** 胜是太子建之子，曾随伍员流亡吴国，如今获召返，号白公。他爱好武事，能谦下待士，又暗中招求死士，叶公担心其中另有图谋，劝阻召回，未被采纳；胜仍准备报父亲在郑被杀之仇。 [[7]](#sj040-baigong-return-note)

### 2. 吴因邾事攻鲁，邾君归国后又被吴拘押

[返回正文第2条](#event-2)

<a id="sj033-cite-122"></a>

**[《史记·鲁周公世家》P078](../../sources/摘录/史记-卷033-鲁周公世家.md#p078)**

> 吳為鄒伐魯，至城下，盟而去。

本转录缺“八年”，仓内三家注本有；本条依经传与注本分年。 [全卷考证](../../meta/考证/史记-卷033-纪年与异说.md)。

> 吴伐我。

> 吴为邾故，将伐鲁，问于叔孙辄。叔孙辄对曰：“鲁有名而无情，伐之必得志焉。”退而告公山不狃。公山不狃曰：“非礼也。君子违，不適仇国，未臣而有伐之，奔命焉，死之可也。所托也则隐。且夫人之行也，不以所恶废乡。今子以小恶而欲覆宗国，不亦难乎？若使子率，子必辞，王将使我。”子张病之。王问于子洩，对曰：“鲁虽无与立，必有与毙。诸侯将救之，未可以得志焉。晋与齐、楚辅之，是四仇也。。夫鲁，齐、晋之唇，唇亡齿寒，君所知也。不救何为？”三月，吴伐我，子洩率，故道险，从武城。

> 初，武城人或有因于吴竟田焉，拘鄫人之沤菅者，曰：“何故使吾水滋？”及吴师至，拘者道之，以伐武城，克之。王犯尝为之宰，澹臺子羽之父好焉。国人惧。懿子谓景伯：“若之何？”对曰：“吴师来，斯与之战，何患焉？且召之而至，又何求焉？”吴师克东阳而进，舍于五梧，明日舍于蚕室。公宾庚、公甲叔子与战于夷，获叔子与析朱鉏。献于王，王曰：“此同车，必使能，国未可望也。”明日，舍于庚宗，遂次于泗上。微虎欲宵攻王舍，私属徒七百人，三踊于幕庭。卒三百人，有若与焉，及稷门之内。或谓季孙曰：“不足以害吴，而多杀国士，不如已也。”乃止之。吴子闻之，一夕三迁。吴人行成，将盟。景伯曰：“楚人围宋，易子而食，析骸而爨，犹无城下之盟。我未及亏，而有城下之盟，是弃国也。吴轻而远，不能久，将归矣。请少待之。”弗从。景伯负载造于莱门，乃请释子服何于吴，吴人许之。以王子姑曹当之而后止。吴人盟而还。

> 初，武城人或有因于吴竟田焉，拘鄫人之沤菅者，曰：“何故使吾水滋？”及吴师至，拘者道之，以伐武城，克之。王犯尝为之宰，澹臺子羽之父好焉。国人惧。懿子谓景伯：“若之何？”对曰：“吴师来，斯与之战，何患焉？且召之而至，又何求焉？”吴师克东阳而进，舍于五梧，明日舍于蚕室。公宾庚、公甲叔子与战于夷，获叔子与析朱鉏。献于王，王曰：“此同车，必使能，国未可望也。”明日，舍于庚宗，遂次于泗上。微虎欲宵攻王舍，私属徒七百人，三踊于幕庭。卒三百人，有若与焉，及稷门之内。或谓季孙曰：“不足以害吴，而多杀国士，不如已也。”乃止之。吴子闻之，一夕三迁。吴人行成，将盟。景伯曰：“楚人围宋，易子而食，析骸而爨，犹无城下之盟。我未及亏，而有城下之盟，是弃国也。吴轻而远，不能久，将归矣。请少待之。”弗从。景伯负载造于莱门，乃请释子服何于吴，吴人许之。以王子姑曹当之而后止。吴人盟而还。

**《史记·鲁周公世家》·吴为邹伐鲁** · [所核固定版本](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E9%AD%AF%E5%91%A8%E5%85%AC%E4%B8%96%E5%AE%B6.md#ref-ab9977d27ab357)

> 吳爲鄒伐魯，至城下，盟而去。

**说明：** 公山不狃又称子洩。武城旧日拘人、导吴军的插曲是前因；夜袭只是准备，并未实际发动。《鲁周公世家》“吴为邹伐鲁”合在本次，不另造一役。

### 太史公论曹亡

司马迁把曹共公不用僖负羁、却有三百人乘轩车，与后来的公孙彊失政连在一起，批评历代曹君没有建立德政。他又借振铎梦兆感叹曹祀终止；这是作者借故事论史，不能把梦当作亡曹的因果证据。[《索隐》](../../sources/史记三家注/卷035.md#p32)还指出部分传本没有这一论赞。

**[《史记·管蔡世家》P040](../../sources/摘录/史记-卷035-管蔡世家.md#p040)**

> 太史公曰：余尋曹共公之不用僖負羈，乃乘軒者三百人，知唯德之不建。及振鐸之夢，豈不欲引曹之祀者哉？如公孫彊不修厥政，叔鐸之祀忽諸。


<a id="sj035-later-zan"></a>

### 后出的《索隐述赞》

这首篇末赞出自唐代司马贞，以韵语串起管蔡之乱、蔡仲复爵、蔡侯受楚齐打击和曹国兴亡。末句“伯阳梦社”概括伯阳时期的社宫梦兆；主文做梦者是曹国人，并不是曹伯阳本人。它既不是前487年发生的事件，也不是司马迁原论。

**[《史记·管蔡世家》Z001](../../sources/摘录/史记-卷035-管蔡世家.md#z001)**

> 【索隱述贊】武王之弟，管、蔡及霍。周公居相，流言是作。狼跋致艱，鴟鴞討惡。胡能改行，克復其爵。獻舞執楚，遇息禮薄。穆侯虜齊，蕩舟乖謔。曹共輕晉，負羈先覺。伯陽夢社，祚傾振鐸。

# 公元前490年（鲁哀公五年）

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **鲁国修筑毗城。** 春季，鲁国修筑毗地城防。 [[1]](#note-1)

<a id="event-2"></a>

2. **晋军围柏人，范氏、中行氏逃齐。** 春季，晋军围柏人，荀寅与士吉射逃到齐国。范氏家臣张柳朔留下守城，命儿子随主出逃，自己死在柏人。此前王生虽与张柳朔有私怨，仍曾推荐他守柏人，张柳朔此次选择留下，也与这段任用关系有关。 [[2]](#note-2)

<a id="event-3"></a>

3. **齐军伐宋，赵鞅为范氏问题攻卫。** 夏季，齐侯进攻宋国。赵鞅则因卫国支持范氏而出兵攻卫，继而围中牟。 [[3]](#note-3)

<a id="event-4"></a>

4. **齐景公去世，荼继位，其他公子分赴卫、鲁。** 齐景公原配燕姬所生之子早亡，宠姬鬻姒的儿子荼后来得到继承安排。景公病中令国夏、高张立荼，把其他公子置于莱。九月景公去世，十月公子嘉、驹、黔逃卫，鉏和阳生逃鲁。叔还赴齐办理往来，闰月齐国安葬景公。 [[4]](#note-4)

<a id="event-5"></a>

5. **郑国驷秦被杀，郑人议论其使用卿的车服。** 郑国驷秦虽为受宠的大夫，却经常在庭中陈列卿的车服。郑人因而怨恨并杀了他，子思借诗句评论官位与行为应相称。 [[5]](#note-5)

<a id="sj014-audit-0490-qin"></a>

<a id="event-6"></a>

6. **秦悼公元年。** 秦国开始悼公纪年。 [[6]](#note-6)

<a id="sj014-audit-0490-cai"></a>

<a id="event-7"></a>

7. **蔡成侯朔元年。** 蔡昭侯遇害之后，蔡国进入成侯朔元年。 [[7]](#note-7)

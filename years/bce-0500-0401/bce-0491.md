<a id="本年纪事"></a>
<a id="event-1"></a>

1. **蔡昭侯赴吴途中被杀，蔡国随后处置参与者。** 二月，蔡昭侯申准备去吴，大夫们担心又将迁都。公孙翩追射蔡侯，蔡侯逃入民家后去世。文之锴冒箭上前，杀死公孙翩。蔡国随后驱逐公孙辰，并在夏季杀公孙姓等人；十二月才安葬昭侯。 [[1]](#note-1)

<a id="event-2"></a>

2. **秦惠公下葬。** 春季，秦国安葬惠公，接续前一年秦君去世的丧事。 [[2]](#note-2)

<a id="event-3"></a>

3. **宋国扣押小邾君。** 宋人拘捕小邾君。 [[3]](#note-3)

<a id="event-4"></a>

4. **楚军北上，迫晋交出逃亡的戎蛮子。** 楚国整备北线，借吴军可能溯江进攻的说法集兵，突袭梁、霍等地，戎蛮子赤战败逃到晋国阴地。楚军向晋施压，赵鞅因国内未定，决定交人。晋方假借分田、筑城和占卜把戎蛮子引来，连同五名大夫交给楚军。楚国又用宗族留守的安排招集其遗民，俘获带回。 [[4]](#note-4)

<a id="event-5"></a>

5. **鲁国修西郛，亳社随后发生火灾。** 夏季，鲁国修筑西面的外郭。六月辛丑，亳社发生火灾。 [[5]](#note-5)

<a id="event-6"></a>

6. **齐、卫继续救范氏，赵鞅攻下邯郸。** 七月，齐国陈乞、弦施与卫国援军围五鹿，支援范氏。赵鞅九月转围邯郸，十一月邯郸投降，荀寅逃鲜虞，赵稷逃临。十二月齐军接应，再攻取晋国一系列城邑，并将荀寅送到柏人继续立足。 [[6]](#note-6)

<a id="event-7"></a>

7. **滕顷公去世，冬季下葬。** 八月甲寅，滕君结去世；冬季，滕国安葬顷公。 [[7]](#note-7)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **齐、卫围戚，试图解除蒯聩据点。** 春季，齐国国夏与卫国石曼姑率军围攻戚地，并向中山求援。蒯聩仍据戚，卫国君位之争没有因上一年铁战而解决。 [[1]](#note-1)

<a id="event-2"></a>

2. **四月发生地震。** 四月甲午，鲁国记录地震。 [[2]](#note-2)

<a id="event-3"></a>

3. **桓、僖两庙失火，鲁国集中抢救人员、典籍和府库。** 五月辛卯，司铎处起火，火势越过公宫，烧到桓公、僖公之庙。南宫敬叔、子服景伯等分别安排转移书籍、准备车马、守护府库，并以湿帷幕保护建筑。季桓子要求若抢救会伤人便停止，财物以后可以再置，同时强调旧有章程不能丢。孔子当时在陈，听到火灾消息后问是否桓、僖两庙。 [[3]](#note-3)

<a id="event-4"></a>

4. **鲁国修筑启阳。** 季孙斯与叔孙州仇率军修筑启阳城防。 [[4]](#note-4)

<a id="event-5"></a>

5. **宋军再次进攻曹国。** 宋国乐髡率军进攻曹国。曹国与宋国的冲突继续发展，尚未到后来曹国灭亡的阶段。 [[5]](#note-5)

<a id="event-6"></a>

6. **周人杀苌弘，王室也卷入晋国卿族争斗。** 周室刘氏与范氏世代婚姻相联，苌弘辅佐刘文公，周方因而偏向范氏。赵鞅追究此事，六月癸卯，周人杀苌弘。 [[6]](#note-6)

<a id="event-7"></a>

7. **季桓子去世，季氏遗命引发继承争议。** 七月，季孙斯去世。病中他曾吩咐正常，南孺子若生男，便报告并立为继承人；若是女孩，则可立肥。季康子肥先继位，葬后南孺子生男，正常抱孩子到朝廷说明遗命，随后逃卫。康子请求退位，鲁君派人查验，孩子却已被人杀死，正常也没有回来。 [[7]](#note-7)

<a id="event-8"></a>

8. **蔡国把公孙猎放逐到吴国。** 蔡人将大夫公孙猎放逐到吴国。 [[8]](#note-8)

<a id="event-9"></a>

9. **秦君去世，鲁军仍在围邾。** 十月癸卯，秦君去世。冬季，叔孙州仇与仲孙何忌又率军围邾，鲁、邾之间的争端尚未结束。 [[9]](#note-9)

<a id="event-10"></a>

10. **中行氏从朝歌突围，转入邯郸。** 十月，赵鞅围攻朝歌，驻军城南。荀寅让部众由北门入城，自己冲出围军，逃往邯郸。十一月，赵鞅又杀士皋夷，继续清理与范氏相关的势力。 [[10]](#note-10)

<a id="sj014-audit-0492-wei"></a>

<a id="event-11"></a>

11. **卫出公辄元年。** 辄已经在上一年卫灵公去世后被拥立，本年开始出公纪年。 [[11]](#note-11)

<a id="sj014-audit-0492-yan"></a>

<a id="event-12"></a>

12. **燕献公元年。** 燕国在简公之后开始献公纪年。 [[12]](#note-12)

<a id="sj014-audit-0492-confucius"></a>

<a id="event-13"></a>

13. **孔子过宋，受到桓魋威胁后离去。** 《年表》在本年记孔子经过宋国、宋司马桓魋敌视他；《宋微子世家》进一步说孔子改换衣装离开。 [[13]](#note-13)

**说明：** 荀寅即中行文子；不能把他的朝歌突围与下一年邯郸投降混为一次。

<a id="sj014-audit-0492-wei-note"></a>
<a id="卷014补核卫出公辄元年"></a>
#### 卷014补核｜卫出公辄元年。

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0492)。卫栏作“衛出公輒元年”。晋纳蒯聩于戚与辄在位并行，不能因父子争位把两人当成本年共同即位。

<a id="sj014-audit-0492-yan-note"></a>
<a id="卷014补核燕献公元年"></a>
#### 卷014补核｜燕献公元年。

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0492)。燕栏作“燕獻公元年”。燕国早期世系材料较简，不补没有出处的登基日月。

<a id="sj014-audit-0492-confucius-note"></a>
<a id="卷014补核孔子过宋受到桓魋威胁后离去"></a>
#### 卷014补核｜孔子过宋，受到桓魋威胁后离去。

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0492)。宋栏作“二十五孔子过宋，桓魋恶之”，宋世家也系景公二十五年。孔子周游次序与绝对年尚有争议，这里明示据本表系年，不把行程中的每一段都倒推为某月某日。

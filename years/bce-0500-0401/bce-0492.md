1. **卫出公辄元年，齐卫围戚迫蒯聩。** 齐、卫围戚，试图解除蒯聩据点。春季，齐国国夏与卫国石曼姑率军围攻戚地，并向中山求援。蒯聩仍据戚，卫国君位之争没有因上一年铁战而解决。卫出公辄元年。辄已经在上一年卫灵公去世后被拥立，本年开始出公纪年。 [[1]](#note-1)

<a id="event-2"></a>

2. **四月发生地震。** 四月甲午，鲁国记录地震。 [[2]](#note-2)

<a id="event-3"></a>

3. **桓、僖两庙失火，鲁国集中抢救人员、典籍和府库。** 五月辛卯，司铎处起火，火势越过公宫，烧到桓公、僖公之庙。南宫敬叔、子服景伯等分别安排转移书籍、准备车马、守护府库，并以湿帷幕保护建筑。季桓子要求若抢救会伤人便停止，财物以后可以再置，同时强调旧有章程不能丢。孔子当时在陈，听到火灾消息后问是否桓、僖两庙。 [[3]](#note-3)

<a id="event-4"></a>

4. **鲁国修筑启阳。** 季孙斯与叔孙州仇率军修筑启阳城防。 [[4]](#note-4)

<a id="event-5"></a>

5. **宋军再次进攻曹国。** 宋国乐髡率军进攻曹国。曹国与宋国的冲突继续发展，尚未到后来曹国灭亡的阶段。 [[5]](#note-5)

<a id="event-6"></a>

6. **周人杀苌弘，王室也卷入晋国卿族争斗。** 周室刘氏与范氏世代婚姻相联，苌弘辅佐刘文公，周方因而偏向范氏。赵鞅追究此事，六月癸卯，周人杀苌弘。 [[6]](#note-6)

<a id="event-7"></a>

7. **季桓子去世，季氏遗命引发继承争议。** 七月，季孙斯去世。病中他曾吩咐正常，南孺子若生男，便报告并立为继承人；若是女孩，则可立肥。季康子肥先继位，葬后南孺子生男，正常抱孩子到朝廷说明遗命，随后逃卫。康子请求退位，鲁君派人查验，孩子却已被人杀死，正常也没有回来。 围绕孔子的另一支遗命传述说，桓子病中后悔当初失礼，嘱康子掌政后召回老师；康子却受公之鱼劝阻，担心再次用而不终会被诸侯笑，改召冉求。冉求离开时孔子流露思归之意，子贡又嘱冉求得用后引老师归鲁。这些后续与原有季氏继承安排分层，不把它们都说成丧日完成。 [[7]](#note-7)

<a id="event-8"></a>

8. **蔡国把公孙猎放逐到吴国。** 蔡人将大夫公孙猎放逐到吴国。 [[8]](#note-8)

<a id="event-9"></a>

9. **秦君去世，鲁军仍在围邾。** 十月癸卯，秦君去世。冬季，叔孙州仇与仲孙何忌又率军围邾，鲁、邾之间的争端尚未结束。 [[9]](#note-9)

<a id="event-10"></a>

10. **中行氏从朝歌突围，转入邯郸。** 十月，赵鞅围攻朝歌，驻军城南。荀寅让部众由北门入城，自己冲出围军，逃往邯郸。十一月，赵鞅又杀士皋夷，继续清理与范氏相关的势力。 [[10]](#note-10)

<a id="sj014-audit-0492-yan"></a>

<a id="event-12"></a>

11. **燕献公元年。** 燕国在简公之后开始献公纪年。 [[11]](#note-12)

<a id="sj014-audit-0492-confucius"></a>

<a id="event-13"></a>

12. **孔子过宋，受到桓魋威胁后离去。** 他与弟子在大树下习礼，宋司马桓魋想加害，拔去树木。孔子遂离开，宋篇还说他改换衣装。弟子劝迅速逃走，孔子以天赋德于己、不畏桓魋自勉。具体过宋时间在各篇叙序中有差，仍同既有本年主条合读。 [[12]](#note-13)

> 夏五月辛卯，司铎火。火踰公宫，桓、僖灾。救火者皆曰：“顾府。”南宫敬叔至，命周人出御书，俟于宫，曰：“庀女而不在，死。”子服景伯至，命宰人出礼书，以待命，命不共，有常刑。校人乘马，巾车脂辖。百官官备，府库慎守，官人肃给。济濡帷幕，郁攸从之，蒙葺公屋。自大庙始，外内以悛，助所不给。有不用命，则有常刑，无赦。公父文伯至，命校人驾乘车。季桓子至，御公立于象魏之外。命救火者伤人则止，财可为也。命藏《象魏》，曰：“旧章不可亡也。”富父槐至，曰：“无备而官办者，犹拾渖也。”于是乎去表之槀，道还公宫。孔子在陈，闻火，曰：“其桓、僖乎。”

### 7. 季桓子去世，季氏遗命引发继承争议

[返回正文第7条](#event-7)

> 秋七月丙子，季孙斯卒。

> 秋，季孙有疾，命正常曰：“无死。南孺子之子，男也，则以告而立之。女也，则肥也可。”季孙卒，康子即位。既葬，康子在朝。南氏生男，正常载以如朝，告曰：“夫子有遗言，命其圉臣曰：‘南氏生男，则以告于君与大夫而立之。’今生矣，男也，敢告。”遂奔卫。康子请退。公使共刘视之，则或杀之矣，乃讨之。召正常，正常不反。

[史料说明](#7note-7-季桓子去世季氏遗命引发继承争议)

<a id="sj047-cite-056"></a>

**[《史记·孔子世家》P039](../../拆分史书/史记/卷047.md#p039)**

> 秋，季桓子病，輦而見魯城，喟然嘆曰：「昔此國幾興矣，以吾獲罪於孔子，故不興也。」顧謂其嗣康子曰：「我即死，若必相魯；相魯，必召仲尼。」後數日，桓子卒，康子代立。已葬，欲召仲尼。公之魚曰：「昔吾先君用之不終，終為諸侯笑。今又用之，不能終，是再為諸侯笑。」康子曰：「則誰召而可？」曰：「必召冉求。」於是使使召冉求。冉求將行，孔子曰：「魯人召求，非小用之，將大用之也。」是日，孔子曰：「歸乎歸乎！吾黨之小子狂簡，斐然成章，吾不知所以裁之。」子貢知孔子思歸，送冉求，因誡曰「即用，以孔子為招」云。

**本卷说明：** 季桓子卒主条在前492；召求及思归为相接后事，不把“明年”与齐景公卒等错综用来重排父死。

> 夏五月辛卯，司铎火。火踰公宫，桓、僖灾。救火者皆曰：“顾府。”南宫敬叔至，命周人出御书，俟于宫，曰：“庀女而不在，死。”子服景伯至，命宰人出礼书，以待命，命不共，有常刑。校人乘马，巾车脂辖。百官官备，府库慎守，官人肃给。济濡帷幕，郁攸从之，蒙葺公屋。自大庙始，外内以悛，助所不给。有不用命，则有常刑，无赦。公父文伯至，命校人驾乘车。季桓子至，御公立于象魏之外。命救火者伤人则止，财可为也。命藏《象魏》，曰：“旧章不可亡也。”富父槐至，曰：“无备而官办者，犹拾渖也。”于是乎去表之槀，道还公宫。孔子在陈，闻火，曰：“其桓、僖乎。”

**说明：** 书籍、象魏与救火指令按原文分层；不把孔子的提问写成远距离先知，更不把失火自动解释成天谴。

> 季孙斯、叔孙州仇帅师城启阳。

**说明：** 经文只记修城，不把具体施工人数、工程量补成实数。

<a id="6note-6-周人杀苌弘王室也卷入晋国卿族争斗"></a>

**《左传》·哀公三年** · [固定版本原文](../../拆分史书/左传/bce-0492.md#all-20261109-t003)

<a id="7note-7-季桓子去世季氏遗命引发继承争议"></a>
#### [[7]](#note-7) 季桓子去世，季氏遗命引发继承争议。

**《春秋》本经·哀公三年** · [固定版本原文](../../拆分史书/左传/bce-0492.md#all-20261109-j006)

> 秋七月丙子，季孙斯卒。

**《左传》·哀公三年** · [固定版本原文](../../拆分史书/左传/bce-0492.md#all-20261109-t004)

> 秋，季孙有疾，命正常曰：“无死。南孺子之子，男也，则以告而立之。女也，则肥也可。”季孙卒，康子即位。既葬，康子在朝。南氏生男，正常载以如朝，告曰：“夫子有遗言，命其圉臣曰：‘南氏生男，则以告于君与大夫而立之。’今生矣，男也，敢告。”遂奔卫。康子请退。公使共刘视之，则或杀之矣，乃讨之。召正常，正常不反。

**说明：** 凶手在这段原文中没有点名，不直接断言是季康子命人杀婴。正常是人名，非“正常状态”。

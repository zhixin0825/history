# 公元前495年（鲁定公十五年）

> 第一轮白话整理，附原文、异说与归年依据。古历月份不直接等同公历月份；段落覆盖不等于逐句翻译或现代学术校勘完成。

## 本年纪事

<a id="event-1"></a>

1. **邾隐公来朝，子贡议论两君执玉的礼仪。**

正月，邾隐公来朝。朝见时邾君执玉较高、定公接玉较低，子贡由仪态提出对两君未来的担忧。 [1](#note-1)

<a id="event-2"></a>

2. **郊牛被鼠咬死，鲁国改选祭牛，五月行郊祭。**

原定用于郊祭的牛被鼷鼠咬伤后死亡，鲁国重新占卜选择祭牛。五月辛亥，举行郊祭。 [2](#note-2)

<a id="event-3"></a>

3. **楚国灭胡，俘获胡君豹。**

胡国曾趁吴军入楚，掳走邻近楚邑的人口；楚国恢复后，胡君豹又拒绝服从楚国。二月，楚国出兵灭胡，将胡君带回。 [3](#note-3)

<a id="event-4"></a>

4. **五月定公去世，邾君来奔丧。**

五月壬申，定公在高寝去世。邾君随后来鲁参加丧事，鲁国开始办理先君葬礼与继承安排。 [4](#note-4)

<a id="event-5"></a>

5. **郑军在老丘败宋，齐、卫会合谋救。**

郑国罕达率军攻宋，在老丘击败宋军。齐侯、卫侯在渠蒢一带驻扎，商议援救宋国。 [5](#note-5)

<a id="event-6"></a>

6. **姒氏去世，九月下葬。**

七月壬申，姒氏去世；九月辛巳下葬，称定姒。她的死葬礼数没有完全按夫人、小君的常规办理。 [6](#note-6)

<a id="event-7"></a>

7. **八月朔发生日食。**

八月庚辰朔，发生日食。 [7](#note-7)

<a id="event-8"></a>

8. **滕君参加定公葬礼，雨势使下葬延期一天。**

九月，滕君来鲁会葬。丁巳原定安葬定公，因为下雨未能完成；次日戊午，到了下午才得下葬。 [8](#note-8)

<a id="event-9"></a>

9. **鲁国修筑漆城，史官在冬季记入。**

鲁国修筑漆地城防，此项工程列入冬季年条。 [9](#note-9)

<a id="sj031-fuchai-first"></a>

10. **夫差元年，吴国整军准备报越之仇。** 阖闾已于前496年槜李之战负伤身亡，由太子夫差继立；吴国在本年开始以夫差元年纪事。夫差任伯嚭为太宰，练习用兵与射艺，谋划报复越国。具体出兵、夫椒之胜及会稽议和属于[下一年](bce-0494.md#event-3)，不能提前写成本年已经获胜。 [10](#note-10)

> 十有五年春，王正月，邾子来朝。

**《左传》·定公十五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0495.md#L47-L47)

> 十五年春，邾隐公来朝。子贡观焉。邾子执玉高，其容仰。公受玉卑，其容俯。子贡曰：“以礼观之，二君者，皆有死亡焉。夫礼，死生存亡之体也。将左右周旋，进退俯仰，于是乎取之。朝祀丧戎，于是乎观之。今正月相朝，而皆不度，心已亡矣。嘉事不体，何以能久？高仰，骄也；卑俯，替也。骄近乱，替近疾。君为主，其先亡乎。”

**说明：** 执玉礼仪可作为文本所载行为；由此推测骄、病、死亡是子贡的解释，不作项目对人物健康、心智的诊断。定公本年去世也不能证明这种预测方法有效。

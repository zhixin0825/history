1. **卫国逐公叔戌等人，鲁、宋接收流亡者。** 春季，卫侯逐公叔戌及其党羽，公叔戌来鲁，赵阳奔宋。夏季，北宫结也因公叔氏一案逃到鲁国。 [[1]](#note-1)

<a id="event-6"></a>

<a id="event-12"></a>

2. **晋国继续清算卿族冲突，齐等商议援范、中行。** 知氏要求追究董安于，董安于自杀，赵氏与知氏重盟。梁婴父劝知文子借先发难之罪除董安于。知氏向赵鞅追责，董安于表示愿以自己之死换晋国安宁、赵氏安定，随后自缢。赵鞅陈其尸于市，向知氏报告已伏罪，两家重盟。赵氏后来在庙中祭祀董安于。鲁、齐、卫会于牵，商议援助范氏、中行氏。晋军围朝歌，定公与齐侯、卫侯在牵一带会面，商议救援范氏、中行氏。析成鲋、小王桃甲率狄军袭晋，甚至进入绛中作战，未能成功，分别逃往周和朝歌。定公会后回鲁。齐、宋会于洮，再议范氏问题。秋季，齐侯与宋公在洮会合，继续商议与范氏有关的事务。晋军在潞、百泉击败范、中行及郑军。十二月，晋军在潞击败范氏、中行氏部队，俘获籍秦、高彊。随后又在百泉击败郑军和范氏军，朝歌战线仍在延续。 [[2]](#note-2)

<a id="event-3"></a>

3. **楚、陈联合灭顿。** 顿君牂想转而服从晋国，背离楚国并断绝与陈的友好。二月，楚国公子结、陈国公孙佗人联合出兵灭顿，俘获顿君。 [[3]](#note-3)

<a id="event-4"></a>

4. **越军在槜李击败吴军，阖庐伤重去世。** 允常此前已与阖庐相互攻伐，去世后由儿子勾践继承越君之位。越人的先世传说追溯到禹与少康庶子受封会稽、守奉禹祀，并记断发文身、开辟草莽；这些是登场以前的族源叙述，不据二十余世推定建国年份。五月，吴国攻越，勾践在槜李迎战。越军先遣死士冲击，未动摇吴阵，又使罪人列队自刭，吸引吴军目光，主力乘机进攻，击败吴军。灵姑浮击伤阖庐，阖庐退到陉去世。临死前，他要求夫差不要忘记父亲死于这场战争。夫差继位后整顿战射，伯嚭担任太宰，报复越国成为此后行动的主线。 [[4]](#note-4)

<a id="event-7"></a>

5. **周王派石尚送来祭肉。** 周天王派石尚来鲁，送来祭祀所分的脤肉，维持王室与诸侯的礼仪往来。 [[5]](#note-7)

<a id="event-8"></a>

6. **卫太子蒯聩谋害南子未成，逃宋；公孟彄也出奔。** 卫侯替夫人南子召宋朝相会。太子蒯聩经过宋境，听到讥刺歌谣，便令戏阳速在朝见南子时动手。见面时蒯聩几次示意，戏阳速没有行动，南子察觉后向卫侯呼救。蒯聩逃宋，党羽被逐；公孟彄先逃郑，后来又到齐。 [[6]](#note-8)

<a id="event-9"></a>

7. **宋公子辰从萧来到鲁国。** 宋公子辰离开此前据守的萧，来到鲁国避难。 [[7]](#note-9)

<a id="event-10"></a>

8. **鲁国大蒐于比蒲，邾君前来会见。** 鲁国在比蒲举行大蒐，邾君前来会见定公。 [[8]](#note-10)

<a id="event-11"></a>

9. **鲁国修筑莒父、霄两地城防。** 鲁国在莒父与霄修城，经营地方防御。 [[9]](#note-11)

<a id="sj014-audit-0496-cao"></a>

<a id="event-13"></a>

10. **曹伯阳任公孙彊为司城。** 公孙彊善射猎，向曹伯阳献白雁，得到赏识。他随即同曹伯阳谈论国事，获任司城，参与政务。 [[10]](#note-13)

### 4. 越军在槜李击败吴军，阖庐伤重去世

[返回正文第4条](#event-4)

> 五月，於越败吴于槜李。

> 吴子光卒。

> 吴伐越。越子勾践御之，陈于槜李。勾践患吴之整也，使死士再，禽焉，不动。使罪人三行，属剑于颈，而辞曰：“二君有治，臣奸旗鼓，不敏于君之行前，不敢逃刑，敢归死。”遂自刭也。师属之目，越子因而伐之，大败之。灵姑浮以戈击阖庐，阖庐伤将指，取其一屦。还卒于陉，去槜李七里。夫差使人立于庭，苟出入，必谓己曰：“夫差，而忘越王之杀而父乎？”则对曰：“唯，不敢忘！”三年，乃报越。

<a id="sj066-cite-028"></a>

**[《史记·伍子胥列传》P016](../../拆分史书/史记/卷066.md#part-1-p016)**

> 後五年，伐越。越王句踐迎擊，敗吳於姑蘇，傷闔廬指，軍卻。闔廬病創將死，謂太子夫差曰：「爾忘句踐殺爾父乎？」夫差對曰：「不敢忘。」是夕，闔廬死。夫差既立為王，以伯嚭為太宰，習戰射。二年後伐越，敗越於夫湫。越王句踐乃以餘兵五千人棲於會稽之上，使大夫種厚幣遺吳太宰嚭以請和，求委國為臣妾。吳王將許之。伍子胥諫曰：「越王為人能辛苦。今王不滅，後必悔之。」吳王不聽，用太宰嚭計，與越平。

**本卷说明：** 本篇姑苏，正义明校檇李，正文沿经传槜李；“是夕卒”与经传退至陉后死的细节不强拼。夫差继位后习战射为后续，二年后伐越另接前494。

### 公孙彊登场以前的亡曹梦兆

这则故事说，一个曹人梦见众君子在社宫商议灭曹，曹叔振铎请求等公孙彊出现；梦者醒后遍寻不见此人，便告诫儿子以后听到他执政就离国。主文一面写“伯阳三年”，后文又说“及伯阳即位”，自身先后不顺；《左传》只作“初”的回顾。故事保存在公孙彊有据登场的前496年，表示阅读位置，不证明梦发生在这一年或前499年，也不把梦兆视为亡国原因。

**[《史记·管蔡世家》P038](../../拆分史书/史记/卷035.md#p038)**

> 伯陽三年，國人有夢眾君子立于社宮，謀欲亡曹；曹叔振鐸止之，請待公孫彊，許之。旦，求之曹，無此人。夢者戒其子曰：「我亡，爾聞公孫彊為政，必去曹，無離曹禍。」及伯陽即位，好田弋之事。

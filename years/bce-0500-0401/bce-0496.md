## 本年纪事

<a id="event-1"></a>

1. **卫国逐公叔戌等人，鲁、宋接收流亡者。**

春季，卫侯逐公叔戌及其党羽，公叔戌来鲁，赵阳奔宋。夏季，北宫结也因公叔氏一案逃到鲁国。 [1](#note-1)

<a id="event-2"></a>

2. **知氏要求追究董安于，董安于自杀，赵氏与知氏重盟。**

梁婴父劝知文子借先发难之罪除董安于。知氏向赵鞅追责，董安于表示愿以自己之死换晋国安宁、赵氏安定，随后自缢。赵鞅陈其尸于市，向知氏报告已伏罪，两家重盟；赵氏后来在庙中祭祀董安于。 [2](#note-2)

<a id="event-3"></a>

3. **楚、陈联合灭顿。**

顿君牂想转而服从晋国，背离楚国并断绝与陈的友好。二月，楚国公子结、陈国公孙佗人联合出兵灭顿，俘获顿君。 [3](#note-3)

<a id="event-4"></a>

4. **越军在槜李击败吴军，阖庐伤重去世。**

五月，吴国攻越，勾践在槜李迎战。越军先遣死士冲击，未动摇吴阵，又使罪人列队自刭，吸引吴军目光，主力乘机进攻，击败吴军。灵姑浮击伤阖庐，阖庐退到陉去世。夫差继位后反复提醒自己不要忘记父亲之死，准备报越。

临死前，阖庐向夫差提起勾践，要求儿子不要忘记父亲因这场战争而死。夫差继位后整顿战射，伯嚭在新王身边担任太宰，对越国的报复成为吴国此后行动的主线。 [4](#note-4)

<a id="event-5"></a>

5. **鲁、齐、卫会于牵，商议援助范氏、中行氏。**

晋军围朝歌，定公与齐侯、卫侯在牵一带会面，商议救援范氏、中行氏。析成鲋、小王桃甲率狄军袭晋，甚至进入绛中作战，未能成功，分别逃往周和朝歌。定公会后回鲁。 [5](#note-5)

<a id="event-6"></a>

6. **齐、宋会于洮，再议范氏问题。**

秋季，齐侯与宋公在洮会合，继续商议与范氏有关的事务。 [6](#note-6)

<a id="event-7"></a>

7. **周王派石尚送来祭肉。**

周天王派石尚来鲁，送来祭祀所分的脤肉，维持王室与诸侯的礼仪往来。 [7](#note-7)

<a id="event-8"></a>

8. **卫太子蒯聩谋害南子未成，逃宋；公孟彄也出奔。**

卫侯替夫人南子召宋朝相会。太子蒯聩经过宋境，听到讥刺歌谣，便令戏阳速在朝见南子时动手。见面时蒯聩几次示意，戏阳速没有行动，南子察觉后向卫侯呼救。蒯聩逃宋，党羽被逐；公孟彄先逃郑，后来又到齐。 [8](#note-8)

<a id="event-9"></a>

9. **宋公子辰从萧来到鲁国。**

宋公子辰离开此前据守的萧，来到鲁国避难。 [9](#note-9)

<a id="event-10"></a>

10. **鲁国大蒐于比蒲，邾君前来会见。**

鲁国在比蒲举行大蒐，邾君前来会见定公。 [10](#note-10)

<a id="event-11"></a>

11. **鲁国修筑莒父、霄两地城防。**

鲁国在莒父与霄修城，经营地方防御。 [11](#note-11)

<a id="event-12"></a>

12. **晋军在潞、百泉击败范、中行及郑军。**

十二月，晋军在潞击败范氏、中行氏部队，俘获籍秦、高彊。随后又在百泉击败郑军和范氏军，朝歌战线仍在延续。 [12](#note-12)

<a id="sj014-audit-0496-cao"></a>
**曹伯阳任公孙彊为司城。** 公孙彊善射猎，献雁受到曹伯阳赏识，进而被任为司城，参与政事。年表又以旧日梦兆串起一户人家的迁离，作为曹亡的伏笔。 [原文与说明](#sj014-audit-0496-cao-note)

> 梁婴父恶董安于，谓知文子曰：“不杀安于，使终为政于赵氏，赵氏必得晋国。盍以其先发难也，讨于赵氏？”文子使告于赵孟曰：“范、中行氏虽信为乱，安于则发之，是安于与谋乱也。晋国有命，始祸者死。二子既伏其罪矣，敢以告。”赵孟患之。安于曰：“我死而晋国宁，赵氏定，将焉用生？人谁不死，吾死莫矣。”乃缢而死。赵孟尸诸市而告于知氏曰：“主命戮罪人，安于既伏其罪矣，敢以告。”知伯从赵孟盟，而后赵氏定，祀安于于庙。

### 卷014补核｜曹伯阳任公孙彊为司城。

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0496)。曹栏与《管蔡世家》伯阳六年相合。任官与梦者之子出走有文本出处，但梦见先祖预知亡国是史书叙事，不当成已验证预言；相关梦的前情见前499年专注。

<a id="sj014-audit-0496-zichan-note"></a>
### 卷014补核｜子产卒年相差二十六年

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0496)。郑栏声公五年记子产卒，对应前496；《左传》昭二十明确子产病卒、子大叔继政，主述在[前522年第10条](../bce-0600-0501/bce-0522.md#event-10)，相差26年。《郑世家》也把子产卒系声公五年，不能把同书重述算作独立证据以推翻经传。[维基百科子产](https://zh.wikipedia.org/wiki/子產)和[百度百科子产](https://wapbaike.baidu.com/item/子产/1102614)均采用前522。吉本道雅[《孔子世家疏证》](https://repository.kulib.kyoto-u.ac.jp/dspace/bitstream/2433/261862/1/lit60_1.pdf)讨论《史记》可能把孔子过郑的行程牵合到这一卒年；这是解释，不据此改写年表原字。

<a id="sj014-audit-0496-confucius-chen-note"></a>
### 卷014补核｜孔子到陈的年次

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0496)。陈栏“六孔子来”是表的具体系年；孔子周游的多段经历在《孔子世家》中常以“居顷之”“明年”等相接，难与各篇君年完全一致。本注保留本表前496到陈，不倒推出离卫、过匡、蒲盟各自的确切月日，也不借此替子产卒于本年背书。

<a id="event-1"></a>

1. **齐、卫进攻晋国河内，齐侯以假警报试探同行的卫侯。** 春季，齐、卫在垂葭驻扎。齐国邴意兹认为晋军传令、集结需要时日，主张趁隙渡河进攻河内。齐侯随后与卫侯同宴，预备载甲战车，令人谎报晋军到来，自己披甲与卫侯同乘，直到有人说明并无晋军才停下。 [[1]](#note-1)

<a id="event-2"></a>

2. **孔子离开鲁国，前往卫国。** 齐国担心鲁因用孔子而强，先送女乐八十人、彩马三十驷试图扰乱其政。季桓子反复往看，又引鲁君游观，数日不理政。子路催老师离开，孔子仍等郊祭后是否按礼分肉，认为礼尚存便可留下；祭后终于不分，才去鲁，宿于屯。师己送行，孔子以歌讽刺妇人言语请托可能逼人离去、使事败坏，季桓子听到转述后知道是在责己。初到卫，他住子路妻兄颜浊邹家，受与在鲁相当的粟禄；后来被进谗、遭人窥察，住了十个月后再离开。后续居卫月数不都归作本年完成，原篇定十四的相接纪年亦另存差数。 [[2]](#note-2)

<a id="event-3"></a>

3. **鲁国筑蛇渊囿，又在比蒲举行大蒐。** 夏季，鲁国修建蛇渊苑囿，并在比蒲举行大规模田猎检阅。 [[3]](#note-3)

<a id="event-4"></a>

4. **卫军再次攻曹。** 卫国公孟彄又率军攻打曹国，接续上一年的两国冲突。 [[4]](#note-4)

<a id="event-5"></a>

<a id="event-6"></a>

<a id="event-7"></a>

5. **赵、范、中行争斗爆发，赵鞅退晋阳后回绛。** 赵鞅与邯郸午争迁五百家，邯郸叛乱。赵鞅要求邯郸午交出卫国贡献的五百家，迁到晋阳。邯郸午起初答应，族人却反对失去与卫联系的人口资源，迁民安排遂生冲突。赵鞅召午至晋阳拘捕并杀死，让邯郸另立继承人。赵稷、涉宾则据邯郸起兵。范氏、中行氏攻赵氏，赵鞅退入晋阳。六月，晋军围邯郸。荀寅与邯郸午有亲属关系，又与范吉射通婚，两家不愿参围。董安于劝赵鞅先作准备，赵鞅顾虑晋国有先发难者死的禁令。范氏、中行氏攻赵氏宫室，赵鞅逃入晋阳，晋人继而围他。荀跞等主张追究范氏与中行氏的责任。范、中行攻晋君失败，退朝歌。赵鞅返回绛。十一月，荀跞、韩不信、魏曼多奉晋君命进攻范氏、中行氏，起初未克。两家继而不听高彊劝告，转攻晋君，遭国人支持晋君反击而败，退到朝歌。韩、魏为赵鞅请求赦免。十二月，赵鞅获赦回到绛、恢复职位，并在公宫盟誓。 [[5]](#note-5)

<a id="event-8"></a>

6. **薛君比被杀。** 冬季，薛国国君比被本国人杀死。 [[6]](#note-8)

<a id="event-9"></a>

7. **卫国公叔氏与国君、南子一方冲突加深。** 公叔文子此前曾担心家族富有招忌，史䲡劝他保持臣职。文子去世后，卫侯开始厌恶富有的公叔戌；公叔戌又要排除夫人南子的党羽，南子于是向卫侯指控他准备作乱。 [[7]](#note-9)

> 趙簡子疾，五日不知人，大夫皆懼。醫扁鵲視之，出，董安于問。扁鵲曰：「血脈治也，而何怪！在昔秦繆公嘗如此，七日而寤。寤之日，告公孫支與子輿曰：『我之帝所甚樂。吾所以久者，適有學也。帝告我：「晉國將大亂，五世不安；其後將霸，未老而死；霸者之子且令而國男女無別。」』公孫支書而藏之，秦讖於是出矣。獻公之亂，文公之霸，而襄公敗秦師於殽而歸縱淫，此子之所聞。今主君之疾與之同，不出三日疾必閒，閒必有言也。」

**本卷说明：** **简子病梦与神遇传说：** 简子病重，五天不省人事，大夫惊惧。扁鹊看诊后告诉董安于，血脉正常，并不奇怪；秦穆公曾昏迷七日，醒来称游于上帝处，听到晋国五世不安、后来将有霸主而未老便死、霸者之子执政而男女失别的预言，穆公将这些告诉公孙支和子舆，公孙支记录收藏，由此形成秦国谶言。扁鹊把晋献公之乱、文公称霸和襄公殽败秦后放回秦将等解释为旧谶应验，并说简子不出三日也会苏醒而有所言。这是医疗故事与政治谶言相连的叙述，不能把病情预测或梦中神命当现代医学、年代事实。 没有独立确年，附范中行之乱前的叙事背景；预言不能反作当年军事决策证据。

> 居二日半，簡子寤。語大夫曰：「我之帝所甚樂，與百神游於鈞天，廣樂九奏萬舞，不類三代之樂，其聲動人心。有一熊欲來援我，帝命我射之，中熊，熊死。又有一羆來，我又射之，中羆，羆死。帝甚喜，賜我二笥，皆有副。吾見兒在帝側，帝屬我一翟犬，曰：『及而子之壯也，以賜之。』帝告我：『晉國且世衰，七世而亡，嬴姓將大敗周人於范魁之西，而亦不能有也。今余思虞舜之勳，適余將以其胄女孟姚配而七世之孫。』」董安于受言而書藏之。以扁鵲言告簡子，簡子賜扁鵲田四萬畝。

**本卷说明：** **简子病梦与神遇传说：** 再过两天半，简子醒来，说与百神游于钧天，在上帝处听九奏万舞之乐，声动人心而不同三代之乐，奉命射死熊与罴，受赐成双的两个竹箱，又见一个孩子和一条狄犬，上帝许把狄犬赐给长成后的孩子。他还转述晋将七世而亡、嬴姓将在范魁以西败周人而不能据有，以及舜裔孟姚将配自己七世孙的预言。董安于记录收藏，并报告扁鹊所言，简子赐扁鹊四万亩田。梦、预言和赐田属于同一传述；世数与后世人物的对应不可倒算成确定神谕发生年。 没有独立确年，附范中行之乱前的叙事背景；预言不能反作当年军事决策证据。

> 秋七月，范氏、中行氏伐赵氏之宫，赵鞅奔晋阳。晋人围之。范皋夷无宠于范吉射，而欲为乱于范氏。梁婴父嬖于知文子，文子欲以为卿。韩简子与中行文子相恶，魏襄子亦与范昭子相恶。故五子谋，将逐荀寅而以梁婴父代之，逐范吉射而以范皋夷代之。荀跞言于晋侯曰：“君命大臣，始祸者死，载书在河。今三臣始祸，而独逐鞅，刑已不钧矣。请皆逐之。”

**说明：** 经文对赵鞅入晋阳书“叛”，传文补其遭攻击后的过程；两层保留，不用一个字替代战事前因。荀跞又称知文子，不同于中行文子荀寅。




<a id="7note-7-范中行攻晋君失败退朝歌赵鞅返回绛"></a>
#### [[7]](#note-7) 范、中行攻晋君失败，退朝歌；赵鞅返回绛。

**《春秋》·定公十三年** · [固定版本原文](../../拆分史书/左传/bce-0497.md#all-20261109-j006)

> 冬，晋荀寅、士吉射入于朝歌以叛。

**《春秋》·定公十三年** · [固定版本原文](../../拆分史书/左传/bce-0497.md#all-20261109-j007)

> 晋赵鞅归于晋。

**《左传》·定公十三年** · [固定版本原文](../../拆分史书/左传/bce-0497.md#all-20261109-t005)

> 冬十一月，荀跞、韩不信、魏曼多奉公以伐范氏、中行氏，弗克。二子将伐公，齐高彊曰：“三折肱知为良医。唯伐君为不可，民弗与也。我以伐君在此矣。三家未睦，可尽克也。克之，君将谁与？若先伐君，是使睦也。”弗听，遂伐公。国人助公，二子败，从而伐之。丁未，荀寅、士吉射奔朝歌，韩、魏以赵氏为请。十二月辛未，赵鞅入于绛，盟于公宫。

**说明：** 归绛不等于内战已经结束，范、中行仍据朝歌，下一年继续作战。高彊以自己曾攻齐君失败作劝，是此前经历的回叙。

<a id="9note-9-卫国公叔氏与国君南子一方冲突加深"></a>
#### [[9]](#note-9) 卫国公叔氏与国君、南子一方冲突加深。

**《左传》·定公十三年** · [固定版本原文](../../拆分史书/左传/bce-0497.md#all-20261109-t006)

> 初，卫公叔文子朝而请享灵公，退，见史而告之。史䲡曰：“子必祸矣，子富而君贪，罪其及子乎。”文子曰：“然。吾不先告子，是吾罪也。君既许我矣，其若之何？”史䲡曰：“无害。子臣，可以免。富而能臣，必免于难，上下同之。戌也骄，其亡乎。富而不骄者鲜，吾唯子之见。骄而不亡者，未之有也。戌必与焉。”及文子卒，卫侯始恶于公叔戌，以其富也。公叔戌又将去夫人之党，夫人愬之曰：“戌将为乱。”

**说明：** 前半为旧事，后半交代下一年公叔戌出奔的前因，不把被逐也提前到本年。工作本史氏人名字形有缺字，原文保留。

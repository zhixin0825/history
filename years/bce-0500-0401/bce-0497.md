<a id="本年纪事"></a>
<a id="event-1"></a>

1. **齐、卫进攻晋国河内，齐侯以假警报试探同行的卫侯。** 春季，齐、卫在垂葭驻扎。齐国邴意兹认为晋军传令、集结需要时日，主张趁隙渡河进攻河内。齐侯随后与卫侯同宴，预备载甲战车，令人谎报晋军到来，自己披甲与卫侯同乘，直到有人说明并无晋军才停下。 [[1]](#note-1)

<a id="event-2"></a>

2. **孔子离开鲁国，前往卫国。** 季桓子接受齐国送来的女乐，连续数日没有照常朝政。郊祭以后，礼肉分送又出现缺失，孔子遂离开鲁国，转到卫国寻求施展主张的机会。 [[2]](#note-2)

<a id="event-3"></a>

3. **鲁国筑蛇渊囿，又在比蒲举行大蒐。** 夏季，鲁国修建蛇渊苑囿，并在比蒲举行大规模田猎检阅。 [[3]](#note-3)

<a id="event-4"></a>

4. **卫军再次攻曹。** 卫国公孟彄又率军攻打曹国，接续上一年的两国冲突。 [[4]](#note-4)

<a id="event-5"></a>

5. **赵鞅与邯郸午争迁五百家，邯郸叛乱。** 赵鞅要求邯郸午交出卫国贡献的五百家，迁到晋阳。邯郸午起初答应，族人却反对失去与卫联系的人口资源，迁民安排遂生冲突。赵鞅召午至晋阳拘捕并杀死，让邯郸另立继承人；赵稷、涉宾则据邯郸起兵。 [[5]](#note-5)

<a id="event-6"></a>

6. **范氏、中行氏攻赵氏，赵鞅退入晋阳。** 六月，晋军围邯郸。荀寅与邯郸午有亲属关系，又与范吉射通婚，两家不愿参围。董安于劝赵鞅先作准备，赵鞅担心晋国“先发难者死”的禁令，未同意先动手。七月，范氏、中行氏攻击赵氏宫室，赵鞅逃入晋阳，晋人继而围他。荀跞等提出，不能只逐赵鞅而不追究另外两家。 [[6]](#note-6)

<a id="event-7"></a>

7. **范、中行攻晋君失败，退朝歌；赵鞅返回绛。** 十一月，荀跞、韩不信、魏曼多奉晋君命进攻范氏、中行氏，起初未克。两家继而不听高彊劝告，转攻晋君，遭国人支持晋君反击而败，退到朝歌。韩、魏为赵鞅请求赦免；十二月，赵鞅获赦回到绛、恢复职位，并在公宫盟誓。 [[7]](#note-7)

<a id="event-8"></a>

8. **薛君比被杀。** 冬季，薛国国君比被本国人杀死。 [[8]](#note-8)

<a id="event-9"></a>

9. **卫国公叔氏与国君、南子一方冲突加深。** 公叔文子此前曾担心家族富有招忌，史䲡劝他保持臣职。文子去世后，卫侯开始厌恶富有的公叔戌；公叔戌又要排除夫人南子的党羽，南子于是向卫侯指控他准备作乱。 [[9]](#note-9)

### 6. 范氏、中行氏攻赵氏，赵鞅退入晋阳

[返回正文第6条](#event-6)

> 秋，晋赵鞅入于晋阳以叛。

> 夏六月，上军司马籍秦围邯郸。邯郸午，荀寅之甥也；荀寅，范吉射之姻也。而相与睦，故不与围邯郸，将作乱。董安于闻之，告赵孟曰：“先备诸。”赵孟曰：“晋国有命，始祸者死，为后可也。”安于曰：“与其害于民，宁我独死。请以我说。”赵孟不可。

> 秋七月，范氏、中行氏伐赵氏之宫，赵鞅奔晋阳。晋人围之。范皋夷无宠于范吉射，而欲为乱于范氏。梁婴父嬖于知文子，文子欲以为卿。韩简子与中行文子相恶，魏襄子亦与范昭子相恶。故五子谋，将逐荀寅而以梁婴父代之，逐范吉射而以范皋夷代之。荀跞言于晋侯曰：“君命大臣，始祸者死，载书在河。今三臣始祸，而独逐鞅，刑已不钧矣。请皆逐之。”

### 9. 卫国公叔氏与国君、南子一方冲突加深

[返回正文第9条](#event-9)

> 初，卫公叔文子朝而请享灵公，退，见史而告之。史䲡曰：“子必祸矣，子富而君贪，罪其及子乎。”文子曰：“然。吾不先告子，是吾罪也。君既许我矣，其若之何？”史䲡曰：“无害。子臣，可以免。富而能臣，必免于难，上下同之。戌也骄，其亡乎。富而不骄者鲜，吾唯子之见。骄而不亡者，未之有也。戌必与焉。”及文子卒，卫侯始恶于公叔戌，以其富也。公叔戌又将去夫人之党，夫人愬之曰：“戌将为乱。”

#### 卷024｜音乐史事的互见与归年

[卷024 P002](../../sources/摘录/史记-卷024-乐书.md#p002)说孔子不能与齐优并容于鲁，接本页[女乐与离鲁的既有事件](#event-2)。[《论语·微子》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%AB%96%E8%AA%9E-%E5%BE%AE%E5%AD%90.md#ref-67ce2c19f15aa9)亦记齐人馈女乐、季桓子三日不朝、孔子行；这里仍采用本页已说明的定公十三年暂定年，不以《乐书》没有年次的概述消除定公十二／十三／十四年的异说。

同段“退正乐”“作五章以刺时”不是一次有明确年月的活动记录；五章的篇目与“彼妇人之口”等引文见三家注的解释，不能把所有讽歌和晚年整理音乐都定在本次离鲁之日。归鲁后的音乐整理互见[前484年说明](bce-0484.md#sj024-note)。

<a id="5note-5-赵鞅与邯郸午争迁五百家邯郸叛乱"></a>
#### [[5]](#note-5) 赵鞅与邯郸午争迁五百家，邯郸叛乱。

**《左传》·定公十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0497.md#all-20261109-t002)

> 晋赵鞅谓邯郸午曰：“归我卫贡五百家，吾舍诸晋阳。”午许诺。归告其父兄，父兄皆曰：“不可。卫是以为邯郸，而寘诸晋阳，绝卫之道也。不如侵齐而谋之。”乃如之，而归之于晋阳。赵孟怒，召午而囚诸晋阳。使其从者说剑而入，涉宾不可。乃使告邯郸人曰：“吾私有讨于午也，二三子唯所欲立。”遂杀午。赵稷、涉宾以邯郸叛。

**说明：** “五百家”为家户，不直接等同五百人；交付经过在传文中句意复杂，正文不加编一个已证实的人口转运日期。




<a id="6note-6-范氏中行氏攻赵氏赵鞅退入晋阳"></a>
#### [[6]](#note-6) 范氏、中行氏攻赵氏，赵鞅退入晋阳。

**《春秋》·定公十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0497.md#all-20261109-j005)

> 秋，晋赵鞅入于晋阳以叛。

**《左传》·定公十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0497.md#all-20261109-t003)

> 夏六月，上军司马籍秦围邯郸。邯郸午，荀寅之甥也；荀寅，范吉射之姻也。而相与睦，故不与围邯郸，将作乱。董安于闻之，告赵孟曰：“先备诸。”赵孟曰：“晋国有命，始祸者死，为后可也。”安于曰：“与其害于民，宁我独死。请以我说。”赵孟不可。

**《左传》·定公十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0497.md#all-20261109-t004)

> 秋七月，范氏、中行氏伐赵氏之宫，赵鞅奔晋阳。晋人围之。范皋夷无宠于范吉射，而欲为乱于范氏。梁婴父嬖于知文子，文子欲以为卿。韩简子与中行文子相恶，魏襄子亦与范昭子相恶。故五子谋，将逐荀寅而以梁婴父代之，逐范吉射而以范皋夷代之。荀跞言于晋侯曰：“君命大臣，始祸者死，载书在河。今三臣始祸，而独逐鞅，刑已不钧矣。请皆逐之。”

**说明：** 经文对赵鞅入晋阳书“叛”，传文补其遭攻击后的过程；两层保留，不用一个字替代战事前因。荀跞又称知文子，不同于中行文子荀寅。

**《左传》·定公十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0497.md#all-20261109-t006)

> 初，卫公叔文子朝而请享灵公，退，见史而告之。史䲡曰：“子必祸矣，子富而君贪，罪其及子乎。”文子曰：“然。吾不先告子，是吾罪也。君既许我矣，其若之何？”史䲡曰：“无害。子臣，可以免。富而能臣，必免于难，上下同之。戌也骄，其亡乎。富而不骄者鲜，吾唯子之见。骄而不亡者，未之有也。戌必与焉。”及文子卒，卫侯始恶于公叔戌，以其富也。公叔戌又将去夫人之党，夫人愬之曰：“戌将为乱。”

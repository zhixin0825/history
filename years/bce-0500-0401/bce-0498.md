<a id="本年纪事"></a>
<a id="event-1"></a>

1. **薛襄公去世，夏季下葬。** 春季，薛伯定去世；夏季，薛国安葬襄公。 [[1]](#note-1)

<a id="event-2"></a>

2. **郈、费城防被毁，费人反攻鲁都后败退。** 仲由任季氏家宰，参与拆毁三家大邑城防的安排。叔孙氏先拆郈。轮到费时，公山不狃、叔孙辄带费人袭鲁都，定公与三家宗主退入季氏宫中，登武子之台。孔丘命申句须、乐颀反击，国人追到姑蔑，击败费军；两名首领逃齐，费的城防随后也被拆毁。 拆城方案以限制臣下私甲、强邑为目标；孔子提出大夫不应有过强城防的原则，仲由参与实际执行。 [[2]](#note-2)

<a id="event-3"></a>

3. **卫军攻曹、克郊，滑罗坚持在阵列中殿后。** 卫国公孟彄率军攻曹，攻下郊地。撤退时滑罗担任殿后，没有脱离阵列卖弄勇武，御者因此讥他，他回答宁可被说不勇，也不要平白冒进。 [[3]](#note-3)

<a id="event-4"></a>

4. **秋季举行大雩。** 秋季，鲁国举行大雩祈雨。 [[4]](#note-4)

<a id="event-5"></a>

5. **定公与齐侯在黄结盟，十一月发生日食。** 十月癸亥，定公与齐侯在黄盟誓。十一月丙寅朔，发生日食，随后经文记定公由黄返回。 [[5]](#note-5)

<a id="event-6"></a>

6. **定公围攻成邑，未能攻下。** 孟氏家臣公敛处父认为成是孟氏的保障，劝孟懿子不要拆城。十二月，定公出兵围成，没有攻克，随后回国，拆除三家大邑城防的计划停在这里。 [[6]](#note-6)

**[《史记·孔子世家》P018](../../sources/摘录/史记-卷047-孔子世家.md#p018)**

> 定公十三年夏，孔子言於定公曰：「臣無藏甲，大夫毋百雉之城。」使仲由為季氏宰，將墮三都。於是叔孫氏先墮郈。季氏將墮費，公山不狃、叔孫輒率費人襲魯。公與三子入于季氏之宮，登武子之臺。費人攻之，弗克，入及公側。孔子命申句須、樂頎下伐之，費人北。國人追之，敗諸姑蔑。二子奔齊，遂墮費。

**本卷说明：** 本篇定十三直算前497；经传明定十二，主事归前498，不能于497再拆一次费。

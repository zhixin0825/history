## 本年纪事

<a id="event-1"></a>

1. **薛襄公去世，夏季下葬。**

春季，薛伯定去世；夏季，薛国安葬襄公。 [1](#note-1)

<a id="event-2"></a>

2. **郈、费城防被毁，费人反攻鲁都后败退。**

仲由任季氏家宰，参与拆毁三家大邑城防的安排。叔孙氏先拆郈。轮到费时，公山不狃、叔孙辄带费人袭鲁都，定公与三家宗主退入季氏宫中，登武子之台。孔丘命申句须、乐颀反击，国人追到姑蔑，击败费军；两名首领逃齐，费的城防随后也被拆毁。 [2](#note-2)

<a id="event-3"></a>

3. **卫军攻曹、克郊，滑罗坚持在阵列中殿后。**

卫国公孟彄率军攻曹，攻下郊地。撤退时滑罗担任殿后，没有脱离阵列卖弄勇武，御者因此讥他，他回答宁可被说不勇，也不要平白冒进。 [3](#note-3)

<a id="event-4"></a>

4. **秋季举行大雩。**

秋季，鲁国举行大雩祈雨。 [4](#note-4)

<a id="event-5"></a>

5. **定公与齐侯在黄结盟，十一月发生日食。**

十月癸亥，定公与齐侯在黄盟誓。十一月丙寅朔，发生日食，随后经文记定公由黄返回。 [5](#note-5)

<a id="event-6"></a>

6. **定公围攻成邑，未能攻下。**

孟氏家臣公敛处父认为成是孟氏的保障，劝孟懿子不要拆城。十二月，定公出兵围成，没有攻克，随后回国，拆除三家大邑城防的计划停在这里。 [6](#note-6)

**《左传》·定公十二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0498.md#L41-L41)

> 仲由为季氏宰，将堕三都。于是叔孙氏堕郈。季氏将堕费，公山不狃、叔孙辄帅费人以袭鲁。公与三子入于季氏之宫，登武子之台。费人攻之，弗克。入及公侧。仲尼命申句须、乐颀下伐之，费人北。国人追之，败诸姑蔑。二子奔齐。遂堕费。将堕成，公敛处父谓孟孙：“堕成，齐人必至于北门。且成，孟氏之保障也，无成，是无孟氏也。子伪不知，我将不堕。”

**《史记·鲁周公世家》·十二年：毁三桓城，成未克** · [核对来源](https://zh.wikisource.org/w/index.php?oldid=7909289&title=史記/魯周公世家)

> 十二年，使仲由毀三桓城，收其甲兵。孟氏不肯墮城，伐之，不克而止。

**《史记·孔子世家》（古文岛所录古籍原文）·本篇以十三年系堕三都，与经传有差** · [核对来源](https://www.guwendao.net/mingju/juv_01c7982b5b40.aspx)

> 定公十三年夏，孔子言於定公曰：“臣无藏甲，大夫毋百雉之城。”使仲由为季氏宰，将堕三都。

**说明：** 同一传段还记公敛处父劝孟氏保成，接下一条围成而未克。《孔子世家》将拆城系于十三年，与《春秋》《左传》及《鲁周公世家》十二年不合；本页按经传明确年条，并非十三年又拆一次。三都之事只完成郈、费，不能写“三都全毁”。《孔子行年考（五）》亦指出两种错置，详见本组研究说明。

**研究参考：** [《孔子行年考（五）》](https://www.chinakongzi.org/content/2862_35479.html)。核读定公十二至十四年相关文献与考辨；未把全篇其他周游行程结论一并采纳。

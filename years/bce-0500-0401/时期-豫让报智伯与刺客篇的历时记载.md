# 春秋战国之际｜豫让报智伯与刺客篇的历时记载（时期阅读）

[本世纪目录](README.md) · [全部世纪](../README.md) · [卷086完整读本](../../sources/摘录/史记-卷086-刺客列传.md) · [纪年与异说](../../meta/考证/史记-卷086-纪年与异说.md)

本页按原传可见的先后和专题阅读。已知年份的事件在相应年页，未独立确年的叙事随原传先后附读。

<a id="reading-start"></a>

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **柯盟与刺王僚之间的年数。** 曹沫柯盟从鲁庄公十三年，专诸刺王僚从鲁昭公二十七年。两事相差166年；本传的167年可用兼计首尾解释。两件事分别回既有年页读。 [[1]](#note-1)

<a id="event-2"></a>

2. **赵襄子放走豫让。** 豫让先后事范氏、中行氏和智伯。智氏覆败后，他想为智伯报仇，被赵襄子发觉。襄子认可他为故主报仇的用心，最终放走了他。智氏败亡归前453，豫让获释时间未详。 [[2]](#note-2)

<a id="event-3"></a>

3. **豫让与朋友辩论事主之义。** 豫让改变形貌和声音，朋友劝他投效赵襄子再图报仇。他反对先做臣子再害其主，认为这是用自己的艰难选择警戒后来的人。 [[3]](#note-3)

<a id="event-4"></a>

4. **豫让用击衣表达为智伯报仇之意。** 再次被捕时，赵襄子问豫让为何不为范氏、中行氏报仇。豫让答说各依受到的礼遇回报。赵襄子允许他击衣，豫让随后自尽。这段经过在智氏覆亡之后，确年未定。 [[4]](#note-4)

<a id="event-5"></a>

5. **本传过渡段中的两个概数。** 专诸之后“七十余年”引出豫让，豫让之后“四十余年”引出聂政。它们提示叙事间隔，不能用来算出豫让谋刺或死亡的年月。 [[5]](#note-5)

<a id="event-6"></a>

6. **聂政姐弟及严仲子的评价。** 聂政之姐不肯让弟弟无名，最终在韩国认出其身。传文用晋楚齐卫的事后评论褒扬姐弟，也赞严仲子能识人，原话是对事件的评价。 [[6]](#note-6)

<a id="event-7"></a>

7. **聂政到荆轲的时距与唐代述赞。** 聂政刺韩相与荆轲刺秦各有独立年据。按本页采用的前397和前227，两件事间隔170年，与传本的“二百二十余年”不同。唐代述赞另以韵语串联五人的故事。 [[7]](#note-7)

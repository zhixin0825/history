# 春秋末期｜子贡游说五国的传述

[孔门问学与传承](未定年-孔门弟子的问学与传承.md) · [本世纪目录](README.md) · [全部世纪](../README.md)

**时间精度：这是连缀多国说辞与多年战事的传述，不能统一定为某一次确年出使。** 前六组依篇内游说次序保留论辩内容；最后的战争结果与已有年页对读。田常掌权、伍员之死、吴晋在黄池的关系和越灭吴的过程，不能因故事连贯便消去年代与史源分歧。艾陵在[前484年](bce-0484.md#note-3)，黄池会盟及越入吴在[前482年](bce-0482.md#note-3)，越灭吴在[前473年](bce-0473.md#note-2)。同号史料完整保存故事原话及不同说法。

<a id="sj067-diplomacy-01-event"></a>

1. **救鲁游说的故事以孔子忧虑母国为开端。** 在救鲁游说的传述中，田常担心高、国、鲍、晏诸族掣肘，打算借攻鲁调动他们的兵力。孔子担心父母之邦和祖墓所在受兵，催弟子出面。子路、子张、子石先后请行，未获许可；子贡请行，孔子答应了。 [[1]](#sj067-diplomacy-01-note)

<a id="sj067-diplomacy-02-event"></a>

2. **子贡劝田常把矛头转向吴国。** 子贡于是出发，到了齐国，对田常说：‘您攻打鲁国，是错了。鲁国是难以攻打的国家：城墙薄而低，土地狭小而地势浅露，国君愚昧而不仁，大臣虚伪而无能，士民又讨厌战争，这样的国家不能同它交战。您不如攻打吴国。吴国城墙高厚，土地广大而有纵深，铠甲坚固崭新，士卒经过挑选，又吃得饱，重要的军器、精锐的兵力都在那里，还有明智的大夫防守，倒是容易攻打的国家。’

    田常变了脸色，生气地说：‘你说难的，别人认为容易；你说容易的，别人认为困难。你这样来教我，是什么意思？’子贡说：‘我听说，忧患在国内的人应当进攻强国，忧患在国外的人应当进攻弱国。如今您的忧患在国内。我听说您三次谋求封赏，三次未成，是因为有大臣不肯听从。现在您攻破鲁国，扩大齐国土地，胜仗使国君骄傲，破国使统兵的大臣尊贵，而功劳却没有您的份，您同国君的关系反而会一天比一天疏远。这是向上助长国君的骄心，向下纵容群臣，要凭这种局面办成大事，很难。君上骄傲便放纵，大臣骄傲便争权，这样您向上同国君有嫌隙，向下又同大臣互相争斗，在齐国的地位就危险了。所以我说不如伐吴。攻吴不能取胜，百姓战死在外，大臣的力量在国内空虚；您向上没有强臣相敌，向下没有百姓非议，能孤立国君、控制齐国的就只有您。’

    田常说：‘好。不过我的军队已经向鲁国进逼，如果撤开转向吴国，大臣会怀疑我，怎么办？’子贡说：‘您先按兵不攻，我去游说吴王，让他救鲁伐齐，您就顺势出兵迎击。’田常答应，让子贡南下去见吴王。 [[2]](#sj067-diplomacy-02-note)

<a id="sj067-diplomacy-03-event"></a>

3. **子贡劝吴王保存越国、救鲁伐齐。** 子贡对吴王说：‘我听说，行王道者不灭绝别国的世系，称霸者不容有强大的敌手；即使重达千钧，在天平一端添上一点分量，也会使它移动。如今有万辆兵车的齐国要吞并只有千辆兵车的鲁国，同吴国争强，我私下为大王担忧。况且救援鲁国能显扬名声，攻打齐国能得到大利。借此安抚泗水一带诸侯，讨伐强暴的齐国而使强晋屈服，没有比这更大的利益了。名义上是保全将亡的鲁国，实际上是困住强大的齐国，明智的人不应犹疑。’

    吴王说：‘好。不过我曾同越国作战，把越王困在会稽。越王劳苦自己、供养勇士，有向我报仇的心。你等我先伐越，再听你的。’

    子贡说：‘越国的强劲不超过鲁国，吴国的强大不超过齐国。大王放下齐国去打越国，齐国就已经平定鲁国了。您正要以保存将亡的国家、接续将绝的世系求名，攻打弱小的越国而畏惧强齐，不算勇敢。勇者不躲避困难，仁者不使困厄者更加穷迫，智者不失去时机，行王道者不绝人世系，以此树立大义。现在保留越国，向诸侯显示仁爱；救鲁伐齐，威势达到晋国，诸侯一定相率来朝吴国，霸业就能成就。如果大王仍然忌惮越国，我愿东去见越王，让他出兵随从：实际上抽空越国的兵力，名义上让他随诸侯出征。’吴王很高兴，便让子贡到越国去。 [[3]](#sj067-diplomacy-03-note)

<a id="sj067-diplomacy-04-event"></a>

4. **子贡劝越王助吴北上，等待吴军疲敝。** 越王扫道郊迎，亲自驾车迎送。子贡告诉他，吴王虽然想伐齐，却担心越国报复，要先向越用兵；没有反攻之心却引人疑、有意图而被识破、计划未动而消息先泄，都是危险。勾践痛述会稽之辱，表示愿与吴王相继而死。子贡指出吴王暴虐、连年战争使百姓和士卒怨苦，太宰嚭又迎合君主保全私利，劝越王出兵助吴，以宝物和谦辞使吴放心北上；吴若败于齐，越便得利，若胜而进逼晋国，便可使晋牵制吴军，越再乘其疲敝而动。越王答应，赠黄金百镒、一剑、两支好矛，子贡没有接受。 [[4]](#sj067-diplomacy-04-note)

<a id="sj067-diplomacy-05-event"></a>

5. **子贡回报吴王，文种献兵器并请率军助战。** 子贡向吴王报告：‘我恭敬地把大王的话告诉越王，越王十分恐惧，说：“我不幸幼年失去先父，不能自量，得罪吴国，军队战败，自己受辱，困居会稽，国家沦为荒墟。承蒙大王恩赐，使我还能奉持祭器，继续祖先祭祀，至死也不敢忘记，哪里还敢考虑别的谋划！”’

    五天后，越国大夫种来到吴国，叩头对吴王说：‘东海役臣勾践的使者臣种，冒昧尽下吏的礼，向大王左右问候。听说大王将举大义，讨伐强国、援救弱国，困住暴齐，安抚周室。越王请求尽发境内士卒三千人，并愿亲自披坚甲、执利器，先承受敌人的箭石；又让越国贱臣种奉上先人收藏的器物：铠甲二十领、战斧、名为屈卢的矛、名为步光的剑，以向军吏致贺。’

    吴王十分高兴，告诉子贡：‘越王要亲自跟随我伐齐，可以吗？’子贡说：‘不可。把人家的国家抽空，把人家的士卒全数征来，还要让人家的国君随从，这不合义。大王可以接受礼物，允许军队来助战，却辞谢国君亲自前来。’吴王答应，便辞谢越王。随后吴王征发九郡兵力，出征齐国。 [[5]](#sj067-diplomacy-05-note)

<a id="sj067-diplomacy-06-event"></a>

6. **子贡赴晋，劝晋君整军休卒以待吴军。** 子贡随即前往晋国，对晋君说：‘我听说，谋划不预先定好，就不能应付突然的变故；军备不预先办好，就不能战胜敌人。现在齐国和吴国将要交战，吴国如果战败，越国一定乘机扰乱它；如果战胜齐国，一定会带兵来到晋国。’晋君十分恐惧，问：‘怎么办？’子贡说：‘整修军备，让士卒休养，等待它来。’晋君答应了。 [[6]](#sj067-diplomacy-06-note)

<a id="sj067-diplomacy-07-event"></a>

7. **多年间吴齐交战、吴晋争长，越国最终灭吴。** 子贡在游说之后返回鲁国。吴军在艾陵击败齐军，后来吴、晋在黄池争长；越趁吴王北上而入袭吴国，双方此后仍有和战，最终吴国灭亡，越取得东方霸主地位。这些结果相隔多年。游说的故事把鲁、齐、吴、晋、越的变局归结到子贡一次出使所引起的相互牵制；具体战事仍按各自的年次阅读。 [[7]](#sj067-diplomacy-07-note)

### 2. 子贡劝田常把矛头转向吴国

[返回正文第2条](#sj067-diplomacy-02-event)

<a id="sj067-cite-137"></a>

**[《史记·仲尼弟子列传》P041](../../sources/摘录/史记-卷067-仲尼弟子列传.md#p041)**

> 遂行，至齊，說田常曰：「君之伐魯過矣。夫魯，難伐之國，其城薄以卑，其地狹以泄，其君愚而不仁，大臣偽而無用，其士民又惡甲兵之事，此不可與戰。君不如伐吳。夫吳，城高以厚，地廣以深，甲堅以新，士選以飽，重器精兵盡在其中，又使明大夫守之，此易伐也。」田常忿然作色曰：「子之所難，人之所易；子之所易，人之所難：而以教常，何也？」子貢曰：「臣聞之，憂在內者攻彊，憂在外者攻弱。今君憂在內。吾聞君三封而三不成者，大臣有不聽者也。今君破魯以廣齊，戰勝以驕主，破國以尊臣，而君之功不與焉，則交日疏於主。是君上驕主心，下恣群臣，求以成大事，難矣。夫上驕則恣，臣驕則爭，是君上與主有卻，下與大臣交爭也。如此，則君之立於齊危矣。故曰不如伐吳。伐吳不勝，民人外死，大臣內空，是君上無彊臣之敵，下無民人之過，孤主制齊者唯君也。」田常曰：「善。雖然，吾兵業已加魯矣，去而之吳，大臣疑我，柰何？」子貢曰：「君按兵無伐，臣請往使吳王，令之救魯而伐齊，君因以兵迎之。」田常許之，使子貢南見吳王。

**本卷说明：** 三封三不成、上无强臣之敌下无民人之过，依说辞自身的权力计算释；不把子贡说给田常的谋略直接改作本项目对各国的价值评断。

<a id="sj067-diplomacy-03-note"></a>

### 3. 子贡劝吴王保存越国、救鲁伐齐

[返回正文第3条](#sj067-diplomacy-03-event)

<a id="sj067-cite-138"></a>

**[《史记·仲尼弟子列传》P042](../../sources/摘录/史记-卷067-仲尼弟子列传.md#p042)**

> 說曰：「臣聞之，王者不絕世，霸者無彊敵，千鈞之重加銖兩而移。今以萬乘之齊而私千乘之魯，與吳爭彊，竊為王危之。且夫救魯，顯名也；伐齊，大利也。以撫泗上諸侯，誅暴齊以服彊晉，利莫大焉。名存亡魯，實困彊齊。智者不疑也。」吳王曰：「善。雖然，吾嘗與越戰，棲之會稽。越王苦身養士，有報我心。子待我伐越而聽子。」子貢曰：「越之勁不過魯，吳之彊不過齊，王置齊而伐越，則齊已平魯矣。且王方以存亡繼絕為名，夫伐小越而畏彊齊，非勇也。夫勇者不避難，仁者不窮約，智者不失時，王者不絕世，以立其義。今存越示諸侯以仁，救魯伐齊，威加晉國，諸侯必相率而朝吳，霸業成矣。且王必惡越，臣請東見越王，令出兵以從，此實空越，名從諸侯以伐也。」吳王大說，乃使子貢之越。

<a id="sj067-diplomacy-04-note"></a>

### 4. 子贡劝越王助吴北上，等待吴军疲敝

[返回正文第4条](#sj067-diplomacy-04-event)

<a id="sj067-cite-139"></a>

**[《史记·仲尼弟子列传》P043](../../sources/摘录/史记-卷067-仲尼弟子列传.md#p043)**

> 越王除道郊迎，身御至舍而問曰：「此蠻夷之國，大夫何以儼然辱而臨之？」子貢曰：「今者吾說吳王以救魯伐齊，其志欲之而畏越，曰『待我伐越乃可』。如此，破越必矣。且夫無報人之志而令人疑之，拙也；有報人之志，使人知之，殆也；事未發而先聞，危也。三者舉事之大患。」句踐頓首再拜曰：「孤嘗不料力，乃與吳戰，困於會稽，痛入於骨髓，日夜焦脣乾舌，徒欲與吳王接踵而死，孤之願也。」遂問子貢。子貢曰：「吳王為人猛暴，群臣不堪；國家敝以數戰，士卒弗忍；百姓怨上，大臣內變；子胥以諫死，太宰嚭用事，順君之過以安其私：是殘國之治也。今王誠發士卒佐之徼其志，重寶以說其心，卑辭以尊其禮，其伐齊必也。彼戰不勝，王之福矣。戰勝，必以兵臨晉，臣請北見晉君，令共攻之，弱吳必矣。其銳兵盡於齊，重甲困於晉，而王制其敝，此滅吳必矣。」越王大說，許諾。送子貢金百鎰，劍一，良矛二。子貢不受，遂行。

**本卷说明：** 原句‘子胥以谏死’不删。索隐引王劭明确指出当时子胥尚未死，家语、越绝无这五字，故不据这一句提前改编伍子胥卒年。

<a id="sj067-diplomacy-05-note"></a>

### 5. 子贡回报吴王，文种献兵器并请率军助战

[返回正文第5条](#sj067-diplomacy-05-event)

<a id="sj067-cite-140"></a>

**[《史记·仲尼弟子列传》P044](../../sources/摘录/史记-卷067-仲尼弟子列传.md#p044)**

> 報吳王曰：「臣敬以大王之言告越王，越王大恐，曰：『孤不幸，少失先人，內不自量，抵罪於吳，軍敗身辱，棲于會稽，國為虛莽，賴大王之賜，使得奉俎豆而修祭祀，死不敢忘，何謀之敢慮！』」後五日，越使大夫種頓首言於吳王曰：「東海役臣孤句踐使者臣種，敢修下吏問於左右。今竊聞大王將興大義，誅彊救弱，困暴齊而撫周室，請悉起境內士卒三千人，孤請自被堅執銳，以先受矢石。因越賤臣種奉先人藏器，甲二十領，鈇屈盧之矛，步光之劍，以賀軍吏。」吳王大說，以告子貢曰：「越王欲身從寡人伐齊，可乎？」子貢曰：「不可。夫空人之國，悉人之眾，又從其君，不義。君受其幣，許其師，而辭其君。」吳王許諾，乃謝越王。於是吳王乃遂發九郡兵伐齊。

**本卷说明：** 主文‘甲二十领’不误作十二领；鈇依索隐作斧，屈卢为矛名，步光为剑名。‘九郡’照传述原名保留，不倒填秦汉郡制或虚列九郡名称。

### 7. 多年间吴齐交战、吴晋争长，越国最终灭吴

[返回正文第7条](#sj067-diplomacy-07-event)

<a id="sj067-cite-142"></a>

**[《史记·仲尼弟子列传》P046](../../sources/摘录/史记-卷067-仲尼弟子列传.md#p046)**

> 子貢去而之魯。吳王果與齊人戰於艾陵，大破齊師，獲七將軍之兵而不歸，果以兵臨晉，與晉人相遇黃池之上。吳晉爭彊。晉人擊之，大敗吳師。越王聞之，涉江襲吳，去城七里而軍。吳王聞之，去晉而歸，與越戰於五湖。三戰不勝，城門不守，越遂圍王宮，殺夫差而戮其相。破吳三年，東向而霸。

**本卷说明：** 索隐已分出艾陵哀十一、黄池哀十三、灭吴哀二十二，明确文辞把相隔数年的事件连写。黄池晋击吴大败、夫差被杀、破吴三年东霸与其他史源有别；本段忠实译文不等于年正文全采此说。

<!-- /sj067-cite-142 -->

<a id="sj067-cite-143"></a>

**[《史记·仲尼弟子列传》P047](../../sources/摘录/史记-卷067-仲尼弟子列传.md#p047)**

> 故子貢一出，存魯，亂齊，破吳，彊晉而霸越。子貢一使，使勢相破，十年之中，五國各有變。

**本卷说明：** ‘十年’保留为本篇总括，未拿其倒排每次出使的年份，也未把五国全部变化确认为一次外交行动所致。

<a id="sj067-cite-175"></a>

**[三家注·p15](../../sources/史记三家注/卷067.md#p15)**

> 按左傳越滅吳在哀二十二年，則事並懸隔數年。蓋此文欲終說其事，故其辭相連。

**本卷说明：** 索隐已说明连写的作用是交代结局，而不是断言事件连续发生在一个年份。艾陵、黄池、灭吴仍分别对读前484、前482、前473。

# 春秋晚期至战国初｜孔门弟子的问学与传承

[孔子生平与问政](../bce-0600-0501/未定年-春秋晚期求学与问政.md) · [子贡游说五国](未定年-子贡游说五国.md) · [本世纪目录](README.md) · [全部世纪](../README.md)

**时间精度：问答、性格和任职多无独立年月。** 本页按春秋晚期孔门受业、仕进与孔子卒后的传承组织阅读，部分早年经历可在前6世纪，不能因目录位置一律定为前5世纪。相对年龄照原文保存，不直接倒推各人生年；西河教学、原宪隐居、有若受立明示为孔子卒后。传易世系的西汉终点及司马迁、司马贞的论赞另标后世附读，不当作孔子时代的同期事件。已有可归年的史事仍在原年页，教学总述、隐者相遇和颜回丧事沿[既有春秋晚期正文](../bce-0600-0501/未定年-春秋晚期求学与问政.md)。

<a id="sj067-disciple-01-event"></a>

1. **孔子敬事各国贤者，也称道前辈的操守。** 孔子敬重周的老子、卫的蘧伯玉、齐的晏平仲、楚的老莱子、郑的子产以及鲁的孟公绰。他也经常称道臧文仲、柳下惠、铜鞮伯华、介山子然，把前贤的言行作为学习资源。 [[1]](#sj067-disciple-01-note)

<a id="sj067-disciple-02-event"></a>

2. **颜回问仁，以安贫、领会和行藏受到称许。** 颜回是鲁国人，字子渊，比孔子小三十岁。颜渊问什么是仁。孔子说：‘约束自己，使行为合于礼，天下人就会归向仁。’孔子说：‘颜回真贤德啊！只有一竹筐饭、一瓢水，住在简陋的巷子里，别人受不了这样的困苦，他却不改自己的快乐。’又说：‘颜回听我说话，仿佛愚钝；他退下后，我察看他私下的言行，却足以发挥我的教导，可见他并不愚钝。’又对他说：‘受到任用就施行主张，不被任用就退而自守，只有我和你能这样吧！’ [[2]](#sj067-disciple-02-note)

<a id="sj067-disciple-03-event"></a>

3. **闵损以孝行受誉，也拒绝违背操守的任用。** 闵损字子骞，比孔子小十五岁。孔子说：‘闵子骞真孝顺！人们听到他父母兄弟赞许他的话，都没有异议。’闵子骞不肯为大夫任职，不接受污浊之君的俸禄。他说：‘如果还有人再来召我，我一定已经到了汶水北边。’ [[3]](#sj067-disciple-03-note)

<a id="sj067-disciple-04-event"></a>

4. **冉耕有德而患恶疾，孔子探病时为之叹息。** 冉耕字伯牛。孔子认为他有德行。伯牛患了严重的疾病。孔子去探望他，从窗口握着他的手，说：‘这是命啊！这样的人竟然得了这样的病，是命啊！’ [[4]](#sj067-disciple-04-note)

<a id="sj067-disciple-05-event"></a>

5. **仲弓问政，孔子重视他的德行而不以父亲出身限之。** 冉雍字仲弓。仲弓问怎样处理政事。孔子说：‘出门办事要像接待贵宾一样郑重，役使百姓要像承办大祭一样谨慎；在诸侯之国不招怨，在大夫之家也不招怨。’孔子认为仲弓有德行，说：‘冉雍可以担任面南治事的君长。’仲弓的父亲出身卑贱。孔子说：‘杂色牛生的牛犊，如果毛色纯赤、角也端正，即使人们想不用它作祭牲，山川之神难道会舍弃它吗？’ [[5]](#sj067-disciple-05-note)

<a id="sj067-disciple-06-event"></a>

6. **冉求能治兵赋，孔子按他的退缩性情鼓励前进。** 冉求字子有，比孔子小二十九岁，曾做季氏的家宰。季康子问孔子：‘冉求有仁德吗？’孔子说：‘有一千户的城邑、拥有一百辆兵车的大夫之家，可以让冉求管理兵赋。至于仁德，我不知道。’季康子又问：‘子路有仁德吗？’孔子回答：‘同冉求一样。’冉求问：‘听到应当做的事，就去实行吗？’孔子说：‘去做。’子路也这样问，孔子却说：‘父亲、兄长都在，怎么能一听见就自己去做！’子华觉得奇怪，问：‘冒昧请问，他们问得相同，为什么回答不同？’孔子说：‘冉求遇事退缩，所以我鼓励他前进；仲由勇气胜人，容易冒进，所以我让他退一步。’ [[6]](#sj067-disciple-06-note)

<a id="sj067-disciple-07-event"></a>

7. **子路好勇而务实践，在受教中学习克制刚猛。** 仲由字子路，是卞地人，比孔子小九岁。子路性情粗朴，好勇力，意志强硬直率，帽上用雄鸡作饰，身上佩着公猪形的饰物，曾对孔子粗暴无礼。孔子用礼仪逐渐引导他。后来子路穿起儒者的衣服，正式执礼求见，通过已有的弟子请求拜孔子为师。子路问怎样处理政事。孔子说：‘自己先作引导，再带领百姓劳作。’子路请求多讲一些，孔子说：‘坚持做下去，不要懈怠。’子路问：‘君子崇尚勇敢吗？’孔子说：‘应当把义放在首位。君子好勇而没有义，会造成祸乱；小人好勇而没有义，就会成为盗贼。’子路听到一项教诲，还没有来得及实行，就怕再听到新的教诲，自己不能一并做到。孔子说：‘单凭一方面的言辞就能判断诉讼的，大概只有仲由吧！’又说：‘仲由好勇超过了我，却不能恰当地运用这种勇气。’又说：‘像仲由这样，恐怕不能寿终。’又说：‘穿着破旧的絮袍，站在穿狐貉皮衣的人身旁也不羞愧的，大概就是仲由吧！’又说：‘仲由已经登上厅堂，还没有进入内室。’最后这句话把学业的进境比作登堂入室。 [[7]](#sj067-disciple-07-note)

<a id="sj067-disciple-08-event"></a>

8. **子路历任家宰和邑宰，治民须兼恭敬、宽正与安静。** 季康子问：‘仲由有仁德吗？’孔子说：‘一个拥有一千辆兵车的国家，可以让他管理兵赋；至于他的仁德，我不知道。’子路担任季氏的家宰。季孙问孔子：‘子路可以称作大臣吗？’孔子说：‘可以说是备足臣下人数的臣罢了。’子路将任蒲地的大夫，向孔子告辞。孔子说：‘蒲地勇壮之士很多，又难治理。我告诉你：恭谨而敬人，可以制约强勇之人；宽厚而公正，可以使众人亲附；恭敬、公正而安静不扰，可以报答上位者。’ [[8]](#sj067-disciple-08-note)

<a id="sj067-disciple-09-event"></a>

9. **宰予善辩，与孔子论丧礼，也因昼寝和问五帝受到批评。** 宰予字子我，口齿伶俐，善于辩说。他受教后问：‘守丧三年，不是太久了吗？君子三年不习礼，礼就会败坏；三年不习乐，乐就会崩坏。旧谷已经吃完，新谷已经收下，钻木取火所用的木材也更换过一轮，满一年就可以结束了。’孔子问：‘这样做你心里安稳吗？’宰予说：‘安稳。’孔子说：‘你心安，就这样做吧。君子守丧，吃美味不觉得香甜，听音乐不觉得快乐，所以不肯这样做。’宰我出去后，孔子说：‘宰予真是不仁啊！孩子生下来，过了三年才能离开父母的怀抱。三年之丧，是天下共同遵行的义。’宰予白天睡觉。孔子说：‘腐朽的木头无法雕琢，用污土堆成的墙也无法粉饰。’宰我询问五帝的德行。孔子说：‘宰予呀，你还不是能够通明这一道理的人。’ [[9]](#sj067-disciple-09-note)

<a id="sj067-disciple-10-event"></a>

10. **子贡善于问答，推尊颜回，也说明孔子广学与闻政的方法。** 端木赐是卫国人，字子贡，比孔子小三十一岁。子贡口齿伶俐，善于措辞，孔子常抑制他逞辩。孔子问：‘你和颜回，谁更出色？’子贡回答：‘我哪里敢同颜回相比！颜回听到一件事就能推知十件，我听到一件只能推知两件。’子贡受教后问：‘我是怎样的人？’孔子说：‘你是一件有用的器物。’子贡问：‘什么器物？’孔子说：‘是宗庙里贵重的瑚琏礼器。’陈子禽问子贡：‘仲尼向谁学习？’子贡说：‘文王、武王的道没有失落，仍保存在人们之中。贤能的人记得其中重要的部分，不够贤能的人记得细小的部分；无论哪一种，都有文武之道。老师在哪里不能学，又何必有一个固定的老师！’陈子禽又问：‘孔子来到一个国家，总能听闻它的政事，是自己求来的，还是别人主动告诉他的？’子贡说：‘老师凭着温和、善良、恭敬、俭约、谦让而得到这些情况。他获取情况的方式，大概和别人的求取方式不同。’子贡问：‘富有而不骄傲，贫穷而不谄媚，怎么样？’孔子说：‘可以了；但还不如贫穷而以道为乐，富有而爱好礼。’ [[10]](#sj067-disciple-10-note)

<a id="sj067-disciple-11-event"></a>

11. **子贡经营财货，也曾在鲁、卫为相。** 子贡喜好买进卖出，随时机转运财货。他喜欢宣扬别人的长处，却不能隐瞒别人的过失，曾在鲁国、卫国为相，家产累积到千金，最终死在齐国。 [[11]](#sj067-disciple-11-note)

<a id="sj067-disciple-12-event"></a>

12. **子游治理武城，以礼乐教人。** 言偃是吴国人，字子游，比孔子小四十五岁。子游受教后，做了武城的邑宰。孔子路过，听到弹琴唱歌的声音，微笑着说：‘杀鸡哪里用得着宰牛的刀？’子游回答：‘从前我听老师说，君子学道就会爱人，百姓学道就容易接受治理。’孔子说：‘弟子们，言偃说得对，我刚才只是同他开个玩笑。’孔子认为子游熟习文献之学。 [[12]](#sj067-disciple-12-note)

<a id="sj067-disciple-13-event"></a>

13. **子夏从诗义发问，孔子告诫他守中并为明道而学。** 卜商字子夏，比孔子小四十四岁。子夏问：‘诗中说，美好的笑容如此动人，明亮的眼睛如此顾盼，再用白色成就其文采，是什么意思？’孔子说：‘作画时，把白色安排在后。’子夏问：‘礼也在后吗？’孔子说：‘商啊，现在可以同你谈诗了。’子贡问：‘颛孙师和卜商谁更贤能？’孔子说：‘师做过了头，商又做得不够。’子贡问：‘那么师更好吗？’孔子说：‘超过应有的分寸，和没有达到，同样不好。’孔子对子夏说：‘你应当做为明道而学的君子儒者，不要做只为自夸名声的小人儒者。’ [[13]](#sj067-disciple-13-note)

<a id="sj067-disciple-14-event"></a>

14. **子张求禄问达，把言行的实质与名声区分开。** 颛孙师是陈国人，字子张，比孔子小四十八岁。子张问怎样求得俸禄。孔子说：‘广泛听闻，疑惑的先存而不论，其余可信的也谨慎表达，就少有责备；广泛观察，危险可疑的先放下，其余可行的也谨慎去做，就少有悔恨。说话少受责备，行事少生悔恨，俸禄就在其中了。’子张问：‘士要怎样才可以称作通达？’孔子说：‘你所说的通达是什么？’子张回答：‘在诸侯之国必定有名声，在大夫之家也必定有名声。’孔子说：‘这只是有名声，不是通达。所谓通达，是本质正直而爱好义，观察别人的言语神色，思量怎样谦下待人，这样在国、在家都能通达。所谓有名声，有人只是外表装得仁厚，实际行为却背离仁，自居其名而不疑，这样在国、在家也都会有名声。’ [[14]](#sj067-disciple-14-note)

<a id="sj067-disciple-15-event"></a>

15. **曾参通习孝道，受孔子授业。** 曾参是南武城人，字子舆，比孔子小四十六岁。孔子认为他能通晓孝道，向他传授学业；曾参后来死于鲁国。他的孝道之学也成为后世传承的重要内容。 [[15]](#sj067-disciple-15-note)

<a id="sj067-disciple-16-event"></a>

16. **澹台灭明退而修行，南游授徒。** 澹台灭明是武城人，字子羽，比孔子小三十九岁。澹台灭明相貌很丑，想拜孔子为师，孔子以为他的才干浅薄。他受教以后，退而修养品行，走路不取邪径，没有公事就不去拜见卿大夫。澹台灭明南游到长江一带，有三百名弟子跟从，讲明取与、进退的准则，名声传播到诸侯之中。孔子听说后，说：‘我根据言辞判断人，在宰予身上判断错了；根据相貌判断人，在子羽身上判断错了。’ [[16]](#sj067-disciple-16-note)

<a id="sj067-disciple-17-event"></a>

17. **子贱治理单父，向当地贤者学习。** 宓不齐字子贱，比孔子小三十岁。孔子评论子贱说：‘真是君子啊！如果鲁国没有君子，他又从哪里学到这样的品德？’子贱做单父的邑宰，回来向孔子报告说：‘这里有五个人比我贤能，他们教我治理的办法。’孔子说：‘可惜不齐所治理的地方太小了；如果治理的地方更大，就很有希望了。’ [[17]](#sj067-disciple-17-note)

<a id="sj067-disciple-18-event"></a>

18. **原宪问耻与仁，不把克制欲望等同于仁的全部。** 原宪字子思。原宪问什么是可耻的。孔子说：‘国家有道，可以食禄；国家无道，仍然食禄，就可耻了。’原宪说：‘不做争强好胜、夸耀功劳、怨恨别人、贪求欲望的事，可以算仁吗？’孔子说：‘可以说是难得了；至于是否是仁，我还不知道。’ [[18]](#sj067-disciple-18-note)

<a id="sj067-disciple-19-event"></a>

19. **公冶长虽曾被囚，孔子认为无罪而以女嫁之。** 公冶长是齐国人，字子长。孔子说：‘公冶长可以把女儿嫁给他。虽然他曾被囚系，那并不是他的罪过。’于是把自己的女儿嫁给了他。 [[19]](#sj067-disciple-19-note)

<a id="sj067-disciple-20-event"></a>

20. **南容崇德慎言，孔子把哥哥的女儿嫁给他。** 南宫括字子容。南宫括问孔子：‘羿善于射箭，奡能够推舟陆行，却都没能善终；禹、稷亲身从事沟洫、稼穑，却取得了天下，这是为什么？’孔子没有回答。南容出去后，孔子说：‘这个人真是君子！这个人崇尚德行啊！’又称他：‘国家有道时不会被废置，国家无道时能免于刑戮。’南容反复诵读诗中告诫慎言的‘白珪之玷’之句，孔子便把哥哥的女儿嫁给他。 [[20]](#sj067-disciple-20-note)

<a id="sj067-disciple-21-event"></a>

21. **公皙哀在失道之世不仕。** 公皙哀字季次。孔子说：‘天下不行正道，许多人却去做大夫的家臣，在都邑任职；只有季次没有做过官。’ [[21]](#sj067-disciple-21-note)

<a id="sj067-disciple-22-event"></a>

22. **曾皙以沂水春游言志。** 曾蒧字皙。曾蒧侍奉在孔子身旁。孔子说：‘说说你的志向。’曾蒧说：‘春天的衣服已经备好，同五六位成年人、六七名童子，在沂水洗浴，到舞雩台上吹风，唱着歌回来。’孔子长叹说：‘我赞同曾蒧啊！’ [[22]](#sj067-disciple-22-note)

<a id="sj067-disciple-23-event"></a>

23. **商瞿受业，并传习易学。** 商瞿是鲁国人，字子木，比孔子小二十九岁。他从孔子受学，传习易学；这一路学业后来有跨越多代的传承。 [[23]](#sj067-disciple-23-note)

<a id="sj067-disciple-24-event"></a>

24. **高柴未熟习学业而被派任宰，孔子担心有害于他。** 高柴字子羔，比孔子小三十岁。子羔身高不到五尺，向孔子受学，孔子认为他愚直。子路让子羔担任费郈的邑宰。孔子说：‘这是害了人家的儿子！’子路说：‘那里有百姓，有社稷，可以学习治民事神，为什么一定要读了书才算学习？’孔子说：‘所以我厌恶那些强辩的人。’ [[24]](#sj067-disciple-24-note)

<a id="sj067-disciple-25-event"></a>

25. **漆雕开自觉尚未有把握，没有急于做官。** 漆雕开字子开。孔子让漆雕开去做官，他回答：‘我对这件事还不能有充分把握。’孔子听了很高兴。 [[25]](#sj067-disciple-25-note)

<a id="sj067-disciple-26-event"></a>

26. **公伯缭诬告子路，孔子不以谗言改变行道的判断。** 公伯缭字子周。公伯缭在季孙面前诬告子路。子服景伯把这件事告诉孔子，说：‘季孙确实被迷惑了。对于公伯缭，我的力量还足以使他受刑，陈尸市朝。’孔子说：‘道将得到推行，是命；道将被废弃，也是命。公伯缭又能把命怎么样！’ [[26]](#sj067-disciple-26-note)

<a id="sj067-disciple-27-event"></a>

27. **司马牛从问仁、问君子学习谨言与自省。** 司马耕字子牛。司马牛话多而急躁，向孔子问仁。孔子说：‘有仁德的人，说话谨慎，不轻易出口。’司马牛问：‘说话谨慎，就可以说有仁德吗？’孔子说：‘实行起来很难，说出来能不谨慎吗！’司马牛问怎样才算君子。孔子说：‘君子不忧愁，不恐惧。’司马牛问：‘不忧愁、不恐惧，就可以说是君子吗？’孔子说：‘反省自己而没有内疚，还有什么可忧愁、可恐惧的！’ [[27]](#sj067-disciple-27-note)

<a id="sj067-disciple-28-event"></a>

28. **樊迟问稼圃、仁与智，孔子从治理和识人作答。** 樊须字子迟，比孔子小三十六岁。樊迟请求学习种田。孔子说：‘我不如老农。’他又请求学习种菜，孔子说：‘我不如老菜农。’樊迟出去后，孔子说：‘樊须眼光真小啊！居上位的人爱好礼，百姓就不敢不恭敬；居上位的人爱好义，百姓就不敢不顺服；居上位的人爱好信，百姓就不敢不以实情相待。做到这样，四方百姓都会用背带背着孩子来归附，哪里还用自己去学种田！’樊迟问仁，孔子说：‘爱人。’又问智，孔子说：‘了解人。’ [[28]](#sj067-disciple-28-note)

<a id="sj067-disciple-29-event"></a>

29. **有若谈礼和、信义与恭敬。** 有若比孔子小四十三岁。他说：‘礼的运用，以和为可贵，先王的道好就好在这里。大小事情都按这个原则去做，也会有行不通的时候；只知道和可贵而一味求和，不用礼加以节制，也行不通。’又说：‘承诺接近于义，所说的话就能践行；恭敬接近于礼，就能远离耻辱；亲近的人不失为应该亲近的人，也就值得尊敬。’ [[29]](#sj067-disciple-29-note)

<a id="sj067-disciple-30-event"></a>

30. **公西赤出使齐国，冉有替其母请粟。** 公西赤字子华，比孔子小四十二岁。子华出使齐国，冉有替他的母亲请求粮食。孔子说：‘给她一釜。’冉有请求增加，孔子说：‘给她一庾。’冉有却给了她五秉粮食。孔子说：‘赤到齐国去，乘着肥壮的马，穿着轻暖的皮衣。我听说，君子救济急难，不给富者继续增益。’ [[30]](#sj067-disciple-30-note)

<a id="sj067-disciple-31-event"></a>

31. **巫马施转告陈司败对同姓婚姻的质疑。** 巫马施字子旗，比孔子小三十岁。陈国掌刑狱的司败问孔子：‘鲁昭公懂礼吗？’孔子说：‘懂礼。’孔子退下后，司败向巫马旗作揖，说：‘我听说君子不偏袒，君子也会偏袒吗？鲁君娶吴国女子为夫人，称她为孟子。她本姓姬，因为避讳同姓结婚，所以不称她吴姬而称孟子。鲁君若算懂礼，谁还不懂礼！’巫马施把这番话告诉孔子。孔子说：‘我真幸运，只要有过错，别人一定会知道。臣下不应当说国君、父母的恶处，为他们避讳，是礼。’ [[31]](#sj067-disciple-31-note)

<a id="sj067-disciple-32-event"></a>

32. **梁鱣等六位门人的记载简略，保留姓名、字和相对年龄。** 梁鱣字叔鱼，比孔子小二十九岁。颜幸字子柳，比孔子小四十六岁。冉孺字子鲁，比孔子小五十岁。曹卹字子循，比孔子小五十岁。伯虔字子析，比孔子小五十岁。公孙龙字子石，比孔子小五十三岁。 [[32]](#sj067-disciple-32-note)

<a id="sj067-disciple-33-event"></a>

33. **门人名籍中另有四十二人。** 除前面三十五人的较详记载外，还保存四十二人的名籍，许多人只有姓名、字，没有独立年岁或完整事迹。冉季的字是子产。公祖句兹的字是子之。秦祖的字是子南。漆雕哆的字是子敛。颜高的字是子骄。这里还列有漆雕徒父，未另记他的字。壤驷赤的字是子徒。这里还列有商泽，未另记他的字。石作蜀的字是子明。任不齐的字是选。公良孺的字是子正。后处的字是子里。秦冉的字是开。公夏首的字是乘。

    奚容箴的字是子皙。公肩定的字是子中。颜祖的字是襄。鄡单的字是子家。这里还列有句井疆，未另记他的字。罕父黑的字是子索。秦商的字是子丕。申党的字是周。颜之仆的字是叔。荣旂的字是子祈。县成的字是子祺。左人郢的字是行。燕伋的字是思。郑国的字是子徒。

    秦非的字是子之。施之常的字是子恒。颜哙的字是子声。步叔乘的字是子车。原亢，字籍。乐欬的字是子声。廉絜的字是庸。叔仲会的字是子期。颜何的字是冉。狄黑的字是皙。邦巽的字是子敛。这里还列有孔忠，未另记他的字。公西舆如的字是子上。公西葴的字也是子上。 [[33]](#sj067-disciple-33-note)

<a id="sj067-disciple-34-event"></a>

34. **孔子去世后，子夏在西河教授，后来成为魏文侯的老师。** 孔子去世后，子夏在西河授徒，后来成为魏文侯的老师。他的儿子去世时，他因痛哭而失明。 [[34]](#sj067-disciple-34-note)

<a id="sj067-disciple-35-event"></a>

35. **孔子去世后，原宪隐居，以贫与病的区别回应子贡。** 孔子去世后，原宪便隐居在荒野草泽之中。子贡在卫国为相，乘着四马驾的车，随从骑马相连，排开藜藿杂草，进入偏僻的小巷，拜访原宪。原宪整理好破旧的衣帽，出来见他。子贡为他的处境感到难堪，说：‘先生是不是困病了？’原宪说：‘我听说，没有财产叫作贫，学了道却不能实行才叫作病。像我，只是贫，并不是病。’子贡感到惭愧，怏怏离去，终身都以说错这番话为耻。 [[35]](#sj067-disciple-35-note)

<a id="sj067-disciple-36-event"></a>

36. **弟子因思慕孔子而立有若为师，后来又请他离座。** 孔子去世后，弟子们思念敬慕他。有若相貌像孔子，大家共同立他为师，像孔子在世时一样侍奉他。一天，弟子上前问：‘从前老师将要出行，让弟子带上雨具，后来果然下雨。弟子问他怎么知道，他说：“诗不是说，月亮运行到毕宿，就会下大雨吗？昨晚月亮不是停在毕宿吗？”可是另一天，月亮也在毕宿，却始终没有下雨。商瞿年纪大了还没有儿子，他母亲替他娶妻。孔子要派他去齐国，他母亲向孔子请求留他下来。孔子说：“不要担心，商瞿四十岁以后会有五个儿子。”后来果然如此。请问，老师怎样能预先知道这些？’有若默然，无法回答。弟子们站起来说：‘有子，请退开吧，这不是你能够坐的位子！’ [[36]](#sj067-disciple-36-note)

<a id="sj067-disciple-37-event"></a>

37. **后世学统附读：商瞿传易的世系延伸到西汉。** 孔子把《易》传给商瞿，商瞿传给楚人馯臂，字子弘；馯臂传给江东人矫疵，字子庸；矫疵传给燕人周竖，字子家；周竖传给淳于人光羽，字子乘；光羽传给齐人田何，字子庄；田何传给东武人王同，字子中；王同传给菑川人杨何。元朔年间，杨何因为研治《易》而担任汉朝的中大夫。 [[37]](#sj067-disciple-37-note)

<a id="sj067-disciple-38-event"></a>

38. **后世编纂与述赞附读：保存门人材料，也辨明评价者的时代。** 西汉的司马迁整理孔门弟子材料，认为赞毁都可能失真，因而重视孔氏古文中的名籍，合录问答，有疑问则留下空缺。到了唐代，司马贞又以述赞追怀孔门教化、弟子的才艺与仕进，并感叹老师有道而无位。这里读的是后世编纂与评价，不是春秋晚期另发生的一场政治事件。 [[38]](#sj067-disciple-38-note)

<a id="sj067-disciple-36-note"></a>

### 36. 弟子因思慕孔子而立有若为师，后来又请他离座

[返回正文第36条](#sj067-disciple-36-event)

<a id="sj067-cite-132"></a>

**[《史记·仲尼弟子列传》P098](../../sources/摘录/史记-卷067-仲尼弟子列传.md#p098)**

> 孔子既沒，弟子思慕，有若狀似孔子，弟子相與共立為師，師之如夫子時也。他日，弟子進問曰：「昔夫子當行，使弟子持雨具，已而果雨。弟子問曰：『夫子何以知之？』夫子曰：『《詩》不云乎？「月離于畢，俾滂沱矣。」昨暮月不宿畢乎？』他日，月宿畢，竟不雨。商瞿年長無子，其母為取室。孔子使之齊，瞿母請之。孔子曰：『無憂，瞿年四十後當有五丈夫子。』已而果然。問夫子何以知此？」有若默然無以應。弟子起曰：「有子避之，此非子之座也！」

**本卷说明：** 主文连叙预雨、生子两事，有若不能回答而退座；属于孔子卒后的追述故事，未据天象或预言倒定实际日期。正义引中备的筮法另属后出古注。

# 春秋末与战国初｜范蠡离越以后的未定年史事

[← 灭吴与越国称霸](bce-0473.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [相关楚越后续 →](../bce-0400-0301/bce-0334.md#sj041-event-6)

**时间范围：前473年灭吴以后，约前5世纪；只保留可以确知的相对先后。** 离越、到齐、居陶、幼子成年、楚国救中子与终老，没有可以据以逐事确定的公元年。文种之死发生在范蠡离越以后、勾践仍在世时，与范蠡相齐、迁陶不能强排精确年月。这是统一时间线中的时期正文，不是另一套按人物或史书重排的年表。

<a id="reading-start"></a>

[本期相关史料](#sources-start)

<a id="sj041-event-1"></a>

1. **范蠡离越，拒绝以国土和威胁留住自己。** 灭吴、渡淮称霸以后，范蠡已为上将军，却认为盛名之下难以久处。他写信向勾践辞行，说当初没有死于会稽之辱，是为了完成复仇，如今可以承担当时未受的诛罚。勾践许以分国，又以杀死相逼，范蠡仍坚持君可行君令、臣自持臣意，携珠玉和私人随从乘舟离开，不再返越。勾践把会稽山的一片地方定作他的奉邑。 [[1]](#sj041-note-1)

<a id="sj041-event-2"></a>

2. **文种没有离越，后来被逼自尽。** 范蠡到齐后致书文种，用鸟尽弓藏、兔死狗烹劝他退身，判断勾践可共患难而难共安乐。文种称病不朝，仍遭人诬告将作乱。勾践赐剑，说文种教伐吴七术，自己只用三术，其余可去为先王试行；文种遂自杀。这里的赐剑和讥刺话是逼死臣下的举动，不是文种真的又受命出征。 [[2]](#sj041-note-2)

<a id="sj041-event-3"></a>

3. **范蠡在齐辞相散财，转到陶经营货殖。** 范蠡从海路来到齐国，改称鸱夷子皮，与儿子在海边经营产业，积累数十万财产。齐人因其贤能请他为相，他却认为家有千金、官至卿相已是布衣所能达到的极点，长享尊名可能招祸，便归还相印，把财物分给知友乡人，携重宝离去。他到交通和货物流通便利的陶，自号陶朱公，再与儿子耕作养畜，贮货待时，追求十分之一利润，不久又成为巨富。 [[3]](#sj041-note-3)

<a id="sj041-event-4"></a>

4. **朱公中子被囚楚，长子坚持代幼子前往救援。** 朱公居陶后生幼子，等幼子成年，中子因杀人被囚楚。朱公承认罪当死，却希望凭财力和旧交求救，原打算让幼子携千镒黄金及书信去找庄生，将金装在粗布器中、用一辆牛车运送，并全听庄生安排。长子以自己是家督、未被遣行便是被父亲视为不肖为由，坚持请行，甚至以死相逼；其母也从旁劝说，朱公才改派长子。长子另带私金数百，到楚将父书和千金交给住在城郭旁、门前荒草蔓生的庄生。庄生嘱他立即离去，弟弟获释也不要问缘由；长子却私自留楚，又用私金贿赂当权者。庄生素以廉直受楚王尊敬，收金并非想占有，已告诉妻子事成要还，若自己突病来不及交代也须归还。长子并不知道这一安排。 [[4]](#sj041-note-4)

<a id="sj041-event-5"></a>

5. **楚王将施行赦令，长子却把千金取回。** 庄生借入见之机，以某星所在将不利楚国为由，劝楚王修德消灾。楚王准备大赦，命封三钱之府；权贵把这项迹象告诉长子，说历来将赦时便如此。长子以为弟弟无须再求人也会获赦，舍不得把千金白给庄生，前往告辞并暗示归金。庄生察觉他的心思，叫他自己到屋里取回，长子带着金子高兴离去。 [[5]](#sj041-note-5)

<a id="sj041-event-6"></a>

6. **楚王为避受赂之名，先杀朱公中子，次日才赦。** 庄生觉得被长子轻侮，再向楚王报告：道路上都说朱公家贿赂王左右，王施赦只是为了其子，谈不上为楚国修德。楚王恼怒，不愿被视为因富人之子施惠，命先论杀中子，第二天才发布赦令。长子只能带弟弟的遗体回家。 [[6]](#sj041-note-6)

<a id="sj041-event-7"></a>

7. **朱公从两子的成长经历解释失败，晚年终老于陶。** 长子带丧回来，母亲与乡人哀伤，朱公却独笑，说自己早已料到：长子小时候与他共历贫苦，知道挣钱艰难，不能忍受大量舍财；幼子出生便见富足，乘好车、驾良马逐兔，不知钱财来之不易，反而能为救人轻弃千金。他说明起初选幼子正为此，并非认为长子不爱弟弟。这是朱公对败局的解释。此后叙事以范蠡多次迁居、所到之处皆有成就作结，他最终老死在陶，留下陶朱公之称，具体卒年与寿数未载。 [[7]](#sj041-note-7)

## 本期相关史料

<a id="sj041-note-1"></a>

### 1. 范蠡离越，拒绝以国土和威胁留住自己

[返回正文第1条](#sj041-event-1)

<a id="sj041-cite-018"></a>

**[《史记·越王勾践世家》P018](../../拆分史书/史记/卷041.md#p018)**

> 范蠡事越王句踐，既苦身力，與句踐深謀二十餘年，竟滅吳，報會稽之恥，北渡兵於淮以臨齊、晉，號令中國，以尊周室，句踐以霸，而范蠡稱上將軍。還反國，范蠡以為大名之下，難以久居，且句踐為人可與同患，難與處安，為書辭句踐曰：「臣聞主憂臣勞，主辱臣死。昔者君王辱於會稽，所以不死，為此事也。今既以雪恥，臣請從會稽之誅。」句踐曰：「孤將與子分國而有之。不然，將加誅于子。」范蠡曰：「君行令，臣行意。」乃裝其輕寶珠玉，自與其私徒屬乘舟浮海以行，終不反。於是句踐表會稽山以為范蠡奉邑。

**本卷说明：** 本段在原卷后半重述灭吴与称霸，是离越故事的前因，不另造第二次战争。本篇未记西施同行；“苦身力”据三家注p17“苦身戮力”理解，不改原始字。

<a id="sj041-note-2"></a>

### 2. 文种没有离越，后来被逼自尽

[返回正文第2条](#sj041-event-2)

<a id="sj041-cite-019"></a>

**[《史记·越王勾践世家》P013](../../拆分史书/史记/卷041.md#p013)**

> 范蠡遂去，自齊遺大夫種書曰：「蜚鳥盡，良弓藏；狡兔死，走狗烹。越王為人長頸鳥喙，可與共患難，不可與共樂。子何不去？」種見書，稱病不朝。人或讒種且作亂，越王乃賜種劍曰：「子教寡人伐吳七術，寡人用其三而敗吳，其四在子，子為我從先王試之。」種遂自殺。

**本卷说明：** 发生在范蠡离越后，无明确卒年，不沿百科直接安到前472或前473。七术与正义引《越绝》九术为不同文本层次；长颈鸟喙是范蠡书中对君主性格的描写，不作现代相术断验。

<a id="sj041-note-3"></a>

### 3. 范蠡在齐辞相散财，转到陶经营货殖

[返回正文第3条](#sj041-event-3)

<a id="sj041-cite-020"></a>

**[《史记·越王勾践世家》P019](../../拆分史书/史记/卷041.md#p019)**

> 范蠡浮海出齊，變姓名，自謂鴟夷子皮，耕于海畔，苦身戮力，父子治產。居無幾何，致產數十萬。齊人聞其賢，以為相。范蠡喟然嘆曰：「居家則致千金，居官則至卿相，此布衣之極也。久受尊名，不祥。」乃歸相印，盡散其財，以分與知友鄉黨，而懷其重寶，閒行以去，止于陶，以為此天下之中，交易有無之路通，為生可以致富矣。於是自謂陶朱公。復約要父子耕畜，廢居，候時轉物，逐什一之利。居無何，則致貲累巨萬。天下稱陶朱公。

**本卷说明：** “居无几何”“居无何”均是约略时距；这里不借《货殖列传》的十九年三致千金或后世行年表，硬算每次迁居的年份。逐什一之利是经营收益的表述，不是税率。

<a id="sj041-note-4"></a>

### 4. 朱公中子被囚楚，长子坚持代幼子前往救援

[返回正文第4条](#sj041-event-4)

<a id="sj041-cite-021"></a>

**[《史记·越王勾践世家》P020](../../拆分史书/史记/卷041.md#p020)**

> 朱公居陶，生少子。少子及壯，而朱公中男殺人，囚於楚。朱公曰：「殺人而死，職也。然吾聞千金之子不死於市。」告其少子往視之。乃裝黃金千溢，置褐器中，載以一牛車。且遣其少子，朱公長男固請欲行，朱公不聽。長男曰：「家有長子曰家督，今弟有罪，大人不遣，乃遺少弟，是吾不肖。」欲自殺。其母為言曰：「今遣少子，未必能生中子也，而先空亡長男，柰何？」朱公不得已而遣長子，為一封書遺故所善莊生。曰：「至則進千金于莊生所，聽其所為，慎無與爭事。」長男既行，亦自私齎數百金。

**本卷说明：** 少子在陶出生后已长成，表明不能把救子故事压到离越同年。楚王无名；正义指出庄周比灭吴晚逾百年，这个庄生不能无据认成庄子。千镒保留古单位，不直接换算现代金价。

<a id="sj041-cite-022"></a>

**[《史记·越王勾践世家》P021](../../拆分史书/史记/卷041.md#p021)**

> 至楚，莊生家負郭，披藜藋到門，居甚貧。然長男發書進千金，如其父言。莊生曰：「可疾去矣，慎毋留！即弟出，勿問所以然。」長男既去，不過莊生而私留，以其私齎獻遺楚國貴人用事者。

**本卷说明：** 庄生要求离去、长子却私留并另贿权贵，是后续信息误判的关键；不是他已经依父命完全照办。

<a id="sj041-cite-023"></a>

**[《史记·越王勾践世家》P022](../../拆分史书/史记/卷041.md#p022)**

> 莊生雖居窮閻，然以廉直聞於國，自楚王以下皆師尊之。及朱公進金，非有意受也，欲以成事後復歸之以為信耳。故金至，謂其婦曰：「此朱公之金。有如病不宿誡，後復歸，勿動。」而朱公長男不知其意，以為殊無短長也。

**本卷说明：** “有如病不宿诫”是假设自己突然病故而未能交代，不是说庄生此时确已得绝症。其原拟归金与后来因受辱改言有先后之别。

<a id="sj041-note-5"></a>

### 5. 楚王将施行赦令，长子却把千金取回

[返回正文第5条](#sj041-event-5)

<a id="sj041-cite-024"></a>

**[《史记·越王勾践世家》P023](../../拆分史书/史记/卷041.md#p023)**

> 莊生閒時入見楚王，言「某星宿某，此則害於楚」。楚王素信莊生，曰：「今為柰何？」莊生曰：「獨以德為可以除之。」楚王曰：「生休矣，寡人將行之。」王乃使使者封三錢之府。楚貴人驚告朱公長男曰：「王且赦。」曰：「何以也？」曰：「每王且赦，常封三錢之府。昨暮王使使封之。」朱公長男以為赦，弟固當出也，重千金虛棄莊生，無所為也，乃復見莊生。莊生驚曰：「若不去邪？」長男曰：「固未也。初為事弟，弟今議自赦，故辭生去。」莊生知其意欲復得其金，曰：「若自入室取金。」長男即自入室取金持去，獨自歡幸。

**本卷说明：** 星占是庄生劝王的说辞，不作现代事实。三钱之府的币制解释及集解引汉灵帝时张成知赦故事属于后出注释，并非本故事发生年代；不能把汉人例证写成楚王当时的制度记录。

<a id="sj041-note-6"></a>

### 6. 楚王为避受赂之名，先杀朱公中子，次日才赦

[返回正文第6条](#sj041-event-6)

<a id="sj041-cite-025"></a>

**[《史记·越王勾践世家》P024](../../拆分史书/史记/卷041.md#p024)**

> 莊生羞為兒子所賣，乃入見楚王曰：「臣前言某星事，王言欲以修德報之。今臣出，道路皆言陶之富人朱公之子殺人囚楚，其家多持金錢賂王左右，故王非能恤楚國而赦，乃以朱公子故也。」楚王大怒曰：「寡人雖不德耳，柰何以朱公之子故而施惠乎！」令論殺朱公子，明日遂下赦令。朱公長男竟持其弟喪歸。

**本卷说明：** 本段是一次先杀特定囚犯、后颁赦令的变局，不能改写成赦令完全撤销或楚国所有囚徒遭杀。庄生的话是推动行动的指控，不等于王原先确已受朱公贿赂。

<a id="sj041-note-7"></a>

### 7. 朱公从两子的成长经历解释失败，晚年终老于陶

[返回正文第7条](#sj041-event-7)

<a id="sj041-cite-026"></a>

**[《史记·越王勾践世家》P025](../../拆分史书/史记/卷041.md#p025)**

> 至，其母及邑人盡哀之，唯朱公獨笑，曰：「吾固知必殺其弟也！彼非不愛其弟，顧有所不能忍者也。是少與我俱，見苦，為生難，故重棄財。至如少弟者，生而見我富，乘堅驅良逐狡兔，豈知財所從來，故輕棄之，非所惜吝。前日吾所為欲遣少子，固為其能棄財故也。而長者不能，故卒以殺其弟，事之理也，無足悲者。吾日夜固以望其喪之來也。」

**本卷说明：** 父亲对性情和经历的解释是一家之言，不引申为富家幼子必能救人、贫困长子必不能救人的普遍规律。

<a id="sj041-cite-027"></a>

**[《史记·越王勾践世家》P026](../../拆分史书/史记/卷041.md#p026)**

> 故范蠡三徙，成名於天下，非茍去而已，所止必成名。卒老死于陶，故世傳曰陶朱公。

**本卷说明：** 老死于陶为主文结局；三家注列华容、平阴陶山两类葬地材料并称未详，不据墓传反造准确卒年、生日或现代纪念日。

## 本年纪事

<a id="event-1"></a>

1. **鲁、齐修好，定公赴夹谷，孔丘辅助会盟。**

三月，鲁国与齐国修好。夏季，两君会于夹谷，孔丘担任辅相。齐方让莱人持兵迫近，孔丘护定公退避，要求守卫应对，并向齐方提出两君修好不应以兵扰盟；齐侯停止了这一行动。 [1](#note-1)

<a id="event-2"></a>

2. **夹谷盟约争取归田，齐国交回郓、讙、龟阴。**

盟约起草时，齐方要求今后出兵，鲁须派三百乘甲车随行。孔丘让兹无还回应，鲁履约也须以齐返还汶阳之田为条件。齐方原拟会后宴享，孔丘又通过梁丘据提出野外行享的礼仪问题，宴享未成。定公返鲁，齐国交回郓、讙、龟阴田。 [2](#note-2)

<a id="event-3"></a>

3. **赵鞅围卫，晋国随后处置涉佗、成何。**

晋国赵鞅围攻卫国，报复前一年夷仪之役。邯郸午与涉佗分别带兵到卫门示威。返国后，晋人追究卫国背离的原因，认为涉佗、成何此前在盟誓中失礼，把涉佗拘捕，想借此与卫修好；卫国仍不接受，晋遂杀涉佗，成何逃燕。 [3](#note-3)

<a id="event-4"></a>

4. **侯犯杀公若后据郈叛乱，鲁军两次围城未克。**

叔孙氏继承争议留下了公若与新宗主一方的仇怨。侯犯参与杀公若后，控制郈邑叛乱。叔孙州仇与孟懿子率军围郈，没有攻下；秋季再与齐军围攻，仍未成功。 [4](#note-4)

<a id="event-5"></a>

5. **驷赤策动郈人逐侯犯，郈回归叔孙氏。**

工师驷赤劝侯犯依靠齐国，又使郈人相信侯犯要拿城邑与齐交换、迁走居民，激起邑人恐慌。他再诱侯犯储甲门前，待齐人来视察时，呼称齐军已到。郈人取甲包围侯犯，迫他离开；驷赤留后接纳鲁军，侯犯逃齐，齐国将郈交回。 [5](#note-5)

<a id="event-6"></a>

6. **宋国乐大心出奔曹国。**

乐大心出奔曹国，成为宋国在外的反对力量之一。 [6](#note-6)

<a id="event-7"></a>

7. **宋公子地因白马与向魋结怨，公子辰也离宋赴陈。**

宋公子地有四匹白马，宋景公取去送给宠臣向魋，公子地又让人夺回。公子辰劝兄长暂时出境，以为宋公必会挽留，结果公子地逃陈后没有被召回。辰求情也未获准，冬季与仲佗、石彄一同奔陈。 [7](#note-7)

<a id="event-8"></a>

8. **齐、卫、郑在安甫会合。**

冬季，齐侯、卫侯与郑国游速在安甫会合，继续经营各国之间的关系。 [8](#note-8)

<a id="event-9"></a>

9. **叔孙州仇出聘齐国，谈及齐国协助归郈。**

叔孙州仇到齐国聘问。齐侯设享，提起郈在齐鲁交界，所以出面帮助鲁国。叔孙答复，叛臣本是各国共同要处置的问题，不应只当成齐给叔孙一家的私恩。 [9](#note-9)

### [5] 驷赤策动郈人逐侯犯，郈回归叔孙氏。

**《左传》·定公十年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0500.md#L51-L51)

> 秋，二子及齐师复围郈，弗克。叔孙谓郈工师驷赤曰：“郈非唯叔孙氏之忧，社稷之患也。将若之何？”对曰：“臣之业，在《扬水》卒章之四言矣。”叔孙稽首。驷赤谓侯犯曰：“居齐、鲁之际，而无事，必不可矣。子盍求事于齐以临民？不然，将叛。”侯犯从之。齐使至，驷赤与郈人为之宣言于郈中曰：“侯犯将以郈易于齐，齐人将迁郈民。”众兇惧。驷赤谓侯犯曰：“众言异矣，子不如易于齐。与其死也，犹是郈也。而得纾焉，何必此？齐人欲以此偪鲁，必倍与子地。且盍多舍甲于子之门，以备不虞？”侯犯曰：“诺。”乃多舍甲焉。侯犯请易于齐，齐有司观郈，将至。驷赤使周走呼曰：“齐师至矣！”郈人大骇，介侯犯之门甲，以围侯犯。驷赤将射之。侯犯止之曰：“谋免我。”侯犯请行，许之。驷赤先如宿，侯犯殿。每出一门，郈人闭之。及郭门，止之曰：“子以叔孙氏之甲出，有司若誅之，群臣惧死。”驷赤曰：“叔孙氏之甲有物，吾未敢以出。”犯谓驷赤曰：“子止而与之数。”驷赤止而纳鲁人。侯犯奔齐，齐人乃致郈。

**说明：** 关于换邑迁民的传言是驷赤发动邑众的策略，不全部认定为齐国已制定并开始实施的迁徙令。侯犯出去时被要求留下叔孙氏甲器，不写成携全城武备投齐。

> 武叔聘于齐。齐侯享之，曰：“子叔孙！若使郈在君之他竟，寡人何知焉？属与敝邑际，故敢助君忧之。”对曰：“非寡君之望也。所以事君，封疆社稷是以。敢以家隶勤君之执事。夫不令之臣，天下之所恶也。君岂以为寡君赐？”

**说明：** 叔孙州仇即武叔。其答辞作为外交立场展示，不由项目替两国计算恩义高低。

# 公元前512年（鲁昭公三十年）

## 本年纪事

<a id="event-1"></a>

1. **昭公仍住乾侯。**

正月，昭公继续居住乾侯。郓已在前一年溃散，他的流亡局面仍未改变。 [1](#note-1)

<a id="event-2"></a>

2. **晋顷公去世、下葬，郑国就丧使规格与晋交涉。**

六月，晋顷公去世；八月下葬。郑国由游吉一人兼办吊丧、送葬，晋方质问为何不再像往年分遣两人。游吉说明，小国承担贡赋与防备，丧使应按实际能力和礼制安排，大国不能只取往例最丰厚的一次，晋人未能再责难。 [2](#note-2)

<a id="event-3"></a>

3. **吴要求徐、钟吾拘捕流亡公子，楚接收两人。**

阖庐要求徐国拘掩馀、钟吾拘烛庸，两位公子遂逃往楚国。楚王厚加安置，令人在养地筑城，从城父及胡地取田给他们，打算牵制吴国。子西担忧这样会激怒吴，劝楚王暂缓，未被采纳。 [3](#note-3)

<a id="event-4"></a>

4. **吴国灭徐，徐君逃楚，楚援军来迟。**

冬季，吴王拘钟吾君，又进攻徐国，堵水灌城。徐国被灭，徐君章禹剪发，带夫人出迎吴王，随后被送往楚国。沈尹戌率楚军来救，已经来不及，转而筑夷城安置徐君。 [4](#note-4)

<a id="event-5"></a>

5. **伍员提出轮番出兵疲楚，阖庐接受。**

阖庐再问伍员如何伐楚。伍员建议把兵分为三部，轮流出动：楚军出迎，吴军就撤；楚军回去，吴再来，使楚不断奔走，再待其疲敝后合兵攻打。阖庐接受这一部署，后续对楚边境的连续行动由此接续。 [5](#note-5)

<a id="event-6"></a>

6. **吴军攻舒，阖庐暂缓直取郢都。**

阖庐派兵进攻楚国，伍员、伯嚭参与，吴军攻下舒，俘获先前流亡在外的两名吴公子。阖庐还想继续向郢推进，孙武提醒军民已经劳苦，应当等待时机，吴军便暂时撤回。

在这以前，伯嚭也因楚国的家难逃到吴，被任为大夫。他是伯州犁的孙子，后来与伍员一同参与谋楚。 [6](#note-6)


<a id="backstory-sj-065-L4642-01"></a>

#### 登场前事｜孙武：孙武以十三篇兵法见阖闾，在宫中试行军令

> 此前经历，确切年月未详；放在这里补叙，不表示发生于前512年。

孙武是齐人，拿兵法见吴王阖闾。阖闾已读十三篇，请他试着训练宫中妇人。孙武把一百八十人分成两队，以两名宠姬做队长，反复说明前后左右的动作。两次击鼓，妇人仍笑，他认为号令已明而不执行应追究队长，拒绝阖闾求情，斩两名队长，改任其他人；再次操练，众人都依令行动。阖闾不愿下台检阅，孙武以只喜其言、不用其实作答。书中最后说阖闾任他为将。

> 夏六月，晋顷公卒。

**《左传》·昭公三十年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0512.md#L29-L29)

> 秋八月，葬。郑游吉吊，且送葬。魏献子使士景伯诘之曰：“悼公之丧，子西吊，子送葬。今吾子无贰，何故？”对曰：“诸侯所以归晋君，礼也。礼也者，小事大，大字小之谓。事大在共其时命，字小在恤其所无。以敝邑居大国之间，共其职贡，与其备御不虞之患，岂忘共命。先王之制，诸侯之丧，士吊，大夫送葬。唯嘉好聘享三军之事，于是乎使卿。晋之丧事，敝邑之间，先君有所助执绋矣。若其不间，虽士大夫有所不获数矣。大国之惠，亦庆其加，而不讨其乏，明厎其情，取备而已，以为礼也。灵王之丧，我先君简公在楚，我先大夫印段实往，敝邑之少卿也。王吏不讨，恤所无也。今大夫曰，女盍从旧。旧有丰有省，不知所从。从其丰，则寡君幼弱，是以不共。从其省，则吉在此矣。唯大夫图之。”晋人不能诘。

**说明：** 游吉即子大叔。正文把交涉理由归给其发言，不把一国的外交主张当作普遍礼制已经无争议。


<a id="note-3"></a>

### [3] 吴要求徐、钟吾拘捕流亡公子，楚接收两人。

**《左传》·昭公三十年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0512.md#L31-L31)

> 吴子使徐人执掩馀，使钟吾人执烛庸。二公子奔楚，楚子大封而定其徙。使监马尹大心逆吴公子，使居养。莠尹然、左司马沈尹戌城之，取于城父与胡田以与之。将以害吴也。子西谏曰：“吴光新得国，而亲其民。视民如子，辛苦同之，将用之也。若好吴边疆，使柔服焉，犹惧其至。吾又疆其仇以重怒之，无乃不可乎。吴，周之胄裔也，而弃在海滨，不与姬通。今而始大，比于诸华。光又甚文，将自同于先王。不知天将以为虐乎，使翦丧吴国而封大异姓乎？其抑亦将卒以祚吴乎？其终不远矣。我盍姑亿吾鬼神，而宁吾族姓，以待其归。将焉用自播扬焉？”王弗听。

**说明：** 两位公子在前515年吴王僚遇刺后先逃徐、钟吾，本年才转入楚；三次地点不能压成同一次出奔。

> 吴子怒，冬十一月，吴子执钟吾子，遂伐徐，防山以水之。己卯，灭徐。徐子章禹断其发，携其夫人，以逆吴子。吴子唁而送之，使其迩臣从之，遂奔楚。楚沈尹戌帅师救徐，弗及，遂城夷，使徐子处之。

<a id="note-5"></a>

### [5] 伍员提出轮番出兵疲楚，阖庐接受。

**《左传》·昭公三十年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0512.md#L35-L35)

> 吴子问于伍员曰：“初而言伐楚，余知其可也，而恐其使余往也，又恶人之有余之功也。今余将自有之矣，伐楚何如？”对曰：“楚执政众而乖，莫適任患。若为三师以肄焉，一师至，彼必皆出。彼出则归，彼归则出，楚必道敝。亟肄以罢之，多方以误之，既罢而后以三军继之，必大克之。”阖庐从之。楚于是乎始病。

**说明：** 这是本年提出并采纳的方案，具体侵夷、潜、六、弦在下一年展开；不能把前506年吴入郢提前写到本年。

> 楚誅其大臣郤宛、伯州犁，伯州犁之孫伯嚭亡奔吳，吳亦以嚭為大夫。前王僚所遣二公子將兵伐楚者，道絕不得歸。後聞闔廬弒王僚自立，遂以其兵降楚，楚封之於舒。闔廬立三年，乃興師與伍胥、伯嚭伐楚，拔舒，遂禽故吳反二將軍。因欲至郢，將軍孫武曰：「民勞，未可，且待之。」乃歸。

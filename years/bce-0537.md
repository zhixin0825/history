# 公元前537年（鲁昭公五年）

## 本年纪事

<a id="event-1"></a>

1. **正月，鲁国撤去中军，三家重新分配公室所属。**

三军初立时，公室分为三份，季氏、叔孙氏、孟氏各取一份，各家征取方式还不完全相同。如今撤去中军，却没有简单地把人众交回国君，而是改成四份：季氏取两份，另外两家各一份，都直接征取，再向公室贡献。季孙让杜洩向叔孙豹灵柩通告，说这是死者的意愿，杜洩当场反驳。随后又有出葬路线之争，杜洩仍坚持旧礼，办完葬事后离去。 [1](#note-1)

<a id="event-2"></a>

2. **仲壬从齐国回来后被杀，竖牛不久也逃亡遇害。**

仲壬回鲁，季孙一度想让他接掌叔孙氏，南遗却阻止，并组织人手帮助竖牛在大库庭攻击仲壬。仲壬中箭身亡，竖牛把东部三十邑交给南遗。叔孙昭子随后召集家众，追究竖牛杀嫡、乱家、割邑的行为，命令处死他。竖牛逃向齐国，途中被孟丙、仲壬的儿子们杀死。 [2](#note-2)

<a id="event-3"></a>

3. **楚王杀屈申，晋楚婚事仍由新任官员接续办理。**

楚灵王怀疑屈申与吴国有两面关系，杀死屈申，改任屈生为莫敖。屈生与令尹子荡赴晋迎亲，途经郑国，郑伯分别慰劳。晋君在邢丘送出女子，郑伯由子产陪同前往相会。政治处置与婚聘并列发生，但不能据此认定屈申已经被证实通吴。 [3](#note-3)

<a id="event-4"></a>

4. **昭公到晋国朝见，礼仪无失，却引出仪节与国政的区别。**

昭公亲自赴晋，从郊外接待到临行赠礼，都按规定行事。晋平公因而问女叔齐是否可说鲁君善礼。女叔齐答复，这只能说明仪节没有出错；他另提到鲁国政令在卿家、公室已被四分，以及鲁莒争端等问题，认为不能仅凭外在礼节概括国政。 [4](#note-4)

<a id="event-5"></a>

5. **韩起与叔向赴楚送亲，楚王听从劝阻，没有侮辱晋使。**

韩起送亲到楚，叔向为副使。郑国使者在途中提醒他们防备，叔向表示应守信、守礼。楚王曾向大夫提出让韩起做守门人、让叔向受宫刑，以此辱晋。薳启彊没有顺着把事情办下去，而是逐项说明晋国其余卿族、军队和人事足以报复，质问楚国是否已有应对准备。楚王收回打算，改以厚礼接待两人，韩起归途中又经过郑国。 [5](#note-5)

<a id="event-6"></a>

6. **郑国罕虎到齐国娶亲，晏婴多次与他会面。**

罕虎到齐国，迎娶子尾家的女子。晏婴屡次拜见他，陈桓子便问缘故。晏婴用罕虎能够任用合适的人解释自己的重视。 [6](#note-6)

<a id="event-7"></a>

7. **莒国牟夷带地投鲁，晋方曾想扣留昭公，最后让他回国。**

夏季，牟夷带着牟娄和防兹来投鲁国，莒人向晋国申诉。昭公当时正在晋国，晋君想把他留下。范献子反对利用对方朝见时将其扣押，建议真要追究，应先遣返，再另行用兵。晋方因此让昭公回去，鲁君七月抵达本国。 [7](#note-7)

<a id="event-8"></a>

8. **莒军来讨取地之事，叔弓在蚡泉击败莒军。**

莒国自行出兵追究鲁国接收土地，却没有做好防备。戊辰，叔弓率鲁军在蚡泉发动攻击，当时莒军尚未完成列阵，遂遭击败。经传没有记下这一战的兵力、俘虏或伤亡数字。 [8](#note-8)

<a id="event-9"></a>

9. **秦景公去世，流亡晋国的秦后子回国。**

秦景公去世以后，他的弟弟鍼从晋国回到秦国。鍼元年离国时曾表示要等待新的国君，此时的归返与那次出奔相接。秦景公的葬事则在下一年另有记载。 [9](#note-9)

<a id="event-10"></a>

10. **楚国联合诸侯与越人再攻吴，未能突破吴国防备。**

十月，楚国为报复棘、栎、麻之役，召集诸侯和东夷出兵，越国大夫常寿过也率军来会。楚军一支仓促追击吴军，在鹊岸失利。吴君派弟弟蹶由犒师，楚王扣住他，原想杀来衅鼓；蹶由说明自己的使命就是观察楚军态度、让吴国早作准备，楚王遂没有杀他。楚军随后推进到罗汭、莱山等地，见吴已设防，无法深入，最终退兵，但把蹶由带走。 [10](#note-10)

> 五年春，王正月，舍中军。

**《左传》·昭公五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0537.md#L33-L33)

> 五年春，王正月，舍中军，卑公室也。毁中军于施氏，成诸臧氏。初作中军，三分公室而各有其一。季氏尽征之，叔孙氏臣其子弟，孟氏取其半焉。及其舍之也，四分公室，季氏择二，二子各一。皆尽征之，而贡于公。以书使杜洩告于殡，曰：“子固欲毁中军，既毁之矣，故告。”杜洩曰：“夫子唯不欲毁也，故盟诸僖闳，诅诸五父之衢。”受其书而投之，帅士而哭之。叔仲子谓季孙曰：“带受命于子叔孙曰，葬鲜者自西门。”季孙命杜洩。杜洩曰：“卿丧自朝，鲁礼也。吾子为国政，未改礼，而又迁之。群臣惧死，不敢自也。”既葬而行。

**说明：** “公室四分”涉及人众和征取关系，不只是军队数量减少。有关初作中军的制度是回叙；本年新事为撤中军和四分安排。杜洩反驳之辞说明竖牛上一年转述叔孙豹意愿不应直接采信。

> 初，穆子之生也，庄叔以《周易》筮之，遇《明夷》[插图]之《谦》[插图]，以示卜楚丘。曰：“是将行，而归为子祀。以谗人入，其名曰牛，卒以馁死。《明夷》，日也。日之数十，故有十时，亦当十位。自王已下，其二为公，其三为卿。日上其中，食日为二，旦日为三。《明夷》之《谦》，明而未融，其当旦乎。故曰为子祀。日之《谦》当鸟，故曰明夷于飞。明而未融，故曰垂其翼。象日之动，故曰君子于行。当三在旦，故曰三日不食。《离》，火也。《艮》，山也。《离》为火，火焚山，山败。于人为言，败言为谗。故曰有攸往。主人有言，言必谗也。纯《离》为牛。世乱谗胜，胜将適《离》，故曰其名曰牛。《谦》不足，飞不翔，垂不峻，翼。故曰其为子后乎。吾子，亚卿也，抑少不终。”

### [4] 昭公到晋国朝见，礼仪无失，却引出仪节与国政的区别。

**《春秋》·昭公五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0537.md#L17-L17)

> 公如晋。

**《左传》·昭公五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0537.md#L45-L45)

> 公如晋，自郊劳至于赠贿，无失礼。晋侯谓女叔齐曰：“鲁侯不亦善于礼乎？”对曰：“鲁侯焉知礼！”公曰：“何为？自郊劳至于赠贿，礼无违者，何故不知？”对曰：“是仪也，不可谓礼。礼所以守其国，行其政令，无失其民者也。今政令在家，不能取也。有子家羁，弗能用也。奸大国之盟，陵虐小国。利人之难，不知其私。公室四分，民食于他。思莫在公，不图其终。为国君，难将及身，不恤其所。礼之本末，将于此乎在，而屑屑焉习仪以亟。言善于礼，不亦远乎？”君子谓：“叔侯于是乎知礼。”

**说明：** 女叔齐对鲁政与昭公的评价是外交谈话中的判断，不是本项目对国君能力的总体评定。昭公本次归国受莒田争端影响，见第7条，不把“无失礼”误写成晋鲁没有争议。

**《左传》·昭公五年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0537.md#L49-L49)

> 及楚，楚子朝其大夫曰：“晋，吾仇敌也。苟得志焉，无恤其他。今其来者，上卿、上大夫也。若吾以韩起为阍，以羊舌肸为司宫，足以辱晋，吾亦得志矣，可乎？”大夫莫对。薳启彊曰：“可。苟有其备，何故不可？耻匹夫不可以无备，况耻国乎？是以圣王务行礼，不求耻人。朝聘有珪，享[插图]有璋，小有述职，大有巡功，设机而不倚，爵盈而不饮，宴有好货，飧有陪鼎，入有郊劳，出有赠贿，礼之至也。国家之败，失之道也，则祸乱兴。城濮之役，晋无楚备，以败于邲。邲之役，楚无晋备，以败于鄢。自鄢以来，晋不失备，而加之以礼，重之以睦，是以楚弗能报而求亲焉。既获姻亲，又欲耻之，以召寇仇，备之若何？谁其重此？若有其人，耻之可也。若其未有，君亦图之。晋之事君，臣曰可矣。求诸侯而麇至，求昏而荐女，君亲送之，上卿及上大夫致之。犹欲耻之，君其亦有备矣。不然，奈何？韩起之下，赵成、中行吴、魏舒、范鞅、知盈；羊舌肸之下，祁午、张趯、籍谈、女齐、梁丙、张骼、辅跞、苗贲皇，皆诸侯之选也。韩襄为公族大夫，韩须受命而使矣。箕襄、邢带、叔禽、叔椒、子羽，皆大家也。韩赋七邑，皆成县也。羊舌四族，皆强家也。晋人若丧韩起、杨肸，五卿、八大夫辅韩须、杨石，因其十家九县，长毂九百，其馀四十县，遗守四千，奋其武怒，以报其大耻，伯华谋之，中行伯、魏舒帅之，其蔑不济矣。君将以亲易怨，实无礼以速寇，而未有其备，使群臣往遗之禽，以逞君心，何不可之有？”王曰：“不穀之过也，大夫无辱。”厚为韩子礼。王欲敖叔向以其所不知，而不能。亦厚其礼。

> 楚子以驲至于罗汭。吴子使其弟蹶由犒师，楚人执之，将以衅鼓。王使问焉，曰：“女卜来吉乎？”对曰：“吉。寡君闻君将治兵于敝邑，卜之以守龟，曰，余亟使人犒师，请行以观王怒之疾徐，而为之备，尚克知之。龟兆告吉，曰，克可知也。君若[插图]焉，好逆使臣，滋敝邑休怠，而忘其死，亡无日矣。今君奋焉震电冯怒，虐执使臣，将以衅鼓，则吴知所备矣。敝邑虽羸，若早修完，其可以息师。难易有备，可谓吉矣。且吴社稷是卜，岂为一人。使臣获衅军鼓，而敝邑知备，以御不虞，其为吉孰大焉。国之守龟，其何事不卜？一臧一否，其谁能常之？城濮之兆，其报在邲。今此行也，其庸有报志。”乃弗杀。

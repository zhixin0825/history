# 公元前574年（鲁成公十七年）

[← 上一张已编年页：公元前575年](bce-0575.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前573年 →](bce-0573.md)

<a id="event-1"></a>

1. **春，卫北宫括侵郑；夏，鲁成公参加晋、齐、宋、卫、曹、邾等诸侯再次伐郑。** 郑国仍依楚，晋国连续发动征讨。[1]

<a id="event-2"></a>

2. **六月，诸侯在柯陵重申盟约；楚军随后救郑，诸侯撤退。** [2]

<a id="event-3"></a>

3. **秋，成公从会盟返回。** [3]

<a id="event-4"></a>

4. **齐国内部爆发高氏、国氏与声孟子集团冲突。** 鲍牵受刑，高无咎逃往莒国，齐国政局明显动荡。[4]

<a id="event-5"></a>

5. **九月，鲁国举行郊祭。** [5]

<a id="event-6"></a>

6. **冬，晋国再次向鲁求兵，诸侯又出兵伐郑并包围郑都；楚军救郑，诸侯撤军。** [6]

<a id="event-7"></a>

7. **公孙婴齐从郑战返鲁途中死于貍脤。** [7]

<a id="event-8"></a>

8. **十二月朔日发生日食；邾君貜且去世。** [8]

<a id="event-9"></a>

9. **晋厉公决心清洗三郤。** 胥童等发动袭击，郤锜、郤犫、郤至被杀。[9]

<a id="event-10"></a>

10. **胥童随后控制栾书、中行偃，但晋厉公没有继续诛杀二人。** 二人后来反而拘禁厉公。[10]

<a id="event-11"></a>

11. **楚国趁舒庸依吴而疏于防备，出兵灭舒庸。** [11]

2. **《春秋·成公十七年》**：“六月乙酉，同盟于柯陵。”

3. **《春秋·成公十七年》**：“秋，公至自会。”

<a id="note-5"></a>

6. **《春秋·成公十七年》**：“晋侯使荀罃来乞师。冬，公会单子、晋侯、宋公、卫侯、曹伯、齐人、邾人伐郑。十有一月，公至自伐郑。”

<a id="note-7"></a>

7. **《春秋·成公十七年》**：“壬申，公孙婴齐卒于貍脤。”

<a id="note-8"></a>

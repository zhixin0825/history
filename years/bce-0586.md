# 公元前586年（鲁成公五年）

[← 上一张已编年页：公元前587年](bce-0587.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前585年 →](bce-0585.md)

<a id="event-1"></a>

1. **春，杞叔姬被夫家遣回鲁国；仲孙蔑赴宋回聘。** [1]

<a id="event-2"></a>

2. **赵同、赵括把赵婴放逐到齐国。** 赵氏内部矛盾继续扩大。[2]

<a id="event-3"></a>

3. **夏，叔孙侨如在穀地会晋荀首。** 荀首此行是去齐国迎亲。[3]

<a id="event-4"></a>

4. **梁山崩塌。** 晋国依礼停乐、降服、出次并祭告山川。[4]

<a id="event-5"></a>

5. **郑悼公赴楚与许国争讼失败，楚人扣押郑大夫；郑国于是重新转向晋国。** 秋，郑伯与晋赵同在垂棘结盟。[5]

<a id="event-6"></a>

6. **秋，鲁国发生大水。** [6]

<a id="event-7"></a>

7. **冬，周定王去世；鲁成公与晋、齐、宋、卫、郑、曹、邾、杞在虫牢同盟。** 郑国重新服晋。[7]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·成公五年》**：“五年春，王正月，杞叔姬来归。仲孙蔑如宋。”

<a id="note-2"></a>

2. **《左传·成公五年》**详记原、屏放赵婴于齐。

<a id="note-3"></a>

3. **《春秋·成公五年》**：“夏，叔孙侨如会晋荀首于穀。”

<a id="note-4"></a>

4. **《春秋·成公五年》**：“梁山崩。”  
   **《左传·成公五年》**详记晋处理山崩礼仪。

<a id="note-5"></a>

5. **《左传·成公五年》**详记郑悼公讼许于楚失败、转而请成于晋并盟垂棘。

<a id="note-6"></a>

6. **《春秋·成公五年》**：“秋，大水。”

<a id="note-7"></a>

7. **《春秋·成公五年》**：“冬十有一月己酉，天王崩。十有二月己丑，公会晋侯、齐侯、宋公、卫侯、郑伯、曹伯、邾子、杞伯同盟于虫牢。”  
   **《左传·成公五年》**：“郑服也。”

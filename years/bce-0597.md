# 公元前597年（鲁宣公十二年）

[← 上一张已编年页：公元前598年](bce-0598.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前596年 →](bce-0596.md)

<a id="event-1"></a>

1. **春，鲁国安葬陈灵公。** [1]

<a id="event-2"></a>

2. **楚庄王大举围郑，攻破郑都；郑襄公肉袒牵羊请降。** [2]

<a id="event-3"></a>

3. **楚庄王没有灭郑，而是退军三十里，与郑讲和并交换人质。** [3]

<a id="event-4"></a>

4. **晋国出兵救郑。主帅荀林父得知郑已降楚后本想撤军，中军佐先縠却擅自渡河，坚持与楚交战。** [4]

<a id="event-5"></a>

5. **晋军内部将帅意见严重分裂，最终全军被拖入战斗。** [5]

<a id="event-6"></a>

6. **六月，晋楚在邲地决战，晋军大败。** 中、下军撤退混乱，上军相对完整地退走。[6]

<a id="event-7"></a>

7. **楚庄王没有把胜利用于夸示战果，而是提出“止戈为武”，把武功解释为禁暴、息兵、安民。** [7]

<a id="event-8"></a>

8. **晋军败归后，荀林父请求承担失败责任；晋景公最终仍让他继续任职。** [8]

<a id="event-9"></a>

9. **冬，楚庄王灭萧。** [9]

<a id="event-10"></a>

10. **晋、宋、卫、曹在清丘结盟；宋随后按盟约伐陈，卫国却出兵救陈。** 盟约刚形成便暴露出成员之间的分歧。[10]

# 公元前598年（鲁宣公十一年）

[← 上一张已编年页：公元前599年](bce-0599.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前597年 →](bce-0597.md)

<a id="event-1"></a>

1. **春，楚庄王进攻郑国，一直打到栎；郑国最终转而服楚。** [1]
<a id="event-2"></a>

2. **夏，楚庄王与陈侯、郑伯在辰陵结盟，陈、郑正式服从楚国。** [2]
<a id="event-3"></a>

3. **楚国令尹蒍艾猎在沂地筑城，工程三十天按期完工。** 这显示楚国军役组织已经相当成熟。[3]
<a id="event-4"></a>

4. **秋，晋成公在欑函会见众狄，众狄因厌恶赤狄而转向晋国。** [4]
<a id="event-5"></a>

5. **冬，楚庄王为陈国夏氏之乱伐陈，杀夏徵舒并车裂于栗门，随后把陈国并为县。** [5]
<a id="event-6"></a>

6. **申叔时批评：讨弑君者是义，但借讨罪吞并陈国就是贪。** 楚庄王接受劝告，恢复陈国，重新安置陈国旧臣。[6]
<a id="event-7"></a>

7. **公孙归父会齐军伐莒。** [7]

## 本年相关史料
<a id="note-1"></a>

1. **《左传·宣公十一年》**详记楚伐郑至栎、郑从楚。
<a id="note-2"></a>

2. **《春秋·宣公十一年》**：“夏，楚子、陈侯、郑伯盟于辰陵。” **《左传》**：“陈、郑服也。”
<a id="note-3"></a>

3. **《左传·宣公十一年》**详记蒍艾猎城沂，三旬而成。
<a id="note-4"></a>

4. **《春秋·宣公十一年》**：“秋，晋侯会狄于欑函。” **《左传》**：“众狄服也。”
<a id="note-5"></a>

5. **《春秋·宣公十一年》**：“冬十月，楚人杀陈夏徵舒。丁亥，楚子入陈。” **《左传》**详记杀徵舒、县陈。
<a id="note-6"></a>

6. **《春秋·宣公十一年》**：“纳公孙宁、仪行父于陈。” **《左传》**详记申叔时劝复陈。
<a id="note-7"></a>

7. **《春秋·宣公十一年》**：“公孙归父会齐人伐莒。”

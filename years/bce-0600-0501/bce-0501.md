# 公元前501年（鲁定公九年）

## 本年纪事

<a id="event-1"></a>

1. **宋国遣使迎乐祁遗体，乐大心被逐。**

宋景公要乐大心赴晋盟誓、迎回乐祁遗体，乐大心称病推辞，宋国改派向巢。乐祁之子与乐大心又因居丧、作乐相互指责，继而告称乐大心将不利戴氏、准备作乱，宋国将他逐走。 [1](#note-1)

<a id="event-2"></a>

2. **驷歂杀邓析，仍采用他的竹刑。**

郑国执政驷歂杀死邓析，却采用他所作的竹刑。传文对此提出批评：既取其有益之法，却不顾作者本人，无法鼓励有才能者。 [2](#note-2)

<a id="event-3"></a>

3. **郑献公去世，六月下葬。**

四月戊申，郑伯虿去世；六月，郑国安葬献公。 [3](#note-3)

<a id="event-4"></a>

4. **阳虎归还宝玉大弓，鲁国重新取得礼器。**

夏季，阳虎将此前带走的宝玉、大弓交回，鲁国重新取得这批器物。 [4](#note-4)

<a id="event-5"></a>

5. **鲁军攻阳关，阳虎逃齐，再经宋投晋赵氏。**

六月，鲁军攻阳关，阳虎令焚莱门，趁军中惊乱冲出，逃到齐国，请齐军攻鲁。鲍文子劝齐侯不要收用一个准备反噬所依附者的人，齐国转而拘禁阳虎。阳虎利用藏身车辆、破坏车轴等手段两次逃脱，最后经宋国来到晋国，投赵氏。 [5](#note-5)

<a id="event-6"></a>

6. **齐、卫进逼晋地，齐军得城后又被中牟军击败。**

秋季，齐侯进攻夷仪，齐将敝无存战死，东郭书与犁弥等先后登城。卫侯赴五氏，经过有晋军驻扎的中牟，中牟人原想攻卫，后来听褚师圃建议，转击已获城、戒备松懈的齐军，击败齐师。齐侯又把禚、媚、杏给予卫国，并处理将士封赏。 [6](#note-6)

<a id="event-7"></a>

7. **齐景公为敝无存收尸，安排厚葬。**

齐军还在夷仪时，齐侯悬赏寻找敝无存，取得尸体后，赐丧服、车盖，并令军众哭悼，自己也参与送行。 [7](#note-7)

<a id="event-8"></a>

8. **秦哀公去世，冬季下葬。**

秦哀公去世，冬季下葬。前506年允诺援楚的秦君，至此结束在位。 [8](#note-8)

[年首与季节题记](#note-calendar)：保留只有年月、没有独立事件的经文，不另造白话史事。

新立的惠公是早死太子夷公之子，王位越过了未及即位的一代。

<a id="note-1"></a>

### [[1]](#note-1) 宋国遣使迎乐祁遗体，乐大心被逐。

**《左传》·定公九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0501.md#L31-L31)

> 九年春，宋公使乐大心盟于晋，且逆乐祁之尸。辞，伪有疾。乃使向巢如晋盟，且逆子梁之尸。子明谓桐门右师出，曰：“吾犹衰绖，而子击钟，何也？”右师曰：“丧不在此故也。”既而告人曰：“己衰绖而生子，余何故舍钟？”子明闻之怒，言于公曰：“右师将不利戴氏，不肯適晋，将作乱也。不然无疾。”乃逐桐门右师。

**说明：** “将作乱”是告发者的指控，不当作已证政变。乐大心又称桐门右师；经文明列奔曹在次年，本页只记传文的被逐，次年补经文去向，不新造第二次驱逐。


<a id="note-2"></a>

### [[2]](#note-2) 驷歂杀邓析，仍采用他的竹刑。

**《左传》·定公九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0501.md#L33-L33)

> 郑驷歂杀邓析，而用其竹刑。君子谓：“子然于是不忠。苟有可以加于国家者，弃其邪可也。《静女》之三章，取彤管焉。《竿旄》‘何以告之’，取其忠也。故用其道，不弃其人。《诗》云：‘蔽芾甘棠，勿翦勿伐，召伯所茇。’思其人犹爱其树，况用其道而不恤其人乎？子然无以劝能矣。”

**说明：** 杀邓析的具体罪名及审理经过不见本段。竹刑的内容不能从后代法典移来；“不忠”是传文评论。

**《左传》·定公九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0501.md#L35-L35)

<a id="note-5"></a>

### [[5]](#note-5) 鲁军攻阳关，阳虎逃齐，再经宋投晋赵氏。

**《左传》·定公九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0501.md#L37-L37)

> 六月，伐阳关。阳虎使焚莱门。师惊，犯之而出，奔齐，请师以伐鲁，曰：“三加必取之。”齐侯将许之。鲍文子谏曰：“臣尝为隶于施氏矣。鲁未可取也。上下犹和，众庶犹睦，能事大国，而无天菑。若之何取之？阳虎欲勤齐师也，齐师罢，大臣必多死亡，己于是乎奋其诈谋。夫阳虎有宠于季氏，而将杀季孙，以不利鲁国，而求容焉。亲富不亲仁，君焉用之？君富于季氏，而大于鲁国，兹阳虎所欲倾覆也。鲁免其疾，而君又收之，无乃害乎？”齐侯执阳虎，将东之。阳虎愿东，乃囚诸西鄙。尽借邑人之车，锲其轴，麻约而归之。载葱灵，寝于其中而逃。追而得之，囚于齐。又以葱灵逃，奔宋，遂奔晋，適赵氏。仲尼曰：“赵氏其世有乱乎。”

**《史记·鲁周公世家》·九年：阳虎逃齐、奔赵** · [核对来源](https://zh.wikisource.org/w/index.php?oldid=7909289&title=史記/魯周公世家)

> 九年，魯伐陽虎，陽虎奔齊，已而奔晉趙氏。

**说明：** 《鲁周公世家》只概括奔齐、奔赵，传文补两次被拘逃脱及经过宋国。阳虎声称“三加必取之”是请兵时的承诺，不证明鲁国实际只需三战便可灭。


<a id="note-6"></a>

### [[6]](#note-6) 齐、卫进逼晋地，齐军得城后又被中牟军击败。

**《春秋》·定公九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0501.md#L21-L21)

> 秋，齐侯、卫侯次于五氏。

**《左传》·定公九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0501.md#L39-L39)

> 秋，齐侯伐晋夷仪。敝无存之父将室之，辞，以与其弟，曰：“此役也不死，反必娶于高、国。”先登，求自门出，死于霤下。东郭书让登，犁弥从之，曰：“子让而左，我让而右，使登者绝而后下。”书左，弥先下。书与王猛息。猛曰：“我先登。”书敛甲曰：“曩者之难，今又难焉。”猛笑曰：“吾从子如骖之靳。”

**《左传》·定公九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0501.md#L41-L41)

> 晋车千乘在中牟。卫侯将如五氏，卜过之，龟焦。卫侯曰：“可也。卫车当其半，寡人当其半，敌矣。”乃过中牟。中牟人欲伐之，卫褚师圃亡在中牟，曰：“卫虽小，其君在焉，未可胜也。齐师克城而骄，其帅又贱，遇，必败之，不如从齐。”乃伐齐师，败之。齐侯致禚、媚、杏于卫。齐侯赏犁弥，犁弥辞曰：“有先登者，臣从之。晳帻而衣貍製。”公使视东郭书，曰：“乃夫子也，吾貺子。”公赏东郭书，辞曰：“彼宾旅也。”乃赏犁弥。

**说明：** 人物王猛在此为齐军中人，不与前520年已故周悼王同名便合一。卜龟焦、卫侯估计车数是出行时的解释，不据此认定卜筮有效。


<a id="note-7"></a>

### [[7]](#note-7) 齐景公为敝无存收尸，安排厚葬。

**《左传》·定公九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/f70523e1175281931ccba31a3f8aceba9d870e53/working-texts/zuozhuan-punctuated-years/years/bce-0501.md#L43-L43)

> 齐师之在夷仪也，齐侯谓夷仪人曰：“得敝无存者，以五家免。”乃得其尸。公三襚之；与之犀轩与直盖，而先归之；坐引者，以师哭之，亲推之三。

**说明：** 这是上一条战死者的丧事，不重复计作另一场战斗；不从葬礼待遇推定全部军士享有同样制度。

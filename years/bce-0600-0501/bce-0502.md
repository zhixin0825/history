<a id="本年纪事"></a>
<a id="event-1"></a>

1. **正月定公攻齐，在阳州城门交战后返回。** 正月，定公率军进攻齐国，到阳州城门外。鲁军传看颜高的强弓，齐人出击后，颜高在交战中倒地，仍射杀对手；军队撤退时，冉猛假装伤足先退，其兄却称他在殿后。鲁军最终回国。 [[1]](#note-1)

<a id="event-2"></a>

2. **单、刘攻打数处据点，继续平定周室。** 二月，单氏与刘氏分别攻穀城、仪栗，随后又攻简城、盂，继续扫除上一年战乱留下的据点。 [[2]](#note-2)

<a id="event-3"></a>

3. **乐祁获释后死在返程，晋国又扣留遗体。** 赵鞅劝晋侯释放乐祁，认为继续拘使会断绝与宋的关系。范献子仍提出留人或让其子代留。乐祁最后获归，却死在太行途中。晋方又把遗体扣在州地，试图以此争取宋国恢复关系。 [[3]](#note-3)

<a id="event-4"></a>

4. **二月鲁军再次攻齐，在廪丘外城交战。** 二月，定公又攻齐，进攻廪丘外城。守军焚烧攻城车，鲁军有人用浸湿的马衣救火，随后破坏外城防御；守军出击时鲁军又退。阳虎激将冉猛追敌，冉猛见无人跟上，装跌倒退出。三月，定公返鲁。 [[4]](#note-4)

<a id="event-5"></a>

5. **曹靖公去世，秋季下葬。** 曹伯露去世，秋季曹国安葬靖公。 [[5]](#note-5)

<a id="event-6"></a>

6. **齐军再攻鲁，晋军来救，定公与晋军会于瓦。** 夏季，齐国国夏、高张进攻鲁国西境。晋国士鞅、赵鞅、荀寅率军援鲁，定公在瓦与晋军会合，随后返回。会见时晋卿所执礼物有羔、有雁，鲁国由此开始尊尚羔礼。 [[6]](#note-6)

<a id="event-7"></a>

7. **卫侯在盟誓中受辱，卫国决定背离晋国。** 晋军准备与卫侯在泽结盟，涉佗、成何轻视卫国，拒绝其礼位要求，涉佗又在歃血时推压卫侯之手。卫侯和王孙贾随后通过向大夫、国人提出受辱、送质子及承受晋军进攻的问题，争取支持。卫国决定不再服从晋国，晋人请求重盟，也未获接受。 [[7]](#note-7)

<a id="event-8"></a>

8. **陈怀公去世，九月下葬。** 七月戊辰，陈侯柳去世；九月，陈国安葬怀公。 [[8]](#note-8)

<a id="event-9"></a>

9. **晋军侵郑、侵卫，鲁军也为晋出兵。** 秋季，士鞅与成桓公会合，进攻郑国、围虫牢，追究伊阙一带的冲突，随后又攻卫。九月，季孙斯、仲孙何忌也率鲁军侵卫，援助晋方。 [[9]](#note-9)

<a id="event-10"></a>

10. **卫、郑在曲濮结盟。** 冬季，卫侯与郑伯在曲濮盟誓，两国在与晋关系紧张时继续相互靠拢。 [[10]](#note-10)

<a id="event-11"></a>

11. **阳虎谋换三桓宗主，以祭祀、宴享作行动准备。** 季寤、公鉏极、公山不狃、叔孙辄、叔仲志等对既有地位不满，依靠阳虎谋划。阳虎打算以季寤代季氏、叔孙辄代叔孙氏，自己代孟氏。十月，他安排顺祀先公、禘祭僖公，并准备在蒲圃宴享时杀季桓子。公敛处父从征集军车中察觉异常，提醒孟懿子预先戒备。 [[11]](#note-11)

<a id="event-12"></a>

12. **季桓子脱险，阳虎劫君攻孟失败，带宝玉大弓据邑叛。** 阳虎押送季桓子前往蒲圃，季桓子说动御者林楚，驾车冲入已戒备的孟氏。阳越追射不中，反被射杀。阳虎转而劫持定公与叔孙武叔攻孟氏，公敛处父率成人入援，先败后胜。阳虎于是脱甲入公宫，取走宝玉、大弓，离开都城，退入讙、阳关据守。 [[12]](#note-12)

<a id="event-13"></a>

13. **郑国驷歂接掌政务。** 驷歂接替子大叔，主持郑国政务。子大叔已在前506年去世，本年年条记录这一继任安排。 [[13]](#note-13)

<a id="sj014-audit-0502-chu"></a>

<a id="event-14"></a>

14. **楚子西与民众相泣，蔡昭侯感到不安。** 子西向楚国民众表达患难之情，民众也为之流泪；年表接着记蔡昭侯因此恐惧楚国再来追究。 [[14]](#note-14)

### 7. 卫侯在盟誓中受辱，卫国决定背离晋国

[返回正文第7条](#event-7)

> 晋师将盟卫侯于泽。赵简子曰：“群臣谁敢盟卫君者？”涉佗、成何曰：“我能盟之。”卫人请执牛耳。成何曰：“卫，吾温原也，焉得视诸侯？”将歃，涉佗捘卫侯之手及捥，卫侯怒。王孙贾趋进曰：“盟以信礼也。有如卫君，其敢不唯礼是事，而受此盟也？”

> 卫侯欲叛晋，而患诸大夫。王孙贾使次于郊，大夫问故。公以晋诟语之，且曰：“寡人辱社稷，其改卜嗣，寡人从焉。”大夫曰：“是卫之祸，岂君之过也？”公曰：“又有患焉，谓寡人必以而子与大夫之子为质。”大夫曰：“苟有益也，公子则往。群臣之子，敢不皆负羁絏以从。”将行，王孙贾曰：“苟卫国有难，工商未尝不为患，使皆行而后可。”公以告大夫，乃皆将行之。行有日，公朝国人，使贾问焉，曰：“若卫叛晋，晋五伐我，病何如矣？”皆曰：“五伐我，犹可以能战。”贾曰：“然则如叛之，病而后质焉，何迟之有？”乃叛晋。晋人请改盟，弗许。

### 12. 季桓子脱险，阳虎劫君攻孟失败，带宝玉大弓据邑叛

[返回正文第12条](#event-12)

> 盗窃宝玉、大弓。

> 阳虎前驱，林楚御桓子，虞人以铍盾夹之，阳越殿。将如蒲圃，桓子咋谓林楚曰：“而先皆季氏之良也，尔以是继之。”对曰：“臣闻命后。阳虎为政，鲁国服焉。违之，征死。死无益于主。”桓子曰：“何后之有？而能以我適孟氏乎？”对曰：“不敢爱死，惧不免主。”桓子曰：“往也。”孟氏选圉人之壮者三百人，以为公期筑室于门外。林楚怒马，及衢而骋，阳越射之，不中，筑者阖门。有自门间射阳越，杀之。阳虎劫公与武叔，以伐孟氏。公敛处父帅成人，自上东门入，与阳氏战于南门之内，弗胜。又战于棘下，阳氏败。阳虎说甲如公宫，取宝玉大弓以出，舍于五父之衢，寝而为食。其徒曰：“追其将至。”虎曰：“鲁人闻余出，喜于征死，何暇追余？”从者曰：“嘻！速驾，公敛阳在。”公敛阳请追之，孟孙弗许。阳欲杀桓子，孟孙惧而归之。子言辨舍爵于季氏之庙而出。阳虎入于讙、阳关以叛。

> 八年，陽虎欲盡殺三桓適，而更立其所善庶子以代之；載季桓子將殺之，桓子詐而得脫。三桓共攻陽虎，陽虎居陽關。

> 赵鞅言于晋侯曰：“诸侯唯宋事晋，好逆其使，犹惧不至。今又执之，是绝诸侯也。”将归乐祁。士鞅曰：“三年止之，无故而归之，宋必叛晋。”献子私谓子梁曰：“寡君惧不得事宋君，是以止子。子姑使溷代子。”子梁以告陈寅。陈寅曰：“宋将叛晋，是弃溷也。不如待之。”乐祁归，卒于大行。士鞅曰：“宋必叛，不如止其尸以求成焉。”乃止诸州。

**说明：** 子梁即乐祁，溷是其子。释放、途中去世、扣尸是三步，不写成晋国直接处死使者；死因原文没有说明。

<a id="7note-7-卫侯在盟誓中受辱卫国决定背离晋国"></a>
#### [[7]](#note-7) 卫侯在盟誓中受辱，卫国决定背离晋国。

**《左传》·定公八年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0502.md#all-20261109-t006)

> 晋师将盟卫侯于泽。赵简子曰：“群臣谁敢盟卫君者？”涉佗、成何曰：“我能盟之。”卫人请执牛耳。成何曰：“卫，吾温原也，焉得视诸侯？”将歃，涉佗捘卫侯之手及捥，卫侯怒。王孙贾趋进曰：“盟以信礼也。有如卫君，其敢不唯礼是事，而受此盟也？”

**《左传》·定公八年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0502.md#all-20261109-t007)

> 卫侯欲叛晋，而患诸大夫。王孙贾使次于郊，大夫问故。公以晋诟语之，且曰：“寡人辱社稷，其改卜嗣，寡人从焉。”大夫曰：“是卫之祸，岂君之过也？”公曰：“又有患焉，谓寡人必以而子与大夫之子为质。”大夫曰：“苟有益也，公子则往。群臣之子，敢不皆负羁絏以从。”将行，王孙贾曰：“苟卫国有难，工商未尝不为患，使皆行而后可。”公以告大夫，乃皆将行之。行有日，公朝国人，使贾问焉，曰：“若卫叛晋，晋五伐我，病何如矣？”皆曰：“五伐我，犹可以能战。”贾曰：“然则如叛之，病而后质焉，何迟之有？”乃叛晋。晋人请改盟，弗许。

**说明：** “五伐我，犹可以能战”是国人的应答，不是本年已发生五次战争。对“温原”的贬称是成何之言，不作项目对卫地位的独立断语。

**《春秋》·定公八年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0502.md#all-20261109-j016)

**《左传》·定公八年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0502.md#all-20261109-t012)

> 阳虎前驱，林楚御桓子，虞人以铍盾夹之，阳越殿。将如蒲圃，桓子咋谓林楚曰：“而先皆季氏之良也，尔以是继之。”对曰：“臣闻命后。阳虎为政，鲁国服焉。违之，征死。死无益于主。”桓子曰：“何后之有？而能以我適孟氏乎？”对曰：“不敢爱死，惧不免主。”桓子曰：“往也。”孟氏选圉人之壮者三百人，以为公期筑室于门外。林楚怒马，及衢而骋，阳越射之，不中，筑者阖门。有自门间射阳越，杀之。阳虎劫公与武叔，以伐孟氏。公敛处父帅成人，自上东门入，与阳氏战于南门之内，弗胜。又战于棘下，阳氏败。阳虎说甲如公宫，取宝玉大弓以出，舍于五父之衢，寝而为食。其徒曰：“追其将至。”虎曰：“鲁人闻余出，喜于征死，何暇追余？”从者曰：“嘻！速驾，公敛阳在。”公敛阳请追之，孟孙弗许。阳欲杀桓子，孟孙惧而归之。子言辨舍爵于季氏之庙而出。阳虎入于讙、阳关以叛。

**《史记·鲁周公世家》·八年：阳虎谋换三桓、据阳关** · [核对来源](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E9%AD%AF%E5%91%A8%E5%85%AC%E4%B8%96%E5%AE%B6.md#ref-2964d3a06d318a)

> 八年，陽虎欲盡殺三桓適，而更立其所善庶子以代之；載季桓子將殺之，桓子詐而得脫。三桓共攻陽虎，陽虎居陽關。

**说明：** 《鲁周公世家》概括三桓共攻，正文用传文补出御者改变路线、挟君与两次交战。盗器和据邑不等于此时已逃齐；真正出奔在下一年。

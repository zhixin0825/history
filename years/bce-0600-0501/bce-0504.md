<a id="本年纪事"></a>
<a id="event-1"></a>

1. **郑国趁楚战败，攻灭许国。** 正月癸亥，郑国游速率军灭许，俘获许君斯。楚国刚遭吴军重创，无力像以往一样保护许国，郑国便乘此机会出兵。 [[1]](#note-1)

<a id="event-2"></a>

2. **定公替晋攻郑，返程过卫引发争执。** 二月，定公攻郑，取得匡地，替晋追究郑国进攻胥靡之事。鲁军去时未经卫国许可借道，返回时阳虎又令季、孟两家军队穿过卫城。卫侯派人追击，公叔文子劝他不要以一时冲突抹去此前援助鲁昭公的往来，卫侯才停止追击。定公随后返鲁。 [[2]](#note-2)

<a id="event-3"></a>

3. **季桓子、孟懿子赴晋，孟氏谈起阳虎的去向。** 夏季，季桓子赴晋献郑国俘虏。阳虎强令孟懿子一同前往，办理答谢聘币之事。晋国合并宴享二人，孟懿子向范献子提出，若阳虎日后不能留鲁而投晋，应给他中军司马一职；范献子没有应允。事后范献子向赵鞅解释，鲁人已经忧虑阳虎，孟氏知道他可能逃晋，才故意提出这种请求。 [[3]](#note-3)

<a id="event-4"></a>

4. **吴再攻楚取番，楚迁都鄀并调整政务。** 四月吴太子终累败楚舟师，俘多名大夫，子期所领陆军也在繁扬失利。子西借危机推动调整，楚王廷离郢北移至鄀，重整政务以稳住战后局面。 [[4]](#note-4)

<a id="event-5"></a>

5. **儋翩联合郑国扰周，敬王再避居姑莸。** 王子朝虽然已死，儋翩仍率其党众，借郑国势力准备在周室起事。郑军攻冯、滑、胥靡等地，晋国六月派阎没驻周、修筑胥靡。到十二月，敬王为避乱迁居姑莸。 [[5]](#note-5)

    [卷四互见与归年](#sj004-504-1)

<a id="event-6"></a>

6. **宋使乐祁在晋遭拘，范、赵之间的往来成为争端。** 八月，宋国乐祁建议按时出使晋国，景公便派他前往。乐祁的家宰陈寅预先劝他安排继承人。抵晋后，赵鞅在绵上迎他饮酒，乐祁又献六十面杨木盾。范献子以使者尚未完成国命便私宴为由，向晋侯提出追究，晋方拘捕乐祁。 [[6]](#note-6)

<a id="event-7"></a>

7. **阳虎再次迫鲁君与三桓盟誓。** 阳虎在周社与定公、三桓盟誓，又在亳社令国人盟誓，在五父之衢举行诅誓。控制不再只限季氏一家，而涉及国君、卿族与国人。 [[7]](#note-7)

<a id="event-8"></a>

8. **鲁国筑中城，又由季、孟率军围郓。** 冬季，鲁国修筑中城。季孙斯与仲孙何忌又率军围攻郓地，继续处理昭公流亡后留下的据点问题。 [[8]](#note-8)

<a id="sj014-audit-0504-yan"></a>

<a id="event-9"></a>

9. **燕简公元年。** 燕国在平公之后开始简公纪年。 [[9]](#note-9)

**《左传》·定公六年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0504.md#all-20261109-t006)

> 秋八月，宋乐祁言于景公曰：“诸侯唯我事晋，今使不往，晋其憾矣。”乐祁告其宰陈寅。陈寅曰：“必使子往。”他日，公谓乐祁曰：“唯寡人说子之言，子必往。”陈寅曰：“子立后而行，吾室亦不亡。唯君亦以我为知难而行也。”见溷而行。赵简子逆而饮之酒于绵上，献杨楯六十于简子。陈寅曰：“昔吾主范氏，今子主赵氏，又有纳焉。以杨楯贾祸，弗可为也已。然子死晋国，子孙必得志于宋。”范献子言于晋侯曰：“以君命越疆而使，未致使而私饮酒，不敬二君，不可不讨也。”乃执乐祁。

**说明：** 乐祁又称乐祁犁、子梁。陈寅将此事联系宋原先亲范、现在亲赵的变化，作为他的分析保留；不可仅据盾牌馈赠就额外认定一项未载的贿赂罪。

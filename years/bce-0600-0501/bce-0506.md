<a id="本年纪事"></a>
<a id="event-1"></a>

1. **陈惠公去世，六月下葬。** 二月癸巳，陈惠公吴去世。六月，陈国为他举行葬礼。 [[1]](#note-1)

<a id="event-2"></a>

2. **诸侯在召陵会师，晋国最终没有替蔡深入伐楚。** 三月，刘文公召诸侯在召陵集合，商议伐楚，定公也参加。晋国荀寅向蔡侯索财未成，转向范献子强调国内危险、诸侯不齐与中山未服等困难。晋方因此辞谢蔡侯，没有落实蔡国期待的大举深入进攻。 [[2]](#note-2)

<a id="event-3"></a>

3. **皋鼬会盟争论蔡、卫先后，卫国获排在蔡前。** 五月，诸侯在皋鼬盟誓。原拟让蔡侯排在卫侯前，卫国祝佗向苌弘援引周初封建、康叔与蔡叔事迹，以及践土旧盟名次争辩。苌弘与刘文公、范献子商议，最后将卫侯排在蔡侯前。七月，定公由会盟返回。 [[3]](#note-3)

<a id="event-4"></a>

4. **子大叔在会盟返程去世。** 郑国子大叔参加召陵之会，回国途中尚未抵达便去世。赵鞅临丧哀悼，回忆他曾在黄父之会提出九条劝告。 [[4]](#note-4)

<a id="event-5"></a>

5. **蔡国灭沈、杀沈君，楚国随后围蔡。** 沈国没有参加召陵会议，晋国使蔡出兵惩讨。四月，蔡将公孙姓灭沈，带回沈君嘉并杀死。秋季，楚国为沈出兵围蔡，蔡侯转而以儿子及大夫子弟作质，向吴国求援。 [[5]](#note-5)

<a id="event-6"></a>

6. **杞悼公在会中去世，秋季下葬。** 杞伯成参加诸侯会议期间去世，秋季杞国安葬悼公。 [[6]](#note-6)

<a id="event-7"></a>

7. **许国迁往容城。** 许国将国都迁到容城，继续迁徙求存。 [[7]](#note-7)

<a id="event-8"></a>

8. **刘文公去世，鲁国记其葬事。** 刘卷去世，即前面主持诸侯会合的刘文公。鲁国随后记录了他的葬礼。 [[8]](#note-8)

<a id="event-9"></a>

9. **晋、卫联军攻鲜虞。** 晋国士鞅与卫国孔圉共同率军攻打鲜虞，北方战线仍在继续。 [[9]](#note-9)

<a id="event-10"></a>

10. **吴、蔡、唐联军攻楚，楚军原定夹击计划中断。** 冬季，吴王阖庐与蔡、唐两国进攻楚国，舍舟进军，到汉水与楚军相持。左司马沈尹戌建议囊瓦沿汉牵制，自己出兵毁吴舟、封关隘，再两面夹击。沈尹戌离开后，囊瓦听从速战意见，先渡汉交战，连续失利，原定会攻未能实行。 [[10]](#note-10)

    出兵以前，伍员与孙武向阖庐指出，唐、蔡都怨恨囊瓦，吴要大举伐楚，应先争取两国一同参与。阖庐接受这个意见，对楚的进攻于是与唐、蔡的处境联系起来。伯嚭也因家族在楚遭难而投吴，参与谋楚。

<a id="event-11"></a>

11. **柏举楚军溃败，囊瓦逃郑；吴军五战进入郢都。** 十一月庚午，两军在柏举列阵。夫概请求先攻未获准，仍带所部五千人冲击囊瓦部队，楚军溃乱，吴主力跟进取胜，囊瓦逃郑。吴军追至清发，待楚军半渡再击，又在雍澨追战，连胜抵郢。楚昭王带妹妹先逃，庚辰吴军进入郢都，各部占据宫室，还因分占发生争执。 [[11]](#note-11)

<a id="event-12"></a>

12. **沈尹戌回援战伤，命部属带走首级。** 沈尹戌从息返回，在雍澨击败一支吴军，却在连续战斗中多次受伤。为免被俘，他要求部属设法带走首级。吴句卑依命结束他的生命，藏好身体，携首离开。 [[12]](#note-12)

<a id="event-13"></a>

13. **楚昭王辗转到随国，随国拒绝交人。** 昭王逃途中遭袭，王孙由于护卫受伤；到郧后，斗辛阻止弟弟怀报父仇，又护王逃到随。吴军追索，许随以汉阳土地。子期提出替王受交，随人最终以旧盟为由拒绝吴军。昭王由此暂获容身之处，并与随盟誓。 [[13]](#note-13)

<a id="event-14"></a>

14. **申包胥向秦求援，秦国决定出兵救楚。** 楚昭王滞留随国时，申包胥赴秦求援，强调吴若控制楚地，也会成为秦国邻境的威胁。秦伯先请他住馆等候，申包胥不肯安住，倚庭墙哭请。经过七日，秦哀公以《无衣》回应，秦军出发援楚。 [[14]](#note-14)

    伍员与申包胥原是朋友。伍员出亡时说要使楚覆亡，申包胥则表示要保存楚国。吴军入郢后，二人围绕报仇的限度产生冲突；申包胥最终把救楚的希望寄托在秦国援军上。

<a id="event-15"></a>

15. **伍员在平王墓前报仇，申包胥责问其是否过度。** 吴军入郢、未能捕获楚昭王以后，关于伍员的记载又留下在平王墓前报仇的故事。申包胥派人责问，这样对待昔日国君是否过于惨烈；伍员回答，自己日暮途远，已经顾不上循常道行事。墓前究竟是鞭墓还是掘墓鞭尸，早期文献并不相同，具体动作不在正文强定。 [[15]](#note-15)

<a id="sj036-qi-yin-killed-event"></a>

16. **杞隐公被弟弟杀死，釐公接位。** 悼公死后，儿子乞一度接掌杞国，称隐公；弟弟遂随后杀死他并夺位，为釐公。这次变乱暂系本年，次年起釐公元年。 [[16]](#sj036-qi-yin-killed-note)

### 3. 皋鼬会盟争论蔡、卫先后，卫国获排在蔡前

[返回正文第3条](#event-3)

> 五月，公及诸侯盟于皋鼬。

> 秋七月，公至自会。

> 晋人假羽旄于郑，郑人与之。明日，或旆以会。晋于是乎失诸侯。将会，卫子行敬子言于灵公曰：“会同难，啧有烦言，莫之治也。其使祝佗从。”公曰：“善。”乃使子鱼。子鱼辞曰：“臣展四体，以率旧职，犹惧不给而烦刑书，若又共二，徼大罪也。且夫祝，社稷之常隶也。社稷不动，祝不出竟，官之制也。君以军行，祓社衅鼓，祝奉以从，于是乎出竟。若嘉好之事，君行师从，卿行旅从，臣无事焉。”公曰：“行也。”及皋鼬，将长蔡于卫。卫侯使祝佗私于苌弘曰：“闻诸道路，不知信否？若闻蔡将先卫，信乎？”苌弘曰：“信。蔡叔，康叔之兄也，先卫，不亦可乎？”子鱼曰：“以先王观之，则尚德也。昔武王克商，成王定之，选建明德，以藩屏周。故周公相王室，以尹天下，于周为睦。分鲁公以大路、大旂，夏后氏之璜，封父之繁弱，殷民六族，条氏、徐氏、萧氏、索氏、长勺氏、尾勺氏，使帅其宗氏，辑其分族，将其类醜，以法则周公，用即命于周。是使之职事于鲁，以昭周公之明德。分之土田陪敦，祝、宗、卜、史，备物典策，官司彝器。因商奄之民，命以伯禽，而封于少皞之虚。分康叔以大路、少帛、茷、旃旌、大吕，殷民七族，陶氏、施氏、繁氏、锜氏、樊氏、饑氏、终葵氏，封畛土略，自武父以南，及圃田之北竟，取于有阎之土，以共王职。取于相土之东都，以会王之东蒐。耼季授土，陶叔授民，命以《康诰》，而封于殷虚，皆启以商政，疆以周索。分唐叔以大路、密须之鼓、阙巩、沽洗，怀姓九宗，职官五正。命以《唐诰》，而封于夏虚，启以夏政，疆以戎索。三者皆叔也，而有令德，故昭之以分物。不然，文、武、成、康之伯犹多，而不获是分也，唯不尚年也。管蔡启商，惎间王室。王于是乎杀管叔而蔡蔡叔，以车七乘，徒七十人。其子蔡仲，改行帅德，周公举之，以为己卿士。见诸王而命之以蔡，其命书云：‘王曰，胡，无若尔考之违王命也。’若之何其使蔡先卫也？武王之母弟八人，周公为大宰，康叔为司寇，耼季为司空，五叔无官，岂尚年哉！曹，文之昭也；晋，武之穆也。曹为伯甸，非尚年也。今将尚之，是反先王也。晋文公为践土之盟，卫成公不在，夷叔，其母弟也，犹先蔡。其载书云：‘王若曰： 晋重、鲁申、卫武、蔡甲午、郑捷、齐潘、宋王臣、莒期。’藏在周府，可覆视也。吾子欲复文、武之略，而不正其德，将如之何？”苌弘说，告刘子，与范献子谋之，乃长卫侯于盟。

### 10. 吴、蔡、唐联军攻楚，楚军原定夹击计划中断

[返回正文第10条](#event-10)

> 冬，蔡侯、吴子、唐侯伐楚。舍舟于淮汭，自豫章与楚夹汉。左司马戌谓子常曰：“子沿汉而与之上下，我悉方城外以毁其舟，还塞大隧、直辕、冥阨。子济汉而伐之，我自后击之，必大败之。”既谋而行。武城黑谓子常曰：“吴用木也，我用革也，不可久也。不如速战。”史皇谓子常：“楚人恶子而好司马，若司马毁吴舟于淮，塞城口而入，是独克吴也。子必速战，不然不免。”乃济汉而陈，自小别至于大别。三战，子常知不可，欲奔。史皇曰：“安求其事，难而逃之，将何所入？子必死之，初罪必尽说。”

> 九年，吳王闔廬謂子胥、孫武曰：「始子言郢未可入，今果何如？」二子對曰：「楚將囊瓦貪，而唐、蔡皆怨之。王必欲大伐之，必先得唐、蔡乃可。」闔廬聽之，悉興師與唐、蔡伐楚，與楚夾漢水而陳。吳王之弟夫概將兵請從，王不聽，遂以其屬五千人擊楚將子常。己卯，楚昭王出奔。庚辰，吳王入郢。子常敗走，奔鄭。於是吳乘勝而前，五戰，遂至郢。

> 楚誅其大臣郤宛、伯州犁，伯州犁之孫伯嚭亡奔吳，吳亦以嚭為大夫。前王僚所遣二公子將兵伐楚者，道絕不得歸。後聞闔廬弒王僚自立，遂以其兵降楚，楚封之於舒。闔廬立三年，乃興師與伍胥、伯嚭伐楚，拔舒，遂禽故吳反二將軍。因欲至郢，將軍孫武曰：「民勞，未可，且待之。」乃歸。

### 14. 申包胥向秦求援，秦国决定出兵救楚

> 初，伍员与申包胥友。其亡也，谓申包胥曰：“我必复楚国。”申包胥曰：“勉之。子能复之，我必能兴之。”及昭王在随，申包胥如秦乞师，曰：“吴为封豕长蛇，以荐食上国。虐始于楚，寡君失守社稷，越在草莽。使下臣告急曰，夷德无厌，若邻于君，疆埸之患也。逮吴之未定，君其取分焉。若楚之遂亡，君之土也。若以君灵抚之，世以事君。”秦伯使辞焉，曰：“寡人闻命矣，子姑就馆，将图而告。”对曰：“寡君越在草莽，未获所伏。下臣何敢即安？”立依于庭墙而哭，日夜不绝声，勺饮不入口，七日。秦哀公为之赋《无衣》，九顿首而坐。秦师乃出。

> 晋人假羽旄于郑，郑人与之。明日，或旆以会。晋于是乎失诸侯。将会，卫子行敬子言于灵公曰：“会同难，啧有烦言，莫之治也。其使祝佗从。”公曰：“善。”乃使子鱼。子鱼辞曰：“臣展四体，以率旧职，犹惧不给而烦刑书，若又共二，徼大罪也。且夫祝，社稷之常隶也。社稷不动，祝不出竟，官之制也。君以军行，祓社衅鼓，祝奉以从，于是乎出竟。若嘉好之事，君行师从，卿行旅从，臣无事焉。”公曰：“行也。”及皋鼬，将长蔡于卫。卫侯使祝佗私于苌弘曰：“闻诸道路，不知信否？若闻蔡将先卫，信乎？”苌弘曰：“信。蔡叔，康叔之兄也，先卫，不亦可乎？”子鱼曰：“以先王观之，则尚德也。昔武王克商，成王定之，选建明德，以藩屏周。故周公相王室，以尹天下，于周为睦。分鲁公以大路、大旂，夏后氏之璜，封父之繁弱，殷民六族，条氏、徐氏、萧氏、索氏、长勺氏、尾勺氏，使帅其宗氏，辑其分族，将其类醜，以法则周公，用即命于周。是使之职事于鲁，以昭周公之明德。分之土田陪敦，祝、宗、卜、史，备物典策，官司彝器。因商奄之民，命以伯禽，而封于少皞之虚。分康叔以大路、少帛、茷、旃旌、大吕，殷民七族，陶氏、施氏、繁氏、锜氏、樊氏、饑氏、终葵氏，封畛土略，自武父以南，及圃田之北竟，取于有阎之土，以共王职。取于相土之东都，以会王之东蒐。耼季授土，陶叔授民，命以《康诰》，而封于殷虚，皆启以商政，疆以周索。分唐叔以大路、密须之鼓、阙巩、沽洗，怀姓九宗，职官五正。命以《唐诰》，而封于夏虚，启以夏政，疆以戎索。三者皆叔也，而有令德，故昭之以分物。不然，文、武、成、康之伯犹多，而不获是分也，唯不尚年也。管蔡启商，惎间王室。王于是乎杀管叔而蔡蔡叔，以车七乘，徒七十人。其子蔡仲，改行帅德，周公举之，以为己卿士。见诸王而命之以蔡，其命书云：‘王曰，胡，无若尔考之违王命也。’若之何其使蔡先卫也？武王之母弟八人，周公为大宰，康叔为司寇，耼季为司空，五叔无官，岂尚年哉！曹，文之昭也；晋，武之穆也。曹为伯甸，非尚年也。今将尚之，是反先王也。晋文公为践土之盟，卫成公不在，夷叔，其母弟也，犹先蔡。其载书云：‘王若曰： 晋重、鲁申、卫武、蔡甲午、郑捷、齐潘、宋王臣、莒期。’藏在周府，可覆视也。吾子欲复文、武之略，而不正其德，将如之何？”苌弘说，告刘子，与范献子谋之，乃长卫侯于盟。

**说明：** 传文同段也记晋向郑借旗帜、翌日持旗赴会及史家议论；旧有封爵、分族、授器和践土盟书全文在原文中保留，不把其中周初人物再记成本年事件。祝佗又称子鱼。

**《左传》·定公四年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0506.md#all-20261109-t011)

> 楚子涉雎济江，入于云中。王寝，盗攻之，以戈击王。王孙由于以背受之，中肩。王奔郧，钟建负季芈以从，由于徐苏而从。郧公辛之弟怀将弑王，曰：“平王杀吾父，我杀其子，不亦可乎！”辛曰：“君讨臣，谁敢仇之？君命，天也，若死天命，将谁仇？《诗》曰：‘柔亦不茹，刚亦不吐。不侮矜寡，不畏强御。’唯仁者能之。违强陵弱，非勇也。乘人之约，非仁也。灭宗废祀，非孝也。动无令名，非知也。必犯是，余将杀女。”鬥辛与其弟巢以王奔随。吴人从之，谓随人曰：“周之子孙在汉川者，楚实尽之。天诱其衷，致罚于楚，而君又窜之，周室何罪？君若顾报周室，施及寡人，以奖天衷，君之惠也。汉阳之田，君实有之。”楚子在公宫之北，吴人在其南。子期似王，逃王而己为王，曰：“以我与之，王必免。”随人卜与之，不吉。乃辞吴曰：“以随之辟小而密迩于楚，楚实存之，世有盟誓，至于今未改。若难而弃之，何以事君？执事之患，不唯一人。若鸠楚竟，敢不听命。”吴人乃退。鑪金初宦于子期氏，实与随人要言。王使见，辞曰：“不敢以约为利。”王割子期之心，以与随人盟。

**《五礼通考》卷二百二十九所引杜预注·胸前取血盟誓，不是杀子期剖心** · [核对来源](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E4%BA%94%E7%A6%AE%E9%80%9A%E8%80%83%20%28%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29-%E5%8D%B7229.md#ref-e9aa223e4abe13)

> 杜云當心前割取血以盟示其至心是也

**引文层次：** 直接核读该卷引文；《左传注疏》原页面检索可见同文但打开未成功，故明确标为经《五礼通考》转引。

**说明：** “王割子期之心”不应直译为挖心杀人。已核《五礼通考》卷229所引杜预注，解释为胸前取血盟誓、表示诚意，不必把“心”判成工作本错字；原文保持不改。子期在下一年继续活动，也与此相合。

**本次汇入《伍子胥列传》：**

**《史记·伍子胥列传》·原TXT第4671行** · [固定版本原文](../../sources/本地分卷/史记/史记-卷066.md#L4671)

> 昭王出亡，入雲夢；盜擊王，王走鄖。鄖公弟懷曰：「平王殺我父，我殺其子，不亦可乎！」鄖公恐其弟殺王，與王奔隨。吳兵圍隨，謂隨人曰：「周之子孫在漢川者，楚盡滅之。」隨人欲殺王，王子綦匿王，己自為王以當之。隨人卜與王於吳，不吉，乃謝吳不與王。

**汇入说明：** 两书都记楚王经郧逃随、吴追索而未得。列传突出王子綦代王、随人卜问不吉，经传则详述随国旧盟及回应吴人的言辞；正文合用确定的逃亡与拒交结果，不把占卜当作项目认定的实际因果。子綦与已有正文子期保留异写，未增造另一个替身。

#### [[14]](#note-14) 申包胥向秦求援，秦国决定出兵救楚。

**《左传》·定公四年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0506.md#all-20261109-t012)

> 初，伍员与申包胥友。其亡也，谓申包胥曰：“我必复楚国。”申包胥曰：“勉之。子能复之，我必能兴之。”及昭王在随，申包胥如秦乞师，曰：“吴为封豕长蛇，以荐食上国。虐始于楚，寡君失守社稷，越在草莽。使下臣告急曰，夷德无厌，若邻于君，疆埸之患也。逮吴之未定，君其取分焉。若楚之遂亡，君之土也。若以君灵抚之，世以事君。”秦伯使辞焉，曰：“寡人闻命矣，子姑就馆，将图而告。”对曰：“寡君越在草莽，未获所伏。下臣何敢即安？”立依于庭墙而哭，日夜不绝声，勺饮不入口，七日。秦哀公为之赋《无衣》，九顿首而坐。秦师乃出。

> 始伍員與申包胥為交，員之亡也，謂包胥曰：「我必覆楚。」包胥曰：「我必存之。」及吳兵入郢，伍子胥求昭王。既不得，乃掘楚平王墓，出其尸，鞭之三百，然後已。申包胥亡於山中，使人謂子胥曰：「子之報讎，其以甚乎！吾聞之，人眾者勝天，天定亦能破人。今子故平王之臣，親北面而事之，今至於僇死人，此豈其無天道之極乎！」伍子胥曰：「為我謝申包胥曰，吾日莫途遠，吾故倒行而逆施之。」於是申包胥走秦告急，求救於秦。秦不許。包胥立於秦廷，晝夜哭，七日七夜不絕其聲。秦哀公憐之，曰：「楚雖無道，有臣若是，可無存乎！」乃遣車五百乘救楚擊吳。六月，敗吳兵於稷。會吳王久留楚求昭王，而闔廬弟夫概乃亡歸，自立為王。闔廬聞之，乃釋楚而歸，擊其弟夫概。夫概敗走，遂奔楚。楚昭王見吳有內亂，乃復入郢。封夫概於堂谿，為堂谿氏。楚復與吳戰，敗吳，吳王乃歸。

**汇入说明：** 友谊与出亡时约言属于前事，不算本年才相识。列传把责伍员、乞师、秦师六月破吴、夫概叛吴及楚王返郢连写；求援在前506年，援军到达、后续反攻及复国依定公五年归前505年。一个长段跨两年，不整段塞入本年。平王墓前报复的不同传述见本页新增第15条。

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **定公赴晋，到黄河边折返。** 正月，定公前往晋国，到黄河边便返回，没有完成这次朝见。 [[1]](#note-1)

<a id="event-2"></a>

2. **邾庄公受伤后去世，下葬时使用人殉。** 二月辛卯，邾庄公看到守门人以水洒庭，询问时听到对夷射姑的指控，命人拘捕却没有找到。冲突中，邾庄公扑向床榻，跌落炉炭而受伤，随后去世。秋季下葬前，安排五乘车、五人殉葬。 [[2]](#note-2)

<a id="event-3"></a>

3. **鲜虞在平中击败晋军，俘获观虎。** 九月，鲜虞在平中击败晋军，晋国观虎被俘。此事后来成为晋国再围鲜虞的理由。 [[3]](#note-3)

<a id="event-4"></a>

4. **孟懿子与邾君结盟，修复两国关系。** 冬季，仲孙何忌与邾君举行盟誓，重新安排两国友好关系。 [[4]](#note-4)

<a id="event-5"></a>

5. **蔡、唐两君被楚久留，交出财物后才获释。** 蔡昭侯带成对的佩玉、皮裘朝楚，唐成公带良马前往，令尹囊瓦都想索取，两君不肯，因此长期被扣留。唐国随从设法将马献给囊瓦，唐君才得归；蔡人也劝蔡侯交出佩玉，终于获释。蔡侯回程在汉水发誓不再向南，继而赴晋，以儿子及大夫子弟作质，请晋伐楚。 [[5]](#note-5)

   [年首与季节题记](#note-calendar)：保留只有年月、没有独立事件的经文，不另造白话史事。

> 蔡昭侯为两佩与两裘以如楚，献一佩一裘于昭王。昭王服之，以享蔡侯。蔡侯亦服其一。子常欲之，弗与。三年止之。唐成公如楚，有两肃爽马，子常欲之，弗与。亦三年止之。唐人或相与谋，请代先从者，许之。饮先从者酒，醉之，窃马而献之子常。子常归唐侯。自拘于司败，曰：“君以弄马之故，隐君身，弃国家群臣。请相夫人以偿马，必如之。”唐侯曰：“寡人之过也，二三子无辱。”皆赏之。蔡人闻之，固请而献佩于子常。子常朝，见蔡侯之徒，命有司曰：“蔡君之久也，官不共也。明日，礼不毕，将死。”蔡侯归，及汉，执玉而沈，曰：“余所有济汉而南者，有若大川！”蔡侯如晋，以其子元与其大夫之子为质焉，而请伐楚。

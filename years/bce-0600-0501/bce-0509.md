<a id="本年纪事"></a>
<a id="event-1"></a>

1. **晋国魏舒主持成周筑城，途中去世。** 正月，魏舒召集各国大夫到狄泉，继续安排成周筑城。他把役事交给韩简子、原寿过，自己转往大陆田猎，回程死于甯。范献子认为他没有复命便擅自出猎，撤去了原拟使用的柏木外椁。 [[1]](#note-1)

<a id="event-2"></a>

2. **宋仲幾争拒工程份额，晋人拘捕他；成周城三旬完工。** 各国开始筑城时，宋仲幾要求把滕、薛、郳的役务纳在宋国之下。薛使以践土旧盟和先祖官职反驳，晋方要求先领工程、回国再查旧档，仲幾仍不接受。晋人拘捕他，三月送到周都处理。筑城经过三旬完成，各国原先派驻周室的守军得以撤回。 [[2]](#note-2)

    [卷四互见与归年](#sj004-509-1)

<a id="event-3"></a>

3. **齐国高张未按诸侯约定参加役事，引起晋人议论。** 齐国高张迟到，没有依照诸侯的共同安排行动。晋国女叔宽将他与组织修城的周人苌弘一起议论，分别从违众、逆天的角度提出警告。 [[3]](#note-3)

<a id="event-4"></a>

4. **昭公灵柩回鲁，公子宋六月正式即位。** 叔孙成子到乾侯迎昭公灵柩，并代季孙邀请子家羁回国共同执政。子家羁拒绝卷入新君选择，也不愿在昭公不知情的情况下自行回鲁。丧队到坏隤时，公子宋先入国，从亡者在那里折返。六月癸亥，昭公灵柩抵鲁；戊辰，公子宋正式即位，是为定公。 [[4]](#note-4)

<a id="event-5"></a>

5. **七月安葬昭公，墓地与先君墓群分隔。** 七月癸巳，昭公下葬，位置在墓道南面。昭公生前未能返回鲁国，身后墓地又没有和其他鲁君墓地连在一起。 [[5]](#note-5)

<a id="event-6"></a>

6. **鲁国举行大雩，并为炀公立庙。** 九月，鲁国举行大雩祈雨，又立炀公之庙。季平子此前在昭公出奔时向炀公祷告，这次建庙与那次祈求相衔接。 [[6]](#note-6)

<a id="event-7"></a>

7. **十月降霜，豆类作物受损。** 十月，降霜冻坏豆类作物，鲁国将这次农作物受灾记入年事。 [[7]](#note-7)

<a id="event-8"></a>

8. **周室巩简公疏远族人，转而任用外来者。** 巩简公不重用自己的子弟，而偏向任用外来者。这种人事安排成为巩氏内部不满的背景，冲突在下一年进一步发展。 [[8]](#note-8)

   [年首与季节题记](#note-calendar)：保留只有年月、没有独立事件的经文，不另造白话史事。

<a id="event-9"></a>

9. **曹隐公元年。** 通已在上一年弑君自立，本年开始隐公纪年。 [[9]](#note-9)

### 4. 昭公灵柩回鲁，公子宋六月正式即位

[返回正文第4条](#event-4)

<a id="sj033-cite-109"></a>

**[《史记·鲁周公世家》P071](../../sources/摘录/史记-卷033-鲁周公世家.md#p071)**

> 魯人共立昭公弟宋為君，是為定公。

> 夏六月癸亥，公之丧至自乾侯。

> 戊辰，公即位。

> 夏，叔孙成子逆公之丧于乾侯。季孙曰：“子家子亟言于我，未尝不中吾志也。吾欲与之从政，子必止之，且听命焉。”子家子不见叔孙，易几而哭。叔孙请见子家子，子家子辞曰：“羁未得见，而从君以出。君不命而薨，羁不敢见。”叔孙使告之曰：“公衍、公为实使群臣不得事君。若公子宋主社稷，则群臣之愿也。凡从君出而可以入者，将唯子是听。子家氏未有后，季孙愿与子从政，此皆季孙之愿也，使不敢以告。”对曰：“若立君，则有卿士大夫与守龟在，羁弗敢知。若从君者，则貌而出者，入可也。寇而出者，行可也。若羁也，则君知其出也，而未知其入也。羁将逃出。”

> 丧及坏隤，公子宋先入，从公者皆自坏隤反。六月癸亥，公之丧至自乾侯。戊辰，公即位。季孙使役如阚，公氏将沟焉。荣驾鹅曰：“生不能事，死又离之，以自旌也。纵子忍之，后必或耻之。”乃止。季孙问于荣驾鹅曰：“吾欲为君谥，使子孙知之。”对曰：“生弗能事，死又恶之，以自信也。将焉用之？”乃止。

**[核对来源](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E9%AD%AF%E5%91%A8%E5%85%AC%E4%B8%96%E5%AE%B6.md#ref-ba2a8639a4e181)**

> 魯人共立昭公弟宋爲君，是爲定公。

**[核对来源](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E9%AD%AF%E5%91%A8%E5%85%AC%E4%B8%96%E5%AE%B6.md#ref-d7a91f656b23b2)**

> 定公立，趙簡子問史墨曰：『季氏亡乎？』史墨對曰：『不亡。季友有大功於魯，受鄪爲上卿，至于文子、武子，世增其業。魯文公卒，東門遂殺適立庶，魯君於是失國政。政在季氏，於今四君矣。民不知君，何以得國！是以爲君慎器與名，不可以假人。』

> 丧及坏隤，公子宋先入，从公者皆自坏隤反。六月癸亥，公之丧至自乾侯。戊辰，公即位。季孙使役如阚，公氏将沟焉。荣驾鹅曰：“生不能事，死又离之，以自旌也。纵子忍之，后必或耻之。”乃止。季孙问于荣驾鹅曰：“吾欲为君谥，使子孙知之。”对曰：“生弗能事，死又恶之，以自信也。将焉用之？”乃止。

**《史记·鲁周公世家》·昭公卒后：拥立公子宋** · [核对来源](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E9%AD%AF%E5%91%A8%E5%85%AC%E4%B8%96%E5%AE%B6.md#ref-ba2a8639a4e181)

> 魯人共立昭公弟宋爲君，是爲定公。

**《史记·鲁周公世家》·定公立后的史墨评论；同一问答前一页已编** · [核对来源](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E9%AD%AF%E5%91%A8%E5%85%AC%E4%B8%96%E5%AE%B6.md#ref-d7a91f656b23b2)

> 定公立，趙簡子問史墨曰：『季氏亡乎？』史墨對曰：『不亡。季友有大功於魯，受鄪爲上卿，至于文子、武子，世增其業。魯文公卒，東門遂殺適立庶，魯君於是失國政。政在季氏，於今四君矣。民不知君，何以得國！是以爲君慎器與名，不可以假人。』

[此前的同一问答](bce-0510.md#note-7)，本处仅作编排差异对照。

**说明：** 《鲁周公世家》将拥立概括接在昭公卒后，本页用经传六月确日补明正式即位。传文还记荣驾鹅阻止季氏以墓沟、恶谥继续贬损昭公。史墨论季氏的同一问答已置前510年末条，本页只交叉核对，不新增第二场对话。

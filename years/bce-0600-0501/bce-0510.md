<a id="本年纪事"></a>
<a id="event-1"></a>

1. **昭公继续居于乾侯。** 正月，昭公仍住在晋地乾侯。上一年斡旋没有达成回鲁安排，本年的处境也没有转变。 [[1]](#note-1)

<a id="event-2"></a>

2. **鲁国取得阚。** 春季，鲁国取得阚地。 [[2]](#note-2)

<a id="event-3"></a>

3. **吴军出兵攻越。** 夏季，吴国出兵进攻越国，并取得胜利。关于这次进攻，保存下来的记载没有展开具体交战经过，也没有给出伤亡数字。 [[3]](#note-3)

<a id="event-4"></a>

4. **敬王请求修成周城，晋国决定组织诸侯承担工程。** 秋季，敬王派富辛、石张向晋请求修筑成周城，希望以更稳固的城防减少诸侯长期戍守的负担。范献子向魏献子建议，与其不断派兵驻周，不如接受这一工程方案。晋方答应，准备通知各国，分配役务。 [[4]](#note-4)

    [卷四互见与归年](#sj004-510-1)

<a id="event-5"></a>

5. **诸国大夫会于狄泉，测量、分派成周筑城任务。** 冬十一月，魏舒、韩不信召各国大夫到狄泉，重申盟约并安排修城，鲁国仲孙何忌参与。士弥牟测量城垣长短、高低、厚薄和沟洫，估算土方、距离、工期、役夫、材料、粮食，再把各国应承担的工程写成文书，交刘氏核验，由韩氏监督。 [[5]](#note-5)

<a id="event-6"></a>

6. **昭公十二月死于乾侯，至死未能回鲁复位。** 十二月，昭公病重，赐从亡大夫财物，众人起初不受。子家羁为不违君命先接受，其他人才跟随。己未，昭公在乾侯去世。子家羁随即把所受财物还给府人，其他大夫也归还。昭公从前517年出奔以来的流亡，至此结束。 [[6]](#note-6)

<a id="event-7"></a>

7. **赵鞅问季氏为何未受诸侯追究，史墨从长期权力转移作答。** 昭公死于国外后，赵鞅问史墨，季氏逐君而民众服从、诸侯交往，为什么没有受到追究。史墨回顾季友受费及文、武两代经营，又说鲁公室多代失政，季氏逐渐掌握官职、名号和民众依附，认为局面不能只由最后一次兵变解释。 [[7]](#note-7)

<a id="sj014-audit-0510-cao"></a>

<a id="event-8"></a>

8. **曹国这一阶段的君位承继，保留弑君夺位的一支记载。** 按这支传承，曹平公之弟通杀死声公，夺取君位，即曹隐公；声、隐两公是否应列入这段君次，古代已有异议。 [[8]](#note-8)

> 秋八月，王使富辛与石张如晋，请城成周。天子曰：“天降祸于周，俾我兄弟并有乱心，以为伯父忧。我一二亲昵甥舅，不皇启处，于今十年，勤戍五年。余一人无日忘之，闵闵焉如农夫之望岁，惧以待时。伯父若肆大惠，复二文之业，弛周室之忧，徼文、武之福，以固盟主，宣昭令名，则余一人有大愿矣。昔成王合诸侯，城成周，以为东都，崇文德焉。今我欲徼福假灵于成王，修成周之城，俾戍人无勤，诸侯用宁，蝥贼远屏，晋之力也。其委诸伯父，使伯父实重图之。俾我一人无征怨于百姓，而伯父有荣施，先王庸之。”范献子谓魏献子曰：“与其戍周，不如城之，天子实云。虽有后事，晋勿与知可也。从王命以纾诸侯，晋国无忧。是之不务，而又焉从事？”魏献子曰：“善。”使伯音对曰：“天子有命，敢不奉承，以奔告于诸侯。迟速衰序，于是焉在。”

### 5. 诸国大夫会于狄泉，测量、分派成周筑城任务

[返回正文第5条](#event-5)

> 冬，仲孙何忌会晋韩不信、齐高张、宋仲幾、卫世叔申、郑国参、曹人、莒人、薛人、杞人、小邾人，城成周。

> 冬十一月，晋魏舒、韩不信如京师，合诸侯之大夫于狄泉，寻盟，且令城成周。魏子南面。卫彪傒曰：“魏子必有大咎，干位以令大事，非其任也。《诗》曰：‘敬天之怒，不敢戏豫。敬天之渝，不敢驰驱。’况敢干位以作大事乎？”

> 城三旬而毕，乃归诸侯之戍。

### 7. 赵鞅问季氏为何未受诸侯追究，史墨从长期权力转移作答

[返回正文第7条](#event-7)

<a id="sj033-cite-110"></a>

**[《史记·鲁周公世家》P072](../../sources/摘录/史记-卷033-鲁周公世家.md#p072)**

> 定公立，趙簡子問史墨曰：「季氏亡乎？」史墨對曰：「不亡。季友有大功於魯，受鄪為上卿，至于文子、武子，世增其業。魯文公卒，東門遂殺適立庶，魯君於是失國政。政在季氏，於今四君矣。民不知君，何以得國！是以為君慎器與名，不可以假人。」

本篇把问答接在定公立后，传文在昭公末年；不另在前509造第二次相同问答。 [全卷考证](../../meta/考证/史记-卷033-纪年与异说.md)。

> 赵简子问于史墨曰：“季氏出其君，而民服焉，诸侯与之，君死于外，而莫之或罪也。”对曰：“物生有两，有三，有五，有陪贰。故天有三辰，地有五行，体有左右，各有妃耦。王有公，诸侯有卿，皆有贰也。天生季氏，以贰鲁侯，为日久矣。民之服焉，不亦宜乎？鲁君世从其失，季氏世修其勤，民忘君矣。虽死于外，其谁矜之？社稷无常奉，君臣无常位，自古以然。故《诗》曰：‘高岸为穀，深穀为陵。’三后之姓，于今为庶，主所知也。在《易》卦，雷乘《乾》曰《大壮》，天之道也。昔成季友，桓之季也，文姜之爱子也，始震而卜，卜人谒之，曰：‘生有嘉闻，其名曰友，为公室辅。’及生，如卜人之言，有文在其手曰‘友’，遂以名之。既而有大功于鲁，受费以为上卿。至于文子、武子，世增其业，不废旧绩。鲁文公薨，而东门遂杀適立庶，鲁君于是乎失国，政在季氏，于此君也四公矣。民不知君，何以得国？是以为君，慎器与名，不可以假人。”

> 定公立，趙簡子問史墨曰：『季氏亡乎？』史墨對曰：『不亡。季友有大功於魯，受鄪爲上卿，至于文子、武子，世增其業。魯文公卒，東門遂殺適立庶，魯君於是失國政。政在季氏，於今四君矣。民不知君，何以得國！是以爲君慎器與名，不可以假人。』

> 冬，仲孙何忌会晋韩不信、齐高张、宋仲幾、卫世叔申、郑国参、曹人、莒人、薛人、杞人、小邾人，城成周。

**《左传》·昭公三十二年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0510.md#all-20261109-t004)

**《左传》·昭公三十二年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0510.md#all-20261109-t005)

<a id="6note-6-昭公十二月死于乾侯至死未能回鲁复位"></a>
#### [[6]](#note-6) 昭公十二月死于乾侯，至死未能回鲁复位。

**《左传》·昭公三十二年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0510.md#all-20261109-t006)

<a id="7note-7-赵鞅问季氏为何未受诸侯追究史墨从长期权力转移作答"></a>
#### [[7]](#note-7) 赵鞅问季氏为何未受诸侯追究，史墨从长期权力转移作答。

**《左传》·昭公三十二年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0510.md#all-20261109-t007)

> 赵简子问于史墨曰：“季氏出其君，而民服焉，诸侯与之，君死于外，而莫之或罪也。”对曰：“物生有两，有三，有五，有陪贰。故天有三辰，地有五行，体有左右，各有妃耦。王有公，诸侯有卿，皆有贰也。天生季氏，以贰鲁侯，为日久矣。民之服焉，不亦宜乎？鲁君世从其失，季氏世修其勤，民忘君矣。虽死于外，其谁矜之？社稷无常奉，君臣无常位，自古以然。故《诗》曰：‘高岸为穀，深穀为陵。’三后之姓，于今为庶，主所知也。在《易》卦，雷乘《乾》曰《大壮》，天之道也。昔成季友，桓之季也，文姜之爱子也，始震而卜，卜人谒之，曰：‘生有嘉闻，其名曰友，为公室辅。’及生，如卜人之言，有文在其手曰‘友’，遂以名之。既而有大功于鲁，受费以为上卿。至于文子、武子，世增其业，不废旧绩。鲁文公薨，而东门遂杀適立庶，鲁君于是乎失国，政在季氏，于此君也四公矣。民不知君，何以得国？是以为君，慎器与名，不可以假人。”

**《史记·鲁周公世家》·世家置于定公立后的史墨评论** · [固定版本原文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E9%AD%AF%E5%91%A8%E5%85%AC%E4%B8%96%E5%AE%B6.md#ref-54e00eb4315981)

> 定公立，趙簡子問史墨曰：『季氏亡乎？』史墨對曰：『不亡。季友有大功於魯，受鄪爲上卿，至于文子、武子，世增其業。魯文公卒，東門遂殺適立庶，魯君於是失國政。政在季氏，於今四君矣。民不知君，何以得國！是以爲君慎器與名，不可以假人。』

**说明：** 这是史墨对历史的解释，不是项目对逐君的正当性裁决。《史记》把类似问答接在“定公立”之后；这里随《左传》置于昭公卒后作总结，并保留不同编排，不断言对话发生于卒日当天。季友出生卜辞、三代与《易》类比均为回叙或议论。

<a id="event-1"></a>

1. **晋国召季孙问罪，季孙到適历表示愿从昭公归国。** 正月，昭公仍在乾侯。晋侯准备出兵送他回鲁，范献子建议先召季孙，看其是否应命。季孙在范氏保证下到適历见荀跞，以练冠、麻衣、赤足表示服罪，声称愿受囚、受死，也愿随国君回鲁。 [[1]](#note-1)

<a id="event-2"></a>

2. **乾侯会面仍未达成复位，昭公与从者的意见分裂。** 四月，季孙随荀跞到乾侯。子家羁劝昭公接受一起归国，昭公一度答应；从者却坚持必须先逐季氏。荀跞奉晋命劝归时，昭公又发誓不能与季孙相见，荀跞退出，让季孙先归祭。子家羁再提议昭公乘一车进入鲁军，昭公想从，从者却阻拦，复位再度未成。 [[2]](#note-2)

<a id="event-3"></a>

3. **薛献公去世，秋季下葬。** 四月丁巳，薛伯穀去世；秋季安葬薛献公。 [[3]](#note-3)

<a id="event-4"></a>

4. **吴军轮番侵楚，楚军往返救潜、救弦。** 秋季，吴军攻夷，侵潜、六。沈尹戌率楚军救潜，吴军撤走；楚把潜人迁往南冈后回师，吴又围弦。楚军再次出动，行至豫章，吴军又撤。吴国开始将伍员所提的轮番疲敌方案用于实战。 [[4]](#note-4)

<a id="event-5"></a>

5. **邾黑肱带滥邑投鲁。** 冬季，邾国黑肱带着滥邑来归鲁国。鲁国由此接受了一名携地离开原君的臣属。 [[5]](#note-5)

<a id="event-6"></a>

6. **十二月日食，赵鞅向史墨询问梦与天象。** 十二月辛亥朔发生日食。同夜赵鞅梦到童子歌舞，次日向史墨询问梦与日食有何关系。史墨的解释涉及未来吴军入郢又不能长久占有的说法。 [[6]](#note-6)

<a id="sj014-audit-0511-jin"></a>

<a id="event-7"></a>

7. **晋定公午元年。** 晋顷公去世后，晋国开始定公午的纪年。 [[7]](#note-7)

> 三十一年春，王正月，公在乾侯，言不能外内也。晋侯将以师纳公。范献子曰：“若召季孙而不来，则信不臣矣。然后伐之，若何？”晋人召季孙，献子使私焉，曰：“子必来，我受其无咎。”季孙意如会晋荀跞于適历。荀跞曰：“寡君使跞谓吾子，何故出君？有君不事，周有常刑。子其图之！”季孙练冠麻衣跣行，伏而对曰：“事君，臣之所不得也，敢逃刑命？君若以臣为有罪，请囚于费，以待君之察也，亦唯君。若以先臣之故，不绝季氏，而赐之死。若弗杀弗亡，君之惠也，死且不朽。若得从君而归，则固臣之愿也。敢有异心？”

### 5. 邾黑肱带滥邑投鲁

[返回正文第5条](#event-5)

> 冬，黑肱以滥来奔。

> 冬，邾黑肱以滥来奔。贱而书名，重地故也。君子曰：“名之不可不慎也如是。夫有所有名，而不如其已。以地叛，虽贱，必书地，以名其人。终为不义，弗可灭已。是故君子动则思礼，行则思义，不为利回，不为义疚。或求名而不得，或欲盖而名章，惩不义也。齐豹为卫司寇，守嗣大夫，作而不义，其书为‘盗’。邾庶其、莒牟夷、邾黑肱以土地出，求食而已，不求其名，贱而必书。此二物者，所以惩肆而去贪也。若艰难其身，以险危大人，而有名章彻，攻难之士，将奔走之。若窃邑叛君，以徼大利而无名，贪冒之民，将寘力焉。是以《春秋》书齐豹曰‘盗’，三叛人名，以惩不义，数恶无礼，其善志也。故曰，《春秋》之称：微而显，婉而辨。上之人能使昭明，善人劝焉，淫人惧焉，是以君子贵之。”

> 冬，邾黑肱以滥来奔。贱而书名，重地故也。君子曰：“名之不可不慎也如是。夫有所有名，而不如其已。以地叛，虽贱，必书地，以名其人。终为不义，弗可灭已。是故君子动则思礼，行则思义，不为利回，不为义疚。或求名而不得，或欲盖而名章，惩不义也。齐豹为卫司寇，守嗣大夫，作而不义，其书为‘盗’。邾庶其、莒牟夷、邾黑肱以土地出，求食而已，不求其名，贱而必书。此二物者，所以惩肆而去贪也。若艰难其身，以险危大人，而有名章彻，攻难之士，将奔走之。若窃邑叛君，以徼大利而无名，贪冒之民，将寘力焉。是以《春秋》书齐豹曰‘盗’，三叛人名，以惩不义，数恶无礼，其善志也。故曰，《春秋》之称：微而显，婉而辨。上之人能使昭明，善人劝焉，淫人惧焉，是以君子贵之。”

**说明：** 传文长论为何记叛者姓名、为何齐豹称盗，属于编纂和褒贬说明；邾庶其、莒牟夷等旧例不再算本年新来奔。

#### [[6]](#note-6) 十二月日食，赵鞅向史墨询问梦与天象。

**《春秋》·昭公三十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0511.md#all-20261109-j007)

> 十有二月辛亥朔，日有食之。

**《左传》·昭公三十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0511.md#all-20261109-t006)

> 十二月辛亥朔，日有食之。是夜也，赵简子梦童子臝而转以歌。旦占诸史墨，曰：“吾梦如是，今而日食，何也？”对曰：“六年及此月也，吴其入郢乎！终亦弗克。入郢，必以庚辰。日月在辰尾，庚午之日，日始有谪。火胜金，故弗克。”

**说明：** 梦和占辞作为文本记载保留，不把它当作已验证的预测。尤其不能因为本段提到吴入郢，就把那场后事安在本年。

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **昭公仍住乾侯。** 正月，昭公继续居住乾侯。郓已在前一年溃散，他的流亡局面仍未改变。 [[1]](#note-1)

<a id="event-2"></a>

2. **晋顷公去世、下葬，郑国就丧使规格与晋交涉。** 六月，晋顷公去世；八月下葬。郑国由游吉一人兼办吊丧、送葬，晋方质问为何不再像往年分遣两人。游吉说明，小国承担贡赋与防备，丧使应按实际能力和礼制安排，大国不能只取往例最丰厚的一次，晋人未能再责难。 顷公去世后，儿子午继承，为定公；定公元年从次年前511计。 [[2]](#note-2)

<a id="event-3"></a>

<a id="event-4"></a>

3. **徐、钟吾所匿吴公子入楚，吴出兵灭徐。** 吴要求徐、钟吾拘捕流亡公子，楚接收两人。阖庐要求徐国拘掩馀、钟吾拘烛庸，两位公子遂逃往楚国。楚王厚加安置，令人在养地筑城，从城父及胡地取田给他们，打算牵制吴国。子西担忧这样会激怒吴，劝楚王暂缓，未被采纳。吴国灭徐，徐君逃楚，楚援军来迟。冬季，吴王拘钟吾君，又进攻徐国，堵水灌城。徐国被灭，徐君章禹剪发，带夫人出迎吴王，随后被送往楚国。沈尹戌率楚军来救，已经来不及，转而筑夷城安置徐君。 [[3]](#note-3)

<a id="event-5"></a>

<a id="event-6"></a>

<a id="event-7"></a>

4. **伍员献疲楚之策，孙武见阖闾陈说兵法。** 孙武是齐人，拿兵法求见吴王阖闾。阖闾说已读完十三篇，请他稍试训练军队，又问能否用妇人试验，孙武都答应。吴王交给他宫中一百八十名女子。孙武分成两队，以两名宠姬为队长，令人人持戟，逐一问明胸前、左右手与背后的方向，说明向前、向左、向右、向后的动作。规则公布后，他摆设刑斧，再三申明号令。伍员提出轮番出兵疲楚，阖庐接受。阖庐再问伍员如何伐楚。伍员建议把兵分为三部，轮流出动：楚军出迎，吴军就撤。楚军回去，吴再来，使楚不断奔走，再待其疲敝后合兵攻打。阖庐接受这一部署，后续对楚边境的连续行动由此接续。吴军攻舒，阖庐暂缓直取郢都。阖庐派兵进攻楚国，伍员、伯嚭参与，吴军攻下舒，俘获先前流亡在外的两名吴公子。阖庐还想继续向郢推进，孙武提醒军民已经劳苦，应当等待时机，吴军便暂时撤回。 [[4]](#note-5)

   在这以前，伯嚭也因楚国的家难逃到吴，被任为大夫。他是伯州犁的孙子，后来与伍员一同参与谋楚。

   第一次击鼓向右，女子们大笑。孙武说规则未明、号令不熟是将领的责任，再作说明；击鼓向左时，她们仍然大笑。他说号令已经明确而不依法执行，便是军吏和士卒的责任，要斩两名队长。阖闾在台上看见，大惊，派人说自己已经知道将军能带兵，没有这两名宠姬便吃不出滋味，请求免杀。孙武答：“我既受命为将，将领在军中，有些君命可以不接受。”他斩两名队长示众，改任次一等的人，再次击鼓，众人的前后左右、跪下起身都合规矩，再无人敢出声。

   孙武派人请吴王下来检阅，表示队伍已整齐，可任意使用，即使赴汤蹈火也行。阖闾却让将军休息回住处，说不愿下去。孙武答他只是喜欢道理、不能实际采用。阖闾由此知道其用兵能力，终于任他为将。这段进见、受任的前事发生年月未详；此处补叙不等于定为前512年。

> 孫子武者，齊人也。以兵法見於吳王闔廬。闔廬曰：「子之十三篇，吾盡觀之矣，可以小試勒兵乎？」對曰：「可。」闔廬曰：「可試以婦人乎？」曰：「可。」於是許之，出宮中美女，得百八十人。孫子分為二隊，以王之寵姬二人各為隊長，皆令持戟。令之曰：「汝知而心與左右手背乎？」婦人曰：「知之。」孫子曰：「前，則視心；左，視左手；右，視右手；後，即視背。」婦人曰：「諾。」約束既布，乃設鈇鉞，即三令五申之。於是鼓之右，婦人大笑。孫子曰：「約束不明，申令不熟，將之罪也。」復三令五申而鼓之左，婦人復大笑。孫子曰：「約束不明，申令不熟，將之罪也；既已明而不如法者，吏士之罪也。」乃欲斬左右隊長。吳王從臺上觀，見且斬愛姬，大駭。趣使使下令曰：「寡人已知將軍能用兵矣。寡人非此二姬，食不甘味，願勿斬也。」孫子曰：「臣既已受命為將，將在軍，君命有所不受。」遂斬隊長二人以徇。用其次為隊長，於是復鼓之。婦人左右前後跪起皆中規矩繩墨，無敢出聲。於是孫子使使報王曰：「兵既整齊，王可試下觀之，唯王所欲用之，雖赴水火猶可也。」吳王曰：「將軍罷休就舍，寡人不願下觀。」孫子曰：「王徒好其言，不能用其實。」於是闔廬知孫子能用兵，卒以為將。西破彊楚，入郢，北威齊晉，顯名諸侯，孫子與有力焉。

**本卷说明：** 本段末“西破强楚、入郢、北威齐晋”为后来功业总述，不能当作进见当日已经发生。孙武作为将军在本页攻舒军议中出现，宫中教战暂在此补此前经历；前512也只是沿阖闾三年的传统换算，未凭后世人物年谱给教战另定年。两孙书籍及作者问题见[实际对读材料](../../sources/补充阅读/史记065-两孙兵书与百科核对.md#liling)。

**说明：** 经文为冬十二月，传文作冬十一月，正文暂只定冬。徐君名经作章羽、传作章禹，按同一人保留异写。不得将原文水攻擅改为已核实的现代河道工程位置。




<a id="5note-5-伍员提出轮番出兵疲楚阖庐接受"></a>
#### [[5]](#note-5) 伍员提出轮番出兵疲楚，阖庐接受。

**《左传》·昭公三十年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0512.md#all-20261109-t006)

> 吴子问于伍员曰：“初而言伐楚，余知其可也，而恐其使余往也，又恶人之有余之功也。今余将自有之矣，伐楚何如？”对曰：“楚执政众而乖，莫適任患。若为三师以肄焉，一师至，彼必皆出。彼出则归，彼归则出，楚必道敝。亟肄以罢之，多方以误之，既罢而后以三军继之，必大克之。”阖庐从之。楚于是乎始病。

**说明：** 这是本年提出并采纳的方案，具体侵夷、潜、六、弦在下一年展开；不能把前506年吴入郢提前写到本年。

> 楚誅其大臣郤宛、伯州犁，伯州犁之孫伯嚭亡奔吳，吳亦以嚭為大夫。前王僚所遣二公子將兵伐楚者，道絕不得歸。後聞闔廬弒王僚自立，遂以其兵降楚，楚封之於舒。闔廬立三年，乃興師與伍胥、伯嚭伐楚，拔舒，遂禽故吳反二將軍。因欲至郢，將軍孫武曰：「民勞，未可，且待之。」乃歸。

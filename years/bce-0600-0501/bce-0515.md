1. **昭公春、冬两次赴齐，仍回郓居住。** 春季，昭公从郓到齐国，随后仍回郓。冬季他又赴齐，齐侯提出设享礼，子家羁认为昭公长期往来于齐，不必再作正式朝享，改以饮酒相见。两次出行都没有带来复位，会后仍以郓为落脚处。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **吴军乘楚国新丧围潜，退路被楚军牵制。** 吴王僚趁楚平王新丧，派公子掩馀、烛庸围潜，又让季札出使中原、赴晋观察诸侯。楚国多路军队救潜，沈尹戌等加入，吴军退路受到牵制，国内恰逢主力在外。 [[2]](#reading-note-2)

<a id="reading-event-3"></a>

3. **登场前事｜伍子胥推荐专诸，公子光谋求王位。** 伍员到吴后曾劝吴王僚，楚可以击破，请再派公子光攻楚。光却说伍员父兄被楚所杀，劝攻楚只是想报私仇，此时还不能击破楚国。伍员看出公子光更关心国内君位、想杀僚自立，暂时不能以外战相劝，于是推荐专诸，自己退到乡野，与太子建之子胜耕作。这些是行刺以前的前情，逐事年月未定。吴王位在兄弟间传递的经历，以及公子光自认有继位资格的理由，仍见同号史料。 [[3]](#reading-note-3)


<a id="event-3"></a>

<a id="reading-event-4"></a>

4. **专诸刺杀吴王僚，公子光即位。** 公子光趁两位公子领兵在外，向专诸提出谋取君位。四月，他设宴招待吴王僚，预先藏伏兵，专诸把剑藏在鱼中进献，近身刺杀吴王，自己也遭卫士夹击。公子光即位，是为阖庐，并任专诸之子为卿。季札归国后哭祭吴王墓、回到原职；掩馀奔徐，烛庸奔钟吾，楚军得知吴国内乱后撤回。 [[4]](#reading-note-4)

   阖庐即位后，召伍员任行人，让他参与国政谋议。伍员不再只是从国外求援的流亡者，而进入吴国的决策圈。

<a id="event-4"></a>

<a id="reading-event-5"></a>

5. **费无极设局，楚令尹下令攻郤氏，郤宛自杀。** 费无极与鄢将师排挤左尹郤宛，先说令尹子常将来饮酒，劝郤宛在门口备甲兵作礼物，又向子常告发郤宛准备行刺。子常派人查见甲兵，信以为真。鄢将师遂令攻打郤氏，郤宛自杀；子常又焚毁其宅，诛灭族党及其他相关人物，引发国中持续议论。 [[5]](#reading-note-5)

<a id="event-5"></a>

<a id="reading-event-6"></a>

6. **扈会再议迎昭公，晋国范献子使方案搁置。** 秋季，晋、宋、卫等国大夫会于扈，安排戍周，也商议送昭公回鲁。宋、卫力主行动，范献子却收了季平子的财物，主张季氏无罪，强调季氏有兵粮、民众和外援，劝两国不要轻易围鲁，并以若不成功便同死的要求加重压力。宋、卫代表退让，诸国最终以事情困难为由作答。 [[6]](#reading-note-6)

<a id="event-6"></a>

<a id="reading-event-7"></a>

7. **孟懿子、阳虎攻郓，昭公一方败于且知。** 孟懿子与阳虎出兵攻郓。郓人准备作战，子家羁反对继续冒险，昭公让他赴晋求助。昭公的部众随后在且知战败，郓地作为流亡据点的处境进一步恶化。 [[7]](#reading-note-7)

<a id="event-7"></a>

<a id="reading-event-8"></a>

8. **子常诛费无极、鄢将师，试图平息郤氏案后的议论。** 郤宛案后，楚人继续指责令尹子常。沈尹戌向他列举费无极逐朝吴、废蔡侯朱、逼走太子建、杀伍奢等事，劝他摒弃谗言。九月己未，子常杀费无极与鄢将师，灭其族，楚国的非议方息。 [[8]](#reading-note-8)

<a id="event-8"></a>

<a id="reading-event-9"></a>

9. **曹悼公去世。** 冬十月，曹伯午去世，是为曹悼公。 [[9]](#reading-note-9)

<a id="event-9"></a>

<a id="reading-event-10"></a>

10. **邾快出奔鲁国。** 邾国的快来到鲁国避难。 [[10]](#reading-note-10)

<a id="event-10"></a>

<a id="reading-event-11"></a>

11. **晋国集结诸侯戍周，鲁以国内有难推辞。** 十二月，晋国籍秦汇集各国派往周室的驻军。鲁国以国内变乱为由推辞，没有按要求参与这一轮集结。 [[11]](#reading-note-11)

<a id="sj014-audit-0515-chu"></a>

<a id="reading-event-12"></a>

12. **楚昭王珍元年。** 楚平王去世后，子西拒绝更改继承安排，楚昭王珍在本年进入元年。 [[12]](#reading-note-12)

### 4. 专诸刺杀吴王僚，公子光即位

[返回正文第4条](#reading-event-4)

<a id="sj086-p006"></a>

**[《史记·刺客列传》P006](../../sources/摘录/史记-卷086-刺客列传.md#p006)**

> 四月丙子，光伏甲士於窟室中，而具酒請王僚。王僚使兵陳自宮至光之家，門戶階陛左右，皆王僚之親戚也。夾立侍，皆持長鈹。酒旣酣，公子光詳爲足疾，入窟室中，使專諸置匕首魚炙之腹中而進之。旣至王前，專諸擘魚，因以匕首刺王僚，王僚立死。左右亦殺專諸，王人擾亂。公子光出其伏甲以攻王僚之徒，盡滅之，遂自立爲王，是爲闔閭。闔閭乃封專諸之子以爲上卿。

**本卷归年说明：** 四月丙子与《左传》相合；本传只称匕首，“鱼肠”名称见其他文献。

> 夏四月，吴弑其君僚。

> 吴公子光曰：“此时也，弗可失也。”告设诸曰：“上国有言曰，不索何获？我，王嗣也，吾欲求之。事若克，季子虽至，不吾废也。”鱄设诸曰：“王可弑也。母老子弱，是无若我何。”光曰：“我，尔身也。”

> 夏四月，光伏甲于堀室而享王。王使甲坐于道，及其门。门阶户席，皆王亲也，夹之以铍。羞者献体改服于门外。执羞者坐行而入，执铍者夹承之，及体以相授也。光伪足疾，入于堀室。鱄设诸置剑于鱼中以进。抽剑刺王，铍交于胸，遂弑王。阖庐以其子为卿。

> 季子至，曰：“苟先君无废祀，民人无废主，社稷有奉，国家无倾，乃吾君也。吾谁敢怨？哀死事生，以待天命。非我生乱，立者从之，先人之道也。”复命哭墓，复位而待。吴公子掩馀奔徐，公子烛庸奔钟吾。楚师闻吴乱而还。

<a id="sj066-cite-011"></a>

**[《史记·伍子胥列传》P008](../../sources/摘录/史记-卷066-伍子胥列传.md#p008)**

> 五年而楚平王卒。初，平王所奪太子建秦女生子軫，及平王卒，軫竟立為後，是為昭王。吳王僚因楚喪，使二公子將兵往襲楚。楚發兵絕吳兵之後，不得歸。吳國內空，而公子光乃令專諸襲刺吳王僚而自立，是為吳王闔廬。闔廬既立，得志，乃召伍員以為行人，而與謀國事。

**本卷说明：** 原全段复用，实际采用刺僚、阖闾即位与伍员参谋；段首楚平王卒在前516。前514另以阖闾元年记伍员行人，不视为前515、514各有一次相同任命。

### 5. 费无极设局，楚令尹下令攻郤氏，郤宛自杀

[返回正文第5条](#reading-event-5)

> 楚杀其大夫郤宛。

> 郤宛直而和，国人说之。鄢将师为右领，与费无极比而恶之。令尹子常贿而信谗。无极谮郤宛焉，谓子常曰：“子恶欲饮子酒。”又谓子恶：“令尹欲饮酒于子氏。”子恶曰：“我，贱人也，不足以辱令尹。令尹将必来辱，为惠已甚。吾无以酬之，若何？”无极曰：“令尹好甲兵，子出之，吾择焉。”取五甲五兵。曰：“寘诸门，令尹至，必观之，而从以酬之。”及飨日，帷诸门左。无极谓令尹曰：“吾几祸子。子恶将为子不利，甲在门矣，子必无往。且此役也，吴可以得志，子恶取赂焉而还，又误群帅，使退其师，曰：‘乘乱不祥。’吴乘我丧，我乘其乱，不亦可乎？”令尹使视郤氏，则有甲焉。不往，召鄢将师而告之。将师退，遂令攻郤氏，且爇之。子恶闻之，遂自杀也。国人弗爇。令曰：“不爇郤氏，与之同罪。”或取一编菅焉，或取一秉秆焉，国人投之，遂弗爇也。令尹炮之。尽灭郤氏之族党，杀阳令终与其弟完及佗与晋陈及其子弟。晋陈之族呼于国曰：“鄢氏、费氏自以为王，专祸楚国，弱寡王室，蒙王与令尹以自利也。令尹尽信之矣，国将如何？”令尹病之。

### 6. 扈会再议迎昭公，晋国范献子使方案搁置

[返回正文第6条](#reading-event-6)

> 秋，晋士鞅、宋乐祁犁、卫北宫喜、曹人、邾人、滕人会于扈。

> 秋，会于扈，令戍周，且谋纳公也。宋、卫皆利纳公，固请之。范献子取货于季孙，谓司城子梁与北宫贞子曰：“季孙未知其罪，而君伐之，请囚，请亡，于是乎不获。君又弗克，而自出也。夫岂无备而能出君乎？季氏之复，天救之也。休公徒之怒，而启叔孙氏之心。不然，岂其伐人而说甲执冰以游？叔孙氏惧祸之滥，而自同于季氏，天之道也。鲁君守齐，三年而无成。季氏甚得其民，淮夷与之，有十年之备，有齐、楚之援，有天之赞，有民之助，有坚守之心，有列国之权，而弗敢宣也，事君如在国。故鞅以为难。二子皆图国者也，而欲纳鲁君，鞅之愿也。请从二子以围鲁，无成，死之。”二子惧，皆辞。乃辞小国，而以难复。

### 7. 孟懿子、阳虎攻郓，昭公一方败于且知

**《左传》·昭公二十七年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0515.md#all-20261109-t007)

> 秋，会于扈，令戍周，且谋纳公也。宋、卫皆利纳公，固请之。范献子取货于季孙，谓司城子梁与北宫贞子曰：“季孙未知其罪，而君伐之，请囚，请亡，于是乎不获。君又弗克，而自出也。夫岂无备而能出君乎？季氏之复，天救之也。休公徒之怒，而启叔孙氏之心。不然，岂其伐人而说甲执冰以游？叔孙氏惧祸之滥，而自同于季氏，天之道也。鲁君守齐，三年而无成。季氏甚得其民，淮夷与之，有十年之备，有齐、楚之援，有天之赞，有民之助，有坚守之心，有列国之权，而弗敢宣也，事君如在国。故鞅以为难。二子皆图国者也，而欲纳鲁君，鞅之愿也。请从二子以围鲁，无成，死之。”二子惧，皆辞。乃辞小国，而以难复。

**说明：** 受货有传文直接支持；范献子所列“十年之备”等仍是他的说服性陈词，不当作本项目核实过的军力统计。


<a id="note-6"></a>

<a id="6note-6-孟懿子阳虎攻郓昭公一方败于且知"></a>
#### [[6]](#note-6) 孟懿子、阳虎攻郓，昭公一方败于且知。

**《左传》·昭公二十七年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0515.md#all-20261109-t008)

> 孟懿子、阳虎伐郓。郓人将战。子家子曰：“天命不慆久矣。使君亡者，必此众也。天既祸之，而自福也，不亦难乎？犹有鬼神，此必败也。呜呼！为无望也夫，其死于此乎！”公使子家子如晋。公徒败于且知。

**说明：** 此时虽战败，仍不能提前写成郓已溃散；经文明记郓溃在昭公二十九年。


<a id="note-7"></a>

<a id="7note-7-子常诛费无极鄢将师试图平息郤氏案后的议论"></a>
#### [[7]](#note-7) 子常诛费无极、鄢将师，试图平息郤氏案后的议论。

**《左传》·昭公二十七年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0515.md#all-20261109-t009)

> 楚郤宛之难，国言未已，进胙者莫不谤令尹。沈尹戌言于子常曰：“夫左尹与中厩尹莫知其罪，而子杀之，以兴谤，至于今不已。戌也惑之。仁者杀人以掩谤，犹弗为也。今吾子杀人以兴谤而弗图，不亦异乎？夫无极，楚之谗人也，民莫不知。去朝吴，出蔡侯朱，丧大子建，杀连尹奢，屏王之耳目，使不聪明。不然，平王之温惠共俭，有过成、庄，无不及焉。所以不获诸侯，迩无极也。今又杀三不辜，以兴大谤，几及子矣。子而不图，将焉用之？夫鄢将师矫子之命，以灭三族，国之良也，而不愆位。吴新有君，疆埸日骇，楚国若有大事，子其危哉！知者除谗以自安也，今子爱谗以自危也，甚矣其惑也！”子常曰：“是瓦之罪，敢不良图。”九月己未，子常杀费无极与鄢将师，尽灭其族，以说于国。谤言乃止。

**说明：** 这里列举的旧案都属于此前各年，不再次计为本年新发生。子常此次处置也不抹掉其此前下令诛郤氏的责任。

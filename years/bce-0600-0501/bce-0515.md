## 本年纪事

<a id="event-1"></a>

1. **昭公春、冬两次赴齐，仍回郓居住。**

春季，昭公从郓到齐国，随后仍回郓。冬季他又赴齐，齐侯提出设享礼，子家羁认为昭公长期往来于齐，不必再作正式朝享，改以饮酒相见。两次出行都没有带来复位，会后仍以郓为落脚处。 [1](#note-1)

<a id="event-2"></a>

2. **吴军乘楚国新丧围潜，退路被楚军牵制。**

吴王僚趁楚平王新丧，派公子掩馀、烛庸围潜，又让季札出使中原、赴晋观察诸侯。楚国多路军队救潜，沈尹戌等加入，吴军退路受到牵制，国内恰逢主力在外。 [2](#note-2)


<a id="backstory-sj-086-L5385-01"></a>

#### 登场前事｜专诸：伍子胥推荐专诸，公子光谋求王位

伍子胥到吴后，发现公子光更关心国内王位问题，于是向他推荐专诸。书中又回顾吴王位在兄弟间传递的经历，并保存公子光自认为有继位资格的理由。

<a id="event-3"></a>

3. **专诸刺杀吴王僚，公子光即位。**

公子光趁两位公子领兵在外，向专诸提出谋取君位。四月，他设宴招待吴王僚，预先藏伏兵，专诸把剑藏在鱼中进献，近身刺杀吴王，自己也遭卫士夹击。公子光即位，是为阖庐，并任专诸之子为卿。季札归国后哭祭吴王墓、回到原职；掩馀奔徐，烛庸奔钟吾，楚军得知吴国内乱后撤回。

阖庐即位后，召伍员任行人，让他参与国政谋议。伍员不再只是从国外求援的流亡者，而进入吴国的决策圈。 [3](#note-3)

<a id="event-4"></a>

4. **费无极设局，楚令尹下令攻郤氏，郤宛自杀。**

费无极与鄢将师排挤左尹郤宛，先说令尹子常将来饮酒，劝郤宛在门口备甲兵作礼物，又向子常告发郤宛准备行刺。子常派人查见甲兵，信以为真。鄢将师遂令攻打郤氏，郤宛自杀；子常又焚毁其宅，诛灭族党及其他相关人物，引发国中持续议论。 [4](#note-4)

<a id="event-5"></a>

5. **扈会再议迎昭公，晋国范献子使方案搁置。**

秋季，晋、宋、卫等国大夫会于扈，安排戍周，也商议送昭公回鲁。宋、卫力主行动，范献子却收了季孙的财物，强调季氏有兵粮、民众和外援，劝两国不要轻易围鲁，并以若不成功便同死的要求加重压力。宋、卫代表退让，诸国最终以事情困难为由作答。 [5](#note-5)

<a id="event-6"></a>

6. **孟懿子、阳虎攻郓，昭公一方败于且知。**

孟懿子与阳虎出兵攻郓。郓人准备作战，子家羁反对继续冒险，昭公让他赴晋求助。昭公的部众随后在且知战败，郓地作为流亡据点的处境进一步恶化。 [6](#note-6)

<a id="event-7"></a>

7. **子常诛费无极、鄢将师，试图平息郤氏案后的议论。**

郤宛案后，楚国指责令尹的声音没有停止。沈尹戌向子常列举费无极逐朝吴、废蔡侯朱、逼走太子建、杀伍奢等旧事，劝他停止相信谗言。九月己未，子常杀费无极与鄢将师，并灭其族，传文记国中议论才渐止。 [7](#note-7)

<a id="event-8"></a>

8. **曹悼公去世。**

冬十月，曹伯午去世，即曹悼公。 [8](#note-8)

<a id="event-9"></a>

9. **邾快出奔鲁国。**

邾国的快来到鲁国避难。 [9](#note-9)

<a id="event-10"></a>

10. **晋国集结诸侯戍周，鲁以国内有难推辞。**

十二月，晋国籍秦汇集各国派往周室的驻军。鲁国以国内变乱为由推辞，没有按要求参与这一轮集结。 [10](#note-10)

> 郤宛直而和，国人说之。鄢将师为右领，与费无极比而恶之。令尹子常贿而信谗。无极谮郤宛焉，谓子常曰：“子恶欲饮子酒。”又谓子恶：“令尹欲饮酒于子氏。”子恶曰：“我，贱人也，不足以辱令尹。令尹将必来辱，为惠已甚。吾无以酬之，若何？”无极曰：“令尹好甲兵，子出之，吾择焉。”取五甲五兵。曰：“寘诸门，令尹至，必观之，而从以酬之。”及飨日，帷诸门左。无极谓令尹曰：“吾几祸子。子恶将为子不利，甲在门矣，子必无往。且此役也，吴可以得志，子恶取赂焉而还，又误群帅，使退其师，曰：‘乘乱不祥。’吴乘我丧，我乘其乱，不亦可乎？”令尹使视郤氏，则有甲焉。不往，召鄢将师而告之。将师退，遂令攻郤氏，且爇之。子恶闻之，遂自杀也。国人弗爇。令曰：“不爇郤氏，与之同罪。”或取一编菅焉，或取一秉秆焉，国人投之，遂弗爇也。令尹炮之。尽灭郤氏之族党，杀阳令终与其弟完及佗与晋陈及其子弟。晋陈之族呼于国曰：“鄢氏、费氏自以为王，专祸楚国，弱寡王室，蒙王与令尹以自利也。令尹尽信之矣，国将如何？”令尹病之。

**说明：** 经文“楚杀其大夫郤宛”与传文“遂自杀”并不必拆成两次死亡：前者归责于楚政令，后者叙具体死法。对饮酒、甲兵、撤军的指控须与确证事实分开。


<a id="note-5"></a>

### [5] 扈会再议迎昭公，晋国范献子使方案搁置。

**《春秋》·昭公二十七年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0515.md#L21-L21)

> 秋，晋士鞅、宋乐祁犁、卫北宫喜、曹人、邾人、滕人会于扈。

**《左传》·昭公二十七年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0515.md#L47-L47)

> 秋，会于扈，令戍周，且谋纳公也。宋、卫皆利纳公，固请之。范献子取货于季孙，谓司城子梁与北宫贞子曰：“季孙未知其罪，而君伐之，请囚，请亡，于是乎不获。君又弗克，而自出也。夫岂无备而能出君乎？季氏之复，天救之也。休公徒之怒，而启叔孙氏之心。不然，岂其伐人而说甲执冰以游？叔孙氏惧祸之滥，而自同于季氏，天之道也。鲁君守齐，三年而无成。季氏甚得其民，淮夷与之，有十年之备，有齐、楚之援，有天之赞，有民之助，有坚守之心，有列国之权，而弗敢宣也，事君如在国。故鞅以为难。二子皆图国者也，而欲纳鲁君，鞅之愿也。请从二子以围鲁，无成，死之。”二子惧，皆辞。乃辞小国，而以难复。

**说明：** 受货有传文直接支持；范献子所列“十年之备”等仍是他的说服性陈词，不当作本项目核实过的军力统计。


<a id="note-6"></a>

### [6] 孟懿子、阳虎攻郓，昭公一方败于且知。

**《左传》·昭公二十七年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0515.md#L49-L49)

> 孟懿子、阳虎伐郓。郓人将战。子家子曰：“天命不慆久矣。使君亡者，必此众也。天既祸之，而自福也，不亦难乎？犹有鬼神，此必败也。呜呼！为无望也夫，其死于此乎！”公使子家子如晋。公徒败于且知。

**说明：** 此时虽战败，仍不能提前写成郓已溃散；经文明记郓溃在昭公二十九年。


<a id="note-7"></a>

### [7] 子常诛费无极、鄢将师，试图平息郤氏案后的议论。

**《左传》·昭公二十七年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0515.md#L51-L51)

> 楚郤宛之难，国言未已，进胙者莫不谤令尹。沈尹戌言于子常曰：“夫左尹与中厩尹莫知其罪，而子杀之，以兴谤，至于今不已。戌也惑之。仁者杀人以掩谤，犹弗为也。今吾子杀人以兴谤而弗图，不亦异乎？夫无极，楚之谗人也，民莫不知。去朝吴，出蔡侯朱，丧大子建，杀连尹奢，屏王之耳目，使不聪明。不然，平王之温惠共俭，有过成、庄，无不及焉。所以不获诸侯，迩无极也。今又杀三不辜，以兴大谤，几及子矣。子而不图，将焉用之？夫鄢将师矫子之命，以灭三族，国之良也，而不愆位。吴新有君，疆埸日骇，楚国若有大事，子其危哉！知者除谗以自安也，今子爱谗以自危也，甚矣其惑也！”子常曰：“是瓦之罪，敢不良图。”九月己未，子常杀费无极与鄢将师，尽灭其族，以说于国。谤言乃止。

**说明：** 这里列举的旧案都属于此前各年，不再次计为本年新发生。子常此次处置也不抹掉其此前下令诛郤氏的责任。

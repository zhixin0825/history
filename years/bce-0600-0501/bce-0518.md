<a id="本年纪事"></a>
<a id="event-1"></a>

1. **孟僖子去世。** 二月丙戌，鲁国仲孙貜去世，即孟僖子。 此前他因赴楚相礼失误而求学；临终嘱孟懿子、南宫敬叔向孔丘学礼，以正考父受命越高越谦恭、弗父何让位的家风说明自己为何看重孔丘。两子后来从学。其“孔子十七岁”的传记说法与本年不合，不能因此把孟僖子的死亡搬到前535。 [[1]](#note-1)

<a id="event-2"></a>

2. **叔孙婼获晋方送归，二月回到鲁国。** 晋国士弥牟到箕接叔孙婼。叔孙事先安排梁其踁守在门内，准备依自己信号行动；见面后，晋方以盟主事务解释久留，并给随从礼物。叔孙接受礼物，二月正式回鲁，结束从前一年开始的拘留。 [[2]](#note-2)

<a id="event-3"></a>

3. **王子朝一方扩大战果，晋国拒收其使者。** 正月，召、南宫两家引甘桓公去见王子朝，王子朝进入邬地。三月，晋人向周人查问内乱缘由，决定拒绝王子朝的使者。六月，王子朝军又攻破瑕、杏两地，战局仍未平定。 [[3]](#note-3)

<a id="event-4"></a>

4. **郑国子大叔催促晋国介入，诸侯约定次年会合。** 郑伯赴晋，子大叔陪同。范献子问王室局势，子大叔用寡妇担心周室、瓶空是酒罍之耻的比喻，说明小国也无法置身事外，尤其需要晋国承担组织救援的责任。范献子与韩宣子商议，召集诸侯，约在下一年会合。 [[4]](#note-4)

<a id="event-5"></a>

5. **五月日食，八月因旱举行大雩。** 五月乙未朔发生日食。梓慎判断将有水灾，叔孙昭子提出相反判断，认为会旱。八月，鲁国因旱举行大雩祈雨。 [[5]](#note-5)

<a id="event-6"></a>

6. **杞平公去世，冬季下葬。** 八月丁酉，杞平公郁釐去世，冬季下葬。 [[6]](#note-6)

<a id="event-7"></a>

7. **王子朝投宝圭于河，后有获玉、献玉的故事。** 十月，王子朝将成周宝圭用于河祭。次日渡口有人得玉，阴不佞率温人向南进兵时拘捕得玉者，取走宝圭。故事又说，待王室安定后，阴不佞献玉并得到东訾。 [[7]](#note-7)

<a id="event-8"></a>

8. **楚舟师进逼吴境，吴乘其撤回取巢、钟离，楚遂加固郢都。** 楚水军巡视侵扰吴境，越大夫与公子来劳军、献舟并出兵随征；楚至圉阳后返，吴尾随，趁边地无备攻两邑而去。另一传述以卑梁、钟离儿童争桑引出家族、邑兵再到两国报复，并说太子建母家在居巢接应，公子光击败陈蔡、带建母离开，楚因惧城郢。争桑各阶段作为前因阅读，没有独立确年。 [[8]](#note-8)

<a id="sj014-audit-0518-cai"></a>

<a id="event-9"></a>

9. **蔡昭侯申元年。** 蔡悼侯东国死后，弟弟申继位，蔡国开始昭侯纪年。 [[9]](#note-9)

<a id="hs-event-10"></a>

10. **鲁八月大雩。** [[10]](#hs-note-10)

> 楚子为舟师以略吴疆。沈尹戌曰：“此行也，楚必亡邑。不抚民而劳之，吴不动而速之，吴踵楚，而疆埸无备，邑能无亡乎？”

> 越大夫胥犴劳王于豫章之汭，越公子仓归王乘舟。仓及寿梦帅师从王，王及圉阳而还。吴人踵楚，而边人不备，遂灭巢及钟离而还。沈尹戌曰：“亡郢之始，于此在矣。王壹动而亡二姓之帅，几如是而不及郢？《诗》曰：‘谁生厉阶，至今为梗。’其王之谓乎。”

<a id="sj066-cite-008"></a>

**[《史记·伍子胥列传》P007](../../sources/摘录/史记-卷066-伍子胥列传.md#p007)**

> 久之，楚平王以其邊邑鐘離與吳邊邑卑梁氏俱蠶，兩女子爭桑相攻，乃大怒，至於兩國舉兵相伐。吳使公子光伐楚，拔其鐘離、居巢而歸。伍子胥說吳王僚曰：「楚可破也。願復遣公子光。」公子光謂吳王曰：「彼伍胥父兄為戮於楚，而勸王伐楚者，欲以自報其讎耳。伐楚未可破也。」伍胥知公子光有內志，欲殺王而自立，未可說以外事，乃進專諸於公子光，退而與太子建之子勝耕於野。

**本卷说明：** 本篇两女子争桑，《楚世家》作小童，《左传》从楚舟师及边邑无备写起。保留传述层次，不将争桑故事的每一步硬系前518；伍员劝伐楚、荐专诸属于前515刺僚之前的前情，不算同日新事。

> 夏五月乙未朔，日有食之。梓慎曰：“将水。”昭子曰：“旱也。日过分而阳犹不克，克必甚，能无旱乎？阳不克莫，将积聚也。”

**《左传》·昭公二十四年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0518.md#all-20261109-j004)

> 秋八月，大雩，旱也。

**说明：** 把预测分歧与后来旱情并列，不据其中一方“应验”宣称占候方法有效。




<a id="6note-6-杞平公去世冬季下葬"></a>
#### [[6]](#note-6) 杞平公去世，冬季下葬。

**《春秋》·昭公二十四年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0518.md#all-20261109-j005)

> 丁酉，杞伯郁釐卒。

**《春秋》·昭公二十四年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0518.md#all-20261109-j006)

> 冬，吴灭巢。葬杞平公。

**说明：** 本条与第8条共引同一经文段，因为该段同时写“吴灭巢。葬杞平公。”；这是声明过的共用出处，不是两次下葬。




<a id="7note-7-王子朝投宝圭于河后有获玉献玉的故事"></a>
#### [[7]](#note-7) 王子朝投宝圭于河，后有获玉、献玉的故事。

**《左传》·昭公二十四年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0518.md#all-20261109-t008)

> 冬十月癸酉，王子朝用成周之宝珪于河。甲戌，津人得诸河上。阴不佞以温人南侵，拘得玉者，取其玉，将卖之，则为石。王定而献之，与之东訾。

**说明：** “欲卖玉而化为石”是原文异闻，不作自然事实确认；“王定而献之”明属后续，不能凭本段位置认定献玉也在本年。




<a id="8note-8-楚舟师进逼吴境吴军尾随攻下巢钟离"></a>
#### [[8]](#note-8) 楚舟师进逼吴境，吴军尾随攻下巢、钟离。

**《春秋》·昭公二十四年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0518.md#all-20261109-j006)

> 冬，吴灭巢。葬杞平公。

**《左传》·昭公二十四年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0518.md#all-20261109-t009)

> 楚子为舟师以略吴疆。沈尹戌曰：“此行也，楚必亡邑。不抚民而劳之，吴不动而速之，吴踵楚，而疆埸无备，邑能无亡乎？”

**《左传》·昭公二十四年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0518.md#all-20261109-t010)

> 越大夫胥犴劳王于豫章之汭，越公子仓归王乘舟。仓及寿梦帅师从王，王及圉阳而还。吴人踵楚，而边人不备，遂灭巢及钟离而还。沈尹戌曰：“亡郢之始，于此在矣。王壹动而亡二姓之帅，几如是而不及郢？《诗》曰：‘谁生厉阶，至今为梗。’其王之谓乎。”

**说明：** 经文只列吴灭巢，传文补钟离；同段经文的葬杞平公另见第6条。沈尹戌关于郢都将受威胁的议论是警告，不是本年郢已失守。

**本次汇入《伍子胥列传》：**

下引原段有的跨年或兼记数事；本条采用范围见说明，[全部去向另列](../../meta/记录/史记-卷066-引文去向.md)。共用原段不重复计为新的史事。

**《史记·伍子胥列传》·原TXT第4666行** · [固定版本原文](../../sources/本地分卷/史记/史记-卷066.md#L4666)

> 久之，楚平王以其邊邑鐘離與吳邊邑卑梁氏俱蠶，兩女子爭桑相攻，乃大怒，至於兩國舉兵相伐。吳使公子光伐楚，拔其鐘離、居巢而歸。伍子胥說吳王僚曰：「楚可破也。願復遣公子光。」公子光謂吳王曰：「彼伍胥父兄為戮於楚，而勸王伐楚者，欲以自報其讎耳。伐楚未可破也。」伍胥知公子光有內志，欲殺王而自立，未可說以外事，乃進專諸於公子光，退而與太子建之子勝耕於野。

**汇入说明：** 《伍子胥列传》将取钟离、居巢之前的纠纷追溯到楚钟离与吴卑梁女子争桑，并由此解释双方交兵；《左传》本年详记楚舟师、越助军、吴尾随袭取无备城邑。正文保留可核的军队行动，不强行断言争桑就是这一次舟师行动的唯一直接原因。列传接叙劝吴再伐、荐专诸及与胜耕田，已在前522年同一事件处交代年次差异，不再制造一次荐举。

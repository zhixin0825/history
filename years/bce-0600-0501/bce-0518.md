# 公元前518年（鲁昭公二十四年）

## 本年纪事

<a id="event-1"></a>

1. **孟僖子去世。**

二月丙戌，鲁国仲孙貜去世，即孟僖子。 [1](#note-1)

<a id="event-2"></a>

2. **叔孙婼获晋方送归，二月回到鲁国。**

晋国士弥牟到箕接叔孙婼。叔孙事先安排梁其踁守在门内，准备依自己信号行动；见面后，晋方以盟主事务解释久留，并给随从礼物。叔孙接受礼物，二月正式回鲁，结束从前一年开始的拘留。 [2](#note-2)

<a id="event-3"></a>

3. **王子朝一方扩大战果，晋国拒收其使者。**

正月，召、南宫两家引甘桓公去见王子朝，王子朝进入邬地。三月，晋人向周人查问内乱缘由，决定拒绝王子朝的使者。六月，王子朝军又攻破瑕、杏两地，战局仍未平定。 [3](#note-3)

<a id="event-4"></a>

4. **郑国子大叔催促晋国介入，诸侯约定次年会合。**

郑伯赴晋，子大叔陪同。范献子问王室局势，子大叔用寡妇担心周室、瓶空是酒罍之耻的比喻，说明小国也无法置身事外，尤其需要晋国承担组织救援的责任。范献子与韩宣子商议，召集诸侯，约在下一年会合。 [4](#note-4)

<a id="event-5"></a>

5. **五月日食，八月因旱举行大雩。**

五月乙未朔发生日食。梓慎判断将有水灾，叔孙昭子提出相反判断，认为会旱。八月，鲁国因旱举行大雩祈雨。 [5](#note-5)

<a id="event-6"></a>

6. **杞平公去世，冬季下葬。**

八月丁酉，杞平公郁釐去世，冬季下葬。 [6](#note-6)

<a id="event-7"></a>

7. **王子朝投宝圭于河，后有获玉、献玉的故事。**

十月，王子朝将成周宝圭用于河祭。次日渡口有人得玉，阴不佞率温人向南进兵时拘捕得玉者，取走宝圭。故事又说，待王室安定后，阴不佞献玉并得到东訾。 [7](#note-7)

<a id="event-8"></a>

8. **楚舟师进逼吴境，吴军尾随攻下巢、钟离。**

楚国出动水军巡视、侵扰吴境，越国大夫与公子前来劳军、献舟并出兵相随。楚军行至圉阳后返回，吴军紧随其后，乘边地没有戒备，攻下巢和钟离，再撤回。 [8](#note-8)

### [4] 郑国子大叔催促晋国介入，诸侯约定次年会合。

**《左传》·昭公二十四年** · [固定版本原文](https://github.com/zhixin0825/history/blob/107ccf2d8ec383dc0f7c4ae0e6ff0f1b55dcdcf0/working-texts/zuozhuan-punctuated-years/years/bce-0518.md#L39-L39)

> 郑伯如晋，子大叔相，见范献子。献子曰：“若王室何？”对曰：“老夫其国家不能恤，敢及王室？抑人亦有言曰：‘嫠不恤其纬，而忧宗周之陨，为将及焉。’今王室实蠢蠢焉，吾小国惧矣。然大国之忧也，吾侪何知焉？吾子其早图之！《诗》曰：‘缾之罄矣，惟罍之耻。’王室之不宁，晋之耻也。”献子惧，而与宣子图之。乃征会于诸侯，期以明年。

**说明：** 此约接续前517年的黄父之会，不在本年提前举办一次大会。

> 楚子为舟师以略吴疆。沈尹戌曰：“此行也，楚必亡邑。不抚民而劳之，吴不动而速之，吴踵楚，而疆埸无备，邑能无亡乎？”

> 越大夫胥犴劳王于豫章之汭，越公子仓归王乘舟。仓及寿梦帅师从王，王及圉阳而还。吴人踵楚，而边人不备，遂灭巢及钟离而还。沈尹戌曰：“亡郢之始，于此在矣。王壹动而亡二姓之帅，几如是而不及郢？《诗》曰：‘谁生厉阶，至今为梗。’其王之谓乎。”

> 久之，楚平王以其邊邑鐘離與吳邊邑卑梁氏俱蠶，兩女子爭桑相攻，乃大怒，至於兩國舉兵相伐。吳使公子光伐楚，拔其鐘離、居巢而歸。伍子胥說吳王僚曰：「楚可破也。願復遣公子光。」公子光謂吳王曰：「彼伍胥父兄為戮於楚，而勸王伐楚者，欲以自報其讎耳。伐楚未可破也。」伍胥知公子光有內志，欲殺王而自立，未可說以外事，乃進專諸於公子光，退而與太子建之子勝耕於野。

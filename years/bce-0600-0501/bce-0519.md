<a id="本年纪事"></a>
<a id="event-1"></a>

1. **晋军与王师攻下郊地，晋军随后暂撤。** 正月，晋军与王师共同围郊，郊地很快溃散。两军分别驻扎平阴、泽邑；周王报告战事暂有间歇后，晋军撤回。 [[1]](#note-1)

<a id="event-2"></a>

2. **鲁人在邾军返程路上设伏，邾国向晋申诉。** 邾人修筑翼城后准备返国。公孙鉏主张绕经武城、沿山向南，其余将领担心低地遇雨难行，仍选择离姑一线。鲁国武城人在前方堵路，将后方树木锯到将断未断；邾军经过时推倒树木，截住并俘获邾军及三名将领。 [[2]](#note-2)

<a id="event-3"></a>

3. **叔孙婼出使晋国遭扣押，拒绝降格受审。** 邾人向晋控诉，晋国派人来追究。叔孙婼奉命出使晋国，却被扣押。晋方要他与邾大夫并坐，他以大国卿与小国君相当为由拒绝，请副使子服回代坐。韩起一度想把他交给邾人，士弥牟提醒，这可能导致鲁国报复并吞邾国，晋方才作罢，转而分别拘留双方。 [[3]](#note-3)

<a id="event-4"></a>

4. **叔孙婼被安置于箕，拒绝通过馈赠谋求脱身。** 晋方将叔孙婼安置在箕，把副使另置一邑。范献子借索冠求取财物，叔孙只按样式送出两顶冠；鲁国申丰携财而来，他将人留在身边，不让其外出行贿。被拘期间，他仍修整住处，离开时保持如初到的状态。 [[4]](#note-4)

<a id="event-5"></a>

5. **叔鞅去世。** 正月癸丑，鲁国叔鞅去世。 [[5]](#note-5)

<a id="event-6"></a>

6. **王子朝进入王城，敬王一方继续退转。** 四月至七月，单、刘两家与尹氏等反复交战。尹圉诱杀刘佗，单氏进攻失利；敬王随支持者转移，王子朝则进入王城，并由鄩罗迎入庄宫。尹氏继续攻打刘氏据点，周室同时存在争夺王位的两方。 [[6]](#note-6)

    [卷四互见与归年](#sj004-519-1)

<a id="event-7"></a>

7. **蔡侯东国死于楚国。** 夏六月，蔡侯东国在楚国去世。 君位由弟弟申承继，是为昭侯，下一年开始新君纪元。 [[7]](#note-7)

<a id="event-8"></a>

8. **莒人逐走庚舆，齐国送郊公回莒。** 莒君庚舆与国人冲突，又准备背离齐国。乌存率国人将他逐走，庚舆逃往鲁国。齐人随后将此前流亡的郊公送回莒国。 [[8]](#note-8)

<a id="event-9"></a>

9. **吴军在鸡父击败楚国所援诸国联军。** 吴军攻州来，楚将薳越率诸国军队来救；楚令尹子瑕去世后，军中部署受到影响。公子光建议先冲击胡、沈、陈三军，再动摇其他部队。吴王先用三千罪人接战，主力跟进，击败三军并俘获胡、沈国君及陈大夫夏齧，又释放部分俘虏传递败讯，许、蔡、顿及楚军相继退败。 [[9]](#note-9)

<a id="event-10"></a>

10. **八月发生地震，南宫极也见于相关灾异记载。** 八月，发生地震。王子朝一方的南宫极也见于震灾叙述，苌弘据此鼓励敬王一方继续行动。 [[10]](#note-10)

<a id="event-11"></a>

11. **吴军进入郹，接走太子建的母亲及宝器。** 太子建的母亲居于郹，召请吴人并为他们打开城门。十月，吴太子诸樊进入郹，将她与宝器带回。楚将薳越追赶不及，拒绝部下再攻吴以求补救的建议，自缢于薳澨。 [[11]](#note-11)

<a id="event-12"></a>

12. **昭公为叔孙婼赴晋，到河边因病折返。** 冬季，昭公为争取释放叔孙婼而前往晋国，到黄河边时生病，折返回鲁。 [[12]](#note-12)

<a id="event-13"></a>

13. **囊瓦任令尹，修筑郢都城防。** 楚国囊瓦任令尹后，修筑郢的城墙。沈尹戌认为，只加固都城而不维护边境、邻国关系和民众生计，并不能解除吴国压力，遂提出一系列守边、亲民、整备建议。 [[13]](#note-13)

<a id="sj014-audit-0519-zhou"></a>

<a id="event-14"></a>

14. **周敬王元年。** 敬王已在上一年周王室内争中被拥立，本年开始敬王纪年。 [[14]](#note-14)

[返回正文第3条](#event-3)

> 二十有三年春，王正月，叔孙婼如晋。

> 晋人执我行人叔孙婼。

> 邾人诉于晋，晋人来讨。叔孙婼如晋，晋人执之。书曰：“晋人执我行人叔孙婼。”言使人也。晋人使与邾大夫坐。叔孙曰：“列国之卿，当小国之君，固周制也。邾又夷也。寡君之命介子服回在，请使当之，不敢废周制故也。”乃不果坐。

> 韩宣子使邾人聚其众，将以叔孙与之。叔孙闻之，去众与兵而朝。士弥牟谓韩宣子曰：“子弗良图，而以叔孙与其仇，叔孙必死之。鲁亡叔孙，必亡邾。邾君亡国，将焉归？子虽悔之，何及？所谓盟主，讨违命也。若皆相执，焉用盟主？”乃弗与。使各居一馆。士伯听其辞而诉诸宣子，乃皆执之。

### 9. 吴军在鸡父击败楚国所援诸国联军

[返回正文第9条](#event-9)

> 戊辰，吴败顿、胡、沈、蔡、陈、许之师于鸡父。

> 胡子髡、沈子逞灭。

> 获陈夏齧。

> 吴人伐州来，楚薳越帅师及诸侯之师奔命救州来。吴人御诸钟离。子瑕卒，楚师熸。吴公子光曰：“诸侯从于楚者众，而皆小国也。畏楚而不获已，是以来。吾闻之曰，作事威克其爱，虽小必济。胡、沈之君幼而狂，陈大夫齧壮而顽，顿与许、蔡疾楚政。楚令尹死，其师，帅贱多宠，政令不壹。七国同役而不同心，帅贱而不能整，无大威命，楚可败也。若分师先以犯胡、沈与陈，必先奔。三国败，诸侯之师乃摇心矣。诸侯乖乱，楚必大奔。请先者去备薄威，后者敦陈整旅。”吴子从之。戊辰晦，战于鸡父。吴子以罪人三千，先犯胡、沈与陈。三国争之。吴为三军以系于后： 中军从王，光帅右，掩馀帅左。吴之罪人或奔或止，三国乱。吴师击之，三国败，获胡、沈之君及陈大夫。舍胡、沈之囚，使奔许与蔡、顿曰：“吾君死矣！”师噪而从之，三国奔。楚师大奔。书曰：“胡子髡、沈子逞灭，获陈夏齧。”君臣之辞也。不言战，楚未陈也。

[返回正文第13条](#event-13)

> 楚囊瓦为令尹，城郢。沈尹戌曰：“子常必亡郢，苟不能卫，城无益也。古者天子守在四夷。天子卑，守在诸侯。诸侯守在四邻。诸侯卑，守在四竟。慎其四竟，结其四援，民狎其野，三务成功，民无内忧，而又无外惧，国焉用城？今吴是惧而城于郢，守已小矣。卑之不获，能无亡乎？昔梁伯沟其公宫而民溃。民弃其上，不亡何待？夫正其疆埸，修其土田，险其走集，亲其民人，明其伍候，信其邻国，慎其官守，守其交礼，不僣不贪，不懦不耆，完其守备，以待不虞，又何畏矣。《诗》曰：‘无念尔祖，聿修厥德。’无亦监乎若敖、蚡冒至于武、文，土不过同，慎其四竟，犹不城郢。今土数圻，而郢是城，不亦难乎！”

> 邾人诉于晋，晋人来讨。叔孙婼如晋，晋人执之。书曰：“晋人执我行人叔孙婼。”言使人也。晋人使与邾大夫坐。叔孙曰：“列国之卿，当小国之君，固周制也。邾又夷也。寡君之命介子服回在，请使当之，不敢废周制故也。”乃不果坐。

**《左传》·昭公二十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0519.md#all-20261109-t004)

> 韩宣子使邾人聚其众，将以叔孙与之。叔孙闻之，去众与兵而朝。士弥牟谓韩宣子曰：“子弗良图，而以叔孙与其仇，叔孙必死之。鲁亡叔孙，必亡邾。邾君亡国，将焉归？子虽悔之，何及？所谓盟主，讨违命也。若皆相执，焉用盟主？”乃弗与。使各居一馆。士伯听其辞而诉诸宣子，乃皆执之。

**说明：** 正文呈现当时援引的等级礼制，不把这些等级关系写成今天应当采用的标准。




<a id="4note-4-叔孙婼被安置于箕拒绝通过馈赠谋求脱身"></a>
#### [[4]](#note-4) 叔孙婼被安置于箕，拒绝通过馈赠谋求脱身。

**《左传》·昭公二十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0519.md#all-20261109-t005)

> 士伯御叔孙，从者四人，过邾馆以如吏。先归邾子。士伯曰：“以刍荛之难，从者之病，将馆子于都。”叔孙旦而立，期焉。乃馆诸箕。舍子服昭伯于他邑。范献子求货于叔孙，使请冠焉。取其冠法，而与之两冠，曰：“尽矣。”为叔孙故，申豐以货如晋。叔孙曰：“见我，吾告女所行货。”见而不出。吏人之与叔孙居于箕者，请其吠狗，弗与。及将归，杀而与之食之。叔孙所馆者，虽一日必葺其墙屋，去之如始至。

**说明：** 请狗、归前杀狗食吏等细节保留于原文。此时仍在被拘，正式回鲁在下一年。

**《春秋》·昭公二十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0519.md#all-20261109-j011)

> 秋七月，莒子庚舆来奔。

**《左传》·昭公二十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0519.md#all-20261109-t007)

<a id="9note-9-吴军在鸡父击败楚国所援诸国联军"></a>
#### [[9]](#note-9) 吴军在鸡父击败楚国所援诸国联军。

**《春秋》·昭公二十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0519.md#all-20261109-j007)

> 戊辰，吴败顿、胡、沈、蔡、陈、许之师于鸡父。

**《春秋》·昭公二十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0519.md#all-20261109-j008)

> 胡子髡、沈子逞灭。

**《春秋》·昭公二十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0519.md#all-20261109-j009)

> 获陈夏齧。

**《左传》·昭公二十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0519.md#all-20261109-j008)

> 吴人伐州来，楚薳越帅师及诸侯之师奔命救州来。吴人御诸钟离。子瑕卒，楚师熸。吴公子光曰：“诸侯从于楚者众，而皆小国也。畏楚而不获已，是以来。吾闻之曰，作事威克其爱，虽小必济。胡、沈之君幼而狂，陈大夫齧壮而顽，顿与许、蔡疾楚政。楚令尹死，其师，帅贱多宠，政令不壹。七国同役而不同心，帅贱而不能整，无大威命，楚可败也。若分师先以犯胡、沈与陈，必先奔。三国败，诸侯之师乃摇心矣。诸侯乖乱，楚必大奔。请先者去备薄威，后者敦陈整旅。”吴子从之。戊辰晦，战于鸡父。吴子以罪人三千，先犯胡、沈与陈。三国争之。吴为三军以系于后： 中军从王，光帅右，掩馀帅左。吴之罪人或奔或止，三国乱。吴师击之，三国败，获胡、沈之君及陈大夫。舍胡、沈之囚，使奔许与蔡、顿曰：“吾君死矣！”师噪而从之，三国奔。楚师大奔。书曰：“胡子髡、沈子逞灭，获陈夏齧。”君臣之辞也。不言战，楚未陈也。

**说明：** 经文胡、沈二君称“灭”、陈夏齧称“获”，传文先记二君被获，再写释俘者喊“吾君死矣”。正文不把战场喊话单独当作二君确切死法的证据。

> 八月乙未，地震。

**《左传》·昭公二十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0519.md#all-20261109-t009)

> 八月丁酉，南宫极震。苌弘谓刘文公曰：“君其勉之，先君之力可济也。周之亡也，其三川震。今西王之大臣亦震，天弃之矣。东王必大克。”

**《左传》·昭公二十三年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0519.md#all-20261109-t012)

> 楚囊瓦为令尹，城郢。沈尹戌曰：“子常必亡郢，苟不能卫，城无益也。古者天子守在四夷。天子卑，守在诸侯。诸侯守在四邻。诸侯卑，守在四竟。慎其四竟，结其四援，民狎其野，三务成功，民无内忧，而又无外惧，国焉用城？今吴是惧而城于郢，守已小矣。卑之不获，能无亡乎？昔梁伯沟其公宫而民溃。民弃其上，不亡何待？夫正其疆埸，修其土田，险其走集，亲其民人，明其伍候，信其邻国，慎其官守，守其交礼，不僣不贪，不懦不耆，完其守备，以待不虞，又何畏矣。《诗》曰：‘无念尔祖，聿修厥德。’无亦监乎若敖、蚡冒至于武、文，土不过同，慎其四竟，犹不城郢。今土数圻，而郢是城，不亦难乎！”

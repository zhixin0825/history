<a id="本年纪事"></a>
<a id="event-1"></a>

1. **周景王准备铸无射大钟，泠州鸠劝阻。** 春季，周景王准备铸造名为无射的大钟。乐官泠州鸠认为钟体过大，声音难与其他乐器协调，劝王不要只求器物宏大而破坏音乐的和谐。 [[1]](#note-1)

<a id="event-2"></a>

2. **三月，蔡平公下葬，继君朱在丧礼中站到卑位。** 蔡国安葬平公，刚继位的蔡侯朱在仪式上没有站在应有的位置。鲁国参加葬礼的大夫回来后，将此事告诉叔孙昭子；昭子因此担心蔡国的君位不会安稳。 [[2]](#note-2)

<a id="event-3"></a>

3. **晋国士鞅来聘，鲁国被迫增加接待用牲。** 夏季，晋国士鞅来鲁。叔孙氏当时主持政务，季孙为了使他在晋国面前受责，安排按此前接待齐国鲍国的规格供给使团。士鞅认为自己的官位、晋国地位都不应受这种待遇，扬言报告晋君。鲁国于是再加四牢，合计供给十一牢。 [[3]](#note-3)

<a id="event-4"></a>

4. **宋国内部再起冲突，华、向两族返回南里。** 华费遂的儿子华多僚反复告发兄弟华貙将接回流亡者。宋元公与华费遂商议，让华貙借出猎离境。消息被华貙一方得知后，张匄等在五月杀了华多僚，挟持华费遂起事，召回流亡陈国的华、向成员。华亥、向宁、华定等进入宋国，盘踞卢门、南里，宋公一方则筑防御设施相抗。 [[4]](#note-4)

<a id="event-5"></a>

5. **七月日食，八月叔辄去世。** 七月壬午朔发生日食。昭公询问梓慎，得到一套以节气和阴阳解释日食的回答；叔辄为日食哭泣，叔孙昭子不赞成这种举动。八月乙亥，叔辄去世。 [[5]](#note-5)

<a id="event-6"></a>

6. **吴军援助华氏，齐、宋与之连战于鸿口、新里。** 十月，华登带吴军来援。驻宋的齐将乌枝鸣采纳厨人濮的建议，趁援军尚未安顿，联合宋军在鸿口击败吴军，俘获两名将领。华登又以余部反击，宋公一度准备出逃；厨人濮召集军众，齐将建议缩减装备、集中近战。齐宋军再攻，终于在新里击退华氏。 [[6]](#note-6)

<a id="event-7"></a>

7. **诸国援军把华氏围在南里，华登向楚求援。** 十一月，公子城带晋军来到，曹、齐、卫等援军也参加救宋。诸军在赭丘与华氏交战，公子城与华豹等战车人员交锋，华氏失利后退守南里。华登突出包围，赴楚求援。楚国已答应派薳越接应，太宰犯则劝楚王不要舍弃宋君而帮助其臣争国。 [[7]](#note-7)

<a id="event-8"></a>

8. **费无极收取东国财物，蔡侯朱被逐往楚国。** 费无极收了东国的财物，向蔡人传话，声称楚王即将废朱立东国，若蔡人不先行动便会遭围攻。蔡人因此逐朱，另立东国。朱到楚国申诉，楚王本想讨蔡，费无极又以蔡灵侯太子后裔与楚王有共同旧怨等理由，劝他接受这一更替。 [[8]](#note-8)

<a id="event-9"></a>

9. **鲁昭公再次朝晋，到黄河边被辞回。** 冬季，昭公前往晋国，到黄河边后被晋方辞回。鼓地再次背离晋国，晋正准备对鲜虞用兵，因此没有接待昭公。 [[9]](#note-9)

### 6. 吴军援助华氏，齐、宋与之连战于鸿口、新里

[返回正文第6条](#event-6)

> 冬十月，华登以吴师救华氏。齐乌枝鸣戍宋。厨人濮曰：“《军志》有之，先人有夺人之心，后人有待其衰。盍及其劳且未定也，伐诸。若入而固，则华氏众矣，悔无及也。”从之。丙寅，齐师、宋师败吴师于鸿口，获其二帅公子苦雂、偃州员。华登帅其馀以败宋师。公欲出，厨人濮曰：“吾小人，可藉死而不能送亡君，请待之。”乃徇曰：“扬徽者，公徒也。”众从之。公自扬门见之，下而巡之曰：“国亡君死，二三子之耻也，岂专孤之罪也？”齐乌枝鸣曰：“用少，莫如齐致死。齐致死，莫如去备。彼多兵矣，请皆用剑。”从之。华氏北，复即之。厨人濮以裳裹首而荷以走，曰：“得华登矣！”遂败华氏于新里。翟偻新居于新里，既战，说甲于公而归。华妵居于公里，亦如之。

### 7. 诸国援军把华氏围在南里，华登向楚求援

[返回正文第7条](#event-7)

> 十一月癸未，公子城以晋师至。曹翰胡会晋荀吴、齐苑何忌、卫公子朝救宋。丙戌，与华氏战于赭丘。郑翩愿为鹳，其御愿为鹅。子禄御公子城，庄堇为右。干犫御吕封人华豹，张匄为右。相遇，城还。华豹曰：“城也！”城怒而反之。将注，豹则关矣。曰：“平公之灵尚辅相余。”豹射出其间。将注，则又关矣。曰：“不狎，鄙。”抽矢。城射之，殪。张匄抽殳而下，射之，折股。扶伏而击之，折轸。又射之，死。干犫请一矢。城曰：“余言女于君。”对曰：“不死伍乘，军之大刑也。干刑而从子，君焉用之？子速诸。”乃射之，殪。大败华氏，围诸南里。华亥搏膺而呼，见华曰：“吾为栾氏矣。” 曰：“子无我迋，不幸而后亡。”使华登如楚乞师。华以车十五乘，徒七十人，犯师而出。食于睢上，哭而送之，乃复入。楚薳越帅师将逆华氏。大宰犯谏曰：“诸侯唯宋事其君，今又争国，释君而臣是助，无乃不可乎？”王曰：“而告我也后，既许之矣。”

以下保留所用古籍原文。回叙、后事、梦占及人物评论依同号说明区分，不将整段都算作本年事实。原工作本的疑字、缺字不静默改写。

**《左传》·昭公二十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0521.md#all-20261109-t001)

> 二十一年春，天王将铸无射。泠州鸠曰：“王其以心疾死乎？夫乐，天子之职也。夫音，乐之舆也。而钟，音之器也。天子省风以作乐，器以钟之，舆以行之，小者不窕，大者不槬，则和于物。物和则嘉成。故和声入于耳而藏于心，心亿则乐。窕则不咸，槬则不容，心是以感。感实生疾。今钟槬矣，王心弗堪，其能久乎？”

**说明：** 传文把声音、内心和疾病联系起来，并预言景王将死于心疾；这是泠州鸠的说法，不是现代医学结论，也不是本项目对人物健康的推断。

<a id="5note-5-七月日食八月叔辄去世"></a>
#### [[5]](#note-5) 七月日食，八月叔辄去世。

**《春秋》·昭公二十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0521.md#all-20261109-j004)

> 秋七月壬午朔，日有食之。

**《春秋》·昭公二十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0521.md#all-20261109-j005)

> 八月乙亥，叔辄卒。

**《左传》·昭公二十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0521.md#all-20261109-j004)

> 秋七月壬午朔，日有食之。公问于梓慎曰：“是何物也，祸福何为？”对曰：“二至、二分，日有食之，不为灾。日月之行也，分，同道也；至，相过也。其他月则为灾。阳不克也，故常为水。”于是叔辄哭日食。昭子曰：“子叔将死，非所哭也。”八月，叔辄卒。

**说明：** 日食与叔辄之死在同一传段中相继出现，但不能据此建立因果关系。古历朔日、月份均照录。




<a id="6note-6-吴军援助华氏齐宋与之连战于鸿口新里"></a>
#### [[6]](#note-6) 吴军援助华氏，齐、宋与之连战于鸿口、新里。

**《左传》·昭公二十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0521.md#all-20261109-t006)

> 冬十月，华登以吴师救华氏。齐乌枝鸣戍宋。厨人濮曰：“《军志》有之，先人有夺人之心，后人有待其衰。盍及其劳且未定也，伐诸。若入而固，则华氏众矣，悔无及也。”从之。丙寅，齐师、宋师败吴师于鸿口，获其二帅公子苦雂、偃州员。华登帅其馀以败宋师。公欲出，厨人濮曰：“吾小人，可藉死而不能送亡君，请待之。”乃徇曰：“扬徽者，公徒也。”众从之。公自扬门见之，下而巡之曰：“国亡君死，二三子之耻也，岂专孤之罪也？”齐乌枝鸣曰：“用少，莫如齐致死。齐致死，莫如去备。彼多兵矣，请皆用剑。”从之。华氏北，复即之。厨人濮以裳裹首而荷以走，曰：“得华登矣！”遂败华氏于新里。翟偻新居于新里，既战，说甲于公而归。华妵居于公里，亦如之。

**说明：** 厨人濮关于“得华登”的呼喊是战场扰敌举动，原文没有因此确认华登被俘。




<a id="7note-7-诸国援军把华氏围在南里华登向楚求援"></a>
#### [[7]](#note-7) 诸国援军把华氏围在南里，华登向楚求援。

**《左传》·昭公二十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0521.md#all-20261109-t007)

> 十一月癸未，公子城以晋师至。曹翰胡会晋荀吴、齐苑何忌、卫公子朝救宋。丙戌，与华氏战于赭丘。郑翩愿为鹳，其御愿为鹅。子禄御公子城，庄堇为右。干犫御吕封人华豹，张匄为右。相遇，城还。华豹曰：“城也！”城怒而反之。将注，豹则关矣。曰：“平公之灵尚辅相余。”豹射出其间。将注，则又关矣。曰：“不狎，鄙。”抽矢。城射之，殪。张匄抽殳而下，射之，折股。扶伏而击之，折轸。又射之，死。干犫请一矢。城曰：“余言女于君。”对曰：“不死伍乘，军之大刑也。干刑而从子，君焉用之？子速诸。”乃射之，殪。大败华氏，围诸南里。华亥搏膺而呼，见华曰：“吾为栾氏矣。” 曰：“子无我迋，不幸而后亡。”使华登如楚乞师。华以车十五乘，徒七十人，犯师而出。食于睢上，哭而送之，乃复入。楚薳越帅师将逆华氏。大宰犯谏曰：“诸侯唯宋事其君，今又争国，释君而臣是助，无乃不可乎？”王曰：“而告我也后，既许之矣。”

**说明：** 个别人物在工作本中出现“华”而缺名，正文不擅补。出战者的对话、射箭过程和劝谏全文保留于同号原文。




<a id="8note-8-费无极收取东国财物蔡侯朱被逐往楚国"></a>
#### [[8]](#note-8) 费无极收取东国财物，蔡侯朱被逐往楚国。

**《春秋》·昭公二十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0521.md#all-20261109-j006)

> 冬，蔡侯朱出奔楚。

**《左传》·昭公二十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0521.md#all-20261109-t008)

> 蔡侯朱出奔楚。费无极取货于东国，而谓蔡人曰：“朱不用命于楚，君王将立东国。若不先从王欲，楚必围蔡。”蔡人惧，出朱而立东国。朱愬于楚，楚子将讨蔡。无极曰：“平侯与楚有盟，故封。其子有二心，故废之。灵王杀隐大子，其子与君同恶，德君必甚。又使立之，不亦可乎？且废寘在君，蔡无他矣。”

**说明：** 须区分费无极对蔡人宣称的“楚王已决定”与楚王实际事后的反应，不能写成一开始就有明确王命。

<a id="卷014补核奔楚的是蔡侯朱不能由列首误指东国"></a>
#### 卷014补核｜奔楚的是蔡侯朱，不能由列首误指东国

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0521)。楚栏“蔡侯来奔”及蔡栏“蔡悼侯东国元年，奔楚”连读易把奔楚者认作东国。按本页第8条《左传》，费无极受东国财物、逐蔡侯朱入楚，东国取得君位；东国后来确实也到楚并于前519死在那里，二人的经历不能互相代换。

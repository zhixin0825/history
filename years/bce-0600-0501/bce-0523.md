<a id="本年纪事"></a>
<a id="event-1"></a>

1. **楚迁阴、筑郏以收缩和加固防线。** 春季，楚国把阴地迁到下阴，又由令尹子瑕修筑郏城。叔孙昭子据此判断楚国已无力经营诸侯霸业，只能先求自保。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚平王留下为太子所聘的秦女，太子建移驻城父。** 楚平王在蔡时与郹阳女子生下太子建。即位以后，他让伍奢辅导太子，费无极担任少师。费无极奉命到秦为太子迎亲，却劝平王把秦女留下，另给太子娶妻。正月，秦女到楚。费无极由此更靠近平王，又担心太子日后继位会追究自己，继续说太子的坏话。后来，他以经营北方、对接诸侯为理由，建议修筑城父，让太子驻在那里，平王接受。 [[2]](#note-2)

<a id="event-3"></a>

3. **宋伐邾取虫，归还鄅俘，并与邾、郳、徐结盟。** 鄅夫人是宋国向戌之女，向宁因此请求宋军救鄅。二月宋元公伐邾围虫，三月攻下后，邾国把此前掳走的鄅人全部归还；随后邾、郳、徐又与宋在虫地结盟。 [[3]](#note-3)

<a id="event-4"></a>

4. **许悼公服太子止所进之药后去世，止奔晋；《春秋》书作“弑君”。** 许悼公患疟疾，五月戊辰服下太子止所进的药后去世，太子随即逃往晋国。经文直接写“世子止弑其君买”，传文则保存君子“尽心力以事君，舍药物可也”的评论，重点在太子对用药结果承担责任；冬季许国安葬悼公。 [[4]](#note-4)

<a id="event-5"></a>

5. **五月己卯发生地震。** 五月己卯，鲁国经文记录地震。本年传文没有为这次地震补出具体灾情或政治解释。 [[5]](#note-5)

<a id="event-6"></a>

6. **齐军攻莒并夺纪鄣，老妇预留的绳索被用作夜袭工具。** 秋季齐国高发率军攻莒，莒君逃到纪鄣。传文讲一名老妇早年被莒君杀夫，后来住在纪鄣时暗中量好城高并把绳索丢到城外；齐军得到这条绳子后夜间攀城，制造大军已入的声势，莒共公惊慌出逃，齐军七月进入纪鄣。 [[6]](#note-6)

<a id="event-7"></a>

7. **郑驷偃死后族人立子瑕，晋国过问，子产以主权理由顶回。** 郑国驷偃去世，儿子丝年幼，族中父兄另立子瑕。丝的晋国舅家向晋求助，晋派人带礼物来郑追问立嗣缘由；子产拒收礼物，指出若晋大夫可以直接决定郑国卿族继承，那郑就成了晋县邑，晋人最终停止干预。 [[7]](#note-7)

<a id="event-8"></a>

8. **楚在州来筑城挑动吴国，沈尹戌认为这会招致失败。** 楚国在州来筑城。沈尹戌认为楚平王虽曾休息民众五年，但国内宫室工程仍重，此时又到吴国刚夺取的州来筑城挑衅，不能算真正安民，迟早会吃败仗。 [[8]](#note-8)

<a id="event-9"></a>

9. **郑国大水出现“龙斗”传闻，子产拒绝为其禳祭。** 郑国发生大水，时门外洧渊传出两条龙相斗的说法，国人请求为龙禳祭。子产认为人类相斗龙并不会来干预，龙在自己的水域相斗也不需要人类介入，因此不祭。 [[9]](#note-9)

<a id="event-10"></a>

10. **楚令尹子瑕劝平王释放蹶由，楚王同意。** 令尹子瑕劝楚平王不要把先前的怒气迁延到蹶由身上，引用“室于怒，市于色”的俗语劝他放下旧怨。楚王接受意见，把蹶由送回。 [[10]](#note-10)

<a id="sj014-audit-0523-cao"></a>

<a id="event-11"></a>

11. **曹悼公午元年。** 曹平公去世后，曹国进入悼公午元年。 [[11]](#note-11)

<a id="sj014-audit-0523-yan"></a>

<a id="event-12"></a>

12. **燕平公元年。** 燕共公去世后，燕国进入平公纪年。 [[12]](#note-12)

### 7. 郑驷偃死后族人立子瑕，晋国过问，子产以主权理由顶回

[返回正文第7条](#event-7)

> 是岁也，郑驷偃卒。子游娶于晋大夫，生丝，弱。其父兄立子瑕。子产憎其为人也，且以为不顺，弗许，亦弗止。驷氏耸。

> 他日，丝以告其舅。冬，晋人使以币如郑，问驷乞之立故。驷氏惧，驷乞欲逃。子产弗遣。请龟以卜，亦弗予。大夫谋对。子产不待而对客曰：“郑国不天，寡君之二三臣，札瘥夭昏。今又丧我先大夫偃，其子幼弱，其一二父兄，惧队宗主，私族于谋而立长亲。寡君与其二三老曰：‘抑天实剥乱是，吾何知焉？’谚曰：‘无过乱门。’民有兵乱，犹惮过之，而况敢知天之所乱。今大夫将问其故，抑寡君实不敢知，其谁实知之。平丘之会，君寻旧盟曰：‘无或失职。’若寡君之二三臣，其即世者，晋大夫而专制其位，是晋之县鄙也，何国之为？”辞客币而报其使。晋人舍之。

#### [[7]](#note-7) 郑驷偃死后族人立子瑕，晋国过问，子产以主权理由顶回

**《左传》·昭公十九年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0523.md#all-20261109-t009)

> 是岁也，郑驷偃卒。子游娶于晋大夫，生丝，弱。其父兄立子瑕。子产憎其为人也，且以为不顺，弗许，亦弗止。驷氏耸。

**《左传》·昭公十九年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0523.md#all-20261109-t010)

> 他日，丝以告其舅。冬，晋人使以币如郑，问驷乞之立故。驷氏惧，驷乞欲逃。子产弗遣。请龟以卜，亦弗予。大夫谋对。子产不待而对客曰：“郑国不天，寡君之二三臣，札瘥夭昏。今又丧我先大夫偃，其子幼弱，其一二父兄，惧队宗主，私族于谋而立长亲。寡君与其二三老曰：‘抑天实剥乱是，吾何知焉？’谚曰：‘无过乱门。’民有兵乱，犹惮过之，而况敢知天之所乱。今大夫将问其故，抑寡君实不敢知，其谁实知之。平丘之会，君寻旧盟曰：‘无或失职。’若寡君之二三臣，其即世者，晋大夫而专制其位，是晋之县鄙也，何国之为？”辞客币而报其使。晋人舍之。

#### [[8]](#note-8) 楚在州来筑城挑动吴国，沈尹戌认为这会招致失败

**《左传》·昭公十九年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0523.md#all-20261109-t011)

> 楚人城州来。沈尹戌曰：“楚人必败。昔吴灭州来，子旗请伐之。王曰：‘吾未抚吾民。’今亦如之，而城州来以挑吴，能无败乎？”侍者曰：“王施舍不倦，息民五年，可谓抚之矣。”戌曰：“吾闻抚民者，节用于内，而树德于外，民乐其性，而无寇仇。今宫室无量，民人日骇，劳罢死转，忘寝与食，非抚之也。”

> 郑大水，龙斗于时门之外洧渊。国人请为禜焉，子产弗许，曰：“我斗，龙不我觌也。龙斗，我独何觌焉？禳之，则彼其室也。吾无求于龙，龙亦无求于我。”乃止也。

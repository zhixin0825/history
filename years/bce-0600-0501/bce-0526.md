## 本年纪事

<a id="event-1"></a>

1. **鲁昭公被晋扣留到春季，夏天才回国**

正月昭公仍在晋国，传文明说“晋人止公”，只是鲁国史书因讳而没有写进经文。到夏天昭公才回鲁；子服昭伯随后从晋君年幼、六卿势强的局面判断晋公室会继续衰弱。 [1](#note-1)

<a id="event-2"></a>

2. **齐伐徐、徐等盟齐；楚诱杀戎蛮子并一度吞并蛮氏**

齐景公出兵伐徐，二月到蒲隧，徐国求和，徐子并与郯、莒代表同齐侯结盟，还以甲父之鼎行赂。同一春，楚平王又让然丹诱杀戎蛮子嘉，夺取蛮氏地盘，后来再立其子。 [2](#note-2)

<a id="event-3"></a>

3. **韩宣子聘郑，孔张在宴礼中失位引发争论**

晋国韩宣子出使郑国，子产先要求朝臣各守礼位。孔张迟到后多次站错位置，被宾客取笑；富子以此责子产，子产反驳说真正可耻的是执政在法令、刑狱、外交上失职，孔张本人既有世职，就应自己知道位置。 [3](#note-3)

<a id="event-4"></a>

4. **韩宣子求郑商人玉环，子产以旧盟和制度拒绝**

韩宣子想得到一只掌握在郑国商人手里的玉环，先向郑伯请求，子产以那不是官府所有为由拒绝。后来韩宣子自己与商人议价，商人坚持要报告执政；子产又援引郑国立国以来与商人的盟誓，说明国家不能替大国强夺民间财物，韩宣子最终放弃。 [4](#note-4)

<a id="event-5"></a>

5. **郑六卿在郊外为韩宣子饯行，以赋诗表达立场**

韩宣子离郑时，郑国六卿在郊外饯行，双方连续赋诗。韩宣子从诗意判断郑国卿族关系尚可维持，并以马匹、玉器回礼；这一段主要呈现当时以《诗》表达外交立场的礼仪。 [5](#note-5)

<a id="event-6"></a>

6. **晋昭公去世，季孙意如赴晋参加葬礼**

八月，晋昭公夷去世。十月，季孙意如前往晋国参加葬礼；至此可以看出，《史记》把鲁昭公上一年的被留直接说成“葬晋昭公”，在年代上至少前后错置了一年。 [6](#note-6)

<a id="event-7"></a>

7. **鲁、郑都遭旱灾；鲁大雩，郑祭桑山时斩木被子产惩处**

九月鲁国举行大雩，传文说明原因是旱。郑国也大旱，官员到桑山祭祀时反而砍树，子产认为祭山本应培育山林，因此撤了他们的官邑。 [7](#note-7)

<a id="sj014-audit-0526-wu"></a>
**吴王僚元年。** 吴王夷末去世之后，吴国进入王僚元年。 [原文与说明](#sj014-audit-0526-wu-note)

## 史料核对说明

《鲁周公世家》没有单列十六年新事；但其十五年“留之葬晋昭公”必须结合本页校正：昭公十六年春仍被留、夏归，晋昭公到秋才去世。

<a id="note-3"></a>

### [[3]](#note-3) 韩宣子聘郑，孔张在宴礼中失位引发争论

**《左传》·昭公十六年** · [固定版本原文](https://github.com/zhixin0825/history/blob/9abd5c4a6b6ae7036c0f7918ba7c981536a60055/working-texts/zuozhuan-punctuated-years/years/bce-0526.md#L37-L37)

> 三月，晋韩起聘于郑，郑伯享之。子产戒之曰：“苟有位于朝，无有不共恪。”孔张后至，立于客间。执政御之，適客后。又御之，適县间。客从而笑之。事毕，富子谏曰：“夫大国之人，不可不慎也，几为之笑而不陵我？我皆有礼，夫犹鄙我。国而无礼，何以求荣？孔张失位，吾子之耻也。”子产怒曰：“发命之不衷，出令之不信，刑之颇类，狱之放纷，会朝之不敬，使命之不听，取陵于大国，罢民而无功，罪及而弗知，侨之耻也。孔张，君之昆孙，子孔之后也，执政之嗣也。为嗣大夫，承命以使，周于诸侯，国人所尊，诸侯所知。立于朝而祀于家，有禄于国。有赋于军，丧祭有职，受脤归脤，其祭在庙，已有著位，在位数世，世守其业，而忘其所，侨焉得耻之？辟邪之人而皆及执政，是先王无刑罚也。子宁以他规我。”


<a id="note-4"></a>

### [[4]](#note-4) 韩宣子求郑商人玉环，子产以旧盟和制度拒绝

**《左传》·昭公十六年** · [固定版本原文](https://github.com/zhixin0825/history/blob/9abd5c4a6b6ae7036c0f7918ba7c981536a60055/working-texts/zuozhuan-punctuated-years/years/bce-0526.md#L39-L39)

> 宣子有环，其一在郑商。宣子谒诸郑伯，子产弗与，曰：“非官府之守器也，寡君不知。”子大叔、子羽谓子产曰：“韩子亦无几求，晋国亦未可以贰。晋国、韩子，不可偷也。若属有谗人交斗其间，鬼神而助之，以兴其凶怒，悔之何及？吾子何爱于一环，其以取憎于大国也，盍求而与之？”子产曰：“吾非偷晋而有二心，将终事之，是以弗与，忠信故也。侨闻君子非无贿之难，立而无令名之患。侨闻为国非不能事大字小之难，无礼以定其位之患。夫大国之人，令于小国，而皆获其求，将何以给之？一共一否，为罪滋大。大国之求，无礼以斥之，何餍之有？吾且为鄙邑，则失位矣。若韩子奉命以使，而求玉焉，贪淫甚矣，独非罪乎？出一玉以起二罪，吾又失位，韩子成贪，将焉用之？且吾以玉贾罪，不亦锐乎？”

**《左传》·昭公十六年** · [固定版本原文](https://github.com/zhixin0825/history/blob/9abd5c4a6b6ae7036c0f7918ba7c981536a60055/working-texts/zuozhuan-punctuated-years/years/bce-0526.md#L41-L41)

> 韩子买诸贾人，既成贾矣，商人曰：“必告君大夫。”韩子请诸子产曰：“日起请夫环，执政弗义，弗敢复也。今买诸商人，商人曰，必以闻，敢以为请。”子产对曰：“昔我先君桓公，与商人皆出自周。庸次比耦，以艾杀此地，斩之蓬蒿藜藋，而共处之。世有盟誓，以相信也，曰：‘尔无我叛，我无强贾，毋或匄夺。尔有利市宝贿，我勿与知。’恃此质誓，故能相保，以至于今。今吾子以好来辱，而谓敝邑强夺商人，是教敝邑背盟誓也，毋乃不可乎！吾子得玉而失诸侯，必不为也。若大国令，而共无艺，郑，鄙邑也，亦弗为也。侨若献玉，不知所成，敢私布之。”韩子辞玉曰：“起不敏，敢求玉以徼二罪？敢辞之。”

### [[5]](#note-5) 郑六卿在郊外为韩宣子饯行，以赋诗表达立场

**《左传》·昭公十六年** · [固定版本原文](https://github.com/zhixin0825/history/blob/9abd5c4a6b6ae7036c0f7918ba7c981536a60055/working-texts/zuozhuan-punctuated-years/years/bce-0526.md#L43-L43)

> 夏四月，郑六卿饯宣子于郊。宣子曰：“二三君子请皆赋，起亦以知郑志。”子齹赋《野有蔓草》。宣子曰：“孺子善哉，吾有望矣。”子产赋郑之《羔裘》。宣子曰：“起不堪也。”子大叔赋《褰裳》。宣子曰：“起在此，敢勤子至于他人乎？”子大叔拜。宣子曰：“善哉，子之言是。不有是事，其能终乎？”子游赋《风雨》，子旗赋《有女同车》，子柳赋蘀兮。宣子喜曰：“郑其庶乎。二三君子以君命贶起，赋不出郑志，皆昵燕好也。二三君子，数世之主也，可以无惧矣。”宣子皆献马焉，而赋《我将》。子产拜，使五卿皆拜，曰：“吾子靖乱，敢不拜德？”宣子私觐于子产，以玉与马，曰：“子命起舍夫玉，是赐我玉而免吾死也，敢不藉手以拜？”

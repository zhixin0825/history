<a id="本年纪事"></a>
<a id="event-1"></a>

1. **吴王夷末去世。** 正月，吴王夷末去世。经文没有在本年条下补写更多吴国继承细节。 [[1]](#note-1)

<a id="event-2"></a>

2. **鲁禘祭武公时叔弓暴卒，祭礼去乐后继续。** 鲁国准备在武公庙举行禘祭。二月癸酉仪式开始，乐舞刚入，主持事务的叔弓突然去世；鲁国撤去音乐后仍把祭礼完成，传文评价这种处置合礼。 [[2]](#note-2)

<a id="event-3"></a>

3. **蔡人逐朝吴，朝吴逃往郑国。** 费无极嫉恨朝吴在蔡国的地位，一面鼓动朝吴向上求位，一面又向蔡国上层说朝吴得到楚王特别信任、迟早压过他们。蔡人因此驱逐朝吴，朝吴逃郑；楚平王发怒后，费无极又把这说成削弱蔡国羽翼。 [[3]](#note-3)

<a id="event-4"></a>

<a id="event-8"></a>

4. **周太子寿、穆后去世，晋使会葬。** 周王太子寿、王穆后先后去世。六月，周景王太子寿去世。八月，王穆后也去世。两场王室大丧相距很近，并成为年底晋使赴周送葬时争议的背景。晋使荀跞葬周穆后，周景王责籍谈“数典忘祖”。十二月，晋国荀跞到周参加穆后葬礼，籍谈作副使。葬后周景王追问晋为什么没有献王室旧器，籍谈回答晋地偏远、先世无分。景王列举唐叔、晋文公所得器物和典籍传统反驳，留下“数典而忘其祖”的评语。叔向回国后又批评景王在重丧中设宴、索器同样失礼。 [[4]](#note-4)

    [卷四互见与归年](#sj004-527-1)

<a id="event-5"></a>

5. **六月朔发生日食。** 六月丁巳朔，发生日食。经文单独记录此事，传文在本年没有再加解释。 [[5]](#note-5)

<a id="event-6"></a>

6. **晋荀吴围鼓，坚持拒绝诱降，粮尽后取城而不杀。** 晋荀吴攻鲜虞并围鼓。有人想把城直接献给晋军，荀吴拒绝利用叛徒；围城三月后，城中一度请求投降，他看见居民仍有食色，又让他们继续守，直到粮尽力竭才受降，攻克后没有杀人，把鼓子鸢鞮带回晋国。 [[6]](#note-6)

<a id="event-7"></a>

7. **鲁昭公因平丘旧事赴晋。** 冬，鲁昭公因平丘之会中鲁国受处置一事前往晋国。他在本年未能返鲁，次年春仍被晋扣留。 [[7]](#note-7)

<a id="sj014-audit-0527-cao"></a>

<a id="event-9"></a>

8. **曹平公须元年。** 曹国在武公去世后进入平公须元年。 [[8]](#note-9)

> 十二月，晋荀跞如周，葬穆后，籍谈为介。既葬除丧，以文伯宴，樽以鲁壶。王曰：“伯氏，诸侯皆有以镇抚王室，晋独无有，何也？”文伯揖籍谈，对曰：“诸侯之封也，皆受明器于王室，以镇抚其社稷，故能荐彝器于王。晋居深山，戎狄之与邻，而远于王室。王灵不及，拜戎不暇，其何以献器？”王曰：“叔氏，而忘诸乎？叔父唐叔，成王之母弟也，其反无分乎？密须之鼓，与其大路，文所以大蒐也。阙巩之甲，武所以克商也。唐叔受之以处参虚，匡有戎狄。其后襄之二路，钺秬鬯，彤弓虎贲，文公受之，以有南阳之田，抚征东夏，非分而何？夫有勋而不废，有绩而载，奉之以土田，抚之以彝器，旌之以车服，明之以文章，子孙不忘，所谓福也。福祚之不登叔父，焉在？且昔而高祖孙伯黡，司晋之典籍，以为大政，故曰籍氏。及辛有之二子董之，晋于是乎有董史。女，司典之后也。何故忘之？”籍谈不能对。宾出，王曰：“籍父其无后乎！数典而忘其祖。”

> 籍谈归，以告叔向。叔向曰：“王其不终乎。吾闻之，所乐必卒焉。今王乐忧，若卒以忧，不可谓终。王一岁而有三年之丧二焉，于是乎以丧宾宴，又求彝器，乐忧甚矣，且非礼也。彝器之来，嘉功之由，非由丧也。三年之丧，虽贵遂服，礼也。王虽弗遂，宴乐以早，亦非礼也。礼，王之大经也。一动而失二礼，无大经矣。言以考典，典以志经，忘经而多言举典，将焉用之？”

### 6. 晋荀吴围鼓，坚持拒绝诱降，粮尽后取城而不杀

[返回正文第6条](#event-6)

> 秋，晋荀吴帅师伐鲜虞。

> 晋荀吴帅师伐鲜虞，围鼓。鼓人或请以城叛，穆子弗许。左右曰：“师徒不勤，而可以获城，何故不为？”穆子曰：“吾闻诸叔向曰：‘好恶不愆，民知所適，事无不济。’或以吾城叛，吾所甚恶也。人以城来，吾独何好焉。赏所甚恶，若所好何？若其弗赏，是失信也，何以庇民？力能则进，否则退，量力而行。吾不可以欲城而迩奸，所丧滋多。”使鼓人杀叛人而缮守备。围鼓三月，鼓人或请降，使其民见，曰：“犹有食色，姑修而城。”军吏曰：“获城而弗取，勤民而顿兵，何以事君？”穆子曰：“吾以事君也。获一邑而教民怠，将焉用邑？邑以贾怠，不如完旧。贾怠无卒，弃旧不祥。鼓人能事其君，我亦能事吾君。率义不爽，好恶不愆，城可获而民知义所，有死命而无二心，不亦可乎！”鼓人告食竭力尽，而后取之。克鼓而反，不戮一人，以鼓子鸢鞮归。

**《史记·鲁周公世家》·十五年：朝晋、被留与所谓葬晋昭公** · [所核固定版本](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E9%AD%AF%E5%91%A8%E5%85%AC%E4%B8%96%E5%AE%B6.md#ref-12bee54bd5de1b)

> 十五年，朝晉，晉留之葬晉昭公，魯恥之。

**说明：** 《史记·鲁周公世家》写成“十五年，朝晋，晋留之葬晋昭公，鲁耻之”。经传确实证明昭公被晋留住，但晋昭公要到下一年秋天才去世，因此“留之葬晋昭公”无法按字面成立；正文依经传分成十五年入晋、十六年春被留和夏归鲁。




<a id="8note-8-晋使荀跞葬周穆后周景王责籍谈数典忘祖"></a>
#### [[8]](#note-8) 晋使荀跞葬周穆后，周景王责籍谈“数典忘祖”

**《左传》·昭公十五年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0527.md#all-20261109-t007)

> 十二月，晋荀跞如周，葬穆后，籍谈为介。既葬除丧，以文伯宴，樽以鲁壶。王曰：“伯氏，诸侯皆有以镇抚王室，晋独无有，何也？”文伯揖籍谈，对曰：“诸侯之封也，皆受明器于王室，以镇抚其社稷，故能荐彝器于王。晋居深山，戎狄之与邻，而远于王室。王灵不及，拜戎不暇，其何以献器？”王曰：“叔氏，而忘诸乎？叔父唐叔，成王之母弟也，其反无分乎？密须之鼓，与其大路，文所以大蒐也。阙巩之甲，武所以克商也。唐叔受之以处参虚，匡有戎狄。其后襄之二路，钺秬鬯，彤弓虎贲，文公受之，以有南阳之田，抚征东夏，非分而何？夫有勋而不废，有绩而载，奉之以土田，抚之以彝器，旌之以车服，明之以文章，子孙不忘，所谓福也。福祚之不登叔父，焉在？且昔而高祖孙伯黡，司晋之典籍，以为大政，故曰籍氏。及辛有之二子董之，晋于是乎有董史。女，司典之后也。何故忘之？”籍谈不能对。宾出，王曰：“籍父其无后乎！数典而忘其祖。”

**《左传》·昭公十五年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0527.md#all-20261109-t008)

> 籍谈归，以告叔向。叔向曰：“王其不终乎。吾闻之，所乐必卒焉。今王乐忧，若卒以忧，不可谓终。王一岁而有三年之丧二焉，于是乎以丧宾宴，又求彝器，乐忧甚矣，且非礼也。彝器之来，嘉功之由，非由丧也。三年之丧，虽贵遂服，礼也。王虽弗遂，宴乐以早，亦非礼也。礼，王之大经也。一动而失二礼，无大经矣。言以考典，典以志经，忘经而多言举典，将焉用之？”

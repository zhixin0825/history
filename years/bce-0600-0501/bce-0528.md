# 公元前528年（鲁昭公十四年）

## 本年纪事

<a id="event-1"></a>

1. **季孙意如从晋国归鲁**

春季，季孙意如终于从晋国回到鲁国。传文把他归国时承认过错、尊重晋国的姿态评价为合礼。 [1](#note-1)

<a id="event-2"></a>

2. **费人反叛南蒯，南蒯逃齐，费邑回归季氏**

南蒯叛季氏已经三年，费地的司徒老祁、虑癸利用民众想脱离南蒯的情绪，逼他离开。南蒯逃到齐国，仍辩称自己原意是壮大鲁公室；费邑则重新归还季氏。 [2](#note-2)

<a id="event-3"></a>

3. **楚平王整顿军政、赈恤民众并休兵**

楚平王命然丹、屈罢分别检查上国、东国兵力，同时赈贫恤弱、整理官职、赦罪查奸，并让民众休息五年后才再用兵。 [3](#note-3)

<a id="event-4"></a>

4. **曹武公去世并下葬**

三月，曹武公滕去世；秋季下葬。经文只给出这两项丧事节点。 [4](#note-4)

<a id="event-5"></a>

5. **莒国政变：意恢被杀、郊公奔齐、庚舆被迎立**

八月莒著丘公去世，他的继承人郊公没有表现出哀戚，引起国人不满。蒲馀侯与公子铎密谋：先杀公子意恢，再逐郊公、迎庚舆；十二月计划实现，郊公逃齐，庚舆由齐人护送回莒。 [5](#note-5)

<a id="event-6"></a>

6. **楚平王杀令尹斗成然并灭养氏**

令尹斗成然曾有功于楚平王，却与养氏结党并不断求取利益。楚王认为局面失控，九月杀斗成然、灭养氏，同时让斗辛镇守郧地，以表示没有完全抹去旧功。 [6](#note-6)

<a id="event-7"></a>

7. **晋国鄐田旧案引出受贿判案与朝廷杀人，三人同被定罪**

邢侯与雍子长期争夺鄐田，叔鱼代审时收受雍子女儿，反判邢侯有罪；邢侯愤而在朝廷杀死叔鱼与雍子。韩宣子问叔向如何定罪，叔向认为行贿、卖狱和擅杀三罪并重，晋国最终处置邢侯并陈尸另外两人；传文又保存孔子对叔向不避亲的赞语。 [7](#note-7)

<a id="sj014-audit-0528-chu"></a>
**楚平王居元年。** 弃疾已在上一年夺得楚王位；本年开始平王纪年，年表称其名居。 [原文与说明](#sj014-audit-0528-chu-note)

<a id="sj014-audit-0528-yan"></a>
**燕共公元年。** 燕国开始共公纪年。 [原文与说明](#sj014-audit-0528-yan-note)

> 南蒯之将叛也，盟费人。司徒老祁、虑癸伪废疾，使请于南蒯曰：“臣愿受盟而疾兴，若以君灵不死，请待间而盟。”许之。二子因民之欲叛也，请朝众而盟。遂劫南蒯曰：“群臣不忘其君，畏子以及今，三年听命矣。子若弗图，费人不忍其君，将不能畏子矣。子何所不逞欲？请送子。”请期五日。遂奔齐。侍饮酒于景公。公曰：“叛夫！”对曰：“臣欲张公室也。”子韩晳曰：“家臣而欲张公室，罪莫大焉。”司徒老祁、虑癸来归费。齐侯使鲍文子致之。

### [[6]](#note-6) 楚平王杀令尹斗成然并灭养氏

**《左传》·昭公十四年** · [固定版本原文](https://github.com/zhixin0825/history/blob/9abd5c4a6b6ae7036c0f7918ba7c981536a60055/working-texts/zuozhuan-punctuated-years/years/bce-0528.md#L37-L37)

<a id="note-7"></a>

### [[7]](#note-7) 晋国鄐田旧案引出受贿判案与朝廷杀人，三人同被定罪

**《左传》·昭公十四年** · [固定版本原文](https://github.com/zhixin0825/history/blob/9abd5c4a6b6ae7036c0f7918ba7c981536a60055/working-texts/zuozhuan-punctuated-years/years/bce-0528.md#L41-L41)

> 晋邢侯与雍子争鄐田，久而无成。士景伯如楚，叔鱼摄理。韩宣子命断旧狱，罪在雍子。雍子纳其女于叔鱼，叔鱼蔽罪邢侯。邢侯怒，杀叔鱼与雍子于朝。宣子问其罪于叔向。叔向曰：“三人同罪，施生戮死可也。雍子自知其罪而赂以买直，鲋也鬻狱，邢侯专杀，其罪一也。己恶而掠美为昏，贪以败官为墨，杀人不忌为贼。《夏书》曰：‘昏、墨、贼，杀。’皋陶之刑也。请从之。”乃施邢侯而尸雍子与叔鱼于市。

**《左传》·昭公十四年** · [固定版本原文](https://github.com/zhixin0825/history/blob/9abd5c4a6b6ae7036c0f7918ba7c981536a60055/working-texts/zuozhuan-punctuated-years/years/bce-0528.md#L43-L43)

> 仲尼曰：“叔向，古之遗直也。治国制刑，不隐于亲，三数叔鱼之恶，不为末減。曰义也夫，可谓直矣。平丘之会，数其贿也，以宽卫国，晋不为暴。归鲁季孙，称其诈也，以宽鲁国，晋不为虐。邢侯之狱，言其贪也，以正刑书，晋不为颇。三言而除三恶，加三利，杀亲益荣，犹义也夫？”

### 卷014补核｜楚平王居元年。

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0528)。楚栏作“楚平王居元年共王子，抱玉。”。前529年政变与复陈蔡已有主述。“共王子，抱玉”属王室世系及埋璧传说，不能在元年另造一次抱玉择君仪式；《楚世家》又记弃疾即位改名熊居。

<a id="sj014-audit-0528-yan-note"></a>
### 卷014补核｜燕共公元年。

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0528)。燕栏作“燕共公元年”。《燕召公世家》依次列悼公、共公；前539年出奔的惠公／简公及复位异年须另辨，不借这一元年消除前段矛盾。

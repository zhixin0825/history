## 本年纪事

<a id="event-1"></a>

1. **叔弓赴宋，参加宋平公葬礼**

二月，鲁国派叔弓到宋国参加宋平公的葬礼。这一条经传都只记送葬本身，没有再补出新的外交冲突。 [1](#note-1)

<a id="event-2"></a>

2. **楚灵王诱杀蔡灵侯，楚军继而围蔡**

周景王问苌弘诸侯吉凶，苌弘把蔡国列为将有大难的一方。楚灵王随后在申地召蔡灵侯，蔡国大夫已经警告这是诱骗，蔡侯仍然前往；楚王先设伏拘住他，四月杀死蔡侯和七十名随从，随后命公子弃疾率军围蔡。韩宣子问叔向楚是否能得手，叔向认为楚可能一时成功，但以欺骗取利会留下后患。 [2](#note-2)

<a id="event-3"></a>

3. **鲁昭公的母亲齐归去世，鲁国仍举行大蒐**

五月，昭公的母亲齐归去世。鲁国同月仍在比蒲举行大规模田猎演习，传文因此批评为不合丧礼。 [3](#note-3)

<a id="event-4"></a>

4. **孟僖子与邾庄公结盟，并留下家族后事**

孟僖子在祲祥与邾庄公结盟，恢复两国关系。传文随后用泉丘女子的梦作引子，交代她后来为孟僖子生下懿子、南宫敬叔，以及僚属代为抚养敬叔的家族后事。 [4](#note-4)

<a id="event-5"></a>

5. **晋召集诸侯谋救蔡，最终未能迫楚退兵**

楚军围蔡时，晋国荀吴已经批评晋作为盟主既不能救陈又不能救蔡。秋季各国在厥慭开会商议救蔡；子产预料这次行动走不远，晋国最后只派狐父向楚请求放过蔡国，楚没有答应。 [5](#note-5)

<a id="event-6"></a>

6. **单成公在会见韩宣子后不久去世**

单成公在戚地会见韩宣子。叔向从他的视线、步态和说话状态推测他将不久于人世；十二月，传文记单成公去世。 [6](#note-6)

<a id="event-7"></a>

7. **齐归下葬，鲁国对丧礼的处理受到批评**

九月，鲁国安葬齐归。传文说昭公没有表现出哀戚，又把此前在国丧中举行大蒐连在一起，史赵、叔向据此批评鲁国君臣关系和公室地位。 [7](#note-7)

<a id="event-8"></a>

8. **楚灭蔡，并以蔡太子祭冈山**

十一月，楚军攻灭蔡国，俘走蔡太子有。传文称楚灵王把这位太子用于冈山祭祀，申无宇当面批评以诸侯作祭牲是不祥之举。 [8](#note-8)

<a id="event-9"></a>

9. **楚在陈、蔡、不羹筑大城，让弃疾主蔡**

灭蔡以后，楚灵王在陈、蔡和不羹经营大城，并让公子弃疾在蔡主持事务。申无宇提醒，边地大城和宗亲重臣在外都可能形成尾大不掉的局面。 [9](#note-9)

> 韩宣子问于叔向曰：“楚其克乎？”对曰：“克哉！蔡侯获罪于其君，而不能其民，天将假手于楚以毙之，何故不克？然肸闻之，不信以幸，不可再也。楚王奉孙吴以讨于陈曰，将定而国。陈人听命，而遂县之。今又诱蔡而杀其君，以围其国，虽幸而克，必受其咎，弗能久矣。桀克有缗以丧其国，纣克东夷而陨其身。楚小位下，而亟暴于二王，能无咎乎？天之假助不善，非祚之也，厚其凶恶而降之罚也。且譬之如天，其有五材而将用之，力尽而敝之，是以无拯，不可没振。”

**说明：** 苌弘、叔向关于天意和报应的判断按人物意见保留，不把它们写成事件发生的客观原因。

**《左传》·昭公十一年** · [固定版本原文](https://github.com/zhixin0825/history/blob/9abd5c4a6b6ae7036c0f7918ba7c981536a60055/working-texts/zuozhuan-punctuated-years/years/bce-0531.md#L59-L59)

> 楚子城陈、蔡、不羹。使弃疾为蔡公。王问于申无宇曰：“弃疾在蔡，何如？”对曰：“择子莫如父，择臣莫如君。郑庄公城栎而寘子元焉，使昭公不立。齐桓公城穀而寘管仲焉，至于今赖之。臣闻五大不在边，五细不在庭。亲不在外，羁不在内。今弃疾在外，郑丹在内。君其少戒。”王曰：“国有大城，何如？”对曰：“郑京、栎实杀曼伯，宋萧、亳实杀子游，齐渠丘实杀无知，卫蒲、戚实出献公，若由是观之，则害于国。末大必折，尾大不掉，君所知也。”

### 年次与异说｜1. 《吴世家》把余祭之死放在十七年

**时间：余祭十七年，属本篇纪年异说** · 异说

按本篇余祭四年对应前544年的年次推算，十七年是前531年，书中说余祭死后由余眛继位。但《左传》在襄公二十九年（前544）已记阍弑余祭。

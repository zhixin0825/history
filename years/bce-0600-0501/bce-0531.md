<a id="本年纪事"></a>
<a id="event-1"></a>

1. **叔弓赴宋，参加宋平公葬礼。** 二月，鲁国派叔弓到宋国参加宋平公的葬礼。这一条经传都只记送葬本身，没有再补出新的外交冲突。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚灵王在宴中诱杀蔡灵侯，随后命弃疾围蔡。** 周景王问诸侯吉凶，苌弘已把蔡列为将有难者。蔡臣警告召见是诱骗，蔡侯仍到申；楚王设伏拘住，借饮酒杀侯，四月又有七十随从一同被杀。韩宣子问叔向楚能否得手，叔向认为虽可能暂成，但欺诈将招后患。 [[2]](#note-2)

<a id="event-3"></a>

3. **鲁昭公的母亲齐归去世，鲁国仍举行大蒐。** 五月，昭公的母亲齐归去世。鲁国同月仍在比蒲举行大规模田猎演习，传文因此批评为不合丧礼。 [[3]](#note-3)

<a id="event-4"></a>

4. **孟僖子与邾庄公结盟，并留下家族后事。** 孟僖子在祲祥与邾庄公结盟，恢复两国关系。传文随后用泉丘女子的梦作引子，交代她后来为孟僖子生下懿子、南宫敬叔，以及僚属代为抚养敬叔的家族后事。 [[4]](#note-4)

<a id="event-5"></a>

5. **晋召集诸侯谋救蔡，最终未能迫楚退兵。** 楚军围蔡时，晋国荀吴已经批评晋作为盟主既不能救陈又不能救蔡。秋季各国在厥慭开会商议救蔡；子产预料这次行动走不远，晋国最后只派狐父向楚请求放过蔡国，楚没有答应。 [[5]](#note-5)

<a id="event-6"></a>

6. **单成公在会见韩宣子后不久去世。** 单成公在戚地会见韩宣子。叔向见其步态、视线和说话的样子，推测他将不久于人世。十二月，单成公去世。 [[6]](#note-6)

<a id="event-7"></a>

7. **齐归下葬，鲁国对丧礼的处理受到批评。** 九月，鲁国安葬齐归。传文说昭公没有表现出哀戚，又把此前在国丧中举行大蒐连在一起，史赵、叔向据此批评鲁国君臣关系和公室地位。 [[7]](#note-7)

<a id="event-8"></a>

8. **楚灭蔡，并以蔡太子祭冈山。** 十一月，楚军灭蔡，俘获蔡太子有。楚灵王以太子有祭冈山，申无宇批评以诸侯作祭牲。 [[8]](#note-8)

<a id="event-9"></a>

9. **楚在陈、蔡、不羹筑大城，让弃疾兼掌陈蔡。** 灭蔡后，公子弃疾在蔡主事，兼掌陈、蔡而号陈蔡公。申无宇警告，边地大城、宗亲重臣远离王廷，可能形成尾大不掉的局面；这些据点后来果然牵动王位争夺。 [[9]](#note-9)

<a id="sj014-audit-0531-jin"></a>

<a id="event-10"></a>

10. **晋昭公夷元年。** 晋平公去世之后，晋国进入昭公夷元年。 [[10]](#note-10)

<a id="sj014-audit-0531-song"></a>

<a id="event-11"></a>

11. **宋元公佐元年。** 宋国在平公去世后开始元公佐的纪年。 [[11]](#note-11)

### 2. 楚灵王诱杀蔡灵侯，楚军继而围蔡

[返回正文第2条](#event-2)

> 夏四月丁巳，楚子虔诱蔡侯般杀之于申。

> 楚公子弃疾帅师围蔡。

> 景王问于苌弘曰：“今兹诸侯，何实吉？何实凶？”对曰：“蔡凶。此蔡侯般弑其君之岁也。岁在豕韦，弗过此矣。楚将有之，然壅也。岁及大梁，蔡复楚凶，天之道也。”

> 楚子在申，召蔡灵侯。灵侯将往。蔡大夫曰：“王贪而无信，唯蔡于感，今币重而言甘，诱我也，不如无往。”蔡侯不可。三月丙申，楚子伏甲而飨蔡侯于申，醉而执之。夏四月丁巳，杀之，刑其士七十人。公子弃疾帅师围蔡。

> 韩宣子问于叔向曰：“楚其克乎？”对曰：“克哉！蔡侯获罪于其君，而不能其民，天将假手于楚以毙之，何故不克？然肸闻之，不信以幸，不可再也。楚王奉孙吴以讨于陈曰，将定而国。陈人听命，而遂县之。今又诱蔡而杀其君，以围其国，虽幸而克，必受其咎，弗能久矣。桀克有缗以丧其国，纣克东夷而陨其身。楚小位下，而亟暴于二王，能无咎乎？天之假助不善，非祚之也，厚其凶恶而降之罚也。且譬之如天，其有五材而将用之，力尽而敝之，是以无拯，不可没振。”

### 5. 晋召集诸侯谋救蔡，最终未能迫楚退兵

[返回正文第5条](#event-5)

> 秋，季孙意如会晋韩起、齐国弱、宋华亥、卫北宫佗、郑罕虎、曹人、杞人于厥慭。

> 楚师在蔡，晋荀吴谓韩宣子曰：“不能救陈，又不能救蔡，物以无亲，晋之不能，亦可知也已！为盟主而不恤亡国，将焉用之？”

> 秋，会于厥慭，谋救蔡也。郑子皮将行。子产曰：“行不远，不能救蔡也。蔡小而不顺，楚大而不德，天将弃蔡以壅楚。盈而罚之，蔡必亡矣。且丧君而能守者，鲜矣。三年，王其有咎乎！美恶周必复，王恶周矣。”晋人使狐父请蔡于楚，弗许。

### 6. 单成公在会见韩宣子后不久去世

[返回正文第6条](#event-6)

> 单子会韩宣子于戚，视下言徐。叔向曰：“单子其将死乎。朝有著定，会有表，衣有襘，带有结。会朝之言，必闻于表著之位，所以昭事序也。视不过结襘、之中，所以道容貌也。言以命之，容貌以明之，失则有阙。今单子为王官伯，而命事于会，视不登带，言不过步，貌不道容，而言不昭矣。不道不共，不昭不从，无守气矣。”

> 十二月，单成公卒。

[返回正文第7条](#event-7)

> 九月，葬齐归，公不慼。晋士之送葬者，归以语史赵。史赵曰：“必为鲁郊。”侍者曰：“何故？”曰：“归，姓也。不思亲，祖不归也。”叔向曰：“鲁公室其卑乎。君有大丧，国不废蒐。有三年之丧，而无一日之慼。国不恤丧，不忌君也。君无慼容，不顾亲也。国不忌君，君不顾亲，能无卑乎？殆其失国。”

> 孟僖子会邾庄公盟于祲祥，修好，礼也。泉丘人有女梦以其帷幕孟氏之庙，遂奔僖子，其僚从之。盟于清丘之社，曰：“有子，无相弃也。”僖子使助薳氏之簉。反自祲祥，宿于薳氏，生懿子及南宫敬叔于泉丘人。其僚无子，使字敬叔。

**说明：** 梦境只作为传文叙事方式保留，不作为生育或政治结果的因果解释。




<a id="5note-5-晋召集诸侯谋救蔡最终未能迫楚退兵"></a>
#### [[5]](#note-5) 晋召集诸侯谋救蔡，最终未能迫楚退兵

**《春秋》·昭公十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0531.md#all-20261109-j007)

> 秋，季孙意如会晋韩起、齐国弱、宋华亥、卫北宫佗、郑罕虎、曹人、杞人于厥慭。

**《左传》·昭公十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0531.md#all-20261109-t007)

> 楚师在蔡，晋荀吴谓韩宣子曰：“不能救陈，又不能救蔡，物以无亲，晋之不能，亦可知也已！为盟主而不恤亡国，将焉用之？”

**《左传》·昭公十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0531.md#all-20261109-t008)

> 秋，会于厥慭，谋救蔡也。郑子皮将行。子产曰：“行不远，不能救蔡也。蔡小而不顺，楚大而不德，天将弃蔡以壅楚。盈而罚之，蔡必亡矣。且丧君而能守者，鲜矣。三年，王其有咎乎！美恶周必复，王恶周矣。”晋人使狐父请蔡于楚，弗许。




<a id="6note-6-单成公在会见韩宣子后不久去世"></a>
#### [[6]](#note-6) 单成公在会见韩宣子后不久去世

**《左传》·昭公十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0531.md#all-20261109-t009)

> 单子会韩宣子于戚，视下言徐。叔向曰：“单子其将死乎。朝有著定，会有表，衣有襘，带有结。会朝之言，必闻于表著之位，所以昭事序也。视不过结襘、之中，所以道容貌也。言以命之，容貌以明之，失则有阙。今单子为王官伯，而命事于会，视不登带，言不过步，貌不道容，而言不昭矣。不道不共，不昭不从，无守气矣。”

**《左传》·昭公十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0531.md#all-20261109-t012)

> 十二月，单成公卒。

**说明：** 叔向的预言与后来的死亡属于文本中的对应，不据此断言能够由外在仪态预测寿命。




<a id="7note-7-齐归下葬鲁国对丧礼的处理受到批评"></a>
#### [[7]](#note-7) 齐归下葬，鲁国对丧礼的处理受到批评

**《春秋》·昭公十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0531.md#all-20261109-j008)

> 九月己亥，葬我小君齐归。

**《左传》·昭公十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0531.md#all-20261109-t010)

> 九月，葬齐归，公不慼。晋士之送葬者，归以语史赵。史赵曰：“必为鲁郊。”侍者曰：“何故？”曰：“归，姓也。不思亲，祖不归也。”叔向曰：“鲁公室其卑乎。君有大丧，国不废蒐。有三年之丧，而无一日之慼。国不恤丧，不忌君也。君无慼容，不顾亲也。国不忌君，君不顾亲，能无卑乎？殆其失国。”

**说明：** 正文只保留可观察到的丧葬与大蒐安排；对昭公品行及鲁公室未来的判断属于人物评论。




<a id="8note-8-楚灭蔡并以蔡太子祭冈山"></a>
#### [[8]](#note-8) 楚灭蔡，并以蔡太子祭冈山

**《春秋》·昭公十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0531.md#all-20261109-j009)

> 冬十有一月丁酉，楚师灭蔡，执蔡世子有以归，用之。

**《左传》·昭公十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0531.md#all-20261109-t011)

> 冬十一月，楚子灭蔡，用隐大子于冈山。申无宇曰：“不祥。五牲不相为用，况用诸侯乎？王必悔之。”

**说明：** 经文称“世子有”，传文作“隐大子”，本页视为同一人。




<a id="9note-9-楚在陈蔡不羹筑大城让弃疾主蔡"></a>
#### [[9]](#note-9) 楚在陈、蔡、不羹筑大城，让弃疾主蔡

**《左传》·昭公十一年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0531.md#all-20261109-t013)

> 楚子城陈、蔡、不羹。使弃疾为蔡公。王问于申无宇曰：“弃疾在蔡，何如？”对曰：“择子莫如父，择臣莫如君。郑庄公城栎而寘子元焉，使昭公不立。齐桓公城穀而寘管仲焉，至于今赖之。臣闻五大不在边，五细不在庭。亲不在外，羁不在内。今弃疾在外，郑丹在内。君其少戒。”王曰：“国有大城，何如？”对曰：“郑京、栎实杀曼伯，宋萧、亳实杀子游，齐渠丘实杀无知，卫蒲、戚实出献公，若由是观之，则害于国。末大必折，尾大不掉，君所知也。”

**说明：** 申无宇列举郑、宋、齐、卫旧事，是劝谏中的历史类比，不把这些旧事重新计入本年。

#### 年次与异说｜1. 《吴世家》把余祭之死放在十七年

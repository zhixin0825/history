# 公元前533年（鲁昭公九年）

> 本页完成第一轮白话整理与逐段去向登记；不是现代学术校勘定本。古历月份不直接换算成同号公历月份。

## 本年纪事

<a id="event-1"></a>

1. **春季，叔弓与宋郑卫使者到陈地会见楚王。**

陈国被楚军控制以后，鲁国叔弓、宋国华亥、郑国游吉、卫国赵黡到陈地会见楚灵王。这是灭陈之后的诸国交往。现存本年条没有详写所议盟约或分地条件，本页不补一份不存在的会议结论。 [1](#note-1)

<a id="event-2"></a>

2. **楚国把许迁到夷，并同时调整周边居民与田地归属。**

二月庚申，楚公子弃疾把许国迁到夷，传文说明这里实际是城父。楚方又拨给许国州来淮北的田地，由伍举授田；然丹把城父原有居民迁到陈，另给夷濮西部田地，还把方城外的人迁入许地。迁许因此不只是一位国君换住处，而是一连串人口与土地安排。 [2](#note-2)

<a id="event-3"></a>

3. **周人与晋人争阎田，晋军攻颍后经交涉退还土地和俘虏。**

周王室的甘人与晋国阎嘉争夺阎田，晋国梁丙、张趯带阴戎攻打颍。周王派詹桓伯向晋提出抗议，强调王室与诸侯的关系。叔向认为周方言辞有据，劝韩起处理。晋国随后趁王室姻亲丧事遣赵成来吊，交还阎田和在颍取得的俘虏；周王也拘送甘大夫襄向晋说明，晋人以礼待之，再送回。 [3](#note-3)

<a id="event-4"></a>

4. **四月，陈地发生火灾。**

陈地在楚国控制之下发生火灾。郑国裨竈据此谈到陈国将来复封和最终灭亡，子产追问其理由，裨竈用星次与五行解释。就本年而言，能够编入的灾事是四月失火，不能顺着预测把几年后的复国提前写进来。 [4](#note-4)

<a id="event-5"></a>

5. **晋国荀盈迎亲归途中去世，屠蒯借进酒劝止宴乐；荀跞随后任下军佐。**

荀盈赴齐迎亲，回程六月死在戏阳，灵柩停在绛，尚未下葬。晋平公却饮酒作乐，膳宰屠蒯请求进酒，先后对乐工、近臣和自己举杯，把“耳目”“调味”各自应尽之责说给国君听。晋君听后撤酒止乐，也停止了原想废去知氏、改立近臣的打算。八月，荀跞被任为下军佐。 [5](#note-5)

<a id="event-6"></a>

6. **孟僖子赴齐聘问。**

鲁国派仲孙貜到齐国进行殷聘。仲孙貜即孟僖子，也是此前随昭公赴楚相礼、归后求学的人。这次是另一次有明确年条的外交活动，不是前往楚国行程的继续。 [6](#note-6)

<a id="event-7"></a>

7. **冬季，鲁国修筑郎囿，叔孙昭子劝季平子不要催工过急。**

鲁国开始筑郎囿，供田猎游观之用。季平子希望工程尽快完成，叔孙昭子引用诗句劝他：可以没有苑囿，却不能因急于完工而耗尽民力。现存记载没有交代季平子是否采纳，也没有给出工程何日完成。 [7](#note-7)

<a id="note-3"></a>

### [[3]](#note-3) 周人与晋人争阎田，晋军攻颍后经交涉退还土地和俘虏。

**《左传》·昭公九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0533.md#L31-L31)

> 周甘人与晋阎嘉争阎田。晋梁丙、张趯率阴戎伐颍。王使詹桓伯辞于晋，曰：“我自夏以后稷，魏、骀、芮、岐、毕，吾西土也。及武王克商，蒲姑、商奄，吾东土也。巴、濮、楚、邓，吾南土也。肃慎、燕、亳，吾北土也。吾何迩封之有？文、武、成、康之建母弟，以蕃屏周，亦其废队是为，岂如弁髦而因以敝之。先王居梼杌于四裔，以御螭魅，故允姓之奸，居于瓜州。伯父惠公归自秦，而诱以来，使偪我诸姬，入我郊甸，则戎焉取之。戎有中国，谁之咎也？后稷封殖天下，今戎制之，不亦难乎？伯父图之。我在伯父，犹衣服之有冠冕，木水之有本原，民人之有谋主也。伯父若裂冠毁冕，拔本塞原，专弃谋主，虽戎狄其何有余一人？”叔向谓宣子曰：“文之伯也，岂能改物？翼戴天子而加之以共。自文以来，世有衰德而暴灭宗周，以宣示其侈，诸侯之贰，不亦宜乎？且王辞直，子其图之。”宣子说。

**《左传》·昭公九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0533.md#L33-L33)

> 王有姻丧，使赵成如周吊，且致阎田与襚，反颍俘。王亦使宾滑执甘大夫襄以说于晋。晋人礼而归之。

**说明：** 詹桓伯列举古代疆域与封建经过，是本次外交陈辞中的历史论据，不等于本年周王实际控制该清单中所有地方。贡襚、交地和还俘是交涉结果，不另杜撰停战条约全文。

### [[4]](#note-4) 四月，陈地发生火灾。

**《春秋》·昭公九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0533.md#L17-L17)

**《左传》·昭公九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0533.md#L35-L35)

> 夏四月，陈灾。郑裨竈曰：“五年，陈将复封。封五十二年而遂亡。”子产问其故。对曰：“陈，水属也，火，水妃也，而楚所相也。今火出而火陈，逐楚而建陈也。妃以五成，故曰五年。岁五及鹑火，而后陈卒亡，楚克有之，天之道也，故曰五十二年。”

**说明：** 预言中的五年、五十二年作为原文观念保留，不视为经过独立验证的预测。火灾损失原文未详，不补估。

### [[5]](#note-5) 晋国荀盈迎亲归途中去世，屠蒯借进酒劝止宴乐；荀跞随后任下军佐。

**《左传》·昭公九年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0533.md#L37-L37)

> 晋荀盈如齐逆女，还，六月，卒于戏阳。殡于绛，未葬。晋侯饮酒，乐。膳宰屠蒯趋入，请佐公使尊。许之。而遂酌以饮工，曰：“女为君耳，将司聪也。辰在子卯，谓之疾日。君彻宴乐，学人舍业，为疾故也。君之卿佐，是谓股肱。股肱或亏，何痛如之？女弗闻而乐，是不聪也。”又饮外嬖嬖叔曰：“女为君目，将司明也。服以旌礼，礼以行事，事有其物，物有其容。今君之容，非其物也，而女不见，是不明也。”亦自饮也，曰：“味以行气，气以实志，志以定言，言以出令。臣实司味，二御失官，而君弗命，臣之罪也。”公说，彻酒。初，公欲废知氏而立其外嬖，为是悛而止。

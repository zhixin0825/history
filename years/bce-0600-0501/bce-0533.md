<a id="本年纪事"></a>
<a id="event-1"></a>

1. **春季，叔弓与宋郑卫使者到陈地会见楚王。** 陈国被楚军控制以后，鲁国叔弓、宋国华亥、郑国游吉、卫国赵黡到陈地会见楚灵王。这是灭陈之后的诸国交往。现存本年条没有详写所议盟约或分地条件，本页不补一份不存在的会议结论。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚国把许迁到夷，并同时调整周边居民与田地归属。** 二月庚申，楚公子弃疾把许国迁到夷，传文说明这里实际是城父。楚方又拨给许国州来淮北的田地，由伍举授田；然丹把城父原有居民迁到陈，另给夷濮西部田地，还把方城外的人迁入许地。迁许因此不只是一位国君换住处，而是一连串人口与土地安排。 [[2]](#note-2)

<a id="event-3"></a>

3. **周人与晋人争阎田，晋军攻颍后经交涉退还土地和俘虏。** 周王室的甘人与晋国阎嘉争夺阎田，晋国梁丙、张趯带阴戎攻打颍。周王派詹桓伯向晋提出抗议，强调王室与诸侯的关系。叔向认为周方言辞有据，劝韩起处理。晋国随后趁王室姻亲丧事遣赵成来吊，交还阎田和在颍取得的俘虏；周王也拘送甘大夫襄向晋说明，晋人以礼待之，再送回。 [[3]](#note-3)

<a id="event-4"></a>

4. **四月，陈地发生火灾。** 陈地在楚国控制之下发生火灾。郑国裨竈据此谈到陈国将来复封和最终灭亡，子产追问其理由，裨竈用星次与五行解释。就本年而言，能够编入的灾事是四月失火，不能顺着预测把几年后的复国提前写进来。 [[4]](#note-4)

<a id="event-5"></a>

5. **晋国荀盈迎亲归途中去世，屠蒯借进酒劝止宴乐；荀跞随后任下军佐。** 荀盈赴齐迎亲，回程六月死在戏阳，灵柩停在绛，尚未下葬。晋平公却饮酒作乐，膳宰屠蒯请求进酒，先后对乐工、近臣和自己举杯，把“耳目”“调味”各自应尽之责说给国君听。晋君听后撤酒止乐，也停止了原想废去知氏、改立近臣的打算。八月，荀跞被任为下军佐。 [[5]](#note-5)

<a id="event-6"></a>

6. **孟僖子赴齐聘问。** 鲁国派仲孙貜到齐国进行殷聘。仲孙貜即孟僖子，也是此前随昭公赴楚相礼、归后求学的人。这次是另一次有明确年条的外交活动，不是前往楚国行程的继续。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬季，鲁国修筑郎囿，叔孙昭子劝季平子不要催工过急。** 鲁国开始筑郎囿，供田猎游观之用。季平子希望工程尽快完成，叔孙昭子引用诗句劝他：可以没有苑囿，却不能因急于完工而耗尽民力。现存记载没有交代季平子是否采纳，也没有给出工程何日完成。 [[7]](#note-7)

<a id="sj014-audit-0533-chu"></a>

<a id="event-8"></a>

8. **楚国派弃疾镇定陈地。** 楚灭陈之后，年表在本年接着记王弟弃疾率军镇定陈地。 [[8]](#note-8)

> 冬，筑郎囿，书时也。季平子欲其速成也，叔孙昭子曰：“《诗》曰：‘经始勿亟，庶民子来。’焉用速成？其以勦民也。无囿犹可，无民其可乎？”

**说明：** “囿”解释为苑囿，不擅加墙高、面积和征役人数。叔孙昭子的劝告是一项实际言事，是否改变工期仍无本条证据。

<a id="sj014-audit-0533-chu-note"></a>
<a id="卷014补核楚国派弃疾镇定陈地"></a>
#### 卷014补核｜楚国派弃疾镇定陈地。

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0533)。楚栏“八弟弃疾将兵定陈”与陈栏“楚来定我”相对；《楚世家》却以灵王八年写弃疾“灭陈”，又与经传及年表前534已灭陈的位置不同。此处保守保留本表“定陈”的继续控制之意，不新造第二次灭陈。陈惠公元年是追记，实际复国仍见前529。

<a id="sj014-audit-0533-chen-note"></a>
<a id="卷014补核陈惠公追记元年与实际复国"></a>
#### 卷014补核｜陈惠公追记元年与实际复国

[本年国别原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0533)。陈栏“陈惠公吴元年”，实际楚平王恢复陈国在[前529年](bce-0529.md#event-5)；《陈杞世家》明确“探续哀公卒时年而为元，空籍五岁”。这里是追记的年次，不表示楚灭陈第二年即已复国。[百度百科陈惠公](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-b13539fd67108804.md#cite-2)也区分前533追记与前529复国；其正文又有“前534为元年”与列年前533不一致，只取其明确指出两类时间的说明，不照搬矛盾。

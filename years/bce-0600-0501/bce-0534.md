1. **晋营建虒祁宫，魏榆异闻引发议论。** 晋国传出石头说话的异闻，师旷借此谈营建虒祁宫的负担。春季，晋国魏榆传出石头说话的消息。晋平公询问师旷，师旷先说明石头本不能说话，提出可能是凭附之说或听闻失真，又把议论转向当时兴建虒祁宫、民力消耗的问题。叔向随后称许他的答话。这里有传闻及答问，并非本项目证实石头真的开口。鲁郑使者到晋国祝贺虒祁宫落成，晋臣却提出另一种看法。鲁国派叔弓赴晋，郑伯也由游吉陪同前往，都是为虒祁宫致贺。晋国史赵见游吉，认为这件事本应表达忧虑，怎么反来祝贺。游吉答复，来贺的不止郑国，天下诸侯都会依这样的往来方式办理。宫室营建在外交上得到庆贺，并不代表当时没有相反意见。 [[1]](#note-1)

<a id="event-2"></a>

<a id="event-6"></a>

<a id="event-8"></a>

2. **陈国内乱，楚围陈并将其灭亡。** 陈国继承争端演成杀太子、改立与出奔，陈哀公也在四月去世。陈哀公的元妃生太子偃师，另一位夫人生公子留，公子胜又出于别的夫人。哀公偏向留，把他托付给司徒招和公子过。三月，招与过杀死偃师，立留为君。四月，哀公缢死。陈使干征师到楚国报丧并通告新君，公子胜又向楚方申诉，楚国却把使者拘杀。公子留随后逃往郑国。公子招杀公子过推卸责任，楚军随后围陈。杀太子之后，公子招把责任推到一同参与的公子过身上，将过杀死。九月，楚公子弃疾奉孙吴率军围陈，宋国戴恶也来会师。由陈国内部的继承争端，局势转成楚军介入。围城与冬季灭陈还要区分先后。冬季，楚军灭陈，弃疾领兵，陈地转由楚治理。公子招被拘并放逐到越，孔奂被杀，楚任穿封戌为陈公。陈哀公葬事也在此时办理，袁克杀马毁玉随葬，楚人欲杀他，他在交涉中逃脱。晋臣随后讨论陈国是否会复国，那些预期仍不是本年的结果。 [[2]](#note-2)

<a id="event-4"></a>

3. **鲁国在红地大蒐。** 秋，鲁国在红地大蒐，召集的兵车从根牟至商、卫，合计千乘。 [[3]](#note-4)

<a id="event-5"></a>

4. **齐国子尾去世后，子旗试图控制其家，陈桓子出面调停。** 七月子尾去世，子旗插手其家，杀梁婴，又逐走子成、子工、子车，这些人逃到鲁国。子良家中的人担心本家被兼并，准备动武，陈桓子也准备相助。子旗得知后去找陈桓子交涉，陈桓子在见面时换作平常服饰，最后促成和解，没有在本年立即爆发两家决战。 [[4]](#note-5)

<a id="event-7"></a>

5. **鲁国举行大雩。** 秋，鲁国举行大雩。 [[5]](#note-7)

<a id="sj014-audit-0534-wei"></a>

<a id="event-9"></a>

6. **卫灵公元年。** 卫襄公在上一年去世，公子元被拥立；本年进入卫灵公纪年。 [[6]](#note-9)

**《左传》·昭公八年** · [固定版本原文](../../拆分史书/左传/bce-0534.md#all-20261109-t001)

> 八年春，石言于晋魏榆。晋侯问于师旷曰：“石何故言？”对曰：“石不能言，或冯焉。不然，民听滥也。抑臣又闻之曰：‘作事不时，怨讟动于民，则有非言之物而言。’今宫室崇侈，民力彫尽，怨讟并作，莫保其性。石言，不亦宜乎。”于是晋侯方筑虒祁之宫。叔向曰：“子野之言，君子哉！君子之言，信而有征，故怨远于其身。小人之言，僭而无征，故怨咎及之。《诗》曰：‘哀哉不能言，匪舌是出，唯躬是瘁。哿矣能言，巧言如流，俾躬处休。’其是之谓乎。是宫也成，诸侯必叛，君必有咎，夫子知之矣。”

**说明：** “石言”作为传文所记的异闻保留，正文明确其证据层级。叔向关于宫成后诸侯会叛的推测，不改写成本年已经发生的反叛。

**说明：** 哀公死日有异：经文作“四月辛丑”，传文作“四月辛亥”。正文只定四月，原日并列保留，未做历法裁决。对杀使一事，传文明确区分罪责不在行人，本页不把干征师写成弑太子的实施者。




<a id="3note-3-鲁郑使者到晋国祝贺虒祁宫落成晋臣却提出另一种看法"></a>
#### [[3]](#note-3) 鲁郑使者到晋国祝贺虒祁宫落成，晋臣却提出另一种看法。

**《春秋》·昭公八年** · [固定版本原文](../../拆分史书/左传/bce-0534.md#all-20261109-j003)

> 叔弓如晋。

**《左传》·昭公八年** · [固定版本原文](../../拆分史书/左传/bce-0534.md#all-20261109-j003)

> 叔弓如晋，贺虒祁也。游吉相郑伯以如晋，亦贺虒祁也。史赵见子大叔曰：“甚哉，其相蒙也！可吊也，而又贺之？”子大叔曰：“若何吊也？其非唯我贺，将天下实贺。”

**说明：** 不同意见分别归于史赵和游吉，不把祝贺活动直接当作各国对晋国营建政策的一致认可。




<a id="4note-4-秋季鲁国在红地举行大规模田猎军演"></a>
#### [[4]](#note-4) 秋季，鲁国在红地举行大规模田猎军演。

**《春秋》·昭公八年** · [固定版本原文](../../拆分史书/左传/bce-0534.md#all-20261109-j006)

> 秋，蒐于红。

**《左传》·昭公八年** · [固定版本原文](../../拆分史书/左传/bce-0534.md#all-20261109-t005)

> 秋，大蒐于红，自根牟至于商、卫，革车千乘。

**说明：** 范围和“千乘”保留为传文数字，不由它推算精确国土边界、常备军数量或全国人口。




<a id="5note-5-齐国子尾去世后子旗试图控制其家陈桓子出面调停"></a>
#### [[5]](#note-5) 齐国子尾去世后，子旗试图控制其家，陈桓子出面调停。

**《左传》·昭公八年** · [固定版本原文](../../拆分史书/左传/bce-0534.md#all-20261109-t006)

> 七月甲戌，齐子尾卒，子旗欲治其室。丁丑，杀梁婴。八月庚戌，逐子成、子工、子车，皆来奔，而立子良氏之宰。其臣曰：“孺子长矣，而相吾室，欲兼我也。”授甲将攻之。陈桓子善于子尾，亦授甲，将助之。或告子旗，子旗不信。则数人告。将往，又数人告于道，遂如陈氏。桓子将出矣，闻之而还，游服而逆之，请命。对曰：“闻彊氏授甲将攻子，子闻诸？”曰：“弗闻。”“子盍亦授甲？无宇请从。”子旗曰：“子胡然？彼孺子也，吾诲之犹惧其不济，吾又宠秩之。其若先人何？子盍谓之？《周书》曰：‘惠不惠，茂不茂。’康叔所以服弘大也。”桓子稽颡曰：“顷、灵福子，吾犹有望。”遂和之如初。

**说明：** 子尾为公孙虿；子旗、子良等家族称呼保持与传文对应。此事与昭公十年栾、高、陈、鲍大战有关联，但本年和解不等于后年的战争已经发生。




<a id="6note-6-公子招杀公子过推卸责任楚军随后围陈"></a>
#### [[6]](#note-6) 公子招杀公子过推卸责任，楚军随后围陈。

**《春秋》·昭公八年** · [固定版本原文](../../拆分史书/左传/bce-0534.md#all-20261109-j007)

> 陈人杀其大夫公子过。

**《左传》·昭公八年** · [固定版本原文](../../拆分史书/左传/bce-0534.md#all-20261109-t007)

> 陈公子招归罪于公子过而杀之。九月，楚公子弃疾帅师奉孙吴围陈，宋戴恶会之。

**说明：** “奉孙吴”是传文交代的出兵安排，不据此写成楚军已经恢复陈国独立。最后楚方如何处置陈地，见第8条。




<a id="7note-7-鲁国举行大雩"></a>
#### [[7]](#note-7) 鲁国举行大雩。

**《春秋》·昭公八年** · [固定版本原文](../../拆分史书/左传/bce-0534.md#all-20261109-j008)

> 大雩。

**说明：** 本条与本年大蒐分开，避免两个仪式被混为同一场活动。




<a id="8note-8-冬季楚军灭陈放逐公子招陈哀公的葬事也在此时办理"></a>
#### [[8]](#note-8) 冬季，楚军灭陈，放逐公子招，陈哀公的葬事也在此时办理。

**《春秋》·昭公八年** · [固定版本原文](../../拆分史书/左传/bce-0534.md#all-20261109-j009)

> 冬十月壬午，楚师灭陈。

**《春秋》·昭公八年** · [固定版本原文](../../拆分史书/左传/bce-0534.md#all-20261109-j010)

> 执陈公子招，放之於越。

**《春秋》·昭公八年** · [固定版本原文](../../拆分史书/左传/bce-0534.md#all-20261109-j011)

> 杀陈孔奂。

**《春秋》·昭公八年** · [固定版本原文](../../拆分史书/左传/bce-0534.md#all-20261109-j012)

> 葬陈哀公。

**《左传》·昭公八年** · [固定版本原文](../../拆分史书/左传/bce-0534.md#all-20261109-t008)

> 冬十一月壬午，灭陈。舆嬖袁克，杀马毁玉以葬。楚人将杀之，请寘之。既又请私，私于幄，加绖于颡而逃。使穿封戌为陈公，曰：“城麇之役，不谄。”侍饮酒于王。王曰：“城麇之役，女知寡人之及此，女其辟寡人乎？”对曰：“若知君之及此，臣必致死礼，以息楚国。”晋侯问于史赵曰：“陈其遂亡乎？”对曰：“未也。”公曰：“何故？”对曰：“陈，颛顼之族也。岁在鹑火，是以卒灭，陈将如之。今在析木之津，犹将复由。且陈氏得政于齐，而后陈卒亡。自幕至于瞽瞍，无违命。舜重之以明德，寘德于遂，遂世守之。及胡公不淫，故周赐之姓，使祀虞帝。臣闻盛德必百世祀，虞之世数未也。继守将在齐，其兆既存矣。”

**说明：** 灭陈月份经作“十月”，传作“十一月”，干支同为壬午；正文只写冬季，两说在此保留。史赵关于陈将复、陈氏将得政于齐的说法是预述，不能在本年添加陈复国事件。《鲁周公世家》八年章华台记载已与七年出返年条合并，详见上一年同号史料。

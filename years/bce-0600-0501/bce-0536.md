<a id="本年纪事"></a>
<a id="event-1"></a>

1. **正月杞文公去世，鲁国分别办理杞、秦两国的吊葬往来。** 杞国国君益姑去世，谥为文公。鲁国按同盟国家的礼数致吊，并派大夫赴秦参加秦景公的葬事。到夏季，年条又记下杞文公的安葬。两位国君死亡、下葬的年份不完全相同，秦景公之死已经记在上一年。 [[1]](#note-1)

<a id="event-2"></a>

2. **三月，郑国铸刑书，子产与叔向就公布刑法发生争论。** 郑国把刑法铸成可见的文字。叔向写信反对，担心民众此后援引条文争讼，而不再服从以礼制、身份和官长裁断维持的秩序，还可能引出更多诉讼和贿赂。子产没有接受劝止，回信说明自己着眼于应付当前问题，并感谢对方提醒。这里既有公开规则的行动，也有当时对它的反对意见。 [[2]](#note-2)

<a id="event-3"></a>

3. **季武子到晋国致谢获得莒田，并辞谢额外礼数。** 季孙宿赴晋，为莒田之事致谢。晋国宴请时增加了笾豆，季武子却通过行人说明，鲁国事奉大国，只求免于责讨，不敢越过本分接受超额待遇。他坚持撤去加设部分后才完成礼仪。晋方称许其辞让，又增加了赠物。 [[3]](#note-3)

<a id="event-4"></a>

4. **宋国寺人柳伪造盟誓痕迹，华合比被逐，华亥接任右师。** 太子佐厌恶受宠的寺人柳，华合比表示愿意杀柳。柳得知后，在坑里埋入牺牲和盟书，再向宋君报告，说华合比已经结盟，要接纳在外的旧族。宋君派人查看，见到预先布置的痕迹，便放逐华合比。华亥想取代其右师职位，又附和指控，终于接任；华合比逃往卫国。 [[4]](#note-4)

<a id="event-5"></a>

5. **六月，郑国发生火灾。** 六月丙戌，郑国失火。传文在此给出的是灾害及干支日期，没有交代火起何处、房屋损失或人员伤亡。前面士文伯曾把铸刑书与将来的火灾相联系，但那只是当时的一种解释，不能代替起火原因的证据。 [[5]](#note-5)

<a id="event-6"></a>

6. **楚公子弃疾回聘晋国，途经郑国时约束随从。** 楚公子弃疾赴晋，回报韩起此前的聘问。郑伯与子皮、子产、游吉在途中慰劳，他按相应礼序分别致礼，还禁止随从践踏田地、砍树、取屋材或强索物资。晋君原想报复楚国先前不迎晋使，也不迎弃疾，叔向劝他不要照做对方的失礼，晋君才安排接待。 [[6]](#note-6)

<a id="event-7"></a>

7. **九月，鲁国因旱举行大雩。** 鲁国遭遇旱情，九月举行大雩祈雨。与有些年份只记仪式不同，这一年传文明说原因为旱。史料没有进一步给出持续时间、受灾田亩或是否随后降雨，叙事到此为止。 [[7]](#note-7)

<a id="event-8"></a>

8. **楚国由伐徐转向攻吴，在房钟战败。** 徐国使者仪楚到楚国聘问，被扣留后逃回。楚国担心徐转向吴，派薳洩攻徐，吴国出兵救援。楚令尹子荡率军攻吴，进到豫章、乾谿一带，却在房钟被吴军打败，宫厩尹弃疾被俘。子荡回国后，把责任归给薳洩，将他处死。 [[8]](#note-8)

<a id="event-9"></a>

9. **冬季，叔弓出使楚国，兼就楚军战败致问。** 鲁国派叔弓到楚国聘问，同时对楚军遭受的失败表达慰问。这次行程接着房钟之战发生，并不是鲁国参加了那场战争。 [[9]](#note-9)

<a id="event-10"></a>

10. **齐景公获晋国同意后出兵北燕，准备送燕简公复位。** 十一月，齐景公先到晋国请求讨伐北燕，晋方同意。十二月，齐军出动，目标是让流亡的燕简公回国。晏婴在出兵前后表达了不同意见，指出燕国已有国君，内部未必愿意再改立。战事的谈判和退军结果，要接着看下一年的记载。 [[10]](#note-10)

<a id="sj014-audit-0536-qin"></a>

<a id="event-11"></a>

11. **秦哀公元年。** 秦景公去世后，秦国进入哀公元年。 [[11]](#note-11)

[返回正文第6条](#event-6)

> 楚公子弃疾如晋，报韩子也。过郑，郑罕虎、公孙侨、游吉从郑伯以劳诸柤。辞不敢见。固请见之，见，如见王，以其乘马八匹私面。见子皮如上卿，以马六匹。见子产，以马四匹。见子大叔，以马二匹。禁刍牧采樵，不入田，不樵树，不采蓺，不抽屋，不强匄。誓曰：“有犯命者，君子废，小人降。”舍不为暴，主不慁宾。往来如是。郑三卿皆知其将为王也。

> 夏，季孙宿如晋。

**《左传》·昭公六年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0536.md#all-20261109-j003)

> 夏，季孙宿如晋，拜莒田也。晋侯享之，有加笾。武子退，使行人告曰：“小国之事大国也，苟免于讨，不敢求贶。得贶不过三献。今豆有加，下臣弗堪，无乃戾也。”韩宣子曰：“寡君以为驩也。”对曰：“寡君犹未敢，况下臣，君之隶也，敢闻加贶？”固请彻加而后卒事。晋人以为知礼，重其好货。

**说明：** “拜莒田”承接此前鲁莒争地，不据此另写一场本年占领。季孙宿即季武子，前后两称并用不计为两个使者。




<a id="4note-4-宋国寺人柳伪造盟誓痕迹华合比被逐华亥接任右师"></a>
#### [[4]](#note-4) 宋国寺人柳伪造盟誓痕迹，华合比被逐，华亥接任右师。

**《春秋》·昭公六年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0536.md#all-20261109-j005)

> 宋华合比出奔卫。

**《左传》·昭公六年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0536.md#all-20261109-t005)

> 宋寺人柳有宠，大子佐恶之。华合比曰：“我杀之。”柳闻之，乃坎用牲埋书，而告公曰：“合比将纳亡人之族，既盟于北郭矣。”公使视之，有焉，遂逐华合比。合比奔卫。于是华亥欲代右师，乃与寺人柳比，从为之征曰：“闻之久矣。”公使代之。见于左师，左师曰：“女夫也，必亡！女丧而宗室，于人何有？人亦于女何有？《诗》曰：‘宗子维城，毋俾城坏，毋独斯畏。’女其畏哉！”

**说明：** 经文对应的出奔见本条同号引用；向戌批评华亥破坏宗族、预言其将亡，是附在此事后的评论，不算本年华亥也已出奔。

#### [[5]](#note-5) 六月，郑国发生火灾。

**《左传》·昭公六年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0536.md#all-20261109-t006)

**说明：** 火灾独立列条，避免藏在铸刑书的评论中；本页不以先有占言、后有灾事证明占卜有效。




<a id="6note-6-楚公子弃疾回聘晋国途经郑国时约束随从"></a>
#### [[6]](#note-6) 楚公子弃疾回聘晋国，途经郑国时约束随从。

**《左传》·昭公六年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0536.md#all-20261109-t007)

> 楚公子弃疾如晋，报韩子也。过郑，郑罕虎、公孙侨、游吉从郑伯以劳诸柤。辞不敢见。固请见之，见，如见王，以其乘马八匹私面。见子皮如上卿，以马六匹。见子产，以马四匹。见子大叔，以马二匹。禁刍牧采樵，不入田，不樵树，不采蓺，不抽屋，不强匄。誓曰：“有犯命者，君子废，小人降。”舍不为暴，主不慁宾。往来如是。郑三卿皆知其将为王也。

**《左传》·昭公六年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0536.md#all-20261109-t008)

> 韩宣子之適楚也，楚人弗逆。公子弃疾及晋竟，晋侯将亦弗逆。叔向曰：“楚辟我衷，若何效辟？《诗》曰：‘尔之教矣，民胥效矣。’从我而已，焉用效人之辟？《书》曰：‘圣作则。’无宁以善人为则，而则人之辟乎？匹夫为善，民犹则之，况国君乎？”晋侯说，乃逆之。

**说明：** 这里是楚国公子弃疾。下文被吴军俘获的是另一个“宫厩尹弃疾”，不能合并为同一人。郑三卿认为公子将来会称王的评论只作传文中的预判，本页不提前记他即位。

<a id="8note-8-楚国由伐徐转向攻吴在房钟战败"></a>

**《左传》·昭公六年** · [固定版本原文](../../sources/春秋左传/有标点原文/bce-0536.md#all-20261109-t010)

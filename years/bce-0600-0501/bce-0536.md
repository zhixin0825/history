## 本年纪事

<a id="event-1"></a>

1. **正月杞文公去世，鲁国分别办理杞、秦两国的吊葬往来。**

杞国国君益姑去世，谥为文公。鲁国按同盟国家的礼数致吊，并派大夫赴秦参加秦景公的葬事。到夏季，年条又记下杞文公的安葬。两位国君死亡、下葬的年份不完全相同，秦景公之死已经记在上一年。 [1](#note-1)

<a id="event-2"></a>

2. **三月，郑国铸刑书，子产与叔向就公布刑法发生争论。**

郑国把刑法铸成可见的文字。叔向写信反对，担心民众此后援引条文争讼，而不再服从以礼制、身份和官长裁断维持的秩序，还可能引出更多诉讼和贿赂。子产没有接受劝止，回信说明自己着眼于应付当前问题，并感谢对方提醒。这里既有公开规则的行动，也有当时对它的反对意见。 [2](#note-2)

<a id="event-3"></a>

3. **季武子到晋国致谢获得莒田，并辞谢额外礼数。**

季孙宿赴晋，为莒田之事致谢。晋国宴请时增加了笾豆，季武子却通过行人说明，鲁国事奉大国，只求免于责讨，不敢越过本分接受超额待遇。他坚持撤去加设部分后才完成礼仪。晋方称许其辞让，又增加了赠物。 [3](#note-3)

<a id="event-4"></a>

4. **宋国寺人柳伪造盟誓痕迹，华合比被逐，华亥接任右师。**

太子佐厌恶受宠的寺人柳，华合比表示愿意杀柳。柳得知后，在坑里埋入牺牲和盟书，再向宋君报告，说华合比已经结盟，要接纳在外的旧族。宋君派人查看，见到预先布置的痕迹，便放逐华合比。华亥想取代其右师职位，又附和指控，终于接任；华合比逃往卫国。 [4](#note-4)

<a id="event-5"></a>

5. **六月，郑国发生火灾。**

六月丙戌，郑国失火。传文在此给出的是灾害及干支日期，没有交代火起何处、房屋损失或人员伤亡。前面士文伯曾把铸刑书与将来的火灾相联系，但那只是当时的一种解释，不能代替起火原因的证据。 [5](#note-5)

<a id="event-6"></a>

6. **楚公子弃疾回聘晋国，途经郑国时约束随从。**

楚公子弃疾赴晋，回报韩起此前的聘问。郑伯与子皮、子产、游吉在途中慰劳，他按相应礼序分别致礼，还禁止随从践踏田地、砍树、取屋材或强索物资。晋君原想报复楚国先前不迎晋使，也不迎弃疾，叔向劝他不要照做对方的失礼，晋君才安排接待。 [6](#note-6)

<a id="event-7"></a>

7. **九月，鲁国因旱举行大雩。**

鲁国遭遇旱情，九月举行大雩祈雨。与有些年份只记仪式不同，这一年传文明说原因为旱。史料没有进一步给出持续时间、受灾田亩或是否随后降雨，叙事到此为止。 [7](#note-7)

<a id="event-8"></a>

8. **楚国由伐徐转向攻吴，在房钟战败。**

徐国使者仪楚到楚国聘问，被扣留后逃回。楚国担心徐转向吴，派薳洩攻徐，吴国出兵救援。楚令尹子荡率军攻吴，进到豫章、乾谿一带，却在房钟被吴军打败，宫厩尹弃疾被俘。子荡回国后，把责任归给薳洩，将他处死。 [8](#note-8)

<a id="event-9"></a>

9. **冬季，叔弓出使楚国，兼就楚军战败致问。**

鲁国派叔弓到楚国聘问，同时对楚军遭受的失败表达慰问。这次行程接着房钟之战发生，并不是鲁国参加了那场战争。 [9](#note-9)

<a id="event-10"></a>

10. **齐景公获晋国同意后出兵北燕，准备送燕简公复位。**

十一月，齐景公先到晋国请求讨伐北燕，晋方同意。十二月，齐军出动，目标是让流亡的燕简公回国。晏婴在出兵前后表达了不同意见，指出燕国已有国君，内部未必愿意再改立。战事的谈判和退军结果，要接着看下一年的记载。 [10](#note-10)

### [[2]](#note-2) 三月，郑国铸刑书，子产与叔向就公布刑法发生争论。

**《左传》·昭公六年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0536.md#L37-L37)

> 三月，郑人铸刑书。叔向使诒子产书曰：“始吾有虞于子，今则已矣。昔先王议事以制，不为刑辟，惧民之有争心也。犹不可禁御，是故闲之以义，纠之以政，行之以礼，守之以信，奉之以仁，制为禄位以劝其从，严断刑罚以威其淫。惧其未也，故诲之以忠，耸之以行，教之以务，使之以和，临之以敬，涖之以强，断之以刚。犹求圣哲之上，明察之官，忠信之长，慈惠之师，民于是乎可任使也，而不生祸乱。民知有辟，则不忌于上，并有争心，以征于书，而徼幸以成之，弗可为矣。夏有乱政而作《禹刑》，商有乱政而作《汤刑》，周有乱政而作《九刑》，三辟之兴，皆叔世也。今吾子相郑国，作封洫，立谤政，制参辟，铸刑书，将以靖民，不亦难乎？《诗》曰：‘仪式刑文王之德，日靖四方。’又曰：‘仪刑文王，万邦作孚。’如是，何辟之有？民知争端矣，将弃礼而征于书。锥刀之末，将尽争之。乱狱滋丰，贿赂并行，终子之世，郑其败乎！肸闻之，国将亡，必多制，其此之谓乎！”复书曰：“若吾子之言。侨不才，不能及子孙，吾以救世也。既不承命，敢忘大惠？”

**《左传》·昭公六年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0536.md#L39-L39)

> 士文伯曰：“火见，郑其火乎。火未出而作火以铸刑器，藏争辟焉。火如象之，不火何为？”

**说明：** 原文记“铸刑书”“刑器”，本页不在没有进一步考证时擅定器物形状、完整条文或铸造数量，也不宣称它是世界第一部法律。士文伯由铸刑器预测火灾，属于占候解释，不是铸法导致失火的因果证据。

> 十一月，齐侯如晋，请伐北燕也。士匄相士鞅，逆诸河，礼也。晋侯许之。十二月，齐侯遂伐北燕，将纳简公。晏子曰：“不入。燕有君矣，民不贰。吾君贿，左右谄谀，作大事不以信，未尝可也。”

**说明：** 晏婴对能否复位的判断作为当时意见保留，不替本项目作预测。经文只写伐燕，传文补出请晋与纳简公的目标，不能把目标直接写成完成。

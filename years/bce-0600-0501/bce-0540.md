# 公元前540年（鲁昭公二年）

## 本年纪事

<a id="event-1"></a>

1. **春季，晋国新执政韩起来鲁通报任职，参观鲁国典籍。**

韩起又称韩宣子，这次来聘兼有告知自己执政的意思。他到鲁国太史处看到《易象》和《鲁春秋》，赞叹当地保存的周礼文献。昭公设享礼，季武子再设宴，双方借《绵》《角弓》等诗篇表达往来之意。季氏庭中的树木又成为谈论保存旧好的一层话题。 [1](#note-1)

<a id="event-2"></a>

2. **晋齐商议婚事，送亲的陈无宇却被晋国扣留。**

韩起离鲁后到齐国纳币，又访问卫国。夏四月，晋国派韩须迎亲，齐国由陈无宇送少姜入晋。晋方认为陈无宇不够卿的等级，把他拘在中都。少姜出面解释，齐国让相应身份的人送亲，正是依照晋国迎亲者的等级办事，不应因此怪罪送使。陈无宇并没有立即获释。 [2](#note-2)

<a id="event-3"></a>

3. **叔弓赴晋答聘，婉辞超过自己使命所需的接待。**

鲁国派叔弓到晋国回报韩起之聘。晋方准备在郊外慰劳，又为他安排较大的馆舍，叔弓逐项辞谢，说明自己的任务是续好，办成国事便已足够，不敢把个人宾客待遇放在前面。叔向把这番答辞理解为先国后己、谦让守礼。 [3](#note-3)

<a id="event-4"></a>

4. **郑国追究公孙黑三项旧罪，命他自尽。**

公孙黑想排除游氏、取代其位置，但计划因伤病而未能实施。子产从外地赶回，遣官员列出他擅攻伯有、与同族争婚、在盟会上逾越君位三项罪名，要求他自尽，否则就正式施刑。公孙黑求缓，又请求替儿子印安排官职，子产都没有答应。七月壬寅，公孙黑自缢，尸体陈列于街衢。 [4](#note-4)

<a id="event-5"></a>

5. **冬季，昭公赴晋吊少姜，到了黄河便被劝回。**

少姜去世后，昭公亲自赴晋，走到黄河边。晋平公派士文伯辞谢，理由是少姜并非正式配偶，不敢劳动鲁君亲来。昭公于是返回，改由季孙宿把丧服等吊丧礼物送去。叔向又借此替先前被拘的陈无宇申辩，指出齐方送亲的等级并无相应罪过；十月，陈无宇得以回国，十一月郑国也派印段来吊。 [5](#note-5)

<a id="event-6"></a>
<a id="sj014-0540-chu-ling"></a>

6. **楚灵王围从本年开始以元年纪年。** 前一年楚公子围杀郏敖而自立为王；本年是《十二诸侯年表》所列楚灵王的元年，并非又发生一次夺位。 [6](#note-6)

<a id="note-1"></a>

### [[1]](#note-1) 春季，晋国新执政韩起来鲁通报任职，参观鲁国典籍。

**《春秋》·昭公二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0540.md#L13-L13)

> 二年春，晋侯使韩起来聘。

**《左传》·昭公二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0540.md#L27-L27)

> 二年春，晋侯使韩宣子来聘，且告为政而来见，礼也。观书于大史氏，见《易象》与《鲁春秋》，曰：“周礼尽在鲁矣。吾乃今知周公之德，与周之所以王也。”公享之。季武子赋《绵》之卒章。韩子赋《角弓》。季武子拜曰：“敢拜子之弥缝敝邑，寡君有望矣。”武子赋《节》之卒章。既享，宴于季氏，有嘉树焉，宣子誉之。武子曰：“宿敢不封殖此树，以无忘《角弓》。”遂赋《甘棠》。宣子曰：“起不堪也，无以及召公。”

**说明：** 这里的《鲁春秋》是韩起所见鲁国史籍的称名，不能据此直接认定就是后世流传版本的《春秋》。引语“周礼尽在鲁矣”属于韩起的感叹。


<a id="note-2"></a>

### [[2]](#note-2) 晋齐商议婚事，送亲的陈无宇却被晋国扣留。

**《左传》·昭公二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0540.md#L29-L29)

> 宣子遂如齐纳币。见子雅。子雅召子旗，使见宣子。宣子曰：“非保家之主也，不臣。”见子尾。子尾见彊。宣子谓之如子旗。大夫多笑之。唯晏子信之，曰：“夫子，君子也。君子有信，其有以知之矣。”自齐聘于卫。卫侯享之，北宫文子赋《淇澳》。宣子赋《木瓜》。

**《左传》·昭公二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0540.md#L31-L31)

> 夏四月，韩须如齐逆女。齐陈无宇送女，致少姜。少姜有宠于晋侯，晋侯谓之少齐。谓陈无宇非卿，执诸中都。少姜为之请曰：“送从逆班，畏大国也，犹有所易，是以乱作。”

**说明：** 韩起对子旗、高彊日后能否守家的评论，以及晏子的应答，保留在原文而不作本项目的人物能力判断。陈无宇获释与少姜去世后的交涉相连，见第5条。


<a id="note-3"></a>

### [[3]](#note-3) 叔弓赴晋答聘，婉辞超过自己使命所需的接待。

**《春秋》·昭公二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0540.md#L15-L15)

> 夏，叔弓如晋。

**《左传》·昭公二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0540.md#L33-L33)

> 叔弓聘于晋，报宣子也。晋侯使郊劳。辞曰：“寡君使弓来继旧好，固曰：‘女无敢为宾！’彻命于执事，敝邑弘矣，敢辱郊使？请辞。”致馆。辞曰：“寡君命下臣来继旧好，好合使成，臣之禄也。敢辱大馆？”叔向曰：“子叔子知礼哉！吾闻之曰：‘忠信，礼之器也。卑让，礼之宗也。’辞不忘国，忠信也。先国后己，卑让也。《诗》曰：‘敬慎威仪，以近有德。’夫子近德矣。”

**说明：** 叔向的赞语与使者实际辞让分开；本条没有补写晋国因此给予鲁国何种未载的利益。


<a id="note-4"></a>

### [[4]](#note-4) 郑国追究公孙黑三项旧罪，命他自尽。

**《春秋》·昭公二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0540.md#L17-L17)

> 秋，郑杀其大夫公孙黑。

**《左传》·昭公二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0540.md#L35-L35)

> 秋，郑公孙黑将作乱，欲去游氏而代其位，伤疾作而不果。驷氏与诸大夫欲杀之。子产在鄙闻之，惧弗及，乘遽而至。使吏数之曰：“伯有之乱，以大国之事，而未尔讨也。尔有乱心，无厌，国不女堪。专伐伯有，而罪一也。昆弟争室，而罪二也。薰隧之盟，女矫君位，而罪三也。有死罪三，何以堪之？不速死，大刑将至。”再拜稽首辞曰：“死在朝夕，无助天为虐。”子产曰：“人谁不死。凶人不终，命也。作凶事，为凶人。不助天，其助凶人乎？”请以印为褚师。子产曰：“印也若才，君将任之。不才，将朝夕从女。女罪之不恤，而又何请焉？不速死，司寇将至。”七月壬寅，缢。尸诸周氏之衢，加木焉。

**说明：** “三项罪名”是子产在传文中所列的指控，不改写成现代司法结论。上一年争婚事件的公孙黑与本条为同一人。


<a id="note-5"></a>

### [[5]](#note-5) 冬季，昭公赴晋吊少姜，到了黄河便被劝回。

**《春秋》·昭公二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0540.md#L19-L19)

> 冬，公如晋，至河乃复。

**《春秋》·昭公二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0540.md#L21-L21)

> 季孙宿如晋。

**《左传》·昭公二年** · [固定版本原文](https://github.com/zhixin0825/history/blob/ee3959bcc3fd321dc5fa9d316ebb6d3526533305/working-texts/zuozhuan-punctuated-years/years/bce-0540.md#L37-L37)

> 晋少姜卒。公如晋，及河。晋侯使士文伯来辞曰：“非伉俪也。请君无辱！”公还，季孙宿遂致服焉。叔向言陈无宇于晋侯曰：“彼何罪？君使公族逆之，齐使上大夫送之。犹曰不共，君求以贪。国则不共，而执其使。君刑已颇，何以为盟主？且少姜有辞。”冬十月，陈无宇归。十一月，郑印段如晋吊。

**《史记·鲁周公世家》·本篇三年：至河而返** · [所核网页固定版本](https://zh.wikisource.org/w/index.php?title=史記/魯周公世家&oldid=7909289)

> 昭公三年，朝晉至河，晉平公謝還之，魯恥焉。

**说明：** 《鲁周公世家》作“三年，朝晋至河”，经传放在二年冬，并有少姜之丧、致服、释使的上下文。本批暂按经传明确年条编排，三年页只设交叉指引，不把两书拼成两次出行。“鲁耻焉”是《史记》的记述；正文先说明传文所载婉拒理由。本批未完成现代整理本的独立纪年校勘，不称这是已证实的学界多数意见。

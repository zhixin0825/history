<a id="本年纪事"></a>
<a id="event-1"></a>

1. **春，叔孙豹从会盟回来，劝鲁国提前安排与晋国卿族的关系。** 他分别向孟孝伯、季武子谈起赵武及晋国政局，担心晋公室衰弱后，掌权卿族会向鲁国提出更多索求，主张预先结交韩氏。孟、季没有接受这一建议。 [[1]](#note-1)

<a id="event-2"></a>

2. **齐国子尾先使闾丘婴攻鲁阳州，又杀闾丘婴以向鲁军交代。** 鲁国询问齐军出动的原因。五月，子尾杀了闾丘婴；工偻洒、渻竈、孔虺、贾寅随后逃往莒国，若干公子也被驱逐。边境军事与齐国内部排挤在这件事中相互牵连。 [[2]](#note-2)

<a id="event-3"></a>

3. **鲁襄公仿照楚国建宫，六月辛巳死在楚宫，鲁国先立子野。** 叔孙豹曾以《大誓》说明自己对营建楚宫的看法。襄公死后，叔仲带取走其拱璧，借御人藏在怀中再取回，因而获罪。鲁国先拥立敬归所生的子野，让他住在季氏处。 [[3]](#note-3)

<a id="event-4"></a>

4. **六月，子产随郑君赴晋，因车马与礼物无处安置，拆开了晋国客馆围墙。** 晋侯以鲁国国丧为由暂缓接见，郑国使团又不能未觐见就交出礼物。馆门小得容不下车，礼物露放还会受燥湿损坏，子产于是让人拆墙纳入。士文伯责问这会破坏宾客防盗，子产便对比晋文公接待诸侯的旧制：盟主应使宾客有宿处、车马有库厩、道路有人修治，不能只扩大自己的宫室，却让小国使者住进仆役般的窄馆。 [[4]](#note-4)

<a id="event-5"></a>

5. **晋国承认待客有失，向郑国道歉，并重建诸侯馆舍。** 士文伯复命后，赵武承认用狭窄馆墙困住诸侯是晋方过失，让使者致歉。晋侯加礼接见郑君，宴享、赠礼也加厚，随后修建诸侯馆舍。叔向以这次交涉说明，清楚表达道理对诸侯往来具有实际作用。 [[5]](#note-5)

<a id="event-6"></a>

6. **郑子皮派印段到楚国，说明郑君已经到晋国。** 宋地弭兵以后，小国仍需要向晋、楚两方说明外交往来。印段的这次告知与子产陪郑君赴晋相关，但不是同一使团，也不省成“郑同时朝晋楚”而抹去执行者。 [[6]](#note-6)

<a id="event-7"></a>

7. **九月，子野因哀毁去世，随后仲孙羯也去世。** 子野在襄公死后短暂被立，尚未开始另一个完整纪年，九月癸巳便死去；己亥，孟孝伯仲孙羯也卒。原文以“毁”解释子野之死，保留丧事中的哀毁说法，不增加具体医学病因。 [[7]](#note-7)

<a id="event-8"></a>

8. **季武子不听叔孙豹反对，改立公子裯，成为后来的鲁昭公。** 公子裯是敬归之妹齐归所生。叔孙豹质疑不按既有继承次序择人，又以他居丧时的表现提出反对；季武子仍立了他。到襄公下葬前，公子裯几次更换丧服，传文用这些举动继续解释对这项选择的忧虑。 [[8]](#note-8)

<a id="event-9"></a>

9. **冬十月，滕成公来参加葬礼，癸酉安葬鲁襄公。** 国君去世、子野短暂被立、再立公子裯以后，襄公的葬礼在十月举行。滕国国君亲来会葬，鲁人对子服惠伯评论其举止的话另作记录。 [[9]](#note-9)

<a id="event-10"></a>

10. **十一月，莒国展舆联合国人杀死国君，自立，去疾逃往齐国。** 莒君先把展舆立为继承人，后来又废掉，父子之间留下争端；国人又不满国君的作为，展舆便借其力量发动攻击。另一子去疾逃往齐国，其母出于齐；展舆的母亲则出于吴。 [[10]](#note-10)

<a id="event-11"></a>

11. **吴国派屈狐庸赴晋，赵武询问季札会不会继位。** 赵武提到诸樊死于巢、余祭被阍人杀害，问接连变故是否会使季札受国。屈狐庸回答，季札守其不受国的主张，不会因此继立，又把希望寄于吴国当时的嗣君。 [[11]](#note-11)

<a id="event-12"></a>

12. **十二月，卫襄公赴楚，经过郑国时受到按礼安排的迎劳。** 北宫文子陪同卫君出行。郑印段在棐林迎候，以聘礼的规格、慰劳的言辞接待；子羽负责外交辞令，冯简子、子太叔迎客。北宫文子完成聘问后，向卫侯称许郑国的礼节安排。 [[12]](#note-12)

<a id="event-13"></a>

13. **子产执政期间按所长分工，筹划外交不由一个人包办。** 遇到诸侯事务，先问熟悉各国与大夫情况的子羽，让他准备辞令；再同裨谌到郊外商议可否，交冯简子作决定，最后由子太叔带着定好的方案应对宾客。传文把这种做法接在本年接待卫使的叙事后，用来解释郑国办事的程序。 [[13]](#note-13)

<a id="event-14"></a>

14. **执政期间，子产不肯拆掉议论政事的乡校，愿把批评当成改错的依据。** 然明建议毁掉国人闲暇议论执政的场所，子产反问为什么要毁。他说，人们赞成的可以做，反对的可以改，这正是自己的老师；强行压住怨言像堵水，暂时止住后若大决，受害更大，不如留出通道，听到意见再补救。然明因而表示信服。 [[14]](#note-14)

<a id="event-15"></a>

15. **子皮曾想让年轻的尹何管理邑，子产劝他先学会办事，不能拿政务试手。** 子皮看重尹何厚道、不会背弃自己，想让他边任职边学习。子产以不会用刀却叫他割物、拿珍贵锦缎学裁为比：邑中百姓和承担的责任，比自家的好衣料更不能随便交给学徒。子皮接受劝告，表示连自己家事也愿听子产的意见。 [[15]](#note-15)

<a id="event-16"></a>

16. **卫君到楚以后，北宫文子与他讨论令尹围的礼仪和君臣界限。** 北宫文子看到公子围举止如国君，担心他别有图谋。卫侯追问何谓威仪，他便区分君主、臣属及其他关系中应有的举止：上位者的言行应可敬、可亲、可效法，才能维系相互关系，而不只是让人害怕。 [[16]](#note-16)

<a id="sj014-audit-0542-cai"></a>

<a id="event-17"></a>

17. **蔡灵侯班元年。** 太子般已在上一年弑父自立，本年按年表开始灵侯纪年。 [[17]](#note-17)

#### 16. 卫君到楚以后，北宫文子与他讨论令尹围的礼仪和君臣界限

**说明：**原段从《诗》《周书》引文到文王囚羑里、伐崇等故事，是谈话中用以论证的旧例，不能把商周事改编成本年。关于围将得志又不能终的断语只是北宫文子的判断。君臣“威仪”的具体排比全文留在对应原文。

<details>
<summary>《左传》传 T018｜原文</summary>

> 卫侯在楚，北宫文子见令尹围之威仪，言于卫侯曰：“令尹似君矣！将有他志。虽获其志，不能终也。《诗》云：‘靡不有初，鲜克有终。’终之实难，令尹其将不免？”公曰：“子何以知之？”对曰：“《诗》云：‘敬慎威仪，惟民之则。’令尹无威仪，民无则焉。民所不则，以在民上，不可以终。”公曰：“善哉！何谓威仪？”对曰：“有威而可畏谓之威，有仪而可象谓之仪。君有君之威仪，其臣畏而爱之，则而象之，故能有其国家，令闻长世。臣有臣之威仪，其下畏而爱之，故能守其官职，保族宜家。顺是以下皆如是，是以上下能相固也。《卫诗》曰：‘威仪棣棣，不可选也。’言君臣、上下、父子、兄弟、内外、大小皆有威仪也。《周诗》曰：‘朋友攸摄，摄以威仪。’言朋友之道，必相教训以威仪也。《周书》数文王之德曰：‘大国畏其力，小国怀其德。’言畏而爱之也。《诗》云：‘不识不知，顺帝之则。’言则而象之也。纣囚文王七年，诸侯皆从之囚。纣于是乎惧而归之。可谓爱之。文王伐崇，再驾而降为臣，蛮夷帅服。可谓畏之。文王之功，天下诵而歌舞之。可谓则之。文王之行，至今为法。可谓象之。有威仪也。故君子在位可畏，施舍可爱，进退可度，周旋可则，容止可观，作事可法，德行可象，声气可乐，动作有文，言语有章，以临其下，谓之有威仪也。”

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **春，楚国派薳罢来鲁聘问，接续新君即位后的邦交。** 叔孙豹询问王子围掌政的情形，薳罢以自己只管奉命办事为由，不肯谈论。叔孙豹一再问仍得不到回答，遂向鲁国大夫表示担忧。 [[1]](#note-1)

<a id="event-2"></a>

2. **子产随郑君到晋国，告诉叔向驷、良两家的争端尚未化解。** 叔向以为郑国大夫已经和解，子产则说伯有与子晳都不能彼此退让，表面的盟誓之下仍在累积怨恨。同年夏四月，郑君与大夫又结盟，后来的内乱仍没有被避免。 [[2]](#note-2)

<a id="event-3"></a>

3. **二月，晋国一名参加筑杞城的老役夫受赏，朝廷由他的记忆推算年龄，并追究仍令其服役的责任。** 老人自述所经历的甲子数，不知道年龄。师旷用鲁晋交往、狄伐鲁等旧事比对，史赵、士文伯又核计日数，认定他已七十三岁。赵武听说老人属于自己辖县，向他道歉，给田并安排职任，又撤免原先负责役使他的舆尉。鲁使把事情带回本国，季武子因而劝人不可轻忽晋国。 [[3]](#note-3)

<a id="event-4"></a>

4. **夏四月，蔡国太子般杀死父亲蔡景公；冬十月安葬景公。** 蔡景公为太子从楚国娶妻，又与其儿媳私通，父子冲突由此发展到弑君。经文将行刺者明确写为世子般，冬季再记景公葬礼。 [[4]](#note-4)

<a id="event-5"></a>

5. **五月，王子佞夫被杀，儋括、王子瑕等逃往晋国。** 周灵王死后，儋括想拥立佞夫，佞夫本人却不知道这项谋划。儋括先出兵驱逐成愆，随后尹言多、刘毅等杀了佞夫。儋括、瑕、廖逃到晋国。经文把责任归于天王，并不表示动手者就是天王本人。 [[5]](#note-5)

<a id="event-6"></a>

6. **五月，宋国发生大火，伯姬死于火中；秋七月鲁国派叔弓参加葬礼。** 伯姬在危急中仍等待女傅相随，因此没有及时离开。鲁国随后派叔弓前往安葬这位出嫁到宋的公室女子。火灾、死亡和出使葬礼分别保留日期，不把后来的救灾盟会提前放到火起当天。 [[6]](#note-6)

<a id="event-7"></a>

7. **六月，子产到陈国监督盟誓，回来后对陈国政事提出担忧。** 他认为陈国虽聚粮、修城，却没有顾及民众，各公子、大夫又各行其政；作为夹在大国之间的小国，依靠城墙和积粟还不够。子产把这些看法作为复命的一部分告诉郑国大夫。 [[7]](#note-7)

<a id="event-8"></a>

8. **郑国伯有夜饮不理朝事，再次强派子晳使楚，终于遭驷氏攻焚而出奔许国。** 伯有在地下窟室饮酒、敲钟，来见他的官员得不到接待。一次朝会后，他仍要子晳去楚，子晳便调集驷氏甲兵攻其家并纵火。伯有先逃到雍梁，酒醒后才知道变乱的经过，接着逃往许国。 [[8]](#note-8)

<a id="event-9"></a>

9. **子产不肯依附内斗中的强者，先为伯有家死者收殓，子皮劝他留下。** 有人劝子产选择自称正直而强大的一方，子产没有加入。他为死者收殓后准备离开，印段跟随。子皮认为连死者都能按礼相待的人更不应赶走，于是把他留下；子产等随后接受新的盟誓。 [[9]](#note-9)

<a id="event-10"></a>

10. **伯有误以为子皮会帮助自己，潜回郑国武装反攻，最终死在羊市。** 伯有得知子皮的甲兵未参加攻他，便把“不攻击”当成“支持”。他清晨从墓门水道入城，到襄库取得武器，进攻旧北门；驷带率国人还击，伯有战死。子产仍把死者的头枕在自己腿上哭泣，收殓后葬在斗城。驷氏又想攻子产，被子皮阻止。 [[10]](#note-10)

<a id="event-11"></a>

11. **游吉听到郑国内乱，一度奔晋；驷带追到酸枣盟誓，才使他回国。** 游吉原本从晋返郑，得知乱事后不入城，让副使代为复命，八月又赴晋。驷带追上他，两人以玉珪为质向河盟誓，另派公孙肸先入郑同大夫结盟，游吉才再次回来。 [[11]](#note-11)

<a id="event-12"></a>

12. **伯有的随从有的同死，有的逃晋谋求伐郑，但晋方没有答应。** 仆展随伯有战死，羽颉则逃到晋国，得到任大夫之职。他与较早流亡的乐成相联，向赵武提出攻郑的建议。晋国顾及宋地弭兵之盟，没有采纳；郑国内由公孙鉏继任马师。 [[12]](#note-12)

<a id="event-13"></a>

13. **楚公子围杀死大司马蒍掩，夺取其家室。** 令尹与军政大臣之间的冲突在楚国爆发。申无宇批评公子围本应保全、任用同僚，却摧折辅佐国家与君主的人，把这件事视为危害楚国的行为。 [[13]](#note-13)

<a id="event-14"></a>

14. **冬十月，各国大夫会于澶渊商议援助宋国，答应的钱物却没有交付。** 鲁叔孙豹与晋赵武、齐公孙虿、宋向戌、卫北宫佗、郑罕虎及小邾大夫聚会，因宋灾议定输送财物。会后却没有把财物归给宋国。传文据此批评与会者失信，解释经文为什么只写某国“人”、不列卿名。 [[14]](#note-14)

<a id="event-15"></a>

15. **子皮把郑国政事交给子产，并承诺支持他约束强族。** 子产先推辞，说国家狭小而受外逼，强族多、受宠者多，很难办事。子皮回答，自己会率先听从，只要处理好与大国的关系，小国也有回旋空间。子产因此承担执政事务。 此前诸公子互相争宠相杀，一度也有人想加害子产；有公子以子产仁厚、郑赖之而存为由劝止，使他免于被害。 《循吏列传》另用大宫子期举荐及“为相”叙写；《左传》本条是子皮授政。 [[15]](#note-15)

<a id="event-16"></a>

16. **子产先安排大族的利益与职位，再着手推行自己的政令。** 他给伯石邑，子太叔不解为何特别厚待一人。子产解释，要先安定有势力者，让他们参与完成国事；伯石退还时，他仍给了。伯有死后，伯石受卿命又连续辞让，太史一退却再请命，最后领受策书，其位被放在子产之后。 [[16]](#note-16)

<a id="event-17"></a>

17. **子产整顿都鄙、服制、田界沟洫和居民编组，推行过程中发生抵抗。** 他按表现扶助忠俭者、抑制奢纵者。丰卷祭祀时请求田猎，子产没有准许，丰卷发怒并调集役众。子产一度出奔晋国，子皮制止事态，驱逐丰卷；子产仍请求保留其田里。正文在这里交代改革与冲突，不把后续几年全部压成同一年。 [[17]](#note-17)

<a id="sj014-audit-0543-wei"></a>

<a id="event-18"></a>

18. **卫襄公恶元年。** 卫国在献公去世之后由恶继位，本年开始襄公纪年。 [[18]](#note-18)

<a id="hs-event-19"></a>

19. **宋国火灾。** 《汉书》在本年记载宋国火灾。 [[19]](#hs-note-19)

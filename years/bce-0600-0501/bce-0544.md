## 本年概述

鲁襄公参与楚康王丧礼，归途中得知季武子占卞。晋主导诸侯筑杞城。吴公子季札聘鲁观周乐，又历访齐、郑、卫与晋。

1. **鲁襄公参加楚康王丧礼，楚郏敖继位。** 春正月，鲁襄公仍在楚国，为亲自给楚康王襚衣的礼节与楚人周旋。襄公不能在本国宗庙主持岁首朝礼，又被要求亲自为楚王送入丧服。叔孙豹建议让巫者先用桃枝、茢草驱除不祥，再交付襚衣，以改变这项礼节的意味。楚人起初没有阻止，事后才后悔。四月，鲁、陈、郑、许诸君参加楚康王丧礼，楚郏敖继位，王子围任令尹。四位国君送到西门外，各国大夫则送到墓地。楚的新君与掌政令尹由此确定。郑国行人子羽看到这种安排，用松柏之下草木难长作比，担忧令尹的权势会压过国君。 [[1]](#reading-note-1)

<a id="event-4"></a>

<a id="reading-event-4"></a>

2. **鲁襄公返国途中得知季武子占取卞邑，一度不愿回鲁，五月才入国。** 季武子让公冶迎候，又用盖印的书信追告，说守卞的人将要叛变，所以自己已率众讨取。公冶先奉命传话，退下后才知道实际取卞之事。襄公认为季氏想要卞邑却借口叛乱，是把自己排除在外；他问还能否回国，公冶回答国君仍有自己的国家，荣成伯又赋《式微》劝归，襄公才继续回程。 [[2]](#reading-note-4)

3. **晋召诸侯为杞筑城，又调处鲁杞田地。** 晋国召集诸侯大夫为杞筑城，鲁仲孙羯参加。晋平公的母亲出于杞，因此晋国特别照顾杞。六月，荀盈召集诸侯大夫筑城，郑国也派子太叔与伯石参加。子太叔却认为晋国不补助衰弱的姬姓诸国，专门扶助与自己有婚姻关系的杞，对盟主的取舍提出异议。晋士鞅到鲁答谢筑杞城，鲁国宴享时还要从家臣中补足射礼人选。鲁襄公设宴接待。射礼需要三耦，公室臣属人数不足，便由展氏家臣补上一耦，其余两耦由公臣组成。出使的目的与仪礼中公臣、家臣的区别一并保留。晋国调处鲁、杞田地，没有把争地全部还给杞，杞文公随后来鲁结盟。司马女叔侯认为不能只因杞与晋有亲缘，就让鲁的土地减少来扩张杞。他向晋侯说明，鲁与晋的朝聘贡纳一直往来正常。晋自身也曾兼并许多姬姓小国，无法一面沿用所得，一面要求鲁全部退让。晋悼夫人怀疑他受赂，他当面作了解释。冬，仲孙羯到晋国，回报士鞅此前的聘问。这是鲁国对晋使来聘的回访，与夏季参加城杞、晋使来谢相接，不合并成同一次出使。 [[3]](#reading-note-9)

5. **吴公子季札聘鲁观乐，遍访齐郑卫晋。** 吴公子季札到鲁聘问，并请求观看周乐。季札见到叔孙豹，赞许他的好善，同时劝他谨慎择人。鲁国随后为季札依次演唱各地国风、小雅、大雅、颂，并表演多种乐舞。季札把音乐的风格与各地风俗、先王传统联系起来。听到《韶箾》后，他说已足观止，不敢再请别的乐。各曲评语的意思见本条后表。季札继续到齐、郑，劝晏婴退还邑与政，也与子产交换礼物。在齐国，季札认为政权争夺尚未停息，劝晏婴尽快交出邑和政事。晏婴通过陈桓子交还。到郑以后，季札与子产相见如故，以缟带相赠，子产回赠纻衣。季札又劝子产将来承担政事时谨守礼制。季札告诫子产，郑国当权者奢侈，祸难将至，国政恐怕将落到他手里。到时必须以礼治理，否则郑会败。子产以厚礼相待。季札经卫赴晋，在戚听到钟声后改变了住宿安排。在卫国，季札与蘧瑗等人交往。前往晋国途中本想住在戚，听见钟声，却认为当地主人曾获罪于君，卫国先君又尚未安葬，此时作乐并不合宜，于是离开。到晋以后，他与赵武（赵文子）、韩起（韩宣子）、魏舒（魏献子）交谈，认为晋国政治将渐归这三家。又提醒叔向留意卿族势力增长带来的风险。当时三家尚未受周王正式封侯。季札过徐，将佩剑挂在徐君墓上。季札出使北方，途经徐国，徐君喜欢他的佩剑。季札尚须佩剑继续出使，经过时没有相赠。返程得知徐君已死，他将剑挂在墓旁的树上，说自己心中早已许诺。 [[5]](#reading-note-12)

6. **二月，齐国将齐庄公安葬于北郭。** 这次安葬延续此前崔氏之乱以后的丧事处理，并不是齐庄公到本年才被杀。经传前后的埋葬、迁殡和安葬，保留各自的动作与年代。 [[6]](#reading-note-2)

7. **周灵王安葬，郑国派印段前往，不能因上卿有事就缺席王室丧礼。** 子展派印段时，伯有认为他力量不足，不宜出使。子展则说，与其无人前往，派资望较弱的人也好；平日努力应付晋、楚，本意也在屏护王室，不能反而把王事空下来。最后印段成行。 [[7]](#reading-note-5)

8. **夏五月卫献公去世，九月安葬。** 经文用名字衎记载卫献公之死，秋季再记其葬礼。国君死亡与安葬是两项不同时间的丧事，合在同一条说明，不漏掉其中一项。 [[8]](#reading-note-6)

9. **郑、宋发生饥荒，子皮继父职后散粮，宋国子罕推动公粮和大夫借粮救济。** 郑子展去世，子皮接掌其职。当时新麦未熟，子皮按父亲遗命给国人每户一钟粟。宋国也缺粮，子罕听说后，请宋平公拿出公粟贷给民众，并让大夫一起出粮。子罕所属的乐氏借出粮食不登记偿还账目，又替没有粮食的大夫出粮。 [[9]](#reading-note-8)

10. **九月，齐国将高止放逐到北燕；高竖随后据卢反抗，议定保存高氏后裔才交城。** 公孙虿、公孙竈把高止驱逐，高竖因此据卢。十月，齐军围卢；高竖提出，只要高氏仍有后人继立，就愿交出城邑。齐人于是立高敬仲的曾孙酀。十一月，高竖交卢出奔晋国，晋人为他筑绵安置。 [[10]](#reading-note-16)

11. **郑伯有强迫公孙黑出使楚国，两家险些动兵，十二月再次会盟。** 公孙黑认为楚、郑正交恶，派自己前去可能送命；伯有则以其家世代承担这类差事为由，坚持派遣。公孙黑发怒，准备攻伯有氏，大夫居中劝止，双方才在伯有家中盟誓。裨谌担心这只是积怨未除时的再盟，并未解决争端。 [[11]](#reading-note-18)

以下都是季札在传文中的看法，不是本编年史对国家或人物所作的优劣排序。歌诗与乐舞按原叙事先后列出，未给郐以下补造评语。

| 歌诗或乐舞 | 季札的评语大意 |
|---|---|
| 周南、召南 | 季札认为这两组音乐表现了周王业初起的勤劳，尚未完全成就，却没有怨恨。 |
| 邶、鄘、卫 | 他听到深远的忧思而非窘迫，将它联系到康叔、武公留给卫地的传统。 |
| 王 | 他认为其中有思虑而不畏惧，把这种声音同周室东迁联系起来。 |
| 郑 | 他觉得声音过细，担心郑民难以承受政事；这是听乐后的判断，不是本年郑国已经亡国。 |
| 齐 | 他称其气象开阔，联想到太公经营东海一带的传统。 |
| 豳 | 他听到舒展而有节制的欢乐，联系到周公东征。 |
| 秦 | 他把秦乐称作夏声，联系到周的旧地；这里是古人的音乐与地理说法。 |
| 魏 | 他认为大而婉、险而易，进而谈到以德辅乐、成为明主的条件。 |
| 唐 | 他听到深远的忧思，联系到陶唐氏留下的风俗，强调没有这样的传统便难有这种声音。 |
| 陈 | 他从乐声发问陈国是否缺少主持者，属于当时的政治评论。 |
| 郐以下 | 原文明确说季札没有再作讥评；不能替这些曲目逐首补写评语。 |
| 小雅 | 他认为其中有忧思而不怀二心、有怨而不明说，把它联系到周室衰时的遗民。 |
| 大雅 | 他从乐声中听出广阔与明朗，认为虽有曲折却以正直为本，联系到文王之德。 |
| 颂 | 他逐项谈直而不倨、曲而不屈、近而不逼、远而不离等相反而相济的特点，并说明五声、八风、节度与次序协调。 |
| 象箾、南籥 | 季札称其美，但认为还有遗憾。此处开始转入观看乐舞，不与此前的歌诗混成一类。 |
| 大武 | 他将其与周盛时的乐舞传统相联系。 |
| 韶濩 | 他把其中的弘大与惭德并举，并感叹为圣人不易。 |
| 大夏 | 他联想到禹勤劳而不自居其功，认为这样的乐舞是禹的传统。 |
| 韶箾 | 他用天地覆载作比，认为已经足观止，不敢再请别的乐；这里只转述季札的反应，不把它当作编者给国家或人物排序。 |

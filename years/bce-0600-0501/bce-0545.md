<a id="本年纪事"></a>
<a id="event-1"></a>

1. **春，鲁国无冰。** 梓慎据此结合星次，担忧宋、郑将有饥荒。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，齐、陈、蔡、燕、杞、胡、沈及白狄朝晋，落实宋盟。** 庆封曾劝齐侯不必去，陈文子认为即使齐国没有参加同一形式的盟誓，也不能忘记与晋国已有的约定，齐侯遂行。 [[2]](#note-2)

<a id="event-3"></a>

3. **卫国清理甯氏党羽，石恶逃晋。** 卫国另立石恶的族侄圃，继续奉祀石氏。 [[3]](#note-3)

<a id="event-4"></a>

4. **邾悼公来鲁朝见。** [[4]](#note-4)

<a id="event-5"></a>

5. **秋八月，鲁国因旱举行大雩。** [[5]](#note-5)

<a id="event-6"></a>

6. **蔡侯过郑两度怠慢礼遇，子产担心蔡国内部将出大乱。** 蔡侯赴晋、返国时都受郑国接待，却始终傲慢。子产由其对外失礼和对内家庭关系，判断祸患可能来自其子。 [[6]](#note-6)

<a id="event-7"></a>

7. **仲孙羯赴晋，预告鲁襄公将按宋盟赴楚。** [[7]](#note-7)

<a id="event-8"></a>

8. **楚国拒绝只接受郑国使臣，要求郑君亲自来朝。** 游吉行至汉水被遣回，指出弭兵原为安小国，不该再强迫国君冒寒露、离封守。回国后，他仍劝郑伯前行，以便尽快完成义务、让百姓休息。 [[8]](#note-8)

<a id="event-9"></a>

9. **郑伯赴楚，子产不肯为驻地大筑坛场。** 子产解释，大国到小国施惠可以筑坛表功，小国到大国多为谢罪、补贡、听命，没有必要把这些困苦再公开夸示给后人。 [[9]](#note-9)

<a id="event-10"></a>

10. **齐庆封沉迷田猎饮酒，把政务交给儿子庆舍。** 他又放回愿意为自己报仇的流亡者。卢蒲癸、王何因此进入庆氏，受信任而持兵护卫，却暗中谋划攻击庆家。 [[10]](#note-10)

<a id="event-11"></a>

11. **齐国其他卿族与庆氏的矛盾日益加深。** 国君膳食被擅换引起子雅、子尾不满，庆封一方又轻视对手。晏婴、北郭佐都不肯替庆氏出谋，陈氏则开始准备。 [[11]](#note-11)

<a id="event-12"></a>

12. **冬，庆封在莱田猎时，庆舍在太公庙祭礼中被杀。** 卢蒲癸、王何设谋，陈、鲍等人用表演引开庆氏甲士，再以其甲武装其他党众。庆舍不听女儿劝阻，仍入庙主持祭祀，终于遭到袭击。 [[12]](#note-12)

<a id="event-13"></a>

13. **庆封返齐反攻失败，先逃鲁，随后又逃吴。** 他在齐国攻内宫不克，到鲁国献华车求容。齐人来责问后，他转赴吴国，获朱方居住，宗族又聚集起来。 [[13]](#note-13)

<a id="event-14"></a>

14. **齐国召回流亡公子，晏婴拒绝借庆氏之败扩大封邑。** 晏婴认为财富必须有界，过多会招人争夺；子雅辞多受少，子尾也陆续归还所得，以免重蹈庆氏之覆辙。 [[14]](#note-14)

<a id="event-15"></a>

15. **齐人追究崔杼身后，又重新为庄公安置丧事。** 卢蒲嫳被逐到北境，崔氏旧臣交出崔杼棺柩。十二月，齐国把庄公迁殡大寝，并公开羞辱崔杼遗体。 [[15]](#note-15)

<a id="event-16"></a>

16. **十一月，诸侯赴楚途中遇楚康王去世，鲁宋作出不同选择。** 鲁襄公与宋、陈、郑、许等君主本往会楚；鲁君到了汉水想返回，叔仲昭伯劝此行为楚国而非只为一人，他遂继续前进。宋公却从向戌意见，先返休息，待楚立君再议。康王在位十五年，子员承位，为郏敖，经传写名麇，次年开始新君纪元。 [[16]](#note-16)

<a id="event-17"></a>

17. **周灵王去世，王室后来报丧的日期与传文所记不同。** 王子贵继位，是为景王。 [卷四互见与归年](#sj004-545-1) [[17]](#note-17)

<a id="event-18"></a>

18. **楚令尹屈建去世，赵武按同盟之礼为他服丧。** [[18]](#note-18)

<a id="event-19"></a>

19. **燕懿公在位四年后去世，燕惠公继立。** 本年依《十二诸侯年表》记懿公去世及承继，惠公的正式元年另见下一年，不能提前改元。 [[19]](#note-19)

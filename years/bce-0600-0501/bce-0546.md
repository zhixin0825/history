<a id="本年纪事"></a>
<a id="event-1"></a>

1. **春，晋使胥梁带不用大军，拘住乌馀并归还诸侯失地。** 他让失地各国备车徒接收土地，又让乌馀以为自己将获新封，率众出来接受。各方配合将其拘获，所占城邑全部退还，诸侯因此更愿亲晋。 [[1]](#note-1)

<a id="event-2"></a>

2. **齐庆封来鲁聘问，车服华美，却不懂宴礼。** 叔孙豹以礼劝讽，庆封仍没有领会。 [[2]](#note-2)

<a id="event-3"></a>

3. **卫献公不满甯喜专政，公孙免馀再攻甯氏，杀甯喜和右宰穀。** 第一次袭击失败，参与者皆死；第二次终于成功。石恶正要赴宋盟，见两人尸体在朝，替他们覆衣、枕尸而哭，但因已经受使臣之命，只能离去。 [[3]](#note-3)

<a id="event-4"></a>

4. **子鲜认为卫君背信，逃往晋国，终身不再做官。** 他曾担保献公复国时的承诺，如今逐君者在外、迎君者被杀，使他无从自处。献公屡次派人挽留，子鲜仍不回头，居木门后连座向也避开卫国。 [[4]](#note-4)

<a id="event-5"></a>

5. **公孙免馀辞让过厚赏邑，又推荐大叔仪为卿。** 他以甯氏多邑而亡为鉴，只肯接受一半，并不愿越过自己的名位。 [[5]](#note-5)

<a id="event-6"></a>

6. **宋向戌奔走晋、楚、齐、秦，推动各国停止大规模相攻。** 晋臣认为战争残民耗财，即使难以完全停息，也不应拒绝；齐国也担心独拒弭兵会失民望。四强先后答应，诸小国接到通知，准备到宋国会合。 [[6]](#note-6)

<a id="event-7"></a>

7. **夏，各国大夫陆续到宋，商议晋楚属国互相朝见。** 楚方原希望所有从国都交相见，赵武指出晋不能强齐、楚也不能强秦。最后齐、秦得到豁免，其他小国仍需同时维持两方关系。 [[7]](#note-7)

<a id="event-8"></a>

8. **秋七月辛巳，晋楚与诸侯大夫在宋盟誓，楚军却暗穿铠甲。** 叔向劝赵武不要因此先坏和议，又主张不与楚争歃血先后。楚方先行盟礼，双方终于没有交战，完成弭兵约定。 [[8]](#note-8)

<a id="event-9"></a>

9. **叔孙豹拒绝照邾、滕的办法退出盟会，坚持鲁国应列于宋、卫之间。** 季武子曾托君命让他看邾、滕行事，而齐、宋分别要求这两个小国不参加正式盟誓。叔孙豹认为鲁不是他国私属，不应照办，遂参与结盟。 [[9]](#note-9)

<a id="event-10"></a>

10. **宋公再宴各国使臣，晋楚随后互派人员确认和约。** 诸大夫又在蒙门外订盟，晋荀盈赴楚，楚薳罢赴晋。宴谈中两国比较执政之德，也评量对方辅臣的能力。 [[10]](#note-10)

<a id="event-11"></a>

11. **赵武在郑国受宴，借七卿赋诗观察各人志向。** 子展、子西、子产、子太叔等以诗表达各自礼意，伯有却以带有私怨的诗句讥上。赵武因此担忧伯有不能长久，并称许子展居上而能谦下。 [[11]](#note-11)

<a id="event-12"></a>

12. **向戌因弭兵请求赏邑，被子罕痛斥后辞赏。** 子罕认为兵本有威不轨的作用，不能以为凭一人就可去兵，更不该借此邀利。他毁弃授邑之书，向戌最终不受赏，还阻止家人报复子罕。 [[12]](#note-12)

<a id="event-13"></a>

13. **齐崔氏因继承和宗邑争执内讧，庆封两面煽动。** 崔杼废长子成而立明，成与彊又被东郭偃、棠无咎拒绝分邑。庆封先答应支持两兄弟除去二人，等崔杼来求助时，又装作要替他讨逆。 [[13]](#note-13)

<a id="event-14"></a>

14. **庆封借机灭崔氏，崔杼自尽，庆氏独掌齐政。** 崔成、崔彊杀东郭偃、棠无咎后，庆封派兵攻崔氏，诛两兄弟并夺其家。崔杼回来发现家室已破，妻子已死，遂自尽；崔明夜逃，后来奔鲁。 [[14]](#note-14)

<a id="event-15"></a>

15. **申鲜虞流亡在外为齐庄公服丧，冬天转赴楚国。** 他曾在野外受雇御车谋生，楚国召他出仕，任为右尹。 [[15]](#note-15)

<a id="event-16"></a>

16. **年末记有一次日食。** [[16]](#note-16)

<a id="event-17"></a>

17. **卫献公衎后元年。** 卫献公在前547年重新回到卫国君位，《十二诸侯年表》从本年起另列后元年。后元是同一位献公复位后的新一段在位纪年，不应被误写成又有一位卫献公继位。 [[17]](#note-17)

> 辛巳，将盟于宋西门之外，楚人衷甲。伯州犁曰：“合诸侯之师，以为不信，无乃不可乎？夫诸侯望信于楚，是以来服。若不信，是弃其所以服诸侯也。”固请释甲。子木曰：“晋、楚无信久矣，事利而已。苟得志焉，焉用有信？”大宰退，告人曰：“令尹将死矣，不及三年。求逞志而弃信，志将逞乎？志以发言，言以出信，信以立志，参以定之。信亡，何以及三？”赵孟患楚衷甲，以告叔向。叔向曰：“何害也。匹夫一为不信，犹不可，单毙其死。若合诸侯之卿，以为不信，必不捷矣。食言者不病，非子之患也。夫以信召人，而以僭济之，必莫之与也，安能害我？且吾因宋以守病，则夫能致死。与宋致死，虽倍楚可也。子何惧焉？又不及是。曰‘弭兵’以召诸侯，而称兵以害我，吾庸多矣，非所患也。”

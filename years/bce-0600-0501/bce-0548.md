## 本年纪事

<a id="event-1"></a>

1. **春，崔杼率齐军侵鲁北境，很快又撤回。** 这次出兵是报复仲孙羯伐齐。孟公绰观察齐军并不纵兵侵掠、也不要求百姓严备，认为崔杼另有图谋，不会久留。 [看原文与说明](#note-1)

<a id="event-2"></a>

2. **崔杼与齐庄公因棠姜结怨，逐步谋划弑君。** 崔杼在棠公死后娶了棠姜，庄公却与她私通，频繁出入崔家，还拿崔杼的冠送人。崔杼又担心齐国攻晋将招报复，打算杀庄公来向晋国求解，遂利用庄公侍者贾举作内应。 [看原文与说明](#note-2)

<a id="event-3"></a>

3. **夏五月乙亥，齐庄公在崔氏家中被杀。** 崔杼称病，庄公来探问后追随棠姜入内。贾举关门隔开随从，伏兵发动；庄公求和、求盟都遭拒，翻墙出逃也未能脱身，身边多人同时遇害。 [看原文与说明](#note-3)

 [卷四互见与归年](#sj004-548-1)


<a id="event-4"></a>

4. **晏婴到崔氏哭君，却不肯为庄公私事殉死或逃亡。** 他认为臣子应为社稷承担生死，不能把国君为己招祸一概当作自己的责任。晏婴入内伏尸而哭后离开，崔杼顾忌其民望，没有杀他；卢蒲癸、王何等则出奔。 [看原文与说明](#note-4)

<a id="event-5"></a>

5. **崔杼拥立齐景公，与庆封共同掌政，强令国人盟誓。** 崔杼为相，庆封为左相，要求大家站在崔、庆一边。晏婴却只承诺忠于国君、利于社稷，不肯把两家私党当作效忠对象。 [看原文与说明](#note-5)

<a id="event-6"></a>

6. **齐国史官坚持记崔杼弑君，连续有人因直书被杀。** 大史被杀后，继任的弟弟仍写同样的话，接连遇害；再一位弟弟继续书写，崔杼才不再杀。南史氏听说大史皆死，也持简赶来，知道记录已经写下才返回。 [看原文与说明](#note-6)

<a id="event-7"></a>

7. **闾丘婴与申鲜虞逃到鲁国。** 申鲜虞责闾丘婴只知保护私亲，却不能匡君、救难；两人途中一度停宿，出了险地后又加速离开，以免被崔、庆军队追上。 [看原文与说明](#note-7)

<a id="event-8"></a>

8. **齐庄公以很低的规格安葬。** 崔氏把丧事安排在北郭、士孙之里，仪仗、车乘与护卫都受到削减。 [看原文与说明](#note-8)

<a id="event-9"></a>

9. **晋国率诸侯会于夷仪伐齐，齐国归罪庄公并重赂求和。** 庆封到军中送宗器、乐器和财物，从晋侯到各级军吏都有馈赠。晋侯接受和议，通告诸侯；鲁国也表示愿意停兵。 [看原文与说明](#note-9)

<a id="event-10"></a>

10. **卫献公进入夷仪，晋国着手安排他的立足之地。** 晋派人迎接，想让卫国把夷仪交给流亡国君；崔杼又扣住献公家属，索取五鹿。 [看原文与说明](#note-10)

<a id="event-11"></a>

11. **六月，郑国子展、子产率七百乘兵车攻入陈国。** 陈军此前侵郑时堵井伐木，郑国因此报复。郑军夜入陈城，却不许侵入公宫，二卿亲自控制城门。陈侯奔墓地后请降，交出宗器、人口、土地等，郑军随后撤回。 [看原文与说明](#note-11)

<a id="event-12"></a>

12. **诸侯在重丘同盟，齐国重新讲和，鲁襄公会后返国。**  [看原文与说明](#note-12)

<a id="event-13"></a>

13. **赵武执政后减轻诸侯聘币，转而要求礼数周到。** 他向叔孙豹表示，齐崔、庆刚掌权，需要与诸侯修好；若对楚国也以礼与辞令相通，战争可能减少。 [看原文与说明](#note-13)

<a id="event-14"></a>

14. **楚国击败救援舒鸠的吴军，灭掉舒鸠。** 屈建接替薳子冯任令尹后出兵。吴军一度插入楚军两部之间，楚将以私卒诱敌，再由整队部队接战，大败吴军，随后攻灭舒鸠。楚王赏屈建，屈建让功，赏赐转给蒍掩。 [看原文与说明](#note-14)

<a id="event-15"></a>

15. **子产穿戎服赴晋献陈捷，逐条回应晋国质问。** 晋人问郑为何侵小、为何以军服行礼，子产追述陈国与周、郑的关系、陈国侵郑之害，以及郑国从王事的旧命。晋方最终认为其辞理顺，接受战功。 [看原文与说明](#note-15)

<a id="event-16"></a>

16. **冬，郑伯赴晋谢陈战之功，郑军又伐陈并订和约。** 子展陪同国君赴晋，子西再次出兵陈国，陈、郑随后讲和。 [看原文与说明](#note-16)

<a id="event-17"></a>

17. **楚国清查土地与物产，按收入整备军赋。** 司马蒍掩分别登记山林、薮泽、丘陵、水田、牧地等，核定车辆、马匹、兵器与甲盾数目，完成后交给令尹。 [看原文与说明](#note-17)

<a id="event-18"></a>

18. **十二月，吴王诸樊攻楚，在巢地城门前中箭而死。** 巢人牛臣认为吴王勇而轻率，只要引他亲临城门便可射中。吴王果然亲自攻门，牛臣伏在短墙后放箭。 [看原文与说明](#note-18)

<a id="event-19"></a>

19. **晋国程郑去世，子产由此更重视然明的见识。** 子产询问为政，然明主张爱民而严惩不仁。子产又告诉子太叔，治政如同农事，应昼夜思考、从始至终照看，并让行动不越出审慎筹划的范围。 [看原文与说明](#note-19)

<a id="event-20"></a>

20. **卫献公从夷仪与甯喜接洽，甯喜答应帮助复位。** 大叔文子担忧甯氏在两个国君间反复，认为置君如举棋不定，终会连累家族。 [看原文与说明](#note-20)

<a id="event-21"></a>

21. **燕懿公元年。** 燕文公在位六年后去世，懿公承继君位；《十二诸侯年表》将本年列为燕懿公元年。燕国的继承不应和本年齐国庄公遇害当成同一次事件。 [原文与说明](#note-21)

<details>

> 郑子产献捷于晋，戎服将事。晋人问陈之罪，对曰：“昔虞阏父为周陶正，以服事我先王。我先王赖其利器用也，与其神明之后也，庸以元女大姬配胡公，而封诸陈，以备三恪。则我周之自出，至于今是赖。桓公之乱，蔡人欲立其出。我先君庄公奉五父而立之，蔡人杀之。我又与蔡人奉戴厉公，至于庄、宣，皆我之自立。夏氏之乱，成公播荡，又我之自入，君所知也。今陈忘周之大德，蔑我大惠，弃我姻亲，介恃楚众，以冯陵我敝邑，不可亿逞。我是以有往年之告。未获成命，则有我东门之役。当陈隧者，井堙木刊。敝邑大惧不竞，而耻大姬。天诱其衷，启敝邑心。陈知其罪，授手于我。用敢献功！”晋人曰：“何故侵小？”对曰：“先王之命，唯罪所在，各致其辟。且昔天子之地一圻，列国一同，自是以衰。今大国多数圻矣！若无侵小，何以至焉？”晋人曰：“何故戎服？”对曰：“我先君武、庄，为平、桓卿士。城濮之役，文公布命曰： ‘各复旧职！’命我文公戎服辅王，以授楚捷，不敢废王命故也。”士庄伯不能诘，复于赵文子。文子曰：“其辞顺，犯顺不祥。”乃受之。

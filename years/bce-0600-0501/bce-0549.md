<a id="本年纪事"></a>
<a id="event-1"></a>

1. **春，叔孙豹出使晋国，与范宣子讨论什么才算死而不朽。** 范宣子举出自家世代受封的谱系，叔孙豹认为这只是世禄；真正不朽，在于立德、立功、立言，即使本人去世仍能留下作用。 [[1]](#note-1)

<a id="event-2"></a>

2. **子产致书范宣子，促使晋国减轻诸侯聘币负担。** 他指出大国不断聚敛小国财物，会使诸侯离心；执政者借此自肥，也会伤及本国。郑伯此行还请求追究陈国侵郑之事。 [[2]](#note-2)

<a id="event-3"></a>

3. **仲孙羯率鲁军侵齐。** 鲁国为晋国出兵，继续维持与齐国的对抗。 [[3]](#note-3)

<a id="event-4"></a>

4. **夏，楚王组织舟师伐吴，没有取得成果。** 水军行动缺乏严整军政，最后无功返还。 [[4]](#note-4)

<a id="event-5"></a>

5. **齐国害怕晋国报复，联系楚国求援。** 齐侯先想与楚王会面，楚派薳启彊来聘并约会期。齐国在社祭时展示军备，又在听说晋军将来后，派陈无宇随楚使南下求兵。 [[5]](#note-5)

<a id="event-6"></a>

6. **崔杼护送使者后转兵伐莒，进攻介根。** [[6]](#note-6)

<a id="event-7"></a>

7. **秋，鲁国记下两次日食，又遭大水。** 七月甲子朔的日食记为全食；八月癸巳朔再次记日食。 [[7]](#note-7)

<a id="event-8"></a>

8. **诸侯会于夷仪准备伐齐，因水患没能进攻。** 鲁襄公与晋、宋、卫、郑、曹、莒、邾、滕、薛、杞、小邾等一同集结。 [[8]](#note-8)

<a id="event-9"></a>

9. **冬，楚、蔡、陈、许攻郑以救齐，诸侯转而救郑。** 楚军攻到郑国东门，驻棘泽；晋系联军被迫改变行动方向，鲁襄公后来返国。 [[9]](#note-9)

<a id="event-10"></a>

10. **晋国张骼、辅跞乘郑人宛射犬的战车挑战楚军。** 两位晋大夫起初怠慢御者，临近敌营才登车。宛射犬不先商量便驰入楚垒，又突然驾出，二人一面接战一面登车，脱身后以同乘如兄弟相诘，最后相笑而解。 [[10]](#note-10)

<a id="event-11"></a>

11. **楚军回程时，另派军队护送齐使陈无宇。** [[11]](#note-11)

<a id="event-12"></a>

12. **吴国招引舒鸠背楚，楚王暂时没有立即动兵。** 楚使问罪时，舒鸠君否认叛楚并请求盟誓。薳子劝先让百姓休息，等其真正背盟再讨，楚王接受。 [[12]](#note-12)

<a id="event-13"></a>

13. **陈国再清算庆氏党羽，鍼宜咎逃楚。** [[13]](#note-13)

<a id="event-14"></a>

14. **叔孙豹赴京师聘问，并祝贺王城修筑。** 齐人为周修筑郏地，周王嘉许鲁使有礼，赐给大路。 [[14]](#note-14)

<a id="event-15"></a>

15. **鲁国发生严重饥荒。** [[15]](#note-15)

<a id="event-16"></a>

16. **晋国程郑向郑使询问如何退让名位，子羽回国后与然明议论。** 然明认为真正懂得谦下的人不必这样发问，担心程郑有难以明说的忧患。 [[16]](#note-16)

<a id="sj034-wengong-death-event"></a>

17. **燕文公去世，懿公继承。** 文公在位六年，懿公的元年接在下一年。此时文公与战国时代接待苏秦叙事中的文公不是一人。 [[17]](#sj034-wengong-death-note)

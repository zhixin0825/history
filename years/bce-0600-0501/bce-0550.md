<a id="本年纪事"></a>
<a id="event-1"></a>

1. **春二月癸酉朔，发生日食。** [[1]](#note-1)

<a id="event-2"></a>

2. **三月己巳，杞孝公去世，夏季下葬。** 晋悼夫人为娘家国君服丧，晋平公却没有撤乐，因此受到责备。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，邾国畀我来奔鲁国。** [[3]](#note-3)

<a id="event-4"></a>

4. **陈国二庆据国抗命，最终被本国役人推翻，公子黄回陈。** 公子黄向楚国申诉，楚人召二庆，庆氏不从，转而据陈反抗。楚屈建随陈侯围城时，城工伤亡激起役人反抗，庆虎、庆寅被杀，楚国送公子黄返陈。 [[4]](#note-4)

<a id="event-5"></a>

5. **齐国把栾盈和随从藏在车中，送回晋国曲沃。** 齐国借护送婚嫁之机秘密行动。栾盈得到胥午接应，夜间召集旧部，再借宴饮试探曲沃人的支持。 [[5]](#note-5)

<a id="event-6"></a>

6. **栾盈率曲沃兵进入绛都，范氏挟国君固守，并夺走魏氏的支持。** 魏氏原与栾盈通谋，其他主要卿族却各有旧怨。晋君在突袭中极度惊惧，范氏阻止其自杀。范鞅强登魏舒战车，把他带到晋君所在处，范宣子又以曲沃利诱，使栾盈失去最重要的盟友。 [[6]](#note-6)

<a id="event-7"></a>

7. **范氏击退栾军，栾盈退守曲沃。** 斐豹以焚掉记载自己罪籍的丹书为条件，杀死栾氏勇士督戎。范鞅随后率众反击，栾军退却，栾乐战死，栾鲂受伤，晋军转而包围曲沃。 [[7]](#note-7)

<a id="event-8"></a>

8. **秋，齐庄公先伐卫，再乘晋国内乱深入晋境。** 晏婴、崔杼都反对冒险，齐侯仍攻取朝歌，进入孟门、太行，在荧庭展示兵势，驻郫邵，以报平阴之役。回军时，晋赵胜率东阳兵追击，俘获晏氂。 [[8]](#note-8)

<a id="event-9"></a>

9. **八月，叔孙豹率鲁军救晋，驻扎雍榆。** [[9]](#note-9)

<a id="event-10"></a>

10. **鲁国季氏早年的继承安排，成为此时卿族争斗的根源。** 季武子想越过年长的公鉏立幼子，臧纥在宴席中帮助安排名位，使公鉏失去继承机会。公鉏后来在闵子马劝说下勤于任事，得到财富与官职，但对臧氏的怨并未消除。 [[10]](#note-10)

<a id="event-11"></a>

11. **仲孙速去世后，公鉏帮助羯夺得孟氏宗主之位。** 孟庄子原有继承人秩，丰点却支持羯，并许诺对付臧氏。羯被立后，秩逃邾；臧纥虽然素与孟庄子不和，仍痛哭，认为失去这个能警醒自己的人，祸患将近。 [[11]](#note-11)

<a id="event-12"></a>

12. **冬十月，孟氏诬告臧氏阻挠丧事，季氏出兵攻臧纥。** 孟氏借借人清道等事制造疑心。臧纥带甲查看后又被告发，最终斩开鹿门关卡，逃往邾国。 [[12]](#note-12)

<a id="event-13"></a>

13. **臧纥设法保住宗祀，交还防邑后转逃齐国。** 他请家中年长亲属持宝龟向鲁国求情，愿退出防邑，只求先人祭祀不断。鲁国改立臧为，又以‘犯门斩关’作为约束臧氏的盟辞。 [[13]](#note-13)

<a id="event-14"></a>

14. **晋国攻破曲沃，杀栾盈及其宗族党羽。** 栾盈是栾书的孙子。栾鲂逃往宋国，栾氏在晋国的势力随之遭到清除。 [[14]](#note-14)

<a id="event-15"></a>

15. **齐侯自晋回军后又袭莒，杞梁战死，其妻拒绝在郊外接受吊唁。** 杞梁等先入莒境，与莒君部队交战。齐侯回程遇到杞梁妻，她要求无罪之臣应在家中正式受吊，不应草率在郊外办理；齐侯遂到其家中吊丧。 [[15]](#note-15)

<a id="event-16"></a>

16. **臧纥到齐国后，以鼠喻齐侯乘晋乱出兵，失去受田机会。** 齐侯本打算给他土地，问到伐晋时，臧纥直言齐国闻乱才动，像躲人而出的鼠。齐侯因此没有赐田。 [[16]](#note-16)

<a id="event-17"></a>

17. **秦景公赴晋，与晋平公结盟。** 亲自赴晋并未使秦晋关系从此固定不变，本纪接着说后来又背离盟约。 [[17]](#note-17)

> 范鞅逆魏舒，则成列既乘，将逆栾氏矣。趋进，曰：“栾氏帅贼以入，鞅之父与二三子在君所矣。使鞅逆吾子。鞅请骖乘持带。”遂超乘，右抚剑，左援带，命驱之出。仆请，鞅曰：“之公。”宣子逆诸阶，执其手，赂之以曲沃。

> 不可。臣闻之，小国间大国之败而毁焉，必受其咎。君其图之

> 将如君何

**[《左传》](../../sources/春秋左传/有标点原文/bce-0550.md#t010)**

> 吾言于君，君弗听也。以为盟主，而利其难。群臣若急，君于何有？子姑止之

**[《左传》](../../sources/春秋左传/有标点原文/bce-0550.md#t010)**

> 崔子将死乎！谓君甚，而又过之，不得其死。过君以义，犹自抑也，况以恶乎

> 秋，齐侯伐卫，遂伐晋。

> 秋，齐侯伐卫。先驱： 穀荣御王孙挥，召扬为右。申驱： 成秩御莒恒，申鲜虞之傅挚为右。曹开御戎，晏父戎为右。贰广： 上之登御邢公，卢蒲癸为右。启： 牢成御襄罢师，狼蘧为右。胠： 商子车御侯朝，桓跳为右。大殿： 商子游御夏之御寇，崔如为右，烛庸之越驷乘。

> 自卫将遂伐晋。晏平仲曰：“君恃勇力以伐盟主，若不济，国之福也。不德而有功，忧必及君。”崔杼谏曰：“不可。臣闻之，小国间大国之败而毁焉，必受其咎。君其图之！”弗听。陈文子见崔武子，曰：“将如君何？”武子曰：“吾言于君，君弗听也。以为盟主，而利其难。群臣若急，君于何有？子姑止之。”文子退，告其人曰：“崔子将死乎！谓君甚，而又过之，不得其死。过君以义，犹自抑也，况以恶乎？”

> 齐侯遂伐晋，取朝歌。为二队，入孟门，登大行，张武军于荧庭。戍郫邵，封少水，以报平阴之役。乃还。赵胜帅东阳之师以追之，获晏氂。八月，叔孙豹帅师救晋，次于雍榆，礼也。

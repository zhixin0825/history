<a id="本年纪事"></a>
<a id="event-1"></a>

1. **春正月，鲁襄公从商任会返回。** [[1]](#note-1)

<a id="event-2"></a>

2. **臧武仲冒雨赴晋，途中被御叔嘲弄，御叔后来被加倍征赋。** 御叔以自己正在饮酒为由，不肯礼遇使者，还嘲笑所谓圣人为什么冒雨出行。叔孙豹听说后，认为此人既不能出使又侮辱使臣，下令惩处。 [[2]](#note-2)

<a id="event-3"></a>

3. **晋国再征郑君来朝，子产长篇申辩小国已被反复征调拖疲。** 他逐次列出郑国近年来朝见、聘问、参战的经过，说明即便没有亲朝，也从未停止遣使和从役；若大国只索取服从、不体恤郑国困难，反会把小国逼成仇敌。 [[3]](#note-3)

<a id="event-4"></a>

4. **秋七月辛酉，鲁国叔老去世。** [[4]](#note-4)

<a id="event-5"></a>

<a id="event-7"></a>

5. **栾盈自楚入齐，诸侯再盟申禁。** 栾盈从楚国赴齐，晏婴劝齐侯遵守商任之约。冬，诸侯在沙随再会，重申禁纳栾氏，鲁襄公会后归国。 [[5]](#note-5)

<a id="event-6"></a>

6. **郑公孙黑肱病重，把多余封邑还给国君。** 他立段为后，要求减官薄祭，只保留足以奉祀的收入，并告诫家人乱世中贵而能贫，胜过以富招祸。九月，他去世。 [[6]](#note-6)

<a id="event-8"></a>

<a id="event-9"></a>

7. **楚诛令尹子南，薳子冯复任。** 楚杀令尹子南和宠臣观起，子南之子弃疾自尽。薳子冯再任令尹，经申叔豫告诫，辞退八位宠臣。 [[7]](#note-8)

<a id="event-10"></a>

8. **郑国游眅抢走他人新妇，被其丈夫杀死，子太叔继任。** 子展召回携妻逃走的丈夫，让他恢复原居，并不许游氏报复，以免把已经发生的恶事继续扩大。 [[8]](#note-10)

<a id="sj014-confucius-birth"></a>
<a id="十二诸侯年表互见孔丘出生"></a>

<a id="event-11"></a>

9. **孔丘生于鲁国陬邑。** 鲁襄公在位时，孔丘生于昌平乡陬邑，字仲尼，父亲是叔梁纥。孔氏祖先来自宋国。 [[9]](#note-11)

### 3. 晋国再征郑君来朝，子产长篇申辩小国已被反复征调拖疲

[返回正文第3条](#event-3)

> 夏四月。

> 夏，晋人征朝于郑，郑人使少正公孙侨对曰：“在晋先君悼公九年，我寡君于是即位。即位八月，而我先大夫子驷从寡君以朝于执事。执事不礼于寡君，寡君惧。因是行也，我二年六月朝于楚，晋是以有戏之役。楚人犹竞，而申礼于敝邑。敝邑欲从执事而惧为大尤，曰晋其谓我不共有礼，是以不敢携贰于楚。我四年三月，先大夫子又从寡君以观衅于楚，晋于是乎有萧鱼之役。谓我敝邑，迩在晋国，譬诸草木，吾臭味也，而何敢差池？楚亦不竞，寡君尽其土实，重之以宗器，以受齐盟。遂帅群臣随于执事以会岁终。贰于楚者，子侯、石盂，归而讨之。湨梁之明年，子蟜老矣，公孙夏从寡君以朝于君，见于尝酎，与执燔焉。间二年，闻君将靖东夏，四月又朝，以听事期。不朝之间，无岁不聘，无役不从。以大国政令之无常，国家罢病，不虞荐至，无日不惕，岂敢忘职。大国若安定之，其朝夕在庭，何辱命焉？若不恤其患，而以为口实，其无乃不堪任命，而翦为仇雠，敝邑是惧。其敢忘君命？委诸执事，执事实重图之。”

#### 3. 晋国再征郑君来朝，子产长篇申辩小国已被反复征调拖疲

**段落层次：**经文‘夏四月’仅是时令标记，没有附具体事件；不据此补造事项，也不据它强定此段外交答辞的日期。

<details>
<summary>《春秋》经 J002｜原文</summary>

> 夏四月。

<details>
<summary>《左传》传 T002｜原文</summary>

> 夏，晋人征朝于郑，郑人使少正公孙侨对曰：“在晋先君悼公九年，我寡君于是即位。即位八月，而我先大夫子驷从寡君以朝于执事。执事不礼于寡君，寡君惧。因是行也，我二年六月朝于楚，晋是以有戏之役。楚人犹竞，而申礼于敝邑。敝邑欲从执事而惧为大尤，曰晋其谓我不共有礼，是以不敢携贰于楚。我四年三月，先大夫子又从寡君以观衅于楚，晋于是乎有萧鱼之役。谓我敝邑，迩在晋国，譬诸草木，吾臭味也，而何敢差池？楚亦不竞，寡君尽其土实，重之以宗器，以受齐盟。遂帅群臣随于执事以会岁终。贰于楚者，子侯、石盂，归而讨之。湨梁之明年，子蟜老矣，公孙夏从寡君以朝于君，见于尝酎，与执燔焉。间二年，闻君将靖东夏，四月又朝，以听事期。不朝之间，无岁不聘，无役不从。以大国政令之无常，国家罢病，不虞荐至，无日不惕，岂敢忘职。大国若安定之，其朝夕在庭，何辱命焉？若不恤其患，而以为口实，其无乃不堪任命，而翦为仇雠，敝邑是惧。其敢忘君命？委诸执事，执事实重图之。”

# 公元前551年（鲁襄公22年）

## 本年纪事

<a id="event-1"></a>

1. **春正月，鲁襄公从商任会返回。**  [看原文与说明](#note-1)

<a id="event-2"></a>

2. **臧武仲冒雨赴晋，途中被御叔嘲弄，御叔后来被加倍征赋。** 御叔以自己正在饮酒为由，不肯礼遇使者，还嘲笑所谓圣人为什么冒雨出行。叔孙豹听说后，认为此人既不能出使又侮辱使臣，下令惩处。 [看原文与说明](#note-2)

<a id="event-3"></a>

3. **晋国再征郑君来朝，子产长篇申辩小国已被反复征调拖疲。** 他逐次列出郑国近年来朝见、聘问、参战的经过，说明即便没有亲朝，也从未停止遣使和从役；若大国只索取服从、不体恤郑国困难，反会把小国逼成仇敌。 [看原文与说明](#note-3)

<a id="event-4"></a>

4. **秋七月辛酉，鲁国叔老去世。**  [看原文与说明](#note-4)

<a id="event-5"></a>

5. **栾盈从楚转赴齐国，晏婴劝齐侯不要破坏商任约定。** 晏婴认为诸侯间必须守信，齐国既答应不纳栾氏，就不该私自收留。齐侯没有接受。 [看原文与说明](#note-5)

<a id="event-6"></a>

6. **郑公孙黑肱病重，把多余封邑还给国君。** 他立段为后，要求减官薄祭，只保留足以奉祀的收入，并告诫家人乱世中贵而能贫，胜过以富招祸。九月，他去世。 [看原文与说明](#note-6)

<a id="event-7"></a>

7. **冬，诸侯再会沙随，重申禁纳栾氏，鲁襄公会后返国。** 栾盈仍留在齐国，晏婴因此担心齐国将直接与晋国交兵。 [看原文与说明](#note-7)

<a id="event-8"></a>

8. **楚国杀令尹子南与其宠臣观起，子南之子弃疾也自尽。** 观起没有增加俸禄，却拥有数十乘马，楚王因此决定追究。弃疾得知父亲将被杀，不泄王命，也不肯在父死后继续事仇，办理葬事后自尽。 [看原文与说明](#note-8)

<a id="event-9"></a>

9. **薳子冯重新担任令尹，受申叔豫警告后辞退八名宠臣。** 这些人同样没有俸禄却多有车马。申叔豫以观起之死作比，使薳子冯惊惧改过，楚王才放下戒心。 [看原文与说明](#note-9)

<a id="event-10"></a>

10. **郑国游眅抢走他人新妇，被其丈夫杀死，子太叔继任。** 子展召回携妻逃走的丈夫，让他恢复原居，并不许游氏报复，以免把已经发生的恶事继续扩大。 [看原文与说明](#note-10)

### 3. 晋国再征郑君来朝，子产长篇申辩小国已被反复征调拖疲

**说明：**长篇答辞回顾多年的郑晋、郑楚关系。正文写的是当年的申辩，不把答辞中所有旧事重新归入前551年。

**段落层次：**经文‘夏四月’仅是时令标记，没有附具体事件；不据此补造事项，也不据它强定此段外交答辞的日期。

<details>
<summary>《春秋》经 J002｜原文</summary>

> 夏四月。

[回到原文位置](../../sources/春秋左传/有标点原文/bce-0551.md#j002)

</details>

<details>
<summary>《左传》传 T002｜原文</summary>

> 夏，晋人征朝于郑，郑人使少正公孙侨对曰：“在晋先君悼公九年，我寡君于是即位。即位八月，而我先大夫子驷从寡君以朝于执事。执事不礼于寡君，寡君惧。因是行也，我二年六月朝于楚，晋是以有戏之役。楚人犹竞，而申礼于敝邑。敝邑欲从执事而惧为大尤，曰晋其谓我不共有礼，是以不敢携贰于楚。我四年三月，先大夫子又从寡君以观衅于楚，晋于是乎有萧鱼之役。谓我敝邑，迩在晋国，譬诸草木，吾臭味也，而何敢差池？楚亦不竞，寡君尽其土实，重之以宗器，以受齐盟。遂帅群臣随于执事以会岁终。贰于楚者，子侯、石盂，归而讨之。湨梁之明年，子蟜老矣，公孙夏从寡君以朝于君，见于尝酎，与执燔焉。间二年，闻君将靖东夏，四月又朝，以听事期。不朝之间，无岁不聘，无役不从。以大国政令之无常，国家罢病，不虞荐至，无日不惕，岂敢忘职。大国若安定之，其朝夕在庭，何辱命焉？若不恤其患，而以为口实，其无乃不堪任命，而翦为仇雠，敝邑是惧。其敢忘君命？委诸执事，执事实重图之。”

</details>

<details>
<summary>《左传》传 T006｜原文</summary>

> 楚观起有宠于令尹子南，未益禄，而有马数十乘。楚人患之，王将讨焉。子南之子弃疾为王御士，王每见之，必泣。弃疾曰：“君三泣臣矣，敢问谁之罪也？”王曰：“令尹之不能，尔所知也。国将讨焉，尔其居乎？”对曰：“父戮子居，君焉用之？洩命重刑，臣亦不为。”王遂杀子南于朝，轘观起于四竟。子南之臣谓弃疾，请徙子尸于朝，曰：“君臣有礼，唯二三子。”三日，弃疾请尸，王许之。既葬，其徒曰：“行乎！”曰：“吾与杀吾父，行将焉入？”曰：“然则臣王乎？”曰：“弃父事仇，吾弗忍也。”遂缢而死。

<details>
<summary>《左传》传 T007｜原文</summary>

> 复使薳子冯为令尹，公子齮为司马，屈建为莫敖。有宠于薳子者八人，皆无禄而多马。他日朝，与申叔豫言。弗应而退。从之，入于人中。又从之，遂归。退朝见之，曰：“子三困我于朝，吾惧，不敢不见。吾过，子姑告我。何疾我也？”对曰：“吾不免是惧，何敢告子？”曰：“何故？”对曰：“昔观起有宠于子南，子南得罪，观起车裂。何故不惧？”自御而归，不能当道。至，谓八人者曰：“吾见申叔夫子，所谓生死而肉骨也。知我者，如夫子则可。不然，请止。”辞八人者，而后王安之。

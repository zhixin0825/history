# 公元前552年（鲁襄公21年）

> 本页合并本年《春秋》《左传》及已核《史记》互见；月份沿用古史年条。回叙、后续与作者评论在相应史料注中区分，不据叙述位置强造发生年。

## 本年纪事

<a id="event-1"></a>

1. **春，鲁襄公赴晋，感谢出师与划给鲁国的邾田，夏季返鲁。**  [看原文与说明](#note-1)

<a id="event-2"></a>

2. **邾国庶其带漆、闾丘两地投鲁，季武子给予厚待。** 季武子用鲁君的姑姊嫁给他，并赏赐随从，使这次携地来奔获得很高的待遇。 [看原文与说明](#note-2)

<a id="event-3"></a>

3. **鲁国盗贼增多，臧武仲当面批评季孙自己就在奖励外来大盗。** 季孙问为何不惩盗，臧武仲回答：庶其带走别人土地而受婚姻、封邑和财物之赏，执政者这样行事，就很难再禁止百姓效仿。 [看原文与说明](#note-3)

<a id="event-4"></a>

4. **齐国继续追究公子牙的党羽，数名公子出奔。** 庆佐出任大夫，公子买被拘于句渎之丘，公子鉏逃鲁，叔孙还逃燕。 [看原文与说明](#note-4)

<a id="event-5"></a>

5. **楚国子庚去世，薳子冯称病推辞令尹，子南继任。** 申叔豫提醒薳子冯，楚国宠臣多、国君弱，政务难办。薳子冯便在暑天冰床上厚衣少食，装出重病模样，楚王改任别人。 [看原文与说明](#note-5)

<a id="event-6"></a>

6. **晋国栾盈遭母亲与范氏诬告，被逐出国。** 栾盈的母亲与家臣州宾私通，担心被儿子追究，向父亲范宣子指控栾盈谋乱，范鞅也作证。范宣子又忌惮栾盈好施、多士归附，借筑著之役把他放逐。 [看原文与说明](#note-6)

<a id="event-7"></a>

7. **秋，栾盈逃楚，晋国大批与栾氏有关的人被杀或拘禁。** 羊舌虎等遇害，叔向、伯华、籍偃被囚。叔向不信乐王鲋的空口求情，认为只有祁奚会真正援救。 [看原文与说明](#note-7)

<a id="event-8"></a>

8. **祁奚出面为叔向申辩，叔向获释。** 祁奚认为叔向是有益社稷的人，不能仅因其弟与栾氏有关就舍弃贤臣。范宣子接受劝告，同他向国君进言；祁奚事后未求见叔向，叔向也没有专门去谢恩。 [看原文与说明](#note-8)

<a id="event-9"></a>

9. **栾盈过周王畿遭抢掠，向王室申诉后得到保护。** 他陈述祖父栾书效力王室的旧功。周王禁止劫掠，命人归还被取财物，并护送栾氏出境。 [看原文与说明](#note-9)

<a id="event-10"></a>

10. **《春秋》经记九月庚戌朔、冬十月庚辰朔两条日食。** 两条是古籍记录，不意味着都已经获得现代天文核实；十月条的准确性仍有争议。 [看原文与说明](#note-10)

<a id="event-11"></a>

11. **曹武公首次来鲁朝见。**  [看原文与说明](#note-11)

<a id="event-12"></a>

12. **诸侯会于商任，下令不得收容栾氏。** 鲁襄公与晋、齐、宋、卫、郑、曹、莒、邾等君主会面，晋国试图阻止栾盈在外获得援助。 [看原文与说明](#note-12)

<a id="event-13"></a>

13. **栾氏余党逃往齐国，晋国对是否收回勇士发生争论。** 知起、中行喜、州绰、邢蒯到齐国；乐王鲋劝范宣子召回州绰、邢蒯，说只要善待他们，也可以使他们为范氏效力。 [看原文与说明](#note-13)

<a id="event-14"></a>

14. **州绰在齐国与本国勇士争功，提醒齐君自己曾俘获他们。** 齐庄公称殖绰、郭最为勇士，州绰举出平阴、东闾之役的经历，要求自己的武功也得到承认。 [看原文与说明](#note-14)

### 3. 鲁国盗贼增多，臧武仲当面批评季孙自己就在奖励外来大盗

<details>
<summary>《左传》传 T003｜原文</summary>

> 于是鲁多盗。季孙谓臧武仲曰：“子盍诘盗？”武仲曰：“不可诘也，纥又不能。”季孙曰：“我有四封，而诘其盗，何故不可？子为司寇，将盗是务去，若之何不能？”武仲曰：“子召外盗而大礼焉，何以止吾盗？子为正卿而来外盗，使纥去之，将何以能？庶其窃邑于邾以来，子以姬氏妻之，而与之邑，其从者皆有赐焉。若大盗，礼焉以君之姑姊与其大邑，其次皂牧舆马，其小者衣裳剑带，是赏盗也。赏而去之，其或难焉。纥也闻之，在上位者，洒濯其心，壹以待人，轨度其信，可明征也，而后可以治人。夫上之所为，民之归也。上所不为而民或为之，是以加刑罚焉，而莫敢不惩。若上之所为而民亦为之，乃其所也，又可禁乎？《夏书》曰：‘念兹在兹，释兹在兹，名言兹在兹，允出兹在兹，惟帝念功。’将谓由己壹也。信由己壹，而后功可念也。”

### 7. 秋，栾盈逃楚，晋国大批与栾氏有关的人被杀或拘禁

**段落层次：**羊舌虎的出生及其母所受的预言是叔向家族的前事。原段保留，不能把出生、娶妾都记作本年发生。

<details>
<summary>《左传》传 T008｜原文</summary>

> 秋，栾盈出奔楚。宣子杀箕遗、黄渊、嘉父、司空靖、邴豫、董叔、邴师、申书、羊舌虎、叔罴，囚伯华、叔向、籍偃。人谓叔向曰：“子离于罪，其为不知乎？”叔向曰：“与其死亡若何？《诗》曰：‘优哉游哉，聊以卒岁。’知也。”乐王鲋见叔向曰：“吾为子请！”叔向弗应。出，不拜。其人皆咎叔向。叔向曰：“必祁大夫。”室老闻之曰：“乐王鲋言于君无不行，求赦吾子，吾子不许。祁大夫所不能也，而曰‘必由之’，何也？”叔向曰：“乐王鲋，从君者也，何能行？祁大夫外举不弃仇，内举不失亲，其独遗我乎？《诗》曰：‘有觉德行，四国顺之。’夫子，觉者也。”

[回到原文位置](../../sources/春秋左传/有标点原文/bce-0552.md#t008)

</details>

<details>
<summary>《左传》传 T010｜原文</summary>

> 初，叔向之母妬叔虎之母美而不使。其子皆谏其母。其母曰：“深山大泽，实生龙蛇。彼美，余惧其生龙蛇以祸女。女，敝族也。国多大宠，不仁人间之，不亦难乎？余何爱焉！”使往视寝，生叔虎。美而有勇力，栾怀子嬖之，故羊舌氏之族及于难。

### 8. 祁奚出面为叔向申辩，叔向获释

<details>
<summary>《左传》传 T009｜原文</summary>

> 晋侯问叔向之罪于乐王鲋，对曰：“不弃其亲，其有焉。”于是祁奚老矣，闻之，乘驲而见宣子，曰：“《诗》曰：‘惠我无疆，子孙保之。’《书》曰：‘圣有谟勋，明征定保。’夫谋而鲜过，惠训不倦者，叔向有焉，社稷之固也。犹将十世宥之，以劝能者。今壹不免其身，以弃社稷，不亦惑乎？鲧殛而禹兴。伊尹放大甲而相之，卒无怨色。管、蔡为戮，周公右王。若之何其以虎也弃社稷？子为善，谁敢不勉。多杀何为？”宣子说，与之乘，以言诸公而免之。不见叔向而归。叔向亦不告免焉而朝。

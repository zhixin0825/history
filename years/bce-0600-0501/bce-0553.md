# 公元前553年（鲁襄公20年）

> 本页合并本年《春秋》《左传》及已核《史记》互见；月份沿用古史年条。回叙、后续与作者评论在相应史料注中区分，不据叙述位置强造发生年。

## 本年纪事

<a id="event-1"></a>

1. **春正月辛亥，仲孙速与莒人在向地结盟。** 鲁、莒借此前督扬之盟恢复和平。 [看原文与说明](#note-1)

<a id="event-2"></a>

2. **夏六月庚申，诸侯在澶渊结盟，齐国重新与晋系诸侯和好。** 鲁襄公与晋、齐、宋、卫、郑、曹、莒、邾、滕、薛、杞、小邾等会合，秋天返鲁。 [看原文与说明](#note-2)

<a id="event-3"></a>

3. **秋，仲孙速率军伐邾，报复邾国屡次来攻。** 鲁国先前忙于参加诸侯事务，没有及时还击，此时才出兵。 [看原文与说明](#note-3)

<a id="event-4"></a>

4. **蔡国公子燮主张归晋，被杀；其弟公子履逃楚。** 公子燮想延续先君亲晋的打算，却未得到国内支持，兄弟二人一死一亡。 [看原文与说明](#note-4)

<a id="event-5"></a>

5. **陈国公子黄被二庆排挤，逃往楚国。** 庆虎、庆寅害怕他的地位威胁自己，向楚国诬称他与蔡公子燮同谋。公子黄出走前公开责骂庆氏专权，预言庆氏终将覆灭。 [看原文与说明](#note-5)

<a id="event-6"></a>

6. **叔老首次赴齐聘问。**  [看原文与说明](#note-6)

<a id="event-7"></a>

7. **冬十月丙辰朔，发生日食。**  [看原文与说明](#note-7)

<a id="event-8"></a>

8. **季孙宿赴宋回聘，宋国厚礼相待。** 季孙回报向戌先前来鲁的聘问，宋方以宴饮、诗歌接待。回鲁复命后，襄公又设宴慰劳；面对国君过高的赞誉，季孙离席辞谢。 [看原文与说明](#note-8)

<a id="event-9"></a>

9. **卫国甯殖临终嘱儿子甯喜迎回卫献公。** 甯殖悔恨自己与孙林父逐君的名声已写入诸侯史册，希望国君回国后能够掩去这一恶名。甯喜答应，甯殖随即去世。 [看原文与说明](#note-9)

<a id="event-10"></a>

10. **齐庄公光元年。** 齐灵公已在上年去世，公子光当时被拥立为齐庄公；《十二诸侯年表》从本年记庄公元年，不是再次拥立一位新君。 [原文与说明](#note-10)

### 5. 陈国公子黄被二庆排挤，逃往楚国

**说明：**公子黄所说庆氏五年不灭便‘无天’，是愤怒中的预言，不直接等同于本年已经确定的后果。

<details>
<summary>《春秋》经 J007｜原文</summary>

> 陈侯之弟黄出奔楚。

[回到原文位置](../../sources/春秋左传/有标点原文/bce-0553.md#j007)

</details>

<details>
<summary>《左传》传 T006｜原文</summary>

> 陈庆虎、庆寅畏公子黄之偪，愬诸楚曰：“与蔡司马同谋。”楚人以为讨。公子黄出奔楚。初，蔡文侯欲事晋，曰：“先君与于践土之盟，晋不可弃，且兄弟也。”畏楚，不能行而卒。楚人使蔡无常，公子燮求从先君以利蔡，不能而死。书曰：“蔡杀其大夫公子燮”，言不与民同欲也。“陈侯之弟黄出奔楚”，言非其罪也。公子黄将出奔，呼于国曰：“庆氏无道，求专陈国，暴蔑其君，而去其亲，五年不灭，是无天也。”

<a id="note-10"></a>

### 10. 齐庄公光元年与公子牙结局异说

[《十二诸侯年表》前553年齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0553)记“齐庄公光元年”；[《齐太公世家》](https://zh.wikisource.org/wiki/史記/卷032)亦记庄公光继位。前554年[灵公死亡、公子光即位](bce-0554.md#event-7)已记，故本年只计改元。《史记》关于公子牙被杀的文字比《左传》记录拘押更进一步；后者不写死亡，不能当作明确否定，分歧继续保留。

## 本年纪事

<a id="event-1"></a>

1. **春，伐齐诸侯重新盟誓，晋国扣押邾君，把部分邾地划给鲁国。** 联军从沂水一带返回，约定大国不得侵小国；晋国又因邾曾攻鲁而拘邾悼公，以漷水划界给鲁。襄公结束伐齐返国，并宴请晋国六卿，赠送命服、锦帛、马匹与鼎器。 [看原文与说明](#note-1)

<a id="event-2"></a>

2. **晋军主帅荀偃返国途中病死。** 他头部生疮，过河后病势加重，临终指定家中继承人。死后仍睁目不能含殓，范宣子起初承诺善待其子，后来又承诺继续处理齐国之事，才完成丧礼。 [看原文与说明](#note-2)

<a id="event-3"></a>

3. **季孙宿赴晋谢援，回鲁后铸钟铭功，却遭臧武仲反对。** 季孙把从齐军所得兵器铸成林钟，想记录鲁国战功。臧武仲指出鲁国借大国力量脱险，不宜把这种所得公开夸耀，以免再激怒别人。 [看原文与说明](#note-3)

<a id="event-4"></a>

4. **曹成公下葬。**  [看原文与说明](#note-4)

<a id="event-5"></a>

5. **夏，卫孙林父继续伐齐，晋国栾鲂率军相助。** 诸侯对齐国的军事压力并没有随主力返国而结束。 [看原文与说明](#note-5)

<a id="event-6"></a>

6. **齐灵公此前改立太子牙，病重时崔杼却迎回公子光。** 灵公宠爱戎子，想废掉早已列于诸侯的太子光，改立由戎子抚养的牙，令高厚、夙沙卫辅佐。等灵公病危，崔杼暗中迎光回国；光取得权力后杀死戎子。 [看原文与说明](#note-6)

<a id="event-7"></a>

7. **齐灵公去世，公子光即位为齐庄公，夙沙卫据高唐反抗。** 庄公拘住公子牙，又与此前帮助改立太子的夙沙卫决裂，齐国内部继承斗争没有立即平息。 [看原文与说明](#note-7)

<a id="event-8"></a>

8. **晋士匄率军侵齐，听说齐侯去世后撤军。** 晋军已到穀地，得知齐丧后停止推进。 [看原文与说明](#note-8)

<a id="event-9"></a>

9. **郑公孙虿去世，周王因其伐秦旧功追赐大路。** 范宣子向晋侯陈述子蟜在伐秦时的表现，晋侯再向周王请求，以所赐车辆用于其丧礼。 [看原文与说明](#note-9)

<a id="event-10"></a>

10. **八月丙辰，鲁国仲孙蔑去世。**  [看原文与说明](#note-10)

<a id="event-11"></a>

11. **齐崔杼杀高厚，并吞其家产。** 高厚此前参与齐国太子废立，此时被崔氏清除。 [看原文与说明](#note-11)

<a id="event-12"></a>

12. **郑国子展、子西诛子孔，子产升为卿。** 子孔独揽政务，国人追究西宫之乱与召楚军到纯门的旧事。子孔与亲近家族披甲自守，仍被攻败；子革、子良逃往楚国。郑国改由子展当国、子西听政。 [看原文与说明](#note-12)

<a id="event-13"></a>

13. **齐军攻破高唐，夙沙卫被杀。** 庆封先围而未克，齐庄公冬季亲往。殖绰、工偻会夜间缒出，接应齐军入城，结束这场内乱。 [看原文与说明](#note-13)

<a id="event-14"></a>

14. **冬，齐灵公下葬。**  [看原文与说明](#note-14)

<a id="event-15"></a>

15. **鲁国修西郛，又与晋会于柯，随后再筑武城。** 齐、晋在大隧议和后，叔孙豹会范宣子于柯。但他仍认为齐国威胁未除，因此鲁国继续加强防御。 [看原文与说明](#note-15)

<a id="event-16"></a>

16. **卫国石共子去世，继承人的居丧表现受到责备。** 石悼子没有表现出应有哀痛，孔成子因此担忧石氏将不能保住宗族地位。 [看原文与说明](#note-16)

<a id="event-17"></a>

17. **燕文公元年。** 燕武公已于上一年去世、燕文公继承君位，本年起按燕文公纪年。 [看原文与说明](#note-17)

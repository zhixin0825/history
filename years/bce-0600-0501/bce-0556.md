# 公元前556年（鲁襄公17年）

<a id="reading-start"></a>

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **春二月庚午，邾君去世。** [[1]](#note-1)

<a id="event-2"></a>

2. **宋军攻陈，俘获陈国司徒卬。** 宋国以陈国轻视自己为出兵理由，由庄朝率军。 [[2]](#note-2)

<a id="event-3"></a>

<a id="event-4"></a>

3. **卫孙蒯田猎与曹生隙，卫军攻取重丘。** 卫孙蒯在曹地田猎，毁坏当地水器，双方由此起争。夏，卫石买、孙蒯发兵攻曹，取重丘。 [[3]](#note-3)

<a id="event-5"></a>

<a id="event-6"></a>

<a id="event-8"></a>

4. **齐围桃、防，鲁救臧纥，臧坚被俘后自尽。** 秋，齐军分别围桃、围防，鲁军夜救臧纥。齐侯攻桃，高厚围住防地。郰叔纥、臧畴、臧贾带三百甲士夜间冲入齐军，护送臧孙出来，再返回本阵。臧坚被齐军俘获，不肯接受夙沙卫慰谕，自尽而死。齐侯原想留他一命，却派受刑出身的夙沙卫传话。臧坚认为国君既要施恩，又这样辱士，于是以木器刺伤而死。冬，邾军又侵鲁南境，配合齐国行动。 [[4]](#note-5)

<a id="event-7"></a>

5. **九月，鲁国举行大雩。** [[5]](#note-7)

<a id="event-9"></a>

6. **宋华臣侵夺兄家、杀害家宰，最后因惊惧逃往陈国。** 华阅死后，华臣逼迫其家，派人杀华吴，又拘其妻索大璧。宋公本想放逐他，左师暂时掩护；后来国人追疯狗进入华臣家，华臣误以为祸至，遂逃陈。 [[6]](#note-9)

<a id="event-10"></a>

7. **宋国在收获时节筑台，子罕先劝缓工，后来亲自督促完工。** 宋公不肯等农事结束，役夫于是唱歌贬皇国父、赞子罕。子罕不愿让小国朝廷分成受诅与受祝的两派，转而督工，使歌声停止。 [[7]](#note-10)

<a id="event-11"></a>

8. **齐晏桓子去世，晏婴坚持严守丧礼。** 晏婴是莱地夷维人，父亲晏桓子名弱。此时他穿粗丧服、食粥、居倚庐、卧草席；家臣认为不合大夫通常礼数，他仍坚持自己的身份与礼制理解。他历事灵公、庄公、景公期间的节俭和问政表现，是一生总述，不在本年同时发生。 [[8]](#note-11)

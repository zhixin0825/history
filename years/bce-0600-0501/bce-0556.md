# 公元前556年（鲁襄公17年）

<a id="reading-start"></a>


[← 上一张已编年页：公元前557年](bce-0557.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前555年 →](bce-0555.md)

> 本页合并本年《春秋》《左传》及已核《史记》互见；月份沿用古史年条。回叙、后续与作者评论在相应史料注中区分，不据叙述位置强造发生年。

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **春二月庚午，邾君去世。**  [[1]](#note-1)

<a id="event-2"></a>

2. **宋军攻陈，俘获陈国司徒卬。** 宋国以陈国轻视自己为出兵理由，由庄朝率军。 [[2]](#note-2)

<a id="event-3"></a>

3. **卫国孙蒯在曹地田猎，毁损当地水器，引起争端。** 重丘人闭门辱骂孙氏逐君，又责孙蒯不忧家国而来田猎。 [[3]](#note-3)

<a id="event-4"></a>

4. **夏，卫石买、孙蒯率军攻曹，夺取重丘。** 曹国向晋国申诉，请求追究卫国。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋，齐军分别围桃、围防，鲁军夜救臧纥。** 齐侯攻桃，高厚围住防地。郰叔纥、臧畴、臧贾带三百甲士夜间冲入齐军，护送臧孙出来，再返回本阵。 [[5]](#note-5)

<a id="event-6"></a>

6. **臧坚被齐军俘获，不肯接受夙沙卫慰谕，自尽而死。** 齐侯原想留他一命，却派受刑出身的夙沙卫传话。臧坚认为国君既要施恩，又这样辱士，于是以木器刺伤而死。 [[6]](#note-6)

<a id="event-7"></a>

7. **九月，鲁国举行大雩。**  [[7]](#note-7)

<a id="event-8"></a>

8. **冬，邾军又侵鲁南境，配合齐国行动。**  [[8]](#note-8)

<a id="event-9"></a>

9. **宋华臣侵夺兄家、杀害家宰，最后因惊惧逃往陈国。** 华阅死后，华臣逼迫其家，派人杀华吴，又拘其妻索大璧。宋公本想放逐他，左师暂时掩护；后来国人追疯狗进入华臣家，华臣误以为祸至，遂逃陈。 [[9]](#note-9)

<a id="event-10"></a>

10. **宋国在收获时节筑台，子罕先劝缓工，后来亲自督促完工。** 宋公不肯等农事结束，役夫于是唱歌贬皇国父、赞子罕。子罕不愿让小国朝廷分成受诅与受祝的两派，转而督工，使歌声停止。 [[10]](#note-10)

<a id="event-11"></a>

11. **齐晏桓子去世，晏婴坚持严守丧礼。** 他穿粗丧服、食粥、居倚庐、卧草席。家臣认为不合大夫通常礼数，他仍坚持自己的身份与礼制理解。 [[11]](#note-11)

<details>
<summary>《左传》传 T007｜原文</summary>

> 宋华阅卒。华臣弱皋比之室，使贼杀其宰华吴。贼六人以铍杀诸卢门合左师之后。左师惧曰：“老夫无罪。”贼曰：“皋比私有讨于吴。”遂幽其妻，曰：“畀余而大璧！”宋公闻之，曰：“臣也，不唯其宗室是暴，大乱宋国之政，必逐之！”左师曰：“臣也，亦卿也。大臣不顺，国之耻也。不如盖之。”乃舍之。左师为己短策，苟过华臣之门，必骋。十一月甲午，国人逐瘈狗，瘈狗入于华臣氏，国人从之。华臣惧，遂奔陈。

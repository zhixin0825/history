1. **晋平公召诸侯会于湨梁，齐高厚离盟，齐又犯鲁。** 春，晋悼公下葬，晋平公整顿官职后召集诸侯。羊舌肸任傅，张君臣任中军司马，祁奚、韩襄、栾盈、士鞅任公族大夫。晋国先在曲沃举行祭祀，再赴湨梁。三月，诸侯会于湨梁，晋国下令归还侵占的土地。鲁襄公与晋、宋、卫、郑、曹、莒、邾、薛、杞、小邾等君主与会。晋国为鲁国讨伐之事，并以通齐、楚使者为由，扣押莒君、邾君。诸侯宴饮中，齐高厚赋诗不合要求，逃离了大夫盟誓。荀偃认为这说明齐国另有打算，要求各国大夫共同约定讨伐不服从者。高厚不肯受盟，逃回齐国。齐军侵鲁北境，鲁襄公夏季才从会中返回。 [[1]](#note-1)

<a id="event-5"></a>

2. **五月甲子，发生地震。** [[2]](#note-5)

<a id="event-6"></a>

<a id="event-7"></a>

3. **诸侯伐许，晋在湛阪败楚。** 鲁叔老随晋系诸侯伐许。晋军在湛阪击败楚军，深入方城外围。 [[3]](#note-6)

<a id="event-8"></a>

<a id="event-10"></a>

4. **齐围成，叔孙豹赴晋求援。** 秋，齐军围成，鲁孟速出兵阻击。冬，叔孙豹赴晋求援，请晋勿再拖延。 [[4]](#note-8)

<a id="event-9"></a>

5. **鲁国举行大雩。** [[5]](#note-9)

### 3. 诸侯伐许，晋在湛阪败楚

> 叔老会郑伯、晋荀偃、卫甯殖、宋人伐许。

> 许男请迁于晋。诸侯遂迁许，许大夫不可。晋人归诸侯。郑子蟜闻将伐许，遂相郑伯以从诸侯之师。穆叔从公。齐子帅师会晋荀偃。书曰：“会郑伯。”为夷故也。

> 夏六月，次于棫林。庚寅，伐许，次于函氏。晋荀偃、栾黡帅师伐楚，以报宋扬梁之役。楚公子格帅师及晋师战于湛阪，楚师败绩。晋师遂侵方城之外，复伐许而还。

# 公元前558年（鲁襄公15年）

## 本年纪事

<a id="event-1"></a>

1. **春，宋向戌来鲁聘问，二月己亥在刘地续盟。** 向戌见孟献子家室华美，批评这与其好名声不称；孟献子解释房屋是自己出使晋国时兄长所建，拆毁反而再劳民力，因此没有改动。 [看原文与说明](#note-1)

<a id="event-2"></a>

2. **周王室派人到齐国迎后。** 刘夏参加迎亲，相关官员随单靖公同行。 [看原文与说明](#note-2)

<a id="event-3"></a>

3. **楚国重新任命一批执政和军官，安定国内。** 公子午任令尹，罢戎任右尹，子冯任大司马，另任左右司马、莫敖、箴尹、连尹及宫廐尹，各守其职。 [看原文与说明](#note-3)

<a id="event-4"></a>

4. **郑国向宋索回西宫之乱的逃亡者。** 郑国以马、乐师和人质交换堵女父、尉翩、司齐，三人被交回处死。宋子罕却让司臣脱身，把他托给季武子，安置在卞地。 [看原文与说明](#note-4)

<a id="event-5"></a>

5. **乐师师慧讥讽以大臣换乐人的交易，子罕退还了他。** 师慧经过宋朝廷时称这里‘无人’，意在责备执政把大事和乐人交易相混。子罕听后坚持把他送还。 [看原文与说明](#note-5)

<a id="event-6"></a>

6. **夏，齐军围成，鲁襄公出兵救援，到达遇地。** 齐国因鲁国依晋而来攻。季孙宿、叔孙豹随后率军修筑成地外城，加强防御。 [看原文与说明](#note-6)

<a id="event-7"></a>

7. **秋八月丁巳，发生日食。**  [看原文与说明](#note-7)

<a id="event-8"></a>

8. **邾军又侵鲁国南境，晋国拟召诸侯问罪，却未能成会。** 鲁国告急后，晋国准备一并讨邾、莒，但晋悼公病重，计划中止。 [看原文与说明](#note-8)

<a id="event-9"></a>

9. **冬十一月癸亥，晋悼公去世。** 郑国派公孙夏等赴晋参与丧事。 [看原文与说明](#note-9)

<a id="event-10"></a>

10. **宋人献玉，子罕以不贪为宝，拒绝据为己有。** 献玉者担心携宝回乡会有危险，子罕便让他暂住自己的里中，请玉工加工，等其能够带着所得返回，才送他回去。 [看原文与说明](#note-10)

<a id="event-11"></a>

11. **十二月，郑人夺取堵狗的妻子，交给范氏。** 现存本年原段只记这一行动，没有展开其具体动机与交涉经过。 [看原文与说明](#note-11)

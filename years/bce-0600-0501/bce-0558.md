# 公元前558年（鲁襄公15年）

[← 上一张已编年页：公元前559年](bce-0559.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前557年 →](bce-0557.md)

> 本页合并本年《春秋》《左传》及已核《史记》互见；月份沿用古史年条。回叙、后续与作者评论在相应史料注中区分，不据叙述位置强造发生年。

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **春，宋向戌来鲁聘问，二月己亥在刘地续盟。** 向戌见孟献子家室华美，批评这与其好名声不称；孟献子解释房屋是自己出使晋国时兄长所建，拆毁反而再劳民力，因此没有改动。 [[1]](#note-1)

<a id="event-2"></a>

2. **周王室派人到齐国迎后。** 刘夏参加迎亲，相关官员随单靖公同行。 [[2]](#note-2)

<a id="event-3"></a>

3. **楚国重新任命一批执政和军官，安定国内。** 公子午任令尹，罢戎任右尹，子冯任大司马，另任左右司马、莫敖、箴尹、连尹及宫廐尹，各守其职。 [[3]](#note-3)

<a id="event-4"></a>

<a id="event-5"></a>

4. **郑向宋索西宫之乱逃亡者，宋归还乐师师慧。** 郑向宋索回西宫之乱的逃亡者。师慧讥讽拿大臣换乐人，宋子罕遂把他送回。 [[4]](#note-4)

<a id="event-6"></a>

5. **夏，齐军围成，鲁襄公出兵救援，到达遇地。** 齐国因鲁国依晋而来攻。季孙宿、叔孙豹随后率军修筑成地外城，加强防御。 [[5]](#note-6)

<a id="event-7"></a>

6. **秋八月丁巳，发生日食。** [[6]](#note-7)

<a id="event-8"></a>

7. **邾军又侵鲁国南境，晋国拟召诸侯问罪，却未能成会。** 鲁国告急后，晋国准备一并讨邾、莒，但晋悼公病重，计划中止。 [[7]](#note-8)

<a id="event-9"></a>

8. **冬十一月癸亥，晋悼公去世。** 郑国派公孙夏等赴晋参与丧事。 悼公晚年曾问师旷如何治国，师旷以仁义为本回答；冬季去世后，儿子彪继承，为平公。 [[8]](#note-9)

<a id="event-10"></a>

9. **宋人献玉，子罕以不贪为宝，拒绝据为己有。** 献玉者担心携宝回乡会有危险，子罕便让他暂住自己的里中，请玉工加工，等其能够带着所得返回，才送他回去。 [[9]](#note-10)

<a id="event-11"></a>

10. **十二月，郑人夺取堵狗的妻子，交给范氏。** 现存本年原段只记这一行动，没有展开其具体动机与交涉经过。 [[10]](#note-11)

<a id="event-12"></a>

11. **卫殇公元年。** 卫献公上年被逐，公孙剽被拥立。本年为卫殇公元年。 [[11]](#note-12)

## 本年纪事

<a id="event-1"></a>

1. **春，晋国召集诸侯在向地会吴，商议楚国对吴的战争。** 季孙宿、叔老代表鲁国参加。晋方先责吴国失德，又扣住通楚的莒公子务娄。 [看原文与说明](#note-1)

<a id="event-2"></a>

2. **晋国指责姜戎驹支泄露会盟言语，驹支当面申辩。** 他陈述祖先受秦驱逐、蒙晋收容后开垦荒地，以及殽战以来助晋作战的旧功；又说戎人与诸夏语言、衣食不同，不该把诸侯离心都归罪于他们。范宣子最终道歉，让他继续与会。 [看原文与说明](#note-2)

<a id="event-3"></a>

3. **吴王诸樊除丧后想让位季札，季札拒绝。** 季札以曹国子臧不争君位的往事为例，坚持诸樊才是应当继位的人。吴国强要立他，他便离开家室去耕田，众人只得作罢。 [看原文与说明](#note-3)

<a id="event-4"></a>

4. **二月乙未朔，发生日食。**  [看原文与说明](#note-4)

<a id="event-5"></a>

5. **夏，诸侯大夫率军伐秦，渡泾水后遭受损失。** 晋侯留在边境，派六卿统军。联军起初不肯过河，鲁、莒率先渡过，郑、卫又劝其他军队跟进。秦人在上游投毒，造成联军多人死亡。 [看原文与说明](#note-5)

<a id="event-6"></a>

6. **晋军号令不一，伐秦最后无功撤回。** 荀偃命令各军唯自己的马首行动，栾黡却表示自己要向东归，下军跟着离去。荀偃承认下令失当，只能命全军撤退，这次行动被称为‘迁延之役’。 [看原文与说明](#note-6)

[补充史料与年次说明](#sj005-111-note)


<a id="event-7"></a>

7. **栾鍼独攻秦军战死，士鞅因此被迫逃秦。** 栾鍼不甘再次无功，与士鞅驰入秦军，自己战死，士鞅返回。栾黡迁怒范氏，逼士鞅出奔；秦君后来替士鞅向晋请求，才让他回国。 [看原文与说明](#note-7)

<a id="event-8"></a>

8. **卫献公怠慢孙林父、甯殖，又用诗歌激怒孙氏。** 国君约二人吃饭，却让他们等到很晚，自己仍在园中射鸟。后来孙蒯入朝，师曹借奉命奏诗的机会报复旧怨，进一步加深国君与孙家的猜忌。 [看原文与说明](#note-8)

<a id="event-9"></a>

9. **孙林父先集家属于戚，继而与国君决裂。** 蘧伯玉不愿参与废立，离开卫国；国君派来与孙氏议盟的人则先后被杀。 [看原文与说明](#note-9)

<a id="event-10"></a>

10. **四月己未，卫献公出奔齐国，孙氏在途中追击。** 卫军在阿泽战败。公孙丁护卫国君，追兵中有人顾念师承而退，有人继续追射。子鲜随献公流亡，齐国以郲地安置他们。 [看原文与说明](#note-10)

<a id="event-11"></a>

11. **卫献公想向神明申诉无罪，定姜当面指出他的过失。** 她列举献公疏远大臣、轻蔑先君所留师保、辱使先君夫人等事，要求只能报告出亡，不可妄称无罪。 [看原文与说明](#note-11)

<a id="event-12"></a>

12. **卫人拥立公孙剽，鲁国分别慰问卫国臣下和流亡国君。** 孙林父、甯殖辅佐新君。厚成叔认为卫国内有大叔仪、外有子鲜，献公仍可能回国；臧纥先因献公言语暴虐而悲观，后来见子展、子鲜善于应对，又改变判断。 [看原文与说明](#note-12)

<a id="event-13"></a>

13. **晋军返国后撤掉新军，恢复三军规模。** 新军缺少合适主帅，相关家族的继承人又年幼，晋国因此不再保留这个编制。 [看原文与说明](#note-13)

<a id="event-14"></a>

14. **师旷劝晋侯不要只责卫臣逐君，也要看到国君失职。** 他认为立君是为养民，不是让一人放纵欲望。各层官员、亲族、朋友、史官、乐工和百姓，都应当能纠正上位者的过错。 [看原文与说明](#note-14)

<a id="event-15"></a>

15. **秋，楚子囊伐吴，回军时在皋舟隘口战败。** 吴军先不出战，楚军以为吴无能而松懈。撤回时被截击，前后不能相救，公子宜穀被吴人俘获。 [看原文与说明](#note-15)

<a id="event-16"></a>

16. **周王派刘定公赐齐灵公命。** 册命追述太公辅周的旧功，要求齐侯环承继祖先职守，不废王命。 [看原文与说明](#note-16)

<a id="event-17"></a>

17. **冬，诸侯大夫会于戚，暂时承认卫国的新局面。** 荀偃劝晋侯不要立即为卫国废立劳师动众，而应先稳住已形成的政权，等待时机。 [看原文与说明](#note-17)

<a id="event-18"></a>

18. **范宣子向齐国借羽毛而不归还，齐国开始怀有二心。**  [看原文与说明](#note-18)

<a id="event-19"></a>

19. **子囊从吴国战场回来后去世，临终仍要求修筑郢都。** 他把加强国都防御作为遗言，交代给子庚。 [看原文与说明](#note-19)

<a id="event-20"></a>

20. **本年，莒军也侵入鲁国东境。**  [看原文与说明](#note-20)

<a id="event-21"></a>

21. **楚康王元年。** 上年楚共王去世后，康王继立；本年是康王纪年的第一年，不重复记一次共王去世。 [看原文与说明](#note-21)

> 十四年春，吴告败于晋。会于向，为吴谋楚故也。范宣子数吴之不德也，以退吴人。执莒公子务娄，以其通楚使也。将执戎子驹支。范宣子亲数诸朝，曰：“来！姜戎氏，昔秦人迫逐乃祖吾离于瓜州，乃祖吾离被苫盖，蒙荆棘，以来归我先君。我先君惠公有不腆之田，与女剖分而食之。今诸侯之事我寡君，不如昔者，盖言语漏洩，则职女之由。诘朝之事，尔无与焉！与将执女！”对曰：“昔秦人负恃其众，贪于土地，逐我诸戎。惠公蠲其大德，谓我诸戎是四岳之裔胄也，毋是翦弃。赐我南鄙之田，狐狸所居，豺狼所嗥。我诸戎除翦其荆棘，驱其狐狸豺狼，以为先君不侵不叛之臣，至于今不贰。昔文公与秦伐郑，秦人窃与郑盟而舍戍焉，于是乎有殽之师。晋御其上，戎亢其下，秦师不复，我诸戎实然。譬如捕鹿，晋人角之，诸戎掎之，与晋踣之，戎何以不免？自是以来，晋之百役，与我诸戎相继于时，以从执政，犹殽志也。岂敢离逷？今官之师旅，无乃实有所阙，以携诸侯，而罪我诸戎！我诸戎饮食衣服，不与华同，贽币不通，言语不达，何恶之能为？不与于会，亦无瞢焉！”赋《青蝇》而退。宣子辞焉，使即事于会，成恺悌也。于是，子叔齐子为季武子介以会，自是晋人轻鲁币，而益敬其使。

### 7. 栾鍼独攻秦军战死，士鞅因此被迫逃秦

**说明：**士鞅向秦君预测栾盈将承受栾黡积怨，是此时谈话中的推断；不把后来栾氏的败亡提前列作本年已发生。

<details>
<summary>《左传》传 T004｜原文</summary>

> 栾鍼曰：“此役也，报栎之败也。役又无功，晋之耻也。吾有二位于戎路，敢不耻乎？”与士鞅驰秦师，死焉。士鞅反，栾黡谓士匄曰：“余弟不欲往，而子召之。余弟死，而子来，是而子杀余之弟也。弗逐，余亦将杀之。”士鞅奔秦。于是，齐崔杼、宋华阅、仲江会伐秦，不书，惰也。向之会亦如之。卫北宫括不书于向，书于伐秦，摄也。

### 12. 卫人拥立公孙剽，鲁国分别慰问卫国臣下和流亡国君

**说明：**两位鲁使关于卫君能否复国的判断不同，正文并存呈现其当时所见，不用后来的结局倒改其言论。

<details>

### 14. 师旷劝晋侯不要只责卫臣逐君，也要看到国君失职

<details>
<summary>《左传》传 T014｜原文</summary>

> 师旷恃于晋侯。晋侯曰：“卫人出其君，不亦甚乎？”对曰：“或者其君实甚。良君将赏善而刑淫，养民如子，盖之如天，容之如地。民奉其君，爱之如父母，仰之如日月，敬之如神明，畏之如雷霆，其可出乎？夫君，神之主而民之望也。若困民之主，匮神乏祀，百姓绝望，社稷无主，将安用之？弗去何为？天生民而立之君，使司牧之，勿使失性。有君而为之贰，使师保之，勿使过度。是故天子有公，诸侯有卿，卿置侧室，大夫有贰宗，士有朋友，庶人、工、商、皂、隶、牧、圉皆有亲暱，以相辅佐也。善则赏之，过则匡之，患则救之，失则革之。自王以下，各有父兄子弟，以补察其政。史为书，瞽为诗，工诵箴谏，大夫规诲，士传言，庶人谤，商旅于市，百工献艺。故《夏书》曰：‘遒人以木铎徇于路。官师相规，工执艺事以谏。’正月孟春，于是乎有之，谏失常也。天之爱民甚矣。岂其使一人肆于民上，以从其淫，而弃天地之性？必不然矣。”

### 21. 楚康王元年

[《史记》卷014《十二诸侯年表》前559年楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0559)记“楚康王昭元年”；[《楚世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-1fc21f1160825e)记共王去世后“子康王招立”。**异文：**年表作“昭”，世家作“招”，暂保留两种写法。共王去世已在[前560年事件5](bce-0560.md#event-5)叙述，元年不等于再一次即位。《年表》同栏另有“共王太子出奔吴”，其人物与纪年另待互校，暂不将它混入本条确定史事。

<a id="event-1"></a>

1. **春，鲁襄公从晋国返回，孟献子把出行功劳记告宗庙。** [[1]](#note-1)

<a id="event-2"></a>

2. **夏，鲁国出兵救邿，最后把邿国据为己有。** 邿国内乱，分成三派，鲁军以救援名义进入，乘势取得其地。 [[2]](#note-2)

<a id="event-3"></a>

3. **荀罃、士鲂去世，晋国重新安排军中主将。** 晋侯在绵上阅兵，士匄把中军主将之位让给年长的荀偃；赵武任上军将，韩起辅佐；栾黡任下军将，魏绛辅佐。新军没有合适主帅，所属官兵暂并入下军。 [[3]](#note-3)

<a id="event-4"></a>

<a id="event-5"></a>

<a id="event-6"></a>

4. **楚共王去世，吴趁丧进犯而败于庸浦。** 楚共王病重，自责年幼即位，又败于鄢陵，请谥为灵或厉。九月庚辰，楚共王去世，在位三十一年。子囊认为能自知其过足以谥共，众大夫从之。其子招继为楚康王。吴国乘楚丧出兵，养由基料吴必轻敌，与子庚设伏，在庸浦击败吴军，俘吴公子党。 [[4]](#note-4)

<a id="event-7"></a>

5. **冬，鲁国等农事结束后才修筑防城。** 原本打算提前开工，臧武仲请求先让百姓完成农事，工程因而推迟。 [[5]](#note-7)

<a id="event-8"></a>

6. **楚国释放此前扣留的郑国使者良霄、石毚。** 石毚向子囊解释，扣着郑国一位卿，反会减少郑国内部竞争，使其更稳定地亲晋；放他们回去，才可能增加郑国君臣间的牵制。楚人接受了这个说法。 [[6]](#note-8)

<a id="event-9"></a>

7. **吴诸樊元年。** 吴王寿梦去世后，诸樊继位，本年为其元年。 [[7]](#note-9)

**[《左传》](../../拆分史书/左传/bce-0560.md#t003)**

> 荀罃、士鲂卒。晋侯蒐于绵上以治兵，使士匄将中军，辞曰：“伯游长。昔臣习于知伯，是以佐之，非能贤也。请从伯游。”荀偃将中军，士匄佐之。使韩起将上军，辞以赵武。又使栾黡，辞曰：“臣不如韩起。韩起愿上赵武，君其听之！”使赵武将上军，韩起佐之。栾黡将下军，魏绛佐之。新军无帅，晋侯难其人，使其什吏，率其卒乘官属，以从于下军，礼也。晋国之民，是以大和。诸侯遂睦。君子曰：“让，礼之主也。范宣子让，其下皆让。栾黡为汰，弗敢违也。晋国以平，数世赖之。刑善也夫！一人刑善，百姓休和，可不务乎？《书》曰：‘一人有庆，兆民赖之，其宁惟永。’其是之谓乎？周之兴也，其《诗》曰：‘仪刑文王，万邦作孚。’言刑善也。及其衰也，其《诗》曰：‘大夫不均，我从事独贤。’言不让也。世之治也，君子尚能而让其下，小人农力以事其上，是以上下有礼，而谗慝黜远，由不争也。谓之懿德。及其乱也，君子称其功以加小人，小人伐其技以冯君子，是以上下无礼，乱虐并生，由争善也。谓之昏德。国家之敝，恒必由之。”

##### 让位年次与吴楚交战的分离

旧稿按《吴太伯世家》诸樊元年，将除丧让季札、季札以子臧为例拒位、离家耕田，以及秋吴攻楚一并归在前560年。《左传》却把诸樊让位放在襄公十四年春，即前559年；吴楚庸浦之战仍在本年。让位过程的正文现在见[前559年同一事件](bce-0559.md#event-3)，不在两个年份重复发生。

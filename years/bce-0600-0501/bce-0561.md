# 公元前561年（鲁襄公12年）

<a id="reading-start"></a>

> 本页合并本年《春秋》《左传》及已核《史记》互见；月份沿用古史年条。回叙、后续与作者评论在相应史料注中区分，不据叙述位置强造发生年。

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **春二月，莒军围台，季孙宿救台后攻入郓地。** 鲁军取回郓地的钟，用来制作国君的盘器。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，晋国士鲂来鲁聘问并致谢。** 此次致谢针对鲁国此前参加诸侯军事行动。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋九月，吴王寿梦去世，鲁国在周庙举哀。** 鲁国按同姓诸侯的亲疏关系选择吊丧场所；对吴国的丧事，采用在周庙临哭的礼节。 [[3]](#note-3)

<a id="event-4"></a>

4. **冬，楚、秦攻宋，报复晋国取得郑国归附。** 楚子囊与秦国庶长无地驻军扬梁，把宋国作为施压对象。 [[4]](#note-4)

<a id="event-5"></a>

5. **周灵王向齐国求后，齐侯答应婚事。** 齐侯先问晏桓子该怎样答复天子求婚，随后由王室使者阴里把婚约落实。 [[5]](#note-5)

<a id="event-6"></a>

6. **鲁襄公再赴晋国朝见。** 他也向晋国答谢士鲂来鲁聘问。 [[6]](#note-6)

<a id="event-7"></a>

7. **秦嬴嫁入楚国，楚司马子庚随后聘秦。** 这次聘问兼有替楚国夫人向母家问安的目的。 [[7]](#note-7)

<a id="sj-031-L2952-01"></a>

#### 《史记》互见｜寿梦去世，诸樊暂掌国事

**时间：寿梦二十五年／鲁襄公十二年** · 事件

寿梦有诸樊、余祭、余眛、季札四个儿子。他原想立季札，季札不肯，便由长子诸樊主持国事。寿梦去世的年份可以与《左传》相核。

[《史记》卷31 吴太伯世家](../../sources/摘录/史记-条目原文.md#ref-sj-2952) · [《春秋／左传》鲁襄公12年](../../sources/摘录/史记-条目原文.md#ref-zz-9-12)

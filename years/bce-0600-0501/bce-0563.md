## 本年纪事

<a id="event-1"></a>

1. **诸侯会于柤，与吴王寿梦接续关系。** 齐太子光由高厚陪同先到钟离会诸侯，因礼数不敬受到晋方批评，随后各国在柤会合。 [看原文与说明](#note-1)

<a id="event-2"></a>

2. **荀偃、士匄坚持攻打偪阳，联军一开始久攻不下。** 荀罃原先认为城虽小却坚固，胜之不足耀武，败则招笑。攻城时，郰人纥撑住落下的悬门，救出入门士卒；狄虒弥以大车轮覆甲作盾，秦堇父则沿敌人垂下的布攀城，数次坠落后再登。 [看原文与说明](#note-2)

<a id="event-3"></a>

3. **荀罃拒绝无功退军，限七日攻克偪阳。** 荀偃、士匄因雨水将至而请撤军，荀罃责他们先强求出兵、如今又想把撤军责任推给主帅，要求二人自己解决。 [看原文与说明](#note-3)

<a id="event-4"></a>

4. **五月甲午，偪阳被攻破，土地交给宋国。** 荀偃、士匄亲受矢石督战。晋国本想把偪阳封给向戌，向戌拒绝，认为不能兴诸侯之师来给自己封地，最终改归宋公。秦堇父因战中表现，回师后被孟献子任为车右。 [看原文与说明](#note-4)

<a id="event-5"></a>

5. **鲁襄公从会盟返回。**  [看原文与说明](#note-5)

<a id="event-6"></a>

6. **宋公用桑林乐招待晋侯，晋侯见舞旗后惊退。** 撤去舞旗才完成宴礼。返途中晋侯生病，有人要回宋请祷，荀罃认为晋方本已辞让，不应再去。晋人又把偪阳君带回献于武宫，并安排其族中后嗣居于霍人。 [看原文与说明](#note-6)

<a id="event-7"></a>

7. **六月，楚、郑联合伐宋，进兵到宋都门外。** 楚子囊、郑子耳驻军訾毋，又围宋并攻桐门。 [看原文与说明](#note-7)

<a id="event-8"></a>

8. **晋荀罃率军伐秦，报复秦国入侵。**  [看原文与说明](#note-8)

<a id="event-9"></a>

9. **卫国救宋，郑国遂奉楚命侵卫，反被卫军俘获皇耳。** 郑子展认为既已得罪晋国，不能再违背楚国。卫孙蒯追击郑军，在大丘擒获郑将皇耳。 [看原文与说明](#note-9)

<a id="event-10"></a>

10. **秋，鲁国西境遭楚、郑进攻，东境又受莒国攻击。** 楚、郑回军后还包围萧，八月克萧，九月再侵宋国北境；莒国则趁诸侯忙于别处，进攻鲁国东方。 [看原文与说明](#note-10)

<a id="event-11"></a>

11. **诸侯再伐郑，齐太子光抢先到军中。** 齐方让太子先至，因此获得排在滕国之前的次序；联军驻牛首。 [看原文与说明](#note-11)

<a id="event-12"></a>

12. **郑国多家贵族因军职与田地争端怨恨子驷。** 尉止因战车编制、献俘等问题与子驷争执；司氏、堵氏、侯氏、子师氏又在开田沟时失去土地，遂联合失意者准备发动变乱。 [看原文与说明](#note-12)

<a id="event-13"></a>

13. **冬十月，叛乱者闯入西宫，杀死子驷、子国、子耳。** 尉止等清晨袭击执政所在的朝廷，又劫持郑君到北宫。子孔事先知道消息，因此没有遇害。 [看原文与说明](#note-13)

<a id="event-14"></a>

14. **子产先守府库、整兵备，再率车兵反击，平定北宫之乱。** 子西仓促奔出后才回去授甲，家中多人逃散、器物丢失。子产则先封闭府库、安顿各官，带十七乘兵车出击；子蟜率国人相助，叛军主力被歼，其余逃晋、宋。 [看原文与说明](#note-14)

<a id="event-15"></a>

15. **子孔执政后企图用载书重新约束大夫，子产劝他烧掉，以平众怒。** 子产指出一意专行又触犯众怒，只会让国家更危险。子孔最终在仓门外焚书，局势才安定。 [看原文与说明](#note-15)

<a id="event-16"></a>

16. **晋国与诸侯修筑虎牢，并在梧、制等处设防。** 士鲂、魏绛驻守，晋国借这些据点继续逼郑。 [看原文与说明](#note-16)

<a id="event-17"></a>

17. **楚军救郑，晋楚隔颍水对峙，郑国夜间再与楚结盟。** 晋军内部一度争论退进，最终并未决战。荀罃认为既不能挡楚、又不能保郑，就不应独怪郑国；诸侯侵郑北境后撤退，楚军也归国，鲁襄公随军返鲁。 [看原文与说明](#note-17)

<a id="event-18"></a>

18. **周王叔陈生与伯舆争政，晋士匄出面调停。** 双方在王庭争论出身、旧功、贿赂与政刑，并核对文契。王叔一方拿不出约契，最终逃往晋国，单靖公接任卿士辅佐王室。 [看原文与说明](#note-18)

### 18. 周王叔陈生与伯舆争政，晋士匄出面调停

<details>
<summary>《左传》传 T020｜原文</summary>

> 王叔陈生与伯舆争政。王右伯舆，王叔陈生怒而出奔。及河，王复之，杀史狡以说焉。不入，遂处之。晋侯使士匄平王室，王叔与伯舆讼焉。王叔之宰与伯舆之大夫瑕禽，坐狱于王庭，士匄听之。王叔之宰曰：“筚门闺窦之人而皆陵其上，其难为上矣！”瑕禽曰：“昔平王东迁，吾七姓从王，牲用备具。王赖之，而赐之骍旄之盟，曰：‘世世无失职。’若筚门闺窦，其能来东底乎？且王何赖焉？今自王叔之相也，政以贿成，而刑放于宠，官之师旅，不胜其富。吾能无筚门闺窦乎？唯大国图之！下而无直，则何谓正矣？”范宣子曰：“天子所右，寡君亦右之。所左，亦左之。”使王叔氏与伯舆合要，王叔氏不能举其契。王叔奔晋。不书，不告也。单靖公为卿士，以相王室。

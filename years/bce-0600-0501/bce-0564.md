## 本年纪事

<a id="event-1"></a>

1. **春，宋国发生大火，子罕组织分区救灾。** 他命人拆小屋、涂护大屋，备水桶、绳索、土料，清出防火通道；同时调集役夫，保护府库、宫室、车马和兵器，避免火灾连带造成城防失控。 [看原文与说明](#note-1)

<a id="event-2"></a>

2. **晋侯询问宋灾与天道的关系，士弱以宋国祭火传统作答。** 士弱讲起阏伯居商丘、商人用大火星纪时的旧传，又说明不能只凭一种现象断定国运；国家失序时，更难用固定征兆判断。 [看原文与说明](#note-2)

<a id="event-3"></a>

3. **夏，季孙宿赴晋回聘。** 他回报士匄此前来鲁的聘问。 [看原文与说明](#note-3)

<a id="event-4"></a>

4. **五月辛酉，穆姜死于东宫。** 此前被安置到东宫时，卜者曾说她很快可以出去。穆姜却认为自己参与动乱、失去应有品德，不能只凭一个吉卦免去过错，因而断定会死在这里。 [看原文与说明](#note-4)

<a id="event-5"></a>

5. **八月癸未，鲁国安葬穆姜。**  [看原文与说明](#note-5)

<a id="event-6"></a>

6. **秦国请求楚国配合伐晋，楚王虽知晋国整齐强盛，仍出兵作援。** 子囊列举晋国君臣的用人、谦让和农工商各守其业，劝勿与晋争锋。楚王以已经答应秦国为由，秋天仍驻军武城；秦军侵晋，晋国因饥荒没有反击。 [看原文与说明](#note-6)

<a id="event-7"></a>

7. **冬，晋国率诸侯多路攻郑，逼郑求和。** 联军分别进攻城门、砍伐行道栗树，并在氾地整备器械粮食，把老弱送回、病者安置虎牢。郑国请求和议后，荀罃主张受盟退军，用轮换军队消耗楚国，不必冒险决战。 [看原文与说明](#note-7)

<a id="event-8"></a>

8. **戏地盟誓中，郑国拒绝承诺无条件服从晋国。** 晋方拟定‘唯晋命是听’，郑方改称愿追随有礼而强、能够保护百姓的一方。荀罃承认晋国还不能充分庇郑，劝不要靠强迫盟誓解决一切，双方最终订盟。 [看原文与说明](#note-8)

<a id="event-9"></a>

9. **晋国随后又攻郑，联军到阴口后撤退。** 晋方仍未满意，十二月再攻郑国三门，闰月进兵。子孔想趁晋军疲惫追击，子展反对。 [看原文与说明](#note-9)

<a id="event-10"></a>

10. **鲁襄公在返程中于卫国举行冠礼。** 晋侯在河上宴请襄公，询问年龄后建议行冠礼。季武子表示在旅途中缺少礼乐器具，便借卫国成公庙与钟磬完成仪式。 [看原文与说明](#note-10)

<a id="event-11"></a>

11. **楚军再来伐郑，郑国又与楚讲和。** 子驷、子展认为先前盟辞本就允许服从能够庇民的强者，晋国此时不能救援。双方在中分同盟；楚庄夫人去世，楚王尚未进一步安定郑国便返国。 [看原文与说明](#note-11)

<a id="event-12"></a>

12. **晋悼公回国后减轻负担，调出积存财物赈贷百姓。** 魏绛建议从国君以下凡有积聚者都拿出来周济，同时节省器用、车服和礼仪开支，让国内没有闲置积蓄，也减少困穷之家。 [看原文与说明](#note-12)

### 2. 晋侯询问宋灾与天道的关系，士弱以宋国祭火传统作答

**说明：**这里记录士弱的历史、星象解释，不把古代灾异观作为现代意义的因果判断。

<details>
<summary>《左传》传 T002｜原文</summary>

> 晋侯问于士弱曰：“吾闻之，宋灾，于是乎知有天道。何故？”对曰：“古之火正，或食于心，或食于咮，以出内火。是故咮为鹑火，心为大火。陶唐氏之火正阏伯居商丘，祀大火，而火纪时焉。相土因之，故商主大火。商人阅其祸败之衅，必始于火，是以日知其有天道也。”公曰：“可必乎？”对曰：“在道。国乱无象，不可知也。”

### 4. 五月辛酉，穆姜死于东宫

[回到原文位置](../../sources/春秋左传/有标点原文/bce-0564.md#j003)

<details>
<summary>《左传》传 T004｜原文</summary>

> 穆姜薨于东宫。始往而筮之，遇《艮》之八。史曰：“是谓《艮》之《随》。《随》，其出也。君必速出。”姜曰：“亡。是於《周易》曰：‘《随》，元、享、利，贞，无咎，’元，体之长也。享，嘉之会也。利，义之和也。贞，事之幹也。体仁足以长人，嘉德足以合礼，利物足以和义，贞固足以幹事。然故不可诬也，是以虽《随》无咎。今我妇人而与于乱。固在下位而有不仁，不可谓元。不靖国家，不可谓亨。作而害身，不可谓利。弃位而姣，不可谓贞。有四德者，《随》而无咎。我皆无之，岂《随》也哉？我则取恶，能无咎乎？必死于此，弗得出矣。”

<details>
<summary>《左传》传 T008｜原文</summary>

> 十一月己亥，同盟于戏，郑服也。将盟，郑六卿公子騑、公子发、公子嘉、公孙辄、公孙虿、公孙舍之及其大夫、门子皆从郑伯。晋士庄子为载书，曰：“自今日既盟之后，郑国而不唯晋命是听，而或有异志者，有如此盟。”公子趋进曰：“天祸郑国，使介居二大国之间。大国不加德音而乱以要之，使其鬼神不获歆其禋祀，其民人不获享其土利，夫妇辛苦垫隘，无所厎告。自今日既盟之后，郑国而不唯有礼与强可以庇民者是从，而敢有异志者，亦如之。”荀偃曰：“改载书。”公孙舍之曰：“昭大神，要言焉。若可改也，大国亦可叛也。”知武子谓献子曰：“我实不德，而要人以盟，岂礼也哉！非礼，何以主盟？姑盟而退，修德息师而来，终必获郑，何必今日？我之不德，民将弃我，岂唯郑？若能休和，远人将至，何恃于郑？”乃盟而还。

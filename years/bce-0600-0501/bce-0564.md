<a id="本年纪事"></a>
<a id="event-1"></a>

1. **春，宋国发生大火，子罕组织分区救灾。** 他命人拆小屋、涂护大屋，备水桶、绳索、土料，清出防火通道；同时调集役夫，保护府库、宫室、车马和兵器，避免火灾连带造成城防失控。 [[1]](#note-1)

<a id="event-2"></a>

2. **晋侯询问宋灾与天道的关系，士弱以宋国祭火传统作答。** 士弱讲起阏伯居商丘、商人用大火星纪时的旧传，又说明不能只凭一种现象断定国运；国家失序时，更难用固定征兆判断。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，季孙宿赴晋回聘。** 他回报士匄此前来鲁的聘问。 [[3]](#note-3)

<a id="event-4"></a>

4. **五月辛酉，穆姜死于东宫。** 此前被安置到东宫时，卜者曾说她很快可以出去。穆姜却认为自己参与动乱、失去应有品德，不能只凭一个吉卦免去过错，因而断定会死在这里。 [[4]](#note-4)

<a id="event-5"></a>

5. **八月癸未，鲁国安葬穆姜。** [[5]](#note-5)

<a id="event-6"></a>

6. **秦国请求楚国配合伐晋，楚王虽知晋国整齐强盛，仍出兵作援。** 子囊列举晋国君臣的用人、谦让和农工商各守其业，劝勿与晋争锋。楚王以已经答应秦国为由，秋天仍驻军武城；秦军侵晋，晋国因饥荒没有反击。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬，晋国率诸侯多路攻郑，逼郑求和。** 联军分别进攻城门、砍伐行道栗树，并在氾地整备器械粮食，把老弱送回、病者安置虎牢。郑国请求和议后，荀罃主张受盟退军，用轮换军队消耗楚国，不必冒险决战。 [[7]](#note-7)

<a id="event-8"></a>

8. **戏地盟誓中，郑国拒绝承诺无条件服从晋国。** 晋方拟定‘唯晋命是听’，郑方改称愿追随有礼而强、能够保护百姓的一方。荀罃承认晋国还不能充分庇郑，劝不要靠强迫盟誓解决一切，双方最终订盟。 [[8]](#note-8)

<a id="event-9"></a>

9. **晋国随后又攻郑，联军到阴口后撤退。** 晋方仍未满意，十二月再攻郑国三门，闰月进兵。子孔想趁晋军疲惫追击，子展反对。 [[9]](#note-9)

<a id="event-10"></a>

10. **鲁襄公在返程中于卫国举行冠礼。** 晋侯在河上宴请襄公，得知他按当时计岁已十二岁，便建议行冠礼。季武子表示在旅途中缺少礼乐器具，便借卫国成公庙与钟磬完成仪式。 [[10]](#note-10)

<a id="event-11"></a>

11. **楚军再来伐郑，郑国又与楚讲和。** 子驷、子展认为先前盟辞本就允许服从能够庇民的强者，晋国此时不能救援。双方在中分同盟；楚庄夫人去世，楚王尚未进一步安定郑国便返国。 [[11]](#note-11)

<a id="event-12"></a>

12. **晋悼公回国后减轻负担，调出积存财物赈贷百姓。** 魏绛建议从国君以下凡有积聚者都拿出来周济，同时节省器用、车服和礼仪开支，让国内没有闲置积蓄，也减少困穷之家。 [[12]](#note-12)

<a id="event-13"></a>
<a id="sj014-0564-shicao"></a>

13. **卫献公让师曹教宫妾弹琴，责打与报复由此结下旧怨。** 师曹因她琴艺不善而责打她，宫妾向献公诉怨，献公又命鞭打师曹三百下。师曹因此怨恨国君；后来他借奏诗激怒孙氏，是五年后卫国内乱的前情，不是本年已经把献公逐走。 [[13]](#note-13)

### 11. 楚军再来伐郑，郑国又与楚讲和

[返回正文第11条](#event-11)

**[《左传》](../../sources/春秋左传/有标点原文/bce-0564.md#t011)**

> 与大国盟，口血未乾而背之，可乎

**[《左传》](../../sources/春秋左传/有标点原文/bce-0564.md#t011)**

> 吾盟固云：‘唯强是从。’今楚师至，晋不我救，则楚强矣。盟誓之言，岂敢背之。且要盟无质，神弗临也，所临唯信。信者，言之瑞也，善之主也，是故临之。明神不蠲要盟，背之可也

#### 13. 师曹与卫献公结怨：有年旧事不留在五年后的回叙里

[卷014前564年卫栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0564)在献公十三年记“师曹鞭公幸妾”；[《卫康叔世家》献公段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-77589a24f8a816)也明确在十三年写教琴、责打宫妾与献公笞曹三百，然后另起十八年的逐君经过。故将这一已给年次的旧事补入本年，而不是把它全定在[前559年师曹奏诗](bce-0559.md#event-8)时。

[《左传》襄公十四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E8%A5%84%E5%85%AC.md#ref-ebcfe99f86e336)用“初”回叙同一旧怨，接到报复性奏诗，未独立给出旧怨的发生年；与本页的处理并不冲突。三百是传世叙事的记数，不补行刑细节、宫妾姓名和月份。此事与本年卫军从晋伐郑是同一国栏中的不同事项，不因合写一格就安排在同一天；也不把音乐冲突当作五年后逐君的唯一原因。

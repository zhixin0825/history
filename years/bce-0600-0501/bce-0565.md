1. **鲁襄公赴晋，晋在邢丘规定诸侯朝聘次数。** 正月，鲁襄公至晋朝见。晋侯在邢丘召集诸国，规定朝见和聘问的次数。 [[1]](#note-1)

<a id="event-2"></a>

<a id="event-3"></a>

2. **郑简公元年，子驷清除政敌并葬郑僖公。** 郑简公嘉本年元年。因郑僖公被杀，郑国政争再起，子驷先下手清除反对者。夏，郑安葬僖公。 [[2]](#note-2)

<a id="event-4"></a>

<a id="event-9"></a>

<a id="event-10"></a>

<a id="event-11"></a>

3. **郑侵蔡，楚伐郑报复，晋准备对郑用兵。** 郑军侵蔡，俘获蔡国司马公子燮，子产却担忧这场胜利。子国、子耳带兵取胜，郑人普遍高兴。子产认为小国没有足够的德政却逞武功，会招楚国来讨。若服楚，晋军又会来，郑国将连年受兵。父亲子国因而责骂他多言。冬，楚子囊伐郑，报复郑国侵蔡。楚军焚烧郊外聚落、逼近城郭，郑国男女忙于救援，伤亡与流离使国内承受很大压力。郑国大夫争论到底该服楚，还是坚守待晋。子驷认为先服眼前强者，可以让百姓暂缓痛苦。子展则主张守信待晋，认为反复改盟会招来无休止的战争。子驷最后承担责任，推动与楚讲和。郑国向晋国解释降楚是被战火逼迫，晋国不接受。王子伯骈详述郑国奉命攻蔡、如今被楚报复的困境。晋方仍认为郑国未经告知就先安于楚，并表示将率诸侯到郑城下问罪。晋国士匄来鲁聘问，通知将对郑国用兵。鲁国以宴饮、赋诗回应，表示愿意承命。士匄也借城濮受赐彤弓的旧事，表明自己继承先君臣职的责任。 [[3]](#note-4)

<a id="event-6"></a>

4. **莒人进攻鲁国东境，争划鄫国旧地。** 鄫灭之后，鲁、莒的土地冲突仍未结束。 [[4]](#note-6)

<a id="event-7"></a>

<a id="hs-event-12"></a>

5. **鲁国九月因旱举行大雩。** [[5]](#note-7)

> 冬，楚子囊伐郑，讨其侵蔡也。子驷、子国、子耳欲从楚，子孔、子蟜、子展欲待晋。子驷曰：“《周诗》有之曰：‘俟河之清，人寿几何？兆云询多，职竞作罗。’谋之多族，民之多违，事滋无成。民急矣，姑从楚以纾吾民。晋师至，吾又从之。敬共币帛，以待来者，小国之道也。牺牲玉帛，待于二竟，以待疆者而庇民焉。寇不为害，民不罢病，不亦可乎？”子展曰：“小所以事大，信也。小国无信，兵乱日至，亡无日矣。五会之信，今将背之，虽楚救我，将安用之？亲我无成，鄙我是欲，不可从也。不如待晋。晋君方明，四军无阙，八卿和睦，必不弃郑。楚师辽远，粮食将尽，必将速归，何患焉？舍之闻之：‘杖莫如信。’完守以老楚，杖信以待晋，不亦可乎？”子驷曰：“《诗》云：‘谋夫孔多，是用不集，发言盈庭，谁敢执其咎？如匪行迈谋，是用不得于道。’请从楚，騑也受其咎。”

> 乃及楚平。使王子伯骈告于晋，曰：“君命敝邑：‘修而车赋，儆而师徒，以讨乱略。’蔡人不从，敝邑之人，不敢宁处，悉索敝赋，以讨于蔡，获司马燮，献于邢丘。今楚来讨曰：‘女何故称兵于蔡？’焚我郊保，冯陵我城郭。敝邑之众，夫妇男女，不皇启处，以相救也。翦焉倾覆，无所控告。民死亡者，非其父兄，即其子弟，夫人愁痛，不知所庇。民知穷困，而受盟于楚，孤也与其二三臣不能禁止。不敢不告。”知武子使行人子员对之曰：“君有楚命，亦不使一个行李告于寡君，而即安于楚。君之所欲也，谁敢违君。寡君将帅诸侯以见于城下，唯君图之！”

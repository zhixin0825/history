# 公元前565年（鲁襄公8年）

## 本年纪事

<a id="event-1"></a>

1. **春正月，鲁襄公赴晋朝见，并听取朝聘次数的安排。**  [看原文与说明](#note-1)

<a id="event-2"></a>

2. **郑简公嘉元年，郑国围绕僖公被杀再起政争，子驷先下手清除反对者。** 简公已在上年僖公遇害后继位，本年是其元年。几位公子因僖公之死图谋对付子驷。四月，子狐、子熙、子侯、子丁被杀，孙击、孙恶逃往卫国。 [看原文与说明](#note-2)

<a id="event-3"></a>

3. **夏，郑僖公下葬。**  [看原文与说明](#note-3)

<a id="event-4"></a>

4. **郑军侵蔡，俘获蔡国司马公子燮，子产却担忧这场胜利。** 子国、子耳带兵取胜，郑人普遍高兴。子产认为小国没有足够的德政却逞武功，会招楚国来讨；若服楚，晋军又会来，郑国将连年受兵。父亲子国因而责骂他多言。 [看原文与说明](#note-4)

<a id="event-5"></a>

5. **晋侯在邢丘会集诸国，规定朝见、聘问的次数。** 季孙宿与齐、宋、卫、邾等国大夫听命；郑伯因亲自献蔡国战俘，也到场受命。鲁襄公随后从晋国返回。 [看原文与说明](#note-5)

<a id="event-6"></a>

6. **莒人进攻鲁国东境，争划鄫国旧地。** 鄫灭之后，鲁、莒的土地冲突仍未结束。 [看原文与说明](#note-6)

<a id="event-7"></a>

7. **秋九月，鲁国因旱举行大雩。**  [看原文与说明](#note-7)

<a id="event-8"></a>

8. **冬，楚子囊伐郑，报复郑国侵蔡。** 楚军焚烧郊外聚落、逼近城郭，郑国男女忙于救援，伤亡与流离使国内承受很大压力。 [看原文与说明](#note-8)

<a id="event-9"></a>

9. **郑国大夫争论到底该服楚，还是坚守待晋。** 子驷认为先服眼前强者，可以让百姓暂缓痛苦；子展则主张守信待晋，认为反复改盟会招来无休止的战争。子驷最后承担责任，推动与楚讲和。 [看原文与说明](#note-9)

<a id="event-10"></a>

10. **郑国向晋国解释降楚是被战火逼迫，晋国不接受。** 王子伯骈详述郑国奉命攻蔡、如今被楚报复的困境。晋方仍认为郑国未经告知就先安于楚，并表示将率诸侯到郑城下问罪。 [看原文与说明](#note-10)

<a id="event-11"></a>

11. **晋国士匄来鲁聘问，通知将对郑国用兵。** 鲁国以宴饮、赋诗回应，表示愿意承命；士匄也借城濮受赐彤弓的旧事，表明自己继承先君臣职的责任。 [看原文与说明](#note-11)

### 8. 冬，楚子囊伐郑，报复郑国侵蔡

<details>
<summary>《春秋》经 J008｜原文</summary>

> 冬，楚公子贞帅师伐郑。

[回到原文位置](../../sources/春秋左传/有标点原文/bce-0565.md#j008)

</details>

<details>
<summary>《左传》传 T008｜原文</summary>

> 冬，楚子囊伐郑，讨其侵蔡也。子驷、子国、子耳欲从楚，子孔、子蟜、子展欲待晋。子驷曰：“《周诗》有之曰：‘俟河之清，人寿几何？兆云询多，职竞作罗。’谋之多族，民之多违，事滋无成。民急矣，姑从楚以纾吾民。晋师至，吾又从之。敬共币帛，以待来者，小国之道也。牺牲玉帛，待于二竟，以待疆者而庇民焉。寇不为害，民不罢病，不亦可乎？”子展曰：“小所以事大，信也。小国无信，兵乱日至，亡无日矣。五会之信，今将背之，虽楚救我，将安用之？亲我无成，鄙我是欲，不可从也。不如待晋。晋君方明，四军无阙，八卿和睦，必不弃郑。楚师辽远，粮食将尽，必将速归，何患焉？舍之闻之：‘杖莫如信。’完守以老楚，杖信以待晋，不亦可乎？”子驷曰：“《诗》云：‘谋夫孔多，是用不集，发言盈庭，谁敢执其咎？如匪行迈谋，是用不得于道。’请从楚，騑也受其咎。”

### 10. 郑国向晋国解释降楚是被战火逼迫，晋国不接受

<details>
<summary>《左传》传 T009｜原文</summary>

> 乃及楚平。使王子伯骈告于晋，曰：“君命敝邑：‘修而车赋，儆而师徒，以讨乱略。’蔡人不从，敝邑之人，不敢宁处，悉索敝赋，以讨于蔡，获司马燮，献于邢丘。今楚来讨曰：‘女何故称兵于蔡？’焚我郊保，冯陵我城郭。敝邑之众，夫妇男女，不皇启处，以相救也。翦焉倾覆，无所控告。民死亡者，非其父兄，即其子弟，夫人愁痛，不知所庇。民知穷困，而受盟于楚，孤也与其二三臣不能禁止。不敢不告。”知武子使行人子员对之曰：“君有楚命，亦不使一个行李告于寡君，而即安于楚。君之所欲也，谁敢违君。寡君将帅诸侯以见于城下，唯君图之！”

## 本年纪事

<a id="event-1"></a>

1. **春，郯君首次朝见鲁襄公。**  [[1]](#note-1)

<a id="event-2"></a>

2. **夏四月，鲁国三次占卜郊祭都不吉，取消了这次祭祀。** 孟献子认为农事已经开始，此时才卜郊，时机本就太迟。 [[2]](#note-2)

<a id="event-3"></a>

3. **小邾穆公也首次来朝鲁襄公。**  [[3]](#note-3)

<a id="event-4"></a>

4. **季氏修筑费城，工程背后有家臣间的相互拉拢。** 费宰南遗得到叔仲昭伯支持；昭伯为了讨好季氏，答应多派役夫，促成筑城。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋，季孙宿出使卫国，回报卫国先前的聘问。** 他也解释回聘较晚并不是怀有二心。 [[5]](#note-5)

<a id="event-6"></a>

6. **八月，鲁国发生螽灾。**  [[6]](#note-6)

<a id="event-7"></a>

7. **晋国韩厥退休，韩无忌让位给弟弟韩起。** 晋侯本想让无忌接任，无忌以自己有病不能亲自处理政务为由推让，并称许韩起好仁。韩起随后入朝接任，无忌则掌管公族大夫事务。 [[7]](#note-7)

<a id="event-8"></a>

8. **冬十月，卫孙林父来鲁聘问并续盟，却在入朝时与鲁君争先后。** 鲁襄公登阶，他也同时登阶，叔孙豹当场提醒使臣应在国君之后。孙林父无言以对，却没有表现出改过之意。壬戌，双方结盟。 [[8]](#note-8)

<a id="event-9"></a>

9. **楚军包围陈国，诸侯在鄬地会合救陈。** 鲁襄公与晋、宋、陈、卫、曹、莒、邾等国一同赴会。 [[9]](#note-9)

<a id="event-10"></a>

10. **郑僖公赴会途中在鄵被杀，五岁的郑简公继位。** 僖公先前多次怠慢随行大夫，将赴鄬会时又不礼子驷，还杀死劝谏的侍者。子驷命人在夜里行刺，却向诸侯报称国君死于疟疾；僖公因此未及与诸侯相见。 [[10]](#note-10)

<a id="event-11"></a>

11. **陈侯中途离开鄬会，赶回陈国。** 庆虎、庆寅与楚国配合，让楚人扣住公子黄，再以国内可能另立国君相威胁，逼陈侯返国。 [[11]](#note-11)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **春三月壬午，杞桓公去世。** 此次杞国报丧用了国君名字，因为此前已经与鲁国同盟。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，宋华弱被逐，逃到鲁国。** 华弱与乐辔从小亲近，成年后互相嘲弄、诋毁；乐辔一怒之下在朝廷用弓把华弱套住。宋平公看到后，认为负责武事的人受辱至此，遂放逐华弱。 [[2]](#note-2)

<a id="event-3"></a>

3. **宋子罕要求乐辔同样受罚，乐辔被逐后射子罕家门泄愤。** 子罕认为两人同样有错却只罚一人不公，何况乐辔擅自在朝廷羞辱大臣。乐辔被逐后威胁子罕，子罕仍像从前一样对待他。 [[3]](#note-3)

<a id="event-4"></a>

4. **秋，杞桓公下葬。** [[4]](#note-4)

<a id="event-5"></a>

5. **滕成公首次来朝鲁襄公。** [[5]](#note-5)

<a id="event-6"></a>

6. **莒国灭鄫，鲁国失去新近争取来的属国。** 鄫国此前依赖送财物求援，并没有因此保住自身。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬，叔孙豹前往邾国聘问，修复两国关系。** [[7]](#note-7)

<a id="event-8"></a>

8. **晋国追问鄫国为何灭亡，季孙宿赴晋听命。** 鲁国此前请求统属鄫国，因此晋国来责问鲁国未能保鄫。 [[8]](#note-8)

<a id="event-9"></a>

9. **齐军攻破莱都，莱君退到棠地。** 这场战争承接此前晏弱筑东阳、围莱的行动。本年杞桓公去世的月份，王湫、正舆子及棠人迎击齐军而败，齐军随后入莱。王湫、正舆子逃莒后被杀，陈无宇把莱国宗庙器物献到齐国襄宫。 [[9]](#note-9)

<a id="event-10"></a>

10. **冬，齐军再克棠地，完成灭莱并迁走莱人。** 晏弱继续包围莱君退守之处；棠地陷落后，莱人被迁往郳，高厚、崔杼负责安排所得土地。 [[10]](#note-10)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **春，鲁襄公从晋国返回。** [[1]](#note-1)

<a id="event-2"></a>

2. **周王派王叔陈生向晋国申诉戎事，晋国反把他扣押。** 士鲂随后赴京师，指称王叔在戎人和王室之间怀有两心。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，郑国公子发来鲁聘问。** 子国代表郑国接续新君即位后的邦交。 [[3]](#note-3)

<a id="event-4"></a>

4. **叔孙豹带鄫太子巫赴晋，落实鄫国归鲁统属的安排。** 鄫太子随鲁国大夫一道受命。 [[4]](#note-4)

<a id="event-5"></a>

<a id="event-7"></a>

<a id="event-8"></a>

<a id="event-9"></a>

<a id="event-10"></a>

5. **鲁卫与吴交涉，诸侯会于戚并出兵救陈。** 鲁、卫先在善道与吴国会面，商议诸侯大会。吴君派寿越到晋国，解释此前没有参加鸡泽会盟的原因，并请求参与诸侯交好。晋国遂让仲孙蔑、孙林父先与吴人商议会期。九月，诸侯在戚地会盟，与吴国接续关系，并命各国驻军陈国。叔孙豹认为继续统属鄫国对鲁不利，便让鄫国大夫直接在会场听命。鲁襄公会后返国。楚国把陈国背叛的责任归于令尹子辛，处死公子壬夫。楚国认为他的贪求侵扰逼走了陈国，随后另立子囊为令尹。晋国范宣子担心陈国终究守不住。子囊接掌楚政后，范宣子判断楚国会改变作风并加紧攻陈。陈国离楚太近，百姓日日受威胁，晋国难以让它长期归附。冬，楚军攻陈，诸侯再次出兵救援。各国先按戚盟驻守陈国，楚子囊仍率军来攻。鲁襄公与晋、宋、卫、郑、曹及齐太子光会合救陈，十二月回鲁。 [[5]](#note-5)

<a id="event-6"></a>

<a id="hs-event-13"></a>

6. **鲁国秋季因旱举行大雩。** [[6]](#note-6)

<a id="event-11"></a>

7. **辛未，季孙行父去世，家中没有显著私积。** 办理丧事时，人们发现他家没有穿丝帛的妾、以谷物喂养的马，也没有储藏的金玉和成套重器。鲁君在场参加敛礼。 [[7]](#note-11)

<a id="event-12"></a>

8. **陈哀公弱从本年开始纪元。** 陈成公在前569年去世，其子弱已经继位；前568年是陈哀公元年，不是再次即位。 [[8]](#note-12)

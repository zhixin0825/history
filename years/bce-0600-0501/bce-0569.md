# 公元前569年（鲁襄公4年）

[← 上一张已编年页：公元前570年](bce-0570.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前568年 →](bce-0568.md)

> 本页合并本年《春秋》《左传》及已核《史记》互见；月份沿用古史年条。回叙、后续与作者评论在相应史料注中区分，不据叙述位置强造发生年。

## 本年纪事

<a id="event-1"></a>

1. **春，楚军仍驻繁阳，晋国担忧难以护住陈国。** 韩厥认为接纳背楚而来的陈国，使晋国面临必须救援却不易承担的压力。 [看原文与说明](#note-1)

<a id="event-2"></a>

2. **三月己酉，陈成公去世，楚国闻丧后暂缓进攻。** 陈国仍没有重新听从楚国命令，双方关系并未缓和。 [看原文与说明](#note-2)

<a id="event-3"></a>

3. **夏，楚将彭名再次侵陈。** 楚国把陈国没有回应其停兵举动视作失礼。 [看原文与说明](#note-3)

<a id="event-4"></a>

4. **叔孙豹赴晋回聘，以不同礼乐回应晋国的招待。** 晋人为他奏天子待元侯的乐、两君相见的乐，他都不拜受；奏到慰劳使者、称美其君的乐章时，他才拜谢，并说明使臣不能越分接受国君之礼。 [看原文与说明](#note-4)

<a id="event-5"></a>

5. **秋，定姒去世，丧具一度没有备齐。** 匠庆责问季文子身为正卿，为何不能完成小君丧礼。最后，他用了季氏原为自己栽种的槚木制作葬具，季文子没有阻止。 [看原文与说明](#note-5)

<a id="event-6"></a>

6. **陈成公下葬。**  [看原文与说明](#note-6)

<a id="event-7"></a>

7. **八月辛亥，鲁国安葬定姒。**  [看原文与说明](#note-7)

<a id="event-8"></a>

8. **冬，鲁襄公赴晋，请求让鄫国归鲁国统属。** 晋侯起初不答应。孟献子解释鲁国土地、赋役不足以承担晋国频繁征调，希望借鄫国的力量补充，晋侯最终允许。 [看原文与说明](#note-8)

<a id="event-9"></a>

9. **陈国包围顿国。** 楚国先让顿国乘隙侵陈，陈国因而反攻。 [看原文与说明](#note-9)

<a id="event-10"></a>

10. **无终国请求与晋和戎，魏绛说服晋悼公接受。** 魏绛认为与戎人和好，可以取得土地、安定边境农事、增加晋国威望，又能避免疲劳军队，使远近各方安定；若此时耗兵攻戎，楚国再攻陈，晋国便无法救援。晋侯采纳建议，派魏绛与诸戎结盟。 [看原文与说明](#note-10)

<a id="event-11"></a>

11. **魏绛借后羿的故事，劝晋悼公不要沉迷田猎。** 他讲后羿凭射术掌权，却荒废民政、疏远贤臣，转而信任寒浞，最后连国家与家族都失去；又讲少康等人恢复夏室。晋侯由此答应修治民事，把田猎安排在合适时节。 [看原文与说明](#note-11)

<a id="event-12"></a>

12. **十月，邾、莒攻鄫，鲁军救鄫后进攻邾国，在狐骀战败。** 臧纥带兵救援未成，鲁国人迎回死者时哀悼，并作歌讥刺他的用兵。 [看原文与说明](#note-12)

### 10. 无终国请求与晋和戎，魏绛说服晋悼公接受

<details>
<summary>《左传》传 T009｜原文</summary>

> 无终子嘉父使孟乐如晋，因魏庄子纳虎豹之皮，以请和诸戎。

[回到原文位置](../../sources/春秋左传/有标点原文/bce-0569.md#t009)

</details>

<details>
<summary>《左传》传 T010｜原文</summary>

> 晋侯曰：“戎狄无亲而贪，不如伐之。”魏绛曰：“诸侯新服，陈新来和，将观于我，我德则睦，否则携贰。劳师于戎，而楚伐陈，必弗能救，是弃陈也，诸华必叛。戎，禽兽也，获戎失华，无乃不可乎？《夏训》有之曰：‘有穷后羿。’”公曰：“后羿何如？”对曰：“昔有夏之方衰也，后羿自鉏迁于穷石，因夏民以代夏政。恃其射也，不修民事而淫于原兽。弃武罗、伯因、熊髡、尨圉而用寒浞。寒浞，伯明氏之谗子弟也。伯明后寒弃之，夷羿收之，信而使之，以为己相。浞行媚于内而施赂于外，愚弄其民而虞羿于田，树之诈慝以取其国家，外内咸服。羿犹不悛，将归自田，家众杀而亨之，以食其子。其子不忍食诸，死于穷门。靡奔有鬲氏。浞因羿室，生浇及豷，恃其谗慝诈伪而不德于民。使浇用师，灭斟灌及斟寻氏。处浇于过，外豷于戈。靡自有鬲氏，收二国之烬，以灭浞而立少康。少康灭浇于过，后杼灭豷于戈。有穷由是遂亡，失人故也。昔周辛甲之为大史也，命百官，官箴王阙。于《虞人之箴》曰：‘芒芒禹迹，画为九州。经启九道，民有寝庙，兽有茂草，各有攸处，德用不扰。在帝夷羿，冒于原兽，忘其国恤，而思其麀牡。武不可重，用不恢于夏家。兽臣司原，敢告仆夫。’《虞箴》如是，可不惩乎？”于是晋侯好田，故魏绛及之。公曰：“然则莫如和戎乎？”对曰：“和戎有五利焉：戎狄荐居，贵华易土，土可贾焉，一也。边鄙不耸，民狎其野，穑人成功，二也。戎狄事晋，四邻振动，诸侯威怀，三也。以德绥戎，师徒不勤，甲兵不顿，四也。鉴于后羿，而用德度，远至迩安，五也。君其图之！”公说，使魏绛盟诸戎，修民事，田以时。

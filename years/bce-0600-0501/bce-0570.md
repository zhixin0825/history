## 本年纪事

<a id="event-1"></a>

1. **春，楚公子婴齐攻吴，先胜后遭重创。** 楚军攻下鸠兹，推进到衡山；邓廖带兵深入吴境后，被吴军截击俘获，部队只有一小部分脱身。 [看原文与说明](#note-1)

<a id="event-2"></a>

2. **吴军随即反攻楚国，夺取驾邑。** 楚军刚回国举行饮至礼三天，吴国便来进攻。楚国不但损失部队，还丢掉重要城邑，子重受到指责，后来忧病而死。 [看原文与说明](#note-2)

<a id="event-3"></a>

3. **鲁襄公首次赴晋朝见，四月在长樗与晋侯结盟后返鲁。** 孟献子陪同。襄公行稽首礼，晋人表示天子尚在，不敢接受这样的礼节；孟献子解释鲁国地处东方、紧邻敌国，必须依靠晋国，因此不敢不敬。 [看原文与说明](#note-3)

<a id="event-4"></a>

4. **晋国派士匄邀请齐国参加诸侯会盟。** 晋国既要巩固郑国归附后的秩序，也想修好吴国。齐侯本想拒绝，又不愿公开表示不合作，最终在耏水外与晋使结盟。 [看原文与说明](#note-4)

<a id="event-5"></a>

5. **祁奚退休时，先推荐仇人解狐，后又推荐儿子祁午。** 解狐尚未就任便去世，晋侯再次询问人选，祁奚举荐祁午；羊舌职去世后，他又推荐羊舌赤。最后祁午任中军尉，羊舌赤辅佐。 [看原文与说明](#note-5)

<a id="event-6"></a>

6. **六月，诸侯在鸡泽同盟，吴君没有赴会。** 鲁襄公与单顷公、晋、宋、卫、郑、莒、邾及齐太子光会合。晋国派荀会到淮水上迎接吴君，但未能把他接来。 [看原文与说明](#note-6)

<a id="event-7"></a>

7. **陈国派袁侨赴会求和，随后与诸侯大夫另行结盟。** 楚令尹子辛不断向小国索取利益，陈国因此希望转向晋国。袁侨到来后，叔孙豹与各国大夫同他订盟，接纳陈国。 [看原文与说明](#note-7)

<a id="event-8"></a>

8. **秋，鲁襄公从会盟返回。**  [看原文与说明](#note-8)

<a id="event-9"></a>

9. **晋侯弟弟扬干扰乱军阵，魏绛处死他的御者，晋侯大怒。** 晋侯一度要杀魏绛。魏绛送上书信请罪，说明军令不可违，自己执行军法是为了避免祸患进一步及于扬干。 [看原文与说明](#note-9)

<a id="event-10"></a>

10. **晋侯承认自己护弟有过，重用魏绛。** 晋侯读信后赤足出迎，阻止魏绛自尽，并表示扬干违命是自己没有教导好。回军后，他让魏绛担任新军副将；张老、士富也得到新的任命。 [看原文与说明](#note-10)

<a id="event-11"></a>

11. **楚公子何忌进攻陈国。** 楚国以陈国转向晋国为由出兵。 [看原文与说明](#note-11)

<a id="event-12"></a>

12. **冬，晋荀罃率军伐许。** 许灵公继续事楚，没有参加鸡泽会盟，晋国因此讨伐。 [看原文与说明](#note-12)

<a id="event-13"></a>

13. **郑釐公惲元年。** 郑成公已于上年去世，其子惲继承郑国君位，年表从本年记釐公元年；同书“釐”亦作“僖”，不另造第二位郑君。 [原文与说明](#note-13)

> 三年春，楚子重伐吴，为简之师，克鸠兹，至于衡山。使邓廖帅组甲三百、被练三千以侵吴。吴人要而击之，获邓廖。其能免者，组甲八十、被练三百而已。子重归，既饮至。三日，吴人伐楚，取驾。驾，良邑也。邓廖，亦楚之良也。君子谓：“子重于是役也，所获不如所亡。”楚人以是咎子重。子重病之，遂遇心疾而卒。

### 5. 祁奚退休时，先推荐仇人解狐，后又推荐儿子祁午

**说明：**‘举仇、举子而不徇私’是传文对此事的评价；正文保留推荐与任命经过，评价原文可在对应段落查看。

<details>
<summary>《左传》传 T005｜原文</summary>

> 祁奚请老，晋侯问嗣焉。称解狐，其仇也，将立之而卒。又问焉，对曰：“午也可。”于是羊舌职死矣，晋侯曰：“孰可以代之？”对曰：“赤也可。”于是使祁午为中军尉，羊舌赤佐之。君子谓：“祁奚于是能举善矣。称其仇，不为谄。立其子，不为比。举其偏，不为党。《商书》曰：‘无偏无党，王道荡荡’其祁奚之谓矣！解狐得举，祁午得位，伯华得官，建一官而三物成，能举善也夫！唯善，故能举其类。《诗》云：‘惟其有之，是以似之。’祁奚有焉。”

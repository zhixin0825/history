# 公元前571年（鲁襄公2年）

> 本页合并本年《春秋》《左传》及已核《史记》互见；月份沿用古史年条。回叙、后续与作者评论在相应史料注中区分，不据叙述位置强造发生年。

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **春正月，周简王下葬。** [[1]](#note-1)

<a id="event-2"></a>

2. **郑国奉楚国命令进攻宋国。** 宋、郑之间的战事继续与晋楚两方的关系牵连。 [[2]](#note-2)

<a id="event-3"></a>

3. **齐侯进攻莱国，莱人送财物求退兵。** 莱国正舆子把马、牛等财物交给齐侯身边的夙沙卫，齐军随后撤退。 [[3]](#note-3)

<a id="event-4"></a>

4. **五月庚寅，齐姜去世，鲁国为她准备葬具。** 穆姜原先挑选好木材，打算给自己制作棺木和琴；季文子却把这批木材拿来办理齐姜的丧事。 [[4]](#note-4)

<a id="event-5"></a>

5. **郑成公去世，临终仍要求臣下不要背弃楚国。** 子驷曾劝他改与晋国和解。郑成公想到楚王曾为郑国在战场伤眼，不愿在自己生前背弃楚国。其死后，子罕主持国事，子驷执政，子国任司马。 儿子恽继位，为釐公，也称僖公；新君元年在次年。 [[5]](#note-5)

<a id="event-6"></a>

6. **晋、宋、卫进攻郑国，郑国没有立即转向晋国。** 一些大夫主张归附晋国，子驷以先君的命令尚未改变为由反对。 [[6]](#note-6)

<a id="event-7"></a>

7. **秋七月，鲁仲孙蔑参加戚地会面，提出筑虎牢来逼郑服从。** 荀罃赞成，但指出齐国以及滕、薛、小邾缺席，必须先让这些国家参加，才能一起落实筑城计划。 [[7]](#note-7)

<a id="event-8"></a>

8. **己丑，鲁国安葬齐姜。** 齐侯派诸姜与宗妇前来送葬。 [[8]](#note-8)

<a id="event-9"></a>

9. **莱君拒绝应齐侯召唤，齐国在东阳筑城施压。** 晏弱负责筑城，齐国与莱国的争端因而继续扩大。 [[9]](#note-9)

<a id="event-10"></a>

10. **叔孙豹前往宋国聘问。** 鲁国借此向宋国通报并接续新君即位后的关系。 [[10]](#note-10)

<a id="event-11"></a>

11. **冬，诸侯再次会于戚，共同修筑虎牢，郑国终于求和。** 齐崔杼与滕、薛、小邾的大夫这次都到场。此前停留在商议中的筑城计划得以落实，直接增加了郑国的压力。 [[11]](#note-11)

<a id="event-12"></a>

12. **楚国处死右司马公子申。** 他大量接受小国的财物，又以自己的势力逼迫子重、子辛，最终被杀。 [[12]](#note-12)

<a id="event-13"></a>

13. **周灵王元年。** 周简王已于上年去世，其子泄心继位；年表从本年开始记灵王元年。年表称灵王“生有髭”，这是回述其出生相貌的传闻，不能认作本年出生。 [[13]](#note-13)

## 本年纪事

<a id="event-1"></a>

1. **春，鲁襄公即位。** 鲁国开始新君的统治。 [看原文与说明](#note-1)

<a id="event-2"></a>

2. **晋国率诸侯围攻彭城，鱼石等五名宋国流亡大夫被带往晋国。** 鲁国仲孙蔑与晋、宋、卫、曹、莒、邾、滕、薛的军队会合，替宋国讨伐占据彭城的鱼石一党。彭城投降后，晋国把五人安置在瓠丘。 [看原文与说明](#note-2)

<a id="event-3"></a>

3. **齐国没有参加围彭城，太子光随后被送到晋国做人质。** 晋国追究齐国缺席的责任；二月，齐太子光到晋国为质。 [看原文与说明](#note-3)

<a id="event-4"></a>

4. **夏，晋军攻郑，鲁国等东方诸侯在鄫地集结接应。** 韩厥、荀偃率军进入郑国外城，在洧水边击败郑国步兵。鲁仲孙蔑与齐崔杼等驻鄫等待；晋军随后会合这支军队，进攻楚国焦夷及陈国，晋侯、卫侯留在戚地作为后援。 [看原文与说明](#note-4)

<a id="event-5"></a>

5. **秋，楚、郑出兵攻宋。** 楚公子壬夫为救郑而进攻宋国吕、留；郑国子然也攻宋，取得犬丘。 [看原文与说明](#note-5)

<a id="event-6"></a>

6. **九月辛酉，周天子去世。**  [看原文与说明](#note-6)

去世的是周简王，接位的儿子泄心，即灵王。 [卷四互见与归年](#sj004-572-1)


<a id="event-7"></a>

7. **邾君来鲁朝见新君。** 这次朝见发生在九月，是两国接续关系的一次正式往来。 [看原文与说明](#note-7)

<a id="event-8"></a>

8. **冬，卫、晋先后派使者来鲁聘问。** 卫国派公孙剽，晋国派荀罃，借新君即位续好结信，并商议两国间事务。 [看原文与说明](#note-8)

# 公元前573年（鲁成公十八年）

[← 上一张已编年页：公元前574年](bce-0574.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前572年 →](bce-0572.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，晋国诛胥童，随后栾书、中行偃发动政变，晋厉公被杀。** 厉公被葬在翼东门外，礼数极低。 [[1]](#note-1)

    [卷四互见与归年](#sj004-573-1)

<a id="event-2"></a>

2. **晋国从周王室迎回年仅十四岁的公子周，即晋悼公。** 悼公即位后大规模整顿官制、减轻赋役、救济贫困，迅速重建晋国秩序。 [[2]](#note-2)

<a id="event-3"></a>

3. **齐国也清算国佐。** 国佐此前专杀、叛谷，最终在内宫被处置；国氏后来由国弱继续承继。 [[3]](#note-3)

<a id="event-4"></a>

4. **鲁成公赴晋朝见新君，回国后晋范宣子来鲁回聘。** 晋鲁关系重新稳定。 [[4]](#note-4)

<a id="event-5"></a>

5. **夏，楚、郑联合伐宋，攻取朝郏、城郜、幽丘等地，并把流亡楚国的鱼石等送回彭城。** 宋国内乱与晋楚竞争重新交织。 [[5]](#note-5)

<a id="event-6"></a>

6. **宋军随后围彭城，晋国准备出兵救宋。** 楚军来援后撤，晋国开始组织诸侯围彭城。 [[6]](#note-6)

<a id="event-7"></a>

7. **秋，杞伯、邾君先后来鲁朝见。** [[7]](#note-7)

<a id="event-8"></a>

8. **鲁国修筑鹿囿，被认为不合时令。** [[8]](#note-8)

<a id="event-9"></a>

9. **八月己丑，鲁成公死于路寝。** [[9]](#note-9)

<a id="event-10"></a>

10. **冬，楚、郑再次侵宋；晋国派士鲂来鲁求兵。** [[10]](#note-10)

<a id="event-11"></a>

11. **十二月，孟献子参加晋、宋、卫、邾、齐在虚朾的同盟，谋划救宋。** [[11]](#note-11)

<a id="event-12"></a>

12. **丁未，鲁国安葬成公。** [[12]](#note-12)

<a id="event-13"></a>

13. **燕武公元年。** 前一年燕昭公去世、武公继位，本年起算武公元年；这是正式纪年的接续，不是本年又一次即位政变。 [[13]](#note-13)

### 2. 晋国从周王室迎回年仅十四岁的公子周，即晋悼公

[返回正文第2条](#event-2)

<a id="sj033-cite-078"></a>

**[《史记·鲁周公世家》P057](../../sources/摘录/史记-卷033-鲁周公世家.md#p057)**

> 襄公元年，晉立悼公。往年冬，晉欒書弒其君厲公。

本卷叙元年、往冬；主线按传文前573正月弑厉与立悼，本年不另起一场元年政变。 [全卷考证](../../meta/考证/史记-卷033-纪年与异说.md)。

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0573.md#all-20261109-t001)**

> 十八年春，王正月庚申，晋栾书、中行偃使程滑弑厉公，葬之于翼东门之外，以车一乘。使荀罃、士鲂逆周子于京师而立之，生十四年矣。大夫逆于清原，周子曰：“孤始愿不及此。虽及此，岂非天乎！抑人之求君，使出命也，立而不从，将安用君？二三子用我今日，否亦今日，共而从君，神之所福也。”对曰：“群臣之愿也，敢不唯命是听。”庚午，盟而入，馆于伯子同氏。辛巳，朝于武宫，逐不臣者七人。周子有兄而无慧，不能辨菽麦，故不可立。

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0573.md#all-20261109-t003)**

> 二月乙酉朔，晋悼公即位于朝。始命百官：施舍已责，逮鳏寡，振废滞，匡乏困，救灾患，禁淫慝，薄赋敛，宥罪戾，节器用，时用民，欲无犯时。使魏相、士鲂、魏颉、赵武为卿。荀家、荀会、栾黡、韩无忌为公族大夫，使训卿之子弟共俭孝弟。使士渥浊为大傅，使修范武子之法。右行辛为司空，使修士蒍之法。弁纠御戎，校正属焉，使训诸御知义。荀宾为右，司士属焉，使训勇力之士时使。卿无共御，立军尉以摄之。祁奚为中军尉，羊舌职佐之。魏绛为司马。张老为候奄。铎遏寇为上军尉。籍偃为之司马，使训卒乘亲以听命。程郑为乘马御，六驺属焉，使训群驺知礼。凡六官之长，皆民誉也。举不失职，官不易方，爵不踰德，师不陵正，旅不偪师，民无谤言，所以复霸也。

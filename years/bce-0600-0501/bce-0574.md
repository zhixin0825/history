# 公元前574年（鲁成公十七年）

[← 上一张已编年页：公元前575年](bce-0575.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前573年 →](bce-0573.md)

<a id="event-1"></a>

1. **春，卫北宫括侵郑；夏，鲁成公参加晋、齐、宋、卫、曹、邾等诸侯再次伐郑。** 郑国仍依楚，晋国连续发动征讨。[[1]](#note-1)

**郑国派太子髡顽、侯獳到楚为质，楚公子成、公子寅驻守郑国。** 随后鲁君会同王室代表和诸侯军伐郑，进至曲洧一线。质子与驻军是郑楚关系的具体安排，补入这场战争的背景。 [看原文与说明](#cq-source-65)

<a id="event-2"></a>

2. **六月，诸侯在柯陵重申盟约；楚军随后救郑，诸侯撤退。** [[2]](#note-2)

<a id="event-3"></a>

3. **秋，成公从会盟返回。** [[3]](#note-3)

<a id="event-4"></a>

4. **齐国内部爆发高氏、国氏与声孟子集团冲突。** 鲍牵受刑，高无咎逃往莒国，齐国政局明显动荡。[[4]](#note-4)

<a id="event-5"></a>

5. **九月，鲁国举行郊祭。** [[5]](#note-5)

<a id="event-6"></a>

6. **冬，晋国再次向鲁求兵，诸侯又出兵伐郑并包围郑都；楚军救郑，诸侯撤军。** [[6]](#note-6)

<a id="event-7"></a>

7. **公孙婴齐从郑战返鲁途中死于貍脤。** [[7]](#note-7)

<a id="event-8"></a>

8. **十二月朔日发生日食；邾君貜且去世。** [[8]](#note-8)

<a id="event-9"></a>

9. **晋厉公决心清洗三郤。** 胥童等发动袭击，郤锜、郤犫、郤至被杀。[[9]](#note-9)

<a id="event-10"></a>

10. **胥童随后控制栾书、中行偃，但晋厉公没有继续诛杀二人。** 二人后来反而拘禁厉公。[[10]](#note-10)

<a id="event-11"></a>

11. **楚国趁舒庸依吴而疏于防备，出兵灭舒庸。** [[11]](#note-11)

<a id="event-12"></a>

12. **六月戊辰，晋国士燮去世。** 他从鄢陵之战回来后，曾向家中祝宗表达自己不愿见到胜战后的内乱；本年死亡有干支，不能只把他作为去年战场中的劝谏者写过便略去。 [看原文与说明](#cq-source-66)

<a id="event-13"></a>

13. **燕昭公在位十三年后去世，燕武公继位。** 本年按照《十二诸侯年表》记昭公去世，武公正式元年另记在前573年；不能将死亡与元年算作同一年第二次更君。 [原文与说明](#note-13)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·成公十七年》**：“十有七年春，卫北宫括帅师侵郑。夏，公会尹子、单子、晋侯、齐侯、宋公、卫侯、曹伯、邾人伐郑。”

<a id="note-2"></a>

2. **《春秋·成公十七年》**：“六月乙酉，同盟于柯陵。”  
   **《左传·成公十七年》**详记楚救郑、诸侯还。

<a id="note-3"></a>

3. **《春秋·成公十七年》**：“秋，公至自会。”

<a id="note-4"></a>

4. **《春秋·成公十七年》**：“齐高无咎出奔莒。”  
   **《左传·成公十七年》**详记齐国内乱。

<a id="note-5"></a>

5. **《春秋·成公十七年》**：“九月辛丑，用郊。”

<a id="note-6"></a>

6. **《春秋·成公十七年》**：“晋侯使荀罃来乞师。冬，公会单子、晋侯、宋公、卫侯、曹伯、齐人、邾人伐郑。十有一月，公至自伐郑。”

<a id="note-7"></a>

7. **《春秋·成公十七年》**：“壬申，公孙婴齐卒于貍脤。”

<a id="note-8"></a>

8. **《春秋·成公十七年》**：“十有二月丁巳朔，日有食之。邾子貜且卒。”

<a id="note-9"></a>

9. **《春秋·成公十七年》**：“晋杀其大夫郤锜、郤犫、郤至。”  
   **《左传·成公十七年》**详记三郤被杀。

<a id="note-10"></a>

10. **《左传·成公十七年》**详记胥童劫栾书、中行偃及晋厉公后被拘。

<a id="note-11"></a>

11. **《春秋·成公十七年》**：“楚人灭舒庸。”

<a id="note-13"></a>

13. **《史记·十二诸侯年表》前574年燕栏**记“昭公十三年卒”。[本年原表](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0574)。[《燕召公世家》](https://zh.wikisource.org/wiki/史記/卷034)记昭公十三年去世、武公继立；次年年表改记武公元年。此处只记当年的卒与继承关系，不推定具体月日。

### 核对66｜六月戊辰，晋国士燮去世

**说明：**向祝宗祈死是古书记录的言辞，不写成祈祷已被证明导致死亡，也不据此诊断人物状态。

<details>
<summary>传 T003｜原文</summary>

> 晋范文子反自鄢陵，使其祝宗祈死，曰：“君骄侈而克敌，是天益其疾也。难将作矣！爱我者惟祝我，使我速死，无及于难，范氏之福也。”六月戊辰，士燮卒。

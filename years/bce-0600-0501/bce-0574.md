# 公元前574年（鲁成公十七年）

[← 上一张已编年页：公元前575年](bce-0575.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前573年 →](bce-0573.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **春，卫北宫括侵郑；夏，鲁成公参加晋、齐、宋、卫、曹、邾等诸侯再次伐郑。** 郑国仍依楚，晋国连续发动征讨。 [[1]](#reading-note-1)

<a id="reading-event-2"></a>

2. **郑国派太子髡顽、侯獳到楚为质，楚公子成、公子寅驻守郑国。** 随后鲁君会同王室代表和诸侯军伐郑，进至曲洧一线。质子与驻军是郑楚关系的具体安排，补入这场战争的背景。 [[2]](#reading-note-2)

<a id="event-2"></a>

<a id="reading-event-3"></a>

3. **六月，诸侯在柯陵重申盟约；楚军随后救郑，诸侯撤退。** [[3]](#reading-note-3)

<a id="event-3"></a>

<a id="reading-event-4"></a>

4. **秋，成公从会盟返回。** [[4]](#reading-note-4)

<a id="event-4"></a>

<a id="reading-event-5"></a>

5. **齐国内部爆发高氏、国氏与声孟子集团冲突。** 鲍牵受刑，高无咎逃往莒国，齐国政局明显动荡。 [[5]](#reading-note-5)

<a id="event-5"></a>

<a id="reading-event-6"></a>

6. **九月，鲁国举行郊祭。** [[6]](#reading-note-6)

<a id="event-6"></a>

<a id="reading-event-7"></a>

7. **冬，晋国再次向鲁求兵，诸侯又出兵伐郑并包围郑都；楚军救郑，诸侯撤军。** [[7]](#reading-note-7)

<a id="event-7"></a>

<a id="reading-event-8"></a>

8. **公孙婴齐从郑战返鲁途中死于貍脤。** [[8]](#reading-note-8)

<a id="event-8"></a>

<a id="reading-event-9"></a>

9. **十二月朔日发生日食；邾君貜且去世。** [[9]](#reading-note-9)

<a id="event-9"></a>

<a id="reading-event-10"></a>

10. **晋厉公决心清洗三郤。** 胥童等发动袭击，郤锜、郤犫、郤至被杀。 [[10]](#reading-note-10)

<a id="event-10"></a>

<a id="reading-event-11"></a>

11. **胥童随后控制栾书、中行偃，但晋厉公没有继续诛杀二人。** 二人后来反而拘禁厉公。 [[11]](#reading-note-11)

<a id="event-11"></a>

<a id="reading-event-12"></a>

12. **楚国趁舒庸依吴而疏于防备，出兵灭舒庸。** [[12]](#reading-note-12)

<a id="event-12"></a>

<a id="reading-event-13"></a>

13. **六月戊辰，晋国士燮去世。** 他从鄢陵之战回来后，曾向家中祝宗表达自己不愿见到胜战后的内乱；本年死亡有干支，不能只把他作为去年战场中的劝谏者写过便略去。 [[13]](#reading-note-13)

<a id="event-13"></a>

<a id="reading-event-14"></a>

14. **燕昭公在位十三年后去世，燕武公继位。** 本年按照《十二诸侯年表》记昭公去世，武公正式元年另记在前573年；不能将死亡与元年算作同一年第二次更君。 [[14]](#reading-note-14)

### 11. 胥童随后控制栾书、中行偃，但晋厉公没有继续诛杀二人

[返回正文第11条](#reading-event-11)

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0574.md#t017)**

> 胥童以甲劫栾书、中行偃于朝。矫曰：“不杀二子，忧必及君。”公曰：“一朝而尸三卿，余不忍益也。”对曰：“人将忍君。臣闻乱在外为奸，在内为轨。御奸以德，御轨以刑。不施而杀，不可谓德。臣偪而不讨，不可谓刑。德刑不立，奸轨并至。臣请行。”遂出奔狄。公使辞于二子，曰：“寡人有讨于郤氏，郤氏既伏其辜矣。大夫无辱，其复职位。”皆再拜稽首曰：“君讨有罪，而免臣于死，君之惠也。二臣虽死，敢忘君德。”乃皆归。公使胥童为卿。

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0574.md#t018)**

> 公游于匠丽氏，栾书、中行偃遂执公焉。召士匄，士匄辞。召韩厥，韩厥辞，曰：“昔吾畜于赵氏，孟姬之谗，吾能违兵。古人有言曰，‘杀老牛莫之敢尸’，而况君乎？二三子不能事君，焉用厥也！”

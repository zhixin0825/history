# 公元前575年（鲁成公十六年）

[← 上一张已编年页：公元前576年](bce-0576.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前574年 →](bce-0574.md)

<a id="event-1"></a>

1. **春，鲁国出现雨后木冰；四月滕文公去世。** [1]

<a id="event-2"></a>

2. **郑国公子喜侵宋，一度取得胜利。** [2]

<a id="event-3"></a>

3. **六月朔日发生日食。** 同月晋厉公向鲁国求兵，准备大举伐郑。[3]

<a id="event-4"></a>

4. **郑国重新依楚，楚共王率军救郑。** 晋楚两军在鄢陵相遇。[4]

<a id="event-5"></a>

5. **六月末，晋楚在鄢陵决战。** 晋军利用楚军左右两翼薄弱集中打击，楚共王中箭伤眼；楚军最终夜间撤退。[5]

<a id="event-6"></a>

6. **楚军主将子反因战败与军纪问题自杀。** [6]

<a id="event-7"></a>

7. **秋，鲁成公到沙随会诸侯，却因叔孙侨如向晋郤犫行贿诬陷，晋侯拒绝见成公；成公随后返回鲁国。** [7]

<a id="event-8"></a>

8. **鲁国又参加诸侯伐郑，战后成公再次返回鲁国。** 成公母穆姜趁机要求除去季、孟两氏，成公没有接受。[8]

<a id="event-9"></a>

9. **晋国扣押季孙行父于苕丘。** 叔孙侨如继续向晋人诬告季、孟谋叛；子叔声伯力争，晋最终释放季孙。[9]

<a id="event-10"></a>

10. **冬，叔孙侨如出奔齐；季孙行父与晋郤犫在扈地结盟后回国。** 鲁国内斗暂时以季、孟获胜告终。[10]

<a id="event-11"></a>

11. **鲁国诛公子偃，又从齐国召叔孙豹回国继立叔孙氏。** [11]

<a id="event-12"></a>

12. **曹成公从周王室获释回国。** [12]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·成公十六年》**：“十有六年春，王正月，雨，木冰。夏四月辛未，滕子卒。”

<a id="note-2"></a>

2. **《春秋·成公十六年》**：“郑公子喜帅师侵宋。”

<a id="note-3"></a>

3. **《春秋·成公十六年》**：“六月丙寅朔，日有食之。晋侯使栾黡来乞师。”

<a id="note-4"></a>

4. **《左传·成公十六年》**详记郑叛晋从楚、楚救郑。

<a id="note-5"></a>

5. **《春秋·成公十六年》**：“甲午晦，晋侯及楚子、郑伯战于鄢陵，楚子、郑师败绩。”  
   **《左传·成公十六年》**详记鄢陵之战全过程。

<a id="note-6"></a>

6. **《春秋·成公十六年》**：“楚杀其大夫公子侧。”  
   **《左传·成公十六年》**详记子反战后自尽。

<a id="note-7"></a>

7. **《春秋·成公十六年》**：“秋，公会晋侯、齐侯、卫侯、宋华元、邾人于沙随，不见公。公至自会。”

<a id="note-8"></a>

8. **《春秋·成公十六年》**：“公会尹子、晋侯、齐国佐、邾人伐郑……公至自会。”  
   **《左传·成公十六年》**详记穆姜谋逐季、孟。

<a id="note-9"></a>

9. **《春秋·成公十六年》**：“九月，晋人执季孙行父，舍之于苕丘。”  
   **《左传·成公十六年》**详记叔孙侨如谗言与声伯救季孙。

<a id="note-10"></a>

10. **《春秋·成公十六年》**：“冬十月乙亥，叔孙侨如出奔齐。十有二月乙丑，季孙行父及晋郤犫盟于扈。”

<a id="note-11"></a>

11. **《春秋·成公十六年》**：“乙酉，刺公子偃。”  
    **《左传·成公十六年》**又记召叔孙豹于齐而立之。

<a id="note-12"></a>

12. **《春秋·成公十六年》**：“曹伯归自京师。”

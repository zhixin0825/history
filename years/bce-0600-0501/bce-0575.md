# 公元前575年（鲁成公十六年）

[← 上一张已编年页：公元前576年](bce-0576.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前574年 →](bce-0574.md)

<a id="event-1"></a>

1. **春，鲁国出现雨后木冰；四月滕文公去世。** [[1]](#note-1)

<a id="event-2"></a>

2. **郑国公子喜侵宋，一度取得胜利。** [[2]](#note-2)

<a id="event-3"></a>

3. **六月朔日发生日食。** 同月晋厉公向鲁国求兵，准备大举伐郑。[[3]](#note-3)

<a id="event-4"></a>

4. **郑国重新依楚，楚共王率军救郑。** 晋楚两军在鄢陵相遇。[[4]](#note-4)

<a id="event-5"></a>

5. **六月末，晋楚在鄢陵决战。** 晋军利用楚军左右两翼薄弱集中打击，楚共王中箭伤眼；楚军最终夜间撤退。[[5]](#note-5)

**鄢陵开战前，晋军内部仍在争论是否应战。** 范文子主张避战，栾书主张固守等待；郤至指出楚军阵列与内部配合的弱点，要求抓住战机。楚王在巢车上观察晋军，由伯州犁说明对方动作；晋侯一侧的苗贲皇则建议先打楚左右两翼，再集兵攻王卒。晋方车驾一度陷泥，栾鍼拒绝让中军将越职代驾，仍按本职救出晋侯。 [看原文与说明](#cq-source-69)

**晋吕锜射伤楚共王的眼睛，养由基奉命射死吕锜。** 交战中郤至遇到楚王仍依礼避让，楚方遣工尹襄致问，他按军中礼答谢。韩厥、郤至先后追近郑君又停手，郑君收起旗帜脱离追击，唐苟留下战死。楚军退至险处时，养由基与叔山冉反击，晋军停止逼近并俘获楚公子茷；栾鍼又在战间向子重送饮，复鼓后继续作战。 [看原文与说明](#cq-source-70)

**战斗从清晨延续到见星，楚军原准备补卒乘、整车马再战。** 晋军也发出整备再战的命令，并放回楚俘，使消息传到楚王。楚王召子反商议时，子反因穀阳竖献酒而醉，不能入见，楚军于是夜退。晋军进入楚营取食三日，范文子仍劝晋君不要因获胜失去戒心。 [看原文与说明](#cq-source-71)

<a id="event-6"></a>

6. **楚军主将子反因战败与军纪问题自杀。** [[6]](#note-6)

<a id="event-7"></a>

7. **秋，鲁成公到沙随会诸侯，却因叔孙侨如向晋郤犫行贿诬陷，晋侯拒绝见成公；成公随后返回鲁国。** [[7]](#note-7)

<a id="event-8"></a>

8. **鲁国又参加诸侯伐郑，战后成公再次返回鲁国。** 成公母穆姜趁机要求除去季、孟两氏，成公没有接受。[[8]](#note-8)

<a id="event-9"></a>

9. **晋国扣押季孙行父于苕丘。** 叔孙侨如继续向晋人诬告季、孟谋叛；子叔声伯力争，晋最终释放季孙。[[9]](#note-9)

<a id="event-10"></a>

10. **冬，叔孙侨如出奔齐；季孙行父与晋郤犫在扈地结盟后回国。** 鲁国内斗暂时以季、孟获胜告终。[[10]](#note-10)

<a id="event-11"></a>

11. **鲁国诛公子偃，又从齐国召叔孙豹回国继立叔孙氏。** [[11]](#note-11)

<a id="event-12"></a>

12. **曹成公从周王室获释回国。** [[12]](#note-12)

<a id="event-13"></a>

13. **晋将郤至奉命到周王室告捷，与单襄公谈话。** 郤至把胜利多归于自己，单襄公则向周臣说明，军政之功不能由一人独占。他还批评郤至拿三卿作比较、借称别人无能来为自己邀功。 [看原文与说明](#cq-source-64)

<a id="event-14"></a>

14. **宋平公元年。** 宋共公已经在上年去世，儿子继位，年表从本年列平公元年；传本所写平公名字有“成”“戌”差异，不能当成两位国君。 [原文与说明](#note-14)

### 核对69｜鄢陵开战前，晋军内部仍在争论是否应战

**说明：**两边人物所说天意、占卜与预测是战前言论，不能当作战争结果的独立证明；叙述不替任何主将作能力排序。

<details>
<summary>传 T004｜原文</summary>

> 郑人闻有晋师，使告于楚，姚句耳与往。楚子救郑，司马将中军，令尹将左，右尹子辛将右。过申，子反入见申叔时，曰：“师其何如？”对曰：“德、刑、详、义、礼、信，战之器也。德以施惠，刑以正邪，详以事神，义以建利，礼以顺时，信以守物。民生厚而德正，用利而事节，时顺而物成。上下和睦，周旋不逆，求无不具，各知其极。故《诗》曰：‘立我烝民，莫匪尔极。’是以神降之福，时无灾害，民生敦厖，和同以听，莫不尽力以从上命，致死以补其阙。此战之所由克也。今楚内弃其民，而外绝其好，渎齐盟，而食话言，奸时以动，而疲民以逞。民不知信，进退罪也。人恤所厎，其谁致死？子其勉之！吾不复见子矣。”姚句耳先归，子驷问焉，对曰：“其行速，过险而不整。速则失志，不整丧列。志失列丧，将何以战？楚惧不可用也。”

</details>

<summary>传 T008｜原文</summary>

> 楚子登巢车以望晋军，子重使大宰伯州犁侍于王后。王曰：“骋而左右，何也？”曰：“召军吏也。”“皆聚于中军矣！”曰：“合谋也。”“张幕矣！”曰：“虔卜于先君也。”“彻幕矣！”曰：“将发命也。”“甚嚣，且尘上矣！”曰：“将塞井夷灶而为行也。”“皆乘矣，左右执兵而下矣！”曰：“听誓也。”“战乎？”曰：“未可知也。”“乘而左右皆下矣！”曰：“战祷也。”伯州犁以公卒告王。苗贲皇在晋侯之侧，亦以王卒告。皆曰：“国士在，且厚，不可当也。”苗贲皇言于晋侯曰：“楚之良，在其中军王族而已。请分良以击其左右，而三军萃于王卒，必大败之。”公筮之。史曰：“吉。其卦遇《复》，曰：‘南国蹙，射其元王，中厥目。’国蹙王伤，不败何待？”公从之。有淖于前，乃皆左右相违于淖。步毅御晋厉公，栾鍼为右。彭名御楚共王，潘党为右。石首御郑成公，唐苟为右。栾、范以其族夹公行，陷于淖。栾书将载晋侯，鍼曰：“书退，国有大任，焉得专之。且侵官，冒也；失官，慢也；离局，奸也。有三罪焉，不可犯也。”乃掀公以出于淖。

<details>
<summary>传 T009｜原文</summary>

> 癸巳，潘尪之党与养由基蹲甲而射之，彻七札焉。以示王，曰：“君有二臣如此，何忧于战？”王怒曰：“大辱国。诘朝，尔射，死艺。”吕锜梦射月，中之，退入于泥。占之，曰：“姬姓，日也。异姓，月也。必楚王也。射而中之，退入于泥，亦必死矣。”及战，射共王中目。王召养由基，与之两矢，使射吕锜，中项，伏弢。以一矢复命。

### 核对71｜战斗从清晨延续到见星，楚军原准备补卒乘、整车马再战

**说明：**“天败楚”的话属于楚王的表达。子反退军后的死另见第6条，不把他的死亡放在夜间撤军之前。

<details>
<summary>传 T014｜原文</summary>

> 旦而战，见星未已。子反命军吏察夷伤，补卒乘，缮甲兵，展车马，鸡鸣而食，唯命是听。晋人患之。苗贲皇徇曰：“蒐乘补卒，秣马利兵，修陈固列，蓐食申祷，明日复战。”乃逸楚囚。王闻之，召子反谋。穀阳竖献饮于子反，子反醉而不能见。王曰：“天败楚也夫！余不可以待。”乃宵遁。晋入楚军，三日穀。范文子立于戎马之前，曰：“君幼，诸臣不佞，何以及此？君其戒之！《周书》曰‘惟命不于常’，有德之谓。”

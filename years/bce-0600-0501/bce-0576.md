# 公元前576年（鲁成公十五年）

[← 上一张已编年页：公元前577年](bce-0577.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前575年 →](bce-0575.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

<a id="event-12"></a>

1. **卫献公元年，卫葬定公。** 卫献公衎本年元年。春，卫国安葬定公。鲁大夫仲婴齐也在春季去世。 [[1]](#note-1)

<a id="event-2"></a>

<a id="event-3"></a>

2. **诸侯会于戚，追究曹成公篡位。** 三月，鲁成公与晋、卫、郑、曹、宋、齐、邾等同盟于戚，追究曹成公篡位。会后鲁成公归国。 [[2]](#note-2)

<a id="event-4"></a>

3. **夏六月，宋共公去世；秋八月下葬。** [[3]](#note-4)

<a id="event-5"></a>

4. **楚国再次北伐郑、卫。** 晋国暂不与楚交战，希望楚失信于诸侯后自弱。 [[4]](#note-5)

<a id="event-6"></a>

<a id="event-7"></a>

5. **宋荡氏杀公子肥引发内乱，华元回宋，鱼石等奔楚。** 宋荡氏削弱公室、杀公子肥，华元奔晋，后来被鱼石追回。鱼石等五名宋大夫最终出奔楚国。 [[5]](#note-6)

<a id="event-8"></a>

6. **冬，叔孙侨如会晋、齐、宋、卫、郑、邾等大夫在钟离与吴国会面。** 这是中原诸侯与吴国正式建立关系的重要节点。 [[6]](#note-8)

<a id="event-9"></a>

7. **许国因受郑国逼迫，请楚帮助迁到叶地。** [[7]](#note-9)

<a id="event-10"></a>

8. **晋国三郤陷害伯宗，伯宗被杀；伯州犁逃楚。** 晋国内部卿族斗争愈演愈烈。 伯宗因屡次直言进谏招怨，其死又使国人对厉公离心。 [[8]](#note-10)

<a id="event-11"></a>

9. **秦景公本年开始纪元。** 父亲秦桓公已于前577年去世，景公继承秦国君位；前576年是景公元年。 [[9]](#note-11)

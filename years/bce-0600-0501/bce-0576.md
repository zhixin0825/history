# 公元前576年（鲁成公十五年）

[← 上一张已编年页：公元前577年](bce-0577.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前575年 →](bce-0575.md)

<a id="event-1"></a>

1. **春，卫定公下葬；鲁大夫仲婴齐去世。** [[1]](#note-1)

<a id="event-2"></a>

2. **三月，鲁成公与晋、卫、郑、曹、宋、齐、邾等在戚地同盟，追究曹成公篡位。** 晋侯把曹伯押送周王室。[[2]](#note-2)

<a id="event-3"></a>

3. **鲁成公从会盟返回。** [[3]](#note-3)

<a id="event-4"></a>

4. **夏六月，宋共公去世；秋八月下葬。** [[4]](#note-4)

<a id="event-5"></a>

5. **楚国再次北伐郑、卫。** 晋国暂不与楚交战，希望楚失信于诸侯后自弱。[[5]](#note-5)

<a id="event-6"></a>

6. **宋国内部荡氏削弱公室并杀公子肥，华元出奔晋；后来被鱼石追回。** 华元回国后讨荡氏，宋国内乱进一步扩大。[[6]](#note-6)

<a id="event-7"></a>

7. **鱼石等宋国五大夫最终出奔楚。** [[7]](#note-7)

<a id="event-8"></a>

8. **冬，叔孙侨如会晋、齐、宋、卫、郑、邾等大夫在钟离与吴国会面。** 这是中原诸侯与吴国正式建立关系的重要节点。[[8]](#note-8)

<a id="event-9"></a>

9. **许国因受郑国逼迫，请楚帮助迁到叶地。** [[9]](#note-9)

<a id="event-10"></a>

10. **晋国三郤陷害伯宗，伯宗被杀；伯州犁逃楚。** 晋国内部卿族斗争愈演愈烈。[[10]](#note-10)

<a id="event-11"></a>

11. **秦景公本年开始纪元。** 父亲秦桓公已于前577年去世，景公继承秦国君位；前576年是景公元年。[[11]](#note-11)

<a id="event-12"></a>

12. **卫献公衎元年。** 卫定公臧于上年去世，其子衎继位；年表从本年记献公元年，不把父君死亡另记为本年事件。 [原文与说明](#note-12)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·成公十五年》**：“十有五年春，王二月，葬卫定公。三月乙巳，仲婴齐卒。”

<a id="note-2"></a>

2. **《春秋·成公十五年》**：“癸丑，公会晋侯、卫侯、郑伯、曹伯、宋世子成、齐国佐、邾人，同盟于戚。晋侯执曹伯，归于京师。”

<a id="note-3"></a>

3. **《春秋·成公十五年》**：“公至自会。”

<a id="note-4"></a>

4. **《春秋·成公十五年》**：“夏六月，宋公固卒……秋八月庚辰，葬宋共公。”

<a id="note-5"></a>

5. **《春秋·成公十五年》**：“楚子伐郑。”  
   **《左传·成公十五年》**详记楚侵郑、卫。

<a id="note-6"></a>

6. **《春秋·成公十五年》**：“宋华元出奔晋。宋华元自晋归于宋。宋杀其大夫山。”  
   **《左传·成公十五年》**详记宋内乱。

<a id="note-7"></a>

7. **《春秋·成公十五年》**：“宋鱼石出奔楚。”

<a id="note-8"></a>

8. **《春秋·成公十五年》**：“冬十有一月，叔孙侨如会晋士燮、齐高无咎、宋华元、卫孙林父、郑公子酉、邾人会吴于钟离。”  
   **《左传·成公十五年》**：“始通吴也。”

<a id="note-9"></a>

9. **《春秋·成公十五年》**：“许迁于叶。”

<a id="note-10"></a>

10. **《左传·成公十五年》**详记三郤害伯宗、伯州犁奔楚。

<a id="note-11"></a>

11. **《史记·十二诸侯年表》前576年秦栏**：“秦景公元年”；**《秦本纪》**：“桓公立二十七年卒，子景公立。”桓公卒、景公承位接前577年既有正文；本年只补元年起算，不据此另记一次继位。 [年表原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0576) · [《秦本纪》](https://zh.wikisource.org/wiki/史記/卷005#秦桓公)

<a id="note-12"></a>

12. **《史记·十二诸侯年表》前576年卫栏**：“卫献公衎元年。” [原表年行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0576)。[《卫康叔世家》](https://zh.wikisource.org/wiki/史記/卷037)记定公十二年卒、子献公衎立；[前577年卫定公之死](bce-0577.md#event-5)已另有正文。仅补本年新君元年，不推断死亡月日。

# 公元前577年（鲁成公十四年）

[← 上一张已编年页：公元前578年](bce-0578.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前576年 →](bce-0576.md)

<a id="event-1"></a>

1. **春，莒君朱去世。** [[1]](#note-1)

<a id="event-2"></a>

2. **卫国孙林父在晋国帮助下回卫。** 卫定公虽然厌恶他，仍在晋国压力和定姜劝说下恢复其地位。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，叔孙侨如赴齐迎娶姜氏。** 九月，夫人姜氏正式抵达鲁国。[[3]](#note-3)

<a id="event-4"></a>

4. **郑国公子喜伐许，郑军先败，随后郑伯再伐并攻入许国外城。** 许国以部分封地求和。[[4]](#note-4)

<a id="event-5"></a>

5. **冬，卫定公去世。** 临终前已经立衎为太子；定姜看见太子缺乏哀色，忧虑卫国未来。[[5]](#note-5)

**卫君病中先命孔成子、甯惠子立衎为太子。** 衎的母亲为敬姒。先立太子再发生国君丧事，继承安排的先后在原文中可见。 [看原文与说明](#cq-source-63)

<a id="event-6"></a>

6. **秦伯也在本年去世。** [[6]](#note-6)

这里去世的秦君是桓公，继位者为其子景公。

[补充史料与年次说明](#sj005-108-note)


<a id="event-7"></a>

7. **曹成公负刍本年开始纪元。** 他在前578年杀太子自立，本年是曹成公元年，不再重写一次篡位。[[7]](#note-7)

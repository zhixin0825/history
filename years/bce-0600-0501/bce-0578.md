# 公元前578年（鲁成公十三年）

[← 上一张已编年页：公元前579年](bce-0579.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前577年 →](bce-0577.md)

<a id="event-1"></a>

1. **春，晋国派郤锜来鲁求援，准备大举伐秦。** 郤锜态度怠慢，鲁大夫已预言郤氏将因无礼而败。[1]

<a id="event-2"></a>

2. **三月，鲁成公赴周王室朝见；随后直接参加晋、齐、宋、卫、郑、曹、邾、滕等伐秦联军。** [2]

<a id="event-3"></a>

3. **晋国正式派吕相向秦国“绝秦”，逐条追溯秦晋数代以来的背盟、战争和旧怨。** 双方关系彻底破裂。[3]

<a id="event-4"></a>

4. **五月，晋与诸侯联军在麻隧大败秦军，俘获秦国将领。** 联军渡泾水深入秦境后才撤退。[4]

<a id="event-5"></a>

5. **曹宣公在军中去世。** [5]

<a id="event-6"></a>

6. **郑国内部又发生政变：公子班试图入太宫，随后与子如、子駹等被清除。** [6]

<a id="event-7"></a>

7. **曹国公子负刍趁国君丧事杀太子自立。** 诸侯准备追究，但晋国因其参加伐秦有功暂缓处理。[7]

<a id="event-8"></a>

8. **秋，鲁成公从伐秦返回；冬安葬曹宣公。** [8]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·成公十三年》**：“十有三年春，晋侯使郤锜来乞师。”  
   **《左传·成公十三年》**详记郤锜来乞师不敬。

<a id="note-2"></a>

2. **《春秋·成公十三年》**：“三月，公如京师。夏五月，公自京师，遂会晋侯、齐侯、宋公、卫侯、郑伯、曹伯、邾人、滕人伐秦。”

<a id="note-3"></a>

3. **《左传·成公十三年》**完整载《吕相绝秦》。

<a id="note-4"></a>

4. **《左传·成公十三年》**详记麻隧之战，秦师败绩。

<a id="note-5"></a>

5. **《春秋·成公十三年》**：“曹伯卢卒于师。”

<a id="note-6"></a>

6. **《左传·成公十三年》**详记郑公子班等作乱及被清除。

<a id="note-7"></a>

7. **《左传·成公十三年》**详记曹负刍杀太子自立。

<a id="note-8"></a>

8. **《春秋·成公十三年》**：“秋七月，公至自伐秦。冬，葬曹宣公。”

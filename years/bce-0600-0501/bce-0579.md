# 公元前579年（鲁成公十二年）

[← 上一张已编年页：公元前580年](bce-0580.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前578年 →](bce-0578.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，周公楚正式出奔晋国。** 周王派人向诸侯通报王室内乱。 [[1]](#note-1)

<a id="event-2"></a>

2. **宋华元促成晋楚第一次正式弭兵。** 夏五月，晋士燮与楚公子罢、许偃在宋西门外盟誓，约定双方不互相用兵、共同救灾讨乱、保持道路畅通。 [[2]](#note-2)

<a id="event-3"></a>

3. **鲁成公会晋侯、卫侯于琐泽。** 郑伯也赴晋听取盟约，晋楚和谈开始影响中原诸侯。 [[3]](#note-3)

<a id="event-4"></a>

4. **狄人趁晋楚新盟防备松懈侵晋，秋天晋军在交刚击败狄军。** [[4]](#note-4)

<a id="event-5"></a>

5. **晋郤至赴楚聘问并履行盟约。** 楚国以隆重礼乐招待，双方虽表面修好，言谈中仍保留强烈戒心。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬，楚公子罢又赴晋聘问，并与晋侯在赤棘结盟。** 晋楚弭兵在这一年完成双向确认。 [[6]](#note-6)

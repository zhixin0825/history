# 公元前580年（鲁成公十一年）

[← 上一张已编年页：公元前581年](bce-0581.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前579年 →](bce-0579.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁成公从晋国返回。** 晋国因鲁国曾与楚结盟而怀疑鲁国，成公请求重新盟誓后才获准回国。 [[1]](#note-1)

<a id="event-2"></a>

2. **晋郤犫来鲁聘问并与鲁国结盟。** [[2]](#note-2)

<a id="event-3"></a>

3. **夏，季孙行父赴晋回聘并重申盟约。** [[3]](#note-3)

<a id="event-4"></a>

4. **秋，叔孙侨如赴齐修复旧好。** [[4]](#note-4)

<a id="event-5"></a>

5. **周公楚与王孙苏争权失败，两次出奔。** 王室内斗持续。 [[5]](#note-5)

<a id="event-6"></a>

6. **晋国郤至与周王室争夺鄇田。** 周王派刘康公、单襄公到晋国交涉。郤至以温地为晋国故地作理由，两位周臣则追述温地原属周王官邑、后来由周襄王赐给晋文公。晋侯最终命郤至停止争夺。 [[6]](#note-6)

<a id="event-7"></a>

7. **宋华元利用自己与楚令尹子重、晋栾书的关系，推动晋楚和谈。** 冬天华元先赴楚、再赴晋，终于促成双方议和。 [[7]](#note-7)

<a id="event-8"></a>

8. **晋厉公寿曼元年，秦晋试图在令狐会盟，但秦伯不肯过河，只隔河盟誓，双方互不信任。** 秦伯回国后很快背盟。 夹河盟后秦又联合狄谋晋，和议很快破裂。 [[8]](#note-8)

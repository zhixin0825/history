# 公元前581年（鲁成公十年）

[← 上一张已编年页：公元前582年](bce-0582.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前580年 →](bce-0580.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，卫国公子黑背率军侵郑，这是晋国命令的一部分。** 晋国继续施压郑国。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏四月，鲁国连续五次占卜郊祭都不吉，最终取消郊祭。** [[2]](#note-2)

<a id="event-3"></a>

3. **郑国内部因晋楚压力再起政变。** 公子班想另立公子繻，郑人随即诛杀繻，改立髠顽；子如逃往许国。 [[3]](#note-3)

<a id="event-4"></a>

4. **五月，鲁成公会晋、齐、宋、卫、曹伐郑。** 晋景公病重，晋国先立太子州蒲主持政务，再率诸侯逼郑。 [[4]](#note-4)

<a id="event-5"></a>

5. **郑国以重器、盟誓和人质向晋求和，郑伯获释回国。** [[5]](#note-5)

<a id="event-6"></a>

6. **晋景公病重，秦国名医缓来诊，判断病已入膏肓，无药可治。** 晋侯六月去世。 [[6]](#note-6)

<a id="event-7"></a>

7. **齐国派媵女来鲁。** [[7]](#note-7)

<a id="event-8"></a>

8. **秋，鲁成公亲赴晋国，被晋人留下参加晋景公葬礼。** 鲁人认为这是受辱，因此经文没有记“葬晋景公”。 [[8]](#note-8)

<a id="event-9"></a>

9. **春，晋国使籴茷出聘楚国，回报楚大宰子商的聘问。** 到了秋季鲁君被留晋送葬时，籴茷仍未归来；出使及后文相接，不误作另一人。 [[9]](#note-9)

<a id="event-10"></a>

10. **齐灵公环元年。** 齐顷公已于上年去世，其子环继位，即齐灵公；《十二诸侯年表》从本年开始记灵公元年，不再把顷公的死亡写作本年发生。 [[10]](#note-10)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·成公十年》**：“十年春，卫侯之弟黑背帅师侵郑。”  
   **《左传·成公十年》**：“晋命也。”

<a id="history-legacy-source-2"></a>


2. **《春秋·成公十年》**：“夏四月，五卜郊，不从，乃不郊。”

<a id="history-legacy-source-3"></a>


3. **《左传·成公十年》**详记郑公子班、公子繻、髠顽及子如之变。

<a id="history-legacy-source-4"></a>


4. **《春秋·成公十年》**：“五月，公会晋侯、齐侯、宋公、卫侯、曹伯伐郑。”

<a id="history-legacy-source-5"></a>


5. **《左传·成公十年》**详记郑以襄钟、盟誓和人质求成，郑伯归国。

<a id="history-legacy-source-6"></a>


6. **《春秋·成公十年》**：“丙午，晋侯獳卒。”  
   **《左传·成公十年》**详记晋景公梦厉、医缓诊病与卒于厕。

<a id="history-legacy-source-7"></a>


7. **《春秋·成公十年》**：“齐人来媵。”

<a id="history-legacy-source-8"></a>


8. **《春秋·成公十年》**：“秋七月，公如晋。”  
   **《左传·成公十年》**详记晋止成公送葬及鲁人以为辱。

<a id="history-legacy-source-9"></a>


10. **《史记·十二诸侯年表》前581年齐栏**记“齐灵公环元年”。[原表行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0581)。[《齐太公世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7032.md#ref-f1331f98566232)记顷公十七年去世，其子灵公环立；[前582年顷公卒](bce-0582.md#event-3)已有正文。此处只补本年纪元与继位承接，未凭元年另定死亡月日。

<a id="event-5"></a>

1. **晋会诸侯伐郑，郑请和后成公获释。** 郑国内部因晋楚压力再起政变。公子班想另立公子繻，郑人随即诛杀繻，改立髠顽。子如逃往许国。春，卫国公子黑背率军侵郑，这是晋国命令的一部分。晋国继续施压郑国。五月，鲁成公会晋、齐、宋、卫、曹伐郑。晋景公病重，晋国先立太子州蒲主持政务，再率诸侯逼郑。郑国以重器、盟誓和人质向晋求和，郑伯获释回国。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏四月，鲁国连续五次占卜郊祭都不吉，最终取消郊祭。** [[2]](#note-2)

<a id="event-6"></a>

<a id="event-8"></a>

3. **晋景公病重，鲁成公赴晋参加葬礼。** 晋景公病重，秦医缓诊视，判断病入膏肓。秋，鲁成公赴晋，被留参加晋景公的葬礼。 [[3]](#note-6)

<a id="event-7"></a>

4. **齐国派媵女来鲁。** [[4]](#note-7)

<a id="event-9"></a>

5. **春，晋国使籴茷出聘楚国，回报楚大宰子商的聘问。** 到了秋季鲁君被留晋送葬时，籴茷仍未归来；出使及后文相接，不误作另一人。 [[5]](#note-9)

<a id="event-10"></a>

6. **齐灵公环元年。** 齐顷公上年去世，儿子环继位，本年为齐灵公元年。 [[6]](#note-10)

<a id="sj042-cite-088"></a>

**[《史记·郑世家》P033](../../sources/摘录/史记-卷042-郑世家.md#p033)**

> 四年春，鄭患晉圍，公子如乃立成公庶兄繻為君。

**本卷说明：** 世家写公子如立成公庶兄繻；经传详记公子班谋立、杀繻立髡顽及子如出奔，正文保留这些旧细节，不拿短文替代。此繻不是后来的繻公駘。

<a id="sj039-cite-208"></a>

**[《史记·晋世家》P108](../../sources/摘录/史记-卷039-晋世家.md#p108)**

> 十九年夏，景公病，立其太子壽曼為君，是為厲公。


**本卷说明：** 太子在景公生前被立主持政务；寿曼与经传州蒲为厉公姓名异写，不能写成景公卒后才第一次立太子。

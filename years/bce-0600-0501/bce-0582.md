# 公元前582年（鲁成公九年）

[← 上一张已编年页：公元前583年](bce-0583.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前581年 →](bce-0581.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，杞桓公来鲁迎回叔姬遗体；鲁成公又会晋、齐、宋、卫、郑、曹、莒、杞在蒲地同盟，会后返回鲁国。** 晋国因归还汶阳田导致诸侯离心，只能再次重申盟约。 [[1]](#note-1)

<a id="event-2"></a>

2. **二月，伯姬正式嫁到宋国；夏，季孙行父赴宋致女，晋国也派媵女。** [[2]](#note-2)

<a id="event-3"></a>

3. **秋，齐顷公去世；冬十一月安葬。** [[3]](#note-3)

<a id="event-4"></a>

<a id="event-5"></a>

<a id="event-8"></a>

4. **晋扣押郑成公，楚救郑，郑以围许示强。** 郑成公赴晋，被晋以反复亲楚为由扣押。楚公子婴齐出兵救郑。郑人又去围许，故意让晋看到郑国仍可在外用兵，试图促晋放还国君。 [[4]](#note-4)

<a id="event-6"></a>

5. **冬，楚军从陈国转攻莒国，连续攻破渠丘、莒城，并进入郓地。** 莒国长期依赖城陋而不修备，迅速崩溃。 [[5]](#note-6)

<a id="event-7"></a>

6. **秦人与白狄联合伐晋。** 晋国归还汶阳田、诸侯离心也影响秦晋局势。 [[6]](#note-7)

<a id="event-9"></a>

7. **鲁国修筑中城。** [[7]](#note-9)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·成公九年》**：“九年春，王正月，杞伯来逆叔姬之丧以归。公会晋侯、齐侯、宋公、卫侯、郑伯、曹伯、莒子、杞伯同盟于蒲。公至自会。”

<a id="history-legacy-source-2"></a>


2. **《春秋·成公九年》**：“二月，伯姬归于宋。夏，季孙行父如宋致女。晋人来媵。”

<a id="history-legacy-source-3"></a>


3. **《春秋·成公九年》**：“秋七月丙子，齐侯无野卒……冬十有一月，葬齐顷公。”

<a id="history-legacy-source-4"></a>


4. **《春秋·成公九年》**：“晋人执郑伯。晋栾书帅师伐郑。”  
   **《左传·成公九年》**详记郑伯被执铜鞮。

<a id="history-legacy-source-5"></a>


5. **《左传·成公九年》**：“楚子重侵陈以救郑。”子重即楚公子婴齐；同篇又记晋国放还楚俘钟仪，使其归楚商议和好。此处是楚国救郑的行动，不同于下条《春秋》所记的“楚公子婴齐帅师伐莒”。 [《十二诸侯年表》前582年楚栏](../../拆分史书/史记/卷014.md#y0582)另称“冬与晋成”。目前《左传》明确写出的程序是晋遣钟仪归楚、双方推动和谈，而前580年华元促成晋楚进一步议和另有记录；本年是否已经正式订盟、与后事有何区别，暂保留年表用语而不冒称所有程序已确证。

<a id="history-legacy-source-6"></a>


6. **《春秋·成公九年》**：“庚申，莒溃。楚人入郓。”  
   **《左传·成公九年》**详记楚攻渠丘、莒及郓。

<a id="history-legacy-source-7"></a>


7. **《春秋·成公九年》**：“秦人、白狄伐晋。”

<a id="history-legacy-source-8"></a>


8. **《春秋·成公九年》**：“郑人围许。”  
   **《左传·成公九年》**详记郑以围许逼晋归君。 
   **年表郑栏互见：**[前582年郑栏](../../拆分史书/史记/卷014.md#y0582)另记“与楚盟”，与本年《左传》描述郑君被晋拘押、楚国救郑及郑围许相互关联；然而目前据此不能独立确定缔盟的时间、地点和仪式，也不能把前580年晋楚和谈误当作郑楚盟誓。此处保存年表的结盟记载，留待补证。

<a id="history-legacy-source-9"></a>


9. **《春秋·成公九年》**：“城中城。”

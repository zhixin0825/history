# 公元前582年（鲁成公九年）

[← 上一张已编年页：公元前583年](bce-0583.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前581年 →](bce-0581.md)

<a id="event-1"></a>

1. **春，杞桓公来鲁迎回叔姬遗体；鲁成公又会晋、齐、宋、卫、郑、曹、莒、杞在蒲地同盟，会后返回鲁国。** 晋国因归还汶阳田导致诸侯离心，只能再次重申盟约。[1]

<a id="event-2"></a>

2. **二月，伯姬正式嫁到宋国；夏，季孙行父赴宋致女，晋国也派媵女。** [2]

<a id="event-3"></a>

3. **秋，齐顷公去世；冬十一月安葬。** [3]

<a id="event-4"></a>

4. **郑成公到晋国，被晋国以反复亲楚为由扣押。** 晋栾书随即率军伐郑。[4]

<a id="event-5"></a>

5. **楚公子婴齐出兵救郑。** 晋国释放楚俘钟仪，让他回楚推动晋楚和谈。[5]

<a id="event-6"></a>

6. **冬，楚军从陈国转攻莒国，连续攻破渠丘、莒城，并进入郓地。** 莒国长期依赖城陋而不修备，迅速崩溃。[6]

<a id="event-7"></a>

7. **秦人与白狄联合伐晋。** 晋国归还汶阳田、诸侯离心也影响秦晋局势。[7]

<a id="event-8"></a>

8. **郑人包围许国，想向晋国表示自己并不急于救被扣的国君，以此迫晋放人。** [8]

<a id="event-9"></a>

9. **鲁国修筑中城。** [9]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·成公九年》**：“九年春，王正月，杞伯来逆叔姬之丧以归。公会晋侯、齐侯、宋公、卫侯、郑伯、曹伯、莒子、杞伯同盟于蒲。公至自会。”

<a id="note-2"></a>

2. **《春秋·成公九年》**：“二月，伯姬归于宋。夏，季孙行父如宋致女。晋人来媵。”

<a id="note-3"></a>

3. **《春秋·成公九年》**：“秋七月丙子，齐侯无野卒……冬十有一月，葬齐顷公。”

<a id="note-4"></a>

4. **《春秋·成公九年》**：“晋人执郑伯。晋栾书帅师伐郑。”  
   **《左传·成公九年》**详记郑伯被执铜鞮。

<a id="note-5"></a>

5. **《春秋·成公九年》**：“楚公子婴齐帅师伐郑。”  
   **《左传·成公九年》**详记钟仪归楚求成。

<a id="note-6"></a>

6. **《春秋·成公九年》**：“庚申，莒溃。楚人入郓。”  
   **《左传·成公九年》**详记楚攻渠丘、莒及郓。

<a id="note-7"></a>

7. **《春秋·成公九年》**：“秦人、白狄伐晋。”

<a id="note-8"></a>

8. **《春秋·成公九年》**：“郑人围许。”  
   **《左传·成公九年》**详记郑以围许逼晋归君。

<a id="note-9"></a>

9. **《春秋·成公九年》**：“城中城。”

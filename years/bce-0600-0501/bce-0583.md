# 公元前583年（鲁成公八年）

[← 上一张已编年页：公元前584年](bce-0584.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前582年 →](bce-0582.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，晋景公命鲁国把汶阳田重新归还齐国。** 季文子批评晋国七年之间一夺一还，失去盟主应有的信用。 [[1]](#note-1)

<a id="event-2"></a>

2. **晋栾书侵蔡并继续深入楚境。** 晋军同时打击沈国，晋楚竞争继续。 [[2]](#note-2)

<a id="event-3"></a>

3. **公孙婴齐前往莒国迎亲；宋华元来鲁聘问共姬婚事。** [[3]](#note-3)

<a id="event-4"></a>

4. **夏，宋国派公孙寿来鲁纳币，为共姬婚礼做准备。** [[4]](#note-4)

<a id="event-5"></a>

5. **晋国内赵庄姬因赵婴被逐，诬告赵同、赵括谋乱。** 晋景公清算赵同、赵括，并把赵氏田邑交给祁奚；韩厥进谏后，晋景公重新立赵武为赵氏继承人，归还原有田邑，使赵氏得以延续。 [[5]](#note-5)

<a id="event-6"></a>

6. **秋，周王派召伯来赐鲁成公命。** [[6]](#note-6)

<a id="event-7"></a>

7. **冬，杞叔姬去世。** [[7]](#note-7)

<a id="event-8"></a>

8. **晋士燮来鲁聘问，并要求鲁国参加伐郯。** 鲁国原想延缓，最后仍由叔孙侨如会晋、齐、邾出兵伐郯。 [[8]](#note-8)

<a id="event-9"></a>

9. **卫国派媵女来鲁，为共姬婚礼助嫁。** [[9]](#note-9)

## 本年相关史料

<a id="note-1"></a>

### 1. 春，晋景公命鲁国把汶阳田重新归还齐国

[返回正文第1条](#event-1)

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0583.md#all-20261109-t001)**

> 八年春，晋侯使韩穿来言汶阳之田，归之于齐。季文子饯之，私焉，曰：“大国制义以为盟主，是以诸侯怀德畏讨，无有贰心。谓汶阳之田，敝邑之旧也，而用师于齐，使归诸敝邑。今有二命曰：‘归诸齐。’信以行义，义以成命，小国所望而怀也。信不可知，义无所立，四方诸侯，其谁不解体？《诗》曰：‘女也不爽，士贰其行。士也罔极，二三其德。’七年之中，一与一夺，二三孰甚焉！士之二三，犹丧妃耦，而况霸主？霸主将德是以，而二三之，其何以长有诸侯乎？《诗》曰：‘犹之未远，是用大简。’行父惧晋之不远犹而失诸侯也，是以敢私言之。”

# 公元前583年（鲁成公八年）

[← 上一张已编年页：公元前584年](bce-0584.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前582年 →](bce-0582.md)

<a id="event-1"></a>

1. **春，晋景公命鲁国把汶阳田重新归还齐国。** 季文子批评晋国七年之间一夺一还，失去盟主应有的信用。[[1]](#note-1)

<a id="event-2"></a>

2. **晋栾书侵蔡并继续深入楚境。** 晋军同时打击沈国，晋楚竞争继续。[[2]](#note-2)

<a id="event-3"></a>

3. **公孙婴齐前往莒国迎亲；宋华元来鲁聘问共姬婚事。** [[3]](#note-3)

<a id="event-4"></a>

4. **夏，宋国派公孙寿来鲁纳币，为共姬婚礼做准备。** [[4]](#note-4)

<a id="event-5"></a>

5. **晋国内赵庄姬因赵婴被逐，诬告赵同、赵括谋乱。** 晋景公清算赵同、赵括，并把赵氏田邑交给祁奚；韩厥进谏后，晋景公重新立赵武为赵氏继承人，归还原有田邑，使赵氏得以延续。[[5]](#note-5)

<a id="event-6"></a>

6. **秋，周王派召伯来赐鲁成公命。** [[6]](#note-6)

<a id="event-7"></a>

7. **冬，杞叔姬去世。** [[7]](#note-7)

<a id="event-8"></a>

8. **晋士燮来鲁聘问，并要求鲁国参加伐郯。** 鲁国原想延缓，最后仍由叔孙侨如会晋、齐、邾出兵伐郯。[[8]](#note-8)

<a id="event-9"></a>

9. **卫国派媵女来鲁，为共姬婚礼助嫁。** [[9]](#note-9)

## 本年相关史料

   **《左传·成公八年》**详记季文子批评晋国反复。

<a id="note-2"></a>

2. **《春秋·成公八年》**：“晋栾书帅师侵蔡。”  
   **《左传·成公八年》**详记侵蔡、楚及沈。

<a id="note-3"></a>

3. **《春秋·成公八年》**：“公孙婴齐如莒。宋公使华元来聘。”

<a id="note-4"></a>

4. **《春秋·成公八年》**：“夏，宋公使公孙寿来纳币。”

<a id="note-5"></a>

   **《左传·成公八年》**详记赵庄姬诬告、赵氏田邑一度交祁奚，以及韩厥进谏后“乃立武，而反其田焉”。[经传原文](https://zh.wikisource.org/wiki/春秋左氏傳/成公#成公八年) · [《十二诸侯年表》前583年晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0583)记“复赵武田邑”。

<a id="note-6"></a>

6. **《春秋·成公八年》**：“秋七月，天子使召伯来赐公命。”

<a id="note-7"></a>

7. **《春秋·成公八年》**：“冬十月癸卯，杞叔姬卒。”

<a id="note-8"></a>

8. **《春秋·成公八年》**：“晋侯使士燮来聘。叔孙侨如会晋士燮、齐人、邾人伐郯。”

9. **《春秋·成公八年》**：“卫人来媵。”

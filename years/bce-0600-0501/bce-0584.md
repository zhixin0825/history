1. **春，鲁国郊祭牺牛两次被鼷鼠咬坏牛角，最终取消郊祭，却仍举行三望。** [[1]](#note-1)

<a id="event-5"></a>

<a id="event-6"></a>

2. **巫臣联吴制楚，吴出兵攻郯和州来。** 巫臣与楚国子重、子反结怨后，推动晋吴联络，并把儿子狐庸留在吴国。吴国此后不断进攻楚国属地，楚军一年多次奔命。巫臣留在楚国的家族遭子反等清除，他写信誓使对方疲于奔命，再向晋请出使吴，教授车战并让儿子留吴任行人。吴国进攻郯国并迫使其求和。季文子由此警惕南方吴国开始进入中原事务。同年吴军攻入州来。晋国申公巫臣已开始出使吴国、教吴车战阵法，吴国由此成为牵制楚国的新力量。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，曹宣公来鲁朝见。** [[3]](#note-3)

<a id="event-4"></a>

<a id="event-9"></a>

<a id="event-10"></a>

4. **郑成公元年，晋会诸侯救郑并盟于马陵。** 郑成公睔从本年纪元。春，子良陪同郑成公赴晋，感谢晋此前救郑。秋，楚军再伐郑，鲁成公与晋、齐、宋、卫、曹、莒、邾、杞等救郑，并在马陵订盟。鲁成公会后归国。 [[4]](#note-4)

<a id="event-7"></a>

5. **冬，鲁国举行大雩。** [[5]](#note-7)

<a id="event-8"></a>

6. **卫国孙林父因与卫定公交恶出奔晋国。** 晋国随后把戚地还给他。 [[6]](#note-8)

### 2. 巫臣联吴制楚，吴出兵攻郯和州来

[返回正文第2条](#event-2)

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0584.md#all-20261109-t001)**

> 七年春，吴伐郯，郯成。季文子曰：“中国不振旅，蛮夷入伐，而莫之或恤，无吊者也夫！《诗》曰：‘不吊昊天，乱靡有定。’其此之谓乎！有上不吊，其谁不受乱？吾亡无日矣！”君子曰：“知惧如是，斯不亡矣。”

[史料说明](#history-legacy-source-2)

<a id="note-5"></a>

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0584.md#all-20261109-t006)**

> 巫臣请使于吴，晋侯许之。吴子寿梦说之。乃通吴于晋。以两之一卒適吴，舍偏两之一焉。与其射御，教吴乘车，教之战陈，教之叛楚。寘其子狐庸焉，使为行人于吴。吴始伐楚，伐巢，伐徐。子重奔命。马陵之会，吴入州来。子重自郑奔命。子重、子反于是乎一岁七奔命。蛮夷属于楚者，吴尽取之。是以始大，通吴于上国。卫定公恶孙林父。

[史料说明](#history-legacy-source-5)

<a id="sj039-cite-206"></a>

**[《史记·晋世家》P106](../../sources/摘录/史记-卷039-晋世家.md#p106)**

> 吳晉始通，約伐楚。


**本卷说明：** 吴入州来及侵楚作为通吴后的实际行动在本年原条阅读，不把使吴和每次侵楚都认定同日。

<!-- /sj039-cite-206 -->

<a id="note-6"></a>

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0584.md#all-20261109-t005)**

> 楚围宋之役，师还。子重请取于申、吕以为赏田，王许之。申公巫臣曰：“不可。此申、吕所以邑也，是以为赋，以御北方。若取之，是无申、吕也。晋、郑必至于汉。”王乃止。子重是以怨巫臣。子反欲取夏姬，巫臣止之，遂取以行。子反亦怨之。及共王即位，子重、子反杀巫臣之族子阎、子荡及清尹弗忌及襄老之子黑要，而分其室。子重取子阎之室，使沈尹与王子罢分子荡之室，子反取黑要与清尹之室。巫臣自晋遗二子书曰：“尔以谗慝贪惏事君，而多杀不辜。余必使尔罢于奔命以死。”

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0584.md#all-20261109-t006)**

> 巫臣请使于吴，晋侯许之。吴子寿梦说之。乃通吴于晋。以两之一卒適吴，舍偏两之一焉。与其射御，教吴乘车，教之战陈，教之叛楚。寘其子狐庸焉，使为行人于吴。吴始伐楚，伐巢，伐徐。子重奔命。马陵之会，吴入州来。子重自郑奔命。子重、子反于是乎一岁七奔命。蛮夷属于楚者，吴尽取之。是以始大，通吴于上国。卫定公恶孙林父。

[史料说明](#history-legacy-source-6)

<a id="sj039-cite-205"></a>

**[《史记·晋世家》P106](../../sources/摘录/史记-卷039-晋世家.md#p106)**

> 十六年，楚將子反怨巫臣，滅其族。巫臣怒，遺子反書曰：「必令子罷於奔命！」乃請使吳，令其子為吳行人，教吳乘車用兵。吳晉始通，約伐楚。


**本卷说明：** 个人仇怨、晋吴合作和吴楚军事行动关联而不等同；“始通”不据此否定早期一切交通。

##### 补充互见｜巫臣到吴国，教车战并留下儿子联络

**时间：寿梦二年／鲁成公七年** · 事件

从楚逃到晋的巫臣奉晋命到吴，教吴人用兵、驾战车，留下儿子做吴的行人。吴由此同中原诸国建立联系，随后攻楚。

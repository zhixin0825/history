# 公元前584年（鲁成公七年）

[← 上一张已编年页：公元前585年](bce-0585.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前583年 →](bce-0583.md)

<a id="event-1"></a>

1. **春，鲁国郊祭牺牛两次被鼷鼠咬坏牛角，最终取消郊祭，却仍举行三望。** [[1]](#note-1)

<a id="event-2"></a>

2. **吴国进攻郯国并迫使其求和。** 季文子由此警惕南方吴国开始进入中原事务。[[2]](#note-2)

<a id="event-3"></a>

3. **夏，曹宣公来鲁朝见。** [[3]](#note-3)

<a id="event-4"></a>

4. **秋，楚军再次伐郑；鲁成公会晋、齐、宋、卫、曹、莒、邾、杞救郑，并在马陵同盟；会后成公返回鲁国。** [[4]](#note-4)

<a id="event-5"></a>

5. **同年吴军攻入州来。** 晋国申公巫臣已开始出使吴国、教吴车战阵法，吴国由此成为牵制楚国的新力量。[[5]](#note-5)

<a id="event-6"></a>

6. **巫臣与楚国子重、子反结怨后，推动晋吴联络，并把儿子狐庸留在吴国。** 吴国此后不断进攻楚国属地，楚军一年多次奔命。[[6]](#note-6)

<a id="event-7"></a>

7. **冬，鲁国举行大雩。** [[7]](#note-7)

<a id="event-8"></a>

8. **卫国孙林父因与卫定公交恶出奔晋国。** 晋国随后把戚地还给他。[[8]](#note-8)

<a id="event-9"></a>

9. **郑成公睔从本年开始纪元。** 郑悼公费已在前585年去世，由其弟睔继承君位；前584年是成公元年，并非再次即位。[[9]](#note-9)

<a id="event-10"></a>

10. **春，郑国子良陪同郑成公前往晋国拜见晋侯，并感谢晋军此前援救郑国。** 这是在秋季楚国再度伐郑以前的一次外交活动。[[10]](#note-10)

<a id="sj-031-L2951-01"></a>

#### 补充互见｜巫臣到吴国，教车战并留下儿子联络

**时间：寿梦二年／鲁成公七年** · 事件

从楚逃到晋的巫臣奉晋命到吴，教吴人用兵、驾战车，留下儿子做吴的行人。吴由此同中原诸国建立联系，随后攻楚。

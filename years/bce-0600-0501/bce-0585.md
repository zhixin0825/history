# 公元前585年（鲁成公六年）

[← 上一张已编年页：公元前586年](bce-0586.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前584年 →](bce-0584.md)

<a id="event-1"></a>

1. **春，鲁成公从虫牢会盟返回；二月在鲁国建立武宫。** 季文子把鞌之战功归到鲁国自身，立武宫纪功，这一做法受到批评。[[1]](#note-1)

<a id="event-2"></a>

2. **鲁国轻易取得鄟地。** [[2]](#note-2)

<a id="event-3"></a>

3. **晋国联合卫、郑及戎族侵宋，因为宋国拒绝参加诸侯会盟。** 卫国因信任晋国而没有设防，晋将一度想趁机袭卫，被伯宗阻止。[[3]](#note-3)

<a id="event-4"></a>

4. **晋国决定迁都新田。** 韩厥主张新田土厚水深、适合长期居住，晋景公采纳。[[4]](#note-4)

<a id="event-5"></a>

5. **夏六月，邾国国君来鲁朝见；鲁公孙婴齐赴晋；壬申日，郑悼公去世。** [[5]](#note-5)

<a id="event-6"></a>

6. **秋，鲁孟献子、叔孙侨如奉晋命侵宋。** [[6]](#note-6)

<a id="event-7"></a>

7. **楚公子婴齐伐郑，因为郑重新依晋。** [[7]](#note-7)

<a id="event-8"></a>

8. **冬，季孙行父赴晋祝贺迁都；晋栾书又出兵救郑，并与楚军相遇。** 晋军继续南下侵蔡，最终因多名将领劝止，没有与楚军决战。[[8]](#note-8)

<a id="event-9"></a>

9. **周简王夷本年为元年。** 周定王已于前586年去世、简王继位，本年开始按简王纪年，不是再次继位。[[9]](#note-9)

<a id="event-10"></a>

10. **吴国开始按寿梦元年纪事。** 寿梦继其父去齐为吴君，吴国在他在位时期逐渐强盛；这是寿梦的元年，不把次年巫臣通吴提前。[[10]](#note-10)

<a id="sj031-shoumeng-prior"></a>

### 寿梦登场前事｜吴国长支王统与中原虞国的区别

**寿梦以前，吴国王位传自太伯、仲雍、季简、叔达、周章的一支**；周章之后又历熊遂、柯相、彊鸠夷、余桥疑吾、柯卢、周繇、屈羽、夷吾、禽处、转、颇高、句卑、去齐，才轮到寿梦。传世谱系无每一君的可靠绝对年数，本年只是寿梦开始纪元，**绝不是上述诸人都在本年继立**。西周初另封的中原虞国是周章弟虞仲一系，其国见[前655年晋灭虞](../bce-0700-0601/bce-0655.md#event-7)，不能说成晋国灭掉吴国。

**史料与辨名：**[《史记》卷031 P003](../../sources/摘录/史记-卷031-吴太伯世家.md#p003) · [原卷“周章至去齐”](https://zh.wikisource.org/w/index.php?title=史記/卷031&oldid=7909287#周章至去齊)。原文将「转」「颇高」「句卑」另见「柯转」「颇梦」「毕轸」的异名留在源文考证，不当另立吴君。

# 公元前585年（鲁成公六年）

[← 上一张已编年页：公元前586年](bce-0586.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前584年 →](bce-0584.md)

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁成公从虫牢会盟返回；二月在鲁国建立武宫。** 季文子把鞌之战功归到鲁国自身，立武宫纪功，这一做法受到批评。 [[1]](#note-1)

<a id="event-2"></a>

2. **鲁国取得鄟地。** [[2]](#note-2)

<a id="event-3"></a>

<a id="event-6"></a>

3. **晋联诸国伐宋，鲁亦奉晋命侵宋。** 宋拒绝参加诸侯会盟，晋与卫、郑及戎族侵宋。秋，鲁孟献子、叔孙侨如奉晋命侵宋。 [[3]](#note-3)

<a id="event-4"></a>

<a id="event-8"></a>

4. **晋迁都新田，鲁季孙行父奉使致贺。** 晋把都城迁到新田，冬鲁季孙行父赴晋致贺。同期楚军进攻郑国，晋栾书出兵援郑，与楚军相遇。 [[4]](#note-4)

<a id="event-5"></a>

5. **夏六月，邾国国君来鲁朝见；鲁公孙婴齐赴晋；壬申日，郑悼公去世。** 悼公去世后，弟弟睔继位，为郑成公。 [[5]](#note-5)

<a id="event-7"></a>

6. **楚公子婴齐伐郑，因为郑重新依晋。** [[6]](#note-7)

<a id="event-9"></a>

7. **周简王夷本年为元年。** 周定王已于前586年去世、简王继位，本年开始按简王纪年，不是再次继位。 [[7]](#note-9)

<a id="event-10"></a>

<a id="sj031-shoumeng-prior"></a>
<a id="寿梦登场前事吴国长支王统与中原虞国的区别"></a>

<a id="event-11"></a>

<a id="event-12"></a>

8. **吴国寿梦元年，吴王世系。** 吴国开始按寿梦元年纪事。寿梦继其父去齐为吴君，吴国在他在位时期逐渐强盛。这是寿梦的元年，不把次年巫臣通吴提前。寿梦以前，吴国王位传自太伯、仲雍、季简、叔达、周章的一支。周章之后又历熊遂、柯相、彊鸠夷、余桥疑吾、柯卢、周繇、屈羽、夷吾、禽处、转、颇高、句卑、去齐，才轮到寿梦。传世谱系无每一君的可靠绝对年数，本年只是寿梦开始纪元，**绝不是上述诸人都在本年继立**。西周初另封的中原虞国是周章弟虞仲一系，其国见[前655年晋灭虞](../bce-0700-0601/bce-0655.md#event-7)，不能说成晋国灭掉吴国。前事辨名：转、颇高、句卑各有异写。寿梦以前的吴君世系中，这三个名字另见「柯转」「颇梦」「毕轸」。作为异名保留，不据此另立三位吴君。 [[8]](#note-10)

<a id="note-12"></a>

<a id="12-史料与辨名"></a>

**登场前事：** 本组原文用于辨认寿梦以前吴国君主的异名，不表示这些君主都在本年继位，也不凭异名另增吴君。

**[《史记》卷031《吴太伯世家》及《索隐》](../../sources/史记三家注/卷031.md#p3)**

> 禽處卒，子轉立。〔索隱〕譙周古史考云「柯轉」。轉卒，子頗高立。〔索隱〕古史考作「頗夢」。頗高卒，子句卑立。〔索隱〕古史考云「畢軫」。

**编读说明：** 以下是现代整理说明，不是古文引文。传世王统依次为：**周章—熊遂—柯相—彊鳩夷—餘橋疑吾—柯盧—周繇—屈羽—夷吾—禽處—轉—頗高—句卑—去齊—壽夢**。原文主要给世系，**并没有这些吴君各自足以折算为公元年份的在位数**；「自太伯至寿梦十九世」是作者的世数概括，不能等分五百余年。

卷内用晋献公灭中原虞国作旁证，指吴国句卑一代与北虞灭亡前后相接；有可确年事件的部分在[前655年晋灭虞](../../years/bce-0700-0601/bce-0655.md#event-7)。这是与吴国共祖而久已分流的中原虞国，**不是吴被晋所灭**。句卑的具体在位起讫不可仅凭「是时」二字断年；去齐之后寿梦开始强盛、称王则以[前585年寿梦元年](../../years/bce-0600-0501/bce-0585.md#event-10)衔接。

# 公元前586年（鲁成公五年）

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，杞叔姬被夫家遣回鲁国；仲孙蔑赴宋回聘。** [[1]](#note-1)

<a id="event-2"></a>

2. **赵同、赵括把赵婴放逐到齐国。** 赵氏内部矛盾继续扩大。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，叔孙侨如在穀地会晋荀首。** 荀首此行是去齐国迎亲。 [[3]](#note-3)

<a id="event-4"></a>

4. **梁山崩塌。** 晋景公急召伯宗商议。伯宗赶路时向一名绛地运车人问计；对方建议国君暂停宴乐、降服、出次，并由祝史按礼祭告。伯宗请这人亲自面见晋侯未果，便转述其建议，晋国随后照办。 [[4]](#note-4)

<a id="event-5"></a>

5. **郑悼公费元年。** 郑襄公已在上年去世。本年郑悼公赴楚与许国争讼失败，楚人扣押郑国的皇戍和子国；郑国于是重新转向晋国。秋，郑伯与晋赵同在垂棘结盟。 [[5]](#note-5)

<a id="event-6"></a>

6. **秋，鲁国发生大水。** [[6]](#note-6)

<a id="event-7"></a>

7. **冬，周定王去世；鲁成公与晋、齐、宋、卫、郑、曹、邾、杞在虫牢同盟。** 郑国重新服晋。 [[7]](#note-7)

   周定王去世，儿子夷继位，即简王；虫牢会盟的诸侯事务不因王室更替而停止。 [卷四互见与归年](#sj004-586-1)

<a id="event-8"></a>

8. **燕昭公本年为元年。** 燕宣公在位十五年后由昭公接续，元年起算不另作本年再次即位。此处是春秋时期的燕昭公，不是战国时期的燕昭王。 [[8]](#note-8)

<a id="hs-event-9"></a>

9. **鲁秋大水。** 《汉书》在本年记载鲁秋大水。 [[9]](#hs-note-9)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·成公五年》**：“五年春，王正月，杞叔姬来归。仲孙蔑如宋。”

<a id="history-legacy-source-2"></a>


2. **《左传·成公五年》**详记原、屏放赵婴于齐。

<a id="history-legacy-source-3"></a>


3. **《春秋·成公五年》**：“夏，叔孙侨如会晋荀首于穀。”

<a id="history-legacy-source-4"></a>


4. **《春秋·成公五年》**：“梁山崩。”  
   **《左传·成公五年》**记晋侯急召伯宗，伯宗向绛地运车人询问处置办法，路人提出减损礼乐、祝史祭告，伯宗“请见之，不可。遂以告而从之”。**《史记·十二诸侯年表》前586年晋栏**强调“伯宗隐其人而用其言”：[原表年行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0586)。应区分《左传》未能安排面君与年表突出隐其人这一叙事差别；建议不是伯宗自行创制。

<a id="history-legacy-source-5"></a>


5. **《左传·成公五年》**记许灵公先向楚申诉，六月郑悼公赴楚争讼未胜，楚人拘押郑国的皇戍和子国；郑悼公回国后派公子偃向晋求和，八月与晋赵同在垂棘结盟。**《春秋左传正义》卷二十六《成公五年传》**作“皇戍”，杜预注子国为郑穆公之子；另见“皇戌”写法，暂视为同一人名的字形异文。[原传及注](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E5%82%B3%E6%AD%A3%E7%BE%A9-%E5%8D%B726.md#ref-fc8a9b8bf64862)。  
   **《史记·十二诸侯年表》前586年郑栏**记“郑悼公费元年公如楚讼”；**《郑世家》**记郑襄公十八年去世，子悼公“沸”继位，又以悼公元年叙述与楚国争讼。[年表原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0586) · [《郑世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7042.md#ref-aa9766bb6a6e17)。年表称“费”、世家称“沸”，保留名字异文；前587年已记襄公去世，不将本年纪元另算一次即位。 **楚国栏归年差异：**年表在[前586年楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0586)另有“伐郑，倍我故也”，但《左传·成公五年》明确的只是楚郑讼事、楚扣郑臣及郑转晋；[次年前585年](bce-0585.md#event-7)《春秋·成公六年》明记“楚公子婴齐帅师伐郑”。两种纪年暂并存；不能凭年表简语在本年另造一次已独立核实的楚国攻郑。

<a id="history-legacy-source-6"></a>


6. **《春秋·成公五年》**：“秋，大水。”

<a id="history-legacy-source-7"></a>


7. **《春秋·成公五年》**：“冬十有一月己酉，天王崩。十有二月己丑，公会晋侯、齐侯、宋公、卫侯、郑伯、曹伯、邾子、杞伯同盟于虫牢。”  
   **《左传·成公五年》**：“郑服也。”

<a id="history-legacy-source-8"></a>


8. **《史记·十二诸侯年表》前586年燕栏**：“燕昭公元年。”[原表年行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0586)。**《史记·燕召公世家》**：“宣公十五年卒，昭公立。”[原文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7034.md#ref-b547c8665dd56e)；承接[前587年年表燕宣公十五年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0587)，这里仅补燕国纪年，不另造一次继位事。

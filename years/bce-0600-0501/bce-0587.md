# 公元前587年（鲁成公四年）

[← 上一张已编年页：公元前588年](bce-0588.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前586年 →](bce-0586.md)

<a id="event-1"></a>

1. **春，宋华元来鲁聘问；三月郑襄公去世，杞伯来鲁朝见。** [[1]](#note-1)

<a id="event-2"></a>

2. **夏四月，臧孙许去世。** 鲁国失去鞌之战中的重要卿大夫。[[2]](#note-2)

<a id="event-3"></a>

3. **夏，鲁成公亲赴晋国，却受到晋景公怠慢；同季安葬郑襄公。** 成公一度想转向楚国、背离晋国，季文子坚决反对。[[3]](#note-3)

<a id="event-4"></a>

4. **秋，成公从晋国返回，最终没有叛晋。** [[4]](#note-4)

<a id="event-5"></a>

5. **冬，鲁国修筑郓城。** [[5]](#note-5)

<a id="event-6"></a>

6. **郑国与许国争地，郑军伐许；晋国随后救许伐郑，楚军又救郑。** 郑许争端被卷入晋楚竞争。[[6]](#note-6)

<a id="event-7"></a>

7. **赵婴与赵庄姬私通。** 这一事件将直接引发赵氏内部大乱。[[7]](#note-7)

<a id="note-4"></a>

4. **《春秋·成公四年》**：“秋，公至自晋。”

<a id="note-5"></a>

5. **《春秋·成公四年》**：“冬，城郓。”

<a id="note-6"></a>

6. **《春秋·成公四年》**：“郑伯伐许。”  
   **《左传·成公四年》**详记晋救许伐郑、楚救郑与郑许争讼。

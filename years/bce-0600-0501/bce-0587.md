# 公元前587年（鲁成公四年）

[← 上一张已编年页：公元前588年](bce-0588.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前586年 →](bce-0586.md)

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，宋华元来鲁聘问；三月郑襄公去世，杞伯来鲁朝见。** [[1]](#note-1)

<a id="event-2"></a>

2. **夏四月，臧孙许去世。** 鲁国失去鞌之战中的重要卿大夫。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，鲁成公亲赴晋国，却受到晋景公怠慢；同季安葬郑襄公。** 成公一度想转向楚国、背离晋国，季文子坚决反对。 [[3]](#note-3)

<a id="event-4"></a>

4. **秋，成公从晋国返回，最终没有叛晋。** [[4]](#note-4)

<a id="event-5"></a>

5. **冬，鲁国修筑郓城。** [[5]](#note-5)

<a id="event-6"></a>

6. **郑国与许国争地，郑军伐许；晋国随后救许伐郑，攻取郑国汜祭，楚军又救郑。** 郑许争端被卷入晋楚竞争。 [[6]](#note-6)

<a id="event-7"></a>

7. **赵婴与赵庄姬私通。** 这一事件将直接引发赵氏内部大乱。 [[7]](#note-7)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·成公四年》**：“四年春，宋公使华元来聘。三月壬申，郑伯坚卒。杞伯来朝。”

<a id="history-legacy-source-2"></a>


2. **《春秋·成公四年》**：“夏四月甲寅，臧孙许卒。”

<a id="history-legacy-source-3"></a>


3. **《春秋·成公四年》**：“公如晋。葬郑襄公。”  
   **《左传·成公四年》**详记晋侯不敬、成公欲叛晋及季文子劝阻。

<a id="history-legacy-source-4"></a>


4. **《春秋·成公四年》**：“秋，公至自晋。”

<a id="history-legacy-source-5"></a>


5. **《春秋·成公四年》**：“冬，城郓。”

<a id="history-legacy-source-6"></a>


6. **《春秋·成公四年》**：“郑伯伐许。”  
   **《左传·成公四年》**：“晋栾书将中军……以救许，伐郑，取汜祭。楚子反救郑。”明确记载晋军攻取汜祭，并详记郑、许争讼。[原传](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E6%88%90%E5%85%AC.md#ref-4f3bde1b9123f3)  
   **《史记·十二诸侯年表》前587年郑栏**：“晋栾书取我氾。襄公薨。”[国别原表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7014.md#ref-8eec4573801e0f) · [原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0587)。年表记“氾”，《左传》记“汜祭”，此处按《左传》补战争结果，保留两书地名文字之别，不作两次攻取。

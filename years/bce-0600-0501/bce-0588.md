# 公元前588年（鲁成公三年）

[← 上一张已编年页：公元前589年](bce-0589.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前587年 →](bce-0587.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁成公会晋、宋、卫、曹伐郑，追究邲之战中郑国依楚。** 郑军设伏反击，联军并未取得决定性成果。 [[1]](#note-1)

<a id="event-2"></a>

2. **同月安葬卫穆公；二月鲁成公从伐郑战事返回。** [[2]](#note-2)

<a id="event-3"></a>

3. **鲁国新宫失火，连续三日举哀；随后安葬宋文公。宋文公去世后，其子瑕继为宋君，本年是宋共公元年。** 宋国为文公采用厚葬。 [[3]](#note-3)

<a id="event-4"></a>

4. **夏，鲁成公亲赴晋国，感谢晋国在鞌战后帮助收回汶阳田，随后返回鲁国。** [[4]](#note-4)

<a id="event-5"></a>

5. **郑国这一年两次伐许：夏由公子去疾率军出兵，冬季又再次进攻。** 许国依楚而不服郑，郑许冲突持续。 [[5]](#note-5)

<a id="event-6"></a>

6. **晋、楚交换俘虏，知罃从楚归晋。** 知罃面对楚王追问怨德，坚持说两国只是为社稷释怨，没有私人恩怨，楚王因此更加礼遇他。 [[6]](#note-6)

<a id="event-7"></a>

7. **秋，叔孙侨如围棘，巩固鲁国重新取得的汶阳田；鲁国又举行大雩。** [[7]](#note-7)

<a id="event-8"></a>

8. **晋、卫进攻啬咎如，继续清理赤狄余部。** [[8]](#note-8)

<a id="event-9"></a>

9. **冬，晋荀庚、卫孙良夫先后来鲁聘问并重申盟约。** 鲁国按晋、卫卿位高下安排先后。 [[9]](#note-9)

<a id="event-10"></a>

10. **晋国增设六军，奖励鞌之战功臣。** 这是鞌战后整军赏功的一环；韩厥的卿位与献子称号在家族传述中一并提及，不能把增置军卿说成晋此前完全没有卿。 [[10]](#note-10)

<a id="event-11"></a>

11. **齐顷公前往晋国朝见晋景公，归国后逐步调整施政。** 他曾提议尊晋景公为王，景公辞让，仍承认周天子的名分。顷公归国后开放苑囿、减赋、赈孤问疾、出积粟救民并厚礼诸侯。这些包含朝晋后的措施和在位期间的总评，不能把直到去世百姓归附的叙述都写成前588年单年结果。 [[11]](#note-11)

<a id="sj014-0588-wei"></a>
<a id="event-12"></a>

12. **卫定公臧元年。** 卫穆公已于上年去世，定公继位；《十二诸侯年表》以本年为定公元年，不是再发生一次君主更替。 [[12]](#note-12)

[返回正文第6条](#event-6)

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0588.md#all-20261109-t004)**

> 晋人归公子穀臣与连尹襄老之尸于楚以求知罃。于是荀首佐中军矣，故楚人许之。王送知罃曰：“子其怨我乎？”对曰：“二国治戎，臣不才，不胜其任，以为俘馘。执事不以衅鼓，使归即戮，君之惠也。臣实不才，又谁敢怨？”王曰：“然则德我乎？”对曰：“二国图其社稷，而求纾其民，各惩其忿以相宥也，两释累囚以成其好。二国有好，臣不与及，其谁敢德？”王曰：“子归，何以报我？”对曰：“臣不任受怨，君亦不任受德，无怨无德，不知所报。”王曰：“虽然，必告不穀。”对曰：“以君之灵，累臣得归骨于晋，寡君之以为戮，死且不朽。若从君之惠而免之，以赐君之外臣首；首其请于寡君而以戮于宗，亦死且不朽。若不获命，而使嗣宗职，次及于事，而帅偏师以修封疆，虽遇执事，其弗敢违。其竭力致死，无有二心，以尽臣礼，所以报也。”王曰：“晋未可与争。”重为之礼而归之。

10. **《左传·成公三年》**：“十二月甲戌，晋作六军”，并列韩厥、赵括、巩朔、韩穿、荀骓、赵旃六人为卿，称为酬赏鞌战之功。**《史记·十二诸侯年表》前588年晋栏**作“始置六卿”；**《晋世家·晋景公十二年》**记“始作六（卿）［军］”，所列六卿中写“赵穿”，与《左传》的“韩穿”不同。两书所述军制变动、六卿名单及“始置”含义均保留原文差异，不据“始置六卿”断言晋国此前没有六卿。[年表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7014.md#ref-5816066546ae28) · [《晋世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7039.md#ref-2a5ca3291f853e) · [《左传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E6%88%90%E5%85%AC.md#ref-7b74c959c6d7eb)。

<a id="history-legacy-source-11"></a>


11. **《史记·十二诸侯年表》前588年齐栏**：“十一頃公如晉，欲王晉，晉不敢受。” **《齐太公世家·齐顷公》**记齐顷公朝晋、欲尊王晋景公而未获接受，并记其归国后宽赋赈民、厚礼诸侯。**《左传·成公三年》**也记“齊侯朝于晉”，另详郤克因齐国妇人嘲笑而阻挠授玉、韩厥在宴中的言行，但未载“欲王晋”；后一点仅据《史记》，不混作《左传》原文。[年表原栏](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7014.md#ref-102237fd272e91) · [《齐太公世家》原文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7032.md#ref-86fea82c33ced8) · [《左传·成公三年》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E6%88%90%E5%85%AC.md#ref-1eefbc96eebf93)

12. **《史记·十二诸侯年表》前588年卫栏**：“衛定公臧元年。”  
   **《史记·卫康叔世家》**：“穆公卒，子定公臧立。定公十二年卒，子獻公衎立。”《春秋·成公二年》记前589年卫侯速去世，《春秋·成公三年》记本年安葬卫穆公，故将继位与次年纪元分开。[国别原表](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7014.md#ref-214c02fe0b2ad4) · [本卷原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0588) · [《卫康叔世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-e786946759781f)。

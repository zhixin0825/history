# 公元前588年（鲁成公三年）

[← 上一张已编年页：公元前589年](bce-0589.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前587年 →](bce-0587.md)

<a id="event-1"></a>

1. **春，鲁成公会晋、宋、卫、曹伐郑，追究邲之战中郑国依楚。** 郑军设伏反击，联军并未取得决定性成果。[1]

<a id="event-2"></a>

2. **同月安葬卫穆公；二月鲁成公从伐郑战事返回。** [2]

<a id="event-3"></a>

3. **鲁国新宫失火，连续三日举哀；随后安葬宋文公。** [3]

<a id="event-4"></a>

4. **夏，鲁成公亲赴晋国，感谢晋国在鞌战后帮助收回汶阳田，随后返回鲁国。** [4]

<a id="event-5"></a>

5. **郑国这一年两次伐许：夏由公子去疾率军出兵，冬季又再次进攻。** 许国依楚而不服郑，郑许冲突持续。[5]

<a id="event-6"></a>

6. **晋、楚交换俘虏，知罃从楚归晋。** 知罃面对楚王追问怨德，坚持说两国只是为社稷释怨，没有私人恩怨，楚王因此更加礼遇他。[6]

<a id="event-7"></a>

7. **秋，叔孙侨如围棘，巩固鲁国重新取得的汶阳田；鲁国又举行大雩。** [7]

<a id="event-8"></a>

8. **晋、卫进攻啬咎如，继续清理赤狄余部。** [8]

<a id="event-9"></a>

9. **冬，晋荀庚、卫孙良夫先后来鲁聘问并重申盟约。** 鲁国按晋、卫卿位高下安排先后。[9]

<a id="event-10"></a>

10. **晋国增设六军，奖励鞌之战功臣。** [10]

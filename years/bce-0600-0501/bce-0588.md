# 公元前588年（鲁成公三年）

[← 上一张已编年页：公元前589年](bce-0589.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前587年 →](bce-0587.md)

<a id="event-1"></a>

1. **春，鲁成公会晋、宋、卫、曹伐郑，追究邲之战中郑国依楚。** 郑军设伏反击，联军并未取得决定性成果。[[1]](#note-1)

<a id="event-2"></a>

2. **同月安葬卫穆公；二月鲁成公从伐郑战事返回。** [[2]](#note-2)

<a id="event-3"></a>

3. **鲁国新宫失火，连续三日举哀；随后安葬宋文公。宋文公去世后，其子瑕继为宋君，本年是宋共公元年。** [[3]](#note-3)

<a id="event-4"></a>

4. **夏，鲁成公亲赴晋国，感谢晋国在鞌战后帮助收回汶阳田，随后返回鲁国。** [[4]](#note-4)

<a id="event-5"></a>

5. **郑国这一年两次伐许：夏由公子去疾率军出兵，冬季又再次进攻。** 许国依楚而不服郑，郑许冲突持续。[[5]](#note-5)

<a id="event-6"></a>

6. **晋、楚交换俘虏，知罃从楚归晋。** 知罃面对楚王追问怨德，坚持说两国只是为社稷释怨，没有私人恩怨，楚王因此更加礼遇他。[[6]](#note-6)

<a id="event-7"></a>

7. **秋，叔孙侨如围棘，巩固鲁国重新取得的汶阳田；鲁国又举行大雩。** [[7]](#note-7)

<a id="event-8"></a>

8. **晋、卫进攻啬咎如，继续清理赤狄余部。** [[8]](#note-8)

<a id="event-9"></a>

9. **冬，晋荀庚、卫孙良夫先后来鲁聘问并重申盟约。** 鲁国按晋、卫卿位高下安排先后。[[9]](#note-9)

<a id="event-10"></a>

10. **晋国增设六军，奖励鞌之战功臣。** [[10]](#note-10)

<a id="event-11"></a>

11. **齐顷公前往晋国朝见晋景公，想尊奉晋景公为王，但晋景公不敢接受。**齐顷公归国后，缩减苑囿、减轻赋税，赈济孤弱、探望病人，并以厚礼对待诸侯。[[11]](#note-11)

<a id="sj014-0588-wei"></a>
<a id="event-12"></a>

12. **卫定公臧元年。** 卫穆公已于上年去世，定公继位；《十二诸侯年表》以本年为定公元年，不是再发生一次君主更替。[[12]](#note-12)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·成公三年》**：“三年春，王正月，公会晋侯、宋公、卫侯、曹伯伐郑。”  
   **《左传·成公三年》**详记郑军御诸侯。

<a id="note-2"></a>

2. **《春秋·成公三年》**：“辛亥，葬卫穆公。二月，公至自伐郑。”

<a id="note-3"></a>

3. **《春秋·成公三年》**：“甲子，新宫灾，三日哭。乙亥，葬宋文公。”  
   **《史记·十二诸侯年表》前588年宋栏**：“宋共公瑕元年”；**《宋微子世家》**：“二十二年，文公卒，子共公瑕立。” [年表原栏](https://zh.wikisource.org/wiki/史記/卷014) · [《宋微子世家》](https://zh.wikisource.org/wiki/史記/卷038)。

<a id="note-4"></a>

4. **《春秋·成公三年》**：“夏，公如晋……公至自晋。”  
   **《左传·成公三年》**：“拜汶阳之田。”

<a id="note-5"></a>

5. **《春秋·成公三年》**：“郑公子去疾帅师伐许……郑伐许。”

<a id="note-6"></a>

6. **《左传·成公三年》**详记晋楚换俘、楚王与知罃对话。

<a id="note-7"></a>

7. **《春秋·成公三年》**：“秋，叔孙侨如帅师围棘。大雩。”

<a id="note-8"></a>

8. **《春秋·成公三年》**：“晋郤克、卫孙良夫伐啬咎如。”

<a id="note-9"></a>

9. **《春秋·成公三年》**：“冬十有一月，晋侯使荀庚来聘。卫侯使孙良夫来聘。丙午，及荀庚盟。丁未，及孙良夫盟。”

<a id="note-10"></a>

10. **《左传·成公三年》**：“十二月甲戌，晋作六军”，并列韩厥、赵括、巩朔、韩穿、荀骓、赵旃六人为卿，称为酬赏鞌战之功。**《史记·十二诸侯年表》前588年晋栏**作“始置六卿”；**《晋世家·晋景公十二年》**记“始作六（卿）［军］”，所列六卿中写“赵穿”，与《左传》的“韩穿”不同。两书所述军制变动、六卿名单及“始置”含义均保留原文差异，不据“始置六卿”断言晋国此前没有六卿。[年表](https://zh.wikisource.org/wiki/史記/卷014) · [《晋世家》](https://zh.wikisource.org/wiki/史記/卷039) · [《左传》](https://zh.wikisource.org/wiki/春秋左氏傳/成公)。

<a id="note-11"></a>

11. **《史记·十二诸侯年表》前588年齐栏**：“十一頃公如晉，欲王晉，晉不敢受。” **《齐太公世家·齐顷公》**记齐顷公朝晋、欲尊王晋景公而未获接受，并记其归国后宽赋赈民、厚礼诸侯。**《左传·成公三年》**也记“齊侯朝于晉”，另详郤克因齐国妇人嘲笑而阻挠授玉、韩厥在宴中的言行，但未载“欲王晋”；后一点仅据《史记》，不混作《左传》原文。[年表原栏](https://zh.wikisource.org/wiki/史記/卷014) · [《齐太公世家》原文](https://zh.wikisource.org/wiki/史記/卷032) · [《左传·成公三年》](https://zh.wikisource.org/wiki/春秋左氏傳/成公)


<a id="note-12"></a>

12. **《史记·十二诸侯年表》前588年卫栏**：“衛定公臧元年。”  
   **《史记·卫康叔世家》**：“穆公卒，子定公臧立。定公十二年卒，子獻公衎立。”《春秋·成公二年》记前589年卫侯速去世，《春秋·成公三年》记本年安葬卫穆公，故将继位与次年纪元分开。[国别原表](https://zh.wikisource.org/wiki/史記/卷014) · [本卷原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0588) · [《卫康叔世家》](https://zh.wikisource.org/wiki/史記/卷037)。

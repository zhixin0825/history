# 公元前589年（鲁成公二年）

[← 上一张已编年页：公元前590年](bce-0590.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前588年 →](bce-0588.md)

<a id="event-1"></a>

1. **春，齐顷公进攻鲁国北境，攻破龙地，并继续南侵。** 鲁国随即向晋国求援。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，卫军与齐军在新筑交战，卫军战败。** 卫孙良夫败后也前往晋国求援。[[2]](#note-2)

<a id="event-3"></a>

3. **六月，鲁、晋、卫、曹联军与齐军在鞌地大战。** 齐顷公轻敌急进，晋郤克中箭仍坚持击鼓，联军最终大败齐军。[[3]](#note-3)

<a id="event-4"></a>

4. **齐顷公在战场上一度险些被俘，靠逢丑父与他换位才脱身。** 逢丑父被晋军抓获后因代君受难而获释。[[4]](#note-4)

<a id="event-5"></a>

5. **齐国战败后派国佐到联军营中议和。** 晋人最初提出让齐侯之母做人质、齐国田垄全部东西向等苛刻条件，经鲁、卫劝阻后放弃。[[5]](#note-5)

<a id="event-6"></a>

6. **七月，齐国与联军在袁娄结盟，并归还鲁国汶阳田。** 鲁国取得鞌之战最直接的领土收益。[[6]](#note-6)

<a id="event-7"></a>

7. **八月，宋文公、卫穆公先后去世。** [[7]](#note-7)

<a id="event-8"></a>

8. **冬，楚、郑联军侵卫；鲁成公又与楚、秦、宋、陈、卫、郑、齐、曹、邾、薛、鄫等在蜀地结盟。** 鲁国在依晋取利后，又因楚军压力参加对楚妥协的广泛盟会。[[8]](#note-8)

**楚军侵鲁时，鲁国送出工匠并让公衡为质，求得讲和。** 臧孙起先不肯前往赂楚，认为楚军路远、久留自会撤退。楚军进到阳桥后，孟孙请往，送执斫、执针、织纴各百人，并以公衡为质。后来楚军到宋，公衡逃回，臧宣叔担心此举危及鲁国与楚的约定。 [看原文与说明](#cq-source-59)

<a id="event-9"></a>

9. **楚使屈巫携夏姬离楚，最后到晋国任邢大夫。** 屈巫即申公巫臣。楚国前此讨陈、邲之战中夏姬丈夫襄老战死以后，巫臣安排夏姬先回郑，自己向郑聘娶。本年奉命聘齐、通告楚军行动时，他带全家出行，到了郑国让副使带聘币回楚，自己携夏姬北走；听闻齐新败，转而经郤至投晋。 [看原文与说明](#cq-source-58)

<a id="event-10"></a>

10. **晋巩朔向周王报献鞌之战胜利，周王不肯按献捷之礼接见。** 周王让单襄公说明：齐是姻亲之国，即使有王命讨伐，战后也应告事而不炫功；何况来使等级不合既有安排。王室最后由三吏接待，按大夫告庆之礼办理，又私下宴赐巩朔，并要求不列作正式礼制。 [看原文与说明](#cq-source-60)

2. **《春秋·成公二年》**：“夏四月丙戌，卫孙良夫帅师及齐师战于新筑，卫师败绩。”

<a id="note-3"></a>

3. **《春秋·成公二年》**：“六月癸酉，季孙行父、臧孙许、叔孙侨如、公孙婴齐帅师会晋郤克、卫孙良夫、曹公子首及齐侯战于鞌，齐师败绩。”  
   **《左传·成公二年》**详记鞌之战全过程。

<a id="note-4"></a>

4. **《左传·成公二年》**详记逢丑父与齐侯易位、韩厥俘丑父又释之。

<a id="note-5"></a>

5. **《春秋·成公二年》**：“秋七月，齐侯使国佐如师。”  
   **《左传·成公二年》**详记议和条件与宾媚人答辞。

<a id="note-6"></a>

6. **《春秋·成公二年》**：“己酉，及国佐盟于袁娄……取汶阳田。”  
   **《左传·成公二年》**说明齐归汶阳之田。

<a id="note-7"></a>

7. **《春秋·成公二年》**：“八月壬午，宋公鲍卒。庚寅，卫侯速卒。”

<a id="note-8"></a>

8. **《春秋·成公二年》**：“冬，楚师、郑师侵卫。十有一月，公会楚公子婴齐于蜀。丙申，公及楚人、秦人、宋人、陈人、卫人、郑人、齐人、曹人、邾人、薛人、鄫人盟于蜀。”  
   **《左传·成公二年》**详记楚师侵卫及蜀盟。
   **《十二诸侯年表》楚栏异说：**[本年原表](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0589)将楚师“侵卫及鲁”联系到“救齐”。经传能确认的是楚、郑侵卫、楚军进逼鲁国以及蜀地盟会，但“救齐”究竟是楚国的军事战略目的、政治声援，还是后来的简括表述，现有材料不足以独立确定；不另造一次楚师援齐的战役。

### 核对58｜楚使屈巫携夏姬离楚，最后到晋国任邢大夫

**说明：**前598年楚讨陈、前597年邲战以及早先归郑是本次出亡的前事。巫臣所说夏姬使多名男子、国家受祸是人物言辞，不采用这种归咎女性的评价作编者判断。

<details>
<summary>传 T016｜原文</summary>

> 楚之讨陈夏氏也，庄王欲纳夏姬，申公巫臣曰：“不可。君召诸侯，以讨罪也。今纳夏姬，贪其色也。贪色为淫，淫为大罚。《周书》曰：‘明德慎罚。’文王所以造周也。明德，务崇之之谓也。慎罚，务去之之谓也。若兴诸侯，以取大罚，非慎之也。君其图之！”王乃止。子反欲取之，巫臣曰：“是不祥人也！是夭子蛮，杀御叔，杀灵侯，戮夏南，出孔、仪，丧陈国，何不祥如是！人生实难，其有不获死乎？天下多美妇人，何必是？”子反乃止。

</details>

<details>

### 核对59｜楚军侵鲁时，鲁国送出工匠并让公衡为质，求得讲和

**说明：**工匠人数为原载，不当作现代核定人口数。公衡逃归与在蜀议盟相接，不写成楚国当即因他再攻鲁。

<details>
<summary>传 T022｜原文</summary>

> 冬，楚师侵卫，遂侵我，师于蜀。使臧孙往，辞曰：“楚远而久，固将退矣。无功而受名，臣不敢。”楚侵及阳桥，孟孙请往赂之。以执斫、执针、织纴，皆百人，公衡为质，以请盟。楚人许平。

<a id="cq-source-60"></a>
### 核对60｜晋巩朔向周王报献鞌之战胜利，周王不肯按献捷之礼接见

**说明：**不接见献捷不等于完全拒绝来使；正式礼与私下宴赐分别保存。

<details>
<summary>传 T026｜原文</summary>

> 晋侯使巩朔献齐捷于周，王弗见，使单襄公辞焉，曰：“蛮夷戎狄，不式王命，淫湎毁常，王命伐之，则有献捷，王亲受而劳之，所以惩不敬，劝有功也。兄弟甥舅，侵败王略，王命伐之，告事而已，不献其功，所以敬亲暱，禁淫慝也。今叔父克遂有功于齐，而不使命卿镇抚王室，所使来抚余一人，而巩伯实来，未有职司于王室，又奸先王之礼，余虽欲于巩伯，其敢废旧典以忝叔父？夫齐，甥舅之国也，而大师之后也，宁不亦淫从其欲以怒叔父，抑岂不可谏诲？”士庄伯不能对。王使委于三吏，礼之如侯伯克敌使大夫告庆之礼，降于卿礼一等。王以巩伯宴而私贿之。使相告之曰：“非礼也，勿籍。”

[本段出处](../../sources/春秋左传/有标点原文/bce-0589.md#t026)

</details>

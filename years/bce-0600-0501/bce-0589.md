1. **春，齐顷公进攻鲁国北境，攻破龙地，并继续南侵。** 鲁国随即向晋国求援。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **夏，卫军与齐军在新筑交战，卫军战败。** 卫孙良夫败后也前往晋国求援。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **六月，鲁、晋、卫、曹联军与齐军在鞌地大战。** 齐顷公轻敌急进，晋郤克中箭仍坚持击鼓，联军最终大败齐军。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **齐顷公在战场上一度险些被俘，靠逢丑父与他换位才脱身。** 逢丑父被晋军抓获后因代君受难而获释。 [[4]](#reading-note-4)

<a id="event-5"></a>

<a id="reading-event-5"></a>

5. **齐国战败后派国佐到联军营中议和。** 晋人最初提出让齐侯之母做人质、齐国田垄全部东西向等苛刻条件，经鲁、卫劝阻后放弃。 [[5]](#reading-note-5)

<a id="event-6"></a>

<a id="reading-event-6"></a>

6. **七月，齐国与联军在袁娄结盟，并归还鲁国汶阳田。** 鲁国取得鞌之战最直接的领土收益。 [[6]](#reading-note-6)

<a id="event-7"></a>

<a id="reading-event-7"></a>

7. **八月，宋文公、卫穆公先后去世。** [[7]](#reading-note-7)

<a id="event-8"></a>

<a id="reading-event-8"></a>

8. **冬，楚、郑联军侵卫；鲁成公又与楚、秦、宋、陈、卫、郑、齐、曹、邾、薛、鄫等在蜀地结盟。** 鲁国在依晋取利后，又因楚军压力参加对楚妥协的广泛盟会。 [[8]](#reading-note-8)

<a id="reading-event-9"></a>

9. **楚军侵鲁时，鲁国送出工匠并让公衡为质，求得讲和。** 臧孙起先不肯前往赂楚，认为楚军路远、久留自会撤退。楚军进到阳桥后，孟孙请往，送执斫、执针、织纴各百人，并以公衡为质。后来楚军到宋，公衡逃回，臧宣叔担心此举危及鲁国与楚的约定。 [[9]](#reading-note-9)

<a id="event-9"></a>

<a id="reading-event-10"></a>

10. **楚使屈巫携夏姬离楚，最后到晋国任邢大夫。** 屈巫即申公巫臣。楚国前此讨陈、邲之战中夏姬丈夫襄老战死以后，巫臣安排夏姬先回郑，自己向郑聘娶。本年奉命聘齐、通告楚军行动时，他带全家出行，到了郑国让副使带聘币回楚，自己携夏姬北走；听闻齐新败，转而经郤至投晋。 [[10]](#reading-note-10)

<a id="event-10"></a>

<a id="reading-event-11"></a>

11. **晋巩朔向周王报献鞌之战胜利，周王不肯按献捷之礼接见。** 周王让单襄公说明：齐是姻亲之国，即使有王命讨伐，战后也应告事而不炫功；何况来使等级不合既有安排。王室最后由三吏接待，按大夫告庆之礼办理，又私下宴赐巩朔，并要求不列作正式礼制。 [[11]](#reading-note-11)

> 十年春，齊伐魯、衛。魯、衛大夫如晉請師，皆因郤克。晉使郤克以車八百乘為中軍將，士燮將上軍，欒書將下軍，以救魯、衛，伐齊。六月壬申，與齊侯兵合靡笄下。癸酉，陳于礱逄丑父為齊頃公右。頃公曰：「馳之，破晉軍會食。」射傷郤克，流血至履。克欲還入壁，其御曰：「我始入，再傷，不敢言疾，恐懼士卒，願子忍之。」遂復戰。戰，齊急，丑父恐齊侯得，乃易處，頃公為右，車絓於木而止。晉小將韓厥伏齊侯車前，曰「寡君使臣救魯、衛」，戲之。丑父使頃公下取飲，因得亡，脫去，入其軍。晉郤克欲殺丑父。丑父曰：「代君死而見僇，後人臣無忠其君者矣。」克捨之，丑父遂得亡歸齊。於是晉軍追齊至馬陵。齊侯請以寶器謝，不聽；必得笑克者蕭桐叔子，令齊東畝。對曰：「叔子，齊君母。齊君母亦猶晉君母，子安置之？且子以義伐而以暴為後，其可乎？」於是乃許，令反魯、衛之侵地。

**读法与异说：** “癸酉，陈于砻逄丑父”是此转录的破碎文字，原句照存；战名及日序采用经传鞌，不能无注校成底本原有。

### 4. 齐顷公在战场上一度险些被俘，靠逢丑父与他换位才脱身

[返回正文第4条](#reading-event-4)

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0589.md#t009)**

> 韩厥梦子舆谓己曰：“旦辟左右。”故中御而从齐侯。邴夏曰：“射其御者，君子也。”公曰：“谓之君子而射之，非礼也。”射其左，越于车下。射其右，毙于车中。綦毋张丧车，从韩厥，曰：“请寓乘从左右。”皆肘之，使立于后。韩厥俛，定其右。逢丑父与公易位。将及华泉，骖絓于木而止。丑父寝于轏中，蛇出于其下，以肱击之，伤而匿之，故不能推车而及。韩厥执絷马前，再拜稽首，奉觞加璧以进，曰：“寡君使群臣为鲁、卫请曰：‘无令舆师陷入君地。’下臣不幸，属当戎行，无所逃隐。且惧奔辟而忝两君，臣辱戎士，敢告不敏，摄官承乏。”丑父使公下，如华泉取饮。郑周父御佐车，宛茷为右，载齐侯以免。韩厥献丑父，郤献子将戮之。呼曰：“自今无有代其君任患者，有一于此，将为戮乎！”郤子曰：“人不难以死免其君，我戮之不祥，赦之以劝事君者。”乃免之。

### 10. 楚使屈巫携夏姬离楚，最后到晋国任邢大夫

[返回正文第10条](#reading-event-10)

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0589.md#t016)**

> 楚之讨陈夏氏也，庄王欲纳夏姬，申公巫臣曰：“不可。君召诸侯，以讨罪也。今纳夏姬，贪其色也。贪色为淫，淫为大罚。《周书》曰：‘明德慎罚。’文王所以造周也。明德，务崇之之谓也。慎罚，务去之之谓也。若兴诸侯，以取大罚，非慎之也。君其图之！”王乃止。子反欲取之，巫臣曰：“是不祥人也！是夭子蛮，杀御叔，杀灵侯，戮夏南，出孔、仪，丧陈国，何不祥如是！人生实难，其有不获死乎？天下多美妇人，何必是？”子反乃止。

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0589.md#t017)**

> 王以予连尹襄老。襄老死于邲，不获其尸，其子黑要烝焉。巫臣使道焉，曰：“归！吾聘女。”又使自郑召之，曰：“尸可得也，必来逆之。”姬以告王，王问诸屈巫。对曰：“其信！知罃之父，成公之嬖也，而中行伯之季弟也，新佐中军，而善郑皇戌，甚爱此子。其必因郑而归王子与襄老之尸以求之。郑人惧于邲之役而欲求媚于晋，其必许之。”王遣夏姬归。将行，谓送者曰：“不得尸，吾不反矣。”巫臣聘诸郑，郑伯许之。

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0589.md#t018)**

> 及共王即位，将为阳桥之役，使屈巫聘于齐，且告师期，巫臣尽室以行。申叔跪从其父将適郢，遇之，曰：“异哉！夫子有三军之惧，而又有《桑中》之喜，宜将窃妻以逃者也。”及郑，使介反币，而以夏姬行。将奔齐，齐师新败，曰：“吾不处不胜之国。”遂奔晋，而因郤至以臣于晋。晋人使为邢大夫。

> 晋侯使巩朔献齐捷于周，王弗见，使单襄公辞焉，曰：“蛮夷戎狄，不式王命，淫湎毁常，王命伐之，则有献捷，王亲受而劳之，所以惩不敬，劝有功也。兄弟甥舅，侵败王略，王命伐之，告事而已，不献其功，所以敬亲暱，禁淫慝也。今叔父克遂有功于齐，而不使命卿镇抚王室，所使来抚余一人，而巩伯实来，未有职司于王室，又奸先王之礼，余虽欲于巩伯，其敢废旧典以忝叔父？夫齐，甥舅之国也，而大师之后也，宁不亦淫从其欲以怒叔父，抑岂不可谏诲？”士庄伯不能对。王使委于三吏，礼之如侯伯克敌使大夫告庆之礼，降于卿礼一等。王以巩伯宴而私贿之。使相告之曰：“非礼也，勿籍。”

#### 核对58｜楚使屈巫携夏姬离楚，最后到晋国任邢大夫

**说明：**前598年楚讨陈、前597年邲战以及早先归郑是本次出亡的前事。巫臣所说夏姬使多名男子、国家受祸是人物言辞，不采用这种归咎女性的评价作编者判断。

<details>
<summary>传 T016｜原文</summary>

> 楚之讨陈夏氏也，庄王欲纳夏姬，申公巫臣曰：“不可。君召诸侯，以讨罪也。今纳夏姬，贪其色也。贪色为淫，淫为大罚。《周书》曰：‘明德慎罚。’文王所以造周也。明德，务崇之之谓也。慎罚，务去之之谓也。若兴诸侯，以取大罚，非慎之也。君其图之！”王乃止。子反欲取之，巫臣曰：“是不祥人也！是夭子蛮，杀御叔，杀灵侯，戮夏南，出孔、仪，丧陈国，何不祥如是！人生实难，其有不获死乎？天下多美妇人，何必是？”子反乃止。

[本段出处](../../sources/春秋左传/有标点原文/bce-0589.md#t016)

</details>

<details>
<summary>传 T017｜原文</summary>

> 王以予连尹襄老。襄老死于邲，不获其尸，其子黑要烝焉。巫臣使道焉，曰：“归！吾聘女。”又使自郑召之，曰：“尸可得也，必来逆之。”姬以告王，王问诸屈巫。对曰：“其信！知罃之父，成公之嬖也，而中行伯之季弟也，新佐中军，而善郑皇戌，甚爱此子。其必因郑而归王子与襄老之尸以求之。郑人惧于邲之役而欲求媚于晋，其必许之。”王遣夏姬归。将行，谓送者曰：“不得尸，吾不反矣。”巫臣聘诸郑，郑伯许之。

<a id="核对60晋巩朔向周王报献鞌之战胜利周王不肯按献捷之礼接见"></a>
#### 核对60｜晋巩朔向周王报献鞌之战胜利，周王不肯按献捷之礼接见

**说明：**不接见献捷不等于完全拒绝来使；正式礼与私下宴赐分别保存。

<details>
<summary>传 T026｜原文</summary>

> 晋侯使巩朔献齐捷于周，王弗见，使单襄公辞焉，曰：“蛮夷戎狄，不式王命，淫湎毁常，王命伐之，则有献捷，王亲受而劳之，所以惩不敬，劝有功也。兄弟甥舅，侵败王略，王命伐之，告事而已，不献其功，所以敬亲暱，禁淫慝也。今叔父克遂有功于齐，而不使命卿镇抚王室，所使来抚余一人，而巩伯实来，未有职司于王室，又奸先王之礼，余虽欲于巩伯，其敢废旧典以忝叔父？夫齐，甥舅之国也，而大师之后也，宁不亦淫从其欲以怒叔父，抑岂不可谏诲？”士庄伯不能对。王使委于三吏，礼之如侯伯克敌使大夫告庆之礼，降于卿礼一等。王以巩伯宴而私贿之。使相告之曰：“非礼也，勿籍。”

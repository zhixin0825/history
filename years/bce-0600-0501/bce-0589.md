# 公元前589年（鲁成公二年）

[← 上一张已编年页：公元前590年](bce-0590.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前588年 →](bce-0588.md)

<a id="event-1"></a>

1. **春，齐顷公进攻鲁国北境，攻破龙地，并继续南侵。** 鲁国随即向晋国求援。[1]

<a id="event-2"></a>

2. **夏，卫军与齐军在新筑交战，卫军战败。** 卫孙良夫败后也前往晋国求援。[2]

<a id="event-3"></a>

3. **六月，鲁、晋、卫、曹联军与齐军在鞌地大战。** 齐顷公轻敌急进，晋郤克中箭仍坚持击鼓，联军最终大败齐军。[3]

<a id="event-4"></a>

4. **齐顷公在战场上一度险些被俘，靠逢丑父与他换位才脱身。** 逢丑父被晋军抓获后因代君受难而获释。[4]

<a id="event-5"></a>

5. **齐国战败后派国佐到联军营中议和。** 晋人最初提出让齐侯之母做人质、齐国田垄全部东西向等苛刻条件，经鲁、卫劝阻后放弃。[5]

<a id="event-6"></a>

6. **七月，齐国与联军在袁娄结盟，并归还鲁国汶阳田。** 鲁国取得鞌之战最直接的领土收益。[6]

<a id="event-7"></a>

7. **八月，宋文公、卫穆公先后去世。** [7]

<a id="event-8"></a>

8. **冬，楚、郑联军侵卫；鲁成公又与楚、秦、宋、陈、卫、郑、齐、曹、邾、薛、鄫等在蜀地结盟。** 鲁国在依晋取利后，又因楚军压力参加对楚妥协的广泛盟会。[8]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·成公二年》**：“二年春，齐侯伐我北鄙。”  
   **《左传·成公二年》**详记围龙、取龙并南侵。

<a id="note-2"></a>

2. **《春秋·成公二年》**：“夏四月丙戌，卫孙良夫帅师及齐师战于新筑，卫师败绩。”

<a id="note-3"></a>

3. **《春秋·成公二年》**：“六月癸酉，季孙行父、臧孙许、叔孙侨如、公孙婴齐帅师会晋郤克、卫孙良夫、曹公子首及齐侯战于鞌，齐师败绩。”  
   **《左传·成公二年》**详记鞌之战全过程。

<a id="note-4"></a>

4. **《左传·成公二年》**详记逢丑父与齐侯易位、韩厥俘丑父又释之。

<a id="note-5"></a>

5. **《春秋·成公二年》**：“秋七月，齐侯使国佐如师。”  
   **《左传·成公二年》**详记议和条件与宾媚人答辞。

<a id="note-6"></a>

6. **《春秋·成公二年》**：“己酉，及国佐盟于袁娄……取汶阳田。”  
   **《左传·成公二年》**说明齐归汶阳之田。

<a id="note-7"></a>

7. **《春秋·成公二年》**：“八月壬午，宋公鲍卒。庚寅，卫侯速卒。”

<a id="note-8"></a>

8. **《春秋·成公二年》**：“冬，楚师、郑师侵卫。十有一月，公会楚公子婴齐于蜀。丙申，公及楚人、秦人、宋人、陈人、卫人、郑人、齐人、曹人、邾人、薛人、鄫人盟于蜀。”  
   **《左传·成公二年》**详记楚师侵卫及蜀盟。

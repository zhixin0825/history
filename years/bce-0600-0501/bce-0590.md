# 公元前590年（鲁成公元年）

[← 上一张已编年页：公元前591年](bce-0591.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前589年 →](bce-0589.md)

<a id="event-1"></a>

1. **春，鲁成公即位；二月安葬宣公。** 同年冬季无冰，气候异常。[1]

<a id="event-2"></a>

2. **三月，鲁国实行“作丘甲”，扩大军赋征发。** 这项措施直接针对齐国威胁，加强基层军事负担。[2]

<a id="event-3"></a>

3. **夏，臧孙许与晋景公在赤棘结盟。** 鲁国正式靠晋应对齐楚关系变化。[3]

<a id="event-4"></a>

4. **周王室一方背盟攻茅戎，在徐吾氏遭到惨败。** 秋天王使来鲁通报战败。[4]

<a id="event-5"></a>

5. **鲁国判断齐、楚可能联合来攻，于冬季修整赋役、城防和守备。** 臧宣叔要求提前备战。[5]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·成公元年》**：“元年春，王正月，公即位。二月辛酉，葬我君宣公。无冰。”

<a id="note-2"></a>

2. **《春秋·成公元年》**：“三月，作丘甲。”  
   **《左传·成公元年》**：“为齐难故，作丘甲。”

<a id="note-3"></a>

3. **《春秋·成公元年》**：“夏，臧孙许及晋侯盟于赤棘。”

<a id="note-4"></a>

4. **《春秋·成公元年》**：“秋，王师败绩于茅戎。”  
   **《左传·成公元年》**详记王师败于徐吾氏、王人来告败。

<a id="note-5"></a>

5. **《左传·成公元年》**详记臧宣叔冬令修赋、缮完、具守备。

# 公元前590年（鲁成公元年）

[← 上一张已编年页：公元前591年](bce-0591.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前589年 →](bce-0589.md)

<a id="event-1"></a>

1. **春，鲁成公即位；二月安葬宣公。** 同年冬季无冰，气候异常。[[1]](#note-1)

<a id="event-2"></a>

2. **三月，鲁国实行“作丘甲”，扩大军赋征发。** 这项措施直接针对齐国威胁，加强基层军事负担。[[2]](#note-2)

<a id="event-3"></a>

3. **夏，臧孙许与晋景公在赤棘结盟。** 鲁国正式靠晋应对齐楚关系变化。[[3]](#note-3)

<a id="event-4"></a>

4. **周王室一方背盟攻茅戎，在徐吾氏遭到惨败。** 秋天王使来鲁通报战败。[[4]](#note-4)

<a id="event-5"></a>

5. **鲁国判断齐、楚可能联合来攻，于冬季修整赋役、城防和守备。** 臧宣叔要求提前备战。[[5]](#note-5)

<a id="sj014-0590-chu"></a>
<a id="event-6"></a>

6. **楚共王审元年。** 上年楚庄王去世，其子审继承楚国君位；本年起计共王元年。[[6]](#note-6)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·成公元年》**：“元年春，王正月，公即位。二月辛酉，葬我君宣公。无冰。”

   **卷014异年回链（鲁栏）：**[《十二诸侯年表》前590年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0590)在鲁成公元年下写“齐取我隆”；但[《鲁周公世家》](https://zh.wikisource.org/wiki/史記/卷033)明记“成公二年春，齐伐取我隆”，[《春秋》《左传》成公二年对应的前589年正文](bce-0589.md#event-1)记齐取鲁龙邑。[同号史料](bce-0589.md#note-1)详见。“隆／龙”是地名异字，这里仅记年表与经传相差一年，不在前590年重复制造第二次攻城。

<a id="note-2"></a>

2. **《春秋·成公元年》**：“三月，作丘甲。”  
   **《左传·成公元年》**：“为齐难故，作丘甲。”

<a id="note-3"></a>

3. **《春秋·成公元年》**：“夏，臧孙许及晋侯盟于赤棘。”

<a id="note-4"></a>

4. **《春秋·成公元年》**：“秋，王师败绩于茅戎。”  
   **《左传·成公元年》**详记王师败于徐吾氏、王人来告败。

<a id="note-5"></a>

5. **《左传·成公元年》**详记臧宣叔冬令修赋、缮完、具守备。

<a id="note-6"></a>

6. **《史记·十二诸侯年表》前590年楚栏**：“楚共王審元年。”  
   **《史记·楚世家》**：“二十三年，莊王卒，子共王審立。”  
   **纪年说明：** 共王继位承接前591年庄王之死，前590年才是年表所列元年，不应写成本年又一次即位。[原表](https://zh.wikisource.org/wiki/史記/卷014) · [卷014摘录原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0590) · [《楚世家》](https://zh.wikisource.org/wiki/史記/卷040)。

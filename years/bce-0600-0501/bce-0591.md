# 公元前591年（鲁宣公十八年）

[← 上一张已编年页：公元前592年](bce-0592.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前590年 →](bce-0590.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，晋景公与卫太子臧伐齐，一直推进到阳穀。** 齐侯被迫与晋侯在缯地结盟，并把公子彊送到晋国做人质。 [[1]](#note-1)

<a id="event-2"></a>

2. **鲁宣公同时出兵伐杞。** [[2]](#note-2)

<a id="event-3"></a>

3. **夏，宣公派使者到楚国请求援军，准备借楚力伐齐。** 鲁国继续在晋、齐、楚之间寻找外援。 [[3]](#note-3)

<a id="event-4"></a>

4. **秋，邾人在鄫国杀死鄫君。** 因为是外人杀国君，记为“戕”而不是“弑”。 [[4]](#note-4)

<a id="event-5"></a>

5. **七月，楚庄王去世。** 楚军因此没有按鲁国请求出兵。 [[5]](#note-5)

    [卷四互见与归年](#sj004-591-1)

<a id="event-6"></a>

6. **公孙归父受到宣公宠信，想借晋国力量削弱三桓、加强公室。** 他奉宣公命前往晋国谋划。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬十月，鲁宣公死于路寝。** 季孙行父随即把“杀嫡立庶、失大援”的责任归到已故襄仲，三桓开始反击东门氏。 [[7]](#note-7)

<a id="event-8"></a>

8. **公孙归父从晋回国，走到笙地得知宣公已死、东门氏被逐，只能完成复命礼后逃往齐国。** [[8]](#note-8)

<a id="sj014-0591-cai"></a>
<a id="event-9"></a>

9. **蔡景侯固元年。** 蔡文侯申已于上年去世，景侯继位；《十二诸侯年表》从本年起计景侯元年，并非蔡国在本年再次立君。 [[9]](#note-9)

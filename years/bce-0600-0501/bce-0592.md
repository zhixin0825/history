# 公元前592年（鲁宣公十七年）

[← 上一张已编年页：公元前593年](bce-0593.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前591年 →](bce-0591.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，许昭公、蔡文公先后去世；夏天两国完成葬礼。** [[1]](#note-1)

<a id="event-2"></a>

2. **晋国派郤克到齐国征召会盟，齐顷公让妇人在帷幕后观看并嘲笑郤克。** 郤克受辱后发誓报仇，回晋请求伐齐。 [[2]](#note-2)

<a id="event-3"></a>

3. **齐国仍派高固、晏弱、蔡朝、南郭偃赴晋会盟。** 高固途中逃回，其余三人继续前往。 [[3]](#note-3)

<a id="event-4"></a>

4. **六月癸卯，发生日食；己未，鲁宣公与晋、卫、曹、邾在断道同盟。** 晋国借会盟追究齐国两面行为，并一度扣押齐使。 [[4]](#note-4)

<a id="event-5"></a>

5. **晋国后来接受劝告，逐渐放松对齐使控制。** [[5]](#note-5)

<a id="event-6"></a>

6. **秋，宣公从会盟返回。** 晋国士会随后告老，郤克开始主持晋国政务。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬，宣公同母弟叔肸去世。** [[7]](#note-7)

### 2. 晋国派郤克到齐国征召会盟，齐顷公让妇人在帷幕后观看并嘲笑郤克

[返回正文第2条](#event-2)

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0592.md#all-20261109-t001)**

> 十七年春，晋侯使郤克征会于齐。齐顷公帷妇人，使观之。郤子登，妇人笑于房。献子怒，出而誓曰：“所不此报，无能涉河。”献子先归，使栾京庐待命于齐，曰：“不得齐事，无复命矣。”郤子至，请伐齐，晋侯弗许；请以其私属，又弗许。

[史料说明](#history-legacy-source-2)

<!-- sj032-supplement -->

**[《史记·齐太公世家》P057](../../sources/摘录/史记-卷032-齐太公世家.md#p057)**

> 六年春，晉使郤克於齊，齊使夫人帷中而觀之。郤克上，夫人笑之。郤克曰：「不是報，不復涉河！」歸，請伐齊，晉侯弗許。齊使至晉，郤克執齊使者四人河內，殺之。

**[《春秋》《左传》前592年·互校](../../sources/摘录/史记-卷032-互校原文.md#z-ke)**

> 十七年春，晋侯使郤克征会于齐。齐顷公帷妇人，使观之。郤子登，妇人笑于房。献子怒，出而誓曰：“所不此报，无能涉河。”献子先归，使栾京庐待命于齐，曰：“不得齐事，无复命矣。”郤子至，请伐齐，晋侯弗许；请以其私属，又弗许。

**[《春秋》《左传》前592年·互校](../../sources/摘录/史记-卷032-互校原文.md#z-sishi)**

> 齐侯使高固、晏弱、蔡朝、南郭偃会。及敛盂，高固逃归。

**[《春秋》《左传》前592年·互校](../../sources/摘录/史记-卷032-互校原文.md#z-release)**

> 夏，会于断道，讨贰也。盟于卷楚，辞齐人。晋人执晏弱于野王，执蔡朝于原，执南郭偃于温。苗贲皇使，见晏桓子，归言于晋侯曰：“夫晏子何罪？昔者诸侯事吾先君，皆如不逮，举言群臣不信，诸侯皆有贰志。齐君恐不得礼，故不出而使四子来。左右或沮之曰：‘君不出，必执吾使。’故高子及敛盂而逃。夫三子者曰：‘若绝君好，宁归死焉。’为是犯难而来，吾若善逆彼，以怀来者，吾又执之以信齐沮，吾不既过矣乎？过而不改，而又久之，以成其悔，何利之有焉？使反者得辞，而害来者，以惧诸侯，将焉用之？”晋人缓之，逸。

**读法与异说：** 本篇顷六折前593年，传文宣十七为前592年；本篇又简作四使尽杀，而传文高固先归、三使被执后释逃。不得合为四人皆死。

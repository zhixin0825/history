# 公元前593年（鲁宣公十六年）

[← 上一张已编年页：公元前594年](bce-0594.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前592年 →](bce-0592.md)

<a id="event-1"></a>

1. **春，晋士会率军灭赤狄甲氏与留吁。** 晋国继续清除赤狄势力。[[1]](#note-1)

<a id="event-2"></a>

2. **晋景公请求周王正式赐命士会，士会升任中军将并兼太傅。** 晋国政权核心进一步集中到范氏。[[2]](#note-2)

<a id="event-3"></a>

3. **夏，成周宣榭失火。** 这场火灾被判断为人为所致。[[3]](#note-3)

<a id="event-4"></a>

4. **秋，郯伯姬被夫家遣回鲁国。** [[4]](#note-4)

<a id="event-5"></a>

5. **周王室因毛、召之乱再次动荡，王孙苏逃晋；晋国又把他送回。** [[5]](#note-5)

<a id="event-6"></a>

6. **冬，晋士会赴周王室调停，并向周定王请教典礼；回晋后据此整顿晋国礼制。** [[6]](#note-6)

<a id="event-7"></a>

7. **冬，鲁国大有年，农业丰收。** [[7]](#note-7)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·宣公十六年》**：“十有六年春，王正月，晋人灭赤狄甲氏及留吁。”  
   **《左传·宣公十六年》**详记士会灭甲氏、留吁铎辰。

<a id="note-2"></a>

2. **《左传·宣公十六年》**详记晋侯请王命士会将中军并为太傅。

<a id="note-3"></a>

3. **《春秋·宣公十六年》**：“夏，成周宣榭火。”  
   **《左传·宣公十六年》**：“人火之也。”

<a id="note-4"></a>

4. **《春秋·宣公十六年》**：“秋，郯伯姬来归。”  
   **《左传·宣公十六年》**：“出也。”

<a id="note-5"></a>

5. **《左传·宣公十六年》**详记王孙苏奔晋、晋人复之。

<a id="note-6"></a>

6. **《左传·宣公十六年》**详记士会平王室并问礼。

<a id="note-7"></a>

7. **《春秋·宣公十六年》**：“冬，大有年。”

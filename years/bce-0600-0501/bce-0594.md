# 公元前594年（鲁宣公十五年）

[← 上一张已编年页：公元前595年](bce-0595.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前593年 →](bce-0593.md)

[本年相关史料](#sources-start)

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **春，公孙归父到宋地会见楚庄王。** 鲁国开始直接与楚国协调。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **宋国被楚军长期包围，城中饥荒极重。** 晋国虽想救宋，伯宗却认为楚势正盛、晋暂难与之争锋，晋国因而没有直接出兵解围。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **晋使解扬被郑国截获送楚，楚王要求他向宋城传假消息，他却仍传达晋君原命。** 楚人以厚赐要求他改传“晋不救宋”；解扬表面应允，登上楼车后却照传原命。楚王欲杀他，最后又听劝放他回晋。 解扬是霍人，字子虎。楚王三次逼约，他才表面答应；对宋却仍说晋将尽出国兵，危急之中千万不要投降。楚王斥他背弃诺言，解扬说君能制命为义、臣能承命为信，自己奉晋君之命出行，即使死也不能失命；暂许楚王，只为取得传达本命的机会。他临死前又呼告楚军，为人臣不要忘记尽忠至死。楚王诸弟劝赦，他得归晋后被授为上卿。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **夏五月，华元夜入楚军，向子反坦陈城中饥困，宋楚终于讲和。** 宋已到易子而食、析骨为炊的地步，华元以实情求议。子反告王，楚军退三十里，与宋议和；本篇概述为庄王赞华元而罢兵，双方传述的中间层次在同号注区分。 [[4]](#reading-note-4)

<a id="event-5"></a>

<a id="reading-event-5"></a>

5. **六月，晋国灭赤狄潞氏，俘虏潞君婴儿。** [[5]](#reading-note-5)

<a id="reading-event-6"></a>

6. **晋侯将狄臣千室赏给荀林父，又赏士伯瓜衍之县。** 士伯此前曾为荀林父进言，晋侯认为自己能获狄土也与留下荀林父有关，故同时赏赐。随后赵同奉命向周王献狄俘，刘康公对其失礼提出批评。 [[6]](#reading-note-6)

<a id="event-6"></a>

<a id="reading-event-7"></a>

7. **秦军伐晋，在辅氏交战；晋将魏颗俘获秦国勇士杜回。** 后世“结草报恩”的故事与此役相连。 [[7]](#reading-note-7)

<a id="event-7"></a>

<a id="reading-event-8"></a>

8. **周王室内王孙苏与召、毛两氏争权，王子捷杀召伯、毛伯。** [[8]](#reading-note-8)

<a id="event-8"></a>

<a id="reading-event-9"></a>

9. **秋，鲁国发生螽灾；仲孙蔑与齐高固在无娄会面。** [[9]](#reading-note-9)

<a id="event-9"></a>

<a id="reading-event-10"></a>

10. **鲁国开始“初税亩”，正式按田亩征税。** 这是鲁国赋税制度的重要变化。 [[10]](#reading-note-10)

<a id="event-10"></a>

<a id="reading-event-11"></a>

11. **冬，蝝虫孳生，同时发生饥荒。** [[11]](#reading-note-11)

<a id="event-11"></a>

<a id="reading-event-12"></a>

12. **曹宣公从本年开始纪元。** 曹文公已于上年去世，曹国转入宣公纪年；这是接续前君之丧的元年，不另记一场新的政变。 [[12]](#reading-note-12)

<a id="hs-event-13"></a>

13. **鲁秋螽。** [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **鲁冬蝝生。** [[14]](#hs-note-14)

<!-- /sj039-cite-188 -->

<a id="sj042-cite-081"></a>

**[《史记·郑世家》P029](../../sources/摘录/史记-卷042-郑世家.md#p029)**

> 乃求壯士得霍人解揚，字子虎，誆楚，令宋毋降。過鄭，鄭與楚親，乃執解揚而獻楚。楚王厚賜與約，使反其言，令宋趣降，三要乃許。於是楚登解揚樓車，令呼宋。遂負楚約而致其晉君命曰：「晉方悉國兵以救宋，宋雖急，慎毋降楚，晉兵今至矣！」楚莊王大怒，將殺之。解揚曰：「君能制命為義，臣能承命為信。受吾君命以出，有死無隕。」莊王曰：「若之許我，已而背之，其信安在？」解揚曰：「所以許王，欲以成吾君命也。」將死，顧謂楚軍曰：「為人臣無忘盡忠得死者！」楚王諸弟皆諫王赦之，於是赦解揚使歸。晉爵之為上卿。

**本卷说明：** “晋兵今至”是给宋坚持的传话，并非晋已经出兵；伯宗阻兵、解扬诈许楚命和最终获释的因果连贯保存。

> 十七年，楚以圍宋五月不解，宋城中急，無食，華元乃夜私見楚將子反。子反告莊王。王問：「城中何如？」曰：「析骨而炊，易子而食。」莊王曰：「誠哉言！我軍亦有二日糧。」以信故，遂罷兵去。

#### 核对57｜晋侯将狄臣千室赏给荀林父，又赏士伯瓜衍之县

**说明：**“千室”照录为来源数字；刘康公关于赵同将有大咎的预言不另算成本年已经遭祸。

<details>
<summary>传 T007｜原文</summary>

> 晋侯赏桓子狄臣千室，亦赏士伯以瓜衍之县。曰：“吾获狄土，子之功也。微子，吾丧伯氏矣。”羊舌职说是赏也，曰：“《周书》所谓‘庸庸祗祗’者，谓此物也夫。士伯庸中行伯，君信之，亦庸士伯，此之谓明德矣。文王所以造周，不是过也。故《诗》曰：‘陈锡载周。’能施也。率是道也，其何不济？”

[本段出处](../../sources/春秋左传/有标点原文/bce-0594.md#t007)

</details>

<summary>传 T008｜原文</summary>

> 晋侯使赵同献狄俘于周，不敬。刘康公曰：“不及十年，原叔必有大咎，天夺之魄矣。”

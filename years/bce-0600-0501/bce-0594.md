# 公元前594年（鲁宣公十五年）

[← 上一张已编年页：公元前595年](bce-0595.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前593年 →](bce-0593.md)

<a id="event-1"></a>

1. **春，公孙归父到宋地会见楚庄王。** 鲁国开始直接与楚国协调。[[1]](#note-1)

<a id="event-2"></a>

2. **宋国被楚军长期包围，城中饥荒极重。** 晋国虽然想救宋，却判断楚势正盛，没有出兵。[[2]](#note-2)

<a id="event-3"></a>

3. **晋使解扬被郑国截获送给楚国，楚王要求他向宋城传假消息；解扬登车后仍传达晋君原命。** 楚王最终放他回晋。[[3]](#note-3)

<a id="event-4"></a>

4. **夏五月，宋大夫华元夜入楚军，与子反直接谈判。** 楚军退三十里，宋楚讲和。[[4]](#note-4)

<a id="event-5"></a>

5. **六月，晋国灭赤狄潞氏，俘虏潞君婴儿。** [[5]](#note-5)

**晋侯将狄臣千室赏给荀林父，又赏士伯瓜衍之县。** 士伯此前曾为荀林父进言，晋侯认为自己能获狄土也与留下荀林父有关，故同时赏赐。随后赵同奉命向周王献狄俘，刘康公对其失礼提出批评。 [看原文与说明](#cq-source-57)

<a id="event-6"></a>

6. **秦军伐晋，在辅氏交战；晋将魏颗俘获秦国勇士杜回。** 后世“结草报恩”的故事与此役相连。[[6]](#note-6)

<a id="event-7"></a>

7. **周王室内王孙苏与召、毛两氏争权，王子捷杀召伯、毛伯。** [[7]](#note-7)

<a id="event-8"></a>

8. **秋，鲁国发生螽灾；仲孙蔑与齐高固在无娄会面。** [[8]](#note-8)

<a id="event-9"></a>

9. **鲁国开始“初税亩”，正式按田亩征税。** 这是鲁国赋税制度的重要变化。[[9]](#note-9)

<a id="event-10"></a>

10. **冬，蝝虫孳生，同时发生饥荒。** [[10]](#note-10)

<a id="event-11"></a>

11. **曹宣公从本年开始纪元。** 曹文公已于上年去世，曹国转入宣公纪年；这是接续前君之丧的元年，不另记一场新的政变。[[11]](#note-11)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·宣公十五年》**：“十有五年春，公孙归父会楚子于宋。”

<a id="note-2"></a>

2. **《左传·宣公十五年》**详记楚围宋、城中严重饥荒。

<a id="note-3"></a>

3. **《左传·宣公十五年》**详记解扬受迫改辞而仍传晋命。

   **卷014郑栏异说：**[《十二诸侯年表》前594年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0594)另称郑“佐楚伐宋，执解扬”。经传可具体核证的是郑人扣获解扬并将他交给楚国；郑是否另遣军直接参与楚军围宋，本轮所据传文未明确交代。此处保留年表说法与证据界限，不凭“佐”字制造一支已确认攻城的郑军。

<a id="note-4"></a>

4. **《春秋·宣公十五年》**：“夏五月，宋人及楚人平。”  
   **《左传·宣公十五年》**详记华元夜入楚师、退三十里而盟。

<a id="note-5"></a>

5. **《春秋·宣公十五年》**：“六月癸卯，晋师灭赤狄潞氏，以潞子婴儿归。”

<a id="note-6"></a>

6. **《春秋·宣公十五年》**：“秦人伐晋。”  
   **《左传·宣公十五年》**详记辅氏之战、魏颗获杜回及结草故事。

<a id="note-7"></a>

7. **《春秋·宣公十五年》**：“王札子杀召伯、毛伯。”

<a id="note-8"></a>

8. **《春秋·宣公十五年》**：“秋，螽。仲孙蔑会齐高固于无娄。”

<a id="note-9"></a>

9. **《春秋·宣公十五年》**：“初税亩。”  
   **《左传·宣公十五年》**：“穀出不过藉，以丰财也。”

<a id="note-10"></a>

10. **《春秋·宣公十五年》**：“冬，蝝生。饥。”

<a id="note-11"></a>

11. **《史记·十二诸侯年表》前594年曹栏**：“曹宣公廬元年。” **《史记·管蔡世家》**：“文公二十三年卒，子宣公彊立。”前者作“廬”、后者作“彊”，两者同指曹文公之子、其后继君宣公，暂保留姓名异文。[原表](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0594) · [《管蔡世家》](https://zh.wikisource.org/wiki/史記/卷035)。

## 补充核对的史料

<a id="cq-source-57"></a>
### 核对57｜晋侯将狄臣千室赏给荀林父，又赏士伯瓜衍之县

**说明：**“千室”照录为来源数字；刘康公关于赵同将有大咎的预言不另算成本年已经遭祸。

<details>
<summary>传 T007｜原文</summary>

> 晋侯赏桓子狄臣千室，亦赏士伯以瓜衍之县。曰：“吾获狄土，子之功也。微子，吾丧伯氏矣。”羊舌职说是赏也，曰：“《周书》所谓‘庸庸祗祗’者，谓此物也夫。士伯庸中行伯，君信之，亦庸士伯，此之谓明德矣。文王所以造周，不是过也。故《诗》曰：‘陈锡载周。’能施也。率是道也，其何不济？”

[本段出处](../../sources/春秋左传/有标点原文/bce-0594.md#t007)

</details>

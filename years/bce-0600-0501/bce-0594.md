# 公元前594年（鲁宣公十五年）

[← 上一张已编年页：公元前595年](bce-0595.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前593年 →](bce-0593.md)

<a id="event-1"></a>

1. **春，公孙归父到宋地会见楚庄王。** 鲁国开始直接与楚国协调。[1]

<a id="event-2"></a>

2. **宋国被楚军长期包围，城中饥荒极重。** 晋国虽然想救宋，却判断楚势正盛，没有出兵。[2]

<a id="event-3"></a>

3. **晋使解扬被郑国截获送给楚国，楚王要求他向宋城传假消息；解扬登车后仍传达晋君原命。** 楚王最终放他回晋。[3]

<a id="event-4"></a>

4. **夏五月，宋大夫华元夜入楚军，与子反直接谈判。** 楚军退三十里，宋楚讲和。[4]

<a id="event-5"></a>

5. **六月，晋国灭赤狄潞氏，俘虏潞君婴儿。** [5]

<a id="event-6"></a>

6. **秦军伐晋，在辅氏交战；晋将魏颗俘获秦国勇士杜回。** 后世“结草报恩”的故事与此役相连。[6]

<a id="event-7"></a>

7. **周王室内王孙苏与召、毛两氏争权，王子捷杀召伯、毛伯。** [7]

<a id="event-8"></a>

8. **秋，鲁国发生螽灾；仲孙蔑与齐高固在无娄会面。** [8]

<a id="event-9"></a>

9. **鲁国开始“初税亩”，正式按田亩征税。** 这是鲁国赋税制度的重要变化。[9]

<a id="event-10"></a>

10. **冬，蝝虫孳生，同时发生饥荒。** [10]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·宣公十五年》**：“十有五年春，公孙归父会楚子于宋。”

<a id="note-2"></a>

2. **《左传·宣公十五年》**详记楚围宋、城中严重饥荒。

<a id="note-3"></a>

3. **《左传·宣公十五年》**详记解扬受迫改辞而仍传晋命。

<a id="note-4"></a>

4. **《春秋·宣公十五年》**：“夏五月，宋人及楚人平。”  
   **《左传·宣公十五年》**详记华元夜入楚师、退三十里而盟。

<a id="note-5"></a>

5. **《春秋·宣公十五年》**：“六月癸卯，晋师灭赤狄潞氏，以潞子婴儿归。”

<a id="note-6"></a>

6. **《春秋·宣公十五年》**：“秦人伐晋。”  
   **《左传·宣公十五年》**详记辅氏之战、魏颗获杜回及结草故事。

<a id="note-7"></a>

7. **《春秋·宣公十五年》**：“王札子杀召伯、毛伯。”

<a id="note-8"></a>

8. **《春秋·宣公十五年》**：“秋，螽。仲孙蔑会齐高固于无娄。”

<a id="note-9"></a>

9. **《春秋·宣公十五年》**：“初税亩。”  
   **《左传·宣公十五年》**：“穀出不过藉，以丰财也。”

<a id="note-10"></a>

10. **《春秋·宣公十五年》**：“冬，蝝生。饥。”

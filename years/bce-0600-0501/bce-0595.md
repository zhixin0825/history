# 公元前595年（鲁宣公十四年）

[← 上一张已编年页：公元前596年](bce-0596.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前594年 →](bce-0594.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，卫国让大夫孔达自尽，以此向晋国交代卫国违反清丘盟救陈之事。** 事后卫国恢复其家族地位。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏五月，曹文公去世；秋天完成葬礼。** 儿子继位为宣公。 [[2]](#note-2)

<a id="event-3"></a>

3. **晋景公伐郑，追究邲战中郑国依楚。** 晋军展示军容后撤退，郑国转而加强与楚关系。 邲败以后楚庄王声势大振，晋对郑用兵也意在追究其助楚。 [[3]](#note-3)

<a id="event-4"></a>

4. **楚庄王派申舟出使齐国，却故意让他不向宋国借道。** 宋国认为这是把自己视同无国，于是扣留并处死申舟。 [[4]](#note-4)

<a id="event-5"></a>

5. **楚庄王得知后立即出兵。秋九月，楚军开始长期包围宋国。** [[5]](#note-5)

<a id="event-6"></a>

6. **冬，公孙归父在穀地会见齐侯。** 鲁国已经开始考虑楚宋战争对自身外交的影响。 [[6]](#note-6)

<a id="note-4"></a>

### 4. 楚庄王派申舟出使齐国，却故意让他不向宋国借道

[返回正文第4条](#event-4)

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0595.md#all-20261109-t003)**

> 楚子使申舟聘于齐，曰：“无假道于宋。”亦使公子冯聘于晋，不假道于郑。申舟以孟诸之役恶宋，曰：“郑昭宋聋，晋使不害，我则必死。”王曰：“杀女，我伐之。”见犀而行。及宋，宋人止之。华元曰：“过我而不假道，鄙我也。鄙我，亡也。杀其使者必伐我，伐我亦亡也。亡一也。”乃杀之。楚子闻之，投袂而起，屦及于窒皇，剑及于寝门之外，车及于蒲胥之市。

# 公元前595年（鲁宣公十四年）

[← 上一张已编年页：公元前596年](bce-0596.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前594年 →](bce-0594.md)

<a id="event-1"></a>

1. **春，卫国让大夫孔达自尽，以此向晋国交代卫国违反清丘盟救陈之事。** 事后卫国恢复其家族地位。[[1]](#note-1)

<a id="event-2"></a>

2. **夏五月，曹文公去世；秋天完成葬礼。** [[2]](#note-2)

<a id="event-3"></a>

3. **晋景公伐郑，追究邲战中郑国依楚。** 晋军展示军容后撤退，郑国转而加强与楚关系。[[3]](#note-3)

<a id="event-4"></a>

4. **楚庄王派申舟出使齐国，却故意让他不向宋国借道。** 宋国认为这是把自己视同无国，于是扣留并处死申舟。[[4]](#note-4)

<a id="event-5"></a>

5. **楚庄王得知后立即出兵。秋九月，楚军开始长期包围宋国。** [[5]](#note-5)

<a id="event-6"></a>

6. **冬，公孙归父在穀地会见齐侯。** 鲁国已经开始考虑楚宋战争对自身外交的影响。[[6]](#note-6)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·宣公十四年》**：“十有四年春，卫杀其大夫孔达。”  
   **《左传·宣公十四年》**详记孔达自缢、卫以说于晋。

<a id="note-2"></a>

2. **《春秋·宣公十四年》**：“夏五月壬申，曹伯寿卒……葬曹文公。”

<a id="note-3"></a>

3. **《春秋·宣公十四年》**：“晋侯伐郑。”  
   **《左传·宣公十四年》**：“为邲故也。”

<a id="note-4"></a>

4. **《左传·宣公十四年》**详记楚使申舟聘齐不假道宋，宋人处置申舟。

<a id="note-5"></a>

5. **《春秋·宣公十四年》**：“秋九月，楚子围宋。”  
   **《左传·宣公十四年》**详记楚庄王得讯后出兵。

<a id="note-6"></a>

6. **《春秋·宣公十四年》**：“冬，公孙归父会齐侯于穀。”

# 公元前597年（鲁宣公十二年）

[← 上一张已编年页：公元前598年](bce-0598.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前596年 →](bce-0596.md)

<a id="event-1"></a>

1. **春，鲁国安葬陈灵公。** [[1]](#note-1)

<a id="event-2"></a>

2. **楚庄王大举围郑，攻破郑都；郑襄公肉袒牵羊请降。** [[2]](#note-2)

<a id="event-3"></a>

3. **楚庄王没有灭郑，而是退军三十里，与郑讲和并交换人质。** [[3]](#note-3)

 [卷四互见与归年](#sj004-597-1)


<a id="event-4"></a>

4. **晋国出兵救郑。主帅荀林父得知郑已降楚后本想撤军，中军佐先縠却擅自渡河，坚持与楚交战。** [[4]](#note-4)

<a id="event-5"></a>

5. **晋军内部将帅意见严重分裂，最终全军被拖入战斗。** [[5]](#note-5)

<a id="event-6"></a>

6. **六月，晋楚在邲地决战，晋军大败。** 中、下军撤退混乱，上军相对完整地退走。[[6]](#note-6)

[补充史料与年次说明](#sj005-105-note)


<a id="event-7"></a>

7. **楚庄王没有把胜利用于夸示战果，而是提出“止戈为武”，把武功解释为禁暴、息兵、安民。** [[7]](#note-7)

<a id="event-8"></a>

8. **晋军败归后，荀林父请求承担失败责任；晋景公最终仍让他继续任职。** [[8]](#note-8)

<a id="event-9"></a>

9. **冬，楚庄王灭萧。** [[9]](#note-9)

**楚围萧以前曾答应：萧若不杀所获楚人，楚军可以退去。** 萧人仍杀了熊相宜僚、公子丙，楚军随后围城。军中天寒，巫臣提醒楚王体恤士卒，楚王巡军慰劳。传文还写还无社与申叔展约定，以枯井上的茅绖为藏身信号；萧溃以后，申叔展循信号救他出来。 [看原文与说明](#cq-source-56)

<a id="event-10"></a>

10. **晋、宋、卫、曹在清丘结盟；宋随后按盟约伐陈，卫国却出兵救陈。** 盟约刚形成便暴露出成员之间的分歧。[[10]](#note-10)

<a id="event-11"></a>

11. **邲之战期间，郑国石制曾引楚军入郑，图谋分郑并另立公子鱼臣。** 郑国后来杀仆叔、子服，传文把它放在借乱谋利的讨论中。这里只记实际引军、谋立和诛杀，不将图谋写成已经分出一个新郑国。 [看原文与说明](#cq-source-54)

<a id="event-12"></a>

12. **郑伯、许男到楚国朝见。** 两国向楚表示归附，是本年战后外交中的一项具体行动。 [看原文与说明](#cq-source-55)

<a id="cq-source-56"></a>
### 核对56｜楚围萧以前曾答应：萧若不杀所获楚人，楚军可以退去

**说明：**麦麹、山鞠穷、河鱼腹疾和眢井的问答属于隐语式情节，本条只说明求救约定，不提供现代医疗解释。萧溃在同段复述，不重复算两次灭萧。

<details>
<summary>传 T018｜原文</summary>

> 冬，楚子伐萧，宋华椒以蔡人救萧。萧人囚熊相宜僚及公子丙。王曰：“勿杀，吾退。”萧人杀之。王怒，遂围萧。萧溃。申公巫臣曰：“师人多寒。”王巡三军，拊而勉之。三军之士，皆如挟纩。遂傅于萧。还无社与司马卯言，号申叔展。叔展曰：“有麦麹乎？”曰：“无。”“有山鞠穷乎？”曰：“无。”“河鱼腹疾奈何？”曰：“目于眢井而拯之。”“若为茅绖，哭井则己。”明日萧溃，申叔视其井，则茅绖存焉，号而出之。

[本段出处](../../sources/春秋左传/有标点原文/bce-0597.md#t018)

</details>

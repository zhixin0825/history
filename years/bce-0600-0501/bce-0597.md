1. **春，鲁国安葬陈灵公。** [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **楚庄王退而复围郑都，攻破城后，郑襄公肉袒牵羊请降。** 楚军初围十七日，见郑人临哭而退；郑人修城后，楚军又进围，约三个月后攻破，由皇门进入。郑伯自认不能事楚之罪，愿受迁往南海、分给诸侯为臣妾等处置，又请念厉、宣、桓、武之旧，不绝郑国社稷，准其改过事楚。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **楚庄王准许郑国求和，亲挥旗令军退三十里。** 楚臣本欲拒降，王认为郑君既能屈己，仍可取信其民，不必灭国。楚遣潘尪入盟，郑送子良为人质。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **晋国出兵救郑。主帅荀林父得知郑已降楚后本想撤军，中军佐先縠却擅自渡河，坚持与楚交战。** 荀林父统中军，士会统上军，赵朔统下军；郤克、栾书、先縠、韩厥、巩朔等参与军中指挥。 [[4]](#reading-note-4)

<a id="event-5"></a>

<a id="reading-event-5"></a>

5. **晋军内部将帅意见严重分裂，最终全军被拖入战斗。** [[5]](#reading-note-5)

<a id="event-6"></a>

<a id="reading-event-6"></a>

6. **六月，晋楚在邲地决战，晋军大败。** 中、下军退却混乱，败军争船，许多人落水或受伤，知罃也被俘；上军较完整退走。楚军战胜后推进至衡雍才回师。 [[6]](#reading-note-6)

<a id="event-7"></a>

<a id="reading-event-7"></a>

7. **楚庄王没有把胜利用于夸示战果，而是提出“止戈为武”，把武功解释为禁暴、息兵、安民。** [[7]](#reading-note-7)

<a id="event-8"></a>

<a id="reading-event-8"></a>

8. **晋军败归后，荀林父请求承担失败责任；晋景公最终仍让他继续任职。** 士会以楚杀子玉曾使晋文公欢喜为例，劝景公不要再杀荀林父、让楚得两重胜利，景公因此留任主将。 [[8]](#reading-note-8)

<a id="event-9"></a>

<a id="reading-event-9"></a>

9. **冬，楚庄王灭萧。** [[9]](#reading-note-9)

<a id="reading-event-10"></a>

10. **楚围萧以前曾答应：萧若不杀所获楚人，楚军可以退去。** 萧人仍杀了熊相宜僚、公子丙，楚军随后围城。军中天寒，巫臣提醒楚王体恤士卒，楚王巡军慰劳。传文还写还无社与申叔展约定，以枯井上的茅绖为藏身信号；萧溃以后，申叔展循信号救他出来。 [[10]](#reading-note-10)

<a id="event-10"></a>

<a id="reading-event-11"></a>

11. **晋、宋、卫、曹在清丘结盟；宋随后按盟约伐陈，卫国却出兵救陈。** 盟约刚形成便暴露出成员之间的分歧。 [[11]](#reading-note-11)

<a id="event-11"></a>

<a id="reading-event-12"></a>

12. **邲之战期间，郑国石制曾引楚军入郑，图谋分郑并另立公子鱼臣。** 郑国后来杀仆叔、子服，传文把它放在借乱谋利的讨论中。这里只记实际引军、谋立和诛杀，不将图谋写成已经分出一个新郑国。 [[12]](#reading-note-12)

<a id="event-12"></a>

<a id="reading-event-13"></a>

13. **郑伯、许男到楚国朝见。** 两国向楚表示归附，是本年战后外交中的一项具体行动。 [[13]](#reading-note-13)

### 7. 楚庄王没有把胜利用于夸示战果，而是提出“止戈为武”，把武功解释为禁暴、息兵、安民

[返回正文第7条](#reading-event-7)

**[《左传》传文](../../sources/春秋左传/有标点原文/bce-0597.md#t014)**

> 丙辰，楚重至于邲，遂次于衡雍。潘党曰：“君盍筑武军，而收晋尸以为京观？臣闻克敌必示子孙，以无忘武功。”楚子曰：“非尔所知也。夫文，止戈为武。武王克商，作《颂》曰：‘载戢干戈，载櫜弓矢。我求懿德，肆于时夏，允王保之。’又作《武》，其卒章曰：‘耆定尔功。’其三曰：‘铺时绎思，我徂惟求定。’其六曰：‘绥万邦，屡丰年。’夫武，禁暴、戢兵、保大、定功、安民、和众、丰财者也。故使子孙无忘其章。今我使二国暴骨，暴矣；观兵以威诸侯，兵不戢矣。暴而不戢，安能保大？犹有晋在，焉得定功？所违民欲犹多，民何安焉？无德而强争诸侯，何以和众？利人之几，而安人之乱，以为己荣，何以丰财？武有七德，我无一焉，何以示子孙？其为先君宫，告成事而已。武非吾功也。古者明王伐不敬，取其鲸鲵而封之，以为大戮，于是乎有京观，以惩淫慝。今罪无所，而民皆尽忠以死君命，又可以为京乎？”祀于河，作先君宫，告成事而还。

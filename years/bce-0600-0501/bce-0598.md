# 公元前598年（鲁宣公十一年）

[← 上一张已编年页：公元前599年](bce-0599.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前597年 →](bce-0597.md)

<a id="event-1"></a>

1. **春，楚庄王进攻郑国，一直打到栎；郑国最终转而服楚。** [[1]](#note-1)
<a id="event-2"></a>

2. **夏，楚庄王与陈侯、郑伯在辰陵结盟，陈、郑正式服从楚国。** [[2]](#note-2)
<a id="event-3"></a>

3. **楚国令尹蒍艾猎在沂地筑城，工程三十天按期完工。** 这显示楚国军役组织已经相当成熟。[[3]](#note-3)

**楚左尹子重还率军侵宋，楚王在郔等待。** 同段随后写蒍艾猎营建沂城：先估算事务、期限、财用与工具，安排粮食和劳役，三旬告成。军事与营建都在该段，不只保留筑城。 [看原文与说明](#cq-source-53)

<a id="event-4"></a>

4. **秋，晋国与各部狄人在欑函会合。** 郤缺先向各部寻求和好；他们不满赤狄的役使，转而归附晋国。大夫原想把狄人叫来，郤缺主张晋方亲自前往，表示求人的一方不能不付出劳力。 [看原文与说明](#cq-source-19)
<a id="event-5"></a>

5. **冬，楚庄王为陈国夏氏之乱伐陈，杀夏徵舒并车裂于栗门，随后把陈国并为县。** [[5]](#note-5)
<a id="event-6"></a>

6. **申叔时批评：讨弑君者是义，但借讨罪吞并陈国就是贪。** 楚庄王接受劝告，从晋国迎回陈灵公太子午，立为陈成公，恢复陈国并重新安置旧臣。前598年为陈成公元年。[[6]](#note-6)
<a id="event-7"></a>

7. **公孙归父会齐军伐莒。** [[7]](#note-7)

<a id="event-8"></a>

8. **齐顷公无野本年开始纪元。** 其父齐惠公已在前599年去世，本年为顷公元年，不重复记一次即位。[[8]](#note-8)

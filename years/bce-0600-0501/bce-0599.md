# 公元前599年（鲁宣公十年）

[← 上一张已编年页：公元前600年](bce-0600.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前598年 →](bce-0598.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁宣公前往齐国，齐国因鲁国长期服从而归还济西田地。** 鲁国为宣公即位付出的土地代价在这一年得到部分恢复。 [[1]](#note-1)

<a id="event-2"></a>

<a id="event-3"></a>

<a id="event-4"></a>

2. **齐惠公去世，崔杼奔卫，鲁使赴齐会葬。** 四月丙辰发生日食，己巳齐惠公死。齐国高氏、国氏忌崔杼受宠，逐他奔卫。鲁宣公赴齐奔丧，五月归国，后来又派公孙归父赴齐会葬。 [[2]](#note-2)

<a id="event-5"></a>

3. **陈灵公与孔宁、仪行父在夏氏饮酒时公开羞辱夏徵舒。** 夏徵舒不堪其辱，在灵公离开时从马厩射杀陈灵公；孔宁、仪行父逃往楚国。 [[3]](#note-5)

<a id="event-6"></a>

4. **六月，宋军伐滕，因为滕国依仗晋国而不事宋。** [[4]](#note-6)

<a id="event-7"></a>

5. **晋景公据元年，晋、宋、卫、曹联合伐郑。** 郑国已经与楚讲和，晋国继续用诸侯联军施压。 [[5]](#note-7)

<a id="event-8"></a>

6. **秋，周王派王季子来鲁聘问。** [[6]](#note-8)

<a id="event-9"></a>

<a id="event-11"></a>

<a id="hs-event-14"></a>

7. **鲁伐邾取绎，鲁境大水后发生饥荒。** 公孙归父领兵伐邾，取绎。秋，鲁国大水，冬发生饥荒。冬季楚庄王又伐郑，晋士会救郑，把楚军逐至颍水以北。 [[7]](#note-9)

<a id="event-10"></a>

8. **季孙行父与公孙归父先后赴齐，齐侯又派国佐来鲁聘问。** [[8]](#note-10)

<a id="event-12"></a>

9. **卫穆公元年。** 卫成公去世后，卫国进入穆公元年。 [[9]](#note-12)

<a id="sj042-zijia-family-event"></a>

10. **郑子家去世，族人遭追究灵公之乱。** 冬，公子归生即子家去世。郑人追究他参与弑君，砍毁他的棺材，驱逐其族，并重新安葬从前称幽公的被弑君主，改谥为灵公。身后追责与楚晋军队进退同在本年，但不因此把诸公子后来的内乱都说成子家一族所为。 [[10]](#sj042-zijia-family-note)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·宣公十年》**：“十年春，公如齐。公至自齐。齐人归我济西田。” **《左传》**：“齐侯以我服故，归济西之田。”
<a id="history-legacy-source-2"></a>


2. **《春秋·宣公十年》**：“夏四月丙辰，日有食之。己巳，齐侯元卒。”
<a id="history-legacy-source-3"></a>


3. **《春秋·宣公十年》**：“齐崔氏出奔卫。” **《左传》**详记高、国逐崔杼。
<a id="history-legacy-source-4"></a>


4. **《春秋·宣公十年》**：“公如齐。五月，公至自齐。”又记：“公孙归父如齐，葬齐惠公。”
<a id="history-legacy-source-5"></a>


5. **《春秋·宣公十年》**：“癸巳，陈夏徵舒弑其君平国。” **《左传》**详记夏氏宴饮、徵舒射杀灵公及二子奔楚。
<a id="history-legacy-source-6"></a>


6. **《春秋·宣公十年》**：“六月，宋师伐滕。”
<a id="history-legacy-source-7"></a>


7. **《春秋·宣公十年》**：“晋人、宋人、卫人、曹人伐郑。” **[《史记·十二诸侯年表》前599年晋栏](../../拆分史书/史记/卷014.md#y0599)**：“晋景公据元年与宋伐郑。” **[《晋世家》](../../拆分史书/史记/卷039.md#part-1-text)**记晋成公去世、其子景公据继立，次年为景公元年。
<a id="history-legacy-source-8"></a>


8. **《春秋·宣公十年》**：“秋，天王使王季子来聘。”
<a id="history-legacy-source-9"></a>


9. **《春秋·宣公十年》**：“公孙归父帅师伐邾，取绎。大水。”
<a id="history-legacy-source-10"></a>


10. **《春秋·宣公十年》**：“季孙行父如齐。冬，公孙归父如齐。齐侯使国佐来聘。”
<a id="history-legacy-source-11"></a>


11. **《春秋·宣公十年》**：“饥。楚子伐郑。” **《左传》**详记晋士会救郑、逐楚师于颍北。

<a id="history-legacy-source-12"></a>


12. **《史记·十二诸侯年表》前599年卫栏**：“卫穆公鸱元年”；[《卫康叔世家》](../../拆分史书/史记/卷037.md#part-1-text)作成公之子“穆公遫”。两篇所记均为卫成公之后的穆公，但“鸱／遫”字形、姓名异文有待三家注和校勘。 [年表原行](../../拆分史书/史记/卷014.md#y0599)。

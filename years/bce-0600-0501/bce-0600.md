# 公元前600年（鲁宣公九年）

[← 上一张已编年页：公元前601年](../bce-0700-0601/bce-0601.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前599年 →](bce-0599.md)

<a id="event-1"></a>

1. **春，鲁宣公前往齐国并返回。** [1]

<a id="event-2"></a>

2. **周王要求鲁国补行聘问，夏天仲孙蔑赴京师；周王厚礼回赠。** [2]

<a id="event-3"></a>

3. **齐侯出兵伐莱。** [3]

<a id="event-4"></a>

4. **秋，鲁国取得根牟。** [4]

<a id="event-5"></a>

5. **八月，滕昭公去世。** [5]

<a id="event-6"></a>

6. **九月，晋成公与宋、卫、郑、曹在扈地会盟，追究不服从者；陈侯没有赴会，晋荀林父遂率诸侯军伐陈。** [6]

<a id="event-7"></a>

7. **晋成公在扈地去世，晋军因此撤退。** [7]

<a id="event-8"></a>

8. **冬，卫成公去世；宋军趁滕国国丧包围滕国。** [8]

<a id="event-9"></a>

9. **楚庄王伐郑，晋郤缺出兵救郑。** 郑军在柳棼击败楚军，但郑国大夫担心这会招来更大的楚国报复。[9]

<a id="event-10"></a>

10. **陈灵公与孔宁、仪行父长期在夏姬处淫乱，洩冶公开劝谏后被杀。** 陈国内政迅速走向崩坏。[10]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·宣公九年》**：“九年春，王正月，公如齐。公至自齐。”

<a id="note-2"></a>

2. **《春秋·宣公九年》**：“夏，仲孙蔑如京师。”  
   **《左传·宣公九年》**：“王使来征聘……孟献子聘于周。”

<a id="note-3"></a>

3. **《春秋·宣公九年》**：“齐侯伐莱。”

<a id="note-4"></a>

4. **《春秋·宣公九年》**：“秋，取根牟。”

<a id="note-5"></a>

5. **《春秋·宣公九年》**：“八月，滕子卒。”

<a id="note-6"></a>

6. **《春秋·宣公九年》**：“九月，晋侯、宋公、卫侯、郑伯、曹伯会于扈。晋荀林父帅师伐陈。”  
   **《左传·宣公九年》**：“陈侯不会。”

<a id="note-7"></a>

7. **《春秋·宣公九年》**：“辛酉，晋侯黑臀卒于扈。”

<a id="note-8"></a>

8. **《春秋·宣公九年》**：“冬十月癸酉，卫侯郑卒。宋人围滕。”  
   **《左传·宣公九年》**：“因其丧也。”

<a id="note-9"></a>

9. **《春秋·宣公九年》**：“楚子伐郑。晋郤缺帅师救郑。”  
   **《左传·宣公九年》**详记郑败楚师于柳棼。

<a id="note-10"></a>

10. **《春秋·宣公九年》**：“陈杀其大夫洩冶。”  
    **《左传·宣公九年》**详记陈灵公、孔宁、仪行父与夏姬及洩冶进谏。

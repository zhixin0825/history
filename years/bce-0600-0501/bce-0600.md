## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·宣公九年》**：“九年春，王正月，公如齐。公至自齐。”

<a id="history-legacy-source-2"></a>


2. **《春秋·宣公九年》**：“夏，仲孙蔑如京师。”  
   **《左传·宣公九年》**：“王使来征聘……孟献子聘于周。”

<a id="history-legacy-source-3"></a>


3. **《春秋·宣公九年》**：“齐侯伐莱。”

<a id="history-legacy-source-4"></a>


4. **《春秋·宣公九年》**：“秋，取根牟。”

<a id="history-legacy-source-5"></a>


5. **《春秋·宣公九年》**：“八月，滕子卒。”

<a id="history-legacy-source-6"></a>


6. **《春秋·宣公九年》**：“九月，晋侯、宋公、卫侯、郑伯、曹伯会于扈。晋荀林父帅师伐陈。”  
   **《左传·宣公九年》**：“陈侯不会。”[卷014晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0600)却先写“使桓子伐楚”，接着写率诸侯伐陈救郑。桓子为中行桓子荀林父，但伐楚与经文明记伐陈的目标不同；本页沿经传具体行动，不为了调和一个字的差异再造一次未经核实的荀林父伐楚。

<a id="history-legacy-source-7"></a>


7. **《春秋·宣公九年》**：“辛酉，晋侯黑臀卒于扈。”[卷014晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0600)成公薨落在这里。前607年继立、前606年元年与本年死亡分清，晋景公元年在下一年，不重复死亡与册立。

<a id="history-legacy-source-8"></a>


8. **《春秋·宣公九年》**：“冬十月癸酉，卫侯郑卒。宋人围滕。”  
   **《左传·宣公九年》**：“因其丧也。”本行年表卫栏虽只有年数，不能据其未载死亡就删去经文有据的卫成公卒事。

<a id="history-legacy-source-9"></a>


9. **《春秋·宣公九年》**：“楚子伐郑。晋郤缺帅师救郑。”  
   [**《左传·宣公九年》**](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E5%AE%A3%E5%85%AC.md#ref-78673a327f7021)明确“郑伯败楚师于柳棼”，并记子良忧惧。[卷014晋、楚、郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0600)压缩记援郑和败楚，主语容易被读成全是晋军。正文区分晋救郑、郑军取胜，不将双方作用互相抹去；子良对未来报复的担忧也不是已经发生于本年的又一次战争。

<a id="history-legacy-source-10"></a>


10. **《春秋·宣公九年》**：“陈杀其大夫洩冶。”传文详记朝中戏衣、洩冶谏、二子请杀而君不禁。原正文概称陈政崩坏，现补明确行动，不用结局倒推一切未记的内幕。陈灵公下一年被杀是后续，不提前计在本年。

# 公元前600年（鲁宣公九年）

[← 上一张已编年页：公元前601年](../bce-0700-0601/bce-0601.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前599年 →](bce-0599.md)

<a id="event-1"></a>

1. **春，鲁宣公前往齐国并返回。** [[1]](#note-1)

<a id="event-2"></a>

2. **周王要求鲁国补行聘问，夏天仲孙蔑赴京师；周王厚礼回赠。** [[2]](#note-2)

<a id="event-3"></a>

3. **齐侯出兵伐莱。** [[3]](#note-3)

<a id="event-4"></a>

4. **秋，鲁国取得根牟。** [[4]](#note-4)

<a id="event-5"></a>

5. **八月，滕昭公去世。** [[5]](#note-5)

<a id="event-6"></a>

6. **九月，晋成公与宋、卫、郑、曹在扈地会盟，追究不服从者；陈侯没有赴会，晋荀林父遂率诸侯军伐陈。** [[6]](#note-6)

<a id="event-7"></a>

7. **晋成公在扈地去世，晋军因此撤退。** [[7]](#note-7)

<a id="event-8"></a>

8. **冬，卫成公去世；宋军趁滕国国丧包围滕国。** [[8]](#note-8)

<a id="event-9"></a>

9. **楚庄王伐郑，晋郤缺出兵救郑；郑伯带兵在柳棼击败楚军。** 郑人大多为胜利高兴，子良却担心这会招来楚国更大的报复。援军到来与郑军作战各有作用，不把战果全归给一个笼统的“诸侯联军”。[[9]](#note-9)

<a id="event-10"></a>

10. **陈灵公与孔宁、仪行父长期同夏姬私通，甚至把她的贴身衣物穿在里面，在朝廷上互相取笑。** 洩冶公开劝谏，陈灵公口头表示会改，却又把劝谏告诉二人；孔宁、仪行父请求杀洩冶，灵公不加制止，洩冶终于被杀。[[10]](#note-10)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·宣公九年》**：“九年春，王正月，公如齐。公至自齐。”

<a id="note-2"></a>

2. **《春秋·宣公九年》**：“夏，仲孙蔑如京师。”  
   **《左传·宣公九年》**：“王使来征聘……孟献子聘于周。”

<a id="note-3"></a>

3. **《春秋·宣公九年》**：“齐侯伐莱。”

<a id="note-4"></a>

4. **《春秋·宣公九年》**：“秋，取根牟。”

<a id="note-5"></a>

5. **《春秋·宣公九年》**：“八月，滕子卒。”

<a id="note-6"></a>

6. **《春秋·宣公九年》**：“九月，晋侯、宋公、卫侯、郑伯、曹伯会于扈。晋荀林父帅师伐陈。”  
   **《左传·宣公九年》**：“陈侯不会。”[卷014晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0600)却先写“使桓子伐楚”，接着写率诸侯伐陈救郑。桓子为中行桓子荀林父，但伐楚与经文明记伐陈的目标不同；本页沿经传具体行动，不为了调和一个字的差异再造一次未经核实的荀林父伐楚。

<a id="note-7"></a>

7. **《春秋·宣公九年》**：“辛酉，晋侯黑臀卒于扈。”[卷014晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0600)成公薨落在这里。前607年继立、前606年元年与本年死亡分清，晋景公元年在下一年，不重复死亡与册立。

<a id="note-8"></a>

8. **《春秋·宣公九年》**：“冬十月癸酉，卫侯郑卒。宋人围滕。”  
   **《左传·宣公九年》**：“因其丧也。”本行年表卫栏虽只有年数，不能据其未载死亡就删去经文有据的卫成公卒事。

<a id="note-9"></a>

9. **《春秋·宣公九年》**：“楚子伐郑。晋郤缺帅师救郑。”  
   [**《左传·宣公九年》**](https://zh.wikisource.org/wiki/春秋左氏傳/宣公#宣公九年)明确“郑伯败楚师于柳棼”，并记子良忧惧。[卷014晋、楚、郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0600)压缩记援郑和败楚，主语容易被读成全是晋军。正文区分晋救郑、郑军取胜，不将双方作用互相抹去；子良对未来报复的担忧也不是已经发生于本年的又一次战争。

<a id="note-10"></a>

10. **《春秋·宣公九年》**：“陈杀其大夫洩冶。”传文详记朝中戏衣、洩冶谏、二子请杀而君不禁。原正文概称陈政崩坏，现补明确行动，不用结局倒推一切未记的内幕。陈灵公下一年被杀是后续，不提前计在本年。

<a id="sj014-0600-yan-blank"></a>
### 燕栏空白不补造元年后的“二”

[带列头原表](https://zh.wikisource.org/wiki/史記/卷014)前601年燕宣公元年，前600年燕栏空，前599年三。本批将前600年燕格与吴格都记为空，不因可作算术推断就擅填史料原文。空格不是燕、吴没有历史的断言。

# 春秋晚期｜求学、问政与周游（未定年）

[本世纪目录](README.md) · [全部时间目录](../README.md) · [孔子及后裔纪年](../../meta/考证/史记-卷047-纪年与异说.md)

**时间精度：未定年与分期传述。** 本页收录孔子一生中未能逐项确年的求学、问政、周游及晚年讲学传述。正文按有关阶段和主题阅读；各组之间的编排不证明实际先后。可以确年的会盟、战争、卒年仍在原年度页，未知年轶事不由篇序或传统年谱强造精度。

<a id="sj047-early-event"></a>

1. **孔子的幼年与谋生经历，在家世传述中留下礼仪学习的线索。** 他幼年丧父，父亲葬防山；自己不知道墓的具体位置，母亲死后先停殡于五父之衢，向郰人挽父之母问明父墓，才合葬。小时候，他曾摆俎豆模拟礼仪。服丧时前往季氏宴士，被阳虎挡回；这段服丧赴宴的叙述与“要经”异文仍有分歧。青年谋生曾管理仓储计量和畜牧，使出入平正、牲畜繁衍。本篇接叙司空和后来的各国行旅，是全生涯提要，不是这些事都发生在少年时期。 [[1]](#sj047-early-note)

<a id="sj047-zhou-event"></a>

2. **赴周问礼的故事，把求知与保身的劝诫放在一起。** 南宫敬叔请求与孔子赴周，鲁君给车马随从。孔子向周人问礼，相传见到掌管周室藏书的老子，姓李、名耳、字聃，传为楚苦县厉乡曲仁里人。老子劝他去除骄气、多欲与外露的志念，用深藏货物的良商、外貌谦退的君子作比；孔子离开后又以难测的龙形容他。另一段临别赠言说，老子以言语代替财物，提醒聪明善辩的人若专好议人、揭人恶，容易自危，做人子、人臣不应事事以自己为中心。孔子返鲁后求学者渐多。会面的年代和老子身份仍有争论。 [[2]](#sj047-zhou-note)

<a id="sj047-setting-event"></a>

3. **鲁国在晋、楚、齐的压力之间寻找生存空间。** 晋国内六卿日益有势，晋军向东经营诸侯；楚国兵强，向中原施压；齐国则既强大又邻近鲁。鲁靠楚会得罪晋，靠晋又可能招楚兵，疏于防齐也会遭侵。这是孔子成长和求仕的政治背景，晋平公、楚灵王的名称对应各自时代，不使后面的所有周游都发生在二人同时在位时。 [[3]](#sj047-setting-note)

<a id="sj047-qi-event"></a>

4. **鲁昭公失国以后，孔子曾赴齐求用，最终仍回鲁。** 他住在高昭子门下，希望通过这层关系见景公；闻韶、习乐的传述，形容他沉浸其美而三个月不知肉味。景公问政，他要求君臣父子各守其职，又主张节用。景公想封尼谿田，晏婴却批评儒者辞辩、厚葬、繁礼未必便民，反对以其改变齐俗。景公仍礼遇而不任用，待遇只许在季、孟之间；齐大夫又有敌意，景公以年老不能用为辞，孔子终于离齐返鲁。 [[4]](#sj047-qi-note)

<a id="sj047-well-event"></a>

5. **季桓子掘井所得异物，引出关于古代怪异之名的问答。** 瓦器中的东西看似羊，桓子却问孔子说得了狗。孔子答应是羊，并区分木石、水与土中各类怪异，称土怪为坟羊。这是古代博物知识与传说的展示。 [[5]](#sj047-well-note)

<a id="sj047-bones-event"></a>

6. **会稽巨骨的传说，被解释为禹会诸侯时的防风氏遗骨。** 吴人传说在攻越后获得可载一车的骨节，向孔子询问。他讲禹诛迟到的防风氏，又把山川神、社稷与守土诸侯的职分相连，说明汪罔氏在虞夏商周的名称变化。问到身高极限，则以僬侥与巨人作答。这里保存的是古代对奇异遗物的解释，不能据此证明巨人存在，也不能把传述另编成一场新吴越战。 [[6]](#sj047-bones-note)

<a id="sj047-gongshan-event"></a>

7. **公山不狃召孔子，孔子虽有意尝试，最后没有前往。** 长期求行其道而无人用，孔子想到文武也曾从丰、镐小地兴起，或许费邑仍可成为恢复周道的起点。子路反对他应叛者之召，他则说召自己未必全无用意；但这一设想终于没有实行。 [[7]](#sj047-gongshan-note)

<a id="sj047-government-event"></a>

8. **孔子参与鲁政的传述，兼有任职、德行理想和争议事迹。** 他由大司寇摄相，面有喜色，弟子以祸不惧、福不喜相问，他说也可乐于居高位而下人。传记继而写诛少正卯，并形容三个月内商贩不虚饰物价、行路有序、遗物不取、宾客受善待。少正卯的事迹和极短期内全面变政的写法有争议，这些叙述保留为政治理想与史源问题，不能当作已经逐项核实的当年纪录。 [[8]](#sj047-government-note)

<a id="sj047-kuang-event"></a>

9. **匡人把孔子一行误认作阳虎，师徒被围困数日。** 驾车的颜刻指城墙缺口谈旧事，而阳虎曾害当地人，孔子形貌又与他相似，遂被拘。颜回迟归，孔子曾担心其死；颜回答老师尚在，自己怎敢先死。弟子恐慌时，孔子以承续文王之文自勉，说若天不灭此道，匡人不能奈何。脱险经过另有疑记，甯武子本人远早于此时，不能据篇末一句确立他亲自营救。 [[9]](#sj047-kuang-note)

<a id="sj047-nanzi-event"></a>

10. **孔子返卫见南子，又因随车招摇过市而感到羞耻。** 他住蘧伯玉家，南子借接见来客的礼数召见，孔子推辞不得，只在帷外稽首，南子在帷内再拜，佩玉作响。子路不悦，孔子向天发誓说明无邪。后来卫灵公与南子同车出行，让孔子坐后车随行，孔子感叹好德不如好色，遂离卫、经过曹国。 [[10]](#sj047-nanzi-note)

<a id="sj047-zheng-event"></a>

11. **在郑国失散时，孔子以笑回应无所归依的比喻。** 他独站外城东门，有人向子贡把他的头颈肩比作尧、皋陶、子产，又说疲惫得像丧家之狗。子贡转告，孔子说相貌并不重要，至于狼狈无归的形容，倒说得相像。 [[11]](#sj047-zheng-note)

<a id="sj047-chen-event"></a>

12. **居陈的传述，以寄居和识物说明孔子在异国的生活。** 他住司城贞子家；陈廷后来落下一只中箭死隼，陈湣公请教，孔子说楛箭石镞是肃慎贡物，追述周武王把远方贡物分给嫁入陈国的大姬，以提醒异姓诸侯职分，陈人查旧府果然找到相似物。故事表现旧物与礼制知识，不能据一箭重建鸟的远飞路线。陈地多战，传记以居留三年概括，孔子想到鲁国年轻弟子，感叹归去而离陈。 [[12]](#sj047-chen-note)

<a id="sj047-pu-event"></a>

13. **蒲人以强盟放行，孔子却没有把胁迫下的承诺视为有效。** 公叔氏据蒲叛卫，孔子经过被扣。公良孺带自家五乘车追随老师，认为匡难之后再受拘，不如死战，奋力抵抗。蒲人惧而求盟，只要不去卫就放行；孔子出城仍赴卫，对子贡解释强迫之盟神不会听从。卫灵公迎接后问能否伐蒲，孔子认为多数邑人仍愿属卫、保境，所讨只四五名首恶。灵公口头赞同却不出兵，也未任用孔子。孔子感叹若真正用他，一年初有规模、三年可成，后来再次离去；这不是已经实施的三年政绩。 [[13]](#sj047-pu-note)

<a id="sj047-fo-event"></a>

14. **佛肸召孔子，引出是否应到叛者手下任职的争论。** 赵氏与范、中行相攻时，佛肸据中牟叛，派人相召。孔子有意往，子路质问为何要违背不入作恶者之门的教诲。孔子以坚不受磨、白不受染自比，表示可以守住原则，又不愿像匏瓜只挂着而无所用。本篇未记最终成行。 [[14]](#sj047-fo-note)

<a id="sj047-music-study-event"></a>

15. **学琴与击磬的传述，分别显示求知的深入和求世人理解的困难。** 向师襄学琴时，孔子已熟曲调仍不肯换曲，继续求技法、求志意，再求作曲者之为人，最后从音乐想象文王气象，老师说曲名正是《文王操》。另一次击磬，过路的荷蒉者听出心意，却劝既无人理解，何必如此执着。 [[15]](#sj047-music-study-note)

<a id="sj047-river-event"></a>

16. **听说赵简子杀旧日贤助，孔子在河边止步。** 他原想西行求见，得知窦鸣犊、舜华遇害，感叹河水浩荡而自己不能渡过。向子贡解释时，他指责先倚贤得志、后杀贤的做法，以伤胎、竭泽、覆巢会使祥瑞远去作比，说禽兽尚避不义，人更应如此。于是回转作琴曲哀悼，再回卫。二人姓名、身份仍有疑问。 [[16]](#sj047-river-note)

<a id="sj047-wei-army-event"></a>

17. **卫灵公问兵阵，孔子以未学军旅回应，再因不受重视离去。** 孔子说自己熟习俎豆礼仪，未学军事。次日交谈，灵公只顾仰看飞雁，心不在他，孔子遂再去陈。 [[17]](#sj047-wei-army-note)

<a id="sj047-ye-event"></a>

18. **在叶地问政，孔子强调安近来远，也以好学不倦自述。** 叶公问治理，他回答要安附近民、招来远方；叶公再向子路问老师为人，子路未答。孔子说，何不说明自己学道不厌、教人不倦，发愤忘食、乐以忘忧，不觉老年将至？ [[18]](#sj047-ye-note)

<a id="sj047-hermits-event"></a>

19. **向隐者问路，子路听到彻底避世的劝告，孔子仍主张参与人世。** 长沮知道车上是孔丘，讥他应当早知渡口；桀溺说天下皆乱，与其追随一个只避坏人的人，不如跟随避世者，仍低头耕作。孔子闻后怅然，说人不能与鸟兽为群，天下有道反而不必如此奔走改变。另一次，荷蓧丈人批评不劳动、不识五谷而谈老师，插杖除草；孔子称之隐者，派子路再去，老人已离开。 [[19]](#sj047-hermits-note)

<a id="sj047-jieyu-event"></a>

20. **接舆以凤歌劝孔子停止从政，孔子想交谈却未能相见。** 歌中感叹德衰，往事不可追回而未来仍能避免，警告当世从政危险。孔子下车，接舆却疾行远去。这是隐者与求仕者的分歧，不是凤凰来去的神异事件。 [[20]](#sj047-jieyu-note)

<a id="sj047-names-event"></a>

21. **卫国父子争位的局面，使正名成为孔子论政的起点。** 出公辄在位而父蒯聩在外，孔门弟子多在卫任职，卫君想用老师。子路问执政先做什么，孔子答正名，遭讥为迂；他解释名不正、言不顺会使政事不成、礼乐不兴、刑罚失当，百姓无所适从。君子所为须能说明正当名分，所言须可落实。这是待用时的原则讨论，不是孔子已任卫相的证明。 [[21]](#sj047-names-note)

<a id="sj047-late-politics-event"></a>

22. **返鲁后的问政，仍围绕择人和执政者自身的示范。** 哀公问治国，孔子重在选臣；本篇接着把举直而置于枉者之上、使邪曲者转正的答语归给季康子，索隐据《论语》指出受问者为哀公。康子忧盗，他答若上位者自己不贪，即使赏盗也难使人去偷，责其先自正。鲁国最终没有充分任用他，他也不再求仕。 [[22]](#sj047-late-politics-note)

<a id="sj047-classics-event"></a>

23. **晚年整理礼乐文献的传述，把孔子看作古代学术的重要传承者。** 他比较夏商周制度，承认讲夏殷之礼却缺杞宋足够证据，又赞周兼采二代而文备，主张从周。传记把从唐虞到秦穆公的书传整理归于他；返鲁后，他论乐曲从合奏展开、声部清晰而相续完成的秩序，又说雅、颂各得其所。说到《诗》，本篇称古诗三千余篇，经他去重而取合礼义者，上叙契、后稷，中述殷周盛衰，直至幽、厉失政，也从夫妻日用讲起，以《关雎》《鹿鸣》《文王》《清庙》作为四类开篇；三百零五篇皆配合乐音弦歌，作为传承礼乐、教育王道的材料。说到《易》，本篇写他晚年喜读，将彖、系辞、象、说卦、文言等序解归于他，形容联简皮绳读断多次；“假我数年”表达仍愿继续深造、期望于易更完备。孔子讲授整理、弟子传承与后学编定须分别考察，不能认定今本每篇都出自他亲笔；三千删为三百、十翼成书及韦编三绝仍各有研究分歧。 [[23]](#sj047-classics-note)

<a id="sj047-teaching-event"></a>

24. **孔门教育兼重文献、实践与自行思考。** 传记概称弟子三千、通六艺者七十二，尚有部分从学者；规模属于传统概数，不是某日在册清单。他以文、行、忠、信为教，戒臆断、强必、固执和唯我，对斋戒、战事与疾病谨慎。学生思而不通时才启发，举一角仍不能类推其他三角，就不重复灌输。“罕言利与命与仁”的断读另有解释，不把它误作全篇从不谈仁。 门人各有所长：德行有颜渊、闵子骞、冉伯牛、仲弓，政事有冉有、季路，言语有宰我、子贡，文献之学有子游、子夏。孔子又按个人的偏执、迟钝、愚直、刚猛等性情分别教导；颜回常贫而乐道，子贡则善于经营和判断行情。 [[24]](#sj047-teaching-note)

<a id="sj047-conduct-event"></a>

25. **孔子的礼仪风范，表现为随场合调整言语和行动。** 在乡里温和，在宗庙朝廷能辨而慎言，对上大夫中正、对下大夫和乐；入公门躬身，奉命迎宾郑重，受召时不等车备便行。饮食腐败或切割不当不食，席不正不坐；与丧者同席不吃饱，哭悼之日不歌，见丧服者或盲者即使年幼也改容致敬。 [[25]](#sj047-conduct-note)

<a id="sj047-learning-event"></a>

26. **不断学习、自省和选择谈论内容，是日常实践的一部分。** 同行者皆有可学之处，德未修、学未讲、闻义不能改从、见过不能改正才是所忧。听人唱得好，会请重唱而随之和歌；对怪异、逞力、悖乱、鬼神不轻易谈论。后一句并不意味着所有祭祀或政治乱事都不曾进入孔子的讨论，须保留古注的不同分法。 [[26]](#sj047-learning-note)

<a id="sj047-students-event"></a>

27. **弟子赞老师善诱，也留下孔子谦言自己多艺的回答。** 子贡说其文教可闻，天道性命深微难得闻；颜回说老师循序引导，以文拓展、以礼约束，使自己欲罢不能而仍难企及。达巷人赞其博学却不局限一技，孔子反问该专做驾车还是射箭，谦说自己驾车好了；子牢又传他因未被任用而多学技艺。这些评价各有说话者，不由赞语推出无所不知的神人形象。 [[27]](#sj047-students-note)

<a id="sj047-grief-event"></a>

28. **晚年的丧徒与道不行之感，在传记中与获麟之叹相连。** 颜回去世令孔子痛呼天丧予；见麟又叹吾道穷，感到无人理解。子贡问缘故，他答不怨天、不责人，由学习人事而上达，理解自己者或许只有天。颜回的卒年另有异说。 颜回二十九岁时已满头白发，早早去世；孔子痛哭，说自从有了颜回，弟子们更加亲近自己。哀公问谁好学，孔子举颜回不迁怒、不再犯同样过错，又哀叹他短命。颜回的父亲颜无繇字路，父子先后受教；颜路家贫，请拿孔子的车置办葬具，孔子以自己儿子鲤也只有棺而无椁、自己不能失去大夫所需车乘为由，没有答应。 [[28]](#sj047-grief-note)

<a id="sj047-withdrawal-event"></a>

29. **评价古代隐者时，孔子拒绝把进退固定成一条不变规则。** 伯夷叔齐守志不辱，柳下惠少连有所屈身，虞仲夷逸隐退而行清、合乎时宜；他说自己无可无不可，既不预定一定出仕，也不预定永远退避，依合宜之道判断。 [[29]](#sj047-withdrawal-note)

<a id="sj047-chunqiu-event"></a>

30. **《春秋》编述传统，把简约史文理解为承担褒贬责任的作品。** 它以鲁为据，上起隐公、下至哀公十四年获麟，贯十二公；亲周而念殷，把吴楚自称的王仍书作子，又将晋召天子写成天王出狩河阳，以字句名分衡量当世。传记说孔子担心道不行而后世无闻，于是据旧史笔削；平时听讼可与人共议，编述此书却自决取舍，弟子不能增一辞。他也说后世会因《春秋》理解自己或责备自己。这是著述及义例的传统解释，既不把全书写定硬定在获麟当年，也不等于已有可核的亲笔改稿。 [[30]](#sj047-chunqiu-note)

<a id="sj063-laozi-leaves-event"></a>

31. **老子离周出关的传述，以隐退与著书作结。** 老子以隐退自身、不求声名为要，见周室衰微而离去。到了关口，关令尹喜请求他留下文字，他便写成上下两篇，讲道与德，共五千余言，然后离开，去向不明。 [[31]](#sj063-laozi-leaves-note)

<a id="sj063-laozi-variants-event"></a>

32. **老子相关传述并列老莱子和不同寿数，没有形成确定年谱。** 另有一说提到楚人老莱子，著十五篇、讲道家之用，与孔子同时；又有老子活一百六十余岁或二百余岁、以修道养寿的传闻。传记保留这些说法，却没有把人物异名、寿数和太史儋的身份疑问全部定成一事。 [[32]](#sj063-laozi-variants-note)

### 28. 晚年的丧徒与道不行之感，在传记中与获麟之叹相连

<a id="sj047-chunqiu-note"></a>

### 30. 《春秋》编述传统，把简约史文理解为承担褒贬责任的作品

[返回正文第30条](#sj047-chunqiu-event)

<a id="sj047-cite-095"></a>

**[《史记·孔子世家》P073](../../sources/摘录/史记-卷047-孔子世家.md#p073)**

> 子曰：「弗乎弗乎，君子病沒世而名不稱焉。吾道不行矣，吾何以自見於後世哉？」乃因史記作春秋，上至隱公，下訖哀公十四年，十二公。據魯，親周，故殷，運之三代。約其文辭而指博。故吳楚之君自稱王，而春秋貶之曰「子」；踐土之會實召周天子，而春秋諱之曰「天王狩於河陽」：推此類以繩當世。貶損之義，後有王者舉而開之。春秋之義行，則天下亂臣賊子懼焉。

<a id="sj047-cite-096"></a>

**[《史记·孔子世家》P074](../../sources/摘录/史记-卷047-孔子世家.md#p074)**

> 孔子在位聽訟，文辭有可與人共者，弗獨有也。至於為春秋，筆則筆，削則削，子夏之徒不能贊一辭。弟子受春秋，孔子曰：「後世知丘者以春秋，而罪丘者亦以春秋。」

<a id="sj063-laozi-leaves-note"></a>

### 31. 老子离周出关的传述，以隐退与著书作结

[返回正文第31条](#sj063-laozi-leaves-event)

<a id="sj063-cite-003"></a>

**[《史记·老子韩非列传》P003](../../sources/摘录/史记-卷063-老子韩非列传.md#p003)**

> 老子修道德，其學以自隱無名為務。居周久之，見周之衰，乃遂去。至關，關令尹喜曰：「子將隱矣，彊為我著書。」於是老子乃著書上下篇，言道德之意五千餘言而去，莫知其所終。

**本卷说明：** 主文只称关，索隐、正义并存函谷与散关之说；不直接择一。紫气、青牛、同行流沙之西来自集解、索隐所引《列仙传》，属于后出神仙传说，不添为本段已证行程。

<a id="sj063-laozi-variants-note"></a>

### 32. 老子相关传述并列老莱子和不同寿数，没有形成确定年谱

[返回正文第32条](#sj063-laozi-variants-event)

<a id="sj063-cite-004"></a>

**[《史记·老子韩非列传》P004](../../sources/摘录/史记-卷063-老子韩非列传.md#p004)**

> 或曰：老萊子亦楚人也，著書十五篇，言道家之用，與孔子同時云。

<a id="sj063-cite-005"></a>

**[《史记·老子韩非列传》P005](../../sources/摘录/史记-卷063-老子韩非列传.md#p005)**

**本卷说明：** 正义明说盖、或皆疑辞。160与200是传闻数字，不按百科生卒或太史儋年次推得。身份讨论另接前374年太史儋同号注。

<!-- /sj063-cite-005 -->

<a id="sj063-cite-006"></a>

**[《史记·老子韩非列传》P008](../../sources/摘录/史记-卷063-老子韩非列传.md#p008)**

> 世之學老子者則絀儒學，儒學亦絀老子。「道不同不相為謀」，豈謂是邪？李耳無為自化，清靜自正。

**本卷说明：** 世上学习老子的人排斥儒学，学习儒学的人也排斥老子。“志向道路不同，就不相互谋议”，难道说的就是这种情形吗？李耳主张无为，使人自然化成；保持清静，使人自然归正。 此为司马迁篇中评议；索隐明指出此段亦是赞，不当成春秋时发生的新事件。

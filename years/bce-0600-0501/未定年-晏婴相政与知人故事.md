# 春秋晚期｜晏婴相政与知人故事（未定年）

[本世纪目录](README.md) · [全部时间目录](../README.md)

**时间精度：未定年与任职期间总述。** 本页收录晏婴历事灵、庄、景三公的概述、任政时的知人故事，以及穰苴传所记景公时期的荐将与治军故事。现有材料未给赎越石父、御者受荐、穰苴斩庄贾的独立年月，不由篇序、任相推定或现代出生年倒配年条。

1. **晏婴历事三位齐君，以节俭与谨慎正直立身。** 他出自莱地夷维，先后事奉齐灵公、庄公、景公。主持政事时，每餐不兼用两样肉食，妾不衣帛；在朝被谈及时谨慎回应，不被谈及时仍修正自身行为。政令有道便遵行，遇无道的命令则权衡可否，凭这些操守名闻诸侯。 [[1]](#sj062-yan-government-note)

<a id="sj062-yueshifu-event"></a>

2. **晏婴赎出越石父，听其申说以后奉为上客。** 越石父贤而被拘系。晏婴途中遇见，用车旁的一匹马赎他，载他回家，却没有好好招呼就进内室。越石父等待后请求绝交；晏婴惊讶，整好衣冠道歉，问自己既救他脱困，为何反被拒绝。越石父说，不知己的人使人屈辱，本在意料中；知己的人使志意伸展，才是可贵。既懂得自己而赎人，却不以礼相待，还不如留在原来的处境。晏婴因此郑重请他入内，奉为上客。 [[2]](#sj062-yueshifu-note)

<a id="sj062-charioteer-event"></a>

3. **御者接受妻子的规劝，晏婴随后因其改变而荐为大夫。** 晏婴外出时，御者的妻子从门缝看丈夫驾四马车、拥大伞盖，得意扬扬。丈夫回家后，妻子提出离开，说晏婴不到六尺却主持齐政、名闻诸侯，思虑深而总能谦下；丈夫八尺身材，只替人驾车，却已满心自得。御者于是收敛骄态。晏婴发现变化，问明缘故后，推荐他为大夫。 [[3]](#sj062-charioteer-note)

<a id="sj064-recommend-event"></a>

4. **景公时期｜晏婴荐穰苴，穰苴请宠臣监军。** 晋伐阿、甄，燕侵河上，齐师战败，景公忧虑。晏婴推荐田完后裔穰苴，称其虽出田氏支庶，却能附众、威敌。景公与他谈兵后任为将领。穰苴以出身低、士卒未附为由，请一位君主宠信且国人尊重的人监军，景公便派庄贾。二人约定次日正午在军门会合。 [[4]](#sj064-recommend-note)

<a id="sj064-zhuangjia-event"></a>

5. **庄贾为送行宴饮迟到，穰苴依军法将他处死。** 穰苴先到军门，立表并用漏壶计时。庄贾自恃骄贵，又以监军身份不急赴约，停留饮酒。到了正午，穰苴便仆表决漏，入营整军、申明约束；庄贾直到傍晚才来，以大夫亲戚相送解释。穰苴责他受命应忘家、临军应忘亲、鼓战应忘身，如今敌深入、士卒露宿、国君不安，百姓性命系于将帅，怎能只顾送行。军正答迟约当斩；庄贾派人求救，尚未返回，便被斩首徇军，众人震惧。 [[5]](#sj064-zhuangjia-note)

<a id="sj064-messenger-event"></a>

6. **君使驰车入军，穰苴以军中约束回应赦令。** 景公使者持节来赦庄贾，驱车直入军中。穰苴说将在军中，有的君命可以不受；军正答驰车也当斩，使者大惧。穰苴免杀君使，却仍斩车的左辅木与左骖马以示众，然后遣使回报、引军出发。 [[6]](#sj064-messenger-note)

<a id="sj064-army-event"></a>

7. **穰苴抚恤士卒、退敌收地，归国后受任大司马。** 驻舍、井灶、饮食、医药与问疾，他都亲自照顾；将军的资粮全给士卒，自己平分粮食，以最羸弱者为比。三日后再整军，病者仍争着请行。晋师闻讯退去，燕军渡水撤解，穰苴再追击、收复旧境，才引军归国。临近国都，他先收束军伍、解除战时约束、誓盟，再入邑；景公与大夫郊迎劳师，成礼后回宫，尊他为大司马，田氏由此益贵。 [[7]](#sj064-army-note)

<a id="sj064-dismissed-event"></a>

8. **穰苴遭大夫进谗，被罢退后病死。** 鲍氏、高氏、国氏等大夫嫉害穰苴，向景公进谗。景公将他罢退，穰苴发病而死；田乞、田豹等因此怨高、国诸族。 [[8]](#sj064-dismissed-note)

### 1. 晏婴历事三位齐君，以节俭与谨慎正直立身

[返回正文第1条](#sj062-yan-government-event)

<a id="sj062-cite-013"></a>

**[《史记·管晏列传》P007](../../sources/摘录/史记-卷062-管晏列传.md#p007)**

> 事齊靈公、莊公、景公，以節儉力行重於齊。既相齊，食不重肉，妾不衣帛。其在朝，君語及之，即危言；語不及之，即危行。國有道，即順命；無道，即衡命。以此三世顯名於諸侯。

**本卷说明：** 这是长期生涯的概括，并不证明他在三朝始终担任同一官职。正义释危言为谦让不夸功、危行为增修业行，衡命为量其可行而行。三世是三位君主，不是晏氏三代。籍贯与父丧的登场说明另接前556年。

### 2. 晏婴赎出越石父，听其申说以后奉为上客

[返回正文第2条](#sj062-yueshifu-event)

<a id="sj062-cite-014"></a>

**[《史记·管晏列传》P008](../../sources/摘录/史记-卷062-管晏列传.md#p008)**

> 越石父賢，在縲紲中。晏子出，遭之涂，解左驂贖之，載歸。弗謝，入閨。久之，越石父請絕。晏子懼然，攝衣冠謝曰：「嬰雖不仁，免子於緦何子求絕之速也？」石父曰：「不然。吾聞君子詘於不知己而信於知己者。方吾在縲紲中，彼不知我也。夫子既已感寤而贖我，是知己；知己而無禮，固不如在縲紲之中。」晏子於是延入為上客。

**本卷说明：** 主TXT“免子於緦何”疑有讹脱，注本p7作“免子於厄，何”；白话明示据后者读，不回写底本。正义所引《晏子春秋》另写贫而为人臣仆、负薪遇救，与篇本拘系不同，不把它们硬接成有判决日期的一次入狱、服刑、获释。事件无确年。

<a id="sj062-charioteer-note"></a>

### 3. 御者接受妻子的规劝，晏婴随后因其改变而荐为大夫

[返回正文第3条](#sj062-charioteer-event)

<a id="sj062-cite-015"></a>

**[《史记·管晏列传》P009](../../sources/摘录/史记-卷062-管晏列传.md#p009)**

> 晏子為齊相，出，其御之妻從門閒而闚其夫。其夫為相御，擁大蓋，策駟馬，意氣揚揚甚自得也。既而歸，其妻請去。夫問其故。妻曰：「晏子長不滿六尺，身相齊國，名顯諸侯。今者妾觀其出，志念深矣，常有以自下者。今子長八尺，乃為人仆御，然子之意自以為足，妾是以求去也。」其後夫自抑損。晏子怪而問之，御以實對。晏子薦以為大夫。

**本卷说明：** 故事没有留下姓名和受荐日期，也没有交代妻子最终是否离去。六尺与八尺为原叙身量对照，不套现代尺制换算。只说晏子荐为大夫，不无据扩写国君诏命、具体官名和俸禄。

### 4. 景公时期｜晏婴荐穰苴，穰苴请宠臣监军

[返回正文第4条](#sj064-recommend-event)

<a id="sj064-cite-001"></a>

**[《史记·司马穰苴列传》P001](../../sources/摘录/史记-卷064-司马穰苴列传.md#p001)**

> 司馬穰苴者，田完之苗裔也。齊景公時，晉伐阿、甄，而燕侵河上，齊師敗績。景公患之。晏嬰乃薦田穰苴曰：「穰苴雖田氏庶孽，然其人文能附眾，武能威敵，願君試之。」景公召穰苴，與語兵事，大說之，以為將軍，將兵捍燕晉之師。穰苴曰：「臣素卑賤，君擢之閭伍之中，加之大夫之上，士卒未附，百姓不信，人微權輕，願得君之寵臣，國之所尊，以監軍，乃可。」於是景公許之，使莊賈往。穰苴既辭，與莊賈約曰：「旦日日中會於軍門。」

**本卷说明：** 本篇把故事放在景公时期，《晏子春秋》也有景公夜访穰苴的传述；四库考证转引苏辙、叶适却据战事不见《左氏》及《战国策》湣王杀穰苴提出质疑。保留篇传范围，不声称已解决人物时代，也不采用网上前531或二手所引约前528的细年。田氏庶孽表示支庶身份，不由此补母亲或具体世系。

**本卷说明：** 所在段在齐湣王失政、燕伐齐的论述中。与景公故事时代有别，不能仅凭同名决定二者如何合一。

### 5. 庄贾为送行宴饮迟到，穰苴依军法将他处死

[返回正文第5条](#sj064-zhuangjia-event)

<a id="sj064-cite-003"></a>

**[《史记·司马穰苴列传》P001](../../sources/摘录/史记-卷064-司马穰苴列传.md#p001)**

> 穰苴先馳至軍，立表下漏待賈。賈素驕貴，以為將己之軍而己為監，不甚急；親戚左右送之，留飲。日中而賈不至。穰苴則仆表決漏，入，行軍勒兵，申明約束。約束既定，夕時，莊賈乃至。穰苴曰：「何後期為？」賈謝曰：「不佞大夫親戚送之，故留。」穰苴曰：「將受命之日則忘其家，臨軍約束則忘其親，援枹鼓之急則忘其身。今敵國深侵，邦內騷動，士卒暴露於境，君寢不安席，食不甘味，百姓之命皆懸於君，何謂相送乎！」召軍正問曰：「軍法期而後至者云何？」對曰：「當斬。」莊賈懼，使人馳報景公，請救。既往，未及反，於是遂斬莊賈以徇三軍。三軍之士皆振慄。

**本卷说明：** 君寢不安的君指国君，百姓之命皆悬于君的后一个君是对庄贾的称呼。日中到夕只是一日，后文三日属于慰抚与整兵阶段，不错接为等待庄贾三天。

### 6. 君使驰车入军，穰苴以军中约束回应赦令

[返回正文第6条](#sj064-messenger-event)

<a id="sj064-cite-004"></a>

**[《史记·司马穰苴列传》P001](../../sources/摘录/史记-卷064-司马穰苴列传.md#p001)**

> 久之，景公遣使者持節赦賈，馳入軍中。穰苴曰：「將在軍，君令有所不受。」問軍正曰：「馳三軍法何？」正曰：「當斬。」使者大懼。穰苴曰：「君之使不可殺之。」乃斬其僕，車之左駙，馬之左驂，以徇三軍。遣使者還報，然後行。

**本卷说明：** 主TXT断为乃斩其仆，车之左驸，马之左骖，可读杀御者；三家注本连作仆车，索隐明释使者仆车之左驸、马左骖，没有另杀御者。白话两说并列，正文仅取共同可读的车木、左骖处分。赦使来时庄贾已死，不改成使者救到庄贾。

<!-- /sj064-cite-004 -->

<a id="sj064-cite-005"></a>

**[三家注本“仆车”及索隐释义](../../sources/史记三家注/卷064.md#p0)**

> 乃斬其僕車之左駙，馬之左驂，以徇三軍。〔索隱〕謂斬其使者僕車之左駙，又斬其馬之左驂，以御者在左故也。〔正義〕軵音附。劉伯莊云：「駙者，箱外之立木，承重校者。」徇，行示也。

<a id="sj064-army-note"></a>

### 7. 穰苴抚恤士卒、退敌收地，归国后受任大司马

[返回正文第7条](#sj064-army-event)

<a id="sj064-cite-006"></a>

**[《史记·司马穰苴列传》P001](../../sources/摘录/史记-卷064-司马穰苴列传.md#p001)**

> 士卒次舍井灶飲食問疾醫藥，身自拊循之。悉取將軍之資糧享士卒，身與士卒平分糧食。最比其羸弱者，三日而後勒兵。病者皆求行，爭奮出為之赴戰。晉師聞之，為罷去。燕師聞之，度水而解。於是追擊之，遂取所亡封內故境而引兵歸。未至國，釋兵旅，解約束，誓盟而後入邑。景公與諸大夫郊迎，勞師成禮，然後反歸寢。既見穰苴，尊為大司馬。田氏日以益尊於齊。

**本卷说明：** 原叙先敌军闻而退，再追击，不能改成已交战大胜才退。正义记比作卑及音读；白话将最比其羸弱者理解为以羸弱士卒的供给标准自处。收地范围不画现代边界。释兵旅与解约束是返国过程，不扩大成罢将。

<a id="sj064-dismissed-note"></a>

### 8. 穰苴遭大夫进谗，被罢退后病死

[返回正文第8条](#sj064-dismissed-event)

<a id="sj064-cite-007"></a>

**[《史记·司马穰苴列传》P002](../../sources/摘录/史记-卷064-司马穰苴列传.md#p002)**

> 已而大夫鮑氏、高、國之屬害之，譖於景公。景公退穰苴，苴發疾而死。田乞、田豹之徒由此怨高、國等。

**本卷说明：** 本传只说发疾而死，不改成景公直接处斩；后世考证转述谮而杀之是另一说法。无独立确年，不按晏婴卒年或景公某年强定。田氏诸支不一律当作穰苴直系后人。

### 司马迁的书目说明、褒贬与唐代述赞

以下只说明作者为什么选择轶事、怎样评价管晏，以及唐代读者怎样追赞，不为这些评议编造具体写作年。司马迁对晏子哭庄公的完整评论，随[前548年第4注](bce-0548.md#note-4)读。

<a id="sj062-cite-018"></a>

**[《史记·管晏列传》P010](../../sources/摘录/史记-卷062-管晏列传.md#p010)**

> 太史公曰：吾讀管氏牧民、山高、乘馬、輕重、九府，及晏子春秋，詳哉其言之也。既見其著書，欲觀其行事，故次其傳。至其書，世多有之，是以不論，論其軼事。

**本卷说明：** 太史公说：我读管氏《牧民》《山高》《乘马》《轻重》《九府》，以及《晏子春秋》，其中说得很详尽。读过这些著述之后，又想看他们的行事，所以编次这篇传记。至于这些书，世间流传得多，因此这里不再论述，转而叙他们的轶事。集解引刘向《别录》说《山高》又名《形势》、《九府》书民间已没有，是另一时代的书目情况；不能据此断言司马迁不曾读过，也不能把本段称书直接当成现存《管子》《晏子春秋》全部出自两人亲笔的证明。

<!-- /sj062-cite-018 -->

<a id="sj062-cite-019"></a>

**[《史记·管晏列传》P011](../../sources/摘录/史记-卷062-管晏列传.md#p011)**

> 管仲世所謂賢臣，然孔子小之。豈以為周道衰微，桓公既賢，而不勉之至王，乃稱霸哉？語曰「將順其美，匡救其惡，故上下能相親也」。豈管仲之謂乎？

**本卷说明：** 管仲是世人所称的贤臣，孔子却说他器量小。难道是因为周道衰微、齐桓公又有才能，管仲没有劝勉他达到王道之治，却只成就霸业吗？古语说，顺势帮助成就其美好之处，纠正挽救其过失，上下才能相亲，这大概就是在说管仲吧？这是司马迁用反问所作的解释和赞许，不把他的推测改成孔子已经亲口说明的唯一理由，也不将至王直接译成已提出推翻周王、自立天子的行动计划。

<!-- /sj062-cite-019 -->

<a id="sj062-cite-020"></a>

**[《史记·管晏列传》Z001](../../sources/摘录/史记-卷062-管晏列传.md#z001)**

> 索隱述贊曰：夷吾成霸，平仲稱賢。粟乃實廩，豆不掩肩。轉禍爲福，危言獲全。孔賴左衽，史忻執鞭。成禮而去，人望存焉。

**本卷说明：** 司马贞的述赞说，夷吾成就霸业，平仲以贤德著称；管仲使仓廪充实，晏子则以祭享俭薄为喻受赞。“豆不掩肩”按承用晏子祭礼典故暂释；[《礼记·礼器》《杂记下》](../../sources/补充古籍/阅读本/礼记-管晏礼制对读.md#liqi)原作“豚肩不揜豆”，赞语的豆、肩次序反转，不据其字面强说器物尺寸，更不写成确定的日常食谱。管仲能够转祸为福，晏子以正直谨慎的言行得以保全。孔子称许管仲使诸夏免于披发左衽，史家向往替晏子执鞭；晏子哭君成礼而去，民望仍在。此为唐人对全篇的追赞，不能当作司马迁自己的赞辞。

### 注本中的墓地异说

这一整段是后出集解、正义对墓址的讨论，主TXT未收；地名不相合，不据现代附会择一强定。

<a id="sj062-cite-021"></a>

**[《史记·管晏列传》N001](../../sources/摘录/史记-卷062-管晏列传.md#n001)**

> 〔集解〕皇覽曰：「晏子冢在臨菑城南淄水南桓公冢西北。」〔正義〕注皇覽云：「晏子冢在臨淄城南菑水南桓公冢西北。」括地志云：「齊桓公墓在青州臨淄縣東南二十三里鼎足上。」又云：「齊晏嬰冢在齊子城北門外。晏子云『吾生近市，死豈易吾志』。乃葬故宅後，人名曰清節里。」按：恐皇覽誤，乃管仲冢也。

**本卷说明：** 集解引《皇览》说，晏子墓在临淄城南、淄水南、齐桓公墓的西北。正义先重引这一说，再引《括地志》所记齐桓公墓在临淄东南鼎足上、晏婴墓在齐子城北门外；并引晏子生前近市、死不改志而葬故宅后的传说，称其地为清节里。正义怀疑《皇览》所指其实是管仲墓。古注既有相互冲突的定位，本轮逐说保留，不据其中之一确定晏婴的现代墓址，更不由墓地说明补出卒年。

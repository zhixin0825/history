# 公元前604年（鲁宣公五年）

[← 上一张已编年页：公元前605年](bce-0605.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前603年 →](bce-0603.md)

<a id="event-1"></a>

1. **春，鲁宣公前往齐国，高固借机请求娶叔姬；夏天宣公返回鲁国。** [1]

<a id="event-2"></a>

2. **秋九月，齐高固亲自到鲁国迎娶叔姬。** 由卿本人亲自迎亲，成为这一婚姻的显著礼仪特征。[2]

<a id="event-3"></a>

3. **叔孙得臣去世。** 鲁国又失去一位长期参与军政的卿大夫。[3]

<a id="event-4"></a>

4. **冬，高固与叔姬一同回鲁，完成婚后回礼。** [4]

<a id="event-5"></a>

5. **楚庄王再次伐郑；陈国随后与楚讲和。** 晋荀林父则出兵救郑并进攻陈国。[5]

## 本年相关史料

1. **《春秋·宣公五年》**：“五年春，公如齐。夏，公至自齐。”  
   **《左传·宣公五年》**详记高固请叔姬。

<a id="note-2"></a>

2. **《春秋·宣公五年》**：“秋九月，齐高固来逆叔姬。”  
   **《左传·宣公五年》**：“卿自逆也。”

<a id="note-3"></a>

3. **《春秋·宣公五年》**：“叔孙得臣卒。”

<a id="note-4"></a>

4. **《春秋·宣公五年》**：“冬，齐高固及子叔姬来。”  
   **《左传·宣公五年》**：“反马也。”

<a id="note-5"></a>

5. **《春秋·宣公五年》**：“楚人伐郑。”  
   **《左传·宣公五年》**：“陈及楚平。晋荀林父救郑伐陈。”

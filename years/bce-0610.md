# 公元前610年（鲁文公十七年）

[← 上一张已编年页：公元前611年](bce-0611.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前609年 →](bce-0609.md)

<a id="event-1"></a>

1. **春，晋、卫、陈、郑联合伐宋，追究宋昭公被弑。** 诸侯最终仍承认宋文公，没有另立新君。[1]

<a id="event-2"></a>

2. **夏四月，鲁国安葬声姜。** 因齐国威胁，葬礼有所拖延。[2]

<a id="event-3"></a>

3. **齐国再次进攻鲁国边境，襄仲请求讲和；六月，鲁文公与齐懿公在穀地结盟。** 秋天，文公从穀地返回鲁国。[3]

<a id="event-4"></a>

4. **晋国在黄父大阅后召集诸侯于扈，调停宋国内乱。** 鲁文公因齐国威胁没有赴会。[4]

<a id="event-5"></a>

5. **晋国怀疑郑国两面亲楚，不肯接见郑伯。** 郑大夫子家写长信申辩，强调郑国处在晋楚之间只能服从强者，晋国最终派巩朔与郑讲和。[5]

<a id="event-6"></a>

6. **郑国以太子夷、石楚到晋国做人质。** 郑晋关系暂时稳定。[6]

<a id="event-7"></a>

7. **秋，周大夫甘歜趁戎人饮酒时击败戎军。** [7]

<a id="event-8"></a>

8. **冬，公子遂前往齐国，拜谢穀地盟约。** 他观察齐懿公言语轻薄，预言齐君将不得善终。[8]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·文公十七年》**：“十有七年春，晋人、卫人、陈人、郑人伐宋。”  
   **《左传·文公十七年》**详记讨弑君而仍立文公。

<a id="note-2"></a>

2. **《春秋·文公十七年》**：“夏四月癸亥，葬我小君声姜。”

<a id="note-3"></a>

3. **《春秋·文公十七年》**：“齐侯伐我西鄙。六月癸未，公及齐侯盟于穀。”又记：“秋，公至自穀。”  
   **《左传·文公十七年》**作“齐侯伐我北鄙”。

   **说明：** 经文作“西鄙”，传文作“北鄙”，地点方向有明显差异；正文只写“边境”，不强行选定。

<a id="note-4"></a>

4. **《春秋·文公十七年》**：“诸侯会于扈。”  
   **《左传·文公十七年》**：“平宋也。公不与会，齐难故也。”

<a id="note-5"></a>

5. **《左传·文公十七年》**详记郑子家致赵宣子长书、晋巩朔与郑成。

<a id="note-6"></a>

6. **《左传·文公十七年》**：“冬十月，郑大子夷、石楚为质于晋。”

<a id="note-7"></a>

7. **《左传·文公十七年》**：“秋，周甘歜败戎于邥垂，乘其饮酒也。”

<a id="note-8"></a>

8. **《春秋·文公十七年》**：“冬，公子遂如齐。”  
   **《左传·文公十七年》**详记襄仲拜穀盟及预言齐君。

# 公元前621年（鲁文公六年）

[← 上一张已编年页：公元前622年](bce-0622.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前620年 →](bce-0620.md)

<a id="event-1"></a>

1. **春，鲁国安葬许僖公。** [1]

<a id="event-2"></a>

2. **晋国重新整编军队，赵盾被提拔为中军佐并开始主持国政。** 他制定法令、整顿刑狱、官职和逃亡人口，晋国权力逐渐集中到赵氏。[2]

<a id="event-3"></a>

3. **夏，季孙行父前往陈国聘问并娶妻；秋又出使晋国。** 鲁国同时经营陈、晋关系。[3]

<a id="event-4"></a>

4. **秦穆公去世，并以子车氏三名贤臣奄息、仲行、鍼虎殉葬。** 秦人深感悲痛，作《黄鸟》哀悼；这一做法严重损耗秦国人才。[4]

<a id="event-5"></a>

5. **八月，晋襄公去世。** 因太子夷皋年幼，晋国大夫一度想另立年长公子。[5]

<a id="event-6"></a>

6. **赵盾主张从秦迎回公子雍，贾季则主张从陈迎公子乐。** 赵盾派先蔑、士会赴秦，贾季派人召公子乐；赵盾又在途中杀掉公子乐。[6]

<a id="event-7"></a>

7. **穆嬴抱着太子夷皋在朝廷哭诉，迫使赵盾和群臣改变主意，最终仍立夷皋为晋灵公。** 晋国因此背弃迎公子雍的计划。[7]

<a id="event-8"></a>

8. **贾季因怨阳处父改变自己军中班次，派续鞫居杀死阳处父；晋国随后诛续鞫居，贾季逃往狄地。** 晋国内部权力斗争加剧。[8]

<a id="event-9"></a>

9. **冬，公子遂到晋国参加晋襄公葬礼。** [9]

<a id="event-10"></a>

10. **闰月，鲁国没有正式告朔，却仍到宗庙朝拜。** 被认为是放弃闰月政令程序。[10]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·文公六年》**：“六年春，葬许僖公。”

<a id="note-2"></a>

2. **《左传·文公六年》**详记晋蒐于夷、董，赵盾升中军佐并“始为国政”。

<a id="note-3"></a>

3. **《春秋·文公六年》**：“夏，季孙行父如陈。秋，季孙行父如晋。”  
   **《左传·文公六年》**详记季文子聘陈且娶。

<a id="note-4"></a>

4. **《左传·文公六年》**详记秦穆公卒，以奄息、仲行、鍼虎殉葬。

<a id="note-5"></a>

5. **《春秋·文公六年》**：“八月乙亥，晋侯驩卒。”

<a id="note-6"></a>

6. **《左传·文公六年》**详记赵盾主张立公子雍、贾季主张立公子乐。

<a id="note-7"></a>

7. **《左传·文公六年》**详记穆嬴抱太子哭于朝、赵盾改立晋灵公。

<a id="note-8"></a>

8. **《春秋·文公六年》**：“晋杀其大夫阳处父。晋狐射姑出奔狄。”  
   **《左传·文公六年》**详记贾季使续鞫居杀阳处父、贾季奔狄。

<a id="note-9"></a>

9. **《春秋·文公六年》**：“冬十月，公子遂如晋，葬晋襄公。”

<a id="note-10"></a>

10. **《春秋·文公六年》**：“闰月，不告月，犹朝于庙。”  
    **《左传·文公六年》**批评“不告闰朔”。

# 公元前645年（鲁僖公十五年）

[← 上一张已编年页：公元前646年](bce-0646.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前644年 →](bce-0644.md)

<a id="event-1"></a>

1. **春，鲁僖公前往齐国。** 齐桓公仍维持诸侯霸主地位。[1]

<a id="event-2"></a>

2. **楚国进攻徐国，齐桓公召集鲁、宋、陈、卫、郑、许、曹在牡丘会盟，并派诸侯军救徐。** 联军驻匡等待救援行动。[2]

<a id="event-3"></a>

3. **夏五月，发生日食；秋又发生螽灾。** 鲁国同年记录了两项灾异。[3]

<a id="event-4"></a>

4. **齐、曹联军攻厉国，以牵制楚军、救援徐国；但冬天楚军仍在娄林击败徐军。** 齐楚争夺淮泗地区的局势继续恶化。[4]

<a id="event-5"></a>

5. **晋惠公长期不履行当年向秦许诺的土地和赏赐，又在晋饥时受秦粮、秦饥时反拒绝卖粮，秦穆公终于出兵伐晋。** 秦晋关系从恩惠与婚姻彻底转向战争。[5]

<a id="event-6"></a>

6. **十一月，秦晋在韩原决战，晋惠公不听庆郑等人劝告，最终兵败被俘。** 晋军虽兵多，秦军士气更盛；惠公战车陷泥后被秦军擒获。[6]

<a id="event-7"></a>

7. **晋惠公之姊秦穆姬以自焚相威胁，请秦穆公不要杀晋侯。** 秦国最终决定释放晋惠公，并与晋国重新议和。[7]

<a id="event-8"></a>

8. **十一月，晋惠公回国，入城前处死庆郑。** 同年晋国再饥，秦穆公仍继续赠粮，并开始实际控制晋河东部分地区。[8]

<a id="event-9"></a>

9. **冬，宋国攻曹；楚军在娄林击败徐军。** 中原与南方战线同时持续。[9]

<a id="event-10"></a>

10. **九月，鲁僖公从诸侯会盟返回；季姬正式回到鄫国。同月月末，雷电击中夷伯庙。** [10]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公十五年》**：“十有五年春，王正月，公如齐。”

<a id="note-2"></a>

2. **《春秋·僖公十五年》**：“楚人伐徐。三月，公会齐侯、宋公、陈侯、卫侯、郑伯、许男、曹伯，盟于牡丘，遂次于匡。公孙敖帅师及诸侯之大夫救徐。”

<a id="note-3"></a>

3. **《春秋·僖公十五年》**：“夏五月，日有食之……八月，螽。”

<a id="note-4"></a>

4. **《春秋·僖公十五年》**：“秋七月，齐师、曹师伐厉……楚人败徐于娄林。”  
   **《左传·僖公十五年》**说明伐厉“以救徐也”。

<a id="note-5"></a>

5. **《左传·僖公十五年》**详叙晋惠公对秦失信、秦晋粮食往来与秦伯伐晋原因。

<a id="note-6"></a>

6. **《春秋·僖公十五年》**：“十有一月壬戌，晋侯及秦伯战于韩。获晋侯。”  
   **《左传·僖公十五年》**详记韩原之战全过程。

<a id="note-7"></a>

7. **《左传·僖公十五年》**详记穆姬登台履薪、秦伯决定不杀晋侯并许晋平。

<a id="note-8"></a>

8. **《左传·僖公十五年》**：“十一月晋侯归。丁丑，杀庆郑而后入……是岁，晋又饥，秦伯又饩之粟。”

<a id="note-9"></a>

9. **《春秋·僖公十五年》**：“冬，宋人伐曹。楚人败徐于娄林。”

<a id="note-10"></a>

10. **《春秋·僖公十五年》**：“九月，公至自会。季姬归于鄫。己卯晦，震夷伯之庙。”

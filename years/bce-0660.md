# 公元前660年（鲁闵公二年）

[← 上一张已编年页：公元前661年](bce-0661.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前659年 →](bce-0659.md)

<a id="event-1"></a>

1. **春，齐国迁移阳地居民。** 齐国继续整顿其控制区域。[1]

<a id="event-2"></a>

2. **五月，鲁国过早为庄公举行吉禘。** 庄公丧期尚近，这次宗庙祭祀被认为举行得太快。[2]

<a id="event-3"></a>

3. **秋八月，庆父利用闵公旧傅卜齮的私怨，指使卜齮在武闱杀死闵公。** 鲁国再次发生弑君；庄公死后不到两年，子般、闵公先后被庆父集团杀害。[3]

<a id="event-4"></a>

4. **季友带着公子申逃往邾国，随后在齐国支持下回鲁，拥立公子申为鲁僖公。** 鲁国政治中心从庆父一派转向季友。[4]

<a id="event-5"></a>

5. **庆父逃往莒国，鲁国用财物向莒国索要；被送回途中，庆父自缢。** 鲁国连续内乱的核心人物由此退出政治舞台。[5]

<a id="event-6"></a>

6. **哀姜因与庆父私通并参与闵公之死，逃往邾国；齐国后来把她抓回，在夷地杀死。** 僖公后来请求把她遗体送回鲁国安葬。[6]

<a id="event-7"></a>

7. **冬十二月，狄人攻破卫国。** 卫懿公好鹤，国内军心涣散；卫军在荧泽大败，卫国都城失守，遗民连夜渡河逃亡。[7]

<a id="event-8"></a>

8. **宋桓公迎接卫国遗民，齐桓公又派兵车与物资帮助卫人立戴公于曹。** 卫国虽亡国破都，却在诸侯援助下迅速重建政权。[8]

<a id="event-9"></a>

9. **郑国故意让高克长期率军驻黄河边又不召回，最终军队自行溃散，高克逃往陈国。** 郑人后来以《清人》讽刺这段军政失序。[9]

<a id="event-10"></a>

10. **晋献公又派太子申生出兵东山皋落氏。** 大夫里克等认为太子不应长期独立统兵，申生身边多人都看出这次任命暗含疏远与废立风险，但申生仍选择服从出征。[10]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·闵公二年》**：“二年春，王正月，齐人迁阳。”

<a id="note-2"></a>

2. **《春秋·闵公二年》**：“夏五月乙酉，吉禘于庄公。”  
   **《左传·闵公二年》**：“吉禘于庄公，速也。”

<a id="note-3"></a>

3. **《春秋·闵公二年》**：“秋八月辛丑，公薨。”  
   **《左传·闵公二年》**：“共仲使卜齮贼公于武闱。”

<a id="note-4"></a>

4. **《左传·闵公二年》**详记成季以僖公适邾，后“入，立之”；并解释僖公为叔姜之子。

<a id="note-5"></a>

5. **《春秋·闵公二年》**：“公子庆父出奔莒。”  
   **《左传·闵公二年》**详记鲁以赂求庆父于莒，庆父归途中自缢。

<a id="note-6"></a>

6. **《春秋·闵公二年》**：“九月，夫人姜氏孙于邾。”  
   **《左传·闵公二年》**详记哀姜与庆父私通、参与闵公之死，齐人后来杀哀姜于夷。

<a id="note-7"></a>

7. **《春秋·闵公二年》**：“十有二月狄入卫。”  
   **《左传·闵公二年》**详记卫懿公好鹤、荧泽战败、狄入卫。

<a id="note-8"></a>

8. **《左传·闵公二年》**详记宋桓公迎卫遗民，立戴公于曹；齐桓公遣公子无亏率军戍曹并大量援助。

<a id="note-9"></a>

9. **《春秋·闵公二年》**：“郑弃其师。”  
   **《左传·闵公二年》**详记郑人恶高克，久使其次河上不召，师溃，高克奔陈。

<a id="note-10"></a>

10. **《左传·闵公二年》**详记晋献公使太子申生伐东山皋落氏，里克、狐突等反复劝谏。

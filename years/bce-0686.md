# 公元前686年（鲁庄公八年）

[← 上一张已编年页：公元前687年](bce-0687.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前685年 →](bce-0685.md)

<a id="event-1"></a>

1. **春，鲁军驻郎地等待陈、蔡军队，并举行军事整训。** 甲午日，鲁国在宗庙举行治兵仪式。[1]

<a id="event-2"></a>

2. **夏，鲁军与齐军共同包围郕国，郕国却只向齐军投降。** 庆父一度主张因此攻击齐军，庄公认为问题在鲁国自身，没有迁怒齐国，最终收兵回国。[2]

<a id="event-3"></a>

3. **齐襄公长期任性用人，国内不满逐渐集中到连称、管至父和公孙无知。** 连称、管至父被派守葵丘，约定瓜熟时换防，却迟迟没人替代，于是开始谋反。[3]

<a id="event-4"></a>

4. **冬，齐襄公出猎时受伤，叛党乘机入宫杀死齐襄公，拥立公孙无知。** 宫中护卫多人战死，齐国进入严重内乱。[4]

<a id="event-5"></a>

5. **齐乱发生前，鲍叔牙已经护送公子小白逃往莒国；管仲、召忽则护送公子纠来到鲁国。** 两位齐国公子分别依靠莒、鲁，下一年将争夺齐国君位。[5]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公八年》**：“八年春，王正月，师次于郎，以俟陈人、蔡人。甲午，治兵。”  
   **《左传·庄公八年》**：“治兵于庙，礼也。”

<a id="note-2"></a>

2. **《春秋·庄公八年》**：“夏，师及齐师围郕，郕降于齐师。秋，师还。”  
   **《左传·庄公八年》**详记庆父请伐齐师而庄公拒绝。

<a id="note-3"></a>

3. **《左传·庄公八年》**详记连称、管至父戍葵丘，“瓜时而往，曰：‘及瓜而代。’”后因不获替代而谋乱。

<a id="note-4"></a>

4. **《春秋·庄公八年》**：“冬十有一月癸未，齐无知弑其君诸儿。”  
   **《左传·庄公八年》**详记齐襄公出猎、受伤及宫中弑杀过程。

   **说明：** 经文系于十一月癸未，传文叙事中作“冬十二月”；本页正文不强行换算月次，只保留“冬”。

<a id="note-5"></a>

5. **《左传·庄公八年》**：“鲍叔牙……奉公子小白出奔莒。乱作，管夷吾、召忽奉公子纠来奔。”

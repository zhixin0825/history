# 公元前697年（鲁桓公十五年）

[← 上一张已编年页：公元前698年](bce-0698.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前696年 →](bce-0696.md)

<a id="event-1"></a>

1. **春二月，周王派家父来鲁国索要车辆。** 这被认为超出正常贡赋范围，因为诸侯本不需要向天子贡献车服，天子也不应私下索财。[1]

<a id="event-2"></a>

2. **三月乙未，周桓王去世。** 周王室再次进入君位更替。[2]

<a id="event-3"></a>

3. **夏四月，齐僖公下葬。** 齐国完成上一年国君去世后的葬礼。[3]

<a id="event-4"></a>

4. **郑厉公不满祭仲专权，密谋让祭仲的女婿雍纠杀掉祭仲；雍纠的妻子雍姬却把计划告诉父亲。** 祭仲抢先杀死雍纠，把尸体陈在周氏之汪。厉公看到计划失败，只能出逃，并责怪雍纠“谋及妇人”。[4]

<a id="event-5"></a>

5. **五月，郑厉公出奔蔡国，郑昭公忽重新回国即位。** 郑国第一次被宋国强行推动的君位更替被推翻，昭公恢复君位。[5]

<a id="event-6"></a>

6. **同年，许叔重新进入许国；鲁桓公与齐侯在艾地会面，商议稳定许国局势。** 许国在多年被郑控制后开始恢复自身政权。[6]

<a id="event-7"></a>

7. **秋，郑厉公借栎人之手杀死当地守将檀伯，进入栎地长期据守。** 他虽然失去郑都，却没有退出争位，而是在栎建立另一个权力中心。[7]

<a id="event-8"></a>

8. **冬，鲁、宋、卫、陈在袲地会合并进攻郑国，想把郑厉公重新送回君位，但没有成功。** 郑国内战由国内权臣冲突扩大为诸侯干预。[8]

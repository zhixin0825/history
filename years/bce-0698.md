# 公元前698年（鲁桓公十四年）

[← 上一张已编年页：公元前699年](bce-0699.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前697年 →](bce-0697.md)

<a id="event-1"></a>

1. **春，鲁桓公与郑厉公在曹地会面，曹国按礼供应食物。** 鲁郑继续维持上一年共同作战后形成的合作关系。[1]

<a id="event-2"></a>

2. **这一年冬季没有结冰。** 这种异常气候被单独记录。[2]

<a id="event-3"></a>

3. **夏，郑厉公派弟弟语到鲁国重申盟约，并延续曹地会面的成果。** 鲁郑关系继续保持稳定。[3]

<a id="event-4"></a>

4. **秋八月，鲁国御廪发生火灾，三天后仍照常举行尝祭。** 火灾没有被认为严重到需要中止祭祀。[4]

<a id="event-5"></a>

5. **冬十二月丁巳，齐僖公去世。** 齐国进入君主更替。[5]

<a id="event-6"></a>

6. **冬，宋国联合齐、蔡、卫、陈大举攻郑，报复上一年的战败。** 联军焚毁郑国渠门，攻入大路，又进攻东郊、夺取牛首，甚至拆下郑国太宫的椽木带回宋国修卢门。[6]

<a id="note-3"></a>

   **《左传·桓公十四年》**：“郑子人来寻盟，且修曹之会。”

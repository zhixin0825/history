# 公元前601年（鲁宣公八年）

[← 上一张已编年页：公元前602年](bce-0602.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前600年 →](../bce-0600-0501/bce-0600.md)

<a id="event-1"></a>

1. **春，鲁宣公从黑壤会盟返回。** [[1]](#note-1)

<a id="event-2"></a>

2. **白狄与晋国讲和；夏天晋军联合白狄伐秦。** 晋军还捕获秦国间谍，在绛市处置；围绕此人的“六日而苏”异闻另见注释。秦晋边境对抗继续。[[2]](#note-2)

[补充史料与年次说明](#sj005-104-note)

<a id="event-3"></a>

3. **六月，公子遂赴齐，走到黄地便返回；辛巳鲁国在太庙祭祀时，公子遂死于垂地。** [[3]](#note-3)

<a id="event-4"></a>

4. **襄仲去世后第二天，鲁国仍继续绎祭，只撤去籥乐而保留万舞。** 这种处理被认为不合礼。[[4]](#note-4)

<a id="event-5"></a>

5. **戊子，敬嬴去世。** 宣公失去母亲和最重要的政治支持者之一。[[5]](#note-5)

<a id="event-6"></a>

6. **楚国因众舒反叛出兵，攻灭舒蓼，再划定新取得地区的疆界。** 楚军进至滑汭，与吴、越盟誓后返回，继续经营东面诸方关系。[[6]](#note-6)

<a id="event-7"></a>

7. **秋七月甲子，发生日全食。** [[7]](#note-7)

<a id="event-8"></a>

8. **冬十月己丑，鲁国原定安葬敬嬴，因雨未能举行；到次日庚寅日中才完成。** 当年因旱缺麻，葬礼开始改用葛制的引柩绳。[[8]](#note-8)

<a id="event-9"></a>

9. **鲁国修筑平阳。** [[9]](#note-9)

<a id="event-10"></a>

10. **陈国与晋讲和后，楚军出兵伐陈，取得和议而还。** [[10]](#note-10)

<a id="event-11"></a>

11. **晋国以郤缺执政，秋季免去胥克，命赵朔佐下军。** 原文先记胥克有疾、郤缺执政，秋季再记免职和赵朔的新军职。疾病只按古书用语记录，不作诊断。 [看原文与说明](#cq-source-52)

<a id="sj014-0601-yan"></a>

12. **燕国开始以宣公元年纪事。** 在位十六年的桓公之后，燕国由宣公接掌；目前所读材料没有给出新君的个人名字及确切即位日。[原文与说明](#sj014-0601-yan-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·宣公八年》**：“八年春，公至自会。”

<a id="note-2"></a>

2. **《春秋·宣公八年》**：“晋师、白狄伐秦。”传文先记春季白狄与晋平，后写夏季会晋伐秦。[卷014晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0601)却作“与鲁伐秦”。正文沿经文明确列名采用晋、白狄，原表“鲁”字留存为参战者异文；不另加一支没有其他依据的鲁军，也不未经校勘直接改原表。

   晋栏及秦栏又互记获秦谍，传文明确“晋人获秦谍，杀诸绛市，六日而苏”。本轮保留捕获、处置的叙事及后附异闻，但不把六日复苏写成已获医学证明的事实，也不猜测行刑方式、间谍姓名和所携情报。[完整经传](https://zh.wikisource.org/wiki/春秋左氏傳/宣公#宣公八年)。

<a id="note-3"></a>

3. **《春秋·宣公八年》**：“夏六月，公子遂如齐，至黄乃复。辛巳，有事于大庙，仲遂卒于垂。”

<a id="note-4"></a>

4. **《春秋·宣公八年》**：“壬午，犹绎。万入去籥。”  
   **《左传·宣公八年》**：“襄仲卒而绎，非礼也。”辛巳、壬午是相接两日，不能将仲遂又看成襄仲以外的另一人。

<a id="note-5"></a>

5. **《春秋·宣公八年》**：“戊子，夫人嬴氏薨。”

<a id="note-6"></a>

6. **《春秋·宣公八年》**作“楚人灭舒蓼”，传文作“楚为众舒叛故，伐舒蓼，灭之”，继写疆及滑汭、盟吴越。[卷014楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0601)也连写舒蓼。**连写本身并不能排除两个国名，必须结合旧注判断。** [《春秋左传正义》卷22](https://zh.wikisource.org/wiki/春秋左傳正義/卷22#宣公八年傳)所收杜注传本文字为“舒、蓼，二国名”，孔疏随即认为“二”属转写之误、应为一国，并举《释例·土地名》的名目为据。本页采用孔疏的一国读法，把正文写作舒蓼；此前把旧页两国读法简单说成误加顿号，理由不足，现明确保留注疏的分歧。

   孔疏又提出此蓼可能与文公五年被灭的蓼相同，曾经复国后再被楚灭。这是一项旧注解释，并非本轮已经独立核定的复国史实；不凭名称相近就改写前622年的“六、蓼”条，也不宣称两者绝无联系。众舒是本次出兵背景，与具体进攻目标分开；吴越盟誓不等于其全部地域已经由楚直接管理。

<a id="note-7"></a>

7. **《春秋·宣公八年》**：“秋七月甲子，日有食之，既。”[卷014鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0601)日食与本条同事，“既”支持全食的文本表述，本轮未独立天文回算日期和可见范围。

<a id="note-8"></a>

8. **《春秋·宣公八年》**：“冬十月己丑，葬我小君敬嬴。雨，不克葬。庚寅，日中而克葬。”明确己丑与庚寅为前后两日，不再让读者以为下雨当天中午即完成。

   传文又记“旱，无麻，始用葛茀”。[杜注与孔疏](https://zh.wikisource.org/wiki/春秋左傳正義/卷22#宣公八年傳)将茀释为引柩、下柩所用之绳，说明与绋、綍的写法相通，因此正文写葛制引柩绳；不是由车蔽的另一字义推成棺罩。缺麻是所记材料问题，不用来推算全国麻产量。

<a id="note-9"></a>

9. **《春秋·宣公八年》**：“城平阳。”

<a id="note-10"></a>

10. **《春秋·宣公八年》**：“楚师伐陈。”  
    **《左传·宣公八年》**：“陈及晋平。楚师伐陈，取成而还。”[卷014楚、陈两栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0601)同事；楚栏同记舒蓼并不说明伐陈与灭舒蓼在同一天。

<a id="sj014-0601-yan-note"></a>
### 燕宣公元年与下一行空格

[卷014本年燕栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0601)明确宣公元年；[《燕召公世家》](https://zh.wikisource.org/wiki/史記/卷034)记桓公十六年卒、宣公立。前617年的桓公元年与该在位数可相接，但原句未明确宣公为桓公之子，本页不补父子关系。

所读公开表在前600年燕栏为空，前599年才写三。本轮保持空格，不靠前后数字自行把缺项补成二，再称原表已经逐字校完。

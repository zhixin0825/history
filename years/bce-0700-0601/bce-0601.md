# 公元前601年（鲁宣公八年）

[← 上一张已编年页：公元前602年](bce-0602.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前600年 →](../bce-0600-0501/bce-0600.md)

<a id="event-1"></a>

1. **春，鲁宣公从黑壤会盟返回。** [[1]](#note-1)

<a id="event-2"></a>

2. **白狄与晋国讲和；夏天晋军联合白狄伐秦。** 秦晋边境对抗继续。[[2]](#note-2)

<a id="event-3"></a>

3. **六月，公子遂赴齐，走到黄地便返回；辛巳鲁国在太庙祭祀时，公子遂死于垂地。** [[3]](#note-3)

<a id="event-4"></a>

4. **襄仲去世后第二天，鲁国仍继续绎祭，只撤去籥乐而保留万舞。** 这种处理被认为不合礼。[[4]](#note-4)

<a id="event-5"></a>

5. **戊子，敬嬴去世。** 宣公失去母亲和最重要的政治支持者之一。[[5]](#note-5)

<a id="event-6"></a>

6. **楚国因舒、蓼等叛乱出兵，将舒、蓼灭掉，并继续经营吴越方向。** [[6]](#note-6)

<a id="event-7"></a>

7. **秋七月甲子，发生日全食。** [[7]](#note-7)

<a id="event-8"></a>

8. **冬，鲁国安葬敬嬴，因下雨一度不能下葬，到日中才完成。** 当年缺麻，葬礼开始使用葛绋。[[8]](#note-8)

<a id="event-9"></a>

9. **鲁国修筑平阳。** [[9]](#note-9)

<a id="event-10"></a>

10. **陈国与晋讲和后，楚军出兵伐陈，取得和议而还。** [[10]](#note-10)

<a id="event-11"></a>

11. **晋国以郤缺执政，秋季免去胥克，命赵朔佐下军。** 原文先记胥克有疾、郤缺执政，秋季再记免职和赵朔的新军职。疾病只按古书用语记录，不作诊断。 [看原文与说明](#cq-source-52)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·宣公八年》**：“八年春，公至自会。”

<a id="note-2"></a>

   **《左传·宣公八年》**详记白狄与晋平、晋伐秦。

<a id="note-3"></a>

3. **《春秋·宣公八年》**：“夏六月，公子遂如齐，至黄乃复。辛巳，有事于大庙，仲遂卒于垂。”

4. **《春秋·宣公八年》**：“壬午，犹绎。《万》入去籥。”  
   **《左传·宣公八年》**：“襄仲卒而绎，非礼也。”

<a id="note-5"></a>

5. **《春秋·宣公八年》**：“戊子，夫人嬴氏薨。”

<a id="note-6"></a>

6. **《春秋·宣公八年》**：“楚人灭舒、蓼。”  
   **《左传·宣公八年》**详记楚灭舒蓼、盟吴越而还。

<a id="note-7"></a>

7. **《春秋·宣公八年》**：“秋七月甲子，日有食之，既。”

<a id="note-8"></a>

8. **《春秋·宣公八年》**：“冬十月己丑，葬我小君敬嬴。雨，不克葬。庚寅，日中而克葬。”  
   **《左传·宣公八年》**详记无麻始用葛绋。

<a id="note-9"></a>

9. **《春秋·宣公八年》**：“城平阳。”

<a id="note-10"></a>

10. **《春秋·宣公八年》**：“楚师伐陈。”  
    **《左传·宣公八年》**：“陈及晋平。楚师伐陈，取成而还。”

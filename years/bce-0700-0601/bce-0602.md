1. **卫与鲁结盟，诸侯会于黑壤。** 春，卫孙良夫赴鲁订盟，鲁卫恢复往来。郑与晋重新讲和。冬，鲁宣公与晋、宋、卫、郑、曹诸侯会于黑壤。 [[1]](#note-1)

<a id="event-2"></a>

<a id="event-4"></a>

<a id="hs-event-8"></a>

2. **鲁宣公会齐伐莱，归国后鲁发生大旱。** 夏，鲁宣公会齐侯伐莱，秋自战事归国。鲁国又在秋季遭遇大旱。 [[2]](#note-2)

<a id="event-3"></a>

3. **赤狄侵晋，夺取向阴一带禾稼。** [[3]](#note-3)

<a id="sj034-huangong-death-event"></a>

4. **燕桓公去世，宣公继承。** 桓公在位十六年，宣公的元年接在下一年。 [[4]](#sj034-huangong-death-note)

# 公元前602年（鲁宣公七年）

[← 上一张已编年页：公元前603年](bce-0603.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前601年 →](bce-0601.md)

<a id="event-1"></a>

1. **春，卫国孙良夫来鲁结盟，鲁卫开始恢复正式往来，并准备共同参与晋国会盟。** [[1]](#note-1)

<a id="event-2"></a>

2. **夏，鲁宣公会齐侯伐莱。** 鲁国并非预先参与谋划，而是在行动中会合齐军。[[2]](#note-2)

<a id="event-3"></a>

3. **赤狄侵晋，夺取向阴一带禾稼。** [[3]](#note-3)

<a id="event-4"></a>

4. **秋，宣公从伐莱战事返回；鲁国随后发生大旱。** [[4]](#note-4)

<a id="event-5"></a>

5. **郑国重新与晋讲和，并参加冬季晋国主导的黑壤会盟。** [[5]](#note-5)

<a id="event-6"></a>

6. **冬，鲁宣公会晋、宋、卫、郑、曹等于黑壤。** 晋成公因宣公即位后长期不朝不聘，扣留宣公；鲁国以贿赂脱身，而且没有参加最后盟誓。[[6]](#note-6)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·宣公七年》**：“七年春，卫侯使孙良夫来盟。”  
   **《左传·宣公七年》**：“始通，且谋会晋也。”

<a id="note-2"></a>

2. **《春秋·宣公七年》**：“夏，公会齐侯伐莱。”  
   **《左传·宣公七年》**：“不与谋也。”

<a id="note-3"></a>

3. **《左传·宣公七年》**：“赤狄侵晋，取向阴之禾。”

<a id="note-4"></a>

4. **《春秋·宣公七年》**：“秋，公至自伐莱。大旱。”

<a id="note-5"></a>

5. **《左传·宣公七年》**：“郑及晋平……故相郑伯以会。”

<a id="note-6"></a>

6. **《春秋·宣公七年》**：“冬，公会晋侯、宋公、卫侯、郑伯、曹伯于黑壤。”  
   **《左传·宣公七年》**详记晋止宣公、盟于黄父，宣公以赂免而未盟。

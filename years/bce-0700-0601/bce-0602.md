# 公元前602年（鲁宣公七年）

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，卫国孙良夫来鲁结盟，鲁卫开始恢复正式往来，并准备共同参与晋国会盟。** [[1]](#note-1)

<a id="event-2"></a>

2. **夏，鲁宣公会齐侯伐莱。** 鲁国并非预先参与谋划，而是在行动中会合齐军。 [[2]](#note-2)

<a id="event-3"></a>

3. **赤狄侵晋，夺取向阴一带禾稼。** [[3]](#note-3)

<a id="event-4"></a>

4. **秋，宣公从伐莱战事返回；鲁国随后发生大旱。** [[4]](#note-4)

<a id="event-5"></a>

5. **郑国重新与晋讲和，并参加冬季晋国主导的黑壤会盟。** [[5]](#note-5)

<a id="event-6"></a>

6. **冬，鲁宣公会晋、宋、卫、郑、曹等于黑壤。** 晋成公因宣公即位后长期不朝不聘，扣留宣公；鲁国以贿赂脱身，而且没有参加最后盟誓。 [[6]](#note-6)

<a id="sj034-huangong-death-event"></a>

7. **燕桓公去世，宣公继承。** 桓公在位十六年，宣公的元年接在下一年。 [[7]](#sj034-huangong-death-note)

<a id="hs-event-8"></a>

8. **鲁秋大旱。** [[8]](#hs-note-8)

# 公元前603年（鲁宣公六年）

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，晋赵盾与卫孙免进攻陈国，因为陈国重新依附楚国。** 晋楚之间的诸侯争夺继续。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，周定王派子服到齐国为王室求婚。** [[2]](#note-2)

<a id="event-3"></a>

3. **秋，赤狄进攻晋国，包围怀地并到达邢丘。** 晋国没有立即反击，准备等待狄人进一步耗损民力。 [[3]](#note-3)

<a id="event-4"></a>

4. **秋八月，鲁国发生螽灾。** [[4]](#note-4)

<a id="event-5"></a>

5. **冬，周王室派召桓公前往齐国迎接王后。** [[5]](#note-5)

<a id="event-6"></a>

6. **楚国进攻郑国，取得和议后撤军。** [[6]](#note-6)

<a id="event-7"></a>

7. **郑公子曼满向王子伯廖谈起自己想做卿的愿望。** 伯廖后来对别人批评他无德而贪，借《周易》卦象推断他将有祸。曼满后来被杀的结局附在这段话后，不能当成本年已经发生。 [[7]](#note-7)

<a id="hs-event-8"></a>

8. **鲁八月螽。** [[8]](#hs-note-8)

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·宣公六年》**：“六年春，晋赵盾、卫孙免侵陈。”  
   **《左传·宣公六年》**：“陈即楚故也。”[卷014晋、卫、陈三栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0603)分别写与卫、与晋、晋卫侵我，为同一行动；不能把三个国栏各算一次联合进攻。

<a id="history-legacy-source-2"></a>

2. **《左传·宣公六年》**：“夏，定王使子服求后于齐。”

<a id="history-legacy-source-3"></a>

3. **《左传·宣公六年》**：“秋，赤狄伐晋。围怀，及邢丘。”不立即出兵是中行桓子的建议，所谓等待对方耗尽民力是其判断，不是已核实的狄人人口损失。

<a id="history-legacy-source-4"></a>

4. **《春秋·宣公六年》**：“秋八月，螽。”

<a id="history-legacy-source-5"></a>

5. **《左传·宣公六年》**：“冬，召桓公逆王后于齐。”夏季求婚与冬季迎后为两步，不合成同日。

<a id="history-legacy-source-6"></a>

6. **《左传·宣公六年》**：“楚人伐郑，取成而还。”

<a id="history-legacy-source-7"></a>

7. [**《左传·宣公六年》**](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E5%AE%A3%E5%85%AC.md#ref-884e61a5759149)记曼满与王子伯廖语，继引伯廖“无德而贪”的评价，末句为“间一岁，郑人杀之”。旧正文直接说“次年果然因贪位无德被杀”，同时把相对时间定得过死，又将伯廖的批评写成已证明的死因。本轮改为本年谈话与后来结局分层；尚未据独立年条核定死亡绝对年，不仅凭一句预叙在前602年再建死亡条，也不以结局证明卦象预测有效。

<a id="sj014-0603-qin-note"></a>
<a id="秦桓公元年属于表中的一套王年链"></a>
#### 秦桓公元年属于表中的一套王年链

[卷014秦栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0603)明列桓公元年，承接前604年共公五年；[卷005 P037](../../sources/摘录/史记-卷005-秦本纪.md#p037)也记共公五年卒、桓公立。但经文宣公四年已记共公死亡，当前主述见[前605年](bce-0605.md#note-2)，本页只保留表中纪元的位置，不另造一次即位。

哪一套积年需要怎样校正，不能仅靠移走一个重复死亡条就全部解决。原表没有改写，前604年旧锚点仍见[纪年异说](bce-0604.md#sj005-103-note)。

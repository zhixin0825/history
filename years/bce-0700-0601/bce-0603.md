# 公元前603年（鲁宣公六年）

[← 上一张已编年页：公元前604年](bce-0604.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前602年 →](bce-0602.md)

<a id="event-1"></a>

1. **春，晋赵盾与卫孙免进攻陈国，因为陈国重新依附楚国。** 晋楚之间的诸侯争夺继续。[1]

<a id="event-2"></a>

2. **夏，周定王派子服到齐国为王室求婚。** [2]

<a id="event-3"></a>

3. **秋，赤狄进攻晋国，包围怀地并到达邢丘。** 晋国没有立即反击，准备等待狄人进一步耗损民力。[3]

<a id="event-4"></a>

4. **秋八月，鲁国发生螽灾。** [4]

<a id="event-5"></a>

5. **冬，周王室派召桓公前往齐国迎接王后。** [5]

<a id="event-6"></a>

6. **楚国进攻郑国，取得和议后撤军。** [6]

<a id="event-7"></a>

7. **郑公子曼满急于求卿位，次年果然因贪位无德被杀。** [7]

## 本年相关史料

1. **《春秋·宣公六年》**：“六年春，晋赵盾、卫孙免侵陈。”  
   **《左传·宣公六年》**：“陈即楚故也。”

<a id="note-2"></a>

2. **《左传·宣公六年》**：“夏，定王使子服求后于齐。”

<a id="note-3"></a>

3. **《左传·宣公六年》**：“秋，赤狄伐晋。围怀，及邢丘。”

<a id="note-4"></a>

4. **《春秋·宣公六年》**：“秋八月，螽。”

<a id="note-5"></a>

5. **《左传·宣公六年》**：“冬，召桓公逆王后于齐。”

<a id="note-6"></a>

6. **《左传·宣公六年》**：“楚人伐郑，取成而还。”

<a id="note-7"></a>

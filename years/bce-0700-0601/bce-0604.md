# 公元前604年（鲁宣公五年）

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁宣公前往齐国，高固让齐侯把他留下，借机请求娶叔姬；夏天宣公才返回鲁国。** 这场婚姻的商议伴随着齐方对鲁君的压力。 [[1]](#note-1)

<a id="event-2"></a>

2. **秋九月，齐高固亲自到鲁国迎娶叔姬。** 由卿本人亲自迎亲，成为这一婚姻的显著礼仪特征。 [[2]](#note-2)

<a id="event-3"></a>

3. **叔孙得臣去世。** 鲁国又失去一位长期参与军政的卿大夫。 [[3]](#note-3)

<a id="event-4"></a>

4. **冬，高固与叔姬一同回鲁，办理反马之礼。** [[4]](#note-4)

<a id="event-5"></a>

5. **郑襄公坚进入在位元年，楚军又来进攻。** 坚是灵公的庶弟，前一年才在弑君之后被拥立。陈国随后与楚讲和，晋荀林父则出兵救郑，并进攻陈国。 [[5]](#note-5)

<a id="event-6"></a>

6. **秦共公去世与桓公继承的主体叙事见前605年。** 旧页在这里又写了一次死亡，本轮改为纪年异说的回链，保留原事件入口。 [[6]](#note-6)

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·宣公五年》**：“五年春，公如齐。夏，公至自齐。”  
   [**《左传·宣公五年》**](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E5%AE%A3%E5%85%AC.md#ref-d308dd70aa991a)：“高固使齐侯止公，请叔姬焉。”原正文只说借机求婚，现补齐侯留住鲁公的步骤，但不增造未记的拘禁方式或求婚日。

<a id="history-legacy-source-2"></a>

2. **《春秋·宣公五年》**：“秋九月，齐高固来逆叔姬。”  
   **《左传·宣公五年》**说明高固为自己迎女而亲来，与国君派卿迎夫人的情况分开，不由此推断所有卿大夫从未亲迎。

<a id="history-legacy-source-3"></a>

3. **《春秋·宣公五年》**：“叔孙得臣卒。”

<a id="history-legacy-source-4"></a>

4. **《春秋·宣公五年》**：“冬，齐高固及子叔姬来。”  
   **《左传·宣公五年》**：“反马也。”保留具体礼名，不把它直接替换为现代回门习俗。

<a id="history-legacy-source-5"></a>

5. **《春秋·宣公五年》**：“楚人伐郑。”  
   **《左传·宣公五年》**：“陈及楚平。晋荀林父救郑伐陈。”[卷014晋、陈、郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0604)合记同一组相连的军事外交行动。中行桓子就是荀林父，不另造一个同时率军的桓子；郑栏明确襄公坚元年、灵公庶弟，承位仍在[前605年](bce-0605.md#event-4)，不因元年再发生一次政变。

### 补充史料与异说

<a id="sj005-103-note"></a>
<a id="sj005-103秦共公卒年保留旧说不重复死亡"></a>
#### sj005-103｜秦共公卒年：保留旧说，不重复死亡

[卷005 P037](../../sources/摘录/史记-卷005-秦本纪.md#p037)记“共公……五年卒”，按前608年元年积年会落前604；[卷014](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0604)此行也列共公五年，下一行桓公元年。

但《春秋》宣公四年明确记“秦伯稻卒”，即本项目的[前605年](bce-0605.md#event-2)。本轮以经文年条为死亡主述，将原来本页的重复死亡改为此处的异说回链；**不改动原始年表数字，不声称整个秦国王年链已独立校定**。名字和、稻及共、恭写法见前608年说明，不能依差别拆为不同国君。前603年的桓公元年只说明表的另一计数，不另造一次父死子立。

古月与干支未经历算，不当作同号公历月日。此前卷005去向文件记录的是当时安排，当前取舍以这三张年页的相互说明为准。

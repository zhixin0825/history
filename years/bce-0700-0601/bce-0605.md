# 公元前605年（鲁宣公四年）

[← 上一张已编年页：公元前606年](bce-0606.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前604年 →](bce-0604.md)

<a id="event-1"></a>

1. **春，鲁宣公与齐侯调停莒、郯冲突；莒国不接受，鲁国遂出兵伐莒并夺取向地。** 以战争强行落实调停，反而使局势更加混乱。[1]

<a id="event-2"></a>

2. **秦共公去世。** [2]

<a id="event-3"></a>

3. **郑灵公因烹鼋时故意不给公子宋吃，激化旧怨。** 公子宋与公子归生先谋弑君，归生起初反对，后来因害怕被反告而参与。[3]

<a id="event-4"></a>

4. **夏六月，郑公子归生等杀郑灵公。** 郑国随后拥立公子坚，是为郑襄公。[4]

<a id="event-5"></a>

5. **楚国内若敖氏与王室彻底决裂。** 子越椒杀蒍贾后聚族准备攻楚王，楚庄王亲自率军迎战。[5]

<a id="event-6"></a>

6. **秋七月，楚庄王在皋浒击败若敖氏，基本灭其宗族。** 子文后裔克黄因忠于王命获保全，并改名生。[6]

<a id="event-7"></a>

7. **秋，鲁宣公前往齐国，随后返回。** [7]

<a id="event-8"></a>

8. **冬，楚庄王再次伐郑，因为郑国新政权仍未完全服楚。** [8]

<a id="event-9"></a>

9. **同年赤狄再次侵齐。** [9]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·宣公四年》**：“四年春，王正月，公及齐侯平莒及郯。莒人不肯，公伐莒，取向。”  
   **《左传·宣公四年》**详记鲁以伐强平。

<a id="note-2"></a>

2. **《春秋·宣公四年》**：“秦伯稻卒。”

<a id="note-3"></a>

3. **《左传·宣公四年》**详记郑灵公食鼋、子公染指及弑君谋议。

<a id="note-4"></a>

4. **《春秋·宣公四年》**：“夏六月乙酉，郑公子归生弑其君夷。”  
   **《左传·宣公四年》**详记立郑襄公。

<a id="note-5"></a>

5. **《左传·宣公四年》**详记若敖氏、子越椒、蒍贾冲突及准备攻王。

<a id="note-6"></a>

6. **《左传·宣公四年》**详记楚庄王与若敖氏战皋浒并灭其族。

<a id="note-7"></a>

7. **《春秋·宣公四年》**：“秋，公如齐。公至自齐。”

<a id="note-8"></a>

8. **《春秋·宣公四年》**：“冬，楚子伐郑。”  
   **《左传·宣公四年》**：“郑未服也。”

9. **《春秋·宣公四年》**：“赤狄侵齐。”

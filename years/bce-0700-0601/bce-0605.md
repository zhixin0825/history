<a id="reading-event-1"></a>

1. **春，鲁宣公与齐侯调停莒、郯冲突；莒国不接受，鲁国遂出兵伐莒并夺取向地。** 以战争强行落实调停，反而使局势更加混乱。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **春，秦共公去世，秦国转入桓公继承后的阶段。** 其死亡主体放在本年，桓公元年的另一套计数另作说明。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **郑灵公夷进入在位元年，却因与公子宋的冲突面临弑君阴谋。** 楚人送来鼋，公子宋拿自己食指会预示美味的话开玩笑；灵公听说后故意不给他分食。公子宋伸指入鼎尝羹，愤而离席，灵公也发怒，想杀掉他。公子宋遂与公子归生商议先下手，归生起初拒绝，后来害怕遭谗告而参与。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **夏六月，郑公子归生等杀郑灵公。** 郑国随后拥立公子坚，是为郑襄公。 [[4]](#reading-note-4)

<a id="reading-event-5"></a>

5. **郑公子去疾先辞君位，又阻止襄公清除穆氏诸公子。** 国人最初推去疾即位，他以公子坚年长为由辞让。坚成为襄公后，想排除穆公其他后人而独留去疾；去疾表示诸兄弟应同存亡，襄公于是保留他们，使为大夫。 [[5]](#reading-note-5)

<a id="event-5"></a>

<a id="reading-event-6"></a>

6. **楚国内若敖氏与王室彻底决裂。** 子越椒杀蒍贾后聚族准备攻楚王，楚庄王亲自率军迎战。 [[6]](#reading-note-6)

<a id="event-6"></a>

<a id="reading-event-7"></a>

7. **秋七月，楚庄王在皋浒击败若敖氏，基本灭其宗族。** 子文后裔克黄因忠于王命获保全，并改名生。 [[7]](#reading-note-7)

<a id="event-7"></a>

<a id="reading-event-8"></a>

8. **秋，鲁宣公前往齐国，随后返回。** [[8]](#reading-note-8)

<a id="event-8"></a>

<a id="reading-event-9"></a>

9. **冬，楚庄王再次伐郑，因为郑国新政权仍未完全服楚。** [[9]](#reading-note-9)

<a id="event-9"></a>

<a id="reading-event-10"></a>

10. **夏，赤狄再次侵齐。** [[10]](#reading-note-10)

### 6. 楚国内若敖氏与王室彻底决裂

[返回正文第6条](#reading-event-6)

**[《左传》鲁宣公4年传文（前605年）](../../sources/春秋左传/有标点原文/bce-0605.md#batch-20261109-t005)**

> 初，楚司马子良生子越椒。子文曰：“必杀之。是子也，熊虎之状，而豺狼之声，弗杀，必灭若敖氏矣。谚曰：‘狼子野心。’是乃狼也，其可畜乎？”子良不可。子文以为大慼，及将死，聚其族曰：“椒也知政，乃速行矣，无及于难。”且泣曰：“鬼犹求食，若敖氏之鬼，不其馁而？”及令尹子文卒，鬥般为令尹，子越为司马，蒍贾为工正。谮子扬而杀之，子越为令尹，己为司马。子越又恶之，乃以若敖氏之族圄伯嬴于 轑阳而杀之，遂处烝野，将攻王。王以三王之子为质焉，弗受，师于漳澨。

### 7. 秋七月，楚庄王在皋浒击败若敖氏，基本灭其宗族

[返回正文第7条](#reading-event-7)

**[《左传》鲁宣公4年传文（前605年）](../../sources/春秋左传/有标点原文/bce-0605.md#batch-20261109-t006)**

> 秋七月戊戌，楚子与若敖氏战于皋浒。伯棼射王，汏辀，及鼓跗，著于丁宁。又射汏辀，以贯笠毂。师惧，退。王使巡师曰：“吾先君文王克息，获三矢焉。伯棼窃其二，尽于是矣。”鼓而进之，遂灭若敖氏。

**[《左传》鲁宣公4年传文（前605年）](../../sources/春秋左传/有标点原文/bce-0605.md#batch-20261109-t007)**

> 初，若敖娶于云阜，生鬥伯比。若敖卒，从其母畜于云阜，淫于云阜子之女，生子文焉。䢵夫人使弃诸梦中，虎乳之。云阜子田，见之，惧而归，夫人以告，遂使收之。楚人谓乳穀，谓虎於菟，故命之曰鬥穀於菟。以其女妻伯比，实为令尹子文。其孙箴尹克黄使于齐，还，及宋，闻乱。其人曰，“不可以入矣。”箴尹曰：“弃君之命，独谁受之？君，天也，天可逃乎？”遂归，复命而自拘于司败。王思子文之治楚国也，曰：“子文无后，何以劝善？”使复其所，改命曰生。

## 归年与考证

<a id="history-legacy-source-1"></a>
<a id="note-1"></a>

1. **《春秋·宣公四年》**：“四年春，王正月，公及齐侯平莒及郯。莒人不肯，公伐莒，取向。”  
   **《左传·宣公四年》**详记鲁以伐强平，其批评留作原作者的礼制评价。

<a id="history-legacy-source-2"></a>
<a id="note-2"></a>

2. **《春秋·宣公四年》**明确在春季记“秦伯稻卒”。[卷005 P037](../../sources/摘录/史记-卷005-秦本纪.md#p037)却说共公五年卒，旧页按前608年元年推到前604年，造成相邻两页都说共公去世。正文采用经文明确年条，前604年保留异说与原锚点，不再重复死亡。[完整经传](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E5%AE%A3%E5%85%AC.md#ref-7ec092b224c10b)。

   [卷014](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0605)本年秦栏仍为四，前604年五，前603年才桓公元年。这是一套不同的王年链，本次没有擅自改源表或声称已经独立复算全部秦君年数。表名和、经名稻也不另造两位秦君。相关旧入口见[前604年注](bce-0604.md#sj005-103-note)、[前603年注](bce-0603.md#sj014-0603-qin-note)。

<a id="history-legacy-source-3"></a>
<a id="note-3"></a>

3. **《左传·宣公四年》**详记食指动、食鼋、染指及谋先。[卷014郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0605)“郑灵公夷元年，公子归生以鼋故杀灵公”是简述，正文补出灵公欲杀、子公谋先及子家被牵入的中间步骤。公子宋称子公，归生称子家，不混成一人；食指预兆作为人物所说的话，不认作生理现象能预测膳食的证据。穆公死亡仍在前606年。

<a id="history-legacy-source-4"></a>
<a id="note-4"></a>

4. **《春秋·宣公四年》**：“夏六月乙酉，郑公子归生弑其君夷。”  
   **《左传·宣公四年》**详记子良辞位、立襄公。经文归责归生与子公参与谋划并存，不因简称“以鼋故”就删掉参与者和事先冲突。

<a id="history-legacy-source-5"></a>
<a id="note-5"></a>

5. **《左传·宣公四年》**详记若敖氏、子越椒、蒍贾冲突及准备攻王。[卷014楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0605)“若敖氏为乱，灭之”与事件5、6同事，不是另一次楚国内乱。

<a id="history-legacy-source-6"></a>
<a id="note-6"></a>

6. **《左传·宣公四年》**详记秋七月戊戌战皋浒、灭若敖氏；克黄奉使回国后复命自拘，楚王念及子文功业而保全他。此前子文预言宗族将亡及出生故事属于回叙与传说，不在本年重新发生。

<a id="history-legacy-source-7"></a>
<a id="note-7"></a>

7. **《春秋·宣公四年》**：“秋，公如齐。公至自齐。”

<a id="history-legacy-source-8"></a>
<a id="note-8"></a>

8. **《春秋·宣公四年》**：“冬，楚子伐郑。”  
   **《左传·宣公四年》**：“郑未服也。”卷014楚栏同格还记伐郑，与国内七月之战是两件事，不共用日期。

<a id="history-legacy-source-9"></a>
<a id="note-9"></a>

9. **《春秋·宣公四年》**：“赤狄侵齐。”该句在本年经文夏季条内，正文按此定位，不受原列表排在第9项影响而移到冬季。

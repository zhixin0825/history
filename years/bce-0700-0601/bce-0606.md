# 公元前606年（鲁宣公三年）

[← 上一张已编年页：公元前607年](bce-0607.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前605年 →](bce-0605.md)

<a id="event-1"></a>

1. **春，鲁国准备郊祭时，牺牲牛先受伤，改选的牛又死去，最后取消郊祭，却仍举行三望。** 这种祭祀安排被认为不合礼。[1]

<a id="event-2"></a>

2. **鲁国安葬周匡王。** [2]

<a id="event-3"></a>

3. **楚庄王讨伐陆浑之戎，一直进到洛水附近，在周王畿展示军队。** 周定王派王孙满慰劳楚军。[3]

<a id="event-4"></a>

4. **楚庄王向王孙满询问九鼎大小轻重，试探周王室权威。** 王孙满以“在德不在鼎”回答，强调周室虽衰，天命未改。[4]

<a id="event-5"></a>

5. **夏，楚军进攻郑国，因为郑国重新依附晋国。** [5]

<a id="event-6"></a>

6. **秋，赤狄侵齐。** [6]

<a id="event-7"></a>

7. **宋国内部武氏、穆氏等公族反宋文公，借曹军伐宋；宋军随后包围曹国报复。** [7]

<a id="event-8"></a>

8. **冬，郑穆公去世并下葬。** 其早年由燕姞梦兰生子、后来获立的故事也在本年被回顾。[8]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·宣公三年》**：“三年春，王正月，郊。牛之口伤，改卜牛，牛死，乃不郊。犹三望。”  
   **《左传·宣公三年》**：“不郊而望，皆非礼也。”

<a id="note-2"></a>

2. **《春秋·宣公三年》**：“葬匡王。”

<a id="note-3"></a>

3. **《春秋·宣公三年》**：“楚子伐陆浑之戎。”  
   **《左传·宣公三年》**详记楚军至雒、观兵周疆。

<a id="note-4"></a>

4. **《左传·宣公三年》**详记楚庄王问鼎与王孙满答“在德不在鼎”。

<a id="note-5"></a>

5. **《春秋·宣公三年》**：“夏，楚人侵郑。”  
   **《左传·宣公三年》**：“郑即晋故也。”

<a id="note-6"></a>

6. **《春秋·宣公三年》**：“秋，赤狄侵齐。”

<a id="note-7"></a>

   **《左传·宣公三年》**详记宋逐武穆之族、武穆借曹师伐宋。

<a id="note-8"></a>

8. **《春秋·宣公三年》**：“冬十月丙戌，郑伯兰卒。葬郑穆公。”

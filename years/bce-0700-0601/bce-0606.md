# 公元前606年（鲁宣公三年）

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁国准备郊祭时，牺牲牛先受伤，改选的牛又死去，最后取消郊祭，却仍举行三望。** 这种祭祀安排被认为不合礼。 [[1]](#note-1)

<a id="event-2"></a>

2. **周国进入定王元年，鲁国参加周匡王的葬礼。** 匡王去世和弟弟瑜承位已经发生在前一年，本年元年与葬事分别承接，不是再有一次王位更替。 [[2]](#note-2)

<a id="event-3"></a>

3. **楚庄王讨伐陆浑之戎，一直进到洛水附近，在周王畿展示军队。** 周定王派王孙满慰劳楚军。 [[3]](#note-3)

<a id="event-4"></a>

4. **楚庄王询问九鼎轻重，王孙满以德与天命回应。** 楚伐陆浑戎后进到洛水、陈兵周郊，庄王夸楚军折钩之金便足以铸鼎。王孙满叙夏铸鼎以示物、桀失德而鼎迁商、纣失德又迁周，强调德明则小鼎也重、昏乱则大鼎也轻；又说成王定鼎郏鄏卜得三十世七百年，周命未改，尚不可问鼎。庄王遂退。 [[4]](#note-4)

   [卷四互见与归年](#sj004-606-1) · [秦本纪互见](#sj005-102-note)

<a id="event-5"></a>

5. **夏，楚军进攻郑国，因为郑国重新依附晋国。** [[5]](#note-5)

<a id="event-6"></a>

6. **秋，赤狄侵齐。** [[6]](#note-6)

<a id="event-7"></a>

7. **宋国内部武氏、穆氏等公族反宋文公，借曹军伐宋；宋军随后包围曹国报复。** [[7]](#note-7)

<a id="event-8"></a>

8. **冬，郑穆公去世并下葬。** 其早年由燕姞梦兰生子、后来获立的故事也在本年被回顾。 太子夷继承君位，为灵公，次年改记元年。 [[8]](#note-8)

<a id="event-9"></a>

9. **晋国进入成公元年，晋军在春季进攻郑国，直到郔地，士会入郑主持盟誓。** 郑国在这次行动后与晋讲和，后来又遭楚军进攻，更能看清郑在两大国之间来回承压的过程。 [[9]](#note-9)

> 楚子伐陆浑之戎，遂至于雒，观兵于周疆。定王使王孙满劳楚子。楚子问鼎之大小轻重焉。对曰：“在德不在鼎。昔夏之方有德也，远方图物，贡金九牧，铸鼎象物，百物而为之备，使民知神奸。故民入川泽山林，不逢不若。螭魅罔两，莫能逢之，用能协于上下以承天休。桀有昏德，鼎迁于商，载祀六百。商纣暴虐，鼎迁于周。德之休明，虽小，重也。其奸回昏乱，虽大，轻也。天祚明德，有所厎止。成王定鼎于郏鄏，卜世三十，卜年七百，天所命也。周德虽衰，天命未改，鼎之轻重，未可问也。”

<a id="sj040-cite-064"></a>

**[《史记·楚世家》P027](../../sources/摘录/史记-卷040-楚世家.md#p027)**

> 八年，伐陸渾戎，遂至洛，觀兵於周郊。周定王使王孫滿勞楚王。楚王問鼎小大輕重，對曰：「在德不在鼎。」莊王曰：「子無阻九鼎！楚國折鉤之喙，足以為九鼎。」王孫滿曰：「嗚呼！君王其忘之乎？昔虞夏之盛，遠方皆至，貢金九牧，鑄鼎象物，百物而為之備，使民知神姦。桀有亂德，鼎遷於殷，載祀六百。殷紂暴虐，鼎遷於周。德之休明，雖小必重；其姦回昏亂，雖大必輕。昔成王定鼎于郟鄏，卜世三十，卜年七百，天所命也。周德雖衰，天命未改。鼎之輕重，未可問也。」楚王乃歸。

**本卷说明：** 诸王世数、神奸和卜年均为政治答辞，不据其造上古确年；本段起句伐戎与第3条为同役背景。

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·宣公三年》**：“三年春王正月，郊牛之口伤，改卜牛，牛死，乃不郊，犹三望。”  
   **《左传·宣公三年》**：“不郊而望，皆非礼也。”旧页引文将“郊。牛”断开，容易误读成已先行郊祭，现按[完整经文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E5%AE%A3%E5%85%AC.md#ref-df851519bccf2f)连读郊牛。祭祀批评属于传文立场，不作已经检验的灾异因果。

<a id="history-legacy-source-2"></a>

2. **《春秋·宣公三年》**：“葬匡王。”[卷014周栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0606)定王元年接[前607年](bce-0607.md#sj004-607-1)匡王死、弟承兄。鲁史书王葬不足以证明鲁国独自主办整个葬礼；正文改为参加，不补未记的使者姓名。

<a id="history-legacy-source-3"></a>

3. **《春秋·宣公三年》**：“楚子伐陆浑之戎。”  
   **《左传·宣公三年》**详记楚军至雒、观兵周疆。

<a id="history-legacy-source-4"></a>

4. **《左传·宣公三年》**详记楚庄王问鼎与王孙满答“在德不在鼎”。[卷014楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0606)的伐陆浑、至洛、问鼎与事件3、4同事，不能因在不同篇章各记一次就算数次问鼎。九鼎、德与天命的关系是答辞中的政治解释，不据此证明天命实际决定周室存亡。

<a id="sj004-606-1"></a>
<a id="楚在王畿观兵与问鼎卷四互见"></a>
##### 楚在王畿观兵与问鼎｜卷四互见

<a id="history-legacy-source-6"></a>

   **《左传·宣公三年》**：“郑即晋故也。”

<a id="history-legacy-source-7"></a>

6. **《春秋·宣公三年》**：“秋，赤狄侵齐。”

<a id="history-legacy-source-8"></a>

7. **《春秋·宣公三年》**：“宋师围曹。”  
   **《左传·宣公三年》**详记宋逐武穆之族、武穆借曹师伐宋。[卷014宋、曹栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0606)“围曹”“宋围我”为同一行动。宋文公清洗的叙次问题仍与[前609年](bce-0609.md#event-12)合读，不据多处追叙另算两次相同清洗。

<a id="history-legacy-source-9"></a>

8. **《春秋·宣公三年》**：“冬十月丙戌，郑伯兰卒。葬郑穆公。”  
   **《左传·宣公三年》**回顾出生与即位，梦兰及临终兰草的联系属传说层，早年出生、奔晋、被迎回不都归本年。

#### 华元赎归在表中后移一年

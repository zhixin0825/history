# 公元前606年（鲁宣公三年）

[← 上一张已编年页：公元前607年](bce-0607.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前605年 →](bce-0605.md)

<a id="event-1"></a>

1. **春，鲁国准备郊祭时，牺牲牛先受伤，改选的牛又死去，最后取消郊祭，却仍举行三望。** 这种祭祀安排被认为不合礼。[[1]](#note-1)

<a id="event-2"></a>

2. **周国进入定王元年，鲁国参加周匡王的葬礼。** 匡王去世和弟弟瑜承位已经发生在前一年，本年元年与葬事分别承接，不是再有一次王位更替。[[2]](#note-2)

<a id="event-3"></a>

3. **楚庄王讨伐陆浑之戎，一直进到洛水附近，在周王畿展示军队。** 周定王派王孙满慰劳楚军。[[3]](#note-3)

<a id="event-4"></a>

4. **楚庄王向王孙满询问九鼎大小轻重，试探周王室权威。** 王孙满以“在德不在鼎”回答，强调周室虽衰，天命未改。[[4]](#note-4)

[卷四互见与归年](#sj004-606-1) · [秦本纪互见](#sj005-102-note)

<a id="event-5"></a>

5. **夏，楚军进攻郑国，因为郑国重新依附晋国。** [[5]](#note-5)

<a id="event-6"></a>

6. **秋，赤狄侵齐。** [[6]](#note-6)

<a id="event-7"></a>

7. **宋国内部武氏、穆氏等公族反宋文公，借曹军伐宋；宋军随后包围曹国报复。** [[7]](#note-7)

<a id="event-8"></a>

8. **冬，郑穆公去世并下葬。** 其早年由燕姞梦兰生子、后来获立的故事也在本年被回顾。[[8]](#note-8)

<a id="event-9"></a>

9. **晋国进入成公元年，晋军在春季进攻郑国，直到郔地，士会入郑主持盟誓。** 郑国在这次行动后与晋讲和，后来又遭楚军进攻，更能看清郑在两大国之间来回承压的过程。 [看原文与说明](#cq-source-50)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·宣公三年》**：“三年春王正月，郊牛之口伤，改卜牛，牛死，乃不郊，犹三望。”  
   **《左传·宣公三年》**：“不郊而望，皆非礼也。”旧页引文将“郊。牛”断开，容易误读成已先行郊祭，现按[完整经文](https://zh.wikisource.org/wiki/春秋左氏傳/宣公#宣公三年)连读郊牛。祭祀批评属于传文立场，不作已经检验的灾异因果。

<a id="note-2"></a>

2. **《春秋·宣公三年》**：“葬匡王。”[卷014周栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0606)定王元年接[前607年](bce-0607.md#sj004-607-1)匡王死、弟承兄。鲁史书王葬不足以证明鲁国独自主办整个葬礼；正文改为参加，不补未记的使者姓名。

<a id="note-3"></a>

3. **《春秋·宣公三年》**：“楚子伐陆浑之戎。”  
   **《左传·宣公三年》**详记楚军至雒、观兵周疆。

<a id="note-4"></a>

4. **《左传·宣公三年》**详记楚庄王问鼎与王孙满答“在德不在鼎”。[卷014楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0606)的伐陆浑、至洛、问鼎与事件3、4同事，不能因在不同篇章各记一次就算数次问鼎。九鼎、德与天命的关系是答辞中的政治解释，不据此证明天命实际决定周室存亡。

<a id="sj004-606-1"></a>
#### 楚在王畿观兵与问鼎｜卷四互见

[卷004 P053](../../sources/摘录/史记-卷004-周本纪.md#p053)。本纪定王元年记楚至洛、使者王孙满、问鼎大小轻重；已有细分两条正文，原文并归本处，不另写第二场问鼎。

<a id="note-5"></a>

5. **《春秋·宣公三年》**：“夏，楚人侵郑。”  
   **《左传·宣公三年》**：“郑即晋故也。”

<a id="note-6"></a>

6. **《春秋·宣公三年》**：“秋，赤狄侵齐。”

<a id="note-7"></a>

7. **《春秋·宣公三年》**：“宋师围曹。”  
   **《左传·宣公三年》**详记宋逐武穆之族、武穆借曹师伐宋。[卷014宋、曹栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0606)“围曹”“宋围我”为同一行动。宋文公清洗的叙次问题仍与[前609年](bce-0609.md#event-12)合读，不据多处追叙另算两次相同清洗。

<a id="note-8"></a>

8. **《春秋·宣公三年》**：“冬十月丙戌，郑伯兰卒。葬郑穆公。”  
   **《左传·宣公三年》**回顾出生与即位，梦兰及临终兰草的联系属传说层，早年出生、奔晋、被迎回不都归本年。

<a id="sj014-0606-huayuan-note"></a>
### 华元赎归在表中后移一年

[卷014本年宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0606)“赎华元，亡归”与郑栏“华元亡归”说的是同一人、同一脱身过程；《左传·宣公二年》却将它接在大棘之战后。主述继续放[前607年事件2](bce-0607.md#event-2)，此处只留异年，不能再替华元安排一次相同的被俘和逃归。

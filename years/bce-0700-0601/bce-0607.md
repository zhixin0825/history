[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，郑国奉楚命伐宋，宋郑在大棘交战，宋军大败，主将华元被俘。** 战前华元杀羊犒军，却没有分给御者羊斟。羊斟怀恨，交战时故意把华元的车驶入郑阵，酿成败局。 [[1]](#note-1)

<a id="event-2"></a>

2. **宋国用大量兵车、良马赎华元，赎物还未送完，华元已经自己逃回宋国。** 他回国后还受到城墙役夫讥讽。 [[2]](#note-2)

<a id="event-3"></a>

3. **秦军伐晋，围焦地，报复晋国前一年侵崇。** [[3]](#note-3)

<a id="event-4"></a>

4. **夏，晋、宋、卫、陈联合侵郑；楚将鬥椒率军救郑。** 赵盾判断楚军内部问题严重，不愿强战，晋军撤退。 [[4]](#note-4)

<a id="event-5"></a>

5. **晋灵公奢侈暴虐，重税修墙、从台上弹人取乐，还因熊掌没煮熟杀厨师。** 赵盾、士季多次劝谏，灵公口头答应却不改。 [[5]](#note-5)

<a id="event-6"></a>

6. **晋灵公派鉏麑刺杀赵盾，鉏麑见赵盾天未亮已整冠待朝，不忍下手，自杀而死。** [[6]](#note-6)

<a id="event-7"></a>

7. **秋，晋灵公又设宴伏兵要杀赵盾。** 提弥明护赵盾突围战死，赵盾早年救过的灵辄也倒戈相助，赵盾得以逃亡。 [[7]](#note-7)

<a id="event-8"></a>

8. **九月，赵穿在桃园杀死晋灵公。** 赵盾尚未越过晋境便返回，又没有诛杀赵穿，史官董狐因此把弑君责任记在赵盾名下。 [[8]](#note-8)

<a id="event-9"></a>

9. **赵盾让赵穿从周王室迎回公子黑臀，立为晋成公。** 晋国同时设置公族、余子、公行等职位，让卿大夫的子弟入仕，改变献公以来不蓄群公子的旧局。赵盾请求由弟弟赵括承公族之职，自己另为旄车之族；赵氏内部的安排也随之调整。 [[9]](#note-9)

<a id="event-10"></a>

10. **冬十月，周匡王去世。** 本段没有提到匡王的儿子，记载的继位者是弟弟瑜，即定王；本纪只记弟承兄，不增造无子原因。 [卷四互见与归年](#sj004-607-1) [[10]](#note-10)

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·宣公二年》**：“二年春，王二月壬子，宋华元帅师及郑公子归生帅师，战于大棘。宋师败绩，获宋华元。”  
   **《左传·宣公二年》**详记羊斟因食羊私怨败军。[卷014宋、郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0607)分别从华元陷敌、郑获华元记同一战事。羊羹故事是传世的败因解释，不据它断言整场战争只受一顿饭决定。

<a id="history-legacy-source-2"></a>

2. **《左传·宣公二年》**记宋以兵车百乘、文马百驷赎华元，“半入，华元逃归”，继写监筑城而被役夫讥笑。[卷014前606年宋、郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0606)却把赎归放在下一行。正文沿本年经传连叙，前606年只登记异年，不再发生第二次逃归。车马数为史书记数，不换算未经核实的价格；逃归也不擅写成郑国已经完成正式释放。

<a id="history-legacy-source-3"></a>

3. **《春秋·宣公二年》**：“秦师伐晋。”  
   **《左传·宣公二年》**：“以报崇也，遂围焦。”

<a id="history-legacy-source-4"></a>

4. **《春秋·宣公二年》**：“夏，晋人、宋人、卫人、陈人侵郑。”  
   **《左传·宣公二年》**详记鬥椒救郑、赵盾退军。

<a id="history-legacy-source-5"></a>

5. **《左传·宣公二年》**详记晋灵公厚敛、弹人、杀宰夫及赵盾士季进谏。

<a id="history-legacy-source-6"></a>

6. **《左传·宣公二年》**详记鉏麑受命刺赵盾而触槐自杀。人物内心独白按传世叙事处理，不把它当作现存现场记录或对自伤行为的赞许。

<a id="history-legacy-source-7"></a>

7. **《左传·宣公二年》**详记宴伏甲、提弥明战死、灵辄救赵盾。灵辄受食是此前背景，不把被救和报恩全定在同日。

<a id="history-legacy-source-8"></a>

8. **《春秋·宣公二年》**：“秋九月乙丑，晋赵盾弑其君夷皋。”  
   **《左传·宣公二年》**详记赵穿杀灵公、董狐书“赵盾弑其君”。

   **说明：**实际行刺者为赵穿；经文归责赵盾，传文解释为“亡不越竟，反不讨贼”。[卷014晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0607)同样记赵穿杀灵公、赵盾使穿迎君。实际行动与史官责任判定分开，不因此断言赵盾一定事先密令弑君。

<a id="history-legacy-source-9"></a>

9. [**《左传·宣公二年》**](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E5%AE%A3%E5%85%AC.md#ref-92104171b72936)详记迎黑臀、卿之子弟入仕、赵盾请以括为公族，冬季赵盾为旄车之族、屏季为公族大夫。屏季即赵括。本次补入表中“赵氏赐公族”的具体去向，不把赵氏全族都算成一次新封的诸侯。卷014所见“黑诈”与经传黑臀不同，正文采用可由经文卒名互核的黑臀，源表疑字保留。

<a id="history-legacy-source-10"></a>

10. **《春秋·宣公二年》**：“冬十月乙亥，天王崩。”[卷014周栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0607)匡王六年崩与本条同事，来年定王元年不再记死一次。

#### 齐王子成父败长狄：两种相距很远的纪年

[卷014本年齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0607)记惠公二年王子成父败长翟；[《齐太公世家》惠公二年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7032.md#ref-fc46109ae4d8c7)也记王子城父杀长翟、埋北门，并接晋灵公被弑。

但[《左传·文公十一年》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E6%96%87%E5%85%AC.md#ref-4c161dc7913b5d)回叙的是“齐襄公之二年”，王子成父获荣如、埋首于周首北门，按本项目齐襄公元年对应前697年的口径，该说应在前696年。两说相差甚远，不能把襄公、惠公互换后声称完全一致，也不因传文放在文公十一年便归前616年。

目前仅把这一冲突登记在本年表所指的位置，由[前616年的长狄回叙入口](bce-0616.md#event-7)串读；**暂不在正文增加一场已确定发生于前607年的新战**。是否同一故事的异年、成父与城父的文本关系及完整人物年表，仍需专题校核，不为求齐全捏造两场一模一样的战斗。

# 公元前607年（鲁宣公二年）

[← 上一张已编年页：公元前608年](bce-0608.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前606年 →](bce-0606.md)

<a id="event-1"></a>

1. **春，郑国奉楚命伐宋，宋郑在大棘交战，宋军大败，主将华元被俘。** 宋军败因还包括御者羊斟因私怨故意把华元车驶入郑阵。[[1]](#note-1)

<a id="event-2"></a>

2. **宋国用大量兵车、良马赎华元，赎物还未送完，华元已经自己逃回宋国。** 他回国后还受到城墙役夫讥讽。[[2]](#note-2)

<a id="event-3"></a>

3. **秦军伐晋，围焦地，报复晋国前一年侵崇。** [[3]](#note-3)

<a id="event-4"></a>

4. **夏，晋、宋、卫、陈联合侵郑；楚将鬥椒率军救郑。** 赵盾判断楚军内部问题严重，不愿强战，晋军撤退。[[4]](#note-4)

<a id="event-5"></a>

5. **晋灵公奢侈暴虐，重税修墙、从台上弹人取乐，还因熊掌没煮熟杀厨师。** 赵盾、士季多次劝谏，灵公口头答应却不改。[[5]](#note-5)

<a id="event-6"></a>

6. **晋灵公派鉏麑刺杀赵盾，鉏麑见赵盾天未亮已整冠待朝，不忍下手，自杀而死。** [[6]](#note-6)

<a id="event-7"></a>

7. **秋，晋灵公又设宴伏兵要杀赵盾。** 提弥明护赵盾突围战死，赵盾早年救过的灵辄也倒戈相助，赵盾得以逃亡。[[7]](#note-7)

<a id="event-8"></a>

8. **九月，赵穿在桃园杀死晋灵公。** 赵盾尚未越过晋境便返回，又没有诛杀赵穿，史官董狐因此把弑君责任记在赵盾名下。[[8]](#note-8)

<a id="event-9"></a>

9. **赵盾迎立公子黑臀，是为晋成公。** 晋国同时重新设置公族、余子、公行等官职，修补献公以来公族断层。[[9]](#note-9)

<a id="event-10"></a>

10. **冬十月，周匡王去世。** [[10]](#note-10)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·宣公二年》**：“二年春，王二月壬子，宋华元帅师及郑公子归生帅师，战于大棘。宋师败绩，获宋华元。”  
   **《左传·宣公二年》**详记羊斟因食羊私怨败军。

<a id="note-2"></a>

2. **《左传·宣公二年》**详记宋以兵车、文马赎华元，华元半途逃归。

<a id="note-3"></a>

3. **《春秋·宣公二年》**：“秦师伐晋。”  
   **《左传·宣公二年》**：“以报崇也，遂围焦。”

<a id="note-4"></a>

4. **《春秋·宣公二年》**：“夏，晋人、宋人、卫人、陈人侵郑。”  
   **《左传·宣公二年》**详记鬥椒救郑、赵盾退军。

<a id="note-5"></a>

5. **《左传·宣公二年》**详记晋灵公厚敛、弹人、杀宰夫及赵盾士季进谏。

<a id="note-6"></a>

6. **《左传·宣公二年》**详记鉏麑受命刺赵盾而触槐自杀。

<a id="note-7"></a>

7. **《左传·宣公二年》**详记宴伏甲、提弥明战死、灵辄救赵盾。

<a id="note-8"></a>

8. **《春秋·宣公二年》**：“秋九月乙丑，晋赵盾弑其君夷皋。”  
   **《左传·宣公二年》**详记赵穿杀灵公、董狐书“赵盾弑其君”。

   **说明：** 实际行刺者为赵穿；经文把责任归赵盾，传文解释为赵盾“亡不越竟，反不讨贼”。正文区分实际杀人者与史官责任判定。

<a id="note-9"></a>

9. **《左传·宣公二年》**详记赵盾迎黑臀于周立为晋成公，并恢复公族制度。

<a id="note-10"></a>

10. **《春秋·宣公二年》**：“冬十月乙亥，天王崩。”

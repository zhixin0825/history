# 公元前608年（鲁宣公元年）

[← 上一张已编年页：公元前609年](bce-0609.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前607年 →](bce-0607.md)

<a id="event-1"></a>

1. **春，鲁宣公即位；公子遂立即前往齐国迎娶姜氏。** 宣公本来不是文公的嫡长子，他的君位依赖襄仲与齐国支持，因此新政权一开始就把齐国关系放在核心位置。[[1]](#note-1)

<a id="event-2"></a>

2. **三月，夫人姜氏从齐国抵鲁。** 新君婚姻成为稳固鲁齐关系的一部分。[[2]](#note-2)

<a id="event-3"></a>

3. **夏，季孙行父赴齐送礼，请求齐侯与宣公会面；随后宣公在平州会齐侯。** 这次会面实际上是在确认宣公的君位。[[3]](#note-3)

<a id="event-4"></a>

4. **为换取齐国承认，鲁国把济西田地交给齐国。** 六月，齐国正式取得济西之田。齐国也已进入惠公元年，新君公子元通过支持鲁国继承者，取得土地和政治回报。[[4]](#note-4)

<a id="event-5"></a>

5. **晋国内部清算“不用命”者，把胥甲父放逐到卫国。** 这是追究此前河曲之役中违命的军将，不把尚未发生的邲战写成此次处置原因。[[5]](#note-5)

<a id="event-6"></a>

6. **秋，邾君来鲁朝见。** 鲁国新君开始恢复周边诸侯往来。[[6]](#note-6)

<a id="event-7"></a>

7. **楚庄王联合郑国进攻陈国，继而侵宋。** 陈、宋转向晋国，郑国则转而依楚，中原晋楚对抗进一步升级。[[7]](#note-7)

<a id="event-8"></a>

8. **晋赵盾率军救陈、宋，并会宋、陈、卫、曹于棐林伐郑。** 楚将蒍贾救郑，在北林与晋军相遇，俘获晋人解扬，晋军于是撤退。[[8]](#note-8)

<a id="event-9"></a>

9. **冬，晋赵穿进攻崇国，想借此逼秦国与晋讲和；秦国没有答应。** 晋人随后再次伐郑，报复北林之役。[[9]](#note-9)

<a id="sj014-0608-qin"></a>

10. **秦国开始以共公元年纪事。** 康公去世后，其子接掌秦国；晋人试图借侵崇求和，面对的已是这位新君。父亲的死亡与继承见前609年，本年不重复记一次。[原文与说明](#sj014-0608-qin-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·宣公元年》**：“元年春，王正月，公即位。公子遂如齐逆女。”  
   **《左传·宣公元年》**：“公子遂如齐逆女，尊君命也。”[卷014鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0608)的元年与“不正，公室卑”，分别是新君计年和史家判断；前609年杀恶、视立宣公的政变不在本年再发生一次。公室受制的具体过程由本页求齐、割地说明，不把评价另算一件事件。

<a id="note-2"></a>

2. **《春秋·宣公元年》**：“三月，遂以夫人妇姜至自齐。”

<a id="note-3"></a>

3. **《春秋·宣公元年》**：“夏，季孙行父如齐……公会齐侯于平州。公子遂如齐。”  
   **《左传·宣公元年》**详记季文子纳赂请会，平州会“以定公位”，襄仲随后拜成。

<a id="note-4"></a>

4. **《春秋·宣公元年》**：“六月，齐人取济西田。”  
   **《左传·宣公元年》**：“为立公故，以赂齐也。”[卷014齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0608)“齐惠公元元年”中，第一个元为公子元的名字，后面的元年才是纪年，不擅自删字作重复排印错误。惠公实际被立在[前609年](bce-0609.md#event-3)。

<a id="note-5"></a>

5. **《春秋·宣公元年》**：“晋放其大夫胥甲父于卫。”  
   **《左传·宣公元年》**详记晋讨不用命者。

<a id="note-6"></a>

6. **《春秋·宣公元年》**：“秋，邾子来朝。”

<a id="note-7"></a>

7. **《春秋·宣公元年》**：“楚子、郑人侵陈，遂侵宋。”[卷014楚、宋、郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0608)从出兵者和受攻者两面记同一过程。“我”须随国栏转换，不能全当鲁国；背楚、从晋等因由属各方对阵营变化的解释。

<a id="note-8"></a>

8. **《春秋·宣公元年》**：“晋赵盾帅师救陈。宋公、陈侯、卫侯、曹伯会晋师于棐林，伐郑。”  
   [**《左传·宣公元年》**](https://zh.wikisource.org/wiki/春秋左氏傳/宣公#宣公元年)明记“楚蒍贾救郑，遇于北林，囚晋解扬，晋人乃还”。本轮补解扬被俘；卷014晋栏和郑栏所记赵盾伐郑与此合读，不另生一场相同战争。

<a id="note-9"></a>

9. **《春秋·宣公元年》**：“冬，晋赵穿帅师侵崇。晋人、宋人伐郑。”  
   **《左传·宣公元年》**详记晋欲借侵崇求秦成及伐郑报北林之役。秋季伐郑和冬季再伐有明确先后，不因目标同是郑国便删除一次。

<a id="sj014-0608-qin-note"></a>
### 秦共公元年及名字异文

[卷014秦栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0608)记“秦共公和元年”，[卷005 P036—P037](../../sources/摘录/史记-卷005-秦本纪.md#p036)记康公卒、子共公立。前609年的死亡、承位与本年计元相接；共、恭为常见称谓互见。此表名和，经文卒条名稻，正文只称秦共公，不未经校勘替两种名字另造两位秦君。其卒年与桓公纪元又有两套记载，见[前605年](bce-0605.md#note-2)、[前604年](bce-0604.md#sj005-103-note)。

# 公元前609年（鲁文公十八年）

[← 上一张已编年页：公元前610年](bce-0610.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前608年 →](bce-0608.md)

<a id="event-1"></a>

1. **春二月丁丑，鲁文公去世。** 同年秦康公也去世。[[1]](#note-1)

<a id="event-2"></a>

2. **齐懿公早年与邴歜之父争田，即位后掘墓刖尸，又夺阎职之妻，强令二人侍奉自己。** 长期积怨最终酿成弑君。[[2]](#note-2)

<a id="event-3"></a>

3. **夏五月，邴歜、阎职在申池杀死齐懿公，把尸体藏在竹中后逃走。** 齐人随后另立公子元，是为齐惠公。[[3]](#note-3)

<a id="event-4"></a>

4. **六月，鲁国安葬文公；秋，襄仲与叔孙得臣前往齐国，既向新立齐惠公示好，也拜谢齐国参加文公葬礼。** [[4]](#note-4)

<a id="event-5"></a>

5. **文公有两位主要夫人：出姜所生的嫡子恶、视，与敬嬴所生的公子俀。** 敬嬴受宠，长期私下依附襄仲，并把儿子托付给他。[[5]](#note-5)

<a id="event-6"></a>

6. **襄仲决定废嫡立庶，先向新立齐惠公请求支持；齐惠公为了拉拢鲁国，同意。** [[6]](#note-6)

<a id="event-7"></a>

7. **冬十月，襄仲杀死嫡子恶、视，改立敬嬴之子俀，是为鲁宣公。** 经文只写“子卒”，没有直接写出被杀。[[7]](#note-7)

<a id="event-8"></a>

8. **叔仲惠伯奉所谓君命入宫，也被襄仲杀死。** 其家臣公冉务人带家属逃蔡，后来叔仲氏得以恢复。[[8]](#note-8)

<a id="event-9"></a>

9. **文公夫人出姜彻底返回齐国，经过市中痛哭，公开指责襄仲“杀嫡立庶”。** 鲁国继承政变由此成为公开政治创伤。[[9]](#note-9)

<a id="event-10"></a>

10. **季孙行父前往齐国。** 鲁国新政权继续寻求齐国承认。[[10]](#note-10)

<a id="event-11"></a>

11. **莒国太子仆联合国人杀死莒君庶其，并带宝玉来投鲁国。** 宣公想赐邑接纳，季孙行父认为弑父窃宝不可奖励，把他逐出鲁境。[[11]](#note-11)

<a id="event-12"></a>

12. **宋国武氏宗族的内乱在传文中接叙到这一年。** 宋文公诛须及昭公诸子、逐武穆之族的详细纪年另见前606年；这里保留传文间的年次差别，不认作两次相同清洗。[[12]](#note-12)

<a id="event-13"></a>

13. **秦康公去世，共公继位。** 康公在位十二年，其间秦晋互相报复，争取和留住流亡人物也是竞争的一部分。其子共公接位。 [原文与说明](#sj005-100-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·文公十八年》**：“十有八年春，王二月丁丑，公薨于台下。秦伯荦卒。”

<a id="note-2"></a>

2. **《左传·文公十八年》**详记齐懿公与邴歜、阎职旧怨。

<a id="note-3"></a>

3. **《春秋·文公十八年》**：“夏五月戊戌，齐人弑其君商人。”  
   **《左传·文公十八年》**详记申池弑齐懿公及齐人立公子元。

<a id="note-4"></a>

4. **《春秋·文公十八年》**：“六月癸酉，葬我君文公。秋，公子遂、叔孙得臣如齐。”  
   **《左传·文公十八年》**说明齐惠公新立，鲁使且拜葬。

<a id="note-5"></a>

5. **《左传·文公十八年》**详记敬嬴生宣公、私事襄仲，并以宣公属之。

<a id="note-6"></a>

6. **《左传·文公十八年》**详记襄仲请齐侯支持立宣公，齐惠公许之。

<a id="note-7"></a>

7. **《春秋·文公十八年》**：“冬十月，子卒。”  
   **《左传·文公十八年》**：“仲杀恶及视而立宣公。”

<a id="note-8"></a>

8. **《左传·文公十八年》**详记襄仲召叔仲惠伯入而杀之。

<a id="note-9"></a>

9. **《春秋·文公十八年》**：“夫人姜氏归于齐。”  
   **《左传·文公十八年》**详记出姜哭过市，斥“杀適立庶”。

<a id="note-10"></a>

10. **《春秋·文公十八年》**：“季孙行父如齐。”

<a id="note-11"></a>

11. **《春秋·文公十八年》**：“莒弑其君庶其。”  
    **《左传·文公十八年》**详记莒仆弑父携宝来鲁、季文子逐之。

<a id="note-12"></a>

12. **《左传·文公十八年》**篇末详记宋武氏之乱及宋文公清洗武、穆之族。

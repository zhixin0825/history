# 公元前610年（鲁文公十七年）

[← 上一张已编年页：公元前611年](bce-0611.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前609年 →](bce-0609.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **宋国开始以文公鲍元年纪事，晋、卫、陈、郑在春季联合伐宋，追究前一年宋昭公被弑。** 鲍是昭公的弟弟，已经在前一年继位。诸侯最终仍承认宋文公，没有另立新君。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **夏四月，鲁国安葬声姜。** 因齐国威胁，葬礼有所拖延。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **齐国再次进攻鲁国边境，襄仲请求讲和；六月，鲁文公与齐懿公在穀地结盟。** 秋天，文公从穀地返回鲁国。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **晋国在黄父大阅后召集诸侯于扈，调停宋国内乱。** 鲁文公因齐国威胁没有赴会。 [[4]](#reading-note-4)

<a id="event-5"></a>

<a id="reading-event-5"></a>

5. **晋国怀疑郑国两面亲楚，不肯接见郑伯。** 郑大夫子家写长信申辩，强调郑国处在晋楚之间只能服从强者，晋国最终派巩朔与郑讲和。 [[5]](#reading-note-5)

<a id="event-6"></a>

<a id="reading-event-6"></a>

6. **郑国以太子夷、石楚到晋国做人质。** 郑晋关系暂时稳定。 [[6]](#reading-note-6)

<a id="reading-event-7"></a>

7. **晋国也把赵穿、公婿池送到郑国为质。** 晋遣巩朔与郑讲和时，先安排两人留郑；冬十月郑太子夷、石楚再到晋国。双方交换人质，不能只写郑国一方。 [[7]](#reading-note-7)

<a id="event-7"></a>

<a id="reading-event-8"></a>

8. **秋，周大夫甘歜趁戎人饮酒时击败戎军。** [[8]](#reading-note-8)

<a id="event-8"></a>

<a id="reading-event-9"></a>

9. **冬，公子遂前往齐国，拜谢穀地盟约。** 他观察齐懿公言语轻薄，预言齐君将不得善终。 [[9]](#reading-note-9)

## 归年与考证

<a id="history-legacy-source-1"></a>
<a id="note-1"></a>

1. **《春秋·文公十七年》**：“十有七年春，晋人、卫人、陈人、郑人伐宋。”  
   **《左传·文公十七年》**详记讨弑君而仍立文公。[卷014宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0610)明确“宋文公鲍元年，昭公弟”，同格“晋率诸侯平我”与晋栏互见，分别接本条及事件4。死亡、继位在[前611年](bce-0611.md#event-9)，元年不另造一次拥立。

<a id="history-legacy-source-2"></a>
<a id="note-2"></a>

2. **《春秋·文公十七年》**：“夏四月癸亥，葬我小君声姜。”

<a id="history-legacy-source-3"></a>
<a id="note-3"></a>

3. **《春秋·文公十七年》**：“齐侯伐我西鄙。六月癸未，公及齐侯盟于穀。”又记：“秋，公至自穀。”  
   **《左传·文公十七年》**作“齐侯伐我北鄙”。

   **说明：**经文作西鄙，传文作北鄙，正文只写边境，方向差别继续保留。[卷014鲁、齐两栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0610)“齐伐我”“伐鲁”是同一战事互见，不再追加一次进攻。

<a id="history-legacy-source-4"></a>
<a id="note-4"></a>

4. **《春秋·文公十七年》**：“诸侯会于扈。”  
   **《左传·文公十七年》**：“平宋也。公不与会，齐难故也。”[卷014晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0610)概述率诸侯平宋，与春季出兵及后续会盟相接，不把会盟日期自动套给前一场战争。

<a id="history-legacy-source-5"></a>
<a id="note-5"></a>

5. **《左传·文公十七年》**详记郑子家致赵宣子长书、晋巩朔与郑成。

<a id="history-legacy-source-6"></a>
<a id="note-6"></a>

6. **《左传·文公十七年》**：“冬十月，郑大子夷、石楚为质于晋。”

<a id="history-legacy-source-7"></a>
<a id="note-7"></a>

7. **《左传·文公十七年》**：“秋，周甘歜败戎于邥垂，乘其饮酒也。”

<a id="history-legacy-source-8"></a>
<a id="note-8"></a>

8. **《春秋·文公十七年》**：“冬，公子遂如齐。”  
   **《左传·文公十七年》**详记襄仲拜穀盟及预言齐君。预言保留为传世对话，不据此认定有预测君主死亡的能力。

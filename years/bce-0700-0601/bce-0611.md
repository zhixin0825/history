# 公元前611年（鲁文公十六年）

[← 上一张已编年页：公元前612年](bce-0612.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前610年 →](bce-0610.md)

<a id="event-1"></a>

1. **春，季孙行父与齐懿公在阳穀会面，请求正式结盟；齐侯以鲁文公患病为由暂不答应。** [[1]](#note-1)

<a id="event-2"></a>

2. **夏，鲁文公因病连续四个月没有亲自视朔。** 原文只交代四次不视朔及有疾，不据此推断具体病情。[[2]](#note-2)

<a id="event-3"></a>

3. **鲁国派襄仲向齐国送礼，六月终于在郪丘与齐懿公结盟。** 鲁齐关系暂时缓和。[[3]](#note-3)

<a id="event-4"></a>

4. **秋八月，声姜去世；鲁国又拆毁泉台。** [[4]](#note-4)

<a id="event-5"></a>

5. **楚国发生大饥荒，周边戎、麇、百濮等趁机进攻，庸国又率群蛮反楚。** 楚国一度考虑迁都避乱。[[5]](#note-5)

<a id="event-6"></a>

6. **楚国最终决定主动伐庸，并故意连续败退诱使庸军轻敌。** 秦、巴也加入楚军，群蛮重新与楚结盟。[[6]](#note-6)

<a id="event-7"></a>

7. **楚、秦、巴联军最终灭庸。** 楚国从严重内外危机中反而完成一次扩张。[[7]](#note-7)

<a id="event-8"></a>

8. **宋国内部，公子鲍广施恩惠、获得国人支持；宋昭公失去人心，襄夫人又策划杀君。** 饥荒时鲍拿出粮食周济，慰问老人、结交卿大夫，逐渐聚拢支持者。[[8]](#note-8)

<a id="event-9"></a>

9. **冬十一月，宋昭公前往孟诸田猎，途中被襄夫人派来的人杀死。** 司城荡意诸不肯离开国君，也在这次袭击中死去。公子鲍接掌君位，是为宋文公。[[9]](#note-9)

<a id="event-10"></a>

10. **传文另记有蛇从泉宫出来、进入国都。** 原文将蛇的数目比作鲁国先君之数。这是本年所录的异象说法，不把它当成能够预测君主死亡的现代证据。 [看原文与说明](#cq-source-48)

<a id="sj014-0611-cai"></a>

11. **蔡国开始以文侯申元年纪事。** 前一年庄侯去世，儿子申已继位；蔡国的君主更替与同年宋国弑君不是同一类事件。[原文与说明](#sj014-0611-cai-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·文公十六年》**：“十有六年春，季孙行父会齐侯于阳穀，齐侯弗及盟。”  
   **《左传·文公十六年》**：“公有疾……齐侯不肯，曰：‘请俟君閒。’”

<a id="note-2"></a>

2. **《春秋·文公十六年》**：“夏五月，公四不视朔。”  
   **《左传·文公十六年》**：“疾也。”

<a id="note-3"></a>

3. **《春秋·文公十六年》**：“六月戊辰，公子遂及齐侯盟于郪丘。”  
   **《左传·文公十六年》**详记襄仲纳赂。

<a id="note-4"></a>

4. **《春秋·文公十六年》**：“秋八月辛未，夫人姜氏薨。毁泉台。”  
   **《左传·文公十六年》**：“声姜薨，毁泉台。”

<a id="note-5"></a>

5. **《左传·文公十六年》**详记楚大饥、戎与百濮进逼、庸率群蛮叛楚。

<a id="note-6"></a>

6. **《左传·文公十六年》**详记楚军七战皆北以骄庸，并合秦、巴及群蛮。

<a id="note-7"></a>

7. **《春秋·文公十六年》**：“楚人、秦人、巴人灭庸。”[卷014楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0611)“三灭庸”与事件5—7同事，不因秦栏仅记王年就删除经文明确出现的秦军。

<a id="note-8"></a>

8. [**《左传·文公十六年》**](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E6%96%87%E5%85%AC.md#ref-3dd41929ec63a6)详记公子鲍赈贷、赠遗、结交及襄夫人助施。这些是当时声望形成的行动，不代表举行了现代意义的民意调查；前此未确年的争位背景也不全部硬定本年。

<a id="note-9"></a>

9. **《春秋·文公十六年》**：“冬十有一月，宋人弑其君杵臼。”  
   **《左传》**记十一月甲寅将田孟诸未至，夫人王姬“使帅甸攻而杀之”。[卷014宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0611)作“襄夫人使卫伯杀昭公。弟鲍立”。两段均指夫人安排袭击，不把卫伯臆解为卫国国君，更不因执行者称谓不同另造一次死亡。宋文公元年接[前610年](bce-0610.md#event-1)。

<a id="sj014-0611-cai-note"></a>
### 蔡文侯元年

[卷014蔡栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0611)与[《管蔡世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7035.md#ref-779a9a2a7977d6)“庄侯卒，子文侯申立”合读；死亡仍在[前612年](bce-0612.md#sj014-0612-cai)，此处不再记一次初立。

<a id="sj014-0611-qi-note"></a>
### 齐懿公“不得民心”是评价

[卷014齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0611)在懿公二年写“不得民心”，[《齐太公世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7032.md#ref-8c01b52c565d1f)概述其骄而民不附。本页保留这一在位评价，不为它虚构一次本年已经发生的齐国民变；齐懿公遇害的具体故事在[前609年](bce-0609.md#event-2)。

1. **鲁文公患病，鲁齐交涉后盟于郪丘。** 春，季孙行父在阳穀与齐懿公相会求盟，齐以鲁文公有病暂未答应。夏，鲁文公因病四个多月未亲自视朔。鲁遣襄仲送礼，六月两国终于盟于郪丘。 [[1]](#note-1)

<a id="event-4"></a>

2. **秋八月，声姜去世；鲁国又拆毁泉台。** [[2]](#note-4)

<a id="event-5"></a>

<a id="event-6"></a>

<a id="event-7"></a>

3. **楚饥荒引发叛乱，楚秦巴合兵灭庸。** 楚国大饥，戎、麇、百濮来犯，庸国联合群蛮反楚，楚一度议迁都。楚随后发兵攻庸，以一再退败诱其轻敌。群蛮转与楚结盟，楚与秦、巴合兵灭庸。 [[3]](#note-5)

<a id="event-8"></a>

<a id="event-9"></a>

4. **宋襄夫人杀宋昭公，公子鲍继位。** 公子鲍在饥荒时发粮赈济，礼遇老人与卿大夫，获得国人支持。宋昭公渐失人心。十一月，襄夫人派人在昭公赴孟诸田猎途中杀他，司城荡意诸不肯离君，也遇害。鲍继位，是为宋文公。 [[4]](#note-8)

<a id="event-10"></a>

<a id="hs-event-13"></a>

5. **鲁国相传有蛇出自泉宫，进入国都。** [[5]](#note-10)

<a id="sj014-0611-cai"></a>

<a id="event-11"></a>

6. **蔡国开始以文侯申元年纪事。** 前一年庄侯去世，儿子申已继位；蔡国的君主更替与同年宋国弑君不是同一类事件。 [[6]](#note-11)

<a id="sj040-zhuang-admonition-event"></a>

7. **庄王早年的听谏故事，以三年不鸣转向亲政。** 庄王沉迷声色并禁谏，伍举以三年不飞不鸣的鸟作隐语，王答将冲天惊人，数月后仍未改。苏从再冒死进言，庄王才罢游乐、听政，诛罚、进用各数百人，任伍举、苏从掌政，国人欢喜。故事接在庄王三年的灭庸以前，姓名和言语带有传述层次。 [[7]](#sj040-zhuang-admonition-note)

**[《左传》鲁文公16年传文（前611年）](../../sources/春秋左传/有标点原文/bce-0611.md#batch-20261109-t009)**

> 莊王即位三年，不出號令，日夜為樂，令國中曰：「有敢諫者死無赦！」伍舉入諫。莊王左抱鄭姬，右抱越女，坐鐘鼓之閒。伍舉曰：「願有進隱。」曰：「有鳥在於阜，三年不蜚不鳴，是何鳥也？」莊王曰：「三年不蜚，蜚將沖天；三年不鳴，鳴將驚人。舉退矣，吾知之矣。」居數月，淫益甚。大夫蘇從乃入諫。王曰：「若不聞令乎？」對曰：「殺身以明君，臣之願也。」於是乃罷淫樂，聽政，所誅者數百人，所進者數百人，任伍舉、蘇從以政，國人大說。

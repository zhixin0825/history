# 公元前612年（鲁文公十五年）

[← 上一张已编年页：公元前613年](bce-0613.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前611年 →](bce-0611.md)

<a id="event-1"></a>

1. **春，季孙行父赴晋求助，希望晋国帮助解决单伯与子叔姬被齐扣押的问题。** [[1]](#note-1)

<a id="event-2"></a>

2. **三月，宋司马华耦来鲁结盟；夏，曹伯来鲁朝见。** 鲁国继续维持宋、曹关系。[[2]](#note-2)

<a id="event-3"></a>

3. **齐国把公孙敖遗体送回鲁国。** 孟氏经过多次请求，终于获准安葬。[[3]](#note-3)

<a id="event-4"></a>

4. **六月朔日发生日食，鲁国击鼓并在社坛用牲。** 这种处理方式被认为不合诸侯日食礼制。[[4]](#note-4)

<a id="event-5"></a>

5. **单伯获齐国释放，返回鲁国。** [[5]](#note-5)

<a id="event-6"></a>

6. **晋郤缺率军伐蔡并攻入蔡国，原因是蔡国没有参加新城之盟。** 晋军取得城下之盟后退回，蔡国没有在这次进攻中被灭掉。[[6]](#note-6)

<a id="event-7"></a>

7. **秋，齐国侵鲁西境，季孙行父再次赴晋求援。** [[7]](#note-7)

<a id="event-8"></a>

8. **冬，晋、宋、卫、蔡、郑、许、曹在扈地会盟，原本准备讨齐。** 齐国贿赂晋侯，诸侯最终没有出兵。[[8]](#note-8)

<a id="event-9"></a>

9. **十二月，齐国归还子叔姬。** 王室介入最终产生效果。[[9]](#note-9)

<a id="event-10"></a>

10. **齐懿公随即再次侵鲁西境，又伐曹并攻入外城，以惩罚曹国来朝鲁国。** 齐国对外行为越来越强横。[[10]](#note-10)

<a id="sj014-0612-accessions"></a>

11. **周、齐都开始按新君元年计事。** 周顷王的儿子班承王位，是为周匡王；齐国则由弑舍自立的商人执政，是为齐懿公。两人的承位已经在前613年发生，本年元年不代表又有两次即位。[原文与说明](#sj014-0612-accessions-note)

<a id="sj014-0612-cai"></a>

12. **蔡庄侯去世，儿子申继承君位。** 蔡国经历晋军入境后又发生君主更替，申的文侯元年接在下一年。[原文与说明](#sj014-0612-cai-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·文公十五年》**：“十有五年春，季孙行父如晋。”  
   **《左传·文公十五年》**：“为单伯与子叔姬故也。”

<a id="note-2"></a>

2. **《春秋·文公十五年》**：“三月，宋司马华孙来盟。夏，曹伯来朝。”

<a id="note-3"></a>

3. **《春秋·文公十五年》**：“齐人归公孙敖之丧。”  
   **《左传·文公十五年》**详记孟氏请求归葬。

<a id="note-4"></a>

4. **《春秋·文公十五年》**：“六月辛丑朔，日有食之。鼓，用牲于社。”  
   **《左传·文公十五年》**批评其礼制不当。[卷014鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0612)的日食与齐伐鲁分别落本条及事件7、10，不能把同一格内的战争也定在日食当天。

<a id="note-5"></a>

5. **《春秋·文公十五年》**：“单伯至自齐。”

<a id="note-6"></a>

6. **《春秋·文公十五年》**：“晋郤缺帅师伐蔡。戊申，入蔡。”  
   **《左传·文公十五年》**：“新城之盟，蔡人不与”，又记“以城下之盟而还”。[卷014晋、蔡两栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0612)分别写“我入蔡”“晋伐我”，是同一行动，入国不等于灭国。

<a id="note-7"></a>

7. **《春秋·文公十五年》**：“秋，齐人侵我西鄙。季孙行父如晋。”

<a id="note-8"></a>

8. **《春秋·文公十五年》**：“冬十有一月，诸侯盟于扈。”  
   [**《左传·文公十五年》**](https://zh.wikisource.org/wiki/春秋左氏傳/文公#文公十五年)列晋侯、宋公、卫侯、蔡侯、郑伯、许男、曹伯，未列陈侯。本轮删去旧正文误添的陈国，不从相邻年份会盟名单移植参加者。

<a id="note-9"></a>

9. **《春秋·文公十五年》**：“十有二月，齐人来归子叔姬。”

<a id="note-10"></a>

10. **《春秋·文公十五年》**：“齐侯侵我西鄙。遂伐曹，入其郛。”[卷014曹栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0612)同事，不另造一次曹国被攻。

<a id="sj014-0612-accessions-note"></a>
### 周匡王与齐懿公元年

[卷014周、齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0612)分别明记元年；实际继承见[前613年王室](bce-0613.md#sj004-613-1)和[齐国政变](bce-0613.md#event-7)。本页只补纪年衔接，不补无据的登位日。

<a id="sj014-0612-cai-note"></a>
### 蔡庄侯死亡与申继位

[卷014蔡栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0612)列庄侯三十四年及薨；[《管蔡世家》庄侯段](https://zh.wikisource.org/wiki/史記/卷035#莊侯)记三十四年卒、子文侯申立。原文没有死亡月日，也没有说死于晋军进攻，不能因两事在同一格便补出战死因果。[前611年](bce-0611.md#sj014-0611-cai)承接文侯元年。

# 公元前612年（鲁文公十五年）

[← 上一张已编年页：公元前613年](bce-0613.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前611年 →](bce-0611.md)

<a id="event-1"></a>

1. **春，季孙行父赴晋求助，希望晋国帮助解决单伯与子叔姬被齐扣押的问题。** [[1]](#note-1)

<a id="event-2"></a>

2. **三月，宋司马华耦来鲁结盟；夏，曹伯来鲁朝见。** 鲁国继续维持宋、曹关系。[[2]](#note-2)

<a id="event-3"></a>

3. **齐国把公孙敖遗体送回鲁国。** 孟氏经过多次请求，终于获准安葬。[[3]](#note-3)

<a id="event-4"></a>

4. **六月朔日发生日食，鲁国击鼓并在社坛用牲。** 这种处理方式被认为不合诸侯日食礼制。[[4]](#note-4)

<a id="event-5"></a>

5. **单伯获齐国释放，返回鲁国。** [[5]](#note-5)

<a id="event-6"></a>

6. **晋郤缺率军伐蔡并攻入蔡国，原因是蔡国没有参加新城之盟。** 晋国继续整顿亲楚诸侯。[[6]](#note-6)

<a id="event-7"></a>

7. **秋，齐国侵鲁西境，季孙行父再次赴晋求援。** [[7]](#note-7)

<a id="event-8"></a>

8. **冬，晋、宋、卫、蔡、陈、郑、许、曹在扈地会盟，原本准备讨齐。** 齐国贿赂晋侯，诸侯最终没有出兵。[[8]](#note-8)

<a id="event-9"></a>

9. **十二月，齐国归还子叔姬。** 王室介入最终产生效果。[[9]](#note-9)

<a id="event-10"></a>

10. **齐懿公随即再次侵鲁西境，又伐曹并攻入外城，以惩罚曹国来朝鲁国。** 齐国对外行为越来越强横。[[10]](#note-10)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·文公十五年》**：“十有五年春，季孙行父如晋。”  
   **《左传·文公十五年》**：“为单伯与子叔姬故也。”

<a id="note-2"></a>

2. **《春秋·文公十五年》**：“三月，宋司马华孙来盟。夏，曹伯来朝。”

<a id="note-3"></a>

3. **《春秋·文公十五年》**：“齐人归公孙敖之丧。”  
   **《左传·文公十五年》**详记孟氏请求归葬。

<a id="note-4"></a>

4. **《春秋·文公十五年》**：“六月辛丑朔，日有食之。鼓，用牲于社。”  
   **《左传·文公十五年》**批评其礼制不当。

<a id="note-5"></a>

5. **《春秋·文公十五年》**：“单伯至自齐。”

<a id="note-6"></a>

6. **《春秋·文公十五年》**：“晋郤缺帅师伐蔡。戊申，入蔡。”  
   **《左传·文公十五年》**：“新城之盟，蔡人不与。”

<a id="note-7"></a>

7. **《春秋·文公十五年》**：“秋，齐人侵我西鄙。季孙行父如晋。”

<a id="note-8"></a>

8. **《春秋·文公十五年》**：“冬十有一月，诸侯盟于扈。”  
   **《左传·文公十五年》**详记谋伐齐而齐赂晋侯。

<a id="note-9"></a>

9. **《春秋·文公十五年》**：“十有二月，齐人来归子叔姬。”

<a id="note-10"></a>

10. **《春秋·文公十五年》**：“齐侯侵我西鄙。遂伐曹，入其郛。”

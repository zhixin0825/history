# 公元前612年（鲁文公十五年）

[← 上一张已编年页：公元前613年](bce-0613.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前611年 →](bce-0611.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，季孙行父赴晋求助，希望晋国帮助解决单伯与子叔姬被齐扣押的问题。** [[1]](#note-1)

<a id="event-2"></a>

2. **三月，宋司马华耦来鲁结盟；夏，曹伯来鲁朝见。** 鲁国继续维持宋、曹关系。 [[2]](#note-2)

<a id="event-3"></a>

3. **齐国把公孙敖遗体送回鲁国。** 孟氏经过多次请求，终于获准安葬。 [[3]](#note-3)

<a id="event-4"></a>

4. **六月朔日发生日食，鲁国击鼓并在社坛用牲。** 这种处理方式被认为不合诸侯日食礼制。 [[4]](#note-4)

<a id="event-5"></a>

5. **单伯获齐国释放，返回鲁国。** [[5]](#note-5)

<a id="event-6"></a>

6. **晋郤缺率军伐蔡并攻入蔡国，原因是蔡国没有参加新城之盟。** 晋军取得城下之盟后退回，蔡国没有在这次进攻中被灭掉。 [[6]](#note-6)

<a id="event-7"></a>

7. **秋，齐国侵鲁西境，季孙行父再次赴晋求援。** [[7]](#note-7)

<a id="event-8"></a>

8. **冬，晋、宋、卫、蔡、郑、许、曹在扈地会盟，原本准备讨齐。** 齐国贿赂晋侯，诸侯最终没有出兵。 [[8]](#note-8)

<a id="event-9"></a>

9. **十二月，齐国归还子叔姬。** 王室介入最终产生效果。 [[9]](#note-9)

<a id="event-10"></a>

10. **齐懿公随即再次侵鲁西境，又伐曹并攻入外城，以惩罚曹国来朝鲁国。** 齐国对外行为越来越强横。 [[10]](#note-10)

<a id="sj014-0612-accessions"></a>

<a id="event-11"></a>

11. **周、齐都开始按新君元年计事。** 周顷王的儿子班承王位，是为周匡王；齐国则由弑舍自立的商人执政，是为齐懿公。两人的承位已经在前613年发生，本年元年不代表又有两次即位。 [[11]](#note-11)

<a id="sj014-0612-cai"></a>

<a id="event-12"></a>

12. **蔡庄侯去世，儿子申继承君位。** 蔡国经历晋军入境后又发生君主更替，申的文侯元年接在下一年。 [[12]](#note-12)

### 3. 齐国把公孙敖遗体送回鲁国

[返回正文第3条](#event-3)


<!-- century-0700-0601-primary -->

**[《春秋》本年经文](../../sources/春秋左传/有标点原文/bce-0612.md#batch-20261109-j004)**

> 齐人归公孙敖之丧。

**[《左传》本年传文](../../sources/春秋左传/有标点原文/bce-0612.md#batch-20261109-t004)**

> 齐人或为孟氏谋，曰：“鲁，尔亲也。饰棺寘诸堂阜，鲁必取之。”从之。卞人以告。惠叔犹毁以为请，立于朝以待命。许之，取而殡之。齐人送之。书曰：“齐人归公孙敖之丧。”为孟氏，且国故也。葬视共仲。声己不视，帷堂而哭。襄仲欲勿哭，惠伯曰：“丧，亲之终也。虽不能始，善终可也。史佚有言曰：‘兄弟致美。’救乏、贺善、吊灾、祭敬、丧哀，情虽不同，毋绝其爱，亲之道也。子无失道，何怨于人？”襄仲说，帅兄弟以哭之。他年，其二子来，孟献子爱之，闻于国。或谮之曰：“将杀子。”献子以告季文子。二子曰：“夫子以爱我闻，我以将杀子闻，不亦远于礼乎？远礼不如死。”一人门于句鼆，一人门于戾丘，皆死。

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·文公十五年》**：“十有五年春，季孙行父如晋。”  
   **《左传·文公十五年》**：“为单伯与子叔姬故也。”

<a id="history-legacy-source-2"></a>


2. **《春秋·文公十五年》**：“三月，宋司马华孙来盟。夏，曹伯来朝。”

<a id="history-legacy-source-3"></a>


3. **《春秋·文公十五年》**：“齐人归公孙敖之丧。”  
   **《左传·文公十五年》**详记孟氏请求归葬。

<a id="history-legacy-source-4"></a>


4. **《春秋·文公十五年》**：“六月辛丑朔，日有食之。鼓，用牲于社。”  
   **《左传·文公十五年》**批评其礼制不当。[卷014鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0612)的日食与齐伐鲁分别落本条及事件7、10，不能把同一格内的战争也定在日食当天。

<a id="history-legacy-source-5"></a>


5. **《春秋·文公十五年》**：“单伯至自齐。”

<a id="history-legacy-source-6"></a>


6. **《春秋·文公十五年》**：“晋郤缺帅师伐蔡。戊申，入蔡。”  
   **《左传·文公十五年》**：“新城之盟，蔡人不与”，又记“以城下之盟而还”。[卷014晋、蔡两栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0612)分别写“我入蔡”“晋伐我”，是同一行动，入国不等于灭国。

<a id="history-legacy-source-7"></a>


7. **《春秋·文公十五年》**：“秋，齐人侵我西鄙。季孙行父如晋。”

<a id="history-legacy-source-8"></a>


8. **《春秋·文公十五年》**：“冬十有一月，诸侯盟于扈。”  
   [**《左传·文公十五年》**](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E6%96%87%E5%85%AC.md#ref-9fd5122160fcf5)列晋侯、宋公、卫侯、蔡侯、郑伯、许男、曹伯，未列陈侯。本轮删去旧正文误添的陈国，不从相邻年份会盟名单移植参加者。

<a id="history-legacy-source-9"></a>


9. **《春秋·文公十五年》**：“十有二月，齐人来归子叔姬。”

<a id="history-legacy-source-10"></a>


10. **《春秋·文公十五年》**：“齐侯侵我西鄙。遂伐曹，入其郛。”[卷014曹栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0612)同事，不另造一次曹国被攻。

<a id="sj014-0612-cai-note"></a>
<a id="蔡庄侯死亡与申继位"></a>
#### 蔡庄侯死亡与申继位

[卷014蔡栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0612)列庄侯三十四年及薨；[《管蔡世家》庄侯段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7035.md#ref-e009cb9b88a5f1)记三十四年卒、子文侯申立。原文没有死亡月日，也没有说死于晋军进攻，不能因两事在同一格便补出战死因果。[前611年](bce-0611.md#sj014-0611-cai)承接文侯元年。

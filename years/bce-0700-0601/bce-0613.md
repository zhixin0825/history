# 公元前613年（鲁文公十四年）

[← 上一张已编年页：公元前614年](bce-0614.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前612年 →](bce-0612.md)

<a id="event-1"></a>

1. **春，鲁文公从晋国返回；邾国因鲁使此前吊丧失礼，出兵攻鲁南境，鲁叔彭生率军反击。** [[1]](#note-1)

<a id="event-2"></a>

2. **周顷王去世，但王室因周公阅与王孙苏争权，没有向诸侯正式报丧，因此鲁史经文没有直接记王崩。** [[2]](#note-2)

顷王死后，儿子班继位，即匡王。 [卷四互见与归年](#sj004-613-1)

<a id="event-3"></a>

3. **夏五月，齐昭公去世，其子舍即位。** 舍的母亲叔姬无宠，舍在齐国也缺乏政治威望；公子商人却长期施惠、聚士，家财用尽以后又向公家借贷，继续经营自己的支持者。[[3]](#note-3)

<a id="event-4"></a>

4. **六月，鲁文公与宋、陈、卫、郑、许、曹及晋赵盾在新城举行大规模同盟。** 这次盟会让此前亲楚诸侯重新服从晋国体系，同时也处理邾国继承问题；会盟结束后，文公返回鲁国。[[4]](#note-4)

<a id="event-5"></a>

5. **秋七月，彗星进入北斗。** 周内史叔服把它解释为不出七年，宋、齐、晋君主将死于乱事。[[5]](#note-5)

<a id="event-6"></a>

6. **晋赵盾率诸侯军准备把捷菑送回邾国争位，最后退军。** 邾文公去世后，邾人已立齐姜所生的貜且，晋姬所生的捷菑则逃晋求援。赵盾带来所报八百乘军队，邾人以貜且年长为由拒绝；赵盾承认理由顺当，没有强行换君。[[6]](#note-6)

<a id="event-7"></a>

7. **齐国公子商人发动政变，杀死齐君舍，自立为齐懿公。** 他曾向另一位公子元让位，元拒绝；商人于是占据君位。[[7]](#note-7)

<a id="event-8"></a>

8. **九月，公孙敖死于齐国。** 鲁国拒绝立即让其归葬。[[8]](#note-8)

<a id="event-9"></a>

9. **宋子哀因不认同宋公政治出奔鲁国。** [[9]](#note-9)

<a id="event-10"></a>

10. **冬，鲁国经王室向齐求助，单伯赴齐请求放回子叔姬，反被扣押。** 齐国又扣住子叔姬，鲁齐关系急剧恶化。[[10]](#note-10)

<a id="event-11"></a>

11. **楚国进入庄王元年，公子燮、鬥克趁大臣出征发动叛乱。** 两人奉命留守，却图谋攻杀出征的子孔；后来又带楚王出走，准备前往商密，最终被庐戢黎、叔麇诱杀。新王的初政并不安稳。[[11]](#note-11)

<a id="event-12"></a>

12. **周王室争政案诉至晋国，赵盾调处以后将有关人员送回。** 周公阅与王孙苏本要到晋国争讼，周王转而疏远王孙苏，让尹氏、聃启同周公在晋国对诉。赵盾居中平定王室争端，使其复归。 [看原文与说明](#cq-source-47)

<a id="sj014-0613-chen"></a>

13. **陈灵公平国元年。** 前一年陈共公朔去世后，儿子平国继承陈国君位，本年开始计陈灵公元年。[[13]](#sj014-0613-chen-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·文公十四年》**：“十有四年春，王正月，公至自晋。邾人伐我南鄙。叔彭生帅师伐邾。”  
   **《左传》**说明邾因鲁吊丧不敬来讨。

<a id="note-2"></a>

2. **《左传·文公十四年》**：“顷王崩。周公阅与王孙苏争政，故不赴。”[卷014周栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0613)同事。“不书”指鲁史经文的记录规则，不是本项目年页也不能收录。

<a id="sj004-613-1"></a>
#### 顷王之后由匡王班接位｜卷四互见

[卷004 P052](../../sources/摘录/史记-卷004-周本纪.md#p052)。本纪顷王六年依其前文积年会提前至前614；此处按《左传》文公十四年的明确叙述归前613。匡王元年另在前612年，不重记继位。

<a id="note-3"></a>

3. **《春秋·文公十四年》**：“夏五月乙亥，齐侯潘卒。”  
   **《左传》**详记舍即位、商人施惠聚士。[卷014齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0613)概称杀太子，与经传已称舍为君的阶段有简详差别。

<a id="note-4"></a>

4. **《春秋·文公十四年》**：“六月，公会宋公、陈侯、卫侯、郑伯、许男、曹伯、晋赵盾，癸酉，同盟于新城。”又记：“公至自会。”  
   **《左传》**：“从于楚者服，且谋邾也。”

<a id="note-5"></a>

5. **《春秋·文公十四年》**：“秋七月，有星孛入于北斗。”[卷014鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0613)兼记七年内三君死乱的预言，与《左传》叔服之言互见。天象与预言分层，不用后来弑君的结果反证天象真能预测政治。

<a id="note-6"></a>

6. **《春秋·文公十四年》**：“晋人纳捷菑于邾，弗克纳。”  
   [**《左传》**](https://zh.wikisource.org/wiki/春秋左氏傳/文公#文公十四年)详记两位公子的母系、长幼与赵盾退兵。[卷014晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0613)“纳捷菑”不能单独读成已成功；八百乘为文本所报，未折算实兵。邾文公死在前614，逃晋是此前后继承的背景，不为两子另造出生年。

<a id="note-7"></a>

7. **《春秋·文公十四年》**：“齐公子商人弑其君舍。”传文系秋七月乙卯夜，又说明后来齐人告难“故书以九月”。《齐太公世家》另有十月墓上弑舍的记载。本页保留本年主述，月次差别和赴告机制留注，不用经文排在九月就改成又一场政变。[世家](https://zh.wikisource.org/wiki/史記/卷032#齊昭公)。

<a id="note-8"></a>

8. **《春秋·文公十四年》**：“九月甲申，公孙敖卒于齐。”

<a id="note-9"></a>

9. **《春秋·文公十四年》**：“宋子哀来奔。”

<a id="note-10"></a>

10. **《春秋·文公十四年》**：“冬，单伯如齐。齐人执单伯。齐人执子叔姬。”传文详记襄仲告王、请借王宠求昭姬。正文不再把这个过程简写为已经核实的一份“鲁国和王室共同任命”诏令；单伯的身份问题不靠一句如齐定案。

<a id="note-11"></a>

11. **《左传·文公十四年》**详记楚庄王初立、二子留守作乱、八月带王出走及被诱杀。[卷014楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0613)明确庄王侶元年；侣、旅为传本文字互见，不造两个楚王。鬥克也称子仪，与周、郑人物的同称分开。旧怨来自此前囚秦后求成未得志及公子燮求令尹不得，不能一律写成元年新发生的任免。

<a id="sj014-0613-chen-note"></a>

13. [**卷014陈栏**](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0613)“陈灵公平国元年”；[《陈杞世家》](https://zh.wikisource.org/wiki/史記/卷036)记共公十八年卒、子灵公平国立。共公死亡见[前614年](bce-0614.md#event-2)，元年不另定登位日。

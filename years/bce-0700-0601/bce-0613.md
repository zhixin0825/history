# 公元前613年（鲁文公十四年）

[← 上一张已编年页：公元前614年](bce-0614.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前612年 →](bce-0612.md)

<a id="event-1"></a>

1. **春，鲁文公从晋国返回；邾国因鲁使此前吊丧失礼，出兵攻鲁南境，鲁叔彭生率军反击。** [[1]](#note-1)

<a id="event-2"></a>

2. **周顷王去世，但王室因周公阅与王孙苏争权，没有向诸侯正式报丧，因此鲁国年表没有直接记王崩。** [[2]](#note-2)

<a id="event-3"></a>

3. **夏五月，齐昭公去世，其子舍即位。** 舍的母亲叔姬无宠，舍在齐国也缺乏政治威望。[[3]](#note-3)

<a id="event-4"></a>

4. **六月，鲁文公与宋、陈、卫、郑、许、曹及晋赵盾在新城举行大规模同盟。** 这次盟会让此前亲楚诸侯重新服从晋国体系，同时也处理邾国继承问题；会盟结束后，文公返回鲁国。[[4]](#note-4)

<a id="event-5"></a>

5. **秋七月，彗星进入北斗。** 周内史叔服预言数年内宋、齐、晋君主将死于乱事。[[5]](#note-5)

<a id="event-6"></a>

6. **晋赵盾率诸侯军准备把捷菑送回邾国争位，但邾人以嫡长秩序拒绝；赵盾认为对方理由正当，主动退军。** [[6]](#note-6)

<a id="event-7"></a>

7. **齐国公子商人发动政变，杀死齐君舍，自立为齐懿公。** [[7]](#note-7)

<a id="event-8"></a>

8. **九月，公孙敖死于齐国。** 鲁国拒绝立即让其归葬。[[8]](#note-8)

<a id="event-9"></a>

9. **宋子哀因不认同宋公政治出奔鲁国。** [[9]](#note-9)

<a id="event-10"></a>

10. **冬，单伯奉鲁国和王室之命赴齐请求释放子叔姬，齐国把单伯和子叔姬一起扣押。** 鲁齐关系急剧恶化。[[10]](#note-10)

<a id="event-11"></a>

11. **楚庄王即位初期，公子燮、鬥克发动叛乱，最终被诱杀。** 楚国内部也经历新君继位后的权力清洗。[[11]](#note-11)

<a id="event-12"></a>

12. **周王室争政案诉至晋国，赵盾调处以后将有关人员送回。** 周公阅与王孙苏本要到晋国争讼，周王转而疏远王孙苏，让尹氏、聃启同周公在晋国对诉。赵盾居中平定王室争端，使其复归。 [看原文与说明](#cq-source-47)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·文公十四年》**：“十有四年春，王正月，公至自晋。邾人伐我南鄙。叔彭生帅师伐邾。”  
   **《左传·文公十四年》**说明邾因鲁吊丧不敬来讨。

<a id="note-2"></a>

2. **《左传·文公十四年》**：“顷王崩。周公阅与王孙苏争政，故不赴。”

<a id="note-3"></a>

3. **《春秋·文公十四年》**：“夏五月乙亥，齐侯潘卒。”  
   **《左传·文公十四年》**详记舍即位。

<a id="note-4"></a>

4. **《春秋·文公十四年》**：“六月，公会宋公、陈侯、卫侯、郑伯、许男、曹伯、晋赵盾，癸酉，同盟于新城。”又记：“公至自会。”  
   **《左传·文公十四年》**：“从于楚者服，且谋邾也。”

<a id="note-5"></a>

5. **《春秋·文公十四年》**：“秋七月，有星孛入于北斗。”

<a id="note-6"></a>

6. **《春秋·文公十四年》**：“晋人纳捷菑于邾，弗克纳。”  
   **《左传·文公十四年》**详记赵盾闻邾人辞顺而还。

<a id="note-7"></a>

7. **《春秋·文公十四年》**：“齐公子商人弑其君舍。”

<a id="note-8"></a>

8. **《春秋·文公十四年》**：“九月甲申，公孙敖卒于齐。”

<a id="note-9"></a>

9. **《春秋·文公十四年》**：“宋子哀来奔。”

<a id="note-10"></a>

10. **《春秋·文公十四年》**：“冬，单伯如齐。齐人执单伯。齐人执子叔姬。”  
    **《左传·文公十四年》**详记鲁向王室求助请昭姬。

<a id="note-11"></a>

11. **《左传·文公十四年》**详记楚庄王初立、公子燮与鬥克作乱并被杀。

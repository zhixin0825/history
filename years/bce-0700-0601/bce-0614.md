# 公元前614年（鲁文公十三年）

[← 上一张已编年页：公元前615年](bce-0615.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前613年 →](bce-0613.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **晋国借魏寿馀假意背晋的计划，将士会从秦国接回。** 晋国卿大夫商议后，让魏寿馀假装带魏地投秦，实际把他的家属留在晋。秦康公答应出面，士会奉派渡河同魏地官员说话；魏寿馀事先给他暗示，士会过河后被晋人接回。秦国随后归还其家属。 [[1]](#note-1)

<a id="event-2"></a>

2. **五月，陈侯朔去世；邾文公也在迁都绎地后去世。** 邾文公明知迁都可能不利自己，仍以“利民”为先决定迁徙。 [[2]](#note-2)

<a id="event-3"></a>

3. **从正月到秋七月，鲁国长期不雨；七月太庙屋顶又倒塌。** [[3]](#note-3)

<a id="event-4"></a>

4. **冬，鲁文公前往晋国朝见并重申盟约。** [[4]](#note-4)

<a id="event-5"></a>

5. **卫侯在沓地会见文公，请鲁国帮助向晋讲和。** 文公答应调停。 [[5]](#note-5)

<a id="event-6"></a>

6. **文公从晋返回途中，郑伯又在棐地会见他，也请求鲁国调解郑晋关系。** 鲁国同时为卫、郑向晋斡旋。 [[6]](#note-6)

<a id="event-7"></a>

7. **十二月，鲁文公与晋侯正式结盟。** [[7]](#note-7)

<a id="event-8"></a>

8. **狄人侵卫。** 卫国在谋求晋国和解的同时仍面对北方压力。 [[8]](#note-8)

<a id="event-9"></a>

9. **春，晋国派詹嘉驻守瑕，守备桃林之塞。** 这是一项边塞驻防任命，与夏季诱回士会的行动分开保存。 [[9]](#note-9)

#### 核对18｜晋国借魏寿馀假意背晋的计划，将士会从秦国接回

**说明：**原文此年只称秦伯；秦穆公已于前621年去世，不能在前614年继续出场。绕朝赠策的旧段一并保留在引文，不凭赠策形制增加细节。

<details>
<summary>传 T002｜原文</summary>

> 晋人患秦之用士会也，夏，六卿相见于诸浮。赵宣子曰：“随会在秦，贾季在狄，难日至矣，若之何？”中行桓子曰：“请复贾季，能外事，且由旧勋。”郤成子曰：“贾季乱，且罪大，不如随会，能贱而有耻，柔而不犯，其知足使也，且无罪。”乃使魏寿馀伪以魏叛者以诱士会，执其帑于晋，使夜逸。请自归于秦，秦伯许之。履士会之足于朝。秦伯师于河西，魏人在东。寿馀曰：“请东人之能与夫二三有司言者，吾与之先。”使士会。士会辞曰：“晋人，虎狼也，若背其言，臣死，妻子为戮，无益于君，不可悔也。”秦伯曰：“若背其言，所不归尔帑者，有如河。”乃行。绕朝赠之以策，曰：“子无谓秦无人，吾谋適不用也。”既济，魏人噪而还。秦人归其帑。其处者为刘氏。

[本段出处](../../sources/春秋左传/有标点原文/bce-0614.md#t002)

</details>

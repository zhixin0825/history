# 公元前614年（鲁文公十三年）

[← 上一张已编年页：公元前615年](bce-0615.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前613年 →](bce-0613.md)

<a id="event-1"></a>

1. **晋国担心士会长期在秦国效力，设计让魏寿馀假装叛晋，把士会诱回晋国。** 秦穆公虽有所怀疑，仍允许士会前往河东谈判，士会最终渡河回晋。[1]

<a id="event-2"></a>

2. **五月，陈侯朔去世；邾文公也在迁都绎地后去世。** 邾文公明知迁都可能不利自己，仍以“利民”为先决定迁徙。[2]

<a id="event-3"></a>

3. **从正月到秋七月，鲁国长期不雨；七月太庙屋顶又倒塌。** [3]

<a id="event-4"></a>

4. **冬，鲁文公前往晋国朝见并重申盟约。** [4]

<a id="event-5"></a>

5. **卫侯在沓地会见文公，请鲁国帮助向晋讲和。** 文公答应调停。[5]

<a id="event-6"></a>

6. **文公从晋返回途中，郑伯又在棐地会见他，也请求鲁国调解郑晋关系。** 鲁国同时为卫、郑向晋斡旋。[6]

<a id="event-7"></a>

7. **十二月，鲁文公与晋侯正式结盟。** [7]

<a id="event-8"></a>

8. **狄人侵卫。** 卫国在谋求晋国和解的同时仍面对北方压力。[8]

## 本年相关史料

<a id="note-1"></a>

1. **《左传·文公十三年》**详记晋用魏寿馀诈叛诱士会归晋。

<a id="note-2"></a>

2. **《春秋·文公十三年》**：“夏五月壬午，陈侯朔卒。邾子蘧蒢卒。”  
   **《左传·文公十三年》**详记邾文公迁绎、五月卒。

<a id="note-3"></a>

3. **《春秋·文公十三年》**：“自正月不雨至于秋七月。大室屋坏。”

<a id="note-4"></a>

4. **《春秋·文公十三年》**：“冬，公如晋。”

<a id="note-5"></a>

5. **《春秋·文公十三年》**：“卫侯会公于沓。”  
   **《左传·文公十三年》**：“请平于晋。”

<a id="note-6"></a>

6. **《春秋·文公十三年》**：“公还自晋。郑伯会公于棐。”  
   **《左传·文公十三年》**：“亦请平于晋。公皆成之。”

<a id="note-7"></a>

7. **《春秋·文公十三年》**：“十有二月己丑，公及晋侯盟。”

<a id="note-8"></a>

8. **《春秋·文公十三年》**：“狄侵卫。”

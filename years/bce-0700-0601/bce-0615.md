# 公元前615年（鲁文公十二年）

[← 上一张已编年页：公元前616年](bce-0616.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前614年 →](bce-0614.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，郕国内乱后，太子带着夫钟、郕邽两地来投鲁国。** 经文把他记作“郕伯来奔”，鲁国以诸侯之礼迎接。 [[1]](#note-1)

<a id="event-2"></a>

2. **杞桓公首次来朝鲁文公，并请求与叔姬解除婚姻关系但保持两国婚姻往来。** 二月，叔姬去世。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，楚国因群舒叛乱出兵，抓获舒子平等并包围巢国。** [[3]](#note-3)

<a id="event-4"></a>

4. **秋，滕昭公首次来鲁朝见。** [[4]](#note-4)

<a id="event-5"></a>

5. **秦康公派西乞术来鲁聘问，并公开表示准备再次伐晋。** 鲁国以厚礼相待。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬，秦晋在河曲交战。** 晋军采取深沟固垒拖疲秦军的策略，秦方则试图诱发晋将赵穿轻进。 [[6]](#note-6)

<a id="event-7"></a>

7. **赵穿擅自出战，迫使晋军全面跟进；双方交锋后秦军夜间撤走，又转攻晋地瑕。** 河曲之战没有形成决定性胜负。 [[7]](#note-7)

<a id="event-8"></a>

8. **冬，季孙行父率军修筑诸、郓两地。** 工程发生在适宜时节。 [[8]](#note-8)

<a id="event-9"></a>

9. **楚令尹大孙伯去世，成嘉继任。** 传文把令尹更替与群舒叛楚连续记载，本年之后的征舒、围巢由新局势展开。 [[9]](#note-9)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·文公十二年》**：“十有二年春，王正月，郕伯来奔。”  
   **《左传·文公十二年》**详记郕伯卒后太子以夫钟、郕邽来奔。

   **说明：** 经文称“郕伯来奔”，传文叙事则把来奔者解释为郕太子；正文按传文关系叙述，并在此保留称谓差异。

<a id="history-legacy-source-2"></a>


2. **《春秋·文公十二年》**：“杞伯来朝。二月庚子，子叔姬卒。”  
   **《左传·文公十二年》**详记杞桓公请绝叔姬而不断婚。

<a id="history-legacy-source-3"></a>


3. **《春秋·文公十二年》**：“夏，楚人围巢。”  
   **《左传·文公十二年》**详记群舒叛楚、楚围巢。

<a id="history-legacy-source-4"></a>


4. **《春秋·文公十二年》**：“秋，滕子来朝。”

<a id="history-legacy-source-5"></a>


5. **《春秋·文公十二年》**：“秦伯使术来聘。”  
   **《左传·文公十二年》**详记西乞术来聘且言将伐晋。

<a id="history-legacy-source-6"></a>


6. **《春秋·文公十二年》**：“冬十有二月戊午，晋人、秦人战于河曲。”  
   **《左传·文公十二年》**详记臾骈固军待秦、秦谋诱赵穿。

<a id="history-legacy-source-7"></a>


7. **《左传·文公十二年》**详记赵穿独出、晋军接战、秦军夜遁并入瑕。

<a id="history-legacy-source-8"></a>


8. **《春秋·文公十二年》**：“季孙行父帅师城诸及郓。”  
   **《左传·文公十二年》**：“书时也。”

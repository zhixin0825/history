# 公元前616年（鲁文公十一年）

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，楚国出兵伐麇，先在防渚击败麇军，又推进到钖穴。** 楚国继续整合汉水周边小国。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，鲁叔彭生与晋郤缺在承筐会面，商议如何对付依附楚国的诸侯。** 晋楚竞争仍在持续。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋，曹文公来鲁朝见。** 他即位后主动来鲁建立关系。 [[3]](#note-3)

<a id="event-4"></a>

4. **公子遂前往宋国聘问。** 同时就宋司城荡意诸出奔鲁国一事协调善后。 [[4]](#note-4)

<a id="event-5"></a>

<a id="event-6"></a>

<a id="event-7"></a>

<a id="hs-event-9"></a>

5. **狄侵齐鲁，鲁军在咸击败狄军。** 狄人先侵齐，继而进犯鲁国。十月，鲁军在咸击败狄军，杀死长狄侨如。鄋瞒此前也曾与宋、齐、卫、晋交战。 [[5]](#note-5)

<a id="event-8"></a>

6. **郕国太子朱儒自居夫钟，但国人没有支持他。** 郕国内部仍然不稳。 [[6]](#note-8)

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·文公十一年》**：“十有一年春，楚子伐麇。”  
   **《左传·文公十一年》**详记成大心、潘崇两次伐麇。

<a id="history-legacy-source-2"></a>

2. **《春秋·文公十一年》**：“夏，叔彭生会晋郤缺于承筐。”  
   **《左传·文公十一年》**：“谋诸侯之从于楚者。”

<a id="history-legacy-source-3"></a>

3. **《春秋·文公十一年》**：“秋，曹伯来朝。”  
   **《左传·文公十一年》**：“即位而来见也。”

<a id="history-legacy-source-4"></a>

4. **《春秋·文公十一年》**：“公子遂如宋。”

<a id="history-legacy-source-5"></a>

5. **《春秋·文公十一年》**：“狄侵齐。”  
   **《左传·文公十一年》**又记鄋瞒遂伐鲁。

<a id="history-legacy-source-6"></a>

6. **《春秋·文公十一年》**：“冬十月甲午，叔孙得臣败狄于鹹。”  
   **《左传·文公十一年》**详记获长狄侨如。

<a id="history-legacy-source-7"></a>

7. **《左传·文公十一年》**回顾鄋瞒、长狄缘斯、焚如、荣如、简如等先后被诸国捕获。
   **纪年冲突：**[《十二诸侯年表》前616年宋栏](../../拆分史书/史记/卷014.md#y0616)与[《宋微子世家》宋昭公四年](../../拆分史书/史记/卷038.md#part-1-text)均将宋军败长狄缘斯于长丘系于昭公四年；但[《左传·文公十一年》](../../拆分史书/左传/异本/春秋左氏傳-文公.md#%E6%96%87%E5%85%AC%E5%8D%81%E4%B8%80%E5%B9%B4)明用“初，宋武公之世”引出同一长丘战的回叙。两者距离相差甚远；本年正文只承认《左传》在此处回顾旧事，暂不把长丘战定为前616年新战，也不抹除《史记》所系昭公四年。

<a id="history-legacy-source-8"></a>

8. **《左传·文公十一年》**：“郕大子朱儒自安于夫钟，国人弗徇。”

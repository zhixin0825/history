# 公元前616年（鲁文公十一年）

[← 上一张已编年页：公元前617年](bce-0617.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前615年 →](bce-0615.md)

<a id="event-1"></a>

1. **春，楚国出兵伐麇，先在防渚击败麇军，又推进到钖穴。** 楚国继续整合汉水周边小国。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，鲁叔彭生与晋郤缺在承筐会面，商议如何对付依附楚国的诸侯。** 晋楚竞争仍在持续。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，曹文公来鲁朝见。** 他即位后主动来鲁建立关系。[[3]](#note-3)

<a id="event-4"></a>

4. **公子遂前往宋国聘问。** 同时就宋司城荡意诸出奔鲁国一事协调善后。[[4]](#note-4)

<a id="event-5"></a>

5. **狄人先侵齐，随后又侵鲁。** 鲁文公命叔孙得臣追击。[[5]](#note-5)

<a id="event-6"></a>

6. **冬十月，鲁军在咸地击败狄军，杀死长狄侨如。** 鲁国把侨如首级埋在子驹之门，作为战功象征。[[6]](#note-6)

<a id="event-7"></a>

7. **传文回叙并预叙长狄与宋、齐、卫、晋的交战，多名首领先后被捕杀；传文接着总述鄋瞒势力最终消失。** [[7]](#note-7)

<a id="event-8"></a>

8. **郕国太子朱儒自居夫钟，但国人没有支持他。** 郕国内部仍然不稳。[[8]](#note-8)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·文公十一年》**：“十有一年春，楚子伐麇。”  
   **《左传·文公十一年》**详记成大心、潘崇两次伐麇。

<a id="note-2"></a>

2. **《春秋·文公十一年》**：“夏，叔彭生会晋郤缺于承筐。”  
   **《左传·文公十一年》**：“谋诸侯之从于楚者。”

<a id="note-3"></a>

3. **《春秋·文公十一年》**：“秋，曹伯来朝。”  
   **《左传·文公十一年》**：“即位而来见也。”

<a id="note-4"></a>

4. **《春秋·文公十一年》**：“公子遂如宋。”

<a id="note-5"></a>

5. **《春秋·文公十一年》**：“狄侵齐。”  
   **《左传·文公十一年》**又记鄋瞒遂伐鲁。

<a id="note-6"></a>

6. **《春秋·文公十一年》**：“冬十月甲午，叔孙得臣败狄于鹹。”  
   **《左传·文公十一年》**详记获长狄侨如。

<a id="note-7"></a>

7. **《左传·文公十一年》**回顾鄋瞒、长狄缘斯、焚如、荣如、简如等先后被诸国捕获。
   **纪年冲突：**[《十二诸侯年表》前616年宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0616)与[《宋微子世家》宋昭公四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7038.md#ref-39cc1c2e9948c8)均将宋军败长狄缘斯于长丘系于昭公四年；但[《左传·文公十一年》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E6%96%87%E5%85%AC.md#ref-bd1aa583f6a70d)明用“初，宋武公之世”引出同一长丘战的回叙。两者距离相差甚远；本年正文只承认《左传》在此处回顾旧事，暂不把长丘战定为前616年新战，也不抹除《史记》所系昭公四年。

<a id="note-8"></a>

8. **《左传·文公十一年》**：“郕大子朱儒自安于夫钟，国人弗徇。”

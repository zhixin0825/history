# 公元前617年（鲁文公十年）

[← 上一张已编年页：公元前618年](bce-0618.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前616年 →](bce-0616.md)

<a id="event-1"></a>

1. **春，臧文仲去世。** 鲁国失去一位长期参与内政、外交的重要卿大夫。[[1]](#note-1)

<a id="event-2"></a>

2. **春，晋国进攻秦国，夺取少梁；夏天秦国反击，夺取北徵。** 秦晋边境战争继续你来我往。[[2]](#note-2)

[补充史料与年次说明](#sj005-097-note)


<a id="event-3"></a>

3. **楚穆王清算旧臣，杀鬥宜申和仲归。** 两人曾参与楚成王末年的权力斗争，楚国新君进一步巩固政权。[[3]](#note-3)

<a id="event-4"></a>

4. **从正月到秋七月，鲁国长期不雨。** [[4]](#note-4)

<a id="event-5"></a>

5. **秋，鲁国与苏子在女栗结盟，背景是周顷王新立。** 鲁国继续修补与王室诸臣关系。[[5]](#note-5)

<a id="event-6"></a>

6. **冬，狄人侵宋。** 宋国北方安全受威胁。[[6]](#note-6)

<a id="event-7"></a>

7. **楚王与蔡侯驻厥貉，准备伐宋；宋国主动出迎楚王、听从命令，战争暂时避免。** 楚国在中原的影响继续扩大。[[7]](#note-7)

<a id="event-8"></a>

8. **陈侯、郑伯也在息地会见楚王。** 多个中原诸侯开始向楚靠拢。[[8]](#note-8)

<a id="event-9"></a>

9. **曹文公寿开始纪年，前617年是他的元年。** 曹共公襄在上一年去世，曹国进入新君时期。[[9]](#note-9)

# 公元前618年（鲁文公九年）

[← 上一张已编年页：公元前619年](bce-0619.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前617年 →](bce-0617.md)

<a id="event-1"></a>

1. **春，周王室在襄王未葬前派毛伯来鲁求金。** 这种直接索取财物被认为不合礼。[[1]](#note-1)

<a id="event-2"></a>

2. **夫人姜氏前往齐国，三月返回；叔孙得臣则赴京师参加周襄王葬礼。** 鲁国同时维持齐、周两条外交线。[[2]](#note-2)

<a id="event-3"></a>

3. **晋国清洗上一年作乱大夫：先都、梁益耳、士縠、箕郑父、蒯得等先后被杀。** 晋国内部赵盾权力进一步稳固。[[3]](#note-3)

**春正月，晋国先克被刺杀，随后才有对作乱诸臣的处置。** 晋国相继杀先都、梁益耳等人的经过，须与先克先被杀的起因连读，不能只留下处死名单。 [看原文与说明](#cq-source-43)

<a id="event-4"></a>

4. **楚穆王听取范山建议，出兵伐郑。** 范山指出晋君年幼，楚国可以向北行动。楚军驻于狼渊，俘虏郑公子坚、公子尨及乐耳，郑国随后与楚讲和。 [看原文与说明](#cq-source-17)

<a id="event-5"></a>

5. **鲁公子遂会同晋、宋、卫、许军队救郑，但行动迟缓，没有追上楚军。** [[5]](#note-5)

<a id="event-6"></a>

6. **夏，狄人侵齐。** 楚军同时又侵陈，陈国随后也被迫与楚讲和。[[6]](#note-6)

**夏秋之间，陈国与楚军先后交战，最终才求和。** 夏季楚军侵陈、攻取壶丘，报复陈国依晋；秋季楚公子朱从东夷方向攻陈，却被陈军击败，公子茷被俘。陈人担心楚国继续报复，随后与楚讲和。 [看原文与说明](#cq-source-44)

<a id="event-7"></a>

7. **秋八月，曹伯襄去世；九月发生地震。** [[7]](#note-7)

<a id="event-8"></a>

8. **冬，楚国越椒来鲁聘问，但态度傲慢。** 鲁大夫已预言若敖氏将因骄傲而亡。[[8]](#note-8)

<a id="event-9"></a>

9. **秦国送来僖公、成风的丧服礼物；鲁国又安葬曹共公。** 秦鲁旧好仍被维持。[[9]](#note-9)

<a id="event-10"></a>

10. **周顷王壬臣开始纪年，本年为顷王元年。** 周襄王在前619年去世，壬臣此前已经继承王位；本年记的是新君元年，不是另一次即位。[[10]](#note-10)

5. **《春秋·文公九年》**：“公子遂会晋人、宋人、卫人、许人救郑。”  
   **《左传·文公九年》**：“不及楚师。”

<a id="note-6"></a>

6. **《春秋·文公九年》**：“夏，狄侵齐。”  
   **《左传·文公九年》**又记楚侵陈、陈楚平。

7. **《春秋·文公九年》**：“秋八月，曹伯襄卒。九月癸酉，地震。”

8. **《春秋·文公九年》**：“冬，楚子使椒来聘。”  
   **《左传·文公九年》**：“执币傲。”

## 补充核对的史料

<a id="cq-source-17"></a>
### 核对17｜楚穆王听取范山建议，出兵伐郑

**说明：**此时是楚穆王，楚庄王尚未即位。旧页误称楚庄王；本条改用相符的君号，出兵判断归于范山的进言。

<details>
<summary>传 T005｜原文</summary>

> 范山言于楚子曰：“晋君少，不在诸侯，北方可图也。”楚子师于狼渊以伐郑。囚公子坚、公子尨及乐耳。郑及楚平。公子遂会晋赵盾、宋华耦、卫孔达、许大夫救郑，不及楚师。卿不书，缓也，以惩不恪。

[本段出处](../../sources/春秋左传/有标点原文/bce-0618.md#t005)

</details>

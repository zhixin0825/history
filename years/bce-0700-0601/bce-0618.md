1. **周顷王元年，王室赴鲁求金，鲁遣使葬襄王。** 周顷王即位，本年为元年。春，周襄王尚未安葬，王室派毛伯到鲁求金。鲁派叔孙得臣到周会葬。鲁夫人姜氏同在春季前往齐国，三月返鲁。 [[1]](#reading-note-1)

<a id="event-3"></a>

<a id="reading-event-3"></a>

<a id="reading-event-4"></a>

2. **晋国先克被杀，五名作乱大夫伏诛。** 正月，晋大夫先克被刺杀。晋随后处死参与作乱的先都、梁益耳、士縠、箕郑父、蒯得。 [[2]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-5"></a>

<a id="event-5"></a>

<a id="reading-event-6"></a>

3. **楚穆王攻郑，鲁晋等国救郑未及。** 楚穆王听范山建议出兵伐郑。鲁公子遂与晋、宋、卫、许联兵援郑，行动迟缓，未能追上楚军。 [[3]](#reading-note-5)

<a id="event-6"></a>

<a id="reading-event-7"></a>

4. **夏，狄人侵齐。** 楚军同时又侵陈，陈国随后也被迫与楚讲和。 [[4]](#reading-note-7)

<a id="reading-event-8"></a>

5. **夏秋之间，陈国与楚军先后交战，最终才求和。** 夏季楚军侵陈、攻取壶丘，报复陈国依晋；秋季楚公子朱从东夷方向攻陈，却被陈军击败，公子茷被俘。陈人担心楚国继续报复，随后与楚讲和。 [[5]](#reading-note-8)

<a id="event-7"></a>

<a id="reading-event-9"></a>

<a id="event-9"></a>

<a id="reading-event-11"></a>

<a id="hs-event-14"></a>

6. **鲁葬曹共公，收秦国丧礼并记地震。** 八月，曹伯襄去世，鲁国后来安葬曹共公。九月，鲁发生地震。秦也在本年送来纪念鲁僖公、成风的丧服礼物。 [[6]](#reading-note-9)

<a id="event-8"></a>

<a id="reading-event-10"></a>

7. **冬，楚国越椒来鲁聘问，但态度傲慢。** 鲁大夫已预言若敖氏将因骄傲而亡。 [[7]](#reading-note-10)

<a id="sj034-xiang-death-event"></a>

8. **燕襄公去世，桓公继承。** 燕襄公在位四十年后去世，燕桓公继位，次年起桓公元年。 [[8]](#sj034-xiang-death-note)

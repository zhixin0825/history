# 公元前618年（鲁文公九年）

[← 上一张已编年页：公元前619年](bce-0619.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前617年 →](bce-0617.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **春，周王室在襄王未葬前派毛伯来鲁求金。** 这种直接索取财物被认为不合礼。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **夫人姜氏前往齐国，三月返回；叔孙得臣则赴京师参加周襄王葬礼。** 鲁国同时维持齐、周两条外交线。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **晋国清洗上一年作乱大夫：先都、梁益耳、士縠、箕郑父、蒯得等先后被杀。** 晋国内部赵盾权力进一步稳固。 [[3]](#reading-note-3)

<a id="reading-event-4"></a>

4. **春正月，晋国先克被刺杀，随后才有对作乱诸臣的处置。** 晋国相继杀先都、梁益耳等人的经过，须与先克先被杀的起因连读，不能只留下处死名单。 [[4]](#reading-note-4)

<a id="event-4"></a>

<a id="reading-event-5"></a>

5. **楚穆王听取范山建议，出兵伐郑。** 范山指出晋君年幼，楚国可以向北行动。楚军驻于狼渊，俘虏郑公子坚、公子尨及乐耳，郑国随后与楚讲和。 [[5]](#reading-note-5)

<a id="event-5"></a>

<a id="reading-event-6"></a>

6. **鲁公子遂会同晋、宋、卫、许军队救郑，但行动迟缓，没有追上楚军。** [[6]](#reading-note-6)

<a id="event-6"></a>

<a id="reading-event-7"></a>

7. **夏，狄人侵齐。** 楚军同时又侵陈，陈国随后也被迫与楚讲和。 [[7]](#reading-note-7)

<a id="reading-event-8"></a>

8. **夏秋之间，陈国与楚军先后交战，最终才求和。** 夏季楚军侵陈、攻取壶丘，报复陈国依晋；秋季楚公子朱从东夷方向攻陈，却被陈军击败，公子茷被俘。陈人担心楚国继续报复，随后与楚讲和。 [[8]](#reading-note-8)

<a id="event-7"></a>

<a id="reading-event-9"></a>

9. **秋八月，曹伯襄去世；九月发生地震。** [[9]](#reading-note-9)

<a id="event-8"></a>

<a id="reading-event-10"></a>

10. **冬，楚国越椒来鲁聘问，但态度傲慢。** 鲁大夫已预言若敖氏将因骄傲而亡。 [[10]](#reading-note-10)

<a id="event-9"></a>

<a id="reading-event-11"></a>

11. **秦国送来僖公、成风的丧服礼物；鲁国又安葬曹共公。** 秦鲁旧好仍被维持。 [[11]](#reading-note-11)

<a id="event-10"></a>

<a id="reading-event-12"></a>

12. **周顷王壬臣开始纪年，本年为顷王元年。** 周襄王在前619年去世，壬臣此前已经继承王位；本年记的是新君元年，不是另一次即位。 [[12]](#reading-note-12)

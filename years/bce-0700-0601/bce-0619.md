# 公元前619年（鲁文公八年）

[← 上一张已编年页：公元前620年](bce-0620.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前618年 →](bce-0618.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，晋国把匡、戚等地归还卫国，又恢复卫国公婿池的封地。** 晋国继续兑现“服则怀之”的政策。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，秦国进攻晋国，夺取武城，报复令狐之败。** 秦晋战争仍未停歇。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋八月，周襄王去世。** 周王室进入新君更替。 [[3]](#note-3)

   襄王去世后，儿子壬臣继位，即顷王。 [卷四互见与归年](#sj004-619-1)

<a id="event-4"></a>

4. **冬，公子遂与晋赵盾在衡雍结盟，补上鲁国此前迟到扈盟的外交缺口；随后又与伊洛之戎在暴地结盟。** [[4]](#note-4)

<a id="event-5"></a>

5. **公孙敖本来前往京师吊丧，却中途返回并带着财物逃往莒国，追随自己所爱的莒女。** 鲁国重要宗族人物再次出奔。 [[5]](#note-5)

<a id="event-6"></a>

6. **鲁国发生螽灾。** [[6]](#note-6)

<a id="event-7"></a>

7. **宋襄夫人利用戴氏宗族清洗宋昭公党羽，杀多名大夫；宋司城荡意诸逃到鲁国。** 宋国内部政治暴力升级。 [[7]](#note-7)

<a id="event-8"></a>

8. **晋国箕郑父、先都、士縠、梁益耳、蒯得等因军职和田地问题开始结党谋乱。** 下一年晋国将大规模清洗这批大夫。 [[8]](#note-8)

<a id="event-9"></a>

9. **宋昭公杵臼本年为元年。** 前一年宋成公去世、宋国内部发生争立后，杵臼继承君位，本年起按昭公王年纪事。 [[9]](#note-9)

## 归年与考证

1. **《左传·文公八年》**：“晋侯使解扬归匡、戚之田于卫，且复致公婿池之封。”

<a id="history-legacy-source-2"></a>

2. **《左传·文公八年》**：“夏，秦人伐晋，取武城，以报令狐之役。”

<a id="history-legacy-source-3"></a>

3. **《春秋·文公八年》**：“秋八月戊申，天王崩。”

<a id="sj004-619-1"></a>
<a id="襄王之后由顷王壬臣接位卷四互见"></a>
##### 襄王之后由顷王壬臣接位｜卷四互见

[卷004 P052](../../sources/摘录/史记-卷004-周本纪.md#p052)。 本纪作襄王三十二年，与按通行王年换算的前620相当；《左传》文公八年明确在前619记襄王崩。采用经传，不另造前620死亡；后续顷、匡二王也不按这一误差整体提前一年。

<a id="history-legacy-source-5"></a>

4. **《春秋·文公八年》**：“冬十月壬午，公子遂会晋赵盾，盟于衡雍。乙酉，公子遂会雒戎，盟于暴。”

<a id="history-legacy-source-6"></a>

5. **《春秋·文公八年》**：“公孙敖如京师，不至而复。丙戌，奔莒。”  
   **《左传·文公八年》**详记穆伯吊丧未至、以币奔莒。

<a id="history-legacy-source-7"></a>

6. **《春秋·文公八年》**：“螽。”

<a id="history-legacy-source-8"></a>

7. **《春秋·文公八年》**：“宋人杀其大夫司马，宋司城来奔。”  
   **《左传·文公八年》**详记襄夫人杀昭公党与荡意诸奔鲁。

<a id="history-legacy-source-9"></a>

8. **《左传·文公八年》**篇末详记箕郑父、先都、士縠、梁益耳、蒯得作乱。

<a id="history-legacy-source-10"></a>

9. **《史记·十二诸侯年表》前619年宋栏**：“宋昭公杵臼元年，襄公之子。”[国别年行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0619)；但[《宋微子世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7038.md#ref-5a25a6712c2353)记“成公少子杵臼”，即称他为宋成公幼子，而非宋襄公之子。此处只把昭公元年作为白话主文；父系冲突另存，不据年表把昭公改为襄公之子。

### 补充史料与异说

<a id="sj014-0619-lu-shift"></a>
<a id="史记卷014前619年鲁栏求金与经传纪年有别"></a>
#### 史记卷014｜前619年鲁栏求金与经传纪年有别

[《十二诸侯年表》前619年鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0619)作“王使卫来求金以葬，非礼”，但《春秋·文公九年》《左传·文公九年》记在**前618年**：“毛伯来求金”“毛伯卫来求金，非礼也”。这里的“卫”属于**毛伯卫的人名**，不指卫国使臣；[前618年现有记事](bce-0618.md#event-1)已记王室遣毛伯求金，故不在前619年重写第二次求金。[《左传·文公九年》原文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E6%96%87%E5%85%AC.md#ref-0d9ef2354aa336)

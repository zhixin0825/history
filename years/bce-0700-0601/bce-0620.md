<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **春，鲁文公趁晋国内部继承不稳出兵伐邾，三月夺取须句并修筑郚地。** 鲁国继续扩大对邾压力。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **夏四月，宋成公去世。** 宋昭公即位后试图清除公族，引发穆、襄诸族反击，多名大夫被杀。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **秦康公开始纪元年，秦军护送公子雍回晋，晋国却改变了继承安排。** 穆嬴抱着太子夷皋在朝廷哭诉，又到赵盾家中追问先君的托付。赵盾与诸大夫终于背弃迎雍之议，改立夷皋为晋灵公，以抵御秦军。哭诉与改立是《左传·文公七年》的叙事，不应断言已经在上一年全部结束。 [[3]](#reading-note-3)

<a id="reading-event-4"></a>

4. **晋灵公夷皋同样从前620年计算元年，赵盾执掌晋国政务。** 年表列元年本身不能反证拥立必在上一年；具体改立经过仍以本年经传及《晋世家》叙事为准，不再另造一次继位。 [[4]](#reading-note-4)

<a id="event-4"></a>

<a id="reading-event-5"></a>

5. **晋军夜间急进，在令狐击败秦军。** 先蔑、士会此前奉命迎公子雍，如今因晋国反悔无地自处，战后逃往秦国。 [[5]](#reading-note-5)

<a id="reading-event-6"></a>

6. **荀林父早先曾劝先蔑不要参与从国外另迎晋君，先蔑没有接受。** 他指出夫人和太子都还在，外迎国君的计划很难实行。先蔑后来出奔秦国，荀林父仍把他的家属、器用和财物送去，说这是为旧同僚尽心。 [[6]](#reading-note-6)

<a id="event-5"></a>

<a id="reading-event-7"></a>

7. **狄人进攻鲁国西部边境。** 鲁国向晋国求援，赵盾借此也询问逃狄的贾季对赵氏的评价。 [[7]](#reading-note-7)

<a id="event-6"></a>

<a id="reading-event-8"></a>

8. **秋，齐、宋、卫、郑、许、曹与晋赵盾在扈地会盟，确认晋灵公的君位。** 鲁文公迟到，因此经文没有列出具体会盟诸侯名单。 [[8]](#reading-note-8)

<a id="event-7"></a>

<a id="reading-event-9"></a>

9. **冬，徐国进攻莒国；公孙敖前往莒国主持盟约。** 公孙敖又因莒女婚姻问题与襄仲发生兄弟冲突，最终调解。 [[9]](#reading-note-9)

<a id="event-8"></a>

<a id="reading-event-10"></a>

10. **晋国决定把此前侵夺的部分卫国土地归还，以显示服从者可获安抚。** 赵盾开始以德、威并用经营诸侯。 [[10]](#reading-note-10)

> 晋郤缺言于赵宣子曰：“日卫不睦，故取其地，今已睦矣，可以归之。叛而不讨，何以示威？服而不柔，何以示怀？非威非怀，何以示德？无德何以主盟？子为正卿以主诸侯，而不务德，将若之何？《夏书》曰：‘戒之用休，董之用威，劝之以九歌勿使坏。’九功之德皆可歌也，谓之九歌。六府、三事，谓之九功。水、火、金、木、土、穀，谓之六府。正德、利用、厚生，谓之三事。义而行之，谓之德礼。无礼不乐，所由叛也。若吾子之德莫可歌也，其谁来之？盍使睦者歌吾子乎？”宣子说之。

   **《左传·文公七年》**详记宋昭公与公族冲突。

   **卷014异文核对：**《十二诸侯年表》前620年**宋栏**写“公孙固杀成公”，按字面是公孙固杀害成公；然而《春秋》明确记“宋公王臣卒”，[《宋微子世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7038.md#ref-0cf30a04587139)则记成公去世后，成公弟御杀太子及大司马公孙固。公孙固在世家中是被杀者，不可倒写为弑宋成公者。本表与世家互相抵牾，暂存原文，不另造一次杀君案。[原始年行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0620)

<a id="review-20261109-chronology"></a>

### 本轮校订：叙事与原文的界限

旧文从“元年”倒推“上一年已经拥立完毕”，超出了年表所能证明的内容。《左传·文公七年》本段将穆嬴哭诉、改立灵公与御秦连叙，[《晋世家》灵公元年四月](../../sources/本地分卷/史记/史记-卷039.md#L3561)也有相同次序。本页据明确叙事修正，前621年留迎雍准备及后续回链。

# 公元前620年（鲁文公七年）

[← 上一张已编年页：公元前621年](bce-0621.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前619年 →](bce-0619.md)

<a id="event-1"></a>

1. **春，鲁文公趁晋国内部继承不稳出兵伐邾，三月夺取须句并修筑郚地。** 鲁国继续扩大对邾压力。[[1]](#note-1)

<a id="event-2"></a>

2. **夏四月，宋成公去世。** 宋昭公即位后试图清除公族，引发穆、襄诸族反击，多名大夫被杀。[[2]](#note-2)

<a id="event-3"></a>

3. **秦康公罃本年开始纪元年，秦国按此前约定出兵护送公子雍回晋；晋国已经在上一年拥立太子夷皋，秦军由“迎君之师”变成敌军。** [[3]](#note-3)

<a id="event-4"></a>

4. **晋军夜间急进，在令狐击败秦军。** 先蔑、士会此前奉命迎公子雍，如今因晋国反悔无地自处，战后逃往秦国。[[4]](#note-4)

**荀林父早先曾劝先蔑不要参与从国外另迎晋君，先蔑没有接受。** 他指出夫人和太子都还在，外迎国君的计划很难实行。先蔑后来出奔秦国，荀林父仍把他的家属、器用和财物送去，说这是为旧同僚尽心。 [看原文与说明](#cq-source-42)

[补充史料与年次说明](#sj005-095-note)


<a id="event-5"></a>

5. **狄人进攻鲁国西部边境。** 鲁国向晋国求援，赵盾借此也询问逃狄的贾季对赵氏的评价。[[5]](#note-5)

<a id="event-6"></a>

6. **秋，齐、宋、卫、郑、许、曹与晋赵盾在扈地会盟，确认晋灵公的君位。** 鲁文公迟到，因此经文没有列出具体会盟诸侯名单。[[6]](#note-6)

<a id="event-7"></a>

7. **冬，徐国进攻莒国；公孙敖前往莒国主持盟约。** 公孙敖又因莒女婚姻问题与襄仲发生兄弟冲突，最终调解。[[7]](#note-7)

<a id="event-8"></a>

8. **晋国决定把此前侵夺的部分卫国土地归还，以显示服从者可获安抚。** 赵盾开始以德、威并用经营诸侯。[[8]](#note-8)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·文公七年》**：“七年春，公伐邾。三月甲戌，取须句。遂城郚。”  
   **《左传·文公七年》**：“间晋难也。”

<a id="note-2"></a>

2. **《春秋·文公七年》**：“夏四月，宋公王臣卒。宋人杀其大夫。”  
   **《左传·文公七年》**详记宋昭公与公族冲突。

   **卷014异文核对：**《十二诸侯年表》前620年**宋栏**写“公孙固杀成公”，按字面是公孙固杀害成公；然而《春秋》明确记“宋公王臣卒”，[《宋微子世家》](https://zh.wikisource.org/wiki/史記/卷038#宋成公)则记成公去世后，成公弟御杀太子及大司马公孙固。公孙固在世家中是被杀者，不可倒写为弑宋成公者。本表与世家互相抵牾，暂存原文，不另造一次杀君案。[原始年行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0620)

<a id="note-3"></a>

3. **《左传·文公七年》**详记穆嬴迫赵盾立灵公、晋拒公子雍与秦军。
   **《史记·十二诸侯年表》前620年秦栏**：“秦康公罃元年。”[本卷年行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0620)；秦穆公去世与康公继立见[前621年](bce-0621.md#event-4)，不重造本年即位。

<a id="note-4"></a>

4. **《春秋·文公七年》**：“戊子，晋人及秦人战于令狐。晋先蔑奔秦。”  
   **《左传·文公七年》**详记晋军夜袭、秦败，先蔑、士会奔秦。

<a id="note-5"></a>

5. **《春秋·文公七年》**：“狄侵我西鄙。”  
   **《左传·文公七年》**详记鲁告晋。

<a id="note-6"></a>

6. **《春秋·文公七年》**：“秋八月，公会诸侯、晋大夫，盟于扈。”  
   **《左传·文公七年》**列齐、宋、卫、郑、许、曹会赵盾。

<a id="note-7"></a>

7. **《春秋·文公七年》**：“冬，徐伐莒。公孙敖如莒涖盟。”  
   **《左传·文公七年》**详记公孙敖婚姻争议。

<a id="note-8"></a>

8. **《左传·文公七年》**篇末详记郤缺劝赵盾归卫地以示德。

### 核对42｜荀林父早先曾劝先蔑不要参与从国外另迎晋君，先蔑没有接受

**说明：**劝阻发生在出使迎君以前；送家属财物则接在本次流亡后，不把前一年迎君再记成前620年新出使。

<details>
<summary>传 T005｜原文</summary>

> 先蔑之使也，荀林父止之，曰：“夫人、大子犹在，而外求君，此必不行。子以疾辞，若何？不然将及。摄卿以往可也，何必子？同官为寮，吾尝同寮，敢不尽心乎！”弗听。为赋《板》之三章。又弗听。及亡，荀伯尽送其帑及其器用财贿于秦，曰：“为同寮故也。”

# 公元前621年（鲁文公六年）

[← 上一张已编年页：公元前622年](bce-0622.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前620年 →](bce-0620.md)

<a id="event-1"></a>

1. **春，鲁国安葬许僖公。** [[1]](#note-1)

<a id="event-2"></a>

2. **春，晋国重新编军，赵盾先任中军佐，随后升到狐射姑之上并掌国政。** 初次在夷地整军，狐射姑为中军将，赵盾佐之。阳处父自温回来后，改在董地检阅并交换中军班次，使赵盾居上。赵盾于是主持制定常法，整顿刑狱、逃亡、契约和官职，再交有关官员推行。 [看原文与说明](#cq-source-16)

<a id="event-3"></a>

3. **夏，季孙行父前往陈国聘问并娶妻；秋又出使晋国。** 鲁国同时经营陈、晋关系。[[3]](#note-3)

<a id="event-4"></a>

4. **秦穆公去世，并以子车氏三名贤臣奄息、仲行、鍼虎殉葬。** 秦人深感悲痛，作《黄鸟》哀悼；这一做法严重损耗秦国人才。[[4]](#note-4)

 [卷四互见与归年](#sj004-621-1)


<a id="event-5"></a>

5. **八月，晋襄公去世。** 因太子夷皋年幼，晋国大夫一度想另立年长公子。[[5]](#note-5)

<a id="event-6"></a>

6. **赵盾主张从秦迎回公子雍，贾季则主张从陈迎公子乐。** 赵盾派先蔑、士会赴秦，贾季派人召公子乐；赵盾又在途中杀掉公子乐。[[6]](#note-6)

<a id="event-7"></a>

7. **穆嬴抱着太子夷皋在朝廷哭诉，迫使赵盾和群臣改变主意，最终仍立夷皋为晋灵公。** 晋国因此背弃迎公子雍的计划。[[7]](#note-7)

<a id="event-8"></a>

8. **贾季因怨阳处父改变自己军中班次，派续鞫居杀死阳处父；晋国随后诛续鞫居，贾季逃往狄地。** 晋国内部权力斗争加剧。[[8]](#note-8)

<a id="event-9"></a>

9. **冬，公子遂到晋国参加晋襄公葬礼。** [[9]](#note-9)

<a id="event-10"></a>

10. **闰月，鲁国没有正式告朔，却仍到宗庙朝拜。** 被认为是放弃闰月政令程序。[[10]](#note-10)

## 补充核对的史料

<a id="cq-source-16"></a>
### 核对16｜春，晋国重新编军，赵盾先任中军佐，随后升到狐射姑之上并掌国政

**说明：**不能省去“改蒐于董，易中军”“是以上之”而一直把执政赵盾写作中军佐。阳处父支持赵氏及认为赵盾可任，是传文交代的理由，不当成编者的能力排名。

<details>
<summary>传 T001｜原文</summary>

> 六年春，晋蒐于夷，舍二军。使狐射姑将中军，赵盾佐之。阳处父至自温，改蒐于董，易中军。阳子，成季之属也，故党于赵氏，且谓赵盾能，曰：“使能，国之利也。”是以上之。宣子于是乎始为国政，制事典，正法罪，辟狱刑，董逋逃，由质要，治旧洿，本秩礼，续常职，出滞淹。既成，以授大傅阳子与大师贾佗，使行诸晋国，以为常法。

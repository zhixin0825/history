# 公元前621年（鲁文公六年）

<a id="event-1"></a>

1. **春，鲁国安葬许僖公。** [[1]](#note-1)

<a id="event-2"></a>

2. **春，晋国重新编军，赵盾先任中军佐，随后升到狐射姑之上并掌国政。** 初次在夷地整军，狐射姑为中军将，赵盾佐之。阳处父自温回来后，改在董地检阅并交换中军班次，使赵盾居上。赵盾于是主持制定常法，整顿刑狱、逃亡、契约和官职，再交有关官员推行。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，季孙行父前往陈国聘问并娶妻；秋又出使晋国。** 鲁国同时经营陈、晋关系。 [[3]](#note-3)

<a id="event-4"></a>

4. **秦穆公去世，子车氏三良殉葬。** 秦穆公去世，子车氏的奄息、仲行、鍼虎被用作殉葬。秦人作《黄鸟》哀悼三人。秦太子继位，是为秦康公。 [[4]](#note-4)

<a id="event-5"></a>

5. **八月，晋襄公去世。** 太子夷皋年幼，晋国大夫因局势多难，一度希望迎立年长公子。 [[5]](#note-5)

<a id="event-6"></a>

6. **赵盾主张从秦迎回公子雍，贾季则主张从陈迎公子乐。** 赵盾看重雍的年长、好善、先君宠爱与秦援；贾季则以辰嬴曾受宠、其子乐有望安众为理由。赵盾反驳乐的母族名分与陈国远小，随后派先蔑、士会赴秦，贾季派人赴陈迎乐；赵盾又在途中杀掉公子乐。 [[6]](#note-6)

<a id="event-7"></a>

7. **晋国迎公子雍之议遇阻。** 晋国大夫一度决定从秦迎立公子雍。穆嬴坚持由太子夷皋承嗣，迎雍的安排后来被推翻。 [[7]](#note-7)

<a id="event-8"></a>

8. **贾季因怨阳处父改变自己军中班次，派续鞫居杀死阳处父；晋国随后诛续鞫居，贾季逃往狄地。** 晋国内部权力斗争加剧。 [[8]](#note-8)

<a id="event-9"></a>

9. **冬，公子遂到晋国参加晋襄公葬礼。** [[9]](#note-9)

<a id="event-10"></a>

10. **闰月，鲁国没有正式告朔，却仍到宗庙朝拜。** 被认为是放弃闰月政令程序。 [[10]](#note-10)

### 6. 赵盾主张从秦迎回公子雍，贾季则主张从陈迎公子乐

[返回正文第6条](#event-6)

**[《左传》鲁文公6年传文（前621年）](../../sources/春秋左传/有标点原文/bce-0621.md#batch-20261109-t006)**

> 八月乙亥，晋襄公卒。灵公少，晋人以难故，欲立长君。赵孟曰：“立公子雍。好善而长，先君爱之，且近于秦。秦旧好也。置善则固，事长则顺，立爱则孝，结旧则安。为难故，故欲立长君，有此四德者，难必抒矣。”贾季曰：“不如立公子乐。辰嬴嬖于二君，立其子，民必安之。”赵孟曰：“辰嬴贱，班在九人，其子何震之有？且为二嬖，淫也。为先君子，不能求大而出在小国，辟也。母淫子辟，无威。陈小而远，无援。将何安焉？杜祁以君故，让偪姞而上之，以狄故，让季隗而己次之，故班在四。先君是以爱其子而仕诸秦，为亚卿焉。秦大而近，足以为援，母义子爱，足以威民，立之不亦可乎？”使先蔑、士会如秦，逆公子雍。贾季亦使召公子乐于陈。赵孟使杀诸郫。贾季怨阳子之易其班也，而知其无援于晋也。九月，贾季使续鞫居杀阳处父。书曰：“晋杀其大夫。”侵官也。

#### 核对16｜春，晋国重新编军，赵盾先任中军佐，随后升到狐射姑之上并掌国政

**说明：**不能省去“改蒐于董，易中军”“是以上之”而一直把执政赵盾写作中军佐。阳处父支持赵氏及认为赵盾可任，是传文交代的理由，不当成编者的能力排名。

<details>
<summary>传 T001｜原文</summary>

> 六年春，晋蒐于夷，舍二军。使狐射姑将中军，赵盾佐之。阳处父至自温，改蒐于董，易中军。阳子，成季之属也，故党于赵氏，且谓赵盾能，曰：“使能，国之利也。”是以上之。宣子于是乎始为国政，制事典，正法罪，辟狱刑，董逋逃，由质要，治旧洿，本秩礼，续常职，出滞淹。既成，以授大傅阳子与大师贾佗，使行诸晋国，以为常法。

#### sj005-094｜同一事件的补充与取舍

[卷005 P035](../../sources/摘录/史记-卷005-秦本纪.md#p035)。

**说明：**《秦本纪》记殉死总数177，但[《十二诸侯年表》前621年秦栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0621)记“从死者百七十人”，两数相差7，尚不能凭现有材料裁定准确总数；《左传》只明确子车氏三良的姓名，不提供殉死总数。三良族名本纪作“子舆”，经传作子车，正文沿用子车。其君子论以遗德与殉良对比，是作者判断，不把“秦不能复东征”当成后世所有战争均未发生。

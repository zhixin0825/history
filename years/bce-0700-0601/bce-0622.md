# 公元前622年（鲁文公五年）

[← 上一张已编年页：公元前623年](bce-0623.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前621年 →](bce-0621.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，周王派荣叔来为成风含玉、赠送丧礼财物；三月成风下葬，周王又派召伯参加葬礼。** 周王室给予鲁国高规格丧礼支持。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，公孙敖前往晋国。** 鲁晋外交继续。 [[2]](#note-2)

<a id="event-3"></a>

3. **鄀国在秦楚之间反复，夏天秦军攻入鄀国。** 小国在两强之间难以稳定站队。 [[3]](#note-3)

<a id="event-4"></a>

4. **六国背楚投向东夷，秋天楚军出兵灭六。** 楚国继续清理淮汉地区反叛附庸。 [[4]](#note-4)

<a id="event-5"></a>

5. **楚国随后又灭蓼。** 皋陶后裔所在的六、蓼接连亡国，引发鲁大夫对宗祀断绝的感叹。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬，许僖公去世。** 许国发生君主更替。 [[6]](#note-6)

<a id="event-7"></a>

7. **晋大夫阳处父出使卫国，甯嬴原本跟随他，途中却因其性格刚愎、华而不实而离去。** 晋国的赵成子、栾贞子、霍伯、臼季四位大夫，也在这一年去世。 赵衰身后又称成季。 [[7]](#note-7)

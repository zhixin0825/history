# 公元前622年（鲁文公五年）

[← 上一张已编年页：公元前623年](bce-0623.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前621年 →](bce-0621.md)

<a id="event-1"></a>

1. **春，周王派荣叔来为成风含玉、赠送丧礼财物；三月成风下葬，周王又派召伯参加葬礼。** 周王室给予鲁国高规格丧礼支持。[1]

<a id="event-2"></a>

2. **夏，公孙敖前往晋国。** 鲁晋外交继续。[2]

<a id="event-3"></a>

3. **鄀国在秦楚之间反复，夏天秦军攻入鄀国。** 小国在两强之间难以稳定站队。[3]

<a id="event-4"></a>

4. **六国背楚投向东夷，秋天楚军出兵灭六。** 楚国继续清理淮汉地区反叛附庸。[4]

<a id="event-5"></a>

5. **楚国随后又灭蓼。** 皋陶后裔所在的六、蓼接连亡国，引发鲁大夫对宗祀断绝的感叹。[5]

<a id="event-6"></a>

6. **冬，许僖公去世。** 许国发生君主更替。[6]

<a id="event-7"></a>

7. **晋大夫阳处父出使卫国，甯嬴原本跟随他，途中却因其性格刚愎、华而不实而离去。** 晋国内部也有多位旧臣在这一时期先后去世。[7]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·文公五年》**：“五年春，王正月，王使荣叔归含，且赗。三月辛亥，葬我小君成风。王使召伯来会葬。”

<a id="note-2"></a>

2. **《春秋·文公五年》**：“夏，公孙敖如晋。”

<a id="note-3"></a>

3. **《春秋·文公五年》**：“秦人入鄀。”  
   **《左传·文公五年》**：“鄀叛楚即秦，又贰于楚。”

<a id="note-4"></a>

4. **《春秋·文公五年》**：“秋，楚人灭六。”  
   **《左传·文公五年》**详记六人叛楚即东夷。

<a id="note-5"></a>

5. **《左传·文公五年》**：“冬，楚子燮灭蓼。”

<a id="note-6"></a>

6. **《春秋·文公五年》**：“冬十月甲申，许男业卒。”

<a id="note-7"></a>

7. **《左传·文公五年》**详记阳处父过甯、甯嬴离去及赵成子等大夫相继卒。

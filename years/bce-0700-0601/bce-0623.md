# 公元前623年（鲁文公四年）

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **春，鲁文公从晋国返回。** 鲁晋重新结盟后关系暂时稳定。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **夏，鲁国从齐国迎娶姜氏，但没有派卿级人物主持迎亲。** 这桩婚姻从一开始就没有得到足够礼遇，为后来出姜被废埋下问题。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **狄人侵齐。** 齐国继续受到北方压力。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **秋，楚国灭江国。** 秦穆公因盟国被灭而降服、停乐、出居反省，虽未能救江，仍表现出对盟国亡国的重视。 [[4]](#reading-note-4)

<a id="event-5"></a>

<a id="reading-event-5"></a>

5. **晋襄公出兵伐秦，包围邧、新城，报复秦国前一年取王官。** 秦晋战争继续反复。 [[5]](#reading-note-5)

<a id="event-6"></a>

<a id="reading-event-6"></a>

6. **卫国甯武子来鲁聘问。** 鲁文公设宴并赋《湛露》《彤弓》，甯武子认为这些是天子礼，不敢接受过度礼遇。 [[6]](#reading-note-6)

<a id="event-7"></a>

<a id="reading-event-7"></a>

7. **冬十一月，成风去世。** 鲁国进入夫人丧期。 [[7]](#reading-note-7)

<a id="event-8"></a>

<a id="reading-event-8"></a>

<a id="event-10"></a>

<a id="reading-event-11"></a>

8. **晋释卫臣孔达，卫成公赴晋致谢。** 春，晋释放被扣押的孔达，让他回卫。夏，卫成公亲往晋国拜谢。 [[8]](#reading-note-8)

<a id="event-9"></a>

<a id="reading-event-9"></a>

<a id="reading-event-10"></a>

9. **秦穆公起用由余，进攻西方诸戎。** 秦用由余参与谋划，进攻西方诸戎。秦国任由余参与谋划，向西攻取诸戎之地。周天子派召公过送金鼓庆贺。此前的人物与交涉。由余的先人出于晋，后来居戎，他能说晋地语言，先以戎王使者身份来到秦。穆公展示宫室和积聚，由余却反问建造是否劳民。双方继而辩论礼乐法度和君民关系。内史廖建议送女乐、留使失期，离间由余与戎王。由余返国屡谏不听，又受秦方延揽，最终离戎归秦，以宾客身份参与谋划。 [[9]](#reading-note-9)

<a id="reading-note-10"></a>

**[《史记·秦本纪》](../../sources/摘录/史记-卷005-秦本纪.md#p033)**

> 戎王使由余於秦。由余，其先晉人也，亡入戎，能晉言。聞繆公賢，故使由余觀秦。秦繆公示以宮室、積聚。由余曰：「使鬼為之，則勞神矣。使人為之，亦苦民矣。」繆公怪之，問曰：「中國以詩書禮樂法度為政，然尚時亂，今戎夷無此，何以為治，不亦難乎？」由余笑曰：「此乃中國所以亂也。夫自上聖黃帝作為禮樂法度，身以先之，僅以小治。及其後世，日以驕淫。阻法度之威，以責督於下，下罷極則以仁義怨望於上，上下交爭怨而相篡弒，至於滅宗，皆以此類也。夫戎夷不然。上含淳德以遇其下，下懷忠信以事其上，一國之政猶一身之治，不知所以治，此真聖人之治也。」於是繆公退而問內史廖曰：「孤聞鄰國有聖人，敵國之憂也。今由余賢，寡人之害，將奈之何？」內史廖曰：「戎王處辟匿，未聞中國之聲。君試遺其女樂，以奪其志；為由余請，以疏其閒；留而莫遣，以失其期。戎王怪之，必疑由余。君臣有閒，乃可虜也。且戎王好樂，必怠於政。」繆公曰：「善。」因與由余曲席而坐，傳器而食，問其地形與其兵勢盡察，而後令內史廖以女樂二八遺戎王。戎王受而說之，終年不還。於是秦乃歸由余。由余數諫不聽，繆公又數使人閒要由余，由余遂去降秦。繆公以客禮禮之，問伐戎之形。

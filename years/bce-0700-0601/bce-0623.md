# 公元前623年（鲁文公四年）

[← 上一张已编年页：公元前624年](bce-0624.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前622年 →](bce-0622.md)

<a id="event-1"></a>

1. **春，鲁文公从晋国返回。** 鲁晋重新结盟后关系暂时稳定。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，鲁国从齐国迎娶姜氏，但没有派卿级人物主持迎亲。** 这桩婚姻从一开始就没有得到足够礼遇，为后来出姜被废埋下问题。[[2]](#note-2)

<a id="event-3"></a>

3. **狄人侵齐。** 齐国继续受到北方压力。[[3]](#note-3)

<a id="event-4"></a>

4. **秋，楚国灭江国。** 秦穆公因盟国被灭而降服、停乐、出居反省，虽未能救江，仍表现出对盟国亡国的重视。[[4]](#note-4)

<a id="event-5"></a>

5. **晋襄公出兵伐秦，包围邧、新城，报复秦国前一年取王官。** 秦晋战争继续反复。[[5]](#note-5)

<a id="event-6"></a>

6. **卫国甯武子来鲁聘问。** 鲁文公设宴并赋《湛露》《彤弓》，甯武子认为这些是天子礼，不敢接受过度礼遇。[[6]](#note-6)

<a id="event-7"></a>

7. **冬十一月，成风去世。** 鲁国进入夫人丧期。[[7]](#note-7)

<a id="event-8"></a>

8. **春，晋国释放孔达，让他回卫。** 晋方认为孔达是卫国所需的人，因而免去其罪而归之。这与同年甯武子来鲁聘问不是同一使事。 [看原文与说明](#cq-source-41)

<a id="event-9"></a>

9. **秦用由余参与谋划，进攻西方诸戎。** 秦军扩张以后，周天子遣召公过以金鼓祝贺；本纪以益国十二、开地千里概述其成果。

**此前的人物与交涉。** 由余的先人出于晋，后来居戎，他能说晋地语言，先以戎王使者身份来到秦。穆公展示宫室和积聚，由余却反问建造是否劳民；双方继而辩论礼乐法度和君民关系。内史廖建议送女乐、留使失期，离间由余与戎王。由余返国屡谏不听，又受秦方延揽，最终离戎归秦，以宾客身份参与谋划。 [原文与说明](#sj005-092-note)

<a id="event-10"></a>

10. **夏，卫成公亲自到晋国拜谢。** 这一趟是卫国国君本人赴晋，和同年卫国甯武子到鲁国聘问，是两件不同的外交活动。[[10]](#note-10)

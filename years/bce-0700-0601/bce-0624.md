# 公元前624年（鲁文公三年）

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁叔孙得臣会同晋、宋、陈、卫、郑军队伐沈，沈国迅速崩溃。** 沈国因依附楚国而遭到晋系诸侯攻击。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，周王子虎去世。** 周王室重要人物退出政治舞台。 [[2]](#note-2)

<a id="event-3"></a>

3. **秦穆公亲自伐晋，渡河后烧毁船只，攻取王官、郊地。** 晋军不出，秦军又从茅津渡河，祭奠殽山战死者后撤退；秦国由此把重心转向西戎。 [[3]](#note-3)

   取王官等地以后，秦军处理旧殽战场遗骸，穆公向军士说起听取老成人意见的重要，要求后人记住自己的错误。

<a id="event-4"></a>

4. **秋，楚军包围江国；宋国又出现大量螽虫随雨坠落。** 晋国随后出兵救江。 [[4]](#note-4)

<a id="event-5"></a>

5. **冬，晋国因救江问题联合周王使者伐楚，一直推进到方城附近后撤。** 晋楚竞争继续。 [[5]](#note-5)

<a id="event-6"></a>

6. **鲁文公亲自赴晋，与晋襄公重新结盟。** 晋国此前以阳处父代盟使鲁受辱，这次改由晋侯亲自盟誓修复关系。 [[6]](#note-6)

<a id="event-7"></a>

7. **卫君前往陈国，感谢陈国促成自己与晋国和解。** “拜晋成”是为晋卫讲和而致谢，不写成卫国此时又与陈国订立一项未经记载的新盟。 [[7]](#note-7)

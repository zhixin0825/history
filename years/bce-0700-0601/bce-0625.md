# 公元前625年（鲁文公二年）

[← 上一张已编年页：公元前626年](bce-0626.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前624年 →](bce-0624.md)

<a id="event-1"></a>

1. **春，秦将孟明视为报殽之败再度伐晋，二月在彭衙被晋军击败。** 秦国连续东征仍未成功。[[1]](#note-1)

**狼瞫在彭衙率自己所属冲击秦军，战死阵中。** 他原在殽战后被选为晋君车右，到箕之役又被先轸黜换，曾拒绝朋友鼓动作乱的建议。本次两军列阵后，他带人冲入秦军，晋军随之进攻而获胜。 [看原文与说明](#cq-source-39)

<a id="event-2"></a>

2. **二月丁丑，鲁国迟至此时才制作僖公神主。** 僖公此前已经下葬，作主却拖到这一年，因而受到“不时”的批评。这里不是说鲁国把仪式办得过早。 [看原文与说明](#cq-source-15)

<a id="event-3"></a>

3. **晋国以鲁文公没有及时朝晋为由问罪，文公亲自赴晋；晋大夫阳处父代晋君与他结盟，使鲁国感到受辱。** 经文只记“及晋处父盟”，没有明写文公赴晋。[[3]](#note-3)

<a id="event-4"></a>

4. **夏，公孙敖与宋、陈、郑及晋大夫士縠在垂陇结盟，继续处理卫国问题。** 晋国仍主导诸侯外交。[[4]](#note-4)

<a id="event-5"></a>

5. **从前一年十二月到这一年七月，鲁国长期不雨。** [[5]](#note-5)

<a id="event-6"></a>

6. **八月，鲁国在太庙大祭时把僖公神位升到闵公之前。** 这种“逆祀”被认为打乱父子、君臣先后次序。[[6]](#note-6)

<a id="event-7"></a>

7. **冬，晋、宋、陈、郑联合伐秦，攻取汪地并推进到彭衙，报复秦国春季进攻。** 秦晋战争持续升级。[[7]](#note-7)

<a id="event-8"></a>

8. **公子遂前往齐国纳币，为鲁文公婚姻做准备。** [[8]](#note-8)

   **《左传·文公二年》**详记晋因文公不朝问罪、阳处父盟公。

<a id="note-4"></a>

5. **《春秋·文公二年》**：“自十有二月不雨，至于秋七月。”

<a id="note-6"></a>

### 核对15｜二月丁丑，鲁国迟至此时才制作僖公神主

**说明：**《左传》仅作“不时”；《穀梁传》明确作“讥其后也”，杜预注解释为“过葬十月”。旧正文“过早”反其义，现更正。见[《日讲春秋解义》所汇三传原文](https://www.shidianguji.com/book/SK0457/chapter/1lxjgb9smyal7)。不将《公羊》与《左传》关于虞主、练主的异说强拼成同一种礼制。

### 核对39｜狼瞫在彭衙率自己所属冲击秦军，战死阵中

**说明：**殽、箕两战只是交代被选、被黜的前事；不得将狼瞫先前杀俘、担任车右也记成前625年的新任命。

<details>
<summary>传 T002｜原文</summary>

> 战于殽也，晋梁弘御戎，莱驹为右。战之明日，晋襄公缚秦囚，使莱驹以戈斩之。囚呼，莱驹失戈，狼瞫取戈以斩囚，禽之以从公乘，遂以为右。箕之役，先轸黜之而立续简伯。狼瞫怒。其友曰：“盍死之？”瞫曰：“吾未获死所。”其友曰：“吾与女为难。”瞫曰：“《周志》有之，勇则害上，不登于明堂。死而不义，非勇也。共用之谓勇。吾以勇求右，无勇而黜，亦其所也。谓上不我知，黜而宜，乃知我矣。子姑待之。”及彭衙，既陈，以其属驰秦师，死焉。晋师从之，大败秦师。君子谓：“狼瞫于是乎君子。《诗》曰：‘君子如怒，乱庶遄沮。’又曰：‘王赫斯怒，爰整其旅。’怒不作乱，而以从师，可谓君子矣。

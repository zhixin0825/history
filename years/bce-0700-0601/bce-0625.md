# 公元前625年（鲁文公二年）

[← 上一张已编年页：公元前626年](bce-0626.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前624年 →](bce-0624.md)

[本年相关史料](#sources-start)

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **春，秦将孟明视为报殽之败再度伐晋，二月在彭衙被晋军击败。** 秦国连续东征仍未成功。 [[1]](#reading-note-1)

<a id="reading-event-2"></a>

2. **狼瞫在彭衙率自己所属冲击秦军，战死阵中。** 他原在殽战后被选为晋君车右，到箕之役又被先轸黜换，曾拒绝朋友鼓动作乱的建议。本次两军列阵后，他带人冲入秦军，晋军随之进攻而获胜。 [[2]](#reading-note-2)

<a id="event-2"></a>

<a id="reading-event-3"></a>

3. **二月丁丑，鲁国迟至此时才制作僖公神主。** 僖公此前已经下葬，作主却拖到这一年，因而受到“不时”的批评。这里不是说鲁国把仪式办得过早。 [[3]](#reading-note-3)

<a id="event-3"></a>

<a id="reading-event-4"></a>

4. **晋国以鲁文公没有及时朝晋为由问罪，文公亲自赴晋；晋大夫阳处父代晋君与他结盟，使鲁国感到受辱。** 经文只记“及晋处父盟”，没有明写文公赴晋。 [[4]](#reading-note-4)

<a id="event-4"></a>

<a id="reading-event-5"></a>

5. **夏，公孙敖与宋、陈、郑及晋大夫士縠在垂陇结盟，继续处理卫国问题。** 晋国仍主导诸侯外交。 [[5]](#reading-note-5)

<a id="event-5"></a>

<a id="reading-event-6"></a>

6. **从前一年十二月到这一年七月，鲁国长期不雨。** [[6]](#reading-note-6)

<a id="event-6"></a>

<a id="reading-event-7"></a>

7. **八月，鲁国在太庙大祭时把僖公神位升到闵公之前。** 这种“逆祀”被认为打乱父子、君臣先后次序。 [[7]](#reading-note-7)

<a id="event-7"></a>

<a id="reading-event-8"></a>

8. **冬，晋、宋、陈、郑联合伐秦，攻取汪地并推进到彭衙，报复秦国春季进攻。** 秦晋战争持续升级。 [[8]](#reading-note-8)

<a id="event-8"></a>

<a id="reading-event-9"></a>

9. **公子遂前往齐国纳币，为鲁文公婚姻做准备。** [[9]](#reading-note-9)

<a id="event-9"></a>

<a id="reading-event-10"></a>

10. **楚穆王商臣开始纪年，前625年为其元年。** 商臣在上一年弑父即位后，将自己原来做太子时的宫室赏给协助他的潘崇，并让潘崇担任要职；这属于其即位后的安排，不表示本年再发生一次政变。 [[10]](#reading-note-10)

> 吾未获死所

**[《左传》](../../sources/春秋左传/有标点原文/bce-0625.md#t002)**

> 吾与女为难

**[《左传》](../../sources/春秋左传/有标点原文/bce-0625.md#t002)**

> 周志》有之，勇则害上，不登于明堂。死而不义，非勇也。共用之谓勇。吾以勇求右，无勇而黜，亦其所也。谓上不我知，黜而宜，乃知我矣。子姑待之

> 战于殽也，晋梁弘御戎，莱驹为右。战之明日，晋襄公缚秦囚，使莱驹以戈斩之。囚呼，莱驹失戈，狼瞫取戈以斩囚，禽之以从公乘，遂以为右。箕之役，先轸黜之而立续简伯。狼瞫怒。其友曰：“盍死之？”瞫曰：“吾未获死所。”其友曰：“吾与女为难。”瞫曰：“《周志》有之，勇则害上，不登于明堂。死而不义，非勇也。共用之谓勇。吾以勇求右，无勇而黜，亦其所也。谓上不我知，黜而宜，乃知我矣。子姑待之。”及彭衙，既陈，以其属驰秦师，死焉。晋师从之，大败秦师。君子谓：“狼瞫于是乎君子。《诗》曰：‘君子如怒，乱庶遄沮。’又曰：‘王赫斯怒，爰整其旅。’怒不作乱，而以从师，可谓君子矣。

### 7. 八月，鲁国在太庙大祭时把僖公神位升到闵公之前

[返回正文第7条](#reading-event-7)


<!-- century-0700-0601-primary -->

**[《春秋》本年经文](../../sources/春秋左传/有标点原文/bce-0625.md#batch-20261109-j006)**

> 八月丁卯，大事于大庙，跻僖公。

**[《左传》本年传文](../../sources/春秋左传/有标点原文/bce-0625.md#batch-20261109-t007)**

> 秋八月丁卯，大事于大庙，跻僖公，逆祀也。于是夏父弗忌为宗伯，尊僖公，且明见曰：“吾见新鬼大，故鬼小。先大后小，顺也。跻圣贤，明也。明顺，礼也。”君子以为失礼。礼无不顺。祀，国之大事也，而逆之，可谓礼乎？子虽齐圣，不先父食久矣。故禹不先鲧，汤不先契，文、武不先不窋。宋祖帝乙，郑祖厉王，犹上祖也。是以《鲁颂》曰：“春秋匪解，享祀不忒，皇皇后帝，皇祖后稷。”君子曰礼，谓其后稷亲而先帝也。《诗》曰：“问我诸姑，遂及伯姊。”君子曰礼，谓其姊亲而先姑也。仲尼曰：“臧文仲，其不仁者三，不知者三。下展禽，废六关，妾织蒲，三不仁也。作虚器，纵逆祀，祀爰居，三不知也。”

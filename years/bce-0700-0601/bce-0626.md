# 公元前626年（鲁文公元年）

[← 上一张已编年页：公元前627年](bce-0627.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前625年 →](bce-0625.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁文公正式即位。** 僖公死后，鲁国完成正常继承。 [[1]](#note-1)

<a id="event-2"></a>

2. **二月癸亥，发生日食。** 同期周王派内史叔服来参加僖公葬礼。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏四月，鲁国安葬僖公；周王又派毛伯赐文公命服，叔孙得臣随后到王室拜谢。** 鲁与周王室完成新君即位后的礼仪往来。 [[3]](#note-3)

<a id="event-4"></a>

4. **晋襄公因卫成公此前不朝晋而伐卫，围戚并夺取该地；卫国随后反攻晋国。** 晋文公死后，晋国仍试图维持霸主威望。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋，公孙敖在戚地会见晋襄公，处理晋重新划定戚田的问题。** 鲁国继续参与晋主导的诸侯秩序。 [[5]](#note-5)

<a id="event-6"></a>

6. **楚成王原本立商臣为太子，后来又想废商臣改立王子职。** 商臣确认消息后与老师潘崇策划政变。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬十月，商臣率宫甲包围楚成王。** 成王请求吃过熊掌再死，商臣没有答应；成王随后自缢，商臣即位，是为楚穆王。楚国发生父子相弑的重大政变。 [[7]](#note-7)

<a id="event-8"></a>

8. **公孙敖前往齐国正式聘问。** 新君即位后，鲁国开始重新修复外援与旧好。 [[8]](#note-8)

<a id="event-9"></a>

9. **秦穆公在殽之败后没有杀孟明视，反而继续让他执政。** 秦国把战败责任归于国君贪功，为之后继续伐晋保留了核心将领。 [[9]](#note-9)

<a id="event-10"></a>

10. **鲁国本年将闰月置在三月，传文批评这种安排。** 作者从一年开始、中间校正和岁末归余的原则解释“不合礼”的理由。记录保留古历原文，不自行计算成公历中的闰三月。 [[10]](#note-10)

<a id="卷026闰三月是本页同一条置闰记载"></a>
### 卷026｜闰三月是本页同一条置闰记载

[《历书》P007](../../sources/摘录/史记-卷026-历书.md#p007)以周襄王二十六年记这次闰三月；对应本页鲁文公元年，仍接[原有第10条](#event-10)和[《左传》全文](#cq-source-38)，不新增第二次闰月。《历书》“春秋非之”是对《春秋》传义的概称，今见直接写出“非礼也”及履端、举正、归余三原则的是[《左传·文公元年》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E6%96%87%E5%85%AC.md#ref-52de22cd009623)，不能把这段传文冒充《春秋》经文逐字所载。

“归邪”古注音余，与传文“归馀／归餘”互见。这里保存的是古代对于置闰次序的议论；没有逐日重建鲁历，更不以现代公历闰年规则证明此闰月的天文学误差。详见[春秋归年](../../meta/考证/史记-卷026-纪年与异说.md#春秋)。

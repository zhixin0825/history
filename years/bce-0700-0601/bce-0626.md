<a id="event-1"></a>

<a id="event-3"></a>

1. **鲁文公即位，葬僖公并受王室命服。** 春，鲁文公即位。四月，鲁国安葬僖公。周王派毛伯赐文公命服，叔孙得臣赴周拜谢。 [[1]](#note-1)

<a id="event-2"></a>

2. **二月癸亥，发生日食。** 同期周王派内史叔服来参加僖公葬礼。 [[2]](#note-2)

<a id="event-4"></a>

<a id="event-5"></a>

3. **晋伐卫取戚，卫反攻，鲁公孙敖赴戚交涉。** 卫成公先前未朝晋，晋襄公伐卫并夺戚，卫出兵反攻。秋，鲁公孙敖在戚见晋襄公，处理晋方划定戚地田界之事。 [[3]](#note-4)

<a id="event-6"></a>

<a id="event-7"></a>

4. **商臣率宫甲围楚成王，自立为君。** 子上早先以楚王年少、多内宠且楚有立少的旧例劝楚成王勿早立商臣，成王未听。后来成王想废商臣、改立公子职，潘崇教商臣以失礼试探江芈，江芈发怒泄露实情。商臣不愿出逃或服事新太子。冬十月，商臣率宫甲围成王，也不允成王吃过熊掌再死。成王丁未自缢，商臣继为楚穆王，将太子宫交给潘崇，任其为太师、掌国政。 [[4]](#note-6)

<a id="event-8"></a>

5. **公孙敖前往齐国正式聘问。** 新君即位后，鲁国开始重新修复外援与旧好。 [[5]](#note-8)

<a id="event-9"></a>

6. **秦穆公在殽之败后没有杀孟明视，反而继续让他执政。** 秦国把战败责任归于国君贪功，为之后继续伐晋保留了核心将领。 [[6]](#note-9)

<a id="event-10"></a>

7. **鲁国本年将闰月置在三月，传文批评这种安排。** 作者从一年开始、中间校正和岁末归余的原则解释“不合礼”的理由。记录保留古历原文，不自行计算成公历中的闰三月。 [[7]](#note-10)

### 4. 商臣率宫甲围楚成王，自立为君

[返回正文第4条](#event-6)

**[《左传》鲁文公1年传文（前626年）](../../拆分史书/左传/bce-0626.md#batch-20261109-t007)**

> 初，楚子将以商臣为大子，访诸令尹子上。子上曰：“君之齿未也，而又多爱，黜乃乱也。楚国之举，恒在少者。且是人也，蠭目而豺声，忍人也，不可立也。”弗听。既又欲立王子职而黜大子商臣。商臣闻之而未察，告其师潘崇曰：“若之何而察之？”潘崇曰：“享江芈而勿敬也。”从之。江芈怒曰：“呼，役夫！宜君王之欲杀女而立职也。”告潘崇曰：“信矣。”潘崇曰：“能事诸乎？”曰：“不能。”“能行乎？”曰：“不能。”“能行大事乎？”曰：“能。”

### 卷026｜闰三月是本页同一条置闰记载

[《历书》P007](../../拆分史书/史记/卷026.md#p007)以周襄王二十六年记这次闰三月；对应本页鲁文公元年，仍接[原有第10条](#event-10)和[《左传》全文](#cq-source-38)，不新增第二次闰月。《历书》“春秋非之”是对《春秋》传义的概称，今见直接写出“非礼也”及履端、举正、归余三原则的是[《左传·文公元年》](../../拆分史书/左传/异本/春秋左氏傳-文公.md#%E6%96%87%E5%85%AC%E5%85%83%E5%B9%B4)，不能把这段传文冒充《春秋》经文逐字所载。

“归邪”古注音余，与传文“归馀／归餘”互见。这里保存的是古代对于置闰次序的议论；没有逐日重建鲁历，更不以现代公历闰年规则证明此闰月的天文学误差。详见[春秋归年](../../拆分史书/史记/卷026.md#kao-52578ba700-389e68053)。

# 公元前627年（鲁僖公三十三年）

[← 上一张已编年页：公元前628年](bce-0628.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前626年 →](bce-0626.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **春，秦军经过周王城北门时表现轻慢，继续秘密东进郑国。** 王孙满当场判断这支军队轻而无礼，进入险地后必败。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **郑商人弦高在途中遇到秦军，假称奉郑君之命用牛犒军，同时急报郑国。** 郑国立即检查秦国驻客，发现他们已经束装厉兵，遂委婉逐客。 弦高原准备到周地经商，遇秦军后以十二头牛犒劳，使对方以为郑已有备。 [[2]](#reading-note-2)

   郑文公上一年去世后，子兰继位，是为郑穆公；这一年为郑穆公元年。

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **秦将孟明见郑国已有准备，放弃袭郑，转而灭滑国后回师。** 秦国远征目标由郑变滑。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **夏四月，晋国与姜戎在殽山伏击秦军，大破秦师，俘获孟明视、西乞术、白乙丙。** 晋襄公在父丧期间以黑色丧服出战，晋国由此“始墨”。 栾枝主张念秦助先君之恩，先轸则认为秦趁晋丧、侵伐同姓，已经不值得报德；晋于是决定截击归秦之师。 [[4]](#reading-note-4)

<a id="event-5"></a>

<a id="reading-event-5"></a>

5. **晋文公夫人文嬴请求释放秦国三帅，晋襄公同意；先轸发现后大怒，但追赶已来不及。** 三将最终渡河返秦。 秦女向襄公说秦要取回三将治罪，襄公允其归。先轸闻讯责备襄公，襄公命阳处父追赶，三将已渡河上船，只遥拜而不肯回来。 [[5]](#reading-note-5)

<a id="event-6"></a>

<a id="reading-event-6"></a>

6. **秦穆公穿素服到郊外迎接败军，公开承认自己不听蹇叔是错误，并继续任用孟明。** 秦国没有把败责全部推给将领。 [[6]](#reading-note-6)

   三将回秦后并未按文嬴的说法被杀，穆公反而恢复其原有官秩，要求继续任事。这也解释了孟明等为什么还会出现在后面的战争中。

<a id="event-7"></a>

<a id="reading-event-7"></a>

7. **齐国派国归父来鲁聘问，礼仪周全。** 臧文仲因此认为齐国仍有礼，劝僖公亲自朝齐。 [[7]](#reading-note-7)

<a id="event-8"></a>

<a id="reading-event-8"></a>

8. **狄人趁晋文公新丧进攻齐国。** 北方压力仍在持续。 [[8]](#reading-note-8)

<a id="event-9"></a>

<a id="reading-event-9"></a>

9. **鲁僖公为报升陉之败出兵伐邾，夺取訾娄；秋天公子遂又再次伐邾。** 鲁邾旧怨延续多年。 [[9]](#reading-note-9)

<a id="event-10"></a>

<a id="reading-event-10"></a>

10. **晋国在箕地击败狄军，先轸战死。** 他此前因晋襄公释放秦将而对国君失礼，自认为有罪，最终免胄冲入狄阵而死。 [[10]](#reading-note-10)

<a id="reading-event-11"></a>

11. **箕之战以后，晋襄公升赏先且居、胥臣与郤缺。** 先且居被命为中军将，胥臣因早先推荐郤缺而受赏，郤缺也升为卿并收回冀地。早年胥臣途经冀，看到郤缺耕田、妻子送饭而相敬，便向晋文公推荐；文公虽顾虑其父有罪，仍任用他。 [[11]](#reading-note-11)

<a id="event-11"></a>

<a id="reading-event-12"></a>

12. **冬，鲁僖公前往齐国朝见并慰问齐国受狄侵扰；回国后十二月乙巳，死于小寝。** 鲁僖公三十三年统治结束。 [[12]](#reading-note-12)

<a id="event-12"></a>

<a id="reading-event-13"></a>

13. **当年冬季霜降却没有杀死草木，李、梅反而结果。** 气候异常被记录。 [[13]](#reading-note-13)

<a id="event-13"></a>

<a id="reading-event-14"></a>

14. **晋、陈、郑联合伐许，追究许国反复依附楚国。** 楚国同时在陈、蔡、郑方向反击，中原晋楚竞争并未因城濮结束。 [[14]](#reading-note-14)

<a id="event-14"></a>

<a id="reading-event-15"></a>

15. **楚令尹子上与晋阳处父隔泜水对峙，最终双方都撤退；子上回楚后被太子商臣诬陷受晋贿赂，被楚王杀死。** 楚国内部政治进一步恶化。 [[15]](#reading-note-15)

<a id="event-15"></a>

<a id="reading-event-16"></a>

16. **僖公后来下葬，但鲁国制作神主的时间被认为过慢。** 丧礼程序出现争议。 [[16]](#reading-note-16)

<a id="event-16"></a>

<a id="reading-event-17"></a>

17. **夏癸巳，晋国安葬晋文公。** 殽之战发生在文公丧期之中，战后晋国才完成国君葬礼。 [[17]](#reading-note-17)

<a id="hs-event-18"></a>

18. **鲁霜不杀草。** [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **鲁冬李梅结实。** [[19]](#hs-note-19)

> 鄭人有賣鄭於秦曰：「我主其城門，鄭可襲也。」繆公問蹇叔、百里傒，對曰：「徑數國千里而襲人，希有得利者。且人賣鄭，庸知我國人不有以我情告鄭者乎？不可。」繆公曰：「子不知也，吾已決矣。」遂發兵，使百里傒子孟明視，蹇叔子西乞術及白乙丙將兵。行日，百里傒、蹇叔二人哭之。繆公聞，怒曰：「孤發兵而子沮哭吾軍，何也？」二老曰：「臣非敢沮君軍。軍行，臣子與往；臣老，遲還恐不相見，故哭耳。」二老退，謂其子曰：「汝軍即敗，必於殽阨矣。」三十三年春，秦兵遂東，更晉地，過周北門。周王孫滿曰：「秦師無禮，不敗何待！」兵至滑，鄭販賣賈人弦高，持十二牛將賣之周，見秦兵，恐死虜，因獻其牛，曰：「聞大國將誅鄭，鄭君謹修守御備，使臣以牛十二勞軍士。」秦三將軍相謂曰：「將襲鄭，鄭今已覺之，往無及已。」滅滑。滑，晉之邊邑也。

### 5. 晋文公夫人文嬴请求释放秦国三帅，晋襄公同意；先轸发现后大怒，但追赶已来不及

[返回正文第5条](#reading-event-5)

> 文嬴请三帅，曰：“彼实构吾二君，寡君若得而食之，不厌，君何辱讨焉！使归就戮于秦，以逞寡君之志，若何？”公许之。先轸朝，问秦囚。公曰：“夫人请之，吾舍之矣。”先轸怒曰：“武夫力而拘诸原，妇人暂而免诸国。堕军实而长寇仇，亡无日矣。”不顾而唾。公使阳处父追之，及诸河，则在舟中矣。释左骖，以公命赠孟明。孟明稽首曰：“君之惠，不以累臣衅鼓，使归就戮于秦，寡君之以为戮，死且不朽若从君惠而免之，三年将拜君赐。”

**[卷005 P030](../../sources/摘录/史记-卷005-秦本纪.md#p030)**

> 當是時，晉文公喪尚未葬。太子襄公怒曰：「秦侮我孤，因喪破我滑。」遂墨衰绖，發兵遮秦兵於殽，擊之，大破秦軍，無一人得脫者。虜秦三將以歸。文公夫人，秦女也，為秦三囚將請曰：「繆公之怨此三人入於骨髓，願令此三人歸，令我君得自快烹之。」晉君許之，歸秦三將。三將至，繆公素服郊迎，向三人哭曰：「孤以不用百里傒、蹇叔言以辱三子，三子何罪乎？子其悉心雪恥，毋怠。」遂復三人官秩如故，愈益厚之。

# 公元前627年（鲁僖公三十三年）

[← 上一张已编年页：公元前628年](bce-0628.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前626年 →](bce-0626.md)

<a id="event-1"></a>

1. **春，秦军经过周王城北门时表现轻慢，继续秘密东进郑国。** 王孙满当场判断这支军队轻而无礼，进入险地后必败。[[1]](#note-1)

[补充史料与年次说明](#sj005-084-note)


<a id="event-2"></a>

2. **郑商人弦高在途中遇到秦军，假称奉郑君之命用牛犒军，同时急报郑国。** 郑国立即检查秦国驻客，发现他们已经束装厉兵，遂委婉逐客。[[2]](#note-2)

郑文公上一年去世后，子兰继位，是为郑穆公；这一年为郑穆公元年。[卷014年表原行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0627) · [《郑世家·郑缪公》](https://zh.wikisource.org/wiki/史記/卷042#鄭繆公)

[补充史料与年次说明](#sj005-085-note)


<a id="event-3"></a>

3. **秦将孟明见郑国已有准备，放弃袭郑，转而灭滑国后回师。** 秦国远征目标由郑变滑。[[3]](#note-3)

[补充史料与年次说明](#sj005-086-note)


<a id="event-4"></a>

4. **夏四月，晋国与姜戎在殽山伏击秦军，大破秦师，俘获孟明视、西乞术、白乙丙。** 晋襄公在父丧期间以黑色丧服出战，晋国由此“始墨”。[[4]](#note-4)

[补充史料与年次说明](#sj005-087-note)


<a id="event-5"></a>

5. **晋文公夫人文嬴请求释放秦国三帅，晋襄公同意；先轸发现后大怒，但追赶已来不及。** 三将最终渡河返秦。[[5]](#note-5)

[补充史料与年次说明](#sj005-088-note)


<a id="event-6"></a>

6. **秦穆公穿素服到郊外迎接败军，公开承认自己不听蹇叔是错误，并继续任用孟明。** 秦国没有把败责全部推给将领。[[6]](#note-6)

三将回秦后并未按文嬴的说法被杀，穆公反而恢复其原有官秩，要求继续任事。这也解释了孟明等为什么还会出现在后面的战争中。

[补充史料与年次说明](#sj005-089-note)


<a id="event-7"></a>

7. **齐国派国归父来鲁聘问，礼仪周全。** 臧文仲因此认为齐国仍有礼，劝僖公亲自朝齐。[[7]](#note-7)

<a id="event-8"></a>

8. **狄人趁晋文公新丧进攻齐国。** 北方压力仍在持续。[[8]](#note-8)

<a id="event-9"></a>

9. **鲁僖公为报升陉之败出兵伐邾，夺取訾娄；秋天公子遂又再次伐邾。** 鲁邾旧怨延续多年。[[9]](#note-9)

<a id="event-10"></a>

10. **晋国在箕地击败狄军，先轸战死。** 他此前因晋襄公释放秦将而对国君失礼，自认为有罪，最终免胄冲入狄阵而死。[[10]](#note-10)

**箕之战以后，晋襄公升赏先且居、胥臣与郤缺。** 先且居被命为中军将，胥臣因早先推荐郤缺而受赏，郤缺也升为卿并收回冀地。早年胥臣途经冀，看到郤缺耕田、妻子送饭而相敬，便向晋文公推荐；文公虽顾虑其父有罪，仍任用他。 [看原文与说明](#cq-source-37)

<a id="event-11"></a>

11. **冬，鲁僖公前往齐国朝见并慰问齐国受狄侵扰；回国后十二月乙巳，死于小寝。** 鲁僖公三十三年统治结束。[[11]](#note-11)

<a id="event-12"></a>

12. **当年冬季霜降却没有杀死草木，李、梅反而结果。** 气候异常被记录。[[12]](#note-12)

<a id="event-13"></a>

13. **晋、陈、郑联合伐许，追究许国反复依附楚国。** 楚国同时在陈、蔡、郑方向反击，中原晋楚竞争并未因城濮结束。[[13]](#note-13)

<a id="event-14"></a>

14. **楚令尹子上与晋阳处父隔泜水对峙，最终双方都撤退；子上回楚后被太子商臣诬陷受晋贿赂，被楚王杀死。** 楚国内部政治进一步恶化。[[14]](#note-14)

<a id="event-15"></a>

15. **僖公后来下葬，但鲁国制作神主的时间被认为过慢。** 丧礼程序出现争议。[[15]](#note-15)

<a id="event-16"></a>

16. **夏癸巳，晋国安葬晋文公。** 殽之战发生在文公丧期之中，战后晋国才完成国君葬礼。[[16]](#note-16)

## 补充核对的史料

<a id="cq-source-37"></a>
### 核对37｜箕之战以后，晋襄公升赏先且居、胥臣与郤缺

**说明：**臼季即本条推荐者胥臣。妻子送饭、晋文公首次任用是此前经历；本年实际记事是晋襄公在箕战后的命赏。

<details>
<summary>传 T010｜原文</summary>

> 初，臼季使过冀，见冀缺耨，其妻馌之。敬，相待如宾。与之归，言诸文公曰：“敬，德之聚也。能敬必有德，德以治民，君请用之。臣闻之，出门如宾，承事如祭，仁之则也。”公曰：“其父有罪，可乎？”对曰：“舜之罪也殛鲧，其举也兴禹。管敬仲，桓之贼也，实相以济。《康诰》曰：‘父不慈，子不祗，兄不友，弟不共，不相及也。’《诗》曰：‘采葑采菲，无以下体。’君取节焉可也。”文公以为下军大夫。反自箕，襄公以三命命先且居将中军，以再命命先茅之县赏胥臣曰：“举郤缺，子之功也。”以一命命郤缺为卿，复与之冀，亦未有军行。

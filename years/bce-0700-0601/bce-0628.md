# 公元前628年（鲁僖公三十二年）

[← 上一张已编年页：公元前629年](bce-0629.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前627年 →](bce-0627.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，楚国主动向晋国求和，晋国派阳处父回应，晋楚开始恢复正式往来。** 城濮大战后的敌对关系出现松动。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏四月，郑文公去世。** 郑国即将换君，而秦国驻郑将领仍掌握北门钥匙。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，狄国内乱，卫国趁机进攻狄人；秋天双方重新结盟。** 卫国在迁都帝丘后逐渐恢复主动。 [[3]](#note-3)

<a id="event-4"></a>

4. **冬十二月，晋文公重耳去世。** 晋国霸业刚建立不久，就进入新君继承。 [[4]](#note-4)

    [卷四互见与归年](#sj004-628-1)

<a id="event-5"></a>

5. **秦国驻郑将领杞子向秦穆公报告：自己掌握郑都北门，如果秦军秘密东来，可以袭取郑国。** 秦穆公决定发动远征。 [[5]](#note-5)

   穆公听到郑国守门者的许诺以后，坚持出兵。二老反对的理由既有路途遥远，也有秦方消息同样可能泄漏；这不是可以单靠内应保证成功的计划。

<a id="event-6"></a>

6. **老臣蹇叔强烈反对远袭郑国，认为千里劳师、敌国必有准备，而且回程必会经过晋国险地。** 秦穆公没有听从，仍命孟明视、西乞术、白乙丙率军东进。 [[6]](#note-6)

<a id="event-7"></a>

7. **蹇叔哭送秦军，预言晋国会在殽山伏击，并告诉随军儿子自己将到那里收尸。** 殽之战已经埋下结局。 [[7]](#note-7)

### 5. 秦国驻郑将领杞子向秦穆公报告：自己掌握郑都北门，如果秦军秘密东来，可以袭取郑国

[返回正文第5条](#event-5)

**[卷005 P029](../../sources/摘录/史记-卷005-秦本纪.md#p029)**

> 鄭人有賣鄭於秦曰：「我主其城門，鄭可襲也。」繆公問蹇叔、百里傒，對曰：「徑數國千里而襲人，希有得利者。且人賣鄭，庸知我國人不有以我情告鄭者乎？不可。」繆公曰：「子不知也，吾已決矣。」遂發兵，使百里傒子孟明視，蹇叔子西乞術及白乙丙將兵。行日，百里傒、蹇叔二人哭之。繆公聞，怒曰：「孤發兵而子沮哭吾軍，何也？」二老曰：「臣非敢沮君軍。軍行，臣子與往；臣老，遲還恐不相見，故哭耳。」二老退，謂其子曰：「汝軍即敗，必於殽阨矣。」三十三年春，秦兵遂東，更晉地，過周北門。周王孫滿曰：「秦師無禮，不敗何待！」兵至滑，鄭販賣賈人弦高，持十二牛將賣之周，見秦兵，恐死虜，因獻其牛，曰：「聞大國將誅鄭，鄭君謹修守御備，使臣以牛十二勞軍士。」秦三將軍相謂曰：「將襲鄭，鄭今已覺之，往無及已。」滅滑。滑，晉之邊邑也。

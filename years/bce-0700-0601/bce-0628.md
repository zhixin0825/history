# 公元前628年（鲁僖公三十二年）

[← 上一张已编年页：公元前629年](bce-0629.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前627年 →](bce-0627.md)

<a id="event-1"></a>

1. **春，楚国主动向晋国求和，晋国派阳处父回应，晋楚开始恢复正式往来。** 城濮大战后的敌对关系出现松动。[[1]](#note-1)

<a id="event-2"></a>

2. **夏四月，郑文公去世。** 郑国即将换君，而秦国驻郑将领仍掌握北门钥匙。[[2]](#note-2)

<a id="event-3"></a>

3. **夏，狄国内乱，卫国趁机进攻狄人；秋天双方重新结盟。** 卫国在迁都帝丘后逐渐恢复主动。[[3]](#note-3)

<a id="event-4"></a>

4. **冬十二月，晋文公重耳去世。** 晋国霸业刚建立不久，就进入新君继承。[[4]](#note-4)

 [卷四互见与归年](#sj004-628-1)


<a id="event-5"></a>

5. **秦国驻郑将领杞子向秦穆公报告：自己掌握郑都北门，如果秦军秘密东来，可以袭取郑国。** 秦穆公决定发动远征。[[5]](#note-5)

<a id="event-6"></a>

6. **老臣蹇叔强烈反对远袭郑国，认为千里劳师、敌国必有准备，而且回程必会经过晋国险地。** 秦穆公没有听从，仍命孟明视、西乞术、白乙丙率军东进。[[6]](#note-6)

<a id="event-7"></a>

7. **蹇叔哭送秦军，预言晋国会在殽山伏击，并告诉随军儿子自己将到那里收尸。** 殽之战已经埋下结局。[[7]](#note-7)

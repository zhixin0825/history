# 公元前629年（鲁僖公三十一年）

<a id="event-1"></a>

<a id="event-2"></a>

1. **晋分曹地给鲁，鲁获济西田并遣使致谢。** 春，晋国重新分配曹地，鲁国取得济西田。鲁公子遂赴晋致谢。 [[1]](#note-1)

<a id="event-3"></a>

2. **夏，鲁国连续四次占卜郊祭日期都不吉，于是免去牺牲，却仍然举行三望。** 这种祭祀处理被认为不合常礼。 [[2]](#note-3)

<a id="event-4"></a>

3. **秋，晋国在清原大阅，建立五军以防御狄人，赵衰成为卿。** 晋文公继续扩充军事体系。 [[3]](#note-4)

<a id="event-5"></a>

4. **冬，杞伯姬来鲁为杞国求娶妇人。** 鲁杞婚姻关系延续。 [[4]](#note-5)

<a id="event-6"></a>

5. **狄人包围卫国，卫人被迫把都城迁到帝丘。** 卜辞称这里可保三百年，卫国由此进入新的都城时期。 [[5]](#note-6)

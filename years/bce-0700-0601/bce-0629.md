# 公元前629年（鲁僖公三十一年）

[← 上一张已编年页：公元前630年](bce-0630.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前628年 →](bce-0628.md)

<a id="event-1"></a>

1. **春，鲁国取得济西田地，这是晋国重新分配曹国土地的一部分。** 鲁国派臧文仲迅速前往办理，避免错失分地机会。[[1]](#note-1)

<a id="event-2"></a>

2. **公子遂赴晋，感谢晋国分给鲁国曹地。** 鲁晋关系进一步制度化。[[2]](#note-2)

<a id="event-3"></a>

3. **夏，鲁国连续四次占卜郊祭日期都不吉，于是免去牺牲，却仍然举行三望。** 这种祭祀处理被认为不合常礼。[[3]](#note-3)

<a id="event-4"></a>

4. **秋，晋国在清原大阅，建立五军以防御狄人，赵衰成为卿。** 晋文公继续扩充军事体系。[[4]](#note-4)

<a id="event-5"></a>

5. **冬，杞伯姬来鲁为杞国求娶妇人。** 鲁杞婚姻关系延续。[[5]](#note-5)

<a id="event-6"></a>

6. **狄人包围卫国，卫人被迫把都城迁到帝丘。** 卜辞称这里可保三百年，卫国由此进入新的都城时期。[[6]](#note-6)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公三十一年》**：“三十有一年春，取济西田。”  
   **《左传·僖公三十一年》**：“分曹地也。”

<a id="note-2"></a>

2. **《春秋·僖公三十一年》**：“公子遂如晋。”  
   **《左传·僖公三十一年》**：“拜曹田也。”

<a id="note-3"></a>

3. **《春秋·僖公三十一年》**：“夏四月，四卜郊不从，乃免牲，犹三望。”  
   **《左传·僖公三十一年》**详记其“不郊而望”的礼制问题。

<a id="note-4"></a>

4. **《左传·僖公三十一年》**：“秋，晋蒐于清原，作五军以御狄。赵衰为卿。”

<a id="note-5"></a>

5. **《春秋·僖公三十一年》**：“冬，杞伯姬来求妇。”

<a id="note-6"></a>

6. **《春秋·僖公三十一年》**：“狄围卫。十有二月，卫迁于帝丘。”  
   **《左传·僖公三十一年》**：“卜曰三百年。”

# 公元前630年（鲁僖公三十年）

[← 上一张已编年页：公元前631年](bce-0631.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前629年 →](bce-0629.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，晋国先侵郑试探；夏，狄人趁晋国牵制郑国时侵齐。** 中原霸权体系同时受到多线压力。 [[1]](#note-1)

<a id="event-2"></a>

2. **秋，卫国内部杀死元咺和公子瑕，卫成公重新回国复位。** 卫国多年君臣冲突暂时结束。 [[2]](#note-2)

<a id="event-3"></a>

3. **九月，晋、秦两国联合包围郑国。** 晋国追究郑国过去对重耳无礼且反复亲楚，秦国则配合晋国东进。 [[3]](#note-3)

<a id="event-4"></a>

4. **郑国老臣烛之武夜间从城上缒出，游说秦穆公。** 他指出灭郑只会让晋国变强，而且晋国过去对秦失信，秦不应替晋扩大东部领土。 [[4]](#note-4)

<a id="event-5"></a>

5. **秦穆公接受烛之武意见，与郑国单独结盟，留下杞子等三将驻郑后撤军。** 晋文公拒绝子犯追击秦军的建议，也随即撤围。 [[5]](#note-5)

<a id="event-6"></a>

6. **郑国公子兰被迎回立为太子，用来与晋国和解。** 郑国在晋楚之间再次调整继承与外交。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬，周王派周公阅来鲁聘问。** 鲁国又派公子遂先到周王室，随后首次正式聘问晋国。 [[7]](#note-7)

<a id="event-8"></a>

8. **介国人侵入萧地。** 这是本年较小的一次边境军事行动。 [[8]](#note-8)

<a id="event-9"></a>

9. **东门襄仲本拟出聘周王室，随后首次出聘晋国。** 鲁国与晋的聘问关系由此又添一项具体使事。原文说的是襄仲的行动，不与本年周使来鲁混成一趟出行。 [[9]](#note-9)

### 3. 九月，晋、秦两国联合包围郑国

[返回正文第3条](#event-3)

**[《春秋》鲁僖公30年经文（前630年）](../../sources/春秋左传/有标点原文/bce-0630.md#j005)**

> 晋人、秦人围郑。

**[《左传》鲁僖公30年传文（前630年）](../../sources/春秋左传/有标点原文/bce-0630.md#t005)**

> 九月甲午，晋侯、秦伯围郑，以其无礼于晋，且贰于楚也。晋军函陵，秦军氾南。佚之狐言于郑伯曰：“国危矣，若使烛之武见秦君，师必退。”公从之。辞曰：“臣之壮也，犹不如人，今老矣，无能为也已。”公曰：“吾不能早用子，今急而求子，是寡人之过也。然郑亡，子亦有不利焉。”许之，夜缒而出，见秦伯曰：“秦、晋围郑，郑既知亡矣。若亡郑而有益于君，敢以烦执事。越国以鄙远，君知其难也，焉用亡郑以陪邻。邻之厚，君之薄也。若舍郑以为东道主，行李之往来，共其乏困，君亦无所害。且君尝为晋君赐矣，许君焦、瑕，朝济而夕设版焉，君之所知也。夫晋何厌之有？既东封郑，又欲肆其西封，若不阙秦，将焉取之？阙秦以利晋，唯君图之。”秦伯说，与郑人盟，使杞子、逢孙、扬孙戍之。乃还。

# 公元前631年（鲁僖公二十九年）

[← 上一张已编年页：公元前632年](bce-0632.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前630年 →](bce-0630.md)

<a id="event-1"></a>

1. **春，介国的葛卢来鲁朝见，但鲁僖公还在诸侯会盟途中，没有见到他。** 鲁国仍按礼供应草料和粮食。[[1]](#note-1)

<a id="event-2"></a>

2. **鲁僖公从围许战事返回。** 上一年的晋国霸权整顿告一段落。[[2]](#note-2)

<a id="event-3"></a>

3. **夏，鲁僖公会同周王使者及晋、宋、齐、陈、蔡、秦大夫在翟泉结盟。** 这次盟约重申践土之盟，并开始谋划伐郑。[[3]](#note-3)

<a id="event-4"></a>

4. **秋，鲁国发生严重冰雹灾害。** [[4]](#note-4)

<a id="event-5"></a>

5. **冬，介葛卢因春天未能见到僖公，再次来鲁朝见。** 鲁国这次增加宴饮礼遇。[[5]](#note-5)

<a id="sj014-0631-chen"></a>

6. **陈国从本年开始以陈共公朔的元年纪事。** 陈穆公款在前632年参加诸侯会盟后去世，其子朔继位为共公。本年陈国大夫参与翟泉之盟，标志陈国仍在晋文公主导的联盟关系之中。 [[6]](#sj014-0631-chen-note)

<a id="note-2"></a>

2. **《春秋·僖公二十九年》**：“公至自围许。”

<a id="note-3"></a>

3. **《春秋·僖公二十九年》**：“夏六月，会王人、晋人、宋人、齐人、陈人、蔡人、秦人盟于翟泉。”  
   **《左传·僖公二十九年》**：“寻践土之盟，且谋伐郑也。”

   **《左传·僖公二十九年》**：“为灾也。”

5. **《春秋·僖公二十九年》**：“冬，介葛卢来。”

## 补充史料与异说

<a id="sj014-0631-chen-note"></a>
### 卷014陈栏｜陈共公朔元年

[《十二诸侯年表》前631年陈栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0631)列「陳共公朔元年」；[《陈杞世家》](https://zh.wikisource.org/wiki/史記/卷036#陳)记穆公十六年卒、子共公朔立，并把穆公之死联系到晋文公败楚的城濮年。[前632年](bce-0632.md#event-14)已写陈侯款去世，本年[翟泉会盟](#event-3)已有陈大夫参加，故只补新君元年，不重写父丧或会盟。

## 本年概述

鲁僖公从围许归国，夏日又参与翟泉之盟；诸国重申践土旧约，着手谋议伐郑。介葛卢春、冬两次来鲁，先因僖公在外而未见，后来获以加礼接待。陈共公进入元年，鲁国秋季遭大雹。

## 围许归国与翟泉续盟

<a id="bce0631-event-1"></a>

<a id="event-2"></a>

1. **鲁僖公从围许战事返回。** 上一年的晋国霸权整顿告一段落。 [[1]](#bce0631-note-1)

<a id="bce0631-event-2"></a>

<a id="event-3"></a>

2. **夏，鲁僖公会同周王使者及晋、宋、齐、陈、蔡、秦大夫在翟泉结盟。** 这次盟约重申践土之盟，并开始谋划伐郑。 [[2]](#bce0631-note-2)

<a id="bce0631-event-3"></a>

<a id="sj014-0631-chen"></a>

<a id="event-6"></a>

3. **陈国从本年开始以陈共公朔的元年纪事。** 陈穆公款在前632年参加诸侯会盟后去世，其子朔继位为共公。本年陈国大夫参与翟泉之盟，标志陈国仍在晋文公主导的联盟关系之中。 [[3]](#bce0631-note-3)

## 介葛卢来鲁与秋雹

<a id="bce0631-event-4"></a>

<a id="event-1"></a>

<a id="event-5"></a>

4. **介葛卢春、冬两次来鲁。** 春天介葛卢来鲁，僖公尚在外，未得相见；鲁国按礼供应草料、粮食。介葛卢冬天再次来见，鲁国增设宴饮以款待。 [[4]](#bce0631-note-4)

<a id="bce0631-event-5"></a>

<a id="event-4"></a>

<a id="hs-event-7"></a>

5. **鲁国秋季大雹。** 《春秋》记“秋，大雨雹”，《汉书·五行志》也系于鲁僖公二十九年。 [[5]](#bce0631-note-5)

### 补充史料与异说

<a id="sj014-0631-wei-variant"></a>
<a id="卷014卫栏晋以卫与宋的系年问题"></a>
#### 卷014卫栏｜「晋以卫与宋」的系年问题

[《十二诸侯年表》前631年卫栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0631)记「四晉以衛與宋」；但[《春秋》《左传·僖公二十九年》](../../sources/春秋左传/data/zz-05-29.json)本年主线为翟泉之盟，没有明确记下新的全卫交付。前一年[晋军干预卫国、卫侯被执](bce-0632.md#event-11)已经详细记录；暂把年表本格视为这一干预的另一纪年或简缩说法，不额外写成晋国于本年彻底把卫国交给宋国统治。

<a id="sj014-0631-chen-note"></a>
<a id="卷014陈栏陈共公朔元年"></a>
#### 卷014陈栏｜陈共公朔元年

[《十二诸侯年表》前631年陈栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0631)列「陳共公朔元年」；[《陈杞世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7036.md#ref-3987471b5a5e78)记穆公十六年卒、子共公朔立，并把穆公之死联系到晋文公败楚的城濮年。[前632年](bce-0632.md#event-14)已写陈侯款去世，本年[翟泉会盟](#event-3)已有陈大夫参加，故只补新君元年，不重写父丧或会盟。

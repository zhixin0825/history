# 公元前632年（鲁僖公二十八年）

[← 上一张已编年页：公元前633年](bce-0633.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前631年 →](bce-0631.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **春，晋文公先后进攻曹、卫，夺取五鹿；卫国拒绝借道后，晋军绕道渡河南下。** 晋国用打击楚国盟友的方式逼楚军从宋国撤兵。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **春，鲁国杀死驻卫的公子买，并向楚人解释。** 公子买率兵戍卫，楚方一度准备救卫，后来未能成行。鲁僖公害怕晋国，杀公子买以求解脱，向楚人说他未能完成戍守任务。鲁军当时是否听命于不同强国的处境，与实际告知对象分开交代。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **三月，晋军攻入曹国，俘曹伯，并特别保护曾在重耳流亡时礼遇他的僖负羁一家。** 晋文公把私人恩怨与国家战争结合起来处理。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **晋国私下答应恢复曹、卫，以此离间它们与楚国；同时拘押楚使宛春，激怒楚将子玉。** 曹、卫随即与楚断绝关系。 [[4]](#reading-note-4)

<a id="event-5"></a>

<a id="reading-event-5"></a>

5. **晋军按照重耳流亡时对楚成王的承诺主动退避三舍。** 楚军本可停止追击，子玉坚持继续推进，战争责任逐渐转向楚方。 [[5]](#reading-note-5)

<a id="event-6"></a>

<a id="reading-event-6"></a>

6. **夏四月，晋、宋、齐、秦联军与楚军在城濮决战。** 晋军先击溃陈、蔡部队，又以佯退、曳柴制造败逃假象，随后中军横击、上军夹攻，楚左右两军崩溃。 [[6]](#reading-note-6)

<a id="event-7"></a>

<a id="reading-event-7"></a>

7. **城濮之战以楚军大败告终，子玉虽收住中军，战后仍因楚王责难自杀。** 晋文公由此取得中原军事优势。 [[7]](#reading-note-7)

<a id="event-8"></a>

<a id="reading-event-8"></a>

8. **五月，晋文公在践土会盟诸侯，并把楚军俘虏献给周襄王。** 周王正式册命晋文公为侯伯，晋国取代齐国成为新的中原霸主；鲁僖公也在王所朝见周王。 [[8]](#reading-note-8)

<a id="event-9"></a>

<a id="reading-event-9"></a>

9. **卫侯因曾亲楚而出奔，后来获准复位；但回国时其前驱误杀叔武，元咺因此逃晋。** 卫国内部矛盾没有因城濮结束。 [[9]](#reading-note-9)

<a id="reading-event-10"></a>

10. **六月，卫侯郑从楚国回到卫国。** 归国日期及出发地在经文明确可见；与卫国拒战、立叔武及后续受拘等事分开，不省去“自楚复归”的环节。 [[10]](#reading-note-10)

<a id="event-10"></a>

<a id="reading-event-11"></a>

11. **冬，诸侯再会于温，晋文公召周王到河阳并让诸侯朝见。** 经文以“天王狩于河阳”保留王室名义，实际上显示晋霸权已经可以调动天子；鲁僖公又在王所朝见周王。 [[11]](#reading-note-11)

     [卷四互见与归年](#sj004-632-1)

<a id="event-11"></a>

<a id="reading-event-12"></a>

12. **卫侯与元咺在晋国诉讼，卫侯败诉，被晋国押送京师；元咺回卫另立公子瑕。** 晋国直接干预卫国内政。 [[12]](#reading-note-12)

<a id="event-12"></a>

<a id="reading-event-13"></a>

13. **诸侯继续围许；曹伯也恢复君位，并参加围许。** 晋国对不服者进行连续整顿。 [[13]](#reading-note-13)

<a id="event-13"></a>

<a id="reading-event-14"></a>

14. **晋国又建立三行以防御狄人。** 城濮胜利后，晋国继续改革军制。 [[14]](#reading-note-14)

<a id="event-14"></a>

<a id="reading-event-15"></a>

15. **本年还记录了三条较小事项：陈侯参加会盟后去世；秋天杞伯姬来鲁；公子遂前往齐国。** [[15]](#reading-note-15)

<a id="sj014-0632-qi"></a>

<a id="reading-event-16"></a>

16. **齐昭公潘进入元年纪年。** 前633年齐孝公昭去世后，异母弟潘继立为齐昭公；齐国虽有继承纷争，仍在本年派军参加晋、楚城濮之战，并随晋文公参加践土会盟。 [[16]](#reading-note-16)

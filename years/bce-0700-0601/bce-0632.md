# 公元前632年（鲁僖公二十八年）

[本年相关史料](#sources-start)

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **春，晋文公先后进攻曹、卫，夺取五鹿；卫国拒绝借道后，晋军绕道渡河南下。** 晋国用打击楚国盟友的方式逼楚军从宋国撤兵。 晋与齐还在敛盂结盟，卫侯请盟被拒；他想依楚，国人却希望取悦晋，遂迫使他出国。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **春，鲁国杀死驻卫的公子买，并向楚人解释。** 公子买率兵戍卫，楚方一度准备救卫，后来未能成行。鲁僖公害怕晋国，杀公子买以求解脱，向楚人说他未能完成戍守任务。鲁军当时是否听命于不同强国的处境，与实际告知对象分开交代。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **三月，晋军攻入曹国，俘曹伯，并特别保护曾在重耳流亡时礼遇他的僖负羁一家。** 晋文公把私人恩怨与国家战争结合起来处理，还责曹君不用僖负羁之言、让美女乘轩者多至三百。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **晋国以曹、卫牵动楚军，又以恢复两国为条件离间它们与楚国。** 宋再次告急时，文公顾念楚、宋昔日均曾礼待，进退为难；先轸建议拘曹伯、把曹卫地分给宋，迫使楚转而救其附国。楚成王本不愿与困而复国、已知险阻的重耳争战，只给坚持求战的子玉少量兵。楚使宛春提出复卫、封曹以解宋围；晋方一面私下许曹、卫复国，一面拘押宛春以激怒子玉，曹、卫随即与楚断绝关系。 [[4]](#reading-note-4)

<a id="event-5"></a>

<a id="reading-event-5"></a>

5. **晋军按照重耳流亡时对楚成王的承诺主动退避三舍。** 楚军本可停止追击，子玉坚持继续推进，战争责任逐渐转向楚方。 [[5]](#reading-note-5)

<a id="event-6"></a>

<a id="reading-event-6"></a>

6. **夏四月，晋、宋、齐、秦联军与楚军在城濮决战。** 晋军先击溃陈、蔡部队，又以佯退、曳柴制造败逃假象，随后中军横击、上军夹攻，楚左右两军崩溃，宋国之围由此解除。回国行赏时文公以狐偃居首：先轸的作战办法带来一时胜利，狐偃劝守信则被认为能长久立国。 [[6]](#reading-note-6)

<a id="event-7"></a>

<a id="reading-event-7"></a>

7. **城濮之战以楚军大败告终，子玉虽收住中军，战后仍因楚王责难自杀。** 晋文公由此取得中原军事优势。 胜后文公仍担心子玉在楚便会继续为患；听到子玉死讯才转忧为喜，认为再无人能这样危及自己。 [[7]](#reading-note-7)

<a id="event-8"></a>

<a id="reading-event-8"></a>

8. **五月，晋文公在践土会盟诸侯，并把楚军俘虏献给周襄王。** 周王正式册命晋文公为侯伯，晋国取代齐国成为新的中原霸主；鲁僖公也在王所朝见周王。 战后晋军到衡雍，并在践土营造王宫，为献俘和朝见作准备。先前助楚的郑国在楚败后求晋盟，晋文公与郑伯订盟；郑由此转入战后的晋方秩序。晋献楚俘、甲车百乘和徒兵千人，周使王子虎赐文公车服、弓矢、祭酒及虎贲。文公三辞后受命，王庭又举行诸侯盟誓。 [[8]](#reading-note-8)

<a id="event-9"></a>

<a id="reading-event-9"></a>

9. **卫侯因曾亲楚而出奔，后来获准复位；但回国时其前驱误杀叔武，元咺因此逃晋。** 卫国内部矛盾没有因城濮结束。 [[9]](#reading-note-9)

<a id="reading-event-10"></a>

10. **六月，卫侯郑从楚国回到卫国。** 归国日期及出发地在经文明确可见；与卫国拒战、立叔武及后续受拘等事分开，不省去“自楚复归”的环节。 [[10]](#reading-note-10)

<a id="event-10"></a>

<a id="reading-event-11"></a>

11. **冬，诸侯再会于温，晋文公召周王到河阳并让诸侯朝见。** 经文以“天王狩于河阳”保留王室名义，实际上显示晋霸权已经可以调动天子；鲁僖公又在王所朝见周王。 文公本想带诸侯朝周，又担心未能控制会众，便请周王以狩猎名义来河阳，让诸侯在此朝见。 [[11]](#reading-note-11)

     [卷四互见与归年](#sj004-632-1)

<a id="event-11"></a>

<a id="reading-event-12"></a>

12. **卫侯与元咺在晋国诉讼，卫侯败诉，被晋国押送京师；元咺回卫另立公子瑕。** 晋国直接干预卫国内政。 [[12]](#reading-note-12)

<a id="event-12"></a>

<a id="reading-event-13"></a>

13. **诸侯继续围许；曹伯也恢复君位，并参加围许。** 晋国对不服者进行连续整顿。曹臣以晋、曹同为周室后裔劝说，指出齐桓公尚能保存异姓国家，晋不宜借会诸侯灭同姓、损害号令诸侯的正当性，文公因而恢复曹伯。 [[13]](#reading-note-13)

<a id="event-13"></a>

<a id="reading-event-14"></a>

14. **晋国又建立三行以防御狄人。** 城濮胜利后，晋国继续改革军制。 荀林父统中行，先蔑统左行，军制在三军以外又有调整。 [[14]](#reading-note-14)

<a id="event-14"></a>

<a id="reading-event-15"></a>

15. **本年还记录了三条较小事项：陈侯参加会盟后去世；秋天杞伯姬来鲁；公子遂前往齐国。** [[15]](#reading-note-15)

<a id="sj014-0632-qi"></a>

<a id="reading-event-16"></a>

16. **齐昭公潘进入元年纪年。** 前633年齐孝公昭去世后，异母弟潘继立为齐昭公；齐国虽有继承纷争，仍在本年派军参加晋、楚城濮之战，并随晋文公参加践土会盟。 [[16]](#reading-note-16)

### 5. 晋军按照重耳流亡时对楚成王的承诺主动退避三舍

[返回正文第5条](#reading-event-5)

**[《左传》鲁僖公28年传文（前632年）](../../sources/春秋左传/有标点原文/bce-0632.md#batch-20261109-t009)**

> 子玉怒，从晋师。晋师退。军吏曰：“以君辟臣，辱也。且楚师老矣，何故退？”子犯曰：“师直为壮，曲为老。岂在久乎？微楚之惠不及此，退三舍辟之，所以报也。背惠食言，以亢其仇，我曲楚直，其众素饱，不可谓老。我退而楚还，我将何求。若其不还，君退臣犯，曲在彼矣。”退三舍，楚众欲止，子玉不可。

[史料说明](#history-legacy-source-5)

> 晉焚楚軍，火數日不息，文公嘆。左右曰：「勝楚而君猶憂，何？」文公曰：「吾聞能戰勝安者唯聖人，是以懼。且子玉猶在，庸可喜乎！」子玉之敗而歸，楚成王怒其不用其言，貪與晉戰，讓責子玉，子玉自殺。晉文公曰：「我擊其外，楚誅其內，內外相應。」於是乃喜。

# 公元前632年（鲁僖公二十八年）

[← 上一张已编年页：公元前633年](bce-0633.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前631年 →](bce-0631.md)

<a id="event-1"></a>

1. **春，晋文公先后进攻曹、卫，夺取五鹿；卫国拒绝借道后，晋军绕道渡河南下。** 晋国用打击楚国盟友的方式逼楚军从宋国撤兵。[1]

<a id="event-2"></a>

2. **鲁国公子买驻守卫国，没有完成防务；鲁僖公因害怕晋国而杀公子买，向晋国解释鲁国并未真正帮助楚。** 鲁国迅速从亲楚转向亲晋。[2]

<a id="event-3"></a>

3. **三月，晋军攻入曹国，俘曹伯，并特别保护曾在重耳流亡时礼遇他的僖负羁一家。** 晋文公把私人恩怨与国家战争结合起来处理。[3]

<a id="event-4"></a>

4. **晋国私下答应恢复曹、卫，以此离间它们与楚国；同时拘押楚使宛春，激怒楚将子玉。** 曹、卫随即与楚断绝关系。[4]

<a id="event-5"></a>

5. **晋军按照重耳流亡时对楚成王的承诺主动退避三舍。** 楚军本可停止追击，子玉坚持继续推进，战争责任逐渐转向楚方。[5]

<a id="event-6"></a>

6. **夏四月，晋、宋、齐、秦联军与楚军在城濮决战。** 晋军先击溃陈、蔡部队，又以佯退、曳柴制造败逃假象，随后中军横击、上军夹攻，楚左右两军崩溃。[6]

<a id="event-7"></a>

7. **城濮之战以楚军大败告终，子玉虽收住中军，战后仍因楚王责难自杀。** 晋文公由此取得中原军事优势。[7]

<a id="event-8"></a>

8. **五月，晋文公在践土会盟诸侯，并把楚军俘虏献给周襄王。** 周王正式册命晋文公为侯伯，晋国取代齐国成为新的中原霸主；鲁僖公也在王所朝见周王。[8]

<a id="event-9"></a>

9. **卫侯因曾亲楚而出奔，后来获准复位；但回国时其前驱误杀叔武，元咺因此逃晋。** 卫国内部矛盾没有因城濮结束。[9]

<a id="event-10"></a>

10. **冬，诸侯再会于温，晋文公召周王到河阳并让诸侯朝见。** 经文以“天王狩于河阳”保留王室名义，实际上显示晋霸权已经可以调动天子；鲁僖公又在王所朝见周王。[10]

<a id="event-11"></a>

11. **卫侯与元咺在晋国诉讼，卫侯败诉，被晋国押送京师；元咺回卫另立公子瑕。** 晋国直接干预卫国内政。[11]

<a id="event-12"></a>

12. **诸侯继续围许；曹伯也恢复君位，并参加围许。** 晋国对不服者进行连续整顿。[12]

<a id="event-13"></a>

13. **晋国又建立三行以防御狄人。** 城濮胜利后，晋国继续改革军制。[13]

<a id="event-14"></a>

14. **本年还记录了三条较小事项：陈侯参加会盟后去世；秋天杞伯姬来鲁；公子遂前往齐国。** [14]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公二十八年》**：“春，晋侯侵曹。晋侯伐卫。”  
   **《左传·僖公二十八年》**详记借道卫不许、晋取五鹿。

<a id="note-2"></a>

2. **《春秋·僖公二十八年》**：“公子买戍卫，不卒戍，刺之。楚人救卫。”  
   **《左传·僖公二十八年》**详记鲁惧晋而杀公子买。

<a id="note-3"></a>

3. **《春秋·僖公二十八年》**：“三月丙午，晋侯入曹，执曹伯，畀宋人。”  
   **《左传·僖公二十八年》**详记保护僖负羁家及曹人处置。

<a id="note-4"></a>

4. **《左传·僖公二十八年》**详记晋私许复曹卫、拘宛春、曹卫告绝于楚。

<a id="note-5"></a>

5. **《左传·僖公二十八年》**详记晋师“退三舍”以报楚惠。

<a id="note-6"></a>

6. **《春秋·僖公二十八年》**：“夏四月己巳，晋侯、齐师、宋师、秦师及楚人战于城濮，楚师败绩。”  
   **《左传·僖公二十八年》**详记晋军战术与楚军败绩。

<a id="note-7"></a>

7. **《春秋·僖公二十八年》**：“楚杀其大夫得臣。”  
   **《左传·僖公二十八年》**详记子玉败后死于连穀。

<a id="note-8"></a>

8. **《春秋·僖公二十八年》**：“五月癸丑，公会晋侯、齐侯、宋公、蔡侯、郑伯、卫子、莒子，盟于践土。”  
   **《左传·僖公二十八年》**详记献楚俘、周王策命晋侯为侯伯。

<a id="note-9"></a>

9. **《春秋·僖公二十八年》**记卫侯出奔楚、六月复归及元咺出奔晋。  
   **《左传·僖公二十八年》**详记叔武被误杀。

<a id="note-10"></a>

10. **《春秋·僖公二十八年》**：“冬，公会晋侯、齐侯、宋公、蔡侯、郑伯、陈子、莒子、邾子、秦人于温。天王狩于河阳。壬申，公朝于王所。”  
    **《左传·僖公二十八年》**说明晋侯实召王会诸侯。

<a id="note-11"></a>

11. **《春秋·僖公二十八年》**：“晋人执卫侯，归之于京师。卫元咺自晋复归于卫。”  
    **《左传·僖公二十八年》**详记卫侯与元咺讼。

<a id="note-12"></a>

12. **《春秋·僖公二十八年》**：“诸侯遂围许。曹伯襄复归于曹，遂会诸侯围许。”

<a id="note-13"></a>

13. **《左传·僖公二十八年》**：“晋侯作三行以御狄。”

<a id="note-14"></a>

14. **《春秋·僖公二十八年》**：“陈侯如会……陈侯款卒。秋，杞伯姬来。公子遂如齐。”

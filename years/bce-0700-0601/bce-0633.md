# 公元前633年（鲁僖公二十七年）

[← 上一张已编年页：公元前634年](bce-0634.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前632年 →](bce-0632.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，杞桓公来鲁朝见。** 因采用夷礼，被以较低称谓记录；鲁国也因此轻视杞国。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏六月，齐孝公去世；秋八月下葬。** 鲁齐虽有旧怨，仍没有破坏正常丧礼秩序。孝公去世后，卫公子开方杀了孝公的儿子，孝公的弟弟潘借此继位，是为齐昭公。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋，公子遂率鲁军进入杞国，追究杞国此前失礼。** 鲁杞关系恶化。 [[3]](#note-3)

<a id="event-4"></a>

4. **冬，楚国联合陈、蔡、郑、许包围宋国。** 宋国向晋国求救，晋楚争霸进入决定性阶段。 [[4]](#note-4)

<a id="event-5"></a>

5. **晋文公决定救宋，但不直接攻楚，而是先准备伐曹、卫，逼楚分兵。** 先轸、狐偃等开始制定城濮之战前的总体战略。 [[5]](#note-5)

<a id="event-6"></a>

6. **晋文公在被庐大阅，建立三军并任命郤縠、狐毛、栾枝等为主将。** 晋军体制完成重组，为第二年大战做准备。 [[6]](#note-6)

<a id="event-7"></a>

7. **十二月，鲁僖公前往宋地与诸侯会盟。** 鲁国也被卷入楚宋冲突。 [[7]](#note-7)

### 5. 晋文公决定救宋，但不直接攻楚，而是先准备伐曹、卫，逼楚分兵

[返回正文第5条](#event-5)

**[《左传》鲁僖公27年传文（前633年）](../../sources/春秋左传/有标点原文/bce-0633.md#batch-20261109-t005)**

> 冬，楚子及诸侯围宋，宋公孙固如晋告急。先轸曰：“报施救患，取威定霸，于是乎在矣。”狐偃曰：“楚始得曹而新昏于卫，若伐曹、卫，楚必救之，则齐、宋免矣。”于是乎蒐于被庐，作三军，谋元帅。赵衰曰：“郤縠可。臣亟闻其言矣。说礼乐而敦诗书。诗书，义之府也。礼乐，德之则也。德义，利之本也。《夏书》曰：‘赋纳以言，明试以功，车服以庸。’君其试之。”乃使郤縠将中军，郤溱佐之；使狐偃将上军，让于狐毛而佐之；命赵衰为卿，让于栾枝、先轸。使栾枝将下军，先轸佐之。荀林父御戎，魏犫为右。

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·僖公二十七年》**：“二十有七年春，杞子来朝。”  
   **《左传·僖公二十七年》**：“用夷礼，故曰子。”

<a id="history-legacy-source-2"></a>

2. **《春秋·僖公二十七年》**：“夏六月庚寅，齐侯昭卒。秋八月乙未，葬齐孝公。”  
   **《左传·僖公二十七年》**：“有齐怨，不废丧纪，礼也。”  
   **[《史记·齐太公世家》](../../sources/本地分卷/史记/史记-卷032.md#L3056)**记「孝公弟潘因衛公子開方殺孝公子而立潘」。[《十二诸侯年表》前633年齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0633)同记这场继承变故，次年才是[齐昭公元年](bce-0632.md#sj014-0632-qi)。

<a id="history-legacy-source-3"></a>

3. **《春秋·僖公二十七年》**：“乙巳，公子遂帅师入杞。”  
   **《左传·僖公二十七年》**：“责无礼也。”

<a id="history-legacy-source-4"></a>

4. **《春秋·僖公二十七年》**：“冬，楚人、陈侯、蔡侯、郑伯、许男围宋。”

<a id="history-legacy-source-5"></a>

5. **《左传·僖公二十七年》**详记宋告急、先轸与狐偃提出伐曹卫以救宋。

<a id="history-legacy-source-6"></a>

6. **《左传·僖公二十七年》**详记晋蒐于被庐、作三军及诸将任命。

<a id="history-legacy-source-7"></a>

7. **《春秋·僖公二十七年》**：“十有二月甲戌，公会诸侯盟于宋。”

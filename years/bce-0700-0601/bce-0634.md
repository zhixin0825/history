# 公元前634年（鲁僖公二十六年）

[← 上一张已编年页：公元前635年](bce-0635.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前633年 →](bce-0633.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁僖公与莒君、卫国大夫甯速在向地结盟，重申洮盟。** 齐国随后以此为理由进攻鲁国西部边境。 [[1]](#note-1)

<a id="event-2"></a>

2. **鲁僖公追击齐军到酅地，没有追上。** 夏天齐军又进攻鲁国北部边境。 [[2]](#note-2)

<a id="event-3"></a>

3. **卫国因洮盟出兵伐齐，支持鲁国。** 鲁、卫、莒形成一条对抗齐孝公的关系线。 [[3]](#note-3)

<a id="event-4"></a>

4. **鲁国派展喜前往齐军犒劳，展喜以周成王旧盟提醒齐国：鲁齐先祖曾受命世代不得相害。** 齐孝公最终撤军。 [[4]](#note-4)

<a id="event-5"></a>

5. **鲁国派公子遂、臧文仲赴楚求援。** 鲁国开始明显转向楚国以制衡齐国。 [[5]](#note-5)

<a id="event-6"></a>

6. **秋，楚国灭夔，把夔君俘回楚国。** 楚国继续整合南方宗族与附庸。 [[6]](#note-6)

<a id="event-7"></a>

7. **宋国因亲晋而背楚，楚令尹子玉、司马子西冬天伐宋并围缗。** 晋楚矛盾开始集中到宋国。 [[7]](#note-7)

<a id="event-8"></a>

8. **鲁僖公借楚军伐齐，攻取穀地，并把齐桓公之子公子雍安置在那里作为鲁国援手。** 鲁国与齐国的对抗达到高点；战后僖公返回鲁国。 [[8]](#note-8)

<a id="sj014-0634-wei"></a>

<a id="event-9"></a>

9. **卫成公郑进入元年纪年。** 卫文公燬已于前635年去世，儿子郑继立，是为卫成公。本年卫国与鲁国订盟、出兵伐齐，正是新君刚继位时的外交选择。 [[9]](#note-9)

### 4. 鲁国派展喜前往齐军犒劳，展喜以周成王旧盟提醒齐国：鲁齐先祖曾受命世代不得相害

[返回正文第4条](#event-4)

**[《左传》鲁僖公26年传文（前634年）](../../sources/春秋左传/有标点原文/bce-0634.md#batch-20261109-t003)**

> 齐侯未入竟，展喜从之，曰：“寡君闻君亲举玉趾，将辱于敝邑，使下臣犒执事。”齐侯曰：“鲁人恐乎？”对曰：“小人恐矣，君子则否。”齐侯曰：“室如县罄，野无青草，何恃而不恐？”对曰：“恃先王之命。昔周公、大公股肱周室，夹辅成王。成王劳之而赐之盟曰：‘世世子孙，无相害也。’载在盟府，大师职之。桓公是以纠合诸侯而谋其不协，弥缝其阙而匡救其灾，昭旧职也。及君即位，诸侯之望曰：‘其率桓之功。’我敝邑用不敢保聚，曰：‘岂其嗣世九年而弃命废职，其若先君何？’君必不然。恃此以不恐。”齐侯乃还。

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·僖公二十六年》**：“春，王正月己未，公会莒子、卫甯速，盟于向。”  
   **《左传·僖公二十六年》**：“寻洮之盟也。齐师侵我西鄙，讨是二盟也。”

<a id="history-legacy-source-2"></a>

2. **《春秋·僖公二十六年》**：“齐人侵我西鄙。公追齐师至酅，弗及。夏，齐人伐我北鄙。”

<a id="history-legacy-source-3"></a>

3. **《春秋·僖公二十六年》**：“卫人伐齐。”

<a id="history-legacy-source-4"></a>

4. **《左传·僖公二十六年》**详记展喜犒齐师、引用周成王旧盟而齐侯还师。

<a id="history-legacy-source-5"></a>

5. **《春秋·僖公二十六年》**：“公子遂如楚乞师。”  
   **《左传·僖公二十六年》**又记臧文仲同往。

<a id="history-legacy-source-6"></a>

6. **《春秋·僖公二十六年》**：“秋，楚人灭夔，以夔子归。”

<a id="history-legacy-source-7"></a>

7. **《春秋·僖公二十六年》**：“冬，楚人伐宋，围缗。”  
   **《左传·僖公二十六年》**说明宋“善于晋侯”，故叛楚即晋。

<a id="history-legacy-source-8"></a>

8. **《春秋·僖公二十六年》**：“公以楚师伐齐，取穀。公至自伐齐。”  
   **《左传·僖公二十六年》**详记置公子雍于穀，易牙奉之为鲁援。

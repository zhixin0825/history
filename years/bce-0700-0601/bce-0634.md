## 本年概述

鲁、莒、卫重申洮盟后，齐侵鲁两鄙，卫出兵伐齐，鲁使展喜以先王旧盟说退齐军。鲁又向楚求援，入冬借楚兵取齐邑穀，安置齐公子雍。楚在同年灭夔、伐宋，卫成公亦于本年纪元。

1. **鲁以展喜说退齐军，继借楚兵攻齐取穀。** 春，鲁僖公与莒君、卫甯速重申洮盟于向，齐出兵侵鲁西境，僖公追至酅未及。夏，齐孝公又攻鲁北鄙，卫为守盟出兵攻齐。鲁使展喜受命于展禽，以成王命周公与太公后代世代不得相侵的旧盟提醒齐孝公，齐军撤走。鲁遣公子遂、臧文仲向楚求兵。冬，僖公与楚将申公叔侯率援军攻齐取穀，安置齐桓公之子雍，令易牙辅佐，作为鲁国的援手。楚以大夫礼接纳奔楚的齐国公子。 [[1]](#bce0634-note-1)

## 楚灭夔与伐宋

<a id="bce0634-event-3"></a>

<a id="event-6"></a>

2. **楚灭夔，俘其国君。** 秋季，楚指斥夔不祭共同祖先祝融、鬻熊，出兵灭夔，俘其国君。 [[2]](#bce0634-note-3)

<a id="bce0634-event-4"></a>

<a id="event-7"></a>

3. **宋国因亲晋而背楚，楚令尹子玉、司马子西冬天伐宋并围缗。** 宋国背楚而亲晋。冬季，楚令尹子玉与司马子西率军攻宋，包围缗地。 [[3]](#bce0634-note-4)

## 卫成公元年

<a id="bce0634-event-5"></a>

<a id="sj014-0634-wei"></a>

<a id="event-9"></a>

4. **卫成公郑进入元年纪年。** 卫文公燬已于前635年去世，儿子郑继立，是为卫成公。本年卫国与鲁国订盟、出兵伐齐，正是新君刚继位时的外交选择。 [[4]](#bce0634-note-5)

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·僖公二十六年》**：“春，王正月己未，公会莒子、卫甯速，盟于向。”  
   **《左传·僖公二十六年》**：“寻洮之盟也。齐师侵我西鄙，讨是二盟也。”

<a id="history-legacy-source-2"></a>

2. **《春秋·僖公二十六年》**：“齐人侵我西鄙。公追齐师至酅，弗及。夏，齐人伐我北鄙。”

<a id="history-legacy-source-3"></a>

3. **《春秋·僖公二十六年》**：“卫人伐齐。”

<a id="history-legacy-source-4"></a>

4. **《左传·僖公二十六年》**详记展喜犒齐师、引用周成王旧盟而齐侯还师。

<a id="history-legacy-source-5"></a>

5. **《春秋·僖公二十六年》**：“公子遂如楚乞师。”  
   **《左传·僖公二十六年》**又记臧文仲同往。

<a id="history-legacy-source-6"></a>

6. **《春秋·僖公二十六年》**：“秋，楚人灭夔，以夔子归。”

<a id="history-legacy-source-7"></a>

7. **《春秋·僖公二十六年》**：“冬，楚人伐宋，围缗。”  
   **《左传·僖公二十六年》**说明宋“善于晋侯”，故叛楚即晋。

<a id="history-legacy-source-8"></a>

8. **《春秋·僖公二十六年》**：“公以楚师伐齐，取穀。公至自伐齐。”  
   **《左传·僖公二十六年》**详记置公子雍于穀，易牙奉之为鲁援。

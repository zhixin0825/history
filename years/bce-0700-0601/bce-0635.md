# 公元前635年（鲁僖公二十五年）

[← 上一张已编年页：公元前636年](bce-0636.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前634年 →](bce-0634.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，卫文公灭邢国。** 卫、邢长期冲突最终以邢亡结束。 [[1]](#note-1)

<a id="event-2"></a>

2. **晋文公接受勤王建议，抢在秦国之前出兵迎接周襄王。** 晋国借恢复王室秩序迅速建立政治声望。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏四月，晋军护送周襄王回到王城，并在温地擒杀太叔带。** 王室内乱至此基本结束。 [[3]](#note-3)

    [卷四互见与归年](#sj004-635-1)

<a id="event-4"></a>

4. **周襄王重赏晋文公，把阳樊、温、原、攒茅等地赐给晋国。** 晋国由此开始大规模控制南阳地区。 [[4]](#note-4)

<a id="event-5"></a>

5. **晋文公围原，只带三日粮食，并承诺三日不降就撤；即使得知原城快降，他仍按时退军。** 原人因此反而主动归降，晋文公借守信建立声望。 [[5]](#note-5)

<a id="event-6"></a>

6. **秋，秦、晋联合伐鄀，楚军驻商密抵抗。** 秦军用伪造盟书制造守军恐慌，最终迫使商密投降。 [[6]](#note-6)

<a id="event-7"></a>

7. **楚令尹子玉追秦军未及，转而围陈并把顿君送回顿国。** 楚国继续经营陈、顿一线。 [[7]](#note-7)

<a id="event-8"></a>

8. **四月，卫文公去世并下葬。** 卫国进入新君时代。 [[8]](#note-8)

<a id="event-9"></a>

9. **冬，鲁僖公与卫国新君、莒庆在洮地结盟，修复鲁卫旧好，并调停鲁莒关系。** [[9]](#note-9)

<a id="event-10"></a>

10. **宋荡伯姬来鲁迎娶妇人；宋国又杀本国大夫。** 宋国内政仍有波动。 [[10]](#note-10)

> 秦伯师于河上，将纳王。狐偃言于晋侯曰：“求诸侯，莫如勤王。诸侯信之，且大义也。继文之业而信宣于诸侯，今为可矣。”使卜偃卜之，曰：“吉，遇黄帝战于阪泉之兆。”公曰：“吾不堪也。”对曰：“周礼未改。今之王，古之帝也。”公曰：“筮之。”筮之，遇《大有》之《睽》，曰：“吉，遇‘公用享于天子’之卦。战克而王享，吉孰大焉。且是卦也，天为泽以当日，天子降心以逆公，不亦可乎？《大有》去《睽》而复，亦其所也。”晋侯辞秦师而下。三月甲辰，次于阳樊。右师围温，左师逆王。

### 5. 晋文公围原，只带三日粮食，并承诺三日不降就撤；即使得知原城快降，他仍按时退军

[返回正文第5条](#event-5)

> 冬，晋侯围原，命三日之粮。原不降，命去之。谍出，曰：“原将降矣。”军吏曰：“请待之。”公曰：“信，国之宝也，民之所庇也，得原失信，何以庇之？所亡滋多。”退一舍而原降。迁原伯贯于冀。赵衰为原大夫，狐溱为温大夫。

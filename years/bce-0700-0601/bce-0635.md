# 公元前635年（鲁僖公二十五年）

[← 上一张已编年页：公元前636年](bce-0636.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前634年 →](bce-0634.md)

<a id="event-1"></a>

1. **春，卫文公灭邢国。** 卫、邢长期冲突最终以邢亡结束。[[1]](#note-1)

<a id="event-2"></a>

2. **晋文公接受勤王建议，抢在秦国之前出兵迎接周襄王。** 晋国借恢复王室秩序迅速建立政治声望。[[2]](#note-2)

<a id="event-3"></a>

3. **夏四月，晋军护送周襄王回到王城，并在温地擒杀太叔带。** 王室内乱至此基本结束。[[3]](#note-3)

<a id="event-4"></a>

4. **周襄王重赏晋文公，把阳樊、温、原、攒茅等地赐给晋国。** 晋国由此开始大规模控制南阳地区。[[4]](#note-4)

<a id="event-5"></a>

5. **晋文公围原，只带三日粮食，并承诺三日不降就撤；即使得知原城快降，他仍按时退军。** 原人因此反而主动归降，晋文公借守信建立声望。[[5]](#note-5)

<a id="event-6"></a>

6. **秋，秦、晋联合伐鄀，楚军驻商密抵抗。** 秦军用伪造盟书制造守军恐慌，最终迫使商密投降。[[6]](#note-6)

<a id="event-7"></a>

7. **楚令尹子玉追秦军未及，转而围陈并把顿君送回顿国。** 楚国继续经营陈、顿一线。[[7]](#note-7)

<a id="event-8"></a>

8. **四月，卫文公去世并下葬。** 卫国进入新君时代。[[8]](#note-8)

<a id="event-9"></a>

9. **冬，鲁僖公与卫国新君、莒庆在洮地结盟，修复鲁卫旧好，并调停鲁莒关系。** [[9]](#note-9)

<a id="event-10"></a>

10. **宋荡伯姬来鲁迎娶妇人；宋国又杀本国大夫。** 宋国内政仍有波动。[[10]](#note-10)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公二十五年》**：“春，王正月丙午，卫侯燬灭邢。”

<a id="note-2"></a>

2. **《左传·僖公二十五年》**详记秦准备纳王、狐偃劝晋文公“勤王”。

<a id="note-3"></a>

3. **《左传·僖公二十五年》**：“夏四月丁巳，王入于王城，取大叔于温，杀之于隰城。”

<a id="note-4"></a>

4. **《左传·僖公二十五年》**详记襄王赐晋文公阳樊、温、原、攒茅等田。

<a id="note-5"></a>

5. **《左传·僖公二十五年》**详记晋侯围原、三日粮尽即退，原城随后降。

<a id="note-6"></a>

6. **《左传·僖公二十五年》**详记秦晋伐鄀、秦军诈降商密。

<a id="note-7"></a>

7. **《春秋·僖公二十五年》**：“秋，楚人围陈，纳顿子于顿。”  
   **《左传·僖公二十五年》**详记子玉追秦不及后围陈。

<a id="note-8"></a>

8. **《春秋·僖公二十五年》**：“夏四月癸酉，卫侯燬卒……葬卫文公。”

<a id="note-9"></a>

9. **《春秋·僖公二十五年》**：“冬十有二月癸亥，公会卫子、莒庆，盟于洮。”  
   **《左传·僖公二十五年》**：“修卫文公之好，且及莒平也。”

<a id="note-10"></a>

10. **《春秋·僖公二十五年》**：“宋荡伯姬来逆妇。宋杀其大夫。”

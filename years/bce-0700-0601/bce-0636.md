## 本年概述

秦穆公助重耳回晋即位，又帮助挫败吕甥等人的政变。周襄王借狄兵伐郑，旋被太叔带与狄军逐出王城。

## 晋文公复国

<a id="event-1"></a>

<a id="event-11"></a>

<a id="event-2"></a>

1. **秦助重耳返晋，晋怀公被杀，吕郤之乱平定。** 晋惠公上年去世，太子圉继为怀公。春，秦穆公派兵援重耳返晋。渡河前狐偃欲辞，重耳投璧于河盟誓。秦围令狐后，双方大夫盟于郇，重耳入曲沃、朝武宫，继为晋文公，怀公逃到高梁被杀。吕甥、郤芮谋焚宫刺杀文公，寺人披告警，文公密赴王城见秦穆公。吕、郤焚宫不获文公，出逃时被秦诱杀。夏，秦送夫人和三千人赴晋护卫。 [[1]](#note-1)

<a id="event-3"></a>

2. **晋文公复国后，狄人送回季隗；赵姬又劝赵衰迎回赵盾及其母叔隗。** 赵姬还请求以赵盾为嫡子，让自己的三子居其下，并尊叔隗为内子。这里应分清文公、赵衰和赵姬各自的行动。 赵姬所生三子即赵同、赵括、赵婴齐。 [[2]](#note-3)

<a id="event-4"></a>

3. **晋文公赏赐从亡之臣，介之推没有主动请功，也没有得到封赏，最终与母亲隐居而死。** 文公后来以绵上之田纪念他，承认自己有失。 介之推认为复国有天命和晋宗祀的缘故，不能尽归从亡者的私人功劳；既批评贪功，也不肯仿效求赏。他母亲劝过他求禄、至少使国君知道，见他坚持隐居，遂答应同行，至死不再出见。传说另有人把一龙五蛇的隐喻写在宫门，为介之推不受赏鸣不平。文公读到后承认疏忽，求访不获，便以绵上山地记其过、旌其善，称介山。壶叔也曾问为何三次行赏还没轮到自己。文公依次说明引导仁义、辅成事业、战阵劳苦和单纯服役的赏功等级，表示尚将及他；晋人因此称许。 魏武子因追随流亡而承续魏氏封邑，列为大夫，仍治于魏；其后魏悼子迁霍及魏绛的承继没有确年，作为这支家族的后续说明。 [[3]](#note-4)

## 周襄王出奔

<a id="event-5"></a>

<a id="event-6"></a>

<a id="event-7"></a>

<a id="event-9"></a>

4. **周襄王借狄伐郑，太叔带助狄逐王。** 郑伐滑，周襄王派伯服斡旋，郑文公因不满周室偏护卫、滑且对先君失礼，扣下伯服。夏，襄王借狄兵伐郑，攻下栎，又欲立狄女为后，富辰劝阻无效。秋，太叔带联合狄军击败王师，襄王奔郑居氾，太叔带与隗氏居温。冬，襄王告难于鲁、晋、秦等国。 [[4]](#note-5)

   王室使者游孙、伯服为滑国向郑请求，郑伯不肯听从，并拘留二人。王欲借狄兵报复，富辰劝他不要为滑而舍弃姬姓郑国，又历数周郑相助的旧事，未能劝止。 [卷四互见与归年](#sj004-636-1)

   襄王欲黜狄后，狄人因此不满；王子带又与狄后相通，利用这项关系争取狄军。富辰即使反对借狄，危急中仍带家族迎战，战死。 [卷四互见与归年](#sj004-636-2)

## 列国政事

<a id="event-8"></a>

5. **郑国公子子臧因服饰僭越受到郑伯厌恶，被派人诱杀。** 郑国内部也在清理宗室异己。 [[5]](#note-8)

<a id="event-10"></a>

6. **同年，宋国与楚国暂时讲和，宋成公从楚返国途中经过郑国，郑伯以高规格接待。** 宋郑关系在楚晋竞争背景下重新调整。 [[6]](#note-10)

<a id="event-12"></a>

7. **卫国准备攻邢，礼至兄弟先到邢国任职。** 礼至认为若不能接近邢国守城的人，便难以取其国，于是请求同兄弟前往邢国求仕。兄弟得到任职，为下一年卫军进攻作内应。 [[7]](#note-12)

<a id="sj014-0636-song"></a>

<a id="event-13"></a>

8. **宋国进入宋成公王臣元年。** 宋襄公在前637年因泓水旧伤去世，由其子王臣继立；本年新君开始纪元。宋成公在这一年随即面对晋、楚争霸的外交选择。 [[8]](#note-13)

### 3. 晋文公赏赐从亡之臣，介之推没有主动请功，也没有得到封赏，最终与母亲隐居而死

[返回正文第3条](#event-4)

**[《左传》鲁僖公24年传文（前636年）](../../sources/春秋左传/有标点原文/bce-0636.md#batch-20261109-t005)**

> 晋侯赏从亡者，介之推不言禄，禄亦弗及。推曰：“献公之子九人，唯君在矣。惠、怀无亲，外内弃之。天未绝晋，必将有主。主晋祀者，非君而谁。天实置之，而二三子以为己力，不亦诬乎？窃人之财，犹谓之盗，况贪天之功，以为己力乎？下义其罪，上赏其奸，上下相蒙，难与处矣！”其母曰：“盍亦求之，以死谁怼？”对曰：“尤而效之，罪又甚焉，且出怨言，不食其食。”其母曰：“亦使知之若何？”对曰：“言，身之文也，身将隐，焉用文之？是求显也。”其母曰：“能如是乎？与女偕隐。”遂隐而死。晋侯求之，不获，以绵上为之田，曰：“以志吾过，且旌善人。”

> 文公修政，施惠百姓。賞從亡者及功臣，大者封邑，小者尊爵。未盡行賞，周襄王以弟帶難出居鄭地，來告急晉。晉初定，欲發兵，恐他亂起，是以賞從亡未至隱者介子推。推亦不言祿，祿亦不及。推曰：「獻公子九人，唯君在矣。惠、懷無親，外內棄之；天未絕晉，必將有主，主晉祀者，非君而誰？天實開之，二三子以為己力，不亦誣乎？竊人之財，猶曰是盜，況貪天之功以為己力乎？下冒其罪，上賞其姦，上下相蒙，難與處矣！」其母曰：「盍亦求之，以死誰懟？」推曰：「尤而效之，罪有甚焉。且出怨言，不食其祿。」母曰：「亦使知之，若何？」對曰：「言，身之文也；身欲隱，安用文之？文之，是求顯也。」其母曰：「能如此乎？與女偕隱。」至死不復見。

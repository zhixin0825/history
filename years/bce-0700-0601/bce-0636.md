# 公元前636年（鲁僖公二十四年）

[← 上一张已编年页：公元前637年](bce-0637.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前635年 →](bce-0635.md)

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，在秦穆公支持下，重耳渡河回晋，进入曲沃，随后杀晋怀公，正式即位为晋文公。** 重耳结束多年流亡，晋国政权完成重大更替。 [[1]](#note-1)

<a id="event-2"></a>

2. **吕甥、郤芮等担心文公清算，密谋焚烧宫室刺杀晋文公。** 寺人披提前告密，文公暗中与秦穆公会面；宫火发生后，吕、郤未能得手，最终被秦人诱杀。 [[2]](#note-2)

<a id="event-3"></a>

3. **晋文公复国后，狄人送回季隗；赵姬又劝赵衰迎回赵盾及其母叔隗。** 赵姬还请求以赵盾为嫡子，让自己的三子居其下，并尊叔隗为内子。这里应分清文公、赵衰和赵姬各自的行动。 [[3]](#note-3)

<a id="event-4"></a>

4. **晋文公赏赐从亡之臣，介之推没有主动请功，也没有得到封赏，最终与母亲隐居而死。** 文公后来以绵上之田纪念他，承认自己有失。 [[4]](#note-4)

<a id="event-5"></a>

5. **夏，周襄王借狄兵伐郑，攻取栎地。** 王室因郑国不听王命而报复，但依赖狄人也迅速带来新的政治风险。 [[5]](#note-5)

   王室使者游孙、伯服为滑国向郑请求，郑伯不肯听从，并拘留二人。王欲借狄兵报复，富辰劝他不要为滑而舍弃姬姓郑国，又历数周郑相助的旧事，未能劝止。 [卷四互见与归年](#sj004-636-1)

<a id="event-6"></a>

6. **周襄王又准备立狄女为后，进一步激化王室内部矛盾。** 富辰反复劝阻无效。 [[6]](#note-6)

<a id="event-7"></a>

7. **秋，太叔带联合狄军击败周王师，周襄王被迫出奔郑国，住在氾地。** 太叔带则与隗氏居温，王室再次陷入内战。 [[7]](#note-7)

   襄王欲黜狄后，狄人因此不满；王子带又与狄后相通，利用这项关系争取狄军。富辰即使反对借狄，危急中仍带家族迎战，战死。 [卷四互见与归年](#sj004-636-2)

<a id="event-8"></a>

8. **郑国公子子臧因服饰僭越受到郑伯厌恶，被派人诱杀。** 郑国内部也在清理宗室异己。 [[8]](#note-8)

<a id="event-9"></a>

9. **冬，周襄王向鲁、晋、秦等诸侯正式通报王室危机，请求勤王。** 晋文公刚刚复国，马上获得介入王室事务的机会。 [[9]](#note-9)

<a id="event-10"></a>

10. **同年，宋国与楚国暂时讲和，宋成公从楚返国途中经过郑国，郑伯以高规格接待。** 宋郑关系在楚晋竞争背景下重新调整。 [[10]](#note-10)

<a id="event-11"></a>

11. **晋惠公夷吾之死属于前一年。** 本条保留旧有互见入口，实际丧事见[前637年](bce-0637.md#event-4)，不再将同一人死亡计入本年。 [[11]](#note-11)

<a id="event-12"></a>

12. **卫国准备攻邢，礼至兄弟先到邢国任职。** 礼至认为若不能接近邢国守城的人，便难以取其国，于是请求同兄弟前往邢国求仕。兄弟得到任职，为下一年卫军进攻作内应。 [[12]](#note-12)

<a id="sj014-0636-song"></a>

<a id="event-13"></a>

13. **宋国进入宋成公王臣元年。** 宋襄公在前637年因泓水旧伤去世，由其子王臣继立；本年新君开始纪元。宋成公在这一年随即面对晋、楚争霸的外交选择。 [[13]](#note-13)

### 1. 春，在秦穆公支持下，重耳渡河回晋，进入曲沃，随后杀晋怀公，正式即位为晋文公

[返回正文第1条](#event-1)

**[《左传》鲁僖公24年传文（前636年）](../../sources/春秋左传/有标点原文/bce-0636.md#batch-20261109-t001)**

> 二十四年春，王正月，秦伯纳之。不书，不告入也。及河，子犯以璧授公子曰：“臣负羁绁从君巡于天下，臣之罪甚多矣。臣犹知之，而况君乎。请由此亡。”公子曰：“所不与舅氏同心者，有如白水。”投其璧于河。济河，围令狐，入桑泉，取臼衰。二月甲午，晋师军于庐柳。秦伯使公子絷如晋师，师退，军于郇。辛丑，狐偃及秦、晋之大夫盟于郇。壬寅，公子入于晋师。丙午，入于曲沃。丁未，朝于武宫。戊申，使杀怀公于高梁。不书，亦不告也。

**[卷005 P027](../../sources/摘录/史记-卷005-秦本纪.md#p027)**

> 二十二年，晉公子圉聞晉君病，曰：「梁，我母家也，而秦滅之。我兄弟多，即君百歲後，秦必留我，而晉輕，亦更立他子。」子圉乃亡歸晉。二十三年，晉惠公卒，子圉立為君。秦怨圉亡去，乃迎晉公子重耳於楚，而妻以故子圉妻。重耳初謝，後乃受。繆公益禮厚遇之。二十四年春，秦使人告晉大臣，欲入重耳。晉許之，於是使人送重耳。二月，重耳立為晉君，是為文公。文公使人殺子圉。子圉是為懷公。

### 2. 吕甥、郤芮等担心文公清算，密谋焚烧宫室刺杀晋文公

[返回正文第2条](#event-2)

**[《左传》鲁僖公24年传文（前636年）](../../sources/春秋左传/有标点原文/bce-0636.md#batch-20261109-t002)**

> 吕、郤畏偪，将焚公宫而弑晋侯。寺人披请见，公使让之，且辞焉。曰：“蒲城之役，君命一宿，女即至。其后余从狄君以田渭滨，女为惠公来求杀余，命女三宿，女中宿至。虽有君命，何其速也。夫袪犹在，女其行乎。”对曰：“臣谓君之入也，其知之矣。若犹未也，又将及难。君命无二，古之制也。除君之恶，唯力是视，蒲人、狄人，余何有焉。今君即位，其无蒲、狄乎？齐桓公置射鉤而使管仲相，君若易之，何辱命焉？行者甚众，岂唯刑臣。”公见之，以难告。三月，晋侯潜会秦伯于王城。己丑晦，公宫火，瑕甥、郤芮不获公，乃如河上，秦伯诱而杀之。晋侯逆夫人嬴氏以归。秦伯送卫于晋三千人，实纪纲之仆。

### 4. 晋文公赏赐从亡之臣，介之推没有主动请功，也没有得到封赏，最终与母亲隐居而死

[返回正文第4条](#event-4)

**[《左传》鲁僖公24年传文（前636年）](../../sources/春秋左传/有标点原文/bce-0636.md#batch-20261109-t005)**

> 晋侯赏从亡者，介之推不言禄，禄亦弗及。推曰：“献公之子九人，唯君在矣。惠、怀无亲，外内弃之。天未绝晋，必将有主。主晋祀者，非君而谁。天实置之，而二三子以为己力，不亦诬乎？窃人之财，犹谓之盗，况贪天之功，以为己力乎？下义其罪，上赏其奸，上下相蒙，难与处矣！”其母曰：“盍亦求之，以死谁怼？”对曰：“尤而效之，罪又甚焉，且出怨言，不食其食。”其母曰：“亦使知之若何？”对曰：“言，身之文也，身将隐，焉用文之？是求显也。”其母曰：“能如是乎？与女偕隐。”遂隐而死。晋侯求之，不获，以绵上为之田，曰：“以志吾过，且旌善人。”

[《十二诸侯年表》前636年宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0636)列「宋成公王臣元年」；[《宋微子世家·宋成公》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7038.md#ref-d7178acecda242)记宋襄公十四年卒、子王臣立，成公元年晋文公即位。[前637年](bce-0637.md#event-2)已记襄公去世；本年只补新君元年，不把既有宋楚和议写成另一轮继位。

### 本轮校订：叙事与原文的界限

赵盾母子归来的倡议者在原文中是赵姬，执行者为赵衰；不能将这件家族安排笼统写成晋文公亲自接回。狄人归季隗与赵氏迎回叔隗、赵盾也不是同一对母子。见[本年传文](../../sources/春秋左传/有标点原文/bce-0636.md#batch-20261109-t004)。

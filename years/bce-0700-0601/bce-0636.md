# 公元前636年（鲁僖公二十四年）

[← 上一张已编年页：公元前637年](bce-0637.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前635年 →](bce-0635.md)

<a id="event-1"></a>

1. **春，在秦穆公支持下，重耳渡河回晋，进入曲沃，随后杀晋怀公，正式即位为晋文公。** 重耳结束多年流亡，晋国政权完成重大更替。[1]

<a id="event-2"></a>

2. **吕甥、郤芮等担心文公清算，密谋焚烧宫室刺杀晋文公。** 寺人披提前告密，文公暗中与秦穆公会面；宫火发生后，吕、郤未能得手，最终被秦人诱杀。[2]

<a id="event-3"></a>

3. **晋文公重新整顿流亡前后的旧臣关系，并接回赵盾及其母。** 他试图把长期流亡形成的人际网络转化为稳定执政基础。[3]

<a id="event-4"></a>

4. **晋文公赏赐从亡之臣，介之推没有主动请功，也没有得到封赏，最终与母亲隐居而死。** 文公后来以绵上之田纪念他，承认自己有失。[4]

<a id="event-5"></a>

5. **夏，周襄王借狄兵伐郑，攻取栎地。** 王室因郑国不听王命而报复，但依赖狄人也迅速带来新的政治风险。[5]

<a id="event-6"></a>

6. **周襄王又准备立狄女为后，进一步激化王室内部矛盾。** 富辰反复劝阻无效。[6]

<a id="event-7"></a>

7. **秋，太叔带联合狄军击败周王师，周襄王被迫出奔郑国，住在氾地。** 太叔带则与隗氏居温，王室再次陷入内战。[7]

<a id="event-8"></a>

8. **郑国公子子臧因服饰僭越受到郑伯厌恶，被派人诱杀。** 郑国内部也在清理宗室异己。[8]

<a id="event-9"></a>

9. **冬，周襄王向鲁、晋、秦等诸侯正式通报王室危机，请求勤王。** 晋文公刚刚复国，马上获得介入王室事务的机会。[9]

<a id="event-10"></a>

10. **同年，宋国与楚国暂时讲和，宋成公从楚返国途中经过郑国，郑伯以高规格接待。** 宋郑关系在楚晋竞争背景下重新调整。[10]

<a id="event-11"></a>

11. **晋惠公夷吾去世。** 晋国旧君一系彻底退出政治舞台。[11]

## 本年相关史料

<a id="note-1"></a>

1. **《左传·僖公二十四年》**详记秦穆公纳重耳入晋，重耳入曲沃，随后杀怀公于高梁。

<a id="note-2"></a>

2. **《左传·僖公二十四年》**详记吕、郤焚宫谋弑、寺人披告难、秦伯诱杀吕郤。

<a id="note-3"></a>

3. **《左传·僖公二十四年》**详记晋文公重新接纳旧臣、赵盾及其母入晋。

<a id="note-4"></a>

4. **《左传·僖公二十四年》**详记介之推不言禄、与母隐而死，文公以绵上为田纪念。

<a id="note-5"></a>

5. **《春秋·僖公二十四年》**：“夏，狄伐郑。”  
   **《左传·僖公二十四年》**详记周襄王借狄伐郑、取栎。

<a id="note-6"></a>

6. **《左传·僖公二十四年》**详记襄王欲立狄女为后，富辰劝谏。

<a id="note-7"></a>

7. **《春秋·僖公二十四年》**：“冬，天王出居于郑。”  
   **《左传·僖公二十四年》**详记太叔带与狄伐周、襄王出居氾。

<a id="note-8"></a>

8. **《左传·僖公二十四年》**详记郑子臧出奔宋、后被盗杀。

<a id="note-9"></a>

9. **《左传·僖公二十四年》**载周襄王遣使向鲁、晋、秦告难。

<a id="note-10"></a>

10. **《左传·僖公二十四年》**详记宋与楚平、宋成公返国途经郑国受享。

<a id="note-11"></a>

11. **《春秋·僖公二十四年》**：“晋侯夷吾卒。”

# 公元前636年（鲁僖公二十四年）

[← 上一张已编年页：公元前637年](bce-0637.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前635年 →](bce-0635.md)

<a id="event-1"></a>

1. **春，在秦穆公支持下，重耳渡河回晋，进入曲沃，随后杀晋怀公，正式即位为晋文公。** 重耳结束多年流亡，晋国政权完成重大更替。[[1]](#note-1)

[补充史料与年次说明](#sj005-076-note)


<a id="event-2"></a>

2. **吕甥、郤芮等担心文公清算，密谋焚烧宫室刺杀晋文公。** 寺人披提前告密，文公暗中与秦穆公会面；宫火发生后，吕、郤未能得手，最终被秦人诱杀。[[2]](#note-2)

<a id="event-3"></a>

3. **晋文公重新整顿流亡前后的旧臣关系，并接回赵盾及其母。** 他试图把长期流亡形成的人际网络转化为稳定执政基础。[[3]](#note-3)

<a id="event-4"></a>

4. **晋文公赏赐从亡之臣，介之推没有主动请功，也没有得到封赏，最终与母亲隐居而死。** 文公后来以绵上之田纪念他，承认自己有失。[[4]](#note-4)

<a id="event-5"></a>

5. **夏，周襄王借狄兵伐郑，攻取栎地。** 王室因郑国不听王命而报复，但依赖狄人也迅速带来新的政治风险。[[5]](#note-5)

王室使者游孙、伯服为滑国向郑请求，郑伯不肯听从，并拘留二人。王欲借狄兵报复，富辰劝他不要为滑而舍弃姬姓郑国，又历数周郑相助的旧事，未能劝止。 [卷四互见与归年](#sj004-636-1)


<a id="event-6"></a>

6. **周襄王又准备立狄女为后，进一步激化王室内部矛盾。** 富辰反复劝阻无效。[[6]](#note-6)

<a id="event-7"></a>

7. **秋，太叔带联合狄军击败周王师，周襄王被迫出奔郑国，住在氾地。** 太叔带则与隗氏居温，王室再次陷入内战。[[7]](#note-7)

襄王欲黜狄后，狄人因此不满；王子带又与狄后相通，利用这项关系争取狄军。富辰即使反对借狄，危急中仍带家族迎战，战死。 [卷四互见与归年](#sj004-636-2)

[补充史料与年次说明](#sj005-077-note)


<a id="event-8"></a>

8. **郑国公子子臧因服饰僭越受到郑伯厌恶，被派人诱杀。** 郑国内部也在清理宗室异己。[[8]](#note-8)

<a id="event-9"></a>

9. **冬，周襄王向鲁、晋、秦等诸侯正式通报王室危机，请求勤王。** 晋文公刚刚复国，马上获得介入王室事务的机会。[[9]](#note-9)

<a id="event-10"></a>

10. **同年，宋国与楚国暂时讲和，宋成公从楚返国途中经过郑国，郑伯以高规格接待。** 宋郑关系在楚晋竞争背景下重新调整。[[10]](#note-10)

<a id="event-11"></a>

11. **晋惠公夷吾之死属于前一年。** 本条保留旧有互见入口，实际丧事见[前637年](bce-0637.md#event-4)，不再将同一人死亡计入本年。[[11]](#note-11)

<a id="event-12"></a>

12. **卫国准备攻邢，礼至兄弟先到邢国任职。** 礼至认为若不能接近邢国守城的人，便难以取其国，于是请求同兄弟前往邢国求仕。兄弟得到任职，为下一年卫军进攻作内应。 [看原文与说明](#cq-source-34)

<a id="sj014-0636-song"></a>

13. **宋国进入宋成公王臣元年。** 宋襄公在前637年因泓水旧伤去世，由其子王臣继立；本年新君开始纪元。宋成公在这一年随即面对晋、楚争霸的外交选择。 [[13]](#sj014-0636-song-note)

## 本年相关史料

<a id="note-1"></a>

1. **《左传·僖公二十四年》**详记秦穆公纳重耳入晋，重耳入曲沃，随后杀怀公于高梁。

<a id="note-2"></a>

2. **《左传·僖公二十四年》**详记吕、郤焚宫谋弑、寺人披告难、秦伯诱杀吕郤。

<a id="note-3"></a>

3. **《左传·僖公二十四年》**详记晋文公重新接纳旧臣、赵盾及其母入晋。

<a id="note-4"></a>

4. **《左传·僖公二十四年》**详记介之推不言禄、与母隐而死，文公以绵上为田纪念。

<a id="note-5"></a>

5. **《春秋·僖公二十四年》**：“夏，狄伐郑。”  
   **《左传·僖公二十四年》**详记周襄王借狄伐郑、取栎。

<a id="sj004-636-1"></a>
#### 王命、滑国与郑国的争执｜卷四互见

[卷004 P048](../../sources/摘录/史记-卷004-周本纪.md#p048)。 本纪分别系十三、十五、十六年，而经传将本次攻滑、执使、借狄与出奔串在前636年；正文按现有经传线。先王东迁的郑国援助是发言中回溯，不编成本年。


<a id="note-6"></a>

6. **《左传·僖公二十四年》**详记襄王欲立狄女为后，富辰劝谏。

<a id="note-7"></a>

7. **《春秋·僖公二十四年》**：“冬，天王出居于郑。”  
   **《左传·僖公二十四年》**详记太叔带与狄伐周、襄王出居氾。

<a id="sj004-636-2"></a>
#### 狄后与王子带成为政变的另一条线｜卷四互见

[卷004 P048](../../sources/摘录/史记-卷004-周本纪.md#p048)。 本纪把立狄后、黜狄后、带私通及出兵连为因果；经传的君后关系、王使颓叔桃子也应保留，不把单一男女关系当成全部原因。


<a id="note-8"></a>

8. **《左传·僖公二十四年》**详记郑子臧出奔宋、后被盗杀。

<a id="note-9"></a>

9. **《左传·僖公二十四年》**载周襄王遣使向鲁、晋、秦告难。

<a id="note-10"></a>

10. **《左传·僖公二十四年》**详记宋与楚平、宋成公返国途经郑国受享。

<a id="note-11"></a>

11. **《春秋·僖公二十四年》**：“晋侯夷吾卒。”

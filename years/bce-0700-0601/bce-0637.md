# 公元前637年（鲁僖公二十三年）

[← 上一张已编年页：公元前638年](bce-0638.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前636年 →](bce-0636.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，齐孝公出兵伐宋并包围缗地，追究宋国没有参加齐地盟会。** 齐国新君开始重新介入诸侯事务。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏五月，宋襄公因泓水之战旧伤去世。** 宋国争夺霸主地位的尝试至此结束。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋，楚将成得臣伐陈，夺取焦、夷并筑顿城。** 成得臣因战功地位上升，成为楚国重要统帅。 [[3]](#note-3)

<a id="event-4"></a>

4. **九月，晋惠公去世，太子圉即位为晋怀公。** 怀公命令所有跟随重耳流亡的人限期回国；狐突拒绝召回两个儿子，被怀公处死。 [[4]](#note-4)

<a id="event-5"></a>

5. **到这一年，重耳已经经历长期流亡，从狄地一路经过卫、齐、曹、宋、郑、楚，最后抵达秦国。** 齐桓公曾厚待重耳，曹共公失礼窥视，宋襄公赠马，郑文公拒绝礼遇，楚成王则设宴相待并把他送往秦国。 [[5]](#note-5)

<a id="event-6"></a>

6. **重耳在楚国曾答应：如果将来返晋而晋楚交兵，愿先退避三舍。** 这段承诺将直接影响数年后的城濮之战。 [[6]](#note-6)

<a id="event-7"></a>

7. **秦穆公接纳重耳，并以五名宗女嫁给他，其中包括原晋太子圉之妻怀嬴。** 秦国已经准备以重耳取代晋怀公，重新干预晋国继承。 [[7]](#note-7)

<a id="event-8"></a>

8. **冬，杞成公去世。** 杞国发生君主更替。 [[8]](#note-8)

### 4. 九月，晋惠公去世，太子圉即位为晋怀公

[返回正文第4条](#event-4)


<!-- century-0700-0601-primary -->

**[《左传》本年传文](../../sources/春秋左传/有标点原文/bce-0637.md#batch-20261109-t004)**

> 九月，晋惠公卒。怀公命无从亡人。期，期而不至，无赦。狐突之子毛及偃从重耳在秦，弗召。冬，怀公执狐突曰：“子来则免。”对曰：“子之能仕，父教之忠，古之制也。策名委质，贰乃辟也。今臣之子名在重耳，有年数矣。若又召之，教之贰也。父教子贰，何以事君？刑之不滥，君之明也，臣之愿也。淫刑以逞，谁则无罪？臣闻命矣。”乃杀之。卜偃称疾不出，曰：“《周书》有之：‘乃大明服。’己则不明而杀人以逞，不亦难乎？民不见德而唯戮是闻，其何后之有？”

### 6. 重耳在楚国曾答应：如果将来返晋而晋楚交兵，愿先退避三舍

[返回正文第6条](#event-6)


<!-- century-0700-0601-primary -->

**[《左传》本年传文](../../sources/春秋左传/有标点原文/bce-0637.md#batch-20261109-t012)**

> 及楚，楚子飨之，曰：“公子若反晋国，则何以报不穀？”对曰：“子女玉帛则君有之，羽毛齿革则君地生焉。其波及晋国者，君之馀也，其何以报君？”曰：“虽然，何以报我？”对曰：“若以君之灵，得反晋国，晋、楚治兵，遇于中原，其辟君三舍。若不获命，其左执鞭弭，右属櫜鞬，以与君周旋。”子玉请杀之。楚子曰：“晋公子广而俭，文而有礼。其从者肃而宽，忠而能力。晋侯无亲，外内恶之。吾闻姬姓，唐叔之后，其后衰者也，其将由晋公子乎。天将兴之，谁能废之！违天必有大咎。”乃送诸秦。

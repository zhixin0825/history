# 公元前637年（鲁僖公二十三年）

[← 上一张已编年页：公元前638年](bce-0638.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前636年 →](bce-0636.md)

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，齐孝公出兵伐宋并包围缗地，追究宋国没有参加齐地盟会。** 齐国新君开始重新介入诸侯事务。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏五月，宋襄公因泓水之战旧伤去世。** 宋国争夺霸主地位的尝试至此结束。 儿子王臣继立，为宋成公，元年从次年起算。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋，楚将成得臣伐陈，夺取焦、夷并筑顿城。** 成得臣因战功地位上升，成为楚国重要统帅。 [[3]](#note-3)

<a id="event-4"></a>

4. **九月，晋惠公去世，太子圉即位为晋怀公。** 十一月，惠公下葬。怀公命跟随重耳流亡的人限期回国，逾期将灭其家。狐突坚持两个儿子既已事重耳，就不应教他们反复易主，因拒绝召子而被杀。十二月，晋国一些大夫得知重耳在秦，暗中劝他回国并准备内应。 [[4]](#note-4)

<a id="event-5"></a>

<a id="event-6"></a>

<a id="event-7"></a>

5. **重耳离齐经曹宋郑楚入秦，秦穆公厚待。** 重耳流亡后曾受齐桓公礼遇。齐桓公死后他起初不愿出走，齐妻与赵衰等将他灌醉送离齐国。过曹，曹共公窥看其身体，僖负羁送食夹玉，重耳收食退玉。宋襄公虽刚在泓水受伤，仍以宾礼待他并赠车马。郑文公不听叔瞻之劝，未以礼相待。到楚后，赵衰劝他接受诸侯礼。楚成王问何以回报，重耳答两军若战于中原，愿退三舍。子玉请杀重耳，楚王不允。秦穆公因圉逃归，派人来召，楚王厚礼送重耳赴秦。秦穆公以五女妻之，其中包括圉的前妻怀嬴。重耳纳怀嬴前曾疑虑，司空季子劝他以返国为重。赵衰宴间歌《黍苗》，以望雨比喻盼望秦援。 [[5]](#note-5)

<a id="event-8"></a>

6. **冬，杞成公去世。** 杞国发生君主更替。 [[6]](#note-8)

## 归年与考证

1. **《春秋·僖公二十三年》**：“二十有三年春，齐侯伐宋，围缗。”

   **《左传·僖公二十三年》**：“宋襄公卒，伤于泓故也。”

<a id="history-legacy-source-3"></a>

3. **《春秋·僖公二十三年》**：“秋，楚人伐陈。”  
   **《左传·僖公二十三年》**详记成得臣取焦、夷、城顿。

<a id="history-legacy-source-4"></a>

4. **《左传·僖公二十三年》**：“九月，晋惠公卒。怀公命无从亡人……”并记杀狐突。

<a id="history-legacy-source-5"></a>

   **说明：** 这是一段回顾性叙事，并非这些经历都发生在前637年；正文明确用“到这一年已经经历”而不重新归年。

<a id="history-legacy-source-6"></a>

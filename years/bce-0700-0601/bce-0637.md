# 公元前637年（鲁僖公二十三年）

[← 上一张已编年页：公元前638年](bce-0638.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前636年 →](bce-0636.md)

<a id="event-1"></a>

1. **春，齐孝公出兵伐宋并包围缗地，追究宋国没有参加齐地盟会。** 齐国新君开始重新介入诸侯事务。[[1]](#note-1)

<a id="event-2"></a>

2. **夏五月，宋襄公因泓水之战旧伤去世。** 宋国争夺霸主地位的尝试至此结束。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，楚将成得臣伐陈，夺取焦、夷并筑顿城。** 成得臣因战功地位上升，成为楚国重要统帅。[[3]](#note-3)

<a id="event-4"></a>

4. **九月，晋惠公去世，太子圉即位为晋怀公。** 怀公命令所有跟随重耳流亡的人限期回国；狐突拒绝召回两个儿子，被怀公处死。[[4]](#note-4)

[补充史料与年次说明](#sj005-074-note)


<a id="event-5"></a>

5. **到这一年，重耳已经经历长期流亡，从狄地一路经过卫、齐、曹、宋、郑、楚，最后抵达秦国。** 齐桓公曾厚待重耳，曹共公失礼窥视，宋襄公赠马，郑文公拒绝礼遇，楚成王则设宴相待并把他送往秦国。[[5]](#note-5)

<a id="event-6"></a>

6. **重耳在楚国曾答应：如果将来返晋而晋楚交兵，愿先退避三舍。** 这段承诺将直接影响数年后的城濮之战。[[6]](#note-6)

<a id="event-7"></a>

7. **秦穆公接纳重耳，并以五名宗女嫁给他，其中包括原晋太子圉之妻怀嬴。** 秦国已经准备以重耳取代晋怀公，重新干预晋国继承。[[7]](#note-7)

[补充史料与年次说明](#sj005-075-note)


<a id="event-8"></a>

8. **冬，杞成公去世。** 杞国发生君主更替。[[8]](#note-8)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公二十三年》**：“二十有三年春，齐侯伐宋，围缗。”  
   **《左传·僖公二十三年》**：“以讨其不与盟于齐也。”

<a id="note-2"></a>

2. **《春秋·僖公二十三年》**：“夏五月庚寅，宋公兹父卒。”  
   **《左传·僖公二十三年》**：“宋襄公卒，伤于泓故也。”

<a id="note-3"></a>

3. **《春秋·僖公二十三年》**：“秋，楚人伐陈。”  
   **《左传·僖公二十三年》**详记成得臣取焦、夷、城顿。

<a id="note-4"></a>

4. **《左传·僖公二十三年》**：“九月，晋惠公卒。怀公命无从亡人……”并记杀狐突。

<a id="note-5"></a>

5. **《左传·僖公二十三年》**在本年集中回顾重耳此前流亡狄、卫、齐、曹、宋、郑、楚等国的经过。

   **说明：** 这是一段回顾性叙事，并非这些经历都发生在前637年；正文明确用“到这一年已经经历”而不重新归年。

<a id="note-6"></a>

6. **《左传·僖公二十三年》**载重耳答楚成王：“晋、楚治兵，遇于中原，其辟君三舍。”

<a id="note-7"></a>

7. **《左传·僖公二十三年》**详记楚送重耳至秦、秦伯纳五女及秦重耳关系。

<a id="note-8"></a>

8. **《春秋·僖公二十三年》**：“冬十有一月，杞子卒。”

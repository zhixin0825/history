# 公元前638年（鲁僖公二十二年）

[← 上一张已编年页：公元前639年](bce-0639.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前637年 →](bce-0637.md)

<a id="event-1"></a>

1. **春，鲁僖公攻邾，夺回须句并恢复须句君。** 鲁国把这次战争解释为恢复小国祭祀与秩序。[1]

<a id="event-2"></a>

2. **夏，宋襄公联合卫、许、滕伐郑。** 郑国此前亲楚，宋国借此继续与楚争夺中原影响。[2]

<a id="event-3"></a>

3. **秦、晋把陆浑之戎迁到伊川。** 戎人进入王畿附近，改变了中原西部族群格局。[3]

<a id="event-4"></a>

4. **秋，鲁国因须句问题再次与邾国交战。** 僖公轻视邾国、没有充分戒备，在升陉遭到惨败，连自己的头盔也被邾军缴获。[4]

<a id="event-5"></a>

5. **冬，楚军为救郑与宋军在泓水交战。** 楚军渡河和列阵过程中，宋军本有两次先击机会，宋襄公都坚持“不击半渡、不击未成列”，最终等楚军列阵完成后才进攻。[5]

<a id="event-6"></a>

6. **宋军在泓水大败，宋襄公大腿受伤。** 他坚持古代“仁义之师”原则，却被子鱼批评完全不懂实际战争；这次伤势后来直接导致宋襄公死亡。[6]

<a id="event-7"></a>

7. **楚成王战后进入郑国受享，并带两名郑女回楚。** 楚在宋郑战线上的优势进一步扩大。[7]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公二十二年》**：“二十有二年春，公伐邾，取须句。”  
   **《左传·僖公二十二年》**：“反其君焉。”

<a id="note-2"></a>

2. **《春秋·僖公二十二年》**：“夏，宋公、卫侯、许男、滕子伐郑。”

<a id="note-3"></a>

3. **《左传·僖公二十二年》**：“秋，秦、晋迁陆浑之戎于伊川。”

<a id="note-4"></a>

4. **《春秋·僖公二十二年》**：“秋八月丁未，及邾人战于升陉。”  
   **《左传·僖公二十二年》**详记僖公轻邾、不设备而败。

<a id="note-5"></a>

5. **《春秋·僖公二十二年》**：“冬十有一月己巳朔，宋公及楚人战于泓，宋师败绩。”  
   **《左传·僖公二十二年》**详记宋襄公拒绝趁楚军半渡、未列阵时进攻。

<a id="note-6"></a>

6. **《左传·僖公二十二年》**详记宋襄公“君子不重伤，不禽二毛”及子鱼反驳。

<a id="note-7"></a>

7. **《左传·僖公二十二年》**详记楚王战后享于郑并“取郑二姬以归”。

# 公元前638年（鲁僖公二十二年）

[← 上一张已编年页：公元前639年](bce-0639.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前637年 →](bce-0637.md)

<a id="event-1"></a>

1. **春，鲁僖公攻邾，夺回须句并恢复须句君。** 鲁国把这次战争解释为恢复小国祭祀与秩序。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，宋襄公联合卫、许、滕伐郑。** 郑国此前亲楚，宋国借此继续与楚争夺中原影响。[[2]](#note-2)

<a id="event-3"></a>

3. **秦、晋把陆浑之戎迁到伊川。** 戎人进入王畿附近，改变了中原西部族群格局。[[3]](#note-3)

<a id="event-4"></a>

4. **秋，鲁国因须句问题再次与邾国交战。** 僖公轻视邾国、没有充分戒备，在升陉遭到惨败，连自己的头盔也被邾军缴获。[[4]](#note-4)

<a id="event-5"></a>

5. **冬，楚军为救郑与宋军在泓水交战。** 楚军渡河和列阵过程中，宋军本有两次先击机会，宋襄公都坚持“不击半渡、不击未成列”，最终等楚军列阵完成后才进攻。[[5]](#note-5)

<a id="event-6"></a>

6. **宋军在泓水大败，宋襄公大腿受伤。** 他坚持古代“仁义之师”原则，却被子鱼批评完全不懂实际战争；这次伤势后来直接导致宋襄公死亡。[[6]](#note-6)

<a id="event-7"></a>

7. **楚成王战后进入郑国受享，并带两名郑女回楚。** 楚在宋郑战线上的优势进一步扩大。[[7]](#note-7)

<a id="event-8"></a>

8. **晋太子圉逃离秦国，妻子嬴氏没有同行。** 圉准备回晋，问嬴氏是否一起走。她认为圉身为晋太子想返国可以理解，自己却奉秦君之命侍奉，不能擅弃使命，所以既不跟走，也不告发。圉遂独自逃归。 [看原文与说明](#cq-source-32)

圉担心父亲一旦去世，秦仍扣住自己而晋国另立别人，所以先自行返晋。秦对此心怀不满，后来转而迎接重耳。

[补充史料与年次说明](#sj005-073-note)


<a id="event-9"></a>

9. **周襄王听从富辰劝告，将王子带从齐国召回京师。** 富辰以兄弟不和便难以要求诸侯相睦为由进言，王同意召回。王子带以后再次卷入争位是后来之事，不能用后果倒写成本年召回时已经爆发内战。 [看原文与说明](#cq-source-33)

 [卷四互见与归年](#sj004-638-1)

<a id="note-2"></a>

2. **《春秋·僖公二十二年》**：“夏，宋公、卫侯、许男、滕子伐郑。”

<a id="note-3"></a>

3. **《左传·僖公二十二年》**：“秋，秦、晋迁陆浑之戎于伊川。”

<a id="note-4"></a>

4. **《春秋·僖公二十二年》**：“秋八月丁未，及邾人战于升陉。”  
   **《左传·僖公二十二年》**详记僖公轻邾、不设备而败。

<a id="note-5"></a>

5. **《春秋·僖公二十二年》**：“冬十有一月己巳朔，宋公及楚人战于泓，宋师败绩。”  
   **《左传·僖公二十二年》**详记宋襄公拒绝趁楚军半渡、未列阵时进攻。

<a id="note-6"></a>

6. **《左传·僖公二十二年》**详记宋襄公“君子不重伤，不禽二毛”及子鱼反驳。

<a id="note-7"></a>

7. **《左传·僖公二十二年》**详记楚王战后享于郑并“取郑二姬以归”。

### 核对32｜晋太子圉逃离秦国，妻子嬴氏没有同行

<details>
<summary>传 T006｜原文</summary>

> 晋大子圉为质于秦，将逃归，谓嬴氏曰：“与子归乎？”对曰：“子，晋大子，而辱于秦，子之欲归，不亦宜乎？寡君之使婢子侍执巾栉，以固子也。从子而归，弃君命也。不敢从，亦不敢言。”遂逃归。富辰言于王曰：“请召大叔。《诗》曰：‘协比其邻，昏姻孔云。’吾兄弟之不协，焉能怨诸侯之不睦？”王说。王子带自齐复归于京师，王召之也。

<a id="sj004-638-1"></a>
### 王子带返京的年次差别｜卷四互见

[卷004 P047](../../sources/摘录/史记-卷004-周本纪.md#p047)。 本纪襄王十二年将召带归置于前640；《左传》僖公二十二年明记，本文以更具体年条保留前638。惠后要求召回、襄王不得已等本纪解释在同号原文，不宣布两次返京。 [《十二诸侯年表》前638年齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0638)另记「歸王弟帶」，强调齐国参与王子带返周；但《左传》只明记周王召回，齐国是否亲自派使护送尚无同条细节，不据此改写成齐国自行决定召回。

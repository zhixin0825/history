# 公元前639年（鲁僖公二十一年）

[← 上一张已编年页：公元前640年](bce-0640.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前638年 →](bce-0638.md)

<a id="event-1"></a>

1. **春，狄人再次侵卫。** 卫国北方压力持续。[[1]](#note-1)

<a id="event-2"></a>

2. **宋襄公与齐、楚在鹿上结盟，希望借楚国支持取得诸侯盟主地位。** 楚国表面答应，宋襄公继续推进争霸计划。[[2]](#note-2)

<a id="event-3"></a>

3. **夏，鲁国发生严重旱灾。** 僖公一度想焚烧巫尪求雨，臧文仲劝他修城、减膳、省用、劝分粮食，僖公接受；当年虽饥，没有酿成大害。[[3]](#note-3)

<a id="event-4"></a>

4. **秋，宋襄公在盂地召集楚、陈、蔡、郑、许、曹等诸侯，却被楚国当场扣押。** 宋国试图以小国实力主盟，反而成为楚国控制的对象。[[4]](#note-4)

<a id="event-5"></a>

5. **楚军随后进攻宋国。** 冬天诸侯在薄地会盟，宋襄公获释，但宋楚矛盾并未结束。[[5]](#note-5)

<a id="event-6"></a>

6. **冬，鲁国出兵攻邾，背景是邾国灭掉须句。** 须句君逃到鲁国，成风请求僖公恢复这个小国，以维护大皞、有济祭祀体系。[[6]](#note-6)

<a id="event-7"></a>

7. **楚国派宜申来鲁献上战胜所得。** 这发生在宋襄公被楚拘押、楚军攻宋的背景下。[[7]](#note-7)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公二十一年》**：“二十有一年春，狄侵卫。”

<a id="note-2"></a>

2. **《春秋·僖公二十一年》**：“宋人、齐人、楚人盟于鹿上。”  
   **《左传·僖公二十一年》**：“宋人为鹿上之盟，以求诸侯于楚。”

<a id="note-3"></a>

3. **《春秋·僖公二十一年》**：“夏，大旱。”  
   **《左传·僖公二十一年》**详记臧文仲阻止焚巫尪并提出救旱措施。

<a id="note-4"></a>

4. **《春秋·僖公二十一年》**：“秋，宋公、楚子、陈侯、蔡侯、郑伯、许男、曹伯会于盂。执宋公以伐宋。”

<a id="note-5"></a>

5. **《春秋·僖公二十一年》**：“十有二月癸丑，公会诸侯盟于薄，释宋公。”  
   **《左传·僖公二十一年》**详记宋公获释。

<a id="note-6"></a>

6. **《春秋·僖公二十一年》**：“冬，公伐邾。”  
   **《左传·僖公二十一年》**详记邾灭须句、须句子奔鲁及成风劝复国。

<a id="note-7"></a>

7. **《春秋·僖公二十一年》**：“楚人使宜申来献捷。”

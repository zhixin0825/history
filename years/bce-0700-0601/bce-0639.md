# 公元前639年（鲁僖公二十一年）

[← 上一张已编年页：公元前640年](bce-0640.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前638年 →](bce-0638.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，狄人再次侵卫。** 卫国北方压力持续。 [[1]](#note-1)

<a id="event-2"></a>

2. **宋襄公与齐、楚在鹿上结盟，希望借楚国支持取得诸侯盟主地位。** 楚国表面答应，宋襄公继续推进争霸计划。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，鲁国发生严重旱灾。** 僖公一度想焚烧巫尪求雨，臧文仲劝他修城、减膳、省用、劝分粮食，僖公接受；当年虽饥，没有酿成大害。 [[3]](#note-3)

<a id="event-4"></a>

4. **秋，宋襄公在盂地召诸侯，被楚扣押，后来才获释。** 宋欲主会召楚，楚王认为受到轻慢，早已决定到会羞辱宋公。楚、陈、蔡、郑、许、曹等君集会时，楚遂扣宋公，宋的主盟企图反成楚控制它的机会；释放是此次拘押的后续，并非另一次会盟。 [[4]](#note-4)

<a id="event-5"></a>

5. **楚军随后进攻宋国。** 冬天诸侯在薄地会盟，宋襄公获释，但宋楚矛盾并未结束。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬，鲁国出兵攻邾，背景是邾国灭掉须句。** 须句君逃到鲁国，成风请求僖公恢复这个小国，以维护大皞、有济祭祀体系。 [[6]](#note-6)

<a id="event-7"></a>

7. **楚国派宜申来鲁献上战胜所得。** 这发生在宋襄公被楚拘押、楚军攻宋的背景下。 [[7]](#note-7)

<a id="hs-event-8"></a>

8. **鲁夏大旱。** [[8]](#hs-note-8)

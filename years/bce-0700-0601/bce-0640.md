# 公元前640年（鲁僖公二十年）

[← 上一张已编年页：公元前641年](bce-0641.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前639年 →](bce-0639.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁国重建南门。** 工程时机被认为不合适。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，郜国国君来鲁朝见；五月，鲁国西宫发生火灾。** 国内同时有外交和宫室灾害。 [[2]](#note-2)

<a id="event-3"></a>

3. **滑国背叛郑国、转而依附卫国，郑军于是攻入滑国。** 郑、卫之间的竞争延伸到小国归属。 [[3]](#note-3)

<a id="event-4"></a>

4. **秋，齐人与狄人在邢地结盟，商议邢国遭卫国威胁的问题。** 齐桓公死后，齐国仍试图维持北方秩序。 [[4]](#note-4)

<a id="event-5"></a>

5. **随国带领汉东诸侯背叛楚国，冬天楚令尹子文出兵伐随，迫使随国重新求和。** 楚国继续巩固汉东控制。 [[5]](#note-5)

<a id="event-6"></a>

6. **宋襄公开始积极谋求召集诸侯、继承齐桓公的霸主地位。** 鲁大夫臧文仲已经认为宋国实力与愿望并不相称。 [[6]](#note-6)

<a id="event-7"></a>

7. **秦灭芮，继续兼并邻近小国。** 芮此前多次与梁一同来秦朝见，现在也失去独立。梁的灭亡已在前641年叙述，本年只接写芮的结局。 [[7]](#note-7)

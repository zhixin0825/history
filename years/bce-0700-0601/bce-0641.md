# 公元前641年（鲁僖公十九年）

[← 上一张已编年页：公元前642年](bce-0642.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前640年 →](bce-0640.md)

<a id="event-1"></a>

1. **春，宋襄公扣押滕宣公。** 齐桓公死后，宋襄公开始试图以强硬手段争夺霸主地位。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，宋、曹、邾在曹南会盟；鄫君前来参加时，却被邾文公按宋襄公命令作为人牲祭祀。** 宋襄公希望借此震慑东夷，但这种极端做法反而严重损害其声望。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，宋军包围曹国，因为曹不服从宋国。** 宋大夫子鱼再次劝宋襄公先修自身德政，不要一味以武力逼服诸侯。[[3]](#note-3)

<a id="event-4"></a>

4. **卫国出兵伐邢，报复上一年的菟圃之役。** 出兵后原本严重干旱的卫国降雨，卫人把它视为征讨正当的象征。[[4]](#note-4)

<a id="event-5"></a>

5. **冬，陈、蔡、楚、郑等在齐地结盟，试图继续维持齐桓公生前建立的诸侯友好关系。** 齐桓公死后，各国仍在寻找新的秩序。[[5]](#note-5)

<a id="event-6"></a>

6. **梁国因为国君长期滥建城邑、反复虚报敌情，百姓最终自行溃散，秦国乘机吞并梁国。** 这是典型的内部治理崩溃导致亡国。[[6]](#note-6)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公十九年》**：“十有九年春，王三月，宋人执滕子婴齐。”

<a id="note-2"></a>

2. **《春秋·僖公十九年》**：“夏六月，宋公、曹人、邾人盟于曹南。鄫子会盟于邾。己酉，邾人执鄫子，用之。”  
   **《左传·僖公十九年》**详记宋公使邾文公“用鄫子于次睢之社”。

<a id="note-3"></a>

3. **《春秋·僖公十九年》**：“秋，宋人围曹。”  
   **《左传·僖公十九年》**详记子鱼劝宋公内省德政。

<a id="note-4"></a>

4. **《春秋·僖公十九年》**：“卫人伐邢。”  
   **《左传·僖公十九年》**：“以报菟圃之役。”

<a id="note-5"></a>

5. **《春秋·僖公十九年》**：“冬，会陈人、蔡人、楚人、郑人盟于齐。”  
   **《左传·僖公十九年》**：“修桓公之好也。”

<a id="note-6"></a>

6. **《春秋·僖公十九年》**：“梁亡。”  
   **《左传·僖公十九年》**详记梁伯好土功、虚报寇至，民溃而秦取梁。

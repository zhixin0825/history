# 公元前642年（鲁僖公十八年）

[← 上一张已编年页：公元前643年](bce-0643.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前641年 →](bce-0641.md)

<a id="event-1"></a>

1. **春，宋襄公联合曹、卫、邾等国出兵齐国，准备按照齐桓公遗命扶立公子昭。** 齐国人随后杀死无亏。[[1]](#note-1)

<a id="event-2"></a>

2. **齐国其余四公子势力仍不服，与宋军交战。** 夏五月，宋军在甗地击败齐军，最终把公子昭立为齐孝公；本年也是齐孝公昭的元年。[[2]](#note-2)

<a id="event-3"></a>

3. **鲁军和狄人也先后出兵救齐。** 齐国内战已经演变成多国干预。[[3]](#note-3)

<a id="event-4"></a>

4. **秋八月，齐桓公终于下葬。** 从死亡到安葬历时很久，反映五公子争位的严重混乱。[[4]](#note-4)

<a id="event-5"></a>

5. **郑伯开始朝见楚国。** 齐桓公死后，郑国迅速加强与楚国关系。[[5]](#note-5)

<a id="event-6"></a>

6. **冬，邢人与狄人联合攻卫，一度围住菟圃。** 卫文公表示愿把国家让给能治理的人，国人不接受，卫军随后准备迎战，狄军撤退。[[6]](#note-6)

<a id="event-7"></a>

7. **此前梁国君主不断扩筑城邑，却没有充实居民，使国内陷入动荡。** 《左传》在本年段落已概述梁国最终被秦国吞并的结局；[梁国正式灭亡](bce-0641.md#event-6)依《春秋·僖公十九年》记在前641年，不另算本年一次亡国。[[7]](#note-7)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公十八年》**：“十有八年春，王正月，宋公、曹伯、卫人、邾人伐齐。”  
   **《左传·僖公十八年》**：“宋襄公以诸侯伐齐。三月，齐人杀无亏。”

<a id="note-2"></a>

2. **《春秋·僖公十八年》**：“五月戊寅，宋师及齐师战于甗，齐师败绩。”  
   **《左传·僖公十八年》**：“宋败齐师于甗，立孝公而还。”  
   **年表互见：**[《十二诸侯年表》前642年齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0642)记「齊孝公昭元年」；[《齐太公世家·齐孝公》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7032.md#ref-e11ff2c4e11a4c)亦详叙宋军帮助公子昭继齐。前643年是桓公死、争位，不能与本年孝公元年混同。

<a id="note-3"></a>

3. **《春秋·僖公十八年》**：“夏，师救齐……狄救齐。”

<a id="note-4"></a>

4. **《春秋·僖公十八年》**：“秋八月丁亥，葬齐桓公。”

<a id="note-5"></a>

5. **《左传·僖公十八年》**：“郑伯始朝于楚。”

<a id="note-6"></a>

6. **《春秋·僖公十八年》**：“冬，邢人、狄人伐卫。”  
   **《左传·僖公十八年》**详记围菟圃、卫侯让国与狄师退。

<a id="note-7"></a>

7. **《左传·僖公十八年》**：“梁伯益其国而不能实也，命曰新里，秦取之。”  
   **归年说明：**此段先概述梁国亡因与结局；[《春秋·僖公十九年》](bce-0641.md#note-6)则明确书“梁亡”，故实际亡国主述在下一年，不因此判断秦两次灭梁。

1. **宋襄公出兵助公子昭即位，齐桓公下葬。** 春，宋襄公依齐桓公旧约，联合曹、卫、邾发兵扶立公子昭。齐国其余四公子的势力仍与宋军交战，鲁军和狄人也出兵救齐。齐国继承纷争平定后，八月安葬齐桓公。 [[1]](#note-1)

<a id="event-5"></a>

2. **郑伯开始朝见楚国。** 齐桓公死后，郑国迅速加强与楚国关系。 [[2]](#note-5)

<a id="event-6"></a>

3. **冬，邢人与狄人联合攻卫，一度围住菟圃。** 卫文公表示愿把国家让给能治理的人，国人不接受，卫军随后准备迎战，狄军撤退。 [[3]](#note-6)

<a id="event-7"></a>

4. **梁国扩筑城邑，国内动荡。** 梁君连年扩筑城邑，居民却无法充实新城，国内日渐动荡。 [[4]](#note-7)

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·僖公十八年》**：“十有八年春，王正月，宋公、曹伯、卫人、邾人伐齐。”  
   **《左传·僖公十八年》**：“宋襄公以诸侯伐齐。三月，齐人杀无亏。”

<a id="history-legacy-source-2"></a>

2. **《春秋·僖公十八年》**：“五月戊寅，宋师及齐师战于甗，齐师败绩。”  
   **《左传·僖公十八年》**：“宋败齐师于甗，立孝公而还。”  
   **年表互见：**[《十二诸侯年表》前642年齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0642)记「齊孝公昭元年」；[《齐太公世家·齐孝公》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7032.md#ref-e11ff2c4e11a4c)亦详叙宋军帮助公子昭继齐。前643年是桓公死、争位，不能与本年孝公元年混同。

<a id="history-legacy-source-3"></a>

3. **《春秋·僖公十八年》**：“夏，师救齐……狄救齐。”

<a id="history-legacy-source-4"></a>

4. **《春秋·僖公十八年》**：“秋八月丁亥，葬齐桓公。”

<a id="history-legacy-source-5"></a>

5. **《左传·僖公十八年》**：“郑伯始朝于楚。”

<a id="history-legacy-source-6"></a>

6. **《春秋·僖公十八年》**：“冬，邢人、狄人伐卫。”  
   **《左传·僖公十八年》**详记围菟圃、卫侯让国与狄师退。

<a id="history-legacy-source-7"></a>

7. **《左传·僖公十八年》**：“梁伯益其国而不能实也，命曰新里，秦取之。”  
   **归年说明：**此段先概述梁国亡因与结局；[《春秋·僖公十九年》](bce-0641.md#note-6)则明确书“梁亡”，故实际亡国主述在下一年，不因此判断秦两次灭梁。

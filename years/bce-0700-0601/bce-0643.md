# 公元前643年（鲁僖公十七年）

[← 上一张已编年页：公元前644年](bce-0644.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前642年 →](bce-0642.md)

<a id="event-1"></a>

1. **春，齐国为帮助徐国，联合徐军攻英氏，报复楚军在娄林击败徐国。** 齐楚外围战争仍在延续。[1]

<a id="event-2"></a>

2. **夏，鲁军灭项国。** 僖公此前参加淮地会盟尚未正式结束诸侯事务，鲁国却先行取项，齐国因此拘留僖公问罪。[2]

<a id="event-3"></a>

3. **秋，声姜为营救僖公，在卞地会见齐桓公；九月僖公才返回鲁国。** 鲁国不得不通过齐国关系解决这次外交危机。[3]

<a id="event-4"></a>

4. **齐桓公晚年继承安排混乱。** 他有多位宠姬和五名争位公子；虽然曾与管仲把孝公托付宋襄公，却又受易牙、寺人貂等影响，许诺立公子无亏。[4]

<a id="event-5"></a>

5. **冬，齐桓公去世，五公子争位立即爆发。** 易牙、寺人貂杀死群吏，拥立无亏；齐桓公遗体长期未能正常入殓，齐国霸主秩序迅速崩解。[5]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公十七年》**：“十有七年春，齐人、徐人伐英氏。”  
   **《左传·僖公十七年》**：“以报娄林之役也。”

<a id="note-2"></a>

2. **《春秋·僖公十七年》**：“夏，灭项。”  
   **《左传·僖公十七年》**详记鲁取项后“齐人以为讨而止公”。

<a id="note-3"></a>

3. **《春秋·僖公十七年》**：“秋，夫人姜氏会齐侯于卞。九月，公至自会。”  
   **《左传·僖公十七年》**说明声姜为僖公而会齐侯。

<a id="note-4"></a>

4. **《左传·僖公十七年》**详记齐桓公诸夫人、内宠和五公子继承问题。

<a id="note-5"></a>

5. **《春秋·僖公十七年》**：“冬十有二月乙亥，齐侯小白卒。”  
   **《左传·僖公十七年》**详记易牙、寺人貂拥立无亏以及桓公死后迟殡。

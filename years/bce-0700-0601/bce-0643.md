# 公元前643年（鲁僖公十七年）

[← 上一张已编年页：公元前644年](bce-0644.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前642年 →](bce-0642.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，齐国为帮助徐国，联合徐军攻英氏，报复楚军在娄林击败徐国。** 齐楚外围战争仍在延续。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，鲁军灭项国。** 僖公此前参加淮地会盟尚未正式结束诸侯事务，鲁国却先行取项，齐国因此拘留僖公问罪。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋，声姜为营救僖公，在卞地会见齐桓公；九月僖公才返回鲁国。** 鲁国不得不通过齐国关系解决这次外交危机。 [[3]](#note-3)

<a id="event-4"></a>

4. **齐桓公晚年继承安排混乱。** 他有多位宠姬和五名争位公子；虽然曾与管仲把孝公托付宋襄公，却又受易牙、寺人貂等影响，许诺立公子无亏。 [[4]](#note-4)

<a id="event-5"></a>

5. **冬，齐桓公去世，五公子争位立即爆发。** 易牙、寺人貂杀死群吏，拥立无亏；齐桓公遗体长期未能正常入殓，齐国霸主秩序迅速崩解。 [[5]](#note-5)

    [卷四互见与归年](#sj004-643-1)

<a id="event-6"></a>

6. **夏，晋太子圉到秦国为质，秦国归还晋河东并把女子嫁给他。** 原文随后回叙夷吾在梁时娶梁女，生圉及其妹；圉此次赴秦，其妹也作为宦女同行。婚姻、归地和质子共同属于秦晋在韩原之战后的安排。 [[6]](#note-6)

> 四十三年。初，齊桓公之夫人三：曰王姬、徐姬、蔡姬，皆無子。桓公好內，多內寵，如夫人者六人，長衛姬，生無詭；少衛姬，生惠公元；鄭姬，生孝公昭；葛嬴，生昭公潘；密姬，生懿公商人；宋華子，生公子雍。桓公與管仲屬孝公於宋襄公，以為太子。雍巫有寵於衛共姬，因宦者豎刀以厚獻於桓公，亦有寵，桓公許之立無詭。管仲卒，五公子皆求立。

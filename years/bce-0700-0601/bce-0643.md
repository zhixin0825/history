# 公元前643年（鲁僖公十七年）

[← 上一张已编年页：公元前644年](bce-0644.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前642年 →](bce-0642.md)

<a id="event-1"></a>

1. **春，齐国为帮助徐国，联合徐军攻英氏，报复楚军在娄林击败徐国。** 齐楚外围战争仍在延续。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，鲁军灭项国。** 僖公此前参加淮地会盟尚未正式结束诸侯事务，鲁国却先行取项，齐国因此拘留僖公问罪。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，声姜为营救僖公，在卞地会见齐桓公；九月僖公才返回鲁国。** 鲁国不得不通过齐国关系解决这次外交危机。[[3]](#note-3)

<a id="event-4"></a>

4. **齐桓公晚年继承安排混乱。** 他有多位宠姬和五名争位公子；虽然曾与管仲把孝公托付宋襄公，却又受易牙、寺人貂等影响，许诺立公子无亏。[[4]](#note-4)

<a id="event-5"></a>

5. **冬，齐桓公去世，五公子争位立即爆发。** 易牙、寺人貂杀死群吏，拥立无亏；齐桓公遗体长期未能正常入殓，齐国霸主秩序迅速崩解。[[5]](#note-5)

 [卷四互见与归年](#sj004-643-1)

<a id="event-6"></a>

6. **夏，晋太子圉到秦国为质，秦国归还晋河东并把女子嫁给他。** 原文随后回叙夷吾在梁时娶梁女，生圉及其妹；圉此次赴秦，其妹也作为宦女同行。婚姻、归地和质子共同属于秦晋在韩原之战后的安排。 [看原文与说明](#cq-source-31)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公十七年》**：“十有七年春，齐人、徐人伐英氏。”  
   **《左传·僖公十七年》**：“以报娄林之役也。”

<a id="note-2"></a>

2. **《春秋·僖公十七年》**：“夏，灭项。”  
   **《左传·僖公十七年》**详记鲁取项后“齐人以为讨而止公”。

<a id="note-3"></a>

3. **《春秋·僖公十七年》**：“秋，夫人姜氏会齐侯于卞。九月，公至自会。”  
   **《左传·僖公十七年》**说明声姜为僖公而会齐侯。

<a id="note-4"></a>

4. **《左传·僖公十七年》**详记齐桓公诸夫人、内宠和五公子继承问题。

<a id="note-5"></a>

5. **《春秋·僖公十七年》**：“冬十有二月乙亥，齐侯小白卒。”  
   **《左传·僖公十七年》**详记易牙、寺人貂拥立无亏以及桓公死后迟殡。

## 补充核对的史料

<a id="cq-source-31"></a>
### 核对31｜夏，晋太子圉到秦国为质，秦国归还晋河东并把女子嫁给他

**说明：**梁伯嫁女及怀孕占卜是太子出生前事，不误编成本年。秦方嫁给圉的女子与他后来离秦时的嬴氏在后续相接。

<details>
<summary>传 T002｜原文</summary>

> 夏，晋大子圉为质于秦，秦归河东而妻之。惠公之在梁也，梁伯妻之。梁嬴孕过期，卜招父与其子卜之。其子曰：“将生一男一女。”招曰：“然。男为人臣，女为人妾。”故名男曰圉，女曰妾。及子圉西质，妾为宦女焉。

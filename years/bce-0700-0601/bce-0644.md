# 公元前644年（鲁僖公十六年）

[← 上一张已编年页：公元前645年](bce-0645.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前643年 →](bce-0643.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春正月，宋国落下五块陨石；同月六只鹢鸟因强风逆飞经过宋都。** 周内史叔兴认为这些只是自然现象，不应直接当作国家吉凶预兆。 [[1]](#note-1)

<a id="event-2"></a>

2. **三月，季友去世。** 鲁国长期依赖的核心执政者退出政治舞台。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，齐国攻厉失败，转而救徐；秋，狄人趁晋国韩原战败后侵入晋境。** 齐、晋分别面对南北两线压力。 [[3]](#note-3)

<a id="event-4"></a>

4. **周王因戎患向齐国求援，齐桓公征召诸侯戍守周都。** 齐国仍承担尊王与协调诸侯的角色。 [[4]](#note-4)

<a id="event-5"></a>

5. **冬，郑国杀太子华。** 太子华此前在甯母会盟中试图借齐国清洗郑国大族，最终失去国内政治基础。 [[5]](#note-5)

<a id="event-6"></a>

6. **十二月，鲁僖公与齐、宋、陈、卫、郑、许、邢、曹等在淮地会合，谋划鄫国与东向扩张。** 联军原想为鄫筑城，但役夫困苦，又有人夜间高呼“齐有乱”，工程最终停止。 [[6]](#note-6)

<a id="event-7"></a>

7. **鄫季姬、公孙兹也在这一年先后去世。** 鲁国一年内出现多起重要宗族成员死亡。 [[7]](#note-7)

<a id="sj014-0644-jin"></a>

<a id="event-8"></a>

8. **晋惠公七年，流亡狄地的公子重耳得知晋惠公仍想加害自己，决定与赵衰等人离开狄地，前往齐国。** 途中经过卫国和五鹿；重耳到齐后得到齐桓公接待。 [[8]](#note-8)

**[P115](../../sources/摘录/史记-卷027-天官书.md#p115)**

> 太史公推古天變，未有可考于今者。蓋略以春秋二百四十二年之閒，日蝕三十六，彗星三見，宋襄公時星隕如雨。天子微，諸侯力政，五伯代興，更為主命，自是之後，眾暴寡，大并小。秦、楚、吳、越，夷狄也，為彊伯。田氏篡齊，三家分晉，并為戰國。爭於攻取，兵革更起，城邑數屠，因以饑饉疾疫焦苦，臣主共憂患，其察禨祥候星氣尤急。近世十二諸侯七國相王，言從衡者繼踵，而皋、唐、甘、石因時務論其書傳，故其占驗淩雜米鹽。

## 归年与考证

1. **《春秋·僖公十六年》**：“十有六年春，王正月戊申朔，陨石于宋五。是月，六鹢退飞过宋都。”  
   **《左传·僖公十六年》**详记叔兴解释陨星与风，并说“吉凶由人”。

《天官书》[P115](../../sources/摘录/史记-卷027-天官书.md#p115)称“宋襄公時星隕如雨”，[《正义》](../../sources/摘录/史记-卷027-三家注对照.md#p115)释为本年“隕石于宋五”。这是注家的对应说；本经“星陨如雨”原句另在[前687年第2条](bce-0687.md#event-2)。本年保留五块陨石、六鹢退飞，不另添一场“流星雨”。详[纪年辨析](../../meta/考证/史记-卷027-纪年与异说.md#宋襄公与星陨)。

### 补充史料与异说

<a id="sj014-0644-qin-variant"></a>
<a id="卷014秦栏河东置官司的地理与制度待核"></a>
#### 卷014秦栏｜河东置官司的地理与制度待核

[《十二诸侯年表》前644年秦栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0644)记「十六為河東置官司」。[《秦本纪》韩原战后](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7005.md#ref-4378c11486f521)记晋献**河西**地、秦地东至河，却未详列本年河东官司的具体设置。河东、河西是不同地理称谓，暂存年表原说，不能拿秦本纪的河西交地直接证成本年在河东已设置了何种机构，也不能凭此推出县数、建置完成时间；相关地理、制度问题仍待校核。

<a id="sj014-0644-jin-note"></a>
<a id="卷014晋栏重耳由狄赴齐"></a>
#### 卷014晋栏｜重耳由狄赴齐

[《十二诸侯年表》前644年晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0644)记「七重耳聞管仲死，去翟之齊」；[《晋世家·晋文公》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7039.md#ref-135c9854c752df)也将重耳离狄归于晋惠公七年，并记经过卫、五鹿后抵齐。管仲、隰朋之死是重耳当时听到的旧讯，不能据此另把他们的死亡定在本年。

# 公元前645年（鲁僖公十五年）

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁僖公前往齐国。** 齐桓公仍维持诸侯霸主地位。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚国进攻徐国，齐桓公召集鲁、宋、陈、卫、郑、许、曹在牡丘会盟，并派诸侯军救徐。** 联军驻匡等待救援行动。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏五月，发生日食；秋又发生螽灾。** 鲁国同年记录了两项灾异。 [[3]](#note-3)

<a id="event-4"></a>

4. **齐、曹联军攻厉国，以牵制楚军、救援徐国；但冬天楚军仍在娄林击败徐军。** 齐楚争夺淮泗地区的局势继续恶化。 [[4]](#note-4)

<a id="event-5"></a>

5. **晋惠公长期不履行当年向秦许诺的土地和赏赐，又在晋饥时受秦粮、秦饥时反拒绝卖粮，秦穆公终于出兵伐晋。** 秦晋关系从恩惠与婚姻彻底转向战争。 [[5]](#note-5)

<a id="event-6"></a>

6. **十一月，秦晋在韩原决战，晋惠公不听庆郑等人劝告，最终兵败被俘。** 晋军虽兵多，秦军士气更盛；惠公战车陷泥后被秦军擒获。 [[6]](#note-6)

   秦方的叙述还写穆公追晋君时反遭围攻，曾受其赦免的食马者冲来解围。这里把这则救援故事附在同一韩原之战，不把秦君一时被围误写成秦军最终战败。

<a id="event-7"></a>

7. **晋惠公之姊秦穆姬以自焚相威胁，请秦穆公不要杀晋侯。** 秦国最终决定释放晋惠公，并与晋国重新议和。 [[7]](#note-7)

   周天子也为晋君求情；穆公在夫人与王室的要求下转向盟约和释放，给晋君更好的住处及牢礼。

<a id="event-8"></a>

8. **十一月，晋惠公回国，入城前处死庆郑。** 同年晋国再饥，秦穆公仍继续赠粮。 [[8]](#note-8)

<a id="event-9"></a>

9. **冬，宋国进攻曹国，报复旧怨。** 楚军在娄林与徐交战的同一件事见本页第4条，不重复列为第二次楚徐战争。 [[9]](#note-9)

<a id="event-10"></a>

10. **九月，鲁僖公从诸侯会盟返回；季姬正式回到鄫国。同月月末，雷电击中夷伯庙。** [[10]](#note-10)

<a id="event-11"></a>

11. **晋惠公被俘期间，晋国以赏田、整备军赋安定国人。** 吕甥让人借君命向国人传达，晋君虽能回来，也已使社稷受辱，可以考虑辅立太子圉。国人表示愿意继续支持，晋国遂作爰田，又整备兵赋、作州兵，使人们看到即使国君暂不能返，也仍有继承与抵抗的安排。 [[11]](#note-11)

<a id="sj014-0645-cai"></a>

<a id="event-12"></a>

12. **蔡国进入蔡庄侯元年。** 蔡穆侯肸已在前一年去世，蔡庄侯继位后的新君纪年从本年算起；其名字在史料中有异文。 [[12]](#note-12)

### 7. 晋惠公之姊秦穆姬以自焚相威胁，请秦穆公不要杀晋侯

[返回正文第7条](#event-7)

**[卷005 P025](../../sources/摘录/史记-卷005-秦本纪.md#p025)**

> 十四年，秦饑，請粟於晉。晉君謀之群臣。虢射曰：「因其饑伐之，可有大功。」晉君從之。十五年，興兵將攻秦。繆公發兵，使丕豹將，自往擊之。九月壬戌，與晉惠公夷吾合戰於韓地。晉君棄其軍，與秦爭利，還而馬騺。繆公與麾下馳追之，不能得晉君，反為晉軍所圍。晉擊繆公，繆公傷。於是岐下食善馬者三百人馳冒晉軍，晉軍解圍，遂脫繆公而反生得晉君。初，繆公亡善馬，岐下野人共得而食之者三百餘人，吏逐得，欲法之。繆公曰：「君子不以畜產害人。吾聞食善馬肉不飲酒，傷人。」乃皆賜酒而赦之。三百人者聞秦擊晉，皆求從，從而見繆公窘，亦皆推鋒爭死，以報食馬之德。於是繆公虜晉君以歸，令於國，齊宿，吾將以晉君祠上帝。周天子聞之，曰「晉我同姓」，為請晉君。夷吾姊亦為繆公夫人，夫人聞之，乃衰绖跣，曰：「妾兄弟不能相救，以辱君命。」繆公曰：「我得晉君以為功，今天子為請，夫人是憂。」乃與晉君盟，許歸之，更舍上舍，而饋之七牢。十一月，歸晉君夷吾，夷吾獻其河西地，使太子圉為質於秦。秦妻子圉以宗女。是時秦地東至河。

### 补充史料与异说

<a id="sj014-0645-lu-eclipse"></a>
<a id="卷014鲁栏五月日食与不书说法"></a>
#### 卷014鲁栏｜五月日食与「不书」说法

[《十二诸侯年表》前645年鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0645)记「五月，日有食之。不書，史官失之」；但[《春秋·僖公十五年》](#note-3)今本文字确有五月日食记录。此处保留经文所载日食及年表「不书」评语的文本冲突，不能用评语删去经文记录，是否指另一种书写传统待进一步校勘。

<a id="sj014-0645-cai-note"></a>
<a id="卷014蔡栏蔡庄侯元年与名字异文"></a>
#### 卷014蔡栏｜蔡庄侯元年与名字异文

[《十二诸侯年表》前645年蔡栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0645)记「蔡莊侯甲午元年」，[《管蔡世家》整理本](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7035.md#ref-076877f2cd2e24)作「子莊侯果立」。该整理本[校勘记](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7035.md#ref-7f92fc92a8a4ab)援引蔡公子果戈等器铭，主张「甲午」为传抄之误；这里保留该校勘观点，尚未独立核验器物铭文。[前646年](bce-0646.md#event-7)已记蔡穆侯去世，不重复计为本年死亡。

# 公元前645年（鲁僖公十五年）

[← 上一张已编年页：公元前646年](bce-0646.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前644年 →](bce-0644.md)

<a id="event-1"></a>

1. **春，鲁僖公前往齐国。** 齐桓公仍维持诸侯霸主地位。[[1]](#note-1)

<a id="event-2"></a>

2. **楚国进攻徐国，齐桓公召集鲁、宋、陈、卫、郑、许、曹在牡丘会盟，并派诸侯军救徐。** 联军驻匡等待救援行动。[[2]](#note-2)

<a id="event-3"></a>

3. **夏五月，发生日食；秋又发生螽灾。** 鲁国同年记录了两项灾异。[[3]](#note-3)

<a id="event-4"></a>

4. **齐、曹联军攻厉国，以牵制楚军、救援徐国；但冬天楚军仍在娄林击败徐军。** 齐楚争夺淮泗地区的局势继续恶化。[[4]](#note-4)

<a id="event-5"></a>

5. **晋惠公长期不履行当年向秦许诺的土地和赏赐，又在晋饥时受秦粮、秦饥时反拒绝卖粮，秦穆公终于出兵伐晋。** 秦晋关系从恩惠与婚姻彻底转向战争。[[5]](#note-5)

<a id="event-6"></a>

6. **十一月，秦晋在韩原决战，晋惠公不听庆郑等人劝告，最终兵败被俘。** 晋军虽兵多，秦军士气更盛；惠公战车陷泥后被秦军擒获。[[6]](#note-6)

秦方的叙述还写穆公追晋君时反遭围攻，曾受其赦免的食马者冲来解围。这里把这则救援故事附在同一韩原之战，不把秦君一时被围误写成秦军最终战败。

[补充史料与年次说明](#sj005-067-note)


<a id="event-7"></a>

7. **晋惠公之姊秦穆姬以自焚相威胁，请秦穆公不要杀晋侯。** 秦国最终决定释放晋惠公，并与晋国重新议和。[[7]](#note-7)

周天子也为晋君求情；穆公在夫人与王室的要求下转向盟约和释放，给晋君更好的住处及牢礼。

[补充史料与年次说明](#sj005-068-note)


<a id="event-8"></a>

8. **十一月，晋惠公回国，入城前处死庆郑。** 同年晋国再饥，秦穆公仍继续赠粮，并开始实际控制晋河东部分地区。[[8]](#note-8)

<a id="event-9"></a>

9. **冬，宋国进攻曹国，报复旧怨。** 楚军在娄林与徐交战的同一件事见本页第4条，不重复列为第二次楚徐战争。[[9]](#note-9)

<a id="event-10"></a>

10. **九月，鲁僖公从诸侯会盟返回；季姬正式回到鄫国。同月月末，雷电击中夷伯庙。** [[10]](#note-10)

<a id="event-11"></a>

11. **晋惠公被俘期间，晋国以赏田、整备军赋安定国人。** 吕甥让人借君命向国人传达，晋君虽能回来，也已使社稷受辱，可以考虑辅立太子圉。国人表示愿意继续支持，晋国遂作爰田，又整备兵赋、作州兵，使人们看到即使国君暂不能返，也仍有继承与抵抗的安排。 [看原文与说明](#cq-source-30)

1. **《春秋·僖公十五年》**：“十有五年春，王正月，公如齐。”

<a id="note-2"></a>

2. **《春秋·僖公十五年》**：“楚人伐徐。三月，公会齐侯、宋公、陈侯、卫侯、郑伯、许男、曹伯，盟于牡丘，遂次于匡。公孙敖帅师及诸侯之大夫救徐。”

<a id="note-3"></a>

3. **《春秋·僖公十五年》**：“夏五月，日有食之……八月，螽。”

<a id="note-4"></a>

4. **《春秋·僖公十五年》**：“秋七月，齐师、曹师伐厉……楚人败徐于娄林。”  
   **《左传·僖公十五年》**说明伐厉“以救徐也”。

<a id="note-5"></a>

5. **《左传·僖公十五年》**详叙晋惠公对秦失信、秦晋粮食往来与秦伯伐晋原因。

<a id="note-6"></a>

6. **《春秋·僖公十五年》**：“十有一月壬戌，晋侯及秦伯战于韩。获晋侯。”  
   **《左传·僖公十五年》**详记韩原之战全过程。

<a id="note-7"></a>

7. **《左传·僖公十五年》**详记穆姬登台履薪、秦伯决定不杀晋侯并许晋平。

<a id="note-8"></a>

8. **《左传·僖公十五年》**：“十一月晋侯归。丁丑，杀庆郑而后入……是岁，晋又饥，秦伯又饩之粟。”

<a id="note-9"></a>

9. **《春秋·僖公十五年》**：“冬，宋人伐曹。楚人败徐于娄林。”

<a id="note-10"></a>

10. **《春秋·僖公十五年》**：“九月，公至自会。季姬归于鄫。己卯晦，震夷伯之庙。”

### 核对30｜晋惠公被俘期间，晋国以赏田、整备军赋安定国人

**说明：**爰田、州兵依本段原名保留；本轮不把它直接称为一次已经考定的私有土地革命或全民征兵制度。

<details>
<summary>传 T010｜原文</summary>

> 晋侯使郤乞告瑕吕饴甥，且召之。子金教之言曰：“朝国人而以君命赏，且告之曰：‘孤虽归，辱社稷矣。其卜贰圉也。’”众皆哭。晋于是乎作爰田。吕甥曰：“君亡之不恤，而群臣是忧，惠之至也。将若君何？”众曰：“何为而可？”对曰：“征缮以辅孺子。诸侯闻之，丧君有君，群臣辑睦，甲兵益多，好我者劝，恶我者惧，庶有益乎！”众说。晋于是乎作州兵。

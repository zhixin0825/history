# 公元前646年（鲁僖公十四年）

[← 上一张已编年页：公元前647年](bce-0647.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前645年 →](bce-0645.md)

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，诸侯为杞国修筑缘陵，并把杞国迁到那里。** 这是齐桓公体系下又一次“存亡国”的救援行动。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，鄫季姬在防地会见鄫子，并要求鄫子亲自来鲁朝见。** 鲁国通过婚姻关系对鄫国施加礼仪压力。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋八月，沙鹿山崩。** 晋国卜偃把它解释为一年内将有大祸的征兆。 [[3]](#note-3)

<a id="event-4"></a>

4. **狄人侵郑。** 郑国同时面对北方狄人与南方楚国的长期压力。 [[4]](#note-4)

<a id="event-5"></a>

5. **冬，秦国也发生饥荒，向晋国请求购粮；晋惠公拒绝。** 这与上一年秦国大规模输粮救晋形成鲜明反差。 庆郑提醒惠公，即位与上次救饥都受过秦援，理应回报；虢射却把秦饥视为可乘之隙，惠公听从后一说。 [[5]](#note-5)

<a id="event-6"></a>

6. **晋大夫庆郑强烈反对拒绝秦粮请求，认为这是背恩、幸灾、失信、失邻。** 晋惠公仍未听从，秦晋关系由此加速恶化。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬，蔡侯肸去世。** 蔡国发生君主更替。 其子继承蔡侯之位，是为庄侯。 [[7]](#note-7)

<a id="sj014-0646-chu"></a>

<a id="event-8"></a>

8. **楚灭英。** 楚成王二十六年，楚国灭英。 [[8]](#note-8)

<a id="hs-event-9"></a>

9. **沙麓山崩。** [[9]](#hs-note-9)

### 5. 冬，秦国也发生饥荒，向晋国请求购粮；晋惠公拒绝

[返回正文第5条](#event-5)

**[《左传》本年传文](../../sources/春秋左传/有标点原文/bce-0646.md#batch-20261109-t005)**

> 冬，秦饥，使乞籴于晋，晋人弗与。

**[卷005 P025](../../sources/摘录/史记-卷005-秦本纪.md#p025)**

> 十四年，秦饑，請粟於晉。晉君謀之群臣。虢射曰：「因其饑伐之，可有大功。」晉君從之。十五年，興兵將攻秦。繆公發兵，使丕豹將，自往擊之。九月壬戌，與晉惠公夷吾合戰於韓地。晉君棄其軍，與秦爭利，還而馬騺。繆公與麾下馳追之，不能得晉君，反為晉軍所圍。晉擊繆公，繆公傷。於是岐下食善馬者三百人馳冒晉軍，晉軍解圍，遂脫繆公而反生得晉君。初，繆公亡善馬，岐下野人共得而食之者三百餘人，吏逐得，欲法之。繆公曰：「君子不以畜產害人。吾聞食善馬肉不飲酒，傷人。」乃皆賜酒而赦之。三百人者聞秦擊晉，皆求從，從而見繆公窘，亦皆推鋒爭死，以報食馬之德。於是繆公虜晉君以歸，令於國，齊宿，吾將以晉君祠上帝。周天子聞之，曰「晉我同姓」，為請晉君。夷吾姊亦為繆公夫人，夫人聞之，乃衰绖跣，曰：「妾兄弟不能相救，以辱君命。」繆公曰：「我得晉君以為功，今天子為請，夫人是憂。」乃與晉君盟，許歸之，更舍上舍，而饋之七牢。十一月，歸晉君夷吾，夷吾獻其河西地，使太子圉為質於秦。秦妻子圉以宗女。是時秦地東至河。

[史料说明](#history-legacy-source-5) · [史料说明](#sj005-066-note)

<a id="sj039-cite-078"></a>

**[《史记·晋世家》P045](../../sources/摘录/史记-卷039-晋世家.md#p045)**

> 五年，秦饑，請糴於晉。晉君謀之，慶鄭曰：「以秦得立，已而倍其地約。晉饑而秦貸我，今秦饑請糴，與之何疑？而謀之！」虢射曰：「往年天以晉賜秦，秦弗知取而貸我。今天以秦賜晉，晉其可以逆天乎？遂伐之。」惠公用虢射謀，不與秦粟，而發兵且伐秦。秦大怒，亦發兵伐晉。


**本卷说明：** 拒粮在前646，秦出兵与韩原大战在前645；原段末句是向下一年的结果连叙。

> 庆郑曰：“背施无亲，幸灾不仁，贪爱不祥，怒邻不义。四德皆失，何以守国？”虢射曰：“皮之不存，毛将安傅？”庆郑曰：“弃信背邻，患孰恤之？无信患作，失援必毙，是则然矣。”虢射曰：“无损于怨而厚于寇，不如勿与。”庆郑曰：“背施幸灾，民所弃也。近犹仇之，况怨敌乎。”弗听。退曰：“君其悔是哉！”

#### 卷014楚栏｜灭英及灭六异年

[《十二诸侯年表》前646年楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0646)记「二十六滅六、英」；[《楚世家·楚成王》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-df7a4185fbdc4e)同年仅记「二十六年，滅英」，在[楚穆王四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-2c403c32fa84e1)另记灭六、蓼。经传在[前622年](bce-0622.md#event-4)也记楚灭六。此处主述灭英，将「灭六」列为《年表》异年，不推定六国先灭后复国再灭。

# 公元前646年（鲁僖公十四年）

[← 上一张已编年页：公元前647年](bce-0647.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前645年 →](bce-0645.md)

<a id="event-1"></a>

1. **春，诸侯为杞国修筑缘陵，并把杞国迁到那里。** 这是齐桓公体系下又一次“存亡国”的救援行动。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，鄫季姬在防地会见鄫子，并要求鄫子亲自来鲁朝见。** 鲁国通过婚姻关系对鄫国施加礼仪压力。[[2]](#note-2)

<a id="event-3"></a>

3. **秋八月，沙鹿山崩。** 晋国卜偃把它解释为一年内将有大祸的征兆。[[3]](#note-3)

<a id="event-4"></a>

4. **狄人侵郑。** 郑国同时面对北方狄人与南方楚国的长期压力。[[4]](#note-4)

<a id="event-5"></a>

5. **冬，秦国也发生饥荒，向晋国请求购粮；晋惠公拒绝。** 这与上一年秦国大规模输粮救晋形成鲜明反差。[[5]](#note-5)

[补充史料与年次说明](#sj005-066-note)


<a id="event-6"></a>

6. **晋大夫庆郑强烈反对拒绝秦粮请求，认为这是背恩、幸灾、失信、失邻。** 晋惠公仍未听从，秦晋关系由此加速恶化。[[6]](#note-6)

<a id="event-7"></a>

7. **冬，蔡侯肸去世。** 蔡国发生君主更替。[[7]](#note-7)

<a id="sj014-0646-chu"></a>

8. **楚成王二十六年，楚国灭英。** 楚势力继续向淮河流域的小国推进；《十二诸侯年表》同列“灭六”，但六国的灭亡另有较晚的经传记年，见下方史料注。 [[8]](#sj014-0646-chu-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公十四年》**：“十有四年春，诸侯城缘陵。”  
   **《左传·僖公十四年》**：“诸侯城缘陵而迁杞焉。”

<a id="note-2"></a>

2. **《春秋·僖公十四年》**：“夏六月，季姬及鄫子遇于防，使鄫子来朝。”  
   **《左传·僖公十四年》**详记庄公因鄫子不朝而留季姬、季姬使鄫子来朝。

<a id="note-3"></a>

3. **《春秋·僖公十四年》**：“秋八月辛卯，沙鹿崩。”  
   **《左传·僖公十四年》**载卜偃“期年将有大咎”。

<a id="note-4"></a>

4. **《春秋·僖公十四年》**：“狄侵郑。”

<a id="note-5"></a>

5. **《左传·僖公十四年》**：“冬，秦饥，使乞籴于晋，晋人弗与。”

<a id="note-6"></a>

6. **《左传·僖公十四年》**详记庆郑批评“背施无亲，幸灾不仁，贪爱不祥，怒邻不义”。

<a id="note-7"></a>

7. **《春秋·僖公十四年》**：“冬，蔡侯肸卒。”

## 补充史料与异说

<a id="sj014-0646-chu-note"></a>
### 卷014楚栏｜灭英及灭六异年

[《十二诸侯年表》前646年楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0646)记「二十六滅六、英」；[《楚世家·楚成王》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-df7a4185fbdc4e)同年仅记「二十六年，滅英」，在[楚穆王四年](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-2c403c32fa84e1)另记灭六、蓼。经传在[前622年](bce-0622.md#event-4)也记楚灭六。此处主述灭英，将「灭六」列为《年表》异年，不推定六国先灭后复国再灭。

# 公元前647年（鲁僖公十三年）

[← 上一张已编年页：公元前648年](bce-0648.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前646年 →](bce-0646.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，狄人进攻卫国。** 北方边患持续。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，鲁国安葬陈宣公；同月齐桓公召集鲁、宋、陈、卫、郑、许、曹等国在咸地会盟。** 淮夷正在侵扰杞国，诸侯同时还要继续处理周王室问题。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋，因为王室仍受戎患威胁，诸侯派兵戍守周都。** 齐国仲孙湫负责协调这次驻防。 [[3]](#note-3)

<a id="event-4"></a>

4. **冬，晋国发生饥荒，向秦国请求购粮。** 秦国内部有人主张趁机伐晋，秦穆公拒绝，认为晋君有过，百姓无罪。 [[4]](#note-4)

   穆公问公孙支与百里奚，两人反对把晋君的过错转嫁给百姓；秦终于用舟车把粟运到晋都绛，丕豹借饥出兵的建议没有被采纳。

<a id="event-5"></a>

5. **秦国从雍地沿黄河一路运粮到晋都绛，史称“泛舟之役”。** 秦晋关系在韩原之战前仍保留着明显的救灾与恩惠关系。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬，公子友前往齐国。** 鲁齐外交继续保持。 [[6]](#note-6)

<a id="event-7"></a>

7. **秋九月，鲁国举行大雩祈雨。** [[7]](#note-7)

<a id="event-8"></a>

8. **春，齐国仲孙湫聘周，准备为王子带求情，却未开口。** 办完正式使事以后，仲孙湫没有谈王子带，回齐说周王怒气未消。他提出的多年后才可能召回只是判断，不当成本年王子带已经归国。 [[8]](#note-8)

<a id="sj014-0647-chen"></a>

<a id="event-9"></a>

9. **陈穆公款进入元年纪年。** 陈宣公杵臼已在前648年去世，其子款继承陈国君位。本年《十二诸侯年表》另记穆公元年；夏季诸侯会于咸时陈侯已经出席，同年举行的陈宣公葬礼并不意味着前任国君直到本年才去世。 [[9]](#note-9)

#### 卷014陈栏｜陈穆公款元年

[《十二诸侯年表》前647年陈栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0647)列「陳穆公款元年」；[《陈杞世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7036.md#ref-ce549cf477fa46)记宣公四十五年卒、子款立为穆公。[前648年](bce-0648.md#event-6)已有陈宣公之死；本页[夏季葬陈宣公及咸会](#event-2)也已有明确正文。此处只补本年新君元年，不重复葬礼，不据元年推定父亲死亡或儿子继位的具体月日。

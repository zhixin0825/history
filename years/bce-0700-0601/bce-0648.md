# 公元前648年（鲁僖公十二年）

[← 上一张已编年页：公元前649年](bce-0649.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前647年 →](bce-0647.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春三月庚午，发生日食。** 天象被精确记录。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚国灭黄国。** 黄国此前依赖齐桓公联盟而拒绝向楚尽职，最终仍未获得及时救援。 [[2]](#note-2)

<a id="event-3"></a>

3. **周襄王因前一年戎乱追究王子带，王子带逃往齐国。** 王室内部矛盾暂时被压下。 [[3]](#note-3)

    [卷四互见与归年](#sj004-648-1)

<a id="event-4"></a>

4. **齐桓公派管仲前往周王室调停戎事，又派隰朋处理晋国与戎人的关系。** 齐国霸权继续承担协调王室与诸侯的角色。 [[4]](#note-4)

<a id="event-5"></a>

5. **周王以上卿礼接待管仲，管仲坚持辞让，最后只受下卿礼。** 他强调自己只是齐国陪臣，不能越过齐国国氏、高氏等正卿的名位。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬十二月，陈宣公去世。** 陈国发生君主更替。 [[6]](#note-6)

<a id="event-7"></a>

7. **春，诸侯为卫国楚丘修筑外城。** 卫国已迁定楚丘，但仍担心狄人再次进攻；本次是加筑外郭，不是前658年安置卫国的同一次初建。 [[7]](#note-7)

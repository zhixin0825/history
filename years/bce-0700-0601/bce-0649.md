# 公元前649年（鲁僖公十一年）

[← 上一张已编年页：公元前650年](bce-0650.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前648年 →](bce-0648.md)

<a id="event-1"></a>

1. **春，晋国杀丕郑父，并向周王通报内乱处置。** 周王随后正式赐命晋惠公，但惠公受玉时态度怠慢，引发王室使者对晋国后世的担忧。[[1]](#note-1)

丕郑之子丕豹逃往秦，主张趁晋君失德而出兵。穆公却认为晋君仍能诛大臣，说明其政权尚可运作，没有立即接受伐晋之议，而暗中起用丕豹。

[补充史料与年次说明](#sj005-063-note)


<a id="event-2"></a>

2. **夏，扬、拒、泉、皋、伊、洛等戎联合攻入周王城，焚烧东门。** 这次进攻由王子带暗中召引，周王室再次发生严重安全危机。[[2]](#note-2)

 [卷四互见与归年](#sj004-649-1)


<a id="event-3"></a>

3. **秦、晋两国联合救周，并帮助王室平定戎患。** 晋惠公随后在王室主持与戎人的和解。[[3]](#note-3)

<a id="event-4"></a>

4. **夏，鲁僖公与夫人姜氏在阳穀会见齐桓公。** 鲁齐关系继续保持密切。[[4]](#note-4)

<a id="event-5"></a>

5. **秋，鲁国举行大雩。** 反映当年对降雨的祈求。[[5]](#note-5)

<a id="event-6"></a>

6. **冬，楚国出兵伐黄，因为黄国长期不向楚纳贡。** 黄国依赖齐国保护，却越来越直接面对楚国压力。[[6]](#note-6)

#### 王子带召戎攻周｜卷四互见

[卷004 P047](../../sources/摘录/史记-卷004-周本纪.md#p047)。 本纪襄王三年把带与戎翟谋攻、带出奔齐、管仲调处压在一段；经传将攻周与次年奔齐、调处分开，两个年页互见，不能整段搬到一个年份。

## 补充史料与异说

<a id="sj014-0649-zheng-legend"></a>
### 卷014郑栏｜燕姞生兰与梦兰传说

[《十二诸侯年表》前649年郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0649)载文公二十四年妾梦得兰而生后来的穆公兰；[《郑世家·郑文公》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7042.md#ref-14e86679b9a195)也在文公二十四年叙燕姞梦兰、文公宠幸而生兰。这个祥瑞梦兆属于史传对人物出生的解释，不能当成已独立证实的梦境，也不强定具体月日。郑穆公继位另在[前627年](bce-0627.md)记述，不提前算作本年即位。

# 公元前649年（鲁僖公十一年）

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，晋国杀丕郑父，并向周王通报内乱处置。** 丕郑之子豹逃往秦国，建议乘晋内乱出兵，秦穆公没有接受。周王随后使召公过来正式赐命晋惠公；惠公受玉时态度倨傲，引发使者对其失礼及晋国后世的担忧。 [[1]](#note-1)

   丕郑之子丕豹逃往秦，主张趁晋君失德而出兵。穆公却认为晋君仍能诛大臣，说明其政权尚可运作，没有立即接受伐晋之议，而暗中起用丕豹。

<a id="event-2"></a>

<a id="event-3"></a>

2. **诸戎攻焚周王城东门，秦晋发兵救周。** 夏，扬、拒、泉、皋、伊、洛等戎联军攻周，烧毁王城东门。秦、晋联合发兵救周，戎患得平。 [[2]](#note-2)

    [卷四互见与归年](#sj004-649-1)

<a id="event-4"></a>

3. **夏，鲁僖公与夫人姜氏在阳穀会见齐桓公。** 鲁齐关系继续保持密切。 [[3]](#note-4)

<a id="event-5"></a>

4. **秋，鲁国举行大雩。** 反映当年对降雨的祈求。 [[4]](#note-5)

<a id="event-6"></a>

5. **冬，楚国出兵伐黄，因为黄国长期不向楚纳贡。** 黄国依赖齐国保护，却越来越直接面对楚国压力。 [[5]](#note-6)

<a id="sj042-lan-birth-event"></a>

6. **燕姞生子兰，梦兰故事成为取名的来历。** 文公地位较低的妾燕姞梦见一人自称祖先伯鯈，给她兰草，说以此生子，兰有国之香。燕姞把梦告诉文公，文公宠幸她，并给兰草为凭信；后来生子，名兰。梦兰是解释子兰出生和得名的传说。 [[6]](#sj042-lan-birth-note)

### 1. 春，晋国杀丕郑父，并向周王通报内乱处置

[返回正文第1条](#event-1)

**[《春秋》本年经文](../../sources/春秋左传/有标点原文/bce-0649.md#batch-20261109-j001)**

> 十有一年春，晋杀其大夫丕郑父。

**[卷005 P022](../../sources/摘录/史记-卷005-秦本纪.md#p022)**

> 晉獻公卒。立驪姬子奚齊，其臣里克殺奚齊。荀息立卓子，克又殺卓子及荀息。夷吾使人請秦，求入晉。於是繆公許之，使百里傒將兵送夷吾。夷吾謂曰：「誠得立，請割晉之河西八城與秦。」及至，已立，而使丕鄭謝秦，背約不與河西城，而殺裏克。丕鄭聞之，恐，因與繆公謀曰：「晉人不欲夷吾，實欲重耳。今背秦約而殺裏克，皆呂甥、郤芮之計也。願君以利急召呂、郤，呂、郤至，則更入重耳便。」繆公許之，使人與丕鄭歸，召呂、郤。呂、郤等疑丕鄭有閒，乃言夷吾殺丕鄭。丕鄭子丕豹奔秦，說繆公曰：「晉君無道，百姓不親，可伐也。」繆公曰：「百姓茍不便，何故能誅其大臣？能誅其大臣，此其調也。」不聽，而陰用豹。

[史料说明](#history-legacy-source-1) · [史料说明](#sj005-063-note)

<a id="sj039-cite-074"></a>

**[《史记·晋世家》P042](../../sources/摘录/史记-卷039-晋世家.md#p042)**

> 三子曰：「幣厚言甘，此必邳鄭賣我於秦。」遂殺邳鄭及裏克、邳鄭之黨七輿大夫。邳鄭子豹奔秦，言伐晉，繆公弗聽。


<!-- /sj039-cite-074 -->

<a id="sj039-cite-075"></a>

**[《史记·晋世家》P043](../../sources/摘录/史记-卷039-晋世家.md#p043)**

**本卷说明：** 前段“国人不附”是对背约杀党后政治处境的总评。

#### 卷014郑栏｜燕姞生兰与梦兰传说

[《十二诸侯年表》前649年郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0649)载文公二十四年妾梦得兰而生后来的穆公兰；[《郑世家·郑文公》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7042.md#ref-14e86679b9a195)也在文公二十四年叙燕姞梦兰、文公宠幸而生兰。这个祥瑞梦兆属于史传对人物出生的解释，不能当成已独立证实的梦境，也不强定具体月日。郑穆公继位另在[前627年](bce-0627.md)记述，不提前算作本年即位。

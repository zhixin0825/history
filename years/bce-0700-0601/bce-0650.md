# 公元前650年（鲁僖公十年）

[← 上一张已编年页：公元前651年](bce-0651.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前649年 →](bce-0649.md)

<a id="event-1"></a>

1. **春，鲁僖公前往齐国。** 齐桓公霸业仍然维持着中原诸侯的朝会网络。[[1]](#note-1)

<a id="event-2"></a>

2. **狄人灭温国，温子逃往卫国。** 温此前反复依附、背叛周王与狄人，最终失国。[[2]](#note-2)

<a id="event-3"></a>

3. **晋惠公夷吾开始以元年纪事，立定以后于四月杀里克。** 周公忌父、王子党会齐隰朋拥立晋侯。惠公随后以里克曾杀二君一大夫为由命其死，里克伏剑自杀。丕郑当时在秦国聘问、解释晋方迟交赂物，所以未同时被杀。 [看原文与说明](#cq-source-68)

<a id="event-4"></a>

4. **晋惠公把太子申生重新安葬。** 新政权试图修复献公末年的继承创伤。[[4]](#note-4)

<a id="event-5"></a>

5. **晋惠公此前答应秦国的土地和赏赐多未兑现，又开始清洗里克、丕郑一党。** 丕郑赴秦后谋划迎重耳入晋，事泄后其党多人被杀。[[5]](#note-5)

丕郑向秦建议以利益诱召吕甥、郤芮，待两人到秦，再安排重耳返晋。这个计划在召请阶段就受到怀疑，没有按原案实现。

[补充史料与年次说明](#sj005-062-note)


<a id="event-6"></a>

6. **夏，齐桓公与许国出兵伐北戎。** 齐国继续维持北方军事压力。[[6]](#note-6)

<a id="event-7"></a>

7. **冬，鲁国降大雪。** 气候异常被记录。[[7]](#note-7)

<a id="sj014-0650-song"></a>

8. **宋国开始以宋襄公兹父的元年纪事，庶兄目夷继续辅佐他。** 宋桓公在前651年去世，兹父当年已继位；前650年是年表新君纪年的第一年，并非宋桓公再度去世。 [[8]](#sj014-0650-song-note)

## 补充史料与异说

<a id="sj014-0650-qin-variant"></a>
### 卷014秦栏｜丕豹赴秦的前后纪年

[《十二诸侯年表》前650年秦栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0650)记「十丕鄭子豹亡來」，但[《春秋·僖公十一年》](../../sources/春秋左传/有标点原文/bce-0649.md)在[前649年](bce-0649.md#event-1)才记晋杀丕郑父，而其子丕豹继而逃秦。《秦本纪》关于丕豹归秦的叙述亦与晋国继承危机相连；本文以经传可定位的父死及后续奔秦主述于前649年，在本处保留年表的较早系年，不将其重写为第二次奔秦。

<a id="sj005-062-note"></a>
### sj005-062｜同一事件的补充与取舍

[卷005 P022](../../sources/摘录/史记-卷005-秦本纪.md#p022)。

**说明：**本纪长段从返晋写到丕郑被杀，后者依经传在前649。此处保留的是拒绝交地与策划召吕郤阶段，不提前重复杀丕郑。

## 补充史料与异说

<a id="sj014-0650-song-note"></a>
### 卷014宋栏｜宋襄公元年与目夷为相

[《十二诸侯年表》前650年宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0650)记「宋襄公茲父元年，目夷相」；[《宋微子世家·宋桓公》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7038.md#ref-ced5b64d9c9e3d)记桓公三十一年卒、太子兹甫立、以目夷为相。[前651年](bce-0651.md#event-1)已写宋桓公卒和兹父继位，本年只补新君元年，不重复死亡、即位或葵丘之会。

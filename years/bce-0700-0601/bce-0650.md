# 公元前650年（鲁僖公十年）

[← 上一张已编年页：公元前651年](bce-0651.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前649年 →](bce-0649.md)

<a id="event-1"></a>

1. **春，鲁僖公前往齐国。** 齐桓公霸业仍然维持着中原诸侯的朝会网络。[1]

<a id="event-2"></a>

2. **狄人灭温国，温子逃往卫国。** 温此前反复依附、背叛周王与狄人，最终失国。[2]

<a id="event-3"></a>

3. **晋国内乱继续：里克杀卓子和荀息；晋惠公夷吾正式立稳后，又杀里克。** 里克虽帮助夷吾取得君位，却因连杀两君及大夫而被视为威胁，最终伏剑而死。[3]

<a id="event-4"></a>

4. **晋惠公把太子申生重新安葬。** 新政权试图修复献公末年的继承创伤。[4]

<a id="event-5"></a>

5. **晋惠公此前答应秦国的土地和赏赐多未兑现，又开始清洗里克、丕郑一党。** 丕郑赴秦后谋划迎重耳入晋，事泄后其党多人被杀。[5]

<a id="event-6"></a>

6. **夏，齐桓公与许国出兵伐北戎。** 齐国继续维持北方军事压力。[6]

<a id="event-7"></a>

7. **冬，鲁国降大雪。** 气候异常被记录。[7]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公十年》**：“十年春，王正月，公如齐。”

   **《左传·僖公十年》**详记苏子叛王即狄又失信于狄。

<a id="note-3"></a>

3. **《春秋·僖公十年》**：“晋里克弑其君卓，及其大夫荀息……晋杀其大夫里克。”  
   **《左传·僖公十年》**详记晋惠公逼里克自杀。

<a id="note-4"></a>

4. **《左传·僖公十年》**：“晋侯改葬共大子。”

<a id="note-5"></a>

5. **《左传·僖公十年》**详记丕郑谋迎重耳、郤芮识破，继而杀丕郑、祁举及七舆大夫。

<a id="note-6"></a>

6. **《春秋·僖公十年》**：“夏，齐侯、许男伐北戎。”

<a id="note-7"></a>

<a id="event-1"></a>

1. **春，鲁僖公前往齐国。** 齐桓公霸业仍然维持着中原诸侯的朝会网络。 [[1]](#note-1)

<a id="event-2"></a>

2. **狄人灭温国，温子逃往卫国。** 温此前反复依附、背叛周王与狄人，最终失国。 [[2]](#note-2)

<a id="event-3"></a>

<a id="event-4"></a>

<a id="event-5"></a>

3. **晋惠公即位，杀里克并改葬申生。** 周公忌父、王子党与齐大夫隰朋共同拥立夷吾，是为晋惠公。四月，惠公以里克曾杀两君和一大夫为由令他自尽。里克反问新君若无废立何以得国，随后伏剑。惠公改葬太子申生，有关狐突见申生鬼魂的传说也从此事引出。惠公以群臣反对为由不割河西给秦国，也不兑现对里克的封邑承诺。丕郑赴秦解释迟交赂物，闻里克被杀，劝秦以重礼联络吕甥、郤称、冀芮迎重耳。诛丕郑与其党见[次年](bce-0649.md#note-1)。 [[3]](#note-3)

   丕郑向秦建议以利益诱召吕甥、郤芮，待两人到秦，再安排重耳返晋。这个计划在召请阶段就受到怀疑，没有按原案实现。

<a id="event-6"></a>

4. **夏，齐桓公与许国出兵伐北戎。** 齐国继续维持北方军事压力。 [[4]](#note-6)

<a id="event-7"></a>

<a id="hs-event-9"></a>

5. **鲁国冬季降大雪。** [[5]](#note-7)

<a id="sj014-0650-song"></a>

<a id="event-8"></a>

6. **宋襄公兹父元年。** 兹父在宋桓公死后继位，本年为宋襄公元年，庶兄目夷继续辅佐。 [[6]](#note-8)

**[《史记·晋世家》P041](../../拆分史书/史记/卷039.md#p041)**

> 晉君改葬恭太子申生。秋，狐突之下國，遇申生，申生與載而告之曰：「夷吾無禮，余得請於帝，將以晉與秦，秦將祀余。」狐突對曰：「臣聞神不食非其宗，君其祀毋乃絕乎？君其圖之。」申生曰：「諾，吾將復請帝。後十日，新城西偏將有巫者見我焉。」許之，遂不見。及期而往，復見，申生告之曰：「帝許罰有罪矣，弊於韓。」兒乃謠曰：「恭太子更葬矣，後十四年，晉亦不昌，昌乃在兄。」


**本卷说明：** 鬼神对话、十日应期及十四年后童谣均为叙述者的预兆解释，不当成可独立定年的政事。

**[《左传》鲁僖公10年传文（前650年）](../../拆分史书/左传/bce-0650.md#batch-20261109-t006)**

> 冬，秦伯使泠至报问，且召三子。郤芮曰：“币重而言甘，诱我也。”遂杀丕郑、祁举及七舆大夫：左行共华、右行贾华、叔坚、骓歂、累虎、特宫、山祁，皆里、丕之党也。丕豹奔秦，言于秦伯曰：“晋侯背大主而忌小怨，民弗与也，伐之必出。”公曰：“失众，焉能杀。违祸，谁能出君。”

**[卷005 P022](../../拆分史书/史记/卷005.md#p022)**

> 晉獻公卒。立驪姬子奚齊，其臣里克殺奚齊。荀息立卓子，克又殺卓子及荀息。夷吾使人請秦，求入晉。於是繆公許之，使百里傒將兵送夷吾。夷吾謂曰：「誠得立，請割晉之河西八城與秦。」及至，已立，而使丕鄭謝秦，背約不與河西城，而殺裏克。丕鄭聞之，恐，因與繆公謀曰：「晉人不欲夷吾，實欲重耳。今背秦約而殺裏克，皆呂甥、郤芮之計也。願君以利急召呂、郤，呂、郤至，則更入重耳便。」繆公許之，使人與丕鄭歸，召呂、郤。呂、郤等疑丕鄭有閒，乃言夷吾殺丕鄭。丕鄭子丕豹奔秦，說繆公曰：「晉君無道，百姓不親，可伐也。」繆公曰：「百姓茍不便，何故能誅其大臣？能誅其大臣，此其調也。」不聽，而陰用豹。

#### 卷014秦栏｜丕豹赴秦的前后纪年

[《十二诸侯年表》前650年秦栏](../../拆分史书/史记/卷014.md#y0650)记「十丕鄭子豹亡來」，但[《春秋·僖公十一年》](../../拆分史书/左传/bce-0649.md)在[前649年](bce-0649.md#event-1)才记晋杀丕郑父，而其子丕豹继而逃秦。《秦本纪》关于丕豹归秦的叙述亦与晋国继承危机相连；本文以经传可定位的父死及后续奔秦主述于前649年，在本处保留年表的较早系年，不将其重写为第二次奔秦。

#### 卷014宋栏｜宋襄公元年与目夷为相

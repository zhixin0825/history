# 公元前651年（鲁僖公九年）

[← 上一张已编年页：公元前652年](bce-0652.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前650年 →](bce-0650.md)

<a id="event-1"></a>

1. **春，宋桓公去世，太子兹父在服丧期间以“宋子”身份参加诸侯活动，后来即位为宋襄公。** 目夷担任左师辅政。[1]

<a id="event-2"></a>

2. **夏，齐桓公在葵丘召开诸侯大会，周王派宰孔赐祭肉，正式以“伯舅”礼遇齐桓公。** 齐桓公仍坚持下拜受赐，以示尊王。[2]

<a id="event-3"></a>

3. **秋九月，诸侯再次在葵丘盟誓，齐桓公霸业达到高峰。** 盟辞要求盟国此后恢复友好、共同维持秩序。[3]

<a id="event-4"></a>

4. **晋献公去世。** 里克等人想迎重耳回国，晋国内部立即爆发争位。[4]

<a id="event-5"></a>

5. **冬，里克杀死骊姬之子奚齐。** 荀息坚持对晋献公临终托孤的承诺，又拥立卓子继续维持原继承安排。[5]

<a id="event-6"></a>

6. **秦、齐开始介入晋国继承，夷吾以重赂向秦求助。** 秦穆公与齐隰朋最终帮助夷吾回晋，为下一年晋惠公即位创造条件。[6]

<a id="event-7"></a>

7. **秋七月乙酉，伯姬去世。** [7]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公九年》**：“春，王三月丁丑，宋公御说卒……宋子……”  
   **《左传·僖公九年》**详记宋襄公即位、目夷为左师。

<a id="note-2"></a>

2. **《春秋·僖公九年》**：“夏，公会宰周公、齐侯、宋子、卫侯、郑伯、许男、曹伯于葵丘。”  
   **《左传·僖公九年》**详记天子赐胙与齐桓公下拜。

<a id="note-3"></a>

3. **《春秋·僖公九年》**：“九月戊辰，诸侯盟于葵丘。”  
   **《左传·僖公九年》**载盟辞“既盟之后，言归于好”。

<a id="note-4"></a>

4. **《春秋·僖公九年》**：“甲子，晋侯佹诸卒。”  
   **《左传·僖公九年》**：“晋献公卒。”

<a id="note-5"></a>

5. **《春秋·僖公九年》**：“冬，晋里克杀其君之子奚齐。”  
   **《左传·僖公九年》**详记荀息受托与奚齐被杀。

<a id="note-6"></a>

6. **《左传·僖公九年》**详记郤芮使夷吾重赂秦求入，齐隰朋会秦师纳晋惠公。

<a id="note-7"></a>

7. **《春秋·僖公九年》**：“秋七月乙酉，伯姬卒。”

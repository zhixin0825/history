# 公元前651年（鲁僖公九年）

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **春，宋桓公去世，太子兹父在服丧期间以“宋子”身份参加诸侯活动，后来即位为宋襄公。** 目夷担任左师辅政。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **夏，齐桓公在葵丘召开诸侯大会，周王派宰孔赐祭肉，正式以“伯舅”礼遇齐桓公。** 齐桓公仍坚持下拜受赐，以示尊王。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **秋九月，诸侯再次在葵丘盟誓，齐桓公霸业达到高峰。** 盟辞要求盟国此后恢复友好、共同维持秩序。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **晋献公去世。** 里克等人想迎重耳回国，晋国内部立即爆发争位。 献公晚年的晋国西至河西、与秦相接，北邻狄，东达河内；这是他在位时期扩张后的概况，不表示这些区域全在去世之年新得。献公曾准备赴葵丘会盟，途中因病落后，又听宰孔批评齐桓公远略而返国。病重时托荀息扶奚齐，荀息以守信答应。 [[4]](#reading-note-4)

<a id="event-5"></a>

<a id="reading-event-5"></a>

5. **冬，里克杀死骊姬之子奚齐。** 荀息坚持对晋献公临终托孤的承诺，又拥立卓子继续维持原继承安排。 [[5]](#reading-note-5)

<a id="reading-event-6"></a>

6. **十一月，卓子也被里克杀死，荀息随之而死。** 奚齐死后，荀息原想殉死，经人劝说先拥立悼子、主持献公葬礼。悼子是骊姬妹妹所生，经传常称他卓子。有人劝荀息自保，他却以受先君托付、不能失信为由留下；里克接着在朝廷杀卓子，荀息一同遭难。早年伐骊戎所得卜兆，也在后来被解释为眼前内乱的预告。 [[6]](#reading-note-6)

<a id="event-6"></a>

<a id="reading-event-7"></a>

7. **秦、齐开始介入晋国继承，夷吾以重赂向秦求助。** 秦军与齐隰朋所率军队帮助夷吾入晋，是本年的继位过程；前650年年表另起晋惠公元年，不是到那时才第一次回国。 里克等先请重耳回国，重耳以违父命出亡、不能侍丧为由谢绝。夷吾转而通过郤芮许秦河西地，又许里克汾阳邑，以此争取送归。 [[7]](#reading-note-7)

<a id="reading-event-8"></a>

8. **齐桓公还率诸侯军到高梁，讨问晋国内乱。** 这支军队抵达高梁以后便返回。鲁国没有接到这次行动的命令，因此经文未专列鲁国参加伐晋；不能仅用秦、齐协助夷吾来概括所有干预。 [[8]](#reading-note-8)

   秦方参与的将领包括百里奚；夷吾以能够继立为条件，许诺割让河西八城。这是一项尚待兑现的许诺，不是本年已经交地。

<a id="event-7"></a>

<a id="reading-event-9"></a>

9. **秋七月乙酉，伯姬去世。** [[9]](#reading-note-9)

<a id="sj014-0651-zhou"></a>

<a id="reading-event-10"></a>

10. **周襄王郑进入元年纪年，诸侯承认其王位。** 周惠王此前去世，襄王因担心王子带争位，一度延迟发丧；到前652年通过洮盟稳住继承并正式向诸侯报丧。本年《十二诸侯年表》才把周襄王列作元年，不能把惠王死、诸侯立王和元年算作同一时点的三次君位变化。 [[10]](#reading-note-10)

**[卷005 P022](../../sources/摘录/史记-卷005-秦本纪.md#p022)**

> 晉獻公卒。立驪姬子奚齊，其臣里克殺奚齊。荀息立卓子，克又殺卓子及荀息。夷吾使人請秦，求入晉。於是繆公許之，使百里傒將兵送夷吾。夷吾謂曰：「誠得立，請割晉之河西八城與秦。」及至，已立，而使丕鄭謝秦，背約不與河西城，而殺裏克。丕鄭聞之，恐，因與繆公謀曰：「晉人不欲夷吾，實欲重耳。今背秦約而殺裏克，皆呂甥、郤芮之計也。願君以利急召呂、郤，呂、郤至，則更入重耳便。」繆公許之，使人與丕鄭歸，召呂、郤。呂、郤等疑丕鄭有閒，乃言夷吾殺丕鄭。丕鄭子丕豹奔秦，說繆公曰：「晉君無道，百姓不親，可伐也。」繆公曰：「百姓茍不便，何故能誅其大臣？能誅其大臣，此其調也。」不聽，而陰用豹。

<a id="sj032-hegemon-review"></a>

### 九合、远征与未举行的封禅：无确年综述

这是本卷霸业评价与封禅愿望的专题连叙，未给独立年、月；置在葵丘主线之后互见，不冒充本年新事件。

**[《史记·齐太公世家》P041](../../sources/摘录/史记-卷032-齐太公世家.md#p041)**

> 是時周室微，唯齊、楚、秦、晉為彊。晉初與會，獻公死，國內亂。秦穆公辟遠，不與中國會盟。楚成王初收荊蠻有之，夷狄自置。唯獨齊為中國會盟，而桓公能宣其德，故諸侯賓會。於是桓公稱曰：「寡人南伐至召陵，望熊山；北伐山戎、離枝、孤竹；西伐大夏，涉流沙；束馬懸車登太行，至卑耳山而還。諸侯莫違寡人。寡人兵車之會三，乘車之會六，九合諸侯，一匡天下。昔三代受命，有何以異於此乎？吾欲封泰山，禪梁父。」管仲固諫，不聽；乃說桓公以遠方珍怪物至乃得封，桓公乃止。

**读法与异说：** 齐桓公未能封禅；本段霸功总述和封禅议论没有明确独立纪年，只放本年背景，不能当作前651年已经举行。

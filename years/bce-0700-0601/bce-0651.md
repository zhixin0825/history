# 公元前651年（鲁僖公九年）

[← 上一张已编年页：公元前652年](bce-0652.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前650年 →](bce-0650.md)

<a id="event-1"></a>

1. **春，宋桓公去世，太子兹父在服丧期间以“宋子”身份参加诸侯活动，后来即位为宋襄公。** 目夷担任左师辅政。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，齐桓公在葵丘召开诸侯大会，周王派宰孔赐祭肉，正式以“伯舅”礼遇齐桓公。** 齐桓公仍坚持下拜受赐，以示尊王。[[2]](#note-2)

[补充史料与年次说明](#sj005-059-note)


<a id="event-3"></a>

3. **秋九月，诸侯再次在葵丘盟誓，齐桓公霸业达到高峰。** 盟辞要求盟国此后恢复友好、共同维持秩序。[[3]](#note-3)

<a id="event-4"></a>

4. **晋献公去世。** 里克等人想迎重耳回国，晋国内部立即爆发争位。[[4]](#note-4)

<a id="event-5"></a>

5. **冬，里克杀死骊姬之子奚齐。** 荀息坚持对晋献公临终托孤的承诺，又拥立卓子继续维持原继承安排。[[5]](#note-5)

**十一月，卓子也被里克杀死，荀息随之而死。** 奚齐死后，荀息原想殉死，经人劝说先立卓子、主持献公葬礼。里克接着在朝廷杀卓子，荀息终于兑现了与献公所作的承诺。 [看原文与说明](#cq-source-67)

[补充史料与年次说明](#sj005-060-note)


<a id="event-6"></a>

6. **秦、齐开始介入晋国继承，夷吾以重赂向秦求助。** 秦穆公与齐隰朋最终帮助夷吾回晋，为下一年晋惠公即位创造条件。[[6]](#note-6)

**齐桓公还率诸侯军到高梁，讨问晋国内乱。** 这支军队抵达高梁以后便返回。鲁国没有接到这次行动的命令，因此经文未专列鲁国参加伐晋；不能仅用秦、齐协助夷吾来概括所有干预。 [看原文与说明](#cq-source-27)

秦方参与的将领包括百里奚；夷吾以能够继立为条件，许诺割让河西八城。这是一项尚待兑现的许诺，不是本年已经交地。

[补充史料与年次说明](#sj005-061-note)


<a id="event-7"></a>

7. **秋七月乙酉，伯姬去世。** [[7]](#note-7)

<a id="sj014-0651-zhou"></a>

8. **周襄王郑进入元年纪年，诸侯承认其王位。** 周惠王此前去世，襄王因担心王子带争位，一度延迟发丧；到前652年通过洮盟稳住继承并正式向诸侯报丧。本年《十二诸侯年表》才把周襄王列作元年，不能把惠王死、诸侯立王和元年算作同一时点的三次君位变化。 [[8]](#sj014-0651-zhou-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公九年》**：“春，王三月丁丑，宋公御说卒……宋子……”  
   **《左传·僖公九年》**详记宋襄公即位、目夷为左师。

<a id="note-2"></a>

2. **《春秋·僖公九年》**：“夏，公会宰周公、齐侯、宋子、卫侯、郑伯、许男、曹伯于葵丘。”  
   **《左传·僖公九年》**详记天子赐胙与齐桓公下拜。

<a id="note-3"></a>

3. **《春秋·僖公九年》**：“九月戊辰，诸侯盟于葵丘。”  
   **《左传·僖公九年》**载盟辞“既盟之后，言归于好”。

<a id="note-4"></a>

4. **《春秋·僖公九年》**：“甲子，晋侯佹诸卒。”  
   **《左传·僖公九年》**：“晋献公卒。”

<a id="note-5"></a>

5. **《春秋·僖公九年》**：“冬，晋里克杀其君之子奚齐。”  
   **《左传·僖公九年》**详记荀息受托与奚齐被杀。

<a id="note-6"></a>

6. **《左传·僖公九年》**详记郤芮使夷吾重赂秦求入，齐隰朋会秦师纳晋惠公。

<a id="note-7"></a>

7. **《春秋·僖公九年》**：“秋七月乙酉，伯姬卒。”

### 核对67｜十一月，卓子也被里克杀死，荀息随之而死

**说明：**《左传》在僖公九年十一月记卓子、荀息之死，《春秋》经却将相应条目列在十年。正文按传文明确的事件月次接写；前650年保留经文的记年差别，不再讲成又死一次。

<details>
<summary>传 T006｜原文</summary>

> 冬十月，里克杀奚齐于次。书曰：“杀其君之子。”未葬也。荀息将死之，人曰：“不如立卓子而辅之。”荀息立公子卓以葬。

[本段出处](../../sources/春秋左传/有标点原文/bce-0651.md#t006)

</details>

<details>
<summary>传 T007｜原文</summary>

> 十一月，里克杀公子卓于朝，荀息死之。君子曰：“诗所谓‘白圭之玷，尚可磨也；斯言之玷，不可为也’，荀息有焉。”

[本段出处](../../sources/春秋左传/有标点原文/bce-0651.md#t007)

## 补充史料与异说


<a id="sj014-0651-zhou-note"></a>
### 卷014周栏｜周襄王元年

[《十二诸侯年表》前651年周栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0651)记「襄王元年，諸侯立王」，上一行前652年周栏则记「襄王立，畏太叔」。[前653年](bce-0653.md#event-6)《左传》记惠王闰月已卒而暂不发丧，[前652年](bce-0652.md#event-1)记洮盟稳定王位、[同年正式告丧](bce-0652.md#event-4)。本页补的是年表元年及诸侯承认的纪年口径，不据年表把惠王死亡移来本年，也不另定新的即位月日。

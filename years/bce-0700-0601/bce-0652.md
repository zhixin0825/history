<a id="event-1"></a>

<a id="event-4"></a>

1. **诸侯会洮处理周室继承，周王室冬告丧。** 春，鲁僖公与周使及齐、宋、卫、许、曹、陈会于洮，商议周王室的继承。冬，周向诸侯正式通告周惠王之丧。 [[1]](#note-1)

   继位的是惠王之子郑，即襄王。王名郑与郑国国名相同，不能因此把这位周王误认成郑国国君。 [卷四互见与归年](#sj004-652-1)

<a id="event-2"></a>

2. **晋军先在采桑击败狄人，夏天狄人又反攻晋国。** 晋、狄边境冲突持续。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋，鲁国在太庙禘祭时把哀姜重新祔入宗庙。** 哀姜死在外地，又没有按正常夫人丧礼程序完成，因此这次做法受到批评。 [[3]](#note-3)

<a id="event-5"></a>

4. **宋桓公病重，太子兹父主动请求把君位让给长而仁的目夷；目夷拒绝。** 兹父仍然成为继承人，次年即位为宋襄公。 [[4]](#note-5)

<a id="sj014-0652-cao"></a>

<a id="event-6"></a>

5. **曹共公襄开始按元年纪事。** 曹昭公班上年去世，入冬安葬。儿子襄继位，本年为曹共公元年。 [[5]](#note-6)

##### 惠王之丧与襄王继立｜卷四互见

[卷004 P047](../../拆分史书/史记/卷004.md#p047)。 经传明记惠王已卒而襄王秘不发丧；本纪以惠王二十五年总括死亡、继立。此前实际死期与本年正式通告分开，不把本年再记第二次周王死亡。

### 补充史料与异说

<a id="sj014-0652-cao-note"></a>
<a id="卷014曹栏曹共公襄元年"></a>
#### 卷014曹栏｜曹共公襄元年

[《十二诸侯年表》前652年曹栏](../../拆分史书/史记/卷014.md#y0652)记「曹共公元年」；[《管蔡世家》曹昭公段](../../拆分史书/史记/卷035.md#part-1-text)称昭公九年卒、子共公襄立。[前653年](bce-0653.md#event-7)已有曹昭公卒及葬礼，本条仅落实次年元年及名字，不定无据的具体即位日、改元日。

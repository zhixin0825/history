# 公元前652年（鲁僖公八年）

[← 上一张已编年页：公元前653年](bce-0653.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前651年 →](bce-0651.md)

<a id="event-1"></a>

1. **春，鲁僖公与周王使者、齐、宋、卫、许、曹、陈等在洮地结盟，处理周王室继承问题。** 郑伯也来请求加入盟约；周襄王先稳住王位，随后才正式发丧。[[1]](#note-1)

<a id="event-2"></a>

2. **晋军先在采桑击败狄人，夏天狄人又反攻晋国。** 晋、狄边境冲突持续。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，鲁国在太庙禘祭时把哀姜重新祔入宗庙。** 哀姜死在外地，又没有按正常夫人丧礼程序完成，因此这次做法受到批评。[[3]](#note-3)

<a id="event-4"></a>

4. **冬，周王室正式向诸侯通告周惠王去世。** 因此前王位风险，讣告被延后。[[4]](#note-4)

继位的是惠王之子郑，即襄王。王名郑与郑国国名相同，不能因此把这位周王误认成郑国国君。 [卷四互见与归年](#sj004-652-1)


<a id="event-5"></a>

5. **宋桓公病重，太子兹父主动请求把君位让给长而仁的目夷；目夷拒绝。** 兹父仍然成为继承人，次年即位为宋襄公。[[5]](#note-5)

<a id="sj014-0652-cao"></a>

6. **曹共公襄开始按元年纪事。** 上年前653年曹昭公班去世、同年冬已举行葬礼，其子襄继位为曹共公。本年年表另起元年，不应把父亲之死和本年改元写成同一次更君。 [[6]](#sj014-0652-cao-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公八年》**：“公会王人、齐侯、宋公、卫侯、许男、曹伯、陈世子款，盟于洮。郑伯乞盟。”  
   **《左传·僖公八年》**：“谋王室也……襄王定位而后发丧。”

<a id="note-2"></a>

2. **《左传·僖公八年》**详记晋军败狄于采桑，夏狄伐晋报复。

<a id="note-3"></a>

3. **《春秋·僖公八年》**：“秋七月，禘于大庙，用致夫人。”  
   **《左传·僖公八年》**指出把哀姜“致”入庙不合礼。

<a id="note-4"></a>

4. **《春秋·僖公八年》**：“冬十有二月丁未，天王崩。”  
   **《左传·僖公八年》**：“王人来告丧，难故也，是以缓。”

<a id="sj004-652-1"></a>
#### 惠王之丧与襄王继立｜卷四互见

[卷004 P047](../../sources/摘录/史记-卷004-周本纪.md#p047)。 经传明记惠王已卒而襄王秘不发丧；本纪以惠王二十五年总括死亡、继立。此前实际死期与本年正式通告分开，不把本年再记第二次周王死亡。


<a id="note-5"></a>

5. **《左传·僖公八年》**详记宋太子兹父请立目夷、目夷辞让。

## 补充史料与异说

<a id="sj014-0652-cao-note"></a>
### 卷014曹栏｜曹共公襄元年

[《十二诸侯年表》前652年曹栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0652)记「曹共公元年」；[《管蔡世家》曹昭公段](https://zh.wikisource.org/wiki/史記/卷035#昭公)称昭公九年卒、子共公襄立。[前653年](bce-0653.md#event-7)已有曹昭公卒及葬礼，本条仅落实次年元年及名字，不定无据的具体即位日、改元日。

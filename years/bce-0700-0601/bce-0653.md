# 公元前653年（鲁僖公七年）

[← 上一张已编年页：公元前654年](bce-0654.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前652年 →](bce-0652.md)

<a id="event-1"></a>

1. **春，齐国再次伐郑，郑国已经难以继续抵抗齐国联盟。** 大夫孔叔主张主动向齐服软。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，郑国杀申侯，以此向齐国交代。** 申侯曾先后受楚、郑宠信，却因贪利和旧怨卷入多方政治，最终被郑伯牺牲。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，齐桓公与鲁、宋、陈、郑等在甯母结盟，继续解决郑国问题。** 郑太子华代表郑国赴会。[[3]](#note-3)

<a id="event-4"></a>

4. **太子华私下向齐桓公提出：若齐国帮助除掉郑国洩氏、孔氏、子人氏三族，郑愿成为齐国内臣。** 管仲坚决反对，认为齐国若以礼信号召诸侯，却趁机参与郑国内部清洗，会破坏霸主信用；齐桓公最终拒绝。[[4]](#note-4)

<a id="event-5"></a>

5. **郑伯随后正式请求与齐国结盟。** 郑国重新回到齐国主导的诸侯体系。[[5]](#note-5)

<a id="event-6"></a>

6. **闰月，周惠王去世，但王室担心太叔带再度作乱，没有立即发丧。** 太子郑先稳住王位，次年才正式公布丧讯。[[6]](#note-6)

<a id="event-7"></a>

7. **本年还有几条鲁国与曹、小邾的常规外交、丧礼记录：小邾子来朝；曹伯班去世，冬天安葬曹昭公；季友又前往齐国。** [[7]](#note-7)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公七年》**：“七年春，齐人伐郑。”  
   **《左传·僖公七年》**详记孔叔劝郑伯下齐。

<a id="note-2"></a>

2. **《春秋·僖公七年》**：“夏……郑杀其大夫申侯。”  
   **《左传·僖公七年》**：“郑杀申侯以说于齐。”

<a id="note-3"></a>

3. **《春秋·僖公七年》**：“秋七月，公会齐侯、宋公、陈世子款、郑世子华，盟于甯母。”

<a id="note-4"></a>

4. **《左传·僖公七年》**详记子华提议除三族、管仲反对及齐桓公拒绝。

<a id="note-5"></a>

5. **《左传·僖公七年》**：“冬，郑伯请盟于齐。”

<a id="note-6"></a>

6. **《左传·僖公七年》**：“闰月，惠王崩。襄王恶大叔带之难，惧不立，不发丧而告难于齐。”

<a id="note-7"></a>

7. **《春秋·僖公七年》**：“夏，小邾子来朝……曹伯班卒。公子友如齐。冬，葬曹昭公。”

# 公元前654年（鲁僖公六年）

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，晋国攻打夷吾所在的屈地，夷吾无法守住，转而逃往梁国。** 晋献公几位成年公子都已离开国都。 夷吾本想逃到狄，冀芮劝他避开重耳：晋若追讨，狄可能无法同时容纳兄弟；梁近秦，可借秦力谋返晋。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，齐桓公率鲁、宋、陈、卫、曹等诸侯伐郑，包围新密。** 这是对郑伯逃离首止盟会的惩罚。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋，楚国包围许国，以迫使齐国联盟放弃伐郑；诸侯转而救许，最终撤军。** 齐楚双方继续通过援助盟国间接竞争。 [[3]](#note-3)

<a id="event-4"></a>

4. **冬，许僖公亲自到楚国请罪，采取面缚衔璧、士舆榇的降服礼。** 楚王参照周武王处置微子的先例，解开束缚、接受玉璧并让许君复国。 [[4]](#note-4)

### 1. 春，晋国攻打夷吾所在的屈地，夷吾无法守住，转而逃往梁国

[返回正文第1条](#event-1)

**[《左传》本年传文](../../sources/春秋左传/有标点原文/bce-0654.md#batch-20261109-t001)**

> 六年春，晋侯使贾华伐屈，夷吾不能守，盟而行。将奔狄。郤芮曰：“后出同走，罪也。不如之梁。梁近秦而幸焉。”乃之梁。

[史料说明](#history-legacy-source-1)

<a id="sj039-cite-061"></a>

**[《史记·晋世家》P035](../../sources/摘录/史记-卷039-晋世家.md#p035)**

> 二十三年，獻公遂發賈華等伐屈，屈潰。夷吾將奔翟。冀芮曰：「不可，重耳已在矣，今往，晉必移兵伐翟，翟畏晉，禍且及。不如走梁，梁近於秦，秦彊，吾君百歲後可以求入焉。」遂奔梁。

## 归年与考证

<a id="history-legacy-source-1"></a>

<a id="history-legacy-source-2"></a>

2. **《春秋·僖公六年》**：“夏，公会齐侯、宋公、陈侯、卫侯、曹伯伐郑，围新城。”  
   **《左传·僖公六年》**：“以其逃首止之盟故也。围新密。”

# 公元前654年（鲁僖公六年）

[← 上一张已编年页：公元前655年](bce-0655.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前653年 →](bce-0653.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，晋国攻打夷吾所在的屈地，夷吾无法守住，转而逃往梁国。** 晋献公几位成年公子都已离开国都。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，齐桓公率鲁、宋、陈、卫、曹等诸侯伐郑，包围新密。** 这是对郑伯逃离首止盟会的惩罚。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋，楚国包围许国，以迫使齐国联盟放弃伐郑；诸侯转而救许，最终撤军。** 齐楚双方继续通过援助盟国间接竞争。 [[3]](#note-3)

<a id="event-4"></a>

4. **冬，许僖公亲自到楚国请罪，采取面缚衔璧、士舆榇的降服礼。** 楚王参照周武王处置微子的先例，解开束缚、接受玉璧并让许君复国。 [[4]](#note-4)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《左传·僖公六年》**：“晋侯使贾华伐屈，夷吾不能守……乃之梁。”

<a id="history-legacy-source-2"></a>


2. **《春秋·僖公六年》**：“夏，公会齐侯、宋公、陈侯、卫侯、曹伯伐郑，围新城。”  
   **《左传·僖公六年》**：“以其逃首止之盟故也。围新密。”

   **说明：** 经文作“新城”，传文作“新密”；正文只写围攻郑国要地，不据此强行校定地名。

<a id="history-legacy-source-3"></a>


3. **《春秋·僖公六年》**：“秋，楚人围许。诸侯遂救许。冬，公至自伐郑。”

<a id="history-legacy-source-4"></a>


4. **《左传·僖公六年》**详记许男面缚衔璧、舆榇见楚王，楚王依微子旧礼释之。

1. **春，晋国正式通告太子申生已死；重耳又遭晋献公派兵追杀，从蒲逃往狄地。** 晋国继承危机进一步扩大。 重耳越墙逃走，勃鞮追砍其衣袖；晋军另攻屈，一时未能攻下。重耳选择母族所在的狄地暂避，五名主要随从以外，还有数十人同行。 赵衰字子余，传说先占事献公及诸公子皆不吉，唯从重耳吉，遂相从。狄伐廧咎如得到两女子，少者配重耳，长者配赵衰，后生赵盾。 魏武子也率魏氏子弟随重耳出亡。 [[1]](#reading-note-1)

<a id="event-3"></a>

2. **齐率诸侯会王太子于首止，郑伯先归。** 夏，齐桓公召诸侯在首止会见周太子郑，欲稳定王室继承。周王私下拉拢郑伯，郑伯又有楚、晋、齐多方压力，未等盟誓便回郑。 [[2]](#reading-note-2)

<a id="event-4"></a>

<a id="reading-event-4"></a>

3. **楚国灭弦国，弦君逃往黄国。** 弦国依赖与齐亲近的江、黄等国而轻视楚国，最终亡国。 [[3]](#reading-note-4)

<a id="event-5"></a>

<a id="reading-event-5"></a>

4. **秋九月朔日发生日食。** 天象被单独记录。 [[4]](#reading-note-5)

<a id="reading-event-6"></a>

5. **晋再借虞道灭虢，回军灭虞。** 晋献公再向虞借道伐虢。宫之奇以辅车相依、唇亡齿寒相劝，又说晋曾残害自己的近族，虞国不可恃为同姓。虞君仍然放行，宫之奇带家族离开。冬，晋灭虢，虢公奔京师。晋回军突袭灭虞，俘虞君及大夫，仍保留虞国祭祀。荀息牵回先前送给虞君的良马，晋献公笑说马齿长了。随虞国被俘的百里奚被带往秦，后又逃至宛，被楚人拘留。秦穆公以寻回媵臣为名，用五张黑羊皮赎回，问政数日后任用他。百里奚举荐早年曾济助、屡次劝止他投身险境的老友蹇叔，穆公礼聘蹇叔为上大夫。 [[5]](#reading-note-6)

<a id="event-8"></a>

<a id="reading-event-9"></a>

6. **本年鲁国还有两条较小的宗族、外交记录：春天杞伯姬来鲁，带儿子朝见；夏天公孙兹前往牟国。** [[6]](#reading-note-9)

<a id="event-9"></a>

<a id="reading-event-10"></a>

7. **陈辕涛涂先帮助郑申侯修邑，随后又告发他图谋背郑。** 辕涛涂记恨申侯在召陵使自己获罪，便劝申侯把所得邑城修得漂亮，代为向诸侯请求。工程完成后，他转向郑伯告发，说申侯如此修城是准备叛变，申侯因此获罪。 [[7]](#reading-note-10)

<a id="event-10"></a>

<a id="reading-event-11"></a>

8. **秦穆公在秋季率军与晋交战于河曲。** 这场战争系穆公五年，与四十年后秦康公时期同名河曲之战不是一场战事。 [[8]](#reading-note-11)

### 5. 晋再借虞道灭虢，回军灭虞

[返回正文第5条](#reading-event-6)

<a id="hs021-l4893-e6"></a>

**[《汉书·律历志》P067](../../sources/摘录/汉书-卷021-律历志.md#p067)** · [仓内TXT L4893](../../sources/本地分卷/汉书/汉书-卷021.md#L4893)

> 冬十二月丙子滅虢。

**互校说明** 鲁僖公五年，古月干支按志保留。

**[《左传》鲁僖公5年传文（前655年）](../../sources/春秋左传/有标点原文/bce-0655.md#t008)**

> 晋侯复假道于虞以伐虢。宫之奇谏曰：“虢，虞之表也。虢亡，虞必从之。晋不可启，寇不可玩，一之谓甚，其可再乎？谚所谓‘辅车相依，唇亡齿寒’者，其虞、虢之谓也。”公曰：“晋，吾宗也。岂害我哉？”对曰：“大伯、虞仲，大王之昭也。大伯不从，是以不嗣。虢仲、虢叔，王季之穆也，为文王卿士，勋在王室，藏于盟府。将虢是灭，何爱于虞。且虞能亲于桓、庄乎，其爱之也？桓、庄之族何罪，而以为戮，不唯偪乎？亲以宠偪，犹尚害之，况以国乎？”公曰：“吾享祀丰絜，神必据我。”对曰：“臣闻之，鬼神非人实亲，惟德是依。故《周书》曰：‘皇天无亲，惟德是辅。’又曰：‘黍稷非馨，明德惟馨。’又曰：‘民不易物，惟德繄物。’如是，则非德民不和，神不享矣。神所冯依，将在德矣。若晋取虞而明德以荐馨香，神其吐之乎？”弗听，许晋使。宫之奇以其族行，曰：“虞不腊矣，在此行也，晋不更举矣。”

> 五年，晉獻公滅虞、虢，虜虞君與其大夫百里傒，以璧馬賂於虞故也。既虜百里傒，以為秦繆公夫人媵於秦。百里傒亡秦走宛，楚鄙人執之。繆公聞百里傒賢，欲重贖之，恐楚人不與，乃使人謂楚曰：「吾媵臣百里傒在焉，請以五羖羊皮贖之。」。楚人遂許與之。當是時，百里傒年已七十餘。繆公釋其囚，與語國事。謝曰：「臣亡國之臣，何足問！」繆公曰：「虞君不用子，故亡，非子罪也。」固問，語三日，繆公大說，授之國政，號曰五羖大夫。百里傒讓曰：「臣不及臣友蹇叔，蹇叔賢而世莫知。臣常游困於齊而乞食铚人，蹇叔收臣。臣因而欲事齊君無知，蹇叔止臣，臣得脫齊難，遂之周。周王子穨好牛，臣以養牛干之。及穨欲用臣，蹇叔止臣，臣去，得不誅。事虞君，蹇叔止臣。臣知虞君不用臣，臣誠私利祿爵，且留。再用其言，得脫，一不用，及虞君難：是以知其賢。」於是繆公使人厚幣迎蹇叔，以為上大夫。

#### 核对26｜陈辕涛涂先帮助郑申侯修邑，随后又告发他图谋背郑

**说明：**辕宣仲即本条辕涛涂；这是前653年申侯被杀之前的一段陷害过程，不提前写成已经处死。

<details>
<summary>传 T005｜原文</summary>

> 陈辕宣仲怨郑申侯之反己于召陵，故劝之城其赐邑，曰：“美城之，大名也，子孙不忘。吾助子请。”乃为之请于诸侯而城之，美。遂谮诸郑伯曰：“美城其赐邑，将以叛也。”申侯由是得罪。

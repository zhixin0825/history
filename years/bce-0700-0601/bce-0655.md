# 公元前655年（鲁僖公五年）

[← 上一张已编年页：公元前656年](bce-0656.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前654年 →](bce-0654.md)

<a id="event-1"></a>

1. **春，晋国正式通告太子申生已死；重耳又遭晋献公派兵追杀，从蒲逃往狄地。** 晋国继承危机进一步扩大。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，齐桓公在首止召集诸侯会见周王太子郑，目的是稳定王室继承。** 秋天诸侯继续在首止结盟。[[2]](#note-2)

<a id="event-3"></a>

3. **郑伯接受周王私下拉拢，担心同时得罪楚、晋与齐国，在盟誓前逃回郑国。** 这一举动使郑国很快遭到齐国联盟惩罚。[[3]](#note-3)

<a id="event-4"></a>

4. **楚国灭弦国，弦君逃往黄国。** 弦国依赖与齐亲近的江、黄等国而轻视楚国，最终亡国。[[4]](#note-4)

<a id="event-5"></a>

5. **秋九月朔日发生日食。** 天象被单独记录。[[5]](#note-5)

<a id="event-6"></a>

6. **晋献公再次向虞国借道伐虢，宫之奇以“辅车相依、唇亡齿寒”劝虞君拒绝，仍未被采纳。** 晋军冬天灭虢，虢公逃往京师。[[6]](#note-6)

<a id="event-7"></a>

7. **晋军回师时突然袭击虞国，虞国也被灭，虞君被俘。** 当年用重宝买来的“借道”最终变成晋国吞并虞、虢两国的工具。[[7]](#note-7)

<a id="event-8"></a>

8. **本年鲁国还有两条较小的宗族、外交记录：春天杞伯姬来鲁，带儿子朝见；夏天公孙兹前往牟国。** [[8]](#note-8)

<a id="event-9"></a>

9. **陈辕涛涂先帮助郑申侯修邑，随后又告发他图谋背郑。** 辕涛涂记恨申侯在召陵使自己获罪，便劝申侯把所得邑城修得漂亮，代为向诸侯请求。工程完成后，他转向郑伯告发，说申侯如此修城是准备叛变，申侯因此获罪。 [看原文与说明](#cq-source-26)

<a id="sj-031-L2948-02"></a>

#### 补充互见｜晋国灭虞，吴的世系叙述提到了另一支的结局

**时间：鲁僖公五年；由虞亡事件同步** · 事件

《吴太伯世家》在句卑一代附近提到晋献公灭虞，为伐虢开路。《左传》僖公五年记晋灭虢后回师灭虞。

### 核对26｜陈辕涛涂先帮助郑申侯修邑，随后又告发他图谋背郑

**说明：**辕宣仲即本条辕涛涂；这是前653年申侯被杀之前的一段陷害过程，不提前写成已经处死。

<details>
<summary>传 T005｜原文</summary>

> 陈辕宣仲怨郑申侯之反己于召陵，故劝之城其赐邑，曰：“美城之，大名也，子孙不忘。吾助子请。”乃为之请于诸侯而城之，美。遂谮诸郑伯曰：“美城其赐邑，将以叛也。”申侯由是得罪。

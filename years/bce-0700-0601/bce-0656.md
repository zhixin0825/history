# 公元前656年（鲁僖公四年）

[本年相关史料](#sources-start)

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **春，齐桓公率鲁、宋、陈、卫、郑、许、曹等诸侯先攻蔡国，蔡军崩溃，联军随即继续南下伐楚。** 这一行动既有蔡姬事件的私人背景，也标志齐楚争霸进入正面碰撞。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **楚国质问齐国为何越境南侵，管仲以周王室旧命、楚国不贡包茅以及周昭王南征未返等理由回应。** 联军继续推进，驻军陉地。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **楚王派屈完谈判，双方最后在召陵结盟。** 齐桓公展示诸侯联军兵力，屈完则强调楚国方城、汉水足以自守；双方没有决战而以妥协收场。八月，鲁僖公从伐楚行程返回鲁国。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **陈大夫辕涛涂因建议联军改走东方，被郑申侯反咬为误军，齐桓公将他拘押。** 秋天江、黄与诸侯攻陈，冬天联军再次侵陈，陈国最终求和，辕涛涂获释。 [[4]](#reading-note-4)

<a id="reading-event-5"></a>

5. **冬十二月，鲁公孙兹与齐、宋、卫、郑、许、曹诸军进攻陈国。** 陈国求和以后，辕涛涂被放回。这次进军发生在召陵谈判及此前诸侯报复之后，不只是笼统的同一次“侵陈”。 [[5]](#reading-note-5)

<a id="event-5"></a>

<a id="reading-event-6"></a>

6. **许穆公死在军中，按高规格安葬。** 诸侯死于王事，丧礼等级相应提高。 [[6]](#reading-note-6)

<a id="event-6"></a>

<a id="reading-event-7"></a>

7. **晋献公准备让骊姬之子奚齐继位，骊姬设计陷害太子申生。** 她把毒放进申生祭肉，伪造成太子弑父阴谋；申生不愿申辩牵连骊姬，也不愿逃亡受“弑父”污名，十二月在新城自缢。 [[7]](#reading-note-7)

<a id="event-7"></a>

<a id="reading-event-8"></a>

8. **骊姬继续诬陷重耳、夷吾也参与谋反，重耳逃蒲，夷吾逃屈。** 晋国继承危机全面爆发。 [[8]](#reading-note-8)

<a id="event-8"></a>

<a id="reading-event-9"></a>

9. **秦穆公迎娶晋献公之女，与晋国结为婚姻。** 所娶女子是晋太子申生的姐姐，后来韩原之战时将介入两国交涉。此时婚姻并不保证秦晋此后不会交战。 [[9]](#reading-note-9)

##### 补充互见｜齐军从攻蔡转而进兵楚国

**时间：鲁僖公四年** · 事件

齐桓公先攻蔡，管仲随后借机进兵楚国，以楚没有向周王室进贡包茅等事交涉。《管晏列传》把最初攻蔡同蔡姬的事情联系起来。

[《史记》卷62 管晏列传](../../sources/摘录/史记-条目原文.md#ref-sj-4595) · [《春秋》 鲁僖公4年](../../sources/摘录/史记-条目原文.md#ref-cq-5-4) · [《史记》卷32 齐太公世家](../../sources/摘录/史记-条目原文.md#ref-sj-3044-3045)

<details><summary>归年依据、同书互见与待核问题</summary>

</details>

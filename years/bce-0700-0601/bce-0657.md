# 公元前657年（鲁僖公三年）

[← 上一张已编年页：公元前658年](bce-0658.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前656年 →](bce-0656.md)

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **从上一年十月到这一年五月，鲁国长期少雨，六月才重新降雨。** 虽然持续数月，但没有发展成严重旱灾。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，徐国夺取舒地。** 徐国继续在淮泗一带扩张。 [[2]](#note-2)

<a id="event-3"></a>

<a id="event-4"></a>

3. **齐召诸侯商议伐楚，鲁遣季友赴齐盟誓。** 秋，齐桓公召宋、江、黄等国会于阳穀，筹划伐楚。冬，鲁遣季友往齐盟誓，加入这次行动。 [[3]](#note-3)

<a id="event-5"></a>

4. **楚国再次伐郑，郑伯一度考虑向楚求和。** 大夫孔叔反对，认为齐国正在积极帮助郑国，不能轻易背弃齐国。 [[4]](#note-5)

<a id="event-6"></a>

5. **齐桓公与蔡姬乘舟嬉戏时发生争执，把她送回蔡国；蔡国随后把她另嫁。** 这件私人冲突成为下一年齐国首先攻蔡的直接导火索。 [[5]](#note-6)

<a id="sj014-0657-yan"></a>

<a id="event-7"></a>

6. **燕襄公开始以元年纪事。** 燕庄公去世后，其子继位，是为燕襄公。本年为襄公元年。 [[6]](#note-7)

<!-- sj035-p011 -->

**[《史记·管蔡世家》P011](../../拆分史书/史记/卷035.md#p011)**

> 繆侯以其女弟為齊桓公夫人。十八年，齊桓公與蔡女戲船中，夫人蕩舟，桓公止之，不止，公怒，歸蔡女而不絕也。蔡侯怒，嫁其弟。

**说明：** 缪侯十八年按元年前674为前657；“弟”是女弟，即妹妹，不是齐桓公另娶蔡侯弟弟。次年的齐军攻蔡另见前656。

### 补充史料与异说

<a id="sj014-0657-yan-note"></a>
<a id="卷014燕栏燕襄公元年"></a>
#### 卷014燕栏｜燕襄公元年

[《十二诸侯年表》前657年燕栏](../../拆分史书/史记/卷014.md#y0657)明记「燕襄公元年」。[《燕召公世家》](../../拆分史书/史记/卷034.md#part-1-text)记燕庄公三十三年卒、子襄公立。此处只将继承链与新君纪年接入统一年页，不凭「元年」强定燕庄公卒日、即位月日，也不把此前齐救燕和讨山戎的旧事重造一次。

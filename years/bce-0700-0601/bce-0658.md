# 公元前658年（鲁僖公二年）

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，诸侯为卫国修筑楚丘，并把卫国重新安置在那里。** 卫国在前660年遭狄军攻破，至本年仍在齐桓公与诸侯帮助下恢复。 [[1]](#note-1)

<a id="event-2"></a>

2. **五月，鲁国安葬哀姜。** 她虽因内乱被齐国处死，最终仍以鲁国国君夫人身份归葬。 [[2]](#note-2)

<a id="event-3"></a>

3. **晋献公用屈地良马和垂棘玉璧贿赂虞君，借道虞国进攻虢国。** 虞国大夫宫之奇谏阻，虞君没有听从，反而表示愿意先攻虢国。 [[3]](#note-3)

<a id="event-4"></a>

4. **夏，虞、晋联军攻虢，先攻下下阳。** 晋国“假道伐虢”的战略正式开始。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋，齐桓公与宋、江、黄等国在贯地结盟。** 江、黄两国进一步加入齐国主导的联盟。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬，鲁国继续少雨；楚国再次进攻郑国，并俘获郑大夫聃伯。** 郑国继续承受来自楚国的压力。 [[6]](#note-6)

<a id="event-7"></a>

7. **齐国寺人貂在多鱼泄漏军情。** 原段很短，只记这一次泄密及地名，没有交代秘密泄给了谁，也没有列出一场由此造成的败战。 [[7]](#note-7)

<a id="event-8"></a>

8. **虢公在桑田击败戎人。** 晋国卜偃听说后，担心虢国在丢失下阳以后反因另一场胜利而轻忽晋军。这里只把战胜记为本年史事，不把卜偃所说的亡国期限当成本年已发生。 [[8]](#note-8)

<a id="sj034-zhuang-death-event"></a>

9. **燕庄公去世，儿子襄公继承。** 庄公在位三十三年，襄公的元年接在下一年。 [[9]](#sj034-zhuang-death-note)

### 本轮校订：叙事与原文的界限

本年是第一次假道攻虢：经传记宫之奇“谏，不听”，没有在这段展开“唇亡齿寒”的整篇论说。明确的相依、再假道与虞虢覆亡之论见[前655年原传](../../sources/春秋左传/有标点原文/bce-0655.md#zhuan)。不把两次借道当成同一场行动。

# 公元前658年（鲁僖公二年）

[← 上一张已编年页：公元前659年](bce-0659.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前657年 →](bce-0657.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，诸侯为卫国修筑楚丘，并把卫国重新安置在那里。** 卫国在前660年遭狄军攻破，至本年仍在齐桓公与诸侯帮助下恢复。 [[1]](#note-1)

<a id="event-2"></a>

2. **五月，鲁国安葬哀姜。** 她虽因内乱被齐国处死，最终仍以鲁国国君夫人身份归葬。 [[2]](#note-2)

<a id="event-3"></a>

3. **晋献公用屈地良马和垂棘玉璧贿赂虞君，借道虞国进攻虢国。** 虞国大夫宫之奇极力反对，认为虢亡之后虞必随之灭亡，虞君仍然答应。 [[3]](#note-3)

<a id="event-4"></a>

4. **夏，虞、晋联军攻虢，先攻下下阳。** 晋国“假道伐虢”的战略正式开始。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋，齐桓公与宋、江、黄等国在贯地结盟。** 江、黄两国进一步加入齐国主导的联盟。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬，鲁国继续少雨；楚国再次进攻郑国，并俘获郑大夫聃伯。** 郑国继续承受来自楚国的压力。 [[6]](#note-6)

<a id="event-7"></a>

7. **齐国寺人貂在多鱼泄漏军情。** 原段很短，只记这一次泄密及地名，没有交代秘密泄给了谁，也没有列出一场由此造成的败战。 [[7]](#note-7)

<a id="event-8"></a>

8. **虢公在桑田击败戎人。** 晋国卜偃听说后，担心虢国在丢失下阳以后反因另一场胜利而轻忽晋军。这里只把战胜记为本年史事，不把卜偃所说的亡国期限当成本年已发生。 [[8]](#note-8)

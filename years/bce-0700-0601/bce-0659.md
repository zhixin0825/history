# 公元前659年（鲁僖公元年）

[← 上一张已编年页：公元前660年](bce-0660.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前658年 →](bce-0658.md)

<a id="event-1"></a>

1. **春，鲁僖公即位，但鲁国刚经历连续弑君和出奔，政局仍在恢复。** 僖公此前随季友逃往邾国，回国后才取得君位。[[1]](#note-1)

<a id="event-2"></a>

2. **狄人继续进攻邢国，齐、宋、曹联军北上救援。** 邢人已经难以守城，诸侯军驱逐狄人，并帮助邢国迁往夷仪。[[2]](#note-2)

<a id="event-3"></a>

3. **夏六月，邢国正式迁到夷仪，齐、宋、曹为其筑城。** 齐桓公继续以“救患”方式维持中原诸侯秩序。[[3]](#note-3)

<a id="event-4"></a>

4. **秋，齐国处死哀姜，并把遗体送回鲁国。** 哀姜因参与庆父之乱被齐国追究；十二月，她的丧车抵达鲁国。[[4]](#note-4)

<a id="event-5"></a>

5. **楚国进攻郑国，因为郑国依附齐国。** 鲁、齐、宋、郑等国随后在柽地会合，商议救郑。[[5]](#note-5)

<a id="event-6"></a>

6. **九月，鲁僖公在偃地击败邾军。** 鲁、邾关系继续紧张。[[6]](#note-6)

<a id="event-7"></a>

7. **冬，季友率军在郦地击败莒军，俘虏莒君之弟挐。** 僖公把汶阳田和费地赐给季友，季氏势力由此进一步坐大。[[7]](#note-7)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公元年》**：“元年春，王正月。”  
   **《左传·僖公元年》**：“不称即位，公出故也。”

<a id="note-2"></a>

2. **《春秋·僖公元年》**：“齐师、宋师、曹师次于聂北，救邢。”  
   **《左传·僖公元年》**详记邢人溃出、诸侯逐狄。

<a id="note-3"></a>

3. **《春秋·僖公元年》**：“夏六月，邢迁于夷仪。齐师、宋师、曹师城邢。”

<a id="note-4"></a>

4. **《春秋·僖公元年》**：“秋七月戊辰，夫人姜氏薨于夷，齐人以归……十有二月丁巳，夫人氏之丧至自齐。”  
   **《左传·僖公元年》**说明齐人杀哀姜。

<a id="note-5"></a>

5. **《春秋·僖公元年》**：“楚人伐郑。八月，公会齐侯、宋公、郑伯、曹伯、邾人于柽。”  
   **《左传·僖公元年》**：“楚人伐郑，郑即齐故也。盟于荦，谋救郑也。”

   **说明：** 经文会地作“柽”，传文作“荦”；正文不强行统一会地点名。

<a id="note-6"></a>

6. **《春秋·僖公元年》**：“九月，公败邾师于偃。”

<a id="note-7"></a>

7. **《春秋·僖公元年》**：“冬十月壬午，公子友帅师败莒师于郦，获莒挐。”  
   **《左传·僖公元年》**：“公赐季友汶阳之田，及费。”

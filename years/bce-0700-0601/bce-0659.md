# 公元前659年（鲁僖公元年）

[← 上一张已编年页：公元前660年](bce-0660.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前658年 →](bce-0658.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁僖公即位，但鲁国刚经历连续弑君和出奔，政局仍在恢复。** 僖公此前随季友逃往邾国，回国后才取得君位。 [[1]](#note-1)

<a id="event-2"></a>

2. **狄人继续进攻邢国，齐、宋、曹联军北上救援。** 邢人已经难以守城，诸侯军驱逐狄人，并帮助邢国迁往夷仪。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏六月，邢国正式迁到夷仪，齐、宋、曹为其筑城。** 齐桓公继续以“救患”方式维持中原诸侯秩序。 [[3]](#note-3)

<a id="event-4"></a>

4. **秋，齐国处死哀姜，并把遗体送回鲁国。** 哀姜因参与庆父之乱被齐国追究；十二月，她的丧车抵达鲁国。 [[4]](#note-4)

<a id="event-5"></a>

5. **楚国进攻郑国，因为郑国依附齐国。** 鲁、齐、宋、郑等国随后在柽地会合，商议救郑。 [[5]](#note-5)

<a id="event-6"></a>

6. **九月，鲁僖公在偃地击败邾军。** 鲁、邾关系继续紧张。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬，季友率军在郦地击败莒军，俘虏莒君之弟挐。** 僖公把汶阳田和费地赐给季友，季氏势力由此进一步坐大。 [[7]](#note-7)

<a id="event-8"></a>

8. **秦穆公元年，出兵攻茅津。** 秦成公上年去世，任好继为秦穆公。本年起元，又率军攻茅津获胜。 [[8]](#note-8)

<a id="sj014-0659-wei"></a>

<a id="event-9"></a>

9. **卫文公燬开始以元年纪事。** 上年卫国遭狄人攻破，宋、齐等国出力援助，卫人先立戴公。戴公死后，弟弟燬继位。本年为卫文公元年。宋桓公夫人为卫文公之妹。 [[9]](#note-9)

### 补充史料与异说

<a id="sj014-0659-wei-note"></a>
<a id="卷014卫栏卫文公燬元年"></a>
#### 卷014卫栏｜卫文公燬元年

[《十二诸侯年表》前659年卫栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0659)明确列「卫文公燬元年，戴公弟也」；[《卫康叔世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-6b47a895f6d771)叙述卫戴公申立而在位不久卒、弟燬继立为文公。卫国失守和戴公受立已有[前660年正文](bce-0660.md#event-7)及[同年援卫立戴公](bce-0660.md#event-8)；卫文公元年与[前658年筑楚丘](bce-0658.md#event-1)应分年，不强定先后各事的具体月日。

<a id="sj005-052-note"></a>
<a id="sj005-052秦穆公亲率军队攻茅津取得胜利"></a>
#### sj005-052｜秦穆公亲率军队攻茅津，取得胜利。

[卷005 P018](../../sources/摘录/史记-卷005-秦本纪.md#p018)。 [《十二诸侯年表》前659年秦栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0659)明记「秦穆公任好元年」，[前660年](bce-0660.md#event-13)另记成公卒与穆公继立。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

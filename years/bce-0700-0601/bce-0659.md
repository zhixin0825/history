# 公元前659年（鲁僖公元年）

[← 上一张已编年页：公元前660年](bce-0660.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前658年 →](bce-0658.md)

<a id="event-1"></a>

1. **春，鲁僖公即位，但鲁国刚经历连续弑君和出奔，政局仍在恢复。** 僖公此前随季友逃往邾国，回国后才取得君位。[[1]](#note-1)

<a id="event-2"></a>

2. **狄人继续进攻邢国，齐、宋、曹联军北上救援。** 邢人已经难以守城，诸侯军驱逐狄人，并帮助邢国迁往夷仪。[[2]](#note-2)

<a id="event-3"></a>

3. **夏六月，邢国正式迁到夷仪，齐、宋、曹为其筑城。** 齐桓公继续以“救患”方式维持中原诸侯秩序。[[3]](#note-3)

<a id="event-4"></a>

4. **秋，齐国处死哀姜，并把遗体送回鲁国。** 哀姜因参与庆父之乱被齐国追究；十二月，她的丧车抵达鲁国。[[4]](#note-4)

<a id="event-5"></a>

5. **楚国进攻郑国，因为郑国依附齐国。** 鲁、齐、宋、郑等国随后在柽地会合，商议救郑。[[5]](#note-5)

<a id="event-6"></a>

6. **九月，鲁僖公在偃地击败邾军。** 鲁、邾关系继续紧张。[[6]](#note-6)

<a id="event-7"></a>

7. **冬，季友率军在郦地击败莒军，俘虏莒君之弟挐。** 僖公把汶阳田和费地赐给季友，季氏势力由此进一步坐大。[[7]](#note-7)

<a id="event-8"></a>

8. **秦穆公亲率军队攻茅津，取得胜利。** 穆公名任好。本纪从他亲自用兵写起，后面才展开对晋国婚姻、招揽人物与争霸的经历。 [原文与说明](#sj005-052-note)

<a id="sj014-0659-wei"></a>

9. **卫文公燬开始以元年纪事。** 前660年狄人攻破卫国后，卫人得到宋、齐等诸侯援助，先立戴公申；戴公在位很短，死后由弟弟燬继位，便是卫文公。本年《十二诸侯年表》记文公元年，并非狄人本年才攻破卫都，也不将[下一年诸侯城楚丘](bce-0658.md#event-1)提前。 [[9]](#sj014-0659-wei-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·僖公元年》**：“元年春，王正月。”  
   **《左传·僖公元年》**：“不称即位，公出故也。”

<a id="note-2"></a>

2. **《春秋·僖公元年》**：“齐师、宋师、曹师次于聂北，救邢。”  
   **《左传·僖公元年》**详记邢人溃出、诸侯逐狄。

<a id="note-3"></a>

3. **《春秋·僖公元年》**：“夏六月，邢迁于夷仪。齐师、宋师、曹师城邢。”

<a id="note-4"></a>

4. **《春秋·僖公元年》**：“秋七月戊辰，夫人姜氏薨于夷，齐人以归……十有二月丁巳，夫人氏之丧至自齐。”  
   **《左传·僖公元年》**说明齐人杀哀姜。

<a id="note-5"></a>

5. **《春秋·僖公元年》**：“楚人伐郑。八月，公会齐侯、宋公、郑伯、曹伯、邾人于柽。”  
   **《左传·僖公元年》**：“楚人伐郑，郑即齐故也。盟于荦，谋救郑也。”

   **说明：** 经文会地作“柽”，传文作“荦”；正文不强行统一会地点名。

<a id="note-6"></a>

6. **《春秋·僖公元年》**：“九月，公败邾师于偃。”

<a id="note-7"></a>

7. **《春秋·僖公元年》**：“冬十月壬午，公子友帅师败莒师于郦，获莒挐。”  
   **《左传·僖公元年》**：“公赐季友汶阳之田，及费。”

## 补充史料与异说

<a id="sj014-0659-wei-note"></a>
### 卷014卫栏｜卫文公燬元年

[《十二诸侯年表》前659年卫栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0659)明确列「卫文公燬元年，戴公弟也」；[《卫康叔世家》](https://zh.wikisource.org/wiki/史記/卷037)叙述卫戴公申立而在位不久卒、弟燬继立为文公。卫国失守和戴公受立已有[前660年正文](bce-0660.md#event-7)及[同年援卫立戴公](bce-0660.md#event-8)；卫文公元年与[前658年筑楚丘](bce-0658.md#event-1)应分年，不强定先后各事的具体月日。



<a id="sj005-052-note"></a>
### sj005-052｜秦穆公亲率军队攻茅津，取得胜利。

[卷005 P018](../../sources/摘录/史记-卷005-秦本纪.md#p018)。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

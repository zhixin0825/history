# 公元前660年（鲁闵公二年）

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **春，齐国迁移阳地居民。** 齐国继续整顿其控制区域。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **五月，鲁国过早为庄公举行吉禘。** 庄公丧期尚近，这次宗庙祭祀被认为举行得太快。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **秋八月，庆父利用闵公旧傅卜齮的私怨，指使卜齮在武闱杀死闵公。** 鲁国再次发生弑君；庄公死后不到两年，子般、闵公先后被庆父集团杀害。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **季友带着公子申逃往邾国；庆父逃莒后，季友回鲁，拥立申为鲁僖公。** 鲁国政治中心从庆父一派转向季友。 [[4]](#reading-note-4)

<a id="event-5"></a>

<a id="reading-event-5"></a>

5. **庆父逃往莒国，鲁国用财物向莒国索要；被送回途中，庆父自缢。** 鲁国连续内乱的核心人物由此退出政治舞台。 [[5]](#reading-note-5)

<a id="event-6"></a>

<a id="reading-event-6"></a>

6. **哀姜参与庆父之乱后逃往邾国。** 《左传》本段连叙她后来被齐人杀于夷、归尸及鲁国安葬；按经文分年，被杀和丧车归鲁接前659年，葬礼接前658年，不把后续都算在本年。闵公生母是哀姜之娣叔姜，《齐太公世家》称哀姜为母的说法另注。 [[6]](#reading-note-6)

<a id="event-7"></a>

<a id="reading-event-7"></a>

7. **冬十二月，狄人攻破卫国。** 卫懿公好鹤，国内军心涣散；卫军在荧泽大败，卫国都城失守，遗民连夜渡河逃亡。 [[7]](#reading-note-7)

<a id="event-8"></a>

<a id="reading-event-8"></a>

8. **宋桓公迎接卫国遗民，齐桓公又派兵车与物资帮助卫人立戴公于曹。** 卫国虽亡国破都，却在诸侯援助下迅速重建政权。 [[8]](#reading-note-8)

<a id="reading-event-9"></a>

9. **卫国复建以后，卫文公任内继续整顿民生和军政。** 传文接写文公穿用粗朴衣冠，注意农事、工商业和教导任用；即位之初兵车三十乘，到其在位末年增为三百乘。它补充卫国从败亡中恢复的过程，但不把整个任期的发展全记在这一年。 [[9]](#reading-note-9)

<a id="event-9"></a>

<a id="reading-event-10"></a>

10. **郑国故意让高克长期率军驻黄河边又不召回，最终军队自行溃散，高克逃往陈国。** 郑人后来以《清人》讽刺这段军政失序。 [[10]](#reading-note-10)

<a id="event-10"></a>

<a id="reading-event-11"></a>

11. **晋献公又派太子申生出兵东山皋落氏。** 大夫里克等认为太子不应长期独立统兵，申生身边多人都看出这次任命暗含疏远与废立风险，但申生仍选择服从出征。 [[11]](#reading-note-11)

<a id="event-11"></a>

<a id="reading-event-12"></a>

12. **冬，齐国高子来鲁结盟。** 鲁国连续发生君位变乱以后，齐使高子来到鲁国。经文另记这次结盟，不能只写齐国支持复位便省去具体使者与盟事。 [[12]](#reading-note-12)

<a id="event-12"></a>

<a id="reading-event-13"></a>

13. **春，虢军在渭汭击败犬戎，舟之侨随后离虢赴晋。** 舟之侨不把这次胜利看成可以放心的理由，担心虢国仍有后患，遂奔晋。战胜与大夫离国是本段前后的两项行动。 [[13]](#reading-note-13)

<a id="event-13"></a>

<a id="reading-event-14"></a>

14. **秦成公去世，穆公任好继位。** 成公在位四年，有七个儿子仍不立，转立弟弟。由德公三子宣、成、穆的连续继承，可见这不是父子世系简单向下。 [[14]](#reading-note-14)

### 11. 晋献公又派太子申生出兵东山皋落氏

[返回正文第11条](#reading-event-11)

**[《左传》鲁闵公2年传文（前660年）](../../sources/春秋左传/有标点原文/bce-0660.md#batch-20261109-t009)**

> 晋侯使大子申生伐东山皋落氏。里克谏曰：“大子奉冢祀社稷之粢盛，以朝夕视君膳者也，故曰冢子。君行则守，有守则从，从曰抚军，守曰监国，古之制也。夫帅师，专行谋，誓军旅，君与国政之所图也，非大子之事也。师在制命而已。禀命则不威，专命则不孝。故君之嗣適不可以帅师。君失其官，帅师不威，将焉用之？且臣闻皋落氏将战，君其舍之。”公曰：“寡人有子，未知其谁立焉。”不对而退。见大子，大子曰：“吾其废乎？”对曰：“告之以临民，教之以军旅，不共是惧，何故废乎？且子惧不孝，无惧弗得立，修己而不责人，则免于难。”

**[《左传》鲁闵公2年传文（前660年）](../../sources/春秋左传/有标点原文/bce-0660.md#batch-20261109-t010)**

> 大子帅师，公衣之偏衣，佩之金玦。狐突御戎，先友为右。梁馀子养御罕夷，先丹木为右。羊舌大夫为尉。先友曰：“衣身之偏，握兵之要。在此行也，子其勉之。偏躬无慝，兵要远灾，亲以无灾，又何患焉！”狐突叹曰：“时，事之征也。衣，身之章也。佩，衷之旗也。故敬其事则命以始，服其身则衣之纯，用其衷则佩之度。今命以时卒，閟其事也；衣之尨服，远其躬也，佩以金玦，弃其衷也。服以远之，时以閟之，尨凉冬杀，金寒玦离，胡可恃也？虽欲勉之，狄可尽乎？”梁馀子养曰：“帅师者受命于庙，受脤于社，有常服矣。不获而尨，命可知也。死而不孝，不如逃之。”罕夷曰：“尨奇无常，金玦不复，虽复何为？君有心矣。”先丹木曰：“是服也，狂夫阻之。曰‘尽敌而反’，敌可尽乎！虽尽敌，犹有内谗，不如违之。”狐突欲行。羊舌大夫曰：“不可。违命不孝，弃事不忠，虽知其寒，恶不可取，子其死之。”大子将战，狐突谏曰：“不可。昔辛伯谂周桓公云：‘内宠并后，外宠二政，嬖子配適，大都耦国，乱之本也。’周公弗从，故及于难。今乱本成矣，立可必乎？孝而安民，子其图之，与其危身以速罪也。”

### 本轮校订：叙事与原文的界限

《左传》“闵公，哀姜之娣叔姜之子也，故齐人立之”说的是先前的闵公，不是紧邻叙事中的僖公。本页修正旧注母系误配，僖公的继立依“共仲奔莒，乃入，立之”叙述；齐高子来盟仍单列本年冬季，不把两件事合成同一条因果。见[本年传文](../../sources/春秋左传/有标点原文/bce-0660.md#batch-20261109-t004)与[冬季经文](../../sources/春秋左传/有标点原文/bce-0660.md#batch-20261109-j006)。

## 本年概述

庆父杀鲁闵公后出奔，季友回鲁拥立僖公。狄人在荧泽击败卫军，宋、齐接应卫国遗民，卫人在曹重建国政。

2. **庆父弑鲁闵公，季友立僖公，齐使来盟。** 八月，庆父借闵公旧傅卜齮的私怨，使他在武闱杀死闵公。季友带公子申奔邾，庆父逃莒，季友返回拥立申，即鲁僖公。鲁以财物向莒索要庆父，庆父在遣返途中自缢。参与此乱的哀姜奔邾。冬，齐大夫高子来鲁结盟。 [[2]](#reading-note-3)

3. **狄破卫国，宋齐救援遗民，卫人暂立于曹。** 卫懿公好鹤，军心涣散。十二月，狄人在荧泽击败卫军，进入卫都，遗民连夜渡河。宋桓公接应卫民，齐桓公派兵车和物资来援，卫人在曹拥立戴公。戴公同年去世，弟弟燬继位，次年为卫文公元年。文公衣用质朴，重农、工商业与教导人才，车兵由初年的三十乘渐增至在位末年的三百乘。 [[3]](#reading-note-7)

4. **春，齐国迁移阳地居民。** 齐国继续整顿其控制区域。 [[4]](#reading-note-1)

## 郑晋虢秦纪事

<a id="event-9"></a>

<a id="reading-event-10"></a>

5. **郑国故意让高克长期率军驻黄河边又不召回，最终军队自行溃散，高克逃往陈国。** 郑人后来以《清人》讽刺这段军政失序。 [[5]](#reading-note-10)

<a id="event-10"></a>

<a id="reading-event-11"></a>

6. **晋献公又派太子申生出兵东山皋落氏。** 里克认为太子平日奉宗庙、侍父君，领军却要专断，若听命太多就无威、专断又易被指不孝。献公答称尚未决定继承人；里克转劝申生尽职，自己则称病不从军。申生身边多人把赐衣、金玦及这次任命看作疏远与废立的危险信号，他仍选择服从出征。 [[6]](#reading-note-11)

<a id="event-12"></a>

<a id="reading-event-13"></a>

7. **春，虢军在渭汭击败犬戎，舟之侨随后离虢赴晋。** 舟之侨不把这次胜利看成可以放心的理由，担心虢国仍有后患，遂奔晋。战胜与大夫离国是本段前后的两项行动。 [[7]](#reading-note-13)

<a id="event-13"></a>

<a id="reading-event-14"></a>

8. **秦成公去世，穆公任好继位。** 成公在位四年，有七个儿子仍不立，转立弟弟。由德公三子宣、成、穆的连续继承，可见这不是父子世系简单向下。 [[8]](#reading-note-14)

### 6. 晋献公又派太子申生出兵东山皋落氏

[返回正文第6条](#reading-event-11)

**[《左传》鲁闵公2年传文（前660年）](../../sources/春秋左传/有标点原文/bce-0660.md#batch-20261109-t009)**

> 晋侯使大子申生伐东山皋落氏。里克谏曰：“大子奉冢祀社稷之粢盛，以朝夕视君膳者也，故曰冢子。君行则守，有守则从，从曰抚军，守曰监国，古之制也。夫帅师，专行谋，誓军旅，君与国政之所图也，非大子之事也。师在制命而已。禀命则不威，专命则不孝。故君之嗣適不可以帅师。君失其官，帅师不威，将焉用之？且臣闻皋落氏将战，君其舍之。”公曰：“寡人有子，未知其谁立焉。”不对而退。见大子，大子曰：“吾其废乎？”对曰：“告之以临民，教之以军旅，不共是惧，何故废乎？且子惧不孝，无惧弗得立，修己而不责人，则免于难。”

**[《左传》鲁闵公2年传文（前660年）](../../sources/春秋左传/有标点原文/bce-0660.md#batch-20261109-t010)**

> 大子帅师，公衣之偏衣，佩之金玦。狐突御戎，先友为右。梁馀子养御罕夷，先丹木为右。羊舌大夫为尉。先友曰：“衣身之偏，握兵之要。在此行也，子其勉之。偏躬无慝，兵要远灾，亲以无灾，又何患焉！”狐突叹曰：“时，事之征也。衣，身之章也。佩，衷之旗也。故敬其事则命以始，服其身则衣之纯，用其衷则佩之度。今命以时卒，閟其事也；衣之尨服，远其躬也，佩以金玦，弃其衷也。服以远之，时以閟之，尨凉冬杀，金寒玦离，胡可恃也？虽欲勉之，狄可尽乎？”梁馀子养曰：“帅师者受命于庙，受脤于社，有常服矣。不获而尨，命可知也。死而不孝，不如逃之。”罕夷曰：“尨奇无常，金玦不复，虽复何为？君有心矣。”先丹木曰：“是服也，狂夫阻之。曰‘尽敌而反’，敌可尽乎！虽尽敌，犹有内谗，不如违之。”狐突欲行。羊舌大夫曰：“不可。违命不孝，弃事不忠，虽知其寒，恶不可取，子其死之。”大子将战，狐突谏曰：“不可。昔辛伯谂周桓公云：‘内宠并后，外宠二政，嬖子配適，大都耦国，乱之本也。’周公弗从，故及于难。今乱本成矣，立可必乎？孝而安民，子其图之，与其危身以速罪也。”

### 本轮校订：叙事与原文的界限

《左传》“闵公，哀姜之娣叔姜之子也，故齐人立之”说的是先前的闵公，不是紧邻叙事中的僖公。本页修正旧注母系误配，僖公的继立依“共仲奔莒，乃入，立之”叙述；齐高子来盟仍单列本年冬季，不把两件事合成同一条因果。见[本年传文](../../sources/春秋左传/有标点原文/bce-0660.md#batch-20261109-t004)与[冬季经文](../../sources/春秋左传/有标点原文/bce-0660.md#batch-20261109-j006)。

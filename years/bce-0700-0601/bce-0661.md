# 公元前661年（鲁闵公元年）

[← 上一张已编年页：公元前662年](bce-0662.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前660年 →](bce-0660.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁闵公在庆父拥立下即位，但鲁国内乱仍未结束。** 子般刚被杀，季友逃往陈国，庆父仍掌握很大权力，因此闵公的君位从一开始就很不稳固。 [[1]](#note-1)

<a id="event-2"></a>

2. **狄人进攻邢国，齐桓公采纳管仲意见出兵救邢。** 管仲主张中原诸侯不能放弃彼此援助，齐国由此继续以霸主身份干预北方局势。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏六月，鲁国安葬庄公。** 因此前连续发生继承危机和弑君，庄公的葬礼拖延到这一年才完成。 [[3]](#note-3)

<a id="event-4"></a>

4. **秋八月，闵公与齐桓公在落姑结盟，请求让季友回鲁。** 齐桓公同意，并派人从陈国召季友；闵公亲自在郎地等待，季友随后回国。 [[4]](#note-4)

<a id="event-5"></a>

5. **冬，齐国大夫仲孙湫来鲁考察内乱。** 他判断只要庆父还在，鲁国祸乱就不会停止；但鲁国仍保存周礼根本，齐国不宜趁乱吞并，而应帮助稳定鲁国、结好有礼诸侯。 [[5]](#note-5)

<a id="event-6"></a>

6. **晋献公建立上、下两军，自将上军，让太子申生统领下军，并灭耿、霍、魏。** 战后赵夙受封耿，毕万受封魏；晋国扩张同时也让太子申生越来越深地卷入军事事务。 [[6]](#note-6)

<a id="event-7"></a>

7. **士蒍已预见申生继承地位危险。** 太子被分派外地、又以卿位领军，在晋国君权结构中反而像被逐步推离国都；这种安排为后来的骊姬之乱埋下伏笔。 [[7]](#note-7)

<a id="sj014-0661-cao"></a>

<a id="event-8"></a>

8. **曹国进入昭公班的元年。** 曹釐公夷在位九年后去世，儿子班继位成为曹昭公。《十二诸侯年表》把昭公元年列在本年；这记的是新君纪年的开始，不应把其父去世的确切月份据此推定。 [[8]](#note-8)

#### 卷014曹栏｜曹昭公班元年

[《十二诸侯年表》前661年曹栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0661)列曹昭公元年；[《管蔡世家》曹釐公、昭公段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7035.md#ref-2200be703d66f4)记“釐公九年卒，子昭公班立”。[前670年](bce-0670.md#sj014-0670-cao)已有釐公夷元年及曹国君位争议说明。本页只补继承链与昭公元年，不额外编造宫变经过或卒、葬月日。

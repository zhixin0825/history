# 公元前661年（鲁闵公元年）

[← 上一张已编年页：公元前662年](bce-0662.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前660年 →](bce-0660.md)

<a id="event-1"></a>

1. **春，鲁闵公在庆父拥立下即位，但鲁国内乱仍未结束。** 子般刚被杀，季友逃往陈国，庆父仍掌握很大权力，因此闵公的君位从一开始就很不稳固。[1]

<a id="event-2"></a>

2. **狄人进攻邢国，齐桓公采纳管仲意见出兵救邢。** 管仲主张中原诸侯不能放弃彼此援助，齐国由此继续以霸主身份干预北方局势。[2]

<a id="event-3"></a>

3. **夏六月，鲁国安葬庄公。** 因此前连续发生继承危机和弑君，庄公的葬礼拖延到这一年才完成。[3]

<a id="event-4"></a>

4. **秋八月，闵公与齐桓公在落姑结盟，请求让季友回鲁。** 齐桓公同意，并派人从陈国召季友；闵公亲自在郎地等待，季友随后回国。[4]

<a id="event-5"></a>

5. **冬，齐国大夫仲孙湫来鲁考察内乱。** 他判断只要庆父还在，鲁国祸乱就不会停止；但鲁国仍保存周礼根本，齐国不宜趁乱吞并，而应帮助稳定鲁国、结好有礼诸侯。[5]

<a id="event-6"></a>

6. **晋献公建立上、下两军，自将上军，让太子申生统领下军，并灭耿、霍、魏。** 战后赵夙受封耿，毕万受封魏；晋国扩张同时也让太子申生越来越深地卷入军事事务。[6]

<a id="event-7"></a>

7. **士蒍已预见申生继承地位危险。** 太子被分派外地、又以卿位领军，在晋国君权结构中反而像被逐步推离国都；这种安排为后来的骊姬之乱埋下伏笔。[7]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·闵公元年》**：“元年春，王正月。”  
   **《左传·闵公元年》**：“不书即位，乱故也。”

<a id="note-2"></a>

2. **《春秋·闵公元年》**：“齐人救邢。”  
   **《左传·闵公元年》**详记管仲劝齐桓公救邢：“戎狄豺狼，不可厌也。诸夏亲暱，不可弃也。”

<a id="note-3"></a>

3. **《春秋·闵公元年》**：“夏六月辛酉，葬我君庄公。”  
   **《左传·闵公元年》**：“乱故，是以缓。”

<a id="note-4"></a>

4. **《春秋·闵公元年》**：“秋八月，公及齐侯盟于落姑。季子来归。”  
   **《左传·闵公元年》**详记闵公请复季友、齐侯召诸陈、闵公次郎而待。

<a id="note-5"></a>

5. **《春秋·闵公元年》**：“冬，齐仲孙来。”  
   **《左传·闵公元年》**详记仲孙湫“来省难”，并判断“不去庆父，鲁难未已”“鲁不弃周礼，未可动也”。

<a id="note-6"></a>

6. **《左传·闵公元年》**详记晋献公作二军、灭耿霍魏、赐赵夙耿、毕万魏。

<a id="note-7"></a>

7. **《左传·闵公元年》**载士蒍判断太子申生“不得立”，并劝其早图自保。

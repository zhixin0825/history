1. **鲁闵公即位后请齐助召季友，齐使察看鲁政。** 春，鲁闵公在庆父拥戴下即位，国内仍乱。六月，鲁国安葬庄公。八月，闵公与齐桓公盟于落姑，请召季友回国。冬，齐派仲孙湫来鲁察看政局。 [[1]](#note-1)

<a id="event-2"></a>

2. **狄人进攻邢国，齐桓公采纳管仲意见出兵救邢。** 管仲主张中原诸侯不能放弃彼此援助，齐国由此继续以霸主身份干预北方局势。 [[2]](#note-2)

<a id="event-6"></a>

<a id="event-7"></a>

3. **晋设二军灭耿霍魏，士蒍忧太子申生。** 晋献公设二军，出兵灭耿、霍、魏。士蒍从献公的安排中预见太子申生的继承地位受到威胁。 [[3]](#note-6)

<a id="sj014-0661-cao"></a>

<a id="event-8"></a>

4. **曹国进入昭公班的元年。** 班承[上年去世的曹釐公](bce-0662.md#sj035-cao-xi-death-event)继位，是为曹昭公。本年为昭公元年。 [[4]](#note-8)

### 3. 晋设二军灭耿霍魏，士蒍忧太子申生

[返回正文第3条](#event-6)

**霍祀与家世** 《赵世家》另叙霍君逃齐后晋旱，卜者归咎霍太山失祀，赵夙迎霍君续祀，随后年谷恢复。毕万家世上溯毕公高，失封后族人散居中原、戎狄，毕万后来入晋。

**[《左传》鲁闵公1年传文（前661年）](../../sources/春秋左传/有标点原文/bce-0661.md#batch-20261109-t006)**

> 晋侯作二军，公将上军，大子申生将下军。赵夙御戎，毕万为右，以灭耿、灭霍、灭魏。还，为大子城曲沃。赐赵夙耿，赐毕万魏，以为大夫。士蒍曰：“大子不得立矣，分之都城而位以卿，先为之极，又焉得立。不如逃之，无使罪至。为吴大伯，不亦可乎？犹有令名，与其及也。且谚曰：‘心苟无瑕，何恤乎无家。’天若祚大子，其无晋乎？”

**[卷005 P011](../../sources/摘录/史记-卷005-秦本纪.md#p011)**

> 十三年，齊人管至父、連稱等殺其君襄公而立公孫無知。晉滅霍、魏、耿。齊雍廩殺無知、管至父等而立齊桓公。齊、晉為彊國。

**本卷说明：** **世系辨异：** 本篇说赵夙在鲁闵公元年生共孟，共孟再生赵衰，赵衰字子余。古注指出，这与《世本》及《左传》所记辈分不同，而且鲁闵公元年已是前661年，不能把此句不加辨别地当作赵衰出生链。保留原文，在赵衰登场处说明父祖异系，不补一个确定出生年。 [三家注p5](../../sources/史记三家注/卷043.md#p5)。

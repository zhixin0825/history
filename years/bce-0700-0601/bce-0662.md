# 公元前662年（鲁庄公三十二年）

[← 上一张已编年页：公元前663年](bce-0663.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前661年 →](bce-0661.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁国修筑小穀，供管仲使用。** 管仲此时已是齐桓公核心执政者，鲁国在境内为其经营据点。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，宋公与齐桓公在梁丘相遇。** 齐桓公因为楚国伐郑，准备召集诸侯，宋公先请求与他见面。 [[2]](#note-2)

<a id="event-3"></a>

3. **庄公晚年面临继承问题。** 他与孟任生子般；孟任原是党氏女子，庄公曾割臂与她盟誓，许以夫人名分。 [[3]](#note-3)

<a id="event-4"></a>

4. **庄公病重后先问叔牙谁适合继位，叔牙推荐庆父；再问季友，季友明确表示愿以死拥立子般。** 庄公把叔牙支持庆父的事情告诉季友，季友于是以君命逼叔牙饮毒酒，叔牙死后形成叔孙氏。 [[4]](#note-4)

<a id="event-5"></a>

5. **八月癸亥，鲁庄公死于路寝，子般继位。** 子般暂住党氏家中，季友成为其主要支持者。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬十月，庆父指使圉人荦在党氏杀死子般。** 荦正是庄公过去见其力大、曾说“不如杀之”的那个人；后来他成为弑君工具。 [[6]](#note-6)

<a id="event-7"></a>

7. **子般死后，季友逃往陈国，庆父拥立闵公。** 鲁国由继承争执迅速进入连续弑君的政治危机。 [[7]](#note-7)

<a id="event-8"></a>

8. **同年，狄人进攻邢国。** 北方诸侯也开始面对狄人压力。 [[8]](#note-8)

<a id="sj035-cao-xi-death-event"></a>

9. **曹釐公去世，儿子班承继。** 釐公夷在位九年后去世，儿子班接掌曹国，称昭公；下一年开始昭公元年。 [[9]](#sj035-cao-xi-death-note)

### 3. 庄公晚年面临继承问题

[返回正文第3条](#event-3)

<a id="sj033-cite-049"></a>

**[《史记·鲁周公世家》P039](../../sources/摘录/史记-卷033-鲁周公世家.md#p039)**

> 初，莊公筑臺臨黨氏，見孟女，說而愛之，許立為夫人，割臂以盟。孟女生子斑。斑長，說梁氏女，往觀。圉人犖自墻外與梁氏女戲。斑怒，鞭犖。莊公聞之，曰：「犖有力焉，遂殺之，是未可鞭而置也。」斑未得殺。

此为子斑身世及圉人荦积怨的前情，不全系于庄公去世当年。 [全卷考证](../../meta/考证/史记-卷033-纪年与异说.md)。

**[《左传》鲁庄公32年传文（前662年）](../../sources/春秋左传/有标点原文/bce-0662.md#batch-20261109-t006)**

> 初，公筑台临党氏，见孟任，从之。閟，而以夫人言许之。割臂盟公，生子般焉。雩，讲于梁氏，女公子观之。圉人荦自墙外与之戏。子般怒，使鞭之。公曰：“不如杀之，是不可鞭。荦有力焉，能投盖于稷门。”

### 4. 庄公病重后先问叔牙谁适合继位，叔牙推荐庆父；再问季友，季友明确表示愿以死拥立子般

[返回正文第4条](#event-4)

<a id="sj033-cite-050"></a>

**[《史记·鲁周公世家》P039](../../sources/摘录/史记-卷033-鲁周公世家.md#p039)**

> 會莊公有疾。莊公有三弟，長曰慶父，次曰叔牙，次曰季友。莊公取齊女為夫人曰哀姜。哀姜無子。哀姜娣曰叔姜，生子開。莊公無適嗣，愛孟女，欲立其子斑。莊公病，而問嗣於弟叔牙。叔牙曰：「一繼一及，魯之常也。慶父在，可為嗣，君何憂？」莊公患叔牙欲立慶父，退而問季友。季友曰：「請以死立斑也。」莊公曰：「曩者叔牙欲立慶父，柰何？」季友以莊公命命牙待於鍼巫氏，使鍼季劫飲叔牙以鴆，曰：「飲此則有後奉祀；不然，死且無後。」牙遂飲鴆而死，魯立其子為叔孫氏。

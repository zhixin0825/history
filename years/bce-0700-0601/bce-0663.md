# 公元前663年（鲁庄公三十一年）

[← 上一张已编年页：公元前664年](bce-0664.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前662年 →](bce-0662.md)

<a id="event-1"></a>

1. **春，鲁庄公在郎地筑台；夏又在薛地筑台，秋再在秦地筑台。** 一年内连续修筑高台，显示庄公后期土木活动频繁。[1]

<a id="event-2"></a>

2. **夏四月，薛伯去世。** 薛国发生君主更替。[2]

<a id="event-3"></a>

3. **六月，齐桓公来鲁献上讨伐山戎的战利品。** 这种四夷战功按礼本应献给周王，而不是诸侯互相赠送，因此受到批评。[3]

<a id="event-4"></a>

4. **冬，鲁国长期不雨。** 干旱进入年表记录。[4]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公三十一年》**：“三十有一年春，筑台于郎……筑台于薛……秋，筑台于秦。”

<a id="note-2"></a>

2. **《春秋·庄公三十一年》**：“夏四月，薛伯卒。”

<a id="note-3"></a>

3. **《春秋·庄公三十一年》**：“六月，齐侯来献戎捷。”  
   **《左传·庄公三十一年》**说明四夷之功应献于王，“诸侯不相遗俘”。

<a id="note-4"></a>

4. **《春秋·庄公三十一年》**：“冬，不雨。”

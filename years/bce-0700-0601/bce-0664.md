# 公元前664年（鲁庄公三十年）

[← 上一张已编年页：公元前665年](bce-0665.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前663年 →](bce-0663.md)

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，周王命虢公讨伐叛臣樊皮；四月，虢军攻入樊地，把樊仲皮押回京师。** 王室成功平息这次地方叛乱。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚令尹子元长期居住王宫，引发大臣反对；秋，申公鬥班杀死子元，鬥穀於菟继任令尹。** 新令尹主动毁家纾难，楚国内部权力重新稳定。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，鲁军驻扎成地。** 现存本年记载没有交代这次驻军最终发生战斗。 [[3]](#note-3)

<a id="event-4"></a>

4. **秋，齐国迫使鄣地投降。** 齐国继续扩大控制范围。 [[4]](#note-4)

<a id="event-5"></a>

5. **八月，鲁国安葬纪叔姬；九月朔日又发生日食，鲁国击鼓并在社坛用牲。** 灾异礼仪仍沿用此前受到批评的做法。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬，鲁庄公与齐桓公在鲁济会面，商议讨伐山戎，因为山戎长期侵扰燕国。** 齐国准备把霸主军事行动推向北方。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬，齐国出兵救燕、讨伐山戎。** 山戎侵扰燕国，齐桓公北上救援。回师时，燕庄公送行越过国境，齐桓公把燕君送到的那段土地划给燕国，并要求燕恢复对周天子的贡职、修行召公的法度。战后的献捷另接下一年。 [[7]](#note-7)

<a id="event-8"></a>

8. **秦宣公去世，弟弟成公继位。** 宣公在位十二年，虽有九个儿子，却没有立其中一人，君位继续在兄弟间转移。 [[8]](#note-8)

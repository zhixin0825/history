# 公元前665年（鲁庄公二十九年）

[← 上一张已编年页：公元前666年](bce-0666.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前664年 →](bce-0664.md)

<a id="event-1"></a>

1. **春，鲁国新建延厩。** 工程被认为不合季节，因为马厩使用有固定出入时令。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，郑国侵入许国。** 这次军事行动没有鸣钟击鼓，因此记为“侵”而不是正式“伐”。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，鲁国出现蜚虫并造成灾害。** 与隐公元年未成灾的蜚虫不同，这一次实际造成影响，因此被记录。[[3]](#note-3)

<a id="event-4"></a>

4. **冬十二月，纪叔姬去世。** 纪国旧宗族最后的相关人物继续出现在鲁国年表。[[4]](#note-4)

<a id="event-5"></a>

5. **冬，鲁国修筑诸、防两地。** 工程发生在适宜的农闲时节。[[5]](#note-5)

<a id="event-6"></a>

6. **周王室大夫樊皮叛乱。** 王室下一年将派虢公讨伐。[[6]](#note-6)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公二十九年》**：“二十有九年春，新延厩。”  
   **《左传·庄公二十九年》**：“书不时也。”

<a id="note-2"></a>

2. **《春秋·庄公二十九年》**：“夏，郑人侵许。”  
   **《左传·庄公二十九年》**解释“有钟鼓曰伐，无曰侵”。

<a id="note-3"></a>

3. **《春秋·庄公二十九年》**：“秋，有蜚。”  
   **《左传·庄公二十九年》**：“为灾也。”

<a id="note-4"></a>

4. **《春秋·庄公二十九年》**：“冬十有二月，纪叔姬卒。”

<a id="note-5"></a>

5. **《春秋·庄公二十九年》**：“城诸及防。”  
   **《左传·庄公二十九年》**：“书时也。”

<a id="note-6"></a>

6. **《左传·庄公二十九年》**：“樊皮叛王。”

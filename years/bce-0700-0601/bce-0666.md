# 公元前666年（鲁庄公二十八年）

[← 上一张已编年页：公元前667年](bce-0667.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前665年 →](bce-0665.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，齐桓公奉周王命伐卫，在战场击败卫军，责其曾参与王子颓之乱，取得赂物后撤军。** 齐国以王命执行惩罚，霸权与王室名义进一步结合。 [[1]](#note-1)

<a id="event-2"></a>

2. **晋献公把太子申生安置曲沃，把重耳、夷吾分别安置蒲、屈，其他公子则被排挤到边地。** 表面上是让几位公子守要地，实际上骊姬及宠臣正推动把他们逐出国都，为奚齐继位制造条件。 [[2]](#note-2)

<a id="event-3"></a>

3. **楚令尹子元想取悦楚文王夫人，在她宫侧大建馆舍并奏武舞；夫人反而责怪他不去报国仇。** 子元受刺激后决定出兵郑国。 [[3]](#note-3)

<a id="event-4"></a>

4. **秋，楚军六百乘进攻郑国，一度进入郑都街市。** 郑国城门保持严密，楚军察觉郑国仍有准备，夜间撤退；前来救郑的诸侯没有与楚军正面决战。 [[4]](#note-4)

<a id="event-5"></a>

5. **冬，鲁国修筑郿地。** 这是普通邑的筑城工程。 [[5]](#note-5)

<a id="event-6"></a>

6. **鲁国严重缺粮，没有麦和禾，臧孙辰前往齐国购买粮食。** 齐国成为鲁国灾荒时的重要粮源。 [[6]](#note-6)

<a id="event-7"></a>

7. **夏四月丁未，邾子琐去世。** 这是邾国国君的死亡记录，与同年齐、卫及楚、郑战事分列。 [[7]](#note-7)

3. **《左传·庄公二十八年》**详记子元为馆、振《万》，文夫人责其忘仇。

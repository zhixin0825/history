# 公元前666年（鲁庄公二十八年）

[← 上一张已编年页：公元前667年](bce-0667.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前665年 →](bce-0665.md)

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，齐桓公奉周王命伐卫，在战场击败卫军，责其曾参与王子颓之乱，取得赂物后撤军。** 齐国以王命执行惩罚，霸权与王室名义进一步结合。 [[1]](#note-1)

<a id="event-2"></a>

2. **晋献公把太子申生安置曲沃，把重耳、夷吾分别安置蒲、屈，其他公子则被排挤到边地。** 表面上是让几位公子守要地，实际上骊姬及宠臣正推动把他们逐出国都，为奚齐继位制造条件。 献公以曲沃有先祖宗庙、蒲邻秦、屈邻狄为理由派诸子外居，自己留在绛与骊姬母子相处。申生之母为齐姜；重耳、夷吾的母族与戎狄女子有关。在这以前，重耳已经成年，以好士著称；赵衰、舅父狐偃、贾佗、先轸、魏武子等与他相从。被遣居蒲，是他从宫中公子转为边地守将的一步。 [[2]](#note-2)

<a id="event-3"></a>

<a id="event-4"></a>

3. **楚令尹子元受斥，随后率军伐郑。** 楚令尹子元在楚文王夫人的宫旁建馆舍、奏武舞，试图取悦她。夫人指责他不去报国仇。秋，子元率六百乘进攻郑国，一度进入郑都街市。 [[3]](#note-3)

<a id="event-5"></a>

4. **冬，鲁国修筑郿地。** 这是普通邑的筑城工程。 [[4]](#note-5)

<a id="event-6"></a>

5. **鲁国严重缺粮，没有麦和禾，臧孙辰前往齐国购买粮食。** 齐国成为鲁国灾荒时的重要粮源。 [[5]](#note-6)

<a id="event-7"></a>

6. **夏四月丁未，邾子琐去世。** 这是邾国国君的死亡记录，与同年齐、卫及楚、郑战事分列。 [[6]](#note-7)

<a id="hs-event-8"></a>

7. **鲁冬大水。** [[7]](#hs-note-8)

### 2. 晋献公把太子申生安置曲沃，把重耳、夷吾分别安置蒲、屈，其他公子则被排挤到边地

[返回正文第2条](#event-2)

**[《左传》鲁庄公28年传文（前666年）](../../sources/春秋左传/有标点原文/bce-0666.md#batch-20261109-t003)**

> 骊姬嬖，欲立其子，赂外嬖梁五与东关嬖五，使言于公曰：“曲沃，君之宗也。蒲与二屈，君之疆也。不可以无主。宗邑无主则民不威，疆埸无主则启戎心。戎之生心，民慢其政，国之患也。若使大子主曲沃，而重耳、夷吾主蒲与屈，则可以威民而惧戎，且旌君伐。”使俱曰：“狄之广莫，于晋为都。晋之启土，不亦宜乎？”晋侯说之。夏，使大子居曲沃，重耳居蒲城，夷吾居屈。群公子皆鄙，唯二姬之子在绛。二五卒与骊姬谮群公子而立奚齐，晋人谓之“二五耦”。

[史料说明](#history-legacy-source-2)

<a id="sj039-cite-049"></a>

**[《史记·晋世家》P026](../../sources/摘录/史记-卷039-晋世家.md#p026)**

> 十二年，驪姬生奚齊。獻公有意廢太子，乃曰：「曲沃吾先祖宗廟所在，而蒲邊秦，屈邊翟，不使諸子居之，我懼焉。」於是使太子申生居曲沃，公子重耳居蒲，公子夷吾居屈。獻公與驪姬子奚齊居絳。晉國以此知太子不立也。太子申生，其母齊桓公女也，曰齊姜，早死。申生同母女弟為秦穆公夫人。重耳母，翟之狐氏女也。夷吾母，重耳母女弟也。獻公子八人，而太子申生、重耳、夷吾皆有賢行。及得驪姬，乃遠此三子。


**本卷说明：** 本段称重耳与夷吾之母为狐氏姐妹，另称齐姜为齐桓公女、穆姬为申生女弟，与其他篇章所见齐宗女及申生姊异说不合；正文只写可辨母系，不强拼其父母年龄。奚齐出生是这里的背景，不另补无证出生年月。

<!-- /sj039-cite-049 -->

<a id="sj039-cite-090"></a>

**[《史记·晋世家》P051](../../sources/摘录/史记-卷039-晋世家.md#p051)**

> 晉文公重耳，晉獻公之子也。自少好士，年十七，有賢士五人：曰趙衰；狐偃咎犯，文公舅也；賈佗；先軫；魏武子。自獻公為太子時，重耳固已成人矣。獻公即位，重耳年二十一。獻公十三年，以驪姬故，重耳備蒲城守秦。


**本卷说明：** 本段守蒲作献公十三年，前段作十二年；正文沿经传前666年分居三城。重耳十七、二十一、四十三等年龄与各篇不同，保存为一条年龄链，不另立确定生年。

# 公元前667年（鲁庄公二十七年）

[← 上一张已编年页：公元前668年](bce-0668.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前666年 →](bce-0666.md)

<a id="event-1"></a>

1. **春，鲁庄公在洮地会见嫁到杞国的伯姬。** 这次会见并非处理明确国事，因此受到礼制批评。[[1]](#note-1)

<a id="event-2"></a>

2. **夏六月，鲁庄公与齐桓公、宋公、陈侯、郑伯在幽地重新举行同盟。** 陈、郑两国重新服从齐国主导的诸侯体系。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，公子友到陈国参加原仲葬礼。** 原仲是季友旧交，这次私人性质的跨国奔丧被认为不合卿大夫出境常礼。[[3]](#note-3)

<a id="event-4"></a>

4. **冬，杞伯姬回鲁探亲，莒国庆来迎娶叔姬，杞伯也来鲁朝见。** 鲁国的婚姻外交非常活跃。[[4]](#note-4)

<a id="event-5"></a>

5. **鲁庄公又与齐桓公在城濮会面。** 鲁齐关系保持稳定。[[5]](#note-5)

<a id="event-6"></a>

6. **晋献公想伐虢，士蒍劝他暂缓，等虢国因连续得胜而骄傲、失去民心后再动手。** 晋国开始形成有计划吞并虢国的战略。[[6]](#note-6)

<a id="event-7"></a>

7. **周王正式赐齐桓公命，并请求齐国讨伐卫国，因为卫国曾参与拥立王子颓。** 齐桓公的霸主身份得到王室进一步承认。[[7]](#note-7)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公二十七年》**：“二十有七年春，公会杞伯姬于洮。”  
   **《左传·庄公二十七年》**：“非事也。”

<a id="note-2"></a>

2. **《春秋·庄公二十七年》**：“夏六月，公会齐侯、宋公、陈侯、郑伯，同盟于幽。”  
   **《左传·庄公二十七年》**：“陈、郑服也。”

<a id="note-3"></a>

3. **《春秋·庄公二十七年》**：“秋，公子友如陈，葬原仲。”  
   **《左传·庄公二十七年》**：“原仲，季友之旧也。”

<a id="note-4"></a>

4. **《春秋·庄公二十七年》**：“冬，杞伯姬来。莒庆来逆叔姬。杞伯来朝。”

<a id="note-5"></a>

5. **《春秋·庄公二十七年》**：“公会齐侯于城濮。”

<a id="note-6"></a>

6. **《左传·庄公二十七年》**详记晋侯欲伐虢，士蒍建议等待虢国骄而失众。

<a id="note-7"></a>

7. **《左传·庄公二十七年》**：“王使召伯廖赐齐侯命，且请伐卫，以其立子颓也。”

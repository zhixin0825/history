# 公元前668年（鲁庄公二十六年）

[← 上一张已编年页：公元前669年](bce-0669.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前667年 →](bce-0667.md)

<a id="event-1"></a>

1. **春，鲁庄公亲自伐戎，夏天回国。** 鲁国继续处理西部和北部边境压力。[[1]](#note-1)

<a id="event-2"></a>

2. **曹国杀死本国大夫。** 现存本年记载没有留下更完整的政变经过。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，鲁国会同宋、齐军队攻徐。** 齐国霸权体系开始把军事行动扩展到徐地。[[3]](#note-3)

<a id="event-4"></a>

4. **冬十二月朔日发生日食。** 天象被精确记录。[[4]](#note-4)

<a id="event-5"></a>

5. **晋国士蒍升任大司空，并修筑绛城、加深宫城防御。** 晋献公清洗群公子后开始重构君权中心。[[5]](#note-5)

<a id="event-6"></a>

6. **虢国秋冬连续两次入侵晋国。** 晋、虢关系急速恶化，为以后“假道伐虢”一系列事件埋下伏笔。[[6]](#note-6)

<a id="sj014-0668-wei"></a>

7. **卫国进入懿公赤元年。** 卫惠公朔在[前669年](bce-0669.md#event-2)去世，其子赤继承君位，本年开始按懿公纪年。卫懿公后来因宠鹤和用人失当遭遇狄兵攻卫，是[前660年](bce-0660.md)的后事，不能提前写成本年败亡。[[7]](#sj014-0668-wei-note)

<a id="note-2"></a>

2. **《春秋·庄公二十六年》**：“曹杀其大夫。”

<a id="note-3"></a>

3. **《春秋·庄公二十六年》**：“秋，公会宋人、齐人伐徐。”

<a id="note-4"></a>

4. **《春秋·庄公二十六年》**：“冬十有二月癸亥朔，日有食之。”

<a id="note-5"></a>

5. **《左传·庄公二十六年》**：“晋士蒍为大司空。夏，士蒍城绛，以深其宫。”

<a id="note-6"></a>

6. **《左传·庄公二十六年》**：“秋，虢人侵晋。冬，虢人又侵晋。”

<a id="sj014-0668-wei-note"></a>

7. **《史记·十二诸侯年表》**[前668年卫栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0668)记“卫懿公赤元年”；[《卫康叔世家·卫惠公、懿公》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-03fd82ed451bcf)记惠公三十一年卒，子懿公赤立。其父死亡、继位与次年纪年接续，不再虚造一个本年的死亡事件。年表在前660年卫栏写狄攻卫与戴公受立，须另按彼年叙事。

# 公元前668年（鲁庄公二十六年）

[← 上一张已编年页：公元前669年](bce-0669.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前667年 →](bce-0667.md)

<a id="event-1"></a>

1. **春，鲁庄公亲自伐戎，夏天回国。** 鲁国继续处理西部和北部边境压力。[1]

<a id="event-2"></a>

2. **曹国杀死本国大夫。** 现存本年记载没有留下更完整的政变经过。[2]

<a id="event-3"></a>

3. **秋，鲁国会同宋、齐军队攻徐。** 齐国霸权体系开始把军事行动扩展到徐地。[3]

<a id="event-4"></a>

4. **冬十二月朔日发生日食。** 天象被精确记录。[4]

<a id="event-5"></a>

5. **晋国士蒍升任大司空，并修筑绛城、加深宫城防御。** 晋献公清洗群公子后开始重构君权中心。[5]

<a id="event-6"></a>

6. **虢国秋冬连续两次入侵晋国。** 晋、虢关系急速恶化，为以后“假道伐虢”一系列事件埋下伏笔。[6]

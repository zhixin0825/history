# 公元前669年（鲁庄公二十五年）

[← 上一张已编年页：公元前670年](bce-0670.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前668年 →](bce-0668.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，陈国派女叔来鲁聘问，鲁陈正式开始建立友好关系。** 这是两国关系的新起点。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏五月，卫惠公朔去世。** 卫国结束这位长期卷入政变与复位的君主时代。 [[2]](#note-2)

<a id="event-3"></a>

3. **六月朔日发生日食，鲁国击鼓并在社坛用牲祭祀。** 这种处理方式被认为超出常规礼制。 [[3]](#note-3)

<a id="event-4"></a>

4. **伯姬嫁到杞国。** 鲁国继续通过婚姻连接周边诸侯。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋，鲁国再次发生大水，又在社坛和城门击鼓、用牲祭祀。** 当时把灾害同祭祀直接联系，但这种做法也受到礼制批评。 [[5]](#note-5)

<a id="event-6"></a>

6. **晋国公族清洗达到高潮：士蒍先让群公子杀尽游氏一族，再把群公子集中到聚地，晋献公随后围聚全部杀死。** 晋献公借旧公族互相残杀，最终一次性清除潜在威胁。 清洗群公子的主张出自士蒍：他以公族人数众多、将来可能作乱说服献公。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬，公子友前往陈国。** 鲁陈新建立的关系继续发展。 [[7]](#note-7)

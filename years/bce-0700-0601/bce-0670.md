# 公元前670年（鲁庄公二十四年）

[← 上一张已编年页：公元前671年](bce-0671.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前669年 →](bce-0669.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁国又雕刻桓公庙屋椽，继续奢华装饰先君宫庙。** 大夫御孙认为俭朴才是德行的共同准则，过度装饰会败坏政治风气。 [[1]](#note-1)

<a id="event-2"></a>

2. **春，曹庄公下葬。** 曹国完成君主丧礼。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，鲁庄公亲自到齐国迎娶齐女；秋天返鲁，八月哀姜正式进入鲁国。** 鲁齐婚姻再次成为鲁国政治核心。 [[3]](#note-3)

<a id="event-4"></a>

4. **哀姜入鲁次日，鲁国大夫与宗妇用同样的币帛相见。** 御孙认为男女礼物本应有别，此举混淆了礼制等级和性别秩序。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋，鲁国发生大水。** 婚礼之后不久又出现严重水灾。 [[5]](#note-5)

<a id="event-6"></a>

6. **晋国清洗公族继续推进，士蒍设计让群公子杀掉游氏二子。** 晋献公正在一步步消除国内旧公族势力。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬，戎人侵曹；曹国又发生内部政争，曹羁出奔陈，赤返回曹国。** 曹国君位和贵族关系持续动荡。 [[7]](#note-7)

<a id="sj014-0670-cao"></a>

<a id="event-8"></a>

8. **曹国开始以釐公夷元年纪事。** 前一年曹庄公去世，本年春举行葬礼；《十二诸侯年表》记继任国君为釐公夷。同年曹羁出奔陈、赤归曹，说明曹国内部另有君位争议，但经传对相关人物身份有异说，不能仅凭赤归曹就断定赤必即夷。 [[8]](#note-8)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·庄公二十四年》**：“二十有四年春，王三月，刻桓宫桷。”  
   **《左传·庄公二十四年》**详记御孙以“俭，德之共也；侈，恶之大也”劝谏。

<a id="history-legacy-source-2"></a>


2. **《春秋·庄公二十四年》**：“葬曹庄公。”

<a id="history-legacy-source-3"></a>


3. **《春秋·庄公二十四年》**：“夏，公如齐逆女。秋，公至自齐。八月丁丑，夫人姜氏入。”

<a id="history-legacy-source-4"></a>


4. **《春秋·庄公二十四年》**：“戊寅，大夫、宗妇觌，用币。”  
   **《左传·庄公二十四年》**详记御孙批评男女同贽。

<a id="history-legacy-source-5"></a>


5. **《春秋·庄公二十四年》**：“大水。”

<a id="history-legacy-source-6"></a>


6. **《左传·庄公二十四年》**：“晋士蒍又与群公子谋，使杀游氏之二子。”

<a id="history-legacy-source-7"></a>


7. **《春秋·庄公二十四年》**：“冬，戎侵曹。曹羁出奔陈。赤归于曹。郭公。”

<a id="sj014-0670-cao-note"></a>

8. **《史记·十二诸侯年表》**[前670年曹栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0670)记“曹釐公夷元年”；[《管蔡世家》曹庄公、釐公段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7035.md#ref-e6588666911537)记庄公卒、子釐公夷立。此处与[前671年曹庄公死亡](bce-0671.md#event-7)衔接，区别继位和元年；本年[《春秋·庄公二十四年》](../../sources/春秋左传/data/zz-03-24.json)又记曹羁出奔、赤归曹。《公羊传》关于曹羁与赤的身份和经文称谓有另一套解释；未完成该异文系统的校勘前，正文不把“赤”直接等同釐公“夷”。

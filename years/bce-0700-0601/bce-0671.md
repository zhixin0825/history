# 公元前671年（鲁庄公二十三年）

[← 上一张已编年页：公元前672年](bce-0672.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前670年 →](bce-0670.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁庄公从齐国返回；周王室的祭叔来鲁聘问。** 鲁国继续处理与齐国婚姻及王室外交。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，庄公专程前往齐国观看社祭，曹刿劝阻无效。** 曹刿认为诸侯出行应当服务于朝会、征伐等公共秩序，不该为了观赏仪式随意出国。 [[2]](#note-2)

<a id="event-3"></a>

3. **楚国首次派使者来鲁聘问。** 楚与鲁之间开始出现正式外交往来。 [[3]](#note-3)

<a id="event-4"></a>

4. **庄公与齐侯在穀地相遇，萧叔也来朝见庄公。** 鲁齐互动持续密集。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋，鲁国把桓公庙柱涂成红色。** 对先君宫室的装饰开始趋于奢华。 [[5]](#note-5)

<a id="event-6"></a>

6. **晋献公担忧国内众多公族威胁君权，士蒍建议先除掉富子，再逐步清洗群公子。** 晋国内部大规模公族清洗由此开始。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬，曹庄公去世；十二月，鲁庄公又与齐侯在扈地结盟。** 鲁国继续保持对齐密切关系。 [[7]](#note-7)

<a id="sj014-0671-chu"></a>

<a id="event-8"></a>

8. **楚国从本年开始采用成王熊恽的元年，恢复内外关系。** 熊恽在前一年争位中取得王位，本年施惠于民，结好诸侯，遣使向周天子进献。周王赐胙，嘱他镇服南方夷越而不得侵中原；楚的疆域此时被概述为千里。 [[8]](#note-8)

<a id="卷014楚栏楚成王熊恽元年"></a>
#### 卷014楚栏｜楚成王熊恽元年

[《十二诸侯年表》前671年楚栏](../../拆分史书/史记/卷014.md#y0671)记“楚成王惲元年”；[《楚世家》](../../拆分史书/史记/卷040.md#part-1-text)在庄敖之后记熊恽继位，并概述成王初政。夺位事依年表在[前672年](bce-0672.md)记述，本年只标明成王纪年开端。世家对布德施惠、结旧好等早期施政没有在此给出逐件月日，不将其强行定为本年完成。

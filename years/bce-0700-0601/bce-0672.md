# 公元前672年（鲁庄公二十二年）

[← 上一张已编年页：公元前673年](bce-0673.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前671年 →](bce-0671.md)

<a id="event-1"></a>

1. **春，鲁国大赦；癸丑，安葬文姜。** 文姜去世后的丧礼正式完成。[1]

<a id="event-2"></a>

2. **陈国杀太子御寇，公子完与颛孙逃往齐国。** 陈国内乱推动公子完进入齐国，这一支后来将在齐国坐大。[2]

<a id="event-3"></a>

3. **齐桓公想任公子完为卿，公子完辞谢，只接受工正之职。** 他以流亡之臣身份谨慎自处，避免一入齐就占据高位。[3]

<a id="event-4"></a>

4. **关于公子完后代，陈国旧有占卜已经预言其子孙会在异国、姜姓之国兴盛。** 这段预言后来被用来解释陈氏在齐国壮大的历史。[4]

<a id="event-5"></a>

5. **秋七月，鲁国与齐国大夫高傒在防地结盟。** 鲁齐关系继续修复。[5]

<a id="event-6"></a>

6. **冬，鲁庄公亲自到齐国纳币，为自己的婚姻做准备。** 庄公即将迎娶齐女哀姜。[6]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公二十二年》**：“二十有二年春，王正月，肆大眚。癸丑，葬我小君文姜。”

<a id="note-2"></a>

2. **《春秋·庄公二十二年》**：“陈人杀其公子御寇。”  
   **《左传·庄公二十二年》**：“陈人杀其大子御寇，陈公子完与颛孙奔齐。”

   **说明：** 经文称“公子御寇”，传文称“大子御寇”；正文只写其被杀，不在正文强定身份层级。

<a id="note-3"></a>

3. **《左传·庄公二十二年》**详记齐桓公欲使敬仲为卿，敬仲辞而为工正。

<a id="note-4"></a>

4. **《左传·庄公二十二年》**详记懿氏卜妻敬仲及《周易》筮辞，后世以此联系陈氏在齐国得政。

<a id="note-5"></a>

5. **《春秋·庄公二十二年》**：“秋七月丙申，及齐高傒盟于防。”

<a id="note-6"></a>

6. **《春秋·庄公二十二年》**：“冬，公如齐纳币。”

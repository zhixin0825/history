# 公元前672年（鲁庄公二十二年）

[← 上一张已编年页：公元前673年](bce-0673.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前671年 →](bce-0671.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁国大赦；癸丑，安葬文姜。** 文姜去世后的丧礼正式完成。 [[1]](#note-1)

<a id="event-2"></a>

2. **陈国杀御寇，公子完与颛孙逃往齐国。** 御寇与完交好，完担心内乱牵连自己，因而离陈入齐；颛孙的同行与去向仍沿经传记载。 [[2]](#note-2)

<a id="event-3"></a>

3. **齐桓公想任公子完为卿，公子完辞谢，只接受工正之职。** 完说，流亡之臣能免于负担奔波已是君恩，不敢承当高位。他后来谥敬仲，后裔以田氏著称，逐渐掌握齐政；改氏另有音近、采地等解释，卒年及改氏时点不从奔齐日期推定。 [[3]](#note-3)

<a id="event-4"></a>

4. **关于公子完后代，陈国旧有占卜已经预言其子孙会在异国、姜姓之国兴盛。** 这段预言后来被用来解释陈氏在齐国壮大的历史。 婚姻占辞另以凤凰和鸣、妫姓在姜姓之国繁衍为意象，懿仲终于把女儿嫁给完；五世、八世昌盛之说属于后世传述所保存的占语。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋七月，鲁国与齐国大夫高傒在防地结盟。** 鲁齐关系继续修复。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬，鲁庄公亲自到齐国纳币，为自己的婚姻做准备。** 庄公即将迎娶齐女哀姜。 [[6]](#note-6)

<a id="event-7"></a>

7. **秦宣公建密畤，并在河阳战胜晋军。** 祭祀设施与东面的秦晋战事同见宣公四年。本纪未给这场河阳之战更长的外交前因，故不借后来的韩原故事填补。 [[7]](#note-7)

<a id="sj014-0672-chu"></a>

<a id="event-8"></a>

8. **楚庄敖与弟弟熊恽争夺君位，熊恽取得王位，后来称楚成王。** 《楚世家》记庄敖想杀熊恽，熊恽逃往随国，后来得到随人相助，回楚袭杀庄敖并继位。《十二诸侯年表》将政变列在本年，下一年前671年才列成王元年。 [[8]](#note-8)

<a id="sj014-0672-zheng"></a>

<a id="event-9"></a>

9. **郑国开始以郑文公捷的元年纪事。** 前一年郑厉公突去世，儿子文公继位；本年《十二诸侯年表》改列郑文公元年。这个元年表示在位纪年的开始，不是厉公再次去世。 [[9]](#note-9)

<a id="sj014-0672-jin"></a>

<a id="event-10"></a>

10. **晋献公五年，晋军攻打骊戎，献公得到骊姬，骊姬此后受到宠爱。** 此事发生在晋国后来围绕太子申生及奚齐的储位斗争之前，不把后续变故提前归入本年。 所得二女是姐妹，二人都受宠；后来奚齐、悼子的出生另作为宫廷继承的背景。 [[10]](#note-10)

### 4. 关于公子完后代，陈国旧有占卜已经预言其子孙会在异国、姜姓之国兴盛

[返回正文第4条](#event-4)

**[《左传》鲁庄公22年传文（前672年）](../../sources/春秋左传/有标点原文/bce-0672.md#batch-20261109-t003)**

> 初，懿氏卜妻敬仲，其妻占之，曰：“吉。是谓‘凤皇于飞，和鸣锵锵。有妫之后，将育于姜。五世其昌，并于正卿。八世之后，莫之与京。’”陈厉公，蔡出也，故蔡人杀五父而立之，生敬仲。其少也，周史有以《周易》见陈侯者，陈侯使筮之，遇《观》之《否》。曰：“是谓‘观国之光，利用宾于王’。此其代陈有国乎？不在此，其在异国；非此其身，在其子孙。光远而自他有耀者也。《坤》，土也。《巽》，风也。《乾》，天也。风为天于土上，山也。有山之材而照之以天光，于是乎居土上。故曰：‘观国之光，利用宾于王。’庭实旅百，奉之以玉帛，天地之美具焉，故曰：‘利用宾于王。’犹有观焉，故曰：‘其在后乎。’风行而著于土，故曰：‘其在异国乎。’若在异国，必姜姓也。姜，大嶽之后也。山岳则配天，物莫能两大。陈衰，此其昌乎。”

[史料说明](#history-legacy-source-4)

<a id="sj036-cite-032"></a>

**[《史记·陈杞世家》P009](../../sources/摘录/史记-卷036-陈杞世家.md#p009)**

> 周太史過陳，陳厲公使以《周易》筮之，卦得觀之否：「是為觀國之光，利用賓于王。此其代陳有國乎？不在此，其在異國？非此其身，在其子孫。若在異國，必姜姓。姜姓，太嶽之後。物莫能兩大，陳衰，此其昌乎？」

**本卷说明：** 占筮为陈完入齐前的回叙；原文未载占卜确切年月，只附于此处阅读。

<a id="sj036-cite-033"></a>

**[《史记·陈杞世家》P012](../../sources/摘录/史记-卷036-陈杞世家.md#p012)**

> 齊懿仲欲妻陳敬仲，卜之，占曰：「是謂鳳皇于飛，和鳴鏘鏘。有媯之後，將育于姜。五世其昌，并于正卿。八世之後，莫之與京。」

**本卷说明：** 这是婚姻占辞，既非确定生育预告，也不是诸代田氏已经在本年掌权；五世、八世的计数古注亦有分歧。

<a id="sj046-cite-002"></a>

**[《史记·田敬仲完世家》P001](../../sources/摘录/史记-卷046-田敬仲完世家.md#p001)**

> 完生，周太史過陳，陳厲公使卜完，卦得觀之否：「是為觀國之光，利用賓于王。此其代陳有國乎？不在此而在異國乎？非此其身也，在其子孫。若在異國，必姜姓。姜姓，四嶽之後。物莫能兩大，陳衰，此其昌乎？」

**本卷说明：** 回述陈完出生时的占辞，不另在奔齐年发生一次出生与占卜。古人的占验解释作为传述保存。

<!-- /sj046-cite-002 -->

<a id="sj046-cite-010"></a>

**[《史记·田敬仲完世家》P003](../../sources/摘录/史记-卷046-田敬仲完世家.md#p003)**

> 齊懿仲欲妻完，卜之，占曰：「是謂鳳皇于蜚，和鳴鏘鏘。有媯之後，將育于姜。五世其昌，并于正卿。八世之後，莫之與京。」卒妻完。

**本卷说明：** 懿仲婚占与较早的周太史占辞分开，都是传述的预言，不用其“五世、八世”倒算世系年份。

#### 卷014楚栏｜庄敖被取代与楚成王继位

[《十二诸侯年表》前672年楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0672)载堵敖五年、弟恽代立；[《楚世家》庄敖段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7040.md#ref-86d82f0858e131)详述庄敖欲杀弟熊恽、恽奔随、与随袭弑庄敖。按《史记》表、传，本年叙述夺位经过，[前671年](bce-0671.md#sj014-0671-chu)另记“楚成王惲元年”，两处是一场继承更迭而不是两个事件。部分经传对楚文王卒年与堵敖在位的纪年不同，参见[前676年楚堵敖元年的异年说明](bce-0676.md#sj014-0676-zhou-chu-note)。

<a id="sj014-0672-zheng-note"></a>
<a id="卷014郑栏郑文公元年"></a>
#### 卷014郑栏｜郑文公元年

[《十二诸侯年表》前672年郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0672)作“鄭文公捷元年”，[《郑世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7042.md#ref-86cc305b1882ba)作“子文公踕立”，是人名文字的异写。[前673年](bce-0673.md#event-4)已记郑厉公卒及冬葬，此处只记改元，不重复其卒葬。

<a id="sj014-0672-jin-note"></a>
<a id="卷014晋栏晋伐骊戎与骊姬入晋"></a>
#### 卷014晋栏｜晋伐骊戎与骊姬入晋

[《十二诸侯年表》前672年晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0672)记「五伐驪戎，得姬」；[《晋世家·晋献公》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7039.md#ref-fce86524f171ed)载「五年，伐驪戎，得驪姬、驪姬弟，俱愛幸之」。本年只据此补晋军伐骊戎及骊姬进入晋宫；[前666年](bce-0666.md#event-2)的太子及公子分居是其后的另一阶段，不反推骊姬生子的确切年月。

<a id="sj014-0672-other-note"></a>
<a id="卷014周晋栏王室继承背景与骊姬的后续记载"></a>
#### 卷014周、晋栏｜王室继承背景与骊姬的后续记载

[本年原表周栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0672)提到太子生母早死、惠后生叔带，这属于解释后来周王室继承争执的前情；不据表列本年就把两人实际死亡、生育的日期定在本年。晋栏记晋献公伐骊戎得到骊姬；[前666年](bce-0666.md)《左传》已有骊姬与其子奚齐的后续背景。**前666年晚于前672年六年**，仅凭这条后续记载不能认定两书互相矛盾；其精确成婚、生子年份仍不强定，避免将同一人物第一次入晋与后来的政治活动重复成多次。

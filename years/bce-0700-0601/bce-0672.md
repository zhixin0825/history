# 公元前672年（鲁庄公二十二年）

[← 上一张已编年页：公元前673年](bce-0673.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前671年 →](bce-0671.md)

<a id="event-1"></a>

1. **春，鲁国大赦；癸丑，安葬文姜。** 文姜去世后的丧礼正式完成。[[1]](#note-1)

<a id="event-2"></a>

2. **陈国杀御寇，公子完与颛孙逃往齐国。** 陈国内乱推动公子完进入齐国，这一支后来将在齐国坐大。[[2]](#note-2)

<a id="event-3"></a>

3. **齐桓公想任公子完为卿，公子完辞谢，只接受工正之职。** 他以流亡之臣身份谨慎自处，避免一入齐就占据高位。[[3]](#note-3)

<a id="event-4"></a>

4. **关于公子完后代，陈国旧有占卜已经预言其子孙会在异国、姜姓之国兴盛。** 这段预言后来被用来解释陈氏在齐国壮大的历史。[[4]](#note-4)

<a id="event-5"></a>

5. **秋七月，鲁国与齐国大夫高傒在防地结盟。** 鲁齐关系继续修复。[[5]](#note-5)

<a id="event-6"></a>

6. **冬，鲁庄公亲自到齐国纳币，为自己的婚姻做准备。** 庄公即将迎娶齐女哀姜。[[6]](#note-6)

<a id="event-7"></a>

7. **秦宣公建密畤，并在河阳战胜晋军。** 祭祀设施与东面的秦晋战事同见宣公四年。本纪未给这场河阳之战更长的外交前因，故不借后来的韩原故事填补。 [原文与说明](#sj005-047-note)

<a id="sj014-0672-chu"></a>

8. **楚庄敖与弟弟熊恽争夺君位，熊恽取得王位，后来称楚成王。** 《楚世家》记庄敖想杀熊恽，熊恽逃往随国，后来得到随人相助，回楚袭杀庄敖并继位。《十二诸侯年表》将政变列在本年，下一年前671年才列成王元年。 [[8]](#sj014-0672-chu-note)

<a id="sj014-0672-zheng"></a>

9. **郑国开始以郑文公捷的元年纪事。** 前一年郑厉公突去世，儿子文公继位；本年《十二诸侯年表》改列郑文公元年。这个元年表示在位纪年的开始，不是厉公再次去世。 [[9]](#sj014-0672-zheng-note)

<a id="sj014-0672-jin"></a>

10. **晋献公五年，晋军攻打骊戎，献公得到骊姬，骊姬此后受到宠爱。** 此事发生在晋国后来围绕太子申生及奚齐的储位斗争之前，不把后续变故提前归入本年。 [[10]](#sj014-0672-jin-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公二十二年》**：“二十有二年春，王正月，肆大眚。癸丑，葬我小君文姜。”

<a id="note-2"></a>

2. **《春秋·庄公二十二年》**：“陈人杀其公子御寇。”  
   **《左传·庄公二十二年》**：“陈人杀其大子御寇，陈公子完与颛孙奔齐。”

   **说明：** 经文称“公子御寇”，传文称“大子御寇”；正文只写其被杀，不在正文强定身份层级。

<a id="note-3"></a>

3. **《左传·庄公二十二年》**详记齐桓公欲使敬仲为卿，敬仲辞而为工正。

<a id="note-4"></a>

4. **《左传·庄公二十二年》**详记懿氏卜妻敬仲及《周易》筮辞，后世以此联系陈氏在齐国得政。

<a id="note-5"></a>

5. **《春秋·庄公二十二年》**：“秋七月丙申，及齐高傒盟于防。”

<a id="note-6"></a>

6. **《春秋·庄公二十二年》**：“冬，公如齐纳币。”

## 补充史料与异说

<a id="sj014-0672-chu-note"></a>
### 卷014楚栏｜庄敖被取代与楚成王继位

[《十二诸侯年表》前672年楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0672)载堵敖五年、弟恽代立；[《楚世家》庄敖段](https://zh.wikisource.org/wiki/史記/卷040)详述庄敖欲杀弟熊恽、恽奔随、与随袭弑庄敖。按《史记》表、传，本年叙述夺位经过，[前671年](bce-0671.md#sj014-0671-chu)另记“楚成王惲元年”，两处是一场继承更迭而不是两个事件。部分经传对楚文王卒年与堵敖在位的纪年不同，参见[前676年楚堵敖元年的异年说明](bce-0676.md#sj014-0676-zhou-chu-note)。

<a id="sj014-0672-zheng-note"></a>
### 卷014郑栏｜郑文公元年

[《十二诸侯年表》前672年郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0672)作“鄭文公捷元年”，[《郑世家》](https://zh.wikisource.org/wiki/史記/卷042)作“子文公踕立”，是人名文字的异写。[前673年](bce-0673.md#event-4)已记郑厉公卒及冬葬，此处只记改元，不重复其卒葬。

<a id="sj014-0672-jin-note"></a>
### 卷014晋栏｜晋伐骊戎与骊姬入晋

[《十二诸侯年表》前672年晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0672)记「五伐驪戎，得姬」；[《晋世家·晋献公》](https://zh.wikisource.org/wiki/史記/卷039#晉獻公)载「五年，伐驪戎，得驪姬、驪姬弟，俱愛幸之」。本年只据此补晋军伐骊戎及骊姬进入晋宫；[前666年](bce-0666.md#event-2)的太子及公子分居是其后的另一阶段，不反推骊姬生子的确切年月。

<a id="sj014-0672-other-note"></a>
### 卷014周、晋栏｜王室继承背景与骊姬的后续记载

[本年原表周栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0672)提到太子生母早死、惠后生叔带，这属于解释后来周王室继承争执的前情；不据表列本年就把两人实际死亡、生育的日期定在本年。晋栏记晋献公伐骊戎得到骊姬；[前666年](bce-0666.md)《左传》已有骊姬与其子奚齐的后续背景。**前666年晚于前672年六年**，仅凭这条后续记载不能认定两书互相矛盾；其精确成婚、生子年份仍不强定，避免将同一人物第一次入晋与后来的政治活动重复成多次。



<a id="sj005-047-note"></a>
### sj005-047｜秦宣公建密畤，并在河阳战胜晋军。

[卷005 P015](../../sources/摘录/史记-卷005-秦本纪.md#p015)。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

# 公元前673年（鲁庄公二十一年）

[← 上一张已编年页：公元前674年](bce-0674.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前672年 →](bce-0672.md)

<a id="event-1"></a>

1. **春，郑、虢两国约定共同出兵恢复周惠王。** 两路军队分别准备从不同城门进入王城。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，郑厉公护送惠王从圉门入城，虢叔从北门入城，杀王子颓和五大夫。** 持续数年的子颓之乱结束，周惠王恢复王位。[[2]](#note-2)

<a id="event-3"></a>

3. **周惠王重赏郑、虢两国。** 郑得到从虎牢以东的武公旧地，虢公也得到酒泉等赏赐；但两国受赏差异又埋下郑王关系新的不满。[[3]](#note-3)

<a id="event-4"></a>

4. **五月辛酉，郑厉公去世；冬十二月下葬。** 郑国在刚结束王室内战后再次更换君主。[[4]](#note-4)

<a id="event-5"></a>

5. **秋七月，文姜去世。** 庄公长期笼罩在母亲与齐国关系之下的政治时代至此结束。[[5]](#note-5)

<a id="event-6"></a>

6. **冬，周惠王从虢国返回王都。** 王室秩序暂时恢复。[[6]](#note-6)

## 本年相关史料

<a id="note-1"></a>

1. **《左传·庄公二十一年》**：“二十一年春，胥命于弭。”

<a id="note-2"></a>

2. **《左传·庄公二十一年》**：“夏，同伐王城。郑伯将王，自圉门入，虢叔自北门入，杀王子颓及五大夫。”

<a id="note-3"></a>

3. **《左传·庄公二十一年》**详记周王赐郑“武公之略”及赐虢酒泉等事。

<a id="note-4"></a>

4. **《春秋·庄公二十一年》**：“夏五月辛酉，郑伯突卒……冬十有二月，葬郑厉公。”

<a id="note-5"></a>

5. **《春秋·庄公二十一年》**：“秋七月戊戌，夫人姜氏薨。”

<a id="note-6"></a>

6. **《左传·庄公二十一年》**：“冬，王归自虢。”

# 公元前674年（鲁庄公二十年）

[← 上一张已编年页：公元前675年](bce-0675.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前673年 →](bce-0673.md)

<a id="event-1"></a>

1. **春，文姜再次前往莒国。** 她晚年的对外活动仍然频繁。[[1]](#note-1)

<a id="event-2"></a>

2. **郑厉公尝试调停周惠王与王子颓之乱，没有成功，还扣押燕仲父。** 郑国开始直接介入王室内战。[[2]](#note-2)

<a id="event-3"></a>

3. **夏，郑厉公把周惠王接到郑国，安置在栎。** 郑国调停未成，便使周王随自己回去。到秋季，周王与郑伯又进入邬和成周取宝器，暂时仍不是已经恢复王城统治。 [看原文与说明](#cq-source-13)

<a id="event-4"></a>

4. **秋，周惠王与郑厉公进入邬地，又进入成周，取走王室宝器后撤回。** 惠王仍未完全恢复统治。[[4]](#note-4)

<a id="event-5"></a>

5. **冬，王子颓与五大夫纵情歌舞，郑厉公认为这种“临祸而乐”显示其政权将败。** 他随即与虢公商议共同迎回周惠王。[[5]](#note-5)

<a id="event-6"></a>

6. **齐国发生大灾，冬天又出兵攻戎。** 齐国一面应对国内灾害，一面继续对外用兵。[[6]](#note-6)

<a id="sj014-0674-cai"></a>

7. **蔡国以蔡穆侯肸的元年纪事。** 蔡哀侯此前被楚国扣留，后来死于楚国；他的儿子肸继承蔡侯之位。《十二诸侯年表》将穆侯的元年列在本年，不能因此推断哀侯恰好在本年某月去世。 [[7]](#sj014-0674-cai-note)

## 补充核对的史料

<a id="cq-source-13"></a>
### 核对13｜夏，郑厉公把周惠王接到郑国，安置在栎

**说明：**“遂以王归”是郑伯带王归郑；栎是此处的安置地。旧文“返回王畿，把他安置在栎”把方向写反，现依原段更正。

<summary>传 T002｜原文</summary>

> 夏，郑伯遂以王归，王处于栎。

[本段出处](../../sources/春秋左传/有标点原文/bce-0674.md#t002)

</details>

<a id="sj014-0674-cai-note"></a>
### 卷014蔡栏｜蔡穆侯元年

[《十二诸侯年表》前674年蔡栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0674)列「蔡穆侯肸元年」。[《管蔡世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7035.md#ref-2040f4483ab1cd)记蔡哀侯因楚文王而被留楚，九年死于楚，子肸立为穆侯；穆、缪为常见异写。本条只接续君位及元年，不用哀侯被扣与其死于楚国两事强行确定具体月日。

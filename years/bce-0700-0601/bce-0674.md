# 公元前674年（鲁庄公二十年）

[← 上一张已编年页：公元前675年](bce-0675.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前673年 →](bce-0673.md)

<a id="event-1"></a>

1. **春，文姜再次前往莒国。** 她晚年的对外活动仍然频繁。[1]

<a id="event-2"></a>

2. **郑厉公尝试调停周惠王与王子颓之乱，没有成功，还扣押燕仲父。** 郑国开始直接介入王室内战。[2]

<a id="event-3"></a>

3. **夏，郑厉公护送周惠王返回王畿，把他安置在栎。** 惠王暂时依靠郑国重新接近成周。[3]

<a id="event-4"></a>

4. **秋，周惠王与郑厉公进入邬地，又进入成周，取走王室宝器后撤回。** 惠王仍未完全恢复统治。[4]

<a id="event-5"></a>

5. **冬，王子颓与五大夫纵情歌舞，郑厉公认为这种“临祸而乐”显示其政权将败。** 他随即与虢公商议共同迎回周惠王。[5]

<a id="event-6"></a>

6. **齐国发生大灾，冬天又出兵攻戎。** 齐国一面应对国内灾害，一面继续对外用兵。[6]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公二十年》**：“二十年春，王二月，夫人姜氏如莒。”

<a id="note-2"></a>

2. **《左传·庄公二十年》**：“郑伯和王室，不克。执燕仲父。”

<a id="note-3"></a>

3. **《左传·庄公二十年》**：“夏，郑伯遂以王归，王处于栎。”

<a id="note-4"></a>

4. **《左传·庄公二十年》**：“秋，王及郑伯入于邬。遂入成周，取其宝器而还。”

<a id="note-5"></a>

5. **《左传·庄公二十年》**详记王子颓享五大夫、歌舞不倦，郑厉公与虢公谋纳王。

<a id="note-6"></a>

6. **《春秋·庄公二十年》**：“夏，齐大灾……冬，齐人伐戎。”

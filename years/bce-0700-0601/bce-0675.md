1. **楚文王败于巴军后攻黄，返程病卒。** 楚文王迎巴军，败于津。回军时大阍鬻拳不许他进城，文王转攻黄，在踖陵取胜，行至湫患病。六月庚申，文王去世，熊艰继立，是为楚庄敖。鬻拳早年曾持兵器强谏楚王，事后自认胁君有罪，断足后受命为大阍。鬻拳葬文王后自杀，葬于绖皇。 [[1]](#reading-note-1)

2. **王子颓联合五大夫逐周惠王，自立为王。** 周惠王取走大夫的园圃、宫室、田地、俸禄，蒍国等五大夫依托苏氏起兵。王子颓为周庄王与受宠的王姚所生。秋，五大夫奉子颓攻王，初战失利，奔温，苏子护送子颓逃至卫国。冬，子颓夺取王都，被拥立为王，惠王失去统治中心。 [[2]](#reading-note-3)

<a id="event-5"></a>

<a id="reading-event-7"></a>

3. **秋，鲁公子结奉命媵送陈人之妇到鄄，途中又同齐侯、宋公结盟。** 原来以婚姻礼事出使的使臣，进一步办理了结盟。 [[3]](#reading-note-7)

<a id="event-6"></a>

<a id="reading-event-8"></a>

4. **文姜前往莒国，冬季齐、宋、陈军又进攻鲁国西部边境。** 婚姻、会盟与对鲁用兵的消息，在本年接连出现。 [[4]](#reading-note-8)

<a id="sj014-0675-qin"></a>

<a id="reading-event-9"></a>

5. **秦宣公开始以元年纪事。** 德公去世与宣公承继在前676年，不能因为本年书元年又记德公死一次。 [[5]](#reading-note-9)

<a id="sj014-0675-song"></a>

<a id="reading-event-10"></a>

6. **宋桓公娶来自卫国的女子为夫人。** 她是后来卫文公的妹妹，宋、卫王族由这场婚姻进一步联结；此时不能因后来的谥号，便把卫文公写成已经在位。 [[6]](#reading-note-10)

<a id="sj035-cai-ai-death-event"></a>

7. **蔡哀侯在楚国去世，儿子肸继位。** 哀侯献舞早年被楚俘获，长期留在楚国，终究未能以国君身份归来。他死后，蔡人立儿子肸，为缪侯；下一年开始新君元年。 [[7]](#sj035-cai-ai-death-note)

## 归年与考证

<a id="history-legacy-source-1"></a>
<a id="note-1"></a>

1. **《左传·庄公十九年》**详记败津、鬻拳不纳、败黄于踖陵、病湫、六月庚申卒。楚王死亡沿经传前675年；年表前676已列堵敖元年，与之存在冲突，见[前页说明](bce-0676.md#sj014-0676-zhou-chu-note)，不在两年各造一次文王死亡。

<a id="history-legacy-source-2"></a>
<a id="note-2"></a>

2. **《左传·庄公十九年》**依次列王取蒍国圃、边伯宫、相关大夫田地并收膳夫秩，继称“五大夫”作乱。旧页把“子禽、祝跪”径拆为两人，又将石速等全列入，正文人数因此与五大夫不合。这里改用“蒍国等五大夫”，将子禽祝跪的分词、官秩和人数对应留作校勘问题，不凭一组顿号生成第六名参与者。[完整传文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E8%8E%8A%E5%85%AC.md#ref-e1570894a04d70)。

<a id="sj004-675-1"></a>
<a id="子颓家世与王室争位卷四互见"></a>
#### 子颓家世与王室争位｜卷四互见

[卷004 P046](../../sources/摘录/史记-卷004-周本纪.md#p046)作夺大臣园为囿，经传细分多项利益。前696年表中“生子颓”在该年作暂定出生记载，本年只补受宠、蒍国为师的旧背景，不再次出生。王子克与王子颓也不是同一争位者。

<a id="history-legacy-source-4"></a>
<a id="note-3"></a>

3. **《左传·庄公十九年》**：“秋，五大夫奉子颓以伐王，不克，出奔温。苏子奉子颓以奔卫。卫师、燕师伐周。”[卷014本年周、燕两栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0675)都概记燕卫攻王、王奔温、立子颓。两栏同事，合读为一场王室战争；传文第一处“出奔温”主语是战败的五大夫，不能偷换成已经被他们打败的惠王。

   **燕军的国别仍须专门核定。** 年表将战事置于燕庄公的年数栏，传文仅称“燕师”，不能单靠表格位置就认定必由北燕庄公亲征。南燕、北燕的对应尚未在本轮独立完成，正文保留燕军这一共同称谓，不补现代出兵地点、统帅名或路线。

<a id="history-legacy-source-5"></a>
<a id="note-4"></a>

4. **《左传·庄公十九年》**：“冬，立子颓。”经传分别记五大夫败退、求援、外军攻周及立子颓，本页不压成同一天。惠王奔温与后来郑接王到栎的简详记述不同，保留[卷四原注](#sj004-675-1)所关联的解释，不以温地出现一次就断定所有主语一致。

<a id="history-legacy-source-6"></a>
<a id="note-5"></a>

5. **《春秋·庄公十九年》**：“秋，公子结媵陈人之妇于鄄，遂及齐侯、宋公盟。”媵送的具体安排、女子与陈君的关系及公子结的权限，不能仅据短句都恢复；不直接将“陈人之妇”误称陈国公主，更不以一句“遂”断言全部外交程序都已核定为违法。

<a id="history-legacy-source-7"></a>
<a id="note-6"></a>

6. **《春秋·庄公十九年》**：“夫人姜氏如莒。冬，齐人、宋人、陈人伐我西鄙。”

<a id="sj014-0675-song-note"></a>
<a id="卷014宋栏文公弟是后称的女弟"></a>
#### 卷014宋栏｜“文公弟”是后称的女弟

[卷014宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0675)记宋桓公七年“取卫女，文公弟”。[《宋微子世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7038.md#ref-f9d007183d4605)明确“文公女弟为桓公夫人”，为女子亲属称谓，不是娶卫文公的男性弟弟。本文以年表给婚姻归前675年，以世家辨关系；世家在后来迎立卫文公时再说这层关系，不能据其段落位置改成同年另婚。夫人本名及婚礼日未记，不补。

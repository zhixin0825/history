# 公元前675年（鲁庄公十九年）

[← 上一张已编年页：公元前676年](bce-0676.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前674年 →](bce-0674.md)

<a id="event-1"></a>

1. **楚文王迎击巴军，在津地大败；随后又转兵伐黄并取胜，回师途中病死。** 楚王死于六月，楚国大臣鬻拳也在安葬楚王后自杀。[[1]](#note-1)

**鬻拳也在楚文王的丧事之后自杀。** 在这以前，他曾持兵器强谏楚王，认为自己以武力使君主屈从有罪，遂自断足，后来担任守门之职。楚王本年败归时，他曾不纳；王死以后，鬻拳安葬楚王，也自杀而被葬在绖皇。 [看原文与说明](#cq-source-21)

<a id="event-2"></a>

2. **周惠王即位后侵夺多名大夫的园圃、宫室、田地和俸禄，王室内部爆发叛乱。** 蒍国、边伯、石速、詹父、子禽、祝跪等联合苏氏，拥立王子颓。[[2]](#note-2)

子颓是庄王宠妾姚所生，曾受到宠爱；这解释了叛乱大夫为什么能够以他为改立对象。 [卷四互见与归年](#sj004-675-1)


<a id="event-3"></a>

3. **秋，五大夫奉王子颓进攻周惠王，第一次未能成功，随后逃到温地和卫国求援。** 卫、燕军队随后出兵攻周。[[3]](#note-3)

<a id="event-4"></a>

4. **冬，王子颓被正式拥立，周惠王失去成周。** 周王室进入持续数年的“子颓之乱”。[[4]](#note-4)

[补充史料与年次说明](#sj005-045-note)


<a id="event-5"></a>

5. **鲁国公子结本来护送陈国女子到鄄地陪嫁，途中却擅自同齐侯、宋公结盟。** 鲁国外交行动出现越权。[[5]](#note-5)

<a id="event-6"></a>

6. **文姜前往莒国；冬天齐、宋、陈联军又攻鲁国西部边境。** 鲁国同时面对内部外交失序和外部军事压力。[[6]](#note-6)

<a id="sj014-0675-qin"></a>

7. **秦宣公进入在位元年。** 秦德公已于前676年去世，由长子宣公继承秦君之位。本年《十二诸侯年表》所记是宣公开始计算在位年次，并非德公在本年才去世。 [[7]](#sj014-0675-qin-note)

## 本年相关史料

<a id="note-1"></a>

1. **《左传·庄公十九年》**详记楚文王败于津、伐黄取胜，六月庚申卒；鬻拳随后自杀。

<a id="note-2"></a>

2. **《左传·庄公十九年》**详记周惠王侵夺诸大夫利益，蒍国等“五大夫”因苏氏作乱。

<a id="sj004-675-1"></a>
#### 子颓的家世与反叛｜卷四互见

[卷004 P046](../../sources/摘录/史记-卷004-周本纪.md#p046)。 本纪作惠王夺大臣园为囿，已有经传页列多名大夫被侵夺利益，采用更具体叙事。出奔温、从郑入栎是先后不同的落脚点，不用本纪摘要抹平经传过程。


<a id="note-3"></a>

3. **《左传·庄公十九年》**：“秋，五大夫奉子颓以伐王，不克……卫师、燕师伐周。”

<a id="note-4"></a>

4. **《左传·庄公十九年》**：“冬，立子颓。”

<a id="note-5"></a>

5. **《春秋·庄公十九年》**：“秋，公子结媵陈人之妇于鄄，遂及齐侯、宋公盟。”

<a id="note-6"></a>

6. **《春秋·庄公十九年》**：“夫人姜氏如莒。冬，齐人、宋人、陈人伐我西鄙。”

## 补充史料与异说

<a id="sj014-0675-qin-note"></a>
### 卷014秦栏｜秦宣公元年

[《十二诸侯年表》前675年秦栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0675)列宣公元年；[《秦本纪》卷005 P015](../../sources/摘录/史记-卷005-秦本纪.md#p015)亦记德公卒后宣公继立。[前676年](bce-0676.md#event-7)已有德公去世与宣公继承的叙述，本年只记新君元年。楚文王之死采用本年《左传》叙事，另见[前676年纪年异说说明](bce-0676.md#sj014-0676-zhou-chu-note)，不重复死亡。

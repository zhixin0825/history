# 公元前676年（鲁庄公十八年）

[← 上一张已编年页：公元前677年](bce-0677.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前675年 →](bce-0675.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春三月，发生日食。** 本年经文保存了这一天象。 [[1]](#note-1)

<a id="event-2"></a>

2. **周王宴请虢公、晋侯，对二人赐同等玉、马。** 两人名位有别，所得礼数却相同，传文对此提出批评。 [[2]](#note-2)

<a id="event-3"></a>

3. **虢公、晋侯、郑伯派原庄公到陈国迎王后，陈妫进入王都，成为惠后。** 具体前去迎接的是使者原庄公，不是三位国君一起亲往陈国。 [[3]](#note-3)

<a id="event-4"></a>

4. **夏，鲁庄公追击来犯戎人至济水以西。** 鲁史记了追击，没有先记入侵。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋，鲁国出现蜮灾。** 原书以成灾而记，不补未经确定的现代物种和损失数字。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬，巴人趁楚国内乱进攻楚国。** 早先楚曾迁徙权国之民，由阎敖等官员治理；后来巴楚共同攻申时失和，巴攻那处、逼楚，阎敖逃回被杀，其族又起乱。巴人利用这些矛盾再度出兵。 [[6]](#note-6)

<a id="event-7"></a>

7. **秦设伏日祠祭，又在都邑四门用狗行禳除之礼。** 德公在位第二年去世，长子宣公接位，另两子成公、穆公将先后承位。 [[7]](#note-7)

<a id="sj014-0676-event"></a>

<a id="event-8"></a>

8. **晋献公诡诸开始以元年纪事。** 父亲武公死与诡诸继位已发生在前一年，元年不是第二次继承。 [[8]](#note-8)

<a id="sj014-0676-zhou-chu"></a>

<a id="event-9"></a>

9. **周惠王阆开始用元年纪事。** 周釐王前一年已死，惠王承位，本年又以迎陈女为后的婚姻连接王室与陈国。楚国在位者的纪年则未完全一致：年表本行已列堵敖元年，经传却仍将楚文王的活动和死亡记到前675年，不同时按两套王年写成两任楚王并立。 [[9]](#note-9)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·庄公十八年》**：“十有八年春，王三月，日有食之。”

<a id="history-legacy-source-2"></a>


2. **《左传·庄公十八年》**详列虢、晋来朝、赐玉五玨和马，评“名位不同，礼亦异数”。礼制判断保留为原作者意见，不用赏赐直接推算两国实力完全相等。

<a id="history-legacy-source-3"></a>


3. **《左传·庄公十八年》**：“虢公、晋侯、郑伯使原庄公逆王后于陈。陈妫归于京师，实惠后。”[卷014本年周栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0676)“取陈后”即此婚姻，不再另造一次娶后。旧正文略去“使原庄公”，容易误认三君亲迎，本次补正。

<a id="history-legacy-source-4"></a>


4. **《春秋·庄公十八年》**：“夏，公追戎于济西。”  
   **《左传》**：“不言其来，讳之也。”这是对鲁史书法的解释，不凭遗漏推论根本没有入侵。

<a id="history-legacy-source-5"></a>


5. **《春秋·庄公十八年》**：“秋，有蜮。”  
   **《左传》**：“为灾也。”

<a id="history-legacy-source-6"></a>


6. **《左传·庄公十八年》**以“初”回叙武王克权、鬥缗作乱受诛、迁权到那处，再接巴楚失和、阎敖被杀与其族乱，最后“冬，巴人因之以伐楚”。只有最后阶段明确在本年冬；此前克权、迁民和官员任免不能都压成本年。

### 补充史料与异说

<a id="sj014-0676-zhou-chu-note"></a>
<a id="卷014周楚栏不能同时照搬两套王年"></a>
#### 卷014周楚栏｜不能同时照搬两套王年

[卷014本年周、楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0676)列惠王、堵敖元年。[前677年周釐王卒](bce-0677.md#event-5)与惠王元年可相接；楚国则不齐一：《楚世家》记文王十三年死，按本表系年前677，而[《左传·庄公十九年》](../../sources/春秋左传/data/zz-03-19.json)在前675年仍详叙文王败巴、伐黄、病死。当前主述从经传置[前675年](bce-0675.md#event-1)，堵敖元年仅登记为另一套纪年，不写成一王已死又复生。堵敖名字在本表及其他篇章有异写，本页不以异写增加另一任楚君，也未据局部取舍宣布整条楚王世系已经校定。

<a id="sj005-044-note"></a>
<a id="sj005-044伏祭与秦德公死亡"></a>
#### sj005-044｜伏祭与秦德公死亡

[卷005 P014](../../sources/摘录/史记-卷005-秦本纪.md#p014)记德公三十三岁即位、二年卒、以狗御蛊；[卷014本年秦栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0676)另有“初作伏，祠社，磔狗邑四门”，本次补入四门的礼仪位置。祠祭观念不改成已经证实的防疫效果；初作伏也不直接等同后世所有三伏算法同时确立。[卷005纪年口径](../../meta/考证/史记-卷005-纪年与异说.md)。

<a id="sj014-0676-note"></a>
<a id="卷014晋栏献公元年"></a>
#### 卷014晋栏｜献公元年

[卷014晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0676)及[《晋世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7039.md#ref-a925736f9e4a39)相接。武公死与诡诸立留在[前677年](bce-0677.md#sj014-0677-event)，不是本年新增一场继承。

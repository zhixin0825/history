# 公元前676年（鲁庄公十八年）

[← 上一张已编年页：公元前677年](bce-0677.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前675年 →](bce-0675.md)

<a id="event-1"></a>

1. **春三月，发生日食。** 这是本年最明确的天象记录。[[1]](#note-1)

<a id="event-2"></a>

2. **周王宴请虢公、晋侯，并以相同规格赐玉和马。** 因两人名位不同却受到相同礼遇，这次赏赐被认为不合等级制度。[[2]](#note-2)

<a id="event-3"></a>

3. **虢公、晋侯、郑伯共同迎接陈女入周王室，她后来成为惠后。** 周王室通过婚姻重新联结陈国。[[3]](#note-3)

<a id="event-4"></a>

4. **夏，鲁庄公追击戎人至济水以西。** 戎人此前已经侵入鲁境，只是来犯过程没有被正式记录。[[4]](#note-4)

<a id="event-5"></a>

5. **秋，鲁国出现蜮虫并造成灾害。** 因实际成灾，这次虫害进入年表。[[5]](#note-5)

<a id="event-6"></a>

6. **冬，巴人趁楚国内乱进攻楚国。** 楚国早先迁权国之民、任命官员，又因巴楚联军伐申后的矛盾引发反叛；巴军最终直接攻楚。[[6]](#note-6)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公十八年》**：“十有八年春，王三月，日有食之。”

<a id="note-2"></a>

2. **《左传·庄公十八年》**详记虢公、晋侯朝王并同受赐，批评名位不同而礼数相同。

<a id="note-3"></a>

3. **《左传·庄公十八年》**：“虢公、晋侯、郑伯使原庄公逆王后于陈。陈妫归于京师，实惠后。”

<a id="note-4"></a>

4. **《春秋·庄公十八年》**：“夏，公追戎于济西。”  
   **《左传·庄公十八年》**：“不言其来，讳之也。”

<a id="note-5"></a>

5. **《春秋·庄公十八年》**：“秋，有蜮。”  
   **《左传·庄公十八年》**：“为灾也。”

<a id="note-6"></a>

6. **《左传·庄公十八年》**详记楚、巴矛盾及“冬，巴人因之以伐楚”。

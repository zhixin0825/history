# 公元前677年（鲁庄公十七年）

[本年相关史料](#sources-start)

<a id="event-1"></a>

<a id="event-3"></a>

1. **齐国扣押郑大夫詹，詹后来逃到鲁国。** 春，齐国以郑不朝齐桓公为由，扣押郑大夫詹。秋，詹从齐逃到鲁国。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，原遂国居民设宴灌醉齐国驻军，将驻军全部杀死。** 遂国虽然已经被齐国灭亡，当地宗族仍发动反抗。 [[2]](#note-2)

<a id="event-4"></a>

3. **冬，鲁国出现大量麋鹿。** 这一异常自然现象被记录下来。 [[3]](#note-4)

<a id="event-5"></a>

4. **周釐王去世，惠王阆继位。** 釐王死，儿子阆继位，即惠王。王室下一阶段的争端很快涉及宫室、园圃与大夫利益。 [[4]](#note-5)

<a id="event-6"></a>

5. **秦德公开始居雍，梁、芮两君来朝。** 德公居雍城大郑宫，以三百牢祭鄜畤，并为居雍占卜。梁伯、芮伯来朝，显示秦与邻国已有稳定使聘关系。 [[5]](#note-6)

<a id="sj014-0677-event"></a>

<a id="event-7"></a>

6. **晋武公去世，儿子诡诸承继晋侯之位，后来称晋献公。** 晋武公统一晋国后在位不久便去世，儿子诡诸承继，是为晋献公，次年为新君元年。 [[6]](#note-7)

[史料说明](#sj014-0677-note)

<a id="sj039-cite-041"></a>

**[《史记·晋世家》P022](../../sources/摘录/史记-卷039-晋世家.md#p022)**

> 武公稱者，先晉穆侯曾孫也，曲沃桓叔孫也。者，始封曲沃。武公，莊伯子也。自桓叔初封曲沃以至武公滅晉也，凡六十七歲，而卒代晉為諸侯。武公代晉二歲，卒。與曲沃通年，即位凡三十九年而卒。子獻公詭諸立。


**本卷说明：** 主本“者，始封曲沃”失去主语，三家注p20作“桓叔者”。自前745封曲沃至前679灭翼，包首尾六十七个年位；至前678册命则六十八年位，不能把两个终点混用。

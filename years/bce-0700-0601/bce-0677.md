# 公元前677年（鲁庄公十七年）

[← 上一张已编年页：公元前678年](bce-0678.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前676年 →](bce-0676.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，齐国扣押郑国大夫詹，理由是郑国没有朝见齐桓公。** 齐国已经开始用霸主身份要求诸侯服从新的会盟秩序。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，原遂国居民设宴灌醉齐国驻军，将驻军全部杀死。** 遂国虽然已经被齐国灭亡，当地宗族仍发动反抗。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋，郑詹从齐国逃到鲁国。** 鲁国因此接纳了一名被齐扣押的郑国大夫。 [[3]](#note-3)

<a id="event-4"></a>

4. **冬，鲁国出现大量麋鹿。** 这一异常自然现象被记录下来。 [[4]](#note-4)

<a id="event-5"></a>

5. **周釐王去世，惠王阆继位。** 釐王死，儿子阆继位，即惠王。王室下一阶段的争端很快涉及宫室、园圃与大夫利益。 [[5]](#note-5)

<a id="event-6"></a>

6. **秦德公开始居雍，梁、芮两君来朝。** 德公居雍城大郑宫，以三百牢祭鄜畤，并为居雍占卜。梁伯、芮伯来朝，显示秦与邻国已有稳定使聘关系。 [[6]](#note-6)

<a id="sj014-0677-event"></a>

<a id="event-7"></a>

7. **晋武公去世，儿子诡诸承继晋侯之位，后来称晋献公。** 武公在曲沃长期执政，兼并翼地后的时间却很短；诡诸在父亲去世后继承国君位置，下一年才按《十二诸侯年表》纪作晋献公元年。 [[7]](#note-7)

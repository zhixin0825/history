# 公元前677年（鲁庄公十七年）

[← 上一张已编年页：公元前678年](bce-0678.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前676年 →](bce-0676.md)

<a id="event-1"></a>

1. **春，齐国扣押郑国大夫詹，理由是郑国没有朝见齐桓公。** 齐国已经开始用霸主身份要求诸侯服从新的会盟秩序。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，原遂国居民设宴灌醉齐国驻军，将驻军全部杀死。** 遂国虽然已经被齐国灭亡，当地宗族仍发动反抗。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，郑詹从齐国逃到鲁国。** 鲁国因此接纳了一名被齐扣押的郑国大夫。[[3]](#note-3)

<a id="event-4"></a>

4. **冬，鲁国出现大量麋鹿。** 这一异常自然现象被记录下来。[[4]](#note-4)

<a id="event-5"></a>

5. **周釐王去世，惠王阆继位。** 釐王死，儿子阆继位，即惠王。王室下一阶段的争端很快涉及宫室、园圃与大夫利益。 [原文与说明](#note-5)

<a id="event-6"></a>

6. **秦德公开始居雍，梁、芮两君来朝。** 德公居雍城大郑宫，以三百牢祭鄜畤，并为居雍占卜。梁伯、芮伯来朝，显示秦与邻国已有稳定使聘关系。 [原文与说明](#sj005-043-note)

<a id="sj014-0677-event"></a>

7. **晋武公去世，儿子诡诸承继晋侯之位，后来称晋献公。** 武公在曲沃长期执政，兼并翼地后的时间却很短；诡诸在父亲去世后继承国君位置，下一年才按《十二诸侯年表》纪作晋献公元年。 [[7]](#sj014-0677-note)

   **《左传·庄公十七年》**：“郑不朝也。”

<a id="note-2"></a>

2. **《春秋·庄公十七年》**：“夏，齐人歼于遂。”  
   **《左传·庄公十七年》**详记遂地四氏设宴灌醉齐戍并杀之。

<a id="note-3"></a>

3. **《春秋·庄公十七年》**：“秋，郑詹自齐逃来。”

<a id="note-4"></a>

## 补充史料与异说

<a id="sj005-043-note"></a>
### sj005-043｜秦德公开始居雍，梁、芮两君来朝。

[卷005 P014](../../sources/摘录/史记-卷005-秦本纪.md#p014)。

**说明：**“后子孙饮马于河”是占辞或后世应验叙法，不在前677年另造征服河西的行动。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj014-0677-note"></a>
### 卷014互见｜晋武公去世，儿子诡诸继位

[《十二诸侯年表》前677年晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0677)记「武公卒，子詭諸立」；[《晋世家·晋武公》](https://zh.wikisource.org/wiki/史記/卷039)同记子献公诡诸立。曲沃时期和成为晋侯后的在位统计口径不同，不把三十九年误算为并晋后三十九年。次年元年见[前676年](bce-0676.md#sj014-0676-event)。

# 公元前678年（鲁庄公十六年）

[← 上一张已编年页：公元前679年](bce-0679.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前677年 →](bce-0677.md)

<a id="event-1"></a>

1. **夏，宋、齐、卫联合伐郑，追究郑国上一年侵宋。** 郑厉公复位后与齐国主导的诸侯体系关系紧张。[[1]](#note-1)

<a id="event-2"></a>

2. **秋，楚国又伐郑，一直打到栎地。** 郑厉公此前从栎复位，却没有及时向楚国通报，楚国因此出兵问罪。[[2]](#note-2)

<a id="event-3"></a>

3. **郑厉公清算当年雍纠之乱的参与者。** 公子阏被杀，强鉏受刖刑，公父定叔逃到卫国；几年后厉公又让定叔回国，以免共叔段一支在郑国绝后。[[3]](#note-3)

<a id="event-4"></a>

4. **冬，齐桓公召集宋、陈、卫、郑、许、滑、滕等国在幽地举行大规模同盟，郑国重新与诸侯和解。** 齐国霸权进入更成熟阶段。[[4]](#note-4)

<a id="event-5"></a>

5. **同年，周王正式册命曲沃武公为晋侯。** 曲沃经过数代争位，终于取得晋国正统名号，旧翼政权彻底退出历史舞台。[[5]](#note-5)

[补充史料与年次说明](#sj005-041-note)


<a id="event-6"></a>

6. **邾子克去世。** 鲁国周边的邾国也发生君主更替。[[6]](#note-6)

<a id="event-7"></a>

7. **秦武公去世，以六十六人从死；继位者是弟弟德公。** 武公葬在雍平阳，其子白没有继位，而被封在平阳。秦君之位转到弟弟一支。 [原文与说明](#sj005-042-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公十六年》**：“夏，宋人、齐人、卫人伐郑。”  
   **《左传·庄公十六年》**：“诸侯伐郑，宋故也。”

<a id="note-2"></a>

2. **《春秋·庄公十六年》**：“秋，荆伐郑。”  
   **《左传·庄公十六年》**：“楚伐郑，及栎，为不礼故也。”

<a id="note-3"></a>

3. **《左传·庄公十六年》**详记郑厉公清算雍纠之乱参与者及后来复公父定叔。

<a id="note-4"></a>

4. **《春秋·庄公十六年》**：“冬十有二月，会齐侯、宋公、陈侯、卫侯、郑伯、许男、滑伯、滕子同盟于幽。”  
   **《左传·庄公十六年》**：“郑成也。”

<a id="note-5"></a>

5. **《左传·庄公十六年》**：“王使虢公命曲沃伯以一军为晋侯。”

<a id="note-6"></a>

6. **《春秋·庄公十六年》**：“邾子克卒。”

1. **宋齐卫与楚相继伐郑，郑后来盟于幽。** 夏，宋、齐、卫联军伐郑，追究郑上年侵宋。秋，楚军攻郑，深入栎地。冬十二月，齐桓公与宋、陈、卫、郑、许、滑、滕等国盟于幽，郑与盟国修好。 [[1]](#note-1)

<a id="event-3"></a>

2. **九月，郑厉公清算早年雍纠之乱的参与者，杀公子阏、刖强鉏，公父定叔出逃卫国。** 后来厉公又让定叔回国，以免共叔段一支在郑国无后；回国不是本年刚出逃就已发生。 [[2]](#note-3)

<a id="event-5"></a>

3. **周王派虢公正式册命曲沃伯，以一军的名额为晋侯。** 曲沃武公吞并翼地后，周王遣虢公正式册命他为晋侯，定礼为一军。 [[3]](#note-5)

<a id="event-6"></a>

4. **邾子克去世。** 鲁的邻国也发生君主更替。 [[4]](#note-6)

<a id="event-7"></a>

5. **秦武公去世，葬于雍平阳，以六十六人从死。** 弟弟德公继位，武公之子白没有接位，而被封在平阳。 [[5]](#note-7)

<a id="sj014-0678-deng"></a>

<a id="event-8"></a>

6. **楚文王再次攻邓，将邓灭亡。** 十年前伐申途经过邓，邓侯因亲属关系不肯听从大夫杀楚王的建议；过境、后来攻邓与这次灭国是不同阶段。 [[6]](#note-8)

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·庄公十六年》**：“夏，宋人、齐人、卫人伐郑。”  
   **《左传》**：“诸侯伐郑，宋故也。”[卷014本年郑栏](../../拆分史书/史记/卷014.md#y0678)“诸侯伐我”落在这次联合进攻，不与下文楚军行动合成完全同一支联军。

<a id="history-legacy-source-2"></a>

2. **《春秋·庄公十六年》**：“秋，荆伐郑。”  
   **《左传》**先说郑自栎入、缓告于楚，再记楚伐郑及栎。实际入郑是[前680年](bce-0680.md#event-3)，这里解释的是后续外交，不让厉公本年再入一次。

<a id="history-legacy-source-3"></a>

3. **《左传·庄公十六年》**记杀阏、刖强鉏、定叔奔卫，又回接后来“三年而复之”，并说以十月入。前段是本年出奔，后段保留相对时间说明，不将两步全归本年，也不将一段中不同层次的日期混为同日。是否另取绝对年须与后年条目核合，当前保留为后来经历。

<a id="history-legacy-source-4"></a>

4. **《春秋·庄公十六年》**：“冬十有二月，会齐侯、宋公、陈侯、卫侯、郑伯、许男、滑伯、滕子同盟于幽。”  
   **《左传》**：“郑成也。”

<a id="history-legacy-source-5"></a>

5. **《左传·庄公十六年》**：“王使虢公命曲沃伯以一军为晋侯。”[卷014本年晋栏](../../拆分史书/史记/卷014.md#y0678)说明并晋后“不更元，因其元年”，沿用曲沃时期年数，不是并晋后又过三十八年。[《读史记十表》卷二](../../拆分史书/读史记十表/异本/讀史記十表-卷二.md)另记录二十八、三十八一类年数问题，本轮不改源表，也不由保留一项王年推称整条晋国纪年已校定。

<a id="history-legacy-source-6"></a>

6. **《春秋·庄公十六年》**：“邾子克卒。”

### 补充史料与异说

<a id="sj014-0678-deng-note"></a>
<a id="卷014楚栏灭邓不倒填到十年前"></a>
#### 卷014楚栏｜灭邓不倒填到十年前

[卷014楚栏](../../拆分史书/史记/卷014.md#y0678)记“伐邓灭之”；[《楚世家》](../../拆分史书/史记/卷040.md#part-1-text)系文王十二年。[《左传·庄公六年》](../../拆分史书/左传/bce-0688.md)在过邓以后远接“十六年，楚复伐邓，灭之”，指鲁庄公十六年，而非再经过十六年。与[前688年过邓](bce-0688.md#event-5)分开，不添未记的战术、月份。

<a id="sj005-041-note"></a>
<a id="sj005-041受命年次的不同记载"></a>
#### sj005-041｜受命年次的不同记载

[卷005 P012](../../拆分史书/史记/卷005.md#p012)以武公十九年记曲沃命晋君，年表前679年也连叙受命。当前以经传本年具体王使作正式册命，前679年并国献宝为前段，不由两条受命文字造两次册命。

<a id="sj005-042-note"></a>
<a id="sj005-042秦武公葬与从死"></a>
#### sj005-042｜秦武公葬与从死

[卷005 P013](../../拆分史书/史记/卷005.md#p013)补六十六人、子白、德公继位，[卷014秦栏](../../拆分史书/史记/卷014.md#y0678)“葬雍，初以人从死”与之同事。初以人从死是此书秦君记载的起点，不扩大为全中国首次人殉；数字为文本记数。来年德公元年不重新记武公又死一次。[卷005纪年说明](../../拆分史书/史记/卷005.md#kao-c691f26620)。

# 公元前679年（鲁庄公十五年）

[← 上一张已编年页：公元前680年](bce-0680.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前678年 →](bce-0678.md)

<a id="event-1"></a>

1. **春，齐桓公再召宋、陈、卫、郑在鄄地会盟，齐国从此开始被视为诸侯霸主。** 连续两年会盟之后，齐国主导中原秩序的地位基本确立。[[1]](#note-1)

 [卷四互见与归年](#sj004-679-1)

[补充史料与年次说明](#sj005-040-note)


<a id="event-2"></a>

2. **夏，文姜前往齐国。** 她与齐国的往来直到晚年仍未中断。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，宋、齐、邾联合攻打郳国；郑国趁机侵宋。** 中原诸侯虽然处于齐国主导的盟会体系中，各国之间的旧怨仍在继续。[[3]](#note-3)

<a id="sj014-0679-event"></a>

4. **曲沃武公击败并消灭翼地晋侯缗的政权，长期分裂的晋国开始归于曲沃一支。** 曲沃一系从桓叔受封起已经与翼地晋侯争位数代，直到晋侯缗败亡才在实质上控制晋国。周王对曲沃武公的正式册命见下一年记事，不能把消灭翼地与获得周王认可混成同一个过程。 [[4]](#sj014-0679-note)

<a id="sj014-0679-zheng"></a>

5. **郑厉公突从栎地重新取得郑国君位，复位后另起纪年。** 他曾被迫离开国都，长期据守栎地。后来甫假诱杀郑子婴及其两个儿子，迎接厉公回国。原来的即位与出奔是更早的事，本年《十二诸侯年表》记的是厉公复位后的元年，不是他第一次成为国君。 [[5]](#sj014-0679-zheng-note)

## 补充史料与异说

<a id="sj014-0679-zheng-note"></a>
### 卷014郑栏｜郑厉公复位及后元年

[《十二诸侯年表》前679年郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0679)题郑厉公元年并说明出亡十七年后复入；[《郑世家》](https://zh.wikisource.org/wiki/史記/卷042)记甫假杀郑子婴及二子、迎厉公返国，继书“厉公突后元年，齐桓公始霸”。这与本年齐国鄄会相接。郑子婴被害的具体月日不据元年栏另加；复位后[前678年的行动](bce-0678.md#event-2)已经以厉公为在位国君。



<a id="sj005-040-note"></a>
### sj005-040｜同一事件的补充与取舍

[卷005 P012](../../sources/摘录/史记-卷005-秦本纪.md#p012)。

**说明：**齐桓公会鄄与曲沃受命在本纪连写；鄄盟仍归本年，晋侯正式册命依经传另归前678。

<a id="sj014-0679-note"></a>
### 卷014互见｜曲沃武公击灭翼地晋侯缗，晋国争位告终

[《十二诸侯年表》前679年晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0679)及[《晋世家·晋武公》](https://zh.wikisource.org/wiki/史記/卷039)将灭晋侯缗、献宝、周釐王命为晋君连叙；[《左传·庄公十六年》](../../sources/春秋左传/data/zz-03-16.json)在相当于前678年明确记王使虢公册命曲沃伯。正文区分本年实质并国和次年王命；有关先后及年次并不由一条年表即可完全解决。

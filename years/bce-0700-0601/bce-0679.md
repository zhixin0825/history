# 公元前679年（鲁庄公十五年）

[← 上一张已编年页：公元前680年](bce-0680.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前678年 →](bce-0678.md)

<a id="event-1"></a>

1. **春，齐桓公再会宋、陈、卫、郑于鄄，齐国开始确立诸侯盟主的地位。** 去年冬季的一次会盟接着本年春季再会，齐桓公协调诸侯的声势继续扩大。[[1]](#note-1) [卷四互见](#sj004-679-1) [秦本纪互见](#sj005-040-note)

<a id="event-2"></a>

2. **夏，文姜前往齐国。** 她与齐的来往仍未停止。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，宋、齐、邾联合攻郳，郑趁机侵宋。** 会盟没有使各国的旧怨立即消失。[[3]](#note-3)

<a id="sj014-0679-event"></a>

4. **曲沃武公消灭翼地晋侯缗的政权，晋国结束长期分立。** 他把所得宝器献给周王，寻求承认；正式王命在下一年的经传记录中出现。数代战争的并国结果，与天子的册命分阶段衔接。[[4]](#sj014-0679-note)

<a id="sj014-0679-zheng"></a>

5. **郑厉公复位后，重新起算元年。** 实际入郑、傅瑕杀子仪及二子、厉公反杀傅瑕并逼原繁自杀，已经发生在[前680年六月及其后](bce-0680.md#event-3)。本年不再重演一次政变，只承接复位后的计年。[[5]](#sj014-0679-zheng-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公十五年》**：“十五年春，齐侯、宋公、陈侯、卫侯、郑伯会于鄄。”  
   **《左传》**：“复会焉，齐始霸也。”[卷014齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0679)同记始霸会鄄。这里的霸是诸侯政治地位，不另造一次周王退位或齐桓公称天子。

<a id="sj004-679-1"></a>
#### 齐桓公始霸｜卷四互见

[卷004 P045](../../sources/摘录/史记-卷004-周本纪.md#p045)以周釐王三年记齐桓公始霸，落同一盟会。

<a id="note-2"></a>

2. **《春秋·庄公十五年》**：“夏，夫人姜氏如齐。”

<a id="note-3"></a>

3. **《春秋·庄公十五年》**：“秋，宋人、齐人、邾人伐郳。郑人侵宋。”  
   **《左传》**：“诸侯为宋伐郳。郑人间之而侵宋。”

## 补充史料与异说

<a id="sj014-0679-zheng-note"></a>
### 卷014郑栏｜后元年不是再复位一次

[卷014本年郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0679)题“郑厉公元年”，回说亡后十七岁复入；[《郑世家》](https://zh.wikisource.org/wiki/史記/卷042)亦先叙甫假迎入、后书“厉公突后元年”。以[《左传》庄公十四年六月甲子](bce-0680.md#note-3)定位实际迎入，本年只计后元。旧页重复叙迎立细节现改回链，原锚点保留。甫假／傅瑕、子婴／子仪按互见识别，不多算两位叛臣或两位郑君；“十七岁”是表的年数，不据此制造月日。

<a id="sj005-040-note"></a>
### sj005-040｜齐会鄄与曲沃受命

[卷005 P012](../../sources/摘录/史记-卷005-秦本纪.md#p012)将鄄会、曲沃受命连叙。本页保留鄄会，正式册命按经传另见[前678年](bce-0678.md#event-5)。

<a id="sj014-0679-note"></a>
### 卷014晋栏｜并国、献宝与王命

[卷014晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0679)和[《晋世家》](https://zh.wikisource.org/wiki/史記/卷039)连叙灭缗、献宝、周命晋君。[《左传·庄公十六年》](../../sources/春秋左传/data/zz-03-16.json)另在前678年明确记王使虢公命曲沃伯。本次补献宝这一中间环节，仍区分实质并国和正式承认；两套纪年不因分阶段处理就已全部消除。晋侯缗的早年王年与经传仍有错位，未在本批重排整条晋君在位序列。

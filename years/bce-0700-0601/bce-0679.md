# 公元前679年（鲁庄公十五年）

[← 上一张已编年页：公元前680年](bce-0680.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前678年 →](bce-0678.md)

<a id="event-1"></a>

1. **春，齐桓公再召宋、陈、卫、郑在鄄地会盟，齐国从此开始被视为诸侯霸主。** 连续两年会盟之后，齐国主导中原秩序的地位基本确立。[[1]](#note-1)

 [卷四互见与归年](#sj004-679-1)


<a id="event-2"></a>

2. **夏，文姜前往齐国。** 她与齐国的往来直到晚年仍未中断。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，宋、齐、邾联合攻打郳国；郑国趁机侵宋。** 中原诸侯虽然处于齐国主导的盟会体系中，各国之间的旧怨仍在继续。[[3]](#note-3)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公十五年》**：“十五年春，齐侯、宋公、陈侯、卫侯、郑伯会于鄄。”  
   **《左传·庄公十五年》**：“复会焉，齐始霸也。”

<a id="sj004-679-1"></a>
#### 齐桓公称霸的周王年｜卷四互见

[卷004 P045](../../sources/摘录/史记-卷004-周本纪.md#p045)。 本纪以釐王三年概括齐桓公始霸，与现有前679年鄄盟相接；不把“霸”理解为周王在本年让出天子称号。


<a id="note-2"></a>

2. **《春秋·庄公十五年》**：“夏，夫人姜氏如齐。”

<a id="note-3"></a>

3. **《春秋·庄公十五年》**：“秋，宋人、齐人、邾人伐郳。郑人侵宋。”  
   **《左传·庄公十五年》**：“诸侯为宋伐郳。郑人间之而侵宋。”

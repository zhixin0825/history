# 公元前680年（鲁庄公十四年）

[← 上一张已编年页：公元前681年](bce-0681.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前679年 →](bce-0679.md)

<a id="event-1"></a>

1. **春，齐、陈、曹联合伐宋，追究宋国背弃北杏盟会。** 齐国又请求周王室派兵参与，夏天单伯也加入联军。[1]

<a id="event-2"></a>

2. **宋国最终重新服从会盟秩序，联军与宋讲和后撤退。** 齐桓公对中原诸侯的组织能力进一步增强。[2]

<a id="event-3"></a>

3. **郑厉公从栎地反攻郑国，俘获傅瑕；傅瑕答应帮助他复位，随后杀郑子及其二子，迎厉公入郑。** 厉公复位后却立即杀傅瑕，并逼原繁自杀，郑国内部多年争位告一段落。[3]

<a id="event-4"></a>

4. **楚文王借蔡哀侯之口得知息妫美貌，灭掉息国并把息妫带回楚国。** 息妫后来生堵敖和楚成王；她长期沉默，称自己一妇人事二夫，无颜多言。[4]

<a id="event-5"></a>

5. **秋，楚军又攻入蔡国。** 蔡哀侯原本想借楚报复息国，最终反而把楚国势力引向自己。[5]

<a id="event-6"></a>

6. **冬，齐桓公再次召集宋、卫、郑等诸侯在鄄地会盟，宋国正式回到齐国主导的秩序中。** 齐国霸业轮廓已经形成。[6]

## 本年相关史料

1. **《春秋·庄公十四年》**：“十四年春，齐人、陈人、曹人伐宋。夏，单伯会伐宋。”  
   **《左传·庄公十四年》**：“诸侯伐宋，齐请师于周。”

<a id="note-2"></a>

2. **《左传·庄公十四年》**：“夏，单伯会之，取成于宋而还。”

<a id="note-3"></a>

3. **《左传·庄公十四年》**详记郑厉公从栎反攻，傅瑕杀郑子迎厉公，厉公随后杀傅瑕，原繁自缢。

<a id="note-4"></a>

4. **《左传·庄公十四年》**详记楚灭息、纳息妫及息妫答楚王之语。

<a id="note-5"></a>

5. **《春秋·庄公十四年》**：“秋七月，荆入蔡。”  
   **《左传·庄公十四年》**：“楚子以蔡侯灭息，遂伐蔡。”

<a id="note-6"></a>

6. **《春秋·庄公十四年》**：“冬，单伯会齐侯、宋公、卫侯、郑伯于鄄。”  
   **《左传·庄公十四年》**：“宋服故也。”

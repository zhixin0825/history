1. **齐请王师讨宋，宋求和后会诸侯于鄄。** 春，齐、陈、曹联合攻宋，追究宋背北杏之约。齐向周请援，夏日单伯率王师加入。联军与宋讲和后撤兵，宋重入盟约。冬，单伯与齐侯、宋公、卫侯、郑伯会于鄄。 [[1]](#note-1)

<a id="event-3"></a>

2. **郑厉公从栎出兵，俘获傅瑕；傅瑕许诺纳君，六月甲子杀郑子仪及其二子，迎厉公入郑。** 厉公随即杀掉帮助自己复位的傅瑕，又因原繁不愿背弃此前所奉之君而逼他自杀。多年争位以一连串杀戮告一阶段。 傅瑕被诱捕时许诺，若厉公放他回去，自己便杀郑子、迎厉公；厉公与他盟誓后释放了他。厉公入国后责原繁身为伯父却不迎自己，原繁答臣子不可有二心，遂自杀；厉公又用同样的“不应二心”理由杀傅瑕，傅瑕临终叹厚恩不能得报。此时人们把六年前郑南门内外两蛇争斗、内蛇死的异象，与厉公重新入国联系起来；这是事后的征兆解释。 [[2]](#note-3)

<a id="event-4"></a>

<a id="event-5"></a>

3. **楚文王灭息，随后出兵攻蔡。** 楚文王听蔡哀侯称说息妫之美，进入息国，灭息并带走息妫。秋七月，楚军又攻入蔡国。 [[3]](#note-4)

### 2. 郑厉公从栎出兵，俘获傅瑕；傅瑕许诺纳君，六月甲子杀郑子仪及其二子，迎厉公入郑

[返回正文第2条](#event-3)

**[《左传》鲁庄公14年传文（前680年）](../../拆分史书/左传/bce-0680.md#batch-20261109-t003)**

> 郑厉公自栎侵郑，及大陵，获傅瑕。傅瑕曰：“苟舍我，吾请纳君。”与之盟而赦之。六月甲子，傅瑕杀郑子及其二子而纳厉公。

**[《左传》鲁庄公14年传文（前680年）](../../拆分史书/左传/bce-0680.md#batch-20261109-t005)**

> 厉公入，遂杀傅瑕。使谓原繁曰：“傅瑕贰，周有常刑，既伏其罪矣。纳我而无二心者，吾皆许之上大夫之事，吾愿与伯父图之。且寡人出，伯父无里言；入，又不念寡人，寡人憾焉。”对曰：“先君桓公命我先人典司宗祏。社稷有主而外其心，其何贰如之？苟主社稷，国内之民其谁不为臣？臣无二心，天之制也。子仪在位十四年矣，而谋召君者，庸非贰乎。庄公之子犹有八人，若皆以官爵行赂，劝贰而可以济事，君其若之何？臣闻命矣。”乃缢而死。

[史料说明](#history-legacy-source-3)

<a id="sj042-cite-039"></a>

**[《史记·郑世家》P014](../../拆分史书/史记/卷042.md#p014)**

> 十四年，故鄭亡厲公突在櫟者使人誘劫鄭大夫甫假，要以求入。假曰：「捨我，我為君殺鄭子而入君。」厲公與盟，乃捨之。六月甲子，假殺鄭子及其二子而迎厲公突，突自櫟復入即位。初，內蛇與外蛇鬬於鄭南門中，內蛇死。居六年，厲公果復入。入而讓其伯父原曰：「我亡國外居，伯父無意入我，亦甚矣。」原曰：「事君無二心，人臣之職也。原知罪矣。」遂自殺。厲公於是謂甫假曰：「子之事君有二心矣。」遂誅之。假曰：「重德不報，誠然哉！」

**本卷说明：** 甫假、甫瑕、傅瑕在本事互见，原与原繁为同人。六年前蛇斗只保留为本段回叙及事后解释，不据此新编一条已确年的自然事件。

<a id="sj042-cite-146"></a>

**[《史记·郑世家》P057](../../拆分史书/史记/卷042.md#p057)**

> 太史公曰：語有之，「以權利合者，權利盡而交疏」，甫瑕是也。甫瑕雖以劫殺鄭子內厲公，厲公終背而殺之，此與晉之裏克何異？守節如荀息，身死而不能存奚齊。變所從來，亦多故矣！

**本卷说明：** 本段是汉代司马迁的篇末史论，解释甫瑕、里克的利害之交，并以荀息守节仍未能保奚齐作对照；不计为前680的一次发言或新事件。

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·庄公十四年》**：“十四年春，齐人、陈人、曹人伐宋。夏，单伯会伐宋。”  
   **《左传》**：“诸侯伐宋，齐请师于周。”本条确有向周请师的叙述，不能因此倒推所有年份的单伯都必以完全同一派遣形式出场。

<a id="history-legacy-source-2"></a>

2. **《左传·庄公十四年》**：“夏，单伯会之，取成于宋而还。”

<a id="history-legacy-source-3"></a>

3. [**《左传·庄公十四年》**](../../拆分史书/左传/异本/春秋左氏傳-莊公.md#%E8%8E%8A%E5%85%AC%E5%8D%81%E5%9B%9B%E5%B9%B4)明确六月甲子纳厉公，傅瑕、原繁随后死亡。[《郑世家》](../../拆分史书/史记/卷042.md#part-1-text)称甫假、子婴，为本段傅瑕、子仪的异称；继书“厉公突后元年，齐桓公始霸”。因此实际复位保留本年，年表的[前679年后元年](bce-0679.md#sj014-0679-zheng)只作计年衔接，不再重复迎立及三人死亡。

<a id="history-legacy-source-4"></a>

4. **《左传·庄公十四年》**以蔡侯报莘之怨串连息妫、灭息、后来的生子与答语。[前684年莘战](bce-0684.md#event-5)是前因，不将其俘蔡侯再次写成本年。堵敖与成王的出生具体年次不能仅靠本段确定，两子后来的王号也不表示此时已各自执政。

<a id="history-legacy-source-5"></a>

5. **《春秋·庄公十四年》**：“秋七月，荆入蔡。”  
   **《左传》**：“楚子以蔡侯灭息，遂伐蔡。”

<a id="history-legacy-source-6"></a>

6. **《春秋·庄公十四年》**：“冬，单伯会齐侯、宋公、卫侯、郑伯于鄄。”  
   **《左传》**：“宋服故也。”次年春再会鄄是另一场已明确分年的会盟，不能因地点相同就删去其中一场。

# 公元前680年（鲁庄公十四年）

[← 上一张已编年页：公元前681年](bce-0681.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前679年 →](bce-0679.md)

<a id="event-1"></a>

1. **春，齐、陈、曹联合攻宋，追究宋背弃北杏之会；齐又请周王室出兵，夏天单伯加入。** 对宋施压由诸侯联军发展为借王室名义出面。[[1]](#note-1)

<a id="event-2"></a>

2. **联军与宋讲和后撤退，宋重新回到会盟关系之中。** 齐国的协调能力进一步增强。[[2]](#note-2)

<a id="event-3"></a>

3. **郑厉公从栎出兵，俘获傅瑕；傅瑕许诺纳君，六月甲子杀郑子仪及其二子，迎厉公入郑。** 厉公随即杀掉帮助自己复位的傅瑕，又因原繁不愿背弃此前所奉之君而逼他自杀。多年争位以一连串杀戮告一阶段。[[3]](#note-3)

<a id="event-4"></a>

4. **楚文王听蔡哀侯称说息妫之美，进入息国，灭息并带走息妫。** 此后她生下堵敖、成王，在传世叙述中长久不语，向楚王解释自己一妇人事二夫、无颜再说话。这些生育和谈话是往后经历的连叙，不一律当成本年已经全部发生。[[4]](#note-4)

<a id="event-5"></a>

5. **秋七月，楚军又攻入蔡国。** 蔡哀侯原想借楚报复息侯，结果楚灭息以后仍转来攻蔡。[[5]](#note-5)

<a id="event-6"></a>

6. **冬，单伯会同齐侯、宋公、卫侯、郑伯在鄄结会。** 宋服从了这次重新确立的盟会安排。[[6]](#note-6)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公十四年》**：“十四年春，齐人、陈人、曹人伐宋。夏，单伯会伐宋。”  
   **《左传》**：“诸侯伐宋，齐请师于周。”本条确有向周请师的叙述，不能因此倒推所有年份的单伯都必以完全同一派遣形式出场。

<a id="note-2"></a>

2. **《左传·庄公十四年》**：“夏，单伯会之，取成于宋而还。”

<a id="note-3"></a>

3. [**《左传·庄公十四年》**](https://zh.wikisource.org/wiki/春秋左氏傳/莊公#莊公十四年)明确六月甲子纳厉公，傅瑕、原繁随后死亡。[《郑世家》](https://zh.wikisource.org/wiki/史記/卷042)称甫假、子婴，为本段傅瑕、子仪的异称；继书“厉公突后元年，齐桓公始霸”。因此实际复位保留本年，年表的[前679年后元年](bce-0679.md#sj014-0679-zheng)只作计年衔接，不再重复迎立及三人死亡。

<a id="note-4"></a>

4. **《左传·庄公十四年》**以蔡侯报莘之怨串连息妫、灭息、后来的生子与答语。[前684年莘战](bce-0684.md#event-5)是前因，不将其俘蔡侯再次写成本年。堵敖与成王的出生具体年次不能仅靠本段确定，两子后来的王号也不表示此时已各自执政。

<a id="note-5"></a>

5. **《春秋·庄公十四年》**：“秋七月，荆入蔡。”  
   **《左传》**：“楚子以蔡侯灭息，遂伐蔡。”

<a id="note-6"></a>

6. **《春秋·庄公十四年》**：“冬，单伯会齐侯、宋公、卫侯、郑伯于鄄。”  
   **《左传》**：“宋服故也。”次年春再会鄄是另一场已明确分年的会盟，不能因地点相同就删去其中一场。

1. **齐桓公会诸侯于北杏，宋随后背盟。** 春，齐桓公与宋、陈、蔡、邾会于北杏，调停宋国内乱。宋国随后背弃会约。 [[1]](#reading-note-1)

<a id="reading-event-2"></a>

2. **夏六月，齐灭遂，留下驻军。** 齐桓公用军事行动惩罚没有赴会的一方。 [[2]](#reading-note-2)

3. **鲁齐会盟于柯，曹沫索还鲁地。** 曹沫曾领鲁军与齐交战，三次战败，鲁君献遂求和，仍用曹沫为将。冬，鲁庄公与齐桓公在柯会盟，曹沫持匕首胁迫齐桓公退还鲁地。齐桓公答允后，曹沫放下兵器回到臣位。桓公事后欲反悔，管仲劝他勿为小利失信于诸侯，齐遂归还鲁地。 [[3]](#reading-note-3)

   列传的“遂邑”与本年齐灭的遂国，不仅凭同字便认定为同一政治实体；三败也不擅自与每一场经传战役强配。

**[《史记·齐太公世家》P033](../../拆分史书/史记/卷032.md#p033)**

> 五年，伐魯，魯將師敗。魯莊公請獻遂邑以平，桓公許，與魯會柯而盟。魯將盟，曹沬以匕首劫桓公於壇上，曰：「反魯之侵地！」桓公許之。已而曹沬去匕首，北面就臣位。桓公後悔，欲無與魯地而殺曹沬。管仲曰：「夫劫許之而倍信殺之，愈一小快耳，而棄信於諸侯，失天下之援，不可。」於是遂與曹沬三敗所亡地於魯。諸侯聞之，皆信齊而欲附焉。

**读法与异说：** 曹沫胁盟属《史记》独有的详细叙述；不由同姓或近音自动认定为长勺曹刿。

## 归年与考证

<a id="history-legacy-source-1"></a>
<a id="note-1"></a>

1. **《春秋·庄公十三年》**：“十有三年春，齐侯、宋人、陈人、蔡人、邾人会于北杏。”  
   **《左传》**：“会于北杏以平宋乱，遂人不至。”不把经文中的“某国人”全改成国君本人。

<a id="history-legacy-source-2"></a>
<a id="note-2"></a>

2. **《春秋·庄公十三年》**：“夏六月，齐人灭遂。”  
   **《左传》**：“齐人灭遂而戍之。”几年后驻军被杀见[前677年](bce-0677.md#event-2)，并非同一结局重复。

<a id="history-legacy-source-3"></a>
<a id="note-3"></a>

3. **《春秋·庄公十三年》**：“冬，公会齐侯，盟于柯。”  
   **《左传》**：“盟于柯，始及齐平也。”

   [卷014鲁、齐栏](../../拆分史书/史记/卷014.md#y0681)分别记曹沫劫盟反地、会柯。本轮把原先仅放在史料区的持刃索地经过移到正文，旧锚点不变；同一盟会不计两次。匕首胁迫与管仲劝约见[《刺客列传》](../../拆分史书/史记/卷086.md#part-1-text)、[《管晏列传》](../../拆分史书/史记/卷062.md#part-1-text)，经传只记会盟，不载这些细节。采用史记所存故事补充，而不称几个同书篇章就是数份独立证词，也不据曹沫、曹刿名字相似就把两人的全部经历合并。

<a id="history-legacy-source-4"></a>
<a id="note-4"></a>

4. **《左传·庄公十三年》**：“宋人背北杏之会。”

<a id="sj014-0681-zhou-note"></a>

5. [**卷014周栏**](../../拆分史书/史记/卷014.md#y0681)“釐王元年”，接[前682年死亡与继承](bce-0682.md#sj004-682-1)，不能据元年补出另一即位日。

<a id="sj014-0681-song-note"></a>

6. [**卷014宋栏**](../../拆分史书/史记/卷014.md#y0681)“宋桓公御说元年，庄公子”，接[前682年平乱](bce-0682.md#event-3)。宋庄公、闵公、桓公是前后不同国君，不能把前683年答辞的作者御说提前写成当时国君。

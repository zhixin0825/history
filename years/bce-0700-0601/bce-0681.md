2. **夏六月，齐灭遂，留下驻军。** 齐桓公用军事行动惩罚没有赴会的一方。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **冬，鲁庄公与齐桓公在柯结盟，鲁齐恢复和平。** 两国经历争夺齐位、乾时与长勺等战事，转到重新结约的阶段。 [[3]](#reading-note-3)

<a id="reading-event-4"></a>

4. **曹沫曾为鲁庄公带兵，与齐作战三次失败。** 庄公害怕齐军，献遂邑求和，却仍然任曹沫为将。 [[4]](#reading-note-4)

   [《刺客列传》旧摘录](../../sources/摘录/史记-条目原文.md#ref-sj-5381) · [原未定年记录](../../meta/考证/史记-未定年与跨年材料.md#sj-086-L5381-01)。列传的“遂邑”与本年齐灭的遂国，不仅凭同字便认定为同一政治实体；三败也不擅自与每一场经传战役强配。

6. **宋国随后背弃北杏之会。** 齐桓公将再联合其他诸侯对宋施压。 [[6]](#reading-note-6)

<a id="reading-event-7"></a>

> 齊桓公許與魯會于柯而盟。桓公與莊公既盟於壇上，曹沫執匕首劫齊桓公，桓公左右莫敢動，而問曰：「子將何欲？」曹沫曰：「齊彊魯弱，而大國侵魯亦甚矣。今魯城壞即壓齊境，君其圖之。」桓公乃許盡歸魯之侵地。既已言，曹沫投其匕首，下壇，北面就群臣之位，顏色不變，辭令如故。桓公怒，欲倍其約。管仲曰：「不可。夫貪小利以自快，棄信於諸侯，失天下之援，不如與之。」於是桓公乃遂割魯侵地，曹沫三戰所亡地盡復予魯。

## 归年与考证

<a id="history-legacy-source-1"></a>
<a id="note-1"></a>

1. **《春秋·庄公十三年》**：“十有三年春，齐侯、宋人、陈人、蔡人、邾人会于北杏。”  
   **《左传》**：“会于北杏以平宋乱，遂人不至。”不把经文中的“某国人”全改成国君本人。

<a id="history-legacy-source-2"></a>
<a id="note-2"></a>

2. **《春秋·庄公十三年》**：“夏六月，齐人灭遂。”  
   **《左传》**：“齐人灭遂而戍之。”几年后驻军被杀见[前677年](bce-0677.md#event-2)，并非同一结局重复。

<a id="history-legacy-source-3"></a>
<a id="note-3"></a>

3. **《春秋·庄公十三年》**：“冬，公会齐侯，盟于柯。”  
   **《左传》**：“盟于柯，始及齐平也。”

   [卷014鲁、齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0681)分别记曹沫劫盟反地、会柯。本轮把原先仅放在史料区的持刃索地经过移到正文，旧锚点不变；同一盟会不计两次。匕首胁迫与管仲劝约见[《刺客列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7086.md#ref-b61700742d2b90)、[《管晏列传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7062.md#ref-ddf527566ebfdd)，经传只记会盟，不载这些细节。采用史记所存故事补充，而不称几个同书篇章就是数份独立证词，也不据曹沫、曹刿名字相似就把两人的全部经历合并。

<a id="history-legacy-source-4"></a>
<a id="note-4"></a>

4. **《左传·庄公十三年》**：“宋人背北杏之会。”

<a id="sj014-0681-zhou-note"></a>

5. [**卷014周栏**](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0681)“釐王元年”，接[前682年死亡与继承](bce-0682.md#sj004-682-1)，不能据元年补出另一即位日。

<a id="sj014-0681-song-note"></a>

6. [**卷014宋栏**](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0681)“宋桓公御说元年，庄公子”，接[前682年平乱](bce-0682.md#event-3)。宋庄公、闵公、桓公是前后不同国君，不能把前683年答辞的作者御说提前写成当时国君。

### 登场前事｜曹沫此前战败与求和

> 以下是《刺客列传》在柯盟以前叙述的经历，各次战役没有分别确年，不都发生在前681年。

# 公元前681年（鲁庄公十三年）

[← 上一张已编年页：公元前682年](bce-0682.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前680年 →](bce-0680.md)

<a id="event-1"></a>

1. **春，齐桓公与宋、陈、蔡、邾各方会于北杏，调停宋国内乱。** 遂国没有赴会。[[1]](#note-1)

<a id="event-2"></a>

2. **夏六月，齐灭遂，留下驻军。** 齐桓公用军事行动惩罚没有赴会的一方。[[2]](#note-2)

<a id="event-3"></a>

3. **冬，鲁庄公与齐桓公在柯结盟，鲁齐恢复和平。** 两国经历争夺齐位、乾时与长勺等战事，转到重新结约的阶段。[[3]](#note-3)

<a id="backstory-sj-086-L5381-01"></a>
#### 登场前事｜曹沫此前战败与求和

> 以下是《刺客列传》在柯盟以前叙述的经历，各次战役没有分别确年，不都发生在前681年。

曹沫曾为鲁庄公带兵，与齐作战三次失败。庄公害怕齐军，献遂邑求和，却仍然任曹沫为将。

[《刺客列传》旧摘录](../../sources/摘录/史记-条目原文.md#ref-sj-5381) · [原未定年记录](../../meta/考证/史记-未定年与跨年材料.md#sj-086-L5381-01)。列传的“遂邑”与本年齐灭的遂国，不仅凭同字便认定为同一政治实体；三败也不擅自与每一场经传战役强配。

<a id="sj-062-L4595-03"></a>
#### 柯盟的歃盟前后｜曹沫索地，管仲劝守约

**曹沫在盟坛上持匕首胁迫齐桓公，要求归还侵占的鲁地。** 桓公应允后，曹沫放下兵器回到臣位。桓公后来想反悔，管仲劝他不要为小利失信于诸侯，齐最终归还曹沫此前战败所失之地。[[3]](#note-3)

[《管晏列传》旧摘录](../../sources/摘录/史记-条目原文.md#ref-sj-4595) · [《刺客列传》旧摘录](../../sources/摘录/史记-条目原文.md#ref-sj-5382) · [《春秋》旧定位](../../sources/摘录/史记-条目原文.md#ref-cq-3-13)

<!-- backstory-end:sj-062-L4595-03 -->

<a id="event-4"></a>

4. **宋国随后背弃北杏之会。** 齐桓公将再联合其他诸侯对宋施压。[[4]](#note-4)

<a id="sj014-0681-zhou"></a>

5. **周釐王胡齐开始以元年纪事。** 周庄王前一年去世，胡齐已承位；这里是新君计年的开始。[[5]](#sj014-0681-zhou-note)

<a id="sj014-0681-song"></a>

6. **宋桓公御说进入在位元年。** 他是庄公之子，前一年平乱后被拥立，本年起算纪年。[[6]](#sj014-0681-song-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公十三年》**：“十有三年春，齐侯、宋人、陈人、蔡人、邾人会于北杏。”  
   **《左传》**：“会于北杏以平宋乱，遂人不至。”不把经文中的“某国人”全改成国君本人。

<a id="note-2"></a>

2. **《春秋·庄公十三年》**：“夏六月，齐人灭遂。”  
   **《左传》**：“齐人灭遂而戍之。”几年后驻军被杀见[前677年](bce-0677.md#event-2)，并非同一结局重复。

<a id="note-3"></a>

3. **《春秋·庄公十三年》**：“冬，公会齐侯，盟于柯。”  
   **《左传》**：“盟于柯，始及齐平也。”

   [卷014鲁、齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0681)分别记曹沫劫盟反地、会柯。本轮把原先仅放在史料区的持刃索地经过移到正文，旧锚点不变；同一盟会不计两次。匕首胁迫与管仲劝约见[《刺客列传》](https://zh.wikisource.org/wiki/史記/卷086)、[《管晏列传》](https://zh.wikisource.org/wiki/史記/卷062)，经传只记会盟，不载这些细节。采用史记所存故事补充，而不称几个同书篇章就是数份独立证词，也不据曹沫、曹刿名字相似就把两人的全部经历合并。

<a id="note-4"></a>

4. **《左传·庄公十三年》**：“宋人背北杏之会。”

<a id="sj014-0681-zhou-note"></a>

5. [**卷014周栏**](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0681)“釐王元年”，接[前682年死亡与继承](bce-0682.md#sj004-682-1)，不能据元年补出另一即位日。

<a id="sj014-0681-song-note"></a>

6. [**卷014宋栏**](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0681)“宋桓公御说元年，庄公子”，接[前682年平乱](bce-0682.md#event-3)。宋庄公、闵公、桓公是前后不同国君，不能把前683年答辞的作者御说提前写成当时国君。

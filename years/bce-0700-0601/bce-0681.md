# 公元前681年（鲁庄公十三年）

[← 上一张已编年页：公元前682年](bce-0682.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前680年 →](bce-0680.md)

<a id="event-1"></a>

1. **春，齐桓公召集宋、陈、蔡、邾等诸侯在北杏会盟，调停宋国内乱。** 遂国没有赴会。[1]

<a id="event-2"></a>

2. **夏六月，齐国灭遂，并在当地驻军。** 齐桓公开始以会盟和军事惩罚建立新的诸侯秩序。[2]

<a id="event-3"></a>

3. **冬，鲁庄公与齐桓公在柯地结盟，鲁齐关系正式恢复和平。** 鲁国从乾时战败、长勺反击一路走到重新与齐结盟。[3]


<a id="backstory-sj-086-L5381-01"></a>

#### 登场前事｜曹沫：曹沫三次战败，鲁国献地求和

> 此前经历，确切年月未详；放在这里补叙，不表示发生于前681年。

曹沫为鲁庄公统兵，与齐作战三次失败。鲁庄公畏惧齐军，献出遂邑之地求和，但仍让曹沫做将领。

[《史记》卷86 刺客列传](../../sources/摘录/史记-条目原文.md#ref-sj-5381)

<details><summary>补叙依据</summary>

本传先说三次战败、献地求和并继续任将，继而说齐鲁会盟于柯；战败次数保留，不将三次战事压成前681年的一次事件。

[原记录](../../meta/考证/史记-未定年与跨年材料.md#sj-086-L5381-01)

</details>




<a id="event-4"></a>

4. **宋国随后背弃北杏之会。** 齐桓公下一步将联合诸侯再次对宋施压。[4]

<a id="sj-062-L4595-03"></a>

#### 补充互见｜柯地结盟：曹沫要求归地，管仲劝桓公守约

**时间：鲁庄公十三年冬** · 事件

齐、鲁在柯会盟。《刺客列传》说，曹沫在盟坛上逼齐桓公答应归还侵占的鲁地。事后桓公想反悔，管仲劝他不要为一时小利失信于诸侯，齐国最终履约。

[《史记》卷62 管晏列传](../../sources/摘录/史记-条目原文.md#ref-sj-4595) · [《史记》卷86 刺客列传](../../sources/摘录/史记-条目原文.md#ref-sj-5382) · [《春秋》 鲁庄公13年](../../sources/摘录/史记-条目原文.md#ref-cq-3-13)

<details><summary>归年依据、同书互见与待核问题</summary>

合并两篇《史记》的同一事件；《春秋》仅记会盟，没有匕首胁迫细节。细节有来源，不等于两份独立见证。

</details>

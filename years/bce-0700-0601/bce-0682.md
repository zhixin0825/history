# 公元前682年（鲁庄公十二年）

[← 上一张已编年页：公元前683年](bce-0683.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前681年 →](bce-0681.md)

<a id="event-1"></a>

1. **春，纪叔姬回到酅地。** 纪国虽然已经瓦解，纪氏仍保留一部分宗族和土地。[[1]](#note-1)

<a id="event-2"></a>

2. **秋八月，宋将南宫万杀死宋闵公，又杀大夫仇牧和太宰华父督，拥立子游。** 宋国内部爆发政变，公族多人外逃。[[2]](#note-2)

<a id="event-3"></a>

3. **宋国反对南宫万的一方很快联合曹军反攻。** 萧叔大心与宋国各公族杀南宫牛、子游，另立宋桓公，政变政权迅速崩溃。[[3]](#note-3)

<a id="event-4"></a>

4. **南宫万逃到陈国，猛获逃到卫国；宋国分别向两国索人，两人最终都被交回处死。** 南宫万被陈人灌醉后裹在犀革中送还宋国，最后遭到醢刑。[[4]](#note-4)

<a id="event-5"></a>

5. **周庄王去世，胡齐继位。** 庄王死后，儿子胡齐接位，即釐王。齐国、宋国的政变之外，周王室也发生了王位承继。 [原文与说明](#note-5)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公十二年》**：“十有二年春，王三月，纪叔姬归于酅。”

<a id="note-2"></a>

2. **《春秋·庄公十二年》**：“秋八月甲午，宋万弑其君捷，及其大夫仇牧。”  
   **《左传·庄公十二年》**详记南宫万又杀太宰督、立子游。

<a id="note-3"></a>

3. **《左传·庄公十二年》**详记萧叔大心联合戴、武、宣、穆、庄诸族和曹军反攻，杀南宫牛、子游，立宋桓公。

<a id="note-4"></a>

4. **《春秋·庄公十二年》**：“冬十月，宋万出奔陈。”  
   **《左传·庄公十二年》**详记卫归猛获、陈归南宫万及其最终被处死。

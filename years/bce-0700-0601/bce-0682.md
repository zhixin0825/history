# 公元前682年（鲁庄公十二年）

[← 上一张已编年页：公元前683年](bce-0683.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前681年 →](bce-0681.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，纪叔姬回到酅地。** 纪国虽已瓦解，宗族仍保留一部分土地与祭祀。 [[1]](#note-1)

<a id="event-2"></a>

2. **秋八月，南宫万杀宋闵公，又杀仇牧和太宰华父督，拥立子游。** 仇牧闻乱赶到宫门，与南宫万相遇而被杀；宋国公族纷纷出走，公子御说逃往亳，叛军又围攻亳地。 君臣矛盾还与狩猎、博戏中的羞辱相连：闵公以长万曾被鲁俘辱之，长万以博局击杀国君。 [[2]](#note-2)

<a id="event-3"></a>

3. **冬，萧叔大心联合宋国各公族与曹国军队反攻，杀南宫牛、子游，拥立御说，是为宋桓公。** 南宫万一方没有守住新政权。 [[3]](#note-3)

<a id="event-4"></a>

4. **南宫万逃到陈国，猛获逃到卫国，宋国分别索人。** 两人被交回后遭处死，南宫万先被陈人灌醉，用犀革裹住送宋，最后遭醢刑。 [[4]](#note-4)

<a id="event-5"></a>

5. **周庄王去世，儿子胡齐继位，即周釐王。** 宋国内乱之外，周王室也发生继承。 [[5]](#note-5)

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·庄公十二年》**：“十有二年春，王三月，纪叔姬归于酅。”

<a id="history-legacy-source-2"></a>

2. **《春秋·庄公十二年》**：“秋八月甲午，宋万弑其君捷，及其大夫仇牧。”  
   **《左传》**详载仇牧闻乱趋君、遇于门，太宰督也被杀，子游立，公族出亡。

   [卷014本年宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0682)“万杀君，仇牧有义”中的“有义”是对仇牧的评价。本轮补出他闻乱赴宫的行动来由，把褒评留注，不另外生成一次仇牧“死义”的事件，也不把后代对忠义的褒扬当作编者要求他人赴死。

<a id="history-legacy-source-3"></a>

3. **《左传·庄公十二年》**详列戴、武、宣、穆、庄诸族及曹师，冬十月杀南宫牛、子游而立桓公。次年[宋桓公元年](bce-0681.md#sj014-0681-song)是继立后的计年，不是又拥立一次。

<a id="history-legacy-source-4"></a>

4. **《春秋·庄公十二年》**：“冬十月，宋万出奔陈。”  
   **《左传》**保存卫交猛获、陈交南宫万的过程，不能由“获”“万”的简称另造不同人。醢为文本所记刑罚，不追加未载的行刑细节。

# 公元前683年（鲁庄公十一年）

[← 上一张已编年页：公元前684年](bce-0684.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前682年 →](bce-0682.md)

<a id="event-1"></a>

1. **夏五月，宋军为报乘丘之败再次侵鲁，鲁军趁宋军尚未列阵，在鄑地将其击败。** 鲁宋战争继续。[[1]](#note-1)

<a id="event-2"></a>

2. **秋，宋国发生大水，鲁庄公派臧文仲前往慰问。** 宋国回应时把灾害归咎于自身治理不敬，这种主动承担责任的说法受到鲁国大夫称许。[[2]](#note-2)

<a id="event-3"></a>

3. **冬，周王姬嫁到齐国，齐侯亲自前来迎娶。** 齐国与周王室的婚姻联系进一步加强。[[3]](#note-3)

<a id="event-4"></a>

4. **宋将南宫长万因曾被鲁国俘虏，又遭宋闵公羞辱，心中积怨。** 这一矛盾很快在下一年演变成弑君政变。[[4]](#note-4)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公十一年》**：“夏五月戊寅，公败宋师于鄑。”  
   **《左传·庄公十一年》**：“宋师未陈而薄之，败诸鄑。”

<a id="note-2"></a>

2. **《春秋·庄公十一年》**：“秋，宋大水。”  
   **《左传·庄公十一年》**详记鲁国吊灾与宋国答辞。  
   **《史记·十二诸侯年表》**[前683年鲁、宋两栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0683)分别记“臧文仲弔宋水”与“魯使臧文仲來弔”。二者指同一次水灾使节往来，故只在原事件2补使者名，不另计一次吊灾。

<a id="note-3"></a>

3. **《春秋·庄公十一年》**：“冬，王姬归于齐。”  
   **《左传·庄公十一年》**：“齐侯来逆共姬。”

<a id="note-4"></a>

4. **《左传·庄公十一年》**详记南宫长万曾在乘丘被鲁国俘虏，归宋后又遭宋公嘲讽，因此怀恨。

# 公元前683年（鲁庄公十一年）

[← 上一张已编年页：公元前684年](bce-0684.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前682年 →](bce-0682.md)

<a id="event-1"></a>

1. **夏五月，宋军为报乘丘之败再侵鲁国，鲁军趁宋军尚未列阵，在鄑将其击败。** 鲁宋战争继续。[[1]](#note-1)

<a id="event-2"></a>

2. **秋，宋国大水，鲁庄公派臧文仲前往慰问。** 宋君答辞自称不能敬奉宗庙、致使天降灾害，反让鲁君担忧。臧文仲回来后称赞这番承担责任的话；后来得知答辞出自公子御说，又称御说懂得忧恤百姓、适合为君。此时宋君仍是闵公，御说还不是国君。[[2]](#note-2)

<a id="event-3"></a>

3. **冬，王姬嫁到齐国，齐侯亲来迎娶。** 齐与周王室的婚姻联系再次加强。[[3]](#note-3)

<a id="event-4"></a>

4. **南宫长万从前在乘丘被鲁军俘虏，归宋后又受宋闵公羞辱，心中积怨。** 这段前情在本年被追叙，下一年将发展为弑君之乱。[[4]](#note-4)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公十一年》**：“夏五月戊寅，公败宋师于鄑。”  
   **《左传》**：“宋师未陈而薄之，败诸鄑。”

<a id="note-2"></a>

2. **《春秋·庄公十一年》**：“秋，宋大水。”  
   [**《左传》**](https://zh.wikisource.org/wiki/春秋左氏傳/莊公#莊公十一年)保存答辞、臧孙达回报与得知公子御说起草后的评论；臧文仲、臧孙达是本段同一位使者，不另造两次出使。

   [卷014鲁、宋两栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0683)记“臧文仲吊宋水”与“鲁使臧文仲来吊”，都落本条。宋栏“公自罪”体现在对鲁使的答辞中，不改成另有一次先行颁出的罪己诏；天灾归因也仅是答辞的政治语言。称许御说适合为君是后续得知答辞作者时的评价，不等于他已在本年继位，也不据“后闻”硬补获知月日。

<a id="note-3"></a>

3. **《春秋·庄公十一年》**：“冬，王姬归于齐。”  
   **《左传》**：“齐侯来逆共姬。”与前693年嫁齐、前692年去世的王姬为不同婚姻，不让前一王姬再次出嫁。

<a id="note-4"></a>

4. **《左传·庄公十一年》**追述乘丘俘长万、后遭宋公嘲讽；乘丘之战在[前684年](bce-0684.md#event-4)。本页“曾被俘”是背景，不在本年再发生相同俘获。

# 公元前684年（鲁庄公十年）

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，齐军伐鲁，鲁庄公准备在长勺迎战，曹刿请求参与。** 曹刿逐项询问凭什么作战，最终认为庄公办理诉讼时尽量按实情判断，才有争取民众、与敌一战的基础。 [[1]](#note-1)

<a id="event-2"></a>

2. **曹刿等齐军三次击鼓以后，才让鲁军进攻；又察看车辙与旗帜，确认齐军混乱后才追击。** 鲁军击败齐军，保存了这场强调士气与谨慎追击的战例。 [[2]](#note-2)

<a id="event-3"></a>

3. **二月，鲁国进攻宋国。** 对齐作战以后，鲁又向另一邻国出兵。 [[3]](#note-3)

<a id="event-4"></a>

4. **夏，齐、宋军驻于郎，鲁公子偃先行攻击宋军，庄公随后跟进，在乘丘大败宋师，齐军撤走。** 鲁再次击退进逼本国的军队。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋九月，楚在莘击败蔡军，俘获蔡侯献舞。** 蔡侯与息侯的夫人都出自陈国。此前息夫人息妫经过蔡国，蔡侯以妻子的姊妹待她，却有失礼之举，引起息侯愤怒。息侯请楚先佯攻息国，等蔡出兵来救，再由楚击蔡。蔡侯果然来援，反成楚军的俘虏。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬，齐桓公灭谭，谭君逃往莒国。** 小白出亡时经过谭国未受礼遇，即位后谭国又没有前来祝贺，齐以此为由出兵。 [[6]](#note-6)

<a id="event-7"></a>

7. **三月，宋国迁徙宿国。** 原文没有交代具体迁往哪里，不另补新都城。 [[7]](#note-7)

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·庄公十年》**：“十年春，王正月，公败齐师于长勺。”  
   **《左传》**详载曹刿问“何以战”。[卷014本年鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0684)以“为纠故”说明齐伐鲁的背景，回接[前685年争位](bce-0685.md)，不另造第二次齐伐鲁。

<a id="history-legacy-source-2"></a>

2. **《左传·庄公十年》**保存三鼓后出击及“一鼓作气，再而衰，三而竭”的解释。传世的对话和战术描写不视为现场逐字记录。

<a id="history-legacy-source-3"></a>

3. **《春秋·庄公十年》**：“二月，公侵宋。”

<a id="history-legacy-source-4"></a>

4. **《春秋·庄公十年》**：“夏六月，齐师、宋师次于郎。公败宋师于乘丘。”  
   **《左传》**记公子偃未经庄公许可先攻，庄公随后跟进。南宫长万在乘丘被俘的后续说明见[前683年](bce-0683.md#event-4)，不把被俘日期改到次年。

<a id="history-legacy-source-5"></a>

5. **《春秋·庄公十年》**：“秋九月，荆败蔡师于莘，以蔡侯献舞归。”  
   [**《左传·庄公十年》**](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E8%8E%8A%E5%85%AC.md#ref-2b9d2624955ffc)详载两国娶陈女、息妫过蔡、蔡侯以“吾姨”相见而不礼、息侯诱蔡救息。

   [卷014本年楚栏与蔡栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0684)分别记原因与“楚虏我侯”，属于同一次战役和俘获，不各记一战。“姨”在这里指妻子的姊妹，不是现代口语中的母亲姊妹；无礼的具体行为未详，不编造场景。两场婚姻、过境与谋划属于本战前情，没有证据把婚期一律定在前684年。前680年楚灭息、再攻蔡另有过程，不与本次俘蔡侯混成一事。

<a id="history-legacy-source-6"></a>

6. **《春秋·庄公十年》**：“冬十月，齐师灭谭。谭子奔莒。”  
   **《左传》**说明出亡时不礼、即位后不贺。旧文“小白复位”改为“即位”，他不是在出亡前已做过齐君。

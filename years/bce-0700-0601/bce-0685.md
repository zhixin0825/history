<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **春，齐国人杀死公孙无知，齐国再度出现君位空缺。** 鲁庄公随即与齐国大夫在蔇地结盟，为支持公子纠回齐做准备。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **夏，鲁国出兵伐齐，准备护送公子纠即位；公子小白却从莒国抢先进入齐国。** 小白在争位中先占一步，成为后来的齐桓公。 《齐太公世家》另补管仲射中小白带钩、小白佯死和高、国内应的经过，作为本书补叙。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **秋，鲁齐在乾时交战，鲁军大败。** 庄公连兵车都丢失，只得换乘其他车辆逃回；齐桓公由此稳住君位。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **齐国随后逼鲁国杀死公子纠，并要求活着交出管仲。** 鲁国在生窦杀死公子纠，召忽殉死，管仲则请求被囚，准备由鲁送往齐国。 [[4]](#reading-note-4)

<a id="event-5"></a>

<a id="reading-event-5"></a>

5. **鲁大夫施伯看出齐国点名要活的管仲并不是只为报仇，而是准备重用，劝庄公先杀管仲；庄公没有听。** 鲁国最终把管仲囚送齐国。鲍叔牙接收管仲并向齐桓公推荐，管仲很快进入齐国权力中心，成为齐桓公后来称霸的重要执政者。 本卷还记到堂阜后鲍叔为管仲解除桎梏、斋祓后引见，说明用旧敌经历了说服与正式礼遇。 [[5]](#reading-note-5)

<a id="reading-event-6"></a>

6. **管仲年轻时常与鲍叔牙来往。** 书中说管仲家贫，有时在财物上多占，鲍叔仍厚待他。两人后来分别跟随公子纠和公子小白。 [[6]](#reading-note-6)

   [《史记》卷62 管晏列传](../../sources/摘录/史记-条目原文.md#ref-sj-4591)

<a id="event-6"></a>

<a id="reading-event-7"></a>

7. **冬，鲁国疏浚洙水。** 这是战败后的国内工程记录。 [[7]](#reading-note-7)

<a id="event-7"></a>

<a id="reading-event-8"></a>

8. **秋七月丁酉，齐国安葬齐襄公。** 齐襄公死于前一年的内乱；公孙无知被杀、小白与子纠争位之后，本年才举行这次葬礼。 [[8]](#reading-note-8)

##### 补充互见｜公子纠死后，鲍叔推荐了被囚的管仲

**时间：鲁庄公九年** · 事件

小白即位为齐桓公，公子纠被杀，管仲成了囚犯。鲍叔牙没有因为两人此前各事其主就排斥他，反而向齐桓公推荐管仲，管仲随后在齐国主持政事。

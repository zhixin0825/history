# 公元前685年（鲁庄公九年）

[← 上一张已编年页：公元前686年](bce-0686.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前684年 →](bce-0684.md)

<a id="event-1"></a>

1. **春，齐国人杀死公孙无知，齐国再度出现君位空缺。** 鲁庄公随即与齐国大夫在蔇地结盟，为支持公子纠回齐做准备。[1]

<a id="event-2"></a>

2. **夏，鲁国出兵伐齐，准备护送公子纠即位；公子小白却从莒国抢先进入齐国。** 小白在争位中先占一步，成为后来的齐桓公。[2]

<a id="event-3"></a>

3. **秋，鲁齐在乾时交战，鲁军大败。** 庄公连兵车都丢失，只得换乘其他车辆逃回；齐桓公由此稳住君位。[3]

<a id="event-4"></a>

4. **齐国随后逼鲁国杀死公子纠，并要求活着交出管仲。** 鲁国在生窦杀死公子纠，召忽殉死，管仲则请求被囚，准备由鲁送往齐国。[4]

<a id="event-5"></a>

5. **鲁大夫施伯看出齐国点名要活的管仲并不是只为报仇，而是准备重用，劝庄公先杀管仲；庄公没有听。** 鲁国最终把管仲囚送齐国。鲍叔牙接收管仲并向齐桓公推荐，管仲很快进入齐国权力中心，成为齐桓公后来称霸的重要执政者。[5]


<a id="backstory-sj-062-L4591-01"></a>

#### 登场前事｜管仲：管仲与鲍叔牙的交情

> 此前经历，确切年月未详；放在这里补叙，不表示发生于前685年。

管仲年轻时常与鲍叔牙来往。书中说管仲家贫，有时在财物上多占，鲍叔仍厚待他。两人后来分别跟随公子纠和公子小白。

[《史记》卷62 管晏列传](../../sources/摘录/史记-条目原文.md#ref-sj-4591)

<details><summary>补叙依据</summary>

原段先说少时与鲍叔来往、家贫及各事其主，继而写小白立和荐管仲；只把前半生涯作为此事以前的补叙，不移动有明确年份的任命。

<a id="event-6"></a>

6. **冬，鲁国疏浚洙水。** 这是战败后的国内工程记录。[6]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公九年》**：“九年春，齐人杀无知。公及齐大夫盟于蔇。”  
   **《左传·庄公九年》**：“雍廪杀无知……齐无君也。”

<a id="note-2"></a>

2. **《春秋·庄公九年》**：“夏，公伐齐，纳子纠。齐小白入于齐。”  
   **《左传·庄公九年》**：“桓公自莒先入。”

<a id="note-3"></a>

3. **《春秋·庄公九年》**：“八月庚申，及齐师战于乾时，我师败绩。”  
   **《左传·庄公九年》**详记庄公丧戎路、传乘而归。

<a id="note-4"></a>

4. **《春秋·庄公九年》**：“九月，齐人取子纠，杀之。”  
   **《左传·庄公九年》**：“乃杀子纠于生窦，召忽死之。管仲请囚。”  
   **《史记·鲁周公世家》**：“鲁急，杀子纠。召忽死。齐告鲁生致管仲。”

<a id="note-5"></a>

5. **《史记·鲁周公世家》**：“鲁人施伯曰：‘齐欲得管仲，非杀之也，将用之，用之则为鲁患。不如杀，以其尸与之。’庄公不听，遂囚管仲与齐。齐人相管仲。”  
   **《左传·庄公九年》**：“鲍叔受之……归而以告曰：‘管夷吾治于高傒，使相可也。’公从之。”

   **说明：** 《史记》保存了施伯劝庄公杀管仲而庄公不从这一层，《左传》则更详细保存鲍叔牙接收并推荐管仲的过程；两者可以自然拼合，不构成实质冲突。


<a id="sj-062-L4591-02"></a>

#### 补充互见｜公子纠死后，鲍叔推荐了被囚的管仲

**时间：鲁庄公九年** · 事件

小白即位为齐桓公，公子纠被杀，管仲成了囚犯。鲍叔牙没有因为两人此前各事其主就排斥他，反而向齐桓公推荐管仲，管仲随后在齐国主持政事。

<a id="sj-062-L4593-01"></a>

#### 补充互见｜鲍叔愿意居于管仲之下

**时间：鲍叔荐管仲之后** · 事件

鲍叔推荐管仲以后，自己愿意居于他之下。《史记》在叙述两人的关系时，特别强调鲍叔能够识人的一面。

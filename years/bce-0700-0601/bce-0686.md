# 公元前686年（鲁庄公八年）

[← 上一张已编年页：公元前687年](bce-0687.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前685年 →](bce-0685.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁军驻郎地等待陈、蔡军队，并举行军事整训。** 甲午日，鲁国在宗庙举行治兵仪式。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，鲁军与齐军共同包围郕国，郕国却只向齐军投降。** 庆父一度主张因此攻击齐军，庄公认为问题在鲁国自身，没有迁怒齐国，最终收兵回国。 [[2]](#note-2)

<a id="event-3"></a>

3. **齐襄公长期任性用人，国内不满逐渐集中到连称、管至父和公孙无知。** 连称、管至父被派守葵丘，约定瓜熟时换防，却迟迟没人替代，于是开始谋反。 [[3]](#note-3)

<a id="event-4"></a>

4. **冬，齐襄公出猎时受伤，叛党乘机入宫杀死齐襄公，拥立公孙无知。** 宫中护卫多人战死，齐国进入严重内乱。 [[4]](#note-4)

<a id="event-5"></a>

5. **齐乱发生前，鲍叔牙已经护送公子小白逃往莒国；管仲、召忽则护送公子纠来到鲁国。** 两位齐国公子分别依靠莒、鲁，下一年将争夺齐国君位。 [[5]](#note-5)

> 齐侯使连称、管至父戍葵丘。瓜时而往，曰：“及瓜而代。”期戍，公问不至。请代，弗许。故谋作乱。僖公之母弟曰夷仲年，生公孙无知，有宠于僖公，衣服礼秩如適，襄公绌之。二人因之以作乱。连称有从妹在公宫，无宠，使间公，曰：“捷，吾以女为夫人。”

[史料说明](#history-legacy-source-3)

**[《史记·齐太公世家》P027](../../sources/摘录/史记-卷032-齐太公世家.md#p027)**

> 十二年，初，襄公使連稱、管至父戍葵丘，瓜時而往，及瓜而代。往戍一歲，卒瓜時而公弗為發代。或為請代，公弗許。故此二人怒，因公孫無知謀作亂。連稱有從妹在公宮，無寵，使之閒襄公，曰「事成以女為無知夫人」。

**[《史记·齐太公世家》P027](../../sources/摘录/史记-卷032-齐太公世家.md#p027)**

> 冬十二月，襄公游姑棼，遂獵沛丘。見彘，從者曰「彭生」。公怒，射之，彘人立而啼。公懼，墜車傷足，失屨。反而鞭主屨者茀三百。茀出宮。而無知、連稱、管至父等聞公傷，乃遂率其眾襲宮。逢主屨茀，茀曰：「且無入驚宮，驚宮未易入也。」無知弗信，茀示之創，乃信之。待宮外，令茀先入。茀先入，即匿襄公戶閒。良久，無知等恐，遂入宮。茀反與宮中及公之幸臣攻無知等，不勝，皆死。無知入宮，求公不得。或見人足於戶閒，發視，乃襄公，遂弒之，而無知自立為齊君。

**读法与异说：** 彭生化彘、三百鞭等均按本书叙事记述，不当作可证实的鬼魂显形。

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·庄公八年》**：“八年春，王正月，师次于郎，以俟陈人、蔡人。甲午，治兵。”  
   **《左传·庄公八年》**：“治兵于庙，礼也。”

<a id="history-legacy-source-2"></a>

2. **《春秋·庄公八年》**：“夏，师及齐师围郕，郕降于齐师。秋，师还。”  
   **《左传·庄公八年》**详记庆父请伐齐师而庄公拒绝。

<a id="history-legacy-source-3"></a>

3. **《左传·庄公八年》**详记连称、管至父戍葵丘，“瓜时而往，曰：‘及瓜而代。’”后因不获替代而谋乱。

<a id="history-legacy-source-4"></a>

4. **《春秋·庄公八年》**：“冬十有一月癸未，齐无知弑其君诸儿。”  
   **《左传·庄公八年》**详记齐襄公出猎、受伤及宫中弑杀过程。

   **说明：** 经文系于十一月癸未，传文叙事中作“冬十二月”；本页正文不强行换算月次，只保留“冬”。

5. **《左传·庄公八年》**：“鲍叔牙……奉公子小白出奔莒。乱作，管夷吾、召忽奉公子纠来奔。”

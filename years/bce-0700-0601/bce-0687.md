# 公元前687年（鲁庄公七年）

[← 上一张已编年页：公元前688年](bce-0688.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前686年 →](bce-0686.md)

<a id="event-1"></a>

1. **春，文姜在防地与齐侯会面；冬天又在穀地会面。** 她与齐侯的私人和政治往来贯穿这一年。[[1]](#note-1)

<a id="event-2"></a>

2. **夏四月辛卯，夜空一度看不见恒星，随后大量流星像下雨一样坠落。** 这场异常天象被完整记录下来。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，鲁国发生大水，又出现麦、苗歉收。** 水灾影响农业，但其他成熟谷物并未全部受损。[[3]](#note-3)

<a id="event-4"></a>

4. **秦在杜、郑置县，并灭小虢。** 这一年继续扩展县的设置。这里的郑是秦经营的地名，不是东方郑国已经被秦灭亡。 [原文与说明](#sj005-036-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公七年》**：“七年春，夫人姜氏会齐侯于防……冬，夫人姜氏会齐侯于穀。”

<a id="note-2"></a>

2. **《春秋·庄公七年》**：“夏四月辛卯，夜，恒星不见。夜中，星陨如雨。”  
   **《左传·庄公七年》**：“恒星不见，夜明也。星陨如雨，与雨偕也。”

<a id="note-3"></a>

3. **《春秋·庄公七年》**：“秋，大水。无麦、苗。”  
   **《左传·庄公七年》**：“无麦、苗，不害嘉谷也。”

# 公元前687年（鲁庄公七年）

[← 上一张已编年页：公元前688年](bce-0688.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前686年 →](bce-0686.md)

<a id="event-1"></a>

1. **春，文姜与齐侯会于防；冬天又会于穀。** 两人的来往并没有因桓公之死而停止。[[1]](#note-1)

<a id="event-2"></a>

2. **夏四月辛卯，夜色异常明亮，平常可见的星辰反而看不见；到夜中，又有星体坠落，并伴有降雨。** 原书将前后两种夜间现象接着记下。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，鲁国大水，麦、苗受损，其他谷物却未全受害。** 受损作物与没有受害的部分并存，不能概括成本年全境粮食全毁。[[3]](#note-3)

<a id="event-4"></a>

4. **秦在杜、郑置县，并灭小虢。** 这里的郑是秦经营的地名，不是东方郑国已经被灭。[原文与说明](#sj005-036-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公七年》**：“七年春，夫人姜氏会齐侯于防……冬，夫人姜氏会齐侯于穀。”

<a id="note-2"></a>

2. **《春秋·庄公七年》**：“夏四月辛卯，夜，恒星不见。夜中，星陨如雨。”  
   **《左传》**：“恒星不见，夜明也。星陨如雨，与雨偕也。”[卷014本年鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0687)也有“与雨偕”。本轮保留这一解释，不只将“如雨”译成数量多；夜光、星陨与雨的具体物理原因仍未定，不未经研究确定现代天体事件名称。

《天官书》在春秋回顾中作“宋襄公時星隕如雨”（[P115](../../sources/摘录/史记-卷027-天官书.md#p115)），《正义》把它联系到[前644年宋国陨石](../../meta/考证/史记-卷027-纪年与异说.md#宋襄公与星陨)。本经“星陨如雨”却明确在本年鲁庄公七年，宋襄公尚未在位。两条现象与年代分别保存，不把本年事件搬到宋襄公时期。

<a id="note-3"></a>

3. **《春秋·庄公七年》**：“秋，大水。无麦、苗。”  
   **《左传》**：“无麦、苗，不害嘉谷也。”

## 补充史料与异说

<a id="sj005-036-note"></a>
### sj005-036｜秦在杜、郑置县，并灭小虢

[卷005 P010](../../sources/摘录/史记-卷005-秦本纪.md#p010)。秦君元年、在位数见[卷005纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月干支不直接换算现代日期；原表本年秦栏只有年数，并不否定秦本纪另有事项。

<a id="sj014-0687-wei-variant"></a>
### 卷014卫栏异年｜齐立惠公与黔牟出奔

[卷014前687年卫栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0687)把齐立惠公、黔牟奔周放在本年；[经传庄公六年](../../sources/春秋左传/data/zz-03-06.json)已于[前688年六月](bce-0688.md#event-2)明确记入卫，后逐黔牟、杀左右公子。这里保留异年，不另记一次复位和出奔，亦不由两条相似句子推断存在两轮相同政变。

# 公元前688年（鲁庄公六年）

[← 上一张已编年页：公元前689年](bce-0689.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前687年 →](bce-0687.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，周王室派人援救卫国，但诸侯联军仍继续推进复立卫惠公。** 王室与诸侯在卫国君位问题上出现不同立场。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏六月，卫惠公朔重新进入卫国。** 他放逐黔牟和甯跪，杀掉左公子洩、右公子职，重新掌权。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋，鲁庄公从伐卫战事返回；同年鲁国发生螟灾。** 卫国政变告一段落，鲁国则转入灾害记录。 [[3]](#note-3)

<a id="event-4"></a>

4. **冬，齐国把卫国宝物送给鲁国，这是文姜请求的结果。** 文姜仍能直接影响鲁齐之间的外交和财物往来。 [[4]](#note-4)

<a id="event-5"></a>

5. **楚文王出兵伐申，途中经过邓国；邓国大夫主张趁机杀楚王，邓侯因亲属关系拒绝。** 几位大夫警告楚国迟早会灭邓，邓侯没有听从；楚国后来果然继续伐邓。 [[5]](#note-5)

<a id="event-6"></a>

6. **秦进攻邽、冀两支戎人，并开始置县。** 占领以后，秦把这些地区改为县，军事占领与管辖方式的变化同时出现。 [[6]](#note-6)

<a id="hs-event-7"></a>

7. **鲁秋螟。** [[7]](#hs-note-7)

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·庄公六年》**：“六年春，王正月，王人子突救卫。”

<a id="history-legacy-source-2"></a>

2. **《春秋·庄公六年》**：“夏六月，卫侯朔入于卫。”  
   **《左传·庄公六年》**详记放黔牟、甯跪，杀左公子洩、右公子职。  
   **纪年异说：**《史记·十二诸侯年表》[前687年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0687)写齐立惠公、黔牟奔周，[前686年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0686)再写惠公复入；但经、传将卫侯入国及驱逐黔牟系于鲁庄公六年（本页前688年）。按经传连续叙事，本页只记一次复国，另两年保留表内异年，不把它们写成三次入卫。

<a id="history-legacy-source-3"></a>

3. **《春秋·庄公六年》**：“秋，公至自伐卫。螟。”

<a id="history-legacy-source-4"></a>

4. **《春秋·庄公六年》**：“冬，齐人来归卫俘。”  
   **《左传·庄公六年》**：“齐人来归卫宝，文姜请之也。”

   **说明：** 经文作“卫俘”，传文解释为“卫宝”；正文按传文所释写为宝物。

<a id="history-legacy-source-5"></a>

5. **《左传·庄公六年》**详记楚文王过邓，三甥请邓侯杀楚王而不从，并预言邓国后患。

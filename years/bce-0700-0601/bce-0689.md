# 公元前689年（鲁庄公五年）

[← 上一张已编年页：公元前690年](bce-0690.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前688年 →](bce-0688.md)

<a id="event-1"></a>

1. **夏，文姜前往齐军驻地。** 她同齐国的往来仍然频繁。[[1]](#note-1)

<a id="event-2"></a>

2. **秋，郳君犁来前往鲁国朝见。** 他尚未得到周王正式册命，经传因而以名字称他。[[2]](#note-2)

<a id="event-3"></a>

3. **冬，鲁庄公会同齐、宋、陈、蔡伐卫，准备让卫惠公朔复位。** 联军出动是本年，朔实际入卫则接在[下一年六月](bce-0688.md#event-2)。[[3]](#note-3)

<a id="sj014-0689-event"></a>

4. **楚武王去世后，儿子熊赀接掌王位，本年为楚文王元年，王室开始以郢为政治中心。** 父王死于前一年伐随途中，楚国由此进入新君时期。[[4]](#sj014-0689-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公五年》**：“夏，夫人姜氏如齐师。”

<a id="note-2"></a>

2. [**《春秋·庄公五年》完整见证**](https://zh.wikisource.org/wiki/春秋左氏傳/莊公#莊公五年)作“秋，郳犁來來朝”，其中前一“来”属于名字犁来，后一“来”是来朝。**《左传》**：“名，未王命也。”旧页面引文少一“来”、正文称“郳国的犁”，造成姓名截断，本次修正页面，不改底层工作文本。未获册命是传文解释，不据此推演他以前从未治理过郳国。

<a id="note-3"></a>

3. **《春秋·庄公五年》**：“冬，公会齐人、宋人、陈人、蔡人伐卫。”  
   **《左传》**：“伐卫，纳惠公也。”[卷014鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0689)同样概写纳惠公；这里先解释战争目的，不把它误当作朔已在本年入国。年表前687、686两处复位异年已与[前688年注2](bce-0688.md#note-2)合并核对。

## 补充史料与异说

<a id="sj014-0689-note"></a>
### 卷014互见｜楚文王元年与始都郢

[卷014本年楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0689)“楚文王貲元年始都郢”，与[《楚世家》](https://zh.wikisource.org/wiki/史記/卷040)相接。始都郢是传世文献提供的都邑变更记载，不等于本轮已经考古核定具体城址、建城月日和全部设施竣工时间。

# 公元前689年（鲁庄公五年）

[← 上一张已编年页：公元前690年](bce-0690.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前688年 →](bce-0688.md)

<a id="event-1"></a>

1. **夏，文姜前往齐军驻地。** 她与齐国的往来仍然频繁。[[1]](#note-1)

<a id="event-2"></a>

2. **秋，郳国的犁来鲁朝见。** 他尚未得到周王正式册命，因此仍以名字被记录。[[2]](#note-2)

<a id="event-3"></a>

3. **冬，鲁庄公会同齐、宋、陈、蔡四国伐卫，目标是让卫惠公朔复位。** 卫国内乱从本国政变变成多国干预。[[3]](#note-3)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公五年》**：“夏，夫人姜氏如齐师。”

<a id="note-2"></a>

2. **《春秋·庄公五年》**：“秋，郳犁来朝。”  
   **《左传·庄公五年》**：“名，未王命也。”

<a id="note-3"></a>

3. **《春秋·庄公五年》**：“冬，公会齐人、宋人、陈人、蔡人伐卫。”  
   **《左传·庄公五年》**：“伐卫，纳惠公也。”

# 公元前690年（鲁庄公四年）

[← 上一张已编年页：公元前691年](bce-0691.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前689年 →](bce-0689.md)

<a id="event-1"></a>

1. **春，文姜在祝丘设宴招待齐侯。** 她与齐侯的公开往来继续。[[1]](#note-1)

<a id="event-2"></a>

2. **楚武王出兵伐随，途中病死，楚军秘不发丧，继续逼随国求和。** 楚军渡汉水后才公布死讯，显示楚国已经具备在汉东持续施压诸侯的能力。[[2]](#note-2)

<a id="event-3"></a>

3. **三月，纪伯姬去世。** 纪国本已在齐国压力下分裂，王室婚姻关系也随之结束一支。[[3]](#note-3)

<a id="event-4"></a>

4. **夏，齐侯、陈侯、郑伯在垂地会面；纪侯随后彻底离开本国。** 纪侯不愿屈服齐国，把剩余国家交给纪季，自己出走，纪国实质上走向灭亡。[[4]](#note-4)

<a id="event-5"></a>

5. **六月，齐侯替纪伯姬主持葬礼。** 齐国已经实际掌握纪地事务。[[5]](#note-5)

<a id="event-6"></a>

6. **冬，鲁庄公与齐人在禚地狩猎。** 鲁齐关系虽然有桓公之死的阴影，却仍保持频繁政治往来。[[6]](#note-6)

<a id="sj014-0690-yan"></a>

7. **燕桓侯在位七年后去世，儿子继承燕国君位，是为燕庄公；本年为燕庄公元年。** 这次更替承接前697年燕桓侯元年；燕国后来逐渐卷入周王室的争位和齐国对山戎的战争，不能把这些后事倒填为本年的行动。[原文与说明](#sj014-0690-yan-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公四年》**：“四年春，王二月，夫人姜氏享齐侯于祝丘。”

<a id="note-2"></a>

2. **《左传·庄公四年》**详记楚武王伐随途中卒于樠木，楚军继续临随、迫其求和，过汉水后才发丧。

<a id="note-3"></a>

3. **《春秋·庄公四年》**：“三月，纪伯姬卒。”

<a id="note-4"></a>

4. **《春秋·庄公四年》**：“夏，齐侯、陈侯、郑伯遇于垂。纪侯大去其国。”  
   **《左传·庄公四年》**：“纪侯不能下齐……违齐难也。”

<a id="note-5"></a>

5. **《春秋·庄公四年》**：“六月乙丑，齐侯葬纪伯姬。”

<a id="note-6"></a>

6. **《春秋·庄公四年》**：“冬，公及齐人狩于禚。”

## 卷014国别互见与纪年说明

<a id="sj014-0690-yan-note"></a>
### 燕庄公元年与齐攻纪的记述范围

[卷014前690年燕栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0690)作“燕庄公元年”，[《燕召公世家》](https://zh.wikisource.org/wiki/史記/卷034)作燕桓侯七年卒、子庄公立；见[前697年燕桓侯元年](bce-0697.md#sj014-0697-yan)。同年[齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0690)作齐伐纪、纪去都邑；《春秋》《左传·庄公四年》明确记[纪侯大去其国](#event-4)，没有详细列战役与城市占取经过。正文继续写纪侯出走与纪国瓦解，不据年表简句补造具体交战日期或围城细节。

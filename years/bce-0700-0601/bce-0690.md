# 公元前690年（鲁庄公四年）

[← 上一张已编年页：公元前691年](bce-0691.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前689年 →](bce-0689.md)

<a id="event-1"></a>

1. **春，文姜在祝丘设宴招待齐侯。** 两人的往来继续。[[1]](#note-1)

<a id="event-2"></a>

2. **楚武王伐随，出发前曾向夫人邓曼说自己心神不安，后来死于樠木。** 大臣鬥祁、屈重暂不发丧，继续带兵逼近随国。随人害怕而求和，双方盟誓，楚军回师渡过汉水以后才公布王的死讯。[[2]](#note-2)

<a id="event-3"></a>

3. **三月，纪侯夫人伯姬去世。** 纪国本已在齐的压力下分裂，又发生夫人的丧事；这位伯姬不应与前692年去世的齐王姬混同。[[3]](#note-3)

<a id="event-4"></a>

4. **夏，齐侯、陈侯、郑伯会于垂，纪侯随后离开本国。** 他不愿屈服于齐，把剩余政治和祭祀的托付交给纪季，自己出走。纪国的独立地位进一步瓦解。[[4]](#note-4)

<a id="event-5"></a>

5. **六月，齐侯为纪伯姬办理葬礼。** 齐国已能直接介入纪地事务。[[5]](#note-5)

<a id="event-6"></a>

6. **冬，鲁庄公与齐人在禚地狩猎。** 两国虽有桓公之死的旧怨，仍保持政治往来。[[6]](#note-6)

<a id="sj014-0690-yan"></a>

7. **燕国开始以庄公元年纪事。** 燕桓侯在位七年后，由儿子庄公接掌君位。后来的战争不都提前放成本年的行动。[原文与说明](#sj014-0690-yan-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公四年》**：“四年春，王二月，夫人姜氏享齐侯于祝丘。”

<a id="note-2"></a>

2. **《左传·庄公四年》**记楚武王亲口说“余心荡”，邓曼作答，其后王卒、秘丧、临随、成盟、过汉发丧。[卷014本年楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0690)压缩为“王伐，随告夫人心动，王卒军中”，展平断句容易把“随”或“心动”的主语弄错。本页据完整叙事理解为王伐随、向夫人告不安，**不是夫人代王心动，也不是夫人病死军中**。不安与其后死亡的串连属于传世叙事，不作为预知死亡的证明。[经传全文](https://zh.wikisource.org/wiki/春秋左氏傳/莊公#莊公四年) · [《读史记十表》相关疑句](https://zh.wikisource.org/wiki/讀史記十表/卷二)。

<a id="note-3"></a>

3. **《春秋·庄公四年》**：“三月，纪伯姬卒。”与纪叔姬、齐王姬均按不同人物处理，不因都涉及婚姻就合并。

<a id="note-4"></a>

4. **《春秋·庄公四年》**：“夏，齐侯、陈侯、郑伯遇于垂。纪侯大去其国。”  
   **《左传》**：“纪侯不能下齐……违齐难也。”[卷014齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0690)写伐纪、去都邑，是对同一局面的概括，不由此添一次有确切日、战法和伤亡的围城。

<a id="note-5"></a>

5. **《春秋·庄公四年》**：“六月乙丑，齐侯葬纪伯姬。”

<a id="note-6"></a>

6. **《春秋·庄公四年》**：“冬，公及齐人狩于禚。”

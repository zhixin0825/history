# 公元前691年（鲁庄公三年）

[← 上一张已编年页：公元前692年](bce-0692.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前690年 →](bce-0690.md)

<a id="event-1"></a>

1. **春，鲁大夫溺会同齐军攻卫。** 鲁国卷入齐国对卫国的军事行动。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，宋庄公下葬；五月，周桓王也终于下葬。** 周桓王去世已久，葬礼拖延到这一年才完成。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，纪季带着酅地投降齐国，纪国开始分裂。** 纪侯与齐国的长期对抗已经无法维持，国内出现主动投齐的一支。[[3]](#note-3)

<a id="event-4"></a>

4. **冬，鲁庄公驻军滑地，本想与郑伯会面商议纪国问题，但郑伯因国内困难拒绝。** 鲁国试图为纪国寻找外交出路，没有成功。[[4]](#note-4)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·庄公三年》**：“三年春，王正月，溺会齐师伐卫。”

<a id="note-2"></a>

2. **《春秋·庄公三年》**：“夏四月，葬宋庄公。五月，葬桓王。”  
   **《左传·庄公三年》**：“葬桓王，缓也。”

<a id="note-3"></a>

3. **《春秋·庄公三年》**：“秋，纪季以酅入于齐。”  
   **《左传·庄公三年》**：“纪于是乎始判。”

<a id="note-4"></a>

4. **《春秋·庄公三年》**：“冬，公次于滑。”  
   **《左传·庄公三年》**：“将会郑伯谋纪故也。郑伯辞以难。”

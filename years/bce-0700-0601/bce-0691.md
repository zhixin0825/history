# 公元前691年（鲁庄公三年）

[← 上一张已编年页：公元前692年](bce-0692.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前690年 →](bce-0690.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁大夫溺会同齐军攻卫。** 鲁国卷入齐国对卫国的军事行动。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，宋庄公下葬；五月，周桓王也终于下葬。** 周桓王去世已久，葬礼拖延到这一年才完成。 [[2]](#note-2)

<a id="event-3"></a>

<a id="event-4"></a>

3. **纪国分裂，鲁未能约郑商议援纪。** 秋，纪季以酅地归齐，纪国开始分裂。冬，鲁庄公驻兵滑地，欲约郑伯相会商议纪国之事，郑伯以国内事务为由谢绝。 [[3]](#note-3)

<a id="sj014-0691-song"></a>

<a id="event-5"></a>

4. **宋庄公冯去世后，儿子捷继位，是为宋闵公（又作宋湣公），本年开始以闵公元年纪事。** 宋国前一年刚办理庄公去世的消息，本年进入新君统治期；几年后宋闵公与南宫万的矛盾，又会引发宋国内乱。 [[4]](#note-5)

<a id="sj034-huanhou-death-event"></a>

5. **燕桓侯去世，儿子庄公继承。** 桓侯在位七年，庄公从下一年开始纪年。 [[5]](#sj034-huanhou-death-note)

#### 宋闵公元年

[卷014前691年宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0691)作“宋湣公捷元年”；[《宋微子世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7038.md#ref-5fd061b7db1fe2)记宋庄公十九年卒、子湣公捷立。前692年正文已记[宋庄公卒](bce-0692.md#event-5)，本年仅接元年，与前682年南宫万弑闵公并非同一阶段。

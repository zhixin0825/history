# 公元前692年（鲁庄公二年）

[← 上一张已编年页：公元前693年](bce-0693.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前691年 →](bce-0691.md)

<a id="event-1"></a>

1. **春，鲁国安葬陈庄公。** 这是上一年陈侯去世后的正常丧礼往来。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，庆父率鲁军攻打於馀丘。** 这是庆父第一次以重要军事角色明显进入庄公时期政治。[[2]](#note-2)

<a id="event-3"></a>

3. **秋七月，嫁到齐国的王姬去世。** 周王室与齐国的婚姻很快结束。[[3]](#note-3)

<a id="event-4"></a>

4. **冬十二月，文姜在禚地与齐侯会面。** 她回齐后仍频繁与齐侯往来，这件事在鲁国政治中持续造成严重的伦理和外交压力。[[4]](#note-4)

<a id="event-5"></a>

5. **同月，宋庄公冯去世。** 宋国进入新的君主更替。[[5]](#note-5)

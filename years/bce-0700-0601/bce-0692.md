# 公元前692年（鲁庄公二年）

[← 上一张已编年页：公元前693年](bce-0693.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前691年 →](bce-0691.md)

<a id="event-1"></a>

1. **春，鲁国安葬陈庄公。** 这是上一年陈侯去世后的正常丧礼往来。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，庆父率鲁军攻打於馀丘。** 这是庆父第一次以重要军事角色明显进入庄公时期政治。[[2]](#note-2)

<a id="event-3"></a>

3. **秋七月，嫁到齐国的王姬去世。** 周王室与齐国的婚姻很快结束。[[3]](#note-3)

<a id="event-4"></a>

4. **冬十二月，文姜在禚地与齐侯会面。** 她回齐后仍频繁与齐侯往来，这件事在鲁国政治中持续造成严重的伦理和外交压力。[[4]](#note-4)

<a id="event-5"></a>

5. **同月，宋庄公冯去世。** 宋国进入新的君主更替。[[5]](#note-5)

<a id="sj014-0692-chen"></a>

6. **陈庄公林去世后，宗室杵臼接掌陈国君位，本年为陈宣公元年。** 杵臼是陈桓公的儿子、庄公林的弟弟；陈国内乱后，两兄弟相继在位。本年国君年次从林转到杵臼，不把此前陈佗、陈侯跃的事再发生一次。[原文与说明](#sj014-0692-chen-note)

### 陈宣公杵臼元年

[卷014前692年陈栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0692)作“陈宣公杵臼元年，杵臼庄公弟”；[《陈杞世家》](https://zh.wikisource.org/wiki/史記/卷036)亦记陈庄公七年卒后弟杵臼立。前693年正文已有[陈庄公去世](bce-0693.md#event-4)，本年是接续纪元，不擅给本年编造即位日。

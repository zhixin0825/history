# 公元前692年（鲁庄公二年）

[← 上一张已编年页：公元前693年](bce-0693.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前691年 →](bce-0691.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁国参加陈庄公的葬礼。** 上一年陈侯林去世，本年鲁与陈继续有丧礼往来。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，公子庆父率鲁军进攻於馀丘。** 庆父以领兵者身份进入本年的军事实事。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋七月，嫁到齐国的王姬去世。** 上一年完成的这场王室婚姻很快失去女主人。 [[3]](#note-3)

<a id="event-4"></a>

4. **冬十二月，文姜与齐侯在禚会面。** 鲁齐之间的私人和政治纠葛仍在延续。 [[4]](#note-4)

<a id="event-5"></a>

5. **同月，宋庄公冯去世。** 宋国进入君主更替。 [[5]](#note-5)

<a id="sj014-0692-chen"></a>

<a id="event-6"></a>

6. **陈庄公林去世后，弟弟杵臼接位，本年为陈宣公元年。** 杵臼也是陈桓公之子；这次继承不是重演更早的陈佗、陈侯跃之乱。 [[6]](#note-6)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·庄公二年》**：“二年春，王二月，葬陈庄公。”这条列于鲁史，正文以鲁国参与葬礼理解，不将它扩大成鲁国主持、独力办理邻国国君的全部葬事；来使姓名未记，不补姓名。

<a id="history-legacy-source-2"></a>


2. **《春秋·庄公二年》**：“夏，公子庆父帅师伐於馀丘。”不能只凭目前已读页断言这是庆父一生第一次领军。

<a id="history-legacy-source-3"></a>


3. **《春秋·庄公二年》**：“秋七月，齐王姬卒。”

<a id="history-legacy-source-4"></a>


4. **《春秋·庄公二年》**：“冬十有二月，夫人姜氏会齐侯于禚。”  
   **《左传》**：“书奸也。”这是原作者的评价，人物会见及评价层次分开。

<a id="history-legacy-source-5"></a>


5. **《春秋·庄公二年》**：“乙酉，宋公冯卒。”

#### 陈宣公杵臼元年

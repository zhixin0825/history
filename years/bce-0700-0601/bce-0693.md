# 公元前693年（鲁庄公元年）

[← 上一张已编年页：公元前694年](bce-0694.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前692年 →](bce-0692.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **鲁国开始以庄公同的元年纪事。** 桓公在齐国遇害后，儿子承位，鲁国内外都处在非常局面。 [[1]](#note-1)

<a id="event-2"></a>

2. **三月，文姜出奔齐国。** 桓公之死以后，这场鲁齐婚姻留下的纠葛继续影响两国。 [[2]](#note-2)

<a id="event-3"></a>

<a id="event-5"></a>

3. **鲁国为王姬筑馆，主持王姬嫁齐。** 夏，单伯送王姬到鲁。秋，鲁国在城外为王姬建馆舍，王姬随后嫁入齐国。 [[3]](#note-3)

<a id="event-4"></a>

4. **冬十月乙亥，陈庄公林去世；周王又派荣叔追赐鲁桓公命服。** 新的丧事与对已故鲁君的名分安排，同在本年被记下。 [[4]](#note-4)

<a id="event-6"></a>

5. **齐军迁徙纪国郱、鄑、郚三地居民。** 齐对纪的压力不断扩大，纪正在失去土地和人口。 [[5]](#note-6)

<a id="event-7"></a>

6. **周王室已经挫败王子克的夺位阴谋。** 周公黑肩、辛伯、王子克的行动见[前694年](bce-0694.md#event-6)。这里保留另一套纪年的阅读入口，不在本年再叙一次相同政变。 [[6]](#note-7)

<a id="sj014-0693-zheng"></a>

<a id="event-8"></a>

7. **郑国开始以公子婴元年纪事。** 祭仲在前一年子亹被杀后从陈国迎回其弟公子婴；他又称子仪，并非另一位新增国君。厉公仍据栎，争位并未彻底平息。 [[7]](#note-8)

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·庄公元年》**：“元年春，王正月。”  
   **《左传》**：“不称即位，文姜出故也。”[卷014本年鲁栏](../../拆分史书/史记/卷014.md#y0693)作“鲁庄公同元年”。**经文未书“即位”，是书法现象，不足以证明没有举行任何即位礼。** 旧文把“书写”和仪式混在一起，本次分开。

<a id="history-legacy-source-2"></a>

2. **《春秋·庄公元年》**：“三月，夫人孙于齐。”  
   **《左传》**：“不称姜氏，绝不为亲，礼也。”这是传文对书法的解释，不改作所有人已经在法律上断绝血缘的证明。

<a id="history-legacy-source-3"></a>

3. **《春秋·庄公元年》**：“夏，单伯送王姬。秋，筑王姬之馆于外。”  
   **《左传》**：“为外，礼也。”正文只写单伯送王姬、鲁筑馆，**不凭此条确定单伯必由周王遣来，也不把馆舍在外的原因简化成文姜不宜与王姬同住**。鲁在桓公新丧、又须参与王姬嫁齐的背景下办理礼事，具体职官与礼解释仍待相关传注互校。

<a id="history-legacy-source-4"></a>

4. **《春秋·庄公元年》**：“冬十月乙亥，陈侯林卒。王使荣叔来锡桓公命。”

<a id="history-legacy-source-5"></a>

5. **《春秋·庄公元年》**：“王姬归于齐。”

<a id="history-legacy-source-6"></a>

6. **《春秋·庄公元年》**记齐师迁纪之郱、鄑、郚。旧工作文本的分隔号易把纪与三邑拆成四地，本页保留纪国三邑的读法，不改原始文件。

#### 郑子婴与子仪

[卷014本年郑栏](../../拆分史书/史记/卷014.md#y0693)“子婴元年，子亹之弟”，与[《郑世家》](../../拆分史书/史记/卷042.md#part-1-text)相接；[《读史记十表》卷二](../../拆分史书/读史记十表/异本/讀史記十表-卷二.md)明言“子婴左作子仪”。这一异称属于郑君，不与同样又称子仪的周王子克合并。迎立在[前694年事件5](bce-0694.md#event-5)，被杀及厉公再入在[前680年](bce-0680.md#event-3)。

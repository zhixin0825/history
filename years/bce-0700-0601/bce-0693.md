# 公元前693年（鲁庄公元年）

[← 上一张已编年页：公元前694年](bce-0694.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前692年 →](bce-0692.md)

<a id="event-1"></a>

1. **春，鲁庄公即位，但没有举行通常的即位书写。** 桓公刚在齐国遇害，文姜又离开鲁国，鲁国内外关系都处在非常状态。[[1]](#note-1)

<a id="event-2"></a>

2. **三月，文姜逃往齐国。** 她在桓公之死后回到齐国，鲁国与齐国的婚姻关系由此成为长期政治阴影。[[2]](#note-2)

<a id="event-3"></a>

3. **夏，周王室派单伯护送王姬前往齐国成婚；鲁国秋天在城外为王姬修筑馆舍。** 因文姜事件，鲁国不适合让王姬住进国君内廷，于是把馆舍建在城外。[[3]](#note-3)

<a id="event-4"></a>

4. **冬，陈庄公去世；周王又派荣叔追赐鲁桓公命服与名位。** 鲁国一面处理桓公身后名分，一面开始庄公时代。[[4]](#note-4)

<a id="event-5"></a>

5. **王姬正式嫁到齐国。** 鲁国承担了周王室王姬出嫁过程中的一部分礼仪事务。[[5]](#note-5)

<a id="event-6"></a>

6. **齐军迁徙纪国郱、鄑、郚三地居民。** 齐国对纪国的压力继续扩大，纪国已经开始失去土地和人口。[[6]](#note-6)

<a id="event-7"></a>

7. **周王室已经挫败王子克的夺位阴谋。** 周公黑肩谋杀庄王、辛伯告发、黑肩被诛以及王子克奔燕，经过见[前694年](bce-0694.md#event-6)。本页保留另一套纪年说法，不把同一场未遂政变记成前693年再次发生。 [原文与说明](#note-7)

<a id="sj014-0693-zheng"></a>

8. **公子婴接替在齐国遇害的子亹，郑国开始以郑子婴元年纪事。** 子亹是前一年被齐襄公杀死的短暂执政者；祭仲从陈国迎回他的弟弟公子婴，郑国由此暂时维持新君政权。仍在栎地的郑厉公并未放弃后来复位的打算。[原文与说明](#sj014-0693-zheng-note)

### 7. 周公黑肩谋改立王子克，辛伯告发后诛黑肩

[卷004 P044](../../sources/摘录/史记-卷004-周本纪.md#p044)。 本纪庄王四年，卷014与鲁庄公元年同列。王子克逃燕是结果，不将他与王子颓、王子带或王子朝混为一人。

## 卷014国别互见与纪年说明

<a id="sj014-0693-zheng-note"></a>
### 郑子婴元年与周王子克事件异年

[卷014前693年郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0693)作“郑子婴元年，子亹之弟”；[《郑世家》](https://zh.wikisource.org/wiki/史記/卷042)记祭仲在子亹遇害后从陈迎其弟公子婴，隔年开始纪元。本年[周栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0693)记周公黑肩谋立王子克，但[《左传·桓公十八年》](https://zh.wikisource.org/wiki/春秋左氏傳/桓公)已将其记在[前694年](bce-0694.md#event-6)。本页旧[事件7](#event-7)保留为异年回顾，不应记为前693年又发生同一政变。

# 公元前694年（鲁桓公十八年）

[← 上一张已编年页：公元前695年](bce-0695.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前693年 →](bce-0693.md)

<a id="event-1"></a>

1. **春，鲁桓公与齐侯在泺地会面，随后带夫人文姜一同前往齐国。** 出发前已有大夫提醒，成年男女各有家庭，不应越过正常界限频繁往来；桓公仍与文姜同行。[1]

<a id="event-2"></a>

2. **到齐国后，文姜与齐侯私通，桓公发现后责备文姜，文姜又把此事告诉齐侯。** 鲁齐这次访问由外交活动迅速变成严重的宫廷冲突。[2]

<a id="event-3"></a>

3. **夏四月丙子，齐国设宴招待鲁桓公，随后让公子彭生扶桓公乘车，桓公死在车中。** 鲁国认为桓公是在齐国遭害，公开要求齐国给出交代。[3]

<a id="event-4"></a>

4. **齐国杀死公子彭生，以此回应鲁国压力；丁酉，桓公遗体从齐国运回鲁国。** 鲁齐表面上用彭生之死结束责任追究，但桓公之死已经成为两国关系中的重大裂痕。[4]

<a id="event-5"></a>

5. **秋，齐侯率军驻在首止，郑国新君公子亹与高渠弥前往会见。** 祭仲预感危险，称病没有同行。七月戊戌，齐人杀死公子亹，又把高渠弥车裂；祭仲随后从陈国迎回另一位郑公子即位。[5]

<a id="event-6"></a>

6. **周王室内部也发生政变未遂：周公黑肩准备杀周庄王，改立王子克。** 辛伯把阴谋报告给庄王，王室随即杀死周公黑肩，王子克逃往燕国。[6]

<a id="event-7"></a>

7. **冬十二月己丑，鲁国安葬桓公。** 桓公在齐国遇害八个月后完成葬礼，鲁国进入庄公时代。[7]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·桓公十八年》**：“十八年春，王正月，公会齐侯于泺。公与夫人姜氏遂如齐。”  
   **《左传·桓公十八年》**详载出行前申𦈡劝谏，桓公仍与文姜如齐。

<a id="note-2"></a>

2. **《左传·桓公十八年》**：“齐侯通焉。公谪之，以告。”

<a id="note-3"></a>

3. **《春秋·桓公十八年》**：“夏四月丙子，公薨于齐。”  
   **《左传·桓公十八年》**：“享公。使公子彭生乘公，公薨于车。”

<a id="note-4"></a>

4. **《春秋·桓公十八年》**：“丁酉，公之丧至自齐。”  
   **《左传·桓公十八年》**详记鲁人向齐交涉，齐人于是杀彭生。

<a id="note-5"></a>

5. **《左传·桓公十八年》**：“秋，齐侯师于首止，子亹会之，高渠弥相。七月戊戌，齐人杀子亹而轘高渠弥，祭仲逆郑子于陈而立之。”

<a id="note-6"></a>

6. **《左传·桓公十八年》**：“周公欲弑庄王而立王子克。辛伯告王，遂与王杀周公黑肩。王子克奔燕。”

<a id="note-7"></a>

7. **《春秋·桓公十八年》**：“冬十有二月己丑，葬我君桓公。”

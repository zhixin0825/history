1. **鲁桓公赴齐遇害，齐杀彭生，鲁迎丧下葬。** 春，鲁桓公与齐侯会于泺，随后带夫人文姜入齐。文姜与齐侯私通，桓公责备夫人，文姜告诉了齐侯。四月丙子，齐侯宴请桓公，命公子彭生扶桓公上车，桓公死在车中。鲁向齐交涉，齐人杀彭生。丁酉，桓公遗体运回鲁国。十二月己丑，鲁国安葬桓公。 [[1]](#note-1)

<a id="event-5"></a>

2. **秋，齐侯驻军首止，郑君子亹由高渠弥陪同前往会见，祭仲称病未去。** 七月戊戌，齐人杀子亹，车裂高渠弥；祭仲从陈国迎回另一位公子接掌郑国，史记称公子婴，左传又称子仪。 子亹过去曾与仍为公子的齐襄公斗争结仇。祭仲劝他不赴会，子亹却怕缺席会招来齐国讨伐，并使居栎的厉公被强行送回，认为亲赴尚有转圜；到会后他也没有向齐侯谢罪，终于被伏甲所杀。祭仲称病，是怕齐将自己一并杀害。 [[2]](#note-5)

<a id="event-6"></a>

3. **周公黑肩谋杀周庄王、改立王子克，辛伯告发后，庄王与辛伯杀了黑肩，克逃往燕国。** 王子克是庄王的弟弟，先前受父王桓王宠爱，黑肩曾被托以照顾他的责任；受宠的王子因而成为改立人选。 [[3]](#note-6)

<a id="sj014-0694-cai"></a>

<a id="event-8"></a>

4. **蔡桓侯去世后，献舞继位，本年开始用蔡哀侯元年纪事。** 蔡桓侯死亡、蔡季回国和葬礼在前695年，不都挪到本年。 [[4]](#note-8)

**[《史记·郑世家》P012](../../sources/摘录/史记-卷042-郑世家.md#p012)**

> 子亹元年七月，齊襄公會諸侯於首止，鄭子亹往會，高渠彌相，從，祭仲稱疾不行。所以然者，子亹自齊襄公為公子之時，嘗會鬬，相仇，及會諸侯，祭仲請子亹無行。子亹曰：「齊彊，而厲公居櫟，即不往，是率諸侯伐我，內厲公。我不如往，往何遽必辱，且又何至是！」卒行。於是祭仲恐齊并殺之，故稱疾。子亹至，不謝齊侯，齊侯怒，遂伏甲而殺子亹。高渠彌亡歸，歸與祭仲謀，召子亹弟公子嬰於陳而立之，是為鄭子。

**本卷说明：** 本篇作高渠弥亡归并参与迎婴，经传记齐人轘渠弥，两者不兼容；正文保留高渠弥被杀及祭仲从陈迎君，不让已死者复活。婴、仪是此君名字异文。

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·桓公十八年》**：“十八年春，王正月，公会齐侯于泺。公与夫人姜氏遂如齐。”  
   **《左传》**保存申繻的劝谏。人名在旧工作文本中有异体，按同一人物处理，不另造两位谏臣。

<a id="history-legacy-source-2"></a>

2. **《左传·桓公十八年》**：“齐侯通焉。公谪之，以告。”这些为传世的宫廷叙事，不扩充未经记载的现场细节。

<a id="history-legacy-source-3"></a>

3. **《春秋·桓公十八年》**：“夏四月丙子，公薨于齐。”  
   **《左传》**：“享公。使公子彭生乘公，公薨于车。”[卷014本年鲁、齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0694)分别从遇害、杀人与诛彭生记同一事；同年两格不是两次杀鲁君。

<a id="history-legacy-source-4"></a>

4. **《春秋·桓公十八年》**：“丁酉，公之丧至自齐。”  
   **《左传》**详载鲁人交涉、齐人杀彭生。原表“诛彭生”在此对应。

<a id="history-legacy-source-5"></a>

5. **《左传·桓公十八年》**：“秋，齐侯师于首止，子亹会之，高渠弥相。七月戊戌，齐人杀子亹而轘高渠弥，祭仲逆郑子于陈而立之。”[卷014](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0694)记子亹元年及被杀，来年[子婴元年](bce-0693.md#sj014-0693-zheng)是后继者计年。[《读史记十表》卷二](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E8%AE%80%E5%8F%B2%E8%A8%98%E5%8D%81%E8%A1%A8-%E5%8D%B7%E4%BA%8C.md#ref-2c38e12138d0cf)辨子婴、子仪异称，不为异名增加一任郑君。

<a id="history-legacy-source-6"></a>

6. **《左传·桓公十八年》**：“周公欲弑庄王而立王子克。辛伯告王，遂与王杀周公黑肩。王子克奔燕。”传文还回叙桓王宠子仪、属之周公。王子克亦称子仪，与郑公子婴的子仪异称不是同一人。

   [卷014前695年周栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0695)只说庄王“有弟克”，属于亲属背景，**不表示克在前695年出生**。该表和周本纪将阴谋列庄王四年、相当于前693；本项目保留经传的前694年主述，下一年只回链异说，不再发生一场同样政变。

<a id="history-legacy-source-7"></a>

7. **《春秋·桓公十八年》**：“冬十有二月己丑，葬我君桓公。”

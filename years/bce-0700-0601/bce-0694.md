# 公元前694年（鲁桓公十八年）

[← 上一张已编年页：公元前695年](bce-0695.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前693年 →](bce-0693.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁桓公与齐侯在泺会面，随后带夫人文姜前往齐国。** 大夫申繻曾在出发前劝止，桓公没有接受。 [[1]](#note-1)

<a id="event-2"></a>

2. **到齐以后，文姜与齐侯私通，桓公责备文姜，文姜又将此事告知齐侯。** 这次访问转成了宫廷冲突。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏四月丙子，齐国设宴招待鲁桓公，命公子彭生扶他上车，桓公死在车中。** 鲁人向齐国要求交代，指向彭生应负的责任。 [[3]](#note-3)

<a id="event-4"></a>

4. **齐国杀彭生回应鲁国；丁酉，桓公遗体运回鲁国。** 彭生被诛没有使两国间的旧怨从此消失。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋，齐侯驻军首止，郑君子亹由高渠弥陪同前往会见，祭仲称病未去。** 七月戊戌，齐人杀子亹，车裂高渠弥；祭仲从陈国迎回另一位公子接掌郑国，史记称公子婴，左传又称子仪。 [[5]](#note-5)

<a id="event-6"></a>

6. **周公黑肩谋杀周庄王、改立王子克，辛伯告发后，庄王与辛伯杀了黑肩，克逃往燕国。** 王子克是庄王的弟弟，先前受父王桓王宠爱，黑肩曾被托以照顾他的责任；受宠的王子因而成为改立人选。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬十二月己丑，鲁国安葬桓公。** 四月遇害至冬季安葬，死亡、遗体返国与丧礼是不同阶段。 [[7]](#note-7)

<a id="sj014-0694-cai"></a>

<a id="event-8"></a>

8. **蔡桓侯去世后，献舞继位，本年开始用蔡哀侯元年纪事。** 蔡桓侯死亡、蔡季回国和葬礼在前695年，不都挪到本年。 [[8]](#note-8)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·桓公十八年》**：“十八年春，王正月，公会齐侯于泺。公与夫人姜氏遂如齐。”  
   **《左传》**保存申繻的劝谏。人名在旧工作文本中有异体，按同一人物处理，不另造两位谏臣。

<a id="history-legacy-source-2"></a>


2. **《左传·桓公十八年》**：“齐侯通焉。公谪之，以告。”这些为传世的宫廷叙事，不扩充未经记载的现场细节。

<a id="history-legacy-source-3"></a>


3. **《春秋·桓公十八年》**：“夏四月丙子，公薨于齐。”  
   **《左传》**：“享公。使公子彭生乘公，公薨于车。”[卷014本年鲁、齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0694)分别从遇害、杀人与诛彭生记同一事；同年两格不是两次杀鲁君。

<a id="history-legacy-source-4"></a>


4. **《春秋·桓公十八年》**：“丁酉，公之丧至自齐。”  
   **《左传》**详载鲁人交涉、齐人杀彭生。原表“诛彭生”在此对应。

<a id="history-legacy-source-5"></a>


5. **《左传·桓公十八年》**：“秋，齐侯师于首止，子亹会之，高渠弥相。七月戊戌，齐人杀子亹而轘高渠弥，祭仲逆郑子于陈而立之。”[卷014](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0694)记子亹元年及被杀，来年[子婴元年](bce-0693.md#sj014-0693-zheng)是后继者计年。[《读史记十表》卷二](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%AE%80%E5%8F%B2%E8%A8%98%E5%8D%81%E8%A1%A8-%E5%8D%B7%E4%BA%8C.md#ref-2c38e12138d0cf)辨子婴、子仪异称，不为异名增加一任郑君。

<a id="history-legacy-source-6"></a>


6. **《左传·桓公十八年》**：“周公欲弑庄王而立王子克。辛伯告王，遂与王杀周公黑肩。王子克奔燕。”传文还回叙桓王宠子仪、属之周公。王子克亦称子仪，与郑公子婴的子仪异称不是同一人。

   [卷014前695年周栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0695)只说庄王“有弟克”，属于亲属背景，**不表示克在前695年出生**。该表和周本纪将阴谋列庄王四年、相当于前693；本项目保留经传的前694年主述，下一年只回链异说，不再发生一场同样政变。

<a id="history-legacy-source-7"></a>


7. **《春秋·桓公十八年》**：“冬十有二月己丑，葬我君桓公。”

#### 蔡哀侯元年与郑子亹的短暂在位

[卷014蔡栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0694)“蔡哀侯献舞元年”，接[前695年蔡桓侯卒](bce-0695.md#event-4)，不补改元月日。郑栏“子亹元年，齐杀子亹，昭公弟”对应本页事件5，子亹在前一年昭公遇害后被立，与本年死亡分开。依据：[《郑世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7042.md#ref-641755454b688b)。

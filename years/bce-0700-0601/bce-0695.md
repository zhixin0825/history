# 公元前695年（鲁桓公十七年）

[← 上一张已编年页：公元前696年](bce-0696.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前694年 →](bce-0694.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春正月，鲁桓公与齐侯、纪侯在黄地结盟，调停齐、纪关系，也商议卫国局势。** 纪国长期受到齐国威胁，卫国上一年又发生君位政变，这次盟会同时处理两条外交线。 [[1]](#note-1)

<a id="event-2"></a>

2. **二月，鲁桓公与邾仪父在趡地结盟，重申隐公元年的蔑盟。** 鲁、邾关系再次通过盟誓确认。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏五月，齐军侵入鲁国边界，鲁军在奚地迎战。** 鲁桓公认为边境事务应由边吏自行守备，敌军真正进入后再战，不必事事先来请命。 [[3]](#note-3)

<a id="event-4"></a>

4. **六月，蔡桓侯去世；秋天蔡人把长期在陈国的蔡季召回，随后安葬蔡桓侯。** 蔡国完成新一轮权力调整。 桓侯死后，君位由弟弟献舞承继，是为哀侯。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋，鲁国与宋、卫联军攻打邾国。** 这次行动主要由宋国推动。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬十月朔日发生日食。** 史官没有留下具体干支日，被归因于掌管历日的官员失职。 [[6]](#note-6)

<a id="event-7"></a>

7. **郑昭公一直厌恶大夫高渠弥，高渠弥担心遭清算，最终先下手杀死昭公，拥立公子亹。** 郑国在短短几年里再次发生弑君和政权更替。 早先昭公仍为太子时，已经反对父亲庄公任高渠弥为卿，庄公却没有听从。冬十月辛卯，高渠弥随昭公出猎，在野外射杀了他；祭仲与渠弥不敢迎回厉公，改立昭公弟亹，亹后来没有谥号。 [[7]](#note-7)

<a id="event-8"></a>

8. **秦武公诛杀三父等人，追究出子被杀。** 为夺立而行动的大臣，反过来成为新君清算的对象，本纪说连及三族。 [[8]](#note-8)

> 昭公二年，自昭公為太子時，父莊公欲以高渠彌為卿，太子忽惡之，莊公弗聽，卒用渠彌為卿。及昭公即位，懼其殺己，冬十月辛卯，渠彌與昭公出獵，射殺昭公於野。祭仲與渠彌不敢入厲公，乃更立昭公弟子亹為君，是為子亹也，無謚號。

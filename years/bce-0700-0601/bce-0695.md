# 公元前695年（鲁桓公十七年）

[← 上一张已编年页：公元前696年](bce-0696.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前694年 →](bce-0694.md)

<a id="event-1"></a>

1. **春正月，鲁桓公与齐侯、纪侯在黄地结盟，调停齐、纪关系，也商议卫国局势。** 纪国长期受到齐国威胁，卫国上一年又发生君位政变，这次盟会同时处理两条外交线。[1]

<a id="event-2"></a>

2. **二月，鲁桓公与邾仪父在趡地结盟，重申隐公元年的蔑盟。** 鲁、邾关系再次通过盟誓确认。[2]

<a id="event-3"></a>

3. **夏五月，齐军侵入鲁国边界，鲁军在奚地迎战。** 鲁桓公认为边境事务应由边吏自行守备，敌军真正进入后再战，不必事事先来请命。[3]

<a id="event-4"></a>

4. **六月，蔡桓侯去世；秋天蔡人把长期在陈国的蔡季召回，随后安葬蔡桓侯。** 蔡国完成新一轮权力调整。[4]

<a id="event-5"></a>

5. **秋，鲁国与宋、卫联军攻打邾国。** 这次行动主要由宋国推动。[5]

<a id="event-6"></a>

6. **冬十月朔日发生日食。** 史官没有留下具体干支日，被归因于掌管历日的官员失职。[6]

<a id="event-7"></a>

7. **郑昭公一直厌恶大夫高渠弥，高渠弥担心遭清算，最终先下手杀死昭公，拥立公子亹。** 郑国在短短几年里再次发生弑君和政权更替。[7]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·桓公十七年》**：“春正月丙辰，公会齐侯、纪侯盟于黄。”  
   **《左传·桓公十七年》**：“盟于黄，平齐、纪，且谋卫故也。”

<a id="note-2"></a>

2. **《春秋·桓公十七年》**：“二月丙午，公会邾仪父，盟于趡。”  
   **《左传·桓公十七年》**：“寻蔑之盟也。”

<a id="note-3"></a>

3. **《春秋·桓公十七年》**：“夏五月丙午，及齐师战于奚。”  
   **《左传·桓公十七年》**：“于是齐人侵鲁疆……事至而战，又何谒焉。”

<a id="note-4"></a>

4. **《春秋·桓公十七年》**：“六月丁丑，蔡侯封人卒。秋八月，蔡季自陈归于蔡。癸巳，葬蔡桓侯。”

<a id="note-5"></a>

5. **《春秋·桓公十七年》**：“及宋人、卫人伐邾。”  
   **《左传·桓公十七年》**：“伐邾，宋志也。”

<a id="note-6"></a>

6. **《春秋·桓公十七年》**：“冬十月朔，日有食之。”  
   **《左传·桓公十七年》**：“不书日，官失之也。”

<a id="note-7"></a>

7. **《左传·桓公十七年》**：“辛卯，弑昭公而立公子亹。”

# 公元前696年（鲁桓公十六年）

[← 上一张已编年页：公元前697年](bce-0697.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前695年 →](bce-0695.md)

<a id="event-1"></a>

1. **春正月，鲁、宋、蔡、卫在曹地会面，继续谋划攻郑。** 去年扶郑厉公复位失败后，诸侯没有放弃干预。[[1]](#note-1)

<a id="event-2"></a>

2. **夏四月，鲁、宋、卫、陈、蔡联合伐郑，七月鲁桓公返回。** 这次行动没有改变郑国的君位格局。[[2]](#note-2)

<a id="event-3"></a>

3. **冬，鲁国修筑向城。** 工程的时节符合当时安排农事与土工的习惯。[[3]](#note-3)

<a id="event-4"></a>

4. **此前的家庭前情：卫惠公朔的继承资格一直伴随旧怨。** 卫宣公与父亲的妾夷姜生急子，后来又娶原本为急子迎来的齐女宣姜，生寿与朔。宣姜和朔构陷急子的经过是往事，不是已经去世的宣公在本年重新下令。[[4]](#note-4)

<a id="event-5"></a>

5. **急子、寿被杀以后，左右公子怨恨后来继位的朔。** 双亡的主体叙事见[前701年](../bce-0800-0701/bce-0701.md#sj014-0701-wei)，这里只说明与本年政变的关系。[[5]](#note-5)

<a id="event-6"></a>

6. **十一月，左公子洩、右公子职拥立公子黔牟，卫惠公朔逃到齐国。** 旧日太子被害的怨恨，在朔在位数年后转成夺位。[[6]](#note-6)

<a id="sj014-0696-zhou"></a>

7. **周国开始用庄王元年计年。** 庄王佗已在前一年桓王去世后继位。年表还将王子颓的出生记在本年；颓是庄王之子，后来才会卷入王室争位。[原文与说明](#sj014-0696-zhou-note)

<a id="sj014-0696-zheng"></a>

8. **郑昭公忽复位以后，重新起算在位年次。** 他前701年曾被立又被逐，前697年再由祭仲迎回。本年所列“昭公元年”属于复位后的纪年。[原文与说明](#sj014-0696-zheng-note)

   **此前的母系：忽的母亲出自邓国，是祭仲为郑庄公迎娶的女子。** 这是早年的婚姻背景，不是说祭仲自己娶了忽的母亲，也不是本年新办婚事。[原文与说明](#sj014-0696-zheng-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·桓公十六年》**：“十有六年春正月，公会宋公、蔡侯、卫侯于曹。”  
   **《左传》**：“会于曹，谋伐郑也。”[卷014本年鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0696)同事。

<a id="note-2"></a>

2. **《春秋·桓公十六年》**：“夏四月，公会宋公、卫侯、陈侯、蔡侯伐郑。秋七月，公至自伐郑。”

<a id="note-3"></a>

3. **《春秋·桓公十六年》**：“冬，城向。”  
   **《左传》**：“冬，城向。书时也。”

<a id="note-4"></a>

4. **《左传·桓公十六年》**以“初，卫宣公烝于夷姜”引出急子、宣姜、寿、朔的家庭关系。婚姻、出生未分别确年，不作本年新事。

<a id="note-5"></a>

5. **《左传·桓公十六年》**回叙寿载急子旌先被杀，急子随后亦死，末以“二公子故怨惠公”引出政变。[卷014前701年卫栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0701)及[《卫康叔世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-c5f9cbf81928f2)提供归年坐标，主体仍在[前701年注9](../bce-0800-0701/bce-0701.md#sj014-0701-wei-note)。上一批已纠正的回叙位置不再移回本年。

<a id="note-6"></a>

6. **《春秋·桓公十六年》**：“十有一月，卫侯朔出奔齐。”  
   **《左传》**：“左公子洩、右公子职立公子黔牟。惠公奔齐。”《卫康叔世家》以惠公四年记出奔；年表提前一年记，正文依经传本年十一月，不重复两场政变。

## 卷014国别互见与纪年说明

<a id="sj014-0696-zhou-note"></a>
### 庄王元年与“生子颓”

[卷014本年周栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0696)“庄王元年生子穨”，由此暂系出生年，不补月份、日子。继位在[前697年](bce-0697.md#event-2)，母王姚及受宠见[前675年](bce-0675.md#sj004-675-1)的既有前情。年表的出生年记载不是已经独立核验过的户籍日期。

<a id="sj014-0696-zheng-note"></a>
### 忽复位与“祭仲取之”的主语

[卷014本年郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0696)作“郑昭公忽元年，忽母邓女，祭仲取之”；[《郑世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7042.md#ref-97f615daaa5aa1)将邓女、忽的出生列在郑庄公婚姻中。[《读史记十表》卷二](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%AE%80%E5%8F%B2%E8%A8%98%E5%8D%81%E8%A1%A8-%E5%8D%B7%E4%BA%8C.md#ref-05a2166db9d71a)明辨“为公取之”。本次把母系背景补到正文，但不将本格误读为祭仲娶妻。复位仍见[前697年事件5](bce-0697.md#event-5)，本年不再发生一次即位。

<a id="sj014-0696-wei-note"></a>
### 黔牟元年与经传错位

年表[前697年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0697)写朔奔、立黔牟，本年列“黔牟元年”；经传则在本年十一月才记出奔、拥立。保留这套异年，不强改原表中的王年数字；相关复入错位见[前688年注2](bce-0688.md#note-2)。

# 公元前696年（鲁桓公十六年）

[← 上一张已编年页：公元前697年](bce-0697.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前695年 →](bce-0695.md)

<a id="event-1"></a>

1. **春正月，鲁、宋、蔡、卫在曹地会面，继续谋划攻郑。** 去年扶郑厉公复位失败后，诸侯并没有放弃干预郑国内政。[[1]](#note-1)

<a id="event-2"></a>

2. **夏四月，鲁、宋、卫、陈、蔡再次联合伐郑。** 这次行动仍没有改变郑国君位格局；七月鲁桓公从战场返回。[[2]](#note-2)

<a id="event-3"></a>

3. **冬，鲁国修筑向城。** 工程发生在适宜时节，被正常记录。[[3]](#note-3)

<a id="event-4"></a>

4. **卫宣公早年的家庭安排最终酿成惨剧。** 他曾与父亲的妾夷姜生下急子，后来又娶原本为急子迎来的齐女宣姜，生下寿与朔。宣姜和公子朔不断陷害急子，卫宣公最终派人埋伏准备杀死急子。[[4]](#note-4)

<a id="event-5"></a>

5. **寿知道阴谋后抢先拿着急子的旗号上路，替哥哥被杀；急子赶到后也主动赴死。** 两兄弟先后被杀，使卫国贵族对后来即位的公子朔更加不满。[[5]](#note-5)

<a id="event-6"></a>

6. **十一月，左公子洩、右公子职拥立公子黔牟，卫惠公朔逃往齐国。** 卫国由宫廷谋杀迅速滑向政变和君位更替。[[6]](#note-6)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·桓公十六年》**：“十有六年春正月，公会宋公、蔡侯、卫侯于曹。”  
   **《左传·桓公十六年》**：“会于曹，谋伐郑也。”

<a id="note-2"></a>

2. **《春秋·桓公十六年》**：“夏四月，公会宋公、卫侯、陈侯、蔡侯伐郑。秋七月，公至自伐郑。”

<a id="note-3"></a>

3. **《春秋·桓公十六年》**：“冬，城向。”  
   **《左传·桓公十六年》**：“冬，城向。书时也。”

<a id="note-4"></a>

4. **《左传·桓公十六年》**详叙卫宣公、夷姜、急子、宣姜、寿、公子朔之间的家庭关系与谋杀计划。

<a id="note-5"></a>

5. **《左传·桓公十六年》**详记寿先载急子之旌被盗贼杀死，急子随后说“我之求也，此何罪？”也被杀。

<a id="note-6"></a>

6. **《春秋·桓公十六年》**：“十有一月，卫侯朔出奔齐。”  
   **《左传·桓公十六年》**：“左公子洩、右公子职立公子黔牟。惠公奔齐。”

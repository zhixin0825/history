# 公元前696年（鲁桓公十六年）

[← 上一张已编年页：公元前697年](bce-0697.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前695年 →](bce-0695.md)

<a id="event-1"></a>

1. **春正月，鲁、宋、蔡、卫在曹地会面，继续谋划攻郑。** 去年扶郑厉公复位失败后，诸侯并没有放弃干预郑国内政。[[1]](#note-1)

<a id="event-2"></a>

2. **夏四月，鲁、宋、卫、陈、蔡再次联合伐郑。** 这次行动仍没有改变郑国君位格局；七月鲁桓公从战场返回。[[2]](#note-2)

<a id="event-3"></a>

3. **冬，鲁国修筑向城。** 工程发生在适宜时节，被正常记录。[[3]](#note-3)

<a id="event-4"></a>

4. **此前的家庭前情：卫惠公朔的继承资格一直伴随旧怨。** 他的父亲卫宣公曾与父亲的妾夷姜生下急子，后来又娶原本为急子迎来的齐女宣姜，生寿与朔。宣姜和朔构陷急子的经过，是《左传》在本年从“初”字引入的往事，不是已故宣公在前696年重新下令。[[4]](#note-4)

<a id="event-5"></a>

5. **急子、寿先后被杀，左右公子由此怨恨后来继位的朔。** 杀人经过的主体已归[前701年](../bce-0800-0701/bce-0701.md#sj014-0701-wei)，这里仅说明它与本年政变的关系，不再次记述一场发生于本年的双亡。[[5]](#note-5)

<a id="event-6"></a>

6. **十一月，左公子洩、右公子职拥立公子黔牟，卫惠公朔逃往齐国。** 先前因太子被害积累的怨恨，在惠公在位数年后转成了这次政变。[[6]](#note-6)

<a id="sj014-0696-zhou"></a>

7. **周桓王去世后，儿子佗承位，是为周庄王；这一年开始用庄王元年计年。** 王室虽然完成继承，周与诸侯的关系并未因此恢复强势，后来庄王又遇到王子克的夺位阴谋。[原文与说明](#sj014-0696-zhou-note)

<a id="sj014-0696-zheng"></a>

8. **郑昭公忽重返国都之后，郑国重新用他的在位年次纪事。** 他曾在前701年首次即位，随后被公子突逐走；前697年祭仲迎他回国。年表本年所书“郑昭公忽元年”，是复位后的纪年阶段，不代表郑国又拥立了一个同名国君。[原文与说明](#sj014-0696-zheng-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·桓公十六年》**：“十有六年春正月，公会宋公、蔡侯、卫侯于曹。”  
   **《左传·桓公十六年》**：“会于曹，谋伐郑也。”

<a id="note-2"></a>

2. **《春秋·桓公十六年》**：“夏四月，公会宋公、卫侯、陈侯、蔡侯伐郑。秋七月，公至自伐郑。”

<a id="note-3"></a>

3. **《春秋·桓公十六年》**：“冬，城向。”  
   **《左传·桓公十六年》**：“冬，城向。书时也。”

<a id="note-4"></a>

4. **《左传·桓公十六年》**以“初，卫宣公烝于夷姜”起叙，详记急子、宣姜、寿、公子朔的家庭关系与谋杀计划。婚姻、出生未分别确年，不作为本年发生的事情。

<a id="note-5"></a>

5. **《左传·桓公十六年》**回叙寿先载急子之旌被杀，急子随后说“我之求也，此何罪？”也被杀，末以“二公子故怨惠公”引出本年政变。

   [卷014前701年卫栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0701)和[《卫康叔世家》宣公十八年](https://zh.wikisource.org/wiki/史記/卷037)提供归年依据，故主述在[前701年注9](../bce-0800-0701/bce-0701.md#sj014-0701-wei-note)。旧稿把双亡作为本年编号事件，容易让读者误认前696年仍是宣公在位；现保留旧锚点和原文来源，但明确改为往事及回链。

<a id="note-6"></a>

6. **《春秋·桓公十六年》**：“十有一月，卫侯朔出奔齐。”  
   **《左传·桓公十六年》**：“左公子洩、右公子职立公子黔牟。惠公奔齐。”

   《卫康叔世家》以惠公四年记出奔，和经传本年相接；[卷014前697年卫栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0697)却提前一年记朔奔、立黔牟。此次同步说明异年，正文仍依经传前696年十一月，不在两年重复政变；并不因此声称卷014前699年以后的所有国别已审完。

## 卷014国别互见与纪年说明

<a id="sj014-0696-zhou-note"></a>
### 周庄王元年及王子颓出生的年表说法

[卷014前696年周栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0696)作“庄王元年生子穨”；[前697年周桓王卒](bce-0697.md#event-2)，且[《周本纪》](https://zh.wikisource.org/wiki/史記/卷004)记其子佗立。王子颓后来的争位事要放在后年；“本年生”是表中记载，不能由此独立推出确切月份。

<a id="sj014-0696-zheng-note"></a>
### 郑昭公复位后的元年

[卷014前696年郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0696)作“郑昭公忽元年”；[《郑世家》](https://zh.wikisource.org/wiki/史記/卷042)记郑厉公出奔后昭公重新入郑，[前697年事件5](bce-0697.md#event-5)已有主述。本年是复位后的计年，不能覆盖前701年的第一次即位和同年的遭逐。

<a id="sj014-0696-wei-note"></a>
### 卫黔牟元年与经传继立的错位

[卷014前697年卫栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0697)提前记“朔奔齐，立黔牟”，[前696年卫栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0696)作“卫黔牟元年”；但《春秋》《左传·桓公十六年》把卫惠公朔出奔、黔牟被拥立明确叙在[前696年十一月](#event-6)。因此只保留年表的纪年信息，不把前697年表中的政变再复制为另一件史事，也不擅补具体即位日期。

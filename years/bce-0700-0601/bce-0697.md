# 公元前697年（鲁桓公十五年）

[← 上一张已编年页：公元前698年](bce-0698.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前696年 →](bce-0696.md)

<a id="event-1"></a>

1. **春二月，周王派家父来鲁国索要车辆。** 这被认为超出正常贡赋范围，因为诸侯本不需要向天子贡献车服，天子也不应私下索财。[[1]](#note-1)

<a id="event-2"></a>

2. **三月乙未，周桓王去世。** 周王室再次进入君位更替。[[2]](#note-2)

桓王死后，儿子佗接位，即庄王。 [卷四互见与归年](#sj004-697-1)


<a id="event-3"></a>

3. **夏四月，齐僖公下葬。** 齐国完成上一年国君去世后的葬礼。[[3]](#note-3)

<a id="event-4"></a>

4. **郑厉公不满祭仲专权，密谋让祭仲的女婿雍纠杀掉祭仲；雍纠的妻子雍姬却把计划告诉父亲。** 祭仲抢先杀死雍纠，把尸体陈在周氏之汪。厉公看到计划失败，只能出逃，并责怪雍纠“谋及妇人”。[[4]](#note-4)

<a id="event-5"></a>

5. **五月，郑厉公出奔蔡国，郑昭公忽重新回国即位。** 郑国第一次被宋国强行推动的君位更替被推翻，昭公恢复君位。[[5]](#note-5)

<a id="event-6"></a>

6. **同年，许叔重新进入许国；鲁桓公与齐侯在艾地会面，商议稳定许国局势。** 许国在多年被郑控制后开始恢复自身政权。[[6]](#note-6)

<a id="event-7"></a>

7. **秋，郑厉公借栎人之手杀死当地守将檀伯，进入栎地长期据守。** 他虽然失去郑都，却没有退出争位，而是在栎建立另一个权力中心。[[7]](#note-7)

<a id="event-8"></a>

8. **冬，鲁、宋、卫、陈在袲地会合并进攻郑国，想把郑厉公重新送回君位，但没有成功。** 郑国内战由国内权臣冲突扩大为诸侯干预。[[8]](#note-8)

<a id="event-9"></a>

9. **邾、牟、葛三国有人来鲁朝见。** 经文分别称邾人、牟人、葛人，没有写出三位国君亲自来朝，故保留称谓范围。 [看原文与说明](#cq-source-6)

<a id="event-10"></a>

10. **秦武公攻彭戏氏，进兵到华山下。** 武公元年仍以平阳封宫为居所。秦在这一阶段向东推进，不是已经迁到后来咸阳。 [原文与说明](#sj005-032-note)

<a id="sj014-0697-qi"></a>

11. **齐僖公去世后，太子诸儿继位，本年是齐襄公元年。** 襄公先前与公孙无知有争执；即位后降低无知原先近似太子的俸禄、服饰待遇，无知因此怀怨。齐国此后的宫廷政变由此又多了一层私人恩怨。[原文与说明](#sj014-0697-qi-note)

<a id="sj014-0697-yan"></a>

12. **燕宣侯去世后，儿子承位，是为燕桓侯，本年开始计元年。** 这次更替应接前一代燕宣侯的在位年，不能与后来同样称“桓公”的其他燕君混为一人。[原文与说明](#sj014-0697-yan-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·桓公十五年》**：“十有五年春二月，天王使家父来求车。”  
   **《左传·桓公十五年》**：“诸侯不贡车服，天子不私求财。”

<a id="note-2"></a>

2. **《春秋·桓公十五年》**：“三月乙未，天王崩。”

<a id="sj004-697-1"></a>

[卷004 P044](../../sources/摘录/史记-卷004-周本纪.md#p044)。 本纪系桓王二十三年；本年死亡、来年元年的口径不混。


<a id="note-3"></a>

3. **《春秋·桓公十五年》**：“夏四月己巳，葬齐僖公。”

<a id="note-4"></a>

4. **《左传·桓公十五年》**详记厉公使雍纠谋杀祭仲，雍姬告父，祭仲杀雍纠。

<a id="note-5"></a>

5. **《春秋·桓公十五年》**：“五月，郑伯突出奔蔡。郑世子忽复归于郑。”  
   **《左传·桓公十五年》**：“夏，厉公出奔蔡。六月乙亥，昭公入。”

<a id="note-6"></a>

6. **《春秋·桓公十五年》**：“许叔入于许。公会齐侯于艾。”  
   **《左传·桓公十五年》**：“公会齐侯于艾，谋定许也。”

<a id="note-7"></a>

7. **《春秋·桓公十五年》**：“秋九月，郑伯突入于栎。”  
   **《左传·桓公十五年》**：“郑伯因栎人杀檀伯，而遂居栎。”

<a id="note-8"></a>

8. **《春秋·桓公十五年》**：“冬十有一月，公会宋公、卫侯、陈侯于袲，伐郑。”  
   **《左传·桓公十五年》**：“谋伐郑，将纳厉公也。弗克而还。”

## 卷014国别互见与纪年说明

<a id="sj014-0697-qi-note"></a>
### 齐襄公元年与无知失宠

[卷014前697年齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0697)作齐襄公诸儿元年并记贬无知秩服；[《齐太公世家》](https://zh.wikisource.org/wiki/史記/卷032)同记襄公元年削无知待遇。相反，[前699年](bce-0699.md#sj014-0699-qi)的优待来自父辈齐僖公，前698年僖公去世；无知此时尚未弑君。

<a id="sj014-0697-yan-note"></a>
### 燕桓侯元年

[卷014前697年燕栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0697)作燕桓侯元年；[《燕召公世家》](https://zh.wikisource.org/wiki/史記/卷034)说燕宣侯十三年卒、子桓侯立，桓侯七年后由燕庄公继承。这里与[前690年燕庄公元年](bce-0690.md#sj014-0690-yan)前后衔接，不补造不见于史料的即位月日。

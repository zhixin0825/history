# 公元前697年（鲁桓公十五年）

[← 上一张已编年页：公元前698年](bce-0698.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前696年 →](bce-0696.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春二月，周王派家父来鲁索要车辆。** 诸侯不以车服作为通常贡物，天子主动索取，引起了礼制上的批评。 [[1]](#note-1)

<a id="event-2"></a>

2. **三月乙未，周桓王去世。** 儿子佗接位，即周庄王。 [卷四互见与归年](#sj004-697-1) [[2]](#note-2)

<a id="event-3"></a>

3. **夏四月，齐僖公下葬。** 齐国完成上一年国君去世后的葬礼。 [[3]](#note-3)

<a id="event-4"></a>

4. **郑厉公不满祭仲专权，让祭仲的女婿雍纠谋杀祭仲；雍纠之妻雍姬却将计划告知父亲。** 祭仲先杀雍纠，将尸体陈于周氏之汪。厉公见计败，责怪雍纠把密谋告诉妇人。 [[4]](#note-4)

<a id="event-5"></a>

5. **五月，郑厉公出奔蔡国；六月乙亥，郑昭公忽重新进入国都。** 宋国先前促成的君位更替被推翻，忽恢复君位。厉公出奔和昭公回国，是前后两个步骤，不是同在五月发生。 [[5]](#note-5)

<a id="event-6"></a>

6. **许叔重新进入许国，鲁桓公与齐侯在艾地会面，商议稳定许国局势。** 许国在被郑控制多年后，开始恢复自身政权。 [[6]](#note-6)

<a id="event-7"></a>

7. **秋九月，郑厉公借栎人之手杀死守将檀伯，进入栎地据守。** 他虽然失去郑都，却没有退出争位。 [[7]](#note-7)

<a id="event-8"></a>

8. **冬十一月，鲁、宋、卫、陈会于袲地，进攻郑国，想让厉公复位，却没有成功。** 郑国君位争夺继续牵动邻国。 [[8]](#note-8)

<a id="event-9"></a>

9. **邾、牟、葛三国有人来鲁朝见。** 经文分别称邾人、牟人、葛人，不扩写为三位国君全都亲自来朝。 [[9]](#note-9)

<a id="event-10"></a>

10. **秦武公攻彭戏氏，进兵到华山下。** 武公元年仍居平阳封宫，不是已经迁都咸阳。 [[10]](#note-10)

<a id="sj014-0697-qi"></a>

<a id="event-11"></a>

11. **齐僖公死后，太子诸儿继位，本年为齐襄公元年。** 襄公降低公孙无知原先比照太子的俸禄、服饰，无知因此怀怨。 [[11]](#note-11)

<a id="sj014-0697-yan"></a>

<a id="event-12"></a>

12. **燕宣侯去世后，儿子承位，是为燕桓侯，本年开始计元年。** 这与后来同样称“桓公”的其他燕君不是一人。 [[12]](#note-12)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·桓公十五年》**：“十有五年春二月，天王使家父来求车。”  
   **《左传》**：“诸侯不贡车服，天子不私求财。”[卷014本年鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0697)“非礼”为史家评价，随同一史事保存，不作又一次索车。

2. **《春秋·桓公十五年》**：“三月乙未，天王崩。”

<a id="sj004-697-1"></a>
<a id="桓王之后庄王佗继位卷四互见"></a>
##### 桓王之后，庄王佗继位｜卷四互见

[卷004 P044](../../sources/摘录/史记-卷004-周本纪.md#p044)。桓王二十三年死亡，与来年庄王元年的计年分开。

<a id="history-legacy-source-4"></a>


3. **《春秋·桓公十五年》**：“夏四月己巳，葬齐僖公。”

<a id="history-legacy-source-5"></a>


4. **《左传·桓公十五年》**详记厉公使雍纠谋杀祭仲，雍姬告父，祭仲杀雍纠。

<a id="history-legacy-source-6"></a>


5. **《春秋·桓公十五年》**：“五月，郑伯突出奔蔡。郑世子忽复归于郑。”  
   **《左传》**：“夏，厉公出奔蔡。六月乙亥，昭公入。”本轮按传文的明确月日分开两步，不把经文后续各句全继承五月。[卷014本年郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0697)压缩为祭仲立忽、公居栎，正文仍保留经蔡再到栎的过程。

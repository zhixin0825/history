# 公元前698年（鲁桓公十四年）

[← 上一张已编年页：公元前699年](bce-0699.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前697年 →](bce-0697.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春正月，鲁桓公与郑厉公在曹地会面，曹国按礼供应食物。** 鲁郑继续维持上一年共同作战后的合作关系。 [[1]](#note-1)

<a id="event-2"></a>

2. **春季没有结冰。** 经文将“无冰”接在春正月条中，不是说这一年冬季无冰。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，郑厉公派弟弟语到鲁国重申盟约，并延续曹地会面的成果。** 鲁郑关系继续保持稳定。 [[3]](#note-3)

<a id="event-4"></a>

4. **秋八月，鲁国御廪发生火灾，三天后仍举行尝祭。** 火灾未妨碍这次祭祀所用的粮食，仪式因而继续。 [[4]](#note-4)

<a id="event-5"></a>

5. **冬十二月丁巳，齐僖公去世。** 齐国进入君主更替。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬，宋国联合齐、蔡、卫、陈攻郑，报复上一年的战败。** 联军焚毁郑国渠门，攻入大路，又进攻东郊、夺取牛首，甚至把郑国太宫的椽木带回宋国修卢门。 [[6]](#note-6)

<a id="event-7"></a>

7. **曾经拥立出子的三父等人，又派人杀死出子，改立他的哥哥武公。** 武公原有太子身份，却没有继承到君位；此时是改立他为君，而不是一位从前已经在位的秦君重新复位。 [[7]](#note-7)

<a id="sj034-xuanhou-death-event"></a>

8. **燕宣侯去世，儿子桓侯继承。** 宣侯在位十三年，桓侯的元年从下一年开始。这里的桓侯不是百余年以后同谥的燕桓公。 [[8]](#sj034-xuanhou-death-note)

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·桓公十四年》**：“十四年春正月，公会郑伯于曹。”  
   **《左传》**：“会于曹。曹人致饩，礼也。”

<a id="history-legacy-source-2"></a>

2. **《春秋·桓公十四年》**在春正月之后书“无冰”。旧页把它放到冬季，本轮改正；保留古月口径，不直接换成现代历的正月气温。

<a id="history-legacy-source-3"></a>

3. **《春秋·桓公十四年》**：“夏五。郑伯使其弟语来盟。”  
   **《左传》**：“郑子人来寻盟，且修曹之会。”原文缺“月”的样式继续保存，正文不擅补干支。

<a id="history-legacy-source-4"></a>

4. **《春秋·桓公十四年》**：“秋八月壬申，御廪灾。乙亥，尝。”  
   **《左传》**：“书不害也。”正文只说没有妨碍本次祭祀，不从此判断火灾整体轻微。

<a id="history-legacy-source-5"></a>

5. **《春秋·桓公十四年》**：“冬十有二月丁巳，齐侯禄父卒。”

<a id="history-legacy-source-6"></a>

6. **《春秋·桓公十四年》**：“宋人以齐人、蔡人、卫人、陈人伐郑。”  
   **《左传》**详记焚渠门、入大逵、伐东郊、取牛首，携太宫椽而归。[卷014前698年郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0698)“诸侯伐我，报宋故”正是这次行动，不另造一场诸侯攻郑。

### 补充史料与异说

<a id="sj005-031-note"></a>
<a id="sj005-031出子被杀改立武公"></a>
#### sj005-031｜出子被杀，改立武公

[卷005 P009](../../sources/摘录/史记-卷005-秦本纪.md#p009) · [卷014前698年秦栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0698)。出子在位六年后遇害，年表作“立其兄武公”。旧文“恢复武公”“重新取得君位”容易把被废太子误作已经执政的君主，现改为继承资格转回武公。下一年才记武公元年。

这位春秋出子与前385年被杀的战国出子不是同一人。秦君元年、在位数的不同口径见[卷005纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)，古月干支未作历算，不当作公历日期。

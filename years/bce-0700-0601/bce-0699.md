# 公元前699年（鲁桓公十三年）

[← 上一张已编年页：公元前700年](bce-0700.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前698年 →](bce-0698.md)

<a id="event-1"></a>

1. **春，楚将屈瑕进攻罗国，因连续胜利而骄傲轻敌。** 鬥伯比一看他的步态就判断“必败”，劝楚王加强约束和支援；楚王起初没有采纳，后来再派人追赶已经来不及。[[1]](#note-1)

<a id="event-2"></a>

2. **屈瑕渡河后队伍混乱，也没有设置防备，最终被罗人与卢戎两面夹击，大败。** 屈瑕逃到荒谷后自缢，其他将领被囚等待治罪。楚王把责任归到自己身上，最终赦免诸将。[[2]](#note-2)

<a id="event-3"></a>

3. **二月，鲁桓公与纪侯、郑厉公会合，同齐、宋、卫、燕交战，齐等四国军队战败。** 宋国不断向郑国索取财物，郑难以承受，转而联合纪、鲁应战。齐军在这一战中属于与鲁、纪、郑交战的一方，不是鲁郑联军的援军。[[3]](#note-3)

<a id="event-4"></a>

4. **三月，卫宣公下葬。** 卫国结束上一年君主去世后的丧礼程序。[[4]](#note-4)

<a id="event-5"></a>

5. **夏，鲁国发生大水。** 这场水灾被记入本年经文。[[5]](#note-5)

<a id="event-6"></a>

6. **战后郑国派人来鲁，请求继续修好。** 鲁郑关系在共同作战后进一步靠近。[[6]](#note-6)

<a id="sj014-0699-qi"></a>

7. **齐僖公特别厚待侄子公孙无知。** 无知是僖公同母弟夷仲年的儿子，享有比照太子的俸禄、衣服和供养。这个特殊待遇使他获得超出普通公族的地位，也成为后来同齐襄公失和的原因。[原文与说明](#sj014-0699-qi-note)

<a id="sj014-0699-wei"></a>

8. **卫宣公去世后，儿子朔继承君位，本年开始用卫惠公元年纪事。** 朔的继位与此前太子伋、寿遇害的旧怨相连；本年不是重新发生一次杀太子事件。[原文与说明](#sj014-0699-wei-note)

<a id="sj014-0699-chen"></a>

9. **陈国以庄公林元年纪事。** 林是陈桓公的儿子；此前陈国内乱，陈侯跃在前700年去世后，林继承君位。陈国几位兄弟的称号在不同传本中容易混淆，本页只叙明确的继承衔接。[原文与说明](#sj014-0699-chen-note)

## 本年相关史料

<a id="note-1"></a>

1. **《左传·桓公十三年》**详记屈瑕伐罗，鬥伯比判断“莫敖必败，举趾高，心不固矣”。

<a id="note-2"></a>

2. **《左传·桓公十三年》**：“及罗，罗与卢戎两军之。大败之。莫敖缢于荒谷……楚子曰：‘孤之罪也。’皆免之。”

<a id="note-3"></a>

3. **《春秋·桓公十三年》**：“春二月，公会纪侯、郑伯。己巳，及齐侯、宋公、卫侯、燕人战。齐师、宋师、卫师、燕师败绩。”  
   **《左传·桓公十三年》**：“宋多责赂于郑，郑不堪命，故以纪、鲁及齐与宋、卫、燕战。”

   **说明：**旧正文将传文“及齐”读成郑又拉齐入盟，因而把齐军放到胜方，与经文明列齐军败绩相抵牾。本轮按明确的交战、败绩名单写鲁纪郑对齐宋卫燕；传文的传写、句读问题保留，不直接改动仓库原文中的“及齐”，也不声称已经证明这两个字一定为衍文。[完整经传](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E6%A1%93%E5%85%AC.md#ref-744f414d78cd91)。

<a id="note-4"></a>

4. **《春秋·桓公十三年》**：“三月，葬卫宣公。”

<a id="note-5"></a>

5. **《春秋·桓公十三年》**：“夏，大水。”

<a id="note-6"></a>

6. **《左传·桓公十三年》**：“郑人来请修好。”

## 卷014国别互见与纪年说明

<a id="sj014-0699-qi-note"></a>
### 齐僖公宠无知与后来的继承

[卷014前699年齐栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0699)记僖公给无知比照太子的秩服；[《齐太公世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7032.md#ref-b78c255b45fff8)详说无知是夷仲年之子。夷仲年去世的亲族背景不由本格另定本年死亡。前698年僖公卒、前697年襄公削减无知待遇为不同阶段，不在这里提前让襄公在位。

<a id="sj014-0699-wei-note"></a>
### 卫惠公元年

[卷014前699年卫栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0699)作“卫惠公朔元年”；[《卫康叔世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-7f587fcee577ee)记卫宣公十九年卒、朔立。[前700年卫宣公卒](bce-0700.md#event-4)与本年元年分开；太子伋、寿之死见[前701年](../bce-0800-0701/bce-0701.md#sj014-0701-wei)。

<a id="sj014-0699-chen-note"></a>
### 陈庄公林元年

[卷014前699年陈栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0699)作“陈庄公林元年”；[《陈杞世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7036.md#ref-ac97b6a798231d)记跃死后弟林立。前700年《春秋》记“陈侯跃卒”，本页据原表暂系林的元年，不用“厉”“利”等异称让一个人死亡两次。[卷014考证](../../meta/考证/史记-卷014-纪年与异说.md)。

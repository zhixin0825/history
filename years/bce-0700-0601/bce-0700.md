# 公元前700年（鲁桓公十二年）

[← 上一张已编年页：公元前701年](../bce-0800-0701/bce-0701.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前699年 →](bce-0699.md)

<a id="event-1"></a>

1. **夏六月，鲁桓公与杞侯、莒子在曲池结盟，调停杞、莒关系。** 鲁国继续充当周边诸侯之间的协调者。[[1]](#note-1)

<a id="event-2"></a>

2. **秋，鲁桓公想调停宋、郑，先后多次与宋公会面。** 双方先在穀丘结盟，后来又在虚、龟两地继续会谈；宋公始终不愿接受对郑和解。[[2]](#note-2)

<a id="event-3"></a>

3. **十一月，鲁桓公转而与郑厉公在武父结盟，随后鲁郑联军直接伐宋。** 十二月丁未，双方在宋地交战。多次盟会没有阻止战争，鲁国最终从调停者变成参战者。[[3]](#note-3)

<a id="event-4"></a>

4. **八月，陈侯跃去世；同年卫宣公晋也去世。** 两个诸侯国都进入君主更替阶段。[[4]](#note-4)

<a id="event-5"></a>

5. **楚国进攻绞国，用故意放松樵采警戒的办法诱敌。** 绞国士卒连续出城抓捕楚国役徒，越来越轻敌；第二天大批出城追逐时，楚军在山下设伏，大败绞军，逼其在城下订盟。[[5]](#note-5)

<a id="event-6"></a>

6. **楚军进攻绞国时，罗国已经派人侦察楚军渡彭水的情况。** 这次侦察成为下一年罗国反击楚军的前奏。[[6]](#note-6)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·桓公十二年》**：“夏六月壬寅，公会杞侯、莒子，盟于曲池。”  
   **《左传·桓公十二年》**：“盟于曲池，平杞、莒也。”

<a id="note-2"></a>

2. **《春秋·桓公十二年》**：“秋七月丁亥，公会宋公、燕人，盟于穀丘……公会宋公于虚。冬十有一月，公会宋公于龟。”  
   **《左传·桓公十二年》**详记桓公欲平宋、郑而宋公不肯。

<a id="note-3"></a>

3. **《春秋·桓公十二年》**：“丙戌，公会郑伯，盟于武父……十有二月，及郑师伐宋。丁未，战于宋。”  
   **《左传·桓公十二年》**：“宋公辞平，故与郑伯盟于武父。遂帅师而伐宋。”

   [卷014本年郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0700)开始以“郑厉公突元年”纪事；实际入郑已在[前701年九月](../bce-0800-0701/bce-0701.md#event-6)，本年与宋反目是后续，并不是再立一次厉公。

<a id="note-4"></a>

4. **《春秋·桓公十二年》**：“八月壬辰，陈侯跃卒……丙戌，卫侯晋卒。”

   **陈君异说：**[卷014本年陈栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0700)写“七，公淫蔡，蔡杀公”，承接此前误把陈佗称厉公的年序；《陈杞世家》更在佗与林之间另写一位仅立五月的“利公跃”。[三家注卷036《索隐》](https://zh.wikisource.org/wiki/史記三家註/卷036)已辨佗即五父、厉公为跃，指出厉、利相混。正文因此保留经文“陈侯跃卒”，不从这套矛盾谱系再复原一场本年蔡人第二次杀陈佗的故事；实际[前706年蔡人杀陈佗](../bce-0800-0701/bce-0706.md#cq-source-4)另在原处。

   **卫国衔接：**[《卫康叔世家》宣公段](https://zh.wikisource.org/wiki/史記/卷037)十九年卒、朔立，与本年宣公之死衔接；[下一年表](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0699)以卫惠公朔元年、陈庄公林元年纪事。死亡与元年分别保留，未造出受命确日。

<a id="note-5"></a>

5. **《左传·桓公十二年》**详记楚伐绞、以樵采诱敌，“大败之，为城下之盟而还”。

<a id="note-6"></a>

6. **《左传·桓公十二年》**：“伐绞之役，楚师分涉于彭。罗人欲伐之，使伯嘉谍之，三巡，数之。”

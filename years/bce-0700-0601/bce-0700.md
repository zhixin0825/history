# 公元前700年（鲁桓公十二年）

[← 上一张已编年页：公元前701年](../bce-0800-0701/bce-0701.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前699年 →](bce-0699.md)

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **夏六月，鲁桓公与杞侯、莒子在曲池结盟，调停杞、莒关系。** 鲁国继续充当周边诸侯之间的协调者。 [[1]](#note-1)

<a id="event-2"></a>

<a id="event-3"></a>

2. **鲁调停宋郑未成，转与郑结盟伐宋。** 秋，鲁桓公想调停宋、郑，多次与宋公会面。十一月，他转而与郑厉公在武父盟誓，鲁、郑共同出兵攻宋。 [[2]](#note-2)

<a id="event-4"></a>

3. **八月，陈侯跃去世；同年卫宣公晋也去世。** 两个诸侯国都进入君主更替阶段。 [[3]](#note-4)

<a id="event-5"></a>

<a id="event-6"></a>

4. **楚诱敌攻绞，罗遣人侦察楚军渡彭水。** 楚军攻绞时故意放松樵采警戒，引出绞军后伏击。楚军渡彭水时，罗国已经派人侦察。 [[4]](#note-5)

## 归年与考证

<a id="history-legacy-source-1"></a>

1. **《春秋·桓公十二年》**：“夏六月壬寅，公会杞侯、莒子，盟于曲池。”  
   **《左传·桓公十二年》**：“盟于曲池，平杞、莒也。”

<a id="history-legacy-source-2"></a>

2. **《春秋·桓公十二年》**：“秋七月丁亥，公会宋公、燕人，盟于穀丘……公会宋公于虚。冬十有一月，公会宋公于龟。”  
   **《左传·桓公十二年》**详记桓公欲平宋、郑而宋公不肯。

<a id="history-legacy-source-3"></a>

3. **《春秋·桓公十二年》**：“丙戌，公会郑伯，盟于武父……十有二月，及郑师伐宋。丁未，战于宋。”  
   **《左传·桓公十二年》**：“宋公辞平，故与郑伯盟于武父。遂帅师而伐宋。”

   [卷014本年郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0700)开始以“郑厉公突元年”纪事；实际入郑已在[前701年九月](../bce-0800-0701/bce-0701.md#event-6)，本年与宋反目是后续，并不是再立一次厉公。

<a id="history-legacy-source-4"></a>

4. **《春秋·桓公十二年》**：“八月壬辰，陈侯跃卒……丙戌，卫侯晋卒。”

   **陈君异说：**[卷014本年陈栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0700)写“七，公淫蔡，蔡杀公”，承接此前误把陈佗称厉公的年序；《陈杞世家》更在佗与林之间另写一位仅立五月的“利公跃”。[三家注卷036《索隐》](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7036.md#ref-d85d9702d178ca)已辨佗即五父、厉公为跃，指出厉、利相混。正文因此保留经文“陈侯跃卒”，不从这套矛盾谱系再复原一场本年蔡人第二次杀陈佗的故事；实际[前706年蔡人杀陈佗](../bce-0800-0701/bce-0706.md#cq-source-4)另在原处。

   **卫国衔接：**[《卫康叔世家》宣公段](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-a0164673150e29)十九年卒、朔立，与本年宣公之死衔接；[下一年表](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0699)以卫惠公朔元年、陈庄公林元年纪事。死亡与元年分别保留，未造出受命确日。

<a id="history-legacy-source-5"></a>

5. **《左传·桓公十二年》**详记楚伐绞、以樵采诱敌，“大败之，为城下之盟而还”。

<a id="history-legacy-source-6"></a>

6. **《左传·桓公十二年》**：“伐绞之役，楚师分涉于彭。罗人欲伐之，使伯嘉谍之，三巡，数之。”

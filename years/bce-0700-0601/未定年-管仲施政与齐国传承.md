# 春秋前期｜管仲施政与齐国传承（未定年）

[本世纪目录](README.md) · [全部时间目录](../README.md)

**时间精度：未定年与任职期间总述。** 本页承接前685年管仲受荐以后的长期施政与身后概述。各项政令没有独立施行年，不把它们全部放到受任当日。鲍叔后人十余世的禄位也不据世数分配年份。

<a id="sj062-policy-event"></a>

1. **管仲把财用、民生与政令的可行性连在一起。** 他在齐国主持政事，推动货物流通、积聚财用，以富国强兵，施政尽量顺应民众的好恶。他把仓廪、衣食充足视为理解礼节荣辱的重要条件，要求在上者服用有度、维持亲属与礼义秩序，认为政令应像流水顺势而行。民众所愿的便设法给予，所厌恶的便除去。 [[1]](#sj062-policy-note)

<a id="sj062-convert-event"></a>

2. **转祸为福、在给予中取得政治收益，是对管仲处事的概括。** 他能把一时失利或君主私怨转成可用的政治机会，审慎衡量轻重得失。柯盟之后，他使桓公遵守对曹沫作出的承诺；北征山戎后，他要求燕国恢复召公的政治传统；桓公因蔡姬而袭蔡时，他又借势转向楚国，责问包茅不贡。桓公守约以后，诸侯归向齐国，由此可见给予也能成为取得的办法。 [[2]](#sj062-convert-note)

<a id="sj062-wealth-event"></a>

3. **管仲富比公室，齐人仍不以为奢侈。** 他拥有接近公室的财富，以及三归、反坫一类享用，齐人却不以为奢侈。 [[3]](#sj062-wealth-note)

<a id="sj062-bao-descendants-event"></a>

4. **鲍叔后人世代享有齐国禄位，史家尤其称许鲍叔知人。** 鲍叔推荐管仲并甘愿居其下，后人世代在齐享禄，拥有封邑延续十余世，常为名大夫。史家在段末特别称许鲍叔的识人之明。 [[4]](#sj062-bao-descendants-note)

## 本期相关史料

<a id="sj062-policy-note"></a>

### 1. 管仲把财用、民生与政令的可行性连在一起

[返回正文第1条](#sj062-policy-event)

<a id="sj062-cite-001"></a>

**[《史记·管晏列传》P004](../../sources/摘录/史记-卷062-管晏列传.md#p004)**

> 管仲既任政相齊，以區區之齊在海濱，通貨積財，富國彊兵，與俗同好惡。故其稱曰：「倉廩實而知禮節，衣食足而知榮辱，上服度則六親固。四維不張，國乃滅亡。下令如流水之原，令順民心。」故論卑而易行。俗之所欲，因而予之；俗之所否，因而去之。

**本卷说明：** 六亲和四维为古代伦理用语；三家注列礼义廉耻并保存两种六亲列法。这里不据此宣布一套现代制度，也不把全部政策提前到任相同日。

### 2. 转祸为福、在给予中取得政治收益，是对管仲处事的概括

[返回正文第2条](#sj062-convert-event)

<a id="sj062-cite-002"></a>

**[《史记·管晏列传》P005](../../sources/摘录/史记-卷062-管晏列传.md#p005)**

> 其為政也，善因禍而為福，轉敗而為功。貴輕重，慎權衡。

**本卷说明：** 这里是跨年归纳，不能把不同战争和盟约并成一次行动。轻重索隐释钱，正义则释耻辱轻重，并以得失释权衡；两种解释不暗改为只有一种经济政策。

<a id="sj062-wealth-note"></a>

### 3. 管仲富比公室，齐人仍不以为奢侈

[返回正文第3条](#sj062-wealth-event)

<a id="sj062-cite-004"></a>

**[《史记·管晏列传》P006](../../sources/摘录/史记-卷062-管晏列传.md#p006)**

> 管仲富擬於公室，有三歸、反坫，齊人不以為侈。

**本卷说明：** 这是传文对生活与声望的并写，不意味着制度上没有礼等限制，也不推为齐国人人都赞成任何奢费。本卷正义释三归为三姓女；仅凭这一古注不足以裁定全部三归异说。反坫原句未记数量尺寸。管仲之死与后续政制另见前645年，同一段不整包重复到每一年。

<!-- /sj062-cite-004 -->



<a id="sj062-bao-descendants-note"></a>

### 4. 鲍叔后人世代享有齐国禄位，史家尤其称许鲍叔知人

[返回正文第4条](#sj062-bao-descendants-event)

<a id="sj062-cite-005"></a>

**[《史记·管晏列传》P003](../../sources/摘录/史记-卷062-管晏列传.md#p003)**

> 子孫世祿於齊，有封邑者十餘世，常為名大夫。天下不多管仲之賢而多鮑叔能知人也。

**本卷说明：** 这里没有逐人的受封和去世年表。索隐在这里引庄仲山、敬仲夷吾以下管氏谱，确与承鲍叔的文势不合。正文保留顺文读法，注中标出矛盾；不据其“凡十代”把原文十余世改字或为鲍叔虚添管氏后裔。

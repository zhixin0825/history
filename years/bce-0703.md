# 公元前703年（鲁桓公九年）

[← 上一张已编年页：公元前704年](bce-0704.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前702年 →](bce-0702.md)

<a id="event-1"></a>

1. **春，纪季姜正式嫁入周王室，成为王后。** 在诸侯女儿出嫁的记录中，王后入京师因为关系到天子婚姻而被特别记载。[1]

<a id="event-2"></a>

2. **巴国希望借楚国同邓国修好，邓国边境的鄾人却抢走聘礼，并杀死楚使道朔和巴国行人。** 楚国要求邓国处置，邓国拒绝，冲突随即升级。[2]

<a id="event-3"></a>

3. **夏，楚军与巴军围攻鄾地，邓军前来救援，反被楚、巴夹击大败。** 楚将鬥廉先故意后退，引邓军追击；邓军转身追楚时把巴军暴露在身后，最终遭到夹攻，鄾人在夜里溃散。[3]

<a id="event-4"></a>

4. **秋，虢仲、芮伯、梁伯、荀侯、贾伯联合攻打曲沃。** 多国势力继续试图压制曲沃扩张。[4]

<a id="event-5"></a>

5. **冬，曹国太子射姑来鲁朝见，鲁国以上卿之礼接待。** 宴饮时太子听到乐声叹息，鲁国施父认为这不是正常的宴享表现，担心他将有忧患。[5]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·桓公九年》**：“九年春，纪季姜归于京师。”  
   **《左传·桓公九年》**：“凡诸侯之女行，唯王后书。”

<a id="note-2"></a>

2. **《左传·桓公九年》**详记巴子请楚与邓修好，邓南鄙鄾人夺币，杀楚使道朔及巴行人。

<a id="note-3"></a>

3. **《左传·桓公九年》**：“夏，楚使鬥廉帅师及巴师围鄾……而夹攻之，邓师大败，鄾人宵溃。”

<a id="note-4"></a>

4. **《左传·桓公九年》**：“秋，虢仲、芮伯、梁伯、荀侯、贾伯伐曲沃。”

<a id="note-5"></a>

5. **《春秋·桓公九年》**：“冬，曹伯使其世子射姑来朝。”  
   **《左传·桓公九年》**：“宾之以上卿，礼也……乐奏而叹。”

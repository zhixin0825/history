# 公元前704年（鲁桓公八年）

[← 上一张已编年页：公元前705年](bce-0705.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前703年 →](bce-0703.md)

<a id="event-1"></a>

1. **春，晋国翼地政权被灭。** 曲沃势力经过多年争夺，已经把翼地政权逼到崩溃；周王室随后仍试图另立晋君维持旧秩序。[1]

<a id="event-2"></a>

2. **正月，鲁国举行烝祭，周天子派家父来聘问；五月又举行一次烝祭。** 一年中两次烝祭都被记录下来。[2]

<a id="event-3"></a>

3. **夏，楚武王在沈鹿召集诸侯，黄国、随国没有参加；楚国随即进攻随国。** 随国大夫季梁建议先让楚军骄躁疲惫再战，但少师坚持速战，随侯采纳少师意见。[3]

<a id="event-4"></a>

4. **楚、随在速杞交战，随军大败，随侯逃脱，少师被俘。** 随军没有按照季梁建议避开楚王主力，结果战败；秋天双方重新讲和。[4]

<a id="event-5"></a>

5. **秋，鲁国出兵攻邾。** 现存本年记载没有留下更详细的战斗过程。[5]

<a id="event-6"></a>

6. **冬十月，鲁国下雪。** 这一天气现象被单独记入年表。[6]

<a id="event-7"></a>

7. **周王命虢仲另立晋哀侯之弟缗为晋君。** 王室试图在翼地政权崩溃后继续维持一个不受曲沃控制的晋国君位。[7]

<a id="event-8"></a>

8. **冬，祭公来鲁，随后前往纪国迎接王后。** 周王室从纪国迎娶王后，祭公承担迎亲任务。[8]

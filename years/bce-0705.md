# 公元前705年（鲁桓公七年）

[← 上一张已编年页：公元前706年](bce-0706.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前704年 →](bce-0704.md)

<a id="event-1"></a>

1. **春二月，鲁国在咸丘焚烧草木围猎。** 这一条只保存行动本身，没有留下更长的经过。[1]

<a id="event-2"></a>

2. **夏，穀伯绥和邓侯吾离先后来鲁朝见。** 两位国君都以名字被记录，反映他们在当时礼制秩序中的地位不高。[2]

<a id="event-3"></a>

3. **盟、向两地先向郑国求和，随后又背弃约定。** 郑国很快联合齐、卫出兵讨伐。[3]

<a id="event-4"></a>

4. **秋，郑、齐、卫攻打盟、向，周王随后把两地居民迁到郏。** 盟、向原有政治格局被打散，人口被王室重新安置。[4]

<a id="event-5"></a>

5. **冬，曲沃伯诱骗晋小子侯并将其杀死。** 晋国内部的曲沃—翼争位再次升级，翼地政权又失去一位君主。[5]

<a id="note-3"></a>

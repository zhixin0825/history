# 公元前708年（鲁桓公四年）

[← 上一张已编年页：公元前709年](bce-0709.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前707年 →](bce-0707.md)

<a id="event-1"></a>

1. **春正月，鲁桓公在郎地狩猎。** 这次狩猎发生在合适的季节，被视为正常的国君田猎活动。[1]

<a id="event-2"></a>

2. **夏，周王派宰渠伯纠到鲁国聘问。** 这是周王室与鲁国之间的一次正式外交往来。[2]

<a id="event-3"></a>

3. **秋，秦军进攻芮国，却遭到失败。** 芮国内乱已经持续数年，秦国开始直接介入。[3]

<a id="event-4"></a>

4. **冬，周王师与秦军联合包围魏地，抓获芮伯并带走。** 芮国的内部纷争最终演变为周、秦共同出兵。[4]

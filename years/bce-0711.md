# 公元前711年（鲁桓公元年）

[← 上一张已编年页：公元前712年](bce-0712.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前710年 →](bce-0710.md)

<a id="event-1"></a>

1. **春，鲁桓公正式即位。** 隐公死后，桓公取得君位；鲁国随即着手修复与郑国的关系。[1]

<a id="event-2"></a>

2. **三月，鲁桓公与郑庄公在垂地会面，郑国以玉璧为礼，推动许田与祊田的交换。** 郑国希望恢复祭祀周公的安排，鲁国最终同意完成这次土地交换。[2]

<a id="event-3"></a>

3. **夏四月丁未，鲁桓公与郑庄公在越地盟誓，为土地交换收尾。** 双方把这次交易正式固定下来，并以“违盟者不得长久享国”相互约束。[3]

<a id="event-4"></a>

4. **秋，鲁国发生大水。** 平原水位漫出，被记录为“大水”。[4]

<a id="event-5"></a>

5. **冬，郑庄公再次确认盟约。** 郑国对越地之盟表示承认，鲁郑关系暂时稳定下来。[5]

<a id="event-6"></a>

6. **宋国太宰华父督在路上见到司马孔父的妻子，被她的美貌吸引。** 这一念头很快演变成下一年宋国内乱的直接导火索。[6]

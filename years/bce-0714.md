# 公元前714年（鲁隐公九年）

[← 上一张已编年页：公元前715年](bce-0715.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前713年 →](bce-0713.md)

<a id="event-1"></a>

1. **春，周天子派南季来鲁国聘问。** 现存本年记载没有再说明这次聘问的具体任务。[1]

<a id="event-2"></a>

2. **三月，鲁国接连出现异常天气：先大雨雷电，随后又下大雪。** 这些现象被视为时令失常；连续三日以上的雨称“霖”，平地积雪一尺则称“大雪”。[2]

<a id="event-3"></a>

3. **这一年名为“挟”的鲁国人物去世。** 现存本年记载没有补充他的身份和丧事经过。[3]

<a id="event-4"></a>

4. **夏，鲁国修筑郎城。** 这项工程被认为施工时间不合适。[4]

<a id="event-5"></a>

5. **宋殇公不朝周王，郑庄公以周王左卿士身份奉王命讨伐宋国；宋国没有把王命转告鲁国，鲁国因此与宋断绝使者往来。** 秋天，郑国专程来鲁通知伐宋。宋、郑旧怨与周王命令由此交织在一起。[5]

<a id="event-6"></a>

6. **冬，鲁隐公与齐侯在防地会面，商议共同攻宋。** 这是前一条宋郑冲突向鲁齐两国扩展的结果。[6]

<a id="event-7"></a>

7. **北戎入侵郑国，郑军利用伏兵大败戎军。** 郑军担心戎兵都是步卒、机动迅速，公子突建议派兵诱敌后退，再布置多层伏兵。戎军贪进、前后不能互救，郑军于是合击。十一月甲寅，北戎大败。[7]

1. **《春秋·隐公九年》**：“九年春，天子使南季来聘。”

<a id="note-2"></a>

2. **《春秋·隐公九年》**：“三月癸酉，大雨震电。庚辰，大雨雪。”  
   **《左传·隐公九年》**：“大雨霖以震，书始也。庚辰，大雨雪，亦如之。书时失也。”

<a id="note-3"></a>

3. **《春秋·隐公九年》**：“挟卒。”

<a id="note-4"></a>

4. **《春秋·隐公九年》**：“夏，城郎。”  
   **《左传·隐公九年》**：“夏，城郎，书不时也。”

<a id="note-5"></a>

5. **《左传·隐公九年》**：“宋公不王。郑伯为王左卿士，以王命讨之，伐宋……秋，郑人以王命来告伐宋。”

<a id="note-6"></a>

6. **《春秋·隐公九年》**：“冬，公会齐侯于防。”  
   **《左传·隐公九年》**：“冬，公会齐侯于防，谋伐宋也。”

<a id="note-7"></a>

7. **《左传·隐公九年》**详叙“北戎侵郑”，公子突建议诱敌设伏，最后“十一月甲寅，郑人大败戎师”。

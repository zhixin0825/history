# 公元前715年（鲁隐公八年）

[← 上一张已编年页：公元前716年](bce-0716.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前714年 →](bce-0714.md)

<a id="event-1"></a>

1. **春，宋公与卫侯先在垂地相见，为齐国调停宋、卫关系做准备。** 齐侯原本准备让宋、卫正式和解，宋公先送礼请求同卫侯提前见面，卫侯答应，因此有了这次会面。[1]

<a id="event-2"></a>

2. **三月，郑庄公把祊地交给鲁国，鲁国随后正式接收。** 郑国希望放弃泰山祭祀相关权利，用祊地交换鲁国的许田，所以派大夫宛来鲁办理交割。庚寅，鲁国进入祊地。[2]

<a id="event-3"></a>

3. **夏，虢公忌父开始在周王室担任卿士。** 这反映周王室内部权力安排的变化，也同郑国此前对周王重用虢氏的不满有关。[3]

<a id="event-4"></a>

4. **四月，郑公子忽到陈国迎娶妫氏，婚礼程序随后受到批评。** 公子忽先把妫氏娶回郑国，后来才告祖庙。陈国送亲的鍼子批评“先配而后祖”，认为这不是合乎礼制的婚姻程序。[4]

<a id="event-5"></a>

5. **秋，齐国终于完成宋、卫之间的调停，宋、齐、卫三国在瓦屋结盟。** 这次结盟化解此前围绕郑国“东门之役”留下的矛盾；郑庄公八月还带齐人朝见周王。[5]

<a id="event-6"></a>

6. **九月，鲁隐公与莒人在浮来结盟，进一步巩固鲁、纪、莒之间的关系。** 这次盟会同鲁国和纪国的婚姻外交有关。[6]

<a id="event-7"></a>

7. **这一年蔡侯考父、宿国国君先后去世，鲁国又安葬蔡宣公。** 六月己亥蔡侯去世，辛亥宿国国君去世；八月，蔡宣公下葬。现存本年记载没有进一步展开他们的死亡经过。[7]

<a id="event-8"></a>

8. **这一年发生螟灾。** 现存本年记载没有进一步说明灾情规模。[8]

<a id="event-9"></a>

9. **冬十二月，无骇去世，鲁国从此为他的后人确定“展氏”这一族氏。** 羽父请求给无骇确定谥和族，隐公询问众仲姓氏制度。众仲解释天子赐姓、诸侯以字为族以及官族、邑氏等规则，隐公最后以无骇的字命为展氏。[9]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·隐公八年》**：“八年春，宋公、卫侯遇于垂。”  
   **《左传·隐公八年》**：“齐侯将平宋、卫，有会期。宋公以币请于卫，请先相见，卫侯许之，故遇于犬丘。”

<a id="note-2"></a>

2. **《春秋·隐公八年》**：“三月，郑伯使宛来归祊。庚寅，我入祊。”  
   **《左传·隐公八年》**：“郑伯请释泰山之祀而祀周公，以泰山之祊易许田。三月，郑伯使宛来归祊。”

<a id="note-3"></a>

3. **《左传·隐公八年》**：“夏，虢公忌父始作卿士于周。”

<a id="note-4"></a>

4. **《左传·隐公八年》**：“四月甲辰，郑公子忽如陈逆妇妫……先配而后祖，鍼子曰：‘是不为夫妇。诬其祖矣，非礼也。’”

<a id="note-5"></a>

5. **《春秋·隐公八年》**：“秋七月庚午，宋公、齐侯、卫侯盟于瓦屋。”  
   **《左传·隐公八年》**：“齐人卒平宋、卫于郑。秋，会于温，盟于瓦屋，以释东门之役，礼也。”

<a id="note-6"></a>

6. **《春秋·隐公八年》**：“九月辛卯，公及莒人盟于浮来。”  
   **《左传·隐公八年》**：“公及莒人盟于浮来，以成纪好也。”

<a id="note-7"></a>

7. **《春秋·隐公八年》**：“夏六月己亥，蔡侯考父卒。辛亥，宿男卒……八月，葬蔡宣公。”

<a id="note-8"></a>

8. **《春秋·隐公八年》**：“螟。”

<a id="note-9"></a>

9. **《春秋·隐公八年》**：“冬十有二月，无骇卒。”  
   **《左传·隐公八年》**：“无骇卒。羽父请谥与族……公命以字为展氏。”

# 公元前718年（鲁隐公五年）

[← 上一张已编年页：公元前719年](bce-0719.md) · [总目录](../README.md#year-list) · [下一张已编年页：公元前717年 →](bce-0717.md)

<a id="event-1"></a>

1. **春，鲁隐公到棠地观看捕鱼，臧僖伯认为这种游观不合国君礼制。** 臧僖伯劝隐公，国君亲自出动应当为了军事训练、祭祀礼制或国家器用等大事，不该为了普通捕鱼游玩。隐公仍然前往，臧僖伯称病不随行。[1]

<a id="event-2"></a>

2. **同一时期，曲沃庄伯联合郑、邢攻打晋国旧都翼，翼侯逃往随。** 这是晋国内部曲沃与翼长期争位的一环；周王室还派尹氏、武氏帮助曲沃一方。[2]

<a id="event-3"></a>

3. **夏四月，卫国安葬前一年被州吁杀死的卫桓公。** 因卫国内乱，正常葬礼一直拖到这一年才举行。[3]

<a id="event-4"></a>

4. **郑、卫冲突继续升级，郑军在北制击败卫国援军燕师。** 郑国先为报复“东门之役”进攻卫牧；卫国随后借燕军反击。郑军把主力列在正面，又让两位公子带兵潜伏后方。燕军只防着正面郑军，没有料到后方伏兵，最终在北制大败。[4]

<a id="event-5"></a>

5. **秋，曲沃再次反叛周王，周王命虢公出兵，重新在翼地立晋哀侯。** 晋国内部的君位争夺继续受到周王室直接干预。[5]

<a id="event-6"></a>

6. **卫军攻入郕国，报复郕国曾趁卫国内乱时入侵卫国。** 这次行动是州吁之乱后的直接报复。[6]

<a id="event-7"></a>

7. **九月，鲁国祭告仲子之宫，第一次使用六羽之舞。** 隐公询问舞者应当用多少羽，众仲回答：天子八佾、诸侯六佾、大夫四佾、士二佾。鲁国于是采用六羽之舞。[7]

<a id="event-8"></a>

8. **邾、郑联合攻宋，攻入宋国外城；宋国随后反攻郑国，包围长葛。** 宋人此前夺取邾地，邾国便请求郑国带路报复。郑军借王师名义伐宋，攻入其郛；到了冬天，宋国又伐郑并围长葛，双方冲突继续扩大。[8]

<a id="event-9"></a>

9. **这一年还发生螟灾；十二月，公子彄（臧僖伯）去世。** 隐公记得臧僖伯此前曾因观鱼之事不满自己，因此在葬礼上给他加等礼遇。[9]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·隐公五年》**：“五年春，公矢鱼于棠。”  
   **《左传·隐公五年》**详载臧僖伯谏隐公不应为观鱼亲出，并说：“书曰‘公矢鱼于棠’，非礼也，且言远地也。”

<a id="note-2"></a>

2. **《左传·隐公五年》**：“曲沃庄伯以郑人、邢人伐翼，王使尹氏、武氏助之。翼侯奔随。”

<a id="note-3"></a>

3. **《春秋·隐公五年》**：“夏四月，葬卫桓公。”  
   **《左传·隐公五年》**：“夏，葬卫桓公。卫乱，是以缓。”

<a id="note-4"></a>

4. **《左传·隐公五年》**详叙郑侵卫牧、卫以燕师伐郑，郑军前后设伏，“六月，郑二公子以制人败燕师于北制。”

<a id="note-5"></a>

5. **《左传·隐公五年》**：“曲沃叛王。秋，王命虢公伐曲沃而立哀侯于翼。”

<a id="note-6"></a>

6. **《春秋·隐公五年》**：“秋，卫师入郕。”  
   **《左传·隐公五年》**：“卫之乱也，郕人侵卫，故卫师入郕。”

<a id="note-7"></a>

7. **《春秋·隐公五年》**：“九月，考仲子之宫，初献六羽。”  
   **《左传·隐公五年》**载众仲答羽数：“天子用八，诸侯用六，大夫四，士二……于是初献六羽、始用六佾也。”

<a id="note-8"></a>

8. **《春秋·隐公五年》**：“邾人、郑人伐宋……宋人伐郑，围长葛。”  
   **《左传·隐公五年》**详叙宋取邾田、邾请郑伐宋、郑入宋郛，以及宋围长葛“以报入郛之役”。

<a id="note-9"></a>

9. **《春秋·隐公五年》**：“螟。冬十有二月辛巳，公子彄卒。”  
   **《左传·隐公五年》**：“冬十二月辛巳，臧僖伯卒。公曰：‘叔父有憾于寡人，寡人弗敢忘。’葬之加一等。”

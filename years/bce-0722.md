# 公元前722年（鲁隐公元年）

[总目录](../README.md#year-list) · [下一张已编年页：公元前721年 →](bce-0721.md)

<a id="event-1"></a>

1. **春，鲁隐公开始摄政。** 鲁惠公去世时，桓公年幼，隐公先代行国君职权，准备以后把君位交给桓公。[1]

<a id="event-2"></a>

2. **三月，鲁隐公与邾仪父在蔑地结盟。** 隐公刚摄政，希望修复鲁、邾关系；邾君当时尚未得到周王正式册命，因此仍以“仪父”称呼。[2]

<a id="event-3"></a>

3. **夏四月，费伯擅自筑郎城；五月，郑庄公在鄢击败弟弟共叔段。** 筑郎城并非出自鲁隐公命令。郑国内乱则更严重：郑武公夫人武姜一直偏爱共叔段，庄公即位后又让段据守京地。段逐步扩张势力，最后整备军队准备袭郑，武姜还准备从城内接应。庄公这才命公子吕出兵，京人背叛共叔段，段逃到鄢后再败，最终出奔共国。[3]

<a id="event-4"></a>

4. **共叔段失败后，郑庄公把母亲武姜迁到城颍，后来又设法与她和好。** 庄公曾发誓“不及黄泉，无相见也”，事后后悔。颍考叔建议挖地见泉，在地道里相见，就不算违背誓言。庄公照做，母子恢复关系。[4]

<a id="event-5"></a>

5. **秋七月，周天子派宰咺给鲁惠公、仲子送赗礼。** 礼物来得较晚，而且仲子当时还没有去世，等于提前办理凶礼，因此这次行动受到批评。[5]

<a id="event-6"></a>

6. **八月，纪人攻打夷；同年又出现蜚虫。** 夷没有向鲁国通报战事；蜚虫也没有造成灾害，因此两件事都没有进入鲁国的正式年表记录。[6]

<a id="event-7"></a>

7. **九月，鲁国与宋人在宿地结盟，鲁、宋开始恢复往来。** 鲁惠公晚年曾在黄地击败宋军，隐公摄位后希望重新讲和，于是双方在宿地结盟。[7]

<a id="event-8"></a>

8. **冬十月，鲁国改葬惠公，卫侯也来参加葬礼。** 隐公本人没有亲临改葬；卫侯虽然来会葬，也没有见到隐公。[8]

<a id="event-9"></a>

9. **郑国内乱的余波继续波及卫国，郑、卫又发生冲突。** 共叔段之乱后，公孙滑逃到卫国。卫人为他攻郑并夺廪延；郑国随后借王师、虢师反攻卫国南境。鲁国公子豫未经隐公允许，又私自参加邾、郑在翼地的结盟。[9]

<a id="event-10"></a>

10. **鲁国新建南门。** 这项工程并非隐公正式下令，因此没有列入鲁国正式年表。[10]

<a id="event-11"></a>

11. **十二月，祭伯来到鲁国；公子益师去世。** 祭伯并非奉周王命令而来。益师即众父；隐公没有参加他的小敛，因此死亡日期没有被正式记录。[11]

   **《左传·隐公元年》**：“夏四月，费伯帅师城郎。不书，非公命也。”又详叙武姜偏爱共叔段、段据京扩张、准备袭郑，庄公出兵，五月辛丑段出奔共。


<a id="sj-042-L3772-01"></a>

#### 补充互见｜郑庄公击败弟弟段，武姜被迁出

**时间：鲁隐公元年五月；郑庄公二十二年** · 事件

《春秋》只简记郑伯在鄢击败段。《郑世家》补充，段受封于京后整备兵力，与母亲武姜合谋；庄公出兵，段先离京、再离鄢，逃到共。庄公随后迁母，并发誓不到黄泉不相见。

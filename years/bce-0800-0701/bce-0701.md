# 公元前701年（鲁桓公十一年）

[← 上一张已编年页：公元前702年](bce-0702.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前700年 →](../bce-0700-0601/bce-0700.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **春，齐、卫、郑、宋在恶曹结盟。** 几个中原诸侯重新调整彼此关系，宋国也加入这次盟会。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **楚将屈瑕准备同贰、轸结盟，却先遭到郧国及其盟友威胁。** 郧军驻蒲骚，又准备联合随、绞、州、蓼夹击楚军。鬥廉主张主动夜袭郧军，认为郧人依仗城池、等待援军，反而戒备不足。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **楚军夜袭蒲骚，击败郧军，屈瑕最终完成盟约。** 屈瑕本想增兵、占卜，鬥廉都认为没有必要，强调胜负关键在军心协同而不在兵多。他提出，若先击败郧军，等待来援的四国就会离散；楚军随后依计打赢，结盟而还。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **五月，郑庄公去世。** 郑国进入继承危机，几位公子都具备争位条件。 [[4]](#reading-note-4)

<a id="reading-event-5"></a>

5. **秋七月，郑庄公安葬。** 庄公之死及其后的郑国继承争端之外，经文还单独记下了七月的葬礼。 [[5]](#reading-note-5)

<a id="event-5"></a>

<a id="reading-event-6"></a>

6. **祭仲先拥立太子忽为郑昭公，宋国随后扣押祭仲，逼他改立公子突。** 公子突的母族雍氏在宋庄公身边得宠，宋人抓住祭仲，威胁“不立突，将死”，又扣押公子突索取财物。祭仲被迫妥协，带公子突回郑。 [[6]](#reading-note-6)

<a id="event-6"></a>

<a id="reading-event-7"></a>

7. **九月，郑昭公忽逃往卫国，公子突即位，是为郑厉公。** 郑国政权在短时间内完成一次强行更替。 [[7]](#reading-note-7)

<a id="event-7"></a>

<a id="reading-event-8"></a>

8. **鲁国继续与宋、陈、蔡等国频繁会盟。** 鲁大夫柔同宋公、陈侯、蔡叔在析结盟，桓公又先后在夫钟、阚与宋公会面。 [[8]](#reading-note-8)

<a id="sj014-0701-cao"></a>

<a id="reading-event-9"></a>

9. **曹国开始以庄公射姑元年纪事。** 射姑在前703年还是来鲁朝见的太子，前一年父亲曹桓公去世，他承接君位，本年进入自己的纪年。 [[9]](#reading-note-9)

<a id="sj014-0701-wei"></a>

<a id="reading-event-10"></a>

10. **卫宣公命人杀太子伋，公子寿却想用自己替哥哥赴死，最后两人都被杀。** 太子伋又称急子，是夷姜之子；宣公后来娶了原本为太子选定的齐女，生寿和朔。齐女宣姜与公子朔一同诋毁太子，宣公遂让太子出使，安排盗贼按旗号认人、途中杀害。寿得知后劝哥哥逃走，急子不肯违背父命；寿于是带着哥哥的旗先出发，被盗贼误杀。急子随后赶到，说明应当被杀的是自己，也遇害。 [[10]](#reading-note-10)

<a id="reading-event-11"></a>

11. **公子朔由此被立为太子。** 辅导急子、寿的左右公子对朔积下怨恨；宣公后来死亡、朔继位，以及左右公子驱逐朔，是此事逐步展开的后果，不全发生在本年。 [[11]](#reading-note-11)

### 10. 卫宣公命人杀太子伋，公子寿却想用自己替哥哥赴死，最后两人都被杀

[返回正文第10条](#reading-event-10)

<a id="sj037-cite-028"></a>

**[《史记·卫康叔世家》P013](../../sources/摘录/史记-卷037-卫康叔世家.md#p013)**

> 十八年，初，宣公愛夫人夷姜，夷姜生子伋，以為太子，而令右公子傅之。右公子為太子取齊女，未入室，而宣公見所欲為太子婦者好，說而自取之，更為太子取他女。宣公得齊女，生子壽、子朔，令左公子傅之。太子伋母死，宣公正夫人與朔共讒惡太子伋。宣公自以其奪太子妻也，心惡太子，欲廢之。及聞其惡，大怒，乃使太子伋於齊而令盜遮界上殺之，與太子白旄，而告界盜見持白旄者殺之。且行，子朔之兄壽，太子異母弟也，知朔之惡太子而君欲殺之，乃謂太子曰：「界盜見太子白旄，即殺太子，太子可毋行。」太子曰：「逆父命求生，不可。」遂行。壽見太子不止，乃盜其白旄而先馳至界。界盜見其驗，即殺之。壽已死，而太子伋又至，謂盜曰：「所當殺乃我也。」盜并殺太子伋，以報宣公。宣公乃以子朔為太子。

**本卷说明：** 十八年是争死事件的编读年；“初”引婚姻、出生、师傅关系等早年背景，不能把全部经过都算前701。

## 归年与考证

<a id="history-legacy-source-1"></a>
<a id="note-1"></a>

1. **《春秋·桓公十一年》**：“十有一年春正月，齐人、卫人、郑人盟于恶曹。”  
   **《左传·桓公十一年》**作“齐、卫、郑、宋盟于恶曹”。

   **说明：**经文未列宋，传文列宋；本页采用传文较详细名单，并保留差异。

<a id="history-legacy-source-2"></a>
<a id="note-2"></a>

2. **《左传·桓公十一年》**详记郧人军蒲骚，准备联合随、绞、州、蓼进攻楚军。

<a id="history-legacy-source-3"></a>
<a id="note-3"></a>

3. **《左传·桓公十一年》**详记鬥廉夜袭之策：“若败郧师，四邑必离。”末记楚军“遂败郧师于蒲骚，卒盟而还”。

   “四邑必离”是鬥廉对计划效果的判断，传文末尾没有逐一记载四国如何退军。正文因此保留为他的谋划，不将旧稿“四国随即瓦解”当作另有记事证明的既成结果。[传文全文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E6%A1%93%E5%85%AC.md#ref-4af8d07a1242fa)。

<a id="history-legacy-source-4"></a>
<a id="note-4"></a>

4. **《春秋·桓公十一年》**：“夏五月癸未，郑伯寤生卒。”  
   **《左传·桓公十一年》**：“夏，郑庄公卒。”

<a id="history-legacy-source-5"></a>
<a id="note-5"></a>

5. **《左传·桓公十一年》**详记祭仲立昭公，宋人诱执祭仲，威胁“不立突，将死”，祭仲遂与宋盟，携公子突归郑。

   [卷014本年宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0701)“执郑祭仲”是同一次干预，不能因列在宋栏就另记一场与郑国继承无关的拘禁。

<a id="history-legacy-source-6"></a>
<a id="note-6"></a>

6. **《春秋·桓公十一年》**：“九月，宋人执郑祭仲。突归于郑。郑忽出奔卫。”  
   **《左传·桓公十一年》**：“秋九月丁亥，昭公奔卫。己亥，厉公立。”

   [下一年表](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0700)才题突元年，保留实际入郑与翌年计元的区别。

<a id="note-7"></a>

7. **《春秋·桓公十一年》**：“柔会宋公、陈侯、蔡叔，盟于析。公会宋公于夫钟。冬十有二月，公会宋公于阚。”

#### 8｜射姑由太子而为曹庄公

[卷014本年曹栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0701)题“曹庄公射姑元年”，与[前703年来朝](bce-0703.md#event-5)、[前702年桓公死葬](bce-0702.md#event-1)衔接。[《管蔡世家》曹国段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7035.md#ref-3edda679327b5f)作“庄公夕姑”，与射姑有名号异写；本页依年表和经传统一用射姑，不另造一位夕姑。材料未定他的受命日，不从元年补出仪式。

<a id="sj014-0701-wei-note"></a>
<a id="9急子寿之死应在宣公生前不是前696年才发生"></a>
#### 9｜急子、寿之死应在宣公生前，不是前696年才发生

[卷014本年卫栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0701)作宣公十八年，记太子伋、寿争相赴死；[《卫康叔世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-9fc122699b0158)也在十八年叙谋杀、朔立太子，十九年才记宣公死。因此死亡主体放在本年，宣公之死接[前700年](../bce-0700-0601/bce-0700.md#event-4)。

[《左传·桓公十六年》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E6%A1%93%E5%85%AC.md#ref-7e58564ea3e9fc)从“初”字回叙夷姜、宣姜、急子、寿、朔的前情，以解释左右公子在[前696年](../bce-0700-0601/bce-0696.md#event-6)驱逐卫惠公，不是把杀人也定在那一年。前696年旧`event-4`、`event-5`锚点改为回链本年，避免让已经死去的宣公再下杀子命令。

世家按白旄辨认、左传按旌旗辨认的细节分属传世叙事；寿盗旗或先使急子醉、埋伏在界上或莘等不拼成未经核实的逐时路线。本文采用共同的计划、替死、双亡、朔为太子四个环节；婚姻和出生未确年，只作此前背景，不都发生于宣公十八年。

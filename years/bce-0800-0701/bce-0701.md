1. **春，齐、卫、郑、宋在恶曹结盟。** 几个中原诸侯重新调整彼此关系，宋国也加入这次盟会。 [[1]](#reading-note-1)

2. **楚军夜破蒲骚，屈瑕与贰、轸结盟。** 楚将屈瑕欲与贰、轸结盟，郧军屯蒲骚，准备联合随、绞、州、蓼进击。屈瑕想增兵、占卜，鬥廉认为郧人倚仗城池并等待援军，戒备不足，劝楚先击郧，其他四国便会离散。楚军依计夜袭蒲骚取胜，屈瑕完成盟约后撤回。 [[2]](#reading-note-2)

3. **郑庄公病故，宋迫祭仲改立郑厉公。** 五月，郑庄公去世。受庄公宠信的祭仲拥立太子忽为君，即郑昭公。七月安葬庄公。公子突的母族雍氏在宋受宠，宋庄公扣押祭仲，胁迫他改立突，又扣押突索取财物。祭仲被迫与宋订盟，带突回郑。九月丁亥，郑昭公奔卫，己亥突入郑继位，即郑厉公。 [[3]](#reading-note-4)

<a id="event-7"></a>

<a id="reading-event-8"></a>

4. **鲁国继续与宋、陈、蔡等国频繁会盟。** 鲁大夫柔同宋公、陈侯、蔡叔在析结盟，桓公又先后在夫钟、阚与宋公会面。 [[4]](#reading-note-8)

<a id="sj014-0701-cao"></a>

<a id="reading-event-9"></a>

5. **曹国开始以庄公射姑元年纪事。** 射姑在前703年还是来鲁朝见的太子，前一年父亲曹桓公去世，他承接君位，本年进入自己的纪年。 [[5]](#reading-note-9)

<a id="sj014-0701-wei"></a>

<a id="reading-event-10"></a>

<a id="reading-event-11"></a>

6. **卫宣公杀太子伋，公子寿同死，朔被立为储。** 太子伋又称急子，是夷姜之子。卫宣公把为太子选定的齐女娶来，生下寿和朔。宣姜与朔诋毁太子，宣公派太子出使，安排盗贼认旗截杀。寿劝兄长逃走未成，夺旗先行而被杀，太子随后赶到，也遇害。卫宣公改立朔为太子，辅佐伋、寿的左右公子由此怨恨朔。 [[6]](#reading-note-10)

### 6. 卫宣公杀太子伋，公子寿同死，朔被立为储

[返回正文第6条](#reading-event-10)

<a id="sj037-cite-028"></a>

**[《史记·卫康叔世家》P013](../../sources/摘录/史记-卷037-卫康叔世家.md#p013)**

> 十八年，初，宣公愛夫人夷姜，夷姜生子伋，以為太子，而令右公子傅之。右公子為太子取齊女，未入室，而宣公見所欲為太子婦者好，說而自取之，更為太子取他女。宣公得齊女，生子壽、子朔，令左公子傅之。太子伋母死，宣公正夫人與朔共讒惡太子伋。宣公自以其奪太子妻也，心惡太子，欲廢之。及聞其惡，大怒，乃使太子伋於齊而令盜遮界上殺之，與太子白旄，而告界盜見持白旄者殺之。且行，子朔之兄壽，太子異母弟也，知朔之惡太子而君欲殺之，乃謂太子曰：「界盜見太子白旄，即殺太子，太子可毋行。」太子曰：「逆父命求生，不可。」遂行。壽見太子不止，乃盜其白旄而先馳至界。界盜見其驗，即殺之。壽已死，而太子伋又至，謂盜曰：「所當殺乃我也。」盜并殺太子伋，以報宣公。宣公乃以子朔為太子。

**本卷说明：** 十八年是争死事件的编读年；“初”引婚姻、出生、师傅关系等早年背景，不能把全部经过都算前701。

#### 8｜射姑由太子而为曹庄公

[卷014本年曹栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0701)题“曹庄公射姑元年”，与[前703年来朝](bce-0703.md#event-5)、[前702年桓公死葬](bce-0702.md#event-1)衔接。[《管蔡世家》曹国段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7035.md#ref-3edda679327b5f)作“庄公夕姑”，与射姑有名号异写；本页依年表和经传统一用射姑，不另造一位夕姑。材料未定他的受命日，不从元年补出仪式。

<a id="sj014-0701-wei-note"></a>
<a id="9急子寿之死应在宣公生前不是前696年才发生"></a>
#### 9｜急子、寿之死应在宣公生前，不是前696年才发生

[卷014本年卫栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0701)作宣公十八年，记太子伋、寿争相赴死；[《卫康叔世家》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7037.md#ref-9fc122699b0158)也在十八年叙谋杀、朔立太子，十九年才记宣公死。因此死亡主体放在本年，宣公之死接[前700年](../bce-0700-0601/bce-0700.md#event-4)。

[《左传·桓公十六年》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E6%A1%93%E5%85%AC.md#ref-7e58564ea3e9fc)从“初”字回叙夷姜、宣姜、急子、寿、朔的前情，以解释左右公子在[前696年](../bce-0700-0601/bce-0696.md#event-6)驱逐卫惠公，不是把杀人也定在那一年。前696年旧`event-4`、`event-5`锚点改为回链本年，避免让已经死去的宣公再下杀子命令。

世家按白旄辨认、左传按旌旗辨认的细节分属传世叙事；寿盗旗或先使急子醉、埋伏在界上或莘等不拼成未经核实的逐时路线。本文采用共同的计划、替死、双亡、朔为太子四个环节；婚姻和出生未确年，只作此前背景，不都发生于宣公十八年。

# 公元前702年（鲁桓公十年）

[← 上一张已编年页：公元前703年](bce-0703.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前701年 →](bce-0701.md)

<a id="event-1"></a>

1. **春，曹桓公去世；五月下葬。** 曹国完成君主更替，鲁国按诸侯礼制记录其丧事。[[1]](#note-1)

<a id="event-2"></a>

2. **虢仲在周王面前诬告大夫詹父，詹父反而借王师进攻虢国，虢公逃到虞国。** 周王室内部的权力斗争直接演变成武装冲突。[[2]](#note-2)

<a id="event-3"></a>

3. **秋，秦国把芮伯万送回芮国。** 芮伯此前被周、秦联军抓走，这一年重新回到本国。[[3]](#note-3)

<a id="event-4"></a>

4. **虞叔先后被虞公索要玉璧和宝剑，最终起兵攻打虞公，虞公逃往共池。** 虞叔最初不愿献玉，后来担心“怀璧其罪”才交出；虞公得寸进尺又要宝剑，虞叔认为对方贪得无厌，索性先发制人。[[4]](#note-4)

<a id="event-5"></a>

5. **秋，鲁桓公准备与卫侯在桃丘会面，却没有真正相见。** 这次会面没有完成，现存记载也没有再交代具体原因。[[5]](#note-5)

<a id="event-6"></a>

6. **冬十二月，齐、卫、郑联军来到郎地同鲁军交战。** 《左传》把冲突追溯到此前郑太子忽救齐以后的一次犒劳：齐国让鲁国安排援军先后，鲁国依据周朝的班次把郑列在后面；忽自认为有功，因而愤怒。郑后来请求齐军，并联合卫军攻鲁。[[6]](#note-6)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·桓公十年》**：“十年春，王正月庚申，曹伯终生卒。夏五月，葬曹桓公。”

   [卷014本年曹栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0702)仍为桓公五十五年，[下一年](bce-0701.md#sj014-0701-cao)才起庄公射姑元年。死、葬、承继与起算元年分开，不把元年反推成本年未见记载的确切即位日。

<a id="note-2"></a>

2. **《左传·桓公十年》**：“虢仲谮其大夫詹父于王。詹父有辞，以王师伐虢。夏，虢公出奔虞。”

<a id="note-3"></a>

3. **《左传·桓公十年》**：“秋，秦人纳芮伯万于芮。”

<a id="note-4"></a>

4. **《左传·桓公十年》**详记虞叔献玉又被索剑，遂“伐虞公，故虞公出奔共池”。

<a id="note-5"></a>

5. **《春秋·桓公十年》**：“秋，公会卫侯于桃丘，弗遇。”

<a id="note-6"></a>

6. **《春秋·桓公十年》**：“冬十有二月丙午，齐侯、卫侯、郑伯来战于郎。”  
   **《左传·桓公十年》**：“齐人饩诸侯，使鲁次之。鲁以周班后郑。郑人怒，请师于齐。齐人以卫师助之。”

   犒劳发生在[前706年救齐之后](bce-0706.md#event-5)，本年仅接它造成的后果。六年条只写“使鲁为其班，后郑”，十年回叙则明确补出“以周班”；因此按周朝班次排序有原文依据，不能仅凭六年略写就删掉这个理由。两段仍未列完整座次，不补出所有参会者的具体排列，也不把同次犒劳在本年再办一次。[两年传文全文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E6%A1%93%E5%85%AC.md#ref-9fad6df2af7a0c)。

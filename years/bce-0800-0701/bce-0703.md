# 公元前703年（鲁桓公九年）

[← 上一张已编年页：公元前704年](bce-0704.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前702年 →](bce-0702.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，纪季姜正式嫁入周王室，成为王后。** 在诸侯女儿出嫁的记录中，王后入京师因为关系到天子婚姻而被特别记载。 [[1]](#note-1)

<a id="event-2"></a>

<a id="event-3"></a>

2. **楚、巴使者被杀，两国联合攻鄾败邓。** 巴国托楚国向邓求和，鄾人夺取聘礼并杀楚使道朔与巴国行人，邓国拒绝追究。夏，楚、巴围鄾，邓军来援。鬥廉把楚军列入巴军阵中，交战后佯退，引邓军追击。巴军在后，双方夹击，邓军败，鄾人夜间溃散。 [[2]](#note-2)

<a id="event-4"></a>

3. **秋，虢仲、芮伯、梁伯、荀侯、贾伯联合攻打曲沃。** 多国势力继续试图压制曲沃扩张。 [[3]](#note-4)

<a id="event-5"></a>

4. **冬，曹国太子射姑来鲁朝见，鲁国以上卿之礼接待。** 宴饮时太子听到乐声叹息，鲁国施父认为这不是正常的宴享表现，担心他将有忧患。 [[4]](#note-5)

<a id="sj014-0703-qin"></a>

<a id="event-6"></a>

5. **秦国开始用出子元年纪事。** 宁公死后，大臣废置原太子，改立年幼的出子；本年进入新君的纪年，而原太子仍将成为日后争位的关键人物。 [[5]](#note-6)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·桓公九年》**：“九年春，纪季姜归于京师。”  
   **《左传·桓公九年》**：“凡诸侯之女行，唯王后书。”

<a id="history-legacy-source-2"></a>


2. **《左传·桓公九年》**详记巴子请楚与邓修好，邓南鄙鄾人夺币，杀楚使道朔及巴行人。

<a id="history-legacy-source-3"></a>


3. **《左传·桓公九年》**：“夏，楚使鬥廉帅师及巴师围鄾……而夹攻之，邓师大败，鄾人宵溃。”

   **战阵关系：**原文“邓人逐之，背巴师而夹攻之”说邓军追楚时背向巴军，结果被楚、巴夹击。旧稿“把巴军暴露在身后”容易误读成巴军暴露于敌，本次按实际主语与前后位置重写。鄾、鬱等见证异写保留来源，不据同音另造战场。[传文全文](../../拆分史书/左传/异本/春秋左氏傳-桓公.md)。

<a id="history-legacy-source-4"></a>


4. **《左传·桓公九年》**：“秋，虢仲、芮伯、梁伯、荀侯、贾伯伐曲沃。”

5. **《春秋·桓公九年》**：“冬，曹伯使其世子射姑来朝。”  
   **《左传·桓公九年》**：“宾之以上卿，礼也……乐奏而叹。”

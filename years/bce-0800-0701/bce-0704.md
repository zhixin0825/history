<a id="event-1"></a>

<a id="event-7"></a>

1. **翼地再遭曲沃打击，周王另立晋侯缗。** 上年曲沃武公已诱杀小子侯。春，翼地再受攻击。周王命虢仲改立晋哀侯的弟弟缗为君，曲沃武公退保曲沃，两支仍然并立。 [[1]](#note-1)

<a id="event-2"></a>

2. **正月，鲁国举行烝祭，周天子派家父来聘问；五月又举行一次烝祭。** 一年中两次烝祭都被记录下来。 [[2]](#note-2)

<a id="event-3"></a>

<a id="event-4"></a>

3. **楚败随于速杞，熊通称王。** 夏，楚在沈鹿召集诸侯，黄国、随国未到。熊通攻随，季梁劝等待楚军骄疲并避其主力，少师坚持速战，随侯从之。双方战于速杞，随军败，随侯逃脱，少师被俘。秋，楚、随议和。熊通以先祖为周效力及南方诸侯服从为理由自行称王，与随结盟退兵后又开拓濮地。 [[3]](#note-3)

<a id="event-5"></a>

4. **秋，鲁国出兵攻邾。** 现存本年记载没有留下更详细的战斗过程。 [[4]](#note-5)

<a id="event-6"></a>

<a id="hs-event-10"></a>

5. **鲁国冬十月降雪。** [[5]](#note-6)

<a id="event-8"></a>

6. **冬，祭公来鲁，随后前往纪国迎接王后。** 周王室从纪国迎娶王后，祭公承担迎亲任务。 [[6]](#note-8)

<a id="event-9"></a>

7. **宁公再伐荡氏，随后去世，秦国大臣另立幼主。** 宁公攻取荡氏后，在位十二年而卒。原有太子武公被大庶长弗忌、威垒、三父等废置，五岁的出子被立为君。武公与德公同母，都是后面争位链条中的人物。 [[7]](#note-9)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《左传·桓公八年》**：“八年春，灭翼。”

   本年冬又有王命立缗，不能把“灭翼”直接写成曲沃此时已经永久兼并整个晋国。曲沃最终代晋的记载另见[前679年](../bce-0700-0601/bce-0679.md)及[前678年王命](../bce-0700-0601/bce-0678.md)，不是本年这次攻破和重立的第二种简称。

<a id="history-legacy-source-2"></a>


2. **《春秋·桓公八年》**：“春正月己卯，烝。天王使家父来聘。夏五月丁丑，烝。”

<a id="history-legacy-source-3"></a>


3. **《左传·桓公八年》**：“夏，楚子合诸侯于沈鹿。黄、随不会……楚子伐随。”

<a id="history-legacy-source-4"></a>


4. **《左传·桓公八年》**详记季梁、少师争论战法，“战于速杞，随师败绩……秋，随及楚平”。

   [卷014本年楚栏](../../拆分史书/史记/卷014.md#y0704)简写“伐随，弗拔，但盟，罢兵”。“弗拔”不能直接改译成楚军在野战中败北；经传有速杞之胜，年表侧重未攻取随而退盟的结果。正文保留详细战事与最终讲和，不因两种表述就增加第二场同年攻随。

<a id="history-legacy-source-5"></a>


5. **《春秋·桓公八年》**：“秋，伐邾。”

<a id="history-legacy-source-6"></a>


6. **《春秋·桓公八年》**：“冬十月，雨雪。”

<a id="history-legacy-source-7"></a>


7. **《左传·桓公八年》**：“冬，王命虢仲立晋哀侯之弟缗于晋。”

   [卷014前706年晋栏](../../拆分史书/史记/卷014.md#y0706)已起缗元年，本年写三年；这与经传本年冬立缗不合。这里采用经传连续的前705年诱杀小子侯、本年重立主线，明示年表王年不同，不在前706、本年各立一次同样的国君。

<a id="history-legacy-source-8"></a>


8. **《春秋·桓公八年》**：“祭公来，遂逆王后于纪。”  
   **《左传·桓公八年》**：“祭公来，遂逆王后于纪，礼也。”

#### sj005-030｜宁公再伐荡氏，随后去世，秦国大臣另立幼主。

[卷005 P009](../../拆分史书/史记/卷005.md#p009)。

**说明：**宁公十岁立是文本年龄，不按含岁算法补造生日。此处“荡氏”与此前“荡社”原词分别保留，不为消除重复自行删字。出子正式按元年纪事见[前703年](bce-0703.md#sj014-0703-qin)，本年改立与次年计元不混成两次继位。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../拆分史书/史记/卷005.md#kao-c691f26620)。古月与干支未作历算时，不当作同号公历月日。

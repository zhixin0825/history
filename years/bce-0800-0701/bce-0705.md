# 公元前705年（鲁桓公七年）

[← 上一张已编年页：公元前706年](bce-0706.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前704年 →](bce-0704.md)

<a id="event-1"></a>

1. **春二月，鲁国在咸丘焚烧草木围猎。** 这一条只保存行动本身，没有留下更长的经过。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，穀伯绥和邓侯吾离先后来鲁朝见。** 两位国君都以名字被记录，反映他们在当时礼制秩序中的地位不高。[[2]](#note-2)

<a id="event-3"></a>

3. **盟、向两地先向郑国求和，随后又背弃约定。** 郑国很快联合齐、卫出兵讨伐。[[3]](#note-3)

<a id="event-4"></a>

4. **秋，郑、齐、卫攻打盟、向，周王随后把两地居民迁到郏。** 盟、向原有政治格局被打散，人口被王室重新安置。[[4]](#note-4)

<a id="event-5"></a>

5. **冬，曲沃伯诱骗晋小子侯并将其杀死。** 晋国内部的曲沃—翼争位再次升级，翼地政权又失去一位君主。[[5]](#note-5)

<a id="sj014-0705-chen"></a>

6. **据《十二诸侯年表》，陈国公子完出生于这一年，后来被称为敬仲。** 他是陈厉公之子，后来将离开陈国、在齐国立足；本年只接住原表明确记出的出生，不把他和后人的经历都放到这一年。[[6]](#sj014-0705-note)

<a id="sj014-0705-note"></a>
### 6｜陈完的出生、父系与占筮不是一类证据

[卷014本年陈栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0705)作“二，生敬仲完。周史卜完后世王齐”，[《陈杞世家》](https://zh.wikisource.org/wiki/史記三家註/卷036)也记厉公二年生完。这里依原表归前705年，未补生日；相邻陈君的姓名、继承存在讹混，故出生年作为这套传世纪年的记载保留，不能称已获独立定年证实。

[《左传·庄公二十二年》](https://zh.wikisource.org/wiki/春秋左氏傳/莊公)叙陈厉公生敬仲，并说他“少也”时，周史用《周易》占得观之否，解释后人将兴于异国。它没有把占筮定为出生当天。年表把出生与后世结局的预测压在同格，不足以定出另一件前705年确日事件，也不证明预测确曾应验。父系以经传及《索隐》所辨厉公跃为主，见[前706年同人辨析](bce-0706.md#cq-source-4)，不把已经被杀的陈佗写作在世的厉公。

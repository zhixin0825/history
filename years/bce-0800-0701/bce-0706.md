# 公元前706年（鲁桓公六年）

[← 上一张已编年页：公元前707年](bce-0707.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前705年 →](bce-0705.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，淳于国君从曹国来到鲁国，但仍没有返回自己的国家。** 他此前已经判断本国危险，这次出行进一步表明淳于政权处境不稳。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚武王进逼随国，既欲借随向周求加名号，也试探随军。** 楚以诸侯互侵相杀为由要求随替楚向周室请提高名号，周王不允。军前楚又故意示弱，让少师看到疲弱的部队，想诱随出击；季梁识破，劝随侯先修政安民，不要轻进。随侯听从，楚暂退兵。 [[2]](#note-2)

<a id="event-3"></a>

<a id="event-9"></a>

3. **纪国两次向鲁询问如何应对齐国。** 夏，鲁桓公与纪侯在成会面，纪侯请教怎样应付齐国的压力。冬，纪侯再来鲁，希望借周王的命令与齐讲和，桓公表示无能为力。 [[3]](#note-3)

<a id="event-4"></a>

<a id="event-5"></a>

<a id="event-6"></a>

4. **郑太子忽救齐，后因犒赏生怨并拒婚。** 北戎攻齐，郑太子忽率兵救援，击败戎军，俘两名将领，献三百甲首。齐方让鲁国排定犒赏次序，鲁依周制把郑排在后面，太子忽愤懑，后来成为郎地争战的一个起因。齐侯早年曾想把文姜嫁给忽，忽以齐大非偶辞谢。救齐后齐侯再提婚事，忽怕被视作凭军功索婚，仍未应允。随军的祭仲担心庄公其他诸子争位，曾劝忽借结亲获得齐国支持。 [[4]](#note-4)

<a id="event-7"></a>

5. **秋，鲁国举行大阅，检点车辆和战马。** 这是一次大规模军事检阅。 [[5]](#note-7)

<a id="event-8"></a>

6. **九月丁卯，桓公与文姜的儿子出生，因为与父亲同日出生，取名“同”。** 鲁国按太子礼仪庆祝其出生，桓公还专门询问命名规则。 [[6]](#note-8)

<a id="event-10"></a>

7. **蔡人杀死陈佗，陈国另立跃为君，即陈厉公。** 陈佗在前一年陈桓公病乱时杀太子免、自立，如今又被杀；在后来的叙事中，陈佗和陈厉公的姓名、经历发生混淆，不能据此把同一个人写成两次死亡。 [[7]](#note-10)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·桓公六年》**：“六年春正月，寔来。”  
   **《左传·桓公六年》**：“自曹来朝。书曰‘寔来’，不复其国也。”

<a id="history-legacy-source-2"></a>


2. **《左传·桓公六年》**详记楚武王侵随、故意“毁军”示弱，少师主张追击，季梁阻止并劝随侯修政，最后“随侯惧而修政，楚不敢伐”。

   [卷014本年楚栏](../../拆分史书/史记/卷014.md#y0706)的“侵随，随为善政，得止”即此事的概述，不另计第二次楚退兵，也不把“善政”当作已有量化成效的调查。

<a id="history-legacy-source-3"></a>


3. **《春秋·桓公六年》**：“夏四月，公会纪侯于成。”  
   **《左传·桓公六年》**：“纪来谘谋齐难也。”

<a id="history-legacy-source-4"></a>


4. **《左传·桓公六年》**：“北戎伐齐……郑太子忽帅师救齐。六月，大败戎师，获其二帅大良、少良，甲首三百。”

   [卷014齐、郑两栏](../../拆分史书/史记/卷014.md#y0706)分别记山戎来伐与太子忽救齐，属于同一轮战争。北戎、山戎用语照所据文本留存，不仅凭异名就另造一支同年同样入侵的军队。

<a id="history-legacy-source-5"></a>


5. **《左传·桓公六年》**：“齐人馈之饩，使鲁为其班，后郑。郑忽以其有功也，怒，故有郎之师。”

   **跨年互见：**六年条没有细说排班依据，十年回叙则明确“鲁以周班后郑”，故正文保留按周朝班次的理由，而不补一份原文未列的完整座次表。不能因较早段落略写，就断言这种解释全无出处。[前702年郎之战注6](bce-0702.md#note-6)合引两年传文；犒劳只在本年主述，战争是后来后果。

<a id="history-legacy-source-6"></a>


6. **《左传·桓公六年》**回叙首次提亲时明确女子为文姜，本年救齐之后只说齐侯“又请妻之”，未再记女名。不能把两次都写成娶文姜，详见[核对12](#cq-source-12)。

<a id="history-legacy-source-7"></a>


7. **《春秋·桓公六年》**：“秋八月壬午，大阅。”  
   **《左传·桓公六年》**：“秋，大阅，简车马也。”

<a id="history-legacy-source-8"></a>


8. **《春秋·桓公六年》**：“九月丁卯，子同生。”  
   **《左传·桓公六年》**详记太子出生礼及桓公问名，最终“命之曰同”。

<a id="history-legacy-source-9"></a>


9. **《春秋·桓公六年》**：“冬，纪侯来朝。”  
   **《左传·桓公六年》**：“请王命以求成于齐，公告不能。”

#### 核对4｜蔡人杀死陈佗，不能把他与后来的陈厉公合并

<details>
<summary>经 J004｜原文</summary>

> 蔡人杀陈佗。

[本段出处](../../拆分史书/左传/bce-0706.md#j004)

</details>

[卷014本年陈栏](../../拆分史书/史记/卷014.md#y0706)却题“陈厉公他元年”，前700年又记这个“公”被蔡人杀。《陈杞世家》把佗、五父、厉公、利公的关系连成另一套故事。[三家注本卷036《索隐》](../../拆分史书/史记/卷036.md#part-2-text)已指出：佗即五父，被蔡人杀；《左传》所说厉公为跃，厉、利音近，不能将佗当作厉公、五父另作一人。

正文因此合用经文与[《左传·庄公二十二年》](../../拆分史书/左传/异本/春秋左氏傳-莊公.md)“蔡人杀五父而立之”的回叙，区分陈佗和其后陈厉公跃。陈桓公及太子免的前事见[前707年](bce-0707.md#event-1)，陈侯跃的死亡见[前700年](../bce-0700-0601/bce-0700.md#event-4)。这里是采用有注家指出的文本取舍，不宣称有现代考古材料把这套谱系逐项证实。

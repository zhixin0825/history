# 公元前706年（鲁桓公六年）

[← 上一张已编年页：公元前707年](bce-0707.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前705年 →](bce-0705.md)

<a id="event-1"></a>

1. **春，淳于国君从曹国来到鲁国，但仍没有返回自己的国家。** 他此前已经判断本国危险，这次出行进一步表明淳于政权处境不稳。[[1]](#note-1)

<a id="event-2"></a>

2. **楚武王进逼随国，故意示弱诱使随军追击；随国大夫季梁识破，没有贸然出兵。** 楚国让少师看到一支显得疲弱的军队，想利用他的轻率诱敌。季梁劝随侯先修政、安民，不要被假象激怒。随侯最终听从，楚国也暂时没有继续进攻。[[2]](#note-2)

<a id="event-3"></a>

3. **夏，鲁桓公与纪侯在成地会面，纪国向鲁国咨询怎样应对齐国威胁。** 齐国对纪国的压力已经从外交试探发展成长期安全问题。[[3]](#note-3)

<a id="event-4"></a>

4. **北戎进攻齐国，郑太子忽率军救齐，大败戎军。** 郑军俘获戎方两名将领，并取三百甲首献给齐国。[[4]](#note-4)

<a id="event-5"></a>

5. **齐国犒劳援军时，让鲁国安排先后，郑国被排在后面。** 太子忽认为郑军立了大功，却没有受到相称的礼遇，因而愤怒。这次不满后来成为郎地之战的前因之一。[[5]](#note-5)

<a id="event-6"></a>

6. **齐国再次向郑太子忽提婚事，他仍未接受。** 早在鲁桓公与齐国婚姻以前，齐侯就曾想把文姜嫁给忽；忽以齐大非偶推辞。本年救齐以后，齐侯又向他提婚，忽不愿被看成借救援索取婚姻，于是再次拒绝。 [看原文与说明](#cq-source-12)

<a id="event-7"></a>

7. **秋，鲁国举行大阅，检点车辆和战马。** 这是一次大规模军事检阅。[[7]](#note-7)

<a id="event-8"></a>

8. **九月丁卯，桓公与文姜的儿子出生，因为与父亲同日出生，取名“同”。** 鲁国按太子礼仪庆祝其出生，桓公还专门询问命名规则。[[8]](#note-8)

<a id="event-9"></a>

9. **冬，纪侯来鲁朝见，希望借周王命令与齐国讲和，鲁桓公表示无能为力。** 纪国面对齐国压力，外交空间越来越小。[[9]](#note-9)

<a id="event-10"></a>

10. **蔡人杀死陈佗，陈国另立跃为君，即陈厉公。** 陈佗在前一年陈桓公病乱时杀太子免、自立，如今又被杀；在后来的叙事中，陈佗和陈厉公的姓名、经历发生混淆，不能据此把同一个人写成两次死亡。 [看原文与说明](#cq-source-4)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·桓公六年》**：“六年春正月，寔来。”  
   **《左传·桓公六年》**：“自曹来朝。书曰‘寔来’，不复其国也。”

<a id="note-2"></a>

2. **《左传·桓公六年》**详记楚武王侵随、故意“毁军”示弱，少师主张追击，季梁阻止并劝随侯修政，最后“随侯惧而修政，楚不敢伐”。

   [卷014本年楚栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0706)的“侵随，随为善政，得止”即此事的概述，不另计第二次楚退兵，也不把“善政”当作已有量化成效的调查。

<a id="note-3"></a>

3. **《春秋·桓公六年》**：“夏四月，公会纪侯于成。”  
   **《左传·桓公六年》**：“纪来谘谋齐难也。”

<a id="note-4"></a>

4. **《左传·桓公六年》**：“北戎伐齐……郑太子忽帅师救齐。六月，大败戎师，获其二帅大良、少良，甲首三百。”

   [卷014齐、郑两栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0706)分别记山戎来伐与太子忽救齐，属于同一轮战争。北戎、山戎用语照所据文本留存，不仅凭异名就另造一支同年同样入侵的军队。

<a id="note-5"></a>

5. **《左传·桓公六年》**：“齐人馈之饩，使鲁为其班，后郑。郑忽以其有功也，怒，故有郎之师。”

   **释义修正：**原文明确的是齐让鲁安排班次、鲁把郑列后，以及忽自认为有功而怒；未在这里说明完整座次，更没有明说一定依哪一条周礼把郑排在鲁之后。正文撤去旧稿补出的具体理由，后续[前702年郎之战](bce-0702.md#event-6)同样按这一证据范围交代。

<a id="note-6"></a>

6. **《左传·桓公六年》**回叙首次提亲时明确女子为文姜，本年救齐之后只说齐侯“又请妻之”，未再记女名。不能把两次都写成娶文姜，详见[核对12](#cq-source-12)。

<a id="note-7"></a>

7. **《春秋·桓公六年》**：“秋八月壬午，大阅。”  
   **《左传·桓公六年》**：“秋，大阅，简车马也。”

<a id="note-8"></a>

8. **《春秋·桓公六年》**：“九月丁卯，子同生。”  
   **《左传·桓公六年》**详记太子出生礼及桓公问名，最终“命之曰同”。

<a id="note-9"></a>

9. **《春秋·桓公六年》**：“冬，纪侯来朝。”  
   **《左传·桓公六年》**：“请王命以求成于齐，公告不能。”

## 补充核对的史料

<a id="cq-source-4"></a>
### 核对4｜蔡人杀死陈佗，不能把他与后来的陈厉公合并

<details>
<summary>经 J004｜原文</summary>

> 蔡人杀陈佗。

[本段出处](../../sources/春秋左传/有标点原文/bce-0706.md#j004)

</details>

[卷014本年陈栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0706)却题“陈厉公他元年”，前700年又记这个“公”被蔡人杀。《陈杞世家》把佗、五父、厉公、利公的关系连成另一套故事。[三家注本卷036《索隐》](https://zh.wikisource.org/wiki/史記三家註/卷036)已指出：佗即五父，被蔡人杀；《左传》所说厉公为跃，厉、利音近，不能将佗当作厉公、五父另作一人。

正文因此合用经文与[《左传·庄公二十二年》](https://zh.wikisource.org/wiki/春秋左氏傳/莊公)“蔡人杀五父而立之”的回叙，区分陈佗和其后陈厉公跃。陈桓公及太子免的前事见[前707年](bce-0707.md#event-1)，陈侯跃的死亡见[前700年](../bce-0700-0601/bce-0700.md#event-4)。这里是采用有注家指出的文本取舍，不宣称有现代考古材料把这套谱系逐项证实。

<a id="cq-source-12"></a>
### 核对12｜齐国再次向郑太子忽提婚事，他仍未接受

**说明：**前一次明确写文姜，后一次只写“又请妻之”，没有再标女名。文姜此前已经嫁鲁，不能把两次都写成要将文姜嫁忽。

<details>
<summary>传 T006｜原文</summary>

> 公之未昏于齐也，齐侯欲以文姜妻郑太子忽。大子忽辞，人问其故，大子曰：“人各有耦，齐大，非吾耦也。《诗》云：‘自求多福。’在我而已，大国何为？”君子曰：“善自为谋。”及其败戎师也，齐侯又请妻之，固辞。人问其故，大子曰：“无事于齐，吾犹不敢。今以君命奔齐之急，而受室以归，是以师昏也。民其谓我何？”遂辞诸郑伯。

[本段出处](../../sources/春秋左传/有标点原文/bce-0706.md#t006)

</details>

<a id="sj014-0706-jin-note"></a>
### 晋国异年｜年表的杀小子、立缗分赴既有年页

[卷014本年晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0706)把曲沃杀小子侯、周伐曲沃、立缗并列，并起缗元年。《左传》却在[前705年冬](bce-0705.md#event-5)记诱杀，在[前704年冬](bce-0704.md#event-7)记王命立缗。本项目保留经传的分阶段主线，本年仅作异年互见，不再增加同一位国君的第二次死亡和同一位继任者的第二次即位。

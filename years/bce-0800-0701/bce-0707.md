# 公元前707年（鲁桓公五年）

[← 上一张已编年页：公元前708年](bce-0708.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前706年 →](bce-0706.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **正月，陈桓公去世，陈国内乱随即爆发。** 陈桓公病重期间，公子佗杀死太子免，自立为君。国内因此分裂混乱，甚至出现两次报丧。 [[1]](#reading-note-1)

<a id="reading-event-2"></a>

2. **陈桓公去世后的葬礼也在本年举行。** 经文另记“葬陈桓公”，不能只写春正月陈国内乱而省去葬事。 [[2]](#reading-note-2)

<a id="event-2"></a>

<a id="reading-event-3"></a>

3. **夏，齐侯与郑庄公前往纪国，原本想乘机袭击纪国，纪人事先察觉。** 齐、纪矛盾由此进一步加深。 [[3]](#reading-note-3)

<a id="event-3"></a>

<a id="reading-event-4"></a>

4. **周桓王撤掉郑庄公在王室中的政权职务，郑庄公从此不再入朝。** 周、郑长期累积的矛盾终于发展成公开决裂。 [[4]](#reading-note-4)

<a id="event-4"></a>

<a id="reading-event-5"></a>

5. **秋，周桓王亲率蔡、卫、陈等诸侯军伐郑，在繻葛遭到惨败。** 郑军先攻击内部混乱、战意不足的陈军，再冲击蔡、卫，周王中军随之动摇。双方在繻葛交战，王师大败，郑将祝聃一箭射中周桓王肩部。 [[5]](#reading-note-5)

    [卷四互见与归年](#sj004-707-1)

<a id="event-5"></a>

<a id="reading-event-6"></a>

6. **郑庄公没有乘胜继续追击周王，夜里反而派祭足慰问。** 郑国虽然在战场上击败王师，却避免把胜利扩大成直接凌辱天子的行动。 [[6]](#reading-note-6)

<a id="event-6"></a>

<a id="reading-event-7"></a>

7. **夏，周王派仍叔之子来鲁聘问；秋，鲁国举行大雩，又发生螽灾。** 大雩举行时间被认为偏晚；这一年鲁国还受到虫灾影响。 [[7]](#reading-note-7)

<a id="event-7"></a>

<a id="reading-event-8"></a>

8. **冬，淳于国君前往曹国后没有再回国。** 他判断本国局势危险，于是留在曹国。 [[8]](#reading-note-8)

<a id="event-8"></a>

<a id="reading-event-9"></a>

9. **鲁国修筑祝丘。** 经文把筑城列在本年后段，没有另记施工人数和工程规模，正文不补数字。 [[9]](#reading-note-9)

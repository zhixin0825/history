1. **陈桓公病死，公子佗杀太子自立。** 陈桓公病重时，公子佗杀死太子免并自立，国内混乱，两次对外报丧。正月，陈桓公去世，本年安葬。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-3"></a>

2. **夏，齐侯与郑庄公前往纪国，原本想乘机袭击纪国，纪人事先察觉。** 齐、纪矛盾由此进一步加深。 [[2]](#reading-note-3)

<a id="event-3"></a>

<a id="reading-event-4"></a>

<a id="event-4"></a>

<a id="reading-event-5"></a>

<a id="event-5"></a>

<a id="reading-event-6"></a>

3. **周王伐郑败于繻葛，郑庄公遣使慰问。** 周桓王撤去郑庄公在王室的职权，庄公不再入朝。秋，周桓王亲率王师、蔡、卫、陈军攻郑。郑军先打退因内乱而不稳的陈军，再破蔡、卫，最后击败中军。祝聃射中周桓王肩部，请求追击，庄公制止，夜遣祭足探问王伤。 [[3]](#reading-note-4)

    [卷四互见与归年](#sj004-707-1)

<a id="event-6"></a>

<a id="reading-event-7"></a>

<a id="hs-event-10"></a>

4. **周王使者来鲁，鲁行大雩并遭螽灾。** 夏，周王派仍叔之子来鲁聘问。秋，鲁国举行大雩，时间被认为偏晚。同年鲁国还发生螽灾。 [[4]](#reading-note-7)

<a id="event-7"></a>

<a id="reading-event-8"></a>

5. **冬，淳于国君前往曹国后没有再回国。** 他判断本国局势危险，于是留在曹国。 [[5]](#reading-note-8)

<a id="event-8"></a>

<a id="reading-event-9"></a>

6. **鲁国修筑祝丘。** 经文把筑城列在本年后段，没有另记施工人数和工程规模，正文不补数字。 [[6]](#reading-note-9)

**[左传](../../拆分史书/左传/bce-0707.md#t001)**

[史料说明](#history-legacy-source-1)

<a id="sj036-cite-022"></a>

**[《史记·陈杞世家》P008](../../拆分史书/史记/卷036.md#p008)**

> 三十八年正月甲戌己丑，桓公鮑卒。桓公弟佗，其母蔡女，故蔡人為佗殺五父及桓公太子免而立佗，是為厲公。桓公病而亂作，國人分散，故再赴。

**本卷说明：** 本篇把佗与五父分作两人，并称佗为厉公；[《索隐》p7](../../拆分史书/史记/卷036.md#part-2-p7)明指五父即佗、厉公为跃。正文保留本页经传叙事；甲戌、己丑是两次赴告的日期，不是桓公死了两次。

<a id="sj046-cite-004"></a>

**[《史记·田敬仲完世家》P002](../../拆分史书/史记/卷046.md#p002)**

> 及桓公病，蔡人為他殺桓公鮑及太子免而立他，為厲公。

**本卷说明：** 本篇蔡人杀桓公及免与经传陈桓公卒、佗杀太子免的叙法不同，合在同一内乱主条，不据此另造两次桓公之死。

# 公元前708年（鲁桓公四年）

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春正月，鲁桓公在郎地狩猎。** 这次狩猎发生在合适的季节，被视为正常的国君田猎活动。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，周王派宰渠伯纠到鲁国聘问。** 这是周王室与鲁国之间的一次正式外交往来。 [[2]](#note-2)

<a id="event-3"></a>

<a id="event-4"></a>

3. **秦伐芮失利，冬与周师围魏擒芮伯。** 上年芮伯被母亲逐至魏地。秋，秦军攻芮失利。冬，秦军与周王师联手围魏，拘获芮伯。 [[3]](#note-3)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·桓公四年》**：“四年春正月，公狩于郎。”  
   **《左传·桓公四年》**：“书时，礼也。”

<a id="history-legacy-source-2"></a>


2. **《春秋·桓公四年》**：“夏，天王使宰渠伯纠来聘。”  
   **《左传·桓公四年》**：“周宰渠伯纠来聘。”

<a id="history-legacy-source-3"></a>


3. **《左传·桓公四年》**：“秋，秦师侵芮，败焉。”

   芮伯被逐、居魏见[前709年](bce-0709.md#event-7)。已读材料从那里接到本年，不足以支持旧稿所说内乱“已经持续数年”，故改按实际可见的前后年次交代。

<a id="history-legacy-source-4"></a>


4. **《左传·桓公四年》**：“冬，王师、秦师围魏，执芮伯以归。”

   [卷014本年](../../拆分史书/史记/卷014.md#y0708)各国只递记在位年数，没有另写这两次出兵；原有经传事件仍保留，不因年表未记就删除。芮伯被捕并非此事终结，秦送他返芮见[前702年](bce-0702.md#event-3)。

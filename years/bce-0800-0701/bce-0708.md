# 公元前708年（鲁桓公四年）

[← 上一张已编年页：公元前709年](bce-0709.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前707年 →](bce-0707.md)

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春正月，鲁桓公在郎地狩猎。** 这次狩猎发生在合适的季节，被视为正常的国君田猎活动。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，周王派宰渠伯纠到鲁国聘问。** 这是周王室与鲁国之间的一次正式外交往来。 [[2]](#note-2)

<a id="event-3"></a>

3. **秋，秦军进攻芮国，却遭到失败。** 前一年芮伯被母亲逐出，芮国的内乱到本年引来秦军直接介入。 [[3]](#note-3)

<a id="event-4"></a>

4. **冬，周王师与秦军联合包围魏地，抓获芮伯并带走。** 芮国的内部纷争进一步演变为周、秦共同出兵。 [[4]](#note-4)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·桓公四年》**：“四年春正月，公狩于郎。”  
   **《左传·桓公四年》**：“书时，礼也。”

<a id="history-legacy-source-2"></a>


2. **《春秋·桓公四年》**：“夏，天王使宰渠伯纠来聘。”  
   **《左传·桓公四年》**：“周宰渠伯纠来聘。”

<a id="history-legacy-source-3"></a>


3. **《左传·桓公四年》**：“秋，秦师侵芮，败焉。”

   芮伯被逐、居魏见[前709年](bce-0709.md#event-7)。已读材料从那里接到本年，不足以支持旧稿所说内乱“已经持续数年”，故改按实际可见的前后年次交代。

<a id="history-legacy-source-4"></a>


4. **《左传·桓公四年》**：“冬，王师、秦师围魏，执芮伯以归。”

   [卷014本年](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0708)各国只递记在位年数，没有另写这两次出兵；原有经传事件仍保留，不因年表未记就删除。芮伯被捕并非此事终结，秦送他返芮见[前702年](bce-0702.md#event-3)。

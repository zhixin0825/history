# 公元前709年（鲁桓公三年）

[← 上一张已编年页：公元前710年](bce-0710.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前708年 →](bce-0708.md)

<a id="event-1"></a>

1. **春，曲沃武公进攻翼地，在汾隰一带追败并俘获翼侯。** 曲沃军由韩万御车、梁弘居右，翼侯逃亡时车辆受阻，夜里被俘，栾共叔也一同被抓。[[1]](#note-1)

<a id="event-2"></a>

2. **正月，鲁桓公与齐侯在嬴地会面，为与齐国成婚作准备。** 鲁齐关系由政治盟会进一步转成婚姻关系。[[2]](#note-2)

<a id="event-3"></a>

3. **夏，齐侯与卫侯在蒲地互相约定友好，但没有举行正式盟誓。** 同期鲁桓公又与杞侯在郕地会面，杞国主动寻求与鲁讲和。[[3]](#note-3)

<a id="event-4"></a>

4. **七月朔日，发生日全食。** 日食被完整记录为“既”，即日面被完全遮蔽。[[4]](#note-4)

<a id="event-5"></a>

5. **秋，鲁国公子翚到齐国迎娶文姜；九月，齐侯亲自把文姜送到讙地，桓公在那里迎接。** 文姜随后正式抵达鲁国，成为桓公夫人。[[5]](#note-5)

<a id="event-6"></a>

6. **冬，齐侯派弟弟年到鲁国聘问，完成婚姻后的礼仪往来。** 这一年鲁齐关系明显升温。[[6]](#note-6)

<a id="event-7"></a>

7. **芮伯因宠妾过多，被母亲芮姜逐出，暂居魏地。** 芮国内部矛盾随后引来秦和周王室介入。[[7]](#note-7)

<a id="sj014-0709-event"></a>

8. **晋哀侯被俘后，翼地拥立他的儿子为小子侯；曲沃武公随后命韩万杀害被俘的晋哀侯。** 这一年翼地政权并未因国君被俘便立即消失，另立幼主维持晋侯一系；曲沃势力增强，却还没有得到周王的晋侯名号。 [[8]](#sj014-0709-note)

## 本年相关史料

<a id="note-1"></a>

1. **《左传·桓公三年》**：“曲沃武公伐翼，次于陉庭……夜获之，及栾共叔。”

<a id="note-2"></a>

2. **《春秋·桓公三年》**：“春正月，公会齐侯于嬴。”  
   **《左传·桓公三年》**：“会于嬴，成昏于齐也。”

<a id="note-3"></a>

3. **《春秋·桓公三年》**：“夏，齐侯、卫侯胥命于蒲。六月，公会杞侯于郕。”  
   **《左传·桓公三年》**：“不盟也……杞求成也。”

<a id="note-4"></a>

4. **《春秋·桓公三年》**：“秋七月壬辰朔，日有食之，既。”

<a id="note-5"></a>

5. **《春秋·桓公三年》**：“公子翚如齐逆女。九月，齐侯送姜氏于讙。公会齐侯于讙。夫人姜氏至自齐。”  
   **《左传·桓公三年》**详述迎婚礼制，并批评齐侯亲自送女不合通常礼制。

<a id="note-6"></a>

6. **《春秋·桓公三年》**：“冬，齐侯使其弟年来聘。”  
   **《左传·桓公三年》**：“齐仲年来聘，致夫人也。”

<a id="note-7"></a>

7. **《左传·桓公三年》**：“芮伯万之母芮姜恶芮伯之多宠人也，故逐之，出居于魏。”

## 补充史料与异说

<a id="sj014-0709-note"></a>
### 卷014互见｜翼国拥立小子侯，曲沃武公命人杀死被俘的晋哀侯

[《晋世家·哀侯、小子侯》](https://zh.wikisource.org/wiki/史記/卷039)叙述哀侯九年被俘、国人立小子侯，小子元年韩万杀哀侯；[《十二诸侯年表》前709年晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0709)仅题「晋小子元年」。[《左传·桓公三年》](../../sources/春秋左传/data/zz-02-03.json)详记夜获翼侯，但未逐句记韩万杀人。晋哀侯战败被俘和后续被杀应区别，不凭世家追叙擅补具体月日。

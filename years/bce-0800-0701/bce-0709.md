# 公元前709年（鲁桓公三年）

[← 上一张已编年页：公元前710年](bce-0710.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前708年 →](bce-0708.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，曲沃武公进攻翼地，在汾隰一带追败并俘获翼侯。** 曲沃军由韩万御车、梁弘居右，翼侯逃亡时车辆受阻，夜里被俘，栾共叔也一同被抓。 战败后翼地又立哀侯之子为小子侯，继续抵抗曲沃。 韩万属于后来韩氏追述的先祖一支，家族传承把韩氏与周同列姬姓，并以韩原封邑解释氏名；这里是认识人物的祖源背景，不表示本年才授封或后世韩厥已出生。 [[1]](#note-1)

<a id="event-2"></a>

2. **正月，鲁桓公与齐侯在嬴地会面，为与齐国成婚作准备。** 鲁齐关系由政治盟会进一步转成婚姻关系。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，齐侯与卫侯在蒲地互相约定友好，但没有举行正式盟誓。** 同期鲁桓公又与杞侯在郕地会面，杞国主动寻求与鲁讲和。 [[3]](#note-3)

<a id="event-4"></a>

4. **七月朔日，发生日全食。** 日食被完整记录为“既”，即日面被完全遮蔽。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋，鲁国公子翚到齐国迎娶文姜；九月，齐侯亲自把文姜送到讙地，桓公在那里迎接。** 文姜随后正式抵达鲁国，成为桓公夫人。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬，齐侯派弟弟年到鲁国聘问，完成婚姻后的礼仪往来。** 这一年鲁齐关系明显升温。 [[6]](#note-6)

<a id="event-7"></a>

7. **芮伯因宠妾过多，被母亲芮姜逐出，暂居魏地。** 芮国内部矛盾随后引来秦和周王室介入。 [[7]](#note-7)

<a id="sj014-0709-event"></a>

<a id="event-8"></a>

8. **晋哀侯被俘后，翼地拥立他的儿子为小子侯；曲沃武公随后命韩万杀害被俘的晋哀侯。** 这一年翼地政权并未因国君被俘便立即消失，另立幼主维持晋侯一系；曲沃势力增强，却还没有得到周王的晋侯名号。 [[8]](#note-8)

#### 卷014互见｜翼国拥立小子侯，曲沃武公命人杀死被俘的晋哀侯

[《晋世家·哀侯、小子侯》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7039.md#ref-bdcb779d99057b)叙述哀侯九年被俘、国人立小子侯，小子元年韩万杀哀侯；[《十二诸侯年表》前709年晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0709)仅题「晋小子元年」。[《左传·桓公三年》](../../sources/春秋左传/data/zz-02-03.json)详记夜获翼侯，但未逐句记韩万杀人。晋哀侯战败被俘和后续被杀应区别，不凭世家追叙擅补具体月日。

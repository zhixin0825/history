# 公元前710年（鲁桓公二年）

[← 上一张已编年页：公元前711年](bce-0711.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前709年 →](bce-0709.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

<a id="reading-event-1"></a>

1. **正月，宋太宰华父督先杀司马孔父，夺其妻，又杀宋殇公。** 宋殇公即位十年间连续用兵，国内已经疲惫。华父督把民怨推给孔父，趁机杀死孔父并夺取其妻；宋殇公震怒，华父督害怕被治罪，索性弑君。 [[1]](#reading-note-1)

<a id="event-2"></a>

<a id="reading-event-2"></a>

2. **华父督从郑国迎回公子冯，立为宋庄公，并用财物争取鲁、齐、陈、郑承认新政权。** 三月，鲁桓公与齐、陈、郑诸侯在稷地会面，宋国送出赂物，各国最终接受了宋庄公；华父督掌握了相位。 [[2]](#reading-note-2)

<a id="event-3"></a>

<a id="reading-event-3"></a>

3. **四月，宋国送给鲁国的郜大鼎被放进太庙，臧哀伯强烈反对。** 他认为把乱臣弑君后送来的赂器公开陈列在祖庙，会让百官把违法和贿赂视为可以效仿的行为；桓公没有听从。 [[3]](#reading-note-3)

<a id="event-4"></a>

<a id="reading-event-4"></a>

4. **秋，杞侯来鲁朝见时礼数不敬，鲁国随后出兵进入杞国。** 杞侯回国后，鲁国决定讨伐，九月军队进入杞地。 [[4]](#reading-note-4)

<a id="event-5"></a>

<a id="reading-event-5"></a>

5. **蔡侯与郑庄公在邓地相会，开始共同担忧楚国势力北上。** 这是楚国逐渐进入中原诸侯视野的一个信号。 [[5]](#reading-note-5)

<a id="event-6"></a>

<a id="reading-event-6"></a>

6. **鲁桓公与戎人在唐地结盟，恢复旧好。** 桓公回国后还按礼告庙，正式结束这次出行。 [[6]](#reading-note-6)

<a id="event-7"></a>

<a id="reading-event-7"></a>

7. **晋国内部的曲沃—翼争位已经延续数十年。** 曲沃势力从桓叔、庄伯一路扩大，先后冲击翼地政权；翼一方也不断另立新君。晋国“本弱末强”的格局越来越难维持，为后面的曲沃吞并埋下基础。 [[7]](#reading-note-7)

<a id="reading-event-8"></a>

8. **曲沃争位有更早的家族背景。** 晋穆侯给长子取名仇，给次子取名成师；成师后来被封在曲沃，号桓叔，由栾宾辅佐。潘父曾杀晋昭侯、迎桓叔而未成，晋人另立孝侯；以后曲沃与翼地的争斗继续扩大。 [[8]](#reading-note-8)

<a id="event-8"></a>

<a id="reading-event-9"></a>

9. **滕国国君来鲁朝见。** 经文称来朝者为滕子；这与同年杞侯来朝、鲁军随后入杞不是一件事，分别保存。 [[9]](#reading-note-9)

<a id="sj014-0710-yan"></a>

<a id="reading-event-10"></a>

10. **燕国开始以宣侯元年纪事。** 宣侯是燕穆侯的儿子，承接上一年发生的君位更替。 [[10]](#reading-note-10)

### 8. 曲沃争位有更早的家族背景

[返回正文第8条](#reading-event-8)

**[《左传》](../../sources/春秋左传/有标点原文/bce-0710.md#t009)**

> 异哉，君之名子也！夫名以制义，义以出礼，礼以体政，政以正民。是以政成而民听，易则生乱。嘉耦曰妃，怨耦曰仇，古之命也。今君命大子曰仇，弟曰成师，始兆乱矣，兄其替乎

**[《左传》](../../sources/春秋左传/有标点原文/bce-0710.md#t010)**

> 吾闻国家之立也，本大而末小，是以能固。故天子建国，诸侯立家，卿置侧室，大夫有贰宗，士有隶子弟，庶人工商各有分亲，皆有等衰。是以民服事其上而下无觊觎。今晋，甸侯也，而建国。本既弱矣，其能久乎

> 初，晋穆侯之夫人姜氏以条之役生大子，命之曰仇。其弟以千亩之战生，命之曰成师。师服曰：“异哉，君之名子也！夫名以制义，义以出礼，礼以体政，政以正民。是以政成而民听，易则生乱。嘉耦曰妃，怨耦曰仇，古之命也。今君命大子曰仇，弟曰成师，始兆乱矣，兄其替乎？”

> 惠之二十四年，晋始乱，故封桓叔于曲沃，靖侯之孙栾宾傅之。师服曰：“吾闻国家之立也，本大而末小，是以能固。故天子建国，诸侯立家，卿置侧室，大夫有贰宗，士有隶子弟，庶人工商各有分亲，皆有等衰。是以民服事其上而下无觊觎。今晋，甸侯也，而建国。本既弱矣，其能久乎？”

> 惠之三十年，晋潘父弑昭侯而纳桓叔，不克。晋人立孝侯。

## 归年与考证

<a id="history-legacy-source-1"></a>
<a id="note-1"></a>

1. **《春秋·桓公二年》**：“王正月戊申，宋督弑其君与夷，及其大夫孔父。”  
   **《左传·桓公二年》**详记华父督“攻孔氏，杀孔父而取其妻”，继而弑宋殇公。

   [卷014本年宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0710)合写起意、杀孔父与弑君；前一年见妻的前情已在[前711年](bce-0711.md#event-6)，本年不重复起因的实际发生。

<a id="history-legacy-source-2"></a>
<a id="note-2"></a>

2. **《春秋·桓公二年》**：“三月，公会齐侯、陈侯、郑伯于稷，以成宋乱。”  
   **《左传·桓公二年》**：“召庄公于郑而立之……齐、陈、郑皆有赂。”

   [卷014宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0710)写“宋公冯元年，华督为相”。补入的是政变后华督的地位，不另造一次新政变，亦不把“相”不加辨别地等同后代统一的丞相官制。

<a id="history-legacy-source-3"></a>
<a id="note-3"></a>

3. **《春秋·桓公二年》**：“夏四月，取郜大鼎于宋。戊申，纳于大庙。”  
   **《左传·桓公二年》**详载臧哀伯劝谏，批评“寘其赂器于大庙”。

   [卷014鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0710)同记受鼎入庙及“君子讥之”，属于本条及其评价，不能再增加一次收受同鼎。

<a id="note-4"></a>

   **《左传·桓公二年》**：“杞侯来朝，不敬。杞侯归，乃谋伐之。”

<a id="history-legacy-source-5"></a>
<a id="note-5"></a>

5. **《春秋·桓公二年》**：“蔡侯、郑伯会于邓。”  
   **《左传·桓公二年》**：“始惧楚也。”

<a id="note-6"></a>

   **《左传·桓公二年》**：“修旧好也。”

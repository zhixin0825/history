# 公元前710年（鲁桓公二年）

1. **华父督弑宋君立公子冯，鲁接受宋国赂鼎。** 宋殇公在位十年间屡次兴兵，民心疲惫。正月，太宰华父督把民怨归咎于司马孔父，杀孔父而夺其妻，又因畏罪杀掉宋殇公。华父督迎回在郑的公子冯为宋庄公，自任相。三月，鲁、齐、陈、郑于稷相会，收受宋国赂物并承认新君。四月，鲁桓公把宋国赂赠的郜大鼎放入太庙，臧哀伯劝他勿以赂器向百官示范，桓公不从。 [[1]](#reading-note-1)

<a id="event-4"></a>

<a id="reading-event-4"></a>

2. **秋，杞侯来鲁朝见时礼数不敬，鲁国随后出兵进入杞国。** 杞侯回国后，鲁国决定讨伐，九月军队进入杞地。 [[2]](#reading-note-4)

<a id="event-5"></a>

<a id="reading-event-5"></a>

3. **蔡侯与郑庄公在邓地相会，开始共同担忧楚国势力北上。** 这是楚国逐渐进入中原诸侯视野的一个信号。 [[3]](#reading-note-5)

<a id="event-6"></a>

<a id="reading-event-6"></a>

4. **鲁桓公与戎人在唐地结盟，恢复旧好。** 桓公回国后还按礼告庙，正式结束这次出行。 [[4]](#reading-note-6)

<a id="event-7"></a>

<a id="reading-event-7"></a>

<a id="reading-event-8"></a>

5. **翼军侵陉廷，陉廷转联曲沃。** 晋穆侯曾以仇、成师为两子命名。成师后来封曲沃，称桓叔，由栾宾辅佐。潘父曾杀晋昭侯企图迎立桓叔，未能成功，晋人另立孝侯。此后曲沃由桓叔到庄伯日渐壮大，与翼地长期争位。本年翼军侵犯陉廷，陉廷转而联系曲沃武公，为次年的汾水战事埋下伏笔。 [[5]](#reading-note-7)

<a id="event-8"></a>

<a id="reading-event-9"></a>

6. **滕国国君来鲁朝见。** 经文称来朝者为滕子；这与同年杞侯来朝、鲁军随后入杞不是一件事，分别保存。 [[6]](#reading-note-9)

<a id="sj014-0710-yan"></a>

<a id="reading-event-10"></a>

7. **燕国开始以宣侯元年纪事。** 宣侯是燕穆侯的儿子，承接上一年发生的君位更替。 [[7]](#reading-note-10)

## 归年与考证

<a id="history-legacy-source-1"></a>
<a id="note-1"></a>

1. **《春秋·桓公二年》**：“王正月戊申，宋督弑其君与夷，及其大夫孔父。”  
   **《左传·桓公二年》**详记华父督“攻孔氏，杀孔父而取其妻”，继而弑宋殇公。

   [卷014本年宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0710)合写起意、杀孔父与弑君；前一年见妻的前情已在[前711年](bce-0711.md#event-6)，本年不重复起因的实际发生。

<a id="history-legacy-source-2"></a>
<a id="note-2"></a>

2. **《春秋·桓公二年》**：“三月，公会齐侯、陈侯、郑伯于稷，以成宋乱。”  
   **《左传·桓公二年》**：“召庄公于郑而立之……齐、陈、郑皆有赂。”

   [卷014宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0710)写“宋公冯元年，华督为相”。补入的是政变后华督的地位，不另造一次新政变，亦不把“相”不加辨别地等同后代统一的丞相官制。

<a id="note-3"></a>

   **《左传·桓公二年》**详载臧哀伯劝谏，批评“寘其赂器于大庙”。

# 公元前710年（鲁桓公二年）

[← 上一张已编年页：公元前711年](bce-0711.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前709年 →](bce-0709.md)

<a id="event-1"></a>

1. **正月，宋太宰华父督先杀司马孔父，夺其妻，又杀宋殇公。** 宋殇公即位十年间连续用兵，国内已经疲惫。华父督把民怨推给孔父，趁机杀死孔父并夺取其妻；宋殇公震怒，华父督害怕被治罪，索性弑君。[1]

<a id="event-2"></a>

2. **华父督从郑国迎回公子冯，立为宋庄公，并用财物争取鲁、齐、陈、郑承认新政权。** 三月，鲁桓公与齐、陈、郑诸侯在稷地会面，宋国送出赂物，各国最终接受了宋庄公。[2]

<a id="event-3"></a>

3. **四月，宋国送给鲁国的郜大鼎被放进太庙，臧哀伯强烈反对。** 他认为把乱臣弑君后送来的赂器公开陈列在祖庙，会让百官把违法和贿赂视为可以效仿的行为；桓公没有听从。[3]

<a id="event-4"></a>

4. **秋，杞侯来鲁朝见时礼数不敬，鲁国随后出兵进入杞国。** 杞侯回国后，鲁国决定讨伐，九月军队进入杞地。[4]

<a id="event-5"></a>

5. **蔡侯与郑庄公在邓地相会，开始共同担忧楚国势力北上。** 这是楚国逐渐进入中原诸侯视野的一个信号。[5]

<a id="event-6"></a>

6. **鲁桓公与戎人在唐地结盟，恢复旧好。** 桓公回国后还按礼告庙，正式结束这次出行。[6]

<a id="event-7"></a>

7. **晋国内部的曲沃—翼争位已经延续数十年。** 曲沃势力从桓叔、庄伯一路扩大，先后冲击翼地政权；翼一方也不断另立新君。晋国“本弱末强”的格局越来越难维持，为后面的曲沃吞并埋下基础。[7]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·桓公二年》**：“王正月戊申，宋督弑其君与夷，及其大夫孔父。”  
   **《左传·桓公二年》**详记华父督“攻孔氏，杀孔父而取其妻”，继而弑宋殇公。

<a id="note-2"></a>

2. **《春秋·桓公二年》**：“三月，公会齐侯、陈侯、郑伯于稷，以成宋乱。”  
   **《左传·桓公二年》**：“召庄公于郑而立之……齐、陈、郑皆有赂。”

<a id="note-3"></a>

3. **《春秋·桓公二年》**：“夏四月，取郜大鼎于宋。戊申，纳于大庙。”  
   **《左传·桓公二年》**详载臧哀伯劝谏，批评“寘其赂器于大庙”。

<a id="note-4"></a>

4. **《春秋·桓公二年》**：“秋七月，杞侯来朝……九月，入杞。”  
   **《左传·桓公二年》**：“杞侯来朝，不敬。杞侯归，乃谋伐之。”

<a id="note-5"></a>

5. **《春秋·桓公二年》**：“蔡侯、郑伯会于邓。”  
   **《左传·桓公二年》**：“始惧楚也。”

<a id="note-6"></a>

6. **《春秋·桓公二年》**：“公及戎盟于唐。冬，公至自唐。”  
   **《左传·桓公二年》**：“修旧好也。”

<a id="note-7"></a>

7. **《左传·桓公二年》**在篇末回顾晋国曲沃、翼两支自晋穆侯以后长期争位，以及桓叔、庄伯、孝侯、鄂侯、哀侯之间的更替。

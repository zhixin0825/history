# 公元前711年（鲁桓公元年）

[← 上一张已编年页：公元前712年](bce-0712.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前710年 →](bce-0710.md)

<a id="event-1"></a>

1. **春，鲁桓公正式即位。** 隐公死后，桓公取得君位；鲁国随即着手修复与郑国的关系。[[1]](#note-1)

<a id="event-2"></a>

2. **三月，鲁桓公与郑庄公在垂地会面，郑国以玉璧为礼，推动许田与祊田的交换。** 郑国希望恢复祭祀周公的安排，鲁国最终同意完成这次土地交换。[[2]](#note-2)

 [卷四互见与归年](#sj004-711-1)


<a id="event-3"></a>

3. **夏四月丁未，鲁桓公与郑庄公在越地盟誓，为土地交换收尾。** 双方把这次交易正式固定下来，并以“违盟者不得长久享国”相互约束。[[3]](#note-3)

<a id="event-4"></a>

4. **秋，鲁国发生大水。** 平原水位漫出，被记录为“大水”。[[4]](#note-4)

<a id="event-5"></a>

5. **冬，郑庄公再次确认盟约。** 郑国对越地之盟表示承认，鲁郑关系暂时稳定下来。[[5]](#note-5)

<a id="event-6"></a>

6. **宋国太宰华父督在路上见到司马孔父的妻子，被她的美貌吸引。** 这一念头很快演变成下一年宋国内乱的直接导火索。[[6]](#note-6)

<a id="sj014-0711-yan"></a>

7. **燕穆侯去世，由儿子接位，后来称燕宣侯。** 本年仍以穆侯十八年归档，下一年进入宣侯元年。[[7]](#sj014-0711-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·桓公元年》**：“元年春，王正月，公即位。”

   **名与母系：**[卷014本年鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0711)题“鲁桓公允元年”，附记其母为宋武公之女，以及她出生时手纹成“鲁夫人”字的传说。手纹说的是母亲，不是本年桓公出生，更不是据此证成预言。本页依经传保留前712年遇弑后的承继与本年正式即位，不把母系补记另作出生事件。

<a id="note-2"></a>

2. **《春秋·桓公元年》**：“三月，公会郑伯于垂，郑伯以璧假许田。”  
   **《左传·桓公元年》**：“郑人请复祀周公，卒易祊田。公许之。”

<a id="sj004-711-1"></a>
#### 交换许田的后续手续｜卷四互见

[卷004 P043](../../sources/摘录/史记-卷004-周本纪.md#p043)。 这里是前715年祊地交付后的后续，不因卷004系在桓王五年就删去经传桓公元年明确的会面、玉璧与盟誓。[卷014郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0711)同记“以璧加鲁，易许田”，不再记一次相同交换。


<a id="note-3"></a>

3. **《春秋·桓公元年》**：“夏四月丁未，公及郑伯盟于越。”  
   **《左传·桓公元年》**：“结祊成也。盟曰：‘渝盟无享国。’”

<a id="note-4"></a>

4. **《春秋·桓公元年》**：“秋，大水。”  
   **《左传·桓公元年》**：“凡平原出水为大水。”

<a id="note-5"></a>

5. **《左传·桓公元年》**：“冬，郑伯拜盟。”

<a id="note-6"></a>

6. **《左传·桓公元年》**：“宋华父督见孔父之妻于路，目逆而送之，曰：‘美而艳。’”

   [卷014前710年宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0710)把见妻、杀孔父、弑殇公连写。这里按经传将见妻作为前情留在本年，翌年只记随后的夺权，不让华督两次遇见同一女子、两次发生相同起意。

<a id="sj014-0711-note"></a>
### 7｜燕穆侯死亡与宣侯元年

[《燕召公世家》穆侯、宣侯段](https://zh.wikisource.org/wiki/史記/卷034)记穆侯七年为鲁隐公元年，又记“十八年卒，子宣侯立”；[卷014本年燕栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0711)为十八，下一行即[宣侯元年](bce-0710.md#sj014-0710-yan)。以同书对应归本年，未确定月日、死因或即位仪式。穆、缪是所据文本异称，不再造两位连续在位的君主。

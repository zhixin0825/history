# 公元前712年（鲁隐公十一年）

[← 上一张已编年页：公元前713年](bce-0713.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前711年 →](bce-0711.md)

<a id="event-1"></a>

1. **春，滕侯、薛侯一同来鲁朝见，却为谁该排在前面发生争执。** 薛侯说自己受封更早；滕侯则强调自己属于周王室宗盟体系，不能排在异姓薛国之后。隐公让羽父出面调解，最终薛侯同意让滕侯居前。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，鲁隐公与郑庄公会面，商议联合攻打许国。** 双方在出兵前先确定了共同进攻许国的计划。[[2]](#note-2)

<a id="event-3"></a>

3. **郑军出征前，公孙阏（子都）与颍考叔因争车结怨。** 颍考叔抢先拉车而走，子都没追上，心中愤怒。这段看似是小事，却直接影响之后攻许时的战场内讧。[[3]](#note-3)

<a id="event-4"></a>

4. **秋七月，鲁、齐、郑三国进攻许国；颍考叔率先登城，却被同军的子都从背后射死。** 另一名郑将瑕叔盈继续举起郑庄公旗帜登城，郑军于是全部登上城墙。七月壬午，许国被攻破，许庄公逃往卫国。[[4]](#note-4)

<a id="event-5"></a>

5. **许国战败后，齐侯本想把许地交给鲁国，隐公拒绝；最后由郑庄公主持善后，而不是直接吞并许国。** 郑庄公让许大夫百里辅佐许叔留在许东部，又派郑国公孙获驻守西部。他甚至明确说郑国未必能长久拥有许地，因此给许国保留了恢复的空间。[[5]](#note-5)

<a id="event-6"></a>

6. **郑庄公后来追查射杀颍考叔的人，却只用诅咒方式处理。** 他让士卒献猪犬鸡作诅，想找出凶手；这种处理方式随后受到“没有正常政刑、只靠诅咒无济于事”的批评。[[6]](#note-6)

<a id="event-7"></a>

7. **周王室与郑国重新交换土地，周、郑关系却没有因此改善。** 周王收回邬、刘、蒍、邘等地，又把苏忿生旧田中的温、原、樊等多处土地给郑。土地重新划分之后，双方政治裂痕仍在扩大。[[7]](#note-7)

<a id="event-8"></a>

8. **郑、息发生争执，息侯直接出兵攻郑，结果大败。** 息国没有衡量双方实力和亲疏关系，也没有先处理争端本身，便贸然开战，最终兵败而归。[[8]](#note-8)

<a id="event-9"></a>

9. **冬十月，郑庄公借虢军攻宋，大败宋军，报复此前宋军攻入郑国。** 宋国没有把这次战败正式通告诸侯，因此它没有进入鲁国的正式年表记录。[[9]](#note-9)

<a id="event-10"></a>

10. **十一月，鲁隐公被羽父派人杀死，桓公随后即位。** 羽父原先提出杀桓公，想借此换取太宰职位；隐公拒绝，说自己本来就准备把君位交还桓公，并打算退居菟裘。羽父害怕事情泄露，反过来向桓公诬陷隐公。隐公祭钟巫、斋戒住在寪氏时，羽父派刺客将他杀死。隐公没有正常完成国君丧礼，桓公随即取得君位。[[10]](#note-10)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·隐公十一年》**：“十有一年春，滕侯、薛侯来朝。”  
   **《左传·隐公十一年》**详记二君“争长”，最终“薛侯许之，乃长滕侯”。

<a id="note-2"></a>

2. **《春秋·隐公十一年》**：“夏，公会郑伯于时来。”  
   **《左传·隐公十一年》**：“夏，公会郑伯于郲，谋伐许也。”

   **说明：** 经文地点作“时来”，传文作“郲”；本页正文不选定其中一种写法。

<a id="note-3"></a>

3. **《左传·隐公十一年》**：“郑伯将伐许……公孙阏与颍考叔争车……子都怒。”

<a id="note-4"></a>

4. **《春秋·隐公十一年》**：“秋七月壬午，公及齐侯、郑伯入许。”  
   **《左传·隐公十一年》**详记颍考叔先登、子都射之，“壬午，遂入许。许庄公奔卫。”

<a id="note-5"></a>

5. **《左传·隐公十一年》**详记齐侯以许让鲁、鲁辞，以及郑庄公安置许叔、公孙获，并评曰：“度德而处之，量力而行之，相时而动，无累后人，可谓知礼矣。”

<a id="note-6"></a>

6. **《左传·隐公十一年》**：“郑伯使卒出豭，行出犬、鸡，以诅射颍考叔者。”随后批评“既无德政，又无威刑……邪而诅之，将何益矣”。

<a id="note-7"></a>

7. **《左传·隐公十一年》**详记周王“取邬、刘、蒍、邘之田于郑”，又以温、原、樊等苏忿生之田与郑，并说“君子是以知桓王之失郑也”。

<a id="note-8"></a>

8. **《左传·隐公十一年》**：“郑、息有违言，息侯伐郑。郑伯与战于竟，息师大败而还。”

<a id="note-9"></a>

9. **《左传·隐公十一年》**：“冬十月，郑伯以虢师伐宋。壬戌，大败宋师……宋不告命，故不书。”

<a id="note-10"></a>

10. **《春秋·隐公十一年》**：“冬十有一月壬辰，公薨。”  
    **《左传·隐公十一年》**详记羽父先请杀桓公、隐公拒绝，羽父反谮隐公，“壬辰，羽父使贼弑公于寪氏，立桓公……不书葬，不成丧也。”

# 公元前713年（鲁隐公十年）

[← 上一张已编年页：公元前714年](bce-0714.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前712年 →](bce-0712.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁、齐、郑三国在中丘会面，又在邓地盟誓，约定共同出兵攻宋的日期。** 这场联合行动承接上一年“宋公不王”和鲁齐在防地谋伐宋的局面。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏五月，羽父先率鲁军会同齐、郑伐宋；六月，鲁隐公亲自加入，并在菅地击败宋军。** 联军随后继续进入宋地，隐公本人也从事先的约师会盟转入了战场行动。 [[2]](#note-2)

<a id="event-3"></a>

3. **郑军先后攻下宋国的郜、防两地，却把两地交给鲁国。** 郑庄公没有据为己有，而是把所得土地用来酬劳参战的鲁国。 [[3]](#note-3)

<a id="event-4"></a>

4. **蔡、卫、郕没有响应周王命令，成为之后郑国报复的对象。** 这为后面的攻伐埋下了直接背景。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋，宋、卫军攻入郑国，又同蔡军一起攻戴；三国彼此不和，反被郑庄公一举击败。** 郑军先攻宋郊，宋、卫趁机入郑，再召蔡军伐戴。八月，郑庄公包围戴国并攻克，连同宋、卫、蔡三军一起击败。三国之间缺乏协调，是失败的重要原因之一。 [[5]](#note-5)

<a id="event-6"></a>

6. **九月，郑庄公进一步攻入宋国。** 战事没有因为戴地的胜利而停止，郑军继续把压力推向宋国本土。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬十月，齐、郑联合攻入郕国，追究郕国此前不服从王命。** 这也是这一年“奉王命讨不庭”逻辑的延续。 [[7]](#note-7)

<a id="event-8"></a>

8. **秦与亳交战，亳王逃往戎地，荡社被灭。** 宁公前一年已发兵，本年接写作战和攻取的结果。 [[8]](#note-8)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·隐公十年》**：“十年春，王二月，公会齐侯、郑伯于中丘。”  
   **《左传·隐公十年》**：“王正月，公会齐侯、郑伯于中丘。癸丑，盟于邓，为师期。”

<a id="history-legacy-source-2"></a>


2. **《春秋·隐公十年》**：“夏，翚帅师会齐人、郑人伐宋。六月壬戌，公败宋师于菅。”  
   **《左传·隐公十年》**：“夏五月，羽父先会齐侯、郑伯伐宋……壬戌，公败宋师于菅。”

   [卷014本年宋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0713)记“诸侯败我。我师与卫人伐郑”，与本年进攻、反击两段互见。鲁军此前已参加诸侯战争，例如[前719年翚擅自伐郑](bce-0719.md#event-5)，故不把本年写成鲁国第一次卷入这些国家之间的冲突。

<a id="history-legacy-source-3"></a>


3. **《春秋·隐公十年》**：“辛未，取郜。辛巳，取防。”  
   **《左传·隐公十年》**：“郑师入郜；辛未，归于我……郑师入防；辛巳，归于我。”

<a id="history-legacy-source-4"></a>


4. **《左传·隐公十年》**：“蔡人、卫人、郕人不会王命。”

<a id="history-legacy-source-5"></a>


5. **《春秋·隐公十年》**：“秋，宋人、卫人入郑。宋人、蔡人、卫人伐戴。郑伯伐取之。”  
   **《左传·隐公十年》**详记郑围戴，“癸亥，克之，取三师焉”，并说宋、卫、蔡不和而败。

<a id="history-legacy-source-6"></a>


6. **《左传·隐公十年》**：“九月戊寅，郑伯入宋。”

<a id="history-legacy-source-7"></a>


7. **《春秋·隐公十年》**：“冬十月壬午，齐人、郑人入郕。”  
   **《左传·隐公十年》**：“冬，齐人、郑人入郕，讨违王命也。”

#### sj005-028｜秦与亳交战，亳王逃往戎地，荡社被灭。

[卷005 P009](../../sources/摘录/史记-卷005-秦本纪.md#p009)。

**说明：**这里的亳王不等同商汤时代的王，也不据“亳”字直接复原一个存续千年的商王国。

**归年：**按本条注明的本纪／年表取舍；秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

# 公元前714年（鲁隐公九年）

[← 上一张已编年页：公元前715年](bce-0715.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前713年 →](bce-0713.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，周天子派南季来鲁国聘问。** 现存本年记载没有再说明这次聘问的具体任务。 [[1]](#note-1)

<a id="event-2"></a>

<a id="hs-event-10"></a>

2. **鲁国三月先大雨雷电，继而降雪。** 鲁国三月先遇大雨雷电，后来又下大雪，当时被视为时令异常。连雨三日以上称为霖，平地积雪一尺称为大雪。 [[2]](#note-2)

<a id="event-3"></a>

3. **这一年名为“挟”的鲁国人物去世。** 现存本年记载没有补充他的身份和丧事经过。 [[3]](#note-3)

<a id="event-4"></a>

4. **夏，鲁国修筑郎城。** 这项工程被认为施工时间不合适。 [[4]](#note-4)

<a id="event-5"></a>

<a id="event-6"></a>

5. **郑奉王命讨宋，鲁与齐商议出兵。** 宋殇公不朝周王，郑庄公以周王左卿士身份奉命讨宋。宋没有向鲁转达王命，鲁遂同宋断绝使者往来。秋，郑来告伐宋。冬，鲁隐公与齐侯在防商议共同攻宋。 [[5]](#note-5)

<a id="event-7"></a>

6. **北戎入侵郑国，郑军利用伏兵大败戎军。** 郑军担心戎兵都是步卒、机动迅速，公子突建议派兵诱敌后退，再布置多层伏兵。戎军贪进、前后不能互救，郑军于是合击。十一月甲寅，北戎大败。 [[6]](#note-7)

<a id="event-8"></a>

7. **秦宁公迁居平阳，并派兵进攻荡社。** 迁居与用兵同系宁公二年。原文的平阳、荡社依其称谓保留，不据同名套用后世县城。 [[7]](#note-8)

<a id="sj014-0714-event"></a>

<a id="event-9"></a>

8. **蔡桓侯封人元年。** 蔡宣公上年去世并下葬，儿子封人继位。本年为蔡桓侯元年。 [[8]](#note-9)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·隐公九年》**：“九年春，天子使南季来聘。”

<a id="history-legacy-source-2"></a>


2. **《春秋·隐公九年》**：“三月癸酉，大雨震电。庚辰，大雨雪。”  
   **《左传·隐公九年》**：“大雨霖以震，书始也。庚辰，大雨雪，亦如之。书时失也。”

   **卷014异文：**[本年鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0714)作“三月，大雨雹，电”，与经传的大雨、雷电及后来的大雪不完全相同。本页沿经传分别记天气，保留表中的“雹”字，不把它另算成本年第三场已经独立证实的灾害，也不静默改写原表。

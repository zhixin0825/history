# 公元前715年（鲁隐公八年）

<a id="event-1"></a>

<a id="event-5"></a>

1. **齐国居中调停，宋、齐、卫在瓦屋结盟。** 齐侯为宋、卫与郑国的和解定了日期。宋公先送礼与卫侯相约，春天在垂相见。秋，齐国促成各方和解，宋、齐、卫在瓦屋盟誓，缓解了东门之役以来的敌对。八月，郑庄公还率齐人朝见周王。 [[1]](#note-1)

<a id="event-2"></a>

2. **三月，郑庄公把祊地交给鲁国，鲁国随后正式接收。** 郑国希望放弃泰山祭祀相关权利，用祊地交换鲁国的许田，所以派大夫宛来鲁办理交割。庚寅，鲁国进入祊地。 [[2]](#note-2)

    [卷四互见与归年](#sj004-715-1)

<a id="event-3"></a>

3. **夏，虢公忌父开始在周王室担任卿士。** 这反映周王室内部权力安排的变化，也同郑国此前对周王重用虢氏的不满有关。 [[3]](#note-3)

<a id="event-4"></a>

4. **四月，郑公子忽到陈国迎娶妫氏，婚礼程序随后受到批评。** 公子忽先把妫氏娶回郑国，后来才告祖庙。陈国送亲的鍼子批评“先配而后祖”，认为这不是合乎礼制的婚姻程序。 [[4]](#note-4)

<a id="event-6"></a>

5. **九月，鲁隐公与莒人在浮来结盟，进一步巩固鲁、纪、莒之间的关系。** 这次盟会同鲁国和纪国的婚姻外交有关。 [[5]](#note-6)

<a id="event-7"></a>

6. **这一年蔡侯考父、宿国国君先后去世，鲁国又安葬蔡宣公。** 六月己亥蔡侯去世，辛亥宿国国君去世；八月，蔡宣公下葬。现存本年记载没有进一步展开他们的死亡经过。 [[6]](#note-7)

<a id="event-8"></a>

<a id="hs-event-11"></a>

7. **鲁国九月发生螟灾。** [[7]](#note-8)

<a id="event-9"></a>

8. **冬十二月，无骇去世，鲁国从此为他的后人确定“展氏”这一族氏。** 羽父请求给无骇确定谥和族，隐公询问众仲姓氏制度。众仲解释天子赐姓、诸侯以字为族以及官族、邑氏等规则，隐公最后以无骇的字命为展氏。 [[8]](#note-9)

<a id="sj014-0715-qin"></a>

<a id="event-10"></a>

9. **秦国进入宁公元年。** 前一年秦文公去世，早死的太子竫公之子接位，本年开始用这位新君的在位年次纪事。 [[9]](#note-10)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·隐公八年》**：“八年春，宋公、卫侯遇于垂。”  
   **《左传·隐公八年》**：“齐侯将平宋、卫，有会期。宋公以币请于卫，请先相见，卫侯许之，故遇于犬丘。”

   **释义：**同年传文后来补明“齐人卒平宋、卫于郑”，调停对象是宋、卫一方与郑国，不宜把省略后的前句误解为齐国只调停宋、卫彼此之间的争端。垂、犬丘保留经传地名差别，不未经地理考证另造两次会面。

<a id="history-legacy-source-2"></a>


2. **《春秋·隐公八年》**：“三月，郑伯使宛来归祊。庚寅，我入祊。”  
   **《左传·隐公八年》**：“郑伯请释泰山之祀而祀周公，以泰山之祊易许田。三月，郑伯使宛来归祊。”

<a id="sj004-715-1"></a>
<a id="许田交换先从交付祊地开始卷四互见"></a>
##### 许田交换先从交付祊地开始｜卷四互见

[卷004 P043](../../拆分史书/史记/卷004.md#p043)。 本纪桓王五年简记郑怨王而与鲁易许田。经传把前715年交祊与前711年会垂、加璧、完成交换分开；不能据本纪一句话把全部手续集中本年，另一阶段见前711年。[卷014鲁、郑两栏](../../拆分史书/史记/卷014.md#y0715)也分别写易许田、与鲁祊，互为同一过程，不另建两条交换。


<a id="history-legacy-source-4"></a>

   婚配的同意已在[前716年](bce-0716.md#event-7)，本条是亲迎及随后的礼制争议，不能在两年各写一次完整婚礼。

<a id="history-legacy-source-6"></a>

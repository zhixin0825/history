# 公元前716年（鲁隐公七年）

[← 上一张已编年页：公元前717年](bce-0717.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前715年 →](bce-0715.md)

<a id="event-1"></a>

1. **春三月，叔姬正式嫁到纪国；同年滕侯去世。** 滕侯此前没有同鲁国参加盟会，因此这次死亡记录没有留下他的名字。[1]

<a id="event-2"></a>

2. **夏，鲁国修筑中丘城。** 这项工程被认为开工时机不合适。[2]

<a id="event-3"></a>

3. **齐侯派弟弟年到鲁国聘问，用来巩固上一年艾地结盟后的关系。** 这次出使继续确认鲁、齐新近恢复的友好关系。[3]

<a id="event-4"></a>

4. **宋、郑暂时讲和，在宿地结盟；随后鲁隐公又出兵攻邾，为宋国讨伐。** 此前宋、郑多年交战，这一年终于和解。七月庚申双方在宿地盟誓；鲁国随后出兵攻邾。[4]

<a id="event-5"></a>

5. **冬，周天子派凡伯来鲁聘问，凡伯回程却被戎人在楚丘袭击并掳走。** 戎人以前朝周时曾向王室公卿送礼，凡伯没有礼遇他们，双方早已有嫌隙。[5]

<a id="event-6"></a>

6. **陈国与郑国也在这一年重新讲和，双方互派人员主持盟誓。** 十二月，陈五父到郑国主持盟约，郑国良佐随后又到陈国。传文还说，参加盟誓的人已经察觉陈国内部将有乱事。[6]

<a id="event-7"></a>

7. **郑庄公为儿子公子忽迎娶陈国女子，郑、陈关系进一步通过婚姻固定下来。** 陈侯主动为女儿求婚，郑庄公同意，婚事由此完成。[7]

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·隐公七年》**：“七年春，王三月，叔姬归于纪。滕侯卒。”  
   **《左传·隐公七年》**：“滕侯卒。不书名，未同盟也。”

<a id="note-2"></a>

2. **《春秋·隐公七年》**：“夏，城中丘。”  
   **《左传·隐公七年》**：“夏，城中丘，书，不时也。”

<a id="note-3"></a>

3. **《春秋·隐公七年》**：“齐侯使其弟年来聘。”  
   **《左传·隐公七年》**：“齐侯使夷仲年来聘，结艾之盟也。”

<a id="note-4"></a>

4. **《春秋·隐公七年》**：“秋，公伐邾。”  
   **《左传·隐公七年》**：“秋，宋及郑平。七月庚申，盟于宿。公伐邾，为宋讨也。”

<a id="note-5"></a>

5. **《春秋·隐公七年》**：“冬，天王使凡伯来聘。戎伐凡伯于楚丘以归。”  
   **《左传·隐公七年》**：“初，戎朝于周，发币于公卿，凡伯弗宾……还，戎伐之于楚丘以归。”

<a id="note-6"></a>

6. **《左传·隐公七年》**：“陈及郑平。十二月，陈五父如郑涖盟……郑良佐如陈涖盟。”

<a id="note-7"></a>

7. **《左传·隐公七年》**：“郑公子忽在王所，故陈侯请妻之。郑伯许之，乃成昏。”

# 公元前716年（鲁隐公七年）

[← 上一张已编年页：公元前717年](bce-0717.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前715年 →](bce-0715.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春三月，叔姬正式嫁到纪国；同年滕侯去世。** 滕侯此前没有同鲁国参加盟会，因此这次死亡记录没有留下他的名字。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏，鲁国修筑中丘城。** 这项工程被认为开工时机不合适。 [[2]](#note-2)

<a id="event-3"></a>

3. **齐侯派弟弟年到鲁国聘问，用来巩固上一年艾地结盟后的关系。** 这次出使继续确认鲁、齐新近恢复的友好关系。 [[3]](#note-3)

<a id="event-4"></a>

4. **宋、郑暂时讲和，在宿地结盟；随后鲁隐公又出兵攻邾，为宋国讨伐。** 此前宋、郑多年交战，这一年终于和解。七月庚申双方在宿地盟誓；鲁国随后出兵攻邾。 [[4]](#note-4)

<a id="event-5"></a>

5. **冬，周天子派凡伯来鲁聘问，凡伯回程却被戎人在楚丘袭击并掳走。** 戎人以前朝周时曾向王室公卿送礼，凡伯没有礼遇他们，双方早已有嫌隙。 [[5]](#note-5)

<a id="event-6"></a>

6. **陈国与郑国也在这一年重新讲和，双方互派人员主持盟誓。** 十二月，陈五父到郑国主持盟约，郑国良佐随后又到陈国。传文还说，参加盟誓的人已经察觉陈国内部将有乱事。 [[6]](#note-6)

<a id="event-7"></a>

7. **郑庄公同意让儿子公子忽与陈国女子订婚，郑、陈又多了一层婚姻关系。** 公子忽正在周王处，陈侯提出嫁女，郑庄公答应。实际前往陈国迎娶，另见[前715年](bce-0715.md#event-4)。 [[7]](#note-7)

<a id="event-8"></a>

8. **秦文公去世，竫公之子秦宪公继位。** 本纪将宪公写作宁公，指同一人。文公在位五十年，葬在西山；世系中早死的竫公仍不另计作一位正式在位秦君。 [[8]](#note-8)

<a id="sj014-0716-event"></a>

<a id="event-9"></a>

9. **曲沃庄伯去世，儿子称接掌曲沃，后来称曲沃武公。** 曲沃是晋国宗室势力据守的封邑，曾多次与都城翼地的晋侯争位；此时翼地仍有晋哀侯在位。称继承的是曲沃君位，并非已经取代翼地晋侯。 [[9]](#note-9)

### 补充史料与异说

<a id="sj005-026-note"></a>
<a id="sj005-026秦文公去世竫公之子宪公传本作宁公继位"></a>
#### sj005-026｜秦文公去世，竫公之子宪公（传本作宁公）继位。

[卷005 P008](../../sources/摘录/史记-卷005-秦本纪.md#p008)。

**名号：**本纪传本作宁公；[卷006篇末先君纪次](../../sources/摘录/史记-卷006-秦始皇本纪.md#p071)则作宪公。秦公钟、镈铭文也见宪公，详见[名号说明](../../meta/考证/史记-卷005-纪年与异说.md#qin-xian)。原文的“宁”仍照录，正文两名指同一位秦君，不增设另一位君主。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj014-0716-note"></a>
<a id="卷014互见曲沃庄伯去世儿子称继承曲沃"></a>
#### 卷014互见｜曲沃庄伯去世，儿子称继承曲沃

《十二诸侯年表》[前716年晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0716)记庄伯卒、子称立；[《晋世家·哀侯》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7039.md#ref-1b8e4ac923fa9f)系于哀侯二年。前745年曲沃初封、前724年庄伯杀孝侯及本年传位，是不同阶段。曲沃武公最终并晋在前679年前后，不能在本年提前写成晋侯。

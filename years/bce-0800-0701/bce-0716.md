# 公元前716年（鲁隐公七年）

[← 上一张已编年页：公元前717年](bce-0717.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前715年 →](bce-0715.md)

<a id="event-1"></a>

1. **春三月，叔姬正式嫁到纪国；同年滕侯去世。** 滕侯此前没有同鲁国参加盟会，因此这次死亡记录没有留下他的名字。[[1]](#note-1)

<a id="event-2"></a>

2. **夏，鲁国修筑中丘城。** 这项工程被认为开工时机不合适。[[2]](#note-2)

<a id="event-3"></a>

3. **齐侯派弟弟年到鲁国聘问，用来巩固上一年艾地结盟后的关系。** 这次出使继续确认鲁、齐新近恢复的友好关系。[[3]](#note-3)

<a id="event-4"></a>

4. **宋、郑暂时讲和，在宿地结盟；随后鲁隐公又出兵攻邾，为宋国讨伐。** 此前宋、郑多年交战，这一年终于和解。七月庚申双方在宿地盟誓；鲁国随后出兵攻邾。[[4]](#note-4)

<a id="event-5"></a>

5. **冬，周天子派凡伯来鲁聘问，凡伯回程却被戎人在楚丘袭击并掳走。** 戎人以前朝周时曾向王室公卿送礼，凡伯没有礼遇他们，双方早已有嫌隙。[[5]](#note-5)

<a id="event-6"></a>

6. **陈国与郑国也在这一年重新讲和，双方互派人员主持盟誓。** 十二月，陈五父到郑国主持盟约，郑国良佐随后又到陈国。传文还说，参加盟誓的人已经察觉陈国内部将有乱事。[[6]](#note-6)

<a id="event-7"></a>

7. **郑庄公为儿子公子忽迎娶陈国女子，郑、陈关系进一步通过婚姻固定下来。** 陈侯主动为女儿求婚，郑庄公同意，婚事由此完成。[[7]](#note-7)

<a id="event-8"></a>

8. **秦文公去世，竫公之子宁公继位。** 文公在位五十年，葬在西山；世系中早死的竫公仍不另计作一位正式在位秦君。 [原文与说明](#sj005-026-note)

<a id="sj014-0716-event"></a>

9. **曲沃庄伯去世，儿子称接掌曲沃，后来称曲沃武公。** 曲沃是晋国宗室势力据守的封邑，曾多次与都城翼地的晋侯争位；此时翼地仍有晋哀侯在位。称继承的是曲沃君位，并非已经取代翼地晋侯。 [[9]](#sj014-0716-note)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·隐公七年》**：“七年春，王三月，叔姬归于纪。滕侯卒。”  
   **《左传·隐公七年》**：“滕侯卒。不书名，未同盟也。”

<a id="note-2"></a>

2. **《春秋·隐公七年》**：“夏，城中丘。”  
   **《左传·隐公七年》**：“夏，城中丘，书，不时也。”

<a id="note-3"></a>

3. **《春秋·隐公七年》**：“齐侯使其弟年来聘。”  
   **《左传·隐公七年》**：“齐侯使夷仲年来聘，结艾之盟也。”

<a id="note-4"></a>

4. **《春秋·隐公七年》**：“秋，公伐邾。”  
   **《左传·隐公七年》**：“秋，宋及郑平。七月庚申，盟于宿。公伐邾，为宋讨也。”

<a id="note-5"></a>

5. **《春秋·隐公七年》**：“冬，天王使凡伯来聘。戎伐凡伯于楚丘以归。”  
   **《左传·隐公七年》**：“初，戎朝于周，发币于公卿，凡伯弗宾……还，戎伐之于楚丘以归。”

<a id="note-6"></a>

6. **《左传·隐公七年》**：“陈及郑平。十二月，陈五父如郑涖盟……郑良佐如陈涖盟。”

<a id="note-7"></a>

7. **《左传·隐公七年》**：“郑公子忽在王所，故陈侯请妻之。郑伯许之，乃成昏。”

## 补充史料与异说

<a id="sj005-026-note"></a>
### sj005-026｜秦文公去世，竫公之子宁公继位。

[卷005 P008](../../sources/摘录/史记-卷005-秦本纪.md#p008)。

**归年：**秦君元年、在位数与《十二诸侯年表》《六国年表》对照，规则及冲突见[本卷纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。古月与干支未作历算时，不当作同号公历月日。

<a id="sj014-0716-note"></a>
### 卷014互见｜曲沃庄伯去世，儿子称继承曲沃

《十二诸侯年表》[前716年晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0716)记庄伯卒、子称立；[《晋世家·哀侯》](https://zh.wikisource.org/wiki/史記/卷039)系于哀侯二年。前745年曲沃初封、前724年庄伯杀孝侯及本年传位，是不同阶段。曲沃武公最终并晋在前679年前后，不能在本年提前写成晋侯。

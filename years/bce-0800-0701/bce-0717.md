# 公元前717年（鲁隐公六年）

[← 上一张已编年页：公元前718年](bce-0718.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前716年 →](bce-0716.md)

<a id="event-1"></a>

1. **春，郑国主动来鲁重新讲和。** 郑、鲁此前的紧张关系由此重新缓和。[[1]](#note-1)

<a id="event-2"></a>

2. **晋国内部继续争位：翼地旧族把晋侯从随迎回，安置到鄂。** 晋人此后称他为“鄂侯”；这件事承接上一年曲沃与翼的冲突。[[2]](#note-2)

<a id="event-3"></a>

3. **夏五月，鲁隐公与齐侯在艾地结盟，鲁、齐开始正式恢复和平。** 这是两国关系重新转向稳定的标志。[[3]](#note-3)

<a id="event-4"></a>

4. **五月，郑庄公进攻陈国，大获全胜；导火索是陈国此前拒绝郑国求和。** 前一年郑曾希望同陈讲和，陈桓公没有接受。大夫五父曾劝他说“亲仁善邻，国之宝也”，陈桓公却认为宋、卫才值得担心。郑军这一年攻陈取胜，陈国此前拒绝和解的代价随即显现。[[4]](#note-4)

<a id="event-5"></a>

5. **秋，宋国终于攻下长期围困的长葛。** 这场围城从隐公五年已经开始，到这一年才以宋军占领长葛告终。[[5]](#note-5)

<a id="event-6"></a>

6. **冬，周王室发生饥荒，鲁隐公替京师向宋、卫、齐、郑等国请求购买粮食。** 鲁国出面协调诸侯粮食，以缓解王畿饥荒。[[6]](#note-6)

<a id="event-7"></a>

7. **郑庄公首次朝见周桓王，却没有受到应有礼遇，周、郑关系进一步恶化。** 周桓公提醒周王：周室东迁以来，晋、郑一直是重要支柱；如果连郑国都不善待，将来更难让诸侯来朝。郑庄公受到冷遇后，周郑矛盾没有缓和。[[7]](#note-7)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·隐公六年》**：“六年春，郑人来输平。”  
   **《左传·隐公六年》**：“六年春，郑人来渝平，更成也。”

   **说明：** 经文作“输平”，传文作“渝平”；两处都指郑、鲁重新讲和，本页保留原字，不擅改。[卷014本年鲁栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0717)亦作渝平，是同次和解。

<a id="note-2"></a>

2. **《左传·隐公六年》**：“翼九宗五正顷父之子嘉父逆晋侯于随，纳诸鄂。晋人谓之鄂侯。”

   **纪年互见：**[卷014本年晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0717)已题“晋哀侯光元年”，前一年又称鄂侯卒。《左传》则明确写前一年翼侯奔随、本年迎入鄂，并在前一年记王命立哀侯。正文保留它对出奔、迎回的连续记载，不把表中的元年另写成一次新即位，也不拼成鄂侯死后复生。有关出兵国王、鄂侯生死的差异见[前718年注2、注5](bce-0718.md#note-2)。

<a id="note-3"></a>

3. **《春秋·隐公六年》**：“夏五月辛酉，公会齐侯，盟于艾。”  
   **《左传·隐公六年》**：“夏，盟于艾，始平于齐也。”

<a id="note-4"></a>

4. **《左传·隐公六年》**：“五月庚申，郑伯侵陈，大获。往岁，郑伯请成于陈，陈侯不许。”又载五父劝曰：“亲仁善邻，国之宝也。”

<a id="note-5"></a>

5. **《春秋·隐公六年》**：“冬，宋人取长葛。”  
   **《左传·隐公六年》**：“秋，宋人取长葛。”

<a id="note-6"></a>

6. **《左传·隐公六年》**：“冬，京师来告饥。公为之请籴于宋、卫、齐、郑，礼也。”

<a id="note-7"></a>

7. **《左传·隐公六年》**：“郑伯如周，始朝桓王也。王不礼焉。”周桓公又劝王善郑，警告“郑不来矣”。

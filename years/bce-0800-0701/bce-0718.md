<a id="hs-event-11"></a>

1. **鲁隐公观鱼不纳谏，臧僖伯卒后获加礼。** 春，鲁隐公到棠地观鱼。臧僖伯劝国君亲自出动须合军政与祭祀礼制，隐公仍然前往，臧僖伯称病不从。秋，鲁国发生螟灾。十二月，臧僖伯去世。隐公记得此前观鱼之争，依加等礼仪办理丧葬。 [[1]](#note-1)

<a id="event-2"></a>

<a id="event-5"></a>

2. **曲沃攻翼后背周，周王遣虢公另立晋哀侯。** 春，曲沃庄伯联合郑、邢攻晋国旧都翼，翼侯逃往随，周王室曾使尹氏、武氏助曲沃。秋，曲沃背叛周王，周王改遣虢公出兵，在翼拥立鄂侯之子光，即晋哀侯。翼地与曲沃仍各有其主。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏四月，卫国安葬前一年被州吁杀死的卫桓公。** 因卫国内乱，正常葬礼一直拖到这一年才举行。 [[3]](#note-3)

<a id="event-4"></a>

4. **郑、卫冲突继续升级，郑军在北制击败卫国援军燕师。** 郑国先为报复“东门之役”进攻卫牧；卫国随后借燕军反击。郑军把主力列在正面，又让两位公子带兵潜伏后方。燕军只防着正面郑军，没有料到后方伏兵，最终在北制大败。 [[4]](#note-4)

<a id="event-6"></a>

5. **卫军攻入郕国，报复郕国曾趁卫国内乱时入侵卫国。** 这次行动是州吁之乱后的直接报复。 [[5]](#note-6)

<a id="event-7"></a>

6. **九月，鲁国祭告仲子之宫，第一次使用六羽之舞。** 隐公询问舞者应当用多少羽，众仲回答：天子八佾、诸侯六佾、大夫四佾、士二佾。鲁国于是采用六羽之舞。 [[6]](#note-7)

<a id="event-8"></a>

7. **邾、郑联合攻宋，攻入宋国外城；宋国随后反攻郑国，包围长葛。** 宋人此前夺取邾地，邾国便请郑出兵，并表示愿意为郑军带路。郑军借王师名义伐宋，攻入其郛；到了冬天，宋国又伐郑并围长葛，双方冲突继续扩大。 [[7]](#note-8)

<a id="event-10"></a>

8. **秦文公的太子先于父亲去世，孙子被立为太子。** 秦文公的太子去世，谥为竫公。竫公的长子承接储位，后来为秦宪公。 [[8]](#note-10)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·隐公五年》**：“五年春，公矢鱼于棠。”  
   **《左传·隐公五年》**详载臧僖伯谏隐公不应为观鱼亲出，并说：“书曰‘公矢鱼于棠’，非礼也，且言远地也。”

   [卷014本年鲁栏](../../拆分史书/史记/卷014.md#y0718)同记观鱼与“君子讥之”；这是同次游观及对它的礼制评论，不另记一次出行。

<a id="history-legacy-source-2"></a>


2. **《左传·隐公五年》**：“曲沃庄伯以郑人、邢人伐翼，王使尹氏、武氏助之。翼侯奔随。”

   **鄂侯生死异说：**[卷014本年晋栏](../../拆分史书/史记/卷014.md#y0718)和[《晋世家》鄂侯段](../../拆分史书/史记/卷039.md#part-2-text)却把鄂侯去世列为曲沃出兵的前提；经传主线是本年翼侯逃随、[前717年被迎到鄂](bce-0717.md#event-2)。两套叙述不能拼成“先死、次年又被迎回”。正文保留经传连续的出奔、迎回过程，死亡说留注，未声称已由独立证据完全解决。

<a id="history-legacy-source-3"></a>


3. **《春秋·隐公五年》**：“夏四月，葬卫桓公。”  
   **《左传·隐公五年》**：“夏，葬卫桓公。卫乱，是以缓。”

   [卷014卫栏](../../拆分史书/史记/卷014.md#y0718)题“卫宣公晋元年”，又回顾共立、讨州吁。宣公的实际拥立和州吁被杀已在[前719年](bce-0719.md#event-7)，本年是元年纪事与前君葬礼，不再造第二次拥立或第二次诛州吁。

<a id="history-legacy-source-4"></a>


4. **《左传·隐公五年》**详叙郑侵卫牧、卫以燕师伐郑，郑军前后设伏，“六月，郑二公子以制人败燕师于北制。”

<a id="history-legacy-source-5"></a>


5. **《左传·隐公五年》**：“曲沃叛王。秋，王命虢公伐曲沃而立哀侯于翼。”

   [卷014周、晋两栏](../../拆分史书/史记/卷014.md#y0718)分记王命伐曲沃和立哀侯光，属于同一轮干预。《晋世家》这里称出兵者为周平王，但平王之死已有[前720年](bce-0720.md#event-2)经传记载，不能让平王在本年再派兵。哀侯元年另见[前717年](bce-0717.md#note-2)，不把即位和起算元年强作同月。

<a id="history-legacy-source-6"></a>


6. **《春秋·隐公五年》**：“秋，卫师入郕。”  
   **《左传·隐公五年》**：“卫之乱也，郕人侵卫，故卫师入郕。”

<a id="history-legacy-source-7"></a>


7. **《春秋·隐公五年》**：“九月，考仲子之宫，初献六羽。”  
   **《左传·隐公五年》**载众仲答羽数：“天子用八，诸侯用六，大夫四，士二……于是初献六羽、始用六佾也。”

<a id="history-legacy-source-8"></a>


8. **《春秋·隐公五年》**：“邾人、郑人伐宋……宋人伐郑，围长葛。”  
   **《左传·隐公五年》**详叙宋取邾田、邾请郑伐宋、郑入宋郛，以及宋围长葛“以报入郛之役”。

   **释义修正：**邾人的原话是“请君释憾于宋，敝邑为道”，“敝邑”是说话者邾国，所以是邾愿带路、请郑出兵，不是邾请求郑替自己带路。[《左传》全文](../../拆分史书/左传/异本/春秋左氏傳-隱公.md)。[卷014宋栏](../../拆分史书/史记/卷014.md#y0718)的“郑伐我。我伐郑”即这条往复战争，不另造两次同名战役。

<a id="history-legacy-source-9"></a>


9. **《春秋·隐公五年》**：“螟。冬十有二月辛巳，公子彄卒。”  
   **《左传·隐公五年》**：“冬十二月辛巳，臧僖伯卒。公曰：‘叔父有憾于寡人，寡人弗敢忘。’葬之加一等。”

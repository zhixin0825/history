# 公元前719年（鲁隐公四年）

[← 上一张已编年页：公元前720年](bce-0720.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前718年 →](bce-0718.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春二月，莒国攻打杞国，夺取牟娄。** 现存本年记载只保存了战果，没有展开战役经过。 [[1]](#note-1)

<a id="event-2"></a>

2. **同月，卫国公子州吁杀死国君卫桓公，自立为君。** 这正是上一年石碏担心的局面。州吁虽然夺得君位，却无法使卫国人心服从，于是转而想靠对外战争取得诸侯支持、压住国内反对。 [[2]](#note-2)

<a id="event-3"></a>

3. **夏，鲁隐公与宋殇公在清地会面。** 原本双方准备依照旧盟正式相会，但卫国突然发生弑君之乱，行程受影响，最后只在清地“遇”。 [[3]](#note-3)

<a id="event-4"></a>

4. **州吁联合宋、陈、蔡攻郑，希望借战争巩固自己的地位。** 宋国想除掉流亡郑国的公子冯，卫国又同郑国有旧怨；州吁于是主动游说宋国，并拉上陈、蔡。四国围攻郑国东门五天后退兵。 [[4]](#note-4)

<a id="event-5"></a>

5. **秋，诸侯再次伐郑，鲁国大夫翚未经隐公允许，执意率军参战。** 隐公本来拒绝宋国求援，翚却再三请求并自行出兵。联军击败郑国步兵，割取庄稼后撤退；翚擅自出兵也因此受到批评。 [[5]](#note-5)

<a id="event-6"></a>

6. **石碏设计借陈国之手除掉州吁，同时连自己的儿子石厚也不放过。** 州吁仍无法安定卫国，石厚便向父亲石碏问怎样取得合法地位。石碏建议他们去陈国，请陈桓公代为向周王请命，却暗中通知陈国：两人正是弑君者，请直接扣押。陈人照办，九月卫人杀州吁于濮；石碏又派家臣在陈国杀掉石厚。后世所谓“大义灭亲”即由这段评价而来。 [[6]](#note-6)

<a id="event-7"></a>

7. **冬十二月，卫人迎回公子晋并拥立为君，是为卫宣公。** 这次拥立由卫国众人共同推动，新君由此确立。 [[7]](#note-7)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·隐公四年》**：“四年春，王二月，莒人伐杞，取牟娄。”

<a id="history-legacy-source-2"></a>


2. **《春秋·隐公四年》**：“戊申，卫州吁弑其君完。”  
   **《左传·隐公四年》**：“四年春，卫州吁弑桓公而立。”

<a id="history-legacy-source-3"></a>


3. **《春秋·隐公四年》**：“夏，公及宋公遇于清。”  
   **《左传·隐公四年》**：“公与宋公为会，将寻宿之盟。未及期，卫人来告乱。夏，公及宋公遇于清。”

<a id="history-legacy-source-4"></a>


4. **《春秋·隐公四年》**：“宋公、陈侯、蔡人、卫人伐郑。”  
   **《左传·隐公四年》**详载州吁“将修先君之怨于郑，而求宠于诸侯以和其民”，遂说宋并联合陈、蔡围郑东门。

<a id="history-legacy-source-5"></a>


5. **《春秋·隐公四年》**：“秋，翚帅师会宋公、陈侯、蔡人、卫人伐郑。”  
   **《左传·隐公四年》**：“宋公使来乞师，公辞之。羽父请以师会之，公弗许，固请而行。故书曰‘翚帅师’，疾之也。”

<a id="history-legacy-source-6"></a>


6. **《春秋·隐公四年》**：“九月，卫人杀州吁于濮。”  
   **《左传·隐公四年》**详叙石碏诱州吁、石厚赴陈，陈人执二人，卫人杀州吁，石碏使家臣杀石厚，并评曰：“大义灭亲，其是之谓乎。”

<a id="history-legacy-source-7"></a>


7. **《春秋·隐公四年》**：“冬十有二月，卫人立晋。”  
   **《左传·隐公四年》**：“卫人逆公子晋于邢。冬十二月，宣公即位。书曰‘卫人立晋’，众也。”

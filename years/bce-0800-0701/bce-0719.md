2. **州吁弑君并联兵攻郑，石碏除乱后卫宣公立。** 春二月，州吁杀卫桓公自立，因难以使国人信服，遂谋求对外用兵。鲁隐公与宋殇公原定依旧盟相会，因卫国生乱，入夏只在清地相遇。宋国欲除去奔郑的公子冯，卫国与郑国也有旧怨，州吁联合宋、陈、蔡围郑东门五天后退。秋，诸侯再伐郑，鲁隐公拒绝宋国求援，鲁大夫翚却自行参战。联军击败郑国步卒，割取庄稼退兵。石厚为州吁向父亲石碏求问如何取得名分，石碏让他们托陈桓公向周王请命，又密告陈人扣押两名弑君者。九月，卫人杀州吁于濮，石碏遣家臣在陈国杀石厚。冬十二月，卫人迎公子晋为君，即卫宣公。 [[2]](#note-2)

## 归年与考证

<a id="history-legacy-source-1"></a>


1. **《春秋·隐公四年》**：“四年春，王二月，莒人伐杞，取牟娄。”

<a id="history-legacy-source-2"></a>


2. **《春秋·隐公四年》**：“戊申，卫州吁弑其君完。”  
   **《左传·隐公四年》**：“四年春，卫州吁弑桓公而立。”

<a id="history-legacy-source-3"></a>


3. **《春秋·隐公四年》**：“夏，公及宋公遇于清。”  
   **《左传·隐公四年》**：“公与宋公为会，将寻宿之盟。未及期，卫人来告乱。夏，公及宋公遇于清。”

<a id="history-legacy-source-4"></a>


4. **《春秋·隐公四年》**：“宋公、陈侯、蔡人、卫人伐郑。”  
   **《左传·隐公四年》**详载州吁“将修先君之怨于郑，而求宠于诸侯以和其民”，遂说宋并联合陈、蔡围郑东门。

<a id="history-legacy-source-5"></a>


5. **《春秋·隐公四年》**：“秋，翚帅师会宋公、陈侯、蔡人、卫人伐郑。”  
   **《左传·隐公四年》**：“宋公使来乞师，公辞之。羽父请以师会之，公弗许，固请而行。故书曰‘翚帅师’，疾之也。”

<a id="history-legacy-source-6"></a>


6. **《春秋·隐公四年》**：“九月，卫人杀州吁于濮。”  
   **《左传·隐公四年》**详叙石碏诱州吁、石厚赴陈，陈人执二人，卫人杀州吁，石碏使家臣杀石厚，并评曰：“大义灭亲，其是之谓乎。”

<a id="history-legacy-source-7"></a>


7. **《春秋·隐公四年》**：“冬十有二月，卫人立晋。”  
   **《左传·隐公四年》**：“卫人逆公子晋于邢。冬十二月，宣公即位。书曰‘卫人立晋’，众也。”

# 公元前720年（鲁隐公三年）

[← 上一张已编年页：公元前721年](bce-0721.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前719年 →](bce-0719.md)

<a id="event-1"></a>

1. **春，鲁国记录了一次日食。** 时间记为王二月己巳，现存本年记载没有进一步解释这次天象。[[1]](#note-1)

<a id="event-2"></a>

2. **三月，周平王去世。** 周王室随后进入新的权力安排阶段，郑国与王室之间原有的矛盾也迅速加深。[[2]](#note-2)

平王的太子洩父早已去世，继位的是孙子林，即桓王。父子之间缺了一代，不能把林误写成平王直接生下的太子。 [卷四互见与归年](#sj004-720-1)


<a id="event-3"></a>

3. **夏四月，隐公之母声子去世。** 鲁国没有按诸侯夫人的完整规格向诸侯报丧，也没有完成反哭、祔庙等礼仪，因此她的丧事规格低于正式夫人之礼。[[3]](#note-3)

<a id="event-4"></a>

4. **周、郑关系迅速恶化，双方甚至从交换人质走到郑国抢收王畿麦禾。** 郑武公、庄公长期在周王室任卿士，周平王又想重用虢公，引起郑庄公不满。周、郑互相交换人质仍无法建立信任。平王死后，郑祭足率兵割取温地麦子，秋天又取成周之禾，双方公开交恶。[[4]](#note-4)

<a id="event-5"></a>

5. **秋，周王室的武氏之子来鲁国请求助丧财物。** 此时周平王尚未安葬。[[5]](#note-5)

<a id="event-6"></a>

6. **八月，宋穆公去世，并在死前坚持把君位还给哥哥宋宣公的儿子，而不是传给自己的儿子。** 宋穆公把公子冯送到郑国居住，让宋殇公继位。这一继承安排后来成为宋、郑长期冲突的背景之一。[[6]](#note-6)

<a id="event-7"></a>

7. **冬十二月，齐侯与郑伯在石门结盟。** 双方重申此前卢地之盟；同月宋穆公下葬。[[7]](#note-7)

<a id="event-8"></a>

8. **卫国内部已经埋下继承危机：州吁受宠、好兵，老臣石碏已经预见祸患。** 卫庄公宠爱嬖人之子州吁，却不约束他。石碏劝国君“爱子，教之以义方”，卫庄公不听；石碏自己的儿子石厚又同州吁亲近。这个背景直接通向下一年的弑君。[[8]](#note-8)

## 本年相关史料

<a id="note-1"></a>

1. **《春秋·隐公三年》**：“三年春，王二月己巳，日有食之。”

<a id="note-2"></a>

2. **《春秋·隐公三年》**：“三月庚戌，天王崩。”  
   **《左传·隐公三年》**：“三年春，王三月壬戌，平王崩。赴以庚戌，故书之。”

   **说明：** 两处纪日不同。传文称平王实际死于壬戌，而讣告作庚戌，所以经文照讣告记庚戌；本页不强行统一。

<a id="sj004-720-1"></a>
#### 平王之后由孙林继位｜卷四互见

[卷004 P042](../../sources/摘录/史记-卷004-周本纪.md#p042)。 本纪平王五十一年与经传本年相合；“太子蚤死”是此前的家世说明，不再单列本年太子之死。


<a id="note-3"></a>

3. **《春秋·隐公三年》**：“夏四月辛卯，君氏卒。”  
   **《左传·隐公三年》**：“君氏卒。声子也。不赴于诸侯，不反哭于寝，不祔于姑，故不曰薨。不称夫人，故不言葬。”

<a id="note-4"></a>

4. **《左传·隐公三年》**：“郑武公、庄公为平王卿士，王贰于虢……故周、郑交质……四月，郑祭足帅师取温之麦。秋，又取成周之禾。周、郑交恶。”

<a id="note-5"></a>

5. **《春秋·隐公三年》**：“秋，武氏子来求赙。”  
   **《左传·隐公三年》**：“武氏子来求赙，王未葬也。”

<a id="note-6"></a>

6. **《春秋·隐公三年》**：“八月庚辰，宋公和卒。”  
   **《左传·隐公三年》**详记宋穆公病重时把君位让还宣公之后，并使公子冯出居郑国。

<a id="note-7"></a>

7. **《春秋·隐公三年》**：“冬十有二月，齐侯、郑伯盟于石门。癸未，葬宋穆公。”  
   **《左传·隐公三年》**：“冬，齐、郑盟于石门，寻卢之盟也。”

<a id="note-8"></a>

8. **《左传·隐公三年》**详叙卫庄公、庄姜、戴妫、卫桓公与州吁的家族关系，并载石碏谏曰：“臣闻爱子，教之以义方，弗纳于邪。”

# 公元前721年（鲁隐公二年）

[← 上一张已编年页：公元前722年](bce-0722.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元前720年 →](bce-0720.md)

<a id="event-1"></a>

1. **春，鲁隐公在潜地会见戎人，想延续鲁惠公时期的友好关系。** 戎人提出结盟，隐公这一次没有马上答应。到了秋天，双方才正式在唐地盟誓。[1]

<a id="event-2"></a>

2. **夏五月，莒国进入向国，把嫁到莒国后又回娘家的向姜带回去。** 莒君娶了向国女子向姜；向姜在莒国住得不安稳，自行回到向国，莒人因此出兵进入向国。[2]

<a id="event-3"></a>

3. **鲁国司空无骇率军攻入极地。** 费庈父在这次行动中取胜，现存记载没有再展开更长的战事经过。[3]

<a id="event-4"></a>

4. **秋八月，鲁隐公终于与戎人在唐地结盟。** 这次结盟承接春天的会面，鲁国与戎人由此重新修复旧好。[4]

<a id="event-5"></a>

5. **九月到十月，纪国与鲁国完成一桩国君婚姻。** 九月，纪国大夫裂繻来鲁迎娶女子；十月，伯姬正式嫁到纪国。由卿替国君迎亲，是这桩婚姻采用的正式安排。[5]

<a id="event-6"></a>

6. **冬，纪子帛与莒子在密地结盟。** 这次结盟同鲁国关系有关；这一年鲁、纪、莒之间的婚姻和盟会彼此牵连。[6]

<a id="event-7"></a>

7. **十二月乙卯，夫人子氏去世。** 现存本年记载没有进一步说明她的丧礼经过。[7]

<a id="event-8"></a>

8. **年底，郑国攻打卫国，继续追究上一年共叔段之乱留下的问题。** 共叔段失败后，公孙滑逃到卫国，卫国曾替他攻郑；郑国这次伐卫，就是这一连串冲突的后续。[8]

## 补充史料与归年说明


<a id="sj-042-L3772-02"></a>

### 年次与异说｜1. 郑庄公后悔，借掘地与母亲相见

**时间：《十二诸侯年表》郑庄公二十三年** · 事件

《郑世家》说过了一年多，庄公想念母亲，又担心违背誓言。颍考叔提出掘地到地下相见的办法，庄公照办。《十二诸侯年表》把此事另写在郑庄公二十三年。

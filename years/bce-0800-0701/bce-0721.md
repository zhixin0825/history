<a id="event-4"></a>

1. **鲁隐公春会戎人，秋盟于唐。** 春，鲁隐公在潜会见戎人，商议延续鲁惠公时的交好关系。戎人请盟，隐公暂未答应。八月，双方正式在唐地盟誓。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏五月，莒国进入向国，把嫁到莒国后又回娘家的向姜带回去。** 莒君娶了向国女子向姜；向姜在莒国住得不安稳，自行回到向国，莒人因此出兵进入向国。 [[2]](#note-2)

<a id="event-3"></a>

3. **鲁国司空无骇率军攻入极地。** 费庈父在这次行动中取胜，现存记载没有再展开更长的战事经过。 [[3]](#note-3)

<a id="event-5"></a>

<a id="event-6"></a>

4. **纪鲁结亲，纪与莒结盟。** 九月，纪国大夫裂繻来鲁为国君迎亲。十月，鲁国伯姬嫁到纪国。冬，纪子帛又与莒子在密盟誓，这一盟约也关系到鲁国。 [[4]](#note-5)

<a id="event-7"></a>

5. **十二月乙卯，夫人子氏去世。** 现存本年记载没有进一步说明她的丧礼经过。 [[5]](#note-7)

<a id="event-8"></a>

6. **年底，郑国攻打卫国，继续追究上一年共叔段之乱留下的问题。** 共叔段失败后，公孙滑逃到卫国，卫国曾替他攻郑；郑国这次伐卫，就是这一连串冲突的后续。 [[6]](#note-8)

<a id="sj-042-L3772-02"></a>

<a id="event-9"></a>

7. **郑庄公想再见母亲，颍考叔替他找到了不违誓言的办法。** 庄公迁母后渐生悔意，却受“不及黄泉，无相见也”的誓言束缚。颍考叔建议向地下挖到泉水，在隧道中相见，以这样的方式解释“黄泉”。庄公采纳，母子重新和好。迁母与立誓见[前722年](bce-0722.md#event-4)；相见的具体月份没有记载。 颍考叔先向庄公献物，受赐食时又请求把君赐的食物留给自己的母亲。庄公由此吐露思母却怕违誓的苦恼，考叔才提出掘地见泉的办法。 [[7]](#note-9)

#### 9｜郑庄公母子和好的年次与唯一阅读位置

[《十二诸侯年表》本年郑栏](../../拆分史书/史记/卷014.md#y0721)记“二十三，公悔，思母不见，穿地相见”；《郑世家》在庄公二十二年迁母之后写“居岁余”。本页据此暂把和好的主体叙述放在庄公二十三年，不另外给出月日。

[《史记》卷42郑世家旧摘录](../../拆分史书/史记/README.md#part-1-ref-sj-3772) · [卷14旧摘录](../../拆分史书/史记/README.md#part-1-ref-sj-960) · [《郑世家》完整互见](../../拆分史书/史记/卷042.md#part-1-text)。原有`sj-042-L3772-02`锚点保留，已从后台式说明移到对应白话正文。

**异说：**[《左传·隐公元年》](../../拆分史书/左传/异本/春秋左氏傳-隱公.md)在前722年的迁母故事后直接连叙颍考叔献食、留肉奉母、掘地相见及母子“如初”，没有另列相见的年月。这里不把元年连叙自动判成次年说必错，也不反过来宣布明确排除了前722年；暂依《史记》的时间线索安排阅读，并在[前722年原注](bce-0722.md#note-4)同时说明。两页指向同一次和好，不能计算成两件史事。

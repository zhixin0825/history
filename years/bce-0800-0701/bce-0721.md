# 公元前721年（鲁隐公二年）

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="event-1"></a>

1. **春，鲁隐公在潜地会见戎人，想延续鲁惠公时期的友好关系。** 戎人提出结盟，隐公这一次没有马上答应。到了秋天，双方才正式在唐地盟誓。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏五月，莒国进入向国，把嫁到莒国后又回娘家的向姜带回去。** 莒君娶了向国女子向姜；向姜在莒国住得不安稳，自行回到向国，莒人因此出兵进入向国。 [[2]](#note-2)

<a id="event-3"></a>

3. **鲁国司空无骇率军攻入极地。** 费庈父在这次行动中取胜，现存记载没有再展开更长的战事经过。 [[3]](#note-3)

<a id="event-4"></a>

4. **秋八月，鲁隐公终于与戎人在唐地结盟。** 这次结盟承接春天的会面，鲁国与戎人由此重新修复旧好。 [[4]](#note-4)

<a id="event-5"></a>

5. **九月到十月，纪国与鲁国完成一桩国君婚姻。** 九月，纪国大夫裂繻来鲁迎娶女子；十月，伯姬正式嫁到纪国。由卿替国君迎亲，是这桩婚姻采用的正式安排。 [[5]](#note-5)

<a id="event-6"></a>

6. **冬，纪子帛与莒子在密地结盟。** 这次结盟同鲁国关系有关；这一年鲁、纪、莒之间的婚姻和盟会彼此牵连。 [[6]](#note-6)

<a id="event-7"></a>

7. **十二月乙卯，夫人子氏去世。** 现存本年记载没有进一步说明她的丧礼经过。 [[7]](#note-7)

<a id="event-8"></a>

8. **年底，郑国攻打卫国，继续追究上一年共叔段之乱留下的问题。** 共叔段失败后，公孙滑逃到卫国，卫国曾替他攻郑；郑国这次伐卫，就是这一连串冲突的后续。 [[8]](#note-8)

<a id="sj-042-L3772-02"></a>

<a id="event-9"></a>

9. **郑庄公想再见母亲，颍考叔替他找到了不违誓言的办法。** 庄公迁母后渐生悔意，却受“不及黄泉，无相见也”的誓言束缚。颍考叔建议向地下挖到泉水，在隧道中相见，以这样的方式解释“黄泉”。庄公采纳，母子重新和好。迁母与立誓见[前722年](bce-0722.md#event-4)；相见的具体月份没有记载。 [[9]](#note-9)

<a id="9郑庄公母子和好的年次与唯一阅读位置"></a>
#### 9｜郑庄公母子和好的年次与唯一阅读位置

[《十二诸侯年表》本年郑栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0721)记“二十三，公悔，思母不见，穿地相见”；《郑世家》在庄公二十二年迁母之后写“居岁余”。本页据此暂把和好的主体叙述放在庄公二十三年，不另外给出月日。

[《史记》卷42郑世家旧摘录](../../sources/摘录/史记-条目原文.md#ref-sj-3772) · [卷14旧摘录](../../sources/摘录/史记-条目原文.md#ref-sj-960) · [《郑世家》完整互见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7042.md#ref-16073c1b3ab1c8)。原有`sj-042-L3772-02`锚点保留，已从后台式说明移到对应白话正文。

**异说：**[《左传·隐公元年》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%98%A5%E7%A7%8B%E5%B7%A6%E6%B0%8F%E5%82%B3-%E9%9A%B1%E5%85%AC.md#ref-76f0bd98c8ff5c)在前722年的迁母故事后直接连叙颍考叔献食、留肉奉母、掘地相见及母子“如初”，没有另列相见的年月。这里不把元年连叙自动判成次年说必错，也不反过来宣布明确排除了前722年；暂依《史记》的时间线索安排阅读，并在[前722年原注](bce-0722.md#note-4)同时说明。两页指向同一次和好，不能计算成两件史事。

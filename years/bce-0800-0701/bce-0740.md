# 公元前740年｜楚武王继位

[← 公元前741年](bce-0741.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前739年 →](bce-0739.md)

**本条据《史记》卷014《十二诸侯年表》的前740年行整理；周、鲁、各国分别纪年。** 本页只写底本有据的继承、婚姻或战争，不等于本年所有国家都已经考证完。

<a id="本年纪事"></a>
<a id="sj014-y0740"></a>

<a id="event-1"></a>

1. **楚武王继位。** 楚国栏出现“武王立”，记的是日后称楚武王的君主登场。此时楚国仍在周平王时代，称王的政治含义应与继位年分开考察。 [[1]](#note-1)

<a id="sj037-zhouyu-command-event"></a>

2. **庄公让州吁领兵，石碏忧虑将来生乱。** 州吁是庄公宠妾之子，长大后喜好军事。庄公让他领兵，石碏劝说庶子好武而掌军可能酿成内乱，庄公没有听从。 [[2]](#sj037-zhouyu-command-note)

### 2. 庄公让州吁领兵，石碏忧虑将来生乱

[返回正文第2条](#sj037-zhouyu-command-event)

<a id="sj037-cite-017"></a>

**[《史记·卫康叔世家》P010](../../sources/摘录/史记-卷037-卫康叔世家.md#p010)**

> 莊公有寵妾，生子州吁。十八年，州吁長，好兵，莊公使將。石碏諫莊公曰：「庶子好兵，使將，亂自此起。」不聽。

**本卷说明：** 庄公十八年接前740；石碏劝谏有较早的回叙层，非前719州吁之乱已经发生。

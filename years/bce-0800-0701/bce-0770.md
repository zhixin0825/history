# 公元前770年｜平王东迁洛邑，周室更加依靠诸侯

**周平王元年（东迁用传统纪年）**

> 本页按古史年条与传统公元对照归档；明确有争议的日期见对应说明。月份、干支未直接换算为公历日期；不以已有一条材料表示本年所有历史都已收齐。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="event-1"></a>

1. **平王东迁洛邑，周室更加依靠诸侯。** 平王把王室重心移到洛邑，以避西方戎患。维持王政所能直接支配的力量缩小，诸侯在拥立、护送与防卫中的作用增大。 [[1]](#note-1)

   此后齐、楚、秦、晋等势力渐强，盟会与征伐越来越由强国主导。这是平王及东周较长时期的变化，不是说四国在迁都当天就同时取得霸主地位。

   襄公以兵护送平王，随后以诸侯身份与各国通使。平王许给岐以西之地，同时要求秦自行逐戎取得；襄公又建西畤，用骝驹、黄牛、羝羊祭祀，宣示新的地位。

<a id="sj014-audit-0770-zheng"></a>

<a id="event-2"></a>

2. **郑武公滑突元年。** 郑国在桓公遇害后，由他的儿子滑突继承国君之位，即郑武公；本年开始武公纪年。 郑在东方取得诸邑的后续经过与年次不明之处，见[西周末与春秋初的东迁阶段](未定年-西周末与春秋初.md#sj042-east-territory-event)，不将其完成强定在武公元年。 [[2]](#note-2)

> 周東徙雒邑。秦襄公攻戎救周，始列爲諸侯。秦襄公旣侯，居西垂，自以爲主少皡之神，作西畤，祠白帝，其牲用駵駒黃牛羝羊各一云。

**本卷归年说明：** 平王东迁、襄公始列诸侯及西畤依原年页，《十二诸侯年表》秦襄公八年载西畤。


<a id="sj110-p002"></a>

**[《史记·匈奴列传》P002](../../拆分史书/史记/卷110.md#p002)** · [三家注](../../拆分史书/史记/卷110.md#part-1-p2)

> 秦襄公救周，於是周平王去酆鄗而東徙雒邑。當是之時，秦襄公伐戎至岐，始列爲諸侯。

**本卷归年说明：** 救周、受封与平王东迁相承，依《周本纪》《秦本纪》及现有年页叙东迁；秦进一步获周西土另论。

## 归年与考证

<a id="sj004-770-1"></a>
<a id="1-平王东迁洛邑周室更加依靠诸侯"></a>
#### 1. 平王东迁洛邑，周室更加依靠诸侯

[卷004 P040](../../拆分史书/史记/卷004.md#p040)。 沿卷014及传统公元对照，前770列平王元年与东迁。清华《系年》有“周亡王九年”、迎平王与三年后东徙的另一套次序，学者对断句、两王并立及绝对年有不同重构；本页保留传统阅读坐标，并在考证中列出异说，不声称770排除了所有问题。

# 公元前780年｜西周三川发生地震，岐山崩塌的记载随之出现

[← 公元前781年](bce-0781.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前779年 →](bce-0779.md)

**周幽王二年**

> 本页按古史年条与传统公元对照归档；明确有争议的日期见对应说明。月份、干支未直接换算为公历日期；不以已有一条材料表示本年所有历史都已收齐。

## 本年纪事

<a id="event-1"></a>

1. **西周三川发生地震，岐山崩塌的记载随之出现。** 王畿三川一带发生地震，本年又被记为三川枯竭、岐山崩塌。水源与山体的变动，使朝中对周室处境的担忧加重。

伯阳甫用阴阳失序、山川与民生相连来解释，并将夏商覆亡作比较，推断周也将有大难。他的话保留为当时的自然观与政治判断，不当成已经验证的地震预报。 [原文与说明](#note-1)

<a id="sj014-0780-jin-wenhou"></a>
2. **晋文侯仇元年。** 太子仇已在前781年袭杀殇叔、取得晋君之位；本年《十二诸侯年表》才从“晋文侯仇元年”起算。这是前一年继承变局后的新年次，不是另一次夺位战争。 [原文与说明](#sj014-0780-jin-note)

<a id="sj014-0780-chen-yigong"></a>
3. **陈夷公说元年。** 陈武公灵去世后，其子说继立为夷公；《十二诸侯年表》在前780年陈国栏记夷公元年。此前陈武公的终年与周幽王元年相接，而本年起算新君年次，两个时间层次不必合并成同一次年内事件。 [原文与说明](#sj014-0780-chen-note)

## 本年相关史料

<a id="note-1"></a>
<a id="sj004-780-1"></a>
### 1. 西周三川发生地震，岐山崩塌的记载随之出现

[卷004 P036](../../sources/摘录/史记-卷004-周本纪.md#p036)。 本纪与卷014均系幽王二年，通行对照前780。原文没有现代震级、震中或伤亡数；夏时伊洛竭、商时河竭属于论证中的往例，不从本条另外生成古代灾害年表。

<a id="sj014-0780-jin-note"></a>
### 2. 晋文侯元年与前一年继位
[卷014前780年晋栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0780)明记“晋文侯仇元年”；[前781年主体](bce-0781.md#sj014-y0781)已记仇袭杀殇叔。《晋世家》“殇叔四年，穆侯太子仇率其徒袭殇叔而立，是为文侯”，见[《晋世家》](https://zh.wikisource.org/wiki/史記/卷039)。继位与次年始元分开，不能倒填未经校定的具体月日。

<a id="sj014-0780-chen-note"></a>
### 3. 陈夷公说元年
[卷014前780年陈栏](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0780)记“陈夷公说元年”；[《陈杞世家》](https://zh.wikisource.org/wiki/史記/卷036)记陈武公十五年卒、子夷公说立，并以“是岁，周幽王即位”联年。周幽王元年为前781年，陈国夷公元年为前780年；区分先君去世、继位与次年始元，不据此推定确切月份。

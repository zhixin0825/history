<a id="event-1"></a>

1. **西周三川发生地震，岐山崩塌的记载随之出现。** 王畿三川一带发生地震，本年又被记为三川枯竭、岐山崩塌。水源与山体的变动，使朝中对周室处境的担忧加重。 [[1]](#note-1)

   伯阳甫用阴阳失序、山川与民生相连来解释，并将夏商覆亡作比较，推断周也将有大难。他的话保留为当时的自然观与政治判断，不当成已经验证的地震预报。

<a id="sj014-0780-jin-wenhou"></a>

<a id="event-2"></a>

2. **晋文侯仇元年。** 太子仇上年袭杀殇叔后继位，本年为晋文侯元年。 [[2]](#note-2)

<a id="sj014-0780-chen-yigong"></a>

<a id="event-3"></a>

3. **陈夷公说元年。** 陈武公灵去世后，儿子说继位，是为陈夷公。本年为其元年。 [[3]](#note-3)

> 是歲二川竭，岐山崩。

**[卷004 P036](../../拆分史书/史记/卷004.md#p036)**

> 四十六年，宣王崩，子幽王宮湦立。幽王二年，西周三川皆震。伯陽甫曰：「周將亡矣。夫天地之氣，不失其序；若過其序，民亂之也。陽伏而不能出，陰迫而不能蒸，於是有地震。今三川實震，是陽失其所而填陰也。陽失而在陰，原必塞；原塞，國必亡。夫水土演而民用也。土無所演，民乏財用，不亡何待！昔伊、洛竭而夏亡，河竭而商亡。今周德若二代之季矣，其川原又塞，塞必竭。夫國必依山川，山崩川竭，亡國之徵也。川竭必山崩。若國亡不過十年，數之紀也。天之所棄，不過其紀。」是歲也，三川竭，岐山崩。

## 归年与考证

<a id="sj004-780-1"></a>
<a id="1-西周三川发生地震岐山崩塌的记载随之出现"></a>
#### 1. 西周三川发生地震，岐山崩塌的记载随之出现

[卷004 P036](../../拆分史书/史记/卷004.md#p036)。 本纪与卷014均系幽王二年，通行对照前780。原文没有现代震级、震中或伤亡数；夏时伊洛竭、商时河竭属于论证中的往例，不从本条另外生成古代灾害年表。

<a id="sj014-0780-jin-note"></a>
<a id="2-晋文侯元年与前一年继位"></a>
#### 2. 晋文侯元年与前一年继位
[卷014前780年晋栏](../../拆分史书/史记/卷014.md#y0780)明记“晋文侯仇元年”；[前781年主体](bce-0781.md#sj014-y0781)已记仇袭杀殇叔。《晋世家》“殇叔四年，穆侯太子仇率其徒袭殇叔而立，是为文侯”，见[《晋世家》](../../拆分史书/史记/卷039.md#part-1-text)。继位与次年始元分开，不能倒填未经校定的具体月日。

<a id="sj014-0780-chen-note"></a>
<a id="3-陈夷公说元年"></a>
#### 3. 陈夷公说元年
[卷014前780年陈栏](../../拆分史书/史记/卷014.md#y0780)记“陈夷公说元年”；[《陈杞世家》](../../拆分史书/史记/卷036.md#part-1-text)记陈武公十五年卒、子夷公说立，并以“是岁，周幽王即位”联年。周幽王元年为前781年，陈国夷公元年为前780年；区分先君去世、继位与次年始元，不据此推定确切月份。

# 公元前795年｜陈武公与曹惠伯开始纪年

[← 公元前796年](bce-0796.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前794年 →](bce-0794.md)

**本条据《史记》卷014《十二诸侯年表》的前795年行整理；周、鲁、各国分别纪年。** 本页只写底本有据的继承、婚姻或战争，不等于本年所有国家都已经考证完。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="sj014-y0795"></a>

<a id="event-1"></a>

1. **陈武公与曹惠伯开始纪年。** 年表将本年列为陈武公灵元年、曹惠伯雉元年。此前[陈釐公孝去世、灵承位](bce-0796.md#sj036-chen-xi-death-event)；曹戴伯之死与惠伯承继已在[前796年](bce-0796.md#sj035-cao-dai-death-event)记录。两国是各自的继承序列，不能因同列一行便说两国同时发生同一事件。 [[1]](#note-1)

<a id="sj032-cheng-death-event"></a>

2. **齐成公去世，庄公继位。** 成公在位九年后去世，其子庄公接位。年表将本年列为成公九年，下一年起庄公元年；本卷名“购”，年表名“赎”，保留字异。 [[2]](#sj032-cheng-death-note)

## 归年与考证

<a id="1国别年表与归年界限"></a>
#### 1｜国别年表与归年界限

[《史记》卷014前795年原始年表行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0795) · [卷014有国别列的固定版](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7014.md#ref-5725d0c629111c)。“武公灵”属于陈国，与前825年鲁武公敖不是同一人。[《陈杞世家》陈釐公卒、武公立](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7036.md#ref-23f6bcfd0ee46f)及[《管蔡世家》戴伯卒、惠伯立](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7035.md#ref-663c6d453e52fb)可核继承关系；《管蔡世家》称曹惠伯「兕」，年表称「雉」，暂保留姓名异文，不当成两位国君。本年确定的是年表所标改元，不能由世家继承叙事径行认定父君死亡的具体月日。 本项目按通行公元前年份对照年表的纪年行，未换算古历月日，也未把国别元年强定为国君死亡年月。

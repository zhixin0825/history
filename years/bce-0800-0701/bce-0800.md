# 公元前800年｜宋惠公去世

[← 公元前802年](../bce-0900-0801/bce-0802.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前799年 →](bce-0799.md)

**本条据《史记》卷014《十二诸侯年表》的前800年行整理；周、鲁、各国分别纪年。** 本页只写底本有据的继承、婚姻或战争，不等于本年所有国家都已经考证完。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>
<a id="sj014-y0800"></a>

<a id="event-1"></a>

1. **宋惠公去世。** 宋国一栏记惠公去世；下一年又列戴公即位。死亡与新君元年分别落在年表相邻两年，不应强行合写为同一月日。 [[1]](#note-1)

<a id="sj040-xiongxun-death-event"></a>

2. **楚君熊徇去世，儿子熊咢承位。** 熊徇在位二十二年去世，熊咢继承；年表下一年以熊鄂元年记之。 [[2]](#sj040-xiongxun-death-note)

**[《史记·宋微子世家》P025](../../sources/摘录/史记-卷038-宋微子世家.md#p025)**

> 三十年，惠公卒，子哀公立。哀公元年卒，子戴公立。

**本卷说明：** 主文从830惠元推三十年为801，再接哀800元卒、戴799元；[年表前800](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0800)却明记惠三十一年薨而不列哀年。本页沿直接载卒的年表，哀公仅作短暂承继背景，不把两链说成完全一致。

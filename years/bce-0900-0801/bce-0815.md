# 公元前815年｜鲁懿公与齐文公并列开始纪年

[← 公元前816年](bce-0816.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前812年 →](bce-0812.md)

**周宣王十三年**

鲁、齐两国分别开始计算新君元年。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="sj014-y0815"></a>

<a id="event-1"></a>

1. **鲁国开始计算懿公戏元年。** 鲁武公死后，戏接任鲁君。此前[宣王选择戏为太子](bce-0816.md)，让这位少子先于哥哥括取得继承资格。鲁国从这一年列懿公元年。 [[1]](#note-1)

<a id="event-2"></a>

2. **齐国开始计算文公赤元年。** 齐厉公执政暴虐。胡公的儿子回到齐国，齐人一度要拥立他，和他一起攻杀厉公。胡公之子也在交战中死去。齐人随后拥立厉公之子赤，是为文公。文公诛杀参与杀厉公的七十人。齐国从这一年计算文公元年。 [[2]](#note-2)

**周宣王七年**

秦庄公接续父辈的西方战事；楚国开始计算熊徇的在位年次。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **秦庄公接续秦仲，和兄弟率周兵反击西戎。** 秦仲战死后，长子庄公接掌家族。宣王召来庄公兄弟五人，给他们七千兵，命他们出击西戎。兄弟击败西戎，秦仲的后人收回旧地，又取得祖先大骆所在的犬丘，庄公担任西垂大夫，住在西犬丘。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚国开始计算熊徇元年。** 楚君熊霜去世后，三个弟弟争位。仲雪死去，叔堪逃到濮地，最后由最小的弟弟季徇继位，也就是熊徇。楚国从这一年开始计算熊徇元年。 [[2]](#note-2)

## 归年与考证

<a id="sj005-009-note"></a>

### 秦庄公元年与西戎战事

卷014给出庄公元年；《秦本纪》连记调兵、破戎、授地与任官，未逐项系年。正文把这些放在庄公登场处交代，七千沿史书记数。见[卷005纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)。

<a id="sj014-0821-note"></a>
<a id="sj014-0821楚熊徇元年及继位背景"></a>

### 楚熊徇的纪年与继承

前827年列熊霜元年，按卷014年线，六年为前822年。熊徇元年列于前821年，世家未给争位各阶段的月日。

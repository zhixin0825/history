# 公元前822年｜秦仲在与西戎的战争中战死

[← 公元前823年](bce-0823.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前821年 →](bce-0821.md)

周宣王六年。秦仲死于与西戎的战争，晋国改用献侯籍的纪年。

<a id="reading-start"></a>

[本年相关史料](#sources-start) · [归年与考证](#appendix-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **秦仲在与西戎的战争中战死。** 宣王即位初年，曾命秦仲以大夫身份讨伐西戎。到秦仲在位第二十三年，他被西戎杀死。秦仲有五个儿子，长子是庄公。 [[1]](#note-1)

<a id="event-2"></a>

2. **晋国开始记献侯籍元年。** 晋釐侯司徒去世后，儿子籍继掌晋国，称献侯。晋国从本年起记献侯元年。 [[2]](#note-2)

---

<a id="sj040-xiongshuang-death-event"></a>

3. **熊霜去世，三个弟弟争位，季徇取得君位。** 仲雪在争夺中死去，叔堪逃往濮地避难，最小的季徇继位，称熊徇；下一年开始熊徇纪年。 [[3]](#sj040-xiongshuang-death-note)

### 秦仲死年与庄公元年

《秦本纪》说秦仲二十三年死于戎，《十二诸侯年表》前822年秦栏正为二十三年，下一行才列庄公元年。宣王调兵、庄公兄弟攻破西戎等后事见前821年条。[前822年年表行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0822) · [前821年庄公元年](bce-0821.md#event-1) · [卷005纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)

<a id="2晋献侯籍元年"></a>

### 晋釐侯之卒与献侯元年

《晋世家》说釐侯在位十八年而卒，年表前823年晋栏正是十八年。前822年起记子籍的元年。三家注读本的表格写作“晉獻公籍元年”，工作本和《晋世家》作“獻侯”，正文据后者。这里的籍与后来晋献公诡诸属于不同世代。[前823年年表行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0823) · [前822年年表行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0822) · [三家注表格](../../sources/史记三家注/卷014.md#p29)

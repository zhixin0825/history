# 公元前825年｜鲁武公与曹戴伯登场

[← 公元前826年](bce-0826.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前824年 →](bce-0824.md)

**本条据《史记》卷014《十二诸侯年表》的前825年行整理；周、鲁、各国分别纪年。** 本页只写底本有据的继承、婚姻或战争，不等于本年所有国家都已经考证完。

## 本年纪事

<a id="sj014-y0825"></a>
**鲁武公与曹戴伯登场。** 鲁国进入武公敖元年，曹国进入戴伯鮮元年。鲁武公后来入周朝见及继承争端有后续，不能把后来的冲突提前到本年。

<a id="sj013-lu-wugong"></a>
**鲁国这次由弟弟承接哥哥的君位：武公敖是前任真公的弟弟。** 这条亲属关系补足了两任鲁君之间的衔接，不是一位同名的“武公”又在共和元年另行即位。[原文与归年说明](#sj013-lu-wugong-note)

## 本年相关史料

<a id="note-1"></a>
### 1｜国别年表与归年界限

[《史记》卷014前825年原始年表行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0825) · [卷014有国别列的固定版](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98-%E5%8D%B7014.md#ref-17df2f96a6c6a8)。继位首年不是后来武公朝周的年份；后者在既有前816年条单列。 本项目按通行公元前年份对照年表的纪年行，未换算古历月日，也未把国别元年强定为国君死亡年月。

<a id="sj013-lu-wugong-note"></a>
### 2｜《三代世表》末行不是共和元年的同步名单

[卷013 T006鲁栏](../../sources/摘录/史记-卷013-三代世表.md#t006)在与“共和，二伯行政”并排的末格写“武公，真公弟”。该格提供亲属与承继信息，却不能单凭横向位置把武公元年改到前841年。当前沿卷014前825年的既有年次补入兄弟关系，保留原事件，不再制造一次即位；实际受位日、真公死亡日仍不由元年倒推。上古时期的王室与诸侯世系背景见[西周对读](../上古/07-西周的治理与危机.md#sj013-kingdoms)。

# 公元前825年｜鲁武公与曹戴伯登场

周宣王三年。鲁国改记武公元年，曹国也开始戴伯的纪年。

<a id="本年纪事"></a>

<a id="event-1"></a>
<a id="sj014-y0825"></a>

1. **曹国开始记戴伯元年。** 此前[苏杀曹幽伯并承位](bce-0826.md#sj035-cao-you-killed-event)，称戴伯。曹国从本年起记戴伯元年。 杀兄夺位者名苏；其新元年同时对应周宣王三年。 [[1]](#note-1)

<a id="event-2"></a>
<a id="sj013-lu-wugong"></a>

2. **鲁国开始记武公敖元年。** 鲁真公去世后，君位传给他的弟弟敖，称武公。鲁国从本年起用武公的纪年。 [[2]](#note-2)

---

<a id="sj032-wu-death-event"></a>

3. **齐武公去世，无忌继位为厉公。** 《齐太公世家》记武公二十六年卒；年表把本年列为武公二十六年，次年前824年才起厉公元年。死亡、承继与次年的纪元分别说明，不算两次更换国君。 [[3]](#sj032-wu-death-note)

## 归年与考证

<a id="1国别年表与归年界限"></a>

### 曹戴伯的名号

《十二诸侯年表》在周宣王三年列“曹戴伯鮮元年”，《管蔡世家》说杀幽伯的是其弟蘇，也把戴伯元年系于宣王初年。两段材料指向同一次交接，正文用谥号戴伯，名字异文保留在原文。世家记弑君在曹幽伯九年，年表前一行是曹幽伯九年、后一行才改记戴伯元年。[前825年年表行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0825) · [《管蔡世家》戴伯条](../../sources/本地分卷/史记/史记-卷035.md#L3302)

<a id="sj013-lu-wugong-note"></a>
<a id="2三代世表末行不是共和元年的同步名单"></a>

### 鲁武公元年与世表的栏次

《鲁周公世家》说真公三十年去世，《十二诸侯年表》前826年鲁栏仍为三十年，前825年改记武公敖元年。《三代世表》把“武公，真公弟”与“共和，二伯行政”排在同一横行，鲁栏在此可用来核对兄弟关系，武公元年仍按各国年表。武公后来朝周及由此发生的继承争议，见前816年条。[《三代世表》鲁栏](../../sources/本地分卷/史记/史记-卷013.md#L832) · [西周诸侯世系](../上古/07-西周的治理与危机.md#sj013-kingdoms) · [前816年鲁武公朝周](bce-0816.md)

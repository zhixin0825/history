# 公元前827年｜宣王起用秦仲，命他承担西方战事

[← 公元前828年](bce-0828.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前826年 →](bce-0826.md)

周宣王元年。王室让秦仲出兵西方，楚国则进入熊霜的第一个纪年。

<a id="reading-start"></a>

[本年相关史料](#sources-start) · [归年与考证](#appendix-start)

<a id="本年纪事"></a>

<a id="event-1"></a>

1. **宣王起用秦仲，命他讨伐西戎。** 此前，西戎背离周王室，灭了犬丘的大骆一族。宣王即位之初，任命秦仲为大夫，让他讨伐西戎。秦仲当时已主持本族多年，这次受命让他承担了王室在西方的战事。 [[1]](#note-1)

<a id="event-2"></a>

2. **楚国开始记熊霜元年。** 此前楚君熊严去世，由长子伯霜承继，称熊霜。他有三个弟弟，分别是仲雪、叔堪和季徇。楚国从本年起记熊霜元年。 [[2]](#note-2)

## 归年与考证

<a id="sj005-007-note"></a>
<a id="sj005-007宣王起用秦仲命他承担西方战事"></a>

### 秦仲受命的归年

《秦本纪》只说“周宣王即位，乃以秦仲為大夫”。《十二诸侯年表》在前828年共和十四年记宣王即位、共和结束，下一行前827年起记宣王元年。任命放在宣王元年条，取即位初期的阅读位置，具体年月存疑。秦仲在位二十三年而死于戎，另见前822年。[共和结束](bce-0828.md) · [秦仲之死](bce-0822.md#event-1) · [卷005纪年说明](../../meta/考证/史记-卷005-纪年与异说.md)

<a id="2楚熊霜元年"></a>

### 熊霜元年与熊严之卒

《楚世家》把“熊霜元年”与“周宣王初立”并述。年表在共和十四年仍记熊严十年，接下来周宣王元年、楚熊霜元年并列。这里用前827年记录熊霜纪年起算，熊严的具体卒日存疑。熊霜死后三弟争位，另见熊徇元年条。[前827年年表行](../../sources/摘录/史记-卷014-十二诸侯年表.md#y0827) · [熊徇元年](bce-0821.md#event-2)

<a id="sj032-declaration"></a>

### 宣王年次互见，不另计即位

本卷武公二十四年记宣王初立；本页是前827年元年，前828年已有承继主体。

**[《史记·齐太公世家》P014](../../sources/摘录/史记-卷032-齐太公世家.md#p014)**

> 二十四年，周宣王初立。

**[《十二诸侯年表》前827年原行·互校](../../sources/摘录/史记-卷032-互校原文.md#y0827)**

> 甲戌 宣王元年 二十九 二十四 十四 十八 楚熊霜元年 四 二十八 五 十一 八 三十八

**读法与异说：** 前827年是宣王元年；前828年厉王死后拥立与次年纪元分开。此条置背景，不再增一次即位。

# 公元前837年｜楚熊严、蔡夷侯分别开始纪年

[← 上一张已编年页：公元前838年](bce-0838.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元前835年 →](bce-0835.md)

**共和五年**

楚与蔡在各自的纪年中，分别开始计算新君的元年。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="本年纪事"></a>

<a id="sj014-y0837"></a>

<a id="event-1"></a>

1. **楚国从本年开始计算熊严元年。** 兄长熊勇已经去世，熊严承继君位；依年表十年与下一君元年的接续，卒事暂放在[前838年](bce-0838.md#sj040-xiongyong-death-event)，本篇共和年数的差异仍在同号注保留。 [[1]](#note-1)

<a id="event-2"></a>

2. **蔡国开始计算夷侯元年。** 蔡武侯死后，其子夷侯接掌蔡国。年表也从这一年列夷侯元年。 [[2]](#note-2)

## 归年与考证

<a id="1国别年表与归年界限"></a>

### 国别年表与归年界限

两国元年同在年表一行，具体继位日均无记载。《楚世家》把厉王出奔记在熊勇六年，卷014在共和元年列熊勇七年；两处对西周事件的同步有一年的差异。卷014本年所列熊严元年用于编年，《楚世家》补足兄弟承继，不由此重排厉王出奔的年次。

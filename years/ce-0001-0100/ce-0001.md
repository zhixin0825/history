# 公元1年｜越裳氏献白雉黑雉、赐王莽安汉公号

[← 公元前1年](../bce-0100-0001/bce-0001.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元2年 →](ce-0002.md)

**汉平帝元始元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **越裳氏献白雉黑雉。** 元始元年正月，本纪称越裳氏经多重翻译来献白雉一、黑雉二，命三公进荐宗庙。《通鉴》把来献同王莽营造周公比附相联系。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **赐王莽安汉公号。** 群臣称王莽功德可比周公，遂赐安汉公号并给孔光等加封。天下民赐爵一级，在位二百石以上的官吏按本秩给禄。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **恢复东平、中山两王国。** 立故东平王刘云的太子刘开明为东平王，立桃乡顷侯之子刘成都为中山王。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **赐爵宣帝后裔及迎立有功人员。** 封宣帝远孙刘信等三十六人为列侯，按功赐反对尊傅氏、参与定策迎立等人员爵邑，也赏平帝来京所经县官。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **调整侯王立嗣、宗室属籍和官吏禄制。** 准无子的王侯以孙或兄弟之子为嗣，侯嗣涉较重罪先请；恢复部分宗室属籍，另定廉佐史与高官致仕待遇。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **偿还三辅强征财物并保护义陵民墓。** 遣使查偿前一年仓卒强征的三辅财物，保留义陵不碍殿宇的民墓，并约束官舍储备器物。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **设羲和、外史和闾师。** 二月设置秩二千石的羲和及秩六百石的外史、闾师，颁行教化，禁止非礼祭祀，黜除郑声。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **义陵寝衣异动记录。** 乙未时义陵寝庙的神衣在匣中，丙申早晨发现移到匣外床上。寝令报告异常，朝廷以太牢祭祀。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **日食、大赦并求直言。** 五月丁巳朔，纪文记日食，朝廷大赦，命公卿、将军、中二千石各荐一名敦厚敢直言者。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **册拜卫姬与赏其亲属。** 六月，遣少傅左将军甄丰送给帝母卫姬玺书，拜为中山孝王后。舅父卫宝、卫玄获赐关内侯；本纪列四位帝妹称君，各食邑二千户，《外戚传》列三妹及封号。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **封周公、孔子后人。** 恢复周公、孔子的奉祀。《外戚恩泽侯表》载六月初封公子宽，本纪简书相如；相如承爵另见同年侯表。朝廷另封孔子后孔均为褒成侯，并追谥孔子为褒成宣尼公。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **停明光宫和三辅驰道。** 罢明光宫及三辅驰道，裁撤相关宫道设施或役用。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **女徒归家及设置劝农官。** 判刑女徒获准归家，按月缴纳顾山钱三百以代服役。每乡给一名贞妇以复除待遇。少府各设海丞、果丞一人，大司农设部丞十三人，分州劝农桑。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **以太皇太后邑租赈贫。** 太皇太后省去自己享用的十个汤沐邑县，交大司农单独核算租入，用以救济贫民。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **赦天下徒。** 秋九月赦天下服刑徒囚。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **以苦陉为卫后汤沐邑。** 以中山苦陉县供给中山孝王后的汤沐邑收入。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **朝廷分封诸王子为列侯。** 元始元年二月，东平、楚、淮阳等宗支的王子、王孙分受侯邑；各支、干支见同号表文。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **严乡侯信一支封爵后续。** 元始元年恢复侯爵。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **武平侯璜一支封爵后续。** 元始元年恢复侯爵，居摄二年举兵死亡。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **武安侯㥅一支封爵后续。** 元始元年恢复侯爵，八年免去侯爵。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **平阳侯曹本始｜增封。** 表载平阳侯曹本始一支本年获增食邑。表中所载事项为益满二千户。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **酂侯萧章｜增封。** 表载酂侯萧章一支本年获增食邑。表中所载事项为益封满二千户。 [[22]](#hs-note-22)

<a id="hs-event-23"></a>

23. **邔严侯黄极忠｜赐爵。** 表载邔严侯黄极忠一支本年另获赐爵。表中所载事项为赐极忠代後者敞爵关内侯。 [[23]](#hs-note-23)

<a id="hs-event-24"></a>

24. **弋阳节侯任宫｜承爵。** 表载弋阳节侯任宫一支本年记载侯位承袭。表中所载事项为侯固承爵。 [[24]](#hs-note-24)

<a id="hs-event-25"></a>

25. **都成敬侯金安上｜绍封。** 表载都成敬侯金安上一支本年接续了原有封爵。表中所载事项为侯钦因安上孙接续封爵。 [[25]](#hs-note-25)

<a id="hs-event-26"></a>

26. **都成敬侯金安上｜承爵。** 表载都成敬侯金安上一支本年记载侯位承袭。表中所载事项为戴侯杨承爵。 [[26]](#hs-note-26)

<a id="hs-event-27"></a>

27. **延乡节侯李谭｜承爵。** 表载延乡节侯李谭一支本年记载侯位承袭。表中所载事项为侯成承爵。 [[27]](#hs-note-27)

<a id="hs-event-28"></a>

28. **邛成共侯王奉光｜绍封。** 表载邛成共侯王奉光一支本年接续了原有封爵。表中所载事项为侯坚固因奉光曾孙接续封爵。 [[28]](#hs-note-28)

<a id="hs-event-29"></a>

29. **扶德侯马宫｜受封。** 表载扶德侯马宫一支本年有始封记载。表中所载事项为二月丙辰封。 [[29]](#hs-note-29)

<a id="hs-event-30"></a>

30. **扶平侯王崇｜受封。** 《汉书》侯籍列扶平侯王崇本年受封，所引月份、干支依表保留。 [[30]](#hs-note-30)

<a id="hs-event-31"></a>

31. **广阳侯甄丰｜受封。** 《汉书》侯籍列广阳侯甄丰本年受封，所引月份、干支依表保留。 [[31]](#hs-note-31)

<a id="hs-event-32"></a>

32. **承阳侯甄邯｜受封。** 《汉书》侯籍列承阳侯甄邯本年受封，所引月份、干支依表保留。 [[32]](#hs-note-32)

<a id="hs-event-33"></a>

33. **公孙相如承褒鲁侯。** 十一月，公孙相如接续公子宽的褒鲁侯爵。《平帝纪》将奉周公祀的授爵简书在相如名下。 [[33]](#hs-note-33)

<a id="hs-event-34"></a>

34. **设置太师和太保。** 平帝初置太师和太保，皆金印紫绶。 [[34]](#hs-note-34)

<a id="hs-event-35"></a>

35. **期门更名虎贲郎。** 期门改称虎贲郎，置中郎将，秩比二千石。 [[35]](#hs-note-35)

<a id="hs-event-36"></a>

36. **司寇更名护军。** 平帝更名护军。 [[36]](#hs-note-36)

<a id="hs-event-37"></a>

37. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[37]](#hs-note-37)

<a id="hs-event-38"></a>

38. **朔方广牧赵春传闻。** 《汉书》在本年记载朔方广牧赵春传闻。 [[38]](#hs-note-38)

<a id="hs-event-39"></a>

39. **长安双头婴儿的记述。** 《汉书》在本年记载长安双头婴儿的记述。 [[39]](#hs-note-39)

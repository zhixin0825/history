# 公元2年｜立广宗、广川和广德三王、霍光等功臣后裔恢复封爵

[← 公元1年](ce-0001.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元3年 →](ce-0003.md)

**汉平帝元始二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **黄支国献犀。** 元始二年春，本纪记黄支国进献犀牛。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **平帝改名。** 诏称皇帝旧有两字名与事物用语相通，故改为符合所引古制的单字名，派太师孔光以太牢告高庙。原名箕子，改名衎见《通鉴》与《王莽传》。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **立广宗、广川和广德三王。** 元始二年四月立刘如意为广宗王、刘宫为广川王、刘伦为广德王。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **霍光等功臣后裔恢复封爵。** 霍阳、张庆忌、周共、樊章恢复列侯；郦商等功臣的后代共一百一十三人获关内侯爵与食邑。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **旱蝗疫灾与施赈。** 青州等地旱蝗，遣人捕蝗、奖励交蝗，分配捐献田宅，按条件免税；疫病患者安置诊治，重丧之家获给葬钱。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **置安民县并安置贫民。** 罢安定呼池苑置安民县，募徙贫民，给田宅及器具，借牛犁、种粮；在长安城建五里、二百所住宅供贫民居住。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **荐勇武知兵者。** 秋，各郡荐一名勇武有节且通兵法者到公车署。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **秋九月日食及赦徒。** 九月戊申晦，纪文记日食，朝廷赦天下徒囚。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **使四十四人持节巡边。** 遣谒者与大司马掾等共四十四人持节巡视边军。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **陈茂招抚江湖盗众。** 执金吾候陈茂携钲鼓，招汝南、南阳勇敢吏士三百人，招抚成重等二百余人出降，将其家送当地处置；成重迁云阳，获赐公家田宅。 萧由本传又称他在任江夏太守时平定成重等有功。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **岁荐治狱平允者。** 冬，令中二千石官每年荐一名审理案件公允的人。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **朝廷分封诸王子为列侯。** 二年四月丁酉封。王子封邑见同号《王子侯表》各条。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **曲逆献侯陈平｜赐爵。** 表载曲逆献侯陈平一支本年另获赐爵。表中所载事项为下诏赐予平代後者凤爵关内获封，不言世。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **临辕坚侯戚鳃｜赐爵。** 表载临辕坚侯戚鳃一支本年另获赐爵。表中所载事项为鳃玄孙之孙少下诏赐予爵关内侯。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **范阳靖侯范代｜赐爵。** 表载范阳靖侯范代一支本年另获赐爵。表中所载事项为玄孙政下诏赐予爵关内侯。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **建平敬侯杜延年｜承爵。** 表载建平敬侯杜延年一支本年记载侯位承袭。表中所载事项为侯辅承爵。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **博阳定侯丙吉｜承爵。** 表载博阳定侯丙吉一支本年记载侯位承袭。表中所载事项为厘侯并承爵。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 扶平侯王崇称病免大司空，就侯国。 光禄大夫孙宝升任大司农。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **元始二年大范围蝗灾。** 《汉书》在本年记载元始二年大范围蝗灾。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **巨鹿坠陨石二。** 《汉书》在本年记载巨鹿坠陨石二。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **元始二年《地理志》所载户口。** 《地理志》在京兆尹条首标元始二年。这里据该口径合读各郡国户口，并保留各数与志末总数；郡县置立、县名和风俗材料有各自时间层次。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **龚胜、邴汉优礼致仕。** 元始二年六月，太皇太后采韩福旧例，让龚胜、邴汉以老病退休并授其所举亲属郎官，给归途及乡里优养之礼。 [[22]](#hs-note-22)

<a id="hs-event-23"></a>

23. **孙宝反对援周公颂王莽。** 越嶲报告黄龙，群臣欲把王莽比周公而告宗庙，孙宝提出反对，甄邯停止议论。不久孙宝另因母亲病中被留在弟家一事获罪，免官。 [[23]](#hs-note-23)

<a id="hs-event-24"></a>

24. **须卜居次云应王莽之请入侍太后。** 王莽意在表明太后威德，托人示意单于遣王昭君之女须卜居次云入侍，太后厚赏。 [[24]](#hs-note-24)

<a id="hs-event-25"></a>

25. **车师后王姑句与去胡来王唐兜降匈奴，被送还处死。** 车师后王与去胡来王逃往匈奴，乌珠留收纳并告汉。王莽遣韩隆等交涉，单于交回两王并为之求赦，朝廷拒绝后集诸国王处死两人。 [[25]](#hs-note-25)

<a id="hs-event-26"></a>

26. **汉颁匈奴不得受降四条。** 王莽在两王案后令使者通知单于，不得收纳汉人、乌孙人、佩汉印绶的西域国人和乌桓降人，收回宣帝旧约的封函。 [[26]](#hs-note-26)

<a id="hs-event-27"></a>

27. **乌珠留单于应王莽之意改名为知。** 王莽主张不用二名，使者示意单于从之。囊知牙斯自请改名为“知”，汉太后遣使褒赏。 [[27]](#hs-note-27)

### 6. 置安民县并安置贫民

[返回正文第6条](#hs-event-6)

### 25. 车师后王姑句与去胡来王唐兜降匈奴，被送还处死

[返回正文第25条](#hs-event-25)

<a id="hs094-l9877-e25"></a>

**[《汉书·匈奴传》P119](../../sources/摘录/汉书-卷094-匈奴传.md#p119)** · [仓内TXT L9877](../../sources/本地分卷/汉书/汉书-卷094.md#L9877)

> 會西域車師後王句姑、去胡來王唐兜皆怨恨都護校尉，將妻子人民亡降匈奴，語在西域傳。單于受置左谷蠡地，遣使上書言狀曰：「臣謹已受。」詔書中郎將韓隆、王昌、副校尉甄阜、侍中謁者帛敞、長水校尉王歙使匈奴，告單于曰：「西域內屬，不當得受，今遣之。」單于曰：「孝宣、孝元皇帝哀憐，為作約束，自長城以南天子有之，長城以北單于有之。有犯塞，輒以狀聞；有降者，不得受。臣知父呼韓邪單于蒙無量之恩，死遺言曰：『有從中國來降者，勿受，輒送至塞，以報天子厚恩。』此外國也，得受之。」使者曰：「匈奴骨肉相攻，國幾絕，蒙中國大恩，危亡復續，妻子完安，累世相繼，宜有以報厚恩。」單于叩頭謝罪，執二虜還付使者。詔使中郎將王萌待西域惡都奴界上逆受。單于遣使送到國，因請其罪。使者以聞，有詔不聽，會西域諸國王斬以示之。

**互校说明** 《通鉴》卷三十五系元始二年，本传名“句姑”，《西域传》及《通鉴》次序“姑句”。

<a id="hs096-l10109-e25"></a>

**[《汉书·西域传》P161](../../sources/摘录/汉书-卷096-西域传.md#p161)** · [仓内TXT L10109](../../sources/本地分卷/汉书/汉书-卷096.md#L10109)

> 元始中，車師後王國有新道，出五船北，通玉門關，往來差近，戊己校尉徐普欲開以省道裡半，避白龍堆之厄。車師後王姑句以道當為拄置，心不便也。地又頗與匈奴南將軍地接，曾欲分明其界然後奏之，召姑句使證之，不肯，系之。姑句數以牛羊賕吏，求出不得。姑句家矛端生火，其妻股紫陬謂姑句曰：「矛端生火，此兵氣也，利以用兵。前車師前王為都護司馬所殺，今久系必死，不如降匈奴。」即馳突出高昌壁，入匈奴。

**互校说明** 《通鉴》卷035系元始二年；徐普与前车师王旧事为前情。

<a id="hs096-l10110-e25"></a>

**[《汉书·西域传》P162](../../sources/摘录/汉书-卷096-西域传.md#p162)** · [仓内TXT L10110](../../sources/本地分卷/汉书/汉书-卷096.md#L10110)

> 又去胡來王唐兜，國比大種赤水羌，數相冠，不勝，告急都護。都護但欽不以時救助，唐兜困急，怨欽，東守玉門關。玉門關不內，即將妻子人民千餘人亡降匈奴。匈奴受之，而遣使上書言狀。是時，新都侯王莽秉政，遣中郎將王昌等使匈奴，告單于西域內屬，不當得受。單于謝屬。執二王以付使者。莽使中郎王萌待西域惡都奴界上逢受。單于遣使送，因請其罪。使者以聞，莽不聽，詔下會西域諸國王，陳軍斬姑句、唐兜以示之。

**互校说明** 《通鉴》卷035所载谕使作韩隆等，本传作王昌等；王萌受人两载相同。

<a id="hs-note-26"></a>

### 26. 汉颁匈奴不得受降四条

[返回正文第26条](#hs-event-26)

<a id="hs094-l9877-e26"></a>

**[《汉书·匈奴传》P119](../../sources/摘录/汉书-卷094-匈奴传.md#p119)** · [仓内TXT L9877](../../sources/本地分卷/汉书/汉书-卷094.md#L9877)

> 乃造設四條：中國人亡入匈奴者，烏孫亡降匈奴者，西域諸國佩中國印綬降匈奴者，烏桓降匈奴者，皆不得受。遣中郎將王駿、王昌、副校尉甄阜、王尋使匈奴，班四條與單于，雜函封，付單于，令奉行，因收故宣帝所為約束封函還。

**互校说明** 《通鉴》卷三十五元始二年；与同年双王案连续，规定内容为另一制度条。

<a id="hs-note-27"></a>

### 27. 乌珠留单于应王莽之意改名为知

[返回正文第27条](#hs-event-27)

<a id="hs094-l9877-e27"></a>

**[《汉书·匈奴传》P119](../../sources/摘录/汉书-卷094-匈奴传.md#p119)** · [仓内TXT L9877](../../sources/本地分卷/汉书/汉书-卷094.md#L9877)

> 時，莽奏令中國不得有二名，因使使者以風單于，宜上書慕化，為一名，漢必加厚賞。單于從之，上書言：「幸得備藩臣，竊樂太平聖制，臣故名囊知牙斯，今謹更名曰知。」莽大說，白太后，遣使者答諭，厚賞賜焉。

**互校说明** 更名与四条连叙，《通鉴》同系元始二年。

1. **修定郊祀与宗庙，改殷周后人封号。** 正月郊祀配祭高祖，宗祀配祭文帝。奉殷后祭祀的殷绍嘉公改称宋公，奉周后祭祀的周承休公改称郑公。王莽奏立明堂、辟雍，定宣帝庙为中宗、元帝庙为高宗，天子世代祭献。朝廷另命各地奉祀有益于民的已故官员，蜀郡奉文翁，九江、南阳奉召信臣。 [[1]](#hs-note-1)

<a id="hs-event-4"></a>

2. **限制拘系犯罪人家属。** 诏重申归女徒、复贞妇的施政理由。妇女自身未犯法及八十岁以上、七岁以下男子，家人非坐不道且未经诏名捕，不得因亲属涉案而拘系；确需核验者就地查问，并明定为令。 [[2]](#hs-note-4)

<a id="hs-event-5"></a>

<a id="hs-event-7"></a>

<a id="hs-event-8"></a>

3. **平帝立王氏为皇后，王莽进号宰衡。** 二月丁未，立王莽女王氏为皇后，大赦。朝廷按等差赐九卿至六百石官员及宗室爵，天下平民各进爵一级，鳏寡孤独和老人赐帛。夏，皇后谒高庙，王莽加宰衡之号，母亲称功显君，王安、王临封列侯。 [[3]](#hs-note-5)

<a id="hs-event-6"></a>

4. **王恽等持节巡行。** 遣太仆王恽等八人设副使、持节分行各地，考察风俗。 [[4]](#hs-note-6)

<a id="hs-event-10"></a>

5. **置西海郡并迁犯禁者。** 汉朝在西羌内附后置西海郡，并将犯禁者迁往当地。 [[5]](#hs-note-10)

<a id="hs-event-11"></a>

6. **梁王刘立自杀。** 梁王刘立因与平帝外家卫氏往来而获罪，被废为庶人、徙汉中，随后自杀。 [[6]](#hs-note-11)

<a id="hs-event-12"></a>

<a id="hs-event-23"></a>

<a id="hs-event-24"></a>

<a id="hs-event-25"></a>

7. **重分京畿并厘定朝廷官制。** 朝廷在京师分置前煇光、后丞烈二郡，重定公卿大夫和八十一元士的名号、位次及十二州州名，重划郡国隶属。宗正改称宗伯，长信少府改称长乐少府。变动繁多，官吏难以周记。 [[7]](#hs-note-12)

<a id="hs-event-13"></a>

8. **长安东门受大风损坏。** 冬，大风几乎吹尽长安城东门屋瓦。 [[8]](#hs-note-13)

9. **功臣、朝臣后人承袭与恢复封爵。** 金常以金日磾曾孙绍封秺侯，食邑千户。傅长以傅介子曾孙绍封义阳侯，衞赏以衞青玄孙获关内侯爵，史岑以史高曾孙绍封乐陵侯。王述承平阿侯，王柱承红阳侯。何武去年因吕宽案被征后自杀，本年其子何况承氾乡侯。王崇绍新甫侯。彭宣辞官就国数年后去世，谥顷，节侯圣承长平侯。 [[9]](#hs-note-14)

### 5. 置西海郡并迁犯禁者

[返回正文第5条](#hs-event-10)

**互校** 《平帝纪》系元始四年，《王莽传》叙次在次年秋；《通鉴考异》从纪。

<a id="hs099-l10366-e10"></a>

**[《汉书·王莽传》P050](../../sources/摘录/汉书-卷099-王莽传.md#p050)** · [仓内TXT L10366](../../sources/本地分卷/汉书/汉书-卷099.md#L10366)

> 莽既致太平，北化匈奴，東致海外，南懷黃支，唯西方未有加。乃遣中郎將平憲等多持金幣誘塞外羌，使獻地，願內屬。憲等奏言：「羌豪良願等種，人口可萬二千人，願為內臣，獻鮮水海、允谷鹽池，平地美草皆予漢民，自居險阻處為藩蔽。問良願降意，對曰：『太皇太后聖明，安漢公至仁，天下太平，五穀成孰，或禾長丈餘，或一粟三米，或不種自生，或嘤不蠶自成，甘露從天下，醴泉自地出，鳳皇來儀，神爵降集。從四歲以來，羌人無所疾苦，故思樂內屬。』宜以時處業，置屬國領護。」事下莽，莽復奏曰：「太后秉統數年，恩澤洋溢，和氣四塞，絕域殊俗，靡不慕義。越裳氏重譯獻白雉，黃支自三萬里貢生犀，東夷王度大海奉國珍，匈奴單于順制作，去二名，今西域良願等復舉地為臣妾，昔唐堯橫被四表，亦亡以加之。今謹案已有東海、南海、北海郡，未有西海郡，請受良願等所獻地為西海郡。臣又聞聖王序天文，定地理，因山川民俗以制州界。漢家地廣二帝三王，凡十三州，州名及界多不應經。堯典十有二州界，後定為九州。漢家廓地遼遠，州牧行部，遠者三萬餘里，不可為九。謹以經義正十二州名分界，以應正始。」奏可。又增法五十條，犯者徙之西海。徙者以千萬數，民始怨矣。

**互校说明** 《平帝纪》系元始四年，本传接五年；《通鉴考异》取本纪，同一置郡。

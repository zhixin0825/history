# 公元4年｜以高祖文帝配祭、殷绍嘉公改宋公

[← 公元3年](ce-0003.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元5年 →](ce-0005.md)

**汉平帝元始四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **以高祖文帝配祭。** 元始四年正月，行郊祀配祭高祖，行宗祀配祭孝文帝。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **殷绍嘉公改宋公。** 《平帝纪》把殷绍嘉公改宋公系元始四年。《恩泽侯表》孔何齐条则系元始二年。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **周承休公改郑公。** 周承休公改称郑公。《恩泽侯表》亦系元始四年。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **限制拘系犯罪人家属。** 诏重申归女徒、复贞妇的施政理由。妇女自身未犯法及八十岁以上、七岁以下男子，家人非坐不道且未经诏名捕，不得因亲属涉案而拘系；确需核验者就地查问，并明定为令。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **王氏立后、大赦。** 二月丁未，立王莽之女王氏为皇后，并大赦天下。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **王恽等持节巡行。** 遣太仆王恽等八人设副使、持节分行各地，考察风俗。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **赐宗室百姓爵帛。** 按等差赐九卿至六百石官员及有属籍的宗室爵，天下平民各赐爵一级，鳏寡孤独和老人赐帛。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **皇后谒高庙、王莽进号宰衡。** 夏，皇后谒高庙，安汉公王莽加宰衡之号，他的母亲称功显君，儿子王安、王临封列侯。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **议立明堂辟雍与定宗庙称号。** 王莽奏建立明堂、辟雍，尊宣帝庙为中宗、元帝庙为高宗，天子世代祭献。次年另见明堂实际合祭。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **置西海郡并迁犯禁者。** 本纪记设西海郡并迁犯禁者前往。《王莽传》将设置列于次年秋，《通鉴考异》从《平帝纪》。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **梁王刘立自杀。** 梁王刘立获罪自杀。《诸侯王表》将获罪废徙及自杀接书于元始三年，《通鉴》据本纪将自杀记四年；年页并注，下一年由刘音续封。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **重分京畿并变更官制区划。** 分京师置前煇光、后丞烈二郡，重改公卿大夫和八十一元士的名号、位次及十二州州名，重划郡国隶属。事多变动，官吏难以周记。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **长安东门受大风损坏。** 冬，大风几乎吹尽长安城东门屋瓦。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **秺敬侯金日磾｜绍封。** 表载秺敬侯金日磾一支本年接续了原有封爵。表中所载事项为侯常因日磾曾孙接续侯爵，千户。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **义阳侯傅介子｜绍封。** 表载义阳侯傅介子一支本年接续了原有封爵。表中所载事项为侯长因介子曾孙接续封爵。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **长平烈侯衞青｜赐爵。** 表载长平烈侯衞青一支本年另获赐爵。表中所载事项为赐青玄孙赏爵关内侯。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **乐陵安侯史高｜绍封。** 表载乐陵安侯史高一支本年接续了原有封爵。表中所载事项为侯岑因高曾孙接续封爵。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **平阿安侯王谭｜承爵。** 表载平阿安侯王谭一支本年记载侯位承袭。表中所载事项为侯述承爵。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **红阳荒侯王立｜承爵。** 表载红阳荒侯王立一支本年记载侯位承袭。表中所载事项为侯柱承爵。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **泛乡侯何武｜承爵。** 表载泛乡侯何武一支本年记载侯位承袭。表中所载事项为侯况承爵。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **新甫侯王嘉｜绍封。** 表载新甫侯王嘉一支本年接续了原有封爵。表中所载事项为侯崇接续封爵。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **长平顷侯彭宣｜承爵。** 表载长平顷侯彭宣一支本年记载侯位承袭。表中所载事项为节侯圣承爵。 [[22]](#hs-note-22)

<a id="hs-event-23"></a>

23. **宗正改称宗伯。** 平帝更名宗正为宗伯。 [[23]](#hs-note-23)

<a id="hs-event-24"></a>

24. **长信少府改称长乐少府。** 平帝更名长信少府为长乐少府。 [[24]](#hs-note-24)

<a id="hs-event-25"></a>

25. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[25]](#hs-note-25)

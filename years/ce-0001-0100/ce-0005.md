# 公元5年｜明堂祫祭及助祭人员受赏、太后诏置宗师

[← 公元4年](ce-0004.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元6年 →](ce-0006.md)

**汉平帝元始五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **明堂祫祭及助祭人员受赏。** 元始五年正月在明堂合祭，召诸侯王二十八、列侯一百二十及宗室子九百余人助祭。礼毕按等差增户、赐爵与金帛、增秩或补官。 曾徵萧由为大鸿胪参与朝会赞礼，萧由因病未及。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **太后诏置宗师。** 太后以平帝年幼、宗族人口众多为由下诏分明各代族氏，命郡国二千石择有德义者为宗师，劝教、监察宗室。违令或有冤屈者，宗师可经邮亭报告宗伯上闻；每年正月赐宗师帛各十匹。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **建礼制及巡风俗使者封侯。** 羲和刘歆等四人办理明堂、辟雍，以比附文王灵台和周公营洛；太仆王恽等八人巡察风俗，宣传教化。两组受任人员皆封列侯。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **征召熟悉经术技艺之士。** 征通逸经、古籍、天文、历算、音律、文字、史篇、方术、本草及教授《五经》《论语》《孝经》《尔雅》者，地方给轻车驿传送到京师，到者数千人。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **刘音绍封梁王。** 本纪记闰月立梁孝王远孙刘音为梁王；《诸侯王表》作同年二月丁酉，保留月次异说。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **平帝死于未央宫。** 《平帝纪》系元始五年古十二月丙午。古历年界与现代公历不同；《通鉴》另载王莽以椒酒下毒，死因须按来源区分。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **平帝崩后大赦。** 平帝崩后朝廷大赦。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **平帝加元服入殓并葬康陵。** 礼官请依礼给年十四岁的皇帝加元服入殓，获准，葬康陵。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **诏令平帝媵妾归家。** 诏以平帝病发气逆、无法言语说明没有遗诏，准其媵妾归家改嫁。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **朝廷分封诸王子为列侯。** 五年闰月丁酉封。王子封邑见同号《王子侯表》各条。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **随桃顷侯赵光｜绍封。** 表载随桃顷侯赵光一支本年接续了原有封爵。表中所载事项为放因光玄孙接续封爵，千户。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **合阳爱侯梁喜｜绍封。** 表载合阳爱侯梁喜一支本年接续了原有封爵。表中所载事项为侯萌因喜孙接续封爵，千户。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **信成侯王定｜绍封。** 表载信成侯王定一支本年接续了原有封爵。表中所载事项为侯杨因定孙接续封爵，千户。 [[13]](#hs-note-13)

<a id="hs-event-14"></a>

14. **童乡厘侯锺祖｜绍封。** 表载童乡厘侯锺祖一支本年接续了原有封爵。表中所载事项为侯匡因祖子接续封爵。 [[14]](#hs-note-14)

<a id="hs-event-15"></a>

15. **爰氏肃侯便乐成｜绍封。** 表载爰氏肃侯便乐成一支本年接续了原有封爵。表中所载事项为闰月丁酉，侯凤因乐成曾孙接续封爵，千户。 [[15]](#hs-note-15)

<a id="hs-event-16"></a>

16. **安平夷侯王舜｜承爵。** 表载安平夷侯王舜一支本年记载侯位承袭。表中所载事项为怀侯买承爵。 [[16]](#hs-note-16)

<a id="hs-event-17"></a>

17. **博山简烈侯孔光｜承爵。** 表载博山简烈侯孔光一支本年记载侯位承袭。表中所载事项为侯放承爵。 太师孔光本年去世，谥简烈侯；王莽请用特等丧礼，公卿会吊送葬。 [[17]](#hs-note-17)

<a id="hs-event-18"></a>

18. **成武侯孙建｜受封。** 《汉书》侯籍列成武侯孙建本年受封，所引月份、干支依表保留。 [[18]](#hs-note-18)

<a id="hs-event-19"></a>

19. **明统侯侯辅｜受封。** 《汉书》侯籍列明统侯侯辅本年受封，所引月份、干支依表保留。 [[19]](#hs-note-19)

<a id="hs-event-20"></a>

20. **陈冯、杜勋因讨郅支旧功获封。** 王莽主政时追赏西汉元帝朝讨郅支之功：陈汤之子陈冯封破胡侯，杜勋封讨狄侯。《恩泽侯表》各书七月丙申，承同段元始五年的年次；《陈汤传》又同段追叙尊元帝庙为高宗，后者在元始四年。追封年随侯表阅读，不能把战事重排到平帝朝。 [[20]](#hs-note-20)

<a id="hs-event-21"></a>

21. **百官公卿表所记官历。** 本年任免、迁转及官历见下列各栏原文；格中任职年数和任官后的卒免不作本年新事。 [[21]](#hs-note-21)

<a id="hs-event-22"></a>

22. **平帝元始五年复长安郊祀。** 本志明系平帝元始五年，王莽议复南北郊；下段合祀、分祀的礼制同时阅读。 [[22]](#hs-note-22)

<a id="hs-event-23"></a>

23. **高帝原庙殿门火灾。** 《汉书》在本年记载高帝原庙殿门火灾。 [[23]](#hs-note-23)

<a id="hs-event-24"></a>

24. **王莽发傅、丁二冢改葬，拆恭皇庙。** 王莽奏发傅太后和丁太后旧冢，夺玺绶，以庶人礼改葬，并拆毁定陶恭皇庙。此前建议定尊号的泠褒、段犹被徙合浦；马宫因参与议谥而辞官，见[本年第25条](#hs-event-25)。 [[24]](#hs-note-24)

<a id="hs-event-25"></a>

25. **马宫因傅太后旧谥议去官。** 马宫因曾迎合哀帝朝议尊傅太后，又经王莽治旧议，主动乞退。太后许交太师和大司徒印绶，仍保扶德侯。 [[25]](#hs-note-25)

<a id="hs-event-26"></a>

26. **朝廷议定并赐王莽九锡。** 张纯等请依周公旧例给王莽九锡。五月庚寅，王政君于前殿授策，赐礼服车马、弓矢斧钺、秬鬯玉圭等。 [[26]](#hs-note-26)

<a id="hs-event-27"></a>

27. **王莽修通子午道。** 王莽以皇后将有子的祥说为由，秋天开通从杜陵越南山往汉中的子午道。 [[27]](#hs-note-27)

<a id="hs-event-28"></a>

28. **刘庆请让王莽行天子事。** 泉陵侯刘庆以周公辅幼主为例，请安汉公代理天子事，群臣响应。 [[28]](#hs-note-28)

<a id="hs-event-29"></a>

29. **记荧惑入月。** 传记冬季出现荧惑与月相近或相掩的天象，并存古书用语。 [[29]](#hs-note-29)

<a id="hs-event-30"></a>

30. **谢嚣献白石符命。** 谢嚣奏武功掘井得刻有劝进文字的白石。太后不信，王舜等以无法阻止为由劝姑且允许。 [[30]](#hs-note-30)

### 2. 太后诏置宗师

[返回正文第2条](#hs-event-2)

<a id="hs012-l1086-e2"></a>

**[《汉书·平帝纪》P042](../../sources/摘录/汉书-卷012-平帝纪.md#p042)** · [仓内TXT L1086](../../sources/本地分卷/汉书/汉书-卷012.md#L1086)

> 詔曰：「蓋聞帝王以德撫民，其次親親以相及也。昔堯睦九族，舜惇敘之。朕以皇帝幼年，且統國政，惟宗室子皆太祖高皇帝子孫及兄弟吳頃、楚元之後，漢元至今，十有餘萬人，雖有王侯之屬，莫能相糾，或陷入刑罪，教訓不至之咎也。傳不云乎？『君子篤於親，則民興於仁。』其為宗室自太上皇以來族親，各以世氏，郡國置宗師以糾之，致教訓焉。二千石選有德義者以為宗師。考察不從教令有冤失職者，宗師得因郵亭書言宗伯，請以聞。常以歲正月賜宗師帛各十匹。」

### 4. 征召熟悉经术技艺之士

[返回正文第4条](#hs-event-4)

<a id="hs099-l10358-e4"></a>

**[《汉书·王莽传》P042](../../sources/摘录/汉书-卷099-王莽传.md#p042)** · [仓内TXT L10358](../../sources/本地分卷/汉书/汉书-卷099.md#L10358)

> 立樂經，益博士員，經各五人。徵天下通一藝教授十一人以上，及有逸禮、古書、毛詩、周官、爾雅、天文、圖讖、鍾律、月令、兵法、史篇文字，通知其意者，皆詣公車。網羅天下異能之士，至者前後千數，皆令記說廷中，將令正乖繆，壹異說云。羣臣奏言：「昔周公奉繼體之嗣，據上公之尊，然猶七年制度乃定。夫明堂、辟雍，墮廢千載莫能興，今安漢公起于第家，輔翼陛下，四年于茲，功德爛然。公以八月載生魄庚子奉使，朝用書臨賦營築，越若翊辛丑，諸生、庶民大和會，十萬眾並集，平作二旬，大功畢成。唐虞發舉，成周造業，誠亡以加。宰衡位宜在諸侯王上，賜以束帛加璧，大國乘車、安車各一，驪馬二駟。」詔曰：「可。其議九錫之法。」

**互校说明** 从《平帝纪》元始五年征通经方技等；本传系制度设立及征集相承。

<a id="hs088-l9543-e4"></a>

### 30. 谢嚣献白石符命

[返回正文第30条](#hs-event-30)

<a id="hs099-l10370-e30"></a>

**[《汉书·王莽传》P054](../../sources/摘录/汉书-卷099-王莽传.md#p054)** · [仓内TXT L10370](../../sources/本地分卷/汉书/汉书-卷099.md#L10370)

> 是月，前煇光謝囂奏武功長孟通浚井得白石，上圓下方，有丹書著石，文曰「告安漢公莽為皇帝」。符命之起，自此始矣。莽使羣公以白太后，太后曰：「此誣罔天下，不可施行！」太保舜謂太后：「事已如此，無可奈何，沮之力不能止。又莽非敢有它，但欲稱攝以重其權，填服天下耳。」太后聽許，舜等即共令太后下詔曰：「蓋聞天生眾民，不能相治，為之立君以統理之。君年幼稚，必有寄託而居攝焉，然後能奉天施而成地化，羣生茂育。書不云乎？『天工，人其代之。』朕以孝平皇帝幼年，且統國政，幾加元服，委政而屬之。今短命而崩，嗚呼哀哉！已使有司徵孝宣皇帝玄孫二十三人，差度宜者，以嗣孝平皇帝之後。玄孫年在繈褓，不得至德君子，孰能安之？安漢公莽輔政三世，比遭際會，安光漢室，遂同殊風，至于制作，與周公異世同符。今前煇光囂、武功長通上言丹石之符，朕深思厥意，云『為皇帝』者，乃攝行皇帝之事也。夫有法成易，非聖人者亡法。其令安漢公居攝踐祚，如周公故事，以武功縣為安漢公采地，名曰漢光邑。具禮儀奏。」

**互校说明** 本传系平帝死的同月；王政君驳，甄邯等继续议居摄。

**孺子婴时期居摄元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **刘赤嗣广德王。** 刘赤嗣广德王。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **刘匡为东平王。** 刘匡为东平王。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **安衆康侯丹一支后事。** 居摄元年举兵，为王莽所灭。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **王莽立刘婴为孺子。** 平帝无子，王莽立广戚侯刘勋之孙、刘显之子刘婴为孺子。王莽代汉后[降刘婴为定安公](ce-0009.md#hs080-l9120-e4)；更始年间刘婴[在临泾被杀](ce-0025.md#hs080-l9120-e1)。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **成安严侯郭忠｜绍封。** 表载成安严侯郭忠一支本年接续了原有封爵。表中所载事项为侯每因忠玄孙之子接续封爵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **安远缪侯郑吉｜绍封。** 表载安远缪侯郑吉一支本年接续了原有封爵。表中所载事项为侯永因吉曾孙接续封爵，千户。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **阳城缪侯刘德｜承爵。** 表载阳城缪侯刘德一支本年记载侯位承袭。表中所载事项为侯飒承爵。 [[7]](#hs-note-7)

### 4. 王莽立刘婴为孺子

[返回正文第4条](#hs-event-4)

<a id="hs080-l9120-e4"></a>

**[《汉书·宣元六王传》P015](../../sources/摘录/汉书-卷080-宣元六王传.md#p015)** · [仓内TXT L9120](../../sources/本地分卷/汉书/汉书-卷080.md#L9120)

**互校说明** 平帝死于元始五年十二月，刘婴为孺子依侯表居摄元年；后被降及被杀分别入相应年。

**互校说明** 平帝去世见元始五年，居摄改元与立孺子见居摄元年。本传从翟义任东郡数岁跨年接叙。

**互校说明** 志接平帝元始五年总结，另以《通鉴》及《王莽传》定居摄元年，未称刘婴已即皇帝位。

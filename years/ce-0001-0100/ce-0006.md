# 公元6年｜刘赤嗣广德王

[← 公元5年](ce-0005.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元7年 →](ce-0007.md)

**孺子婴时期居摄元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **刘赤嗣广德王。** 刘赤嗣广德王。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **刘匡为东平王。** 刘匡为东平王。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **安众侯刘崇与张绍举兵。** 居摄元年四月，安众侯刘崇与国相张绍率宗族攻宛，未能入城，起兵失败。《王子侯表》在安众侯刘丹一系下记此事。《王莽传》又记张竦为刘嘉作奏后，受封淑德侯。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **王莽立刘婴为孺子。** 平帝无子，王莽立广戚侯刘勋之孙、刘显之子刘婴为孺子。王莽代汉后[降刘婴为定安公](ce-0009.md#hs080-l9120-e4)；更始年间刘婴[在临泾被杀](ce-0025.md#hs080-l9120-e1)。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **成安严侯郭忠｜绍封。** 表载成安严侯郭忠一支本年接续了原有封爵。表中所载事项为侯每因忠玄孙之子接续封爵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **安远缪侯郑吉｜绍封。** 表载安远缪侯郑吉一支本年接续了原有封爵。表中所载事项为侯永因吉曾孙接续封爵，千户。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **阳城缪侯刘德｜承爵。** 表载阳城缪侯刘德一支本年记载侯位承袭。表中所载事项为侯飒承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **王莽受摄政礼。** 群臣援周公故事把摄政说成保全宗庙，规定用天子仪礼而在太后、孺子前自称臣的办法。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **王莽代行郊祀等礼，设柱下五史。** 王莽代行南郊、迎春、大射、养三老五更诸礼，并置五史侍记言行。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **十月朔日食。** 传明书十月丙辰朔日食。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **增设摄政宫府属官卫士。** 请增摄政宫府的率更、庙厩厨官、属员和卫士，并改名摄省、摄殿、摄宫，奏获允。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **追赏参与制度和边事的辅臣。** 王莽借太后诏录孔光、王舜、甄丰、甄邯、孙建等的礼制与边政之功，推恩及子弟。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **西海羌起兵，王莽遣窦况。** 庞恬、傅幡等怨设西海郡而攻太守程永，永逃走被诛，王莽遣窦况讨伐。 [[13]](#hs-note-13)

> 於是羣臣奏言：「太后聖德昭然，深見天意，詔令安漢公居攝。臣聞周成王幼少，周道未成，成王不能共事天地，修文武之烈。周公權而居攝，則周道成，王室安；不居攝，則恐周隊失天命。書曰：『我嗣事子孫，大不克共上下，遏失前人光，在家不知命不易。天應棐諶，乃亡隊命。』說曰：周公服天子之冕，南面而朝羣臣，發號施令，常稱王命。召公賢人，不知聖人之意，故不說也。禮明堂記曰：『周公朝諸侯於明堂，天子負斧依南面而立。』謂『周公踐天子位，六年朝諸侯，制禮作樂，而天下大服』也。召公不說。時武王崩，縗麤未除。由是言之，周公始攝則居天子之位，非乃六年而踐阼也。書逸嘉禾篇曰：『周公奉鬯立于阼階，延登，贊曰：「假王蒞政，勤和天下。」』此周公攝政，贊者所稱。成王加元服，周公則致政。書曰『朕復子明辟』，周公常稱王命，專行不報，故言我復子明君也。臣請安漢公居攝踐祚，服天子韍冕，背斧依于戶牖之間，南面朝羣臣，聽政事。車服出入警蹕，民臣稱臣妾，皆如天子之制。郊祀天地，宗祀明堂，共祀宗廟，享祭羣神，贊曰『假皇帝』，民臣謂之『攝皇帝』，自稱曰『予』。平決朝事，常以皇帝之詔稱『制』，以奉順皇天之心，輔翼漢室，保安孝平皇帝之幼嗣，遂寄託之義，隆治平之化。其朝見太皇太后、帝皇后，皆復臣節。自施政教於其宮家國采，如諸侯禮故事。臣昧死請。」太后詔曰：「可。」明年，改元曰居攝。

**互校说明** 接前一年末符命，礼分对太后、孺子及天下发号。

**孺子婴时期居摄二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **刘舜嗣长沙王。** 刘舜嗣长沙王。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **刘宏嗣广陵王。** 刘宏嗣广陵王。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **翟义起兵，立刘信。** 居摄二年九月都试日，东郡太守翟义起兵反对王莽，立东平王刘匡之父、严乡侯刘信为帝。翟义兵败被捕。侯表记刘信死，《翟方进传》和《通鉴》说始终未捕得刘信。三辅响应者战至[次年](ce-0008.md#hs084-l9298-e1)。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **武平侯璜一支后事。** 居摄二年举兵死亡。 官军在陈留菑击破翟义部，刘璜被斩。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **当涂康侯魏不害｜改封。** 表载当涂康侯魏不害一支本年爵号或封邑改易。表中所载事项为更为翼汉侯。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **义成侯甘延寿｜改封。** 表载义成侯甘延寿一支本年爵号或封邑改易。表中所载事项为更为诛郅支侯。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **建成定侯黄霸｜承爵。** 表载建成定侯黄霸一支本年记载侯位承袭。表中所载事项为侯辅承爵。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **居摄二年改铸大钱与刀币。** 《王莽传》明载居摄二年，三种新币与五铢并行。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **王莽遣将镇压翟义并命诸将设防。** 王莽任孙建、王邑等七人为将，征关东军讨翟义，并派兵守函谷关、武关和三辅要地。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **王莽仿《周书》作《大诰》。** 王莽以周公摄政自比，借管蔡、武庚旧事声讨翟义、刘信，在居摄二年十月发诰，又使桓谭等宣告将还政孺子。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **王莽初赏东征将士并大赦。** 官军获胜后，王莽命先封孙贤等五十五人为列侯，派使者赴军中授印，并大赦。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **三辅赵明、霍鸿等起事。** 赵明、霍鸿等闻翟义起兵，在三辅二十三县响应，攻官署、杀官吏。王莽分兵迎击并加强长安防备。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **窦况击破西羌。** 居摄二年春，窦况等报告击破西羌，与前一年起兵分读。 [[13]](#hs-note-13)

1. **刘舜嗣长沙王。** 刘舜嗣长沙王。 [[1]](#hs-note-1)

2. **刘宏嗣广陵王。** 刘宏嗣广陵王。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **严乡侯信一支后事。** 居摄二年，东郡太守翟义举兵，立信为天子，兵败，死亡。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **武平侯璜一支后事。** 居摄二年举兵死亡。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **当涂康侯魏不害｜改封。** 表载当涂康侯魏不害一支本年爵号或封邑改易。表中所载事项为更为翼汉侯。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **义成侯甘延寿｜改封。** 表载义成侯甘延寿一支本年爵号或封邑改易。表中所载事项为更为诛郅支侯。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **建成定侯黄霸｜承爵。** 表载建成定侯黄霸一支本年记载侯位承袭。表中所载事项为侯辅承爵。 [[7]](#hs-note-7)

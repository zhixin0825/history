# 公元8年｜三辅战事结束，王莽劳军封爵

[← 公元7年](ce-0007.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元9年 →](ce-0009.md)

**居摄三年／初始元年**

本年正、二月仍用居摄年号。汉历年末称帝与改正朔见[公元9年同号史料](ce-0009.md#hs-note-4)。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **王邑回师并平定赵明、霍鸿。** 正月，王邑所率自关东回师，旋即与西向各军合兵。二月，西部各县的起事被平定，官军班师。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **王莽白虎殿劳军，合计东西军功封爵。** 平三辅后，王莽于白虎殿劳饷将帅；又合录益州、金城等役，按差次封侯、伯、子、男三百九十五人。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **王莽追诛翟氏并筑五处武军。** 王莽毁翟氏宅第祖坟，株连其族；又令在濮阳、无盐、圉、槐里、盩厔五处聚败者尸首筑武军。 [[3]](#hs-note-3)

## 本年相关史料

<a id="hs-note-1"></a>

### 1. 王邑回师并平定赵明、霍鸿

[返回正文第1条](#hs-event-1)

<a id="hs084-l9298-e1"></a>

**[《汉书·翟方进传》P036](../../sources/摘录/汉书-卷084-翟方进传.md#p036)** · [仓内TXT L9298](../../sources/本地分卷/汉书/汉书-卷084.md#L9298)

> 正月，虎牙將軍王邑等自關東還，便引兵西。彊弩將軍王駿以無功免，揚武將軍劉歆歸故官。復以邑弟侍中王奇為揚武將軍，城門將軍趙恢為彊弩將軍，中郎將李棽為厭難將軍，復將兵西。二月，明等殄滅，諸縣悉平，還師振旅。

**互校说明** 《通鉴》卷036列初始元年春；以当时政令，十一月才改元，故正、二月仍为居摄三年。本传赵明，《通鉴》《王莽传》赵朋。

<a id="hs-note-2"></a>

### 2. 王莽白虎殿劳军，合计东西军功封爵

[返回正文第2条](#hs-event-2)

<a id="hs084-l9298-e2"></a>

**[《汉书·翟方进传》P036](../../sources/摘录/汉书-卷084-翟方进传.md#p036)** · [仓内TXT L9298](../../sources/本地分卷/汉书/汉书-卷084.md#L9298)

> 莽乃置酒白虎殿，勞饗將帥，大封拜。先是益州蠻夷及金城塞外羌反畔，時州郡擊破之。莽乃并錄，以小大為差，封侯伯子男凡三百九十五人，曰「皆以奮怒，東指西擊，羌寇蠻盜，反虜逆賊，不得旋踵，應時殄滅，天子咸服」之功封云。

**互校说明** 《通鉴》卷036将大封拜接居摄三年二月班师。诏把东西数路战功合并计等；羌、蛮诸战并非都发生于这一月。

<a id="hs-note-3"></a>

### 3. 王莽追诛翟氏并筑五处武军

[返回正文第3条](#hs-event-3)

<a id="hs084-l9301-e3"></a>

**[《汉书·翟方进传》P039](../../sources/摘录/汉书-卷084-翟方进传.md#p039)** · [仓内TXT L9301](../../sources/本地分卷/汉书/汉书-卷084.md#L9301)

> 莽盡壞義第宅，汙池之。發父方進及先祖冢在汝南者，燒其棺柩，夷滅三族，誅及種嗣，至皆同坑，以棘五毒并葬之。而下詔曰：「蓋聞古者伐不敬，取其鯨鯢築武軍，封以為大戮，於是乎有京觀以懲淫慝。乃者反虜劉信、翟義誖逆作亂於東，而芒竹群盜趙明、霍鴻造逆西土，遣武將征討，咸伏其辜。惟信、義等始發自濮陽，結姦無鹽，殄滅於圉。趙明依阻槐里環隄，霍鴻負倚盩厔芒竹，咸用破碎，亡有餘類。其取反虜逆賊之鯨鯢，聚之通路之旁，濮陽、無鹽、圉、槐里、盩厔凡五所，各方六丈，高六尺，築為武軍，封以為大戮，薦樹之棘。建表木，高丈六尺。書曰『反虜逆賊鯨鯢』，在所長吏常以秋循行，勿令壞敗，以懲淫慝焉。」

**互校说明** 《通鉴》卷036接两路平定后书发翟氏祖坟、诏筑五处武军；本传亦接次年清剿总报。

# 公元9年｜徐乡侯炔一支后事

[← 公元8年](ce-0008.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元10年 →](ce-0010.md)

**新莽始建国元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **徐乡侯炔一支后事。** 建国元年，举兵欲被诛莽，死亡。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **徐乡侯刘炔起兵反莽而死。** 徐乡侯刘炔起兵反莽而死。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **酇文终侯萧何｜改封。** 表载酇文终侯萧何一支本年爵号或封邑改易。表中所载事项为更为萧乡侯。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **王莽代汉称帝。** 王莽由居摄而代汉，以新为国号。汉历居摄三年末的政事见[前一年](ce-0008.md)，改正朔与新朝起始在本条合读。 王莽代汉后，将孺子刘婴降为定安公。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **颁行王田、私属禁售。** 始建国元年颁王田令，依《王莽传》和《通鉴》。 [[5]](#hs-note-5)

> 莽於是自謂大得天人之助，至其年十二月，遂即真矣。

**互校说明** 本传概称居摄三年末十二月即真；《通鉴》卷036与《王莽传》分列戊辰受禅、改旧十二月癸酉朔为始建国元年正月朔。此处在公元9年既有称帝条互见，不把居摄三年十二月直接当公历12月。

# 公元10年｜义成侯甘延寿｜承爵

[← 公元9年](ce-0009.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元11年 →](ce-0011.md)

**新莽始建国二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **义成侯甘延寿｜承爵。** 表载义成侯甘延寿一支本年记载侯位承袭。表中所载事项为侯相承爵。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **安成共侯王崇｜承爵。** 表载安成共侯王崇一支本年记载侯位承袭。表中所载事项为侯持弓承爵。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **高武贞侯傅喜｜承爵。** 表载高武贞侯傅喜一支本年记载侯位承袭。表中所载事项为侯劲承爵。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **王莽改行宝货。** 依据《通鉴》卷037编次，并列宝货多种；其撤并不与初造强系同日。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **设五均、赊贷与诸斡。** 始建国二年，置五均司市；制度参数与执行弊端见卷内。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **新朝作八风台。** 《郊祀志》记王莽即位后二年；按始建国二年系。晚年祠数是总说。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **甄寻符命案。** 甄寻续献符命，王莽下令收捕，甄丰自杀，甄寻逃匿。后来追究刘棻等人；得知刘棻曾从扬雄学字，办案者一度查到天禄阁，扬雄坠阁几死，王莽未治他的罪。 [[7]](#hs-note-7)

### 7. 甄寻符命案

[返回正文第7条](#hs-event-7)

<a id="hs087-l9476-e7"></a>

**[《汉书·扬雄传》P076](../../sources/摘录/汉书-卷087-扬雄传.md#p076)** · [仓内TXT L9476](../../sources/本地分卷/汉书/汉书-卷087.md#L9476)

> 王莽時，劉歆、甄豐皆爲上公，莽旣以符命自立，即位之後，欲絕其原以神前事，而豐子尋、歆子棻復獻之。莽誅豐父子，投棻四裔，辭所連及，便收不請。時雄校書天祿閣上，治獄使者來，欲收雄，雄恐不能自免，迺從閣上自投下，幾死。莽聞之曰：「雄素不與事，何故在此？」閒請問其故，迺劉棻甞從雄學作竒字，雄不知情。有詔勿問。然京師爲之語曰：「惟寂寞，自投閣；爰清靜，作符命。」

**互校说明** 甄寻续作符命、甄丰自杀系《王莽传》《通鉴》始建国二年，后续追捕逾年。扬雄投阁因该案而发，附入案发年；其具体年、月未见。

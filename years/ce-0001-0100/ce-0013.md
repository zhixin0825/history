# 公元13年｜王政君去世、乌累单于继位

[← 公元12年](ce-0012.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元14年 →](ce-0014.md)

**新莽始建国五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **王政君葬渭陵。** 王政君葬渭陵，与汉元帝合葬。《游侠传》记原涉在丧事中代理复土校尉。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **乌珠留单于去世，咸继为乌累单于。** 乌珠留卒，须卜当与妻须卜居次云越过舆而拥立咸。咸改授舆以左谷蠡王，并降低乌珠留系护于的位号。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **焉耆杀西域都护但钦。** 焉耆杀死驻西域都护但钦，王莽未能及时发兵讨伐。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **王政君去世。** 始建国五年二月，元帝皇后王政君去世，传称年八十四。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **孔永退任，逯并接大司马。** 孔永请退，以特进就朝位，逯并接职。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **王莽宣布日后移都洛阳。** 民闻迁都而不修房，王莽以符命设想第八年移都，令先修常安，迁都未如诏行。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **乌孙两昆弥使者座次之争。** 两昆弥使者同来，新朝欲拉拢乌孙以对匈奴，命小昆弥使在大昆弥使上，满昌劾不合礼。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **十一月见彗。** 十一月彗见二十余日后不见。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **撤去挟铜炭禁。** 犯禁者多，王莽撤去私持铜、炭的此项禁令。 [[9]](#hs-note-9)

### 2. 乌珠留单于去世，咸继为乌累单于

[返回正文第2条](#hs-event-2)

<a id="hs094-l9890-e2"></a>

**[《汉书·匈奴传》P132](../../sources/摘录/汉书-卷094-匈奴传.md#p132)** · [仓内TXT L9890](../../sources/本地分卷/汉书/汉书-卷094.md#L9890)

> 烏珠留單于立二十一歲，建國五年死。匈奴用事大臣右骨都侯須卜當，即王昭君女伊墨居次云之婿也。云常欲與中國和親，又素與咸厚善，見咸前後為莽所拜，故遂越輿而立咸為烏累若鞮單于。

**互校说明** 本传明载建国五年，《通鉴》同。

<a id="hs094-l9891-e2"></a>

**[《汉书·匈奴传》P133](../../sources/摘录/汉书-卷094-匈奴传.md#p133)** · [仓内TXT L9891](../../sources/本地分卷/汉书/汉书-卷094.md#L9891)

> 烏累單于咸立，以弟輿為左谷蠡王。烏珠留單于子蘇屠胡本為左賢王，以弟屠耆閼氏子盧渾為右賢王。烏珠留單于在時，左賢王數死，以為其號不祥，更易命左賢王曰「護于」。護于之尊最貴，次當為單于，故烏珠留單于授其長子以為護于，欲傳以國。咸怨烏珠留單于貶賤己號，不欲傳國，及立，貶護于為左屠耆王。云、當遂勸咸和親。

**互校说明** 承本年继立的调整；护于改号始于乌珠留，和议随后始于次年。

<a id="hs099-l10474-e2"></a>

**[《汉书·王莽传》P158](../../sources/摘录/汉书-卷099-王莽传.md#p158)** · [仓内TXT L10474](../../sources/本地分卷/汉书/汉书-卷099.md#L10474)

> 匈奴單于知死，弟咸立為單于，求和親。

**互校说明** 继位从卷094明记的建国五年；返还陈良等另据天凤元年。

### 6. 王莽宣布日后移都洛阳

<a id="hs099-l10460-e6"></a>

**[《汉书·王莽传》P144](../../sources/摘录/汉书-卷099-王莽传.md#p144)** · [仓内TXT L10460](../../sources/本地分卷/汉书/汉书-卷099.md#L10460)

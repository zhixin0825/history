# 公元14年｜周子南君姬嘉｜改封

[← 公元13年](ce-0013.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元15年 →](ce-0015.md)

**新莽天凤元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **周子南君姬嘉｜改封。** 表载周子南君姬嘉一支本年爵号或封邑改易。表中所载事项为公常承爵。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

<a id="hs-event-3"></a>

2. **新朝始行货布、货泉。** 天凤元年，新朝改行货布、货泉，新货泉一枚当一钱，与货布并用。旧大钱到地皇元年才满流通期限。 [[2]](#hs-note-2)

<a id="hs-event-4"></a>

<a id="hs-event-12"></a>

3. **乌累单于交还陈良、终带，新朝撤屯边诸军。** 须卜居次云、须卜当沟通两国，王歙、王飒出使，乌累单于交回陈良、终带等及其家属，王莽施焚如之刑。久屯边塞的士卒缺粮，如普主张乘议和撤军，韩威仍主进攻。新朝本年罢诸将屯兵，边境后来仍有攻掠。 [[3]](#hs-note-4)

<a id="hs-event-5"></a>

4. **益州起事，王莽遣冯茂出兵。** 益州诸部起事并杀郡大尹程隆。王莽命平蛮将军冯茂从巴蜀和犍为征兵、征取军费粮秣。 [[4]](#hs-note-5)

<a id="hs-event-6"></a>

5. **改元天凤并赦。** 次年改元为天凤，本段为年序过渡。 [[5]](#hs-note-6)

<a id="hs-event-7"></a>

6. **王莽发布巡狩计划。** 诏拟从建寅月出巡，要求沿途轻供、亲示农作，连叙巡狩名物及推迟情形。 [[6]](#hs-note-7)

<a id="hs-event-8"></a>

7. **三月日食、易大司马。** 日食后大赦，以兵不息等责大司马，收逯并印；减兼官，任苗訢为大司马。 [[7]](#hs-note-8)

<a id="hs-event-9"></a>

8. **霜雾、风雹。** 分记四月陨霜、六月黄雾、七月风拔木、吹瓦及雹杀牛羊。 [[8]](#hs-note-9)

<a id="hs-event-10"></a>

9. **天凤元年重新部署地方官。** 王莽参照《周官》《王制》改置地方官，设卒正、连率、大尹，职掌相当于太守；设置州牧、部监，每位部监督五郡，并规定官员等第和礼仪。 [[9]](#hs-note-10)

<a id="hs-event-11"></a>

10. **改旬首和宫冠婚日规则。** 改六旬首为戊子，对冠礼、婚礼日期立新规，民间多不遵行。 [[10]](#hs-note-11)

<a id="hs-event-13"></a>

11. **戴参接任宁始将军。** 侯辅被免，讲易祭酒戴参任宁始将军。 [[11]](#hs-note-13)

<a id="hh-event-14"></a>

12. **琅邪海曲有吕母者，子为县吏，犯小罪，宰论杀之。** 天凤元年，琅邪海曲有吕母者，子为县吏，犯小罪，宰论杀之。 [[12]](#hh-note-14)

> 天鳳元年，云、當遣人之西河虎猛制虜塞下，告塞吏曰欲見和親侯。和親侯王歙者，王昭君兄子也。中部都尉以聞。莽遣歙、歙弟騎都尉展德侯颯使匈奴，賀單于初立，賜黃金衣被繒帛，紿言侍子登在，因購求陳良、終帶等。單于盡收四人及手殺校尉刀護賊芝音妻子以下二十七人，皆械檻付使者，遣廚唯姑夕王富等四十人送歙、颯。莽作焚如之刑，燒殺陳良等，罷諸將率屯兵，但置游擊都尉。單于貪莽賂遺，故外不失漢故事，然內利寇掠。又使還，知子登前死，怨恨，寇虜從左地入，不絕。使者問單于，輒曰：「烏桓與匈奴無狀黠民共為寇入塞，譬如中國有盜賊耳！咸初立持國，威信尚淺，盡力禁止，不敢有二心。」

**互校说明** 天凤元年，既有新莽及西域诸传可互见。登已于建国四年被杀，非此年尚存。

> 緣邊大飢，人相食。諫大夫如普行邊兵，還言「軍士久屯塞苦，邊郡無以相贍。今單于新和，宜因是罷兵。」校尉韓威進曰：「以新室之威而吞胡虜，無異口中蚤蝨。臣願得勇敢之士五千人，不齎斗糧，飢食虜肉，渴飲其血，可以橫行。」莽壯其言，以威為將軍。然采普言，徵還諸將在邊者。免陳欽等十八人，又罷四關填都尉諸屯兵。會匈奴使還，單于知侍子登前誅死，發兵寇邊，莽復發軍屯。於是邊民流入內郡，為人奴婢，乃禁吏民敢挾邊民者棄市。

### 6. 王莽发布巡狩计划

[返回正文第6条](#hs-event-7)

<a id="hs099-l10468-e7"></a>

**[《汉书·王莽传》P152](../../sources/摘录/汉书-卷099-王莽传.md#p152)** · [仓内TXT L10468](../../sources/本地分卷/汉书/汉书-卷099.md#L10468)

> 莽曰：「予以二月建寅之節行巡狩之禮，太官齎糒乾肉，內者行張坐臥，所過毋得有所給。予之東巡，必躬載耒，每縣則耕，以勸東作。予之南巡，必躬載耨，每縣則薅，以勸南偽。予之西巡，必躬載銍，每縣則穫，以勸西成。予之北巡，必躬載拂，每縣則粟，以勸蓋藏。畢北巡狩之禮，即于土中居雒陽之都焉。敢有趨讙犯法，輒以軍法從事。」群公奏言：「皇帝至孝，往年文母聖體不豫，躬親供養，衣冠稀解。因遭棄群臣悲哀，顏色未復，飲食損少。今一歲四巡，道路萬里，春秋尊，非糒乾肉之所能堪。且無巡狩，須闋大服，以安聖體。臣等盡力養牧兆民，奉稱明詔。」莽曰：「群公、群牧、群司、諸侯、庶尹願盡力相帥養牧兆民，欲以稱予，繇此敬聽，其勗之哉！毋食言焉。更以天鳳七年，歲在大梁，倉龍庚辰，行巡狩之禮。厥明年，歲在實沈，倉龍辛巳，即土之中雒陽之都。」乃遣太傅平晏、大司空王邑之雒陽，營相宅兆，圖起宗廟、社稷、郊兆云。

**互校说明** 诏书中的拟行与实际成行不同。

### 9. 天凤元年重新部署地方官

[返回正文第9条](#hs-event-10)

<a id="hs099-l10472-e10"></a>

**[《汉书·王莽传》P156](../../sources/摘录/汉书-卷099-王莽传.md#p156)** · [仓内TXT L10472](../../sources/本地分卷/汉书/汉书-卷099.md#L10472)

> 莽以周官、王制之文，置卒正、連率、大尹，職如太守；屬令、屬長，職如都尉。置州牧、部監二十五人。見禮如三公。監位上大夫，各主五郡。公氏作牧，侯氏卒正，伯氏連率，子氏屬令，男氏屬長，皆世其官，其無爵者為尹。分長安城旁六鄉，置帥各一人。分三輔為六尉郡，河東、河內、弘農、河南、潁川、南陽為六隊郡，置大夫，職如太守；屬正，職如都尉。更名河南大尹曰保忠信卿。益河南屬縣滿三十。置六郊州長各一人，人主五縣。及它官名悉改。大郡至分為五。郡縣以亭為名者三百六十，以應符命文也。緣邊又置竟尉，以男為之。諸侯國閒田，為黜陟增減云。莽下書曰：「常安西都曰六鄉，眾縣曰六尉。義陽東都曰六州，眾縣曰六隊。粟米之內曰內郡，其外曰近郡。有鄣徼者曰邊郡。合百二十有五郡。九州之內，縣二千二百有三。公作甸服，是為惟城；諸在侯服，是為惟寧；在采、任諸侯，是為惟翰；在賓服，是為惟屏；在揆文教，奮武衛，是為惟垣；在九州之外，是為惟藩：各以其方為稱，總為萬國焉。」其後，歲復變更，一郡至五易名，而還復其故。吏民不能紀，每下詔書，輒繫其故名，曰：「制詔陳留大尹、太尉：其以益歲以南付新平。新平，故淮陽。以雍丘以東付陳定。陳定，故梁郡。以封丘以東付治亭。治亭，故東郡。以陳留以西付祈隧。祈隧，故滎陽。陳留已無復有郡矣。大尹、太尉，皆詣行在所。」其號令變易，皆此類也。

**互校说明** 以州牧部监、卒正等操办地方政务。

# 公元15年｜归还侍子登之丧与新莽朝政

[← 公元14年](ce-0014.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元16年 →](ce-0016.md)

**新莽天凤二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **王莽遣使归登之丧并改匈奴名号。** 王歙、王咸等送还登之丧，赠礼并令改“匈奴”为“恭奴”、“单于”为“善于”，给须卜当父子封号，支付陈良等悬购金。使团十二月回塞。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **王路堂置酒与二月大赦。** 天凤二年二月在王路堂置酒，群公陪饮，同月书赦。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **白昼见星的记载。** 传记日中见星，未明其现代天体种类。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **陈茂接任大司马。** 苗訢左迁，延德侯陈茂任大司马。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **黄山宫黄龙传言。** 传言黄山宫有黄龙坠死，万人趋看，追查未得传言源头。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **邯郸以北水灾。** 记大雨、积水深数丈，冲死数千人。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **孙建死后诸将递迁。** 赵闳接立国将军，戴参回故职，廉丹任宁始将军。 [[7]](#hs-note-7)

### 1. 王莽遣使归登之丧并改匈奴名号

[返回正文第1条](#hs-event-1)

<a id="hs094-l9893-e1"></a>

**[《汉书·匈奴传》P135](../../sources/摘录/汉书-卷094-匈奴传.md#p135)** · [仓内TXT L9893](../../sources/本地分卷/汉书/汉书-卷094.md#L9893)

> 天鳳二年五月，莽復遣歙與五威將王咸率伏黯、丁業等六人，使送右廚唯姑夕王，因奉歸前所斬侍子登及諸貴人從者喪，皆載以常車。至塞下，單于遣云、當子男大且渠奢等至塞迎。咸等至，多遺單于金珍，因諭說改其號，號匈奴曰「恭奴」，單于曰「善于」，賜印綬。封骨都侯當為後安公，當子男奢為後安侯。單于貪莽金幣，故曲聽之，然寇盜如故。咸、歙又以陳良等購金付云、當，令自差與之。十二月，還入塞，莽大喜，賜歙錢二百萬，悉封黯等。

**互校说明** 本传天凤二年五月遣使，十二月入塞；《通鉴》卷三十八同。

<a id="hs099-l10482-e1"></a>

**[《汉书·王莽传》P166](../../sources/摘录/汉书-卷099-王莽传.md#p166)** · [仓内TXT L10482](../../sources/本地分卷/汉书/汉书-卷099.md#L10482)

> 單于咸既和親，求其子登屍，莽欲遣使送致，恐咸怨恨害使者，乃收前言當誅侍子者故將軍陳欽，以他罪繫獄。欽曰：「是欲以我為說於匈奴也。」遂自殺。莽選儒生能顓對者濟南王咸為大使，五威將琅邪伏黯等為帥，使送登屍。敕令掘單于知墓，棘鞭其屍。又令匈奴卻塞於漠北，責單于馬萬匹，牛三萬頭，羊十萬頭，及稍所略邊民生口在者皆還之。莽好為大言如此。咸到單于庭，陳莽威德，責單于背畔之罪，應敵從橫，單于不能詘，遂致命而還之。入塞，咸病死，封其子為伯，伏黯等皆為子。

**互校说明** 陈钦事件发生在送还登尸前，和卷094所记新称先后互见。

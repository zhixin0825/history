# 公元16年｜新莽攻益州与焉耆

[← 公元15年](ce-0015.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元17年 →](ce-0017.md)

**新莽天凤三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **冯茂获罪，王莽改遣廉丹、史熊。** 冯茂军中疫病致大量伤亡，王莽召回诛杀。廉丹、史熊继领兵，军粮难继，战事经年未定；越巂任贵亦杀太守枚根。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **王骏攻焉耆阵亡，李崇退保龟兹。** 王骏、李崇出兵西域，焉耆诈降并联合姑墨、尉犁、危须军反击。王骏等战败身亡，郭钦率别部撤回，李崇退保龟兹。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **关东地震雪灾及王邑谢事。** 关东积雪甚深，竹柏受损。王邑以司空主土为由请退，王莽拒并按旧说解释。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **颁官吏俸禄制度。** 王莽列原俸禄供应艰窘，另按官爵品阶、天下丰耗拟定给禄，实际支给仍受财计限制。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **长平馆岸崩堵泾水与边军调遣。** 长平馆西岸崩堵泾水，勘视后群臣附会河图为匈奴将亡，遂遣宋弘、任萌等出兵。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **霸城门失火。** 七月辛酉霸城门着火，民间叫青门。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **日食后大赦举贤，严尤接大司马。** 记朔晦干支和大赦，令荐四行，陈茂免大司马、严尤接任。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **朱鸟门鸣与对策。** 崔发把门鸣解释为广招贤士的吉兆，令群臣称贺，令被举者由此门入而对策。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **王孙庆被捕。** 王莽命医官、工匠量王孙庆五藏及脉理，以为医治可取法；原文仅说明其声称目的。 [[9]](#hs-note-9)

## 本年相关史料

<a id="hs-note-1"></a>

### 1. 冯茂获罪，王莽改遣廉丹、史熊

[返回正文第1条](#hs-event-1)

<a id="hs095-l9913-e1"></a>

**[《汉书·西南夷两粤朝鲜传》P010](../../拆分史书/汉书/卷095.md#p010)** · [仓内TXT L9913](../../拆分史书/汉书/卷095.md#part-1-L9913)

> 出入三年，疾疫死者什七，巴、蜀騷動。莽征茂還，誅之。更遣甯始將軍廉丹與庸部牧史熊大發天水、隴西騎士，廣漢、巴、蜀、犍爲吏民十萬人，轉輸者合二十萬人，擊之。始至，頗斬首數千，其後軍糧前後不相及，士卒饑疫，三歲余死者數萬。而粵巂蠻夷任貴亦殺太守枚根，自立爲邛谷王。

**互校说明** 《通鉴》卷三十八天凤三年条接冯茂败诛、遣廉丹史熊，田况上奏及任贵事件。正文后半的三岁余是持续战事。

<a id="hs099-l10492-e1"></a>

**[《汉书·王莽传》P176](../../拆分史书/汉书/卷099.md#p176)** · [仓内TXT L10492](../../拆分史书/汉书/卷099.md#part-1-L10492)

> 平蠻將軍馮茂擊句町，士卒疾疫，死者什六七，賦斂民財什取五，益州虛耗而不克，徵還下獄死。更遣寧始將軍廉丹與庸部牧史熊擊句町，頗斬首，有勝。莽徵丹、熊，丹、熊願益調度，必克乃還。復大賦斂，就都大尹馮英不肯給，上言「自越巂遂久仇牛、同亭邪豆之屬反畔以來，積且十年，郡縣距擊不已。續用馮茂，苟施一切之政。僰道以南，山險高深，茂多敺眾遠居，費以億計，吏士離毒氣死者什七。今丹、熊懼於自詭期會，調發諸郡兵穀，復訾民取其十四，空破梁州，功終不遂。宜罷兵屯田，明設購賞。」莽怒，免英官。後頗覺寤，曰：「英亦未可厚非。」復以英為長沙連率。

**互校说明** 始末与卷095同号互见；本传作“馬茂”，《西南夷传》《通鉴》作“馮茂”。

### 2. 王骏攻焉耆阵亡，李崇退保龟兹

[返回正文第2条](#hs-event-2)

<a id="hs096-l10114-e2"></a>

**[《汉书·西域传》P166](../../拆分史书/汉书/卷096.md#p166)** · [仓内TXT L10114](../../拆分史书/汉书/卷096.md#part-1-L10114)

> 天鳳三年，乃遣五威將王駿、西域都護李崇將戊己校尉出西域，諸國皆郊迎，送兵谷，焉耆詐降而聚兵自備。駿等將莎車、龜慈兵七千餘人，分為數部入焉耆，焉耆伏兵要遮駿。及姑墨、尉犁、危須國兵為反間，還共襲擊駿等，皆殺之。唯戊己校尉郭欽別將兵，後至焉耆。焉耆兵未還，欽擊殺其老弱，引兵還。莽封欽為剼鬍子。李崇收余士，還保龜茲。

**互校说明** 《王莽传》及本传同系天凤三年，文末李崇结局另在数年后。

<a id="hs099-l10494-e2"></a>

**[《汉书·王莽传》P178](../../拆分史书/汉书/卷099.md#p178)** · [仓内TXT L10494](../../拆分史书/汉书/卷099.md#part-1-L10494)

> 是歲，遣大使五威將王駿、西域都護李崇將戊己校尉出西域，諸國皆郊迎貢獻焉。諸國前殺都護但欽，駿欲襲之，命佐帥何封、戊己校尉郭欽別將。焉耆詐降，伏兵擊駿等，皆死。欽、封後到，襲擊老弱，從車師還入塞。莽拜欽為填外將軍，封劋胡子，何封為集胡男。西域自此絕。

**互校说明** 与《西域传》《通鉴》卷038同。

### 3. 关东地震雪灾及王邑谢事

[返回正文第3条](#hs-event-3)

<a id="hs099-l10486-e3"></a>

**[《汉书·王莽传》P170](../../拆分史书/汉书/卷099.md#p170)** · [仓内TXT L10486](../../拆分史书/汉书/卷099.md#part-1-L10486)

> 三年二月乙酉，地震，大雨雪，關東尤甚，深者一丈，竹柏或枯。大司空王邑上書言：「視事八年，功業不效，司空之職尤獨廢頓，至乃有地震之變。願乞骸骨。」莽曰：「夫地有動有震，震者有害，動者不害。春秋記地震，易繫坤動，動靜辟脅，萬物生焉。災異之變，各有云為。天地動威，以戒予躬，公何辜焉，而乞骸骨，非所以助予者也。使諸吏散騎司祿大衛脩寧男遵諭予意焉。」

**互校说明** 天凤三年二月。

### 4. 颁官吏俸禄制度

[返回正文第4条](#hs-event-4)

<a id="hs099-l10487-e4"></a>

**[《汉书·王莽传》P171](../../拆分史书/汉书/卷099.md#p171)** · [仓内TXT L10487](../../拆分史书/汉书/卷099.md#part-1-L10487)

> 五月，莽下吏祿制度，曰：「予遭陽九之阨，百六之會，國用不足，民人騷動，自公卿以下，一月之祿十愑布二匹，或帛一匹。予每念之，未嘗不戚焉。今阨會已度，府帑雖未能充，略頗稍給，其以六月朔庚寅始，賦吏祿皆如制度。」四輔公卿大夫士，下至輿僚，凡十五等。僚祿一歲六十六斛，稍以差增，上至四輔而為萬斛云。莽又曰：「『普天之下，莫非王土；率土之賓，莫非王臣。』蓋以天下養焉。周禮膳羞百有二十品，今諸侯各食其同、國、則；辟、任、附城食其邑；公、卿、大夫、元士食其采。多少之差，咸有條品。歲豐穰則充其禮，有災害則有所損，與百姓同憂喜也。其用上計時通計，天下幸無災害者，太官膳羞備其品矣；即有災害，以什率多少而損膳焉。東嶽太師立國將軍保東方三州一部二十五郡；南嶽太傅前將軍保南方二州一部二十五郡；西嶽國師寧始將軍保西方一州二部二十五郡；北嶽國將衛將軍保北方二州一部二十五郡；大司馬保納卿、言卿、仕卿、作卿、京尉、扶尉、兆隊、右隊、中部左洎前七部；大司徒保樂卿、典卿、宗卿、秩卿、翼尉、光尉、左隊、前隊、中部、右部，有五郡；大司空保予卿、虞卿、共卿、工卿、師尉、列尉、祈隊、後隊、中部洎後十郡；及六司，六卿，皆隨所屬之公保其災害，亦以十率多少而損其祿。郎、從官、中都官吏食祿都內之委者，以太官膳羞備損而為節。諸侯、辟、任、附城、群吏亦各保其災害。幾上下同心，勸進農業，安元元焉。」莽之制度煩碎如此，課計不可理，吏終不得祿，各因官職為姦，受取賕賂以自共給。

**互校说明** 天凤三年五月颁诏，文称六月起。

### 5. 长平馆岸崩堵泾水与边军调遣

[返回正文第5条](#hs-event-5)

<a id="hs099-l10488-e5"></a>

**[《汉书·王莽传》P172](../../拆分史书/汉书/卷099.md#p172)** · [仓内TXT L10488](../../拆分史书/汉书/卷099.md#part-1-L10488)

> 是月戊辰，長平館西岸崩，邕涇水不流，毀而北行。遣大司空王邑行視，還奏狀，群臣上壽，以為河圖所謂「以土填水」，匈奴滅亡之祥也。乃遣并州牧宋弘、游擊都尉任萌等將兵擊匈奴，至邊止屯。

**互校说明** 天凤三年五月戊辰，灾异与用兵联系源自朝臣占辞。

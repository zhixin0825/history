# 公元18年｜长平顷侯彭宣｜承爵

[← 公元17年](ce-0017.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元19年 →](ce-0019.md)

**新莽天凤五年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **长平顷侯彭宣｜承爵。** 表载长平顷侯彭宣一支本年记载侯位承袭。表中所载事项为侯业承爵。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **扬雄去世。** 扬雄天凤五年去世，传称七十一岁。长期从学的侯芭为他营墓并服丧。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **乌累单于死，舆继为呼都而尸道皋若鞮单于。** 乌累单于咸死，其弟舆继位。传文又解释“若鞮”是匈奴语“孝”，单于受汉帝谥号影响而沿用。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **北军南门失火。** 天凤五年正月朔记北军南门着火。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **费兴议赈贷荆扬，王莽罢之。** 费兴论山泽税夺民生、旱饥致盗，请贷贷粮钱及安辑归业，因言忤意而未获任用。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **没入侵利边吏财产。** 俸禄不支，吏多借军务取利。王莽令查侵利致富者并收家产五分之四。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **王宗坐案自杀。** 王宗私画像、刻印并通被徙母族，案发自杀。朝廷又追论其封号及有关人等。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **王渉为卫将军。** 王涉承王根之爵；王莽念王根曾荐己，改父子所用封号。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **力子都、樊崇等在琅邪聚众。** 力子都、樊崇等因饥聚众，转掠，郡国兵不能克；各支形成时间可与《后汉书》对读。 [[9]](#hs-note-9)

<a id="hh-event-10"></a>

10. **莎车王延卒，康继立。** 王莽时拒附匈奴的莎车王延去世，其子康继立。 [[10]](#hh-note-10)

### 6. 没入侵利边吏财产

[返回正文第6条](#hs-event-6)

<a id="hs099-l10502-e6"></a>

**[《汉书·王莽传》P186](../../拆分史书/汉书/卷099.md#p186)** · [仓内TXT L10502](../../拆分史书/汉书/卷099.md#part-1-L10502)

> 天下吏以不得奉祿，並為姦利，郡尹縣宰家累千金。莽下詔曰：「詳考始建國二年胡虜猾夏以來，諸軍吏及緣邊吏大夫以上為姦利增產致富者，收其家所有財產五分之四，以助邊急。」公府士馳傳天下，考覆貪饕，開吏告其將，奴婢告其主，幾以禁姦，姦愈甚。

**互校说明** 本年追查始建国二年以来的财富。

### 7. 王宗坐案自杀

[返回正文第7条](#hs-event-7)

<a id="hs099-l10503-e7"></a>

**[《汉书·王莽传》P187](../../拆分史书/汉书/卷099.md#p187)** · [仓内TXT L10503](../../拆分史书/汉书/卷099.md#part-1-L10503)

> 皇孫功崇公宗坐自畫容貌，被服天子衣冠，刻印三：一曰「維祉冠存己夏處南山臧薄冰」，二曰「肅聖寶繼」，三曰「德封昌圖」。又宗舅呂寬家前徙合浦，私與宗通，發覺按驗，宗自殺。莽曰：「宗屬為皇孫，爵為上公，知寬等叛逆族類，而與交通；刻銅印三，文意甚害，不知厭足，窺欲非望。春秋之義，『君親毋將，將而誅焉。』迷惑失道，自取此辜，烏呼哀哉！宗本名會宗，以制作去二名，今復名會宗。貶厥爵，改厥號，賜諡為功崇繆伯，以諸伯之禮葬于故同穀城郡。」宗姊妨為衛將軍王興夫人，祝詛姑，殺婢以絕口。事發覺，莽使中常侍鹊惲責問妨，并以責興，皆自殺。事連及司命孔仁妻，亦自殺。仁見莽免冠謝，莽使尚書劾仁：「乘乾車，駕巛馬，左蒼龍，右白虎，前朱雀，後玄武，右杖威節，左負威斗，號曰赤星，非以驕仁，乃以尊新室之威命也。仁擅免天文冠，大不敬。」有詔勿劾，更易新冠。其好怪如此。

**互校说明** 本传天凤五年。

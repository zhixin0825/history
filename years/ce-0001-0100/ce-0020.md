# 公元20年｜地皇改元、城防与改行货币

[← 公元19年](ce-0019.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元21年 →](ce-0021.md)

**新莽地皇元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

<a id="hs-event-3"></a>

1. **王莽改元地皇，增列军将并严刑。** 王莽改元地皇，正月大赦。为应对各地起事，王莽仿黄帝旧说增列军将和军职，又以军兴为由，命犯法当斩者毋待秋冬论决，延至年末。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **日中昏黑。** 记录中午昏暗，王莽归咎王匡的属官查问告变者，并以诏令解释天象。 [[2]](#hs-note-2)

<a id="hs-event-4"></a>

3. **大风毁王路堂。** 七月风雷折木毁屋，王莽以符命解释震惧，并牵涉王安和王临封国的安排。 [[3]](#hs-note-4)

<a id="hs-event-5"></a>

4. **杜陵御衣异象。** 吏卒报告藏匣中虎文衣自立又倒，王莽忌之，令近侍改服绛。 [[4]](#hs-note-5)

<a id="hs-event-6"></a>

5. **王莽令兴建九庙。** 占者说有土功之象，王莽以宗庙未修为由规划新庙，高耗营建与财计紧张同时发生。 [[5]](#hs-note-6)

<a id="hs-event-7"></a>

6. **马适求谋起燕赵兵，王丹告发。** 马适求等计划动燕赵兵，王丹告发，追查广及郡国豪杰，王丹获封。 [[6]](#hs-note-7)

<a id="hs-event-8"></a>

7. **停大小钱，专行货布、货泉。** 书罢大小钱，列货布、货钱的尺寸重量和比值，并惩私铸知而不举者；初铸与旧币退出的年次另辨。 [[7]](#hs-note-8)

<a id="hs-event-9"></a>

8. **唐尊接平晏任太傅。** 平晏卒，唐尊入任，提倡俭省，自用柴车瓦器，又以赭旗染不循男女异路者衣。 [[8]](#hs-note-9)

<a id="hs-event-10"></a>

9. **下江诸部聚于绿林。** 张霸、羊牧、王匡等聚众，称下江兵。同段武功水乡下陷另属灾异。 [[9]](#hs-note-10)

## 本年相关史料

<a id="hs-note-1"></a>

### 1. 王莽改元地皇，增列军将并严刑

[返回正文第1条](#hs-event-1)

<a id="hs099-l10512-e1"></a>

**[《汉书·王莽传》P196](../../sources/摘录/汉书-卷099-王莽传.md#p196)** · [仓内TXT L10512](../../sources/本地分卷/汉书/汉书-卷099.md#L10512)

> 明年改元曰地皇，從三萬六千歲曆號也。

**互校说明** 接地皇元年。

<a id="hs099-l10513-e1"></a>

**[《汉书·王莽传》P197](../../sources/摘录/汉书-卷099-王莽传.md#p197)** · [仓内TXT L10513](../../sources/本地分卷/汉书/汉书-卷099.md#L10513)

> 地皇元年正月乙未，赦天下。下書曰：「方出軍行師，敢有趨讙犯法者，輒論斬，毋須時，盡歲止。」於是春夏斬人都市，百姓震懼，道路以目。

**互校说明** 本传地皇元年正月乙未，权刑后续持续。

<a id="hs099-l10520-e1"></a>

**[《汉书·王莽传》P204](../../sources/摘录/汉书-卷099-王莽传.md#p204)** · [仓内TXT L10520](../../sources/本地分卷/汉书/汉书-卷099.md#L10520)

> 自莽為不順時令，百姓怨恨，莽猶安之，又下書曰：「惟設此壹切之法以來，常安六鄉巨邑之都，枹鼓稀鳴，盜賊衰少，百姓安土，歲以有年，此乃立權之力也。今胡虜未滅誅，蠻僰未絕焚，江湖海澤麻沸，盜賊未盡破殄，又興奉宗廟社稷之大作，民眾動搖。今復壹切行此令，盡二年止之，以全元元，救愚姦。」

**互校说明** 独立诏书中声称治安改善，以本年正月权刑互见。

<a id="hs-note-3"></a>

<a id="hs099-l10515-e3"></a>

**[《汉书·王莽传》P199](../../sources/摘录/汉书-卷099-王莽传.md#p199)** · [仓内TXT L10515](../../sources/本地分卷/汉书/汉书-卷099.md#L10515)

> 莽見四方盜賊多，復欲厭之，又下書曰：「予之皇初祖考黃帝定天下，將兵為上將軍，建華蓋，立斗獻，內設大將，外置大司馬五人，大將軍二十五人，偏將軍百二十五人，裨將軍千二百五十人，校尉萬二千五百人，司馬三萬七千五百人，候十一萬二千五百人，當百二十二萬五千人，士吏四十五萬人，士千三百五十萬人，應協於易『弧矢之利，以威天下』。予受符命之文，稽前人，將條備焉。」於是置前後左右中大司馬之位，賜諸州牧號為大將軍，郡卒正、連帥、大尹為偏將軍，屬令長裨將軍，縣宰為校尉。乘傳使者經歷郡國，日且十輩，倉無見穀以給，傳車馬不能足，賦取道中車馬，取辦於民。

**互校说明** 托为黄帝旧制的诏。

<a id="hs-note-2"></a>

### 2. 日中昏黑

[返回正文第2条](#hs-event-2)

<a id="hs099-l10514-e2"></a>

**[《汉书·王莽传》P198](../../sources/摘录/汉书-卷099-王莽传.md#p198)** · [仓内TXT L10514](../../sources/本地分卷/汉书/汉书-卷099.md#L10514)

> 二月壬申，日正黑。莽惡之，下書曰：「乃者日中見昧，陰薄陽，黑氣為變，百姓莫不驚怪。兆域大將軍王匡遣吏考問上變事者，欲蔽上之明，是以適見于天，以正于理，塞大異焉。」

**互校说明** 本传二月壬申，王莽归咎于王匡的解释依诏文保存。

<a id="hs-note-4"></a>

### 3. 大风毁王路堂

[返回正文第3条](#hs-event-4)

<a id="hs099-l10516-e4"></a>

**[《汉书·王莽传》P200](../../sources/摘录/汉书-卷099-王莽传.md#p200)** · [仓内TXT L10516](../../sources/本地分卷/汉书/汉书-卷099.md#L10516)

> 七月，大風毀王路堂。復下書曰：「乃壬午餔時，有列風雷雨發屋折木之變，予甚弁焉，予甚栗焉，予甚恐焉。伏念一旬，迷乃解矣。昔符命文立安為新遷王，臨國雒陽，為統義陽王。是時予在攝假，謙不敢當，而以為公。其後金匱文至，議者皆曰：『臨國雒陽為統，謂據土中為新室統也，宜為皇太子。』自此後，臨久病，雖瘳不平，朝見挈茵輿行。見王路堂者，張於西廂及後閣更衣中，又以皇后被疾，臨且去本就舍，妃妾在東永巷。壬午，列風毀王路西廂及後閣更衣中室。昭寧堂池東南榆樹大十圍，東僵，擊東閣，閣即東永巷之西垣也。皆破折瓦壞，發屋拔木，予甚驚焉。又候官奏月犯心前星，厥有占，予甚憂之。伏念紫閣圖文，太一、黃帝皆得瑞以僊，後世褒主當登終南山。所謂新遷王者，乃太一新遷之後也。統義陽王乃用五統以禮義登陽上遷之後也。臨有兄而稱太子，名不正。宣尼公曰：『名不正，則言不順，至於刑罰不中，民無錯手足。』惟即位以來，陰陽未和，風雨不時，數遇枯旱蝗螟為災，穀稼鮮耗，百姓苦飢，蠻夷猾夏，寇賊姦宄，人民正營，無所錯手足。深惟厥咎，在名不正焉。其立安為新遷王，臨為統義陽王，幾以保全二子，子孫千億，外攘四夷，內安中國焉。」

**互校说明** 地皇元年七月。

### 4. 杜陵御衣异象

[返回正文第4条](#hs-event-5)

<a id="hs099-l10517-e5"></a>

**[《汉书·王莽传》P201](../../sources/摘录/汉书-卷099-王莽传.md#p201)** · [仓内TXT L10517](../../sources/本地分卷/汉书/汉书-卷099.md#L10517)

> 是月，杜陵便殿乘輿虎文衣廢臧在室匣中者出，自樹立外堂上，良久乃委地。吏卒見者以聞，莽惡之，下書曰：「寶黃廝赤，其令郎從官皆衣絳。」

### 5. 王莽令兴建九庙

[返回正文第5条](#hs-event-6)

<a id="hs099-l10518-e6"></a>

**[《汉书·王莽传》P202](../../sources/摘录/汉书-卷099-王莽传.md#p202)** · [仓内TXT L10518](../../sources/本地分卷/汉书/汉书-卷099.md#L10518)

> 望氣為數者多言有土功象，莽又見四方盜賊多，欲視為自安能建萬世之基者，乃下書曰：「予受命遭陽九之厄，百六之會，府帑空虛，百姓匱乏，宗廟未修，且祫祭於明堂太廟，夙夜永念，非敢寧息。深惟吉昌莫良於今年，予乃卜波水之北，郎池之南，惟玉食。予又卜金水之南，明堂之西，亦惟玉食。予將新築焉。」於是遂營長安城南，提封百頃。九月甲申，莽立載行視，親舉築三下。司徒王尋、大司空王邑持節，及侍中常侍執法杜林等數十人將作。崔發、張邯說莽曰：「德盛者文縟，宜崇其制度，宣視海內，且令萬世之後無以復加也。」莽乃博徵天下工匠諸圖畫，以望法度算，及吏民以義入錢穀助作者，駱驛道路。壞徹城西苑中建章、承光、包陽、大臺、儲元宮及平樂、當路、陽祿館，凡十餘所，取其材瓦，以起九廟。是月，大雨六十餘日。令民入米六百斛為郎，其郎吏增秩賜爵至附城。九廟：一曰黃帝太初祖廟，二曰帝虞始祖昭廟，三曰陳胡王統祖穆廟，四曰齊敬王世祖昭廟，五曰濟北愍王王祖穆廟，凡五廟不墮云；六曰濟南伯王尊禰昭廟，七曰元城孺王尊禰穆廟，八曰陽平頃王戚禰昭廟，九曰新都顯王戚禰穆廟。殿皆重屋。太初祖廟東西南北各四十丈，高十七丈，餘廟半之。為銅薄櫨，飾以金銀琱文，窮極百工之巧。帶高增下，功費數百鉅萬，卒徒死者萬數。

**互校说明** 地皇三年落成另见。

### 6. 马适求谋起燕赵兵，王丹告发

[返回正文第6条](#hs-event-7)

<a id="hs099-l10519-e7"></a>

**[《汉书·王莽传》P203](../../sources/摘录/汉书-卷099-王莽传.md#p203)** · [仓内TXT L10519](../../sources/本地分卷/汉书/汉书-卷099.md#L10519)

### 7. 停大小钱，专行货布、货泉

[返回正文第7条](#hs-event-8)

<a id="hs099-l10521-e8"></a>

**[《汉书·王莽传》P205](../../sources/摘录/汉书-卷099-王莽传.md#p205)** · [仓内TXT L10521](../../sources/本地分卷/汉书/汉书-卷099.md#L10521)

> 是歲，罷大小錢，更行貨布，長二寸五分，廣一寸，直貨錢二十五。貨錢徑一寸，重五銖，枚直一。兩品並行。敢盜鑄錢及偏行布貨，伍人知不發舉，皆沒入為官奴婢。

**互校说明** 《食货志》天凤元年已造货布、货泉；地皇元年是旧钱退出的另一阶段。

### 8. 唐尊接平晏任太傅

[返回正文第8条](#hs-event-9)

<a id="hs099-l10522-e9"></a>

**[《汉书·王莽传》P206](../../sources/摘录/汉书-卷099-王莽传.md#p206)** · [仓内TXT L10522](../../sources/本地分卷/汉书/汉书-卷099.md#L10522)

> 太傅平晏死，以予虞唐尊為太傅。尊曰：「國虛民貧，咎在奢泰。」乃身短衣小袖，乘牝馬柴車，藉槁，瓦器，又以歷遺公卿。出見男女不異路者，尊自下車，以象刑赭幡汙染其衣。莽聞而說之，下詔申敕公卿思與厥齊。封尊為平化侯。

**互校说明** 平晏死后继任。

<a id="hs099-l10523-e10"></a>

**[《汉书·王莽传》P207](../../sources/摘录/汉书-卷099-王莽传.md#p207)** · [仓内TXT L10523](../../sources/本地分卷/汉书/汉书-卷099.md#L10523)

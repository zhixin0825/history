# 公元21年｜王临案与地皇末年政局

[← 公元20年](ce-0020.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元22年 →](ce-0022.md)

**新莽地皇二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **改置牧监副。** 以州牧虽居高位而监察懈怠，改设牧监副，主事近汉刺史。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **王莽妻死及王临案。** 王莽妻葬渭陵长寿园西；追叙其因多子被杀失明，王临与原碧的事败露后获罪。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **王安病死。** 新迁王王安病死，叙王莽早年在新都有子女，因身份疑而久留故里，此后安排其去处。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **李焉、王况因图谶被治。** 王况以田制、币制与兵役之失预言汉复兴，劝魏成大尹李焉用李姓附会，事发被治。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **三辅增捕盗都尉，王莽分遣将兵。** 三辅盗众，新设捕盗都尉，派景尚、王党等出兵青徐，曹放助攻句町，并转运钱谷。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **霜、蝗与关东大饥。** 秋霜杀豆，关东饥荒兼蝗害。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **瓜田仪未及出降而死，获追号。** 储夏请招降，瓜田仪未出而死。王莽求尸立冢祠并追谥，希望招徕余众，未能收效。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **闰月大赦。** 闰月丙辰大赦，诏及原有公私丧服的解除。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **王莽遣使采择女子。** 阳成脩献符命及黄帝多女之说，王莽分使各地采选乡里所称淑女。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **毁铜人铭、击汉高庙。** 王莽恶梦中铜人及汉家铭文，命工斫铭，又遣人击高庙、以桃汤赭鞭行厌胜之举。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **秦丰、迟昭平聚众。** 面对新起诸部，群臣谀称不难平。公孙禄批评贼势和任人之失，传复列不同答议。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **田况在青徐发民自守。** 田况未经虎符发兵，以约束护郡，赤眉暂不入。先被责而又受任督青徐，后遭调离。 [[12]](#hs-note-12)

### 2. 王莽妻死及王临案

[返回正文第2条](#hs-event-2)

<a id="hs099-l10525-e2"></a>

**[《汉书·王莽传》P209](../../sources/摘录/汉书-卷099-王莽传.md#p209)** · [仓内TXT L10525](../../sources/本地分卷/汉书/汉书-卷099.md#L10525)

> 是月，莽妻死，諡曰孝睦皇后，葬渭陵長壽園西，令永侍文母，名陵曰億年。初莽妻以莽數殺其子，涕泣失明，莽令太子臨居中養焉。莽妻旁侍者原碧，莽幸之。後臨亦通焉，恐事泄，謀共殺莽。臨妻愔，國師公女，能為星，語臨宮中且有白衣會。臨喜，以為所謀且成。後貶為統義陽王，出在外第，愈憂恐。會莽妻病困，臨予書曰：「上於子孫至嚴，前長孫、中孫年俱三十而死。今臣臨復適三十，誠恐一旦不保中室，則不知死命所在！」莽侯妻疾，見其書，大怒，疑臨有惡意，不令得會喪。既葬，收原碧等考問，具服姦、謀殺狀。莽欲祕之，使殺案事使者司命從事，埋獄中，家不知所在。賜臨藥，臨不肯飲，自刺死。使侍中票騎將軍同說侯林賜魂衣璽韍，策書曰：「符命文立臨為統義陽王，此言新室即位三萬六千歲後，為臨之後者乃當龍陽而起。前過聽議者，以臨為太子，有烈風之變，輒順符命，立為統義陽王。在此之前，自此之後，不作信順，弗蒙厥佑，夭年隕命，嗚呼哀哉！跡行賜諡，諡曰繆王。」又詔國師公：「臨本不知星，事從愔起。」愔亦自殺。

**互校说明** 本传二年正月，传次叙王临先前私情及获罪。

### 3. 王安病死

[返回正文第3条](#hs-event-3)

<a id="hs099-l10526-e3"></a>

**[《汉书·王莽传》P210](../../sources/摘录/汉书-卷099-王莽传.md#p210)** · [仓内TXT L10526](../../sources/本地分卷/汉书/汉书-卷099.md#L10526)

> 是月，新遷王安病死。初，莽為侯就國時，幸侍者增秩、懷能、開明。懷能生男興，增秩生男匡、女嘱，開明生女捷，皆留新都國，以其不明故也。及安疾甚，莽自病無子，為安作奏，使上言：「興等母雖微賤，屬猶皇子，不可以棄。」章視群公，皆曰：「安友于兄弟，宜及春夏加封爵。」於是以王車遣使者迎興等，封興為功脩公，匡為功建公，嘱為睦脩任，捷為睦逮任。孫公明公壽病死，旬月四喪焉。莽壞漢孝武、孝昭廟，分葬子孫其中。

**互校说明** 和上一段同月。

### 4. 李焉、王况因图谶被治

[返回正文第4条](#hs-event-4)

<a id="hs099-l10527-e4"></a>

**[《汉书·王莽传》P211](../../sources/摘录/汉书-卷099-王莽传.md#p211)** · [仓内TXT L10527](../../sources/本地分卷/汉书/汉书-卷099.md#L10527)

> 魏成大尹李焉與卜者王況謀，況謂焉曰：「新室即位以來，民田奴婢不得賣買，數改錢貨，徵發煩數，軍旅騷動，四夷並侵，百姓怨恨，盜賊並起，漢家當復興。君姓李，李音徵，徵火也，當為漢輔。」因為焉作讖書，言「文帝發忿，居地下趣軍，北告匈奴，南告越人。江中劉信，執敵報怨，復續古先，四年當發軍。江湖有盜，自稱樊王，姓為劉氏，萬人成行，不受赦令，欲動秦、雒陽。十一年當相攻，太白揚光，歲星入東井，其號當行。」又言莽大臣吉凶，各有日期。會合十餘萬言。焉令吏寫其書，吏亡告之。莽遣使者即捕焉，獄治皆死。

**互校说明** 在二年内。

<a id="hs099-l10531-e4"></a>

**[《汉书·王莽传》P215](../../sources/摘录/汉书-卷099-王莽传.md#p215)** · [仓内TXT L10531](../../sources/本地分卷/汉书/汉书-卷099.md#L10531)

> 莽以王況讖言荊楚當興，李氏為輔，欲厭之，乃拜侍中掌牧大夫李棽為大將軍、揚州牧，賜名聖，使將兵奮擊。

**互校说明** 王莽托谶解释所授姓名。

### 5. 三辅增捕盗都尉，王莽分遣将兵

**[《汉书·王莽传》P212](../../sources/摘录/汉书-卷099-王莽传.md#p212)** · [仓内TXT L10528](../../sources/本地分卷/汉书/汉书-卷099.md#L10528)

### 10. 毁铜人铭、击汉高庙

[返回正文第10条](#hs-event-10)

<a id="hs099-l10535-e10"></a>

**[《汉书·王莽传》P219](../../sources/摘录/汉书-卷099-王莽传.md#p219)** · [仓内TXT L10535](../../sources/本地分卷/汉书/汉书-卷099.md#L10535)

> 莽夢長樂宮銅人五枚起立，莽惡之，念銅人銘有「皇帝初兼天下」之文，即使尚方工鐫滅所夢銅人膺文。又感漢高廟神靈，遣虎賁武士入高廟，拔劍四面提擊，斧壞戶牖，桃湯赭鞭鞭灑屋壁，令輕車校尉居其中，又令中軍北壘居高寢。

**互校说明** 传写王莽厌胜。

<a id="hs099-l10536-e10"></a>

**[《汉书·王莽传》P220](../../sources/摘录/汉书-卷099-王莽传.md#p220)** · [仓内TXT L10536](../../sources/本地分卷/汉书/汉书-卷099.md#L10536)

> 或言黃帝時建華蓋以登僊，莽乃造華蓋九重，高八丈一尺，金瑵羽葆，載以祕機四輪車，駕六馬，力士三百人黃衣幘，車上人擊鼓，輓者皆呼「登僊」。莽出，令在前。百官竊言「此似狈車，非僊物也。」

**互校说明** 接二年叙事。

### 11. 秦丰、迟昭平聚众

[返回正文第11条](#hs-event-11)

<a id="hs099-l10537-e11"></a>

**[《汉书·王莽传》P221](../../sources/摘录/汉书-卷099-王莽传.md#p221)** · [仓内TXT L10537](../../sources/本地分卷/汉书/汉书-卷099.md#L10537)

> 是歲，南郡秦豐眾且萬人。平原女子遲昭平能說經博以八投，亦聚數千人在河阻中。莽召問群臣禽賊方略，皆曰：「此天囚行尸，命在漏刻。」故左將軍公孫祿徵來與議，祿曰：「太史令宗宣典星曆，候氣變，以凶為吉，亂天文，誤朝廷。太傅平化侯飾虛偽以媮名位，『賊夫人之子』。國師嘉信公顛倒五經，毀師法，令學士疑惑。明學男張邯、地理侯孫陽造井田，使民棄土業。犧和魯匡設六筦，以窮工商。說符侯崔發阿諛取容，令下情不上通。宜誅此數子以慰天下！」又言：「匈奴不可攻，當與和親。臣恐新室憂不在匈奴，而在封域之中也。」莽怒，使虎賁扶祿出。然頗采其言，左遷魯匡為五原卒正，以百姓怨非故。六筦非匡所獨造，莽厭眾意而出之。

**互校说明** 本传地皇二年，以公孙禄廷议互读。

### 12. 田况在青徐发民自守

[返回正文第12条](#hs-event-12)

<a id="hs099-l10539-e12"></a>

**[《汉书·王莽传》P223](../../sources/摘录/汉书-卷099-王莽传.md#p223)** · [仓内TXT L10539](../../sources/本地分卷/汉书/汉书-卷099.md#L10539)

> 唯翼平連率田況素果敢，發民年十八以上四萬餘人，授以庫兵，與刻石為約。赤糜聞之，不敢入界。況自劾奏，莽讓況：「未賜虎符而擅發兵，此弄兵也，厥罪乏興。以況自詭必禽滅賊，故且勿治。」後況自請出界擊賊，所嚮皆破。莽以璽書令況領青、徐二州牧事。況上言：「盜賊始發，其原甚微，非部吏、伍人所能禽也。咎在長吏不為意，縣欺其郡，郡欺朝廷，實百言十，實千言百。朝廷忽略，不輒督責，遂至延曼連州，乃遣將率，多發使者，傳相監趣。郡縣力事上官，應塞詰對，共酒食，具資用，以救斷斬，不給復憂盜賊治官事。將率又不能躬率吏士，戰則為賊所破，吏氣寖傷，徒費百姓。前幸蒙赦令，賊欲解散，或反遮擊，恐入山谷轉相告語，故郡縣降賊，皆更驚駭，恐見詐滅，因饑饉易動，旬日之間更十餘萬人，此盜賊所以多之故也。今雒陽以東，米石二千。竊見詔書，欲遣太師、更始將軍，二人爪牙重臣，多從人眾，道上空竭，少則亡以威視遠方。宜急選牧、尹以下，明其賞罰，收合離鄉。小國無城郭者，徙其老弱置大城中，積藏穀食，并力固守。賊來攻城，剛不能下，所過無食，勢不得群聚。如此，招之必降，擊之則滅。今空復多出將率，郡縣苦之，反甚於賊。宜盡徵還乘傳諸使者，以休息郡縣。委任臣況以二州盜賊，必平定之。」莽畏惡況，陰為發代，遣使者賜況璽書。使者至，見況，因令代監其兵。況隨使者西，到，拜為師尉大夫。況去，齊地遂敗。

**互校说明** 本传地皇二年，赤眉不入界与后来田况被调分叙。

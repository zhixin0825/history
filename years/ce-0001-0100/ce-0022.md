1. **刘秀第一次登场以前。** 刘秀是汉景帝之子长沙定王刘发的后代。九岁丧父，由叔父刘良抚养。《后汉书》特别写他年轻时勤于农事，和喜欢结交豪侠的长兄刘縯性格不同；王莽天凤年间，他还到长安学过《尚书》。这些是人物背景，**放在22年首次登场旁补叙，不等于都发生在22年**。 [[1]](#note-1)

<a id="22年南阳饥荒把刘氏宗族推入乱局"></a>

<a id="event-2"></a>

2. **22年：南阳饥荒，把刘氏宗族推入乱局。** 王莽末年灾荒、盗贼四起，南阳尤其缺粮。刘秀一度在新野躲避官吏，又到宛卖谷。宛人李通家长期相信“刘氏复兴、李氏为辅”一类谶言，李通、李轶因此找刘秀商议起兵。刘秀起初没有直接接受这种说法，但他判断王莽政权已经摇摇欲坠，兄长刘縯也早有举事打算，于是加入谋划。十月，刘秀与李轶等在宛起兵。 [[2]](#note-2)

   回到舂陵后，宗族子弟起初怕刘縯把大家拖去送死；看到一向谨慎的刘秀也穿上将军服加入，才逐渐安定。新市、平林等部也与刘縯合流。刘秀最初甚至没有战马，《后汉书》写他先骑牛作战，攻杀新野尉后才得到马。部队攻下棘阳后，在小长安聚遭王莽军重创，刘氏宗族多人战死，只得退回棘阳。

   这里《资治通鉴》补出了刘秀、刘縯家世、李通谋划以及小长安败战的更长背景；它和《后汉书》关系密切，不能把两书相同叙述当作两份互相独立的现代证据。

<a id="hs-event-3"></a>

3. **九庙成，王莽纳神主。** 地皇三年正月九庙成，王莽盛仪谒庙，给参与营造的官吏钱爵。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **霸桥起火。** 数千人救火不灭，王莽以帝王德运附会灾象，下书改桥等称谓。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **赤眉杀景尚。** 二月记赤眉杀太师牺仲景尚；同时关东严重饥荒。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **王匡、廉丹率军东征。** 四月二军出发，雨湿军士衣。赐诏将灾饥与征讨联系，并令宣慰。 [[6]](#hs-note-6)

<a id="hs-event-7"></a>

7. **草木酪、开放山泽等赈饥。** 使者教民以草木制酪而难食，反添劳费；王莽又下令放宽山泽采取以济饥。 [[7]](#hs-note-7)

<a id="hs-event-8"></a>

8. **飞蝗从东方到长安并入宫。** 蝗自东来至长安甚至入宫，朝廷设赏督捕。 [[8]](#hs-note-8)

<a id="hs-event-9"></a>

9. **廉丹、王匡攻拔无盐。** 索卢恢等按城起兵，廉丹、王匡攻拔，传书死者众，莽随后封赏。 [[9]](#hs-note-9)

<a id="hs-event-10"></a>

10. **新军成昌兵败，廉丹死。** 王匡不待士卒休整便进击董宪等，战败逃走；廉丹交印令其走而亲自战死。 [[10]](#hs-note-10)

<a id="hs-event-11"></a>

11. **王莽增派哀章等守东线。** 哀章自比黄帝旧将，请与王匡并力。王莽派阳浚守敖仓，王寻屯洛阳等地。 [[11]](#hs-note-11)

<a id="hs-event-12"></a>

12. **王莽拟废旧禁，未及全面施行。** 各地起兵攻城，王莽拟撤井田、奴婢、山泽六筦等禁，由使者分行，传书局势急而未及施行。 [[12]](#hs-note-12)

<a id="hs-event-13"></a>

13. **十一月见张宿孛星。** 十一月孛星东南行。术士安慰王莽群盗将灭，属于当时占断。 [[13]](#hs-note-13)

[返回正文第4条](#hs-event-4)

<a id="hs099-l10541-e4"></a>

> 二月，霸橋災，數千人以水沃救，不滅。莽惡之，下書曰：「夫三皇象春，五帝象夏，三王象秋，五伯象冬。皇王，德運也；伯者，繼空續乏以成曆數，故其道駮。惟常安御道多以所近為名。乃二月癸巳之夜，甲午之辰，火燒霸橋，從東方西行，至甲午夕，橋盡火滅。大司空行視考問，或云寒民舍居橋下，疑以火自燎，為此災也。其明旦即乙未，立春之日也。予以神明聖祖黃虞遺統受命，至于地皇四年為十五年。正以三年終冬絕滅霸駮之橋，欲以興成新室統壹長存之道也。又戒此橋空東方之道。今東方歲荒民飢，道路不通，東岳太師亟科條，開東方諸倉，賑貸窮乏，以施仁道。其更名霸館為長存館，霸橋為長存橋。」

### 12. 王莽拟废旧禁，未及全面施行

[返回正文第12条](#hs-event-12)

<a id="hs099-l10552-e12"></a>

**[《汉书·王莽传》P236](../../sources/摘录/汉书-卷099-王莽传.md#p236)** · [仓内TXT L10552](../../sources/本地分卷/汉书/汉书-卷099.md#L10552)

> 四方盜賊往往數萬人攻城邑，殺二千石以下。太師王匡等戰數不利。莽知天下潰畔，事窮計迫，乃議遣風俗大夫司國憲等分行天下，除井田奴婢山澤六筦之禁，即位以來詔令不便於民者皆收還之。待見未發，會世祖與兄齊武王伯升、宛人李通等帥舂陵子弟數千人，招致新巿平林朱鮪、陳牧等合攻拔棘陽。是時嚴尤、陳茂破下江兵，成丹、王常等數千人別走，入南陽界。

**互校说明** 地皇三年末，与地皇四年各地兵事相接；与此前局部放宽买卖有别。

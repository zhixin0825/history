## 本年概述

更始三年、建武元年。刘秀先在河北击败尤来、大枪、五幡，诸将屡劝即位，六月他在鄗南称帝，改元建武。邓禹西取河东，吴汉围取洛阳；朱鲔归降之后，刘秀十月入洛阳定都。

关内，方望拥立刘婴而败。赤眉六月拥立刘盆子，九月攻入长安，年底杀更始帝刘玄。公孙述在蜀称帝，刘永也在睢阳称帝，刘秀新朝与各地势力继续交战。

## 河北战事与鄗南即位

<a id="ce0025-event-1"></a>

<a id="25年称帝但远没有统一天下"></a>

<a id="event-1"></a>

<a id="hh-event-15"></a>

1. **刘秀北平尤来等部，诸将劝进，六月即位。** 刘秀从元氏追击尤来、大枪、五幡到右北平，在顺水北因乘胜轻进而败，王丰让马，耿弇射退追兵，余部退保范阳。吴汉在军中稳定众心，刘秀复进安次击败敌军，又命吴汉率十二将军在潞东、平谷追破其众。马武先请即尊位；刘秀过范阳收葬吏士，到中山、南平棘再受劝进。耿纯说追随者离乡冒死，迟迟不定名位，恐人心离散。至鄗，彊华献赤伏符，群臣据以再请。六月己未，刘秀在鄗南设坛告天，即皇帝位、改元建武。 [[1]](#ce0025-note-1)

<a id="ce0025-event-2"></a>

<a id="hh-event-8"></a>

2. **邓禹破箕关入河东，在安邑击败王匡。** 正月邓禹自箕关入河东，河东都尉闭关拒守，邓禹攻十日破之，获辎重千余乘。六月甲子，他在安邑击败更始定国公王匡，斩其将刘均。 [[2]](#ce0025-note-2)

## 洛阳定都与朝廷任官

3. **吴汉围洛阳，朱鲔降，刘秀入洛定都。** 朱鲔先遣苏茂攻温，被冯异、寇恂击败，将领贾彊战死。七月刘秀到怀，令耿弇、陈俊扼五社津，吴汉率朱祐、岑彭、贾复等十一将军围洛阳。八月祭社稷，于怀宫祠高祖、太宗、世宗，进至河阳。九月辛卯朱鲔献城，十月癸丑刘秀入南宫却非殿，遂定都洛阳。杜诗岁中三迁为侍御史，安集洛阳；丁綝任河南太守。入洛阳后又遣吴汉等击檀乡，至次年正月在邺东大破其众。 [[3]](#ce0025-note-3)

4. **刘秀任三公、太傅并封授旧臣。** 七月拜邓禹大司徒、王梁大司空、吴汉大司马，同时授景丹、耿弇、盖延、朱祐、杜茂军职；九月任卓茂为太傅，赐侯爵。邳彤本年改封灵寿侯、行大司空事，入洛阳后拜太常。宣秉拜御史中丞。王泓以父王丹曾为将军战死，又与刘秀有旧，受封武桓侯。 [[4]](#ce0025-note-4)

5. **郭贵人生刘强，光武迎阴贵人。** 郭贵人本年生皇子刘强。刘秀遣使到新野迎阴贵人，并征其兄阴识。 [[5]](#ce0025-note-5)

## 更始、赤眉与诸地称帝

<a id="ce0025-event-6"></a>

6. **方望立刘婴，更始军攻破临泾。** 正月，平陵人方望等迎前孺子刘婴至临泾，立为天子。更始遣丞相李松击破临泾，刘婴被杀。 [[6]](#ce0025-note-6)

<a id="ce0025-event-7"></a>

<a id="hs-event-3"></a>

<a id="hs-event-4"></a>

<a id="hh-event-16"></a>

7. **赤眉拥立刘盆子，入长安而杀更始。** 六月樊崇、逢安等拥立刘盆子。九月赤眉入长安，刘玄逃到高陵，刘秀辛未诏封刘玄为淮阳王，禁止吏民加害。刘玄后来归降赤眉，十二月被杀。赤眉欲降曹竟，曹竟持剑抗拒而死；曾奉更始之命出使匈奴的陈遵留在朔方，更始失败时也遭当地武装杀害。 [[7]](#ce0025-note-7)

<a id="ce0025-event-8"></a>

<a id="hh-event-7"></a>

8. **公孙述称帝于蜀，刘永称帝于睢阳。** 四月公孙述在蜀自立为天子，号成家。梁王刘永随后自称天子。年底隗嚣仍据陇右，卢芳起于安定。 [[8]](#ce0025-note-8)

> 光武皇帝，著紀以景帝後高祖九世孫受命中興復漢，改元曰建武

**[固定版本](../../sources/摘录/后汉书-卷001-光武帝纪-22至25年原文.md#L24)**

> 光武北擊尤來、大搶、五幡於元氏，追至右北平，連破之。又戰於順水北，乘勝輕進，反為所敗。賊追急，短兵接，光武自投高岸，遇突騎王豐，下馬授光武，光武撫其肩而上，顧笑謂耿弇曰：「幾為虜嗤。」弇頻射卻賊，得免。士卒死者數千人，散兵歸保范陽。軍中不見光武，或雲已歿，諸將不知所為。吳漢曰：「卿曹努力！王兄子在南陽，何憂無主？」衆恐懼，數日乃定。賊雖戰勝，而素懾大威，客主不相知，夜遂引去。大軍復進至安次，與戰，破之，斬首三千餘級。賊入漁陽，乃遣吳漢率耿弇、陳俊、馬武等十二將軍追戰於潞東，及平谷，大破滅之。
>
> 於是諸將議上尊號。馬武先進曰：「天下無主。如有聖人承敝而起，雖仲尼為相，孫子為將，猶恐無能有益。反水不收，後悔無及。大王雖執謙退，柰宗廟社稷何！冝且還薊即尊位，乃議征伐。今此誰賊而馳騖擊之乎？」光武驚曰：「何將軍出是言？可斬也！」武曰：「諸將盡然。」光武使出曉之，乃引軍還至薊。
>
> 光武從薊還，過范陽，命收葬吏士。至中山，諸將復上奏曰：「漢遭王莽，宗廟廢絕，豪傑憤怒，兆人塗炭。王與伯升首舉義兵，更始因其資以據帝位，而不能奉承大統，敗亂綱紀，盜賊日多，羣生危蹙。大王初征昆陽，王莽自潰；後拔邯鄲，北州弭定；參分天下而有其二，跨州據土，帶甲百萬。言武力則莫之敢抗，論文德則無所與辭。臣聞帝王不可以乆曠，天命不可以謙拒，惟大王以社稷為計，萬姓為心。」光武又不聽。
>
> 行到南平棘，諸將復固請之。光武曰：「寇賊未平，四面受敵，何遽欲正號位乎？諸將且出。」耿純進曰：「天下士大夫捐親戚，棄土壤，從大王於矢石之閒者，其計固望其攀龍鱗，附鳳翼，以成其所志耳。今功業即定，天人亦應，而大王留時逆衆，不正號位，純恐士大夫望絕計窮，則有去歸之思，無為乆自苦也。大衆一散，難可復合。時不可留，衆不可逆。」純言甚誠切，光武深感，曰：「吾將思之。」
>
> 行至鄗，光武先在長安時同舍生彊華自關中奉赤伏符，曰「劉秀發兵捕不道，四夷雲集龍鬬野，四七之際火為主」。羣臣因復奏曰：「受命之符，人應為大，萬里合信，不議同情，周之白魚，曷足比焉？今上無天子，海內淆亂，符瑞之應，昭然著聞，冝荅天神，以塞羣望。」光武於是命有司設壇場於鄗南千秋亭五成陌。

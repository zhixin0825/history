1. **25年：称帝，但远没有统一天下。** 年初刘秀仍在河北作战，甚至在顺水北一度因轻进而战败，部队一时误以为他已经战死。此后他恢复攻势。随着更始政权继续崩坏，诸将不断劝他即皇帝位。刘秀起初拒绝，耿纯的理由很现实：追随者放弃家产、冒死从军，本来就希望建立新政权；如果一直不给明确的政治归宿，队伍可能自行散掉。 本年春正月，方望等在临泾另立前孺子刘婴，更始遣丞相李松击破，刘婴被杀。 [[1]](#note-1)

   六月己未，刘秀在鄗南即皇帝位，改元建武。史书把赤伏符等谶纬写进了即位过程；整理时应把它当作当时政治合法性叙事的一部分，而不是把符命本身当作历史因果。就在同一个月，赤眉军也立刘盆子为帝。四月称帝的公孙述仍据巴蜀，更始帝也尚未立刻退出历史舞台，所以“刘秀称帝”绝不能写成“东汉至此已经统一”。

   七月，刘秀任命邓禹为大司徒、吴汉为大司马等，开始搭建朝廷。九月赤眉进入长安，更始帝刘玄出逃。刘秀下诏封刘玄为淮阳王。同月辛卯，朱鲔献洛阳投降。十月癸丑，刘秀进入洛阳南宫，定都洛阳。十二月，更始帝被赤眉杀死。此时关中、陇右、巴蜀、山东等地仍存在多个独立势力，建武战争继续多年。

<a id="hs-event-2"></a>

2. **武桓侯王泓受封。** 《恩泽侯表》记建武元年封王泓为武桓侯，缘于其父王丹以将军战死和王泓与光武帝有旧。王丹战死未载确年。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **赤眉入长安时曹竟拒降而死。** 赤眉入长安后要曹竟归降，曹竟持剑抗拒而死。此前更始延揽、曹竟不受侯爵见本传同段。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **陈遵在朔方遇害。** 更始政权败亡前后，曾出使匈奴的陈遵留在朔方，为当地反抗势力所杀。 [[4]](#hs-note-4)

8. **禹自箕关将入河东，河东都尉守关不开，禹攻十日，破之，获辎重千余乘。** 建武元年正月，禹自箕关将入河东，河东都尉守关不开，禹攻十日，破之，获辎重千余乘。 [[8]](#hh-note-8)

11. **拜御史中丞。** 建武元年，拜御史中丞。 [[11]](#hh-note-11)

12. **岁中三迁为侍御史，安集洛阳。** 建武元年，岁中三迁为侍御史，安集洛阳。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **光武遣使迎阴贵人於新野，并徵识。** 建武元年，光武遣使迎阴贵人于新野，并徵识。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **拜河南太守。** 建武元年，拜河南太守。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **已前，文书散亡，旧典不具，不能明经文，以章句细微相况八十一卷，明者爲验，又其十卷，皆不昭晰。** 建武元年，已前，文书散亡，旧典不具，不能明经文，以章句细微相况八十一卷，明者爲验，又其十卷，皆不昭晰。 [[15]](#hh-note-15)

> 
> 朱鮪遣討難將軍蘇茂攻溫，馮異、寇恂與戰，大破之，斬其將賈彊。
> 
> 於是諸將議上尊號。馬武先進曰：「天下無主。如有聖人承敝而起，雖仲尼為相，孫子為將，猶恐無能有益。反水不收，後悔無及。大王雖執謙退，柰宗廟社稷何！冝且還薊即尊位，乃議征伐。今此誰賊而馳騖擊之乎？」光武驚曰：「何將軍出是言？可斬也！」武曰：「諸將盡然。」光武使出曉之，乃引軍還至薊。

> 
> 行到南平棘，諸將復固請之。光武曰：「寇賊未平，四面受敵，何遽欲正號位乎？諸將且出。」耿純進曰：「天下士大夫捐親戚，棄土壤，從大王於矢石之閒者，其計固望其攀龍鱗，附鳳翼，以成其所志耳。今功業即定，天人亦應，而大王留時逆衆，不正號位，純恐士大夫望絕計窮，則有去歸之思，無為乆自苦也。大衆一散，難可復合。時不可留，衆不可逆。」純言甚誠切，光武深感，曰：「吾將思之。」
>

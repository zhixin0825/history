# 公元26年｜安衆康侯丹一支封爵后续

[← 公元25年](ce-0025.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元28年 →](ce-0028.md)

**汉光武帝建武二年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **安衆康侯丹一支封爵后续。** 建武二年以崇从父弟接续旧封。 [[1]](#hs-note-1)

<a id="hs-event-2"></a>

2. **平阳侯曹宏｜承爵。** 表载平阳侯曹宏一支本年记载侯位承袭。表中所载事项为侯宏承爵，因本始子举兵佐军，接续封爵。 [[2]](#hs-note-2)

<a id="hs-event-3"></a>

3. **高昌壮侯董忠｜绍封。** 表载高昌壮侯董忠一支本年接续了原有封爵。表中所载事项为五月己巳，侯永接续封爵。 [[3]](#hs-note-3)

<a id="hs-event-4"></a>

4. **归德靖侯先贤掸｜承爵。** 表载归德靖侯先贤掸一支本年记载侯位承袭。表中所载事项为侯襄承爵。 [[4]](#hs-note-4)

<a id="hs-event-5"></a>

5. **周子南君姬嘉｜改封。** 表载周子南君姬嘉一支本年爵号或封邑改易。表中所载事项为五月戊辰更为周承休侯。 [[5]](#hs-note-5)

<a id="hs-event-6"></a>

6. **平阿安侯王谭｜去世。** 表载平阿安侯王谭一支本年记载去世。表中所载事项为去世，爵祀中止。 [[6]](#hs-note-6)

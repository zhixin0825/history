1. **以偏将军冯异为征西大将军。** 三年春正月甲子，以偏将军冯异为征西大将军，杜茂为骠骑大将军，大司徒邓禹及冯异与赤眉战于回溪，禹、异败绩。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **征虏将军祭遵破蛮中，斩张满。** [[2]](#hh-note-2)

<a id="hh-event-4"></a>

4. **大赦天下。** 壬午，颁布大赦。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **闰月乙巳，大司徒邓禹免。** [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **冯异与赤眉战於崤底，大破之，余衆南向冝阳，帝自将征之。** 冯异与赤眉战于崤底，大破之，余衆南向冝阳，帝自将征之。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **幸冝阳。** 己亥，幸冝阳。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **亲勒六军，大陈戎马，大司马吴汉精卒当前，中军次之，骁骑、武衞分陈左右。** 甲辰，亲勒六军，大陈戎马，大司马吴汉精卒当前，中军次之，骁骑、武衞分陈左右。 [[8]](#hh-note-8)

9. **赤眉望见震怖，遣使乞降。** [[9]](#hh-note-9)

10. **赤眉君臣面缚，奉高皇帝玺绶，诏以属城门校尉。** 丙午，赤眉君臣面缚，奉高皇帝玺绶，诏以属城门校尉。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **至自冝阳，己酉，诏曰。** 戊申，至自冝阳，己酉，诏曰：「群盗纵横，贼害元元，盆子窃尊号，乱惑天下。朕奋兵讨击，应时崩解，十余万衆束手降服，先帝玺绶归之王府。斯皆祖宗之灵，士人之力，朕曷足以享斯哉！其择吉日祠高庙，赐天下长子当为父后者爵，人一级。」 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **祠高庙，受传国玺。** 二月己未，祠高庙，受传国玺。 [[12]](#hh-note-12)

13. **刘永立董宪为海西王，张步为齐王。** [[13]](#hh-note-13)

<a id="hh-event-28"></a>

28. **诏曰“吏不满六百石”。** 庚辰，诏曰：「吏不满六百石，下至墨绶长、相，有罪先请。男子八十以上，十岁以下，及妇人从坐者，自非不道，诏所名捕，皆不得系。当验问者即就验。女徒雇山归家。」 [[28]](#hh-note-28)

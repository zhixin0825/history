<a id="hh-event-1"></a>

1. **改舂陵郷为章陵县。** 六年春正月丙辰，改舂陵郷为章陵县。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **世世复傜役，比丰、沛，无有所豫。** [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **诏曰“往岁水旱蝗虫为灾”。** 辛酉，诏曰：「往岁水旱蝗虫为灾，谷价腾跃，人用困乏。朕惟百姓无以自赡，恻然愍之。其命郡国有谷者，给禀高年、鳏、寡、孤、独及笃［］、无家属贫不能自存者，如律。二千石勉加循抚，无令失职。」 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **扬武将军马成等拔舒，获李宪。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **大司马吴汉拔朐，获董宪、庞萌，山东悉平。** 二月，大司马吴汉拔朐，获董宪、庞萌，山东悉平。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **诸将还京师，置酒赏赐。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **公孙述遣将任满寇南郡。** 三月，公孙述遣将任满寇南郡。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **幸长安，始谒高庙，遂有事十一陵。** 夏四月丙子，前往长安，始谒高庙，遂有事十一陵。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **遣虎牙大将军盖延等七将军从陇道伐公孙述。** [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **至自长安。** 五月己未，至自长安。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **隗嚻反，盖延等因与嚻战於陇阺，诸将败绩。** 隗嚻反，盖延等因与嚻战于陇阺，诸将败绩。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **诏曰“惟天水、陇西、安定、北地吏人为隗”。** 辛丑，诏曰：「惟天水、陇西、安定、北地吏人为隗嚻所诖误者，又三辅遭难赤眉，有犯法不道者，自殊死以下，皆赦除之。」 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **诏曰“夫张官置吏”。** 六月辛卯，诏曰：「夫张官置吏，所以为人也。今百姓遭难，户口耗少，而县官吏职所置尚繁，其令司隷、州牧各实所部，省减吏员。县国不足置长吏可并合者，上大司徒、大司空二府。」于是条奏并省四百余县，吏职减损，十置其一。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **代郡太守刘兴击卢芳将贾览於高柳，战殁。** 代郡太守刘兴击卢芳将贾览于高柳，战殁。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **初，乐浪人王调据郡不服。** [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **遣乐浪太守王遵击之，郡吏杀调降。** 秋，遣乐浪太守王遵击之，郡吏杀调降。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **遣前将军李通率二将军，与公孙述将战於西城，破之。** 遣前将军李通率二将军，与公孙述将战于西城，破之。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **蝗。** 夏，蝗。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **赦乐浪谋反大逆殊死已下。** 秋九月庚子，赦乐浪谋反大逆殊死已下。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **日有食之。** 丙寅晦，发生日食。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **诏曰“吾德薄不明”。** 冬十月丁丑，诏曰：「吾德薄不明，寇贼为害，强弱相陵，元元失所。诗云：『日月告凶，不用其行。』永念厥咎，内疚于心。其勑公卿举贤良、方正各一人；百僚并上封事，无有隐讳；有司修职，务遵法度。」 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **诏王莽时吏人没入为奴婢不应旧法者，皆免为庶人。** 十一月丁卯，诏王莽时吏人没入为奴婢不应旧法者，皆免为庶人。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **大司空宋弘免。** 十二月壬辰，大司空宋弘免。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **诏曰“顷者师旅未解”。** 癸巳，诏曰：「顷者师旅未解，用度不足，故行十一之税。今军士屯田，粮储差积。其命各郡国收见田租三十税一，如旧制。」 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **隗嚻遣将行巡寇扶风，征西大将军冯异拒破之。** [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **是岁，初罢郡国都尉官。** 当年，初罢郡国都尉官。 [[26]](#hh-note-26)

<a id="hh-event-27"></a>

27. **始遣列侯就国。** [[27]](#hh-note-27)

<a id="hh-event-28"></a>

28. **匈奴遣使来献，使中郎将报命。** 匈奴派使者进献，使中郎将报命。 [[28]](#hh-note-28)

<a id="hh-event-29"></a>

29. **温序拒苟宇而死。** 温序任护羌校尉，行至襄武被隗嚣将领苟宇拘劫，拒绝投附而死。 [[29]](#hh-note-29)

<a id="hh-event-30"></a>

30. **弟成物故，嚣乃听林持丧东归。** 建武六年，弟成物故，嚣乃听林持丧东归。 [[30]](#hh-note-30)

<a id="hh-event-31"></a>

31. **日食，衍上书陈八事。** 建武六年，日食，衍上书陈八事：其一曰显文德，二曰褒武烈，三曰修旧功，四曰招俊杰，五曰明好恶，六曰简法令，七曰差秩禄，八曰抚边境。 [[31]](#hh-note-31)

<a id="hh-event-32"></a>

32. **都尉官省，拜太中大夫。** 建武六年，都尉官省，拜太中大夫。 [[32]](#hh-note-32)

<a id="hh-event-33"></a>

33. **光武遣太守王遵将兵击之。** 建武六年，光武遣太守王遵将兵击之。 [[33]](#hh-note-33)

<a id="hh-event-34"></a>

34. **征为洛阳令，政有能名。** 建武六年，征为洛阳令，政有能名。 [[34]](#hh-note-34)

<a id="hh-event-35"></a>

35. **省都尉官，遂弃领东地，悉封其渠帅为县侯，皆岁时朝贺。** 建武六年，省都尉官，遂弃领东地，悉封其渠帅为县侯，皆岁时朝贺。 [[35]](#hh-note-35)

<a id="hh-event-36"></a>

36. **世祖建武六年，蜀童谣曰。** 世祖建武六年，蜀童谣曰：「黄牛白腹，五铢当复。」 [[36]](#hh-note-36)

# 公元31年｜建武七年

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **诏中都官、三辅、郡、国出系囚，非犯殊死，皆一切勿案其罪。** 七年春正月丙申，诏中都官、三辅、郡、国出系囚，非犯殊死，皆一概停止审理其罪。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **见徒免为庶民。** [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **耐罪亡命，吏以文除之。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **又诏曰。** 又诏曰：「世以厚葬为德，薄终为鄙，至于富者奢僭，贫者单财，法令不能禁，礼义不能止，仓卒乃知其咎。其布告天下，令知忠臣、孝子、慈兄、悌弟薄葬送终之义。」 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **罢护漕都尉官。** 二月辛巳，罢护漕都尉官。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **诏曰“今国有衆军”。** 三月丁酉，诏曰：「今国有衆军，并多精勇，冝且罢轻车、骑士、材官、楼船士及军假吏，令还复民伍。」 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **公孙述立隗嚻为朔宁王。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **日有食之，避正殿，寑兵，不听事五日。** 癸亥晦，发生日食，避正殿，寑兵，不听事五日。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **诏曰“吾德薄致灾”。** 诏曰：「吾德薄致灾，讁见日月，战栗恐惧，夫何言哉！今方念愆，庶消厥咎。其令有司各修职任，奉遵法度，惠兹元元。百僚各上封事，无有所讳。其上书者，不得言圣。」 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **诏曰“比阴阳错谬”。** 夏四月壬午，诏曰：「比阴阳错谬，日月薄食。百姓有过，在予一人，颁布大赦。公、卿、司隷、州牧举贤良、方正各一人，遣到公车，朕将览试焉。」 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **前将军李通为大司空。** 五月戊戌，前将军李通为大司空。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **诏吏人遭饥乱及为青、徐贼所略为奴婢下妻，欲去留者，恣听之。** 甲寅，诏吏人遭饥乱及为青、徐贼所略为奴婢下妻，欲去留者，恣听之。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **敢拘制不还，以卖人法从事。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **是夏，连雨水。** [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **汉忠将军王常为横野大将军。** [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **封前河闲王邵为河闲王。** 八月丁亥，封前河闲王邵为河闲王。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **隗嚻寇安定，征西大将军冯异、征虏将军祭遵击却之。** [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **卢芳所置朔方太守田飒、云中太守乔扈各举郡降。** 冬，卢芳所置朔方太守田飒、云中太守乔扈各举郡降。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **是岁，省长水、射声二校尉官。** 当年，省长水、射声二校尉官。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **王梁开渠不成，被劾转任。** 王梁开渠以引谷水过京都，工程完工无水，有司弹劾，他上书请退。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **杜诗迁南阳太守，在任兴修水利与用水排。** 杜诗任南阳太守后以水排鼓风冶铸农具，并修陂池扩充耕地，发明的具体年月未载。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **诏书征刚。** 建武七年，诏书征刚。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **光武建武七年四月丙寅，日有晕抱，白虹贯晕，在毕八度。** [[23]](#hh-note-23)

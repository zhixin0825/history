<a id="hh-event-3"></a>

1. **赦非殊死系囚，放见徒并除逃亡罪。** 正月丙申，诏中都官、三辅、郡国释出非犯殊死的系囚，停止审理其罪。见徒免为庶人，处耐罪而逃亡者，由官吏依法除罪。 [[1]](#hh-note-1)

<a id="hh-event-4"></a>

2. **又诏曰。** 又诏曰：「世以厚葬为德，薄终为鄙，至于富者奢僭，贫者单财，法令不能禁，礼义不能止，仓卒乃知其咎。其布告天下，令知忠臣、孝子、慈兄、悌弟薄葬送终之义。」 [[2]](#hh-note-4)

<a id="hh-event-5"></a>

<a id="hh-event-6"></a>

<a id="hh-event-19"></a>

3. **罢护漕都尉，裁减军士与校尉。** 朝廷撤护漕都尉。三月丁酉，因已聚精兵甚多，诏遣轻车、骑士、材官、楼船士及军中假吏还归民伍。本年又省长水、射声二校尉。 [[3]](#hh-note-5)

<a id="hh-event-7"></a>

<a id="hh-event-17"></a>

4. **公孙述封隗嚣，隗嚣攻安定被退。** 公孙述封隗嚣为朔宁王。隗嚣来犯安定，冯异、祭遵将他击退。 [[4]](#hh-note-7)

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

<a id="hh-event-10"></a>

5. **日食后避殿停事，诏举贤良方正。** 日食在癸亥晦，光武避正殿、停兵，五日不听政，诏有司修职守法、百官密奏无讳，并禁止上书称圣。四月壬午，再下诏自责，大赦，令公卿、司隶、州牧各举贤良、方正一人，由光武亲自察试。 [[5]](#hh-note-8)

<a id="hh-event-11"></a>

6. **前将军李通为大司空。** 五月戊戌，前将军李通为大司空。 [[6]](#hh-note-11)

<a id="hh-event-12"></a>

<a id="hh-event-13"></a>

7. **遭掳为奴婢与下妻者可自行去留。** 甲寅，诏吏民遭饥乱或被青、徐贼所掳为奴婢、下妻者，听从本人意愿去留，敢拘制不放者按卖人之法治罪。 [[7]](#hh-note-12)

<a id="hh-event-14"></a>

8. **是夏，连雨水。** [[8]](#hh-note-14)

<a id="hh-event-15"></a>

9. **汉忠将军王常为横野大将军。** [[9]](#hh-note-15)

<a id="hh-event-16"></a>

10. **封前河闲王邵为河闲王。** 八月丁亥，封前河闲王邵为河闲王。 [[10]](#hh-note-16)

<a id="hh-event-18"></a>

11. **卢芳所置朔方太守田飒、云中太守乔扈各举郡降。** 冬，卢芳所置朔方太守田飒、云中太守乔扈各举郡降。 [[11]](#hh-note-18)

<a id="hh-event-20"></a>

12. **王梁开渠不成，被劾转任。** 王梁开渠以引谷水过京都，工程完工无水，有司弹劾，他上书请退。 [[12]](#hh-note-20)

<a id="hh-event-21"></a>

13. **杜诗迁南阳太守，在任兴修水利与用水排。** 杜诗出任南阳太守，在任时以水排鼓风铸造农具，并修治陂池，扩大耕地。 [[13]](#hh-note-21)

<a id="hh-event-22"></a>

14. **诏书征刚。** 建武七年，诏书征刚。 [[14]](#hh-note-22)

<a id="hh-event-23"></a>

15. **光武建武七年四月丙寅，日有晕抱，白虹贯晕，在毕八度。** [[15]](#hh-note-23)

<a id="sy-event-24"></a>

16. **镇星进入舆鬼星区。** 九月庚子，记镇星进入舆鬼星区。 [[16]](#sy-note-24)

<a id="hh031-l2609-e21"></a>

**[《后汉书·郭杜孔张廉王苏羊贾陆列传》](../../sources/摘录/后汉书-卷031-郭杜孔张廉王苏羊贾陆列传.md#p001)** · [仓内TXT L2609](../../sources/本地分卷/后汉书/后汉书-卷031.md#L2609)

1. **来歙夺略阳，光武征隗嚣，蜀援至后陇右再变。** 来歙袭略阳，杀隗嚣守将而据城，隗嚣反攻不克。郭宪劝光武勿亲征，光武仍于闰月赴陇右，窦融率河西五郡太守在高平会合。陇右军溃，隗嚣奔西城，吴汉、岑彭奉命围攻。颍川起事后光武自上邽东还。公孙述遣兵援隗嚣，吴汉、盖延等撤至长安，天水、陇西复归隗嚣。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **司隷校尉傅抗下狱死。** 夏四月，司隷校尉傅抗下狱后死亡。 [[2]](#hh-note-2)

<a id="hh-event-6"></a>

<a id="hh-event-8"></a>

3. **颍川、河东作乱，光武东还平颍川。** 颍川盗众攻陷属县，河东守军也叛，京师震动。光武八月从上邽昼夜东驰，九月乙卯还宫，庚申亲讨颍川，盗众归降，戊寅回宫。 [[3]](#hh-note-6)

<a id="hh-event-7"></a>

<a id="hh-event-18"></a>

4. **秋季大水。** 秋，大水。 [[4]](#hh-note-7)

<a id="hh-event-11"></a>

5. **安丘侯张步叛归琅邪，琅邪太守陈俊讨获之。** [[5]](#hh-note-11)

<a id="hh-event-13"></a>

<a id="hh-event-14"></a>

6. **光武幸怀后还宫。** 光武帝前往怀县，随后回宫。 [[6]](#hh-note-13)

<a id="hh-event-17"></a>

<a id="hh-event-20"></a>

7. **高句骊使者奉贡，光武恢复王号。** 高句骊遣使入朝奉贡，光武恢复其王号。 [[7]](#hh-note-17)

<a id="sy-event-21"></a>

8. **朱浮、许淑请修历。** 朱浮、许淑多次指出历法不准，请求更改。观测误差尚微，光武帝因天下初定而暂未深究。 [[8]](#sy-note-21)

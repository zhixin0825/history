<a id="hh-event-1"></a>

1. **中郎将来歙袭略阳，杀隗嚻守将而据其城。** 八年春正月，中郎将来歙袭略阳，杀隗嚻守将而据其城。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **司隷校尉傅抗下狱死。** 夏四月，司隷校尉傅抗下狱后死亡。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **隗嚻攻来歙，不能下。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **闰月，帝自征嚻，河西太守窦融率五郡太守与车驾会高平。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **陇右溃，隗嚻奔西城，遣大司马吴汉、征南大将军岑彭围之。** 陇右溃，隗嚻奔西城，遣大司马吴汉、征南大将军岑彭围之；进幸上邽，不降，命虎牙大将军盖延、建威大将军耿弇攻之。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **颍川盗贼寇没属县，河东守守兵亦叛，京师骚动。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **大水。** 秋，大水。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **帝自上邽晨夜东驰。** 八月，帝自上邽晨夜东驰。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **车驾还宫。** 九月乙卯，皇帝回宫。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **帝自征颍川盗贼，皆降。** 庚申，帝自征颍川盗贼，皆降。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **安丘侯张步叛归琅邪，琅邪太守陈俊讨获之。** [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **至自颍川。** 戊寅，至自颍川。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **幸怀。** 冬十月丙午，幸怀。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **至自怀。** 十一月乙丑，至自怀。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **公孙述遣兵救隗嚻，吴汉、盖延等还军长安。** [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **天水、陇西复反归嚻。** [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **高句丽王遣使奉贡。** 十二月，高句丽王遣使奉贡。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **是岁大水。** 当年大水。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **光武帝亲征隗嚣。** 郭宪劝光武勿亲自出兵，帝未从。颍川发生兵乱后，光武从陇地赶回。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **朝廷恢复高句骊王号。** 高句骊遣使来朝进贡，光武恢复其王号。 [[20]](#hh-note-20)

<a id="sy-event-21"></a>

21. **朱浮、许淑请修历。** 朱浮、许淑多次指出历法不准，请求更改。观测误差尚微，光武帝因天下初定而暂未深究。 [[21]](#sy-note-21)

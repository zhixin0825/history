1. **隗嚻病死，其将王元、周宗复立嚻子纯为王。** 九年春正月，隗嚻病死，其将王元、周宗复立嚻子纯为王。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **徙鴈门吏人於太原。** 徙鴈门吏人于太原。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **初置青巾左校尉官。** 三月辛亥，初置青巾左校尉官。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **公孙述遣将田戎、任满据荆门。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **幸缑氏，登轘辕。** 夏六月丙戌，幸缑氏，登轘辕。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **遣大司马吴汉率四将军击卢芳将贾览於高柳，战不利。** 遣大司马吴汉率四将军击卢芳将贾览于高柳，战不利。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **遣中郎将来歙监征西大将军冯异等五将军讨隗纯於天水。** 秋八月，派中郎将来歙监征西大将军冯异等五将军讨隗纯于天水。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **骠骑大将军杜茂与贾览战於繁畤，茂军败绩。** 骠骑大将军杜茂与贾览战于繁畤，茂军败绩。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **是岁，省关都尉，复置护羌校尉官。** 当年，省关都尉，复置护羌校尉官。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **牛邯任护羌校尉。** 隗嚣卒后班彪请复设护羌校尉，光武采纳，命牛邯持节领护。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **隗嚣死，司徒掾班彪上言。** 建武九年，隗嚣死，司徒掾班彪上言：「今凉州部皆有降羌，羌胡被发左衽，而与汉人杂处，习俗既异，言语不通。数为小吏黠人所见侵夺，穷恚无聊，故致反叛。夫蛮夷寇乱，皆为此也。旧制：益州部署蛮夷骑都尉，幽州部署领乌桓校尉，凉州部署护羌校尉，皆持节领护，理其怨结，岁时循行，问所疾苦。又数遣使驿通动静，使塞外羌夷为吏耳目，州郡因此可得儆备。今宜复如旧，以明威防。」 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **光武建武九年七月乙丑，金犯轩辕大星。** [[12]](#hh-note-12)

<a id="sgz-event-13"></a>

13. **东汉光武时阴贵人母弟遭劫。** 孙盛引《光武纪》，称建武九年贼劫持阴贵人母弟，吏受制不能逼贼，贼竟杀人。 [[13]](#sgz-note-13)

### 11. 隗嚣死，司徒掾班彪上言

[返回正文第11条](#hh-event-11)

<a id="hh087-l6464-e11"></a>

**[《后汉书·西羌传》](../../sources/摘录/后汉书-卷087-西羌传.md#p002)** · [仓内TXT L6464](../../sources/本地分卷/后汉书/后汉书-卷087.md#L6464)

> 建武九年，隗囂死，司徒掾班彪上言：「今涼州部皆有降羌，羌胡被髮左衽，而與漢人雜處，習俗既異，言語不通。數為小吏黠人所見侵奪，窮恚無聊，故致反叛。夫蠻夷寇亂，皆為此也。舊制：益州部署蠻夷騎都尉，幽州部署領烏桓校尉，涼州部署護羌校尉，皆持節領護，理其怨結，歲時循行，問所疾苦。又數遣使驛通動靜，使塞外羌夷為吏耳目，州郡因此可得儆備。今宜復如舊，以明威防。」

**归年与互校** 传文原载年号，节录该句。

# 公元34年｜建武十年

[← 公元33年](ce-0033.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元35年 →](ce-0035.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **大司马吴汉率捕虏将军王霸等五将军击贾览於高柳。** 十年春正月，大司马吴汉率捕虏将军王霸等五将军击贾览于高柳，匈奴遣骑救览，诸将与战，郤之。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **修理长安高庙。** [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **征西大将军冯异破公孙述将赵匡於天水，斩之。** 夏，征西大将军冯异破公孙述将赵匡于天水，斩之。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **征西大将军冯异薨。** 征西大将军冯异去世。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **幸长安，祠高庙，遂有事十一陵。** 秋八月己亥，前往长安，祠高庙，遂有事十一陵。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **进幸汧。** 戊戌，进幸汧。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **隗嚻将高峻降。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **中郎将来歙等大破隗纯於落门，其将王元奔蜀，纯与周宗降，陇右平。** 冬十月，中郎将来歙等大破隗纯于落门，其将王元奔蜀，纯与周宗降，陇右平。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **先零羌寇金城、陇西，来歙率诸将击羌於五谿，大破之。** 先零羌寇金城、陇西，来歙率诸将击羌于五谿，大破之。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **车驾还宫。** 庚寅，皇帝回宫。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **是岁，省定襄郡，徙其民於西河。** 当年，省定襄郡，徙其民于西河。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **泗水王歙薨。** 泗水王歙去世。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **淄川王终薨。** 淄川王终去世。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **张汜请修河汴。** 阳武令张汜奏请修防黄河、汴渠，光武先征发役卒，后又听乐俊议而停。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **流星如月，从太微出，入北斗魏第六星，色白。** 《天文志》记十年三月癸卯，流星如月，从太微出，入北斗魏第六星，色白。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **大流星如缶，出柳西南行，入轸。** 《天文志》记十二月己亥，大流星如缶，出柳西南行，入轸。 [[16]](#hh-note-16)

<a id="sy-event-17"></a>

17. **光武帝下诏沿用旧漏法。** 和帝时太史令等追述，光武帝于建武十年二月壬午下诏施行宣帝时颁行的官用漏法。 [[17]](#sy-note-17)

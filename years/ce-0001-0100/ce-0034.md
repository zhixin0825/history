1. **大司马吴汉率捕虏将军王霸等五将军击贾览於高柳。** 十年春正月，大司马吴汉率捕虏将军王霸等五将军击贾览于高柳，匈奴遣骑救览，诸将与战，郤之。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-5"></a>

<a id="hh-event-6"></a>

<a id="hh-event-10"></a>

2. **光武修高庙并赴长安、汧祭巡。** 朝廷修理长安高庙。光武到长安祭高庙及十一陵，再至汧县，随后回宫。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

<a id="hh-event-7"></a>

<a id="hh-event-8"></a>

3. **冯异破蜀援，陇右诸部归降。** 夏，冯异在天水击破公孙述部将赵匡，将其斩杀，冯异本年去世。隗嚣部将高峻投降。冬十月，来歙等在落门大破隗纯，王元奔蜀，隗纯和周宗投降，陇右平定。 [[3]](#hh-note-3)

<a id="hh-event-9"></a>

4. **先零羌寇金城、陇西，来歙率诸将击羌於五谿，大破之。** 先零羌寇金城、陇西，来歙率诸将击羌于五谿，大破之。 [[4]](#hh-note-9)

<a id="hh-event-11"></a>

5. **是岁，省定襄郡，徙其民於西河。** 当年，省定襄郡，徙其民于西河。 [[5]](#hh-note-11)

<a id="hh-event-12"></a>

6. **泗水王歙薨。** 泗水王歙去世。 [[6]](#hh-note-12)

<a id="hh-event-13"></a>

7. **淄川王终薨。** 淄川王终去世。 [[7]](#hh-note-13)

<a id="hh-event-14"></a>

8. **张汜请修河汴。** 阳武令张汜奏请修防黄河、汴渠，光武先征发役卒，后又听乐俊议而停。 [[8]](#hh-note-14)

<a id="hh-event-15"></a>

9. **流星如月，从太微出，入北斗魏第六星，色白。** 十年三月癸卯，流星如月，从太微出，入北斗魏第六星，色白。 [[9]](#hh-note-15)

<a id="hh-event-16"></a>

10. **大流星如缶，出柳西南行，入轸。** 十二月己亥，大流星如缶，出柳西南行，入轸。 [[10]](#hh-note-16)

<a id="sy-event-17"></a>

11. **光武帝下诏沿用旧漏法。** 和帝时太史令等追述，光武帝于建武十年二月壬午下诏施行宣帝时颁行的官用漏法。 [[11]](#sy-note-17)

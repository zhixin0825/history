1. **光武调整奴婢刑律。** 二月己卯，诏杀奴婢者不得减罪。又诏灸灼奴婢者依法治罪，被灸灼者免为庶人。十月壬午，废奴婢射伤他人处弃市的旧律。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-4"></a>

2. **光武幸南阳后还宫。** 光武到南阳，随后回宫。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **城阳王祉薨。** 城阳王祉去世。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

<a id="hh-event-6"></a>

<a id="hh-event-13"></a>

<a id="hh-event-14"></a>

<a id="hh-event-19"></a>

<a id="hh-event-21"></a>

4. **汉军破荆门、平巴郡，岑彭遇刺后吴汉续征。** 闰月，岑彭率三将军在荆门大破蜀将田戎、任满，获任满。冯骏在江州围田戎，岑彭率舟师伐蜀，平巴郡。八月岑彭在黄石击破侯丹，臧宫在渖水大破延岑。公孙述遣间人刺杀岑彭。十二月，吴汉继率舟师伐蜀。 [[4]](#hh-note-5)

<a id="hh-event-7"></a>

5. **省大司徒司直官。** 夏四月丁卯，省大司徒司直官。 [[5]](#hh-note-7)

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

<a id="hh-event-10"></a>

<a id="hh-event-15"></a>

<a id="hh-event-20"></a>

6. **来歙破蜀将于下辩，遇刺后马成平武都。** 先零羌入犯临洮。六月，来歙与马成在下辩击破公孙述部将王元、环安，环安遣间人刺杀来歙。王元归降，马成平武都，马援击破先零羌，朝廷将其部众移置天水、陇西、扶风。 [[6]](#hh-note-8)

<a id="hh-event-11"></a>

<a id="hh-event-12"></a>

<a id="hh-event-16"></a>

7. **光武赴长安督伐蜀后还宫。** 光武亲自督征公孙述，七月驻长安，后还宫。 [[7]](#hh-note-11)

<a id="hh-event-22"></a>

<a id="hh-event-23"></a>

8. **朔方并入并州，州牧不得径自回京奏事。** 本年罢朔方牧，将其辖地并入并州，并开始禁止州牧自行回朝奏事。 [[8]](#hh-note-22)

<a id="hh-event-24"></a>

9. **征为司隶校尉。** 建武十一年，征为司隶校尉。 [[9]](#hh-note-24)

<a id="hh-event-25"></a>

10. **拜大司农。** 建武十一年，拜大司农。 [[10]](#hh-note-25)

<a id="hh-event-1"></a>

1. **诏曰“天地之性人为贵”。** 十一年春二月己卯，诏曰：「天地之性人为贵。其杀奴婢，不得减罪。」 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **幸南阳。** 己酉，幸南阳；还，幸章陵，祠园陵。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **城阳王祉薨。** 城阳王祉去世。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **车驾还宫。** 庚午，皇帝回宫。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **闰月，征南大将军岑彭率三将军与公孙述将田戎、任满战於荆门，大破之，获任满。** 闰月，征南大将军岑彭率三将军与公孙述将田戎、任满战于荆门，大破之，获任满。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **威虏将军冯骏围田戎於江州，岑彭遂率舟师伐公孙述，平巴郡。** 威虏将军冯骏围田戎于江州，岑彭遂率舟师伐公孙述，平巴郡。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **省大司徒司直官。** 夏四月丁卯，省大司徒司直官。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **先零羌寇临洮。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **中郎将来歙率扬武将军马成破公孙述将王元、环安於下辩。** 六月，中郎将来歙率扬武将军马成破公孙述将王元、环安于下辩。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **安遣间人刺杀中郎将来歙。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **帝自将征公孙述。** [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **次长安。** 秋七月，次长安。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **岑彭破公孙述将侯丹於黄石。** 八月，岑彭破公孙述将侯丹于黄石。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **辅威将军臧宫与公孙述将延岑战於渖水，大破之。** 辅威将军臧宫与公孙述将延岑战于渖水，大破之。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **王元降。** [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **至自长安。** [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **诏曰“敢灸灼奴婢”。** 癸亥，诏曰：「敢灸灼奴婢，论如律，免所灸灼者为庶民。」 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **诏除奴婢射伤人弃市律。** 冬十月壬午，诏除奴婢射伤人弃市律。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **公孙述遣间人刺杀征南大将军岑彭。** [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **马成平武都，因陇西太守马援击破先零羗，徙致天水、陇西、扶风。** [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **大司马吴汉率舟师伐公孙述。** 十二月，大司马吴汉率舟师伐公孙述。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **是岁，省朔方牧，并并州。** 当年，省朔方牧，并并州。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **初断州牧自还奏事。** [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **征为司隶校尉。** 建武十一年，征为司隶校尉。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **拜大司农。** 建武十一年，拜大司农。 [[25]](#hh-note-25)

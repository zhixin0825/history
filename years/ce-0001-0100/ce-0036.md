# 公元36年｜建武十二年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **大司马吴汉与公孙述将史兴战於武阳，斩之。** 十二年春正月，大司马吴汉与公孙述将史兴战于武阳，斩之。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏陇、蜀民被略为奴婢自讼者，及狱官未报，一切免为庶民。** 三月癸酉，诏陇、蜀民被略为奴婢自讼者，及狱官未报，一切免为庶民。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **甘露降南行唐。** 夏，甘露降南行唐。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **黄龙见东阿。** 六月，黄龙见东阿。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **威虏将军冯骏拔江州，获田戎。** 秋七月，威虏将军冯骏拔江州，获田戎。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **吴汉大破公孙述将谢丰於广都，斩之。** 九月，吴汉大破公孙述将谢丰于广都，斩之。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **辅威将军臧宫拔涪城，斩公孙恢。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **大司空李通罢。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **吴汉、臧宫与公孙述战於成都，大破之。** 冬十一月戊寅，吴汉、臧宫与公孙述战于成都，大破之。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **述被创，夜死。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **吴汉屠成都，夷述宗族及延岑等。** 辛巳，吴汉屠成都，夷述宗族及延岑等。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **扬武将军马成行大司空事。** 十二月辛卯，扬武将军马成行大司空事。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **是岁，九真徼外蛮夷张游率种人内属，封为归汉里君。** 当年，九真徼外蛮夷张游率种人内属，封为归汉里君。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **省金城郡属陇西。** [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **参狼羌寇武都，陇西太守马援讨降之。** 参狼羌寇武都，陇西太守马援讨降服。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **诏边吏力不足战则守，追虏料敌不拘以逗留法。** [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **横野大将军王常薨。** 横野大将军王常去世。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **遣骠骑大将军杜茂将衆郡施刑屯北边，筑亭候，修烽燧。** [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **张游率众内属。** 九真境外的张游率众内附，受封归汉里君。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **辰，小流星百枚以上，四面行。** 《天文志》记六月戊戌辰，小流星百枚以上，四面行。 [[20]](#hh-note-20)

**归年与互校** 卷001建武十二年十一月详记公孙述受创夜死和成都陷落；本传合叙，称“戰死城下”，本纪称“被創，夜死”。

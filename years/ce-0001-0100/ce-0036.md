1. **吴汉、臧宫攻成都，公孙述败亡。** 吴汉在武阳击杀蜀将史兴。七月，冯骏克江州，获田戎。九月吴汉在广都大破并斩谢丰，臧宫克涪城，斩公孙恢。十一月戊寅，吴汉、臧宫大破公孙述于成都，公孙述负伤，当夜死。辛巳，吴汉屠成都，诛公孙述宗族及延岑等。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏陇、蜀民被略为奴婢自讼者，及狱官未报，一切免为庶民。** 三月癸酉，诏陇、蜀民被略为奴婢自讼者，及狱官未报，一切免为庶民。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **甘露降南行唐。** 夏，甘露降南行唐。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **黄龙见东阿。** 六月，黄龙见东阿。 [[4]](#hh-note-4)

<a id="hh-event-8"></a>

<a id="hh-event-12"></a>

5. **李通罢官，马成行大司空事。** 大司空李通罢官。十二月辛卯，以扬武将军马成行大司空事。 [[5]](#hh-note-8)

<a id="hh-event-13"></a>

<a id="hh-event-19"></a>

6. **九真边外张游率众归附。** 九真边界以外的张游率部众内附，受封归汉里君。 [[6]](#hh-note-13)

<a id="hh-event-14"></a>

7. **省金城郡属陇西。** [[7]](#hh-note-14)

<a id="hh-event-15"></a>

8. **参狼羌寇武都，陇西太守马援讨降之。** 参狼羌寇武都，陇西太守马援讨降服。 [[8]](#hh-note-15)

<a id="hh-event-16"></a>

9. **诏边吏力不足战则守，追虏料敌不拘以逗留法。** [[9]](#hh-note-16)

<a id="hh-event-17"></a>

10. **横野大将军王常薨。** 横野大将军王常去世。 [[10]](#hh-note-17)

<a id="hh-event-18"></a>

11. **遣骠骑大将军杜茂将衆郡施刑屯北边，筑亭候，修烽燧。** [[11]](#hh-note-18)

<a id="hh-event-20"></a>

12. **辰，小流星百枚以上，四面行。** 六月戊戌辰，小流星百枚以上，四面行。 [[12]](#hh-note-20)

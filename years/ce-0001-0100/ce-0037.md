1. **重定宗室等级、并旧王国并续封先代后裔。** 诏降长沙王刘兴、真定王刘得、河间王刘邵、中山王刘茂为临湘、真定、乐成、单父侯，宗室和绝国改封列侯者一百三十七人。赵王刘良、太原王刘章、鲁王刘兴降为赵公、齐公、鲁公。朝廷并除西京十三国，广平属钜鹿、真定属常山、河间属信都、城阳属琅邪、泗水属广陵、淄川属高密、胶东属北海、六安属庐江、广阳属上谷。侯松承安众侯。殷绍嘉公孔安改宋公、周承休公姬常改衞公，孔均之子孔志复封褒成侯。 [[1]](#hs-note-1)

2. **侯霸去世，朝廷更调公卿并裁将职。** 正月庚申，侯霸去世，沛郡太守韩歆继任大司徒。马成所行大司空事罢，冀州牧窦融任大司空。朝廷撤左右将军官，建威大将军耿弇罢职。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **诏曰“往年已勑郡国”。** 戊子，诏曰：「往年已勑郡国，异味不得有所献御，今犹未止，非徒有豫养导择之劳，至乃烦扰道上，疲费过所。其令太官勿复受。明勑下以远方口实所以荐宗庙，自如旧制。」 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **遣捕虏将军马武屯虖沱河以备匈奴。** 二月，遣捕虏将军马武屯虖沱河以备匈奴。 [[4]](#hh-note-4)

5. **卢芳自五原亡入匈奴。** [[5]](#hh-note-5)

6. **蜀平后吴汉还京，朝廷大飨论功。** 四月，吴汉自蜀还京，朝廷大宴将士，策勋论功，功臣增邑更封三百六十五人，外戚恩泽封爵四十五人。益州送至公孙述旧有的瞽师、郊庙乐器、葆车、舆辇，汉廷典礼用物始备。兵事渐息，朝廷减省文书调役，繁多者减至约原有十分之一。 [[6]](#hh-note-13)

<a id="hh-event-21"></a>

7. **匈奴寇河东。** 五月，匈奴寇河东。 [[7]](#hh-note-21)

<a id="hh-event-22"></a>

<a id="hh-event-29"></a>

8. **广汉边外白马羌归附，楼登受封。** 秋七月，广汉边外白马羌首领楼登等率五千余户内附，楼登受封归义君长。 [[8]](#hh-note-22)

<a id="hh-event-23"></a>

9. **日南徼外蛮夷献白雉、白兔。** 九月，日南徼外蛮夷献白雉、白兔。 [[9]](#hh-note-23)

<a id="hh-event-24"></a>

10. **诏益州民自八年以来被略为奴婢者，皆一切免为庶民。** 冬十二月甲寅，诏益州民自八年以来被略为奴婢者，皆一切免为庶民；或依托为人下妻，欲去者，恣听之；敢拘留者，比青、徐二州以略人法从事。 [[10]](#hh-note-24)

<a id="hh-event-25"></a>

11. **复置金城郡。** [[11]](#hh-note-25)

<a id="hh-event-26"></a>

12. **马援平武都参狼羌。** 参狼羌起事后，马援率兵进武都，使各部归降。 [[12]](#hh-note-26)

<a id="hh-event-27"></a>

13. **异国有献名马者，日行千里，又进宝劒，贾兼百金，诏以马驾鼓车，劒赐骑士。** 建武十三年，异国有献名马者，日行千里，又进宝劒，贾兼百金，诏以马驾鼓车，劒赐骑士。 [[13]](#hh-note-27)

# 公元37年｜安衆康侯丹一支爵位承袭

[← 公元36年](ce-0036.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元38年 →](ce-0038.md)

**汉光武帝建武十三年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **安衆康侯丹一支爵位承袭。** 建武十三年，侯松继承侯爵。 [[1]](#hs-note-1)

<a id="hh-event-2"></a>

2. **大司徒侯霸薨。** 十三年春正月庚申，大司徒侯霸去世。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **诏曰“往年已勑郡国”。** 戊子，诏曰：「往年已勑郡国，异味不得有所献御，今犹未止，非徒有豫养导择之劳，至乃烦扰道上，疲费过所。其令太官勿复受。明勑下以远方口实所以荐宗庙，自如旧制。」 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **遣捕虏将军马武屯虖沱河以备匈奴。** 二月，遣捕虏将军马武屯虖沱河以备匈奴。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **卢芳自五原亡入匈奴。** [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **诏曰“长沙王兴、真定王得、河闲王邵、中”。** 丙辰，诏曰：「长沙王兴、真定王得、河闲王邵、中山王茂，皆袭爵为王，不应经义。其以兴为临湘侯，得为真定侯，邵为乐成侯，茂为单父侯。」 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **其宗室及绝国封侯者凡一百三十七人。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **降赵王良为赵公，太原王章为齐公，鲁王兴为鲁公。** 丁巳，降赵王良为赵公，太原王章为齐公，鲁王兴为鲁公。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **以殷绍嘉公孔安为宋公，周承休公姬常为衞公。** 庚午，以殷绍嘉公孔安为宋公，周承休公姬常为衞公。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **省并西京十三国。** 省并西京十三国：广平属钜鹿，真定属常山，河闲属信都，城阳属琅邪，泗水属广陵，淄川属高密，胶东属北海，六安属庐江，广阳属上谷。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **沛郡太守韩歆为大司徒。** 三月辛未，沛郡太守韩歆为大司徒。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **行大司空马成罢。** 丙子，行大司空马成罢。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **大司马吴汉自蜀还京师，於是大飨将士，班劳策勳。** 夏四月，大司马吴汉自蜀还京师，于是大飨将士，班劳策勳。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **功臣增邑更封，凡三百六十五人。** [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **其外戚恩泽封者四十五人。** [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **罢左右将军官。** [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **建威大将军耿弇罢。** [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **益州传送公孙述瞽师、郊庙乐器、葆车、舆辇，於是法物始备。** 益州传送公孙述瞽师、郊庙乐器、葆车、舆辇，于是法物始备。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **时兵革旣息，天下少事，文书调役，务从简寡，至乃十存一焉。** [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **兾州牧窦融为大司空。** 甲寅，兾州牧窦融为大司空。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **匈奴寇河东。** 五月，匈奴寇河东。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **广汉徼外白马羌豪率种人内属。** 秋七月，广汉徼外白马羌豪率种人内属。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **日南徼外蛮夷献白雉、白兔。** 九月，日南徼外蛮夷献白雉、白兔。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **诏益州民自八年以来被略为奴婢者，皆一切免为庶民。** 冬十二月甲寅，诏益州民自八年以来被略为奴婢者，皆一切免为庶民；或依托为人下妻，欲去者，恣听之；敢拘留者，比青、徐二州以略人法从事。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **复置金城郡。** [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **马援平武都参狼羌。** 参狼羌起事后，马援率兵进武都，使各部归降。 [[26]](#hh-note-26)

<a id="hh-event-27"></a>

27. **异国有献名马者，日行千里，又进宝劒，贾兼百金，诏以马驾鼓车，劒赐骑士。** 建武十三年，异国有献名马者，日行千里，又进宝劒，贾兼百金，诏以马驾鼓车，劒赐骑士。 [[27]](#hh-note-27)

<a id="hh-event-28"></a>

28. **世祖复封均子志爲褒成侯。** 建武十三年，世祖复封均子志爲褒成侯。 [[28]](#hh-note-28)

<a id="hh-event-29"></a>

29. **广汉塞外白马羌豪楼登等率种人五千余户内属，光武封楼登为归义君长。** 建武十三年，广汉塞外白马羌豪楼登等率种人五千余户内属，光武封楼登为归义君长。 [[29]](#hh-note-29)

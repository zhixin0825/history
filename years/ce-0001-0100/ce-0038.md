# 公元38年｜建武十四年

[← 公元37年](ce-0037.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元39年 →](ce-0039.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **起南宫前殿。** 十四年春正月，起南宫前殿。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **匈奴遣使奉献，使中郎将报命。** 匈奴派使者进献，使中郎将报命。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **封孔子後志为襃成侯。** 夏四月辛巳，封孔子后志为襃成侯。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **越巂人任贵自称太守，遣使奉计。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **平城人贾丹杀卢芳将尹由来降。** 秋九月，平城人贾丹杀卢芳将尹由来降。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **是岁，会稽大疫。** 当年，会稽大疫。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **莎车国、鄯善国遣使奉献。** 莎车国、鄯善国派使者进献。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **诏益、凉二州奴婢，自八年以来自讼在所官，一切免为庶民，卖者无还直。** 十二月癸卯，诏益、凉二州奴婢，自八年以来自讼在所官，一切免为庶民，卖者无还直。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **马成整治北边障塞。** 马成驻常山、中山防北边，接替杜茂修塞并设置保壁烽燧。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **授长贵越巂太守印绶。** 长贵遣使报三年政绩，光武授越巂太守印绶。 [[10]](#hh-note-10)

1. **大司徒韩歆免，自杀。** 十五年春正月辛丑，大司徒韩歆免，自杀。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **有星孛於昴。** 丁未，有星孛于昴。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **汝南太守欧阳歙为大司徒。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **建义大将军朱佑罢。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **有星孛於营室。** 丁未，有星孛于营室。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **徙鴈门、代郡、上谷三郡民，置常关、居庸关以东。** 二月，徙鴈门、代郡、上谷三郡民，置常关、居庸关以东。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **初，巴蜀旣平，大司马吴汉上书请封皇子，不许，重奏连岁。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **乃诏羣臣议。** 三月，乃诏群臣议。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **大司空融、固始侯通、胶东侯复、高密侯禹、太常登等奏议曰。** 大司空融、固始侯通、胶东侯复、高密侯禹、太常登等奏议曰：「古者封建诸侯，以藩屏京师。周封八百，同姓诸姬并为建国，夹辅王室，尊事天子，享国永长，为后世法。故诗云：『大启尔宇，为周室辅。』高祖圣德，光有天下，亦务亲亲，封立兄弟诸子，不违旧章。陛下德横天地，兴复宗统，襃德赏勳，亲睦九族，功臣宗室，咸蒙封爵，多受广地，或连属县。今皇子赖天，能胜衣趋拜，陛下恭谦克让，抑而未议，群臣百姓，莫不失望。冝因盛夏吉时，定号位，以广藩辅，明亲亲，尊宗庙，重社稷，应古合旧，厌塞衆心。臣请大司空上舆地图，太常择吉日，具礼仪。」 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **制曰“可”。** 制曰：「可。」 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **以太牢告祠宗庙。** 夏四月戊申，以太牢告祠宗庙。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **使大司空融告庙，封皇子辅为右翊公，英为楚公，阳为东海公，康为济南公，苍为东平公，延为淮阳公…。** 丁巳，使大司空融告庙，封皇子辅为右翊公，英为楚公，阳为东海公，康为济南公，苍为东平公，延为淮阳公，荆为山阳公，衡为临淮公，焉为左翊公，京为琅邪公。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **追谥兄伯升为齐武公，兄仲为鲁哀公。** 癸丑，追谥兄伯升为齐武公，兄仲为鲁哀公。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **复置屯骑、长水、射声三校尉官。** 六月庚午，复置屯骑、长水、射声三校尉官；改青巾左校尉为越骑校尉。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **诏下州郡检核垦田顷［］及户口年纪，又考实二千石长吏阿枉不平者。** [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **大司徒欧阳歙下狱死。** 冬十一月甲戌，大司徒欧阳歙下狱后死亡。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **关内侯戴涉为大司徒。** 十二月庚午，关内侯戴涉为大司徒。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **卢芳自匈奴入居高柳。** [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **是岁，骠骑大将军杜茂免。** 当年，骠骑大将军杜茂免。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **虎牙大将军盖延薨。** 虎牙大将军盖延去世。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **封刘庄为东海公。** 刘庄最初封为东海公。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **彗星见昴，稍西北行，入营室，犯离宫，三月乙未，至东壁灭，见四十九日。** 十五年正月丁未，彗星见昴，稍西北行，入营室，犯离宫，三月乙未，至东壁灭，见四十九日。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **改河南郡为河南尹。** 光武定都洛阳后，改京畿为河南尹。 [[23]](#hh-note-23)

### 9. 大司空融、固始侯通、胶东侯复、高密侯禹、太常登等奏议曰

[返回正文第9条](#hh-event-9)

<a id="hh001-l266-e9"></a>

**[《后汉书·光武帝纪》](../../sources/摘录/后汉书-卷001-光武帝纪.md#p006)** · [仓内TXT L266](../../sources/本地分卷/后汉书/后汉书-卷001.md#L266)

> 大司空融、固始侯通、膠東侯復、高密侯禹、太常登等奏議曰：「古者封建諸侯，以藩屏京師。周封八百，同姓諸姬並為建國，夾輔王室，尊事天子，享國永長，為後世法。故詩云：『大啟爾宇，為周室輔。』高祖聖德，光有天下，亦務親親，封立兄弟諸子，不違舊章。陛下德橫天地，興復宗統，襃德賞勳，親睦九族，功臣宗室，咸蒙封爵，多受廣地，或連屬縣。今皇子賴天，能勝衣趨拜，陛下恭謙克讓，抑而未議，羣臣百姓，莫不失望。冝因盛夏吉時，定號位，以廣藩輔，明親親，尊宗廟，重社稷，應古合舊，厭塞衆心。臣請大司空上輿地圖，太常擇吉日，具禮儀。」

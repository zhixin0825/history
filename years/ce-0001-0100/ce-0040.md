# 公元40年｜光武帝建武十六年始行五铢

[← 公元39年](ce-0039.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元41年 →](ce-0041.md)

**汉光武帝建武十六年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **光武帝建武十六年始行五铢。** 《后汉书·光武帝纪》明系建武十六年（40）；本志把受命、清政与复钱接叙，不能照受命年硬作同年。 [[1]](#hs-note-1)

<a id="hh-event-2"></a>

2. **交址女子徵侧反，略有城邑。** 十六年春二月，交址女子徵侧反，略有城邑。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **日有蚀之。** 三月辛丑晦，发生日食。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **河南尹张汲及诸郡守十余人，坐度田不实，皆下狱死。** 秋九月，河南尹张汲及诸郡守十余人，坐度田不实，均被收监，死于狱中。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **郡国大姓及兵长、羣盗处处并起，攻劫在所，害杀长吏。** 郡国大姓及兵长、群盗处处并起，攻劫在所，害杀长吏。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **郡县追讨，到则解散，去复屯结。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **青、徐、幽、兾四州尤甚。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **遣使者下郡国，听羣盗自相纠擿，五人共斩一人者，除其罪。** 冬十月，派使者下郡国，听群盗自相纠擿，五人共斩一人者，除其罪。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **吏虽逗留回避故纵者，皆勿问，听以禽讨为效。** [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **其牧守令长坐界内盗贼而不收捕者。** 其牧守令长坐界内盗贼而不收捕者，又以畏愞捐城委守者，皆不以为负，但取获贼多少为殿最，唯蔽匿者乃罪之。于是更相追捕，贼并解散。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **徙其魁帅於它郡，赋田受禀，使安生业。** 徙其魁帅于它郡，赋田受禀，使安生业。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **自是牛马放牧，邑门不闭。** [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **卢芳遣使乞降。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **封芳为代王。** 十二月甲辰，封芳为代王。 [[14]](#hh-note-14)

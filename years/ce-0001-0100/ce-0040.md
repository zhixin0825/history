1. **光武帝建武十六年始行五铢。** 刘秀恢复行用五铢钱。王莽末年战乱之后，布、帛、金、粟曾一并用作交易媒介。 [[1]](#hs-note-1)

<a id="hh-event-2"></a>

2. **交址女子徵侧反，略有城邑。** 十六年春二月，交址女子徵侧反，略有城邑。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **日有蚀之。** 三月辛丑晦，发生日食。 [[3]](#hh-note-3)

4. **度田问罪与郡国兵乱，光武改令招抚。** 九月河南尹张汲及郡守十余人因度田不实下狱死。郡国大姓、兵长和群盗起兵，攻劫官署，杀长吏，青、徐、幽、冀尤甚。郡县军到则散、去则聚，难以平定。十月光武遣使下郡国，准群盗相互告发，五人共斩一人者尽免罪；守令此前逗留失守者免究，以捕获人数考绩，隐匿者治罪。各部解散后，朝廷迁首领于别郡，授田给粮，使其复业，城乡渐趋安定。 [[4]](#hh-note-4)

<a id="hh-event-13"></a>

<a id="hh-event-14"></a>

5. **卢芳请降，受封代王。** 卢芳遣使请降，光武封他为代王。 [[5]](#hh-note-13)

## 本年相关史料

<a id="hs-note-1"></a>

### 1. 光武帝建武十六年始行五铢

[返回正文第1条](#hs-event-1)

**互校** 《光武帝纪》将恢复五铢系于建武十六年。《食货志》接叙刘秀受命、清政与复钱，所叙并非同年。

<a id="hh001-l278-e1"></a>

**[《后汉书·光武帝纪》](../../拆分史书/后汉书/卷001.md#p006)** · [仓内TXT L278](../../拆分史书/后汉书/卷001.md#part-2-L278)

> 初，王莽亂後，貨幣雜用布、帛、金、粟。是歲，始行五銖錢。

<a id="hh024-l2163-e1"></a>

**[《后汉书·马援列传》](../../拆分史书/后汉书/卷024.md#p002)** · [仓内TXT L2163](../../拆分史书/后汉书/卷024.md#part-1-L2163)

> 乃援還，從公府求得前奏，難十餘條，乃隨牒解釋，更具表言。帝從之，天下賴其便。

**归年与互校** 本传记较早提出建议，《光武帝纪》明确建武十六年正式颁行。

<a id="hs024-l5132-e1"></a>

**[《汉书·食货志》P054](../../拆分史书/汉书/卷024.md#p054)** · [仓内TXT L5132](../../拆分史书/汉书/卷024.md#part-1-L5132)

> 復五銖錢，與天下更始。

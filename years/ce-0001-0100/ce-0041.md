# 公元41年｜建武十七年

[← 公元40年](ce-0040.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元42年 →](ce-0042.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **赵公良薨。** 十七年春正月，赵公良去世。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **日有食之。** 二月乙亥晦，发生日食。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

3. **光武携皇太子诸公南巡，至颍川、叶、章陵。** 四月乙卯，光武携皇太子及右翊公刘辅、楚公刘英、东海公刘阳、济南公刘康、东平公刘苍南巡，经颍川、叶、章陵，五月乙卯还宫。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

4. **临淮公衡薨。** 六月癸巳，临淮公衡去世。 [[4]](#hh-note-5)

<a id="hh-event-6"></a>

<a id="hh-event-7"></a>

5. **李广据皖，马援、段志进讨斩之。** 巫者李广等据皖城起兵，光武遣虎贲中郎将马援、骠骑将军段志讨之，攻破皖城并斩李广等。 [[5]](#hh-note-6)

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

<a id="hh-event-18"></a>

6. **郭氏废为中山太后，阴氏立后。** 光武废郭皇后为中山太后，立阴贵人为皇后。原右翊公刘辅进中山王，食常山郡，阴皇后子刘阳由东海公进东海王，即后来的刘庄。 [[6]](#hh-note-8)

<a id="hh-event-10"></a>

<a id="hh-event-11"></a>

<a id="hh-event-12"></a>

<a id="hh-event-13"></a>

<a id="hh-event-14"></a>

<a id="hh-event-16"></a>

7. **光武再至章陵修园庙，优礼舂陵宗族。** 甲申，光武到章陵，修园庙、祀旧宅，观田庐，设酒乐赐宗亲。宗室诸母说光武少时谨信、性情直柔，如今竟得天下。光武笑称自己也想以柔道治天下，为舂陵宗室皆起祠堂。十二月自章陵回宫。 [[7]](#hh-note-10)

<a id="hh-event-15"></a>

8. **有五凤皇见於颍川之郏县。** 有五凤皇见于颍川之郏县。 [[8]](#hh-note-15)

<a id="hh-event-17"></a>

9. **是岁，莎车国遣使贡献。** 当年，莎车国遣使贡献。 [[9]](#hh-note-17)

<a id="hh-event-19"></a>

10. **遣马援征交阯。** 刘隆起复，复封扶乐乡侯并副马援征交阯。 [[10]](#hh-note-19)

<a id="hh-event-20"></a>

11. **光武再召严光。** 光武特召归隐富春山的严光，严光没有应召。 [[11]](#hh-note-20)

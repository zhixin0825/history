1. **史歆叛据成都，吴汉破城，朝廷赦益州。** 蜀郡守将史歆叛，吴汉率二将军围成都，攻拔其城，斩史歆等。朝廷赦益州所部死罪以下。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

<a id="hh-event-5"></a>

<a id="hh-event-18"></a>

2. **光武西巡长安，祠高庙、十一陵和后土。** 甲寅，光武西巡幸长安，三月壬午祭高庙及十一陵。又经冯翊至蒲坂，祭后土，随后还宫。 [[2]](#hh-note-2)

<a id="hh-event-6"></a>

3. **诏曰“今边郡盗谷五十斛”。** 癸酉，诏曰：「今边郡盗谷五十斛，罪至于死，开残吏妄杀之路，其蠲除此法，同之内郡。」 [[3]](#hh-note-6)

<a id="hh-event-7"></a>

4. **遣伏波将军马援率楼船将军段志等击交址贼徵侧等。** [[4]](#hh-note-7)

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

5. **光武幸河内后还宫。** 光武到河内，随后回宫。 [[5]](#hh-note-8)

<a id="hh-event-10"></a>

6. **旱。** 五月，旱。 [[6]](#hh-note-10)

<a id="hh-event-11"></a>

7. **卢芳复亡入匈奴。** [[7]](#hh-note-11)

<a id="hh-event-14"></a>

<a id="hh-event-15"></a>

<a id="hh-event-16"></a>

8. **光武经宜城，回程祠章陵。** 冬十月庚辰，光武到宜城，回程祭祀章陵，随后还宫。 [[8]](#hh-note-14)

<a id="hh-event-17"></a>

9. **是岁，罢州牧，置刺史。** 当年，罢州牧，置刺史。 [[9]](#hh-note-17)

<a id="hh-event-19"></a>

10. **栋蚕等反益州。** 栋蚕合多部举兵，益州太守繁胜败退朱提。 [[10]](#hh-note-19)

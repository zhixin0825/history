# 公元43年｜建武十九年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **追尊孝宣皇帝曰中宗。** 十九年春正月庚子，追尊孝宣皇帝曰中宗。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **始祠昭帝、元帝於太庙，成帝、哀帝、平帝於长安，舂陵节侯以下四世於章陵。** 始祠昭帝、元帝于太庙，成帝、哀帝、平帝于长安，舂陵节侯以下四世于章陵。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **妖巫单臣、傅镇等反，据原武，遣太中大夫臧宫围之。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **拔原武，斩臣、镇等。** 夏四月，拔原武，斩臣、镇等。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **伏波将军马援破交址，斩徵侧等。** [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **因击破九真贼都阳等，降之。** 因击破九真贼都阳等，降服。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **闰月戊申，进赵、齐、鲁三国公爵为王。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **诏曰“春秋之义”。** 六月戊申，诏曰：「春秋之义，立子以贵。东海王阳，皇后之子，冝承大统。皇太子强，崇执谦退，愿备藩国。父子之情，重乆违之。其以强为东海王，立阳为皇太子，改名庄。」 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **南巡狩。** 秋九月，南巡狩。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **幸南阳，进幸汝南南顿县舍，置酒会，赐吏人，复南顿田租岁。** 壬申，幸南阳，进幸汝南南顿县舍，置酒会，赐吏人，复南顿田租岁。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **父老前叩头言。** 父老前叩头言：「皇考居此日乆，陛下识知寺舍，每来辄加厚恩，愿赐复十年。」 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **帝曰“天下重器”。** 帝曰：「天下重器，常恐不任，日复一日，安敢远期十岁乎？」 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **吏人又言。** 吏人又言：「陛下实惜之，何言谦也？」 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **帝大笑，复增一岁。** 帝大笑，复增一岁。进幸淮阳、梁、沛。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **西南夷寇益州郡，遣武威将军刘尚讨之。** [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **越巂太守任贵谋叛，十二月，刘尚袭贵，诛之。** [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **是岁，复置函谷关都尉。** 当年，复置函谷关都尉。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **修西京宫室。** [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **立刘庄为皇太子。** 郭后所生刘彊辞储后，刘庄获立。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **年六十余，始辟大司徒府。** 建武十九年，年六十余，始辟大司徒府。 [[20]](#hh-note-20)

# 公元43年｜建武十九年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

<a id="hh-event-2"></a>

1. **尊宣帝为中宗，议定诸帝奉祀之地。** 追尊宣帝为中宗，始于太庙祠昭帝、元帝，在长安祠成帝、哀帝、平帝，在章陵祠舂陵节侯以下四世。 [[1]](#hh-note-1)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

2. **单臣等据原武，臧宫拔城平乱。** 巫者单臣、傅镇等据原武起事，臧宫奉命围攻，拔城斩单臣、傅镇等。 [[2]](#hh-note-3)

<a id="hh-event-5"></a>

<a id="hh-event-6"></a>

3. **马援破交阯，继平九真。** 伏波将军马援在交阯破徵侧等，将其斩杀，继在九真击败并招降都阳等部。 [[3]](#hh-note-5)

<a id="hh-event-7"></a>

<a id="hh-event-8"></a>

<a id="hh-event-19"></a>

4. **赵齐鲁进封为王，刘阳改名刘庄并立太子。** 闰月戊申，进赵、齐、鲁三国公为王。六月戊申，原太子刘强多次请就藩，光武以阴皇后子东海王刘阳应承大统，改封刘强为东海王，立刘阳为太子，改名刘庄。 [[4]](#hh-note-7)

<a id="hh-event-9"></a>

<a id="hh-event-10"></a>

<a id="hh-event-11"></a>

<a id="hh-event-12"></a>

<a id="hh-event-13"></a>

<a id="hh-event-14"></a>

5. **光武南巡，在南顿免田租两年。** 九月，光武巡至南阳及汝南南顿，在县舍设酒赏赐吏民，免南顿一年田租。父老说帝父曾久居此，请免租十年。光武称承当天下重任，难以远期十岁，吏民笑说皇帝实在舍不得，光武也笑，增免一年，继至淮阳、梁、沛。 [[5]](#hh-note-9)

<a id="hh-event-15"></a>

<a id="hh-event-16"></a>

6. **刘尚出讨西南夷，袭杀越巂任贵。** 西南夷进犯益州郡，武威将军刘尚奉命出讨。越巂太守任贵谋叛，十二月，刘尚袭杀任贵。 [[6]](#hh-note-15)

<a id="hh-event-17"></a>

7. **是岁，复置函谷关都尉。** 当年，复置函谷关都尉。 [[7]](#hh-note-17)

<a id="hh-event-18"></a>

8. **修西京宫室。** [[8]](#hh-note-18)

<a id="hh-event-20"></a>

9. **年六十余，始辟大司徒府。** 建武十九年，年六十余，始辟大司徒府。 [[9]](#hh-note-20)

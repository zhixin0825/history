<a id="hh-event-1"></a>

1. **车驾还宫。** 二十年春二月戊子，皇帝回宫。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **大司徒戴涉下狱死。** 夏四月庚辰，大司徒戴涉下狱后死亡。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **大司空窦融免。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **大司马吴汉薨。** 五月辛亥，大司马吴汉去世。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **匈奴寇上党、天水，遂至扶风。** [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **广汉太守蔡茂为大司徒，太仆朱浮为大司空。** 六月庚寅，广汉太守蔡茂为大司徒，太仆朱浮为大司空。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **左中郎将刘隆为骠骑将军，行大司马事。** 壬辰，左中郎将刘隆为骠骑将军，行大司马事。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **徙中山王辅为沛王。** 乙未，徙中山王辅为沛王。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **东夷韩国人率衆诣乐浪内附。** 秋，东夷韩国人率衆到乐浪内附。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **东巡狩。** 冬十月，东巡狩。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **幸鲁，进幸东海、楚、沛国。** 甲午，幸鲁，进幸东海、楚、沛国。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **匈奴寇天水。** 十二月，匈奴寇天水。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **车驾还宫。** 壬寅，皇帝回宫。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **是岁，省五原郡，徙其吏人置河东。** 当年，省五原郡，徙其吏人置河东。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **复济阳县傜役六岁。** [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **马援交阯班师。** 马援自交阯班师，传称军吏因瘴疫死近半，皇帝赐兵车。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **苏马諟等来贡。** 韩人苏马諟等到乐浪进贡，光武赐君号。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **代戴涉为司徒，在职清俭匪懈。** 建武二十年，代戴涉为司徒，在职清俭匪懈。 [[18]](#hh-note-18)

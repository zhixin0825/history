1. **车驾还宫。** 二十年春二月戊子，皇帝回宫。 [[1]](#hh-note-1)

<a id="hh-event-18"></a>

2. **戴涉、吴汉去世，蔡茂等接掌三公。** 四月庚辰，大司徒戴涉下狱死，大司空窦融罢。五月辛亥，大司马吴汉死。六月庚寅，广汉太守蔡茂、太仆朱浮分任大司徒、大司空。壬辰，左中郎将刘隆任骠骑将军、行大司马事。蔡茂在任清俭勤勉。 [[2]](#hh-note-2)

<a id="hh-event-5"></a>

<a id="hh-event-12"></a>

<a id="hh-event-14"></a>

3. **北边遇袭，朝廷省五原并移民河东。** 匈奴犯上党、天水，深入扶风，十二月再犯天水。朝廷本年撤五原郡，徙其吏民置河东。 [[3]](#hh-note-5)

<a id="hh-event-8"></a>

4. **徙中山王辅为沛王。** 乙未，徙中山王辅为沛王。 [[4]](#hh-note-8)

<a id="hh-event-9"></a>

5. **东夷韩国人率衆诣乐浪内附。** 秋，东夷韩国人率衆到乐浪内附。 [[5]](#hh-note-9)

<a id="hh-event-10"></a>

<a id="hh-event-11"></a>

<a id="hh-event-13"></a>

6. **光武巡鲁与东海、楚、沛。** 光武东巡，到鲁、东海、楚、沛各地，随后回宫。 [[6]](#hh-note-10)

<a id="hh-event-15"></a>

7. **复济阳县傜役六岁。** [[7]](#hh-note-15)

<a id="hh-event-16"></a>

8. **马援交阯班师。** 马援自交阯班师，传称军吏因瘴疫死近半，皇帝赐兵车。 [[8]](#hh-note-16)

<a id="hh-event-17"></a>

9. **苏马諟等来贡。** 韩人苏马諟等到乐浪进贡，光武赐君号。 [[9]](#hh-note-17)

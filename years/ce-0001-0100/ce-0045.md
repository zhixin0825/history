<a id="hh-event-1"></a>

<a id="hh-event-8"></a>

1. **刘尚追讨益州栋蚕至不韦。** 正月，刘尚击破益州起兵诸部，后接连追讨至不韦，击灭栋蚕等首领。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **安定属国胡叛，屯聚青山，遣将兵长史陈欣讨平之。** 夏四月，安定属国胡叛，屯聚青山，遣将兵长史陈欣讨平之。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-11"></a>

3. **祭肜击退入辽东的鲜卑、匈奴。** 鲜卑和匈奴入犯辽东，太守祭肜领军反击，大破来兵。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

<a id="hh-event-10"></a>

4. **马援出五阮关攻乌桓不克。** 伏波将军马援率三千骑出五阮关，乌桓已经退去，转而追袭归军，汉军损失马匹。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **匈奴寇上谷、中山。** [[5]](#hh-note-5)

<a id="hh-event-6"></a>

<a id="hh-event-7"></a>

<a id="hh-event-9"></a>

<a id="hh-event-12"></a>

6. **西域诸国请置都护，光武还侍子。** 冬，车师、鄯善、焉耆等国遣子入侍奉贡，请汉朝遣都护。光武以天下初定，未暇经略西域，厚加赏赐后遣返侍子，鄯善等国随后仍附匈奴。 [[6]](#hh-note-6)

### 4. 马援出五阮关攻乌桓不克

[返回正文第4条](#hh-event-4)

<a id="hh001-l319-e4"></a>

**[《后汉书·光武帝纪》](../../sources/摘录/后汉书-卷001-光武帝纪.md#p006)** · [仓内TXT L319](../../sources/本地分卷/后汉书/后汉书-卷001.md#L319)

> 冬十月，遣伏波將軍馬援出塞擊烏桓，不克。

<a id="sgz030-b-1579-13"></a>

**[《三国志·乌丸鲜卑东夷传》仓内原文 L1579](../../sources/本地分卷/三国志/三国志-卷030.md#l1579)**

> 光武定天下，遣伏波將軍馬援將三千騎，從五原關出塞征之，無利，而殺馬千餘匹。

**释读** 马援率三千骑出关，作战不利，损失大量战马。

**归年** 《后汉书·光武帝纪》建武二十一年秋；范晔《乌桓传》作五阮关，保留本传“五原關”。

<a id="sgz030-p-001-12"></a>

**[《三国志·乌丸鲜卑东夷传》裴注 001·12](../../sources/本地分卷/三国志/三国志-卷030.md#pei-001-12)**

> 光武定天下遣伏波將軍馬援將三千騎從五原闗出塞征之無利而殺馬千餘匹

**释读** 马援出五原关，率三千骑进兵，损失千余战马。

**归年** 《后汉书·光武帝纪》建武二十一年，附同一役；《后汉书·乌桓传》关名作五阮。

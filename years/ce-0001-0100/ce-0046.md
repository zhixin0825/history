# 公元46年｜建武二十二年

<a id="hh-event-1"></a>

<a id="hh-event-2"></a>

1. **光武幸长安祠高庙、十一陵后还宫。** 闰月丙戌，光武至长安祠高庙，祭十一陵，随后回宫。 [[1]](#hh-note-1)

<a id="hh-event-3"></a>

2. **日有食之。** 夏五月乙未晦，发生日食。 [[2]](#hh-note-3)

<a id="hh-event-4"></a>

3. **司隷校尉苏邺下狱死。** 秋七月，司隷校尉苏邺下狱后死亡。 [[3]](#hh-note-4)

<a id="hh-event-5"></a>

<a id="hh-event-6"></a>

<a id="hh-event-15"></a>

4. **地震四十二处，光武下诏赈恤南阳。** 九月戊辰，郡国多处地震，共四十二处，南阳灾情最重，地裂压杀居民。光武免南阳本年田租与刍稾，遣谒者察灾，在戊辰以前定罪的死囚减一等，解徒人刑具并给衣絮。每名被压死的郡民发棺钱三千，房屋严重毁坏者免追口赋逋税，家贫无力收尸的，由官府出钱谷雇人寻找。 [[4]](#hh-note-5)

<a id="hh-event-7"></a>

<a id="hh-event-8"></a>

5. **朱浮免大司空，杜林继任。** 大司空朱浮罢免，光禄勋杜林继任。 [[5]](#hh-note-7)

<a id="hh-event-9"></a>

6. **是岁，齐王章薨。** 当年，齐王章去世。 [[6]](#hh-note-9)

<a id="hh-event-10"></a>

7. **青州蝗。** [[7]](#hh-note-10)

<a id="hh-event-11"></a>

<a id="hh-event-12"></a>

<a id="hh-event-13"></a>

8. **乌桓破匈奴，匈奴北徙，日逐王比请和。** 乌桓击败匈奴，匈奴北移，幕南地空，朝廷罢诸边郡亭候吏卒。匈奴薁鞬日逐王比遣使至渔阳请和亲，光武命中郎将李茂答复。 [[8]](#hh-note-11)

<a id="hh-event-14"></a>

9. **莎车王贤攻鄯善、龟兹。** 贤得知东汉不会派都护，先攻鄯善，冬又杀龟兹王、兼并其国。 [[9]](#hh-note-14)

### 4. 地震四十二处，光武下诏赈恤南阳

[返回正文第4条](#hh-event-5)

<a id="hh001-l325-e5"></a>

**[《后汉书·光武帝纪》](../../拆分史书/后汉书/卷001.md#p006)** · [仓内TXT L325](../../拆分史书/后汉书/卷001.md#part-2-L325)

> 九月戊辰，地震裂。

<a id="hh-note-6"></a>

<a id="hh001-l325-e6"></a>

**[《后汉书·光武帝纪》](../../拆分史书/后汉书/卷001.md#p006)** · [仓内TXT L325](../../拆分史书/后汉书/卷001.md#part-2-L325)

> 制詔曰：「日者地震，南陽尤甚。夫地者，任物至重，靜而不動者也。而今震裂，咎在君上。鬼神不順無德，災殃將及吏人，朕甚懼焉。其令南陽勿輸今年田租芻稾。遣謁者案行，其死罪繫囚在戊辰以前，減死罪一等；徒皆［］解鉗，衣絲絮。賜郡中居人壓死者棺錢，人三千。其口賦逋稅而廬宅尤破壞者，勿收責。吏人死亡，或在壞垣毀屋之下，而家羸弱不能收拾者，其以見錢穀取傭，為尋求之。」

<a id="hh-note-15"></a>

<a id="hh106-l7434-e15"></a>

**[《后汉书·五行志四》](../../拆分史书/后汉书/卷106.md#p001)** · [仓内TXT L7434](../../拆分史书/后汉书/卷106.md#part-1-L7434)

> 世祖建武二十二年九月，郡國四十二地震，南陽尤甚，地裂壓殺人。

**归年与互校** 本志原载年号。志文的占验解释见原卷上下文。

# 公元46年｜建武二十二年

[← 公元45年](ce-0045.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元47年 →](ce-0047.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **闰月丙戌，幸长安，祠高庙，遂有事十一陵。** 二十二年春，闰月丙戌，前往长安，祠高庙，遂有事十一陵。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **至自长安。** 二月己巳，至自长安。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **日有食之。** 夏五月乙未晦，发生日食。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **司隷校尉苏邺下狱死。** 秋七月，司隷校尉苏邺下狱后死亡。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **地震裂。** 九月戊辰，地震裂。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **制诏曰。** 制诏曰：「日者地震，南阳尤甚。夫地者，任物至重，静而不动者也。而今震裂，咎在君上。鬼神不顺无德，灾殃将及吏人，朕甚惧焉。其令南阳勿输今年田租刍稾。派谒者案行，其在押死囚在戊辰以前，减死罪一等；徒皆［］解钳，衣丝絮。赐郡中居人压死者棺钱，人三千。其口赋逋税而庐宅尤破坏者，勿收责。吏人死亡，或在坏垣毁屋之下，而家羸弱不能收拾者，其以见钱谷取佣，为寻求之。」 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **大司空朱浮免。** 冬十月壬子，大司空朱浮免。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **光禄勳杜林为大司空。** 癸丑，光禄勳杜林为大司空。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **是岁，齐王章薨。** 当年，齐王章去世。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **青州蝗。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **匈奴薁鞬日逐王比遣使诣渔阳请和亲，使中郎将李茂报命。** 匈奴薁鞬日逐王比遣使到渔阳请和亲，使中郎将李茂报命。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **乌桓击破匈奴，匈奴北徙，幕南地空。** [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **诏罢诸边郡亭候吏卒。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **莎车王贤攻鄯善、龟兹。** 贤得知东汉不会派都护，先攻鄯善，冬又杀龟兹王、兼并其国。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **世祖建武二十二年九月，郡国四十二地震，南阳尤甚，地裂压杀人。** [[15]](#hh-note-15)

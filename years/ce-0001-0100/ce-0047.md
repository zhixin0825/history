1. **刘尚平南郡雷迁等，迁降众至江夏。** 正月，南郡雷迁等起兵，武威将军刘尚率军击败，迁其降众七千余人至江夏。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

<a id="hh-event-5"></a>

2. **蔡茂、杜林去世，玉况、张纯递掌公职。** 大司徒蔡茂、大司空杜林去世，陈留太守玉况任大司徒，太仆张纯任大司空。 [[2]](#hh-note-2)

<a id="hh-event-6"></a>

<a id="hh-event-9"></a>

3. **高句骊戴升等率众内属乐浪。** 高句骊蠶支落大加戴升等率部众万余人，请在乐浪内属。 [[3]](#hh-note-6)

<a id="hh-event-7"></a>

4. **武陵蛮叛，寇掠郡县，遣刘尚讨之，战於沅水，尚军败殁。** 十二月，武陵蛮叛，寇掠郡县，遣刘尚讨之，战于沅水，尚军败殁。 [[4]](#hh-note-7)

<a id="hh-event-8"></a>

5. **是岁，匈奴薁鞬日逐王比率部曲遣使诣西河内附。** 当年，匈奴薁鞬日逐王比率部曲遣使到西河内附。 [[5]](#hh-note-8)

<a id="hh-event-11"></a>

6. **其王贤栗遣兵乘箅船，南下江、汉，击附塞夷鹿茤，鹿茤人弱，爲所擒获。** 建武二十三年，其王贤栗遣兵乘箅船，南下江、汉，击附塞夷鹿茤，鹿茤人弱，爲所擒获。 [[6]](#hh-note-11)

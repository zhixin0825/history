# 公元47年｜建武二十三年

[← 公元46年](ce-0046.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元48年 →](ce-0048.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **南郡蛮叛，遣武威将军刘尚讨破之，徙其种人於江夏。** 二十三年春正月，南郡蛮叛，遣武威将军刘尚讨破之，徙其种人于江夏。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **大司徒蔡茂薨。** 夏五月丁卯，大司徒蔡茂去世。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **大司空杜林薨。** 秋八月丙戌，大司空杜林去世。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **陈留太守玉况为大司徒。** 九月辛未，陈留太守玉况为大司徒。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **太仆张纯为大司空。** 冬十月丙申，太仆张纯为大司空。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **高句丽率种人诣乐浪内属。** 高句丽率种人到乐浪内属。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **武陵蛮叛，寇掠郡县，遣刘尚讨之，战於沅水，尚军败殁。** 十二月，武陵蛮叛，寇掠郡县，遣刘尚讨之，战于沅水，尚军败殁。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **是岁，匈奴薁鞬日逐王比率部曲遣使诣西河内附。** 当年，匈奴薁鞬日逐王比率部曲遣使到西河内附。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **高句骊戴升等内属乐浪。** 高句骊蠶支落大加戴升等万余人请求在乐浪内属。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **刘尚讨潳山雷迁。** 雷迁等举兵，刘尚率军攻破，迁降者七千余人至江夏。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **其王贤栗遣兵乘箅船，南下江、汉，击附塞夷鹿茤，鹿茤人弱，爲所擒获。** 建武二十三年，其王贤栗遣兵乘箅船，南下江、汉，击附塞夷鹿茤，鹿茤人弱，爲所擒获。 [[11]](#hh-note-11)

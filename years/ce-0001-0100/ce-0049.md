1. **二十五春正月，辽东徼外貊人寇右北平、渔阳、上谷、太原，辽东太守祭肜招降之。** 二十五春正月，辽东徼外貊人寇右北平、渔阳、上谷、太原，辽东太守祭肜招降服。 [[1]](#hh-note-1)

<a id="hh-event-9"></a>

2. **乌桓郝旦等率众内属。** 乌桓渠帅郝旦等率众朝贡、内附，汉廷随后授诸部首领侯、王、君、长名号。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

3. **南单于奉蕃称臣并遣子入侍。** 南单于遣使奉贡称臣，又命左贤王击破北匈奴、退其地千余里。三月遣子入侍。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

4. **日有食之。** 戊申晦，发生日食。 [[4]](#hh-note-5)

<a id="hh-event-6"></a>

<a id="hh-event-7"></a>

<a id="hh-event-10"></a>

5. **马援进击武陵诸部，病卒壶头。** 马援等在临沅击破武陵诸部，后进壶头，因险阻与疾疫滞留，马援病逝军中。梁松借军议追究，朝廷收回马援的新息侯印。冬十月，起兵的各部悉降。 [[5]](#hh-note-6)

<a id="hh-event-8"></a>

<a id="hh-event-12"></a>

6. **夫余使者进贡，汉廷厚报。** 夫余王遣使来献，光武厚加回赠，此后双方使者常年往来。 [[6]](#hh-note-8)

<a id="hh-event-11"></a>

7. **卫飒因病未受少府任。** 光武征回卫飒，拟以为少府，卫飒因病未能受任。 [[7]](#hh-note-11)

> 是歲，烏桓大人率衆內屬，詣闕朝貢。

<a id="sgz030-b-1579-15"></a>

**[《三国志·乌丸鲜卑东夷传》仓内原文 L1579](../../拆分史书/三国志/卷030.md#l1579)**

> 建武二十五年，烏丸大人郝旦等九千餘人率衆詣闕，封其渠帥爲侯王者八十餘人，使居塞內，布列遼東屬國、遼西、右北平、漁陽、廣陽、上穀、代郡、雁門、太原、朔方諸郡界，招來種人，給其衣食，置校尉以領護之，遂爲漢偵備，擊匈奴、鮮卑。

**释读** 郝旦等人来朝，汉封八十余名首领，令其居民分布诸边郡并设置校尉，作为塞上预警和战力。

**归年** 明载建武二十五年；与同年《后汉书·乌桓传》合并。

<a id="sgz030-p-001-14"></a>

**[《三国志·乌丸鲜卑东夷传》裴注 001·14](../../拆分史书/三国志/卷030.md#pei-001-14)**

> 建武二十五年烏丸大人郝且等九千餘人率衆詣闕封其渠帥為侯王者八十餘人使居塞内布列遼東屬國遼西右北平漁陽廣陽上谷代郡鴈門太原朔方諸郡界招来種人給其衣食置校尉以領䕶之遂為漢偵備擊匈奴鮮卑

**释读** 乌丸多部入朝，渠帅封王侯，沿边安置，朝廷供衣食并置校尉护领，由其侦防。

**归年** 注直载建武二十五年；四库本郝且，仓内TXT郝旦。

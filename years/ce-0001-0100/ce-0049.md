<a id="hh-event-1"></a>

1. **二十五春正月，辽东徼外貊人寇右北平、渔阳、上谷、太原，辽东太守祭肜招降之。** 二十五春正月，辽东徼外貊人寇右北平、渔阳、上谷、太原，辽东太守祭肜招降服。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **乌桓大人来朝。** 乌桓大人入朝觐见。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **南单于遣使诣阙贡献，奉蕃称臣。** 南单于遣使到阙贡献，奉蕃称臣；又遣其左贤王击破北匈奴，却地千余里。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **南单于遣子入侍。** 三月，南单于遣子入侍。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **日有食之。** 戊申晦，发生日食。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **伏波将军马援等破武陵蛮於临沅。** 伏波将军马援等破武陵蛮于临沅。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **叛蛮悉降。** 冬十月，叛蛮悉降。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **夫余王遣使奉献。** 夫余王派使者进献。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **是岁，乌桓大人率衆内属，诣阙朝贡。** 当年，乌桓大人率衆内属，到阙朝贡。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **马援军至壶头，染病而卒。** 军进壶头后遇险阻和疾疫，马援死于军中，梁松借军议追究，朝廷收回新息侯印。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **卫飒因病未受少府任。** 光武征回卫飒，拟以为少府，卫飒因病未能受任。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **夫余王遣使进贡。** 夫余王遣使来献，光武厚报，双方使者继而常年往来。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **乌桓渠帅率众来朝。** 郝旦等率众入朝进献，汉廷随后授诸部首领侯王君长名号。 [[13]](#hh-note-13)

[返回正文第9条](#hh-event-9)

<a id="hh001-l346-e9"></a>

**[《后汉书·光武帝纪》](../../sources/摘录/后汉书-卷001-光武帝纪.md#p007)** · [仓内TXT L346](../../sources/本地分卷/后汉书/后汉书-卷001.md#L346)

> 是歲，烏桓大人率衆內屬，詣闕朝貢。

<a id="sgz030-b-1579-15"></a>

**[《三国志·乌丸鲜卑东夷传》仓内原文 L1579](../../sources/本地分卷/三国志/三国志-卷030.md#l1579)**

> 建武二十五年，烏丸大人郝旦等九千餘人率衆詣闕，封其渠帥爲侯王者八十餘人，使居塞內，布列遼東屬國、遼西、右北平、漁陽、廣陽、上穀、代郡、雁門、太原、朔方諸郡界，招來種人，給其衣食，置校尉以領護之，遂爲漢偵備，擊匈奴、鮮卑。

**释读** 郝旦等人来朝，汉封八十余名首领，令其居民分布诸边郡并设置校尉，作为塞上预警和战力。

**归年** 明载建武二十五年；与同年《后汉书·乌桓传》合并。

<a id="sgz030-p-001-14"></a>

**[《三国志·乌丸鲜卑东夷传》裴注 001·14](../../sources/本地分卷/三国志/三国志-卷030.md#pei-001-14)**

> 建武二十五年烏丸大人郝且等九千餘人率衆詣闕封其渠帥為侯王者八十餘人使居塞内布列遼東屬國遼西右北平漁陽廣陽上谷代郡鴈門太原朔方諸郡界招来種人給其衣食置校尉以領䕶之遂為漢偵備擊匈奴鮮卑

**释读** 乌丸多部入朝，渠帅封王侯，沿边安置，朝廷供衣食并置校尉护领，由其侦防。

**归年** 注直载建武二十五年；四库本郝且，仓内TXT郝旦。

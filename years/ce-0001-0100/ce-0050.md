# 公元50年｜建武二十六年

[← 公元49年](ce-0049.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元51年 →](ce-0051.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **诏有司增百官奉。** 二十六年正月，诏有司增百官奉。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **其千石已上，减於西京旧制。** 其千石已上，减于西京旧制；六百石已下，增于旧秩。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **初作寿陵。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **将作大匠窦融上言园陵广袤，无虑所用。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **帝曰“古者帝王之葬”。** 帝曰：「古者帝王之葬，皆陶人瓦器，木车茅马，使后世之人不知其处。太宗识终始之义，景帝能述遵孝道，遭天下反覆，而霸陵独完受其福，岂不美哉！今所制地不过二三顷，无为山陵，陂池裁令流水而已。」 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **遣中郎将段郴授南单于玺绶，令入居云中，始置使匈奴中郎将，将兵衞护之。** 派中郎将段郴授南单于玺绶，令入居云中，始置使匈奴中郎将，将兵衞护之。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **南单于遣子入侍，奉奏诣阙。** 南单于遣子入侍，奉奏到阙。于是云中、五原、朔方、北地、定襄、鴈门、上谷、代八郡民归于本土。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **遣谒者分将施刑补理城郭。** 派谒者分将施刑补理城郭。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **发遣边民在中国者，布还诸县，皆赐以装钱，转输给食。** [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **光武命张纯议定禘、祫祭制。** 诏先询张纯，张纯提出礼经、祭时及西汉旧例，光武采用其议。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **南单于徙居美稷。** 南部兵抵御北单于追兵不利，朝廷令南单于移驻西河美稷，留段郴等护卫。 [[11]](#hh-note-11)

<a id="sy-event-12"></a>

12. **置沅南县。** 武陵郡设置沅南县。 [[12]](#sy-note-12)

<a id="sy-event-13"></a>

13. **朝廷增发官吏俸禄。** 四月戊戌，朝廷增加官吏俸禄。 [[13]](#sy-note-13)

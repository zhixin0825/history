1. **朝廷调整百官俸禄。** 正月诏有司增百官俸禄。新定俸例与西京旧制相比，千石及以上的官秩减俸，六百石及以下增俸。四月戊戌，朝廷给官吏增俸。 [[1]](#hh-note-1)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

<a id="hh-event-5"></a>

2. **光武营建寿陵，主张俭薄不封山陵。** 朝廷开始营建寿陵，将作大匠窦融上奏陵园范围和用度。光武援古帝王薄葬与汉文帝霸陵得全之例，主张用陶瓦、木车茅马，陵地不过二三顷，不作高大封土，只疏池引流。 [[2]](#hh-note-3)

<a id="hh-event-6"></a>

<a id="hh-event-7"></a>

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

<a id="hh-event-11"></a>

3. **汉授南单于玺绶，安置南部与归边居民。** 汉使段郴授南单于玺绶，令居云中，置使匈奴中郎将率兵护卫。南单于遣子入侍、奉奏。汉廷遣返内徙边民，使云中、五原、朔方、北地、定襄、雁门、上谷、代八郡居民回乡，赐装钱并供途中粮食，遣使率刑徒修治城郭。南部抵御北单于追兵不利后，汉廷令南单于移驻西河美稷，留段郴等护卫。 [[3]](#hh-note-6)

<a id="hh-event-10"></a>

4. **光武命张纯议定禘、祫祭制。** 诏先询张纯，张纯提出礼经、祭时及西汉旧例，光武采用其议。 [[4]](#hh-note-10)

<a id="sy-event-12"></a>

5. **置沅南县。** 武陵郡设置沅南县。 [[5]](#sy-note-12)

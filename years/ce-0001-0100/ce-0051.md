1. **玉况去世，改三公官名并重定人选。** 四月戊午，大司徒玉况去世。五月丁丑，光武以契、禹官名为例，诏司徒、司空去「大」字，并改大司马为太尉。骠骑将军刘隆所行大司马事罢，以太仆赵憙为太尉，大司农冯勤为司徒。 [[1]](#hh-note-1)

<a id="hh-event-5"></a>

<a id="hh-event-8"></a>

2. **哀牢等领众内属。** 益州郡边外各部内属，哀牢王贤栗等率部归附，光武封其首领为君长。 [[2]](#hh-note-5)

<a id="hh-event-6"></a>

3. **北匈奴遣使诣武威乞和亲。** 北匈奴遣使到武威乞和亲。 [[3]](#hh-note-6)

<a id="hh-event-7"></a>

<a id="hh-event-9"></a>

4. **鲁王刘兴、齐王刘石分别就国。** 冬季，鲁王刘兴、齐王刘石初次到各自封国。 [[4]](#hh-note-7)

<a id="hh-event-10"></a>

5. **举孝廉，补淮阳国医工长，随王之国。** 建武二十七年，举孝廉，补淮阳国医工长，随王之国。 [[5]](#hh-note-10)

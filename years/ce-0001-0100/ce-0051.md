# 公元51年｜建武二十七年

[← 公元50年](ce-0050.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元52年 →](ce-0052.md)

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **大司徒玉况薨。** 二十七年夏四月戊午，大司徒玉况去世。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏曰“昔契作司徒”。** 五月丁丑，诏曰：「昔契作司徒，禹作司空，皆无『大』名，其令二府去『大』。」 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **又改大司马为太尉。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **骠骑大将军行大司马刘隆即日罢，太仆赵憙为太尉，大司农冯勤为司徒。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **益州郡徼外蛮夷率种人内属。** [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **北匈奴遣使诣武威乞和亲。** 北匈奴遣使到武威乞和亲。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **鲁王兴、齐王石始就国。** 冬，鲁王兴、齐王石始就国。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **哀牢王贤栗内属。** 贤栗等率众请内附，光武封他们为君长。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **石始就国。** 建武二十七年，石始就国。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **举孝廉，补淮阳国医工长，随王之国。** 建武二十七年，举孝廉，补淮阳国医工长，随王之国。 [[10]](#hh-note-10)

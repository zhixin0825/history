# 公元54年｜建武三十年

[← 公元53年](ce-0053.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元55年 →](ce-0055.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **鲜卑大人内属，朝贺。** 三十年春正月，鲜卑大人内属，朝贺。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **东巡狩。** 二月，东巡狩。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **幸鲁，进幸济南。** 甲子，幸鲁，进幸济南。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **闰月癸丑，车驾还宫。** 闰月癸丑，皇帝回宫。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **有星孛於紫宫。** 有星孛于紫宫。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **徙左翊王焉为中山王。** 夏四月戊子，徙左翊王焉为中山王。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **大水。** 五月，大水。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **赐天下男子爵，人二级。** 赐天下男子爵，人二级；鳏、寡、孤、独、笃［］、贫不能自存者粟，人五斛。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **幸鲁国。** 秋七月丁酉，幸鲁国。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **复济阳县是年傜役。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **至自鲁。** 冬十一月丁酉，至自鲁。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **班彪卒于望都长任上。** 班彪任望都长时去世，年五十二。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **鲜卑大人来朝。** 鲜卑大人于仇贲、满头等率众来朝，称愿附汉。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **闰月甲午，水在东井二十度，生白气，东南指，炎长五尺，为彗，东北行，至紫宫西籓。** 《天文志》记三十年闰月甲午，水在东井二十度，生白气，东南指，炎长五尺，为彗，东北行，至紫宫西籓止，五月甲子不见，凡见三十一日。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **封栩二子为乡侯。** 建武三十年，封栩二子为乡侯。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **羣臣上言，即位三十年，宜封禅泰山。** 建武三十年二月，群臣上言，即位三十年，宜封禅泰山。 [[16]](#hh-note-16)

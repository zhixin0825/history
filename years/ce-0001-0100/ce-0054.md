# 公元54年｜建武三十年

[← 公元53年](ce-0053.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元55年 →](ce-0055.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

<a id="hh-event-13"></a>

1. **鲜卑于仇贲、满头等率众来朝。** 正月，鲜卑首领于仇贲、满头等率众来朝，并愿内属。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

2. **光武东巡鲁、济南后还宫。** 光武东巡到鲁、济南，闰月癸丑还宫。 [[2]](#hh-note-2)

<a id="hh-event-5"></a>

<a id="hh-event-14"></a>

3. **彗星从东井行至紫宫。** 闰月甲午，东井所见彗长五尺，向东北行，停在紫宫西藩，五月甲子不见，共见三十一日。 [[3]](#hh-note-5)

<a id="hh-event-6"></a>

4. **徙左翊王焉为中山王。** 夏四月戊子，徙左翊王焉为中山王。 [[4]](#hh-note-6)

<a id="hh-event-7"></a>

5. **大水。** 五月，大水。 [[5]](#hh-note-7)

<a id="hh-event-8"></a>

6. **赐天下男子爵，人二级。** 赐天下男子爵，人二级；鳏、寡、孤、独、笃［］、贫不能自存者粟，人五斛。 [[6]](#hh-note-8)

<a id="hh-event-9"></a>

<a id="hh-event-11"></a>

7. **光武秋日再幸鲁国。** 七月丁酉，光武再到鲁国，随后还宫。 [[7]](#hh-note-9)

<a id="hh-event-10"></a>

8. **复济阳县是年傜役。** [[8]](#hh-note-10)

<a id="hh-event-12"></a>

9. **班彪卒于望都长任上。** 班彪任望都长时去世，年五十二。 [[9]](#hh-note-12)

<a id="hh-event-15"></a>

10. **封栩二子为乡侯。** 建武三十年，封栩二子为乡侯。 [[10]](#hh-note-15)

<a id="hh-event-16"></a>

11. **羣臣上言，即位三十年，宜封禅泰山。** 建武三十年二月，群臣上言，即位三十年，宜封禅泰山。 [[11]](#hh-note-16)

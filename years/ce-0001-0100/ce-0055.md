<a id="hh-event-4"></a>

1. **郡国水灾与夏季蝗灾。** 本年有大水，夏季又发生蝗灾。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **赐天下男子爵，人二级。** 戊辰，赐天下男子爵，人二级；鳏、寡、孤、独、笃［］、贫不能自存者粟，人六斛。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **日有食之。** 癸酉晦，发生日食。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

4. **诏令死罪系囚皆一切募下蚕室，其女子宫。** 秋九月甲辰，诏令在押死囚皆一切募下蚕室，其女子宫。 [[4]](#hh-note-5)

<a id="hh-event-6"></a>

5. **是岁，陈留雨谷，形如稗实。** 当年，陈留雨谷，形如稗实。 [[5]](#hh-note-6)

<a id="hh-event-7"></a>

6. **北匈奴遣使奉献。** 北匈奴派使者进献。 [[6]](#hh-note-7)

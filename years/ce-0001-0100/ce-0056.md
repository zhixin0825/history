**汉光武帝建武中元元年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **光武营起明堂辟雍。** 《通鉴》据本纪把起明堂、灵台、辟雍归建武中元元年。 [[1]](#hs-note-1)

<a id="hh-event-2"></a>

2. **东海王强、沛王辅、楚王英、济南王康、淮阳王延、赵王盱皆来朝。** 中元元年春正月，东海王强、沛王辅、楚王英、济南王康、淮阳王延、赵王盱皆入朝觐见。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **东巡狩。** 丁卯，东巡狩。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **幸鲁，进幸太山。** 二月己卯，幸鲁，进幸太山。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **北海王兴、齐王石朝於东岳。** 北海王兴、齐王石朝于东岳。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **柴望岱宗，登封太山。** 辛卯，柴望岱宗，登封太山；甲午，禅于梁父。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **司空张纯薨。** 三月戊辰，司空张纯去世。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **车驾还宫。** 夏四月癸酉，皇帝回宫。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **大赦天下。** 己卯，颁布大赦。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **复嬴、博、梁父、奉高，勿出今年田租刍稾。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **改年为中元。** [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **行幸长安。** 行前往长安。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **祀长陵。** 戊子，祀长陵。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **至自长安。** 五月乙丑，至自长安。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **太仆冯鲂为司空。** 六月辛卯，太仆冯鲂为司空。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **司徒冯勤薨。** 乙未，司徒冯勤去世。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **是夏，京师醴泉涌出，饮之者固疾皆愈，惟眇、蹇者不瘳。** [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **又有赤草生於水崖。** 又有赤草生于水崖。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **郡国频上甘露。** [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **羣臣奏言。** 群臣奏言：「地只灵应而朱草萌生。孝宣帝每有嘉瑞，辄以改元，神爵、五凤、甘露、黄龙，列为年纪，盖以感致神只，表彰德信。是以化致昇平，称为中兴。今天下清宁，灵物仍降。陛下情存损挹，推而不居，岂可使祥符显庆，没而无闻？冝令太史撰集，以传来世。」 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **帝不纳。** [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **常自谦无德，每郡国所上，辄抑而不当，故史官罕得记焉。** [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **郡国三蝗。** 秋，郡国三蝗。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **司隷校尉东莱李欣为司徒。** 冬十月辛未，司隷校尉东莱李欣为司徒。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **使司空告祠高庙曰。** 甲申，使司空告祠高庙曰：「高皇帝与群臣约，非刘氏不王。吕太后贼害三赵，专王吕氏，赖社稷之灵，禄、产伏诛，天命几坠，危朝更安。吕太后不冝配食高庙，同祧至尊。薄太后母德慈仁，孝文皇帝贤明临国，子孙赖福，延祚至今。其上薄太后尊号曰高皇后，配食地只。迁吕太后庙主于园，四时上祭。」 [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **日有食之。** 十一月甲子晦，发生日食。 [[26]](#hh-note-26)

<a id="hh-event-27"></a>

27. **宣布图谶於天下。** 宣布图谶于天下。 [[27]](#hh-note-27)

<a id="hh-event-28"></a>

28. **复济阳、南顿是年傜役。** [[28]](#hh-note-28)

<a id="hh-event-29"></a>

29. **参狼羌寇武都，败郡兵，陇西太守刘盱遣军救之，及武都郡兵讨叛羌，皆破之。** [[29]](#hh-note-29)

<a id="hh-event-30"></a>

30. **复行司徒事。** 中元元年，复行司徒事。 [[30]](#hh-note-30)

<a id="hh-event-31"></a>

31. **袭父友封显亲侯。** 中元元年，袭父友封显亲侯。 [[31]](#hh-note-31)

<a id="hh-event-32"></a>

32. **薨，帝悼惜之，使者吊祠，赐东园秘器，賵赠有加。** 中元元年，薨，帝悼惜之，使者吊祠，赐东园秘器，賵赠有加。 [[32]](#hh-note-32)

<a id="hh-event-33"></a>

33. **从封泰山。** 中元元年，从封泰山。 [[33]](#hh-note-33)

<a id="hh-event-34"></a>

34. **从东封岱宗，行卫尉事。** 中元元年，从东封岱宗，行卫尉事。 [[34]](#hh-note-34)

<a id="hh-event-35"></a>

35. **山阳、楚、沛多蝗，其飞至九江界者，辄东西散去，由是名称远近。** 中元元年，山阳、楚、沛多蝗，其飞至九江界者，辄东西散去，由是名称远近。 [[35]](#hh-note-35)

<a id="hh-event-36"></a>

36. **入朝，从封岱山，因留京师。** 中元元年，入朝，从封岱山，因留京师。 [[36]](#hh-note-36)

<a id="hh-event-37"></a>

37. **迁黾池令。** 中元元年，迁黾池令。 [[37]](#hh-note-37)

<a id="hh-event-38"></a>

38. **武都参狼羌反，杀略吏人，太守与战不胜，陇西太守刘盱遣从事辛都、监军掾李苞，将五千人赴武都…。** 中元元年，武都参狼羌反，杀略吏人，太守与战不胜，陇西太守刘盱遣从事辛都、监军掾李苞，将五千人赴武都，与羌战，斩其酋豪，首虏千余人。 [[38]](#hh-note-38)

<a id="hh-event-39"></a>

39. **日有蚀之，在斗二十度。** 中元元年十一月甲子晦，发生日食，在斗二十度。 [[39]](#hh-note-39)

<a id="sy-event-40"></a>

40. **南单于比去世，弟莫继位。** 南单于比去世，中郎将段郴吊祭、分兵护丧。左贤王莫继位，朝廷派使者授印绶、赐衣物，并令赐诸王。 [[40]](#sy-note-40)

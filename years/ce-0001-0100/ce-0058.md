1. **帝率公卿已下朝於原陵，如元会仪。** 永平元年春正月，帝率公卿已下朝于原陵，如元会仪。 [[1]](#hh-note-1)

<a id="hh-event-12"></a>

2. **太傅邓禹去世，谥元侯。** 太傅邓禹去世，年五十七，谥元侯。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

3. **东海王刘强去世，厚礼下葬。** 东海王刘强去世，朝廷遣司空冯鲂持节视丧，赐升龙旄头、銮辂和龙旗，以恭王之号下葬。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

<a id="hh-event-6"></a>

<a id="hh-event-10"></a>

4. **窦固、马武破烧当羌并募士戍陇右。** 七月，马武等大破烧当羌。窦固、马武在西邯击败滇吾，并迁置降者。朝廷另招募士卒戍守陇右，每人赐钱三万。 [[4]](#hh-note-5)

<a id="hh-event-7"></a>

5. **徙山阳王荆为广陵王，遣就国。** 八月戊子，徙山阳王荆为广陵王，遣就国。 [[5]](#hh-note-7)

<a id="hh-event-8"></a>

<a id="hh-event-13"></a>

<a id="hh-event-23"></a>

6. **祭肜使偏何破赤山乌桓与歆志贲。** 辽东太守祭肜使鲜卑首领偏何攻破赤山乌桓，偏何斩其魁帅并送首级到辽东，塞外震动。祭肜又资助偏何击杀歆志贲。鲜卑诸部首领陆续归附，到辽东受赏，青、徐二州每年拨钱二亿七千万以作常例。 [[6]](#hh-note-8)

<a id="hh-event-9"></a>

<a id="hh-event-22"></a>

7. **姑复夷再起，益州军平定。** 越巂姑复夷再起，益州刺史发兵击破，斩其首领，传首京师。 [[7]](#hh-note-9)

<a id="hh-event-11"></a>

<a id="hh-event-16"></a>

11. **诏曰“故侍中卫尉关内侯兴”。** 永平元年，诏曰：『故侍中卫尉关内侯兴，典领禁兵，从平天下，当以军功显受封爵，又诸舅比例，应蒙恩泽，兴皆固让，安乎里巷。辅导朕躬，有周昌之直，在家仁孝，有曾、闵之行，不幸早卒，朕甚伤之。贤者子孙，宜加优异。其以汝南之鮦阳封兴子庆为鲷阳侯，庆弟博为㶏强侯。』 [[11]](#hh-note-16)

<a id="hh-event-17"></a>

> 是歲，遼東太守祭肜使鮮卑擊赤山烏桓，大破之，斬其渠帥。

<a id="sgz030-b-1579-16"></a>

**[《三国志·乌丸鲜卑东夷传》仓内原文 L1579](../../拆分史书/三国志/卷030.md#l1579)**

> 至永平中，漁陽烏丸大人欽志賁帥種人叛，鮮卑還爲寇害，遼東太守祭肜募殺志賁，遂破其衆。

**释读** 渔阳乌丸首领欽志賁据众反叛，辽东太守祭肜招杀首领、破其部众。

**归年** 《后汉书·明帝纪》永平元年载祭肜使鲜卑破赤山乌桓、斩渠帅。两书记人名、地名的详略有异，附作同一役互证。

<a id="sgz030-p-001-15"></a>

**[《三国志·乌丸鲜卑东夷传》裴注 001·15](../../拆分史书/三国志/卷030.md#pei-001-15)**

> 至永平中漁陽烏丸大人欽志賁帥種人叛鮮卑還為宼害遼東太守祭彤募殺志賁遂破其衆

**释读** 祭彤利用鲜卑击破反叛的乌丸首领。

**归年** 《后汉书·鲜卑传》永平元年同事，作祭肜、歆志賁；固定本照录。

<a id="sgz030-p-004-4"></a>

**[《三国志·乌丸鲜卑东夷传》裴注 004·4](../../拆分史书/三国志/卷030.md#pei-004-4)**

> 永平中祭彤為遼東太守誘賂鮮卑使斬叛烏丸欽志賁等首於是鮮卑自燉煌酒泉以東邑落大人皆詣遼東受賞賜青徐二州嵗給錢二億七千萬以為常

**释读** 祭彤以报偿诱鲜卑斩乌丸反叛头领，之后鲜卑各部来领赏，并由青徐二州供钱。

**归年** 《后汉书·鲜卑传》明确永平元年，作祭肜、歆志賁；后段受赏为此役之后的长期措施。

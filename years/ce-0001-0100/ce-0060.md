# 公元60年｜永平三年

[← 公元59年](ce-0059.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元61年 →](ce-0061.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **诏曰“朕奉郊祀”。** 三年春正月癸巳，诏曰：『朕奉郊祀，登灵台，见史官，正仪度。夫春者，岁之始也。始得其正，则三时有成。比者水旱不节，边人食寡，政失于上，人受其咎，有司其勉顺时气，劝督农桑，去其螟蜮，以及蝥贼；详刑慎罚，明察单辞，夙夜匪懈，以称朕意。』 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **太尉赵憙、司徒李欣免。** 二月甲寅，太尉赵憙、司徒李欣免。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **左冯翊郭丹为司徒。** 丙辰，左冯翊郭丹为司徒。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **南阳太守虞延为太尉。** 己未，南阳太守虞延为太尉。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **立贵人马氏为皇后，皇子炟为皇太子。** 甲子，立贵人马氏为皇后，皇子炟为皇太子。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **赐天下男子爵，人二级。** 赐天下男子爵，人二级；三老、孝悌、力田人三级；流人无名数欲占者人一级；鳏、寡、孤、独、笃癃、贫不能自存者粟，人五斛。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **封皇子建为千乘王，羡为广平王。** 夏四月辛酉，封皇子建为千乘王，羡为广平王。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **有星孛於天船北。** 六月丁卯，有星孛于天船北。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **改大乐为大予乐。** 秋八月戊辰，改大乐为大予乐。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **日有蚀之。** 壬申晦，发生日食。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **诏曰“朕奉承祖业”。** 诏曰：『朕奉承祖业，无有善政。日月薄蚀，彗孛见天，水旱不节，稼穑不成，人无宿储，下生愁垫。虽夙夜勤思，而智能不逮。昔楚庄无灾，以致戒惧；鲁哀祸大，天不降谴。今之动变，傥尚可救。有司勉思厥职，以匡无德。古者卿士献诗，百工箴谏。其言事者，靡有所讳。』 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **蒸祭光武庙，初奏《文始》、《五行》、《武德》之舞。** 冬十月，蒸祭光武庙，初奏《文始》、《五行》、《武德》之舞。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **车驾从皇太后幸章陵，观旧庐。** 甲子，车驾从皇太后幸章陵，观旧庐。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **至自章陵。** 十二月戊辰，至自章陵。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **是岁，起北宫及诸官府。** 当年，起北宫及诸官府。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **京师及郡国七大水。** [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **立刘炟为皇太子。** 明帝立贾贵人所生刘炟为太子。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **休莫霸起兵脱离莎车。** 于窴君得暴虐被杀，休莫霸与韩融等起兵，夺城并成为于窴王。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **彗星出天舩北，长二尺所，稍北行至亢南。** 《天文志》记三年六月丁卯，彗星出天舩北，长二尺所，稍北行至亢南。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **帝从太后幸章陵，置酒旧宅，会阴、邓故人诸家子孙，并受赏赐。** 永平三年冬，帝从太后幸章陵，置酒旧宅，会阴、邓故人诸家子孙，并受赏赐。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **有司奏立长秋宫，帝未有所言。** 永平三年春，有司奏立长秋宫，帝未有所言。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **代李为司徒。** 永平三年，代李为司徒。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **察孝廉，显宗诏曰。** 永平三年，察孝廉，显宗诏曰：「大孝入朝，凡诸举者一听平之。」 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **明帝永平三年八月壬申晦，日有蚀之，在氐二度。** 明帝永平三年八月壬申晦，发生日食，在氐二度。 [[24]](#hh-note-24)

# 公元61年｜永平四年

[← 公元60年](ce-0060.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元62年 →](ce-0062.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **诏曰“朕亲耕藉田”。** 四年春二月辛亥，诏曰：『朕亲耕藉田，以祈农事。京师冬无宿雪，春不燠沐，烦劳群司，积精祷求。而比再得时雨，宿麦润泽。其赐公卿半奉。有司勉遵时政，务平刑罚。』 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **千乘王建薨。** 秋九月戊寅，千乘王建去世。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

3. **郭丹、冯鲂免职，范迁、伏恭接任。** 司徒郭丹、司空冯鲂罢免。河南尹范迁任司徒，太仆伏恭任司空。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

4. **陵乡侯梁松下狱死。** 十二月，陵乡侯梁松下狱后死亡。 [[4]](#hh-note-5)

<a id="hh-event-6"></a>

5. **客星出梗河西北，指贯索，七十日去。** 四年八月辛酉，客星出梗河西北，指贯索，七十日去。 [[5]](#hh-note-6)

<a id="hh-event-7"></a>

6. **徵拜河南尹，以清静称。** 永平四年，徵拜河南尹，以清静称。 [[6]](#hh-note-7)

<a id="hh-event-8"></a>

7. **坐考陇西太守邓融，听任奸吏，策免，削爵士。** 永平四年，坐考陇西太守邓融，听任奸吏，策免，削爵士。 [[7]](#hh-note-8)

<a id="hh-event-9"></a>

8. **随例归国。** 永平四年，随例归国。 [[8]](#hh-note-9)

<a id="sy-event-10"></a>

9. **捕虏将军马武去世。** 捕虏将军马武去世。 [[9]](#sy-note-10)

# 公元62年｜永平五年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **骠骑将军东平王苍罢归藩。** 五年春二月庚戌，骠骑将军东平王苍罢归藩；琅邪王京就国。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **行幸邺。** 冬十月，行幸邺。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **与赵王栩会邺。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **常山三老言於帝曰。** 常山三老言于帝曰：『上生于元氏，愿蒙优复。』 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **诏曰“丰、沛、济阳”。** 诏曰：『丰、沛、济阳，受命所由，加恩报德，适其宜也。今永平之政，百姓怨结，而吏人求复，令人愧笑。重逆此县之拳拳，其复元氏县田租更赋六岁，劳赐县掾史，及门阑走卒。』 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **至自邺。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **北匈奴寇五原。** 十一月，北匈奴寇五原；十二月；寇云中，南单于击却之。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **是岁，发遣边人在内郡者，赐装钱人二万。** 当年，发遣边人在内郡者，赐装钱人二万。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **班固奉召校书，班超随母入洛阳。** 班固被召为校书郎，班超随母入京，以替官府抄书养家。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **刘昞初封常山王。** 刘昞初封常山，后来徙淮阳。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **显宗更封平为竟陵侯。** 永平五年，显宗更封平为竟陵侯。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **入代鲍昱为司隶校尉，多所举正，百僚敬惮之。** 永平五年，入代鲍昱为司隶校尉，多所举正，百僚敬惮之。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **坐救火迟，免。** 永平五年，坐救火迟，免。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **坐法征，老小攀车叩马，啼呼相随，日裁行数里，不得前，伦乃伪止亭舍，阴乘船去。** 永平五年，坐法征，老小攀车叩马，啼呼相随，日裁行数里，不得前，伦乃伪止亭舍，阴乘船去。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **诏书捕男子周虑。** 永平五年，诏书捕男子周虑。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **迁大鸿胪。** 永平五年，迁大鸿胪。 [[16]](#hh-note-16)

### 9. 班固奉召校书，班超随母入洛阳

[返回正文第9条](#hh-event-9)

<a id="hh047-l3598-e9"></a>

**[《后汉书·班梁列传》](../../sources/摘录/后汉书-卷047-班梁列传.md#p001)** · [仓内TXT L3598](../../sources/本地分卷/后汉书/后汉书-卷047.md#L3598)

> 永平五年，兄固被召詣校書郎，超與母隨至洛陽。家貧，常爲官傭書以供養。乆勞苦，甞輟業投筆歎曰：「大丈夫無它志略，猶當效傅介子、張騫立功異域，以取封侯，安能乆事筆研閒乎？」左右皆笑之。超曰：「小子安知壯士志哉！」其後行詣相者，曰：「祭酒，布衣諸生耳，而當封侯萬里之外。」超問其狀。相者指曰：「生燕頷虎頸，飛而食肉，此萬里侯相也。」乆之，顯宗問固「卿弟安在」，固對「爲官寫書，受直以養老母」。帝乃除超爲蘭臺令史，後坐事免官。

**归年与互校** 年次据本传。

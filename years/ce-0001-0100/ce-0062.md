1. **骠骑将军东平王苍罢归藩。** 五年春二月庚戌，骠骑将军东平王苍罢归藩；琅邪王京就国。 [[1]](#hh-note-1)

2. **明帝幸邺，会赵王并免元氏租赋。** 十月明帝到邺，与赵王刘栩相会。常山三老以明帝生于元氏，请朝廷优免当地赋税。明帝下诏免元氏六年田租更赋，赏县掾史与门阑、走卒，随后回宫。 [[2]](#hh-note-2)

<a id="hh-event-7"></a>

<a id="hh-event-8"></a>

3. **北匈奴犯五原、云中，朝廷遣还边民。** 十一月北匈奴犯五原，十二月又犯云中，南单于将其击退。朝廷遣居内郡的边民还乡，每人给装钱两万。 [[3]](#hh-note-7)

<a id="hh-event-9"></a>

4. **班固奉召校书，班超随母入洛阳。** 班固被召为校书郎，班超随母入京，以替官府抄书养家。 [[4]](#hh-note-9)

<a id="hh-event-10"></a>

5. **刘昞初封常山王。** 刘昞初封常山，后来徙淮阳。 [[5]](#hh-note-10)

<a id="hh-event-11"></a>

6. **显宗更封平为竟陵侯。** 永平五年，显宗更封平为竟陵侯。 [[6]](#hh-note-11)

13. **杨岑与官历校测月相。** 杨岑指出官历所署月食日期滞后一日。朝廷用实际天象校验从七月至十一月的五次弦望，杨岑所报皆中，遂使其负责推算月相和月食，又让张盛等以四分法与之比较。 [[13]](#sy-note-18)

<a id="sy-hh089-l6624-e7"></a>

> 五年冬，北匈奴六七千騎入於五原塞，遂寇雲中，至原陽。南單于擊卻之，西河長史馬襄赴救，虜乃引去。

**本段所记** 北匈奴入五原塞、犯云中至原阳，南单于击退来敌，西河长史马襄也率兵赴救。

**归年与互校** “五年冬”承同段永平纪年，和《明帝纪》永平五年条互证，未增另一场战事。

### 4. 班固奉召校书，班超随母入洛阳

[返回正文第4条](#hh-event-9)

<a id="hh047-l3598-e9"></a>

**[《后汉书·班梁列传》](../../拆分史书/后汉书/卷047.md#p001)** · [仓内TXT L3598](../../拆分史书/后汉书/卷047.md#part-1-L3598)

> 永平五年，兄固被召詣校書郎，超與母隨至洛陽。家貧，常爲官傭書以供養。乆勞苦，甞輟業投筆歎曰：「大丈夫無它志略，猶當效傅介子、張騫立功異域，以取封侯，安能乆事筆研閒乎？」左右皆笑之。超曰：「小子安知壯士志哉！」其後行詣相者，曰：「祭酒，布衣諸生耳，而當封侯萬里之外。」超問其狀。相者指曰：「生燕頷虎頸，飛而食肉，此萬里侯相也。」乆之，顯宗問固「卿弟安在」，固對「爲官寫書，受直以養老母」。帝乃除超爲蘭臺令史，後坐事免官。

**归年与互校** 年次据本传。

### 13. 杨岑与官历校测月相

[返回正文第13条](#sy-event-18)

<a id="sy-hh092-l6820-e18"></a>

**[《后汉书·律历志中》](../../拆分史书/后汉书/卷092.md#p001)** · [仓内TXT L6820](../../拆分史书/后汉书/卷092.md#part-1-L6820)

> 至永平五年，官歷署七月十六日食。待詔楊岑見時月食多先歷，即縮用筭上為日，上言「月當十五日食，官歷不中」。詔書令岑普，與官課。起七月，盡十一月，弦望凡五，官歷皆失，岑皆中。庚寅，詔令岑署弦望月食官，復令待詔張盛﹑景防﹑鮑鄴等以四分法與岑課。

**归年与互校** 《律历志》明记永平五年。原文“起七月，尽十一月”，所校为弦、望。

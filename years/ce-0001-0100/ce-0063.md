# 公元63年｜永平六年

[← 公元62年](ce-0062.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元64年 →](ce-0064.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **沛王辅、楚王英、东平王苍、淮阳王延、浪邪王京、东海王政、赵王盱、北海王兴、齐王石来朝。** 六年春正月，沛王辅、楚王英、东平王苍、淮阳王延、浪邪王京、东海王政、赵王盱、北海王兴、齐王石入朝觐见。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **王雒山出宝鼎，庐江太守献之。** 二月，王雒山出宝鼎，庐江太守献之。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **诏曰“昔禹收九牧之金”。** 夏四月甲子，诏曰：『昔禹收九牧之金，铸鼎以象物，使人知神奸，不逢恶气。遭德则兴，迁于商、周；周德既衰，鼎乃沦亡。祥瑞之降，以应有德。方今政化多僻，何以致兹？《易》曰鼎象三公，岂公卿奉职得其理邪？太常其以礿祭之日，陈鼎于庙，以备器用。赐三公帛五十匹，九卿、二千石半之。先帝诏书，禁人上事言圣，而间者章奏颇多浮词，自今若有过称虚誉，尚书皆宜抑而不省，示不为谄子蚩也。』 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **行幸鲁，祠东海恭王陵。** 冬十月，行幸鲁，祠东海恭王陵；会沛王辅、楚王英、济南王康、东平王苍、淮阳王延、琅邪王京、东海王政。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **还，幸阳城，遣使者祠中岳。** 十二月，还，幸阳城，派使者祠中岳。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **车驾还宫。** 壬午，皇帝回宫。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **东平王苍、琅邪王京从驾来朝皇太后。** [[7]](#hh-note-7)

1. **沛王辅、楚王英、东平王苍、淮阳王延、浪邪王京、东海王政、赵王盱、北海王兴、齐王石来朝。** 六年春正月，沛王辅、楚王英、东平王苍、淮阳王延、浪邪王京、东海王政、赵王盱、北海王兴、齐王石入朝觐见。 [[1]](#hh-note-1)

<a id="hh-event-3"></a>

2. **庐江献王雒山宝鼎，明帝下诏。** 庐江太守进献王雒山发现的宝鼎，明帝以禹收九牧之金铸鼎的旧事下诏。 [[2]](#hh-note-2)

<a id="hh-event-4"></a>

<a id="hh-event-5"></a>

<a id="hh-event-6"></a>

3. **明帝祭东海恭王陵并遣使祠中岳。** 明帝到鲁祭东海恭王陵，回经阳城，命使者祭中岳，随后回宫。 [[3]](#hh-note-4)

<a id="hh-event-7"></a>

4. **东平王苍、琅邪王京从驾来朝皇太后。** [[4]](#hh-note-7)

<a id="sy-event-8"></a>

5. **南匈奴单于长即位。** 胡邪尸逐侯鞮单于长接立。 [[5]](#sy-note-8)

<a id="hh002-l426-e3"></a>

**[《后汉书·明帝纪》](../../sources/摘录/后汉书-卷002-明帝纪.md#p002)** · [仓内TXT L426](../../sources/本地分卷/后汉书/后汉书-卷002.md#L426)

> 夏四月甲子，詔曰：『昔禹收九牧之金，鑄鼎以象物，使人知神姦，不逢惡氣。遭德則興，遷於商、周；周德既衰，鼎乃淪亡。祥瑞之降，以應有德。方今政化多僻，何以致茲？《易》曰鼎象三公，豈公卿奉職得其理邪？太常其以礿祭之日，陳鼎於廟，以備器用。賜三公帛五十匹，九卿、二千石半之。先帝詔書，禁人上事言聖，而間者章奏頗多浮詞，自今若有過稱虛譽，尚書皆宜抑而不省，示不為諂子蚩也。』

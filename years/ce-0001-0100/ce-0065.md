<a id="hh-event-2"></a>

1. **范迁去世，虞延接司徒，赵憙行太尉事。** 司徒范迁去世，太尉虞延继任司徒，卫尉赵憙行太尉事。 [[1]](#hh-note-1)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

<a id="hh-event-15"></a>

<a id="hh-event-17"></a>

2. **郑众使北匈奴，汉置度辽将军。** 汉遣越骑司马郑众为报使。郑众在边塞发现南部部分首领私通北匈奴，奏请设将防备。朝廷始置度辽将军，屯五原曼柏。北匈奴本年犯西河等郡。 [[2]](#hh-note-3)

<a id="hh-event-5"></a>

3. **郡国十四雨水。** 秋，郡国十四雨水。 [[3]](#hh-note-5)

<a id="hh-event-6"></a>

4. **北宫成。** 冬十月，北宫成。 [[4]](#hh-note-6)

<a id="hh-event-7"></a>

5. **临辟雍，养三老、五更。** 丙子，临辟雍，养三老、五更。礼毕，诏三公募郡国中都官在押死囚，减刑一等，勿笞，到度辽将军营，屯朔方、五原之边县；妻子自随，便占着边县；父母同产欲相代者，恣听之。 [[5]](#hh-note-7)

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

<a id="hh-event-10"></a>

6. **减刑、赎罪与流徙给粮。** 罪在大逆、无道等殊死者，准募下蚕室。逃亡者依等次赎罪，徙民给弓弩、衣、粮。 [[6]](#hh-note-8)

<a id="hh-event-11"></a>

<a id="hh-event-12"></a>

<a id="hh-event-13"></a>

<a id="hh-event-14"></a>

7. **日全食后，明帝诏群臣言政失。** 壬寅晦发生日全食，明帝下诏自责，令群臣各上封事，极言无讳。览章后，他将奏章颁示百官，又下诏承认冤狱未理、吏黠难禁、役民修宫等弊。 [[7]](#hh-note-11)

<a id="hh-event-16"></a>

8. **楚王刘英献缣，明帝诏还。** 楚王刘英笃好黄老、浮屠，在死罪许以缣帛赎罚时主动献帛，明帝命交还。 [[8]](#hh-note-16)

<a id="hh-event-18"></a>

9. **举孝廉，稍迁。** 永平八年，举孝廉，稍迁；建初中，拜杨州刺史。 [[9]](#hh-note-18)

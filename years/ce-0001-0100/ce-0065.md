# 公元65年｜永平八年

[← 公元64年](ce-0064.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元66年 →](ce-0066.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **司徒范迁薨。** 八年春正月己卯，司徒范迁去世。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **太尉虞延为司徒，卫尉赵憙行太尉事。** 三月辛卯，太尉虞延为司徒，卫尉赵憙行太尉事。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **遣越骑司马郑众报使北匈奴。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **初置度辽将军，屯五原曼柏。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **郡国十四雨水。** 秋，郡国十四雨水。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **北宫成。** 冬十月，北宫成。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **临辟雍，养三老、五更。** 丙子，临辟雍，养三老、五更。礼毕，诏三公募郡国中都官在押死囚，减刑一等，勿笞，到度辽将军营，屯朔方、五原之边县；妻子自随，便占着边县；父母同产欲相代者，恣听之。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **其大逆无道殊死者，一切募下蚕室。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **亡命者令赎罪各有差。** [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **凡徙者，赐弓弩衣粮。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **日有食之，既。** 壬寅晦，发生日食，既。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **诏曰“朕以无德”。** 诏曰：『朕以无德，奉承大业，而下贻人怨，上动三光。日食之变，其灾尤大，《春秋》图谶所为至谴。永思厥咎，在予一人。群司勉修职事，极言无讳。』于是在位者皆上封事，各言得失。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **帝览章，深自引咎，乃以所上班示百官。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **诏曰“群僚所言”。** 诏曰：『群僚所言，皆朕之过。人冤不能理，吏黠不能禁；而轻用人力，缮修宫宇，出入无节，喜怒过差。昔应门失守，《关雎》刺世；飞蓬随风，微子所叹。永览前戒，竦然兢惧。徒恐薄德，久而致怠耳。』 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **北匈奴寇西河诸郡。** [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **楚王刘英献缣，明帝诏还。** 楚王刘英笃好黄老、浮屠，在死罪许以缣帛赎罚时主动献帛，明帝命交还。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **郑众出使北匈奴。** 郑众出塞发现南部部分首领与北匈奴私通，奏请设置将领防之。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **举孝廉，稍迁。** 永平八年，举孝廉，稍迁；建初中，拜杨州刺史。 [[18]](#hh-note-18)

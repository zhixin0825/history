# 公元66年｜永平九年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **诏郡国死罪囚减罪，与妻子诣五原、朔方占着，所在死者皆赐妻父若男同产一人复终身。** 九年春三月辛丑，诏郡国死罪囚减罪，与妻子到五原、朔方占着，所在死者皆赐妻父若男同产一人复终身；其妻无父兄独有母者，赐其母钱六万，又复其口筭。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏郡国以公田赐贫人各有差。** 夏四月甲辰，诏郡国以公田赐贫人各有差。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

3. **考察墨绶长吏的治绩。** 令司隶校尉与部刺史每年推荐一名任职三年以上、政绩尤其优异的墨绶长吏，随岁计上报。尤其不称职者，也须上闻。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

4. **是岁，大有年。** 当年，大有年。 [[4]](#hh-note-5)

<a id="hh-event-6"></a>

<a id="hh-event-10"></a>

5. **南宫为四姓小侯设学。** 明帝为四姓小侯在南宫开设学校，置《五经》师。 [[5]](#hh-note-6)

<a id="hh-event-7"></a>

6. **刘恭赐灵寿王号。** 刘恭先得灵寿王号，后另封钜鹿。 [[6]](#hh-note-7)

<a id="hh-event-8"></a>

7. **刘党获重熹王号。** 刘党先赐重熹王名号，后才封乐成。 [[7]](#hh-note-8)

<a id="hh-event-9"></a>

8. **客星出牵牛，长八尺，历建星至房南灭，见至五十日。** 九年正月戊申，客星出牵牛，长八尺，历建星至房南灭，见至五十日。 [[8]](#hh-note-9)

<a id="sy-event-11"></a>

9. **董萌上奏历法失准。** 太史待诏董萌认为历法失准，朝廷令三公、太常及通晓历法者共同评议。 [[9]](#sy-note-11)

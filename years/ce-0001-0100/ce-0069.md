# 公元69年｜永平十二年

[← 公元68年](ce-0068.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元70年 →](ce-0070.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **益州徼外夷哀牢王相率内属，於是置永昌郡，罢益州西部都尉。** 十二年春正月，益州徼外夷哀牢王相率内属，于是置永昌郡，罢益州西部都尉。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **遣将作谒者王吴修汴渠，自荥阳至於千乘海口。** 夏四月，遣将作谒者王吴修汴渠，自荥阳至于千乘海口。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **赐天下男子爵，人二级，三老、孝悌、力田人三级，流民无名数欲占者人一级。** 五月丙辰，赐天下男子爵，人二级，三老、孝悌、力田人三级，流民无名数欲占者人一级；鳏、寡、孤、独、笃癃、贫无家属不能自存者粟，人三斛。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **诏曰“昔曾、闵奉亲”。** 诏曰：『昔曾、闵奉亲，竭欢致养；仲尼葬子，有棺无椁。丧贵致哀，礼存宁俭。今百姓送终之制，竞为奢靡。生者无担石之储，而财力尽于坟土。伏腊无糟糠，而牲牢兼于一奠。糜破积世之业，以供终朝之费，子孙饥寒，绝命于此，岂祖考之意哉！又车服制度，恣极耳目。田荒不耕，游食者众。有司其申明科禁，宜于今者，宣下郡国。』 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **司空伏恭罢。** 秋七月乙亥，司空伏恭罢。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **大司农牟融为司空。** 乙未，大司农牟融为司空。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **司隶校尉王康下狱死。** 冬十月，司隶校尉王康下狱后死亡。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **是岁，天下安平，人无徭役，岁比登稔，百姓殷富，粟斛三十，牛羊被野。** 当年，天下安平，人无徭役，岁比登稔，百姓殷富，粟斛三十，牛羊被野。 [[8]](#hh-note-8)

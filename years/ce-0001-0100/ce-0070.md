# 公元70年｜永平十三年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **帝耕於藉田。** 十三年春二月，帝耕于藉田。礼毕，赐观者食。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **河南尹薛昭下狱死。** 三月，河南尹薛昭下狱后死亡。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **汴渠成。** 夏四月，汴渠成。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **行幸荥阳，巡行河渠。** 辛巳，行幸荥阳，巡行河渠。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **诏曰“自汴渠决败”。** 乙酉，诏曰：『自汴渠决败，六十余岁，加顷年以来，雨水不时，汴流东侵，日月益甚，水门故处，皆在河中，漭瀁广溢，莫测圻岸，荡荡极望，不知纲纪。今兖、豫之人，多被水患，乃云县官不先人急，好兴它役。又或以为河流入汴，幽、冀蒙利，故曰左堤强则右堤伤，左右俱强则下方伤，宜任水势所之，使人随高而处，公家息壅塞之费，百姓无陷溺之患。议者不同，南北异论，朕不知所从，久而不决。今既筑堤理渠，绝水立门，河、汴分流，复其旧迹，陶丘之北，渐就壤坟，故荐嘉玉絜牲，以礼河神。东过洛汭，叹禹之绩。今五土之宜，反其正色，滨渠下田，赋与贫人，无令豪右得固其利，庶继世宗《瓠子》之作。』 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **因遂度河。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **登太行，进幸上党。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **车驾还宫。** 壬寅，皇帝回宫。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **日有食之。** 冬十月壬辰晦，发生日食。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **三公免冠自劾。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **制曰“冠履勿劾”。** 制曰：『冠履勿劾。灾异屡见，咎在朕躬，忧惧遑遑，未知其方。将有司陈事，多所隐讳，使君上壅蔽，下有不畅乎？昔卫有忠臣，灵公得守其位。今何以和穆阴阳，消伏灾谴？刺史、太守详刑理冤，存恤鳏孤，勉思职焉。』 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **楚王英谋反，废，国除，迁於泾县，所连及死徙者数千人。** 十一月，楚王英谋反，废，国除，迁于泾县，所连及死徙者数千人。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **是岁，齐王石薨。** 当年，齐王石去世。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **河汴工程完成。** 王景、王吴所修之渠在次夏完工，明帝亲自巡行。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **闰月丁亥，火犯舆鬼，爲大丧，质星爲大臣诛戮。** 《天文志》记十三年闰月丁亥，火犯舆鬼，爲大丧，质星爲大臣诛戮。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **亦坐楚事国除。** 永平十三年，亦坐楚事国除。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **坐与舅王平谋反，伏诛，国除。** 永平十三年，坐与舅王平谋反，伏诛，国除。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **楚王英谋为逆，事下郡覆考。** 永平十三年，楚王英谋为逆，事下郡覆考。 [[18]](#hh-note-18)

> 乙酉，詔曰：『自汴渠決敗，六十餘歲，加頃年以來，雨水不時，汴流東侵，日月益甚，水門故處，皆在河中，漭瀁廣溢，莫測圻岸，蕩蕩極望，不知綱紀。今兗、豫之人，多被水患，乃雲縣官不先人急，好興它役。又或以為河流入汴，幽、冀蒙利，故曰左堤強則右堤傷，左右俱強則下方傷，宜任水勢所之，使人隨高而處，公家息壅塞之費，百姓無陷溺之患。議者不同，南北異論，朕不知所從，久而不決。今既築堤理渠，絕水立門，河、汴分流，復其舊跡，陶丘之北，漸就壤墳，故薦嘉玉絜牲，以禮河神。東過洛汭，嘆禹之績。今五土之宜，反其正色，濱渠下田，賦與貧人，無令豪右得固其利，庶繼世宗《瓠子》之作。』

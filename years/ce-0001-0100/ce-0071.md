# 公元71年｜归德侯先贤霸获罪失爵

[← 公元70年](ce-0070.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元72年 →](ce-0072.md)

**汉明帝永平十四年**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hs-event-1"></a>

1. **归德侯先贤霸获罪失爵。** 《功臣表》记归德侯先贤霸在东汉明帝永平十四年获罪失爵。此人为前汉归德侯先贤掸的后嗣；原行没有记他去世，也没有交代具体罪名。 [[1]](#hs-note-1)

<a id="hh-event-2"></a>

2. **司徒虞延免，自杀。** 十四年春三月甲戌，司徒虞延免，自杀。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **钜鹿太守南阳邢穆为司徒。** 夏四月丁巳，钜鹿太守南阳邢穆为司徒。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **前楚王英自杀。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **封故广陵王荆子元寿为广陵侯。** 夏五月，封故广陵王荆子元寿为广陵侯。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **初作寿陵。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **袁安受命追审楚狱。** 楚王英案牵连数千人，袁安以擅治剧郡，次年被荐任楚郡太守。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **客星出昴，六十日，在轩辕右角稍灭。** 《天文志》记十四年正月戊子，客星出昴，六十日，在轩辕右角稍灭。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **封石二子为乡侯。** 永平十四年，封石二子为乡侯。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **坐与楚事相连，国除。** 永平十四年，坐与楚事相连，国除。 [[10]](#hh-note-10)

### 7. 袁安受命追审楚狱

[返回正文第7条](#hh-event-7)

<a id="hh045-l3455-e7"></a>

**[《后汉书·袁张韩周列传》](../../sources/摘录/后汉书-卷045-袁张韩周列传.md#p001)** · [仓内TXT L3455](../../sources/本地分卷/后汉书/后汉书-卷045.md#L3455)

> 明年，三府舉安能理劇，拜楚郡太守。是時英辭所連及系者數千人，顯宗怒甚，吏案之急，迫痛自誣，死者甚觿。

**归年与互校** 承永平十三年发案，十四年袁安任楚郡守；本传到郡后具奏放出四百余家。

<a id="hh045-l3456-e7"></a>

**[《后汉书·袁张韩周列传》](../../sources/摘录/后汉书-卷045-袁张韩周列传.md#p001)** · [仓内TXT L3456](../../sources/本地分卷/后汉书/后汉书-卷045.md#L3456)

> 遂分別具奏。帝感悟，即報許，得出者四百餘家。

**归年与互校** 承上年次，此为到郡先后，不另硬定月日。

<a id="sgz006-p-040-1"></a>

**[《三国志·董二袁刘传》裴注 040·1](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-040-1)**

> 華嶠漢書曰安字邵公好學有威重明帝時為楚郡太守治楚王獄所申理者四百餘家皆蒙全濟安遂為名臣

**释读** 袁安为楚郡太守，复核楚王狱，使四百余家免受诛连。

**归年** 《后汉书·袁安传》永平十三年（70）记楚王英案发，明年（71）袁安拜楚郡太守，到郡后复核此案。

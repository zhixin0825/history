1. **明帝东巡诸王国，祀仲尼并命诸王说经。** 明帝东巡，到偃师时令罪在殊死以下的逃犯各得赎罪。沛王刘辅会驾睢阳，明帝亲耕下邳，征琅邪王刘京会良成、东平王刘苍会阳都、广陵侯及其三弟会鲁。明帝祠东海恭王陵，又至孔子故宅祭孔子及七十二弟子，亲到讲堂，命皇太子、诸王说经。又到东平、大梁、定陶，祭定陶恭王陵后回宫。 [[1]](#hh-note-1)

<a id="hh-event-13"></a>

<a id="hh-event-19"></a>

<a id="hh-event-20"></a>

<a id="hh-event-21"></a>

<a id="hh-event-22"></a>

2. **分置王国，明帝六位皇子受封。** 改信都为乐成国、临淮为下邳国，封皇子刘恭为钜鹿王、刘党为乐成王、刘衍为下邳王、刘畅为汝南王、刘昞为常山王、刘长为济阴王。 [[2]](#hh-note-12)

<a id="hh-event-14"></a>

<a id="hh-event-15"></a>

<a id="hh-event-16"></a>

3. **赐民爵，准大酺并大赦。** 赐天下男子爵三级，许大酺五日，又大赦，将谋反、大逆及旧例不在宽赦之列者也赦免。 [[3]](#hh-note-14)

<a id="hh-event-17"></a>

4. **车骑校猎上林苑。** 冬，车骑校猎上林苑。 [[4]](#hh-note-17)

<a id="hh-event-18"></a>

5. **遣奉车都尉窦固、驸马都尉耿秉屯凉州。** 十二月，遣奉车都尉窦固、驸马都尉耿秉屯凉州。 [[5]](#hh-note-18)

<a id="hh-event-23"></a>

6. **太白与月面相近。** 十一月乙丑，太白与月面相近。 [[6]](#hh-note-23)

<a id="hh-event-24"></a>

7. **皇后敕使移居洛阳。** 永平十五年，皇后敕使移居洛阳。 [[7]](#hh-note-24)

<a id="hh-event-25"></a>

8. **入授皇太子经，迁越骑校尉，诏勑太子、诸王各奉贺致礼。** 永平十五年，入授皇太子经，迁越骑校尉，诏勑太子、诸王各奉贺致礼。 [[8]](#hh-note-25)

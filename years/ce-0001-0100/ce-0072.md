# 公元72年｜永平十五年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **东巡狩。** 十五年春二月庚子，东巡狩。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **幸偃师，诏亡命自殊死以下赎。** 辛丑，幸偃师，诏亡命自殊死以下赎：死罪缣四十匹，右趾至髡钳城旦舂十匹，完城旦至司寇五匹；犯罪未发觉，诏书到日自告者，半入赎。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **徵沛王辅会睢阳。** 徵沛王辅会睢阳。进幸彭城。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **帝耕於下邳。** 癸亥，帝耕于下邳。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **徵琅邪王京会良成，徵东平王苍会阳都，又徵广陵侯及其三弟会鲁。** 三月，徵琅邪王京会良成，徵东平王苍会阳都，又徵广陵侯及其三弟会鲁。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **祠东海恭王陵。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **还，幸孔子宅，祠仲尼及七十二弟子。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **亲御讲堂，命皇太子、诸王说经。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **又幸东平。** [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **进幸大梁，至定陶，祠定陶恭王陵。** 辛卯，进幸大梁，至定陶，祠定陶恭王陵。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **车驾还宫。** 夏四月庚子，皇帝回宫。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **改信都为乐成国，临淮为下邳国。** [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **封皇子恭为钜鹿王、党为乐成王、衍为下邳王、畅为汝南王、丙为常山王、长为济阴王。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **赐天下男子爵，人三级。** 赐天下男子爵，人三级；郎、从官视事二十岁已上帛百匹，十岁已上二十匹，十岁已下十匹，官府吏五匹，书佐、小史三匹。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **令天下大酺五日。** [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **大赦天下，其谋反大逆及诸不应宥者，皆赦除之。** 乙巳，颁布大赦，其谋反大逆及诸不应宥者，皆赦除之。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **车骑校猎上林苑。** 冬，车骑校猎上林苑。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **遣奉车都尉窦固、驸马都尉耿秉屯凉州。** 十二月，遣奉车都尉窦固、驸马都尉耿秉屯凉州。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **封明帝诸子为王。** 刘恭于永平十五年封为钜鹿王。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **刘衍封下邳王。** 明帝立刘衍为下邳王，章帝即位后常留其于身边。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **刘畅初封汝南王。** 明帝封宠子刘畅在汝南，租入多于诸国。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **刘长封济阴王。** 刘长初封济阴。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **太白入月中，爲大将戮，人主亡，不出三年。** 《天文志》记十五年十一月乙丑，太白入月中，爲大将戮，人主亡，不出三年。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **皇后敕使移居洛阳。** 永平十五年，皇后敕使移居洛阳。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **入授皇太子经，迁越骑校尉，诏勑太子、诸王各奉贺致礼。** 永平十五年，入授皇太子经，迁越骑校尉，诏勑太子、诸王各奉贺致礼。 [[25]](#hh-note-25)

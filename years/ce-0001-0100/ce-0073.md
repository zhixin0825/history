3. **耿秉、来苗、祭肜并无功而还。** [[3]](#hh-note-3)

4. **淮阳王延谋反，发觉。** 夏五月，淮阳王延谋反，发觉。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **司徒邢穆、驸马都尉韩光坐事下狱死，所连及诛死者甚众。** 癸丑，司徒邢穆、驸马都尉韩光因事获罪下狱后死亡，所连及诛死者甚众。 [[5]](#hh-note-5)

<a id="hh-event-8"></a>

8. **淮阳王延徙封阜陵王。** 秋七月，淮阳王延徙封阜陵王。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **诏令郡国中都官死罪系囚减死罪一等，勿笞，诣军营，屯朔方、敦煌。** 九月丁卯，诏命各郡国中都官在押死囚减死罪一等，勿笞，到军营，屯朔方、敦煌；妻子自随，父母同产欲求从者，恣听之；女子嫁为人妻，勿与俱。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **谋反大逆无道不用此书。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **是岁，北匈奴寇云中，云中太守廉范击破之。** 当年，北匈奴寇云中，云中太守廉范将其击败。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **窦固出击北匈奴，班超使西域。** 班超先随窦固出战，别攻伊吾，随后与郭恂受命使西域。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **班超初使鄯善。** 国王广对班超礼意忽变，班超推知匈奴另遣使者争夺鄯善。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **班超在疏勒改立新王。** 班超入疏勒后拘捕兜题，立故王侄儿忠为疏勒王。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **岁星犯房右骖，北第一星不见，辛巳乃见。** 十六年正月丁丑，岁星犯房右骖，北第一星不见，辛巳乃见。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **太白犯毕。** 四月癸未，太白犯毕。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **明帝永平十六年，龟兹王建攻杀疏勒王成，自以龟兹左侯兜题为疏勒王。** [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **明帝永平十六年，汉取伊吾卢，通西域，车师始复内属。** [[18]](#hh-note-18)

<a id="sy-event-19"></a>

19. **班超使于阗，于阗王杀匈奴使者。** 班超奉命再使，先至于阗，借处理巫者的请求向国王广德施压。广德闻其此前在鄯善的所为，杀其地匈奴使者而归汉。 [[19]](#sy-note-19)

### 13. 班超初使鄯善

[返回正文第13条](#hh-event-13)

<a id="hh047-l3601-e13"></a>

**[《后汉书·班梁列传》](../../sources/摘录/后汉书-卷047-班梁列传.md#p001)** · [仓内TXT L3601](../../sources/本地分卷/后汉书/后汉书-卷047.md#L3601)

> 超到鄯善，鄯善王廣奉超禮敬甚備，後忽更踈懈。超謂其官屬曰：「寧覺廣禮意薄乎？此必有北虜使來，狐疑未知所從故也。明者睹未萌，況已著邪。」乃召侍胡詐之曰：「匈奴使來數日，今安在乎？」侍胡惶恐，具服其狀。超乃閉侍胡，悉會其吏士三十六人，與共飲，酒酣，因激怒之曰：「卿曹與我俱在絕域，欲立大功，以求富貴。今虜使到裁數日，而王廣禮敬即廢；如令鄯善収吾屬送匈奴，骸骨長爲豺狼食矣。爲之柰何？」官屬皆曰：「今在危亡之地，死生從司馬。」超曰：「不入虎穴，不得虎子。

**归年与互校** 承永平十六年奉使，非次年赴疏勒。

<a id="sy-hh047-l3601-e13"></a>

**[《后汉书·班梁列传》](../../sources/摘录/后汉书-卷047-班梁列传.md#p001)** · [仓内TXT L3601](../../sources/本地分卷/后汉书/后汉书-卷047.md#L3601)

> 超乃順風縱火，前後鼓譟。虜衆驚亂，超手格殺三人，吏兵斬其使及從士三十餘級，餘衆百許人悉燒死。明日乃還告郭恂，恂大驚，旣而色動。超知其意，舉手曰：「掾雖不行，班超何心獨擅之乎？」恂乃恱。超於是召鄯善王廣，以虜使首示之，一國震怖。超曉告撫慰，遂納子爲質。還奏於竇固，固大喜，具上超功效，並求更選使使西域。帝壯超節，詔固曰：「吏如班超，何故不遣而更選乎？今以超爲軍司馬，令遂前功。」超復受使，固欲益其兵，超曰：「願將本所從三十餘人足矣。如有不虞，多益爲累。」

**本段所记** 班超在鄯善打破匈奴使团，示首于鄯善王。鄯善王纳质，窦固奏其功，朝廷授班超军司马，遣其继续出使。

**归年与互校** “初使”承永平十六年明确任命，补同一事件早先所缺结尾。

**[《后汉书》班超传李贤注引《东观记》](../../sources/摘录/后汉书-李贤刘昭注编年首批.md#a-077-53-73)**

> 東觀記曰斬得匈奴節使屋賴帶副使比離支首及節也

**归年与互校** 本传记班超在鄯善斩匈奴使，此注补使者屋赖带、副使比离支及所得符节。

> 是時於窴王廣德新攻破莎車，遂雄張南道，而匈奴遣使監護其國。超旣西，先至於窴。廣德禮意甚踈。且其俗信巫。巫言：「神怒何故欲向漢？漢使有騧馬，急求取以祠我。」廣德乃遣使就超請馬。超密知其狀，報許之，而令巫自來取馬。有頃，巫至，超即斬其首以送廣德，因辭讓之。廣德素聞超在鄯善誅滅虜使，大惶恐，即攻殺匈奴使者而降超。超重賜其王以下，因鎮撫焉。

**归年与互校** 《班梁列传》列在鄯善之后和“明年春”赴疏勒之前，《通鉴》卷045永平十六年条同列于阗降。

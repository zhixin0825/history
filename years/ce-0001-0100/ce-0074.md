# 公元74年｜永平十七年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **甘露降於甘陵。** 十七年春正月，甘露降于甘陵。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **北海王睦薨。** 北海王睦去世。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **司徒王敏薨。** 二月乙巳，司徒王敏去世。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **汝南太守鲍昱为司徒。** 三月癸丑，汝南太守鲍昱为司徒。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **是岁，甘露仍降，树枝内附，芝草生殿前，神雀五色翔集京师。** 当年，甘露仍降，树枝内附，芝草生殿前，神雀五色翔集京师。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **西南夷哀牢、儋耳、僬侥、盘木、白狼、动黏诸种，前後慕义贡献。** 西南夷哀牢、儋耳、僬侥、盘木、白狼、动黏诸种，前后慕义贡献；西域诸国遣子入侍。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **公卿百官以帝威德怀远，祥物显应，乃并集朝堂，奉觞上寿。** 夏五月戊子，公卿百官以帝威德怀远，祥物显应，乃并集朝堂，奉觞上寿。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **制曰“天生神物”。** 制曰：『天生神物，以应王者；远人慕化，实由有德。朕以虚薄，何以享斯？唯高祖、光武圣德所被，不敢有辞。其敬举觞，太常择吉日策告宗庙。其赐天下男子爵，人二级，三老、孝悌、力田人三级，流人无名数欲占者人一级；鳏、寡、孤、独、笃癃、贫不能自存者粟，人三斛；郎、从官视事十岁以上者，帛十匹。中二千石、二千石下至黄绶，贬秩奉赎，在去年以来皆还赎。』 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **令武威、张掖、酒泉、敦煌及张掖属国，系囚右趾已下任兵者，皆一切勿治其罪，诣军营。** 秋八月丙寅，令武威、张掖、酒泉、敦煌及张掖属国，系囚右趾已下任兵者，皆一切勿治其罪，到军营。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **遣奉车都尉窦固、驸马都尉耿秉、骑都尉刘张出敦煌崑仑塞，击破白山虏於蒲类海上，遂入车师。** 冬十一月，遣奉车都尉窦固、驸马都尉耿秉、骑都尉刘张出敦煌崑仑塞，击破白山虏于蒲类海上，遂入车师。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **初置西域都护、戊己校尉。** [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **是岁，改天水为汉阳郡。** 当年，改天水为汉阳郡。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **班超在疏勒改立本族之后为王。** 班超赴疏勒，先使田虑擒龟兹所立的兜题，继立前王兄子忠。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **骑都尉刘张出击车师，请恭爲司马，与奉车都尉窦固及从弟驸马都尉秉破降之。** 永平十七年冬，骑都尉刘张出击车师，请恭爲司马，与奉车都尉窦固及从弟驸马都尉秉破降服。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **征入为太仆。** 永平十七年，征入为太仆。 [[15]](#hh-note-15)

### 13. 班超在疏勒改立本族之后为王

[返回正文第13条](#hh-event-13)

<a id="hh047-l3603-e13"></a>

**[《后汉书·班梁列传》](../../sources/摘录/后汉书-卷047-班梁列传.md#p001)** · [仓内TXT L3603](../../sources/本地分卷/后汉书/后汉书-卷047.md#L3603)

> 明年春，超從閒道至疏勒。去兜題所居槃橐城九十里，逆遣吏田慮先往降之。勑慮曰：「兜題本非疏勒種，國人必不用命。若不即降，便可執之。」慮旣到，兜題見慮輕弱，殊無降意。慮因其無備，遂前劫縛兜題。左右出其不意，皆驚懼奔走。慮馳報超，超即赴之，悉召疏勒將吏，說以龜茲無道之狀，因立其故王兄子忠爲王，國人大恱。忠及官屬皆請殺兜題，超不聽，欲示以威信，釋而遣之。疏勒由是與龜茲結怨。

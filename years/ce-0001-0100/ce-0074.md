1. **郡国献贡并报瑞物，公卿上寿。** 甘陵及多地报甘露，另有殿前芝草、五色鸟集京师、树枝内合等记载。哀牢、儋耳、僬侥、盘木、白狼、动黏等西南部众先后贡献，公卿百官会于朝堂向明帝奉觞上寿，明帝下诏回应。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **北海王睦薨。** 北海王睦去世。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

3. **王敏去世，鲍昱继任司徒。** 司徒王敏去世，汝南太守鲍昱接任司徒。 [[3]](#hh-note-3)

<a id="hh-event-9"></a>

<a id="hh-event-10"></a>

<a id="hh-event-11"></a>

<a id="hh-event-14"></a>

4. **窦固等破白山部及车师，设置西域都护。** 诏武威、张掖、酒泉、敦煌和张掖属国的囚徒中，罚在右趾以下而可从军者，免治其罪，赴军营。窦固、耿秉、刘张出敦煌昆仑塞，击破蒲类海上的白山部，与耿恭等攻降车师。朝廷置西域都护、戊己校尉。 [[4]](#hh-note-9)

<a id="hh-event-12"></a>

5. **是岁，改天水为汉阳郡。** 当年，改天水为汉阳郡。 [[5]](#hh-note-12)

<a id="hh-event-13"></a>

6. **班超擒兜题，立疏勒故王兄子忠。** 班超赴疏勒，先使田虑擒龟兹所立的兜题，继立前王兄子忠。 [[6]](#hh-note-13)

<a id="hh-event-15"></a>

7. **征入为太仆。** 永平十七年，征入为太仆。 [[7]](#hh-note-15)

### 6. 班超擒兜题，立疏勒故王兄子忠

[返回正文第6条](#hh-event-13)

<a id="hh047-l3603-e13"></a>

**[《后汉书·班梁列传》](../../拆分史书/后汉书/卷047.md#p001)** · [仓内TXT L3603](../../拆分史书/后汉书/卷047.md#part-1-L3603)

> 明年春，超從閒道至疏勒。去兜題所居槃橐城九十里，逆遣吏田慮先往降之。勑慮曰：「兜題本非疏勒種，國人必不用命。若不即降，便可執之。」慮旣到，兜題見慮輕弱，殊無降意。慮因其無備，遂前劫縛兜題。左右出其不意，皆驚懼奔走。慮馳報超，超即赴之，悉召疏勒將吏，說以龜茲無道之狀，因立其故王兄子忠爲王，國人大恱。忠及官屬皆請殺兜題，超不聽，欲示以威信，釋而遣之。疏勒由是與龜茲結怨。

**归年与互校** “明年”承永平十六年首次出使。

**[《后汉书》班超传李贤注引《续汉书》](../../拆分史书/后汉书/README.md#part-1-a-077-82-74)**

> 續漢書曰求得故王兄子榆勒立之更名曰忠也

**归年与互校** 《班超传》承永平十六年而书“明年春”，从本传及《通鉴》系永平十七年。《西域传》系上年冬，见[73年异说](ce-0073.md#hh-note-14)。

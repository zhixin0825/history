# 公元77年｜建初二年

[← 公元76年](ce-0076.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元78年 →](ce-0078.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **诏曰“比年阴阳不调”。** 二年春三月辛丑，诏曰：『比年阴阳不调，饥馑屡臻。深惟先帝忧人之本，诏书曰：「不伤财，不害人」，诚欲元元去末归本。而今贵戚近亲，奢纵无度，嫁娶送终，尤为僭侈。有司废典，莫肯举察。《春秋》之义，以贵理贱。今自三公，并宜明纠非法，宣振威风。朕在弱冠，未知稼穑之艰难，区区管窥，岂能照一隅哉！其科条制度所宜施行，在事者备为之禁，先京师而后诸夏。』 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **罢伊吾庐屯兵。** 甲辰，罢伊吾庐屯兵。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **永昌、越巂、益州三郡民、夷讨哀牢，破平之。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **诏还坐楚、淮阳事徙者四百余家，令归本郡。** 夏四月戊子，诏还坐楚、淮阳事徙者四百余家，令归本郡。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **诏齐相省冰纨、方空縠、吹纶絮。** 癸巳，诏齐相省冰纨、方空縠、吹纶絮。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **烧当羌叛，金城太守郝崇讨之，败绩，羌遂寇汉阳。** 六月，烧当羌叛，金城太守郝崇讨之，败绩，羌遂寇汉阳。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **遣行车骑将军马防讨平之。** 秋八月，遣行车骑将军马防讨平之。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **有星孛於紫宫。** 十二月戊寅，有星孛于紫宫。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **章帝封曹参后人曹湛为平阳侯。** 韦彪传追记曹湛早在建初二年即已获封，故建初七年西巡追录时没有重封。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **刘畅舅阴棠封西陵侯。** 章帝封刘畅母舅为西陵侯。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **卤承等击破类牢。** 邪龙县昆明部族首领鹵承等应募，与诸郡军在博南击破类牢。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **罢伊吾屯田。** 汉廷撤去伊吾屯田，匈奴遂占据该地。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **流星过紫宫中，长数丈，散爲三，灭。** 《天文志》记二年九月甲寅，流星过紫宫中，长数丈，散爲三，灭。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **彗星出娄三度，长八九尺，稍入紫宫中，百六日稍灭。** 《天文志》记十二月戊寅，彗星出娄三度，长八九尺，稍入紫宫中，百六日稍灭。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **章帝绍封嵩子勤为伊亭侯，勤无子，国除。** 建初二年，章帝绍封嵩子勤为伊亭侯，勤无子，国除。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **又封基弟毅为平望侯。** 建初二年，又封基弟毅为平望侯。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **复封栩十子为亭侯。** 建初二年，复封栩十子为亭侯。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **肃宗追思纯功，绍封阜子盱为高亭侯。** 建初二年，肃宗追思纯功，绍封阜子盱为高亭侯。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **女弟立为皇后，拜宪为郎，稍迁侍中、虎贲中郎将。** 建初二年，女弟立为皇后，拜宪为郎，稍迁侍中、虎贲中郎将；弟笃，为黄门侍郎。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **迁屯骑校尉。** 建初二年，迁屯骑校尉。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **肃宗封英子楚侯，五弟皆为列侯，并不得置相臣吏人。** 建初二年，肃宗封英子楚侯，五弟皆为列侯，并不得置相臣吏人。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **举孝廉，四迁，五年，为尚书。** 建初二年，举孝廉，四迁，五年，为尚书。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **肃宗行飨礼，以恭为三老。** 建初二年冬，肃宗行飨礼，以恭为三老。 [[23]](#hh-note-23)

<a id="sy-event-24"></a>

24. **耿恭任长水校尉，副马防讨西羌。** 耿恭任长水校尉，本年秋金城、陇西羌反，率五校士三千副马防，驻枹罕与羌军作战。 [[24]](#sy-note-24)

### 24. 耿恭任长水校尉，副马防讨西羌

[返回正文第24条](#sy-event-24)

<a id="sy-hh019-l1933-e24"></a>

**[《后汉书·耿弇列传》](../../sources/摘录/后汉书-卷019-耿弇列传.md#p003)** · [仓内TXT L1933](../../sources/本地分卷/后汉书/后汉书-卷019.md#L1933)

> 明年，遷長水校尉。其秋，金城、隴西羌反。恭上疏言方略，詔召入問狀。乃遣恭將五校士三千人，副車騎將軍馬防討西羌。恭屯枹罕，數與羌接戰。

**归年与互校** “明年”承建初元年。《通鉴》卷046 L207–214及《马援列传》L2204。同年任命马防已有条，若归并则可附。

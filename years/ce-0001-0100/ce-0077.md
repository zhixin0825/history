# 公元77年｜建初二年

[← 公元76年](ce-0076.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元78年 →](ce-0078.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **诏曰“比年阴阳不调”。** 二年春三月辛丑，诏曰：『比年阴阳不调，饥馑屡臻。深惟先帝忧人之本，诏书曰：「不伤财，不害人」，诚欲元元去末归本。而今贵戚近亲，奢纵无度，嫁娶送终，尤为僭侈。有司废典，莫肯举察。《春秋》之义，以贵理贱。今自三公，并宜明纠非法，宣振威风。朕在弱冠，未知稼穑之艰难，区区管窥，岂能照一隅哉！其科条制度所宜施行，在事者备为之禁，先京师而后诸夏。』 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-12"></a>

2. **罢伊吾卢屯兵、屯田。** 朝廷撤伊吾卢屯兵，罢其屯田。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-11"></a>

3. **诸郡会攻哀牢，卤承等击破类牢。** 永昌、越巂、益州三郡军民共同讨伐哀牢，邪龙县昆明卤承等应募，与诸军在博南击破类牢。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **诏还坐楚、淮阳事徙者四百余家，令归本郡。** 夏四月戊子，诏还坐楚、淮阳事徙者四百余家，令归本郡。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **诏齐相省冰纨、方空縠、吹纶絮。** 癸巳，诏齐相省冰纨、方空縠、吹纶絮。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

<a id="hh-event-7"></a>

<a id="sy-event-24"></a>

6. **烧当羌入寇汉阳，马防、耿恭进讨。** 六月，烧当羌反叛，击败金城太守郝崇的军队，进犯汉阳。八月，朝廷命马防行车骑将军事进讨，耿恭任长水校尉，率五校士三千人相助，驻枹罕与羌军交战。 [[6]](#hh-note-6)

<a id="hh-event-8"></a>

<a id="hh-event-14"></a>

7. **彗星出娄，经紫宫后渐灭。** 彗星从娄宿三度出现，长八九尺，渐入紫宫，一百零六日后渐灭。 [[7]](#hh-note-8)

<a id="hh-event-9"></a>

8. **章帝封曹参后人曹湛为平阳侯。** 韦彪传追记曹湛早在建初二年即已获封，故建初七年西巡追录时没有重封。 [[8]](#hh-note-9)

<a id="hh-event-10"></a>

9. **刘畅舅阴棠封西陵侯。** 章帝封刘畅母舅为西陵侯。 [[9]](#hh-note-10)

<a id="hh-event-13"></a>

10. **流星过紫宫中，长数丈，散爲三，灭。** 二年九月甲寅，流星过紫宫中，长数丈，散爲三，灭。 [[10]](#hh-note-13)

<a id="hh-event-15"></a>

11. **章帝绍封嵩子勤为伊亭侯，勤无子，国除。** 建初二年，章帝绍封嵩子勤为伊亭侯，勤无子，国除。 [[11]](#hh-note-15)

<a id="hh-event-16"></a>

12. **又封基弟毅为平望侯。** 建初二年，又封基弟毅为平望侯。 [[12]](#hh-note-16)

<a id="hh-event-17"></a>

13. **复封栩十子为亭侯。** 建初二年，复封栩十子为亭侯。 [[13]](#hh-note-17)

<a id="hh-event-18"></a>

14. **肃宗追思纯功，绍封阜子盱为高亭侯。** 建初二年，肃宗追思纯功，绍封阜子盱为高亭侯。 [[14]](#hh-note-18)

<a id="hh-event-19"></a>

15. **女弟立为皇后，拜宪为郎，稍迁侍中、虎贲中郎将。** 建初二年，女弟立为皇后，拜宪为郎，稍迁侍中、虎贲中郎将；弟笃，为黄门侍郎。 [[15]](#hh-note-19)

<a id="hh-event-20"></a>

16. **迁屯骑校尉。** 建初二年，迁屯骑校尉。 [[16]](#hh-note-20)

<a id="hh-event-21"></a>

17. **肃宗封英子楚侯，五弟皆为列侯，并不得置相臣吏人。** 建初二年，肃宗封英子楚侯，五弟皆为列侯，并不得置相臣吏人。 [[17]](#hh-note-21)

<a id="hh-event-22"></a>

18. **举孝廉，四迁，五年，为尚书。** 建初二年，举孝廉，四迁，五年，为尚书。 [[18]](#hh-note-22)

<a id="hh-event-23"></a>

19. **肃宗行飨礼，以恭为三老。** 建初二年冬，肃宗行飨礼，以恭为三老。 [[19]](#hh-note-23)

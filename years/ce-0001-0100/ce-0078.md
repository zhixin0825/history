<a id="hh-event-1"></a>

1. **宗祀明堂。** 三年春正月己酉，宗祀明堂。礼毕，登灵台，望云物。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **大赦天下。** 颁布大赦。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **立贵人窦氏为皇后。** 三月癸巳，立贵人窦氏为皇后。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **赐爵，人二级、三老、孝悌、力田人三级，民无名数及流民欲占者人一级。** 赐爵，人二级、三老、孝悌、力田人三级，民无名数及流民欲占者人一级；鳏、寡、孤、独、笃癃、贫不能自存者粟，人五斛。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **罢常山呼沲石臼河漕。** 夏四月己巳，罢常山呼沲石臼河漕。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **行车骑将军马防破烧当羌於临洮。** 行车骑将军马防破烧当羌于临洮。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **闰月，西域假司马班超击姑墨，大破之。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **以马防为车骑将军。** 冬十二月丁酉，以马防为车骑将军。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **武陵漊中蛮叛。** [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **是岁，零陵献芝草。** 当年，零陵献芝草。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **章帝暂留刘羡、刘恭及刘党京师。** 有司请令诸王就国，章帝眷爱诸王，暂留京城。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **刘恭改封江陵王。** 章帝改南郡为江陵王国，徙刘恭居此。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **宋贵人生刘庆。** 在章帝后宫，年长的宋贵人于本年生刘庆，次年立太子。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **杜笃战死射姑山。** 杜笃随马防攻羌，任从事中郎，在射姑山战死。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **复封骏为观都侯，卒，无子，国除。** 建初三年，复封骏为观都侯，卒，无子，国除。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **拜训谒者，使监领其事。** 建初三年，拜训谒者，使监领其事。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **追录前功，增邑一千三百户。** 建初三年，追录前功，增邑一千三百户。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **肃宗使五官中郎将持节追策，谥援曰忠成侯。** 建初三年，肃宗使五官中郎将持节追策，谥援曰忠成侯。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **司徒鲍昱辟之，後举直言，并不诣。** 建初三年，司徒鲍昱辟之，后举直言，并不到。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **以老病乞身，肃宗许之。** 建初三年，以老病乞身，肃宗许之。 [[20]](#hh-note-20)

<a id="hh047-l3605-e7"></a>

**[《后汉书·班梁列传》](../../sources/摘录/后汉书-卷047-班梁列传.md#p002)** · [仓内TXT L3605](../../sources/本地分卷/后汉书/后汉书-卷047.md#L3605)

> 建初三年，超率疏勒、康居、於窴、拘彌兵一萬人攻姑墨石城，破之，斬首七百級。超欲因此叵平諸國，乃上疏請兵。曰：「臣竊見先帝欲開西域，故北擊匈奴，西使外國，鄯善、於窴即時向化。今拘彌、莎車、疏勒、月氏、烏孫、康居復願歸附，欲共並力破滅龜茲，平通漢道。若得龜茲，則西域未服者百分之一耳。臣伏自惟念，卒伍小吏，實願從谷吉效命絕域，庶幾張騫棄身曠野。昔魏絳列國大夫，尚能和輯諸戎，況臣奉大漢之威，而無鈆刀一割之用乎？前世議者皆曰取三十六國，號爲斷匈奴右臂。

**归年与互校** 年次据本传。

### 13. 宋贵人生刘庆

[返回正文第13条](#hh-event-13)

<a id="hh055-l4072-e13"></a>

**[《后汉书·章帝八王列传》](../../sources/摘录/后汉书-卷055-章帝八王列传.md#p002)** · [仓内TXT L4072](../../sources/本地分卷/后汉书/后汉书-卷055.md#L4072)

> 建初三年，大貴人生慶，明年立為皇太子，征楊為議郎，□賜甚渥。貴人長於人事，供奉長樂宮，身埶饋饌，太后憐之。太后崩後，竇皇后寵盛，以貴人姊妹並幸，慶為太子，心內惡之。與母比陽主謀陷宋氏。外令兄弟求其纖過，內使御者偵伺得失。後於掖庭門邀遮得貴人書，雲「病思生菟，令家求之」，因誣言欲作蠱道祝詛，以菟為厭勝之術，日夜毀譖，貴人母子遂漸見疏。

**归年与互校** 年次据本传。

2. **立刘庆为太子，改封与增益诸王国。** 四月戊子，立皇子刘庆为太子。朝廷赐爵，男子二级，三老、孝悌、力田三级，无户籍和愿登记的流人一级。己丑，钜鹿王刘恭徙江陵，汝南王刘畅徙梁，常山王刘昞徙淮阳，淮阳增汝南的新安、西华。皇子刘伉封千乘王，刘全封平春王，当年无子而亡，国除。又从清河、勃海、涿郡分八县增乐成国，以东郡离狐、陈留长垣增济阴国。 [[2]](#hh-note-2)

3. **马太后去世，葬明德皇后。** 皇太后马氏去世，以明德皇后之礼下葬。 [[3]](#hh-note-8)

<a id="hh-event-10"></a>

<a id="hh-event-22"></a>

4. **京师冬季牛疫。** 冬季，京师牛疫流行。 [[4]](#hh-note-10)

<a id="hh-event-11"></a>

5. **章帝在白虎观召议五经。** 十一月壬戌，章帝下诏命公卿、博士、议郎与儒生等会于白虎观，商议五经义理的同异。五官中郎将魏应奉诏提问，侍中淳于恭呈奏，章帝亲自裁决，编为《白虎议奏》。 [[5]](#hh-note-11)

<a id="hh-event-12"></a>

6. **是岁，甘露降泉陵、洮阳二县。** 当年，甘露降泉陵、洮阳二县。 [[6]](#hh-note-12)

<a id="hh-event-13"></a>

<a id="sy-event-23"></a>

7. **马廖、马防、马光受封。** 马廖多次辞让，受封顺阳侯，以特进身份还第。章帝封马防为颍阳侯、马光为许侯，两人各六千户，马防又以平羌等功增食邑。 [[7]](#hh-note-13)

<a id="hh-event-19"></a>

8. **薨，车驾亲临其丧。** 建初四年，薨，车驾亲临其丧。 [[8]](#hh-note-19)

<a id="hh-event-20"></a>

9. **徙封鲁阳乡侯。** 建初四年，徙封鲁阳乡侯。 [[9]](#hh-note-20)

<a id="hh-event-21"></a>

10. **拜五官中郎将，诏入授千乘王伉。** 建初四年，拜五官中郎将，诏入授千乘王伉。 [[10]](#hh-note-21)

<a id="sy-event-24"></a>

11. **置轮氏县。** 颍川郡设置轮氏县。 [[11]](#sy-note-24)

<a id="sy-event-25"></a>

12. **徙宋公于宋国。** 章帝将宋公徙封至《郡国志》所列宋公国。志记此地周时名丘，入汉改称新。 [[12]](#sy-note-25)

### 5. 章帝在白虎观召议五经

[返回正文第5条](#hh-event-11)

<a id="hh003-l500-e11"></a>

**[《后汉书·章帝纪》](../../拆分史书/后汉书/卷003.md#p001)** · [仓内TXT L500](../../拆分史书/后汉书/卷003.md#part-1-L500)

> 十一月壬戌，詔曰：『蓋三代導人，教學為本。漢承暴秦，褒顯儒術，建立《五經》，為置博士。其後學者精進，雖曰承師，亦別名家。孝宣皇帝以為去聖久遠，學不厭博，故遂立大、小夏侯《尚書》，後又立《京氏易》。至建武中，復置顏氏、嚴氏《春秋》，《大、小戴禮》博士。此皆所以扶進微學，尊廣道藝也。中元元年詔書，《五經》章句煩多，議欲減省。至永平元年，長水校尉儵奏言，先帝大業，當以時施行。欲使諸儒共正經義，頗令學者得以自助。孔子曰：「學之不講，是吾憂也。」又曰：「博學而篤志，切問而近思，仁在其中矣。」於戲，其勉之哉！』於是下太常，將、大夫、博士、議郎、郎官及諸生、諸儒會白虎觀，講議《五經》同異，使五官中郎將魏應承制問，侍中淳於恭奏，帝親稱制臨決，如孝宣甘露石渠故事，作《白虎議奏》。

**[《后汉书·儒林列传》](../../拆分史书/后汉书/卷079.md#p001)** · [仓内TXT L5631](../../拆分史书/后汉书/卷079.md#part-1-L5631)

> 大會諸儒於白虎觀，考詳同異，連月乃罷。

# 公元80年｜建初五年

<a id="hh-event-16"></a>

1. **二月日食，章帝下诏。** 二月庚辰朔，日食于东壁八度。章帝念及去岁皇太后丧事，下诏自责。 [[1]](#hh-note-1)

<a id="hh-event-3"></a>

2. **诏曰“《春秋》书「无麦苗」”。** 甲申，诏曰：『《春秋》书「无麦苗」，重之也。去秋雨泽不适，今时复旱，如炎如焚。凶年无时，而为备未至。朕之不德，上累三光，震栗忉忉，痛心疾首。前代圣君，博思咨诹，虽降灾咎，辄有开匮反风之应。令予小子，徒惨惨而已。其令二千石理冤狱，录轻系；祷五岳四渎，及名山能兴云致雨者，冀蒙不崇朝遍雨天下之报。务加肃敬焉。』 [[2]](#hh-note-3)

<a id="hh-event-4"></a>

3. **诏曰“孔子曰：「刑罚不中”。** 三月甲寅，诏曰：『孔子曰：「刑罚不中，则人无所措手足。」今吏多不良，擅行喜怒，或案不以罪，迫胁无辜，致令自杀者，一岁且多于断狱，甚非为人父母之意也。有司其议纠举之。』 [[3]](#hh-note-4)

<a id="hh-event-5"></a>

4. **荆、豫诸郡兵讨破武陵漊中叛蛮。** [[4]](#hh-note-5)

<a id="hh-event-6"></a>

5. **诏曰“朕思直士”。** 夏五月辛亥，诏曰：『朕思直士，侧席异闻。其先至者，各以发愤吐懑，略闻子大夫之志矣，皆欲置于左右，顾问省纳。建武诏书又曰，尧试臣以职，不直以言语笔札。今外官多旷，并可以补任。』 [[5]](#hh-note-6)

<a id="hh-event-7"></a>

<a id="hh-event-13"></a>

6. **章帝临视病中的赵憙，赵憙去世。** 太傅赵憙病重，章帝亲往看视。赵憙本年去世。 [[6]](#hh-note-7)

<a id="hh-event-8"></a>

7. **始行月令迎气乐。** 冬，始行月令迎气乐。 [[7]](#hh-note-8)

<a id="hh-event-9"></a>

8. **是岁，零陵献芝草。** 当年，零陵献芝草。 [[8]](#hh-note-9)

<a id="hh-event-10"></a>

9. **有八黄龙见於泉陵。** 有八黄龙见于泉陵。 [[9]](#hh-note-10)

<a id="hh-event-11"></a>

10. **西域假司马班超击疏勒，破之。** [[10]](#hh-note-11)

<a id="hh-event-12"></a>

11. **迁太仆，八年，代窦固为光禄勋，所历皆有称。** 建初五年，迁太仆，八年，代窦固为光禄勋，所历皆有称。 [[11]](#hh-note-12)

<a id="hh-event-14"></a>

12. **兴夫人卒，肃宗使五官中郎将持节即墓赐策，追谥兴曰翼侯。** 建初五年，兴夫人卒，肃宗使五官中郎将持节即墓赐策，追谥兴曰翼侯。 [[12]](#hh-note-14)

<a id="hh-event-15"></a>

13. **坐事左转太中大夫，後为左中郎将。** 建初五年，因事获罪左转太中大夫，后为左中郎将。 [[13]](#hh-note-15)

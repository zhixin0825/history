# 公元80年｜建初五年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **日有食之。** 五年春二月庚辰朔，发生日食。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏曰“朕新离供养”。** 诏曰：「朕新离供养，愆咎众着，上天降异，大变随之。《诗》不云乎：「亦孔之丑。」又久旱伤麦，忧心惨切。公卿已下，其举直言极谏、能指朕过失者各一人，遣到公车，将亲览问焉。其以岩穴为先，勿取浮华。』 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **诏曰“《春秋》书「无麦苗」”。** 甲申，诏曰：『《春秋》书「无麦苗」，重之也。去秋雨泽不适，今时复旱，如炎如焚。凶年无时，而为备未至。朕之不德，上累三光，震栗忉忉，痛心疾首。前代圣君，博思咨诹，虽降灾咎，辄有开匮反风之应。令予小子，徒惨惨而已。其令二千石理冤狱，录轻系；祷五岳四渎，及名山能兴云致雨者，冀蒙不崇朝遍雨天下之报。务加肃敬焉。』 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **诏曰“孔子曰：「刑罚不中”。** 三月甲寅，诏曰：『孔子曰：「刑罚不中，则人无所措手足。」今吏多不良，擅行喜怒，或案不以罪，迫胁无辜，致令自杀者，一岁且多于断狱，甚非为人父母之意也。有司其议纠举之。』 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **荆、豫诸郡兵讨破武陵漊中叛蛮。** [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **诏曰“朕思直士”。** 夏五月辛亥，诏曰：『朕思直士，侧席异闻。其先至者，各以发愤吐懑，略闻子大夫之志矣，皆欲置于左右，顾问省纳。建武诏书又曰，尧试臣以职，不直以言语笔札。今外官多旷，并可以补任。』 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **太傅赵憙薨。** 戊辰，太傅赵憙去世。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **始行月令迎气乐。** 冬，始行月令迎气乐。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **是岁，零陵献芝草。** 当年，零陵献芝草。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **有八黄龙见於泉陵。** 有八黄龙见于泉陵。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **西域假司马班超击疏勒，破之。** [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **迁太仆，八年，代窦固为光禄勋，所历皆有称。** 建初五年，迁太仆，八年，代窦固为光禄勋，所历皆有称。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **憙疾病，帝亲幸视。** 建初五年，憙疾病，帝亲幸视。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **兴夫人卒，肃宗使五官中郎将持节即墓赐策，追谥兴曰翼侯。** 建初五年，兴夫人卒，肃宗使五官中郎将持节即墓赐策，追谥兴曰翼侯。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **坐事左转太中大夫，後为左中郎将。** 建初五年，因事获罪左转太中大夫，后为左中郎将。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **章帝建初五年二月庚辰朔，日有蚀之，在东壁八度。** 章帝建初五年二月庚辰朔，发生日食，在东壁八度。 [[16]](#hh-note-16)

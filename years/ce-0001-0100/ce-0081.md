1. **琅邪王京薨。** 六年春二月辛卯，琅邪王京去世。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **赵王盱薨。** 夏五月辛酉，赵王盱去世。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **太尉鲍昱薨。** 六月丙辰，太尉鲍昱去世。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **日有食之。** 辛未晦，发生日食。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **以大司农邓彪为太尉。** 秋七月癸巳，以大司农邓彪为太尉。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **代邓彪为大司农。** 建初六年，代邓彪为大司农。 [[6]](#hh-note-6)

<a id="hh-event-1"></a>

1. **沛王辅、济南王康、东平王苍、中山王焉、东海王政、琅邪王宇来朝。** 七年春正月，沛王辅、济南王康、东平王苍、中山王焉、东海王政、琅邪王宇入朝觐见。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **废皇太子庆为清河王，立皇子肇为皇太子。** 夏六月甲寅，废皇太子庆为清河王，立皇子肇为皇太子。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **徙广平王羡为西平王。** 己未，徙广平王羡为西平王。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **饮酎高庙，禘祭光武皇帝、孝明皇帝。** 秋八月，饮酎高庙，禘祭光武皇帝、孝明皇帝。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **诏曰“《书》云：「祖考来假」”。** 甲辰，诏曰：『《书》云：「祖考来假」，明哲之祀。予末小子，质又菲薄，仰惟先帝烝烝之情，前修禘祭，以尽孝敬。朕得识昭穆之序，寄远祖之思。今年大礼复举，加以先帝之坐，悲伤感怀。乐以迎来，哀以送往，虽祭亡如在，而空虚不知所裁，庶或飨之。岂亡克慎肃雍之臣，辟公之相，皆助朕之依依。今赐公钱四十万，卿半之，及百官执事各有差。』 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **幸偃师，东涉卷津，至河内。** 九月甲戌，幸偃师，东涉卷津，至河内。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **下诏曰。** 下诏曰：『车驾行秋稼，观收获，因涉郡界。皆精骑轻行，无它辎重。不得辄修道桥，远离城郭，遣吏逢迎，刺探起居，出入前后，以为烦扰。动务省约，但患不能脱粟瓢饮耳。所过欲令贫弱有利，无违诏书。』 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **遂览淇园。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **进幸邺，劳飨魏郡守令已下，至於三老、门阑、走卒，赐钱各有差。** 己酉，进幸邺，劳飨魏郡守令已下，至于三老、门阑、走卒，赐钱各有差。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **劳赐常山、赵国吏人，复元氏租赋三岁。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **车驾还宫。** 辛卯，皇帝回宫。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **诏天下系囚减死一等，勿笞，诣边戍。** 诏天下系囚减死一等，勿笞，到边戍；妻子自随，占着所在；父母同产欲相从者，恣听之；有不到者，皆以乏军兴论。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **及犯殊死，一切募下蚕室。** 及犯殊死，一切募下蚕室；其女子宫。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **系系鬼薪、白粲已上，皆减本罪各一等，输司寇作。** [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **亡命赎。** 亡命赎：死罪入缣二十匹，右趾至髡钳城旦舂十匹，完城旦至司寇三匹，吏人有罪未发觉，诏书到自告者，半入赎。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **西巡狩，幸长安。** 冬十月癸丑，西巡狩，前往长安。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **祠高庙，遂有事十一陵。** 丙辰，祠高庙，遂有事十一陵。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **遣使者祠太上皇於万年，以中牢祠萧何、霍光。** 派使者祠太上皇于万年，以中牢祠萧何、霍光。进幸槐里。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **岐山得铜器，形似酒罇，献之。** [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **又获白鹿。** [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **帝曰“上无明天子”。** 帝曰：『上无明天子，下无贤方伯。「人之无良，想怨一方。」斯器亦曷为来哉？』 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **又幸长平，御池阳宫，东至高陵，造舟於泾而还。** 又幸长平，御池阳宫，东至高陵，造舟于泾而还。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **每所到幸，辄会郡县吏人，劳赐作乐。** [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **诏劳赐河东守、令、掾以下。** 十一月，诏劳赐河东守、令、掾以下。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **车驾还宫。** 十二月丁亥，皇帝回宫。 [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **是岁，京师及郡国螟。** 当年，京师及郡国螟。 [[26]](#hh-note-26)

<a id="hh-event-27"></a>

27. **废刘庆，立刘肇为太子。** 刘肇由窦后抚养，接替刘庆为太子。 [[27]](#hh-note-27)

<a id="hh-event-28"></a>

28. **章帝西巡追封萧何后人。** 韦彪随驾西巡，请访高祖功臣萧何和西汉辅政大臣霍光后裔，最后找到萧何末孙萧熊并封酇侯。 [[28]](#hh-note-28)

<a id="hh-event-29"></a>

29. **王景任徐州刺史。** 王景迁任徐州刺史。 [[29]](#hh-note-29)

<a id="hh-event-30"></a>

30. **郡国螟伤稼，犬牙缘界，不入中牟。** 建初七年，郡国螟伤稼，犬牙缘界，不入中牟。 [[30]](#hh-note-30)

<a id="hh-event-31"></a>

31. **车驾西巡府，以彪行太常从，数召入，问以三辅旧事，礼仪风俗。** 建初七年，车驾西巡府，以彪行太常从，数召入，问以三辅旧事，礼仪风俗。 [[31]](#hh-note-31)

<a id="hh-event-32"></a>

32. **肃宗诏元寿兄弟与诸王俱朝京师。** 建初七年，肃宗诏元寿兄弟与诸王俱朝京师。 [[32]](#hh-note-32)

<a id="hh-event-33"></a>

33. **封宇弟十三人为列侯。** 建初七年，封宇弟十三人为列侯。 [[33]](#hh-note-33)

# 公元83年｜建初八年

[← 公元82年](ce-0082.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元84年 →](ce-0084.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **东平王苍薨。** 八年春正月壬辰，东平王苍去世。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **葬东平宪王，赐銮辂、龙旗。** 三月辛卯，葬东平宪王，赐銮辂、龙旗。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **北匈奴大人率众款塞降。** 夏六月，北匈奴大人率众款塞降。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **东巡狩，幸陈留、梁国、淮阳、颍阳。** 冬十二月甲午，东巡狩，幸陈留、梁国、淮阳、颍阳。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **车驾还宫。** 戊申，皇帝回宫。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **诏曰“《五经》剖判”。** 诏曰：『《五经》剖判，去圣弥远，章句遗辞，乖疑难正，恐先师微言将遂废绝，非所以重稽古，求道真也。其令群儒选高才生，受学《左氏》、《谷梁春秋》、《古文尚书》、《毛诗》，以扶微学，广异义焉。』 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **是岁，京师及郡国螟。** 当年，京师及郡国螟。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **梁贵人受谮，梁竦死狱中。** 窦后派人毁谤梁贵人姊妹，梁竦受牵连死于狱，其家属徙九真。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **班超受拜将兵长史。** 班超拜将兵长史，徐干任军司马，李邑护送乌孙使者。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **王景在庐江推广犁耕。** 王景转任庐江太守，修复芍陂的旧稻田，教人用牛牵犁耕种。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **徙封盱为平春侯，以奉汉後。** 建初八年，徙封盱为平春侯，以奉汉后。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **以顺中子奋袭主爵为平阳侯，薨，无子。** 建初八年，以顺中子奋袭主爵为平阳侯，薨，无子。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **代郑众为大司农。** 建初八年，代郑众为大司农。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **肃宗复还所削地，康遂多殖财货，大修宫室，奴婢至千四百人，厩马千二百匹，私田八百顷，奢侈恣欲…。** 建初八年，肃宗复还所削地，康遂多殖财货，大修宫室，奴婢至千四百人，厩马千二百匹，私田八百顷，奢侈恣欲，游观无节。 [[14]](#hh-note-14)

<a id="hh-event-1"></a>

1. **中山王焉来朝。** 元和元年春正月，中山王焉入朝觐见。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-27"></a>

2. **日南境外邑豪献生犀、白雉。** 日南边外究不事人邑豪进献活犀牛和白雉。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **闰月辛丑，济阴王长薨。** 闰月辛丑，济阴王长去世。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **诏曰“王者八政”。** 二月甲戌，诏曰：『王者八政，以食为本，故古者急耕稼之业，致耒耜之勤，节用储蓄，以备凶灾，是以岁虽不登而人无饥色。自牛疫已来，谷食连少，良由吏教未至，刺史、二千石不以为负。其命各郡国募人无田欲徙它界就肥饶者，恣听之。到在所，赐给公田，为雇耕佣，赁种飠尚，贳与田器，勿收租五岁，除筭三年。其后欲还本乡者，勿禁。』 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **分东平国，封宪王苍子尚为任城王。** 夏四月己卯，分东平国，封宪王苍子尚为任城王。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **沛王辅薨。** 六月辛酉，沛王辅去世。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **诏曰“《律》云「掠者唯得榜、笞、立」”。** 秋七月丁未，诏曰：『《律》云「掠者唯得榜、笞、立」。又《令丙》，箠长短有数。自往者大狱已来，掠考多酷，钻钻之属，惨苦无极。念其痛毒，怵然动心。《书》曰「鞭作官刑」，岂云若此？宜及秋冬理狱，明为其禁。』 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

<a id="hh-event-24"></a>

8. **邓彪罢太尉，郑弘接任。** 太尉邓彪罢免，大司农郑弘继任。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **诏曰“朕道化不德”。** 癸酉，诏曰：『朕道化不德，吏政失和，元元未谕，抵罪于下。寇贼争心不息，边野邑屋不修。永惟庶事，思稽厥衷，与凡百君子，共弘斯道。中心悠悠，将何以寄？其改建初九年为元和元年。郡国中都官系囚减死一等，勿笞，到边县；妻子自随，占着在所。其犯殊死，一切募下蚕室；其女子宫。系囚鬼薪、白粲以上，皆减本罪一等，输司寇作。亡命者赎，各有差。』 [[9]](#hh-note-9)

10. **章帝南巡祭章陵、江陵，禁郡县铺张迎送。** 章帝南巡，诏所经郡县不得额外备置供奉或遣使探问迎送，违者追究二千石。司空率刑徒支护桥梁，沿途鳏寡孤独等不能自存者各给谷五斛。章帝到章陵，祀旧宅园庙，按等赏赐宗室旧人，再到江陵。命庐江太守祭南岳，命长沙、零陵太守祭长沙定王、舂陵节侯、郁林府君。回经宛县，还宫后按等赐随从。 [[10]](#hh-note-10)

<a id="hh-event-14"></a>

11. **东平王忠薨。** 九月乙未，东平王忠去世。 [[11]](#hh-note-14)

<a id="hh-event-19"></a>

12. **诏曰“《书》云：「父不慈”。** 十二月壬子，诏曰：『《书》云：「父不慈，子不祗，兄不友，弟不恭，不相及也。」往者妖言大狱，所及广远，一人犯罪，禁至三属，莫得垂缨仕宦王朝。如有贤才而没齿无用，朕甚怜之，非所谓与之更始也。诸以前妖恶禁锢者，一皆蠲除之，以明弃咎之路，但不得在宿卫而已。』 [[12]](#hh-note-19)

<a id="hh-event-20"></a>

13. **班超进击莎车，疏勒王忠叛。** 汉廷增兵西域，此后莎车以厚利引疏勒王忠反叛。 [[13]](#hh-note-20)

<a id="hh-event-21"></a>

14. **北匈奴与汉边市互市。** 北单于请开互市，孟云奉诏接洽，匈奴遣王率牛马与汉商交易。 [[14]](#hh-note-21)

<a id="hh-event-22"></a>

15. **徵，再迁，拜赵相。** 元和元年，徵，再迁，拜赵相。 [[15]](#hh-note-22)

<a id="hh-event-23"></a>

16. **诏告庐江太守、东平相曰。** 元和元年，诏告庐江太守、东平相曰：『议郎郑均，束修安贫，恭俭节整，前在机密，以病致仕，守善贞固，黄发不怠。又前安邑令毛义，躬履逊让，比徵辞病，淳洁之风，东州称仁。书不云乎：「章厥有常，吉哉！」其赐均、义谷各千斛，常以八月长吏存问，赐羊酒，显兹异行。』 [[16]](#hh-note-23)

<a id="hh-event-25"></a>

17. **封孝王孙二人为列侯。** 元和元年，封孝王孙二人为列侯。 [[17]](#hh-note-25)

<a id="hh-event-26"></a>

18. **赐策罢，赠钱三十万，在所以二千石奉终其身。** 元和元年，赐策罢，赠钱三十万，在所以二千石奉终其身。 [[18]](#hh-note-26)

<a id="hh-event-28"></a>

19. **待诏候钟律殷肜上言。** 元和元年，待诏候钟律殷肜上言：「官无晓六十律以准调音者。故待诏严崇具以准法教子男宣，宣通习。愿召宣补学官，主调乐器。」 [[19]](#hh-note-28)

<a id="sy-event-29"></a>

20. **章帝命黄香到东观读书。** 章帝让郎中黄香到东观阅读平时未见书籍。 [[20]](#sy-note-29)

<a id="sy-event-30"></a>

21. **三县归属梁国。** 三县划归梁国。梁国所在原是秦砀郡，汉高帝时改建封国。 [[21]](#sy-note-30)

> 明年，復遣假司馬和恭等四人將兵八百詣超，超因發疏勒、於窴兵擊莎車。莎車陰通使疏勒王忠，啖以重利忠遂反從之，西保烏即城。超乃更立其府丞成大爲疏勒王，悉發其不反者以攻忠。積半歲，而康居遣精兵救之，超不能下。是時月氏新與康居婚，相親，超乃使使多齎錦帛遺月氏王，令曉示康居王，康居王乃罷兵，執忠以歸其國，烏即城遂降於超。

**归年与互校** “明年”承建初八年。

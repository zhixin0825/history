2. **章帝北巡中山、元氏与赵，命高邑祭即位坛。** 章帝北巡，济南、中山、西平、六安、乐成、淮阳、任城、沛诸王从行。章帝亲耕于怀，告各地太守、国相并敕侍御史、司空。过真定，郭氏来朝献寿，与帝宴饮。到中山，遣使祠北岳，又出长城，回到元氏，在县舍正堂祠光武、明帝，命高邑令祠光武即位坛，免元氏七年徭役。继至赵，在灵寿祠房山，还宫后按等赐从者。 [[2]](#hh-note-2)

3. **郑弘、第五伦罢，宋田、袁安接任。** 太尉郑弘罢免，大司农宋田继任。司空第五伦罢免，朝廷以二千石俸禄优养，赐钱五十万、公宅一所，太仆袁安继任司空。 [[3]](#hh-note-15)

4. **章帝至安邑观盐池。** 章帝到安邑观盐池，随后还宫。 [[4]](#hh-note-17)

<a id="hh-event-19"></a>

5. **北海王基薨。** 冬十月，北海王基去世。 [[5]](#hh-note-19)

6. **烧当羌寇陇西，张纡释放号吾。** 烧当羌迷吾、号吾再叛，进犯陇西，张纡随后释放号吾。 [[6]](#hh-note-20)

<a id="hh-event-21"></a>

7. **是岁，西域长史班超击斩疏勒王。** 当年，西域长史班超击斩疏勒王。 [[7]](#hh-note-21)

8. **郭躬任廷尉。** 郭躬三迁，至元和三年拜廷尉，继而厘定可从轻的刑文。 [[8]](#hh-note-22)

11. **许太后薨，复遣光禄大夫持节吊祠，因留护丧事，赙钱五百万。** 元和三年，许太后薨，复遣光禄大夫持节吊祠，因留护丧事，赙钱五百万。 [[11]](#hh-note-27)

<a id="hh-event-28"></a>

12. **行东巡守，幸东平宫，帝追感念苍，谓其诸子曰。** 元和三年，行东巡守，幸东平宫，帝追感念苍，谓其诸子曰：「思其人，至其乡；其处在，其人亡。」 [[12]](#hh-note-28)

<a id="sy-event-29"></a>

13. **曹褒请修汉礼，巢堪反对。** 曹褒上疏请求确定汉代礼制，太常巢堪认为一代典章不可由曹褒独定。 [[13]](#sy-note-29)

<a id="sy-event-31"></a>

14. **于阗广德击杀不居征，改立莎车王。** 匈奴护送不居征任莎车王，于阗王广德再杀之，立其弟齐黎。 [[14]](#sy-note-31)

### 13. 曹褒请修汉礼，巢堪反对

**[《后汉书·张曹郑列传》](../../拆分史书/后汉书/卷035.md#p002)** · [仓内TXT L2833](../../拆分史书/后汉书/卷035.md#part-1-L2833)

> 褒知帝旨欲有興作，乃上疏曰：『昔者聖人受命而王，莫不制禮作樂，以著功德。功成作樂，化定製禮，所以救世俗，致禎祥，為萬姓獲福於皇天者也。今皇天降祉，嘉瑞並臻，製作之符，甚於言語。宜定文制，著成漢禮，丕顯祖宗盛德之美。』章下太常，太常巢堪以為一世大典，非褒所定，不可許。

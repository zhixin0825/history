[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **诏曰“盖君人者”。** 三年春正月乙酉，诏曰：『盖君人者，视民如父母，有憯怛之忧，有忠和之教，匍匐之救。其婴儿无父母亲属，及有子不能养食者，禀给如《律》。』 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **北巡狩，济南王康、中山王焉、西平王羡、六安王恭、乐成王党、淮阳王昞、任城王尚、沛王定皆从。** 丙申，北巡狩，济南王康、中山王焉、西平王羡、六安王恭、乐成王党、淮阳王昞、任城王尚、沛王定皆从。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **帝耕於怀。** 辛丑，帝耕于怀。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **告常山、魏郡、清河、钜鹿、平原、东平郡太守、相曰。** 二月壬寅，告常山、魏郡、清河、钜鹿、平原、东平郡太守、相曰：『朕惟巡狩之制，以宣声教，考同遐迩，解释怨结也。今「四国无政，不用其良」，驾言出游，欲亲知其剧易。前祠园陵，遂望祀华、霍，东祡贷宗，为人祈福。今将礼常山，遂徂北土，历魏郡，经平原，升践堤防，询访耆老，咸曰「往者汴门未作，深者成渊，浅则泥涂」。追惟先帝勤人之德，厎绩远图，复禹弘业，圣迹滂流，至于海表。不克堂构，朕甚慙焉。《月令》，孟春善相丘陵土地所宜。今肥田尚多，未有垦辟。其悉以赋贫民，给与粮种，务尽地力，勿令游手。所过县邑，听半入今年田租，以劝农夫之劳。』 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **勑侍御史、司空曰。** 乙丑，勑侍御史、司空曰：『方春，所过无得有所伐杀。车可以引避，引避之；騑马可辍解，辍解之。《诗》云：「敦彼行苇，牛羊勿践履。」《礼》，人君伐一草木不时，谓之不孝。俗知顺人，莫知顺天。其明称朕意。』 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **进幸中山，遣使者祠北岳。** 戊辰，进幸中山，派使者祠北岳。 [[6]](#hh-note-6)

<a id="hh-event-23"></a>

23. **肃宗北巡狩，过真定，会诸郭，朝见上寿，引入倡饮甚欢。** 元和三年，肃宗北巡狩，过真定，会诸郭，朝见上寿，引入倡饮甚欢。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **卢水胡反畔，以训为竭者，乘传到武威，拜张掖太守。** 元和三年，卢水胡反畔，以训为竭者，乘传到武威，拜张掖太守。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **徙封马亭乡侯。** 元和三年，徙封马亭乡侯。 [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **赐策罢，以二千石奉终其身，加赐钱五十万，公宅一区。** 元和三年，赐策罢，以二千石奉终其身，加赐钱五十万，公宅一区。 [[26]](#hh-note-26)

<a id="hh-event-27"></a>

27. **许太后薨，复遣光禄大夫持节吊祠，因留护丧事，赙钱五百万。** 元和三年，许太后薨，复遣光禄大夫持节吊祠，因留护丧事，赙钱五百万。 [[27]](#hh-note-27)

<a id="hh-event-28"></a>

28. **行东巡守，幸东平宫，帝追感念苍，谓其诸子曰。** 元和三年，行东巡守，幸东平宫，帝追感念苍，谓其诸子曰：「思其人，至其乡；其处在，其人亡。」 [[28]](#hh-note-28)

<a id="sy-event-29"></a>

29. **曹褒请修汉礼，巢堪反对。** 曹褒上疏请求确定汉代礼制，太常巢堪认为一代典章不可由曹褒独定。 [[29]](#sy-note-29)

<a id="sy-event-30"></a>

30. **迷吾、号吾复叛，张纡释放号吾。** 秋季号吾轻兵袭扰陇西，被李章捕获。张纡听其愿解兵之说放归，羌部暂散，迷吾退居河北归义城。 [[30]](#sy-note-30)

<a id="sy-event-31"></a>

31. **于阗广德击杀不居征，改立莎车王。** 匈奴护送不居征任莎车王，于阗王广德再杀之，立其弟齐黎。 [[31]](#sy-note-31)

<a id="sgz-event-32"></a>

32. **汉章帝诏高邑祭即位坛。** 裴松之据《汉纪》记东汉章帝元和三年诏高邑县祭即位坛五成陌，比照腊祭门户的规格。 [[32]](#sgz-note-32)

**[《后汉书·班梁列传》](../../sources/摘录/后汉书-卷047-班梁列传.md#p002)** · [仓内TXT L3609](../../sources/本地分卷/后汉书/后汉书-卷047.md#L3609)

> 後三年，忠說康居王借兵，還據損中，密與龜茲謀，遣使詐降於超。超內知其姦而外僞許之。忠大喜，即從輕騎詣超。超密勒兵待之，爲供張設樂。酒行，乃叱吏縛忠斬之。因擊破其衆，殺七百餘人，南道於是遂通。

1. **初令郎官诏除者得占丞、尉，以比秩为真。** 永元元年春三月甲辰，初令郎官诏除者得占丞、尉，以比秩为真。 [[1]](#hh-note-1)

2. **窦宪大破北匈奴，登燕然勒石。** 六月，窦宪出鸡鹿塞，邓鸿出稒阳塞，南单于出满夷谷，于稽落山大破北匈奴，追至私渠比鞮海。窦宪登燕然山刻石纪功后还，令梁讽携金帛前往北单于处招降，北单于遣弟右温禺鞮王奉奏贡献。九月庚申，窦宪进大将军，中郎将刘尚进车骑将军。 [[2]](#hh-note-2)

3. **会稽南山崩，郡国大水伤稼。** 七月，会稽南山崩，郡国九处大水，损伤农作。 [[3]](#hh-note-5)

<a id="hh-event-6"></a>

4. **闰月丙子，诏曰。** 闰月丙子，诏曰：『匈奴背叛，为害久远。赖祖宗之灵，师克有捷，丑虏破碎，遂扫厥庭，役不再籍，万里清荡，非朕小子眇身所能克堪。有司其案旧典，告类荐功，以章休烈。』 [[4]](#hh-note-6)

<a id="hh-event-8"></a>

5. **令郡国刑输作军营，其徙出塞者，刑虽未竟，皆免归田里。** 冬十月，命各郡国刑输作军营，其徙出塞者，刑虽未竟，皆免归田里。 [[5]](#hh-note-8)

<a id="hh-event-9"></a>

6. **阜陵王延薨。** 庚子，阜陵王延去世。 [[6]](#hh-note-9)

7. **本年所见流星。** 正月辛卯，参宿见黄白有光的流星，长约四丈。又有青白流星自天棓向东北行三丈消失，夜有流星起自太微东蕃，长三丈，另有流星起于天津，又有一星自天将军向东北行。 [[7]](#hh-note-12)

<a id="hh-event-17"></a>

8. **卒，诏尚书。** 永元元年，卒，诏尚书：『故大鸿胪韦彪，在位无愆，方欲录用，奄忽而卒。其赐钱二十万，布百匹，谷三千斛。』 [[8]](#hh-note-17)

<a id="hh-event-18"></a>

9. **复拜城门校尉。** 永元元年，复拜城门校尉。 [[9]](#hh-note-18)

<a id="hh-event-19"></a>

10. **纡坐征，以张掖太守邓训代为校尉，稍以赏赂离间之，由是诸种少解。** 永元元年，纡坐征，以张掖太守邓训代为校尉，稍以赏赂离间之，由是诸种少解。 [[10]](#hh-note-19)

<a id="hh-event-20"></a>

11. **天以七月後闰食，术以八月。** 永元元年，天以七月后闰食，术以八月。 [[11]](#hh-note-20)

<a id="sy-event-23"></a>

12. **五年观测确定冬至太阳位置。** 太史令玄等连续五年校测日行及冬至太阳位置，观测结果与《石氏星经》的部分数据相合。称冬至太阳在牵牛初的旧说自此淘汰。 [[12]](#sy-note-23)

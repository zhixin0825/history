# 公元89年｜永元元年

[← 公元88年](ce-0088.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元90年 →](ce-0090.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **初令郎官诏除者得占丞、尉，以比秩为真。** 永元元年春三月甲辰，初令郎官诏除者得占丞、尉，以比秩为真。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **车骑将军窦宪出鸡鹿塞。** 夏六月，车骑将军窦宪出鸡鹿塞，度辽将军邓鸿出稒阳塞，南单于出满夷谷，与北匈奴战于稽落山，大破之，追至私渠比鞮海。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **窦宪遂登燕然山，刻石勒功而还。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **北单于遣弟右温禺鞮王奉奏贡献。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **会稽山崩。** 秋七月乙未，会稽山崩。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **闰月丙子，诏曰。** 闰月丙子，诏曰：『匈奴背叛，为害久远。赖祖宗之灵，师克有捷，丑虏破碎，遂扫厥庭，役不再籍，万里清荡，非朕小子眇身所能克堪。有司其案旧典，告类荐功，以章休烈。』 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **以车骑将军窦宪为大将军，以中郎将刘尚为车骑将军。** 九月庚申，以车骑将军窦宪为大将军，以中郎将刘尚为车骑将军。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **令郡国刑输作军营，其徙出塞者，刑虽未竟，皆免归田里。** 冬十月，命各郡国刑输作军营，其徙出塞者，刑虽未竟，皆免归田里。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **阜陵王延薨。** 庚子，阜陵王延去世。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **是岁，郡国九大水。** 当年，郡国九大水。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **窦宪遣梁讽先使北匈奴。** 窦宪征匈奴，令梁讽携金帛先使北单于，招徕降附。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **孝和永元元年正月辛卯，有流星起参，长四丈，有光，色黄白。** 《天文志》记孝和永元元年正月辛卯，有流星起参，长四丈，有光，色黄白。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **流星起天棓，东北行三丈所，灭，色青白。** 《天文志》记二月，流星起天棓，东北行三丈所，灭，色青白。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **夜，有流星起太微东蕃，长三丈。** 《天文志》记壬申夜，有流星起太微东蕃，长三丈。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **流星起天津。** 《天文志》记三月丙辰，流星起天津。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **有流星起天将军，东北行。** 《天文志》记壬戌，有流星起天将军，东北行。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **卒，诏尚书。** 永元元年，卒，诏尚书：『故大鸿胪韦彪，在位无愆，方欲录用，奄忽而卒。其赐钱二十万，布百匹，谷三千斛。』 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **复拜城门校尉。** 永元元年，复拜城门校尉。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **纡坐征，以张掖太守邓训代为校尉，稍以赏赂离间之，由是诸种少解。** 永元元年，纡坐征，以张掖太守邓训代为校尉，稍以赏赂离间之，由是诸种少解。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **天以七月後闰食，术以八月。** 永元元年，天以七月后闰食，术以八月。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **和帝永元元年七月，郡国九大水，伤稼。** [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **和帝永元元年七月，会稽南山崩。** [[22]](#hh-note-22)

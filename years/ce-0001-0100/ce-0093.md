[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **宗祀五帝於明堂，遂登灵台，望云物。** 五年春正月乙亥，宗祀五帝于明堂，遂登灵台，望云物。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **大赦天下。** 颁布大赦。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **千乘王伉薨。** 戊子，千乘王伉去世。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **封皇帝万岁为广宗王。** 辛卯，封皇帝万岁为广宗王。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **诏有司省减内外厩及凉州诸苑马。** 二月戊戌，诏有司省减内外厩及凉州诸苑马。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **自京师离宫果园上林广成囿悉以假贫民，恣得采捕，不收其税。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **诏曰“去年秋麦入少”。** 丁未，诏曰：『去年秋麦入少，恐民食不足。其上尤贫不能自给者户口人数。往者郡国上贫民，以衣履釜鬵为赀，而豪右得其饶利。诏书实核，欲有以益之，而长吏不能躬亲，反更徵召会聚，令失农作，愁扰百姓。若复有犯者，二千石先坐。』 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **太傅邓彪薨。** 甲寅，太傅邓彪去世。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **陇西地震。** 戊午，陇西地震。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **诏曰“选举良才”。** 三月戊子，诏曰：『选举良才，为政之本。科别行能，必由乡曲。而郡国举吏，不加简择，故先帝明勑在所，令试之以职，乃得充选。又德行尤异，不须经职者，别署状上。而宣布以来，出入九年，二千石曾不承奉，恣心从好，司隶、刺史讫无纠察。今新蒙赦令，且复申勑，后有犯者，显明其罚。在位不以选举为忧，督察不以发觉为负，非独州郡也。是以庶官多非其人。下民被奸邪之伤，由法不行故也。』 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **遣使者分行贫民，举实流冗，开仓赈禀三十余郡。** 庚寅，派使者分行贫民，举实流冗，开仓赈禀三十余郡。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **封阜陵王种兄鲂为阜陵王。** 夏四月壬子，封阜陵王种兄鲂为阜陵王。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **郡国三雨雹。** 六月丁酉，郡国三雨雹。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **广宗王万岁薨，无子，国除。** 秋九月辛酉，广宗王万岁薨，无子，国除。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **匈奴单于於除鞬叛，遣中朗将任尚讨灭之。** 匈奴单于于除鞬叛，遣中朗将任尚讨灭之。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **令郡县劝民蓄蔬食以助五谷。** 壬午，令郡县劝民蓄蔬食以助五谷。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **其官有陂池，令得采取，勿收假税二岁。** [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **太尉尹睦薨。** 冬十月辛未，太尉尹睦去世。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **太仆张酺为太尉。** 十一月乙丑，太仆张酺为太尉。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **是岁，武陵郡兵破叛蛮，降之。** 当年，武陵郡兵破叛蛮，降服。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **护羌校尉贯友讨烧当羌，羌乃遁去。** [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **南单于安国叛，骨都侯喜斩之。** [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **梁节王刘畅被劾削县。** 豫州刺史告刘畅不道，朝廷最终削其两县，保留王封。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **刘万岁封广宗王、同年卒。** 和帝分钜鹿为广宗国，刘万岁当年即薨，国地归钜鹿。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **周纡上疏劾窦瑰。** 周纡复任御史中丞，弹劾仍在朝的夏阳侯窦瑰。 [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **太白、荧惑、辰星俱在东井。** 《天文志》记五年四月癸巳，太白、荧惑、辰星俱在东井。 [[26]](#hh-note-26)

<a id="hh-event-27"></a>

27. **岁星犯轩辕大星。** 《天文志》记七月壬午，岁星犯轩辕大星。 [[27]](#hh-note-27)

<a id="hh-event-28"></a>

28. **金在南斗魁中。** 《天文志》记九月，金在南斗魁中。 [[28]](#hh-note-28)

<a id="hh-event-29"></a>

29. **火犯房北第一星。** 《天文志》记火犯房北第一星。 [[29]](#hh-note-29)

<a id="hh-event-30"></a>

30. **迁酺为太仆。** 永元五年，迁酺为太仆。 [[30]](#hh-note-30)

<a id="hh-event-31"></a>

31. **和帝永元五年六月，郡国三雨雹，大如鸡子。** [[31]](#hh-note-31)

<a id="hh-event-32"></a>

32. **和帝永元五年五月戊寅，南阳大风，拔树木。** [[32]](#hh-note-32)

# 公元96年｜永元八年

[← 公元95年](ce-0095.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元97年 →](ce-0097.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **立贵人阴氏为皇后。** 八年春二月己丑，立贵人阴氏为皇后。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **赐天下男子爵，人二级，三老、孝悌、力田三级，民无名数及流民欲占者一级。** 赐天下男子爵，人二级，三老、孝悌、力田三级，民无名数及流民欲占者一级；鳏、寡、孤、独、笃癃，贫不能自存者粟，人五斛。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **乐成王党薨。** 夏四月癸亥，乐成王党去世。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **诏赈贷幷州四郡贫民。** 甲子，诏赈贷幷州四郡贫民。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **河内、陈留蝗。** 五月，河内、陈留蝗。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **南匈奴右温禺犊王叛，为寇。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **行度辽将军庞奋、越骑校尉冯柱追讨之，斩右温禺犊王。** 秋七月，行度辽将军庞奋、越骑校尉冯柱追讨之，斩右温禺犊王。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **车师後王叛，击其前王。** 车师后王叛，击其前王。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **饮酎。** 八月辛酉，饮酎。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **诏郡国中都官系囚减死一等，诣敦煌戍。** 诏郡国中都官系囚减死一等，到敦煌戍。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **其犯大逆，募下蚕室。** 其犯大逆，募下蚕室；其女子宫。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **自死罪已下，至司寇及亡命者入赎，各有差。** [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **京师蝗。** 九月，京师蝗。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **吏民言事者，多归责有司。** [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **诏曰“蝗虫之异”。** 诏曰：『蝗虫之异，殆不虚生，万方有罪，在予一人，而言事者专咎自下，非助我者也。朕寤寐恫矜，思弭忧衅。昔楚严无灾而惧，成王出郊而反风。将何以匡朕不逮，以塞灾变？百僚师尹，勉修厥职，刺史、二千石详刑辟，理冤虐，恤鳏寡，矜孤弱，思惟致灾兴蝗之咎。』 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **复置广阳郡。** 庚子，复置广阳郡。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **北海王威有罪自杀。** 冬十月乙丑，北海王威有罪自杀。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **陈王羡薨。** 十二月辛亥，陈王羡去世。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **南宫宣室殿火。** 丁巳，南宫宣室殿火。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **封鲂弟十二人为乡、亭侯。** 永元八年，封鲂弟十二人为乡、亭侯。 [[20]](#hh-note-20)

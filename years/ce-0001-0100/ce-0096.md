# 公元96年｜永元八年

[← 公元95年](ce-0095.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元97年 →](ce-0097.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

<a id="hh-event-2"></a>

1. **和帝立阴皇后，赐民爵。** 立阴贵人为皇后，赐男子爵二级，三老、孝悌、力田三级，未有户籍及愿登记的流民一级。 [[1]](#hh-note-1)

<a id="hh-event-3"></a>

2. **乐成王党薨。** 夏四月癸亥，乐成王党去世。 [[2]](#hh-note-3)

<a id="hh-event-4"></a>

3. **诏赈贷幷州四郡贫民。** 甲子，诏赈贷幷州四郡贫民。 [[3]](#hh-note-4)

<a id="hh-event-5"></a>

<a id="hh-event-13"></a>

<a id="hh-event-14"></a>

<a id="hh-event-15"></a>

4. **河内、陈留与京师蝗，和帝诏恤冤弱。** 五月河内、陈留蝗，九月京师蝗。吏民上言多归咎有司，和帝下诏以灾咎自任，令百官修职，地方详核刑狱、理冤，救恤鳏寡孤弱。 [[4]](#hh-note-5)

<a id="hh-event-6"></a>

<a id="hh-event-7"></a>

5. **南匈奴右温禺犊王入寇，被庞奋、冯柱斩杀。** 南匈奴右温禺犊王叛乱为寇，七月，庞奋、冯柱追讨，将其斩杀。 [[5]](#hh-note-6)

<a id="hh-event-8"></a>

6. **车师後王叛，击其前王。** 车师后王叛，击其前王。 [[6]](#hh-note-8)

<a id="hh-event-9"></a>

7. **饮酎。** 八月辛酉，饮酎。 [[7]](#hh-note-9)

<a id="hh-event-10"></a>

<a id="hh-event-11"></a>

<a id="hh-event-12"></a>

8. **减刑戍敦煌，按等次准赎。** 朝廷令郡国、中都官系囚减死一等、戍敦煌，犯大逆者募下蚕室。死罪以下到司寇及亡命者，准依等次纳赎。 [[8]](#hh-note-10)

<a id="hh-event-16"></a>

9. **复置广阳郡。** 庚子，复置广阳郡。 [[9]](#hh-note-16)

<a id="hh-event-17"></a>

10. **北海王威有罪自杀。** 冬十月乙丑，北海王威有罪自杀。 [[10]](#hh-note-17)

<a id="hh-event-18"></a>

11. **陈王羡薨。** 十二月辛亥，陈王羡去世。 [[11]](#hh-note-18)

<a id="hh-event-19"></a>

12. **南宫宣室殿火。** 丁巳，南宫宣室殿火。 [[12]](#hh-note-19)

<a id="hh-event-20"></a>

13. **封鲂弟十二人为乡、亭侯。** 永元八年，封鲂弟十二人为乡、亭侯。 [[13]](#hh-note-20)

<a id="sy-event-21"></a>

14. **贾逵复任侍中、兼领骑都尉。** 贾逵兼领秘书近署，受和帝信任。 [[14]](#sy-note-21)

<a id="sy-event-22"></a>

15. **置临汝县。** 豫章郡设置临汝县。 [[15]](#sy-note-22)

<a id="sy-event-23"></a>

16. **复置北平邑县。** 代郡恢复北平邑县。 [[16]](#sy-note-23)

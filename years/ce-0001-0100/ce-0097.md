<a id="hh-event-1"></a>

1. **永昌徼外蛮夷及掸国重译奉贡。** 九年春正月，永昌徼外蛮夷及掸国重译奉贡。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **陇西地震。** 三月庚辰，陇西地震。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **济南王康薨。** 癸巳，济南王康去世。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **西域长史王林击车师後王，斩之。** 西域长史王林击车师后王，斩之。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **封乐成王党子巡为乐成王。** 夏四月丁卯，封乐成王党子巡为乐成王。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **蝗、旱。** 六月，蝗、旱。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **诏“今年秋稼为蝗虫所伤”。** 戊辰，诏：『今年秋稼为蝗虫所伤，皆勿收租、更、刍稾；若有所损失，以实除之，余当收租者亦半入。其山林饶利，陂池渔采，以赡元元，勿收假税。』 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **蝗虫飞过京师。** 秋七月，蝗虫飞过京师。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **鲜卑寇肥如，辽东太守祭参下狱死。** 八月，鲜卑寇肥如，辽东太守祭参下狱后死亡。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **闰月辛巳，皇太后窦氏崩。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **葬章德皇后。** 丙申，葬章德皇后。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **烧当羌寇陇西，杀长吏，遣行征西将军刘尚、越骑校尉赵世等讨破之。** [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **司徒刘方策免，自杀。** 九月庚申，司徒刘方策免，自杀。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **追尊皇妣梁贵人为皇太后。** 甲子，追尊皇妣梁贵人为皇太后。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **改葬恭怀梁皇后於西陵。** 冬十月乙酉，改葬恭怀梁皇后于西陵。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **光禄勳河南吕盖为司徒。** 十一月癸卯，光禄勳河南吕盖为司徒。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **司空张奋罢。** 十二月丙寅，司空张奋罢。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **太仆韩棱为司空。** 壬申，太仆韩棱为司空。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **复置若庐狱官。** 己丑，复置若庐狱官。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **李法以贤良方正应对策。** 李法以贤良方正被选入朝，任博士，后来又有多项公开进谏。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **蔡伦监制器械。** 蔡伦为尚方令时监制秘剑和其他器械，工艺精密。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **班超遣甘英使大秦。** 甘英奉班超之命向西，抵海而还。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **辽东鲜卑攻肥如。** 鲜卑攻击肥如县，太守祭参以失利获罪。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **徵拜议郎。** 永元九年，徵拜议郎。 [[24]](#hh-note-24)

### 20. 李法以贤良方正应对策

[返回正文第20条](#hh-event-20)

<a id="hh048-l3650-e20"></a>

**[《后汉书·杨李翟应霍爰徐列传》](../../sources/摘录/后汉书-卷048-杨李翟应霍爰徐列传.md#p002)** · [仓内TXT L3650](../../sources/本地分卷/后汉书/后汉书-卷048.md#L3650)

> 和帝永元九年，應賢良方正對策，除愽士，遷侍中、光祿大夫。歲餘，上疏以爲朝政苛碎，違永平、建初故事；宦官權重，椒房寵盛；又譏史官記事不實，後世有識，尋功計德，必不明信。坐失旨，下有司，免爲庶人。還鄉里，杜門自守。故人儒生時有候之者，言談之次，問其不合上意之由，法未甞應對。友人固問之，法曰：「鄙夫可與事君乎哉？苟患失之，無所不至。孟子有言：『夫仁者如射，正己而後發。發而不中，不怨勝己者，反諸身而已矣。

**归年与互校** 年次据本传。

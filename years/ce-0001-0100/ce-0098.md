1. **诏曰“堤防沟渠”。** 十年春三月壬戌，诏曰：『堤防沟渠，所以顺助地理，通利壅塞。今废慢懈弛，不以为负。刺史、二千石其随宜疏导。勿因缘妄发，以为烦扰，将显行其罚。』 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-6"></a>

<a id="hh-event-12"></a>

2. **京师及五州雨水为灾。** 京师大水，另有五州雨水。本年淫雨损伤农作。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

3. **韩棱去世，巢堪继任司空。** 司空韩棱去世，太常巢堪接任。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

4. **复置廪牺官。** 九月庚戌，复置廪牺官。 [[4]](#hh-note-5)

<a id="hh-event-7"></a>

5. **烧当羌豪迷唐等率种人诣阙贡献。** 十二月，烧当羌豪迷唐等率种人到阙贡献。 [[5]](#hh-note-7)

<a id="hh-event-8"></a>

6. **梁王畅薨。** 戊寅，梁王畅去世。 [[6]](#hh-note-8)

<a id="hh-event-9"></a>

7. **卒於家，时年八十二。** 永元十年，卒于家，时年八十二。 [[7]](#hh-note-9)

<a id="hh-event-10"></a>

8. **封苍孙梁为矜阳亭侯，敞弟六人为列侯。** 永元十年，封苍孙梁为矜阳亭侯，敞弟六人为列侯。 [[8]](#hh-note-10)

<a id="hh-event-11"></a>

9. **迁少府、大司农。** 永元十年，迁少府、大司农。 [[9]](#hh-note-11)

<a id="sy-event-13"></a>

10. **刘恺让爵，和帝令刘宪承袭居巢侯。** 有司重议刘恺避封。贾逵上疏称其让爵为孝友节行，和帝接受，命弟刘宪承袭。 [[10]](#sy-note-13)

### 10. 刘恺让爵，和帝令刘宪承袭居巢侯

[返回正文第10条](#sy-event-13)

<a id="sy-hh039-l3075-e13"></a>

**[《后汉书·刘赵淳于江刘周赵列传》](../../sources/摘录/后汉书-卷039-刘赵淳于江刘周赵列传.md#p004)** · [仓内TXT L3075](../../sources/本地分卷/后汉书/后汉书-卷039.md#L3075)

> 積十餘歲，至永元十年，有司復奏之，侍中賈逵因上書曰：「孔子稱『能以禮讓為國，於從政乎何有』。竊見居巢侯劉般嗣子愷，素行孝友，謙遜絜清，讓封弟憲，潛身遠多。有司不原樂善之心，而繩以循常之法，懼非長克讓之風，成含弘之化。前世扶陽侯韋玄成，近有陵陽侯丁鴻、鄳侯鄧彪，並以高行絜身辭爵，未聞貶削，而皆登三事。今愷景仰前修，有伯夷之節，宜蒙矜宥，全其先功，以增聖朝尚德之美。」和帝納之，下詔曰：「故居巢侯劉般嗣子愷，當襲般爵，而稱父遺意，致國弟憲，遁亡七年，所守彌篤。蓋王法崇善，成人之美。其聽憲嗣爵。

**归年与互校** 《刘赵淳于江刘周赵列传》附刘恺传明记永元十年；其此前避封、章和年间议绝封属先事。

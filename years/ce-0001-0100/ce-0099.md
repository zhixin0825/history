# 公元99年｜永元十一年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **遣使循行郡国，禀贷被灾害不能自存者，令得渔采山林池泽，不收假税。** 十一年春二月，遣使循行郡国，禀贷被灾害不能自存者，令得渔采山林池泽，不收假税。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏郡国中都官徒及笃癃老小女徒各除半刑，其未竟三月者，皆免归田里。** 丙午，诏郡国中都官徒及笃癃老小女徒各除半刑，其未竟三月者，皆免归田里。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **大赦天下。** 夏四月丙寅，颁布大赦。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **复置右校尉官。** 己巳，复置右校尉官。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **诏曰“吏民逾僭”。** 秋七月辛卯，诏曰：『吏民逾僭，厚死伤生，是以旧令节之制度。顷者贵戚近亲，百僚师尹，莫肯率从，有司不举，怠放日甚。又商贾小民，或忘法禁，奇巧靡货，流积公行。其在位犯者，当先举正。市道小民，但且申明宪纲，勿因科令，加虐羸弱。』 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **陈王刘羡使客杀李仪家属。** 刘羡令宾客隗久杀县令李仪家属，有司其后奏请处分。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **流星大如瓜，起氐，西南行，稍有光，白色。** 《天文志》记十一年五月丙午，流星大如瓜，起氐，西南行，稍有光，白色。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **封错弟七人为列侯。** 永元十一年，封错弟七人为列侯。 [[8]](#hh-note-8)

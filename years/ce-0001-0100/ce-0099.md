# 公元99年｜永元十一年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **遣使循行郡国，禀贷被灾害不能自存者，令得渔采山林池泽，不收假税。** 十一年春二月，遣使循行郡国，禀贷被灾害不能自存者，令得渔采山林池泽，不收假税。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-3"></a>

2. **减刑免遣并颁大赦。** 诏各地及中都官的刑徒、残疾老幼及女徒皆减半刑，余刑三月者免遣归乡。朝廷又颁大赦。 [[2]](#hh-note-2)

<a id="hh-event-4"></a>

3. **复置右校尉官。** 己巳，复置右校尉官。 [[3]](#hh-note-4)

<a id="hh-event-5"></a>

4. **诏曰“吏民逾僭”。** 秋七月辛卯，诏曰：『吏民逾僭，厚死伤生，是以旧令节之制度。顷者贵戚近亲，百僚师尹，莫肯率从，有司不举，怠放日甚。又商贾小民，或忘法禁，奇巧靡货，流积公行。其在位犯者，当先举正。市道小民，但且申明宪纲，勿因科令，加虐羸弱。』 [[4]](#hh-note-5)

<a id="hh-event-6"></a>

5. **陈王刘羡使客杀李仪家属。** 刘羡令宾客隗久杀县令李仪家属，有司其后奏请处分。 [[5]](#hh-note-6)

<a id="hh-event-7"></a>

6. **流星大如瓜，起氐，西南行，稍有光，白色。** 十一年五月丙午，流星大如瓜，起氐，西南行，稍有光，白色。 [[6]](#hh-note-7)

<a id="hh-event-8"></a>

7. **封错弟七人为列侯。** 永元十一年，封错弟七人为列侯。 [[7]](#hh-note-8)

<a id="sy-event-9"></a>

8. **复置潘县。** 上谷郡恢复潘县。 [[8]](#sy-note-9)

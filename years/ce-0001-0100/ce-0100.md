<a id="hh-event-1"></a>

1. **旄牛徼外白狼、貗薄夷率种人内属。** 十二年春二月，旄牛徼外白狼、貗薄夷率种人内属。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏贷被灾诸郡民种粮。** [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **赐下贫、鳏、寡、孤、独、不能自存者，及郡国流民，听入陂池渔采，以助蔬食。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **诏曰“比年不登”。** 三月丙申，诏曰：『比年不登，百姓虚匮。京师去冬无宿雪，今春无澍雨，黎民流离，困于道路。朕痛心疾首，靡知所济。「瞻仰昊天，何辜今人？」三公，朕之腹心，而未获承天安民之策。数诏有司，务择良吏。今犹不改，竞为苛暴，侵愁小民，以求虚名，委任下吏，假势行邪。是以令下而蕊生，禁至而诈起。巧法析律，饰文增辞，货行于言，罪成乎手，朕甚病焉。公卿不思助明好恶，将何以救其咎罚？咎罚既至，复令灾及小民。若上下同心，庶或有廖。其赐天下男子爵，人二级，三老、孝悌、力田三级，民无名数及流民欲占者人一级；鳏、寡、孤、独、笃癃、贫不能自存者粟，人三斛。』 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **赐博士员弟子在太学者布，人三匹。** 壬子，赐博士员弟子在太学者布，人三匹。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **日南象林蛮夷反，郡兵讨破之。** 夏四月，日南象林蛮夷反，郡兵讨破之。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **闰月，赈贷敦煌、张掖、五原民下贫者糓。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **秭归山崩。** 戊辰，秭归山崩。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **舞阳大水，赐被水灾尤贫者谷，人三斛。** 六月，舞阳大水，赐被水灾尤贫者谷，人三斛。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **日有食之。** 秋七月辛亥朔，发生日食。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **太尉张酺免。** 九月戊午，太尉张酺免。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **大司农张禹为太尉。** 丙寅，大司农张禹为太尉。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **西域蒙奇、兜勒二国遣使内附，赐其王金印紫绶。** 冬十一月，西域蒙奇、兜勒二国遣使内附，赐其王金印紫绶。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **是岁，烧当羌复叛。** 当年，烧当羌复叛。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **班超上疏求自西域生还。** 班超年老思归，上疏愿入玉门关，后有班昭为兄请归。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **杨终奉召为郎中而病卒。** 朝廷遣召杨终为郎中，他未及久仕即病卒。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **夜，有苍白气，长三丈，起天园，东北指军市，见积十日。** 《天文志》记十二年十一月癸酉夜，有苍白气，长三丈，起天园，东北指军市，见积十日。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **复征，三迁五官中郎将。** 永元十二年，复征，三迁五官中郎将。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **征拜太常，卒官。** 永元十二年，征拜太常，卒官。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **和帝永元十二年，旄牛徼外白狼、楼薄蛮夷王唐缯等，遂率种人十七万口，归义内属。** [[20]](#hh-note-20)

# 开国将相与光武诸王

[本世纪目录](README.md) · [全部世纪](../README.md) · [《后汉书》分卷目录](../../拆分史书/后汉书/README.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **刘玄从平林起兵到更始败亡。** 刘玄早避仇家于平林，后被绿林各军拥为天子。迁长安后赏罚失序，三辅受兵，赤眉入关前后群臣离散，刘玄降后被杀。 [[1]](#note-1)

<a id="event-2"></a>

2. **赤眉起兵、刘盆子即位与归降。** 樊崇、逄安等起兵，改用赤眉作识别，迎宗室刘盆子为帝。长安粮尽后赤眉东归，在宜阳投降。刘盆子后来获安置，卷末评两政权兴亡。 [[2]](#note-2)

<a id="event-3"></a>

3. **王昌诈称刘子舆。** 王昌一名王郎，借成帝遗子之名据邯郸。赵王家与河北豪杰响应，旋为刘秀及上谷、渔阳等郡兵所败。 [[3]](#note-3)

<a id="event-4"></a>

4. **刘永据梁。** 刘永先由更始封梁王，后自立，与董宪等互为声援。盖延攻睢阳及砀等地，梁地战争延续至刘永子刘纡败亡。 [[4]](#note-4)

<a id="event-5"></a>

5. **张步与董宪、李宪。** 张步据齐地，先后应更始、刘永。耿弇击败张步后对其部众分遣，董宪、李宪等在东海、淮南抵抗，终被东汉攻灭。 [[5]](#note-5)

<a id="event-6"></a>

6. **彭宠据渔阳。** 彭宠曾遣兵助刘秀，因封赏和与朱浮不和而反，后被家奴杀死。其弟亲族由此覆亡。 [[6]](#note-6)

<a id="event-7"></a>

7. **卢芳称帝、入匈奴及史论。** 卢芳诈称武帝后裔，在匈奴支持下据北方诸郡。降汉、再叛后最终流寓匈奴。史论以民心和诸割据的失策为主。 [[7]](#note-7)

<a id="event-8"></a>

8. **隗嚣据陇右。** 隗嚣趁新朝瓦解在天水起兵，与更始、东汉与蜀地公孙述先后交涉。马援、来歙等往来，汉军长期围攻；隗嚣死后，其子和旧部相继失去据点。 [[8]](#note-8)

<a id="event-9"></a>

9. **公孙述据蜀与成都陷落。** 公孙述在成都称帝，延岑等受其招纳。岑彭、吴汉、臧宫相继进攻，公孙述负伤死，成都归汉。史论以赵佗与公孙述对照，并及延岑。 [[9]](#note-9)

<a id="event-10"></a>

10. **刘縯起兵及被更始所杀。** 刘縯结豪杰，起于舂陵，与绿林联合后打败甄阜等，围攻宛。更始忌其威望，刘稷事起后刘縯亦被杀。 [[10]](#note-10)

<a id="event-11"></a>

11. **北海靖王刘兴一系。** 刘縯子刘章、刘兴受封，鲁国、北海的边界与支系随爵位移并。所载嗣王、国除和封侯分别参照年页。 [[11]](#note-11)

<a id="event-12"></a>

12. **赵王刘良。** 刘良曾养育幼年刘秀，受封后曾因骄纵被朝廷责备，迁封及后嗣见下。 [[12]](#note-12)

<a id="event-13"></a>

13. **城阳王刘祉与舂陵世系。** 刘祉家出于长沙定王，列舂陵侯诸世的袭封、迁徙及反新后的得失。 [[13]](#note-13)

<a id="event-14"></a>

14. **泗水王刘歙。** 刘歙父子与刘秀有旧，在更始及光武政权中受任与封爵，后世承袭及国除所由见本传。 [[14]](#note-14)

<a id="event-15"></a>

15. **刘赐、刘顺、刘嘉。** 刘赐曾辅佐更始、招纳赤眉。刘顺、刘嘉先后归光武，受任及其子孙事迹表明宗族各支在两政权之间的选择。 [[15]](#note-15)

<a id="event-16"></a>

16. **李通响应光武。** 李氏本以货殖著姓。李通随图谶之说与刘秀议举大事，父兄遭王莽杀戮；李通在两汉之际从军，并参与新政权的建置。 [[16]](#note-16)

<a id="event-17"></a>

17. **王常与下江兵。** 王常避仇至江夏，与绿林诸部举兵。联合舂陵军、更始败后投光武，随后随诸将讨诸郡敌军。 [[17]](#note-17)

<a id="event-18"></a>

18. **邓晨。** 邓晨娶刘秀姊元，参与早期起兵，战乱中家人受难。归附光武后担任军政官，兴水利并以勤政著称。 [[18]](#note-18)

<a id="event-19"></a>

19. **来歙使陇，袭略阳及后人。** 来歙以使者联络隗嚣与陇右人士，率先据略阳，后于军中遭刺。传文续记其后人及史家对他守信的评价。 [[19]](#note-19)

<a id="event-20"></a>

20. **邓禹佐刘秀、入关与持守。** 邓禹少年识刘秀，在河北献策，后率军西征关中。与赤眉交锋受挫，回朝后仍以持谨受重。 [[20]](#note-20)

<a id="event-21"></a>

21. **邓训、邓骘与邓氏宗族。** 邓训抚绥羌与小月氏。邓绥临朝时邓骘等以外戚在朝并参加羌战；太后死后邓氏受清算。传末评外戚祸福。 [[21]](#note-21)

<a id="event-22"></a>

22. **寇恂守河内、平颍川。** 寇恂从上谷归刘秀，守河内保障供应，又与冯异应付洛阳兵。受命治颍川、招抚地方；附兄弟子孙和论赞。 [[22]](#note-22)

<a id="event-23"></a>

23. **冯异助定关中。** 冯异自父城归汉，随刘秀平河北，后入关对抗赤眉，受命守关中。其与主将及地方势力的往来见本传各段。 [[23]](#note-23)

<a id="event-24"></a>

24. **岑彭征南、伐蜀。** 岑彭早守棘阳，后归汉，参与招降朱鲔；他由荆州逆江上行，水陆并进，入蜀后被刺。 [[24]](#note-24)

<a id="event-25"></a>

25. **贾复及贾宗。** 贾复从刘嘉转从刘秀，以武勇立功，后退居列侯。子孙仍参与边州军政。论赞并论岑彭、冯异和贾氏。 [[25]](#note-25)

<a id="event-26"></a>

26. **吴汉取幽州兵、破蜀。** 吴汉在渔阳经营并结交豪杰，联合上谷兵助刘秀。后以大司马平各地，与臧宫等进兵成都；传文对其勇断及作战处置均有记载。 [[26]](#note-26)

<a id="event-27"></a>

27. **盖延攻睢阳。** 盖延由渔阳兵归光武，参加平河北、讨刘永和支援西征。军职、受封与后人继嗣见传。 [[27]](#note-27)

<a id="event-28"></a>

28. **陈俊在山东。** 陈俊早为刘嘉属吏，归光武后长期从军，又治琅邪等地，攻海岱诸军。 [[28]](#note-28)

<a id="event-29"></a>

29. **臧宫入蜀及论赞。** 臧宫从下江兵归汉，参与冯异、岑彭、吴汉诸方作战，兵入蜀地。战后有关对外用兵的进言与皇帝答诏并见。 [[29]](#note-29)

<a id="event-30"></a>

30. **耿弇取河北、定齐地。** 耿弇引上谷、渔阳骑兵响应，参与平邯郸。后单独统军临淄，先后破费邑、张步，传末论其决策。 [[30]](#note-30)

<a id="event-31"></a>

31. **耿国、耿秉、耿夔。** 耿国入侍并参与南北匈奴决策，耿秉与耿夔继从窦宪等对北匈奴用兵，涉及燕然及金微山。 [[31]](#note-31)

<a id="event-32"></a>

32. **耿恭与耿晔。** 耿恭领守车师后部，被围疏勒，奉救援撤还。耿晔以后为乌桓校尉。范晔将耿恭守城与苏武守节并论。 [[32]](#note-32)

<a id="event-33"></a>

33. **铫期。** 铫期参与刘秀从河北突围与平邯郸，后治魏郡并入朝任卫尉。受封及后人仕历见传。 [[33]](#note-33)

<a id="event-34"></a>

34. **王霸。** 王霸早从刘秀，参与昆阳与河北诸战。后屯上谷，经营北边。河冰故事依原传保留。 [[34]](#note-34)

<a id="event-35"></a>

35. **祭遵。** 祭遵掌军纪，严于制军，从攻关中及陇右，卒后光武亲自临丧。传记特举其好经书及礼遇之事。 [[35]](#note-35)

<a id="event-36"></a>

36. **祭肜与辽东。** 祭肜在辽东招抚边民并应付数次入寇，后参与出击匈奴。论赞着重其用兵刚方与守边成绩。 [[36]](#note-36)

<a id="event-37"></a>

37. **任光与任隗。** 任光保信都迎刘秀，协助集兵。任隗后来任官，遇窦宪权势正盛时与袁安持异议。 [[37]](#note-37)

<a id="event-38"></a>

38. **李忠与万脩。** 二人为信都守城的一方，率吏民响应刘秀，参与攻取河北及其后军政。二传又载封爵和继嗣。 [[38]](#note-38)

<a id="event-39"></a>

39. **邳彤主张继续经营河北。** 王郎起兵之际邳彤归光武，劝其借河北力量救信都。范晔借其议论评辨见机决断。 [[39]](#note-39)

<a id="event-40"></a>

40. **刘植和耿纯。** 刘植率宗族据昌城，往说真定王刘杨归汉。耿纯举族助光武，渡河平兵，后治东郡。卷末合赞任光等。 [[40]](#note-40)

<a id="event-41"></a>

41. **朱祐从征与退居。** 朱祐与光武兄弟交好，从征后封侯。被邓奉擒获，及邓奉兵败复职，续平南阳，行军以受降定邑为务，约束部众不得掳掠。卸兵权后议降诸王为公、三公去大号，末叙其嗣爵。 [[41]](#note-41)

<a id="event-42"></a>

42. **景丹由上谷拥护光武。** 景丹先任上谷长史，与耿况抗拒王郎，率上谷兵归光武。吴汉为大司马，景丹受骠骑将军之任，后封故乡栎阳，东征中卒。嗣爵中绝后，邓太后复封一支。 [[42]](#note-42)

<a id="event-43"></a>

43. **王梁受命与开渠。** 王梁随彭宠所遣兵归附，从军事起家。违诏调兵险遭处死而获赦，后任河南尹，开渠引谷水未成，被劾谢病。后裔因楚王英案失爵。 [[43]](#note-43)

<a id="event-44"></a>

44. **杜茂、马成与刘隆。** 杜茂平五校余部，久镇北边。马成以坚壁疲困李宪，后来经营边塞。刘隆早年家受王莽案牵连，归汉参与征讨和屯田，又因度田获罪，终定封慎侯。 [[44]](#note-44)

<a id="event-45"></a>

45. **傅俊、坚镡与马武。** 傅俊迎军受任，随征秦丰后东下。坚镡取宛，处在邓奉、董訢两敌之间，孤守到援军到达。马武历事更始和光武，参加讨刘永、庞萌、隗嚣及北边征战。 [[45]](#note-45)

<a id="event-46"></a>

46. **云台功臣题名与史论。** 论光武处置佐命诸将的用意，列永平年间图画上南宫云台的二十八将及另列的王常、李通、窦融、卓茂。 [[46]](#note-46)

<a id="event-47"></a>

47. **窦融立足河西。** 窦融出自外戚旧族，曾随王莽将王邑兵败昆阳，后降更始。因家族熟悉河西条件，约诸郡相保，拒绝隗嚣游说，遣使向光武表明归附。 [[47]](#note-47)

<a id="event-48"></a>

48. **河西联军与光武会师。** 窦融写信责隗嚣失约，与五郡备兵，并打击与隗嚣结盟的羌部。光武西进一度停顿，后与窦融、河西兵在高平会师，优礼相待。 [[48]](#note-48)

<a id="event-49"></a>

49. **窦融入朝与子孙犯法。** 陇蜀平后，窦融代河西诸守还朝，出任大司空，因三公连坐免职，又典宿卫。窦氏一家多联姻公主，窦林及穆、勋等涉案败落。篇末评其高位求退。 [[49]](#note-49)

<a id="event-50"></a>

50. **窦固开通伊吾。** 窦固袭父爵，与耿忠等出塞追逐北匈奴，留兵伊吾卢，后来同耿秉再出白山，安置车师事。入朝受顾问、增封，历任光禄勋、卫尉。 [[50]](#note-50)

<a id="event-51"></a>

51. **窦宪专权、北征与败亡。** 窦宪凭章德皇后亲属身份掌权，因刺杀刘畅获罪，自请出击匈奴，燕然刻铭后被抬高班次。接着耿夔等出击金微山。党势侵凌朝廷，和帝与郑众谋诛其党，窦宪就国自杀，篇末以功高败名作评。 [[51]](#note-51)

<a id="event-52"></a>

52. **窦章入东观与晚年。** 窦章因羌乱移居外黄，经荐入东观校书。女儿为贵人，窦章历任官职，处梁、窦相争之间而全身，梁太后称制时去职。赞辞回顾窦氏数代功业。 [[52]](#note-52)

<a id="event-53"></a>

53. **马援游走陇蜀而归光武。** 马援少任边职，新末避地凉州，受隗嚣重用。访公孙述后不取其好修仪卫，赴洛阳见光武，向隗嚣述所见。隗嚣与汉决裂后，马援上疏自陈，并致书杨广欲说动其主。 [[53]](#note-53)

<a id="event-54"></a>

54. **西征、治陇西与五铢钱。** 光武是否深入陇地未决时，马援聚米拟山谷，指陈进兵道路。受命治陇西后讨先零等羌，主张恢复金城诸县、安置归民，后来请复行五铢钱，又破维汜余党李广。 [[54]](#note-54)

<a id="event-55"></a>

55. **马援南征及北边出兵。** 徵侧、徵贰起兵后，马援率部由合浦进交阯，平复九真等地，修城开渠并厘定与汉律不合之处。归来进献铜马式，随后赴北边防守，也并记马援与梁松间因礼数引起的冲突。 [[55]](#note-55)

<a id="event-56"></a>

56. **壶头病死、身后案与追谥。** 刘尚战败后，马援请征五溪，进军壶头时因暑热瘴疫而死。耿舒所诉军议、梁松问责及薏苡被诬为珠宝，令家属一度不敢归葬。朱勃上书申论其功，后来重修坟祠，并追谥忠成侯。 [[56]](#note-56)

<a id="event-57"></a>

57. **马廖、马防、马光及嗣爵。** 马援诸子因椒房亲属位高。马廖屡让封爵，子豫后因诽谤获罪；马防曾统军讨羌，马光一支遭窦宪案牵连。马氏先罢居封国，后又获准回京并恢复若干封爵。 [[57]](#note-57)

<a id="event-58"></a>

58. **马严、马续与马棱。** 马严与宫中学者校定《建武注记》，又上陈西域屯军问题。马续后来任度辽将军。马棱治广陵重赈济、灌溉，在边地供军则因加赋被追责。 [[58]](#note-58)

<a id="event-59"></a>

59. **卓茂治密、受封与去世。** 卓茂习经，在密县以教化而非苛刑待人，新末去官。光武即位后尊为太傅，卓茂死后亲临送葬，后叙爵位传承。 [[59]](#note-59)

<a id="event-60"></a>

60. **鲁恭治中牟与慎刑劝农。** 鲁恭重信义，其任中牟之民传有蝗不入界、雉驯儿童之说。入朝后主张遵循时令慎刑，批评盛夏、春耕时追召农民，历任司徒。 [[60]](#note-60)

<a id="event-61"></a>

61. **鲁丕讲经与治郡。** 鲁丕因对策擢用，主张表贤慎刑，治赵国时不许赵王移住学官，后治东郡等地修水利荐名士，也因赈给失实被问责。 [[61]](#note-61)

<a id="event-62"></a>

62. **鲁丕晚年受征。** 鲁丕仍以儒学受到征用，历任侍中及三老，终于官位。 [[62]](#note-62)

<a id="event-63"></a>

63. **魏霸治丧工程与退职。** 魏霸任将作大匠，督造和帝顺陵时以宽恕劝勉下吏，后为太常、长乐卫尉，因病求退。 [[63]](#note-63)

<a id="event-64"></a>

64. **刘宽以宽恕理政。** 刘宽遇人误认牛也不争，任郡守常以蒲鞭示罚而不使人受苦，后任太尉。传末记其屡免屡任、黄巾谋发前奏报及身后追赠。 [[64]](#note-64)

<a id="event-65"></a>

65. **伏湛摄政与伏无忌校书。** 伏湛为伏生后人，历郡县之任，光武征战时留守总摄诸司。后因不依诏亲护丧事被罢职。族人伏无忌奉诏校定经书诸子，又参与修《汉记》。 [[65]](#note-65)

<a id="event-66"></a>

66. **伏隆出使青徐与遇害。** 伏隆奉使青徐招降，张步一度受光武册拜，后因刘永许以王爵转变，拘执并杀伏隆。 [[66]](#note-66)

<a id="event-67"></a>

67. **侯霸采集汉初旧制。** 侯霸治临淮得民拥戴，光武后征为尚书令，访求旧典，上奏可行制度，继任大司徒，与隗嚣旧交亦见于传。 [[67]](#note-67)

<a id="event-68"></a>

68. **宋弘荐士及宋氏后人。** 宋弘拒赤眉征召，东汉任大司空，荐桓谭而责其过度奉乐，婉拒湖阳主婚议。宋汉后任度辽将军，宋则任郡守亦见于传。 [[68]](#note-68)

<a id="event-69"></a>

69. **蔡茂、郭贺与冯勤。** 蔡茂以儒学进，后为司徒。郭贺守荆州以政绩获公开表彰。冯勤主簿领封赏差次，后受光武信任入三公，末附其子孙承袭。 [[69]](#note-69)

<a id="event-70"></a>

70. **赵憙平乱、典礼与临终举贤。** 赵憙自更始历任军府、郡县，以捕治强人、保护州民显名，光武时掌三公及军政。受遗诏主持帝丧，以礼排诸王，晚年仍屡任太傅等职。 [[70]](#note-70)

<a id="event-71"></a>

71. **牟融通经与韦彪论用人。** 牟融经学起家，以治剧县和办理朝政见称。韦彪重经术品行，入朝后议选士应取有实德者，并省去妨害议政的文书程序。 [[71]](#note-71)

<a id="event-72"></a>

72. **韦氏支属与卷评。** 续载韦彪反对守令迎合请托的奏议及身后褒荣，附族子韦义、韦义之兄韦顺与韦豹及豹子韦著，史论归纳诸传人品行得失。 [[72]](#note-72)

<a id="event-73"></a>

73. **宣秉、张湛与王丹。** 宣秉拒仕王莽，入东汉后任御史中丞，清约见重。张湛严整知礼，屡以病辞。王丹以财赈给、教导乡人，重实际往来。 [[73]](#note-73)

<a id="event-74"></a>

74. **王良与杜林。** 王良讲《尚书》而辞荣，入朝后以守贫节知名。杜林在战乱中仍保存漆书《古文尚书》，入朝任大司空等职，传中收反对增立严法之议。 [[74]](#note-74)

<a id="event-75"></a>

75. **郭丹、吴良、承宫与郑均。** 郭丹坚持节义，后以谏议进。吴良斥谄言并受荐。承宫由牧豕就学，后来入朝答使者。郑均以己力劝兄不受赠，晚年获特礼赐职。 [[75]](#note-75)

<a id="event-76"></a>

76. **赵典及其侄赵谦、赵温。** 赵典善经礼，不与外戚及宦官权势相附。其侄赵谦讨黄巾、历任三公，赵温在献帝朝辗转任职，以书劝阻李傕加害朝廷。 [[76]](#note-76)

<a id="event-77"></a>

77. **桓谭论治与反谶。** 桓谭博习经学音律，参与更始及光武朝政。因直陈治道、反对借谶定事触怒皇帝，出任六安郡丞途中病死，附著论。 [[77]](#note-77)

<a id="event-78"></a>

78. **冯衍历事及失意。** 冯衍早年为更始系统谋策，又与鲍永等辗转河东，归光武后仍屡起屡废；传录其书疏与自陈，保存新汉相际地方抉择。 [[78]](#note-78)

<a id="event-79"></a>

79. **冯衍《显志赋》。** 赋追叙身世和仕途，托周览山川与古人行事说明进退，结归守节全身。篇首篇末兼叙作赋背景与经历。 [[79]](#note-79)

<a id="event-80"></a>

80. **冯豹与卷论。** 冯豹以家门和孝友见知，任尚书一类近职。史论比较桓谭、冯衍的才识、议论与际遇。 [[80]](#note-80)

<a id="event-81"></a>

81. **申屠刚谏阻王莽及光武。** 申屠刚因劝勿委政王氏被逐，乱中一度依隗嚣，归汉任尚书令，曾以身阻车争谏，后因言不见纳转职。 [[81]](#note-81)

<a id="event-82"></a>

82. **鲍永归汉与鲍昱任职。** 鲍永由更始旧臣归汉，并保全曾同事者，后为司隶校尉，治吏不避贵戚。子鲍昱历诸郡及三公，奉职不苟。 [[82]](#note-82)

<a id="event-83"></a>

83. **郅恽犯颜与郅寿抗强权。** 郅恽新莽时以天文劝退王莽，东汉历县令、皇太子傅等职，守城门和论东宫师职皆据礼直行。其子郅寿与窦宪冲突而死。 [[83]](#note-83)

<a id="event-84"></a>

84. **苏竟以书劝解兵争。** 苏竟善《易》与图纬，曾为尹融写信晓谕邓仲况、刘龚等，希望诸部顺大势并免兵祸，传录书中文字。 [[84]](#note-84)

<a id="event-85"></a>

85. **杨厚研习图讖与应征。** 杨厚嗣其家学，借阴阳推测灾异，数受朝廷征询，又常以病请退，门徒传其学。 [[85]](#note-85)

<a id="event-86"></a>

86. **郎顗应诏陈灾异与时政。** 郎顗承父习风角星算，在灾异之际应征，借天象论用贤、赋役、奢侈和时令，并列举可荐之士。 [[86]](#note-86)

<a id="event-87"></a>

87. **襄楷因天象进言。** 襄楷论灾异，将宫庭好尚、刑狱、宦官势力等与灾象并举，复奉书论事。部分言论遭朝臣驳诘，篇末评其才术。 [[87]](#note-87)

<a id="event-88"></a>

88. **郭伋与杜诗。** 郭伋任地方官时守信安民，传有约期返见儿童事。杜诗诛横暴军人，守南阳造水排以助冶铸，又建议凭虎符发军。 [[88]](#note-88)

<a id="event-89"></a>

89. **孔奋与张堪。** 孔奋在河西显贵而自守清贫，后参与东汉平乱。张堪随汉军入蜀后移守渔阳，据地安边，整饬田业，百姓为之歌。 [[89]](#note-89)

<a id="event-90"></a>

90. **廉范、王堂、苏章与苏不韦。** 廉范自为受难旧主守丧起家，守蜀郡改夜作火禁。王堂平巴郡边患，抑遏请托。苏章念旧而仍按罪治故人，附苏不韦为父复仇事。 [[90]](#note-90)

<a id="event-91"></a>

91. **羊续、贾琮与陆康。** 羊续守南阳以俭约拒馈，贾琮巡交阯先求民变根由，陆康守庐江平乱，后抗袁术围攻。篇末比较地方治理。 [[91]](#note-91)

<a id="event-92"></a>

92. **樊氏经营、封爵与樊准奏疏。** 樊重以农桑治产持家，樊宏为光武母族长者，亲贵而谦退。后附樊鲦、樊准等宗族仕历与谏疏。 [[92]](#note-92)

<a id="event-93"></a>

93. **阴识、阴兴与阴就。** 阴识从光武起兵，持谨厚之节。阴兴以宿卫受信任，辞封不居外戚恩泽。末及阴就及其子获罪，评宗族成败。 [[93]](#note-93)

<a id="event-94"></a>

94. **朱浮与彭宠相争。** 朱浮以幽州管帅任事，和渔阳太守彭宠在军需、权限上相冲突。彭宠起兵后，朱浮致书责辨，并折回洛阳。 [[94]](#note-94)

<a id="event-95"></a>

95. **朱浮论吏治与儒学。** 朱浮还朝后以朝廷屡换郡守不利教化，又请礼待儒士、重视学校，身居三公仍不能免于祸。 [[95]](#note-95)

<a id="event-96"></a>

96. **冯鲂与虞延。** 冯鲂由兵乱归汉，后历典京畿与三公，亦有对宗室不法的处置。虞延以治剧擢用，历司隶与公卿，因楚王英相关问题服罪。 [[96]](#note-96)

<a id="event-97"></a>

97. **郑弘、周章与史评。** 郑弘任官论边赋与转运，得罪权势。周章历官至司空，曾谋废立而败，史评论其刚直及政治判断。 [[97]](#note-97)

<a id="event-98"></a>

98. **梁统择所归与主张刑法。** 梁统与河西诸郡协守，归东汉后参与陇右军务。传录他主张整饬法令、加重部分刑罚的奏议及朝廷处置。 [[98]](#note-98)

<a id="event-99"></a>

99. **梁松、梁竦及梁商。** 梁松以婚姻亲贵并因案被诛，梁竦一支随宫闱变化或放逐或追尊。梁商因女立后掌兵政，谨慎任用外族，卒后梁冀继位。 [[99]](#note-99)

<a id="event-100"></a>

100. **梁冀专权与覆亡。** 梁冀凭外戚干政，涉及质帝之死和桓帝继立，压制公卿，广置田宅，夺人财货。桓帝联同近侍收权，梁冀夫妇自杀，党属治罪，附史论。 [[100]](#note-100)

<a id="event-101"></a>

101. **张纯议宗庙封禅及张奋。** 张纯归东汉后考议宗庙、郊祀、封禅典礼，历任三公；其子张奋笃学，任官亦见礼制等议。 [[101]](#note-101)

<a id="event-102"></a>

102. **曹褒承礼学修礼仪。** 曹褒承父曹充经学，受诏校订朝廷礼仪。所撰篇章遭争论，过于凭借个人判断是史家讨论的问题之一。 [[102]](#note-102)

<a id="event-103"></a>

103. **郑玄游学著述及身后名望。** 郑玄从马融受学，归后聚徒，著经注、驳异义，党锢时仍治学。传记载其在兵乱间所受礼遇、辞征及卒年，继以总论。 [[103]](#note-103)

<a id="event-104"></a>

104. **郑兴论礼法与拒谶。** 郑兴善古学，辗转更始、隗嚣，归光武后论郊礼、时政，不肯以谶记答问。 [[104]](#note-104)

<a id="event-105"></a>

105. **郑众出使与任大司农。** 郑众习经，出使匈奴时不肯向单于下拜，后反对再次出使，又曾出兵救戊己校尉。任大司农时坚持反对复设盐铁官。底本此传以“觿”书其名。 [[105]](#note-105)

<a id="event-106"></a>

106. **范升谏王莽征发与争立经博士。** 范升在新莽时上书责王邑征发而扰耕。光武征为博士，范升在云台反对为《左氏》《费氏易》立学，与韩歆等辩论，并保留他对师承及国家设学的见解。 [[106]](#note-106)

<a id="event-107"></a>

107. **陈元争立《左氏春秋》。** 陈元承陈钦之学，为《左氏》争博士之位，与范升等反复辩论，朝廷一度设置左氏博士。 [[107]](#note-107)

<a id="event-108"></a>

108. **贾逵论古文经学。** 贾逵承父业，擅长《左氏》《国语》等，奉诏比较经义、收徒讲授；传收其奏，并记朝廷对其学说的扶持。 [[108]](#note-108)

<a id="event-109"></a>

109. **张霸一族的仕学。** 张霸以经术德行显名，治郡与教子皆有记述；后世宗族多习经或为郡守，盛衰相继，篇末评论经师。 [[109]](#note-109)

<a id="event-110"></a>

110. **桓荣说经与明帝尊师。** 桓荣客佣治学，乱中流离，后为太子讲《尚书》，屡进礼让，明帝即位后仍尊之为师。 [[110]](#note-110)

<a id="event-111"></a>

111. **桓郁以下传学与任职。** 桓郁、桓焉继续为皇室讲经，之后桓典、桓鸾、桓晔、桓彬等各具仕履与行迹，附刘猛的议政。 [[111]](#note-111)

<a id="event-112"></a>

112. **丁鸿讲《尚书》并上奏。** 丁鸿曾欲让爵给弟，后来以经义应对，参与白虎观议论。任司徒时借日食上封事，主张渐收外戚之权。 [[112]](#note-112)

<a id="event-113"></a>

113. **张宗、法雄与滕抚。** 张宗新末聚众后归汉，能在险地全军。法雄善治盗与地方抚纳，附子法真。滕抚任郡县后统兵平江淮诸部。 [[113]](#note-113)

<a id="event-114"></a>

114. **冯绲平荆州及受争议。** 冯绲任车骑将军，出讨荆州叛军。因军费及公私纠葛受弹劾，朝廷议其功罪；前段也写父冯焕遭买通使者陷害。 [[114]](#note-114)

<a id="event-115"></a>

115. **度尚与杨琁。** 度尚早年依附侯览，后任荆州刺史平乱，故意以焚掠所得解除兵士顾虑，亦曾被同僚奏劾。杨琁治地方急变，后附史论。 [[115]](#note-115)

<a id="event-116"></a>

116. **序论毛义与薛包。** 篇首辨孝的本末，毛义意在奉养亲长，薛包被逐仍执子职，各以至诚感人。 [[116]](#note-116)

<a id="event-117"></a>

117. **刘平、赵孝与淳于恭。** 刘平冒险救兄女、奉母，后来治郡；附王望和王扶。赵孝以身代弟，淳于恭缓急顾人、以恩服众，亦皆有仕履。 [[117]](#note-117)

<a id="event-118"></a>

118. **江革负母避乱。** 江革兵乱中背母播迁，以佣作供养，后虽受贵人礼敬仍不取私馈。章帝以其孝行厚礼存问。 [[118]](#note-118)

<a id="event-119"></a>

119. **刘般、刘恺论礼。** 刘般奉养亲属，论王侯制度。其子刘恺让爵、入朝为三公，主张长吏与牧守得居父母丧，又拒为犯法者解免。 [[119]](#note-119)

<a id="event-120"></a>

120. **周磐、赵咨与篇末赞。** 周磐就官为养，后弃官授徒，临终以礼约束子孙。赵咨事亲修己，治郡退让，临终从简办理丧事。 [[120]](#note-120)

<a id="event-121"></a>

121. **班彪择主与修前史。** 班彪避乱依隗嚣，作《王命论》劝其归汉，继而为窦融谋策。后续《史记》旧事成《后传》，传并载史学评述和东宫用人奏议。 [[121]](#note-121)

<a id="event-122"></a>

122. **班固入兰台修史与《西都赋》。** 班固受人告发私改国史，弟班超上书申解，明帝命班固入校书部，终成《汉书》。传录其向东平王刘苍推荐人才的奏记及铺陈长安形胜、宫室的《西都赋》。 [[122]](#note-122)

<a id="event-123"></a>

123. **班固《东都赋》《典引》与晚年。** 续录班固代表文章和史论，关涉汉家疆域、京师典礼与文士进退；窦宪败后班固被捕死狱中，末列班固仍传于世的四十一篇著述。 [[123]](#note-123)

<a id="event-124"></a>

124. **史论衡班固父子。** 结卷论班氏才学，兼及班固修《汉书》之功、为人持守及身后遭遇。 [[124]](#note-124)

<a id="event-125"></a>

125. **第五伦从亭长到司空。** 第五伦新末率乡里自保，入东汉历郡县，治蜀汉与京畿以清议见称。为三公后奏劾权贵，并自省偏私之心。 [[125]](#note-125)

<a id="event-126"></a>

126. **钟离意理狱并谏营宫。** 钟离意待罪吏与徒囚以诚信，任尚书时拒私分珍货，因旱象奏请缓刑、停营宫室，离京后治理鲁国。 [[126]](#note-126)

<a id="event-127"></a>

127. **宋均以宽简治郡。** 宋均任官主张去苛察，招降蛮部，撤除九江虎阱；传并存虎离境的旧说，附族人宋意事。 [[127]](#note-127)

<a id="event-128"></a>

128. **寒朗覆楚狱。** 寒朗作为谒者参与审理楚王英案，指出无证牵连及大臣噤声，明帝听后释放一批被囚者。末附其后仕历。 [[128]](#note-128)

<a id="event-129"></a>

129. **东海恭王刘彊及嗣王。** 郭后被废后，太子刘彊请求出居藩国，遂封东海王。明帝优礼其疾丧，以下各记后王袭爵、进献军费与魏初改封。 [[129]](#note-129)

<a id="event-130"></a>

130. **沛献王刘辅。** 刘辅由右翊公徙封中山、沛，曾牵涉更始子刘鲤复仇，后来著经说，其后王爵绵延至魏。 [[130]](#note-130)

<a id="event-131"></a>

131. **楚王刘英与楚狱。** 刘英好游侠、黄老及浮屠斋戒，因讖书案废徙丹阳后自杀，朝廷随后处置其妻子、母族与诸子爵位。 [[131]](#note-131)

<a id="event-132"></a>

132. **济南安王刘康。** 刘康封济南王，曾因越制受责，仍以宗室长辈获礼。下列国统数绝数续与再封情况。 [[132]](#note-132)

<a id="event-133"></a>

133. **东平宪王刘苍论礼与辞兵。** 刘苍为明帝所重，参定郊礼、服制、庙乐，谏止春日校猎，后辞将军归藩。传录诏答、来往音问以及丧葬赐礼。 [[133]](#note-133)

<a id="event-134"></a>

134. **任城孝王刘尚及其子孙。** 刘苍之子刘尚另封任城，以下记刘安、刘崇等袭爵及国祀再续的经过。 [[134]](#note-134)

<a id="event-135"></a>

135. **阜陵质王刘延与广陵思王刘荆。** 刘延几度因违法而削徙，朝廷屡念骨肉从宽。刘荆先伪造书信，后涉巫祷案自杀，后嗣复封。 [[135]](#note-135)

<a id="event-136"></a>

136. **刘衡、刘焉、刘京及其后嗣。** 刘衡早卒无嗣。刘焉徙封中山，刘京就琅邪国，篇中记诏责、归藩和子孙分封等事。 [[136]](#note-136)

<a id="event-137"></a>

137. **光武诸王史评。** 结尾总论光武诸王身居宗亲封国时的不同表现。 [[137]](#note-137)

<a id="event-138"></a>

138. **朱晖不私与直言。** 朱晖自少守节，入仕后不徇广陵王等权势，独以资财周济旧交家属，居官屡因言事去留。 [[138]](#note-138)

<a id="event-139"></a>

139. **朱穆诛暴与论宫中用人。** 朱穆治冀州捕治豪猾，与中官势力相冲突。学生刘陶等上书营救，朱穆后再入朝，仍批评近侍侵政，传存遗文与身后议谥。 [[139]](#note-139)

<a id="event-140"></a>

140. **乐恢劝收外戚权力。** 乐恢早以事父著名，仕郡与入京后守法严整。窦氏专政，他进言不纳，归乡后受逼迫而死。 [[140]](#note-140)

<a id="event-141"></a>

141. **何敞谏窦氏与宽治汝南。** 何敞追论刘畅遇害、征匈奴耗费和窦氏起宅等事，因忤外戚出任济南，后治汝南举冤狱。窦氏败后亦受子交游牵连。 [[141]](#note-141)

<a id="event-142"></a>

142. **邓彪与张禹。** 邓彪让爵并为朝廷倚用，窦氏用其居上位。张禹任地方官治水灌溉，入为公卿后多次参与朝议和摄政之事。 [[142]](#note-142)

<a id="event-143"></a>

143. **徐防论太学试法。** 徐防承家学，建议考试据所习经章句，限制师说混杂，后历三公，终以灾异等事被策免。 [[143]](#note-143)

<a id="event-144"></a>

144. **张敏与《轻侮法》。** 张敏任尚书时驳议以受侮为由宽减报杀者的法例，强调既有制度与伦理立场，后历任三公。 [[144]](#note-144)

<a id="event-145"></a>

145. **胡广历事与参与继统。** 胡广早年经法雄所荐而显，历数朝任职。质帝遇害后参与议立，梁冀败后受牵连免为庶人。 [[145]](#note-145)

<a id="event-146"></a>

146. **胡广再入三公及《百官箴》。** 胡广复居上公，身后获礼。传记列其续补、编次《百官箴》，兼记时人对其处世评价及范晔的篇末评论。 [[146]](#note-146)

<a id="event-147"></a>

147. **袁安平楚狱与抗议北伐。** 袁安清理楚王英案牵连诸狱，任公卿后主张守对匈奴的信用。窦宪出征、另立单于及诸窦恣纵时，多次力争。 [[147]](#note-147)

<a id="event-148"></a>

148. **袁氏经学与数代分支。** 袁安之后，袁京、袁汤、袁逢、袁隗等凭家学和累代官位显贵，亦遭董卓屠杀；旁支袁敞因案自杀，袁闳及其弟袁忠等则另有退隐守节和举宦的记述。 [[148]](#note-148)

<a id="event-149"></a>

149. **张酺说经与历任公卿。** 张酺以经学教授皇太子，任郡守整饬豪强，历任三公。晚年和司隶校尉等论事不合，附后人行迹。 [[149]](#note-149)

<a id="event-150"></a>

150. **韩棱持法与判断用人。** 韩棱因家世经学入仕，在郡对劝进求名和违法办事有所裁抑；议赋校书者佩剑等事，以知人见称，附孙韩演。 [[150]](#note-150)

<a id="event-151"></a>

151. **周荣助袁安及后代。** 周荣受袁安信任，支持奏劾窦景、反对窦氏处置北单于。之后周兴、周景、周忠仕历相继，末录史评。 [[151]](#note-151)

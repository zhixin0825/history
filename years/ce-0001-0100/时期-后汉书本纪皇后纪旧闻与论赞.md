# 本纪与皇后纪：家世、制度和论赞

[本世纪目录](README.md) · [全部世纪](../README.md) · [《后汉书》分卷目录](../../sources/后汉书读本目录.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **家世、入长安学与舂陵举兵。** 刘秀出自西汉长沙定王一支，早孤，由叔父抚养，曾入长安研习《尚书》。新朝末年的灾荒与李通所传图谶促成举事。刘秀返舂陵与兄刘縯会合，军入棘阳后在小长安受挫。 [[1]](#note-1)

<a id="event-2"></a>

2. **治国作风与史家论赞。** 传文回顾光武战后收兵、进用文吏、勤于听政的方式。卷末把出生瑞兆、谶言和兴复汉室相连，包含史家评价与天命叙事。 [[2]](#note-2)

<a id="event-3"></a>

3. **明帝用法与范晔评价。** 本纪称明帝守建武成制、抑制外戚干政并谨慎授官。范晔既肯定法令明白，又保留钟离意、宋均对苛察的批评。 [[3]](#note-3)

<a id="event-4"></a>

4. **章帝晚期与史论。** 晚年巡行、颁恤民诏并应对西羌、通西域。章和二年去世。范晔着重写宽刑、孝奉太后、安抚宗室和崇尚儒礼。 [[4]](#note-4)

<a id="event-5"></a>

5. **和帝亲政后的东汉。** 政令涉及灾荒赈贷、边民安置、官吏选补、边境用兵和禁中礼学。和帝废阴后、立邓后，晚年新改元兴。论赞以永元前后的边境与户口状况衡量和帝政绩。 [[5]](#note-5)

<a id="event-6"></a>

6. **殇帝即位与邓太后临朝。** 刘隆出生百余日即被立帝。邓太后主持朝局，诏复禁锢者、减宫中开销、责地方隐瞒灾情。殇帝在延平元年夭折。 [[6]](#note-6)

<a id="event-7"></a>

7. **安帝出自清河王家，永初间边事与灾荒。** 邓太后与邓骘在殇帝死后迎刘祜即位。永初年间西羌用兵、郡县受灾，朝廷调兵并连发免租与赈济令。 [[7]](#note-7)

<a id="event-8"></a>

8. **邓太后卒、安帝亲政与废储。** 邓太后去世后安帝亲政，邓氏受处置。辽东和西域仍有战事，安帝又以谗言废太子保。安帝巡行途中崩，阎后改立北乡侯；史论追究政权易手和废储的后果。 [[8]](#note-8)

<a id="event-9"></a>

9. **顺帝阳嘉到建康。** 立梁氏为后，朝廷调整孝廉和官员选补、允许宦官养子承袭爵位，同时应对西羌、南匈奴和武陵等地的战事。顺帝崩后遗命从薄葬。 [[9]](#note-9)

<a id="event-10"></a>

10. **冲帝即位、梁太后临朝。** 刘炳幼年继位，由梁氏临朝，李固等参录尚书。扬州、九江有兵乱，冲帝改元不久病卒。 [[10]](#note-10)

<a id="event-11"></a>

11. **质帝登位及被杀。** 梁太后与梁冀选择年幼的刘缵。滕抚平定九江等地叛军，朝廷处理征敛与灾荒；梁冀在本初元年使质帝中毒而死，李固随即被免。 [[11]](#note-11)

<a id="event-12"></a>

12. **桓帝即位、梁氏主政与建和至永兴。** 刘志由蠡吾侯入承帝位，梁太后临朝。朝廷颁宽政、处理疫疠和边事。梁太后归政后去世，梁氏宗族仍长期掌权。 [[12]](#note-12)

<a id="event-13"></a>

13. **延熹后期、党锢与桓帝死。** 后期诏祠老子，军队续讨诸羌。朝廷追究李膺等交结，后在永康改元赦免党人。皇帝死后窦后临朝，卷末评价诛梁冀以后权力仍归近幸。 [[13]](#note-13)

<a id="event-14"></a>

14. **中平末的州牧、继立与禁中政变。** 凉州等处战事延续，朝廷改置州牧。灵帝崩，刘辩即位；何进被宦官杀，袁绍、袁术等攻宫，董卓随后入京废少帝。末附范晔对灵帝及宦官的评论。 [[14]](#note-14)

<a id="event-15"></a>

15. **魏公魏王、汉魏禅代及山阳公后事。** 曹操进魏公、魏王，死后曹丕继为魏王。献帝于220年逊位而为山阳公，234年去世后依汉制葬于禅陵；后代袭封与除国另有卷末纪年。 [[15]](#note-15)

<a id="event-16"></a>

16. **皇后纪序。** 范晔先述后宫名位的制度源流，以及皇太后掌权、左右王朝继立的情形。他用前代事迹引出东汉诸后的纪传。 [[16]](#note-16)

<a id="event-17"></a>

17. **郭圣通与郭氏。** 光武在真定纳郭圣通，即位后立为皇后，又立其子刘彊为太子；郭后后来被废，郭氏仍受优待。明帝与章帝对诸郭有恩，郭璜父子后来牵入窦宪案。 [[17]](#note-17)

<a id="event-18"></a>

18. **阴丽华与许美人。** 刘秀在宛娶阴丽华，复汉后立为贵人，郭后被废后始为皇后。明帝奉阴氏为太后。其间阴氏家属遭盗杀，卷内保留光武恤问的文字。 [[18]](#note-18)

<a id="event-19"></a>

19. **马皇后、贾贵人。** 马援之女入太子宫，后来抚养贾贵人所生刘炟。章帝即位后她反对以灾异为由封其诸舅，辞谢外家恩泽。贾贵人直到马太后亡故后才加礼遇。 [[19]](#note-19)

<a id="event-20"></a>

20. **窦后、梁贵人和宋贵人。** 窦后抚养梁贵人所生刘肇，章帝时宋氏与原太子刘庆失势。梁竦被构陷而诛；和帝后来尊所生梁氏，并处理窦氏旧事。 [[20]](#note-20)

<a id="event-21"></a>

21. **和帝阴后。** 阴氏因父族而贵，后以巫蛊案被废。邓氏继其后位，阴氏亲属的连坐与复归见原文。 [[21]](#note-21)

<a id="event-22"></a>

22. **邓绥临朝及其去世。** 邓绥由和帝贵人成为皇后，迎立殇帝与安帝。临朝期间录冤狱、节用、求贤及加强对外戚宾客的约束。卷末诏书叙掌政经过，史论兼评其施政与未归政。 [[22]](#note-22)

<a id="event-23"></a>

23. **阎皇后与顺帝复位。** 阎氏弟兄掌禁兵并参与废太子。安帝死后阎后迎立北乡侯，北乡侯死后孙程等迎立刘保，阎氏因此败亡。 [[23]](#note-23)

<a id="event-24"></a>

24. **梁妠临朝。** 梁妠为顺帝皇后，继立冲帝、质帝与桓帝期间维持朝政。归政、临终诏与外戚处置的时序见原文。 [[24]](#note-24)

<a id="event-25"></a>

25. **匽氏、梁女莹与邓猛女。** 匽氏因生桓帝被追尊；梁女莹曾恃姊兄权势而居正宫，邓猛女继立后随宠遇转移被废，亲族亦受牵连。 [[25]](#note-25)

<a id="event-26"></a>

26. **窦妙与董太后。** 窦后临朝择立灵帝，其父窦武失败后她退居南宫。董氏因生灵帝受尊号，参与宫廷事务；灵帝死后与何氏争权，家族迅速失势。 [[26]](#note-26)

<a id="event-27"></a>

27. **宋后、何后与灵帝后宫。** 宋后被构以祝诅，废后忧死。何氏因皇子辩即位而为皇太后，兄何进死于宦官，董卓再废少帝并杀何后。献帝生母王美人早年被害。 [[27]](#note-27)

<a id="event-28"></a>

28. **伏寿、曹节及史论。** 伏后去信父亲伏完，后来事泄被废杀。曹节继立，汉魏禅代时交出玺绶。范晔论东汉皇后追号与外戚，并作赞。 [[28]](#note-28)

<a id="event-29"></a>

29. **东汉公主及封爵次序。** 按诸帝列公主及其母族、婚配和公主封号。出生多不具年月，封邑改动与确年封授可参本纪及相应传记。 [[29]](#note-29)

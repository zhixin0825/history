# 哀帝平帝本纪的早年与班固论赞

[本世纪目录](README.md) · [全部世纪](../README.md)

这里按原卷保留表序、栏头、谱系和无法确系单一年度的材料。确年原句由各卷去向连接对应年份。


<a id="event-1"></a>

1. **刘欣出身、袭定陶及入朝。** 刘欣是元帝之孙、定陶恭王刘康与丁姬之子，三岁袭王，喜好文辞与法令。元延四年和成帝之弟中山王刘兴同入朝；刘欣依诸侯王朝见的规定，带了秩二千石的傅、相、中尉，能解释法令并诵解《诗》。刘兴只带了傅。文句续下行。袭王年见《诸侯王表》阳朔三年。 [[1]](#note-1)


<a id="event-2"></a>

2. **班固论赞哀帝。** 班固评刘欣少有文名，见成帝时权落外家，即位后频惩大臣，想效法武帝、宣帝而振皇权。班固又称他素不好声色，偶观卞射等武戏，即位已患痿痹，末年加剧，在位短促。 [[2]](#note-2)


<a id="event-3"></a>

3. **刘箕子袭中山与入继帝位。** 平帝刘箕子是元帝之孙、中山孝王刘兴与卫姬之子，三岁袭王，《诸侯王表》系绥和二年。元寿二年六月哀帝死，王政君夺董贤大司马印，董贤同日自杀，王莽接任掌尚书事务。七月遣王舜、左咸持节迎刘箕子；赵、傅两太后或皇后被降处别宫，傅晏、董恭等失官爵迁合浦。九月辛酉，刘箕子即皇帝位、谒高庙并大赦。 [[3]](#note-3)


<a id="event-4"></a>

4. **班固论赞王莽专政。** 班固说平帝时政令出自王莽，他用褒善表功抬高自己，诏文渲染远人归服、祥瑞齐集；天象灾异与民怨出现，文饰终于无法掩盖现实。 [[4]](#note-4)

# 公元101年｜永元十三年

[← 公元100年](../ce-0001-0100/ce-0100.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元102年 →](ce-0102.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **帝幸东观，览书林，阅篇籍，博选术蓺之士以充其官。** 十三年春正月丁丑，帝幸东观，览书林，阅篇籍，博选术蓺之士以充其官。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **任城王尚薨。** 二月，任城王尚去世。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

3. **赈边郡贫民，助象林民恢复农桑。** 赈贷张掖、居延、朔方、日南贫民及孤寡羸弱不能自存者。象林人失去农桑生业，朝廷给种粮，并赈下贫者谷食。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

4. **北宫盛馔门阁火。** 己亥，北宫盛馔门阁火。 [[4]](#hh-note-5)

<a id="hh-event-6"></a>

<a id="hh-event-7"></a>

5. **周鲔击破烧当羌，朝廷救恤荆州水灾。** 护羌校尉周鲔击破烧当羌。另有荆州积年雨水过节，和帝下诏救恤当地。 [[5]](#hh-note-6)

<a id="hh-event-8"></a>

6. **安息国遣使献师子及条枝大爵。** 冬十一月，安息国遣使献师子及条枝大爵。 [[6]](#hh-note-8)

<a id="hh-event-9"></a>

7. **诏曰“幽、幷、凉州户口率少”。** 丙辰，诏曰：『幽、幷、凉州户口率少，边役众剧，束修良吏，进仕路狭。抚接夷狄，以人为本。其令缘边郡口十万以上，岁举孝廉一人；不满十万，二岁举一人；五万以下，三岁举一人。』 [[7]](#hh-note-9)

<a id="hh-event-10"></a>

8. **鲜卑寇右北平，遂入渔阳，渔阳太守击破之。** 鲜卑寇右北平，遂入渔阳，渔阳太守将其击败。 [[8]](#hh-note-10)

<a id="hh-event-11"></a>

<a id="hh-event-12"></a>

9. **吕盖罢司徒，鲁恭接任。** 司徒吕盖罢免，光禄勋鲁恭任司徒。 [[9]](#hh-note-11)

<a id="hh-event-13"></a>

<a id="hh-event-16"></a>

10. **巫蛮许圣等因税起乱，进犯南郡。** 许圣等不满郡里收税不均，屯聚反叛，攻犯南郡。 [[10]](#hh-note-13)

<a id="hh-event-14"></a>

11. **轩辕第四星间有小客星，色青黄。** 十三年十一月乙丑，轩辕第四星间有小客星，色青黄。 [[11]](#hh-note-14)

<a id="hh-event-15"></a>

12. **卒，时年七十二。** 永元十三年，卒，时年七十二。 [[12]](#hh-note-15)

<a id="sy-event-17"></a>

13. **贾逵去世。** 贾逵七十二岁去世，朝廷为其去世惋惜，任其二子为太子舍人。 [[13]](#sy-note-17)

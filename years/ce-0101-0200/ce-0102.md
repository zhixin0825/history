# 公元102年｜永元十四年

[← 公元101年](ce-0101.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元103年 →](ce-0103.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **东海王政薨。** 十四年春二月乙卯，东海王政去世。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **缮修故西海郡，徙金城西部都尉以戍之。** [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **临辟雍，飨射，大赦天下。** 三月戊辰，临辟雍，飨射，颁布大赦。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **遣使者督荆州兵讨巫蛮，破降之。** 夏四月，派使者督荆州兵讨巫蛮，破降服。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **赈贷张掖、居延、敦煌、五原、汉阳、会稽流民下贫谷，各有差。** 庚辰，赈贷张掖、居延、敦煌、五原、汉阳、会稽流民下贫谷，各有差。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **初置象林将兵长史官。** 五月丁未，初置象林将兵长史官。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **废皇后阴氏，後父特进纲自杀。** 六月辛卯，废皇后阴氏，后父特进纲自杀。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **诏复象林县更赋、田租、刍稾二岁。** 秋七月甲寅，诏复象林县更赋、田租、刍稾二岁。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **常山王侧薨。** 壬子，常山王侧去世。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **是秋，三州雨水。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **诏“兖、豫、荆州今年水雨淫过”。** 冬十月甲申，诏：『兖、豫、荆州今年水雨淫过，多伤农功。其令被害什四以上皆半入田租、刍稾；其不满者，以实除之。』 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **立贵人邓氏为皇后。** 辛卯，立贵人邓氏为皇后。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **司空巢堪罢。** 丁酉，司空巢堪罢。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **大司农徐防为司空。** 十一月癸卯，大司农徐防为司空。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **是岁，初复郡国上计补郎官。** 当年，初复郡国上计补郎官。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **班超归洛阳并去世。** 班超八月还京、拜射声校尉，九月病故。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **郑众受封鄛乡侯。** 和帝追念其功，封郑众为鄛乡侯。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **阴皇后巫蛊事发，乾从兄奉以後舅被诛，乾从坐，国除。** 永元十四年，阴皇后巫蛊事发，乾从兄奉以后舅被诛，乾从坐，国除。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **封母弟福为桃乡侯。** 永元十四年，封母弟福为桃乡侯。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **待诏太史霍融上言。** 永元十四年，待诏太史霍融上言：「官漏刻率九日增减一刻，不与天相应，或时差至二刻半，不如夏历密。」 [[20]](#hh-note-20)

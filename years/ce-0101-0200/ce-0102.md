[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **东海王政薨。** 十四年春二月乙卯，东海王政去世。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **缮修故西海郡，徙金城西部都尉以戍之。** [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **临辟雍，飨射，大赦天下。** 三月戊辰，临辟雍，飨射，颁布大赦。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **遣使者督荆州兵讨巫蛮，破降之。** 夏四月，派使者督荆州兵讨巫蛮，破降服。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **赈贷张掖、居延、敦煌、五原、汉阳、会稽流民下贫谷，各有差。** 庚辰，赈贷张掖、居延、敦煌、五原、汉阳、会稽流民下贫谷，各有差。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

<a id="hh-event-8"></a>

6. **象林置将兵长史，免两年租赋。** 朝廷始置象林将兵长史，又免象林县两年更赋、田租和刍稾。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

<a id="hh-event-12"></a>

<a id="hh-event-18"></a>

7. **阴氏因巫蛊被废，邓贵人立为皇后。** 六月辛卯，废阴皇后，后父阴纲自杀。后舅阴奉被诛，阴乾连坐，侯国撤销。朝廷另在辛卯日立邓贵人为皇后。 [[7]](#hh-note-7)

<a id="hh-event-9"></a>

8. **常山王侧薨。** 壬子，常山王侧去世。 [[8]](#hh-note-9)

<a id="hh-event-10"></a>

<a id="hh-event-11"></a>

9. **兖、豫、荆州雨水，和帝下诏。** 秋，兖、豫、荆三州雨水过多，和帝下诏应对。 [[9]](#hh-note-10)

<a id="hh-event-13"></a>

<a id="hh-event-14"></a>

10. **巢堪罢司空，徐防继任。** 司空巢堪罢免，大司农徐防任司空。 [[10]](#hh-note-13)

<a id="hh-event-15"></a>

11. **是岁，初复郡国上计补郎官。** 当年，初复郡国上计补郎官。 [[11]](#hh-note-15)

<a id="hh-event-16"></a>

<a id="sy-event-22"></a>

12. **班超还洛阳后去世，任尚接西域都护。** 朝廷征还班超，任戊己校尉任尚为西域都护。交接时，班超劝任尚简政宽小过。八月班超到洛阳，任射声校尉，九月病死。 [[12]](#hh-note-16)

<a id="hh-event-17"></a>

13. **郑众受封鄛乡侯。** 和帝追念其功，封郑众为鄛乡侯。 [[13]](#hh-note-17)

<a id="hh-event-19"></a>

14. **封母弟福为桃乡侯。** 永元十四年，封母弟福为桃乡侯。 [[14]](#hh-note-19)

<a id="hh-event-20"></a>

15. **待诏太史霍融上言。** 永元十四年，待诏太史霍融上言：「官漏刻率九日增减一刻，不与天相应，或时差至二刻半，不如夏历密。」 [[15]](#hh-note-20)

<a id="sy-event-21"></a>

16. **尚书冯豹任上去世。** 冯豹自武威太守被征入为尚书，永元十四年死于任上。 [[16]](#sy-note-21)

### 15. 待诏太史霍融上言

[返回正文第15条](#hh-event-20)

<a id="hh092-l6832-e20"></a>

**[《后汉书·律历志中》](../../sources/摘录/后汉书-卷092-律历志中.md#p002)** · [仓内TXT L6832](../../sources/本地分卷/后汉书/后汉书-卷092.md#L6832)

> 永元十四年，待詔太史霍融上言：「官漏刻率九日增減一刻，不與天相應，或時差至二刻半，不如夏歷密。」

**归年与互校** 本志原载年号。志文的占验解释见原卷上下文。

<a id="sy-hh092-l6832-e20"></a>

**[《后汉书·律历志中》](../../sources/摘录/后汉书-卷092-律历志中.md#p002)** · [仓内TXT L6832](../../sources/本地分卷/后汉书/后汉书-卷092.md#L6832)

> 詔書下太常，令史官與融以儀校天，課度遠近。

**本段所记** 霍融奏称旧漏刻同实测相差太远，朝廷命太常组织史官与霍融对照仪器校验。

**归年与互校** 《律历志》永元十四年同一奏议的下文。

<a id="sy-hh092-l6833-e20"></a>

**[《后汉书·律历志中》](../../sources/摘录/后汉书-卷092-律历志中.md#p002)** · [仓内TXT L6833](../../sources/本地分卷/后汉书/后汉书-卷092.md#L6833)

> 太史令舒、承、梵等對：「案官所施漏法令甲第六常符漏品，孝宣皇帝三年十二月乙酉下，建武十年二月壬午詔書施行。漏刻以日長短為數，率日南北二度四分而增減一刻。一氣俱十五日，日去極各有多少。今官漏率九日移一刻，不隨日進退。夏歷漏隨日南北為長短，密近於官漏，分明可施行。」其年十一月甲寅，詔曰：「告司徒、司空：漏所以節時分，定□明。

**本段所记** 太史令舒等提交比较结果，认为夏历漏法更贴近观测；和帝十一月甲寅下诏。

**归年与互校** 原文“其年”承永元十四年。建武十年诏旧漏法为奏议追述。

<a id="sy-hh092-l6834-e20"></a>

**[《后汉书·律历志中》](../../sources/摘录/后汉书-卷092-律历志中.md#p002)** · [仓内TXT L6834](../../sources/本地分卷/后汉书/后汉书-卷092.md#L6834)

> □明長短，起於日去極遠近，日道周，不可以計率分，當據儀度，下參晷景。今官漏以計率分□明，九日增減一刻，違失其實，至為疏數以耦法。太史待詔霍融上言，不與天相應。太常史官運儀下水，官漏失天者至三刻。以晷景為刻，少所違失，密近有驗。今下晷景漏刻四十八箭，立成斧官府當用者，計吏到，班予四十八箭。」

**本段所记** 诏书说明旧法误差可达三刻，敕颁按日影验得的漏刻四十八箭。保存仓内原文缺字。

**归年与互校** 衔接上一行永元十四年十一月甲寅诏。

1. **赈济贫民并供粮助流民返乡。** 闰月乙未，诏欲返乡而缺粮的流民，所过地方须实给口粮，生病者加给医药。又赈贷颍川、汝南、陈留、江夏、梁国、敦煌贫民，令鳏寡者可于陂池渔采，两年免其假税。 [[1]](#hh-note-1)

<a id="hh-event-3"></a>

2. **日有食之。** 夏四月甲子晦，发生日食。 [[2]](#hh-note-3)

<a id="hh-event-4"></a>

3. **南阳大风。** 五月戊寅，南阳大风。 [[3]](#hh-note-4)

<a id="hh-event-6"></a>

4. **济南王错薨。** 秋七月丙寅，济南王错去世。 [[4]](#hh-note-6)

<a id="hh-event-7"></a>

5. **复置涿郡故安铁官。** [[5]](#hh-note-7)

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

<a id="hh-event-11"></a>

<a id="hh-event-12"></a>

<a id="hh-event-14"></a>

<a id="hh-event-20"></a>

6. **和帝南巡章陵与云梦，擢任郡功曹。** 和帝南巡，清河王刘庆、济北王刘寿、河间王刘开随行。沿途按等赐郡守、长吏、三老、官属和百岁老人钱布。到章陵祭旧宅、园庙，会宗亲，劳赐作乐。南阳郡功曹被召见后拜郎中，随驾还宫，特补尚书郎。和帝又至云梦，临汉水而返，回宫赐从臣及留守百官钱布。 [[6]](#hh-note-8)

<a id="hh-event-10"></a>

7. **是秋，四州雨水。** [[7]](#hh-note-10)

<a id="hh-event-15"></a>

8. **琅邪王宇薨。** 十二月庚子，琅邪王宇去世。 [[8]](#hh-note-15)

<a id="hh-event-16"></a>

<a id="hh-event-17"></a>

9. **议夏至审决较轻案件。** 有司称夏至微阴初起，建议可决轻案。本年始令郡国于夏至审理薄刑。 [[9]](#hh-note-16)

<a id="hh-event-18"></a>

10. **王涣任洛阳令。** 王涣从南巡回来，受任洛阳令，擅决久积的疑狱。 [[10]](#hh-note-18)

<a id="hh-event-19"></a>

11. **隆卒，无子，国除。** 永元十五年，隆卒，无子，国除。 [[11]](#hh-note-19)

<a id="sy-event-21"></a>

12. **诏造太史黄道铜仪。** 和帝命造黄道铜仪，并确定各宿度数。铜仪帮助校验日月行度和弦望，不过仪器随黄道与度数转动，使用较难。 [[12]](#sy-note-21)

### 12. 诏造太史黄道铜仪

[返回正文第12条](#sy-event-21)

<a id="sy-hh092-l6829-e21"></a>

**[《后汉书·律历志中》](../../拆分史书/后汉书/卷092.md#p001)** · [仓内TXT L6829](../../拆分史书/后汉书/卷092.md#part-1-L6829)

> 至十五年七月甲辰，詔書造太史黃道銅儀，以角為十三度，亢十，氐十六，房五，心五，尾十八，箕十，斗二十四四分度之一，牽牛七，須女十一，虛十，危十六，營室十八，東壁十，奎十七，婁十二，胃十五，昴十二，畢十六，觜三，參八，東井三十，輿鬼四，柳十四，星七，張十七，翼十九，軫十八，凡三百六十五度四分度之一。冬至日在斗十九度四分度之一。史官以日月行，參弦望，雖密近而不為注日。儀，黃道與度轉運，難以候，是以少循其事。

**归年与互校** 《律历志》“十五年”承永元，且给出七月甲辰。

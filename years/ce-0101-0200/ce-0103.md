# 公元103年｜永元十五年

[← 公元102年](ce-0102.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元104年 →](ce-0104.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **闰月乙未，诏流民欲还归本而无粮食者，过所实禀之，疾病加致医药。** 十五年春，闰月乙未，诏流民欲还归本而无粮食者，过所实禀之，疾病加致医药；其不欲还归者，勿强。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏禀贷颍川、汝南、陈留、江夏、梁国、敦煌贫民。** 二月，诏禀贷颍川、汝南、陈留、江夏、梁国、敦煌贫民。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **日有食之。** 夏四月甲子晦，发生日食。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **南阳大风。** 五月戊寅，南阳大风。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **诏令百姓鳏、寡渔采陂池，勿收假税二岁。** 六月，诏令百姓鳏、寡渔采陂池，勿收假税二岁。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **济南王错薨。** 秋七月丙寅，济南王错去世。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **复置涿郡故安铁官。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **南巡狩，清河王庆、济北王寿、河间王开并从。** 九月壬午，南巡狩，清河王庆、济北王寿、河间王开并从。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **赐所过二千石长吏以下、三老、官属及民百年者钱、布，各有差。** [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **是秋，四州雨水。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **幸章陵，祠旧宅。** 冬十月戊申，幸章陵，祠旧宅。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **祠园庙，会宗室於旧庐，劳赐作乐。** 癸丑，祠园庙，会宗室于旧庐，劳赐作乐。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **进幸云梦，临汉水而还。** 戊午，进幸云梦，临汉水而还。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **车驾还宫，赐从臣及留者公卿以下钱、布，各有差。** 十一月甲申，皇帝回宫，赐从臣及留者公卿以下钱、布，各有差。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **琅邪王宇薨。** 十二月庚子，琅邪王宇去世。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **有司奏，以为夏至则微阴起，靡草死，可以决小事。** [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **是岁，初令郡国以日北至案薄刑。** 当年，初命各郡国以日北至案薄刑。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **王涣任洛阳令。** 王涣从南巡回来，受任洛阳令，擅决久积的疑狱。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **隆卒，无子，国除。** 永元十五年，隆卒，无子，国除。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **和帝幸南阳，准为郡功曹，召见，帝器之，拜郎中，从车驾还宫，特补尚书郎。** 永元十五年，和帝幸南阳，准为郡功曹，召见，帝器之，拜郎中，从皇帝回宫，特补尚书郎。 [[20]](#hh-note-20)

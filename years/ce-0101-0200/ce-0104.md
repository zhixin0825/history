# 公元104年｜永元十六年

[← 公元103年](ce-0103.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元105年 →](ce-0105.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **诏贫民有田业而以匮乏不能自农者，贷种粮。** 十六年春正月己卯，诏贫民有田业而以匮乏不能自农者，贷种粮。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏兖、豫、徐、冀四州比年雨多伤稼，禁沽酒。** 二月己未，诏兖、豫、徐、冀四州比年雨多伤稼，禁沽酒。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **遣三府掾分行四州，贫民无以耕者，为雇犁牛直。** 夏四月，遣三府掾分行四州，贫民无以耕者，为雇犁牛直。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **赵王商薨。** 五月壬午，赵王商去世。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **旱。** 秋七月，旱。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **诏曰“今秋稼方穗而旱”。** 戊午，诏曰：『今秋稼方穗而旱，云雨不沾，疑吏行惨刻，不宣恩泽，妄拘无罪，幽闭良善所致。其一切囚徒于法疑者勿决，以奉秋令。方察烦苛之吏，显明其罚。』 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **司徒鲁恭免。** 辛酉，司徒鲁恭免。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **光禄勳张酺为司徒。** 庚午，光禄勳张酺为司徒。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **诏令天下皆半入今年田租、刍稾。** 辛巳，诏令天下皆半入今年田租、刍稾；其被灾害者，以实除之。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **贫民受贷种粮及田租、刍稾，皆勿收责。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **司徒张酺薨。** 八月己酉，司徒张酺去世。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **司空徐防为司徒，大鸿胪陈宠为司空。** 冬十月辛卯，司空徐防为司徒，大鸿胪陈宠为司空。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **行幸缑氏，登百岯山，赐百官从臣布，各有差。** 十一月己丑，行幸缑氏，登百岯山，赐百官从臣布，各有差。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **北匈奴遣使称臣贡献。** [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **复置辽东西部都尉官。** 十二月，复置辽东西部都尉官。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **梁王刘坚弟二人分封。** 梁国宗室中刘坚两弟封乡侯、亭侯。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **紫宫中生白气，如粉絮。** 《天文志》记十六年四月丁未，紫宫中生白气，如粉絮。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **客星出紫宫西行至昴，五月壬申灭。** 《天文志》记戊午，客星出紫宫西行至昴，五月壬申灭。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **水在舆鬼中。** 《天文志》记七月庚午，水在舆鬼中。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **流星起鈎陈，北行三丈，有光，色黄。** 《天文志》记十月辛亥，流星起鈎陈，北行三丈，有光，色黄。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **徵拜将作大匠。** 永元十六年，徵拜将作大匠。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **封肃弟二十一人皆为列侯。** 永元十六年，封肃弟二十一人皆为列侯。 [[22]](#hh-note-22)

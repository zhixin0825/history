1. **四州雨灾后助耕，秋旱减免租税。** 命各地贷种粮给有田而无资自耕的贫民。兖、豫、徐、冀连年雨多伤稼，诏禁沽酒，又遣三府掾巡行，替贫民雇犁牛。秋季作物吐穗时遭旱，和帝下诏只收本年一半田租、刍稾，贫民先前所贷种粮和田租、刍稾免催征。 [[1]](#hh-note-1)

<a id="hh-event-4"></a>

2. **赵王商薨。** 五月壬午，赵王商去世。 [[2]](#hh-note-4)

<a id="hh-event-7"></a>

<a id="hh-event-8"></a>

<a id="hh-event-11"></a>

<a id="hh-event-12"></a>

3. **鲁恭罢免，张酺、徐防递任司徒。** 司徒鲁恭免职，光禄勋张酺继任。张酺本年去世，司空徐防改任司徒，大鸿胪陈宠继为司空。 [[3]](#hh-note-7)

<a id="hh-event-13"></a>

4. **行幸缑氏，登百岯山，赐百官从臣布，各有差。** 十一月己丑，行幸缑氏，登百岯山，赐百官从臣布，各有差。 [[4]](#hh-note-13)

<a id="hh-event-14"></a>

5. **北匈奴遣使称臣贡献。** [[5]](#hh-note-14)

<a id="hh-event-15"></a>

6. **复置辽东西部都尉官。** 十二月，复置辽东西部都尉官。 [[6]](#hh-note-15)

<a id="hh-event-16"></a>

7. **梁王刘坚弟二人分封。** 梁国宗室中刘坚两弟封乡侯、亭侯。 [[7]](#hh-note-16)

<a id="hh-event-17"></a>

8. **紫宫中生白气，如粉絮。** 十六年四月丁未，紫宫中生白气，如粉絮。 [[8]](#hh-note-17)

<a id="hh-event-18"></a>

9. **客星出紫宫西行至昴，五月壬申灭。** 戊午，客星出紫宫西行至昴，五月壬申灭。 [[9]](#hh-note-18)

<a id="hh-event-19"></a>

10. **水在舆鬼中。** 七月庚午，水在舆鬼中。 [[10]](#hh-note-19)

<a id="hh-event-20"></a>

11. **流星起鈎陈，北行三丈，有光，色黄。** 十月辛亥，流星起鈎陈，北行三丈，有光，色黄。 [[11]](#hh-note-20)

<a id="hh-event-21"></a>

12. **徵拜将作大匠。** 永元十六年，徵拜将作大匠。 [[12]](#hh-note-21)

<a id="hh-event-22"></a>

13. **封肃弟二十一人皆为列侯。** 永元十六年，封肃弟二十一人皆为列侯。 [[13]](#hh-note-22)

<a id="sy-event-23"></a>

14. **分海昏置建昌县。** 豫章郡析海昏县设置建昌县。 [[14]](#sy-note-23)

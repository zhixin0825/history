# 公元105年｜元兴元年

[← 公元104年](ce-0104.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元106年 →](ce-0106.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **引三署郎召见禁中，选除七十五人，补谒者、长、相。** 元兴元年春正月戊午，引三署郎召见禁中，选除七十五人，补谒者、长、相。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **高句骊寇郡界。** [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **大赦天下，改元元兴。** 夏四月庚午，颁布大赦，改元元兴。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **宗室以罪绝者，悉复属籍。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **雍地裂。** 五月癸酉，雍地裂。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **辽东太守耿夔击貊人，破之。** 秋九月，辽东太守耿夔击貊人，破之。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **和帝崩，立皇子隆。** 冬十二月辛未，皇帝在章德前殿去世，年二十七。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **立皇子隆为皇太子。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **赐天下男子爵，人二级，三老、孝悌、力田人三级，民无名数及流民欲占者人一级。** 赐天下男子爵，人二级，三老、孝悌、力田人三级，民无名数及流民欲占者人一级；鳏、寡、孤、独、笃癃、贫不能自存者粟，人三斛。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **殇帝即位，邓太后临朝。** 孝殇皇帝讳隆，和帝少子也。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **夜，即皇帝位，时诞育百余日。** 元兴元年十二月辛未，夜，即皇帝位，时诞育百余日。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **尊皇后曰皇太后，太后临朝。** [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **北匈奴遣使称臣，诣敦煌奉献。** 北匈奴遣使称臣，到敦煌奉献。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **何敞因蔡伦奏报诈病获罪。** 何敞微疾未赴祠庙斋戒，后来又参加百官会议，蔡伦据此奏其诈病。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **王涣任上去世。** 洛阳令王涣病卒，百姓相率设奠悼念。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **蔡伦奏上制纸方法。** 蔡伦改用树皮、麻头、破布和旧鱼网制纸，上奏后得到和帝认可。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **耿夔击退高句骊。** 高句骊进兵辽东六县，太守耿夔击退其军。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **有流星起角、亢五丈所。** 《天文志》记元兴元年二月庚辰，有流星起角、亢五丈所。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **有流星起斗，东北行到须女。** 《天文志》记四月辛亥，有流星起斗，东北行到须女。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **有流星起天市五丈所，光色赤。** 《天文志》记七月己巳，有流星起天市五丈所，光色赤。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **水、金会爲兵诛。** 《天文志》记水、金会爲兵诛。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **帝崩，长子平原王有疾，而诸皇子夭没，前後十数，後生者辄隐秘养於人间。** 元兴元年，帝崩，长子平原王有疾，而诸皇子夭没，前后十数，后生者辄隐秘养于人间。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **和帝复封乾本国，拜侍中。** 元兴元年，和帝复封乾本国，拜侍中。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **和帝以训皇后之父，使谒者持节至训墓，赐策追封，谥曰平寿敬侯。** 元兴元年，和帝以训皇后之父，使谒者持节至训墓，赐策追封，谥曰平寿敬侯。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **貊人寇郡界，夔追击，斩其渠帅。** 元兴元年，貊人寇郡界，夔追击，斩其渠帅。 [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **封正弟二人为县侯。** 元兴元年，封正弟二人为县侯。 [[26]](#hh-note-26)

<a id="hh-event-27"></a>

27. **重遣使诣敦煌贡献，辞以国贫未能备礼，愿请大使，当遣子入侍。** 元兴元年，重遣使到敦煌贡献，辞以国贫未能备礼，愿请大使，当遣子入侍。 [[27]](#hh-note-27)

<a id="hh-event-28"></a>

28. **和帝元兴元年冬十一月壬午，郡国四冬雷。** [[28]](#hh-note-28)

<a id="hh-event-29"></a>

29. **右扶风雍地裂。** 元兴元年五月癸酉，右扶风雍地裂。 [[29]](#hh-note-29)

<a id="sy-event-30"></a>

30. **改天水为汉阳郡。** 天水郡由汉武帝设置，和帝永元十七年更名汉阳郡。 [[30]](#sy-note-30)

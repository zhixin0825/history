4. **禀司隶、兖、豫、徐、冀、幷州贫民。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **以广成游猎地及被灾郡国公田假与贫民。** 二月丙午，以广成游猎地及被灾郡国公田假与贫民。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **分清河国封帝弟常保为广川王。** 丁卯，分清河国封帝弟常保为广川王。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **司徒梁鲔薨。** 庚午，司徒梁鲔去世。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **日有食之，诏公卿内外众官、郡国守、相，举贤良方正、有道术之士，明政术、达古今、能直言极谏者…。** 三月癸酉，发生日食，诏公卿内外众官、郡国守、相，举贤良方正、有道术之士，明政术、达古今、能直言极谏者，各一人。 [[8]](#hh-note-8)

9. **永昌徼外僬侥种夷贡献内属。** 己卯，永昌徼外僬侥种夷贡献内属。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **葬清河孝王，赠龙旗、虎贲。** 甲申，葬清河孝王，赠龙旗、虎贲。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **长乐卫尉鲁恭为司徒。** 夏五月甲戌，长乐卫尉鲁恭为司徒。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **诏封北海王睦孙寿光侯普为北海王。** 丁丑，诏封北海王睦孙寿光侯普为北海王。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **九真徼外夜郎蛮夷举土内属。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **爵皇太后母阴氏为新野君。** 六月戊申，爵皇太后母阴氏为新野君。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **河东地陷。** 丁巳，河东地陷。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **罢西域都护。** 壬戌，罢西域都护。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **先零种羌叛，断陇道，大为寇掠，遣车骑将军邓骘、征西校尉任尚讨之。** [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **赦除诸羌相连结谋叛逆者罪。** 丁卯，赦除诸羌相连结谋叛逆者罪。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **诏三公明申旧令，禁奢侈，无作浮巧之物，殚财厚葬。** 秋九月庚午，诏三公明申旧令，禁奢侈，无作浮巧之物，殚财厚葬。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **是日，太尉徐防免。** [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **司空尹勤免。** 辛未，司空尹勤免。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **调杨州五郡租米，赡给东郡、济阴、陈留、梁国、下邳、山阳。** 癸酉，调杨州五郡租米，赡给东郡、济阴、陈留、梁国、下邳、山阳。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **诏曰“自今长吏被考竟未报”。** 丁丑，诏曰：『自今长吏被考竟未报，自非父母丧，无故辄去职者，剧县十岁、平县五岁以上，乃得次用。』 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **诏太仆、少府减黄门鼓吹，以补羽林士。** 壬午，诏太仆、少府减黄门鼓吹，以补羽林士；厩马非乘舆常所御者，皆减半食；诸所造作，非供宗庙园陵之用，皆且止。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **诏死罪以下及亡命赎，各有差。** 丙戌，诏死罪以下及亡命赎，各有差。 [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **太傅张禹为太尉，太常周章为司空。** 庚寅，太傅张禹为太尉，太常周章为司空。 [[26]](#hh-note-26)

<a id="hh-event-27"></a>

27. **倭国遣使奉献。** 冬十月，倭国派使者进献。 [[27]](#hh-note-27)

<a id="hh-event-28"></a>

28. **新城山泉水大出。** 辛酉，新城山泉水大出。 [[28]](#hh-note-28)

<a id="hh-event-29"></a>

29. **司空周章密谋废立，策免，自杀。** 十一月丁亥，司空周章密谋废立，策免，自杀。 [[29]](#hh-note-29)

<a id="hh-event-30"></a>

30. **勑司隶校尉、冀、幷二州刺史。** 戊子，勑司隶校尉、冀、幷二州刺史：『民讹言相惊，弃捐旧居，老弱相携，穷困道路。其各勑所部长吏，躬亲晓喻。若欲归本郡，在所为封长檄；不欲，勿强。』 [[30]](#hh-note-30)

<a id="hh-event-31"></a>

31. **颍川太守张敏为司空。** 十二月乙卯，颍川太守张敏为司空。 [[31]](#hh-note-31)

<a id="hh-event-32"></a>

32. **是岁，郡国十八地震。** 当年，郡国十八地震；四十一雨水，或山水暴至；二十八大风，雨雹。 [[32]](#hh-note-32)

<a id="hh-event-33"></a>

33. **陈勤因雨水伤稼免职。** 陈勤因雨水损害庄稼被免职，遣回封国。 [[33]](#hh-note-33)

<a id="hh-event-34"></a>

34. **庞参上书议先零羌乱和凉州民困。** 邓骘奉命西征，庞参在服罪中托子上书，指出征役加重凉州困苦。 [[34]](#hh-note-34)

<a id="hh-event-35"></a>

35. **分清河封刘常保，宋衍等受爵。** 刘虎威继清河国后，邓太后封常保为广川王，并授宋衍及刘庆子女封爵。 [[35]](#hh-note-35)

<a id="hh-event-36"></a>

36. **邓太后封申转为新亭侯。** 济北王刘寿的舅父申转获新亭侯。 [[36]](#hh-note-36)

<a id="hh-event-37"></a>

37. **杜根举孝廉、任郎中。** 杜根入仕，后来劝邓太后令安帝亲政而险死。 [[37]](#hh-note-37)

<a id="hh-event-38"></a>

38. **倭国王帅升等请见。** 帅升等送来百六十名生口，请求朝见。 [[38]](#hh-note-38)

<a id="hh-event-39"></a>

39. **降羌因征发反叛。** 王弘急征羌兵赴西域，降羌因惧远戍及久受侵役离散起事。 [[39]](#hh-note-39)

<a id="hh-event-40"></a>

40. **孝安永初元年五月戊寅，荧惑逆行，守心前星。** 孝安永初元年五月戊寅，荧惑逆行，守心前星。 [[40]](#hh-note-40)

<a id="hh-event-41"></a>

41. **客星在东井、弧星西南。** 八月戊申，客星在东井、弧星西南。 [[41]](#hh-note-41)

<a id="hh-event-42"></a>

42. **爵号太夫人为新野君，万户供汤沐邑。** 永初元年，爵号太夫人为新野君，万户供汤沐邑。 [[42]](#hh-note-42)

<a id="hh-event-43"></a>

43. **封骘上蔡侯、悝叶侯、弘西平侯、阊西华侯，食邑各万户。** 永初元年，封骘上蔡侯、悝叶侯、弘西平侯、阊西华侯，食邑各万户。 [[43]](#hh-note-43)

<a id="hh-event-44"></a>

44. **复代梁鲔为司徒。** 永初元年，复代梁鲔为司徒。 [[44]](#hh-note-44)

<a id="hh-event-45"></a>

45. **入授安帝，三迁爲侍中步兵校尉。** 永初元年，入授安帝，三迁爲侍中步兵校尉。 [[45]](#hh-note-45)

<a id="hh-event-46"></a>

46. **代周章为太常。** 永初元年，代周章为太常。 [[46]](#hh-note-46)

<a id="hh-event-47"></a>

47. **封寿弟八人为列侯。** 永初元年，封寿弟八人为列侯。 [[47]](#hh-note-47)

<a id="hh-event-48"></a>

48. **以定策功封安乡侯，食邑千二百户，与太尉徐防、司空尹勤同日俱封。** 永初元年，以定策功封安乡侯，食邑千二百户，与太尉徐防、司空尹勤同日俱封。 [[48]](#hh-note-48)

<a id="hh-event-49"></a>

49. **和熹皇后益封三百户。** 永初元年，和熹皇后益封三百户。 [[49]](#hh-note-49)

<a id="hh-event-50"></a>

50. **徼外焦侥种夷陆类等三千余口举种内附，献象牙、水牛、封牛。** 永初元年，徼外焦侥种夷陆类等三千余口举种内附，献象牙、水牛、封牛。 [[50]](#hh-note-50)

<a id="hh-event-51"></a>

51. **安帝永初元年，蜀郡三襄种夷与徼外污衍种幷兵三千余人反叛，攻蚕陵城，杀长吏。** [[51]](#hh-note-51)

<a id="hh-event-52"></a>

52. **安帝永初元年十一月，民讹言相惊，司隶、并、冀州民人流移。** [[52]](#hh-note-52)

<a id="hh-event-53"></a>

53. **安帝永初元年冬十月辛酉，河南新城山水虣出，突坏民田，坏处泉水出，深三丈。** [[53]](#hh-note-53)

<a id="hh-event-54"></a>

54. **安帝永初元年六月丁巳，河东杨地陷，东西百四十步，南北百二十步，深三丈五尺。** [[54]](#hh-note-54)

<a id="hh-event-55"></a>

55. **安帝永初元年，大风拔树。** [[55]](#hh-note-55)

<a id="hh-event-56"></a>

56. **安帝永初元年三月二日癸酉，日有蚀之，在胃二度。** 安帝永初元年三月二日癸酉，发生日食，在胃二度。 [[56]](#hh-note-56)

<a id="sy-event-57"></a>

57. **河南郡县火灾，死一百零五人。** 十二月，河南郡县发生火灾，死一百零五人。 [[57]](#sy-note-57)

1. **遣使赈贫并贷流民。** 赈济河南、下邳、东莱、河内贫民，遣光禄大夫樊准、吕仓巡冀、兖二州赈贷流民。又赈给济阴、山阳、玄菟，及东郡、钜鹿、广阳、安定、定襄、沛国贫民。 [[1]](#hh-note-1)

2. **滇零称天子，邓骘、任尚进讨受挫。** 车骑将军邓骘为羌兵败于冀西，征西校尉任尚在平襄与先零羌战败。十一月辛酉，朝廷拜邓骘大将军，调回京师，留任尚屯陇右。先零羌滇零称天子于北地，寇三辅，东侵赵、魏，南入益州，杀汉中太守董炳。 [[2]](#hh-note-2)

<a id="hh-event-4"></a>

3. **汉阳城中火，烧杀三千五百七十人。** 夏四月甲寅，汉阳城中火，烧杀三千五百七十人。 [[3]](#hh-note-4)

<a id="hh-event-5"></a>

<a id="hh-event-25"></a>

4. **京师旱，收葬城旁客死者。** 夏季旱，久祷无雨，官员收葬洛阳城傍客死骸骨一万余具。 [[4]](#hh-note-5)

<a id="hh-event-6"></a>

5. **皇太后幸洛阳寺及若庐狱。** 丙寅，皇太后幸洛阳寺及若庐狱，录囚徒，赐河南尹、廷尉、卿及官属以下各有差，即日降雨。 [[5]](#hh-note-6)

<a id="hh-event-7"></a>

6. **京师及郡国四十大水，大风，雨雹。** 六月，京师及郡国四十大水，大风，雨雹。 [[6]](#hh-note-7)

<a id="hh-event-8"></a>

7. **诏曰“昔在帝王”。** 秋七月戊辰，诏曰：『昔在帝王，承天理民，莫不据璇机玉衡，以齐七政。朕以不德，遵奉大业，而阴阳差越，变异并见，万民饥流，羌貊叛戾。夙夜克己，忧心京京。间令公卿郡国举贤良方正，远求博选，开不讳之路，冀得至谋，以鉴不逮，而所对皆循尚浮言，无卓尔异闻。其百僚及郡国吏人，有道术明习灾异阴阳之度璇机之数者，各使指变以闻。二千石长吏明以诏书，博衍幽隐，朕将亲览，待以不次，冀获嘉谋，以承天诫。』 [[7]](#hh-note-8)

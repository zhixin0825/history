# 公元109年｜永初三年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **皇帝加元服。** 三年春正月庚子，皇帝加元服。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **大赦天下。** 颁布大赦。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **赐王、主、贵人、公、卿以下金帛各有差。** 赐王、主、贵人、公、卿以下金帛各有差；男子为父后，及三老、考悌、力田爵，人二级，流民欲占者人一级。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **遣骑都尉任仁讨先零羌，不利，羌遂破没临洮。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **高句骊遣使贡献。** [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **京师大饥，民相食。** 三月，京师大饥，民相食。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **公卿诣阙谢。** 壬辰，公卿到阙谢。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **诏曰“朕以幼冲”。** 诏曰：『朕以幼冲，奉承鸿业，不能宣流风化，而感逆阴阳，至令百姓饥荒，更相噉食。永怀悼叹，若坠渊水。咎在朕躬，非群司之责，而过自贬引，重朝廷之不德。其务思变复，以助不逮。』 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **诏以鸿池假与贫民。** 癸巳，诏以鸿池假与贫民。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **司徒鲁恭免。** 壬寅，司徒鲁恭免。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **大鸿胪九江夏勤为司徒。** 夏四月丙寅，大鸿胪九江夏勤为司徒。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **三公以国用不足，奏令吏人入钱谷，得为关内侯、虎贲羽林郎、五大夫、官府吏、缇骑、营士各有差。** [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **诏上林、广成苑可垦辟者，赋与贫民。** 己巳，诏上林、广成苑可垦辟者，赋与贫民。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **清河王虎威薨。** 甲申，清河王虎威去世。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **封乐安王宠子延平为清河王。** 五月丙申，封乐安王宠子延平为清河王。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **沛王正薨。** 丁酉，沛王正去世。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **京师大风。** 癸丑，京师大风。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **乌桓寇代郡、上谷、涿郡。** 六月，乌桓寇代郡、上谷、涿郡。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **海贼张伯路等寇略缘海九郡，遣侍御史庞雄督州、郡兵讨破之。** 秋七月，海贼张伯路等寇略缘海九郡，遣侍御史庞雄督州、郡兵讨破之。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **诏长吏案行在所，皆令种宿麦蔬食，务尽地力，其贫者给种饷。** 庚子，诏长吏案行在所，皆令种宿麦蔬食，务尽地力，其贫者给种饷。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **鴈门乌桓及鲜卑叛，败五原郡兵於高渠谷。** 九月，鴈门乌桓及鲜卑叛，败五原郡兵于高渠谷。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **南单于叛，围中郎将耿种於美稷。** 冬十月，南单于叛，围中郎将耿种于美稷。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **遣行车骑将军何熙讨之。** 十一月，遣行车骑将军何熙讨之。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **郡国九地震。** 十二月辛酉，郡国九地震。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **有星孛於天苑。** 乙亥，有星孛于天苑。 [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **是岁，京师及郡国四十一雨水雹。** 当年，京师及郡国四十一雨水雹。 [[26]](#hh-note-26)

<a id="hh-event-27"></a>

27. **幷、凉二州大饥，人相食。** [[27]](#hh-note-27)

<a id="hh-event-28"></a>

28. **洛阳大水，杨厚答邓太后问。** 洛阳大水又见太白入斗，邓太后通过中常侍问杨厚，杨厚建议诸王子还国。 [[28]](#hh-note-28)

<a id="hh-event-29"></a>

29. **乌桓等攻代郡及五原。** 漁阳乌桓与右北平胡侵代郡、上谷，秋季数部又合攻五原。 [[29]](#hh-note-29)

<a id="hh-event-30"></a>

30. **太白入斗中。** 《天文志》记己亥，太白入斗中。 [[30]](#hh-note-30)

<a id="hh-event-31"></a>

31. **彗星起天菀南，东北指，长六七尺，色苍白。** 《天文志》记十二月，彗星起天菀南，东北指，长六七尺，色苍白。 [[31]](#hh-note-31)

<a id="hh-event-32"></a>

32. **迁射声校尉。** 永初三年，迁射声校尉。 [[32]](#hh-note-32)

<a id="hh-event-33"></a>

33. **南单于檀反畔，使夔率鲜卑及诸郡兵屯雁门，与车骑将军何熙共击之。** 永初三年，南单于檀反畔，使夔率鲜卑及诸郡兵屯雁门，与车骑将军何熙共击之。 [[33]](#hh-note-33)

<a id="hh-event-34"></a>

34. **吉卒，无子，国除。** 永初三年，吉卒，无子，国除。 [[34]](#hh-note-34)

<a id="hh-event-35"></a>

35. **海贼张伯路等三千余人，冠赤帻，服绦衣，自称。** 永初三年，海贼张伯路等三千余人，冠赤帻，服绦衣，自称「将军」，寇滨海九郡，杀二千石令长。 [[35]](#hh-note-35)

<a id="hh-event-36"></a>

36. **太尉张禹荐朗为博士，徵诣公车，会卒，时年八十四。** 永初三年，太尉张禹荐朗为博士，徵到公车，会卒，时年八十四。 [[36]](#hh-note-36)

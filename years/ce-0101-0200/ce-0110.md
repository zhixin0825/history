<a id="hh-event-1"></a>

1. **元日，会，彻乐，不陈充庭车。** 四年春正月，元日，会，彻乐，不陈充庭车。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏以三辅比遭寇乱，人庶流冗，除三年逋租、过更、口筭、刍稾。** 辛卯，诏以三辅比遭寇乱，人庶流冗，除三年逋租、过更、口筭、刍稾；禀上郡贫民各有差。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **海贼张伯路复与勃海。** 海贼张伯路复与勃海、平原剧贼刘文河、周文光等攻厌次，杀县令，遣御史中丞王宗督青州刺史法雄讨破之。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

<a id="hh-event-7"></a>

<a id="hh-event-11"></a>

4. **梁慬、耿夔讨南匈奴，南单于降。** 梁慬、耿夔在属国故城击破南单于。南匈奴又犯常山，三月南单于归降。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **诏减百官及州、郡、县奉各有差。** 丙午，诏减百官及州、郡、县奉各有差。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **禀九江贫民。** 二月丁巳，禀九江贫民。 [[6]](#hh-note-6)

<a id="hh-event-8"></a>

7. **初置长安、雍二营都尉官。** 乙丑，初置长安、雍二营都尉官。 [[7]](#hh-note-8)

<a id="hh-event-9"></a>

8. **诏自建初以来，诸祆言它过坐徙边者，各归本郡。** 乙亥，诏自建初以来，诸祆言它过坐徙边者，各归本郡；其没入官为奴婢者，免为庶人。 [[8]](#hh-note-9)

<a id="hh-event-10"></a>

9. **诏谒者刘珍及《五经》博士。** 诏谒者刘珍及《五经》博士，校定东观《五经》、诸子、传记、百家蓺术，整齐脱误，是正文字。 [[9]](#hh-note-10)

<a id="hh-event-12"></a>

<a id="hh-event-13"></a>

<a id="hh-event-19"></a>

<a id="hh-event-22"></a>

<a id="hh-event-23"></a>

10. **羌乱延及汉中，朝廷议弃守凉州。** 先零羌犯褒中，汉中太守郑勤战死。朝廷将金城郡治迁至襄武，骑都尉任仁下狱后死。羌胡战事军费日增，大将军邓骘议撤凉州，虞诩进言反对，邓骘本年罢职。 [[10]](#hh-note-12)

<a id="hh-event-14"></a>

11. **杜陵园火。** 戊子，杜陵园火。 [[11]](#hh-note-14)

<a id="hh-event-15"></a>

12. **郡国九地震。** 癸巳，郡国九地震。 [[12]](#hh-note-15)

<a id="hh-event-16"></a>

13. **六州蝗。** 夏四月，六州蝗。 [[13]](#hh-note-16)

<a id="hh-event-17"></a>

14. **大赦天下。** 丁丑，颁布大赦。 [[14]](#hh-note-17)

<a id="hh-event-18"></a>

15. **三郡大水。** 秋七月乙酉，三郡大水。 [[15]](#hh-note-18)

<a id="hh-event-20"></a>

16. **益州郡地震。** 九月甲申，益州郡地震。 [[16]](#hh-note-20)

<a id="hh-event-21"></a>

<a id="hh-event-26"></a>

17. **新野君阴氏去世，邓太后赦还阴氏亲属。** 新野君阴氏去世，使司空持节护丧。邓太后下诏赦阴氏被徙者返归故郡，归还其资财五百余万。 [[17]](#hh-note-21)

<a id="hh-event-24"></a>

18. **客星大如李，苍白，芒气长二尺，西南指上阶星。** 四年六月甲子，客星大如李，苍白，芒气长二尺，西南指上阶星。 [[18]](#hh-note-24)

<a id="hh-event-25"></a>

19. **太白入舆鬼。** 癸酉，太白入舆鬼。 [[19]](#hh-note-25)

<a id="hh-event-27"></a>

20. **封福弟亢为当涂乡侯。** 永初四年，封福弟亢为当涂乡侯。 [[20]](#hh-note-27)

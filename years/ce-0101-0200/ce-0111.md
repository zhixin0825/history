<a id="hh-event-1"></a>

1. **日有食之。** 五年春正月庚辰朔，发生日食。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **郡国十地震。** 丙戌，郡国十地震。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **太尉张禹免。** 己丑，太尉张禹免。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **光禄勳李修为太尉。** 甲申，光禄勳李修为太尉。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **诏省减郡国贡献太官口食，先零羌寇河东，遂至河内。** 二月丁卯，诏省减郡国贡献太官口食，先零羌寇河东，遂至河内。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **诏陇西徙襄武，安定徙美阳，北地徙池阳，上郡徙衙。** 三月，诏陇西徙襄武，安定徙美阳，北地徙池阳，上郡徙衙。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **夫余夷犯塞，杀伤吏人。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **闰月丁酉，赦凉州河西四郡。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **诏曰“朕以不德”。** 戊戌，诏曰：『朕以不德，奉郊庙，承大业，不能兴和降善，为人祈福。灾异蜂起，寇贼纵横，夷狄猾夏，戎事不息，百姓匮乏，疲于徵发。重以蝗虫滋生，害及成麦，秋稼方收，甚可悼也。朕以不明，统理失中，亦未获忠良以毗阙政。传曰：「颠而不扶，危而不持，则将焉用彼相矣。」公卿大夫将何以匡救，济斯艰戹，承天诫哉？盖为政之本，莫若得人，褒贤显善，圣制所先。「济济多士，文王以宁」。思得忠良正直之臣，以辅不逮。其令三公、特进、侯、中二千石、二千石、郡守、诸侯相举贤良方正、有道术、达于政化、能直言极谏之士各一人，及至孝与众卓异者，并遣到公车，朕将亲览焉。』 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **乐成王巡薨。** 六月甲辰，乐成王巡去世。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **诏三公、特进、九卿、校尉，举列将子孙明晓战陈任将帅者。** 秋七月己巳，诏三公、特进、九卿、校尉，举列将子孙明晓战陈任将帅者。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **汉阳人杜琦、王信叛，与先零诸种羌攻陷上邽城。** 九月，汉阳人杜琦、王信叛，与先零诸种羌攻陷上邽城。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **汉阳太守赵博遣客刺杀杜琦。** 十二月，汉阳太守赵博遣客刺杀杜琦。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **是岁，九州蝗，郡国八雨水。** 当年，九州蝗，郡国八雨水。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **法雄破张伯路，辽东人杀余部。** 张伯路余部乏食，抄掠东莱，法雄击败之，其逃辽东后为李久等所诛。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **夫余兵侵乐浪。** 夫余王率步骑抄掠乐浪，后复归附。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **高句骊王请求属玄菟。** 王宫遣使进贡，请编入玄菟管辖。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **太白昼见，经天。** 五年六月辛丑，太白昼见，经天。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **拜长乐卫尉，以病乞身，复为光禄大夫，卒於官。** 永初五年，拜长乐卫尉，以病乞身，复为光禄大夫，卒于官。 [[19]](#hh-note-19)

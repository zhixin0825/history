# 公元111年｜永初五年

[← 公元110年](ce-0110.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元112年 →](ce-0112.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **日有食之。** 五年春正月庚辰朔，发生日食。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **郡国十地震。** 丙戌，郡国十地震。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

3. **张禹免太尉，李修继任。** 太尉张禹罢免，光禄勋李修任太尉。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

<a id="hh-event-6"></a>

4. **先零羌进犯河东、河内，朝廷迁四郡治。** 二月丁卯，朝廷诏减郡国供给太官的口食。先零羌寇河东，进至河内。三月，朝廷将陇西郡治迁到襄武、安定迁到美阳、北地迁到池阳、上郡迁到衙。 [[4]](#hh-note-5)

<a id="hh-event-7"></a>

<a id="hh-event-16"></a>

5. **夫余王率兵犯塞，抄掠乐浪。** 夫余王率步骑抄掠乐浪，杀伤汉朝吏民，后来重新归附。 [[5]](#hh-note-7)

<a id="hh-event-8"></a>

6. **闰月丁酉，赦凉州河西四郡。** [[6]](#hh-note-8)

<a id="hh-event-9"></a>

7. **诏曰“朕以不德”。** 戊戌，诏曰：『朕以不德，奉郊庙，承大业，不能兴和降善，为人祈福。灾异蜂起，寇贼纵横，夷狄猾夏，戎事不息，百姓匮乏，疲于徵发。重以蝗虫滋生，害及成麦，秋稼方收，甚可悼也。朕以不明，统理失中，亦未获忠良以毗阙政。传曰：「颠而不扶，危而不持，则将焉用彼相矣。」公卿大夫将何以匡救，济斯艰戹，承天诫哉？盖为政之本，莫若得人，褒贤显善，圣制所先。「济济多士，文王以宁」。思得忠良正直之臣，以辅不逮。其令三公、特进、侯、中二千石、二千石、郡守、诸侯相举贤良方正、有道术、达于政化、能直言极谏之士各一人，及至孝与众卓异者，并遣到公车，朕将亲览焉。』 [[7]](#hh-note-9)

<a id="hh-event-10"></a>

8. **乐成王巡薨。** 六月甲辰，乐成王巡去世。 [[8]](#hh-note-10)

<a id="hh-event-11"></a>

9. **诏三公、特进、九卿、校尉，举列将子孙明晓战陈任将帅者。** 秋七月己巳，诏三公、特进、九卿、校尉，举列将子孙明晓战陈任将帅者。 [[9]](#hh-note-11)

<a id="hh-event-12"></a>

<a id="hh-event-13"></a>

10. **杜琦等合羌兵攻上邽，赵博遣人杀杜琦。** 汉阳杜琦、王信起兵，联合先零诸羌攻下上邽。汉阳太守赵博遣客刺杀杜琦。 [[10]](#hh-note-12)

<a id="hh-event-14"></a>

11. **是岁，九州蝗，郡国八雨水。** 当年，九州蝗，郡国八雨水。 [[11]](#hh-note-14)

<a id="hh-event-15"></a>

12. **法雄破张伯路，辽东人杀余部。** 张伯路余部乏食，抄掠东莱，法雄击败之，其逃辽东后为李久等所诛。 [[12]](#hh-note-15)

<a id="hh-event-17"></a>

13. **高句骊王请求属玄菟。** 王宫遣使进贡，请编入玄菟管辖。 [[13]](#hh-note-17)

<a id="hh-event-18"></a>

14. **太白昼见，经天。** 五年六月辛丑，太白昼见，经天。 [[14]](#hh-note-18)

<a id="hh-event-19"></a>

15. **拜长乐卫尉，以病乞身，复为光禄大夫，卒於官。** 永初五年，拜长乐卫尉，以病乞身，复为光禄大夫，卒于官。 [[15]](#hh-note-19)

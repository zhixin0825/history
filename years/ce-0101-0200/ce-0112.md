# 公元112年｜永初六年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **诏越巂置长利、高望、始昌三苑，又令益州郡置万岁苑，犍为置汉平苑。** 六年春正月庚申，诏越巂置长利、高望、始昌三苑，又令益州郡置万岁苑，犍为置汉平苑。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **十州蝗。** 三月，十州蝗。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

3. **张敏罢司空，刘恺继任。** 司空张敏罢免，太常刘恺任司空。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

4. **旱。** 五月，旱。 [[4]](#hh-note-5)

<a id="hh-event-6"></a>

<a id="hh-event-7"></a>

<a id="hh-event-9"></a>

5. **朝廷恢复官吏秩级，邓太后亲理冤狱。** 丙寅，诏中二千石以下至黄绶官员复秩还赎，按等差赐爵。戊辰，邓太后至洛阳寺审录囚徒、处理冤狱。辛巳，朝廷大赦。 [[5]](#hh-note-6)

<a id="hh-event-8"></a>

6. **豫章、员谿、原山崩。** 六月壬辰，豫章、员谿、原山崩。 [[6]](#hh-note-8)

<a id="hh-event-10"></a>

7. **遣侍御史唐喜讨汉阳贼王信，破斩之。** [[7]](#hh-note-10)

<a id="hh-event-11"></a>

8. **护乌桓校尉吴祉下狱死。** 冬十一月辛丑，护乌桓校尉吴祉下狱后死亡。 [[8]](#hh-note-11)

<a id="hh-event-12"></a>

9. **是岁，先零羌滇零死，子零昌复袭伪号。** 当年，先零羌滇零死，子零昌复袭伪号。 [[9]](#hh-note-12)

<a id="hh-event-13"></a>

10. **刘恭子阿奴封竹邑侯。** 彭城一系另封阿奴为竹邑侯。 [[10]](#hh-note-13)

<a id="hh-event-14"></a>

11. **安帝下诏曰。** 永初六年，安帝下诏曰：『夫仁不遗亲，义不忘劳，兴灭继绝，善善及子孙，古之典也。昔我光武受命中兴，恢弘圣绪，横被四表，昭假上下，光耀万世，祉祚流衍，垂于罔极。予末小子，夙夜永思，追惟勋烈，披图案籍，建武元功二十八将，佐命虎臣，谶记有徵。盖萧、曹绍封，传继于今；况此未远，而或至乏祀，朕其湣之。其条二十八将无嗣绝世，若犯罪夺国，其子孙应当统后者，分别署状上。将及景风，章叙旧德，显兹遗功焉。』 [[11]](#hh-note-14)

<a id="hh-event-15"></a>

12. **安帝永初六年十月丙戌，郡六冬雷。** [[12]](#hh-note-15)

### 11. 安帝下诏曰

[返回正文第11条](#hh-event-14)

<a id="hh017-l1808-e14"></a>

**[《后汉书·冯岑贾列传》](../../sources/摘录/后汉书-卷017-冯岑贾列传.md#p001)** · [仓内TXT L1808](../../sources/本地分卷/后汉书/后汉书-卷017.md#L1808)

> 永初六年，安帝下詔曰：『夫仁不遺親，義不忘勞，興滅繼絕，善善及子孫，古之典也。昔我光武受命中興，恢弘聖緒，橫被四表，昭假上下，光耀萬世，祉祚流衍，垂於罔極。予末小子，夙夜永思，追惟勛烈，披圖案籍，建武元功二十八將，佐命虎臣，讖記有徵。蓋蕭、曹紹封，傳繼於今；況此未遠，而或至乏祀，朕其湣之。其條二十八將無嗣絕世，若犯罪奪國，其子孫應當統後者，分別署狀上。將及景風，章敘舊德，顯茲遺功焉。』

**归年与互校** 传文原载年号，节录该句。

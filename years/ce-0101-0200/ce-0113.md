1. **皇太后率大臣命妇谒宗庙。** 七年春正月庚戌，皇太后率大臣命妇谒宗庙。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **郡国十八地震。** 二月丙午，郡国十八地震。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **平原王胜薨。** 夏四月乙未，平原王胜去世。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **日有食之。** 丙申晦，发生日食。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **京师大雩。** 五月庚子，京师大雩。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **护羌校尉侯霸、骑都尉马贤破先零羌。** 秋，护羌校尉侯霸、骑都尉马贤破先零羌。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

<a id="hh-event-10"></a>

7. **京师遭蝗，朝廷减租、调米赈饥。** 八月丙寅，京师大风，蝗群飞过洛阳。朝廷赐民爵，蝗灾使禾稼减产达一半的郡国免本年田租，其余受灾地据实减免。九月，调零陵、桂阳、豫章、会稽租米，赈济南阳、广陵、下邳、彭城、山阳、庐江、九江饥民，又调滨水各县谷物送进敖仓。 [[7]](#hh-note-7)

<a id="hh-event-11"></a>

8. **陈王刘羡孙安国封耕亭侯。** 朝廷另封刘羡之孙，使其受亭侯爵。 [[8]](#hh-note-11)

<a id="hh-event-12"></a>

9. **邓太后绍封延曾孙恢为芦亭侯。** 永初七年，邓太后绍封延曾孙恢为芦亭侯。 [[9]](#hh-note-12)

<a id="hh-event-13"></a>

10. **邓太后复封纯琴亭侯。** 永初七年，邓太后复封纯琴亭侯。 [[10]](#hh-note-13)

<a id="hh-event-14"></a>

11. **邓太后诏诸马子孙还京师，随四时见会如故事，复绍封光子朗爲合乡侯。** 永初七年，邓太后诏诸马子孙还京师，随四时见会如故事，复绍封光子朗爲合乡侯。 [[11]](#hh-note-14)

<a id="hh-event-15"></a>

12. **为奴所杀，无子，国绝。** 永初七年，为奴所杀，无子，国绝。 [[12]](#hh-note-15)

1. **日有食之。** 四年春二月乙巳朔，发生日食。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **大赦天下。** 乙卯，颁布大赦。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **武库灾。** 壬戌，武库灾。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

<a id="hh-event-6"></a>

<a id="hh-event-28"></a>

4. **袁敞去世，李合任司空。** 四月戊申，司空袁敞去世。五月丁丑，太常李合继任，常向朝廷陈说政事得失。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **鲜卑寇辽西，辽西郡兵与乌桓击破之。** 己巳，鲜卑寇辽西，辽西郡兵与乌桓将其击败。 [[5]](#hh-note-5)

<a id="hh-event-7"></a>

<a id="hh-event-29"></a>

6. **三郡雨雹伤六畜。** 三郡遇雹，雹有大如盂杯或鸡子者，伤杀六畜。 [[6]](#hh-note-7)

<a id="hh-event-8"></a>

7. **陈王钧薨。** 秋七月辛丑，陈王钧去世。 [[7]](#hh-note-8)

<a id="hh-event-9"></a>

8. **京师及郡国十雨水。** [[8]](#hh-note-9)

<a id="hh-event-10"></a>

9. **诏曰“今年秋稼茂好”。** 诏曰：『今年秋稼茂好，垂可收获，而连雨未霁，惧必淹伤。夕惕惟忧，思念厥咎。夫霖雨者，人怨之所致。其武吏以威暴下，文吏妄行苛刻，乡吏因公生奸，为百姓所患苦者，有司显明其罚。又《月令》「仲秋养衰老，授几杖，行糜粥」。方今案比之时，郡、县多不奉行。虽有糜粥，糠秕相半，长吏怠事，莫有躬亲，甚违诏书养老之意。其务崇仁恕，赈护寡独，称朕意焉。』 [[9]](#hh-note-10)

<a id="hh-event-11"></a>

<a id="hh-event-14"></a>

<a id="hh-event-15"></a>

<a id="hh-event-19"></a>

10. **任尚破先零，零昌被刺，虔人羌归降。** 护羌校尉任尚遣客刺杀先零首领零昌，与骑都尉马贤在富平上河大破先零羌。狼莫等也受汉军进击，虔人羌率众归降，陇右平定。 [[10]](#hh-note-11)

<a id="hh-event-12"></a>

11. **彭城王恭薨。** 冬十一月己卯，彭城王恭去世。 [[11]](#hh-note-12)

<a id="hh-event-13"></a>

12. **越巂夷寇遂久，杀县令。** 十二月，越巂夷寇遂久，杀县令。 [[12]](#hh-note-13)

<a id="hh-event-16"></a>

13. **是岁，郡国十三地震。** 当年，郡国十三地震。 [[13]](#hh-note-16)

<a id="hh-event-17"></a>

14. **杨震入为太仆，后迁太常。** 杨震进中央任太仆，随后任太常，推荐通晓经义的士人。 [[14]](#hh-note-17)

<a id="hh-event-18"></a>

15. **命刘珍等赴东观校书。** 朝廷择刘珍等赴东观校书，蔡伦督办。 [[15]](#hh-note-18)

<a id="hh-event-20"></a>

<a id="hh-event-22"></a>

<a id="hh-event-23"></a>

<a id="hh-event-24"></a>

<a id="hh-event-25"></a>

16. **五纬迭入舆鬼。** 岁星停留舆鬼，太白、辰星、荧惑先后入舆鬼。辰星犯岁星，戊戌荧惑犯舆鬼大星。 [[16]](#hh-note-20)

<a id="hh-event-21"></a>

17. **太白昼见丙上。** 乙未，太白昼见丙上。 [[17]](#hh-note-21)

<a id="hh-event-26"></a>

18. **太白入南斗口中。** 九月辛巳，太白入南斗口中。 [[18]](#hh-note-26)

<a id="hh-event-27"></a>

19. **与母别居，国除。** 元初四年，与母别居，国除。 [[19]](#hh-note-27)

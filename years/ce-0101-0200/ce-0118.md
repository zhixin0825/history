[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **越巂夷叛。** 五年春正月，越巂夷叛。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **中山王宪薨。** 二月壬戌，中山王宪去世。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **京师及郡国五旱，诏禀遭旱贫人。** 三月，京师及郡国五旱，诏禀遭旱贫人。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **高句骊与秽貊寇玄菟。** 夏六月，高句骊与秽貊寇玄菟。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **越巂蛮夷及旄牛豪叛，杀长吏。** 秋七月，越巂蛮夷及旄牛豪叛，杀长吏。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **诏曰“旧令制度”。** 丙子，诏曰：『旧令制度，各有科品，欲令百姓务崇节约。遭永初之际，人离荒戹，朝廷躬自菲薄，去绝奢饰，食不兼味，衣无二彩。比年虽获丰穰，尚乏储积，而小人无虑，不图久长，嫁聚送终，纷华靡丽，至有走卒奴婢被绮縠，着珠玑。京师尚若斯，何以示四远？设张法禁，恳恻分明，而有司惰任，讫不奉行。秋节既立，鸷鸟将用，且复重申，以观后效。』 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **日有食之。** 八月丙申朔，发生日食。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **鲜卑寇代郡，杀长吏。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **鲜卑寇上谷。** 冬十月，鲜卑寇上谷。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **中郎将任尚有辠，弃市。** 十二月丁巳，中郎将任尚有辠，弃市。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **是岁，郡国十四地震。** 当年，郡国十四地震。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **刘道弟弟和刘恭孙分封。** 彭城国刘道的弟弟三人封乡侯，刘恭孙顺封东安亭侯。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **高句骊与濊貊进攻华丽城。** 高句骊同濊貊侵入玄菟，进攻华丽城。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **邓遵募人杀狼莫。** 邓遵募雕何等刺杀狼莫，雕何赐为羌侯，邓遵进封。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **南匈奴逢侯入塞降。** 逢侯败于鲜卑后部众离散，次春至朔方塞归降。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **镇星犯东井钺星。** 五年三月丙申，镇星犯东井钺星。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **辰星犯舆鬼质星。** 五月庚午，辰星犯舆鬼质星。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **太白犯钺星。** 丙戌，太白犯钺星。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **刘毅请记载邓太后在位事迹。** 平望侯刘毅上书安帝，追述邓太后拥立安帝、赈济灾民、录用功臣后人与解除禁锢等事，请命史官撰《长乐宫注》《圣德颂》。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **封乾二弟为亭侯。** 元初五年，封乾二弟为亭侯。 [[20]](#hh-note-20)

### 19. 刘毅请记载邓太后在位事迹

[返回正文第19条](#hh-event-19)

<a id="hh010-l1350-e19"></a>

**[《后汉书·皇后纪》](../../sources/摘录/后汉书-卷010-皇后纪.md#p007)** · [仓内TXT L1350](../../sources/本地分卷/后汉书/后汉书-卷010.md#L1350)

> 元初五年，平望侯劉毅以太后多德政，欲令早有注記，上書安帝曰：『臣聞《易》載羲、農而皇德著，《書》述唐、虞而帝道崇，故雖聖明，必書功於竹帛，流音於管弦。伏惟皇太后膺大聖之姿，體乾坤之德，齊蹤虞妃，比跡任、姒。孝悌慈仁，允恭節約，杜絕奢盈之源，防抑逸欲之兆。正位內朝，流化四海。及元興、延平之際，國無儲副，仰觀乾象，參之人譽，援立陛下為天下主，永安漢室，綏靜四海。又遭水潦，東州飢荒。垂恩元元，冠蓋交路，菲薄衣食，躬率群下，損膳解驂，以贍黎苗。惻隱之恩，猶視赤子。克已引愆，顯揚仄陋。崇晏晏之政，敷在寬之教。興滅國，繼絕世，錄功臣，復宗室。追還徙人，蠲除禁錮。政非惠和，不圖於心，制非舊典，不訪於朝。弘德洋溢，充塞宇宙；洪澤豐沛，漫衍八方。華夏樂化，戎狄混幷。丕功著於大漢，碩惠加於生人。巍巍之業，可聞而不可及；蕩蕩之勳，可誦而不可名。古之帝王，左右置史；漢之舊典，世有注記。夫道有夷崇，治有進退。若善政不述，細異輒書，是為堯、湯負洪水大旱之責，而無咸熙假天之美；高宗、成王有雉雊迅風之變，而無中興康寧之功也。上考《詩》、《書》，有虞二妃，周室三母，修行佐德，思不逾閾。未有內遭家難，外遇灾害，覽總大麓，經營天物，功德巍巍若茲者也。宜令史官著《長樂宮注》、《聖德頌》，以敷宣景燿，勒勳金石，縣之日月，攄之罔極，以崇陛下烝烝之孝。』

**归年与互校** 传文原载年号，节录该句。

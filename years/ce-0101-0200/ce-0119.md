1. **京师及郡国四十二地震，或坼裂，水泉涌出。** 六年春二月乙巳，京师及郡国四十二地震，或坼裂，水泉涌出。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏三府选掾属高第，能惠利牧养者各五人，光禄勲与中郎将选孝廉郎宽博有谋、清白行高者五十人，出…。** 壬子，诏三府选掾属高第，能惠利牧养者各五人，光禄勲与中郎将选孝廉郎宽博有谋、清白行高者五十人，出补令、长、丞、尉。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **诏曰“夫政”。** 乙卯，诏曰：『夫政，先京师，后诸夏。《月令》仲春「养幼小，存诸孤」，季春「赐贫穷，赈乏绝，省妇使，表贞女」，所以顺阳气，崇生长也。其赐人尤贫困、孤弱、单独谷，人三斛；贞妇有节义十斛，甄表门闾，旌显厥行。』 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **始立六宗，祀於洛城西北。** 三月庚辰，始立六宗，祀于洛城西北。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

<a id="hh-event-22"></a>

5. **会稽大疫，诏派医治并减赋。** 夏四月，会稽发生大疫。朝廷遣光禄大夫率太医巡行诊治，赐死者棺木，并免田租、口赋。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **沛国，勃海大风，雨雹。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **京师旱。** 五月，京师旱。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **乐成王宾薨。** 六月丁丑，乐成王宾去世。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **平原王得薨。** 丙戌，平原王得去世。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **鲜卑寇马城，度辽将军邓遵率南单于击破之。** 秋七月，鲜卑寇马城，度辽将军邓遵率南单于将其击败。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **陈王竦薨。** 九月癸巳，陈王竦去世。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **日有食之，既。** 十二月戊午朔，发生日食，既。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **郡国八地震。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **是岁，永昌、益州蜀郡夷叛，与越巂夷杀长吏，燔城邑，益州刺史张乔讨破降之。** 当年，永昌、益州蜀郡夷叛，与越巂夷杀长吏，燔城邑，益州刺史张乔讨破降服。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **索班屯伊吾及西域复守议。** 曹宗遣索班屯伊吾，数月后索班为北单于与车师后部所攻；对是否关闭玉门关，朝议意见不同。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **征济北、河间诸王子入京。** 邓太后征两国王子于京，后来选刘翼奉平原王后。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **太白入舆鬼。** 六年四月癸丑，太白入舆鬼。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **荧惑在舆鬼中。** 六月丙戌，荧惑在舆鬼中。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **镇星在舆鬼中。** 丁卯，镇星在舆鬼中。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **太白犯左执法。** 辛巳，太白犯左执法。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **国相行弘奏请废之。** 元初六年，国相行弘奏请废之。 [[21]](#hh-note-21)

### 4. 始立六宗，祀於洛城西北

[返回正文第4条](#hh-event-4)

<a id="hh005-l759-e4"></a>

**[《后汉书·安帝纪》](../../sources/摘录/后汉书-卷005-安帝纪.md#p002)** · [仓内TXT L759](../../sources/本地分卷/后汉书/后汉书-卷005.md#L759)

> 三月庚辰，始立六宗，祀於洛城西北。

<a id="sy-hh098-l7158-e4"></a>

**[《后汉书·祭祀志中》](../../sources/摘录/后汉书-卷098-祭祀志中.md#p002)** · [仓内TXT L7158](../../sources/本地分卷/后汉书/后汉书-卷098.md#L7158)

> 安帝即位，元初六年，以《尚書》歐陽家說，謂六宗者，在天地四方之中，為上下四方之宗。以元始中故事，謂六宗《易》六子之氣日、月、雷公、風伯、山、澤者為非是。三月庚辰，初更立六宗，祀於雒陽西北戍亥之地，禮比太社也。

**本段所记** 安帝采用《尚书》欧阳家关于六宗的解释，三月庚辰重立六宗祭，地点在洛阳西北，礼仪比照太社。

**归年与互校** 《安帝纪》同日同事，《祭祀志》另载祭祀立论与规格。

### 15. 索班屯伊吾及西域复守议

[返回正文第15条](#hh-event-15)

<a id="hh047-l3625-e15"></a>

**[《后汉书·班梁列传》](../../sources/摘录/后汉书-卷047-班梁列传.md#p004)** · [仓内TXT L3625](../../sources/本地分卷/后汉书/后汉书-卷047.md#L3625)

> 元初六年，敦煌太守曹宗遣長史索班將千餘人屯伊吾，車師前王及鄯善王皆來降班。後數月，北單于與車師後部遂共攻沒班，進擊走前王，略有北道。鄯善王急，求救於曹宗，宗因此請出兵五千人擊匈奴，報索班之恥，因復取西域。鄧太后召勇詣朝堂會議。先是公卿多以爲宜閉玉門關，遂棄西域。勇上議曰：「昔孝武皇帝患匈奴彊盛，兼緫百蠻，以逼障塞。於是開通西域，離其黨與，論者以爲奪匈奴府藏，斷其右臂。遭王莽篡盜，徵求無猒，胡夷忿毒，遂以背叛。

**归年与互校** 出屯明载元初六年，“後數月”及其后的朝议为后续，确月未载。

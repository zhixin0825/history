<a id="hh-event-41"></a>

41. **高句骊遂成继位。** 据传高句骊王宫死，遂成继立，姚光建议乘丧出兵，陈忠反对，安帝听从。 [[41]](#hh-note-41)

<a id="hh-event-42"></a>

42. **其至鞬叛，围马城。** 其至鞬进犯居庸，成严战死；鲜卑继围徐常于马城。 [[42]](#hh-note-42)

<a id="hh-event-43"></a>

<a id="hh-event-48"></a>

48. **年七十三，岁朝会集诸生，讲论终日，因令其二子曰。** 建光元年，年七十三，岁朝会集诸生，讲论终日，因令其二子曰：「吾日者梦见先师东里先生，与我讲于阴堂之奥。」 [[48]](#hh-note-48)

<a id="hh-event-49"></a>

49. **马贤率兵召卢{匆心}斩之。** 建光元年春，马贤率兵召卢{匆心}斩之，因放兵击其种人，首虏二千余人，掠马、牛、羊十万头，忍良等皆亡出塞。 [[49]](#hh-note-49)

<a id="hh-event-50"></a>

50. **邓遵免，复以耿夔代为度辽将军。** 建光元年，邓遵免，复以耿夔代为度辽将军。 [[50]](#hh-note-50)

<a id="hh-event-51"></a>

51. **京都及郡国二十九淫雨伤稼。** 建光元年，京都及郡国二十九淫雨伤稼。 [[51]](#hh-note-51)

<a id="hh-event-52"></a>

52. **郡国七冬雷。** 建光元年十月，郡国七冬雷。 [[52]](#hh-note-52)

<a id="sy-event-53"></a>

53. **安帝以策书征樊英等六人。** 公车传策书征樊英、孔乔、李昺、郎宗、杨伦、王辅，只有郎宗与杨伦到洛阳。 [[53]](#sy-note-53)

54. **邓太后崩后杜根得出。** 安帝褒忠直而录被诛者子孙，杜根自出应征，任符节令。 [[54]](#sgz-note-54)

**[《后汉书·刘赵淳于江刘周赵列传》](../../sources/摘录/后汉书-卷039-刘赵淳于江刘周赵列传.md#p004)** · [仓内TXT L3080](../../sources/本地分卷/后汉书/后汉书-卷039.md#L3080)

> 會馬英策罷，尚書陳忠上疏薦愷曰：「臣聞三公上則台階，下象山嶽，股肱元首，鼎足居職，協和陰陽，調訓五品，考功量才，以序庶僚，遭烈風不迷，遇迅雨不惑，位莫重焉。而今上司缺職，未議其人。臣竊差次諸卿，考合觿議，咸稱太常朱倀、少府荀遷。臣父寵，前忝司空，倀、遷並為掾屬，具知其能。倀能說經書而用心褊狹，遷嚴毅剛直而薄於藝文。伏見前司徒劉愷，沉重淵懿，道德博備，克讓爵土，致祚弱弟，躬浮雲之志，兼浩然之氣，頻歷二司，舉動得禮。以疾致仕，側身里巷，處約思純，進退有度，百僚景式，海內歸懷。往者孔光、師丹，近世鄧彪、張酺，皆去宰相，復序上司。誠宜簡練卓異，以猒觿望。」書奏，詔引愷拜太尉。

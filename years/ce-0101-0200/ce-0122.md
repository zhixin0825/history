1. **夫余遣使奉贡，高句骊遣还所俘并请降。** 二月，夫余继助汉在[前一年](ce-0121.md#hh-note-37)解玄菟之围后遣使奉贡。高句骊王遂成归还此前所俘的汉人，向玄菟请降。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

<a id="hh-event-5"></a>

2. **改元延光，大赦并恢复徙者户籍。** 改元延光，大赦，遣还徙者，恢复户邑属籍。赐民爵，三老、孝悌、力田受爵二级。 [[2]](#hh-note-2)

<a id="hh-event-6"></a>

3. **京师郡国二十一雨雹。** 夏四月癸未，京师郡国二十一雨雹。 [[3]](#hh-note-6)

<a id="hh-event-7"></a>

<a id="hh-event-8"></a>

4. **陈褒免司空，刘授接任。** 司空陈褒免职，宗正刘授继任。 [[4]](#hh-note-7)

<a id="hh-event-9"></a>

5. **改乐成国为安平，封河间王开子得为安平王。** 己巳，改乐成国为安平，封河间王开子得为安平王。 [[5]](#hh-note-9)

<a id="hh-event-10"></a>

6. **郡国蝗。** 六月，郡国蝗。 [[6]](#hh-note-10)

<a id="hh-event-11"></a>

7. **京师及郡国十三地震。** 秋七月癸卯，京师及郡国十三地震。 [[7]](#hh-note-11)

<a id="hh-event-13"></a>

8. **虔人羌叛，攻谷罗城，度辽将军耿夔讨破之。** [[8]](#hh-note-13)

<a id="hh-event-14"></a>

<a id="hh-event-33"></a>

9. **阳陵园寝殿失火。** 阳陵园寝殿失火。 [[9]](#hh-note-14)

<a id="hh-event-15"></a>

10. **九真言黄龙见无功。** 辛卯，九真言黄龙见无功。 [[10]](#hh-note-15)

<a id="hh-event-16"></a>

<a id="hh-event-17"></a>

11. **命三公郡国察举清白爱民吏。** 诏三公、中二千石官举任职一至十年间廉洁爱民的刺史、二千石、令、长、相。刺史举所辖官员，郡守、国相举墨绶官，皆须认真核实品行与治绩。 [[11]](#hh-note-16)

<a id="hh-event-18"></a>

12. **郡国二十七地震。** 九月甲戌，郡国二十七地震。 [[12]](#hh-note-18)

<a id="hh-event-19"></a>

<a id="hh-event-20"></a>

13. **鲜卑入寇雁门、定襄与太原。** 鲜卑先后攻犯雁门、定襄、太原。 [[13]](#hh-note-19)

<a id="hh-event-21"></a>

<a id="hh-event-26"></a>

14. **烧当羌降，马贤击降麻奴。** 烧当羌首领归降，马贤击败并招降麻奴。 [[14]](#hh-note-21)

<a id="hh-event-22"></a>

<a id="hh-event-30"></a>

15. **九真边外部众奉贡内属。** 九真边外各部贡献，请求内属。 [[15]](#hh-note-22)

<a id="hh-event-23"></a>

<a id="hh-event-24"></a>

<a id="hh-event-32"></a>

16. **郡国风水灾，赐死者家属钱。** 京师及郡国二十七处大雨伤稼，大风杀人。诏被压、被溺身亡者年七岁以上，每人给钱二千。 [[16]](#hh-note-23)

<a id="hh-event-27"></a>

17. **更封显长社候，食邑万三千五百户，追尊后母宗为荥阳君。** 延光元年，更封显长社候，食邑万三千五百户，追尊后母宗为荥阳君。 [[17]](#hh-note-27)

<a id="hh-event-28"></a>

18. **尊历母为长公主。** 延光元年，尊历母为长公主。 [[18]](#hh-note-28)

<a id="hh-event-29"></a>

19. **河西大雨雹，大者如斗。** 延光元年，河西大雨雹，大者如斗。 [[19]](#hh-note-29)

<a id="hh-event-31"></a>

20. **中谒者但诵亦非四分庚申，上言当用命历序甲寅元。** 延光元年，中谒者但诵亦非四分庚申，上言当用命历序甲寅元。 [[20]](#hh-note-31)

<a id="sy-event-34"></a>

21. **设置蜀郡属国都尉。** 蜀郡原西部都尉改为属国都尉，单独治理四城。 [[21]](#sy-note-34)

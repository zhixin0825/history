# 公元127年｜永建二年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **乐安王鸿来朝。** 二年春正月戊申，乐安王鸿入朝觐见。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **常山王章薨。** 丁卯，常山王章去世。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-5"></a>

3. **鲜卑寇辽东、玄菟，耿晔与南单于击退。** 鲜卑进攻辽东、玄菟，护乌桓校尉耿晔率南单于击破来兵。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **诏禀贷荆、豫、兖、冀四州流冗贫人，所在安业之。** 甲辰，诏禀贷荆、豫、兖、冀四州流冗贫人，所在安业之；疾病致医药。 [[4]](#hh-note-4)

<a id="hh-event-6"></a>

5. **旱，遣使者录囚徒。** 三月，旱，派使者录囚徒。 [[5]](#hh-note-6)

<a id="hh-event-7"></a>

<a id="hh-event-22"></a>

6. **疏勒臣磐来贡，汉授都尉。** 疏勒王臣磐遣使奉贡，顺帝拜臣磐为汉大都尉，拜其侄臣勋为守国司马。 [[6]](#hh-note-7)

<a id="hh-event-8"></a>

7. **追尊谥皇妣李氏为恭愍皇后，葬於恭北陵。** 夏六月乙酉，追尊谥皇妣李氏为恭愍皇后，葬于恭北陵。 [[7]](#hh-note-8)

<a id="hh-event-9"></a>

8. **西域长史班勇、敦煌太守张朗讨焉耆、尉犁、危须三国，破之。** 西域长史班勇、敦煌太守张朗讨焉耆、尉犁、危须三国，破之；并遣子贡献。 [[8]](#hh-note-9)

<a id="hh-event-10"></a>

<a id="hh-event-23"></a>

9. **七月日食。** 七月甲戌朔，日食于翼宿九度。 [[9]](#hh-note-10)

<a id="hh-event-11"></a>

<a id="hh-event-12"></a>

10. **朱宠、朱伥去职，刘光任太尉。** 太尉朱宠、司徒朱伥罢免，太常刘光任太尉、录尚书事。 [[10]](#hh-note-11)

<a id="hh-event-13"></a>

11. **下邳王成薨。** 辛丑，下邳王成去世。 [[11]](#hh-note-13)

<a id="hh-event-14"></a>

12. **梁王刘匡七兄弟封侯。** 刘匡的兄弟七人受封乡侯或亭侯。 [[12]](#hh-note-14)

<a id="hh-event-15"></a>

13. **刘仪两兄获封亭侯。** 常山王刘仪兄二人获封亭侯。 [[13]](#hh-note-15)

<a id="hh-event-16"></a>

<a id="hh-event-19"></a>

14. **顺帝征樊英、杨厚等。** 顺帝备礼征樊英，樊英称病辞谢。顺帝又特征杨厚，诏郡县催他启程。黄琼、贺纯在这一时期也与杨厚同受公车征召。 [[14]](#hh-note-16)

<a id="hh-event-17"></a>

15. **孝顺永建二年二月癸未，太白昼见三十九日。** 孝顺永建二年二月癸未，太白昼见三十九日。 [[15]](#hh-note-17)

<a id="hh-event-18"></a>

16. **荧惑入舆鬼。** 八月乙巳，荧惑入舆鬼。 [[16]](#hh-note-18)

<a id="hh-event-20"></a>

17. **徵入为将作大臣。** 永建二年，徵入为将作大臣。 [[17]](#hh-note-20)

<a id="hh-event-21"></a>

18. **封臻二弟敏、俭为乡侯。** 永建二年，封臻二弟敏、俭为乡侯。 [[18]](#hh-note-21)

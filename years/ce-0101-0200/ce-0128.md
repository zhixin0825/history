<a id="hh-event-4"></a>

1. **汉阳地震地裂，朝廷抚恤赈贷。** 京师地震，汉阳地陷裂。朝廷命核查伤亡，七岁以上死者每人给二千钱，免汉阳本年田租、口赋。遣光禄大夫巡视汉阳及河内、魏郡、陈留、东郡，赈贷贫民。 [[1]](#hh-note-1)

<a id="hh-event-5"></a>

<a id="hh-event-6"></a>

2. **旱后遣使理狱。** 本年遇旱，朝廷遣使审录囚徒，处理轻系。 [[2]](#hh-note-5)

<a id="hh-event-7"></a>

3. **济南王显薨。** 甲寅，济南王显去世。 [[3]](#hh-note-7)

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

4. **茂陵园寝失火，命太常持节告祠。** 茂陵园寝失火，顺帝着素服避正殿，遣太常王龚持节告祠茂陵。 [[4]](#hh-note-8)

<a id="hh-event-10"></a>

5. **鲜卑寇渔阳。** 九月，鲜卑寇渔阳。 [[5]](#hh-note-10)

<a id="hh-event-11"></a>

6. **太傅桓焉免。** 冬十二月己亥，太傅桓焉免。 [[6]](#hh-note-11)

<a id="hh-event-12"></a>

7. **是岁，车骑将军来历罢。** 当年，车骑将军来历罢。 [[7]](#hh-note-12)

<a id="hh-event-13"></a>

8. **与姑俱选入掖庭，时年十三，相工茅通见後，惊，再拜贺曰。** 永建三年，与姑俱选入掖庭，时年十三，相工茅通见后，惊，再拜贺曰：『此所谓日角偃月，相之极贵，臣所未尝见也。』 [[8]](#hh-note-13)

<a id="sy-event-14"></a>

9. **钟武更名重安。** 零陵郡钟武侯国更名为重安。 [[9]](#sy-note-14)

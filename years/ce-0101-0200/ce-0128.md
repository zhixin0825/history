# 公元128年｜永建三年

[← 公元127年](ce-0127.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元129年 →](ce-0129.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **京师地震，汉阳地陷裂。** 三年春正月丙子，京师地震，汉阳地陷裂。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏实核伤害者，赐年七岁以上钱，人二千。** 甲午，诏实核伤害者，赐年七岁以上钱，人二千；一家被害，郡县为收敛。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **诏勿收汉阳今年田租、口赋。** 乙未，诏勿收汉阳今年田租、口赋。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **遣光禄大夫案行汉阳及河内、魏郡、陈留、东郡，禀贷贫人。** 夏四月癸卯，遣光禄大夫案行汉阳及河内、魏郡、陈留、东郡，禀贷贫人。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **旱。** 六月，旱。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **遣使者录囚徒，理轻系。** 派使者录囚徒，理轻系。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **济南王显薨。** 甲寅，济南王显去世。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **茂陵园寝灾，帝缟素避正殿。** 秋七月丁酉，茂陵园寝灾，帝缟素避正殿。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **使太常王龚持节告祠茂陵。** 辛亥，使太常王龚持节告祠茂陵。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **鲜卑寇渔阳。** 九月，鲜卑寇渔阳。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **太傅桓焉免。** 冬十二月己亥，太傅桓焉免。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **是岁，车骑将军来历罢。** 当年，车骑将军来历罢。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **与姑俱选入掖庭，时年十三，相工茅通见後，惊，再拜贺曰。** 永建三年，与姑俱选入掖庭，时年十三，相工茅通见后，惊，再拜贺曰：『此所谓日角偃月，相之极贵，臣所未尝见也。』 [[13]](#hh-note-13)

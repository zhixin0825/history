# 公元129年｜永建四年

1. **诏曰“朕托王公之上”。** 四年春正月丙寅，诏曰：『朕托王公之上，涉道日寡，政失厥中，阴阳气隔，寇盗肆暴，庶狱弥繁，忧悴永叹，疢如疾首。《诗》云：「君子如祉，乱庶遄已。」三朝之会，朔旦立春，嘉与海内洗心自新。其赦天下。从甲寅赦令已来复秩属籍，三年正月已来还赎。其阎显、江京等知识婚姻禁锢，一原除之。务崇宽和，敬顺时令，遵典去苛，以称朕意。』 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

<a id="hh-event-5"></a>

2. **顺帝加元服，出赐金帛与爵。** 丙子，顺帝加元服。朝廷按等差赐王、公主、贵人、公卿以下金帛，男子及愿登入户籍的流民赐爵一级，为父后者、三老、孝悌、力田者赐爵二级，鳏、寡、孤、独、残疾贫困不能自养者每人帛一匹。 [[2]](#hh-note-2)

<a id="hh-event-6"></a>

3. **诏以民入山凿石，发泄藏气，勑有司检察所当禁绝，如建武、永平故事。** 二月戊戌，诏以民入山凿石，发泄藏气，勑有司检察所当禁绝，如建武、永平故事。 [[3]](#hh-note-6)

<a id="hh-event-7"></a>

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

<a id="hh-event-22"></a>

4. **五州水灾伤稼，顺帝退珠并遣使抚恤。** 五月壬辰，顺帝以海内有灾，命太官减膳，不用珍玩，将桂阳太守文砻进献的大珠封还。司隶及荆、豫、兖、冀雨水过多，损伤庄稼。八月庚子，朝廷派使者核查死者，收殓遗体并赈恤贫困百姓。 [[4]](#hh-note-7)

<a id="hh-event-10"></a>

<a id="hh-event-12"></a>

<a id="hh-event-13"></a>

<a id="hh-event-14"></a>

<a id="hh-event-16"></a>

5. **刘光、张皓、许敬罢，庞参等继任三公。** 太尉刘光、司空张皓免职，大鸿胪庞参任太尉、录尚书事，太常王龚任司空。司徒许敬免，宗正刘崎任司徒。 [[5]](#hh-note-10)

<a id="hh-event-11"></a>

6. **复安定、北地、上郡归旧土。** 九月，复安定、北地、上郡归旧土。 [[6]](#hh-note-11)

<a id="hh-event-15"></a>

7. **鲜卑寇朔方。** [[7]](#hh-note-15)

<a id="hh-event-17"></a>

8. **东汉分会稽为吴郡和会稽郡。** 朝廷以浙江为界，把原会稽郡的北部另置吴郡，会稽郡的治所迁回山阴。 [[8]](#hh-note-17)

<a id="hh-event-18"></a>

<a id="hh-event-21"></a>

9. **于阗放前改立拘弥王，拘弥遣使献贡。** 于阗王放前杀拘弥王兴，立自己儿子为拘弥王，遣使向汉朝贡献。 [[9]](#hh-note-18)

<a id="hh-event-19"></a>

10. **郭镇去世。** 郭镇罢官后卒于家，获赐葬地。 [[10]](#hh-note-19)

<a id="hh-event-20"></a>

11. **樊英任五官中郎将。** 顺帝礼遇樊英，正式问政，樊英接受五官中郎将一职。 [[11]](#hh-note-20)

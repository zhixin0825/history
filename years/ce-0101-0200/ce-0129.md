# 公元129年｜永建四年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **诏曰“朕托王公之上”。** 四年春正月丙寅，诏曰：『朕托王公之上，涉道日寡，政失厥中，阴阳气隔，寇盗肆暴，庶狱弥繁，忧悴永叹，疢如疾首。《诗》云：「君子如祉，乱庶遄已。」三朝之会，朔旦立春，嘉与海内洗心自新。其赦天下。从甲寅赦令已来复秩属籍，三年正月已来还赎。其阎显、江京等知识婚姻禁锢，一原除之。务崇宽和，敬顺时令，遵典去苛，以称朕意。』 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **帝加元服。** 丙子，帝加元服。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **赐王、主、贵人、公卿以下金、帛各有差。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **赐男子爵及流民欲占者人一级。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **为父後、三老、孝悌、力田人二级。** 为父后、三老、孝悌、力田人二级；鳏、寡、孤、独、笃癃、贫不能自存帛，人一匹。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **诏以民入山凿石，发泄藏气，勑有司检察所当禁绝，如建武、永平故事。** 二月戊戌，诏以民入山凿石，发泄藏气，勑有司检察所当禁绝，如建武、永平故事。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **诏曰“海内颇有灾异”。** 夏五月壬辰，诏曰：『海内颇有灾异，朝廷修政，太官减膳，珍玩不御。而桂阳太守文砻，不惟竭忠，宣畅本朝，而远献大珠，以求幸媚，今封以还之。』 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **五州雨水。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **遣使实核死亡，收敛禀赐。** 秋八月庚子，遣使实核死亡，收敛禀赐。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **太尉刘光、司空张皓免。** 丁巳，太尉刘光、司空张皓免。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **复安定、北地、上郡归旧土。** 九月，复安定、北地、上郡归旧土。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **大鸿胪庞参为太尉，录尚书事。** 癸酉，大鸿胪庞参为太尉，录尚书事。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **太常王龚为司空。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **司徒许敬免。** 冬十一月庚辰，司徒许敬免。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **鲜卑寇朔方。** [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **宗正刘崎为司徒。** 十二月乙卯，宗正刘崎为司徒。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **是岁，分会稽为吴郡。** 当年，分会稽为吴郡。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **拘弥国遣使贡献。** [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **郭镇去世。** 郭镇罢官后卒于家，获赐葬地。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **樊英任五官中郎将。** 顺帝礼遇樊英，正式问政，樊英接受五官中郎将一职。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **顺帝永建四年，於窴王放前杀拘弥王兴，自立其子为拘弥王，而遣使者贡献於汉。** 顺帝永建四年，于窴王放前杀拘弥王兴，自立其子为拘弥王，而派使者贡献于汉。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **顺帝永建四年，司隶、荆、豫、兖、冀部淫雨伤稼。** [[22]](#hh-note-22)

1. **疏勒王遣侍子，及大宛、莎车王皆奉使贡献。** 五年春正月，疏勒王遣侍子，及大宛、莎车王皆奉使贡献。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

<a id="hh-event-10"></a>

2. **京师旱，十二处蝗灾，诏减灾民徭役。** 京师旱，京师及郡国十二处有蝗。朝廷免被灾贫民本年过更之费。 [[2]](#hh-note-2)

<a id="hh-event-5"></a>

3. **诏郡国中都官死罪系囚皆减罪一等，诣北地、上郡、安定戍。** 冬十月丙辰，诏郡国中都官在押死囚皆减刑一等，到北地、上郡、安定戍。 [[3]](#hh-note-5)

<a id="hh-event-6"></a>

4. **定远侯班始坐杀其妻阴城公主，腰斩，同产皆弃市。** 乙亥，定远侯班始坐杀其妻阴城公主，腰斩，同产皆弃市。 [[4]](#hh-note-6)

<a id="hh-event-7"></a>

5. **朝廷允分蠡吾封刘翼。** 刘翼遭废后，河间王刘开申请分蠡吾县给刘翼，顺帝准奏。 [[5]](#hh-note-7)

<a id="hh-event-8"></a>

6. **封广弟文为乐城亭侯。** 永建五年，封广弟文为乐城亭侯。 [[6]](#hh-note-8)

<a id="hh-event-9"></a>

7. **举孝廉，除郎中。** 永建五年，举孝廉，除郎中。 [[7]](#hh-note-9)

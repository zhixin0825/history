# 公元131年｜永建六年

[← 公元130年](ce-0130.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元132年 →](ce-0132.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **河间王开薨。** 六年春二月庚午，河间王开去世。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **复伊吾屯田，复置伊吾司马一人。** 三月辛亥，复伊吾屯田，复置伊吾司马一人。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **缮起太学。** 秋九月辛巳，缮起太学。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **护乌桓校尉耿晔遣兵击鲜卑，破之。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

<a id="hh-event-9"></a>

5. **于阗王遣侍子来献。** 于阗王遣侍子入朝贡献。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **诏曰“连年灾潦”。** 冬十一月辛亥，诏曰：『连年灾潦，冀部尤甚。比蠲除实伤，赡恤穷匮，而百姓犹有弃业，流亡不绝。疑郡县用心怠惰，恩泽不宣。《易》美「损上益下」，《书》称「安民则惠」。其令冀部勿收今年田租、刍稾。』 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **日南徼外叶调国、掸国遣使贡献。** 十二月，日南徼外叶调国、掸国遣使贡献。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

<a id="hh-event-12"></a>

8. **客星见牵牛。** 客星见于牵牛六度，色苍白，芒长二尺余，指向西南。 [[8]](#hh-note-8)

<a id="hh-event-10"></a>

9. **荧惑入太微中，犯左、右执法西北方六寸所。** 六年四月，荧惑入太微中，犯左、右执法西北方六寸所。 [[9]](#hh-note-10)

<a id="hh-event-11"></a>

10. **太白昼见。** 十月乙卯，太白昼见。 [[10]](#hh-note-11)

<a id="sy-event-13"></a>

11. **马续请将屯田移还湟中。** 马续接替韩皓任护羌校尉，继将两河间屯田迁回湟中，以安抚受逼惧的羌部。 [[11]](#sy-note-13)

## 本年概述

顺帝立梁氏为皇后，改元阳嘉。太学建成后增招明经，朝廷规定察举孝廉的年龄、经学与文书要求。张衡造候风地动仪。江淮和会稽发生兵乱，北边设屯田，京师旱、冀部积水，朝廷祷雨赈济。

1. **立梁小贵人为皇后，赐爵并赈甘陵。** 有司以乘氏侯梁商为先帝外戚，奏请立梁小贵人为皇后。梁氏立后，朝廷赐男子爵二级、三老孝悌力田三级，准超过公乘的爵给亲属，无户籍及愿入籍的流民一级。皇后谒高庙、光武庙，诏赈给甘陵贫民，大小口各有差。 [[1]](#hh-note-1)

<a id="hh-event-12"></a>

2. **帝临辟雍飨射，大赦天下，改元阳嘉。** 庚寅，帝临辟雍飨射，颁布大赦，改元阳嘉。 [[2]](#hh-note-12)

<a id="hh-event-13"></a>

3. **诏宗室绝属籍者，一切复籍。** 诏宗室绝属籍者，一切复籍；禀冀州尤贫民，勿收今年更、租、口赋。 [[3]](#hh-note-13)

<a id="hh-event-14"></a>

4. **阜陵王恢薨。** 夏五月戊寅，阜陵王恢去世。 [[4]](#hh-note-14)

5. **太学落成增选弟子，朝廷改定孝廉选法。** 丙辰，太学新成，试明经落第者可以补太学弟子，甲、乙科各增十名。朝廷任命郡国耆儒九十人为郎、舍人。辛卯，诏各郡国举孝廉以四十岁为下限，儒生须通章句，文吏须能笺奏，才行特异者可破格。闰月丁亥，诏特拜为郎者年满四十并通过同等课试，可参选孝廉，每年举一人。 [[5]](#hh-note-16)

<a id="hh-event-18"></a>

6. **诏郡国中都官系囚皆减死一等，亡命者赎，各有差。** 九月，诏郡国中都官系囚皆减死一等，亡命者赎，各有差。 [[6]](#hh-note-18)

<a id="hh-event-22"></a>

7. **东平王敞薨。** 十二月丁未，东平王敞去世。 [[7]](#hh-note-22)

<a id="hh-event-26"></a>

8. **诏曰“间者以来”。** 辛卯，诏曰：『间者以来，吏政不勤，故灾咎屡臻，盗贼多有。退省所由，皆以选举不实，官非其人，是以天心未得，人情多怨。《书》歌股肱，《诗》刺三事。今刺史、二千石之选，归任三司。其简序先后，精核高下，岁月之次，文武之宜，务存厥衷。』 [[8]](#hh-note-26)

10. **下邳王刘意八弟受封。** 刘意的八位弟弟分别获封乡侯或亭侯。 [[10]](#hh-note-29)

11. **河间王刘政十三弟封亭侯。** 刘政十三弟各获亭侯。 [[11]](#hh-note-30)

<a id="hh-note-32"></a>

<a id="hh059-l4348-e32"></a>

**[《后汉书·张衡列传》](../../sources/摘录/后汉书-卷059-张衡列传.md#p003)** · [仓内TXT L4348](../../sources/本地分卷/后汉书/后汉书-卷059.md#L4348)

> 陽嘉元年，復造候風地動儀。以精銅鑄成，員徑八尺，合蓋隆起，形似酒尊，飾以篆文山龜鳥獸之形。中有都柱，傍行八道，施關發機。外有八龍，首銜銅丸，下有蟾蜍，張口承之。其牙機巧制，皆隱在尊中，覆蓋周密無際。如有地動，尊則振龍機發吐丸，而蟾蜍銜之。振聲激揚，伺者因此覺知。雖一龍發機，而七首不動，尋其方面，乃知震之所在。驗之以事，合契若神。自書典所記，未之有也。嘗一龍機發而地不覺動，京師學者咸怪其無征，後數日驛至，果地震隴西，於是皆服其妙。

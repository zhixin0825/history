<a id="hh-event-1"></a>

1. **立皇后梁氏。** 阳嘉元年春正月乙巳，立皇后梁氏。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **赐爵，人二级，三老、孝悌、力田三级，爵过公乘，得移与子若同产、同产子，民无名数及流民欲占着…。** 赐爵，人二级，三老、孝悌、力田三级，爵过公乘，得移与子若同产、同产子，民无名数及流民欲占着者人一级；鳏、寡、孤、独、笃癃、贫不能自存者粟，人五斛。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **海贼曾旌等寇会稽，杀句章、鄞、鄮三县长，攻会稽东部都尉。** 二月，海贼曾旌等寇会稽，杀句章、鄞、鄮三县长，攻会稽东部都尉。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **诏缘海县各屯兵戍。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **皇后谒高庙、光武庙，诏禀甘陵贫人，大小口各有差。** 丁巳，皇后谒高庙、光武庙，诏禀甘陵贫人，大小口各有差。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **京师旱。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **勑郡国二千石各祷名山岳渎，遣大夫、谒者诣嵩高、首阳山，并祠河、洛，请雨。** 庚申，勑郡国二千石各祷名山岳渎，遣大夫、谒者到嵩高、首阳山，并祠河、洛，请雨。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **雩。** 戊辰，雩。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **以冀部比年水潦，民食不赡，诏案行禀贷，劝农功，赈乏绝。** [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **诏曰“政失厥和”。** 甲戌，诏曰：『政失厥和，阴阳隔幷，冬鲜宿雪，春无澍雨。分祷祈请，靡神不禜。深恐在所慢违「如在」之义，今遣侍中王辅等，持节分到岱山、东海、荥阳、河、洛，尽心祈焉。』 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **杨州六郡妖贼章河等寇四十九县，杀伤长吏。** 三月，杨州六郡妖贼章河等寇四十九县，杀伤长吏。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **帝临辟雍飨射，大赦天下，改元阳嘉。** 庚寅，帝临辟雍飨射，颁布大赦，改元阳嘉。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **诏宗室绝属籍者，一切复籍。** 诏宗室绝属籍者，一切复籍；禀冀州尤贫民，勿收今年更、租、口赋。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **阜陵王恢薨。** 夏五月戊寅，阜陵王恢去世。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **史官始作候风地动铜仪。** 秋七月，史官始作候风地动铜仪。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **以太学新成，试明经下第者补弟子，增甲、乙科员各十人。** 丙辰，以太学新成，试明经下第者补弟子，增甲、乙科员各十人。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **除郡国耆儒九十人补郎、舍人。** [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **诏郡国中都官系囚皆减死一等，亡命者赎，各有差。** 九月，诏郡国中都官系囚皆减死一等，亡命者赎，各有差。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **鲜卑寇辽东。** [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **望都、蒲阴狼杀女子九十七人，诏赐狼所杀者钱，人三千。** 冬十一月甲申，望都、蒲阴狼杀女子九十七人，诏赐狼所杀者钱，人三千。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **初令郡国举孝廉，限年四十以上，诸生通章句，文吏能笺奏，乃得应选。** 辛卯，初命各郡国举孝廉，限年四十以上，诸生通章句，文吏能笺奏，乃得应选；其有茂才异行，若颜渊、子奇，不拘年齿。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **东平王敞薨。** 十二月丁未，东平王敞去世。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **复置玄菟郡屯田六部。** 庚戌，复置玄菟郡屯田六部。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **闰月丁亥，令诸以诏除为郎，年四十以上课试如孝廉科者，得参廉选，岁举一人。** [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **客星出天苑。** 戊子，客星出天苑。 [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **诏曰“间者以来”。** 辛卯，诏曰：『间者以来，吏政不勤，故灾咎屡臻，盗贼多有。退省所由，皆以选举不实，官非其人，是以天心未得，人情多怨。《书》歌股肱，《诗》刺三事。今刺史、二千石之选，归任三司。其简序先后，精核高下，岁月之次，文武之宜，务存厥衷。』 [[26]](#hh-note-26)

<a id="hh-event-27"></a>

27. **恭陵百丈庑灾。** 庚子，恭陵百丈庑灾。 [[27]](#hh-note-27)

<a id="hh-event-28"></a>

28. **是岁，起西苑，修饰宫殿。** 当年，起西苑，修饰宫殿。 [[28]](#hh-note-28)

<a id="hh-event-29"></a>

29. **下邳王刘意八弟受封。** 刘意的八位弟弟分别获封乡侯或亭侯。 [[29]](#hh-note-29)

<a id="hh-event-30"></a>

30. **河间王刘政十三弟封亭侯。** 刘政十三弟各获亭侯。 [[30]](#hh-note-30)

<a id="hh-event-31"></a>

31. **张皓同年再任廷尉并卒。** 朝廷遣使吊祭，赐河南县葬地。 [[31]](#hh-note-31)

<a id="hh-event-32"></a>

32. **张衡造候风地动仪。** 张衡以铸铜制成候风地动仪，传文继述内部机关与据铜丸测方的形式。 [[32]](#hh-note-32)

<a id="hh-event-33"></a>

33. **太学告成并考试明经。** 朝廷将通过明经试者增补到太学，并按科分员。 [[33]](#hh-note-33)

<a id="hh-event-34"></a>

34. **玄菟设六部屯田。** 顺帝阳嘉元年，朝廷在玄菟郡编置六部屯田。 [[34]](#hh-note-34)

<a id="hh-event-35"></a>

35. **闰月戊子，客星气白，广二尺，长五丈，起天菀西南。** 阳嘉元年闰月戊子，客星气白，广二尺，长五丈，起天菀西南。 [[35]](#hh-note-35)

<a id="hh-event-36"></a>

36. **有司奏立长秋宫，以乘氏侯商先帝外戚，《春秋》之义，娶先大国，梁小贵人宜配天祚，正位坤极。** 阳嘉元年春，有司奏立长秋宫，以乘氏侯商先帝外戚，《春秋》之义，娶先大国，梁小贵人宜配天祚，正位坤极。 [[36]](#hh-note-36)

<a id="hh-event-37"></a>

37. **程病甚，即拜奉车都尉，位特进。** 阳嘉元年，程病甚，即拜奉车都尉，位特进。 [[37]](#hh-note-37)

<a id="hh-event-38"></a>

38. **徐由遣疏勒王臣盘发二万人击於窴。** 阳嘉元年，徐由遣疏勒王臣盘发二万人击于窴，破之，斩首数百级，放兵大掠，更立兴宗人成国为拘弥王而还。 [[38]](#hh-note-38)

<a id="hh-event-39"></a>

39. **耿晔遣乌桓亲汉都尉戎朱廆率众王侯咄归等。** 阳嘉元年冬，耿晔遣乌桓亲汉都尉戎朱廆率众王侯咄归等，出塞抄击鲜卑，大斩获而还，赐咄归等已下为率众王、侯、长，赐彩缯各有差。 [[39]](#hh-note-39)

<a id="hh-event-40"></a>

40. **顺帝阳嘉元年十月中，望都蒲阴狼杀童儿九十七人。** [[40]](#hh-note-40)

<a id="hh-event-41"></a>

41. **恭陵庑灾，及东西莫府火。** 阳嘉元年，恭陵庑灾，及东西莫府火。 [[41]](#hh-note-41)

<a id="sy-event-42"></a>

42. **湟中增置屯田五部。** 因湟中土地广，增置五部屯田，总数为十部。 [[42]](#sy-note-42)

[返回正文第32条](#hh-event-32)

<a id="hh059-l4348-e32"></a>

**[《后汉书·张衡列传》](../../sources/摘录/后汉书-卷059-张衡列传.md#p003)** · [仓内TXT L4348](../../sources/本地分卷/后汉书/后汉书-卷059.md#L4348)

> 陽嘉元年，復造候風地動儀。以精銅鑄成，員徑八尺，合蓋隆起，形似酒尊，飾以篆文山龜鳥獸之形。中有都柱，傍行八道，施關發機。外有八龍，首銜銅丸，下有蟾蜍，張口承之。其牙機巧制，皆隱在尊中，覆蓋周密無際。如有地動，尊則振龍機發吐丸，而蟾蜍銜之。振聲激揚，伺者因此覺知。雖一龍發機，而七首不動，尋其方面，乃知震之所在。驗之以事，合契若神。自書典所記，未之有也。嘗一龍機發而地不覺動，京師學者咸怪其無征，後數日驛至，果地震隴西，於是皆服其妙。

4. **复置陇西南部都尉官。** 夏四月，复置陇西南部都尉官。 [[4]](#hh-note-4)

5. **京师地震、洛阳地裂，顺帝求言，李固对策。** 四月己亥，京师地震。五月庚子，顺帝以地震下诏自责，令公卿直言政事得失。六月丁丑，洛阳宣德亭地裂长八十五丈，近郊也受影响。公卿因灾异举荐李固，顺帝召问时政弊端。 [[5]](#hh-note-5)

6. **王龚免司空，孔扶接任。** 司空王龚免，太常孔扶任司空。 [[6]](#hh-note-7)

<a id="hh-event-21"></a>

7. **疏勒臣磐献狮子与封牛。** 疏勒王臣磐派使者来献狮子和封牛。 [[7]](#hh-note-9)

8. **是月，旱。** [[8]](#hh-note-11)

9. **庞参免太尉，施延继任，耿晔领度辽。** 太尉庞参免职，大鸿胪施延继任，朝廷又迁度辽将军为太仆，以护乌桓校尉耿晔继为度辽将军。 [[9]](#hh-note-12)

<a id="hh-event-14"></a>

10. **鲜卑寇代郡。** [[10]](#hh-note-14)

<a id="hh-event-15"></a>

11. **行礼辟雍，奏应钟，始复黄钟，作乐器随月律。** 冬十月庚午，行礼辟雍，奏应钟，始复黄钟，作乐器随月律。 [[11]](#hh-note-15)

<a id="hh-event-16"></a>

12. **马融以敦朴对策，拜议郎。** 城门校尉岑起举马融敦厚质朴，朝廷对策后授官。 [[12]](#hh-note-16)

<a id="hh-event-18"></a>

13. **代来历爲大鸿胪，数日，迁爲太常。** 阳嘉二年，代来历爲大鸿胪，数日，迁爲太常。 [[13]](#hh-note-18)

<a id="hh-event-19"></a>

14. **封代兄便亲为勃遒亭侯。** 阳嘉二年，封代兄便亲为勃遒亭侯。 [[14]](#hh-note-19)

<a id="hh-event-20"></a>

15. **征拜太中大夫。** 阳嘉二年，征拜太中大夫。 [[15]](#hh-note-20)

<a id="sy-event-25"></a>

16. **青衣县更名汉嘉。** 蜀郡属国青衣县更名汉嘉。 [[16]](#sy-note-25)

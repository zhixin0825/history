# 公元134年｜阳嘉三年

[← 公元133年](ce-0133.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元135年 →](ce-0135.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **诏以久旱，京师诸狱无轻重皆且勿考竟，须得澍雨。** 三年春二月己丑，诏以久旱，京师诸狱无轻重皆且勿考竟，须得澍雨。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **益州盗贼劫质令长，杀列侯。** 三月庚戌，益州盗贼劫质令长，杀列侯。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **车师後部司马率後部王加特奴等掩击匈奴，大破之，获其季母。** 夏四月丙寅，车师后部司马率后部王加特奴等掩击匈奴，大破之，获其季母。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **制诏曰。** 五月戊戌，制诏曰：『昔我太宗，丕显之德，假于上下，俭以恤民，政致康乂。朕秉事不明，政失厥道，天地谴怒，大变仍见。春夏连旱，寇贼弥繁，元元被害，朕甚愍之。嘉与海内洗心更始。其颁布大赦，自殊死以下谋反大逆诸犯不当得赦者，皆赦除之。赐民年八十以上米，人一斛，肉二十斤，酒五斗；九十以上加赐帛，人二匹，絮三斤。』 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **钟羌寇陇西、汉阳。** 秋七月庚戌，钟羌寇陇西、汉阳。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **护羌校尉马续击破之。** 冬十月，护羌校尉马续将其击败。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **司徒刘崎、司空孔扶免。** 十一月壬寅，司徒刘崎、司空孔扶免。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **大司农南郡黄尚为司徒，光禄勳河东王卓为司空。** 乙巳，大司农南郡黄尚为司徒，光禄勳河东王卓为司空。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **武都塞上屯羌及外羌攻破屯官，驱略人畜。** 丙午，武都塞上屯羌及外羌攻破屯官，驱略人畜。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **左雄荐周举即任尚书。** 周举受荐入朝，后与黄琼主持政务，年内河南及三辅大旱。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **卒，谥曰义侯。** 阳嘉三年，卒，谥曰义侯。 [[11]](#hh-note-11)

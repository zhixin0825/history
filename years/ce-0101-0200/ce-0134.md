# 公元134年｜阳嘉三年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

<a id="hh-event-4"></a>

1. **久旱暂停审结京师狱案，顺帝颁赦赐老。** 旱情持续，顺帝令京师各狱暂不定案，等候及时雨。五月戊戌，顺帝下诏自责春夏连旱、寇贼增多，大赦天下，通常不赦的谋反、大逆等罪也在赦免之列。八十岁以上每人赐米一斛、肉二十斤、酒五斗，九十岁以上再赐帛二匹、絮三斤。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **益州盗贼劫质令长，杀列侯。** 三月庚戌，益州盗贼劫质令长，杀列侯。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **车师後部司马率後部王加特奴等掩击匈奴，大破之，获其季母。** 夏四月丙寅，车师后部司马率后部王加特奴等掩击匈奴，大破之，获其季母。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

<a id="hh-event-6"></a>

4. **钟羌犯陇西、汉阳，马续击破。** 钟羌进犯陇西、汉阳，护羌校尉马续击败来兵。 [[4]](#hh-note-5)

<a id="hh-event-7"></a>

<a id="hh-event-8"></a>

5. **刘崎、孔扶免，黄尚、王卓接任。** 司徒刘崎、司空孔扶免。大司农黄尚任司徒，光禄勋王卓任司空。 [[5]](#hh-note-7)

<a id="hh-event-9"></a>

6. **武都塞上屯羌及外羌攻破屯官，驱略人畜。** 丙午，武都塞上屯羌及外羌攻破屯官，驱略人畜。 [[6]](#hh-note-9)

<a id="hh-event-10"></a>

7. **左雄荐周举即任尚书。** 周举受荐入朝，后与黄琼主持政务，年内河南及三辅大旱。 [[7]](#hh-note-10)

<a id="hh-event-11"></a>

8. **卒，谥曰义侯。** 阳嘉三年，卒，谥曰义侯。 [[8]](#hh-note-11)

<a id="sy-event-12"></a>

9. **索县更名汉寿。** 武陵郡索县更名汉寿，《郡国志》在此县也标注刺史治所。 [[9]](#sy-note-12)

<a id="sgz-event-13"></a>

10. **疏勒王臣槃献海西青石、金带。** 疏勒王臣槃进献称来自海西的青石及金带各一。 [[10]](#sgz-note-13)

### 10. 疏勒王臣槃献海西青石、金带

[返回正文第10条](#sgz-event-13)

<a id="wei030-l135-9"></a>

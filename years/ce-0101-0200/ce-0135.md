# 公元135年｜阳嘉四年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **初听中官得以养子为後，世袭封爵。** 四年春二月丙子，初听中官得以养子为后，世袭封爵。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **自去冬旱，至於是月。** 自去冬旱，至于是月。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **谒者马贤击钟羌，大破之。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

<a id="hh-event-5"></a>

4. **施延免太尉，庞参复任，梁商进大将军。** 太尉施延免，前太尉庞参复任，执金吾梁商任大将军。 [[4]](#hh-note-4)

<a id="hh-event-6"></a>

5. **梁王匡薨。** 六月己未，梁王匡去世。 [[5]](#hh-note-6)

<a id="hh-event-7"></a>

6. **济北王登薨。** 秋七月己亥，济北王登去世。 [[6]](#hh-note-7)

<a id="hh-event-8"></a>

7. **闰月丁亥朔，日有食之。** 闰月丁亥朔，发生日食。 [[7]](#hh-note-8)

<a id="hh-event-9"></a>

<a id="hh-event-10"></a>

<a id="hh-event-12"></a>

8. **乌桓进犯云中，围耿晔于兰池，汉军赴援。** 十月，乌桓进犯云中，截掠商旅。度辽将军耿晔出兵争沙南，十一月被围于兰池，朝廷发诸郡兵救援，乌桓撤退。 [[8]](#hh-note-9)

<a id="hh-event-11"></a>

9. **京师地震。** 十二月甲寅，京师地震。 [[9]](#hh-note-11)

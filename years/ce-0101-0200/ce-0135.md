# 公元135年｜阳嘉四年

[← 公元134年](ce-0134.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元136年 →](ce-0136.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **初听中官得以养子为後，世袭封爵。** 四年春二月丙子，初听中官得以养子为后，世袭封爵。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **自去冬旱，至於是月。** 自去冬旱，至于是月。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **谒者马贤击钟羌，大破之。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **太尉施延免。** 夏四月甲子，太尉施延免。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **执金吾梁商为大将军，前太尉庞参为太尉。** 戊寅，执金吾梁商为大将军，前太尉庞参为太尉。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **梁王匡薨。** 六月己未，梁王匡去世。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **济北王登薨。** 秋七月己亥，济北王登去世。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **闰月丁亥朔，日有食之。** 闰月丁亥朔，发生日食。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **乌桓寇云中。** 冬十月，乌桓寇云中。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **围度辽将军耿晔於兰池，发诸郡兵救之，乌桓退走。** 十一月，围度辽将军耿晔于兰池，发诸郡兵救之，乌桓退走。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **京师地震。** 十二月甲寅，京师地震。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **耿晔与乌桓争沙南。** 乌桓截掠云中商旅，耿晔出击后被围于兰池，朝廷发兵救援。 [[12]](#hh-note-12)

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

<a id="hh-event-10"></a>

1. **夫余王入朝。** 夫余王入朝。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏曰“朕秉政不明”。** 乙卯，诏曰：『朕秉政不明，灾眚屡臻。典籍所忌，震食为重。今日变方远，地摇京师，咎徵不虚，必有所应。群公百僚其各上封事，指陈得失，靡有所讳。』 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **宗祀明堂，登灵台，改元永和，大赦天下。** 己巳，宗祀明堂，登灵台，改元永和，颁布大赦。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **偃师蝗。** 秋七月，偃师蝗。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

<a id="hh-event-17"></a>

5. **承福殿失火，顺帝避御云台。** 承福殿失火，顺帝避御云台。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

<a id="hh-event-8"></a>

6. **庞参罢太尉，王龚接任。** 太尉庞参罢，前司空王龚任太尉。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

<a id="hh-event-11"></a>

<a id="hh-event-14"></a>

7. **象林起事，武陵增税后另发兵变。** 象林部众起事。武陵太守以当地诸部已经归服、可比汉民为由奏请增租赋，武陵部众随后反抗。 [[7]](#hh-note-7)

<a id="hh-event-9"></a>

8. **顺帝召公卿问灾异。** 史记宫省恶灾异，顺帝在显亲殿召集朝臣，问周公葬礼以及灾变所由。 [[8]](#hh-note-9)

<a id="hh-event-12"></a>

9. **诏无忌与议郎黄景校定中书《五经》、诸子百家、艺术。** 永和元年，诏无忌与议郎黄景校定中书《五经》、诸子百家、艺术。 [[9]](#hh-note-12)

<a id="hh-event-13"></a>

10. **拜河南尹。** 永和元年，拜河南尹。 [[10]](#hh-note-13)

<a id="hh-event-15"></a>

<a id="hh-event-16"></a>

11. **耿晔以病召还，马续接任度辽。** 度辽将军耿晔因病被召回，护羌校尉马续接任。马贤继任护羌校尉。 [[11]](#hh-note-15)

<a id="sy-event-18"></a>

12. **置汉宁县。** 桂阳郡设置汉宁县。 [[12]](#sy-note-18)

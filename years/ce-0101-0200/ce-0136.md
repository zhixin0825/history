# 公元136年｜永和元年

[← 公元135年](ce-0135.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元137年 →](ce-0137.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **夫余王来朝。** 永和元年春正月，夫余王入朝觐见。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏曰“朕秉政不明”。** 乙卯，诏曰：『朕秉政不明，灾眚屡臻。典籍所忌，震食为重。今日变方远，地摇京师，咎徵不虚，必有所应。群公百僚其各上封事，指陈得失，靡有所讳。』 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **宗祀明堂，登灵台，改元永和，大赦天下。** 己巳，宗祀明堂，登灵台，改元永和，颁布大赦。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **偃师蝗。** 秋七月，偃师蝗。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **承福殿火，帝避御云台。** 冬十月丁亥，承福殿火，帝避御云台。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **太尉庞参罢。** 十一月丙子，太尉庞参罢。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **象林蛮夷叛。** 十二月，象林蛮夷叛。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **以前司空王龚为太尉。** 乙巳，以前司空王龚为太尉。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **顺帝召公卿问灾异。** 史记宫省恶灾异，顺帝在显亲殿召集朝臣，问周公葬礼以及灾变所由。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **夫余王入朝。** 夫余王入朝京师，顺帝以鼓吹、角抵戏接待。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **武陵加赋引发兵变。** 武陵太守建议增加租赋，虞诩反对，冬季澧中、漊中因贡布起兵。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **诏无忌与议郎黄景校定中书《五经》、诸子百家、艺术。** 永和元年，诏无忌与议郎黄景校定中书《五经》、诸子百家、艺术。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **拜河南尹。** 永和元年，拜河南尹。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **顺帝永和元年，武陵太守上书，以蛮夷率服，可比汉人，增其租赋。** [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **马续迁度辽将军，复以马贤代为校尉。** 永和元年，马续迁度辽将军，复以马贤代为校尉。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **晔病徵，以护羌校尉马续代为度辽将军。** 永和元年，晔病徵，以护羌校尉马续代为度辽将军。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **承福殿火。** 永和元年十月丁未，承福殿火。 [[17]](#hh-note-17)

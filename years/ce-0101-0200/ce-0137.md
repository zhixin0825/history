9. **九真、交址二郡兵反。** 秋七月，九真、交址二郡兵反。 [[9]](#hh-note-9)

10. **荧惑犯南斗。** 八月庚子，荧惑犯南斗。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **江夏盗贼杀邾长。** [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **行幸长安，所过鳏、寡、孤、独、贫不能自存者赐粟，人五斛。** 冬十月甲申，行前往长安，所过鳏、寡、孤、独、贫不能自存者赐粟，人五斛。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **幸未央宫，会三辅郡守、都尉及官属，劳赐作乐。** 庚子，幸未央宫，会三辅郡守、都尉及官属，劳赐作乐。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **祠高庙。** 十一月丙午，祠高庙。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **遂有事十一陵。** 丁未，遂有事十一陵。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **京师地震。** 丁卯，京师地震。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **至自长安。** 十二月乙亥，至自长安。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **太白昼见。** 永和二年五月戊申，太白昼见。 [[18]](#hh-note-18)

19. **发觉，并遣就国，减祖四分之一。** 永和二年，发觉，并遣就国，减祖四分之一。 [[19]](#hh-note-19)

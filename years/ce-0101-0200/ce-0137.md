1. **武陵部众围充县，李进击破。** 武陵部众围充县，又进犯夷道。武陵太守李进率军击破。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **广汉属国都尉击破白马羌。** 二月，广汉属国都尉击破白马羌。 [[2]](#hh-note-2)

<a id="hh-event-4"></a>

3. **北海王翼薨。** 三月辛亥，北海王翼去世。 [[3]](#hh-note-4)

<a id="hh-event-5"></a>

<a id="hh-event-6"></a>

4. **王卓去世，郭虔任司空。** 司空王卓去世，光禄勋郭虔继任。 [[4]](#hh-note-5)

<a id="hh-event-7"></a>

<a id="hh-event-16"></a>

<a id="hh-event-20"></a>

5. **京师年内两见地震。** 京师年内两次记有地震。 [[5]](#hh-note-7)

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

6. **岭南事起，日南郡府被攻，九真、交阯兵反。** 日南反叛者进攻郡府，九真、交阯两郡兵卒亦反叛。 [[6]](#hh-note-8)

<a id="hh-event-10"></a>

7. **荧惑犯南斗。** 八月庚子，荧惑犯南斗。 [[7]](#hh-note-10)

<a id="hh-event-11"></a>

8. **江夏盗贼杀邾长。** [[8]](#hh-note-11)

<a id="hh-event-12"></a>

<a id="hh-event-13"></a>

<a id="hh-event-14"></a>

<a id="hh-event-15"></a>

<a id="hh-event-17"></a>

9. **顺帝西巡长安，赐贫民粮并祭诸陵。** 顺帝西巡长安，沿途赐鳏寡孤独和不能存身的贫民各五斛粟。至未央宫召三辅郡守、都尉和属吏，宴赏作乐，祭高庙和十一陵，随后回宫。 [[9]](#hh-note-12)

<a id="hh-event-18"></a>

10. **太白昼见。** 永和二年五月戊申，太白昼见。 [[10]](#hh-note-18)

<a id="hh-event-19"></a>

11. **发觉，并遣就国，减祖四分之一。** 永和二年，发觉，并遣就国，减祖四分之一。 [[11]](#hh-note-19)

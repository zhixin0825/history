<a id="hh-event-3"></a>

3. **九江贼蔡伯流寇郡界，及广陵，杀江都长。** 夏四月，九江贼蔡伯流寇郡界，及广陵，杀江都长。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **遣光禄大夫案行金城、陇西，赐压死者年七岁以上钱，人二千。** 戊戌，遣光禄大夫案行金城、陇西，赐压死者年七岁以上钱，人二千；一家皆被害，为收敛之。 [[4]](#hh-note-4)

5. **除今年田租，尤甚者勿收口赋。** [[5]](#hh-note-5)

7. **京师地震。** 己酉，京师地震。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **吴郡丞羊珍反，攻郡府，太守王衡破斩之。** 五月，吴郡丞羊珍反，攻郡府，太守王衡破斩之。 [[8]](#hh-note-8)

<a id="hh-event-12"></a>

13. **光禄勳长沙刘寿为司徒。** 九月己酉，光禄勳长沙刘寿为司徒。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **令大将军、三公各举故刺史、二千石及见令、长、郎、谒者、四府掾属刚毅武猛有谋谟任将帅者各二人…。** 丙戌，令大将军、三公各举故刺史、二千石及见令、长、郎、谒者、四府掾属刚毅武猛有谋谟任将帅者各二人，特进、卿、校尉各一人。 [[14]](#hh-note-14)

<a id="hh-event-16"></a>

16. **日有食之。** 十二月戊戌朔，发生日食。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **左雄去世。** 左雄卒于任尚书之后。 [[17]](#hh-note-17)

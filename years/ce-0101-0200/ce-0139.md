# 公元139年｜永和四年

[← 公元138年](ce-0138.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元140年 →](ce-0140.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **中常侍张逵、蘧政、杨定等有罪诛，连及弘农太守张凤、安平相杨告，下狱死。** 四年春正月庚辰，中常侍张逵、蘧政、杨定等有罪诛，连及弘农太守张凤、安平相杨告，下狱后死亡。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **京师地震。** 三月乙亥，京师地震。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **护羌校尉马贤讨烧当羌，大破之。** 夏四月癸卯，护羌校尉马贤讨烧当羌，大破之。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **大赦天下。** 戊午，颁布大赦。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **赐民爵及粟、帛各有差。** [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **封故济北惠王寿子安为济北王。** 五月戊辰，封故济北惠王寿子安为济北王。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **太原郡旱，民庶流冗。** 秋八月，太原郡旱，民庶流冗。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **遣光禄大夫案行禀贷，除更赋。** 癸丑，遣光禄大夫案行禀贷，除更赋。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **校猎上林苑，历函谷关而还。** 冬十月戊午，校猎上林苑，历函谷关而还。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **幸广成苑。** 十一月丙寅，幸广成苑。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **刘安国封济北王。** 战乡侯刘安国入继济北王。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **张衡去世。** 张衡由河间相召还任尚书，后以六十二岁卒。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **荧惑入南斗犯第三星。** 《天文志》记四年七月壬午，荧惑入南斗犯第三星。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **中常侍张逵、蘧政，内者令石光，尚方令傅福，冗从仆射杜永连谋，共谮商及中常侍曹腾、孟贲，云欲…。** 永和四年，中常侍张逵、蘧政，内者令石光，尚方令傅福，冗从仆射杜永连谋，共谮商及中常侍曹腾、孟贲，云欲征诸王子，图议废立，请收商等案罪。 [[14]](#hh-note-14)

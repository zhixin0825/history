3. **句龙吾斯、车纽围美稷并联合乌桓，汉军进讨。** 南匈奴左部句龙吾斯、车纽叛，围美稷。度辽将军马续击破其军，使匈奴中郎将陈龟随后迫杀南单于。句龙吾斯等又东引乌桓阿坚、羌渠，西收羌胡，犯上郡，立车纽为单于。使匈奴中郎将张耽击破来军，车纽及余部归降。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

4. **己亚晦，日有食之。** 己亚晦，发生日食。 [[4]](#hh-note-5)

5. **且冻羌犯三辅武都，朝廷修陇道防御。** 且冻羌进犯三辅，杀令长，又寇武都、焚陇关。朝廷令扶风、汉阳筑陇道坞壁三百处，派兵屯守，并任马贤为征西将军。 [[5]](#hh-note-6)

<a id="hh-event-7"></a>

6. **令死罪以下及亡命赎，各有差。** 丁丑，令死罪以下及亡命赎，各有差。 [[6]](#hh-note-7)

7. **王龚罢太尉，桓焉继任。** 太尉王龚罢，太常桓焉继任。 [[7]](#hh-note-9)

<a id="hh-event-12"></a>

8. **徙西河郡居离石，上郡居夏阳，朔方居五原。** 丁亥，徙西河郡居离石，上郡居夏阳，朔方居五原。 [[8]](#hh-note-12)

<a id="hh-event-17"></a>

9. **太白昼见。** 五年四月戊午，太白昼见。 [[9]](#hh-note-17)

<a id="hh-event-18"></a>

10. **荧惑入太微。** 八月己酉，荧惑入太微。 [[10]](#hh-note-18)

<a id="hh-event-19"></a>

11. **河南尹的编户与人口。** 河南尹有二十万八千四百八十六户、一百零一万零八百二十七人。 [[11]](#hh-note-19)

<a id="hh-event-21"></a>

12. **封据弟三人为乡侯。** 永和五年，封据弟三人为乡侯。 [[12]](#hh-note-21)

<a id="hh-event-22"></a>

13. **徵拜将作大匠。** 永和五年，徵拜将作大匠。 [[13]](#hh-note-22)

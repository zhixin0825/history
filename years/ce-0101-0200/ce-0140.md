1. **京师地震。** 五年春二月戊申，京师地震。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **中山王弘薨。** 夏四月庚子，中山王弘去世。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **南匈奴左部句龙大人吾斯、车纽等叛，围美稷。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **度辽将军马续讨吾斯、车纽，破之，使匈奴中郎将陈龟迫杀南单于。** 五月，度辽将军马续讨吾斯、车纽，破之，使匈奴中郎将陈龟迫杀南单于。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **己亚晦，日有食之。** 己亚晦，发生日食。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **且冻羌寇三辅，杀令长。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **令死罪以下及亡命赎，各有差。** 丁丑，令死罪以下及亡命赎，各有差。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **令扶风、汉阳筑陇道坞三百所，置屯兵。** 九月，令扶风、汉阳筑陇道坞三百所，置屯兵。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **太尉王龚罢。** 辛未，太尉王龚罢。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **且冻羌寇武都，烧陇关。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **太常桓焉为太尉。** 壬午，太常桓焉为太尉。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **徙西河郡居离石，上郡居夏阳，朔方居五原。** 丁亥，徙西河郡居离石，上郡居夏阳，朔方居五原。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **句龙吾斯等东引乌桓，西收羌胡，寇上郡，立车纽为单于。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **遣使匈奴中郎将张耽击破之，车纽降。** 冬十一月辛巳，遣使匈奴中郎将张耽将其击败，车纽降。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **陈龟拜使匈奴中郎将。** 陈龟由五原太守升任使匈奴中郎将。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **马贤任征西将军。** 且冻、傅难等部进攻金城，朝廷任马贤为征西将军，耿叔为副。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **太白昼见。** 《天文志》记五年四月戊午，太白昼见。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **荧惑入太微。** 《天文志》记八月己酉，荧惑入太微。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **永和五年河南尹编户。** 《郡国志》以永和五年记河南尹的户数、人口。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **代王龚爲太尉。** 永和五年，代王龚爲太尉。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **封据弟三人为乡侯。** 永和五年，封据弟三人为乡侯。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **徵拜将作大匠。** 永和五年，徵拜将作大匠。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **乌桓大人阿坚、羌渠等与南匈奴左部句龙吾斯反畔，中郎将张耽击破斩之，余众悉降。** 永和五年，乌桓大人阿坚、羌渠等与南匈奴左部句龙吾斯反畔，中郎将张耽击破斩之，余众悉降。 [[23]](#hh-note-23)

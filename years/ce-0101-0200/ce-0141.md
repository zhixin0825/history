1. **马贤战死，赵冲破羌，朝廷迁郡治并屯三辅。** 征西将军马贤战且冻羌于射姑山，兵败身死，安定太守郭璜下狱死。闰月，巩唐羌犯陇西及三辅，被武威太守赵冲击破，后又寇北地，诸羌也侵犯武威。朝廷迁安定郡治于扶风、北地郡治于冯翊，命执金吾张乔行车骑将军事，领兵屯三辅。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏贷王、侯国租一岁。** [[2]](#hh-note-2)

<a id="hh-event-4"></a>

<a id="hh-event-18"></a>

<a id="hh-event-19"></a>

3. **东方彗星行经营室及奎。** 东方见青白彗星，长六七尺，向西南指营室和坟墓，又在奎宿一度见长约六尺。 [[3]](#hh-note-4)

<a id="hh-event-6"></a>

<a id="hh-event-8"></a>

4. **郭虔免司空，赵戒继任。** 司空郭虔免，太仆赵戒继任。 [[4]](#hh-note-6)

<a id="hh-event-7"></a>

5. **河间王政薨。** 乙巳，河间王政去世。 [[5]](#hh-note-7)

<a id="hh-event-9"></a>

6. **齐王无忌薨。** 夏五月庚子，齐王无忌去世。 [[6]](#hh-note-9)

<a id="hh-event-10"></a>

7. **使匈奴中郎将张耽大破乌桓、羌胡於天山。** 使匈奴中郎将张耽大破乌桓、羌胡于天山。 [[7]](#hh-note-10)

<a id="hh-event-12"></a>

8. **诏假民有赀者户钱一千。** 秋七月甲午，诏假民有赀者户钱一千。 [[8]](#hh-note-12)

<a id="hh-event-13"></a>

9. **大将军梁商薨。** 八月丙辰，大将军梁商薨；壬戌，河南尹梁冀为大将军。 [[9]](#hh-note-13)

<a id="hh-event-15"></a>

10. **日有食之。** 辛亥晦，发生日食。 [[10]](#hh-note-15)

<a id="hh-event-20"></a>

11. **封畅弟荆为南乡侯。** 永和六年，封畅弟荆为南乡侯。 [[11]](#hh-note-20)

> 永和六年，西羌大寇三輔，圍安定，征西將軍馬賢將諸郡兵擊之，不能克。規雖在布衣，見賢不恤軍事，審其必敗，乃上書言狀。尋而賢果為羌所沒。郡將知規有兵略，乃命為功曹，使率甲士八百，與羌交戰，斬首數級，賊遂退卻。

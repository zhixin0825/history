1. **宗祀明堂，大赦天下，改元汉安。** 汉安元年春正月癸巳，宗祀明堂，颁布大赦，改元汉安。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏大将军、公、卿举贤良方正、能探赜索隐者各一人。** 二月丙辰，诏大将军、公、卿举贤良方正、能探赜索隐者各一人。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **始置承华厩。** 秋七月，始置承华厩。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

<a id="hh-event-16"></a>

4. **句龙吾斯等复犯并部。** 南匈奴左部首领句龙吾斯、薁鞬台耆与且渠伯德等又叛，进犯并部。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

<a id="hh-event-6"></a>

<a id="hh-event-11"></a>

5. **遣八使巡州郡，张纲任广陵太守并招降张婴。** 顺帝遣杜乔、周举、郭遵、冯羡、栾巴、张纲、周栩、刘班分行州郡。广陵张婴等攻掠郡县，本年到太守张纲处归降。 [[5]](#hh-note-5)

<a id="hh-event-7"></a>

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

<a id="hh-event-13"></a>

6. **桓焉、刘寿等去职，赵峻、胡广继任。** 太尉桓焉、司徒刘寿免职，行车骑将军事的张乔亦罢，司隶校尉赵峻任太尉，大司农胡广任司徒。 [[6]](#hh-note-7)

<a id="hh-event-10"></a>

7. **诏大将军、三公选武猛试用有效验任为将校者各一人。** 癸卯，诏大将军、三公选武猛试用有效验任为将校者各一人。 [[7]](#hh-note-10)

<a id="hh-event-12"></a>

8. **顺帝特下诏告河南尹曰。** 汉安元年，顺帝特下诏告河南尹曰：「故长陵令张楷行慕原宪，操拟夷、齐，轻贵乐贱，窜迹幽薮，高志确然，独拔腢俗。前比征命，盘桓未至，将主者翫习于常，优贤不足，使其难进欤？郡时以礼发遣。」 [[8]](#hh-note-12)

<a id="hh-event-14"></a>

9. **进补大司农，左转太中大夫，卒於官。** 汉安元年，进补大司农，左转太中大夫，卒于官。 [[9]](#hh-note-14)

<a id="hh-event-15"></a>

10. **以赵冲为护羌校尉。** 汉安元年，以赵冲为护羌校尉。 [[10]](#hh-note-15)

<a id="hh-event-17"></a>

11. **雒阳刘汉等百九十七家为火所烧，後四年，宫车比三晏驾，建和元年君位乃定。** 汉安元年三月甲午，雒阳刘汉等百九十七家为火所烧，后四年，宫车比三晏驾，建和元年君位乃定。 [[11]](#hh-note-17)

> 漢安元年拜光祿大夫與侍中杜喬等八人同日受詔持節分出案行天下貪廉墨綬有罪便収刺史二千石以驛表聞威惠清忠名振郡國號曰八雋是時大將軍梁冀侵擾百姓喬等七人皆奉命四出唯綱獨埋車輪於洛陽都亭不去曰豺狼當路安問狐貍遂上書曰大將軍梁冀河南尹不疑䝉外戚之援荷國厚恩以芻蕘之姿安居阿保不能敷揚五教翼贊日月而專為封豕長蛇肆其貪饕甘心好貨縱恣無厭多樹謟諛以害忠良誠天威所不赦大辟所宜加也謹條其無君之心十五事於左皆忠臣之所切齒也書奏御京師震悚時冀妹為皇后内寵方盛冀兄弟權重於人主順帝雖知綱言不誣然無心治冀冀深恨綱

<a id="sgz045-p-003-7"></a>

**[《三国志·邓张宗杨传》裴注 003·7](../../sources/本地分卷/三国志/三国志-卷045.md#pei-003-7)**

> 㑹廣陵賊張嬰等衆數萬人殺刺史二千石冀欲䧟綱乃諷尚書以綱為廣陵太守若不為嬰所殺則欲以法中之前太守往輒多請兵及綱受拜詔問當得兵馬幾何綱對曰無用兵馬遂單車之官徑詣嬰壘門示以禍福嬰大驚懼走欲閉門綱又於門外罷遣吏兵留所親者十餘人以書語其長老素為嬰所信者請與相見問以本變因示以詔恩使還請嬰嬰見綱意誠即出見綱綱延置上坐問其疾苦禮畢乃謂之曰前後二千石多非其人杜塞國恩肆其私求鄉郡逺天子不能朝夕聞也故民人相聚以避害二千石信有罪矣為之者乃非義也忠臣不欺君以自榮孝子不捐父以求福天子聖人欲文徳以來之故使太守來思以爵祿相榮不願以刑也今誠轉禍為福之時也若聞義不服天子赫然發怒大兵雲合豈不危乎宜深計其利害嬰聞泣曰荒裔愚人數為二千石所侵枉不堪其困故遂相聚偷生明府仁及草木乃嬰等更生之澤但恐投兵之日不免孥戮耳綱曰豈其然乎要之以天地誓之以日月方當相顯以爵位何禍之有乎嬰曰茍赦其罪得全首領以就農畆則抱戴没齒爵祿非所望也嬰雖為大賊起於狂暴自以為必死及得綱言曠然開明乃辭還營

**释读** 梁冀想借张婴陷害张纲，让他当广陵太守。张纲不用军队，单车到张婴营，先退吏兵，再和张婴谈当地官吏侵害、朝廷可赦的情由。

**归年** 《后汉书·顺帝纪》汉安元年广陵张婴降，张纲交涉始末附于该役。

<a id="sgz045-p-003-8"></a>

**[《三国志·邓张宗杨传》裴注 003·8](../../sources/本地分卷/三国志/三国志-卷045.md#pei-003-8)**

> 明日遂將所部萬餘人與妻子面〔四库字图3511〕詣綱降綱悉釋〔四库字图3511〕慰納謂嬰曰卿諸人一旦解散方垂盪然當條名上之必受封賞嬰曰乞歸故業不願以穢名汙眀時也綱以其至誠乃各從其意親為安處居宅子弟欲為吏者隨才任職欲為民者勸以農桑田業並豐南州晏然

**释读** 张婴次日携万余人及妻儿面缚而降。张纲解绑慰纳，准其归业，为当地安居授职，南州得宁。

**归年** 《后汉书·顺帝纪》汉安元年所记投降；“面”后一字四库图字3511，与点校“縛”对。

# 公元142年｜汉安元年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **宗祀明堂，大赦天下，改元汉安。** 汉安元年春正月癸巳，宗祀明堂，颁布大赦，改元汉安。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏大将军、公、卿举贤良方正、能探赜索隐者各一人。** 二月丙辰，诏大将军、公、卿举贤良方正、能探赜索隐者各一人。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **始置承华厩。** 秋七月，始置承华厩。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **南匈奴左部大人句龙吾斯与薁鞬台耆等反叛。** 八月，南匈奴左部大人句龙吾斯与薁鞬台耆等反叛。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **遣侍中杜乔，光禄大夫周举，守光禄大夫郭遵、冯羡、栾巴、张纲、周栩、刘班等八人分行州、郡，班…。** 丁卯，遣侍中杜乔，光禄大夫周举，守光禄大夫郭遵、冯羡、栾巴、张纲、周栩、刘班等八人分行州、郡，班宣风化，举实臧否。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **广陵盗贼张婴等寇郡县。** 九月庚寅，广陵盗贼张婴等寇郡县。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **太尉桓焉、司徒刘寿免。** 冬十月辛未，太尉桓焉、司徒刘寿免。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **行车骑将军张乔罢。** 甲戌，行车骑将军张乔罢。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **司隶校尉赵峻为太尉，大司农胡广为司徒。** 十一月壬午，司隶校尉赵峻为太尉，大司农胡广为司徒。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **诏大将军、三公选武猛试用有效验任为将校者各一人。** 癸卯，诏大将军、三公选武猛试用有效验任为将校者各一人。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **是岁，广陵贼张婴等诣太守张纲降。** 当年，广陵贼张婴等到太守张纲降。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **顺帝特下诏告河南尹曰。** 汉安元年，顺帝特下诏告河南尹曰：「故长陵令张楷行慕原宪，操拟夷、齐，轻贵乐贱，窜迹幽薮，高志确然，独拔腢俗。前比征命，盘桓未至，将主者翫习于常，优贤不足，使其难进欤？郡时以礼发遣。」 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **以日食免。** 汉安元年，以日食免。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **进补大司农，左转太中大夫，卒於官。** 汉安元年，进补大司农，左转太中大夫，卒于官。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **以赵冲为护羌校尉。** 汉安元年，以赵冲为护羌校尉。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **吾斯与薁鞮台耆、且渠伯德等复掠并部。** 汉安元年秋，吾斯与薁鞮台耆、且渠伯德等复掠并部。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **雒阳刘汉等百九十七家为火所烧，後四年，宫车比三晏驾，建和元年君位乃定。** 汉安元年三月甲午，雒阳刘汉等百九十七家为火所烧，后四年，宫车比三晏驾，建和元年君位乃定。 [[17]](#hh-note-17)

# 公元143年｜汉安二年

[← 公元142年](ce-0142.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元144年 →](ce-0144.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **鄯善国遣使贡献。** 二年春二月丙辰，鄯善国遣使贡献。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-8"></a>

2. **赵冲等在参栾、阿阳破羌。** 护羌校尉赵冲与汉阳太守张贡在参栾击破烧何羌。闰月，赵冲又在阿阳击破烧当羌。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-15"></a>

3. **荧惑光芒犯镇星。** 荧惑与镇星接近，光芒相犯。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

<a id="hh-event-9"></a>

4. **立兜楼储为南单于，马寔遣人诛句龙吾斯。** 朝廷立守义王兜楼储为南匈奴单于。使匈奴中郎将马寔遣人刺杀句龙吾斯。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **令郡国中都官系囚殊死以下出缣赎，各有差。** 冬十月辛丑，命各郡国中都官系囚殊死以下出缣赎，各有差；其不能入赎者，遣到临羌县居作二岁。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **减百官奉。** 甲辰，减百官奉。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **禁沽酒，又贷王、侯国租一岁。** 丙午，禁沽酒，又贷王、侯国租一岁。 [[7]](#hh-note-7)

<a id="hh-event-10"></a>

8. **杨、徐盗贼攻烧城寺，杀略吏民。** 十二月，杨、徐盗贼攻烧城寺，杀略吏民。 [[8]](#hh-note-10)

<a id="hh-event-11"></a>

9. **是岁，凉州地百八十震。** 当年，凉州地百八十震。 [[9]](#hh-note-11)

<a id="hh-event-12"></a>

10. **曹娥投江。** 曹盱五月五日在县江溺死，曹娥沿江找寻父亲，后投江而死。 [[10]](#hh-note-12)

<a id="hh-event-13"></a>

11. **太白昼见。** 汉安二年正月己亥，太白昼见。 [[11]](#hh-note-13)

<a id="hh-event-14"></a>

12. **辰星犯舆鬼。** 五月丁亥，辰星犯舆鬼。 [[12]](#hh-note-14)

<a id="hh-event-16"></a>

13. **太白昼见。** 七月甲申，太白昼见。 [[13]](#hh-note-16)

<a id="hh-event-17"></a>

14. **转大鸿胪。** 汉安二年，转大鸿胪。 [[14]](#hh-note-17)

<a id="hh-event-18"></a>

15. **尚书侍郎边韶上奏论历。** 尚书侍郎边韶上奏，叙汉武帝命司马迁、邓平等订太初历、刘歆推演九道，以及章帝改用四分历的经过，论及时历推算与日月观测不合。 [[15]](#hh-note-18)

### 15. 尚书侍郎边韶上奏论历

[返回正文第15条](#hh-event-18)

<a id="hh092-l6839-e18"></a>

**[《后汉书·律历志中》](../../sources/摘录/后汉书-卷092-律历志中.md#p002)** · [仓内TXT L6839](../../sources/本地分卷/后汉书/后汉书-卷092.md#L6839)

> 順帝漢安二年，尚書侍郎邊韶上言：「世微於數虧，道盛於得常。數虧則物衰，得常則國昌。孝武皇帝攄發聖思，因元封七年十一月甲子朔旦冬至，乃詔太史令司馬遷、治歷鄧平等更建太初，改元易朔，行夏之正，干鑿度八十分之四十三為日法。設清台之候，驗六異，課效觕密，太初為最。其後劉歆研機極深，驗之春秋，參以易道，以河圖帝覽嬉、雒書曜度推廣九道，百七十一歲進退六十三分，百四十四歲一超次，與天相應，少有闕謬。從太初至永平十一年，百七十歲，進退余分六十三，治歷者不知處之。推得十二度弦望不效，挾廢術者得竄其說。至和二年，小終之數寖過，余分稍增，月不用晦朔而先見。孝章皇帝以保干圖『三百年斗歷改憲』，就用四分。以太白復樞甲子為癸亥，引天從筭，耦之目前。更以庚申為元，既無明文；

**归年与互校** 本志原载年号。志文的占验解释见原卷上下文。

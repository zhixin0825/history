# 公元144年｜建康元年

<a id="hh-event-1"></a>

1. **诏曰“陇西、汉阳、张掖、北地、武威、武”。** 建康元年正月辛丑，诏曰：『陇西、汉阳、张掖、北地、武威、武都，自去年九月已来，地百八十震，山谷坼裂，坏败城寺，杀害民庶。夷狄叛逆，赋役重数，内外怨旷，惟咎叹息。其遣光禄大夫案行，宣畅恩泽，惠此下民，勿为烦扰。』 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **沛王广薨。** 三月庚子，沛王广去世。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **领护羌校尉卫琚追讨叛羌，破之。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **南郡、江夏盗贼寇掠城邑，州郡讨平之。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **使匈奴中郎将马寔击南匈奴左部，破之，於是胡羌、乌桓悉诣寔降。** 夏四月，使匈奴中郎将马寔击南匈奴左部，破之，于是胡羌、乌桓悉到寔降。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **立皇子炳为皇太子，改年建康，大赦天下。** 辛巳，立皇子炳为皇太子，改年建康，颁布大赦。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **赐人爵各有差。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **清河王延平薨。** 秋七月丙午，清河王延平去世。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **杨、徐盗贼范容、周生等寇掠城邑，遣御史中丞冯赦督州郡兵讨之。** 八月，杨、徐盗贼范容、周生等寇掠城邑，遣御史中丞冯赦督州郡兵讨之。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **顺帝崩于玉堂前殿。** 庚午，皇帝在玉堂前殿去世，时年三十。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **遗诏无起寝庙，敛以故服，珠玉玩好皆不得下。** [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **冲帝即位，梁太后临朝。** 建康元年，立为皇太子，其年八月庚午，即皇帝位，年二岁。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **尊皇后曰皇太后。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **太后临朝。** [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **以太尉赵峻为太傅。** 丁丑，以太尉赵峻为太傅；大司农李固为太尉，参录尚书事。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **葬孝顺皇帝於宪陵，庙曰敬宗。** 九月丙午，葬孝顺皇帝于宪陵，庙曰敬宗。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **是日，京师及太原、鴈门地震，三郡水涌土裂。** [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **诏三公、特进、侯、卿、校尉，举贤良方正、幽逸修道之士各一人，百僚皆上封事。** 庚戌，诏三公、特进、侯、卿、校尉，举贤良方正、幽逸修道之士各一人，百僚皆上封事。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **九江太守丘腾有罪，下狱死。** 己未，九江太守丘腾有罪，下狱后死亡。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **杨州刺史尹耀、九江太守邓显讨贼范容等於历阳，军败，耀、显为贼所殁。** 杨州刺史尹耀、九江太守邓显讨贼范容等于历阳，军败，耀、显为贼所殁。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **日南蛮夷攻烧城邑，交址刺史夏方招诱降之。** 冬十月，日南蛮夷攻烧城邑，交址刺史夏方招诱降服。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **常山王仪薨。** 壬申，常山王仪去世。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **零陵太守刘康坐杀无辜，下狱死。** 己卯，零陵太守刘康坐杀无辜，下狱后死亡。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **九江盗贼徐凤、马勉等称。** 十一月，九江盗贼徐凤、马勉等称『无上将军』，攻烧城邑。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **令郡国中都官系囚减死一等，徙边。** 己酉，命各郡国中都官系囚减死一等，徙边；谋反大逆，不用此令。 [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **九江贼黄虎等攻合肥。** 十二月，九江贼黄虎等攻合肥。 [[26]](#hh-note-26)

<a id="hh-event-27"></a>

27. **是岁，群盗发宪陵。** 当年，群盗发宪陵。 [[27]](#hh-note-27)

<a id="hh-event-28"></a>

28. **护羌校尉赵冲追击叛羌於鸇阴河，战殁。** 护羌校尉赵冲追击叛羌于鸇阴河，战殁。 [[28]](#hh-note-28)

<a id="hh-event-29"></a>

29. **赵冲遇伏战死。** 赵冲在亶阴河一带追击叛走部众，遇伏身死。 [[29]](#hh-note-29)

<a id="hh-event-30"></a>

30. **梁後称制，章自免，卒於家。** 建康元年，梁后称制，章自免，卒于家。 [[30]](#hh-note-30)

<a id="hh-event-31"></a>

31. **九江范容、周生等相聚反乱，屯据历阳，为江淮巨患，遣御史中丞冯绲将兵督扬州刺史尹燿、九江太守…。** 建康元年，九江范容、周生等相聚反乱，屯据历阳，为江淮巨患，遣御史中丞冯绲将兵督扬州刺史尹燿、九江太守邓显讨之。 [[31]](#hh-note-31)

<a id="hh-event-32"></a>

32. **护羌从事马玄遂为诸羌所诱，将羌众亡出塞。** 建康元年春，护羌从事马玄遂为诸羌所诱，将羌众亡出塞。 [[32]](#hh-note-32)

<a id="hh-event-33"></a>

33. **进击余党，斩首千二百级。** 建康元年，进击余党，斩首千二百级。 [[33]](#hh-note-33)

<a id="sgz-event-34"></a>

34. **《续汉书》记张纲病卒，张婴等服丧。** 《续汉书》说张纲在任上病卒，年三十六，张婴等三百余人送丧至洛阳，立祠祭祀，皇帝命其一子为郎。 [[34]](#sgz-note-34)

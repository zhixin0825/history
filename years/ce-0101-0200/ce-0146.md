[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **诏曰“昔尧命四子”。** 本初元年春正月丙申，诏曰：『昔尧命四子，以钦天道，《鸿范》九畴，休咎有象。夫瑞以和降，异因逆感，禁微应大，前圣所重。顷者，州郡轻慢宪防，竞逞残暴，造设科条，陷入无罪。或以喜怒驱逐长吏，恩阿所私，罚枉雠隙，至令守阙诉讼，前后不绝。送故迎新，人离其害，怨气伤和，以致灾眚。《书》云：「明德慎罚。」方春东作，育微敬始。其勑有司，罪非殊死，且勿案验，以崇在宽。』 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **广陵太守王喜坐讨贼逗留，下狱死。** 壬子，广陵太守王喜坐讨贼逗留，下狱后死亡。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **诏曰“九江、广陵二郡数离寇害”。** 二月庚辰，诏曰：『九江、广陵二郡数离寇害，残夷最甚。生者失其资业。死者委屍原野。昔之为政，一物不得其所，若己为之，况我元元，婴此困毒。方春戒节，赈济乏戹，掩骼埋胔之时。其调比郡见谷，出禀穷弱，收葬枯骸，务加埋恤，以称朕意。』 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **令郡国举明经，年五十以上、七十以上诣太学。** 夏四月庚辰，命各郡国举明经，年五十以上、七十以上到太学。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **自大将军至六百石，皆遣子受业，岁满课试，以高第五人补郎中，次五人太子舍人。** [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **又千石、六百石、四府掾属、三署郎、四姓小侯先能通经者，各令随家法，其高第者上名牒，当以次赏进。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

8. **海水溢。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

<a id="hh-event-10"></a>

10. **太白犯荧惑。** 庚戌，太白犯荧惑。 [[10]](#hh-note-10)

<a id="hh-event-12"></a>

17. **会质帝崩，太后遂与兄大将军冀定策禁中，闰月庚寅，使冀持节，以王青盖车迎帝入南宫，其日即皇帝…。** 会质帝崩，太后遂与兄大将军冀定策禁中，闰月庚寅，使冀持节，以王青盖车迎帝入南宫，其日即皇帝位，时年十五。 [[17]](#hh-note-17)

22. **诏曰“孝廉、廉吏皆当典城牧民”。** 丙戌，诏曰：『孝廉、廉吏皆当典城牧民，禁奸举善，兴化之本，恒必由之。诏书连下，分明恳恻，而在所翫习，遂至怠慢，选举乖错，害及元元。顷虽颇绳正，犹未惩改。方今淮夷未殄，军师屡出，百姓疲悴，困于徵发。庶望群吏，惠我劳民，蠲涤贪秽，以祈休祥。其令秩满百石，十岁以上，有殊才异行，乃得参选。臧吏子孙，不得察举。杜绝邪伪请托之原。令廉白守道者得信其操。各明守所司，将观厥后。』 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **追尊皇祖河间孝王曰孝穆皇，夫人赵氏曰孝穆皇后，皇考蠡吾侯曰孝崇皇。** 九月戊戌，追尊皇祖河间孝王曰孝穆皇，夫人赵氏曰孝穆皇后，皇考蠡吾侯曰孝崇皇。 [[23]](#hh-note-23)

<a id="hh-event-29"></a>

29. **封乾一子为亭侯。** 本初元年，封乾一子为亭侯。 [[29]](#hh-note-29)

<a id="hh-event-30"></a>

30. **梁太后诏备古礼以聘厚，遂辞疾不就。** 本初元年，梁太后诏备古礼以聘厚，遂辞疾不就。 [[30]](#hh-note-30)

<a id="hh-event-31"></a>

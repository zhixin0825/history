## 本年概述

本初元年，梁冀毒杀质帝，梁太后与梁冀定策迎蠡吾侯刘志即位，太后仍掌朝政。朝廷招通经士人进太学，对高官子弟行课试。乐安、北海遭海水漫溢，朝廷遣使收葬死者，赈济贫弱。

3. **质帝遇鸩，桓帝继位，梁太后仍临朝。** 闰月甲申，大将军梁冀暗下毒，质帝死于玉堂前殿，年九岁。太尉李固被免，司徒胡广任太尉，司空赵戒任司徒，同梁冀参录尚书事；太仆袁汤任司空。梁太后与梁冀在禁中定策，闰月庚寅，命梁冀持节以青盖王车迎刘志入南宫，当日由蠡吾侯即皇帝位。梁太后仍临朝，质帝葬静陵。桓帝谒高庙、光武庙，追尊祖父河间孝王为孝穆皇，夫人赵氏为孝穆皇后，父蠡吾侯为孝崇皇，尊母匽氏为孝崇博园贵人。 [[3]](#hh-note-12)

## 吏治、察举与太学

<a id="hh-event-1"></a>

10. **诏曰“昔尧命四子”。** 本初元年春正月丙申，诏曰：『昔尧命四子，以钦天道，《鸿范》九畴，休咎有象。夫瑞以和降，异因逆感，禁微应大，前圣所重。顷者，州郡轻慢宪防，竞逞残暴，造设科条，陷入无罪。或以喜怒驱逐长吏，恩阿所私，罚枉雠隙，至令守阙诉讼，前后不绝。送故迎新，人离其害，怨气伤和，以致灾眚。《书》云：「明德慎罚。」方春东作，育微敬始。其勑有司，罪非殊死，且勿案验，以崇在宽。』 [[10]](#hh-note-1)

<a id="hh-event-2"></a>

11. **广陵太守王喜坐讨贼逗留，下狱死。** 壬子，广陵太守王喜坐讨贼逗留，下狱后死亡。 [[11]](#hh-note-2)

<a id="hh-event-3"></a>

12. **诏曰“九江、广陵二郡数离寇害”。** 二月庚辰，诏曰：『九江、广陵二郡数离寇害，残夷最甚。生者失其资业。死者委屍原野。昔之为政，一物不得其所，若己为之，况我元元，婴此困毒。方春戒节，赈济乏戹，掩骼埋胔之时。其调比郡见谷，出禀穷弱，收葬枯骸，务加埋恤，以称朕意。』 [[12]](#hh-note-3)

<a id="hh-event-4"></a>

<a id="hh-event-5"></a>

<a id="hh-event-6"></a>

13. **广招明经，令高官遣子就学课试。** 郡国举五十岁以上及七十岁以上通经者赴太学。大将军以下至六百石官皆遣子受学，岁满课试，前五名补郎中、次五名补太子舍人。千石、六百石、四府掾属、三署郎及四姓小侯中能通经者按家法学习，高第上名，依次进用。 [[13]](#hh-note-4)

<a id="hh-event-22"></a>

14. **诏曰“孝廉、廉吏皆当典城牧民”。** 丙戌，诏曰：『孝廉、廉吏皆当典城牧民，禁奸举善，兴化之本，恒必由之。诏书连下，分明恳恻，而在所翫习，遂至怠慢，选举乖错，害及元元。顷虽颇绳正，犹未惩改。方今淮夷未殄，军师屡出，百姓疲悴，困于徵发。庶望群吏，惠我劳民，蠲涤贪秽，以祈休祥。其令秩满百石，十岁以上，有殊才异行，乃得参选。臧吏子孙，不得察举。杜绝邪伪请托之原。令廉白守道者得信其操。各明守所司，将观厥后。』 [[14]](#hh-note-22)

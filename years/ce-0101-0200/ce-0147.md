<a id="hh-event-1"></a>

1. **日有食之。** 建和元年春正月辛亥朔，发生日食。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏三公、九卿、校尉各言得失。** [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **大赦天下。** 戊午，颁布大赦。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **赐吏更劳一岁。** 赐吏更劳一岁；男子爵，人二级，为父后及三老、孝悌、力田人三级；鳏、寡、孤、独、笃癃、贫不能自存者粟，人五斛；贞妇帛，人三匹。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **灾害所伤什四以上，勿收田租。** 灾害所伤什四以上，勿收田租；其不满者，以实除之。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **荆、扬二州人多饿死，遣四府掾分行赈给。** 二月，荆、扬二州人多饿死，遣四府掾分行赈给。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **沛国言黄龙见谯。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **京师地震。** 夏四月庚寅，京师地震。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **诏大将军、公、卿、校尉举贤良方正、能直言极谏者各一人。** [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **又命列侯、将、大夫、御史、谒者、千石、六百石、博士、议郎、郎官各上封事，指陈得失。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **又诏大将军、公、卿、郡、国举至孝笃行之士各一人。** [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **诏州郡不得迫胁驱逐长吏。** 壬辰，诏州郡不得迫胁驱逐长吏。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **长吏臧满三十万而不纠举者，刺史、二千石以纵避为罪。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **若有擅相假印绶者，与杀人同弃市论。** [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **诏郡国系囚减死罪一等，勿笞。** 丙午，诏郡国系囚减死罪一等，勿笞。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **唯谋反大逆，不用此书。** [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **又诏曰。** 又诏曰：『比起陵茔，弥历时岁，力役既广，徒隶尤勤。顷雨泽不沾，密云复散，傥或在兹。其令徒作陵者减刑各六月。』 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **是月，立阜陵王代兄勃遒亭侯便为阜陵王。** [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **郡国六地裂，水涌井溢。** [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **芝草生中黄藏府。** [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **太尉胡广罢，大司农杜乔为太尉。** 六月，太尉胡广罢，大司农杜乔为太尉。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **勃海王鸿薨，立帝弟蠡吾侯悝为勃海王。** 秋七月，勃海王鸿薨，立帝弟蠡吾侯悝为勃海王。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **立皇后梁氏。** 八月乙未，立皇后梁氏。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **京师地震。** 九月丁卯，京师地震。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **太尉杜乔免。** [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **司徒赵戒为太尉，司空袁汤为司徒，前太尉胡广为司空。** 冬十月，司徒赵戒为太尉，司空袁汤为司徒，前太尉胡广为司空。 [[26]](#hh-note-26)

<a id="hh-event-27"></a>

27. **济阴言有五色大鸟见於己氏。** 十一月，济阴言有五色大鸟见于己氏。 [[27]](#hh-note-27)

<a id="hh-event-28"></a>

28. **减天下死罪一等，戍边。** 戊午，减天下死罪一等，戍边。 [[28]](#hh-note-28)

<a id="hh-event-29"></a>

29. **清河刘文反，杀国相射暠，欲立清河王蒜为天子。** 清河刘文反，杀国相射暠，欲立清河王蒜为天子；事觉伏诛。 [[29]](#hh-note-29)

<a id="hh-event-30"></a>

30. **蒜坐贬为尉氏候，徙桂阳，自杀。** [[30]](#hh-note-30)

<a id="hh-event-31"></a>

31. **前太尉李固、杜乔皆下狱死。** 前太尉李固、杜乔均被收监，死于狱中。 [[31]](#hh-note-31)

<a id="hh-event-32"></a>

32. **陈留盗贼李坚自称皇帝，伏诛。** [[32]](#hh-note-32)

<a id="hh-event-33"></a>

33. **刘文、刘鲔欲拥清河王刘蒜。** 地方人传播刘蒜应代桓帝的说法，图谋共立，刘蒜遭牵连。 [[33]](#hh-note-33)

<a id="hh-event-34"></a>

34. **梁太后劝刘次依礼节哀。** 刘次为父居丧身体受损，梁太后诏令遵礼节哀。 [[34]](#hh-note-34)

<a id="hh-event-35"></a>

35. **建和元年日食与黄琬答问。** 魏郡报日食，京师不见；黄琬以初月形状帮助黄琼回答太后询问。 [[35]](#hh-note-35)

<a id="hh-event-36"></a>

36. **清河王刘蒜案与李固下狱。** 梁冀因刘文等谋立刘蒜，诬报李固同谋，使李固入狱。 [[36]](#hh-note-36)

<a id="hh-event-37"></a>

37. **杜乔任太尉并拒梁冀请托。** 杜乔代胡广为太尉，反对加礼迎梁氏入宫与任用汜宫。 [[37]](#hh-note-37)

<a id="hh-event-38"></a>

38. **孝桓建和元年八月壬寅，荧惑犯舆鬼质星。** 孝桓建和元年八月壬寅，荧惑犯舆鬼质星。 [[38]](#hh-note-38)

<a id="hh-event-39"></a>

39. **始入掖庭，八月立为皇后。** 建和元年六月，始入掖庭，八月立为皇后。 [[39]](#hh-note-39)

<a id="hh-event-40"></a>

40. **益封冀万三千户，增大将军府举高第茂才，官属倍於三公。** 建和元年，益封冀万三千户，增大将军府举高第茂才，官属倍于三公。 [[40]](#hh-note-40)

<a id="hh-event-41"></a>

41. **桓帝立勃遒亭侯便亲为恢嗣，是为恭王。** 建和元年，桓帝立勃遒亭侯便亲为恢嗣，是为恭王。 [[41]](#hh-note-41)

<a id="hh-event-42"></a>

42. **桓帝建和元年四月庚寅，京都地震。** [[42]](#hh-note-42)

<a id="hh-event-43"></a>

43. **桓帝建和元年正月辛亥朔，日有蚀之，在营室三度。** 桓帝建和元年正月辛亥朔，发生日食，在营室三度。 [[43]](#hh-note-43)

<a id="sy-event-44"></a>

44. **南匈奴单于居车儿即位。** 伊陵尸逐就单于居车儿继位。 [[44]](#sy-note-44)

<a id="hh061-l4518-e35"></a>

**[《后汉书·左周黄列传》](../../sources/摘录/后汉书-卷061-左周黄列传.md#p005)** · [仓内TXT L4518](../../sources/本地分卷/后汉书/后汉书-卷061.md#L4518)

> 建和元年正月日食，京師不見而瓊以狀聞。太后詔問所食多少，瓊思其對而未知所況。琬年七歲，在傍，曰：「何不言日食之餘，如月之初？」瓊大驚，即以其言應詔，而深奇愛之。後瓊為司徒，琬以公孫拜童子郎，辭病不就，知名京師。時司空盛允有疾，瓊遣琬候問，會江夏上蠻賊事副府，允發書視畢，微戲琬曰：「江夏大邦，而蠻多士少。」琬奉手對曰：「蠻夷猾夏，責在司空。」因拂衣辭去。允甚奇之。

# 公元148年｜建和二年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **皇帝加元服。** 二年春正月甲子，皇帝加元服。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **大赦天下。** 庚午，颁布大赦。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **赐河间、勃海二王黄金各百斤，彭城诸国王各五十斤。** 赐河间、勃海二王黄金各百斤，彭城诸国王各五十斤；公主、大将军、三公、特进、侯、中二千石、二千石、将、大夫、郎吏、从官、四姓及梁、邓小侯、诸夫人以下帛，各有差。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **年八十以上赐米、酒、肉，九十以上加帛二匹，绵三斤。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **帝从皇太后幸大将军梁冀府。** 三月戊辰，帝从皇太后幸大将军梁冀府。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **白马羌寇广汉属国，杀长吏，益州刺史率板楯蛮讨破之。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **封帝弟硕为平原王，奉孝崇皇祀。** 夏四月丙子，封帝弟硕为平原王，奉孝崇皇祀。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **尊孝崇皇夫人马氏为孝崇园贵人。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **嘉禾生大司农帑藏。** [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **北宫掖廷中德阳殿及左掖门火，车驾移幸南宫。** 五月癸丑，北宫掖廷中德阳殿及左掖门火，车驾移幸南宫。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **改清河为甘陵，立安平王得子经侯理为甘陵王。** 六月，改清河为甘陵，立安平王得子经侯理为甘陵王。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **京师大水。** 秋七月，京师大水。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **河东言木连理。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **长平陈景自号。** 冬十月，长平陈景自号『黄帝子』，署置官属，又南顿管伯亦称『真人』，并图举兵，悉伏诛。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **刘硕继封平原王，奉刘翼后。** 桓帝改封刘硕为平原王以奉其父祭祀，刘翼夫人马氏亦获尊号。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **荧惑行在舆鬼中。** 《天文志》记二年二月辛卯，荧惑行在舆鬼中。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **桓帝建和二年五月癸丑，北宫掖庭中德阳殿火，及左掖门。** [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **桓帝建和二年七月，京师大水。** [[18]](#hh-note-18)

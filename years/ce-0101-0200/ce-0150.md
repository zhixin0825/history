# 公元150年｜和平元年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **大赦天下，改元和平。** 和平元年春正月甲子，颁布大赦，改元和平。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏曰“曩者遭家不造”。** 乙丑，诏曰：『曩者遭家不造，先帝早世。永惟大宗之重，深思嗣续之福，询谋台辅，稽之兆占。既建明哲，克定统业，天人协和，万国咸宁。元服已加，将即委付，而四方盗窃，颇有未静，故假延临政，以须安谧。幸赖股肱御侮之助，残丑消荡，民和年稔，普天率土，遐迩洽同。远览「复子明辟」之义，近慕先姑归授之法，及今令辰，皇帝称制。群公卿士，虔恭尔位，勠力一意，勉同断金。「展也大成」，则所望矣。』 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **扶风妖贼裴优自称皇帝，伏诛。** 二月，扶风妖贼裴优自称皇帝，伏诛。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **皇太后梁氏崩。** 甲寅，皇太后梁氏崩。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **车驾徙幸北宫。** 三月，车驾徙幸北宫。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **葬顺烈皇后。** 甲午，葬顺烈皇后。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **尊博园匽贵人曰孝崇皇后。** 夏五月庚辰，尊博园匽贵人曰孝崇皇后。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **梓潼山崩。** 秋七月，梓潼山崩。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **减天下死罪一等，徙边戍。** 冬十一月辛巳，减天下死罪一等，徙边戍。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **归政於帝，太后寝疾遂笃，乃御辇幸宣德殿，见宫省官属及诸梁兄弟。** 和平元年春，归政于帝，太后寝疾遂笃，乃御辇幸宣德殿，见宫省官属及诸梁兄弟。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **梁太后崩，乃就博陵尊后为孝崇皇后。** 和平元年，梁太后崩，乃就博陵尊后为孝崇皇后。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **重增封冀万户，并前所袭合三万户。** 和平元年，重增封冀万户，并前所袭合三万户。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **广汉梓潼山崩。** 和平元年七月，广汉梓潼山崩。 [[13]](#hh-note-13)

1. **京师及九江庐江大疫，遣官视疾。** 正月京师大疫，朝廷遣光禄大夫携医药巡察。九江、庐江本年也发生大疫。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **大赦天下，改元元嘉。** 癸酉，颁布大赦，改元元嘉。 [[2]](#hh-note-2)

3. **河间王建薨。** 甲午，河间王建去世。 [[3]](#hh-note-4)

<a id="hh-event-5"></a>

4. **安平王得薨。** 夏四月己丑，安平王得去世。 [[4]](#hh-note-5)

5. **京师旱。** [[5]](#hh-note-6)

<a id="hh-event-7"></a>

6. **任城、梁国饥，民相食。** [[6]](#hh-note-7)

7. **张歆、胡广罢，吴雄、黄琼续任。** 司徒张歆罢，光禄勋吴雄继任；司空胡广罢，太常黄琼继任。 [[7]](#hh-note-8)

<a id="hh-event-9"></a>

<a id="hh-event-17"></a>

8. **武陵詹山等起兵据山。** 秋，武陵詹山等四千余人反叛，拘执县令，屯聚深山。 [[8]](#hh-note-9)

<a id="hh-event-11"></a>

<a id="hh-event-21"></a>

9. **京师地震。** 京师地震。 [[9]](#hh-note-11)

<a id="hh-event-12"></a>

10. **闰月庚午，任城王崇薨。** 闰月庚午，任城王崇去世。 [[10]](#hh-note-12)

<a id="hh-event-14"></a>

11. **度尚改葬曹娥并立碑。** 上虞长度尚在江南道旁改葬曹娥，为她立碑。 [[11]](#hh-note-14)

<a id="hh-event-15"></a>

12. **太白昼见。** 元嘉元年二月戊子，太白昼见。 [[12]](#hh-note-15)

<a id="hh-event-16"></a>

13. **帝以冀有援立之功，欲崇殊典，乃大会公卿，共议其礼。** 元嘉元年，帝以冀有援立之功，欲崇殊典，乃大会公卿，共议其礼。 [[13]](#hh-note-16)

<a id="hh-event-18"></a>

14. **长史赵评在於窴病痈死，评子迎丧，道经拘弥。** 元嘉元年，长史赵评在于窴病痈死，评子迎丧，道经拘弥。 [[14]](#hh-note-18)

<a id="hh-event-19"></a>

15. **桓帝元嘉元年，呼衍王将三千余骑寇伊吾，伊吾司马毛恺遣吏兵五百人於蒲类海东与呼衍王战，悉为所…。** 桓帝元嘉元年，呼衍王将三千余骑寇伊吾，伊吾司马毛恺遣吏兵五百人于蒲类海东与呼衍王战，悉为所没，呼衍王遂攻伊吾屯城。 [[15]](#hh-note-19)

<a id="hh-event-20"></a>

16. **桓帝元嘉元年十一月，五色大鸟见济阴己氏。** [[16]](#hh-note-20)

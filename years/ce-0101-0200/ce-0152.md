# 公元152年｜元嘉二年

[← 公元151年](ce-0151.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元153年 →](ce-0153.md)

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **西域长史王敬为於窴国所杀。** 二年春正月，西域长史王敬为于窴国所杀。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **京师地震。** 丙辰，京师地震。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **孝崇皇后匽氏崩。** 夏四月甲寅，孝崇皇后匽氏崩。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **常山王豹薨。** 庚午，常山王豹去世。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **葬孝崇皇后於博陵。** 五月辛卯，葬孝崇皇后于博陵。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **日有食之。** 秋七月庚辰，发生日食。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **济阴言黄龙见句阳，金城言黄龙见允街。** 八月，济阴言黄龙见句阳，金城言黄龙见允街。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **京师地震。** 冬十月乙亥，京师地震。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **司空黄琼免。** 十一月，司空黄琼免。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **特进赵戒为司空。** 十二月，特进赵戒为司空。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **右北平太守和旻坐臧，下狱死。** 右北平太守和旻坐臧，下狱后死亡。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **二日庚辰，日有蚀之，在翼四度。** 元嘉二年七月，二日庚辰，发生日食，在翼四度。 [[12]](#hh-note-12)

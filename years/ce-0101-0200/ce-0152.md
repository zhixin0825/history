2. **京师地震。** 丙辰，京师地震。 [[2]](#hh-note-2)

3. **孝崇皇后匽氏崩，葬博陵。** 孝崇皇后匽氏去世，葬于博陵。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **常山王豹薨。** 庚午，常山王豹去世。 [[4]](#hh-note-4)

<a id="hh-event-6"></a>

<a id="hh-event-12"></a>

5. **庚辰日食于翼宿。** 庚辰日食于翼宿四度。 [[5]](#hh-note-6)

<a id="hh-event-7"></a>

6. **济阴言黄龙见句阳，金城言黄龙见允街。** 八月，济阴言黄龙见句阳，金城言黄龙见允街。 [[6]](#hh-note-7)

<a id="hh-event-8"></a>

7. **京师地震。** 冬十月乙亥，京师地震。 [[7]](#hh-note-8)

<a id="hh-event-9"></a>

<a id="hh-event-10"></a>

8. **黄琼免司空，赵戒接任。** 司空黄琼免，特进赵戒继任。 [[8]](#hh-note-9)

<a id="hh-event-11"></a>

9. **右北平太守和旻坐臧，下狱死。** 右北平太守和旻坐臧，下狱后死亡。 [[9]](#hh-note-11)

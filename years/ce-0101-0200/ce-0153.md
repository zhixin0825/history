# 公元153年｜永兴元年

<a id="hh-event-1"></a>

1. **张掖言白鹿见。** 永兴元年春二月，张掖言白鹿见。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **幸鸿池。** 三月丁亥，幸鸿池。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **大赦天下，改元永兴。** 夏五月丙申，颁布大赦，改元永兴。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **济南王广薨，无子，国除。** 丁酉，济南王广薨，无子，国除。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **郡国三十二蝗。** 秋七月，郡国三十二蝗。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **河水溢。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **百姓饥穷，流冗道路，至有数十万户，冀州尤甚。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **诏在所赈给乏绝，安慰居业。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **太尉袁汤免，太常胡广为太尉。** 冬十月，太尉袁汤免，太常胡广为太尉。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **司徒吴雄罢，司空赵戒免。** 司徒吴雄罢，司空赵戒免；以太仆黄琼为司徒，光禄勲房植为司空。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **诏减天下死罪一等，徙边戍。** 十一月丁丑，诏减天下死罪一等，徙边戍。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **是岁，武陵太守应奉招诱叛蛮，降之。** 当年，武陵太守应奉招诱叛蛮，降服。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **车师后王阿罗多攻汉屯田。** 阿罗多与屯田官不和，围且固城，后因部众离散而北走。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **河溢，漂害人庶数十万户，百姓荒馑，流移道路。** 永兴元年，河溢，漂害人庶数十万户，百姓荒馑，流移道路。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **车师後王复反攻屯营。** 永兴元年，车师后王复反攻屯营。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **河水溢，漂害人、物。** 永兴元年秋，河水溢，漂害人、物。 [[16]](#hh-note-16)

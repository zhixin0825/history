1. **大赦天下。** 二年春正月甲午，颁布大赦。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-17"></a>

2. **准刺史、二千石服三年丧。** 采纳赵岐关于外官得去职居亲丧的意见，初许刺史、二千石官行三年丧服。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

<a id="hh-event-18"></a>

<a id="hh-event-22"></a>

3. **京师地震，诏举贤良，刘淑应征。** 京师地震，桓帝因灾异下诏，命公、卿、校尉举贤良方正、能直言极谏之士。刘淑以贤良方正应召，任议郎。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

4. **彭城泗水增长逆流。** 六月，彭城泗水增长逆流。 [[4]](#hh-note-5)

<a id="hh-event-6"></a>

5. **诏司隶校尉、部刺史曰。** 诏司隶校尉、部刺史曰：『蝗灾为害，水变仍至，五谷不登，人无宿储。其令所伤郡国种芜菁以助人食。』 [[5]](#hh-note-6)

<a id="hh-event-7"></a>

6. **京师蝗。** [[6]](#hh-note-7)

<a id="hh-event-8"></a>

7. **东海朐山崩。** [[7]](#hh-note-8)

<a id="hh-event-9"></a>

<a id="hh-event-10"></a>

<a id="hh-event-23"></a>

8. **角宿日食，桓帝下诏自责。** 日食于角宿五度，桓帝以朝政失中下诏自责。 [[8]](#hh-note-9)

<a id="hh-event-11"></a>

<a id="hh-event-12"></a>

9. **胡广免太尉，黄琼、尹颂补公职。** 太尉胡广免，司徒黄琼继为太尉，闰月光禄勋尹颂任司徒。 [[9]](#hh-note-11)

<a id="hh-event-13"></a>

10. **减天下死罪一等，徙边戍。** [[10]](#hh-note-13)

<a id="hh-event-14"></a>

11. **蜀郡李伯诈称宗室，当立为。** 蜀郡李伯诈称宗室，当立为『太初皇帝』，伏诛。 [[11]](#hh-note-14)

<a id="hh-event-15"></a>

12. **校猎上林苑，遂至函谷关，赐所过道傍年九十以上钱，各有差。** 冬十一月甲辰，校猎上林苑，遂至函谷关，赐所过道傍年九十以上钱，各有差。 [[12]](#hh-note-15)

<a id="hh-event-16"></a>

13. **太山、琅邪贼公孙举等反叛，杀长吏。** [[13]](#hh-note-16)

<a id="hh-event-19"></a>

14. **闰月丁酉，太白昼见。** 永兴二年闰月丁酉，太白昼见。 [[14]](#hh-note-19)

<a id="hh-event-20"></a>

15. **封不疑子马为颍阴侯，胤子桃为城父侯。** 永兴二年，封不疑子马为颍阴侯，胤子桃为城父侯。 [[15]](#hh-note-20)

<a id="hh-event-21"></a>

16. **桓帝永兴二年四月丙午，光禄勋吏舍壁下夜有青气，视之，得玉鈎、玦各一。** [[16]](#hh-note-21)

### 3. 京师地震，诏举贤良，刘淑应征

[返回正文第3条](#hh-event-3)

<a id="hh007-l993-e3"></a>

**[《后汉书·桓帝纪》](../../sources/摘录/后汉书-卷007-桓帝纪.md#p001)** · [仓内TXT L993](../../sources/本地分卷/后汉书/后汉书-卷007.md#L993)

<a id="hh007-l993-e4"></a>

**[《后汉书·桓帝纪》](../../sources/摘录/后汉书-卷007-桓帝纪.md#p001)** · [仓内TXT L993](../../sources/本地分卷/后汉书/后汉书-卷007.md#L993)

> 詔曰：『比者星辰謬越，坤靈震動，災異之降，必不空發。勑己修政，庶望有補。其輿服制度有逾侈長飾者，皆宜損省。郡縣務存儉約，申明舊令，如永平故事。』

<a id="hh-note-18"></a>

<a id="hh067-l4857-e18"></a>

**[《后汉书·党锢列传》](../../sources/摘录/后汉书-卷067-党锢列传.md#p002)** · [仓内TXT L4857](../../sources/本地分卷/后汉书/后汉书-卷067.md#L4857)

> 永興二年，司徒種暠舉淑賢良方正，辭以疾。桓帝聞淑高名，切責州郡，使輿病詣京師。淑不得已而赴洛陽，對策為天下第一，拜議郎。又陳時政得失，災異之占，事皆效驗。

**归年与互校** 年次据本传。

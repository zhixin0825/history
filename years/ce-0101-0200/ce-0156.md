# 公元156年｜永寿二年

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **初听中官得行三年服。** 二年春正月，初听中官得行三年服。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **东海王臻薨。** 二月甲申，东海王臻去世。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-13"></a>

3. **蜀郡属国夷反叛，杀掠吏民。** 蜀郡属国部众起兵，杀掠吏民。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

<a id="hh-event-10"></a>

4. **鲜卑檀石槐率骑寇云中。** 鲜卑首领檀石槐率骑兵攻犯云中。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

<a id="hh-event-8"></a>

5. **段颎任中郎将，击斩公孙举等。** 太山公孙举等攻掠青、兖、徐等地，朝廷选任段颎为中郎将进讨，将公孙举等击破斩杀。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **置太官右监丞官。** 冬十一月，置太官右监丞官。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

<a id="hh-event-14"></a>

7. **京师地震。** 京师地震。 [[7]](#hh-note-7)

<a id="hh-event-9"></a>

8. **朱达等攻九真。** 居风县令贪暴引发事变，朱达等杀县令攻九真，太守儿式战死，魏朗征讨。 [[8]](#hh-note-9)

<a id="hh-event-11"></a>

9. **辰星入太微，遂伏不见。** 二年六月甲寅，辰星入太微，遂伏不见。 [[9]](#hh-note-11)

<a id="hh-event-12"></a>

10. **太白犯轩辕大星。** 八月戊午，太白犯轩辕大星。 [[10]](#hh-note-12)

<a id="hh067-l4862-e4"></a>

**[《后汉书·党锢列传》](../../sources/摘录/后汉书-卷067-党锢列传.md#p003)** · [仓内TXT L4862](../../sources/本地分卷/后汉书/后汉书-卷067.md#L4862)

> 永壽二年，鮮卑寇雲中，桓帝聞膺能，乃復征為度遼將軍。先是羌虜及疏勒、龜茲，數出攻鈔張掖、酒泉、雲中諸郡，百姓屢被其害。自膺到邊，皆望風懼服，先所掠男女，悉送還塞下。自是之後，聲振遠域。

**归年与互校** 年次据本传。

# 公元157年｜永寿三年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **大赦天下。** 三年春正月己未，颁布大赦。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **九真蛮夷叛，太守儿式讨之，战殁。** 夏四月，九真蛮夷叛，太守儿式讨之，战殁；遣九真都尉魏朗将其击败。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **复屯据日南。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **闰月庚辰晦，日有食之。** 闰月庚辰晦，发生日食。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **初以小黄门为守宫令，置冗从右仆射官。** 六月，初以小黄门为守宫令，置冗从右仆射官。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **京师蝗。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **河东地裂。** 秋七月，河东地裂。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **司徒尹颂薨。** 冬十一月，司徒尹颂去世。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **长沙蛮叛，寇益阳。** [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **司空韩演为司徒，太常北海孙朗为司空。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **长沙蛮反叛，屯益阳。** 永寿三年十一月，长沙蛮反叛，屯益阳。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **河东地裂，时梁皇后兄兾秉政，桓帝欲自由，内患之。** 永寿三年七月，河东地裂，时梁皇后兄兾秉政，桓帝欲自由，内患之。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **桓帝永寿三年十二月壬戌，月蚀非其月。** [[13]](#hh-note-13)

# 公元160年｜延熹三年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **大赦天下。** 三年春正月丙申，颁布大赦。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **车骑将军单超薨。** 丙午，车骑将军单超去世。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **闰月，烧何羌叛，寇张掖，护羌校尉段熲追击於积石，大破之。** 闰月，烧何羌叛，寇张掖，护羌校尉段熲追击于积石，大破之。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **白马令李云坐直谏，下狱死。** 白马令李云坐直谏，下狱后死亡。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **上郡言甘露降。** 夏四月，上郡言甘露降。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **汉中山崩。** 五月甲戌，汉中山崩。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **司徒祝恬薨。** 六月辛丑，司徒祝恬去世。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **司空盛允为司徒，太常虞放为司空。** 秋七月，司空盛允为司徒，太常虞放为司空。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **长沙蛮寇郡界。** [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **太山、琅邪贼劳丙等复叛，寇掠百姓。** 九月，太山、琅邪贼劳丙等复叛，寇掠百姓。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **遣御史中丞赵某持节督州郡讨之。** [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **诏无事之官权绝奉，丰年如故。** 丁亥，诏无事之官权绝奉，丰年如故。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **日南蛮贼率众诣郡降。** 冬十一月，日南蛮贼率众到郡降。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **勒姐羌围允街，段熲击破之。** 勒姐羌围允街，段熲将其击败。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **太山贼叔孙无忌攻杀都尉侯章。** [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **遣中郎将宗资讨破之。** 十二月，派中郎将宗资讨破之。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **武陵蛮寇江陵，车骑将军冯绲讨，皆降散。** [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **荆州刺史度尚讨长沙蛮，平之。** [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **杨秉因争李云之狱免官。** 杨秉争白马令李云谏案而不成，免去职务。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **夏方再任交趾刺史。** 因熟悉当地且素有威望，朝廷重新任命夏方，日南叛众相率归降。 [[20]](#hh-note-20)

<a id="sgz-event-21"></a>

21. **卞氏生于齊郡白亭。** 《魏书》记卞氏延熹三年十二月己巳出生在齐郡白亭，又叙出生见黄气、占者称吉的传说。 [[21]](#sgz-note-21)

<a id="sgz-event-22"></a>

22. **祝公为司徒祝恬。** 裴松之辨明刘焉守丧的老师是司徒祝恬。 [[22]](#sgz-note-22)

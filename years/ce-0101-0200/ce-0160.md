4. **李云因直谏下狱死，杨秉争救免官。** 白马令李云以直谏罪下狱后死，杨秉为此争谏被免官。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **上郡言甘露降。** 夏四月，上郡言甘露降。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **汉中山崩。** 五月甲戌，汉中山崩。 [[6]](#hh-note-6)

<a id="hh-event-8"></a>

<a id="sgz-event-22"></a>

7. **祝恬去世，盛允、虞放改任三公。** 司徒祝恬去世，司空盛允继为司徒，太常虞放任司空。 [[7]](#hh-note-7)

<a id="hh-event-18"></a>

8. **长沙部众入寇，度尚率军平定。** 长沙部众进犯郡境，荆州刺史度尚讨平。 [[8]](#hh-note-9)

<a id="hh-event-10"></a>

<a id="hh-event-11"></a>

<a id="hh-event-15"></a>

<a id="hh-event-16"></a>

9. **太山琅邪诸部再起，宗资等出讨。** 太山、琅邪劳丙等再叛寇掠百姓，朝廷遣御史中丞持节督州郡讨伐。叔孙无忌攻杀太山都尉侯章，中郎将宗资奉命击破其众。 [[9]](#hh-note-10)

<a id="hh-event-12"></a>

10. **诏无事之官权绝奉，丰年如故。** 丁亥，诏无事之官权绝奉，丰年如故。 [[10]](#hh-note-12)

<a id="hh-event-13"></a>

<a id="hh-event-20"></a>

11. **夏方再任交趾，日南部众降。** 夏方再任交趾刺史，日南起兵之众向郡中投降。 [[11]](#hh-note-13)

<a id="hh-event-14"></a>

12. **勒姐羌围允街，段熲击破之。** 勒姐羌围允街，段熲将其击败。 [[12]](#hh-note-14)

<a id="hh-event-17"></a>

13. **武陵蛮寇江陵，车骑将军冯绲讨，皆降散。** [[13]](#hh-note-17)

<a id="sgz-event-21"></a>

14. **卞氏出生于齐郡白亭。** 十二月己巳，卞氏出生于齐郡白亭。 [[14]](#sgz-note-21)

### 14. 卞氏出生于齐郡白亭

[返回正文第14条](#sgz-event-21)

**互校** 《魏书》接记生时室内见黄气，卜者认为是吉兆。

<a id="sgz005-p-001-1"></a>

**归年** 注文直书延熹三年，异象只作为《魏书》的记述。

**《后妃傳》互見** [TXT 第11行](../../拆分史书/三国志/卷005.md#edition-wei005-l11-1)

<a id="wei005-l10-1"></a>

**[《三國志·后妃傳》裴注](../../拆分史书/三国志/卷005.md#edition-wei005-l10-1)** · [TXT L10](../../拆分史书/三国志/卷005.txt#L10)

> 魏書曰：后以漢延熹三年十二月己巳生齊郡白亭，有黃氣滿室移日。父敬侯怪之，以問卜者王旦，旦曰：「此吉祥也。」

**釋讀與歸年** 汉延熹三年十二月己巳，卞氏生于齐郡白亭。黄气及其父问卜王旦为《魏书》所述出生祥异。

5. **长沙零陵诸部联合入寇，州郡出兵未克。** 长沙、零陵等地起事，聚众七八千人，进犯桂阳、苍梧、南海、交趾。艾县部众焚长沙郡县、入寇益阳杀令，零陵各部也入寇长沙。御史中丞盛入修督州郡讨伐，未能攻克。 [[5]](#hh-note-5)

10. **诏减虎贲、羽林住寺不任事者半奉，勿与冬衣。** 八月庚子，诏减虎贲、羽林住寺不任事者半奉，勿与冬衣；其公卿以下给冬衣之半。 [[10]](#hh-note-17)

11. **罢琅邪都尉官。** 己卯，罢琅邪都尉官。 [[11]](#hh-note-20)

<a id="hh-event-21"></a>

<a id="hh-event-24"></a>

12. **武陵进犯江陵，冯绲进讨。** 武陵部众起事，进犯江陵，南郡太守李肃因退逃伏诛。朝廷遣冯绲在武陵大破反叛部众。 [[12]](#hh-note-21)

<a id="hh-event-22"></a>

<a id="hh-event-23"></a>

13. **借官俸和王侯租以助军粮。** 朝廷借公卿以下俸禄，又暂用王侯租入助军粮，以濯龙中藏钱归还。 [[13]](#hh-note-22)

<a id="hh-event-25"></a>

14. **京兆虎牙都尉宗谦坐臧，下狱死。** 京兆虎牙都尉宗谦坐臧，下狱后死亡。 [[14]](#hh-note-25)

<a id="hh-event-26"></a>

15. **滇那羌寇武威、张掖、酒泉。** [[15]](#hh-note-26)

<a id="hh-event-27"></a>

16. **太尉刘矩免，太常杨秉为太尉。** [[16]](#hh-note-27)

<a id="hh-event-28"></a>

17. **度尚受朱穆荐任荆州刺史。** 长江以南诸部攻桂阳、苍梧等地，先遣二将讨击不克。桓帝从尚书朱穆之荐，任度尚为荆州刺史。 [[17]](#hh-note-28)

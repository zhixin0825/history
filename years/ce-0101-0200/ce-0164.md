1. **沛王荣薨。** 七年春正月庚寅，沛王荣去世。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-19"></a>

2. **右扶风和鄠有陨石。** 三月癸亥，右扶风陨石一枚，鄠县又陨石二枚，声如雷。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **梁王成薨。** 夏四月丙寅，梁王成去世。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **京师雨雹。** 五月己丑，京师雨雹。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **赵王乾薨。** 秋七月辛卯，赵王乾去世。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **野王山上有死龙。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **荆州刺史度尚击零陵、桂阳盗贼及蛮夷，大破平之。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

<a id="hh-event-10"></a>

<a id="hh-event-12"></a>

8. **桓帝南巡祭章陵，至云梦临汉水。** 桓帝南巡，至章陵祭旧宅园庙，按等赐郡守、县令以下。又至云梦，临汉水，随后还宫。 [[8]](#hh-note-8)

<a id="hh-event-11"></a>

9. **护羌校尉段熲击当煎羌，破之。** [[9]](#hh-note-11)

<a id="hh-event-13"></a>

10. **辰星犯岁星。** 七年七月戊辰，辰星犯岁星。 [[10]](#hh-note-13)

<a id="hh-event-14"></a>

11. **荧惑犯舆鬼质星。** 八月庚戌，荧惑犯舆鬼质星。 [[11]](#hh-note-14)

<a id="hh-event-15"></a>

12. **岁星犯轩辕大星。** 庚申，岁星犯轩辕大星。 [[12]](#hh-note-15)

<a id="hh-event-16"></a>

13. **太白犯房北星。** 十月丙辰，太白犯房北星。 [[13]](#hh-note-16)

<a id="hh-event-17"></a>

14. **辰星犯太白。** 丁卯，辰星犯太白。 [[14]](#hh-note-17)

<a id="hh-event-18"></a>

15. **荧惑犯轩辕第二星。** 十二月乙丑，荧惑犯轩辕第二星。 [[15]](#hh-note-18)

<a id="sgz-event-20"></a>

16. **唐衡卒，裴松之据此考婚年。** 裴松之引《汉记》唐衡延熹七年死，按当时荀彧约二岁，待成婚时唐衡死已久，不成立慕势之说。 [[16]](#sgz-note-20)

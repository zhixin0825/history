1. **桓帝遣左悺、管霸至苦县祠老子。** 桓帝遣中常侍左悺、管霸先后到陈国苦县祭祀老子。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

<a id="hh-event-30"></a>

2. **勃海王刘悝降为廮陶王。** 勃海王刘悝因谋反被降为廮陶王。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

<a id="hh-event-4"></a>

<a id="hh-event-31"></a>

3. **日食后举贤良，刘瑜奏陈时政。** 日食，朝廷令公、卿、校尉举贤良方正。刘瑜应举，奏陈时政。 [[3]](#hh-note-3)

<a id="hh-event-5"></a>

4. **南宫嘉德署黄龙见。** 二月己酉，南宫嘉德署黄龙见。 [[4]](#hh-note-5)

<a id="hh-event-6"></a>

5. **千秋万岁殿火。** [[5]](#hh-note-6)

<a id="hh-event-7"></a>

6. **太仆左称有辠自杀。** [[6]](#hh-note-7)

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

<a id="hh-event-26"></a>

<a id="hh-event-33"></a>

<a id="hh-event-38"></a>

7. **邓皇后被废，窦贵人立后。** 邓皇后被废，河南尹邓万世与虎贲中郎将邓会下狱死。窦氏以选入掖庭为贵人，冬立为皇后，父窦武受封。窦皇后很少进见，桓帝宠采女田圣等。 [[7]](#hh-note-8)

<a id="hh-event-10"></a>

8. **护羌校尉段熲击罕姐羌，破之。** [[8]](#hh-note-10)

<a id="hh-event-11"></a>

9. **大赦天下。** 三月辛巳，颁布大赦。 [[9]](#hh-note-11)

<a id="hh-event-12"></a>

10. **安陵园寝火。** 夏四月甲寅，安陵园寝火。 [[10]](#hh-note-12)

<a id="hh-event-13"></a>

11. **坏郡国诸房祀。** 丁巳，坏郡国诸房祀。 [[11]](#hh-note-13)

<a id="hh-event-14"></a>

<a id="hh-event-42"></a>

12. **济阴、东郡、济北河水清。** 济阴、东郡、济北报河水变清。 [[12]](#hh-note-14)

<a id="hh-event-15"></a>

13. **罢太山都尉官。** 五月壬申，罢太山都尉官。 [[13]](#hh-note-15)

<a id="hh-event-16"></a>

<a id="hh-event-22"></a>

14. **杨秉去世，陈蕃任太尉。** 太尉杨秉去世，太中大夫陈蕃继任太尉。 [[14]](#hh-note-16)

<a id="hh-event-17"></a>

15. **缑氏地裂。** 六月丙辰，缑氏地裂。 [[15]](#hh-note-17)

<a id="hh-event-18"></a>

<a id="hh-event-19"></a>

16. **胡兰、朱盖攻零陵，陈球拒守。** 桂阳胡兰、朱盖等再起，攻陷郡县，转攻零陵，太守陈球抵御。苍梧太守张敍被擒、桂阳太守任胤临敌退避，二人均被处死。 [[16]](#hh-note-18)

<a id="hh-event-20"></a>

17. **闰月甲午，南宫长秋和欢殿後钩楯、掖庭、朔平署火。** 闰月甲午，南宫长秋和欢殿后钩楯、掖庭、朔平署火。 [[17]](#hh-note-20)

<a id="hh-event-21"></a>

18. **段熲击当煎羌於湟中，大破之。** 六月，段熲击当煎羌于湟中，大破之。 [[18]](#hh-note-21)

<a id="hh-event-23"></a>

19. **初令郡国有田者亩敛税钱。** 八月戊辰，初命各郡国有田者亩敛税钱。 [[19]](#hh-note-23)

<a id="hh-event-24"></a>

20. **京师地震。** 九月丁未，京师地震。 [[20]](#hh-note-24)

<a id="hh-event-25"></a>

21. **司空周景免，太常刘茂为司空。** 冬十月，司空周景免，太常刘茂为司空。 [[21]](#hh-note-25)

<a id="hh-event-27"></a>

22. **勃海妖贼盖登等称。** 勃海妖贼盖登等称『太上皇帝』，有玉印、珪、璧、铁券，相署置，皆伏诛。 [[22]](#hh-note-27)

<a id="hh-event-28"></a>

23. **德阳殿西合、黄门北寺火，延及广义、神虎门，烧杀人。** 十一月壬子，德阳殿西合、黄门北寺火，延及广义、神虎门，烧杀人。 [[23]](#hh-note-28)

<a id="hh-event-32"></a>

24. **张俭任督邮，劾侯览及其母。** 张俭举发侯览家暴害民众，侯览阻遏奏章，双方结怨。 [[24]](#hh-note-32)

<a id="hh-event-34"></a>

25. **太白犯舆鬼质星。** 八年五月癸酉，太白犯舆鬼质星。 [[25]](#hh-note-34)

<a id="hh-event-35"></a>

26. **荧惑入太微右执法。** 壬午，荧惑入太微右执法。 [[26]](#hh-note-35)

<a id="hh-event-36"></a>

<a id="hh-event-37"></a>

27. **岁星入太微，犯左执法。** 岁星进入太微星区，犯左执法星。 [[27]](#hh-note-36)

<a id="hh-event-39"></a>

28. **徵拜尚书令，迁南阳太守。** 延熹八年，徵拜尚书令，迁南阳太守。 [[28]](#hh-note-39)

<a id="hh-event-40"></a>

29. **黜为关内侯，食本县租千斛。** 延熹八年，黜为关内侯，食本县租千斛。 [[29]](#hh-note-40)

<a id="hh-event-43"></a>

30. **月蚀非其月。** 延熹八年正月辛巳，月蚀非其月。 [[30]](#hh-note-43)

<a id="hh-event-1"></a>

1. **日有食之。** 九年春正月辛卯朔，发生日食。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **诏公、卿、校尉、郡国举至孝。** [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **沛国戴异得黄金印，无文字，遂与广陵人龙尚等共祭井，作符书，称。** 沛国戴异得黄金印，无文字，遂与广陵人龙尚等共祭井，作符书，称『太上皇』，伏诛。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **诏曰“比岁不登”。** 己酉，诏曰：『比岁不登，民多饥穷，又有水旱疾疫之困。盗贼徵发，南州尤甚。灾异日食，谴告累至。政乱在予，仍获咎徵。其令大司农绝今岁调度徵求，及前年所调未毕者，勿复收责。其灾旱盗贼之郡，勿收租，余郡悉半入。』 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **京师有火光转行，人相惊噪。** 三月癸巳，京师有火光转行，人相惊噪。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **司隶、豫州饥死者什四五，至有灭户者，遣三府掾赈禀之。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **陈留太守韦毅坐臧自杀。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **济阴、东郡、济北、平原河水清。** 夏四月，济阴、东郡、济北、平原河水清。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **司徒许栩免。** [[9]](#hh-note-9)

10. **太常胡广为司徒。** 五月，太常胡广为司徒。 [[10]](#hh-note-10)

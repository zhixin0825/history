<a id="hh-event-1"></a>

1. **大赦天下。** 二年春正月丁丑，颁布大赦。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **尊慎园董贵人为孝仁皇后。** 三月乙巳，尊慎园董贵人为孝仁皇后。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **大风，雨雹。** 夏四月癸巳，大风，雨雹。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **诏公卿以下各上封事。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **大尉闻人袭罢，司空许栩免。** 五月，大尉闻人袭罢，司空许栩免。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **司徒刘宠为太尉，太常许训为司徒，太仆长沙刘嚣为司空。** 六月，司徒刘宠为太尉，太常许训为司徒，太仆长沙刘嚣为司空。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **破羌将军段熲大破先零羌於射虎塞外谷。** 秋七月，破羌将军段熲大破先零羌于射虎塞外谷。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **东羌悉平。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **江夏蛮叛，州郡讨平之。** 九月，江夏蛮叛，州郡讨平之。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **丹阳山越贼围太守陈夤，夤击破之。** 丹阳山越贼围太守陈夤，夤将其击败。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **中常侍侯览讽有司奏前司空虞放。** 冬十月丁亥，中常侍侯览讽有司奏前司空虞放、太仆杜密、长乐少府李膺、司隶校尉朱㝢、颍川太守巴肃、沛相荀昱、河内太守魏朗、山阳太守翟超皆为钩党，下狱，死者百余人，妻子徙边，诸附从者锢及五属。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **制诏州郡大举钩党，於是天下豪桀及儒学行义者，一切结为党人。** 制诏州郡大举钩党，于是天下豪桀及儒学行义者，一切结为党人。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **日有食之。** 戊戌晦，发生日食。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **太尉刘宠免，太仆郭禧为太尉。** 十一月，太尉刘宠免，太仆郭禧为太尉。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **鲜卑寇并州。** [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **是岁，长乐太仆曹节为车骑将军，百余日罢。** 当年，长乐太仆曹节为车骑将军，百余日罢。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **谢弼等三人以有道受试授官。** 谢弼、陈敦、公孙度在有道对策后授郎中。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **张俭劾侯览。** 侯览返乡葬母，大兴坟墓，督邮张俭弹劾其夺人田宅等事。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **耿临出兵高句骊。** 玄菟太守耿临出兵，斩首数百级。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **灵帝建宁二年四月，雨雹。** [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **灵帝建宁二年四月癸巳，京都大风雨雹，拔郊道树十围已上百余枚。** [[21]](#hh-note-21)

**[《后汉书·党锢列传》](../../sources/摘录/后汉书-卷067-党锢列传.md#p005)** · [仓内TXT L4913](../../sources/本地分卷/后汉书/后汉书-卷067.md#L4913)

> 建寧二年，遂大誅黨人，詔下急捕滂等。督郵吳導至縣，抱詔書，閉傳捨，伏默而泣。滂聞之，曰：「必為我也。」即自詣獄。縣令郭揖大驚，出解印綬，引與俱亡。曰：「天下大矣，子何為在此？」滂曰：「滂死則禍塞，何敢以罪累君，又令老母流離乎！」其母就與之訣。滂白母曰：「仲博孝敬，足以供養，滂從龍舒君歸黃泉，存亡各得其所。惟大人割不可忍之恩，勿增感戚。」

**归年与互校** 年次据本传。

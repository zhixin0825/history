## 本年概述

桥玄继任司空，推荐陈球。郁林太守谷永招乌浒归附，朝廷置七县。济南有兵乱，凉州刺史孟佗出兵疏勒未克。

## 三公任免与宫廷

<a id="hh-event-3"></a>

1. **太尉郭禧罢，太中大夫闻人袭为太尉。** 夏四月，太尉郭禧罢，太中大夫闻人袭为太尉。 [[1]](#hh-note-3)

<a id="hh-event-4"></a>

<a id="hh-event-5"></a>

<a id="hh-event-9"></a>

2. **刘嚣免司空，桥玄接任并举陈球。** 七月刘嚣罢司空，八月由大鸿胪桥玄接任。桥玄入三公，向朝廷推荐先前与自己不睦的陈球，其后又转任司徒。 [[2]](#hh-note-4)

<a id="hh-event-6"></a>

3. **执金吾董宠下狱死。** 九月，执金吾董宠下狱后死亡。 [[3]](#hh-note-6)

<a id="hh-event-10"></a>

4. **蔡邕入桥玄司徒府。** 蔡邕受辟入桥玄府，后经地方历练入东观校书。 [[4]](#hh-note-10)

<a id="hh-event-12"></a>

5. **选入掖庭为贵人。** 建宁三年，选入掖庭为贵人。 [[5]](#hh-note-12)

## 济南、郁林与边境

<a id="hh-event-7"></a>

6. **济南贼起，攻东平陵。** 冬，济南贼起，攻东平陵。 [[6]](#hh-note-7)

<a id="hh-event-8"></a>

<a id="hh-event-13"></a>

7. **谷永招抚郁林乌浒，属地设七县。** 郁林太守谷永以恩信招抚，乌浒十余万人相率内属，受赐冠带，朝廷开置七县。 [[7]](#hh-note-8)

<a id="hh-event-11"></a>

8. **孟佗遣兵攻疏勒不克。** 孟佗遣任涉等与西域诸国合兵攻桢中城，多日不下而撤。 [[8]](#hh-note-11)

<a id="hh-event-14"></a>

9. **灵帝建宁三年，烧当羌奉使贡献。** [[9]](#hh-note-14)

## 岁时与日食

<a id="hh-event-2"></a>

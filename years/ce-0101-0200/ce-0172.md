[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **太傅胡广薨。** 熹平元年春三月壬戌，太傅胡广去世。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **大赦天下，改元熹平。** 夏五月己巳，颁布大赦，改元熹平。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **长乐太仆侯览有罪，自杀。** 长乐太仆侯览获罪后自杀。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **京师雨水。** 六月，京师雨水。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **皇太后窦氏崩。** 癸巳，皇太后窦氏崩。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **葬桓思皇后。** 秋七月甲寅，葬桓思皇后。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **宦官讽司隶校尉段熲捕系太学诸生千余人。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **渤海王悝被诬谋反，丁亥，悝及妻子皆自杀。** 冬十月，渤海王悝被诬谋反，丁亥，悝及妻子皆自杀。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **会稽人许生自称。** 十一月，会稽人许生自称『越王』，寇郡县，遣杨州刺史臧旻、丹阳太守陈夤讨破之。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **司徒许栩罢，大鸿胪袁隗为司徒。** 十二月，司徒许栩罢，大鸿胪袁隗为司徒。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **鲜卑寇并州。** [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **是岁，甘陵王恢薨。** 当年，甘陵王恢去世。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **杨赐以灾异上封事。** 御座上有异状，灵帝向杨赐询问，引出其议政封事。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **勃海王刘悝被逼自杀。** 王甫党人诬奏迎立刘悝，朝廷派使者迫责，刘悝死。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **陈球主张以皇太后礼葬窦氏。** 窦太后卒，宦官欲采用贵人礼，陈球上言宜合葬宣陵。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **许昭起兵句章。** 许昭称大将军，奉父为越王，攻克若干城邑，牵涉臧旻后续平乱。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **朱雀阙书揭发宦官。** 窦太后死后，有人在朱雀阙留书斥责曹节、王甫等。司隶校尉刘猛不急于追缉，被贬官。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **荧惑入南斗中。** 《天文志》记熹平元年十月，荧惑入南斗中。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **太后母卒於比景，太后感疾而崩。** 熹平元年，太后母卒于比景，太后感疾而崩。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **霖雨七十余日。** 熹平元年夏，霖雨七十余日。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **青蛇见御坐上。** 熹平元年四月甲午，青蛇见御坐上。 [[21]](#hh-note-21)

<a id="sg-event-22"></a>

22. **臧旻、孙坚等平会稽许昌。** 句章许昌与子许韶聚众，自号阳明皇帝，孙坚募兵协助州郡讨平，以功改任盐渎丞。 [[22]](#sg-note-22)

<a id="sy-event-23"></a>

23. **南匈奴屠特若尸逐就单于即位。** 南匈奴屠特若尸逐就单于即位，本传仅写名“某”。 [[23]](#sy-note-23)

> 熹平元年春三月壬戌，太傅胡廣薨。

<a id="sy-hh044-l3445-e1"></a>

**[《后汉书·邓张徐张胡列传》](../../sources/摘录/后汉书-卷044-邓张徐张胡列传.md#p005)** · [仓内TXT L3445](../../sources/本地分卷/后汉书/后汉书-卷044.md#L3445)

> 年八十二，熹平元年薨。使五官中郎將持節奉策贈太傅﹑安樂鄉侯印綬，給東園梓器，謁者護喪事，賜頤塋於原陵，謚文恭侯，拜家一人為郎中。故吏自公﹑卿﹑大夫﹑博士﹑議郎以下數百人，皆縗絰殯位，自終及葬。

**本段所记** 胡广病卒，朝廷派使赠太傅及安乐乡侯印绶、谥文恭，其旧吏数百人从殡至葬服丧。

**归年与互校** 《灵帝纪》记熹平元年三月壬戌去世，《胡广传》补追赠、丧仪及门生故吏。

### 15. 陈球主张以皇太后礼葬窦氏

**[《后汉书·张王种陈列传》](../../sources/摘录/后汉书-卷056-张王种陈列传.md#p004)** · [仓内TXT L4177](../../sources/本地分卷/后汉书/后汉书-卷056.md#L4177)

> 熹平元年，竇太后崩。太后本遷南宮雲台，宦者積怨竇氏，遂以衣車載後屍，置城南市捨數日。中常侍曹節、王甫欲用貴人體殯，帝曰：「太後親立朕躬，統承大業。詩云：『無德不報，無言不酬。』豈宜以貴人終乎？」於是發喪成禮。及將葬，節等復欲別葬太后，而以馮貴人配祔。

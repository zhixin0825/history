[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **太学刊立五经石刻。** 四年春三月，诏诸儒正《五经》文字，刻石立于太学门外。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **封河间王建子佗为任城王。** [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **郡国七大水。** 夏四月，郡国七大水。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **大赦天下。** 五月丁卯，颁布大赦。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **延陵园灾，遣使者持节告祠延陵。** 延陵园灾，派使者持节告祠延陵。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **鲜卑寇幽州。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **弘农、三辅螟。** 六月，弘农、三辅螟。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **遣守宫令之盐监，穿渠为民兴利。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **令郡国遇灾者，减田租之半。** 命各郡国遇灾者，减田租之半；其伤害十四以上，勿收责。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **令天下系囚罪未决，入缣赎。** 冬十月丁巳，令天下系囚罪未决，入缣赎。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **拜冲帝母虞美人为宪园贵人，质帝母陈夫人为渤海孝王妃。** [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **改平准为中准，使宦者为令，列於内署。** 改平准为中准，使宦者为令，列于内署。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **自是诸署悉以阉人为丞、令。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **蔡邕等奏正六经文字。** 蔡邕会同杨赐、堂溪典、马日磾等请校定六经文字，朝廷许可。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **卢植守九江，抚定当地反抗。** 九江反叛后，卢植受四府所举，任太守并使反叛者归服。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **小黄门赵佑、议郎卑整上言。** 熹平四年，小黄门赵佑、议郎卑整上言：『《春秋》之义，母以子贵。隆汉盛典，尊崇母氏，凡在外戚，莫不加宠。今冲帝母虞大家，质帝母陈夫人，皆诞生圣皇，而未有称号。夫臣子虽贱，尚有追赠之典，况二母见在，不蒙崇显之次，无以述遵先世，垂示后世也。』 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **灵帝复立河闲贞王新昌侯佗为任城王，奉孝王后。** 熹平四年，灵帝复立河闲贞王新昌侯佗为任城王，奉孝王后。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **灵帝乃诏诸儒正定《五经》。** 熹平四年，灵帝乃诏诸儒正定《五经》，刊于石碑，爲古文、篆、隶三体书法以相参检，树之学门，使天下咸取则焉。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **灵帝熹平四年，五官郎中冯光、沛相上计掾陈晃言。** 灵帝熹平四年，五官郎中冯光、沛相上计掾陈晃言：「历元不正，故妖民叛寇益州，盗贼相续为。历用甲寅为元而用庚申，图纬无以庚为元者。近秦所用代周之元。太史治治历中郭香、刘固意造妄说，乞本庚申元经纬明，受虚欺重诛。」 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **灵帝熹平四年五月，延陵园灾。** [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **灵帝熹平四年六月，弘农、三辅螟虫爲害。** [[21]](#hh-note-21)

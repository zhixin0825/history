# 公元180年｜光和三年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **大赦天下。** 三年春正月癸酉，颁布大赦。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **公府驻驾庑自坏。** 二月，公府驻驾庑自坏。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **梁王元薨。** 三月，梁王元去世。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **江夏蛮叛。** 夏四月，江夏蛮叛。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **诏公卿举能通《古文尚书》。** 六月，诏公卿举能通《古文尚书》、《毛诗》、《左氏》、《谷梁春秋》各一人，悉除议郎。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **表是地震，涌水出。** 秋，表是地震，涌水出。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **令系囚罪未决，入缣赎，各有差。** 八月，令系囚罪未决，入缣赎，各有差。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **闰月，有星孛於狼、弧。** 冬闰月，有星孛于狼、弧。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **鲜卑寇幽、幷二州。** [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **立贵人何氏为皇后。** 十二月己巳，立贵人何氏为皇后。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **是岁，作罼圭、灵昆苑。** 当年，作罼圭、灵昆苑。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **彗星出狼、弧，东行至於张乃去。** 《天文志》记三年冬，彗星出狼、弧，东行至於张乃去。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **立为皇后。** 光和三年，立为皇后。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **江夏蛮复反，与庐江贼黄穰相连结，十余万人，攻没四县，寇患累年。** 光和三年，江夏蛮复反，与庐江贼黄穰相连结，十余万人，攻没四县，寇患累年。 [[14]](#hh-note-14)

**归年与互校** 何进传作光和二年；灵帝纪（L1139）载三年十二月己巳，皇后纪（L1395）亦作三年，采用180。

<a id="sgz006-p-005-2"></a>

> 光和三年立為皇后進由是貴幸

**释读** 光和三年，何氏立为皇后，何进由此贵幸。

**归年** 注书光和三年，《后汉书·灵帝纪》同。

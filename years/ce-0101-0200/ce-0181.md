7. **河南言凤皇见新城，群鸟随之。** 秋七月，河南言凤皇见新城，群鸟随之；赐新城令及三老、力田帛，各有差。 [[7]](#hh-note-7)

11. **司徒杨赐罢。** [[11]](#hh-note-11)

<a id="hh-event-13"></a>

13. **鲜卑寇幽、幷二州。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **是岁，帝作列肆於後宫，使诸采女贩卖，更相盗窃争斗。** 当年，帝作列肆于后宫，使诸采女贩卖，更相盗窃争斗。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **帝着商估服，饮宴为乐。** [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **又於西园弄狗，着进贤冠，带绶。** 又于西园弄狗，着进贤冠，带绶。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **又驾四驴，帝躬自操辔，驱驰周旋，京师转相放效。** [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **张奂去世。** 张奂七十八岁去世，遗言反对烦奢丧仪。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **灵帝光和四年秋，五色大鸟见於新城，众鸟随之，时以为凤皇。** 灵帝光和四年秋，五色大鸟见于新城，众鸟随之，时以为凤皇。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **雨雹，大如鸡子。** 光和四年六月，雨雹，大如鸡子。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **黄气抱日，黄白珥在其表。** 光和四年二月己巳，黄气抱日，黄白珥在其表。 [[21]](#hh-note-21)

[返回正文第18条](#hh-event-18)

<a id="hh065-l4742-e18"></a>

> 光和四年卒，年七十八。遺命曰：「吾前後仕進，十要銀艾，不能和光同塵，為讒邪所忌。通塞命也，始終常也。但地厎冥冥，長無曉期，而復纏以纊撓，牢以釘密，為不喜耳。幸有前窀，朝殞夕下，措屍靈默，幅巾而已。奢非晉文，儉非王孫，推情從意，庶無咎吝。」諸子從之。武威多為立祠，世世不絕。所著銘、頌、書、教、誡述、志、對策、章表二十四篇。

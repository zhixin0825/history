## 本年概述

光和五年，陈耽和曹操指出公卿举劾避开宦官亲信，朝廷命追问。袁隗继任司徒。巴郡板楯蛮投降；灵帝出巡广成苑，年底回京后到太学。

## 灵帝朝政及巡行

<a id="hh-event-3"></a>

<a id="hh-event-5"></a>

<a id="hh-event-14"></a>

1. **陈耽与曹操谏不实举劾，袁隗继任司徒。** 朝廷令公卿据民谣举奏害民的刺史、郡守。司徒陈耽与议郎曹操上书指出，许戫、张济避开宦官亲信，反而举劾边郡小官。灵帝下令追问。三月陈耽免为司徒，以太常袁隗继任。 [[1]](#hh-note-3)

<a id="hh-event-11"></a>

2. **太尉许<有>罢，太常杨赐为太尉。** 冬十月，太尉许<有>罢，太常杨赐为太尉。 [[2]](#hh-note-11)

<a id="hh-event-9"></a>

3. **令系囚罪未决，入缣赎。** 癸酉，令系囚罪未决，入缣赎。 [[3]](#hh-note-9)

<a id="hh-event-10"></a>

4. **起四百尺观於阿亭道。** 八月，起四百尺观于阿亭道。 [[4]](#hh-note-10)

<a id="hh-event-12"></a>

<a id="hh-event-13"></a>

5. **灵帝校猎并巡行广成苑，回京临太学。** 灵帝在上林苑校猎，经函谷关到广成苑巡狩。十二月回京后到太学。 [[5]](#hh-note-12)

<a id="hh-event-1"></a>

6. **大赦天下。** 五年春正月辛未，颁布大赦。 [[6]](#hh-note-1)

> 光和五年，詔公卿以謠言舉刺史﹑二千石為民蠹害者。時太尉許戫﹑司空張濟承望內官，受取貨賂，其宦者子弟賓客，雖貪污穢濁，皆不敢問，而虛愨邊遠小郡清修有惠化者二十六人。吏人詣闕陳訴，耽與議郎曹操上言：「公卿所舉，率黨其私，所謂放鴟梟而囚鸞鳳。」其言忠切，帝以讓戫﹑濟，由是諸坐謠言征者悉拜議郎。宦官怨之，遂誣陷耽死獄中。李雲

**归年与互校** 年次据本传。

<a id="wu-p-007-5"></a>

**[《三国志·武帝纪》裴注 007·5](../../sources/本地分卷/三国志/三国志-卷001.md#pei-007-5)**

> 是後詔書勑三府舉奏州縣政理無效民為作謠言者免罷之三公傾邪皆希世見用貨賂並行彊者為怨不見舉奏弱者守道多被陷毁太祖疾之是歲以災異博問得失因此復上書切諫說三公所舉奏專回避貴戚之意奏上天子感寤以示三府責讓之諸以謠言徵者皆拜議郎

**释读** 诏令三府据民谣举奏州县，曹操反对只举势弱而回避贵戚。皇帝责问三府，并将因民谣征还者任为议郎。

**归年** 《后汉书·刘陶传》仓内TXT L4222明记光和五年，司徒陈耽与议郎曹操上书，同记皇帝责问及因民谣被征者获拜议郎。

11. **太尉许<有>罢，太常杨赐为太尉。** 冬十月，太尉许<有>罢，太常杨赐为太尉。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **校猎上林苑，历函谷关，遂巡狩於广成苑。** 校猎上林苑，历函谷关，遂巡狩于广成苑。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **还，幸太学。** 十二月，还，幸太学。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **陈耽与曹操上书纠正不实举劾。** 朝廷诏公卿据民谣举奏害民的刺史、郡守。司徒陈耽与议郎曹操上书，指出许戫、张济避开宦官亲信而举劾边郡小官，灵帝下令责问。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **荧惑在太微中，守屏。** 《天文志》记五年四月，荧惑在太微中，守屏。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **彗星出三台下，东行入太微，至太子、幸臣，二十余日而消。** 《天文志》记七月，彗星出三台下，东行入太微，至太子、幸臣，二十余日而消。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **岁星、荧惑、太白三合於虚，相去各五六寸，如连珠。** 《天文志》记十月，岁星、荧惑、太白三合於虚，相去各五六寸，如连珠。 [[17]](#hh-note-17)

<a id="sy-event-18"></a>

18. **谏议大夫何休去世。** 何休终年五十四岁。 [[18]](#sy-note-18)

<a id="sgz-event-19"></a>

19. **甄氏出生。** 《魏书》记甄氏光和五年十二月丁酉生。 [[19]](#sgz-note-19)

### 14. 陈耽与曹操上书纠正不实举劾

[返回正文第14条](#hh-event-14)

<a id="hh057-l4222-e14"></a>

**[《后汉书·杜栾刘李刘谢列传》](../../sources/摘录/后汉书-卷057-杜栾刘李刘谢列传.md#p003)** · [仓内TXT L4222](../../sources/本地分卷/后汉书/后汉书-卷057.md#L4222)

> 光和五年，詔公卿以謠言舉刺史﹑二千石為民蠹害者。時太尉許戫﹑司空張濟承望內官，受取貨賂，其宦者子弟賓客，雖貪污穢濁，皆不敢問，而虛愨邊遠小郡清修有惠化者二十六人。吏人詣闕陳訴，耽與議郎曹操上言：「公卿所舉，率黨其私，所謂放鴟梟而囚鸞鳳。」其言忠切，帝以讓戫﹑濟，由是諸坐謠言征者悉拜議郎。宦官怨之，遂誣陷耽死獄中。李雲

**归年与互校** 年次据本传。

<a id="wu-p-007-5"></a>

**[《三国志·武帝纪》裴注 007·5](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-007-5)**

> 是後詔書勑三府舉奏州縣政理無效民為作謠言者免罷之三公傾邪皆希世見用貨賂並行彊者為怨不見舉奏弱者守道多被陷毁太祖疾之是歲以災異博問得失因此復上書切諫說三公所舉奏專回避貴戚之意奏上天子感寤以示三府責讓之諸以謠言徵者皆拜議郎

**释读** 诏令三府据民谣举奏州县，曹操反对只举势弱而回避贵戚。皇帝责问三府，并将因民谣征还者任为议郎。

**归年** 《后汉书·刘陶传》仓内TXT L4222明记光和五年，司徒陈耽与议郎曹操上书，同记皇帝责问及因民谣被征者获拜议郎。

## 本年概述

中平三年，江夏兵赵慈杀南阳太守秦颉，羊续与荆州刺史王敏发兵平定。张温在长安受任太尉，前太尉张延后来下狱而死。武陵与幽、并先后有兵事。张温从凉州战场还朝后，韩遂的兵势扩大，进围陇西。

### 4. 孙坚出任议郎

[返回正文第4条](#ce0186-event-4)

**互校** 《孙坚传》将张温奉命西征系于中平三年；《灵帝纪》《资治通鉴》列在上年，参[美阳、榆中及军中议董卓](ce-0185.md#sgz046-b-2249-3)。本传接叙孙坚任议郎，拜官的年月未载。

<a id="sg-note-17"></a>



<a id="sg046-l2249-e17"></a>

[本傳所載中平三年原文](ce-0185.md#sgz046-b-2249-2)。

<a id="sgz046-b-2249-3"></a>

[原句移至185年第18条](ce-0185.md#sgz046-b-2249-3)。

<a id="sgz046-b-2249-4"></a>

**[《三國志·孫破虜討逆傳》](../../sources/本地分卷/三国志/三国志-卷046.md#edition-sgz046-b-2249-4)** · [TXT L19](../../sources/本地分卷/三国志/三国志-卷046.txt#L19)

> 章、遂聞大兵向至，黨衆離散，皆乞降。軍還，議者以軍未臨敵，不斷功賞，然聞堅數卓三罪，勸溫斬之，無不歎息。拜堅議郎。

**释读** 边章及韩遂一方据本传曾离散乞降。官军回来议功未决，多人赞孙坚能看出董卓三罪；孙坚后来被授议郎。

**归年** 本传西征后段，旧186#17维持该役；《灵帝纪》张温与边韩后续交战另有记载，不能据此说凉州已定。

### 5. 边章死，韩遂进围陇西

[返回正文第5条](#ce0186-event-5)

**互校** 《董卓传》继中平三年冬张温还京记韩遂杀边章等，《资治通鉴》将此事系于次年春。《典略》另称边章病卒。

<a id="sgz-note-18"></a>



<a id="wu-p-096-3"></a>

**[《三国志·武帝纪》裴注 096·3](../../sources/本地分卷/三国志/三国志-卷001.md#pei-096-3)**

> 章尋病卒遂為揚等所劫不得已遂阻兵為亂積三十二年

**释读** 《典略》称边章不久病卒，宋扬等胁迫韩遂，韩遂其后据兵多年。

**归年** 同号《董卓传》说韩遂杀边章，《资治通鉴》从其死因而另系次年。《典略》所写“尋”不足以推算独立病卒年，附此对读。

<a id="hh072-l5154-e18"></a>

**[《后汉书·董卓传》仓内原文 L5154](../../sources/本地分卷/后汉书/后汉书-卷072.md#L5154)**

> 其冬，徵溫還京師，韓遂乃殺邊章及伯玉、文侯，擁兵十餘萬，進圍隴西。

**归年** 《董卓传》接中平三年冬张温还京。《资治通鉴》卷五十八系于[中平四年春](ce-0187.md#sg-review-187-hansui)，列在耿鄙出兵以前。

1. **江夏兵赵慈反，杀南阳太守秦颉。** 三年春二月，江夏兵赵慈反，杀南阳太守秦颉。 [[1]](#hh-note-1)

2. **大赦天下。** 庚戌，颁布大赦。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **大尉张延罢。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **车骑将军张温为太尉，中常侍赵忠为车骑将军。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **复修玉堂殿，铸铜人四，黄钟四，及天禄、虾蟆，又铸四出文钱。** [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **日有食之。** 五月壬辰晦，发生日食。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **荆州刺史王敏讨赵慈，斩之。** 六月，荆州刺史王敏讨赵慈，斩之。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **车骑将军赵忠罢。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **怀陵上有雀万数，悲鸣，因斗相杀。** 秋八月，怀陵上有雀万数，悲鸣，因斗相杀。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **武陵蛮叛，寇郡界，郡兵讨破之。** 冬十月，武陵蛮叛，寇郡界，郡兵讨破之。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **前太尉张延为宦人所谮，下狱死。** 前太尉张延为宦人所谮，下狱后死亡。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **鲜卑寇幽、幷二州。** 十二月，鲜卑寇幽、幷二州。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **荧惑逆行守心後星，十月戊午，月食心後星。** 《天文志》记三年四月，荧惑逆行守心後星，十月戊午，月食心後星。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **江夏兵赵慈反叛，杀南阳太守秦颉，攻没六县，拜续为南阳太守。** 中平三年，江夏兵赵慈反叛，杀南阳太守秦颉，攻没六县，拜续为南阳太守。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **中，怀陵上有万余爵，先极悲鸣，已因乱斗相杀，皆断头，悬着树枝枳棘。** 中平三年八月，中，怀陵上有万余爵，先极悲鸣，已因乱斗相杀，皆断头，悬着树枝枳棘。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **日有蚀之。** 中平三年五月壬辰晦，发生日食。 [[16]](#hh-note-16)

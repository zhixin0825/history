<a id="hh-event-1"></a>

1. **大赦天下。** 四年春正月己卯，颁布大赦。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **荥阳贼杀中牟令。** 二月，荥阳贼杀中牟令。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **南宫内殿罘罳自坏。** 己亥，南宫内殿罘罳自坏。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **河南尹何苗讨荥阳贼，破之，拜苗为车骑将军。** 三月，河南尹何苗讨荥阳贼，破之，拜苗为车骑将军。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **凉州刺史耿鄙讨金城贼韩遂，鄙兵大败，遂寇汉阳，汉阳太守傅燮战没。** 夏四月，凉州刺史耿鄙讨金城贼韩遂，鄙兵大败，遂寇汉阳，汉阳太守傅燮战没。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **扶风人马腾、汉阳人王国并叛，寇三辅。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **太尉张温免，司徒崔烈为太尉。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **司空许相为司徒，光禄勳沛国丁宫为司空。** 五月，司空许相为司徒，光禄勳沛国丁宫为司空。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **洛阳民生男，两头共身。** 六月，洛阳民生男，两头共身。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **渔阳人张纯与同郡张举举兵叛。** 渔阳人张纯与同郡张举举兵叛，攻杀右北平太守刘政、辽东太守杨终、护乌桓校尉公綦稠等。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **举自称天子，寇幽、冀二州。** [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **令天下系囚罪未决，入缣赎。** 秋九月丁酉，令天下系囚罪未决，入缣赎。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **零陵人观鹄自称。** 冬十月，零陵人观鹄自称『平天将军』，寇桂阳，长沙太守孙坚击斩之。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **太尉崔烈罢，大司农曹嵩为太尉。** 十一月，太尉崔烈罢，大司农曹嵩为太尉。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **休屠各胡叛。** 十二月，休屠各胡叛。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **是岁，卖关内侯，假金印紫绶，传世，入钱五百万。** 当年，卖关内侯，假金印紫绶，传世，入钱五百万。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **陈寔去世，何进遣使吊祭。** 陈寔年八十四卒，赴丧者传称三万余人，共立碑谥文范。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **何苗讨平荥阳之乱。** 荥阳多人攻县烧城，何苗率兵平叛，受拜车骑将军并封侯。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **前中山太守张纯反畔，遂率鲜卑寇边郡。** 中平四年，前中山太守张纯反畔，遂率鲜卑寇边郡。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **前中山太守张纯畔，入丘力居众中，自号弥天安定王，遂为诸郡乌桓元帅，寇掠青、徐、幽、冀四州。** 中平四年，前中山太守张纯畔，入丘力居众中，自号弥天安定王，遂为诸郡乌桓元帅，寇掠青、徐、幽、冀四州。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **雨水，大雷电。** 中平四年十二月晦，雨水，大雷电。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **黑气大如瓜，在日中。** 中平四年三月丙申，黑气大如瓜，在日中。 [[22]](#hh-note-22)

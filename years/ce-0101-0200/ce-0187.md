<a id="hh-event-16"></a>

16. **是岁，卖关内侯，假金印紫绶，传世，入钱五百万。** 当年，卖关内侯，假金印紫绶，传世，入钱五百万。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **陈寔去世，何进遣使吊祭。** 陈寔年八十四卒，赴丧者传称三万余人，共立碑谥文范。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **何苗讨平荥阳之乱。** 荥阳多人攻县烧城，何苗率兵平叛，受拜车骑将军并封侯。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **前中山太守张纯反畔，遂率鲜卑寇边郡。** 中平四年，前中山太守张纯反畔，遂率鲜卑寇边郡。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **前中山太守张纯畔，入丘力居众中，自号弥天安定王，遂为诸郡乌桓元帅，寇掠青、徐、幽、冀四州。** 中平四年，前中山太守张纯畔，入丘力居众中，自号弥天安定王，遂为诸郡乌桓元帅，寇掠青、徐、幽、冀四州。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **雨水，大雷电。** 中平四年十二月晦，雨水，大雷电。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **黑气大如瓜，在日中。** 中平四年三月丙申，黑气大如瓜，在日中。 [[22]](#hh-note-22)

<a id="sg-event-23"></a>

23. **曹丕出生于谯。** 曹丕为曹操太子，本纪称中平四年冬生于谯。 [[23]](#sg-note-23)

<a id="sgz-event-24"></a>

24. **孙坚出任长沙太守，平区星及零陵、桂阳武装。** 区星自号将军，率万人围城。朝廷以孙坚守长沙，孙坚到任亲自率军，旬月破区星。 [[24]](#sgz-note-24)

<a id="hh058-l4289-e5"></a>

**[《后汉书·虞傅盖臧列传》](../../sources/摘录/后汉书-卷058-虞傅盖臧列传.md#p003)** · [仓内TXT L4289](../../sources/本地分卷/后汉书/后汉书-卷058.md#L4289)

> 中平四年，鄙率六郡兵討金城賊王國、韓遂等。燮知鄙失觿，必敗，諫曰：「使君統政日淺，人未知教。孔子曰：『不教人戰，是謂□之。』今率不習之人，越大隴之阻，將十舉十危，而賊聞大軍將至，必萬人一心。邊兵多勇，其鋒難當，而新合之觿，上下未和，萬一內變，雖悔無及。不若息軍養德，明賞必罰。賊得寬挺，必謂我怯，腢惡爭埶，其離可必。然後率已教之人，討已離之賊，其功可坐而待也。

### 17. 陈寔去世，何进遣使吊祭

[返回正文第17条](#hh-event-17)

<a id="hh062-l4586-e17"></a>

**[《后汉书·荀韩钟陈列传》](../../sources/摘录/后汉书-卷062-荀韩钟陈列传.md#p005)** · [仓内TXT L4586](../../sources/本地分卷/后汉书/后汉书-卷062.md#L4586)

> 中平四年，年八十四，卒於家。何進遣使弔祭，海內赴者三萬餘人，制衰麻者以百數。共刊石立碑，謚為文范先生。

**归年与互校** 年次据本传。

<a id="sgz022-p-004-6"></a>

**[《三国志·桓二陈徐卫卢传》裴注 004·6](../../sources/摘录/三国志-卷022-桓二陈徐卫卢传裴注.md#pei-004-6)**

> 寔之亡也司空荀爽太僕令韓融並制緦麻執子孫禮四方至者車數千乘自太原郭泰等無不造門

**释读** 魏书记二人以子孙礼服丧，来致哀数千车，连郭泰等名士皆被举来说明其门誉。

**归年** 《后汉书》定陈寔中平四年（187）卒。郭泰同书本传在建宁二年（169）已卒，故这句不能释为他187年到场。

<a id="sgz022-p-004-7"></a>

**[《三国志·桓二陈徐卫卢传》裴注 004·7](../../sources/摘录/三国志-卷022-桓二陈徐卫卢传裴注.md#pei-004-7)**

> 傅子曰寔亡天下致弔㑹其葬者三萬人制縗麻者以百數

**释读** 远近致吊三万人，服衰麻以百计。

**归年** 《后汉书·陈寔传》同列中平四年卒吊。

<a id="sgz022-p-004-8"></a>

**[《三国志·桓二陈徐卫卢传》裴注 004·8](../../sources/摘录/三国志-卷022-桓二陈徐卫卢传裴注.md#pei-004-8)**

> 先賢行狀曰大將軍何進遣屬弔祠諡曰文範先生

**释读** 何进遣人吊祠，陈寔得谥文范先生。

**归年** 《后汉书·陈寔传》中平四年去世并载何进遣使祭。

### 24. 孙坚出任长沙太守，平区星及零陵、桂阳武装

[返回正文第24条](#sgz-event-24)

<a id="sgz046-b-2249-5"></a>

**[《三国志·孙破虏讨逆传》仓内原文 L2249](../../sources/本地分卷/三国志/三国志-卷046.md#l2249)**

> 時長沙賊區星自稱將軍，眾萬餘人攻圍城邑，乃以堅為長沙太守。到郡親率將士，施設方略，旬月之間，克破星等。

**归年** 《通鉴》卷058中平四年冬十月；本传仅接张温事之后未独记年。

<a id="sgz046-b-2249-6"></a>

**[《三国志·孙破虏讨逆传》仓内原文 L2249](../../sources/本地分卷/三国志/三国志-卷046.md#l2249)**

> 周朝、郭石亦帥徒眾起於零、桂，與星相應。遂越境尋討，三郡肅然。

**释读** 周朝、郭石各在零陵、桂阳起兵响应区星，孙坚越境讨定，三郡恢复秩序。

**归年** 与187区星之役相承，区星已破，分别进入邻郡。

<a id="sgz046-b-2249-7"></a>

**[《三国志·孙破虏讨逆传》仓内原文 L2249](../../sources/本地分卷/三国志/三国志-卷046.md#l2249)**

> 漢朝錄前後功，封堅為烏程侯。

**释读** 汉廷录孙坚前后功劳，封他为乌程侯。

**归年** 《通鉴》卷058中平四年，与讨区星相承。

<a id="sgz046-p-007-1"></a>

**[《三国志·孙破虏讨逆传》裴注 007·1](../../sources/摘录/三国志-卷046-孙破虏讨逆传裴注.md#pei-007-1)**

> 魏書曰堅到郡郡中震服任用良吏勅吏曰謹遇良善治官曹文書必循治以盗賊付太守

**释读** 孙坚令善待百姓，政务依法，盗贼归太守处置。

**归年** 接187讨区星任长沙太守，语令确日无载，附长沙任职同条。

<a id="sgz046-p-010-2"></a>

**[《三国志·孙破虏讨逆传》裴注 010·2](../../sources/摘录/三国志-卷046-孙破虏讨逆传裴注.md#pei-010-2)**

> 吳錄曰叡先與堅共擊零桂賊以堅武官言頗輕之

**释读** 王叡先前与孙坚共击零、桂之众，因为孙坚是武官，言语间轻视他。

**归年** 《吴录》回指孙坚任长沙期间邻郡讨伐，旧传无另年，接187讨区星的同一战争阶段。

16. **大鸿胪韩融、少府阴修、执金吾胡母班、将作大匠吴修、越骑校尉王瓌安集关东，後将军袁术、河内太…。** 大鸿胪韩融、少府阴修、执金吾胡母班、将作大匠吴修、越骑校尉王瓌安集关东，后将军袁术、河内太守王匡各执而杀之，唯韩融获免。 [[16]](#hh-note-16)

17. **董卓坏五铢钱，更铸小钱。** [[17]](#hh-note-17)

<a id="hh-event-19"></a>

19. **是岁，有司奏，和、安、顺、桓四帝无功德，不宜称宗，又恭怀、敬隐、恭愍三皇后并非正嫡，不合称…。** 当年，有司奏，和、安、顺、桓四帝无功德，不宜称宗，又恭怀、敬隐、恭愍三皇后并非正嫡，不合称后，皆请除尊号。 [[19]](#hh-note-19)

22. **蔡邕随献帝迁都长安。** 蔡邕拜左中郎将，随帝西行，受封高阳乡侯。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **刘虞受命为太傅。** 刘虞先受任大司马、封襄贲侯，次年朝廷再征代袁隗为太傅，但道路阻断。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **公孙度经营辽东。** 公孙度分辽东置郡，又过海收东莱数县，自称辽东侯、平州牧。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

<a id="hh-event-26"></a>

26. **从大驾西迁长安，後时入掖庭为贵人。** 初平元年，从大驾西迁长安，后时入掖庭为贵人。 [[26]](#hh-note-26)

<a id="hh-event-27"></a>

27. **遣弟邈至长安奉章贡献，帝以邈为九江太守，封阳都侯。** 初平元年，遣弟邈至长安奉章贡献，帝以邈为九江太守，封阳都侯。 [[27]](#hh-note-27)

<a id="hh-event-28"></a>

28. **馥等到官，与袁绍之徒十余人，各兴义兵，同盟讨卓，而伍琼、周珌阴为内主。** 初平元年，馥等到官，与袁绍之徒十余人，各兴义兵，同盟讨卓，而伍琼、周珌阴为内主。 [[28]](#hh-note-28)

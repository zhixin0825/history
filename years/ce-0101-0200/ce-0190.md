35. **太祖曰“举义兵以诛暴乱”。** 太祖曰：「举义兵以诛暴乱，大衆已合，诸君何疑？向使董卓闻山东兵起，倚王室之重，据二周之险，东向以临天下；虽以无道行之，犹足爲患。今焚烧宫室，劫迁天子，海内震动，不知所归，此天亡之时也。一战而天下定矣，不可失也。」 [[35]](#sg-note-35)

<a id="sg-event-36"></a>

36. **曹操战于荥阳汴水。** 遂引兵西，将据成臯。邈遣将衞兹分兵随太祖。到荧阳汴水，遇卓将徐荣，与战不利，士卒死伤甚多。太祖爲流矢所中，所乘马被创，从弟洪以马与太祖，得夜遁去。 [[36]](#sg-note-36)

<a id="sg-event-37"></a>

37. **荣见太祖所将兵少，力战尽日。** 荣见太祖所将兵少，力战尽日，谓酸枣未易攻也，亦引兵还。 [[37]](#sg-note-37)

<a id="sg-event-38"></a>

38. **太祖到酸枣，诸军兵十余万。** 太祖到酸枣，诸军兵十余万，日置酒高会，不图进取。 [[38]](#sg-note-38)

<a id="sg-event-39"></a>

39. **太祖责让之，因爲谋曰“诸君听吾计”。** 太祖责让之，因爲谋曰：「诸君听吾计，使勃海引河内之衆临孟津，酸枣各将领守成臯，据敖仓，塞轘辕、太谷，全制其险；使袁将军率南阳之军军丹、析，入武关，以震三辅：皆高垒深壁，勿与战，益爲疑兵，示天下形势，以顺诛逆，可立定也。今兵以义动，持疑而不进，失天下之望，窃爲诸君耻之！」 [[39]](#sg-note-39)

<a id="sg-event-45"></a>

<a id="sy-event-46"></a>

46. **董卓征皇甫嵩为城门校尉，拟以狱案诛杀。** 董卓因旧怨征召皇甫嵩，长史梁衍建议拒不应召并联合关东义军，皇甫嵩不从；有司承董卓意旨拟诛。 [[46]](#sy-note-46)

<a id="wu-event-47"></a>

47. **郑泰向董卓说孔伷善清谈。** 关东各军起兵后，郑泰为劝董卓不征大兵，向他说孔伷擅清谈、能“嘘枯吹生”，却无实战才能。 [[47]](#wu-note-47)

<a id="wu-b-063-1"></a>

**[《三国志·武帝纪》仓内原文 L63](../../sources/本地分卷/三国志/三国志-卷001.md#l63)**

> 初，紹與公共起兵，紹問公曰：「若事不輯，則方面何所可據？」公曰：「足下意以爲何如？」紹曰：「吾南據河，北阻燕、代，兼戎狄之衆，南向以爭天下，庶可以濟乎？」公曰：「吾任天下之智力，以道御之，無所不可。」

**释读** 两人共起兵时，袁绍设想凭河北地势、军力南争天下；曹操表示要任用天下智力。

**归年** “共起兵”对应初平元年关东诸军共同讨董卓，据本纪L8；这是破邺后追叙，未记会话确月。

<a id="wu-p-060-1"></a>

**[《三国志·武帝纪》裴注 060·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-060-1)**

> 傅子曰太祖又云湯武之王豈同土哉若以險固為資則不能應機而變化也

**释读** 曹操又以商汤、周武王不依同一地势取得天下为例，认为只靠地势会失去随机应变的能力。

**归年** “又云”接正文L63曹操、袁绍共起兵时的对话，约初平元年。

<a id="sgz002-p-049-2"></a>

**[《三国志·文帝纪》裴注 049·2](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-049-2)**

> 山東牧守咸以春秋之義衛人討州吁于濮言人人皆得討賊於是大興義兵名豪大俠富室强族飄揚雲會萬里相赴兗豫之師戰于滎陽河内之甲軍於孟津

**释读** 曹丕称州牧郡守援旧典起兵，豪强多响应，兖、豫军战荥阳，河内军据孟津。

**归年** 本纪武帝纪L8–9、荥阳与河内军诸事在初平元年。

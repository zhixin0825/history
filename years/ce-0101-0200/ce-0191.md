4. **董卓遂发掘洛阳诸帝陵。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **董卓入长安。** 夏四月，董卓入长安。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **地震。** 六月丙戌，地震。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **司空种拂免，光禄大夫济南淳于嘉为司空。** 秋七月，司空种拂免，光禄大夫济南淳于嘉为司空。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **太尉赵谦罢，太常马日磾为太尉。** [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **蚩尤旗见於角、亢。** 九月，蚩尤旗见于角、亢。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **董卓杀卫尉张温。** 冬十月壬戌，董卓杀卫尉张温。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **青州黄巾寇太山，太山太守应劭击破之。** 十一月，青州黄巾寇太山，太山太守应劭将其击败。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **黄巾转寇勃海，公孙瓒与战於东光，复大破之。** 黄巾转寇勃海，公孙瓒与战于东光，复大破之。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **是岁，长沙有人死经月复活。** 当年，长沙有人死经月复活。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **赵谦为谢弼伸冤，韩绍伏诛。** 赵谦追论谢弼被害之事，遂依法收斩韩绍。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **董卓拟封王允温侯，王允减受食邑。** 董卓按入关之功封王允五千户，王允让后只受二千户。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **荀彧离袁绍从曹操。** 荀彧认为袁绍不能成事，遂离袁绍而从曹操。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **袁绍等欲立刘虞。** 韩馥等谋尊刘虞，刘虞拒绝，后遣田畴等奉使长安。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **刘焉击任岐、贾龙。** 犍为太守任岐、贾龙起兵攻刘焉，均被击杀。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **孝献初平二年九月，蚩尤旗见，长十余丈，色白，出角、亢之南。** 《天文志》记孝献初平二年九月，蚩尤旗见，长十余丈，色白，出角、亢之南。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **献帝初平二年三月，长安宣平城门外屋无故自坏。** [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **献帝初平二年六月丙戌，地震。** [[21]](#hh-note-21)

<a id="sg-event-22"></a>

22. **卓还长安。** 夏四月，卓还长安。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **袁绍胁韩馥，取冀州。** 秋七月，袁绍胁韩馥，取冀州。 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **曹操破白绕，领东郡太守。** 黑山贼于毒、白绕、眭固等十余万衆略魏郡、东郡，王肱不能御，太祖引兵入东郡，击白绕于濮阳，破之。 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **袁绍因表太祖爲东郡太守。** 袁绍因表太祖爲东郡太守，治东武阳。 [[25]](#sg-note-25)

<a id="sg-event-26"></a>

26. **孙坚入洛阳整修诸陵。** 孙坚抵达洛阳，修复诸陵并填掩被盗掘处，随后回军鲁阳。 [[26]](#sg-note-26)

<a id="sg-review-191-event"></a>

27. **孙坚攻刘表遇害（《资治通鉴》系年）。** 袁术使孙坚攻刘表，孙坚追黄祖时中箭身亡。司马光依据张璠《汉纪》和胡冲《吴历》列在初平二年。两部正史的初平三年说明见[192年第2条](ce-0192.md#hh-note-2)。 [[27]](#sg-review-191-note)

<a id="sgz-event-28"></a>

28. **刘焉遣张鲁据汉中、切断谷道。** 刘焉任张鲁为督义司马，遣往汉中，占谷道并杀汉使；刘焉上书称米贼阻路。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **献帝遣刘璋劝谕，刘焉将其留下。** 献帝令刘璋入蜀劝父，刘焉留下刘璋。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **刘焉召刘璋回蜀的异载。** 《典略》说刘焉托病，刘璋请求探望父亲，于是被留下。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **献帝命刘和出关召兵。** 献帝思东归，令侍中刘和假装逃亡，潜出武关请刘虞发兵迎驾，袁术因想取得刘虞支援而扣留刘和。 [[31]](#sgz-note-31)

<a id="sgz-event-32"></a>

32. **刘虞发骑；公孙瓒遣越与袁术联络。** 刘虞见书后派数千骑。公孙瓒先阻而不果，随后遣从弟公孙越将千骑至袁术处，暗劝袁术夺刘和兵，嫌隙转深。刘和出走又被袁绍留住。 [[32]](#sgz-note-32)

<a id="sgz-event-33"></a>

33. **阳城冲突、公孙越中箭死。** 袁绍部将周昂占孙坚所屯阳城，袁术使公孙越助孙坚进取，公孙越中箭死。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **公孙瓒屯磐河，公孙范转用勃海兵。** 公孙瓒以弟死怨袁绍，出兵屯磐河。袁绍授公孙范勃海太守以望结援，反被公孙范以其兵助公孙瓒。 [[34]](#sgz-note-34)

<a id="sgz-event-35"></a>

35. **公孙瓒上疏数袁绍前六项罪。** 以君臣礼法起笔，指控袁绍引董卓入京、失其节传、起兵使宗族受诛、克剥百姓、夺冀州疑有僭意、以观察星日约期劫郡县。 [[35]](#sgz-note-35)

<a id="sgz-event-36"></a>

36. **公孙瓒数袁绍后四项罪。** 指控袁绍杀有功的刘勋、逼死高焉姚贡，以出身贬袁绍，又指袁绍夺孙坚豫州、断其粮，以此使董卓未灭。 [[36]](#sgz-note-36)

<a id="sgz-event-37"></a>

37. **公孙瓒上疏请讨袁绍。** 称常得袁术非袁绍同类的书信，援齐桓晋文尊王旧例，请率诸将州郡兵伐罪，战情续报。 [[37]](#sgz-note-37)

<a id="sgz-event-38"></a>

38. **公孙瓒自置三州长官。** 署严纲主冀州、田楷主青州、单经主兖州，并安排郡县官。 [[38]](#sgz-note-38)

<a id="sgz-event-39"></a>

39. **於夫罗劫张杨，董卓任张杨河内太守。** 於夫罗欲背袁绍，劫持张杨。麴义在邺南追击并获胜，於夫罗到黎阳后击败度辽将军耿祉，部众再振，董卓任张杨为建义将军、河内太守。 [[39]](#sgz-note-39)

### 35. 公孙瓒上疏数袁绍前六项罪

[返回正文第35条](#sgz-event-35)

<a id="sgz008-b-407-1"></a>

**[《三国志·二公孙陶四张传》仓内原文 L407](../../sources/本地分卷/三国志/三国志-卷008.md#l407)**

> 臣聞皇、羲以來，始有君臣上下之事，張化以導民，刑罰以禁暴。今行車騎將軍袁紹，託其先軌，寇竊人爵，既性暴亂，厥行淫穢。昔為司隸校尉，會值國家喪禍之際，太后承攝，何氏輔政，紹專為邪媚，不能舉直，至令丁原焚燒孟津，招來董卓，造為亂根，紹罪一也。卓既入雒而主見質，紹不能權譎以濟君父，而棄置節傳，迸竄逃亡，忝辱爵命，背上不忠，紹罪二也。紹為勃海太守，默選戎馬，當攻董卓，不告父兄，至使太傅門戶，太僕母子，一旦而斃，不仁不孝，紹罪三也。紹既興兵，涉歷二年，不恤國難，廣自封殖，乃多以資糧專為不急，割剝富室，收考責錢，百姓吁嗟，莫不痛怨，紹罪四也。韓馥之迫，竊其虛位，矯命詔恩，刻金印玉璽，每下文書，皁囊施檢，文曰『詔書一封，邟鄉侯印』。邟，口浪反。昔新室之亂，漸以即真，今紹所施，擬而方之，紹罪五也。紹令崔巨業候視星日，財貨賂遺，與共飲食，剋期會合，攻鈔郡縣，此豈大臣所當宜為？紹罪六也。

**归年** 《通鉴》卷060置磐河举兵时（191）；疏内189年董卓事、190年宗族受诛、191年夺冀州是公孙瓒的追诉。

<a id="sgz008-p-008-1"></a>

**[《三国志·二公孙陶四张传》裴注 008·1](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-008-1)**

> 典略載瓉表紹罪状曰臣聞皇羲以來始有君臣上下之事張化以導民刑罰以禁暴今行車騎将軍袁紹托其先軌㓂竊人爵既性暴亂厥行淫穢昔為司隷校尉㑹國家値喪禍之際太后承攝何氏輔政紹專為邪媚不能舉直至令丁原焚燒孟津招來董卓造為亂根紹罪一也卓既入雒而主見質紹不能權謀以濟君父而棄置節傳迸竄逃亡忝辱爵命背上不忠紹罪二也紹為渤海太守黙選戎馬當攻董卓不告父兄至使太傅門户太僕母子一旦而斃不仁不孝紹罪三也紹既興兵涉歴二年不䘏國難廣自封殖乃多以資糧專為不急割剝富室收考責錢百姓吁嗟莫不痛怨紹罪四也韓馥之廹竊其虚位矯命詔恩刻金印玉璽每下文書皂嚢施檢文曰詔書一封邟口浪反鄉侯印昔新室之亂漸以即眞今紹所施擬而方之紹罪五也紹令崔巨業候視星日財貨賂遺與共飲食克期㑹合攻鈔郡縣此豈大臣所當宜為紹罪六也

**释读** 《典略》引公孙瓒上表，指袁绍引董卓入京都、弃节逃亡、连累袁氏、借兵敛财、迫韩馥僭制，又使崔巨业占候以谋攻郡县。

**归年** 《通鉴》卷060在初平二年公孙瓒屯磐河、袁绍授公孙范渤海守后录公孙瓒上疏。《全书TXT》本卷L407保存同段。

### 36. 公孙瓒数袁绍后四项罪

[返回正文第36条](#sgz-event-36)

<a id="sgz008-b-407-2"></a>

**[《三国志·二公孙陶四张传》仓内原文 L407](../../sources/本地分卷/三国志/三国志-卷008.md#l407)**

> 紹與故虎牙都尉劉勛首共造兵，勳仍有效，又降伏張楊，而以小忿枉害於勳，信用讒慝，殺害有功，紹罪七也。紹又上故上谷太守高焉、故甘陵相姚貢，橫責其錢，錢不備畢，二人並命，紹罪八也。春秋之義，子以母貴。紹母親為婢使，紹實微賤，不可以為人後，以義不宜，乃據豐隆之重任，忝污王爵，損辱袁宗，紹罪九也。又長沙太守孫堅，前領豫州刺史，驅走董卓，掃除陵廟，其功莫大；紹令周昂盜居其位，斷絕堅糧，令不得入，使卓不被誅，紹罪十也。

**归年** 上疏在191，文中行事、籍贯及私生指控按上疏态度处理，不作独立实证。

<a id="sgz008-p-008-2"></a>

**[《三国志·二公孙陶四张传》裴注 008·2](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-008-2)**

> 紹與故虎牙都尉劉勲首共造兵勲仍有効又降服張楊而以小忿枉害于勲信用䜛慝殺害有功紹罪七也紹又上故上谷太守髙焉故甘陵相姚貢横責其錢錢不備畢二人并命紹罪八也春秋之義子以母貴紹母親為婢使紹實㣲賤不可以為人後以義不宜乃據豊隆之重任忝汚王爵損辱袁宗紹罪九也又長沙太守孫堅前領豫州刺史驅走董卓掃除陵廟其功莫大紹令周昻盗居其位斷絶堅糧令不得入使卓不被誅紹罪十也

**释读** 公孙瓒指袁绍杀刘勋、敛钱逼杀高焉与姚贡，藉袁氏家世责其承嗣，并指其命周昂夺孙坚屯地。

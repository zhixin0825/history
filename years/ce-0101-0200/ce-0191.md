<a id="hh-event-8"></a>

8. **太尉赵谦罢，太常马日磾为太尉。** [[8]](#hh-note-8)

<a id="hh-event-19"></a>

<a id="hh-event-9"></a>

9. **蚩尤旗见于角、亢。** 九月见蚩尤旗。《天文志》记其色白，长十余丈，出于角、亢以南。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **董卓杀卫尉张温。** 冬十月壬戌，董卓杀卫尉张温。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **青州黄巾寇太山，太山太守应劭击破之。** 十一月，青州黄巾寇太山，太山太守应劭将其击败。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **黄巾转寇勃海，公孙瓒与战於东光，复大破之。** 黄巾转寇勃海，公孙瓒与战于东光，复大破之。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **是岁，长沙有人死经月复活。** 当年，长沙有人死经月复活。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **赵谦为谢弼伸冤，韩绍伏诛。** 赵谦追论谢弼被害之事，遂依法收斩韩绍。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **董卓拟封王允温侯，王允减受食邑。** 董卓按入关之功封王允五千户，王允让后只受二千户。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **荀彧离袁绍从曹操。** 荀彧认为袁绍不能成事，遂离袁绍而从曹操。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **袁绍等欲立刘虞。** 韩馥等谋尊刘虞，刘虞拒绝，后遣田畴等奉使长安。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **刘焉击任岐、贾龙。** 犍为太守任岐、贾龙起兵攻刘焉，均被击杀。 [[18]](#hh-note-18)

<a id="hh-event-20"></a>

20. **献帝初平二年三月，长安宣平城门外屋无故自坏。** [[20]](#hh-note-20)

<a id="sg-event-22"></a>

22. **卓还长安。** 夏四月，卓还长安。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **袁绍胁韩馥，取冀州。** 秋七月，袁绍胁韩馥，取冀州。 [[23]](#sg-note-23)

<a id="sg-event-25"></a>

<a id="sg-event-24"></a>

24. **曹操破白绕，领东郡太守。** 于毒、白绕、眭固等攻掠魏郡、东郡，王肱不能抵御。曹操在濮阳击破白绕，袁绍于是表曹操为东郡太守，治东武阳。 [[24]](#sg-note-24)

<a id="sg-event-26"></a>

26. **孙坚入洛阳整修诸陵。** 孙坚抵达洛阳，修复诸陵并填掩被盗掘处，随后回军鲁阳。 [[26]](#sg-note-26)

<a id="sg-review-191-event"></a>

27. **孙坚攻刘表遇害（《资治通鉴》系年）。** 袁术使孙坚攻刘表，孙坚追黄祖时中箭身亡。司马光依据张璠《汉纪》和胡冲《吴历》列在初平二年。两部正史的初平三年说明见[192年第2条](ce-0192.md#hh-note-2)。 [[27]](#sg-review-191-note)

<a id="sgz-event-28"></a>

28. **刘焉遣张鲁据汉中、切断谷道。** 刘焉任张鲁为督义司马，遣往汉中，占谷道并杀汉使；刘焉上书称米贼阻路。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **献帝遣刘璋劝谕，刘焉将其留下。** 献帝令刘璋入蜀劝父，刘焉留下刘璋。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **刘焉召刘璋回蜀的异载。** 《典略》说刘焉托病，刘璋请求探望父亲，于是被留下。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **献帝命刘和出关召兵。** 献帝思东归，令侍中刘和假装逃亡，潜出武关请刘虞发兵迎驾，袁术因想取得刘虞支援而扣留刘和。 [[31]](#sgz-note-31)

<a id="sgz-event-32"></a>

32. **刘虞发骑；公孙瓒遣越与袁术联络。** 刘虞见书后派数千骑。公孙瓒先阻而不果，随后遣从弟公孙越将千骑至袁术处，暗劝袁术夺刘和兵，嫌隙转深。刘和出走又被袁绍留住。 [[32]](#sgz-note-32)

<a id="sgz-event-33"></a>

33. **阳城冲突、公孙越中箭死。** 袁绍部将周昂占孙坚所屯阳城，袁术使公孙越助孙坚进取，公孙越中箭死。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **公孙瓒屯磐河，公孙范转用勃海兵。** 公孙瓒以弟死怨袁绍，出兵屯磐河。袁绍授公孙范勃海太守以望结援，反被公孙范以其兵助公孙瓒。 [[34]](#sgz-note-34)

<a id="sgz-event-36"></a>

<a id="sgz-event-37"></a>

<a id="sgz-event-35"></a>

35. **公孙瓒上疏数袁绍前六项罪。** 以君臣礼法起笔，指控袁绍引董卓入京、失其节传、起兵使宗族受诛、克剥百姓、夺冀州疑有僭意、以观察星日约期劫郡县。 [[35]](#sgz-note-35)

<a id="sgz-event-38"></a>

38. **公孙瓒自置三州长官。** 署严纲主冀州、田楷主青州、单经主兖州，并安排郡县官。 [[38]](#sgz-note-38)

<a id="sgz-event-39"></a>

39. **於夫罗劫张杨，董卓任张杨河内太守。** 於夫罗欲背袁绍，劫持张杨。麴义在邺南追击并获胜，於夫罗到黎阳后击败度辽将军耿祉，部众再振，董卓任张杨为建义将军、河内太守。 [[39]](#sgz-note-39)

<a id="sgz-event-40"></a>

40. **韩馥因惧自杀。** 韩馥求离袁绍，转依张邈，见袁绍使者与张邈耳语，疑遭谋害，遂在厕所自杀。 [[40]](#sgz-note-40)

<a id="sgz-event-41"></a>

41. **赵云受举携兵投公孙瓒。** 常山举其将兵，公孙瓒因袁绍新得冀州而询问其来由，赵云说郡中愿归仁政。 [[41]](#sgz-note-41)

<a id="sgz-event-42"></a>

42. **梁东孙坚被袭，祖茂助其脱围。** 孙坚移梁东，被董卓军打散，令祖茂戴自己的红头巾分散追兵。祖茂后把头巾放在坟地焦柱上，伏草脱身。 [[42]](#sgz-note-42)

<a id="sgz-event-43"></a>

43. **董卓遣李傕求结亲，孙坚拒绝。** 孙坚返屯后，董卓派李傕等求结亲，并表示可以为孙氏子弟保举官职。孙坚指董卓败乱汉室，拒绝。 [[43]](#sgz-note-43)

<a id="sgz-event-44"></a>

44. **曹操表鲍信为济北相。** 曹操为东郡太守时，表请鲍信任济北相。 [[44]](#sgz-note-44)

<a id="sgz-event-45"></a>

45. **田豫年少依刘备。** 刘备投公孙瓒时，少年田豫归往，刘备十分赏识。 [[45]](#sgz-note-45)

<a id="sgz006-b-334-6"></a>

**[《三国志·董二袁刘传》仓内原文 L334](../../sources/本地分卷/三国志/三国志-卷006.md#l334)**

> 爲太師，號曰尚父。

**释读** 董卓拜太师，称尚父。

<a id="sgz006-p-097-2"></a>

**[《三国志·董二袁刘传》裴注 097·2](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-097-2)**

> 獻帝記曰卓既為太師復欲稱尚父以問蔡邕邕曰昔武王受命太公為師輔佐周室以伐無道是以天下尊之稱為尚父今公之功德誠為巍巍宜須關東悉定車駕東還然後議之乃止

**释读** 董卓已为太师，询问能否称尚父。蔡邕以周武王、太公故事为例，劝待关东平、帝还洛后再议，董卓遂止。

**归年** 初平二年二月董卓任太师之后。称尚父和正文写号曰尚父有异。

**归年** 《后汉书·献帝纪》《资治通鉴》卷060系初平二年。孙坚击董卓部将，正文以主帅代部众。

<a id="sgz046-b-2251-5"></a>

**[《三国志·孙破虏讨逆传》仓内原文 L2251](../../sources/本地分卷/三国志/三国志-卷046.md#l2251)**

> 是時，或間堅於術，術懷疑，不運軍糧。陽人去魯陽百餘里，堅夜馳見術，畫地計校，曰：「所以出身不顧，上為國家討賊，下慰將軍家門之私仇。堅與卓非有骨肉之怨也，而將軍受譖潤之言，還相嫌疑！」術踧踖，即調發軍糧。

**释读** 有人离间袁术、孙坚，袁术因此停供军粮。孙坚从阳人夜驰鲁阳解释要为国家讨董卓并报袁术家仇，袁术恢复供应。

**归年** 《通鉴》卷060直续初平二年阳人战，粮争系本次。

<a id="sgz046-p-013-1"></a>

**[《三国志·孙破虏讨逆传》裴注 013·1](../../sources/摘录/三国志-卷046-孙破虏讨逆传裴注.md#pei-013-1)**

> 英雄記曰初堅討董卓到梁縣之陽人卓亦遣兵步騎五千迎之陳郡太守胡軫為大督䕶呂布為騎督其餘步騎將校都督者甚衆軫字文才性急預宣言曰今此行也要當斬一青綬乃整齊耳諸將聞而惡之軍到廣成去陽人城數十里日暮士馬疲極當止宿又本受卓節度宿廣成秣馬飲食以夜進兵投曉攻城諸將惡憚軫欲賊敗其事布等宣言陽人城中賊已走當追尋之不然失之矣便夜進軍城中守備甚設不可掩襲於是吏士饑渴人馬甚疲且夜至又無壍壘釋甲休息而布又宣言相驚云城中賊出來軍衆擾亂奔走皆棄甲失鞍馬行十餘里定無賊㑹天明便還拾取兵器欲進攻城城守已固穿壍已深軫等不能攻而還

**释读** 胡轸性急，出师前扬言杀一青绶官。吕布等对他不满，至广成又诈称敌军已逃，引军夜进。部队惊乱丢弃军械，天明返回后城防已牢，攻不克而退。

**归年** 《通鉴》卷060、《献帝纪》初平二年阳人。四库以陈郡太守称胡轸，《通鉴》作东郡，仍保留。

<a id="sgz046-p-014-1"></a>

**[《三国志·孙破虏讨逆传》裴注 014·1](../../sources/摘录/三国志-卷046-孙破虏讨逆传裴注.md#pei-014-1)**

> 江表傳曰或謂術曰堅若得洛不可復制此為除狼而得虎也故術疑之

**释读** 有人说孙坚若得洛阳便无法控制，袁术因而生疑。

**归年** 《通鉴》卷060初平二年阳人战后，撤粮与同一封锁相续。

<a id="sgz046-p-015-1"></a>

**[《三国志·孙破虏讨逆传》裴注 015·1](../../sources/摘录/三国志-卷046-孙破虏讨逆传裴注.md#pei-015-1)**

> 江表傳載堅語曰大勲垂㨗而軍糧不繼此吳起所以歎泣於西河樂毅所以遺恨於垂成也願將軍深思之

**释读** 孙坚称大功将成而军粮中断，会重演吴起和乐毅壮志未遂之憾，希望袁术斟酌。

**归年** 初平二年鲁阳会袁术讨粮时的同一次说话。

<a id="sgz056-b-2677-4"></a>

**[《三国志·朱治朱然吕范朱桓传》仓内原文 L2677](../../sources/本地分卷/三国志/三国志-卷056.md#l2677)**

> 從破董卓於陽人，

**释读** 朱治随孙坚在阳人破董卓部将。

**归年** 《后汉书·刘虞传》初平二年，参《献帝纪》。

<a id="sgz006-p-071-1"></a>

**[《三国志·董二袁刘传》裴注 071·1](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-071-1)**

> 吳書曰時議者以靈帝失道使天下叛亂少帝㓜弱為賊臣所立又不識母氏所出幽州牧劉虞宿有德望紹等欲立之以安當時使人報術術觀漢室衰陵隂懐異志故外託公義以拒紹紹復與術書曰前與韓文節共建永世之道欲海内見再興之主今西名有㓜君無血脉之屬公卿以下皆媚事卓安可復信但當使兵往屯關要皆自蹙死於西東立聖君太平可冀如何有疑又室家見戮不念子胥可復北靣乎違天不祥願詳思之術荅曰聖主聰叡有周成之質賊卓因危亂之際威服百寮此乃漢家小厄之㑹亂尚未厭復欲興之乃云今主無血脉之屬豈不誣乎先人以來奕世相承忠義為先太傅公仁慈惻隱雖知賊卓必為禍害以信狥義不忍去也門户滅絶死亡流漫幸蒙逺近來相赴助不因此時上討國賊下刷家耻而圖於此非所聞也又曰室家見戮可復北靣此卓所為豈國家哉君命天也天不可讐况非君命乎慺慺赤心志在滅卓不識其他

**释读** 《吴书》说袁绍等想拥立幽州刘虞，以信告袁术。袁绍质疑献帝身份，谋使兵守关要。袁术回书主张合力灭董卓，无意废立。

**归年** 初平二年袁绍、韩馥欲立刘虞；信中西京幼君议论属于当事人陈说。

### 23. 袁绍胁韩馥，取冀州

<a id="sg006-l348-e23"></a>

**[《三国志·董二袁刘传》](../../sources/摘录/三国志-卷006-董二袁刘传.md#p003)** · [仓内TXT L348](../../sources/本地分卷/三国志/三国志-卷006.md#l348)

<a id="sgz007-b-396-3"></a>

**释读** 信中举张景明奔走说韩馥交印，使袁绍领冀州的往事。

**归年** 卷006《袁绍传》及《通鉴》卷060 L112–165明初平二年七月袁绍得冀州，裴注文补张导参与经过。

<a id="sgz007-p-023-1"></a>

**[《三国志·吕布臧洪传》裴注 023·1](../../sources/摘录/三国志-卷007-吕布臧洪传裴注.md#pei-023-1)**

> 臣松之案英雄記云袁紹使張景明郭公則高元才等説韓馥使讓冀州然馥之讓位景明亦有其功其餘之事未詳

**释读** 裴松之引《英雄记》说袁绍遣张景明、郭图、高干等劝韩馥交出冀州，张景明确有其功，其他未详。

**归年** 《通鉴》卷060 L113–165及卷006《袁绍传》可确初平二年七月韩馥让位；张景明被诛不在此明证内。

<a id="sgz006-b-348-3"></a>

**[《三国志·董二袁刘传》仓内原文 L348](../../sources/本地分卷/三国志/三国志-卷006.md#l348)**

> 後馥軍安平，爲公孫瓚所敗。瓚遂引兵入冀州，以討卓爲名，內欲襲馥。馥懷不自安。

**释读** 韩馥军在安平败于公孙瓒。公孙瓒借讨董卓领兵入冀州，实图袭韩馥，韩馥惶惧。

**归年** 《通鉴》卷060初平二年袁绍得冀州前。

<a id="sgz006-b-348-4"></a>

**[《三国志·董二袁刘传》仓内原文 L348](../../sources/本地分卷/三国志/三国志-卷006.md#l348)**

> 會卓西入關，紹還軍延津，因馥惶遽，使陳留高幹、頴川荀諶等說馥曰：「公孫瓚乘勝來向南，而諸郡應之，袁車騎引軍東向，此其意不可知，竊爲將軍危之。」馥曰：「爲之柰何？」諶曰：「公孫提燕、代之卒，其鋒不可當。袁氏一時之傑，必不爲將軍下。夫冀州，天下之重資也，若兩雄並力，兵交於城下，危亡可立而待也。夫袁氏，將軍之舊，且同盟也，當今爲將軍計，莫若舉冀州以讓袁氏。袁氏得冀州，則瓚不能與之爭，必厚德將軍。冀州入於親交，是將軍有讓賢之名，而身安於泰山也。願將軍勿疑！」馥素恇怯，因然其計。

**释读** 董卓西入关之际袁绍还军延津，利用韩馥恐惧，令高干、荀谌以公孙瓒兵到、袁绍威胁游说。荀谌劝韩馥把冀州让给同盟袁绍以保身，韩馥同意。

**归年** 承初平二年公孙瓒入冀州与韩馥让州的连续事件。

<a id="sgz006-b-348-5"></a>

**[《三国志·董二袁刘传》仓内原文 L348](../../sources/本地分卷/三国志/三国志-卷006.md#l348)**

> 馥長史耿武、別駕閔純、治中李歷諫馥曰：「冀州雖鄙，帶甲百萬，穀支十年。袁紹孤客窮軍，仰我鼻息，譬如嬰兒在股掌之上，絕其哺乳，立可餓殺。柰何乃欲以州與之？」馥曰：「吾，袁氏故吏，且才不如本初，度德而讓，古人所貴，諸君獨何病焉！」從事趙浮、程奐請以兵拒之，馥又不聽。

**释读** 长史耿武等说冀州兵食充足，袁绍依靠韩馥，不能轻易让州。韩馥自称袁氏旧吏，认为让贤可贵，且拒绝赵浮、程奂以兵拒绍的建议。

**归年** 初平二年韩馥让冀州前，与后文同一过程。

<a id="sgz006-b-350-1"></a>

**[《三国志·董二袁刘传》仓内原文 L350](../../sources/本地分卷/三国志/三国志-卷006.md#l350)**

> 從事沮授說紹曰：「將軍弱冠登朝，則播名海內；值廢立之際，則忠義奮發；單騎出奔，則董卓懷怖；濟河而北，則勃海稽首。振一郡之卒，撮冀州之衆，威震河朔，名重天下。雖黃巾猾亂，黑山跋扈，舉軍東向，則青州可定；還討黑山，則張燕可滅；回衆北首，則公孫必喪；震脅戎狄，則匈奴必從。橫大河之北，合四州之地，收英雄之才，擁百萬之衆，迎大駕於西京，復宗廟於洛邑，號令天下，以討未復，以此爭鋒，誰能敵之？比及數年，此功不難。」紹喜曰：「此吾心也。」即表授爲監軍、奮威將軍。

**释读** 沮授以袁绍早年声望和赴勃海起兵概括其资望，建议先定青州、讨张燕和公孙瓒、抚匈奴，再并四州迎帝号令天下。袁绍赞同，表沮授为监军、奋威将军。

**归年** 说辞中早事是追述，陈策和拜官发生于初平二年据冀州后，见《资治通鉴》卷060。

<a id="sgz006-p-045-1"></a>

**[《三国志·董二袁刘传》裴注 045·1](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-045-1)**

> 英雄記曰逢紀説紹曰將軍舉大事而仰人資給不據一州無以自全紹答云冀州兵彊吾士饑之設不能辦無所容立紀曰可與公孫瓚相聞導使來南擊取冀州公孫必至而馥懼矣因使説利害為陳禍福馥必遜讓於此之際可據其位紹從其言而瓚果來

**释读** 逢纪建议袁绍诱公孙瓒南来，再以利害游说韩馥让冀州，袁绍采纳、公孙瓒果至。

**归年** 《通鉴》卷060初平二年韩馥让州之前。

<a id="sgz006-p-046-1"></a>

**[《三国志·董二袁刘传》裴注 046·1](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-046-1)**

> 九州春秋曰馥遣都督從事趙浮程奐將彊弩萬張屯河陽浮等聞馥欲以冀州與紹自孟津馳東下時紹尚在朝歌清水口浮等從後來船數百艘衆萬餘人整兵鼔夜過紹營紹甚惡之浮等到謂馥曰袁本初軍無斗糧各已離散雖有張楊於扶羅新附未肯為用不足敵也小從事等請自以見兵拒之旬日之閒必土崩瓦解明將軍但當開閤高枕何憂何懼馥不從乃避位出居趙忠故舍遣子齎冀州印綬於黎陽與紹

**释读** 《九州春秋》载赵浮、程奂带兵自河阳来，军无粮的袁绍见其阵容不安；二人劝韩馥拒让，他不从并交出冀州印绶。

**归年** 初平二年秋七月袁绍领冀州的前情。

<a id="sgz006-p-048-2"></a>

**[《三国志·董二袁刘传》裴注 048·2](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-048-2)**

**释读** 袁绍得冀州后又辟沮授。《英雄记》说袁绍以本初与初平相合，认为能克乱。

**归年** 初平二年袁绍领冀州，《献帝纪》可证。

<a id="sgz006-p-050-1"></a>

**[《三国志·董二袁刘传》裴注 050·1](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-050-1)**

**[《三国志·崔毛徐何邢鲍司马传》裴注 021·9](../../sources/摘录/三国志-卷012-崔毛徐何邢鲍司马传裴注.md#pei-021-9)**

> 臣聞皇、羲以來，始有君臣上下之事，張化以導民，刑罰以禁暴。今行車騎將軍袁紹，託其先軌，寇竊人爵，既性暴亂，厥行淫穢。昔為司隸校尉，會值國家喪禍之際，太后承攝，何氏輔政，紹專為邪媚，不能舉直，至令丁原焚燒孟津，招來董卓，造為亂根，紹罪一也。卓既入雒而主見質，紹不能權譎以濟君父，而棄置節傳，迸竄逃亡，忝辱爵命，背上不忠，紹罪二也。紹為勃海太守，默選戎馬，當攻董卓，不告父兄，至使太傅門戶，太僕母子，一旦而斃，不仁不孝，紹罪三也。紹既興兵，涉歷二年，不恤國難，廣自封殖，乃多以資糧專為不急，割剝富室，收考責錢，百姓吁嗟，莫不痛怨，紹罪四也。韓馥之迫，竊其虛位，矯命詔恩，刻金印玉璽，每下文書，皁囊施檢，文曰『詔書一封，邟鄉侯印』。邟，口浪反。昔新室之亂，漸以即真，今紹所施，擬而方之，紹罪五也。紹令崔巨業候視星日，財貨賂遺，與共飲食，剋期會合，攻鈔郡縣，此豈大臣所當宜為？紹罪六也。

**归年** 《通鉴》卷060置磐河举兵时（191）；疏内189年董卓事、190年宗族受诛、191年夺冀州是公孙瓒的追诉。

<a id="sgz008-p-008-1"></a>

**[《三国志·二公孙陶四张传》裴注 008·1](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-008-1)**

> 典略載瓉表紹罪状曰臣聞皇羲以來始有君臣上下之事張化以導民刑罰以禁暴今行車騎将軍袁紹托其先軌㓂竊人爵既性暴亂厥行淫穢昔為司隷校尉㑹國家値喪禍之際太后承攝何氏輔政紹專為邪媚不能舉直至令丁原焚燒孟津招來董卓造為亂根紹罪一也卓既入雒而主見質紹不能權謀以濟君父而棄置節傳迸竄逃亡忝辱爵命背上不忠紹罪二也紹為渤海太守黙選戎馬當攻董卓不告父兄至使太傅門户太僕母子一旦而斃不仁不孝紹罪三也紹既興兵涉歴二年不䘏國難廣自封殖乃多以資糧專為不急割剝富室收考責錢百姓吁嗟莫不痛怨紹罪四也韓馥之廹竊其虚位矯命詔恩刻金印玉璽每下文書皂嚢施檢文曰詔書一封邟口浪反鄉侯印昔新室之亂漸以即眞今紹所施擬而方之紹罪五也紹令崔巨業候視星日財貨賂遺與共飲食克期㑹合攻鈔郡縣此豈大臣所當宜為紹罪六也

**释读** 《典略》引公孙瓒上表，指袁绍引董卓入京都、弃节逃亡、连累袁氏、借兵敛财、迫韩馥僭制，又使崔巨业占候以谋攻郡县。

**归年** 《通鉴》卷060在初平二年公孙瓒屯磐河、袁绍授公孙范渤海守后录公孙瓒上疏。《全书TXT》本卷L407保存同段。

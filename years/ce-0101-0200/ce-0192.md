<a id="hh-event-1"></a>

1. **大赦天下。** 三年春正月丁丑，颁布大赦。 [[1]](#hh-note-1)

<a id="hh-event-27"></a>

<a id="hh-event-2"></a>

2. **孙坚攻刘表，在岘山遇害。** 袁术遣孙坚攻刘表。孙坚击退黄祖、进围襄阳，在岘山中箭身亡。《后汉书·献帝纪》《三国志·孙破虏讨逆传》系于本年。《通鉴》采用初平二年，见[191年同事异说](ce-0191.md#sg-review-191-note)。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **界桥之战，袁绍击败公孙瓒。** 公孙瓒率军南下。袁绍使麴义先登，公孙瓒兵败，退至界桥再战，又失营垒。袁绍随后被溃骑围住，麴义来迎才解围。《公孙瓒传》说严纲被生擒，裴注引《英雄记》及《后汉书·袁绍传》写他战死。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **王允、士孙瑞与吕布诛董卓。** 四月，献帝病愈，在未央殿大会。王允、士孙瑞策划，以吕布为内应。李肃等扮作卫士在掖门等候，董卓入门后，吕布奉诏亲手刺杀董卓。董氏宗族也在这一场政变中被诛。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **王允录尚书事，吕布封温侯。** 王允主掌朝政，遣张种抚慰山东。吕布获授将军、假节，仪比三司，封温侯，与王允共掌朝政。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **刘岱战死，鲍信等迎曹操领兖州。** 青州黄巾入兖州，任城相郑遂、兖州刺史刘岱先后被杀。鲍信、万潜等迎曹操领兖州，陈宫参与劝说州吏。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **曹操与黄巾战于寿张，鲍信战死。** 曹操在寿张以东与黄巾军交战，《通鉴》说初战不利。鲍信力战而死，遗体未寻获，众人刻木像祭哭。[冬季济北受降](#sg-event-41)另有明确季节。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **五月丁酉大赦一说。** 《献帝纪》记五月丁酉大赦。《通鉴考异》根据王允说一岁不能再赦，对该条存疑。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **征西将军皇甫嵩为车骑将军。** 丁未，征西将军皇甫嵩为车骑将军。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **李傕、郭汜等起兵西攻长安。** 牛辅死后，李傕等求赦未获，采纳贾诩建议，联合董卓旧部向长安进兵。王允派徐荣、胡轸在新丰迎击，徐荣战死，胡轸投降。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **六月长安陷落，吕布出走。** 六月戊午，李傕等攻入长安，吕布战败。种拂、周奂等官员及大批吏民遇害。吕布出城前邀王允同走，王允留下辅护献帝。诸书对围城日数及吕布败走与董卓死相隔多久有异。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **李傕等并自为将军。** [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **大赦天下。** 己未，颁布大赦。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **黄琬下狱死，王允与宋翼、王宏同被杀。** 长安陷落后，李傕等收捕黄琬。为免两郡起兵救王允，又征左冯翊宋翼、右扶风王宏入朝。王宏提议联合关东讨李傕，宋翼坚持应召。六月甲子，王允与二人同被杀，王允宗族多人遇害，侄子王晨、王凌逃出，旧吏赵戬收殓。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **前将军赵谦为司徒。** 丙子，前将军赵谦为司徒。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **太尉马日磾为太傅，录尚书事。** 秋七月庚子，太尉马日磾为太傅，录尚书事。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **马日磾与赵岐持节抚慰关东。** 八月遣马日磾、赵岐奉节出使。《三国志·华歆传》还载马日磾征辟华歆，华歆同行至徐州，受诏任豫章太守。赵岐本传还载他从洛阳另出巡各郡。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **车骑将军皇甫嵩为太尉。** [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **司徒赵谦罢。** [[19]](#hh-note-19)

<a id="sg-event-34"></a>

<a id="hh-event-20"></a>

20. **李傕等受封，李傕、郭汜、樊稠共掌朝政。** 九月，李傕任车骑将军、领司隶校尉，郭汜任后将军，樊稠任右将军。张济也受封，后出屯弘农。张济将军号在诸书有异。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **济出屯弘农。** [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **司空淳于嘉为司徒，光禄大夫杨彪为司空，并录尚书事。** 甲申，司空淳于嘉为司徒，光禄大夫杨彪为司空，并录尚书事。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **太尉皇甫嵩免。** 冬十二月，太尉皇甫嵩免。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **光禄大夫周忠为太尉，参录尚书事。** [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **卢植去世。** 卢植临卒嘱薄葬，传录所著碑、诔、表、记。 [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **袁绍在龙凑再次击败公孙瓒。** 公孙瓒再次派兵挑战，在龙凑被袁绍击败，退回幽州。《资治通鉴》把此役列在本年末，袁绍后来致书追叙时也分别说到界桥与龙河。 [[26]](#hh-note-26)

<a id="hh-event-28"></a>

28. **献帝初平三年五月丙申，无云而雷。** [[28]](#hh-note-28)

<a id="sg-event-31"></a>

<a id="sg-event-30"></a>

<a id="sg-event-29"></a>

29. **曹操屯顿丘，回攻于毒本营以解东武阳之围。** 春，于毒等攻东武阳。曹操西进攻击其本营，于毒撤围回援。曹操随后截击眭固与于夫罗，见[第32条](#sg-event-32)。 [[29]](#sg-note-29)

<a id="sg-event-32"></a>

32. **曹操击破眭固，又在内黄击破于夫罗。** 于毒撤离东武阳后，曹操截击眭固，又在内黄击匈奴于夫罗，均获胜。 [[32]](#sg-note-32)

<a id="sg-event-33"></a>

33. **吕布出武关后南奔袁术。** 吕布率数百骑出武关，想因诛董卓之功得到袁术接纳。《三国志》记袁术拒绝，《后汉书》及《通鉴》记袁术先厚待，后因吕布部众劫掠而生嫌隙。吕布后续投奔袁绍、张杨的先后，各书也有出入。 [[33]](#sg-note-33)

<a id="sg-event-35"></a>

35. **袁术与公孙瓒联合，遣兵牵制袁绍。** 袁术与袁绍交恶，求援于公孙瓒。公孙瓒使刘备屯高唐、单经屯平原、陶谦屯发干，形成对袁绍的牵制。 [[35]](#sg-note-35)

<a id="sg-event-36"></a>

36. **曹操与袁绍合兵击破对方诸军。** 《武帝纪》和《后汉书·袁术传》均载曹操与袁绍合击公孙瓒、袁术一方。次年曹操破袁术于匡亭另见193年。 [[36]](#sg-note-36)

<a id="sg-event-37"></a>

37. **韩遂、马腾到长安，分别领兵回金城、屯郿。** 董卓曾招揽韩遂、马腾。两人率部到长安时董卓已死，李傕等以韩遂为镇西将军，遣归金城，马腾任征西将军，屯郿。马腾攻长安另系194年。 [[37]](#sg-note-37)

<a id="sg-event-38"></a>

38. **牛辅遣李傕等在中牟击败朱儁。** 春，牛辅派李傕、郭汜和张济出战，在中牟击败朱儁，又劫掠陈留、颍川。荀彧传所记颍川族人遇难可与此互证。 [[38]](#sg-note-38)

<a id="sg-event-39"></a>

39. **吕布遣李肃讨牛辅，李肃与牛辅先后遇害。** 董卓死后，吕布命李肃持诏到陕地讨牛辅。李肃战败退到弘农，被吕布杀死。牛辅后来因军营惊乱而出逃，被胡赤儿等杀害。 [[39]](#sg-note-39)

<a id="sg-event-40"></a>

40. **蔡邕被收狱，未能续成汉史。** 董卓被诛后，蔡邕在王允座上叹息，被交廷尉治罪。蔡邕请求受刑以继续撰史，马日磾为他说情。蔡邕最终死于狱中。裴注引谢承、张璠两说，也保留裴松之的质疑。 [[40]](#sg-note-40)

<a id="sg-event-41"></a>

41. **曹操在济北接受黄巾投降，编为青州兵。** 冬，曹操追至济北，接受黄巾军投降，从降卒中选精锐编为青州兵。《三国志》记冬，《通鉴》接在十二月任免之后。 [[41]](#sg-note-41)

<a id="sg-event-42"></a>

42. **朝廷任金尚为兖州刺史，曹操拒其入州。** 朝廷任命京兆人金尚为兖州刺史。金尚将赴任，曹操迎击，他转投袁术。 [[42]](#sg-note-42)

<a id="sg-event-43"></a>

43. **刘表遣使奉贡，获授荆州牧。** 冬十月，刘表遣使入贡。李傕等想让他充当外援，授其镇南将军、荆州牧，封成武侯，假节。 [[43]](#sg-note-43)

<a id="sg-event-44"></a>

44. **毛玠劝曹操奉天子、修耕植。** 曹操辟毛玠为治中从事。毛玠建议尊奉天子以号令不臣者，恢复耕作以积蓄军需，曹操采纳。 [[44]](#sg-note-44)

<a id="sg-event-45"></a>

45. **曹操遣使通长安，董昭、钟繇促成。** 曹操欲借道河内派使者入长安，张杨起初拒绝，听从董昭劝说后予以通行并荐举曹操。长安的李傕、郭汜也曾疑虑，经钟繇劝说后答复来使。 [[45]](#sg-note-45)

<a id="sg-event-46"></a>

46. **陶谦等推朱儁讨李傕，朱儁奉诏入朝。** 陶谦等推举朱儁为太师，打算联合州郡讨李傕、迎献帝。李傕采纳周忠、贾诩建议，征召朱儁。朱儁应召，复任太仆，陶谦等的计划中止。 [[46]](#sg-note-46)

<a id="sg-event-47"></a>

47. **陈温去世与扬州易手的异说。** 《通鉴》系陈温病故于初平三年，记袁绍派袁遗领扬州、袁术击败袁遗而任陈瑀。《献帝纪》在[193年第3条](ce-0193.md#hh-note-3)写袁术杀陈温、据淮南。两条互见，指向同一人的不同死年与死因。 [[47]](#sg-note-47)

<a id="sg-event-48"></a>

48. **荀攸因诛董卓之谋下狱，董卓死后获释。** 荀攸与郑泰、种辑等另有诛董卓之谋，事泄后荀攸被拘，至董卓死后获免。同谋名单在《荀攸传》和《通鉴》有异。 [[48]](#sg-note-48)

<a id="sg-event-49"></a>

49. **贾诩辞封侯，改任尚书。** 李傕等任贾诩为左冯翊，想因进攻长安之谋封他为侯。他辞封，也辞尚书仆射，后来以尚书掌选举。 [[49]](#sg-note-49)

<a id="sg-event-50"></a>

50. **董昭在界桥战事期间领钜鹿。** 袁绍在界桥迎击公孙瓒时，钜鹿太守李邵和部分当地士族倾向公孙瓒。袁绍命董昭领钜鹿，董昭以伪檄诛孙伉等人，稳定郡内。 [[50]](#sg-note-50)

<a id="sgz-event-51"></a>

51. **董氏族人在朝任职。** 董旻任左将军封鄠侯，董璜任侍中、中军校尉统兵，董氏亲属列于朝廷。 [[51]](#sgz-note-51)

<a id="sgz-event-52"></a>

52. **董卓筑郿坞。** 董卓建与长安城同高的郿坞，积三十年粮储，欲以此进据天下或退守终老。 [[52]](#sgz-note-52)

<a id="sgz-event-53"></a>

53. **牛辅驻陕。** 董卓女婿中郎将牛辅独领军驻陕。 [[53]](#sgz-note-53)

<a id="sgz-event-54"></a>

54. **董卓改葬郿县。** 董卓被葬在郿，暴雨入墓冲出棺椁。 [[54]](#sgz-note-54)

<a id="sgz-event-55"></a>

55. **董卓给亲属童稚金紫封号。** 《英雄记》载董卓侍妾抱儿亦封侯，未笄孙女名白受封渭阳君，董璜授印绶。 [[55]](#sgz-note-55)

<a id="sgz-event-56"></a>

56. **董卓旧部收灰合葬、郿坞积财。** 董卓旧部收拾此前被焚者的遗灰合棺葬郿，郿坞金银珠玉数不可计。 [[56]](#sgz-note-56)

<a id="sgz-event-57"></a>

57. **士孙瑞迁大司农。** 董卓诛后，士孙瑞迁为大司农，成为国中元老，多位公卿让荐。 [[57]](#sgz-note-57)

**释读** 计划将成而败露，何颙和荀攸入狱，本传说何颙忧惧自杀。

**归年** 《通鉴》对参与名单持疑，故何颙死的原因年月以此传异说保留。

<a id="sgz010-b-517-5"></a>

**[《三国志·二荀贾传》仓内原文 L517](../../sources/本地分卷/三国志/三国志-卷010.md#l517)**

> 攸言語飲食自若，會卓死得免。

**释读** 荀攸在狱中言笑饮食自如，董卓死后他获免。

**归年** 《通鉴》卷060 L379–383、卷006《董卓传》明确初平三年董卓被诛。

### 49. 贾诩辞封侯，改任尚书

[返回正文第49条](#sg-event-49)

<a id="sg010-l526-e49"></a>

**[《三国志·贾诩传》](../../sources/摘录/三国志-卷010-二荀贾传.md#p003)** · [仓内TXT L526](../../sources/本地分卷/三国志/三国志-卷010.md#l526)

> 後詡爲左馮翊，傕等欲以功侯之，詡曰：「此救命之計，何功之有！」固辭不受。又以爲尚書僕射，詡曰：「尚書僕射，官之師長，天下所望，詡名不素重，非所以服人也。縱詡昧於榮利，柰國朝何！」乃更拜詡尚書，典選舉，多所匡濟，傕等親而憚之。

**归年与互校** 《通鉴》卷六十接王允遇害之后。

<a id="hh072-l5178-e49"></a>

**[《后汉书·董卓传》](../../sources/摘录/后汉书-卷072-董卓列传.md#p004)** · [仓内TXT L5178](../../sources/本地分卷/后汉书/后汉书-卷072.md#L5178)

> 以賈詡為左馮翊，欲侯之。詡曰：「此救命之計，何功之有！」固辭乃止。更以為尚書典選。

<a id="sgz010-b-526-8"></a>

**[《三国志·二荀贾传》仓内原文 L526](../../sources/本地分卷/三国志/三国志-卷010.md#l526)**

> 後詡爲左馮翊，傕等欲以功侯之，詡曰：「此救命之計，何功之有！」固辭不受。

**释读** 贾诩任左冯翊后，李傕等要以其功封侯。贾诩称只是救命之计，无功坚辞。

**归年** 《通鉴》卷060 L473–474明确初平三年入长安之后。

<a id="sgz010-b-526-9"></a>

**[《三国志·二荀贾传》仓内原文 L526](../../sources/本地分卷/三国志/三国志-卷010.md#l526)**

> 又以爲尚書僕射，詡曰：「尚書僕射，官之師長，天下所望，詡名不素重，非所以服人也。縱詡昧於榮利，柰國朝何！」乃更拜詡尚書，

**释读** 拟拜尚书仆射时，贾诩称资望不足，不能服人，最终改拜尚书。

**归年** 《通鉴》卷060 L474–476明初平三年。

### 50. 董昭在界桥战事期间领钜鹿

[返回正文第50条](#sg-event-50)

<a id="sg014-l705-e50"></a>

**[《三国志·董昭传》](../../sources/摘录/三国志-卷014-程郭董刘蒋刘传.md#p003)** · [仓内TXT L705](../../sources/本地分卷/三国志/三国志-卷014.md#L705)

> 紹逆公孫瓚於界橋，鉅鹿太守李邵及郡冠蓋，以瓚兵強，皆欲屬瓚。紹聞之，使昭領鉅鹿。問：「御以何術？」對曰：「一人之微，不能消眾謀，欲誘致其心，唱與同議，及得其情，乃當權以制之耳。計在臨時，未可得言。」時郡右姓孫伉等數十人專為謀主，驚動吏民。昭至郡，偽作紹檄告郡云：「得賊羅候安平張吉辭，當攻鉅鹿，賊故孝廉孫伉等為應，檄到收行軍法，惡止其身，妻子勿坐。」昭案檄告令，皆即斬之。一郡惶恐，乃以次安慰，遂皆平集。事訖白紹，紹稱善。

**归年与互校** “逆公孫瓚於界橋”是列传内部纪年依据。

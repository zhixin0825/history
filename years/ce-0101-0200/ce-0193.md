31. **术退保封丘，遂围之。** 术退保封丘，遂围之，未合，术走襄邑，追到太寿，决渠水灌城。 [[31]](#sg-note-31)

<a id="sg-event-32"></a>

<a id="sgz-event-36"></a>

36. **袁绍与吕布在常山击张燕。** 袁绍和吕布在常山攻张燕。张燕有逾万精兵和几千骑。 [[36]](#sgz-note-36)

<a id="sgz-event-37"></a>

37. **袁绍谋刺吕布，吕布逃回张杨处。** 吕布想增兵，部下从事抢掠，袁绍因此嫌忌，吕布察觉后请求离开。 [[37]](#sgz-note-37)

<a id="sgz-event-38"></a>

38. **吕布投张杨路过张邈，握手盟誓。** 吕布离袁绍去张杨处，路过张邈领地，分别时与张邈握手盟誓，袁绍获悉后深恨。 [[38]](#sgz-note-38)

<a id="sgz-event-39"></a>

39. **魏郡兵与于毒攻陷邺城。** 袁绍到薄落津会宾客，闻魏郡兵叛合黑山于毒破邺杀栗成。袁绍安然，陶升保护袁家和冠族撤至斥丘。 [[39]](#sgz-note-39)

<a id="sgz-event-40"></a>

40. **袁绍杀于毒等黑山部首领。** 袁绍屯斥丘用陶升，入朝歌鹿场山击杀于毒、壶寿及多名黑山军首领，并破诸屯。 [[40]](#sgz-note-40)

<a id="sgz-event-41"></a>

41. **赵岐使河北，袁绍、公孙瓒通信。** 赵岐奉帝命往河北调停，袁绍远迎，公孙瓒回书称愿和。 [[41]](#sgz-note-41)

<a id="sgz-event-42"></a>

42. **田畴哭刘虞墓，与公孙瓒抗辩。** 田畴至刘虞墓，陈祭并发章表，哭后离去。 [[42]](#sgz-note-42)

<a id="sgz-event-43"></a>

43. **《英雄记》记孙坚初平四年被吕公伏杀。** 《英雄记》说孙坚初平四年正月七日死，刘表将吕公在山上落石击中其头，与中箭异说。 [[43]](#sgz-note-43)

### 3. 袁术进入淮南，陈温死因有异说

[返回正文第3条](#hh-event-3)

<a id="hh009-l1222-e3"></a>

**[《后汉书·献帝纪》](../../sources/摘录/后汉书-卷009-献帝纪.md#p001)** · [仓内TXT L1222](../../sources/本地分卷/后汉书/后汉书-卷009.md#L1222)

> 三月，袁術殺楊州刺史陳溫，據淮南。

初平三年陈温病死一说及袁遗、陈瑀前后，见[192年第47条](ce-0192.md#sg-note-47)。

<a id="sgz006-b-361-9"></a>

**[《三国志·董二袁刘传》仓内原文 L361](../../sources/本地分卷/三国志/三国志-卷006.md#l361)**

> 術以餘衆奔九江，殺楊州刺史陳溫，領其州。以張勳、橋蕤等爲大將軍。

**释读** 袁术率残军奔九江。本传称他杀扬州刺史陈温后自领扬州，任张勋、桥蕤为大将军。

**归年** 《三国志·武帝纪》初平四年袁术奔九江。《英雄记》称陈温此前已病死，初平三年陈温卒见异说条。

<a id="sgz006-p-102-2"></a>

**[《三国志·董二袁刘传》裴注 102·2](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-102-2)**

> 瑀字公瑋下邳人瑀既領州而術敗於封丘南向壽春瑀拒術不納術退保隂陵更合軍攻瑀瑀懼走歸下邳如此則温不為術所殺與本傳不同

**释读** 陈瑀领扬州时袁术从封丘败向寿春，陈瑀拒不纳；袁术退保阴陵再攻，陈瑀归下邳。裴松之据此不从本传谓袁术杀陈温。

**归年** 建安以前的初平四年，《武帝纪》明载袁术由封丘、宁陵后奔九江。

<a id="sgz051-b-2452-4"></a>

**[《三国志·宗室传》仓内原文 L2452](../../sources/本地分卷/三国志/三国志-卷051.md#l2452)**

> 後袁術徙壽春，賁又依之。

**释读** 袁术迁往寿春，孙贲前去依附。

**归年** 《通鉴》卷六十、《武帝纪》初平四年袁术奔九江。

<a id="sgz056-p-007-2"></a>

**[《三国志·朱治朱然吕范朱桓传》裴注 007·2](../../sources/摘录/三国志-卷056-朱治朱然吕范朱桓传裴注.md#pei-007-2)**

> 後術為曹公所敗於封丘南人叛瑀瑀拒之術走隂陵好辭以下瑀瑀不知權而又怯不即攻術術於淮北集兵向夀春瑀懼使其弟公琰請和於術術執之而進瑀走歸下邳

**释读** 袁术在封丘败于曹操，陈瑀不纳袁术；袁术退阴陵在淮北集兵逼寿春，扣下求和的陈公琰，陈瑀逃回下邳。

**归年** 《武帝纪》和《通鉴》卷六十明系初平四年；与192陈温、陈祎的异说分开。

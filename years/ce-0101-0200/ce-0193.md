4. **长安宣平城门外屋自坏。** [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **无云而雷。** 夏五月癸酉，无云而雷。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **扶风大风，雨雹。** 六月，扶风大风，雨雹。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **华山崩裂。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

<a id="hh-event-9"></a>

<a id="hh-event-10"></a>

10. **遣侍御史裴茂讯诏狱，原轻系。** [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **天狗西北行。** 六月辛丑，天狗西北行。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **试儒生四十余人，上第赐位郎中，次太子舍人，下第者罢之。** 九月甲午，试儒生四十余人，上第赐位郎中，次太子舍人，下第者罢之。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **诏曰“孔子叹「学之不讲」”。** 诏曰：『孔子叹「学之不讲」，不讲则所识日忘。今耆儒年踰六十，去离本土，营求粮资，不得专业。结童入学，白首空归，长委农野，永绝荣望，朕甚愍焉。其依科罢者，听为太子舍人。』 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **太学行礼，车驾幸永福城门，临观其仪，赐博士以下各有差。** 冬十月，太学行礼，车驾幸永福城门，临观其仪，赐博士以下各有差。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **京师地震。** 辛丑，京师地震。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **有星孛於天市。** 有星孛于天市。 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **司空杨彪免，太常赵温为司空。** [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **公孙瓒杀大司马刘虞。** [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **地震。** 十二月辛丑，地震。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **司空赵温免，乙巳，卫尉张喜为司空。** [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **是岁，琅邪王容薨。** 当年，琅邪王容去世。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **曹操初攻陶谦。** 曹操这一年东攻徐州，从郯退兵途中攻屠数县。《资治通鉴》系曹嵩遇害于本年出兵前，《应劭传》另系次年。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **孛星出两角间，东北行入天市中而灭。** 《天文志》记四年十月，孛星出两角间，东北行入天市中而灭。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **遣子琬至长安奉章，献帝封琬汶阳侯，拜为平原相。** 初平四年，遣子琬至长安奉章，献帝封琬汶阳侯，拜为平原相。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **献帝初平四年六月，寒风如冬时。** [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **献帝初平四年六月，右扶风雹如斗。** [[26]](#hh-note-26)

<a id="sg-event-27"></a>

27. **曹操破袁术于匡亭。** 四年春，军鄄城。 [[27]](#sg-note-27)

<a id="sg-event-28"></a>

28. **荆州牧刘表断术粮道，术引军入陈留。** 荆州牧刘表断术粮道，术引军入陈留，屯封丘，黑山余贼及于夫罗等佐之。 [[28]](#sg-note-28)

<a id="sg-event-29"></a>

29. **术使将刘详屯匡亭。** 术命将领刘详屯匡亭。 [[29]](#sg-note-29)

<a id="sg-event-30"></a>

30. **太祖击详，术救之。** 太祖击详，术救之，与战，大破之。 [[30]](#sg-note-30)

<a id="sg-event-31"></a>

31. **术退保封丘，遂围之。** 术退保封丘，遂围之，未合，术走襄邑，追到太寿，决渠水灌城。 [[31]](#sg-note-31)

<a id="sg-event-32"></a>

32. **走宁陵，又追之。** 走宁陵，又追之，走九江。 [[32]](#sg-note-32)

<a id="sg-event-33"></a>

33. **太祖还军定陶。** 夏，太祖还军定陶。 [[33]](#sg-note-33)

<a id="sg-event-49"></a>

49. **孙策归附袁术，获还孙坚旧部。** 孙策在曲阿葬父后，渡江客居江都，陶谦对他颇有忌意。孙策在江都向张纮问计，商议求还父亲旧部、在丹杨募兵，并托付母亲和弟弟。孙策到寿春投袁术，起初未能领到孙坚旧部。他与吕范、孙河迎母至曲阿，依舅父吴景募得数百人。后来孙策再见袁术，获交还孙坚旧部。太傅马日磾在寿春以礼征辟孙策。孙策有部下逃入袁术营，孙策派人将其处死，袁术未责备他。 [[49]](#sg-note-49)

51. **曹操与吕布在濮阳交战，相持百余日。** 曹操进攻屯濮阳的吕布。交战中吕布骑兵冲击青州兵，曹军阵乱，曹操突火坠马、左掌受伤，后回营再次组织进攻。两军相持百余日，终于因蝗灾粮荒各引军退走。 [[51]](#wu-note-51)

57. **吕布与夏侯惇交战后入濮阳。** 夏侯惇路遇吕布，两军交战；吕布退而入濮阳，袭取夏侯惇军中辎重。 [[57]](#sgz-note-57)

<a id="sgz-event-58"></a>

58. **韩浩救出夏侯惇。** 吕布遣部将诈降，捉住夏侯惇索要财货，夏侯军中惊恐。 [[58]](#sgz-note-58)

<a id="sgz-event-59"></a>

59. **郭贡率众到鄄城，荀彧见其使其退。** 郭贡率数万人到城下，守军猜他与吕布共谋而害怕。 [[59]](#sgz-note-59)

<a id="sgz-event-61"></a>

61. **吴景逼退周昕而领丹杨。** 吴景攻周昕未下，声称追随周昕者皆死；周昕不愿连累百姓，散兵回本郡。 [[61]](#sgz-note-61)

<a id="sgz-event-62"></a>

62. **袁术向陆康求粮未果，令孙策攻庐江。** 袁术本已答应以孙策为九江太守，却改用陈纪。袁术又想攻徐州，向庐江太守陆康索要军粮，陆康拒绝。袁术命孙策围攻庐江，答应破城后让孙策领郡。《陆康传》载陆康守城二年，城陷逾月病卒。袁术再次失约，改任旧吏刘勋。城陷和换守的确年无明文。 [[62]](#sgz-note-62)

<a id="sgz-event-60"></a>

<a id="sgz-event-63"></a>

63. **刘繇渡江治曲阿，与袁术沿江对峙。** 袁术已据扬州旧治寿春，汉廷所任刺史刘繇由吴景、孙贲迎至曲阿。刘繇以二人与袁术相连，驱逐二人，命樊能、于麋守横江津，张英屯当利口。袁术另置刺史，令吴景、孙贲攻张英等，逾年未克。汉廷加刘繇州牧及振武将军，《后汉书》官号作振威。次年[孙策渡江](ce-0195.md#sg-note-43)。 [[63]](#sgz-note-63)

<a id="sgz-event-64"></a>

64. **曹操以程昱为东平相屯范。** 曹操回军后握手致谢，表任程昱屯范。 [[64]](#sgz-note-64)

<a id="sgz-event-65"></a>

65. **濮阳相持时司马朗率家回温。** 曹操与吕布在濮阳相持，朗将家人带回温。 [[65]](#sgz-note-65)

<a id="sgz-event-66"></a>

66. **兖州大饥时司马朗救恤宗族。** 岁荒至人相食，司马朗收恤宗族并教弟弟，不使因乱废学治业。 [[66]](#sgz-note-66)

<a id="sgz-event-67"></a>

67. **曹操任典韦为亲营都尉。** 典韦被纳入宿卫，领亲兵数百绕大帐。 [[67]](#sgz-note-67)

**[《三国志·刘二牧传》仓内原文 L1633](../../sources/本地分卷/三国志/三国志-卷031.md#l1633)**

>  時征西將軍馬騰屯郿而反，焉及範與騰通謀，引兵襲長安。範謀洩，奔槐里，騰敗，退還涼州，範應時見殺，於是收誕行刑。議郎河南龐羲與焉通家，乃募將焉諸孫入蜀。

**释读** 刘焉与刘范联络马腾。事泄后马腾退，刘范被杀，刘诞被捕处死。庞羲招呼刘氏诸孙入蜀。

**归年** 兴平元年《献帝纪》及《通鉴》载马腾和刘范起兵失败。庞羲护送时间承诸子之难。

<a id="sgz031-p-009-1"></a>

**[《三国志·刘二牧传》裴注 009·1](../../sources/本地分卷/三国志/三国志-卷031.md#pei-009-1)**

> 英䧺記曰範從長安亡之馬騰營從馬求兵焉使校尉孫肇將兵徃助之敗於長安

**释读** 刘范到马腾处求兵。刘焉的校尉孙肇赴援，兵败长安。

**归年** 《献帝纪》兴平元年记刘范与马腾起兵，注文补军官和行军。

**[《三國志·孫破虜討逆傳》 裴注 023·1](../../sources/本地分卷/三国志/三国志-卷046.md#pei-023-1)** · [TXT L60](../../sources/本地分卷/三国志/三国志-卷046.txt#L60)

> 吳歷曰：初策在江都時，張紘有母喪。策數詣紘，咨以世務，曰：「方今漢祚中微，天下擾攘，英雄儁傑各擁衆營私，未有能扶危濟亂者也。先君與袁氏共破董卓，功業未遂，卒爲黃祖所害。策雖暗稚，竊有微志，欲從袁揚州求先君餘兵，就舅氏於丹楊，收合流散，東據吳會，報讎雪恥，爲朝廷外藩。君以爲何如？」紘荅曰：「旣素空劣，方居衰絰之中，無以奉贊盛略。」策曰：「君高名播越，遠近懷歸。今日事計，決之於君，何得不紆慮啟告，副其高山之望？若微志得展，血讎得報，此乃君之勳力，策心所望也。」因涕泣橫流，顏色不變。紘見策忠壯內發，辭令慷慨，感其志言，乃荅曰：「昔周道陵遲，齊、晉並興；王室已寧，諸侯貢職。今君紹先侯之軌，有驍武之名，若投丹楊，收兵吳會，則荊、揚可一，讎敵可報。據長江，奮威德，誅除羣穢，匡輔漢室，功業侔於桓、文，豈徒外藩而已哉？方今世亂多難，若功成事立，當與同好俱南濟也。」策曰：「一與君同符合契，同有永固之分，今便行矣，以老母弱弟委付於君，策無復回顧之憂。」

**释读** 孙策想向袁术请父亲旧军，赴丹杨聚兵、夺吴会，为父报仇。张纮以齐桓晋文类比，认为可据江东辅汉。孙策约他同心，并托母弟。

**附叙** 《吴历》回述孙策居江都时向张纮问计及托付家人；《资治通鉴》卷六十一接在兴平元年投袁术前，问计无确年。

**[《三國志·劉繇太史慈士燮傳》](../../sources/本地分卷/三国志/三国志-卷049.md#edition-period-sgz049-b-2385-5)** · [TXT L10](../../sources/本地分卷/三国志/三国志-卷049.txt#L10)

> 避亂淮浦，詔書以爲揚州刺史。時袁術在淮南，繇畏憚，不敢之州。欲南渡江，吳景、孫賁迎置曲阿。

**刘繇避居淮浦，受任扬州刺史** 袁术已居淮南，刘繇不敢到旧治，吴景、孙贲迎他到曲阿。

**附敘** 《資治通鑑》卷六十一於興平元年末記朝廷任劉繇為揚州刺史、吳景與孫賁迎置曲阿。詔命月日無載。

<a id="period-sgz049-b-2385-6"></a>

**[《三國志·劉繇太史慈士燮傳》](../../sources/本地分卷/三国志/三国志-卷049.md#edition-period-sgz049-b-2385-6)** · [TXT L10](../../sources/本地分卷/三国志/三国志-卷049.txt#L10)

> 術圖爲僭逆，攻沒諸郡縣。繇遣樊能、張英屯江邊以拒之。以景、賁術所授用，乃迫逐使去。於是術乃自置揚州刺史，與景、賁并力攻英、能等，歲餘不下。漢命加繇爲牧，振武將軍，衆數萬人，

**袁术、刘繇争夺扬州诸县** 刘繇遣樊能、张英守江边，逐吴景、孙贲。袁术自署刺史，共进攻岁余未克，汉授刘繇牧与振武将军。

**附敘** 《資治通鑑》卷六十一在興平元年段記劉繇逐吳景、孫賁，雙方沿江進拒。本傳謂圍攻歲餘、漢加劉繇州牧及振武將軍；《後漢書》作振威將軍，稱在興平中。戰事接至興平二年孫策渡江。

<a id="sgz046-b-2257-8"></a>

**[《三國志·孫破虜討逆傳》](../../sources/本地分卷/三国志/三国志-卷046.md#edition-sgz046-b-2257-8)** · [TXT L62](../../sources/本地分卷/三国志/三国志-卷046.txt#L62)

> 先是，劉繇爲揚州刺史，州舊治壽春。

**归年** 《通鉴》卷061兴平元年；任命、渡江及军争前后。

<a id="sgz046-b-2258-1"></a>

**[《三國志·孫破虜討逆傳》](../../sources/本地分卷/三国志/三国志-卷046.md#edition-sgz046-b-2258-1)** · [TXT L62](../../sources/本地分卷/三国志/三国志-卷046.txt#L62)

> 壽春，術已據之，繇乃渡江治曲阿。時吳景尚在丹楊，策從兄賁又爲丹楊都尉，繇至，皆迫逐之。景、賁退舍歷陽。

**释读** 袁术已据寿春，刘繇渡江以曲阿为治所。原在丹杨的吴景和孙贲被赶逐，退守历阳。

**归年** 《通鉴》卷061兴平元年末。刘繇传先记吴景、孙贲迎刘繇，继而见忌被逐。

<a id="sgz046-b-2258-2"></a>

**[《三國志·孫破虜討逆傳》](../../sources/本地分卷/三国志/三国志-卷046.md#edition-sgz046-b-2258-2)** · [TXT L62](../../sources/本地分卷/三国志/三国志-卷046.txt#L62)

> 繇遣樊能、于麋屯橫江津，張英屯當利口，以距術。

**释读** 樊能、于麋屯横江津，张英屯当利口，抵拒袁术方面。

**归年** 《通鉴》卷061系兴平元年末；持续对峙到次年渡江。

<a id="sgz046-b-2258-3"></a>

**[《三國志·孫破虜討逆傳》](../../sources/本地分卷/三国志/三国志-卷046.md#edition-sgz046-b-2258-3)** · [TXT L62](../../sources/本地分卷/三国志/三国志-卷046.txt#L62)

> 術自用故吏琅邪惠衢爲揚州刺史，更以景爲督軍中郎將，與賁共將兵擊英等，連年不克。

**释读** 袁术以属吏惠衢对置扬州刺史，让吴景督军与孙贲攻张英等，经过多时没有攻克。

**归年** 《通鉴》卷061从兴平元年起，连年不克跨到195。

**合读** 《刘繇传》补先迎后逐，《孙策传》详双方沿江设军，次年孙策渡江另见195年第43条。

<a id="sgz051-b-2452-7"></a>

**[《三国志·宗室传》仓内原文 L2452](../../sources/本地分卷/三国志/三国志-卷051.md#l2452)**

> 為楊州刺史劉繇所迫逐，因將士眾還住歷陽。頃之，術復使賁與吳景共擊樊能、張英等，未能拔。

**归年** 《通鉴》卷六十一在兴平元年叙迫逐及初攻，《刘繇传》说相攻岁余。

<a id="sgz056-b-2677-10"></a>

**[《三国志·朱治朱然吕范朱桓传》仓内原文 L2677](../../sources/本地分卷/三国志/三国志-卷056.md#l2677)**

> 是時吳景已在丹楊，而策為術攻廬江。於是劉繇恐為袁、孫所並，遂構嫌隙。

**释读** 孙策为袁术攻庐江、吴景任丹杨之时，刘繇怕被袁氏和孙氏兼并，双方发生嫌隙。

**归年** 《通鉴》卷六十一兴平元年叙刘繇与孙贲、吴景交恶，复用同事件题。

<a id="sg-event-48"></a>

48. **刘备领徐州。** 陶谦病故后，麋竺迎刘备接掌徐州，陈登等劝其接受。 [[48]](#sg-note-48)

<a id="sg-event-49"></a>

49. **孙策从袁术并收父亲旧部。** 孙策由东渡回到袁术统下，袁术将孙坚旧部交还，马日磾又以上宾礼征用孙策。 [[49]](#sg-note-49)

<a id="sg-event-50"></a>

50. **太祖征陶谦，任彧留事。** 兴平元年，太祖征陶谦，任彧留事。 [[50]](#sg-note-50)

<a id="wu-event-51"></a>

51. **曹操判断吕布部署并攻濮阳。** 曹操认为吕布得兖州却不控制东平、切断亢父和泰山险路，只屯濮阳，遂进兵攻打。 [[51]](#wu-note-51)

<a id="wu-event-52"></a>

52. **濮阳交战，曹操坠马灼伤。** 吕布以骑兵冲击青州兵，曹军乱，曹操突火、坠马灼伤左掌；司马楼异扶他上马退出。 [[52]](#wu-note-52)

<a id="wu-event-53"></a>

53. **曹操整军复攻，与吕布相持百余日。** 诸将因未见曹操回营而惊惧。曹操勉力慰劳将士，赶制攻具再攻，与吕布相持百余天。 [[53]](#wu-note-53)

<a id="wu-event-54"></a>

54. **兖州闹蝗饥，曹吕各退。** 蝗虫成灾，百姓饥饿，吕布也粮尽，两军各自撤走。 [[54]](#wu-note-54)

<a id="sgz-event-55"></a>

55. **刘焉去世，刘璋继任益州。** 刘焉去世，刘璋继领益州。 [[55]](#sgz-note-55)

<a id="sgz-event-56"></a>

56. **《吴书》记甘宁率僮客归刘表。** 甘宁领八百人投刘表。 [[56]](#sgz-note-56)

<a id="sgz-event-57"></a>

57. **吕布与夏侯惇交战后入濮阳。** 夏侯惇路遇吕布，两军交战；吕布退而入濮阳，袭取夏侯惇军中辎重。 [[57]](#sgz-note-57)

<a id="sgz-event-58"></a>

58. **韩浩救出夏侯惇。** 吕布遣部将诈降，捉住夏侯惇索要财货，夏侯军中惊恐。 [[58]](#sgz-note-58)

<a id="sgz-event-59"></a>

59. **郭贡率众到鄄城，荀彧见其使其退。** 郭贡率数万人到城下，守军猜他与吕布共谋而害怕。 [[59]](#sgz-note-59)

<a id="sgz-event-60"></a>

60. **刘繇逐孙贲、吴景至历阳。** 刘繇把袁术所属的孙贲、吴景赶到历阳；袁术命二将攻樊能、张英，未克。 [[60]](#sgz-note-60)

<a id="sgz-event-61"></a>

61. **吴景逼退周昕而领丹杨。** 吴景攻周昕未下，声称追随周昕者皆死；周昕不愿连累百姓，散兵回本郡。 [[61]](#sgz-note-61)

<a id="sgz-event-62"></a>

62. **袁术向陆康求军米被拒，命孙策攻庐江。** 袁术打算攻徐州，请庐江太守陆康给米三万斛，未获答允。孙策本就怨陆康以前不亲见他。袁术遣孙策攻陆康，又许地。 [[62]](#sgz-note-62)

<a id="sgz-event-63"></a>

63. **刘繇移治曲阿，与袁术部下争扬州。** 刘繇任扬州刺史，扬州此前以寿春为治所。 [[63]](#sgz-note-63)

<a id="sgz031-b-1633-4"></a>

**[《三国志·刘二牧传》仓内原文 L1633](../../sources/本地分卷/三国志/三国志-卷031.md#l1633)**

>  時征西將軍馬騰屯郿而反，焉及範與騰通謀，引兵襲長安。範謀洩，奔槐里，騰敗，退還涼州，範應時見殺，於是收誕行刑。議郎河南龐羲與焉通家，乃募將焉諸孫入蜀。

**释读** 刘焉与刘范联络马腾。事泄后马腾退，刘范被杀，刘诞被捕处死。庞羲招呼刘氏诸孙入蜀。

**归年** 兴平元年《献帝纪》及《通鉴》载马腾和刘范起兵失败。庞羲护送时间承诸子之难。

<a id="sgz031-p-009-1"></a>

**[《三国志·刘二牧传》裴注 009·1](../../sources/摘录/三国志-卷031-刘二牧传裴注.md#pei-009-1)**

> 英䧺記曰範從長安亡之馬騰營從馬求兵焉使校尉孫肇將兵徃助之敗於長安

**释读** 刘范到马腾处求兵。刘焉的校尉孙肇赴援，兵败长安。

**归年** 《献帝纪》兴平元年记刘范与马腾起兵，注文补军官和行军。

<a id="sgz006-b-339-2"></a>

> 壽春，術已據之，繇乃渡江治曲阿。時吳景尚在丹楊，策從兄賁又為丹揚都尉，繇至，皆迫逐之。景、賁退捨歷陽。

**释读** 袁术已据寿春，刘繇渡江以曲阿为治所。原在丹杨的吴景和孙贲被赶逐，退守历阳。

**归年** 《通鉴》卷061兴平元年末。刘繇传先记吴景、孙贲迎刘繇，继而见忌被逐。

<a id="sgz046-b-2258-2"></a>

**[《三国志·孙破虏讨逆传》仓内原文 L2258](../../sources/本地分卷/三国志/三国志-卷046.md#l2258)**

> 繇遣樊能、於麋東屯橫江津，張英屯當利口，以距術。

**释读** 樊能、于麋屯横江津，张英屯当利口，抵拒袁术方面。

**归年** 《通鉴》卷061系兴平元年末；持续对峙到次年渡江。

<a id="sgz046-b-2258-3"></a>

**[《三国志·孙破虏讨逆传》仓内原文 L2258](../../sources/本地分卷/三国志/三国志-卷046.md#l2258)**

> 術自用故吏琅邪惠衢為揚州刺史，更以景為督軍中郎將，與賁共將兵擊英等，連年不克。

**释读** 袁术以属吏惠衢对置扬州刺史，让吴景督军与孙贲攻张英等，经过多时没有攻克。

**归年** 《通鉴》卷061从兴平元年起，连年不克跨到195。

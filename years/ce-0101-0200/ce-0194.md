[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **大赦天下，改元兴平。** 兴平元年春正月辛酉，颁布大赦，改元兴平。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **帝加元服。** 甲子，帝加元服。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **追尊谥皇妣王氏为灵怀皇后，甲申，改葬於文昭陵。** 二月壬午，追尊谥皇妣王氏为灵怀皇后，甲申，改葬于文昭陵。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **帝耕於藉田。** 丁亥，帝耕于藉田。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **韩遂、马腾与郭汜、樊稠战於长平观，遂、腾败绩，左中郎将刘范、前益州刺史种劭战殁。** 三月，韩遂、马腾与郭汜、樊稠战于长平观，遂、腾败绩，左中郎将刘范、前益州刺史种劭战殁。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **分凉州河西四郡为痈州。** 夏六月丙子，分凉州河西四郡为痈州。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **地震。** 丁丑，地震；戊寅，又震。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **日有食之，帝避正殿，寝兵，不听事五日。** 乙巳晦，发生日食，帝避正殿，寝兵，不听事五日。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **太尉朱儁免。** 秋七月壬子，太尉朱儁免。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **太常杨彪为太尉，录尚书事。** 戊午，太常杨彪为太尉，录尚书事。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **三辅大旱，自四月至於是月。** 三辅大旱，自四月至于是月。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **帝避正殿请雨，遣使者洗囚徒，原轻系。** 帝避正殿请雨，派使者洗囚徒，原轻系。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **是时谷一斛五十万，豆麦一斛二十万，人相食啖，白骨委积。** [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **帝使侍御史侯汶出太仓米豆，为饥人作糜粥，经日而死者无降。** [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **帝疑赋恤有虚，乃亲於御坐前量试作糜，乃知非实，使侍中刘艾出让有司。** 帝疑赋恤有虚，乃亲于御坐前量试作糜，乃知非实，使侍中刘艾出让有司。于是尚书令以下皆到省阁谢，奏收侯汶考实。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **诏曰“未忍致汶於理”。** 诏曰：『未忍致汶于理，可杖五十。』 [[16]](#hh-note-16)

<a id="hh-event-17"></a>

17. **自是之後，多得全济。** 自是之后，多得全济。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **冯翊羌叛，寇属县，郭汜、樊稠击破之。** 八月，冯翊羌叛，寇属县，郭汜、樊稠将其击败。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **桑复生椹，人得以食。** 九月，桑复生椹，人得以食。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **司徒淳于嘉罢。** [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **长安市门自坏。** 冬十月，长安市门自坏。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **以卫尉赵温为司徒，录尚书事。** [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **分安定、扶风为新平郡。** 十二月，分安定、扶风为新平郡。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **是岁，杨州刺史刘繇与袁术将孙策战於曲阿，繇军败绩，孙策遂据江东。** 《献帝纪》把孙策击败扬州刺史刘繇、据江东系于兴平元年。《资治通鉴》据《江表传》采用兴平二年。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **太傅马日磾薨於寿春。** 太傅马日磾薨于寿春。 [[25]](#hh-note-25)

<a id="hh-event-26"></a>

26. **曹嵩遇害异说。** 应劭遣兵接应曹嵩、曹德，未及到，两人便在郡界遇害；本传以陶谦主使。 [[26]](#hh-note-26)

<a id="hh-event-27"></a>

27. **朝廷下诏征赵岐。** 兴平元年下诏征召赵岐。他后来劝董承联络刘表助车驾东归。 [[27]](#hh-note-27)

<a id="hh-event-28"></a>

28. **张邈、陈宫迎吕布。** 曹操攻陶谦时张邈、陈宫迎吕布，荀彧守鄄城，识破张邈试探，部署防御。 [[28]](#hh-note-28)

<a id="hh-event-29"></a>

29. **曹操再攻陶谦。** 曹操再攻陶谦，因张邈等据兖州撤回，陶谦同年病死。 [[29]](#hh-note-29)

<a id="hh-event-30"></a>

30. **帝加元服。** 兴平元年，帝加元服。 [[30]](#hh-note-30)

<a id="hh-event-31"></a>

31. **曹操东击陶谦，令其将武阳人陈宫屯东郡。** 兴平元年，曹操东击陶谦，令其将武阳人陈宫屯东郡。 [[31]](#hh-note-31)

<a id="hh-event-32"></a>

32. **献帝兴平元年秋，长安旱。** [[32]](#hh-note-32)

<a id="hh-event-33"></a>

33. **献帝兴平元年九月，桑复生椹，可食。** [[33]](#hh-note-33)

<a id="hh-event-34"></a>

34. **献帝兴平元年夏，大蝗。** [[34]](#hh-note-34)

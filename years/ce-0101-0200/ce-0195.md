<a id="sg-event-43"></a>

43. **孙策渡江破刘繇，进据曲阿。** 吴景、孙贲攻当利口久未能取胜，孙策获袁术准许前往增援。在历阳集众五六千，周瑜带兵和粮饷来会。孙策安置母亲后进兵，攻下横江、当利及牛渚，取得仓粮军械。孙策进攻秣陵，薛礼败走，笮融退守营垒。樊能、于麋夺回牛渚，孙策回军再夺。孙策二攻笮融时中箭，乘敌误信自己已死，设伏击败追兵；见其营垒坚固，转攻湖孰、江乘。太史慈在神亭与孙策交手。刘繇在曲阿败退，孙策入城，宽待降人，招纳兵众，并任用张昭、张纮、秦松、陈端等。 [[43]](#sg-note-43)

<a id="sgz-event-44"></a>

44. **杨奉与宋果谋杀李傕未成。** 杨奉与李傕军吏宋果密谋杀李傕，泄露后杨奉率兵反叛，李傕势力削弱。 [[44]](#sgz-note-44)

<a id="sgz-event-45"></a>

45. **韩融促李傕、郭汜放回被掳人员。** 韩融赴弘农与李傕、郭汜议和，使其归还宫人、公卿百官和车马。 [[45]](#sgz-note-45)

<a id="sgz-event-46"></a>

46. **赵温书劝和李傕反受威胁。** 赵温被关后写信劝李傕放弃挟帝往黄白城，应服诏讲和。李傕怒欲加害，李应劝止，常洽告知献帝。 [[46]](#sgz-note-46)

<a id="sgz-event-47"></a>

47. **郭汜扣押公卿，杨彪责其乱。** 郭汜宴公卿议攻李傕，杨彪斥责两人劫帝、扣公卿，郭汜欲杀杨彪，杨密等劝免。 [[47]](#sgz-note-47)

<a id="sgz-event-48"></a>

48. **李傕祠鬼见帝，君臣持刀。** 《献帝起居注》记李傕信巫鬼，设董卓神坐，携刀入见，左右惊惧持械，侍中李祯疏解。 [[48]](#sgz-note-48)

<a id="sgz-event-49"></a>

49. **皇甫郦奉诏调和李傕、郭汜。** 皇甫郦劝和，两将仅郭汜受诏。皇甫郦以董卓前车斥李傕，复与胡邈争辩，献帝命其离开，虎贲王昌不忍追捕。 [[49]](#sgz-note-49)

<a id="sgz-event-50"></a>

50. **魏略称秦伯南为救曹操遇害。** 《魏略》另说兴平末曹操受袁术部党追击，秦伯南开门舍之、冒作曹操而被害，曹操因而改变曹真姓。 [[50]](#sgz-note-50)

<a id="sgz-event-51"></a>

51. **朱皓与诸葛玄争豫章，笮融杀朱皓。** 朝廷更选朱皓接任豫章太守。朱皓从刘繇求兵，诸葛玄退守西城。笮融诈杀朱皓据郡，后为刘繇击破，入山被杀。 [[51]](#sgz-note-51)

<a id="sgz-event-52"></a>

52. **贾诩离李傕，投华阴段煨。** 段煨驻华阴、与贾诩同郡；贾诩离李傕以投段煨。 [[52]](#sgz-note-52)

<a id="sgz-event-53"></a>

53. **朱治从钱唐进吴郡，击败许贡。** 吴郡太守许贡在由拳阻击朱治，战败后投严白虎；朱治入吴郡领太守事。 [[53]](#sgz-note-53)

<a id="sgz-event-54"></a>

54. **钟繇韩斌协助献帝脱离长安。** 李傕胁持天子，钟繇与尚书郎韩斌同谋，助帝出长安。 [[54]](#sgz-note-54)

<a id="sgz-event-55"></a>

55. **朝廷以华歆为豫章太守。** 到徐州即奉诏任豫章太守，清静爱民，吏民敬服。 [[55]](#sgz-note-55)

<a id="sgz-event-57"></a>

57. **袁术以袁胤代周尚为丹杨太守。** 袁胤代职，周尚及周瑜回寿春。 [[57]](#sgz-note-57)

<a id="sgz-event-58"></a>

58. **曹操以李整领其父兵讨薛兰李封。** 李整领父军，随曹军讨薛兰、李封，继平诸县，后迁青州刺史。 [[58]](#sgz-note-58)

> 傕兄子利隨稠利還告傕韓樊交馬語不知所道意愛甚密傕以是疑稠與韓遂私和而有異意稠欲將兵東出關從傕索益兵因請稠㑹議便於坐殺稠

**释读** 李利把樊稠与韩遂密谈告诉李傕，李傕猜疑，乘樊稠请求增兵出关时召会杀死。

> 典畧曰傕數設酒請氾或留汜止宿汜妻懼傕與汜婢妾而奪己愛思有以離間之㑹傕送饋妻乃以䜴為藥汜將食妻曰食從外來儻或有故遂摘藥示之曰一棲不二雄我固疑將軍之信李公也他日傕復請汜大醉汜疑傕藥之絞糞汁飲之乃解於是遂生嫌隙而治兵相攻

**释读** 《典略》称郭汜妻因恐夺宠，假作药物令郭汜疑李傕下毒。郭汜醉后因疑李傕而饮汁解毒，继与其相攻。

**[《三国志·董二袁刘传》](../../sources/摘录/三国志-卷006-董二袁刘传.md#p002)** · [仓内TXT L340](../../sources/本地分卷/三国志/三国志-卷006.md#l340)

> 傕質天子於營，燒宮殿城門，略官寺，盡收乘輿服御物置其家。

<a id="hh009-l1237-e3"></a>

**[《后汉书·献帝纪》](../../sources/摘录/后汉书-卷009-献帝纪.md#p001)** · [仓内TXT L1237](../../sources/本地分卷/后汉书/后汉书-卷009.md#L1237)

> 三月丙寅，李傕脅帝幸其營，焚宮室。

<a id="sgz006-p-031-1"></a>

**[《三国志·董二袁刘传》裴注 031·1](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-031-1)**

> 獻帝起居注曰初汜謀迎天子幸其營夜有亡告傕者傕使兄子暹將數千兵圍宮以車三乗迎天子楊彪曰自古帝王無在人臣家者舉事當合天下心諸君作此非是也暹曰將軍計定矣於是天子一乗貴人伏氏一乗賈詡左靈一乗其餘皆步從

**释读** 李傕得知郭汜迎帝之谋，命侄李暹率兵围宫。杨彪抗议未果，只有献帝、伏氏、贾诩左灵等乘车，其余步行。

**归年** 兴平二年三月李傕胁帝幸其营。

> 天子以謁者僕射皇甫酈涼州舊姓有專對之才遣令和傕汜酈先詣汜汜受詔命詣傕傕不肯曰我有呂布之功輔政四年三輔清静天下所知也郭多盜馬虜耳何敢乃欲與吾等邪必欲誅之君為涼州人觀吾方畧士衆足辦多不多又刧質公卿所為如是而君茍欲利郭多李傕有膽自知之酈答曰昔有窮后羿恃其善射不思患難以至於斃近董公之彊明將軍目所見内有王公以為内主外有董旻承璜以為鯁毒呂布受恩而反圖之斯須之間頭縣竿端此有勇而無謀也今將軍身為上將把鉞杖節子孫握權宗族荷寵國家好爵而皆據之今郭多刼質公卿將軍脅至尊誰為輕重邪張濟與郭多楊定有謀又為冠帶所附楊奉白波帥耳猶知將軍所為非是將軍雖拜寵之猶不肯盡力也傕不納酈言而呵之令出酈出詣省門白傕不肯從詔辭語不順侍中胡邈為傕所幸呼傳詔者令飾其辭又謂酈曰李將軍於卿不薄又皇甫公為太尉李將軍力也酈答曰胡敬才卿為國家常伯輔弼之臣也語言如此寧可用邪邈曰念卿失李將軍意恐不易耳我與卿何事者酈言我累世受恩身又常在幃幄君辱臣死當坐國家為李傕所殺則天命也天子聞酈答語切恐傕聞之便勅遣酈酈裁出營門傕遣虎賁王昌呼之昌知酈忠直縱令去還答傕言追之不及

**归年** 《通鉴》卷061于兴平二年夏李、郭相攻时。

### 51. 朱皓与诸葛玄争豫章，笮融杀朱皓

[返回正文第51条](#sgz-event-51)

<a id="sgz035-p-001-1b"></a>

**[《三国志》卷035裴注 001·1b](../../sources/摘录/三国志-卷035-诸葛亮传裴注.md#pei-001-1b)**

> 遣朱皓代玄皓從揚州太守劉繇求兵擊玄玄退屯西城皓入南昌

**释读** 朱皓从刘繇请求军队，击诸葛玄，诸葛玄退至西城，朱皓入南昌。

**归年** 《资治通鉴》卷六十一系兴平二年，与此卷本传朝廷更选朱皓互证。

<a id="sgz035-b-1752-2b"></a>

**[《三国志·诸葛亮传》仓内原文 L1752](../../sources/本地分卷/三国志/三国志-卷035.md#l1752)**

> 會漢朝更選朱皓代玄。

**释读** 朝廷另选朱皓接代诸葛玄。

**归年** 《资治通鉴》卷六十一系朱皓与诸葛玄交兵于兴平二年。《献帝春秋》记交战，本传只记更选。

<a id="sgz049-b-2385-8"></a>

**[《三国志·刘繇太史慈士燮传》仓内原文 L2385](../../sources/本地分卷/三国志/三国志-卷049.md#l2385)**

> 笮融先至。殺太守朱皓，入居郡中。繇進討融，為融所破，更復招合屬縣，攻破融，融敗走入山。為民所殺。

**归年** 《通鉴》卷061列于兴平二年末，先后详在L543—550；《献帝春秋》另载刘繇本派其助朱皓。

<a id="sgz049-b-2387-6"></a>

**[《三国志·刘繇太史慈士燮传》仓内原文 L2387](../../sources/本地分卷/三国志/三国志-卷049.md#l2387)**

> 過殺禮，然後殺皓。

**释读** 笮融过秣陵杀薛礼，后至豫章杀朱皓。

**归年** 《通鉴》卷061把末段连叙在195，朱皓之死与L2385用同条。

<a id="sgz049-p-004-2"></a>

**[《三国志·刘繇太史慈士燮传》裴注 004·2](../../sources/摘录/三国志-卷049-刘繇太史慈士燮传裴注.md#pei-004-2)**

> 獻帝春秋曰是嵗繇屯彭澤又使融助晧討劉表所用太守諸葛玄許子將謂繇曰笮融出軍不顧命名義者也朱文明善推誠以信人宜使宻防之融到果詐殺晧代領郡事

**释读** 刘繇驻彭泽让笮融助朱皓攻诸葛玄，许劭请朱皓小心，笮融到后杀朱皓。

**归年** 《通鉴》卷061兴平二年。《献帝春秋》作刘表所遣诸葛玄，《三国志·诸葛亮传》作袁术所署，《通鉴》从后者。

1. **郊祀上帝於安邑，大赦天下，改元建安。** 建安元年春正月癸酉，郊祀上帝于安邑，颁布大赦，改元建安。 [[1]](#hh-note-1)

<a id="hh-event-25"></a>

<a id="hh-event-2"></a>

2. **韩暹攻董承，董承奔张杨。** 二月诸将相争，韩暹攻卫将军董承。董承奔张杨，张杨令其先修洛阳宫室。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **幸闻喜。** 夏六月乙未，幸闻喜。 [[3]](#hh-note-3)

<a id="hh-event-22"></a>

<a id="sg-event-31"></a>

<a id="hh-event-4"></a>

4. **献帝还洛阳，暂居赵忠故宅。** 七月甲子，车驾在董承、杨奉、韩暹等护持下到洛阳，暂居赵忠故宅。张杨供粮，杨奉别屯梁。之后迁许另见第14条。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **郊祀上帝，大赦天下。** 丁丑，郊祀上帝，颁布大赦。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **谒太庙。** 己卯，谒太庙。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **幸南宫杨安殿。** 八月辛丑，幸南宫杨安殿。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **安国将军张杨为大司马，韩暹为大将军，杨奉为车骑将军。** 癸卯，安国将军张杨为大司马，韩暹为大将军，杨奉为车骑将军。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **是时，宫室烧尽，百官披荆棘，依墙壁间。** [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **州郡各拥强兵，而委输不至，群僚饥乏，尚书郎以下自出采穭，或饥死墙壁间，或为兵士所杀。** [[10]](#hh-note-10)

<a id="sg-event-33"></a>

<a id="hh-event-11"></a>

11. **曹操在洛阳录尚书事，兼领司隶校尉。** 八月辛亥，《献帝纪》记曹操自领司隶校尉、录尚书事。《武帝纪》记韩暹遁后，献帝授曹操节钺、命录尚书事；裴注所引《献帝纪》又记兼领司隶校尉。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **曹操杀侍中台崇、尚书冯硕等。** [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **封卫将军董承为辅国将军，伏完等十三人为列侯，赠沮儁为弘农太守。** [[13]](#hh-note-13)

<a id="hh-event-19"></a>

<a id="hh-event-14"></a>

14. **迁都许。** 庚申，迁都许。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **幸曹操营。** 己巳，幸曹操营。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **太尉杨彪、司空张喜罢。** 九月，太尉杨彪、司空张喜罢。 [[16]](#hh-note-16)

<a id="sg-event-40"></a>

<a id="hh-event-17"></a>

17. **曹操为司空，行车骑将军事。** 十一月丙戌，曹操为司空，行车骑将军事。《后汉书》说“自为”，《武帝纪》写作“天子拜公”。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **应劭奏报所编《汉仪》。** 应劭通检旧案、新典，编定并上奏朝廷礼制文献。 [[18]](#hh-note-18)

<a id="hh-event-20"></a>

20. **袁谭攻破孔融。** 建安元年袁谭围孔融，城陷后孔融出逃，妻子被俘。 [[20]](#hh-note-20)

<a id="sg-event-45"></a>

<a id="hh-event-21"></a>

21. **张济攻穰中箭死，张绣领其余众。** 张济在弘农缺粮，从关中进攻南阳穰城，中箭死。刘表以吊丧相待并招纳余众。张济的侄子张绣接领部众，屯宛，与刘表联合。 [[21]](#hh-note-21)

<a id="hh-event-23"></a>

23. **拜完辅国将军，仪比三司。** 建安元年，拜完辅国将军，仪比三司。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **自徐州还高密，道遇黄巾贼数万人，见玄皆拜，相约不敢入县境。** 建安元年，自徐州还高密，道遇黄巾贼数万人，见玄皆拜，相约不敢入县境。 [[24]](#hh-note-24)

<a id="sg-event-26"></a>

26. **太祖军临武平，袁术所置陈相袁嗣降。** 建安元年春正月，太祖军临武平，袁术所置陈相袁嗣降。 [[26]](#sg-note-26)

<a id="sg-event-27"></a>

27. **太祖将迎天子，诸将或疑。** 太祖将迎天子，各将领或疑，荀彧、程昱劝之，乃遣曹洪将兵西迎，衞将军董承与袁术将苌奴拒险，洪不得进。 [[27]](#sg-note-27)

<a id="sg-event-46"></a>

<a id="sg-event-28"></a>

<a id="sg-event-29"></a>

29. **曹操击破汝南、颍川黄巾，何仪率部投降。** 二月，曹操出兵讨何仪、黄邵等。于禁击破夜袭曹营的黄巾军，黄邵等被杀，何仪率部投降。 [[29]](#sg-note-29)

<a id="sg-event-30"></a>

30. **天子拜太祖建德将军，夏六月。** 天子拜太祖建德将军，夏六月，迁镇东将军，封费亭侯。 [[30]](#sg-note-30)

<a id="sg-event-32"></a>

32. **太祖遂至洛阳，衞京都。** 太祖遂至洛阳，衞京都，暹遁走。 [[32]](#sg-note-32)

<a id="sg-event-34"></a>

34. **献帝任曹操为大将军，封武平侯。** 献帝任曹操为大将军，封武平侯。任官与献帝迁许相接，迁都见第14条。 [[34]](#sg-note-34)

<a id="sg-event-35"></a>

35. **迁许后重建宗庙、社稷制度。** 献帝西迁以来，朝政长期动荡。迁都许县后，宗庙、社稷等礼制重新建立。 [[35]](#sg-note-35)

<a id="sg-event-36"></a>

36. **天子之东也，奉自梁欲要之。** 天子之东也，奉自梁欲要之，不及。 [[36]](#sg-note-36)

<a id="sg-event-37"></a>

37. **公征奉，奉南奔袁术。** 冬十月，公征奉，奉南奔袁术，遂攻其梁屯，拔之。 [[37]](#sg-note-37)

<a id="sg-event-39"></a>

<a id="sg-event-38"></a>

38. **袁绍拒授太尉，曹操辞让大将军。** 朝廷以袁绍为太尉，袁绍以位在曹操之下为耻，拒绝受命。曹操辞让大将军给袁绍。《后汉书·献帝纪》记次年袁绍正式拜大将军。 [[38]](#sg-note-38)

<a id="sg-event-41"></a>

41. **是岁用枣祗、韩浩等议。** 当年用枣祗、韩浩等议，始兴屯田。 [[41]](#sg-note-41)

<a id="sgz-event-54"></a>

<a id="sg-event-42"></a>

42. **袁术攻刘备，吕布乘隙袭取下邳。** 袁术来攻，刘备使张飞留守下邳，亲赴盱眙、淮阴抵御。两军相持，吕布乘机水陆并进，袭取下邳，俘获刘备妻儿与将吏家口。诸书对曹豹、许耽和丹杨兵迎布的经过有异。刘备回师时军溃，一度退海西，后来与吕布议和。 [[42]](#sg-note-42)

<a id="sg-event-44"></a>

<a id="sg-event-43"></a>

43. **刘备败投曹操，获兵粮回小沛。** 纪灵退兵后，刘备在小沛收合兵众。吕布亲自出兵来攻，刘备战败，投奔曹操。程昱劝曹操早作处置，曹操以正在招揽天下豪杰为由拒绝，任刘备为豫州牧，给兵粮使他回小沛。射戟罢兵见第50条；高顺、张辽后来破沛见198年第26条。 [[43]](#sg-note-43)

<a id="sg-event-47"></a>

47. **太祖定黄巾于许，遣使诣河东。** 建安元年，太祖定黄巾于许，派使诣河东。 [[47]](#sg-note-47)

<a id="sg-event-48"></a>



<a id="sgz-event-50"></a>

50. **吕布辕门射戟，纪灵与刘备罢兵。** 刘备屯小沛时，袁术遣纪灵率军攻打刘备。刘备向吕布求援。吕布担心袁术击破刘备后会与泰山诸将连结，便带兵屯于沛西南，约纪灵等同饮。他让人在营门立戟，约定射中小支便解兵，随后一箭射中。次日诸将再会，而后各自收兵。 [[50]](#sgz-note-50)

<a id="sgz-event-51"></a>

51. **袁术为儿子向吕布求婚。** 袁术想结吕布为援，为儿子聘吕布之女，吕布答应。 [[51]](#sgz-note-51)

<a id="sgz-event-52"></a>

52. **郝萌夜袭吕布，被高顺平定。** 郝萌半夜攻击吕布所居府署，吕布带妻子翻出至高顺营；高顺认出叛者，率兵射退之。曹性伤郝萌一臂，高顺斩郝萌送曹性见吕布。 [[52]](#sgz-note-52)

<a id="sgz-event-53"></a>

53. **追论士孙瑞功、封其子。** 天子都许后追叙其功，封士孙萌澹津亭侯。 [[53]](#sgz-note-53)

<a id="sgz-event-55"></a>

55. **曹操表刘备镇东将军、封宜城亭侯。** 曹操表授刘备镇东将军、宜城亭侯。 [[55]](#sgz-note-55)

<a id="sgz-event-56"></a>

56. **麋竺让妹嫁刘备并出资助军。** 刘备退至海西乏资，麋竺以妹嫁刘备，送奴客两千和金银财货资军。 [[56]](#sgz-note-56)

<a id="sgz-event-57"></a>

57. **荀彧进侍中，守尚书令。** 献帝进用荀彧为汉侍中，代理尚书令。 [[57]](#sgz-note-57)

<a id="sgz-event-58"></a>

58. **荀彧向曹操推荐荀攸、钟繇。** 曹操问谁能代替荀彧谋划，荀彧说荀攸与钟繇。 [[58]](#sgz-note-58)

<a id="sgz-event-59"></a>

59. **戏志才死后荀彧荐郭嘉。** 戏志才死，荀彧又举荐郭嘉。 [[59]](#sgz-note-59)

<a id="sgz-event-60"></a>

60. **曹操征荀攸，让其做尚书。** 曹操致书邀荀攸参与时事，将他征为汝南太守，又入为尚书。 [[60]](#sgz-note-60)

<a id="sgz-event-61"></a>

61. **曹操用荀攸为军师。** 曹操素闻荀攸名，与之谈后喜欢，向荀彧、钟繇称有荀攸谋事天下可定，并任军师。 [[61]](#sgz-note-61)

<a id="sgz-event-62"></a>

62. **贾诩离开段煨，投张绣。** 张绣在南阳，贾诩暗结、获使迎，向旁人解释段煨疑己、去而自全且可保妻子；张绣以子孙礼相待，段煨果安置其家。 [[62]](#sgz-note-62)

<a id="sgz-event-63"></a>

63. **贾诩劝张绣和刘表联合。** 贾诩建议张绣与刘表结盟。 [[63]](#sgz-note-63)

<a id="sgz-event-64"></a>

64. **贾诩见刘表，评其有平世三公才。** 贾诩南见刘表，刘表待为客，贾诩说刘表堪平世三公、遇变化疑而不决，不能成事。 [[64]](#sgz-note-64)

<a id="sg-event-49"></a>

<a id="sgz-event-65"></a>

65. **孙策攻取会稽，王朗走东冶。** 孙静与孙策会于钱唐，王朗据固陵抵御。孙策从孙静计，绕查渎袭高迁，击斩周昕，取会稽，王朗浮海走东冶。孙策自领会稽太守，任程普为吴郡都尉、治钱唐，署周泰为别部司马、董袭为门下贼曹，察贺齐为孝廉。 [[65]](#sgz-note-65)

<a id="sgz-event-66"></a>

66. **袁术问张承能否成霸业。** 张范遣张承见袁术，袁术自恃土广民众，拟比齐桓公、汉高祖。 [[66]](#sgz-note-66)

<a id="sgz-event-67"></a>

67. **许都征孔融为将作大匠。** 建安元年征还朝任将作大匠，后迁任少府，朝议常主发言。 [[67]](#sgz-note-67)

<a id="sgz-event-68"></a>

68. **献帝初都许，孔融请定千里王畿。** 请按古制以司隶辖境为王畿，曾带公卿上言；议不适朝廷初立曹袁未分。 [[68]](#sgz-note-68)

<a id="sgz-event-69"></a>

69. **曹操为大将军后任满宠为许令。** 曹操辟署满宠为西曹属、许县令。 [[69]](#sgz-note-69)

<a id="sgz-event-70"></a>

70. **满宠为许令，处死犯法的曹洪宾客。** 曹洪向满宠求情未获，又告曹操。满宠预料曹操要赦免宾客，立即杀掉，曹操反表示欣赏其果断。 [[70]](#sgz-note-70)

<a id="sgz-event-71"></a>

71. **董昭拟曹操书结纳杨奉。** 天子还洛后诸将不和，董昭认为杨奉兵强援弱，代曹写书。 [[71]](#sgz-note-71)

<a id="sgz-event-72"></a>

72. **曹操迎帝都许，赵俨决意归附。** 称曹操有担当天下之资，定会济中国。 [[72]](#sgz-note-72)

<a id="sgz-event-73"></a>

73. **丁冲任司隶校尉。** 魏略叙曹操奉迎天子至许后任丁冲为司隶校尉。 [[73]](#sgz-note-73)

<a id="sgz-event-74"></a>

74. **吕布令袁涣辱骂刘备，袁涣拒绝。** 吕布逼袁涣写信辱骂刘备，袁涣以德行相劝，又表示即使被杀也不肯执笔。《资治通鉴》系在建安元年。 [[74]](#sgz-note-74)

<a id="hh-event-20"></a>

20. **袁谭攻破孔融。** 建安元年袁谭围孔融，城陷后孔融出逃，妻子被俘。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **张济攻穰城中箭而死。** 张济从关中到南阳，攻穰城中箭死，刘表招纳其余众。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **献帝还洛阳。** 去卑和韩暹等参与保卫东归车驾，抵抗李傕、郭汜，天子之后迁许。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

<a id="hh-event-25"></a>

25. **诸将争权，韩暹遂攻董承，承奔张杨，杨乃使承先缮修洛宫。** 建安元年春，诸将争权，韩暹遂攻董承，承奔张杨，杨乃使承先缮修洛宫。 [[25]](#hh-note-25)

<a id="sg-event-26"></a>

<a id="sg-event-27"></a>

27. **太祖将迎天子，诸将或疑。** 太祖将迎天子，各将领或疑，荀彧、程昱劝之，乃遣曹洪将兵西迎，衞将军董承与袁术将苌奴拒险，洪不得进。 [[27]](#sg-note-27)

<a id="sg-event-29"></a>

29. **太祖进军讨破之，斩辟、邵等。** 二月，太祖进军讨破之，斩辟、邵等，仪及其衆皆降。 [[29]](#sg-note-29)

<a id="sg-event-30"></a>

30. **天子拜太祖建德将军，夏六月。** 天子拜太祖建德将军，夏六月，迁镇东将军，封费亭侯。 [[30]](#sg-note-30)

<a id="sg-event-31"></a>

31. **杨奉、韩暹以天子还洛阳。** 秋七月，杨奉、韩暹以天子还洛阳，奉别屯梁。 [[31]](#sg-note-31)

<a id="sg-event-32"></a>

32. **太祖遂至洛阳，衞京都。** 太祖遂至洛阳，衞京都，暹遁走。 [[32]](#sg-note-32)

33. **天子假太祖节钺，录尚书事。** [[33]](#sg-note-33)

<a id="sg-event-34"></a>

34. **车驾出轘辕而东，以太祖爲大将军。** 九月，车驾出轘辕而东，以太祖爲大将军，封武平侯。 [[34]](#sg-note-34)

<a id="sg-event-35"></a>

35. **自天子西迁，朝廷日乱。** 自天子西迁，朝廷日乱，至是宗庙社稷制度始立。 [[35]](#sg-note-35)

<a id="sg-event-36"></a>

36. **天子之东也，奉自梁欲要之。** 天子之东也，奉自梁欲要之，不及。 [[36]](#sg-note-36)

37. **公征奉，奉南奔袁术。** 冬十月，公征奉，奉南奔袁术，遂攻其梁屯，拔之。 [[37]](#sg-note-37)

<a id="sg-event-38"></a>

38. **于是以袁绍爲太尉，绍耻班在公下。** 于是以袁绍爲太尉，绍耻班在公下，不肯受。 [[38]](#sg-note-38)

39. **公乃固辞，以大将军让绍。** [[39]](#sg-note-39)

40. **天子拜公司空，行车骑将军。** [[40]](#sg-note-40)

<a id="sg-event-41"></a>

41. **是岁用枣祗、韩浩等议。** 当年用枣祗、韩浩等议，始兴屯田。 [[41]](#sg-note-41)

<a id="sg-event-42"></a>

42. **吕布袭取下邳。** 吕布袭刘备，取下邳。 [[42]](#sg-note-42)

<a id="sg-event-43"></a>

43. **程昱说公曰“观刘备有雄才而甚得衆心”。** 程昱说公曰：「观刘备有雄才而甚得衆心，终不爲人下，不如早图之。」 [[43]](#sg-note-43)

<a id="sg-event-44"></a>

44. **公曰“方今收英雄时也”。** 公曰：「方今收英雄时也，杀一人而失天下之心，不可。」 [[44]](#sg-note-44)

45. **济死，从子绣领其衆。** [[45]](#sg-note-45)

<a id="sgz-event-50"></a>

50. **吕布辕门射戟止兵。** 袁术派纪灵等率三万步骑攻刘备，刘备向吕布求救。 [[50]](#sgz-note-50)

<a id="sgz-event-51"></a>

51. **袁术为儿子向吕布求婚。** 袁术想结吕布为援，为儿子聘吕布之女，吕布答应。 [[51]](#sgz-note-51)

<a id="sgz-event-52"></a>

52. **郝萌夜袭吕布，被高顺平定。** 郝萌半夜攻击吕布所居府署，吕布带妻子翻出至高顺营；高顺认出叛者，率兵射退之。曹性伤郝萌一臂，高顺斩郝萌送曹性见吕布。 [[52]](#sgz-note-52)

<a id="sgz-event-53"></a>

53. **追论士孙瑞功、封其子。** 天子都许后追叙其功，封士孙萌澹津亭侯。 [[53]](#sgz-note-53)

<a id="sgz-event-54"></a>

54. **袁术与刘备交战于盱眙、淮阴。** 袁术进攻刘备，刘备在盱眙、淮阴抵抗。 [[54]](#sgz-note-54)

<a id="sgz-event-55"></a>

55. **曹操表刘备镇东将军、封宜城亭侯。** 曹操表授刘备镇东将军、宜城亭侯。 [[55]](#sgz-note-55)

<a id="sgz-event-56"></a>

56. **麋竺让妹嫁刘备并出资助军。** 刘备退至海西乏资，麋竺以妹嫁刘备，送奴客两千和金银财货资军。 [[56]](#sgz-note-56)

<a id="sgz-event-57"></a>

57. **荀彧进侍中，守尚书令。** 献帝进用荀彧为汉侍中，代理尚书令。 [[57]](#sgz-note-57)

<a id="sgz-event-58"></a>

58. **荀彧向曹操推荐荀攸、钟繇。** 曹操问谁能代替荀彧谋划，荀彧说荀攸与钟繇。 [[58]](#sgz-note-58)

<a id="sgz-event-59"></a>

59. **戏志才死后荀彧荐郭嘉。** 戏志才死，荀彧又举荐郭嘉。 [[59]](#sgz-note-59)

<a id="sgz-event-60"></a>

60. **曹操征荀攸，让其做尚书。** 曹操致书邀荀攸参与时事，将他征为汝南太守，又入为尚书。 [[60]](#sgz-note-60)

<a id="sgz-event-61"></a>

61. **曹操用荀攸为军师。** 曹操素闻荀攸名，与之谈后喜欢，向荀彧、钟繇称有荀攸谋事天下可定，并任军师。 [[61]](#sgz-note-61)

<a id="sgz-event-62"></a>

62. **贾诩离开段煨，投张绣。** 张绣在南阳，贾诩暗结、获使迎，向旁人解释段煨疑己、去而自全且可保妻子；张绣以子孙礼相待，段煨果安置其家。 [[62]](#sgz-note-62)

<a id="sgz-event-63"></a>

63. **贾诩劝张绣和刘表联合。** 贾诩建议张绣与刘表结盟。 [[63]](#sgz-note-63)

<a id="sgz-event-64"></a>

64. **贾诩见刘表，评其有平世三公才。** 贾诩南见刘表，刘表待为客，贾诩说刘表堪平世三公、遇变化疑而不决，不能成事。 [[64]](#sgz-note-64)

<a id="sgz-event-65"></a>

65. **孙策与孙静会师并取会稽。** 孙策攻会稽前邀孙静，孙静与家属在钱唐同孙策会合。王朗倚固陵抵抗，吴军屡渡水未能攻克。 [[65]](#sgz-note-65)

<a id="sgz-event-66"></a>

66. **袁术问张承能否成霸业。** 张范遣张承见袁术，袁术自恃土广民众，拟比齐桓公、汉高祖。 [[66]](#sgz-note-66)

> 布於沛西南一里安屯，遣鈴下請靈等，靈等亦請布共飲食。布謂靈等曰：「玄德，布弟也。弟爲諸君所困，故來救之。布性不喜合鬬，但喜解鬬耳。」布令門候於營門中舉一隻戟，布言：「諸君觀布射戟小支，一發中者諸君當解去，不中可留決鬬。」布舉弓射戟，正中小支。諸將皆驚，言「將軍天威也」！明日復歡會，然後各罷。

16. **太尉杨彪、司空张喜罢。** 九月，太尉杨彪、司空张喜罢。 [[16]](#hh-note-16)

17. **曹操自为司空，行车骑将军事，百官总己以听。** 冬十一月丙戌，曹操自为司空，行车骑将军事，百官总己以听。 [[17]](#hh-note-17)

<a id="hh-event-18"></a>

18. **应劭奏报所编《汉仪》。** 应劭通检旧案、新典，编定并上奏朝廷礼制文献。 [[18]](#hh-note-18)

<a id="hh-event-19"></a>

19. **杨彪从献帝自洛阳迁许。** 献帝迁许，杨彪随驾，后与曹操发生冲突。 [[19]](#hh-note-19)

<a id="hh-event-20"></a>

20. **袁谭攻破孔融。** 建安元年袁谭围孔融，城陷后孔融出逃，妻子被俘。 [[20]](#hh-note-20)

<a id="hh-event-21"></a>

21. **张济攻穰城中箭而死。** 张济从关中到南阳，攻穰城中箭死，刘表招纳其余众。 [[21]](#hh-note-21)

<a id="hh-event-22"></a>

22. **献帝还洛阳。** 去卑和韩暹等参与保卫东归车驾，抵抗李傕、郭汜，天子之后迁许。 [[22]](#hh-note-22)

<a id="hh-event-23"></a>

23. **拜完辅国将军，仪比三司。** 建安元年，拜完辅国将军，仪比三司。 [[23]](#hh-note-23)

<a id="hh-event-24"></a>

24. **自徐州还高密，道遇黄巾贼数万人，见玄皆拜，相约不敢入县境。** 建安元年，自徐州还高密，道遇黄巾贼数万人，见玄皆拜，相约不敢入县境。 [[24]](#hh-note-24)

<a id="hh-event-25"></a>

25. **诸将争权，韩暹遂攻董承，承奔张杨，杨乃使承先缮修洛宫。** 建安元年春，诸将争权，韩暹遂攻董承，承奔张杨，杨乃使承先缮修洛宫。 [[25]](#hh-note-25)

<a id="sg-event-26"></a>

26. **太祖军临武平，袁术所置陈相袁嗣降。** 建安元年春正月，太祖军临武平，袁术所置陈相袁嗣降。 [[26]](#sg-note-26)

<a id="sg-event-27"></a>

27. **太祖将迎天子，诸将或疑。** 太祖将迎天子，各将领或疑，荀彧、程昱劝之，乃遣曹洪将兵西迎，衞将军董承与袁术将苌奴拒险，洪不得进。 [[27]](#sg-note-27)

<a id="sg-event-28"></a>

28. **汝南、颍川黄巾何仪、刘辟、黄邵、何曼等。** 汝南、颍川黄巾何仪、刘辟、黄邵、何曼等，衆各数万，初应袁术，又附孙坚。 [[28]](#sg-note-28)

<a id="sg-event-29"></a>

29. **太祖进军讨破之，斩辟、邵等。** 二月，太祖进军讨破之，斩辟、邵等，仪及其衆皆降。 [[29]](#sg-note-29)

<a id="sg-event-30"></a>

30. **天子拜太祖建德将军，夏六月。** 天子拜太祖建德将军，夏六月，迁镇东将军，封费亭侯。 [[30]](#sg-note-30)

<a id="sg-event-31"></a>

31. **杨奉、韩暹以天子还洛阳。** 秋七月，杨奉、韩暹以天子还洛阳，奉别屯梁。 [[31]](#sg-note-31)

<a id="sg-event-32"></a>

32. **太祖遂至洛阳，衞京都。** 太祖遂至洛阳，衞京都，暹遁走。 [[32]](#sg-note-32)

<a id="sg-event-33"></a>

33. **天子假太祖节钺，录尚书事。** [[33]](#sg-note-33)

<a id="sg-event-34"></a>

34. **车驾出轘辕而东，以太祖爲大将军。** 九月，车驾出轘辕而东，以太祖爲大将军，封武平侯。 [[34]](#sg-note-34)

<a id="sg-event-35"></a>

35. **自天子西迁，朝廷日乱。** 自天子西迁，朝廷日乱，至是宗庙社稷制度始立。 [[35]](#sg-note-35)

<a id="sg-event-36"></a>

36. **天子之东也，奉自梁欲要之。** 天子之东也，奉自梁欲要之，不及。 [[36]](#sg-note-36)

<a id="sg-event-37"></a>

37. **公征奉，奉南奔袁术。** 冬十月，公征奉，奉南奔袁术，遂攻其梁屯，拔之。 [[37]](#sg-note-37)

<a id="sg-event-38"></a>

38. **于是以袁绍爲太尉，绍耻班在公下。** 于是以袁绍爲太尉，绍耻班在公下，不肯受。 [[38]](#sg-note-38)

<a id="sg-event-39"></a>

39. **公乃固辞，以大将军让绍。** [[39]](#sg-note-39)

<a id="sg-event-40"></a>

40. **天子拜公司空，行车骑将军。** [[40]](#sg-note-40)

<a id="sg-event-41"></a>

41. **是岁用枣祗、韩浩等议。** 当年用枣祗、韩浩等议，始兴屯田。 [[41]](#sg-note-41)

<a id="sg-event-42"></a>

42. **吕布袭取下邳。** 吕布袭刘备，取下邳。 [[42]](#sg-note-42)

<a id="sg-event-43"></a>

43. **程昱说公曰“观刘备有雄才而甚得衆心”。** 程昱说公曰：「观刘备有雄才而甚得衆心，终不爲人下，不如早图之。」 [[43]](#sg-note-43)

<a id="sg-event-44"></a>

44. **公曰“方今收英雄时也”。** 公曰：「方今收英雄时也，杀一人而失天下之心，不可。」 [[44]](#sg-note-44)

<a id="sg-event-45"></a>

45. **济死，从子绣领其衆。** [[45]](#sg-note-45)

<a id="sg-event-46"></a>

46. **太祖击破黄巾。** 建安元年，太祖击破黄巾。 [[46]](#sg-note-46)

<a id="sg-event-47"></a>

47. **太祖定黄巾于许，遣使诣河东。** 建安元年，太祖定黄巾于许，派使诣河东。 [[47]](#sg-note-47)

<a id="sg-event-48"></a>

48. **吕布乘先主之出拒袁术。** 建安元年，吕布乘先主之出拒袁术，袭下邳，虏先主妻子。 [[48]](#sg-note-48)

<a id="sg-event-49"></a>

49. **孙策临郡，察齐孝廉。** 建安元年，孙策临郡，察齐孝廉。 [[49]](#sg-note-49)

### 41. 是岁用枣祗、韩浩等议

> 是歲用棗祗、韓浩等議，始興屯田。

<a id="wu-p-037-2"></a>

**[《三国志·武帝纪》裴注 037·2](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-037-2)**

> 公曰夫定國之術在於彊兵足食秦人以急農兼天下孝武以屯田定西域此先代之良式也是歲乃募民屯田許下得穀百萬斛

**释读** 曹操引秦以农战并天下、武帝以屯田定西域，主张足食强兵，当年在许招募百姓屯田，史称得谷百万斛。

**归年** 本纪L34与裴注“是歲”同指建安元年。引秦与汉武旧事是曹操训语，不当新造同名史事。

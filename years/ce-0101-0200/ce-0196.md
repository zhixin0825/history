## 本年概述

建安元年，献帝由安邑回到洛阳。宫室已毁，诸州军粮又不到，护驾诸将也争权。曹操此前派兵西迎受阻，后来亲到洛阳，录尚书事，继而迁帝都许。许都逐步恢复宗庙、社稷和朝廷官署，曹操同时经营汝颍及许下。

东边，袁术出兵攻刘备，吕布乘机袭取下邳。刘备一度借吕布之力迫使纪灵退兵，随后又与吕布交战，败投曹操。南阳张济战死，张绣据宛与刘表联合。孙策越过钱唐攻克会稽，王朗渡海退守东冶，仍被孙策追败。

1. **献帝离安邑还洛阳，诸将分掌兵权。** 正月癸酉，献帝在安邑郊祀上帝、大赦，改元建安。二月韩暹攻董承，董承奔张杨，张杨使他先修洛阳宫室。六月乙未，献帝到闻喜。七月甲子，张杨沿途送粮。董承、杨奉、韩暹等护帝到洛阳，暂居赵忠故宅。张杨认为朝中已有公卿，自己应在外御敌，遂还屯野王；杨奉别屯梁。丁丑郊祀大赦，己卯谒太庙，八月辛丑进驻南宫杨安殿，癸卯任张杨为大司马、韩暹为大将军、杨奉为车骑将军。洛阳宫室毁于兵火，百官在残垣间办公。诸州郡拥兵而粮运不到，尚书郎以下自行采集野谷，有人饿死，也有人被兵士杀害。 [[1]](#ce0196-note-1)

2. **曹操平汝颍黄巾，遣兵迎帝并与杨奉联系。** 正月，曹操军到武平，袁术所置的陈相袁嗣投降。曹操想迎天子，荀彧、程昱赞成，先遣曹洪西进，因董承和袁术部将苌奴据险而未能通过。二月，曹操讨汝南、颍川黄巾，屯兵版梁。于禁击退夜袭者，黄邵等被杀，何仪率众归降，于禁升平虏校尉。曹操经略淮、汝期间，许褚率部来投，曹操使他入宿卫，所带侠客编为虎士。献帝先授曹操建德将军，其后曹操迁镇东将军、封费亭侯，到八月已任镇东将军。曹操又派使到河东。他率军西迎天子，途经新郑时军中缺粮，县长杨沛献上储存的干桑椹。其间杨奉接触曹使，后来天子还洛、诸将失和，董昭衡量杨奉兵强而援弱，代曹操写信与之结纳。 [[2]](#ce0196-note-2)

3. **曹操入洛护驾，迁都许与重分军政权。** 献帝回到洛阳后，曹操议奉迎，诸将顾虑韩暹、杨奉在京、又与张杨相连。荀彧力主趁此护持朝廷、争取各方人才。韩暹与董承在洛阳屡起争执。徐晃劝杨奉归附曹操，杨奉起初想接受，后来反悔。曹操遂到洛阳护卫朝廷，韩暹出走。八月曹操领司隶校尉、录尚书事。曹操杀台崇、冯硕等，董承被封辅国将军，伏完等十三人为列侯，死事的沮儁获赠弘农太守。庚申迁都许，己巳献帝到曹操军营。杨奉从梁来截未及，十月曹操攻下梁屯，杨奉南奔袁术，徐晃归附曹操。迁许后重立宗庙、社稷。曹洪任谏议大夫，曹仁因军功拜广阳太守，仍留军中，以议郎身份督骑。九月杨彪、张喜罢职，曹操亦在此期间受大将军、武平侯之任。袁绍嫌太尉位在曹操之下而拒受，曹操辞大将军相让。十一月丙戌曹操为司空、行车骑将军事。 [[3]](#ce0196-note-3)

5. **曹操在许招纳辅佐，开始屯田。** 荀彧为侍中、守尚书令，向曹操推荐荀攸、钟繇；戏志才死后，曹操请荀彧举荐继任者。荀彧荐郭嘉，曹操召见论事后任他为司空军祭酒。曹操征荀攸，先授汝南太守，又召入为尚书，谈论后任为军师。赵俨见曹操迎帝都许，决定归附。丁冲在迁许后任司隶校尉。曹操任大将军时辟满宠为西曹属、许令。曹洪为犯法宾客求情，满宠先依法处死，曹操反而赏识他。韩浩建议把耕作列为急务。曹操在许下推行屯田，任任峻为典农中郎将、韩浩为护军。屯田起初拟按牛定额纳谷，枣祗主张按收成分谷，以免歉年负担过重，曹操采纳。此后数年各地仓廪渐实。 [[5]](#ce0196-note-5)

6. **吕布袭取下邳，刘备由海西、小沛转投曹操。** 袁术攻徐州，刘备令张飞守下邳，自赴盱眙、淮阴拒敌。其间曹操表授刘备镇东将军、宜城亭侯。吕布乘相持之机袭下邳，俘刘备妻儿与将吏家口。刘备回师而军溃，退到海西，糜竺把妹妹嫁给刘备，又以奴客、金银助军。刘备与吕布议和后屯小沛。袁术遣纪灵来攻，吕布担心袁术兼并刘备后联结泰山诸将，往沛西南调停，在营门射中戟支，纪灵、刘备遂罢兵。刘备重新聚兵后又遭吕布攻击，战败投曹操。曹操不采程昱处置刘备之议，给以兵粮并遣回小沛，任他为豫州牧。吕布逼曾受刘备举荐的袁涣写信骂刘备。袁涣说，若今日可以辱骂旧主，他日也可以这样辱骂吕布。吕布惭愧而作罢。吕布占徐州后还征召正在辅佐孙策的张纮。张纮不愿应召，孙策也答书拒绝遣送。 [[6]](#ce0196-note-6)

7. **袁术联络吕布，郝萌在下邳夜叛。** 袁术想联结吕布，为儿子求娶吕布的女儿，吕布答允；同在此年，袁术延请张范，张范称病，遣弟张承相见。袁术以齐桓公、汉高祖自比，张承说成事在德，轻率僭号只会失去人心。六月，郝萌夜攻吕布在下邳的府署，吕布携妻逃到高顺营中。高顺辨出叛军，发兵射退。曹性倒戈并砍伤郝萌，高顺斩郝萌。曹性供称袁术主使、陈宫同谋，吕布没有追究。曹性养好伤后接领郝萌旧部。 [[7]](#ce0196-note-7)

8. **青州孔融兵败，郑玄还高密。** 袁谭先逐田楷，随后向东围攻孔融，自春至夏。孔融在围中仍读书谈论，城陷后逃出，妻儿被俘；孔融随后为许都所征。本年郑玄从徐州回高密，途中遇黄巾，众人敬其名望，拜见并相约不进高密县境；这是青州一带的另一件事。 [[8]](#ce0196-note-8)

9. **张济战死，张绣据宛联刘表。** 张济军中乏粮，由关中攻南阳穰城，中箭死，刘表遣人吊丧、招纳余众。张济侄儿张绣领其部屯宛，与刘表联合。贾诩认为段煨猜疑自己，离段煨投张绣，家属仍受段煨妥善安置。他劝张绣与刘表结盟，又南下拜见刘表，认为刘表可做太平时的三公，遇事却易迟疑。 [[9]](#ce0196-note-9)

10. **孙策攻克会稽，追破王朗于东冶。** 吴景建议先击据吴地的严白虎等，孙策决意先取会稽，与孙静会于钱唐。功曹虞翻劝王朗避战，王朗不从，据固陵抵抗。孙策几次渡水进攻未克。孙静建议绕行查渎，孙策下令张火迷惑王朗，分兵夜袭高迁，击斩周昕，夺得会稽。王朗败后由虞翻护送，渡海走东冶。候官长起初闭城，经虞翻劝说才接纳王朗。候官长商升又为王朗起兵。孙策让永宁长韩晏领南部都尉讨商升，改任贺齐为永宁长。王朗打算投奔交州，虞翻劝他留下。王朗再被孙策追破，往见后受责而免死。虞翻应王朗之意，回乡奉养老母。孙策入会稽，余姚人董袭在高迁亭迎接，被任为门下贼曹。孙策领会稽太守，任程普为吴郡都尉，治钱唐，署周泰为别部司马并授兵，又察贺齐为孝廉。胡综十四岁时在孙策府中任门下循行，留在吴地与孙权一起读书。孙策任十五岁的孙权为阳羡长，朱治举孙权为孝廉。孙河也参加了平定吴、会稽的战事。孙策表任孙静为奋武校尉，孙静请求留乡镇守。孙策也让虞翻继续任功曹，亲自到他家中，以友礼相待。虞翻劝孙策慎于轻装出猎，以免随从来不及护卫。 [[10]](#ce0196-note-10)

> 建安元年，楊奉、董承、韓暹挾天子還舊京，糧乏。楊以糧迎道路，遂至洛陽。謂諸將曰：「天子當與天下共之，幸有公卿大臣，楊當捍外難，何事京都？」遂還野王。即拜爲大司馬。

**釋讀與歸年** 张杨沿路送粮迎接还洛阳的献帝，向诸将陈明自己应在外御敌，旋还野王。[《后汉书·献帝纪》](../../史书/003-后汉书/后汉书-CCDH.txt#L1245-L1246)记七月甲子车驾至洛，八月癸卯张杨任大司马；[《资治通鉴》卷62](../../史书/025-资治通鉴/KR2b0007_062.txt#L42-L50)也记迎驾、命殿名杨安和还野王。195年安邑供粮是前一事。

> 諸將不能相率，上下亂，糧食盡。奉、暹、承乃以天子還洛陽。出箕關，下軹道，張楊以食迎道路，拜大司馬。語在楊傳。天子入洛陽，宮室燒盡，街陌荒蕪，百官披荊棘，依丘牆間。州郡各擁兵自爲，莫有至者。饑窮稍甚，尚書郎以下自出樵采，或饑死牆壁閒。

**釋讀與歸年** 诸将争权又缺粮，杨奉、韩暹、董承护送献帝经箕关、轵道回洛阳，张杨供应粮食，拜大司马。[《张杨传》](../../拆分史书/三国志/卷008.txt#L74)系建安元年；[《后汉书·献帝纪》](../../史书/003-后汉书/后汉书-CCDH.txt#L1244-L1246)载六月至闻喜、七月甲子抵洛、八月癸卯拜张杨大司马，入洛后官员无粮自采。

> 英雄記曰：布初入徐州，書與袁術。術報書曰：「昔董卓作亂，破壞王室，禍害術門戶，術舉兵關東，未能屠裂卓。將軍誅卓，送其頭首，爲術掃滅讐耻，使術明目於當世，死生不愧，其功一也。昔將金元休向兖州，甫詣封部，爲曹操逆所拒破，流離迸走，幾至滅亡。將軍破兖州，術復明目於遐邇，其功二也。術生年已來，不聞天下有劉備，備乃舉兵與術對戰；術憑將軍威靈，得以破備，其功三也。將軍有三大功在術，術雖不敏，奉以生死。將軍連年攻戰，軍糧苦少，今送米二十萬斛，迎逢道路，非直此止，當駱驛復致；若兵器戰具，佗所乏少，大小唯命。」布得書大喜，遂造下邳。

**釋讀與歸年** 《英雄记》全录袁术复书，称诛董卓、破兖州、助袁术攻刘备为三功，以二十万斛米及后续军资引吕布前往下邳；米数出自袁术信中，《后汉书》另记后来粮运不继。信中董卓被诛、金尚遭拒、张邈迎吕布是此前旧事。 [《后汉书·吕布传》](../../史书/003-后汉书/后汉书-CCDH.txt#L5396) · [《先主传》](../../拆分史书/三国志/卷032.txt#L24)

**[《三國志·呂布張邈臧洪傳》裴注](../../拆分史书/三国志/卷007.md#edition-wei007-l36-5)** · [TXT L36](../../拆分史书/三国志/卷007.txt#L36)

> 英雄記曰：布水陸東下，軍到下邳西四十里。備中郎將丹楊許耽夜遣司馬章誑來詣布，言「張益德與下邳相曹豹共爭，益德殺豹，城中大亂，不相信。丹楊兵有千人屯西白城門內，聞將軍來東，大小踊躍，如復更生。將軍兵向城西門，丹楊軍便開門內將軍矣」。布遂夜進，晨到城下。天明，丹楊兵悉開門內布兵。布於門上坐，步騎放火，大破益德兵，獲備妻子軍資及部曲將吏士家口。

**釋讀與歸年** 《英雄记》详许耽遣司马章诳夜报张飞杀曹豹，丹杨兵开西门纳吕布；吕布入城后纵兵放火，击破张飞，夺得刘备的家属、将吏家口及军资。《先主传》本传记曹豹暗中迎布，同书裴注引《英雄记》又说张飞欲杀曹豹、曹豹部众据营求援，曹豹死否及具体迎城者记法不同。 [《先主传》正文及裴注](../../拆分史书/三国志/卷032.txt#L24-L25)

> 術遣將紀靈等步騎三萬攻備，備求救於布。布諸將謂布曰：「將軍常欲殺備，今可假手於術。」布曰：「不然。術若破備，則北連太山諸將，吾爲在術圍中，不得不救也。」便嚴步兵千、騎二百，馳往赴備。靈等聞布至，皆斂兵不敢復攻。布於沛西南一里安屯，遣鈴下請靈等，靈等亦請布共飲食。布謂靈等曰：「玄德，布弟也。弟爲諸君所困，故來救之。布性不喜合鬬，但喜解鬬耳。」布令門候於營門中舉一隻戟，布言：「諸君觀布射戟小支，一發中者諸君當解去，不中可留決鬬。」布舉弓射戟，正中小支。諸將皆驚，言「將軍天威也」！明日復歡會，然後各罷。

**釋讀與歸年** 袁术派纪灵等攻刘备，吕布考虑袁术若吞并刘备将与泰山诸将相连，自率步骑往沛城西南斡旋，在营门射中戟的小支；次日再宴后各自罢兵。谋议、射戟约定和事后罢兵连续收录。《资治通鉴》列建安元年，具体日月无载。 [《后汉书·吕布传》](../../史书/003-后汉书/后汉书-CCDH.txt#L5397) · [《资治通鉴》卷六十二](../../史书/025-资治通鉴/KR2b0007_062.txt#L251-L267)

> 獻帝春秋曰：孫策率軍如閩、越討朗。朗泛舟浮海，欲走交州，爲兵所逼，遂詣軍降。策令使者詰朗曰：「問逆賊故會稽太守王朗：朗受國恩當官，云何不惟報德，而阻兵安忍？大軍征討，幸免梟夷，不自埽屏，復聚黨衆，屯住郡境。遠勞王誅，卒不悟順。捕得云降，庶以欺詐，用全首領，得爾與不，具以狀對。」朗稱禽虜，對使者曰：「朗以瑣才，誤竊朝私，受爵不讓，以遘罪網。前見征討，畏死苟免。因治人物，寄命須臾。又迫大兵，惶怖北引。從者疾患，死亡略盡。獨與老母共乘一欐，流矢始交，便棄欐就俘，稽顙自首於征役之中。朗惶惑不達，自稱降虜。緣前迷謬，被詰慙懼。朗愚淺駑怯，畏威自驚。又無良介，不早自歸。於破亡之中，然後委命下隷。身輕罪重，死有餘辜。申脰就鞅，蹴足入絆，叱咤聽聲，東西惟命。」
>
> **〔正文續〕**
> 雖流移窮困，朝不謀夕，而收卹親舊，分多割少，行義甚著。

**釋讀與歸年** 孙策取会稽，虞翻劝避，王朗认为有守土之责，出战不胜，浮海逃到东冶，又被追破，前往孙策军中。孙策诘责而不杀。[《资治通鉴》卷62](../../史书/025-资治通鉴/KR2b0007_062.txt#L148-L171)将交战列建安元年。

**釋讀與歸年** 《献帝春秋》另写王朗想逃往交州，因被追逼前往孙策军中，并录使者问辞与王朗答辞。王朗以俘虏自称，叙随从多亡及与母同乘逃难。两篇问答均照底本完整合引。

**釋讀與歸年** 王朗流离时身处窘境，仍分所有周济亲旧。传文附在东冶兵败、被拘之后，具体日期未载。

**歸年** 《資治通鑑》卷062將虞翻勸王朗避敵繫於建安元年。父喪與勸諫始末另有《翻別傳》所記異文。

<a id="sgz057-b-2714-3"></a>

<a id="wu057-l7-3"></a>

**[《三國志·虞陸張駱陸吾朱傳》正文](../../拆分史书/三国志/卷057.md#edition-wu057-l7-3)** · [TXT L7](../../拆分史书/三国志/卷057.txt#L7)

> 朗不能用，拒戰敗績，亡走浮海。翻追隨營護，到東部候官，候官長閉城不受，翻往說之，然後見納。

**釋讀** 王朗未採納勸告，拒戰敗走而浮海。虞翻追隨護送到東部候官，城長起初閉門，經虞翻勸說方予接納。

**歸年** 與《資治通鑑》卷062及《王朗傳》同為會稽戰敗後的南逃。《虞翻傳》的東部候官與他傳所稱東冶，可依《通鑑》卷062胡注互見。

<a id="sgz057-p-002-1"></a>

<a id="wu057-l8-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》裴注 002](../../拆分史书/三国志/卷057.md#edition-wu057-l8-1)** · [TXT L8](../../拆分史书/三国志/卷057.txt#L8)

> 吳書曰：翻始欲送朗到廣陵，朗惑王方平記，言「疾來邀我，南岳相求」，故遂南行。旣至候官，又欲投交州，翻諫朗曰：「此妄書耳，交州無南岳，安所投乎？」乃止。

**釋讀** 虞翻本想送王朗到廣陵，王朗因王方平的讖記決意南行。抵候官後，王朗又想去交州，虞翻指交州並無讖記中的南岳，王朗才打消此意。

**歸年** 《吳書》補王朗南行及不去交州的前後原因。《王朗傳》裴注《獻帝春秋》亦載王朗想去交州，歸降始末另有說法。

<a id="sgz057-b-2714-4"></a>

<a id="wu057-l9-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》正文](../../拆分史书/三国志/卷057.md#edition-wu057-l9-1)** · [TXT L9](../../拆分史书/三国志/卷057.txt#L9)

> 朗謂翻曰：「卿有老母，可以還矣。」

**釋讀** 王朗念及虞翻還有年老的母親，讓虞翻回鄉。

**歸年** 接上文王朗兵敗南走，卷062同敘。

<a id="sgz057-p-003-1"></a>

<a id="wu057-l10-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》裴注 003](../../拆分史书/三国志/卷057.md#edition-wu057-l10-1)** · [TXT L10](../../拆分史书/三国志/卷057.txt#L10)

> 翻別傳曰：朗使翻見豫章太守華歆，圖起義兵。翻未至豫章，聞孫策向會稽，翻乃還。會遭父喪，以臣使有節，不敢過家，星行追朗至候官。朗遣翻還，然後奔喪。而傳云孫策之來，翻衰絰詣府門，勸朗避策，則爲大異。

**釋讀** 《翻別傳》記，王朗差虞翻去見豫章太守華歆，謀起義兵。虞翻尚未到豫章，聞孫策進攻便回返。雖遇父喪，他以自己負有出使之責，未敢先回家，急行追至候官。王朗遣還，才回家奔喪。這與正文所記虞翻先著喪服勸王朗避戰不同。

**歸年** 異說附於同一場會稽攻守。王朗遣虞翻見華歆亦在這段回敘中，勿與199年虞翻替孫策說華歆混為一事。

<a id="sgz057-b-2714-5"></a>

<a id="wu057-l11-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》正文](../../拆分史书/三国志/卷057.md#edition-wu057-l11-1)** · [TXT L11](../../拆分史书/三国志/卷057.txt#L11)

> 翻旣歸，策復命爲功曹，待以交友之禮，身詣翻第。

**釋讀** 虞翻回來後，孫策又以他為功曹，以交友的禮相待，親至虞翻宅第。

**歸年** 《資治通鑑》卷062敘在孫策據會稽後。

<a id="sgz057-p-004-1"></a>

<a id="wu057-l12-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》裴注 004](../../拆分史书/三国志/卷057.md#edition-wu057-l12-1)** · [TXT L12](../../拆分史书/三国志/卷057.txt#L12)

> 江表傳曰：策書謂翻曰：「今日之事，當與卿共之，勿謂孫策作郡吏相待也。」

**釋讀** 孫策寫信說應與虞翻共處政事，以超越郡守、郡吏的交情相待。

**歸年** 《江表傳》為緊接正文的孫策原書，信書日月未見。

<a id="sgz057-b-2715-1"></a>

<a id="sgz057-b-2715-2"></a>

<a id="wu057-l14-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》正文](../../拆分史书/三国志/卷057.md#edition-wu057-l14-1)** · [TXT L14](../../拆分史书/三国志/卷057.txt#L14)

> 策好馳騁游獵，翻諫曰：「明府用烏集之衆，驅散附之士，皆得其死力，雖漢高帝不及也。至於輕出微行，從官不暇嚴，吏卒常苦之。夫君人者不重則不威，故白龍魚服，困於豫且，白蛇自放，劉季害之，願少留意。」策曰：「君言是也。然時有所思，端坐悒悒，有裨諶草創之計，是以行耳。」

**釋讀** 孫策喜馳騁游獵，虞翻先稱其能使新附士卒效死，繼而說他輕裝微行，隨從來不及戒備，以白龍化魚被豫且所困、白蛇遭劉邦所殺為喻，勸他持重。孫策說虞翻勸得對，但有時室內獨坐思緒鬱塞，想效法裨諶出野謀事。

**歸年** 《資治通鑑》卷062附於建安元年孫策任虞翻功曹之後，勸諫本身未紀月日。

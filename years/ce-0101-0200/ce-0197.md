<a id="hh-event-9"></a>

9. **献帝建安二年九月，汉水流，害民人。** [[9]](#hh-note-9)

<a id="sg-event-10"></a>

10. **张绣先降后叛，曹操败于宛城。** 二年春正月，公到宛。张绣降，旣而悔之，复反。公与战，军败，爲流矢所中，长子昂、弟子安民遇害。公乃引兵还舞阴，绣将骑来钞，公击破之。绣奔穰，与刘表合。公谓各将领曰：「吾降张绣等，失不便取其质，以至于此。吾知所以败。诸卿观之，自今已后不复败矣。」遂还许。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **布收其使，上其书。** [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **术怒，攻布。** 术怒，攻布，爲布所破。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **术侵陈，公东征之。** 秋九月，术侵陈，公东征之。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **术闻公自来，弃军走。** 术闻公自来，弃军走，留其将桥蕤、李丰、梁纲、乐就；公到，击破蕤等，皆斩之。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **术走渡淮。** [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **公之自舞阴还也，南阳、章陵诸县复叛爲绣。** 公之自舞阴还也，南阳、章陵诸县复叛爲绣，公遣曹洪击之，不利，还屯叶，数爲绣、表所侵。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **公自南征，至宛。** 冬十一月，公自南征，至宛。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **表将邓济据湖阳。** [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **攻拔之，生禽济。** 攻拔之，生禽济，湖阳降。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **攻舞阴，下之。** [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **赵俨任朗陵长。** 赵俨从荆州扶老携幼投曹操，出任朗陵长，治理豪强。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **夔将还乡里，度术必急追。** 建安二年，夔将还乡里，度术必急追，乃间行得免，明年到本郡。 [[22]](#sg-note-22)

<a id="wu-event-23"></a>

23. **裴松之举杨彪下狱反驳曹操。** 裴松之指出，杨彪实际曾被曹操逼迫，险些被害。 [[23]](#wu-note-23)

<a id="sgz-event-24"></a>

24. **吕布得拜左将军，陈登入许都。** 陈珪想派陈登拜见曹操，起初吕布不同意，等曹操派来使者、授吕布左将军，吕布才准陈登入许并奉章谢恩。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **陈登赴许都受曹操委任。** 陈登面见曹操，称吕布勇而无谋、去就不定，宜早图之；曹操称陈登能察实情，增陈珪之秩，授陈登广陵太守。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **袁术杀拒受伪命的金尚。** 袁术僭号后暗劝金尚做太尉，金尚没有屈服；袁术起初不敢强迫，金尚逃离时被袁术杀害。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **金尚灵柩抵京并获诏吊祭。** 金尚灵柩与太傅马日磾之丧俱至京，献帝褒其忠烈，诏百官吊祭、拜其子金玮为郎中；马日磾没有受到同样礼遇。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **吕布、韩暹和杨奉进军钟离。** 吕布联合二军水陆趋寿春，到钟离掳掠后渡淮北，留信讥袁术。袁术率五千步骑在淮上张势，吕布骑兵隔岸笑而引回。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **萧建据莒，臧霸攻破莒城。** 琅邪相萧建守莒，不来往于吕布；吕布来书自述诛董、光复京师之志，以乐毅田单旧事劝通，萧建遣主簿奉笺献马五匹。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **杨奉、韩暹之死。** 韩暹、杨奉在徐、扬间劫掠，本传合称两人被刘备杀。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **郭汜被部将杀。** 郭汜遭部将五习突袭，死于郿。 [[31]](#sgz-note-31)

<a id="sgz-event-32"></a>

32. **《英雄记》分述杨奉、韩暹遇害。** 刘备诱杨奉赴会而执之，韩暹返并州途中为杼秋屯帅张宣截杀。 [[32]](#sgz-note-32)

<a id="sgz-event-33"></a>

33. **袁绍致书傲慢，荀彧为曹操分析四胜。** 袁绍因此更加骄慢，给曹操的信语多无礼。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **荀彧劝曹操先取吕布。** 曹操喜荀彧之言，荀彧又劝不先除吕布便难谋河北。 [[34]](#sgz-note-34)

<a id="sgz-event-35"></a>

35. **荀彧荐钟繇安抚关中。** 曹操赞同先取，但忧袁绍侵扰关中、惑羌胡、结蜀汉，使自己独据兖豫而敌众。 [[35]](#sgz-note-35)

**释读** 《典略》载袁术认为己出舜后、以土承火，并以名字应代汉者当涂高，建立仲氏年号或国号。

**释读** 孙策劝阻不果，断江津并通知吴景，吴景弃广陵后再任丹杨太守。

**归年** 《后汉书·献帝纪》建安二年袁术称帝；吴景回任为其后同组事。

### 10. 张绣先降后叛，曹操败于宛城

[返回正文第10条](#sg-event-10)

<a id="sg001-l37-e10"></a>

**[《三国志·武帝纪》](../../sources/摘录/三国志-卷001-武帝纪.md#p004)** · [仓内TXT L37](../../sources/本地分卷/三国志/三国志-卷001.md#l37)

> 二年春正月，公到宛。張繡降，旣而悔之，復反。公與戰，軍敗，爲流矢所中，長子昂、弟子安民遇害。公乃引兵還舞陰，繡將騎來鈔，公擊破之。繡奔穰，與劉表合。公謂諸將曰：「吾降張繡等，失不便取其質，以至於此。吾知所以敗。諸卿觀之，自今已後不復敗矣。」遂還許。

<a id="sg008-l435-e10"></a>

**[《三国志·二公孙陶四张传》](../../sources/摘录/三国志-卷008-二公孙陶四张传.md#p006)** · [仓内TXT L435](../../sources/本地分卷/三国志/三国志-卷008.md#l435)

> 計漏，繡掩襲太祖。太祖軍敗，二子沒。

**归年与互校** 《武帝纪》记建安二年春正月；本传所叙起因并列。

<a id="wu-b-037-1"></a>

**[《三国志·武帝纪》仓内原文 L37](../../sources/本地分卷/三国志/三国志-卷001.md#l37)**

> 二年春正月，公到宛。

**释读** 春正月，曹操率军到达宛城。

**归年** 本纪明记建安二年春正月。

<a id="wu-b-037-2"></a>

**[《三国志·武帝纪》仓内原文 L37](../../sources/本地分卷/三国志/三国志-卷001.md#l37)**

> 張繡降，旣而悔之，復反。公與戰，軍敗，爲流矢所中，長子昂、弟子安民遇害。

**释读** 张绣先降又反，曹军战败，曹操中箭，长子曹昂、侄子曹安民遇害。

**归年** 本纪建安二年正月，卷008《张绣传》、卷018《典韦传》及《资治通鉴》卷062互参。

<a id="wu-b-037-3"></a>

**[《三国志·武帝纪》仓内原文 L37](../../sources/本地分卷/三国志/三国志-卷001.md#l37)**

> 公乃引兵還舞陰，繡將騎來鈔，公擊破之。繡奔穰，與劉表合。

**释读** 曹操引兵退到舞阴，击退张绣追骑；张绣奔穰，与刘表合兵。

**归年** 同年第一次讨张绣败后，区别于是年冬再取舞阴。

> 公謂諸將曰：「吾降張繡等，失不便取其質，以至於此。吾知所以敗。諸卿觀之，自今已後不復敗矣。」遂還許。

**释读** 曹操告诉诸将，未及时要张绣交出人质导致战败，并说以后不会再犯；随后回许。

**归年** 紧接建安二年初宛城、舞阴之战。

> 魏書曰公所乘馬名絶影為流矢所中傷頰及足幷中公右臂世語曰昻不能騎進馬於公公故免而昻遇害

**释读** 《魏书》说战马绝影面颊及足中箭，曹操右臂也中箭；《世语》说曹昂把马交给曹操，曹操脱险，曹昂死于战中。

### 33. 袁绍致书傲慢，荀彧为曹操分析四胜

[返回正文第33条](#sgz-event-33)

<a id="sgz010-b-507-4"></a>

**[《三国志·二荀贾传》仓内原文 L507](../../sources/本地分卷/三国志/三国志-卷010.md#l507)**

> 紹益驕，與太祖書，其辭悖慢。

**归年** 通鉴卷062 L336–370紧随建安二年张绣败曹操。

<a id="sgz010-b-507-5"></a>

**[《三国志·二荀贾传》仓内原文 L507](../../sources/本地分卷/三国志/三国志-卷010.md#l507)**

> 太祖大怒，出入動靜變於常，衆皆謂以失利於張繡故也。鍾繇以問彧，彧曰：「公之聦明，必不追咎往事，殆有他慮。」

**释读** 曹操怒而形于外，众人以为因张绣败。钟繇问荀彧，荀彧说曹操不会追究既往，应该另有顾虑。

**归年** 与同次袁绍书、曹操议形势相连。

<a id="sgz010-b-507-6"></a>

**[《三国志·二荀贾传》仓内原文 L507](../../sources/本地分卷/三国志/三国志-卷010.md#l507)**

> 則見太祖問之，太祖乃以紹書示彧，曰：「今將討不義，而力不敵，何如？」

**释读** 荀彧问曹操，曹操出示袁绍的信，问打不义而实力不敌怎么办。

**归年** 通鉴卷062建安二年同次。

<a id="sgz010-b-507-7"></a>

**[《三国志·二荀贾传》仓内原文 L507](../../sources/本地分卷/三国志/三国志-卷010.md#l507)**

> 彧曰：「古之成敗者，誠有其才，雖弱必彊，苟非其人，雖彊易弱，劉、項之存亡，足以觀矣。今與公爭天下者，唯袁紹爾。紹貌外寬而內忌，任人而疑其心，公明達不拘，唯才所宜，此度勝也。

**释读** 荀彧以刘邦项羽兴亡为比，说人才使弱能强；袁绍貌宽内忌，曹操善任不疑，胜于气度。

**归年** 197年对话，通鉴卷062另综合荀彧郭嘉列十胜。

<a id="sgz010-b-507-8"></a>

**[《三国志·二荀贾传》仓内原文 L507](../../sources/本地分卷/三国志/三国志-卷010.md#l507)**

> 紹遲重少決，失在後機，公能斷大事，應變無方，此謀勝也。紹御軍寬緩，法令不立，士卒雖衆，其實難用，公法令旣明，賞罰必行，士卒雖寡，皆爭致死，此武勝也。

**释读** 袁迟疑而误时，曹善决断；袁军法弛，曹军赏罚有序且士肯死，曹智谋和军事两胜。

**归年** 同次四胜之论。

<a id="sgz010-b-507-9"></a>

**[《三国志·二荀贾传》仓内原文 L507](../../sources/本地分卷/三国志/三国志-卷010.md#l507)**

> 紹憑世資，從容飾智，以收名譽，故士之寡能好問者多歸之，公以至仁待人，推誠心不爲虛美，行己謹儉，而與有功者無所恡惜，故天下忠正效實之士咸願爲用，此德勝也。夫以四勝輔天子，扶義征伐，誰敢不從？紹之彊其何能爲！」

**释读** 袁靠家世修饰声名，而曹操待人真诚、俭而赏功，士愿归，是德胜。凭四胜扶天子征伐足以压服袁绍。

**归年** 同次197年说四胜。

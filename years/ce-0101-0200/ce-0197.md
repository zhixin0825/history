<a id="hh-event-1"></a>

1. **袁术僭号，孙策劝止未果后与之断绝。** 春，袁术在淮南称帝。孙策曾在袁术称帝前致书相劝，袁术未听。孙策于是责备袁术，与他断绝往来。吴景等也离开袁术，回归孙策。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **袁绍自为大将军。** 三月，袁绍自为大将军。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **蝗。** 夏五月，蝗。 [[3]](#hh-note-3)

<a id="hh-event-9"></a>

<a id="hh-event-4"></a>

4. **汉水溢。** 秋九月，汉水溢。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **是岁饥，江淮间民相食。** 当年饥，江淮间民相食。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **袁术杀陈王宠。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **孙策派刘由、高承赴许献贡，汉廷遣王誧授官。** 孙策派奉正都尉刘由、五官掾高承到许都奉章、进献方物。夏，汉廷遣议郎王誧持诏，追念孙坚讨董卓的功劳，授孙策骑都尉、袭乌程侯、领会稽太守。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **追杨氏前功，封蓩亭侯。** 朝廷在献帝建安二年追及杨震旧功施封。 [[8]](#hh-note-8)

<a id="sg-event-10"></a>

10. **张绣先降后叛，曹操败于宛城。** 二年春正月，公到宛。张绣降，旣而悔之，复反。公与战，军败，爲流矢所中，长子昂、弟子安民遇害。公乃引兵还舞阴，绣将骑来钞，公击破之。绣奔穰，与刘表合。公谓各将领曰：「吾降张绣等，失不便取其质，以至于此。吾知所以败。诸卿观之，自今已后不复败矣。」遂还许。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **布收其使，上其书。** [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **术怒，攻布。** 术怒，攻布，爲布所破。 [[12]](#sg-note-12)

<a id="sg-event-15"></a>

13. **曹操到陈击败袁术，袁术渡淮退走。** 九月，袁术侵陈，曹操出军。袁术渡淮，留桥蕤等拒敌；曹操击破并斩其将。 [[13]](#sg-note-13)

<a id="sg-event-16"></a>

16. **公之自舞阴还也，南阳、章陵诸县复叛爲绣。** 公之自舞阴还也，南阳、章陵诸县复叛爲绣，公遣曹洪击之，不利，还屯叶，数爲绣、表所侵。 [[16]](#sg-note-16)

<a id="sg-event-18"></a>

<a id="sg-event-19"></a>

<a id="sg-event-20"></a>

<a id="sg-event-17"></a>

17. **曹操再征张绣，取湖阳与舞阴。** 曹操冬季向宛进兵，随后取湖阳，擒刘表将邓济，再攻下舞阴。这次出兵与春季曹操在宛被张绣袭击是两次战事。 [[17]](#sg-note-17)

<a id="sg-event-21"></a>

21. **赵俨任朗陵长。** 赵俨从荆州扶老携幼投曹操，出任朗陵长，治理豪强。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **夔将还乡里，度术必急追。** 建安二年，夔将还乡里，度术必急追，乃间行得免，明年到本郡。 [[22]](#sg-note-22)

<a id="wu-event-23"></a>

23. **裴松之举杨彪下狱反驳曹操。** 裴松之指出，杨彪实际曾被曹操逼迫，险些被害。 [[23]](#wu-note-23)

<a id="sgz-event-25"></a>

<a id="sgz-event-24"></a>

24. **吕布得拜左将军，陈登入许都。** 陈珪想派陈登拜见曹操，起初吕布不同意，等曹操派来使者、授吕布左将军，吕布才准陈登入许并奉章谢恩。 [[24]](#sgz-note-24)

<a id="sgz-event-26"></a>

26. **袁术杀拒受伪命的金尚。** 袁术僭号后暗劝金尚做太尉，金尚没有屈服；袁术起初不敢强迫，金尚逃离时被袁术杀害。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **金尚灵柩抵京并获诏吊祭。** 金尚灵柩与太傅马日磾之丧俱至京，献帝褒其忠烈，诏百官吊祭、拜其子金玮为郎中；马日磾没有受到同样礼遇。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **吕布、韩暹和杨奉进军钟离。** 吕布联合二军水陆趋寿春，到钟离掳掠后渡淮北，留信讥袁术。袁术率五千步骑在淮上张势，吕布骑兵隔岸笑而引回。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **萧建据莒，臧霸攻破莒城。** 琅邪相萧建守莒，不来往于吕布；吕布来书自述诛董、光复京师之志，以乐毅田单旧事劝通，萧建遣主簿奉笺献马五匹。 [[29]](#sgz-note-29)

<a id="sgz-event-32"></a>

<a id="sgz-event-30"></a>

30. **杨奉、韩暹先后被杀。** 两人先后遇害。《董卓传》合称刘备所杀，《英雄记》分记刘备诱杨奉赴会、张宣截杀韩暹。《通鉴》取分记。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **郭汜被部将杀。** 郭汜遭部将五习突袭，死于郿。 [[31]](#sgz-note-31)

<a id="sgz-event-33"></a>

33. **袁绍致书傲慢，荀彧为曹操分析四胜。** 袁绍因此更加骄慢，给曹操的信语多无礼。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **荀彧劝曹操先取吕布。** 曹操喜荀彧之言，荀彧又劝不先除吕布便难谋河北。 [[34]](#sgz-note-34)

<a id="sgz-event-35"></a>

35. **荀彧荐钟繇安抚关中。** 曹操赞同先取，但忧袁绍侵扰关中、惑羌胡、结蜀汉，使自己独据兖豫而敌众。 [[35]](#sgz-note-35)

<a id="sgz-event-36"></a>

36. **朝廷令孙策、吕布、陈瑀合击袁术。** 诏谴袁术伪造符命、私建宫署、僭行郊祀，说吕布告知详情，令孙策协同吕布、陈瑀进兵。 [[36]](#sgz-note-36)

<a id="sgz-event-37"></a>

37. **王誧承制假孙策明汉将军。** 孙策自认为领众仅得骑都尉太轻，请王誧承制给明汉将军之号。 [[37]](#sgz-note-37)

<a id="sgz-event-39"></a>

<a id="sgz-event-38"></a>

38. **孙策遣吕范、徐逸在海西击败陈瑀。** 屯海西的陈瑀联络祖郎、严白虎为内应，准备趁孙策奉诏发兵讨袁术时袭取诸郡。孙策遣吕范、徐逸攻破陈瑀，斩其将陈牧。 [[38]](#sgz-note-38)

<a id="sgz-event-40"></a>

40. **《献帝春秋》称诸葛玄被西城人杀。** 西城居民反，杀诸葛玄，送首刘繇。 [[40]](#sgz-note-40)

<a id="sgz-event-41"></a>

41. **郭嘉劝乘袁绍北击公孙瓒先取吕布。** 郭嘉提醒乘袁绍远征先除吕布，否则二者可能相援，曹操赞同。 [[41]](#sgz-note-41)

<a id="sgz-event-42"></a>

42. **李通支持赵俨依法处置其妻伯父。** 李通妻伯父触法，赵俨据律定罪，李通同意不徇私情。 [[42]](#sgz-note-42)

> 又袁術僣號於九江下皆稱臣名門曰建號門衣被皆為天子之制兩婦預爭為皇后志計已定人有勸術使遂即帝位露布天下答言曹公尚在未可也

<a id="sgz006-p-074-1"></a>

**[《三国志·董二袁刘传》裴注 074·1](../../sources/本地分卷/三国志/三国志-卷006.md#pei-074-1)**

> 典畧曰術以袁姓出陳陳舜之後以土承火得應運之次又見䜟文云代漢者當塗高也自以名字當之乃建號稱仲氏

**释读** 《典略》载袁术认为己出舜后、以土承火，并以名字应代汉者当涂高，建立仲氏年号或国号。

**归年** 《孝献帝纪》建安二年袁术称帝；仲氏原字保留。

**释读** 孙策劝阻不果，断江津并通知吴景，吴景弃广陵后再任丹杨太守。

**释读** 孙策遣孙贲、吴景到寿春报信，逢袁术僭号任置百官，孙贲拒九江太守命，舍妻儿还江南。

**释读** 孙策写信问宗亲去就，吴景弃守回孙策处，孙贲也脱离袁术，孙香因路远未能回。

<a id="sgz046-p-029-1"></a>

**[《三國志·孫破虜討逆傳》 裴注 029·1](../../sources/本地分卷/三国志/三国志-卷046.md#pei-029-1)** · [TXT L75](../../sources/本地分卷/三国志/三国志-卷046.txt#L75)

> 吳錄載策使張紘爲書曰：「蓋上天垂司過之星，聖王建敢諫之鼓，設非謬之備，急箴闕之言，何哉？凡有所長，必有所短也。去冬傳有大計，無不悚懼；旋知供備貢獻，萬夫解惑。頃聞建議，復欲追遵前圖，即事之期，便有定月。益使憮然，想是流妄；設其必爾，民何望乎？

**释读** 书以劝谏为古圣先王所设，说听到袁术再拟称尊便使人忧惧。

**归年** 《孙策传》建安二年责袁术并绝交，同一书。

<a id="sgz046-p-029-2"></a>

**[《三國志·孫破虜討逆傳》 裴注 029·2](../../sources/本地分卷/三国志/三国志-卷046.md#pei-029-2)** · [TXT L75](../../sources/本地分卷/三国志/三国志-卷046.txt#L75)

> 曩日之舉義兵也，天下之士所以響應者，董卓擅廢置，害太后、弘農王，略烝宮人，發掘園陵，暴逆至此，故諸州郡雄豪聞聲慕義。神武外振，卓遂內殲。元惡旣斃，幼主東顧，俾保傅宣命，欲令諸軍振旅，然河北通謀黑山，曹操放毒東徐，劉表稱亂南荊，公孫瓚炰烋北幽，劉繇決力江滸，劉備爭盟淮隅，是以未獲承命櫜弓戢戈也。今備、繇旣破，操等饑餒，謂當與天下合謀，以誅醜類。捨而不圖，有自取之志，非海內所望，一也。

**释读** 回顾董卓废立、杀何太后与弘农王、掘陵和关东讨董；又叙列诸方互斗，主张同谋讨乱，不宜为己夺天下。

**归年** 建安二年书信以早期史事立论；189至192旧事见各年，所指不混于同年。

**校讀** 新底本作「然河北通謀黑山，曹操放毒東徐」，指各地仍有戰亂、諸軍未能收兵。四庫本另有「振旅於河北」「東齊」之文。

<a id="sgz046-p-029-3"></a>

**[《三國志·孫破虜討逆傳》 裴注 029·3](../../sources/本地分卷/三国志/三国志-卷046.md#pei-029-3)** · [TXT L75](../../sources/本地分卷/三国志/三国志-卷046.txt#L75)

> 昔成湯伐桀，稱有夏多罪；武王伐紂，曰殷有罪罰重哉。此二王者，雖有聖德，宜當君世；如使不遭其時，亦無由興矣。幼主非有惡於天下，徒以春秋尚少，脅於彊臣，若無過而奪之，懼未合於湯、武之事，二也。卓雖狂狡，至廢主自與，亦猶未也，而天下聞其桀虐，攘臂同心而疾之，以中土希戰之兵，當邊地勁悍之虜，所以斯須游魂也。今四方之人，皆玩敵而便戰鬬矣，可得而勝者，以彼亂而我治，彼逆而我順也。見當世之紛若，欲大舉以臨之，適足趣禍，三也。

**释读** 以汤武有时有德为比，说天子年少受胁，不能为此便夺位；又预判无须因他方战乱而贸然用兵。

**归年** 劝袁术的同一信札。

**[《三國志·孫破虜討逆傳》 裴注 029·4](../../sources/本地分卷/三国志/三国志-卷046.md#pei-029-4)** · [TXT L75](../../sources/本地分卷/三国志/三国志-卷046.txt#L75)

> 天下神器，不可虛干，必須天贊與人力也。殷湯有白鳩之祥，周武有赤烏之瑞，漢高有星聚之符，世祖有神光之徵，皆因民困瘁於桀、紂之政，毒苦於秦、莽之役，故能芟去無道，致成其志。今天下非患於幼主，未見受命之應驗，而欲一旦卒然登即尊號，未之或有，四也。天子之貴，四海之富，誰不欲焉？義不可，勢不得耳。陳勝、項籍、王莽、公孫述之徒，皆南面稱孤，莫之能濟。帝王之位，不可橫兾，五也。幼主岐嶷，若除其偪，去其鯁，必成中興之業。夫致主於周成之盛，自受旦、奭之美，此誠所望於尊明也。縱使幼主有他改異，猶望推宗室之譜屬，論近親之賢良，以紹劉統，以固漢宗。皆所以書功金石，圖形丹青，流慶無窮，垂聲管弦。捨而不爲，爲其難者，想明明之素，必所不忍，六也。五世爲相，權之重，勢之盛，天下莫得而比焉。忠貞者必曰宜夙夜思惟，所以扶國家之躓頓，念社稷之危殆，以奉祖考之志，以報漢室之恩。其忽履道之節而彊進取之欲者，將曰天下之人非家吏則門生也，孰不從我？四方之敵非吾匹則吾役也，誰能違我？盍乘累世之勢，起而取之哉？二者殊數，不可不詳察，七也。所貴於聖哲者，以其審於機宜，慎於舉措。若難圖之事，難保之勢，以激羣敵之氣，以生衆人之心，公義故不可，私計又不利，明哲不處，八也。世人多惑於圖緯而牽非類，比合文字以恱所事，苟以阿上惑衆，終有後悔者，自往迄今，未嘗無之，不可不深擇而熟思，九也。九者，尊明所見之餘耳，庶備起予，補所遺忘。忠言逆耳，幸留神聽！」

**释读** 荀彧以刘邦项羽兴亡为比，说人才使弱能强；袁绍貌宽内忌，曹操善任不疑，胜于气度。

<a id="sgz010-b-507-8"></a>

> 紹遲重少決，失在後機，公能斷大事，應變無方，此謀勝也。紹御軍寬緩，法令不立，士卒雖衆，其實難用，公法令旣明，賞罰必行，士卒雖寡，皆爭致死，此武勝也。

**释读** 袁迟疑而误时，曹善决断；袁军法弛，曹军赏罚有序且士肯死，曹智谋和军事两胜。

**归年** 同次四胜之论。

<a id="sgz010-b-507-9"></a>

**[《三国志·二荀贾传》仓内原文 L507](../../sources/本地分卷/三国志/三国志-卷010.md#l507)**

> 紹憑世資，從容飾智，以收名譽，故士之寡能好問者多歸之，公以至仁待人，推誠心不爲虛美，行己謹儉，而與有功者無所恡惜，故天下忠正效實之士咸願爲用，此德勝也。夫以四勝輔天子，扶義征伐，誰敢不從？紹之彊其何能爲！」

**释读** 袁靠家世修饰声名，而曹操待人真诚、俭而赏功，士愿归，是德胜。凭四胜扶天子征伐足以压服袁绍。

**归年** 同次197年说四胜。

<a id="sgz014-b-695-1"></a>

**[《三国志·程郭董刘蒋刘传》仓内原文 L695](../../sources/本地分卷/三国志/三国志-卷014.md#l695)**

> 劉、項之不敵，公所知也。漢祖唯智勝；項羽雖強，終為所禽。嘉竊料之，紹有十敗，公有十勝，雖兵強，無能為也。紹繁禮多儀，公體任自然，此道勝一也。紹以逆動，公奉順以率天下，此義勝二也。漢末政失於寬，紹以寬濟寬，故不攝，公糾之以猛而上下知制，此治勝三也。紹外寬內忌，用人而疑之，所任唯親戚子弟，公外易簡而內機明，用人無疑，唯才所宜，不間遠近，此度勝四也。紹多謀少決，失在後事，公策得輒行，應變無窮，此謀勝五也。紹因累世之資，高議揖讓以收名譽，士之好言飾外者多歸之，公以至心待人，推誠而行，不為虛美，以儉率下，與有功者無所吝，士之忠正遠見而有實者皆原為用，此德勝六也。紹見人飢寒，卹念之形於顏色，其所不見，慮或不及也，所謂婦人之仁耳，公於目前小事，時有所忽，至於大事，與四海接，恩之所加，皆過其望，雖所不見，慮之所周，無不濟也，此仁勝七也。紹大臣爭權，讒言惑亂，公禦下以道，浸潤不行，此明勝八也。紹是非不可知，公所是進之以禮，所不是正之以法，此文勝九也。紹好為虛勢，不知兵要，公以少克眾，用兵如神，軍人恃之，敵人畏之，此武勝十也。

**释读** 郭嘉比曹袁如刘项，列自然、不逆、治军、用人、决断、诚信、广济、御谗、文法、军事十端。

**归年** TXT此段为混入《傅子》裴注的节录，完整见校注；《资治通鉴》卷六十二建安二年通行系年。袁绍致书时荀彧另有“四胜”，人名、论目须各据原文。

<a id="sgz014-p-009-1"></a>

**[《三国志·程郭董刘蒋刘传》裴注 009·1](../../sources/本地分卷/三国志/三国志-卷014.md#pei-009-1)**

> 傅子曰太祖謂嘉曰本初擁冀州之衆靑并從之地廣兵彊而數為不遜吾欲討之力不敵如何對曰劉項之不敵公所知也漢祖唯智勝項羽雖彊終為所禽嘉竊料之紹有十敗公有十勝雖兵彊無能為也紹繁禮多儀公體任自然此道勝一也紹以逆動公奉順以率天下此義勝二也漢末政失於寛紹以寛濟寛故不懾公紏之以猛而上下知制此治勝三也紹外寛内忌用人而疑之所任唯親戚子弟公外易簡而内機明用人無疑唯才所宜不問遠近此度勝四也紹多謀少决失在後事公䇿得輒行應變無窮此謀勝五也紹因累世之資髙議揖讓以收名譽士之好言飾外者多歸之公以至心待人推誠而行不為虚美以儉率下與有功者無所吝士之忠正遠見而有實者皆願為用此徳勝六也紹見人飢寒恤念之形於顔色其所不見慮或不及也所謂婦人之仁耳公於目前小事時有所忽至於大事與四海接恩之所加皆過其望雖所不見慮之所周無不濟也此仁勝七也紹大臣争權䜛言惑亂公御下以道浸潤不行此明勝八也紹是非不可知公所是進之以禮所不是正之以法此文勝九也紹好為虚勢不知兵要公以少克衆用兵如神軍人恃之敵人畏之此武勝十也太祖笑曰如卿所言孤何徳以堪之也

**释读** 曹操问以弱对袁绍，郭嘉以道、义、治、度、谋、德、仁、明、文、武逐项论曹胜袁败，曹操谦称担当不起。

**归年** 《资治通鉴》卷六十二建安二年系袁绍致书、荀彧四胜及此十胜。TXT部分文字重复见卷十四正文栏，应挂同事件。

> 山陽公載記曰：瑀單騎走兾州，自歸袁紹，紹以爲故安都尉。

**释读** 陈瑀独骑走冀州，依袁绍，为故安都尉。

**归年** 承前建安二年海西败，受官月日未记。

### 42. 李通支持赵俨依法处置其妻伯父

[返回正文第42条](#sgz-event-42)

<a id="sgz018-b-905-4"></a>

**[《三国志·二李臧文吕许典二庞阎传》仓内原文 L905](../../sources/本地分卷/三国志/三国志-卷018.md#l905)**

> 通妻伯父犯法，朗陵長趙儼收治，致之大辟。是時殺生之柄，決於牧守，通妻子號泣以請其命。通曰：「方與曹公戮力，義不以私廢公。」嘉儼執憲不阿，與為親交。

**释读** 李通妻伯父触法，赵俨据律定罪，李通同意不徇私情。

6. **袁术杀陈王宠。** [[6]](#hh-note-6)

7. **孙策遣使奉贡。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **追杨氏前功，封蓩亭侯。** 朝廷在献帝建安二年追及杨震旧功施封。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **献帝建安二年九月，汉水流，害民人。** [[9]](#hh-note-9)

<a id="sg-event-10"></a>

10. **张绣先降后叛，曹操败于宛城。** 二年春正月，公到宛。张绣降，旣而悔之，复反。公与战，军败，爲流矢所中，长子昂、弟子安民遇害。公乃引兵还舞阴，绣将骑来钞，公击破之。绣奔穰，与刘表合。公谓各将领曰：「吾降张绣等，失不便取其质，以至于此。吾知所以败。诸卿观之，自今已后不复败矣。」遂还许。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **布收其使，上其书。** [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **术怒，攻布。** 术怒，攻布，爲布所破。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **术侵陈，公东征之。** 秋九月，术侵陈，公东征之。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **术闻公自来，弃军走。** 术闻公自来，弃军走，留其将桥蕤、李丰、梁纲、乐就；公到，击破蕤等，皆斩之。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **术走渡淮。** [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **公之自舞阴还也，南阳、章陵诸县复叛爲绣。** 公之自舞阴还也，南阳、章陵诸县复叛爲绣，公遣曹洪击之，不利，还屯叶，数爲绣、表所侵。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **公自南征，至宛。** 冬十一月，公自南征，至宛。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **表将邓济据湖阳。** [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **攻拔之，生禽济。** 攻拔之，生禽济，湖阳降。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **攻舞阴，下之。** [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **赵俨任朗陵长。** 赵俨从荆州扶老携幼投曹操，出任朗陵长，治理豪强。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **夔将还乡里，度术必急追。** 建安二年，夔将还乡里，度术必急追，乃间行得免，明年到本郡。 [[22]](#sg-note-22)

<a id="wu-event-23"></a>

23. **裴松之举杨彪下狱反驳曹操。** 裴松之指出，杨彪实际曾被曹操逼迫，险些被害。 [[23]](#wu-note-23)

<a id="sgz-event-24"></a>

24. **吕布得拜左将军，陈登入许都。** 陈珪想派陈登拜见曹操，起初吕布不同意，等曹操派来使者、授吕布左将军，吕布才准陈登入许并奉章谢恩。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **陈登赴许都受曹操委任。** 陈登面见曹操，称吕布勇而无谋、去就不定，宜早图之；曹操称陈登能察实情，增陈珪之秩，授陈登广陵太守。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **袁术杀拒受伪命的金尚。** 袁术僭号后暗劝金尚做太尉，金尚没有屈服；袁术起初不敢强迫，金尚逃离时被袁术杀害。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **金尚灵柩抵京并获诏吊祭。** 金尚灵柩与太傅马日磾之丧俱至京，献帝褒其忠烈，诏百官吊祭、拜其子金玮为郎中；马日磾没有受到同样礼遇。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **吕布、韩暹和杨奉进军钟离。** 吕布联合二军水陆趋寿春，到钟离掳掠后渡淮北，留信讥袁术。袁术率五千步骑在淮上张势，吕布骑兵隔岸笑而引回。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **萧建据莒，臧霸攻破莒城。** 琅邪相萧建守莒，不来往于吕布；吕布来书自述诛董、光复京师之志，以乐毅田单旧事劝通，萧建遣主簿奉笺献马五匹。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **杨奉、韩暹之死。** 韩暹、杨奉在徐、扬间劫掠，本传合称两人被刘备杀。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **郭汜被部将杀。** 郭汜遭部将五习突袭，死于郿。 [[31]](#sgz-note-31)

<a id="sgz-event-32"></a>

32. **《英雄记》分述杨奉、韩暹遇害。** 刘备诱杨奉赴会而执之，韩暹返并州途中为杼秋屯帅张宣截杀。 [[32]](#sgz-note-32)

<a id="sgz-event-33"></a>

33. **袁绍致书傲慢，荀彧为曹操分析四胜。** 袁绍因此更加骄慢，给曹操的信语多无礼。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **荀彧劝曹操先取吕布。** 曹操喜荀彧之言，荀彧又劝不先除吕布便难谋河北。 [[34]](#sgz-note-34)

<a id="sgz-event-35"></a>

35. **荀彧荐钟繇安抚关中。** 曹操赞同先取，但忧袁绍侵扰关中、惑羌胡、结蜀汉，使自己独据兖豫而敌众。 [[35]](#sgz-note-35)

<a id="sgz-event-36"></a>

36. **朝廷令孙策、吕布、陈瑀合击袁术。** 诏谴袁术伪造符命、私建宫署、僭行郊祀，说吕布告知详情，令孙策协同吕布、陈瑀进兵。 [[36]](#sgz-note-36)

<a id="sgz-event-37"></a>

37. **王辅承制假孙策明汉将军。** 孙策自认为领众仅得骑都尉太轻，请王辅承制给明汉将军之号。 [[37]](#sgz-note-37)

<a id="sgz-event-38"></a>

38. **孙策在海西击败陈瑀。** 陈瑀派万演等携印渡江，约祖郎等与严白虎作内应，准备在孙策发兵时袭取各郡。孙策发觉后遣吕范、徐逸击破陈瑀并获其吏士家属。 [[38]](#sgz-note-38)

<a id="sgz-event-39"></a>

39. **吕范徐逸击陈瑀于海西。** 陈瑀自称吴郡太守、驻海西并联严白虎，孙策讨白虎，另遣吕范和徐逸攻陈瑀，斩其部将陈牧。 [[39]](#sgz-note-39)

<a id="sgz-event-40"></a>

40. **《献帝春秋》称诸葛玄被西城人杀。** 西城居民反，杀诸葛玄，送首刘繇。 [[40]](#sgz-note-40)

<a id="sgz-event-41"></a>

41. **郭嘉劝乘袁绍北击公孙瓒先取吕布。** 郭嘉提醒乘袁绍远征先除吕布，否则二者可能相援，曹操赞同。 [[41]](#sgz-note-41)

<a id="wu-p-074-8"></a>

**[《三国志·武帝纪》裴注 074·8](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-074-8)**

> 又袁術僣號於九江下皆稱臣名門曰建號門衣被皆為天子之制兩婦預爭為皇后志計已定人有勸術使遂即帝位露布天下答言曹公尚在未可也

**释读** 曹操说袁术作僭礼，用天子规格，两夫人争皇后，有人劝公开称帝，袁术忌惮曹操。

**归年** 令出210年；本纪L38及《献帝纪》建安二年记袁术僭号，私下交谈无确日。

<a id="sgz006-p-074-1"></a>

**[《三国志·董二袁刘传》裴注 074·1](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-074-1)**

> 典畧曰術以袁姓出陳陳舜之後以土承火得應運之次又見䜟文云代漢者當塗高也自以名字當之乃建號稱仲氏

**释读** 《典略》载袁术认为己出舜后、以土承火，并以名字应代汉者当涂高，建立仲氏年号或国号。

**归年** 《孝献帝纪》建安二年袁术称帝；仲氏原字保留。

<a id="sgz050-b-2410-6"></a>

**[《三国志·妃嫔传》仓内原文 L2410](../../sources/本地分卷/三国志/三国志-卷050.md#l2410)**

> 術後僭號。策以書喻術，術不納，便絕江津，不與通，使人告景。景即委郡東歸，策復以景為丹揚太守。

**释读** 孙策劝阻不果，断江津并通知吴景，吴景弃广陵后再任丹杨太守。

**归年** 《后汉书·献帝纪》建安二年袁术称帝；吴景回任为其后同组事。

<a id="sgz051-b-2452-9"></a>

**[《三国志·宗室传》仓内原文 L2452](../../sources/本地分卷/三国志/三国志-卷051.md#l2452)**

> 策遣賁、景還壽春報術，值術僭號，署置百官。除賁九江太守。賁不就，棄妻孥還江南。

**释读** 孙策遣孙贲、吴景到寿春报信，逢袁术僭号任置百官，孙贲拒九江太守命，舍妻儿还江南。

**归年** 《武帝纪》《通鉴》建安二年袁术僭号。

<a id="sgz051-p-004-2"></a>

**[《三国志·宗室传》裴注 004·2](../../sources/摘录/三国志-卷051-宗室传裴注.md#pei-004-2)**

> 策與景等書曰今征江東未知二三君意云何耳景即棄守歸賁因而獲免香以道逺獨不得還

**释读** 孙策写信问宗亲去就，吴景弃守回孙策处，孙贲也脱离袁术，孙香因路远未能回。

**归年** 本传《孙贲传》、附吴景事及《吴主传》连于袁术建安二年称帝、孙策绝交。

<a id="sgz046-b-2259-6"></a>

**[《三国志·孙破虏讨逆传》仓内原文 L2259](../../sources/本地分卷/三国志/三国志-卷046.md#l2259)**

> 復以吳景為丹楊太守，

**释读** 孙策再任吴景为丹杨太守。

**归年** 《宗室传》注引《吴书》与《徐夫人传》皆记吴景因袁术僭号等事自广陵归孙策，复守丹杨。

<a id="sgz046-p-029-1"></a>

**[《三国志·孙破虏讨逆传》裴注 029·1](../../sources/摘录/三国志-卷046-孙破虏讨逆传裴注.md#pei-029-1)**

> 吳録載策使張紘為書曰蓋上天垂司過之星聖王建敢諫之皷設非謬之備急箴闕之言何哉凡有所長必有所短也去冬傳有大計無不悚懼旋知供備貢獻萬夫解惑頃聞建議復欲追遵前圖即事之期便有定月益使憮然想是流妄設其必爾民何望乎

**释读** 书以劝谏为古圣先王所设，说听到袁术再拟称尊便使人忧惧。

**归年** 《孙策传》建安二年责袁术并绝交，同一书。

<a id="sgz046-p-029-2"></a>

**[《三国志·孙破虏讨逆传》裴注 029·2](../../sources/摘录/三国志-卷046-孙破虏讨逆传裴注.md#pei-029-2)**

> 曩日之舉義兵也天下之士所以響應者董卓擅廢置害太后弘農王畧烝宮人發掘園陵暴逆至此故諸州郡雄豪聞聲慕義神武外振卓遂内殱元惡既斃幼主東顧俾保傅宣命欲令諸軍振旅於河北通謀黒山曹操故毒東齊劉表稱亂南荆公孫瓉炰烋北幽劉繇決力江滸劉備爭盟淮隅是以未獲承命櫜弓戢戈也今備繇既破操等饑餒謂當與天下合謀以誅醜類捨而不圖有自取之志非海内所望一也

**释读** 回顾董卓废立、杀何太后与弘农王、掘陵和关东讨董；又叙列诸方互斗，主张同谋讨乱，不宜为己夺天下。

**归年** 建安二年书信以早期史事立论；189至192旧事见各年，所指不混于同年。

<a id="sgz046-p-029-3"></a>

**[《三国志·孙破虏讨逆传》裴注 029·3](../../sources/摘录/三国志-卷046-孙破虏讨逆传裴注.md#pei-029-3)**

> 昔成湯伐桀稱有夏多罪武王伐紂曰殷有罪罰重哉此二主者雖有聖徳宜當君世如使不遭其時亦無由興矣幼主非有惡於天下徒以春秋尚少脅於彊臣若無過而奪之懼未合於湯武之事二也卓雖狂狡至廢主自與亦猶未也而天下聞其桀虐攘臂同心而疾之以中土希戰之兵當邊地勁捍之虜所以斯湏游魂也今四方之人皆玩敵而便戰鬬矣可得而勝者以彼亂而我治彼逆而我順也見當世之紛若欲大舉以臨之適足趣禍三也

**释读** 以汤武有时有德为比，说天子年少受胁，不能为此便夺位；又预判无须因他方战乱而贸然用兵。

**归年** 劝袁术的同一信札。

**[《三国志·二荀贾传》仓内原文 L507](../../sources/本地分卷/三国志/三国志-卷010.md#l507)**

> 則見太祖問之，太祖乃以紹書示彧，曰：「今將討不義，而力不敵，何如？」

**释读** 荀彧问曹操，曹操出示袁绍的信，问打不义而实力不敌怎么办。

**归年** 通鉴卷062建安二年同次。

<a id="sgz010-b-507-7"></a>

**[《三国志·二荀贾传》仓内原文 L507](../../sources/本地分卷/三国志/三国志-卷010.md#l507)**

> 彧曰：「古之成敗者，誠有其才，雖弱必彊，苟非其人，雖彊易弱，劉、項之存亡，足以觀矣。今與公爭天下者，唯袁紹爾。紹貌外寬而內忌，任人而疑其心，公明達不拘，唯才所宜，此度勝也。

**释读** 荀彧以刘邦项羽兴亡为比，说人才使弱能强；袁绍貌宽内忌，曹操善任不疑，胜于气度。

**归年** 197年对话，通鉴卷062另综合荀彧郭嘉列十胜。

<a id="sgz010-b-507-8"></a>

**[《三国志·二荀贾传》仓内原文 L507](../../sources/本地分卷/三国志/三国志-卷010.md#l507)**

> 紹遲重少決，失在後機，公能斷大事，應變無方，此謀勝也。紹御軍寬緩，法令不立，士卒雖衆，其實難用，公法令旣明，賞罰必行，士卒雖寡，皆爭致死，此武勝也。

**释读** 袁迟疑而误时，曹善决断；袁军法弛，曹军赏罚有序且士肯死，曹智谋和军事两胜。

**归年** 同次四胜之论。

<a id="sgz010-b-507-9"></a>

**[《三国志·二荀贾传》仓内原文 L507](../../sources/本地分卷/三国志/三国志-卷010.md#l507)**

> 紹憑世資，從容飾智，以收名譽，故士之寡能好問者多歸之，公以至仁待人，推誠心不爲虛美，行己謹儉，而與有功者無所恡惜，故天下忠正效實之士咸願爲用，此德勝也。夫以四勝輔天子，扶義征伐，誰敢不從？紹之彊其何能爲！」

**释读** 袁靠家世修饰声名，而曹操待人真诚、俭而赏功，士愿归，是德胜。凭四胜扶天子征伐足以压服袁绍。

**归年** 同次197年说四胜。

<a id="sgz014-b-695-1"></a>

**[《三国志·程郭董刘蒋刘传》仓内原文 L695](../../sources/本地分卷/三国志/三国志-卷014.md#l695)**

> 劉、項之不敵，公所知也。漢祖唯智勝；項羽雖強，終為所禽。嘉竊料之，紹有十敗，公有十勝，雖兵強，無能為也。紹繁禮多儀，公體任自然，此道勝一也。紹以逆動，公奉順以率天下，此義勝二也。漢末政失於寬，紹以寬濟寬，故不攝，公糾之以猛而上下知制，此治勝三也。紹外寬內忌，用人而疑之，所任唯親戚子弟，公外易簡而內機明，用人無疑，唯才所宜，不間遠近，此度勝四也。紹多謀少決，失在後事，公策得輒行，應變無窮，此謀勝五也。紹因累世之資，高議揖讓以收名譽，士之好言飾外者多歸之，公以至心待人，推誠而行，不為虛美，以儉率下，與有功者無所吝，士之忠正遠見而有實者皆原為用，此德勝六也。紹見人飢寒，卹念之形於顏色，其所不見，慮或不及也，所謂婦人之仁耳，公於目前小事，時有所忽，至於大事，與四海接，恩之所加，皆過其望，雖所不見，慮之所周，無不濟也，此仁勝七也。紹大臣爭權，讒言惑亂，公禦下以道，浸潤不行，此明勝八也。紹是非不可知，公所是進之以禮，所不是正之以法，此文勝九也。紹好為虛勢，不知兵要，公以少克眾，用兵如神，軍人恃之，敵人畏之，此武勝十也。

**释读** 郭嘉比曹袁如刘项，列自然、不逆、治军、用人、决断、诚信、广济、御谗、文法、军事十端。

**归年** TXT此段为混入《傅子》裴注的节录，完整见校注；《资治通鉴》卷六十二建安二年通行系年。袁绍致书时荀彧另有“四胜”，人名、论目须各据原文。

<a id="sgz014-p-009-1"></a>

**[《三国志·程郭董刘蒋刘传》裴注 009·1](../../sources/摘录/三国志-卷014-程郭董刘蒋刘传裴注.md#pei-009-1)**

> 傅子曰太祖謂嘉曰本初擁冀州之衆靑并從之地廣兵彊而數為不遜吾欲討之力不敵如何對曰劉項之不敵公所知也漢祖唯智勝項羽雖彊終為所禽嘉竊料之紹有十敗公有十勝雖兵彊無能為也紹繁禮多儀公體任自然此道勝一也紹以逆動公奉順以率天下此義勝二也漢末政失於寛紹以寛濟寛故不懾公紏之以猛而上下知制此治勝三也紹外寛内忌用人而疑之所任唯親戚子弟公外易簡而内機明用人無疑唯才所宜不問遠近此度勝四也紹多謀少决失在後事公䇿得輒行應變無窮此謀勝五也紹因累世之資髙議揖讓以收名譽士之好言飾外者多歸之公以至心待人推誠而行不為虚美以儉率下與有功者無所吝士之忠正遠見而有實者皆願為用此徳勝六也紹見人飢寒恤念之形於顔色其所不見慮或不及也所謂婦人之仁耳公於目前小事時有所忽至於大事與四海接恩之所加皆過其望雖所不見慮之所周無不濟也此仁勝七也紹大臣争權䜛言惑亂公御下以道浸潤不行此明勝八也紹是非不可知公所是進之以禮所不是正之以法此文勝九也紹好為虚勢不知兵要公以少克衆用兵如神軍人恃之敵人畏之此武勝十也太祖笑曰如卿所言孤何徳以堪之也

**释读** 曹操问以弱对袁绍，郭嘉以道、义、治、度、谋、德、仁、明、文、武逐项论曹胜袁败，曹操谦称担当不起。

**归年** 《资治通鉴》卷六十二建安二年系袁绍致书、荀彧四胜及此十胜。TXT部分文字重复见卷十四正文栏，应挂同事件。

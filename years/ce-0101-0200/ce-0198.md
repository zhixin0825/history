6. **张羡起兵反刘表。** 张羡联合零陵、桂阳反刘表，刘表用兵攻围，后来平复。 [[6]](#hh-note-6)

10. **刘表遣兵救绣，以绝军后。** 夏五月，刘表遣兵救绣，以绝军后。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **公将引还，绣兵来。** 公将引还，绣兵来，公军不得进，连营稍前。 [[11]](#sg-note-11)

12. **公与荀彧书曰“贼来追吾”。** 公与荀彧书曰：「贼来追吾，虽日行数里，吾策之，到安衆，破绣必矣。」 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **到安衆，绣与表兵合守险。** 到安衆，绣与表兵合守险，公军前后受敌。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **公乃夜凿险爲地道，悉过辎重。** 公乃夜凿险爲地道，悉过辎重，设奇兵。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **会明，贼谓公爲遁也。** 会明，贼谓公爲遁也，悉军来追。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **乃纵奇兵步骑夹攻，大破之。** [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **公还许。** 秋七月，公还许。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **荀彧问公，「前以策贼必破。** 荀彧问公：「前以策贼必破，何也？」 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **公曰“虏遏吾归师”。** 公曰：「虏遏吾归师，而与吾死地战，吾是以知胜矣。」 [[19]](#sg-note-19)

<a id="wu-event-20"></a>

20. **曹操在吕布败后接纳臧霸等。** 吕布败后，曹操得到臧霸等人，厚待并任用。 [[20]](#wu-note-20)

<a id="wu-event-21"></a>

21. **曹操以青徐沿海委臧霸等并分置诸郡。** 曹操将青、徐两州沿海交给臧霸等负责，并分琅邪、东海、北海设置城阳、利城、昌虑郡。 [[21]](#wu-note-21)

<a id="wu-event-22"></a>

22. **眭固杀杨丑并率部依附袁绍。** 眭固杀了杨丑，率部归附袁绍。 [[22]](#wu-note-22)

### 4. 曹操击吕布於徐州，斩之

[返回正文第4条](#hh-event-4)

<a id="sg001-l41-e4"></a>

**[《三国志·武帝纪》](../../sources/摘录/三国志-卷001-武帝纪.md#p004)** · [仓内TXT L41](../../sources/本地分卷/三国志/三国志-卷001.md#l41)

> 呂布復爲袁術使高順攻劉備，公遣夏侯惇救之，不利。備爲順所敗。九月，公東征布。冬十月，屠彭城，獲其相侯諧。進至下邳，布自將騎逆擊。大破之，獲其驍將成廉。追至城下，布恐，欲降。陳宮等沮其計，求救於術，勸布出戰，戰又敗，乃還固守，攻之不下。時公連戰，士卒罷，欲還，用荀攸、郭嘉計，遂決泗、沂水以灌城。月餘，布將宋憲、魏續等執陳宮，舉城降，生禽布、宮，皆殺之。太山臧霸、孫觀、吳敦、尹禮、昌狶各聚衆。布之破劉備也，霸等悉從布。布敗，獲霸等，公厚納待，遂割青、徐二州附於海以委焉，分琅邪、東海、北海爲城陽、利城、昌慮郡。

<a id="sg007-l386-e4"></a>

**[《三国志·吕布臧洪传》](../../sources/摘录/三国志-卷007-吕布臧洪传.md#p002)** · [仓内TXT L386](../../sources/本地分卷/三国志/三国志-卷007.md#l386)

> 太祖塹圍之三月，上下離心，其將侯成、宋憲、魏續縛陳宮，將其衆降。布與其麾下登白門樓。兵圍急，乃下降。

**归年与互校** 《献帝纪》记建安三年十二月癸酉。

<a id="hh009-l1249-e4"></a>

**[《后汉书·献帝纪》](../../sources/摘录/后汉书-卷009-献帝纪.md#p002)** · [仓内TXT L1249](../../sources/本地分卷/后汉书/后汉书-卷009.md#L1249)

> 十二月癸酉，曹操擊呂布於徐州，斬之。

<a id="hh075-l5403-e4"></a>

**[《后汉书·刘焉袁术吕布列传》](../../sources/摘录/后汉书-卷075-刘焉袁术吕布列传.md#p004)** · [仓内TXT L5403](../../sources/本地分卷/后汉书/后汉书-卷075.md#L5403)

> 布及宮、順皆縊殺之，傳首許市。

**归年与互校** 按《献帝纪》建安三年十二月。

<a id="wu-b-041-7"></a>

**[《三国志·武帝纪》仓内原文 L41](../../sources/本地分卷/三国志/三国志-卷001.md#l41)**

> 月餘，布將宋憲、魏續等執陳宮，舉城降，生禽布、宮，皆殺之。

**释读** 一个多月后，宋宪、魏续等擒陈宫，献出下邳；曹操俘获吕布、陈宫并杀死。

**归年** 《后汉书·献帝纪》L1249及《资治通鉴》卷062 L587–605同记建安三年十二月癸酉。年页按建安三年归198页，实际换算在公元199年初。通鉴《考异》从武帝纪“月餘”，不从两书吕布传“三月”。

<a id="wu-b-042-3"></a>

**[《三国志·武帝纪》仓内原文 L42](../../sources/本地分卷/三国志/三国志-卷001.md#l42)**

> 及布破，諶生得，衆爲諶懼，公曰：「夫人孝於其親者，豈不亦忠於君乎！吾所求也。」以爲魯相。

**释读** 吕布败后毕谌被俘，曹操肯定其孝心，任为鲁相。

**归年** 上文建安三年十二月击破吕布；本句连叙败后任用，未载另月。沿用仓内建安三年年页。

<a id="sgz003-p-014-3"></a>

**释读** 下邳城陷后，曹操看见杜氏并纳入家中，秦宜禄归降而任铚长。

**归年** 接建安三年十二月平吕布，年页年号口径为198，实际历日跨公历199年初。授铚长无独立月日。

**释读** 吕布说绑得太紧，曹操答捆老虎不得不紧。

**归年** 本传接城陷被俘，属建安三年十二月的同日对话。

<a id="sgz007-b-386-10"></a>

**[《三国志·吕布臧洪传》仓内原文 L386](../../sources/本地分卷/三国志/三国志-卷007.md#l386)**

> 布請曰：「明公所患不過於布，今已服矣，天下不足憂。明公將步，令布將騎，則天下不足定也。」

**释读** 吕布说如今自己归服，愿替曹操统骑兵，与曹操统步卒配合平天下。

**归年** 与同日城陷被俘相接；裴注《献帝春秋》载当日吕布尝求刘备说情等异说。

**释读** 曹操面有犹疑，刘备提醒不可忘吕布如何对待丁原、董卓。曹操点头，吕布便指刘备最不可相信。

**归年** 《通鉴》卷062 L587–596亦列同日；话中丁原189、董卓192往事在L374、376已各归年。

> 於是縊殺布。布與宮、順等皆梟首送許，然後葬之。

**释读** 吕布被缢死，吕布与陈宫、高顺等的首级送往许都示众，然后安葬。

**归年** 卷001 L44、《通鉴》卷062 L580–596曰建安三年十二月癸酉。公历值次年年初，沿本项目史书汉年归建安三年页。

> 太祖之禽宮也，問宮欲活老母及女不？

**释读** 曹操擒陈宫，询问他是否想保全老母和女儿。

**归年** 见紧前下邳陷及曹操杀陈宫，建安三年十二月癸酉。

<a id="sgz007-b-388-2"></a>

> 宮對曰：「宮聞孝治天下者不絕人之親，仁施四海者不乏人之祀，老母在公，不在宮也。」

**释读** 陈宫说以孝治天下不会使人绝亲，施仁不会使人绝嗣，母亲能否活命在曹操。

**归年** 与紧前下邳被俘同日，本传与裴注《典略》分别记对答。

### 9. 公围张绣于穰

[返回正文第9条](#sg-event-9)

<a id="sg001-l40-e9"></a>

**[《三国志·武帝纪》](../../sources/摘录/三国志-卷001-武帝纪.md#p004)** · [仓内TXT L40](../../sources/本地分卷/三国志/三国志-卷001.md#l40)

> 三月，公圍張繡於穰。

<a id="sy-sg010-l518-e9"></a>

**[《三国志·二荀贾传》](../../sources/摘录/三国志-卷010-二荀贾传.md#p002)** · [仓内TXT L518](../../sources/本地分卷/三国志/三国志-卷010.md#L518)

> 建安三年，從征張繡。攸言於太祖曰：「繡與劉表相恃爲彊，然繡以遊軍仰食於表，表不能供也，勢必離。不如緩軍以待之，可誘而致也；若急之，其勢必相救。」太祖不從，遂進軍之穰，與戰。繡急，表果救之。軍不利。太祖謂攸曰：「不用君言至是。」乃設奇兵復戰，大破之。

**本段所记** 荀攸建议等张绣与刘表因供粮分离再作进攻，曹操未采。刘表派兵援张绣，曹军作战不利；曹操再用奇兵击破对方。

**归年与互校** 本传明记建安三年，《资治通鉴》卷062系三月围穰及其后战事。

<a id="sgz008-b-435-7"></a>

**[《三国志·二公孙陶四张传》仓内原文 L435](../../sources/本地分卷/三国志/三国志-卷008.md#l435)**

> 繡還保穰，太祖比年攻之，不克。

**释读** 张绣回据穰，曹操多次进攻未克。

**归年** “比年”跨197、198年；《武帝纪》建安三年三月围穰记此阶段。

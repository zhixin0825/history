9. **曹操围张绣于穰，回师在安众反击。** 三月曹操围穰。五月刘表遣军救张绣并断归路。曹军至安众移出辎重、设伏，大破追兵。《贾诩传》还记张绣依其计再次追击而胜。七月曹操回许，向荀彧说明临阵判断。 [[9]](#sg-note-9)

24. **邓羲劝刘表，辞职。** 邓羲进谏未纳，托病退职，直到刘表死都未再出任。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **刘表答邓羲关于与袁绍结约。** 《汉书春秋》记刘表认为内不失贡职、外不背盟主是天下通义，反问邓羲何以责怪。 [[25]](#sgz-note-25)

26. **高顺、张辽破小沛，俘刘备妻子。** 吕布遣高顺攻刘备，曹操派夏侯惇救援，夏侯惇败于高顺。《英雄记》记高顺与张辽九月破沛，刘备脱走，妻子被俘。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **刘备兵劫吕布买马使者。** 建安三年春，吕布派携金使者到河内买马，为刘备兵所劫。 [[27]](#sgz-note-27)

<a id="sgz-event-29"></a>

29. **刘繇病卒于豫章。** 刘繇病卒于豫章，年四十二，《资治通鉴》系于建安三年。长子刘基年十四，居丧尽礼，故吏馈送皆辞。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

<a id="sgz-event-33"></a>

30. **孙策平丹杨七县，擒祖郎与太史慈并任用。** 孙策在陵阳擒祖郎。太史慈此前进据泾县，山越多附，孙策又在勇里擒获他，解缚重谈神亭旧事，任为门下督，回吴后授兵、拜折冲中郎将。祖郎也获释任官，军还时与太史慈同为前导。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **孙策遣太史慈抚刘繇故部，太史慈如期回报。** 刘繇死后，孙策令太史慈赴豫章看望其子、招抚故部，并察华歆治郡及庐陵、鄱阳、海昏形势。孙策在昌门送行，太史慈约不逾六十日，带数十人赴豫章，如期回报；孙策由此有兼并之意，次年[取得豫章](ce-0199.md#sgz-note-35)。 [[31]](#sgz-note-31)

<a id="sgz-event-34"></a>

34. **孙策改任讨逆将军、封吴侯。** 孙策又遣使向汉廷进献方物，贡物是前次的两倍。曹操表孙策为讨逆将军，改封吴侯。 [[34]](#sgz-note-34)

<a id="sgz-event-35"></a>

35. **曹操以联姻和征辟安抚孙氏。** 曹操不便与已据江东的孙策交战，改用联姻。他把弟女嫁孙匡，为曹彰娶孙贲之女，又以礼征孙权、孙翊。 [[35]](#sgz-note-35)

<a id="sgz-event-36"></a>

<a id="sgz-event-37"></a>

37. **曹操表征王朗，孙策准其离开。** 曹操表天子征王朗。 [[37]](#sgz-note-37)

<a id="sgz-event-38"></a>

38. **董昭转河南尹。** 董昭迁河南尹。 [[38]](#sgz-note-38)

<a id="sgz-event-39"></a>

39. **周瑜回吴，孙策拜建威中郎将。** 周瑜由居巢回吴，孙策亲迎并授建威中郎将。 [[39]](#sgz-note-39)

<a id="sgz-event-40"></a>

40. **鲁肃指仓粮赠周瑜。** 周瑜过访求粮，鲁肃把两囷中一囷三千斛相赠，两人结厚交。 [[40]](#sgz-note-40)

<a id="sgz-event-41"></a>

41. **鲁肃辞袁术，投周瑜东渡。** 鲁肃获袁术任东城长，嫌其无纲纪，领老弱及轻侠百余人就周瑜，同行东渡定居曲阿。 [[41]](#sgz-note-41)

### 4. 曹操围下邳，擒斩吕布

[返回正文第4条](#hh-event-4)

<a id="sg001-l41-e4"></a>

**[《三国志·武帝纪》](../../sources/本地分卷/三国志/三国志-卷001.md#p004)** · [仓内TXT L41](../../sources/本地分卷/三国志/三国志-卷001.md#l41)

> 呂布復爲袁術使高順攻劉備，公遣夏侯惇救之，不利。備爲順所敗。九月，公東征布。冬十月，屠彭城，獲其相侯諧。進至下邳，布自將騎逆擊。大破之，獲其驍將成廉。追至城下，布恐，欲降。陳宮等沮其計，求救於術，勸布出戰，戰又敗，乃還固守，攻之不下。時公連戰，士卒罷，欲還，用荀攸、郭嘉計，遂決泗、沂水以灌城。月餘，布將宋憲、魏續等執陳宮，舉城降，生禽布、宮，皆殺之。太山臧霸、孫觀、吳敦、尹禮、昌狶各聚衆。布之破劉備也，霸等悉從布。布敗，獲霸等，公厚納待，遂割青、徐二州附於海以委焉，分琅邪、東海、北海爲城陽、利城、昌慮郡。

<a id="sg007-l386-e4"></a>

**[《三国志·吕布臧洪传》](../../sources/本地分卷/三国志/三国志-卷007.md#p002)** · [仓内TXT L386](../../sources/本地分卷/三国志/三国志-卷007.md#l386)

> 太祖塹圍之三月，上下離心，其將侯成、宋憲、魏續縛陳宮，將其衆降。布與其麾下登白門樓。兵圍急，乃下降。

**归年与互校** 《献帝纪》记建安三年十二月癸酉。

<a id="hh009-l1249-e4"></a>

**[《后汉书·献帝纪》](../../sources/摘录/后汉书-卷009-献帝纪.md#p002)** · [仓内TXT L1249](../../sources/本地分卷/后汉书/后汉书-卷009.md#L1249)

> 十二月癸酉，曹操擊呂布於徐州，斬之。

<a id="hh075-l5403-e4"></a>

**[《后汉书·刘焉袁术吕布列传》](../../sources/摘录/后汉书-卷075-刘焉袁术吕布列传.md#p004)** · [仓内TXT L5403](../../sources/本地分卷/后汉书/后汉书-卷075.md#L5403)

> 布及宮、順皆縊殺之，傳首許市。

**归年与互校** 按《献帝纪》建安三年十二月。

<a id="wu-b-041-7"></a>

**[《三国志·武帝纪》仓内原文 L41](../../sources/本地分卷/三国志/三国志-卷001.md#l41)**

> 月餘，布將宋憲、魏續等執陳宮，舉城降，生禽布、宮，皆殺之。

**释读** 一个多月后，宋宪、魏续等擒陈宫，献出下邳；曹操俘获吕布、陈宫并杀死。

**归年** 《后汉书·献帝纪》L1249及《资治通鉴》卷062 L587–605同记建安三年十二月癸酉。年页按建安三年归198页，实际换算在公元199年初。通鉴《考异》从武帝纪“月餘”，不从两书吕布传“三月”。

<a id="wu-b-042-3"></a>

**[《三国志·武帝纪》仓内原文 L42](../../sources/本地分卷/三国志/三国志-卷001.md#l42)**

> 及布破，諶生得，衆爲諶懼，公曰：「夫人孝於其親者，豈不亦忠於君乎！吾所求也。」以爲魯相。

**释读** 吕布败后毕谌被俘，曹操肯定其孝心，任为鲁相。

**归年** 上文建安三年十二月击破吕布；本句连叙败后任用，未载另月。沿用仓内建安三年年页。

<a id="sgz003-p-014-3"></a>

**[《三国志·明帝纪》裴注 014·3](../../sources/本地分卷/三国志/三国志-卷003.md#pei-014-3)**

> 及城陷太祖見之乃自納之宜祿歸降以為銍長

**释读** 下邳城陷后，曹操看见杜氏并纳入家中，秦宜禄归降而任铚长。

**归年** 接建安三年十二月平吕布，年页年号口径为198，实际历日跨公历199年初。授铚长无独立月日。

<a id="sgz007-b-386-7"></a>

> 其將侯成、宋憲、魏續縛陳宮，將其衆降。

**释读** 侯成、宋宪、魏续绑了陈宫，率所部归降。

**归年** 卷001 L44系建安三年十二月癸酉，作缚陈宫、高顺，裴注另述侯成生怨。

<a id="sgz007-b-386-8"></a>

**[《三国志·吕布臧洪传》仓内原文 L386](../../sources/本地分卷/三国志/三国志-卷007.md#l386)**

> 布與其麾下登白門樓。兵圍急，乃下降。遂生縛布，

**释读** 吕布同部下登白门楼，被兵围急才下楼投降，遭生擒。

**归年** 同次下邳城陷。《通鉴》卷062 L581–596仍列建安三年十二月癸酉。

<a id="sgz007-b-386-9"></a>

**[《三国志·吕布臧洪传》仓内原文 L386](../../sources/本地分卷/三国志/三国志-卷007.md#l386)**

> 布曰：「縛太急，小緩之。」太祖曰：「縛虎不得不急也。」

**释读** 吕布说绑得太紧，曹操答捆老虎不得不紧。

**归年** 本传接城陷被俘，属建安三年十二月的同日对话。

<a id="sgz007-b-386-10"></a>

### 9. 曹操围张绣于穰，回师在安众反击

**释读** 张绣问两次精兵与败军使用得到相反结果，为何都如贾诩所料。

**归年** 建安三年退穰两次追击后对话。

**释读** 贾诩认为首次曹操将自断后，张绣即使用精兵也不敌曹操锐兵。

**[《三国志·钟繇华歆王朗传》裴注 025·3](../../sources/本地分卷/三国志/三国志-卷013.md#pei-025-3)**

> 建安三年太祖表徴朗䇿遣之

**释读** 曹操表征王朗，孙策准。

**归年** 注明建安三年。

### 39. 周瑜回吴，孙策拜建威中郎将

[返回正文第39条](#sgz-event-39)

<a id="sgz054-b-2560-9"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2560](../../sources/本地分卷/三国志/三国志-卷054.md#l2560)**

> 術欲以瑜為將，瑜觀術終無所成，故求為居巢長，欲假塗東歸，術聽之。

**释读** 袁术欲任周瑜为将，周瑜请到居巢任长，借道东归，袁术同意。

**归年** 《资治通鉴》卷六十二在建安三年列此事；下文周瑜东归也明记是年。

<a id="sgz054-b-2560-10"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2560](../../sources/本地分卷/三国志/三国志-卷054.md#l2560)**

> 遂自居巢還吳。是歲，建安三年也。

**归年** 本传明书建安三年。

<a id="sgz054-b-2561-1"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2561](../../sources/本地分卷/三国志/三国志-卷054.md#l2561)**

> 策親自迎瑜，授建威中郎將，即與兵二千人，騎五十匹。瑜時年二十四，吳中皆呼為周郎。

**释读** 孙策亲迎，授兵二千、骑五十；周瑜二十四岁，吴人称周郎。

**归年** 承前建安三年，裴注《江表传》补赏赐。

<a id="sgz054-p-002-1"></a>

**[《三国志·周瑜鲁肃吕蒙传》裴注 002·1](../../sources/本地分卷/三国志/三国志-卷054.md#pei-002-1)**

> 江表傳曰策又給瑜鼓吹為治館舍贈賜莫與為比䇿令曰周公瑾英儁異才與孤有總角之好骨肉之分如前在丹陽發衆及船糧以濟大事論徳酬功此未足以報者也

**释读** 孙策为周瑜治馆舍，给鼓吹、厚物，令中称两人少年如骨肉，礼物难以报偿丹杨时兵船粮助。

**归年** 本传周瑜建安三年回吴；同年受兵军礼，从“孙策授周瑜建威中郎将”。

<a id="sgz-note-40"></a>

### 40. 鲁肃指仓粮赠周瑜

[返回正文第40条](#sgz-event-40)

<a id="sgz054-b-2576-2"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2576](../../sources/本地分卷/三国志/三国志-卷054.md#l2576)**

> 周瑜為居巢長，將數百人故過候肅，並求資糧。肅家有兩囷米，各三千斛。肅乃指一囷與周瑜，瑜益知其奇也。遂相親結，定僑、札之分。

**归年** 《通鉴》卷六十二把周瑜为居巢长、鲁肃署东城长放在建安三年；赠粮具体月未载。

<a id="sgz-note-41"></a>

### 41. 鲁肃辞袁术，投周瑜东渡

[返回正文第41条](#sgz-event-41)

<a id="sgz054-b-2576-3"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2576](../../sources/本地分卷/三国志/三国志-卷054.md#l2576)**

> 袁術聞其名，就署東城長。肅見術無綱紀，不足與立事，乃攜老弱將輕俠少年百餘人，南到居巢就瑜。瑜之東渡，因與同行，留家曲阿。

**归年** 接周瑜建安三年还吴；《吴书》见孙策，勿误成后来的见孙权。

<a id="sgz054-p-012-2"></a>

**[《三国志·周瑜鲁肃吕蒙传》裴注 012·2](../../sources/本地分卷/三国志/三国志-卷054.md#pei-012-2)**

> 後雄傑並起中州擾亂肅乃命其屬曰中國失綱寇賊横暴淮泗間非遺種之地吾聞江東沃野萬里民富兵彊可以避害寜肯相随俱至樂土以觀時變乎其屬皆從命乃使細弱在前彊壯在後男女三百餘人行州追騎至肅等徐行勒兵持滿謂之曰卿等丈夫當觧大數今日天下兵亂有功弗賞不追無罰何為相偪乎又自植盾引弓射之矢皆洞貫騎既嘉肅言且度不能制乃相率還肅渡江往見策策亦雅奇之

**释读** 鲁肃谓淮泗兵乱难存，愿众避居江东，以弱在前、壮在后率男女三百余人；以言语和弓透盾止州骑，过江见孙策。

**归年** 承正文随周瑜198回吴。四库《考证》不取见孙策说，正文先到曲阿、后荐孙权；此处仅作《吴书》异文。

13. **洪、尚率衆降，封爲列侯。** 洪、尚率衆降，封爲列侯，还军敖仓。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **以魏种爲河内太守，属以河北事。** [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **是时袁绍旣并公孙瓒，兼四州之地。** 是时袁绍旣并公孙瓒，兼四州之地，衆十余万，将进军攻许，各将领以爲不可敌，公曰：「吾知绍之爲人，志大而智小，色厉而胆薄，忌克而少威，兵多而分画不明，将骄而政令不一，土地虽广，粮食虽丰，适足以爲吾奉也。」 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **公进军黎阳，使臧霸等入青州破齐、北海、东安。** 秋八月，公进军黎阳，使臧霸等入青州破齐、北海、东安，留于禁屯河上。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **公还许，分兵守官渡。** 九月，公还许，分兵守官渡。 [[17]](#sg-note-17)

18. **张绣率衆降，封列侯。** 冬十一月，张绣率衆降，封列侯。 [[18]](#sg-note-18)

19. **公军官渡。** 十二月，公军官渡。 [[19]](#sg-note-19)

20. **袁术自败于陈，稍困。** 袁术自败于陈，稍困，袁谭自青州遣迎之。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **术欲从下邳北过，公遣刘备、朱灵要之。** [[21]](#sg-note-21)

<a id="sg-event-23"></a>

23. **公悔，追之不及。** [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **备之未东也，阴与董承等谋反。** 备之未东也，阴与董承等谋反，至下邳，遂杀徐州刺史车胄，举兵屯沛。 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **遣刘岱、王忠击之，不克。** [[25]](#sg-note-25)

<a id="sg-event-26"></a>

26. **庐江太守刘勳率衆降，封爲列侯。** [[26]](#sg-note-26)

<a id="sg-event-27"></a>

27. **孙策乘虚夺庐江。** 袁术死后刘勋尽收其部众，孙策诱其远出，乘虚攻庐江，刘勋以数百人归曹操。 [[27]](#sg-note-27)

<a id="sg-event-28"></a>

28. **策遣紘奉章至许宫，留为侍御史。** 建安四年，策遣紘奉章至许宫，留为侍御史。 [[28]](#sg-note-28)

<a id="sy-event-29"></a>

29. **袁术死后徐璆上交所得印玺。** 徐璆在袁术死、部众败后取得袁术僭用的国玺，回许都献上，也还此前所假两郡印绶。赵温询问之时，徐璆以苏武自比。 [[29]](#sy-note-29)

<a id="wu-event-30"></a>

30. **袁绍赐乌丸首领单于名位。** 袁绍给乌丸首领单于名位，并用宗族中的女子与之结姻。 [[30]](#wu-note-30)

> 備之未東也，陰與董承等謀反，至下邳，遂殺徐州刺史車冑，舉兵屯沛。

<a id="sgz003-p-014-4"></a>

**[《三国志·明帝纪》裴注 014·4](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-014-4)**

> 及劉備走小沛張飛随之過謂宜祿曰人取汝妻而為之長乃蚩蚩若是邪随我去乎宜祿從之數里悔欲還飛殺之

**归年** 卷001 L46、卷032《先主传》系刘备反曹并据冀徐小沛于建安四年。“走小沛”承秦宜禄归曹后，非建安三年败高顺之役，具体月日未详。

### 29. 袁术死后徐璆上交所得印玺

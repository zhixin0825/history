<a id="sgz008-b-411-1"></a>

**[《三国志·二公孙陶四张传》仓内原文 L411](../../sources/本地分卷/三国志/三国志-卷008.md#l411)**

> 建安四年，紹悉軍圍之。瓚遣子求救於黑山賊，復欲自將突騎直出，傍西南山，擁黑山之眾，陸梁冀州，橫斷紹後。

**释读** 袁绍调诸军围易京，公孙瓒派子向黑山求救，计划亲率突骑会合助军、绕至袁军之后。

**归年** 本传明书建安四年，张燕、公孙续援兵参《通鉴》卷063。

<a id="sgz008-b-411-2"></a>

**[《三国志·二公孙陶四张传》仓内原文 L411](../../sources/本地分卷/三国志/三国志-卷008.md#l411)**

> 長史關靖說瓚曰：「今將軍將士，皆已土崩瓦解，其所以能相守持者，顧戀其居處老小，以將軍為主耳。將軍堅守曠日，袁紹要當自退；自退之後，四方之眾必復可合也。若將軍今舍之而去，軍無鎮重，易京之危，可立待也。將軍失本，孤在草野，何所成邪！」瓚遂止不出。

**释读** 关靖说军士守易京是为保护家属和依止主将，主将离去全军就会散，公孙瓒听从。

**归年** 199年易京被围中，与出山求援的方案同一背景。

<a id="sgz008-b-411-3"></a>

**[《三国志·二公孙陶四张传》仓内原文 L411](../../sources/本地分卷/三国志/三国志-卷008.md#l411)**

> 救至，欲內外擊紹。遣人與子書，刻期兵至，舉火為應。紹侯者得其書，如期舉火。瓚以為救兵至，遂出欲戰。紹設伏擊，大破之，復還守。

**释读** 公孙瓒欲与外援约期以火信为应；袁军截得书信照期举火，诱其赴战，伏击得胜。

**归年** 199年易京攻破之前，参《通鉴》卷063。

<a id="sgz008-b-411-4"></a>

**[《三国志·二公孙陶四张传》仓内原文 L411](../../sources/本地分卷/三国志/三国志-卷008.md#l411)**

> 紹為地道，突壞其樓，稍至中京。瓚自知必敗，盡殺其妻子，乃自殺。

**释读** 袁军挖地道破楼，推进至中京；公孙瓒知无力挽回，杀妻儿后自杀。

**归年** 《后汉书·献帝纪》《资治通鉴》同系建安四年。

<a id="sgz008-b-433-7"></a>

**[《三国志·二公孙陶四张传》仓内原文 L433](../../sources/本地分卷/三国志/三国志-卷008.md#l433)**

> 袁紹與公孫瓚爭冀州，燕遣將杜長等助瓚，與紹戰，為紹所敗，人眾稍散，

**释读** 袁绍与公孙瓒相持时，张燕派杜长等援公孙瓒，遭袁绍击败，部众分散。

**归年** 以此为袁、公孙末期战事的背景。《后汉书·公孙瓒传》《通鉴》明记199年张燕与公孙续援易京，本卷未明杜长出战具体日月。

<a id="sgz008-p-015-1"></a>

**[《三国志·二公孙陶四张传》裴注 015·1](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-015-1)**

> 典略曰瓉遣行人文則齎書告子續曰袁氏之攻似若神鬼皷角鳴於地中梯衝舞吾樓上日窮月踧無所聊賴汝當碎首於張燕速致輕騎到者當起烽火於北吾當從内出不然吾亡之後天下雖廣汝欲求安足之地其可得乎

**释读** 公孙瓒派文则传书，称易京受到地道及器械夹攻，要求公孙续催张燕并约北面起火。

**归年** 正文建安四年及《后汉书·公孙瓒传》都将此书系于易京最后一围。

<a id="sgz008-p-015-2"></a>

**[《三国志·二公孙陶四张传》裴注 015·2](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-015-2)**

> 獻帝春秋曰瓉夢薊城崩知必敗乃遣間使與續書紹候者得之使陳琳更其書曰盖聞在昔衰周之世僵尸流血以為不然豈意今日身當其衝其餘語與典略所載同

**释读** 此书说公孙瓒梦见蓟城崩，拟书遣间使，而袁绍候人截获并命陈琳改写，附存另一开篇。

**归年** 同一求援书的异说，附建安四年攻易京。

<a id="sgz008-p-016-1"></a>

**[《三国志·二公孙陶四张传》裴注 016·1](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-016-1)**

> 英雄記曰袁紹分部攻者掘地為道穿穴其樓下稍稍施木柱之度足達半便燒所施之柱樓輙傾倒

**释读** 《英雄记》详述分部挖地道、置柱承托挖空处，深度足够便焚柱使楼倒。

**归年** 《后汉书·公孙瓒传》及本传系建安四年易京失陷，附同次攻楼。

<a id="sgz008-p-017-1"></a>

**[《三国志·二公孙陶四张传》裴注 017·1](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-017-1)**

> 漢晉春秋曰關靖曰吾聞君子䧟人於危必同其難豈可獨生乎乃策馬赴紹軍而死紹悉送其首於許

**释读** 《汉晋春秋》称关靖以使人陷危者当共难为由，策马赴袁绍军而死，袁绍将所获首级送至许。

**归年** 附建安四年易京陷落；《后汉书·公孙瓒传》有同事。

<a id="sgz-event-31"></a>

31. **袁绍使耿苞言符命、继杀之。** 《典略》说袁绍令耿苞密言袁氏以黄代赤。众将以为妖妄，袁绍杀耿苞以自解。 [[31]](#sgz-note-31)

<a id="sgz-event-32"></a>

32. **曹操论英雄，刘备落箸。** 曹操对刘备说当世英雄只有刘备与曹操，袁绍不足数；刘备食时掉落匕箸。 [[32]](#sgz-note-32)

<a id="sgz-event-33"></a>

33. **刘备以雷震解释落箸。** 《华阳国志》说其时恰逢雷震，刘备引用迅雷风烈必变来解释惊得落箸。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **孔融忧袁军难克，荀彧分析其内忧。** 孔融认为袁绍地广兵强，又有谋士、忠臣、勇将，担心不能攻克。 [[34]](#sgz-note-34)

<a id="sgz008-b-411-1"></a>

**[《三国志·二公孙陶四张传》仓内原文 L411](../../sources/本地分卷/三国志/三国志-卷008.md#l411)**

> 建安四年，紹悉軍圍之。瓚遣子求救於黑山賊，復欲自將突騎直出，傍西南山，擁黑山之眾，陸梁冀州，橫斷紹後。

**释读** 袁绍调诸军围易京，公孙瓒派子向黑山求救，计划亲率突骑会合助军、绕至袁军之后。

**归年** 本传明书建安四年，张燕、公孙续援兵参《通鉴》卷063。

<a id="sgz008-b-411-2"></a>

**[《三国志·二公孙陶四张传》仓内原文 L411](../../sources/本地分卷/三国志/三国志-卷008.md#l411)**

> 長史關靖說瓚曰：「今將軍將士，皆已土崩瓦解，其所以能相守持者，顧戀其居處老小，以將軍為主耳。將軍堅守曠日，袁紹要當自退；自退之後，四方之眾必復可合也。若將軍今舍之而去，軍無鎮重，易京之危，可立待也。將軍失本，孤在草野，何所成邪！」瓚遂止不出。

**释读** 关靖说军士守易京是为保护家属和依止主将，主将离去全军就会散，公孙瓒听从。

**归年** 199年易京被围中，与出山求援的方案同一背景。

<a id="sgz008-b-411-3"></a>

**[《三国志·二公孙陶四张传》仓内原文 L411](../../sources/本地分卷/三国志/三国志-卷008.md#l411)**

> 救至，欲內外擊紹。遣人與子書，刻期兵至，舉火為應。紹侯者得其書，如期舉火。瓚以為救兵至，遂出欲戰。紹設伏擊，大破之，復還守。

**释读** 公孙瓒欲与外援约期以火信为应；袁军截得书信照期举火，诱其赴战，伏击得胜。

**归年** 199年易京攻破之前，参《通鉴》卷063。

<a id="sgz008-b-411-4"></a>

**[《三国志·二公孙陶四张传》仓内原文 L411](../../sources/本地分卷/三国志/三国志-卷008.md#l411)**

> 紹為地道，突壞其樓，稍至中京。瓚自知必敗，盡殺其妻子，乃自殺。

**释读** 袁军挖地道破楼，推进至中京；公孙瓒知无力挽回，杀妻儿后自杀。

**归年** 《后汉书·献帝纪》《资治通鉴》同系建安四年。

<a id="sgz008-b-433-7"></a>

**[《三国志·二公孙陶四张传》仓内原文 L433](../../sources/本地分卷/三国志/三国志-卷008.md#l433)**

> 袁紹與公孫瓚爭冀州，燕遣將杜長等助瓚，與紹戰，為紹所敗，人眾稍散，

**释读** 袁绍与公孙瓒相持时，张燕派杜长等援公孙瓒，遭袁绍击败，部众分散。

**归年** 以此为袁、公孙末期战事的背景。《后汉书·公孙瓒传》《通鉴》明记199年张燕与公孙续援易京，本卷未明杜长出战具体日月。

<a id="sgz008-p-015-1"></a>

**[《三国志·二公孙陶四张传》裴注 015·1](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-015-1)**

> 典略曰瓉遣行人文則齎書告子續曰袁氏之攻似若神鬼皷角鳴於地中梯衝舞吾樓上日窮月踧無所聊賴汝當碎首於張燕速致輕騎到者當起烽火於北吾當從内出不然吾亡之後天下雖廣汝欲求安足之地其可得乎

**释读** 公孙瓒派文则传书，称易京受到地道及器械夹攻，要求公孙续催张燕并约北面起火。

**归年** 正文建安四年及《后汉书·公孙瓒传》都将此书系于易京最后一围。

<a id="sgz008-p-015-2"></a>

**[《三国志·二公孙陶四张传》裴注 015·2](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-015-2)**

> 獻帝春秋曰瓉夢薊城崩知必敗乃遣間使與續書紹候者得之使陳琳更其書曰盖聞在昔衰周之世僵尸流血以為不然豈意今日身當其衝其餘語與典略所載同

**释读** 此书说公孙瓒梦见蓟城崩，拟书遣间使，而袁绍候人截获并命陈琳改写，附存另一开篇。

**归年** 同一求援书的异说，附建安四年攻易京。

<a id="sgz008-p-016-1"></a>

**[《三国志·二公孙陶四张传》裴注 016·1](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-016-1)**

> 英雄記曰袁紹分部攻者掘地為道穿穴其樓下稍稍施木柱之度足達半便燒所施之柱樓輙傾倒

**释读** 《英雄记》详述分部挖地道、置柱承托挖空处，深度足够便焚柱使楼倒。

**归年** 《后汉书·公孙瓒传》及本传系建安四年易京失陷，附同次攻楼。

<a id="sgz008-p-017-1"></a>

**[《三国志·二公孙陶四张传》裴注 017·1](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-017-1)**

> 漢晉春秋曰關靖曰吾聞君子䧟人於危必同其難豈可獨生乎乃策馬赴紹軍而死紹悉送其首於許

**释读** 《汉晋春秋》称关靖以使人陷危者当共难为由，策马赴袁绍军而死，袁绍将所获首级送至许。

**归年** 附建安四年易京陷落；《后汉书·公孙瓒传》有同事。

<a id="sgz006-b-351-7"></a>

**[《三国志·董二袁刘传》仓内原文 L351](../../sources/本地分卷/三国志/三国志-卷006.md#l351)**

> 頃之。擊破瓚於易京，井其衆。

**释读** 袁绍击破易京的公孙瓒，兼并其军。

**归年** 《后汉书·孝献帝纪》建安四年三月；井疑并，底本照录。

<a id="sgz006-p-100-5"></a>

**[《三国志·董二袁刘传》裴注 100·5](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-100-5)**

> 紹後用豐謀以平公孫瓚逢紀憚豐亮直數讒之於紹紹遂忌豐

**释读** 田丰出谋平公孙瓒，逢纪后来妒其刚直、屡谗，袁绍因而忌惮田丰。

**归年** 建安四年袁绍攻破易京；逢纪谗毁无独立年。

<a id="sgz010-b-527-9"></a>

**[《三国志·二荀贾传》仓内原文 L527](../../sources/本地分卷/三国志/三国志-卷010.md#l527)**

> 是後，太祖拒袁紹於官渡，紹遣人招繡，並與詡書結援。

**释读** 曹操对峙袁绍之际，袁绍遣人招张绣，写信让贾诩为援。

**归年** 《武帝纪》L46与通鉴卷063 L103–118明确建安四年十一月降曹，议归袁、曹先于冬降，不因本句“官渡”改作200。

<a id="sgz010-b-527-10"></a>

**[《三国志·二荀贾传》仓内原文 L527](../../sources/本地分卷/三国志/三国志-卷010.md#l527)**

> 繡欲許之，詡顯於繡坐上謂紹使曰：「歸謝袁本初，兄弟不能相容，而能容天下國士乎？」

**释读** 张绣原愿许袁，贾诩当众请使者说袁绍兄弟不相容，不能包容天下士。

**归年** 同一次建安四年张绣择归。

<a id="sgz010-b-527-11"></a>

**[《三国志·二荀贾传》仓内原文 L527](../../sources/本地分卷/三国志/三国志-卷010.md#l527)**

> 繡驚懼曰：「何至於此！」竊謂詡曰：「若此，當何歸？」詡曰：「不如從曹公。」繡曰：「袁彊曹弱，又與曹爲讎，從之如何？」

**释读** 张绣惊贾诩直拒，私问该往哪里。贾诩主张从曹，张绣担心袁强曹弱且曹与己有仇。

**归年** 建安四年官渡布防后、张绣归曹前。

<a id="sgz010-b-527-12"></a>

**[《三国志·二荀贾传》仓内原文 L527](../../sources/本地分卷/三国志/三国志-卷010.md#l527)**

> 詡曰：「此乃所以宜從也。夫曹公奉天子以令天下，其宜從一也。紹彊盛，我以少衆從之，必不以我爲重。曹公衆弱，其得我必喜，其宜從二也。夫有霸王之志者，固將釋私怨，以明德於四海，其宜從三也。願將軍無疑！」

**释读** 曹操奉天子，有不足之众会重张绣，欲成霸王也须释私怨；袁绍强盛反不重少兵。贾诩请张绣决定归曹。

**归年** 《通鉴》卷063 L105–116在建安四年十一月降前详三项理由。

<a id="sgz010-b-527-13"></a>

**[《三国志·二荀贾传》仓内原文 L527](../../sources/本地分卷/三国志/三国志-卷010.md#l527)**

> 繡從之，率衆歸太祖。太祖見之，喜，執詡手曰：「使我信重於天下者，子也。」

**释读** 张绣归曹，曹操欣喜执贾诩手，说能使自己取信天下是他的功劳。

**归年** 卷001 L46、《通鉴》卷063 L116–118明确建安四年冬十一月。

<a id="sgz010-b-527-14"></a>

**[《三国志·二荀贾传》仓内原文 L527](../../sources/本地分卷/三国志/三国志-卷010.md#l527)**

**释读** 曹操表贾诩任执金吾、封都亭侯。

**归年** 《三国志·孙策传》建安四年破刘勋。

<a id="sgz055-b-2605-7"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2605](../../sources/本地分卷/三国志/三国志-卷055.md#l2605)**

> 從討劉勳於尋陽，進攻黃祖於沙羨，還鎮石城。

**释读** 从孙策在寻阳讨刘勋而进击沙羡，之后归石城。

**归年** 《孙破虏传》叙袁术死后西袭刘勋。《太祖纪》建安四年冬刘勋降操，《通鉴》卷063同系199。

<a id="sgz055-b-2614-3"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2614](../../sources/本地分卷/三国志/三国志-卷055.md#l2614)**

**释读** 韩当随军打败刘勋、黄祖。

**归年** 《太祖纪》建安四年刘勋来降，《通鉴》卷063将连贯战事置199。

<a id="sgz055-b-2617-3"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2617](../../sources/本地分卷/三国志/三国志-卷055.md#l2617)**

**释读** 蒋钦参与继庐江之后的豫章战事。

**归年** 《资治通鉴》卷063接在建安四年讨刘勋之后。

<a id="sgz055-b-2622-4"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2622](../../sources/本地分卷/三国志/三国志-卷055.md#l2622)**

**释读** 从军攻皖、江夏，经豫章授宜春长并食其租赋。

**归年** 《孙破虏传》及《通鉴》卷063记为199同一西征；补官附战后。

<a id="sgz055-b-2627-3"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2627](../../sources/本地分卷/三国志/三国志-卷055.md#l2627)**

**释读** 孙策破刘勋后挑出庐江精兵，令陈武统率。

**归年** 《太祖纪》与《通鉴》同系建安四年。

<a id="sgz055-b-2632-3"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2632](../../sources/本地分卷/三国志/三国志-卷055.md#l2632)**

> 從策攻皖，又討劉勳於尋陽，伐黃祖於江夏。

**释读** 董袭参加对刘勋和黄祖的战事。

**归年** 《孙破虏传》《资治通鉴》并系建安四年。

<a id="sgz049-b-2388-1"></a>

**[《三国志·刘繇太史慈士燮传》仓内原文 L2388](../../sources/本地分卷/三国志/三国志-卷049.md#l2388)**

**释读** 孙策经豫章收载刘繇之丧。

**归年** 《通鉴》卷063记建安四年孙策讨刘勋、黄祖后定豫章，与此吻合。

<a id="sgz049-p-008-2"></a>

**[《三国志·刘繇太史慈士燮传》裴注 008·2](../../sources/摘录/三国志-卷049-刘繇太史慈士燮传裴注.md#pei-008-2)**

**释读** 太史慈回报后，孙策有兼并图谋，继而实取豫章。

**归年** 《通鉴》卷063建安四年孙策讨刘勋还而定豫章。

<a id="sgz050-b-2419-2"></a>

**[《三国志·妃嫔传》仓内原文 L2419](../../sources/本地分卷/三国志/三国志-卷050.md#l2419)**

> 漢末，其母攜將徙廬江，廬江為孫策所破，皆東渡江，以美麗得幸於權，寵冠後庭。

**释读** 从移居庐江改往江东；随后步氏得孙权宠爱。

**归年** 《孙破虏传》《通鉴》卷063建安四年孙策攻皖，步氏受宠不必同年。

### 34. 孔融忧袁军难克，荀彧分析其内忧

[返回正文第34条](#sgz-event-34)

<a id="sgz010-b-508-4"></a>

**[《三国志·二荀贾传》仓内原文 L508](../../sources/本地分卷/三国志/三国志-卷010.md#l508)**

> 孔融謂彧曰：「紹地廣兵彊；田豐、許攸，智計之士也，爲之謀；審配、逢紀，盡忠之臣也，任其事；顏良、文醜，勇冠三軍，統其兵：殆難克乎！」

**归年** 《通鉴》卷063 L91–100系建安四年八月进军黎阳前。

<a id="sgz010-b-508-5"></a>

**[《三国志·二荀贾传》仓内原文 L508](../../sources/本地分卷/三国志/三国志-卷010.md#l508)**

> 彧曰：「紹兵雖多而法不整。田豐剛而犯上，許攸貪而不治。審配專而無謀，逢紀果而自用，此二人留知後事，若攸家犯其法，必不能縱也，

**释读** 荀彧说袁军无章，田丰刚而犯上，许攸贪，審配专、逢纪果而自用；许家若犯法，以他们留后必追查。

**归年** 同次建安四年评议。

<a id="sgz010-b-508-6"></a>

**[《三国志·二荀贾传》仓内原文 L508](../../sources/本地分卷/三国志/三国志-卷010.md#l508)**

> 不縱，攸必爲變。顏良、文醜，一夫之勇耳，可一戰而禽也。」

**释读** 荀彧料许攸会因家人被惩背袁，颜良文丑仅匹夫之勇，一战可擒。

**归年** 《通鉴》卷063 L94–100，预言应验在200年。

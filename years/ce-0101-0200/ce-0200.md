1. **车骑将军董承、偏将军王服、越骑校尉种辑受密诏诛曹操，事泄。** 五年春正月，车骑将军董承、偏将军王服、越骑校尉种辑受密诏诛曹操，事泄。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **曹操杀董承等，夷三族。** 壬午，曹操杀董承等，夷三族。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **立皇子冯为南阳王。** 秋七月，立皇子冯为南阳王。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **南阳王冯薨。** 壬午，南阳王冯去世。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **日有食之。** 九月庚午朔，发生日食。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **诏三公举至孝二人，九卿、校尉、郡国守、相各一人。** [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **皆上封事，靡有所讳。** [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **曹操与袁绍战於官度，绍败走。** 曹操与袁绍战于官度，绍败走。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **有星孛於大梁。** 冬十月辛亥，有星孛于大梁。 [[9]](#hh-note-9)

<a id="hh-event-10"></a>

10. **东海王祗薨。** 东海王祗去世。 [[10]](#hh-note-10)

<a id="hh-event-11"></a>

11. **是岁，孙策死，弟权袭其余业。** 当年，孙策死，弟权袭其余业。 [[11]](#hh-note-11)

<a id="hh-event-12"></a>

12. **郑玄在元城去世。** 袁绍与曹操相拒官渡时，袁谭逼郑玄随军，郑玄抵元城后病重，六月死，临终要求薄葬。 [[12]](#hh-note-12)

<a id="hh-event-13"></a>

13. **曹操东征刘备。** 刘备杀车胄据沛，曹操亲征；袁绍未采纳田丰趁虚进兵的建议。 [[13]](#hh-note-13)

<a id="hh-event-14"></a>

14. **赵媛姜掩护盛道逃狱。** 盛道聚众兵败，夫妻入狱。赵媛姜劝丈夫设法逃走，自己留下抵罪。 [[14]](#hh-note-14)

<a id="hh-event-15"></a>

15. **还共击璋，蜀郡、广汉、犍为皆反应。** 建安五年，还共击璋，蜀郡、广汉、犍为皆反应。 [[15]](#hh-note-15)

<a id="hh-event-16"></a>

16. **日有蚀之。** 建安五年九月庚午朔，发生日食。 [[16]](#hh-note-16)

<a id="sg-event-17"></a>

17. **公曰“夫刘备”。** 公曰：「夫刘备，人杰也，今不击，必爲后患。袁绍虽有大志，而见事遟，必不动也。」 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **郭嘉亦劝公，遂东击备。** 郭嘉亦劝公，遂东击备，破之，生禽其将夏侯博。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **备走奔绍，获其妻子。** [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **备将关羽屯下邳，复进攻之。** 备将关羽屯下邳，复进攻之，羽降。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **昌狶叛爲备，又攻破之。** [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **公还官渡，绍卒不出。** [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **白马、延津之战。** 袁绍派颜良围白马。曹操采荀攸分兵引开袁军之计，命张辽、关羽进击，颜良被杀；随后在延津再破文丑。 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **汝南降贼刘辟等叛应绍。** 汝南降贼刘辟等叛应绍，略许下。 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **绍使刘备助辟，公使曹仁击破之。** [[25]](#sg-note-25)

<a id="sg-event-26"></a>

26. **备走，遂破辟屯。** [[26]](#sg-note-26)

<a id="sg-event-27"></a>

27. **官渡相持期间曹操未南救张羡。** 曹操受官渡战事牵制，未能南下援助张羡；张羡病死后张怿被刘表击败。 [[27]](#sg-note-27)

<a id="sg-event-28"></a>

28. **官渡相持期间刘备略许下。** 曹操与袁绍相持，刘备为袁绍游兵入许下，关羽此时脱离曹操回归刘备。 [[28]](#sg-note-28)

<a id="sg-event-29"></a>

29. **曹公东征，先主奔袁绍。** 建安五年，曹公东征，先主奔袁绍。 [[29]](#sg-note-29)

<a id="wu-event-30"></a>

30. **曹操烧掉与袁绍通信的书札。** 曹操缴获许都及军中人员写给袁绍的书信，全部焚毁。 [[30]](#wu-note-30)

<a id="wu-event-31"></a>

31. **刘备再次入汝南，共都附从。** 官渡败前，袁绍另派刘备去汝南，当地共都一部响应。 [[31]](#wu-note-31)

<a id="wu-event-32"></a>

32. **蔡扬败于汝南。** 曹操曾派蔡扬攻共都，在汝南败丧。 [[32]](#wu-note-32)

<a id="sgz-event-33"></a>

33. **阎柔遣使归曹操、任护乌丸校尉。** 曹操与袁绍在官渡相持时，阎柔遣使受命，升护乌丸校尉。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **鲜于辅亲见曹操、还镇幽州。** 鲜于辅本人来见曹操，得度辽将军、亭侯，回镇本州。 [[34]](#sgz-note-34)

<a id="sgz-event-35"></a>

35. **沮授谋还袁氏被杀。** 沮授后来谋归袁氏，被杀。 [[35]](#sgz-note-35)

<a id="sgz-event-36"></a>

36. **田丰谏勿速战，遭囚。** 袁绍南进前，田丰劝据险结合豪杰、修农战，以奇兵迭扰河南使曹军疲敝；袁绍不从，认为田丰沮众而将他械系。 [[36]](#sgz-note-36)

<a id="sgz-event-37"></a>

37. **袁绍兵败后杀田丰。** 田丰判断袁军战败自己必死。袁绍归军，自言因不用田丰之言遭讥笑，遂杀田丰。 [[37]](#sgz-note-37)

<a id="sgz-event-38"></a>

38. **官渡相持时刘表两不出兵。** 官渡相持时袁绍求助，刘表答应但未出兵，也未帮助曹操，想自保江汉以观变化。 [[38]](#sgz-note-38)

<a id="sgz-event-39"></a>

39. **韩嵩、刘先、蒯越劝刘表附曹操。** 韩嵩、刘先说刘表握重兵，却难以保持中立，曹操极可能胜袁绍、势进江汉，归附可保自身及后代。蒯越也加入劝说。 [[39]](#sgz-note-39)

<a id="sgz-event-40"></a>

40. **刘表遣韩嵩赴曹，韩嵩返后被疑。** 刘表犹豫，遣韩嵩探曹操虚实。韩嵩返后称曹操威德，劝遣子入质。刘表疑其反为曹说话，欲杀韩嵩，审治并杀部分随从后知其无异志，停止。 [[40]](#sgz-note-40)

<a id="sgz-event-41"></a>

41. **陈琳为袁绍发布讨曹檄文的开头。** 檄文以赵高、吕氏乱政为比，借剪除乱臣论臣下可临机立权。 [[41]](#sgz-note-41)

<a id="sgz-event-42"></a>

42. **陈琳檄追述曹操父祖与早年战事。** 檄文攻击曹氏谱系和曹腾、曹嵩，称袁绍讨宦官、董卓及与曹操合作，举曹的早期败事、袁绍帮扶和曹操杀边让等罪名。 [[42]](#sgz-note-42)

<a id="sgz-event-43"></a>

43. **陈琳檄指控曹操迎帝后专权。** 檄文借献帝东归、迁许指责曹操专权、拷讯杨彪、滥杀赵彦、发掘梁孝王墓等，称朝政与舆情受制。 [[43]](#sgz-note-43)

<a id="sgz-event-44"></a>

44. **陈琳檄陈战局并号召出兵。** 檄文回顾上年围公孙瓒、引兵渡河一节，列举将从并、青、荆诸地向曹操进兵，末称捍卫汉室须将士尽力；裴注标明陈琳所作。 [[44]](#sgz-note-44)

<a id="sgz-event-45"></a>

45. **《傅子》述韩嵩赴许、回荆州遭囚。** 韩嵩临行言若在许受官、成天子之臣，不能仍死节刘表。赴许授侍中、零陵太守，返后主张刘表奉曹。刘表欲杀，蔡氏以其言直劝阻，终囚之。 [[45]](#sgz-note-45)

<a id="sgz-event-46"></a>

46. **官渡败后逢纪谗田丰，曹操评其策。** 袁军溃败而叹未用田丰，逢纪说田丰为应验而笑，袁绍遂欲杀之。曹操先闻田丰未从征断言袁必败，后说若用田丰尚未可知。 [[46]](#sgz-note-46)

<a id="sgz-event-47"></a>

47. **曹仁在鸡洛山击破韩荀。** 袁绍别将韩荀袭断西道，曹仁于鸡洛山大破其军，袁绍遂不敢再分兵。 [[47]](#sgz-note-47)

<a id="sgz-event-48"></a>

48. **张飞娶夏侯霸从妹。** 建安五年，夏侯霸从妹年十三四外出采樵，被张飞带走，张飞知道她出身良家而娶为妻。 [[48]](#sgz-note-48)

<a id="sgz-event-49"></a>

49. **严象为庐江太守李术所杀。** 严象建安五年被孙策所置庐江太守李术杀害，享年三十八。 [[49]](#sgz-note-49)

<a id="sgz-event-50"></a>

50. **徐琨随孙权攻李术，受封广德侯。** 徐琨领兵破李术，后任平虏将军。 [[50]](#sgz-note-50)

<a id="sgz-event-51"></a>

51. **乐进、于禁等渡河北攻获嘉。** 乐进渡河攻获嘉后返军。 [[51]](#sgz-note-51)

<a id="sgz-event-52"></a>

52. **曹操用何夔守城父。** 何夔出为城父令。 [[52]](#sgz-note-52)

<a id="sgz-event-53"></a>

53. **曹操表征华歆，孙权犹豫。** 曹操在官渡时表汉帝征华歆，孙权不愿放行。 [[53]](#sgz-note-53)

<a id="sgz-event-54"></a>

54. **曹操表征华歆，孙权遣行。** 华歆称去许可以为孙权巩固与曹操的关系，孙权欣然送他去。 [[54]](#sgz-note-54)

<a id="sgz-event-55"></a>

55. **华歆辞还送行者馈礼。** 千余故旧送行，赠达数百金。 [[55]](#sgz-note-55)

<a id="sgz-event-56"></a>

56. **曹操任张纮为会稽东部都尉。** 曹操想让张纮辅孙权归附内地，派他出任会稽东部都尉。 [[56]](#sgz-note-56)

<a id="sgz-event-57"></a>

57. **孙权派张纮赴会稽东部。** 有人怀疑张纮曾受北方任命，孙权仍信任，派他到所领之部。 [[57]](#sgz-note-57)

<a id="sgz-event-58"></a>

58. **程昱以七百人守鄄城拒袁绍。** 曹操拟加两千守卒。程昱认为少兵反使敌轻视绕过，袁绍果然未攻，曹操称其胆过孟贲、夏育。 [[58]](#sgz-note-58)

> 獻帝春秋曰董承之誅伏后與父完書言司空殺董承帝方為報怨完得書以示彧彧惡之久隐而不言完以示妻弟樊普普封以呈太祖太祖隂為之備

**释读** 董承被杀后，伏皇后与父伏完书，说曹操杀董承、皇帝欲报怨。伏完给荀彧看，荀彧不喜并隐匿，伏完亲族传书到曹操。

**归年** 董承在建安五年正月被杀，注以同事发端。《后汉书·伏皇后纪》同写因董承而致书；荀彧参与属裴松之所嫌诬说。

### 58. 程昱以七百人守鄄城拒袁绍

[返回正文第58条](#sgz-event-58)

<a id="sgz014-b-685-8"></a>

**[《三国志·程郭董刘蒋刘传》仓内原文 L685](../../sources/本地分卷/三国志/三国志-卷014.md#l685)**

> 袁紹在黎陽，將南渡。時昱有七百兵守鄄城，太祖聞之，使人告昱，欲益二千兵。昱不肯，曰：「袁紹擁十萬眾，自以所向無前。今見昱兵少，必輕易不來攻。若益昱兵，過則不可不攻，攻之必克，徒兩損其勢。原公無疑！」太祖從之。紹聞昱兵少，果不往。太祖謂賈詡曰：「程昱之膽，過於賁、育。」

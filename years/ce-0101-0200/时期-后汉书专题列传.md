# 循吏、宦官、学者及其他人物

[本世纪目录](README.md) · [全部世纪](../README.md) · [《后汉书》分卷目录](../../拆分史书/后汉书/README.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **循吏总叙及卫飒。** 序言写两汉地方吏治及光武帝择任郡守。卫飒在桂阳推学校婚礼、修通道路，减少行旅劳扰，后因病交还印绶。 [[1]](#note-1)

<a id="event-2"></a>

2. **任延。** 任延在会稽礼遇士人，在九真推广耕作、婚礼，调任武威后既抵御边患也修治教育。他以公正拒绝刻意讨好上官，后来任河内太守。 [[2]](#note-2)

<a id="event-3"></a>

3. **王景治河汴。** 王景好数术，父亲王閎曾助平乐浪。黄河、汴渠水患积久，王景与王吴承命修渠筑堤，以水门调节；又任徐州刺史、庐江太守，发展农业并讨论都洛制度。 [[3]](#note-3)

<a id="event-4"></a>

4. **秦彭及王涣。** 秦彭在山阳以礼教、乡老和水田治理地方，后任颍川太守。王涣为洛阳令善断积案，死后百姓祭奠，邓太后表扬其政，赐其子财物。 [[4]](#note-4)

<a id="event-5"></a>

5. **许荆、孟尝与第五访。** 许荆长于调解地方纠纷，进入桂阳以礼整顿风俗；孟尝在合浦革除贪弊，恢复贸易及采珠旧业，传以珠还写政绩。第五访为守时劝民生产、储粮备荒，并礼遇士人。 [[5]](#note-5)

<a id="event-6"></a>

6. **刘矩、刘宠及刘氏后辈。** 刘矩居乡任官重教化，升任太尉后为灾异和边患所累。刘宠任会稽太守去苛政，离任时只象征收受父老一钱；其后辈刘岱、刘繇在汉末分别任州牧刺史。 [[6]](#note-6)

<a id="event-7"></a>

7. **仇览、童恢与赞。** 仇览以宽厚感化乡里，有人诉儿不孝，他劝母子亲睦。童恢治不其劝农、理狱，传附处置伤人之虎的故事；赞以地方官能体察民情为主旨。 [[7]](#note-7)

<a id="event-8"></a>

8. **董宣、樊晔与李章。** 董宣依法惩办湖阳公主家奴，拒绝在公主前屈服，死时家贫。樊晔治郡用法严厉而郡境安定；李章平定盗乱，办案中也有严酷手段。 [[8]](#note-8)

<a id="event-9"></a>

9. **周纡。** 周纡强项直言，处断多峻，弹劾窦瑰，一度因审讯致伤及皇帝亲录狱囚被降职，后任将作大匠。 [[9]](#note-9)

<a id="event-10"></a>

10. **黄昌。** 黄昌从县吏起，能辨奸伪，也以重法治豪强；其断案既有察微明情的事例，也有因私愤杀妇人的记载。 [[10]](#note-10)

<a id="event-11"></a>

11. **阳球与王吉。** 阳球以苛法治人，出任司隶校尉后劾王甫、王吉，后因宦官反击获罪。王吉任沛相擅断积狱，也搜录民间细过并滥杀。 [[11]](#note-11)

<a id="event-12"></a>

12. **酷吏史论。** 范晔比较严刑与宽政，指出酷吏的才能可短期抑制奸猾，日久却容易损害仁信根本。 [[12]](#note-12)

<a id="event-13"></a>

13. **宦者序、郑众与蔡伦。** 序说明宦官职掌及后宫、幼主政治中的权力来源。郑众助和帝夺窦氏权而封侯；蔡伦从宫中受事升至中常侍，改进造纸用料，后监校经传，安帝亲政后坐旧案自尽。 [[13]](#note-13)

<a id="event-14"></a>

14. **孙程、曹腾。** 孙程等迎立济阴王，是为顺帝，十九人同日受封，后来因替虞诩诉冤等事反复出入封国。曹腾久居宫中，荐引名士，桓帝立后受封，身后由养子曹嵩嗣。 [[14]](#note-14)

<a id="event-15"></a>

15. **五侯与小黄门。** 单超、徐璜、具瑗、左悺、唐衡参与桓帝诛梁冀，同时封侯，亲族侵暴州郡。数人后遭弹劾，家族及封爵受到不同处置。 [[15]](#note-15)

<a id="event-16"></a>

16. **侯览、曹节与王甫。** 侯览倚势占田宅，张俭弹劾遭阻，后侯览被追收印绶自尽。曹节、王甫参与迎灵帝和反击窦武、陈蕃；王甫及其养子后为阳球劾治，曹节仍执政至死。 [[16]](#note-16)

<a id="event-17"></a>

17. **吕强进谏。** 吕强辞封，劝灵帝抑宦官贪敛、正用人和财政，又在黄巾起事后请赦党人。他被赵忠等诬构后自尽，亲属受牵连。 [[17]](#note-17)

<a id="event-18"></a>

18. **张让、赵忠与宦官败亡。** 张让、赵忠受灵帝宠信，聚敛营建。何进谋清除中官，事泄被杀，袁绍等入宫捕宦官，张让挟帝出逃，终投河而死。范晔追究内官得势、外臣结党与政局崩坏的过程。 [[18]](#note-18)

<a id="event-19"></a>

19. **东汉经学与太学。** 王莽、刘玄乱后典籍流散，光武搜求文献，招纳诸儒，立五经博士、开太学；明帝、章帝延续讲经、校定不同经说的政策。 [[19]](#note-19)

<a id="event-20"></a>

20. **刘昆至戴凭。** 刘昆传《施氏易》，出守江陵。洼丹、任安、杨政、张兴各有经学传授，杨政曾为师范升申辩；戴凭善说《京氏易》，以辩经重席著称。 [[20]](#note-20)

<a id="event-21"></a>

21. **孙期至周防。** 孙期在乡授徒而不应征举；欧阳歙家传《尚书》，弟子请为其赎罪。牟长、宋登、张驯、尹敏、周防各有授经、议礼与仕履，尹敏参与校图谶而指出其中杂谬。 [[21]](#note-21)

<a id="event-22"></a>

22. **孔僖至魏应。** 孔僖与崔骃议论武帝被告，后仍受章帝任用。杨伦治《尚书》，高诩、包咸、魏应以经义受业和教授，包咸曾为明帝讲学，魏应主持白虎观问难。 [[22]](#note-22)

<a id="event-23"></a>

23. **伏恭至赵晔。** 伏恭承家传《齐诗》，任末重师义，景鸾兼通经术，薛汉、杜抚所授《韩诗》各有传本。召驯、杨仁服官以授经见知，赵晔以穷研经学并述吴越史事闻名。 [[23]](#note-23)

<a id="event-24"></a>

24. **卫宏至程曾。** 卫宏作《毛诗序》及仪制旧事，董钧、丁恭、周泽以讲经明礼受用。孙堪刚介，钟兴、甄宇、楼望、程曾讲《春秋》各有师承，甄宇故事关涉博士推礼。 [[24]](#note-24)

<a id="event-25"></a>

25. **张玄至蔡玄及史论。** 张玄、李育、何休在经书今古学间各有取舍，服虔、颍容、谢该解《左氏》，许慎辨五经异说并著《说文解字》。史论肯定经学复兴的教化作用，也指出门户争论和繁琐章句的弊端。 [[25]](#note-25)

<a id="event-26"></a>

26. **杜笃与《论都赋》。** 杜笃在狱中为吴汉作诔，以文得宥；其赋从地势、交通与西汉经营之功论长安，为关中旧都争地位。其后列家人仕履。 [[26]](#note-26)

<a id="event-27"></a>

27. **王隆、夏恭与傅毅。** 王隆、夏恭以文章与经学见称。傅毅论求贤，《迪志诗》自述志操，任兰台令史掌文书，又与班固等同事。 [[27]](#note-27)

<a id="event-28"></a>

28. **黄香至王逸。** 黄香少时孝行与文章并闻，任尚书令掌密命、后治魏郡。刘毅、李尤、苏顺、刘珍、葛龚、王逸各以文章受用，传并记兰台、东观、碑铭、经籍校理及《楚辞》。 [[28]](#note-28)

<a id="event-29"></a>

29. **崔琦、边韶与张升。** 崔琦用赋与诗劝戒梁冀而终遭杀害；边韶以歌谐应弟子揶揄，兼传教学与校书。张升轻权贵而重意气，终以吏事得罪。 [[29]](#note-29)

<a id="event-30"></a>

30. **赵壹及《刺世疾邪赋》。** 赵壹先后遭罪与赦免，获皇甫规夫妇等援助，后名闻京师。其赋借宾主对话及诗歌直言当世邪正倒置、文士易受压抑。 [[30]](#note-30)

<a id="event-31"></a>

31. **刘梁论和同。** 刘梁论王道政治及交友“和”与“同”的区分，认为礼义上的相和与徇情苟同有别。篇末附录家世及同时以文才著称者。 [[31]](#note-31)

<a id="event-32"></a>

32. **边让与郦炎。** 边让以辩才受何进征辟，传收《章华赋》；郦炎不应辟命，以诗表达志气，后陷狱而死。 [[32]](#note-32)

<a id="event-33"></a>

33. **侯瑾、高彪、张超及祢衡。** 侯瑾著《汉皇德传》，高彪工文赋且以诗箴寓劝戒，张超善文与草书。祢衡因才气凌人，历经曹操、刘表而被黄祖杀害；篇赞说明文章应与情志相发。 [[33]](#note-33)

<a id="event-34"></a>

34. **独行序及谯玄、李业。** 发端解释狂狷之行，取其有所守。谯玄曾拒王莽征召，公孙述强召时更不受；李业拒仕公孙述，不受威逼而死。 [[34]](#note-34)

<a id="event-35"></a>

35. **刘茂至周嘉。** 刘茂在战乱中保全郡守，温序不屈于叛军，彭修舍身护郡守，索卢放为郡守争免死罪，周嘉奋身护太守。所载多在险急时见臣属之义。 [[35]](#note-35)

<a id="event-36"></a>

36. **范式至陆续。** 范式践友约、奔丧，李善扶养主人遗孤并保全宗祀，王忳收葬异乡死者，张武守亲丧，陆续等在楚王狱中受讯，坚持不作牵连证词。 [[36]](#note-36)

<a id="event-37"></a>

37. **戴封、李充、缪肜与陈重。** 戴封待人以诚，以礼让财物闻名；李充曾召亲族劝止分产，缪肜也以自责促家人和睦。陈重善为同僚济急，并与雷义交好。 [[37]](#note-37)

<a id="event-38"></a>

38. **雷义、范冉与戴就。** 雷义举荐他人、不受救命之金，与陈重以让相成；范冉守经不阿，在穷困中仍自得；戴就受酷讯，拒绝诬陷郡吏。 [[38]](#note-38)

<a id="event-39"></a>

39. **赵苞至王烈与赞。** 赵苞因母妻遭挟持仍出战，后自伤不孝；向栩因言获罪，谅辅请为灾民求雨，刘翊在乱中周急，王烈以德使失行者自返。篇赞推崇事临危义而不失其操。 [[39]](#note-39)

<a id="event-40"></a>

40. **方术序、任文公与郭宪。** 序列卜筮、阴阳、数术、图谶的来源，提出取证之难；任文公据候变避乱，郭宪本以拒仕王莽闻名，传又附有异能故事。 [[40]](#note-40)

<a id="event-41"></a>

41. **许杨至李郃。** 许杨治理汝南水利，高获、王乔、谢夷吾、杨由、李南及李郃都有预知、察候或鉴人记载，部分以近臣或地方官的仕履与本事相连。 [[41]](#note-41)

<a id="event-42"></a>

42. **段翳、廖扶、折像、樊英。** 数人通经及阴阳术，又各有隐居与辞辟举止；樊英名重海内而在朝未有大用，史论借此讨论处士之名、实际才能与政事效率。 [[42]](#note-42)

<a id="event-43"></a>

43. **唐檀至董扶。** 唐檀、公沙穆、许曼、赵彦、樊志张、单飏、韩说、董扶的传记记录占候、风角、灾异与预言，多以某地将出现祸患或兴替为叙事线。 [[43]](#note-43)

<a id="event-44"></a>

44. **郭玉与华佗。** 郭玉承脉学，解释对贵势患者用药之难；华佗行医，多以查察病候定治法，书中还载其麻沸散、导引和医术传授，后因曹操征召而下狱死。 [[44]](#note-44)

<a id="event-45"></a>

45. **徐登至刘和平及篇末史论。** 徐登、费长房、蓟子训、刘根、左慈等所传有禁咒、幻化与延寿轶事，兼有不知本名和卒所者。篇末论赞承认其中难以核实的部分。 [[45]](#note-45)

<a id="event-46"></a>

46. **隐逸序及向长、逢萌、周党、王霸。** 序讨论避世可能出于志趣、保身与不合作等缘由。野王二老拒显于世，向长游名山，逢萌避王莽，周党、王霸在征聘和仪礼上自持。 [[46]](#note-46)

<a id="event-47"></a>

47. **严光、井丹、梁鸿与高凤。** 严光不因与光武有旧而受官，归耕富春；井丹以经学和游处闻名，梁鸿与孟光相敬、迁居隐身，高凤专心读书并拒任官职。 [[47]](#note-47)

<a id="event-48"></a>

48. **台佟至庞公及赞。** 台佟以采药自养，韩康卖药守价而避名，矫慎、戴良、法真各重简约；两位老父、庞公以寓言式言语昭示不求利禄，篇赞言远俗保志。 [[48]](#note-48)

<a id="event-49"></a>

49. **桓少君、王霸妻、姜诗妻与赵阿。** 桓少君放下厚妆与鲍宣共守简朴；王霸妻劝以志节自安，姜诗妻侍养与行善事见乡里，赵阿的故事同载于孝义篇章。 [[49]](#note-49)

<a id="event-50"></a>

50. **班昭续《汉书》与《女诫》。** 班昭奉诏在东观接续兄班固未成的《汉书》；受召入宫教授皇后和诸贵人，曾为兄班超请归。其《女诫》论当时妇女所受家教及行为规范，反映汉代男女礼教观念。 [[50]](#note-50)

<a id="event-51"></a>

51. **乐羊子妻至马伦。** 乐羊子妻以断织劝夫终学；李穆姜抚养前妻子女，曹娥寻溺亡之父而投江，吕荣、马伦各以守义、辞辩见载，所记处境有别。 [[51]](#note-51)

<a id="event-52"></a>

52. **赵娥至叔先雄。** 赵娥为父报仇而自首；桓氏、皇甫规妻等应对家族变故和强权逼迫，荀采、赵媛姜的叙事突出守志，叔先雄因父溺亡而投水。 [[52]](#note-52)

<a id="event-53"></a>

53. **蔡文姬归汉与《悲愤诗》。** 蔡琰在兴平乱中为胡骑所虏，居南匈奴十二年并育二子，后由曹操赎回。她为董祀求情，又追忆所记父亲藏书。传录两篇抒写乱离、归还与母子分离的诗。 [[53]](#note-53)

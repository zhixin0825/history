# 中后期官吏、经学及士林

[本世纪目录](README.md) · [全部世纪](../README.md) · [《后汉书》分卷目录](../../sources/后汉书读本目录.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **左雄以限年、复试改察举。** 左雄为刺史劾贪郡守，入尚书后上疏定孝廉年龄并分科试才，查办违令郡国；又反对笞辱九卿，要求朝廷按职分行礼。 [[1]](#note-1)

<a id="event-2"></a>

2. **周举清政、治禁火旧俗与议灾。** 周举任刺史以书晓谕太原因介子推而长期禁火的居民，救其寒害。入朝后反复论灾异、外戚、宦官与选官，推举人才而拒徇私。 [[2]](#note-2)

<a id="event-3"></a>

3. **周勰隐居与宾客之谋。** 周勰放弃官职，家人与旧吏因其父旧事谋起兵，图谋未成，另记地方官处置始末。 [[3]](#note-3)

<a id="event-4"></a>

4. **黄琼从辞征到议郎与三公。** 黄琼以礼命入朝，答策律历、奏议制度；与梁氏权势的往还、三公迁罢、举贤黜恶和遭宦官挤压，一贯兼见借重与抵拒。 [[4]](#note-4)

<a id="event-5"></a>

5. **黄琬议日食与董卓政局。** 黄琬幼时以初生月形比喻日食后太阳仍可见的部分，后任州郡与三公，反对董卓迁都，参与谋诛董卓，李傕攻入长安后遇害。末论察举进退有制度责任。 [[5]](#note-5)

<a id="event-6"></a>

6. **荀淑清议与荀氏诸子。** 荀淑不以章句见长，却以识人和直节闻名。受梁冀排斥而任朗陵侯相，死后士人追怀；荀昱、荀昙等亦见党祸相关事。 [[6]](#note-6)

<a id="event-7"></a>

7. **荀爽著经与董卓征召。** 荀爽早通经学，议礼制、冠婚与丧葬，党禁时隐处著书；董卓后强征使位至司空，荀爽暗中谋去卓，旋病卒。 [[7]](#note-7)

<a id="event-8"></a>

8. **荀悦奉诏作《汉纪》及《申鉴》。** 荀悦在献帝旁讲论，奉命仿《左传》体撰《汉纪》；《申鉴》所引长文把政治弊害、权臣与制度约束相联。 [[8]](#note-8)

<a id="event-9"></a>

9. **韩韶开仓、钟皓授业与后人。** 韩韶为嬴县长时开仓救流亡人，承担擅发官粮责任；子韩融以辩论知名。钟皓长于经律，因清议辞辟，后人见附传。 [[9]](#note-9)

<a id="event-10"></a>

10. **陈寔及陈纪、陈谌。** 陈寔由县吏至太丘长，处理乡争务公平，党狱愿与同道共受。陈纪、陈谌有孝友声，董卓强征后陈纪亦曾上疏反对迁都。 [[10]](#note-10)

<a id="event-11"></a>

11. **颍川士行论赞。** 范晔把党禁时代士人声望与各自实际政行对看，借陈寔、韩韶等说明乡里教化与在官救民可以并存。 [[11]](#note-11)

<a id="event-12"></a>

12. **李固陈政与任地方官。** 李固博学能言，以灾异对策警告权贵外戚挠政。历任郡县时安抚盗贼，宽减苛细，后入朝居三公。 [[12]](#note-12)

<a id="event-13"></a>

13. **李固争立清河王、遇梁冀迫害。** 冲帝、质帝先后死，李固主张立年长有德的清河王刘蒜，梁冀联宦官改立桓帝。李固罢官，又因刘文等欲立刘蒜案被牵连处死。 [[13]](#note-13)

<a id="event-14"></a>

14. **李燮避难和李固定冤。** 李固幼子李燮由姊与门人营救，潜匿佣作，梁氏伏诛后归里，成年以经行历任地方和朝廷职务。 [[14]](#note-14)

<a id="event-15"></a>

15. **杜乔与李固共争立嗣。** 杜乔巡察兖州奏劾贵幸，任太尉后与梁冀争帝位人选，因不肯向权家输送亲党而罢。其与李固同死，门生为收尸丧葬而争。 [[15]](#note-15)

<a id="event-16"></a>

16. **吴佑和厚治民。** 吴佑早劝父不要因制作大批竹简招惹权贵猜疑。为胶东相等官，问民疾苦，重乡里调解，明刑而矜恕。 [[16]](#note-16)

<a id="event-17"></a>

17. **延笃经学、去官与答书。** 延笃师承《左氏传》，入朝掌校书并任郡县地方官；传录书信论孝、学及出处，晚遭党禁归田。 [[17]](#note-17)

<a id="event-18"></a>

18. **史弼抗梁冀余势与解党狱。** 史弼不肯以滥捕邀功，又遭贵势构陷。平原人出资助其出狱，作者比较史弼刚直与吴佑仁厚。 [[18]](#note-18)

<a id="event-19"></a>

19. **卢植治经、讨黄巾及抗董卓。** 卢植从马融学经，编定礼经、疏陈学术与选任。讨黄巾时未能即克广宗，为宦者进谗被罢；董卓议废少帝，他抗言后归隐。 [[19]](#note-19)

<a id="event-20"></a>

20. **赵岐避祸、使诸镇及著述。** 赵岐为唐衡家所迫，外逃受孙嵩保护。后为朝廷使者晓谕关东诸镇，献帝东归亦有劳，著《孟子章句》等。 [[20]](#note-20)

<a id="event-21"></a>

21. **皇甫规守边与清察附党。** 皇甫规预见羌军动向，被弃言后仍率众抗敌。任护羌将领时先抚降诸部，又劾边吏贪虐致反，朝中避宦权、主动称助护党人。 [[21]](#note-21)

<a id="event-22"></a>

22. **张奂边镇功与宫变后引咎。** 张奂曾安置归降羌胡、拒受馈赠，后守度辽及北边。灵帝初被宦官利用参与击窦武，事后求削赏，营救获罪之家。 [[22]](#note-22)

<a id="event-23"></a>

23. **段颎东西羌战役及边策。** 段颎与皇甫规、张奂并称凉州三明，关于羌乱一主追击、一主招抚。传中按部署述西羌及东羌诸战，叙获爵、从宦官及死狱。 [[23]](#note-23)

<a id="event-24"></a>

24. **陈蕃早年、礼贤及外任。** 陈蕃少有扫除天下之志，为郡守礼处士、治积狱，入朝时论外戚求取与赋役。范晔以郡政、推荐与奏议层层铺写其声望。 [[24]](#note-24)

<a id="event-25"></a>

25. **陈蕃抗宦官与窦武败局。** 陈蕃要求宽免被宦官构陷的士人。灵帝初与窦武、刘瑜谋罢宦官，曹节、王甫反制，陈蕃率属闯宫而死，其家故旧遭株连。 [[25]](#note-25)

<a id="event-26"></a>

26. **王允谋诛董卓及长安陷落。** 王允举起兵诛吏、拒赂和出逃后入朝，表面与董卓周旋，暗结吕布杀卓。未能安置凉州旧军，李傕、郭汜入长安，王允一门死。 [[26]](#note-26)

<a id="event-27"></a>

27. **王宏、士孙瑞、赵戬与论赞。** 王宏议董卓而被牵连，士孙瑞、赵戬在禁中及朝廷迁徙各有经历。范晔以正立、以谋济二语比较陈蕃、王允的政治应对。 [[27]](#note-27)

<a id="event-28"></a>

28. **党锢序及两次党祸。** 范晔从风俗、士人交游与清议写起，叙甘陵“南北部”、汝南与南阳名士之谣。李膺等首先被收系后放还禁锢；窦武、陈蕃死后，党人案再起并蔓延亲族。 [[28]](#note-28)

<a id="event-29"></a>

29. **刘淑讲学与抗议宦官。** 刘淑以五经教授闻名，任官后不愿趋附权近，在党人案件中坚持己见，死后其家受到牵连。 [[29]](#note-29)

<a id="event-30"></a>

30. **李膺整肃权贵与下狱。** 李膺历任郡守、司隶，诛宦官家属张朔。张成之子案引起第一次党祸，其后并州等地人士因避捕而死，同一禁锢案须与帝纪互证。 [[30]](#note-30)

<a id="event-31"></a>

31. **杜密、刘祐、魏朗等人的处分。** 杜密和李膺齐名，刘祐弹劾宦者，魏朗、夏馥、宗慈、巴肃各因名节与交游受牵。传中兼载避祸方式、自首与家属遭难。 [[31]](#note-31)

<a id="event-32"></a>

32. **范滂清议、解绶与赴狱。** 范滂任郡功曹斥请托，党狱初起曾对御史抗辩。再逮时自投官府，避免令长担罪，传中录其与母诀别，作者称其以洁行激风俗。 [[32]](#note-32)

<a id="event-33"></a>

33. **尹勋、蔡衍、羊陟与张俭。** 尹勋参与窦武之谋，蔡衍、羊陟以执法见称；张俭奏侯览后，侯党以结党诬奏，张俭亡命而所在争相掩护，救护者多人获罪。 [[33]](#note-33)

<a id="event-34"></a>

34. **岑晊等地方名士。** 岑晊整治宦者亲属乡里势力，陈翔、孔昱、苑康、刘儒等以品行、执法或交游列名，后各遭黜免、禁锢或逮捕。 [[34]](#note-34)

<a id="event-35"></a>

35. **贾彪劝窦武营救党人。** 贾彪为新息长，救民弃子，后入朝游说窦武等上书，使受系党人归乡；政局厄变时仍拒屈权势。 [[35]](#note-35)

<a id="event-36"></a>

36. **何颙周旋于亡命士人与汉末政局。** 何颙等联络袁绍冒险营救避祸之人。党禁解后继续在朝，参与诛董谋议，卷末论赞将党人操守置于浊世比较。 [[36]](#note-36)

<a id="event-37"></a>

37. **郭太交游、识士和乡里教化。** 郭太出身寒贫，辞县役而求学，游洛阳与李膺相善。党祸中言论有节，退而教徒，丧后四方来会，蔡邕为作碑。 [[37]](#note-37)

<a id="event-38"></a>

38. **茅容等人被郭太鉴识。** 茅容、孟敏、庾乘、宋果、贾淑、黄允、谢甄和王氏兄弟各以一言一事被品评，传文常以其后来行事验证评语。 [[38]](#note-38)

<a id="event-39"></a>

39. **郭太论赞和符融识人。** 范晔引《庄子》论识人之难，称郭太能察情伪。符融自都官吏转学，能够推荐乡里士人，后辞官归隐。 [[39]](#note-39)

<a id="event-40"></a>

40. **许劭与月旦品评。** 许劭重人伦、好奖拔，与从兄许靖评点乡党人物，以月旦评闻名。曹操求评一节保存其政治鉴识的传说，袁术、刘繇下的去留见后段。 [[40]](#note-40)

<a id="event-41"></a>

41. **窦武入辅与密谋罢宦官。** 窦武因女为皇后入外戚之列，遇桓帝崩而定策迎灵帝。数劾中常侍，奏早除宦官，消息泄露后曹节等劫持皇帝，窦武兵败自杀。 [[41]](#note-41)

<a id="event-42"></a>

42. **胡腾、张敞及窦氏余脉。** 前文写窦氏亲属被收系，幼孙窦辅由故吏胡腾、张敞保护。这里续述胡腾随桓帝出巡时约束乘势求取的权贵，胡腾解除禁锢后官至尚书，张敞是太尉张温之弟。 [[42]](#note-42)

<a id="event-43"></a>

43. **何进由外戚入辅与袁氏用事。** 何进因异母妹入宫受封，黄巾之乱中拜大将军。灵帝崩后何太后临朝，何进、袁绍等借诛宦官议集中兵权。 [[43]](#note-43)

<a id="event-44"></a>

44. **何进败死、袁绍尽诛宦者及论赞。** 何进不纳早断之说，又令董卓等入京迫太后；宦官先下手杀何进，袁绍、袁术等发兵诛戮宦官，天子奔出宫。作者合评何进、窦武借外戚得权而未能处置失机。 [[44]](#note-44)

### 15. 杜乔与李固共争立嗣

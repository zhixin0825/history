# 明章和安诸朝的政局与文献

[本世纪目录](README.md) · [全部世纪](../README.md) · [《后汉书》分卷目录](../../拆分史书/后汉书/README.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **郭躬、郭镇与郭氏世习刑律。** 郭弘在寇恂幕府决狱三十年，以平恕闻名。其子郭躬入廷尉后条陈四十一项可以从轻之重文，又请将赦减戍边推及尚未发觉的亡命者。郭镇拥立顺帝时率羽林杀阎景；后人仍有任廷尉、太尉者。 [[1]](#note-1)

<a id="event-2"></a>

2. **范晔论慎刑。** 作者以曾子“哀矜而勿喜”解释决狱之本，称郭躬体察案情、以宽恕用法，且比较郭氏子弟用刑是否尽得其意。 [[2]](#note-2)

<a id="event-3"></a>

3. **陈宠从断狱议到三公。** 陈宠继承家学，与贾宗等论冬月断狱及旱灾关系，主张按事实适用法令。任廷尉时亲自审议疑狱，请删补过严条文。其后居三公，殇帝无嗣一节及陈勤受封免职见本组。 [[3]](#note-3)

<a id="event-4"></a>

4. **陈忠论宽刑和服丧。** 陈忠任尚书后上言整理刑制，处理迁徙、亲属代罪、丧葬徭役等问题，又升司隶校尉。范晔肯定其审狱慎重，同时批评允许亲属替死会使无罪者受祸。 [[4]](#note-4)

<a id="event-5"></a>

5. **班超投笔与初通西域。** 班固入朝校书后，班超随母迁洛阳，以佣书为生。出塞后奉窦固之命出使，在鄯善袭杀匈奴使者，赴于阗改变国王态度，又在疏勒擒龟兹所立的兜题，改立本族之后。 [[5]](#note-5)

<a id="event-6"></a>

6. **班超经营南北道与抗月氏。** 班超联合诸国攻姑墨，并上疏请兵。疏勒降叛、莎车设伏及月氏副王谢进军分属不同阶段；班超兼用联盟、威慑与切断外援，随后定龟兹、姑墨、温宿，在西域建制。 [[6]](#note-6)

<a id="event-7"></a>

7. **定远侯封爵、东归及其子。** 班超封定远侯，派甘英向西出使，其年老上疏求归，班昭亦上书请求。回洛阳后不久卒，任尚接任时听取其安边主张。班始坐杀公主伏诛，班勇另有事迹。 [[7]](#note-7)

<a id="event-8"></a>

8. **班勇再开西域与车师六国。** 西域都护撤回后，敦煌派索班屯伊吾而遭袭。班勇在朝议力陈边地形势，后来出屯柳中，招徕鄯善、龟兹并收车师诸国。焉耆之役中与张朗争先，班勇以逾期获罪。 [[8]](#note-8)

<a id="event-9"></a>

9. **梁慬与何熙的边事经历。** 梁慬父梁讽曾出使匈奴而为窦宪所害；梁慬任西域副校尉时诸国反叛，参与边军撤回，后与何熙出兵。卷末的论赞将班超、梁慬视为在边疆以武略立功之人。 [[9]](#note-9)

<a id="event-10"></a>

10. **杨终论刑狱、徙民与远屯。** 杨终从郡吏入兰台校书，面对建初旱灾与粮价高昂，上疏把几次王府大狱、远屯与吏民怨苦连起来，建议收减过度惩处。他晚年继续著述，朝廷再召时病卒。 [[10]](#note-10)

<a id="event-11"></a>

11. **李法论外戚、宦官和史官。** 李法以贤良方正入朝，奏称法令苛细、外戚宦官势重，并质疑史官记录。其仕途受奏疏影响，退居及复任须依原文先后理解。 [[11]](#note-11)

<a id="event-12"></a>

12. **翟酺的合纵式进谏与兴学。** 翟酺好图纬历数，早年因报仇出亡。入朝后以言术应对孙懿，再援周公、毕公等说君主须得贤臣。为酒泉太守时击退叛羌，后在将作大匠任内议兴学校、减役省财。 [[12]](#note-12)

<a id="event-13"></a>

13. **应奉治武陵、应劭论边兵与文献。** 应奉善记人事，任武陵太守招降叛众、兴学校。应劭论乌桓和鲜卑兵力，继而击退泰山黄巾；曹嵩案后避入冀州。他整理朝廷典故、礼制和律例，《汉仪》奏报本末见下。 [[13]](#note-13)

<a id="event-14"></a>

14. **霍谞为宋光辨诬。** 霍谞年十五即为受刑的舅父宋光向梁商上书，推论所谓刊改章表难以成立。成年后仍以经术、议狱与直言见称。 [[14]](#note-14)

<a id="event-15"></a>

15. **爰延以礼化乡与直陈政事。** 爰延为乡官以教化得民心，后在朝回答帝问，直言政治得失，举荐端直之人，因不习附会而进退。 [[15]](#note-15)

<a id="event-16"></a>

16. **徐璆拒董太后请托。** 徐璆任荆州刺史，不为董太后亲属张忠隐蔽赃罪；从朱儁破宛县黄巾后仍因宦者构陷免官。献帝时期遭袁术扣留，后来持其所得国玺归朝。 [[16]](#note-16)

<a id="event-17"></a>

17. **王充的学校、读书和论衡。** 王充少孤，从班彪受学，不守章句，常在洛阳书肆读书。返乡后闭门写《论衡》，以辨世俗失实之说；后来还作《养性书》。 [[17]](#note-17)

<a id="event-18"></a>

18. **王符潜夫论所论世弊。** 王符以寒微与耿介不见用于世，作《潜夫论》。本组摘载其对于用人、考绩、侈费、边事、卜巫等议论，区别史家叙传和作者借事立论。 [[18]](#note-18)

<a id="event-19"></a>

19. **仲长统论制度兴衰。** 仲长统访高干而知其危，又曾为尚书郎、参曹操军事。所引《昌言》借古今土地、吏治与豪族问题反省政体，末附范晔对王充、王符、仲长统三家的衡量。 [[19]](#note-19)

<a id="event-20"></a>

20. **千乘哀王与陈国数世。** 千乘哀王建早卒无子。广平王刘羡后徙陈，宾客杀县令家属而受处分；陈国嗣王刘宠以祭天遭追劾，后保国于乱世，终与骆俊同遭袁术袭杀。 [[20]](#note-20)

<a id="event-21"></a>

21. **彭城王一系的徙封与狱案。** 刘恭从灵寿名号起，历封钜鹿、江陵、六安、彭城。国相赵牧借其子自杀诬奏，朝廷核实豁免，其后世系、封列侯及汉魏易代处置另叙。 [[21]](#note-21)

<a id="event-22"></a>

22. **乐成王、安平王及中平被废。** 刘党爱史书但对属人急刻，刘崇一度嗣封而获罪，后来河间王之子刘得继国并改国号安平。刘续在黄巾之乱被劫，复国后旋以不道被诛。 [[22]](#note-22)

<a id="event-23"></a>

23. **下邳惠王与梁节王。** 刘衍受章帝亲厚，下邳后世在黄巾起时出走，建安十一年国除。梁王刘畅原封汝南，受阴氏之宠；有司奏其不道，和帝削县而赦，续叙各代封嗣。 [[23]](#note-23)

<a id="event-24"></a>

24. **淮阳、常山、济阴及论赞。** 刘昞初封常山，徙淮阳后由刘侧继常山，宗藩相续至汉末。济阴刘长早亡无子。范晔借马后反对重封，讨论限诸王财权的用意。 [[24]](#note-24)

<a id="event-25"></a>

25. **李恂事舅主、为官廉约。** 李恂辞辟持丧、聚徒授《韩诗》，后来奉使与治郡拒受馈赠，因不从权近被免，困居依然坚持不取非己之财。 [[25]](#note-25)

<a id="event-26"></a>

26. **陈禅守义与夷乐之争。** 陈禅为郡功曹时受审不改其辞，入朝见百戏表演，以夹谷故事谏勿让君主公开观赏。他也在治郡与边地事务中屡被征任。 [[26]](#note-26)

<a id="event-27"></a>

27. **庞参由系徒到领边军与太尉。** 庞参在罪中遣子建言，指出涼州军役与饥荒相互加重；获起用后抚降诸羌、打通河西。移官内地仍与宦官冲突，两度入太尉。 [[27]](#note-27)

<a id="event-28"></a>

28. **陈龟察边弊、请减轻民负。** 陈龟习骑射，历任使匈奴中郎将、度辽将军等。他上书列边官扰民，求换将、减税、宽徭；后与梁冀及近习相忤，终自杀。 [[28]](#note-28)

<a id="event-29"></a>

29. **桥玄守法荐贤与知曹操。** 桥玄不避豪贵，历任边郡和三公，荐与己有旧隙的陈球。他在幼子被劫时请求依法擒贼，又因识曹操闻名。其身后清贫，范晔另议严法与人情的轻重。 [[29]](#note-29)

<a id="event-30"></a>

30. **崔篆历新莽而退处。** 崔氏先世为郡国官，崔篆辞王莽军职，任郡守时释放囚犯并因此触犯新朝法令，作《慰志赋》阐明自守。 [[30]](#note-30)

<a id="event-31"></a>

31. **崔骃入窦幕、文学与去职。** 崔骃早有文誉，《达旨》等借问答谈出处。窦宪辟之入幕而少采其直言，崔骃出任长岑长后弃官还乡，著作、卒年由本传结记。 [[31]](#note-31)

<a id="event-32"></a>

32. **崔瑗的历学、政事和家书。** 崔瑗师从贾逵，明天文历数，与张衡、马融交好。由兄仇、入吏到为济北相，政事、狱案与清俭可由两处官任互见；临终家书申明薄葬。 [[32]](#note-32)

<a id="event-33"></a>

33. **崔寔政论与四民月令。** 崔寔耻以父名求仕，历任议郎、郡守等，论重典与时弊；四时家务和地方农桑亦见传文。范晔比较三世文学、从政与自守。 [[33]](#note-33)

<a id="event-34"></a>

34. **卷序论出处。** 作者引《易》与《论语》，以出仕、退处皆须守诚为题，串联汉世不同处境的隐居者与辞聘之士。 [[34]](#note-34)

<a id="event-35"></a>

35. **周燮和冯良拒聘。** 周燮生有异貌而笃学，冯良以毁车遁去开始隐学。安帝遣郡吏备礼聘二人，两人坚持不就，其事可据诏与传文互看。 [[35]](#note-35)

<a id="event-36"></a>

36. **黄宪不著言而服人。** 黄宪出身贫贱，荀淑、戴良等见之皆折服。作者指出其言论实无传本，评价来自交游中见其品格者。 [[36]](#note-36)

<a id="event-37"></a>

37. **徐稚拒征与名士交往。** 徐稚亲耕自给，公府数辟不应，陈蕃任太守时特为他设榻，徐稚离去后便悬起。陈蕃等荐举及其归终在传文分别叙述，后及其子徐胤、同郡处士李昙。 [[37]](#note-37)

<a id="event-38"></a>

38. **姜肱兄弟与避诏。** 姜肱兄弟相敬爱，路遇劫者后又劝其改过。朝廷屡欲授官，他闭门远避，弟子后来刻石追述。 [[38]](#note-38)

<a id="event-39"></a>

39. **申屠蟠远党祸而辞命。** 申屠蟠事母、守丧及救女，传为乡里事迹。后来见党人声名可能招祸，隐居梁砀；董卓掌权时他仍未应召。 [[39]](#note-39)

<a id="event-40"></a>

40. **杨震早年、拒金与斥王圣。** 杨震出自累世通经之家，以暮夜拒金表明操守。任司徒后，上疏反对安帝乳母王圣及其亲属凭恩势出入宫禁、纳赂。 [[40]](#note-40)

<a id="event-41"></a>

41. **杨震任太尉、罢官与平反。** 杨震不应耿宝替李闰之兄求辟，反对营造耗费；被樊丰等谮免后自尽。顺帝即位后遣使祭祀、改葬，后来又追及其家封赏。 [[41]](#note-41)

<a id="event-42"></a>

42. **杨秉论李云及按劾侯览。** 杨秉为李云力争无效而免，复仕后按劾宦官亲属，晚任太尉，与同时诸公清理近习及郡县赃吏。他拒纳财物有家法可循。 [[42]](#note-42)

<a id="event-43"></a>

43. **杨赐议灾异、党禁和黄巾。** 杨赐以讲学入朝，议灾异时直陈近习、权势，论黄巾时主张预先解散流民与教众。罢复三公历程及帝追赠诏分别在段中。 [[43]](#note-43)

<a id="event-44"></a>

44. **杨彪历董卓、李傕及曹操之际。** 杨彪揭王甫门生牟利，反对董卓迁都。李傕、郭汜争斗时护从献帝，迁许后又受曹操疑忌，被孔融等营救。 [[44]](#note-44)

<a id="event-45"></a>

45. **杨修与杨氏四世太尉论赞。** 杨修为曹操主簿，以敏捷知名，涉储嗣争端而被杀。魏朝礼遇杨彪至其卒，作者合评杨震以来的四世太尉。 [[45]](#note-45)

<a id="event-46"></a>

46. **千乘、乐安及勃海王刘悝。** 章帝封刘伉、刘全，刘伉后人改乐安。刘悝一度以不道被贬又获复，王甫等干预后再次获罪自杀。 [[46]](#note-46)

<a id="event-47"></a>

47. **清河王刘庆废立、助诛窦氏。** 宋贵人受宠后生刘庆，后被窦氏构陷，刘庆从太子降清河王；和帝与刘庆友善，密取《外戚传》并拘诛窦氏。刘庆就国后的令、遗意与后嗣附录。 [[47]](#note-47)

<a id="event-48"></a>

48. **清河刘蒜被逼自杀与甘陵继统。** 刘蒜曾为朝廷选嗣人选，梁冀排斥之。刘文、刘鲔欲共立蒜，朝廷案治，刘蒜徙置后自杀，其后另立甘陵王。 [[48]](#note-48)

<a id="event-49"></a>

49. **济北国诸王及刘次的服丧诏。** 刘寿受封后子孙迭立。刘次幼年丧父，哀毁至病，梁太后下诏令改从规定的丧礼；国统在建安十一年绝。 [[49]](#note-49)

<a id="event-50"></a>

50. **河间一支出桓帝、灵帝。** 河间王刘开善守法，刘翼一度奉平原王后，遭邓氏政局牵连后改封蠡吾，其子为桓帝。刘淑一支出灵帝，后有追尊、奉祀和袭封。 [[50]](#note-50)

<a id="event-51"></a>

51. **城阳、广宗、平原王与论赞。** 城阳刘淑、广宗刘万岁皆早卒无后。和帝长子刘胜以疾受封平原，继统先后转给乐安、河间诸子，作者借章帝敦厚解释后嗣仍传多支。 [[51]](#note-51)

<a id="event-52"></a>

52. **张皓争储与张纲按风俗。** 正文多处缺字，首人名通行作张皓。他任廷尉辨疑狱，并争安帝废太子。子张纲以巡行使身份弹劾梁冀，后任广陵太守，亲赴张婴营说降。 [[52]](#note-52)

<a id="event-53"></a>

53. **王龚、王畅的用人与郡政。** 王龚任汝南太守招致陈蕃等，为太尉请黜宦官而遭构陷；王畅治郡严明，听取儒生劝谏后宽刑，终以灾异免三公。 [[53]](#note-53)

<a id="event-54"></a>

54. **种暠守储、治羌与后人。** 种暠早年护太子，任益州等职整顿吏治；任边将时晓示恩信、安抚诸部，晚任司徒。后叙种岱、种拂、种劭各自仕履和祸难。 [[54]](#note-54)

<a id="event-55"></a>

55. **陈球抗议窦太后葬制与谋诛宦官。** 陈球任零陵太守固守城池，任廷尉时力争以皇太后礼葬窦氏，从三公退居之后与刘合谋诛宦官，事泄伏诛。 [[55]](#note-55)

<a id="event-56"></a>

56. **杜根与成翊世抗直。** 杜根劝安帝亲政，几被邓太后扑杀，逃亡多年后再起；成翊世以直谏反对近习擅权，两人的生死与复任分叙。 [[56]](#note-56)

<a id="event-57"></a>

57. **栾巴经历宦者之职、郡守与诏狱。** 栾巴由宫中迁地方，毁坏淫祀、兴教、移易民俗。其反对朝廷处置宗室，遭收系并死，叙事兼有时人异术传说。 [[57]](#note-57)

<a id="event-58"></a>

58. **刘陶议财用、荒饥与苛吏。** 刘陶参与训释《尚书》，奏言民生、货币、财政及权幸用人；传中长疏用古今对比求通流民生计。他后来按举郡吏而触近习，死于狱中。 [[58]](#note-58)

<a id="event-59"></a>

59. **白马令李云进谏及杜众请死。** 梁冀被诛后，宦官及新皇后的家族受封，李云公开进谏，杜众上书求同死。作者比较隐讽和犯颜直谏的利弊。 [[59]](#note-59)

<a id="event-60"></a>

60. **刘瑜、尹勋与谢弼诸谏。** 刘瑜用灾异说陈述宦官坏政，参与窦武谋议；勋以公议反宦官；谢弼对策批评政弊，遭内官报复，后有昭雪。 [[60]](#note-60)

<a id="event-61"></a>

61. **虞诩不弃凉州与治朝歌。** 虞诩反对邓骘放弃凉州，以防西州人失望转从羌胡。后到多盗的朝歌，先以离间和侦察破其聚众，再以治理恢复当地秩序。 [[61]](#note-61)

<a id="event-62"></a>

62. **虞诩守武都与纠劾权幸。** 虞诩在武都凭地形、异服增灶等计对羌，复开栈道运输，后来任司隶校尉连劾高官宦者，在狱中获释并再掌尚书。 [[62]](#note-62)

<a id="event-63"></a>

63. **傅燮的拒贿和汉阳死守。** 傅燮从征黄巾，不为宦官家属说项。在汉阳任上力谏不用未经训练的兵，刺史兵败后本人拒绝敌方招降，死于守郡。 [[63]](#note-63)

<a id="event-64"></a>

64. **盖勋守陇右与面抗董卓。** 盖勋布置兵力抗击边章、韩遂之乱，军中救旧怨、守臣节，后在朝议兵时反对徒示声威，在董卓专权时谏诤。 [[64]](#note-64)

<a id="event-65"></a>

65. **臧洪讨董盟誓与雍丘死节。** 臧洪受诸军推举登坛盟誓讨董卓，与袁绍有旧。张超被围时臧洪请援不许，遂与袁绍决裂，遭围粮尽被杀，陈容同死。 [[65]](#note-65)

<a id="event-66"></a>

66. **张衡博学与《二京赋》。** 张衡入太学通经艺，辞举辟；见都城承平而王侯尚奢，仿班固《两都赋》作《二京赋》以讽。 [[66]](#note-66)

<a id="event-67"></a>

67. **张衡从郎中到太史令与《应间》。** 张衡擅机巧和历算，研浑天、作《灵宪》；因仕进迟缓有《应间》自辩，说明何以守节待时、回避躁进。 [[67]](#note-67)

<a id="event-68"></a>

68. **候风地动仪与朝廷用事。** 本组述仪器外有八龙吐丸示方的构造、京师未觉而后报陇西地震的见验，以及张衡应对宫中宦者妒忌的经过。 [[68]](#note-68)

<a id="event-69"></a>

69. **张衡论图谶与《思玄赋》。** 张衡疏辨图谶所称经义的来源，反对以失实预言操持政策；又借《思玄赋》中的游历、遇合表达不得直达朝廷的忧虑。 [[69]](#note-69)

<a id="event-70"></a>

70. **河间治绩、卒年与论赞。** 张衡出任河间相，治豪右与奸吏，使一郡肃然，后征拜尚书而卒。范晔以其精于数术制作为评。 [[70]](#note-70)

<a id="event-71"></a>

71. **马融早年求学与入馆。** 马融从挚恂读经，拒邓骘初辟，羌乱米贵后始应召入职，入东观校书。其后因议政与权贵冲突的铺垫见本组。 [[71]](#note-71)

<a id="event-72"></a>

72. **马融《广成颂》、仕履和讲学。** 《广成颂》以田猎礼议国家制度；马融其后任多职，与梁冀牵连，迭遭处分与恢复。讲学规模、诸经训诂、雅好音乐及遗令薄葬均见传末。 [[72]](#note-72)

<a id="event-73"></a>

73. **蔡邕早年、东观与正定六经。** 蔡邕师从胡广，擅辞章音乐，亲闻琴弦之事体现其知音。入东观后与杨赐、堂溪典等请校诸经，灵帝准奏，后来刻成太学石经。 [[73]](#note-73)

<a id="event-74"></a>

74. **蔡邕论灾异、鸿都门学与流徙。** 蔡邕回答灾异诏问，直指宦官和嬖幸用事，又论史官、学校选士。奏疏泄露后遭诬流徙，遇赦仍因险情迁迹江海。 [[74]](#note-74)

<a id="event-75"></a>

75. **蔡邕入董卓朝与死狱。** 董卓逼召蔡邕，累迁官爵。董卓伏诛后，蔡邕在王允坐中感叹而被收狱，马日磾等求情不得，遂死。 [[75]](#note-75)

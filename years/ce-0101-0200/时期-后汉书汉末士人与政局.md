# 东汉末年人事记载

[本世纪目录](README.md) · [全部世纪](../README.md) · [《后汉书》分卷目录](../../sources/后汉书读本目录.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **郑太与董卓。** 郑太先劝何进勿招董卓，后暗助关东起兵。董卓欲广征兵，他以九条理由称山东不足为患，借此阻止董卓增兵。迁都长安后，他用家资赈救宾客，与荀攸等谋诛董卓，事泄出奔。 [[1]](#note-1)

<a id="event-2"></a>

2. **孔融家世与北海治事。** 孔融少年以见李膺、庇护张俭闻名。入仕后举劾内官亲族，因在废立问题上忤董卓而出守北海。他收编流民，办学荐贤，却不能在袁氏、曹氏之间维持独立，终于建安元年败于袁谭。 [[2]](#note-2)

<a id="event-3"></a>

3. **孔融议政与被杀。** 许都朝议中，孔融反对追礼马日磾和恢复肉刑，就王室祭礼提出意见，又与曹操争论禁酒及封建。曹操使路粹罗织罪名，孔氏父子遇害。史论以他直言敢任为可贵，亦记其才性与时局不合。 [[3]](#note-3)

<a id="event-4"></a>

4. **荀彧的军国谋议。** 荀彧迁族避乱，离袁绍从曹操，留守鄄城时抵制张邈、陈宫迎吕布，又劝先取兖州、迎献帝都许。官渡军粮将尽时力劝坚持，袁绍败后劝继续经营河北。其后阻止曹操进爵国公、加九锡，曹操不悦，本传记其见空食器后饮药。 [[4]](#note-4)

<a id="event-5"></a>

5. **皇甫嵩破黄巾。** 张角以治病和教化聚众，预定举事日期暴露后起兵。皇甫嵩与朱儁出击，利用风势火攻长社围军，又破仓亭卜己、广宗张梁、下曲阳张宝；平乱后奏免冀州一年田租，拒绝阎忠进取天下之议。 [[5]](#note-5)

<a id="event-6"></a>

6. **皇甫嵩平凉州军与晚年。** 边章、韩遂进犯时，皇甫嵩因宦官构陷免职。王国围陈仓，他先静待对方疲弊，再追击破敌，遂与董卓结怨。董卓秉政后靠儿子坚寿力争得免；董卓死后曾任征西将军、太尉等职，后来病卒。 [[6]](#note-6)

<a id="event-7"></a>

7. **朱儁出仕及攻宛。** 朱儁早年事母，以才行见知，曾设法免太守尹端死刑；出征交趾平梁龙，后与皇甫嵩平颍川黄巾，再围南阳宛城。围城时他撤去一面，使困守者出城后再分兵追击。 [[7]](#note-7)

<a id="event-8"></a>

8. **黑山部众与朱儁晚年。** 黄巾之后河北多起兵众，张燕获朝廷任命掌河北山谷，后来仍扰河内。朱儁反对迁都长安，一度联络关东诸将，后回朝任太尉，在李傕、郭汜相攻时被扣留而病卒。史论评两将平乱有功，终未挽回主弱臣强。 [[8]](#note-8)

<a id="event-9"></a>

9. **董卓起家与凉州军。** 董卓早年结交羌部豪帅，因从张奂破叛羌受赏。讨黄巾失利获罪，后参与关中御羌、援陈仓。灵帝末拒绝释军赴任，保留军队成为朝廷制约不了的力量。 [[9]](#note-9)

<a id="event-10"></a>

10. **董卓控制洛阳与废立。** 何进秘密招董卓入朝，宦官杀进后挟帝出逃，董卓在北芒迎回天子。他收编何氏旧部，废少帝、立陈留王，以追复党人爵位和任用名士争取声望，同时纵兵掠民。 [[10]](#note-10)

<a id="event-11"></a>

11. **迁都长安及董卓被诛。** 白波军扰乱河东，关东州郡起兵。董卓推动迁都，驱徙洛阳民众并焚城，与孙坚等交战后退入关中；筑郿坞、僭用车服，又杀张温。王允、吕布、士孙瑞共谋，董卓赴朝时被杀。 [[11]](#note-11)

<a id="event-12"></a>

12. **李傕郭汜攻长安及献帝东归。** 牛辅败亡后，李傕等求赦未获，听贾诩计回攻长安，杀王允后分掌军政。长安饥乱，李傕杀樊稠后与郭汜相攻，分别控制天子、大臣，张济调停后车驾东行，途中又受追击。 [[12]](#note-12)

<a id="event-13"></a>

13. **许都、关中将帅与史论。** 回洛阳后诸将争权，曹操迎帝都许。段煨等奉诏攻灭李傕，董承受密诏谋诛曹操未成。韩遂、马腾在凉州相攻，后分别受朝命。范晔论董卓恃乱夺权给汉廷及民众造成的祸患。 [[13]](#note-13)

<a id="event-14"></a>

14. **刘虞治幽州及被杀。** 刘虞以宽政招徕边部、安置流民，拒绝韩馥和袁绍推尊，遣田畴、鲜于银赴长安。他与公孙瓒在对待乌桓、征取军需等事上渐不相容，仓促攻瓒失败，被公孙瓒所杀。 [[14]](#note-14)

<a id="event-15"></a>

15. **公孙瓒边功与争夺河北。** 公孙瓒从卢植受业，以抵御鲜卑、追张纯著名，常以白马骑士为亲兵。破青徐黄巾后与袁绍交战，自署刺史分取郡县。杀刘虞后移镇易京，失却人心，刘虞旧部聚兵反击。 [[15]](#note-15)

<a id="event-16"></a>

16. **易京陷落与史论。** 公孙瓒闭守易京，因关靖劝阻不亲自求援。张燕来救之际，袁绍截获密书并利用先约信号，攻克易京。公孙瓒死，关靖赴敌而死。史论设想刘虞、公孙瓒如果合作，幽燕或可保全。 [[16]](#note-16)

<a id="event-17"></a>

17. **陶谦治徐州与战事。** 陶谦平徐州黄巾，向长安进贡，受任徐州牧。曹嵩遇害后曹操两度东征，第一次屠戮多县，第二次因兖州变乱撤军，陶谦同年病卒。附记笮融以运粮资源造佛寺及赵昱事。 [[17]](#note-17)

<a id="event-18"></a>

18. **袁绍出仕、讨董与夺冀州。** 袁绍出自累世公卿之家，善结士人。参与何进谋诛宦官，反对董卓废立，出奔勃海后主持关东联军。他随后取得韩馥的冀州，与公孙瓒争战，由麴义等击破对方军队。 [[18]](#note-18)

<a id="event-19"></a>

19. **袁绍与迁都之争。** 献帝遭李傕诸将追逼，袁绍没有接受沮授迎帝据邺之策。曹操迎帝后责袁绍专据地方，本段载其申辩；随后袁曹之间有大将军任命、封侯及控制河北等事。 [[19]](#note-19)

<a id="event-20"></a>

20. **官渡、乌巢及袁绍去世。** 袁绍未采田丰趁曹操东征袭后的建议，进兵后同曹操在官渡相持。许攸离绍投操，曹操突袭乌巢，袁军溃败。袁绍败后重新控制部分冀州城邑，建安七年病卒。 [[20]](#note-20)

<a id="event-21"></a>

21. **袁氏争立与公孙氏据辽东。** 逢纪、审配扶立袁尚，袁谭、袁尚相攻，曹操乘势攻邺、斩袁谭。高干再反失败，袁尚、袁熙在乌桓败后奔辽东，为公孙康所杀。附记公孙度兴起及公孙康继据辽东。 [[21]](#note-21)

<a id="event-22"></a>

22. **刘表据荆州及子嗣。** 刘表以蒯越、蔡瑁之策招聚宗党、稳住荆州，纳张济余部并平张羡诸郡之乱。他资助学校、收容寄寓士人，对曹操与袁绍之争持观望。曹操南下前刘表病死，刘琮继立后降。 [[22]](#note-22)

<a id="event-23"></a>

23. **刘焉刘璋据益州。** 刘焉建议选重臣出任州牧，入益州后集结东州兵，击灭任岐、贾龙，与马腾谋攻李傕未成。刘璋继任后遣张松见曹操，又引刘备入蜀抗张鲁，双方终于反目，成都被围后刘璋开城出降。 [[23]](#note-23)

<a id="event-24"></a>

24. **张鲁治汉中。** 传记张鲁家族传道、设祭酒及义舍，借信众控制汉中；曹操进兵时，张鲁欲降，因弟张卫先抗拒而至巴中，后归曹操获封。 [[24]](#note-24)

<a id="event-25"></a>

25. **袁术称仲家及败亡。** 袁术在南阳后据淮南，广征军用、依符命僭号，自称仲家，置公卿。与吕布婚盟不成，出兵再败，又遇饥荒、军众离散，北投袁氏无路，呕血而死。 [[25]](#note-25)

<a id="event-26"></a>

26. **吕布与张邈。** 吕布先杀丁原从董卓，后助王允杀董卓，辗转依附袁术、袁绍、张杨。张邈、陈宫迎他据兖州，曹操反攻后吕布夺下邳。后来曹操围下邳，吕布被部将所执，同陈宫等被杀。史论评各方乘汉末之乱各自图强。 [[26]](#note-26)

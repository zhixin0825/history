# 匈奴、西域及其他边地

[本世纪目录](README.md) · [全部世纪](../README.md) · [《后汉书》分卷目录](../../sources/后汉书读本目录.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **东夷总叙。** 范晔从礼制中的分类和上古传说写起，综述战国秦汉东部诸地区变迁。卷中“东夷”是史书所用分类，包含不同政治实体与习俗。 [[1]](#note-1)

<a id="event-2"></a>

2. **夫余与挹娄。** 先述夫余区位、建国传说及与东汉交涉，再述挹娄的环境、生产和部落组织，两地在传文中相邻而语言并不相同。 [[2]](#note-2)

<a id="event-3"></a>

3. **高句骊及边郡往来。** 记录高句骊国土、风俗、王莽时期的征发和严尤斩驺，此后叙宫、遂成、伯固等与辽东、玄菟的攻守及归附。部分事件在不同传文中有先后或人物矛盾。 [[3]](#note-3)

<a id="event-4"></a>

4. **沃沮及濊。** 区分南北沃沮，叙述其与高句骊的关系以及濊的边界、作物、山川禁约和居住习俗；附箕子教化旧说。 [[4]](#note-4)

<a id="event-5"></a>

5. **三韩及州胡。** 叙马韩、辰韩、弁辰分布，记纹身、田蚕、铁和海岛交易；朝鲜准南走与汉代受贡被放在这种地理、风俗叙述之中。 [[5]](#note-5)

<a id="event-6"></a>

6. **倭诸国及卷末史论。** 记倭地诸国、建武中元二年受印绶、永初元年请见，以及卑弥呼被推为王的传闻，末及会稽外海诸洲；史论用教化解释各地风俗差异。 [[6]](#note-6)

<a id="event-7"></a>

7. **南方总述与武陵诸部。** 由槃瓠传说和先秦沿革引出武陵武谿沿线冲突。东汉屡次出兵或招抚，争端亦与赋役失平及官吏贪暴相关。 [[7]](#note-7)

<a id="event-8"></a>

8. **交趾、九真及日南。** 记越裳献雉旧说、秦汉设郡、锡光任延教化、征侧征贰起兵及马援征讨；象林、日南诸次反抗中，李固从路途、供给等方面劝止远征，建议任用地方长吏招抚。 [[8]](#note-8)

<a id="event-9"></a>

9. **巴、南郡与板楯诸部。** 记巴郡南郡诸姓、廪君和射虎传说，以及汉初租赋特例。刘尚讨潳山，后来地方征税、板楯攻掠与招降各有年月。 [[9]](#note-9)

<a id="event-10"></a>

10. **夜郎、滇及益州郡。** 列夜郎、滇、邛都方位与相传旧事，续记西汉置郡、王莽末地方动乱和东汉棟蚕反叛，益州郡治理时有战事与招抚。 [[10]](#note-10)

<a id="event-11"></a>

11. **哀牢内属与永昌郡。** 先录沙壹、九隆始祖传说，继叙贤栗早期归附、柳貌率众内属后设永昌郡。郑纯议定固定贡赋，后世又有徼外诸国遣使、进献乐人。 [[11]](#note-11)

<a id="event-12"></a>

12. **邛都、越巂与长贵。** 叙邛都置县、越巂设郡，以及长贵杀枚根、自立、先从公孙述再受汉封。东汉又视郡治成败、赋敛轻重而屡见内属与反叛。 [[12]](#note-12)

<a id="event-13"></a>

13. **莋都与西南乐歌。** 莋都旧郡并回蜀部，朱辅以通译招徕白狼等部。三首乐歌保存译辞与音记，后续记永元、永初年间的归附和征发。 [[13]](#note-13)

<a id="event-14"></a>

14. **冉駹、白马氐与论赞。** 记汶山郡改置、恢复及冉駹各部习俗，叙武都白马氐风俗与王莽、后汉之际的动向；范晔把用兵与地方往来合论。 [[14]](#note-14)

<a id="event-15"></a>

15. **羌族源流及西汉经营。** 传由三苗、姜姓等旧说展开，记西周至秦各戎部消长及爰剑后裔分种，接述西汉徙居、边郡守御及宣帝时羌地争议。 [[15]](#note-15)

<a id="event-16"></a>

16. **烧当羌兴起及明章和三朝。** 王莽末至光武年间，羌部在金城、陇西等地活动。滇良、滇吾相继扩张，边吏与诸羌或战或降；傅育败死、张纡杀迷吾及永元处置反复记录。 [[16]](#note-16)

<a id="event-17"></a>

17. **永初羌乱及零昌败亡。** 强征降羌去西域、边吏侵役导致诸种反叛，滇零、零昌先后组织抵抗。战事扩及三辅、汉中，地方被迫迁徙，朝廷合兵并收买内应，战争耗资甚巨。 [[17]](#note-17)

<a id="event-18"></a>

18. **马贤出兵与虞诩论守边。** 自永宁到顺帝，马贤反复击降麻奴、钟羌等部，边官处置质子及屯田使冲突复起；虞诩从安民、守土与供给主张整治西北。 [[18]](#note-18)

<a id="event-19"></a>

19. **永和以来的战事及耗费。** 白马羌、烧当、且冻等部与汉军交战，马贤失利战死，赵冲等续战。篇中追计征战十余年耗费，并指将领贪盗军粮，后记段熲、张奂之役。 [[19]](#note-19)

<a id="event-20"></a>

20. **羌种统计、湟中月氏与赞。** 说明爰剑后分出的诸部及大小强弱，区别湟中月氏胡的来历与羌人。史论将长年边患与汉廷约束失当、豪右侵役联系起来。 [[20]](#note-20)

<a id="event-21"></a>

21. **西域三通三绝。** 先叙西汉都护和戊己校尉、新莽断绝，继述明帝取伊吾、班超经营、安帝罢都护、张璫陈策和班勇复屯柳中。 [[21]](#note-21)

<a id="event-22"></a>

22. **两道地理与塔里木南道诸国。** 列玉门关外东西路线、双河源和车师要冲，从拘弥、于窴往西列西夜、子合、德若等国及道里、户兵、土产。 [[22]](#note-22)

<a id="event-23"></a>

23. **条支、安息和大秦。** 叙由陆路至条支、安息的里程，班超遣甘英赴大秦而止于海边。大秦条兼录贸易、货币、制度与远方传闻，对《汉书》里程记载也有异同。 [[23]](#note-23)

<a id="event-24"></a>

24. **大月氏、高附、天竺等国。** 写贵霜由五翕侯之一扩张建立王国，辨高附在旧书中的归类，叙天竺及邻国的商旅、佛教与遣使；“明帝梦金人”以“世传”引出。 [[24]](#note-24)

<a id="event-25"></a>

25. **莎车的强盛与衰落。** 自王延、康、贤叙莎车先抗匈奴而后并诸小国，汉廷未满足其都护所请，各国当时进退不同。于窴摆脱莎车统治，广德灭莎车后又受匈奴围攻。 [[25]](#note-25)

<a id="event-26"></a>

26. **疏勒与焉耆。** 记龟兹置疏勒王及班超更立疏勒王，后述臣磐从大月氏归国；焉耆段区别明帝末陈睦军覆没与和帝时班超再征而立新王。 [[26]](#note-26)

<a id="event-27"></a>

27. **蒲类、移支、东且弥、车师及论赞。** 叙蒲类分徙、移支与东且弥生活，辨车师前后部的都邑、通道。两部在汉与匈奴间数次变动，班勇、后王与屯戍吏的事见本段。史论串联张骞和班超的经营。 [[27]](#note-27)

<a id="event-28"></a>

28. **南匈奴分立及美稷安置。** 单于传位引发争执，比由八部拥立而称呼韩邪，请依附东汉。段郴、王郁奉使，与南单于约定朝贡、侍子和屯戍，后迁其庭至美稷。 [[28]](#note-28)

<a id="event-29"></a>

29. **初期南北交涉。** 北单于屡遣使求和与互市，太子、班彪主张谨慎应答。南部数易单于并继续御边；郑众察觉南北私下联系，朝廷后来设度辽将军。 [[29]](#note-29)

<a id="event-30"></a>

30. **北方互市与窦宪出塞。** 章帝时恢复边市，北匈奴受南部、丁零等夹击而内乱；南单于上策请乘机合击。诸军出塞，北庭受创，南部追抚北匈奴余众。 [[30]](#note-30)

<a id="event-31"></a>

31. **师子、逢侯与檀等继立。** 新降部众反叛，胁立逢侯。师子及其后继者继续与逢侯交战；檀本人又曾背叛，汉廷更换度辽将军，鲜卑则成为塞上主要压力。 [[31]](#note-31)

<a id="event-32"></a>

32. **休利以来的反复与更立。** 度辽将军数度更换，吾斯、车纽等叛，车纽被推为新单于。汉廷立兜楼储、居车儿，后来对南单于废立发生争议，张修擅杀呼征获罪。 [[32]](#note-32)

<a id="event-33"></a>

33. **羌渠、於扶罗与呼厨泉。** 征发南匈奴协讨张纯引起部内反对，羌渠被杀，於扶罗求朝廷申理并流转内地。呼厨泉继位，去卑参与献帝东归；史末略论汉廷长期匈奴政策。 [[33]](#note-33)

<a id="event-34"></a>

34. **乌桓来源、风俗与西汉关系。** 记乌桓由东胡余部发展，包含游牧、葬仪、部落与法俗，李贤注辨名物与音义。西汉迁其居五郡边塞，并数度招纳或交战。 [[34]](#note-34)

<a id="event-35"></a>

35. **东汉乌桓与三郡势力。** 马援出塞后退，乌桓乘匈奴内乱入贡，东汉授封渠帅并置校尉。其后有数次寇边，丘力居及蹋顿等势力扩展；蹋顿助袁绍攻公孙瓒，曹操此后北征乌桓。 [[35]](#note-35)

<a id="event-36"></a>

36. **鲜卑来源、边境往来。** 记鲜卑与乌桓均出东胡而自有风俗，光武朝祭肜御边后发展互市，后来鲜卑进入北匈奴故地。使者、质馆和攻守交错，历代交涉并非始终一致。 [[36]](#note-36)

<a id="event-37"></a>

37. **檀石槐崛起与蔡邕议边。** 东汉与鲜卑冲突持久，檀石槐整合势力、划分三部。夏育等请大举出兵，蔡邕援引汉武帝长年征伐耗费和堵塞边漏等理由反对，李贤注逐一说明其所用典故。 [[37]](#note-37)

<a id="event-38"></a>

38. **汉军出塞败还与部落分争。** 灵帝采出兵议，夏育、田晏、臧旻三道进军，被檀石槐分部击败。檀石槐死后继承者内部纷争，篇末史论归结东汉边势转变。 [[38]](#note-38)

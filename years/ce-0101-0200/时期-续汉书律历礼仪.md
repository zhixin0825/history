# 律历与礼仪

[本世纪目录](README.md) · [全部世纪](../README.md) · [《后汉书》分卷目录](../../拆分史书/后汉书/README.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **律数、京房六十律与律准。** 篇首把律度量衡归入数术。汉初张苍以律历任职，武帝置协律，京房以十二律相生推到六十律，用有弦的准辅助定音。 [[1]](#note-1)

<a id="event-2"></a>

2. **六十律表。** 逐列各律的数值、所生之律及充当宫、商、徵的位置，兼列律管和弦准长度。黄钟数作十七万七千一百四十七，以下随相生递推。 [[2]](#note-2)

<a id="event-3"></a>

3. **试律、准法与候气。** 殷肜奏严崇子能传准法，诏令考试实音；末段写密室排列律管、用灰看是否受气而动，呈现当时律学与节气观念的联系。 [[3]](#note-3)

<a id="event-4"></a>

4. **三统历误差和贾逵议历。** 本篇从朔受误差入手，记太初历沿用百余年所遇的问题。贾逵等比较旧历与新术，重点涉及朔日大小次序、黄赤道度及月行迟疾。 [[4]](#note-4)

<a id="event-5"></a>

5. **漏刻、历元与蔡邕反驳。** 霍融质疑官漏推算；延光时有人倡甲寅元或恢复太初历，汉安时边韶又论历术。熹平四年冯光、陈晃以灾乱论历元，蔡邕主张以实测弦望检验主张。 [[5]](#note-5)

<a id="event-6"></a>

6. **不同月食算法。** 四分历仍在月食推算中出现先后差。官历与张恂、王汉等人的测记、算法相比较；奏议引纬书的部分保留当时的论证方式。 [[6]](#note-6)

<a id="event-7"></a>

7. **四分历的天体、月年和节气概念。** 本段说明天球、日月相对运动如何用度、日和月表示，并以冬至、合朔组织章、蔀、纪、元。还说明无中气之月置闰的原则。 [[7]](#note-7)

<a id="event-8"></a>

8. **历法常数与月食参数。** 列元法、纪法、章法、日法等常数，继列食数、月数、食法等，用来同步推算年月日与周期性月食。 [[8]](#note-8)

<a id="event-9"></a>

9. **冬至、朔望、月食的推法。** 逐条给出从纪元、蔀、日入手的算法，用整数除法、余分和进位推定朔日、望及上下弦，又求日月所行度和可能月食的时刻。 [[9]](#note-9)

<a id="event-10"></a>

10. **五纬盈缩与历表。** 列五星运动参数和见伏、留行算法，连同朔月及二十八宿度数，说明计算者如何将行度换到宿次并与节气对应。 [[10]](#note-10)

<a id="event-11"></a>

11. **二十四气、晷影及漏刻。** 逐气给出黄道距极、晷影、昼夜观测等值，以及迟早所配的占候。末段比较不同分野方案，再用日所在宿度判中星。 [[11]](#note-11)

<a id="event-12"></a>

12. **历法递变与论赞。** 史论追叙不同历元，说历制随年代改易，赞强调用衡玑等测验日月与制度相符。 [[12]](#note-12)

<a id="event-13"></a>

13. **月朔、迎春、五供、上陵与冠礼。** 交代威仪的等级意义。记录每月朔日颁历、立春易服、五供和上陵，继叙祭祀斋戒及天子加元服。 [[13]](#note-13)

<a id="event-14"></a>

14. **天子亲耕藉田。** 按次序记录祭先农、天子和公卿推耕及礼仪停止的条件。古注对藉田的起名、躬耕和由民终耕各有解释。 [[14]](#note-14)

<a id="event-15"></a>

15. **高禖、养老、亲蚕与祓禊。** 依季节安排求嗣、养老、蚕事和水滨祓禊。部分解释为后人引经，读时应与主要仪节区分。 [[15]](#note-15)

<a id="event-16"></a>

16. **夏秋迎气、祈雨及封授。** 礼随阴阳时令更换服色、祭所和音乐，另载请雨与太子、王公封拜的仪程和相关印绶。 [[16]](#note-16)

<a id="event-17"></a>

17. **案户、星祭、冬礼及朝会。** 秋季有核计户口、祠星；冬至及岁末有腊祭、大傩、土牛和遣卫士。后叙正旦朝会人员、班列与上寿。 [[17]](#note-17)

<a id="event-18"></a>

18. **皇帝病、崩与大丧。** 从帝病进药、告祠至崩后成服、殡敛、送葬，依角色、时刻、路线和礼器排列。 [[18]](#note-18)

<a id="event-19"></a>

19. **封王侯、贵人与公主之丧。** 列诸侯王列侯初封及送遣礼，也说明贵人、公主去世后的治丧等第。赞以等级得礼、仪节得中作结。 [[19]](#note-19)

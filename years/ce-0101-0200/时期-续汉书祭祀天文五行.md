# 祭祀、天文与五行

[本世纪目录](README.md) · [全部世纪](../README.md) · [《后汉书》分卷目录](../../拆分史书/后汉书/README.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **光武即位告天与洛阳郊坛。** 光武即位于鄗的告天地之礼采旧例。次年建南郊坛。杜林议高祖当否配食，平陇蜀以后又扩充祭祀。 [[1]](#note-1)

<a id="event-2"></a>

2. **封禅泰山及建武中元改元。** 记群臣前后请封禅、皇帝早先拒绝及后来东行。交代告祀名物、登封与禅祭及改元前后政令。 [[2]](#note-2)

<a id="event-3"></a>

3. **北郊、三雍与五郊迎气。** 记北郊、明堂、辟雍、灵台及相关祭位，分春夏、季夏、秋冬列青赤黄白黑服色、乐舞与所祭神灵。 [[3]](#note-3)

<a id="event-4"></a>

4. **章帝、安帝和桓帝的增祀。** 章帝巡泰山并添山川祭祀，安帝议六宗、依成例祭祀，桓帝又有派使祠老子和亲祀的记录。 [[4]](#note-4)

<a id="event-5"></a>

5. **高庙、光武庙与社稷。** 记洛阳立高庙及历代帝主的位置，又因明帝遗诏留下更衣别庙起源。太社太稷另有坛位和岁祭。 [[5]](#note-5)

<a id="event-6"></a>

6. **灵星、先农、地方迎春与史论。** 地方祭先农、风伯、雨师有定日。郡县立春迎礼及史论辨析常祀和过度祭祀，赞收束全志。 [[6]](#note-6)

<a id="event-7"></a>

7. **天文志序与王莽三条。** 以日月五星和地上州分说明当时的观象法，列王莽时的天象及其后叙。天象和占验对应是志书判断。 [[7]](#note-7)

<a id="event-8"></a>

8. **光武朝观象。** 列建武、中元及相关星官记录，包含彗星、行星相犯等事件，并附作者所配的政事。 [[8]](#note-8)

<a id="event-9"></a>

9. **明帝朝十二项观测。** 永平年间流星、彗星、客星与行星出没分年记载，往往用星官与地域解释，并回配诸王、边战与帝丧。 [[9]](#note-9)

<a id="event-10"></a>

10. **章帝朝观象。** 建初和元和分别观测行星、流星、彗星与客星。部分紧连同年灾异，部分另引以后事件。 [[10]](#note-10)

<a id="event-11"></a>

11. **和帝到殇帝。** 从永元元年起按年记行星聚合、流星、客星等，及元兴与延平。某些年份的政事只是占辞所解释的后应。 [[11]](#note-11)

<a id="event-12"></a>

12. **安、顺、质帝诸朝。** 安帝年间永初、元初与延光都有观测；顺帝续永建、阳嘉、永和、汉安各年。质帝本初条并列行星变象与皇帝遇害。 [[12]](#note-12)

<a id="event-13"></a>

13. **桓帝朝观象。** 记录建和、元嘉、永兴、永寿、延熹诸年行星入犯及彗、客星，并附宫廷、刑赏和征战的占释。 [[13]](#note-13)

<a id="event-14"></a>

14. **灵帝朝观象。** 按建宁、熹平、光和、中平记星象。部分史事相隔数年，如黄巾和何进案，不能因占验同段误归同年。 [[14]](#note-14)

<a id="event-15"></a>

15. **献帝朝观象与陨石附记。** 初平和建安的星象与州郡战事分年记载。末附殇帝时陈留陨石和桓帝时扶风、鄠陨石。 [[15]](#note-15)

<a id="event-16"></a>

16. **五行志一的灾异类别。** 以前汉《五行志》为参照，汇记东汉雨旱、服妖、鸡祸、屋坏、谣言及狼伤人。事件常伴“先兆—应验”解释，各时间要循原文分别读。 [[16]](#note-16)

<a id="event-17"></a>

17. **火灾与草木、鸟兽异象。** 先论火失其性，再由朝廷和地方火灾扩及草木、羽虫及羊等异象。记录与归咎于政治的旧说并列。 [[17]](#note-17)

<a id="event-18"></a>

18. **水患、寒雹及蝗灾。** 把水溢、雨水异常、严寒、雹、冬雷与山鸣等编入五行类目，后及鱼异、蝗灾。按纪年阅读时以具体受灾年月为准。 [[18]](#note-18)

<a id="event-19"></a>

19. **地震、山崩和风灾。** 分年记录京师及郡国地震，继列山崩、地陷、大风拔树、螟害和牛疫。志中部分列郡县范围与朝廷救灾措施。 [[19]](#note-19)

<a id="event-20"></a>

20. **龙蛇、动物、疾病与其他异象。** 此卷列射妖、龙蛇、马变、人事异常、疫和虹霓等。仅据史籍原记说明传统灾异分类。 [[20]](#note-20)

<a id="event-21"></a>

21. **日食、日色与月食等历象。** 广列历朝目击或记录的日食与日色变化，并收虹贯日和不同寻常的月食。对于朔晦、日干支和方位，读者可和本纪同号对看。 [[21]](#note-21)

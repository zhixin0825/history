# 郡国、百官与舆服

[本世纪目录](README.md) · [全部世纪](../README.md) · [《后汉书》分卷目录](../../拆分史书/后汉书/README.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **司隶七郡与京畿。** 说明以《汉书·地理志》为参照，重记东汉更易。列河南尹、河内、河东、弘农、京兆、左冯翊及右扶风等郡的城邑、户口和地名沿革。永和五年户口为统计断面。 [[1]](#note-1)

<a id="event-2"></a>

2. **豫州与冀州郡县。** 自颍川起列豫州、冀州郡国，各条包括治所方位、所属县、户口以及故名。县名用方括形标识，卷末合计一州郡国数。 [[2]](#note-2)

<a id="event-3"></a>

3. **兖州与徐州郡县。** 从陈留记起，列兖州与徐州的郡国、县邑、户口和旧称。地名改置涉及多个朝代，不能一律归于编户统计年。 [[3]](#note-3)

<a id="event-4"></a>

4. **青州、荆州与扬州郡县。** 这三州均有郡县条、王国条和小地名。合读各州条末城邑统计，可见县国分布与东汉户口记录的口径。 [[4]](#note-4)

<a id="event-5"></a>

5. **益、凉、并、幽、交及全国卷末。** 从汉中起列益州及西北、北方、东北和交州郡国。附边郡道里、山川、旧制、地理分野和全国性汇计。 [[5]](#note-5)

<a id="event-6"></a>

6. **三公、太傅及将军。** 篇首先概述秦汉到光武的官制变化。此卷列太傅、太尉、司徒、司空及将军府等属官秩禄，说明度辽将军最初因南匈奴事务设置。 [[6]](#note-6)

<a id="event-7"></a>

7. **太常与光禄勋。** 太常管礼仪祠祀及有关学官，光禄勋属有五官、左右及羽林、虎贲设置。按官名列员额、俸秩，并记郎与谒者。 [[7]](#note-7)

<a id="event-8"></a>

8. **卫尉、太仆、廷尉与大鸿胪。** 卫尉属掌宫门与宿卫，太仆有关车辆、马厩；廷尉、大鸿胪分掌刑狱与宾客朝会事务。 [[8]](#note-8)

<a id="event-9"></a>

9. **宗正与大司农。** 列宗正及宗室业务，又列大司农所属太仓、平准、导官等机构，说明秩禄与所属。 [[9]](#note-9)

<a id="event-10"></a>

10. **少府与宫中近属。** 少府所属涵盖医药、膳食、园苑、侍从、掖庭、尚方及诸库。条末亦列尚书、符节、御史中丞与兰台等官。 [[10]](#note-10)

<a id="event-11"></a>

11. **执金吾、皇后宫与太子宫。** 先列执金吾及武库，再列太子太傅、大长秋和中宫诸官。太子少傅以下，班簿兼记宫属、率更、仓食和警卫事务。 [[11]](#note-11)

<a id="event-12"></a>

12. **将作、城门、北军与司隶。** 将作管营造，城门校尉领门卫；北军中候属五校。司隶校尉与河南尹、三辅条见卷末。 [[12]](#note-12)

<a id="event-13"></a>

13. **州郡县乡与边职。** 列刺史、郡守、县令长等地方分工及乡、亭、里职吏，再列使匈奴中郎将、护乌桓与护羌校尉。 [[13]](#note-13)

<a id="event-14"></a>

14. **王国、列侯、属国与官俸。** 区分王国与侯国的国相等官，另记宋卫以及来附诸国。卷末列俸秩并以不增冗官作赞。 [[14]](#note-14)

<a id="event-15"></a>

15. **舆服等级与车辆用途。** 先释车服表功，再列天子玉路和乘舆车辆、耕猎戎车，以及太后、皇子、官员及命妇车辆的盖、轓、饰件。 [[15]](#note-15)

<a id="event-16"></a>

16. **卤簿、使车与导从。** 分别记大驾、法驾、小驾及其随车警卫，也列使车、丧车和官吏导从，最后查车马纹饰。 [[16]](#note-16)

<a id="event-17"></a>

17. **各类冠冕。** 从礼服起源列冕冠、长冠、爵弁、委貌、通天冠及各类文武、祭祀冠式，并依身份配缨蕤。 [[17]](#note-17)

<a id="event-18"></a>

18. **佩玉、印绶和色采。** 列朝服、佩玉、印章及绶色，区别天子、诸侯王、公卿至百石的工艺、尺幅和纹采。 [[18]](#note-18)

<a id="event-19"></a>

19. **后妃命妇服饰与卷末赞。** 记皇后、太后、贵人、公主和命妇的祭蚕衣、步摇与簪珥，末段列裁制、禁令和行礼服用，赞概括车服的礼制意义。 [[19]](#note-19)

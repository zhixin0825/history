## 本年概述

建安六年，曹操在仓亭击破袁绍军，袁绍回河北收聚散卒、平定叛郡。曹操采荀彧之议，仍以河北为先。他九月回许，随后转攻刘备，刘备转投刘表。荆州另有刘表攻西鄂，益州则是刘璋平赵韙。

> 六年，太祖就穀東平之安民，糧少，不足與河北相支，欲因紹新破，以其間擊討劉表。

**释读** 建安六年曹操到东平安民就粮，粮不够在河北久持，想乘袁绍初败南击刘表。

**归年** 本传明六年，卷001 L55、《通鉴》卷064相应。

<a id="sgz010-b-510-2"></a>

**[《三国志·二荀贾传》仓内原文 L510](../../sources/本地分卷/三国志/三国志-卷010.md#l510)**

> 彧曰：「今紹敗，其衆離心，宜乘其困，遂定之；而背兗、豫，遠師江、漢，若紹收其餘燼，承虛以出人後，則公事去矣。」太祖復次於河上。

**释读** 荀彧说袁军人心离散宜乘势击，若远攻刘表则袁绍会整军袭后，曹操从之又屯河上。

**归年** 《通鉴》卷064建安六年及本传同事。

<a id="sgz010-p-010-2"></a>

**[《三国志·二荀贾传》裴注 010·2](../../sources/本地分卷/三国志/三国志-卷010.md#pei-010-2)**

> 及紹破敗臣糧亦盡以為河北未易圖也欲南討劉表彧復止臣陳其得失臣用反斾遂吞㐫族克平四州

**释读** 曹操说官渡胜后军粮也尽，想南攻刘表，荀彧再讲利弊，令自己回军继续攻袁氏。

**归年** 建安六年，正文 L510、通鉴卷064均同。句末“克平四州”是其后数年达成。

> 與夏侯淵圍昌豨於東海，數月糧盡，議引軍還，遼謂淵曰：「數日已來，每行諸圍，豨輒屬目視遼。又其射矢更稀，此必豨計猶豫，故不力戰。遼欲挑與語，儻可誘也？」

<a id="sgz017-b-873-10"></a>

**[《三国志·二张乐于徐传》仓内原文 L873](../../sources/本地分卷/三国志/三国志-卷017.md#l873)**

> 乃使謂豨曰：「公有命，使遼傳之。」豨果下與遼語，遼為說「太祖神武，方以德懷四方，先附者受大賞」。豨乃許降。

**释读** 张辽遣人传话，再以归曹有赏相劝，昌豨答应投降。

**归年** 同属《通鉴》所系东海之战。

<a id="sgz017-b-873-11"></a>

> 遼遂單身上三公山，入豨家，拜妻子。豨歡喜，隨詣太祖。太祖遣豨還，責遼曰：「此非大將法也。」遼謝曰：「以明公威信著於四海，遼奉聖旨，豨必不敢害故也。」

**释读** 张辽独登三公山见昌豨及家人，昌豨随其见曹操。曹操令昌豨回去，却责张辽行事犯险；张辽以曹操信誉作答。

**归年** 一次围降，后来于禁所讨系另一次复叛。

### 4. 刘表攻西鄂，杜袭率吏民守城

[返回正文第4条](#ce201-event-4)

<a id="sgz-note-19"></a>

<a id="sgz023-b-1258-3"></a>

**[《三国志·和常杨杜赵裴传》仓内原文 L1258](../../sources/本地分卷/三国志/三国志-卷023.md#l1258)**

> 會荊州出步騎萬人來攻城，襲乃悉召縣吏民任拒守者五十餘人，與之要誓。其親戚在外欲自營護者，恣聽遣出；皆叩頭原致死。

**归年** 裴注《九州春秋》明建安六年。

<a id="sgz023-b-1258-4"></a>

**[《三国志·和常杨杜赵裴传》仓内原文 L1258](../../sources/本地分卷/三国志/三国志-卷023.md#l1258)**

> 於是身執矢石，率與戮力。吏民感恩，咸為用命。臨陳斬數百級，而襲眾死者三十餘人，其餘十八人盡被創，賊得入城。襲帥傷痍吏民決圍得出，死喪略盡，而無反背者。遂收散民，徙至摩陂營，吏民慕而從之如歸。

**释读** 斩敌数百，自方伤亡几尽，杜袭率余人突围，集散民移摩陂。

**归年** 仍为《九州春秋》所证201年围西鄂。

<a id="sgz023-p-013-1"></a>

**[《三国志·和常杨杜赵裴传》裴注 013·1](../../sources/本地分卷/三国志/三国志-卷023.md#pei-013-1)**

> 九州春秋曰建安六年劉表攻西鄂西鄂長杜子緒帥縣男女嬰城而守時南陽功曹栢孝長亦在城中聞兵攻聲恐懼入室閉戸牽被覆頭相攻半日稍敢出面其明側立而聽二日往出戸問消息至四五日乃更負楯親鬬語子緒曰勇可習也

**释读** 《九州春秋》记柏孝长在攻城时由畏伏被中，逐渐敢持盾出斗，因此说勇可习。

**归年** 注文明确建安六年，与杜袭当守事互见。

> 巴西太守龐羲以天下擾亂，郡宜有武衛，頗招合部曲。有讒於璋，說羲欲叛者，璋陰疑之。羲聞，甚懼，將謀自守，遣畿子鬱宣旨，索兵自助。畿報曰：「郡合部曲，本不為叛，雖有交構，要在盡誠；若必以懼，遂懷異志，非畿之所聞。」並敕鬱曰：「我受州恩，當為州牧盡節。汝為郡吏，當為太守效力，不得以吾故有異志也。」羲使人告畿曰：「爾子在郡，不從太守，家將及禍！」畿曰：「昔樂羊為將，飲子之羹，非父子無恩，大義然也。今雖復羹子，吾必飲之。」羲知畿必不為己，厚陳謝於璋以致無咎。璋聞之，遷畿江陽太守。

**释读** 庞羲在益州乱后疑惧，派程祁劝父亲程畿发賨兵。程畿不肯，后来升任江阳太守。

**归年** 《资治通鉴》卷六十四系庞羲与程畿事于建安六年赵韙败亡之后。本传后及升任，未书月日。

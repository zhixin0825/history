# 201年｜司马懿第一次被曹操征召，却没有去

[← 公元200年](../ce-0101-0200/ce-0200.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元202年 →](ce-0202.md)

**汉献帝建安六年**


> 本页已整理的内容：司马懿第一次进入有明确年份的政治记录。郡里举他为上计掾，曹操也想征用他，但《晋书》记他以风痹为由拒绝出仕。
>
> 本页只整理本轮已经审到的《晋书》材料及必要互证，不代表201年的全部历史已经写完。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="郡里先把司马懿举出来"></a>

<a id="event-1"></a>

1. **郡里先把司马懿举出来。** 建安六年，河内郡举司马懿为上计掾。这是《晋书》卷一第一次给司马懿的经历安上明确年号，也因此成为本项目处理《晋书》的第一张可确定年份页。 [[1]](#note-1)

   “上计”本来与地方向中央呈报户口、财政等事务有关。这里最重要的不是官名细节，而是：到201年，司马懿已经进入地方官府可以推荐、征用的士人范围。

<a id="曹操想征他他称病不出"></a>

<a id="event-2"></a>

2. **曹操想征他，他称病不出。** 当时曹操还任司空。《晋书》说曹操听到司马懿的名声后征召他，司马懿不愿“屈节曹氏”，便称自己患风痹、不能起居。曹操甚至派人夜里去试探，他仍躺着不动。 [[2]](#note-2)

   这段“夜里试病”的故事很有传记色彩。它目前只有《晋书》这条叙事支撑；《资治通鉴》建安六年的年条没有收入这次征辟。因此正文保留“《晋书》记司马懿拒辟”这一事实层级，不把夜间试探进一步发挥成已经被多源证实的戏剧场景。

<a id="登场前事他是谁"></a>

<a id="event-3"></a>

3. **登场前事：他是谁。** 在进入201年以前，《晋书》先交代司马懿字仲达，是河内温县人、司马防第二子；又说同郡的杨俊在司马懿未满二十岁时已看出他的才干。崔琰也曾向司马朗称赞其弟。 [[3]](#note-3)

   这些评价说明《晋书》希望把司马懿塑造成早有名望的人物，但原段没有给每次评价的确年。这里把它们放在首次登场处帮助读者认识人物，**不表示这些事都发生在201年**。

> 宣皇帝諱懿，字仲達，河內溫縣孝敬里人，姓司馬氏。其先出自帝高陽之子重黎，為夏官祝融。歷唐、虞、夏、商，世序其職。及周，以夏官為司馬。其後程伯休父，周宣王時，以世官克平徐方，錫以官族，因而為氏。楚漢間，司馬卬為趙將，與諸侯伐秦。秦亡，立為殷王，都河內。漢以其地為郡，子孫遂家焉。自卬八世，生征西將軍鈞，字叔平。鈞生豫章太守量，字公度。量生潁川太守儁，字元異。儁生京兆尹防，字建公。帝即防之第二子也。少有奇節，聰朗多大略，博學洽聞，伏膺儒教。漢末大亂，常慨然有憂天下心。南陽太守同郡楊俊名知人，見帝，未弱冠，以為非常之器。尚書清河崔琰與帝兄朗善，亦謂朗曰：「君弟聰亮明允，剛斷英特，非子所及也。」
> 
> 漢建安六年，郡舉上計掾。魏武帝為司空，聞而辟之。帝知漢運方微，不欲屈節曹氏，辭以風痹，不能起居。魏武使人夜往密刺之，帝堅臥不動。及魏武為丞相，又辟為文學掾，敕行者曰：「若復盤桓，便收之。」帝懼而就職。於是使與太子游處，遷黃門侍郎，轉議郎、丞相東曹屬，尋轉主簿。

这里的“魏武帝”“宣皇帝”都是《晋书》站在后来晋朝立场上的追称；201年当时曹操并非皇帝，司马懿也当然还不是“宣帝”。

> 司馬宣王年十六七，與俊相遇，俊曰：「此非常之人也。」

（次段）

> 太祖除俊曲梁長，入為丞相掾屬，舉茂才，安陵令，遷南陽太守。

《晋书》仓内本以杨俊后来的南阳太守职称介绍其人，旧本另作南郡。钱大昕据《三国志》辨正为南阳。《三国志》先叙相遇，后叙杨俊任南阳太守，正文因此把会面与任官分开。[百科与文献复核](../../meta/记录/晋书-卷001-黄初段引文去向.md#建安七页复核)

[返回正文第15条](#sg-event-15)

<a id="sg031-l1636-e15"></a>

**[《三国志·刘二牧传》](../../sources/摘录/三国志-卷031-刘二牧传.md#p002)** · [仓内TXT L1636](../../sources/本地分卷/三国志/三国志-卷031.md#l1636)

> 趙韙稱兵內向，眾散見殺

**归年与互校** 本传连叙起事与败亡，《华阳国志》卷五明确败亡在起事次年。

<a id="sgz031-b-1636-3"></a>

**[《三国志·刘二牧传》仓内原文 L1636](../../sources/本地分卷/三国志/三国志-卷031.md#l1636)**

> 趙韙稱兵內向，眾散見殺，皆由璋明斷少而外言入故也。

**释读** 赵韙在益州起兵反刘璋，所部溃散，他被杀。

**归年** 《通鉴》卷063、064分别系200年起兵和201年败亡；传文合叙，各节点见注012。

<a id="sgz031-p-012-3"></a>

**[《三国志·刘二牧传》裴注 012·3](../../sources/摘录/三国志-卷031-刘二牧传裴注.md#pei-012-3)**

**释读** 刘璋退守成都，东州人合力为其作战。赵韙部将庞乐、李异倒戈，赵韙身死。

**归年** 《通鉴》卷064建安六年接续。

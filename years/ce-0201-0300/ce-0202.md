## 本年概述

袁绍五月去世，袁尚继领其部，袁谭自号车骑将军屯黎阳。曹操秋季自官渡向黎阳进兵，与二袁连战；河东另有钟繇会关中诸军击郭援。荆州方面，刘备在博望设伏，孙权在江东拒绝送质子。

## 河北、河东与荆州战事

1. **袁绍去世，袁尚继立，袁谭屯黎阳。** 五月庚戌，袁绍去世。审配、逢纪奉袁尚继领其众，辛评、郭图等则与长子袁谭交好。袁谭未能继立，自号车骑将军，屯黎阳。二人继位争议与随后相攻，见[次年河北战事](ce-0203.md#sg-note-9)。 [[1]](#ce202-note-1)

2. **曹操从官渡进黎阳，与袁谭、袁尚连战。** 曹操进军官渡，秋九月进兵黎阳，袁谭向袁尚求援，因未获足够兵力而杀随军的逢纪。袁尚命审配守邺，亲自率军来援。二袁与曹军连战后退据城中。荀攸随军。袁尚遣高蕃截断黄河水路，曹操本令李典、程昱必要时改走陆路。李典看出敌军倚水而无备，和程昱商定先行渡河，击破高蕃，使粮船得以通行。战事延至次年春。 [[2]](#ce202-note-2)

3. **朝廷安抚马腾、韩遂，钟繇会关中兵击郭援。** 曹操在河北用兵，朝廷任马腾为征南将军、韩遂为征西将军。钟繇围匈奴单于于平阳，袁尚所任的河东太守郭援与高干率兵进入河东，郭援与单于合攻绛邑，守将贾逵在被俘前已派人送回官印，请河东先守皮氏，又设法拖延郭援的进军。绛邑失守，贾逵拒绝降服，父老与郭援军中有人力救，他才免死，后由祝公道从土窖救出。钟繇主张趁郭援渡汾未半击之。张既、傅干劝马腾助曹，马腾遣马超率兵与钟繇会合，马超所部庞德为前锋，在平阳击破郭援、高干，斩郭援。郭援是钟繇的外甥，钟繇见其首级哭泣，却认为庞德无罪。庞德获任中郎将，封都亭侯。匈奴单于投降。 [[3]](#ce202-note-3)

<a id="ce202-event-4"></a>

<a id="sgz-event-19"></a>

4. **刘备设伏博望，李典驰援夏侯惇。** 刘表派刘备北进至叶县，夏侯惇、于禁等在博望与之相持。刘备焚营诈退，李典见南道狭窄、草木茂密，劝夏侯惇不要追击。夏侯惇、于禁仍率兵追入伏中，李典驰救，刘备随即退兵。此役赵云生擒夏侯兰，向刘备求免其死并荐为军正。 [[4]](#ce202-note-4)

## 江东人事与朝廷纪事

6. **孙权表朱治为太守、行扶义将军。** 朱治此前已领吴郡事务。孙权本年上表授他太守职，行扶义将军，以娄、由拳、无锡、毗陵四县为奉邑，设置长吏。 [[6]](#ce202-note-6)

<a id="ce202-event-7"></a>

<a id="sgz-event-17"></a>

7. **曹操索孙权质子，孙权拒送。** 曹操破袁绍后向孙权索取质子，张昭、秦松等犹豫。孙权不愿送，同周瑜到母亲面前定议。周瑜指出江东有兵有粮，送出人质便要受曹操支使，劝孙权保持自主，观望局势。孙母赞同，孙权遂不送人质。 [[7]](#ce202-note-7)

### 2. 曹操从官渡进黎阳，与袁谭、袁尚连战

> 太祖擊譚、尚於黎陽，使典與程昱等以船運軍糧。會尚遣魏郡太守高蕃將兵屯河上，絕水道，太祖勑典、昱：「若船不得過，下從陸道。」典與諸將議曰：「蕃軍少甲而恃水，有懈怠之心，擊之必克。軍不內禦；苟利國家，專之可也，宜亟擊之。」昱亦以爲然。遂北渡河，攻蕃，破之，水道得通。

**釋讀與歸年** 曹操攻黎阳，李典与程昱等的运粮船遭魏郡太守高蕃阻断，奉命若不通便改走陆路。李典料敌少甲且恃河松懈，主张相机出击，程昱同意，二人北渡击破高蕃。[《三国志·武帝纪》](../../拆分史书/三国志/卷001.txt#L136-L138)定黎阳战事始于建安七年秋，延至次春，破高蕃无独立月日，随粮道受阻附首年。

**[《三國志·劉司馬梁張溫賈傳》](../../拆分史书/三国志/卷015.md#edition-wei015-l85-2)** · [TXT L85](../../拆分史书/三国志/卷015.txt#L85) · [TXT L86（裴注）](../../拆分史书/三国志/卷015.txt#L86) · [TXT L87](../../拆分史书/三国志/卷015.txt#L87)

> 郭援之攻河東，所經城邑皆下，逵堅守，援攻之不拔，乃召單于并軍急攻之。城將潰，絳父老與援要，不害逵。絳人旣潰，援聞逵名，欲使爲將，以兵劫之，逵不動。左右引逵使叩頭，逵叱之曰：「安有國家長吏爲賊叩頭！」援怒，將斬之。絳吏民聞將殺逵，皆乘城呼曰：「負要殺我賢君，寧俱死耳！」左右義逵，多爲請，遂得免。
>

**釋讀與歸年** 郭援诸城皆下，遭贾逵坚守，后会南匈奴单于合围。绛民以不伤贾逵为降约。城破后贾逵拒绝拜降，吏民登城相救，郭援军中也有人替他说情，才免一死。[《资治通鉴》卷64](../../史书/025-资治通鉴/KR2b0007_064.txt#L84-L94)把守绛与破郭援同入建安七年。

**釋讀與歸年** 《魏略》记贾逵被俘后曾囚在壶关的土窖里，祝公道听到他斥问守者，趁夜将他救出。正文只说明免于被斩，此注补被囚与脱身经过。

**釋讀與歸年** 绛邑告急时，贾逵派人送回印绶并请抢占皮氏，又设法迷惑郭援的谋士祝奥，拖住敌军七天。河东依计先据皮氏。[《资治通鉴》卷64](../../史书/025-资治通鉴/KR2b0007_064.txt#L86-L99)将贾逵保河东、随后钟繇等击郭援连记。

>
> **〔裴注〕**
> 司馬彪戰略曰：袁尚遣高幹、郭援將兵數萬人，與匈奴單于寇河東，遣使與馬騰、韓遂等連和，騰等陰許之。傅幹說騰曰：「古人有言『順道者昌，逆德者亡』。曹公奉天子誅暴亂，法明國治，上下用命，有義必賞，無義必罰，可謂順道矣。袁氏背王命，驅胡虜以陵中國，寬而多忌，仁而無斷，兵雖彊，實失天下心，可謂逆德矣。今將軍旣事有道，不盡其力，陰懷兩端，欲以坐觀成敗，吾恐成敗旣定，奉辭責罪，將軍先爲誅首矣。」於是騰懼。幹曰：「智者轉禍爲福。今曹公與袁氏相持，而高幹、郭援獨制河東，曹公雖有萬全之計，不能禁河東之不危也。將軍誠能引兵討援，內外擊之，其勢必舉。是將軍一舉，斷袁氏之臂，解一方之急，曹公必重德將軍。將軍功名，竹帛不能盡載也。唯將軍審所擇！」騰曰：「敬從教。」於是遣子超將精兵萬餘人，并將遂等兵，與繇會擊援等，大破之。

### 7. 曹操索孙权质子，孙权拒送

[返回正文第7条](#ce202-event-7)

<a id="sgz054-p-005-1"></a>

<a id="sgz054-p-005-2"></a>

<a id="sgz054-p-005-3"></a>

<a id="wu054-l17-1"></a>

**[《三國志·周瑜魯肅呂蒙傳》裴注 005](../../拆分史书/三国志/卷054.md#edition-wu054-l17-1)** · [TXT L17](../../拆分史书/三国志/卷054.txt#L17)

> 江表傳曰：曹公新破袁紹，兵威日盛，建安七年，下書責權質任子。權召羣臣會議，張昭、秦松等猶豫不能決，權意不欲遣質，乃獨將瑜詣母前定議，瑜曰：「昔楚國初封於荊山之側，不滿百里之地，繼嗣賢能，廣土開境，立基於郢，遂據荊揚，至於南海，傳業延祚，九百餘年。今將軍承父兄餘資，六郡之衆，兵精糧多，將士用命，鑄山爲銅，煑海爲鹽，境內富饒，人不思亂，汎舟舉帆，朝發夕到，士風勁勇，所向無敵，有何偪迫，而欲送質？質一入，不得不與曹氏相首尾，與相首尾，則命召不得不往，便見制於人也。極不過一侯印，僕從十餘人，車數乘，馬數匹，豈與南靣稱孤同哉？不如勿遣，徐觀其變。若曹氏能率義以正天下，將軍事之未晚。若圖爲暴，亂兵猶火也，不戢將自焚。將軍韜勇抗威，以待天命，何送質之有！」權母曰：「公瑾議是也。公瑾與伯符同年，小一月耳，我視之如子也，汝其兄事之。」遂不送質。

**釋讀** 曹操戰勝袁紹、兵威正盛，向孫權索要人質。張昭、秦松等議而未決；孫權本不願送，帶周瑜到母親面前議定。周瑜以楚國初封不足百里、後據荊揚傳世九百餘年為例，指出江東承父兄之業，六郡兵糧充足，兵士用命，產銅鹽而百姓安定，乘船調兵便利。一旦送質便須聽曹操號令，所得至多是列侯的儀仗，遠不及在江東自立。他勸孫權先觀望，若曹操能以義平天下，再依從亦未晚，若恃兵行暴，終會害到自身。孫母支持，說周瑜比孫策小一月，把他當作自己的兒子，讓孫權以兄事之。孫權遂不送人質。

**歸年** 裴注明書建安七年，《通鑑》卷六十四同繫此年；與208年曹操入荊州後朱治阻孫賁送質分屬兩事。

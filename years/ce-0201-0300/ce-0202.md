# 公元202年｜建安七年

[← 公元201年](ce-0201.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元203年 →](ce-0203.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **袁绍薨。** 七年夏五月庚戌，袁绍去世。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **於窴国献驯象。** 于窴国献驯象。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **是岁，越巂男子化为女子。** 当年，越巂男子化为女子。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **马腾、韩遂奉朝命各领将军。** 曹操在河北用兵，怕二人乘虚，先拜马腾为征南将军、韩遂为征西将军。 [[4]](#hh-note-4)

<a id="sg-event-5"></a>

5. **公军谯，令曰“吾起义兵”。** 七年春正月，公军谯，令曰：「吾起义兵，爲天下除暴乱。旧土人民，死丧略尽，国中终日行，不见所识，使吾凄怆伤怀。其举义兵已来，将士绝无后者，求其亲戚以后之，授上田，官给耕牛，置学师以教之。爲存者立庙，使祀其先人，魂而有灵，吾百年之后何恨哉！」 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **遂至浚仪，治睢阳渠。** 遂至浚仪，治睢阳渠，派使以太牢祀桥玄。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **进军官渡。** [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **小子尚代，谭自号车骑将军。** 小子尚代，谭自号车骑将军，屯黎阳。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **公征之，连战。** 秋九月，公征之，连战。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **谭、尚数败退，固守。** [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **钟繇会关中诸将击郭援。** 马超所部庞德充当前锋，击破郭援、高干军并亲自斩郭援。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **孙权母吴夫人去世。** 建安七年吴夫人去世，临终向张昭等托付后事。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **权表治为〔吴郡〕太守。** 建安七年，权表治为〔吴郡〕太守，行扶义将军，割娄、由拳、无锡。 [[13]](#sg-note-13)

<a id="sy-event-14"></a>

14. **荀攸随曹操讨袁谭、袁尚。** 荀攸随曹操进兵黎阳，讨伐袁谭、袁尚。 [[14]](#sy-note-14)

**归年** 本纪建安七年春正月遣使祀桥玄，《通鉴》卷六十四同；相识与约定属祭文追念，未独载年月。

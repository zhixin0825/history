<a id="hh-event-1"></a>

1. **袁绍薨。** 七年夏五月庚戌，袁绍去世。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **於窴国献驯象。** 于窴国献驯象。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **是岁，越巂男子化为女子。** 当年，越巂男子化为女子。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **马腾、韩遂奉朝命各领将军。** 曹操在河北用兵，怕二人乘虚，先拜马腾为征南将军、韩遂为征西将军。 [[4]](#hh-note-4)

<a id="sg-event-5"></a>

5. **公军谯，令曰“吾起义兵”。** 七年春正月，公军谯，令曰：「吾起义兵，爲天下除暴乱。旧土人民，死丧略尽，国中终日行，不见所识，使吾凄怆伤怀。其举义兵已来，将士绝无后者，求其亲戚以后之，授上田，官给耕牛，置学师以教之。爲存者立庙，使祀其先人，魂而有灵，吾百年之后何恨哉！」 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **遂至浚仪，治睢阳渠。** 遂至浚仪，治睢阳渠，派使以太牢祀桥玄。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **进军官渡。** [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **小子尚代，谭自号车骑将军。** 小子尚代，谭自号车骑将军，屯黎阳。 [[8]](#sg-note-8)

<a id="sg-event-10"></a>

<a id="sy-event-14"></a>

<a id="sgz-event-18"></a>

<a id="sg-event-9"></a>

9. **曹操在黎阳与袁谭、袁尚连战。** 秋九月，曹操进兵黎阳，袁谭、袁尚败而据城自守。荀攸随军，曹军又击高蕃，解除粮道受阻。次年春续战另见203年。 [[9]](#sg-note-9)

<a id="sg-event-11"></a>

11. **钟繇会关中诸将击郭援。** 马超所部庞德充当前锋，击破郭援、高干军并亲自斩郭援。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **孙权母吴夫人去世。** 建安七年吴夫人去世，临终向张昭等托付后事。 [[12]](#sg-note-12)

<a id="sgz-event-16"></a>

<a id="sg-event-13"></a>

13. **权表治为〔吴郡〕太守。** 建安七年，权表治为〔吴郡〕太守，行扶义将军，割娄、由拳、无锡。 [[13]](#sg-note-13)

<a id="sgz-event-15"></a>

15. **经师任安去世。** 任安去世，年七十九，门人为之立碑颂扬。 [[15]](#sgz-note-15)

<a id="sgz-event-17"></a>

17. **曹操索孙权质子，孙权拒送。** 曹操破袁绍后向孙权索取质子，张昭、秦松等犹豫。孙权不愿送，于母亲前同周瑜定议。 [[17]](#sgz-note-17)

<a id="sgz-event-19"></a>

19. **刘备设伏博望，李典驰援夏侯惇。** 夏侯惇、于禁与刘备在博望相持。刘备焚营诈退，魏军追击中伏，李典驰救。此役赵云生擒夏侯兰，向刘备求免其死并荐为军正。 [[19]](#sgz-note-19)

### 9. 曹操在黎阳与袁谭、袁尚连战

[返回正文第9条](#sg-event-9)

> 太祖擊譚、尚於黎陽，使典與程昱等以船運軍糧。會尚遣魏郡太守高蕃將兵屯河上，絕水道，太祖敕典、昱：「若船不得過，下從陸道。」

**归年** 《武帝纪》建安七年九月至次年三月同一黎阳战事，船运随起役。

<a id="sgz018-b-901-4"></a>

**[《三国志·二李臧文吕许典二庞阎传》仓内原文 L901](../../sources/本地分卷/三国志/三国志-卷018.md#l901)**

> 典與諸將議曰：「蕃軍少甲而恃水，有懈怠之心，擊之必克。軍不內御；苟利國家，專之可也，宜亟擊之。」昱亦以為然。遂北渡河，攻蕃，破之，水道得通。

**释读** 李典以高蕃甲少而恃水，主张将领因利而决，程昱赞成，北渡破敌恢复水运。

**归年** 同一官军黎阳运输事，确日未载。

**释读** 曹操渡河攻袁谭，袁尚怕被袁谭夺援军，令审配守邺，自领兵至黎阳一同抵战。

> 郭援之攻河東，所經城邑皆下，逵堅守，援攻之不拔，乃召單于並軍急攻之。城將潰，絳父老與援要，不害逵。絳人既潰，援聞逵名，欲使爲將，以兵劫之，逵不動。左右引逵使叩頭，逵叱之曰：「安有國家長吏爲賊叩頭！」援怒，將斬之。絳吏民聞將殺逵，皆乘城呼曰：「負要殺我賢君，寧俱死耳！」左右義逵，多爲請，遂得免。

**释读** 郭援围绛，会同南匈奴急攻；父老请降保逵。城破后郭援欲迫任贼将，贾逵不肯下拜，众人援誓力救，终免死。

**[《三国志·周瑜鲁肃吕蒙传》裴注 005·2](../../sources/本地分卷/三国志/三国志-卷054.md#pei-005-2)**

> 瑜曰昔楚國初封於荆山之側不滿百里之地繼嗣賢能廣土開境立基於郢遂據荆陽至於南海傳業延祚九百餘年今將軍承父兄餘資兼六郡之衆兵精糧多將士用命鑄山為銅煮海為鹽境内富饒人不思亂汎舟舉㠶朝發夕到土風勁勇所向無敵冇何偪廹而欲送質質一入不得不與曹氏相首尾與相首尾則命召不得不往便見制於人也極不過一侯印僕從十餘人車數乗馬數匹豈與南面稱孤同哉不如勿遣徐觀其變若曹氏能率義以正天下將軍事之未晩若圖為暴亂兵猶火也不戢將自焚將軍韜勇抗威以待天命何送質之冇

**释读** 周瑜以楚从小发展为强作譬，指出孙权已有六郡、兵粮富足，失质子将交出自主，所得不过微薄侯爵；宜观曹操能否扶义再定。

**归年** 同202质子事，楚始封只是所引往事。

<a id="sgz054-p-005-3"></a>

**[《三国志·周瑜鲁肃吕蒙传》裴注 005·3](../../sources/本地分卷/三国志/三国志-卷054.md#pei-005-3)**

> 權母曰公瑾議是也公瑾與伯符同年小一月耳我視之如子也汝其兄事之遂不送質

**释读** 吴夫人支持周瑜，称其比孙策小一月如同己子，叫孙权以兄礼待，最终不遣质。

**归年** 同202拒质。

<a id="sgz-note-19"></a>

### 19. 刘备设伏博望，李典驰援夏侯惇

[返回正文第19条](#sgz-event-19)

<a id="sgz036-p-019-4"></a>

**[《三国志·关张马黄赵传》裴注 019·4](../../sources/本地分卷/三国志/三国志-卷036.md#pei-019-4)**

> 先是與夏侯惇戰於博望生獲夏侯蘭蘭是雲鄉里人少小相知雲白先主活之薦蘭明於法律以為軍正雲不用自近其慎慮類如此

**释读** 赵云生擒同乡夏侯兰，向刘备求全其命，荐为军正。

**归年** 《先主传》《李典传》同一博望之战。《资治通鉴》卷六十四系建安七年。

<a id="sgz032-b-1651-4"></a>

**[《三国志·先主传》仓内原文 L1651](../../sources/本地分卷/三国志/三国志-卷032.md#l1651)**

> 使拒夏侯惇、于禁等於博望。久之，先主設伏兵，一旦自燒屯偽遁，惇等追之，為伏兵所破。

**释读** 刘备在博望抵御夏侯惇、于禁。两军相持后，刘备焚营诈退，伏兵击破追兵。

**归年** 《李典传》地名、焚屯与伏兵同。《资治通鉴》卷六十四列为建安七年。

<a id="sgz018-b-901-5"></a>

**[《三国志·二李臧文吕许典二庞阎传》仓内原文 L901](../../sources/本地分卷/三国志/三国志-卷018.md#l901)**

> 劉表使劉備北侵，至葉，太祖遣典從夏侯惇拒之。

**归年** 《通鉴》卷六十四系建安七年，记到叶与博望伏击相连。

<a id="sgz018-b-901-6"></a>

**[《三国志·二李臧文吕许典二庞阎传》仓内原文 L901](../../sources/本地分卷/三国志/三国志-卷018.md#l901)**

> 備一旦燒屯去，惇率諸軍追擊之，典曰：「賊無故退，疑必有伏。南道狹窄，草木深，不可追也。」惇不聽，與於禁追之，典留守。惇等果入賊伏里，戰不利，典往救，備望見救至，乃散退。

**释读** 刘备焚屯退走，李典疑险道有伏劝勿追，夏侯惇、于禁仍追；果中伏，李典来救，刘备见而还。

**归年** 同次博望。

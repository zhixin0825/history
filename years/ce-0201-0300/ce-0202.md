[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **袁绍薨。** 七年夏五月庚戌，袁绍去世。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **於窴国献驯象。** 于窴国献驯象。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **是岁，越巂男子化为女子。** 当年，越巂男子化为女子。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **马腾、韩遂奉朝命各领将军。** 曹操在河北用兵，怕二人乘虚，先拜马腾为征南将军、韩遂为征西将军。 [[4]](#hh-note-4)

<a id="sg-event-5"></a>

5. **公军谯，令曰“吾起义兵”。** 七年春正月，公军谯，令曰：「吾起义兵，爲天下除暴乱。旧土人民，死丧略尽，国中终日行，不见所识，使吾凄怆伤怀。其举义兵已来，将士绝无后者，求其亲戚以后之，授上田，官给耕牛，置学师以教之。爲存者立庙，使祀其先人，魂而有灵，吾百年之后何恨哉！」 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **遂至浚仪，治睢阳渠。** 遂至浚仪，治睢阳渠，派使以太牢祀桥玄。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **进军官渡。** [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **小子尚代，谭自号车骑将军。** 小子尚代，谭自号车骑将军，屯黎阳。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **公征之，连战。** 秋九月，公征之，连战。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **谭、尚数败退，固守。** [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **钟繇会关中诸将击郭援。** 马超所部庞德充当前锋，击破郭援、高干军并亲自斩郭援。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **孙权母吴夫人去世。** 建安七年吴夫人去世，临终向张昭等托付后事。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **权表治为〔吴郡〕太守。** 建安七年，权表治为〔吴郡〕太守，行扶义将军，割娄、由拳、无锡。 [[13]](#sg-note-13)

<a id="sy-event-14"></a>

14. **荀攸随曹操讨袁谭、袁尚。** 荀攸随曹操进兵黎阳，讨伐袁谭、袁尚。 [[14]](#sy-note-14)

<a id="sgz-event-15"></a>

15. **经师任安去世。** 任安去世，年七十九，门人为之立碑颂扬。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **孙权表朱治为吴郡太守。** 孙权表朱治为吴郡太守、行扶义将军，以娄、由拳、无锡、毗陵为奉邑并任长吏。 [[16]](#sgz-note-16)

> 小子尚代，譚自號車騎將軍，屯黎陽。

<a id="sgz006-b-357-2"></a>

**[《三国志·董二袁刘传》仓内原文 L357](../../sources/本地分卷/三国志/三国志-卷006.md#l357)**

> 衆以譚長，欲立之。配等恐譚立而評等爲己害，緣紹素意，乃奉尚代紹位。譚至，不得立，自號車騎將軍。由是譚、尚有隙。

**释读** 众人原欲立年长的袁谭，审配等怕受害，奉袁尚继位。袁谭不能继立，自号车骑将军，与袁尚失和。

**归年** 袁绍建安七年五月死后。

<a id="sgz006-p-101-2"></a>

**[《三国志·董二袁刘传》裴注 101·2](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-101-2)**

**释读** 《典论》称袁绍死未殡，刘氏嫉杀其五妾并毁容，袁尚杀其家。

> 秋九月，公征之，連戰。

<a id="sgz006-b-357-3"></a>

**[《三国志·董二袁刘传》仓内原文 L357](../../sources/本地分卷/三国志/三国志-卷006.md#l357)**

> 太祖北征譚、尚。譚軍黎陽，尚少與譚兵，而使逢紀從譚。譚求益兵，配等議不與。譚怒，殺紀。

**释读** 曹操北征，袁谭驻黎阳；袁尚仅给少量兵且遣逢纪从军。袁谭求增兵未获，怒杀逢纪。

**归年** 《资治通鉴》卷064建安七年曹操开始北征的时段。

<a id="sgz006-b-357-4"></a>

**[《三国志·董二袁刘传》仓内原文 L357](../../sources/本地分卷/三国志/三国志-卷006.md#l357)**

> 太祖渡河攻譚，譚告急於尚。尚欲分兵益譚，恐譚遂奪其衆，乃使審配守鄴，尚自將兵助譚，與太祖相拒於黎陽。

**释读** 曹操渡河攻袁谭，袁尚怕被袁谭夺援军，令审配守邺，自领兵至黎阳一同抵战。

**归年** 《三国志·武帝纪》建安七年九月北征渡河，相持至八年。

**释读** 建安十二至十三年会稽无贡举，簿称府君遭忧；八、九年仍有举，虞喜认为卒在十二年。

**归年** 补录于本传202卒条，与本传建安七年并存。原注推论采用休举为证，可见其论据。

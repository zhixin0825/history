1. **公卿初迎冬於北郊，总章始复备八佾舞。** 八年冬十月己巳，公卿初迎冬于北郊，总章始复备八佾舞。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **初置司直官，督中都官。** [[2]](#hh-note-2)

<a id="sg-event-3"></a>

3. **攻其郭，乃出战。** 八年春三月，攻其郭，乃出战，击，大破之，谭、尚夜遁。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **进军邺。** 夏四月，进军邺。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **还许，留贾信屯黎阳。** 五月还许，留贾信屯黎阳。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **令曰“《司马法》『将军死绥』”。** 己酉，令曰：「《司马法》『将军死绥』，故赵括之母，乞不坐括。是古之将者，军破于外，而家受罪于内也。自命将征行，但赏功而不罚罪，非国典也。其令各将领出征，败军者抵罪，失利者免官爵。」 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **令曰“丧乱已来”。** 秋七月，令曰：「丧乱已来，十有五年，后生者不见仁义礼让之风，吾甚伤之。其令郡国各修文学，县满五百户置校官，选其乡之俊造而教学之，庶几先王之道不废，而有以益于天下。」 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **公征刘表，军西平。** 八月，公征刘表，军西平。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **公之去邺而南也，谭、尚争冀州。** 公之去邺而南也，谭、尚争冀州，谭爲尚所败，走保平原。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **尚攻之急，谭遣辛毗乞降请救。** [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **诸将皆疑，荀攸劝公许之。** 各将领皆疑，荀攸劝公许之，公乃引军还。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **到黎阳，爲子整与谭结婚。** 冬十月，到黎阳，爲子整与谭结婚。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **尚闻公北，乃释平原还邺。** [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **东平吕旷、吕翔叛尚，屯阳平。** 东平吕旷、吕翔叛尚，屯阳平，率其衆降，封爲列侯。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **孙权西讨黄祖而未拔城。** 孙权毁黄祖水师，城池未能攻克，因山中武装复起而回。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **丹杨太守吴景去世。** 吴景在吴夫人去世的次年卒，其后人袭封并领兵。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **以偏将军领丹杨太守，时年二十。** 建安八年，以偏将军领丹杨太守，时年二十。 [[17]](#sg-note-17)

<a id="sy-event-18"></a>

18. **曹操表封荀彧为万岁亭侯。** 曹操上表列数荀彧前后的功劳，请封荀彧为万岁亭侯。 [[18]](#sy-note-18)

<a id="wu-event-19"></a>

19. **曹操发庚申令，区分才德和战功。** 曹操回应军吏有功但未必适合治理郡国的问题，引用管仲说明任官用才、奖赏据战功的区别。 [[19]](#wu-note-19)

### 11. 诸将皆疑，荀攸劝公许之

[返回正文第11条](#sg-event-11)

<a id="sg001-l61-e11"></a>

**[《三国志·武帝纪》](../../sources/摘录/三国志-卷001-武帝纪.md#p005)** · [仓内TXT L61](../../sources/本地分卷/三国志/三国志-卷001.md#L61)

> 諸將皆疑，荀攸勸公許之，公乃引軍還。

<a id="sy-sg010-l521-e11"></a>

**[《三国志·二荀贾传》](../../sources/摘录/三国志-卷010-二荀贾传.md#p002)** · [仓内TXT L521](../../sources/本地分卷/三国志/三国志-卷010.md#L521)

> 明年，太祖方征劉表，譚、尚爭冀州。譚遣辛毗乞降請救，太祖將許之，以問羣下。羣下多以爲表彊，宜先平之，譚、尚不足憂也。攸曰：「天下方有事，而劉表坐保江、漢之閒，其無四方志可知矣。袁氏據四州之地，帶甲十萬，紹以寬厚得衆，借使二子和睦以守其成業，則天下之難未息也。今兄弟遘惡，其勢不兩全。若有所並則力專，力專則難圖也。及其亂而取之，天下定矣，此時不可失也。」太祖曰：「善。」乃許譚和親，遂還擊破尚。

**本段所记** 袁谭遣辛毗求援，诸将主张先讨刘表，荀攸则以袁氏兄弟分裂有机可乘，劝曹操允约回兵。

**归年与互校** 《荀攸传》承上句“七年”。《武帝纪》同年载荀攸劝许之。

<a id="wu-p-054-1"></a>

**[《三国志·武帝纪》裴注 054·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-054-1)**

> 魏書曰公云我攻吕布表不為冦官渡之役不救袁紹此自守之賊也宜為後圖譚尚狡猾當乘其亂縱譚挾詐不終束手使我破尚偏收其地利自多矣乃許之

**释读** 曹操判断刘表倾向自守，可以后图；袁氏兄弟争斗之际，即使袁谭怀诈也可乘机破袁尚，遂答应袁谭。

**归年** 紧接建安八年辛毗求援与荀攸倡议；攻吕布和官渡都是谈话中举出的旧例。

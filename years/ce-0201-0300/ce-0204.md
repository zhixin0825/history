<a id="wu-event-21"></a>

<a id="sgz-event-22"></a>

22. **孙权杀盛宪。** 盛宪被孙权诛杀，其故吏妫览、戴员藏入山中。 [[22]](#sgz-note-22)

<a id="sgz-event-23"></a>

23. **孔融致书曹操请救盛宪。** 孔融担忧好友盛宪受害，致书曹操。以知交零落起笔，说盛宪困于孙氏，妻儿已经亡没，处境孤危。 [[23]](#sgz-note-23)

<a id="sgz-event-24"></a>

24. **曹操辟崔琰为冀州别驾，崔琰劝先救民。** 曹操辟崔琰为冀州别驾，阅户籍估说该州可动员三十万人。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **邢颙由田畴处归冀州。** 邢颙说黄巾后二十多年天下久乱，曹公法令严，民厌乱必望平，愿先归乡。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **许攸恃功戏曹操、被捕及诛。** 后来曹操平冀州，许攸有功，却在座上呼曹操小字明说没自己不能取冀州；曹操外笑内嫌。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **曹操围邺，董昭致书袁春卿。** 曹军围邺，城内魏郡太守袁春卿之父袁元长在扬州，曹操遣使迎他。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **邺定，董昭任谏议大夫。** 曹操攻下邺城后授董昭谏议大夫。 [[28]](#sgz-note-28)

### 1. 曹操大破袁尚，平冀州，自领冀州牧

[返回正文第1条](#hh-event-1)

<a id="sg001-l62-e1"></a>

**[《三国志·武帝纪》](../../sources/摘录/三国志-卷001-武帝纪.md#p005)** · [仓内TXT L62](../../sources/本地分卷/三国志/三国志-卷001.md#l62)

> 九年春正月，濟河，遏淇水入白溝以通糧道。二月，尚復攻譚，留蘇由、審配守鄴。公進軍到洹水，由降。旣至，攻鄴，爲土山、地道。武安長尹楷屯毛城，通上黨糧道。夏四月，留曹洪攻鄴，公自將擊楷，破之而還。尚將沮鵠守邯鄲，又擊拔之。易陽令韓範、涉長梁岐舉縣降，賜爵關內侯。五月，毀土山、地道，作圍壍，決漳水灌城；城中餓死者過半。秋七月，尚還救鄴，諸將皆以爲「此歸師，人自爲戰，不如避之」。公曰：「尚從大道來，當避之；若循西山來者，此成禽耳。」尚果循西山來，臨滏水爲營。夜遣兵犯圍，公逆擊破走之，遂圍其營。未合，尚懼。故豫州刺史陰夔及陳琳乞降，公不許，爲圍益急。尚夜遁，保祁山，追擊之。其將馬延、張顗等臨陣降，衆大潰，尚走中山。盡獲其輜重，得尚印綬節鉞，使尚降人示其家，城中崩沮。八月，審配兄子榮夜開所守城東門內兵。配逆戰，敗，生禽配，斬之，鄴定。公臨祀紹墓，哭之流涕；慰勞紹妻，還其家人寶物，賜雜繒絮，廩食之。

<a id="wu-b-062-6"></a>

**[《三国志·武帝纪》仓内原文 L62](../../sources/本地分卷/三国志/三国志-卷001.md#l62)**

> 秋七月，尚還救鄴，諸將皆以爲「此歸師，人自爲戰，不如避之」。公曰：「尚從大道來，當避之；若循西山來者，此成禽耳。」尚果循西山來，臨滏水爲營。夜遣兵犯圍，公逆擊破走之，遂圍其營。未合，尚懼。故豫州刺史陰夔及陳琳乞降，公不許，爲圍益急。尚夜遁，保祁山，追擊之。其將馬延、張顗等臨陣降，衆大潰，尚走中山。盡獲其輜重，得尚印綬節鉞，使尚降人示其家，城中崩沮。

**释读** 袁尚沿西山回救，夜攻曹军包围线未果，遣人求降未获允；将领临阵降曹，袁尚逃往中山。曹军取其辎重和凭信展示给城中。

**归年** 本纪建安九年七月，《袁绍传》《通鉴》同述细节，退守地点异文保留。

<a id="wu-b-062-7"></a>

**[《三国志·武帝纪》仓内原文 L62](../../sources/本地分卷/三国志/三国志-卷001.md#l62)**

> 八月，審配兄子榮夜開所守城東門內兵。配逆戰，敗，生禽配，斬之，鄴定。

**释读** 审配侄子审荣夜开东门纳曹兵，审配被俘而斩，邺城归曹操。

**归年** 本纪建安九年八月，《后汉书·献帝纪》作八月戊寅。

<a id="wu-p-058-1"></a>

**[《三国志·武帝纪》裴注 058·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-058-1)**

> 曹瞞傳曰遣候者數部前後參之皆曰定從西道已在邯鄲公大喜會諸將曰孤已得冀州諸君知之乎皆曰不知公曰諸君方見不久也

**释读** 《曹瞒传》称数批侦候都证实袁尚由西道来，到邯郸时曹操告诉诸将，得冀州已不远。

**归年** 建安九年秋七月袁尚回救邺，参本纪L62。

<a id="sgz003-p-034-1"></a>

**[《三国志·明帝纪》裴注 034·1](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-034-1)**

> 臣松之案魏武以建安九年八月定鄴文帝始納甄后

**释读** 裴松之认为曹操建安九年定邺后曹丕才接纳甄氏，曹叡的年龄不得早于这一时间背景。

**归年** 本书卷001 L62明建安九年八月定邺；卷005《甄皇后传》亦记太祖定邺后曹丕纳甄氏。通鉴卷074《考异》记围定邺的月次有异说。

<a id="sgz005-b-310-2"></a>

**[《三国志·后妃传》仓内原文 L310](../../sources/本地分卷/三国志/三国志-卷005.md#l310)**

> 及冀州平，文帝納後於鄴，有寵，

**释读** 曹操平定冀州后，曹丕在邺纳甄氏，甄氏受宠。

**归年** 建安九年秋邺破。后文子女生年另判。

<a id="sgz005-p-009-2"></a>

**[《三国志·后妃传》裴注 009·2](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-009-2)**

> 及鄴城破紹妻及后共坐室堂上文帝入紹舍見紹妻及后后怖以頭伏姑膝上紹妻兩手自搏文帝謂曰劉夫人云何如此令新婦舉頭姑乃捧后令仰文帝就視見其顔色非凡稱歎之太祖聞其意遂為迎取世語曰太祖下鄴文帝先入袁尚府有婦人披髪垢面垂涕立紹妻劉後文帝問之劉荅是熙妻顧擥髪髻以巾拭面姿貌絶倫既過劉謂后不憂死矣遂見納有寵

**释读** 《魏略》称曹丕见甄氏伏在婆母膝上，由曹操代为迎取。《世语》称曹丕先入袁尚家，替甄氏拭面，后纳之。

**归年** 两种说法都以建安九年邺城陷落为时点。人物位置和迎取经过有别。

<a id="sgz006-b-358-5"></a>

**[《三国志·董二袁刘传》仓内原文 L358](../../sources/本地分卷/三国志/三国志-卷006.md#l358)**

> 尚聞鄴急，將兵萬餘人還救之，依西山來，東至陽平亭，去鄴十七里，臨滏水，舉火以示城中，城中亦舉火相應。配出兵城北，欲與尚對決圍。太祖逆擊之，敗還，尚亦破走，依曲漳爲營，

**释读** 袁尚率万余兵出西山到阳平亭，和城中以火相应。审配出城配合，被曹操击退，袁尚败走，依曲漳为营。

**归年** 《三国志·武帝纪》建安九年秋七月。

<a id="sgz006-b-358-6"></a>

**[《三国志·董二袁刘传》仓内原文 L358](../../sources/本地分卷/三国志/三国志-卷006.md#l358)**

> 太祖遂圍之。未合，尚懼，遣陰夔、陳琳乞降，不聽。尚還走濫口，進復圍之急，其將馬延等臨陣降，衆大潰，尚奔中山。盡收其輜重，得尚印綬、節鉞及衣物，以示其家，城中崩沮。

**释读** 袁尚求降未获许可，又退滥口。曹操追围，马延等临阵降，袁尚军大溃，奔中山，其辎重和印绶衣物被缴获。

**归年** 建安九年七月袁尚援邺战的后续。

<a id="sgz006-b-358-7"></a>

**[《三国志·董二袁刘传》仓内原文 L358](../../sources/本地分卷/三国志/三国志-卷006.md#l358)**

> 配兄子榮守東門，夜開門內太祖兵，與配戰城中，生禽配。配聲氣壯烈，終無撓辭，見者莫不歎息。遂斬之。

**释读** 守东门的审荣夜开门纳曹军。审配巷战被擒仍无屈辞，最终被斩。

**归年** 《三国志·武帝纪》建安九年八月，此处补审荣姓名和临刑情节。

<a id="sgz006-p-067-3"></a>

**[《三国志·董二袁刘传》裴注 067·3](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-067-3)**

> 及配兄子開城門内兵時配在城東南角樓上望見太祖兵入忿辛郭壊敗冀州乃遣人馳詣鄴獄指殺仲治家是時辛毗在軍聞門開馳走詣獄欲解其兄家兄家已死是日生縛配將詣帳下辛毗等逆以馬鞭擊其頭罵之曰奴汝今日真死矣配顧曰狗軰正由汝曹破我冀州恨不得殺汝也且汝今日能殺生我邪有頃公引見謂配知誰開卿城門配曰不知也曰自卿文榮耳配曰小兒不足用乃至此公復謂曰曩日孤之行圍何弩之多也配曰恨其少耳公曰卿忠於袁氏父子亦自不得不爾也有意欲活之配既無撓辭而辛毗等號哭不已乃殺之初冀州人張子謙先降素與配不善笑謂配曰正南卿竟何如我配厲聲曰汝為降虜審配為忠臣雖死豈若汝生邪臨行刑叱持兵者令北向曰我君在北

**释读** 审荣开门时审配先命杀辛评家，辛毗赶到已晚。曹操责问被缚的审配，审配无屈辞，辛毗等痛哭，曹操终杀之；审配临刑北向。

**归年** 建安九年八月邺破，前情与曹操攻城条合。

**[《三国志·董二袁刘传》裴注 067·4](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-067-4)**

> 樂資山陽公載記及袁暐獻帝春秋並云太祖兵入城審配戰於門中既敗逃干井中於井獲之

**释读** 《山阳公载记》《献帝春秋》称审配在城门败逃藏井被擒。

**归年** 同年邺破另一记载。

**[《三国志·诸夏侯曹传》仓内原文 L446](../../sources/本地分卷/三国志/三国志-卷009.md#l446)**

> 太祖平河北，爲大將軍後拒。

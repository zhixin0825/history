### 1. 曹操大破袁尚，平冀州，自领冀州牧

[返回正文第1条](#hh-event-1)

<a id="sg001-l62-e1"></a>

**[《三国志·武帝纪》](../../sources/摘录/三国志-卷001-武帝纪.md#p005)** · [仓内TXT L62](../../sources/本地分卷/三国志/三国志-卷001.md#l62)

> 九年春正月，濟河，遏淇水入白溝以通糧道。二月，尚復攻譚，留蘇由、審配守鄴。公進軍到洹水，由降。旣至，攻鄴，爲土山、地道。武安長尹楷屯毛城，通上黨糧道。夏四月，留曹洪攻鄴，公自將擊楷，破之而還。尚將沮鵠守邯鄲，又擊拔之。易陽令韓範、涉長梁岐舉縣降，賜爵關內侯。五月，毀土山、地道，作圍壍，決漳水灌城；城中餓死者過半。秋七月，尚還救鄴，諸將皆以爲「此歸師，人自爲戰，不如避之」。公曰：「尚從大道來，當避之；若循西山來者，此成禽耳。」尚果循西山來，臨滏水爲營。夜遣兵犯圍，公逆擊破走之，遂圍其營。未合，尚懼。故豫州刺史陰夔及陳琳乞降，公不許，爲圍益急。尚夜遁，保祁山，追擊之。其將馬延、張顗等臨陣降，衆大潰，尚走中山。盡獲其輜重，得尚印綬節鉞，使尚降人示其家，城中崩沮。八月，審配兄子榮夜開所守城東門內兵。配逆戰，敗，生禽配，斬之，鄴定。公臨祀紹墓，哭之流涕；慰勞紹妻，還其家人寶物，賜雜繒絮，廩食之。

<a id="wu-b-062-6"></a>

**[《三国志·武帝纪》仓内原文 L62](../../sources/本地分卷/三国志/三国志-卷001.md#l62)**

> 秋七月，尚還救鄴，諸將皆以爲「此歸師，人自爲戰，不如避之」。公曰：「尚從大道來，當避之；若循西山來者，此成禽耳。」尚果循西山來，臨滏水爲營。夜遣兵犯圍，公逆擊破走之，遂圍其營。未合，尚懼。故豫州刺史陰夔及陳琳乞降，公不許，爲圍益急。尚夜遁，保祁山，追擊之。其將馬延、張顗等臨陣降，衆大潰，尚走中山。盡獲其輜重，得尚印綬節鉞，使尚降人示其家，城中崩沮。

**释读** 袁尚沿西山回救，夜攻曹军包围线未果，遣人求降未获允；将领临阵降曹，袁尚逃往中山。曹军取其辎重和凭信展示给城中。

**归年** 本纪建安九年七月，《袁绍传》《通鉴》同述细节，退守地点异文保留。

<a id="wu-b-062-7"></a>

**[《三国志·武帝纪》仓内原文 L62](../../sources/本地分卷/三国志/三国志-卷001.md#l62)**

> 八月，審配兄子榮夜開所守城東門內兵。配逆戰，敗，生禽配，斬之，鄴定。

**释读** 审配侄子审荣夜开东门纳曹兵，审配被俘而斩，邺城归曹操。

**归年** 本纪建安九年八月，《后汉书·献帝纪》作八月戊寅。

<a id="wu-p-058-1"></a>

**[《三国志·武帝纪》裴注 058·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-058-1)**

> 曹瞞傳曰遣候者數部前後參之皆曰定從西道已在邯鄲公大喜會諸將曰孤已得冀州諸君知之乎皆曰不知公曰諸君方見不久也

**释读** 《曹瞒传》称数批侦候都证实袁尚由西道来，到邯郸时曹操告诉诸将，得冀州已不远。

**归年** 建安九年秋七月袁尚回救邺，参本纪L62。

<a id="sgz003-p-034-1"></a>

**[《三国志·明帝纪》裴注 034·1](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-034-1)**

> 臣松之案魏武以建安九年八月定鄴文帝始納甄后

**释读** 裴松之认为曹操建安九年定邺后曹丕才接纳甄氏，曹叡的年龄不得早于这一时间背景。

**归年** 本书卷001 L62明建安九年八月定邺；卷005《甄皇后传》亦记太祖定邺后曹丕纳甄氏。通鉴卷074《考异》记围定邺的月次有异说。

<a id="sgz005-b-310-2"></a>

**[《三国志·后妃传》仓内原文 L310](../../sources/本地分卷/三国志/三国志-卷005.md#l310)**

> 及冀州平，文帝納後於鄴，有寵，

**释读** 曹操平定冀州后，曹丕在邺纳甄氏，甄氏受宠。

**归年** 建安九年秋邺破。后文子女生年另判。

<a id="sgz005-p-009-2"></a>

**[《三国志·后妃传》裴注 009·2](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-009-2)**

> 及鄴城破紹妻及后共坐室堂上文帝入紹舍見紹妻及后后怖以頭伏姑膝上紹妻兩手自搏文帝謂曰劉夫人云何如此令新婦舉頭姑乃捧后令仰文帝就視見其顔色非凡稱歎之太祖聞其意遂為迎取世語曰太祖下鄴文帝先入袁尚府有婦人披髪垢面垂涕立紹妻劉後文帝問之劉荅是熙妻顧擥髪髻以巾拭面姿貌絶倫既過劉謂后不憂死矣遂見納有寵

**释读** 《魏略》称曹丕见甄氏伏在婆母膝上，由曹操代为迎取。《世语》称曹丕先入袁尚家，替甄氏拭面，后纳之。

**归年** 两种说法都以建安九年邺城陷落为时点。人物位置和迎取经过有别。

**[《三国志·武帝纪》裴注 061·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-061-1)**

> 魏書載公令曰有國有家者不患寡而患不均不患貧而患不安袁氏之治也使豪彊擅恣親戚兼并下民貧弱代出租賦衒鬻家財不足應命審配宗族至乃藏匿罪人為逋逃主欲望百姓親附甲兵彊盛豈可得邪其收田租畝四升戸出絹二疋綿二斤而已他不得擅興發郡國守相明檢察之無令彊民有所隱藏而弱民兼賦也

**归年** 附建安九年九月免当年租赋条，此令关乎整治旧制和征收常额，不与免当年租赋相混。

**归年与互校** 原传明记年号和年次；后续回叙见本卷。

<a id="wu-b-062-1"></a>

**[《三国志·武帝纪》仓内原文 L62](../../sources/本地分卷/三国志/三国志-卷001.md#l62)**

> 九年春正月，濟河，遏淇水入白溝以通糧道。

**释读** 曹军渡河，拦淇水引入白沟，沟通运粮水路。

**归年** 本纪明记建安九年正月；是围邺前运输工程。

<a id="wu-b-062-2"></a>

**[《三国志·武帝纪》仓内原文 L62](../../sources/本地分卷/三国志/三国志-卷001.md#l62)**

> 二月，尚復攻譚，留蘇由、審配守鄴。公進軍到洹水，由降。

**释读** 袁尚留苏由、审配守邺，自攻袁谭。曹军至洹水时苏由归降。

**归年** 本纪建安九年二月起；《袁绍传》补述苏由内应败露事。

<a id="wu-b-062-3"></a>

**[《三国志·武帝纪》仓内原文 L62](../../sources/本地分卷/三国志/三国志-卷001.md#l62)**

> 旣至，攻鄴，爲土山、地道。

**释读** 曹军抵邺，修土山、开地道。

**归年** 本纪建安九年，承二月袁尚离开邺城。

<a id="wu-b-062-4"></a>

**[《三国志·武帝纪》仓内原文 L62](../../sources/本地分卷/三国志/三国志-卷001.md#l62)**

> 武安長尹楷屯毛城，通上黨糧道。夏四月，留曹洪攻鄴，公自將擊楷，破之而還。尚將沮鵠守邯鄲，又擊拔之。易陽令韓範、涉長梁岐舉縣降，賜爵關內侯。

**释读** 尹楷驻毛城保上党粮道，曹操留曹洪继续围邺，自己打败尹楷，又攻取沮鹄驻守的邯郸；易阳、涉县降，令长受爵。

**归年** 本纪建安九年四月；《通鉴》卷六十四补足易阳、涉县归降次序。

<a id="wu-b-062-5"></a>

**[《三国志·武帝纪》仓内原文 L62](../../sources/本地分卷/三国志/三国志-卷001.md#l62)**

> 五月，毀土山、地道，作圍壍，決漳水灌城；城中餓死者過半。

**释读** 曹操改挖围沟，引漳水淹灌邺城，城中饥死者过半。

**归年** 本纪建安九年五月；《袁绍传》说饥死过半是五月至八月结果。

<a id="wu-p-057-1"></a>

**[《三国志·武帝纪》裴注 057·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-057-1)**

> 沮音菹河朔間今猶有此姓鵠沮授子也

**释读** 注解释沮氏姓读如“菹”，并说邯郸守将沮鹄是沮授之子。

**归年** 人物与语音注附建安九年四月曹军取邯郸。

<a id="sy-note-19"></a>

### 19. 荀彧劝曹操暂缓复古九州

[返回正文第19条](#sy-event-19)

<a id="sy-sg010-l510-e19"></a>

**[《三国志·二荀贾传》](../../sources/摘录/三国志-卷010-二荀贾传.md#p001)** · [仓内TXT L510](../../sources/本地分卷/三国志/三国志-卷010.md#L510)

> 或說太祖「宜復古置九州，則冀州所制者廣大，天下服矣。」太祖將從之，彧言曰：「若是，則冀州當得河東、馮翊、扶風、西河、幽、並之地，所奪者衆。前日公破袁尚，禽審配，海內震駭，必人人自恐不得保其土地，守其兵衆也；今使分屬冀州，將皆動心。且人多說關右諸將以閉關之計；今聞此，以爲必以次見奪。一旦生變，雖有善守者，轉相脅爲非，則袁尚得寬其死，而袁譚懷貳，劉表遂保江、漢之閒，天下未易圖也。願公急引兵先定河北，然後脩復舊京，南臨荊州，責貢之不入，則天下咸知公意，人人自安。天下大定，乃議古制，此社稷長久之利也。」太祖遂寢九州議。

**归年与互校** 《荀彧传》上句明记建安九年、曹操拔邺领冀州。“前日公破袁尚，禽審配”又证发生在拔邺之后。

<a id="wu-p-059-1"></a>

**[《三国志·武帝纪》裴注 059·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-059-1)**

> 孫盛云昔者先王之為誅賞也將以懲惡勸善永彰鑒戒紹因世艱危遂懐逆謀上議神器下干國紀薦社汚宅古之制也而乃盡哀於逆臣之冡加恩於饕餮之室為政之道於斯躓矣夫匿怨友人前哲所耻稅驂舊館義無虚涕茍道乖好絶何哭之有昔漢高失之於項氏魏武遵謬於此舉豈非百慮之一失也

**释读** 孙盛认为袁绍图谋僭越，哭祭他并善待家属有违惩恶，举汉高祖与项氏之旧事比照。

**归年** 评论对象为建安九年秋破邺后对袁氏家属的待遇，孫盛之评论是后世所作。

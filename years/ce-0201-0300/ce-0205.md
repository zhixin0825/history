## 本年概述

正月曹操攻下南皮，袁谭被杀，袁熙、袁尚随后败走乌丸。曹军在河北整编新附势力，八月又北上消灭赵犊等、解鲜于辅之围。并州高干重新举兵，河东卫固等与之响应，战事延入次年。

<a id="sgz026-b-1392-1"></a>

**[《三国志·满田牵郭传》仓内原文 L1392](../../sources/本地分卷/三国志/三国志-卷026.md#l1392)**

> 太祖將討袁譚，而柳城烏丸欲出騎助譚。太祖以招嘗領烏丸，遣詣柳城。到，值峭王嚴，以五千騎當遣詣譚。又遼東太守公孫康自稱平州牧，遣使韓忠齎單于印綬往假峭王。峭王大會群長，忠亦在坐。峭王問招：「昔袁公言受天子之命，假我爲單于；今曹公復言當更白天子，假我真單于；遼東復持印綬來。如此，誰當爲正？」招荅曰：「昔袁公承制，得有所拜假；中間違錯，天子命曹公代之，言當白天子，更假真單于，是也。遼東下郡，何得擅稱拜假也？」忠曰：「我遼東在滄海之東，擁兵百萬，又有扶餘、濊貊之用；當今之勢，彊者爲右，曹操獨何得爲是也？」招呵忠曰：「曹公允恭明哲，翼戴天子，伐叛柔服，寧靜四海，汝君臣頑嚚，今恃險遠，背違王命，欲擅拜假，侮弄神器，方當屠戮，何敢慢易咎毀大人？」便捉忠頭頓築，拔刀欲斬之。峭王驚怖，徒跣抱招，以救請忠，左右失色。招乃還坐，爲峭王等說成敗之效，禍福所歸，皆下席跪伏，敬受勑教，便辭遼東之使，罷所嚴騎。

**释读** 辽东公孙康与曹方都有册授之议，韩忠辩称强者有理，牵招斥之几斩。峭王接受曹方理由，遣返辽东使并撤五千援骑。

**归年** 《通鉴》卷六十四建安十年南皮战前，牵招本传按讨袁谭事相连。

> 魏畧曰詔徴河東太守王邑邑以天下未定心不願徴而吏民亦戀邑郡掾衛固中郎將范先等各詣繇求乞邑而詔已拜杜畿為太守畿已入界

**释读** 王邑不愿离郡，吏民亦不舍，卫固范先找钟繇请留，杜畿已受命入界。

**归年** 《通鉴》卷064建安十年冬。

<a id="sgz013-p-005-2"></a>

**[《三国志·钟繇华歆王朗传》裴注 005·2](../../sources/本地分卷/三国志/三国志-卷013.md#pei-005-2)**

> 繇不聼先等促邑交符邑佩卬綬徑從河北詣許自歸

**释读** 钟繇拒请求，王邑佩绶经河北县往许归朝。

**归年** 同次郡守交替。

<a id="sgz015-b-799-3"></a>

**[《三国志·刘司马梁张温贾传》仓内原文 L799](../../sources/本地分卷/三国志/三国志-卷015.md#l799)**

> 其後幹復舉並州反。河內張晟衆萬餘人無所屬，冦崤、澠閒，河東衞固、弘農張琰各起兵以應之。

**释读** 高干再起；张晟此前聚众扰崤渑，卫固、张琰相应。

**归年** 《武帝纪》建安十年高干叛，《杜畿传》《资治通鉴》卷六十四详诸人。

<a id="sgz015-b-816-2"></a>

**[《三国志·刘司马梁张温贾传》仓内原文 L816](../../sources/本地分卷/三国志/三国志-卷015.md#l816)**

> 高幹之反，張琰將舉兵以應之。逵不知其謀，往見琰。聞變起，欲還，恐見執，乃爲琰畫計，如與同謀者，琰信之。時縣寄治蠡城，城塹不固，逵從琰求兵脩城。諸欲爲亂者皆不隱其謀，故逵得盡誅之。遂脩城拒琰。

**释读** 贾逵至张琰处才知其反，假意应谋，从张琰求兵修蠡城并尽知乱党，诛杀之，守城拒张琰。

**归年** 《武帝纪》建安十年高干叛，《杜畿传》《资治通鉴》卷六十四可互证西部诸贼；始叛防守系当年，战局跨年。

<a id="sgz016-b-836-1"></a>

**[《三国志·任苏杜郑仓传》仓内原文 L836](../../sources/本地分卷/三国志/三国志-卷016.md#l836)**

> 太祖既定河北，而高幹舉并州反。時河東太守王邑被徵，河東人衛固、范先外以請邑為名，而內實與幹通謀。

**释读** 王邑被征，卫固、范先表称请留太守，实与高干勾结。

**归年** 《资治通鉴》卷六十四建安十年冬。

<a id="sgz016-b-836-2"></a>

**[《三国志·任苏杜郑仓传》仓内原文 L836](../../sources/本地分卷/三国志/三国志-卷016.md#l836)**

> 太祖謂荀彧曰：「關西諸將，恃險與馬，征必為亂。張晟寇殽、澠間，南通劉表，固等因之，吾恐其為害深。河東被山帶河，四鄰多變，當今天下之要地也。君為我舉蕭何、寇恂以鎮之。」彧曰：「杜畿其人也。」於是追拜畿為河東太守。

**释读** 曹操顾虑关西诸军、大河和山地使河东难守，请荀彧荐才，任命杜畿。

**归年** 《资治通鉴》卷六十四建安十年冬；《荀彧传》同案。

<a id="sgz016-b-836-3"></a>

**[《三国志·任苏杜郑仓传》仓内原文 L836](../../sources/本地分卷/三国志/三国志-卷016.md#l836)**

> 固等使兵數千人絕陝津，畿至不得渡。太祖遣夏侯惇討之，未至。或謂畿曰：「宜須大兵。」畿曰：「河東有三萬戶，非皆欲為亂也。今兵迫之急，欲為善者無主，必懼而聽於固。固等勢專，必以死戰。討之不勝，四鄰應之，天下之變未息也；討之而勝，是殘一郡之民也。且固等未顯絕王命，外以請故君為名，必不害新君。吾單車直往，出其不意。固為人多計而無斷，必偽受吾。吾得居郡一月，以計縻之，足矣。」遂詭道從郖津度。范先欲殺畿以威眾。且觀畿去就，於門下斬殺主簿已下三十餘人，畿舉動自若。於是固曰：「殺之無損，徒有惡名；且制之在我。」遂奉之。

**释读** 卫范绝陕津，援军未到。杜畿认为大军会逼民皆叛，独入河东；范先杀吏试探，卫固以为杜畿可控，奉其为主。

**归年** 《资治通鉴》卷六十四系建安十年高干事，等待及赴任具体或跨岁。

<a id="sgz016-b-836-4"></a>

**[《三国志·任苏杜郑仓传》仓内原文 L836](../../sources/本地分卷/三国志/三国志-卷016.md#l836)**

> 畿謂衛固、范先曰：「衛、范，河東之望也，吾仰成而已。然君臣有定義，成敗同之，大事當共平議。」以固為都督，行丞事，領功曹；將校吏兵三千餘人，皆范先督之。固等喜，雖陽事畿，不以為意。固欲大發兵，畿患之，說固曰：「夫欲為非常之事，不可動眾心。今大發兵，眾必擾，不如徐以貲募兵。」固以為然，從之，遂為貲調發，數十日乃定，諸將貪多應募而少遣兵。又入喻固等曰：「人情顧家，諸將掾吏，可分遣休息，急緩召之不難。」固等惡逆眾心，又從之。於是善人在外，陰為己援；惡人分散，各還其家，則眾離矣。

**释读** 给卫固、范先授职使其放心，劝募兵取代征发；又让将吏分批休息，使可用之人远出为己助，恶党分散。

**归年** 《资治通鉴》卷六十四连叙同段；计数十日，勿定日。

<a id="sgz016-b-836-5"></a>

**[《三国志·任苏杜郑仓传》仓内原文 L836](../../sources/本地分卷/三国志/三国志-卷016.md#l836)**

> 會白騎攻東垣，高幹入濩澤，上黨諸縣殺長吏，弘農執郡守，固等密調兵未至。畿知諸縣附己，因出，單將數十騎，赴張辟拒守，吏民多舉城助畿者，比數十日，得四千餘人。固等與幹、晟共攻畿，不下，略諸縣，無所得。

**释读** 高干等响应东垣、上党、弘农之乱，杜畿从河东各县获得支持，薄兵据张辟，卫固等攻掠无获。

**归年** 《资治通鉴》卷六十四建安十年相关；叛乱延至建安十一年。

<a id="sgz016-p-009-1"></a>

**[《三国志·任苏杜郑仓传》裴注 009·1](../../sources/本地分卷/三国志/三国志-卷016.md#pei-009-1)**

> 傅子曰彧稱畿勇足以當大難智能應變其可試之

**释读** 《傅子》称杜畿勇可当大难，智足应变，值得任用。

**归年** 《资治通鉴》卷六十四建安十年，荀彧推荐赴河东。

<a id="sgz016-p-010-3"></a>

**[《三国志·任苏杜郑仓传》裴注 010·3](../../sources/本地分卷/三国志/三国志-卷016.md#pei-010-3)**

> 及畿之官而固為郡功曹張時故任京兆畿迎司隷與時㑹華隂時畿相見於儀當各持版時歎曰昨日功曹今為郡將軍也

**释读** 卫固当时任郡功曹。故京兆尹张时华阴见杜畿，叹昨日功曹如今郡将。

**归年** 《资治通鉴》卷六十四建安十年获任河东，与本传及注相合。有的赴任细节可能跨年。

<a id="sgz016-p-011-1"></a>

**[《三国志·任苏杜郑仓传》裴注 011·1](../../sources/本地分卷/三国志/三国志-卷016.md#pei-011-1)**

> 傅子曰先云既欲為虎而惡食人肉失所以為虎矣今不殺必為後患

**释读** 范先以老虎不得厌恶吃肉作比，劝不先杀杜畿必有后患。

**归年** 建安十年的河东事；参本传范先试杀吏、卫固暂容。

<a id="hh-event-1"></a>

1. **曹操破袁谭於青州，斩之。** 十年春正月，曹操破袁谭于青州，斩之。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **墨山贼张燕率众降。** 夏四月，墨山贼张燕率众降。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **赐百官尤贫者金、帛，各有差。** 秋九月，赐百官尤贫者金、帛，各有差。 [[3]](#hh-note-3)

<a id="sg-event-4"></a>

4. **下令曰“其与袁氏同恶者”。** 下令曰：「其与袁氏同恶者，与之更始。」 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **令民不得复私雠，禁厚葬。** 令民不得复私雠，禁厚葬，皆一之于法。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **是月，袁熙大将焦触、张南等叛攻熙、尚。** 是月，袁熙大将焦触、张南等叛攻熙、尚，熙、尚奔三郡乌丸。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **触等举其县降，封爲列侯。** [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **初讨谭时，民亡椎冰。** 初讨谭时，民亡椎冰，令不得降。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **顷之，亡民有诣门首者，公谓曰“听汝则违令”。** 顷之，亡民有诣门首者，公谓曰：「听汝则违令，杀汝则诛首，归深自藏，无爲吏所获。」 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **民垂泣而去，后竟捕得。** 民垂泣而去；后竟捕得。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **故安赵犊、霍奴等杀幽州刺史、涿郡太守。** [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **三郡乌丸攻鲜于辅于犷平。** [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **公征之，斩犊等。** 秋八月，公征之，斩犊等，乃渡潞河救犷平，乌丸奔走出塞。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **令曰“阿党比周”。** 九月，令曰：「阿党比周，先圣所疾也。闻冀州俗，父子异部，更相毁誉。昔直不疑无兄，世人谓之盗嫂；弟五伯鱼三娶孤女，谓之挝妇翁；王凤擅权，谷永比之申伯；王商忠议，张匡谓之左道：此皆以白爲黑，欺天罔君者也。吾欲整齐风俗，四者不除，吾以爲羞。」 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **公还邺。** 冬十月，公还邺。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **编年更正。** 高干初降归204年；206年壶关陷落见当年条 见[204年第21条](ce-0204.md#wu-b-069-2)。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **干闻公讨乌丸，乃以州叛。** 干闻公讨乌丸，乃以州叛，执上党太守，举兵守壶关口。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **遣乐进、李典击之，干还守壶关城。** [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **贺齐讨上饶并置建平县。** 孙权派贺齐出征上饶，分设建平县。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **与松俱至。** 建安十年，与松俱至。 [[20]](#sg-note-20)

<a id="sgz-event-21"></a>

21. **曹丕与曹真在邺西打猎。** 曹丕说冀州平定时有弓马进献，暮春与曹真在邺西射猎。 [[21]](#sgz-note-21)

<a id="sgz-event-22"></a>

22. **许芝追述建安十年彗星。** 许芝称建安十年有彗星扫过紫微；因其说旨在论证易代，应保留这种解释为奏表所言。 [[22]](#sgz-note-22)

<a id="sgz-event-23"></a>

23. **阎柔向曹操献名马。** 曹操破袁谭于南皮后，阎柔率部曲与鲜卑向曹军献名马。 [[23]](#sgz-note-23)

**释读** 张绣随曹操破袁谭，增封后共二千户；本传并言战乱人口凋残，其他诸将食邑少有达到千户。

**归年** 建安十年正月破袁谭，食邑增加承该役，无独立月日。

<a id="sgz009-b-465-2"></a>

**[《三国志·诸夏侯曹传》仓内原文 L465](../../sources/本地分卷/三国志/三国志-卷009.md#l465)**

> 督虎豹騎從圍南皮。袁譚出戰，士卒多死。太祖欲緩之，純曰：「今千里蹈敵，進不能克，退必喪威；且縣師深入，難以持久。彼勝而驕，我敗而懼，以懼敵驕，必可克也。」太祖善其言，遂急攻之，譚敗。純麾下騎斬譚首。

**释读** 曹纯督虎豹骑围南皮，袁谭出战使曹军多死，曹纯劝曹操利用敌骄己惧急攻，击败袁谭后部骑斩其首。

**归年** 卷001 L65建安十年正月甲戌斩袁谭。

### 7. 触等举其县降，封爲列侯

<a id="sg001-l66-e7"></a>

**[《三国志·武帝纪》](../../sources/摘录/三国志-卷001-武帝纪.md#p006)** · [仓内TXT L66](../../sources/本地分卷/三国志/三国志-卷001.md#l66)

> 觸等舉其縣降，封爲列侯。

<a id="sgz006-b-359-8"></a>

**[《三国志·董二袁刘传》仓内原文 L359](../../sources/本地分卷/三国志/三国志-卷006.md#l359)**

> 觸自號幽州刺史，驅率諸郡太守令長，背袁向曹，陳兵數萬，殺白馬盟，令曰：「違命者斬！」衆莫敢語，各以次歃。

**释读** 焦触自号幽州刺史，迫各郡县长吏与袁氏断绝而归曹氏，陈兵杀白马盟誓，扬言杀违命者，众人依次盟誓。

**归年** 建安十年焦触、张南攻袁熙、袁尚之后，《武帝纪》载焦触等举县来降。

<a id="sgz006-b-359-9"></a>

**[《三国志·董二袁刘传》仓内原文 L359](../../sources/本地分卷/三国志/三国志-卷006.md#l359)**

> 至別駕韓珩，曰：「吾受袁公父子厚恩，今其破亡，智不能救，勇不能死，於義闕矣；若乃北靣於曹氏，所弗能爲也。」一坐爲珩失色。觸曰：「夫興大事，當立大義，事之濟否，不待一人，可卒珩志，以勵事君。」

**释读** 韩珩称受袁氏恩厚，袁氏败亡时自己无力相救，不能改事曹氏。焦触以忠义为重，未强迫韩珩盟誓。

**归年** 建安十年焦触盟誓内的反应。

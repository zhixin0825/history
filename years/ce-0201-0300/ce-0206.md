<a id="hh-event-1"></a>

1. **有星孛於北斗。** 十一年春正月，有星孛于北斗。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **曹操破高干於幷州，获之。** 三月，曹操破高干于幷州，获之。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **武威太守张猛杀雍州刺史邯郸商。** 秋七月，武威太守张猛杀雍州刺史邯郸商。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **是岁，立故琅邪王容子熙为琅邪王。** 当年，立故琅邪王容子熙为琅邪王。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **齐、北海、阜陵、下邳、常山、甘陵、济北、平原八国皆除。** [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **下邳国除。** 嗣王刘宜数月即死而无子，至此国除。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **甘陵国除。** 甘陵王一系归终，无继承人而国除。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **星孛於北斗，首在斗中，尾贯紫宫，及北辰。** 《天文志》记十一年正月，星孛於北斗，首在斗中，尾贯紫宫，及北辰。 [[8]](#hh-note-8)

<a id="hh-event-9"></a>

9. **复立容子熙为王。** 建安十一年，复立容子熙为王。 [[9]](#hh-note-9)

<a id="sg-event-10"></a>

10. **公征干。** 十一年春正月，公征干。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **干闻之，乃留其别将守城。** 干闻之，乃留其别将守城，走入匈奴，求救于单于，单于不受。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **公围壶关三月，拔之。** [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **干遂走荆州，上洛都尉王琰捕斩之。** [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **公东征海贼管承，至淳于。** 秋八月，公东征海贼管承，至淳于，遣乐进、李典击破之，承走入海岛。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **割东海之襄贲、郯、戚以益琅邪。** 割东海之襄贲、郯、戚以益琅邪，省昌虑郡。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **编年更正。** 乌丸乘乱进入幽州是开渠征讨前的长期背景 见[三郡乌丸进入幽州（时期）](时期-三国志魏纪后妃及汉末群雄.md#wu-period-b-071-1)。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **编年更正。** 袁绍授乌丸诸首领单于印绶可与建安四年史事对读 见[199年第30条](../ce-0101-0200/ce-0199.md#wu-b-071-2)。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **编年更正。** 蹋顿受袁绍厚待属征乌丸前的背景 见[蹋顿受袁绍厚待（时期）](时期-三国志魏纪后妃及汉末群雄.md#wu-period-b-071-3)。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **公将征之，凿渠。** 公将征之，凿渠，自呼沲入泒水，名平虏渠；又从泃河口凿入潞河，名泉州渠，以通海。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **曹操讨高干，高干被杀。** 高干出走求匈奴援军未果，欲投荆州，被上洛都尉捕斩。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **太史慈去世。** 太史慈建安十一年去世，时年四十一。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **太祖表汉帝，称进及于禁、张辽曰“武力既弘”。** 建安十一年，太祖表汉帝，称进及于禁、张辽曰：「武力既弘，计略周备，质忠性一，守执节义，每临战攻，常为督率，奋强突固，无坚不陷，自援枹鼓，手不知倦。又遣别征，统御师旅，抚众则和，奉令无犯，当敌制决，靡有遗失。论功纪用，宜各显宠。」 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **柳城之役的异年。** 卷三十《乌丸传》系在建安十一年；《张辽传》本段没有书年。按《武帝纪》《献帝纪》归建安十二年，见[207年柳城之役](ce-0207.md#hh-note-1)。 [[23]](#sg-note-23)

<a id="sy-event-24"></a>

24. **周瑜攻麻、保二屯，擒黄祖部将邓龙。** 周瑜督孙瑜等攻取麻、保二屯，后在柴桑击破黄祖遣来的邓龙，俘邓龙送吴。 [[24]](#sy-note-24)

<a id="wu-event-25"></a>

25. **曹操令僚佐每月初一指出其过失。** 曹操以长久未闻善谋为由，令掾属、治中和别驾在每月初一列陈自己的过失。 [[25]](#wu-note-25)

<a id="sgz-event-26"></a>

26. **昌豨再反，于禁围降后斩之。** 平冀州后，昌豨再叛。于禁围攻，昌豨以旧交来降；将领欲移送曹操，于禁以围后降不赦为由，哭着杀之。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **崔琰劝曹丕停止游猎。** 曹操留崔琰在邺辅佐曹丕，曹丕常改装外出打猎，崔琰写信劝止。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **曹操征壶关时擢崔林为冀州主簿。** 并州刺史张陟荐崔林为循良之首，曹操擢为冀州主簿。 [[28]](#sgz-note-28)

### 12. 公围壶关三月，拔之

[返回正文第12条](#sg-event-12)

<a id="sg001-l69-e12"></a>

**[《三国志·武帝纪》](../../sources/摘录/三国志-卷001-武帝纪.md#p006)** · [仓内TXT L69](../../sources/本地分卷/三国志/三国志-卷001.md#l69)

> 公圍壺關三月，拔之。

<a id="sgz009-b-460-1"></a>

**[《三国志·诸夏侯曹传》仓内原文 L460](../../sources/本地分卷/三国志/三国志-卷009.md#l460)**

> 河北既定，從圍壺關。太祖令曰：「城拔，皆坑之。」連月不下。

**释读** 河北平后曹仁从围壶关，曹操令城破后尽坑，城数月未下。

**归年** 卷001 L70系建安十一年正月曹操自征，围三月拔；前一年乐进、李典先击高干，区别两阶段。

<a id="sgz009-b-460-2"></a>

**[《三国志·诸夏侯曹传》仓内原文 L460](../../sources/本地分卷/三国志/三国志-卷009.md#l460)**

> 仁言於太祖曰：「圍城必示之活門，所以開其生路也。今公告之必死，將人自爲守。且城固而糧多，攻之則士卒傷，守之則引日久；今頓兵堅城之下，以攻必死之虜，非良計也。」

**释读** 曹仁说围城应给活路，明示必死会迫对手力守；坚城固粮，强攻费兵、久守费时。

**归年** 建安十一年围壶关期间，司马光《通鉴》卷064相承有载。

<a id="sgz009-b-460-3"></a>

**[《三国志·诸夏侯曹传》仓内原文 L460](../../sources/本地分卷/三国志/三国志-卷009.md#l460)**

> 太祖從之，城降。

**释读** 曹操采纳曹仁的建议，壶关投降。

**归年** 卷001同年记“拔之”，本传补改令后投降。

<a id="sgz017-b-879-1"></a>

**[《三国志·二张乐于徐传》仓内原文 L879](../../sources/本地分卷/三国志/三国志-卷017.md#l879)**

> 進別征高幹，從北道入上黨，回出其後。幹等還守壺關，連戰斬首。幹堅守未下，會太祖自征之，乃拔。

**释读** 乐进绕至高干军后方，高干退守壶关，乐进连战有斩获。曹操亲征后拔关。

**归年** 《武帝纪》建安十年末遣乐进、李典先击，十一年春亲征克关；本段主要落在克城，另并存前一年条。

<a id="sgz006-b-359-14"></a>

**[《三国志·董二袁刘传》仓内原文 L359](../../sources/本地分卷/三国志/三国志-卷006.md#l359)**

> 獨與數騎亡，欲南奔荊州，上洛都尉捕斬之。

**释读** 高干随少数骑兵出逃，想南奔荆州，被上洛都尉捕斩。

<a id="sgz006-p-068-1"></a>

**[《三国志·董二袁刘传》裴注 068·1](../../sources/摘录/三国志-卷006-董二袁刘传裴注.md#pei-068-1)**

> 典論曰上洛都尉王琰獲高幹以功封侯其妻哭於室以為琰富貴將更娶妾媵而奪己愛故也

**释读** 《典论》记上洛都尉王琰以擒高干封侯，其妻恐他富贵另娶，哭于家中。

**归年** 擒高干建安十一年；封侯、其妻哭随本注事后，未别年。

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **曹操大破乌桓於柳城，斩其蹋顿。** 十二年秋八月，曹操大破乌桓于柳城，斩其蹋顿。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **有星孛於鹑尾。** 冬十月辛卯，有星孛于鹑尾。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **黄巾贼杀济南王贇。** 乙巳，黄巾贼杀济南王贇。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **辽东太守公孙康杀袁尚、袁熙。** 十一月，辽东太守公孙康杀袁尚、袁熙。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **河间王刘贇遇害。** 刘贇为黄巾所害，其子刘开继位。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **曹操上表论荀彧之功。** 曹操上表追述荀彧在官渡劝守及规划平定河北的功劳。 [[6]](#hh-note-6)

<a id="sg-event-7"></a>

7. **曹操由淳于回到邺城。** 建安十二年春二月，曹操由淳于回到邺城。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **丁酋，令曰“吾起义兵诛暴乱”。** 丁酋，令曰：「吾起义兵诛暴乱，于今十九年，所征必克，岂吾功哉？乃贤士大夫之力也。天下虽未悉定，吾当要与贤士大夫共定之；而专飨其劳，吾何以安焉！其促定功行封。」 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **于是大封功臣二十余人。** 于是大封功臣二十余人，皆爲列侯，其余各以次受封，及复死事之孤，轻重各有差。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **张绣北征途中去世。** 张绣随军赴乌丸，未到柳城即死。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **郭嘉去世。** 郭嘉随征乌丸，回师时病重去世，曹操亲临丧。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **刘备劝刘表袭许。** 曹操北征乌丸，刘备建议刘表乘机取许，未被采纳。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **孙权再征黄祖。** 孙权征黄祖，掳居民后回军，黄祖此年未被杀。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **录惇前后功，增封邑千八百户。** 建安十二年，录惇前后功，增封邑千八百户，并前二千五百户。 [[14]](#sg-note-14)

<a id="sy-event-15"></a>

15. **曹操论功，增封荀攸。** 曹操论功，称荀攸谋略过人，增封七百户，合一千二百户，转中军师。 [[15]](#sy-note-15)

<a id="wu-event-16"></a>

16. **郭嘉劝曹操北征乌丸。** 诸将忧刘备趁曹军北出游说刘表袭取许都；郭嘉判断刘表不敢充分授权刘备，劝曹操按计划进兵。 [[16]](#wu-note-16)

<a id="wu-event-17"></a>

17. **乌丸代郡、上郡单于来贺。** 曹操到易水，代郡、上郡两名代理单于与名王来祝贺。 [[17]](#wu-note-17)

<a id="wu-event-18"></a>

18. **曹操厚赏先前反对远征者。** 北征归来，曹操查问此前劝阻的人，厚赏他们，说明这次胜利有侥幸，望诸将以后仍敢进言。 [[18]](#wu-note-18)

> 將北征三郡烏丸，諸將皆曰：「袁尚，亡虜耳，夷狄貪而無親，豈能爲尚用？今深入征之，劉備必說劉表以襲許。萬一爲變，事不可悔。」惟郭嘉策表必不能任備，勸公行。夏五月，至無終。秋七月，大水，傍海道不通，田疇請爲鄉導，公從之。引軍出盧龍塞，塞外道絕不通，乃壍山堙谷五百餘里，經白檀，歷平岡，涉鮮卑庭，東指柳城。未至二百里，虜乃知之。尚、熙與蹋頓、遼西單于樓班、右北平單于能臣抵之等，將數萬騎逆軍。八月，登白狼山，卒與虜遇，衆甚盛。公車重在後，被甲者少，左右皆懼。公登高，望虜陳不整，乃縱兵擊之，使張遼爲先鋒，虜衆大崩，斬蹋頓及名王已下，胡、漢降者二十餘萬口。遼東單于速僕丸及遼西、北平諸豪，棄其種人，與尚、熙奔遼東，衆尚有數千騎。初，遼東太守公孫康恃遠不服。及公破烏丸，或說公遂征之，尚兄弟可禽也。公曰：「吾方使康斬送尚、熙首，不煩兵矣。」九月，公引兵自柳城還，康即斬尚、熙及速僕丸等，傳其首。諸將或問：「公還而康斬送尚、熙，何也？」公曰：「彼素畏尚等，吾急之則並力，緩之則自相圖，其勢然也。」十一月至易水，代郡烏丸行單于普富盧、上郡烏丸行單于那樓將其名王來賀。

### 9. 于是大封功臣二十余人

[返回正文第9条](#sg-event-9)

<a id="sg001-l72-e9"></a>

**[《三国志·武帝纪》](../../sources/摘录/三国志-卷001-武帝纪.md#p006)** · [仓内TXT L72](../../sources/本地分卷/三国志/三国志-卷001.md#l72)

> 於是大封功臣二十餘人，皆爲列侯，其餘各以次受封，及復死事之孤，輕重各有差。

<a id="wu-p-068-1"></a>

**[《三国志·武帝纪》裴注 068·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-068-1)**

> 魏書載公令曰昔趙奢竇嬰之為將也受賜千金一朝散之故能濟成大功永世流聲吾讀其文未嘗不慕其為人也與諸將士大夫共從戎事幸賴賢人不愛其謀羣士不遺其力是以夷險平亂而吾得竊大賞户邑三萬追思竇嬰散金之義今分所受租與諸將掾屬及故戍於陳蔡者庶以酬答衆勞不擅大惠也宜差死事之孤以租穀及之若年殷用足租奉畢入將大與衆人悉共饗之

**释读** 曹操以赵奢、窦婴散金为例，决定将封邑所收的租赋分给诸将、掾属和原戍陈蔡者，并给因公死难者遗孤谷物。

**归年** 《魏书》附建安十二年二月大封功臣；援引古人是令文历史比照。

> 十二年，西征黃祖。虜其人民而還。

<a id="sgz063-b-2967-1"></a>

**[《三国志·吴范刘惇赵达传》仓内原文 L2967](../../sources/本地分卷/三国志/三国志-卷063.md#l2967)**

> 初，權在吳，欲討黃祖。范曰：「今茲少利，不如明年。明年戊子，荊州劉表亦身死國亡。」權遂征祖，卒不能克。

**释读** 吴范认为当年难获利，请等次年，并预言刘表死。孙权仍出兵黄祖，未能攻克。

**归年** 《吴主传》建安十二年再征黄祖而还，十三年始灭黄祖。吴范所说“明年戊子”与208年的岁次相合，本次出兵在207。

# 公元207年｜建安十二年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **曹操大破乌桓於柳城，斩其蹋顿。** 十二年秋八月，曹操大破乌桓于柳城，斩其蹋顿。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **有星孛於鹑尾。** 冬十月辛卯，有星孛于鹑尾。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **黄巾贼杀济南王贇。** 乙巳，黄巾贼杀济南王贇。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **辽东太守公孙康杀袁尚、袁熙。** 十一月，辽东太守公孙康杀袁尚、袁熙。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **河间王刘贇遇害。** 刘贇为黄巾所害，其子刘开继位。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **曹操上表论荀彧之功。** 曹操上表追述荀彧在官渡劝守及规划平定河北的功劳。 [[6]](#hh-note-6)

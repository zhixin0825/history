## 本年概述

建安十三年春，孙权攻克江夏，黄祖被杀。曹操秋季南征时刘表去世，刘琮举荆州降曹。曹军在长坂赶上刘备，刘备转往夏口，继与孙权结盟。孙刘联军在赤壁击败曹军。其后周瑜等追至南郡，刘备南取荆州四郡，孙权另于十二月围合肥。

1. **孙权破江夏杀黄祖，刘琦继任太守。** 甘宁劝孙权乘刘表、黄祖势弱，先取江夏，再向西经略荆州、巴蜀。张昭担心出兵后吴地生变，孙权仍决定出征。春季孙权攻黄祖，以周瑜为前部大督。凌统率数十亲兵乘舟先出，在右江斩黄祖将张硕，俘其船上人员，回报孙权。黄祖遣陈就率水军迎战，又在沔口以缆绳横系两艘蒙冲，船上弩手阻住吴军。董袭、凌统各率百名敢死士披双铠登舟冲击，董袭斩断两缆，吴军水陆并进，吕蒙斩黄祖水军将领陈就，凌统率先攻城，吴军攻下城池。黄祖出逃，被骑士冯则追上杀死。孙权在次日军宴上举杯嘉许董袭，以吕蒙斩陈就之功授他横野中郎将，又升凌统为承烈都尉，拨兵给甘宁屯于当口。黄祖故将苏飞早年曾助甘宁脱身，甘宁在席间为他求情，孙权赦免苏飞。刘琦先因受刘表疏远，向诸葛亮问自保之计。黄祖死后，刘琦得以外任江夏太守。 [[1]](#ce208-note-1)

2. **贺齐、蒋钦讨黟、歙，吴设新都郡。** 孙权派贺齐攻黟、歙，蒋钦督万人助战。武强、叶乡等四乡先降，贺齐请以叶乡为始新县。金奇、毛甘各据山寨，陈仆、祖山屯林历山。正面山路险窄，守军居高落石。贺齐募轻捷士以铁弋从隐处攀援，夜登山顶，放下布匹接引后队，再从四面齐鸣鼓角。守路者以为吴军已登山，惊散回营，吴军趁势攻破陈仆等。孙权应贺齐所请，将始新、新定、黎阳、休阳、黟、歙六县置为新都郡，任贺齐为太守、治始新，加偏将军。 [[2]](#ce208-note-2)

3. **孙贲受任征虏将军，朱治劝阻送质。** 汉使刘隐持诏授孙贲征虏将军，仍领豫章。孙贲的女儿此前嫁给曹操之子曹彰。曹军取荆州后，孙贲惧而欲遣子入质。朱治以孙氏在江东兵势已盛、刘备又来求援，中原却疲于军旅和饥荒，劝他顾全宗族。孙贲遂止。 [[3]](#ce208-note-3)

10. **鲁肃联络刘备，诸葛亮赴吴求援。** 刘表死后，鲁肃请赴荆州吊丧并察看形势，争取与刘备联手。鲁肃赶到南郡时，刘琮已经投降曹操，刘备兵败南走。鲁肃在当阳长坂追上刘备，转达孙权之意，劝他与江东合力抗曹，并与诸葛亮结交。刘备进驻夏口，遣诸葛亮到柴桑说孙权，鲁肃回报孙权。程昱也预料孙权会援刘备。 [[10]](#ce208-note-11)

11. **孙权决计联刘抗曹，赤壁破曹军。** 刘琮降曹后，曹操来书声称有八十万水陆军，孙权群臣多主迎降。鲁肃劝孙权召周瑜还议。周瑜指出曹操北方未定，士卒疲敝又不习水战，主张抗拒。孙权斫案决计，以周瑜、程普为左右督，令鲁肃任赞军校尉、协助谋划，自备后援。吴军与刘备会合，在赤壁初战取胜。曹军原已有疾疫，战败退至江北，联军驻江南。黄盖诈降，乘风放火，波及曹军战船和岸营，周瑜等随即进击。韩当、周泰、吕范随军拒曹，甘宁、凌统也参加了乌林一战。黄盖在战斗中中箭落水，吴军救起时未能认出他，韩当听出他的呼声，赶来为他换衣，黄盖才得以活命。曹军退保南郡，刘备、周瑜等领军追击。曹操焚余船北还，留曹仁、徐晃守江陵，乐进守襄阳。鲁肃率先回师，孙权召诸将迎接。黄盖后来拜武锋中郎将。吕范拜裨将军、领彭泽太守，以彭泽、柴桑、历阳为奉邑。 [[11]](#ce208-note-12)

12. **周瑜等追攻南郡，救出夷陵守军。** 赤壁败后，曹仁留守江陵，周瑜等转攻南郡。周瑜、程普与曹仁隔江对峙，刘备提出由张飞率千人协助周瑜，周瑜拨二千人给刘备从夏水迂回，截曹仁后路。甘宁建议先取夷陵，得城后合并新兵也只有约千人。曹仁遣五六千人包围，筑高楼向城中射箭。甘宁处之自若，派人向周瑜告急。周瑜采纳吕蒙的建议，留凌统守营，亲与吕蒙驰援，又派三百人用柴木封住险道。围兵当夜败退，弃马步行，吴军缴获三百匹马，随后渡江屯于北岸。袭肃来附，周瑜一度想把他的部众拨给吕蒙，吕蒙劝孙权仍让袭肃领兵。江陵相持延至[次年](ce-0209.md#ce209-note-1)。 [[12]](#ce208-note-13)

### 1. 孙权破江夏杀黄祖，刘琦继任太守

> 十三年春，權復征黃祖，祖先遣舟兵拒軍，都尉呂蒙破其前鋒，而淩統、董襲等盡銳攻之，遂屠其城。祖挺身亡走，騎士馮則追梟其首，虜其男女數萬口。

**孙权第三次西征黄祖，攻克江夏** 黄祖派舟师，吕蒙击破前锋，凌统、董袭等攻克城池，黄祖逃走被骑士冯则擒杀，吴掠男女数万。

> 從征黃祖，祖令都督陳就逆以水軍出戰。蒙勒前鋒，親梟就首，將士乘勝，進攻其城。祖聞就死，委城走，兵追禽之。權曰：「事之克，由陳就先獲也。」以蒙爲橫野中郎將，賜錢千萬。

**釋讀** 黃祖命都督陳就率水軍迎戰，呂蒙帶前鋒斬陳就。黃祖棄城逃走，被追及。孫權把勝利歸功於呂蒙先取陳就，授橫野中郎將，賜錢千萬。

**歸年** 《吳主傳》明記建安十三年春，並記騎士馮則追斬黃祖；本傳著眼前鋒之戰，記黃祖被追禽。



<a id="sy-sg055-l2635-e24"></a>

<a id="sgz055-b-2635-1"></a>

> 建安十三年，權討黃祖。祖橫兩蒙衝挾守沔口，以栟閭大紲繫石爲矴，上有千人，以弩交射，飛矢雨下，軍不得前。襲與凌統俱爲前部，各將敢死百人，人被兩鎧，乘大舸船，突入蒙衝裏。襲身以刀斷兩紲，蒙衝乃橫流，大兵遂進。祖便開門走，兵追斬之。明日大會，權舉觴屬襲曰：「今日之會，斷紲之功也。」

**釋讀** 黄祖用粗栟榈缆绳系石，在沔口横两艘蒙冲，舟上千人列弩阻吴军。董袭、凌统各领百名敢死士，身披双铠，乘大船冲进去，董袭斩断两缆，蒙冲漂开，大军得进。黄祖开门逃走，被追杀。次日孙权设宴，举杯称是董袭断缆的功劳。

> 江表傳曰：權拔刀斫前奏案曰：「諸將吏敢復有言當迎操者，與此案同！」及會罷之夜，瑜請見曰：「諸人徒見操書，言水步八十萬，而各恐懾，不復料其虛實，便開此議，甚無謂也。今以實校之，彼所將中國人，不過十五六萬，且軍已久疲，所得表衆，亦極七八萬耳，尚懷狐疑。夫以疲病之卒，御狐疑之衆，衆數雖多，甚未足畏。得精兵五萬，自足制之，願將軍勿慮。」權撫背曰：「公瑾，卿言至此，甚合孤心。子布、元表諸人，各顧妻子，挾持私慮，深失所望，獨卿與子敬與孤同耳，此天以卿二人贊孤也。五萬兵難卒合，已選三萬人，船糧戰具俱辦，卿與子敬、程公便在前發，孤當續發人衆，多載資糧，爲卿後援。卿能辦之者誠決，邂逅不如意，便還就孤，孤當與孟德決之。」

**釋讀** 孫權斫案表明拒曹決心。周瑜當夜求見，說曹操來書聲稱水步八十萬，估計曹部北軍只十五六萬，已遠行疲敝，所得荊州軍至多七八萬，難以盡信。周瑜估計五萬精兵足以制敵；孫權說五萬一時集不齊，已備好三萬人和船糧器械，讓周瑜、魯肅、程普先發，他續供人眾資糧，若前軍無法取勝則退回會合，再與曹操決戰。

**歸年** 附208年決策與發兵。曹書自稱、周瑜估敵與孫權實際發兵各有所指。

**归年** 《通鉴》系于建安十三年末还军，次年另有还谯记载。

<a id="sgz011-b-553-5"></a>

**[《三国志·袁张凉国田王邴管传》仓内原文 L553](../../sources/本地分卷/三国志/三国志-卷011.md#l553)**

> 疇上疏陳誠，以死自誓。太祖不聽，欲引拜之，至於數四，終不受。

**释读** 田畴上疏以死明志，曹操多次欲强拜，终不受。

**归年** 《通鉴》接叙。

<a id="sgz011-b-553-6"></a>

**[《三国志·袁张凉国田王邴管传》仓内原文 L553](../../sources/本地分卷/三国志/三国志-卷011.md#l553)**

> 有司劾疇狷介違道，苟立小節，宜免官加刑。太祖重其事，依違者久之。

**释读** 有司以其狷介守小节，不遵常道，主张免官并加刑，曹操犹豫良久。

**归年** 《通鉴》接叙，具体讨论持续到何时无记。

<a id="sgz011-b-553-7"></a>

**[《三国志·袁张凉国田王邴管传》仓内原文 L553](../../sources/本地分卷/三国志/三国志-卷011.md#l553)**

**释读** 曹丕援子文、申胥辞禄为比，荀彧、钟繇也主张尊重田畴的决定。

**归年** 《通鉴》同系建安十三年；当时曹丕尚未正式立为魏太子。

**[《三国志·袁张凉国田王邴管传》仓内原文 L553](../../sources/本地分卷/三国志/三国志-卷011.md#l553)**

**释读** 曹操仍想封侯，私托与田畴亲善的夏侯惇劝说，夏侯惇到他家住宿。

**归年** 《通鉴》同系于此次封爵议。

<a id="sgz011-b-553-9"></a>

**[《三国志·袁张凉国田王邴管传》仓内原文 L553](../../sources/本地分卷/三国志/三国志-卷011.md#l553)**

> 疇揣知其指，不復發言。惇臨去，乃拊疇背曰：「田君，主意殷勤，曾不能顧乎！」

**释读** 田畴知道来意不发问，夏侯惇离开才问，难道不能顾念曹操的殷勤。

**归年** 同上。

<a id="sgz011-b-553-10"></a>

**[《三国志·袁张凉国田王邴管传》仓内原文 L553](../../sources/本地分卷/三国志/三国志-卷011.md#l553)**

> 疇荅曰：「是何言之過也！疇，負義逃竄之人耳，蒙恩全活，為幸多矣。豈可賣盧龍之塞，以易賞祿哉？縱國私疇，疇獨不愧於心乎？將軍雅知疇者，猶復如此，若必不得已，請願效死刎首於前。」言未卒，涕泣橫流。

**释读** 田畴说蒙恩保全已很幸，不能把卢龙之塞换取禄赏，若相逼宁愿自尽，说罢落泪。

**归年** 同上。

<a id="sgz011-b-553-11"></a>

**[《三国志·袁张凉国田王邴管传》仓内原文 L553](../../sources/本地分卷/三国志/三国志-卷011.md#l553)**

> 惇具荅太祖。太祖喟然知不可屈，乃拜為議郎。

**释读** 夏侯惇如实复命，曹操知不可强屈，改拜议郎。

**归年** 同上。

<a id="sgz011-p-018-1"></a>

**[《三国志·袁张凉国田王邴管传》裴注 018·1](../../sources/本地分卷/三国志/三国志-卷011.md#pei-018-1)**

> 先賢行状載太祖命曰蓨令田疇至節髙尚

**释读** 曹操再下命，以田畴节操高尚为表彰。

**归年** 《通鉴》置208末；本令末说出入三载，有延至209的可能。

<a id="sgz011-p-018-6"></a>

**[《三国志·袁张凉国田王邴管传》裴注 018·6](../../sources/本地分卷/三国志/三国志-卷011.md#pei-018-6)**

> 而疇懇惻前後辭賞出入三載厯年未賜此為成一人之髙甚違王典失之多矣宜従表封無久留吾過

**释读** 田畴前后辞赏，令称出入三载未受爵，曹操自责过去允辞违典，要求尽快依表封赏。

**归年** 《通鉴》再封系208末；自207首尾计三年可至209，记时两证并列。

<a id="sgz011-p-019-1"></a>

**[《三国志·袁张凉国田王邴管传》裴注 019·1](../../sources/本地分卷/三国志/三国志-卷011.md#pei-019-1)**

> 魏書載世子議曰昔薳敖逃禄傳載其羙所以激濁世勵貪夫賢於尸禄素餐之人也故可得而小不可得而毁至於田疇方斯近矣免官加刑於法為重

**释读** 曹丕在议中主张田畴守高节，有励俗之效，免官加刑未免过重。

**归年** 《魏书》载议、《通鉴》系208，与正文同。

<a id="sgz011-p-019-2"></a>

**[《三国志·袁张凉国田王邴管传》裴注 019·2](../../sources/本地分卷/三国志/三国志-卷011.md#pei-019-2)**

> 魏畧載教曰昔夷齊棄爵而譏武王可謂愚闇孔子猶以為求仁得仁疇之所守雖不合道但欲清髙耳使天下悉如疇志即墨翟兼愛尚同之事而老𣆀使民結繩之道也外議雖善為復使令司隷以决之

**释读** 曹操认为田畴近伯夷求仁之意，却不宜人人效之；令尚书令与司隶再断。

**归年** 《魏略》载同次教。

<a id="sgz011-p-019-3"></a>

**[《三国志·袁张凉国田王邴管传》裴注 019·3](../../sources/本地分卷/三国志/三国志-卷011.md#pei-019-3)**

> 魏書載荀彧議以為君子之道或出或䖏期扵為善而已故匹夫守志聖人各因而成之

**释读** 荀彧认为出仕和隐居皆可行善，圣人可成全守志者。

**归年** 同议。

<a id="sgz011-p-019-4"></a>

**[《三国志·袁张凉国田王邴管传》裴注 019·4](../../sources/本地分卷/三国志/三国志-卷011.md#pei-019-4)**

**释读** 钟繇以原思辞粟、子路拒牛为比，也认为田畴有益谦让风气，宜从曹丕意见。

<a id="201年的拒绝到208年结束了"></a>

### 201年的“拒绝”，到208年结束了

把两次征召分开，就能看到一个比“司马懿装病”更重要的变化：201年时他还能拒绝，208年曹操的政治控制力已经强得多，而且直接把他纳入丞相府。

《晋书》随后连续写司马懿升黄门侍郎、议郎、丞相东曹属、主簿，但没有给这几次升迁逐项标年。因此本页只确定“文学掾”这一格，后面的官职暂留在 [未确年材料](../../meta/考证/晋书-卷001-宣帝纪-未定年.md)，不硬塞进208年。

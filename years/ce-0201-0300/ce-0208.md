# 208年｜曹操再征司马懿：这一次他入了幕府

[← 公元207年](ce-0207.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元209年 →](ce-0209.md)

**汉献帝建安十三年**


> 这一年的关键变化：七年前拒绝曹操征召的司马懿，在曹操出任丞相后再次被征。这一次《晋书》和《资治通鉴》都把他进入丞相府文学掾的位置放在同一时间点。

<a id="event-1"></a>

1. **曹操任用司马朗、司马懿。** 司马朗出任主簿，司马懿出任文学掾。 [[1]](#note-1)

   《晋书》也把第二次征辟系在“魏武为丞相”之后，并说曹操这次态度很强硬：如果司马懿再拖延，就把他收捕。司马懿于是就职。

17. **编年更正。** 孙权于建安十三年岁末出军，解围入次年 见[209年第12条](ce-0209.md#wu-b-075-9)。 [[17]](#sg-note-17)

25. **贺齐、蒋钦讨黟、歙，吴设新都郡。** 孙权派贺齐攻黟、歙，蒋钦督万人助战。贺齐先降数乡，继据山势部署攻坚，平定后析置新都郡。 [[25]](#sg-note-25)

<a id="sgz-event-30"></a>

30. **马腾入朝，马超继统其军。** 马腾入朝任卫尉，其子马超接领部曲。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **刘琦请出任江夏太守。** 刘琦受刘表疏远，曾向诸葛亮求自全，得劝请求外任。黄祖死后，刘琦得任江夏太守。 [[31]](#sgz-note-31)

<a id="sgz-event-32"></a>

32. **李立任荆州刺史。** 本注接华容女子后事，说她又唱李立将贵，曹操取荆州，以涿郡李立为荆州刺史。 [[32]](#sgz-note-32)

<a id="sgz-event-34"></a>

34. **甘宁先据夷陵，周瑜、吕蒙解围。** 甘宁以少兵守夷陵，曹仁部众围攻，吕蒙建议救援，周瑜率军解围。 [[34]](#sgz-note-34)

<a id="sgz-event-35"></a>

35. **曹仁平荆州后留守江陵。** 平荆州后，曹仁行征南将军、留江陵防御周瑜。 [[35]](#sgz-note-35)

<a id="sgz-event-38"></a>

38. **曹操辟刘巴并遣招长沙等三郡。** 曹操征刘巴为掾，令招纳长沙、零陵、桂阳。 [[38]](#sgz-note-38)

<a id="sgz-event-40"></a>

40. **田畴于曹操还荆州后再辞封。** 曹操由荆州还，念田畴殊功，认为允辞有亏封赏制度，重新欲授原爵。 [[40]](#sgz-note-40)

<a id="sgz-event-41"></a>

41. **张辽将赴长社，制止夜间营变。** 荆州未定，张辽将赴长社。夜中叛卒点火扰营，他令无异心者坐定，以少数亲兵列阵，擒杀主谋。 [[41]](#sgz-note-41)

<a id="sgz-event-42"></a>

42. **曹操平荆州后乐进驻襄阳。** 乐进随曹军收荆州，留守襄阳，击走关羽与苏非等；南郡一带山谷部落来附。 [[42]](#sgz-note-42)

<a id="sgz-event-43"></a>

43. **朱治劝孙贲勿遣子质曹。** 孙贲女嫁曹操之子；曹操攻占荆州后，孙贲惧而拟遣子为质，朱治分析利害劝止。 [[43]](#sgz-note-43)

<a id="sgz-event-44"></a>

44. **崔琰任曹操丞相府掾。** 崔琰又任东、西曹掾等事；《通鉴》记开丞相府时任西曹掾。 [[44]](#sgz-note-44)

<a id="sgz-event-45"></a>

45. **崔琰毛玠并掌丞相府选举。** 毛玠在曹操任司空、丞相时任东曹掾，与崔琰同掌选举。 [[45]](#sgz-note-45)

<a id="sgz-event-46"></a>

46. **曹操平荆州后任司马芝为菅长。** 曹操平荆州后，任司马芝为菅县长。 [[46]](#sgz-note-46)

<a id="sgz-event-47"></a>

47. **曹操平荆州辟隗禧。** 曹操召他为军谋掾。 [[47]](#sgz-note-47)

<a id="sgz-event-50"></a>

<a id="sgz-event-48"></a>

48. **鲁肃联络刘备，诸葛亮赴吴求援。** 鲁肃到荆州并在长坂兵败后与刘备相见，诸葛亮随即赴柴桑说孙权联兵抗曹。程昱预料孙权会援助刘备。吴方诸传各有侧重，详见同号史料。 [[48]](#sgz-note-48)

<a id="sgz-event-49"></a>

49. **张昭向孙权推荐诸葛亮，诸葛亮辞留。** 《袁子》称张昭荐诸葛亮，亮说孙权虽是人主，却不能尽其所长，故不留。 [[49]](#sgz-note-49)

<a id="sgz-event-51"></a>

51. **曹操平荆州征韩暨入丞相府。** 曹操据荆州后辟韩暨为丞相士曹属。 [[51]](#sgz-note-51)

<a id="sgz-event-52"></a>

52. **吕蒙请把兵还给来附的袭肃。** 周瑜建议将袭肃来降部众拨吕蒙，吕蒙称袭肃有胆且远道来附，宜增兵不宜夺兵。孙权听取。 [[52]](#sgz-note-52)

<a id="sgz-event-53"></a>

53. **扬州刺史刘馥去世。** 刘馥卒于建安十三年。 [[53]](#sgz-note-53)

<a id="sgz-event-54"></a>

54. **曹操任文聘为江夏太守。** 江夏连吴，曹操委北兵与边事，赐关内侯。 [[54]](#sgz-note-54)

<a id="sgz-event-55"></a>

55. **马腾入卫尉而庞德留从马超。** 马腾进朝为卫尉，庞德留随马超部。 [[55]](#sgz-note-55)

<a id="sgz-event-56"></a>

56. **曹操取荆州后辟和洽。** 聘为丞相掾。 [[56]](#sgz-note-56)

<a id="sgz-event-57"></a>

57. **曹操征荆州任赵俨督护七军。** 先领章陵太守，改都督护军，督于禁、张辽等七军。 [[57]](#sgz-note-57)

<a id="sgz-event-58"></a>

58. **曹操入荆州，辟裴潜参丞相军事。** 任裴潜幕职。 [[58]](#sgz-note-58)

<a id="sgz-event-59"></a>

59. **吉黄违禁奔赵温丧被杀。** 吉黄任长陵令，因曾为赵温故吏擅奔丧，为司隶钟繇法办。 [[59]](#sgz-note-59)

<a id="sgz-event-60"></a>

60. **曹操招王粲为丞相掾。** 归附后授幕职赐关内侯。 [[60]](#sgz-note-60)

<a id="sgz-event-61"></a>

61. **王粲汉滨举酒贺曹操纳荆州贤才。** 批袁绍好士不能用、刘表不知荆州贤才；称曹操定冀用人。 [[61]](#sgz-note-61)

<a id="sgz-event-62"></a>

62. **荆州归曹后曹操召邯郸淳。** 因素闻声名，召见敬异。 [[62]](#sgz-note-62)

<a id="sgz-event-63"></a>

63. **路粹秉曹操意上奏孔融罪。** 称孔融在北海招徒图非，以及触赏猥辞等罪。 [[63]](#sgz-note-63)

<a id="sgz-event-64"></a>

64. **曹操定荆州后辟桓阶。** 曹操闻桓阶为张羡谋划，称异而辟丞相掾主簿。 [[64]](#sgz-note-64)

> 癸巳，以曹操为丞相……河内司马朗为主簿，弟懿为文学掾。

**[《三国志·诸葛亮传》仓内原文 L1757](../../sources/本地分卷/三国志/三国志-卷035.md#l1757)**

> 亮曰：「豫州軍雖敗於長阪，今戰士還者及關羽水軍精甲萬人，劉琦合江夏戰士亦不下萬人。曹操之眾，遠來疲弊，聞追豫州，輕騎一日一夜行三百餘里，此所謂『彊弩之末，勢不能穿魯縞』者也。故兵法忌之，曰『必蹶上將軍』。且北方之人，不習水戰﹔又荊州之民附操者，逼兵勢耳，非心服也。今將軍誠能命猛將統兵數萬，與豫州協規同力，破操軍必矣。操軍破，必北還，如此則荊、吳之勢彊，鼎足之形成矣。成敗之機，在於今日。」

**释读** 诸葛亮估算刘备与刘琦人众，称曹军远道劳顿、不习水战，荆州军附非心服。建议吴发兵并力，预计可成鼎足。

**归年** 建安十三年同一次对策，兵力为引语的当事人说法。

<a id="201年的拒绝到208年结束了"></a>

### 201年的“拒绝”，到208年结束了

把两次征召分开，就能看到一个比“司马懿装病”更重要的变化：201年时他还能拒绝，208年曹操的政治控制力已经强得多，而且直接把他纳入丞相府。

《晋书》随后连续写司马懿升黄门侍郎、议郎、丞相东曹属、主簿，但没有给这几次升迁逐项标年。因此本页只确定“文学掾”这一格，后面的官职暂留在 [未确年材料](../../meta/考证/晋书-卷001-宣帝纪-未定年.md)，不硬塞进208年。

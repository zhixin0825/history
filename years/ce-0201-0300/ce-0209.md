# 公元209年｜建安十四年

[← 公元208年](ce-0208.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元210年 →](ce-0210.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **荆州地震。** 十四年冬十月，荆州地震。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **荀悦去世。** 荀悦六十二岁卒，留下《汉纪》《申鉴》等著述。 [[2]](#hh-note-2)

<a id="sg-event-3"></a>

3. **军至谯，作轻舟。** 十四年春三月，军至谯，作轻舟，治水军。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **自涡入淮，出肥水。** 秋七月，自涡入淮，出肥水，军合肥。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **令曰“自顷已来”。** 辛未，令曰：「自顷已来，军数征行，或遇疫气，吏士死亡不归，家室怨旷，百姓流离，而仁者岂乐之哉？不得已也。其令死者家无基业不能自存者，县官勿绝廪，长吏存恤抚循，以称吾意。」 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **置扬州郡县长吏，开芍陂屯田。** [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **军还谯。** 十二月，军还谯。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **周瑜围江陵，曹仁出救牛金。** 牛金率少数将士出击被包围，曹仁两次入围，将牛金等救出。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **编年更正。** 刘备南取荆州四郡见《通鉴》建安十三年十二月。本年刘琦死、刘备领荆州牧见[第10条](#sg-note-10)。 见[208年第19条](ce-0208.md#sg001-l75-e19)。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **刘备领荆州牧，治公安。** 刘琦死后，刘备为荆州牧，驻治公安；孙权进妹修好。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **曹仁撤江陵，周瑜领南郡。** 周瑜与曹仁相持逾年，曹仁最终弃江陵，周瑜领南郡。 [[11]](#sg-note-11)

<a id="wu-event-12"></a>

12. **孙权撤合肥之围。** 孙权听说援军已到而撤退；蒋济传说撤退时张憙尚未到，孙权得到了蒋济设计的假情报。 [[12]](#wu-note-12)

### 10. 刘备领荆州牧，治公安

[返回正文第10条](#sg-event-10)

<a id="sg032-l1654-e10"></a>

**[《三国志·先主传》](../../sources/摘录/三国志-卷032-先主传.md#p003)** · [仓内TXT L1654](../../sources/本地分卷/三国志/三国志-卷032.md#l1654)

> 琦病死，羣下推先主為荊州牧，治公安。權稍畏之，進妹固好。

<a id="sgz032-b-1654-3"></a>

**[《三国志·先主传》仓内原文 L1654](../../sources/本地分卷/三国志/三国志-卷032.md#l1654)**

> 琦病死，羣下推先主為荊州牧，治公安。

**释读** 刘琦病死，部属推刘备任荆州牧，治公安。

**归年** 《通鉴》卷066在建安十四年，接周瑜领南郡事项。

<a id="sgz032-b-1654-4"></a>

**[《三国志·先主传》仓内原文 L1654](../../sources/本地分卷/三国志/三国志-卷032.md#l1654)**

> 權稍畏之，進妹固好。

**释读** 孙权渐畏刘备，嫁妹以巩固关系。

**归年** 《资治通鉴》卷066建安十四年。

<a id="sgz032-p-028-1"></a>

**[《三国志·先主传》裴注 028·1](../../sources/摘录/三国志-卷032-先主传裴注.md#pei-028-1)**

> 江表傳曰備立營於油口改名公安

**释读** 《江表传》说刘备立营油口，改称公安。

**归年** 附刘备建安十四年治公安；同书详文在第26注，异称油口和油江口应留。

<a id="sg-note-11"></a>

### 11. 曹仁撤江陵，周瑜领南郡

[返回正文第11条](#sg-event-11)

<a id="sg047-l2277-e11"></a>

**[《三国志·吴主传》](../../sources/摘录/三国志-卷047-吴主传.md#p002)** · [仓内TXT L2277](../../sources/本地分卷/三国志/三国志-卷047.md#L2277)

> 十四年，瑜、仁相守歳餘，所殺傷甚眾。仁委城走。權以瑜爲南郡太守。

<a id="sgz055-b-2606-6"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2606](../../sources/本地分卷/三国志/三国志-卷055.md#l2606)**

> 又進攻南郡，走曹仁。

**释读** 程普参与继续进攻南郡，终于迫曹仁撤走。

**归年** 进军和解夷陵之围在208年，江陵归吴的结果见《通鉴》建安十四年209。原句以结果为重点，挂江陵撤守条。

<a id="sgz055-b-2623-3"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2623](../../sources/本地分卷/三国志/三国志-卷055.md#l2623)**

> 攻曹仁於南郡。

**释读** 赤壁之后周泰随周瑜进取南郡。

**归年** 南郡战始208、曹仁撤江陵在209，以战果条为落点。

<a id="sgz055-b-2649-3"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2649](../../sources/本地分卷/三国志/三国志-卷055.md#l2649)**

> 遂攻曹仁，遷爲校尉。

**释读** 凌统随军转攻江陵，军功后任校尉。

**归年** 《周瑜传》南郡续战，攻围自208延至209撤军，任官附终局。

<a id="sgz032-p-026-1"></a>

**[《三国志·先主传》裴注 026·1](../../sources/摘录/三国志-卷032-先主传裴注.md#pei-026-1)**

> 江表傳曰周瑜為南郡太守分南岸地以給備備别立營於油江口改名為公安劉表吏士見堤北軍多叛来投備

**释读** 周瑜领南郡太守，拨南岸地给刘备，刘备在油江口建营，改名公安，部分原属刘表而在北军的吏士来归。

**归年** 周瑜建安十四年取江陵后领南郡；《江表传》所记刘备公安起名见第28注。

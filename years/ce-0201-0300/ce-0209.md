# 公元209年｜建安十四年

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **荆州地震。** 十四年冬十月，荆州地震。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **荀悦去世。** 荀悦六十二岁卒，留下《汉纪》《申鉴》等著述。 [[2]](#hh-note-2)

<a id="sg-event-3"></a>

3. **军至谯，作轻舟。** 十四年春三月，军至谯，作轻舟，治水军。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **自涡入淮，出肥水。** 秋七月，自涡入淮，出肥水，军合肥。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **令曰“自顷已来”。** 辛未，令曰：「自顷已来，军数征行，或遇疫气，吏士死亡不归，家室怨旷，百姓流离，而仁者岂乐之哉？不得已也。其令死者家无基业不能自存者，县官勿绝廪，长吏存恤抚循，以称吾意。」 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **置扬州郡县长吏，开芍陂屯田。** [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **军还谯。** 十二月，军还谯。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **周瑜围江陵，曹仁出救牛金。** 牛金率少数将士出击被包围，曹仁两次入围，将牛金等救出。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **编年更正。** 刘备南取荆州四郡见《通鉴》建安十三年十二月。本年刘琦死、刘备领荆州牧见[第10条](#sg-note-10)。 见[208年第19条](ce-0208.md#sg001-l75-e19)。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **刘备领荆州牧，治公安。** 刘琦死后，刘备为荆州牧，驻治公安；孙权进妹修好。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **曹仁撤江陵，周瑜领南郡。** 周瑜与曹仁相持逾年，曹仁最终弃江陵，周瑜领南郡。 [[11]](#sg-note-11)

<a id="wu-event-12"></a>

12. **孙权撤合肥之围。** 孙权听说援军已到而撤退；蒋济传说撤退时张憙尚未到，孙权得到了蒋济设计的假情报。 [[12]](#wu-note-12)

<a id="sgz-event-13"></a>

13. **夏侯渊行领军。** 建安十四年，夏侯渊代理领军。 [[13]](#sgz-note-13)

<a id="sgz-event-14"></a>

14. **夏侯渊击破庐江雷绪。** 曹操讨孙权还后，夏侯渊率诸将击破庐江叛者雷绪。 [[14]](#sgz-note-14)

<a id="sgz-event-15"></a>

15. **曹纯从曹操还谯。** 曹纯随曹操还谯。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **史涣去世，史静嗣爵。** 建安十四年史涣去世，其子史静承袭。 [[16]](#sgz-note-16)

<a id="sgz-event-17"></a>

17. **段煨建安十四年去世。** 段煨寿终，时为建安十四年。 [[17]](#sgz-note-17)

### 8. 周瑜围江陵，曹仁出救牛金

[返回正文第8条](#sg-event-8)

<a id="sg009-l461-e8"></a>

**[《三国志·诸夏侯曹传》](../../sources/摘录/三国志-卷009-诸夏侯曹传.md#p003)** · [仓内TXT L461](../../sources/本地分卷/三国志/三国志-卷009.md#l461)

> 金眾少，遂爲所圍。

**归年与互校** 《吴主传》把围城起点与赤壁连叙，次年记曹仁撤离；本传未单独标牛金被围年月，随江陵围城记。

<a id="sgz009-b-461-2"></a>

**[《三国志·诸夏侯曹传》仓内原文 L461](../../sources/本地分卷/三国志/三国志-卷009.md#l461)**

> 瑜將數萬眾來攻，前鋒數千人始至，仁登城望之，乃募得三百人，遣部曲將牛金逆與挑戰。賊多，金眾少，遂爲所圍。

**释读** 周瑜有数万人，数千先锋先至。曹仁募三百人使牛金出战，被敌围。

**归年** 沿现年页建安十四年，通鉴卷065–066显示江陵战起208冬、至209才退；牛金出战本传不纪月份。

<a id="sgz009-b-461-3"></a>

**[《三国志·诸夏侯曹传》仓内原文 L461](../../sources/本地分卷/三国志/三国志-卷009.md#l461)**

> 長史陳矯俱在城上，望見金等垂沒，左右皆失色。仁意氣奮怒甚，謂左右取馬來，矯等共援持之。謂仁曰：「賊眾盛，不可當也。假使棄數百人何苦，而將軍以身赴之！」

**释读** 长史陈矫等见牛金危急，拦阻要亲自上马的曹仁，认为不该置将军于险。

**归年** 同次江陵前锋战。

<a id="sgz009-b-461-4"></a>

**[《三国志·诸夏侯曹传》仓内原文 L461](../../sources/本地分卷/三国志/三国志-卷009.md#l461)**

> 仁不應，遂被甲上馬，將其麾下壯士數十騎出城。去賊百餘步，迫溝，矯等以爲仁當住溝上，爲金形勢也，仁徑渡溝直前，衝入賊圍，金等乃得解。餘眾未盡出，仁復直還突之，拔出金兵，亡其數人，賊眾乃退。

**释读** 曹仁率数十骑披甲出城，越沟两次冲入敌阵，先救牛金再救余众，只损数人，周瑜军退。

**归年** 同次江陵前锋战。

<a id="sgz009-b-461-5"></a>

**[《三国志·诸夏侯曹传》仓内原文 L461](../../sources/本地分卷/三国志/三国志-卷009.md#l461)**

> 矯等初見仁出，皆懼，及見仁還，乃嘆曰：「將軍真天人也！」三軍服其勇。

**释读** 陈矫等起初惊惧，见曹仁归后叹为天人，全军钦服其勇。

**归年** 同次江陵前锋战。

<a id="sgz032-b-1654-3"></a>

**[《三国志·先主传》仓内原文 L1654](../../sources/本地分卷/三国志/三国志-卷032.md#l1654)**

> 琦病死，羣下推先主為荊州牧，治公安。

**归年** 《通鉴》卷066在建安十四年，接周瑜领南郡事项。

<a id="sgz032-b-1654-4"></a>

**[《三国志·先主传》仓内原文 L1654](../../sources/本地分卷/三国志/三国志-卷032.md#l1654)**

> 權稍畏之，進妹固好。

**释读** 孙权渐畏刘备，嫁妹以巩固关系。

**归年** 《资治通鉴》卷066建安十四年。

<a id="sgz032-p-028-1"></a>

**[《三国志·先主传》裴注 028·1](../../sources/摘录/三国志-卷032-先主传裴注.md#pei-028-1)**

> 江表傳曰備立營於油口改名公安

**释读** 《江表传》说刘备立营油口，改称公安。

**归年** 附刘备建安十四年治公安；同书详文在第26注，异称油口和油江口应留。

<a id="sgz037-b-1827-6"></a>

**[《三国志·庞统法正传》仓内原文 L1827](../../sources/本地分卷/三国志/三国志-卷037.md#l1827)**

> 初，孫權以妹妻先主，妹才捷剛猛，有諸兄之風，侍婢百餘人，皆親執刀侍立，先主每入，衷心常凜凜；亮又知先主雅愛信正，故言如此。

**释读** 孙权把妹妹嫁给刘备。孙夫人勇毅，侍婢百余皆持刀侍从，刘备入室常不安，诸葛亮也知他信任法正。

**归年** 《先主传》L1654接周瑜破曹仁、刘备领荆州牧而书，按孙刘结亲所在阶段归209；后文长期行为无确日。

<a id="sgz039-b-1872-2"></a>

**[《三国志·董刘马陈董吕传》仓内原文 L1872](../../sources/本地分卷/三国志/三国志-卷039.md#l1872)**

> 先主領荊州，闢為從事。

**释读** 刘备任荆州牧，征马良为从事。

**归年** 《先主传》《通鉴》卷065系刘备领荆州牧为209；因本传以此次领州为任官线索，附此。

<a id="sgz039-b-1879-2"></a>

**[《三国志·董刘马陈董吕传》仓内原文 L1879](../../sources/本地分卷/三国志/三国志-卷039.md#l1879)**

> 先主領荊州牧，闢為從事，部諸郡，

**释读** 刘备领荆州牧时征陈震为从事，在诸郡分任。

**归年** 《先主传》系刘备领荆州牧于209；附初辟，督察经过跨时。

<a id="sgz040-b-1912-2"></a>

**[《三国志·刘彭廖李刘魏杨传》仓内原文 L1912](../../sources/本地分卷/三国志/三国志-卷040.md#l1912)**

### 11. 曹仁撤江陵，周瑜领南郡

[返回正文第11条](#sg-event-11)

<a id="sg047-l2277-e11"></a>

**[《三国志·吴主传》](../../sources/摘录/三国志-卷047-吴主传.md#p002)** · [仓内TXT L2277](../../sources/本地分卷/三国志/三国志-卷047.md#L2277)

> 十四年，瑜、仁相守歳餘，所殺傷甚眾。仁委城走。權以瑜爲南郡太守。

<a id="sgz055-b-2606-6"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2606](../../sources/本地分卷/三国志/三国志-卷055.md#l2606)**

> 又進攻南郡，走曹仁。

**释读** 程普参与继续进攻南郡，终于迫曹仁撤走。

**归年** 进军和解夷陵之围在208年，江陵归吴的结果见《通鉴》建安十四年209。原句以结果为重点，挂江陵撤守条。

<a id="sgz055-b-2623-3"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2623](../../sources/本地分卷/三国志/三国志-卷055.md#l2623)**

> 攻曹仁於南郡。

**释读** 赤壁之后周泰随周瑜进取南郡。

**归年** 南郡战始208、曹仁撤江陵在209，以战果条为落点。

<a id="sgz055-b-2649-3"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2649](../../sources/本地分卷/三国志/三国志-卷055.md#l2649)**

> 遂攻曹仁，遷爲校尉。

**释读** 凌统随军转攻江陵，军功后任校尉。

**归年** 《周瑜传》南郡续战，攻围自208延至209撤军，任官附终局。

<a id="sgz032-p-026-1"></a>

**[《三国志·先主传》裴注 026·1](../../sources/摘录/三国志-卷032-先主传裴注.md#pei-026-1)**

> 江表傳曰周瑜為南郡太守分南岸地以給備備别立營於油江口改名為公安劉表吏士見堤北軍多叛来投備

**释读** 周瑜领南郡太守，拨南岸地给刘备，刘备在油江口建营，改名公安，部分原属刘表而在北军的吏士来归。

**归年** 周瑜建安十四年取江陵后领南郡；《江表传》所记刘备公安起名见第28注。

<a id="sgz037-b-1819-4"></a>

**[《三国志·庞统法正传》仓内原文 L1819](../../sources/本地分卷/三国志/三国志-卷037.md#l1819)**

> 吳將周瑜助先主取荊州，因領南郡太守。

**释读** 周瑜协助刘备在荆州对曹军作战，并在曹仁撤后领南郡太守。

**归年** 《吴志·周瑜传》《通鉴》卷065同载周瑜屯江陵、领南郡，系建安十四年；其参与赤壁开始于208。

## 本年概述

周瑜继续围攻江陵，曹仁最终弃城，周瑜领南郡。刘琦死后，刘备领荆州牧，驻公安。孙权也撤回围合肥的军队。曹操在谯造船，秋季再至合肥，部署扬州边防和屯田，冬季回谯。

1. **江陵围守逾年，曹仁弃城，周瑜领南郡。** 周瑜与曹仁在江陵相持逾年，程普、周泰、凌统也参加围攻。其间，曹仁曾突入围中救出牛金等人；周瑜也在战斗中右胁中箭，曹仁乘机出兵，周瑜带伤巡营，激励军心，使曹仁退去。曹仁后来弃守江陵，孙权任周瑜为偏将军、南郡太守，给以下隽、汉昌、浏阳、州陵为奉邑，周瑜进屯江陵。程普此后领江夏太守，治沙羡。吕蒙班师后迁偏将军，领寻阳令，凌统升为校尉。 [[1]](#ce209-note-1)

2. **刘琦去世，刘备领荆州牧，治公安。** 刘备接续[上年南取四郡](ce-0208.md#sg001-l75-e19)，刘琦死后被推为荆州牧，以左将军领其职，治公安，任潘濬为治中从事。刘备表孙权行车骑将军、领徐州牧，张昭任军师，孙权召吾粲为主簿，又任全柔为车骑将军长史，全柔后来转任桂阳太守。孙权又任滕耽为右司马。孙权驻京口期间，从鄂县召胡综回来掌书部，与是仪、徐详共同处理军国机密。孙权进妹与刘备结好。 [[2]](#ce209-note-2)

<a id="ce209-event-3"></a>

<a id="sgz-event-22"></a>

3. **曹操遣蒋干游说周瑜。** 曹操遣善辩的蒋干游说周瑜。蒋干穿便服、以私人名义来访，周瑜见面便问他是否为曹操作说客。周瑜留他饮宴，又带他巡看营库和军械，表示自己受到孙权知遇，绝无改事他主之意。蒋干归去后称周瑜襟怀深广，无法说动。 [[3]](#ce209-note-3)

**[《三国志·诸夏侯曹传》](../../拆分史书/三国志/卷009.md#p003)** · [仓内TXT L461](../../拆分史书/三国志/卷009.md#l461)

**归年与互校** 《吴主传》把围城起点与赤壁连叙，次年记曹仁撤离；本传未单独标牛金被围年月，随江陵围城记。

<a id="sgz009-b-461-2"></a>

**[《三国志·诸夏侯曹传》仓内原文 L461](../../拆分史书/三国志/卷009.md#l461)**

> 瑜將數萬眾來攻，前鋒數千人始至，仁登城望之，乃募得三百人，遣部曲將牛金逆與挑戰。賊多，金眾少，遂爲所圍。

**释读** 周瑜有数万人，数千先锋先至。曹仁募三百人使牛金出战，被敌围。

**归年** 沿现年页建安十四年，通鉴卷065–066显示江陵战起208冬、至209才退；牛金出战本传不纪月份。

> 長史陳矯俱在城上，望見金等垂沒，左右皆失色。仁意氣奮怒甚，謂左右取馬來，矯等共援持之。謂仁曰：「賊眾盛，不可當也。假使棄數百人何苦，而將軍以身赴之！」

**释读** 长史陈矫等见牛金危急，拦阻要亲自上马的曹仁，认为不该置将军于险。

**归年** 同次江陵前锋战。

<a id="sgz009-b-461-4"></a>

**释读** 曹仁率数十骑披甲出城，越沟两次冲入敌阵，先救牛金再救余众，只损数人，周瑜军退。

**归年** 同次江陵前锋战。

**释读** 陈矫等起初惊惧，见曹仁归后叹为天人，全军钦服其勇。

**归年** 同次江陵前锋战。

### 3. 曹操遣蒋干游说周瑜

[返回正文第3条](#ce209-event-3)

<a id="sgz054-p-011-2"></a>

<a id="sgz054-p-011-3"></a>

<a id="wu054-l38-2"></a>

**[《三國志·周瑜魯肅呂蒙傳》裴注 011](../../拆分史书/三国志/卷054.md#edition-wu054-l38-2)** · [TXT L38](../../拆分史书/三国志/卷054.txt#L38)

> 初曹公聞瑜年少有美才，謂可游說動也，乃密下揚州，遣九江蔣幹往見瑜。幹有儀容，以才辯見稱，獨步江、淮之閒，莫與爲對。乃布衣葛巾，自託私行詣瑜。瑜出迎之，立謂幹曰：「子翼良苦，遠涉江湖爲曹氏作說客邪？」幹曰：「吾與足下州里，中閒別隔，遙聞芳烈，故來叙闊，并觀雅規，而云說客，無乃逆詐乎？」瑜曰：「吾雖不及夔、曠，聞弦賞音，足知雅曲也。」因延幹入，爲設酒食。畢，遣之曰：「適吾有密事，且出就館，事了，別自相請。」後三日，瑜請幹與周觀營中，行視倉庫軍資器仗訖，還宴飲，示之侍者服飾珍玩之物，因謂幹曰：「丈夫處世，遇知己之主，外託君臣之義，內結骨肉之恩，言行計從，禍福共之，假使蘇張更生，酈叟復出，猶撫其背而折其辭，豈足下幼生所能移乎？」幹但笑，終無所言。幹還，稱瑜雅量高致，非言辭所間。中州之士，亦以此多之。

**釋讀** 曹操密遣九江辯士蔣幹以私人身分訪周瑜。周瑜識破來意，宴飲招待；三日後與他巡營、觀軍資，表明不改事知己之主。蔣幹回去稱許周瑜，說客無從離間。

**歸年** 《江表傳》未明年月；《資治通鑑》卷六十六把游說置於建安十四年曹仁棄江陵之後。

### 7. 张辽等讨陈兰、梅成

[返回正文第7条](#ce209-event-8)

<a id="sgz-note-18"></a>

<a id="sgz017-b-874-2"></a>

**[《三国志·二张乐于徐传》仓内原文 L874](../../拆分史书/三国志/卷017.md#l874)**

> 陳蘭、梅成以氐六縣叛，太祖遣于禁、臧霸等討成，遼督張郃、牛蓋等討蘭。成偽降禁，禁還。成遂將其眾就蘭，轉入灊山。

**归年** 《通鉴考异》引繁钦《征天山赋》系建安十四年。仓内「牛蓋」两宋本所见有异，四库正文作「朱蓋」，所附考证作「朱宋本作牛」；《徐晃传》作「硃蓋」。

<a id="sgz017-b-874-3"></a>

**[《三国志·二张乐于徐传》仓内原文 L874](../../拆分史书/三国志/卷017.md#l874)**

> 灊中有天柱山，高峻二十餘里，道險狹，步徑裁通，蘭等壁其上。遼欲進，諸將曰：「兵少道險，難用深入。」遼曰：「此所謂一與一，勇者得前耳。」遂進到山下安營，攻之，斬蘭、成首，盡虜其眾。太祖論諸將功，曰：「登天山，履峻險，以取蘭、成，蕩寇功也。」增邑，假節。

**释读** 天柱山险峻，诸将以兵少和路险力谏。张辽仍进，攻灭陈兰、梅成并俘其众，曹操论功，增邑假节。

**归年** 建安十四年灊、六之役，连同于禁传和张郃传互参。

<a id="sgz017-b-882-9"></a>

**[《三国志·二张乐于徐传》仓内原文 L882](../../拆分史书/三国志/卷017.md#l882)**

> 後與臧霸等攻梅成，張遼、張郃等討陳蘭。禁到，成舉眾三千餘人降。既降復叛，其眾奔蘭。遼等與蘭相持，軍食少，禁運糧前後相屬，遼遂斬蘭、成。增邑二百戶，並前千二百戶。

**释读** 梅成先以三千余人向于禁投降，后同陈兰合兵。于禁持续运粮给张辽，陈兰、梅成败死；于禁增邑二百。

**归年** 《通鉴考异》引《征天山赋》系209年；与张辽、张郃传同役。

<a id="sgz017-b-886-7"></a>

**[《三国志·二张乐于徐传》仓内原文 L886](../../拆分史书/三国志/卷017.md#l886)**

> 又與張遼討陳蘭、梅成等，破之。

**释读** 张郃协同张辽破陈兰、梅成。

**归年** 通鉴借《征天山赋》系209年。

<a id="sgz018-b-909-7"></a>

**[《三国志·二李臧文吕许典二庞阎传》仓内原文 L909](../../拆分史书/三国志/卷018.md#l909)**

> 張遼之討陳蘭，霸別遣至皖，討吳將韓當，使權不得救蘭。當遣兵逆霸，霸與戰於逢龍，當復遣兵邀霸於夾石，與戰破之，還屯舒。

**释读** 臧霸受命至皖牵制韩当，逢龙与敌相遇，复破夹石来军并屯舒。

**归年** 建安十四年《张辽传》陈兰梅成反。

<a id="sgz018-b-909-8"></a>

**[《三国志·二李臧文吕许典二庞阎传》仓内原文 L909](../../拆分史书/三国志/卷018.md#l909)**

> 權遣數萬人乘船屯舒口，分兵救蘭，聞霸軍在舒，遁還。霸夜追之，比明，行百餘里，邀賊前後擊之。賊窘急，不得上船，赴水者甚眾。由是賊不得救蘭，遼遂破之。

**释读** 孙权水军由舒口援陈兰，闻臧霸在舒退走；臧霸连夜追击使不得上船，张辽遂破陈兰。

**归年** 同一次阻援。

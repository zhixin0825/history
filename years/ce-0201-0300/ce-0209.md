# 公元209年｜建安十四年

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **荆州地震。** 十四年冬十月，荆州地震。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **荀悦去世。** 荀悦六十二岁卒，留下《汉纪》《申鉴》等著述。 [[2]](#hh-note-2)

<a id="sg-event-3"></a>

3. **军至谯，作轻舟。** 十四年春三月，军至谯，作轻舟，治水军。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **自涡入淮，出肥水。** 秋七月，自涡入淮，出肥水，军合肥。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **令曰“自顷已来”。** 辛未，令曰：「自顷已来，军数征行，或遇疫气，吏士死亡不归，家室怨旷，百姓流离，而仁者岂乐之哉？不得已也。其令死者家无基业不能自存者，县官勿绝廪，长吏存恤抚循，以称吾意。」 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **置扬州郡县长吏，开芍陂屯田。** [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **军还谯。** 十二月，军还谯。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **周瑜围江陵，曹仁出救牛金。** 牛金率少数将士出击被包围，曹仁两次入围，将牛金等救出。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **编年更正。** 刘备南取荆州四郡见《通鉴》建安十三年十二月。本年刘琦死、刘备领荆州牧见[第10条](#sg-note-10)。 见[208年第19条](ce-0208.md#sg001-l75-e19)。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **刘备领荆州牧，治公安。** 刘琦死后，刘备为荆州牧，驻治公安；孙权进妹修好。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **曹仁撤江陵，周瑜领南郡。** 周瑜与曹仁相持逾年，曹仁最终弃江陵，周瑜领南郡。 [[11]](#sg-note-11)

<a id="wu-event-12"></a>

12. **孙权撤合肥之围。** 孙权听说援军已到而撤退；蒋济传说撤退时张憙尚未到，孙权得到了蒋济设计的假情报。 [[12]](#wu-note-12)

<a id="sgz-event-13"></a>

13. **夏侯渊行领军。** 建安十四年，夏侯渊代理领军。 [[13]](#sgz-note-13)

<a id="sgz-event-14"></a>

14. **夏侯渊击破庐江雷绪。** 曹操讨孙权还后，夏侯渊率诸将击破庐江叛者雷绪。 [[14]](#sgz-note-14)

<a id="sgz-event-15"></a>

15. **曹纯从曹操还谯。** 曹纯随曹操还谯。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **史涣去世，史静嗣爵。** 建安十四年史涣去世，其子史静承袭。 [[16]](#sgz-note-16)

<a id="sgz-event-17"></a>

17. **段煨建安十四年去世。** 段煨寿终，时为建安十四年。 [[17]](#sgz-note-17)

<a id="sgz-event-18"></a>

18. **张辽等讨陈兰、梅成。** 曹操令于禁、臧霸攻梅成，张辽督张郃等攻陈兰；梅成诈降后与陈兰合兵退入灊山。 [[18]](#sgz-note-18)

<a id="sgz-event-19"></a>

19. **张辽、乐进、李典屯守合肥。** 曹操征孙权归来，令张辽、乐进、李典等七千余人驻合肥。 [[19]](#sgz-note-19)

<a id="sgz-event-20"></a>

20. **蒋济赴谯，反对曹操迁淮南民。** 曹操用官渡时徙燕、白马民为例问淮南迁民；蒋济称今强昔弱，百姓恋土，强徙将致扰。 [[20]](#sgz-note-20)

<a id="sgz-event-21"></a>

21. **吕蒙升偏将军领寻阳。** 班师后获偏将军、寻阳令之职。 [[21]](#sgz-note-21)

<a id="sgz-event-22"></a>

22. **曹操遣蒋干游说周瑜。** 蒋干辩才佳，乔装私访，周瑜直问是否为曹氏说客，蒋干称来叙旧，周瑜表示已懂来意。 [[22]](#sgz-note-22)

<a id="sgz-event-23"></a>

23. **阎行出使曹操、受封并劝韩遂归附。** 曹操厚待韩遂所遣阎行，拜犍为太守，准父入宿卫。阎行回述曹操招抚之意，并劝韩遂遣子，韩遂先说要观望。 [[23]](#sgz-note-23)

<a id="sgz-event-24"></a>

24. **《典略》系张猛杀邯郸商于建安十四年。** 张猛与商初戏侮积怨，商谋诛猛反被拘，欲逃而遭杀。 [[24]](#sgz-note-24)

### 8. 周瑜围江陵，曹仁出救牛金

[返回正文第8条](#sg-event-8)

<a id="sg009-l461-e8"></a>

**[《三国志·诸夏侯曹传》](../../sources/摘录/三国志-卷009-诸夏侯曹传.md#p003)** · [仓内TXT L461](../../sources/本地分卷/三国志/三国志-卷009.md#l461)

> 金眾少，遂爲所圍。

**归年与互校** 《吴主传》把围城起点与赤壁连叙，次年记曹仁撤离；本传未单独标牛金被围年月，随江陵围城记。

<a id="sgz009-b-461-2"></a>

**[《三国志·诸夏侯曹传》仓内原文 L461](../../sources/本地分卷/三国志/三国志-卷009.md#l461)**

> 瑜將數萬眾來攻，前鋒數千人始至，仁登城望之，乃募得三百人，遣部曲將牛金逆與挑戰。賊多，金眾少，遂爲所圍。

**释读** 周瑜有数万人，数千先锋先至。曹仁募三百人使牛金出战，被敌围。

**归年** 沿现年页建安十四年，通鉴卷065–066显示江陵战起208冬、至209才退；牛金出战本传不纪月份。

<a id="sgz009-b-461-3"></a>

**[《三国志·诸夏侯曹传》仓内原文 L461](../../sources/本地分卷/三国志/三国志-卷009.md#l461)**

> 長史陳矯俱在城上，望見金等垂沒，左右皆失色。仁意氣奮怒甚，謂左右取馬來，矯等共援持之。謂仁曰：「賊眾盛，不可當也。假使棄數百人何苦，而將軍以身赴之！」

**释读** 长史陈矫等见牛金危急，拦阻要亲自上马的曹仁，认为不该置将军于险。

**归年** 同次江陵前锋战。

<a id="sgz009-b-461-4"></a>

**[《三国志·诸夏侯曹传》仓内原文 L461](../../sources/本地分卷/三国志/三国志-卷009.md#l461)**

> 仁不應，遂被甲上馬，將其麾下壯士數十騎出城。去賊百餘步，迫溝，矯等以爲仁當住溝上，爲金形勢也，仁徑渡溝直前，衝入賊圍，金等乃得解。餘眾未盡出，仁復直還突之，拔出金兵，亡其數人，賊眾乃退。

**释读** 曹仁率数十骑披甲出城，越沟两次冲入敌阵，先救牛金再救余众，只损数人，周瑜军退。

**归年** 同次江陵前锋战。

<a id="sgz009-b-461-5"></a>

**[《三国志·诸夏侯曹传》仓内原文 L461](../../sources/本地分卷/三国志/三国志-卷009.md#l461)**

> 矯等初見仁出，皆懼，及見仁還，乃嘆曰：「將軍真天人也！」三軍服其勇。

**释读** 陈矫等起初惊惧，见曹仁归后叹为天人，全军钦服其勇。

**归年** 同次江陵前锋战。

<a id="sgz017-b-892-14"></a>

**[《三国志·二张乐于徐传》仓内原文 L892](../../sources/本地分卷/三国志/三国志-卷017.md#l892)**

> 與曹仁擊周瑜於江陵。

**释读** 徐晃与曹仁在江陵抗击周瑜。

**归年** 本役自赤壁后开始，《吴主传》《周瑜传》围江陵收束于209年，具体战次无日。

<a id="sgz054-b-2567-4"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2567](../../sources/本地分卷/三国志/三国志-卷054.md#l2567)**

> 瑜親跨馬擽陳，會流矢中右脅，瘡甚，便還。

**释读** 周瑜亲骑冲阵时右胁中箭，因重伤暂退。

**归年** 《通鉴》卷六十五先载208渡江屯北岸，卷六十六载209结束围城，伤事两者之间，按期战段挂209，确月无载。

<a id="sgz047-b-2276-9"></a>

**[《三国志·吴主传》仓内原文 L2276](../../sources/本地分卷/三国志/三国志-卷047.md#l2276)**

> 時甘寧在夷陵，爲仁黨所圍，用呂蒙計，留淩統以拒仁，以其半救寧，軍以勝反。

**释读** 甘宁在夷陵受曹仁部围困，周瑜依吕蒙计留凌统应付曹仁，分军西救取胜。

**归年** 本处承208年末，江陵相持延至209。《周瑜传》并叙，归江陵围援既有条。

**[《三国志·先主传》仓内原文 L1654](../../sources/本地分卷/三国志/三国志-卷032.md#l1654)**

> 琦病死，羣下推先主為荊州牧，治公安。

**归年** 《通鉴》卷066在建安十四年，接周瑜领南郡事项。

<a id="sgz032-b-1654-4"></a>

**[《三国志·先主传》仓内原文 L1654](../../sources/本地分卷/三国志/三国志-卷032.md#l1654)**

> 權稍畏之，進妹固好。

**释读** 孙权渐畏刘备，嫁妹以巩固关系。

**归年** 《资治通鉴》卷066建安十四年。

<a id="sgz032-p-028-1"></a>

**[《三国志·先主传》裴注 028·1](../../sources/摘录/三国志-卷032-先主传裴注.md#pei-028-1)**

> 江表傳曰備立營於油口改名公安

**释读** 《江表传》说刘备立营油口，改称公安。

**归年** 附刘备建安十四年治公安；同书详文在第26注，异称油口和油江口应留。

<a id="sgz037-b-1827-6"></a>

**[《三国志·庞统法正传》仓内原文 L1827](../../sources/本地分卷/三国志/三国志-卷037.md#l1827)**

> 初，孫權以妹妻先主，妹才捷剛猛，有諸兄之風，侍婢百餘人，皆親執刀侍立，先主每入，衷心常凜凜；亮又知先主雅愛信正，故言如此。

**释读** 孙权把妹妹嫁给刘备。孙夫人勇毅，侍婢百余皆持刀侍从，刘备入室常不安，诸葛亮也知他信任法正。

**归年** 《先主传》L1654接周瑜破曹仁、刘备领荆州牧而书，按孙刘结亲所在阶段归209；后文长期行为无确日。

<a id="sgz039-b-1872-2"></a>

**[《三国志·董刘马陈董吕传》仓内原文 L1872](../../sources/本地分卷/三国志/三国志-卷039.md#l1872)**

> 先主領荊州，闢為從事。

**释读** 刘备任荆州牧，征马良为从事。

**归年** 《先主传》《通鉴》卷065系刘备领荆州牧为209；因本传以此次领州为任官线索，附此。

<a id="sgz039-b-1879-2"></a>

**[《三国志·董刘马陈董吕传》仓内原文 L1879](../../sources/本地分卷/三国志/三国志-卷039.md#l1879)**

**归年** 《先主传》系刘备领荆州牧于209；附初辟，督察经过跨时。

**[《三国志·二李臧文吕许典二庞阎传》仓内原文 L909](../../sources/本地分卷/三国志/三国志-卷018.md#l909)**

> 權遣數萬人乘船屯舒口，分兵救蘭，聞霸軍在舒，遁還。霸夜追之，比明，行百餘里，邀賊前後擊之。賊窘急，不得上船，赴水者甚眾。由是賊不得救蘭，遼遂破之。

**释读** 孙权水军由舒口援陈兰，闻臧霸在舒退走；臧霸连夜追击使不得上船，张辽遂破陈兰。

**归年** 同一次阻援。

### 20. 蒋济赴谯，反对曹操迁淮南民

[返回正文第20条](#sgz-event-20)

<a id="sgz014-b-749-4"></a>

**[《三国志·程郭董刘蒋刘传》仓内原文 L749](../../sources/本地分卷/三国志/三国志-卷014.md#l749)**

> 明年使於譙，太祖問濟曰：「昔孤與袁本初對官渡，徙燕、白馬民，民不得走，賊亦不敢鈔。今欲徙淮南民，何如？」濟對曰：「是時兵弱賊強，不徙必失之。自破袁紹，北拔柳城，南向江、漢，荊州交臂，威震天下，民無他志。然百姓懷土，實不樂徙，懼必不安。」

**归年** 本传自建安十三年书“明年”，故建安十四年；《资治通鉴》将问答附在建安十八年部下渡江处，曰“初”。官渡为议中回顾。

### 22. 曹操遣蒋干游说周瑜

[返回正文第22条](#sgz-event-22)

<a id="sgz054-p-011-2"></a>

**[《三国志·周瑜鲁肃吕蒙传》裴注 011·2](../../sources/摘录/三国志-卷054-周瑜鲁肃吕蒙传裴注.md#pei-011-2)**

> 初曹公聞瑜年少有羙才謂可游説動也乃宻下揚州遣九江蔣幹往見瑜幹有儀容以才辯見稱獨歩江淮之間莫與為對乃布衣葛巾自託私行詣瑜瑜出迎之立謂幹曰子翼良苦逺渉江湖為曹氏作説客邪幹曰吾與足下州里中間别隔遥聞芳烈故來叙濶并觀雅規而云説客無乃逆詐乎瑜曰吾雖不及䕫曠聞〔四库字图2959〕賞音足知雅曲也

**归年** 《通鉴》卷六十六于建安十四年接周瑜据江陵而书；原注“初”未记年。

<a id="sgz054-p-011-3"></a>

**[《三国志·周瑜鲁肃吕蒙传》裴注 011·3](../../sources/摘录/三国志-卷054-周瑜鲁肃吕蒙传裴注.md#pei-011-3)**

> 因延幹入為設酒食畢遣之曰適吾有宻事且出就館事了别自相請後三日瑜請幹與周觀營中行視倉庫軍資器仗訖還宴飲示之侍者服飾珍玩之物因謂幹曰丈夫處世遇知己之主外託君臣之義内結骨肉之恩言行計從禍福共之假使蘇張更生酈叟復出猶摭其背而折其辭豈足下㓜生所能移乎幹但笑終無所言幹還稱瑜雅量高致非言辭所間中州之士亦以此多之

**释读** 周瑜宴蒋干，三日后让察营舍、军备及侍者器物，申言与孙氏如骨肉，蒋干知无法劝动，归称周瑜高雅。

**归年** 同《通鉴》编次209的游说。

# 公元210年｜建安十五年

[← 公元209年](ce-0209.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元211年 →](ce-0211.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **日有食之。** 十五年春二月乙巳朔，发生日食。 [[1]](#hh-note-1)

<a id="sg-event-2"></a>

2. **曹操颁求贤令。** 十五年春，下令曰：「自古受命及中兴之君，曷尝不得贤人君子与之共治天下者乎！及其得贤也，曾不出闾巷，岂幸相遇哉？上之人不求之耳。今天下尚未定，此特求贤之急时也。『孟公绰爲赵、魏老则优，不可以爲滕、薛大夫』。若必廉士而后可用，则齐桓其何以霸世！今天下得无有被褐怀玉而钓于渭濵者乎？又得无盗嫂受金而未遇无知者乎？二三子其佐我明扬仄陋，唯才是举，吾得而用之。」 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **作铜爵台。** 冬，作铜爵台。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **吴析置鄱阳与汉昌两郡。** 分豫章置鄱阳，分长沙置汉昌，以鲁肃守汉昌并屯陆口。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **孙权遣步骘为交州刺史。** 步骘抵交州，士燮兄弟服其节度，后吴巨被步骘处置。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **周瑜在巴丘病逝。** 周瑜得孙权允准筹划取蜀，回江陵整备，途中病卒。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **鲁肃承周瑜领军。** 周瑜病重举荐鲁肃，孙权任鲁肃为奋武校尉，让他接领周瑜旧部及封邑。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **出领鄱阳太守。** 建安十五年，出领鄱阳太守。 [[8]](#sg-note-8)

<a id="sy-event-9"></a>

9. **曹纯去世。** 督虎豹骑的曹纯去世。 [[9]](#sy-note-9)

<a id="wu-event-10"></a>

10. **曹操颁述志和让县之令。** 十二月己亥，曹操追叙起兵以来的志向，说明仍将领兵，归还阳夏、柘、苦三县两万户，保留武平一万户。 [[10]](#wu-note-10)

<a id="sgz-event-11"></a>

11. **赵温辟曹丕而被免的纪年异说。** 《献帝起居注》称赵温征辟曹丕，曹操劾其举荐不实，郗虑奉策免赵温。 [[11]](#sgz-note-11)

<a id="sgz-event-12"></a>

12. **程普仍领江夏，孙权以荆州地给刘备。** 孙权分荆州地与刘备，程普返回领江夏。 [[12]](#sgz-note-12)

<a id="sgz-event-13"></a>

13. **刘备到京口会见孙权。** 刘备往京会见孙权，加深关系。 [[13]](#sgz-note-13)

<a id="sgz-event-14"></a>

14. **《山阳公载记》述刘备别孙权返程。** 刘备自孙权处返回，认为难居其下，不宜再见，日夜兼行。 [[14]](#sgz-note-14)

<a id="sgz-event-15"></a>

15. **庞统在昌门会陆绩、顾劭、全琮。** 将返西时庞统在吴昌门与陆绩、顾劭、全琮相会，分别以良马、驮牛和樊子昭喻其才行，陆、顾相约将来一起品评天下士人。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **庞统守耒阳令被免。** 庞统在刘备任荆州牧期间，由从事守耒阳令，因县政不治被免。 [[16]](#sgz-note-16)

<a id="sgz-event-17"></a>

17. **鲁肃、诸葛亮荐庞统，刘备任为军师中郎将。** 鲁肃举荐庞统说他非治一县之才，诸葛亮也推荐。刘备与他深谈后任为治中从事，继任军师中郎将。 [[17]](#sgz-note-17)

> 今孤言此若為自大欲人言盡故無諱耳設使國家無有孤不知當㡬人稱帝㡬人稱王或者人見孤彊盛又性不信天命之事恐私心相評言有不遜之志妄相忖度每用耿耿齊桓晉文所以垂稱至今日者以其兵勢廣大猶能奉事周室也論語云三分天下有其二以服事殷周之徳可謂至徳矣夫能以大事小也昔樂毅走趙趙王欲與之圖燕樂毅伏而垂泣對曰臣事昭王猶事大王臣若獲戾放在他國没世然後已不忍謀趙之徒隸况燕後嗣乎胡亥之殺蒙恬也恬曰自吾先人及至子孫積信於秦三世矣今臣將兵三十餘萬其勢足以背叛然自知必死而守義者不敢辱先人之教以忘先王也孤每讀此二人書未嘗不愴然流涕也孤祖父以至孤身皆當親重之任可謂見信者矣以及子植兄弟過於三世矣孤非徒對諸君說此也常以語妻妾皆令深知此意孤謂之言顧我萬年之後汝曹皆當出嫁欲令傳道我心使他人皆知之孤此言皆肝鬲之要也所以勤勤懇懇敘心腹者見周公有金縢之書以自明恐人不信之故然欲孤便爾委捐所典兵衆以還執事歸就武平侯國實不可也何者誠恐已離兵為人所禍也既為子孫計又已敗則國家傾危是以不得慕虚名而處實禍此所不得為也前朝恩封三子為侯固辭不受今更欲受之非欲復以為榮欲以為外援為萬安計孤聞介推之避晉封申胥之逃楚賞未嘗不舍書而歎有以自省也奉國威靈仗鉞征伐推弱以克彊處小而禽大意之所圖動無違事心之所慮何向不濟遂蕩平天下不辱主命可謂天助漢室非人力也然封兼四縣食戸三萬何徳堪之江湖未静不可讓位至於邑土可得而辭今上還陽夏柘苦三縣戸二萬但食武平萬戸且以分損謗議少減孤之責也

**释读** 曹操以齐桓晋文、乐毅、蒙恬、周公等自明，称不交出军队，同时接受给三子封侯，归还阳夏、柘、苦三县，仅保武平万户。

**归年** 《通鉴》卷六十六建安十五年十二月己亥。令举旧典取譬，朝廷实际分封曹植等承建安十六年正月，见下一注。

**归年** 依本传210年送周瑜丧返西前在昌门会陆、顾、全，宿语与该行相连。

### 16. 庞统守耒阳令被免

[返回正文第16条](#sgz-event-16)

<a id="sgz037-b-1820-1"></a>

**[《三国志·庞统法正传》仓内原文 L1820](../../sources/本地分卷/三国志/三国志-卷037.md#l1820)**

> 先主領荊州，統以從事守耒陽令，在縣不治，免官。

**归年** “先主领荆州”是此前的政局，《通鉴》卷066列庞统任耒阳令免职于建安十五年。

<a id="sgz-note-17"></a>

### 17. 鲁肃、诸葛亮荐庞统，刘备任为军师中郎将

[返回正文第17条](#sgz-event-17)

<a id="sgz037-b-1820-2"></a>

**[《三国志·庞统法正传》仓内原文 L1820](../../sources/本地分卷/三国志/三国志-卷037.md#l1820)**

> 吳將魯肅遺先主書曰：「龐士元非百里才也，使處治中、別駕之任，始當展其驥足耳。」諸葛亮亦言之於先主，先主見與善譚，大器之，以為治中從事。親待亞於諸葛亮，遂與亮併為軍師中郎將。

**归年** 《通鉴》卷066据本传系鲁肃荐及刘备用于建安十五年。

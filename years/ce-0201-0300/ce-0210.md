# 公元210年｜建安十五年

[← 公元209年](ce-0209.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元211年 →](ce-0211.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **日有食之。** 十五年春二月乙巳朔，发生日食。 [[1]](#hh-note-1)

<a id="sg-event-2"></a>

2. **曹操颁求贤令。** 十五年春，下令曰：「自古受命及中兴之君，曷尝不得贤人君子与之共治天下者乎！及其得贤也，曾不出闾巷，岂幸相遇哉？上之人不求之耳。今天下尚未定，此特求贤之急时也。『孟公绰爲赵、魏老则优，不可以爲滕、薛大夫』。若必廉士而后可用，则齐桓其何以霸世！今天下得无有被褐怀玉而钓于渭濵者乎？又得无盗嫂受金而未遇无知者乎？二三子其佐我明扬仄陋，唯才是举，吾得而用之。」 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **作铜爵台。** 冬，作铜爵台。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **吴析置鄱阳与汉昌两郡。** 分豫章置鄱阳，分长沙置汉昌，以鲁肃守汉昌并屯陆口。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **孙权遣步骘为交州刺史。** 步骘抵交州，士燮兄弟服其节度，后吴巨被步骘处置。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **周瑜在巴丘病逝。** 周瑜得孙权允准筹划取蜀，回江陵整备，途中病卒。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **鲁肃承周瑜领军。** 周瑜病重举荐鲁肃，孙权任鲁肃为奋武校尉，让他接领周瑜旧部及封邑。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **出领鄱阳太守。** 建安十五年，出领鄱阳太守。 [[8]](#sg-note-8)

<a id="sy-event-9"></a>

9. **曹纯去世。** 督虎豹骑的曹纯去世。 [[9]](#sy-note-9)

<a id="wu-event-10"></a>

10. **曹操颁述志和让县之令。** 十二月己亥，曹操追叙起兵以来的志向，说明仍将领兵，归还阳夏、柘、苦三县两万户，保留武平一万户。 [[10]](#wu-note-10)

<a id="sgz-event-11"></a>

11. **赵温辟曹丕而被免的纪年异说。** 《献帝起居注》称赵温征辟曹丕，曹操劾其举荐不实，郗虑奉策免赵温。 [[11]](#sgz-note-11)

<a id="sgz-event-12"></a>

12. **程普仍领江夏，孙权以荆州地给刘备。** 孙权分荆州地与刘备，程普返回领江夏。 [[12]](#sgz-note-12)

<a id="sgz-event-13"></a>

13. **刘备到京口会见孙权。** 刘备往京会见孙权，加深关系。 [[13]](#sgz-note-13)

<a id="sgz-event-14"></a>

14. **《山阳公载记》述刘备别孙权返程。** 刘备自孙权处返回，认为难居其下，不宜再见，日夜兼行。 [[14]](#sgz-note-14)

<a id="sgz-event-15"></a>

15. **庞统在昌门会陆绩、顾劭、全琮。** 将返西时庞统在吴昌门与陆绩、顾劭、全琮相会，分别以良马、驮牛和樊子昭喻其才行，陆、顾相约将来一起品评天下士人。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **庞统守耒阳令被免。** 庞统在刘备任荆州牧期间，由从事守耒阳令，因县政不治被免。 [[16]](#sgz-note-16)

<a id="sgz-event-17"></a>

17. **鲁肃、诸葛亮荐庞统，刘备任为军师中郎将。** 鲁肃举荐庞统说他非治一县之才，诸葛亮也推荐。刘备与他深谈后任为治中从事，继任军师中郎将。 [[17]](#sgz-note-17)

<a id="sgz-event-18"></a>

18. **曹操选邴原、王烈任丞相征事。** 转署曹操丞相征事。 [[18]](#sgz-note-18)

<a id="sgz-event-19"></a>

19. **张纮再谏休兵养民。** 次年孙权又打算出军，张纮谏休兵、耕作、用贤、宽政，孙权遂罢。 [[19]](#sgz-note-19)

> 十五年，分豫章爲鄱陽郡；分長沙爲漢昌郡。以魯肅爲太守，屯陸口。

<a id="sgz054-b-2582-4"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2582](../../sources/本地分卷/三国志/三国志-卷054.md#l2582)**

> 肅初住江陵，後下屯陸口，威恩大行，眾增萬餘人，拜漢昌太守、偏將軍。

**释读** 鲁肃初居江陵，后下屯陆口，施恩威，部众增万余，任汉昌太守、偏将军。

**归年** 《吴主传》建安十五年分汉昌置守屯陆口；士众增加可能跨期。

<a id="sgz054-b-2588-1"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2588](../../sources/本地分卷/三国志/三国志-卷054.md#l2588)**

> 魯肅代周瑜，當之陸口，過蒙屯下。肅意尚輕蒙，或說肅曰：「呂將軍功名日顯，不可以故意待也，君宜顧之。」遂往詣蒙。酒酣，蒙問肅曰：「君受重任，與關羽為鄰，將何計畧以備不虞？」肅造次應曰：「臨時施宜。」蒙曰：「今東西雖為一家，而關羽實熊虎也，計安可不豫定？」因為肅畫五策。

**释读** 鲁肃赴陆口，先轻吕蒙；经劝而访，吕蒙指出孙刘虽盟，关羽强悍，宜预先准备，画五策。

**归年** 《通鉴》卷六十六系210；《江表传》作三策。

<a id="sgz054-b-2588-2"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2588](../../sources/本地分卷/三国志/三国志-卷054.md#l2588)**

> 肅於是越席就之，拊其背曰：「呂子明，吾不知卿才畧所及乃至於此也。」遂拜蒙母，結友而別。

**释读** 鲁肃越席称叹吕蒙，拜其母，结友而去。

**归年** 同鲁肃代周瑜、赴陆口。

<a id="sgz054-p-019-3"></a>

**[《三国志·周瑜鲁肃吕蒙传》裴注 019·3](../../sources/摘录/三国志-卷054-周瑜鲁肃吕蒙传裴注.md#pei-019-3)**

> 後魯肅上代周瑜過䝉言議常欲受屈肅拊䝉背曰吾謂大弟但有武畧耳至於今者學識英博非復呉下阿䝉䝉曰士别三日即更刮目相待大兄今論何一稱穰侯乎

**释读** 鲁肃接周瑜的职务时过访，交谈常受屈，感叹吕蒙已有学识；吕蒙说分别三日当另眼相看。

**归年** 《通鉴》卷六十六建安十五年，正文同一次过屯。

<a id="sgz054-p-019-4"></a>

**[《三国志·周瑜鲁肃吕蒙传》裴注 019·4](../../sources/摘录/三国志-卷054-周瑜鲁肃吕蒙传裴注.md#pei-019-4)**

> 兄今代公瑾既難為繼且與闗羽為鄰斯人長而好學讀左傳畧皆上口梗亮有雄氣然性頗自負好陵人今與為對當有單複以卿待之宻為肅陳三策肅敬受之秘而不宣

**释读** 吕蒙称关羽能熟读《左传》又好凌人，须有应对，秘献三策，鲁肃敬受不宣。

**归年** 同210过屯，正文“五策”与注“三策”并列。

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2607](../../sources/本地分卷/三国志/三国志-卷055.md#l2607)**

**释读** 程普代周瑜领南郡太守。

<a id="sgz037-b-1819-5"></a>

**释读** 周瑜去世，庞统将其灵柩护送到吴，吴地多人因此知名。

**归年** 《通鉴》卷066建安十五年记周瑜卒，其传记丧还吴；庞统活动属同一丧事。

<a id="sgz054-b-2568-4"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2568](../../sources/本地分卷/三国志/三国志-卷054.md#l2568)**

> 是時劉璋為益州牧。外有張魯寇侵，瑜乃詣京見權曰：「今曹操新折衄，方憂在腹心，未能與將軍連兵相事也。乞與奮威俱進取蜀，得蜀而並張魯，因留奮威固守其地，好與馬超結援。瑜還與將軍據襄陽以蹙操，北方可圖也。」權許之。

**释读** 刘璋时为张鲁所侵，周瑜请求与孙瑜西取巴蜀、并张鲁，以马超为援，随后与孙权取襄阳，孙权同意。

**归年** 《通鉴》卷六十六据本传，连周瑜病卒同系210。

<a id="sgz054-b-2568-5"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2568](../../sources/本地分卷/三国志/三国志-卷054.md#l2568)**

> 瑜還江陵為行裝，而道於巴丘病卒，時年三十六。

**释读** 周瑜往江陵整备，途中卒于巴丘，三十六岁。

**归年** 《通鉴》卷六十六《考异》据与孙策同年、两人卒年年龄差定210；裴注巴丘即后巴陵。

<a id="sgz054-b-2568-6"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2568](../../sources/本地分卷/三国志/三国志-卷054.md#l2568)**

> 權素服舉哀。感動左右。喪當還吳，又迎之蕪湖，眾事費度，一為供給。

**释读** 素服致哀感动周围，周瑜灵柩回吴途中亲至芜湖迎接，供给葬事费用。

**归年** 本传连周瑜210去世。

<a id="sgz054-p-010-1"></a>

**[《三国志·周瑜鲁肃吕蒙传》裴注 010·1](../../sources/摘录/三国志-卷054-周瑜鲁肃吕蒙传裴注.md#pei-010-1)**

**释读** 拟取蜀往江陵整装的周瑜卒于今巴陵，和初年留镇的巴丘县同名异地。

**归年** 释210卒，与199所镇并见。

**[《三国志·周瑜鲁肃吕蒙传》裴注 011·7](../../sources/摘录/三国志-卷054-周瑜鲁肃吕蒙传裴注.md#pei-011-7)**

**释读** 孙权流泪感叹周瑜短命，不知还能依谁。

**归年** 承周瑜卒。

### 7. 鲁肃承周瑜领军

[返回正文第7条](#sg-event-7)

<a id="sg054-l2582-e7"></a>

**[《三国志·周瑜鲁肃吕蒙传》](../../sources/摘录/三国志-卷054-周瑜鲁肃吕蒙传.md#p003)** · [仓内TXT L2582](../../sources/本地分卷/三国志/三国志-卷054.md#l2582)

> 即拜肅奮武校尉，代瑜領兵。瑜士眾四千餘人。奉邑四縣，皆屬焉。

**归年与互校** 承周瑜病卒，《资治通鉴》同在建安十五年。

<a id="sgz054-b-2582-2"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2582](../../sources/本地分卷/三国志/三国志-卷054.md#l2582)**

> 周瑜病困，上疏曰：「當今天下，方有事役，是瑜乃心夙夜所憂，願至尊先慮未然，然後康樂。今既與曹操為敵，劉備近在公安，邊境密邇，百姓未附，宜得良將以鎮撫之。魯肅智略足任，乞以代瑜。瑜隕踣之日，所懷盡矣。」

**释读** 周瑜以曹操为敌、刘备在公安且近境未定，建议用鲁肃智略镇抚。

**归年** 《周瑜传》《通鉴》建安十五年病卒前。

<a id="sgz054-b-2582-3"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2582](../../sources/本地分卷/三国志/三国志-卷054.md#l2582)**

> 即拜肅奮武校尉，代瑜領兵。瑜士眾四千餘人。奉邑四縣，皆屬焉。令程普領南郡太守。

**释读** 鲁肃任奋武校尉，接周瑜四千余人及四县奉邑，程普任南郡太守。

**归年** 同建安十五年军权交接。

> 原與平原王烈俱以選補

> 既還，明年將復出軍，紘又諫曰：「自古帝王受命之君，雖有皇靈佐於上，文德播於下，亦賴武功以昭其勳。然而貴於時動，乃後為威耳。今麾下值四百之厄，有扶危之功，宜且隱息師徒，廣開播殖，任賢使能，務祟寬惠，順天命以行誅，可不勞而定也。」於是遂止不行。

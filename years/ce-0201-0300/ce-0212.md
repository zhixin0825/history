# 公元212年｜建安十七年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **诛卫尉马腾，夷三族。** 十七年夏五月癸未，诛卫尉马腾，夷三族。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **日有食之。** 六月庚寅晦，发生日食。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **洧水、颍水溢。** 秋七月，洧水、颍水溢。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **马超破凉州，杀刺史韦康。** 八月，马超破凉州，杀刺史韦康。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **立皇子熙为济阴王，懿为山阳王，为济北王，敦为东海王。** 九月庚戌，立皇子熙为济阴王，懿为山阳王，为济北王，敦为东海王。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **星孛於五诸侯。** 冬十二月，星孛于五诸侯。 [[6]](#hh-note-6)

<a id="hh-event-7"></a>

7. **荀彧反对曹操进爵。** 董昭等拟进曹操为国公、加九锡，荀彧反对。本传并记其留在曹操军中及此后的死因。 [[7]](#hh-note-7)

<a id="hh-event-8"></a>

8. **刘璋杀张松，刘备反攻。** 张松兄张肃告发其图谋，刘璋杀张松，禁止关口放行。刘备回兵击刘璋。 [[8]](#hh-note-8)

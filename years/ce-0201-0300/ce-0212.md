2. **日有食之。** 六月庚寅晦，发生日食。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **洧水、颍水溢。** 秋七月，洧水、颍水溢。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **马超破凉州，杀刺史韦康。** 八月，马超破凉州，杀刺史韦康。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **立皇子熙为济阴王，懿为山阳王，为济北王，敦为东海王。** 九月庚戌，立皇子熙为济阴王，懿为山阳王，为济北王，敦为东海王。 [[5]](#hh-note-5)

<a id="hh-event-6"></a>

6. **星孛於五诸侯。** 冬十二月，星孛于五诸侯。 [[6]](#hh-note-6)

<a id="sg-event-14"></a>

<a id="hh-event-7"></a>

7. **荀彧反对曹操进国公，同年去世。** 董昭等拟进曹操为国公、加九锡，荀彧以曹操起兵本在匡扶汉室为由反对。此后荀彧随军，在寿春去世。关于死因，诸书记载不同。 [[7]](#hh-note-7)

<a id="sg-event-15"></a>

<a id="hh-event-8"></a>

8. **刘璋杀张松，刘备转兵攻刘璋。** 张松兄张肃告发张松与刘备的计谋，刘璋杀张松并令关戍阻断与刘备的通信。刘备召杀杨怀等人，转兵攻刘璋。 [[8]](#hh-note-8)

<a id="sg-event-9"></a>

9. **公还邺。** 十七年春正月，公还邺。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **天子命公赞拜不名，入朝不趋。** 天子命公赞拜不名，入朝不趋，劔履上殿，如萧何故事。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **马超余衆梁兴等屯蓝田。** 马超余衆梁兴等屯蓝田，使夏侯渊击平之。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **割河内之荡阴、朝歌、林虑。** 割河内之荡阴、朝歌、林虑，东郡之衞国、顿丘、东武阳、发干，钜鹿之廮陶、曲周、南和，广平之任城，赵之襄国、邯郸、易阳以益魏郡。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **公征孙权。** 冬十月，公征孙权。 [[13]](#sg-note-13)

<a id="sg-event-16"></a>

16. **筑石头城，秣陵改建业。** 孙权筑石头，改秣陵为建业，筹备北防。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **太祖追录信功，表封勋兄邵新都亭侯。** 建安十七年，太祖追录信功，表封勋兄邵新都亭侯。 [[17]](#sg-note-17)

<a id="sy-event-18"></a>

18. **张范去世。** 长期受曹操礼重、曾与邴原辅佐曹丕居守的张范去世。 [[18]](#sy-note-18)

<a id="sgz-event-19"></a>

19. **吴范预言刘备将在甲午年得益州。** 壬辰年，吴范称刘备将在甲午年取得益州。 [[19]](#sgz-note-19)

<a id="sgz-event-20"></a>

20. **夏侯渊击刘雄鸣，刘奔汉中。** 曹操派夏侯渊攻破刘雄鸣，刘雄鸣南奔汉中。 [[20]](#sgz-note-20)

<a id="sgz-event-21"></a>

21. **曹仁督七军讨平田银、苏伯。** 苏伯田银叛乱，曹仁行骁骑将军，督七军讨破。 [[21]](#sgz-note-21)

### 8. 刘璋杀张松，刘备转兵攻刘璋

[返回正文第8条](#hh-event-8)

<a id="hh075-l5369-e8"></a>

**[《后汉书·刘焉袁术吕布列传》](../../sources/摘录/后汉书-卷075-刘焉袁术吕布列传.md#p001)** · [仓内TXT L5369](../../sources/本地分卷/后汉书/后汉书-卷075.md#L5369)

> 明年，出屯葭萌。松兄廣漢太守肅懼禍及己，乃以松謀白璋，收松斬之

<a id="sg-note-15"></a>

<a id="sg032-l1657-e15"></a>

**[《三国志·先主传》](../../sources/摘录/三国志-卷032-先主传.md#p004)** · [仓内TXT L1657](../../sources/本地分卷/三国志/三国志-卷032.md#l1657)

> 松兄廣漢太守肅，懼禍逮己，白璋發其謀。於是璋收斬松，嫌隙始構矣。 璋敕關戍諸將文書勿複關通先主。先主大怒，召璋白水軍督楊懷，責以無禮，斬之。乃使黃忠、卓膺勒兵向璋。

**归年与互校** 承卷032建安十六年“明年”，所称救孙权是借口与前后交涉。

<a id="sgz031-b-1638-1"></a>

**[《三国志·刘二牧传》仓内原文 L1638](../../sources/本地分卷/三国志/三国志-卷031.md#l1638)**

> 明年，先主至葭萌，還兵南向，所在皆克。

**释读** 刘备到葭萌后改变目标，南下攻刘璋，所至多克。

**归年** 承建安十六年，“明年”为十七年。先主传另叙张松事泄后双方开战。

<a id="sgz032-b-1657-2"></a>

**[《三国志·先主传》仓内原文 L1657](../../sources/本地分卷/三国志/三国志-卷032.md#l1657)**

> 先主遣使告璋曰：「曹公徵吳，吳憂危急。孫氏與孤本為脣齒，又樂進在青泥與關羽相拒，今不往救羽，進必大克，轉侵州界，其憂有甚於魯。魯自守之賊，不足慮也。」乃從璋求萬兵及資（寶），欲以東行。璋但許兵四千，其餘皆給半。&#32;

**释读** 刘备对刘璋称孙权与自己唇齿相依、乐进与关羽在青泥相拒，请兵一万及军资东行。刘璋许兵四千，其他只给一半。

**归年** 本传冬征见于十七年，《通鉴》卷066。

<a id="sgz032-b-1657-3"></a>

**[《三国志·先主传》仓内原文 L1657](../../sources/本地分卷/三国志/三国志-卷032.md#l1657)**

> 張松書與先主及法正曰：「今大事垂可立，如何釋此去乎！」松兄廣漢太守肅，懼禍逮己，白璋發其謀。於是璋收斬松，嫌隙始構矣。 璋敕關戍諸將文書勿複關通先主。

**释读** 张松致书刘备、法正，质疑将成大事时离开。其兄张肃怕连坐告发，刘璋收斩张松，并命关戍断绝刘备文书。

**归年** 《三国志·刘二牧传》及《通鉴》卷066建安十七年冬。

<a id="sgz032-b-1657-4"></a>

**[《三国志·先主传》仓内原文 L1657](../../sources/本地分卷/三国志/三国志-卷032.md#l1657)**

> 先主大怒，召璋白水軍督楊懷，責以無禮，斬之。乃使黃忠、卓膺勒兵向璋。先主徑至關中，質諸將並士卒妻子，引兵與忠、膺等進到涪，據其城。

**释读** 刘备召杀白水军督杨怀，遣黄忠、卓膺率军向刘璋，扣关军及家口，进据涪城。

**归年** 建安十七年张松死、文书隔绝后。《刘二牧传》《通鉴》另记杨怀与高沛皆杀。此句所到关中按白水关理解。

<a id="sgz032-p-032-1"></a>

**[《三国志·先主传》裴注 032·1](../../sources/摘录/三国志-卷032-先主传裴注.md#pei-032-1)**

> 魏書曰備因激怒其衆曰吾為益州征强敵師徒勤瘁不遑寜居今積帑蔵之財而恡於賞功望士大夫為出死力戰其可得乎

**释读** 《魏书》称刘备对部属指责刘璋积财不赏功，而自己官兵征敌劳苦，反问怎能使将士尽死力。

**归年** 建安十七年刘备向刘璋索军资失败后。

<a id="sgz032-p-036-1"></a>

**[《三国志·先主传》裴注 036·1](../../sources/摘录/三国志-卷032-先主传裴注.md#pei-036-1)**

> 傅子曰初劉備襲蜀丞相掾趙戬曰劉備其不濟乎拙扵用兵每戰必敗奔亡不暇何以圖人蜀雖小區險固四塞獨守之國難卒并也徴士傅幹曰劉備寛仁有度能得人死力諸葛亮逹治知變正而有謀而為之相張飛闗羽勇而有義皆萬人之敵而為之将此三人者皆人傑也以備之畧三傑佐之何為不濟也

**释读** 《傅子》载赵戬以刘备拙战、蜀险难取判其不能成功；傅干以刘备得众死力、诸葛亮和关羽张飞得人杰，认为有望。

**归年** 注说初袭蜀，建安十七年冬刘备转攻刘璋起；具体议论年月未载。

<a id="sgz037-b-1821-2"></a>

**[《三国志·庞统法正传》仓内原文 L1821](../../sources/本地分卷/三国志/三国志-卷037.md#l1821)**

> 璋既還成都，先主當為璋北征漢中，統復說曰：「陰選精兵，晝夜兼道，徑襲成都；璋既不武，又素無預備，大軍卒至，一舉便定，此上計也。

**释读** 刘璋返成都，刘备原约出兵汉中，庞统提出精兵急袭无备的成都作为上计。

**归年** 《通鉴》卷066在建安十七年十二月叙庞统于葭萌献三计。

<a id="sgz037-b-1821-3"></a>

**[《三国志·庞统法正传》仓内原文 L1821](../../sources/本地分卷/三国志/三国志-卷037.md#l1821)**

> 楊懷、高沛，璋之名將，各仗強兵，據守關頭，聞數有箋諫璋，使發遣將軍還荊州。將軍未至，遣與相聞，說荊州有急，欲還救之，並使裝束，外作歸形；此二子既服將軍英名，又喜將軍之去，計必乘輕騎來見，將軍因此執之，進取其兵，乃向成都，此中計也。

**释读** 庞统建议佯称荆州告急以引杨怀、高沛轻骑来见，进而擒两将、收兵攻成都。

**归年** 和上、下计属于建安十七年同一次献策。

<a id="sgz037-b-1821-4"></a>

**[《三国志·庞统法正传》仓内原文 L1821](../../sources/本地分卷/三国志/三国志-卷037.md#l1821)**

> 退還白帝，連引荊州，徐還圖之，此下計也。若沈吟不去，將致大困，不可久矣。」

**释读** 庞统建议下计为退保白帝、与荆州联络再谋蜀，并劝刘备切勿长期迟疑。

**归年** 《通鉴》卷066同列于建安十七年十二月。

<a id="sgz037-b-1821-5"></a>

**[《三国志·庞统法正传》仓内原文 L1821](../../sources/本地分卷/三国志/三国志-卷037.md#l1821)**

> 先主然其中計，即斬懷、沛，還向成都，所過輒克。

**释读** 刘备采用中计，杀杨怀、高沛，取各处并回军向成都。

**归年** 《通鉴》卷066建安十七年斩二将、进据涪城；向成都的后续攻战跨年。

<a id="sgz037-b-1824-9"></a>

**释读** 刘备不再以北讨张鲁为目标，南向攻刘璋。

**归年** 《通鉴》卷066在建安十七年十二月叙刘备采用庞统中计、南入涪城，进攻延续到214。

<a id="sgz041-b-1934-3"></a>

**[《三国志·霍王向张杨费传》仓内原文 L1934](../../sources/本地分卷/三国志/三国志-卷041.md#l1934)**

> 先主自葭萌南還襲劉璋，留峻守葭萌城。

**释读** 刘备离葭萌转兵袭刘璋，留下霍峻守葭萌城。

**归年** 与《先主传》建安十七年冬转兵同一行动。《通鉴》卷067在214定蜀段追叙从前留守。

<a id="sgz041-b-1938-2"></a>

**[《三国志·霍王向张杨费传》仓内原文 L1938](../../sources/本地分卷/三国志/三国志-卷041.md#l1938)**

> 先主起事葭萌，進軍來南，連閉城不降，先主義之，不強逼也。

**释读** 刘备从葭萌起兵南下，王连闭城不降，刘备认为守义，未强攻。

**归年** 《三国志·先主传》建安十七年冬先主转兵攻刘璋；围城实际可跨次年。

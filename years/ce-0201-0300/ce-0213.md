# 213年｜曹操受封魏公，魏国建立

[← 公元212年](ce-0212.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元214年 →](ce-0214.md)

**汉献帝建安十八年**


> 本页已整理的内容：曹操被封为魏公、以十郡建立魏国后，司马懿迁太子中庶子，开始更直接地进入曹丕身边。
>
> 注意：这里的“魏国”还是汉朝名义下曹操的封国，**不是220年汉魏禅代后的曹魏帝国**。

<a id="曹操受封魏公魏国有了正式建置"></a>

<a id="sgz-event-46"></a>

<a id="event-1"></a>

1. **曹操受封魏公，魏国有了正式建置。** 建安十八年五月，汉廷以冀州十郡封曹操为魏公，并加九锡；到七月，《通鉴》又记“魏始建社稷宗庙”。这正好解释《晋书》所谓“魏国既建”的时间锚点。 [[1]](#note-1)

   《晋书》原来的叙述顺序容易误导：它先写215年从讨张鲁、又写后来从讨孙权，然后才回头说“魏国既建”。如果不拆段，就会把213年的事错排到215或217年以后。

<a id="司马懿转入曹丕身边"></a>

<a id="event-2"></a>

2. **魏国建立后，司马懿在曹丕身边任职。** 《晋书》记司马懿迁太子中庶子，参与曹丕的谋议，与陈群、吴质、朱铄号“四友”。这段为建国后的事，曹丕到建安二十二年（217）十月才正式成为魏太子，司马懿何时获任未详。 [[2]](#note-2)

24. **署严为护军，拒先主于绵竹。** 建安十八年，署严为护军，拒先主于绵竹。 [[24]](#sg-note-24)

25. **刘璋军拒刘备于涪，败保绵竹。** 刘璋遣刘跂、冷苞、张任、邓贤拒刘备，诸将败退绵竹。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

<a id="sgz-event-27"></a>

<a id="sgz-event-28"></a>

28. **《益部耆旧杂记》载刘璋兵拒刘备于涪。** 刘璋遣张任、刘璝率精兵在涪阻击刘备，兵败退守雒城，与刘循会合。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **张任在雁桥败，被擒后不屈而死。** 张任出雁桥战败被俘。刘备敬其忠勇，令降，张任坚称不事二主，被杀，刘备叹惜。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **郑度献徙民坚壁绝粮之计。** 郑度劝刘璋将巴西、梓潼人移至涪水西，清除仓储野谷，深沟高垒，等刘备军因缺乏军资撤退后再追击。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **曹操遣将击凉州。** 次年冬曹操遣偏将击凉州。 [[31]](#sgz-note-31)

<a id="sgz-event-32"></a>

32. **张承领赵郡太守。** 魏国初建，丞相参军祭酒张承兼领赵郡太守，政令施行。 [[32]](#sgz-note-32)

<a id="sgz-event-33"></a>

33. **徐邈在魏国初建时为尚书郎。** 魏国设立后，徐邈担任尚书郎。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **曹操与群臣议复肉刑而罢。** 曹操令议可否改部分死刑为宫割，钟繇主张古肉刑代死，有司以非民悦事，罢议。 [[34]](#sgz-note-34)

<a id="sgz-event-35"></a>

35. **魏初王朗兼魏郡太守。** 魏建立之初，以军祭酒领魏郡太守。 [[35]](#sgz-note-35)

<a id="sgz-event-36"></a>

36. **曹操下令迁淮南居民，纷纷渡江归吴。** 曹操不从蒋济之言，十余万江淮居民惊走入吴。 [[36]](#sgz-note-36)

<a id="sgz-event-37"></a>

37. **蒋济使邺，曹操自言徙民失算。** 蒋济后来到邺，曹操承认迁民适得其反，转任蒋济丹阳太守。 [[37]](#sgz-note-37)

<a id="sgz-event-38"></a>

38. **曹操建魏国后以高柔为尚书郎。** 魏国初建即任尚书郎。 [[38]](#sgz-note-38)

<a id="sgz-event-39"></a>

39. **杨阜、姜叙等举兵逐马超。** 杨阜、姜叙在卤城起兵，赵衢等诱马超出击，回城不得入，遂逃汉中。《通鉴》从建安十八年九月，《杨阜传》作十七年九月，《武帝纪》列于[十九年正月](ce-0214.md#sg-note-7)。 [[39]](#sgz-note-39)

<a id="sgz-event-40"></a>

40. **曹操赏逐马超将士，杨阜辞功。** 十一人封侯，杨阜获关内侯。 [[40]](#sgz-note-40)

<a id="sgz-event-41"></a>

41. **魏建国任和洽侍中。** 受侍中官。 [[41]](#sgz-note-41)

<a id="sgz-event-42"></a>

42. **魏立国后任常林尚书。** 拜常林尚书。 [[42]](#sgz-note-42)

<a id="sgz-event-43"></a>

43. **魏立国任杨俊中尉。** 迁魏中尉。 [[43]](#sgz-note-43)

<a id="sgz-event-44"></a>

44. **魏国初建用杜袭王粲和洽为侍中。** 三人并用。 [[44]](#sgz-note-44)

<a id="sgz-event-45"></a>

45. **曹操以刘廙为黄门侍郎。** 魏国初建所授。 [[45]](#sgz-note-45)

<a id="sgz-event-47"></a>

47. **魏国初建，以桓阶为虎贲中郎将、侍中。** 魏国初建，桓阶任虎贲中郎将并兼侍中。 [[47]](#sgz-note-47)

<a id="sgz-event-48"></a>

48. **魏国初建任陈群御史中丞。** 魏国建立后，陈群改任御史中丞。 [[48]](#sgz-note-48)

<a id="sgz-event-49"></a>

49. **魏国始建时任卢毓为吏部郎。** 魏国建置后，卢毓进入吏部任郎。 [[49]](#sgz-note-49)

<a id="sgz022-b-1181-1"></a>

**[《三国志·桓二陈徐卫卢传》仓内原文 L1181](../../sources/本地分卷/三国志/三国志-卷022.md#l1181)**

> 臣父紀以為漢除肉刑而增加笞，本興仁惻而死者更眾，所謂名輕而實重者也。名輕則易犯，實重則傷民。書曰：『惟敬五刑，以成三德。』易著劓、刖、滅趾之法，所以輔政助教，懲惡息殺也。且殺人償死，合於古制；至於傷人，或殘毀其體而裁翦毛髮，非其理也。若用古刑，使淫者下蠶室，盜者刖其足，則永無淫放穿窬之奸矣。夫三千之屬，雖未可悉復，若斯數者，時之所患，宜先施用。漢律所殺殊死之罪，仁所不及也，其餘逮死者，可以刑殺。如此，則所刑之與所生足以相貿矣。今以笞死之法易不殺之刑，是重人支體而輕人軀命也。

**释读** 陈群说汉废肉刑后用笞反杀更多人，以礼经说明毁体替死可以省杀，建议先行宫、刖等，保全部分重罪者性命。

**归年** 建安十八年议刑陈群复答。

**释读** 钟繇同意，王朗等持异议，曹操虽赞同钟陈，顾军事和众论暂置不行。

**[《三国志·辛毗杨阜高堂隆传》仓内原文 L1329](../../sources/本地分卷/三国志/三国志-卷025.md#l1329)**

> 阜內有報超之志，而未得其便。頃之，阜以喪妻求葬假。阜外兄姜敘屯歷城。阜少長敘家，見敘母及敘，說前在冀中時事，歔欷悲甚。

**归年** 《通鉴》卷六十六建安十八年接冀城陷落记此。

<a id="sgz025-b-1329-2"></a>

**[《三国志·辛毗杨阜高堂隆传》仓内原文 L1329](../../sources/本地分卷/三国志/三国志-卷025.md#l1329)**

> 敘曰：「何爲乃爾？」阜曰：「守城不能完，君亡不能死，亦何面目以視息於天下！馬超背父叛君，虐殺州將，豈獨阜之憂責，一州士大夫皆蒙其恥。君擁兵專制而無討賊心，此趙盾所以書殺君也。超彊而無義，多釁易圖耳。」敘母慨然，勑敘從阜計。

**释读** 杨阜痛陈不能保城、不能为故君死，说马超强而无义，姜叙当讨；姜母让姜叙从计。

**归年** 同次举兵前密议。

<a id="sgz025-b-1329-3"></a>

**[《三国志·辛毗杨阜高堂隆传》仓内原文 L1329](../../sources/本地分卷/三国志/三国志-卷025.md#l1329)**

> 計定，外與鄉人姜隱、趙昂、尹奉、姚瓊、孔信、武都人李俊、王靈結謀，定討超約，使從弟謨至冀語岳，並結安定梁寬、南安趙衢、龐恭等。

**释读** 杨阜联姜隐、赵昂等，遣杨谟报杨岳，又联梁宽、赵衢等，约定举事。

**归年** 同一军事部署。

<a id="sgz025-b-1329-4"></a>

**[《三国志·辛毗杨阜高堂隆传》仓内原文 L1329](../../sources/本地分卷/三国志/三国志-卷025.md#l1329)**

> 約誓旣明，十七年九月，與敘起兵於鹵城。超聞阜等兵起，自將出。而衢、寬等解岳，閉冀城門，討超妻子。

**释读** 本传写十七年九月同姜叙起于卤城，马超出战，赵衢等释杨岳并闭冀城，杀马超妻儿。

**归年** 《通鉴考异》明列本传十七年与《武帝纪》十八、十九年异文，按九月举兵及随即闭门、翌年正月捷音至邺，取213。

<a id="sgz025-b-1329-5"></a>

**[《三国志·辛毗杨阜高堂隆传》仓内原文 L1329](../../sources/本地分卷/三国志/三国志-卷025.md#l1329)**

> 超襲歷城，得敘母。敘母罵之曰：「汝背父之逆子，殺君之桀賊，天地豈乆容汝，而不早死，敢以面目視人乎！」超怒，殺之。

**释读** 马超袭历城擒姜母；姜母骂其背父杀君，被杀。

**归年** 承同一举兵，《通鉴》置213。

<a id="sgz025-b-1329-6"></a>

**[《三国志·辛毗杨阜高堂隆传》仓内原文 L1329](../../sources/本地分卷/三国志/三国志-卷025.md#l1329)**

> 阜與超戰，身被五創，宗族昆弟死者七人。超遂南奔張魯。

**释读** 杨阜五处受创、七族人战死，马超归张鲁。

**归年** 《武帝纪》次年正月书赵衢等讨超，司马光认为是捷报抵邺；实际过程采213。

<a id="sgz025-p-006-2"></a>

**[《三国志·辛毗杨阜高堂隆传》裴注 006·2](../../sources/摘录/三国志-卷025-辛毗杨阜高堂隆传裴注.md#pei-006-2)**

> 㑹阜妻死辭超寧歸西因過至歴候敘母說康被害及冀中之難相對泣良久姜敘舉室感悲敘母曰咄伯奕韋使君遇難豈一州之恥亦汝之負豈獨義山哉汝無顧我事淹變生人誰不死死國忠義之大者但當速發我自為汝當之不以餘年累汝也

**释读** 杨阜因妻丧访姜叙母，叙说韦康被害，姜母自任遇害风险，催姜叙发兵。

**归年** 《通鉴》十八年同姜母敦促部署。

<a id="sgz025-p-006-3"></a>

**[《三国志·辛毗杨阜高堂隆传》裴注 006·3](../../sources/摘录/三国志-卷025-辛毗杨阜高堂隆传裴注.md#pei-006-3)**

> 因勅敘與阜參議許諾分人傳語鄉里尹奉趙昂及安定梁寛等令敘先舉兵叛超超怒必自來擊敘寛等因從後閉門約誓已定敘遂進兵入鹵昂奉守祁山超聞果自出擊敘寛等從後閉冀門

**释读** 与尹奉、赵昂、梁宽约谋，姜叙先入卤城引马超出，赵昂等守祁山，梁宽闭冀门。

**归年** 同次举兵。正文记十七年，《考异》定十八年。

<a id="sgz025-p-006-4"></a>

**[《三国志·辛毗杨阜高堂隆传》裴注 006·4](../../sources/摘录/三国志-卷025-辛毗杨阜高堂隆传裴注.md#pei-006-4)**

> 超失據過鹵叙守鹵超因進至歴歴中見超往以為敘軍還又傳聞超已走奔漢中故歴無備及超入歴執敘母母怒罵超超被罵大怒即殺敘母及其子燒城而去

**释读** 马超绕卤城入历城，守军误以为己方；马超杀骂他的姜叙母及其子，烧城而去。

**归年** 同次举兵。

<a id="sgz025-p-006-12"></a>

**[《三国志·辛毗杨阜高堂隆传》裴注 006·12](../../sources/摘录/三国志-卷025-辛毗杨阜高堂隆传裴注.md#pei-006-12)**

> 又刼昂質其嫡子月於南鄭欲要昂以為己用然心未甚信超妻楊聞異節行請與讌終日異欲信昂於超以濟其謀謂楊曰昔管仲入齊立九合之功由余適秦穆公成霸方今社稷初定治亂在於得人涼州士馬廼可與中夏爭鋒不可不詳也楊深感之以為忠於已遂與異重相接結昂所以得信於超全功免禍者異之力也

**释读** 马超以赵昂嫡子赵月为质，王异假引管仲、由余，使马超妻杨氏信任，为赵昂掩护。

**归年** 冀陷后至九月起兵前，依《通鉴》建安十八年。

<a id="sgz025-p-006-13"></a>

**[《三国志·辛毗杨阜高堂隆传》裴注 006·13](../../sources/摘录/三国志-卷025-辛毗杨阜高堂隆传裴注.md#pei-006-13)**

> 及昂與楊阜等結謀討超告異曰吾謀如是事必萬全當奈月何異厲聲應曰忠義立於身雪君父之大恥喪元不足為重况一子哉夫項託顔淵豈復百年貴義存耳昂曰善遂共閉門逐超

**释读** 赵昂忧儿子，王异劝坚守忠义；赵昂从之闭城门逐马超。

**归年** 同次逐马超。

<a id="sgz025-b-1330-2"></a>

> 阜讓曰：「阜君存無扞難之功，君亡無死節之効，於義當絀，於法當誅；超又不死，無宜苟荷爵祿。」

**归年** 同次辞爵。

<a id="sgz025-b-1330-3"></a>

> 太祖報曰：「君與羣賢共建大功，西土之人以爲美談。子貢辭賞，仲尼謂之止善。君其剖心以順國命。姜敘之母，勸敘早發，明智乃爾，雖楊敞之妻蓋不過此。賢哉，賢哉！良史記錄，必不墜於地矣。」

**释读** 曹操用子贡辞赏为戒，劝杨阜受命，并称姜叙母智勇宜载史。

**归年** 同次答书。

**归年** 接建安十八年平定与封赏，承本传。

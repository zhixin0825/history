# 213年｜曹操受封魏公，魏国建立

[← 公元212年](ce-0212.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元214年 →](ce-0214.md)

**汉献帝建安十八年**


> 本页已整理的内容：曹操被封为魏公、以十郡建立魏国后，司马懿迁太子中庶子，开始更直接地进入曹丕身边。
>
> 注意：这里的“魏国”还是汉朝名义下曹操的封国，**不是220年汉魏禅代后的曹魏帝国**。

<a id="曹操受封魏公魏国有了正式建置"></a>

<a id="event-1"></a>

1. **曹操受封魏公，魏国有了正式建置。** 建安十八年五月，汉廷以冀州十郡封曹操为魏公，并加九锡；到七月，《通鉴》又记“魏始建社稷宗庙”。这正好解释《晋书》所谓“魏国既建”的时间锚点。 [[1]](#note-1)

   《晋书》原来的叙述顺序容易误导：它先写215年从讨张鲁、又写后来从讨孙权，然后才回头说“魏国既建”。如果不拆段，就会把213年的事错排到215或217年以后。

<a id="司马懿转入曹丕身边"></a>

<a id="event-2"></a>

2. **魏国建立后，司马懿在曹丕身边任职。** 《晋书》记司马懿迁太子中庶子，参与曹丕的谋议，与陈群、吴质、朱铄号“四友”。这段为建国后的事，曹丕到建安二十二年（217）十月才正式成为魏太子，司马懿何时获任未详。 [[2]](#note-2)

**归年** 本传及《李严传》建安十八年。

<a id="sgz045-b-2172-2"></a>

**释读** 吴壹为刘璋中郎将，率兵在涪拒刘备，战事中投降。

**归年** 《先主传》建安十八年刘备与刘璋军在涪、绵竹交兵。

<a id="sgz043-b-2024-2"></a>

**[《三国志·黄李吕马王张传》仓内原文 L2024](../../sources/本地分卷/三国志/三国志-卷043.md#l2024)**

**释读** 李恢受荐赴州途中闻刘备从葭萌反攻刘璋，判断刘璋必败，借郡使名义在绵竹见刘备。

**归年** 刘备起兵在212；《先主传》与《通鉴》记213年战于涪并至绵竹，以会见落点系。

### 30. 郑度献徙民坚壁绝粮之计

[返回正文第30条](#sgz-event-30)

<a id="sgz037-b-1825-1"></a>

**[《三国志·庞统法正传》仓内原文 L1825](../../sources/本地分卷/三国志/三国志-卷037.md#l1825)**

> 鄭度說璋曰：「左將軍縣軍襲我，兵不滿萬，士眾未附，野谷是資，軍無輜重。其計莫若盡驅巴西、梓潼民內涪水以西，其倉廩野谷，一皆燒除，高壘深溝，靜以待之。彼至，請戰，勿許，久無所資，不過百日，必將自走。走而擊之，則必禽耳。」

**归年** 《通鉴》卷066建安十八年记刘备南攻后的郑度奏劝，列在雒城围攻之前。

<a id="sgz037-b-1825-2"></a>

**[《三国志·庞统法正传》仓内原文 L1825](../../sources/本地分卷/三国志/三国志-卷037.md#l1825)**

> 先主聞而惡之，以問正。正曰：「終不能用，無可憂也。」璋果如正言，謂其群下曰：「吾聞拒敵以安民，未聞動民以避敵也。」於是黜度，不用其計。

**释读** 刘备听说郑度的对策而忧，法正料刘璋终不用；刘璋以拒敌为安民、不可先扰民为由弃计，罢郑度。

**归年** 《通鉴》卷066建安十八年同一抗敌筹议；用同一事件号可与郑度上计互读。

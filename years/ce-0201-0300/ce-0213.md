# 213年｜“魏国”建立后，司马懿进入曹丕的核心圈

[← 上一张已编年页：公元208年](ce-0208.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元215年 →](ce-0215.md)

**汉献帝建安十八年**


> 本页已整理的内容：曹操被封为魏公、以十郡建立魏国后，司马懿迁太子中庶子，开始更直接地进入曹丕身边。
>
> 注意：这里的“魏国”还是汉朝名义下曹操的封国，**不是220年汉魏禅代后的曹魏帝国**。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="曹操受封魏公魏国有了正式建置"></a>

<a id="event-1"></a>

1. **曹操受封魏公，魏国有了正式建置。** 建安十八年五月，汉廷以冀州十郡封曹操为魏公，并加九锡；到七月，《通鉴》又记“魏始建社稷宗庙”。这正好解释《晋书》所谓“魏国既建”的时间锚点。 [[1]](#note-1)

   《晋书》原来的叙述顺序容易误导：它先写215年从讨张鲁、又写后来从讨孙权，然后才回头说“魏国既建”。如果不拆段，就会把213年的事错排到215或217年以后。

<a id="司马懿转入曹丕身边"></a>

<a id="event-2"></a>

2. **司马懿转入曹丕身边。** 《晋书》说，魏国建立后，司马懿迁为太子中庶子，参与谋议，受到曹丕信任，并与陈群、吴质、朱铄并称“四友”。 [[2]](#note-2)

   这一步对理解司马懿后来的政治位置很重要：他不再只是曹操丞相府里的一名属官，也开始成为曹丕个人政治圈的一员。

   “四友”是《晋书》传记给出的称呼。本轮先保存，不因为名称醒目就推定四人每天都作为固定集团行动。

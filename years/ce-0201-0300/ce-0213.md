# 213年｜曹操受封魏公，魏国建立

[← 公元212年](ce-0212.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元214年 →](ce-0214.md)

**汉献帝建安十八年**


> 本页已整理的内容：曹操被封为魏公、以十郡建立魏国后，司马懿迁太子中庶子，开始更直接地进入曹丕身边。
>
> 注意：这里的“魏国”还是汉朝名义下曹操的封国，**不是220年汉魏禅代后的曹魏帝国**。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="曹操受封魏公魏国有了正式建置"></a>

<a id="event-1"></a>

1. **曹操受封魏公，魏国有了正式建置。** 建安十八年五月，汉廷以冀州十郡封曹操为魏公，并加九锡；到七月，《通鉴》又记“魏始建社稷宗庙”。这正好解释《晋书》所谓“魏国既建”的时间锚点。 [[1]](#note-1)

   《晋书》原来的叙述顺序容易误导：它先写215年从讨张鲁、又写后来从讨孙权，然后才回头说“魏国既建”。如果不拆段，就会把213年的事错排到215或217年以后。

<a id="司马懿转入曹丕身边"></a>

<a id="event-2"></a>

2. **魏国建立后，司马懿在曹丕身边任职。** 《晋书》记司马懿迁太子中庶子，参与曹丕的谋议，与陈群、吴质、朱铄号“四友”。这段为建国后的事，曹丕到建安二十二年（217）十月才正式成为魏太子，司马懿何时获任未详。 [[2]](#note-2)

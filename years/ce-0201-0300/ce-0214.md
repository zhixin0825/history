<a id="hh-event-1"></a>

1. **旱。** 十九年夏四月，旱。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **雨水。** 五月，雨水。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **刘备破刘璋，据益州。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **曹操遣将夏侯渊讨宋建於枹罕，获之。** 冬十月，曹操遣将夏侯渊讨宋建于枹罕，获之。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **曹操杀皇后伏氏，灭其族及二皇子。** 十一月丁卯，曹操杀皇后伏氏，灭其族及二皇子。 [[5]](#hh-note-5)

<a id="sg-event-6"></a>

6. **始耕籍田。** 十九年春正月，始耕籍田。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **南安赵衢、汉阳尹奉等讨超。** 南安赵衢、汉阳尹奉等讨超，枭其妻子，超奔汉中。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **韩遂徙金城，入氐王千万部。** 韩遂徙金城，入氐王千万部，率羌、胡万余骑与夏侯渊战，击，大破之，遂走西平。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **渊与诸将攻兴国，屠之。** 渊与各将领攻兴国，屠之。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **省安东、永阳郡。** [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **安定太守毋丘兴将之官，公戒之曰“羌”。** 安定太守毋丘兴将之官，公戒之曰：「羌，胡欲与中国通，自当遣人来，慎勿遣人徃。善人难得，必将教羌、胡妄有所请求，因欲以自利；不从便爲失异俗意，从之则无益事。」 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **兴至，遣校尉范陵至羌中。** 兴至，遣校尉范陵至羌中，陵果教羌，使自请爲属国都尉。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **公曰“吾预知当尔”。** 公曰：「吾预知当尔，非圣也，但更事多耳。」 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **天子使魏公位在诸侯王上。** 三月，天子使魏公位在诸侯王上，改授金玺，赤绂、远游冠。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **公征孙权。** 秋七月，公征孙权。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **公自合肥还。** [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **公至孟津。** 十二月，公至孟津。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **天子命公置旄头，宫殿设锺虡。** [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **令曰“夫有行之士未必能进取”。** 乙未，令曰：「夫有行之士未必能进取，进取之士未必能有行也。陈平岂笃行，苏秦岂守信邪？而陈平定汉业，苏秦济弱燕。由此言之，士有偏短，庸可废乎！主管官员明思此义，则士无遗滞，官无废业矣。」 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **又曰“夫刑”。** 又曰：「夫刑，百姓之命也，而军中典狱者或非其人，而任以三军死生之事，吾甚惧之。其选明达法理者，使持典刑。」 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **于是置理曹掾属。** [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **龐统攻雒县时遇害。** 龐统率众围攻雒城，中箭身死，刘备痛惜。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **孙权攻克皖城。** 五月出征，闰月攻克皖城，获庐江太守朱光及城中军民。 [[23]](#sg-note-23)

<a id="wu-event-24"></a>

24. **汉使至魏迎曹氏二贵人。** 《献帝起居注》记王邑、刘艾持节，带副使与礼物、宦官等到魏公国迎曹氏二贵人。 [[24]](#wu-note-24)

<a id="sgz-event-25"></a>

25. **蒯越去世并托付家族。** 蒯越临终致书曹操托其照顾家人，曹操回信承诺不会有愧于死者与生者。 [[25]](#sgz-note-25)

### 5. 曹操杀皇后伏氏，灭其族及二皇子

[返回正文第5条](#hh-event-5)

**[《三国志·武帝纪》](../../sources/摘录/三国志-卷001-武帝纪.md#p007)** · [仓内TXT L97](../../sources/本地分卷/三国志/三国志-卷001.md#l97)

<a id="hh009-l1277-e5"></a>

**[《后汉书·献帝纪》](../../sources/摘录/后汉书-卷009-献帝纪.md#p003)** · [仓内TXT L1277](../../sources/本地分卷/后汉书/后汉书-卷009.md#L1277)

> 十一月丁卯，曹操殺皇后伏氏，滅其族及二皇子。

<a id="wu-p-095-1"></a>

**[《三国志·武帝纪》裴注 095·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-095-1)**

> 曹瞞傳曰公遣華歆勒兵入宫收后后閉戸匿壁中歆壞户發壁牽后出帝時與御史大夫郗慮坐后被髪徒跣過執帝手曰不能復相活邪帝曰我亦不自知命在何時也帝謂慮曰郗公天下寧有是乎遂將后殺之完及宗族死者數百人

**释读** 《曹瞒传》载华歆破壁拖出伏后，她散发赤足向献帝诀别，帝答不知自己寿数，又质问郗虑。书称伏后被杀，伏完及宗族数百人亦死。

**归年** 建安十九年十一月。《后汉书·皇后纪》记伏后幽死、二子遇害和宗族百余人死，另《后汉书·皇后纪》明确伏完209年已卒，故《曹瞒传》所称伏完于214年被杀及死者数，均与彼书记载有异。

<a id="wu-p-094-1"></a>

**[《三国志·武帝纪》裴注 094·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-094-1)**

> 九州春秋曰參軍傅幹諫曰治天下之大具有二文與武也用武則先威用文則先徳威徳足以相濟而後王道備矣徃者天下大亂上下失序明公用武攘之十平其九今未承王命者吳與蜀也吳有長江之險蜀有崇山之阻難以威服易以徳懐愚以為可且按甲寢兵息軍養士分土定封論功行賞若此則内外之心固有功者勸而天下知制矣然後漸興學校以導其善性而長其義節公神武震於四海若修文以濟之則普天之下無思不服矣今舉十萬之衆頓之長江之濵若賊負固深藏則士馬不能逞其能竒變無所用其權則大威有屈而敵心未能服矣唯明公思虞舜舞干戚之義全威養徳以道制勝公不從軍遂無功

**释读** 《九州春秋》记傅幹称威德须并用，吴蜀地险宜以文德招来，应休兵、论功定封、兴学；十万兵压在长江边若敌坚守也难见效，故劝曹操以舜旧典修德。曹操未听，此征无功。

**归年** 附《武帝纪》建安十九年秋七月征孙权条；意见、成败均系这次征战。

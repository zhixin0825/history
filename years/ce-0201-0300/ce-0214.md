[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **旱。** 十九年夏四月，旱。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **雨水。** 五月，雨水。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **刘备破刘璋，据益州。** [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **曹操遣将夏侯渊讨宋建於枹罕，获之。** 冬十月，曹操遣将夏侯渊讨宋建于枹罕，获之。 [[4]](#hh-note-4)

<a id="hh-event-5"></a>

5. **曹操杀皇后伏氏，灭其族及二皇子。** 十一月丁卯，曹操杀皇后伏氏，灭其族及二皇子。 [[5]](#hh-note-5)

<a id="sg-event-6"></a>

6. **始耕籍田。** 十九年春正月，始耕籍田。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **南安赵衢、汉阳尹奉等讨超。** 南安赵衢、汉阳尹奉等讨超，枭其妻子，超奔汉中。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **韩遂徙金城，入氐王千万部。** 韩遂徙金城，入氐王千万部，率羌、胡万余骑与夏侯渊战，击，大破之，遂走西平。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **渊与诸将攻兴国，屠之。** 渊与各将领攻兴国，屠之。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **省安东、永阳郡。** [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **安定太守毋丘兴将之官，公戒之曰“羌”。** 安定太守毋丘兴将之官，公戒之曰：「羌，胡欲与中国通，自当遣人来，慎勿遣人徃。善人难得，必将教羌、胡妄有所请求，因欲以自利；不从便爲失异俗意，从之则无益事。」 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **兴至，遣校尉范陵至羌中。** 兴至，遣校尉范陵至羌中，陵果教羌，使自请爲属国都尉。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **公曰“吾预知当尔”。** 公曰：「吾预知当尔，非圣也，但更事多耳。」 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **天子使魏公位在诸侯王上。** 三月，天子使魏公位在诸侯王上，改授金玺，赤绂、远游冠。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **公征孙权。** 秋七月，公征孙权。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **公自合肥还。** [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **公至孟津。** 十二月，公至孟津。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **天子命公置旄头，宫殿设锺虡。** [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **令曰“夫有行之士未必能进取”。** 乙未，令曰：「夫有行之士未必能进取，进取之士未必能有行也。陈平岂笃行，苏秦岂守信邪？而陈平定汉业，苏秦济弱燕。由此言之，士有偏短，庸可废乎！主管官员明思此义，则士无遗滞，官无废业矣。」 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **又曰“夫刑”。** 又曰：「夫刑，百姓之命也，而军中典狱者或非其人，而任以三军死生之事，吾甚惧之。其选明达法理者，使持典刑。」 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **于是置理曹掾属。** [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **龐统攻雒县时遇害。** 龐统率众围攻雒城，中箭身死，刘备痛惜。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **孙权攻克皖城。** 五月出征，闰月攻克皖城，获庐江太守朱光及城中军民。 [[23]](#sg-note-23)

<a id="wu-event-24"></a>

24. **汉使至魏迎曹氏二贵人。** 《献帝起居注》记王邑、刘艾持节，带副使与礼物、宦官等到魏公国迎曹氏二贵人。 [[24]](#wu-note-24)

<a id="sgz-event-25"></a>

25. **蒯越去世并托付家族。** 蒯越临终致书曹操托其照顾家人，曹操回信承诺不会有愧于死者与生者。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **刘备纳吴氏为夫人。** 群臣劝刘备聘刘瑁遗孀吴氏；刘备顾虑同族，法正举晋文公与子圉为例，刘备遂纳吴氏。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **法正致书刘璋劝变计保全家族。** 围雒城时法正向刘璋写劝书，随后列举利害。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **刘备任法正蜀郡太守及扬武将军。** 法正主管都畿，内为刘备参谋。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **马超再围祁山，夏侯渊决计先救。** 马超还围祁山，姜叙告急，诸将等曹操节度；夏侯渊担心往返邺四千里后救援已晚。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **夏侯渊攻长离，引韩遂出战。** 韩遂在显亲，夏侯渊欲袭，韩遂逃离；夏侯渊取粮追至略阳附近，诸将争论追韩遂或攻兴国氐。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **霍峻击破围兵，斩向存。** 守军不足千人，趁敌懈怠出击，大破刘璋军并斩向存。 [[31]](#sgz-note-31)

<a id="sgz-event-32"></a>

32. **刘备平蜀后设盐府校尉治盐铁。** 刘备平蜀后设主管盐铁利益的盐府校尉。 [[32]](#sgz-note-32)

<a id="sgz-event-33"></a>

33. **刘巴议铸直百钱并设官市。** 刘备许士卒取蜀府库物资，成都破后府库空耗。刘巴建议铸直百钱、平物价、令吏设官市，刘备听从，国库数月充实。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **邢颙为曹植家丞，刘桢劝曹植敬贤。** 曹操为子择有法度的官属，选邢颙为曹植家丞。 [[34]](#sgz-note-34)

**释读** 蜀地富盛，刘备置酒犒军，以城中金银分赐，粮帛归还。

**归年** 建安十九年成都受降后。

<a id="sgz032-b-1658-3"></a>

**[《三国志·先主传》仓内原文 L1658](../../sources/本地分卷/三国志/三国志-卷032.md#l1658)**

> 先主復領益州牧，諸葛亮為股肱，法正為謀主，關羽、張飛、馬超為爪牙，許靖、麋竺、簡雍為賓友。及董和、黃權、李嚴等本璋之所授用也，吳壹、費觀等又璋之婚親也，彭羕又璋之所排擯也，劉巴者宿昔之所忌恨也，皆處之顯任，盡其器能。有誌之士，無不競勸。

**释读** 刘备任益州牧，以诸葛亮、法正等参与核心军政；也任用董和、黄权、李严和刘璋姻亲、曾与己有嫌之人。

**归年** 《通鉴》卷067建安十九年定蜀后，文中概叙后来诸任，不能据以设各个人物精确任年月。

> 先主西定益州，拜羽董督荊州事。

**释读** 关羽被正式拜掌荆州军务。

<a id="sgz036-b-1794-7"></a>

**[《三国志·关张马黄赵传》仓内原文 L1794](../../sources/本地分卷/三国志/三国志-卷036.md#l1794)**

> 羽聞馬超來降，舊非故人，羽書與諸葛亮，問超人才可誰比類。亮知羽護前，乃答之曰：「孟起兼資文武，雄烈過人，一世之傑，黥、彭之徒，當與益德並驅爭先，猶未及髯之絕倫逸群也。」羽美鬚髯，故亮謂之髯。羽省書大悅，以示賓客。

**释读** 得知马超投刘备，关羽询问其才，诸葛亮将马超比英布、彭越，同时赞关羽绝伦。关羽喜欢并给众人看。

**归年** 马超降刘备在214（《马超传》及《先主传》）。问答接其新来。

<a id="sgz036-b-1799-7"></a>

**[《三国志·关张马黄赵传》仓内原文 L1799](../../sources/本地分卷/三国志/三国志-卷036.md#l1799)**

> 先主入益州，還攻劉璋，飛與諸葛亮等溯流而上，分定郡縣。至江州，破璋將巴郡太守嚴顏，生獲顏。飛呵顏曰：「大軍至，何以不降而敢拒戰？」顏答曰：「卿等無狀，侵奪我州，我州但有斷頭將軍，無有降將軍也。」飛怒，令左右牽去斫頭，顏色不變，曰：「斫頭便斫頭，何為怒邪！」飛壯而釋之，引為賓客。飛所過戰克，與先主會於成都。

**释读** 从荆州溯江西上，张飞生获严颜。严颜至斩不屈，张飞赏识，释为宾客，后会刘备于成都。

> 先主定益州，以壹為護軍討逆將軍，納壹妹為夫人。

**释读** 刘备定州后任吴壹护军讨逆将军，纳其妹吴氏为夫人。

**归年** 《穆皇后传》定益州后纳公议，建安十九年。

### 27. 法正致书刘璋劝变计保全家族

[返回正文第27条](#sgz-event-27)

<a id="sgz037-b-1825-3"></a>

**[《三国志·庞统法正传》仓内原文 L1825](../../sources/本地分卷/三国志/三国志-卷037.md#l1825)**

> 及軍圍雒城，正箋與璋曰：

**归年** 《通鉴》卷067在建安十九年围雒近一年、庞统死时摘要收书；围雒起于213，书内张飞等部行军符合214后期围城。

<a id="sgz037-b-1826-1"></a>

**[《三国志·庞统法正传》仓内原文 L1826](../../sources/本地分卷/三国志/三国志-卷037.md#l1826)**

> 正受性無術，盟好違損，懼左右不明本末，必並歸咎，蒙恥沒身，辱及執事，是以損身於外，不敢反命。恐聖聽穢惡其聲，故中間不有箋敬，顧念宿遇，瞻望悢々。然惟前後披露腹心，自從始初以至於終，實不藏情，有所不盡，但愚闇策薄，精誠不感，以致於此耳。今國事已危，禍害在速，雖捐放於外，言足憎尤，猶貪極所懷，以盡餘忠。

**释读** 法正自述居于外、没敢及时反命，但既受知遇，愿在益州事势危急时陈言。

**归年** 建安十九年劝刘璋书首，《通鉴》卷067于雒城陷前叙同一书。

<a id="sgz037-b-1826-2"></a>

**[《三国志·庞统法正传》仓内原文 L1826](../../sources/本地分卷/三国志/三国志-卷037.md#l1826)**

> 明將軍本心，正之所知也，實為區區不欲失左將軍之意，而卒至於是者，左右不達英雄從事之道，謂可違信黷誓，而以意氣相致，日月相遷，趨求順耳悅目，隨阿遂指，不圖遠慮為國深計故也。事變既成，又不量強弱之勢，以為左將軍縣遠之眾，糧谷無儲，欲得以多擊少，曠日相持。

**释读** 法正称刘璋本无意加害刘备，指其左右不明形势，后又高估自身兵力、料刘备困在远征补给中。

**归年** 同一214年书，为法正辩己并责刘璋僚属的说辞。

<a id="sgz037-b-1826-3"></a>

**[《三国志·庞统法正传》仓内原文 L1826](../../sources/本地分卷/三国志/三国志-卷037.md#l1826)**

> 而從關至此，所歷輒破，離宮別屯，日自零落。雒下雖有萬兵，皆壞陳之卒，破軍之將，若欲爭一旦之戰，則兵將勢力，實不相當。各欲遠期計糧者，今此營守已固，穀米已積，而明將軍土地日削，百姓日困，敵對遂多，所供遠曠。愚意計之，謂必先竭，將不復以持久也。

**释读** 法正历举刘备转战获胜和积粮已足，而刘璋地缩民困、给养先尽，认为不能相持。

**归年** 同一封214年书，数项战略判断依写信者立场。

<a id="sgz037-b-1826-4"></a>

**[《三国志·庞统法正传》仓内原文 L1826](../../sources/本地分卷/三国志/三国志-卷037.md#l1826)**

> 空爾相守，猶不相堪，今張益德數萬之眾，已定巴東，入犍為界，分平資中、德陽，三邈道侵，將何以御之？本為明將軍計者，必謂此軍縣遠無糧，饋運不及，兵少無繼。今荊州道通，眾數十倍，加孫車騎遣弟及李異、甘寧等為其後繼。

**释读** 法正称张飞已定巴东进犍为、资中、德阳，荆州交通已通，孙权援军亦可作为后继。

**归年** 《通鉴》卷067在建安十九年记张飞、赵云等分路进兵；吴方军援是书中所称，可另核，不把书中兵力当实数。

<a id="sgz037-b-1826-5"></a>

**[《三国志·庞统法正传》仓内原文 L1826](../../sources/本地分卷/三国志/三国志-卷037.md#l1826)**

> 若爭客主之勢，以土地相勝者，今此全有巴東，廣漢、犍為，過半已定，巴西一郡，復非明將軍之有也。計益州所仰惟蜀，蜀亦破壞；三分亡二，吏民疲睏，思為亂者十戶而八；若敵遠則百姓不能堪役，敵近則一旦易主矣。廣漢諸縣，是明比也。又魚復與關頭實為益州福禍之門，今二門悉開，堅城皆下，諸軍並破，兵將俱盡，而敵家數道併進，已入心腹，坐守都、雒，存亡之勢，昭然可見。

**释读** 法正逐指巴东、广汉、犍为、巴西相继落入刘备控制，刘璋失去大半州土，鱼复和关头既开，守成都和雒也无救。

**归年** 为214年雒围论战局，本信的领土、民意比例属于劝降话语。

<a id="sgz037-b-1826-6"></a>

**[《三国志·庞统法正传》仓内原文 L1826](../../sources/本地分卷/三国志/三国志-卷037.md#l1826)**

> 斯乃大略，其外較耳，其餘屈曲，難以辭極也。以正下愚，猶知此事不可覆成，況明將軍左右明智用謀之士，豈當不見此數哉？旦夕偷幸，求容取媚，不慮遠圖，莫肯盡心獻良計耳。若事窮勢迫，將各索生，求濟門戶，展轉反覆，與今計異，不為明將軍盡死難也。而尊門猶當受其憂。正雖獲不忠之謗，然心自謂不負聖德，顧惟分義，實竊痛心。左將軍從本舉來，舊心依依，實無薄意。愚以為可圖變化，以保尊門。

**释读** 法正指身边谋士多求自保，不会共死，重申刘备没有薄待刘璋本意，建议早变计以保刘氏家门。

**归年** 为同一214年劝书的结语；《通鉴》接书叙刘璋未答。

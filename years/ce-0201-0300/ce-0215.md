## 本年概述

建安二十年，曹操越关夺取汉中，张鲁归降。魏、刘两家继续争夺巴地。孙权与刘备在荆州先争后和，孙权还军后围合肥，遭张辽反击。

1. **曹操会诸军入汉中，张鲁退而归降。** 曹操西进，夏侯渊率凉州诸将于休亭会师，张既别攻氐并集粮，苏则为向导，杜畿与京兆尹郑浑转运军粮。张郃、朱灵先攻破阻道的氐兵，曹操出散关后又攻破河池氐王窦茂。张郃领五千步卒向汉中开路，徐晃分兵降服攻櫝、仇夷诸山氐人。七月，曹军进至阳平关。张鲁有意投降，弟张卫率众守关，曹军一度攻不下，后来攻破关隘，进至南郑。张鲁听从阎圃建议退入巴中，离开前将仓库财货封存。曹操入城后，得知张鲁有意归降，遣人慰谕。十一月，张鲁率家属归降，曹操拜他为镇南将军，封阆中侯，食邑万户，五子和阎圃等也封列侯。刘雄鸣、程银、侯选先后来降，曹操恢复刘雄鸣的官职、程银与侯选的官爵。曹操又授李休等官，收用庞德，任杨阜为益州刺史。 [[1]](#ce0215-note-1)

2. **曹操停止进取蜀地，部署汉中及关中。** 汉中初定，司马懿和刘晔劝曹操乘势进取益州。曹操未立即进兵，刘晔数日后认为蜀中形势已变。张既、和洽分别就迁民、补实三辅及减轻远戍负担进言。曹操从南郑还军，夏侯渊留屯汉中，拜征西将军，张郃等协同据守。有人建议让韩浩留守汉中，曹操不愿失去掌禁兵的护军，将韩浩带回。赵俨随后处理斜谷兵变。 [[2]](#ce0215-note-2)

3. **汉中战后，魏与刘备争巴地。** 朴胡、杜濩率巴夷、賨民附曹操。夏侯渊代理都护将军，督张郃、徐晃等进平巴郡，苏则安定下辩氐。刘备派黄权迎张鲁未及，转而击破杜濩、朴胡。张郃进兵巴东、巴西，将一部分降民迁往汉中，继而进军宕渠。张飞与张郃相持五十多日，最终在瓦口一带击败魏军。张郃率余部退回南郑。 [[3]](#ce0215-note-3)

4. **韩遂身亡，首级送交曹操。** 韩遂在关陇兵败后曾投奔郭宪，郭宪保护了他。韩遂身亡后，西平、金城当地将领将首级送到正在武都的曹操军中。郭宪不肯列名领功，曹操后来得知，仍赐他关内侯。 [[4]](#ce0215-note-4)

## 荆州与合肥

<a id="ce0215-event-5"></a>

<a id="sg-event-12"></a>

<a id="sg-event-13"></a>

5. **孙刘争荆南，在益阳对峙后议和。** 鲁肃、关羽所守地界相接，早有争端，鲁肃一直以维持和好为务。刘备占有益州后，孙权索长沙、零陵、桂阳，刘备拒绝。孙权命吕蒙、凌统等进兵，吕岱督孙茂等十将参战。长沙、桂阳归服，零陵太守郝普拒守。刘备自蜀至公安，遣关羽争三郡，孙权命鲁肃率兵驻益阳，又召吕蒙驰援。吕蒙将召令秘而不宣，通过郝普旧交邓玄之让郝普误以为援军无望。郝普出降后，吕蒙留人守零陵，当天赶赴益阳。关羽选锐士五千，准备夜渡益阳上游浅滩。甘宁原有三百人，请求增兵，鲁肃派一千人补给他，甘宁当夜赴浅滩。关羽闻讯停止渡水，在岸边扎营，这处浅滩后来称关羽濑。孙权赏功，拜甘宁为西陵太守，领阳新、下雉两县。鲁肃在益阳约关羽会谈，双方所部退至百步外，两将持刀赴会。曹操入汉中后，刘备担心益州受威胁，遣使向孙权求和。孙权派诸葛瑾回复，双方以湘水为界议分荆州，孙权交还零陵。诸葛瑾此行与弟弟诸葛亮只在公事上会面。安成等四县官吏曾合兵据阴山城拒战，吕岱将其围降，留镇长沙。三郡平定后，安成长吴砀与中郎将袁龙响应关羽，分别据攸县和醴陵。鲁肃攻攸，吴砀突围逃走；吕岱攻醴陵，擒斩袁龙，后任庐陵太守。 [[5]](#ce0215-note-5)

<a id="ce0215-event-6"></a>

<a id="sg-event-6"></a>

6. **孙权围合肥，张辽等在逍遥津再击吴军。** 孙权率军围合肥。守军拆看曹操出征汉中前交给护军薛悌的密令，照令由乐进守城，张辽、李典出战。三将平素不和，张辽担心部众难以协力，李典表示愿放下私怨、共解城围。张辽募八百人，夜间宰牛犒军，次日清晨率兵冲到孙权旗下。孙权登高冢自守，吴军见张辽人少，合围数重。张辽突围后折返，救出仍陷阵中的部众。徐盛受伤失矛，贺齐领兵挡击并夺回其矛，陈武战死，宋谦、徐盛两部一度溃退，潘璋斩两名逃兵，其余士兵回身再战。魏军守城十余日。吴军有疫，撤兵时主力已先行，张辽等突袭津北，孙权召前军回援，已来不及。吕蒙、蒋钦、甘宁与凌统等护卫孙权。甘宁引弓拒敌，急催军中鼓吹，右部督凌统率三百亲兵护送孙权突围。津桥已被破坏，孙权策马越桥脱险。凌统回身抵敌，亲兵尽死，自己负伤，披甲潜行回到孙权舟上。孙权见凌统为亲兵痛哭，亲自替他拭泪，将他留在舟上养伤。凌统得卓氏良药保住性命，升偏将军，原领部伍加倍。贺齐率三千兵在津南接应孙权。孙权登船后，贺齐在席中流泪劝他以后不可轻涉险地，孙权答应铭记。孙权亲临陈武的葬礼。战后曹操拜张辽为征东将军，给李典增邑百户。蒋钦迁荡寇将军、领濡须督，早年随孙权募兵、曾在豫章平乱的潘璋也获任偏将军，屯半州。 [[6]](#ce0215-note-6) [甘宁卒年异说](#gan-ning-death-dating)。

**釋讀與歸年** 曹操征汉中时任郑浑为京兆尹。郑浑整顿新附人口的居住、耕作和互助，使殷弱相伍、温信者与孤老相邻，严禁盗贼。出征时京兆转运军粮为最，郑浑所遣屯田民无人逃亡。治理可随建安二十年任命和军运合读，各措施持续多久未载。

> 太祖征張魯，轉曄爲主簿。旣至漢中，山峻難登，軍食頗乏。太祖曰：「此妖妄之國耳，何能爲有無？吾軍少食，不如速還。」便自引歸，令曄督後諸軍，使以次出。曄策魯可克，加糧道不繼，雖出，軍猶不能皆全，馳白太祖：「不如致攻。」遂進兵，多出弩以射其營。魯奔走，漢中遂平。

**S1｜《晋书》卷一**

> 从讨张鲁，言于魏武曰：“刘备以诈力虏刘璋，蜀人未附而远争江陵，此机不可失也。今若曜威汉中，益州震动，进兵临之，势必瓦解。”

曹操回答的大意是：人总是不知足，已经得陇，又想得蜀。

**釋讀** 諸將疑單刀相會有變，魯肅主張當面說明。關羽以劉備在烏林有功爭取立足之地，魯肅則以劉備長阪困敗後由孫權安置、現已有益州為由爭辯，並警告為此以弱爭強終將取禍。

**歸年** 《吳書》補同一次益陽會談，爭地是雙方立場；所引烏林、長阪是會中回顧。

<a id="wei017-l14-2"></a>

<a id="wei017-l15-1"></a>

**[《三國志·張樂于張徐傳》](../../拆分史书/三国志/卷017.md#edition-wei017-l14-2)** · [TXT L14](../../拆分史书/三国志/卷017.txt#L14) · [TXT L15（裴注）](../../拆分史书/三国志/卷017.txt#L15)

> 太祖征張魯，教與護軍薛悌，署函邊曰「賊至乃發」。俄而權率十萬衆圍合肥，乃共發教，教曰：「若孫權至者，張、李將軍出戰；樂將軍守，護軍勿得與戰。」諸將皆疑。遼曰：「公遠征在外，比救至，彼破我必矣。是以教指及其未合逆擊之，折其盛勢，以安衆心，然後可守也。成敗之機，在此一戰，諸君何疑？」李典亦與遼同。於是遼夜募敢從之士，得八百人，椎牛饗將士，明日大戰。平旦，遼被甲持戟，先登陷陣，殺數十人，斬二將，大呼自名，衝壘入，至權麾下。權大驚，衆不知所爲，走登高冢，以長戟自守。遼叱權下戰，權不敢動，望見遼所將衆少，乃聚圍遼數重。遼左右麾圍，直前急擊，圍開，遼將麾下數十人得出，餘衆號呼曰：「將軍棄我乎！」遼復還突圍，拔出餘衆。權人馬皆披靡，無敢當者。自旦戰至日中，吳人奪氣，還脩守備，衆心乃安，諸將咸服。權守合肥十餘日，城不可拔，乃引退。遼率諸軍追擊，幾復獲權。太祖大壯遼，拜征東將軍。
>
> **〔裴注〕**
> 孫盛曰：夫兵固詭道，奇正相資，若乃命將出征，推轂委權，或賴率然之形，或憑掎角之勢，羣帥不和，則棄師之道也。至於合肥之守，縣弱無援，專任勇者則好戰生患，專任怯者則懼心難保。且彼衆我寡，必懷貪墯；以致命之兵，擊貪墯之卒，其勢必勝；勝而後守，守則必固。是以魏武推選方圓，參以同異，爲之密教，節宣其用；事至而應，若合符契妙矣！

**異文** 《太平御覽》卷三百三十九〈兵部·牙〉引《吳書》記同一場城下接戰，徐盛所失作「牙」，指軍中牙旗。《賀齊傳》所載作「矛」。

> 賀齊從上討合肥，時城中出戰，徐盛失牙，齊別拒擊得盛所失牙。

<a id="wu060-l30-1"></a>

> 江表傳曰：權征合肥還，爲張遼所掩襲於津北，幾至危殆。齊時率三千兵在津南迎權。

**釋讀** 《江表傳》記孫權從合肥撤兵，張遼從逍遙津北突襲，孫權幾乎遇險。賀齊率三千兵在津南接應。

**歸年** 與〈吳主傳〉〈凌統傳〉同敘建安二十年撤離合肥時的津北突襲。

### 甘宁卒年的异说

**《建康實錄》卷一〈太祖上〉**

> 冬，折衝將軍、升城督甘寧卒。

**歸年** 紀於建安二十年（215）冬。〈甘寧傳〉只記甘寧卒後孫權痛惜，未載卒年或死因。卷051記孫權調解甘寧與孫皎爭執，信稱與北方為敵「中間十年」，若以208年赤壁為起點，約在217至218年前後。卷055〈潘璋傳〉於219年擒關羽之後、222年夷陵之戰以前敘「甘寧卒，又并其軍」，交接時間不能直接當作卒年。甘寧百騎夜襲所屬戰事也有歧說，尚不能作為卒年的確切依據。[〈甘寧傳〉](时期-三国志卷055-程黄韩蒋周陈董甘凌徐潘丁传纪年待考.md#wu055-l113-1) · [孫權手書](时期-三国志卷051-宗室传纪年待考.md#wu051-l17-6) · [〈潘璋傳〉](时期-三国志卷055-程黄韩蒋周陈董甘凌徐潘丁传纪年待考.md#wu055-l155-2) · [百騎夜襲](时期-三国志卷055-程黄韩蒋周陈董甘凌徐潘丁传纪年待考.md#wu055-l105-1)

<a id="后来发生什么不能倒过来当作当时一定能赢"></a>

### 后来发生什么，不能倒过来当作当时一定能赢

这段很容易被写成“司马懿早就看穿一切，曹操错失灭蜀良机”。但史料只证明司马懿和刘晔主张继续进攻，曹操选择停止；它并不能证明如果立即入蜀，魏军就一定能够成功。

《晋书》原文用“刘备以诈力虏刘璋”来描述刘备取得益州，这是站在魏晋政治叙事中的评价性措辞。正文改成“刘备刚取得益州不久”，保留事件事实，不把史家的立场词直接当作中性描述。

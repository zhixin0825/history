10. **以大理锺繇爲相国。** 八月，以大理锺繇爲相国。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **治兵，遂征孙权。** 冬十月，治兵，遂征孙权，十一月至谯。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **曹操驻兵居巢，进攻濡须。** 曹操在冬季进兵居巢，战事延至次年。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **贺齐和陆逊讨平尤突。** 鄱阳尤突接受曹操印绶起事，陵阳等县响应。贺齐与陆逊破之，吴取得新编兵众。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **太祖复征孙权，到合肥。** 建安二十一年，太祖再征孙权，到合肥，循行辽战处，叹息者良久。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **封鄢陵侯。** 建安二十一年，封鄢陵侯。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **封寿春侯。** 建安二十一年，封寿春侯。 [[16]](#sg-note-16)

<a id="wu-event-17"></a>

17. **曹操下令厘定春祭仪节。** 甲午开始春祠；曹操下令入庙升殿仍佩剑着履，亲手盥洗，等祭乐完送神才起，亲持祭礼至礼终。 [[17]](#wu-note-17)

<a id="wu-event-18"></a>

18. **魏国改定讲武礼。** 《魏书》记有司比照秦汉练兵，说汉只在十月都试车马，以五营之士演八阵。因现时军民习战，提议停止四时讲武，仅在立秋择吉大朝车骑、称为治兵，获准。 [[18]](#wu-note-18)

<a id="wu-event-19"></a>

19. **魏国始设奉常、宗正。** 《魏书》记魏国始设置奉常、宗正两官。 [[19]](#wu-note-19)

<a id="sgz-event-20"></a>

20. **夏侯渊增封食邑。** 建安二十一年增三百户，合八百户。 [[20]](#sgz-note-20)

<a id="sgz-event-21"></a>

21. **曹衮封平乡侯。** 曹操之子曹衮封平乡侯。 [[21]](#sgz-note-21)

<a id="sgz-event-22"></a>

22. **曹峻封郿侯。** 曹峻受封郿侯。 [[22]](#sgz-note-22)

<a id="sgz-event-23"></a>

23. **曹彪封寿春侯。** 曹彪受寿春侯爵。 [[23]](#sgz-note-23)

<a id="sgz-event-24"></a>

24. **曹操以致杨训书罪崔琰。** 杨训上表称曹操功德，有人批评趋附浮伪，说崔琰举错了人。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **毛玠被告怨谤，下狱后免官。** 毛玠因崔琰死不悦，有人告发他说给叛徒妻儿黥面为奴婢招致旱灾。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **何夔不肯屈事丁仪。** 丁仪兄弟进宠，与何夔不合，傅选建议因丁仪已害毛玠等而稍让；何夔以害人者终自害为答。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **毛玠遭谮，和洽请察实。** 曹操闻控毛玠怨谤并悯崔琰，震怒，和洽以素行求核。 [[27]](#sgz-note-27)

> 獻帝傳載詔曰自古帝王雖號稱相變爵等不同至乎褒崇元勲建立功徳光啓氏姓延于子孫庶姓之與親豈有殊焉昔我聖祖受命剏業肇基造我區夏鑒古今之制通爵等之差盡封山川以立藩屏使異姓親戚並列土地據國而王所以保乂天命安固萬嗣歴世承平臣主無事世祖中興而時有難易是以曠年數百無異姓諸侯王之位朕以不徳繼序弘業遭率土分崩羣兇縱毒自西徂東辛苦卑約當此之際唯恐溺入于難以羞先帝之聖徳賴皇天之靈俾君秉義奮身震迅神武捍朕於艱難獲保宗廟華夏遺民含氣之倫莫不蒙焉君勤過稷禹忠侔伊周而掩之以謙讓守之以彌恭是以徃者初開魏國錫君土宇懼君之違命慮君之固辭故且懐志屈意封君為上公欲以欽順高義須俟勲績韓遂宋建南結巴蜀羣逆合從圖危社稷君復命將龍驤虎奮梟其元首屠其窟栖暨至西征陽平之役親擐甲胄深入險阻芟夷蝥賊殄其凶醜盪定西陲縣旌萬里聲教逺振寧我區夏蓋唐虞之盛三后樹功文武之興旦奭作輔二祖成業英豪佐命夫以聖哲之君事為己任猶錫土班瑞以報功臣豈有如朕寡徳仗君以濟而賞典不豐將何以答神祗慰萬民哉今進君爵為魏王使使持節行御史大夫宗正劉艾奉䇿璽玄土之社苴以白茅金虎符第一至第五竹使符第一至十君其正王位以丞相領冀州牧如故其上魏公璽綬符策敬服朕命簡恤爾衆克綏庶績以揚我祖宗之休命

**释读** 《献帝传》诏追述汉初异姓王制度、献帝流离及曹操历年功劳，并以剿宋建、韩遂、张鲁等为进爵理由；命刘艾持节送策、王玺、社土及金虎符、竹使符，曹操仍领丞相及冀州牧，归还魏公印绶符策。

**归年** 接本纪建安二十一年五月进魏王；《献帝纪》系四月甲午。诏中213年封魏公、214–215年西征等为追叙。

<a id="wu-p-104-2"></a>

**[《三国志·武帝纪》裴注 104·2](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-104-2)**

> 魏王上書三辭詔三報不許又手詔曰大聖以功徳為高美以忠和為典訓故剏業垂名使百世可希行道制義使力行可效是以勲烈無窮休光茂著稷契載元首之聰明周召因文武之智用雖經營庶官仰歎俯思其對豈有若君者哉朕惟古人之功美之如彼思君忠勤之績茂之如此是以每將鏤符析瑞陳禮命冊寤寐慨然自忘守文之不徳焉今君重違朕命固辭懇切非所以稱朕心而訓後世也其抑志撙節勿復固辭

**释读** 曹操三次上书辞位。献帝三次不准，再下手诏称其功德，令勿固辞。

**归年** 建安二十一年魏王册命后的诏答。

**[《三国志·崔毛徐何邢鲍司马传》仓内原文 L603](../../sources/本地分卷/三国志/三国志-卷012.md#l603)**

> 臣垂齠執簡，累勤取官，職在機近，人事所竄。屬臣以私，無勢不絕，語臣以冤，無細不理。人情淫利，爲法所禁，法禁於利，勢能害之。青蠅橫生，爲臣作謗，謗臣之人，勢不在他。

**释读** 自陈自幼以书简进，近朝任职不受私托且愿理冤，触犯有势力者而遭诬谤。

**归年** 同案。

<a id="sgz012-b-603-3"></a>

**[《三国志·崔毛徐何邢鲍司马传》仓内原文 L603](../../sources/本地分卷/三国志/三国志-卷012.md#l603)**

> 昔王叔、陳生爭正王廷，宣子平理。命舉其契，是非有宜，曲直有所，春秋嘉焉，是以書之。

**释读** 引宣子审王叔与陈生例，主张凭文券证据明曲直。

**归年** 同案。

<a id="sgz012-b-603-4"></a>

**[《三国志·崔毛徐何邢鲍司马传》仓内原文 L603](../../sources/本地分卷/三国志/三国志-卷012.md#l603)**

> 臣不言此，無有時、人。說臣此言，必有徵要。乞蒙宣子之辨，而求王叔之對。

**释读** 断言自己没说，没有对应的时间人物，请找谤者和具体证据对质。

**归年** 同案。

<a id="sgz012-b-603-5"></a>

**[《三国志·崔毛徐何邢鲍司马传》仓内原文 L603](../../sources/本地分卷/三国志/三国志-卷012.md#l603)**

> 若臣以曲聞，即刑之日，方之安駟之贈；賜劍之來，比之重賞之惠。謹以狀對。

**释读** 称若查明有罪，处死如赏赐，自己甘受。

**归年** 同案。

<a id="sgz012-b-604-1"></a>

**[《三国志·崔毛徐何邢鲍司马传》仓内原文 L604](../../sources/本地分卷/三国志/三国志-卷012.md#l604)**

> 時桓階、和洽進言救玠。玠遂免黜，

**释读** 桓阶、和洽为毛玠求情，他最终免官。

**归年** 《通鉴》卷067建安二十一年。

<a id="sgz-note-27"></a>

### 27. 毛玠遭谮，和洽请察实

[返回正文第27条](#sgz-event-27)

<a id="sgz023-b-1240-2"></a>

**[《三国志·和常杨杜赵裴传》仓内原文 L1240](../../sources/本地分卷/三国志/三国志-卷023.md#l1240)**

> 後有白毛玠謗毀太祖，太祖見近臣，怒甚。洽陳玠素行有本，求案實其事。

**归年** 《毛玠传》明在崔琰被杀以后，《通鉴》置建安二十一年同一阶段。

<a id="sgz023-b-1240-3"></a>

**[《三国志·和常杨杜赵裴传》仓内原文 L1240](../../sources/本地分卷/三国志/三国志-卷023.md#l1240)**

> 罷朝，太祖令曰：「今言事者白玠不但謗吾也。乃復為崔琰觖望。此損君臣恩義，妄為死友怨嘆，殆不可忍也。昔蕭、曹與高祖並起微賤，致功立勛。高祖每在屈笮，二相恭順，臣道益彰，所以祚及後世也。和侍中比求實之，所以不聽，欲重參之耳。」

**释读** 曹操引萧何曹参在汉初恭顺，称要慎核毛玠怨愤之言。

**归年** 同案。

<a id="sgz023-b-1240-4"></a>

**[《三国志·和常杨杜赵裴传》仓内原文 L1240](../../sources/本地分卷/三国志/三国志-卷023.md#l1240)**

> 洽對曰：「如言事者言，玠罪過深重，非天地所覆載。臣非敢曲理玠以枉大倫也，以玠出群吏之中，特見拔擢，顯在首職，歷年荷寵，剛直忠公，為眾所憚，不宜有此。然人情難保，要宜考覈，兩驗其實。今聖恩垂含垢之仁，不忍致之於理，更使曲直之分不明，疑自近始。」

**释读** 和洽说传言若实罪甚重，但毛历年刚直公正，宜两验控诉。

**归年** 同案。

<a id="sgz023-b-1240-5"></a>

**[《三国志·和常杨杜赵裴传》仓内原文 L1240](../../sources/本地分卷/三国志/三国志-卷023.md#l1240)**

> 太祖曰：「所以不考，欲兩全玠及言事者耳。」洽對曰：「玠信有謗上之言，當肆之巿朝；若玠無此，言事者加誣大臣以誤主聽；二者不加檢覈，臣竊不安。」

**释读** 曹操欲全告者与被告；和洽说有谤则当刑，无谤则是诬，不能两舍。

**归年** 同案。

<a id="sgz023-b-1240-6"></a>

**[《三国志·和常杨杜赵裴传》仓内原文 L1240](../../sources/本地分卷/三国志/三国志-卷023.md#l1240)**

> 太祖曰：「方有軍事，安可受人言便考之邪？狐射姑刺陽處父於朝，此為君之誡也。」

**释读** 曹操虑当军事不可遽考，引狐射姑刺阳处父为戒。

**归年** 同案；春秋典例属引述。

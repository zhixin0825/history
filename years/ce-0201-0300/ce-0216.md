# 公元216年｜建安二十一年

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **曹操自进号魏王。** 二十一年夏四月甲午，曹操自进号魏王。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **日有食之。** 五月己亥朔，发生日食。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **匈奴南单于来朝。** 秋七月，匈奴南单于入朝觐见。 [[3]](#hh-note-3)

<a id="hh-event-4"></a>

4. **是岁，曹操杀琅邪王熙，国除。** 当年，曹操杀琅邪王熙，国除。 [[4]](#hh-note-4)

<a id="sg-event-5"></a>

5. **公还邺。** 二十一年春二月，公还邺。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **公亲耕籍田。** 三月壬寅，公亲耕籍田。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **代郡乌丸行单于普富卢与其侯王来朝。** [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **天子命王女爲公主，食汤沐邑。** [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **匈奴南单于呼厨泉将其名王来朝。** 秋七月，匈奴南单于呼厨泉将其名王来朝，待以客礼，遂留魏，使右贤王去卑监其国。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **以大理锺繇爲相国。** 八月，以大理锺繇爲相国。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **治兵，遂征孙权。** 冬十月，治兵，遂征孙权，十一月至谯。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **曹操驻兵居巢，进攻濡须。** 曹操在冬季进兵居巢，战事延至次年。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **贺齐和陆逊讨平尤突。** 鄱阳尤突接受曹操印绶起事，陵阳等县响应。贺齐与陆逊破之，吴取得新编兵众。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **太祖复征孙权，到合肥。** 建安二十一年，太祖再征孙权，到合肥，循行辽战处，叹息者良久。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **封鄢陵侯。** 建安二十一年，封鄢陵侯。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **封寿春侯。** 建安二十一年，封寿春侯。 [[16]](#sg-note-16)

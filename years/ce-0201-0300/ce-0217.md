# 217年｜濡须交兵之后，孙权为什么又向曹操“请降”？

[← 公元216年](ce-0216.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元218年 →](ce-0218.md)

**汉献帝建安二十二年**


> 本页已整理的内容：曹操与孙权在濡须方向交兵后，孙权派人向曹操请降、修好。《晋书》把这件事进一步写进汉魏易代的劝进语境。

1. **前线刚打完，双方马上又谈关系。** 建安二十二年，曹操进攻濡须，孙权防守。三月曹军撤退后，《通鉴》记孙权让都尉徐详去见曹操“请降”，曹操则派使者回应，双方修好，并约定婚姻关系。 [[1]](#note-1)

   所以这里的“请降”不宜简单理解成孙权已经真正把江东交给曹操。至少从紧接着发生的事情看，更像战后外交安排：双方暂时停止这一轮对抗，同时重新建立政治关系。

<a id="晋书把它写成了一场天命对话"></a>

<a id="event-2"></a>

2. **《晋书》在此接叙“天命”对话。** 《晋书》连写孙权乞降、上表称臣、曹操说起炉炭及司马懿劝进，整段未另标年。《吴主传》与《通鉴》只在217年明记徐详请降及修好；同类称臣、劝进对话另见[219年岁末](ce-0219.md#sunquan-chenfan-0219)。 [[2]](#note-2)

### 2. 《晋书》把它写成了一场“天命”对话

[返回正文第2条](#event-2)

**[《晋书》工作文本，第6行](../../sources/本地分卷/晋书/晋书-卷001.md#L6)**

> 從討張魯，言於魏武曰：「劉備以詐力虜劉璋，蜀人未附而遠爭江陵，此機不可失也。今若曜威漢中，益州震動，進兵臨之，勢必瓦解。因此之勢，易為功力。聖人不能違時，亦不失時矣。」魏武曰：「人苦無足，既得隴右，復欲得蜀！」言竟不從。既而從討孫權，破之。軍還，權遣使乞降，上表稱臣，陳說天命。魏武帝曰：「此兒欲踞吾著爐炭上邪！」答曰：「漢運垂終，殿下十分天下而有其九，以服事之。權之稱臣，天人之意也。虞、夏、殷、周不以謙讓者，畏天知命也。」

### 14. 法正劝刘备取汉中

[返回正文第14条](#sg-event-14)

<a id="sg037-l1828-e14"></a>

**[《三国志·庞统法正传》](../../sources/摘录/三国志-卷037-庞统法正传.md#p002)** · [仓内TXT L1828](../../sources/本地分卷/三国志/三国志-卷037.md#l1828)

> 二十二年，正說先主曰：「曹操一舉而降張魯，定漢中，不因此勢以圖巴、蜀，而留夏侯淵、張郃屯守，身遽北還，此非其智不逮而力不足也，必將內有憂偪故耳。今策淵、郃才略，不勝國之將帥，舉眾往討，則必可克。之克〔克之〕之日，廣農積谷，觀釁伺隙，上可以傾覆寇敵，尊獎王室，中可以蠶食雍、涼，廣拓境土，下可以固守要害，為持久之計。此蓋天以與我，時不可失也。」先主善其策，乃率諸將進兵漢中，正亦從行。

<a id="sgz037-b-1828-1"></a>

**[《三国志·庞统法正传》仓内原文 L1828](../../sources/本地分卷/三国志/三国志-卷037.md#l1828)**

> 二十二年，正說先主曰：「曹操一舉而降張魯，定漢中，不因此勢以圖巴、蜀，而留夏侯淵、張郃屯守，身遽北還，此非其智不逮而力不足也，必將內有憂偪故耳。今策淵、郃才略，不勝國之將帥，舉眾往討，則必可克。之克〔克之〕之日，廣農積谷，觀釁伺隙，上可以傾覆寇敵，尊獎王室，中可以蠶食雍、涼，廣拓境土，下可以固守要害，為持久之計。此蓋天以與我，時不可失也。」

**释读** 法正判断曹操不渡汉中继续入蜀是内部有忧，建议打败夏侯渊、张郃后积粮扩境，保险待机。

**归年** 本传明书建安二十二年，《通鉴》卷068同年记此策和付诸军事。

**释读** 刘备认可计划，率将领进兵汉中，法正从行。

**归年** 承建安二十二年；《通鉴》卷068同年接载张飞、马超等屯下辨。

<a id="sgz042-b-1971-1"></a>

**[《三国志·二杜周许孟来尹李谯郤传》仓内原文 L1971](../../sources/本地分卷/三国志/三国志-卷042.md#l1971)**

> 先主欲曹公爭漢中，問羣，羣對曰：「當得其地，不得其民也，若出偏軍，必不利，當戒慎之！」時州後部司馬蜀郡張裕亦曉佔候，而天才過羣，諫先主曰：「不可爭漢中，軍必不利。」

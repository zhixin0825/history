# 217年｜濡须交兵之后，孙权为什么又向曹操“请降”？

[← 上一张已编年页：公元215年](ce-0215.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [下一张已编年页：公元219年 →](ce-0219.md)

**汉献帝建安二十二年**


> 本页已整理的内容：曹操与孙权在濡须方向交兵后，孙权派人向曹操请降、修好。《晋书》把这件事进一步写进汉魏易代的劝进语境。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="前线刚打完双方马上又谈关系"></a>

<a id="event-1"></a>

1. **前线刚打完，双方马上又谈关系。** 建安二十二年，曹操进攻濡须，孙权防守。三月曹军撤退后，《通鉴》记孙权让都尉徐详去见曹操“请降”，曹操则派使者回应，双方修好，并约定婚姻关系。 [[1]](#note-1)

   所以这里的“请降”不宜简单理解成孙权已经真正把江东交给曹操。至少从紧接着发生的事情看，更像战后外交安排：双方暂时停止这一轮对抗，同时重新建立政治关系。

<a id="晋书把它写成了一场天命对话"></a>

<a id="event-2"></a>

2. **《晋书》把它写成了一场“天命”对话。** 《晋书》说孙权不仅乞降，还上表称臣、谈到天命。曹操说，这小子是想把我架到炉火上；司马懿则顺势说，汉运将终，曹操已经拥有天下大部分，却还以臣礼奉汉，应当懂得“天命”。 [[2]](#note-2)

   这段对话的意义主要在于**后来的晋史如何解释汉魏权力转移**。本轮不把它当成现代意义上的逐字会议记录，也不因为《晋书》保存了这段劝进话，就说217年曹操已经决定称帝——事实上曹操至死没有正式取代汉帝。

   《通鉴》保留了孙权“请降—曹操修好—重结婚”的外交事实，却没有在这里收入司马懿这段天命议论。这一差别会保留在史料说明中。

本年春曹操进攻濡须，三月退军。随后：

> 权令都尉徐详诣操请降，操报使修好，誓重结婚。

[建安二十二年开篇及濡须战，第13—29行](../../sources/资治通鉴/KR2b0007_068.txt#L13-L29)

两书都支持“战后孙权主动向曹操请降／修好”；《晋书》额外保存的“称臣、天命、司马懿劝进”属于更强的政治解释层。

<a id="note-2"></a>

### 2. 《晋书》把它写成了一场“天命”对话

[返回正文第2条](#event-2)

**[《晋书》工作文本，第6行](../../sources/本地分卷/晋书/晋书-卷001.md#L6)**

> 從討張魯，言於魏武曰：「劉備以詐力虜劉璋，蜀人未附而遠爭江陵，此機不可失也。今若曜威漢中，益州震動，進兵臨之，勢必瓦解。因此之勢，易為功力。聖人不能違時，亦不失時矣。」魏武曰：「人苦無足，既得隴右，復欲得蜀！」言竟不從。既而從討孫權，破之。軍還，權遣使乞降，上表稱臣，陳說天命。魏武帝曰：「此兒欲踞吾著爐炭上邪！」答曰：「漢運垂終，殿下十分天下而有其九，以服事之。權之稱臣，天人之意也。虞、夏、殷、周不以謙讓者，畏天知命也。」

<a id="s1"></a>
<a id="s1晋书卷一"></a>

**S1｜《晋书》卷一**

> 既而从讨孙权，破之。军还，权遣使乞降，上表称臣，陈说天命。

随后《晋书》记曹操与司马懿围绕“天命”有一段对话。

# 217年｜濡须交兵之后，孙权为什么又向曹操“请降”？

## 本年概述

建安二十二年，曹操自濡须还军，孙权遣使修好。曹操礼秩再增，曹丕被定为魏太子。刘备准备进取汉中，吴则着手收服山越。是年大疫，王粲、徐干等人去世。

1. **曹操再攻濡须后撤军，孙权遣徐详修好。** 曹操与夏侯惇、臧霸等出兵濡须。吕蒙与蒋钦共同节制吴军。徐盛此前拘押过蒋钦的屯吏，担心蒋钦报复。蒋钦仍向孙权推荐徐盛，称他忠勤、有胆略，可领万人。吕蒙督守濡须坞，置强弩防御，趁曹军前锋立营未稳时将其击破。曹操与孙权相持后于三月退军，吕蒙获任左护军、虎威将军。参加拒敌的周泰留督濡须，拜平虏将军。朱然、徐盛等起初不服，孙权宴请诸将，亲问周泰每处伤痕来自哪场战斗，因而以礼相勉，赐自用伞盖。徐盛等从此敬服。孙权遣都尉徐详往曹操处请降修好，双方约重结婚。夏侯惇从征有功，曹操后来赐以乐伎。 [[1]](#ce0217-note-1)

2. **鲁肃去世，严畯辞任，吕蒙接掌陆口。** 鲁肃四十六岁去世，孙权亲临葬礼，诸葛亮也为他发哀。孙权拟让严畯接领鲁肃的万余兵马、镇守陆口，严畯自认不善领兵，坚辞不就。吕蒙随后统领鲁肃的部众，出任汉昌太守、镇守陆口。吕蒙与关羽分守长江相邻地段，初至陆口时对关羽格外殷勤。 [[2]](#ce0217-note-2)

4. **陆逊请平山越，受命讨费栈。** 陆逊认为山中武装未平，难以向外用兵，劝孙权整编当地人口、选取精兵。孙权采纳，任陆逊为帐下右部督。丹杨费栈受曹操印绶，煽动山越充当内应。陆逊兵少，便增设旗帜，在山谷分布鼓角，夜间鼓噪进兵，打散费栈的部众。吴军随后整编丹杨、新都、会稽三郡，选壮丁入军，编其余人为民户，得精兵数万。陆逊班师屯芜湖。会稽太守淳于式曾上表说陆逊枉取百姓。陆逊入见时仍称许淳于式，认为他是为保护百姓才进言。孙权赞许陆逊。 [[4]](#ce0217-note-4)

本年春曹操进攻濡须，三月退军。随后：

> 权令都尉徐详诣操请降，操报使修好，誓重结婚。

[建安二十二年开篇及濡须战，第13—29行](../../史书/025-资治通鉴/KR2b0007_068.txt#L13-L29)

**[《三国志·吴主传》](../../史书/004-三国志/三国志-CCDH.txt#L2282-L2283)**

> 二十二年春，權令都尉徐詳詣曹公請降，公報使修好，誓重結婚。

《吴主传》记曹军攻濡须在上一年冬，《武帝纪》将曹军进至居巢、攻濡须列在本年正、二月。《通鉴》卷首《考异》明确采用后者。徐详赴曹营修好，仍随本年同一条阅读。

所以这里的“请降”不宜简单理解成孙权已经真正把江东交给曹操。至少从紧接着发生的事情看，更像战后外交安排：双方暂时停止这一轮对抗，同时重新建立政治关系。

> 二十二年，正說先主曰：「曹操一舉而降張魯，定漢中，不因此勢以圖巴、蜀，而留夏侯淵、張郃屯守，身遽北還，此非其智不逮而力不足也，必將內有憂偪故耳。今策淵、郃才略，不勝國之將帥，舉眾往討，則必可克。之克〔克之〕之日，廣農積谷，觀釁伺隙，上可以傾覆寇敵，尊獎王室，中可以蠶食雍、涼，廣拓境土，下可以固守要害，為持久之計。此蓋天以與我，時不可失也。」

**释读** 法正判断曹操不渡汉中继续入蜀是内部有忧，建议打败夏侯渊、张郃后积粮扩境，保险待机。

**归年** 本传明书建安二十二年，《通鉴》卷068同年记此策和付诸军事。

<a id="sgz037-b-1828-2"></a>

**[《三国志·庞统法正传》仓内原文 L1828](../../拆分史书/三国志/卷037.md#l1828)**

> 先主善其策，乃率諸將進兵漢中，正亦從行。

**释读** 刘备认可计划，率将领进兵汉中，法正从行。

**归年** 承建安二十二年；《通鉴》卷068同年接载张飞、马超等屯下辨。

<a id="sgz042-b-1971-1"></a>

**[《三国志·二杜周许孟来尹李谯郤传》仓内原文 L1971](../../拆分史书/三国志/卷042.md#l1971)**

> 先主欲曹公爭漢中，問羣，羣對曰：「當得其地，不得其民也，若出偏軍，必不利，當戒慎之！」時州後部司馬蜀郡張裕亦曉佔候，而天才過羣，諫先主曰：「不可爭漢中，軍必不利。」

**释读** 周群料可得地却难得民，出偏师不利；张裕也反对出军。

**归年** 《先主传》建安二十二年法正进言，二十三年刘备与夏侯渊对峙；此为拟动兵时所问，年依筹策，原文无日月。

> 劉備遣張飛、馬超、吳蘭等屯下辯；遣曹洪拒之。

<a id="sgz009-b-470-5"></a>

**[《三国志·诸夏侯曹传》仓内原文 L470](../../拆分史书/三国志/卷009.md#l470)**

> 劉備遣將吳蘭屯下辯，太祖遣曹洪征之，以休爲騎都尉，參洪軍事。太祖謂休曰：「汝雖參軍，其實帥也。」洪聞此令，亦委事於休。

**释读** 刘备派吴兰屯下辩，曹操派曹洪去抵挡，使骑都尉曹休参军并实际主事，曹洪委事于他。

**归年** 卷001 L110把刘备遣兵、曹操遣曹洪系建安二十二年冬，次年才见破吴兰。

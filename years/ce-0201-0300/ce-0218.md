<a id="hh-event-1"></a>

1. **少府耿纪、丞相司直韦晃起兵诛曹操，不克，夷三族。** 二十三年春正月甲子，少府耿纪、丞相司直韦晃起兵诛曹操，不克，夷三族。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **有星孛於东方。** 三月，有星孛于东方。 [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **孛星晨见东方二十余日。** 《天文志》记二十三年三月，孛星晨见东方二十余日，夕出西方，犯历五车、东井、五诸侯、文昌、轩辕、后妃、太微，锋炎指帝坐。 [[3]](#hh-note-3)

<a id="sg-event-4"></a>



<a id="sg-event-5"></a>

5. **曹洪破吴兰，斩其将任夔等。** [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **张飞、马超走汉中，阴平氐强端斩吴兰。** 三月，张飞、马超走汉中，阴平氐强端斩吴兰，传其首。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **代郡、上谷乌丸无臣氐等叛。** 夏四月，代郡、上谷乌丸无臣氐等叛，遣鄢陵侯彰讨破之。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **令曰“古之葬者”。** 六月，令曰：「古之葬者，必居瘠薄之地。其规西门豹祠西原上爲寿陵，因高爲基，不封不树。周礼冢人掌公墓之地，凡诸侯居左右以前，卿大夫居后，汉制亦谓之陪陵。其公卿大臣列将有功者，宜陪寿陵，其广爲兆域，使足相容。」 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **治兵，遂西征刘备。** 秋七月，治兵，遂西征刘备，九月，至长安。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **宛守将侯音等反，执南阳太守。** 冬十月，宛守将侯音等反，执南阳太守，劫略吏民，保宛。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **初，曹仁讨关羽。** 初，曹仁讨关羽，屯樊城，是月使仁围宛。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **刘备率军争汉中。** 刘备至阳平关与夏侯渊、张郃对峙，遣吴兰、雷铜入武都未成。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **孙权庱亭射虎。** 十月孙权亲骑射虎，马受伤，张世协助获虎。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **陆浑长张固被书调丁夫。** 建安二十三年，陆浑长张固被书调丁夫，当给汉中。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **乐进去世。** 乐进于本年去世。 [[15]](#sg-note-15)

<a id="wu-event-16"></a>

16. **曹操颁疫后赈济与养老令。** 命官府照顾无亲无产的老妇、幼儿及残疾人，依条令廪食；缺乏自养能力的贫民可逐口给贷，九十岁以上老人的家免一人徭役以照护。 [[16]](#wu-note-16)

<a id="sgz-event-17"></a>

17. **许芝追述二十三年彗星。** 许芝说建安二十三年又有彗星扫过太微。 [[17]](#sgz-note-17)

<a id="sgz-event-18"></a>

18. **刘备屯阳平关，夏侯渊率军相持。** 建安二十三年，刘备屯阳平关，夏侯渊率诸将对峙，战事跨到下一年。 [[18]](#sgz-note-18)

<a id="sgz-event-19"></a>

19. **曹真从至长安，领中领军。** 曹真随至长安，领中领军。 [[19]](#sgz-note-19)

<a id="sgz-event-20"></a>

20. **杨洪代法正任蜀郡太守。** 法正随刘备北征，诸葛亮表杨洪领蜀郡太守，因各项事务都办得好，使之正式任职。 [[20]](#sgz-note-20)

<a id="sgz-event-21"></a>

21. **杨洪升蜀郡太守早于李严离犍为。** 杨洪原为李严功曹，李严还未离开犍为，杨洪已经任蜀郡太守。 [[21]](#sgz-note-21)

<a id="sgz-event-22"></a>

22. **李严以郡兵平马秦、高胜起事。** 马秦、高胜聚众到资中，李严率郡士五千迎击，斩二人，部众散归民籍。 [[22]](#sgz-note-22)

<a id="sgz-event-23"></a>

23. **王烈不至而卒辽东。** 《三国志》裴注《先贤行状》记王烈未赴征召，于本年卒于辽东；《后汉书》系[219年](ce-0219.md#hh-note-9)。 [[23]](#sgz-note-23)

### 1. 少府耿纪、丞相司直韦晃起兵诛曹操，不克，夷三族

[返回正文第1条](#hh-event-1)

<a id="hh009-l1281-e1"></a>

**[《后汉书·献帝纪》](../../sources/摘录/后汉书-卷009-献帝纪.md#p003)** · [仓内TXT L1281](../../sources/本地分卷/后汉书/后汉书-卷009.md#L1281)

> 二十三年春正月甲子，少府耿紀、丞相司直韋晃起兵誅曹操，不克，夷三族。

<a id="wu-b-111-1"></a>

**[《三国志·武帝纪》仓内原文 L111](../../sources/本地分卷/三国志/三国志-卷001.md#l111)**

> 二十三年春正月，漢太醫令吉本與少府耿紀、司直韋晃等反，攻許，燒丞相長史王必營，必與潁川典農中郎將嚴匡討斬之。

**释读** 吉本、耿纪、韦晃等起事，攻许县并焚王必营；王必与严匡击斩起事者。

**归年** 本纪明记建安二十三年正月，《献帝纪》记甲子。

<a id="wu-p-109-1"></a>

**[《三国志·武帝纪》裴注 109·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-109-1)**

> 三輔決錄注曰時有京兆金禕字徳禕自以世為漢臣自日磾討莽何羅忠誠顯著名節累葉覩漢祚將移謂可季興乃喟然發憤遂與耿紀韋晃吉本本子邈邈弟穆等結謀紀字季行少有美名為丞相掾王甚敬異之遷侍中守少府邈字文然穆字思然以禕慷慨有日磾之風又與王必善因以聞之若殺必欲挾天子以攻魏南援劉備時闗羽彊盛而王在鄴留必典兵督許中事

**释读** 《三辅决录》注称金祎自述祖先金日磾忠汉，和耿纪、韦晃、吉本以及吉邈、吉穆图谋杀王必后奉献帝討魏、联络刘备。注还交代耿纪历任及金祎与王必相善。

**归年** 承建安二十三年正月许都起事，官历、金日磾旧事是用于说明动机的背景。

<a id="wu-p-109-2"></a>

**[《三国志·武帝纪》裴注 109·2](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-109-2)**

> 文然等率雜人及家僮千餘人夜燒門攻必禕遣人為内應射必中肩必不知攻者為誰以素與禕善走投禕夜喚徳禕禕家不知是必謂為文然等錯應曰王長史已死乎卿曹事立矣必乃更他路奔或曰必欲投禕其帳下督謂必曰今日事竟知誰門而投入乎扶必奔南城會天明必猶在文然等衆散故敗後十餘日必竟以創死

**释读** 吉邈率千余人夜攻，王必中箭。引文一说他因认出金祎家内应而改道，一说是部将劝阻后扶他去南城；天明王必仍在，袭击者溃散，王必十余日后伤重而死。

**归年** 附本纪建安二十三年正月，《通鉴》卷068採随督奔南城一说。

<a id="wu-p-109-3"></a>

**[《三国志·武帝纪》裴注 109·3](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-109-3)**

> 獻帝春秋曰收紀晃等將斬之紀呼魏王名曰恨吾不自生意竟為羣兒所誤耳晃頓首搏頰以至於死

**释读** 《献帝春秋》称耿纪临斩呼魏王名，说自己错信他人；韦晃顿首击颊至死。

**归年** 承建安二十三年正月起事失败后的处决。

<a id="wu-p-109-4"></a>

**[《三国志·武帝纪》裴注 109·4](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-109-4)**

> 山陽公載記曰王聞王必死盛怒召漢百官詣鄴令救火者左不救火者右衆人以為救火者必無罪皆附左王以為不救火者非助亂救火乃實賊也皆殺之

**释读** 《山阳公载记》说曹操召百官到邺，令当时曾救火者站左，因认为救火是假装而把站左者全部杀死。

**归年** 这部佚书系于218年王必死后。《武帝纪》《献帝纪》并未载这次大杀百官，依此书语气列作异载。

### 5. 曹洪破吴兰，斩其将任夔等

[返回正文第5条](#sg-event-5)

<a id="sg001-l112-e5"></a>

**[《三国志·武帝纪》](../../sources/摘录/三国志-卷001-武帝纪.md#p008)** · [仓内TXT L112](../../sources/本地分卷/三国志/三国志-卷001.md#l112)

> 曹洪破吳蘭，斬其將任夔等。

<a id="sg009-l470-e5"></a>

**[《三国志·诸夏侯曹传》](../../sources/摘录/三国志-卷009-诸夏侯曹传.md#p005)** · [仓内TXT L470](../../sources/本地分卷/三国志/三国志-卷009.md#l470)

> 洪從之，進兵擊蘭，大破之，飛果走。

**归年与互校** 《武帝纪》将战果载于建安二十三年春。

<a id="sgz032-b-1660-2"></a>

**[《三国志·先主传》仓内原文 L1660](../../sources/本地分卷/三国志/三国志-卷032.md#l1660)**

> 分遣將軍吳蘭、雷銅等入武都，皆為曹公軍所沒。

**释读** 刘备派吴兰、雷铜进入武都，二将均为曹方所灭。

**归年** 与《武帝纪》建安二十三年三月曹洪破吴兰、强端斩吴兰对读；不可把曹洪作亲手斩吴兰。

<a id="sgz009-b-470-6"></a>

**[《三国志·诸夏侯曹传》仓内原文 L470](../../sources/本地分卷/三国志/三国志-卷009.md#l470)**

> 備遣張飛屯固山，欲斷軍後。眾議狐疑，休曰：「賊實斷道者，當伏兵潛行。今乃先張聲勢，此其不能也。宜及其未集，促擊蘭，蘭破則飛自走矣。」洪從之，進兵擊蘭，大破之，飛果走。

**释读** 张飞屯固山扬言断后，曹休以寻常断道当潜行推知不能，让曹洪乘敌未集急击吴兰，敌遂大败，张飞退走。

**归年** 卷001 L112记218破吴兰、三月张飞马超退；本传补曹休的谋划。

<a id="sgz009-b-473-6"></a>

**[《三国志·诸夏侯曹传》仓内原文 L473](../../sources/本地分卷/三国志/三国志-卷009.md#l473)**

> 以偏將軍將兵擊劉備別將於下辯，破之，拜中堅將軍。

**释读** 曹真以偏将军在下辩打败刘备别将，拜中坚将军。

**归年** 卷001 L110–112系建安二十二年冬出兵、二十三年击破；本传写破敌、升任，合218。

<a id="sgz042-b-1971-3"></a>

**[《三国志·二杜周许孟来尹李谯郤传》仓内原文 L1971](../../sources/本地分卷/三国志/三国志-卷042.md#l1971)**

> 遣將軍吳蘭、雷銅等入成都，皆沒不還，悉如羣言。

**释读** 刘备派吴兰、雷铜等另进，被曹军击败，未能回来。

**归年** 仓内作“入成都”，四库、维基点校作“入武都”。《武帝纪》《曹洪传》建安二十三年春下辩作战可证，译从武都。

> 曹瞞傳曰是時南陽間苦繇投音於是執太守東里褒與吏民共反與闗羽連和南陽功曹宗子卿徃說音曰足下順民心舉大事逺近莫不望風然執郡將逆而無益何不遣之吾與子共勠力比曹公軍來闗羽兵亦至矣音從之即釋遣太守子卿因夜踰城亡出遂與太守收餘民圍音

**释读** 《曹瞒传》说南阳苦于徭役，侯音拘太守东里褒、联络关羽。功曹宗子卿说服侯音释放太守，又连夜逾城随太守招集余民反围侯音。

**归年** 本纪记起于218年十月；《通鉴》卷068同年记南阳劳役与劝释，太守名字写东里衮。

**[《三国志·三少帝纪》裴注 023·1](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-023-1)**

> 楚國先賢傳曰余字子正天姿方毅志尚仁義建安二十三年為郡功曹是時吳蜀不賔疆場多虞宛將侯音扇動山民保城以叛余與太守東里衮當擾攘之際迸竄得出音即遣騎追逐去城十里相及賊便射衮飛矢交流余前以身當箭被七創因謂追賊曰侯音狂佞造為凶逆大軍尋至誅夷在近謂卿曹本是善人素無惡心當思反善何為受其指揮我以身代君以被重創若身死君全隕没無恨因仰天號哭泣涕血淚俱下賊見其義烈釋衮不害賊去之後余亦命絶

**释读** 《楚国先贤传》记218年应余为郡功曹，侯音据宛反时与太守东里衮外逃。应余挡箭受七创，说服追兵释太守，随后死去。

**归年** 注记建安二十三年；《通鉴》卷068与《武帝纪》裴注互读，保留各书太守名字字形及伤死先后区别。

<a id="sgz041-b-1948-4"></a>

> 先主爭漢中，急書發兵，軍師將軍諸葛亮以問洪，洪曰：「漢中則益州咽喉，存亡之機會，若無漢中則無蜀矣，此家門之禍也。方今之事，男子當戰，女子當運，發兵何疑？」

**释读** 刘备为争汉中急调益州兵，诸葛亮问杨洪，杨洪说汉中是益州咽喉、要及时调兵和输送粮物。

**归年** 《资治通鉴》卷068建安二十三年与张郃在广石相抗后。

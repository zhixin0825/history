# 219年｜关羽威震华夏时，曹操为什么没有迁都？

[← 公元218年](ce-0218.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元220年 →](ce-0220.md)

**汉献帝建安二十四年**


> 这一年的主线：关羽围樊，于禁七军因洪水覆没，曹操一度考虑迁离许都。司马懿和蒋济判断孙权不会愿意看见关羽坐大，主张利用孙刘之间的矛盾，而不是先迁都示弱。

<a id="樊城一下子变成了大危机"></a>

<a id="event-1"></a>

1. **樊城一下子变成了大危机。** 建安二十四年，关羽北攻曹仁于樊。八月大雨，汉水暴涨，于禁所领诸军覆没，于禁投降；关羽又围襄阳，荆州刺史胡修、南乡太守傅方也投向关羽。关羽声势迅速扩张，史书用“威震华夏”概括当时的震动。 [[1]](#note-1)

   《晋书》此前曾写司马懿认为胡修、傅方不适合放在边地，曹操没有听，后来二人果然降关羽。这一“事后应验”的叙事很符合人物传记写法；因为原文没给当初进言的年份，本页只把它当背景，不把那次进言硬定在219年。

<a id="曹操一度想迁离许都"></a>

<a id="event-2"></a>

2. **曹操一度想迁离许都。** 关羽的影响已经扩展到许都以南。曹操考虑迁都以避其锋芒。 [[2]](#note-2)

   这时，《资治通鉴》明确写的是**司马懿与蒋济两人**一同进言：于禁军覆没主要是水灾造成，并非国家整体军事力量已经崩溃；刘备与孙权表面亲近，实际上利益并不一致，孙权尤其不会愿意关羽在长江上游坐大。因此不必先迁都，可以推动孙权从关羽背后下手。

   曹操接受了这个判断。

<a id="不能把后来吕蒙袭荆州简化成司马懿一计"></a>

<a id="event-3"></a>

3. **不能把后来吕蒙袭荆州简化成“司马懿一计”。** 后来的确发生了孙权夺荆州、吕蒙袭取公安、关羽败亡。但《通鉴》紧接着又回顾：鲁肃在世时主张暂时维持孙刘合作；吕蒙接替鲁肃后，早已有对付关羽、夺取荆州的整体打算。 [[3]](#note-3)

   所以更准确的说法是：司马懿、蒋济判断出了孙刘联盟的利益裂缝，并建议曹操利用它；这项建议与孙权内部已经形成的夺荆州计划同向。不能写成“孙权本来没有计划，因为司马懿一句话才偷袭”。

> 遷為軍司馬，言於魏武曰：「昔箕子陳謀，以食為首。今天下不耕者蓋二十餘萬，非經國遠籌也。雖戎甲未卷，自宜且耕且守。」魏武納之，於是務農積穀，國用豐贍。帝又言荊州刺史胡脩粗暴，南鄉太守傅方驕奢，並不可居邊。魏武不之察。及蜀將關羽圍曹仁於樊，于禁等七軍皆沒，脩、方果降羽，而仁圍甚急焉。
> 
> 是時漢帝都許昌，魏武以為近賊，欲徙河北。帝諫曰：「禁等為水所沒，非戰守之所失，於國家大計未有所損，而便遷都，既示敵以弱，又淮沔之人大不安矣。孫權、劉備，外親內疏，羽之得意，權所不願也。可喻權所，令掎其後，則樊圍自解。」魏武從之。權果遣將呂蒙西襲公安，拔之，羽遂為蒙所獲。
> 
> 魏武以荊州遺黎及屯田在潁川者逼近南寇，皆欲徙之。帝曰：「荊楚輕脫，易動難安。關羽新破，諸為惡者藏竄觀望。今徙其善者，既傷其意，將令去者不敢復還。」從之。其後諸亡者悉復業。

**S2｜《资治通鉴》卷六十八：樊城危机**

> 後呂蒙當襲南郡，權欲令皎與蒙為左右部大督。蒙說權曰："若至尊以征虜能，宜用之。以蒙能，宜用蒙。昔周瑜、程普為左右部督，共攻匯陵，雖事決於瑜，普自恃久將，且俱是督，遂共不睦，幾敗國事，此目前之戒也。"權寤，謝蒙曰：「以卿為大督，命皎為後繼。」禽關羽，定荊州，皖有力焉。

### 《晋书》为什么看起来像司马懿一人献策

《晋书》卷一是司马懿本纪，因此把整段意见放在司马懿名下；《通鉴》则把蒋济并列。正文采用后者更完整的人员信息，同时保留《晋书》的文本特点。[看两书差异](#s1)

**[《三国志·关羽传》](../../sources/二十四史/txt/04_sanguozhi_full.txt#L1796)**

> 司馬宣王、蔣濟以為關羽得志，孫權必不原也。可遣人勸權躡其後，許割江南以封權，則樊圍自解。曹公從之。

<a id="sunquan-chenfan-0219"></a>

### 孙权称臣与曹操的答语

[《通鉴》卷六十八](../../sources/资治通鉴/KR2b0007_068.txt#L527-L535)在本年孙权获领荆州牧、封南昌侯后，记孙权上书称臣并论天命。曹操以炉火语作答，陈群等劝进，曹操自比周文王。[《晋书》相关段落](ce-0217.md#note-2)把相近对话接在濡须请降后，劝说者写司马懿。这组材料与217年徐详请降、修好分别阅读。

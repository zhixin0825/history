# 220年｜曹操死后：先继魏王，再到汉魏禅代

[← 上一张已编年页：公元219年](ce-0219.md) · [本世纪目录](README.md) · [公元221年 →](ce-0221.md) · [全部世纪](../README.md)

**汉献帝建安二十五年／魏文帝黄初元年**


> 这一年的关键是把两个“即位”分开：曹操正月去世后，曹丕先继承魏王；到十月汉魏禅代，曹丕才成为皇帝。《晋书》卷一把这些变化压在很短的几句话里，逐年整理时必须拆开。

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="曹操死于洛阳继承问题立刻开始运转"></a>

<a id="event-1"></a>

1. **曹操死于洛阳，继承问题立刻开始运转。** 正月，曹操死于洛阳。曹丕当时在邺，魏国需要马上处理发丧、军队秩序和继承。 [[1]](#note-1)

   《晋书》说司马懿“纲纪丧事”，使内外秩序安定，并护送曹操灵柩返回邺。

   但《通鉴》在邺城这一端写得更具体：群臣一度只顾聚哭、秩序混乱，司马懿的弟弟司马孚出面要求先稳定继承秩序，又整顿禁卫、处理丧事。

   这两条并不一定只能选一个：一个可能侧重洛阳至邺的护丧，一个侧重邺城内部的继承与禁卫。但目前证据不足以把两人的具体分工拼成一幅过分精确的流程图，所以正文保留差别。

<a id="曹丕先继承的是魏王"></a>

<a id="event-2"></a>

2. **曹丕先继承的是魏王。** 曹操死后，曹丕先继魏王位。《晋书》随后说司马懿封河津亭侯，转丞相长史。 [[2]](#note-2)

   这里尤其要避免一个常见误读：《晋书》用后来谥号写“魏文帝即位”，但同一句后面又另说“及魏受汉禅”。这说明前一个节点不能直接理解成“曹丕此时已经当皇帝”。

<a id="襄阳要不要放弃司马懿再次反对撤退"></a>

<a id="event-3"></a>

3. **襄阳要不要放弃，司马懿再次反对撤退。** 关羽刚败后，孙权一度向西活动。魏廷有人认为樊、襄阳粮食不足，难以防守，想让曹仁撤回宛城。 [[3]](#note-3)

   司马懿反对：孙权刚刚击破关羽，此时正想稳固与魏的关系，不太可能马上转头北攻；襄阳又是水陆要冲，不应轻易丢掉。这个意见没有被采纳，曹仁焚弃樊、襄阳，孙权后来也没有趁机进攻。《晋书》把这件事作为司马懿判断正确的一例。

   这里暂按《晋书》叙事放在曹丕继魏王后的220年；后续处理其他卷次时若出现更细的月份材料，再细化。

<a id="到汉魏禅代以后司马懿的官职继续上升"></a>

<a id="event-4"></a>

4. **到汉魏禅代以后，司马懿的官职继续上升。** 十月以后，汉献帝让位，曹丕建立曹魏政权。《晋书》接着记司马懿任尚书，随后又任督军、御史中丞，封安国乡侯。 [[4]](#note-4)

   这一年因此是司马懿政治履历的一个明显分界：他早年的仕途是在汉朝名义下的曹操、魏国体制中展开；从此以后，才进入真正的曹魏皇朝。

**S3｜《晋书》同一原行的三个节点**

本条截取继魏王后的封侯、转官；[第3条](#note-3)引襄阳去留，[第4条](#note-4)引受禅后的任官。“魏文帝”是后来的谥号，不能据此把正月继魏王提前写成称帝。

### 3. 襄阳要不要放弃，司马懿再次反对撤退

[返回正文第3条](#event-3)

**[《晋书》工作文本，第12行](../../sources/本地分卷/晋书/晋书-卷001.md#L12)**

> 會孫權帥兵西過，朝議以樊、襄陽無穀，不可以禦寇。時曹仁鎮襄陽，請召仁還宛。帝曰：「孫權新破關羽，此其欲自結之時也，必不敢為患。襄陽水陸之衝，禦寇要害，不可棄也。」言竟不從。仁遂焚棄二城，權果不為寇，魏文悔之。

此处仅引襄阳去留；同一原行前记继魏王、后记受禅任官，分别见[第2条](#note-2)及[第4条](#note-4)。

### 4. 到汉魏禅代以后，司马懿的官职继续上升

[返回正文第4条](#event-4)

**[《晋书》工作文本，第12行](../../sources/本地分卷/晋书/晋书-卷001.md#L12)**

> 及魏受漢禪，以帝為尚書。頃之，轉督軍、御史中丞，封安國鄉侯。

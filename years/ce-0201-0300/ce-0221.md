# 公元221年｜刘备称帝东征，司马懿升任尚书右仆射

**魏文帝黄初二年；蜀汉章武元年（四月起）。**

[本年相关史料](#sources-start)

<a id="正文"></a>

<a id="event-1"></a>

1. **刘备称帝，把延续汉朝的主张变成自己的皇朝。** 四月（魏黄初二年），刘备在成都即皇帝位，改元章武，任诸葛亮为丞相、许靖为司徒。此前蜀中一度传言汉献帝已被杀害，刘备为他发丧；费诗反对在尚未击败曹魏时先称帝，没有得到采纳。刘备仍以汉为国号；现在魏与蜀汉各有皇帝，双方都不承认对方有权统治天下。 [[1]](#note-1)

<a id="event-2"></a>

2. **刘备出兵伐吴前，张飞被部下杀死。** 刘备准备攻打孙权，为关羽之死及荆州之失讨回局面。张飞原定从阆中带兵到江州会合，临出发时，却被部将张达、范强杀害，凶手带着他的首级投奔孙权。七月（蜀汉章武元年），刘备没有改变东征计划，亲自带兵东下；孙权的求和未能阻止战争。吴班、冯习等打到巫地，刘备军队随后进抵秭归，孙权则让陆逊统率诸军抵挡。 [[2]](#note-2)

<a id="event-3"></a>

3. **孙权向魏称臣，先避免同时面对两面夹击。** 八月（魏黄初二年），孙权向曹丕称臣，并送还于禁等人。曹丕接受归附，派使者册封他为吴王。刘晔反对把这种称臣看得太实在：孙权正在应付刘备，最需要的就是稳住北方；曹丕仍选择接受。这时孙权接受的是魏的吴王封号，还不是称帝。 [[3]](#note-3)

<a id="event-4"></a>

4. **司马懿的职务转入侍中和尚书右仆射。** 本年（魏黄初二年，具体月份未详），督军一职被撤销，司马懿转任侍中、尚书右仆射。 [[4]](#note-4)

> 臣聞河圖、洛書，五經讖、緯，孔子所甄，驗應自遠。謹案洛書甄曜度曰：『赤三日德昌，九世會備，合為帝際。』洛書寶號命曰：『天度帝道備稱皇，以統握契，百成不敗。』洛書錄運期曰：『九侯七傑爭命民炊骸，道路籍籍履人頭，誰使主者玄且來。』孝經鉤命決錄曰：『帝三建九會備。』臣父群未亡時，言西南數有黃氣，直立數丈，見來積年，時時有景雲祥風，從璿璣下來應之，此為異瑞。又二十二年中，數有氣如旗，從西竟東，中天而行，圖、書曰『必有天子出其方』。加是年太白、熒惑、填星，常從歲星相追。近漢初興，五星從歲星謀；歲星主義，漢位在西，義之上方，故漢法常以歲星候人主。當有聖主起於此州，以致中興。時許帝尚存，故群下不敢漏言。頃者熒惑復追歲星，見在胃昴畢；昴畢為天綱，經曰『帝星處之，眾邪消亡』。聖諱豫睹，推揆期驗，符合數至，若此非一。臣聞聖王先天而天不違，後天而奉天時，故應際而生，與神合契。原大王應天順民，速即洪業，以寧海內。

[返回正文第32条](#sg-event-32)

<a id="sg032-l1674-e32"></a>

**[《三国志·先主传》](../../sources/摘录/三国志-卷032-先主传.md#p007)** · [仓内TXT L1674](../../sources/本地分卷/三国志/三国志-卷032.md#l1674)

<a id="sg034-l1739-e32"></a>

**[《三国志·二主妃子传》](../../sources/摘录/三国志-卷034-二主妃子传.md#p002)** · [仓内TXT L1739](../../sources/本地分卷/三国志/三国志-卷034.md#l1739)

<a id="sgz033-b-1683-3"></a>

**[《三国志·后主传》仓内原文 L1683](../../sources/本地分卷/三国志/三国志-卷033.md#l1683)**

> 及即尊號，冊曰：「惟章武元年五月辛巳，皇帝若曰：太子禪，朕遭漢運艱難，賊臣篡盜，社稷無主，格人群正，以天明命，朕繼大統。今以禪為皇太子，以承宗廟，祗肅社稷。使使持節丞相亮授印綬，敬聽師傅，行一物而三善皆得焉，可不勉與！」

**释读** 刘备称帝，五月辛巳持节授皇太子印绶，嘱其敬听师傅，借《礼记》之语劝勉。

**归年** 册文自记章武元年五月辛巳。《甘皇后传》说明刘禅生母，《穆皇后传》另记册后；这里记立太子。

<a id="sgz033-p-001-1"></a>

**[《三国志·后主传》裴注 001·1](../../sources/摘录/三国志-卷033-后主传裴注.md#pei-001-1)**

> 禮記曰行一物而三善者惟世子而已其齒於學之謂也鄭玄曰物猶事也

**释读** 裴注引《礼记》说世子在学中按年龄同列，从一事得三善。郑玄释“物”即“事”。

**归年** 本注附于章武元年五月辛巳册太子；礼经及郑注本身无事件年。

<a id="sgz034-b-1737-8"></a>

**[《三国志·二主妃子传》仓内原文 L1737](../../sources/本地分卷/三国志/三国志-卷034.md#l1737)**

> 章武元年夏五月，策曰：「朕承天命，奉至尊，臨萬國。今以后為皇后，遣使持節丞相亮授璽綬，承宗廟，母天下，皇后其敬之哉！」

**释读** 刘备让持节丞相诸葛亮在五月授吴氏皇后玺绶，册命承庙、母天下。

**归年** 本传立后诏书明书章武元年五月，与当年刘备称帝相承。

<a id="sgz034-b-1744-2"></a>

**[《三国志·二主妃子传》仓内原文 L1744](../../sources/本地分卷/三国志/三国志-卷034.md#l1744)**

> 章武元年六月，使司徒靖立永為魯王，策曰：「小子永，受茲青土。朕承天序，繼統大業，遵脩稽古，建爾國家，封於東土，奄有龜蒙，世為籓輔。嗚呼，恭朕之詔！惟彼魯邦，一變適道，風化存焉。人之好德，世茲懿美。王其秉心率禮，綏爾士民，是饗是宜，其戒之哉！」

**释读** 六月，刘备命司徒许靖立刘永为鲁王，诏以鲁地旧事训诫，嘱守礼敬民。

**归年** 册文在本传明确章武元年六月，亦见《先主传》“子永、理等并为诸王”的归类。

<a id="sgz034-b-1746-2"></a>

**[《三国志·二主妃子传》仓内原文 L1746](../../sources/本地分卷/三国志/三国志-卷034.md#l1746)**

> 章武元年六月，使司徒靖立理為梁王，策曰：「小子理，朕統承漢序，祗順天命，遵脩典秩，建爾於東，為漢籓輔。惟彼梁土，畿甸之邦，民狎教化，易導以禮。往悉乃心，懷保黎庶，以永爾國，王其敬之哉！」

**释读** 六月，刘备命司徒许靖立刘理为梁王，诏以梁为汉朝屏障，嘱其敬慎承命。

**归年** 本传明书章武元年六月。

<a id="sgz032-b-1674-3"></a>

**释读** 五月立吴氏为皇后，立刘禅为皇太子。

**归年** 本传明载章武元年六月。

# 公元222年｜夷陵战败以后，魏与吴也打了起来

[← 公元221年](ce-0221.md) · [本世纪目录](README.md) · [公元223年 →](ce-0223.md)

**魏文帝黄初三年；蜀汉章武二年；吴黄武元年（本年开始使用）。**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="正文"></a>

<a id="event-1"></a>

1. **刘备继续向东推进，陆逊却不急着决战。** 年初（蜀汉章武二年），刘备从秭归继续东进，让黄权率部留在江北，自己带主力沿江南山地进入猇亭一带。陆逊没有迎着蜀军最盛的锐气硬打，而是守住要地，等待这支深入敌境的军队露出疲态。双方相持数月，刘备不断设营，也没能把吴军引出来打一场自己想要的决战。 [[1]](#note-1)

<a id="event-2"></a>

2. **陆逊转守为攻，刘备的连营接连崩溃。** 闰月（魏黄初三年），陆逊试攻后改用火攻，又让各路军队一齐进击。蜀军营垒接连失守，冯习、张南等战死；刘备退到马鞍山仍不能稳住阵脚，只得乘夜逃走，最后退入白帝城。原本要收回荆州、压倒孙权的东征，反而使蜀汉损失了大批军队和军资。 [[2]](#note-2)

<a id="event-3"></a>

3. **黄权退路被切断，转而归魏。** 八月（魏黄初三年），留在江北的黄权无法随刘备撤回，率领部众投降曹魏。蜀汉官员主张追究他家人的责任，刘备却没有照办：黄权是因全军败退、归路隔绝才走到这一步，不能简单当成主动背叛。曹丕接纳黄权，任他为镇南将军。 [[3]](#note-3)

<a id="event-4"></a>

4. **孙权不肯送儿子入魏，曹丕决定三路出兵。** 孙权虽然在上一年向魏称臣，却迟迟不肯把儿子孙登入魏的要求办下来。曹丕认为不能再信任他，九月（魏黄初三年）命曹休等攻洞口，曹仁攻濡须，曹真、夏侯尚等围攻南郡。孙权刚打退刘备，紧接着又要面对魏军。十月前后，孙权开始使用黄武年号，沿江部署防守。 [[4]](#note-4)

<a id="event-5"></a>

5. **吴蜀开始恢复联系，但还不是已经化敌为盟。** 到年末，吴与蜀汉重新有了使者往来。刘备仍驻白帝，双方的战争创伤没有消失；不过魏军南下，使两边都不能再只盯着彼此。正式重建合作，还要经过下一年的交涉。 [[5]](#note-5)

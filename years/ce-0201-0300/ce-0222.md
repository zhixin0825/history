# 公元222年｜夷陵战败以后，魏与吴也打了起来

[← 公元221年](ce-0221.md) · [本世纪目录](README.md) · [公元223年 →](ce-0223.md)

**魏文帝黄初三年；蜀汉章武二年；吴黄武元年（本年开始使用）。**

<a id="event-1"></a>

1. **刘备继续向东推进，陆逊却不急着决战。** 年初（蜀汉章武二年），刘备从秭归继续东进，让黄权率部留在江北，自己带主力沿江南山地进入猇亭一带。陆逊没有迎着蜀军最盛的锐气硬打，而是守住要地，等待这支深入敌境的军队露出疲态。双方相持数月，刘备不断设营，也没能把吴军引出来打一场自己想要的决战。 [[1]](#note-1)

<a id="event-2"></a>

2. **陆逊转守为攻，刘备的连营接连崩溃。** 闰月（魏黄初三年），陆逊试攻后改用火攻，又让各路军队一齐进击。蜀军营垒接连失守，冯习、张南等战死；刘备退到马鞍山仍不能稳住阵脚，只得乘夜逃走，最后退入白帝城。原本要收回荆州、压倒孙权的东征，反而使蜀汉损失了大批军队和军资。 [[2]](#note-2)

<a id="event-3"></a>

3. **黄权退路被切断，转而归魏。** 八月（魏黄初三年），留在江北的黄权无法随刘备撤回，率领部众投降曹魏。蜀汉官员主张追究他家人的责任，刘备却没有照办：黄权是因全军败退、归路隔绝才走到这一步，不能简单当成主动背叛。曹丕接纳黄权，任他为镇南将军。 [[3]](#note-3)

<a id="event-4"></a>

4. **孙权不肯送儿子入魏，曹丕决定三路出兵。** 孙权虽然在上一年向魏称臣，却迟迟不肯把儿子孙登入魏的要求办下来。曹丕认为不能再信任他，九月（魏黄初三年）命曹休等攻洞口，曹仁攻濡须，曹真、夏侯尚等围攻南郡。孙权刚打退刘备，紧接着又要面对魏军。十月前后，孙权开始使用黄武年号，沿江部署防守。 [[4]](#note-4)

<a id="event-5"></a>

5. **吴蜀开始恢复联系，但还不是已经化敌为盟。** 到年末，吴与蜀汉重新有了使者往来。刘备仍驻白帝，双方的战争创伤没有消失；不过魏军南下，使两边都不能再只盯着彼此。正式重建合作，还要经过下一年的交涉。 [[5]](#note-5)

<a id="sgz002-p-035-1"></a>

**[《三国志·文帝纪》裴注 035·1](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-035-1)**

> 孫盛曰夫經國營治必憑俊喆之輔賢達令徳必居參亂之任故雖周室之盛有婦人與焉然則坤道承天南面罔二三從之禮謂之至順至於號令自天子出奏事專行非古義也昔在申吕實匡有周茍以天下為心惟徳是杖則親疏之授至公一也何至后族而必斥逺之哉二漢之季世王道陵遲故令外戚憑寵職為亂階於此自時昬道喪運祚將移縱無王吕之難豈乏田趙之禍乎而後世觀其若此深懐酸毒之戒也至於魏文遂發一概之詔可謂有識之爽言非帝者之宏議

**释读** 孙盛承认君令归一，却认为任用应以德才为准，援引周时母后与申、吕诸族以及两汉政乱批评一概排斥。

**归年** 评论对象为黄初三年九月甲午的诏，所引先代例不作曹魏新史事。

> 黃初三年，將登後位，文帝欲立為後，中郎棧潛上疏曰：「在昔帝王之治天下，不惟外輔，亦有內助，治亂所由，盛衰從之。故西陵配黃，英娥降媯，並以賢明，流芳上世。桀奔南巢，禍階末喜；紂以砲烙，怡悅妲己。是以聖哲慎立元妃，必取先代世族之家，擇其令淑以統六宮，虔奉宗廟，陰教聿修。易曰：『家道正而天下定。』由內及外，先王之令典也。春秋書宗人釁夏雲，無以妾為夫人之禮。齊桓誓命於葵丘，亦曰『無以妾為妻』。今後宮嬖寵，常亞乘輿。若因愛登後，使賤人暴貴，臣恐後世下陵上替，開張非度，亂自上起也。」文帝不從，遂立為皇后。

### 24. 表首阳山东爲寿陵，作终制曰“礼”

[返回正文第24条](#sg-event-24)

<a id="sg002-l153-e24"></a>

**[《三国志·文帝纪》](../../sources/摘录/三国志-卷002-文帝纪.md#p003)** · [仓内TXT L153](../../sources/本地分卷/三国志/三国志-卷002.md#l153)

> 冬十月甲子，表首陽山東爲壽陵，作終制曰：「禮，國君即位爲椑，存不忘亡也。昔堯葬穀林，通樹之，禹葬會稽，農不易畝，故葬於山林，則合乎山林。封樹之制，非上古也，吾無取焉。壽陵因山爲體，無爲封樹，無立寑殿，造園邑，通神道。夫葬也者，藏也，欲人之不得見也。骨無痛癢之知，冢非棲神之宅，禮不墓祭，欲存亡之不黷也，爲棺槨足以朽骨，衣衾足以朽肉而已。故吾營此丘墟不食之地，欲使易代之後不知其處。無施葦炭，無藏金銀銅鐵，一以瓦器，合古塗車、芻靈之義。棺但漆際會三過，飯含無以珠玉，無施珠襦玉匣，諸愚俗所爲也。季孫以璵璠斂，孔子歷級而救之，譬之暴骸中原。宋公厚葬，君子謂華元、樂莒不臣，以爲棄君於惡。漢文帝之不發，霸陵無求也；光武之掘，原陵封樹也。霸陵之完，功在釋之；原陵之掘，罪在明帝。是釋之忠以利君，明帝愛以害親也。忠臣孝子，宜思仲尼、丘明、釋之之言，鑒華元、樂莒、明帝之戒，存於所以安君定親，使魂靈萬載無危，斯則賢聖之忠孝矣。自古及今，未有不亡之國，亦無不掘之墓也。喪亂以來，漢氏諸陵無不發掘，至乃燒取玉匣金縷，骸骨並盡，是焚如之刑也，豈不重痛哉！禍由乎厚葬封樹。『桑、霍爲我戒』，不亦明乎？其皇后及貴人以下，不隨王之國者，有終沒皆葬澗西，前又以表其處矣。蓋舜葬蒼梧，二妃不從，延陵葬子，遠在嬴、博，魂而有靈，無不之也，一澗之閒，不足爲遠。若違今詔，妄有所變改造施，吾爲戮屍地下，戮而重戮，死而重死。臣子爲蔑死君父，不忠不孝，使死者有知，將不福汝。其以此詔藏之宗廟，副在尚書、祕書、三府。」

<a id="sgz002-p-036-1"></a>

**[《三国志·文帝纪》裴注 036·1](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-036-1)**

**释读** 裴松之标“椑”音并解释天子、诸侯棺有多重，最内一重称椑。

**归年** 语词注附黄初三年十月终制。

<a id="sgz002-p-037-1"></a>

**[《三国志·文帝纪》裴注 037·1](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-037-1)**

**[1] 《资治通鉴》卷069，黄初三年刘备进军与陆逊持守条。**

> 以權為鎮北將軍，使督江北諸軍；自率諸將，自江南緣山截嶺，軍於夷道猇亭。

> 自正月與吳相拒，至六月不決。

[原文及陆逊对地形、蜀军锐气的判断](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7069.md#ref-7822231fc5b8bb)。月份沿用史书，不直接等同现代公历同号月份。

<a id="history-legacy-source-2"></a>

**[2] 《资治通鉴》卷069，黄初三年闰月条。**

> 乃敕各持一把茅，以火攻，拔之；一爾勢成，通率諸軍，同時俱攻，斬張南、馮習及胡王沙摩柯等首，破其四十餘營。

> 漢主夜遁……僅得入白帝城，其舟船、器械，水、步軍資，一時略盡。

[火攻、马鞍山与退入白帝原文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7069.md#ref-1009f3bc0f92d5)。说明：《吴主传》《通鉴》把陆逊破敌列在闰月，百科常称闰六月。《先主传》在“夏六月”黄气见后接“後十餘日”破军，未为败战另标月份。这十余日可能跨月，正文沿《通鉴》的闰月，具体日仍未定。[百科与文献复核](../../meta/记录/晋书-卷001-黄初段引文去向.md#百科与文献复核)

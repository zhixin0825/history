# 公元223年｜刘备去世，吴蜀重新走向合作

[← 公元222年](ce-0222.md) · [本世纪目录](README.md) · [公元224年 →](ce-0224.md)

**魏文帝黄初四年；蜀汉章武三年、建兴元年（五月改元）；吴黄武二年。**

[本年相关史料](#sources-start)

<a id="正文"></a>

<a id="event-1"></a>

1. **魏军围攻江陵、濡须，最后还是撤了回去。** 春季（魏黄初四年），上一年开始的攻吴战争仍在继续。朱桓守濡须，击退曹仁部队；朱然守江陵，在疾病、缺粮和城内有人谋应魏军的压力下坚持不降。魏军虽占据江中洲渚，却面临水涨后退路受威胁的危险。曹丕接受董昭的警告，催令撤出；又逢疫病，魏军各路陆续收兵，曹丕于三月回到洛阳。 [[1]](#note-1)

<a id="event-2"></a>

2. **刘备在永安托孤，四月去世。** 二月（蜀汉章武三年），诸葛亮来到永安探视刘备。病势转重后，刘备把辅佐刘禅的重任交给诸葛亮，以李严为副，并叮嘱儿子像对待父亲一样事奉丞相。四月，刘备在永安去世。他没能从夷陵败战中重新起身，蜀汉接下来面对的，是年轻继承人能否稳住朝局的问题。 [[2]](#note-2)

<a id="event-3"></a>

3. **刘禅即位，诸葛亮先把内政和粮食稳下来。** 五月（蜀汉建兴元年），刘禅即皇帝位，改元建兴。诸葛亮继续担任丞相，并领益州牧，朝廷政务集中到他这里。南中已有地方势力叛离，诸葛亮却没有立即大举出兵；国家刚经历败战和皇帝去世，他选择先安定内部、恢复耕作和积粮。南中的大规模征讨，要到225年才展开。 [[3]](#note-3)

<a id="event-4"></a>

4. **邓芝到吴，把相互猜疑谈成了共同抗魏。** 十月（蜀汉建兴元年），邓芝奉诸葛亮之命到孙权处。孙权担心刘禅年幼、蜀汉太弱，仍在考虑怎样处理与魏的关系。邓芝指出：吴蜀各有险阻，合作尚能互相支撑；一旦完全臣服于魏，就可能不断被要求入朝、送太子为质，不答应又会成为出兵的借口。孙权接受了这个判断，转向与蜀汉专力合作。夷陵之后的停战往来，至此向稳定的联盟迈进。 [[4]](#note-4)

<a id="sgz-note-56"></a>

### 56. 诸葛亮等请尊甘氏为昭烈皇后并合葬

[返回正文第56条](#sgz-event-56)

<a id="sgz034-b-1733-8"></a>

**[《三国志·二主妃子传》仓内原文 L1733](../../sources/本地分卷/三国志/三国志-卷034.md#l1733)**

> 丞相亮上言：

**归年** 事在刘备死、灵柩还成都后，承章武三年并转建兴元年。

<a id="sgz034-b-1734-1"></a>

**[《三国志·二主妃子传》仓内原文 L1734](../../sources/本地分卷/三国志/三国志-卷034.md#l1734)**

> 皇思夫人履行脩仁，淑慎其身。大行皇帝昔在上將，嬪妃作合，載育聖躬，大命不融。大行皇帝存時，篤義垂恩，念皇思夫人神柩在遠飄颻，特遣使者奉迎。會大行皇帝崩，今皇思夫人神柩以到，又梓宮在道，園陵將成，安厝有期。

**释读** 诸葛亮称甘氏仁谨、生育后主，刘备生前曾遣使迎柩；刘备已死，今其柩和甘氏灵柩相继到来，园陵将建成。

**归年** 奏文兼追述往事。诸葛亮在刘备崩、甘氏柩到、刘备尚待下葬时上奏，据《先主传》为223。

<a id="sgz034-b-1734-2"></a>

**[《三国志·二主妃子传》仓内原文 L1734](../../sources/本地分卷/三国志/三国志-卷034.md#l1734)**

> 臣輒與太常臣賴恭等議：《禮記》曰：『立愛自親始，教民孝也；立敬自長始，教民順也。』不忘其親，所由生也。春秋之義，母以子貴。昔高皇帝追尊太上昭靈夫人為昭靈皇后，孝和皇帝改葬其母梁貴人，尊號曰恭懷皇后，孝愍皇帝亦改葬其母王夫人，尊號曰靈懷皇后。

**释读** 诸葛亮与太常赖恭等参议，援《礼记》孝敬及《春秋》母子尊贵原则，列高祖、汉和帝、汉献帝尊生母的先例。

**归年** 同一223年奏文。“孝愍皇帝”系蜀汉对汉献帝的称谓，东汉改葬王氏灵怀后事见《献帝纪》兴平元年。

<a id="sgz034-b-1734-3"></a>

**[《三国志·二主妃子传》仓内原文 L1734](../../sources/本地分卷/三国志/三国志-卷034.md#l1734)**

> 今皇思夫人宜有尊號，以慰寒泉之思，輒與恭等案諡法，宜曰昭烈皇后。《詩》曰：『谷則異室，死則同穴。』故昭烈皇后宜與大行皇帝合葬，臣請太尉告宗廟，布露天下，具禮儀別奏。

**释读** 按谥法拟尊甘氏为昭烈皇后，引用《诗》生时异室、死后同穴，奏请与刘备合葬，命太尉告庙并另奏礼节。

**归年** 同一223年奏议。《先主传》明记刘备八月葬惠陵，不能据此补甘氏柩到具体日期。

<a id="sgz034-b-1735-1"></a>

**[《三国志·二主妃子传》仓内原文 L1735](../../sources/本地分卷/三国志/三国志-卷034.md#l1735)**

> 制曰可。

**释读** 刘禅批准诸葛亮等提出的追尊和合葬礼议。

**归年** 承223年奏议，批复无独立月日。

# 公元223年｜刘备去世，吴蜀重新走向合作

[← 公元222年](ce-0222.md) · [本世纪目录](README.md) · [公元224年 →](ce-0224.md)

**魏文帝黄初四年；蜀汉章武三年、建兴元年（五月改元）；吴黄武二年。**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="正文"></a>

<a id="event-1"></a>

1. **魏军围攻江陵、濡须，最后还是撤了回去。** 春季（魏黄初四年），上一年开始的攻吴战争仍在继续。朱桓守濡须，击退曹仁部队；朱然守江陵，在疾病、缺粮和城内有人谋应魏军的压力下坚持不降。魏军虽占据江中洲渚，却面临水涨后退路受威胁的危险。曹丕接受董昭的警告，催令撤出；又逢疫病，魏军各路陆续收兵，曹丕于三月回到洛阳。 [[1]](#note-1)

<a id="event-2"></a>

2. **刘备在永安托孤，四月去世。** 二月（蜀汉章武三年），诸葛亮来到永安探视刘备。病势转重后，刘备把辅佐刘禅的重任交给诸葛亮，以李严为副，并叮嘱儿子像对待父亲一样事奉丞相。四月，刘备在永安去世。他没能从夷陵败战中重新起身，蜀汉接下来面对的，是年轻继承人能否稳住朝局的问题。 [[2]](#note-2)

<a id="event-3"></a>

3. **刘禅即位，诸葛亮先把内政和粮食稳下来。** 五月（蜀汉建兴元年），刘禅即皇帝位，改元建兴。诸葛亮继续担任丞相，并领益州牧，朝廷政务集中到他这里。南中已有地方势力叛离，诸葛亮却没有立即大举出兵；国家刚经历败战和皇帝去世，他选择先安定内部、恢复耕作和积粮。南中的大规模征讨，要到225年才展开。 [[3]](#note-3)

<a id="event-4"></a>

4. **邓芝到吴，把相互猜疑谈成了共同抗魏。** 十月（蜀汉建兴元年），邓芝奉诸葛亮之命到孙权处。孙权担心刘禅年幼、蜀汉太弱，仍在考虑怎样处理与魏的关系。邓芝指出：吴蜀各有险阻，合作尚能互相支撑；一旦完全臣服于魏，就可能不断被要求入朝、送太子为质，不答应又会成为出兵的借口。孙权接受了这个判断，转向与蜀汉专力合作。夷陵之后的停战往来，至此向稳定的联盟迈进。 [[4]](#note-4)

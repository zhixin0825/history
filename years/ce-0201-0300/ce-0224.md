# 公元224年｜曹丕南下，司马懿留镇许昌

[← 公元223年](ce-0223.md) · [本世纪目录](README.md) · [公元225年 →](ce-0225.md)

**魏文帝黄初五年；蜀汉建兴二年；吴黄武三年。**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="正文"></a>

<a id="event-1"></a>

1. **魏廷恢复太学，重建经学教育。** 四月（魏黄初五年），曹丕设立太学、设置博士，依照汉朝制度安排《五经》的课试。长期战乱破坏的官学开始恢复；这一年魏廷既在整理内部制度，也没有放下向南用兵的打算。 [[1]](#note-1)

<a id="event-2"></a>

2. **吴蜀互派使者，让上一年的合作继续运转。** 本年（吴黄武三年），孙权派张温出使蜀汉，蜀汉也再次派邓芝到吴，两边使者往来不断。孙权在处理与刘禅、诸葛亮的重要书信时，还让陆逊参与斟酌。双方并没有忘记各自统一天下的目标，但眼下先要把共同面对曹魏的关系维持住。 [[2]](#note-2)

<a id="event-3"></a>

3. **曹丕坚持南征，把许昌交给司马懿。** 七月（魏黄初五年），曹丕来到许昌，准备再次大举攻吴。辛毗劝他先养民、屯田，等国家恢复实力再动手，曹丕没有接受，留下司马懿镇守许昌，自己继续南下。司马懿在本年的任职中改封向乡侯，受抚军、假节之任，领兵五千，又加给事中、录尚书事。面对司马懿的推辞，曹丕解释，这不是单纯给他荣誉，而是要他分担政务和军务。 [[3]](#note-3)

<a id="event-4"></a>

4. **到了广陵，魏军仍没能把优势变成渡江的胜利。** 八月（魏黄初五年），曹丕乘龙舟率水军经蔡水、颍水入淮，经过寿春；九月到达广陵。吴将徐盛在江边设置假城楼等设施虚张声势，又陈列船舰。江水上涨，曹丕的船还遇上大风，魏军始终没有实现预期的渡江进攻。十月，曹丕退回许昌；南征没有换来决定性的战果。 [[4]](#note-4)

<a id="sg-event-5"></a>

5. **初令谋反大逆乃得相告。** 五年春正月，初令谋反大逆乃得相告，其余皆勿听治；敢妄相告，以其罪罪之。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **行自许昌还洛阳宫。** 三月，行自许昌还洛阳宫。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **有司以公卿朝朔望日，因奏疑事。** 五月，主管官员以公卿朝朔望日，因奏疑事，听断大政，论辨得失。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **行东巡，幸许昌宫。** 秋七月，行东巡，幸许昌宫。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **爲水军，亲御龙舟。** 八月，爲水军，亲御龙舟，循蔡、頴，浮淮，幸寿春。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **扬州界将吏士民，犯五岁刑已下。** 扬州界将吏士民，犯五岁刑已下，皆原除之。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **太白昼见。** 冬十月乙卯，太白昼见。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **行还许昌宫。** [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **以冀州饥，遣使者开仓廪振之。** 十一月庚寅，以冀州饥，派使者开仓廪振之。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **日有食之。** 戊申晦，日有食之。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **诏曰“先王制礼”。** 十二月，诏曰：「先王制礼，所以昭孝事祖，大则郊社，其次宗庙，三辰五行，名山大川，非此族也，不在祀典。叔世衰乱，崇信巫史，至乃宫殿之内，户牖之间，无不沃酹，甚矣其惑也。自今，其敢设非祀之祭，巫祝之言，皆以执左道论，着于令典。」 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **是岁穿天渊池。** 当年穿天渊池。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **蜀汉休养农力。** 蜀汉劝农产粮，闭关让百姓休养。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **诸葛亮征辟杜微。** 诸葛亮兼领益州牧后，延揽秦宓、五梁、杜微。杜微耳聋，本来谢绝，诸葛亮用车迎来，在座中写信与他交谈。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **吴遣张温聘蜀。** 黄武三年夏孙权遣张温聘蜀，加深吴蜀往来。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **朱治去世。** 朱治于本年去世。 [[20]](#sg-note-20)

<a id="sy-event-21"></a>

21. **鲜卑步度根赴魏朝献。** 步度根入朝贡奉，魏廷厚赐。 [[21]](#sy-note-21)

<a id="sgz-event-22"></a>

22. **曹丕诏议从轻用刑。** 曹丕认为民少事多、法条苛密，援“苛政猛于虎”的旧例，令广议轻刑。 [[22]](#sgz-note-22)

<a id="sgz-event-23"></a>

23. **陈表在暨艳获罪时仍相厚。** 暨艳得罪，其他人力求自免，陈表未改变交谊，由此受士人敬重。 [[23]](#sgz-note-23)

<a id="sgz-event-24"></a>

24. **夏侯尚徙昌陵乡侯。** 黄初五年改封昌陵乡侯。 [[24]](#sgz-note-24)

<a id="sg002-l158-e4"></a>

[史料说明](#history-legacy-source-4)

<a id="sgz005-b-319-1"></a>

**[《三国志·后妃传》仓内原文 L319](../../sources/本地分卷/三国志/三国志-卷005.md#l319)**

> 五年，帝東征，後留許昌永始台。時霖雨百餘日，城樓多壞，有司奏請移止。後曰：「昔楚昭王出遊，貞姜留漸台，江水至，使者迎而無符，不去，卒沒。今帝在遠，吾幸未有是患，而便移止，奈何？」群臣莫敢復言。

**释读** 曹丕东征时郭后留许昌，久雨使楼门损坏，郭后以楚昭王夫人故事辞迁。

**归年** 本传上承黄初，明称五年；楚昭王夫人为郭后举例。

<a id="sgz055-b-2659-1"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2659](../../sources/本地分卷/三国志/三国志-卷055.md#l2659)**

> ﻿後魏文帝大出，有渡江之志，盛建計從建業築圍，作薄落，圍上設假樓，江中浮船。諸將以爲無益，盛不聽，固立之。文帝到廣陵，望圍愕然，彌漫數百里，而江水盛長，便引軍退。諸將乃伏。。　《魏氏春秋》云：文帝歎曰：「魏雖有武騎千羣，無所用也。」〉

**释读** 徐盛沿江设长围假楼和浮船，魏文帝至广陵时江水上涨，又见守备，退军；本段TXT末还混入《魏氏春秋》一语。

**归年** 《吴主传》《通鉴》卷070明黄武三年（224）九月，时江水盛长；225年再到广陵时逢大寒，区别两次。四库本将魏氏语明作注。

<a id="sgz055-p-020-1"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》裴注 020·1](../../sources/摘录/三国志-卷055-程黄韩蒋周陈董甘凌徐潘丁传裴注.md#pei-020-1)**

> 干寳晋紀所云疑城已注孫權傳魏氏春秋云文帝歎曰魏雖有武騎千羣無所用也

**释读** 裴注指疑城旧见《吴主传》注，另录魏文帝叹骑兵无用。

**归年** 据《吴主传》《通鉴》黄武三年九月，和225寒冻退军分开。TXT L2659已混录后一条，史料均归同一条。

## 归年与考证

<a id="history-legacy-source-1"></a>

**[1] 《资治通鉴》卷070，黄初五年四月条。**

> 夏，四月，初立太學；置博士，依漢制設《五經》課試之法。

[原文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-262dd9ba104f05)。说明：“初立”在这里说曹魏恢复建立太学，不能写成中国历史上第一次出现太学。

<a id="history-legacy-source-2"></a>

**[2] 《资治通鉴》卷070，黄初五年吴蜀往来条。**

> 吳王使輔義中郎將吳郡張溫聘於漢，自是吳、漢信使不絕。

[原文及陆逊参与书信、邓芝再使吴](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-265f76e61e5809)。说明：本条未另给张温出使的确月，不以它排列在四月太学条之后，就直接认定也是四月。

<a id="history-legacy-source-3"></a>

**[3] 《资治通鉴》卷070黄初五年七月条，与《晋书》卷001黄初五年段合读。**

> 帝不從，留尚書僕射司馬懿鎮許昌。

《晋书》补充：

> 帝留鎮許昌，改封向鄉侯，轉撫軍、假節，領兵五千，加給事中、錄尚書事。

[《通鉴》南征与留守](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-1386ba89d8b49c) · [《晋书》原文摘录HC02及曹丕解释](../../sources/摘录/晋书/卷001-黄初.md#hc02)。

**说明：** 《晋书》把“转抚军”等系于黄初五年；《通鉴》本年仍称尚书仆射，至[225年二月](ce-0225.md#note-1)才明记“司马懿为抚军大将军”。本页保留《晋书》的本年任职记载和用语，不擅自把完整“大将军”任命提前；也不把同一留守职责重复叙成两次互不相干的事件。留镇许昌有七月的编年依据，不等于爵位、加官各项都有七月确日。这属于尚需继续核对的职称与系年差别，不能声称已由学界一致解决。

<a id="history-legacy-source-4"></a>

**[4] 《资治通鉴》卷070，黄初五年八月至十月条。**

> 八月，為水軍，親御龍舟，循蔡、潁，浮淮如壽春。九月，至廣陵。

> 冬，十月，帝還許昌。

[原文及徐盛布置、江水与风浪](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-2bd91322176c10)。说明：此役因水势、吴方防备等未能推进，不把未见记载的渡江大战或歼敌数写入正文。下一年还将再次南征，不能把两次出兵合并。

# 公元224年｜曹丕南下，司马懿留镇许昌

[← 公元223年](ce-0223.md) · [本世纪目录](README.md) · [公元225年 →](ce-0225.md)

**魏文帝黄初五年；蜀汉建兴二年；吴黄武三年。**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="正文"></a>

<a id="event-1"></a>

1. **魏廷恢复太学，重建经学教育。** 四月（魏黄初五年），曹丕设立太学、设置博士，依照汉朝制度安排《五经》的课试。长期战乱破坏的官学开始恢复；这一年魏廷既在整理内部制度，也没有放下向南用兵的打算。 [[1]](#note-1)

<a id="event-2"></a>

2. **吴蜀互派使者，让上一年的合作继续运转。** 本年（吴黄武三年），孙权派张温出使蜀汉，蜀汉也再次派邓芝到吴，两边使者往来不断。孙权在处理与刘禅、诸葛亮的重要书信时，还让陆逊参与斟酌。双方并没有忘记各自统一天下的目标，但眼下先要把共同面对曹魏的关系维持住。 [[2]](#note-2)

<a id="event-3"></a>

3. **曹丕坚持南征，把许昌交给司马懿。** 七月（魏黄初五年），曹丕来到许昌，准备再次大举攻吴。辛毗劝他先养民、屯田，等国家恢复实力再动手，曹丕没有接受，留下司马懿镇守许昌，自己继续南下。司马懿在本年的任职中改封向乡侯，受抚军、假节之任，领兵五千，又加给事中、录尚书事。面对司马懿的推辞，曹丕解释，这不是单纯给他荣誉，而是要他分担政务和军务。 [[3]](#note-3)

<a id="event-4"></a>

4. **到了广陵，魏军仍没能把优势变成渡江的胜利。** 八月（魏黄初五年），曹丕乘龙舟率水军经蔡水、颍水入淮，经过寿春；九月到达广陵。吴将徐盛在江边设置假城楼等设施虚张声势，又陈列船舰。江水上涨，曹丕的船还遇上大风，魏军始终没有实现预期的渡江进攻。十月，曹丕退回许昌；南征没有换来决定性的战果。 [[4]](#note-4)

<a id="sg-event-5"></a>

5. **初令谋反大逆乃得相告。** 五年春正月，初令谋反大逆乃得相告，其余皆勿听治；敢妄相告，以其罪罪之。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **行自许昌还洛阳宫。** 三月，行自许昌还洛阳宫。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **有司以公卿朝朔望日，因奏疑事。** 五月，主管官员以公卿朝朔望日，因奏疑事，听断大政，论辨得失。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **行东巡，幸许昌宫。** 秋七月，行东巡，幸许昌宫。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **爲水军，亲御龙舟。** 八月，爲水军，亲御龙舟，循蔡、頴，浮淮，幸寿春。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **扬州界将吏士民，犯五岁刑已下。** 扬州界将吏士民，犯五岁刑已下，皆原除之。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **太白昼见。** 冬十月乙卯，太白昼见。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **行还许昌宫。** [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **以冀州饥，遣使者开仓廪振之。** 十一月庚寅，以冀州饥，派使者开仓廪振之。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **日有食之。** 戊申晦，日有食之。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **诏曰“先王制礼”。** 十二月，诏曰：「先王制礼，所以昭孝事祖，大则郊社，其次宗庙，三辰五行，名山大川，非此族也，不在祀典。叔世衰乱，崇信巫史，至乃宫殿之内，户牖之间，无不沃酹，甚矣其惑也。自今，其敢设非祀之祭，巫祝之言，皆以执左道论，着于令典。」 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **是岁穿天渊池。** 当年穿天渊池。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **蜀汉休养农力。** 蜀汉劝农产粮，闭关让百姓休养。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **诸葛亮征辟杜微。** 诸葛亮兼领益州牧后，延揽秦宓、五梁、杜微。杜微耳聋，本来谢绝，诸葛亮用车迎来，在座中写信与他交谈。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **吴遣张温聘蜀。** 黄武三年夏孙权遣张温聘蜀，加深吴蜀往来。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **朱治去世。** 朱治于本年去世。 [[20]](#sg-note-20)

<a id="sy-event-21"></a>

21. **鲜卑步度根赴魏朝献。** 步度根入朝贡奉，魏廷厚赐。 [[21]](#sy-note-21)

<a id="sgz-event-22"></a>

22. **曹丕诏议从轻用刑。** 曹丕认为民少事多、法条苛密，援“苛政猛于虎”的旧例，令广议轻刑。 [[22]](#sgz-note-22)

<a id="sgz-event-23"></a>

23. **陈表在暨艳获罪时仍相厚。** 暨艳得罪，其他人力求自免，陈表未改变交谊，由此受士人敬重。 [[23]](#sgz-note-23)

<a id="sgz-event-24"></a>

24. **夏侯尚徙昌陵乡侯。** 黄初五年改封昌陵乡侯。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **诸葛亮辟秦宓为别驾。** 秦宓被选作益州别驾，随后任左中郎将、长水校尉。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **追进曹昂为丰悼王。** 曹魏追加曹昂王号。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **曹丕改封诸王为县王。** 诏以历代置郡增减为由，改封诸王为县王，曹据由此改封定陶县。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **曹敏改封范阳王。** 曹敏移封范阳。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **满宠拜前将军。** 曹魏任满宠为前将军。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **田豫援素利，抗击轲比能。** 素利违约给魏马匹，遭轲比能袭击，田豫为避免其兼并出兵。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **郭淮正式任雍州刺史。** 由领事升为实授。 [[31]](#sgz-note-31)

<a id="sgz-event-32"></a>

32. **董昭转封成都乡侯、拜太常。** 朝廷转封董昭为成都乡侯、拜太常。 [[32]](#sgz-note-32)

<a id="sgz-event-33"></a>

33. **董昭改为光禄大夫给事中。** 同年董昭转光禄大夫、给事中。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **张温奉命赴豫章整兵。** 孙权使张温进入豫章编伍出兵，所办未竟。 [[34]](#sgz-note-34)

<a id="sgz-event-35"></a>

35. **孙权因暨艳案罢张温。** 孙权暗厌张温称赞蜀政，嫌其名声太盛，担忧不能尽为己用，借暨艳案治张温。 [[35]](#sgz-note-35)

<a id="sgz-event-36"></a>

36. **骆统为张温申辩。** 骆统上表为张温说明情由。 [[36]](#sgz-note-36)

> 蜀復令芝重往，權謂芝曰：「若天下太平，二主分治，不亦樂乎！」芝對曰：「夫天無二日，土無二王，如並魏之後，大王未深識天命者也，君各茂其德，臣各盡其忠，將提枹鼓，則戰爭方始耳。」權大笑曰：「君之誠款，乃當爾邪！」權與亮書曰：「丁厷掞張，陰化不盡；和合二國，唯有鄧芝。」

**释读** 蜀再使邓芝。孙权提出天下太平后两主分治；邓芝说并魏之后各事其君，争天下方始。孙权笑而称其诚意，致信诸葛亮赞邓芝最能和合两国。

**归年** 《资治通鉴》卷070将张温报聘、邓芝重往连载于黄武三年；孙权书未独载年。

<a id="sgz005-b-319-1"></a>

**[《三国志·后妃传》仓内原文 L319](../../sources/本地分卷/三国志/三国志-卷005.md#l319)**

> 五年，帝東征，後留許昌永始台。時霖雨百餘日，城樓多壞，有司奏請移止。後曰：「昔楚昭王出遊，貞姜留漸台，江水至，使者迎而無符，不去，卒沒。今帝在遠，吾幸未有是患，而便移止，奈何？」群臣莫敢復言。

**释读** 曹丕东征时郭后留许昌，久雨使楼门损坏，郭后以楚昭王夫人故事辞迁。

**归年** 本传上承黄初，明称五年；楚昭王夫人为郭后举例。

<a id="sgz055-b-2659-1"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2659](../../sources/本地分卷/三国志/三国志-卷055.md#l2659)**

> ﻿後魏文帝大出，有渡江之志，盛建計從建業築圍，作薄落，圍上設假樓，江中浮船。諸將以爲無益，盛不聽，固立之。文帝到廣陵，望圍愕然，彌漫數百里，而江水盛長，便引軍退。諸將乃伏。。　《魏氏春秋》云：文帝歎曰：「魏雖有武騎千羣，無所用也。」〉

**释读** 徐盛沿江设长围假楼和浮船，魏文帝至广陵时江水上涨，又见守备，退军；本段TXT末还混入《魏氏春秋》一语。

**归年** 《吴主传》《通鉴》卷070明黄武三年（224）九月，时江水盛长；225年再到广陵时逢大寒，区别两次。四库本将魏氏语明作注。

> 干寳晋紀所云疑城已注孫權傳魏氏春秋云文帝歎曰魏雖有武騎千羣無所用也

**释读** 裴注指疑城旧见《吴主传》注，另录魏文帝叹骑兵无用。

**归年** 据《吴主传》《通鉴》黄武三年九月，和225寒冻退军分开。TXT L2659已混录后一条，史料均归同一条。

> 伏惟殿下，天生明德，神啟聖心，招髦秀於四方，署俊乂於宮朝。多士既受普篤之恩，張溫又蒙最隆之施。而溫自招罪譴，孤負榮遇，念其如此，誠可悲疚。然臣周旋之間，為國觀聽，深知其狀，故密陳其理。

<a id="sgz057-b-2736-2"></a>

**[《三国志·虞陆张骆陆吾朱传》仓内原文 L2736](../../sources/本地分卷/三国志/三国志-卷057.md#l2736)**

> 溫實心無他情，事無逆跡，但年紀尚少，鎮重尚淺，而戴赫烈之寵，體卓偉之才，亢臧否之譚，效褒貶之議。於是務勢者妒者寵，爭名者嫉其才，玄默者非其譚，瑕釁者諱其議，此臣下所當詳辨，明朝所當究察也，

**释读** 骆统说张温心无异志，但年轻、持重不足，因才华与议论招来同僚妒恨，朝廷应细加察辨。

**归年** 同一奏议。

<a id="sgz057-b-2736-3"></a>

**[《三国志·虞陆张骆陆吾朱传》仓内原文 L2736](../../sources/本地分卷/三国志/三国志-卷057.md#l2736)**

> 昔賈誼，至忠之臣也，漢文，大明之君也，然而絳、灌一言，賈誼遠退。何者？疾之者深，譖之者巧也。然而誤聞於天下，失彰於後世，故孔子曰：『為君難，為臣不易』也。溫雖智非從橫，武非虓武，然其弘雅之素，英秀之德，文章之采，論議之辯，卓躒冠群，煒曄曜世，世人未有及之者也。故論溫才即可惜，言罪則可恕。若忍威烈以赦盛德，有賢才以敦大業，固明朝之休光，四方之麗觀也。

**释读** 骆统以贾谊被谗外放作比，认为张温文章议论难及、罪可宽宥，惜贤有利吴国。

**归年** 同一奏议；贾谊是借说。

<a id="sgz057-b-2736-4"></a>

**[《三国志·虞陆张骆陆吾朱传》仓内原文 L2736](../../sources/本地分卷/三国志/三国志-卷057.md#l2736)**

> 國家之於暨艷，不內之忌族，猶等之平民，是故先見用於朱治，次見舉於眾人，中見任於明朝，亦見交於溫也。君臣之義，義之最重，朋友之交，交之最輕者也。國家不嫌於艷為最重之義，是以溫亦不嫌與艷為最輕之交也。時世寵之於上，溫竊親之於下也。

**释读** 骆统说暨艳先获朱治等荐，再为孙权所用，张温与他结友不足获罪。

**归年** 同一奏议，对应党暨艳之责。

<a id="sgz057-b-2736-5"></a>

**[《三国志·虞陆张骆陆吾朱传》仓内原文 L2736](../../sources/本地分卷/三国志/三国志-卷057.md#l2736)**

> 夫宿惡之民，放逸山險，則為勁寇，將置平土，則為健兵，故溫念在欲取宿惡，以除勁寇之害，而增健兵之銳也。但自錯落，功不副言。然計其送兵，以比許晏，數之多少，溫不減之。用之強羸，溫不下之。至於遲速，溫不後之，故得及秋冬之月，赴有警之期，不敢忘恩而遺力也。

**释读** 骆统说张温整编豫章人众旨在减威胁、增兵员，任务虽未达最初承诺，所得强弱、多少与送到时间并不逊于许晏。

**归年** 同一奏议，对应豫章的责备。

<a id="sgz057-b-2736-6"></a>

**[《三国志·虞陆张骆陆吾朱传》仓内原文 L2736](../../sources/本地分卷/三国志/三国志-卷057.md#l2736)**

> 溫之到蜀，共譽殷禮，雖臣無境外之交，亦有可原也。境外之交，謂無君命而私相從，非國事而陰相聞者也。若以命行，既修君好，因敘己情，亦使臣之道也。故孔子使鄰國，則有私覿之禮。季子聘諸夏，亦有燕譚之義也。古人有言，欲知其君，觀其所使，見其下之明明，知其上之赫赫。溫若譽禮，能使彼歎之，誠所以昭我臣之多良，明使之得其人，顯國美於異境，揚君命於他邦。是以晉趙文子之盟於宋也，稱隨今於屈建。楚王孫圉之使於晉也，譽左史於趙鞅。亦向他國之輔，而歎本邦之臣，經傳美之以光國，而不譏之以外交也。

**释读** 骆统说张温称赞使副殷礼是奉国家使命对外展示人才，和无君命的私交有别，举孔子、季札和晋楚使事为证。

**归年** 同一奏议，对应出使责备。

<a id="sgz057-b-2736-7"></a>

**[《三国志·虞陆张骆陆吾朱传》仓内原文 L2736](../../sources/本地分卷/三国志/三国志-卷057.md#l2736)**

> 王靖內不憂時，外不趨事，溫彈之不私，推之不假，於是與靖遂為大怨，此其盡節之明驗也。靖兵眾之勢，干任之用，皆勝於賈原、蔣康，溫尚不容私以安於靖，豈敢賣恩以協原、康邪？又原在職不勤，當事不堪，溫數對以丑色，彈以急聲。若其誠欲賣恩作亂，則亦不必貪原也。

**释读** 骆统称张温据公弹劾王靖、贾原，与他们有怨，证明并非拉拢贾、蒋邀势。

**归年** 同一奏议，对应滥许官职的指责。

<a id="sgz057-b-2736-8"></a>

**[《三国志·虞陆张骆陆吾朱传》仓内原文 L2736](../../sources/本地分卷/三国志/三国志-卷057.md#l2736)**

> 凡此數者，校之於事既不合，參之於眾亦不驗。臣竊念人君雖有聖哲之姿，非常之智，然以一人之身御兆民之眾，從層宮之內，瞰四國之外，昭群下之情，求萬機之理，猶未易周也，固當聽察群下之言，以廣聰明之烈。今者人非溫既殷勤，臣是溫又契闊，辭則俱巧，意則俱至，各自言欲為國，誰其言欲為私，倉卒之間，猶難即別。然以殿下之聰睿，察講論之曲直。若潛神留思，纖粗研核，情何嫌而不宣，事何昧而不昭哉?溫非親臣，臣非愛溫者也，昔之君子，皆抑私忿，以增君明。彼獨行之於前，臣恥廢之於後，故遂發宿懷於今日。納愚言於聖聽，實盡心於明朝，非有念於溫身也。

**释读** 骆统说就事和舆情都不能证实指控，人君不能独知万端，应多听下情、明察众说，他自己出于忠心陈言。

**归年** 同一奏议的总结。

**释读** 孙权最终不采纳骆统辩说。

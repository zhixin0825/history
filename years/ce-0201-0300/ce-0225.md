# 公元225年｜诸葛亮平定南中，曹丕再次征吴

[← 公元224年](ce-0224.md) · [本世纪目录](README.md) · [公元226年 →](ce-0226.md)

**魏文帝黄初六年；蜀汉建兴三年；吴黄武四年。**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="正文"></a>

<a id="event-1"></a>

1. **司马懿留在后方，曹丕让他负责的不只是守城。** 二月（魏黄初六年），陈群任镇军大将军，随曹丕出行并处理行在尚书事务；司马懿任抚军大将军，留在许昌，负责后方文书政务。曹丕再次准备以水军攻吴时，又让司马懿安定内部、供应前线军资。曹丕把这种分工比作萧何守后方的重要性，希望自己出征时不用再担忧身后。 [[1]](#note-1)

<a id="event-2"></a>

2. **诸葛亮出兵南中，既要打赢，也要留下能维持的统治。** 春季（蜀汉建兴三年），诸葛亮率军南下，处理雍闿等地方势力叛离的问题。李恢、马忠分别从其他方向进军，随后与主力会合。作战推进后，诸葛亮收服了孟获等在当地有影响的人物，任用地方首领，并征集军需物资。他不打算只靠外来军队长期驻扎、不断转运粮食维持秩序，而是试图让当地可以自行安定下来，减轻蜀汉后方的负担。 [[2]](#note-2)

<a id="event-3"></a>

3. **顾雍出任吴相。** 六月（吴黄武四年），孙权在孙邵去世后，任命顾雍为丞相、平尚书事。顾雍办事谨慎，选用官员重视各人的能力；对江边将领为争功而提出的小规模袭扰，也主张不能只图眼前一点战果。这种态度与吴正在应对魏军压力的处境有关：保住整体局面，比让各将领各自求胜更要紧。 [[3]](#note-3)

<a id="event-4"></a>

4. **魏军再到广陵，严寒和水道又使南征受阻。** 八月（魏黄初六年），曹丕率水军从谯地沿涡水进入淮河，没有采纳蒋济关于水道难通的警告。十月，魏军到达广陵故城，吴方严加防守；严寒结冰又使船只难以入江，曹丕只得撤回。回程中大批战船滞留，蒋济组织开渠、蓄水，把船队重新引入淮河。这次出兵仍未打开局面，曹丕回到洛阳已经是下一年正月。 [[4]](#note-4)

<a id="hh-event-5"></a>

5. **杨彪卒于家。** 杨彪以八十四岁卒，传概述其家四世任太尉。 [[5]](#hh-note-5)

<a id="sg-event-6"></a>

6. **遣使者循行许昌以东尽沛郡。** 六年春二月，派使者循行许昌以东尽沛郡，问民所疾苦，贫者振贷之。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **行幸召陵，通讨虏渠。** 三月，行幸召陵，通讨虏渠。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

<a id="sg-event-9"></a>

9. **并州刺史梁习讨鲜卑轲比能。** 并州刺史梁习讨鲜卑轲比能，大破之。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **帝爲舟师东征。** 辛未，帝爲舟师东征。 [[10]](#sg-note-10)

11. **幸谯。** 五月戊申，幸谯。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **荧惑入太微。** 壬戌，荧惑入太微。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **利成郡兵蔡方等以郡反。** 六月，利成郡兵蔡方等以郡反，杀太守徐质。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **遣屯骑校尉任福、步兵校尉段昭与青州刺史讨平之。** 遣屯骑校尉任福、步兵校尉段昭与青州刺史讨平之；其见胁略及亡命者，皆赦其罪。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **立皇子鉴爲东武阳王。** 秋七月，立皇子鉴爲东武阳王。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **筑东巡台。** 九月，筑东巡台。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **是岁大寒，水道冰。** 当年大寒，水道冰，舟不得入江，乃引还。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **东武阳王鉴薨。** 十一月，东武阳王鉴去世。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **行自谯过梁，遣使以太牢祀故汉太尉桥玄。** 十二月，行自谯过梁，派使以太牢祀故汉太尉桥玄。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **诸葛亮经李鸿问孟达。** 诸葛亮南征回至汉阳，向降人李鸿了解孟达，费诗反对联络。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **程秉为太子孙登迎娶周瑜之女。** 太子太傅程秉兼摄太常，奉命赴吴迎接周瑜女。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **入拜尚书，迁尚书令。** 建兴三年，入拜尚书，迁尚书令，奉命使吴。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **丞相亮以为参军，署府事。** 建兴三年，丞相亮以为参军，署府事，将南行。 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **为越巂太守，随丞相亮南征。** 建兴三年，为越巂太守，随丞相亮南征，为蛮夷所害，时年三十一。 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **迎母于吴。** 黄武四年，迎母于吴。 [[25]](#sg-note-25)

<a id="sg-event-26"></a>

26. **尚书仆射，卒。** 黄武四年尚书仆射，卒。 [[26]](#sg-note-26)

<a id="sy-event-27"></a>

27. **夏侯尚病重还洛阳。** 夏侯尚病重还都，曹丕多次探问，握其手哭泣。 [[27]](#sy-note-27)

<a id="sgz-event-28"></a>

28. **陈震入朝为尚书。** 陈震由地方官入为尚书。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **费祎首次使吴，孙权敬重。** 诸葛亮除费祎昭信校尉，使吴。面对孙权及诸葛恪、羊誖等辩难，他据理应答，孙权叹他将为蜀廷股肱。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **孙权以常用宝刀赠费祎。** 孙权把自己常执的宝刀送给费祎。费祎说刀用来惩不服、禁暴乱，愿孙权建功，双方共扶汉室。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **诸葛亮南征，李邵留任治中并去世。** 诸葛亮南征，留李邵为治中从事；李邵当年去世。 [[31]](#sgz-note-31)

<a id="sgz-event-32"></a>

32. **王士随南征动员并遇害。** 诸葛亮南征时，改任王士益州太守，王士将南行，为当地反抗者所杀。 [[32]](#sgz-note-32)

> 會丞相亮南征，轉為益州太守，將南行，為蠻夷所害。

**归年** 《后主传》建兴三年诸葛亮南征，事因与同年行动直接相承。

<a id="appendix-start"></a>

## 归年与考证

<a id="history-legacy-source-1"></a>

**[1] 《资治通鉴》卷070黄初六年二月条，与《晋书》卷001黄初六年段合读。**

> 司馬懿為撫軍大將軍，留許昌，督後臺文書。

《晋书》补充：

> 復命帝居守，內鎮百姓，外供軍資。

> 曹參雖有戰功，而蕭何為重。使吾無西顧之憂，不亦可乎！

[《通鉴》二月任职与分工](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-9e31f4a29ba9b8) · [《晋书》原文摘录HC03](../../sources/摘录/晋书/卷001-黄初.md#hc03)。说明：本年“大将军”的明载月份采用编年底本；《晋书》上一年“转抚军”的差别保留在[224年同号说明](ce-0224.md#note-3)。不把后方留守写成司马懿亲率曹丕水军作战。

<a id="history-legacy-source-2"></a>

**[2] 《资治通鉴》卷070，黄初六年诸葛亮南征始末。**

> 漢諸葛亮率眾討雍闓等。

> 益州、永昌、牂柯、越巂四郡皆平，亮即其渠率而用之。

> 今吾欲使不留兵，不運糧，而綱紀粗定，夷、漢粗安故耳。

[原文、分路进军及战后安排](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-0fe7f9a87e1099)。说明：这里合叙同一次战役的出发、推进和收束，不表示全部行动都发生于春季同月。《通鉴》另记孟获“七纵七擒”，原文链接保留；本页没有足够逐场材料，不把它扩写成七次有地点、日期、战术细节的战斗。也不把暂时平定改写为此后南中永远没有反抗。

<a id="history-legacy-source-3"></a>

**[3] 《资治通鉴》卷070，黄初六年吴丞相更替条。**

> 六月，以太常顧雍為丞相、平尚書事。

> 其所選用文武將吏，各隨能所任，心無適莫。

[原文及顾雍对边将求功的意见](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-dc35109b5672db)。说明：任相有六月纪年；史书随后叙述的处事风格和谏言，是任职经历的概述，不能逐件都锁定为本月发言。

<a id="history-legacy-source-4"></a>

**[4] 《资治通鉴》卷070，黄初六年八月至冬十月南征条，并接黄初七年正月。**

> 八月，帝以舟師自譙循渦入淮。尚書蔣濟表言水道難通，帝不從。

> 時大寒，冰，舟不得入江。

次年：

> 春，正月，壬子，帝還洛陽。

[出兵、退军及蒋济疏通水道](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-de3e409144d9e6) · [226年回洛阳](ce-0226.md#note-1)。说明：《晋书》黄初六年段连写“天子自广陵还洛阳”，是叙事收束跨到次年，不能因段首“六年”而把还京也定在225年。

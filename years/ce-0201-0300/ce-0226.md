# 公元226年｜曹丕去世，司马懿受顾命并出战襄阳

[← 公元225年](ce-0225.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元227年 →](ce-0227.md)

**魏黄初七年（五月曹叡即位，本年仍用黄初年号）；蜀汉建兴四年；吴黄武五年。**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="正文"></a>

<a id="event-1"></a>

1. **曹丕南征归来，司马懿继续承担留守事务。** 正月（魏黄初七年），曹丕从上一年的南征回到洛阳。他肯定蒋济保全船队的工作，又继续让司马懿镇守许昌，明确自己在东时由司马懿总理西面的事务，自己在西时则由司马懿处理东面的事务。司马懿负责接续皇帝出行时的后方政务和军务，不只是留一支兵守城。 [[1]](#note-1)

<a id="event-2"></a>



<a id="event-3"></a>

3. **孙权趁魏国大丧攻江夏，文聘守住了城。** 八月（魏黄初七年），孙权亲自率军进攻江夏。太守文聘坚守，曹叡判断吴军已经失去突然袭击的机会，难以久围。正在边地慰劳的荀禹调集沿途县兵和随行兵马，依山举火，形成援兵声势，孙权随后退去。 [[3]](#note-3)

<a id="event-4"></a>

4. **另一支吴军攻襄阳，司马懿率军击退诸葛瑾。** 同年，吴将诸葛瑾等进攻襄阳，司马懿督军迎击，斩杀吴将张霸。魏军也在寻阳击败吴军别部，《三国志·明帝纪》记领兵者为曹休，《资治通鉴》记为曹真。 [[4]](#note-4)

<a id="event-5"></a>



<a id="sg-event-6"></a>

6. **曹丕托孤与去世。** 七年春正月，将幸许昌，许昌城南门无故自崩，帝心恶之，遂不入。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **行还洛阳宫。** 壬子，行还洛阳宫。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **筑九华台。** 三月，筑九华台。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **遣后宫淑媛、昭仪已下归其家。** [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **葬首阳陵。** 六月戊寅，葬首阳陵。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **自殡及葬，皆以终制从事。** [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **编年更正。** 幼年受曹操喜爱，见[曹叡早年时期条](时期-三国志魏纪后妃及汉末群雄.md#period-sgz003-b-167-2)。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **编年更正。** 曹叡封武德侯见延康元年。 [220年第18条](ce-0220.md#sg-note-18)。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **编年更正。** 甄氏赐死见黄初二年。 [221年第21条](ce-0221.md#sg-note-21)。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **帝病笃，乃立爲皇太子。** 七年夏五月，帝病笃，乃立爲皇太子。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **即皇帝位，大赦。** 丁巳，即皇帝位，大赦。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **尊皇太后曰太皇太后，皇后曰皇太后。** [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **诸臣封爵各有差。** [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **追谥母甄夫人曰文昭皇后。** 癸未，追谥母甄夫人曰文昭皇后。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **立皇弟蕤爲阳平王。** 壬辰，立皇弟蕤爲阳平王。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>



<a id="sg-event-22"></a>

22. **立皇子冏爲清河王。** 辛巳，立皇子冏爲清河王。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **论功行赏各有差。** [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **清河王冏薨。** 冬十月，清河王冏去世。 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **以太尉锺繇爲太傅，征东大将军曹休爲大司马。** 十二月，以太尉锺繇爲太傅，征东大将军曹休爲大司马，中军大将军曹真爲大将军，司徒华歆爲太尉，司空王朗爲司徒，镇军大将军陈群爲司空，抚军大将军司马宣王爲骠骑大将军。 [[25]](#sg-note-25)

<a id="sg-event-26"></a>

26. **李严移驻江州。** 李严由永安移屯江州，并筑城。 [[26]](#sg-note-26)

<a id="sg-event-27"></a>

27. **秦宓去世。** 秦宓迁大司农，建兴四年卒。 [[27]](#sg-note-27)

<a id="sg-event-28"></a>

28. **士燮去世。** 士燮担任交阯太守四十余年，在黄武五年去世，年九十。 [[28]](#sg-note-28)

<a id="sg-event-29"></a>

29. **士徽拒命，吕岱率军进交阯。** 士燮死后，吴令戴良、陈时接管交州、交阯。士徽拒命，吕岱率兵三千昼夜浮海南下。 [[29]](#sg-note-29)

<a id="sg-event-30"></a>

30. **迁太常，进封南乡亭侯。** 黄初七年，迁太常，进封南乡亭侯，邑二百户。 [[30]](#sg-note-30)

<a id="sy-event-31"></a>

31. **卞秉进封开阳侯。** 曹丕时期，卞秉进封开阳侯，食邑一千二百户，任昭烈将军。 [[31]](#sy-note-31)

<a id="sy-event-32"></a>

32. **吴范病卒。** 吴范因病去世，其术无人继承。孙权以千户侯征求能推荐像吴范、赵达一样通晓术数的人，最终未获。 [[32]](#sy-note-32)

<a id="sgz-event-33"></a>

33. **许昌南门倒塌，曹丕不入城。** 曹丕计划去许昌，城南门忽倒塌，他厌恶这个征兆，便没有入城。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **曹叡即位后任秦朗内官。** 曹叡即位后授秦朗驍骑将军、给事中，车驾出入常让他随行。 [[34]](#sgz-note-34)

<a id="sgz003-b-168-2"></a>

**[《三国志·明帝纪》仓内原文 L168](../../sources/本地分卷/三国志/三国志-卷003.md#l168)**

> 朝議欲發兵救之，帝曰：「權習水戰，所以敢下船陸攻者，幾掩不備也。今已與聘相持，夫攻守勢倍，終不敢久也。」

**释读** 朝议发兵救文聘，曹叡认为吴军擅水战，陆攻要靠突袭，既已与守军相持便不敢久留。

**归年** 接226年八月江夏围攻。同年第21条是第3条内的朝议细节宜归并；《资治通鉴》卷070 L410后可互校。

**释读** 此前魏廷派治书侍御史荀禹去边地慰劳。

**归年** 本纪“先時”相对当前江夏战事，派遣月日不详；按本纪及通鉴系黄初七年用兵背景，和举火分读。

**归年** 本纪于226年江夏之役。文聘传与孙权本纪另有守城细节。

**[《三国志·文帝纪》仓内原文 L163](../../sources/本地分卷/三国志/三国志-卷002.md#l163)**

> 夏五月丙辰，帝疾篤，召中軍大將軍曹真、鎮軍大將軍陳羣、征東大將軍曹休、撫軍大將軍司馬宣王，並受遺詔輔嗣主。

**释读** 曹丕病情危重，命曹真、陈群、曹休、司马懿共同辅佐继承者。

**释读** 曹丕在嘉福殿去世，虚岁四十。

**归年** 本纪黄初七年五月丁巳；生于187年冬与旧式虚岁相合。

## 归年与考证

<a id="history-legacy-source-1"></a>

**[1] 《资治通鉴》卷070黄初七年正月条，与《晋书》卷001黄初六年段的跨年收束合读。**

> 春，正月，壬子，帝還洛陽。

《晋书》：

> 天子自廣陵還洛陽，詔帝曰：「吾東，撫軍當總西事；吾西，撫軍當總東事。」於是帝留鎮許昌。

[《通鉴》还京月份与慰劳蒋济](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-de2d02c231f3d6) · [《晋书》原文摘录HC03](../../sources/摘录/晋书/卷001-黄初.md#hc03)。说明：南征在225年，还洛阳在226年。分工诏令由《晋书》与还京相连叙述，但没有独立确日；不将所有细节都写成正月壬子当天发生。

<a id="history-legacy-source-2"></a>

**[2] 《资治通鉴》卷070黄初七年五月条；《晋书》卷001顾命段。**

> 夏，五月，帝疾篤，乃立叡為太子。丙辰，召中軍大將軍曹真、鎮軍大將軍陳群、撫軍大將軍司馬懿，並受遺詔輔政。丁巳，帝殂。

《晋书》：

> 帝與曹真、陳羣等見於崇華殿之南堂，並受顧命輔政。

> 明帝即位，改封舞陽侯。

[《通鉴》顾命、文帝去世与明帝即位](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-9fcfddb81aae45) · [《晋书》原文摘录HC04及诏太子语](../../sources/摘录/晋书/卷001-黄初.md#hc04)。说明：《通鉴》列三人，《晋书》列三人后用“等”，诏语作「此三公」。《三国志·文帝纪》另列曹休，正文据该纪列四人。《三国志·明帝纪》记丁巳即位，本年余月仍为黄初七年，次年始用太和元年。[百科与文献复核](../../meta/记录/晋书-卷001-黄初段引文去向.md#百科与文献复核)

<a id="history-legacy-source-3"></a>

**[3] 《资治通鉴》卷070，黄初七年八月江夏条。**

> 吳王聞魏有大喪，秋，八月，自將攻江夏郡，太守文聘堅守。

> 禹到江夏，發所經縣兵及所從步騎千人乘山舉火，吳王遁走。

[原文及曹叡对局势的判断](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-1a544c5a8e6aba)。说明：《晋书》黄初段把孙权围江夏、诸葛瑾攻襄阳、司马懿督军连叙。本页依《通鉴》分写两处战场，避免吞掉文聘、荀禹的行动；这不是已证明司马懿绝未参与整轮防御，而是不把压缩叙述放大成独占全部战功。

<a id="history-legacy-source-4"></a>

**[4] 《资治通鉴》卷070，黄初七年襄阳条；《晋书》卷001交战段。**

> 吳左將軍諸葛瑾等寇襄陽，司馬懿擊破之，斬其部將張霸。曹真又破其別將於尋陽。

《晋书》：

> 進擊，敗瑾，斬霸，并首級千餘。

[《通鉴》原文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-028a207a4f1700) · [《晋书》原文摘录HC05](../../sources/摘录/晋书/卷001-黄初.md#hc05)。说明：三书同记司马懿击退诸葛瑾、斩张霸，《晋书》另记首级千余。襄阳交战在八月段，未另署日。寻阳一役《明帝纪》作曹休，《通鉴》作曹真，尚缺能够裁决此处人名的记载。

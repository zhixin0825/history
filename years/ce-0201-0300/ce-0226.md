# 公元226年｜曹丕去世，司马懿受顾命并出战襄阳

**魏黄初七年（五月曹叡即位，本年仍用黄初年号）；蜀汉建兴四年；吴黄武五年。**

## 本年概述

黄初七年，曹丕结束南征回洛阳，仍令司马懿留镇许昌。五月曹丕病重，立曹叡为太子，以曹真、陈群、曹休、司马懿辅政。曹叡即位后办理大丧、追尊母亲甄氏，并在年末重定公卿与辅政大臣的职任。

孙权闻曹丕去世后围江夏石阳，诸葛瑾又攻襄阳，二路均未得手。交阯士燮死后，孙权分置州郡，士徽率族兵拒命，吕岱南下平定交阯。蜀汉方面，李严从永安移驻江州。

11. **吴分别进攻江夏石阳、襄阳，魏军击退两路。** 孙权闻曹丕去世，在秋季亲率军围江夏石阳，韩综正服父丧，留守武昌。孙奂命鲜于丹领五千人先断淮道，自率吴硕、张梁等为前锋，降高城，得三将。太守文聘坚守；曹叡判断吴军既失突袭之机，不能久围。荀禹调沿途县兵及随行步骑千人登山举火，孙权退军。潘璋率部殿后，夜间撤兵时队伍混乱，魏军追至。朱然掉头迎敌，等前队船只走远后再撤。退军途中，孙权见孙奂队伍齐整，任他为扬威将军，封沙羡侯；吴硕、张梁也受封赏。吴将诸葛瑾、张霸又攻襄阳，司马懿击败吴军、斩张霸；魏军另在寻阳击破吴军。张郃另与司马懿追击吴将刘阿等于祁口。 [[11]](#ce0226-note-11)

### 2. 鲍勋被刘曜告发，曹丕不从廷议而诛之

<a id="sgz063-p-003-1"></a>

<a id="wu063-l24-1"></a>

**[《三國志·吳範劉惇趙達傳》裴注 003](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l24-1)** · [TXT L24](../../sources/本地分卷/三国志/三国志-卷063.txt#L24)

> 吳錄曰：範先知其死日，謂權曰：「陛下某日當喪軍師。」權曰：「吾無軍師，焉得喪之？」範曰：「陛下出軍臨敵，須臣言而後行，臣乃陛下之軍師也。」至其日果卒。　臣松之案，範死時，權未稱帝，此云陛下，非也。

**釋讀** 《吳錄》說吳範預知自己的死日，告訴孫權某日將失去軍師。孫權問自己沒有軍師，怎會失去。吳範答，孫權出兵臨敵，要聽過自己的意見才行動，可見自己就是他的軍師。《吳錄》稱吳範到那一天果然死去。裴松之按道，吳範死時孫權還未稱帝，此處稱「陛下」有誤。

**歸年** 引書逸事繫於同一226年吳範卒事，保留原文稱謂與裴松之辨誤，實際談話的時間與死日均無明文。卷047記孫權於229年黃龍元年始稱帝。

# 公元226年｜曹丕去世，司马懿受顾命并出战襄阳

**魏黄初七年（五月曹叡即位，本年仍用黄初年号）；蜀汉建兴四年；吴黄武五年。**

## 本年概述

黄初七年，曹丕结束南征回洛阳，仍令司马懿留镇许昌。五月曹丕病重，立曹叡为太子，以曹真、陈群、曹休、司马懿辅政。曹叡即位后办理大丧、追尊母亲甄氏，并在年末重定公卿与辅政大臣的职任。

孙权闻曹丕去世后围江夏石阳，诸葛瑾又攻襄阳，二路均未得手。交阯士燮死后，孙权分置州郡，士徽率族兵拒命，吕岱南下平定交阯。蜀汉方面，李严从永安移驻江州。

10. **陆逊、孙权议曹丕死后魏局。** 曹丕死后，陆逊认为魏用忠良、宽刑薄赋，百姓因而安定，恐较曹操时更难对付。孙权另咨诸葛瑾，认为新政是曹叡借此安定人心；以陈群、曹真等分掌权柄及张耳、陈余先亲后争为例，推断魏廷日后可能结党相攻。 [[10]](#ce0226-note-10)

11. **吴分别进攻江夏石阳、襄阳，魏军击退两路。** 孙权闻曹丕去世，秋季亲率军进围江夏石阳，韩综正服父丧，留守武昌。孙奂命鲜于丹领五千人先断淮道，自率吴硕、张梁等为前锋，降高城，得三将。太守文聘坚守；曹叡判断吴军既失突袭之机，不能久围。荀禹调沿途县兵及随行步骑千人登山举火。孙权围城二十余日未能攻克，随后退军，文聘出兵追击。潘璋率部殿后，夜间撤兵时队伍混乱，魏军追至。朱然掉头迎敌，等前队船只走远后再撤。退军途中，孙权见孙奂队伍齐整，任他为扬威将军，封沙羡侯；吴硕、张梁也受封赏。吴将诸葛瑾、张霸又攻襄阳，司马懿督军击败吴军、斩张霸，徐晃率军抵御诸葛瑾。魏军另在寻阳击破吴军，张郃与司马懿在祁口击退吴将刘阿部。魏随后分别论功行赏。 [[11]](#ce0226-note-11)

13. **吴令民休息、议广耕并设置东安郡。** 黄武五年春，孙权因久战妨碍农事，令各州郡宽息民力。陆逊请诸将因谷少增广农田，孙权批准，并说自己与儿子也亲自耕作。丹杨、吴、会稽三郡山民攻下属县，孙权析十个险远县设东安郡，以全琮为太守，治富春。全琮用赏罚招抚山民，数年间来附者上万。苍梧本年报见凤凰。 [[13]](#ce0226-note-13)

14. **陆逊奏请宽刑薄调，孙权令审改科条。** 冬十月，陆逊劝孙权缓刑轻赋，并让低位之臣屡陈有利政务。孙权答书说刑罚用来预防犯罪，也同意听取意见，审酌过重的条文；随即令有司抄送科条，由褚逢交陆逊、诸葛瑾检视增减。 [[14]](#ce0226-note-14)

15. **士燮卒，士徽拒命，吕岱平交阯。** 士燮为交阯太守四十余年，收容北来士人，年九十卒。孙权分置广州、交州，任戴良为交州刺史、吕岱为广州刺史，遣陈时代领交阯。士燮之子士徽自署太守、起兵拒命，笞杀谏者桓邻，引来其子弟攻城，数月后约和。薛综随吕岱渡海南下。吕岱率三千人沿海南进，经合浦与戴良会师，令士匡劝降。士徽兄弟六人肉袒出迎，次日吕岱宣诏处死。士徽属将甘醴、桓治等反攻，战败逃散。广州又并入交州。吕岱进讨九真，薛综也随军进至九真，战事结束后回都代理谒者仆射。孙盛后来批评吕岱违背劝降承诺。 [[15]](#ce0226-note-15)

> 帝從壽春還，屯陳留郡界。太守孫邕見，出過勛。時營壘未成，但立摽埒，邕邪行不從正道，軍營令史劉曜欲推之，勛以塹壘未成，解止不舉。大軍還洛陽，曜有罪，勛奏絀遣，而曜密表勛私解邕事。詔曰：「勛指鹿作馬，收付廷尉。」廷尉法議：「正刑五歲。」三官駮：「依律罰金二斤。」帝大怒曰：「勛無活分，而汝等敢縱之！收三官已下付刺姦，當令十鼠同穴。」太尉鍾繇、司徒華歆、鎮軍大將軍陳羣、侍中辛毗、尚書衞臻、守廷尉高柔等並表「勛父信有功於太祖」，求請勛罪。帝不許，遂誅勛。勛內行旣脩，廉而能施，死之日，家無餘財。

**[《三國志·諸夏侯曹傳》](../../拆分史书/三国志/卷009.md#edition-wei009-l90-2)** · [TXT L90](../../拆分史书/三国志/卷009.txt#L90) · [TXT L91（裴注）](../../拆分史书/三国志/卷009.txt#L91)

> 遂以舍客犯法，下獄當死。羣臣並救莫能得。卞太后謂郭后曰：「令曹洪今日死，吾明日勑帝廢后矣。」於是泣涕屢請，乃得免官削爵土。
>
> **〔裴注〕**
> 魏略曰：文帝收洪，時曹真在左右，請之曰：「今誅洪，洪必以真爲譖也。」帝曰：「我自治之，卿何豫也？」會卞太后責怒帝，言「梁、沛之間，非子廉無有今日」。詔乃釋之。猶尚沒入其財產。太后又以爲言，後乃還之。

**釋讀與歸年** 曹洪因舍客犯法下狱论死，群臣求援无效。卞太后以废后警告郭皇后，曹洪终免死，免官削爵。[《资治通鉴》卷70](../../史书/025-资治通鉴/KR2b0007_070.txt#L379-L384)明记郭后屡次哭请；[《晋书·天文志》](../../史书/005-晋书/晋书-CCDH.txt#L1908)在黄初七年正月记曹洪免为庶人。

**釋讀與歸年** 《魏略》说曹真当面请求宽宥，曹丕起初拒绝；卞太后提醒曹丕，曹氏起事时曾靠曹洪相助，曹洪才获释。被没收的家产后来因太后再次出面而归还，归还月日未载。

<a id="wei009-l91-4"></a>

**[《三國志·諸夏侯曹傳》裴注](../../拆分史书/三国志/卷009.md#edition-wei009-l91-4)** · [TXT L91](../../拆分史书/三国志/卷009.txt#L91)

> 及洪犯法，自分必死，旣得原，喜，上書謝曰：「臣少不由道，過在人倫，長竊非任，遂蒙含貸。性無檢度知足之分，而有犲狼無厭之質，老惛倍貪，觸突國網，罪迫三千，不在赦宥，當就辜誅，棄諸市朝，猶蒙天恩，骨肉更生。臣仰視天日，愧負靈神，俯惟愆闕，慙愧怖悸，不能雉經以自裁割，謹塗顏闕門，拜章陳情。」

**釋讀與歸年** 曹洪自料必死，获免后上表谢恩，自陈贪得与年老昏惑，称获赦后无以自报，入朝陈情。保留《魏略》所载完整谢表，随226年获罪、免死同条。

> 洪先帝功臣，時人多爲觖望。明帝即位，拜後將軍，更封樂城侯，邑千戶，位特進，

> 魏書載三公奏曰：「蓋孝敬之道，篤乎其親，乃四海所以承化，天地所以明察，是謂生則致其養，歿則光其靈，誦述以盡其美，宣揚以顯其名者也。今陛下以聖懿之德，紹承洪業，至孝烝烝，通於神明，遭離殷憂，每勞謙讓。先帝遷神山陵，大禮旣備，至於先后，未有顯謚。伏惟先后恭讓著於幽微，至行顯於不言，化流邦國，德侔二南，故能膺神靈嘉祥，爲大魏世妃。雖夙年登遐，萬載之後，永播融烈，后妃之功莫得而尚也。案謚法：『聖聞周達曰昭。德明有功曰昭。』昭者，光明之至，盛乆而不昧者也。宜上尊謚曰文昭皇后。」

> 鄄城侯植爲誄曰：「惟黃初七年五月七日，大行皇帝崩，嗚呼哀哉！于時天震地駭，崩山隕霜，陽精薄景，五緯錯行，百姓呼嗟，萬國悲悼，若喪考妣，恩過墓唐，擗踊郊野，仰想穹蒼，僉曰何辜，早世殞喪，嗚呼哀哉！悲夫大行，忽焉光滅，永棄萬國，雲往雨絕。承問荒忽，惛懵哽咽，袖鋒抽刃，歎自僵斃，追慕三良，甘心同穴。感惟南風，惟以鬱滯，終於偕沒，指景自誓。考諸先記，尋之哲言，生若浮寄，惟德可論，朝聞夕逝，孔志所存。皇雖一沒，天祿永延，何以述德？表之素旃。何以詠功？宣之管絃。乃作誄曰：皓皓太素，兩儀始分，中和產物，肈有人倫，爰曁三皇，寔秉道真，降逮五帝，繼以懿純，三代製作，踵武立勳。季嗣不維，網漏于秦，崩樂滅學，儒坑禮焚，二世而殲，漢氏乃因，弗求古訓，嬴政是遵，王綱帝典，闃爾無聞。末光幽昧，道究運遷，乾坤迴歷，簡聖授賢，乃眷大行，屬以黎元。龍飛啟祚，合契上玄，五行定紀，改號革年，明明赫赫，受命于天。仁風偃物，德以禮宣；祥惟聖質，嶷在幼妍。庻幾六典，學不過庭，潛心無罔，亢志青冥。才秀藻朗，如玉之瑩，聽察無嚮，瞻覩未形。其剛如金，其貞如瓊，如氷之絜，如砥之平。爵公無私，戮違無輕，心鏡萬機，攬照下情。思良股肱，嘉昔伊呂，搜揚側陋，舉湯代禹；拔才巖穴，取士蓬戶，唯德是縈，弗拘禰祖。宅土之表，道義是圖，弗營厥險，六合是虞。齊契共遵，下以純民，恢折規矩，克紹前人。科條品制，襃貶以因。乘殷之輅，行夏之辰。金根黃屋，翠葆龍鱗，紼冕崇麗，衡紞惟新，尊肅禮容，矚之若神。方牧妙舉，欽於恤民，虎將荷節，鎮彼四鄰；朱旗所勦，九壤被震，疇克不若？孰敢不臣？縣旌海表，萬里無塵。虜備凶徹，鳥殪江岷，權若涸魚，乾腊矯鱗，肅慎納貢，越裳效珍，條支絕域，侍子內賔。德儕先皇，功侔太古。上靈降瑞，黃初叔祜：河龍洛龜，淩波游下；平鈞應繩，神鸞翔舞；數莢階除，系風扇暑；皓獸素禽，飛走郊野；神鍾寶鼎，形自舊土；雲英甘露，瀸塗被宇；靈芝冒沼，朱華陰渚。回回凱風，祁祁甘雨，稼穡豐登，我稷我黍。家佩惠君，戶蒙慈父。圖致太和，洽德全義。將登介山，先皇作儷。鐫石紀勳，兼錄衆瑞，方隆封禪，歸功天地，賔禮百靈，勳命視規，望祭四嶽，燎封奉柴，肅于南郊，宗祀上帝。三牲旣供，夏禘秋甞，元侯佐祭，獻璧奉璋。鸞輿幽藹，龍旂太常，爰迄太廟，鍾鼓鍠鍠，頌德詠功，八佾鏘鏘。皇祖旣饗，烈考來享，神具醉止，降茲福祥。天地震蕩，大行康之；三辰暗昧，大行光之；皇紘絕維，大行綱之；神器莫統，大行當之；禮樂廢弛，大行張之；仁義陸沈，大行揚之；潛龍隱鳳，大行翔之；疏狄遐康，大行匡之。在位七載，元功仍舉，將永太和，絕迹三五，宜作物師，長爲神主，壽終金石，等筭東父，如何奄忽，摧身后土，俾我棾棾，靡瞻靡顧。嗟嗟皇穹，胡寧忍務？嗚呼哀哉！明監吉凶，體遠存亡，深垂典制，申之嗣皇。聖上虔奉，是順是將，乃剏玄宇，基爲首陽，擬迹穀林，追堯慕唐，合山同陵，不樹不疆，塗車芻靈，珠玉靡藏。百神警侍，來賔幽堂，耕禽田獸，望魂之翔。於是，俟大隧之致功兮，練元辰之淑禎，潛華體於梓宮兮，馮正殿以居靈。顧望嗣之號咷兮，存臨者之悲聲，悼晏駕之旣修兮，感容車之速征。浮飛魂於輕霄兮，就黃墟以滅形，背三光之昭晰兮，歸玄宅之冥冥。嗟一往之不反兮，痛閟闥之長扃。咨遠臣之眇眇兮，成凶諱以怛驚，心孤絕而靡告兮，紛流涕而交頸。思恩榮以橫奔兮，閡闕塞之嶢崢，顧衰絰以輕舉兮，迫關防之我嬰。欲高飛而遙憩兮，憚天網之遠經，遙投骨於山足兮，報恩養於下庭。慨拊心而自悼兮，懼施重而命輕，嗟微驅之是效兮，甘九死而忘生，幾司命之役籍兮，先黃髮而隕零，天蓋高而察卑兮，兾神明之我聽。獨鬱伊而莫愬兮，追顧景而憐形，奏斯文以寫思兮，結翰墨以敷誠。嗚呼哀哉！」

**釋讀與歸年** 裴注保存曹植为曹丕所作诔，开篇明记黄初七年五月七日大行皇帝崩，并写曹植初闻讣告的哀痛。曹植在诔中所用“鄄城侯”号见原注，不据此回改其年内封爵。

**釋讀與歸年** 诔先由三皇五帝和礼制沿革讲到汉魏易代，再述曹丕受命与资质、学识、务求贤才。是失去君主后的颂辞，典故与所历之年不能一概视为226年事件。

**釋讀與歸年** 曹植追颂魏朝法度与车服、任用方牧虎将、对蜀吴和诸境外交及祥瑞。多层为诔文颂语，不能把所举“万里无尘”、远人进献和祥瑞逐项认作独立确年的事件。

**釋讀與歸年** 曹植述农业、朝礼及郊庙祭礼，再赞曹丕在位七载恢复礼乐并以哀叹收束此段。“方隆封禅”是诔中所表述前景，不能据此说魏文帝实际赴山封禅。

**釋讀與歸年** 曹植说曹丕预定葬制，新君依照施行，以首阳陵因山安葬，不封不树，薄其随葬。其所叙是226葬礼，薄葬诏明载在222年。

**釋讀與歸年** 诔末描写入殡、送葬及嗣君发哀，又自述作为远臣因关防阻隔而悲悼，分别为曹植所写葬礼场景和个人哀语。

### 10. 陆逊、孙权议曹丕死后魏局

[返回正文第10条](#ce0226-event-10)

<a id="sgz052-b-2501-2"></a>

<a id="wu052-l103-2"></a>

<a id="wu052-l103-3"></a>

<a id="full-wu052-l103-2"></a>

**[《三國志·張顧諸葛步傳》](../../拆分史书/三国志/卷052.md#full-wu052-l103-2)** · [TXT L103](../../拆分史书/三国志/卷052.txt#L103)

> 又別咨瑾曰：「近得伯言表，以爲曹丕已死，毒亂之民，當望旌瓦解，而更靜然。聞皆選用忠良，寬刑罰，布恩惠，薄賦省役，以恱民心，其患更深於操時。孤以爲不然。操之所行，其惟殺伐小爲過差，及離閒人骨肉，以爲酷耳。至於將御，自古少有。比之於操，萬不及也。今叡之不如丕，猶丕不如操也。其所以務崇小惠，必以其父新死，自度衰微，恐困苦之民一朝崩沮，故彊屈曲以求民心，欲以自安住耳，寧是興隆之漸邪！聞任陳長文、曹子丹輩，或文人諸生，或宗室戚臣，寧能御雄才虎將以制天下乎？夫威柄不專，則其事乖錯，如昔張耳、陳餘，非不敦睦，至於秉勢，自還相賊，乃事理使然也。又長文之徒，昔所以能守善者，以操笮其頭，畏操威嚴，故竭心盡意，不敢爲非耳。逮丕繼業，年已長大，承操之後，以恩情加之，用能感義。今叡幼弱，隨人東西，此曹等輩，必當因此弄巧行態，阿黨比周，各助所附。如此之日，姧讒並起，更相陷懟，轉成嫌貳。一爾已往，羣下爭利，主幼不御，其爲敗也焉得乆乎？所以知其然者，自古至今，安有四五人把持刑柄，而不離刺轉相蹄齧者也！彊當陵弱，弱當求援，此亂亡之道也。子瑜，卿但側耳聽之，伯言常長於計校，恐此一事小短也。」

**釋讀** 陸遜認為魏任用忠良、輕刑薄賦，未必因曹丕死而衰弱。孫權向諸葛瑾談起此事，認為曹叡能力不及父祖，只是借恩惠穩定人心。

**歸年** 本傳明言曹丕新死、曹叡即位。《魏明帝紀》可繫黃初七年，未載此信的確日。

**釋讀** 孫權以陳群、曹真等多頭掌權與張耳、陳餘由親轉仇為例，預測曹叡御下不力、諸臣將因權勢結黨相攻。

**歸年** 同一封諮詢的後半。這些是孫權的推測，接下來的注文評其是否應驗。

<a id="sgz052-b-2501-3"></a>

<a id="wu052-l104-1"></a>

**[《三國志·張顧諸葛步傳》裴注 027](../../拆分史书/三国志/卷052.md#edition-wu052-l104-1)** · [TXT L104](../../拆分史书/三国志/卷052.txt#L104)

> 臣松之以爲魏明帝一時明主，政自己出，孫權此論，竟爲無徵，而史載之者，將以主幼國疑，威柄不一，亂亡之形，有如權言，宜其存錄以爲鑒戒。或當以雖失之於明帝，而事著於齊王，齊王之世，可不謂驗乎！不敢顯斥，抑足表之微辭。

**釋讀** 裴松之認為曹叡能親自掌政，孫權料其在位時群下弄權之說未驗。史家記下這段，也許用來警惕少主在位、權柄不一，或暗指後來的齊王曹芳朝。

**歸年** 這是對226年談話的後見史評。末句涉及後來的曹芳朝，隨其評議對象保留。

> **〔裴注〕**
> 魏略曰：孫權嘗自將數萬衆卒至。時大雨，城柵崩壞，人民散在田野，未及補治。聘聞權到，不知所施，乃思惟莫若潛默可以疑之。乃勑城中人使不得見，又自卧舍中不起。權果疑之，語其部黨曰：「北方以此人忠臣也，故委之以此郡，今我至而不動，此不有密圖，必當有外救。」遂不敢攻而去。魏略此語，與本傳反。

> 增邑五百戶，并前千九百戶。

**釋讀與歸年** 《魏略》称天雨城柵坏、百姓散在野，文聘令城中藏身，自己卧舍不出。孙权疑城内有计或外援，没有攻城便退。末句指出它与本传二十余日攻围的叙述相反；随同一石阳战事并读。

> 交阯太守士燮卒，權以燮子徽爲安遠將軍，領九真太守，以校尉陳時代燮。岱表分海南三郡爲交州，以將軍戴良爲刺史，海東四郡爲廣州，岱自爲刺史。遣良與時南入，而徽不承命，舉兵戍海口以拒良等。岱於是上疏請討徽罪，督兵三千人晨夜浮海。或謂岱曰：「徽藉累世之恩，爲一州所附，未易輕也。」岱曰：「今徽雖懷逆計，未虞吾之卒至，若我潛軍輕舉，掩其無備，破之必也。稽留不速，使得生心，嬰城固守，七郡百蠻，雲合響應，雖有智者，誰能圖之？」遂行，過合浦，與良俱進。徽聞岱至，果大震怖，不知所出，即率兄弟六人肉袒迎岱。岱皆斬送其首。徽大將甘醴、桓治等率吏民攻岱，岱奮擊，大破之，進封番禺侯。於是除廣州，復爲交州如故。岱旣定交州，復進討九真，斬獲以萬數。

**釋讀** 士燮死後，孫權改任士徽為安遠將軍、領九真太守，以陳時接交阯。呂岱奏分交州、廣州，由戴良治交州、呂岱治廣州。士徽拒命守海口，呂岱認為戰貴神速，率三千人與戴良進兵。士徽猝聞呂岱至，率兄弟六人肉袒相迎，呂岱悉斬送首。甘醴、桓治率吏民來攻，呂岱擊敗他們，封番禺侯。吳撤廣州，恢復原交州，呂岱又進軍九真，斬獲以萬計。

**歸年** 卷049〈士燮傳〉記黃武五年士燮卒及士徽抗命，亦見卷053〈薛綜傳〉南征後續。倉內《通鑑》卷070將罷廣州、進討九真接在同一紀事，分州、交阯初平與九真後續在年頁合讀，後者無單獨月日。

### 16. 吴范病卒，孙权求术数传人

[返回正文第16条](#ce0226-event-16)

<a id="sy-sg063-l2972-e32"></a>

<a id="sgz063-b-2972-1"></a>

<a id="wu063-l23-1"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../拆分史书/三国志/卷063.md#edition-wu063-l23-1)** · [TXT L23](../../拆分史书/三国志/卷063.txt#L23)

> 黃武五年，範病卒。長子先死，少子尚幼，於是業絕。權追思之，募三州有能舉知術數如吳範、趙達者，封千戶侯，卒無所得。

**釋讀** 黃武五年，吳範病故。長子先死，幼子年紀還小，這門術業因此失傳。孫權追念吳範，向三州招募，許諾若有人能舉薦像吳範、趙達一樣懂術數的人，就封舉薦者為千戶侯，終究沒能找到。

**歸年** 本傳明載黃武五年（226）吳範病卒。懸賞在他身後，具體月年無載，隨吳範病卒及術業失傳後的反應同條合讀。

<a id="sgz063-p-003-1"></a>

<a id="wu063-l24-1"></a>

**[《三國志·吳範劉惇趙達傳》裴注 003](../../拆分史书/三国志/卷063.md#edition-wu063-l24-1)** · [TXT L24](../../拆分史书/三国志/卷063.txt#L24)

> 吳錄曰：範先知其死日，謂權曰：「陛下某日當喪軍師。」權曰：「吾無軍師，焉得喪之？」範曰：「陛下出軍臨敵，須臣言而後行，臣乃陛下之軍師也。」至其日果卒。　臣松之案，範死時，權未稱帝，此云陛下，非也。

**釋讀** 《吳錄》說吳範預知自己的死日，告訴孫權某日將失去軍師。孫權問自己沒有軍師，怎會失去。吳範答，孫權出兵臨敵，要聽過自己的意見才行動，可見自己就是他的軍師。《吳錄》稱吳範到那一天果然死去。裴松之按道，吳範死時孫權還未稱帝，此處稱「陛下」有誤。

**歸年** 引書逸事繫於同一226年吳範卒事，保留原文稱謂與裴松之辨誤，實際談話的時間與死日均無明文。卷047記孫權於229年黃龍元年始稱帝。

# 公元226年｜曹丕去世，司马懿受顾命并出战襄阳

[← 公元225年](ce-0225.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元227年 →](ce-0227.md)

**魏黄初七年（五月曹叡即位，本年仍用黄初年号）；蜀汉建兴四年；吴黄武五年。**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="正文"></a>

<a id="event-1"></a>

1. **曹丕南征归来，司马懿继续承担留守事务。** 正月（魏黄初七年），曹丕从上一年的南征回到洛阳。他肯定蒋济保全船队的工作，又继续让司马懿镇守许昌，明确自己在东时由司马懿总理西面的事务，自己在西时则由司马懿处理东面的事务。司马懿负责接续皇帝出行时的后方政务和军务，不只是留一支兵守城。 [[1]](#note-1)

<a id="event-2"></a>



<a id="event-3"></a>

3. **孙权趁魏国大丧攻江夏，文聘守住了城。** 八月（魏黄初七年），孙权亲自率军进攻江夏。太守文聘坚守，曹叡判断吴军已经失去突然袭击的机会，难以久围。正在边地慰劳的荀禹调集沿途县兵和随行兵马，依山举火，形成援兵声势，孙权随后退去。 [[3]](#note-3)

<a id="event-4"></a>

4. **另一支吴军攻襄阳，司马懿率军击退诸葛瑾。** 同年，吴将诸葛瑾等进攻襄阳，司马懿督军迎击，斩杀吴将张霸。魏军也在寻阳击败吴军别部，《三国志·明帝纪》记领兵者为曹休，《资治通鉴》记为曹真。 [[4]](#note-4)

<a id="event-5"></a>



<a id="sg-event-6"></a>

6. **曹丕托孤与去世。** 七年春正月，将幸许昌，许昌城南门无故自崩，帝心恶之，遂不入。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

<a id="sg-event-8"></a>

8. **筑九华台。** 三月，筑九华台。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **遣后宫淑媛、昭仪已下归其家。** [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **葬首阳陵。** 六月戊寅，葬首阳陵。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **自殡及葬，皆以终制从事。** [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **编年更正。** 幼年受曹操喜爱，见[曹叡早年时期条](时期-三国志魏纪后妃及汉末群雄.md#period-sgz003-b-167-2)。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **编年更正。** 曹叡封武德侯见延康元年。 [220年第18条](ce-0220.md#sg-note-18)。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **编年更正。** 甄氏赐死见黄初二年。 [221年第21条](ce-0221.md#sg-note-21)。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **帝病笃，乃立爲皇太子。** 七年夏五月，帝病笃，乃立爲皇太子。 [[15]](#sg-note-15)

16. **即皇帝位，大赦。** 丁巳，即皇帝位，大赦。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **尊皇太后曰太皇太后，皇后曰皇太后。** [[17]](#sg-note-17)

<a id="sg-event-20"></a>

20. **立皇弟蕤爲阳平王。** 壬辰，立皇弟蕤爲阳平王。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>



<a id="sg-event-22"></a>

23. **论功行赏各有差。** [[23]](#sg-note-23)

24. **清河王冏薨。** 冬十月，清河王冏去世。 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **以太尉锺繇爲太傅，征东大将军曹休爲大司马。** 十二月，以太尉锺繇爲太傅，征东大将军曹休爲大司马，中军大将军曹真爲大将军，司徒华歆爲太尉，司空王朗爲司徒，镇军大将军陈群爲司空，抚军大将军司马宣王爲骠骑大将军。 [[25]](#sg-note-25)

<a id="sg-event-26"></a>

26. **李严移驻江州。** 李严由永安移屯江州，并筑城。 [[26]](#sg-note-26)

<a id="sg-event-27"></a>

27. **秦宓去世。** 秦宓迁大司农，建兴四年卒。 [[27]](#sg-note-27)

<a id="sg-event-28"></a>

28. **士燮去世。** 士燮担任交阯太守四十余年，在黄武五年去世，年九十。 [[28]](#sg-note-28)

<a id="sg-event-29"></a>

29. **士徽拒命，吕岱率军进交阯。** 士燮死后，吴令戴良、陈时接管交州、交阯。士徽拒命，吕岱率兵三千昼夜浮海南下。 [[29]](#sg-note-29)

<a id="sg-event-30"></a>

30. **迁太常，进封南乡亭侯。** 黄初七年，迁太常，进封南乡亭侯，邑二百户。 [[30]](#sg-note-30)

<a id="sy-event-31"></a>

31. **卞秉进封开阳侯。** 曹丕时期，卞秉进封开阳侯，食邑一千二百户，任昭烈将军。 [[31]](#sy-note-31)

<a id="sy-event-32"></a>

32. **吴范病卒。** 吴范因病去世，其术无人继承。孙权以千户侯征求能推荐像吴范、赵达一样通晓术数的人，最终未获。 [[32]](#sy-note-32)

<a id="sgz-event-33"></a>

33. **许昌南门倒塌，曹丕不入城。** 曹丕计划去许昌，城南门忽倒塌，他厌恶这个征兆，便没有入城。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **曹叡即位后任秦朗内官。** 曹叡即位后授秦朗驍骑将军、给事中，车驾出入常让他随行。 [[34]](#sgz-note-34)

<a id="sgz-event-35"></a>

35. **韩当病卒，韩综袭侯。** 韩当病逝，其子韩综接领兵马与侯爵。 [[35]](#sgz-note-35)

<a id="sgz-event-36"></a>

36. **曹洪因舍客犯法下狱，群臣救不成。** 曹丕因曹洪客犯法，收狱论死，群臣求情不成。 [[36]](#sgz-note-36)

<a id="sgz-event-37"></a>

37. **卞太后与郭皇后营救曹洪，免死削爵。** 卞太后以废后警告郭后，郭后哭求，曹洪免死而罢官削爵；时人以曹洪有先朝功而不平。 [[37]](#sgz-note-37)

<a id="sgz-event-38"></a>

38. **明帝即位复封曹洪为乐城侯。** 明帝即位，授后将军，更封乐城侯，食千户、位特进。 [[38]](#sgz-note-38)

<a id="sgz-event-39"></a>

39. **曹休进封长平侯。** 魏明帝即位，进曹休爵为长平侯。 [[39]](#sgz-note-39)

<a id="sgz-event-40"></a>

40. **明帝即位，以曹爽为散骑侍郎。** 曹叡即位后，任曹爽为散骑侍郎。 [[40]](#sgz-note-40)

<a id="sgz-event-41"></a>

41. **曹洪免死后上表陈情。** 曹洪原以为必死，获赦后上表自责其行、自陈感戴，在阙门拜章。 [[41]](#sgz-note-41)

<a id="sgz-event-42"></a>

42. **曹林徙封鄄城。** 曹林迁封鄄城。 [[42]](#sgz-note-42)

<a id="sgz-event-43"></a>

43. **曹衮徙封濮阳。** 曹衮迁到濮阳。 [[43]](#sgz-note-43)

<a id="sgz-event-44"></a>

44. **曹敏徙封句阳。** 曹敏移封句阳。 [[44]](#sgz-note-44)

<a id="sgz-event-45"></a>

45. **曹干徙封钜鹿。** 曹干迁封钜鹿。 [[45]](#sgz-note-45)

<a id="sgz-event-46"></a>

46. **曹彪徙封白马。** 曹彪迁封白马。 [[46]](#sgz-note-46)

<a id="sgz-event-47"></a>

47. **曹茂徙封中丘。** 曹茂移封中丘。 [[47]](#sgz-note-47)

<a id="sgz-event-48"></a>

48. **芮玄卒，潘濬领其兵屯夏口。** 芮玄死后，潘濬兼领他的兵马屯夏口。 [[48]](#sgz-note-48)

<a id="sgz-event-49"></a>

49. **曹丕处死鲍勋。** 军还洛阳，鲍勋请斥有罪刘曜，刘曜密告鲍勋私放孙邕。 [[49]](#sgz-note-49)

<a id="sgz-event-50"></a>

50. **曹叡即位后进封满宠昌邑侯。** 满宠爵位进为昌邑侯。 [[50]](#sgz-note-50)

<a id="sgz-event-51"></a>

51. **曹叡即位赐牵招关内侯。** 曹叡即位后赐牵招关内侯。 [[51]](#sgz-note-51)

<a id="sgz-event-52"></a>

52. **曹叡给王昶扬烈将军号、关内侯。** 曹叡即位后加王昶官爵。 [[52]](#sgz-note-52)

<a id="sgz-event-53"></a>

53. **吴置东安郡，以全琮为太守。** 丹杨、吴、会稽山民攻陷属县，孙权划三郡险地置东安，任全琮为太守。 [[53]](#sgz-note-53)

<a id="sgz-event-54"></a>

54. **董昭随曹丕东征还，拜太仆。** 董昭从还拜任太仆。 [[54]](#sgz-note-54)

<a id="sgz-event-55"></a>

55. **韩暨升太常进南乡亭侯。** 韩暨迁掌礼的太常，进封南乡亭侯二百户。 [[55]](#sgz-note-55)

<a id="sgz-event-56"></a>

56. **曹叡即位赐崔林关内侯。** 明帝登基赐崔林爵。 [[56]](#sgz-note-56)

<a id="sgz-event-57"></a>

57. **曹叡即位封高柔延寿亭侯。** 因明帝即位封延寿亭侯。 [[57]](#sgz-note-57)

<a id="sgz-event-58"></a>

58. **曹叡即位命州郡申报剧易。** 下令按负担与边情区分郡县。 [[58]](#sgz-note-58)

<a id="sgz-event-59"></a>

59. **曹叡即位进辛毗颍乡侯。** 封颍乡侯，邑三百户。 [[59]](#sgz-note-59)

<a id="sgz-event-60"></a>

60. **曹叡即位擢高堂隆并纳罢宴谏。** 即位后用为给事中、博士、驸马都尉。群臣拟奏乐宴会，高堂隆以唐虞、殷高宗守丧礼劝停。 [[60]](#sgz-note-60)

<a id="sgz-event-61"></a>

61. **吴令州郡宽息民力。** 孙权因久战离农、亲属不能相恤，下令州郡给民休息。 [[61]](#sgz-note-61)

<a id="sgz-event-62"></a>

62. **孙权准陆逊增广农亩。** 陆逊因谷少请将军增种，孙权允并说自己与子共同受田耕作。 [[62]](#sgz-note-62)

<a id="sgz-event-63"></a>

63. **苍梧报凤凰。** 苍梧报见凤凰。 [[63]](#sgz-note-63)

<a id="sgz-event-64"></a>

64. **陆逊劝孙权宽刑薄调。** 陆逊请示便宜，劝施德宽刑、减轻征调，并请准低位之臣屡次陈闻有利事务。 [[64]](#sgz-note-64)

<a id="sgz-event-65"></a>

65. **孙权答陆逊宽刑薄调书。** 孙权称先严申令再惩，是为了防止犯罪，若有太重，自己愿再咨询损益。 [[65]](#sgz-note-65)

<a id="sgz-event-66"></a>

66. **孫权令陆逊、诸葛瑾审改科条。** 孙权令有司抄送科条，由郎中褚逢带给陆逊、诸葛瑾，令二人增减有碍条文。 [[66]](#sgz-note-66)

<a id="sgz-event-67"></a>

67. **曹叡即位加臧霸封邑。** 加五百户至三千五百户。 [[67]](#sgz-note-67)

<a id="sgz-event-68"></a>

68. **曹叡即位改封吕虔万年亭侯。** 加二百户至六百户。 [[68]](#sgz-note-68)

<a id="sgz-event-69"></a>

69. **曹叡即位进封许褚牟乡侯。** 邑七百户，并赐一子关内侯。 [[69]](#sgz-note-69)

<a id="sgz-event-70"></a>

70. **孙权与诸葛瑾论曹叡新立。** 陆逊说曹丕死后魏任贤宽刑薄赋，仍安；孙权认为小惠为魏自求安定，曹叡才能不及父祖。 [[70]](#sgz-note-70)

<a id="sgz-event-71"></a>

71. **孙权估计魏权柄分掌将生党争。** 以陈群、曹真等不足制天下、张耳陈余因争权而相攻为例，对年轻曹叡能否掌众人权势存疑，认为陆逊见有短处。 [[71]](#sgz-note-71)

<a id="sgz-event-72"></a>

72. **步骘假节移屯沤口。** 步骘得假节，移驻长沙沤口。 [[72]](#sgz-note-72)

<a id="sgz-event-73"></a>

73. **曹叡即位进和洽西陵乡侯。** 给食邑二百户。 [[73]](#sgz-note-73)

<a id="sgz-event-74"></a>

74. **曹叡即位进常林高阳乡侯。** 进封。 [[74]](#sgz-note-74)

<a id="sgz-event-75"></a>

75. **曹叡即位进杜袭平阳乡侯。** 升乡侯。 [[75]](#sgz-note-75)

<a id="sgz-event-76"></a>

76. **曹叡即位进封赵俨都乡侯。** 六百户，监荆州军假节。 [[76]](#sgz-note-76)

<a id="sgz-event-77"></a>

77. **曹叡即位任裴潜尚书。** 召入任尚书。 [[77]](#sgz-note-77)

<a id="sgz-event-78"></a>

78. **曹叡即位进卫觊閺乡侯。** 邑三百户。 [[78]](#sgz-note-78)

<a id="sgz-event-79"></a>

79. **魏明帝即位任刘劭陈留太守。** 敦教化，民称誉。 [[79]](#sgz-note-79)

<a id="sgz-event-80"></a>

80. **曹丕卒，吴质赋诗哀慕。** 作诗叹失知遇和身世，同时自勉。 [[80]](#sgz-note-80)

<a id="sgz-event-81"></a>

81. **曹叡进封陈群颍阴侯、开府。** 增邑五百合一千三百户，和曹休、曹真、司马懿等并得开府。 [[81]](#sgz-note-81)

<a id="sgz-event-82"></a>

82. **陈群上疏论教化与臣党。** 明帝初亲临政事，陈群上疏。 [[82]](#sgz-note-82)

<a id="sgz-event-83"></a>

83. **曹叡进陈矫为东乡侯。** 进爵东乡侯，食邑六百户。 [[83]](#sgz-note-83)

<a id="sgz-event-84"></a>

84. **曹叡封徐宣津阳亭侯。** 明帝即位封徐宣，食邑二百户。 [[84]](#sgz-note-84)

<a id="sgz-event-85"></a>

85. **曹叡进封卫臻康乡侯。** 明帝即位提高卫臻爵位。 [[85]](#sgz-note-85)

> 魏書春秋曰明帝將送葬曹真陳羣王朗等以暑熱固諫乃止孫盛曰夫窀穸之事孝子之極痛也人倫之道於斯莫重故天子七月而葬同軌畢至夫以義感之情猶盡臨隧之哀况乎天性發中敦禮者重之哉魏氏之徳仍世不基矣昔華元厚葬君子以為棄君於惡羣等之諫棄孰甚焉

> 明監吉凶體逺存亡深垂典制申之嗣皇聖上䖍奉是順是將乃剏玄宇基為首陽擬迹穀林追堯慕唐合山同陵不樹不彊塗車芻靈珠玉靡藏百神警侍來賔幽堂耕禽田獸望魂之翔於是俟大隧之致功兮練元辰之淑禎潛華體於梓宫兮馮正殿以居靈顧望嗣之號咷兮存臨者之悲聲悼晏駕之既疾兮感容車之速征浮飛魂於輕霄兮就黄墟以滅形背三光之昭晰兮歸玄宅之冥冥嗟一徃之不反兮痛閟闥之長扄咨逺臣之眇眇兮感凶諱以怛驚心孤絶而靡告兮紛流涕而交頸思恩榮以横奔兮閡闕塞之嶢崢顧衰絰以輕舉兮廹闗防之我嬰欲髙飛而遙逝兮憚天網之逺經遙投骨於山足兮報恩養於下庭慨拊心而自悼兮懼施重而命輕嗟微軀之是效兮甘九死而忘生㡬司命之役籍兮先黄髪而隕零天蓋高而察卑兮冀神明之我聼獨鬱伊而莫愬兮追顧景而憐形奏斯文以寫思兮結翰墨以敷誠嗚呼哀哉

**释读** 诔称曹丕预立首阳葬制，继位者遵从，并描写入殡、送葬与自己闻讣的悲痛。

**归年** 226葬礼，终制制定另见222年；诔中的尧葬是典故。

## 归年与考证

<a id="history-legacy-source-1"></a>

**[1] 《资治通鉴》卷070黄初七年正月条，与《晋书》卷001黄初六年段的跨年收束合读。**

> 春，正月，壬子，帝還洛陽。

《晋书》：

> 天子自廣陵還洛陽，詔帝曰：「吾東，撫軍當總西事；吾西，撫軍當總東事。」於是帝留鎮許昌。

[《通鉴》还京月份与慰劳蒋济](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-de2d02c231f3d6) · [《晋书》原文摘录HC03](../../sources/摘录/晋书/卷001-黄初.md#hc03)。说明：南征在225年，还洛阳在226年。分工诏令由《晋书》与还京相连叙述，但没有独立确日；不将所有细节都写成正月壬子当天发生。

<a id="history-legacy-source-2"></a>

**[2] 《资治通鉴》卷070黄初七年五月条；《晋书》卷001顾命段。**

> 夏，五月，帝疾篤，乃立叡為太子。丙辰，召中軍大將軍曹真、鎮軍大將軍陳群、撫軍大將軍司馬懿，並受遺詔輔政。丁巳，帝殂。

《晋书》：

> 帝與曹真、陳羣等見於崇華殿之南堂，並受顧命輔政。

> 明帝即位，改封舞陽侯。

[《通鉴》顾命、文帝去世与明帝即位](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-9fcfddb81aae45) · [《晋书》原文摘录HC04及诏太子语](../../sources/摘录/晋书/卷001-黄初.md#hc04)。说明：《通鉴》列三人，《晋书》列三人后用“等”，诏语作「此三公」。《三国志·文帝纪》另列曹休，正文据该纪列四人。《三国志·明帝纪》记丁巳即位，本年余月仍为黄初七年，次年始用太和元年。[百科与文献复核](../../meta/记录/晋书-卷001-黄初段引文去向.md#百科与文献复核)

<a id="history-legacy-source-3"></a>

**[3] 《资治通鉴》卷070，黄初七年八月江夏条。**

> 吳王聞魏有大喪，秋，八月，自將攻江夏郡，太守文聘堅守。

> 禹到江夏，發所經縣兵及所從步騎千人乘山舉火，吳王遁走。

[原文及曹叡对局势的判断](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E8%B3%87%E6%B2%BB%E9%80%9A%E9%91%91-%E5%8D%B7070.md#ref-1a544c5a8e6aba)。说明：《晋书》黄初段把孙权围江夏、诸葛瑾攻襄阳、司马懿督军连叙。本页依《通鉴》分写两处战场，避免吞掉文聘、荀禹的行动；这不是已证明司马懿绝未参与整轮防御，而是不把压缩叙述放大成独占全部战功。

《晋书》：

> 進擊，敗瑾，斬霸，并首級千餘。

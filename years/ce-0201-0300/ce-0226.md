# 公元226年｜曹丕去世，司马懿受顾命并出战襄阳

[← 公元225年](ce-0225.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元234年 →](ce-0234.md)

**魏黄初七年（五月曹叡即位，本年仍用黄初年号）；蜀汉建兴四年；吴黄武五年。**

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="正文"></a>

<a id="event-1"></a>

1. **曹丕南征归来，司马懿继续承担留守事务。** 正月（魏黄初七年），曹丕从上一年的南征回到洛阳。他肯定蒋济保全船队的工作，又继续让司马懿镇守许昌，明确自己在东时由司马懿总理西面的事务，自己在西时则由司马懿处理东面的事务。司马懿负责接续皇帝出行时的后方政务和军务，不只是留一支兵守城。 [[1]](#note-1)

<a id="event-2"></a>

2. **曹丕病重，司马懿成为受遗命辅政的大臣之一。** 五月（魏黄初七年），曹丕病势加重，立曹叡为太子。《三国志·文帝纪》记曹真、陈群、曹休、司马懿同受遗诏辅政。《晋书》记曹丕嘱咐太子留意别人挑拨他与三位大臣的关系。曹丕次日去世，曹叡即位，司马懿改封舞阳侯。 [[2]](#note-2)

<a id="event-3"></a>

3. **孙权趁魏国大丧攻江夏，文聘守住了城。** 八月（魏黄初七年），孙权亲自率军进攻江夏。太守文聘坚守，曹叡判断吴军已经失去突然袭击的机会，难以久围。正在边地慰劳的荀禹调集沿途县兵和随行兵马，依山举火，形成援兵声势，孙权随后退去。 [[3]](#note-3)

<a id="event-4"></a>

4. **另一支吴军攻襄阳，司马懿率军击退诸葛瑾。** 同年，吴将诸葛瑾等进攻襄阳，司马懿督军迎击，斩杀吴将张霸。魏军也在寻阳击败吴军别部，《三国志·明帝纪》记领兵者为曹休，《资治通鉴》记为曹真。 [[4]](#note-4)

<a id="event-5"></a>

5. **年底，魏廷重新安排大臣位次。** 十二月（魏黄初七年），曹叡任钟繇为太傅、曹休为大司马、曹真为大将军、陈群为司空，司马懿升为骠骑大将军。从留守许昌，到受顾命，再到统兵应对襄阳方面的吴军，司马懿已经同时承担朝廷和战场上的重要职责。 [[5]](#note-5)

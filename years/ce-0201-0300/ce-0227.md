<a id="sg-event-1"></a>

1. **郊祀武皇帝以配天，宗祀文皇帝于明堂以配上帝。** 太和元年春正月，郊祀武皇帝以配天，宗祀文皇帝于明堂以配上帝。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **分江夏南部，置江夏南部都尉。** [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **西平麴英反，杀临羌令、西都长。** 西平麴英反，杀临羌令、西都长，遣将军郝昭、鹿磐讨斩之。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **帝耕于藉田。** 二月辛未，帝耕于藉田。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **立文昭皇后寝庙于邺。** 辛巳，立文昭皇后寝庙于邺。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **朝日于东郊。** 丁亥，朝日于东郊。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **行五铢钱。** 夏四月乙亥，行五铢钱。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **初营宗庙。** 甲申，初营宗庙。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **夕月于西郊。** 秋八月，夕月于西郊。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **治兵于东郊。** 冬十月丙寅，治兵于东郊。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **焉耆王遣子入侍。** [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **立皇后毛氏。** 十一月，立皇后毛氏。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **赐天下男子爵人二级，鳏寡孤独不能自存者赐谷。** [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **封后父毛嘉爲列侯。** 十二月，封后父毛嘉爲列侯。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **新城太守孟达反，诏骠骑将军司马宣王讨之。** [[15]](#sg-note-15)

<a id="sg-event-16"></a>



<a id="sg-event-17"></a>

17. **徐晃去世。** 徐晃于太和元年死，谥壮侯，由其子徐盖嗣封。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **曹茂封聊城王。** 曹茂在曹丕时独未封王，魏明帝朝迁为聊城公，同年进王。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **诸葛亮出屯汉中。** 诸葛亮北上，在沔北、阳平、石马一带驻军。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **吴平彭绮，韩综降魏。** 吴诸将正月俘彭绮，闰月韩综领部下归魏。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **以中山魏昌之安城乡户千。** 太和元年三月，以中山魏昌之安城乡户千，追封逸，諡曰敬侯；适孙像袭爵。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **徙封浚仪。** 太和元年，徙封浚仪。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **丞相亮北住汉中，广汉绵竹山贼张慕等钞盗军资。** 建兴五年，丞相亮北住汉中，广汉绵竹山贼张慕等钞盗军资，劫略吏民，嶷以都尉将兵讨之。 [[23]](#sg-note-23)

<a id="sy-event-24"></a>

24. **诸葛亮问杨洪是否留张裔理府事。** 诸葛亮驻汉中前拟以张裔为留府长史，杨洪称张裔虽才明而未可独任，建议由向朗留府、张裔随军。 [[24]](#sy-note-24)

<a id="sgz-event-25"></a>

25. **曹叡优叙甄家亲属。** 曹叡自称梦见母亲，按亲疏等第授官、赏赐，以甄像为虎贲中郎将。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **甄氏母去世，曹叡临丧。** 甄氏的母亲去世，曹叡穿缌麻服临丧，百官陪位。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **明帝时钟繇王朗辩肉刑，终于未行。** 钟繇在太和年间上疏称以虞夏为典，汉文帝改制不合古道。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **贺齐去世。** 袭蕲春后四年贺齐去世。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **孙资以险阻及劳耗反对入汉中攻蜀。** 孙资追念曹操攻阳平与退夏侯渊旧部时以汉中为天狱，认为新阙进取要加兵十五六万，不若遣现兵固守，久则吴蜀自弊。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **曹植徙封浚仪。** 曹叡太和元年把曹植改封浚仪。 [[30]](#sgz-note-30)

### 5. 立文昭皇后寝庙于邺

[返回正文第5条](#sg-event-5)

<a id="sg003-l170-e5"></a>

**[《三国志·明帝纪》](../../sources/摘录/三国志-卷003-明帝纪.md#p001)** · [仓内TXT L170](../../sources/本地分卷/三国志/三国志-卷003.md#l170)

> 辛巳，立文昭皇后寢廟於鄴。

<a id="sgz005-b-313-2"></a>

**[《三国志·后妃传》仓内原文 L313](../../sources/本地分卷/三国志/三国志-卷005.md#l313)**

> 四月，初營宗廟，掘地得玉璽，方一寸九分，其文曰「天子羨思慈親」，明帝為之改容，以太牢告廟。

**释读** 营宗庙掘出有“天子羨思慈親”字的玉玺，曹叡以太牢告庙。

**归年** 本传太和元年四月，作为该年新增宗庙记事。

<a id="sgz005-p-011-2"></a>

**[《三国志·后妃传》裴注 011·2](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-011-2)**

> 無寢廟以承享禮非所以報顯德昭孝敬也稽之古制宜依周禮先妣别立寢廟並奏可之

**释读** 奏称无寝庙不足承享，依据《周礼》为先妣别立，朝廷采纳。

**归年** 卷003明太和元年二月于邺正式立寝庙。

<a id="sgz013-b-668-2"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L668](../../sources/本地分卷/三国志/三国志-卷013.md#l668)**

> 使至鄴省文昭皇后陵，見百姓或有不足。

**释读** 奉命往邺视文昭皇后陵，见民生窘迫。

**归年** 《通鉴》太和元年二月修甄后寝园后。

<a id="sgz013-b-668-3"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L668](../../sources/本地分卷/三国志/三国志-卷013.md#l668)**

> 是時方營脩宮室，朗上疏曰：「陛下即位已來，恩詔屢布，百姓萬民莫不欣欣。臣頃奉使北行，往反道路，聞衆傜役，其可得蠲除省減者甚多。願陛下重留日昃之聽，以計制寇。

**释读** 曹叡正营宫室，王朗称恩诏民欣，却闻有很多徭役可以蠲省，宜筹运国计制敌。

**归年** 《通鉴》卷070太和元年。

<a id="sgz013-b-668-4"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L668](../../sources/本地分卷/三国志/三国志-卷013.md#l668)**

> 昔大禹將欲拯天下之大患，故乃先卑其宮室，儉其衣食，用能盡有九州，弼成五服。句踐欲廣其禦兒之疆，馘夫差於姑蘇，故亦約其身以及家，儉其家以施國，用能囊括五湖，席捲三江，取威中國，定霸華夏。

**释读** 引大禹卑宫菲食而成功、勾践先节省家国然后灭吴为例。

**归年** 同疏典故。

<a id="sgz013-b-668-5"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L668](../../sources/本地分卷/三国志/三国志-卷013.md#l668)**

> 漢之文、景亦欲恢弘祖業，增崇洪緒，故能割意於百金之臺，昭儉於弋綈之服，內減太官而不受貢獻，外省傜賦而務農桑，用能號稱昇平，幾致刑錯。

**释读** 汉文景减宫苑、俭衣食、省税役务农，接近刑不必用的治世。

**归年** 同疏。

<a id="sgz013-b-668-6"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L668](../../sources/本地分卷/三国志/三国志-卷013.md#l668)**

> 孝武之所以能奮其軍勢，拓其外境，誠因祖考畜積素足，故能遂成大功。霍去病，中才之將，猶以匈奴未滅，不治第宅。明卹遠者略近，事外者簡內。

**释读** 汉武帝因祖考有积蓄方能拓境，霍去病尚以匈奴未灭不治宅，重边宜略亲身。

**归年** 同疏。

<a id="sgz013-b-668-7"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L668](../../sources/本地分卷/三国志/三国志-卷013.md#l668)**

> 自漢之初及其中興，皆於金革略寢之後，然後鳳闕猥閌，德陽並起。

**释读** 汉初和中兴均在兵事稍息才建高阙、大殿。

**归年** 同疏。

<a id="sgz013-b-668-8"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L668](../../sources/本地分卷/三国志/三国志-卷013.md#l668)**

> 今當建始之前足用列朝會，崇華之後足用序內官，華林、天淵足用展游宴，若且先成閶闔之象魏，使足用列遠人之朝貢者，脩城池，使足用絕踰越，成國險，其餘一切，且須豐年。

**释读** 现有宫殿够用，修象魏以接朝贡、修池城以保国防即可，其他工程待丰年。

**归年** 同疏。

<a id="sgz013-b-668-9"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L668](../../sources/本地分卷/三国志/三国志-卷013.md#l668)**

> 一以勤耕農爲務，習戎備爲事，則國無怨曠，戶口滋息，民充兵彊，而寇戎不賔，緝熙不足，未之有也。」

**释读** 宜专事农兵，使人口兵力滋长，敌自归服，治政光明。

**归年** 同疏。

**[《三国志·钟繇华歆王朗传》仓内原文 L649](../../sources/本地分卷/三国志/三国志-卷013.md#l649)**

> 陛下遠追二祖遺意，惜斬趾可以禁惡，恨入死之無辜，使明習律令，與群臣共議。出本當右趾而入大辟者，復行此刑。

**释读** 主复部分斩右趾以代死，防恶保无辜，令通律者与群臣共同议定。

**归年** 同次奏。

<a id="sgz013-b-649-6"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L649](../../sources/本地分卷/三国志/三国志-卷013.md#l649)**

> 書云：『皇帝清問下民，鰥寡有辭於苗。』此言堯當除蚩尤、有苗之刑，先審問於下民之有辭者也。

**释读** 引《尚书》说尧欲除旧刑先广纳有意见者。

**归年** 同次奏所引经。

<a id="sgz013-b-649-7"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L649](../../sources/本地分卷/三国志/三国志-卷013.md#l649)**

> 若今蔽獄之時，訊問三槐、九棘、群吏、萬民，使如孝景之令，其當棄巿，欲斬右趾者許之。其黥、劓、左趾、宮刑者，自如孝文，易以髠、笞。

**释读** 主审狱问百官万民，待处弃市而自愿受右趾刑的许之，其余依文帝例改髡笞。

**归年** 同次奏。

<a id="sgz013-b-649-8"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L649](../../sources/本地分卷/三国志/三国志-卷013.md#l649)**

> 能有姦者，率年二十至四五十，雖斬其足，猶任生育。今天下人少於孝文之世，下計所全，歲三千人。張蒼除肉刑，所殺歲以萬計。臣欲復肉刑，歲生三千人。

**释读** 认为恶人大多在壮年，刑余仍能养生育子，估一年可保三千条命，张苍减肉刑反增死者。

**归年** 同次奏，为钟繇估计。

<a id="sgz013-b-649-9"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L649](../../sources/本地分卷/三国志/三国志-卷013.md#l649)**

> 子貢問能濟民可謂仁乎？子曰：『何事於仁，必也聖乎，堯、舜其猶病諸！』又曰：『仁遠乎哉？我欲仁，斯仁至矣。』若誠行之，斯民永濟。」

**释读** 用《论语》子贡问仁主张真的行之可长久济民。

**归年** 同次奏。

<a id="sgz013-b-649-10"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L649](../../sources/本地分卷/三国志/三国志-卷013.md#l649)**

> 書奏，詔曰：「太傅學優才高，留心政事，又於刑理深遠。此大事，公卿羣寮善共平議。」

**释读** 明帝褒其通刑理，令公卿集议。

**归年** 同次议。

<a id="sgz013-b-649-11"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L649](../../sources/本地分卷/三国志/三国志-卷013.md#l649)**

> 司徒王朗議，以爲「繇欲輕減大辟之條，以增益刖刑之數，此即起偃爲豎，化屍爲人矣。然臣之愚，猶有未合微異之意。

**释读** 司徒王朗承认钟繇以刖免死是救活人的主意，己有不同看法。

**归年** 同次议。

<a id="sgz013-b-649-12"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L649](../../sources/本地分卷/三国志/三国志-卷013.md#l649)**

> 夫五刑之屬，著在科律，自有減死一等之法，不死即爲減。施行已乆，不待遠假斧鑿於彼肉刑，然後有罪次也。

**释读** 现律已有死罪减一等，不必再借用久废肉刑以区分刑等。

**归年** 同次议。

<a id="sgz013-b-649-13"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L649](../../sources/本地分卷/三国志/三国志-卷013.md#l649)**

> 前世仁者，不忍肉刑之慘酷，是以廢而不用。不用已來，歷年數百。今復行之，恐所減之文未彰於萬民之目，而肉刑之問已宣於寇讎之耳，非所以來遠人也。

**释读** 肉刑废已久；若复，百姓还未见减死，敌方已知有酷刑，远人难归。

**归年** 同次议。

<a id="sgz013-b-649-14"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L649](../../sources/本地分卷/三国志/三国志-卷013.md#l649)**

> 今可按繇所欲輕之死罪，使減死之髠、刖。嫌其輕者，可倍其居作之歲數。內有以生易死不訾之恩，外無以刖易釱駭耳之聲。」

**释读** 减死用髡及较轻刑代之，久服役弥补刑轻；可救人也不外传断足骇声。

**归年** TXT作“髠、刖”，《通鉴》作“髠刑”，并见末句非议刖刑，保留异文。

<a id="sgz013-b-649-15"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L649](../../sources/本地分卷/三国志/三国志-卷013.md#l649)**

> 議者百餘人，與朗同者多。帝以吳、蜀未平，且寢。

**释读** 议者百余且多赞成王朗，因吴蜀未平，明帝搁置。

**归年** 同一太和议。

<a id="sgz-note-29"></a>

### 29. 孙资以险阻及劳耗反对入汉中攻蜀

[返回正文第29条](#sgz-event-29)

<a id="sgz014-b-772-1"></a>

**[《三国志·程郭董刘蒋刘传》仓内原文 L772](../../sources/本地分卷/三国志/三国志-卷014.md#l772)**

> 昔武皇帝征南鄭，取張魯，陽平之役，危而後濟。又自往拔出夏侯淵軍，數言『南鄭直為天獄，中斜谷道為五百里石穴耳』，言其深險，喜出淵軍之辭也。又武皇帝聖於用兵，察蜀賊棲於山岩，視吳虜竄於江湖，皆橈而避之，不責將士之力，不爭一朝之忿，誠所謂見勝而戰，知難而退也。今若進軍就南鄭討亮，道既險阻，計用精兵又轉運鎮守南方四州遏禦水賊，凡用十五六萬人，必當復更有所發興。天下騷動，費力廣大，此誠陛下所宜深慮。夫守戰之力，力役參倍。但以今日見兵，分命大將據諸要險，威足以震攝強寇，鎮靜疆埸，將士虎睡，百姓無事。數年之間，中國日盛，吳蜀二虜必自罷弊。

**归年** TXT为《资别传》注中节文。《资治通鉴》卷七十太和元年诸葛亮屯汉中后系此议；数项曹操旧事为援引。

<a id="sgz014-p-034-1"></a>

**[《三国志·程郭董刘蒋刘传》裴注 034·1](../../sources/摘录/三国志-卷014-程郭董刘蒋刘传裴注.md#pei-034-1)**

> 資别傳曰諸葛亮出在南鄭時議者以為可因大發兵就討之帝意亦然以問資資曰昔武皇帝征南鄭取張魯陽平之役危而後濟又自往拔出夏侯淵軍數言南鄭直為天獄中斜谷道為五百里石穴耳言其深險喜出淵軍之辭也又武皇帝聖於用兵察蜀賊栖於山巖視呉虜竄於江湖皆撓而避之不責將士之力不争一朝之忿誠所謂見勝而戰知難而退也今若進軍就南鄭討亮道既險阻計用精兵又轉運鎮守南方四州遏禦水賊凡用十五六萬人必當復更有所發興天下騷動費力廣大此誠陛下所宜深慮夫守戰之力力役參倍但以今日見兵分命大將據諸要險威足以震懾彊寇鎮静疆場將士虎睡百姓無事數年之間中國日盛呉蜀二虜必自罷弊帝由是止

**释读** 诸葛亮屯南郑，群臣与明帝议征，孙资以武帝阳平得之甚难自说汉中如天牢为证，计算调兵转运同守江南须十余万，主张守险养民等待敌自疲，皇帝乃止。

**归年** 《资治通鉴》卷七十太和元年录议；TXT夹注同归本事件。

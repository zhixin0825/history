# 公元228年｜魏太和二年／蜀建兴六年／吴黄武七年

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **司马懿克新城，杀孟达。** 二年春正月，宣王攻破新城，斩达，传其首。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **分新城之上庸、武陵、巫县爲上庸郡。** 分新城之上庸、武陵、巫县爲上庸郡，锡县爲锡郡。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **诸葛亮出祁山，魏军在街亭反击。** 诸葛亮出祁山，天水、南安、安定响应。魏命曹真都督关右，张郃在街亭击破蜀军，诸葛亮退还。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **行幸长安。** 丁未，行幸长安。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **还洛阳宫。** 夏四月丁酉，还洛阳宫。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **赦系囚非殊死以下。** [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **论讨亮功，封爵增邑各有差。** 乙巳，论讨亮功，封爵增邑各有差。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **大旱。** 五月，大旱。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **诏曰“尊儒贵学”。** 六月，诏曰：「尊儒贵学，王教之本也。自顷儒官或非其人，将何以宣明圣道？其高选博士，才任侍中常侍者。申勑郡国，贡士以经学爲先。」 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **石亭之战。** 吴鄱阳太守周鲂诈降，曹休引兵至皖。陆逊率军在石亭击败曹休，魏军经夹石退走。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **立皇子穆爲繁阳王。** 乙酉，立皇子穆爲繁阳王。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **大司马曹休薨。** 庚子，大司马曹休去世。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **诏公卿近臣举良将各一人。** 冬十月，诏公卿近臣举良将各一人。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **司徒王朗薨。** 十一月，司徒王朗去世。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **诸葛亮围陈仓，曹真遣将军费曜等拒之。** 十二月，诸葛亮围陈仓，曹真遣将军费曜等拒之。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **辽东太守公孙恭兄子渊劫夺恭位。** 辽东太守公孙恭兄子渊劫夺恭位，遂以渊领辽东太守。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **曹植上疏求自试。** 曹植次年回封雍丘，上疏要求以军国事务考验自己的才干。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **田豫出塞与马城被围。** 郁筑鞬杀魏使，田豫率部击破郁筑鞬，回到马城被轲比能围七日，靠阎志劝说解围。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **姜维在街亭战役期间归蜀。** 魏天水太守疑姜维，夜走上邽，不纳姜维。姜维与梁绪等转投诸葛亮。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **吴濡须督骆统去世。** 骆统曾从陆逊拒蜀、守濡须，又主张整治侵害民众的占募；黄武七年去世。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **帝爲二道征吴，遣司马宣王从汉水下。** 太和二年，帝爲二道征吴，遣司马宣王从汉水下，〔休督〕诸军向寻阳。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **徵拜大司农。** 太和二年，徵拜大司农。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **就国，尚约俭。** 太和二年就国，尚约俭，教敕妃妾纺绩织紝，习为家人之事。 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **护乌丸校尉田豫出塞，爲轲比能所围于故马邑城。** 太和二年，护乌丸校尉田豫出塞，爲轲比能所围于故马邑城，移招求救。 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **豫遣译夏舍诣比能女壻郁筑鞬部。** 太和二年，豫遣译夏舍诣比能女壻郁筑鞬部，舍爲鞬所杀。 [[25]](#sg-note-25)

<a id="sg-event-26"></a>

26. **范迁大司马，印绶未下。** 黄武七年，范迁大司马，印绶未下，疾卒。 [[26]](#sg-note-26)

<a id="sg-event-27"></a>

27. **封建昌侯。** 黄武七年，封建昌侯。 [[27]](#sg-note-27)

<a id="sy-event-28"></a>

28. **鲜卑素利死，成律归摄其部。** 素利去世，其子尚小，由弟成律归为王，代理其部。 [[28]](#sy-note-28)

> 魏畧曰宣王誘達將李輔及達甥鄧賢賢等開門納軍達被圍旬有六日而敗焚其首于洛陽四達之衢

**释读** 司马懿诱孟达部将李辅和孟达外甥邓贤归降；他们开门纳魏军。孟达被围十六日败，首级送洛阳并在大道焚毁。

**归年** 本纪太和二年正月克新城；《魏略》注明被围十六日，通鉴卷071太和二年开头可互校。

**[《三国志·诸葛亮传》](../../sources/摘录/三国志-卷035-诸葛亮传.md#p003)** · [仓内TXT L1766](../../sources/本地分卷/三国志/三国志-卷035.md#L1766)

> 亮使馬謖督諸軍在前，與郃戰于街亭。謖違亮節度，舉動失宜，大為張郃所破。亮拔西縣千余家，還于漢中，戮謖以謝眾。

**[《三国志·关张马黄赵传》](../../sources/摘录/三国志-卷036-关张马黄赵传.md#p004)** · [仓内TXT L1813](../../sources/本地分卷/三国志/三国志-卷036.md#L1813)

> 明年，亮出軍，揚聲由斜谷道，曹真遣大眾當之。亮令雲與鄧芝往拒，而身攻祁山。雲、芝兵弱敵強，失利於箕谷，然斂眾固守，不至大敗。軍退，貶為鎮軍將軍。

<a id="sg039-l1877-e3"></a>

**[《三国志·董刘马陈董吕传》](../../sources/摘录/三国志-卷039-董刘马陈董吕传.md#p002)** · [仓内TXT L1877](../../sources/本地分卷/三国志/三国志-卷039.md#L1877)

> 建興六年 ，亮出軍向祁山，時有宿將魏延、吳壹等，論者皆言以為宜令為先鋒，而亮違眾拔謖，統大眾在前，與魏將張郃戰於街亭，為郃所破，士卒離散。亮進無所據，退軍還漢中。謖下獄物故，亮為之流涕。

**归年与互校** 本传作“下獄物故”，《诸葛亮传》作“戮謖”，保留各传用语。

<a id="sg043-l2036-e3"></a>

**[《三国志·黄李吕马王张传》](../../sources/摘录/三国志-卷043-黄李吕马王张传.md#p003)** · [仓内TXT L2036](../../sources/本地分卷/三国志/三国志-卷043.md#L2036)

> 建興六年，屬參軍馬謖先鋒。謖捨水上山，舉措煩擾，平連規諫謖，謖不能用，大敗於街亭。眾盡星散，惟平所領千人鳴鼓自持，魏將張郃疑其伏兵，不往逼也。於是平徐徐收合諸營遺迸，率將士而還。

<a id="sg026-l1401-e3-2"></a>

**[《三国志·满田牵郭传》](../../sources/摘录/三国志-卷026-满田牵郭传.md#p004)** · [仓内TXT L1401](../../sources/本地分卷/三国志/三国志-卷026.md#L1401)

> 太和二年，蜀相諸葛亮出祁山，遣將軍馬謖至街亭，高詳屯列柳城。

**归年与互校** 原传明记年号和年次；后续回叙见本卷。

<a id="sgz003-b-172-1"></a>

**[《三国志·明帝纪》仓内原文 L172](../../sources/本地分卷/三国志/三国志-卷003.md#l172)**

> 蜀大將諸葛亮寇邊，天水、南安、安定三郡吏民叛應亮。

**释读** 诸葛亮出祁山，天水、南安、安定部分吏民转而响应。

**归年** 本纪太和二年春；卷035《诸葛亮传》明确蜀建兴六年春扬声斜谷、亲攻祁山。

<a id="sgz003-b-172-2"></a>

**[《三国志·明帝纪》仓内原文 L172](../../sources/本地分卷/三国志/三国志-卷003.md#l172)**

> 遣大將軍曹真都督關右，並進兵。

**释读** 魏命大将军曹真督关右军，各路并进。

**归年** 本纪 L172 明载或承接太和二年条。

<a id="sgz003-b-172-3"></a>

**[《三国志·明帝纪》仓内原文 L172](../../sources/本地分卷/三国志/三国志-卷003.md#l172)**

> 右將軍張郃擊亮於街亭，大破之。亮敗走，三郡平。

**释读** 张郃在街亭大破蜀军，诸葛亮撤兵，三郡平定。

**归年** 卷035《诸葛亮传》明张郃所破为马谡。原文“擊亮”指诸葛亮所部，不写诸葛亮亲临街亭。

<a id="sgz003-p-006-1"></a>

**[《三国志·明帝纪》裴注 006·1](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-006-1)**

> 魏書曰是時朝臣未知計所出帝曰亮阻山為固今者自來既合兵書致人之術且亮貪三郡知進而不知退今因此時破亮必也乃部勒兵馬歩騎五萬拒亮

**释读** 诸葛亮进军、魏三郡响应，朝臣一时无策，曹叡说诸葛亮熟知主动出兵却贪地不知退，部署步骑五万抵禦。

**归年** 本纪太和二年春第一次北伐；注从曹叡角度记判断和领兵人数。

<a id="sgz003-p-007-1"></a>

**[《三国志·明帝纪》裴注 007·1](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-007-1)**

> 魏畧載帝露布天下幷班告益州曰劉備背恩自竄巴蜀諸葛亮棄父母之國阿殘賊之黨神人被毒惡積身滅亮外慕立孤之名而内貪專擅之實劉升之兄弟守空城而已亮又侮易益土虐用其民是以利狼宕渠高定靑羌莫不瓦解為亮讐敵而亮反裘負薪裏盡毛殫刖趾適屨刻肌傷骨反更稱說自以為能行兵於井底游歩於牛蹄自朕即位三邊無事猶哀憐天下數遭兵革且欲養四海之耆老長後生之孤幼先移風於禮樂次講武於農隙置亮畫外未以為虞而亮懐李熊愚勇之智不思荆邯度徳之戒驅畧吏民盜利祁山王師方振膽破氣奪馬謖高祥望旗奔敗虎臣逐北蹈尸渉血亮也小子震驚朕師猛銳踊躍咸思長驅朕惟率土莫非王臣師之所處荆棘生焉不欲使千室之邑忠信貞良與夫淫昏之黨共受塗炭故先開示以昭國誠勉思變化無滯亂邦巴蜀將吏士民諸為亮所刼廹公卿已下皆聴束手

**释读** 《魏略》记曹叡公布文告，贬斥刘备与诸葛亮，指责蜀方长期困敝，举祁山、马谡、高祥败退，称魏不欲百姓与其兵患同受摧残，招诱蜀将吏士民归降。

**归年** 本纪太和二年曹叡幸长安、街亭战后。露布中的旧事与敌我评价系文告的论证或宣传，勿当作228年的独立事实。

> 魏畧曰是時譌言云帝已崩從駕羣臣迎立雍丘王植京師自卞太后羣公盡懼及帝還皆私察顔色卞太后悲喜欲推始言者帝曰天下皆言將何所推

**释读** 《魏略》说京师谣传曹叡已死，随驾官员迎立雍丘王曹植。卞太后以下都惊惧，见曹叡还京后都暗中察其脸色。有人想追谣，曹叡以众人都在说而不查。

**归年** 本纪太和二年四月丁酉还洛阳；注文标“是時”，明确紧接此次归还。

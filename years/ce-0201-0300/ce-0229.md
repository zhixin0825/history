<a id="sg-event-1"></a>

1. **元城王礼薨。** 三年夏四月，元城王礼去世。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **繁阳王穆薨。** 六月癸卯，繁阳王穆去世。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **追尊高祖大长秋曰高皇帝。** 戊申，追尊高祖大长秋曰高皇帝，夫人吴氏曰高皇后。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **诏曰“礼”。** 秋七月，诏曰：「礼，王后无嗣，择建支子以继太宗，则当纂正统而奉公义，何得复顾私亲哉！汉宣继昭帝后，加悼考以皇号；哀帝以外藩援立，而董宏等称引亡秦，或误时朝，旣尊恭皇，立庙京都，又宠藩妾，使比长信，叙昭穆于前殿，并四位于东宫，僭差无度，人神弗佑，而非罪师丹忠正之谏，用致丁、傅焚如之祸。自是之后，相踵行之。昔鲁文逆祀，罪由夏父；宋国非度，讥在华元。其令公卿主管官员，深以前世行事爲戒。后嗣万一有由诸侯入奉大统，则当明爲人后之义；敢爲佞邪导谀时君，妄建非正之号以干正统，谓考爲皇，称妣爲后，则股肱大臣，诛之无赦。其书之金策，藏之宗庙，着于今典。」 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **改平望观曰听讼观。** 冬十月，改平望观曰听讼观。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **初，洛阳宗庙未成。** 初，洛阳宗庙未成，神主在邺庙。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **庙始成，使太常韩曁持节迎高皇帝、太皇帝、武帝、文帝神主于邺。** 十一月，庙始成，使太常韩曁持节迎高皇帝、太皇帝、武帝、文帝神主于邺，十二月己丑至，奉安神主于庙。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **大月氏王波调遣使奉献。** 癸卯，大月氏王波调派使奉献，以调爲亲魏大月氏王。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **蜀取武都、阴平。** 诸葛亮遣陈式取武都、阴平二郡。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **蜀置汉城、乐城。** 诸葛亮移幕府，在南山下建汉、乐二城。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **孙权称帝，蜀吴定盟。** 孙权即帝位，吴蜀重申同盟并约定将来的分界。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **赵云去世。** 建兴七年赵云去世，后追谥顺平。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **孙权即帝位，改元黄龙。** 孙权夏四月丙申在南郊即位，大赦，追尊孙坚、吴氏、孙策，立孙登为太子。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **吴迁都建业，陆逊辅孙登守武昌。** 孙权迁建业，陆逊受命辅佐太子孙登统领武昌留事。 [[14]](#sg-note-14)

<a id="sgz-event-38"></a>

<a id="sg-event-15"></a>

15. **拜散骑常侍。** 太和三年，拜散骑常侍。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **改昂諡曰愍王。** 太和三年改昂諡曰愍王。 [[16]](#sg-note-16)

<a id="sgz-event-35"></a>

<a id="sg-event-17"></a>

17. **进爵为公。** 太和三年，进爵为公。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **以交州属吴，解恢刺史。** 建兴七年，以交州属吴，解恢刺史。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **封都乡侯，后以罪徙庐陵郡。** 黄龙元年，封都乡侯，后以罪徙庐陵郡。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **拜车骑将军、右护军、领兖州牧。** 黄龙元年，拜车骑将军、右护军、领兖州牧。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **拜桓前将军，领青州牧。** 黄龙元年，拜桓前将军，领青州牧，假节。 [[21]](#sg-note-21)

<a id="sgz-event-40"></a>

<a id="sg-event-22"></a>

22. **拜上大将军、右都护。** 黄龙元年，拜上大将军、右都护。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **权称尊号，登爲皇太子。** 黄龙元年，权称尊号，登爲皇太子，以恪爲左辅，休右弼，谭爲辅正，表爲翼正都尉，是爲四友，而谢景、范慎、刁玄、羊衜等皆爲賔客，于是东宫号爲多士。 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **迁卫将军、左护军、徐州牧。** 黄龙元年，迁卫将军、左护军、徐州牧，尚公主。 [[24]](#sg-note-24)

<a id="sgz-event-25"></a>

25. **陈脩卒。** 陈脩于黄龙元年去世。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **孙权立黄龙大牙，命胡综作文。** 黄龙旗常在中军，调度众军看旗所向，孙权命胡综作赋。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **《黄龙大牙赋》先叙礼兵并颂建国。** 胡综从天象谈兵制，引高辛、舜、启、商周汉的征讨典故，赞颂孙吴受命。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **《黄龙大牙赋》叙阵法与旗号。** 赋说大牙居军中，众军见旗进退，仪法取象天时，借周赤乌与孙吴黄龙申说受命。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **胡综假托魏将吴质作降文。** 因降人称吴质疑惧，胡综拟作三则吴质降表。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **伪吴质降文第一篇。** 叙汉末动荡，称吴君受命，假托吴质令黄定奉表，声称愿归吴。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **伪吴质降文第二篇论处境与愿归吴。** 假称吴质在魏遭排斥，举伊尹、陈平、乐毅等说明改事新主，以周光口传一节取信孙权。 [[31]](#sgz-note-31)

<a id="sgz-event-32"></a>

32. **伪吴质降文第二篇论魏备与进军。** 假称曹魏内部失和，建议吴军据淮泗、乘春驱马，与所谓吴质河北举兵相应。 [[32]](#sgz-note-32)

<a id="sgz-event-33"></a>

33. **伪吴质降文第三篇促孙权及早响应。** 借许攸归曹及边将起事失机说法，假称吴质请求孙权勿失时机。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **追封曹铄相殇王。** 曹魏给早卒的曹铄追封谥。 [[34]](#sgz-note-34)

<a id="sgz-event-36"></a>

36. **邯郸怀王曹邕去世。** 曹邕薨，本篇称怀王。 [[36]](#sgz-note-36)

<a id="sgz-event-37"></a>

37. **吴佯称渡江北猎，满宠戒备西阳。** 降人报告孙权大整部众，宣称江北打猎。满宠判断将袭西阳而戒备，孙权得知退还。 [[37]](#sgz-note-37)

<a id="sgz-event-39"></a>

39. **刘禅以诸葛亮功复丞相。** 诏把街亭责任归马谡，称诸葛亮曾自贬，后攻陈仓斩王双、取武都阴平，以此恢复丞相。 [[39]](#sgz-note-39)

<a id="sgz-event-41"></a>

41. **刘晔与卫臻议当以高皇为追尊所止。** 曹叡下诏讨论高皇父的谥号。 [[41]](#sgz-note-41)

<a id="sgz-event-42"></a>

42. **孙权遣张刚、管笃使辽东。** 五月吴遣校尉张刚、管笃赴辽东。 [[42]](#sgz-note-42)

<a id="sgz-event-43"></a>

43. **蜀使夸本国，孙权恢复接见张昭。** 无人驳蜀使，孙权思念张昭，遣人请见，张昭离座谢罪，孙权跪请其止。 [[43]](#sgz-note-43)

<a id="sgz-event-44"></a>

44. **曹植徙封东阿。** 曹叡把曹植由雍丘徙封东阿。 [[44]](#sgz-note-44)

<a id="sgz-event-45"></a>

45. **追进曹熊为萧怀王。** 曹叡将已故曹熊进爵为王。 [[45]](#sgz-note-45)

<a id="sgz-event-46"></a>

46. **卫觊请设律博士。** 掌司法有尊法轻吏之弊，请教长吏知汉律，置博士传授，帝用其议。 [[46]](#sgz-note-46)

<a id="sgz-event-47"></a>

47. **魏修新律十八篇。** 刘劭与庾嶷、荀诜等定律令，著律略；后为散骑常侍。 [[47]](#sgz-note-47)

> 其二曰：「昔伊尹去夏人商，陳平委楚歸漢，書功竹帛，遺名陵後世，世主不謂之背誕者，以為知天命也。臣昔為曹氏所見交接，外托群臣，內如骨肉，恩義綢繆，有合無離，遂受偏方之任，總河北之軍。當此之時，志望高大，永與曹氏同死懼生。惟恐功之不建，事之不成耳。及曹氏之亡，後嗣繼位，幼沖統政，讒言彌興。同儕者以勢相害，異趣者得間其言，而臣受性簡略，素不下人，視彼數子，意實迫之，此亦臣之過也。遂為邪議所見構會，招至猜疑，誣臣欲叛。雖識真者保明其心，世亂讒勝，余嫌猶在，常懼一旦橫受無辜，憂心孔疚，如覆冰炭。昔樂毅為燕昭王立功於齊，惠王即位，疑奪其任，遂去燕之趙，休烈不虧。彼豈欲二三其德，蓋畏功名不建，而懼禍之將及也。昔遣魏郡周光以賈販為名，托叛南詣，宣達密計。時以倉卒，未敢便有章表，使光口傳而已。以為天下大歸可見，天意所在，非吳復誰?此方之民，思為臣妾，延頸舉踵，惟恐兵來之遲耳。若使聖恩少加信納，當以河北承望王師，疑心赤實，天日是鑒。而光去經年，不聞咳唾，未審此意竟得達不?瞻望長歎，日月以幾，魯望高子，何足以喻!又臣今日見待稍薄，蒼蠅之聲，綿綿不絕，必受此禍，遲速事耳。臣私度陛下未垂明慰者，必以臣質貫穿仁義之道，不行若此之事，謂光所傳，多虛少實，或謂比中有他消息，不知臣質構讒見疑，恐受大害也。且臣質著有罪之日，自當奔赴鼎鑊，束身待罪，此蓋人臣之宜也。今日無罪，橫見譖毀，將有商鞅、白起之禍。尋惟事勢，去亦直也。死而弗義，不去何為!樂毅之出，吳起之走，君子傷其不遇，未有非之者也。願陛下推古況今，不疑怪於臣質也。又念人臣獲罪，當如伍員奉己自效，不當繞幸因事為利。然今與古，厥勢不同，南北悠遠。江湖隔絕，自不舉事，何得濟免!是以忘志士之節，而思立功之義也之也。

**归年** 系黄龙元年一组拟文，人事及表中追叙不作独立史实。

### 32. 伪吴质降文第二篇论魏备与进军

[返回正文第32条](#sgz-event-32)

<a id="sgz062-b-2954-2"></a>

**[《三国志·是仪胡综传》仓内原文 L2954](../../sources/本地分卷/三国志/三国志-卷062.md#l2954)**

> 且臣質又以曹氏之嗣，非天命所在，政弱刑亂，柄奪於臣，諸將專威於外，各自為政，莫或同心，士卒衰耗，帑藏空虛，綱紀毀廢，上下並□，想前後數得降叛，具聞此問，兼弱攻昧，宜應天時，此實陛下進取之秋。是以區區敢獻其計。今若內兵淮、泗，據有下邳，荊、揚二州，聞聲響應，臣從河北席眷而南，形勢一連，根牙永固。關西之兵繫於所衛，青、徐二州不敢徹守，許，洛余兵眾不滿萬，誰能來東與陛下爭者?此城千載一會之期，可不深思而熟計乎!及臣所在，既自多馬，加以羌、胡常以三四月中美草時，驅馬來出，隱度今者，可得三千餘匹。陛下出軍，當投此時，多將騎士來就馬耳。此皆先定所一二知。凡兩軍不能相究虛實，今此間實羸，易可克定，陛下舉動，應者必多。上定洪業，使普天一統，下令臣質建非常之功，此乃天也。若不見納，此亦天也。願陛下思之，不復多陳。」

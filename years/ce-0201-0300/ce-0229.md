[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **元城王礼薨。** 三年夏四月，元城王礼去世。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **繁阳王穆薨。** 六月癸卯，繁阳王穆去世。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **追尊高祖大长秋曰高皇帝。** 戊申，追尊高祖大长秋曰高皇帝，夫人吴氏曰高皇后。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **诏曰“礼”。** 秋七月，诏曰：「礼，王后无嗣，择建支子以继太宗，则当纂正统而奉公义，何得复顾私亲哉！汉宣继昭帝后，加悼考以皇号；哀帝以外藩援立，而董宏等称引亡秦，或误时朝，旣尊恭皇，立庙京都，又宠藩妾，使比长信，叙昭穆于前殿，并四位于东宫，僭差无度，人神弗佑，而非罪师丹忠正之谏，用致丁、傅焚如之祸。自是之后，相踵行之。昔鲁文逆祀，罪由夏父；宋国非度，讥在华元。其令公卿主管官员，深以前世行事爲戒。后嗣万一有由诸侯入奉大统，则当明爲人后之义；敢爲佞邪导谀时君，妄建非正之号以干正统，谓考爲皇，称妣爲后，则股肱大臣，诛之无赦。其书之金策，藏之宗庙，着于今典。」 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **改平望观曰听讼观。** 冬十月，改平望观曰听讼观。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **初，洛阳宗庙未成。** 初，洛阳宗庙未成，神主在邺庙。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **庙始成，使太常韩曁持节迎高皇帝、太皇帝、武帝、文帝神主于邺。** 十一月，庙始成，使太常韩曁持节迎高皇帝、太皇帝、武帝、文帝神主于邺，十二月己丑至，奉安神主于庙。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **大月氏王波调遣使奉献。** 癸卯，大月氏王波调派使奉献，以调爲亲魏大月氏王。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **蜀取武都、阴平。** 诸葛亮遣陈式取武都、阴平二郡。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **蜀置汉城、乐城。** 诸葛亮移幕府，在南山下建汉、乐二城。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **孙权称帝，蜀吴定盟。** 孙权即帝位，吴蜀重申同盟并约定将来的分界。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **赵云去世。** 建兴七年赵云去世，后追谥顺平。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **孙权即帝位，改元黄龙。** 孙权夏四月丙申在南郊即位，大赦，追尊孙坚、吴氏、孙策，立孙登为太子。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **吴迁都建业，陆逊辅孙登守武昌。** 孙权迁建业，陆逊受命辅佐太子孙登统领武昌留事。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **拜散骑常侍。** 太和三年，拜散骑常侍。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **改昂諡曰愍王。** 太和三年改昂諡曰愍王。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **进爵为公。** 太和三年，进爵为公。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **以交州属吴，解恢刺史。** 建兴七年，以交州属吴，解恢刺史。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **封都乡侯，后以罪徙庐陵郡。** 黄龙元年，封都乡侯，后以罪徙庐陵郡。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **拜车骑将军、右护军、领兖州牧。** 黄龙元年，拜车骑将军、右护军、领兖州牧。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **拜桓前将军，领青州牧。** 黄龙元年，拜桓前将军，领青州牧，假节。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **拜上大将军、右都护。** 黄龙元年，拜上大将军、右都护。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **权称尊号，登爲皇太子。** 黄龙元年，权称尊号，登爲皇太子，以恪爲左辅，休右弼，谭爲辅正，表爲翼正都尉，是爲四友，而谢景、范慎、刁玄、羊衜等皆爲賔客，于是东宫号爲多士。 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **迁卫将军、左护军、徐州牧。** 黄龙元年，迁卫将军、左护军、徐州牧，尚公主。 [[24]](#sg-note-24)

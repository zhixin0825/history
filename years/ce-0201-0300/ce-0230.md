## 本年概述

魏太和四年，曹叡升曹真为大司马、司马懿为大将军，两人分路伐蜀。蜀军守城固、赤坂，大雨使栈道断绝，魏军被召回。魏延另在阳溪击败郭淮、费瑶。洛阳方面，太傅钟繇、太皇太后卞氏先后去世。

吴派卫温、诸葛直出海寻夷洲、亶洲，又在东兴筑堤拦巢湖。孙权冬日到合肥，满宠识破先退后袭之计，魏守住城。吴国内，隐蕃谋叛败露，被捕处死。

6. **魏分道伐蜀，遇大雨班师。** 六月丙申，魏撤上庸郡。七月，曹叡命曹真、司马懿伐蜀。曹真原想从斜谷进兵，陈群认为山路险阻，军粮难以转运。曹真改请走子午道，陈群仍陈其不便。八月，魏军分道向汉中进兵。司马懿从西城溯汉水进兵，计划在南郑会师。另有魏军经子午、斜谷及武威进兵。夏侯霸任子午道前锋，进至兴世围，在曲谷扎营，蜀军围攻，魏援军来到后方才解围。诸葛亮进驻城固、赤坂，命骠骑将军李严率二万人赴汉中，又表李严之子李丰为江州都督督军，接掌江州事务。华歆上疏说远征耗损耕作和粮储，劝曹叡先安百姓。曹叡答复说此番出军还想试探蜀军虚实，但记取其劝。大雨三十余日，伊、洛、黄河与汉水泛溢，部分栈道断绝。王肃、陈群请求班师，少府杨阜也指出军队困在山谷、输粮艰难，劝曹叡撤军节用。九月，朝廷召曹真等回军。 [[6]](#ce0230-note-6)

10. **孙权遣卫温、诸葛直远航。** 孙权筹议出兵取夷州、朱崖。陆逊认为连年用兵已使民力减损，远航有风浪、疾疫之险，主张休养军民、减轻租赋。全琮也以海路气候、水土和染疫风险劝止。正月，孙权仍遣卫温、诸葛直率军入海求夷洲、亶洲。船队经年，至[231年](ce-0231.md#sgz-note-32)从夷洲带数千人返吴，所得不足弥补损失。 [[10]](#ce0230-note-10)

13. **隐蕃谋叛被诛，郝普受责自尽。** 青州人隐蕃入吴上书，孙权召问时政。胡综认为他虽能辞辩却未有治才，朱据、郝普称许他，郝普与之亲善。隐蕃擅谈刑狱，孙权任他为廷尉监。全琮等也以礼相待，羊衜、杨迪拒绝跟他交往。潘濬得知儿子潘翥结交隐蕃、馈送粮食，写信命他受杖一百，并追回粮食。隐蕃谋叛败露后被捕，拒说同谋而死；郝普受孙权责问后自杀。朱据也遭禁制，过了一段时间才解除。 [[13]](#ce0230-note-13)

>
> **〔裴注〕**
> 世語曰：是時，當世俊士散騎常侍夏侯玄、尚書諸葛誕、鄧颺之徒，共相題表，以玄、疇四人爲四聡，誕、備八人爲八達，中書監劉放子熈、孫資子密、吏部尚書衞臻子烈三人，咸不及比，以父居勢位，容之爲三豫，凡十五人。帝以構長浮華，皆免官廢錮。

**釋讀與歸年** 諸葛誕、夏侯玄、鄧颺等互相標榜，魏明帝罷諸葛誕等官，據[《資治通鑑》卷七十一](../../史书/025-资治通鉴/KR2b0007_071.txt#L452-L468)於太和四年黜浮華詔下繫免官。

**釋讀與歸年** 《世語》記互相題品的四聡、八達、三豫及受罷免禁錮之事，接本傳被罷。

<a id="wei022-l102-1"></a>

**[《三國志·桓二陳徐衞盧傳》正文](../../拆分史书/三国志/卷022.md#edition-wei022-l102-1)** · [TXT L102](../../拆分史书/三国志/卷022.txt#L102)

> 前此諸葛誕、鄧颺等馳名譽，有四䆫八達之誚，帝疾之。

**釋讀與歸年** 本傳追述諸葛誕、鄧颺等以聲譽相標榜，當時譏作四䆫八達，曹叡厭惡。[《資治通鑑》](../../史书/025-资治通鉴/KR2b0007_071.txt#L433-L443)用「四聰八達」說並記在太和四年被免官。

<a id="wei014-l81-3"></a>

**[《三國志·程郭董劉蔣劉傳》正文](../../拆分史书/三国志/卷014.md#edition-wei014-l81-3)** · [TXT L81](../../拆分史书/三国志/卷014.txt#L81)

> 昭上疏陳末流之弊曰：「凡有天下者，莫不貴尚敦樸忠信之士，深疾虛偽不真之人者，以其毀教亂治，敗俗傷化也。近魏諷則伏誅建安之末，曹偉則斬戮黃初之始。伏惟前後聖詔，深疾浮偽，欲以破散邪黨，常用切齒；而執法之吏皆畏其權勢，莫能糾擿，毀壞風俗，侵欲滋甚。竊見當今年少，不復以學問爲本，專更以交游爲業；國士不以孝悌清脩爲首，乃以趨勢游利爲先。合黨連羣，互相襃歎，以毀訾爲罰戮，用黨譽爲爵賞，附己者則歎之盈言，不附者則爲作瑕釁。至乃相謂『今世何憂不度邪，但求人道不勤，羅之不博耳；又何患其不知己矣，但當吞之以藥而柔調耳。』又聞或有使奴客名作在職家人，冒之出入，往來禁奧，交通書疏，有所探問。凡此諸事，皆法之所不取，刑之所不赦，雖諷、偉之罪，無以加也。」帝於是發切詔，斥免諸葛誕、鄧颺等。

**釋讀與歸年** 董昭上疏批评年轻士人结党互相品第、借势求官，甚至令奴客冒充在职人员出入禁中，举魏讽、曹伟为警戒。曹叡下严诏免诸葛诞、邓飏等职。传文把谏疏叙在「六年，拜真」之后，未给奏年；《资治通鉴》称董昭「行司徒事」，于太和四年春叙整治，并系诏于二月壬午。此采用《通鉴》且留本传顺读可得较晚年的异解。 [《资治通鉴》卷071](../../史书/025-资治通鉴/KR2b0007_071.txt#L433-L472)

> 是時大司馬曹真伐蜀，遇雨不進。阜上疏曰：「昔文王有赤烏之符，而猶日仄不暇食；武王白魚入舟，君臣變色。而動得吉瑞，猶尚憂懼，況有災異而不戰竦者哉？今吳、蜀未平，而天屢降變，陛下宜深有以專精應荅，側席而坐，思示遠以德，綏邇以儉。閒者諸軍始進，便有天雨之患，稽閡山險，以積日矣。轉運之勞，擔負之苦，所費以多，若有不繼，必違本圖。傳曰：『見可而進，知難而退，軍之善政也。』徒使六軍困於山谷之間，進無所略，退又不得，非主兵之道也。武王還師，殷卒以亡，知天期也。今年凶民饑，宜發明詔損膳減服，技巧珍玩之物，皆可罷之。昔邵信臣爲少府於無事之世，而奏罷浮食；今者軍用不足，益宜節度。」帝即召諸軍還。

**釋讀與歸年** 曹真伐蜀連遇雨阻，楊阜請停止艱難轉運、班師並節省飲膳器玩，曹叡召回諸軍。與[《資治通鑑》卷七十一](../../史书/025-资治通鉴/KR2b0007_071.txt#L491-L505)及同條《明帝紀》互見。奏疏完整。

**[《三國志·桓二陳徐衞盧傳》正文](../../拆分史书/三国志/卷022.md#edition-wei022-l26-2)** · [TXT L26](../../拆分史书/三国志/卷022.txt#L26)

> 太和中，曹真表欲數道伐蜀，從斜谷入。羣以爲「太祖昔到陽平攻張魯，多收豆麥以益軍糧，魯未下而食猶乏。今旣無所因，且斜谷阻險，難以進退，轉運必見鈔截，多留兵守要，則損戰士，不可不熟慮也」。帝從羣議。真復表從子午道。羣又陳其不便，并言軍事用度之計。詔以羣議下真，真據之遂行。會霖雨積日，羣又以爲宜詔真還，帝從之。

**釋讀與歸年** 陈群预见由斜谷出兵运粮困难，曹叡起先听从；曹真再请走子午道，陈群仍陈不便和经费。出师遇久雨，陈群再请回师，朝廷从之。本传作太和中，[《明帝纪》](../../拆分史书/三国志/卷003.txt#L44-L45)明确系太和四年七月至九月。

**[《三國志·鍾繇華歆王朗傳》正文](../../拆分史书/三国志/卷013.md#edition-wei013-l67-1)** · [TXT L67](../../拆分史书/三国志/卷013.txt#L67)

> 太和中，遣曹真從子午道伐蜀，車駕東幸許昌。歆上疏曰：「兵亂以來，過踰二紀。大魏承天受命，陛下以聖德當成康之隆，宜弘一代之治，紹三王之迹。雖有二賊負險延命，苟聖化日躋，遠人懷德，將襁負而至。夫兵不得已而用之，故戢而時動。臣誠願陛下先留心於治道，以征伐爲後事。且千里運糧，非用兵之利；越險深入，無獨克之功。如聞今年徵役，頗失農桑之業。爲國者以民爲基，民以衣食爲本。使中國無饑寒之患，百姓無離土之心，則天下幸甚，二賊之釁，可坐而待也。臣備位宰相，老病日篤，犬馬之命將盡，恐不復奉望鑾蓋，不敢不竭臣子之懷，唯陛下裁察！」帝報曰：「君深慮國計，朕甚嘉之。賊憑恃山川，二祖勞於前世，猶不克平，朕豈敢自多，謂必滅之哉！諸將以爲不一探取，無由自弊，是以觀兵以闚其釁。若天時未至，周武還師，乃前事之鑒，朕敬不忘所戒。」時秋大雨，詔真引軍還。

**[《三國志·鍾繇華歆王朗傳》正文](../../拆分史书/三国志/卷013.md#edition-wei013-l111-3)** · [TXT L111](../../拆分史书/三国志/卷013.txt#L111)

> 四年，大司馬曹真征蜀，肅上疏曰：「前志有之，『千里饋糧，士有饑色，樵蘇後爨，師不宿飽』，此謂平塗之行軍者也。又況於深入阻險，鑿路而前，則其爲勞必相百也。今又加之以霖雨，山坂峻滑，衆逼而不展，糧縣而難繼，實行軍者之大忌也。聞曹真發已踰月而行裁半谷，治道功夫，戰士悉作。是賊偏得以逸而待勞，乃兵家之所憚也。言之前代，則武王伐紂，出關而復還；論之近事，則武、文征權，臨江而不濟。豈非所謂順天知時，通於權變者哉！兆民知聖上以水雨艱劇之故，休而息之，後日有釁，乘而用之，則所謂恱以犯難，民忘其死者矣。」於是遂罷。

### 13. 隐蕃谋叛被诛，郝普受责自尽

[返回正文第13条](#ce0230-event-13)

<a id="sg-note-20"></a>





<a id="wu059-l8-6"></a>

**[《三國志·吳主五子傳》裴注 002](../../拆分史书/三国志/卷059.md#edition-wu059-l8-6)** · [TXT L8](../../拆分史书/三国志/卷059.txt#L8)

> 吳書曰：衜初爲中庶子，年二十。時廷尉監隱蕃交結豪傑，自衞將軍全琮等皆傾心敬待，惟衜及宣詔郎豫章楊迪拒絕不與通，時人咸怪之。而蕃後叛逆，衆乃服之。　

**釋讀** 羊衜初任中庶子時年二十。廷尉監隱蕃廣交豪傑，連衛將軍全琮等都以禮相接，只有羊衜與宣詔郎、豫章人楊迪拒絕交往，眾人起初驚異。後來隱蕃叛逆，眾人才信服他們的判斷。

**歸年** 《資治通鑑》卷071將隱蕃與羊衜、楊迪一事繫於黃龍二年，羊衜始任中庶子及交往始日無獨立年月。



<a id="sgz061-p-005-3"></a>

<a id="sgz061-p-005-4"></a>

<a id="wu061-l16-3"></a>

**[《三國志·潘濬陸凱傳》裴注 005](../../拆分史书/三国志/卷061.md#edition-wu061-l16-3)** · [TXT L16](../../拆分史书/三国志/卷061.txt#L16)

> 歸義隱蕃，以口辯爲豪傑所善，濬子翥亦與周旋，饋餉之。濬聞大怒，疏責翥曰：「吾受國厚恩，志報以命，爾輩在都，當念恭順，親賢慕善，何故與降虜交，以糧餉之？在遠聞此，心震面熱，惆悵累旬。疏到，急就往使受杖一百，促責所餉。」當時人咸怪濬，而蕃果圖叛誅夷，衆乃歸服。

**釋讀** 隱蕃投吳，以辯才結交豪傑。潘翥亦與他來往贈糧，潘濬得知後寫信急斥，說自己受國恩、誓以性命報國，諸子在京當恭順慕賢，怎能結交新降之人並給糧。他命潘翥就使者受杖一百，追還已給的糧食。時人不解，直到隱蕃圖叛被誅，才服其判斷。

**歸年** 卷062〈胡綜傳〉以黃龍二年記隱蕃入吳，卷059裴注也敘其交結、事敗。責子與案發均隨隱蕃事件同條，個別月日未載。



<a id="sg062-l2957-e20"></a>

<a id="sgz062-b-2957-1"></a>

<a id="sgz062-b-2957-2"></a>

<a id="wu062-l52-1"></a>

**[《三國志·是儀胡綜傳》正文](../../拆分史书/三国志/卷062.md#edition-wu062-l52-1)** · [TXT L52](../../拆分史书/三国志/卷062.txt#L52)

> 二年，青州人隱蕃歸吳，上書曰：「臣聞紂爲無道，微子先出；高祖寬明，陳平先入。臣年二十二，委棄封域，歸命有道，賴蒙天靈，得自全致。臣至止有日，而主者同之降人，未見精別，使臣微言妙旨，不得上達。於邑三歎，曷惟其已。謹詣闕拜章，乞蒙引見。」權即召入。蕃謝荅問，及陳時務，甚有辭觀。綜時侍坐，權問何如，綜對曰：「蕃上書，大語有似東方朔，巧捷詭辯有似禰衡，而才皆不及。」權又問可堪何官，綜對曰：「未可以治民，且試以都輦小職。」權以蕃盛論刑獄，用爲廷尉監。左將軍朱據、廷尉郝普稱蕃有王佐之才，普尤與之親善，常怨歎其屈。後蕃謀叛，事覺伏誅，

**釋讀** 黃龍二年，青州人隱蕃來到吳國。二十二歲的他上書引微子去殷、陳平入漢自比，說自己離開原境投奔有道之主，承賴天佑才得保全。管接待的官員把他與一般降人同待，使他的意見無法上達；因此請求召見。孫權召他，隱蕃答問、評時事，言談神采出眾。胡綜說他的高談像東方朔，敏捷巧辯像禰衡，但才力不及二人，又說還未能治理百姓，可以先試都城小職。孫權見他善談刑獄，任為廷尉監。朱據、郝普稱他有輔佐君王之才，郝普尤其與他親密，常替他抱屈。後隱蕃謀叛，事敗被誅。

**歸年** 承上孫權即位及改元，「二年」為黃龍二年。《通鑑》卷071於該年同敘隱蕃歸吳、上書、所授官與後來案發，各節未載確月。

<a id="sgz062-p-003-2"></a>

<a id="wu062-l53-1"></a>

**[《三國志·是儀胡綜傳》裴注 003](../../拆分史书/三国志/卷062.md#edition-wu062-l53-1)** · [TXT L53](../../拆分史书/三国志/卷062.txt#L53)

> 吳錄曰：蕃有口才，魏明帝使詐叛如吳，令求作廷尉職，重案大臣以離間之。旣爲廷尉監，衆人以據、普與蕃親善，常車馬雲集，賔客盈堂。及至事覺，蕃亡走，捕得，考問黨與，蕃無所言。吳主使將入，謂曰：「何乃以肌肉爲人受毒乎？」蕃曰：「孫君，丈夫圖事，豈有無伴！烈士死，不足相牽耳。」遂閉口而死。

**釋讀** 《吳錄》說隱蕃有辯才，魏明帝命他假裝叛逃到吳，求任廷尉系統的官職，從重查辦大臣以離間吳廷。他任廷尉監後，眾人見朱據、郝普同他交好，常有賓客乘車騎馬來訪，滿堂會聚。事發後隱蕃逃走被捕，刑訊也未供同黨。孫權問何必為別人讓自己受苦；隱蕃答做這種事必有同伴，烈士將死，無須再牽累別人，遂閉口而死。

**歸年** 隨230年廷尉監及謀叛案合讀。魏明帝遣人詐降、求廷尉職以離間吳臣的緣由見《吳錄》，〈胡綜傳〉正文與《通鑑》卷071未載授命或確日；被捕受訊及拒供也是此注所敘。

<a id="sgz062-p-003-3"></a>

<a id="wu062-l53-2"></a>

**[《三國志·是儀胡綜傳》裴注 003](../../拆分史书/三国志/卷062.md#edition-wu062-l53-2)** · [TXT L53](../../拆分史书/三国志/卷062.txt#L53)

> 　吳歷曰：權問普：「卿前盛稱蕃，又爲之怨望朝廷，使蕃反叛，皆卿之由。」

**釋讀** 《吳歷》說孫權責問郝普：先前極力稱讚隱蕃，又替他怨望朝廷，孫權因此把隱蕃叛亂的責任歸於郝普。

**歸年** 同一隱蕃案。正文接敘郝普受責而自殺，《通鑑》卷071亦列於黃龍二年。

**[《三國志·是儀胡綜傳》正文](../../拆分史书/三国志/卷062.md#edition-wu062-l54-1)** · [TXT L54](../../拆分史书/三国志/卷062.txt#L54)

> 普見責自殺。據禁止，歷時乃解。

**釋讀** 郝普受到斥責後自殺，朱據受「禁止」處分，過了一段時間才解禁。

**歸年** 〈胡綜傳〉和《通鑑》卷071都把二人處分接在隱蕃伏誅後。胡三省注先釋「禁止」為未下獄而受看守限制，又引鄭樵、洪氏說為禁入殿省。此處解禁的確切年月無載。

# 公元230年｜魏太和四年／蜀建兴八年／吴黄龙二年

[← 公元229年](ce-0229.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元231年 →](ce-0231.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **诏曰“世之质文”。** 四年春二月壬午，诏曰：「世之质文，随教而变。兵乱以来，经学废绝，后生进趣，不由典谟。岂训导未洽，将进用者不以德显乎？其郎吏学通一经，才任牧民，博士课试，擢其高第者，亟用；其浮华不务道本者，皆罢退之。」 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **诏太傅三公，以文帝《典论》刻石。** 戊子，诏太傅三公：以文帝《典论》刻石，立于庙门之外。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **以大将军曹真爲大司马。** 癸巳，以大将军曹真爲大司马，骠骑将军司马宣王爲大将军，辽东太守公孙渊爲车骑将军。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **太傅锺繇薨。** 夏四月，太傅锺繇去世。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **太皇太后崩。** 六月戊子，太皇太后崩。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **省上庸郡。** 丙申，省上庸郡。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **武宣卞后祔葬于高陵。** 秋七月，武宣卞后祔葬于高陵。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **诏大司马曹真、大将军司马宣王伐蜀。** [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **行东巡，遣使者以特牛祠中岳。** 八月辛巳，行东巡，派使者以特牛祠中岳。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **幸许昌宫。** 乙未，幸许昌宫。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **行还洛阳宫。** 冬十月乙卯，行还洛阳宫。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **令，「罪非殊死听赎各有差。** 庚申，令：「罪非殊死听赎各有差。」 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **太白犯岁星。** 十一月，太白犯岁星。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **改葬文昭甄后于朝阳陵。** 十二月辛未，改葬文昭甄后于朝阳陵。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **诏公卿举贤良。** 丙寅，诏公卿举贤良。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **魏延在阳溪破郭淮。** 魏延于阳溪击退郭淮。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **徙刘永、刘理封国。** 鲁、梁属吴蜀预定分区的吴方，刘永、刘理改封甘陵、安平。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **张裔去世。** 张裔任留府长史，建兴八年去世。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **吴遣卫温、诸葛直航海求夷洲、亶洲。** 史载孙权遣卫温、诸葛直率兵浮海，终未至亶洲，带夷洲居民回吴。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **魏人隐蕃归吴，孙权召见。** 青州隐蕃来到吴地，以纣、文王及陈平等为比请求进见，孙权召入询问政务，胡综另上判断。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **诏封表安阳亭侯，又进爵乡侯。** 太和四年，诏封表安阳亭侯，又进爵乡侯，增邑并前五百户，迁中垒将军。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **行司徒事，六年。** 太和四年，行司徒事，六年，拜真。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **追进玹爵，諡曰怀公。** 太和四年，追进玹爵，諡曰怀公。 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **转为中护军，后又为司马。** 建兴八年，转为中护军，后又为司马。 [[24]](#sg-note-24)

<a id="sg-event-8"></a>

8. **皇子殷生，大赦。** 乙酉，皇子殷生，大赦。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **诏曰“古者诸侯朝聘”。** 八月，诏曰：「古者诸侯朝聘，所以敦睦亲亲协和万国也。先帝着令，不欲使诸王在京都者，谓幼主在位，母后摄政，防微以渐，关诸盛衰也。朕惟不见诸王十有二载，悠悠之怀，能不兴思！其令诸王及宗室公侯各将适子一人朝。后有少主、母后在宫者，自如先帝令，申明着于令。」 [[9]](#sg-note-9)

10. **月犯轩辕大星。** 十一月乙酉，月犯轩辕大星。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **日有蚀之。** 戊戌晦，发生日食。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **月犯镇星。** 十二月甲辰，月犯镇星。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **太尉华歆薨。** 戊午，太尉华歆去世。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **李严因运粮案废徙梓潼。** 李严被废并徙梓潼。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **张翼出任庲降都督。** 张翼任庲降都督、绥南中郎将；本传记他执法严，不得当地部族欢心。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **潘濬率军讨武陵。** 黄龙三年二月，潘濬领军攻武陵诸部。卫温、诸葛直同年因违诏无功被杀。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

<a id="sg-event-18"></a>

18. **追封諡曰经殇公。** 太和五年追封諡曰经殇公。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **建昌侯虑为镇军大将军。** 黄龙三年，建昌侯虑为镇军大将军，屯半州，以综为长史，外掌众事，内授书籍。 [[19]](#sg-note-19)

<a id="sy-event-20"></a>

20. **曹上等早卒宗室获追封谥。** 早卒无后的曹上获追封及谥号，曹勤、曹乘、曹京、曹棘同年亦然。 [[20]](#sy-note-20)

<a id="sy-event-21"></a>

21. **曹悌承嗣曹礼。** 曹魏以任城王曹楷之子曹悌继曹礼之后。 [[21]](#sy-note-21)

<a id="sy-event-22"></a>

22. **曹温承嗣曹邕。** 曹魏以任城王曹楷之子曹温承继曹邕。 [[22]](#sy-note-22)

<a id="sgz-event-23"></a>

23. **江阳到江州之间群鸟渡江坠水。** 《汉书春秋》说十月江阳至江州间，许多鸟从江南往江北飞渡，中途坠水大量死亡。 [[23]](#sgz-note-23)

<a id="sgz-event-24"></a>

24. **李恢去世。** 李恢去世。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **马忠、张嶷讨汶山叛羌。** 祁山军还后，马忠督张嶷等讨伐汶山郡叛羌。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **孙松卒，诸葛亮致书哀悼。** 孙松去世，诸葛亮致书诸葛瑾，因受吴廷厚待、与子弟亲近，见孙松所赠用物而流泪；传说源于养子诸葛乔的称述。 [[26]](#sgz-note-26)

<a id="sgz009-b-475-5"></a>

<a id="sgz009-b-475-6"></a>

**[《三国志·诸夏侯曹传》仓内原文 L475](../../sources/本地分卷/三国志/三国志-卷009.md#l475)**

> 帝追思真功，詔曰：「大司馬蹈履忠節，佐命二祖，內不恃親戚之寵，外不驕白屋之士，可謂能持盈守位，勞謙其德者也。其悉封真五子羲、訓、則、彥、皚皆爲列侯。」

**释读** 明帝诏赞曹真辅二祖、谦守大位，将曹羲、曹训、曹则、曹彦和曹皚封列侯。

**归年** 本传接太和五年曹真死后。只把随葬封褒一次归年。

**[《三国志·二张乐于徐传》](../../sources/摘录/三国志-卷017-二张乐于徐传.md#p004)** · [仓内TXT L889](../../sources/本地分卷/三国志/三国志-卷017.md#l889)

<a id="sg033-l1692-e3"></a>

**[《三国志·后主传》](../../sources/摘录/三国志-卷033-后主传.md#p003)** · [仓内TXT L1692](../../sources/本地分卷/三国志/三国志-卷033.md#l1692)

**归年与互校** 《后主传》称张郃追至青封，《张郃传》作木门，均系其退军追击中的死事。

<a id="sg035-l1769-e3"></a>

**[《三国志·诸葛亮传》](../../sources/摘录/三国志-卷035-诸葛亮传.md#p003)** · [仓内TXT L1769](../../sources/本地分卷/三国志/三国志-卷035.md#L1769)

> 九年，亮復出祁山，以木牛運，糧盡退軍，與魏將張郃交戰，射殺郃。

<a id="sgz003-p-012-1"></a>

**[《三国志·明帝纪》裴注 012·1](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-012-1)**

> 魏書曰初亮出議者以為亮軍無輜重糧必不繼不擊自破無為勞兵或欲自芟上邽左右生麥以奪賊食帝皆不從前後遣兵增宣王軍又勅使䕶麥宣王與亮相持賴得此麥以為軍糧

**释读** 诸葛亮出兵后，有人认为蜀军粮草不足，无须出战，有人请割除上邽附近青麦断其粮。曹叡不从，先后增兵，又命保护麦田，魏军相持时借此取粮。

**归年** 本纪太和五年诸葛亮出兵天水，注“初亮出”回到进兵，后半是魏蜀对峙时在上邽粮务；同年赏功第7条在其后。

<a id="sgz033-b-1692-1"></a>

**[《三国志·后主传》仓内原文 L1692](../../sources/本地分卷/三国志/三国志-卷033.md#l1692)**

> 九年春二月，亮復出軍圍祁山，始以木牛運。

**释读** 诸葛亮二月再出祁山，开始用木牛运送军资。

**归年** 建兴九年，《诸葛亮传》同事为231，魏明帝太和五年。

<a id="sgz033-b-1692-2"></a>

**[《三国志·后主传》仓内原文 L1692](../../sources/本地分卷/三国志/三国志-卷033.md#l1692)**

> 魏司馬懿、張郺救祁山。

**释读** 魏军司马懿、张郃赴祁山抵御蜀军。

**归年** 《明帝纪》太和五年见司马懿拒诸葛亮，《张郃传》见张郃督诸将到略阳。

<a id="sgz033-b-1692-3"></a>

**[《三国志·后主传》仓内原文 L1692](../../sources/本地分卷/三国志/三国志-卷033.md#l1692)**

> 夏六月，亮糧盡退軍，郺追至青封，與亮交戰，被箭死。

**释读** 蜀军六月粮尽退，魏将张郃追至青封，中箭身亡。

**归年** 本传建兴九年《张郃传》地名作木门，称箭中右膝；《通鉴》卷072叙木门同年，不以两地名拆成两战。

<a id="sgz040-b-1919-1"></a>

**[《三国志·刘彭廖李刘魏杨传》仓内原文 L1919](../../sources/本地分卷/三国志/三国志-卷040.md#l1919)**

> 九年春，亮軍祁山，平催督運事。

**释读** 诸葛亮出兵祁山，李平催督运粮。

**归年** 建兴九年、《明帝纪》太和五年同年，李平即李严。

<a id="sgz043-b-2034-11"></a>

**[《三国志·黄李吕马王张传》仓内原文 L2034](../../sources/本地分卷/三国志/三国志-卷043.md#l2034)**

> 明年，亮出祁山，忠詣亮所，經營戌事。

**释读** 诸葛亮出祁山，马忠到军中经营驻防。

**归年** 《后主传》建兴九年春。

<a id="sgz043-b-2036-8"></a>

**[《三国志·黄李吕马王张传》仓内原文 L2036](../../sources/本地分卷/三国志/三国志-卷043.md#l2036)**

> 九年，亮圍祁山，平別守南圍。魏大將軍司馬宣王攻亮，張郃攻平，平堅守不動，郃不能克。

**释读** 司马懿出击诸葛亮，张郃攻王平守卫的南围未克。

**归年** 本传建兴九年；《汉晋春秋》所载卤城交战可参。

<a id="sgz017-b-889-1"></a>

**[《三国志·二张乐于徐传》仓内原文 L889](../../sources/本地分卷/三国志/三国志-卷017.md#l889)**

**释读** 诸葛亮再出祁山，张郃督军往略阳，后追至木门。本传记飞箭中右膝，谥壮侯，子张雄嗣。

**归年** 《明帝纪》太和五年，《诸葛亮传》及《后主传》建兴九年。魏略另记中髀及司马懿强令追敌。

<a id="sgz017-p-009-1"></a>

**[《三国志·二张乐于徐传》裴注 009·1](../../sources/摘录/三国志-卷017-二张乐于徐传裴注.md#pei-009-1)**

> 魏畧曰亮軍退司馬宣王使郃追之郃曰軍法圍城必開出路歸軍勿追宣王不聽郃不得已遂進蜀軍乘髙布伏弓弩亂發矢中郃髀

**释读** 诸葛亮退军，张郃主张归军勿追，司马懿仍命他进击；蜀军设高地伏，矢中其髀。

**归年** 太和五年木门追击，正文说中右膝，裴注所引说中大腿。

### 9. 诏曰“古者诸侯朝聘”

[返回正文第9条](#sg-event-9)

<a id="sg003-l180-e9"></a>

**[《三国志·明帝纪》](../../sources/摘录/三国志-卷003-明帝纪.md#p002)** · [仓内TXT L180](../../sources/本地分卷/三国志/三国志-卷003.md#l180)

### 25. 马忠、张嶷讨汶山叛羌

[返回正文第25条](#sgz-event-25)

<a id="sgz043-b-2034-12"></a>

**[《三国志·黄李吕马王张传》仓内原文 L2034](../../sources/本地分卷/三国志/三国志-卷043.md#l2034)**

> 軍還，督將軍張嶷等討汶山郡叛羌。

**归年** 本传紧承建兴九年出祁山、军还。

<a id="sgz043-b-2043-9"></a>

**[《三国志·黄李吕马王张传》仓内原文 L2043](../../sources/本地分卷/三国志/三国志-卷043.md#l2043)**

> 北討汶山叛羌，

**释读** 张嶷随马忠北讨汶山，谋划攻取多有成效。

**归年** 同卷《马忠传》系于建兴九年出祁山军还之后。

<a id="sgz043-p-014-1"></a>

**[《三国志·黄李吕马王张传》裴注 014·1](../../sources/摘录/三国志-卷043-黄李吕马王张传裴注.md#pei-014-1)**

> 益部耆舊傳曰嶷受兵馬三百人隨馬忠討叛羌

**释读** 张嶷领兵马三百，随马忠讨叛羌。

**归年** 联系本卷《马忠传》建兴九年军还后。

<a id="sgz043-p-014-2"></a>

**[《三国志·黄李吕马王张传》裴注 014·2](../../sources/摘录/三国志-卷043-黄李吕马王张传裴注.md#pei-014-2)**

> 嶷别督數營在先至他里邑所在髙峻嶷随山立上四五里羌於要厄作石門於門上施牀積石於其上過者下石槌擊之無不糜爛

**释读** 张嶷领数营先到他里邑，沿山行四五里。对方在要隘设石门、堆压落石。

**归年** 同年汶山叛羌，裴注补地点与防御。

<a id="sgz043-p-014-3"></a>

**[《三国志·黄李吕马王张传》裴注 014·3](../../sources/摘录/三国志-卷043-黄李吕马王张传裴注.md#pei-014-3)**

> 嶷度不可得攻乃使譯告曉之曰汝汶山諸種反叛傷害良善天子命將討滅惡類汝等若稽顙過軍資給糧費福祿永隆其報百倍若終不從大兵致誅雷擊電下雖追悔之亦無益也

**释读** 张嶷料不能强攻，命译者晓谕降者将受报、不从则将进兵。

**归年** 同年汶山叛羌，裴注补招降。

<a id="sgz043-p-014-4"></a>

**[《三国志·黄李吕马王张传》裴注 014·4](../../sources/摘录/三国志-卷043-黄李吕马王张传裴注.md#pei-014-4)**

> 耆帥得命即出詣嶷給糧過軍軍前討餘種餘種聞他里已下悉恐怖失所或迎軍出降或奔竄山谷放兵攻擊軍以克㨗

**释读** 他里耆帅出谒，给军粮让部队通过；其余各部有人投降、有人逃散，军队随即进击获胜。

**归年** 同年汶山叛羌，裴注补过程。

### 26. 孙松卒，诸葛亮致书哀悼

[返回正文第26条](#sgz-event-26)

<a id="sgz051-b-2457-5"></a>

**[《三国志·宗室传》仓内原文 L2457](../../sources/本地分卷/三国志/三国志-卷051.md#l2457)**

> 黃龍三年卒。蜀丞相諸葛亮與兄瑾書曰：「既受東朝厚遇，依依於子弟。又子喬良器，為之惻愴。見其所與亮器物，感用流涕。」其悼松如此，由亮養子喬咨述故雲。

**归年** 本传明记黄龙三年卒，致书承卒，不单记月；下文子乔涉及诸葛亮养子。

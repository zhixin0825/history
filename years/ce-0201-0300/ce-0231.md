<a id="sg-event-1"></a>

1. **帝耕于藉田。** 五年春正月，帝耕于藉田。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **大司马曹真薨。** 三月，大司马曹真去世。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **诸葛亮寇天水，诏大将军司马宣王拒之。** [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **自去冬十月至此月不雨。** 自去冬十月至此月不雨，辛巳，大雩。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **鲜卑附义王轲比能率其种人及丁零大人儿禅诣幽州贡名马。** 夏四月，鲜卑附义王轲比能率其种人及丁零大人儿禅诣幽州贡名马。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **复置护匈奴中郎将。** [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **以亮退走，封爵增位各有差。** 秋七月丙子，以亮退走，封爵增位各有差。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **皇子殷生，大赦。** 乙酉，皇子殷生，大赦。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **诏曰“古者诸侯朝聘”。** 八月，诏曰：「古者诸侯朝聘，所以敦睦亲亲协和万国也。先帝着令，不欲使诸王在京都者，谓幼主在位，母后摄政，防微以渐，关诸盛衰也。朕惟不见诸王十有二载，悠悠之怀，能不兴思！其令诸王及宗室公侯各将适子一人朝。后有少主、母后在宫者，自如先帝令，申明着于令。」 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **月犯轩辕大星。** 十一月乙酉，月犯轩辕大星。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **日有蚀之。** 戊戌晦，发生日食。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **月犯镇星。** 十二月甲辰，月犯镇星。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **太尉华歆薨。** 戊午，太尉华歆去世。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **李严因运粮案废徙梓潼。** 李严被废并徙梓潼。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **张翼出任庲降都督。** 张翼任庲降都督、绥南中郎将；本传记他执法严，不得当地部族欢心。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **潘濬率军讨武陵。** 黄龙三年二月，潘濬领军攻武陵诸部。卫温、诸葛直同年因违诏无功被杀。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **加冲号曰邓哀王。** 太和五年，加冲号曰邓哀王。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **追封諡曰经殇公。** 太和五年追封諡曰经殇公。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **建昌侯虑为镇军大将军。** 黄龙三年，建昌侯虑为镇军大将军，屯半州，以综为长史，外掌众事，内授书籍。 [[19]](#sg-note-19)

<a id="sy-event-20"></a>

20. **曹上等早卒宗室获追封谥。** 早卒无后的曹上获追封及谥号，曹勤、曹乘、曹京、曹棘同年亦然。 [[20]](#sy-note-20)

<a id="sy-event-21"></a>

21. **曹悌承嗣曹礼。** 曹魏以任城王曹楷之子曹悌继曹礼之后。 [[21]](#sy-note-21)

<a id="sy-event-22"></a>

22. **曹温承嗣曹邕。** 曹魏以任城王曹楷之子曹温承继曹邕。 [[22]](#sy-note-22)

## 本年概述

诸葛亮再出祁山，司马懿接替曹真拒蜀，张郃在追击中战死，蜀廷追究李严的运粮责任。孙吴在淮南诱击魏军，又出兵武陵。曹叡恢复部分宗室朝见，曹植也就宗室交往与任用进言。

## 魏蜀祁山之役

<a id="sg-event-2"></a>

<a id="sgz-event-37"></a>

1. **曹真病卒，司马懿接掌其军。** 三月，大司马曹真去世。司马懿接掌其部，曹真原军师杜袭仍任军师，并增封至五百五十户。 [[1]](#ce231-note-1)

<a id="sg-event-3"></a>

<a id="sg-event-7"></a>

<a id="sgz-event-31"></a>

2. **诸葛亮再出祁山，张郃追至木门战死。** 建兴九年春，诸葛亮出祁山，曹叡命司马懿拒蜀。两军转战上邽、卤城，郭淮向羌、胡筹谷供应魏军。蜀军粮运不继而退，张郃追到木门，中箭战死。曹叡临朝惋惜张郃，陈群、辛毗各陈其意。七月，魏廷因蜀军退去而封赏将士。 [[2]](#ce231-note-2)

<a id="ce231-event-3"></a>

<a id="sg-event-14"></a>

3. **蜀廷追究祁山运粮责任，废李严徙梓潼。** 李严当时改名李平，负责军粮运输。霖雨使粮运不继，他派狐忠、成籓通知诸葛亮撤军，事后却称粮足，又向刘禅称蜀军假退诱敌。诸葛亮呈出李严前后文书，八月蜀廷废李严并徙梓潼。 [[3]](#ce231-note-3)

<a id="ce231-event-4"></a>

<a id="sgz-event-25"></a>

4. **马忠、张嶷讨汶山叛羌。** 祁山军还后，马忠督张嶷等讨伐汶山郡叛羌。 [[4]](#ce231-note-4)

## 吴军在淮南、武陵与交州

<a id="ce231-event-5"></a>

<a id="sgz-event-27"></a>

<a id="sgz-event-28"></a>

5. **孙布诈降诱王凌，满宠入朝后还镇。** 孙布以投降为名，请魏发兵接应。满宠识破计策，入朝前告诫部属勿借兵给王凌。王凌仍出兵接应，吴军设伏，魏军撤走。满宠因王凌党人指其衰老而被召，曹叡见他仍强健，命其还镇。 [[5]](#ce231-note-5)

<a id="ce231-event-6"></a>

<a id="sg-event-16"></a>

6. **潘濬率军讨武陵。** 黄龙三年二月，孙权派太常潘濬率五万人讨武陵诸部，吕岱参与其役。 [[6]](#ce231-note-6)

<a id="ce231-event-7"></a>

<a id="sgz-event-30"></a>

<a id="sgz-event-29"></a>

7. **吕岱离交州还屯漚口，薛综上疏论继任。** 这段时期，孙权以南境已定，召吕岱还屯长沙漚口。薛综虑继任者不称职，上疏追述交州沿革及近年用人得失。 [[7]](#ce231-note-7)

<a id="ce231-event-8"></a>

<a id="sgz-event-32"></a>

<a id="sgz-event-33"></a>

8. **吴军从夷洲带回数千人，卫温、诸葛直获罪被诛。** 两将奉命寻访夷洲、亶洲，[黄龙二年出海](ce-0230.md#sg047-l2305-e19)，未抵亶洲，从夷洲带回数千人。黄龙三年，吴以违诏无功将两将下狱诛杀。 [[8]](#ce231-note-8)

**归年与互校** 《后主传》称张郃追至青封，《张郃传》作木门，均系其退军追击中的死事。

> 九年，亮復出祁山，以木牛運，糧盡退軍，與魏將張郃交戰，射殺郃。

<a id="sgz003-p-012-1"></a>

**[《三国志·明帝纪》裴注 012·1](../../sources/本地分卷/三国志/三国志-卷003.md#pei-012-1)**

> 魏書曰初亮出議者以為亮軍無輜重糧必不繼不擊自破無為勞兵或欲自芟上邽左右生麥以奪賊食帝皆不從前後遣兵增宣王軍又勅使䕶麥宣王與亮相持賴得此麥以為軍糧

**释读** 诸葛亮出兵后，有人认为蜀军粮草不足，无须出战，有人请割除上邽附近青麦断其粮。曹叡不从，先后增兵，又命保护麦田，魏军相持时借此取粮。

**归年** 本纪太和五年诸葛亮出兵天水，注“初亮出”回到进兵，后半是魏蜀对峙时在上邽粮务；同年赏功第7条在其后。

**释读** 诸葛亮二月再出祁山，开始用木牛运送军资。

**归年** 建兴九年，《诸葛亮传》同事为231，魏明帝太和五年。

**释读** 魏军司马懿、张郃赴祁山抵御蜀军。

**归年** 《明帝纪》太和五年见司马懿拒诸葛亮，《张郃传》见张郃督诸将到略阳。

**释读** 蜀军六月粮尽退，魏将张郃追至青封，中箭身亡。

**归年** 本传建兴九年《张郃传》地名作木门，称箭中右膝；《通鉴》卷072叙木门同年，不以两地名拆成两战。

> 明年，亮出祁山，忠詣亮所，經營戌事。

**释读** 诸葛亮出祁山，马忠到军中经营驻防。

**归年** 《后主传》建兴九年春。

<a id="sgz043-b-2036-8"></a>

**[《三国志·黄李吕马王张传》仓内原文 L2036](../../sources/本地分卷/三国志/三国志-卷043.md#l2036)**

> 九年，亮圍祁山，平別守南圍。魏大將軍司馬宣王攻亮，張郃攻平，平堅守不動，郃不能克。

**释读** 司马懿出击诸葛亮，张郃攻王平守卫的南围未克。

**归年** 本传建兴九年；《汉晋春秋》所载卤城交战可参。

<a id="sgz017-b-889-1"></a>

**[《三国志·二张乐于徐传》仓内原文 L889](../../sources/本地分卷/三国志/三国志-卷017.md#l889)**

> 諸葛亮復出祁山，詔郃督諸將西至略陽，亮還保祁山，郃追至木門，與亮軍交戰，飛矢中郃右膝，薨，諡曰壯侯。子雄嗣。

**释读** 诸葛亮再出祁山，张郃督军往略阳，后追至木门。本传记飞箭中右膝，谥壮侯，子张雄嗣。

**归年** 《明帝纪》太和五年，《诸葛亮传》及《后主传》建兴九年。魏略另记中髀及司马懿强令追敌。

<a id="sgz017-p-009-1"></a>

**[《三国志·二张乐于徐传》裴注 009·1](../../sources/本地分卷/三国志/三国志-卷017.md#pei-009-1)**

### 21. 孙松卒，诸葛亮致书哀悼

[返回正文第21条](#ce231-event-21)

<a id="sgz051-b-2457-5"></a>

<a id="wu051-l57-1"></a>

**[《三國志·宗室傳》正文](../../sources/本地分卷/三国志/三国志-卷051.md#edition-wu051-l57-1)** · [TXT L57](../../sources/本地分卷/三国志/三国志-卷051.txt#L57)

> 黃龍三年卒。蜀丞相諸葛亮與兄瑾書曰：「旣受東朝厚遇，依依於子弟。又子喬良器，爲之惻愴。見其所與亮器物，感用流涕。」其悼松如此，由亮養子喬咨述故云。

**釋讀** 孫松黃龍三年卒。諸葛亮寫信給諸葛瑾悼念孫松，見其所贈物品而流淚。傳文將這份情誼繫於諸葛亮養子諸葛喬的稱述。

**歸年** 本傳明記卒於231年，致書緊隨卒後；諸葛喬稱述在此前，具體年月未載。

**异文与补证** 诸葛亮写给诸葛瑾的信中提到，自己从养子诸葛乔得知孙松的情况。

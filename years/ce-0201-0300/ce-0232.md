# 公元232年｜魏太和六年／蜀建兴十年／吴嘉禾元年

[← 公元231年](ce-0231.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元233年 →](ce-0233.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **诏曰“古之帝王”。** 六年春二月，诏曰：「古之帝王，封建诸侯，所以藩屏王室也。诗不云乎，『怀德维宁，宗子维城』。秦、汉继周，或强或弱，俱失厥中。大魏创业，诸王开国，随时之宜，未有定制，非所以永爲后法也。其改封诸侯王，皆以郡爲国。」 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **行东巡，所过存问高年鳏寡孤独。** 三月癸酉，行东巡，所过存问高年鳏寡孤独，赐谷帛。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **月犯轩辕大星。** 乙亥，月犯轩辕大星。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **行幸许昌宫。** 夏四月壬寅，行幸许昌宫。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **初进新果于庙。** 甲子，初进新果于庙。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **皇子殷薨，追封谥安平哀王。** 五月，皇子殷薨，追封谥安平哀王。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **以衞尉董昭爲司徒。** 秋七月，以衞尉董昭爲司徒。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **行幸摩陂，治许昌宫。** 九月，行幸摩陂，治许昌宫，起景福、承光殿。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **殄夷将军田豫帅衆讨吴将周贺于成山。** 冬十月，殄夷将军田豫帅衆讨吴将周贺于成山，杀贺。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **太白昼见。** 十一月丙寅，太白昼见。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **有星孛于翼，近太微上将星。** [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **陈思王植薨。** 庚寅，陈思王植去世。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **行还许昌宫。** 十二月，行还许昌宫。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **黄沙休士务农。** 诸葛亮驻黄沙休整，劝农并讲习军事，制作木牛、流马。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **明帝爱女淑薨，追封諡淑为平原懿公主。** 太和六年，明帝爱女淑薨，追封諡淑为平原懿公主，为之立庙。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **曹洪去世。** 曹洪于本年去世。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **以疾拜太中大夫。** 太和六年，以疾拜太中大夫。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **复改封任城国，食五县二千五百户。** 太和六年，复改封任城国，食五县二千五百户。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **改封诸王，皆以郡为国。** 太和六年，改封诸王，皆以郡为国，据复封彭城。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **改封燕王。** 太和六年，改封燕王。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **改封赵王。** 太和六年，改封赵王。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **改封东平。** 太和六年，改封东平。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **改封北海。** 太和六年，改封北海。 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **改封东海。** 太和六年，改封东海。 [[24]](#sg-note-24)

<a id="sg-event-26"></a>

26. **建昌侯虑卒。** 嘉禾元年春正月，建昌侯虑卒。 [[26]](#sg-note-26)

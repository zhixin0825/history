<a id="sg-event-1"></a>

1. **青龙见郏之摩陂井中。** 青龙元年春正月甲申，青龙见郏之摩陂井中。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **幸摩陂观龙，于是改年。** 二月丁酉，幸摩陂观龙，于是改年；改摩陂爲龙陂，赐男子爵人二级，鳏寡孤独无出今年租赋。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **诏公卿举贤良笃行之士各一人。** 三月甲子，诏公卿举贤良笃行之士各一人。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **诏祀故大将军夏侯惇、大司马曹仁、车骑将军程昱于太祖庙庭。** 夏五月壬申，诏祀故大将军夏侯惇、大司马曹仁、车骑将军程昱于太祖庙庭。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **北海王蕤薨。** 戊寅，北海王蕤去世。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **闰月庚寅朔，日有蚀之。** 闰月庚寅朔，发生日食。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **改封宗室女非诸王女皆爲邑主。** 丁酉，改封宗室女非诸王女皆爲邑主。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **诏诸郡国山川不在祠典者勿祠。** [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **洛阳宫鞠室灾。** 六月，洛阳宫鞠室灾。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **保塞鲜卑大人步度根与叛鲜卑大人轲比能私通。** 保塞鲜卑大人步度根与叛鲜卑大人轲比能私通，并州刺史毕轨表，辄出军以外威比能，内镇步度根。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **帝省表曰“步度根以爲比能所诱”。** 帝省表曰：「步度根以爲比能所诱，有自疑心。今轨出军，适使二部惊合爲一，何所威镇乎？」 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **促勑轨，以出军者慎勿越塞过句注也。** [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **比诏书到，轨以进军屯阴馆。** 比诏书到，轨以进军屯阴馆，遣将军苏尚、董弼追鲜卑。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **比能遣子将千余骑迎步度根部落。** 比能遣子将千余骑迎步度根部落，与尚、弼相遇，战于楼烦，二将败没。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **步度根部落皆叛出塞，与比能合寇边。** [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **遣骁骑将军秦朗将中军讨之。** 遣骁骑将军秦朗将中军讨之，虏乃走漠北。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **安定保塞匈奴大人胡薄居姿职等叛。** 秋九月，安定保塞匈奴大人胡薄居姿职等叛，司马宣王遣将军胡遵等追讨，破降之。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **步度根部落大人戴胡阿狼泥等诣并州降。** 冬十月，步度根部落大人戴胡阿狼泥等诣并州降，朗引军还。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **公孙渊杀孙权使者。** 十二月，公孙渊斩送孙权所派使张弥、许晏首，以渊爲大司马乐浪公。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **满宠移筑合肥新城。** 满宠主张将合肥城守军西移三十里以避江湖水势，朝廷采纳。孙权欲围新城而迟疑，满宠伏兵袭击上岸吴军。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **蜀军聚米于斜谷。** 诸葛亮命军队运粮于斜谷口，营建仓储。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **马忠平刘胄。** 刘胄起事，马忠击破。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **孙权遣张弥、许晏等册公孙渊为燕王。** 孙权不顾群臣劝谏，遣张弥等泛海送往册命、九锡与财货。 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **全琮攻六安而未分兵追捕。** 全琮率步骑五万攻六安，居民散走，诸将请分兵追逐。全琮判断利少而风险大，没有答应。 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **子愍王潜嗣，其年薨。** 青龙元年，子愍王潜嗣，其年去世。 [[25]](#sg-note-25)

<a id="sgz-event-27"></a>

<a id="sg-event-26"></a>

26. **曹衮被有司举奏，削邑两县。** 有司举奏曹衮，魏明帝起初考虑从轻，有司坚持，最终削去两县及七百五十户。 [[26]](#sg-note-26)

<a id="sgz-event-28"></a>

28. **曹彪因入朝违禁被削邑。** 有司奏曹彪违禁，明帝削三县一千五百户。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **孙权烧张昭门后和解。** 张昭仍称病，孙权火烧其门欲使出，后命灭火，诸子扶张昭，孙权载回宫并自责。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **刘劭主张暂缓讨受吴封的公孙渊。** 借公孙康斩袁尚兄弟及所闻难实，谏魏不宜拘计吏急出兵。 [[30]](#sgz-note-30)

<a id="sgz003-p-013-1"></a>

**[《三国志·明帝纪》裴注 013·1](../../sources/本地分卷/三国志/三国志-卷003.md#pei-013-1)**

> 魏書載詔曰昔先王之禮於功臣存則顯其爵祿没則祭于大烝故漢氏功臣祀於廟庭大魏元功之臣功勲優著終始休明者其皆依禮祀之於是以惇等配享之

**归年** 正文青龙元年五月壬申。注文引“故漢氏”是诏书中的前代制度，非233年发生的汉事。

### 10. 保塞鲜卑大人步度根与叛鲜卑大人轲比能私通

[返回正文第10条](#sg-event-10)

<a id="sg003-l183-e10"></a>

**[《三国志·明帝纪》](../../sources/本地分卷/三国志/三国志-卷003.md#p003)** · [仓内TXT L183](../../sources/本地分卷/三国志/三国志-卷003.md#l183)

> 保塞鮮卑大人步度根與叛鮮卑大人軻比能私通，并州刺史畢軌表，輒出軍以外威比能，內鎮步度根。

<a id="sg030-l1587-e10"></a>

**[《三国志·乌丸鲜卑东夷传》](../../sources/本地分卷/三国志/三国志-卷030.md#p002)** · [仓内TXT L1587](../../sources/本地分卷/三国志/三国志-卷030.md#l1587)

<a id="sgz003-b-183-1"></a>

**[《三国志·明帝纪》仓内原文 L183](../../sources/本地分卷/三国志/三国志-卷003.md#l183)**

> 保塞鮮卑大人步度根與叛鮮卑大人軻比能私通，

**释读** 依附魏的鲜卑首领步度根与已叛魏的鲜卑首领轲比能私下联络。

**归年** 本纪 L183 明载或承接青龙元年条。

<a id="sgz003-b-183-2"></a>

**[《三国志·明帝纪》仓内原文 L183](../../sources/本地分卷/三国志/三国志-卷003.md#l183)**

> 并州刺史畢軌表，輒出軍以外威比能，內鎮步度根。

**释读** 并州刺史毕轨表明要出兵对外威慑轲比能、对内镇抚步度根。

**归年** 本纪 L183 明载或承接青龙元年条。

<a id="sgz009-p-035-19"></a>

**[《三国志·诸夏侯曹传》裴注 035·19](../../sources/本地分卷/三国志/三国志-卷009.md#pei-035-19)**

> 時雜虜數為暴害吏民軌輙出軍擊鮮卑軻比能失利中䕶軍蒋濟表曰畢軌前失既往不咎但恐是後難可以再凡人材有長短不可彊成軌文雅志意自為美器今失并州換置他州若入居顯職不毁其徳於國事實善此安危之要唯聖恩察之

**释读** 鲜卑屡扰边，毕轨出兵击轲比能而失败；蒋济认为他文雅有才不宜强令治边，主张改州或入任显职。

**归年** 《明帝纪》及《通鉴》卷072 L402–417系青龙元年毕轨进军阴馆、部将被杀，其次才遣秦朗平定边患。蒋济表附兵败。

<a id="sgz030-b-1577-11"></a>

**[《三国志·乌丸鲜卑东夷传》仓内原文 L1577](../../sources/本地分卷/三国志/三国志-卷030.md#l1577)**

> 畢軌有陘北之敗。

**释读** 毕轨出兵，部将在陉北一带战败。

**归年** 下文青龙元年及《明帝纪》同年。

<a id="sgz030-b-1584-9"></a>

**[《三国志·乌丸鲜卑东夷传》仓内原文 L1584](../../sources/本地分卷/三国志/三国志-卷030.md#l1584)**

> 至青龍元年，比能誘步度根深結和親，於是步度根將泄歸泥及部衆悉保比能，寇鈔并州，殺略吏民。

**释读** 步度根率泄归泥和部众投轲比能，同叛并州。

**归年** 青龙元年；《明帝纪》同年步度根与轲比能私通。

<a id="sgz030-b-1587-4"></a>

**[《三国志·乌丸鲜卑东夷传》仓内原文 L1587](../../sources/本地分卷/三国志/三国志-卷030.md#l1587)**

> 至青龍元年，比能誘納步度根，使叛并州，與結和親，自勒萬騎迎其累重於陘北。并州刺史畢軌遣將軍蘇尚、董弼等擊之，比能遣子將騎與尚等會戰於樓煩，臨陣害尚、弼。

**释读** 轲比能迎步度根家眷及辎重，毕轨派苏尚、董弼接战，二将被杀。

**归年** 青龙元年；《明帝纪》毕轨追击与本传同役，楼烦为具体交战处。

<a id="sgz026-b-1377-1"></a>

**释读** 满宠说旧城临水利于吴兵而魏援难到，建议向西三十里选险地筑城，引敌离水。

**归年** 本传青龙元年，《通鉴》卷七十二将提出及批准系太和六年末，攻新城仍在233年，保留立议一年差异。

<a id="sgz026-b-1377-2"></a>

**[《三国志·满田牵郭传》仓内原文 L1377](../../sources/本地分卷/三国志/三国志-卷026.md#l1377)**

> 護軍將軍蔣濟議，以爲：「旣示天下以弱，且望賊煙火而壞城，此爲未攻而自拔。一至於此，劫略無限，必以淮北爲守。」帝未許。寵重表曰：「孫子言，兵者，詭道也。故能而示之以弱不能，驕之以利，示之以懾。此爲形實不必相應也。又曰『善動敵者形之』。今賊未至而移城卻內，此所謂形而誘之也。引賊遠水，擇利而動，舉得於外，則福生於內矣。」尚書趙咨以寵策爲長，詔遂報聽。

**释读** 蒋济以为撤城示弱，会使淮北承受劫掠。满宠引《孙子》论引敌远水，赵咨认为有利，曹叡准许。

**归年** 本传青龙元年；《通鉴》作232年末，参同条。

> 嘉禾二年，督步騎五萬征六安，六安民皆散走

<a id="sgz060-b-2855-1"></a>

**[《三国志·贺全吕周钟离传》仓内原文 L2855](../../sources/本地分卷/三国志/三国志-卷060.md#l2855)**

> 嘉禾二年，督步騎五萬征六安，六安民皆散走，諸將欲分兵捕之。

**释读** 全琮督五万步骑攻六安，当地民人逃散，诸将要分兵捕捉。

**归年** 本传嘉禾二年，《吴主传》同年征六安不克。

<a id="sgz060-b-2855-2"></a>

**[《三国志·贺全吕周钟离传》仓内原文 L2855](../../sources/本地分卷/三国志/三国志-卷060.md#l2855)**

> 琮曰：「夫乘危僥倖，舉不百全者，非國家大體也。今分兵捕民，得失相半，豈可謂全哉?縱有所獲，猶不足以弱敵而副國望也。如或邂逅，虧損非小，與其獲罪，琮寧以身受之。不敢徼功以負國也。」

**释读** 全琮认为分兵风险足以伤国，即使俘获人众也难削弱魏国，宁自受责，拒以侥幸邀功。

**归年** 同役军议。

<a id="sgz047-b-2308-7"></a>

**[《三国志·吴主传》仓内原文 L2308](../../sources/本地分卷/三国志/三国志-卷047.md#l2308)**

> 遣將軍全瓊征六安，皆不克還。

**释读** 孙权令全琮攻六安，未克而还。

**归年** 本纪作“全瓊”，《全琮传》嘉禾二年同役明确。

### 29. 孙权烧张昭门后和解

[返回正文第29条](#sgz-event-29)

<a id="sgz052-b-2475-5"></a>

**[《三国志·张顾诸葛步传》仓内原文 L2475](../../sources/本地分卷/三国志/三国志-卷052.md#l2475)**

> 權數慰謝昭，昭固不起，權因出過其門呼昭，昭辭疾篤。權燒其門，欲以恐之，昭更閉門戶。權使人滅火，住門良久，昭諸子共扶昭起，權載以還宮，深自克責。昭不得已，然後朝會。

**归年** 《通鉴》卷七十二接公孙渊杀使后；未载明确日。

<a id="sgz052-p-007-1"></a>

**[《三国志·张顾诸葛步传》裴注 007·1](../../sources/本地分卷/三国志/三国志-卷052.md#pei-007-1)**

> 習鑿齒曰張昭於是乎不臣矣夫臣人者三諌不從則奉身而退身茍不絶何忿懟之有且秦穆違諌卒霸西戎晉文暫怒終成大業遺誓以悔過見錄狐偃無怨絶之辭君臣道泰上下俱榮今權悔徃之非而求昭後益廻慮降心不逺而復是其善也昭為人臣不度權得道匡其後失夙夜匪懈以延來譽乃追忿不用歸罪於君閉戸拒命坐待焚滅豈不悖哉

**释读** 批评张昭谏不从而闭门赌气，认为孙权已回心求助，臣当尽力纠正后失。举秦穆公、晋文公遇谏事来说明。

**归年** 评论针对嘉禾二年册封公孙渊的君臣争执；与正文“孙权烧张昭门后和解”同事。

# 公元234年｜青龙二年

[← 公元233年](ce-0233.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元235年 →](ce-0235.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **山阳公刘协去世。** 魏青龙二年三月庚寅，山阳公去世。 [[1]](#hh-note-1)

<a id="hh-event-2"></a>

2. **自逊位至薨，十有四年，年五十四，谥孝献皇帝。** [[2]](#hh-note-2)

<a id="hh-event-3"></a>

3. **以汉天子礼仪葬於禅陵，置园邑令丞。** 八月壬申，以汉天子礼仪葬于禅陵，置园邑令丞。 [[3]](#hh-note-3)

<a id="sg-event-4"></a>

4. **太白犯荧惑。** 二年春二月乙未，太白犯荧惑。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **诏曰“鞭作官刑”。** 癸酉，诏曰：「鞭作官刑，所以纠慢怠也，而顷多以无辜死。其减鞭杖之制，着于令。」 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **大赦。** 己酉，大赦。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **大疫。** 夏四月，大疫。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **崇华殿灾。** [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **诏有司以太牢告祠文帝庙。** 丙寅，诏主管官员以太牢告祠文帝庙。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **追谥山阳公爲汉孝献皇帝。** 追谥山阳公爲汉孝献皇帝，葬以汉礼。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **诸葛亮出斜谷，与司马懿相持。** 诸葛亮出斜谷，屯于渭南。曹叡令司马懿据守待蜀军粮尽，再伺机追击。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **太白昼见。** 五月，太白昼见。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **孙权入居巢湖口，向合肥新城。** 孙权入居巢湖口，向合肥新城，又遣将陆议、孙韶各将万余人入淮、沔。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **征东将军满宠进军拒之。** 六月，征东将军满宠进军拒之。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **宠欲拔新城守，致贼寿春，帝不听，曰“昔汉光武遣兵县据略阳”。** 宠欲拔新城守，致贼寿春，帝不听，曰：「昔汉光武遣兵县据略阳，终以破隗嚣，先帝东置合肥，南守襄阳，西固祁山，贼来辄破于三城之下者，地有所必争也。纵权攻新城，必不能拔。勑各将领坚守，吾将自往征之，比至，恐权走也。」 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **帝亲御龙舟东征，权攻新城。** 秋七月壬寅，帝亲御龙舟东征，权攻新城，将军张頴等拒守力战，帝军未至数百里，权遁走，议、韶等亦退。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **群臣以爲大将军方与诸葛亮相持未解。** 群臣以爲大将军方与诸葛亮相持未解，车驾可西幸长安。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **帝曰“权走”。** 帝曰：「权走，亮胆破，大将军以制之，吾无忧矣。」 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **遂进军幸寿春，录诸将功。** 遂进军幸寿春，录各将领功，封赏各有差。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **大曜兵，飨六军。** 八月己未，大曜兵，飨六军，派使者持节犒劳合肥、寿春诸军。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **行还许昌宫。** 辛巳，行还许昌宫。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **诸葛亮去世后蜀军退兵。** 司马懿与诸葛亮相持多日。诸葛亮在军中去世后，蜀军撤退。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **月犯镇星及轩辕。** 冬十月乙丑，月犯镇星及轩辕。 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **月犯太白。** 戊寅，月犯太白。 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **京都地震，从东南来。** 十一月，京都地震，从东南来，隐隐有声，摇动屋瓦。 [[25]](#sg-note-25)

<a id="sg-event-26"></a>

26. **诏有司删定大辟，减死罪。** 十二月，诏主管官员删定大辟，减死罪。 [[26]](#sg-note-26)

<a id="sg-event-27"></a>

27. **卢毓任侍中。** 卢毓入朝为侍中，传中并载他建议统一法度和劝魏明帝容纳高堂隆直谏。 [[27]](#sg-note-27)

<a id="sg-event-28"></a>

28. **魏延与杨仪争兵。** 诸葛亮死后，魏延和杨仪争权交兵，魏延死，杨仪率军归成都。 [[28]](#sg-note-28)

<a id="sg-event-29"></a>

29. **吴壹督汉中、蒋琬任尚书令。** 吴壹为车骑将军督汉中，蒋琬领尚书令、统理国事。 [[29]](#sg-note-29)

<a id="sg-event-30"></a>

30. **诸葛亮葬定军山。** 遗言因山作坟，仅容棺材，衣殓从简。 [[30]](#sg-note-30)

<a id="sg-event-31"></a>

31. **李严去世。** 李严在听说诸葛亮去世之后病死。 [[31]](#sg-note-31)

<a id="sg-event-32"></a>

32. **刘琰被处死。** 刘琰疑妻与后主私通而殴打她；妻告发后，刘琰被处死，命妇入朝礼遂废止。 [[32]](#sg-note-32)

<a id="sg-event-33"></a>

33. **追諡后兄俨曰安城乡穆侯。** 青龙二年春，追諡后兄俨曰安城乡穆侯。 [[33]](#sg-note-33)

<a id="sg-event-34"></a>

34. **子哀王炳嗣，食邑二千五百户。** 青龙二年，子哀王炳嗣，食邑二千五百户。 [[34]](#sg-note-34)

<a id="sg-event-35"></a>

35. **私通宾客，为有司所奏。** 青龙二年，私通宾客，为主管官员所奏，赐干玺书诫诲之，曰： [[35]](#sg-note-35)

<a id="sg-event-36"></a>

36. **徽使官属挝寿张县吏，为有司所奏。** 青龙二年，徽使官属挝寿张县吏，为主管官员所奏。 [[36]](#sg-note-36)

<a id="sg-event-37"></a>

37. **更追改号諡。** 青龙二年，更追改号諡。 [[37]](#sg-note-37)

<a id="sg-event-38"></a>

38. **亮出武功，与瑾书曰“瞻今已八岁”。** 建兴十二年，亮出武功，与瑾书曰：「瞻今已八岁，聪慧可爱，嫌其早成，恐不为重器耳。」 [[38]](#sg-note-38)

<a id="sg-event-39"></a>

39. **诸葛恪领丹杨太守，讨平山越。** 嘉禾三年，诸葛恪领丹杨太守，讨平山越，以表领新安都尉，与恪参势。 [[39]](#sg-note-39)

<a id="sg-event-40"></a>

40. **权令岱领潘璋士众，屯陆口。** 嘉禾三年，权令岱领潘璋士众，屯陆口，后徙蒲圻。 [[40]](#sg-note-40)

<a id="sgz-event-41"></a>

41. **潘璋去世。** 潘璋在嘉禾三年去世。 [[41]](#sgz-note-41)

<a id="sgz-event-42"></a>

42. **蜀在诸葛亮卒后大赦。** 蜀在杨仪等归成都之后大赦。 [[42]](#sgz-note-42)

<a id="sgz-event-43"></a>

43. **向朗迁左将军，封显明亭侯。** 诸葛亮死后，向朗迁左将军，追论旧功，封显明亭侯、位特进。 [[43]](#sgz-note-43)

<a id="sgz-event-44"></a>

44. **诸葛亮卒后邓芝改任前军师等。** 邓芝为前军师、前将军，兼兖州刺史，封阳武亭侯。 [[44]](#sgz-note-44)

<a id="sgz-event-45"></a>

45. **张翼在诸葛亮卒后任前领军并受爵。** 张翼拜前领军，因前次讨刘胄的功劳封关内侯。 [[45]](#sgz-note-45)

<a id="sgz-event-46"></a>

46. **诸葛亮卒后吴增巴丘、蜀增永安守兵。** 吴忧魏趁势灭蜀，在巴丘增一万人，一可救援，一为可能的分割作准备；蜀也增永安军。 [[46]](#sgz-note-46)

<a id="sgz-event-47"></a>

47. **宗预奉使回应孙权对增兵的质问。** 孙权问既为盟友，蜀为何增白帝守军。宗预说吴增巴丘、蜀增白帝都是势所必然，孙权欣赏他的坦率。 [[47]](#sgz-note-47)

<a id="sgz-event-48"></a>

48. **诸葛亮卒后杨戏任尚书右选部郎。** 杨戏任尚书右选部郎，刺史蒋琬请他任治中从事史。 [[48]](#sgz-note-48)

<a id="sgz-event-49"></a>

49. **诸葛亮死后马齐任尚书。** 马齐改任尚书。 [[49]](#sgz-note-49)

<a id="sgz-event-50"></a>

50. **来敏在诸葛亮卒后回成都，任大长秋。** 诸葛亮死后来敏回成都，出任大长秋。 [[50]](#sgz-note-50)

<a id="sgz-event-51"></a>

51. **尹默在诸葛亮卒后还成都任太中大夫。** 随军返成都，任太中大夫。 [[51]](#sgz-note-51)

<a id="sgz-event-52"></a>

52. **孙奂卒而子孙承继任。** 孙奂四十岁去世，子孙承袭，以昭武中郎将统旧兵、领江夏。 [[52]](#sgz-note-52)

<a id="sgz-event-53"></a>

53. **曹偃承相王一支。** 曹偃于青龙二年继承，得邑两千五百户。 [[53]](#sgz-note-53)

<a id="sgz-event-54"></a>

54. **曹衮恢复先前削去的两县。** 明帝嘉其意，恢复曹衮封户。 [[54]](#sgz-note-54)

<a id="sgz-event-55"></a>

55. **魏明帝以私通宾客诫曹干。** 有司奏曹干私结宾客，明帝赐玺书诫勉。 [[55]](#sgz-note-55)

<a id="sgz-event-56"></a>

56. **魏大赦后归还曹彪被削封县。** 曹彪在大赦后恢复先前所削三县。 [[56]](#sgz-note-56)

<a id="sgz-event-57"></a>

57. **曹徽因打寿张县吏被削封，旋复县。** 曹徽遣属官殴打寿张县吏，有司奏明，魏削一县五百户，同年又恢复封县。 [[57]](#sgz-note-57)

<a id="sgz-event-58"></a>

58. **曹协改追封谥。** 魏改曹协的号谥，卷题称赞哀王。 [[58]](#sgz-note-58)

<a id="sgz-event-59"></a>

59. **曹赞奉曹蕤后，封昌乡公。** 以琅邪王之子曹赞承曹蕤之后。 [[59]](#sgz-note-59)

<a id="sgz-event-60"></a>

60. **潘濬平定五溪、还武昌。** 潘濬赏罚严明，历年军获以万数，此后武陵诸部衰弱，地方宁静。 [[60]](#sgz-note-60)

<a id="sgz003-p-016-5"></a>

**[《三国志·明帝纪》裴注 016·5](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-016-5)**

> 八月壬申葬于山陽國陵曰禪陵置園邑葬之日帝制錫衰弁絰哭之慟適孫桂氏鄉侯康嗣立為山陽公

**释读** 八月壬申以汉礼葬于山阳国，陵名禅陵、设园邑，曹叡身着丧服恸哭，刘协嫡孙桂氏乡侯刘康继为山阳公。

**归年** 《后汉书·献帝纪》明青龙二年八月壬申葬。刘康继封与葬同段，未单列纪日。

> 易稱『開國承家，小人勿用』，詩著『大車惟塵』之誡。自太祖受命創業，深睹治亂之源，鑒存亡之機，初封諸侯，訓以恭慎之至言，輔以天下之端士，常稱馬援之遺誡，重諸侯賓客交通之禁，乃使與犯妖惡同。夫豈以此薄骨肉哉？徒欲使子弟無過失之愆，士民無傷害之悔耳。高祖踐阼，祗慎萬機，申著諸侯不朝之令。朕感詩人常棣之作，嘉采菽之義，亦緣詔文曰『若有詔得詣京都』，故命諸王以朝聘之禮。而楚、中山並犯交通之禁，趙宗、戴捷咸伏其辜。近東平王復使屬官毆壽張吏，有司舉奏，朕裁削縣。（令）有司以曹纂、王喬等因九族時節，集會王家，或非其時，皆違禁防。朕惟王幼少有恭順之素，加受先帝顧命，欲崇恩禮，延乎後嗣，況近在王之身乎？且自非聖人，孰能無過？已詔有司宥王之失。古人有言：『戒慎乎其所不睹，恐懼乎其所弗聞，莫見乎隱，莫顯乎微，故君子慎其獨焉。』叔父茲率先聖之典，以纂乃先帝之遺命，戰戰兢兢，靖恭厥位，稱朕意焉。

**归年** 同年诏书；诏中回叙诸王事还见各人在本卷的小传。

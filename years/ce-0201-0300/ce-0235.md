<a id="sg-event-2"></a>

2. **复置朔方郡。** 己亥，复置朔方郡。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **京都大疫。** [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **皇太后崩。** 丁巳，皇太后崩。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **陨石于寿光县。** 乙亥，陨石于寿光县。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **葬文德郭后，营陵于首阳陵涧西。** 三月庚寅，葬文德郭后，营陵于首阳陵涧西，如终制。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **是时，大治洛阳宫。** 是时，大治洛阳宫，起昭阳、太极殿，筑緫章观。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **百姓失农时，直臣杨阜、高堂隆等各数切谏。** 百姓失农时，直臣杨阜、高堂隆等各数切谏，虽不能听，常优容之。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **洛阳崇华殿灾，八月庚午。** 秋七月，洛阳崇华殿灾，八月庚午，立皇子芳爲齐王，询爲秦王。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **行还洛阳宫。** 丁巳，行还洛阳宫。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **命有司复崇华，改名九龙殿。** 命主管官员复崇华，改名九龙殿。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **中山王衮薨。** 冬十月己酉，中山王衮去世。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **太白昼见。** 壬申，太白昼见。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **行幸许昌宫。** 十一月丁酉，行幸许昌宫。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **曹芳立为齐王。** 曹叡无嗣，收养曹芳、曹询，先立曹芳为齐王。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **王雄遣韩龙刺轲比能。** 幽州刺史王雄遣勇士韩龙刺杀鲜卑首领轲比能，改立其弟。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **杨仪废徙汉嘉。** 正月杨仪被废徙汉嘉。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **蒋琬为大将军。** 四月蒋琬升为大将军。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **吴准许以珠宝同魏换马。** 魏使希望以马易珠、翠羽等，孙权认为吴可用不急之物交换所需战马，准许交易。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **吕岱分兵讨李桓等。** 庐陵、东冶、南海多地同时起事，孙权命吕岱督刘纂、唐咨等分别进兵。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>



<a id="sg-event-22"></a>

22. **嘉薨，追赠光禄大夫。** 青龙三年，嘉薨，追赠光禄大夫，改封安国侯，增邑五百，并前千户，諡曰节侯。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **楷坐私遣官属诣中尚方作禁物。** 青龙三年，楷坐私遣官属诣中尚方作禁物，削县二千户。 [[23]](#sg-note-23)

<a id="sy-event-24"></a>

24. **曹范去世。** 曹范去世，谥悼公，无子。 [[24]](#sy-note-24)

<a id="sgz-event-25"></a>

25. **寿春一农妇自号登女祈福。** 寿春有一农人之妻自称天神派下、命为登女，说自己应保卫帝室、驱邪纳福。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **登女以水示疗，被安置于后宫。** 登女使人饮水或用水洗伤，有人好转，她由此获赐后宫馆舍及诏书褒扬。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **《魏氏春秋》称张掖玄川涌水，见石图。** 《魏氏春秋》说张掖删丹县金山玄川涨水，岸上现有龟形巨石和七匹石马，另有玉玦及鸟兽、天象和文字纹样；《世语》称还有鸡像。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **甄像去世，诸子受封。** 甄像死后赠卫将军，改封魏昌县、谥贞侯。子甄畅承爵，另外三子封列侯。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **郭表进封观津侯，郭详迁官。** 曹叡晋郭表为观津侯，增至千户，郭详迁驸马都尉。 [[29]](#sgz-note-29)

<a id="sgz003-p-018-2"></a>

**[《三国志·明帝纪》裴注 018·2](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-018-2)**

> 太后崩哀思哭泣

**释读** 郭太后去世，女子哀思哭泣。

**归年** 本纪直书青龙三年正月丁巳郭太后崩，见235年第4条。哀哭起于当时，延续到次片。

<a id="sgz005-b-320-4"></a>

**[《三国志·后妃传》仓内原文 L320](../../sources/本地分卷/三国志/三国志-卷005.md#l320)**

> 青龍三年春，後崩於許昌，以終制營陵，

**释读** 郭太后死于许昌，遗命依终制营陵。

**归年** 本传明青龙三年春，卷003载正月戊子。

<a id="sgz005-p-017-1"></a>

**[《三国志·后妃传》裴注 017·1](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-017-1)**

> 魏畧曰明帝既嗣立追痛甄后之葬故太后以憂暴崩甄后臨没以帝屬李夫人

**释读** 《魏略》说曹叡追念甄后丧葬，郭太后因忧而暴卒，并回叙甄氏临终托儿于李夫人。

**归年** 郭太后卒年依本纪和本传青龙三年春。李夫人托儿是221年甄后死前的追叙。

<a id="sgz005-p-017-5"></a>

**[《三国志·后妃传》裴注 017·5](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-017-5)**

> 帝知之心常懐忿數泣問甄后死狀郭后曰先帝自殺何以責問我且汝為人子可追讐死父為前母枉殺後母邪明帝怒遂逼殺之勅殯者使如甄后故事

**释读** 曹叡追问生母死状，郭太后以父母名分反诘，曹叡怒而逼死她，命殡敛如甄后。

**归年** 与《魏略》“忧暴崩”异，系郭太后卒葬的235年。对话仅依该书。

**[《三国志·明帝纪》](../../sources/摘录/三国志-卷003-明帝纪.md#p004)** · [仓内TXT L192](../../sources/本地分卷/三国志/三国志-卷003.md#l192)

> 三月庚寅，葬文德郭后，營陵於首陽陵澗西，如終制。

<a id="sgz005-b-320-5"></a>

**[《三国志·后妃传》仓内原文 L320](../../sources/本地分卷/三国志/三国志-卷005.md#l320)**

> 三月庚寅，葬首陽陵西。

**释读** 三月庚寅葬于首阳陵西。

**归年** 卷003载三月庚寅。

<a id="sgz005-p-017-2"></a>

**[《三国志·后妃传》裴注 017·2](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-017-2)**

> 及太后崩夫人乃説甄后見譖之禍不獲大歛被髪覆面帝哀恨流涕命殯葬太后皆如甄后故事

**释读** 李夫人向曹叡述甄后受害及非常殡敛，曹叡下令郭后也照甄后旧例殡敛。

**归年** 附在郭太后卒葬段，235年。甄后掩发的内容为所回忆的221年殡敛。

<a id="sgz005-p-017-6"></a>

**[《三国志·后妃传》裴注 017·6](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-017-6)**

> 魏書載哀䇿曰維青龍二年三月壬申皇太后梓宮啟殯將葬于首陽之西陵哀子皇帝叡親奉冊祖載遂親遣奠叩心擗踊號咷仰訴痛靈魂之遷幸悲容車之向路背三光以潛翳就黃壚而安厝嗚呼哀哉昔二女妃虞帝道以彰三母嬪周聖善彌光既多受祉享國延長哀哀慈妣興化閨房龍飛紫極作合聖皇不虞中年暴離災殃愍予小子㷀㷀摧傷魂雖永逝定省曷望嗚呼哀哉

**释读** 《魏书》载汉式哀册，述曹叡亲祭与哀痛，原注哀册开头写“青龙二年三月壬申”。

**归年** 不能把传正文和《明帝纪》同载的青龙三年戊子卒、三月庚寅葬改到234。哀册保留异年异日，系正文丧葬处互校。

**[《三国志·文帝纪》裴注 025·2](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-025-2)**

> 至明帝時始於漢南宫崇徳殿處起太極昭陽諸殿

**释读** 四库电子错页重出曹叡借汉南宫旧址兴建诸殿。

**归年** 《明帝纪》TXT L192–193明确青龙三年；与注025相同。

<a id="sgz003-p-019-1"></a>

**[《三国志·明帝纪》裴注 019·1](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-019-1)**

> 魏畧曰是年起太極諸殿築總章觀高十餘文建翔鳯於其上又於芳林園中起陂池楫櫂越歌又於列殿之北立八坊諸才人以次序處其中貴人夫人以上轉南附焉

**释读** 《魏略》说该年建太极殿等、筑高总章观置飞凤，在芳林园开池从事舟楫歌娱，又分设八坊安置才人，贵人、夫人以上按等级住在南边。

**归年** 本纪置青龙三年宫室条，“是年”指235；个别工程落成不一定均在当年。

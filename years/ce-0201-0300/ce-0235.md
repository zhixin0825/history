## 本年概述

曹叡继续营建洛阳宫，崇华殿失火后又建九龙殿，朝臣屡劝节用息役。郭太后去世，魏在首阳陵旁为她下葬。蜀汉废徙杨仪，蒋琬进任大将军。吴在南部动兵，并与魏议以珠宝换马。

2. **郭太后去世，魏葬太后并封甄、郭两家。** 正月丁巳，郭太后在许昌去世。三月壬申，梓宫启殡，曹叡亲自遣奠。庚寅，依遗制葬在首阳陵涧西。魏又进郭表为观津侯，增至千户，任郭详为驸马都尉。甄像同年去世，魏追赠卫将军、改封魏昌并谥贞侯，子甄畅承爵，另有三子受封。 [[2]](#sg-note-4)

3. **曹叡营建洛阳宫，崇华殿火后重建。** 魏大治洛阳宫，营昭阳殿、太极殿和总章观，在芳林园开池，又在北面建八坊安排宫人。徭役使百姓耽误农时。杨阜指出魏军正为防吴、蜀而四处调动，宫室耗费应当停止。他还请减省宫人，问御府宫人的数目，小吏按旧令不答，受了杖罚。高堂隆屡次进谏。王基以水能载舟覆舟为喻，劝曹叡在民力耗竭之前减役，也提醒他留意边将久握重兵。陈群请先劝农练兵，留足人力财力应付吴、蜀。曹叡以战后仍须兴建为由保留工程，经陈群再劝，才有所减省。高柔请朝廷把在建的殿舍做到足供朝宴，就让役夫返乡务农，并裁减后宫人数。曹叡听取孙礼的建议，下诏放民归农。监工李惠又请留役夫一月，孙礼直接赴工地按原诏遣散役夫，曹叡没有追究。殿中监擅自拘押兰台令史，卫臻奏请查处，指出营宫也不该让官员越职。曹叡又想削平北邙高地，建台远望孟津。辛毗说土工耗费人力，夷平丘陵也不利于防洪，曹叡于是作罢。七月，崇华殿失火。曹叡问是否应该祈禳，又提到汉武帝在柏梁台失火后重修宫殿。高堂隆劝他停役、减省宫人和宫室。八月丁巳，曹叡回洛阳，命重建宫殿。当时郡国报告见龙，崇华殿更名九龙殿。朝廷引谷水过殿前，高堂隆、秦朗与马钧争论古时是否真有指南车，曹叡命马钧试制，也让他用水力转动百戏的木偶和布景。陵霄阙初建时有鹊筑巢，高堂隆再次劝曹叡停工修政。王肃劝朝廷留一万名役夫轮换，其余遣归务农，并请将死刑交有司审理、公开罪状。蒋济也请勿在农时使役，并减省后宫。[两年后张茂等人仍在劝止宫中奢费](ce-0237.md#sgz-note-50)。 [[3]](#sg-note-7)

4. **曹芳封齐王，曹询封秦王。** 曹叡收养曹芳、曹询。八月庚午，二人同时封王，曹芳为齐王，曹询为秦王。 [[4]](#sg-note-15)

<a id="sg-event-12"></a>

5. **中山王曹衮去世。** 秋，中山王曹衮病重。曹叡遣太医诊治，命太妃与沛王曹林探视。曹衮嘱咐属官按朝令从俭办丧，又训诫世子敬重长幼、以礼待臣。冬十月己酉，曹衮去世，谥恭。曹林留至下葬，大鸿胪持节护丧，宗正吊祭，曹孚承袭。 [[5]](#sg-note-12)

12. **曹鉴受追谥。** 魏廷赐谥；本传并说其无子，封国已除。 [[12]](#sgz-note-34)

13. **寿春农妇自号登女，以水治病后入宫。** 寿春有一农人之妻自称天神派下、命为登女，说自己应保卫帝室、驱邪纳福。 登女使人饮水或用水洗伤，有人好转，她由此获赐后宫馆舍及诏书褒扬。 [[13]](#sgz-note-25)

<a id="sgz-event-38"></a>

14. **高柔请求准百姓捕鹿护田。** 禁地捕鹿当死，家产没官，告发有赏。鹿群却屡入田间践食禾苗，荥阳一带近乎无收。高柔请求解禁，准百姓捕鹿，又算出禁地内的虎、狼、狐每年吞食的鹿，说明长久不捕也难增加鹿群。 [[14]](#sgz-note-38)

## 辽西与魏吴边境

<a id="sg-event-2"></a>

15. **复置朔方郡。** 正月己亥，魏复设朔方郡。 [[15]](#sg-note-2)

<a id="sg-event-16"></a>

16. **王雄遣韩龙刺轲比能。** 幽州刺史王雄遣勇士韩龙刺杀鲜卑首领轲比能，继而改立轲比能的弟弟。鲜卑诸部相继离散、互相攻伐，有的远徙，有的向魏归附，北边袭扰一度减少。 [[16]](#sg-note-16)

<a id="sgz-event-35"></a>

17. **吴兵江北屯田，魏军秋破其田屯。** 孙权遣军农屯江北，满宠等至八月田熟遣兵击屯焚粮，朝廷嘉奖，把缴获分给将士。 [[17]](#sgz-note-35)

## 蜀、吴纪事

<a id="sg-event-17"></a>

18. **费祎密奏杨仪怨言，杨仪废徙后自杀。** 诸葛亮去世后，杨仪自认功劳在蒋琬之上，向费祎发怨言，称后悔当时未领军投魏。费祎密告。正月，杨仪被废为平民，徙汉嘉。到迁所后，他又上书，言辞激切；朝廷命郡里收捕，杨仪自杀。 [[18]](#sg-note-17)

<a id="sg-event-18"></a>

19. **蒋琬为大将军。** 四月蒋琬升为大将军。 [[19]](#sg-note-18)

<a id="sgz-event-30"></a>

20. **陈震去世。** 陈震卒于建兴十三年。 [[20]](#sgz-note-30)

<a id="sg-event-19"></a>

21. **吴准许以珠宝同魏换马。** 魏使希望以马易珠、翠羽等，孙权认为吴可用不急之物交换所需战马，准许交易。 [[21]](#sg-note-19)

<a id="sg-event-20"></a>

22. **吕岱分兵讨李桓等。** 庐陵李桓、路合，东冶随春和南海罗厉等先后作乱。孙权命吕岱督刘纂、唐咨等分别进兵。随春先降，吕岱授他偏将军，仍令他统领原部；其余战事续见[次年](ce-0236.md#sgz-note-25)。 [[22]](#sg-note-20)

<a id="sgz-event-37"></a>

23. **吴七月有雹。** 七月下雹。 [[23]](#sgz-note-37)

**[《三國志·后妃傳》裴注](../../拆分史书/三国志/卷005.md#edition-wei005-l64-1)** · [TXT L64](../../拆分史书/三国志/卷005.txt#L64)

> 魏略曰：明帝旣嗣立，追痛甄后之薨，故太后以憂暴崩。甄后臨沒，以帝屬李夫人。及太后崩，夫人乃說甄后見譖之禍，不獲大斂，被髮覆靣，帝哀恨流涕，命殯葬太后，皆如甄后故事。

**釋讀與歸年** 《魏略》说曹叡追痛生母之死，郭太后因忧惧暴崩。李夫人在郭太后死后才向曹叡述甄后遇害与殡殓受辱，曹叡命依甄后旧例办理；《资治通鉴》同记郭太后以忧殂。甄后临终托付是221年事，随本段回叙。

<a id="wei005-l64-2"></a>

**[《三國志·后妃傳》裴注](../../拆分史书/三国志/卷005.md#edition-wei005-l64-2)** · [TXT L64](../../拆分史书/三国志/卷005.txt#L64)

> 漢晉春秋曰：初，甄后之誅，由郭后之寵，及殯，令被髮覆面，以糠塞口，遂立郭后，使養明帝。帝知之，心常懷忿，數泣問甄后死狀。郭后曰：「先帝自殺，何以責問我？且汝爲人子，可追讎死父，爲前母枉殺後母邪？」明帝怒，遂逼殺之，勑殯者使如甄后故事。

**釋讀與歸年** 《汉晋春秋》则说郭后抚养曹叡，曹叡得知生母殡葬受辱后屡次追问，郭后答以先帝所为，曹叡遂逼死郭后并命照旧例殡殓。此说与《魏略》忧崩、死后方闻受辱之说有别，纪、传正文也未载逼死。段首附叙221年甄后之死及222年立郭后。

<a id="wei005-l64-3"></a>

**[《三國志·后妃傳》裴注](../../拆分史书/三国志/卷005.md#edition-wei005-l64-3)** · [TXT L64](../../拆分史书/三国志/卷005.txt#L64)

> 魏書載哀策曰：「維青龍三年三月壬申，皇太后梓宮啟殯，將葬于首陽之西陵。哀子皇帝叡親奉冊祖載，遂親遣奠，叩心擗踊，號咷仰訴，痛靈魂之遷幸，悲容車之向路，背三光以潛翳，就黃壚而安厝。嗚呼哀哉！昔二女妃虞，帝道以彰，三母嬪周，聖善彌光，旣多受祉，享國延長。哀哀慈妣，興化閏房，龍飛紫極，作合聖皇，不虞中年，暴離災殃。愍予小子，煢煢摧傷，魂雖永逝，定省曷望？嗚呼哀哉！」

**釋讀與歸年** 所用标点本《魏书》哀策作青龙三年三月壬申，所记为启殡、遣奠之日。传与《明帝纪》的三月庚寅为安葬之日。

**釋讀與歸年** 王基見宮室役民，援舟水、東野御馬二喻請節勞役，又以賈誼為例提醒擁兵諸將之患。[《資治通鑑》卷七十三](../../史书/025-资治通鉴/KR2b0007_073.txt#L138-L154)繫青龍三年，與曹叡營洛陽宮、諸臣進諫同條。

**釋讀與歸年** 曹叡想鏟平北芒高處、築臺望孟津，辛毗以勞費和防洪為由勸止，曹叡採納。[《資治通鑑》卷七十三](../../史书/025-资治通鉴/KR2b0007_073.txt#L93-L99)繫青龍三年，與洛陽營建同條。

**[《三國志·辛毗楊阜高堂隆傳》正文](../../拆分史书/三国志/卷025.md#edition-wei025-l52-1)** · [TXT L52](../../拆分史书/三国志/卷025.txt#L52)

> 阜又上疏欲省宮人諸不見幸者，乃召御府吏問後宮人數。吏守舊令，對曰：「禁密，不得宣露。」阜怒，杖吏一百，數之曰：「國家不與九卿爲密，反與小吏爲密乎？」帝聞而愈敬憚阜。

**釋讀與歸年** 楊阜請裁減宮人，詢御府吏宮人實數，對方依舊令不說，受杖一百，曹叡因而更敬憚楊阜。敘事無確年，沿既有年頁，附青龍三年大營洛陽、建八坊置宮人的相關政務，不定該次問話的年月。

<a id="wei025-l57-1"></a>

<a id="wei025-l58-1"></a>

**[《三國志·辛毗楊阜高堂隆傳》](../../拆分史书/三国志/卷025.md#edition-wei025-l56-1)** · [TXT L56](../../拆分史书/三国志/卷025.txt#L56) · [TXT L57（裴注）](../../拆分史书/三国志/卷025.txt#L57) · [TXT L58](../../拆分史书/三国志/卷025.txt#L58)

> 帝旣新作許宮，又營洛陽宮殿觀閣。阜上疏曰：「堯尚茅茨而萬國安其居，禹卑宮室而天下樂其業；及至殷、周，或堂崇三尺，度以九筵耳。古之聖帝明王，未有極宮室之高麗以彫弊百姓之財力者也。桀作琁室、象廊，紂爲傾宮、鹿臺，以喪其社稷，楚靈以築章華而身受其禍；秦始皇作阿房而殃及其子，天下叛之，二世而滅。夫不度萬民之力，以從耳目之欲，未有不亡者也。陛下當以堯、舜、禹、湯、文、武爲法則，夏桀、殷紂、楚靈、秦皇爲深誡。高高在上，實監后德。慎守天位，以承祖考，巍巍大業，猶恐失之。不夙夜敬止，允恭卹民，而乃自暇自逸，惟宮臺是侈是飾，必有顛覆危亡之禍。易曰：『豐其屋，蔀其家，闚其戶，閴其無人。』王者以天下爲家，言豐屋之禍，至於家無人也。方今二虜合從，謀危宗廟，十萬之軍，東西奔赴，邊境無一日之娛；農夫廢業，民有饑色。陛下不以是爲憂，而營作宮室，無有已時。使國亡而臣可以獨存，臣又不言也；
>
> **〔裴注〕**
> 臣松之以爲忠至之道，以亡己爲理。是以匡救其惡，不爲身計。而阜表云「使國亡而臣可以獨存，臣又不言也」，此則發憤爲己，豈爲國哉？斯言也，豈不傷讜烈之義，爲一表之病乎！
>
> **〔正文續〕**
> 君作元首，臣爲股肱，存亡一體，得失同之。孝經曰：『天子有爭臣七人，雖無道不失其天下。』臣雖駑怯，敢忘爭臣之義？言不切至，不足以感寤陛下。陛下不察臣言，恐皇祖烈考之祚，將墜于地。使臣身死有補萬一，則死之日，猶生之年也。謹叩棺沐浴，伏俟重誅。」奏御，天子感其忠言，手筆詔荅。

**釋讀與歸年** 許宮建後又營洛陽宮殿。楊阜疏陳殷、楚、秦奢建失國，吳蜀用兵時尤應顧民力。奏文續在下句，裴注夾在原處。[《資治通鑑》卷七十三](../../史书/025-资治通鉴/KR2b0007_073.txt#L105-L125)繫青龍三年。

**釋讀與歸年** 裴松之就疏中「使國亡而臣可以獨存，臣又不言也」一語辨忠臣諫爭不計己身。置於原奏相應句後。

**釋讀與歸年** 楊阜續以君臣一體、臣有諫爭之義，表明即使受罰也願進言。曹叡感其忠，親筆答詔。

<a id="wei025-l69-2"></a>

**[《三國志·辛毗楊阜高堂隆傳》正文](../../拆分史书/三国志/卷025.md#edition-wei025-l69-2)** · [TXT L69](../../拆分史书/三国志/卷025.txt#L69)

> 崇華殿災，詔問隆：「此何咎？於禮，寧有祈禳之義乎？」隆對曰：「夫災變之發，皆所以明教誡也，惟率禮脩德，可以勝之。易傳曰：『上不儉，下不節，孽火燒其室。』又曰：『君高其臺，天火爲災。』此人君苟飾宮室，不知百姓空竭，故天應之以旱，火從高殿起也。上天降鑒，故譴告陛下；陛下宜增崇人道，以荅天意。昔太戊有桑穀生於朝，武丁有雊雉登於鼎，皆聞災恐懼，側身脩德，三年之後，遠夷朝貢，故號曰中宗、高宗。此則前代之明鑒也。今案舊占，災火之發，皆以臺榭宮室爲誡。然今宮室之所以充廣者，實由宮人猥多之故。宜簡擇留其淑懿，如周之制，罷省其餘。此則祖乙之所以訓高宗，高宗之所以享遠號也。」詔問隆：「吾聞漢武帝時，栢梁災，而大起宮殿以厭之，其義云何？」隆對曰：「臣聞西京栢梁旣災，越巫陳方，建章是經，以厭火祥；乃夷越之巫所爲，非聖賢之明訓也。五行志曰：『栢梁災，其後有江充巫蠱也，衞太子事。』如志之言，越巫建章無所厭也。孔子曰：『災者脩類應行，精祲相感，以戒人君。』是以聖主覩災責躬，退而脩德，以消復之。今宜罷散民役。宮室之制，務從約節，內足以待風雨，外足以講禮儀。清埽所災之處，不敢於此有所立作，萐莆、嘉禾必生此地，以報陛下虔恭之德。豈可疲民之力，竭民之財！實非所以致符瑞而懷遠人也。」帝遂復崇華殿，時郡國有九龍見，故改曰九龍殿。

**釋讀與歸年** 崇華殿火後，曹叡問祈禳並舉漢武帝火後重建為例。高堂隆兩次答以修德、罷役、裁省宮人和宮室為宜。曹叡終重建，以諸郡報見龍而改名九龍殿。[《明帝紀》](../../拆分史书/三国志/卷003.txt#L87)、《資治通鑑》[卷七十三](../../史书/025-资治通鉴/KR2b0007_073.txt#L165-L185)把火災、重建、更名繫青龍三年。234年亦有崇華殿火，那次無重建改名之文。

<a id="wei025-l71-1"></a>

**[《三國志·辛毗楊阜高堂隆傳》正文](../../拆分史书/三国志/卷025.md#edition-wei025-l71-1)** · [TXT L71](../../拆分史书/三国志/卷025.txt#L71)

> 陵霄闕始構，有鵲巢其上，帝以問隆，對曰：「詩云『惟鵲有巢，惟鳩居之』。今興宮室，起陵霄闕，而鵲巢之，此宮室未成身不得居之象也。天意若曰，宮室未成，將有他姓制御之，斯乃上天之戒也。夫天道無親，惟與善人，不可不深防，不可不深慮。夏、商之季，皆繼體也，不欽承上天之明命，惟讒諂是從，廢德適欲，故其亡也忽焉。太戊、武丁，覩災竦懼，祗承天戒，故其興也勃焉。今若休罷百役，儉以足用，增崇德政，動遵帝則，除普天之所患，興兆民之所利，三王可四，五帝可六，豈惟殷宗轉禍爲福而已哉！臣備腹心，苟可以繁祉聖躬，安存社稷，臣雖灰身破族，猶生之年也。豈憚忤逆之災，而令陛下不聞至言乎？」於是帝改容動色。

**釋讀與歸年** 陵霄闕初起，有鵲作巢。高堂隆借《詩》勸曹叡停役修政，又警告新建宮室可能易姓而主，曹叡因而動容。[《資治通鑑》卷七十三](../../史书/025-资治通鉴/KR2b0007_073.txt#L190-L199)繫於青龍三年重建九龍殿之後。本傳緊接「是歲」下敘236年彗星，也可能將兩事視作同年；本處從《通鑑》的營宮次第並附此疑。

<a id="wei024-l67-1"></a>

**[《三國志·韓崔高孫王傳》正文](../../拆分史书/三国志/卷024.md#edition-wei024-l67-1)** · [TXT L67](../../拆分史书/三国志/卷024.txt#L67)

> 後大興殿舍，百姓勞役；廣采衆女，充盈後宮；後宮皇子連夭，繼嗣未育。柔上疏曰：「二虜狡猾，潛自講肄，謀動干戈，未圖束手；宜畜養將士，繕治甲兵，以逸待之。而頃興造殿舍，上下勞擾；若使吳、蜀知人虛實，通謀并勢，復俱送死，甚不易也。昔漢文惜十家之資，不營小臺之娛；去病慮匈奴之害，不遑治第之事。況今所損者非惟百金之費，所憂者非徒北狄之患乎？可粗成見所營立，以充朝宴之儀。訖罷作者，使得就農。二方平定，復可徐興。昔軒轅以二十五子，傳祚彌遠；周室以姬國四十，歷年滋多。陛下聦達，窮理盡性，而頃皇子連多夭逝，熊羆之祥又未感應。羣下之心，莫不悒戚。周禮，天子后妃以下百二十人，嬪嬙之儀，旣以盛矣。竊聞後庭之數，或復過之，聖嗣不昌，殆能由此。臣愚以爲可妙簡淑媛，以備內官之數，其餘盡遣還家。且以育精養神，專靜爲寶。如此，則螽斯之徵，可庶而致矣。」帝報曰：「知卿忠允，乃心王室，輒克昌言；他復以聞。」

**釋讀與歸年** 曹叡大興宮室並廣選宮人。高柔上疏勸量成現役後讓百姓歸農，以備吳蜀，又勸裁後庭人數。帝稱其忠而令此後仍陳意見。《資治通鑑》所錄部分奏文繫青龍三年，這裡保留全部奏答。[《通鑑》卷七十三](../../史书/025-资治通鉴/KR2b0007_073.txt#L73-L85)。

> 青龍中，營治宮室，百姓失農時。羣上疏曰：「禹承唐、虞之盛，猶卑宮室而惡衣服，況今喪亂之後，人民至少，比漢文、景之時，不過一大郡。
>
> **〔裴注〕**
> 臣松之案：漢書地理志云：元始二年，天下戶口最盛，汝南郡爲大郡，有三十餘萬戶。則文、景之時不能如是多也。案晉太康三年地記，晉戶有三百七十七萬，吳、蜀戶不能居半。以此言之，魏雖始承喪亂，方晉亦當無乃大殊。長文之言，於是爲過。
>
> **〔正文續〕**
> 加邊境有事，將士勞苦，若有水旱之患，國家之深憂也。且吳、蜀未滅，社稷不安。宜及其未動，講武勸農，有以待之。今舍此急而先宮室，臣懼百姓遂困，將何以應敵？昔劉備自成都至白水，多作傳舍，興費人役，太祖知其疲民也。今中國勞力，亦吳、蜀之所願。此安危之機也，惟陛下慮之。」帝荅曰：「王者宮室，亦宜並立。滅賊之後，但當罷守耳，豈可復興役邪？是故君之職，蕭何之大略也。」羣又曰：「昔漢祖唯與項羽爭天下，羽已滅，宮室燒焚，是以蕭何建武庫、太倉，皆是要急，然猶非其壯麗。今二虜未平，誠不宜與古同也。
>
> **〔裴注〕**
> 孫盛曰：周禮，天子之宮，有斲礲之制。然質文之飾，與時推移。漢承周、秦之弊，宜敦簡約之化，而何崇飾宮室，示侈後嗣。此乃武帝千門萬戶所以大興，豈無所復增之謂邪？況乃魏氏方有吳、蜀之難，四海罹塗炭之艱，而述蕭何之過議，以爲令軌，豈不惑於大道而昧得失之辨哉？使百代之君眩於奢儉之中，何之由矣。詩云：「斯言之玷，不可爲也。」其斯之謂乎！
>
> **〔正文續〕**
> 夫人之所欲，莫不有辭，況乃天王，莫之敢違。前欲壞武庫，謂不可不壞也；後欲置之，謂不可不置也。若必作之，固非臣下辭言所屈；若少留神，卓然回意，亦非臣下之所及也。漢明帝欲起德陽殿，鍾離意諫，即用其言，後乃復作之；殿成，謂羣臣曰：『鍾離尚書在，不得成此殿也。』夫王者豈憚一臣，蓋爲百姓也。今臣曾不能少凝聖聽，不及意遠矣。」帝於是有所減省。

**釋讀與歸年** 青龙中魏治宫室、扰农时，陈群先以禹俭、魏经战乱人口少进谏。下文裴注与奏疏正文相间，按TXT同组连读。

**釋讀與歸年** 裴松之以[《汉书·地理志》](../../拆分史书/汉书/卷028.txt)元始二年汝南户口、晋太康三年地记的户数为对照，认为陈群把魏人口说成汉代一个大郡属于言过其实。两处年份是用来比较的统计年份。胡三省注[《资治通鉴》卷七十三](../../史书/025-资治通鉴/KR2b0007_073.txt#L39-L45)另参景元四年魏、蜀合计户数，认为陈群此言有据。两注所比年代和户数各异。

**釋讀與歸年** 陈群接着主张先修武备、劝农、应对吴蜀。曹叡以战后仍需营建为由坚持兴宫，举萧何为例；陈群指出萧何在统一后先建武库、太仓，魏时情势不同。下有孙盛注及疏文余段。

**釋讀與歸年** 孙盛评萧何治宫已为后人奢侈张本，更不赞成魏在吴蜀未平时援此为大营宫室的先例。

**釋讀與歸年** 陈群再以汉明帝欲建德阳殿、曾听钟离意进谏为例，希望曹叡回心。曹叡稍减工程规模。传称青龙中；[《明帝纪》](../../拆分史书/三国志/卷003.txt#L86-L87)和[《资治通鉴》卷七十三](../../史书/025-资治通鉴/KR2b0007_073.txt#L35-L64)可将大治洛阳宫及相连谏议系于235年，数次奏答具体日期未载。

> 景初中，外勤征役，內務宮室，怨曠者多，而年糓饑儉。濟上疏曰：「陛下方當恢崇前緒，光濟遺業，誠未得高枕而治也。今雖有十二州，至於民數，不過漢時一大郡。二賊未誅，宿兵邊陲，且耕且戰，怨曠積年。宗廟宮室，百事草創，農桑者少，衣食者多，今其所急，唯當息耗百姓，不至甚弊。弊攰之民，儻有水旱，百萬之衆，不爲國用。凡使民必須農隙，不奪其時。夫欲大興功之君，先料其民力而燠休之。句踐養胎以待用，昭王恤病以雪仇，故能以弱燕服彊齊，羸越滅勁吳。今二敵不攻不滅，不事即侵，當身不除，百世之責也。以陛下聖明神武之略，舍其緩者，專心討賊，臣以爲無難矣。又歡娛之躭，害於精爽；神太用則竭，形太勞則弊。願大簡賢妙，足以充『百斯男』者。其宂散未齒，且悉分出，務在清靜。」詔曰：「微護軍，吾弗聞斯言也。」

**[《三國志·鍾繇華歆王朗傳》正文](../../拆分史书/三国志/卷013.md#edition-wei013-l116-2)** · [TXT L116](../../拆分史书/三国志/卷013.txt#L116)

> 景初間，宮室盛興，民失農業，期信不敦，刑殺倉卒。肅以疏曰：「大魏承百王之極，生民無幾，干戈未戢，誠宜息民而惠之以安靜遐邇之時也。夫務畜積而息疲民，在於省傜役而勤稼穡。今宮室未就，功業未訖，運漕調發，轉相供奉。是以丁夫疲於力作，農者離其南畒，種穀者寡，食穀者衆，舊穀旣沒，新穀莫繼。斯則有國之大患，而非備豫之長策也。今見作者三四萬人，九龍可以安聖體，其內足以列六宮，顯陽之殿，又向將畢，惟泰極已前，功夫尚大，方向盛寒，疾疢或作。誠願陛下發德音，下明詔，深愍役夫之疲勞，厚矜兆民之不贍，取常食廩之士，非急要者之用，選其丁壯，擇留萬人，使一朞而更之，咸知息代有日，則莫不恱以即事，勞而不怨矣。計一歲有三百六十萬夫，亦不爲少。當一歲成者，聽且三年。分遣其餘，使皆即農，無窮之計也。倉有溢粟，民有餘力：以此興功，何功不立？以此行化，何化不成？夫信之於民，國家大寶也。仲尼曰：『自古皆有死，民非信不立。』夫區區之晉國，微微之重耳，欲用其民，先示以信，是故原雖將降，顧信而歸，用能一戰而霸，于今見稱。前車駕當幸洛陽，發民爲營，有司命以營成而罷。旣成，又利其功力，不以時遣。有司徒營其目前之利，不顧經國之體。臣愚以爲自今已後，儻復使民，宜明其令，使必如期。若有事以次，寧復更發，無或失信。凡陛下臨時之所行刑，皆有罪之吏，宜死之人也。然衆庶不知，謂爲倉卒。故願陛下下之於吏而暴其罪。鈞其死也，無使汙于宮掖而爲遠近所疑。且人命至重，難生易殺，氣絕而不續者也，是以聖賢重之。孟軻稱殺一無辜以取天下，仁者不爲也。漢時有犯蹕驚乘輿馬者，廷尉張釋之奏使罰金，文帝恠其輕，而釋之曰：『方其時，上使誅之則已。今下廷尉。廷尉，天下之平也，一傾之，天下用法皆爲輕重，民安所措其手足？』臣以爲大失其義，非忠臣所宜陳也。廷尉者，天子之吏也，猶不可以失平，而天子之身，反可以惑謬乎？斯重於爲己，而輕於爲君，不忠之甚也。周公曰：『天子無戲言；言則史書之，工誦之，士稱之。』言猶不戲，而况行之乎？故釋之之言不可不察，周公之戒不可不法也。」

### 5. 中山王曹衮去世

[返回正文第5条](#sg-event-12)

<a id="wei020-l44-3"></a>

**[《三國志·武文世王公傳》正文](../../拆分史书/三国志/卷020.md#edition-wei020-l44-3)** · [TXT L44](../../拆分史书/三国志/卷020.txt#L44)

> 三年秋，衮得疾病，詔遣太醫視疾，殿中、虎賁齎手詔、賜珍膳相屬，又遣太妃、沛王林並就省疾。衮疾困，勑令官屬曰：「吾寡德忝寵，大命將盡。吾旣好儉，而聖朝著終誥之制，爲天下法。吾氣絕之日，自殯及葬，務奉詔書。昔衞大夫蘧瑗葬濮陽，吾望其墓，常想其遺風，願託賢靈以弊髮齒，營吾兆域，必往從之。禮：男子不卒婦人之手。亟以時成東堂。」堂成，名之曰遂志之堂，輿疾往居之。又令世子曰：「汝幼少，未聞義方，早爲人君，但知樂，不知苦；不知苦，必將以驕奢爲失也。接大臣，務以禮。雖非大臣，老者猶宜荅拜。事兄以敬，恤弟以慈；兄弟有不良之行，當造膝諫之。諫之不從，流涕喻之；喻之不改，乃白其母。若猶不改，當以奏聞，并辭國土。與其守寵罹禍，不若貧賤全身也。此亦謂大罪惡耳，其微過細故，當掩覆之。嗟爾小子，慎脩乃身，奉聖朝以忠貞，事太妃以孝敬。閨闈之內，奉令于太妃；閫閾之外，受教於沛王。無怠乃心，以慰予靈。」其年薨。詔沛王林留訖葬，使大鴻臚持節典護喪事，宗正弔祭，贈賵甚厚。凡所著文章二萬餘言，才不及陳思王而好與之侔。子孚嗣。

**釋讀與歸年** 青龙三年秋曹衮病重，曹叡遣太医并派人赐膳，令太妃和沛王曹林看望。曹衮遵终诰从俭，愿葬于濮阳蘧瑗墓旁，病中移入遂志堂，并以守礼、敬亲、规谏兄弟等事戒世子。曹衮本年薨，曹林监护至葬；朝廷命大鸿胪典护、宗正吊祭，子曹孚嗣。文章二万余言为全传总计。[《明帝纪》](../../拆分史书/三国志/卷003.txt#L87)明卒日在冬十月己酉。

### 14. 高柔请求准百姓捕鹿护田

[返回正文第14条](#sgz-event-38)

<a id="wei024-l76-1"></a>

<a id="wei024-l77-1"></a>

**[《三國志·韓崔高孫王傳》](../../拆分史书/三国志/卷024.md#edition-wei024-l76-1)** · [TXT L76](../../拆分史书/三国志/卷024.txt#L76) · [TXT L77（裴注）](../../拆分史书/三国志/卷024.txt#L77)

> 是時，殺禁地鹿者身死，財產沒官，有能覺告者厚加賞賜。柔上疏曰：「聖王之御世，莫不以廣農爲務，儉用爲資。夫農廣則穀積，用儉則財畜，畜財積穀而有憂患之虞者，未之有也。古者，一夫不耕，或爲之饑；一婦不織，或爲之寒。中閒已來，百姓供給衆役，親田者旣減，加頃復有獵禁，羣鹿犯暴，殘食生苗，處處爲害，所傷不貲。民雖障防，力不能禦。至如熒陽左右，周數百里，歲略不收，元元之命，實可矜傷。方今天下生財者甚少，而麋鹿之損者甚多。卒有兵戎之役，凶年之災，將無以待之。惟陛下覽先聖之所念，愍稼穡之艱難，寬放民間，使得捕鹿，遂除其禁，則衆庶久濟，莫不恱預矣。」
>
> **〔裴注〕**
> 魏名臣奏載柔上疏曰：「臣深思陛下所以不早取此鹿者，誠欲使極蕃息，然後大取以爲軍國之用。然臣竊以爲今鹿但有日耗，終無從得多也。何以知之？今禁地廣輪且千餘里，臣下計無慮其中有虎大小六百頭，狼有五百頭，狐萬頭。使大虎一頭三日食一鹿，一虎一歲百二十鹿，是爲六百頭虎一歲食七萬二千頭鹿也。使十狼日共食一鹿，是爲五百頭狼一歲共食萬八千頭鹿。鹿子始生，未能善走，使十狐一日共食一子，比至健走一月之間，是爲萬狐一月共食鹿子三萬頭也。大凡一歲所食十二萬頭。其鵰鶚所害，臣置不計。以此推之，終無從得多，不如早取之爲便也。」

**釋讀與歸年** 獵禁嚴峻，捕禁地鹿者死且沒財，賞告人。高柔說群鹿踐害禾苗，熒陽周邊近乎顆粒無收，請准捕鹿以護農。[《資治通鑑》卷七十三](../../史书/025-资治通鉴/KR2b0007_073.txt#L84-L94)把此議繫青龍三年；傳文寫在公孫晃案之後，以「是時」帶過，並沒有明記年份。

**釋讀與歸年** 裴注《魏名臣奏》所錄另一疏，按虎、狼、狐捕食所舉數字推算，每年約食十二萬頭鹿，勸趁早捕取。與本傳禁鹿之疏同一議題；注文未載確年。

<a id="sgz024-b-1302-1"></a>

[本卷同事原句](#wei024-l76-1)。

**归年** 《资治通鉴》卷七十三系青龙三年。

### 27. 张掖玄川涨水，传有石图

[返回正文第27条](#sgz-event-27)

**异文与补证** 《魏氏春秋》还记七匹石马、玉玦、鸟兽及天象图形，《世语》另有鸡像。

**《明帝紀》互見** [TXT 第88行第2段](../../拆分史书/三国志/卷003.md#edition-wei003-l88-2) · [TXT 第88行第3段](../../拆分史书/三国志/卷003.md#edition-wei003-l88-3) · [TXT 第88行第4段](../../拆分史书/三国志/卷003.md#edition-wei003-l88-4)

<a id="wei003-l88-1"></a>

**[《三國志·明帝紀》裴注](../../拆分史书/三国志/卷003.md#edition-wei003-l88-1)** · [TXT L88](../../拆分史书/三国志/卷003.txt#L88)

> 魏氏春秋曰：是歲張掖郡刪丹縣金山玄川溢涌，寶石負圖，狀象靈龜，廣一丈六尺，長一丈七尺一寸，圍五丈八寸，立于川西。有石馬七，其一仙人騎之，其一羈絆，其五有形而不善成。有玉匣關蓋於前，上有玉字，玉玦二，璜一。麒麟在東，鳳鳥在南，白虎在西，犧牛在北，馬自中布列四面，色皆蒼白。其南有五字，曰「上上三天王」；又曰「述大金，大討曹，金但取之，金立中，大金馬一匹在中，大吉開壽，此馬甲寅述水」。凡「中」字六，「金」字十；又有若八卦及列宿孛彗之象焉。世語曰：又有一雞象。

**釋讀與歸年** 《魏氏春秋》以“是歲”记张掖删丹县玄川水涨、石上纹饰；《世语》另增一鸡。此年见石的说法与次年《张臶传》所录辛亥诏宣示石图可区分。[《资治通鉴》卷073第236至249行](../../史书/025-资治通鉴/KR2b0007_073.txt#L236-L249)汇录两地名说。

<a id="sgz003-p-020-1"></a>

[本卷同事原句](#wei003-l88-1)。

**归年** 本注在青龙三年条末以“是歲”归235；236年第16条《高堂隆传》保存次年正式诏书中的相似祥瑞报道，年份及地点表述可互校，以此注明异年，不把各异说当多次发现。

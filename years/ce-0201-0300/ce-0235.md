6. **葬文德郭后，营陵于首阳陵涧西。** 三月庚寅，葬文德郭后，营陵于首阳陵涧西，如终制。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **是时，大治洛阳宫。** 是时，大治洛阳宫，起昭阳、太极殿，筑緫章观。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **百姓失农时，直臣杨阜、高堂隆等各数切谏。** 百姓失农时，直臣杨阜、高堂隆等各数切谏，虽不能听，常优容之。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **七月洛阳崇华殿灾。** 秋七月，七月洛阳崇华殿灾，立皇子芳爲齐王，询爲秦王。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **行还洛阳宫。** 丁巳，行还洛阳宫。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **重建崇华殿改名九龙，马钧奉诏制器。** 崇华殿火灾后，曹叡命重建，改名九龙殿。《魏略》还记引谷水过殿、命马钧造司南车及水转百戏，具体完工日期未详。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **中山王衮薨。** 冬十月己酉，中山王衮去世。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **太白昼见。** 壬申，太白昼见。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **行幸许昌宫。** 十一月丁酉，行幸许昌宫。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **曹芳立为齐王。** 曹叡无嗣，收养曹芳、曹询，先立曹芳为齐王。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **王雄遣韩龙刺轲比能。** 幽州刺史王雄遣勇士韩龙刺杀鲜卑首领轲比能，改立其弟。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **费祎密奏杨仪怨言，杨仪废徙汉嘉。** 诸葛亮去世后，杨仪自认功劳在蒋琬之上，向费祎发怨言，称后悔当时未领军投魏。费祎密告。正月，杨仪被废，徙汉嘉。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **蒋琬为大将军。** 四月蒋琬升为大将军。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **吴准许以珠宝同魏换马。** 魏使希望以马易珠、翠羽等，孙权认为吴可用不急之物交换所需战马，准许交易。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **吕岱分兵讨李桓等。** 庐陵、东冶、南海多地同时起事，孙权命吕岱督刘纂、唐咨等分别进兵。 [[20]](#sg-note-20)

<a id="sg-event-22"></a>

22. **嘉薨，追赠光禄大夫。** 青龙三年，嘉薨，追赠光禄大夫，改封安国侯，增邑五百，并前千户，諡曰节侯。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **楷坐私遣官属诣中尚方作禁物。** 青龙三年，楷坐私遣官属诣中尚方作禁物，削县二千户。 [[23]](#sg-note-23)

<a id="sgz-event-32"></a>

<a id="sy-event-24"></a>

24. **曹范去世。** 曹范去世，谥悼公，无子。 [[24]](#sy-note-24)

<a id="sgz-event-25"></a>

25. **寿春一农妇自号登女祈福。** 寿春有一农人之妻自称天神派下、命为登女，说自己应保卫帝室、驱邪纳福。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **登女以水示疗，被安置于后宫。** 登女使人饮水或用水洗伤，有人好转，她由此获赐后宫馆舍及诏书褒扬。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **张掖玄川涨水，传有石图。** 张掖删丹县的玄川涨水，传说水边出现了龟形大石，上有文字和纹样。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **甄像去世，诸子受封。** 甄像死后赠卫将军，改封魏昌县、谥贞侯。子甄畅承爵，另外三子封列侯。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **郭表进封观津侯，郭详迁官。** 曹叡晋郭表为观津侯，增至千户，郭详迁驸马都尉。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **陈震去世。** 陈震卒于建兴十三年。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **曹宇入朝。** 曹宇应召入朝。 [[31]](#sgz-note-31)

<a id="sgz-event-33"></a>

33. **曹寻继曹协后。** 儿子曹寻继承曹协一支，后来谥殇王。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **曹鉴受追谥。** 魏廷赐谥；本传并说其无子，封国已除。 [[34]](#sgz-note-34)

<a id="sgz-event-35"></a>

35. **吴兵江北屯田，魏军秋破其田屯。** 孙权遣军农屯江北，满宠等至八月田熟遣兵击屯焚粮，朝廷嘉奖，把缴获分给将士。 [[35]](#sgz-note-35)

<a id="sgz-event-36"></a>

36. **王肃谏营宫室、劝守信慎刑。** 宫室工程繁兴使民离农，工期失信，明帝临时处刑；王肃上疏称战争未停应休民。 [[36]](#sgz-note-36)

<a id="sgz-event-37"></a>

37. **吴七月有雹。** 七月下雹。 [[37]](#sgz-note-37)

<a id="sgz-event-38"></a>

38. **高柔请求准百姓捕鹿护田。** 高柔指出，鹿入田间践食禾苗，百姓畏禁而不能驱捕，建议准捕。 [[38]](#sgz-note-38)

**释读** 曹叡追问生母死状，郭太后以父母名分反诘，曹叡怒而逼死她，命殡敛如甄后。

### 7. 是时，大治洛阳宫

[返回正文第7条](#sg-event-7)

<a id="sgz025-b-1337-1"></a>

**[《三国志·辛毗杨阜高堂隆传》仓内原文 L1337](../../sources/本地分卷/三国志/三国志-卷025.md#l1337)**

> 阜又上疏欲省宮人諸不見幸者，乃召御府吏問後宮人數。吏守舊令，對曰：「禁密，不得宣露。」阜怒，杖吏一百，數之曰：「國家不與九卿爲密，反與小吏爲密乎？」帝聞而愈敬憚阜。

**释读** 杨阜请求裁减不受召见的宫人，因御府吏拒报人数而杖责他。

**归年** 《资治通鉴》卷七十三在青龙三年大兴洛阳宫室一段记此事。

<a id="sg003-l193-e7"></a>

**[《三国志·明帝纪》](../../sources/本地分卷/三国志/三国志-卷003.md#p004)** · [仓内TXT L193](../../sources/本地分卷/三国志/三国志-卷003.md#l193)

> 是時，大治洛陽宮，起昭陽、太極殿，築緫章觀。

<a id="sgz002-p-025-2"></a>

**[《三国志·文帝纪》裴注 025·2](../../sources/本地分卷/三国志/三国志-卷002.md#pei-025-2)**

> 至明帝時始於漢南宫崇徳殿處起太極昭陽諸殿

**释读** 裴松之说曹叡在汉旧南宫崇德殿所在修建太极、昭阳诸殿。

**归年** 《明帝纪》TXT L192–193明确青龙三年兴建昭阳、太极诸殿。

<a id="sgz002-p-027-2"></a>

**[《三国志·文帝纪》裴注 027·2](../../sources/本地分卷/三国志/三国志-卷002.md#pei-027-2)**

> 至明帝時始於漢南宫崇徳殿處起太極昭陽諸殿

**释读** 四库电子错页重出曹叡借汉南宫旧址兴建诸殿。

**归年** 《明帝纪》TXT L192–193明确青龙三年；与注025相同。

<a id="sgz003-p-019-1"></a>

**[《三国志·明帝纪》裴注 019·1](../../sources/本地分卷/三国志/三国志-卷003.md#pei-019-1)**

> 魏畧曰是年起太極諸殿築總章觀高十餘文建翔鳯於其上又於芳林園中起陂池楫櫂越歌又於列殿之北立八坊諸才人以次序處其中貴人夫人以上轉南附焉

**释读** 《魏略》说该年建太极殿等、筑高总章观置飞凤，在芳林园开池从事舟楫歌娱，又分设八坊安置才人，贵人、夫人以上按等级住在南边。

**归年** 本纪置青龙三年宫室条，“是年”指235；个别工程落成不一定均在当年。

<a id="sgz027-b-1430-1"></a>

**[《三国志·徐胡二王传》仓内原文 L1430](../../sources/本地分卷/三国志/三国志-卷027.md#l1430)**

> 明帝盛脩宮室，百姓勞瘁。基上疏曰：「臣聞古人以水喻民，曰『水所以載舟，亦所以覆舟』。故在民上者，不可以不戒懼。夫民逸則慮易，苦則思難，是以先王居之以約儉，俾不至於生患。昔顏淵雲東野子之御，馬力盡矣而求進不已，是以知其將敗。今事役勞苦，男女離曠，願陛下深察東野之弊，留意舟水之喻，息奔駟於未盡，節力役於未困。昔漢有天下，至孝文時唯有同姓諸侯，而賈誼憂之曰：『置火積薪之下而寢其上，因謂之安也。』今寇賊未殄，猛將擁兵，檢之則無以應敵，乆之則難以遺後，當盛明之世，不務以除患，若子孫不競，社稷之憂也。使賈誼復起，必深切於曩時矣。」

**释读** 王基以水载舟覆舟、马力已尽而强驱为喻，劝节役；再引贾谊「积薪」议，指出强将坐镇则防患宜早，以免留后世。

**归年** 《通鉴》卷七十三青龙三年同录疏，《明帝纪》同年大修洛阳宫。

**[《三国志·辛毗杨阜高堂隆传》仓内原文 L1345](../../sources/本地分卷/三国志/三国志-卷025.md#l1345)**

> 夫災變之發，皆所以明教誡也，惟率禮脩德，可以勝之。易傳曰：『上不儉，下不節，孽火燒其室。』又曰：『君高其臺，天火爲災。』此人君苟飾宮室，不知百姓空竭，故天應之以旱，火從高殿起也。上天降鑒，故譴告陛下；陛下宜增崇人道，以荅天意。昔太戊有桑穀生於朝，武丁有雊雉登於鼎，皆聞災恐懼，側身脩德，三年之後，遠夷朝貢，故號曰中宗、高宗。此則前代之明鑒也。

**释读** 高堂隆说灾为天戒，应节宫修德，举太戊武丁闻灾修德、远夷入朝为例。

**归年** 承青龙三年崇华殿火。

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 前車駕當幸洛陽，發民爲營，有司命以營成而罷。旣成，又利其功力，不以時遣。有司徒營其目前之利，不顧經國之體。

**释读** 上次建车驾营，有司许工成即罢而贪其劳力不遣，责其只图眼前。

**归年** 此段奏书回忆，发民筑营的年月无确记。

<a id="sgz013-b-673-9"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 臣愚以爲自今已後，儻復使民，宜明其令，使必如期。若有事以次，寧復更發，無或失信。

**释读** 今后发役令当准时，再有事便另征，莫失信。

**归年** 同奏。

<a id="sgz013-b-673-10"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 凡陛下臨時之所行刑，皆有罪之吏，宜死之人也。然衆庶不知，謂爲倉卒。故願陛下下之於吏而暴其罪。鈞其死也，無使汙於宮掖而爲遠近所疑。

**释读** 临时处刑者纵有死罪，公众难知，宜交有司公示，免在宫中擅刑引疑。

**归年** 同奏。

<a id="sgz013-b-673-11"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 且人命至重，難生易殺，氣絕而不續者也，是以聖賢重之。孟軻稱殺一無辜以取天下，仁者不爲也。

**释读** 人命难生易杀，孟子以杀一个无辜而取天下亦不得为。

**归年** 同奏。

<a id="sgz013-b-673-12"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 漢時有犯蹕驚乘輿馬者，廷尉張釋之奏使罰金，文帝恠其輕，而釋之曰：『方其時，上使誅之則已。今下廷尉。廷尉，天下之平也，一傾之，天下用法皆爲輕重，民安所措其手足？』

**释读** 转引汉文帝时有人犯警跸惊马，张释之判罚金并对皇帝称廷尉法度贵公。

**归年** 同奏内史例。

<a id="sgz013-b-673-13"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 臣以爲大失其義，非忠臣所宜陳也。廷尉者，天子之吏也，猶不可以失平，而天子之身，反可以惑謬乎？斯重於爲己，而輕於爲君，不忠之甚也。

**释读** 认为张释之说皇帝可以先杀而廷尉不宜枉判，实际上对君宽纵而不忠。

**归年** 同奏。

<a id="sgz013-b-673-14"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 周公曰：『天子無戲言；言則史書之，工誦之，士稱之。』言猶不戲，而況行之乎？故釋之之言不可不察，周公之戒不可不法也。」

**释读** 引周公天子不戏言，更不可任意刑杀。

**归年** 同奏。

### 38. 高柔请求准百姓捕鹿护田

[返回正文第38条](#sgz-event-38)

<a id="sgz024-b-1302-1"></a>

**[《三国志·韩崔高孙王传》仓内原文 L1302](../../sources/本地分卷/三国志/三国志-卷024.md#l1302)**

> 是時，殺禁地鹿者身死，財產沒官，有能覺告者厚加賞賜。柔上疏曰：「聖王之御世，莫不以廣農為務，儉用為資。夫農廣則穀積，用儉則財畜，畜財積穀而有憂患之虞者，未之有也。古者，一夫不耕，或為之饑；一婦不織，或為之寒。中閒已來，百姓供給衆役，親田者旣減，加頃復有獵禁，羣鹿犯暴，殘食生苗，處處為害，所傷不貲。民雖障防，力不能禦。至如熒陽左右，周數百里，歲略不收，元元之命，實可矜傷。方今天下生財者甚少，而麋鹿之損者甚多。卒有兵戎之役，凶年之災，將無以待之。惟陛下覽先聖之所念，愍稼穡之艱難，寬放民間，使得捕鹿，遂除其禁，則衆庶久濟，莫不恱預矣。」

**释读** 高柔请求变通禁苑捕鹿的禁令，以保护农田。

**归年** 《资治通鉴》卷七十三系青龙三年。

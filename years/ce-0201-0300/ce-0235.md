<a id="sgz003-p-019-1"></a>

**[《三国志·明帝纪》裴注 019·1](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-019-1)**

> 魏畧曰是年起太極諸殿築總章觀高十餘文建翔鳯於其上又於芳林園中起陂池楫櫂越歌又於列殿之北立八坊諸才人以次序處其中貴人夫人以上轉南附焉

**释读** 《魏略》说该年建太极殿等、筑高总章观置飞凤，在芳林园开池从事舟楫歌娱，又分设八坊安置才人，贵人、夫人以上按等级住在南边。

**归年** 本纪置青龙三年宫室条，“是年”指235；个别工程落成不一定均在当年。

<a id="sgz027-b-1430-1"></a>

**[《三国志·徐胡二王传》仓内原文 L1430](../../sources/本地分卷/三国志/三国志-卷027.md#l1430)**

> 明帝盛脩宮室，百姓勞瘁。基上疏曰：「臣聞古人以水喻民，曰『水所以載舟，亦所以覆舟』。故在民上者，不可以不戒懼。夫民逸則慮易，苦則思難，是以先王居之以約儉，俾不至於生患。昔顏淵雲東野子之御，馬力盡矣而求進不已，是以知其將敗。今事役勞苦，男女離曠，願陛下深察東野之弊，留意舟水之喻，息奔駟於未盡，節力役於未困。昔漢有天下，至孝文時唯有同姓諸侯，而賈誼憂之曰：『置火積薪之下而寢其上，因謂之安也。』今寇賊未殄，猛將擁兵，檢之則無以應敵，乆之則難以遺後，當盛明之世，不務以除患，若子孫不競，社稷之憂也。使賈誼復起，必深切於曩時矣。」

**释读** 王基以水载舟覆舟、马力已尽而强驱为喻，劝节役；再引贾谊「积薪」议，指出强将坐镇则防患宜早，以免留后世。

**归年** 《通鉴》卷七十三青龙三年同录疏，《明帝纪》同年大修洛阳宫。

<a id="sgz024-b-1298-1"></a>

**[《三国志·韩崔高孙王传》仓内原文 L1298](../../sources/本地分卷/三国志/三国志-卷024.md#l1298)**

> 後大興殿舍，百姓勞役；廣采衆女，充盈後宮；後宮皇子連夭，繼嗣未育。

**释读** 宫室劳役广兴，后宫多人而皇子连夭。

**归年** 《明帝纪》和《通鉴》青龙三年载大营宫室；下各分片与这一轮营建同见《通鉴》。

**释读** 高堂隆说灾为天戒，应节宫修德，举太戊武丁闻灾修德、远夷入朝为例。

> 又令世子曰：「汝幼少，未聞義方，早為人君，但知樂，不知苦；不知苦，必將以驕奢為失也。接大臣，務以禮。雖非大臣，老者猶宜答拜。事兄以敬，恤弟以慈；兄弟有不良之行，當造膝諫之。諫之不從，流涕喻之；喻之不改，乃白其母。若猶不改，當以奏聞，並辭國土。與其守寵罹禍，不若貧賤全身也。此亦謂大罪惡耳，其微過細故，當掩覆之。嗟爾小子，慎脩乃身，奉聖朝以忠貞，事太妃以孝敬。閨闈之內，奉令於太妃；閫閾之外，受教於沛王。無怠乃心，以慰予靈。」

**释读** 大修、漕运和调发疲民，种粮少、食粮多，旧谷耗而新谷不继是大患。

**归年** 同奏。

<a id="sgz013-b-673-4"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 今見作者三四萬人，九龍可以安聖體，其內足以列六宮，顯陽之殿，又向將畢，惟泰極已前，功夫尚大，方向盛寒，疾疢或作。

**释读** 三四万人在作，九龙等殿够用，显阳将毕，太极殿前尚多，需要防寒疫。

**归年** 同奏。

<a id="sgz013-b-673-5"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 誠願陛下發德音，下明詔，深愍役夫之疲勞，厚矜兆民之不贍，取常食廩之士，非急要者之用，選其丁壯，擇留萬人，使一朞而更之，咸知息代有日，則莫不恱以即事，勞而不怨矣。

**释读** 请从吃官粮的非急用之人择丁壮万人，一年轮代，使知休息之期而乐于赴工。

**归年** 同奏。

<a id="sgz013-b-673-6"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 計一歲有三百六十萬夫，亦不爲少。當一歲成者，聽且三年。分遣其餘，使皆即農，無窮之計也。倉有溢粟，民有餘力：以此興功，何功不立？以此行化，何化不成？

**释读** 原一年工程许三年，其余归农，积蓄与民力增加以后自能兴功。

**归年** 同奏。

<a id="sgz013-b-673-7"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 夫信之於民，國家大寶也。仲尼曰：『自古皆有死，民非信不立。』夫區區之晉國，微微之重耳，欲用其民，先示以信，是故原雖將降，顧信而歸，用能一戰而霸，於今見稱。

**释读** 援民无信不立及晋文公守信得原，说明国家对民信义是重宝。

**归年** 同奏。

<a id="sgz013-b-673-8"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 前車駕當幸洛陽，發民爲營，有司命以營成而罷。旣成，又利其功力，不以時遣。有司徒營其目前之利，不顧經國之體。

**释读** 上次建车驾营，有司许工成即罢而贪其劳力不遣，责其只图眼前。

**归年** 此段奏书回忆，发民筑营的年月无确记。

<a id="sgz013-b-673-9"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 臣愚以爲自今已後，儻復使民，宜明其令，使必如期。若有事以次，寧復更發，無或失信。

**释读** 今后发役令当准时，再有事便另征，莫失信。

**归年** 同奏。

<a id="sgz013-b-673-10"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 凡陛下臨時之所行刑，皆有罪之吏，宜死之人也。然衆庶不知，謂爲倉卒。故願陛下下之於吏而暴其罪。鈞其死也，無使汙於宮掖而爲遠近所疑。

**释读** 临时处刑者纵有死罪，公众难知，宜交有司公示，免在宫中擅刑引疑。

**归年** 同奏。

<a id="sgz013-b-673-11"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 且人命至重，難生易殺，氣絕而不續者也，是以聖賢重之。孟軻稱殺一無辜以取天下，仁者不爲也。

**释读** 人命难生易杀，孟子以杀一个无辜而取天下亦不得为。

**归年** 同奏。

<a id="sgz013-b-673-12"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 漢時有犯蹕驚乘輿馬者，廷尉張釋之奏使罰金，文帝恠其輕，而釋之曰：『方其時，上使誅之則已。今下廷尉。廷尉，天下之平也，一傾之，天下用法皆爲輕重，民安所措其手足？』

**释读** 转引汉文帝时有人犯警跸惊马，张释之判罚金并对皇帝称廷尉法度贵公。

**归年** 同奏内史例。

<a id="sgz013-b-673-13"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 臣以爲大失其義，非忠臣所宜陳也。廷尉者，天子之吏也，猶不可以失平，而天子之身，反可以惑謬乎？斯重於爲己，而輕於爲君，不忠之甚也。

**释读** 认为张释之说皇帝可以先杀而廷尉不宜枉判，实际上对君宽纵而不忠。

**归年** 同奏。

<a id="sgz013-b-673-14"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L673](../../sources/本地分卷/三国志/三国志-卷013.md#l673)**

> 周公曰：『天子無戲言；言則史書之，工誦之，士稱之。』言猶不戲，而況行之乎？故釋之之言不可不察，周公之戒不可不法也。」

**释读** 引周公天子不戏言，更不可任意刑杀。

**归年** 同奏。

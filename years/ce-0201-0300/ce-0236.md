# 公元236年｜魏青龙四年／蜀建兴十四年／吴嘉禾五年

[← 公元235年](ce-0235.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元237年 →](ce-0237.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **太白复昼见，月犯太白。** 四年春二月，太白复昼见，月犯太白，又犯轩辕一星，入太微而出。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **置崇文观，徵善属文者以充之。** 夏四月，置崇文观，徵善属文者以充之。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **司徒董昭薨。** 五月乙卯，司徒董昭去世。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **肃慎氏献楛矢。** 丁巳，肃慎氏献楛矢。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **诏曰“有虞氏画象而民弗犯”。** 六月壬申，诏曰：「有虞氏画象而民弗犯，周人刑错而不用。朕从百王之末，追望上世之风，邈乎何相去之远？法令滋章，犯者弥多，刑罚愈衆，而奸不可止。往者桉大辟之条，多所蠲除，思济生民之命，此朕之至意也。而郡国毙狱，一岁之中尚过数百，岂朕训导不醇，俾民轻罪，将苛法犹存，爲之陷穽乎？主管官员其议狱缓死，务从宽简，及乞恩者，或辞未出而狱以报断，非所以究理尽情也。其令廷尉及天下狱官，诸有死罪具狱以定，非谋反及手杀人，亟语其亲治，有乞恩者，使与奏当文书俱上，朕将思所以全之。其布告天下，使明朕意。」 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **高句骊王宫斩送孙权使胡衞等首。** 秋七月，高句骊王宫斩送孙权使胡衞等首，诣幽州。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **太白犯轩辕大星。** 甲寅，太白犯轩辕大星。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **行还洛阳宫。** 冬十月己卯，行还洛阳宫。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **有星孛于大辰，乙酉。** 甲申，有星孛于大辰，乙酉，又孛于东方。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **彗星见，犯宦者天纪星。** 十一月己亥，彗星见，犯宦者天纪星。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **司空陈群薨。** 十二月癸巳，司空陈群去世。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **行幸许昌宫。** 乙未，行幸许昌宫。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **刘禅至湔及迁武都氐户。** 四月刘禅至湔观汶水，随后返成都；徙苻健及氐人四百余户入成都。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **吴铸当五百大钱。** 嘉禾五年春，吴铸当五百大钱，令吏民缴铜并计铜付值，又定盗铸之法。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **吴辅吴将军张昭去世。** 二月辅吴将军张昭去世。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **诏书，「张掖郡玄川溢涌。** 青龙四年辛亥诏书：「张掖郡玄川溢涌，激波奋荡，宝石负图，状像灵龟，宅于川西，嶷然磐峙，仓质素章，麟凤龙马，焕炳成形，文字告命，粲然着明。太史令高堂隆上言：古皇圣帝所未尝蒙，实有魏之祯命，东序之世宝。」 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **徐宣去世。** 徐宣于本年去世。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **诏「欲得有才智文章，谋虑渊深。** 青龙四年，诏「欲得有才智文章，谋虑渊深，料远若近，视昧而察，筹不虚运，策弗徒发，端一小心，清修密静，乹乹不解，志尚在公者，无限年齿，勿拘贵贱，卿校已上各举一人」。 [[18]](#sg-note-18)

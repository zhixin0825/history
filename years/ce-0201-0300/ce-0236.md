## 本年概述

魏徵召善作文辭和謀略之士，設崇文觀。高句麗王斬送孫權的使者，蜀漢遷武都氐戶，吳鑄當五百大錢。年內各地還記有旱情、彗星與其他報聞。

## 魏廷人事與文教政令

<a id="sg-event-2"></a>

<a id="sg-event-18"></a>

1. **魏设崇文观，诏征文才与谋略之士。** 四月，魏设崇文观，征召善于作文的人。曹叡另诏公卿和列校各荐一人，要求有才智、能预料军国大事、廉慎尽职，年龄和出身均不限。司马懿举荐王昶。 [[1]](#sg-note-2)

<a id="sg-event-3"></a>

2. **司徒董昭薨。** 五月乙卯，司徒董昭去世。 [[2]](#sg-note-3)

<a id="sg-event-5"></a>

3. **曹叡诏令复核死罪乞恩案。** 六月壬申，曹叡指出，朝廷虽已删减死刑，郡国每年仍有数百人毙于狱中，有些犯人的乞恩书还未发出，案件已判决。他命廷尉和各地狱官在死罪审定后，除谋反、亲手杀人外，及时告知犯人亲属。如有乞恩书，随拟判文书一并上报。 [[3]](#sg-note-5)

<a id="sg-event-8"></a>

4. **行还洛阳宫。** 冬十月己卯，行还洛阳宫。 [[4]](#sg-note-8)

<a id="sg-event-11"></a>

5. **司空陈群薨。** 十二月癸巳，司空陈群去世。 [[5]](#sg-note-11)

<a id="sg-event-12"></a>

6. **行幸许昌宫。** 乙未，行幸许昌宫。 [[6]](#sg-note-12)

<a id="sg-event-16"></a>

7. **魏颁诏以张掖石图为祥瑞。** 张掖上年报玄川水涨、出现有纹图的巨石。太史令高堂隆以为魏朝祥瑞，曹叡在青龙四年辛亥颁诏通告各地。任县令于绰问张臶，张臶认为此石若有征兆，也当关乎将来。 [[7]](#sg-note-16)

<a id="sg-event-17"></a>

8. **徐宣去世。** 徐宣于本年去世。 [[8]](#sg-note-17)

<a id="sy-event-20"></a>

9. **曹阐承嗣曹整。** 魏封曹范弟东安乡公曹阐为郿公，承嗣曹整。 [[9]](#sy-note-20)

<a id="sgz-event-21"></a>

10. **改封甄氏亲属。** 甄逸、甄俨均改封魏昌侯，旧谥保留；又封甄俨妻刘氏、追封甄逸妻张氏。 [[10]](#sgz-note-21)

<a id="sgz-event-22"></a>

11. **改封文德郭后的先世。** 改封父郭永和母董氏，追谥三个兄弟，使者奉策以太牢祭祀。 [[11]](#sgz-note-22)

<a id="sgz-event-23"></a>

12. **追封毛后母夏氏。** 毛后母夏氏追封野王君。 [[12]](#sgz-note-23)

<a id="sgz-event-24"></a>

13. **曹偃死而无嗣，国除。** 曹偃去世，无子，撤封国。 [[13]](#sgz-note-24)

<a id="sgz-event-30"></a>

14. **卢毓请曹叡包容高堂隆直谏。** 高堂隆因建宫屡谏使曹叡不悦，卢毓援明君应使群臣直言及立谏鼓之意，劝容直士。 [[14]](#sgz-note-30)

## 高句麗、蜀與吳

<a id="sg-event-4"></a>

15. **肃慎献楛矢。** 五月丁巳，肃慎献楛矢。 [[15]](#sg-note-4)

<a id="sg-event-6"></a>

16. **高句骊王宫斩送吴使首级。** 七月，高句骊王宫斩杀孙权使者胡卫等，将首级送到魏幽州。此前孙吴已数次通使高句骊，参见[辽东交涉的前因](ce-0237.md#sg-note-18)。 [[16]](#sg-note-6)

<a id="sg-event-13"></a>

17. **刘禅至湔及迁武都氐户。** 四月刘禅至湔观汶水，随后返成都；徙苻健及氐人四百余户入成都。 [[17]](#sg-note-13)

<a id="sg-event-14"></a>

18. **吴铸当五百大钱。** 嘉禾五年春，吴铸当五百大钱，令吏民缴铜并计铜付值，又定盗铸之法。 [[18]](#sg-note-14)

<a id="sg-event-15"></a>

19. **吴辅吴将军张昭去世。** 三月，辅吴将军张昭去世，年八十一。张昭遗命用素棺，以常服入殓。孙权身着素服亲往吊唁，谥张昭为文侯。长子张承此前已封侯，由少子张休袭爵。 [[19]](#sg-note-15)

<a id="sgz-event-25"></a>

20. **吴军斩获李桓、罗厉。** 上年孙权命吕岱分部讨平多郡叛乱。春，吾粲擒获李桓，唐咨擒获罗厉等，叛军首领被杀，首级传至国都。孙权下诏嘉奖吕岱，称李桓反复起事、多年未能擒获，如今诸郡可安，并命他裁定奖赏。 [[20]](#sgz-note-25)

<a id="sgz-event-29"></a>

21. **鄱阳彭旦起事。** 鄱阳彭旦等反。 [[21]](#sgz-note-29)

### 3. 曹叡诏令复核死罪乞恩案

[返回正文第3条](#sg-event-5)

<a id="sg003-l196-e5"></a>

<a id="wei003-l92-1"></a>

**[《三國志·明帝紀》正文](../../拆分史书/三国志/卷003.md#edition-wei003-l92-1)** · [TXT L92](../../拆分史书/三国志/卷003.txt#L92)

> 六月壬申，詔曰：「有虞氏畫象而民弗犯，周人刑錯而不用。朕從百王之末，追望上世之風，邈乎何相去之遠？法令滋章，犯者彌多，刑罰愈衆，而姦不可止。往者桉大辟之條，多所蠲除，思濟生民之命，此朕之至意也。而郡國斃獄，一歲之中尚過數百，豈朕訓導不醇，俾民輕罪，將苛法猶存，爲之陷穽乎？有司其議獄緩死，務從寬簡，及乞恩者，或辭未出而獄以報斷，非所以究理盡情也。其令廷尉及天下獄官，諸有死罪具獄以定，非謀反及手殺人，亟語其親治，有乞恩者，使與奏當文書俱上，朕將思所以全之。其布告天下，使明朕意。」

**釋讀與歸年** 青龙四年六月壬申，曹叡说前次删减大辟后，郡国每年仍有数百人毙于狱中。死刑案已审定时，除谋反及亲手杀人外，应告知犯人的亲属；若有求恩书，与拟判文书一并上报。参看[234年删定大辟](ce-0234.md#ce234-note-19)。

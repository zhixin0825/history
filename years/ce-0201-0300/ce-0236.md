## 本年概述

魏徵召善作文辭和謀略之士，設崇文觀。高句麗王斬送孫權的使者，蜀漢遷武都氐戶，吳鑄當五百大錢。年內各地還記有旱情、彗星與其他報聞。

## 魏廷人事與文教政令

<a id="sg-event-2"></a>

<a id="sg-event-18"></a>

1. **魏设崇文观，诏征文才与谋略之士。** 四月，魏设崇文观，征召善于作文的人。曹叡另诏公卿和列校各荐一人，要求有才智、能预料军国大事、廉慎尽职，年龄和出身均不限。司马懿举荐王昶。 [[1]](#sg-note-2)

<a id="sg-event-3"></a>

2. **司徒董昭薨。** 五月乙卯，司徒董昭去世。 [[2]](#sg-note-3)

<a id="sg-event-5"></a>

3. **曹叡诏令复核死罪乞恩案。** 六月壬申，曹叡指出，朝廷虽已删减死刑，郡国每年仍有数百人毙于狱中，有些犯人的乞恩书还未发出，案件已判决。他命廷尉和各地狱官在死罪审定后，除谋反、亲手杀人外，及时告知犯人亲属。如有乞恩书，随拟判文书一并上报。 [[3]](#sg-note-5)

<a id="sg-event-8"></a>

4. **曹叡回洛阳宫。** 十月己卯，曹叡回洛阳宫。 [[4]](#sg-note-8)

<a id="sg-event-11"></a>

5. **司空陈群去世。** 十二月癸巳，司空陈群去世，谥靖侯，由儿子陈泰承袭。曹叡念其旧功，从封邑里析出户数，另封其一子为列侯。 [[5]](#sg-note-11)

<a id="sg-event-12"></a>

6. **曹叡到许昌宫。** 十二月乙未，曹叡到许昌宫。 [[6]](#sg-note-12)

<a id="sg-event-16"></a>

7. **魏颁诏以张掖石图为祥瑞。** 张掖上年报玄川水涨、出现有纹图的巨石。太史令高堂隆以为魏朝祥瑞，曹叡在青龙四年辛亥颁诏通告各地。任县令于绰问张臶，张臶认为此石若有征兆，也当关乎将来。 [[7]](#sg-note-16)

<a id="sg-event-17"></a>

8. **徐宣去世。** 徐宣此前曾请退休，曹叡未准。本年徐宣去世，遗命用布衣、疏巾和素常服饰入殓。曹叡称他历仕三朝、可托孤寄命，追赠车骑将军，准以三公之礼安葬，谥贞。子徐钦袭爵。 [[8]](#sg-note-17)

<a id="sy-event-20"></a>

9. **曹阐承嗣曹整。** 魏封曹范弟东安乡公曹阐为郿公，承嗣曹整。 [[9]](#sy-note-20)

<a id="sgz-event-21"></a>

<a id="sgz-event-22"></a>

<a id="sgz-event-23"></a>

10. **魏追封甄、郭、毛三家亲属。** 魏改封甄逸、甄俨为魏昌侯，仍用旧谥，封甄俨的世妇刘氏为东乡君，追封甄逸的世妇张氏为安喜君。改封郭永为观津敬侯、董氏为堂阳君，追谥郭浮、郭都、郭成，并遣使以太牢祭祀。毛皇后的母亲夏氏追封野王君。 [[10]](#sgz-note-21)

<a id="sgz-event-24"></a>

11. **曹偃死而无嗣，国除。** 曹偃去世，无子，撤封国。 [[11]](#sgz-note-24)

<a id="sgz-event-30"></a>

12. **卢毓请曹叡包容高堂隆直谏。** 高堂隆因建宫屡谏使曹叡不悦，卢毓援明君应使群臣直言及立谏鼓之意，劝容直士。 [[12]](#sgz-note-30)

## 高句麗、蜀與吳

<a id="sg-event-4"></a>

13. **肃慎献楛矢。** 五月丁巳，肃慎献楛矢。 [[13]](#sg-note-4)

<a id="sg-event-6"></a>

14. **高句骊王宫斩送吴使首级。** 七月，高句骊王宫斩杀孙权使者胡卫等，将首级送到魏幽州。此前孙吴已数次通使高句骊，参见[辽东交涉的前因](ce-0237.md#sg-note-18)。 [[14]](#sg-note-6)

<a id="sg-event-13"></a>

15. **刘禅至湔及迁武都氐户。** 四月，刘禅到湔县登观阪，看汶水，十日后返成都。武都氐王苻健率众归蜀，蜀廷把他和随行的四百余户安置在广都。他的弟弟率另外四百户投魏。 蜀曾派张尉迎接苻健，迟迟未返；张嶷判断是其弟另有去向而耽搁，后来传回的消息印证了这一判断。 [[15]](#sg-note-13)

<a id="sg-event-14"></a>

16. **吴铸当五百大钱。** 嘉禾五年春，吴铸当五百大钱，令吏民缴铜并计铜付值，又定盗铸之法。 [[16]](#sg-note-14)

<a id="sg-event-15"></a>

17. **吴辅吴将军张昭去世。** 三月，辅吴将军张昭去世，年八十一。张昭遗命用素棺，以常服入殓。孙权身着素服亲往吊唁，谥张昭为文侯。长子张承此前已封侯，由少子张休袭爵。 [[17]](#sg-note-15)

<a id="sgz-event-25"></a>

18. **吴军斩获李桓、罗厉。** 上年孙权命吕岱分部讨平多郡叛乱。春，吾粲擒获李桓，唐咨擒获罗厉等，叛军首领被杀，首级传至国都。孙权下诏嘉奖吕岱，称李桓反复起事、多年未能擒获，如今诸郡可安，并命他裁定奖赏。 [[18]](#sgz-note-25)

<a id="sgz-event-29"></a>

19. **鄱阳彭旦起事。** 鄱阳彭旦等反。 [[19]](#sgz-note-29)

## 《晋书》补记

<a id="jin001-event-l34"></a>

24. **司马懿献白鹿，曹叡以周公故事褒答。** 司马懿得到白鹿，献给曹叡。曹叡以周公辅成王时的素雉进贡作比，说他承担分陕以西的重任而献白鹿，忠诚与祥瑞相应，和周公千载契合，并祝其安邦、永享美誉。这是当时君臣的祥瑞解释。 [[24]](#jin001-note-l34)

### 3. 曹叡诏令复核死罪乞恩案

[返回正文第3条](#sg-event-5)

<a id="sg003-l196-e5"></a>

<a id="wei003-l92-1"></a>

**[《三國志·明帝紀》正文](../../拆分史书/三国志/卷003.md#edition-wei003-l92-1)** · [TXT L92](../../拆分史书/三国志/卷003.txt#L92)

> 六月壬申，詔曰：「有虞氏畫象而民弗犯，周人刑錯而不用。朕從百王之末，追望上世之風，邈乎何相去之遠？法令滋章，犯者彌多，刑罰愈衆，而姦不可止。往者桉大辟之條，多所蠲除，思濟生民之命，此朕之至意也。而郡國斃獄，一歲之中尚過數百，豈朕訓導不醇，俾民輕罪，將苛法猶存，爲之陷穽乎？有司其議獄緩死，務從寬簡，及乞恩者，或辭未出而獄以報斷，非所以究理盡情也。其令廷尉及天下獄官，諸有死罪具獄以定，非謀反及手殺人，亟語其親治，有乞恩者，使與奏當文書俱上，朕將思所以全之。其布告天下，使明朕意。」

**釋讀與歸年** 青龙四年六月壬申，曹叡说前次删减大辟后，郡国每年仍有数百人毙于狱中。死刑案已审定时，除谋反及亲手杀人外，应告知犯人的亲属；若有求恩书，与拟判文书一并上报。参看[234年删定大辟](ce-0234.md#ce234-note-19)。

### 7. 魏颁诏以张掖石图为祥瑞

[返回正文第7条](#sg-event-16)

**《明帝紀》互見** [TXT 第88行第1段](../../拆分史书/三国志/卷003.md#edition-wei003-l88-1) · [TXT 第88行第4段](../../拆分史书/三国志/卷003.md#edition-wei003-l88-4)

<a id="wei011-l139-5"></a>

<a id="wei011-l140-1"></a>

<a id="wei011-l141-1"></a>

**[《三國志·袁張涼國田王邴管傳》](../../拆分史书/三国志/卷011.md#edition-wei011-l139-5)** · [TXT L139](../../拆分史书/三国志/卷011.txt#L139) · [TXT L140（裴注）](../../拆分史书/三国志/卷011.txt#L140) · [TXT L141](../../拆分史书/三国志/卷011.txt#L141)

> 青龍四年辛亥詔書：「張掖郡玄川溢涌，激波奮蕩，寶石負圖，狀像靈龜，宅于川西，嶷然磐峙，倉質素章，麟鳳龍馬，煥炳成形，文字告命，粲然著明。太史令高堂隆上言：古皇聖帝所未甞蒙，實有魏之禎命，東序之世寶。」
>
> **〔裴注〕**
> 尚書顧命篇曰：「大玉、夷玉、天球、河圖在東序。」注曰：「河圖，圖出於河，帝王聖者之所受。」
>
> **〔正文續〕**
> 事班天下。任令于綽連齎以問臶，臶密謂綽曰：「夫神以知來，不追已往，禎祥先見而後廢興從之。漢已乆亡，魏已得之，何所追興徵祥乎！此石，當今之變異而將來之禎瑞也。」

**釋讀與歸年** 青龙四年辛亥诏称张掖玄川涨水后发现似龟的石图，高堂隆说是魏朝祥瑞。[《资治通鉴》卷73](../../史书/025-资治通鉴/KR2b0007_073.txt#L236-L249)把石图见及颁诏、问张臶连叙于青龙三年；区分异象初报前后与本传明确纪年的诏书。

**釋讀與歸年** 裴注引《尚书·顾命》说明东序所藏宝物如河图，释诏书所谓「東序之世寶」。

**釋讀與歸年** 诏文颁于天下。任县令于绰据以问张臶，张臶认为祥瑞预示后来的兴废，魏朝已经接替汉朝，本石所示应是未来。

> 桓、厲等皆見斬獲，傳首詣都。權詔岱曰：「厲負險作亂，自致梟首；桓凶狡反覆，已降復叛。前後討伐，歷年不禽，非君規略，誰能梟之？忠武之節，於是益著。元惡旣除，大小震懾，其餘細類，埽地族矣。自今已去，國家永無南顧之虞，三郡晏然，無怵惕之驚，又得惡民以供賦役，重自歎息。賞不踰月，國之常典，制度所宜，君其裁之。」

**釋讀** 吳軍斬獲李桓、羅厲等，傳首都城。孫權詔稱羅厲負險、李桓降後再叛，因呂岱謀略方能梟首，叛者受震懾，三郡安定，諸戶復入賦役，令呂岱依典裁賞。

**歸年** 卷047以嘉禾五年記吾粲獲李桓、唐咨獲羅厲（原文春季記事承「三月」，未為二人另標月份）；褒詔接戰後。

### 20. 魏记太白昼见及彗星

[返回正文第20条](#sg-event-1)

**[《三國志·辛毗楊阜高堂隆傳》正文](../../拆分史书/三国志/卷025.md#edition-wei025-l73-1)** · [TXT L73](../../拆分史书/三国志/卷025.txt#L73)

> 是歲，有星孛于大辰。隆上疏曰：「凡帝王徙都立邑，皆先定天地社稷之位，敬恭以奉之。將營宮室，則宗廟爲先，廄庫爲次，居室爲後。今圜丘、方澤、南北郊、明堂、社稷，神位未定，宗廟之制又未如禮，而崇飾居室，士民失業。外人咸云宮人之用，與興戎軍國之費，所盡略齊。民不堪命，皆有怨怒。書曰『天聦明自我民聦明，天明畏自我民明威』，輿人作頌，則嚮以五福，民怒吁嗟，則威以六極，言天之賞罰，隨民言，順民心也。是以臨政務在安民爲先，然後稽古之化，格于上下，自古及今，未嘗不然也。夫采椽卑宮，唐、虞、大禹之所以垂皇風也；玉臺瓊室，夏癸、商辛之所以犯昊天也。今之宮室，實違禮度，乃更建立九龍，華飾過前。天彗章灼，始起於房心，犯帝坐而干紫微，此乃皇天子愛陛下，是以發教戒之象，始卒皆於尊位，殷勤鄭重，欲必覺寤陛下；斯乃慈父懇切之訓，宜崇孝子祗聳之禮，以率先天下，以昭示後昆，不宜有忽，以重天怒。」

**釋讀與歸年** 冬十月甲申孛星見於大辰，高堂隆因事上疏，主張先定郊廟社稷再治宮室，並以民怨解釋災異。[《明帝紀》](../../拆分史书/三国志/卷003.txt#L94)、《資治通鑑》[卷七十三](../../史书/025-资治通鉴/KR2b0007_073.txt#L264-L289)同繫青龍四年。

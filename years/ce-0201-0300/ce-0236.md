# 公元236年｜魏青龙四年／蜀建兴十四年／吴嘉禾五年

<a id="sg-event-1"></a>

1. **太白复昼见，月犯太白。** 四年春二月，太白复昼见，月犯太白，又犯轩辕一星，入太微而出。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **置崇文观，徵善属文者以充之。** 夏四月，置崇文观，徵善属文者以充之。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **司徒董昭薨。** 五月乙卯，司徒董昭去世。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **肃慎氏献楛矢。** 丁巳，肃慎氏献楛矢。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **诏曰“有虞氏画象而民弗犯”。** 六月壬申，诏曰：「有虞氏画象而民弗犯，周人刑错而不用。朕从百王之末，追望上世之风，邈乎何相去之远？法令滋章，犯者弥多，刑罚愈衆，而奸不可止。往者桉大辟之条，多所蠲除，思济生民之命，此朕之至意也。而郡国毙狱，一岁之中尚过数百，岂朕训导不醇，俾民轻罪，将苛法犹存，爲之陷穽乎？主管官员其议狱缓死，务从宽简，及乞恩者，或辞未出而狱以报断，非所以究理尽情也。其令廷尉及天下狱官，诸有死罪具狱以定，非谋反及手杀人，亟语其亲治，有乞恩者，使与奏当文书俱上，朕将思所以全之。其布告天下，使明朕意。」 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **高句骊王宫斩送孙权使胡衞等首。** 秋七月，高句骊王宫斩送孙权使胡衞等首，诣幽州。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **太白犯轩辕大星。** 甲寅，太白犯轩辕大星。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **行还洛阳宫。** 冬十月己卯，行还洛阳宫。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **有星孛于大辰，乙酉。** 甲申，有星孛于大辰，乙酉，又孛于东方。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **彗星见，犯宦者天纪星。** 十一月己亥，彗星见，犯宦者天纪星。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **司空陈群薨。** 十二月癸巳，司空陈群去世。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **行幸许昌宫。** 乙未，行幸许昌宫。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **刘禅至湔及迁武都氐户。** 四月刘禅至湔观汶水，随后返成都；徙苻健及氐人四百余户入成都。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **吴铸当五百大钱。** 嘉禾五年春，吴铸当五百大钱，令吏民缴铜并计铜付值，又定盗铸之法。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **吴辅吴将军张昭去世。** 二月辅吴将军张昭去世。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **诏书，「张掖郡玄川溢涌。** 青龙四年辛亥诏书：「张掖郡玄川溢涌，激波奋荡，宝石负图，状像灵龟，宅于川西，嶷然磐峙，仓质素章，麟凤龙马，焕炳成形，文字告命，粲然着明。太史令高堂隆上言：古皇圣帝所未尝蒙，实有魏之祯命，东序之世宝。」 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **徐宣去世。** 徐宣于本年去世。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **诏「欲得有才智文章，谋虑渊深。** 青龙四年，诏「欲得有才智文章，谋虑渊深，料远若近，视昧而察，筹不虚运，策弗徒发，端一小心，清修密静，乹乹不解，志尚在公者，无限年齿，勿拘贵贱，卿校已上各举一人」。 [[18]](#sg-note-18)

<a id="sy-event-19"></a>

19. **《陆逊传》系攻襄阳于嘉禾五年。** 本传所书遣将、韩扁被俘、陆逊收兵，与[234年孙权兵分三路攻魏](ce-0234.md#sg-note-13)所记相合，参同年[白围袭三县](ce-0234.md#sgz-note-62)。 [[19]](#sy-note-19)

<a id="sy-event-20"></a>

20. **曹阐承嗣曹整。** 魏封曹范弟东安乡公曹阐为郿公，承嗣曹整。 [[20]](#sy-note-20)

<a id="sgz-event-21"></a>

21. **改封甄氏亲属。** 甄逸、甄俨均改封魏昌侯，旧谥保留；又封甄俨妻刘氏、追封甄逸妻张氏。 [[21]](#sgz-note-21)

<a id="sgz-event-22"></a>

22. **改封文德郭后的先世。** 改封父郭永和母董氏，追谥三个兄弟，使者奉策以太牢祭祀。 [[22]](#sgz-note-22)

<a id="sgz-event-23"></a>

23. **追封毛后母夏氏。** 毛后母夏氏追封野王君。 [[23]](#sgz-note-23)

<a id="sgz-event-24"></a>

24. **曹偃死而无嗣，国除。** 曹偃去世，无子，撤封国。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **吴军斩获李桓、罗厉。** 李桓、罗厉等被斩获，首级传至国都。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **武昌礼宾殿报甘露。** 二月武昌报告礼宾殿降甘露。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **吴久旱。** 自十月至夏未下雨。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **吴报东方彗星。** 冬十月东方有彗星。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **鄱阳彭旦起事。** 鄱阳彭旦等反。 [[29]](#sgz-note-29)

<a id="sgz025-b-1348-1"></a>

**[《三国志·辛毗杨阜高堂隆传》仓内原文 L1348](../../sources/本地分卷/三国志/三国志-卷025.md#l1348)**

> 是歲，有星孛於大辰。隆上疏曰：「凡帝王徙都立邑，皆先定天地社稷之位，敬恭以奉之。將營宮室，則宗廟爲先，廄庫爲次，居室爲後。

**释读** 彗星出大辰，高堂隆疏论建都与营造应先天地宗庙、宫居最后。

**归年** 《明帝纪》青龙四年十月甲申首先有星孛于大辰、乙酉再孛于东方。

<a id="sgz025-b-1348-2"></a>

**[《三国志·辛毗杨阜高堂隆传》仓内原文 L1348](../../sources/本地分卷/三国志/三国志-卷025.md#l1348)**

> 今圜丘、方澤、南北郊、明堂、社稷，神位未定，宗廟之制又未如禮，而崇飾居室，士民失業。外人咸雲宮人之用，與興戎軍國之費，所盡略齊。民不堪命，皆有怨怒。書曰『天聦明自我民聦明，天明畏自我民明威』，輿人作頌，則嚮以五福，民怒吁嗟，則威以六極，言天之賞罰，隨民言，順民心也。

**释读** 诸祀位未定，反营宫费力，使百姓积怨；引《书》谓天意从民。

**归年** 同一上疏。

<a id="sgz025-b-1348-3"></a>

**[《三国志·辛毗杨阜高堂隆传》仓内原文 L1348](../../sources/本地分卷/三国志/三国志-卷025.md#l1348)**

> 是以臨政務在安民爲先，然後稽古之化，格於上下，自古及今，未嘗不然也。夫采椽卑宮，唐、虞、大禹之所以垂皇風也；玉臺瓊室，夏癸、商辛之所以犯昊天也。今之宮室，實違禮度，乃更建立九龍，華飾過前。天彗章灼，始起於房心，犯帝坐而干紫微，此乃皇天子愛陛下，是以發教戒之象，始卒皆於尊位，殷勤鄭重，欲必覺寤陛下；斯乃慈父懇切之訓，宜崇孝子祗聳之禮，以率先天下，以昭示後昆，不宜有忽，以重天怒。」

**释读** 以唐虞茅椽、桀纣玉室相衡，称重造九龙殿使星孛冲帝座，当率先改过。

**归年** 同一上疏。

### 13. 刘禅至湔及迁武都氐户

[返回正文第13条](#sg-event-13)

<a id="sg033-l1697-e13"></a>

**[《三国志·后主传》](../../sources/摘录/三国志-卷033-后主传.md#p003)** · [仓内TXT L1697](../../sources/本地分卷/三国志/三国志-卷033.md#l1697)

> 十四年夏四月，後主至湔，登觀坂，看汶水之流，旬日還成都。徙武都氐王苻健及氐民四百餘戶於成都。

<a id="sgz033-b-1697-1"></a>

**[《三国志·后主传》仓内原文 L1697](../../sources/本地分卷/三国志/三国志-卷033.md#l1697)**

> 十四年夏四月，後主至湔，登觀坂，看汶水之流，旬日還成都。

**释读** 刘禅四月赴湔，登观坂观看汶水水流，十天后回成都。

**归年** 本传明书建兴十四年。

<a id="sgz033-b-1697-2"></a>

**[《三国志·后主传》仓内原文 L1697](../../sources/本地分卷/三国志/三国志-卷033.md#l1697)**

> 徙武都氐王苻健及氐民四百餘戶於成都。

**释读** 将武都氐王苻健及氐民四百余户迁置成都。

**归年** 本传承建兴十四年；《张嶷传》记苻健分半来降，其兄不随降。

<a id="sgz043-b-2044-1"></a>

**[《三国志·黄李吕马王张传》仓内原文 L2044](../../sources/本地分卷/三国志/三国志-卷043.md#l2044)**

> 十四年，武都氐王苻健請降，遣將軍張尉往迎，過期不到，大將軍蔣琬深以為念。嶷平之曰：「苻健求附款至，必無他變。素聞健弟狡黠，又夷狄不能同功，將有乖離，是以稽留耳。」數日，問至，健弟果將四百戶就魏，獨健來從。

**[《三国志·陆逊传》](../../sources/摘录/三国志-卷058-陆逊传.md#p003)** · [仓内TXT L2787](../../sources/本地分卷/三国志/三国志-卷058.md#l2787)

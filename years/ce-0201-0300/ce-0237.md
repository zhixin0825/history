<a id="sg-event-1"></a>

1. **曹魏改历及景初年号。** 景初元年春正月壬辰，山茌县言黄龙见。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **于是有司奏，以爲魏得地统。** 于是主管官员奏，以爲魏得地统，宜以建丑之月爲正。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **定历改年爲孟夏四月。** 三月，定历改年爲孟夏四月。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **服色尚黄，牺牲用白。** 服色尚黄，牺牲用白，戎事乘黑首白马，建大赤之旗，朝会建大白之旗。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **其春夏秋冬孟仲季月虽与正岁不同。** 其春夏秋冬孟仲季月虽与正岁不同，至于郊祀、迎气、礿祠、蒸尝、巡狩、蒐田、分至启闭、班宣时令、中气早晚、敬授民事，皆以正岁斗建爲历数之序。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **行还洛阳宫。** 五月己巳，行还洛阳宫。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **大赦。** 己丑，大赦。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **京都地震。** 六月戊申，京都地震。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **以尚书令陈矫爲司徒，尚书右仆射衞臻爲司空。** 己亥，以尚书令陈矫爲司徒，尚书右仆射衞臻爲司空。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **分魏兴之魏阳、锡郡之安富、上庸爲上庸郡。** 丁未，分魏兴之魏阳、锡郡之安富、上庸爲上庸郡。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **省锡郡，以锡县属魏兴郡。** [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **有司奏，武皇帝拨乱反正。** 主管官员奏：武皇帝拨乱反正，爲魏太祖，乐用武始之舞。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **文皇帝应天受命，爲魏高祖。** 文皇帝应天受命，爲魏高祖，乐用咸熙之舞。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **帝制作兴治，爲魏烈祖。** 帝制作兴治，爲魏烈祖，乐用章武之舞。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **三祖之庙万世不毁，其余四庙亲尽迭毁。** 三祖之庙万世不毁，其余四庙亲尽迭毁，如周后稷、文、武庙祧之制。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **司徒陈矫薨。** 秋七月丁卯，司徒陈矫去世。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **孙权遣将朱然等二万人围江夏郡。** 孙权遣将朱然等二万人围江夏郡，荆州刺史胡质等击之，然退走。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **初，权遣使浮海与高句骊通。** 初，权派使浮海与高句骊通，欲袭辽东。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **遣幽州刺史毋丘俭率诸军及鲜卑、乌丸屯辽东南界。** 遣幽州刺史毋丘俭率诸军及鲜卑、乌丸屯辽东南界，玺书徵公孙渊。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **渊发兵反，俭进军讨之。** 渊发兵反，俭进军讨之，会连雨十日，辽水大涨，诏俭引军还。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **右北平乌丸单于寇娄敦、辽西乌丸都督王护留等居辽东。** 右北平乌丸单于寇娄敦、辽西乌丸都督王护留等居辽东，率部衆随俭内附。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **诏辽东将吏士民爲渊所胁略不得降者。** 己卯，诏辽东将吏士民爲渊所胁略不得降者，一切赦之。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **太白昼见。** 辛卯，太白昼见。 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **渊自俭还，遂自立爲燕王。** 渊自俭还，遂自立爲燕王，置百官，称绍汉元年。 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **诏青、兖、幽、冀四州大作海船。** [[25]](#sg-note-25)

<a id="sg-event-26"></a>

26. **冀、兖、徐、豫四州民遇水。** 九月，冀、兖、徐、豫四州民遇水，遣侍御史循行没溺死亡及失财产者，在所开仓振救之。 [[26]](#sg-note-26)

<a id="sg-event-27"></a>

27. **皇后毛氏卒。** 庚辰，皇后毛氏卒。 [[27]](#sg-note-27)

<a id="sg-event-28"></a>

28. **月犯荧惑。** 冬十月丁未，月犯荧惑。 [[28]](#sg-note-28)

<a id="sg-event-29"></a>

29. **葬悼毛后于愍陵。** 癸丑，葬悼毛后于愍陵。 [[29]](#sg-note-29)

<a id="sg-event-30"></a>

30. **营洛阳南委粟山爲圜丘。** 乙卯，营洛阳南委粟山爲圜丘。 [[30]](#sg-note-30)

<a id="sg-event-31"></a>

31. **冬至，始祀。** 十二月壬子冬至，始祀。 [[31]](#sg-note-31)

<a id="sg-event-32"></a>

32. **分襄阳临沮、宜城、旍阳、邔四县。** 丁巳，分襄阳临沮、宜城、旍阳、邔四县，置襄阳南部都尉。 [[32]](#sg-note-32)

<a id="sg-event-33"></a>

33. **有司奏文昭皇后立庙京都。** 己未，主管官员奏文昭皇后立庙京都。 [[33]](#sg-note-33)

<a id="sg-event-34"></a>

34. **分襄阳郡之鄀叶县属义阳郡。** [[34]](#sg-note-34)

<a id="sg-event-35"></a>

35. **曹叡赐毛皇后死。** 毛后因得知北园曲宴而触怒曹叡，被赐死，仍以皇后礼加谥。 [[35]](#sg-note-35)

<a id="sg-event-36"></a>

36. **蜀汉敬哀张皇后去世。** 刘禅的敬哀张皇后去世。 [[36]](#sg-note-36)

<a id="sg-event-37"></a>

37. **王平接督汉中。** 吴壹去世后，王平升封安汉侯，接督汉中。 [[37]](#sg-note-37)

<a id="sg-event-38"></a>

38. **吴讨论奔丧与任官纪律。** 孙权命群臣重新商议在任长吏奔丧的规制，要求兼顾职事与丧礼。传文又在后面叙孟宗奔丧自拘案。 [[38]](#sg-note-38)

<a id="sg-event-39"></a>

39. **陆逊破彭旦，诸葛恪平山越。** 陆逊讨彭旦等，吴军又袭六安未克。诸葛恪结束山越战事后北屯庐江。 [[39]](#sg-note-39)

<a id="sg-event-40"></a>

40. **有司议定七庙。** 景初元年夏，主管官员议定七庙。 [[40]](#sg-note-40)

<a id="sg-event-41"></a>

41. **帝游后园，召才人以上曲宴极乐。** 景初元年，帝游后园，召才人以上曲宴极乐。 [[41]](#sg-note-41)

<a id="sg-event-42"></a>

42. **琮坐于中尚方作禁物，削户三百。** 景初元年，琮坐于中尚方作禁物，削户三百，贬爵为都乡侯。 [[42]](#sg-note-42)

<a id="sg-event-43"></a>

43. **据坐私遣人诣中尚方作禁物。** 景初元年，据坐私遣人诣中尚方作禁物，削县二千户。 [[43]](#sg-note-43)

<a id="sg-event-44"></a>

44. **曹抗去世。** 曹抗于本年去世。 [[44]](#sg-note-44)

<a id="sg-event-45"></a>

45. **陈矫去世。** 陈矫于本年去世。 [[45]](#sg-note-45)

<a id="sg-event-46"></a>

46. **司徒、司空并缺，散骑侍郎孟康荐林曰“夫宰相者”。** 景初元年，司徒、司空并缺，散骑侍郎孟康荐林曰：「夫宰相者，天下之所瞻效，诚宜得秉忠履正本德杖义之士，足为海内所师表者。窃见司隷校尉崔林，禀自然之正性，体高雅之弘量。论其所长以比古人，忠直不回则史鱼之俦，清俭守约则季文之匹也。牧守州郡，所在而治，及为外司，万里肃齐，诚台辅之妙器，衮职之良才也。」 [[46]](#sg-note-46)

<a id="sg-event-47"></a>

47. **入为贵人。** 建兴十五年，入为贵人。 [[47]](#sg-note-47)

<a id="sg-event-48"></a>

48. **魏庐江主簿吕习请大兵自迎。** 嘉禾六年，魏庐江主簿吕习请大兵自迎，欲开门为应。 [[48]](#sg-note-48)

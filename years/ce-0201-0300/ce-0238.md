# 公元238年｜魏景初二年／蜀延熙元年／吴赤乌元年

[← 公元237年](ce-0237.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元239年 →](ce-0239.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **魏遣司马懿讨公孙渊。** 二年春正月，诏太尉司马宣王帅衆讨辽东。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **以大中大夫韩曁爲司徒。** 二月癸卯，以大中大夫韩曁爲司徒。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **月犯心距星，又犯心中央大星。** 癸丑，月犯心距星，又犯心中央大星。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **司徒韩曁薨。** 夏四月庚子，司徒韩曁去世。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **分沛国萧、相、竹邑、符离、蕲、銍、龙亢、山桑、洨、虹十县爲汝阴郡。** 壬寅，分沛国萧、相、竹邑、符离、蕲、銍、龙亢、山桑、洨、虹十县爲汝阴郡。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **宋县、陈郡苦县皆属谯郡。** [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **以沛、杼秋、公丘、彭城丰国、广戚。** 以沛、杼秋、公丘、彭城丰国、广戚，并五县爲沛王国。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **大赦。** 庚戌，大赦。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **月犯心距星，又犯中央大星。** 五月乙亥，月犯心距星，又犯中央大星。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **省渔阳郡之狐奴县，复置安乐县。** 六月，省渔阳郡之狐奴县，复置安乐县。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **烧当羌王芒中、注诣等叛。** 秋八月，烧当羌王芒中、注诣等叛，凉州刺史率诸郡攻讨，斩注诣首。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **有彗星见张宿。** 癸丑，有彗星见张宿。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **司马懿攻克襄平。** 司马懿在襄平打败公孙渊，后者被杀，辽东诸郡归魏。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **以司空衞臻爲司徒，司隷校尉崔林爲司空。** 壬午，以司空衞臻爲司徒，司隷校尉崔林爲司空。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **闰月，月犯心中央大星。** [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **帝寝疾不豫。** 十二月乙丑，帝寝疾不豫。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **立皇后。** 辛巳，立皇后。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **赐天下男子爵人二级，鳏寡孤独谷。** [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **以燕王宇爲大将军，甲申免。** 以燕王宇爲大将军，甲申免，以武衞将军曹爽代之。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **曹叡立郭氏为皇后。** 曹叡病重，立郭氏为皇后。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **卑弥呼遣使入魏受封。** 难升米等在六月至带方求入朝；十二月魏廷以卑弥呼为亲魏倭王，赐印绶及物品。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **蜀汉立张皇后、刘璿为储。** 刘禅新立张后，改元延熙，立刘璿为太子、刘瑶为安定王。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **蒋琬出屯汉中。** 冬十一月，蒋琬出屯汉中。 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **吴改元赤乌并铸当千大钱。** 吴铸当千大钱，群臣因武昌报麒麟建议改元，孙权取此前亲见赤乌为年号。 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **吕壹伏诛，孙权自责求直谏。** 校事吕壹用法苛急，大臣少敢进言；吕壹罪发被诛，孙权谴责自身并向诸将求策。 [[25]](#sg-note-25)

<a id="sg-event-26"></a>

26. **辽东平定，以参谋之功。** 景初二年，辽东平定，以参谋之功，各进爵，封本县，放方城侯，资中都侯。 [[26]](#sg-note-26)

<a id="sg-event-27"></a>

27. **立为饶安王。** 景初二年，立为饶安王。 [[27]](#sg-note-27)

<a id="sg-event-28"></a>

28. **以宠年老徵还，迁爲太尉。** 景初二年，以宠年老徵还，迁爲太尉。 [[28]](#sg-note-28)

<a id="sg-event-29"></a>

29. **大将军蒋琬住沔阳，平更为前护军。** 延熙元年，大将军蒋琬住沔阳，平更为前护军，署琬府事。 [[29]](#sg-note-29)

<a id="sg-event-30"></a>

30. **诏琬曰“寇难未弭”。** 延熙元年，诏琬曰：「寇难未弭，曹睿骄凶，辽东三郡劳其暴虐，遂相纠结，与之离隔。睿大兴众役，还相攻伐。囊秦之亡，胜、广首难，今有此变，斯乃天时。君其治严，总帅诸军屯任汉中，须吴举动，东西掎角，以乘其畔。」 [[30]](#sg-note-30)

<a id="sg-event-31"></a>

31. **随大将军蒋琬住汉中。** 延熙元年，随大将军蒋琬住汉中。 [[31]](#sg-note-31)

<a id="sg-event-32"></a>

32. **入为尚书，稍迁督建威。** 延熙元年，入为尚书，稍迁督建威，假节，进封都亭侯，征西大将军。 [[32]](#sg-note-32)

[返回正文第13条](#sg-event-13)

<a id="sg003-l206-e13"></a>

**[《三国志·明帝纪》](../../sources/摘录/三国志-卷003-明帝纪.md#p005)** · [仓内TXT L206](../../sources/本地分卷/三国志/三国志-卷003.md#L206)

> 丙寅，司馬宣王圍公孫淵於襄平，大破之，傳淵首於京都，海東諸郡平。冬十一月，錄討淵功，太尉宣王以下增邑封爵各有差。初，帝議遣宣王討淵，發卒四萬人。議臣皆以爲四萬兵多，役費難供。帝曰：「四千里征伐，雖雲用奇，亦當任力，不當稍計役費。」遂以四萬人行。及宣王至遼東，霖雨不得時攻，羣臣或以爲淵未可卒破，宜詔宣王還。帝曰：「司馬懿臨危制變，擒淵可計日待也。」卒皆如所策。

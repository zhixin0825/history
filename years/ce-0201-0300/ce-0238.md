## 本年概述

魏遣司马懿攻辽东，公孙渊在襄平败死。年底曹叡病重，曹宇短暂受命为大将军。蜀立后与太子，蒋琬出屯汉中；吴诛吕壹，孙权为用人失当自责求谏。

14. **蒋琬出屯汉中，王平转任前护军。** 冬十一月，蒋琬出屯汉中。 延熙元年，大将军蒋琬住沔阳，平更为前护军，署琬府事。 [[14]](#sg-note-23)

<a id="sg-event-32"></a>

15. **入为尚书，稍迁督建威。** 延熙元年，入为尚书，稍迁督建威，假节，进封都亭侯，征西大将军。 [[15]](#sg-note-32)

<a id="sgz-event-36"></a>

16. **蜀军攻宕蕈营，魏将游奕兵败，王赟中箭死。** 九月，蜀阴平太守出兵攻打守善羌侯宕蕈营。郭淮派王赟、游奕分兵应对，曹叡担心兵力分散，命其合兵。诏令未到，游奕已战败，王赟中流矢而死。 [[16]](#sgz-note-36)

<a id="sg-event-24"></a>

17. **吴改元赤乌并铸当千大钱。** 吴铸当千大钱，群臣因武昌报麒麟建议改元，孙权取此前亲见赤乌为年号。 [[17]](#sg-note-24)

<a id="sg-event-25"></a>

18. **吕壹伏诛，孙权自责求谏。** 吕壹、秦博审查各级官府的文书，吕壹等人借机擅权，设置榷酒等管制以取利，又罗织罪名，顾雍、朱据等大臣也遭奏劾。朱据部下应领三万缗，被工匠王遂冒领。吕壹疑是朱据取走，杖讯经办者致死，又拿朱据为死者厚殓一事加以诬告。孙权屡加责问，朱据只能待罪。数月后典军吏刘助查出是王遂冒领，孙权醒悟，赏刘助百万钱，并追究吕壹。太子孙登多次进谏，步骘也上疏指斥冤狱，建议都下断狱问顾雍，武昌则问陆逊、潘濬。吕壹罪行败露，被交廷尉。顾雍亲自讯问，也制止尚书郎怀叙当面辱骂吕壹。有司奏请处吕壹死刑，有人提议加焚裂之刑，阚泽劝止，孙权采纳。吕壹伏诛后，孙权引咎自责，遣中书郎袁礼向诸将求策，再下诏劝他们尽言。诸葛瑾就具体政事作答。 [[18]](#sg-note-25)

<a id="sy-event-33"></a>

19. **孙权追册步夫人为皇后。** 孙权曾属意步夫人为后，宫中也以皇后称呼她。步夫人去世后，孙权命丞相顾雍持节追册，使她配享先后，葬于蒋陵。 [[19]](#sy-note-33)

<a id="sy-event-34"></a>

20. **朱桓去世，朱异继领其部。** 朱桓治军时轻财重义，常分俸禄、财产给吏士及亲属。他病重时全营忧戚，病逝时年六十二。朱桓家无余财，孙权赐盐五十斛助办丧事。朱异承其爵，后来拜骑都尉，领朱桓旧部。 [[20]](#sy-note-34)

<a id="sgz-event-40"></a>

21. **吕岱讨庐陵后归陆口。** 吕岱讨庐陵起事者完毕，回陆口。 [[21]](#sgz-note-40)

<a id="sgz003-b-206-3"></a>

**[《三国志·明帝纪》仓内原文 L206](../../sources/本地分卷/三国志/三国志-卷003.md#l206)**

> 初，帝議遣宣王討淵，發卒四萬人。議臣皆以爲四萬兵多，役費難供。帝曰：「四千里征伐，雖雲用奇，亦當任力，不當稍計役費。」遂以四萬人行。

**释读** 此前讨辽东时，有大臣认为四万士卒供给不易；曹叡说远征四千里不能只计省费，仍定四万人。

**归年** 本纪“初”回到景初二年年初议军，与L203正月出征同组。四万数见《晋书·宣帝纪》。

**[《三国志·明帝纪》裴注 027·1](../../sources/本地分卷/三国志/三国志-卷003.md#pei-027-1)**

> 干寳晉紀曰帝問宣王度淵將何計以待君宣王對曰淵棄城預走上計也據遼水拒大軍其次也坐守襄平此為成禽耳帝曰然則三者何出對曰唯明智審量彼我乃預有所割棄此既非淵所及又謂今徃縣逺不能持久必先拒遼水後守也帝曰徃還㡬日對曰徃百日攻百日還百日以六十日為休息如此一年足矣

**释读** 曹叡询问辽东会采取何策，司马懿说弃城先走为上、拒守辽水其次、坐守襄平则必被擒；料公孙渊会先拒辽水再进城，并估计往攻还各百日，另休息六十日。

**归年** 干宝《晋纪》附景初二年正月命征辽东，晋书宣帝纪与通鉴卷074同记这场问答。

<a id="sgz003-p-027-2"></a>

**[《三国志·明帝纪》裴注 027·2](../../sources/本地分卷/三国志/三国志-卷003.md#pei-027-2)**

> 魏名臣奏載散騎常侍何曾表曰臣聞先王制法必於全慎故建官授任則置假輔陳師命將則立監貳宣命遣使則設介副臨敵交刃則參御右蓋以盡謀思之功防安危之變也是以在險當難則權足相濟隕缺不預則手足相代其為固防至深至逺及至漢氏亦循舊章韓信伐趙張耳為貳馬援討越劉隆副軍前世之迹著在篇志今懿奉辭誅罪歩騎數萬道路廻阻四千餘里雖假天威有征無戰冦或潛遁消散日月命無常期人非金石逺慮詳備誠宜有副今北邊諸將及懿所督皆為僚屬名位不殊素無定分卒有變急不相鎮攝存不忘亡聖達所戒宜選大臣名將威重宿著者盛其禮秩遣詣懿軍進同謀畧退為副佐雖有萬一不虞之災軍主有儲則無患矣

**释读** 何曾主张远行讨公孙渊必须选资深副帅，使万一主将有变仍能统众；并举韩信伐赵、马援征越的古例。

**归年** 景初二年出师时的建议，长疏中的汉事为论证。可与同条主事件一并阅读。

**释读** 本注引材料说朝廷让毌丘俭担任司马懿的副帅。

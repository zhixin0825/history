<a id="sg-event-30"></a>

30. **诏琬曰“寇难未弭”。** 延熙元年，诏琬曰：「寇难未弭，曹睿骄凶，辽东三郡劳其暴虐，遂相纠结，与之离隔。睿大兴众役，还相攻伐。囊秦之亡，胜、广首难，今有此变，斯乃天时。君其治严，总帅诸军屯任汉中，须吴举动，东西掎角，以乘其畔。」 [[30]](#sg-note-30)

<a id="sg-event-31"></a>

<a id="sg-event-32"></a>

32. **入为尚书，稍迁督建威。** 延熙元年，入为尚书，稍迁督建威，假节，进封都亭侯，征西大将军。 [[32]](#sg-note-32)

<a id="sy-event-33"></a>

33. **孙权追册步夫人为皇后。** 步夫人死后，孙权追册她为皇后，遣顾雍持节行册礼，使她得以配享先后。 [[33]](#sy-note-33)

<a id="sy-event-34"></a>

34. **吴将朱桓去世。** 朱桓去世，传载六十二岁，家中无余财，孙权赐盐五千斛助办丧事，其子朱异承继。 [[34]](#sy-note-34)

<a id="sgz-event-35"></a>

35. **魏明帝诏禁汉高祖、光武陵外百步耕采。** 戊子，曹叡诏称刘邦开国、刘秀中兴，汉陵坍塌且有孩童牧竖践踏，命以标识划出陵外百步，禁止耕牧樵采。 [[35]](#sgz-note-35)

<a id="sgz-event-36"></a>

36. **魏军讨蜀阴平，游奕兵败、王赟中箭死。** 九月，《魏书》说蜀阴平太守廖惇攻守善羌侯宕蕈部，郭淮派广魏太守王赟、南安太守游奕分兵应对；曹叡担心分军不利，命合兵，诏未到，游奕军败，王赟中箭死。 [[36]](#sgz-note-36)

<a id="sg-note-1"></a>

### 1. 魏遣司马懿讨公孙渊

[返回正文第1条](#sg-event-1)

<a id="sg003-l203-e1"></a>

**[《三国志·明帝纪》](../../sources/摘录/三国志-卷003-明帝纪.md#p005)** · [仓内TXT L203](../../sources/本地分卷/三国志/三国志-卷003.md#l203)

> 二年春正月，詔太尉司馬宣王帥衆討遼東。

<a id="sgz003-b-206-3"></a>

**[《三国志·明帝纪》仓内原文 L206](../../sources/本地分卷/三国志/三国志-卷003.md#l206)**

> 初，帝議遣宣王討淵，發卒四萬人。議臣皆以爲四萬兵多，役費難供。帝曰：「四千里征伐，雖雲用奇，亦當任力，不當稍計役費。」遂以四萬人行。

**释读** 此前讨辽东时，有大臣认为四万士卒供给不易；曹叡说远征四千里不能只计省费，仍定四万人。

**归年** 本纪“初”回到景初二年年初议军，与L203正月出征同组。四万数见《晋书·宣帝纪》。

<a id="sgz003-p-027-1"></a>

**[《三国志·明帝纪》裴注 027·1](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-027-1)**

> 干寳晉紀曰帝問宣王度淵將何計以待君宣王對曰淵棄城預走上計也據遼水拒大軍其次也坐守襄平此為成禽耳帝曰然則三者何出對曰唯明智審量彼我乃預有所割棄此既非淵所及又謂今徃縣逺不能持久必先拒遼水後守也帝曰徃還㡬日對曰徃百日攻百日還百日以六十日為休息如此一年足矣

**释读** 曹叡询问辽东会采取何策，司马懿说弃城先走为上、拒守辽水其次、坐守襄平则必被擒；料公孙渊会先拒辽水再进城，并估计往攻还各百日，另休息六十日。

**归年** 干宝《晋纪》附景初二年正月命征辽东，晋书宣帝纪与通鉴卷074同记这场问答。

<a id="sgz003-p-027-2"></a>

**[《三国志·明帝纪》裴注 027·2](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-027-2)**

> 魏名臣奏載散騎常侍何曾表曰臣聞先王制法必於全慎故建官授任則置假輔陳師命將則立監貳宣命遣使則設介副臨敵交刃則參御右蓋以盡謀思之功防安危之變也是以在險當難則權足相濟隕缺不預則手足相代其為固防至深至逺及至漢氏亦循舊章韓信伐趙張耳為貳馬援討越劉隆副軍前世之迹著在篇志今懿奉辭誅罪歩騎數萬道路廻阻四千餘里雖假天威有征無戰冦或潛遁消散日月命無常期人非金石逺慮詳備誠宜有副今北邊諸將及懿所督皆為僚屬名位不殊素無定分卒有變急不相鎮攝存不忘亡聖達所戒宜選大臣名將威重宿著者盛其禮秩遣詣懿軍進同謀畧退為副佐雖有萬一不虞之災軍主有儲則無患矣

**释读** 何曾主张远行讨公孙渊必须选资深副帅，使万一主将有变仍能统众；并举韩信伐赵、马援征越的古例。

**归年** 景初二年出师时的建议，长疏中的汉事为论证。可与同条主事件一并阅读。

<a id="sgz003-p-027-3"></a>

**[《三国志·明帝纪》裴注 027·3](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-027-3)**

> 毌丘儉志記云時以儉為宣王副也

**释读** 本注引材料说朝廷让毌丘俭担任司马懿的副帅。

**归年** 属景初二年司马懿征辽东，与237年毌丘俭亲率兵征召公孙渊分开。

<a id="sgz008-b-430-1"></a>

**[《三国志·二公孙陶四张传》仓内原文 L430](../../sources/本地分卷/三国志/三国志-卷008.md#l430)**

> 二年春，遣太尉司馬宣王徵淵。六月，軍至遼東。

**释读** 魏命太尉司马懿讨辽东，六月军到辽东。

**归年** 承景初二年，《明帝纪》明记春正月出师。

<a id="sgz008-p-036-2"></a>

**[《三国志·二公孙陶四张传》裴注 036·2](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-036-2)**

> 聞魏人将討復稱臣於吳乞兵北伐以自救吳人欲戮其使羊衜曰不可是肆匹夫之怒而捐覇王之計也不如因而厚之遣竒兵潛往以要其成若魏伐淵不克而我軍逺赴是恩結遐夷義盖萬里若兵連不觧首尾離隔則我虜其傍郡驅略而歸亦足以致天之罰報雪曩事矣權曰善乃勒兵大出謂淵使曰請俟後問當從簡書必與弟同休戚共存亡雖隕於中原吾所甘心也又曰司馬懿所向無前深為弟憂也

**释读** 公孙渊闻魏将出征后再向吴称臣求援。羊衜劝孙权留使出兵，孙权表示愿与辽东共患难，又说深忧司马懿攻无不克。

**归年** 所说魏将司马懿见《明帝纪》景初二年春正月奉诏出征；出兵和答使记录依《汉晋春秋》。

**[《三国志·二杜周许孟来尹李谯郤传》](../../sources/摘录/三国志-卷042-二杜周许孟来尹李谯郤传.md#p003)** · [仓内TXT L1990](../../sources/本地分卷/三国志/三国志-卷042.md#L1990)

<a id="sgz033-b-1699-1"></a>

**[《三国志·后主传》仓内原文 L1699](../../sources/本地分卷/三国志/三国志-卷033.md#l1699)**

> 延熙元年春正月，立皇后張氏。大赦，攻元。

**释读** 正月，刘禅立先前故后之妹张氏为皇后，大赦改为延熙；底本“攻元”，四库本“改元”。

**归年** 本传明书延熙元年，《二主妃子传》同年立后。

<a id="sgz033-b-1699-2"></a>

**[《三国志·后主传》仓内原文 L1699](../../sources/本地分卷/三国志/三国志-卷033.md#l1699)**

> 立子睿為太子，子瑤為安定王。

**释读** 太子按本卷仓本作“睿”，以《二主妃子传》及四库本人物名校为刘璿；同时封刘瑶安定王。

**归年** 承延熙元年；《二主妃子传》明载延熙元年正月璿立太子，刘瑶受封月份从本传。

## 本年概述

曹叡病逝，曹芳即位，曹爽与司马懿同受遗诏辅政。司马懿转任太傅，曹爽逐渐控制奏事与选官。吴遣使赴辽东，又调吕岱、唐咨平廖式等叛乱。

1. **曹叡病逝，曹芳即位，曹爽与司马懿辅政。** 曹叡早年收养曹芳、曹询。正月丁亥朔，司马懿自河内应召疾驰入宫。曹叡在病榻指认齐王曹芳为继承人，嘱咐司马懿与曹爽共辅幼主，当日立曹芳为皇太子，旋逝于嘉福殿。曹芳即位，大赦，尊郭皇后为皇太后，称永宁宫。刘放、孙资因参与议定辅政各增邑三百户，两家子弟亦获官爵。曹爽加侍中，改封武安侯，获准剑履上殿、入朝不趋、赞拜不名。魏追封郭太后之父郭满为西都定侯，由郭建承爵，封其母杜氏为郃阳君。曹芳下诏停办宫室工程，令六十岁及以上的官奴婢免为良人。曹叡殡于九龙前殿，正月癸丑葬于高平陵。刘劭先前建议制定礼乐，写成《乐论》十四篇，因曹叡去世未及呈上。芳林园因避曹芳名讳改称华林园。秋七月，曹芳首次临朝听公卿奏事。 [[1]](#sg-note-1)

2. **司马懿转太傅，满宠继任太尉。** 曹爽逐渐起用何晏、邓飏、丁谧、毕轨、李胜等人。他采纳丁谧的建议，表荐司马懿为太傅，使尚书奏事先由自己过问。魏诏司马懿转任太傅，仍持节统兵、都督诸军事。三月，满宠由征东将军接任太尉。 [[2]](#sg-note-10)

3. **曹芳即位后调整赵俨与卢毓等官职。** 曹芳即位后，朝廷命赵俨持节监雍凉军事，赵俨后来又历任征蜀、征西将军并都督西边。卢毓因新帝即位获赐关内侯，其后曹爽调他为尚书仆射，以何晏主铨选。 [[3]](#sgz-note-39)

8. **魏恢复部分宗室爵邑，并给曹彪、曹寻增邑。** 曹彪增封五百户，合原封共三千户。 曹寻增封五百户，合原封共三千户。 曹琮恢复己氏公爵，曹据先前被削的封邑也获归还。 [[8]](#sg-note-24)

## 辽东、交州与吴廷

<a id="sg-event-12"></a>

10. **以辽东东沓县吏民渡海居齐郡界。** 夏六月，以辽东东沓县吏民渡海居齐郡界，以故纵城为新沓县以居徙民。 [[10]](#sg-note-12)

<a id="sg-event-19"></a>



<a id="sg-event-20"></a>

11. **吴遣羊衜、郑胄、孙怡赴辽东。** 三月，吴遣使者羊衜、郑胄和将军孙怡赴辽东。公孙渊[上年已被魏军击破](ce-0238.md#sg-note-1)，吴使进击魏守将张持、高虑等，掳得男女。郑胄还吴后迁执金吾。 [[11]](#sg-note-20)

<a id="sg-event-21"></a>

12. **廖式、廖潜反，吴遣吕岱、唐咨平乱。** 冬，将军蒋秘南下征讨。他的部将廖式杀临贺太守严纲，自称平南将军，与弟廖潜攻扰零陵、桂阳、苍梧及郁林等郡。吕岱上表后即昼夜南行，孙权遣使追拜他为交州牧，又派唐咨等陆续赴援。战事延续逾年，廖式及其所任临贺太守费杨等被斩，诸郡复平，吕岱还武昌。 [[12]](#sg-note-21)

<a id="sg-event-22"></a>

13. **陆瑁去世。** 州闾以议论人物知名，陆瑁赤乌二年去世，其子陆喜亦涉文籍。 [[13]](#sg-note-22)

<a id="sg-event-23"></a>

14. **吴太常潘濬去世。** 潘濬自荆州入吴，多次领军，冬十月去世，子潘翥继爵。吕岱接掌荆州文书，与陆逊同驻武昌，仍兼督蒲圻。 [[14]](#sg-note-23)

<a id="sg-event-26"></a>

15. **诸葛瑾、步骘请为周胤复爵。** 周胤此前获罪徙居庐陵。诸葛瑾、步骘联名上疏，念及周瑜破曹操于乌林、逐曹仁于江陵的功劳，请赦免周胤，归还兵权与爵位。孙权认为周胤受过多次告诫，仍未悔改，起初未同意。诸葛瑾、步骘再三上表，朱然、全琮也帮忙请求，孙权最终答允，适逢周胤病逝。 [[15]](#sg-note-26)

<a id="sgz-event-35"></a>

16. **吴城沙羡。** 夏五月修沙羡城。 [[16]](#sgz-note-35)

<a id="sgz-event-36"></a>

17. **吴选宿卫郎吏依四科。** 孙权说宿卫郎吏应当精选，过去任用有人不合，自今三署按四科选，不得虚饰。 [[17]](#sgz-note-36)

<a id="sgz-event-38"></a>

<a id="sgz-event-37"></a>

18. **吴地两次地震，步骘借灾异劝任大臣。** 正月初一和二十七日，吴地两次地震。步骘把这两次地震与嘉禾六年的地震、接连发生的旱灾一并上疏，劝孙权填补官缺，信任大臣。 [[18]](#sgz-note-37)

**[《三國志·諸夏侯曹傳》](../../拆分史书/三国志/卷009.md#edition-wei009-l125-7)** · [TXT L125](../../拆分史书/三国志/卷009.txt#L125) · [TXT L126（裴注）](../../拆分史书/三国志/卷009.txt#L126)

> 丁謐畫策，使爽白天子，發詔轉宣王爲太傅，外以名號尊之，內欲令尚書奏事，先來由己，得制其輕重也。
>
> **〔裴注〕**
> 魏書曰：爽使弟羲爲表曰：「臣亡父真，奉事三朝，入備冢宰，出爲上將。先帝以臣肺腑遺緒，獎飭拔擢，典兵禁省，進無忠恪積累之行，退無羔羊自公之節。先帝聖體不豫，臣雖奔走，侍疾嘗藥，曾無精誠翼日之應，猥與太尉懿俱受遺詔，且慙且懼，靡所厎告。臣聞虞舜序賢，以稷、契爲先，成湯襃功，以伊、呂爲首，審選博舉，優劣得所，斯誠輔世長民之大經，錄勳報功之令典，自古以來，未之或闕。今臣虛闇，位冠朝首，顧惟越次，中心愧惕，敢竭愚情，陳寫至實。夫天下之達道者三，謂德、爵、齒也。懿本以高明中正，處上司之位，名足鎮衆，義足率下，一也。包懷大略，允文允武，仍立征伐之勳，遐邇歸功，二也。萬里旋斾，親受遺詔，翼亮皇家，內外所向，三也。加之耆艾，紀綱邦國，體練朝政；論德則過於吉甫、樊仲；課功則踰於方叔、召虎：凡此數者，懿實兼之。臣抱空名而處其右，天下之人將謂臣以宗室見私，知進而不知退。陛下岐嶷，克明克類，如有以察臣之言，臣以爲宜以懿爲太傅、大司馬，上昭陛下進賢之明，中顯懿身文武之實，下使愚臣免於謗誚。」於是帝使中書監劉放令孫資爲詔曰：「昔吳漢佐光武，有征定四方之功，爲大司馬，名稱于今。太尉體履正直，功蓋海內，先帝本以前後欲更其位者，輒不彌乆，是以遲遲不施行耳。今大將軍薦太尉宜爲大司馬，旣合先帝本旨，又放推讓，進德尚勳，乃欲明賢良、辯等列、順長少也。雖旦、奭之屬，宗師呂望，念在引領以處其下，何以過哉！朕甚嘉焉。朕惟先帝固知君子樂天知命，纖介細疑，不足爲忌，當顧栢人彭亡之文，故用低佪，有意未遂耳！斯亦先帝敬重大臣，恩愛深厚之至也。昔成王建保傅之官，近漢顯宗以鄧禹爲太傅，皆所以優崇儁乂，必有尊也。其以太尉爲太傅。」

**釋讀與歸年** 曹爽采纳丁谧建议，朝廷转司马懿为太傅，曹爽因而可先看尚书奏事。[《资治通鉴》卷74](../../史书/025-资治通鉴/KR2b0007_074.txt#L306-L322)合叙任用党人、转司马懿官；翌注表诏所举理由附列。

**釋讀與歸年** 曹爽令曹羲代拟表章，称颂司马懿的资历功勋，荐他为太傅、大司马；颁发的诏书由中书监刘放令孙资起草，最终授太傅。两件公文全文同列。

> 赤烏二年，諸葛瑾、步隲連名上疏曰：「故將軍周瑜子胤，昔蒙粉飾，受封爲將，不能養之以福，思立功效，至縱情欲，招速罪辟。臣竊以瑜昔見寵任，入作心膂，出爲爪牙，銜命出征，身當矢石，盡節用命，視死如歸，故能摧曹操於烏林，走曹仁於郢都，揚國威德，華夏是震，蠢爾蠻荊，莫不賔服，雖周之方叔，漢之信、布，誠無以尚也。夫折衝扞難之臣，自古帝王莫不貴重，故漢高帝封爵之誓曰『使黃河如帶，太山如礪，國以永存，爰及苗裔』；申以丹書，重以盟詛，藏于宗廟，傳於無窮，欲使功臣之後，世世相踵，非徒子孫，乃關苗裔，報德明功，勤勤懇懇，如此之至，欲以勸戒後人，用命之臣，死而無悔也。況於瑜身沒未乆，而其子胤降爲匹夫，益可悼傷。竊惟陛下欽明稽古，隆於興繼，爲胤歸訴，乞匄餘罪，還兵復爵，使失旦之雞，復得一鳴，抱罪之臣，展其後效。」

**釋讀** 諸葛瑾、步隲連名上疏，先說周胤受封後因自縱獲罪，再用周瑜在烏林破曹操、在郢都逐曹仁的功勞及漢高帝的封爵誓言，請赦罪、還兵復爵，使他能報效。

**歸年** 上疏明載赤烏二年；烏林、郢都與漢高帝誓詞均為上疏中的追述。

<a id="sgz054-b-2573-1"></a>

<a id="sgz054-b-2573-2"></a>

<a id="wu054-l42-8"></a>

**[《三國志·周瑜魯肅呂蒙傳》正文](../../拆分史书/三国志/卷054.md#edition-wu054-l42-8)** · [TXT L42](../../拆分史书/三国志/卷054.txt#L42)

> 權荅曰：「腹心舊勳，與孤協事，公瑾有之，誠所不忘。昔胤年少，初無功勞，橫受精兵，爵以侯將，蓋念公瑾以及於胤也。而胤恃此，酗淫自恣，前後告喻，曾無悛改。孤於公瑾，義猶二君，樂胤成就，豈有已哉？迫胤罪惡，未宜便還，且欲苦之，使自知耳。今二君勤勤援引漢高河山之誓，孤用恧然。雖德非其疇，猶欲庶幾，事亦如爾，故未順旨。以公瑾之子，而二君在中間，苟使能改，亦何患乎！」

**釋讀** 孫權答稱不能忘周瑜之功，先前便因此厚待周胤；周胤多次受誡而未改，不宜立刻復用，但若悔過，仍可許復。

**歸年** 接赤烏二年諸葛瑾、步隲上疏。

<a id="sgz054-b-2573-3"></a>

<a id="wu054-l42-9"></a>

**[《三國志·周瑜魯肅呂蒙傳》正文](../../拆分史书/三国志/卷054.md#edition-wu054-l42-9)** · [TXT L42](../../拆分史书/三国志/卷054.txt#L42)

> 瑾、隲表比上，朱然及全琮亦俱陳乞，權乃許之。會胤病死。

**釋讀** 諸葛瑾、步隲數次上表，朱然、全琮也請求，孫權最終答允，適逢周胤病死。

**歸年** 同赤烏二年請復爵的後續，允復月日和周胤確切卒年未另載，隨請復一事附敘。

> 又曰：「天子父天母地，故宮室百官，動法列宿。若施政令，欽順時節，官得其人，則陰陽和平，七曜循度。至於今日，官寮多闕，雖有大臣，復不信任，如此天地焉得無變？故頻年枯旱，亢陽之應也。又嘉禾六年五月十四日，赤烏二年正月一日及二十七日，地皆震動。地陰類，臣之象，陰氣盛故動，臣下專政之故也。夫天地見異，所以警悟人主，可不深思其意哉！」

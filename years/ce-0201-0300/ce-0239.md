# 公元239年｜魏景初三年／蜀延熙二年／吴赤乌二年

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **曹叡托孤后去世。** 曹叡召司马懿至病榻，命与曹爽辅佐少主，当日死于嘉福殿，旋葬高平陵。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **明帝无子，养王及秦王询。** 明帝无子，养王及秦王询；宫省事秘，莫有知其所由来者。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **编年更正。** 曹芳受封齐王见青龙三年。 [235年第15条](ce-0235.md#sg-note-15)。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **帝甚病，乃立为皇太子。** 景初三年正月丁亥朔，帝甚病，乃立为皇太子。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **是日，即皇帝位。** 是日，即皇帝位，大赦。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **尊皇后曰皇太后。** [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **大将军曹爽、太尉司马宣王辅政。** [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **诏曰“朕以眇身”。** 诏曰：「朕以眇身，继承鸿业，茕茕在疚，靡所控告。大将军、太尉奉受末命，夹辅朕躬，司徒、司空、冢宰、元辅总率百僚，以宁社稷，其与群卿大夫勉勖乃心，称朕意焉。诸所兴作宫室之役，皆以遗诏罢之。官奴婢六十已上，免为良人。」 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **西域重译献火浣布，诏大将军、太尉临试以示百寮。** 二月，西域重译献火浣布，诏大将军、太尉临试以示百寮。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **诏曰“太尉体道正直”。** 丁丑诏曰：「太尉体道正直，尽忠三世，南擒孟达，西破蜀虏，东灭公孙渊，功盖海内。昔周成建保傅之官，近汉显宗崇宠邓禹，所以优隆儁乂，必有尊也。其以太尉为太傅，持节统兵都督诸军事如故。」 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **以征东将军满宠为太尉。** 三月，以征东将军满宠为太尉。《满宠传》合记征还和迁任作[238年](ce-0238.md#sg-note-28)。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **以辽东东沓县吏民渡海居齐郡界。** 夏六月，以辽东东沓县吏民渡海居齐郡界，以故纵城为新沓县以居徙民。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **上始亲临朝，听公卿奏事。** 秋七月，上始亲临朝，听公卿奏事。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **大赦。** 八月，大赦。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **以镇南将军黄权为车骑将军。** 冬十月，魏任镇南将军黄权为车骑将军、仪同三司。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **曹魏恢复夏正。** 十二月，诏曰：「烈祖明皇帝以正月弃背天下，臣子永惟忌日之哀，其复用夏正；虽违先帝通三统之义，斯亦礼制所由变改也。又夏正于数为得天正，其以建寅之月为正始元年正月，以建丑月为后十二月。」 [[16]](#sg-note-16)

<a id="sg-event-17"></a>



<a id="sg-event-18"></a>

18. **蒋琬进大司马。** 三月蒋琬位进大司马。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>



<a id="sg-event-20"></a>

20. **吴遣羊衜、郑胄、孙怡赴辽东。** 赤乌二年三月，吴遣使者羊衜、郑胄和将军孙怡赴辽东，进击魏守将张持、高虑等，掳得男女。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **廖式、廖潜反，吴遣吕岱、唐咨平乱。** 冬，将军蒋秘南下征讨。他的部将廖式杀临贺太守严纲，自称平南将军，与弟廖潜攻扰零陵、桂阳、苍梧及郁林等郡。孙权遣吕岱、唐咨征讨，逾年平定。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **陆瑁去世。** 州闾以议论人物知名，陆瑁赤乌二年去世，其子陆喜亦涉文籍。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **吴太常潘濬去世。** 潘濬自荆州入吴，多次领军，赤乌二年卒，子潘翥继爵。 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **魏增封曹彪五百户。** 曹彪增封五百户，合原封共三千户。 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **魏增封曹寻五百户。** 曹寻增封五百户，合原封共三千户。 [[25]](#sg-note-25)

<a id="sg-event-26"></a>

26. **诸葛瑾、步骘连名上疏曰“”。** 赤乌二年，诸葛瑾、步骘连名上疏曰： [[26]](#sg-note-26)

<a id="sgz-event-27"></a>

27. **芳林园在曹芳即位时易名华林园。** 裴松之指出芳林园即他当时所谓华林园，曹芳即位时改园名。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **丁谧劝曹爽尊司马懿为太傅以控制尚书奏事。** 丁谧让曹爽发诏升司马懿太傅，名号高而尚书奏事先由曹爽裁夺。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **曹爽表荐司马懿为太傅。** 曹爽令曹羲代拟表。先述曹真服务曹氏三朝、自己受明帝恩与司马懿同受顾命，再论选贤录功的正道。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **曹琮恢复己氏公爵。** 曹琮重新为己氏公。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **复曹据所削户邑。** 恢复曹据先前被削去的户邑。 [[31]](#sgz-note-31)

<a id="sgz-event-32"></a>

32. **曹宇奉命归邺。** 曹宇夏季回邺。 [[32]](#sgz-note-32)

<a id="sgz-event-33"></a>

33. **曹爽出孙礼为扬州刺史。** 曹爽不便其刚直，使出为扬州刺史、伏波将军并赐爵。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **零陵报甘露。** 零陵报告甘露。 [[34]](#sgz-note-34)

<a id="sgz-event-35"></a>

35. **吴城沙羡。** 夏五月修沙羡城。 [[35]](#sgz-note-35)

<a id="sgz-event-36"></a>

36. **吴选宿卫郎吏依四科。** 孙权说宿卫郎吏应当精选，过去任用有人不合，自今三署按四科选，不得虚饰。 [[36]](#sgz-note-36)

<a id="sgz-event-37"></a>

37. **步骘借灾异劝孙权专任大臣。** 说官得其人即阴阳和，朝廷不任大臣致干旱；以地为臣象，解释地震警主。 [[37]](#sgz-note-37)

<a id="sgz-event-38"></a>

38. **步骘疏记正月两次地震及其征兆。** 赤乌二年正月初一与二十七地震，步骘说地震象臣下专政，愿孙权省察。 [[38]](#sgz-note-38)

<a id="sgz-event-39"></a>

39. **曹芳即位遣赵俨监雍凉。** 假节；后来历征蜀、征西将军以及都督西边。 [[39]](#sgz-note-39)

<a id="sgz-event-40"></a>

40. **曹芳即帝位赐卢毓关内侯。** 卢毓随曹芳继位获赐爵。 [[40]](#sgz-note-40)

<a id="sgz-event-41"></a>

41. **曹爽迁卢毓为仆射，以何晏主铨选。** 操权后为扩植亲党，改卢毓职，让何晏接手选举。 [[41]](#sgz-note-41)

### 1. 曹叡托孤后去世

> 三年春正月丁亥，太尉宣王還至河內，帝驛馬召到，引入臥內，執其手謂曰：「吾疾甚，以後事屬君，君其與爽輔少子。吾得見君，無所恨！」宣王頓首流涕。即日，帝崩於嘉福殿，時年三十六。癸丑，葬高平陵。

<a id="sg014-l774-e1"></a>

**[《三国志·程郭董刘蒋刘传》](../../sources/本地分卷/三国志/三国志-卷014.md#p006)** · [仓内TXT L774](../../sources/本地分卷/三国志/三国志-卷014.md#l774)

> 太尉亦至，登床受詔，然後帝崩。

<a id="sgz003-b-209-1"></a>

**[《三国志·明帝纪》仓内原文 L209](../../sources/本地分卷/三国志/三国志-卷003.md#l209)**

> 三年春正月丁亥，太尉宣王還至河內，帝驛馬召到，

**释读** 景初三年春正月丁亥，司马懿回军至河内，曹叡派驿马急召他到宫中。

**归年** 本纪景初三年正月丁亥。景初历正月建丑，以年号对照归239页。

<a id="sgz003-b-209-2"></a>

**[《三国志·明帝纪》仓内原文 L209](../../sources/本地分卷/三国志/三国志-卷003.md#l209)**

> 引入臥內，執其手謂曰：「吾疾甚，以後事屬君，君其與爽輔少子。吾得見君，無所恨！」宣王頓首流涕。

**释读** 曹叡把司马懿引入卧内，执手托付后事，命司马懿与曹爽共同辅佐少主；司马懿顿首流泪。

**归年** 本纪同日，卷004《齐王纪》同载；裴注有临终属托过程异文。

<a id="sgz003-b-209-3"></a>

**[《三国志·明帝纪》仓内原文 L209](../../sources/本地分卷/三国志/三国志-卷003.md#l209)**

> 即日，帝崩於嘉福殿，時年三十六。

**释读** 同日，曹叡死于嘉福殿。本纪记年三十六。

**归年** 本纪景初三年正月丁亥，明确卒年。裴松之以204年曹丕纳甄氏及历法改年辨“三十六”不合，保留史文年龄与异说。

<a id="sgz003-b-209-4"></a>

**[《三国志·明帝纪》仓内原文 L209](../../sources/本地分卷/三国志/三国志-卷003.md#l209)**

> 癸丑，葬高平陵。

**释读** 癸丑，安葬魏明帝于高平陵。

**归年** 本纪景初三年正月癸丑，后于丁亥去世。《资治通鉴》卷074同载。

<a id="sgz003-p-032-3"></a>

**[《三国志·明帝纪》裴注 032·3](../../sources/本地分卷/三国志/三国志-卷003.md#pei-032-3)**

> 宣王得前詔斯須復得後手筆疑京師有變乃馳到入見帝勞問訖乃召齊秦二王以示宣王别指齊王謂宣王曰此是也君諦視之勿誤也又教齊王令前抱宣王頸

**释读** 司马懿接连收到两份内容不同的诏书，以为京师有变而驰入。曹叡召齐王、秦王来见，明示齐王为嗣，让齐王上前抱住司马懿的颈。

**归年** 前后两诏为238年岁末与239年正月衔接的过程；入见明确在本纪景初三年正月丁亥，归239年第1条。

<a id="sgz003-p-032-4"></a>

**[《三国志·明帝纪》裴注 032·4](../../sources/本地分卷/三国志/三国志-卷003.md#pei-032-4)**

> 魏氏春秋曰時太子芳年八歲秦王九歲在于御側帝執宣王手目太子曰死乃復可忍朕忍死待君君其與爽輔此宣王曰陛下不見先帝屬臣以陛下乎

**释读** 《魏氏春秋》说曹芳八岁、曹询九岁在皇帝身侧；曹叡执司马懿手嘱其与曹爽辅曹芳，司马懿提起此前曹丕也将曹叡托付于他。

**归年** 附本纪正月丁亥临终托孤，所提曹丕之托是226年回忆。

<a id="sgz003-p-033-1"></a>

**[《三国志·明帝纪》裴注 033·1](../../sources/本地分卷/三国志/三国志-卷003.md#pei-033-1)**

> 魏書曰殯于九龍前殿

**释读** 《魏书》记曹叡死后殡在九龙前殿。

**归年** 本纪景初三年正月去世至安葬之间，正文日期丁亥、癸丑；殡日未单列。

<a id="sgz016-p-023-2"></a>

**[《三国志·任苏杜郑仓传》裴注 023·2](../../sources/本地分卷/三国志/三国志-卷016.md#pei-023-2)**

> 明帝崩時人多為恕言者

**释读** 曹叡去世，一些人替杜恕说话。

**归年** 《明帝纪》景初三年正月；注以明帝崩系其故。

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2572](../../sources/本地分卷/三国志/三国志-卷054.md#l2572)**

> 故將軍周瑜子胤，昔蒙粉飾，受封為將，不能養之以福，思立功效，至縱情慾，招速罪辟。臣竊以瑜昔見寵任，入作心膂，出為爪牙，銜命出征，身當矢石，盡節用命，視死如歸。故能摧曹操於烏林，走曹仁於郢都，揚國威德，華夏是震，蠢爾蠻荊，莫不賓服。雖周之方叔，漢之信、布，誠無以尚也。

**释读** 周胤受厚恩却纵欲招罪；二臣以父周瑜赴矢石，破曹操于乌林、逐曹仁，威振荆州为请。

**归年** 239年上疏中的旧事追叙，实际战年208—209。

<a id="sgz054-b-2572-2"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2572](../../sources/本地分卷/三国志/三国志-卷054.md#l2572)**

> 夫折沖扦難之臣，自古帝王莫不貴重，故漢高帝封爵之誓曰『使黃河如帶，太山如礪，國以永存，爰及苗裔』。申以丹書，重以盟詛，藏於宗廟，傳於無窮，欲使功臣之後，世世相踵，非徒子孫，乃關苗裔，報德明功，勤勤懇懇，如此之至，欲以勸戒後人，用命之臣，死而無悔也。

**释读** 引高祖河山带砺之誓、丹书庙藏，说明厚待功臣苗裔以令后人尽力。

**归年** 同239年联疏。

<a id="sgz054-b-2572-3"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2572](../../sources/本地分卷/三国志/三国志-卷054.md#l2572)**

> 況於瑜身沒未久，而其子胤降為匹夫，益可悼傷。竊惟陛下欽明稽古，隆於興繼，為胤歸訴，乞丐餘罪，還兵復爵，使失旦之雞，復得鳴。抱罪之臣，展其後效。

**释读** 二臣惋惜周瑜死后不久儿子降为平民，愿赦余罪、恢复兵爵，使他能再效于国。

**归年** 同239年联疏。

<a id="sgz054-b-2573-1"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2573](../../sources/本地分卷/三国志/三国志-卷054.md#l2573)**

> 權答曰：「腹心舊勳，與孤協事，公瑾有之，誠所不忘。昔胤年少，初無功勞，橫受精兵，爵以侯將，蓋念公瑾以及於胤也。而胤恃此，酗淫自恣，前後告喻，曾無悛改。孤於公瑾，義猶二君，樂胤成就，豈有已哉？迫胤罪惡，未宜便還，且欲苦之，使自知耳。

**释读** 孙权念周瑜旧勋，但周胤年少无功而受兵侯，后来酗酒荒淫且屡戒不改，所以先令改过。

**归年** 承239上表之答。

<a id="sgz054-b-2573-2"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2573](../../sources/本地分卷/三国志/三国志-卷054.md#l2573)**

> 今二君勤勤援引漢高河山之誓，孤用恧然。雖德非其疇，猶欲庶幾，事亦如爾，故未順旨。以公瑾之子，而二君在中間，苟使能改，亦何患乎！」

**释读** 引汉高祖誓言使孙权惭愧；称因周胤是功臣子，若能改便仍可复用。

**归年** 同一回复。

<a id="sgz054-b-2573-3"></a>

**[《三国志·周瑜鲁肃吕蒙传》仓内原文 L2573](../../sources/本地分卷/三国志/三国志-卷054.md#l2573)**

> 瑾、騭表比上，朱然及全琮亦俱陳乞，權乃許之。

**释读** 诸葛瑾、步骘连续求请，朱然、全琮也请，孙权批准。

**归年** 赤乌二年初疏所引后续，批准具体月未载。

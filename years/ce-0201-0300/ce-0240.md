# 公元240年｜魏正始元年／蜀延熙三年／吴赤乌三年

[← 公元239年](ce-0239.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元241年 →](ce-0241.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **加侍中中书监刘放、侍中中书令孙资为左右光禄大夫。** 正始元年春二月乙丑，加侍中中书监刘放、侍中中书令孙资为左右光禄大夫。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **以辽东汶、北丰县民流徙渡海。** 丙戌，以辽东汶、北丰县民流徙渡海，规齐郡之西安、临菑、昌国县界为新汶、南丰县，以居流民。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **自去冬十二月至此月不雨。** [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **诏令狱官亟平冤枉，理出轻微。** 丙寅，诏令狱官亟平冤枉，理出轻微；群公卿士谠言嘉谋，各悉乃心。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **车骑将军黄权薨。** 夏四月，车骑将军黄权去世。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **诏曰“易称损上益下”。** 秋七月，诏曰：「易称损上益下，节以制度，不伤财，不害民。方今百姓不足而御府多作金银杂物，将奚以为？今出黄金银物百五十种，千八百余斤，销冶以供军用。」 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **车驾巡省洛阳界秋稼，赐高年力田各有差。** 八月，车驾巡省洛阳界秋稼，赐高年力田各有差。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **魏遣梯俊至倭国授印绶。** 带方太守弓遵派梯俊捧诏印赴倭，授魏所赐名号、印绶与礼物，倭王遣使上表谢恩。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **张嶷治理越巂。** 蜀遣张嶷为越巂太守，逐步平定当地。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **向宠征汉嘉遇害。** 中领军向宠征讨汉嘉时遇害。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>



<a id="sg-event-12"></a>

12. **吴约束农时徭役并赈饥。** 孙权令督军、郡守纠察农时违规役民，冬十一月又因饥荒开仓救济。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **戴鵀之鸟，巢臶门阴。** 正始元年，戴鵀之鸟，巢臶门阴。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **出爲广平太守。** 正始元年，出爲广平太守。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **更加放左光禄大夫，资右光禄大夫。** 正始元年，更加放左光禄大夫，资右光禄大夫，金印紫绶，仪同三司。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **蜀将羌维出陇西。** 正始元年，蜀将羌维出陇西。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **还爲大司农。** 正始元年，还爲大司农。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **徙选曹尚书。** 赤乌三年，徙选曹尚书。 [[18]](#sg-note-18)

<a id="sgz-event-19"></a>

<a id="sgz-event-20"></a>

20. **姜维出陇西，郭淮追抵强中并改徙氐户。** 姜维退后，郭淮讨羌迷当并抚柔氐三千余部落，把人口迁往关中，迁左将军。 [[20]](#sgz-note-20)

<a id="sgz-event-21"></a>

21. **徐邈自凉州还任大司农。** 徐邈返朝为大司农。 [[21]](#sgz-note-21)

**释读** 蜀考虑恢复旧郡，任命张嶷为太守；张嶷率部入郡，以恩信招纳当地诸族。

**归年** 《后主传》延熙三年使张嶷安抚越巂，最初就任系该年。

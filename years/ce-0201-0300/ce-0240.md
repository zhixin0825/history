## 本年概述

魏久旱，曹芳命平反冤案、減省宮中用度，並巡察洛陽一帶秋稼。蜀漢仍在陇西用兵，張嶷治理越巂。魏遣使到倭國授印，吳同年申令保障農時並賑饑。

## 魏旱情與朝廷政事

<a id="sg-event-3"></a>

<a id="sg-event-4"></a>

<a id="sg-event-6"></a>

<a id="sg-event-7"></a>

1. **魏久旱，诏平冤狱并省用恤民。** 自上年十二月至二月，魏久无雨。曹芳命狱官平反冤案、从宽处置轻罪，并召公卿直陈政事。七月因百姓困乏，下令熔铸御府金银器一百五十种，共千八百余斤以供军用。八月曹芳巡视洛阳近郊秋稼，分别赐赏高年老人和力田者。 [[1]](#sg-note-3)

<a id="sg-event-15"></a>

<a id="sg-event-1"></a>

2. **加侍中中书监刘放、侍中中书令孙资为左右光禄大夫。** 正始元年春二月乙丑，加侍中中书监刘放、侍中中书令孙资为左右光禄大夫。 [[2]](#sg-note-1)

<a id="sg-event-2"></a>

3. **魏置新汶、南丰二县安置辽东移民。** 继上年置[新沓县](ce-0239.md#sg-note-12)以后，魏又划齐郡西安、临淄、昌国县部分辖境设置新汶、南丰二县，安置从辽东汶、北丰二县渡海而来的民众。 [[3]](#sg-note-2)

<a id="sg-event-5"></a>

4. **车骑将军黄权薨。** 夏四月，车骑将军黄权去世，谥景侯，儿子黄邕承袭爵位。 [[4]](#sg-note-5)

<a id="sg-event-14"></a>

5. **王肃任广平太守。** 王肃到任后寻访隐居求学的张臶，才得知他已[在当年去世](#sg-note-13)。 [[5]](#sg-note-14)

<a id="sgz-event-21"></a>

<a id="sg-event-17"></a>

6. **徐邈还朝任大司农。** 正始元年，凉州刺史徐邈还朝，任大司农。 [[6]](#sg-note-17)

<a id="sgz-event-24"></a>

7. **魏正始初起用诸葛诞。** 夏侯玄等在职，诸葛诞复任御史中丞尚书，再出任扬州刺史、昭武将军。 [[7]](#sgz-note-24)

## 使節往來與蜀、吳軍政

<a id="sg-event-8"></a>

8. **魏遣梯儁至倭国授印绶。** 带方太守弓遵派建中校尉梯儁捧诏赴倭，授卑弥呼魏廷先前所赐的名号、印绶和礼物。卑弥呼又派人向魏廷上表谢恩。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **张嶷入越巂平郡。** 依《后主传》，春，蜀汉派越巂太守张嶷恢复当地郡县；他在马忠统领下逐步收复失地。此年明确的是平郡行动，初任和还旧郡的年份另有疑异，《华阳国志》还旧郡作239，见同号注。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **向宠征汉嘉遇害。** 中领军向宠征讨汉嘉时遇害。 [[10]](#sg-note-10)

<a id="sgz-event-20"></a>

<a id="sg-event-16"></a>

11. **姜维出陇西，郭淮追至彊中。** 姜维出兵陇西，郭淮追至彊中，姜维退军。郭淮接着出兵讨迷当等，又招抚柔氐三千余落，内徙关中，后来升任左将军。 [[11]](#sg-note-16)

<a id="sg-event-11"></a>



<a id="sg-event-12"></a>

12. **吴约束农时徭役并赈饥。** 孙权令督军、郡守纠察农时违规役民，冬十一月又因饥荒开仓救济。 [[12]](#sg-note-12)

<a id="sgz-event-22"></a>

<a id="sg-event-18"></a>

13. **薛综任选曹尚书。** 赤乌三年，薛综改任选曹尚书。 [[13]](#sg-note-18)

<a id="sgz-event-19"></a>

<a id="sgz-event-23"></a>

14. **吴大赦并命郡县修守备。** 夏四月大赦，令诸郡县修城郭、建谯楼、筑壕沟以备盗。 [[14]](#sgz-note-23)

## 地方報聞

<a id="sg-event-13"></a>

15. **张臶去世，王肃表彰其家。** 张臶见戴鵀鸟在门的背阴处筑巢，自认为不祥，抚琴作诗二首，十日后去世，年一百零五。新任广平太守王肃闻讯，遣吏慰问张臶家属，并下令表彰。 [[15]](#sg-note-13)

## 《晉書·宣帝紀》補記

<a id="jin001-event-l45"></a>

16. **諸方遣使進貢，司馬懿增封。** 《晉書》記正始元年正月，倭國、焉耆、危須等及鮮卑名王遣使進貢，曹芳歸功輔臣，增加司馬懿封邑。這是本紀所列的一組進貢記載，不與先前卑彌呼遣使、魏授印綬混為同一批。 [[16]](#jin001-note-l45)

> 又越嶲郡亦乆失土地，忠率將太守張嶷開復舊郡，

**释读** 越巂郡长期失去对原有地区的控制，马忠统率太守张嶷恢复旧郡。

**归年与互校** [《后主传》](../../拆分史书/三国志/卷033.md#txt-l52)明记延熙三年春（240）使张嶷平越嶲，故将恢复属地的主要军事行动附本年。任命、还旧治、修城、通道历年展开，不全等于240。[《华阳国志》卷三的还郡异载](../../史书/062-华阳国志/KR2i0003_003.txt#L412-L415)作239，详见[张嶷任官互校](#shu043-l71-2)。

> 時論欲復舊郡，除嶷爲越嶲太守，嶷將所領往之郡，誘以恩信，蠻夷皆服，頗來降附。

**释读** 蜀廷要恢复越嶲旧郡的统治，任命张嶷为太守。张嶷率所部入郡，以恩信招抚，当地诸部陆续归附。

**归年与互校** [《后主传》](../../拆分史书/三国志/卷033.md#txt-l52)明记延熙三年春（240）使越嶲太守张嶷平郡，故本组随240年的军事行动合读，不能反推初任太守必在同年。254入朝所记“在郡十五年”可与240—254首尾计年相合，但只是一种核法。[《华阳国志》卷三](../../史书/062-华阳国志/KR2i0003_003.txt#L412-L415)另明书延熙二年（239）还旧郡，该本又说明此段旧文讹舛、曾加整顿，故作为异载保留；239说不全是十五年相减而来。

### 16. 諸方遣使進貢，司馬懿增封。

[返回正文第16條](#jin001-event-l45)

<a id="jin001-l45"></a>

> 正始元年春正月，東倭重譯納貢，焉耆、危須諸國，弱水以南，鮮卑名王，皆遣使來獻。天子歸美宰輔，又增帝封邑。

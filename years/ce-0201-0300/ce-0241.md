<a id="sg-event-1"></a>

1. **帝初通《论语》，使太常以太牢祭孔子于辟雍。** 二年春二月，帝初通《论语》，使太常以太牢祭孔子于辟雍，以颜渊配。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **吴将朱然等围襄阳之樊城。** 夏五月，吴将朱然等围襄阳之樊城，太傅司马宣王率衆拒之。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **退。** 六月辛丑，退。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **以征东将军王陵为车骑将军。** 己卯，以征东将军王陵为车骑将军。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **南安郡地震。** 冬十二月，南安郡地震。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **王基等荐管宁。** 管宁早年已辞多次朝命，陶丘一、王基等再次举荐。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **费祎至汉中议政。** 费祎赴汉中与蒋琬议国事，岁末回成都。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **杨戏作《季汉辅臣赞》。** 杨戏撰赞褒论蜀汉人物。陈寿将未立专传者的生平附在赞辞之后。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **全琮与王凌战于芍陂。** 吴军略淮南、决芍陂，全琮与魏将王凌交军，吴方中郎将秦晃等十余人战死。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **吴太子孙登去世。** 孙登五月去世。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **吴大将军诸葛瑾去世。** 吴大将军诸葛瑾在闰月去世。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **乃开广漕渠，每东南有事。** 正始二年，乃开广漕渠，每东南有事，大军兴众，泛舟而下，达于江、淮，资食有储而无水害，艾所建也。 [[12]](#sg-note-12)

<a id="sgz-event-13"></a>

13. **蒋琬造舟拟由汉水攻魏兴、上庸。** 蒋琬见先前取秦川路险粮难，拟从汉、沔水攻魏兴、上庸，造舟后因旧病未发。群臣认为失利后归路危险。 [[13]](#sgz-note-13)

### 10. 吴太子孙登去世

[返回正文第10条](#sg-event-10)

<a id="sg047-l2320-e10"></a>

**[《三国志·吴主传》](../../sources/摘录/三国志-卷047-吴主传.md#p009)** · [仓内TXT L2320](../../sources/本地分卷/三国志/三国志-卷047.md#L2320)

> 五月，太子登卒。

<a id="sy-sg059-l2819-e10"></a>

**[《三国志·吴主五子传》](../../sources/摘录/三国志-卷059-吴主五子传.md#p001)** · [仓内TXT L2819](../../sources/本地分卷/三国志/三国志-卷059.md#l2819)

> 旣絕而後書聞，權益以摧感，言則隕涕。是歲，赤烏四年也。謝景時爲豫章太守，不勝哀情，棄官奔赴，拜表自劾。權曰：「君與太子從事，異於他吏。」使中使慰勞，聽復本職，發遣還郡。謚登曰宣太子。

**本段所记** 孙登卒后遗表上达，孙权哀恸。豫章太守谢景弃官奔丧，自劾，孙权反而遣使慰劳、命他回郡。

**归年与互校** 本传明记是岁赤乌四年。

<a id="sgz059-b-2819-1"></a>

**[《三国志·吴主五子传》仓内原文 L2819](../../sources/本地分卷/三国志/三国志-卷059.md#l2819)**

> ﻿立凡二十一年，年三十三卒。

**释读** 孙登为储凡二十一年，三十三岁去世。

**归年** 本传末自明赤乌四年，《吴主传》五月死。

<a id="sgz059-b-2819-2"></a>

**[《三国志·吴主五子传》仓内原文 L2819](../../sources/本地分卷/三国志/三国志-卷059.md#l2819)**

> 臨終，上疏曰：「臣以無狀，嬰抱篤疾，自省微劣，懼卒隕斃。臣不自惜，念當委離供養，埋胔后土，長不復奉望宮省，朝覲日月，生無益於國，死貽陛下重慼，以此爲哽結耳。臣聞死生有命，長短自天，周晉、顏回有上智之才，而尚夭折，況臣愚陋，年過其壽，生爲國嗣，沒享榮祚，於臣已多，亦何悲恨哉！方今大事未定，逋寇未討，萬國喁喁，係命陛下，危者望安，亂者仰治。願陛下棄忘臣身，割下流之恩，脩黃老之術，篤養神光，加羞珍膳，廣開神明之慮，以定無窮之業，則率土幸賴，臣死無恨也。

**释读** 说自身死不足惜，愿孙权减轻丧忧、奉养身心以定大业。

**归年** 赤乌四年临终之疏，周晋、颜回是典故。

<a id="sgz059-b-2819-3"></a>

**[《三国志·吴主五子传》仓内原文 L2819](../../sources/本地分卷/三国志/三国志-卷059.md#l2819)**

> 皇子和仁孝聦哲，德行清茂，宜早建置，以繫民望。諸葛恪才略博達，器任佐時。張休、顧譚、謝景，皆通敏有識斷，入宜委腹心，出可爲爪牙。范慎、華融矯矯壯節，有國士之風。羊衜辯捷，有專對之材。刁玄優弘，志履道真。裴欽博記，翰采足用。蔣脩、虞翻，志節分明。凡此諸臣，或宜廊廟，或任將帥，皆練時事，明習法令，守信固義，有不可奪之志。此皆陛下日月所照，選置臣宮，得與從事，備知情素，敢以陳聞。

**释读** 建议孙和为储，荐诸葛恪、张休、顾谭、谢景和各僚属任事。

**归年** 同一241遗疏。孙和实际立储见242。

<a id="sgz059-b-2819-4"></a>

**[《三国志·吴主五子传》仓内原文 L2819](../../sources/本地分卷/三国志/三国志-卷059.md#l2819)**

> 臣重惟當今方外多虞，師旅未休，當厲六軍，以圖進取。軍以人爲衆，衆以財爲寶，竊聞郡縣頗有荒殘，民物凋弊，姦亂萌生，是以法令繁滋，刑辟重切。臣聞爲政聽民，律令與時推移，誠宜與將相大臣詳擇時宜，博採衆議，寬刑輕賦，均息力役，以順民望。

**释读** 建议与将相商议，宽刑轻赋，减省力役。

**归年** 同一241遗疏，经济与法令是奏疏所论，未必当年施行。

<a id="sgz059-b-2819-5"></a>

**[《三国志·吴主五子传》仓内原文 L2819](../../sources/本地分卷/三国志/三国志-卷059.md#l2819)**

> 陸遜忠勤於時，出身憂國，謇謇在公，有匪躬之節。諸葛瑾、步隲、朱然、全琮、朱據、呂岱、吾粲、闞澤、嚴畯、張承、孫怡忠於爲國，通達治體。可令陳上便宜，蠲除苛煩，愛養士馬，撫循百姓。五年之外，十年之內，遠者歸復，近者盡力，兵不血刃，而大事可定也。臣聞『鳥之將死其鳴也哀，人之將死其言也善』，故子囊臨終，遺言戒時，君子以爲忠，豈況臣登，其能已乎？願陛下留意聽采，臣雖死之日，猶生之年也。」

**释读** 赞陆逊忠勤和诸葛瑾等诸人通达政体，建议使其陈便宜，宽政抚民。

**归年** 同一死前遗疏末，所举子囊遗言是典。

<a id="sgz059-b-2819-6"></a>

**[《三国志·吴主五子传》仓内原文 L2819](../../sources/本地分卷/三国志/三国志-卷059.md#l2819)**

> 旣絕而後書聞，權益以摧感，言則隕涕。是歲，赤烏四年也。

**释读** 疏呈上时孙登已去世，孙权见而摧感。

**归年** 本段自署赤乌四年。

<a id="sgz059-b-2819-7"></a>

**[《三国志·吴主五子传》仓内原文 L2819](../../sources/本地分卷/三国志/三国志-卷059.md#l2819)**

> 謝景時爲豫章太守，不勝哀情，棄官奔赴，拜表自劾。權曰：「君與太子從事，異於他吏。」使中使慰勞，聽復本職，發遣還郡。謚登曰宣太子。

**释读** 谢景弃职奔丧并自劾。孙权念旧，慰劝后令回任；孙登谥宣太子。

**归年** 赤乌四年孙登死后同组史事，《吴主传》书宣太子。

<a id="sgz059-p-004-1"></a>

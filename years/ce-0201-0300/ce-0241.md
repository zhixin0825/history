## 本年概述

吳分路向魏進兵，朱然圍樊城，全琮與王凌戰於芍陂，諸葛恪攻六安。魏議開渠屯田。蜀漢討論自漢水進兵的路線，東吳太子孫登與諸葛瑾先後去世。

## 樊城、芍陂與淮南軍務

<a id="sg-event-3"></a>

<a id="sg-event-2"></a>

<a id="sgz-event-19"></a>

1. **朱然等围樊城，魏派司马懿救援。** 五月，朱然围襄阳一带的樊城，吕据、朱异攻破其外围。魏荆州刺史胡质认为樊城地势低、守兵少，率轻兵赶到城外接应，守军得以稳住阵脚。六月，魏太傅司马懿率诸军南下解围，先遣轻骑挑战，再整顿军伍准备进攻。吴军夜撤，魏军追至三州口，缴获舟船和军资。吕据和朱异回军后任偏将军。吴军在岘山东采木时，士兵已把不肯接受他人食物的人比作以清介闻名的沐并。魏军回师后，司马懿受封赏，仍以乡里晚辈之礼拜见太常常林。 [[1]](#sg-note-2)

<a id="sg-event-9"></a>

2. **全琮与王凌战于芍陂。** 吴军略淮南、决芍陂，全琮与魏将王凌交军，吴军失利，中郎将秦晃等十余人战死。魏扬州刺史孙礼遇到州兵多在休假，只得率留守将士应战，自早至晚，所部死伤过半。他的坐骑多次受创，他仍亲自击鼓督战。张休、顾承反击，阻住魏军攻势。全绪、全端趁势进击，王凌收兵，吴军后来也撤走。魏廷赐孙礼七百匹绢。他为阵亡将士设祭，把所赐的绢全数分给死者家属。吴军在淮南失利收船，早年筑起的[东兴堤](ce-0230.md#ce0230-note-11)随之废弃。吴方论功，以阻住魏军较难，张休、顾承并拜杂号将军，顾承获奋威将军之号，后出督京下；全绪、全端只授偏裨。 [[2]](#sg-note-9)

<a id="sgz-event-17"></a>

3. **诸葛恪攻六安。** 诸葛恪率军攻六安，以助同年吴军淮南行动。 [[3]](#sgz-note-17)

<a id="sgz-event-18"></a>

4. **陆逊修邾城。** 八月陆逊筑邾城。 [[4]](#sgz-note-18)

<a id="sgz-event-20"></a>

<a id="sg-event-12"></a>

5. **邓艾议淮南屯田，魏开广漕渠。** 邓艾从陈、项考察到寿春，写成《济河论》，建议开渠兼顾漕运和灌溉，在淮北、淮南增设屯田，把余粮就地储作军用。司马懿采纳。魏本年开凿广漕渠，后来得以水运供给东南诸军。 [[5]](#sg-note-12)

<a id="sg-event-4"></a>

6. **以征东将军王陵为车骑将军。** 己卯，以征东将军王陵为车骑将军。 [[6]](#sg-note-4)

## 魏廷文教與地方災情

<a id="sg-event-1"></a>

7. **帝初通《论语》，使太常以太牢祭孔子于辟雍。** 二年春二月，帝初通《论语》，使太常以太牢祭孔子于辟雍，以颜渊配。 [[7]](#sg-note-1)

<a id="sg-event-5"></a>

8. **南安郡地震。** 冬十二月，南安郡地震。 [[8]](#sg-note-5)

<a id="sg-event-6"></a>

9. **王基等荐管宁。** 管宁曾多次辞官。太仆陶丘一、永宁卫尉孟观、侍中孙邕、中书侍郎王基联名上表，请按前朝礼贤旧例，备礼聘他入朝议政。魏廷于是备蒲轮安车、帛和玉璧征聘。 [[9]](#sg-note-6)

<a id="sgz-event-15"></a>

10. **管宁去世。** 聘礼尚未请得管宁到朝，他便去世，传记其年八十四。他的儿子管邈随后获授郎中，日后任博士。 [[10]](#sgz-note-15)

<a id="sgz-event-16"></a>

11. **大雪伤鸟兽。** 春正月大雪，地积三尺，鸟兽死去大半。 [[11]](#sgz-note-16)

## 蜀、吳朝廷紀事

<a id="sg-event-7"></a>

12. **费祎至汉中议政，朝廷劝止水攻。** 十月，尚书令费祎到汉中与蒋琬商议国事，年底回成都。本传另记费祎、中监军姜维奉命向蒋琬说明朝廷反对水路东攻的意见；蒋琬上疏与实际移驻涪县的系年，见[243年对应条目](ce-0243.md#shu044-l13-3)。 [[12]](#sg-note-7)

<a id="sg-event-8"></a>

13. **杨戏作《季汉辅臣赞》。** 杨戏撰序与赞辞，先追述刘备创业、承汉宗祀，再评论诸葛亮及蜀汉文武。赞语既表彰谋略、忠勇、清节和文治，也批评李严、魏延、杨仪以及降吴诸人的行止，并哀悼夷陵死者。全篇按本年成文阅读，所叙旧事另见相关年页。陈寿后来收入本传，并为未立专传者补述生平；附传中晚于241年的事迹，不属于杨戏在本年所写的赞辞。 [[13]](#sg-note-8)

<a id="sgz-event-13"></a>

14. **附记：蒋琬水攻计划的筹备时间未详。** 蒋琬屯汉中期间，认为取秦川路险粮难，拟造舟沿汉、沔水袭魏兴、上庸，因旧病未能出发；群臣又担心失利后难以回师。《通鉴》在本年叙此，筹划及造舟的具体起年未载，见[时期材料与互校](时期-三国志卷044-蒋琬费祎姜维传纪年待考.md#shu044-l13-1)。 [[14]](#sgz-note-13)

<a id="sg-event-10"></a>

15. **太子孙登去世，遗疏劝立孙和。** 五月，太子孙登病逝，年三十三，居储位二十一年。他临终上疏劝孙权节哀自养，请早立皇子孙和以安人心，并荐举诸葛恪、张休、顾谭、谢景等东宫旧臣。孙登认为战事未息、郡县百姓困乏，建议宽刑轻赋、减省徭役，请陆逊、诸葛瑾、步骘等将相陈述治国方略。奏疏送到时孙登已死，孙权读后悲痛。豫章太守谢景离任奔丧并上表自劾，孙权因他曾与太子共事，遣使慰问，令他回原任。孙登谥宣太子，初葬句容，设园邑奉守。此后张休任侍中，领羽林，后来迁扬武将军。 [[15]](#sg-note-10)

<a id="sg-event-11"></a>

16. **诸葛瑾去世，诸葛融袭爵驻公安。** 吴大将军诸葛瑾闰月去世，年六十八，遗命用素棺和时服收殓，务从简约。其子诸葛恪已另受爵，便由诸葛融袭爵并接领父亲的军队，驻守公安。 [[16]](#sg-note-11)

<a id="sgz-event-14"></a>

17. **孙韶去世。** 孙韶去世，其子孙越嗣爵。 [[17]](#sgz-note-14)

### 1. 朱然等围樊城，魏派司马懿救援

[返回正文第1条](#sg-event-2)

**《三少帝紀》互見** [TXT 第21行](../../拆分史书/三国志/卷004.md#edition-wei004-l21-1)

<a id="wei027-l28-2"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l28-2)** · [TXT L28](../../拆分史书/三国志/卷027.txt#L28)

> 吳大將朱然圍樊城，質輕軍赴之。議者皆以爲賊盛不可迫，質曰：「樊城卑下，兵少，故當進軍爲之外援；不然，危矣。」遂勒兵臨圍，城中乃安。

**釋讀與歸年** 朱然圍樊城，胡質認為城低兵少，須及時接應，率輕軍逼近圍城之吳軍，使城內獲安。[《資治通鑑》卷七十四](../../史书/025-资治通鉴/KR2b0007_074.txt#L393-L409)明係正始二年，先敘胡質部至，後記司馬懿六月又督諸軍赴援。與237年朱然圍江夏和242年柤中戰事的地點、行軍記述有別。

<a id="wei023-l36-4"></a>

<a id="wei023-l37-1"></a>

**[《三國志·和常楊杜趙裴傳》](../../拆分史书/三国志/卷023.md#edition-wei023-l36-4)** · [TXT L36](../../拆分史书/三国志/卷023.txt#L36) · [TXT L37（裴注）](../../拆分史书/三国志/卷023.txt#L37)

> 晉宣王以林鄉邑耆德，每爲之拜。或謂林曰：「司馬公貴重，君宜止之。」林曰：「司馬公自欲敦長幼之叙，爲後生之法。貴非吾之所畏，拜非吾之所制也。」言者踧踖而退。
>
> **〔裴注〕**
> 魏略曰：初，林少與司馬京兆善。太傅每見林，輒欲跪。林止之曰：「公尊貴矣，止也！」及司徒缺，太傅有意欲以林補之。案魏略此語，與本傳反。　臣松之以爲林之爲人，不畏權貴者也。論其然否，謂本傳爲是。

**釋讀與歸年** 司马懿敬常林为乡里长辈，每会皆行拜礼；常林说敬长辈是给后进示范，不因司马懿权势而拒礼。[《晋书·宣帝纪》](../../史书/005-晋书/晋书-CCDH.txt#L47-L49)在正始二年司马懿救樊城、增封后附记其谦恭事迹，本文每见之拜属总叙，随241年本纪集中附载。

**釋讀與歸年** 《魏略》另称常林曾制止司马懿行礼，司马懿又想补任常林为司徒；裴松之认为本传可信。此为上条同事互校，司徒缺位的确年未载。

<a id="wei023-l39-12"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l39-12)** · [TXT L39](../../拆分史书/三国志/卷023.txt#L39)

> 時吳使朱然、諸葛瑾攻圍樊城，遣船兵於峴山東斫材，牂牁人兵作食，有先熟者呼後熟者，言：「共食來。」後熟者荅言：「不也。」呼者曰：「汝欲作沐德信邪？」其名流布，播於異域如此。雖自華夏，不知者以爲前世人也。

**釋讀與歸年** 正始二年吴军北进时，峴山采木的牂牁士兵以“沐德信”比喻克己不受食，见沐并清介之名流传甚远。《魏略》概称朱然、诸葛瑾攻樊城，[《三少帝纪》](../../拆分史书/三国志/卷004.txt)与[《晋书·宣帝纪》](../../史书/005-晋书/晋书-CCDH.txt#L47-L48)则记吴军分路，朱然围樊，诸葛瑾另趋柤中。

<a id="wei015-l60-2"></a>

**[《三國志·劉司馬梁張溫賈傳》裴注](../../拆分史书/三国志/卷015.md#edition-wei015-l60-2)** · [TXT L60](../../拆分史书/三国志/卷015.txt#L60)

> 正始二年，朱然圍樊城，城中守將乙脩等求救甚急。儒進屯鄧塞，以兵少不敢進，但作鼓吹，設導從，去然六七里，翱翔而還，使脩等遙見之，數數如是。月餘，及太傅到，乃俱進，然等走。時謂儒爲怯，或以爲曉以少疑衆，得聲救之宜。儒猶以此召還，爲太僕。

**釋讀與歸年** 正始二年朱然围樊城，乙脩告急。夏侯儒屯邓塞，因兵少以鼓吹导从反复示威，等司马懿到后一道进兵，朱然退。有人讥他怯，有人赞以少疑众为得策；夏侯儒仍被召还任太仆。

> **〔裴注〕**
> 漢晉春秋曰：零陵太守殷禮言於權曰：「今天棄曹氏，喪誅累見，虎爭之際而幼童莅事。陛下身自御戎，取亂侮亡，宜滌荊、揚之地，舉彊羸之數，使彊者執戟，羸者轉運，西命益州軍于隴右，授諸葛瑾、朱然大衆指事襄陽，陸遜、朱桓別征壽春，大駕入淮陽，歷青、徐。襄陽、壽春困於受敵，長安以西務對蜀軍，許、洛之衆勢必分離；掎角瓦解，民必內應，將帥對向，或失便宜；一軍敗績，則三軍離心，便當秣馬脂車，陵蹈城邑，乘勝逐北，以定華夏。若不悉軍動衆，循前輕舉，則不足大用，易於屢退。民疲威消，時往力竭，非出兵之策也。」權弗能用之。

**釋讀** 零陵太守殷禮建議吳、蜀分路攻魏，並請孫權親率主力入淮陽。此為議案，孫權未採用。

**歸年** 《資治通鑑》卷七十四列於正始二年春，作「殷札」，注一作「殷禮」。所提朱桓已於赤烏元年卒，議案與當年各軍實際行動分讀。

**释读** 殷札设想魏兵多处分离、有内应，吴可乘势追击。若沿用轻出即退之法，只会耗尽民力。孙权未采用此计。
**归年** 同一次伐魏前议，策略主张未实际执行。

> 干寶晉紀曰：吳將全琮寇芍陂，朱然、孫倫五萬人圍樊城，諸葛瑾、步隲寇柤中；琮已破走而樊圍急。宣王曰：「柤中民夷十萬，隔在水南，流離無主，樊城被攻，歷月不解，此危事也，請自討之。」議者咸言：「賊遠圍樊城不可拔，挫於堅城之下，有自破之勢，宜長策以御之。」宣王曰：「軍志有之：將能而御之，此爲縻軍；不能而任之，此爲覆軍。今疆埸騷動，民心疑惑，是社稷之大憂也。」六月，督諸軍南征，車駕送津陽城門外。宣王以南方暑溼，不宜持乆，使輕騎挑之，然不敢動。於是乃令諸軍休息洗沐，簡精銳，募先登，申號令，示必攻之勢。然等聞之，乃夜遁。追至三州口，大殺獲。

### 5. 邓艾议淮南屯田，魏开广漕渠

**[《三國志·王毋丘諸葛鄧鍾傳》正文](../../拆分史书/三国志/卷028.md#edition-wei028-l103-1)** · [TXT L103](../../拆分史书/三国志/卷028.txt#L103)

> 時欲廣田畜糓，爲滅賊資，使艾行陳、項已東至壽春。艾以爲「田良水少，不足以盡地利，宜開河渠，可以引水澆溉，大積軍糧，又通運漕之道。」乃著濟河論以喻其指。又以爲「昔破黃巾，因爲屯田，積穀於許都以制四方。今三隅已定，事在淮南，每大軍征舉，運兵過半，功費巨億，以爲大役。陳、蔡之間，土下田良，可省許昌左右諸稻田，并水東下。令淮北屯二萬人，淮南三萬人，十二分休，常有四萬人，且田且守。水豐常收三倍於西，計除衆費，歲完五百萬斛以爲軍資。六七年間，可積三千萬斛於淮上，此則十萬之衆五年食也。以此乘吳，無往而不克矣。」宣王善之，事皆施行。正始二年，乃開廣漕渠，每東南有事，大軍興衆，汎舟而下，達于江、淮，資食有儲而無水害，艾所建也。

> 臣聞龍鳳隱耀，應德而臻，明哲潛遁，俟時而動。是以鸞鷟鳴岐，周道隆興，四皓爲佐，漢帝用康。伏見太中大夫管寧，應二儀之中和，總九德之純懿，含章素質，冰絜淵清，玄虛澹泊，與道逍遙；娛心黃老，游志六藝，升堂入室，究其閫奧，韜古今於胷懷，包道德之機要。中平之際，黃巾陸梁，華夏傾蕩，王綱弛頓。遂避時難，乘桴越海，羈旅遼東三十餘年。在乾之姤，匿景藏光，嘉遁養浩，韜韞儒墨，潛化傍流，暢於殊俗。
>
> 黃初四年，高祖文皇帝疇咨羣公，思求儁乂，故司徒華歆舉寧應選，公車特徵，振翼遐裔，翻然來翔。行遇屯厄，遭罹疾病，即拜太中大夫。烈祖明皇帝嘉美其德，登爲光祿勳。寧疾彌留，未能進道。今寧舊疾已瘳，行年八十，志無衰倦。環堵篳門，偃息窮巷，飯鬻餬口，并日而食，吟詠詩書，不改其樂。困而能通，遭難必濟，經危蹈險，不易其節，金聲玉色，乆而彌彰。揆其終始，殆天所祚，當贊大魏，輔亮雍熙。袞職有闕，羣下屬望。昔高宗刻象，營求賢哲，周文啟龜，以卜良佐。況寧前朝所表，名德已著，而乆栖遲，未時引致，非所以奉遵明訓，繼成前志也。陛下踐阼，纂承洪緒。聖敬日躋，超越周成。每發德音，動諮師傅。若繼二祖招賢故典，賔禮儁邁，以廣緝熙，濟濟之化，侔於前代。
>
> 寧清高恬泊，擬跡前軌，德行卓絕，海內無偶。歷觀前世玉帛所命，申公、枚乘、周黨、樊英之儔，測其淵源，覽其清濁，未有厲俗獨行若寧者也。誠宜束帛加璧，備禮徵聘，仍授几杖，延登東序，敷陳墳素，坐而論道，上正璇璣，恊和皇極，下阜羣生，彝倫攸叙，必有可觀，光益大化。若寧固執匪石，守志箕山，追迹洪崖，參蹤巢、許。斯亦聖朝同符唐、虞，優賢揚歷，垂聲千載。
>
> **〔裴注〕**
> 今文尚書曰「優賢揚歷」，謂揚其所歷試。左思魏都賦曰：「優賢著於揚歷」也。
>
> **〔正文續〕**
> 雖出處殊塗，俯仰異體，至於興治美俗，其揆一也。

**釋讀與歸年** 正始二年陶丘一、孟观、孙邕、王基联名荐管宁。表文跨数行，连读。

**釋讀與歸年** 荐表先引凤鸣岐山和汉初四皓，再提管宁品德、学问与避黄巾渡海，三十余年间在辽东化俗。中平和辽东经历是241年书中的追叙。

**釋讀與歸年** 荐表追述曹丕在223年征管宁，曹叡后加光禄勋，称管宁虽贫病已高年，仍读书安道，劝曹芳接续两代礼贤之制。表报「行年八十」而卒载八十四。卒年不能仅由这两个数字倒推。

**釋讀與歸年** 荐表列申公、枚乘等汉代旧例，请备玉帛、几杖优礼征访。即使管宁坚持隐退，也足以表彰贤德。下一句仍属表文。

**釋讀與歸年** 裴注以今文《尚书》和左思《魏都赋》释表中「優賢揚歷」。所引古文和晋人赋句是裴注用来释义，未单立纪年。

**釋讀與歸年** 荐表结语谓在朝和隐逸路径不同，都可助成良好风俗。

> 戲以延熈四年著季漢輔臣贊，

**释读** 杨戏在延熙四年撰写《季汉辅臣赞》。

**归年与互校** 本传明记延熙四年，即241年；后附赞辞均以此为撰作时点，人物附传再按所叙事件分别处理。

**[《三國志·鄧張宗楊傳》正文](../../拆分史书/三国志/卷045.md#edition-shu045-l48-1)** · [TXT L48](../../拆分史书/三国志/卷045.txt#L48)

> 昔文王歌德，武王歌興，夫命世之主，樹身行道，非唯一時，亦由開基植緒，光于來世者也。自我中漢之末，王綱棄柄，雄豪並起，役殷難結，生人塗地。於是世主感而慮之，初自燕、代則仁聲洽著，行自齊、魯則英風播流，寄業荊、郢則臣主歸心，顧援吳、越則賢愚賴風，奮威巴、蜀則萬里肅震，厲師庸、漢則元寇歛迹，故能承高祖之始兆，復皇漢之宗祀也。然而姦凶懟險，天征未加，猶孟津之翔師，復須戰於鳴條也。天祿有終，奄忽不豫。雖攝歸一統，萬國合從者，當時儁乂扶攜翼戴，明德之所懷致也，蓋濟濟有可觀焉。遂乃並述休風，動于後聽。其辭曰：

**释读** 杨戏在序中说，古人歌颂周文王的德行与周武王的兴起，因为应世而生的君主建立自身、实行正道，影响不限于一时，还在于开创基业，把光辉传给后世。东汉末年，王朝失去统御权，群雄并起，战事频繁，灾难相连，百姓遭受涂炭。刘备因此感慨忧虑，从燕、代起步，仁名逐渐显著；转战齐、鲁，英风传播；寄身荆州，得到君臣归心；援助吴、越，贤愚都依赖他的声望；在巴、蜀奋起，使远方震动；整军取上庸、汉中，使强敌退缩，于是承继汉高祖的开创事业，恢复汉家宗祀。

序文又说，凶险的敌人仍未受到征讨，正如周武王会师孟津之后仍待进兵，又如商汤必须战于鸣条。刘备却天命已终，忽然患病而死。文中把聚众归附称为“摄归一统、万国合从”，将这些成就归于当时俊杰的扶持，也归于刘备德望的招徕，认为众臣之盛值得记述，所以一并写下其美善风范，留给后来人听闻，随后列出赞辞。

### 18. 曹髦出生

[返回正文第18条](#wei004-event-241-birth)

<a id="wei004-l112-birth"></a>

**[《三國志·三少帝紀》裴注引《帝集》](../../拆分史书/三国志/卷004.md#edition-wei004-l112-1)** · [TXT L112](../../拆分史书/三国志/卷004.txt#L112)

> 帝集載帝自敘始生禎祥曰：「昔帝王之生，或有禎祥，蓋所以彰顯神異也。惟予小子，支胤末流，謬爲靈祇之所相祐也，豈敢自比於前喆，聊記錄以示後世焉。其辭曰：惟正始三年九月辛未朔，二十五日乙未直成，予生。于時也，天氣清明，日月暉光，爰有黃氣，烟熅於堂，照曜室宅，其色煌煌。相而論之曰：未者爲土，魏之行也；厥日直成，應嘉名也；烟熅之氣，神之精也；無災無害，蒙神靈也。齊王不弔，顛覆厥度，羣公受予，紹繼皇祚。以眇眇之身，質性頑固，未能涉道，而遵大路，臨深履冰，涕泗憂懼。古人有云，懼則不亡。伊予小子，曷敢怠荒？庶不忝辱，永奉烝甞。」

**歸年** 底本作「正始三年九月辛未朔，二十五日乙未」。潘眉《三國志旁證》卷六推得正始三年（242）九月朔为丙寅，二十五日应为庚寅。正始二年（241）九月朔为辛未，二十五日确为乙未。生年依月朔和日干支系正始二年，[正始三年存年号异文](ce-0242.md#wei004-l112-birth)。黄气为曹髦的自述，全文作于即位以后，撰年未明。

## 本年概述

吳分路向魏進兵，朱然圍樊城，全琮與王凌戰於芍陂，諸葛恪攻六安。魏議開渠屯田。蜀漢討論自漢水進兵的路線，東吳太子孫登與諸葛瑾先後去世。

## 樊城、芍陂與淮南軍務

<a id="sg-event-3"></a>

<a id="sg-event-2"></a>

<a id="sgz-event-19"></a>

1. **朱然等围樊城，魏派司马懿救援。** 夏五月，朱然等围襄阳一带的樊城，吕据和朱异破其外围，魏太傅司马懿率众抵御。吴军屯在樊城外时曾伐木作炊，军士间还传称以廉洁著名的沐并，后来吴军撤围。吕据和朱异回军后任偏将军。 [[1]](#sg-note-2)

<a id="sg-event-9"></a>

2. **全琮与王凌战于芍陂。** 吴军略淮南、决芍陂，全琮与魏将王凌交军，吴军失利，中郎将秦晃等十余人战死。张休、顾承反击，阻住魏军攻势。全绪、全端趁势进击，王凌收兵，吴军后来也撤走。吴军在淮南失利收船，早年筑起的[东兴堤](ce-0230.md#ce0230-note-11)随之废弃。吴方论功，以阻住魏军较难，张休、顾承并拜杂号将军，顾承获奋威将军之号，后出督京下；全绪、全端只授偏裨。 [[2]](#sg-note-9)

<a id="sgz-event-17"></a>

3. **诸葛恪攻六安。** 诸葛恪率军攻六安，以助同年吴军淮南行动。 [[3]](#sgz-note-17)

<a id="sgz-event-18"></a>

4. **陆逊修邾城。** 八月陆逊筑邾城。 [[4]](#sgz-note-18)

6. **以征东将军王陵为车骑将军。** 己卯，以征东将军王陵为车骑将军。 [[6]](#sg-note-4)

## 蜀、吳朝廷紀事

<a id="sg-event-7"></a>

12. **费祎至汉中议政。** 费祎赴汉中与蒋琬议国事，岁末回成都。 [[12]](#sg-note-7)

<a id="sg-event-8"></a>

13. **杨戏作《季汉辅臣赞》。** 杨戏撰赞褒论蜀汉人物。陈寿将未立专传者的生平附在赞辞之后。 [[13]](#sg-note-8)

<a id="sgz-event-13"></a>

14. **蒋琬造舟拟由汉水攻魏兴、上庸。** 蒋琬见先前取秦川路险粮难，拟从汉、沔水攻魏兴、上庸，造舟后因旧病未发。群臣认为失利后归路危险。 [[14]](#sgz-note-13)

<a id="sg-event-10"></a>

15. **太子孙登去世，遗疏劝立孙和。** 五月，太子孙登病逝，年三十三，居储位二十一年。他临终上疏劝孙权节哀自养，请早立皇子孙和以安人心，并荐举诸葛恪、张休、顾谭、谢景等东宫旧臣。孙登认为战事未息、郡县百姓困乏，建议宽刑轻赋、减省徭役，请陆逊、诸葛瑾、步骘等将相陈述治国方略。奏疏送到时孙登已死，孙权读后悲痛。豫章太守谢景离任奔丧并上表自劾，孙权因他曾与太子共事，遣使慰问，令他回原任。孙登谥宣太子，初葬句容，设园邑奉守。此后张休任侍中，领羽林，后来迁扬武将军。 [[15]](#sg-note-10)

<a id="sg-event-11"></a>

16. **诸葛瑾去世，诸葛融袭爵驻公安。** 吴大将军诸葛瑾闰月去世，年六十八，遗命用素棺和时服收殓，务从简约。其子诸葛恪已另受爵，便由诸葛融袭爵并接领父亲的军队，驻守公安。 [[16]](#sg-note-11)

<a id="sgz-event-14"></a>

17. **孙韶去世。** 孙韶去世，其子孙越嗣爵。 [[17]](#sgz-note-14)

> 漢晉春秋曰：零陵太守殷禮言於權曰：「今天棄曹氏，喪誅累見，虎爭之際而幼童莅事。陛下身自御戎，取亂侮亡，宜滌荊、揚之地，舉彊羸之數，使彊者執戟，羸者轉運，西命益州軍于隴右，授諸葛瑾、朱然大衆指事襄陽，陸遜、朱桓別征壽春，大駕入淮陽，歷青、徐。

**[《三國志·吳主傳》 裴注 047·2](../../拆分史书/三国志/卷047.md#pei-047-2)** · [TXT L161](../../拆分史书/三国志/卷047.txt#L161)

> 襄陽、壽春困於受敵，長安以西務對蜀軍，許、洛之衆勢必分離；掎角瓦解，民必內應，將帥對向，或失便宜；一軍敗績，則三軍離心，便當秣馬脂車，陵蹈城邑，乘勝逐北，以定華夏。若不悉軍動衆，循前輕舉，則不足大用，易於屢退。民疲威消，時往力竭，非出兵之策也。」權弗能用之。

**释读** 殷札设想魏兵多处分离、有内应，吴可乘势追击。若沿用轻出即退之法，只会耗尽民力。孙权未采用此计。

**[《三國志·吳主五子傳》正文](../../拆分史书/三国志/卷059.md#edition-wu059-l15-4)** · [TXT L15](../../拆分史书/三国志/卷059.txt#L15)

> 臣重惟當今方外多虞，師旅未休，當厲六軍，以圖進取。軍以人爲衆，衆以財爲寶，竊聞郡縣頗有荒殘，民物凋弊，姦亂萌生，是以法令繁滋，刑辟重切。臣聞爲政聽民，律令與時推移，誠宜與將相大臣詳擇時宜，博采衆議，寬刑輕賦，均息力役，以順民望。

**釋讀** 孫登以境外有憂、戰事未息，練軍進取需要人口、財力。因郡縣荒殘、百姓困乏而法禁、刑罰加重，請與將相商議，使法令隨時調整，寬刑、輕賦，減省力役。

**歸年** 同一241年臨終奏疏，為奏議中的診斷及主張，施行與否未見於本條。

**[《三國志·吳主五子傳》正文](../../拆分史书/三国志/卷059.md#edition-wu059-l15-5)** · [TXT L15](../../拆分史书/三国志/卷059.txt#L15)

> 陸遜忠勤於時，出身憂國，謇謇在公，有匪躬之節。諸葛瑾、步隲、朱然、全琮、朱據、呂岱、吾粲、闞澤、嚴畯、張承、孫怡忠於爲國，通達治體。可令陳上便宜，蠲除苛煩，愛養士馬，撫循百姓。五年之外，十年之內，遠者歸復，近者盡力，兵不血刃，而大事可定也。臣聞『鳥之將死其鳴也哀，人之將死其言也善』，故子囊臨終，遺言戒時，君子以爲忠，豈況臣登，其能已乎？願陛下留意聽采，臣雖死之日，猶生之年也。」

**釋讀** 孫登稱陸遜憂國忠勤，又稱諸葛瑾、步隲、朱然、全琮、朱據、呂岱、吾粲、闞澤、嚴畯、張承、孫怡忠國且通曉政體。請讓諸人陳述政策利弊，除苛法，養士馬，安撫百姓，盼數年後遠人歸附、近人效力。末引臨終善言及楚令尹子囊的遺戒，請孫權留意。

**歸年** 同一241年臨終奏疏。陸遜等是建議諮詢國政的將相舊臣，與前段東宮人選分別閱讀。此處未載孫權是否另外命諸人陳奏。

> 旣絕而後書聞，權益以摧感，言則隕涕。是歲，赤烏四年也。謝景時爲豫章太守，不勝哀情，棄官奔赴，拜表自劾。權曰：「君與太子從事，異於他吏。」使中使慰勞，聽復本職，發遣還郡。謚登曰宣太子。

**釋讀** 孫登死後，奏疏才上達，孫權悲痛，談及便流淚。豫章太守謝景離職奔喪，上表自劾。孫權念及謝景曾與太子共事，遣宮中使者慰問，讓他回原任。孫登謚宣太子。

**歸年** 本段自署赤烏四年，讀作五月孫登卒的後續，謝景奔喪、復官未載確日。

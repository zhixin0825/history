<a id="sg-event-1"></a>

1. **东平王徽薨。** 三年春正月，东平王徽去世。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **太尉满宠薨。** 三月，太尉满宠去世。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **南安郡地震。** 秋七月甲申，南安郡地震。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **以领军将军蒋济为太尉。** 乙酉，以领军将军蒋济为太尉。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **魏郡地震。** 冬十二月，魏郡地震。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **高句丽王宫寇西安平。** 高句丽王宫侵扰西安平，其后与魏幽州刺史毌丘俭开战。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **姜维还屯涪县。** 姜维率偏军由汉中返屯涪县。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **孙和立为太子，孙霸封鲁王。** 赤乌五年正月立孙和为太子，八月封孙霸为鲁王，两宫并立。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **吴遣聂友、陆凯进兵珠崖、儋耳。** 七月吴命聂友和陆凯领三万人攻珠崖、儋耳。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **东平灵王薨，茂称嗌痛。** 正始三年，东平灵王薨，茂称嗌痛，不肯发哀，居处出入自若。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **满宠去世。** 满宠于本年去世。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **还朝，因至汉中。** 延熙五年还朝，因至汉中，见大司马蒋琬，宣传诏旨，加拜镇南大将军。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **姚伷去世。** 姚伷于本年去世。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **拜太子太傅，领中书如故。** 赤乌五年，拜太子太傅，领中书如故。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **征柤中，魏将蒲忠、胡质各将数千人。** 赤乌五年，征柤中，魏将蒲忠、胡质各将数千人，忠要遮险隘。 [[15]](#sg-note-15)

<a id="sy-event-16"></a>

16. **钟离牧任太子辅义都尉。** 钟离牧从郎中补任太子辅义都尉。原传随后载其迁南海太守。 [[16]](#sy-note-16)

<a id="sgz-event-17"></a>

17. **曹髦出生。** 曹髦自述生于正始三年九月乙未，并称当时天晴、室中有黄气，解释为魏尚土德的祥兆。 [[17]](#sgz-note-17)

### 8. 孙和立为太子，孙霸封鲁王

[返回正文第8条](#sg-event-8)

<a id="sg047-l2321-e8"></a>

**[《三国志·吴主传》](../../sources/摘录/三国志-卷047-吴主传.md#p009)** · [仓内TXT L2321](../../sources/本地分卷/三国志/三国志-卷047.md#L2321)

<a id="sg059-l2825-e8"></a>

**[《三国志·吴主五子传》](../../sources/摘录/三国志-卷059-吴主五子传.md#p003)** · [仓内TXT L2825](../../sources/本地分卷/三国志/三国志-卷059.md#l2825)

> 赤烏五年，立爲太子，時年十九。闞澤爲太傅，薛綜爲少傅

<a id="sgz062-b-2943-7"></a>

**[《三国志·是仪胡综传》仓内原文 L2943](../../sources/本地分卷/三国志/三国志-卷062.md#l2943)**

> 南、魯二宮初立，儀以本職領魯王傅。儀嫌二宮相近切，乃上疏曰："臣竊以魯王天挺懿德，兼資文武，當今之宜，宜鎮四方，為國藩輔。宣揚德美，廣耀威靈，乃國家之良規，海內所瞻望。但臣言辭鄙野，不能究盡其意。愚以二宮宜有降殺，正上下之序，明教化之本。"書三四上。

**释读** 孙和、孙霸名位方立，是仪领孙霸傅，数次请求孙霸出镇并区别嫡庶。

**归年** 《通鉴》卷074系赤乌五年八月封孙霸时，疏文指此政局。

<a id="sgz059-b-2825-2"></a>

**[《三国志·吴主五子传》仓内原文 L2825](../../sources/本地分卷/三国志/三国志-卷059.md#l2825)**

> 赤烏五年，立爲太子，時年十九。闞澤爲太傅，薛綜爲少傅，而蔡穎、張純、封俌、嚴維等皆從容侍從。

**释读** 孙和十九岁立储，阚泽、薛综为傅；蔡颖、张纯、封俌、严维侍从。

**归年** 本传赤乌五年，《吴主传》正月立太子。

<a id="sgz059-b-2831-2"></a>

**[《三国志·吴主五子传》仓内原文 L2831](../../sources/本地分卷/三国志/三国志-卷059.md#l2831)**

> 和爲太子。霸爲魯王，寵愛崇特，與和無殊。

**释读** 孙霸的宠遇与太子相当。

**归年** 《吴主传》赤乌五年正月立和、八月封霸。

<a id="sgz059-p-008-1"></a>

**[《三国志·吴主五子传》裴注 008·1](../../sources/摘录/三国志-卷059-吴主五子传裴注.md#pei-008-1)**

> 殷基通語曰初權既立和為太子而封霸為魯王初拜猶同宫室禮秩未分羣公之議以為太子國王上下有序禮秩宜異於是分宫别僚而隙端開矣

**释读** 孙和与孙霸起初同住，礼数未分；大臣主张分服制、僚属，以区别太子与藩王。

**归年** 《吴主传》赤乌五年一立一封；分宫具体月日无载。

### 15. 征柤中，魏将蒲忠、胡质各将数千人

[返回正文第15条](#sg-event-15)

<a id="sg056-l2688-e15"></a>

**[《三国志·朱治朱然吕范朱桓传》](../../sources/摘录/三国志-卷056-朱治朱然吕范朱桓传.md#p002)** · [仓内TXT L2688](../../sources/本地分卷/三国志/三国志-卷056.md#l2688)

> 赤烏五年，征柤中，魏將蒲忠、胡質各將數千人，忠要遮險隘。

**归年与互校** 原传明记年号和年次；后续回叙见本卷。

<a id="sgz056-b-2688-1"></a>

**[《三国志·朱治朱然吕范朱桓传》仓内原文 L2688](../../sources/本地分卷/三国志/三国志-卷056.md#l2688)**

> 赤烏五年，征柤中，魏將蒲忠、胡質各將數千人，忠要遮險隘。圖斷然後，質為忠繼援。時然所督兵將先四出，聞問不暇收合，便將帳下見兵八百人逆掩。忠戰不利，質等皆退。

**释读** 朱然深入，蒲忠和胡质拟封隘断后；朱然未及收拢分出的部队，率手边八百人迎击，蒲忠战不利，魏将撤退。

**归年** 本传作赤乌五年242；裴注《孙氏异同评》疑实为237。同见237和241不同北进记录，采取主文保留异说。

<a id="sgz056-p-005-4"></a>

**[《三国志·朱治朱然吕范朱桓传》裴注 005·4](../../sources/摘录/三国志-卷056-朱治朱然吕范朱桓传裴注.md#pei-005-4)**

> 吳志說赤烏五年於魏為正始三年魏將蒲忠與朱然戰忠不利質等皆退按魏少帝紀及孫權傳是嵗竝無事當是陳夀誤以吳嘉禾六年為赤烏五年耳

**释读** 吴传明记赤乌五年战蒲忠、胡质，孙氏指出当年魏少帝纪和吴主纪无此战，疑陈寿误把嘉禾六年写为赤乌五年。

**归年** 赤乌五年为242，嘉禾六年为237。系在既有242本传条，并明与237之记为同役一说、避免重复判定。

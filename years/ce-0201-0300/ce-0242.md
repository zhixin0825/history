## 本年概述

吳立孫和為太子、封孫霸為魯王，派兵前往珠崖、儋耳。魏太尉滿寵去世，由蔣濟繼任，東北則有高句麗攻西安平。吳發生疫病，孫權命宮中減省用度。

## 吳立太子與軍政

<a id="sg-event-14"></a>

<a id="sy-event-16"></a>

6. **孙和立为太子，孙霸封鲁王，钟离牧入东宫。** 正月，孙权立十九岁的孙和为太子，其母王夫人地位随之上升。阚泽任太子太傅，仍领中书，薛综任太子少傅，仍主管选官，蔡颖、张纯、封俌、严维等侍从东宫。八月，孙权封孙霸为鲁王，对他的宠遇与太子相当。孙和、孙霸最初仍住在同一宫室，礼秩未分。是仪兼任鲁王傅，屡次上疏建议让孙霸出镇一方，明确太子与诸侯王的礼秩差别。[两宫后来分居，各置僚属，争储日益激烈](ce-0245.md#sg-note-12)。孙权还曾赐薛综紫绶囊，要他以文章与礼教辅导太子。钟离牧从郎中补任太子辅义都尉。 [[6]](#sg-note-8)

<a id="sg-event-9"></a>

7. **吴遣聂友、陆凯进兵珠崖、儋耳。** 七月，孙权命聂友、陆凯率三万人渡海攻珠崖、儋耳。陆凯出讨朱崖有斩获，这一时期曾任儋耳太守、建武校尉。 [[7]](#sg-note-9)

<a id="sg-event-15"></a>

8. **朱然与蒲忠、胡质交战的纪年异说。** 朱然与蒲忠、胡质交兵，有242年攻柤中和[237年围江夏](ce-0237.md#sg-note-17)两种系年。蒲忠试图截断吴军归路，朱然率帐下八百人反击。[241年朱然围樊、诸葛瑾取柤中](ce-0241.md#sg-note-2)及[246年朱然再出柤中](ce-0246.md#sg-note-10)另见各年。 [[8]](#sg-note-15)

<a id="sgz-event-18"></a>

9. **吴改禾兴为嘉兴。** 吴改禾兴县为嘉兴县。 [[9]](#sgz-note-18)

<a id="sgz-event-19"></a>

10. **海盐报黄龙。** 海盐县三月报告黄龙。 [[10]](#sgz-note-19)

<a id="sgz-event-20"></a>

<a id="sgz-event-21"></a>

11. **吴大疫，减御膳并禁进献。** 孙权禁止向宫中进献，削减太官膳食。 同年吴大疫。 [[11]](#sgz-note-20)

<a id="sgz-event-22"></a>

12. **孙皓约于本年出生。** 孙和的姬妾何氏生子，孙权为他取名彭祖，即后来的孙皓。 [[12]](#sgz-note-22)

<a id="wu053-l79-1"></a>

**[《三國志·張嚴程闞薛傳》裴注 021](../../拆分史书/三国志/卷053.md#edition-wu053-l79-1)** · [TXT L79](../../拆分史书/三国志/卷053.txt#L79)

> 吳書曰：後權賜綜紫綬囊，綜陳讓紫色非所宜服，權曰：「太子年少，涉道日淺，君當博之以文，約之以禮，茅土之封，非君而誰？」是時綜以名儒居師傅之位，仍兼選舉，甚爲優重。

**釋讀** 孫權賜薛綜紫色綬囊。薛綜自謙不宜受紫，孫權請他以文章、禮制教導太子，嘉許其身兼師傅及選官之任。

**歸年** 「後」承任太子少傅。賜囊與辭讓日期未載，作任內後續隨立儲及任官同讀。

**[《三國志·吳主五子傳》裴注 008](../../拆分史书/三国志/卷059.md#edition-wu059-l37-1)** · [TXT L37](../../拆分史书/三国志/卷059.txt#L37)

> 殷基通語曰：初權旣立和爲太子，而封霸爲魯王，初拜猶同宮室，禮秩未分。羣公之議，以爲太子、國王上下有序，禮秩宜異，於是分宮別僚，而隙端開矣。

**釋讀** 《殷基通语》记孙权立孙和为太子、封孙霸为鲁王之后，两人最初同宫，礼秩未分。群臣以为储君和诸侯王应有上下区别，于是分宫另设僚属，从此发生嫌隙。

**歸年** [《吴主传》](../../拆分史书/三国志/卷047.txt#L164)赤乌五年正月立储、八月封孙霸。分宫、设僚由封册而起，确日未载。同宫指孙霸受封后初期。

<a id="wu059-l54-1"></a>

**[《三國志·吳主五子傳》正文](../../拆分史书/三国志/卷059.md#edition-wu059-l54-1)** · [TXT L54](../../拆分史书/三国志/卷059.txt#L54)

> 孫霸字子威，和弟也。和爲太子。霸爲魯王，寵愛崇特，與和無殊。

**釋讀** 孫霸字子威，是孫和的弟弟。孫和為太子、孫霸封魯王，孫權厚愛孫霸，待遇與太子相當。

**歸年** 卷047〈吳主傳〉赤烏五年正月立孫和、秋八月封孫霸。字、兄弟關係與受寵是立封前後概敘，本句未說孫霸生母。

> 赤烏五年，從郎中補太子輔義都尉，

**釋讀** 赤烏五年，鍾離牧從郎中補任太子輔義都尉。

**歸年** 本傳明記赤烏五年，卷059《孫和傳》同年載孫和立為太子。



<a id="sgz062-b-2943-7"></a>

<a id="wu062-l20-1"></a>

**[《三國志·是儀胡綜傳》正文](../../拆分史书/三国志/卷062.md#edition-wu062-l20-1)** · [TXT L20](../../拆分史书/三国志/卷062.txt#L20)

> 南、魯二宮初立，儀以本職領魯王傅。儀嫌二宮相近切，乃上疏曰：「臣竊以魯王天挺懿德，兼資文武，當今之宜，宜鎮四方，爲國藩輔。宣揚德美，廣耀威靈，乃國家之良規，海內所瞻望，。但臣言辭鄙野，不能究盡其意。愚以二宮宜有降殺，正上下之序，明教化之本。」書三四上。爲傅盡忠，動輒規諫；事上勤，與人恭。

**釋讀** 南宮太子孫和與魯王孫霸初立，是儀以原官兼任魯王傅。見兩宮親近而禮秩過於相等，他上疏稱孫霸德行出眾、兼備文武，宜出鎮一方，藩輔國家，宣揚德威。又自謙不能盡陳，主張區分兩宮禮秩，確立上下與教化。他屢次上書，任傅時盡忠勤諫，侍奉君上勤勉，待人恭謹。

**歸年** 孫和242年正月立為太子，孫霸於同年八月封魯王。《通鑑》卷074同年載是儀兼傅及進諫。反覆上書、任傅勤勉隨此事敘，未載各次年月；兩宮後來分置僚屬，宜另看245年前後的爭議。

### 8. 朱然与蒲忠、胡质交战的纪年异说

[返回正文第8条](#sg-event-15)

<a id="sg056-l2688-e15"></a>

<a id="sgz056-b-2688-1"></a>

<a id="wu056-l40-1"></a>

**[《三國志·朱治朱然呂範朱桓傳》正文](../../拆分史书/三国志/卷056.md#edition-wu056-l40-1)** · [TXT L40](../../拆分史书/三国志/卷056.txt#L40)

> 赤烏五年，征柤中，

**釋讀** 本传说朱然赤乌五年攻柤中。

**歸年** 裴注《孙氏异同评》疑“赤烏五年”误记[237年江夏出兵](ce-0237.md#sg-note-17)，现条专列异说，不从此单立确年战役。

<a id="wu056-l41-1"></a>

**[《三國志·朱治朱然呂範朱桓傳》裴注 005](../../拆分史书/三国志/卷056.md#edition-wu056-l41-1)** · [TXT L41](../../拆分史书/三国志/卷056.txt#L41)

> 襄陽記曰：柤音如租稅之租。柤中在上黃界，去襄陽一百五十里。魏時夷王梅敷兄弟三人，部曲萬餘家屯此，分布在中廬宜城西山鄢、沔二谷中，土地平敞，宜桑麻，有水陸良田，沔南之膏腴沃壤，謂之柤中。

**釋讀** 《襄阳记》说“柤”音同“租”。柤中在上黄界内，距襄阳一百五十里。魏时梅敷兄弟三人有部曲万余家屯聚其地，分在中庐、宜城西山鄢沔两谷。当地平旷宜桑麻，水陆皆有良田，为沔南沃壤。

**歸年** 地理与聚居情况是柤中事项背景，未以赤乌五年定梅敷入屯之年。

<a id="wu056-l42-1"></a>

**[《三國志·朱治朱然呂範朱桓傳》正文](../../拆分史书/三国志/卷056.md#edition-wu056-l42-1)** · [TXT L42](../../拆分史书/三国志/卷056.txt#L42)

> 魏將蒲忠、胡質各將數千人，忠要遮險隘，圖斷然後，質爲忠繼援。時然所督兵將先四出，聞問不暇收合，便將帳下見兵八百人逆掩。忠戰不利，質等皆退。

**釋讀** 蒲忠、胡质各率魏兵数千。蒲忠据险欲断朱然后路，胡质接应。朱然部队已分出，来不及召回，便用帐下八百现兵迎击。蒲忠战失利，胡质等撤退。

**歸年** 承本传赤乌五年，地名及战果有别于《明帝纪》所写237年围江夏退兵，段后即载孙盛的同役异年异说。

<a id="sgz056-p-005-4"></a>

<a id="wu056-l43-4"></a>

**[《三國志·朱治朱然呂範朱桓傳》裴注 006](../../拆分史书/三国志/卷056.md#edition-wu056-l43-4)** · [TXT L43](../../拆分史书/三国志/卷056.txt#L43)

> 吳志說赤烏五年，於魏爲正始三年，魏將蒲忠與朱然戰，忠不利，質等皆退。按魏少帝紀及孫權傳，是歲並無事，當是陳壽誤以吳嘉禾六年爲赤烏五年耳。

**釋讀** 孙盛列举吴志把蒲忠失利、胡质等退载于赤乌五年，即魏正始三年。《魏少帝纪》和《孙权传》该年均无此役，因而怀疑陈寿误写了嘉禾六年。

**歸年** 嘉禾六年237，正始二年241，赤乌五年242。孙盛把蒲忠、胡质之战归于237，并以241朱然另外出兵为对读。

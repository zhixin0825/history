# 公元243年｜魏正始四年／蜀延熙六年／吴赤乌六年

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **帝加元服，赐群臣各有差。** 四年春正月，帝加元服，赐群臣各有差。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **立皇后甄氏，大赦。** 夏四月乙卯，立皇后甄氏，大赦。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **日有蚀之，旣。** 五月朔，发生日食，旣。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **诏祀故大司马曹真、曹休、征南大将军夏侯尚、太常桓阶、司空陈群、太傅锺…。** 秋七月，诏祀故大司马曹真、曹休、征南大将军夏侯尚、太常桓阶、司空陈群、太傅锺繇、车骑将军张合、左将军徐晃、前将军张辽、右将军乐进、太尉华歆、司徒王朗、骠骑将军曹洪、征西将军夏侯渊、后将军朱灵、文聘、执金吾臧霸、破虏将军李典、立义将军庞德、武猛校尉典韦于太祖庙庭。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **倭国女王俾弥呼遣使奉献。** 冬十二月，倭国女王俾弥呼派使奉献。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **蒋琬住涪，费祎任大将军。** 蒋琬改住涪，十一月费祎任大将军。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **王平统汉中。** 蒋琬从汉中还驻涪县，王平任前监军、镇北大将军，统领汉中。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **邓芝升车骑将军。** 延熙六年，邓芝升车骑将军。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **吴丞相顾雍去世。** 赤乌六年十一月，顾雍去世。[次年正月陆逊继任](ce-0244.md#sg047-l2323-e13)。 [[9]](#sg-note-9)

<a id="sgz-event-25"></a>

25. **扶南王范旃遣使献乐人及方物。** 赤乌六年十二月，扶南王范旃遣使献乐人及方物。 [[25]](#sgz-note-25)

<a id="sg-event-10"></a>

10. **吴胡综去世。** 典掌文书及军政的胡综在此年去世，子胡冲继嗣。 [[10]](#sg-note-10)

<a id="sgz-event-24"></a>

<a id="sg-event-11"></a>

11. **赵俨因病回朝，拜骠骑将军。** 正始四年，赵俨因年老多病请求还朝，被召为骠骑将军。其后于245年拜司空，见该年本纪。 [[11]](#sg-note-11)

<a id="sgz-event-14"></a>

<a id="sg-event-12"></a>

12. **加辅国将军。** 延熙六年，加辅国将军。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **孙承去世，孙壹承继孙奂一支。** 孙承去世，无子。其庶弟孙壹受封，承继父亲孙奂一支的祭祀和军职。 [[13]](#sg-note-13)

<a id="sgz-event-15"></a>

15. **曹冏上书论魏宗室与封建。** 曹冏以经籍为证，论宗族与贤者皆须任用，并质疑魏朝对诸王有封而无权，难以同担患难。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **诸葛恪在庐江方向出兵取民。** 本传说诸葛恪轻兵袭舒，掩得人口而返。 [[16]](#sgz-note-16)

<a id="sgz-event-23"></a>

<a id="sgz-event-17"></a>

17. **司马懿入舒与诸葛恪转屯柴桑。** 诸葛恪拟侦探通往寿春的要路，孙权不允攻寿春。 [[17]](#sgz-note-17)

<a id="sgz-event-18"></a>

18. **王昶表请移新野、练水军广耕。** 认为宛距襄阳远，诸军分散、船在宣池，遇急来不及接应，奏徙治新野，并令荆、豫二州训练舟师和屯田。 [[18]](#sgz-note-18)

<a id="sgz-event-19"></a>

19. **阚泽去世，孙权哀悼。** 阚泽冬天死，孙权伤悼数日吃不下饭。 [[19]](#sgz-note-19)

<a id="sgz-event-20"></a>

20. **薛综春卒。** 薛综于赤乌六年春去世。 [[20]](#sgz-note-20)

<a id="sgz-event-21"></a>

21. **新都报白虎。** 新都正月报告见白虎。 [[21]](#sgz-note-21)

<a id="sgz-event-22"></a>

22. **诸葛恪击破六安谢顺营。** 诸葛恪攻六安，破魏将谢顺营，收其民人。 [[22]](#sgz-note-22)

### 6. 蒋琬住涪，费祎任大将军

[返回正文第6条](#sg-event-6)

<a id="sg033-l1703-e6"></a>

**[《三国志·后主传》](../../sources/本地分卷/三国志/三国志-卷033.md#p004)** · [仓内TXT L1703](../../sources/本地分卷/三国志/三国志-卷033.md#l1703)

> 六年冬十月，大司馬蔣琬自還漢中，住涪。十一月，大赦。以尚書令費禕為大將軍。

<a id="sgz033-b-1703-1"></a>

**[《三国志·后主传》仓内原文 L1703](../../sources/本地分卷/三国志/三国志-卷033.md#l1703)**

> 六年冬十月，大司馬蔣琬自還漢中，住涪。

**释读** 蒋琬十月从汉中返回、驻涪。

**归年** 延熙六年，《蒋琬传》补述其病与回涪便应东北、西北理由。

<a id="sgz033-b-1703-2"></a>

**[《三国志·后主传》仓内原文 L1703](../../sources/本地分卷/三国志/三国志-卷033.md#l1703)**

> 十一月，大赦。以尚書令費禕為大將軍。

**释读** 蜀在十一月大赦，尚书令费祎继任大将军。

**归年** 本传承延熙六年，《费祎传》称代蒋琬为大将军。

<a id="sgz044-b-2062-1"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2062](../../sources/本地分卷/三国志/三国志-卷044.md#l2062)**

> 芟穢弭難，臣職是掌。自臣奉辭漢中，已經六年，臣既闇弱，加嬰疾疢，規方無成，夙夜憂慘。今魏跨帶九州，根蒂滋蔓，平除未易。若東西並力，首尾掎角。雖未能速得如志，且當分裂蠶食，先摧其支黨。然吳期二三，連不克果，俯仰惟艱，實忘寢食。

**释读** 蒋琬自称在汉中六年而抱病未成，魏跨九州，拟与吴进退成角，先摧魏支党，但吴国屡未能依期行动。

**归年** 《通鉴》卷074即引于241使费祎后；本传自称自驻汉中已经六年，238起按首尾计应为243，且紧接实际当年还涪，故243主条保留241异。

<a id="sgz044-b-2062-2"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2062](../../sources/本地分卷/三国志/三国志-卷044.md#l2062)**

> 輒與費禕等議，以涼州胡塞之要，進退有資，賊之所惜；且羌、胡乃心思漢如渴。又昔偏軍人羌，郭淮破走，算其長短，以為事首，宜以姜維為涼州刺史。若維征行，銜持河右，臣當帥軍為維鎮繼。今涪水陸四通，惟急是應。若東北有虞，赴之不難。

**释读** 蒋琬与费祎议凉州险要、当地羌胡向汉，建议姜维出守凉州，以己殿军。涪水陆道会，利于策应，故请驻涪。

**归年** 同一上疏，241《通鉴》预叙和文本驻汉中六年推243异；姜维领凉州刺史由本传延熙六年落实。

<a id="sgz044-b-2063-1"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2063](../../sources/本地分卷/三国志/三国志-卷044.md#l2063)**

> 由是琬遂還住涪。

**释读** 因上疏，蒋琬改驻涪。

**归年** 《后主传》《通鉴》卷074延熙六年冬十月。

<a id="sgz044-b-2069-5"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2069](../../sources/本地分卷/三国志/三国志-卷044.md#l2069)**

> 琬自漢中還涪，禕遷大將軍，錄尚書事。

**释读** 蒋琬从汉中还涪，费祎升大将军、录尚书事。

**归年** 《通鉴》卷074延熙六年，十月还涪、十一月费祎任大将军。

<a id="sgz044-b-2074-4"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2074](../../sources/本地分卷/三国志/三国志-卷044.md#l2074)**

> 六年，遷鎮西大將軍，領涼州刺史。

**释读** 延熙六年，姜维迁镇西大将军，领凉州刺史。

**归年** 本传明纪，与蒋琬还涪所议部署相合。

### 15. 曹冏上书论魏宗室与封建

[返回正文第15条](#sgz-event-15)

<a id="sgz020-p-011-2"></a>

**[《三国志·武文世王公传》裴注 011·2](../../sources/本地分卷/三国志/三国志-卷020.md#pei-011-2)**

> 魏氏春秋載宗室曹冏上書曰臣聞古之王者必建同姓以明親親必樹異姓以明賢賢故傳曰庸勲親親昵近尊賢書曰克明峻徳以親九族詩云懐德維寧宗子維城由是觀之非賢無與興功非親無與輔治夫親親之道專用則其漸也微弱賢賢之道偏任則其弊也刼奪先聖知其然也故博求親疎而並用之近則有宗盟藩衛之固逺則有仁賢輔弼之助盛則有與共其治衰則有與守其土安則有與享其福危則有與同其禍夫然故能有其國家保其社稷歴紀長久本支百世也今魏尊尊之法雖明親親之道未備詩不云乎鶺鴒在原兄弟急難以斯言之明凡弟相救於䘮亂之際同心於憂禍之間雖有䦧牆之忿不忘禦侮之事何則憂患同也今則不然或任而不重或釋而不任一旦疆場稱警闗門反拒股肱不扶胷心無衞臣竊惟此寝不安席思獻丹誠貢䇿朱闕

**归年** 《通鉴》卷七十四置正始四年，文称魏兴二十四年，取自220年首尾计。

<a id="sgz020-p-011-3"></a>

**[《三国志·武文世王公传》裴注 011·3](../../sources/本地分卷/三国志/三国志-卷020.md#pei-011-3)**

> 謹撰合所聞叙論成敗論曰昔夏殷周歴世數十而秦二世而亡何則三代之君與天下共其民故天下同其憂秦王獨制其民故傾危而莫救夫與民共其樂者人必憂其憂與民同其安者人必拯其危先王知獨治之不能久也故與人共治之知獨守之不能固也故與人共守之兼親疎而兩用參同異而並建

**释读** 比较夏商周多世与秦二世亡，认为君主需要与贤者、宗亲共治并彼此制衡。

**归年** 同一正始四年上书；古代史实是当时论据。

<a id="sgz020-p-011-4"></a>

**[《三国志·武文世王公传》裴注 011·4](../../sources/本地分卷/三国志/三国志-卷020.md#pei-011-4)**

> 是以輕重足以相鎮親疎足以相衞并兼路塞逆節不生及其衰也桓文帥禮苞茅不貢齊師伐楚宋不城周晉戮其宰王綱弛而復張諸侯慠而復肅二霸之後浸以陵遲呉楚慿江負固方城雖心希九鼎而畏迫宗姫姦情㪚于胷懐逆謀消於脣吻斯豈非信重親戚任用賢能枝葉碩茂本根頼之與自此之後轉相攻伐呉并於越晉分為三魯㓕於楚鄭兼於韓暨於戰國諸姫微矣惟燕衞獨存然皆弱小西廹彊秦南畏齊楚憂懼㓕亡匪遑相恤至於王赧降為庻人猶枝幹相持得居虚位海内無主四十餘年秦據勢勝之地騁譎詐之術征伐關東蠶食九國至於始皇乃定天位曠日若彼用力若此豈非深固根蒂不㧞之道乎易曰其亡其亡繫於苞桑周徳其可謂當之矣

**释读** 述春秋齐桓、晋文尊王，继及吴越兴亡、三家分晋和周室衰弱，认为根本固而周能久存。

**归年** 同一正始四年《六代论》，周末用秦统一相对照。

<a id="sgz020-p-011-5"></a>

**[《三国志·武文世王公传》裴注 011·5](../../sources/本地分卷/三国志/三国志-卷020.md#pei-011-5)**

> 秦觀周之弊以為小弱見奪於是廢五等之爵立郡縣之官弃禮樂之教任苛刻之政子弟無尺寸之封功臣無立錐之地内無宗子以自毗輔外無諸侯以為藩衞仁心不加於親戚恵澤不流於枝葉譬猶芟刈股肱獨任胷腹浮舟江海捐棄楫櫂觀者為之寒心而始皇晏然自以為闗中之固金城千里子孫帝王萬世之業也豈不悖哉是時淳于越諫曰臣聞殷周之王封子弟功臣千有餘城今陛下君有海内而子弟為匹夫卒有田常六卿之臣而無輔弼何以相救事不師古而能長久者非所聞也始皇聼李斯偏説而絀其議至於身死之日無所寄付委天下之重於凡夫之手託廢立之命於奸臣之口至令趙髙之徒誅鉏宗室胡亥少習刻薄之教長遵凶父之業不能改制易法寵任兄弟而乃師譚申商諮謀趙髙自幽深宮委政讒賊身殘望夷求為黔首豈可得哉遂乃郡國離心衆庻漬叛勝廣倡之於前劉項弊之於後向使始皇納淳于之䇿抑李斯之論割裂州國分王子弟封三代之後報功臣之勞士有常君民有定主枝葉相扶首尾為用雖使子孫有失道之行時人無湯武之賢奸謀未發而身已屠戮何區區之陳項而復得指其手足哉

**释读** 批评秦废封建、孤立宗室，以淳于越力谏与李斯反对相对，继述二世不能抑赵高、秦帝业迅速败亡。

**归年** 同一上书，先秦至秦末是回顾。所涉具年史事各见相应年页。

<a id="sgz020-p-011-6"></a>

**[《三国志·武文世王公传》裴注 011·6](../../sources/本地分卷/三国志/三国志-卷020.md#pei-011-6)**

> 故漢祖奮三尺之劍驅烏集之衆五年之中遂成帝業自開闢以來其興立功勲未有若漢祖之易也夫伐深根者難為功摧枯朽者易為力理勢然也漢監秦之失封殖子弟及諸呂擅權圖危劉氏而天下所以不傾動百姓所以不易心者徒以諸侯彊大盤石膠固東牟朱虚受命于内齊代呉楚作衞于外故也向使髙祖踵亡秦之法忽先王之制則天下已傳非劉氏有也然髙祖封建地過古制大者跨州兼郡小者連城數十上下無别權侔京室故有呉楚七國之患賈誼曰諸侯彊盛長亂起奸夫欲天下之治安莫若衆建諸侯而少箕力令海内之勢若身之使臂臂之使指則下無背叛之心上無誅伐之事文帝不從至於孝景猥用晁錯之計削黜諸侯親者怨恨疎者震恐呉楚倡謀五國從風兆發髙帝釁鍾文景由寛之過制急之不漸故也所謂末大必折尾大難掉尾同於體猶或不從況乎非體之尾其可掉哉

**释读** 称刘邦由布衣建帝业，汉初藩王有助平诸吕；也指出封国过大造成七国之乱，贾谊先有削强之议。

**归年** 同一上书，汉初史事实例；七国之乱见前154年。

**[《三国志·武文世王公传》裴注 011·7](../../sources/本地分卷/三国志/三国志-卷020.md#pei-011-7)**

> 武帝從主父之䇿下推恩之令自是之後齊分為七趙分為六淮南三割梁代五分遂以陵遲子孫微弱衣食租税不預政事或以酎金免削或以無後國除至於成帝王氏擅朝劉向諫曰臣聞公族者國之枝葉枝葉落則本根無所庇䕃方今同姓疏逺母黨專政排擯宗室孤弱公族非所以保守社稷安固國嗣也其言深切多所稱引成帝雖悲傷歎息而不能用至於哀平異姓秉權假周公之事而為田常之亂髙拱而竊天位一朝而臣四海漢宗室王侯解印釋紱貢奉社稷猶懼不得為臣妾或乃為之符命頌莽恩徳豈不哀哉由斯言之非宗子獨忠孝於恵文之間而叛逆於哀平之際也徒權輕勢弱不能有定耳

**释读** 叙汉武帝推恩削弱诸侯，后朝王氏专权，刘向以宗室为国之枝叶劝谏而未起作用。

**归年** 同一正始四年上书；西汉后期属取证旧事。

> 頼光武皇帝挺不世之姿禽王莽於已成紹漢嗣於既絶斯豈非宗子之力也而曾不監秦之失策襲周之舊制踵亡國之法而徼倖無疆之期至於桓靈閹監執衡朝無死難之臣外無同憂之國君孤立於上臣弄權於下本末不能相御身首不能相使由是天下鼎沸姧凶並爭宗廟焚為灰燼宮室變為榛藪居九州之地而身無所安處悲夫

**释读** 赞光武恢复汉业，批评东汉继续防抑宗族，桓灵时宦官控制朝堂，天下纷乱。

**释读** 称曹操平乱定都、汉禅魏，感叹魏兴二十四年却未取前代教训，宗室不能参与政务。

**释读** 指出州牧郡守权广大而宗室无人配合，宗室文才仅能居小县、武才仅率少众，无法激励有能力者。

**归年** 同一裴注所引曹冏正始四年奏议。

<a id="sgz020-p-011-11"></a>

**[《三国志·武文世王公传》裴注 011·11](../../sources/本地分卷/三国志/三国志-卷020.md#pei-011-11)**

> 夫泉竭則流涸根朽則葉枯枝繁者䕃根條落者本孤故語曰百足之蟲至死不僵以扶之者衆也此言雖小可以譬大且墉基不可倉卒而成威名不可一朝而立皆為之有漸建之有素譬之種樹久則深固其本根茂盛其枝葉若造次徙於山林之中植於宮闕之下雖壅之以黑墳煖之以春日猶不救於枯槁而何暇繁育哉夫樹猶親戚土猶士民建置不久則輕下慢上平居猶懼其離叛危急将若之何是以聖王安而不逸以慮危也存而設備以懼亡也故疾風卒至而無摧拔之憂天下有變而無傾危之患矣

**释读** 以泉源与树根比国之根基，主张用长期经营保持稳固，如同树要早种，不能临危才移。

**归年** 正始四年奏议收尾，比喻不另系年。

**[《三国志·诸葛滕二孙濮阳传》仓内原文 L2988](../../sources/本地分卷/三国志/三国志-卷064.md#l2988)**

> 赤烏中，魏司馬宣王謀欲攻恪。權方發兵應之，望氣者以為不利，於是徒恪屯於柴桑。

**释读** 司马懿谋攻诸葛恪，孙权拟发援军，望气者说不利，孙权让诸葛恪改屯柴桑。

**归年** 《吴主传》赤乌六年及《通鉴》卷七十四记司马懿入舒而恪改屯。

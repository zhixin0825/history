# 公元243年｜魏正始四年／蜀延熙六年／吴赤乌六年

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **帝加元服，赐群臣各有差。** 四年春正月，帝加元服，赐群臣各有差。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **立皇后甄氏，大赦。** 夏四月乙卯，立皇后甄氏，大赦。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **日有蚀之，旣。** 五月朔，发生日食，旣。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **诏祀故大司马曹真、曹休、征南大将军夏侯尚、太常桓阶、司空陈群、太傅锺…。** 秋七月，诏祀故大司马曹真、曹休、征南大将军夏侯尚、太常桓阶、司空陈群、太傅锺繇、车骑将军张合、左将军徐晃、前将军张辽、右将军乐进、太尉华歆、司徒王朗、骠骑将军曹洪、征西将军夏侯渊、后将军朱灵、文聘、执金吾臧霸、破虏将军李典、立义将军庞德、武猛校尉典韦于太祖庙庭。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **倭国女王俾弥呼遣使奉献。** 冬十二月，倭国女王俾弥呼派使奉献。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **蒋琬住涪，费祎任大将军。** 蒋琬改住涪，十一月费祎任大将军。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **王平统汉中。** 蒋琬从汉中还驻涪县，王平任前监军、镇北大将军，统领汉中。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **邓芝升车骑将军。** 延熙六年，邓芝升车骑将军。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **顾雍去世，扶南遣使献方物。** 顾雍十一月去世，十二月扶南王范旃派使者献乐人及当地物产。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **吴胡综去世。** 典掌文书及军政的胡综在此年去世，子胡冲继嗣。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **老疾求还，徵为骠骑将军。** 正始四年，老疾求还，徵为骠骑将军，迁司空。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **加辅国将军。** 延熙六年，加辅国将军。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **孙承去世。** 孙承于本年去世。 [[13]](#sg-note-13)

<a id="sgz-event-14"></a>

14. **董允加辅国将军。** 董允在延熙六年加辅国将军。 [[14]](#sgz-note-14)

### 6. 蒋琬住涪，费祎任大将军

[返回正文第6条](#sg-event-6)

<a id="sg033-l1703-e6"></a>

**[《三国志·后主传》](../../sources/摘录/三国志-卷033-后主传.md#p004)** · [仓内TXT L1703](../../sources/本地分卷/三国志/三国志-卷033.md#l1703)

> 六年冬十月，大司馬蔣琬自還漢中，住涪。十一月，大赦。以尚書令費禕為大將軍。

<a id="sgz033-b-1703-1"></a>

**[《三国志·后主传》仓内原文 L1703](../../sources/本地分卷/三国志/三国志-卷033.md#l1703)**

> 六年冬十月，大司馬蔣琬自還漢中，住涪。

**释读** 蒋琬十月从汉中返回、驻涪。

**归年** 延熙六年，《蒋琬传》补述其病与回涪便应东北、西北理由。

<a id="sgz033-b-1703-2"></a>

**[《三国志·后主传》仓内原文 L1703](../../sources/本地分卷/三国志/三国志-卷033.md#l1703)**

> 十一月，大赦。以尚書令費禕為大將軍。

**释读** 蜀在十一月大赦，尚书令费祎继任大将军。

**归年** 本传承延熙六年，《费祎传》称代蒋琬为大将军。

<a id="sgz044-b-2062-1"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2062](../../sources/本地分卷/三国志/三国志-卷044.md#l2062)**

> 芟穢弭難，臣職是掌。自臣奉辭漢中，已經六年，臣既闇弱，加嬰疾疢，規方無成，夙夜憂慘。今魏跨帶九州，根蒂滋蔓，平除未易。若東西並力，首尾掎角。雖未能速得如志，且當分裂蠶食，先摧其支黨。然吳期二三，連不克果，俯仰惟艱，實忘寢食。

**释读** 蒋琬自称在汉中六年而抱病未成，魏跨九州，拟与吴进退成角，先摧魏支党，但吴国屡未能依期行动。

**归年** 《通鉴》卷074即引于241使费祎后；本传自称自驻汉中已经六年，238起按首尾计应为243，且紧接实际当年还涪，故243主条保留241异。

<a id="sgz044-b-2062-2"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2062](../../sources/本地分卷/三国志/三国志-卷044.md#l2062)**

> 輒與費禕等議，以涼州胡塞之要，進退有資，賊之所惜；且羌、胡乃心思漢如渴。又昔偏軍人羌，郭淮破走，算其長短，以為事首，宜以姜維為涼州刺史。若維征行，銜持河右，臣當帥軍為維鎮繼。今涪水陸四通，惟急是應。若東北有虞，赴之不難。

**释读** 蒋琬与费祎议凉州险要、当地羌胡向汉，建议姜维出守凉州，以己殿军。涪水陆道会，利于策应，故请驻涪。

**归年** 同一上疏，241《通鉴》预叙和文本驻汉中六年推243异；姜维领凉州刺史由本传延熙六年落实。

<a id="sgz044-b-2063-1"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2063](../../sources/本地分卷/三国志/三国志-卷044.md#l2063)**

> 由是琬遂還住涪。

**释读** 因上疏，蒋琬改驻涪。

**归年** 《后主传》《通鉴》卷074延熙六年冬十月。

<a id="sgz044-b-2069-5"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2069](../../sources/本地分卷/三国志/三国志-卷044.md#l2069)**

> 琬自漢中還涪，禕遷大將軍，錄尚書事。

**释读** 蒋琬从汉中还涪，费祎升大将军、录尚书事。

**归年** 《通鉴》卷074延熙六年，十月还涪、十一月费祎任大将军。

<a id="sgz044-b-2074-4"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2074](../../sources/本地分卷/三国志/三国志-卷044.md#l2074)**

> 六年，遷鎮西大將軍，領涼州刺史。

**释读** 延熙六年，姜维迁镇西大将军，领凉州刺史。

**归年** 本传明纪，与蒋琬还涪所议部署相合。

## 本年概述

曹爽率魏軍攻蜀，在興勢受阻後撤回。毌丘儉在東北攻高句麗。吳任陸遜為丞相，孫權就蜀吳盟約釋諸臣疑慮。

## 興勢交戰與蜀漢任官

<a id="sg-event-4"></a>

1. **曹爽进攻蜀汉，在兴势受阻后撤军。** 五年春二月，诏大将军曹爽率衆征蜀。 丙午，大将军曹爽引军还。 [[1]](#sg-note-1)

<a id="sg-event-12"></a>

2. **安平王刘理去世。** 四月刘理去世。 [[2]](#sg-note-12)

<a id="sgz-event-16"></a>

3. **费祎自汉中返回成都。** 费祎九月回到成都。 [[3]](#sgz-note-16)

## 魏東北邊事與朝廷紀事

<a id="sg-event-6"></a>

5. **鲜卑内附，置辽东属国。** 九月，鲜卑内附，置辽东属国，立昌黎县以居之。 [[5]](#sg-note-6)

<a id="sg-event-11"></a>

6. **毌丘俭初破高句丽。** 高句丽王宫此前发兵侵扰西安平。毌丘俭率魏军由玄菟分道出击，在沸流一带击败王宫，进攻丸都。 [[6]](#sg-note-11)

<a id="sg-event-2"></a>

7. **日有蚀之。** 夏四月朔，发生日食。 [[7]](#sg-note-2)

<a id="sg-event-3"></a>

<a id="sg-event-5"></a>

<a id="sg-event-8"></a>

9. **秦王曹询去世，封国改复京兆郡。** 秋八月，秦王询去世。 己酉，复秦国为京兆郡。 [[9]](#sg-note-5)

<a id="sg-event-7"></a>

10. **诏祀故尚书令荀攸于太祖庙庭。** 冬十一月癸卯，诏祀故尚书令荀攸于太祖庙庭。 [[10]](#sg-note-7)

<a id="sg-event-9"></a>

11. **司空崔林薨。** 十二月，司空崔林去世。 [[11]](#sg-note-9)

<a id="sg-event-10"></a>

12. **曹髦封高贵乡公。** 东海定王曹霖的儿子曹髦被封为高贵乡公。 [[12]](#sg-note-10)

<a id="sg-event-14"></a>

13. **裴潜去世。** 裴潜于本年去世。 [[13]](#sg-note-14)

<a id="sgz-event-19"></a>

<a id="sgz-event-20"></a>

14. **曹茂徙乐陵，恢复旧户并加邑。** 曹魏因其租奉少、子嗣多，赐还曾削诸户，并另加七百户。 [[14]](#sgz-note-20)

## 吳廷人事與外交

<a id="sg-event-13"></a>

15. **陆逊任吴丞相。** 正月，孙权任上大将军陆逊继顾雍为丞相，遣代理太常的傅常持节授印绶。陆逊原领的州牧、都护及武昌事务照旧。 [[15]](#sg-note-13)

<a id="sy-event-15"></a>

16. **张承去世。** 曾任濡须都督、奋威将军的张承去世，年六十七，谥定侯，儿子张震承袭。 [[16]](#sy-note-15)

<a id="sgz-event-17"></a>

17. **改葬孙登于蒋陵。** 孙登自[初葬句容](ce-0241.md#sg-note-10)三年后，改葬蒋陵。 [[17]](#sgz-note-17)

<a id="sgz-event-21"></a>

18. **宛陵报嘉禾。** 秋宛陵报告生嘉禾。 [[18]](#sgz-note-21)

<a id="sgz-event-22"></a>

19. **步骘、朱然疑蜀背盟，孙权释疑。** 步骘、朱然等闻蜀建船筑城，蒋琬从汉中还近成都，怀疑与魏交通。孙权认为司马懿停驻舒地仅十余日，蜀道远，来不及联动；修船筑城同于吴国整备，遂以全家担保蜀无异谋。陈寿接记蜀果无谋。 [[19]](#sgz-note-22)

<a id="sgz-event-23"></a>

20. **吴禁诛叛将妻儿。** 孙权诏说以妻子连坐逼人弃夫父，有伤教义，命此后将领出逃反叛不杀妻子。 [[20]](#sgz-note-23)

<a id="sgz-event-24"></a>

21. **顾谭任太常并平尚书事。** 祖父顾雍卒后数月，顾谭领太常、代管尚书事。 [[21]](#sgz-note-24)

<a id="sgz-event-25"></a>

22. **潘夫人生孙亮。** 孙权的潘夫人在宫中生下孙亮。 [[22]](#sgz-note-25)

**释读** 关中与氐、羌无力维持转运，牛马等多死，民夷道哭；蜀据险固守，魏军行数百里仍不得前进。

**释读** 曹爽袭蜀，有人议固城待魏自退。刘敏认为田野、百姓都将遭受损失，随王平据兴势并多张旗帜。

**释读** 魏大将军曹爽率十余万步骑出向汉川，前锋到骆谷，汉中守军不到三万，诸将惊慌。

**归年** 本传延熙七年春；《曹爽传》正始五年所发「六七萬人」是所征兵数，口径不同，保留本传军势记载。

> 或曰：「今力不足以拒敵，聽當固守漢、樂二城，遇賊令入，比爾間，涪軍足得救關。」平曰：「不然。漢中去涪垂千里。賊若得關，便為禍也。今宜先遣劉護軍、杜參軍據興勢，平為後拒。若賊分向黃金，平率千人下自臨之，比爾間，涪軍行至，此計之上也。」惟護軍劉敏與平意同，即便施行。

**释读** 诸将有人建议退守汉、乐二城待涪救兵；王平认为一失关隘为祸，应先据兴势，自己在后接应并准备救黄金，刘敏赞同并施行。

**归年** 延熙七年兴势之役。

<a id="sgz026-b-1403-1"></a>

**[《三国志·满田牵郭传》仓内原文 L1403](../../拆分史书/三国志/卷026.md#l1403)**

> 五年，夏侯玄伐蜀，淮督諸軍爲前鋒。淮度勢不利，輙拔軍出，故不大敗。還假淮節。

**释读** 郭淮率前锋，形势不利遂率部先退出，回魏后获假节。

**归年** 正始五年兴势之役，《齐王纪》《王平传》同，另有撤军同年条。

**归年** 《后主传》《王平传》延熙七年兴势之役，魏正始五年。

> 毓與書曰：「竊以爲廟勝之策，不臨矢石；王者之兵，有征無戰。誠以干戚可以服有苗，退舍足以納原寇，不必縱吳漢於江關，騁韓信於井陘也。見可而進，知難而退，蓋自古之政。惟公侯詳之！」

**释读** 钟毓写信说运筹未必亲冒矢石，用舜、晋文公不用战求成的旧例相劝，亦举吴汉、韩信之战非必效。

> 赤烏七年，代顧雍爲丞相，詔曰：「朕以不德，應期踐運，王塗未一，姦宄充路，夙夜戰懼，不惶鑒寐。惟君天資聦叡，明德顯融，統任上將，匡國弭難。夫有超世之功者，必應光大之寵；懷文武之才者，必荷社稷之重。昔伊尹隆湯，呂尚翼周，內外之任，君實兼之。今以君爲丞相，使使持節守太常傅常授印綬。君其茂昭明德，脩乃懿績，敬服王命，綏靖四方。於乎！總司三事，以訓羣寮，可不敬與，君其勗之！其州牧都護領武昌事如故。」

**釋讀** 赤烏七年陸遜繼顧雍為丞相。孫權詔稱天下未定、夙夜憂懼，陸遜身任上將而有安定國難之功，才兼文武，可以擔負社稷之重。

**歸年** 卷047〈吳主傳〉記赤烏七年春正月以上大將軍陸遜為丞相，與本傳年號相合。

**釋讀** 孫權用伊尹輔商湯、呂尚輔周為比，使守太常傅常持節授丞相印綬，命陸遜統領百官；州牧、都護兼掌武昌事都照舊。

**歸年** 同一任丞相之詔。伊尹、呂尚為用人典故，「守太常」為傅常職任。

### 19. 步骘、朱然疑蜀背盟，孙权释疑

[返回正文第19条](#sgz-event-22)

<a id="sgz047-b-2323-3"></a>

**[《三國志·吳主傳》](../../拆分史书/三国志/卷047.md#edition-sgz047-b-2323-3)** · [TXT L168](../../拆分史书/三国志/卷047.txt#L168)

> 是歲，步隲、朱然等各上疏云：「自蜀還者，咸言背盟與魏交通，多作舟舩，繕治城郭。又蔣琬守漢中，聞司馬懿南向，不出兵乘虛以掎角之，反委漢中，還近成都。事已彰灼，無所復疑，宜爲之備。」

**吴臣疑蜀背盟，孙权消解疑虑** 步骘、朱然等称听闻蜀修船城、蒋琬从汉中回近成都，怀疑与魏交通，请有备。

**归年依据** 本纪赤乌七年，所引司马懿入舒是243年。

<a id="sgz047-b-2323-4"></a>

<a id="sgz047-b-2323-5"></a>

<a id="full-sgz047-b-2323-4"></a>

**[《三國志·吳主傳》](../../拆分史书/三国志/卷047.md#full-sgz047-b-2323-4)** · [TXT L168](../../拆分史书/三国志/卷047.txt#L168)

> 權揆其不然，曰：「吾待蜀不薄，聘享盟誓，無所負之，何以致此？又司馬懿前來入舒，旬日便退，蜀在萬里，何知緩急而便出兵乎？昔魏欲入漢川，此閒始嚴，亦未舉動，會聞魏還而止，蜀寧可復以此有疑邪？又人家治國，舟船城郭，何得不獲？今此閒治軍，寧復欲以禦蜀邪？人言苦不可信，朕爲諸君破家保之。」蜀竟自無謀，如權所籌。

**吴臣疑蜀背盟，孙权消解疑虑** 孙权以平日无负于蜀、其路远不及乘魏退之机反问，并拿吴曾欲助汉中而不及发军为比。

**吴臣疑蜀背盟，孙权消解疑虑** 孙权认为修船治城是国政常事，吴整军亦非为攻蜀，表示愿破家担保。后来蜀果无异谋。

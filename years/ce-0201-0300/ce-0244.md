<a id="sg-event-1"></a>

1. **诏大将军曹爽率衆征蜀。** 五年春二月，诏大将军曹爽率衆征蜀。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **日有蚀之。** 夏四月朔，发生日食。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **讲尚书经通，使太常以太牢祠孔子于辟雍。** 五月癸巳，讲尚书经通，使太常以太牢祠孔子于辟雍，以颜渊配；赐太传、大将军及侍讲者各有差。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **大将军曹爽引军还。** 丙午，大将军曹爽引军还。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **秦王询薨。** 秋八月，秦王询去世。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **鲜卑内附，置辽东属国。** 九月，鲜卑内附，置辽东属国，立昌黎县以居之。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **诏祀故尚书令荀攸于太祖庙庭。** 冬十一月癸卯，诏祀故尚书令荀攸于太祖庙庭。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **复秦国为京兆郡。** 己酉，复秦国为京兆郡。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **司空崔林薨。** 十二月，司空崔林去世。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **曹髦封高贵乡公。** 东海定王曹霖的儿子曹髦被封为高贵乡公。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **毌丘俭初破高句丽。** 高句丽王宫先袭扰西安平，《高句丽》以正始五年为毌丘俭击败王宫之年；本传记魏军从玄菟出兵，战沸流、攻破丸都。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **安平王刘理去世。** 四月刘理去世。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **陆逊任吴丞相。** 孙权任原上大将军陆逊为丞相，续顾雍之后主持朝政。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **裴潜去世。** 裴潜于本年去世。 [[14]](#sg-note-14)

<a id="sy-event-15"></a>

15. **张承去世。** 吴将张承去世，传载六十七岁，谥定侯，其子张震承袭。 [[15]](#sy-note-15)

<a id="sgz-event-16"></a>

16. **费祎自汉中返回成都。** 费祎九月回到成都。 [[16]](#sgz-note-16)

<a id="sgz-event-17"></a>

17. **改葬孙登于蒋陵。** 孙登初葬三年后迁葬。 [[17]](#sgz-note-17)

<a id="sgz-event-18"></a>

18. **董允以侍中守尚书令，副费祎。** 董允兼摄尚书令，作为费祎副手。 [[18]](#sgz-note-18)

<a id="sgz-event-19"></a>

<a id="sgz-event-20"></a>

20. **曹茂徙乐陵，恢复旧户并加邑。** 曹魏因其租奉少、子嗣多，赐还曾削诸户，并另加七百户。 [[20]](#sgz-note-20)

> 五年春二月，詔大將軍曹爽率衆征蜀。

<a id="sg033-l1704-e1"></a>

**[《三国志·后主传》](../../sources/摘录/三国志-卷033-后主传.md#p004)** · [仓内TXT L1704](../../sources/本地分卷/三国志/三国志-卷033.md#l1704)

> 七年閏月，魏大將軍曹爽、夏侯玄等向漢中，鎮北大將軍王平拒興勢圍，大將軍費禕督諸軍往赴救，魏軍退。

<a id="sg043-l2038-e1"></a>

**[《三国志·黄李吕马王张传》](../../sources/摘录/三国志-卷043-黄李吕马王张传.md#p003)** · [仓内TXT L2038](../../sources/本地分卷/三国志/三国志-卷043.md#l2038)

> 七年春，魏大將軍曹爽率步騎十餘萬向漢川，前鋒已在駱谷。時漢中守兵不滿三萬，諸將大驚。或曰：「今力不足以拒敵，聽當固守漢、樂二城，遇賊令入，比爾間，涪軍足得救關。」平曰：「不然。漢中去涪垂千里。賊若得關，便為禍也。今宜先遣劉護軍、杜參軍據興勢，平為後拒。若賊分向黃金，平率千人下自臨之，比爾間，涪軍行至，此計之上也。」惟護軍劉敏與平意同，即便施行。涪諸軍及費禕自成都相繼而至，魏軍退還，如平本策。

<a id="sg044-l2065-e1"></a>

**[《三国志·蒋琬费祎姜维传》](../../sources/摘录/三国志-卷044-蒋琬费祎姜维传.md#p001)** · [仓内TXT L2065](../../sources/本地分卷/三国志/三国志-卷044.md#l2065)

> 遂帥所領與平據興勢，多張旗幟，彌亙百餘里。會大將軍費禕從成都至，魏軍即退。敏以功封雲亭侯。

<a id="sg044-l2070-e1"></a>

**[《三国志·蒋琬费祎姜维传》](../../sources/摘录/三国志-卷044-蒋琬费祎姜维传.md#p002)** · [仓内TXT L2070](../../sources/本地分卷/三国志/三国志-卷044.md#l2070)

> 延熙七年，魏軍次於興勢，假禕節，率眾往御之。光祿大夫來敏至禕許別，求共圍棋。於時羽檄交馳，人馬擐甲，嚴駕已訖。禕與敏留意對戲，色無厭倦。敏曰：「向聊觀試君耳!君信可人，必能辦賊者也。」禕至，敵遂退，封成鄉侯。

<a id="sgz033-b-1704-1"></a>

**[《三国志·后主传》仓内原文 L1704](../../sources/本地分卷/三国志/三国志-卷033.md#l1704)**

> 七年閏月，魏大將軍曹爽、夏侯玄等向漢中，鎮北大將軍王平拒興勢圍，大將軍費禕督諸軍往赴救，

**释读** 闰月，魏大举向汉中，王平据兴势抵御，费祎督军增援。

**归年** 延熙七年，魏正始五年；《魏志·曹爽传》及《王平传》叙进攻始末。

<a id="sgz009-b-478-4"></a>

**[《三国志·诸夏侯曹传》仓内原文 L478](../../sources/本地分卷/三国志/三国志-卷009.md#l478)**

> 颺等欲令爽立威名於天下，勸使伐蜀，爽從其言，宣王止之不能禁。

**释读** 邓飏等欲使曹爽立武名，劝伐蜀，司马懿阻止不成。

**归年** 卷004正始五年春三月诏曹爽征蜀；本卷和通鉴卷074交代决策来由。

<a id="sgz009-b-478-5"></a>

**[《三国志·诸夏侯曹传》仓内原文 L478](../../sources/本地分卷/三国志/三国志-卷009.md#l478)**

> 正始五年，爽乃西至長安，大發卒六七萬人，從駱穀入。

**释读** 曹爽到长安征兵六七万，从骆谷推进。

**归年** 本传明正始五年，卷004《三少帝纪》与《通鉴》卷074 L586–601同年。

<a id="sgz009-b-478-6"></a>

**[《三国志·诸夏侯曹传》仓内原文 L478](../../sources/本地分卷/三国志/三国志-卷009.md#l478)**

> 是時，關中及氐、羌轉輸不能供，牛馬騾驢多死，民夷號泣道路。入穀行數百里，賊因山爲固，兵不得進。

**释读** 关中与氐、羌无力维持转运，牛马等多死，民夷道哭；蜀据险固守，魏军行数百里仍不得前进。

**归年** 与正始五年骆谷进军同役。

<a id="sgz009-b-496-2"></a>

**[《三国志·诸夏侯曹传》仓内原文 L496](../../sources/本地分卷/三国志/三国志-卷009.md#l496)**

> 與曹爽共興駱穀之役，時人譏之。

**释读** 夏侯玄和曹爽共同发动骆谷之役，时人讥议。

**归年** 卷004正始五年及本卷曹爽传记同役。

<a id="sgz009-p-035-27"></a>

**[《三国志·诸夏侯曹传》裴注 035·27](../../sources/摘录/三国志-卷009-诸夏侯曹传裴注.md#pei-035-27)**

> 駱谷之役議從勝出由是司馬宣王不悦於勝

**释读** 注说骆谷之役出自李胜建议，因此司马懿不满他。

**归年** 卷004正始五年三月曹爽伐蜀。

<a id="sgz044-b-2065-2"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2065](../../sources/本地分卷/三国志/三国志-卷044.md#l2065)**

> 魏遣大將軍曹爽襲蜀時，時議者或謂但可守城，不出拒敵，必自引退。敏以為男女布野，農谷棲畝，若聽敵人，則大事去矣。遂帥所領與平據興勢，多張旗幟，彌亙百餘里。

**释读** 曹爽袭蜀，有人议固城待魏自退。刘敏认为田野、百姓都将遭受损失，随王平据兴势并多张旗帜。

**归年** 《后主传》《王平传》《通鉴》卷074，延熙七年春，主战同兴势。

<a id="sgz044-b-2070-1"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2070](../../sources/本地分卷/三国志/三国志-卷044.md#l2070)**

> 延熙七年，魏軍次於興勢，假禕節，率眾往御之。光祿大夫來敏至禕許別，求共圍棋。於時羽檄交馳，人馬擐甲，嚴駕已訖。禕與敏留意對戲，色無厭倦。敏曰：「向聊觀試君耳!君信可人，必能辦賊者也。」

**释读** 魏军到兴势，费祎假节率军抵御。来敏来别，请下棋，费祎在军情紧张时仍从容对弈，来敏因之相信他能抗敌。

**归年** 本传明书延熙七年，《资治通鉴》卷074正始五年闰月发援。

<a id="sgz044-b-2078-2"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2078](../../sources/本地分卷/三国志/三国志-卷044.md#l2078)**

> 及興勢之役，王平捍拒曹爽，皆承此制。

**释读** 兴势之役王平拒曹爽，沿用先前设兵诸围办法。

**归年** 《王平传》延熙七年；本段追叙。

<a id="sgz043-b-2034-21"></a>

**[《三国志·黄李吕马王张传》仓内原文 L2034](../../sources/本地分卷/三国志/三国志-卷043.md#l2034)**

> 七年春，大將軍費韋北禦魏敵，留忠成都，平尚書事。

**释读** 费祎北上防御曹魏，马忠留成都平尚书事。

**归年** 本传明记延熙七年春，底本「費韋」为费祎。

<a id="sgz043-b-2038-1"></a>

**[《三国志·黄李吕马王张传》仓内原文 L2038](../../sources/本地分卷/三国志/三国志-卷043.md#l2038)**

> 七年春，魏大將軍曹爽率步騎十餘萬向漢川，前鋒已在駱谷。時漢中守兵不滿三萬，諸將大驚。

**释读** 魏大将军曹爽率十余万步骑出向汉川，前锋到骆谷，汉中守军不到三万，诸将惊慌。

**归年** 本传延熙七年春；《曹爽传》正始五年所发「六七萬人」是所征兵数，口径不同，保留本传军势记载。

<a id="sgz043-b-2038-2"></a>

**[《三国志·黄李吕马王张传》仓内原文 L2038](../../sources/本地分卷/三国志/三国志-卷043.md#l2038)**

> 或曰：「今力不足以拒敵，聽當固守漢、樂二城，遇賊令入，比爾間，涪軍足得救關。」平曰：「不然。漢中去涪垂千里。賊若得關，便為禍也。今宜先遣劉護軍、杜參軍據興勢，平為後拒。若賊分向黃金，平率千人下自臨之，比爾間，涪軍行至，此計之上也。」惟護軍劉敏與平意同，即便施行。

**释读** 诸将有人建议退守汉、乐二城待涪救兵；王平认为一失关隘为祸，应先据兴势，自己在后接应并准备救黄金，刘敏赞同并施行。

**归年** 延熙七年兴势之役。

<a id="sgz026-b-1403-1"></a>

**[《三国志·满田牵郭传》仓内原文 L1403](../../sources/本地分卷/三国志/三国志-卷026.md#l1403)**

> 五年，夏侯玄伐蜀，淮督諸軍爲前鋒。淮度勢不利，輙拔軍出，故不大敗。還假淮節。

**释读** 郭淮率前锋，形势不利遂率部先退出，回魏后获假节。

**归年** 正始五年兴势之役，《齐王纪》《王平传》同，另有撤军同年条。

<a id="sgz064-p-008-4"></a>

**[《三国志·诸葛滕二孙濮阳传》裴注 008·4](../../sources/摘录/三国志-卷064-诸葛滕二孙濮阳传裴注.md#pei-008-4)**

> 昔魏人伐蜀蜀人禦之精嚴垂發六軍雲擾士馬擐甲羽檄交馳費禕時為元帥荷國任重而與来敏圍棊意無厭倦敏臨别謂禕君必能辦賊者也言其明略内定貌無憂色

**释读** 魏伐蜀将行，费祎仍与来敏弈棋，来敏认为费祎此态足以办敌。

**归年** 《费祎传》延熙七年救汉中，裴注《别传》同见围棋。

<a id="sgz013-b-652-9"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L652](../../sources/本地分卷/三国志/三国志-卷013.md#l652)**

> 大將軍曹爽盛夏興軍伐蜀，蜀拒守，軍不得進。爽方欲增兵，

**释读** 曹爽盛夏出军，被蜀兵阻守，想增兵。

**归年** 《后主传》《王平传》延熙七年兴势之役，魏正始五年。

<a id="sgz013-b-652-10"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L652](../../sources/本地分卷/三国志/三国志-卷013.md#l652)**

> 毓與書曰：「竊以爲廟勝之策，不臨矢石；王者之兵，有徵無戰。誠以干戚可以服有苗，退舍足以納原寇，不必縱吳漢於江關，騁韓信於井陘也。

**释读** 钟毓写信说运筹未必亲冒矢石，用舜、晋文公不用战求成的旧例相劝，亦举吴汉、韩信之战非必效。

**归年** 同一书。

<a id="sgz013-b-652-11"></a>

**[《三国志·钟繇华歆王朗传》仓内原文 L652](../../sources/本地分卷/三国志/三国志-卷013.md#l652)**

> 見可而進，知難而退，蓋自古之政。惟公侯詳之！」爽無功而還。

**释读** 请知难而退，曹爽终无功班师。

**归年** 同役。

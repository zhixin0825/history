[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **诏大将军曹爽率衆征蜀。** 五年春二月，诏大将军曹爽率衆征蜀。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **日有蚀之。** 夏四月朔，发生日食。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **讲尚书经通，使太常以太牢祠孔子于辟雍。** 五月癸巳，讲尚书经通，使太常以太牢祠孔子于辟雍，以颜渊配；赐太传、大将军及侍讲者各有差。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **大将军曹爽引军还。** 丙午，大将军曹爽引军还。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **秦王询薨。** 秋八月，秦王询去世。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **鲜卑内附，置辽东属国。** 九月，鲜卑内附，置辽东属国，立昌黎县以居之。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **诏祀故尚书令荀攸于太祖庙庭。** 冬十一月癸卯，诏祀故尚书令荀攸于太祖庙庭。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **复秦国为京兆郡。** 己酉，复秦国为京兆郡。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **司空崔林薨。** 十二月，司空崔林去世。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **曹髦封高贵乡公。** 东海定王曹霖的儿子曹髦被封为高贵乡公。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **毌丘俭初破高句丽。** 高句丽王宫先袭扰西安平，《高句丽》以正始五年为毌丘俭击败王宫之年；本传记魏军从玄菟出兵，战沸流、攻破丸都。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **安平王刘理去世。** 四月刘理去世。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **陆逊任吴丞相。** 孙权任原上大将军陆逊为丞相，续顾雍之后主持朝政。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **裴潜去世。** 裴潜于本年去世。 [[14]](#sg-note-14)

<a id="sy-event-15"></a>

15. **张承去世。** 吴将张承去世，传载六十七岁，谥定侯，其子张震承袭。 [[15]](#sy-note-15)

<a id="sgz-event-16"></a>

16. **费祎自汉中返回成都。** 费祎九月回到成都。 [[16]](#sgz-note-16)

> 五年春二月，詔大將軍曹爽率衆征蜀。

<a id="sg033-l1704-e1"></a>

**[《三国志·后主传》](../../sources/摘录/三国志-卷033-后主传.md#p004)** · [仓内TXT L1704](../../sources/本地分卷/三国志/三国志-卷033.md#l1704)

> 七年閏月，魏大將軍曹爽、夏侯玄等向漢中，鎮北大將軍王平拒興勢圍，大將軍費禕督諸軍往赴救，魏軍退。

<a id="sg043-l2038-e1"></a>

**[《三国志·黄李吕马王张传》](../../sources/摘录/三国志-卷043-黄李吕马王张传.md#p003)** · [仓内TXT L2038](../../sources/本地分卷/三国志/三国志-卷043.md#L2038)

> 七年春，魏大將軍曹爽率步騎十餘萬向漢川，前鋒已在駱谷。時漢中守兵不滿三萬，諸將大驚。或曰：「今力不足以拒敵，聽當固守漢、樂二城，遇賊令入，比爾間，涪軍足得救關。」平曰：「不然。漢中去涪垂千里。賊若得關，便為禍也。今宜先遣劉護軍、杜參軍據興勢，平為後拒。若賊分向黃金，平率千人下自臨之，比爾間，涪軍行至，此計之上也。」惟護軍劉敏與平意同，即便施行。涪諸軍及費禕自成都相繼而至，魏軍退還，如平本策。

<a id="sg044-l2065-e1"></a>

**[《三国志·蒋琬费祎姜维传》](../../sources/摘录/三国志-卷044-蒋琬费祎姜维传.md#p001)** · [仓内TXT L2065](../../sources/本地分卷/三国志/三国志-卷044.md#L2065)

> 遂帥所領與平據興勢，多張旗幟，彌亙百餘里。會大將軍費禕從成都至，魏軍即退。敏以功封雲亭侯。

<a id="sg044-l2070-e1"></a>

**[《三国志·蒋琬费祎姜维传》](../../sources/摘录/三国志-卷044-蒋琬费祎姜维传.md#p002)** · [仓内TXT L2070](../../sources/本地分卷/三国志/三国志-卷044.md#L2070)

> 延熙七年，魏軍次於興勢，假禕節，率眾往御之。光祿大夫來敏至禕許別，求共圍棋。於時羽檄交馳，人馬擐甲，嚴駕已訖。禕與敏留意對戲，色無厭倦。敏曰：「向聊觀試君耳!君信可人，必能辦賊者也。」禕至，敵遂退，封成鄉侯。

<a id="sgz033-b-1704-1"></a>

**[《三国志·后主传》仓内原文 L1704](../../sources/本地分卷/三国志/三国志-卷033.md#l1704)**

> 七年閏月，魏大將軍曹爽、夏侯玄等向漢中，鎮北大將軍王平拒興勢圍，大將軍費禕督諸軍往赴救，

**释读** 闰月，魏大举向汉中，王平据兴势抵御，费祎督军增援。

**归年** 延熙七年，魏正始五年；《魏志·曹爽传》及《王平传》叙进攻始末。

> 冬十一月癸卯，詔祀故尚書令荀攸於太祖廟庭。

<a id="sgz004-p-003-1"></a>

**[《三国志·三少帝纪》裴注 003·1](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-003-1)**

> 臣松之以為故魏氏配饗不及荀彧蓋以其末年異議又位非魏臣故也至於升程昱而遺郭嘉先鍾繇而後荀攸則未詳厥趣也徐佗謀逆而許褚心動忠義之至逺同於日磾且潼關之危非褚不濟褚之功烈有過典韋今祀韋而不及褚又所未達也

**释读** 裴松之推想荀彧未配享或因晚年政见和非魏臣身份，又不解程昱先于郭嘉、钟繇先于荀攸、典韦入祀而许褚不入。以许褚忠于曹操并救潼关之危为比较。

**归年** 注释244年荀攸配享，占位是对多年祭制的考语。郭嘉增入见262，潼关见211。

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **南安郡地震。** 六年春二月丁卯，南安郡地震。 [[1]](#sg-note-1)

<a id="sgz-event-27"></a>

<a id="sg-event-2"></a>

2. **赵俨升任司空，六月去世。** 正始六年二月赵俨由骠骑将军升任司空，六月卒，谥穆，子赵亭承嗣。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **以太常高柔为司空。** 八月丁卯，以太常高柔为司空。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **以左光禄大夫刘放为骠骑将军。** 癸巳，以左光禄大夫刘放为骠骑将军，右光禄大夫孙资为衞将军。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **祫祭太祖庙，始祀前所论佐命臣二十一人。** 冬十一月，祫祭太祖庙，始祀前所论佐命臣二十一人。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **诏故司徒王朗所作易传。** 十二月辛亥，诏故司徒王朗所作易传，令学者得以课试。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **诏曰“明日大会群臣”。** 乙亥，诏曰：「明日大会群臣，其令太傅乘舆上殿。」 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **毌丘俭复征高句丽。** 高句丽王宫逃走，玄菟太守王颀追经沃沮至肃慎南境，魏军刻石纪功。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **乐浪带方出兵东濊。** 刘茂与弓遵攻打原属高句丽的东濊，不耐侯等以所属邑来降。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **魏赐难升米黄幢。** 魏廷诏令赐难升米黄幢，由带方郡授予，实际遣人送达见后文。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **费祎巡汉中。** 十二月，蜀大将军费祎巡察汉中守备。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **陆逊去世。** 赤乌八年二月，吴丞相陆逊去世。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **吴发屯田、役作人开句容水道。** 八月赦后，校尉陈勋领三万人开凿句容通道，使市场交通相接，并设邸阁。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **蜀穆皇太后吴氏薨，与刘备合葬惠陵。** 延熙八年，后薨，合葬惠陵。 [[14]](#sg-note-14)

<a id="sgz-event-15"></a>

15. **魏氏春秋称赵俨葬礼众客逾席迎夏侯玄。** 《魏氏春秋》追叙司空赵俨卒，司马氏兄弟赴葬，夏侯玄晚来，众客越席相迎，致司马师嫌恶。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **吴诛谋乱将领马茂。** 降吴者马茂谋逆，事泄被诛，孙权深恨。 [[16]](#sgz-note-16)

<a id="sgz-event-17"></a>

17. **二宫分党，陆逊警告全琮。** 中外官多遣子侍两宫；全琮告陆逊，陆逊说勿徇荣利，两宫势敌必成党争。 [[17]](#sgz-note-17)

<a id="sgz-event-18"></a>

18. **陆逊、顾谭请分别孙和、孙霸的礼秩。** 陆逊要求稳固太子正统，使鲁王宠秩有别；重复上奏并请求回都面陈嫡庶，孙权未准。顾谭也上疏请分别太子与国王的尊卑、礼秩，以求保全兄弟。 [[18]](#sgz-note-18)

<a id="sgz-event-26"></a>

<a id="sgz-event-19"></a>

19. **全氏追争芍陂战功，顾谭等被徙，张休被赐死。** 顾谭上疏后与鲁王生隙，早先又不肯结交投靠鲁王的全寄。全琮父子追究芍陂赏功，指控典军陈恂为张休、顾承虚增战功，张休因此入狱。孙权想让顾谭谢罪了结，顾谭却当众直斥谗言。有司以大不敬议顾谭死罪，孙权念及顾雍，改为流放。顾谭、顾承、张休被徙交州，亲附太子的姚信也遭流徙。后来孙弘再进谗言，张休被赐死，年四十一。顾谭在流徙中著《新言》二十篇。 [[19]](#sgz-note-19)

<a id="sgz-event-22"></a>

<a id="sgz-event-20"></a>

20. **吾粲因涉及二宫事被诛。** 吾粲多与陆逊通信，被下狱诛死。 [[20]](#sgz-note-20)

<a id="sgz-event-21"></a>

21. **陆抗袭领五千部曲并答孙权质问。** 陆逊卒时陆抗二十岁，任建武校尉领父部五千，送葬回东。孙权隔绝宾客而问杨竺发告的二十事，陆抗逐件作答，孙权渐解。 [[21]](#sgz-note-21)

<a id="sgz-event-23"></a>

23. **雷击吴宫与南津桥。** 夏季雷击宫门柱、南津大桥柱。 [[23]](#sgz-note-23)

<a id="sgz-event-24"></a>

24. **茶陵水灾。** 茶陵洪水，冲坏二百余户。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **吴八月大赦。** 吴大赦天下。 [[25]](#sgz-note-25)

<a id="sgz-event-28"></a>

28. **缪袭去世。** 缪袭历事魏朝四世，六十岁去世。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **琅邪王夫人遭全公主进谗，忧惧而死。** 孙权病时孙和祭庙，受张休邀请短暂过访。全公主借此称孙和与妃家筹议，又称王夫人见孙权病而喜。孙权怒责王夫人，王夫人忧惧而死，孙和失宠。 [[29]](#sgz-note-29)

### 8. 毌丘俭复征高句丽

[返回正文第8条](#sg-event-8)

<a id="sg028-l1451-e8"></a>

**[《三国志·王毌丘诸葛邓钟传》](../../sources/本地分卷/三国志/三国志-卷028.md#p002)** · [仓内TXT L1451](../../sources/本地分卷/三国志/三国志-卷028.md#l1451)

> 六年，復征之，宮遂奔買溝。儉遣玄菟太守王頎追之，過沃沮千有餘里，至肅慎氏南界

**归年与互校** “六年”承正始。另见卷三十五年初破及《齐王纪》七年讨高句丽，不强行统一。

<a id="sgz030-b-1590-10"></a>

**[《三国志·乌丸鲜卑东夷传》仓内原文 L1590](../../sources/本地分卷/三国志/三国志-卷030.md#l1590)**

> 其後高句麗背叛，又遣偏師致討，窮追極遠，逾烏丸、骨都，過沃沮，踐肅慎之庭，東臨大海。

**释读** 诸军攻高句丽后追过沃沮、至肃慎，穷其东界。

**归年** 《毌丘俭传》六年再征并遣王颀远追，244年初征另有条。

<a id="sgz030-b-1593-3"></a>

**[《三国志·乌丸鲜卑东夷传》仓内原文 L1593](../../sources/本地分卷/三国志/三国志-卷030.md#l1593)**

> 正始中，幽州刺史毌丘儉討句麗，遣玄菟太守王頎詣夫餘，位居遣大加郊迎，供軍糧。

**释读** 毌丘俭讨高句丽时派玄菟太守王颀到夫余，位居派大加相迎并供军粮。

**归年** 对照《毌丘俭传》正始六年再次出征并以王颀远追的军务，先后未详，附同年复征。

<a id="sgz030-b-1604-1"></a>

**[《三国志·乌丸鲜卑东夷传》仓内原文 L1604](../../sources/本地分卷/三国志/三国志-卷030.md#l1604)**

> 毌丘儉討句麗，句麗王宮奔沃沮，遂進師擊之。沃沮邑落皆破之，斬獲首虜三千餘級，宮奔北沃沮。

**释读** 高句丽王位宫奔沃沮，魏军追击，破邑落、斩俘三千余，王再奔北沃沮。

**归年** 《毌丘俭传》正始六年复征时“奔買溝”；后有王颀追至肃慎。

<a id="sgz030-b-1604-3"></a>

**[《三国志·乌丸鲜卑东夷传》仓内原文 L1604](../../sources/本地分卷/三国志/三国志-卷030.md#l1604)**

> 王頎別遣追討宮，盡其東界。

**释读** 王颀奉遣继续追击，直到东境。

**归年** 《毌丘俭传》正始六年再征，玄菟太守王颀追至肃慎。

<a id="sgz030-b-1604-4"></a>

**[《三国志·乌丸鲜卑东夷传》仓内原文 L1604](../../sources/本地分卷/三国志/三国志-卷030.md#l1604)**

> 問其耆老「海東復有人不」？

**释读** 魏军询问当地长者有关海外人居的情况。

**归年** 系于245年追讨中采问；答语中的漂流无年。

<a id="sgz028-b-1451-4"></a>

**[《三国志·王毌丘诸葛邓钟传》仓内原文 L1451](../../sources/本地分卷/三国志/三国志-卷028.md#l1451)**

> 六年，復征之，宮遂奔買溝。儉遣玄菟太守王頎追之，過沃沮千有餘里，至肅慎氏南界，刻石紀功，刊丸都之山，銘不耐之城。

**释读** 王宫逃到买沟，王颀追并刻石记功，于丸都及不耐等处纪功。

**归年** 正始六年，《东夷传》《三少帝纪》可互查；刻石残碑纪年有异读。

<a id="sgz028-b-1451-5"></a>

**[《三国志·王毌丘诸葛邓钟传》仓内原文 L1451](../../sources/本地分卷/三国志/三国志-卷028.md#l1451)**

> 諸所誅納八千餘口，論功受賞，侯者百餘人。穿山溉灌，民賴其利。

**释读** 讨降计八千余，受封百多人，另记通渠灌溉，民赖之。

**归年** 245年续征奏功，灌溉实施期无明确日。

### 29. 琅邪王夫人遭全公主进谗，忧惧而死

[返回正文第29条](#sgz-event-29)



<a id="sgz050-b-2424-2b"></a>

<a id="wu050-l51-3"></a>

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l51-3)** · [TXT L51](../../sources/本地分卷/三国志/三国志-卷050.txt#L51)

> 權將立夫人爲后，而全公主素憎夫人，稍稍譖毀。及權寢疾，言有喜色，由是權深責怒，以憂死。

**釋讀** 孙权曾意欲册王氏。全公主谗称孙权患病时王氏面有喜色，王氏被责忧死。

**歸年** 与《孙和传》孙权卧病、全主谮王夫人及孙和同案；此处沿年页与仓内《通鉴》卷七十四赤乌八年，前段拟立、久谗及具体死日未独立记年。

<a id="sgz059-b-2827-1"></a>

**[《三国志·吴主五子传》仓内原文 L2827](../../sources/本地分卷/三国志/三国志-卷059.md#l2827)**

> ﻿是後王夫人與全公主有隙。權嘗寢疾，和祠祭於廟，和妃叔父張休居近廟，邀和過所居。全公主使人覘視，因言太子不在廟中，專就妃家計議；又言王夫人見上寢疾，有喜色。權由是發怒，夫人憂死，而和寵稍損，懼於廢黜。

**释读** 孙和祭庙过张休家，全公主使人窥伺，诬言王夫人见孙权有病而喜，王夫人因责怒忧死。

**归年** 《资治通鉴》卷七十四系赤乌八年。

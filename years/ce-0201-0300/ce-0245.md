# 公元245年｜魏正始六年／蜀延熙八年／吴赤乌八年

[← 公元244年](ce-0244.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元246年 →](ce-0246.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **南安郡地震。** 六年春二月丁卯，南安郡地震。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **以骠骑将军赵俨为司空。** 丙子，以骠骑将军赵俨为司空；夏六月，俨去世。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **以太常高柔为司空。** 八月丁卯，以太常高柔为司空。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **以左光禄大夫刘放为骠骑将军。** 癸巳，以左光禄大夫刘放为骠骑将军，右光禄大夫孙资为衞将军。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **祫祭太祖庙，始祀前所论佐命臣二十一人。** 冬十一月，祫祭太祖庙，始祀前所论佐命臣二十一人。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **诏故司徒王朗所作易传。** 十二月辛亥，诏故司徒王朗所作易传，令学者得以课试。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **诏曰“明日大会群臣”。** 乙亥，诏曰：「明日大会群臣，其令太傅乘舆上殿。」 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **毌丘俭复征高句丽。** 高句丽王宫逃走，玄菟太守王颀追经沃沮至肃慎南境，魏军刻石纪功。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **乐浪带方出兵东濊。** 刘茂与弓遵攻打原属高句丽的东濊，不耐侯等以所属邑来降。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **魏赐难升米黄幢。** 魏廷诏令赐难升米黄幢，由带方郡授予，实际遣人送达见后文。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **费祎巡汉中。** 十二月，蜀大将军费祎巡察汉中守备。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **陆逊去世。** 赤乌八年二月，吴丞相陆逊去世。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **吴发屯田、役作人开句容水道。** 八月赦后，校尉陈勋领三万人开凿句容通道，使市场交通相接，并设邸阁。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **蜀穆皇太后吴氏薨，与刘备合葬惠陵。** 延熙八年，后薨，合葬惠陵。 [[14]](#sg-note-14)

<a id="sgz-event-15"></a>

15. **魏氏春秋称赵俨葬礼众客逾席迎夏侯玄。** 《魏氏春秋》追叙司空赵俨卒，司马氏兄弟赴葬，夏侯玄晚来，众客越席相迎，致司马师嫌恶。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **吴诛谋乱将领马茂。** 降吴者马茂谋逆，事泄被诛，孙权深恨。 [[16]](#sgz-note-16)

<a id="sgz-event-17"></a>

17. **二宫分党，陆逊警告全琮。** 中外官多遣子侍两宫；全琮告陆逊，陆逊说勿徇荣利，两宫势敌必成党争。 [[17]](#sgz-note-17)

<a id="sgz-event-18"></a>

18. **陆逊屡疏请分别孙和、孙霸。** 陆逊要求稳固太子正统，使鲁王宠秩有别；重复上奏并请求回都面陈嫡庶。 [[18]](#sgz-note-18)

<a id="sgz-event-19"></a>

19. **顾谭、顾承、姚信被流徙。** 孙权不允面陈，陆逊的外甥顾谭、顾承、姚信因亲附太子被流放。 [[19]](#sgz-note-19)

<a id="sgz-event-20"></a>

20. **吾粲因涉及二宫事被诛。** 吾粲多与陆逊通信，被下狱诛死。 [[20]](#sgz-note-20)

<a id="sgz-event-21"></a>

21. **陆抗袭领五千部曲并答孙权质问。** 陆逊卒时陆抗二十岁，任建武校尉领父部五千，送葬回东。孙权隔绝宾客而问杨竺发告的二十事，陆抗逐件作答，孙权渐解。 [[21]](#sgz-note-21)

<a id="sgz-event-22"></a>

22. **吾粲谏嫡庶之分、下狱被杀。** 二宫相争时吾粲要求鲁王孙霸出驻夏口，杨竺不得留都，以明嫡庶。 [[22]](#sgz-note-22)

<a id="sgz-event-23"></a>

23. **雷击吴宫与南津桥。** 夏季雷击宫门柱、南津大桥柱。 [[23]](#sgz-note-23)

<a id="sgz-event-24"></a>

24. **茶陵水灾。** 茶陵洪水，冲坏二百余户。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **吴八月大赦。** 吴大赦天下。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **孙弘进谗，张休被赐死。** 张休平日不满孙弘奸佞，被他进谗，孙权命张休死，年四十一。 [[26]](#sgz-note-26)

**释读** 马茂等计划孙权在苑射猎时伪称诏命拘执公卿，入苑刺孙权，分据宫中、石头并联络魏，事泄皆被族诛。

**归年** 本纪赤乌八年七月，《通鉴》卷七十四同记。

### 17. 二宫分党，陆逊警告全琮

<a id="sgz058-b-2794-1"></a>

**[《三国志·陆逊传》仓内原文 L2794](../../sources/本地分卷/三国志/三国志-卷058.md#l2794)**

> 先是，二宮並闕，中外職司，多遣子弟給侍。全琮報遜，遜以為「子弟苟有才，不憂不用，不宜私出以要榮利。若其不佳，終為取禍。且聞二宮勢敵，必有彼此，此古人之厚忌也。」

### 18. 陆逊屡疏请分别孙和、孙霸

[返回正文第18条](#sgz-event-18)

<a id="sgz058-b-2794-3"></a>

**[《三国志·陆逊传》仓内原文 L2794](../../sources/本地分卷/三国志/三国志-卷058.md#l2794)**

> 及太子有不安之儀，遜上疏陳：「太子正統，宜有磐石之固，魯王藩臣，當使寵秩有差，彼此得所，上下獲安。謹叩頭流血以聞。」書三四上，及求詣都，欲口論適庶之分，以匡得失。

**归年** 《通鉴》卷七十四将极谏系245。

<a id="sgz052-b-2491-2"></a>

**[《三国志·张顾诸葛步传》仓内原文 L2491](../../sources/本地分卷/三国志/三国志-卷052.md#l2491)**

> 是時魯王霸有盛寵，與太子和齊衡，譚上疏曰：

**释读** 鲁王孙霸盛宠、与太子孙和齐礼，顾谭为此进疏。

**归年** 《通鉴》卷七十四编于245陆逊等谏之后。

<a id="sgz052-b-2492-1"></a>

**[《三国志·张顾诸葛步传》仓内原文 L2492](../../sources/本地分卷/三国志/三国志-卷052.md#l2492)**

> 臣聞有國有家者，必明嫡庶之端，異尊卑之禮，使高下有差，階級逾邈，如此則骨肉之恩生，覬覦之望絕。昔賈誼陳治安之計，論諸侯之勢，以為勢重，雖親必有逆節之累，勢輕，雖疏必有保全之祚。故淮南親弟，不終饗國，失之於勢重也。吳芮疏臣，傳祚長沙，得之於勢輕也。

**释读** 宜明尊卑杜绝觊觎；引贾谊及淮南王、吴芮受封轻重，说明礼位之差可保骨肉。

**归年** 245太子与鲁王争端上疏。

<a id="sgz052-b-2492-2"></a>

**[《三国志·张顾诸葛步传》仓内原文 L2492](../../sources/本地分卷/三国志/三国志-卷052.md#l2492)**

> 昔漢文帝使慎夫人與皇后同席，袁盎退夫人之座，帝有怒色。及盎辨上下之儀，陳人彘之戒，帝既悅怪，夫人亦悟。今臣所陳，非有所偏，誠欲以安太子而便魯王也。

**释读** 引袁盎撤慎夫人座以明尊卑，表明兼为保太子和鲁王，并非偏向某人。

**归年** 同245年奏疏；汉文帝旧事为引证。

> 為魯王霸友黨所譖，與顧譚、承俱以芍陂論功事，休、承與典軍陳恂通情，詐增其伐，並徙交州。

**释读** 鲁王党派谓张休、顾承与陈恂通情虚报芍陂战功，张休与顾谭顾承同徙。

**归年** 芍陂战241，获谮处分从《通鉴》245。

<a id="sgz052-b-2493-1"></a>

**释读** 顾谭因此与鲁王有隙，不容倾邪的全琮子全寄。

**归年** 《通鉴》卷七十四连二宫和流放列245。

<a id="sgz052-b-2493-4"></a>

**[《三国志·张顾诸葛步传》仓内原文 L2493](../../sources/本地分卷/三国志/三国志-卷052.md#l2493)**

> 寄父子益恨，共構會譚。譚坐徙交州，幽而發憤，著《新言》仁十篇。其《知難篇》蓋以自悼傷也。

**释读** 挟战功旧争合谋加罪，顾谭被放逐，到南方后愤而著《新言》，《知难篇》自悼。

**归年** 《通鉴》卷七十四245徙；书在流放期间，作年不确。

<a id="sgz052-b-2495-5"></a>

**[《三国志·张顾诸葛步传》仓内原文 L2495](../../sources/本地分卷/三国志/三国志-卷052.md#l2495)**

> 數年，與兄譚，張休等懼徙交州，

**释读** 数年后顾承与兄顾谭、张休一同被徙交州。

**归年** 《通鉴》卷七十四系赤乌八年。

<a id="sgz052-p-022-1"></a>

**[《三国志·张顾诸葛步传》裴注 022·1](../../sources/摘录/三国志-卷052-张顾诸葛步传裴注.md#pei-022-1)**

> 吳錄曰全琮父子屢言芍陂之役為典軍陳恂詐增張休顧承之功而休承與恂通情休坐繫獄

**释读** 《吴录》说全琮父子屡告陈恂虚增二人芍陂战功，张休由此入狱。

**归年** 追究241战功，与245徙人同案；原役归241#9。

<a id="sgz052-p-022-2"></a>

**[《三国志·张顾诸葛步传》裴注 022·2](../../sources/摘录/三国志-卷052-张顾诸葛步传裴注.md#pei-022-2)**

**归年** 245案经过，《吴录》。

<a id="sgz052-p-022-3"></a>

**[《三国志·张顾诸葛步传》裴注 022·3](../../sources/摘录/三国志-卷052-张顾诸葛步传裴注.md#pei-022-3)**

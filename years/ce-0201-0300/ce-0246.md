# 公元246年｜魏正始七年／蜀延熙九年／吴赤乌九年

[← 公元245年](ce-0245.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元247年 →](ce-0247.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **幽州刺史毋丘俭讨高句骊。** 七年春二月，幽州刺史毋丘俭讨高句骊，夏五月，讨濊貊，皆破之。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **韩那奚等数十国各率种落降。** [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **诏曰“属到巿观见所斥卖官奴婢”。** 秋八月戊申，诏曰：「属到巿观见所斥卖官奴婢，年皆七十，或𤸇疾残病，所谓天民之穷者也。且官以其力竭而复鬻之，进退无谓，其悉遣为良民。若有不能自存者，郡县振给之。」 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **诏曰“吾乃当以十九日亲祠”。** 己酉，诏曰：「吾乃当以十九日亲祠，而昨出已见治道，得雨当复更治，徒弃功夫。每念百姓力少役多，夙夜存心。道路但当期于通利，闻乃檛捶老小，务崇修饰，疲困流离，以至哀叹，吾岂安乘此而行，致馨德于宗庙邪？自今已后，明申勑之。」 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **讲《礼记》通，使太常以太牢祀孔子于辟雍。** 冬十二月，讲《礼记》通，使太常以太牢祀孔子于辟雍，以颜渊配。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **蒋琬去世。** 费祎六月回成都，十一月蒋琬去世。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **董允去世。** 董允在延熙九年去世，此前是尚书令、费祎副手。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **孟光反对频繁赦免。** 秋季大赦，孟光当众责问费祎，主张大赦只用于不得已时，频繁宽赦会纵容犯法之人。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **蒋琬去世。** 蒋琬病重回涪县，延熙九年去世，谥恭。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **朱然征柤中，步骘等分受新职。** 春二月朱然攻取柤中，秋九月吴任步骘为丞相，朱然等一并调任。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **徙封济南，三千户。** 正始七年，徙封济南，三千户。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **转封平阳公。** 正始七年，转封平阳公。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **徙封文安。** 正始七年，徙封文安。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **代陆逊为丞相，犹诲育门生。** 赤乌九年，代陆逊为丞相，犹诲育门生，手不释书。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **迁骠骑将军。** 赤乌九年，迁骠骑将军。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **迁立节中郎将，与诸葛恪换屯柴桑。** 赤乌九年，迁立节中郎将，与诸葛恪换屯柴桑。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **迁右大司马、左军师。** 赤乌九年，迁右大司马、左军师。 [[17]](#sg-note-17)

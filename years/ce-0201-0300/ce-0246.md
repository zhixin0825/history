## 本年概述

韓地諸部歸魏，東北戰事另有系年異說。蜀漢蒋琬、董允去世。吳任步騭為丞相，調整諸將屯駐，並罷行大錢。

## 魏東北邊事與朝廷紀事

<a id="sg-event-1"></a>

<a id="sg-event-2"></a>

1. **韩地诸部归魏。** 韩那奚等数十国各率部众归魏。魏军讨高句丽、濊貊也有系于正始七年二月、五月的记载，详见[244年初战](ce-0244.md#sg-note-11)、[245年复征及进攻东濊](ce-0245.md#sg-note-8)与本条注。 [[1]](#sg-note-1)

<a id="sg-event-3"></a>

2. **曹芳下令释放年迈和残病的官奴婢。** 八月戊申，曹芳在市中见到被出售的年迈或残病官奴婢，下令释放这些人为良民，由郡县救济不能维生者。 [[2]](#sg-note-3)

<a id="sg-event-4"></a>

3. **曹芳下诏减省修路民役。** 八月己酉，曹芳得知道路为亲祭而反复整修，老幼被鞭责劳作，下令今后只须修至道路可通。 [[3]](#sg-note-4)

<a id="sg-event-5"></a>

4. **讲《礼记》通，使太常以太牢祀孔子于辟雍。** 冬十二月，讲《礼记》通，使太常以太牢祀孔子于辟雍，以颜渊配。 [[4]](#sg-note-5)

<a id="sg-event-11"></a>

<a id="sg-event-12"></a>

<a id="sg-event-13"></a>

5. **魏徙封曹楷、曹琮和曹赞。** 任城王曹楷改封济南，食三千户。承嗣曹冲的曹琮转封平阳公，承嗣曹蕤的曹赞徙封文安。 [[5]](#sg-note-11)

<a id="sgz-event-18"></a>

6. **刘放、孙资各再封一子为亭侯。** 两人又各有一子获亭侯。 [[6]](#sgz-note-18)

## 蜀廷人事與政令

<a id="sg-event-6"></a>

7. **蒋琬去世。** 六月，费祎结束[上年开始的汉中巡察](ce-0245.md#sg-note-11)，回到成都。十一月，蒋琬去世，谥恭，儿子蒋斌承袭爵位。刘禅此后亲自处理国事，费祎仍参与商定政令和赏罚。 [[7]](#sg-note-6)

<a id="sg-event-7"></a>

8. **董允去世，吕乂接任尚书令。** 董允在延熙九年去世。吕乂接任尚书令，陈祗接任侍中。陈祗与黄皓相互勾连，黄皓由此开始参与政事。 [[8]](#sg-note-7)

<a id="sg-event-8"></a>

9. **孟光反对频繁赦免。** 秋季大赦，孟光当众责问费祎，主张大赦只用于不得已时，频繁宽赦会纵容犯法之人。他又以秋季鹰隼开始捕击为例，认为此时赦罪不合时令。费祎只能回顾致歉，神情局促。 [[9]](#sg-note-8)

## 吳軍務與財政

<a id="sg-event-9"></a>



<a id="sg-event-10"></a>

10. **朱然进攻魏柤中。** 二月，朱然率兵攻柤中。魏将李兴等引步骑六千，企图截断吴军退路，朱然夜袭后撤。柤中大批民吏渡沔水避兵，司马懿劝暂留他们在北岸，曹爽仍让他们返回，吴军后来又来袭击。袁淮建议魏退守淮、汉以北，朝廷未采纳。出征前，朱然曾上疏请以战功纾解朝廷对马茂谋逆的愤怒；孙权在群臣贺胜时出示该奏疏，称许朱然。 [[10]](#sg-note-10)

11. **吴任步骘为丞相，并改任诸将。** 秋九月，孙权任步骘为丞相，朱然为左大司马、兼右军师，全琮为右大司马、兼左军师，吕岱为上大将军，诸葛恪为大将军，假节驻武昌，接掌陆逊原领的荆州军务。武昌分为两部，吕岱督右部，自武昌上至蒲圻。其子吕凯任副军校尉、在蒲圻监兵。本年朱据升骠骑将军，陆抗升立节中郎将，与诸葛恪换营，移屯柴桑。陆抗离开旧营前修好城垣墙屋，保护营中住屋及桑果。诸葛恪到任后见营舍如新，再对照自己原屯柴桑的破损，深感惭愧。 [[11]](#sg-note-14)

<a id="sgz-event-19"></a>

12. **武昌报甘露。** 夏四月武昌报告甘露。 [[12]](#sgz-note-19)

<a id="sgz-event-20"></a>

13. **吴罢行大钱并准折价输还。** 孙权说谢宏原议铸大钱以广货，百姓却不便，下诏省罢改铸器物。民间持币可公藏折付价钱，不许亏枉。 [[13]](#sgz-note-20)

### 2. 曹芳下令释放年迈和残病的官奴婢

<a id="wei004-l34-3"></a>

**[《三國志·三少帝紀》正文](../../拆分史书/三国志/卷004.md#edition-wei004-l34-3)** · [TXT L34](../../拆分史书/三国志/卷004.txt#L34)

> 秋八月戊申，詔曰：「屬到巿觀見所斥賣官奴婢，年皆七十，或𤸇疾殘病，所謂天民之窮者也。且官以其力竭而復鬻之，進退無謂，其悉遣爲良民。若有不能自存者，郡縣振給之。」

**釋讀與歸年** 八月戊申，曹芳见市上出售年约七十或患残疾的官奴婢，下诏免为良民，并责郡县赈济无力自存者。

<a id="sgz004-p-004-1"></a>

**归年** 附正始七年八月释老病官奴婢的条文；比较的是239及246两项。

<a id="wei004-l35-1"></a>

**[《三國志·三少帝紀》裴注](../../拆分史书/三国志/卷004.md#edition-wei004-l35-1)** · [TXT L35](../../拆分史书/三国志/卷004.txt#L35)

> 臣松之案：帝初即位，有詔「官奴婢六十以上免爲良人」。旣有此詔，則宜遂爲永制。七八年間，而復貨年七十者，且七十奴婢及𤸇疾殘病，並非可售之物，而鬻之於巿，此皆事之難解。

**釋讀與歸年** 裴松之据239年即位诏本已有免六十以上官奴婢的规定，指出七八年后又发卖年七十者难解；两道诏各保留在施行当年。

### 10. 朱然进攻魏柤中

**釋讀** 車騎將軍朱然進攻魏柤中，斬獲千餘。

**歸年** 本傳赤烏九年二月。

<a id="sgz004-p-005-1"></a>

**归年** “是年”承正始七年，与吴书《朱然传》赤乌九年一致；再次袭击无确月。

<a id="wei004-l38-1"></a>

**[《三國志·三少帝紀》裴注](../../拆分史书/三国志/卷004.md#edition-wei004-l38-1)** · [TXT L38](../../拆分史书/三国志/卷004.txt#L38)

> 習鑿齒漢晉春秋曰：是年，吳將朱然入柤中，斬獲數千；柤中民吏萬餘家渡沔。司馬宣王謂曹爽曰：「若便令還，必復致寇，宜權留之。」爽曰：「今不脩守沔南，留民沔北，非長策也。」宣王曰：「不然。凡物置之安地則安，危地則危，故兵書曰，成敗形也，安危勢也，形勢御衆之要，不可不審。設令賊二萬人斷沔水，三萬人與沔南諸軍相持，萬人陸鈔柤中，君將何以救之？」爽不聽，卒令還。然後襲殺之。

**釋讀與歸年** 《汉晋春秋》本条书“是年”，记朱然攻柤中及万余家渡沔，司马懿与曹爽对遣还意见相反；曹爽最终遣还。与正始二年多路攻魏和《朱然传》下文的叙事分别读。

<a id="sgz004-p-005-2"></a>

**归年** 承246年柤中战事，《汉晋春秋》同注。讲的是建议，不能当作已迁。

<a id="wei004-l38-2"></a>

**[《三國志·三少帝紀》裴注](../../拆分史书/三国志/卷004.md#edition-wei004-l38-2)** · [TXT L38](../../拆分史书/三国志/卷004.txt#L38)

> 袁淮言於爽曰：「吳楚之民脆弱寡能，英才大賢不出其土，比技量力，不足與中國相抗，然自上世以來常爲中國患者，蓋以江漢爲池，舟楫爲用，利則陸鈔，不利則入水，攻之道遠，中國之長技無所用之也。孫權自十數年以來，大畋江北，繕治甲兵，精其守禦，數出盜竊，敢遠其水，陸次平土，此中國所願聞也。夫用兵者，貴以飽待飢，以逸擊勞，師不欲乆，行不欲遠，守少則固，力專則彊。當今宜捐淮、漢已南，退却避之。若賊能入居中央，來侵邊境，則隨其所短，中國之長技得用矣。若不敢來，則邊境得安，無鈔盜之憂矣。使我國富兵彊，政脩民一，陵其國不足爲遠矣。今襄陽孤在漢南，賊循漢而上，則斷而不通，一戰而勝，則不攻而自服，故置之無益於國，亡之不足爲辱。自江夏已東，淮南諸郡，三后已來，其所亡幾何，以近賊疆界易鈔掠之故哉！若徙之淮北，遠絕其間，則民人安樂，何鳴吠之驚乎？」遂不徙。

**釋讀與歸年** 袁淮就吴水军和淮汉地利陈说全篇，建议撤出淮、汉以南诱吴离水；结语“遂不徙”是此建议未实行，区别于上文曹爽遣还柤中流民。

**釋讀** 赤乌九年，朱然再攻柤中。李兴等率魏军步骑六千截其回路，朱然夜间迎击，胜后返回。

**[《三國志·吳主傳》 裴注 050·1](../../拆分史书/三国志/卷047.md#pei-050-1)** · [TXT L176](../../拆分史书/三国志/卷047.txt#L176)

> 江表傳曰：是歲，權詔曰：「謝宏往日陳鑄大錢，云以廣貨，故聽之。今聞民意不以爲便，其省息之，鑄爲器物，官勿復出也。私家有者，勑以輸藏，計畀其直，勿有所枉也。」

**归年** 《江表传》“是嵗”承赤乌九年，《通鉴》卷七十五正始七年明载罢大钱。

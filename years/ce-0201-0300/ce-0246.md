<a id="sg-event-1"></a>

1. **幽州刺史毋丘俭讨高句骊。** 七年春二月，幽州刺史毋丘俭讨高句骊，夏五月，讨濊貊，皆破之。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **韩那奚等数十国各率种落降。** [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **诏曰“属到巿观见所斥卖官奴婢”。** 秋八月戊申，诏曰：「属到巿观见所斥卖官奴婢，年皆七十，或𤸇疾残病，所谓天民之穷者也。且官以其力竭而复鬻之，进退无谓，其悉遣为良民。若有不能自存者，郡县振给之。」 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **诏曰“吾乃当以十九日亲祠”。** 己酉，诏曰：「吾乃当以十九日亲祠，而昨出已见治道，得雨当复更治，徒弃功夫。每念百姓力少役多，夙夜存心。道路但当期于通利，闻乃檛捶老小，务崇修饰，疲困流离，以至哀叹，吾岂安乘此而行，致馨德于宗庙邪？自今已后，明申勑之。」 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **讲《礼记》通，使太常以太牢祀孔子于辟雍。** 冬十二月，讲《礼记》通，使太常以太牢祀孔子于辟雍，以颜渊配。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **蒋琬去世。** 费祎六月回成都，十一月蒋琬去世。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **董允去世。** 董允在延熙九年去世，此前是尚书令、费祎副手。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **孟光反对频繁赦免。** 秋季大赦，孟光当众责问费祎，主张大赦只用于不得已时，频繁宽赦会纵容犯法之人。 [[8]](#sg-note-8)

10. **朱然征柤中，步骘等分受新职。** 春二月朱然攻取柤中，秋九月吴任步骘为丞相，朱然等一并调任。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **徙封济南，三千户。** 正始七年，徙封济南，三千户。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **转封平阳公。** 正始七年，转封平阳公。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **徙封文安。** 正始七年，徙封文安。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **代陆逊为丞相，犹诲育门生。** 赤乌九年，代陆逊为丞相，犹诲育门生，手不释书。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **迁骠骑将军。** 赤乌九年，迁骠骑将军。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **迁立节中郎将，与诸葛恪换屯柴桑。** 赤乌九年，迁立节中郎将，与诸葛恪换屯柴桑。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **迁右大司马、左军师。** 赤乌九年，迁右大司马、左军师。 [[17]](#sg-note-17)

<a id="sgz-event-18"></a>

18. **刘放、孙资各再封一子为亭侯。** 两人又各有一子获亭侯。 [[18]](#sgz-note-18)

<a id="sgz-event-19"></a>

19. **武昌报甘露。** 夏四月武昌报告甘露。 [[19]](#sgz-note-19)

<a id="sgz-event-20"></a>

20. **吴罢行大钱并准折价输还。** 孙权说谢宏原议铸大钱以广货，百姓却不便，下诏省罢改铸器物。民间持币可公藏折付价钱，不许亏枉。 [[20]](#sgz-note-20)

> 秋八月戊申，詔曰：「屬到巿觀見所斥賣官奴婢，年皆七十，或𤸇疾殘病，所謂天民之窮者也。且官以其力竭而復鬻之，進退無謂，其悉遣為良民。若有不能自存者，郡縣振給之。」

<a id="sgz004-p-004-1"></a>

**[《三国志·三少帝纪》裴注 004·1](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-004-1)**

> 臣松之案帝初即位有詔官奴婢六十以上免為良人既有此詔則宜遂為永制七八年間而復貨年七十者且七十奴婢及癃疾殘病竝非可售之物而鬻之於市此皆事之難解

**释读** 裴松之指出曹芳即位时释放六十以上官奴婢，七八年后市上仍在出售七十岁及残疾者，对诏令未延续表示不解。

**归年** 附正始七年八月释老病官奴婢的条文；比较的是239及246两项。

### 10. 朱然征柤中，步骘等分受新职

[返回正文第10条](#sg-event-10)

<a id="sg047-l2325-e10"></a>

**[《三国志·吴主传》](../../sources/摘录/三国志-卷047-吴主传.md#p009)** · [仓内TXT L2325](../../sources/本地分卷/三国志/三国志-卷047.md#l2325)

> 秋九月，以驃騎步騭爲丞相，車騎朱然爲左大司馬，衞將軍全琮爲右大司馬，鎮南呂岱爲上大將軍，威北將軍諸葛恪爲大將軍。

<a id="sgz004-p-005-1"></a>

**[《三国志·三少帝纪》裴注 005·1](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-005-1)**

> 習鑿齒漢晉春秋曰是年吳將朱然入柤中斬獲數千柤中民吏萬餘家渡沔司馬宣王謂曹爽曰若便令還必復致寇宜權留之爽曰今不修守沔南留民沔北非長策也宣王曰不然凡物置之安地則安危地則危故兵書曰成敗形也安危勢也形勢御衆之要不可不審設令賊二萬人斷沔水三萬人與沔南諸軍相持萬人陸鈔柤中君將何以救之爽不聽卒令還然後襲破之

**释读** 《汉晋春秋》载朱然入柤中，军民万余家渡沔；司马懿主张暂留，曹爽认为长留沔北非策，命居民回去，吴军后来又侵袭。

**归年** “是年”承正始七年，与吴书《朱然传》赤乌九年一致；再次袭击无确月。

<a id="sgz004-p-005-2"></a>

**[《三国志·三少帝纪》裴注 005·2](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-005-2)**

> 袁淮言於爽曰吳楚之民脆弱寡能英才大賢不出其土比技量力不足與中國相抗然自上世以來常為中國患者蓋以江漢為池舟楫為用利則陸鈔不利則入水攻之道逺中國之長技無所用之也孫權自十數年以來大畋江北繕治甲兵精其守禦數出盜竊敢逺其水陸次平土此中國所願聞也夫用兵者貴以飽待饑以逸擊勞師不欲久行不欲逺守少則固力專則彊當今宜損淮漢以南退却避之若賊能入居中央來侵邊境則隨其所短中國之長技得用矣若不敢來則邊境得安無鈔盜之憂矣使我國富兵彊政修民一陵其國不足為逺矣今襄陽孤在漢南賊循漢而上則斷而不通一戰而勝則不攻而自服故置之無益於國亡之不足為辱自江夏已東淮南諸郡三后已來其所亡幾何以近賊疆界易鈔掠之故哉若徙之淮北逺絶其間則民人安樂何鳴吠之驚乎遂不徙

**释读** 袁淮以吴善舟师、水为屏障，主张舍近敌难保之地，把居民移至较远处，使吴军失其水上便利、魏军得用所长，曹爽没有迁徙。

**归年** 承246年柤中战事，《汉晋春秋》同注。讲的是建议，不能当作已迁。

<a id="sgz056-b-2688-2"></a>

**[《三国志·朱治朱然吕范朱桓传》仓内原文 L2688](../../sources/本地分卷/三国志/三国志-卷056.md#l2688)**

> 九年，復征柤中，魏將李興等聞然深入，率步騎六千斷然後道，然夜出逆之，軍以勝反。

**释读** 李兴领六千步骑断吴归路，朱然夜出迎击获胜。

**归年** 《吴主传》赤乌九年二月亦记柤中之役。

<a id="sgz056-b-2688-4"></a>

**[《三国志·朱治朱然吕范朱桓传》仓内原文 L2688](../../sources/本地分卷/三国志/三国志-卷056.md#l2688)**

> 然臨行上疏曰："馬茂小子，敢負恩養。臣今奉天威，事蒙克捷，欲令所獲，震耀遠近，方舟塞江，使足可觀，以解上下之忿。惟陛下識臣先言，責臣後效。"權時抑表不出。

**释读** 朱然上疏说将立战功、以战果平上下之忿，孙权先压下其表。

**归年** 本传承赤乌九年征柤中。

<a id="sgz056-b-2688-5"></a>

**[《三国志·朱治朱然吕范朱桓传》仓内原文 L2688](../../sources/本地分卷/三国志/三国志-卷056.md#l2688)**

> 然既獻捷，群臣上賀，權乃舉酒作樂，而出然表曰："此家前初有表，孤以為難必，今果如其言，可謂明於見事也。"遣使拜然為左大司馬、右軍師。

**释读** 献捷后孙权让群臣知其前表，称赞预见，拜左大司马、右军师。

**归年** 《吴主传》赤乌九年秋九月任左大司马；献捷在战后。

> 恪遷大將軍，假節，駐武昌，代遜領荊州事。

**释读** 诸葛恪任大将军、假节，驻武昌接替陆逊管理荆州。

**归年** 《吴主传》赤乌九年九月明记大将军任命；本传把任命和陆逊245年之卒接叙，驻武昌未另记月。

**[《三国志·贺全吕周钟离传》仓内原文 L2868](../../sources/本地分卷/三国志/三国志-卷060.md#l2868)**

> 諸葛恪代遜，權乃分武昌為兩部，岱督右部，自武昌上至蒲圻。

**释读** 诸葛恪接陆逊之任，孙权把武昌分两部，令吕岱督右部，自武昌上至蒲圻。

**归年** 《吴主传》赤乌九年诸葛恪、吕岱大迁官，《诸葛恪传》也记代逊。

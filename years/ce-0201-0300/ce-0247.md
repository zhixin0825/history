## 本年概述

郭淮、姜維在羌地與隴右交兵。司馬懿稱疾避居，曹爽主政。吳有步騭、全琮去世，又重建太初宮，邊地准諸葛壹以詐降誘魏。

## 魏廷政事與司馬懿退居

<a id="sgz-event-14"></a>

<a id="sgz-event-15"></a>

1. **曹爽排斥异己，司马懿称疾。** 曹爽把尚书奏事和禁军职权逐渐收归亲近的人。何晏掌选举，曹爽的弟弟曹羲、曹训分领中军和武卫，奏事逐渐绕过司马懿。五月，司马懿称病，不再参与朝政。 [[1]](#sgz-note-14)

<a id="sg-event-3"></a>

<a id="sg-event-4"></a>

<a id="sg-event-5"></a>

2. **何晏、孔乂先后向曹芳进谏。** 七月，何晏劝曹芳亲近正直之人，临幸式乾殿、游后园时让大臣随行，借此询问政事、讲论经义。十二月，谏议大夫孔乂请去宫室朱丹装饰，停止在后园习骑，出行乘车，并慎定赏罚。 [[2]](#sg-note-3)

<a id="sg-event-1"></a>

3. **日有蚀之。** 八年春二月朔，发生日食。 [[3]](#sg-note-1)

<a id="sg-event-2"></a>

4. **分河东之汾北十县为平阳郡。** 夏五月，分河东之汾北十县为平阳郡。 [[4]](#sg-note-2)

<a id="sg-event-13"></a>

5. **为屯骑校尉。** 延熙十年，为屯骑校尉。 [[5]](#sg-note-13)

<a id="sgz-event-22"></a>

6. **钟会任尚书郎，母执手戒自满。** 钟会年轻即入朝任职，母亲张昌蒲拉着他的手，告诫他不要因早受选用而自满。钟毓宴后回家，谈到曹爽纵酒骄奢，张昌蒲指出，身居高位须自守节度，曹爽如此行事难以长保富贵。 [[6]](#sgz-note-22)

## 魏蜀西北與海東邊事

<a id="sg-event-6"></a>

<a id="sg-event-9"></a>

7. **羌、蜀与魏争西北，郭淮进兵，姜维接纳降众。** 陇西、南安等地的饿何、烧戈等羌部起事，招引蜀军，凉州的治无戴也响应。诸将主张先平枹罕，郭淮料姜维将袭为翅，先去援助屯守的夏侯霸，逼姜维退走，再回军击羌，斩饿何、烧戈，一万余落归降。白虎文、治无戴等降蜀，姜维置于繁县，又讨平汶山平康。 [[7]](#sg-note-6)

<a id="sg-event-7"></a>

8. **魏册不耐濊王。** 继[正始六年的战事](ce-0245.md#sg-note-8)之后，不耐侯到魏廷朝贡，魏改封他为不耐濊王；他仍定期赴边郡朝谒，为乐浪、带方两郡供役纳赋。 [[8]](#sg-note-7)

<a id="sg-event-8"></a>

9. **卑弥呼遣使陈说与狗奴国的争战。** 王颀到任带方太守后，卑弥呼派载斯、乌越到郡中说明与狗奴国的战事。带方郡随后派张政等携魏诏和[早先获赐的黄幢](ce-0245.md#sg-note-10)赴倭，授命难升米，并以檄文告谕。其后卑弥呼去世，倭国内乱，改立[宗女壹与](时期-三国志卷030-乌丸鲜卑东夷传纪年待考（3）.md#period-sgz030-b-1624-7)。 [[9]](#sg-note-8)

<a id="sg-event-10"></a>

10. **向朗去世。** 向朗年老仍校书，延熙十年去世。 [[10]](#sg-note-10)

## 吳廷人事及軍政

<a id="sg-event-11"></a>

11. **吴丞相步骘去世。** 赤乌十年夏五月，丞相步骘去世，儿子步协接领他的部众，加抚军将军。他于[上年九月任相](ce-0246.md#sg047-l2325-e10)。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **吴右大司马全琮去世。** 全琮任吴右大司马，去世后由儿子全怿袭爵。 [[12]](#sg-note-12)

<a id="sgz-event-16"></a>

13. **吴重建太初宫，调武昌旧宫材瓦。** 赤乌十年三月，孙权因建业旧宫屋柱腐朽，下令取武昌宫材瓦重作太初宫，诸将和州郡出力，次年三月宫成。 [[13]](#sgz-note-16)

<a id="sgz-event-17"></a>

14. **孙权集兵建业，王基判断吴军不会北进。** 吴在建业调集军队，扬言攻扬州。扬州刺史诸葛诞问安丰太守王基如何应对。王基说孙权年老，陆逊等旧将已死，新将尚未获信，起兵远出还要担心内乱。这次集兵是重整兵力以自保，吴军果然没有出动。 [[14]](#sgz-note-17)

<a id="sgz-event-18"></a>

15. **孙权前往南宫。** 二月孙权赴南宫。 [[15]](#sgz-note-18)

<a id="sgz-event-19"></a>

16. **吴十月赦死罪。** 十月吴赦免死罪。 [[16]](#sgz-note-19)

<a id="sgz-event-20"></a>

17. **吴令诸葛壹诈降诱诸葛诞。** 孙权派诸葛壹诈叛，诸葛诞率步骑二万人到高山接应。孙权进至高山，潜军设伏。太子孙和担忧孙权露宿军中和战事无常，多次上谏劝他持重。诸葛诞察觉后撤退，孙和等到孙权回师才安心。 [[17]](#sgz-note-20)

<a id="sgz-event-21"></a>

18. **顾谭卒于交阯。** 流放后两年死于交阯，享年四十二。 [[18]](#sgz-note-21)

### 2. 何晏、孔乂先后向曹芳进谏

<a id="sg004-l226-e3"></a>

<a id="wei004-l42-1"></a>

**[《三國志·三少帝紀》正文](../../拆分史书/三国志/卷004.md#edition-wei004-l42-1)** · [TXT L42](../../拆分史书/三国志/卷004.txt#L42)

> 秋七月，尚書何晏奏曰：「善爲國者必先治其身，治其身者慎其所習。所習正則其身正，其身正則不令而行；所習不正則其身不正，其身不正則雖令不從。是故爲人君者，所與游必擇正人，所觀覽必察正象，放鄭聲而弗聽，遠佞人而弗近，然後邪心不生而正道可弘也。季末闇主不知損益，斥遠君子，引近小人，忠良疏遠，便辟褻狎，亂生近暱，譬之社鼠；考其昏明，所積以然，故聖賢諄諄以爲至慮。舜戒禹曰『鄰哉鄰哉』，言慎所近也，周公戒成王曰『其朋其朋』，言慎所與也。書云：『一人有慶，兆民賴之。』可自今以後，御幸式乾殿及游豫後園，皆大臣侍從，因從容戲宴，兼省文書，詢謀政事，講論經義，爲萬世法。」

**釋讀與歸年** 秋七月何晏上奏，劝曹芳择正人相从，正视听、远佞臣，并令临幸式乾殿和游后园时大臣侍从、问政讲经。奏文完整合引。

> 冬十二月，散騎常侍諫議大夫孔晏乂奏曰：「禮，天子之宮，有斲礱之制，無朱丹之飾，宜循禮復古。今天下已平，君臣之分明，陛下但當不懈于位，平公正之心，審賞罰以使之。可絕後園習騎乘馬，出必御輦乘車，天下之福，臣子之願也。」

### 3. 日有蚀之

[返回正文第3条](#sg-event-1)

<a id="wei014-l130-1"></a>

**[《三國志·程郭董劉蔣劉傳》正文](../../拆分史书/三国志/卷014.md#edition-wei014-l130-1)** · [TXT L130](../../拆分史书/三国志/卷014.txt#L130)

> 是時，曹爽專政，丁謐、鄧颺等輕改法度。會有日蝕變，詔群臣問其得失，濟上疏曰：「昔大舜佐治，戒在比周；周公輔政，慎於其朋；齊侯問災，晏嬰對以布惠；魯君問異，臧孫荅以緩役。應天塞變，乃實人事。今二賊未滅，將士暴露已數十年，男女怨曠，百姓貧苦。夫爲國法度，惟命世大才，乃能張其綱維以垂于後，豈中下之吏所宜改易哉？終無益於治，適足傷民，望宜使文武之臣各守其職，率以清平，則和氣祥瑞可感而致也。」

**釋讀與歸年** 曹爽专政，丁谧、邓飏常改法度。日食后朝廷征询得失，蒋济说应灾在于人事，劝节役、各尽其职，勿让小吏轻改祖制。[《资治通鉴》卷75](../../史书/025-资治通鉴/KR2b0007_075.txt#L84-L102)及[《晋书·天文志》](../../史书/005-晋书/晋书-CCDH.txt#L1807)均把此疏接在正始八年日食之后，本文无独立奏日。

<a id="sg045-l2096-e13"></a>

**[《三国志·邓张宗杨传》](../../拆分史书/三国志/卷045.md#p002)** · [仓内TXT L2096](../../拆分史书/三国志/卷045.md#l2096)

> 延熙十年，為屯騎校尉。

**归年与互校** 原传明记年号和年次；后续回叙见本卷。

<a id="sgz045-b-2096-1"></a>

**[《三国志·邓张宗杨传》仓内原文 L2096](../../拆分史书/三国志/卷045.md#l2096)**

> 延熙十年，為屯騎校尉。時車騎將軍鄧芝自江州還，來朝，謂預曰：「禮，六十不服戎，而卿甫受兵，何也？」預答曰：「卿七十不還兵，我六十何為不受邪？」芝性驕傲，自大將軍費禕等皆避下之，而預獨不為屈。

**释读** 邓芝从江州返朝，说按礼六十不从戎，宗预反问他年七十仍未交还兵权，自己六十为何不能受兵；宗预不屈于邓芝。

**归年** 本传延熙十年，新官答话相承。两人口中年龄非出生原始记录。

> 吳嘗大發衆集建業，揚聲欲入攻揚州，刺史諸葛誕使基策之。基曰：「昔孫權再至合肥，一至江夏，其後全琮出廬江，朱然寇襄陽，皆無功而還。今陸遜等已死，而權年老，內無賢嗣，中無謀主。權自出則懼內釁卒起，癕疽發潰；遣將則舊將已盡，新將未信。此不過欲補定支黨，還自保護耳。」後權竟不能出。

**釋讀與歸年** 孫權大集兵於建業、揚言攻揚州。諸葛誕請安豐太守王基分析，王基指出陸遜等故將已死、孫權年老且內有矛盾，判斷集兵為自保；吳終未出。[《資治通鑑》卷七十五](../../史书/025-资治通鉴/KR2b0007_075.txt#L109-L130)繫正始八年，同條保留完整問答。

**归年** 《通鉴》卷七十五正始八年冬。引前几次攻合肥、江夏、庐江、襄阳皆为回述。

### 17. 吴令诸葛壹诈降诱诸葛诞

[返回正文第17条](#sgz-event-20)

<a id="sgz047-p-051-1"></a>

**[《三國志·吳主傳》 裴注 051·1](../../拆分史书/三国志/卷047.md#pei-051-1)** · [TXT L179](../../拆分史书/三国志/卷047.txt#L179)

> 江表傳曰：是歲權遣諸葛壹偽叛以誘諸葛誕，誕以步騎二萬迎壹於高山。權出涂中，遂至高山，潛軍以待之。誕覺而退。

**釋讀** 孫權遣諸葛壹假降，諸葛誕率步騎二萬至高山迎接。孫權由涂中出至高山，諸葛誕退走。

**歸年** 《江表傳》繫赤烏十年。



<a id="wu059-l32-2"></a>

**[《三國志·吳主五子傳》裴注 007](../../拆分史书/三国志/卷059.md#edition-wu059-l32-2)** · [TXT L32](../../拆分史书/三国志/卷059.txt#L32)

> 後諸葛壹偽叛以誘魏將諸葛誕，權潛軍待之。和以權暴露外次，又戰者凶事，常憂勞憯怛，不復會同飲食，數上諫，戒令持重，務在全勝，權還，然後敢安。

**釋讀** 诸葛壹诈作叛变诱骗魏将诸葛诞，孙权自己埋伏兵马等待。孙和担忧孙权露宿在外、出兵有险，停了聚饮，多次上谏劝持重，以全胜为先。孙权返回，他方安心。

**歸年** [《吴主传》引《江表传》](../../拆分史书/三国志/卷047.txt#L178-L179)在赤乌十年记同一次诈叛、孙权伏军于高山；两处今用TXT均作“諸葛壹”，旧摘录另作“諸葛豐”。

### 18. 顾谭卒于交阯

**[《三國志·張顧諸葛步傳》正文](../../拆分史书/三国志/卷052.md#edition-wu052-l80-2)** · [TXT L80](../../拆分史书/三国志/卷052.txt#L80)

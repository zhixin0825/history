# 公元247年｜魏正始八年／蜀延熙十年／吴赤乌十年

[← 公元246年](ce-0246.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元248年 →](ce-0248.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **日有蚀之。** 八年春二月朔，发生日食。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **分河东之汾北十县为平阳郡。** 夏五月，分河东之汾北十县为平阳郡。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **尚书何晏奏曰“善为国者必先治其身”。** 秋七月，尚书何晏奏曰：「善为国者必先治其身，治其身者慎其所习。所习正则其身正，其身正则不令而行；所习不正则其身不正，其身不正则虽令不从。是故为人君者，所与游必择正人，所观览必察正象，放郑声而弗听，远佞人而弗近，然后邪心不生而正道可弘也。季末闇主不知损益，斥远君子，引近小人，忠良疏远，便辟亵狎，乱生近昵，譬之社鼠；考其昏明，所积以然，故圣贤谆谆以为至虑。舜戒禹曰『邻哉邻哉』，言慎所近也，周公戒成王曰『其朋其朋』，言慎所与也。书云：『一人有庆，兆民赖之。』可自今以后，御幸式乾殿及游豫后园，皆大臣侍从，因从容戏宴，兼省文书，询谋政事，讲论经义，为万世法。」 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **散骑常侍谏议大夫孔晏乂奏曰“礼”。** 冬十二月，散骑常侍谏议大夫孔晏乂奏曰：「礼，天子之宫，有斲砻之制，无朱丹之饰，宜循礼复古。今天下已平，君臣之分明，陛下但当不懈于位，平公正之心，审赏罚以使之。可绝后园习骑乘马，出必御辇乘车，天下之福，臣子之愿也。」 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **晏乂咸因阙以进规谏。** [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **郭淮平西北羌乱并抵姜维。** 陇西等地羌众起事，会同凉州胡部招引蜀军；郭淮先救屯为翅的夏侯霸，再击诸羌。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **魏册不耐濊王。** 不耐侯等入朝，魏以不耐濊王重新册拜，四时仍向边郡朝谒。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **倭国遣使陈说狗奴国争战。** 带方太守王颀到任时，卑弥呼遣人来说明与狗奴国的冲突，魏郡派张政等在后续送诏书、黄幢。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **姜维安置凉州降众，讨平平康。** 白虎文、治无戴等降蜀，姜维置于繁县，又讨平汶山平康。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **向朗去世。** 向朗年老仍校书，延熙十年去世。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **吴重建太初宫，丞相步骘去世。** 在主传所载全琮正月卒后，吴三月重作太初宫，丞相步骘五月去世。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **全琮去世异年。** 吴主传载右大司马全琮是年正月去世。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **为屯骑校尉。** 延熙十年，为屯骑校尉。 [[13]](#sg-note-13)

[返回正文第3条](#sg-event-3)

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p002)** · [仓内TXT L226](../../sources/本地分卷/三国志/三国志-卷004.md#l226)

> 秋七月，尚書何晏奏曰：「善為國者必先治其身，治其身者慎其所習。所習正則其身正，其身正則不令而行；所習不正則其身不正，其身不正則雖令不從。是故為人君者，所與游必擇正人，所觀覽必察正象，放鄭聲而弗聽，遠佞人而弗近，然後邪心不生而正道可弘也。季末闇主不知損益，斥遠君子，引近小人，忠良疏遠，便辟褻狎，亂生近暱，譬之社鼠；考其昏明，所積以然，故聖賢諄諄以為至慮。舜戒禹曰『鄰哉鄰哉』，言慎所近也，周公戒成王曰『其朋其朋』，言慎所與也。書云：『一人有慶，兆民賴之。』可自今以後，御幸式乾殿及游豫後園，皆大臣侍從，因從容戲宴，兼省文書，詢謀政事，講論經義，為萬世法。」

### 9. 姜维安置凉州降众，讨平平康

[返回正文第9条](#sg-event-9)

<a id="sg033-l1707-e9"></a>

**[《三国志·后主传》](../../sources/摘录/三国志-卷033-后主传.md#p005)** · [仓内TXT L1707](../../sources/本地分卷/三国志/三国志-卷033.md#l1707)

> 十年，涼州胡王白虎文、治無戴等率眾降，衛將軍姜維迎逆安撫，居之於繁縣。是歲，汶山平康夷反，維往討，破平之。

<a id="sg044-l2074-e9"></a>

**[《三国志·蒋琬费祎姜维传》](../../sources/摘录/三国志-卷044-蒋琬费祎姜维传.md#p003)** · [仓内TXT L2074](../../sources/本地分卷/三国志/三国志-卷044.md#L2074)

> 十年，遷衛將軍，與大將軍費禕共錄尚書事。是歲，漢山平康夷反，維率眾討定之。又出隴西、南安、金城界，與魏大將軍郭淮、夏侯霸等戰於洮西。胡王治無戴等舉部落降，維將還安處之。

<a id="sgz033-b-1707-1"></a>

**[《三国志·后主传》仓内原文 L1707](../../sources/本地分卷/三国志/三国志-卷033.md#l1707)**

> 十年，涼州胡王白虎文、治無戴等率眾降，衛將軍姜維迎逆安撫，居之於繁縣。

**释读** 凉州首领白虎文、治无戴率众归蜀，姜维迎接，安置于繁县。

**归年** 延熙十年，《姜维传》同年叙胡王治无戴等降。

<a id="sgz033-b-1707-2"></a>

**[《三国志·后主传》仓内原文 L1707](../../sources/本地分卷/三国志/三国志-卷033.md#l1707)**

> 是歲，汶山平康夷反，維往討，破平之。

**释读** 汶山的平康部众起事，姜维出讨击平。

**归年** 本传延熙十年，《姜维传》写“漢山平康夷”，同一事件的地名呈异。

# 公元247年｜魏正始八年／蜀延熙十年／吴赤乌十年

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **日有蚀之。** 八年春二月朔，发生日食。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **分河东之汾北十县为平阳郡。** 夏五月，分河东之汾北十县为平阳郡。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **尚书何晏奏曰“善为国者必先治其身”。** 秋七月，尚书何晏奏曰：「善为国者必先治其身，治其身者慎其所习。所习正则其身正，其身正则不令而行；所习不正则其身不正，其身不正则虽令不从。是故为人君者，所与游必择正人，所观览必察正象，放郑声而弗听，远佞人而弗近，然后邪心不生而正道可弘也。季末闇主不知损益，斥远君子，引近小人，忠良疏远，便辟亵狎，乱生近昵，譬之社鼠；考其昏明，所积以然，故圣贤谆谆以为至虑。舜戒禹曰『邻哉邻哉』，言慎所近也，周公戒成王曰『其朋其朋』，言慎所与也。书云：『一人有庆，兆民赖之。』可自今以后，御幸式乾殿及游豫后园，皆大臣侍从，因从容戏宴，兼省文书，询谋政事，讲论经义，为万世法。」 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **散骑常侍谏议大夫孔晏乂奏曰“礼”。** 冬十二月，散骑常侍谏议大夫孔晏乂奏曰：「礼，天子之宫，有斲砻之制，无朱丹之饰，宜循礼复古。今天下已平，君臣之分明，陛下但当不懈于位，平公正之心，审赏罚以使之。可绝后园习骑乘马，出必御辇乘车，天下之福，臣子之愿也。」 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **晏乂咸因阙以进规谏。** [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **郭淮平西北羌乱并抵姜维。** 陇西等地羌众起事，会同凉州胡部招引蜀军；郭淮先救屯为翅的夏侯霸，再击诸羌。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **魏册不耐濊王。** 不耐侯等入朝，魏以不耐濊王重新册拜，四时仍向边郡朝谒。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **倭国遣使陈说狗奴国争战。** 带方太守王颀到任时，卑弥呼遣人来说明与狗奴国的冲突，魏郡派张政等在后续送诏书、黄幢。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **姜维安置凉州降众，讨平平康。** 白虎文、治无戴等降蜀，姜维置于繁县，又讨平汶山平康。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **向朗去世。** 向朗年老仍校书，延熙十年去世。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **吴重建太初宫，丞相步骘去世。** 在主传所载全琮正月卒后，吴三月重作太初宫，丞相步骘五月去世。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **全琮去世异年。** 吴主传载右大司马全琮是年正月去世。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **为屯骑校尉。** 延熙十年，为屯骑校尉。 [[13]](#sg-note-13)

<a id="sgz-event-14"></a>

14. **司马懿称疾退避曹爽。** 司马懿托病退避曹爽。 [[14]](#sgz-note-14)

<a id="sgz-event-15"></a>

15. **魏略称丁谧促使郭太后出居别宫。** 《魏略》指丁谧使郭太后出居别宫。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **孙权调武昌旧宫材瓦修建业宫。** 裴松之说孙权赤乌十年诏运武昌宫的木材、瓦片去修建业宫。 [[16]](#sgz-note-16)

> 延熙十年，為屯騎校尉。

**归年与互校** 原传明记年号和年次；后续回叙见本卷。

<a id="sgz045-b-2096-1"></a>

**[《三国志·邓张宗杨传》仓内原文 L2096](../../sources/本地分卷/三国志/三国志-卷045.md#l2096)**

> 延熙十年，為屯騎校尉。時車騎將軍鄧芝自江州還，來朝，謂預曰：「禮，六十不服戎，而卿甫受兵，何也？」預答曰：「卿七十不還兵，我六十何為不受邪？」芝性驕傲，自大將軍費禕等皆避下之，而預獨不為屈。

**释读** 邓芝从江州返朝，说按礼六十不从戎，宗预反问他年七十仍未交还兵权，自己六十为何不能受兵；宗预不屈于邓芝。

**归年** 本传延熙十年，新官答话相承。两人口中年龄非出生原始记录。

**归年** 《通鉴》卷075 L101–108系正始八年五月称疾。

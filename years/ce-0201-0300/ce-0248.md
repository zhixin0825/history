# 公元248年｜魏正始九年／蜀延熙十一年／吴赤乌十一年

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **衞将军中书令孙资，癸巳。** 九年春二月，衞将军中书令孙资，癸巳，骠骑将军中书监刘放，三月甲午，司徒衞臻，各逊位，以侯就第，位特进。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **以司空高柔为司徒，光禄大夫徐邈为司空。** 四月，以司空高柔为司徒；光禄大夫徐邈为司空，固辞不受。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **以车骑将军王淩为司空。** 秋九月，以车骑将军王淩为司空。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **大风发屋折树。** 冬十月，大风发屋折树。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **郭淮击遮塞、治无戴。** 郭淮以白土城渡河作战，败诸羌；再击败治无戴并转攻廖化，牵制姜维。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **费祎屯汉中，邓芝讨涪陵。** 费祎五月屯汉中；秋涪陵属国起事，邓芝平之。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **朱然修江陵，吴太初宫落成。** 正月朱然筑江陵，三月朝廷宫室建成。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **陆胤为交州刺史，招抚平乱。** 交阯、九真多处受攻，陆胤以刺史入南方，以恩信招降地方首领。 [[8]](#sg-note-8)

<a id="sy-event-9"></a>

9. **管辂被举为秀才。** 管辂被察举为秀才。 [[9]](#sy-note-9)

<a id="sy-event-10"></a>

10. **曹寻去世，封国撤除。** 曹寻去世，无子承袭，封国撤除。 [[10]](#sy-note-10)

<a id="sy-event-11"></a>

11. **李胜访司马懿，为其称病所欺。** 李胜出任荆州刺史前访司马懿，司马懿装作疾病沉重，李胜信以为真。 [[11]](#sy-note-11)

<a id="sgz-event-12"></a>

12. **皇甫谧正始九年冬梦曹爽遇诛。** 皇甫谧梦见洛阳宗庙车骑称诛曹爽；同乡不信，以曹爽握兵为据，皇甫谧用东汉阎显事比有兵也不能免。 [[12]](#sgz-note-12)

<a id="sgz-event-13"></a>

13. **王平去世。** 王平去世，儿子王训承袭。 [[13]](#sgz-note-13)

<a id="sgz-event-14"></a>

14. **孙礼临行劝司马懿匡扶魏室。** 司马懿以为不满并州、边界事；孙礼说忧社稷，泣请匡辅答明帝。 [[14]](#sgz-note-14)

<a id="sgz-event-15"></a>

15. **吴地连续地震。** 二月吴地再震。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **吴报雹及云阳黄龙。** 四月雨雹，云阳报告黄龙。 [[16]](#sgz-note-16)

<a id="sgz-event-17"></a>

17. **鄱阳报白虎、孙权诏论祥瑞。** 五月鄱阳报白虎仁，孙权诏引古代积善获祥瑞及《尚书》自勉，要求官员勤职辅正。 [[17]](#sgz-note-17)

<a id="sgz-event-18"></a>

18. **地震后孙权下诏求言过失。** 孙权因地震自认不明、获谴于神灵，令百官思陈其过，勿所忌讳。 [[18]](#sgz-note-18)

<a id="sgz-event-19"></a>

19. **管辂会何晏、邓颺并论《易》。** 何晏问能否位至三公及青蝇集鼻的梦，管辂以周公辅政与《易》谦、壮两卦劝少自盈；邓颺不接受。管辂归告舅父，舅责他言太直。 [[19]](#sgz-note-19)

> 九年二月乃賜詔曰君掌機密三十餘年經營庶事勲著前朝暨朕統位動頼良謀是以曩者增崇寵章同之三事外帥羣官内望讜言屬以年耆疾篤上還印綬前後鄭重辭㫖懇切天地以大順成徳君子以善恕成仁重以職事違奪君志今聼所執賜錢百萬使兼光禄勲少府親策詔君養疾于第君其勉進醫藥頤神和氣以永無疆之祚置舍人官騎加以日秩肴酒之膳焉

**释读** 下诏承认孙资多次以疾请辞，赐钱、派官宣诏让其家居养病，同时给舍人卫骑及膳。

**归年** 《资别传》正始九年二月；《三少帝纪》同年冬十月系二人逊位，日期异说。

<a id="sgz022-b-1221-7"></a>

**[《三国志·桓二陈徐卫卢传》仓内原文 L1221](../../sources/本地分卷/三国志/三国志-卷022.md#l1221)**

**释读** 卫臻坚求退休，曹魏诏以段干木、张良相勉，仍望献善谋，赐宅，加特进秩同三司。

**归年** 《三少帝纪》正始九年三月甲午和刘放、孙资辞官相列；纪作司徒，《通鉴》作司马。

### 5. 郭淮击遮塞、治无戴

[返回正文第5条](#sg-event-5)

<a id="sg026-l1403-e5"></a>

**[《三国志·满田牵郭传》](../../sources/摘录/三国志-卷026-满田牵郭传.md#p004)** · [仓内TXT L1403](../../sources/本地分卷/三国志/三国志-卷026.md#l1403)

> 九年，遮塞等屯河關、白土故城，據河拒軍。

<a id="sgz026-b-1403-4"></a>

**[《三国志·满田牵郭传》仓内原文 L1403](../../sources/本地分卷/三国志/三国志-卷026.md#l1403)**

> 九年，遮塞等屯河關、白土故城，據河拒軍。淮見形上流，密於下渡兵據白土城，擊，大破之。

**释读** 郭淮在上游示形，秘密率军从下游渡河，夺白土城并破遮塞。

**归年** 本传明正始九年。

<a id="sgz026-b-1403-5"></a>

**[《三国志·满田牵郭传》仓内原文 L1403](../../sources/本地分卷/三国志/三国志-卷026.md#l1403)**

> 治無戴圍武威，家屬留在西海。淮進軍趨西海，欲掩取其累重，會無戴折還，與戰於龍夷之北，破走之。

**释读** 治无戴围武威、家属在西海，郭淮趋西海，遇其撤回，在龙夷北将之击败。

**归年** 同一正始九年胡羌战局。

<a id="sgz026-b-1403-6"></a>

**[《三国志·满田牵郭传》仓内原文 L1403](../../sources/本地分卷/三国志/三国志-卷026.md#l1403)**

> 令居惡虜在石頭山之西，當大道止，斷絕王使。淮還過討，大破之。

**释读** 挡住大道使者的部众为郭淮回军所击破。

**归年** 本传承分叙正始九年战事。

<a id="sgz026-b-1403-7"></a>

**[《三国志·满田牵郭传》仓内原文 L1403](../../sources/本地分卷/三国志/三国志-卷026.md#l1403)**

> 姜維出石營，從彊川，乃西迎治無戴，留陰平太守廖化於成重山築城，斂破羌保質。淮欲分兵取之。諸將以維衆西接彊胡，化以據險，分軍兩持，兵勢轉弱，進不制維，退不拔化，非計也，不如合而俱西，及胡、蜀未接，絕其內外，此伐交之兵也。淮曰：「今往取化，出賊不意，維必狼顧。比維自致，足以定化，且使維疲於奔命。兵不遠西，而胡交自離，此一舉而兩全之策也。」乃別遣夏侯霸等追維於沓中，淮自率諸軍就攻化等。維果馳還救化，皆如淮計。進封都鄉侯。

**释读** 姜维西迎治无戴，令廖化筑城纳羌。郭淮评估先攻廖化可引姜维折返，遣夏侯霸追姜维，自己率兵攻廖化；姜维果往救。郭淮进都乡侯。

**归年** 正始九年据本传，本条归郭淮击各部战事；封侯随传役后所叙。

<a id="sg045-l2088-e6"></a>

**[《三国志·邓张宗杨传》](../../sources/摘录/三国志-卷045-邓张宗杨传.md#p001)** · [仓内TXT L2088](../../sources/本地分卷/三国志/三国志-卷045.md#l2088)

> 十一年夏五月，大將軍費禕出屯漢中。

<a id="sgz033-b-1708-2"></a>

**释读** 涪陵属国民夷于秋起事，车骑将军邓芝率军平定。

**归年** 本传明书延熙十一年，《邓芝传》亦记其率军平涪陵。

<a id="sgz044-b-2070-4"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2070](../../sources/本地分卷/三国志/三国志-卷044.md#l2070)**

**释读** 延熙十一年费祎出屯汉中，蒋琬、费祎在外时，赏罚刑威皆先远咨再行。

**归年** 《后主传》延熙十一年夏五月，遥决政事是二人掌政期间概述。

<a id="sgz045-p-002-1"></a>

**[《三国志·邓张宗杨传》裴注 002·1](../../sources/摘录/三国志-卷045-邓张宗杨传裴注.md#pei-002-1)**

> 華陽國志曰芝征涪陵見玄猿緣山芝性好弩手自射猿中之猿抜其箭卷木葉塞其創芝曰嘻吾違物之性其將死矣

**释读** 邓芝征涪陵时射中一只玄猿，见猿自行拔箭，以树叶塞伤，叹自伤物性。

**归年** 本传延熙十一年邓芝讨涪陵，并《后主传》本年；猿事作为该役所附异闻。

### 8. 陆胤为交州刺史，招抚平乱

[返回正文第8条](#sg-event-8)

<a id="sg061-l2935-e8"></a>

**[《三国志·潘濬陆凯传》](../../sources/摘录/三国志-卷061-潘濬陆凯传.md#p003)** · [仓内TXT L2935](../../sources/本地分卷/三国志/三国志-卷061.md#l2935)

> 赤烏十一年，交阯九真夷賊攻沒城邑，交部騷動。以胤為交州刺史、安南校尉。

<a id="sgz061-b-2935-5"></a>

**归年** 同一平乱过程，承248出镇。黄吴为人名。

<a id="sgz061-b-2935-6"></a>

<a id="sgz009-p-029-1"></a>

**[《三国志·诸夏侯曹传》裴注 029·1](../../sources/摘录/三国志-卷009-诸夏侯曹传裴注.md#pei-029-1)**

> 魏末傳曰爽等令勝辭宣王并伺察焉宣王見勝勝自陳無他功勞横䝉時㤙當為本州詣閣拜辭不悟加㤙得䝉引見宣王令兩婢侍邉持衣衣落復上指口言渴求飲婢進粥宣王持盃飲粥粥皆流出沾胸勝愍然為之涕泣謂宣王曰今主上尚幼天下恃賴明公然衆情謂明公方舊風疾發何意尊體乃爾宣王徐更寛言才令氣息相屬説年老沉疾死在旦夕君當屈并州并州近胡好善為之恐不復相見如何勝曰當還忝本州非并州也宣王仍復陽為昏謬曰君方到并州努力自愛錯亂其辭状如荒語勝復曰當忝荆州非并州也

**释读** 曹爽遣李胜告别兼试探。司马懿让两婢扶衣、饮粥故意淌胸，佯称行将不久，故把荆州听成并州。

**归年** 卷009正文 L479明正始九年冬，《通鉴》卷075 L179–194同录。

<a id="sgz009-p-029-2"></a>

**[《三国志·诸夏侯曹传》裴注 029·2](../../sources/摘录/三国志-卷009-诸夏侯曹传裴注.md#pei-029-2)**

> 宣王乃若微悟者謂勝曰懿年老意荒忽不觧君言今還為本州刺史盛徳烈壯好建功勲今當與君别自顧氣力轉微後必不更㑹因欲自力設薄主人生死共别令師昭兄弟結君為友不可相舍去副懿區區之心因流涕哽咽勝亦長歎荅曰輒當承教湏待勅命勝辭出與爽等相見説太傅語言錯悞口不攝盃指南為北乂云吾當作并州吾荅言當還為荆州非并州也徐徐與語冇識人時乃知當還為荆州耳乂欲設主人祖送不可舍去宜湏待之更向爽等垂淚云太傅患不可復濟令人愴然

**释读** 司马懿慢慢假作明白，称送别并令二子结交。李胜回见曹爽等，说司马懿言错手颤、已不能康复。

**归年** 正始九年冬同一次探病。

<a id="sgz009-p-035-29"></a>

**[《三国志·诸夏侯曹传》裴注 035·29](../../sources/摘录/三国志-卷009-诸夏侯曹传裴注.md#pei-035-29)**

> 為尹嵗餘㕔事前屠蘇壊令人更治之小材一枚激墮正撾受符吏石虎頭斷之後旬日遷為荆州刺史

**释读** 李胜任尹一年多，有厅构损坏，修缮时小木击断受符吏石虎之头；十日后，李胜迁荆州刺史。

### 19. 管辂会何晏、邓颺并论《易》

[返回正文第19条](#sgz-event-19)

<a id="sgz029-b-1568-1"></a>

**[《三国志·方技传》仓内原文 L1568](../../sources/本地分卷/三国志/三国志-卷029.md#l1568)**

> 十二月二十八日，吏部尚書何晏請之，鄧颺在晏許。晏謂輅曰：「聞君著爻神妙，試為作一卦，知位當至三公不？」又問：「連夢見青蠅數十頭，來在鼻上，驅之不肯去，有何意故？」輅曰：「夫飛鴞，天下賤鳥，及其在林食椹，則懷我好音，況輅心非草木，敢不盡忠？昔元、凱之弼重華，宣惠慈和，周公之翼成王，坐而待旦，故能流光六合，萬國咸寧。此乃履道休應。非卜筮之所明也。今君侯位重山嶽，勢若雷電，而懷德者鮮，畏威者眾，殆非小心翼翼多福之仁。又鼻者艮，此天中之山，高而不危，所以長守貴也。今青蠅臭惡，而集之焉。位峻者顛，輕豪者亡，不可不思害盈之數，盛衰之期。是故山在地中曰謙，雷在天上曰壯；謙則裒多益寡，壯則非禮不履。未有損己而不光大，行非而不傷敗。原君侯上追文王六爻之旨，下思尼父彖象之義，然後三公可決，青蠅可驅也。」颺曰：「此老生之常譚。」輅答曰：「夫老生者見不生，常譚者見不譚。」晏曰：「過歲更當相見。」輅還邑舍，具以此言語舅氏，舅氏責輅言太切至。輅曰；「與死人語，何所畏邪？」舅大怒，謂輅狂悖。

**归年** 本传正始九年十二月二十八日，《通鉴》卷七十五作丙戌；赴会、告舅同岁。

<a id="sgz029-p-019-1"></a>

**释读** 裴松之说明相书视鼻为天中、鼻象山，语出管辂席间论梦。

**[《三国志·方技传》裴注 020·1](../../sources/摘录/三国志-卷029-方技传裴注.md#pei-020-1)**

> 輅别傳曰輅為何晏所請果共論易九事九事皆明晏曰君論隂陽此世無雙時鄧颺與晏共坐颺言君見謂善易而語初不及易中辭義何故也輅尋聲答之曰夫善易者不論易也晏含笑而讚之可謂要言不煩也因請輅為卦輅既稱引鍳戒晏謝之曰知㡬其神乎古人以為難交疏而吐其誠今人以為難君今一靣而盡二難之道可謂明徳惟馨詩不云乎中心藏之何日忘之

**释读** 管辂与何晏俱论九事、答邓飏“善易者不论易”，又为之卜并作规劝；何晏称赞初交而能吐诚。

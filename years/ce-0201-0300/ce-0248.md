## 本年概述

曹爽遣李勝出任荊州，李勝臨行見司馬懿，被其所示病狀瞞過。郭淮在西邊用兵，蜀將費祎屯漢中，吳以陸胤治理交州。

## 魏廷人事與高平陵事變前情

<a id="sg-event-1"></a>

<a id="sg-event-2"></a>

<a id="sg-event-3"></a>

1. **孙资等退职，魏任高柔为司徒、王凌为司空。** 二月，孙资、刘放先后退职，三月卫臻退职，三人均以列侯归第，位列特进。四月，司空高柔转任司徒，朝廷拟任光禄大夫徐邈为司空。徐邈说三公掌议论国政，坚辞任命。九月，车骑将军王凌接任司空。 [[1]](#sg-note-1)

<a id="sy-event-11"></a>

<a id="sgz-event-14"></a>

2. **司马懿称病骗过李胜，孙礼劝他匡扶魏室。** 清河、平原二郡此前为郡界争执多年。冀州牧孙礼查勘曹叡初封平原王的官图，认定应以王翁河为界。曹爽听信清河一方，拒用官图。孙礼上疏抗辩，反被判五年刑，居家一年方获复用。孙礼受命镇并州、应对鲜卑侵扰，临行见司马懿，说自己落泪是为魏室处境。司马懿劝他忍耐。冬，河南尹李胜改任荆州刺史，临行时去见司马懿。司马懿装作穿不住衣服、喝不进粥，又把荆州反复说成并州。李胜信以为真，回去告诉曹爽等人，司马懿恐怕已病得无法救治。 [[2]](#sy-note-11)

<a id="sgz-event-12"></a>

3. **皇甫谧正始九年冬梦曹爽遇诛。** 皇甫谧梦见洛阳宗庙车骑称诛曹爽；同乡不信，以曹爽握兵为据，皇甫谧用东汉阎显事比有兵也不能免。 [[3]](#sgz-note-12)

<a id="sy-event-9"></a>

4. **管辂被举为秀才。** 十月，管辂被举为秀才。辞行时裴徽提醒他，到洛阳后何晏可能问《易》，管辂和裴徽谈及如何论《易》，并说来年岁首可能刮起大风。 [[4]](#sy-note-9)

<a id="sgz-event-19"></a>

5. **何晏请管辂论《易》。** 十二月二十八日，何晏请管辂论《易》，问自己能否位至三公，并请他解青蝇聚在鼻上的梦。管辂以周公辅政和《易》的谦、壮两卦劝何晏谦谨守礼。邓颺说这是老生常谈，何晏约来年再会。管辂回去告知舅父，舅父责他话说得太直。 [[5]](#sgz-note-19)

<a id="sy-event-10"></a>

6. **曹寻去世，封国撤除。** 曹寻去世，无子承袭，封国撤除。 [[6]](#sy-note-10)

<a id="sg-event-4"></a>

7. **大风发屋折树。** 冬十月，大风发屋折树。 [[7]](#sg-note-4)

## 魏蜀邊事與漢中

<a id="sg-event-5"></a>

8. **郭淮破遮塞、治无戴，进军牵制姜维。** 蛾遮塞等据白土城一带拒守。郭淮佯作从上游进兵，实际从下游渡河夺城，击破羌军。治无戴围武威，郭淮趋西海欲截其辎重，两军在龙夷以北交战，治无戴败走。郭淮回师途中又击破在石头山截断官道的令居部。姜维西去接应治无戴，留下廖化筑城。郭淮分兵，让夏侯霸追姜维，自己攻廖化，姜维被迫回援。郭淮进封都乡侯。 [[8]](#sg-note-5)

<a id="sg-event-6"></a>

9. **费祎屯汉中，邓芝讨涪陵。** 五月，大将军费祎出屯汉中。秋，涪陵属国居民起事，杀了都尉，车骑将军邓芝率军击败起事者，斩其首领。 《华阳国志》还将邓芝射猿后悔的故事附在此次征讨下，另有射中母猿、幼猿为之拔箭塞伤的异说；这里只按原书记作故事，不以“自知当死”推算其卒年。 [[9]](#sg-note-6)

<a id="sgz-event-13"></a>

10. **王平去世。** 王平去世，儿子王训承袭。 [[10]](#sgz-note-13)

## 吳治交州與朝廷紀事

<a id="sg-event-8"></a>

12. **陆胤为交州刺史，招抚平乱。** 交阯、九真多处城邑被攻占。孙权任衡阳督军都尉陆胤为交州刺史、安南校尉。陆胤以恩信招抚，高凉首领黄吴等率部三千余家先降。陆胤再往南招抚，以财帛相赠，先后有百余名首领、五万余户归附。交州逐渐安定，陆胤后来就地加安南将军。 [[12]](#sg-note-8)

### 2. 司马懿称病骗过李胜，孙礼劝他匡扶魏室

[返回正文第2条](#sy-event-11)

**《諸夏侯曹傳》互見** [TXT 第132行第3段](../../拆分史书/三国志/卷009.md#edition-wei009-l132-3) · [TXT 第134行第3段](../../拆分史书/三国志/卷009.md#edition-wei009-l134-3) · [TXT 第134行第6段](../../拆分史书/三国志/卷009.md#edition-wei009-l134-6) · [TXT 第138行第1段](../../拆分史书/三国志/卷009.md#edition-wei009-l138-1) · [TXT 第150行第26段](../../拆分史书/三国志/卷009.md#edition-wei009-l150-26) · [TXT 第150行第28段](../../拆分史书/三国志/卷009.md#edition-wei009-l150-28) · [TXT 第185行第7段](../../拆分史书/三国志/卷009.md#edition-wei009-l185-7)

<a id="wei024-l94-2"></a>

<a id="wei024-l96-1"></a>

**[《三國志·韓崔高孫王傳》](../../拆分史书/三国志/卷024.md#edition-wei024-l94-2)** · [TXT L94](../../拆分史书/三国志/卷024.txt#L94) · [TXT L96](../../拆分史书/三国志/卷024.txt#L96)

> 太傅司馬宣王謂禮曰：「今清河、平原爭界八年，更二刺史，靡能決之；虞、芮待文王而了，宜善令分明。」禮曰：「訟者據墟墓爲驗，聽者以先老爲正，而老者不可加以榎楚，又墟墓或遷就高敞，或徙避仇讎。如今所聞，雖臯陶猶將爲難。若欲使必也無訟，當以烈祖初封平原時圖決之。何必推古問故，以益辭訟？昔成王以桐葉戲叔虞，周公便以封之。今圖藏在天府，便可於坐上斷也，豈待到州乎？」宣王曰：「是也。當別下圖。」禮到，案圖宜屬平原。而曹爽信清河言，下書云：「圖不可用，當參異同。」禮上疏曰：「管仲霸者之佐，其器又小，猶能奪伯氏駢邑，使沒齒無怨言。臣受牧伯之任，奉聖朝明圖，驗地著之界，界實以王翁河爲限；而鄃以馬丹候爲驗，詐以鳴犢河爲界。假虛訟訴，疑誤臺閣。竊聞衆口鑠金，浮石沈木，三人成巿虎，慈母投其杼。今二郡爭界八年，一朝決之者，緣有解書圖畫，可得尋案擿校也。平原在兩河，向東上，其閒有爵隄，爵隄在高唐西南，所爭地在高唐西北，相去二十餘里，可謂長歎息流涕者也。案解與圖奏而鄃不受詔，此臣軟弱不勝其任，臣亦何顏尸祿素餐。」輒束帶著履，駕車待放。爽見禮奏，大怒。劾禮怨望，結刑五歲。在家期年，衆人多以爲言，除城門校尉。
>
> 時匈奴王劉靖部衆彊盛，而鮮卑數寇邊，乃以禮爲并州刺史，加振武將軍，使持節，護匈奴中郎將。往見太傅司馬宣王，有忿色而無言。宣王曰：「卿得并州，少邪？恚理分界失分乎？今當遠別，何不懽也！」禮曰：「何明公言之乖細也！禮雖不德，豈以官位往事爲意邪？本謂明公齊蹤伊、呂，匡輔魏室，上報明帝之託，下建萬世之勳。今社稷將危，天下兇兇，此禮之所以不恱也。」因涕泣橫流。宣王曰：「且止，忍不可忍。」

**釋讀與歸年** 清河、平原爭界八年。孫禮主張按曹叡初封平原王的官圖判定，以王翁河為界。曹爽採信清河之說，駁官圖；孫禮上疏自辯，反被劾怨望、判五年刑，在家一年後復起。原文完整諫疏和問答皆為赴并州前因，《資治通鑑》於正始九年回敘，分界、定罪實在復起前，具體年不硬定。[《通鑑》卷七十五](../../史书/025-资治通鉴/KR2b0007_075.txt#L169-L183)。

**釋讀與歸年** 因劉靖部強、鮮卑頻擾，孫禮奉命持節鎮并州。臨行見司馬懿，哭言朝廷危急，所憂在魏室，非為疆界案受屈或所授官不足，司馬懿曰「且止，忍不可忍」。與清河平原案的回敘及司馬懿此前伺機的事件同條。[《通鑑》卷七十五](../../史书/025-资治通鉴/KR2b0007_075.txt#L170-L193)。

**[《三國志·方技傳》](../../拆分史书/三国志/卷029.md#edition-wei029-l122-1)** · [TXT L122](../../拆分史书/三国志/卷029.txt#L122) · [TXT L123（裴注）](../../拆分史书/三国志/卷029.txt#L123) · [TXT L124](../../拆分史书/三国志/卷029.txt#L124) · [TXT L125（裴注）](../../拆分史书/三国志/卷029.txt#L125) · [TXT L126](../../拆分史书/三国志/卷029.txt#L126)

> 十二月二十八日，吏部尚書何晏請之，鄧颺在晏許。晏謂輅曰：「聞君著爻神妙，試爲作一卦，知位當至三公不？」又問：「連夢見青蠅數十頭，來在鼻上，驅之不肯去，有何意故？」輅曰：「夫飛鴞，天下賤鳥，及其在林食椹，則懷我好音，況輅心非草木，敢不盡忠？昔元、凱之弼重華，宣慈惠和，周公之翼成王，坐而待旦，故能流光六合，萬國咸寧。此乃履道休應。非卜筮之所明也。今君侯位重山嶽，勢若雷電，而懷德者鮮，畏威者衆，殆非小心翼翼多福之仁。又鼻者艮，此天中之山，
>
> **〔裴注〕**
> 臣松之案：相書謂鼻之所在爲天中。鼻有山象，故曰：「天中之山」也。
>
> **〔正文續〕**
> 高而不危，所以長守貴。今青蠅臭惡，而集之焉。位峻者顛，輕豪者亡，不可不思害盈之數，盛衰之期。是故山在地中曰謙，雷在天上曰壯；謙則襃多益寡，壯則非禮不履。未有損己而不光大，行非而不傷敗。願君侯上追文王六爻之旨，下思尼父彖象之義，然後三公可決，青蠅可驅也。」颺曰：「此老生之常譚。」輅荅曰：「夫老生者見不生，常譚者見不譚。」晏曰：「過歲更當相見。」
>
> **〔裴注〕**
> 輅別傳曰：輅爲何晏所請，果共論易九事，九事皆明。晏曰：「君論陰陽，此世無雙。」時鄧颺與晏共坐，颺言：「君見謂善易，而語初不及易中辭義，何故也？」輅尋聲荅之曰：「夫善易者不論易也。」晏含笑而讚之「可謂要言不煩也」。因請輅爲卦。輅旣稱引鑒誡，晏謝之曰：「知機其神乎，古人以爲難；交疏而吐其誠，今人以爲難。君今一靣而盡二難之道，可謂明德惟馨。詩不云乎，『中心藏之，何日忘之』！」
>
> **〔正文續〕**
> 輅還邑舍，具以此言語舅氏，舅氏責輅言太切至。輅曰；「與死人語，何所畏邪？」舅大怒，謂輅狂悖。

**釋讀與歸年** 正始九年十二月二十八，何晏與鄧颺在座，問能否至三公及夢見青蠅之意。管輅援古勸其以德守位。以卷內正始九年紀年及次年歲朝定本次問答；[《資治通鑑》卷七十五](../../史书/025-资治通鉴/KR2b0007_075.txt#L195-L216)繫十二月丙戌。

**釋讀與歸年** 裴松之引相書釋鼻為「天中」，說明原話的山象，夾注依原位置保留。

**釋讀與歸年** 管輅引謙、壯二卦和文王、孔子義理再勸何晏，鄧颺以「老生」譏他，何晏稱過歲再會。

**釋讀與歸年** 《輅別傳》補本次會見論《易》九事、鄧颺發難及何晏稱許；整段引語照錄。

> 九年，遮塞等屯河關、白土故城，據河拒軍。淮見形上流，密於下渡兵據白土城，擊，大破之。治無戴圍武威，家屬留在西海。淮進軍趨西海，欲掩取其累重，會無戴折還，與戰於龍夷之北，破走之。令居惡虜在石頭山之西，當大道止，斷絕王使。淮還過討，大破之。姜維出石營，從彊川，乃西迎治無戴，留陰平太守廖化於成重山築城，斂破羌保質。淮欲分兵取之。諸將以維衆西接彊胡，化以據險，分軍兩持，兵勢轉弱，進不制維，退不拔化，非計也，不如合而俱西，及胡、蜀未接，絕其內外，此伐交之兵也。淮曰：「今往取化，出賊不意，維必狼顧。比維自致，足以定化，且使維疲於奔命。兵不遠西，而胡交自離，此一舉而兩全之策也。」乃別遣夏侯霸等追維於沓中，淮自率諸軍就攻化等。維果馳還救化，皆如淮計。進封都鄉侯。

**釋讀與歸年** 正始九年，郭淮佯作上流進兵，實從下流渡河據白土城，破蛾遮塞諸部。又在龍夷以北擊退治無戴，路過石頭山討令居截道者。姜維往西接應治無戴，留廖化守成重山；郭淮令夏侯霸追姜維，自己攻廖化，姜維遂回援。因功郭淮進都鄉侯。

**[《三國志·鄧張宗楊傳》注文](../../拆分史书/三国志/卷045.md#edition-shu045-l10-1)** · [TXT L10](../../拆分史书/三国志/卷045.txt#L10)

> **〔裴注〕**
>
> 華陽國志曰：芝征涪陵，見玄猿緣山。芝性好弩，手自射猿，中之。猿拔其箭，卷木葉塞其創。芝曰：「嘻，吾違物之性，其將死矣！」　一曰：芝見猿抱子在樹上，引弩射之，中猿母，其子爲拔箭，以木葉塞創。芝乃歎息，投弩水中，自知當死。

**释读** 《华阳国志》记，邓芝征涪陵时看见黑猿攀山。他喜爱用弩，亲自射中一猿；猿拔出箭，又卷起树叶堵住伤口。邓芝感叹，自己违逆了生物的天性，恐怕将要死去。另一种说法是，他看见母猿抱着幼猿在树上，射中了母猿，幼猿替母亲拔箭、用树叶堵伤；邓芝因而叹息，把弩投入水中，觉得自己将死。两说中拔箭塞伤的主体不同，第二说还多出投弩入水的情节。

**归年与互校** 裴注第一说明确以“芝征涪陵”为背景，随正文248年讨涪陵之事附列；第二说是同一故事的异文，并没有另载日期。“将死”“自知当死”是故事中的邓芝感想，不能解释为248年即死，也不能当作射猿造成其死亡的证据；正文另明记251年卒。

### 12. 陆胤为交州刺史，招抚平乱

[返回正文第12条](#sg-event-8)

<a id="sg061-l2935-e8"></a>

<a id="sgz061-b-2935-5"></a>

<a id="sgz061-b-2935-6"></a>

<a id="wu061-l110-2"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l110-2)** · [TXT L110](../../拆分史书/三国志/卷061.txt#L110)

> 赤烏十一年，交阯九真夷賊攻沒城邑，交部搔動。以胤爲交州刺史、安南校尉。胤入南界，喻以恩信，務崇招納，高涼渠帥黃吳等支黨三千餘家皆出降。引軍而南，重宣至誠，遺以財幣。賊帥百餘人，民五萬餘家，深幽不羈，莫不稽顙，交域清泰。就加安南將軍。

**釋讀** 赤烏十一年，交阯、九真一帶的武裝攻陷城邑，交州各地受到搖動。孫權任陸胤為交州刺史、安南校尉。陸胤入南境，以恩信開導招納，高涼首領黃吳等所部三千餘家出降。他又領軍南下，表明誠意並贈予財幣，百餘名首領、五萬餘戶久居深僻而不受約束的民眾亦歸服，交州平定。陸胤隨後在任上加安南將軍。

**歸年** 本傳明記赤烏十一年（248）出任與平亂的開端，《資治通鑑》卷075亦於該年敘交阯、九真起事及陸胤招降五萬餘家；下文招撫與就任加官事相承，未另記各事確月及加官確年。

**趙嫗異說** 《太平御覽》卷六百九十八引劉欣期《交州記》，載九真女子趙嫗聚眾，未記年份與陸胤。《大越史記全書》外紀卷四在戊辰條記陸胤（其傳本作陵胤）招降，續說趙嫗攻郡而為胤所平。戊辰與248年相符，該書所附「吳永安元年」則為258年，與干支不合。《欽定越史通鑑綱目》前編卷三改列赤烏十一年，明將二事合敘。〈陸胤傳〉未稱趙嫗之名。

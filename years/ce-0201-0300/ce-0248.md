## 本年概述

曹爽遣李勝出任荊州，李勝臨行見司馬懿，被其所示病狀瞞過。郭淮在西邊用兵，蜀將費祎屯漢中，吳以陸胤治理交州。

## 魏廷人事與高平陵事變前情

<a id="sg-event-1"></a>

<a id="sg-event-2"></a>

<a id="sg-event-3"></a>

1. **孙资等退职，魏任高柔为司徒、王凌为司空。** 二月，孙资、刘放先后退职，三月卫臻退职，三人均以列侯归第，位列特进。四月，司空高柔转任司徒，光禄大夫徐邈辞任司空。九月，车骑将军王凌接任司空。 [[1]](#sg-note-1)

<a id="sy-event-11"></a>

<a id="sgz-event-14"></a>

2. **司马懿称病骗过李胜，孙礼劝他匡扶魏室。** 李胜将赴荆州，临行去见司马懿。司马懿故意装作病重耳背，李胜据此向曹爽报告。孙礼临行另见司马懿，为任事受屈而落泪，劝他匡扶魏室。 [[2]](#sy-note-11)

<a id="sgz-event-12"></a>

3. **皇甫谧正始九年冬梦曹爽遇诛。** 皇甫谧梦见洛阳宗庙车骑称诛曹爽；同乡不信，以曹爽握兵为据，皇甫谧用东汉阎显事比有兵也不能免。 [[3]](#sgz-note-12)

<a id="sy-event-9"></a>

4. **管辂被举为秀才。** 管辂被察举为秀才。 [[4]](#sy-note-9)

<a id="sgz-event-19"></a>

5. **管辂会何晏、邓颺并论《易》。** 何晏问能否位至三公及青蝇集鼻的梦，管辂以周公辅政与《易》谦、壮两卦劝少自盈；邓颺不接受。管辂归告舅父，舅责他言太直。 [[5]](#sgz-note-19)

<a id="sy-event-10"></a>

6. **曹寻去世，封国撤除。** 曹寻去世，无子承袭，封国撤除。 [[6]](#sy-note-10)

<a id="sg-event-4"></a>

7. **大风发屋折树。** 冬十月，大风发屋折树。 [[7]](#sg-note-4)

## 魏蜀邊事與漢中

<a id="sg-event-5"></a>

8. **郭淮击遮塞、治无戴。** 郭淮以白土城渡河作战，败诸羌；再击败治无戴并转攻廖化，牵制姜维。 [[8]](#sg-note-5)

<a id="sg-event-6"></a>

9. **费祎屯汉中，邓芝讨涪陵。** 费祎五月屯汉中；秋涪陵属国起事，邓芝平之。 [[9]](#sg-note-6)

<a id="sgz-event-13"></a>

10. **王平去世。** 王平去世，儿子王训承袭。 [[10]](#sgz-note-13)

## 吳治交州與朝廷紀事

<a id="sg-event-7"></a>

11. **朱然筑江陵城。** 赤乌十一年春正月，朱然修筑江陵城。 [[11]](#sg-note-7)

<a id="sg-event-8"></a>

12. **陆胤为交州刺史，招抚平乱。** 交阯、九真多处城邑被攻占。孙权任衡阳督军都尉陆胤为交州刺史、安南校尉。陆胤以恩信招抚，高凉首领黄吴等率部三千余家先降。陆胤再往南招抚，以财帛相赠，先后有百余名首领、五万余户归附。交州逐渐安定，陆胤后来就地加安南将军。 [[12]](#sg-note-8)

<a id="sgz-event-15"></a>

<a id="sgz-event-18"></a>

13. **吴地震，孙权诏群臣陈政失。** 赤乌十一年二月地震，孙权以地震自责，诏群臣直陈政事过失。 [[13]](#sgz-note-15)

<a id="sgz-event-20"></a>

14. **吴太初宫建成。** 赤乌十一年三月，太初宫建成。上年三月起建，见[247年第13条](ce-0247.md#sgz047-b-2326-3)。 [[14]](#sgz-note-20)

<a id="sgz-event-16"></a>

15. **吴报雹及云阳黄龙。** 四月雨雹，云阳报告黄龙。 [[15]](#sgz-note-16)

<a id="sgz-event-17"></a>

16. **鄱阳报白虎、孙权诏论祥瑞。** 五月鄱阳报白虎仁，孙权诏引古代积善获祥瑞及《尚书》自勉，要求官员勤职辅正。 [[16]](#sgz-note-17)

### 2. 司马懿称病骗过李胜，孙礼劝他匡扶魏室

**[《三国志·诸夏侯曹传》](../../拆分史书/三国志/卷009.md#p007)** · [仓内TXT L479](../../拆分史书/三国志/卷009.md#l479)

**归年与互校** 《曹爽传》明系正始九年冬，次年高平陵之变另见249年。

<a id="sgz009-p-029-1"></a>

**[《三国志·诸夏侯曹传》裴注 029·1](../../拆分史书/三国志/卷009.md#pei-029-1)**

> 魏末傳曰爽等令勝辭宣王并伺察焉宣王見勝勝自陳無他功勞横䝉時㤙當為本州詣閣拜辭不悟加㤙得䝉引見宣王令兩婢侍邉持衣衣落復上指口言渴求飲婢進粥宣王持盃飲粥粥皆流出沾胸勝愍然為之涕泣謂宣王曰今主上尚幼天下恃賴明公然衆情謂明公方舊風疾發何意尊體乃爾宣王徐更寛言才令氣息相屬説年老沉疾死在旦夕君當屈并州并州近胡好善為之恐不復相見如何勝曰當還忝本州非并州也宣王仍復陽為昏謬曰君方到并州努力自愛錯亂其辭状如荒語勝復曰當忝荆州非并州也

**释读** 曹爽遣李胜告别兼试探。司马懿让两婢扶衣、饮粥故意淌胸，佯称行将不久，故把荆州听成并州。

**归年** 卷009正文 L479明正始九年冬，《通鉴》卷075 L179–194同录。

<a id="sgz009-p-029-2"></a>

**[《三国志·诸夏侯曹传》裴注 029·2](../../拆分史书/三国志/卷009.md#pei-029-2)**

> 宣王乃若微悟者謂勝曰懿年老意荒忽不觧君言今還為本州刺史盛徳烈壯好建功勲今當與君别自顧氣力轉微後必不更㑹因欲自力設薄主人生死共别令師昭兄弟結君為友不可相舍去副懿區區之心因流涕哽咽勝亦長歎荅曰輒當承教湏待勅命勝辭出與爽等相見説太傅語言錯悞口不攝盃指南為北乂云吾當作并州吾荅言當還為荆州非并州也徐徐與語冇識人時乃知當還為荆州耳乂欲設主人祖送不可舍去宜湏待之更向爽等垂淚云太傅患不可復濟令人愴然

**释读** 司马懿慢慢假作明白，称送别并令二子结交。李胜回见曹爽等，说司马懿言错手颤、已不能康复。

**归年** 正始九年冬同一次探病。

<a id="sgz009-p-035-29"></a>

**[《三国志·诸夏侯曹传》裴注 035·29](../../拆分史书/三国志/卷009.md#pei-035-29)**

> 為尹嵗餘㕔事前屠蘇壊令人更治之小材一枚激墮正撾受符吏石虎頭斷之後旬日遷為荆州刺史

**释读** 李胜任尹一年多，有厅构损坏，修缮时小木击断受符吏石虎之头；十日后，李胜迁荆州刺史。

**归年** 本传明正始九年冬出为荆州，注文明确此前十日。

> 至十月舉為秀才輅辭裴使君使君言丁鄧二尚書有經國才略於物理不精也何尚書神明精㣲言皆巧妙巧妙之志殆破秋毫君當慎之自言不解易九事必當以相問比至洛宜善精其理也

**释读** 《别传》补十月；临辞时裴徽以丁、邓和何晏才具提醒管辂到洛阳可能被问《易》九事。

> 輅言何若巧妙以攻難之才游形之表未入於神夫入神者當歩天元推隂陽探玄虚極幽明然後覧道無窮未暇細言若欲差次老荘而參爻象愛㣲辯而興浮藻可謂射侯之巧非能破秋毫之妙也若九事皆至義者不足勞思也若隂陽者精之已乆輅去之後嵗朝當有時刑大風風必摧破樹木若發於乾者必有天威不足共清譚者

**释读** 认为何晏巧言不等于通神；说出次年岁首或有西北大风的预言。

**归年** 离裴徽赴洛见何晏前；预测所指次年不能作为这段谈话发生年。

> 十二月二十八日，吏部尚書何晏請之，鄧颺在晏許。晏謂輅曰：「聞君著爻神妙，試為作一卦，知位當至三公不？」又問：「連夢見青蠅數十頭，來在鼻上，驅之不肯去，有何意故？」輅曰：「夫飛鴞，天下賤鳥，及其在林食椹，則懷我好音，況輅心非草木，敢不盡忠？昔元、凱之弼重華，宣惠慈和，周公之翼成王，坐而待旦，故能流光六合，萬國咸寧。此乃履道休應。非卜筮之所明也。今君侯位重山嶽，勢若雷電，而懷德者鮮，畏威者眾，殆非小心翼翼多福之仁。又鼻者艮，此天中之山，高而不危，所以長守貴也。今青蠅臭惡，而集之焉。位峻者顛，輕豪者亡，不可不思害盈之數，盛衰之期。是故山在地中曰謙，雷在天上曰壯；謙則裒多益寡，壯則非禮不履。未有損己而不光大，行非而不傷敗。原君侯上追文王六爻之旨，下思尼父彖象之義，然後三公可決，青蠅可驅也。」颺曰：「此老生之常譚。」輅答曰：「夫老生者見不生，常譚者見不譚。」晏曰：「過歲更當相見。」輅還邑舍，具以此言語舅氏，舅氏責輅言太切至。輅曰；「與死人語，何所畏邪？」舅大怒，謂輅狂悖。

**归年** 本传正始九年十二月二十八日，《通鉴》卷七十五作丙戌；赴会、告舅同岁。

> 姜維出石營，從彊川，乃西迎治無戴，留陰平太守廖化於成重山築城，斂破羌保質。淮欲分兵取之。諸將以維衆西接彊胡，化以據險，分軍兩持，兵勢轉弱，進不制維，退不拔化，非計也，不如合而俱西，及胡、蜀未接，絕其內外，此伐交之兵也。淮曰：「今往取化，出賊不意，維必狼顧。比維自致，足以定化，且使維疲於奔命。兵不遠西，而胡交自離，此一舉而兩全之策也。」乃別遣夏侯霸等追維於沓中，淮自率諸軍就攻化等。維果馳還救化，皆如淮計。進封都鄉侯。

### 12. 陆胤为交州刺史，招抚平乱

[返回正文第12条](#sg-event-8)

<a id="sg061-l2935-e8"></a>

<a id="sgz061-b-2935-5"></a>

<a id="sgz061-b-2935-6"></a>

<a id="wu061-l110-2"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l110-2)** · [TXT L110](../../拆分史书/三国志/卷061.txt#L110)

> 赤烏十一年，交阯九真夷賊攻沒城邑，交部搔動。以胤爲交州刺史、安南校尉。胤入南界，喻以恩信，務崇招納，高涼渠帥黃吳等支黨三千餘家皆出降。引軍而南，重宣至誠，遺以財幣。賊帥百餘人，民五萬餘家，深幽不羈，莫不稽顙，交域清泰。就加安南將軍。

**釋讀** 赤烏十一年，交阯、九真一帶的武裝攻陷城邑，交州各地受到搖動。孫權任陸胤為交州刺史、安南校尉。陸胤入南境，以恩信開導招納，高涼首領黃吳等所部三千餘家出降。他又領軍南下，表明誠意並贈予財幣，百餘名首領、五萬餘戶久居深僻而不受約束的民眾亦歸服，交州平定。陸胤隨後在任上加安南將軍。

**歸年** 本傳明記赤烏十一年（248）出任與平亂的開端，《資治通鑑》卷075亦於該年敘交阯、九真起事及陸胤招降五萬餘家；下文招撫與就任加官事相承，未另記各事確月及加官確年。

**趙嫗異說** 《太平御覽》卷六百九十八引劉欣期《交州記》，載九真女子趙嫗聚眾，未記年份與陸胤。《大越史記全書》外紀卷四在戊辰條記陸胤（其傳本作陵胤）招降，續說趙嫗攻郡而為胤所平。戊辰與248年相符，該書所附「吳永安元年」則為258年，與干支不合。《欽定越史通鑑綱目》前編卷三改列赤烏十一年，明將二事合敘。〈陸胤傳〉未稱趙嫗之名。

1. **高平陵政变与曹爽被诛。** 司马懿趁曹芳等出谒高平陵，奏免曹爽兄弟。朝廷审问黄门张当后，以谋逆诛灭曹爽集团。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **大赦。** 丙午，大赦。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **以太傅司马宣王为丞相。** 丁未，以太傅司马宣王为丞相，固让乃止。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **改年。** 夏四月乙丑，改年。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **太尉蒋济薨。** 丙子，太尉蒋济去世。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **以司空王淩为太尉。** 冬十二月辛卯，以司空王淩为太尉。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **以司隷校尉孙礼为司空。** 庚子，以司隷校尉孙礼为司空。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **王凌与令狐愚谋立楚王曹彪。** 王凌、令狐愚商议使楚王曹彪在许昌继位。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **姜维出雍州。** 姜维出攻雍州未克，句安和李韶归魏。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **马忠去世。** 马忠延熙十二年去世，南中民为立庙。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **吴左大司马朱然去世。** 三月朱然卒。四月任朱据领丞相。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **全琮去世异年。** 全琮本传记其于赤乌十二年去世，子全怿继其爵与军业。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **迁征西将军，都督雍、凉诸军事。** 嘉平元年，迁征西将军，都督雍、凉诸军事。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

> 嘉平元年春正月甲午，車駕謁高平陵。太傅司馬宣王奏免大將軍曹爽、爽弟中領軍羲、武衞將軍訓、散騎常侍彥官，以侯就第。戊戌，有司奏収黃門張當付廷尉，考實其辭，爽與謀不軌。又尚書丁謐、鄧颺、何晏、司隷校尉畢軌、荊州刺史李勝、大司農桓範皆與爽通姦謀，夷三族。

**[《三国志·诸夏侯曹传》](../../sources/摘录/三国志-卷009-诸夏侯曹传.md#p007)** · [仓内TXT L480](../../sources/本地分卷/三国志/三国志-卷009.md#L480)

> 十年正月，車駕朝高平陵，爽兄弟皆從。宣王部勒兵馬，先據武庫，遂出屯洛水浮橋。

**归年与互校** 本传以正始十年年首系同一年事，《齐王纪》作嘉平元年春。

**[《三国志·韩崔高孙王传》](../../sources/摘录/三国志-卷024-韩崔高孙王传.md#p003)** · [仓内TXT L1304](../../sources/本地分卷/三国志/三国志-卷024.md#L1304)

<a id="sg033-l1709-e1"></a>

**[《三国志·后主传》](../../sources/摘录/三国志-卷033-后主传.md#p005)** · [仓内TXT L1709](../../sources/本地分卷/三国志/三国志-卷033.md#L1709)

> 十二年春正月，魏誅大將軍曹爽等，右將軍夏侯霸來降。

<a id="sgz004-b-228-1"></a>

**[《三国志·三少帝纪》仓内原文 L228](../../sources/本地分卷/三国志/三国志-卷004.md#l228)**

> 嘉平元年春正月甲午，車駕謁高平陵。太傅司馬宣王奏免大將軍曹爽、爽弟中領軍羲、武衞將軍訓、散騎常侍彥官，以侯就第。

**释读** 曹芳一行去谒高平陵，司马懿奏免曹爽及其弟曹羲、曹训、曹彦等职，令按侯爵归家。

**归年** 嘉平元年正月甲午；四月才改元，本条追称嘉平。

<a id="sgz004-b-228-2"></a>

**[《三国志·三少帝纪》仓内原文 L228](../../sources/本地分卷/三国志/三国志-卷004.md#l228)**

> 戊戌，有司奏収黃門張當付廷尉，考實其辭，爽與謀不軌。又尚書丁謐、鄧颺、何晏、司隷校尉畢軌、荊州刺史李勝、大司農桓範皆與爽通姦謀，夷三族。語在《爽傳》。

**释读** 黄门张当交廷尉讯问；曹爽等被指谋逆，曹爽党属何晏、丁谧、邓飏等被夷三族。

**归年** 嘉平元年正月戊戌，参《曹爽传》；卷内“彥官”保留，前段实为爽弟散骑常侍曹彦，后段另为尚书何晏。

<a id="sgz004-p-006-1"></a>

**[《三国志·三少帝纪》裴注 006·1](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-006-1)**

> 孫盛魏世籍曰髙平陵在洛水南大石山去洛城九十里

**释读** 孙盛记高平陵在洛水南大石山，离洛城九十里。

**归年** 地理注附249年谒陵条，不另立营陵纪年。

### 3. 以太傅司马宣王为丞相

[返回正文第3条](#sg-event-3)

<a id="sg004-l228-e3"></a>

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p003)** · [仓内TXT L228](../../sources/本地分卷/三国志/三国志-卷004.md#l228)

> 丁未，以太傅司馬宣王為丞相，固讓乃止。

<a id="sgz004-p-007-1"></a>

**[《三国志·三少帝纪》裴注 007·1](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-007-1)**

> 孔衍漢魏春秋曰詔使太常王肅册命太傅為丞相増邑萬户羣臣奏事不得稱名如漢霍光故事太傅上書辭讓曰臣親受顧命憂深責重慿賴天威摧弊姦凶贖罪為幸功不足論又三公之官聖王所制著之典禮至於丞相始自秦政漢氏因之無復變改今三公之官皆備横復寵臣違越先典革聖明之經襲秦漢之路雖在異人臣所宜正况當臣身而不固爭四方議者將謂臣何書十餘上詔乃許之

**释读** 《汉魏春秋》说太常王肃奉册，拟增食邑万户并享奏事不名；司马懿上书自称只依天威除弊，并以秦汉丞相官制为由多次辞谢，获准。

**归年** 嘉平元年正月，以本纪丁未为任命日期。

<a id="sgz004-p-007-2"></a>

**[《三国志·三少帝纪》裴注 007·2](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-007-2)**

> 復加九錫之禮太傅又言太祖有大功大德漢氏崇重故加九錫此乃歴代異事非後代之君臣所得議也又辭不受

**释读** 司马懿称曹操受九锡有特殊历史条件，自己不能比，拒受九锡。

**归年** 同一政变后册礼与辞让，《晋书·宣帝纪》亦系本年。

<a id="sy-sg056-l2689-e11"></a>

**[《三国志·朱治朱然吕范朱桓传》](../../sources/摘录/三国志-卷056-朱治朱然吕范朱桓传.md#p002)** · [仓内TXT L2689](../../sources/本地分卷/三国志/三国志-卷056.md#L2689)

> 寢疾二年，後漸增篤，權晝為減膳。夜為不寐，中使醫藥口食之物，相望於道。然每遣使表疾病消息，權輒召見，口自問訊。入賜酒食，出送布帛。自創業功臣疾病，權意之所鐘，呂蒙、淩統最重，然其次矣。年六十八，赤烏十二年卒，權素服舉哀，為之感慟。子績嗣。

**本段所记** 朱然病重，孙权屡遣使探问，病死后为其着丧服举哀，朱绩承袭。

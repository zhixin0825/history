<a id="sg-event-4"></a>

4. **改年。** 夏四月乙丑，改年。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **太尉蒋济薨。** 丙子，太尉蒋济去世。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **以司空王淩为太尉。** 冬十二月辛卯，以司空王淩为太尉。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **以司隷校尉孙礼为司空。** 庚子，以司隷校尉孙礼为司空。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **王凌与令狐愚谋立楚王曹彪。** 王凌、令狐愚商议使楚王曹彪在许昌继位。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **姜维出雍州。** 姜维出攻雍州未克，句安和李韶归魏。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **马忠去世。** 马忠延熙十二年去世，南中民为立庙。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **吴左大司马朱然去世。** 三月朱然卒。四月任朱据领丞相。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **全琮去世异年。** 全琮本传记其于赤乌十二年去世，子全怿继其爵与军业。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

<a id="sg-event-14"></a>

14. **与征西将军郭淮拒蜀偏将军姜维。** 嘉平元年，与征西将军郭淮拒蜀偏将军姜维。 [[14]](#sg-note-14)

<a id="sgz-event-15"></a>

15. **魏右将军夏侯霸来降蜀。** 夏侯霸在曹爽被诛后逃入蜀境归降。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **蜀汉四月大赦。** 蜀汉于四月大赦。 [[16]](#sgz-note-16)

<a id="sgz-event-17"></a>

<a id="sgz-event-18"></a>

18. **郭淮迁征西将军、都督雍凉。** 魏授郭淮征西将军，督雍凉诸军事。 [[18]](#sgz-note-18)

<a id="sgz-event-19"></a>

19. **徐邈以光禄大夫卒，按公礼葬。** 徐邈在家去世，七十八岁，谥穆侯，子徐武嗣。 [[19]](#sgz-note-19)

<a id="sgz-event-20"></a>

20. **王昶陈治国五策。** 主张崇学抑浮、考试核实、官员久任、俭约并给予实禄、杜绝奢靡。 [[20]](#sgz-note-20)

> 十二年春正月，魏誅大將軍曹爽等，右將軍夏侯霸來降。

<a id="sgz004-b-228-1"></a>

**[《三国志·三少帝纪》仓内原文 L228](../../sources/本地分卷/三国志/三国志-卷004.md#l228)**

> 嘉平元年春正月甲午，車駕謁高平陵。太傅司馬宣王奏免大將軍曹爽、爽弟中領軍羲、武衞將軍訓、散騎常侍彥官，以侯就第。

**释读** 曹芳一行去谒高平陵，司马懿奏免曹爽及其弟曹羲、曹训、曹彦等职，令按侯爵归家。

**归年** 嘉平元年正月甲午；四月才改元，本条追称嘉平。

<a id="sgz004-b-228-2"></a>

**[《三国志·三少帝纪》仓内原文 L228](../../sources/本地分卷/三国志/三国志-卷004.md#l228)**

> 戊戌，有司奏収黃門張當付廷尉，考實其辭，爽與謀不軌。又尚書丁謐、鄧颺、何晏、司隷校尉畢軌、荊州刺史李勝、大司農桓範皆與爽通姦謀，夷三族。語在《爽傳》。

**释读** 黄门张当交廷尉讯问；曹爽等被指谋逆，曹爽党属何晏、丁谧、邓飏等被夷三族。

**归年** 嘉平元年正月戊戌，参《曹爽传》；卷内“彥官”保留，前段实为爽弟散骑常侍曹彦，后段另为尚书何晏。

<a id="sgz004-p-006-1"></a>

**[《三国志·三少帝纪》裴注 006·1](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-006-1)**

> 孫盛魏世籍曰髙平陵在洛水南大石山去洛城九十里

**释读** 孙盛记高平陵在洛水南大石山，离洛城九十里。

**归年** 地理注附249年谒陵条，不另立营陵纪年。

<a id="sgz033-b-1709-1"></a>

**[《三国志·后主传》仓内原文 L1709](../../sources/本地分卷/三国志/三国志-卷033.md#l1709)**

> 十二年春正月，魏誅大將軍曹爽等，

**释读** 魏正月诛曹爽等。

**归年** 蜀延熙十二年相当于魏嘉平元年，参魏《齐王纪》与《曹爽传》。

<a id="sgz009-b-480-2"></a>

**[《三国志·诸夏侯曹传》仓内原文 L480](../../sources/本地分卷/三国志/三国志-卷009.md#l480)**

> 奏爽曰：「臣昔從遼東還，先帝詔陛下、秦王及臣升御牀，把臣臂，深以後事爲念。臣言『二祖亦屬臣以後事爲念，此自陛下所見，無所憂苦；萬一有不如意，臣當以死奉明詔』。黃門令董箕等，才人侍疾者，皆所聞知。

**释读** 司马懿奏中追叙辽东归来后明帝召幼主、秦王和自己至御榻前托后事，他承诺以死奉诏，有宫人等目闻。

**归年** 奏作249政变当日，原始顾命在238岁末至239年初，正文477另见。

<a id="sgz009-b-480-3"></a>

**[《三国志·诸夏侯曹传》仓内原文 L480](../../sources/本地分卷/三国志/三国志-卷009.md#l480)**

> 今大將軍爽背棄顧命，敗亂國典，內則僭擬，外專威權；破壞諸營，盡據禁兵，羣官要職，皆置所親；殿中宿衞，歷世舊人皆復斥出，欲置新人以樹私計；根據槃牙，縱恣日甚。

**释读** 司马懿在奏中指曹爽负顾命、独权僭制、控制诸营，换掉宿卫而置亲信。

**归年** 249当日奏词中的指控。

<a id="sgz009-b-480-4"></a>

**[《三国志·诸夏侯曹传》仓内原文 L480](../../sources/本地分卷/三国志/三国志-卷009.md#l480)**

> 外旣如此，又以黃門張當爲都監，專共交關，看察至尊，候伺神器，離間二宮，傷害骨肉。天下洶洶，人懷危懼，陛下但爲寄坐，豈得久安！此非先帝詔陛下及臣升御牀之本意也。臣雖朽邁，敢忘往言？昔趙高極意，秦氏以滅；呂、霍早斷，漢祚永世。此乃陛下之大鑒，臣受命之時也。

**释读** 奏指曹爽用黄门张当窥察君主、间隔两宫，暗持政局，以赵高、吕氏和霍氏作鉴。

**归年** 249当日奏章。古代事例只是奏中的论证。

<a id="sgz009-b-480-5"></a>

**[《三国志·诸夏侯曹传》仓内原文 L480](../../sources/本地分卷/三国志/三国志-卷009.md#l480)**

> 太尉臣濟、尚書令臣孚等，皆以爽爲有無君之心，兄弟不宜典兵宿衞，奏永寧宮。皇太後令勑臣如奏施行。臣輒勑主者及黃門令罷爽、羲、訓吏兵，以侯就第，不得逗留以稽車駕；敢有稽留，便以軍法從事。

**释读** 司马懿称蒋济、司马孚等已奏永宁宫，太后命如奏办理；故罢曹爽、曹羲、曹训官军，限以侯就第，不得阻乘舆。

**归年** 卷004 L228、《通鉴》卷075 L220–245列同次政变。

<a id="sgz009-b-480-6"></a>

**[《三国志·诸夏侯曹传》仓内原文 L480](../../sources/本地分卷/三国志/三国志-卷009.md#l480)**

> 臣輙力疾，將兵屯洛水浮橋，伺察非常。」

**释读** 司马懿在奏尾自行说明已抱病领兵屯浮桥，监视非常动向。

**归年** 正始十年正月甲午同一奏。

<a id="sgz009-b-481-1"></a>

**[《三国志·诸夏侯曹传》仓内原文 L481](../../sources/本地分卷/三国志/三国志-卷009.md#l481)**

> 爽得宣王奏事，不通，迫窘不知所爲。

**释读** 曹爽知道司马懿的奏事，感到急迫，不知如何是好。

**归年** 与政变同日。

<a id="sgz009-b-481-2"></a>

**[《三国志·诸夏侯曹传》仓内原文 L481](../../sources/本地分卷/三国志/三国志-卷009.md#l481)**

> 大司農沛國桓範聞兵起，不應太後召，矯詔開平昌門，拔取劒戟，略將門候，南奔爽。宣王知，曰：「範畫策，爽必不能用範計。」

**释读** 桓范不应皇太后召，矫诏开城携剑戟出逃，南会曹爽；司马懿料曹爽不会采用其计。

**归年** 卷004与《通鉴》卷075 L246–271同一政变。

<a id="sgz009-b-481-3"></a>

**[《三国志·诸夏侯曹传》仓内原文 L481](../../sources/本地分卷/三国志/三国志-卷009.md#l481)**

> 範說爽使車駕幸許昌，招外兵。爽兄弟猶豫未決，範重謂羲曰：「當今日，卿門戶求貧賤復可得乎？且匹夫持質一人，尚慾望活，今卿與天子相隨，令於天下，誰敢不應者？」羲猶不能納。

**释读** 桓范屡劝曹爽与曹羲带皇帝去许昌征外兵，指出手中有天子可号令四方，兄弟始终未采纳。

**归年** 《通鉴》卷075 L265–280同载。

<a id="sgz009-b-481-4"></a>

**[《三国志·诸夏侯曹传》仓内原文 L481](../../sources/本地分卷/三国志/三国志-卷009.md#l481)**

> 侍中許允、尚書陳泰說爽，使早自歸罪。爽於是遣允、泰詣宣王，歸罪請死，乃通宣王奏事。遂免爽兄弟，以侯還第。

**释读** 许允、陈泰劝立即认罪，曹爽遣两人请罪，奏章获通；兄弟免官以侯归家。

**归年** 卷004 L228正始十年正月甲午，正文与裴注有劝降使者主动方的异文。

<a id="sgz009-b-483-2"></a>

**[《三国志·诸夏侯曹传》仓内原文 L483](../../sources/本地分卷/三国志/三国志-卷009.md#l483)**

> 疑其有姦，收當治罪。當陳爽與晏等陰謀反逆，並先習兵，須三月中欲發，於是收晏等下獄。

**释读** 官府疑张当所为有奸，收审。张当称曹爽、何晏等练兵拟于三月行动，何晏等被捕。

**归年** 《三少帝纪》卷004 L228明确正始十年正月戊戌；三月仅指供词中的预定日期。

<a id="sgz009-b-483-3"></a>

**[《三国志·诸夏侯曹传》仓内原文 L483](../../sources/本地分卷/三国志/三国志-卷009.md#l483)**

> 會公卿朝臣廷議，以爲「春秋之義，『君親無將，將而必誅』。爽以支屬，世蒙殊寵，親受先帝握手遺詔，託以天下，而包藏禍心，蔑棄顧命，乃與晏、颺及當等謀圖神器，範黨同罪人，皆爲大逆不道」。

**释读** 朝臣以《春秋》之义称曹爽背顾命、与何晏邓飏等谋反，桓范同党，都以大逆不道论。

**归年** 《通鉴》卷075 L283–293及本传均系249年政变后审案。

<a id="sgz009-b-485-6"></a>

**[《三国志·诸夏侯曹传》仓内原文 L485](../../sources/本地分卷/三国志/三国志-卷009.md#l485)**

> 及爽被誅，曹氏盡死。

**释读** 夹注述及曹爽遭诛、其一支亲属尽死。

**归年** 卷004 L228和本卷前段与同年高平陵政变同事。“曹氏盡死”在该家语境，不是魏宗室尽死。

<a id="sgz009-b-496-3"></a>

**[《三国志·诸夏侯曹传》仓内原文 L496](../../sources/本地分卷/三国志/三国志-卷009.md#l496)**

> 爽誅，徵玄爲大鴻臚，

**释读** 曹爽被诛后，朝廷召夏侯玄回，任大鸿胪。

**归年** 《通鉴》卷075 L347–360明确249年政变后召还。

<a id="sgz009-p-030-2"></a>

**[《三国志·诸夏侯曹传》裴注 030·2](../../sources/摘录/三国志-卷009-诸夏侯曹传裴注.md#pei-030-2)**

> 至是乃盡出也

**释读** 当皇帝去高平陵时，曹爽兄弟全都出城。

**归年** 卷004 L228明正始十年正月甲午。

<a id="sgz009-p-031-1"></a>

**[《三国志·诸夏侯曹传》裴注 031·1](../../sources/摘录/三国志-卷009-诸夏侯曹传裴注.md#pei-031-1)**

> 世語曰初宣王勒兵從闕下趣武庫當爽門人逼車住爽妻劉怖出至㕔事謂帳下守督曰公在外今兵起如何督曰夫人勿憂乃上門樓引弩注箭欲發將孫謙在後牽止之曰天下亊未可知如此者三宣王遂得過去

**释读** 司马懿由阙下赴武库时受爽门人阻。曹爽妻刘氏惊，守督欲发弩，孙谦再三劝阻，司马懿遂得通过。

### 15. 魏右将军夏侯霸来降蜀

[返回正文第15条](#sgz-event-15)

<a id="sgz033-b-1709-2"></a>

**[《三国志·后主传》仓内原文 L1709](../../sources/本地分卷/三国志/三国志-卷033.md#l1709)**

> 右將軍夏侯霸來降。

**归年** 本传承延熙十二年，《夏侯渊传》附夏侯霸及《通鉴》卷075同记，逃奔实际日期不必与正月诛曹爽同日。

<a id="sgz009-b-456-5"></a>

**[《三国志·诸夏侯曹传》仓内原文 L456](../../sources/本地分卷/三国志/三国志-卷009.md#l456)**

> 聞爽誅，自疑，亡入蜀。以淵舊勳赦霸子，徙樂浪郡。

**释读** 夏侯霸知曹爽死后疑惧而逃到蜀，魏朝念夏侯渊有功，赦夏侯霸之子，迁往乐浪。

**归年** 《通鉴》卷075 L347–369及卷004 L228接正始十年正月政变后。赦迁为同一事件处分，日不载。

<a id="sgz009-p-009-4"></a>

**[《三国志·诸夏侯曹传》裴注 009·4](../../sources/摘录/三国志-卷009-诸夏侯曹传裴注.md#pei-009-4)**

> 及司馬宣王誅曹爽遂召玄玄來東霸聞曹爽被誅而玄又徵以為禍必轉相及心既内恐又霸先與雍州刺史郭淮不和而淮代玄為征西霸益不安故遂奔蜀南趣隂平而失道入窮谷中糧盡殺馬歩行足破卧巖石下使人求道未知何之蜀聞之乃使人迎霸

**释读** 曹爽被诛、夏侯玄受召，郭淮继任，夏侯霸因彼此不和害怕祸及而奔蜀；在阴平迷路杀马为粮，足伤后获蜀人迎接。

**归年** 《通鉴》卷075 L347–366明正始十年政变后，正文 L456同事。

<a id="sgz009-p-009-8"></a>

**[《三国志·诸夏侯曹传》裴注 009·8](../../sources/摘录/三国志-卷009-诸夏侯曹传裴注.md#pei-009-8)**

> 及霸入蜀禪與相見釋之曰卿父自遇害於行間耳非我先人之手刃也指其兒子以示之曰此夏侯氏之甥也厚加爵寵

**释读** 夏侯霸到蜀后，刘禅说其父遇害乃战阵，并非自己先人亲手杀，并指儿子向他说明两家为亲，加爵厚待。

**归年** 《通鉴》卷075 L347–369置于249奔蜀后入见。是同年归蜀的接纳情节。

<a id="sgz009-p-046-2"></a>

**[《三国志·诸夏侯曹传》裴注 046·2](../../sources/摘录/三国志-卷009-诸夏侯曹传裴注.md#pei-046-2)**

> 魏氏春秋曰初夏侯霸将奔蜀呼玄欲與之俱玄曰吾豈茍存自容於冦虜乎遂還京師

**释读** 夏侯霸邀夏侯玄一起奔蜀，夏侯玄不愿苟活于敌国，返回京师。

**归年** 《通鉴》卷075 L347–366、卷009本传明正始十年曹爽死后。

### 20. 王昶陈治国五策

[返回正文第20条](#sgz-event-20)

<a id="sgz027-b-1425-2"></a>

**[《三国志·徐胡二王传》仓内原文 L1425](../../sources/本地分卷/三国志/三国志-卷027.md#l1425)**

> 昶陳治略五事：「其一，欲崇道篤學，抑絕浮華，使國子入太學而脩庠序；其二，欲用考試，考試猶準繩也，未有舍準繩而意正曲直，廢黜陟而空論能否也；其三，欲令居官者乆於其職，有治績則就增位賜爵；其四，欲約官實祿，勵以廉恥，不使與百姓爭利；其五，欲絕侈靡，務崇節儉，令衣服有章，上下有敘，儲糓畜帛，反民於樸。」

**归年** 本传嘉平初接249年司马懿奏问，依置于同年。

<a id="sgz027-b-1425-3"></a>

**[《三国志·徐胡二王传》仓内原文 L1425](../../sources/本地分卷/三国志/三国志-卷027.md#l1425)**

> 詔書襃讚。因使撰百官考課事，昶以爲唐虞雖有黜陟之文，而考課之法不垂。周制冢宰之職，大計群吏之治而誅賞，又無校比之制。由此言之，聖主明於任賢，略舉黜陟之體，以委達官之長，而總其統紀，故能否可得而知也。其大指如此。

**释读** 诏称许其奏，令拟百官考课。王昶认为虞周旧法重主管统查治绩，无须拘守固定比校细则。

**归年** 本传直接接五议，按同一次问策主条。

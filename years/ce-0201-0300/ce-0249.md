## 本年概述

曹芳谒高平陵时，司马懿夺取洛阳要地，使曹爽交兵，随后诛杀曹爽一党。夏侯霸奔蜀，姜维出兵雍州，魏调整西边诸将。王凌与令狐愚在淮南谋立楚王曹彪。

1. **司马懿发动高平陵政变，曹爽伏诛，魏重新任用群臣。** 正月甲午，曹芳出谒高平陵，曹爽兄弟随行。司马懿趁机起兵，经过曹爽宅门时，守督想放箭，被孙谦制止。司马懿控制武库，请皇太后下令解除曹爽诸兄弟的兵权，命司徒高柔假节、代理大将军，接管曹爽营，命太仆王观代理中领军，接管曹羲营，自己与蒋济屯于洛水浮桥。曹爽府司马鲁芝率兵闯出城门前去会合，招参军辛敞同行。辛敞惧祸问姐姐，辛宪英判断司马懿意在诛曹爽，仍劝弟弟谨守职分，辛敞便出了城。曹爽收到奏章后没有转报，留曹芳在伊水南，征发屯兵护卫。大司农桓范假传诏命出了平昌门，劝曹爽奉曹芳赴许昌、征调外兵，自己可以用大司农印筹办军粮。曹爽迟疑未决，许允、陈泰往来劝解，蒋济又致书，尹大目对洛水起誓说只免曹爽等人的官。五更时，曹爽决定交权，转呈奏章，请曹芳下诏免官。曹芳回宫，曹爽兄弟以侯爵归第，随即受到监视。戊戌，有司因黄门张当曾私给曹爽宫中才人，将张当交廷尉审问。张当供称曹爽等拟在三月起事，公卿遂以大逆议罪。曹爽、曹羲、曹训、曹彦及何晏、丁谧、邓飏、毕轨、李胜、桓范、张当皆被处死，夷三族。岁首曾起西北大风，[上年](ce-0248.md#sgz-note-19)听管辂转述会见何、邓的舅父，此时得知二人被杀，才信管辂所说。钟毓此前问过天下治乱，到这时也领会了管辂的用意。丙午大赦。丁未，魏命司马懿为丞相，他先后辞去丞相和九锡。蒋济获进封都乡侯，辞谢未获准。孙资复任侍中、领中书令。四月乙丑，魏改元嘉平。曹爽败后，高柔进封万岁乡侯，王观复任尚书、加驸马都尉、赐关内侯，孙礼入为司隶校尉。钟毓回朝历任御史中丞、侍中、廷尉，卢毓奉司马懿之命代理司隶校尉，审理曹爽一案，随后回任吏部尚书、加奉车都尉，封高乐亭侯。傅嘏任河南尹，逐步恢复旧有法纪，按才干选用本地和外地人士。刘陶居家，为从前口出高论谢过。 [[1]](#sg-note-1)

2. **蒋济去世，魏任王凌为太尉、孙礼为司空。** 四月丙子，太尉蒋济去世，谥景侯。冬十二月辛卯，魏任司空王凌为太尉。庚子，任司隶校尉孙礼为司空，封大利亭侯、食邑百户。 [[2]](#sg-note-5)

<a id="sg-event-8"></a>

3. **王凌与令狐愚谋立楚王曹彪。** 司空王凌与兖州刺史令狐愚商议废曹芳、迎楚王曹彪到许昌继位。九月，令狐愚派张式到白马与曹彪接洽，王凌也派人告诉儿子王广，王广劝父亲别率先废立。十一月，令狐愚再次遣张式出使，使者未返，令狐愚便病逝。王凌后来升太尉，[两年后事泄](ce-0251.md#sg-note-6)。 [[3]](#sg-note-8)

<a id="sgz-event-19"></a>

4. **徐邈以光禄大夫卒，按公礼葬。** 徐邈以光禄大夫身份在家去世，年七十八。朝廷以公礼安葬，谥穆侯，子徐武承袭。 [[4]](#sgz-note-19)

<a id="sgz-event-20"></a>

5. **王昶陈治国五策。** 司马懿广询政事得失，王昶请兴学、以考核察实绩、使官员久任、精简官署而充实俸禄，并削减奢侈用度。朝廷下诏称许，又命王昶拟定百官考课办法。 [[5]](#sgz-note-20)

<a id="sgz-event-21"></a>

6. **王基复任尚书，出镇荆州。** 高平陵事变后，拟任河南尹的王基因曾任曹爽府属而免官。朝廷同年重新起用他为尚书，随后让他出任荆州刺史，加扬烈将军。 [[6]](#sgz-note-21)

<a id="sgz-event-27"></a>

<a id="sgz-event-28"></a>

7. **程喜弹劾杜恕，杜恕免死徙章武。** 幽州刺史杜恕与征北将军程喜同驻蓟城，袁侃曾提醒杜恕留意二人同城持节的处境。杜恕到任未满一年，鲜卑首领之子带数十骑绕过关塞来到州府，州府杀了一名从人，未奏报朝廷。程喜托司马宋权传话，要杜恕低头道歉。杜恕回信说愿按职责办事，也愿承担斩人之责。程喜随即弹劾，廷尉拟处死刑。朝廷念杜恕之父杜畿因公殉职，免其死，贬为庶人，流徙章武。 [[7]](#sgz-note-27)

<a id="sgz-event-31"></a>

8. **王弼免官，秋天病逝。** 曹爽被废后，王弼因公事免官。王弼曾注《周易》《老子》，与钟会齐名。本年秋天他染疫去世，年二十四，无子。司马师闻讯叹息多日。 [[8]](#sgz-note-31)

9. **姜维进兵雍州，魏调将应战，夏侯霸奔蜀。** 本年蜀廷授姜维假节。高平陵事变后，魏廷召夏侯玄还洛阳，任大鸿胪。夏侯霸素与接任征西将军的郭淮不和，又怕因与曹爽亲近而被追究，遂逃往蜀地。他曾邀夏侯玄同行，夏侯玄没有答应。夏侯霸取道阴平时迷路，蜀汉遣人迎接，刘禅以姻亲之礼相待，加授爵位。夏侯霸判断，司马懿正忙于巩固家族势力，又指出魏廷年轻的钟会将成为吴、蜀之患。魏因夏侯渊旧功赦免夏侯霸的儿子，徙往乐浪。郭淮本年迁征西将军、都督雍凉诸军事，陈泰接任雍州刺史，加奋威将军。姜维命句安、李歆据守麴山两城。陈泰与郭淮合谋，派徐质、邓艾等截断两城的粮道和水源。姜维从牛头山来援，陈泰坚垒不战，郭淮率军进驻洮水。姜维怕退路被截，撤回蜀地，句安、李歆率孤立的两城降魏。姜维命廖化屯白水南岸牵制邓艾，邓艾识破姜维另取洮城之意，先占洮城，魏军得以保城；邓艾获赐关内侯、加讨寇将军。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **马忠去世。** 延熙十二年，马忠去世，儿子马脩承袭爵位；南中各族纷纷前往丧所举哀。此后当地立庙祭祀，建庙确年未载。 [[10]](#sg-note-10)

<a id="sgz-event-16"></a>

11. **蜀汉四月大赦。** 蜀汉于四月大赦。 [[11]](#sgz-note-16)

> 嘉平元年，車駕朝高平陵，會爲中書郎，從行。相國宣文侯始舉兵，衆人恐懼，而夫人自若。中書令劉放、侍郎衞瓘、夏侯和等家皆怪問：『夫人一子在危難之中，何能無憂？』荅曰：『大將軍奢僭無度，吾常疑其不安。太傅義不危國，必爲大將軍舉耳。吾兒在帝側何憂？聞且出兵無他重器，其勢必不乆戰。』果如其言，一時稱明。

**釋讀與歸年** 高平陵之變時鍾會以中書郎從曹芳謁陵，張昌蒲判斷司馬懿舉兵針對曹爽、事不至久戰，時人稱其有識。

> 歲朝，西北大風，塵埃蔽天，十餘日，聞晏、颺皆誅，然後舅氏乃服。
>
> **〔裴注〕**
> 輅別傳曰：舅夏大夫問輅：「前見何、鄧之日，爲已有凶氣未也？」輅言：「與禍人共會，然後知神明交錯；與吉人相近，又知聖賢求精之妙。夫鄧之行步，則筋不束骨，脉不制肉，起立傾倚，若無手足，謂之鬼躁。何之視候，則魂不守宅，血不華色，精爽煙浮，容若槁木，謂之鬼幽。故鬼躁者爲風所收，鬼幽者爲火所燒，自然之符，不可以蔽也。」

**釋讀與歸年** 正始十年歲首西北大風；十餘日後舅父聽聞何晏、鄧颺同被誅。與同年高平陵政變相承，傳中的風為先兆敘事，不據此換算處決日。

**釋讀與歸年** 舅父夏大夫在何、鄧死後問管輅何以預見，管輅以鬼躁、鬼幽解其行止容貌；[《資治通鑑》卷七十五](../../史书/025-资治通鉴/KR2b0007_075.txt#L333-L338)繫在曹爽敗後。

> 魏末傳曰：爽兄弟歸家，勑洛陽縣發民八百人，使尉部圍爽第四角，角作高樓，令人在上望視爽兄弟舉動。爽計窮愁悶，持彈到後園中，樓上人便唱言「故大將軍東南行！」爽還廳事上，與兄弟共議，未知宣王意深淺，作書與宣王曰：「賤子爽哀惶恐怖，無狀招禍，分受屠滅，前遣家人迎糧，于今未反，數日乏匱，當煩見餉，以繼旦夕。」宣王得書大驚，即荅書曰：「初不知乏糧，甚懷踧踖。令致米一百斛，并肉脯、鹽豉、大豆。」尋送。爽兄弟不達變數，即便喜歡，自謂不死。

**釋讀與歸年** 曹爽收到奏事后截住不报，一时拿不定主意。与桓范来劝、交权前后诸说同号。

**釋讀與歸年** 干宝《晋纪》记曹爽留车驾宿伊水南、组织屯兵。另据《魏末传》，司马懿嘱司马孚送帷帐和饮食至行在。二者各说一方举措，接在曹爽收到奏事后。

**釋讀與歸年** 桓范假传诏命出平昌门，建议护送曹芳到许昌，征外兵。曹爽兄弟迟疑；许允、陈泰劝曹爽归罪。曹爽派二人往见司马懿才转达奏事。[《资治通鉴》卷75](../../史书/025-资治通鉴/KR2b0007_075.txt#L254-L279)并记到五更方决定；与此传「歸罪請死」及裴注所记仅免官的保证互读。

**釋讀與歸年** 三则裴注补蒋济预料曹爽不能用桓范、尹大目指洛水转达仅免官的保证，以及曹爽欲作富家翁、桓范预见族祸。三则都在交出兵权前后，同号读。

**釋讀與歸年** 曹爽兄弟除去军政职务，以原来的侯爵还第。此时尚未公开收捕、处死。

**釋讀與歸年** 《魏末传》载司马懿使洛阳吏卒临视曹爽兄弟。曹爽向司马懿乞粮，司马懿回书并送米、肉脯等，曹爽兄弟因此以为可免死。两封短函连引。

> 淩、愚密協計，謂齊王不任天位，楚王彪長而才，欲迎立彪都許昌。嘉平元年九月，愚遣將張式至白馬，與彪相問往來。淩又遣舍人勞精詣洛陽，語子廣。廣言：「廢立大事，勿爲禍先。」
>
> **〔裴注〕**
> 漢晉春秋曰：淩、愚謀，以帝幼制於彊臣，不堪爲主，楚王彪長而才，欲迎立之，以興曹氏。淩使人告廣，廣曰：「凡舉大事，應本人情。今曹爽以驕奢失民，何平叔虛而不治，丁、畢、桓、鄧雖並有宿望，皆專競於世。加變易朝典，政令數改，所存雖高而事不下接，民習於舊，衆莫之從。故雖勢傾四海，聲震天下，同日斬戮，名士減半，而百姓安之，莫或之哀，失民故也。今懿情雖難量，事名有逆，而擢用賢能，廣樹勝己，脩先朝之政令，副衆心之所求。爽之所以爲惡者，彼莫不必改，夙夜匪解，以恤民爲先。父子兄弟並握兵要，未易亡也。」淩不從。臣松之以爲如此言之類，皆前史所不載，而猶出習氏。且制言法體不似於昔，疑悉鑿齒所自造者也。
>
> **〔正文續〕**
> 其十一月，愚復遣式詣彪，未還，會愚病死。

**釋讀與歸年** 王淩、令狐愚因認為曹芳不足當位，計議迎曹彪至許昌。九月令狐愚使張式至白馬接洽，王淩遣勞精告兒子王廣，王廣反對率先廢立。

**釋讀與歸年** 《漢晉春秋》詳載王廣比較曹爽失人心、司馬懿復舊政並用賢，勸父勿起事。裴松之指出前史並無此段，文體不類當時，懷疑習鑿齒擬作；兩說與正文並列。

**釋讀與歸年** 十一月令狐愚再遣張式聯絡曹彪，使者尚未返，令狐愚病死。

> 嘉平初，太傅司馬宣王旣誅曹爽，乃奏愽問大臣得失。昶陳治略五事：其一，欲崇道篤學，抑絕浮華，使國子入太學而脩庠序；其二，欲用考試，考試猶準繩也，未有舍準繩而意正曲直，廢黜陟而空論能否也；其三，欲令居官者乆於其職，有治績則就增位賜爵；其四，欲約官實祿，勵以廉恥，不使與百姓爭利；其五，欲絕侈靡，務崇節儉，令衣服有章，上下有叙，儲糓畜帛，反民於樸。詔書襃讚。因使撰百官考課事，昶以爲唐虞雖有黜陟之文，而考課之法不垂。周制冢宰之職，大計群吏之治而誅賞，又無校比之制。由此言之，聖主明於任賢，略舉黜陟之體，以委達官之長，而總其統紀，故能否可得而知也。其大指如此。

### 7. 程喜弹劾杜恕，杜恕免死徙章武

[返回正文第7条](#sgz-event-27)

**《任蘇杜鄭倉傳》互見** [TXT 第107行](../../拆分史书/三国志/卷016.md#edition-wei016-l107-2)

<a id="wei016-l103-3"></a>

**[《三國志·任蘇杜鄭倉傳》正文](../../拆分史书/三国志/卷016.md#edition-wei016-l103-3)** · [TXT L103](../../拆分史书/三国志/卷016.txt#L103)

> 復出爲幽州刺史，加建威將軍，使持節，護烏丸校尉。時征北將軍程喜屯薊，尚書袁侃等戒恕曰：「程申伯處先帝之世，傾田園讓於青州。足下今俱杖節，使共屯一城，宜深有以待之。」而恕不以爲意。

**釋讀與歸年** 杜恕出任幽州刺史，加建威将军、使持节、护乌丸校尉。程喜以征北将军屯蓟，袁侃提醒同城执节及程喜从前在青州让田园的事，劝他防备；杜恕没放在心上。本年案发，到任尚未满一年，具体任命可在此前。

<a id="wei016-l103-4"></a>

**[《三國志·任蘇杜鄭倉傳》正文](../../拆分史书/三国志/卷016.md#edition-wei016-l103-4)** · [TXT L103](../../拆分史书/三国志/卷016.txt#L103)

> 至官未期，有鮮卑大人兒，不由關塞，徑將數十騎詣州，州斬所從來小子一人，無表言上。喜於是劾奏恕，下廷尉，當死。以父畿勤事水死，免爲庶人，徙章武郡，是歲嘉平元年。

**釋讀與歸年** 鲜卑大人之子率骑不经指定关塞来州，州府斩其随行一人，未上表。经程喜弹劾，廷尉拟死；朝廷念父杜畿勤事殉职，免死削为庶人、流徙章武。传文明系嘉平元年。

<a id="wei016-l104-1"></a>

**[《三國志·任蘇杜鄭倉傳》裴注](../../拆分史书/三国志/卷016.md#edition-wei016-l104-1)** · [TXT L104](../../拆分史书/三国志/卷016.txt#L104)

> 杜氏新書曰：喜欲恕折節謝己，諷司馬宋權示之以微意。恕荅權書曰：「況示委曲。夫法天下事，以善意相待，無不致快也；以不善意相待，無不致嫌隙也。而議者言，凡人天性皆不善，不當待以善意，更墮其調中。僕得此輩，隨欲歸蹈滄海乘桴耳，不能自諧在其間也。然以年五十二，不見廢棄，頗遭明達君子亮其本心；若不見亮，使人刳心著地，正與數斤肉相似，何足有所明，故終不自解說。程征北功名宿著，在僕前甚多，有人出征北乎！若令下官事無大小，咨而後行，則非上司彈繩之意；若咨而不從，又非上下相順之宜。故推一心，任一意，直而行之耳。殺胡之事，天下謂之是邪，是僕諧也；呼爲非邪，僕自受之，無所怨咎。程征北明之亦善，不明之亦善，諸君子自共爲其心耳，不在僕言也。」喜於是遂深文劾恕。

**釋讀與歸年** 程喜由司马宋权婉转传意，要杜恕折节称谢。杜恕回信坚持以善意待人，写自己五十二岁，并说明凡事请示便失监察本意，问而不从又有损上下相从，只能径依职责。鲜卑案无论判是判非，均愿自负其责。程喜继而按法深劾。原文顺序为传意、回信、深劾；与本传定罪同一事件。

<a id="wei016-l105-1"></a>

**[《三國志·任蘇杜鄭倉傳》正文](../../拆分史书/三国志/卷016.md#edition-wei016-l105-1)** · [TXT L105](../../拆分史书/三国志/卷016.txt#L105)

> 恕倜儻任意，而思不防患，終致此敗。

**釋讀與歸年** 陈寿以杜恕倜傥任意、不预防祸患说明他在本案失败的原因，属传末评断，随流徙原事。

**釋讀與歸年** 《世語》與《漢晉春秋》都稱夏侯霸歸蜀後談司馬懿、鍾會，問者、所答各有出入；嘉平元年夏侯霸奔蜀有本紀年據，問答隨入蜀附讀。

**釋讀與歸年** 姜维遣句安、李歆占麴山二城，役使羌胡。陈泰说服郭淮堵截粮道与流水，句安军粮水渐尽。姜维出牛头山救援，陈泰坚垒不战，郭淮进驻洮水策应截归路，姜维退走，两城归魏。[《郭淮传》](../../拆分史书/三国志/卷026.txt#L81)及[《通鉴》卷七十五](../../史书/025-资治通鉴/KR2b0007_075.txt#L371-L392)都置249年。陈泰传和《通鉴》作李歆，《后主传》作李韶。陈泰传称姜维为大将军，249年按蜀本纪在位为卫将军。

> 然長不盈七尺，氣候分明，內行脩絜，其所文采，惟施軍器，餘皆質素。終日欽欽，常在戰場，臨急膽定，尤過絕人，雖世無事，每朝夕嚴鼓，兵在營者，咸行裝就隊，以此玩敵，使不知所備，故出輒有功。

**釋讀** 朱然身高不足七尺，神气分明，私德清整，除了军器加文饰，其他皆质朴。军务上终日戒慎，临急尤其镇定。即便平时无警，早晚也击鼓整军、整装就队，使敌军无法从警备判断何时出兵，因此作战常立功。

**歸年** 本传卒传前总叙行事性情，随原段落置于卒事资料，均为多年常态。

**[《三國志·朱治朱然呂範朱桓傳》正文](../../拆分史书/三国志/卷056.md#edition-wu056-l46-3)** · [TXT L46](../../拆分史书/三国志/卷056.txt#L46)

> 寢疾二年，後漸增篤，權晝爲減膳，夜爲不寐，中使醫藥口食之物，相望於道。然每遣使表疾病消息，權輒召見，口自問訊，入賜酒食，出送布帛。自創業功臣疾病，權意之所鍾，呂蒙、凌統最重，然其次矣。

**釋讀** 朱然患病卧床两年，逐渐加重。孙权日间减膳，夜不能寐，派使者送医送药送食。每次朱然遣人报病情，孙权亲问，赐来使酒食和布帛。开国功臣病重时孙权最牵念吕蒙、凌统，其次朱然。

**歸年** 病程两年，起病无确月，与病逝缘由连叙。

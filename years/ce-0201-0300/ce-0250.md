## 本年概述

孫權廢太子孫和、賜魯王孫霸死，立孫亮為太子。王昶由荊州渡江攻吳，姜維出兵西平。吳丹楊等地水患後，朝廷蠲免積欠，並貸種糧。

## 吳廢立太子與國內政事

1. **孙权废孙和、赐孙霸死，改立孙亮。** 孙权早先担心诸子不和、群臣结党，曾对孙峻说这样会重蹈袁氏争嗣败亡的覆辙。秋，孙权幽闭太子孙和。朱据、屈晃率诸将吏涂泥自缚，连日在宫门请求释放孙和。朱据力陈太子是国本，举申生与戾太子因谗致死为戒。陈正、陈象也以晋献公废立致乱进谏。孙权族诛陈正、陈象，杖朱据、屈晃各一百，贬朱据为新都郡丞，罢斥屈晃回乡。张纯因力谏被囚，随后在市中处死。孙权废孙和为庶人，迁居故鄣，赐鲁王孙霸死，并诛依附孙霸、构陷太子的杨笁、全寄、吴安、孙奇等。杨笁的尸体被投入江中；其兄杨穆曾多次劝戒他，获免死，仍被流徙南州。朱据还未赴新都，孙弘乘孙权病重，发文书追赐朱据死。全公主先前已劝孙权为孙亮迎娶全尚之女。十一月，孙权立孙亮为太子，以全氏为妃，又应孙亮之请，准许其母潘氏的姐姐出嫁。 [[1]](#sg-note-8)

<a id="sgz-event-14"></a>

2. **孙俊去世。** 孙桓之弟孙俊任定武中郎将，屯戍薄落，赤乌十三年去世。 [[2]](#sgz-note-14)

<a id="sgz-event-18"></a>

3. **吴记荧惑犯南斗。** 五月夏至荧惑入南斗，七月经过斗魁第二星后往东。 [[3]](#sgz-note-18)

<a id="sgz-event-19"></a>

4. **丹杨等处山崩水溢，吴免积欠、贷种粮。** 赤乌十三年八月，丹杨、句容、故鄣、宁国诸山崩，洪水泛溢。孙权下诏免除积欠，贷给种子和口粮。 [[4]](#sgz-note-19)

<a id="sgz-event-20"></a>

5. **吴作堂邑涂塘。** 吴遣军十万修作堂邑涂塘，试图水淹北路。 [[5]](#sgz-note-20)

<a id="sgz-event-21"></a>

6. **吴有将改元立后的传闻。** 吴地传说有人得神人授书，预言吴将改元并立皇后。 [[6]](#sgz-note-21)

## 江防與魏蜀軍事

<a id="sg-event-5"></a>

7. **王昶攻江陵，朱绩追至纪南失利。** 十二月乙未，魏征南将军王昶渡江攻江陵，未克城便退兵。朱绩判断魏军疲困，约诸葛融分兵前后夹击，诸葛融应允。朱绩追至距江陵三十里的纪南，初战得手，诸葛融没有出兵，王昶伏兵击败朱绩，吴将钟离茂、许旻战死。孙权嘉许朱绩，责备诸葛融。诸葛融因兄长诸葛恪受到重用而未失职，双方旧隙加深。 [[7]](#sg-note-5)

<a id="sgz-event-16"></a>

8. **文钦诈降，朱异与吕据往迎而不至。** 朱异察觉文钦请降有诈并呈其书，孙权令设防仍去接引，吕据率二万助朱异；至边界，文钦果然未降。 [[8]](#sgz-note-16)

<a id="sg-event-6"></a>

9. **姜维攻西平，俘获郭脩。** 姜维出兵西平，未能攻克，俘获郭脩而还。郭脩后来任蜀汉左将军。[253年，他在汉寿刺杀费祎](ce-0253.md#sg-note-4)。 [[9]](#sg-note-6)

<a id="sg-event-7"></a>

10. **杜琼去世。** 杜琼年过八十卒，所著韩诗章句未传诸子。 [[10]](#sg-note-7)

> 權患之，謂侍中孫峻曰：「子弟不睦，臣下分部，將有袁氏之敗，爲天下笑。一人立者，安得不亂？」於是有改嗣之規矣。

> 吳歷曰：晃入，口諫曰：「太子仁明，顯聞四海。今三方鼎跱，實不宜搖動太子，以生衆心。願陛下少垂聖慮，老臣雖死，猶生之年。」叩頭流血，辭氣不撓。權不納晃言，斥還田里。

**釋讀** 《吴历》说屈晃入殿仍口头进谏，认为孙和仁明，三国并立时动摇储君会动摇人心，请孙权考虑。他叩头流血，态度坚定。孙权没有采纳，将他罢斥回乡。

**歸年** 与250年幽禁孙和、杖责诸臣相接。《吴历》只记屈晃罢归，孙皓于[264年](ce-0264.md#wu059-l39-2)下诏称屈晃「忠諫亡身」。近修《台州地区志》人物传作罢归次年（251）忧愤而死，早期史料的卒年未详。

> 十三年，姜維復出西平，不克而還。

<a id="sgz044-b-2074-9"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2074](../../拆分史书/三国志/卷044.md#l2074)**

> 十二年，假維節復出西平，不克而還。

**释读** 本传称延熙十二年姜维假节再攻西平，不克而还。

**归年** 《后主传》延熙十二年（249）出雍州，十三年（250）复出西平。攻西平的年次从《后主传》及《资治通鉴》，并存《姜维传》系于延熙十二年的记载。假节未另析年。

<a id="wei004-l68-xiping"></a>

**[《三國志·三少帝紀》裴注引《魏氏春秋》](../../拆分史书/三国志/卷004.md#edition-wei004-l68-1)** · [TXT L68](../../拆分史书/三国志/卷004.txt#L68)

> 魏氏春秋曰：脩字孝先，素有業行，著名西州。姜維劫之，脩不爲屈。劉禪以爲左將軍，脩欲刺禪而不得親近，每因慶賀，且拜且前，爲禪左右所遏，事輙不克，故殺禕焉。

**归年** [《资治通鉴》卷七十五](../../史书/025-资治通鉴/KR2b0007_075.txt#L725-L732)追叙姜维攻西平时获郭偱，胡三省注明确回指[嘉平二年姜维攻西平条](../../史书/025-资治通鉴/KR2b0007_075.txt#L478-L482)，即250年。《齐王纪》[褒赠诏](../../拆分史书/三国志/卷004.md#edition-wei004-l67-1)也说姜维进兵郭脩本郡时俘获了他。出任左将军及谋刺刘禅的年月无载，作为身世和[253年费祎遇刺](ce-0253.md#sg-note-4)的前因。魏纪作「郭脩」，《后主传》《费祎传》作「郭循」。《通鉴》此处作「郭偱」，胡三省认为「偱」可能是「脩」的传写讹字。

### 11. 以征西将军郭淮为车骑将军

[返回正文第11条](#sg-event-1)

<a id="wei004-l53-1"></a>

**[《三國志·三少帝紀》正文](../../拆分史书/三国志/卷004.md#edition-wei004-l53-1)** · [TXT L53](../../拆分史书/三国志/卷004.txt#L53)

> 二年夏五月，以征西將軍郭淮爲車騎將軍。

**釋讀與歸年** 嘉平二年五月郭淮由征西将军转车骑将军。

<a id="sgz026-b-1404-3"></a>

**[《三国志·满田牵郭传》仓内原文 L1404](../../拆分史书/三国志/卷026.md#l1404)**

> 二年，詔曰：「昔漢川之役，幾至傾覆。淮臨危濟難，功書王府。在關右三十餘年，外征寇虜，內綏民夷。比歲以來，摧破廖化，禽虜句安，功績顯著，朕甚嘉之。今以淮爲車騎將軍、儀同三司，持節、都督如故。」

**释读** 郭淮共有食邑两千七百八十户，分三百户封一子为亭侯。

**归年** 嘉平二年见本传紧承升车骑诏，封授未另载月日。

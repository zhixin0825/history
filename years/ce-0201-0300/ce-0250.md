[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **以征西将军郭淮为车骑将军。** 二年夏五月，以征西将军郭淮为车骑将军。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **以特进孙资为骠骑将军。** 冬十月，以特进孙资为骠骑将军。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **司空孙礼薨。** 十一月，司空孙礼去世。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **东海王霖薨。** 十二月甲辰，东海王霖去世。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **征南将军王昶渡江，掩攻吴。** 乙未，征南将军王昶渡江，掩攻吴，破之。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **姜维出西平。** 姜维攻西平未克而还。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **杜琼去世。** 杜琼年过八十卒，所著韩诗章句未传诸子。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **孙权废孙和、赐孙霸死、立孙亮。** 孙和被废而居故鄣，孙霸赐死，至十一月改立孙亮为太子。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **放薨，諡曰敬侯。** 嘉平二年，放薨，諡曰敬侯。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **孙礼去世。** 孙礼于本年去世。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **胡质去世。** 胡质于本年去世。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **和废，权遂立亮爲太子。** 赤乌十三年，和废，权遂立亮爲太子，以全氏爲妃。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **亮立为太子，请出嫁夫人之姊。** 赤乌十三年，亮立为太子，请出嫁夫人之姊，权听许之。 [[13]](#sg-note-13)

### 8. 孙权废孙和、赐孙霸死、立孙亮

[返回正文第8条](#sg-event-8)

<a id="sg047-l2329-e8"></a>

**[《三国志·吴主传》](../../sources/摘录/三国志-卷047-吴主传.md#p010)** · [仓内TXT L2329](../../sources/本地分卷/三国志/三国志-卷047.md#L2329)

> 廢太子和，處故鄣。魯王霸賜死。

<a id="sgz059-b-2827-3"></a>

**[《三国志·吴主五子传》仓内原文 L2827](../../sources/本地分卷/三国志/三国志-卷059.md#l2827)**

> 後遂幽閉和。於是驃騎將軍朱據、尚書僕射屈晃率諸將吏泥頭自縛，連日詣闕請和。權登白爵觀見，甚惡之，勑據、晃等無事忩忩。權欲廢和立亮，無難督陳正、五營督陳象上書，稱引晉獻公殺申生，立奚齊，晉國擾亂，又據、晃固諫不止。權大怒，族誅正、象，據、晃牽入殿，杖一百，竟徙和於故鄣，羣司坐諫誅放者十數。衆咸冤之。

**释读** 朱据、屈晃等请释孙和，孙权不听。陈正、陈象引申生旧事谏储，遭族诛；孙和被徙故鄣，朱据等受杖。

**归年** 《吴主传》赤乌十三年废和、赐霸死、立孙亮。原段前段长期纷争与此处正式废黜有别。

<a id="sgz059-b-2832-2"></a>

**[《三国志·吴主五子传》仓内原文 L2832](../../sources/本地分卷/三国志/三国志-卷059.md#l2832)**

> 太子以敗，霸亦賜死。流笁屍於江，兄穆以數諫戒笁，得免大辟，猶徙南州。霸賜死後，又誅寄、安、奇等，咸以黨霸搆和故也。

**释读** 杨笁尸投江，兄杨穆免死仍迁南方。全寄、吴安、孙奇以党霸构和被诛。

**归年** 《吴主传》赤乌十三年赐霸死并诛其党；杨穆处置另无日期。

<a id="sgz059-p-009-1"></a>

**[《三国志·吴主五子传》裴注 009·1](../../sources/摘录/三国志-卷059-吴主五子传裴注.md#pei-009-1)**

> 吳厯曰晃入口諫曰太子仁明顯聞四海今三方鼎跱實不宜揺動太子以生衆心願陛下少垂聖慮老臣雖死猶生之年叩頭流血辭氣不撓權不納晃言斥還田里

**释读** 屈晃称孙和贤，不宜动摇众心，叩头流血。孙权斥之还田里。

**归年** 赤乌十三年废孙和，《吴历》所载谏诤随本事。

<a id="sgz059-p-009-4"></a>

**[《三国志·吴主五子传》裴注 009·4](../../sources/摘录/三国志-卷059-吴主五子传裴注.md#pei-009-4)**

> 吳書曰張純亦盡言極諌權幽之遂棄市

**释读** 孙权囚张纯，终于弃市。

**归年** 接赤乌十三年废储谏诤，刑期具体年月未详。

<a id="sgz050-b-2412-3"></a>

**[《三国志·妃嫔传》仓内原文 L2412](../../sources/本地分卷/三国志/三国志-卷050.md#l2412)**

> 安坐黨魯王霸死。

**释读** 吴安卷入二宫党争受诛。

**归年** 《吴主传》《孙霸传》赤乌十三年诛鲁王党。

<a id="sgz050-b-2428-3"></a>

**[《三国志·妃嫔传》仓内原文 L2428](../../sources/本地分卷/三国志/三国志-卷050.md#l2428)**

> 赤烏十三年，亮立為太子，請出嫁夫人之姊，權聽許之。

**释读** 孙权应允孙亮所请。

**归年** 本传赤乌十三年；《吴主传》同年立亮。

<a id="sgz050-b-2430-2"></a>

**[《三国志·妃嫔传》仓内原文 L2430](../../sources/本地分卷/三国志/三国志-卷050.md#l2430)**

> 及潘夫人母子有寵，全主自以與孫和母有隙，乃勸權為潘氏男亮納夫人，亮遂為嗣。

**释读** 全主与孙和母有隙，因潘氏母子受宠进言，孙亮遂为嗣。

**归年** 《三嗣主传》赤乌十三年孙亮立储，以全氏为妃。

<a id="sgz050-b-2434-3"></a>

**[《三国志·妃嫔传》仓内原文 L2434](../../sources/本地分卷/三国志/三国志-卷050.md#l2434)**

> 太子和既廢，

**释读** 孙和储位被夺。

**归年** 《吴主传》赤乌十三年。

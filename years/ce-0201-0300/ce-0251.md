## 本年概述

魏平王凌谋立曹彪之事，王凌自杀，曹彪被赐死。司马懿同年去世，司马师继管军政。吴立潘氏为皇后，孙权入冬病重，召诸葛恪与滕胤辅太子。

## 王凌案与魏廷交接

1. **王凌谋废曹芳立曹彪，事败后二人先后身死。** 丙午，闻太尉王淩谋废帝，立楚王彪，太傅司马宣王东征淩。 五月甲寅，淩自杀。 六月，彪赐死。 [[1]](#sg-note-6)

<a id="sgz-event-26"></a>

2. **司马懿去世，司马师继掌军政。** 戊寅，太傅司马宣王薨，以衞将军司马景王为抚军大将军，录尚书事。 王基提醒万机须谨慎，建议用亲忠良，荐许允、傅嘏、袁侃、崔赞，司马师采纳。 [[2]](#sg-note-11)

3. **司马孚从尚书令升司空、太尉，郑冲继任司空。** 三月，以尚书令司马孚为司空。 辛未，以司空司马孚为太尉。 十二月，以光禄勳郑冲为司空。 [[3]](#sg-note-3)

<a id="sg-event-13"></a>

6. **骠骑将军孙资薨。** 庚子，骠骑将军孙资去世。 [[6]](#sg-note-13)

7. **有司奏诸功臣应飨食于太祖庙者。** 十一月，主管官员奏诸功臣应飨食于太祖庙者，更以官为次，太傅司马宣王功高爵尊，最在上。 [[7]](#sg-note-14)

## 南北边事

<a id="sg-event-1"></a>

<a id="sg-event-2"></a>

<a id="sg-event-4"></a>

9. **魏军攻吴荆州，安置降附，王昶进号。** 三年春正月，荆州刺史王基、新城太守州泰攻吴，破之，降者数千口。 二月，置南郡之夷陵县以居降附。 四月甲申，以征南将军王昶为征南大将军。 [[9]](#sg-note-1)

<a id="sgz-event-32"></a>

10. **邓艾建议分刘豹部、调整边地杂居。** 司马师接掌政务，邓艾建议分开刘豹势力，褒奖去卑后裔，并渐次迁出与汉民杂居的部分羌胡。司马师多从其议。 [[10]](#sgz-note-32)

## 吴在孙权病中的安排

<a id="sg-event-18"></a>

11. **吴立潘氏为后并改元太元。** 五月孙权立潘氏为皇后，赦免并改元太元。 [[11]](#sg-note-18)

<a id="sg-event-21"></a>

12. **陆抗返都治病，孙权向他说明陆逊旧案。** 陆抗本年回建业治病。病愈将还，孙权流泪承认过去听信谗言，负了陆逊，嘱陆抗把此前查问陆逊的文书销毁。 [[12]](#sg-note-21)

<a id="sg-event-22"></a>

<a id="sgz-event-25"></a>

<a id="sgz-event-27"></a>

13. **孙权病中问蜀使，召诸葛恪、滕胤辅太子。** 蜀遣校尉樊建使吴，孙权病中未能接见，便问诸葛恪来使为人。诸葛恪称樊建才识不及宗预而性情雅正。冬十一月，孙权南郊祭祀回宫后患风疾，曾想召孙和回来复立，全公主、孙峻和孙弘力争，他遂作罢。群臣属意诸葛恪辅政。孙权担心他刚愎自用，孙峻力荐。十二月，孙权征诸葛恪领太子太傅，任会稽太守滕胤为太常，命二人辅佐太子；中书令孙弘领少傅。 [[13]](#sgz-note-25)

<a id="sgz-event-28"></a>

<a id="sgz-event-29"></a>

14. **吴迎罗阳王表至建业。** 临海罗阳传有自称王表的神。五月孙权遣李崇持辅国将军、罗阳王印绶迎王表，七月抵建业，安置在苍龙门外。传文所载谈论和水旱预言属当时传闻。 [[14]](#sgz-note-28)

<a id="sg-event-20"></a>

15. **大风，江水溢流。** 吴地大风，江水上涌，渐淹城门。孙权派人察看，发现只有吕据已命人取大船防备，便嘉许他，拜为荡魏将军。 [[15]](#sg-note-20)

<a id="sgz-event-30"></a>

16. **吴十一月大赦。** 太元元年冬十一月大赦。 [[16]](#sgz-note-30)

<a id="sgz-event-31"></a>

17. **吴下诏省徭减赋。** 吴下诏减少徭役、征赋，除民所苦。 [[17]](#sgz-note-31)

19. **邓芝去世。** 邓芝卒于延熙十四年。 [[19]](#sg-note-17)

> 呂乂卒，祗又以侍中守尚書令，加鎮軍將軍，

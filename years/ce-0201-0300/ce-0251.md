<a id="sg-event-1"></a>

1. **荆州刺史王基、新城太守州泰攻吴。** 三年春正月，荆州刺史王基、新城太守州泰攻吴，破之，降者数千口。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **置南郡之夷陵县以居降附。** 二月，置南郡之夷陵县以居降附。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **以尚书令司马孚为司空。** 三月，以尚书令司马孚为司空。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **以征南将军王昶为征南大将军。** 四月甲申，以征南将军王昶为征南大将军。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **大赦。** 壬辰，大赦。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **闻太尉王淩谋废帝，立楚王彪。** 丙午，闻太尉王淩谋废帝，立楚王彪，太傅司马宣王东征淩。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **淩自杀。** 五月甲寅，淩自杀。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **彪赐死。** 六月，彪赐死。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **皇后甄氏崩。** 秋七月壬戌，皇后甄氏崩。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **以司空司马孚为太尉。** 辛未，以司空司马孚为太尉。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **太傅司马宣王薨，以衞将军司马景王为抚军大将军。** 戊寅，太傅司马宣王薨，以衞将军司马景王为抚军大将军，录尚书事。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **葬怀甄后于太清陵。** 乙未，葬怀甄后于太清陵。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **骠骑将军孙资薨。** 庚子，骠骑将军孙资去世。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **有司奏诸功臣应飨食于太祖庙者。** 十一月，主管官员奏诸功臣应飨食于太祖庙者，更以官为次，太傅司马宣王功高爵尊，最在上。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **以光禄勳郑冲为司空。** 十二月，以光禄勳郑冲为司空。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **费祎回成都后驻汉寿。** 费祎夏返成都，冬北驻汉寿，朝廷大赦。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **邓芝去世。** 邓芝卒于延熙十四年。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **吴立潘氏为后并改元太元。** 五月孙权立潘氏为皇后，赦免并改元太元。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **畅薨，追赠车骑将军。** 嘉平三年正月，畅薨，追赠车骑将军，諡曰恭侯；子绍嗣。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **大风，江水溢流。** 太元元年，大风，江水溢流，渐淹城门，权使视水，独见据使人取大船以备害。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **就都治病。** 太元元年，就都治病。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **权寝疾，诣都。** 太元元年，权寝疾，诣都，留为太常；与诺葛恪等俱受遗诏辅政。 [[22]](#sg-note-22)

<a id="sy-event-23"></a>

23. **蜀汉尚书令吕乂去世。** 曾接替董允担任尚书令的吕乂去世。 [[23]](#sy-note-23)

<a id="sgz-event-24"></a>

24. **蜀汉冬季大赦。** 本传在费祎冬驻汉寿一事以后载蜀施大赦。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **孙权病，命诸葛恪、滕胤辅太子。** 孙权冬天病重，征诸葛恪为太子太傅、会稽太守滕胤为太常，诏二人辅太子。 [[25]](#sgz-note-25)

### 6. 闻太尉王淩谋废帝，立楚王彪

[返回正文第6条](#sg-event-6)

<a id="sg004-l231-e6"></a>

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p003)** · [仓内TXT L231](../../sources/本地分卷/三国志/三国志-卷004.md#l231)

> 丙午，聞太尉王淩謀廢帝，立楚王彪，太傅司馬宣王東征淩。

<a id="sgz026-p-009-1"></a>

**[《三国志·满田牵郭传》裴注 009·1](../../sources/摘录/三国志-卷026-满田牵郭传裴注.md#pei-009-1)**

> 世語曰淮妻王凌之妹凌誅妹當從坐御史往収督將及羌胡渠帥數千人叩頭請淮表留妻淮不從

**释读** 郭淮妻是王凌之妹，依法当连坐，御史来捕；郭淮起先不答将吏和羌胡数千人恳请留妻。

**归年** 《齐王纪》嘉平三年王凌案；《世语》补郭淮一家。

<a id="sgz026-p-009-2"></a>

**[《三国志·满田牵郭传》裴注 009·2](../../sources/摘录/三国志-卷026-满田牵郭传裴注.md#pei-009-2)**

> 妻上道莫不流涕人人扼腕欲劫留之淮五子叩頭流血請淮淮不忍視乃命左右追妻於是追者數千騎數日而還淮以書白司馬宣王曰五子哀母不惜其身若無其母是無五子無五子亦無淮也今輒追還若於法未通當受罪於主者覲展在近書至宣王亦宥之

**释读** 郭淮见部众和五子哀求后派数千骑追回，称若无母则无五子也无郭淮，愿自请罪；司马懿宽许。

**归年** 同一嘉平三年王凌案，司马懿该年七月去世，为行动上限。

<a id="sg020-l1078-e8"></a>

**[《三国志·武文世王公传》](../../sources/摘录/三国志-卷020-武文世王公传.md#p002)** · [仓内TXT L1078](../../sources/本地分卷/三国志/三国志-卷020.md#l1078)

<a id="sg028-l1447-e8"></a>

**[《三国志·王毌丘诸葛邓钟传》](../../sources/摘录/三国志-卷028-王毌丘诸葛邓钟传.md#p001)** · [仓内TXT L1447](../../sources/本地分卷/三国志/三国志-卷028.md#L1447)

> 彪賜死，諸相連者悉夷三族。

<a id="sgz020-b-1078-14"></a>

**[《三国志·武文世王公传》仓内原文 L1078](../../sources/本地分卷/三国志/三国志-卷020.md#l1078)**

> 乃遣傅及侍御史就國案驗，收治諸相連及者。廷尉請徵彪治罪。於是依漢燕王旦故事，使兼廷尉大鴻臚持節賜彪璽書切責之，使自圖焉。

**释读** 遣官查案，收捕有关人员；廷尉请将曹彪召回治罪，朝廷照汉燕王旦前例，赐书令自行处置。

**归年** 《齐王纪》嘉平三年四月案发、六月赐死，处置从本条。

<a id="sgz020-b-1078-15"></a>

**[《三国志·武文世王公传》仓内原文 L1078](../../sources/本地分卷/三国志/三国志-卷020.md#l1078)**

> 彪乃自殺。妃及諸子皆免為庶人，徙平原。彪之官屬以下及監國謁者，坐知情無輔導之義，皆伏誅。國除為淮南郡。

**释读** 曹彪自尽后，妃子和诸子被免为庶人并徙平原，知情官属等伏诛，楚国改淮南郡。

**归年** 《齐王纪》嘉平三年六月赐死，随后案决及改置附同条。

<a id="sgz020-p-008-1"></a>

**[《三国志·武文世王公传》裴注 008·1](../../sources/摘录/三国志-卷020-武文世王公传裴注.md#pei-008-1)**

> 孔衍漢魏春秋載璽書曰夫先王行賞不遺仇讎用戮不違親戚至公之義也故周公流涕而决二叔之罪孝武傷懐而㫁昭平之獄古今常典也惟王國之至親作藩於外不能祇奉王度表率宗室而謀於奸邪乃與太尉王凌兗州刺史令狐愚構通逆謀圖危社稷有悖忒之心無忠孝之意宗廟有靈王其何面目以見先帝朕深痛王自陷罪辜既得王情深用憮然有司奏王當就大理朕惟公族甸師之義不忍肆王市朝故遣使者賜書王自作孽匪由於他燕刺之事宜足以觀王其自圖之

**释读** 孔衍《汉魏春秋》载诏借周公治二叔、汉武帝治昭平一类旧事，指责曹彪与王凌、令狐愚结谋，诏以宗族礼免其公开受刑，令自裁。

**归年** 《齐王纪》嘉平三年六月赐死；诏中阴谋始于249年。

### 16. 费祎回成都后驻汉寿

[返回正文第16条](#sg-event-16)

<a id="sg033-l1711-e16"></a>

**[《三国志·后主传》](../../sources/摘录/三国志-卷033-后主传.md#p005)** · [仓内TXT L1711](../../sources/本地分卷/三国志/三国志-卷033.md#l1711)

> 十四年夏，大將軍費禕還成都。冬，復北駐漢壽。大赦。

<a id="sgz033-b-1711-1"></a>

**[《三国志·后主传》仓内原文 L1711](../../sources/本地分卷/三国志/三国志-卷033.md#l1711)**

> 十四年夏，大將軍費禕還成都。冬，復北駐漢壽。

**释读** 费祎于夏天从汉中返成都，冬天向北驻于汉寿。

**归年** 本传明书延熙十四年；《费祎传》也记当年回成都。

<a id="sgz044-b-2070-5"></a>

### 25. 孙权病，命诸葛恪、滕胤辅太子

[返回正文第25条](#sgz-event-25)

<a id="sgz048-b-2336-2"></a>

**[《三国志·三嗣主传》仓内原文 L2336](../../sources/本地分卷/三国志/三国志-卷048.md#l2336)**

> 冬，權寢疾，徵大將軍諸葛恪爲太子太傅，會稽太守滕胤爲太常，並受詔輔太子。

**归年** 承251太元元年；《吴主传》十一月大将军恪为辅，《滕胤传》亦载权寝疾召胤。原252#9合叙可互链。

<a id="sgz064-b-2991-1"></a>

**[《三国志·诸葛滕二孙濮阳传》仓内原文 L2991](../../sources/本地分卷/三国志/三国志-卷064.md#l2991)**

> 久之，權不豫，而太子少，乃徵恪以大將軍領太子太傅，中書令孫弘領少傅。

**释读** 孙权病重，太子幼少，征诸葛恪领太子太傅，孙弘为少傅。

**归年** 《吴主传》太元元年十一月病、十二月征恪。

<a id="sgz064-b-3011-7"></a>

**[《三国志·诸葛滕二孙濮阳传》仓内原文 L3011](../../sources/本地分卷/三国志/三国志-卷064.md#l3011)**

> 太元元年，權寢疾，詣都，留為太常；

**释读** 孙权卧病，滕胤入都而留任太常。

**归年** 本传太元元年；《孙亮传》也明记。

<a id="sgz064-p-004-1"></a>

**[《三国志·诸葛滕二孙濮阳传》裴注 004·1](../../sources/摘录/三国志-卷064-诸葛滕二孙濮阳传裴注.md#pei-004-1)**

> 吳書曰權寝疾議所付託時朝臣咸皆注意于恪而孫峻表恪噐任輔政可付大事權嫌恪剛狠自用峻以當今朝臣皆莫及遂固保之乃徴恪

**释读** 孙权病，朝臣瞩目诸葛恪；孙权疑其刚愎，孙峻坚持无臣可代，促成召恪。

**归年** 《吴主传》太元元年十二月征诸葛恪为太子太傅。

<a id="sgz064-p-008-2"></a>

**[《三国志·诸葛滕二孙濮阳传》裴注 008·2](../../sources/摘录/三国志-卷064-诸葛滕二孙濮阳传裴注.md#pei-008-2)**

> 志林曰初權病䔍召恪輔政臨去大司馬呂岱戒之曰世方多難子毎事必十思恪答曰昔季文子三思而後行夫子曰再思可矣今君令恪十思明恪之劣也岱無以答當時咸謂之失言

**释读** 孙权病召恪，吕岱劝多思再行；恪用孔子说再思已够讥为十思显自己低劣，吕岱无言。

**归年** 承《吴主传》251十二月征恪；吕岱正式拜大司马在252，注称追称。

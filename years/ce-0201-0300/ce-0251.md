## 本年概述

魏平王凌谋立曹彪之事，王凌自杀，曹彪被赐死。司马懿同年去世，司马师继管军政。吴立潘氏为皇后，孙权入冬病重，召诸葛恪与滕胤辅太子。

## 王凌案与魏廷交接

1. **王凌谋废曹芳立曹彪，事败后二人先后身死。** 《三国志》《通鉴》记四月吴军截塞涂水，太尉王凌想借讨吴起兵，朝廷没准出兵；《晋书》把请兵记在正月，并说塞涂水是王凌的虚报。他让部属杨弘去探问兖州刺史黄华是否肯参与[废曹芳、立楚王曹彪之谋](ce-0249.md#sg-note-8)，杨弘与黄华联名告发。司马懿先下赦令，同时率中军沿水路东进，《晋书》记九日到甘城，任诸葛诞为镇东将军、督扬州军。王凌自知不敌，缴还印绶、节钺，到丘头缚手请降（《晋书》称武丘）。司马懿替他解缚，仍派兵把他押往京师。本纪又记王凌问自己若有罪，何不发一封简书相召，何必亲率大军前来；司马懿回答，正因他不是凭简书就会来的那种人。王凌经过贾逵庙，自称忠于魏国，请贾逵神灵作证。五月甲寅，王凌行至项地，服毒自尽。司马懿到寿春查办，张式等自首。朝廷另遣人到楚国查验，廷尉请将曹彪征至京师治罪。朝廷依汉燕王刘旦的旧例，遣使持节向曹彪宣示罪状。六月，曹彪自裁，妻子儿女皆降为庶人、徙平原。知情的王府官属和监国谒者被诛，楚国改为淮南郡。王凌、令狐愚家属被诛，两人被开棺陈尸示众；《晋书》概括称王凌余党皆夷三族，与曹彪被杀并叙，具体请兵、降服、王凌自尽及曹彪赐死仍按诸书月次分开。此后魏诸王公被集中安置在邺，受有司监视，彼此不得交往。黄华、杨弘因告发进封乡侯，令狐邵之子令狐华因族属疏远免坐。郭淮之妻是王凌的妹妹，原要被收押问罪。将吏、羌胡首领与郭淮的五个儿子相继请留，郭淮派人追回妻子，致书司马懿自陈愿担责，得到赦免。 **《晋书》补记：** 讨王凌时，司马昭督淮北诸军、领兵会于项，增邑三百户、假金印紫绶，随后进都督号。 [[1]](#sg-note-6)

2. **司马懿去世，司马师继掌军政。** 六月，司马懿卧病，《晋书》还记他梦见贾逵、王凌作祟，视为不祥。八月戊寅（汪曰桢推为初五），他在京师去世，年七十三；据虚岁推算生于[179年](../ce-0101-0200/ce-0179.md#jin001-note-birth)。曹芳素服亲临吊唁，命丧葬仪卫依汉霍光旧例，追赠相国、郡公；司马孚上表陈述其兄生前志愿，辞去郡公之赠和轀辌车。九月庚申（汪曰桢推为十八日）葬于河阴，谥文。依司马懿预定的终制，墓在首阳山，只作土藏，不起坟、不植树，以平时衣服入殓，不置明器，后来去世的家人也不合葬。其顾命有三篇，本纪只保存这些遗制的概述。卫将军司马师升为抚军大将军、录尚书事。王基劝司马师谨慎处理军国政务，亲近忠良，举荐许允、傅嘏、袁侃、崔赞，司马师采纳。许允以为司马懿去世后夏侯玄可以安心，夏侯玄却担心司马师、司马昭不会相容。 **《晋书》补记：** 司马懿去世后，朝议以伊尹死后伊陟承事为比，曹芳命司马师以抚军大将军辅政。 [[2]](#sg-note-11)

13. **孙权病中问蜀使，召诸葛恪、滕胤辅太子。** 蜀遣校尉樊建使吴，孙权病中未能接见，便问诸葛恪来使为人。诸葛恪称樊建才识不及宗预而性情雅正。冬十一月，孙权南郊祭祀回宫后患风疾，曾想召孙和回来复立，全公主、孙峻和孙弘力争，他遂作罢。群臣属意诸葛恪辅政。孙权担心他刚愎自用，孙峻力荐。十二月，孙权征诸葛恪领太子太傅，任会稽太守滕胤为太常，命二人辅佐太子；中书令孙弘领少傅。 [[13]](#sgz-note-25)

## 蜀汉纪事

<a id="sg-event-16"></a>

18. **费祎回成都后驻汉寿。** 夏，费祎返回成都。冬，他又向北移驻汉寿。 本传还记望气者声称成都没有宰相之位，并以此解释费祎冬季北屯；这是原书保存的望气说。 [[18]](#sg-note-16)

<a id="sg-event-17"></a>

19. **邓芝去世，邓良袭爵。** 邓芝卒于延熙十四年，儿子邓良承袭爵位。邓芝长期任将，赏罚明断、体恤士卒，又不经营私产，身后家中没有余财；这些生平总评另见[统兵品行](时期-三国志卷045-邓张宗杨传纪年待考（1）.md#shu045-l13-1)与[家计记载](时期-三国志卷045-邓张宗杨传纪年待考（1）.md#shu045-l13-2)。 [[19]](#sg-note-17)

<a id="sy-event-23"></a>

20. **吕乂去世，陈祗兼尚书令。** 尚书令吕乂去世，陈祗以侍中兼摄尚书令，加镇军将军。 [[20]](#sy-note-23)

<a id="sgz-event-24"></a>

### 1. 王凌谋废曹芳立曹彪，事败后二人先后身死

[返回正文第1条](#sg-event-6)

<a id="jin002-l90-1"></a>

**[《晉書·文帝紀》L90：司马昭参加平王凌](../../拆分史书/晋书/卷002.md#edition-jin002-l90-1)**

> 及大軍討王淩，帝督淮北諸軍事，帥師會於項。增邑三百戸，假金印紫綬。

<a id="jin001-l70"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L70)**

> 三年春正月，王淩詐言吳人塞塗水，請發兵以討之。帝潛知其計，不聽。

**釋讀與歸年** 《晋书》把王凌请求发兵系于正月，并称其“诈言”吴塞涂水；《三国志·王凌传》说“三年春，吴贼塞涂水”，《三少帝纪》及《通鉴》卷075在四月叙事发。正文沿既有四月事件链，保留正月及真伪之异，不把吴塞水径改成已证实的虚报。

<a id="jin001-l71"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L71)**

> 夏四月，帝自帥中軍，汎舟沿流，九日而到甘城。淩計無所出，乃迎於武丘，面縛水次，曰：「淩若有罪，公當折簡召淩，何苦自來邪！」帝曰：「以君非折簡之客故耳。」即以淩歸於京師。道經賈逵廟，淩呼曰：「賈梁道！王淩是大魏之忠臣，惟爾有神知之。」至項，仰鴆而死。收其餘黨，皆夷三族，並殺彪。悉錄魏諸王公置於鄴，命有司監察，不得交關。

**釋讀與歸年** 本段从四月司马懿出军起，连叙王凌死、诛连与曹彪死，不能全压在四月。《三少帝纪》明记五月甲寅王凌自尽、六月赐曹彪死；拘诸王于邺亦随六月处置。甘城、武丘与《王凌传》《通鉴》的百尺、丘头各按原文保存；呼贾逵庙语是本纪所载临死言语。

**《王毋丘諸葛鄧鍾傳》互見** [诸葛诞任扬州刺史、昭武将军](../../拆分史书/三国志/卷028.md#edition-wei028-l64-2)

<a id="wei028-l17-1"></a>

**[《三國志·王毋丘諸葛鄧鍾傳》正文](../../拆分史书/三国志/卷028.md#edition-wei028-l17-1)** · [TXT L17](../../拆分史书/三国志/卷028.txt#L17)

> 三年春，吳賊塞涂水。淩欲因此發，大嚴諸軍，表求討賊；詔報不聽。淩陰謀滋甚，遣將軍楊弘以廢立事告兖州刺史黃華，華、弘連名以白太傅司馬宣王。宣王將中軍乘水道討淩，先下赦赦淩罪，又將尚書廣東，使爲書喻淩，大軍掩至百尺逼淩。淩自知勢窮，乃乘船單出迎宣王，遣掾王彧謝罪，送印綬、節鉞。軍到丘頭，淩靣縛水次。宣王承詔遣主簿解縛反服，見淩，慰勞之，還印綬、節鉞，遣步騎六百人送還京都。淩至項，飲藥死。

**釋讀與歸年** 嘉平三年吳塞涂水，王淩欲借討吳起事，魏不許。他使楊弘探兗州刺史黃華，二人聯名告司馬懿。司馬懿先赦再率水軍迫近，王淩交印節、於丘頭面縛，解縛後仍被送京，行至項飲藥死。以《三少帝紀》四月事發、五月甲寅自盡為時標。

<a id="wei028-l18-1"></a>

**[《三國志·王毋丘諸葛鄧鍾傳》裴注](../../拆分史书/三国志/卷028.md#edition-wei028-l18-1)** · [TXT L18](../../拆分史书/三国志/卷028.txt#L18)

> 魏畧載淩與太傅書曰：「卒聞神軍密發，巳在百尺，雖知命窮盡，遲於相見，身首分離，不以爲恨，前後遣使，有書未得還報，企踵西望，無物以譬。昨遣書之後，便乘船來相迎宿丘頭，旦發於浦口，奉被露布赦書，又得二十三日況，累紙誨示，聞命驚愕，五內失守，不知何地可以自處？僕乆忝朝恩，歷試無効，統御戎馬，董齊東夏，事有闕廢，中心犯義，罪在三百，妻子同縣，無所禱矣。不圖聖恩天覆地載，橫蒙視息，復覩日月。亡甥令狐愚攜惑群小之言，僕即時呵抑，使不得竟其語。旣人已知，神明所鑒，夫非事無陰，卒至發露，知此梟夷之罪也。生我者父母，活我者子也。」又重曰：「身陷刑罪，謬蒙赦宥。今遣掾送印綬，頃至，當如詔書自縛歸命。雖足下私之，官法有分。」及到，如書。太傅使人解其縛。淩旣蒙赦，加怙舊好，不復自疑，徑乘小船自趣太傅。太傅使人逆止之，住船淮中，相去十餘丈。淩知見外，乃遙謂太傅曰：「卿直以折簡召我，我當敢不至邪？而乃引軍來乎！」太傅曰：「以卿非肯逐折簡者故也。」淩曰：「卿負我！」太傅曰：「我寧負卿，不負國家。」遂使人送來西。淩自知罪重，試索棺釘，以觀太傅意，太傅給之。淩行到項，夜呼掾屬與決曰：「行年八十，身名並滅邪！」遂自殺。干寶晉紀曰：淩到項，見賈逵祠在水側，淩呼曰：「賈梁道，王淩固忠於魏之社稷者，唯尔有神，知之。」

**釋讀與歸年** 《魏略》載王淩降前致司馬懿兩封書、隔船相問、索棺釘及自盡。干寶《晉紀》另載臨死經賈逵祠自稱忠於魏，均隨本案。

> 延熈十四年卒。

**释读** 吕乂在延熙十四年去世。

**归年与互校** 本传明记延熙十四年，即251年；与本卷陈祗继任尚书令相互印证。

> 呂乂卒，祗又以侍中守尚書令，加鎮軍將軍，

**释读** 吕乂去世后，陈祗又以侍中兼摄尚书令，加镇军将军。

**归年与互校** 本卷[《吕乂传》](../../拆分史书/三国志/卷039.md#txt-l69)明书延熙十四年卒；[《通鉴》卷七十五](../../史书/025-资治通鉴/KR2b0007_075.txt)在251年记陈祗接任。加将军随同事附叙，未载月日。

<a id="jin001-note-251"></a>

### 22. 司马懿辞相国、安平郡公。

[返回正文第22条](#jin001-event-l72)

<a id="jin001-l72"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L72)**

> 天子遣侍中韋誕持節勞軍於五池。帝至自甘城，天子又使兼大鴻臚、太僕庾嶷持節，策命帝為相國，封安平郡公，孫及兄子各一人為列侯，前後食邑五萬戶，侯者十九人。固讓相國、郡公不受。

**釋讀與歸年** 本段在王凌案后、六月寝疾前，归251年；本卷未另记授命的月日。“前后食邑五万户”及“侯者十九人”是累计数，不写成本次单独新封十九侯。

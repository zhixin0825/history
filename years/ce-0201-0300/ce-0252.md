<a id="sg-event-1"></a>

1. **以抚军大将军司马景王为大将军。** 四年春正月癸卯，以抚军大将军司马景王为大将军。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **立皇后张氏，大赦。** 二月，立皇后张氏，大赦。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **鱼二，见于武库屋上。** 夏五月，鱼二，见于武库屋上。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **诏征南大将军王昶、征东将军胡遵、镇南将军毋丘俭等征吴。** 冬十一月，诏征南大将军王昶、征东将军胡遵、镇南将军毋丘俭等征吴。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **东兴之战。** 魏派王昶、胡遵、毌丘俭等分路攻吴。十二月，诸葛恪在东兴击败魏军，魏纪称交战地为东关。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>



<a id="sg-event-7"></a>

7. **刘琮受封西河王。** 孙权去世同年，刘禅封子刘琮为西河王。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **吴改元神凤，孙权去世。** 二月吴改元神凤，潘后去世，孙权四月去世，葬蒋陵。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **孙亮继位，诸葛恪与滕胤辅政。** 孙权病重时召诸葛恪、滕胤辅储；死后孙亮即位改元建兴。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **命禕开府。** 延熙十五年，命禕开府。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **封琅邪王，居虎林。** 太元二年正月，封琅邪王，居虎林。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **迁镇东将军。** 建兴元年，迁镇东将军。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **迁镇南将军。** 建兴元年，迁镇南将军。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **拜奋威将军。** 建兴元年，拜奋威将军。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **立爲齐王，居武昌。** 太元二年，立爲齐王，居武昌。 [[15]](#sg-note-15)

<a id="sgz-event-16"></a>

16. **征调之议引起雁门、新兴反抗。** 陈泰请并州合兵讨诸葛恪，雁门、新兴以为将远戍而反。司马师称应自负其责，魏人因此愿报效。 [[16]](#sgz-note-16)

<a id="sgz-event-17"></a>

17. **司马师任李丰为中书令。** 嘉平四年，司马懿死后中书令出缺，司马师询朝臣后用李丰；李丰虽然知道并非显选，仍欲亲近天子而接受。 [[17]](#sgz-note-17)

<a id="sgz-event-18"></a>

18. **孙权封孙和为南阳王、遣居长沙。** 孙和封南阳王。 [[18]](#sgz-note-18)

<a id="sgz-event-19"></a>

19. **孙权死后，诸葛恪令孙奋离开长江军事重地。** 太傅诸葛恪令孙奋改居豫章，孙奋不从，并多次逾越法度。 [[19]](#sgz-note-19)

<a id="sgz-event-20"></a>

20. **施绩升镇东将军。** 施绩迁为镇东将军。 [[20]](#sgz-note-20)

<a id="sgz-event-21"></a>

21. **朱异升镇南将军。** 孙亮建兴元年，朱异任镇南将军。 [[21]](#sgz-note-21)

<a id="sgz-event-22"></a>

22. **吴报大风雷电。** 十二月朔丙申，大风并有雷电。 [[22]](#sgz-note-22)

<a id="sgz-event-23"></a>

23. **武昌端门、内殿两次火灾。** 同在十二月，雷雨中武昌端门火灾，改修后内殿又火灾。 [[23]](#sgz-note-23)

<a id="sgz-event-24"></a>

24. **诸葛恪重作武昌宫，裴松之辨火灾所焚。** 《吴录》说诸葛恪拟迁都而另起武昌宫。裴松之据此认为252受灾的端门、内殿是新宫。 [[24]](#sgz-note-24)

> 漢晉春秋曰毌丘儉王昶聞東軍敗各燒屯走朝議欲貶黜諸將景王曰我不聽公休以至於此此我過也諸將何罪悉原之時司馬文王為監軍統諸軍惟削文王爵而已

**释读** 《汉晋春秋》载毌丘俭、王昶闻东路军败即烧屯撤走；司马师拒绝贬罚诸将并自承未听诸葛诞，只削监军司马昭爵。

**归年** 承嘉平四年冬东兴战败，原注与前注的纳议说相左。处分实月未载；另见《晋书·文帝纪》。

<a id="sgz055-b-2615-5"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2615](../../sources/本地分卷/三国志/三国志-卷055.md#l2615)**

> 東興之役，綜爲前鋒，軍敗身死，諸葛恪斬送其首，以白權廟。

**释读** 韩综担当前锋，东兴败后身死，诸葛恪取首报于孙权庙。

**归年** 《三嗣主传》建兴元年十二月载东兴破魏军杀韩综。

<a id="sgz055-b-2669-1"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2669](../../sources/本地分卷/三国志/三国志-卷055.md#l2669)**

> ﻿魏遣諸葛誕、胡遵等攻東興，諸葛恪率軍拒之。諸將皆曰：「敵聞太傅自來，上岸必遁走。」奉獨曰：「不然。彼動其境內，悉許、洛兵大舉而來，必有成規，豈虛還哉？無恃敵之不至，恃吾有以勝之。」及恪上岸，奉與將軍唐咨、呂據、留贊等，俱從山西上。奉曰：「今諸軍行遲，若敵據便地，則難與爭鋒矣。」乃辟諸軍使下道，帥麾下三千人徑進。時北風，奉舉帆二日至，遂據徐塘。天寒雪，敵諸將置酒高會，奉見其前部兵少，相謂曰：「取封侯爵賞，正在今日！」乃使兵解鎧著冑，持短兵。敵人從而笑焉，不爲設備。奉縱兵斫之，大破敵前屯。會據等至，魏軍遂潰。遷滅寇將軍，進封都鄉侯。

**释读** 丁奉建议急据徐塘，乘北风先到，遇雪带精兵轻装击魏，吕据等赶到后魏军大溃。丁奉获迁官封侯。

**归年** 《三嗣主传》建兴元年十二月系东兴之战，《诸葛恪传》互证。

<a id="sgz011-p-023-2"></a>

**[《三国志·袁张凉国田王邴管传》裴注 023·2](../../sources/摘录/三国志-卷011-袁张凉国田王邴管传裴注.md#pei-023-2)**

> 東關之敗文王曰近日之事誰任其咎儀曰責在軍帥文王怒曰司馬欲委罪扵孤耶遂殺之

**释读** 司马昭问谁应对东关败兵负责，王仪答主帅之责，司马昭以为归罪于自己，杀了王仪。

**归年** 《晋书·五行志》以嘉平四年东关败应武库鱼异，《晋书·王裒传》确定两事相连。

<a id="sgz056-b-2701-10"></a>

**[《三国志·朱治朱然吕范朱桓传》仓内原文 L2701](../../sources/本地分卷/三国志/三国志-卷056.md#l2701)**

> 魏出東興，據赴討有功。

**释读** 魏军攻东兴，吕据到战场应敌有功。

**归年** 《三嗣主传》建兴元年冬十二月。

<a id="sgz048-b-2337-2"></a>

**[《三国志·三嗣主传》仓内原文 L2337](../../sources/本地分卷/三国志/三国志-卷048.md#l2337)**

> 冬十月，太傅恪率軍遏巢湖，城東興，使將軍全端守西城，都尉留略守東城。

**释读** 诸葛恪率兵挡巢湖水，筑东兴城，全端守西城，留略守东城。

**归年** 本传建兴元年冬十月，《诸葛恪传》同年筑两城。

<a id="sgz048-b-2337-4"></a>

**[《三国志·三嗣主传》仓内原文 L2337](../../sources/本地分卷/三国志/三国志-卷048.md#l2337)**

> 魏使將軍諸葛誕、胡遵等步騎七萬圍東興，將軍王昶攻南郡，毌丘儉向武昌。甲寅，恪以大兵赴敵。戊午，兵及東興，交戰，大破魏軍，殺將軍韓綜、桓嘉等。

**释读** 魏派诸葛诞、胡遵围东兴，王昶攻南郡，毌丘俭趋武昌。诸葛恪甲寅赴敌，戊午交战大胜，杀韩综、桓嘉等。

**归年** 《齐王纪》《诸葛恪传》《通鉴》卷075嘉平四年，东兴与东关名称并存。

<a id="sgz064-b-2995-5"></a>

**[《三国志·诸葛滕二孙濮阳传》仓内原文 L2995](../../sources/本地分卷/三国志/三国志-卷064.md#l2995)**

> 魏以吳軍入其疆土，恥於受侮，命大將胡遵、諸葛誕等率眾七萬，欲攻圍兩塢，圖壞堤遏。恪興軍四萬，晨夜赴救。

**释读** 魏以吴军入境，遣胡遵、诸葛诞等攻两城并欲毁堤；诸葛恪领四万兼程驰援。

**归年** 《齐王纪》《孙亮传》252年冬；吴纪及本传魏军七万，《通鉴》作十万。

<a id="sgz064-b-2995-6"></a>

**[《三国志·诸葛滕二孙濮阳传》仓内原文 L2995](../../sources/本地分卷/三国志/三国志-卷064.md#l2995)**

> 遵等敕其諸軍作浮橋度，陳於堤上，分兵攻兩城。城在高峻，不可卒拔。

**释读** 胡遵等借浮桥渡兵，在堤上布阵，分攻两座地势高险的城，没有攻下。

**归年** 同次东兴关战。

### 19. 孙权死后，诸葛恪令孙奋离开长江军事重地

[返回正文第19条](#sgz-event-19)

<a id="sgz059-b-2835-3"></a>

**[《三国志·吴主五子传》仓内原文 L2835](../../sources/本地分卷/三国志/三国志-卷059.md#l2835)**

> 權薨，太傅諸葛恪不欲諸王處江濵兵馬之地，徙奮於豫章。奮怒，不從命，又數越法度。

**归年** 《通鉴》卷075在孙权死后、建兴元年252记其事。

<a id="sgz059-b-2835-4"></a>

**[《三国志·吴主五子传》仓内原文 L2835](../../sources/本地分卷/三国志/三国志-卷059.md#l2835)**

> 恪上牋諫曰：「帝王之尊，與天同位，是以家天下，臣父兄，四海之內，皆爲臣妾。仇讎有善，不得不舉，親戚有惡，不得不誅，所以承天理物，先國後身，蓋聖人立制，百代不易之道也。昔漢初興，多王子弟至於太彊，輒爲不軌，上則幾危社稷，下則骨肉相殘，其後懲戒，以爲大諱。自光武以來，諸王有制，惟得自娛於宮內，不得臨民，干與政事，其與交通，皆有重禁，遂以全安，各保福祚。此則前世得失之驗也。近袁紹、劉表各有國土，土地非狹，人衆非弱，以適庶不分，遂滅其宗祀。此乃天下愚智，所共嗟痛。大行皇帝覽古戒今，防芽遏萌，慮於千載。是以寢疾之日，分遣諸王，各早就國，詔策殷勤，科禁嚴峻，其所戒勑，無所不至，誠欲上安宗廟，下全諸王，使百世相承，無凶國害家之悔也。大王宜上惟太伯順父之志，中念河間獻王、東海王彊恭敬之節，下當裁抑驕恣荒亂以爲警戒。

**释读** 举汉诸王、袁绍刘表分嫡庶而败等，劝遵孙权生前所定约束。

**归年** 承252改徙任务。《通鉴》卷075同次事件。

<a id="sgz059-b-2835-5"></a>

**[《三国志·吴主五子传》仓内原文 L2835](../../sources/本地分卷/三国志/三国志-卷059.md#l2835)**

> 而聞頃至武昌以來，多違詔勑，不拘制度，擅發諸將兵治護宮室。又左右常從有罪過者，當以表聞，公付有司，而擅私殺，事不明白。大司馬呂岱親受先帝詔勑，輔導大王，旣不承用其言，令懷憂怖。華錡先帝近臣，忠良正直，其所陳道，當納用之，而聞怒錡，有收縛之語。又中書楊融，親受詔勑，所當恭肅，雲『正自不聽禁，當如我何』？聞此之日，大小驚怪，莫不寒心。里語曰：『明鏡所以照形，古事所以知今。』

**释读** 指出孙奋不听吕岱、华锜、杨融劝阻。

**归年** 同一252谏牋，所列旧事不从该日。

<a id="sgz059-b-2835-6"></a>

**[《三国志·吴主五子传》仓内原文 L2835](../../sources/本地分卷/三国志/三国志-卷059.md#l2835)**

> 大王宜深以魯王爲戒，改易其行，戰戰兢兢，盡敬朝廷，如此則無求不得。若棄忘先帝法教，懷輕慢之心，臣下寧負大王，不敢負先帝遺詔，寧爲大王所怨疾，豈敢忘尊主之威，而令詔勑不行於藩臣邪？此古今正義，大王所照知也。夫福來有由，禍來有漸，漸生不憂，將不可悔。向使魯王早納忠直之言，懷驚懼之慮，享祚無窮，豈有滅亡之禍哉？夫良藥苦口，惟疾者能甘之。忠言逆耳，惟達者能受之。今者恪等慺慺欲爲大王除危殆於萌芽，廣福慶之基原，是以不自知言至，願蒙三思。」

**释读** 请孙奋尽礼改过，太傅坚称必须执行孙权遗诏。

**归年** 同一谏牋后段。

<a id="sgz059-b-2836-1"></a>

**[《三国志·吴主五子传》仓内原文 L2836](../../sources/本地分卷/三国志/三国志-卷059.md#l2836)**

**释读** 得诸葛恪书后移居南昌，游猎却日甚。

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **大赦。** 五年夏四月，大赦。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **吴太傅诸葛恪围合肥新城。** 五月，吴太傅诸葛恪围合肥新城，诏太尉司马孚拒之。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **恪退还。** 秋七月，恪退还。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **诏曰“故中郎西平郭修”。** 八月，诏曰：「故中郎西平郭修，砥节厉行，秉心不回。乃者蜀将姜维寇钞修郡，为所执略。往岁伪大将军费禕驱率群衆，阴图闚𨵦，道经汉寿，请会衆賔，修于广坐之中手刃击禕，勇过聂政，功逾介子，可谓杀身成仁，释生取义者矣。夫追加襃宠，所以表扬忠义；祚及后胤，所以奖劝将来。其追封修为长乐乡侯，食邑千户，谥曰威侯；子袭爵，加拜奉车都尉；赐银千鉼，绢千匹，以光宠存亡，永垂来世焉。」 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **费祎遇刺。** 费祎在汉寿被魏降人郭循杀死。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **姜维围南安。** 姜维率军围南安，未克撤兵。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>



<a id="sg-event-8"></a>

8. **孙峻伏杀诸葛恪。** 冬十月大飨，孙峻在殿内设伏杀诸葛恪，随后封富春侯、任丞相。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **孙峻夺南阳王印绶并逼死孙和。** 孙峻在诸葛恪被杀后夺孙和印绶，迁其新都，派使者赐死。 [[9]](#sg-note-9)

<a id="sgz-event-10"></a>

10. **诸葛恪被杀后，孙奋杀劝阻的谢慈等。** 孙奋到芜湖拟赴建业，谢慈等阻劝被杀，孙奋废为庶人、徙章安。 [[10]](#sgz-note-10)

<a id="sgz-event-11"></a>

11. **孙亮立全夫人为皇后。** 父全尚升官封都亭侯。 [[11]](#sgz-note-11)

<a id="sgz-event-12"></a>

12. **魏王昶等退，吴军自东兴返并封赏。** 庚午魏王昶等退兵，二月吴军从东兴回来，普遍酬赏。 [[12]](#sgz-note-12)

<a id="sgz-event-13"></a>

13. **春申见大鸟，吴据此改次年年号。** 十一月有五只大鸟出现在春申，用来改下一年为五凤。 [[13]](#sgz-note-13)

**[《三国志·三少帝纪》仓内原文 L236](../../sources/本地分卷/三国志/三国志-卷004.md#l236)**

> 昔諸葛恪圍合肥新城，城中遣士劉整出圍傳消息，為賊所得，考問所傳，語整曰：『諸葛公欲活汝，汝可具服。』整罵曰：『死狗，此何言也！我當必死為魏國鬼，不苟求活，逐汝去也。欲殺我者，便速殺之。』終無他辭。又遣士鄭像出城傳消息，或以語恪，恪遣馬騎尋圍跡索，得像還。四五人靮頭靣縛，將繞城表，勑語像，使大呼，言『大軍已還洛，不如早降。』像不從其言，更大呼城中曰：『大軍近在圍外，壯士努力！』賊以刀築其口，使不得言，像遂大呼，令城中聞知。整、像為兵，能守義執節，子弟宜有差異。」

**释读** 吴围合肥时刘整、郑像冒险出城报信，被捕后拒供或高喊援军就在城外，以安守城军。附引奏末请加褒奖。

**归年** 所叙在嘉平五年（253）围新城时；毌丘俭在254年追奏。

<a id="sgz004-p-011-2"></a>

**[《三国志·三少帝纪》裴注 011·2](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-011-2)**

> 及諸葛恪圍城特與將軍樂方等三軍衆合有三千人吏兵疾病及戰死者過半而恪起土山急攻城將陷不可䕶特乃謂吳人曰今我無心復戰也然魏法被攻過百日而救不至者雖降家不坐也自受敵以來已九十餘日矣此城中本有四千餘人而戰死者已過半城雖陷尚有半人不欲降我當還為相語之條名别善惡明日早送名且持我印綬去以為信乃投其印綬以與之吳人聽其辭而不取印綬不攻頃之特還乃夜徹諸屋材柵補其缺為二重明日謂吳人曰我但有鬬死耳吳人大怒進攻之不能㧞遂引去

**释读** 诸葛恪围城，张特与乐方约三千人守御，伤病过半；张特声称守满百日后可按魏例投降，用印绶取信，趁缓攻夜修工事再拒战，吴最终撤退。

**归年** 嘉平五年围城。同役见《诸葛恪传》《通鉴》。

<a id="sgz064-b-2997-1"></a>

**[《三国志·诸葛滕二孙濮阳传》仓内原文 L2997](../../sources/本地分卷/三国志/三国志-卷064.md#l2997)**

> 夫天無二日，土無二王，王者不務兼併天下而欲垂祚後世，古今未之有也。昔戰國之時，諸候自恃兵強地廣，互有救援，謂此足以傳世，人莫能危。恣情從懷，憚於勞苦，使秦漸得自大，遂以並之，此既然矣。近者劉景昇在荊州，有眾十萬，財谷如山。不及曹操尚微，與之力競，坐觀其強大，吞滅諸袁，北方都定之後，操率三十萬眾來向荊州，當時雖有吞智者，不能復為畫計，於是景升兒子，交臂請降，遂為囚虜。凡敵國欲相吞，即仇讎欲相除也，有仇而長之，禍不在己，則在後人，不可不為遠慮也。

**释读** 诸葛恪以战国诸侯坐视秦强、刘表坐视曹操发展而子辈投降为例，论仇敌不能任其坐大。

**归年** 《通鉴》卷七十六253年收文，内述事为回顾。

<a id="sgz064-b-2997-2"></a>

**[《三国志·诸葛滕二孙濮阳传》仓内原文 L2997](../../sources/本地分卷/三国志/三国志-卷064.md#l2997)**

> 昔伍子胥曰：『越十年生聚，十年教訓，二十年之外，吳其為沼乎！』夫差自恃強大，聞此邈然，是以誅子胥而無備越之心，至於臨敗悔之，豈有及乎？越小於吳，尚為吳禍，況其強大者邪？昔秦但得關西耳，尚以併吞六國，今賊皆得秦趙、韓、魏、燕齊九州之地，地悉戎馬之鄉，士林之藪。今以魏比古之秦，土地數倍；以吳與蜀比古穴國，不能半之。

**释读** 以夫差轻视越、杀伍员而亡吴作譬，认为曹魏国土和兵马之源超过秦，也胜于吴蜀。

**归年** 同一253年论。

<a id="sgz064-b-2997-3"></a>

**[《三国志·诸葛滕二孙濮阳传》仓内原文 L2997](../../sources/本地分卷/三国志/三国志-卷064.md#l2997)**

> 然所以能敵之，但以操時兵眾於今適盡，而後生者未悉長大，正是賊衰少未盛之時。加司馬懿先誅王淩，續自隕斃，其子幼弱，而專彼大任，雖有智計之士，未得施用。當今伐之，是其厄會。聖人急於趨時，誠謂今日。若順眾人之情，懷偷安之計，以為長江之險可以傳世；不論魏之終始，而以今日遂輕其後。此吾所以長歎息者也。

**释读** 说曹操旧兵刚老去、新兵未长，司马懿诛王凌后去世，其子承位不足服众；主张乘此进兵。

**[《三国志·诸葛滕二孙濮阳传》仓内原文 L3014](../../sources/本地分卷/三国志/三国志-卷064.md#l3014)**

> 滕胤以恪子竦妻父辭位。峻曰：「鯀、禹罪不相及，滕侯何為？」峻、胤雖內不沾洽，而外相包容，進胤爵高密侯，共事如前。

**释读** 滕胤因是诸葛恪子竦岳父请辞，孙峻以鲧禹不相坐拒绝，外表与之相容，晋爵高密侯。

**归年** 承253诸葛恪诛后政局。

<a id="sgz064-b-3020-2"></a>

**[《三国志·诸葛滕二孙濮阳传》仓内原文 L3020](../../sources/本地分卷/三国志/三国志-卷064.md#l3020)**

> 初，峻從弟慮與諸葛恪之謀，峻厚之，至右將軍、無難督，授節蓋，平九官事。

**释读** 孙峻从弟参与诸葛恪案，得孙峻厚待，后任右将军、无难督、平九官事。

**归年** 《通鉴》卷七十七回叙253参与诛恪；后任各职年不独立确定；仓本「慮」从《孙亮传》与《通鉴》为孙宪。

<a id="sgz064-p-006-1"></a>

**[《三国志·诸葛滕二孙濮阳传》裴注 006·1](../../sources/摘录/三国志-卷064-诸葛滕二孙濮阳传裴注.md#pei-006-1)**

> 吳歴曰張約朱恩密䟽告恪恪以示滕〔四库字图2596〕〔四库字图2596〕勸恪還恪曰峻小子何能為邪但恐因酒食中人耳乃以藥酒入

**释读** 张约朱恩提醒，恪把密书给滕胤看；滕胤劝回，恪认为孙峻不能成事，只怕酒食，带药酒入宫。

**归年** 《通鉴》卷七十六从《吴历》，与正文滕胤劝其赴宴一异。

<a id="sgz064-p-007-1"></a>

**[《三国志·诸葛滕二孙濮阳传》裴注 007·1](../../sources/摘录/三国志-卷064-诸葛滕二孙濮阳传裴注.md#pei-007-1)**

> 吳録曰峻提刀稱詔收恪亮起立曰非我所為非我所為乳母引亮還内

**释读** 《吴录》称孙峻持刀称诏时，孙亮起身说不是自己所为，乳母牵入内。

**归年** 同一253年宫宴的异说。

<a id="sgz064-p-007-2"></a>

**[《三国志·诸葛滕二孙濮阳传》裴注 007·2](../../sources/摘录/三国志-卷064-诸葛滕二孙濮阳传裴注.md#pei-007-2)**

> 吳歴云峻先引亮入然後出稱詔與夲傳同

**释读** 《吴历》说孙峻先促孙亮进内才出称诏，与正文相近。

**归年** 同一253年宫宴的另一说法。

<a id="sgz064-p-008-1"></a>

**[《三国志·诸葛滕二孙濮阳传》裴注 008·1](../../sources/摘录/三国志-卷064-诸葛滕二孙濮阳传裴注.md#pei-008-1)**

> 搜神記曰恪入已被殺其妻在室使婢語曰汝何故血臰婢曰不也有頃愈劇又問婢曰汝眼目視瞻何以不常婢蹷然起躍頭至于棟攘臂切齒而言曰諸葛公乃為孫峻所殺于是大小知恪死矣而吏兵尋至

**释读** 书载恪妻闻婢有血腥味，婢突然跳高呼诸葛恪为孙峻所杀，官兵随至。

**归年** 附253年被杀，属志怪传闻。

<a id="sgz064-p-009-1"></a>

**[《三国志·诸葛滕二孙濮阳传》裴注 009·1](../../sources/摘录/三国志-卷064-诸葛滕二孙濮阳传裴注.md#pei-009-1)**

> 吳録曰恪時年五十一

**释读** 诸葛恪遇害时五十一岁。

**归年** 附传253年被杀。

<a id="sgz064-p-015-1"></a>

**[《三国志·诸葛滕二孙濮阳传》裴注 015·1](../../sources/摘录/三国志-卷064-诸葛滕二孙濮阳传裴注.md#pei-015-1)**

> 吳録曰羣臣上奏共推峻為太尉議〔四库字图2596〕為司徒時有娟峻者以為大統宜在公族若滕〔四库字图2596〕為亞公聲名素重衆心所附不可貳也乃表以峻為丞相又不置御史大夫士人皆失望矣

**释读** 公议欲奉孙峻为太尉、滕胤为司徒；有人称政统宜归宗室，又怕滕胤声望为第二位重臣，遂表孙峻为相且不设御史大夫，士人失望。

**归年** 《孙亮传》建兴二年诛恪后任孙峻丞相；字图为胤。

<a id="sgz035-b-1784-5"></a>

**[《三国志·诸葛亮传》仓内原文 L1784](../../sources/本地分卷/三国志/三国志-卷035.md#l1784)**

> 諸葛恪見誅於吳，子孫皆盡，

**释读** 诸葛恪获罪，全家被杀。

**归年** 《孙亮传》建兴二年冬十月，253年；诸葛攀还宗另为后续。

<a id="sgz058-p-013-2"></a>

**[《三国志·陆逊传》裴注 013·2](../../sources/摘录/三国志-卷058-陆逊传裴注.md#pei-013-2)**

> 恪誅景母坐見黜

**释读** 诸葛恪被诛，陆景母连坐见黜。

**归年** 《孙亮传》建兴二年十月杀恪。

### 9. 孙峻夺南阳王印绶并逼死孙和

[返回正文第9条](#sg-event-9)

<a id="sg059-l2828-e9"></a>

**[《三国志·吴主五子传》](../../sources/摘录/三国志-卷059-吴主五子传.md#p003)** · [仓内TXT L2828](../../sources/本地分卷/三国志/三国志-卷059.md#l2828)

> 及恪被誅，孫峻因此奪和璽綬，徙新都，又遣使者賜死。

**归年与互校** 行首的太元二年是封和为王及孙权卒（252），本句承孙峻诛诸葛恪（253），不归252。

<a id="sgz059-b-2828-4"></a>

**[《三国志·吴主五子传》仓内原文 L2828](../../sources/本地分卷/三国志/三国志-卷059.md#l2828)**

> 及恪被誅，孫峻因此奪和璽綬，徙新都，又遣使者賜死。和與妃張辭別，張曰：「吉凶當相隨，終不獨生活也。」亦自殺，舉邦傷焉。

**释读** 诸葛恪被杀后，孙峻夺孙和印绶，把他迁新都后赐死，张妃自杀。

**归年** 《三嗣主传》建兴二年，《通鉴》卷076同年。

<a id="sgz050-b-2434-6"></a>

**[《三国志·妃嫔传》仓内原文 L2434](../../sources/本地分卷/三国志/三国志-卷050.md#l2434)**

> 峻素媚事全主，全主與和母有隙，遂勸峻徙和居新都，遣使賜死，嫡妃張氏亦自殺。何姬曰：「若皆從死，誰當養孤？」遂拊育皓及其三弟。

**释读** 孙和迁新都后赐死，张妃自杀，何姬为养孙皓兄弟而活。

**归年** 《孙和传》及《通鉴》卷076明确系诸葛恪被杀后，建兴二年。

<a id="sgz048-p-019-2"></a>

**[《三国志·三嗣主传》裴注 019·2](../../sources/摘录/三国志-卷048-三嗣主传裴注.md#pei-019-2)**

> 呉録曰陟字子上丹陽人初為中書郎孫峻使詰南陽王和令其引分陟宻使令正辭自理峻怒陟懼閉門不出

**释读** 纪陟早为中书郎，孙峻遣他向南阳王孙和问责，他暗请孙和用正辞自理，孙峻发怒，纪陟不敢出门。

**归年** 《孙和传》建兴二年孙峻杀诸葛恪后处置孙和；纪陟生平字号随此事引起。

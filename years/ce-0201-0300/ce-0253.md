# 公元253年｜魏嘉平五年／蜀延熙十六年／吴建兴二年

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **大赦。** 五年夏四月，大赦。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **吴太傅诸葛恪围合肥新城。** 五月，吴太傅诸葛恪围合肥新城，诏太尉司马孚拒之。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **恪退还。** 秋七月，恪退还。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **诏曰“故中郎西平郭修”。** 八月，诏曰：「故中郎西平郭修，砥节厉行，秉心不回。乃者蜀将姜维寇钞修郡，为所执略。往岁伪大将军费禕驱率群衆，阴图闚𨵦，道经汉寿，请会衆賔，修于广坐之中手刃击禕，勇过聂政，功逾介子，可谓杀身成仁，释生取义者矣。夫追加襃宠，所以表扬忠义；祚及后胤，所以奖劝将来。其追封修为长乐乡侯，食邑千户，谥曰威侯；子袭爵，加拜奉车都尉；赐银千鉼，绢千匹，以光宠存亡，永垂来世焉。」 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **费祎遇刺。** 费祎在汉寿被魏降人郭循杀死。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **姜维围南安。** 姜维率军围南安，未克撤兵。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **费祎遇刺。** 延熙十六年新岁宴，魏降人郭循持刃杀费祎，蜀谥为敬侯。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **孙峻伏杀诸葛恪。** 冬十月大飨，孙峻在殿内设伏杀诸葛恪，随后封富春侯、任丞相。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **孙峻夺南阳王印绶并逼死孙和。** 孙峻在诸葛恪被杀后夺孙和印绶，迁其新都，派使者赐死。 [[9]](#sg-note-9)

### 4. 诏曰“故中郎西平郭修”

[返回正文第4条](#sg-event-4)

<a id="sg004-l234-e4"></a>

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p003)** · [仓内TXT L234](../../sources/本地分卷/三国志/三国志-卷004.md#L234)

> 八月，詔曰：「故中郎西平郭脩，砥節厲行，秉心不回。乃者蜀將姜維寇鈔脩郡，為所執略。往歲偽大將軍費禕驅率羣衆，陰圖闚𨵦，道經漢壽，請會衆賔，脩於廣坐之中手刃擊禕，勇過聶政，功逾介子，可謂殺身成仁，釋生取義者矣。夫追加襃寵，所以表揚忠義；祚及後胤，所以獎勸將來。其追封脩為長樂鄉侯，食邑千戶，謚曰威侯；子襲爵，加拜奉車都尉；賜銀千鉼，絹千匹，以光寵存亡，永垂來世焉。」

**归年与互校** 此处是魏在本年八月褒奖郭脩；诏书“往岁”对刺杀的回述与《后主传》延熙十六年正月相校。

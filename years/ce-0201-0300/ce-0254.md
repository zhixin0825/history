1. **毌丘俭奏合肥守兵刘整。** 六年春二月己丑，镇东将军毋丘俭上言：「昔诸葛恪围合肥新城，城中遣士刘整出围传消息，为贼所得，考问所传，语整曰：『诸葛公欲活汝，汝可具服。』整骂曰：『死狗，此何言也！我当必死为魏国鬼，不苟求活，逐汝去也。欲杀我者，便速杀之。』终无他辞。又遣士郑像出城传消息，或以语恪，恪遣马骑寻围迹索，得像还。四五人靮头靣缚，将绕城表，勑语像，使大呼，言『大军已还洛，不如早降。』像不从其言，更大呼城中曰：『大军近在围外，壮士努力！』贼以刀筑其口，使不得言，像遂大呼，令城中闻知。整、像为兵，能守义执节，子弟宜有差异。」 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **诏曰“夫显爵所以襃元功”。** 诏曰：「夫显爵所以襃元功，重赏所以宠烈士。整、像召募通使，越蹈重围，冒突白刃，轻身守信，不幸见获，抗节弥厉，扬六军之大势，安城守之惧心，临难不顾，毕志传命。昔解杨执楚，有陨无贰，齐路中大夫以死成命，方之整、像，所不能加。今追赐整、像爵关中侯，各除士名，使子袭爵，如部曲将死事科。」 [[2]](#sg-note-2)

### 3. 李丰、夏侯玄、张缉等被诛

<a id="sgz004-b-237-1"></a>

**[《三国志·三少帝纪》仓内原文 L237](../../sources/本地分卷/三国志/三国志-卷004.md#l237)**

> 庚戌，中書令李豐與皇后父光祿大夫張緝等謀廢易大臣，以太常夏侯玄為大將軍。事覺，諸所連及者皆伏誅。

**释读** 中书令李丰与张缉等谋换执政大臣，拟以太常夏侯玄为大将军；事泄，涉案者被诛。

**归年** 嘉平六年二月庚戌，与《夏侯玄传》《通鉴》同。

<a id="sgz004-p-013-2"></a>

**[《三国志·三少帝纪》裴注 013·2](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-013-2)**

> 臣松之案夏侯玄傳及魏畧許允此年春與李豐事相連豐既誅即出允為鎮北將軍未發以放散官物收付廷尉徙樂浪追殺之允此秋不得故為領軍而建此謀

**释读** 据《夏侯玄传》《魏略》，254年春夏侯玄李丰案后许允已出镇北，不久因放散官物被徙乐浪而后杀，裴氏据此否定同秋仍当中领军并参与密谋。

**归年** 案发明确嘉平六年春，裴氏校对年内先后；评说本身不另定年。

<a id="sgz009-b-496-9"></a>

**[《三国志·诸夏侯曹传》仓内原文 L496](../../sources/本地分卷/三国志/三国志-卷009.md#l496)**

> 嘉平六年二月，當拜貴人，豐等欲因御臨軒，諸門有陛兵，誅大將軍，以玄代之，以緝爲驃騎將軍。

**释读** 嘉平六年二月将举行拜贵人仪式，李丰等计划趁朝会诸门有兵杀大将军，由夏侯玄代，以张缉为骠骑将军。

**归年** 本传明嘉平六年二月，通鉴卷076 L269–288同记。

<a id="sgz009-b-496-10"></a>

**[《三国志·诸夏侯曹传》仓内原文 L496](../../sources/本地分卷/三国志/三国志-卷009.md#l496)**

> 豐密語黃門監蘇鑠、永寧署令樂敦、宂從僕射劉賢等曰：「卿諸人居內多有不法，大將軍嚴毅，累以爲言，張當可以爲誡。」鑠等皆許以從命。

**释读** 李丰暗说司马师责内官不法、张当是前例，拉拢苏铄等，三人答应听命。

**归年** 接嘉平六年二月谋划。

> 世語及魏氏春秋並云此秋姜維寇隴右時安東將軍司馬文王鎮許昌徵還擊維至京師帝於平樂觀以臨軍過中領軍許允與左右小臣謀因文王辭殺之勒其衆以退大將軍已書詔於前文王入帝方食栗優人雲午等唱曰青頭雞青頭雞青頭雞者鴨也帝懼不敢發文王引兵入城景王因是謀廢帝

**释读** 两书称254年秋司马昭受命击姜维，经京都向曹芳辞行，曹芳与许允等谋杀司马昭以牵制司马师。优人借“青头鸡”暗示，他未敢发动，司马师因此谋废他。

**归年** 正文记正秋废帝；谋杀为《世语》《魏氏春秋》异载，须读下一段裴松之驳议。

> 甲戌，太后令曰：「皇帝芳春秋已長，不親萬機，耽淫內寵，沈漫女德，日延倡優，縱其醜謔；迎六宮家人留止內房，毀人倫之敘，亂男女之節；恭孝日虧，悖慠滋甚，不可以承天緒，奉宗廟。使兼太尉高柔奉策，用一元大武告於宗廟，遣芳歸藩於齊，以避皇位。」

**释读** 《魏书》载司马师接太后令召集群臣，众人援伊尹、霍光废立为例，司马师声称不敢逃避。

**归年** 254年九月废帝奏，署名、罪状按魏方奏文。

<a id="sgz004-p-014-3"></a>

**[《三国志·三少帝纪》裴注 014·3](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-014-3)**

> 又於廣望觀上使懐信等於觀下作遼東妖婦嬉褻過度道路行人掩目帝於觀上以為讌笑於陵雲臺曲中施帷見九親婦女帝臨宣曲觀呼懷信使入帷共飲酒懐信等更行酒婦女皆醉戲侮無别使保林李華劉勲等與懐信等戲清商令令狐景呵華勲曰諸女上左右人各有官職何以得爾華勲數讒毁景帝常喜以彈彈人以此恚景彈景不避首目景語帝曰先帝持門户急今陛下日將妃后游戲無度至乃共觀倡優裸袒為亂不可令皇太后聞景不愛死為陛下計耳帝言我作天子不得自在耶太后何與我事使人燒鐵灼景身體皆爛

**释读** 奏文列广望观、陵云台等处宫中游戏、人伦失序，并指曹芳弹射、用炙铁虐清商令令狐景，蔑视太后。

**归年** 252–254年间行为的追诉，个别行为无确日年；归于254年正式奏文。

<a id="sgz004-p-014-4"></a>

**[《三国志·三少帝纪》裴注 014·4](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-014-4)**

> 甄后崩後帝欲立王貴人為皇后太后更欲外求帝恚語景等魏家前後立皇后皆從所愛耳太后必違我意知我當徃不也後卒待張皇后疏薄太后遭合陽君䘮帝日在後園倡優音樂自若不數往定省清商丞龎熙諫帝皇太后至孝今遭重憂水漿不入口陛下當數往寛慰不可但在此作樂帝言我自爾誰能奈我何皇太后還北宫殺張羙人及禺婉帝恚望語景等太后橫殺我所寵愛此無復母子恩數往至故處啼哭私使暴室厚殯棺不令太后知也

**释读** 奏称甄后死后曹芳要立王贵人、不喜太后另立张氏，太后居丧而曹芳不常省问，亦指其因太后处置宠人而怨望。

**归年** 254年公文中追叙。甄后卒251，张后立252，宠人案确年不明。

<a id="sgz004-p-014-5"></a>

**[《三国志·三少帝纪》裴注 014·5](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-014-5)**

> 每見九親婦女有美色或留以付清商帝至後園竹間戲或與從官携手共行熙白從官不宜與至尊相提挈帝怒復以彈彈熙日游後園每有外文書入帝不省左右曰出帝亦不索視太后令帝常在式乾殿上講學不欲使行來帝徑去太后來問輙詐令黃門答言在耳景熙等畏恐不敢復止更共謟媚帝肆行昏滛敗人倫之敘亂男女之節恭孝彌頽凶徳浸盛臣等憂懼恐覆天下危墜社稷雖殺身斃命不足以塞責今帝不可以承天緒臣請依漢霍光故事收帝璽綬帝本以齊王踐阼宜歸藩于齊使司徒臣柔持節與有司以太牢告祀宗廟臣謹昧死以聞奏可

**释读** 奏称曹芳留近亲女、常游后园、拒阅文书、虚报讲学，结论是援霍光故事收玺、遣归齐藩，遣高柔祭告宗庙。

**归年** 254年九月联名奏尾；其行为系奏者所申罪状，保留史源归属。

**释读** 《魏略》说司马师让郭芝告诉太后和曹芳欲废帝另立曹据，太后欲见司马师而被拒，得知外兵已布后交出玺绶。

**归年** 嘉平六年九月废立。《魏书》联奏之叙与此相比各有立场。

<a id="sgz004-b-240-9"></a>

**[《三国志·三少帝纪》仓内原文 L240](../../sources/本地分卷/三国志/三国志-卷004.md#l240)**

> 詔曰：「昔三祖神武聖德，應天受祚。齊王嗣位，肆行非度，顛覆厥德。皇太后深惟社稷之重，延納宰輔之謀，用替厥位，集大命於餘一人。以眇眇之身，託於王公之上，夙夜祗畏，懼不能嗣守祖宗之大訓，恢中興之弘業，戰戰兢兢，如臨於谷。今羣公卿士股肱之輔，四方征鎮宣力之佐，皆積德累功，忠勤帝室；庶憑先祖先父有德之臣，左右小子，用保乂皇家，俾朕蒙闇，垂拱而治。蓋聞人君之道，德厚侔天地，潤澤施四海，先之以慈愛，示之以好惡，然後教化行於上，兆民聽於下。朕雖不德，昧於大道，思與宇內共臻茲路。書不云乎：『安民則惠，黎民懷之。』」

<a id="sgz027-b-1410-5"></a>

**[《三国志·徐胡二王传》仓内原文 L1410](../../sources/本地分卷/三国志/三国志-卷027.md#l1410)**

**释读** 诏表扬三人历事四世，出将入相，忠清不营产业，死后无余财；各家赐谷两千斛、钱三十万。

**释读** 记魏帝褒胡质清行、赐家钱谷。原TXT「語在。」有省脱，全文见前面《徐邈传》。

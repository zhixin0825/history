<a id="sg-event-1"></a>

1. **毌丘俭奏合肥守兵刘整。** 六年春二月己丑，镇东将军毋丘俭上言：「昔诸葛恪围合肥新城，城中遣士刘整出围传消息，为贼所得，考问所传，语整曰：『诸葛公欲活汝，汝可具服。』整骂曰：『死狗，此何言也！我当必死为魏国鬼，不苟求活，逐汝去也。欲杀我者，便速杀之。』终无他辞。又遣士郑像出城传消息，或以语恪，恪遣马骑寻围迹索，得像还。四五人靮头靣缚，将绕城表，勑语像，使大呼，言『大军已还洛，不如早降。』像不从其言，更大呼城中曰：『大军近在围外，壮士努力！』贼以刀筑其口，使不得言，像遂大呼，令城中闻知。整、像为兵，能守义执节，子弟宜有差异。」 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **诏曰“夫显爵所以襃元功”。** 诏曰：「夫显爵所以襃元功，重赏所以宠烈士。整、像召募通使，越蹈重围，冒突白刃，轻身守信，不幸见获，抗节弥厉，扬六军之大势，安城守之惧心，临难不顾，毕志传命。昔解杨执楚，有陨无贰，齐路中大夫以死成命，方之整、像，所不能加。今追赐整、像爵关中侯，各除士名，使子袭爵，如部曲将死事科。」 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **李丰、夏侯玄、张缉等被诛。** 庚戌，中书令李丰与皇后父光禄大夫张缉等谋废易大臣，以太常夏侯玄为大将军。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **事觉，诸所连及者皆伏诛。** [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **大赦。** 辛亥，大赦。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **废皇后张氏。** 三月，废皇后张氏。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **立皇后王氏，大赦。** 夏四月，立皇后王氏，大赦。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **封后父奉车都尉王夔为广明乡侯、光禄大夫。** 五月，封后父奉车都尉王夔为广明乡侯、光禄大夫，位特进，妻田氏为宣阳乡君。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **大将军司马景王将谋废帝。** 秋九月，大将军司马景王将谋废帝，以闻皇太后。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **太后令曰“皇帝芳春秋已长”。** 甲戌，太后令曰：「皇帝芳春秋已长，不亲万机，耽淫内宠，沈漫女德，日延倡优，纵其丑谑；迎六宫家人留止内房，毁人伦之叙，乱男女之节；恭孝日亏，悖慠滋甚，不可以承天绪，奉宗庙。使兼太尉高柔奉策，用一元大武告于宗庙，遣芳归藩于齐，以避皇位。」 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **是日迁居别宫，年二十三。** [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **使者持节送衞，营齐王宫于河内重门。** 使者持节送衞，营齐王宫于河内重门，制度皆如藩国之礼。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **令曰“东海王霖”。** 丁丑，令曰：「东海王霖，高祖文皇帝之子。霖之诸子，与国至亲，高贵乡公髦有大成之量，其以为明皇帝嗣。」 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **封歘县高贵乡公。** 正始五年，封歘县高贵乡公。 [[14]](#sg-note-14)

15. **少好学，夙成。** [[15]](#sg-note-15)

<a id="sg-event-16"></a>

17. **公至于玄武馆，群臣奏请舍前殿。** 十月己丑，公至于玄武馆，群臣奏请舍前殿，公以先帝旧处，避止西厢；群臣又请以法驾迎，公不听。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **公入于洛阳，群臣迎拜西掖门南。** 庚寅，公入于洛阳，群臣迎拜西掖门南，公下舆将荅拜，傧者请曰：「仪不拜。」 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **公曰“吾人臣也”。** 公曰：「吾人臣也。」 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **至止车门下舆。** [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **左右曰“旧乘舆入”。** 左右曰：「旧乘舆入。」 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **公曰“吾被皇太后徵”。** 公曰：「吾被皇太后徵，未知所为！」 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **遂步至太极东堂，见于太后。** [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **其日即皇帝位于太极前殿。** 其日即皇帝位于太极前殿，百寮陪位者欣欣焉。 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **诏曰“昔三祖神武圣德”。** 诏曰：「昔三祖神武圣德，应天受祚。齐王嗣位，肆行非度，颠覆厥德。皇太后深惟社稷之重，延纳宰辅之谋，用替厥位，集大命于余一人。以眇眇之身，托于王公之上，夙夜祗畏，惧不能嗣守祖宗之大训，恢中兴之弘业，战战兢兢，如临于谷。今群公卿士股肱之辅，四方征镇宣力之佐，皆积德累功，忠勤帝室；庶凭先祖先父有德之臣，左右小子，用保乂皇家，俾朕蒙闇，垂拱而治。盖闻人君之道，德厚侔天地，润泽施四海，先之以慈爱，示之以好恶，然后教化行于上，兆民听于下。朕虽不德，昧于大道，思与宇内共臻兹路。书不云乎：『安民则惠，黎民怀之。』」大赦，改元。 [[25]](#sg-note-25)

<a id="sg-event-26"></a>

26. **减乘舆服御后宫用度，及罢尚方御府百工技巧靡丽无益之物。** [[26]](#sg-note-26)

<a id="sg-event-27"></a>

27. **遣侍中持节分适四方，观风俗。** 正元元年冬十月壬辰，遣侍中持节分适四方，观风俗，劳士民，察冤枉失职者。 [[27]](#sg-note-27)

<a id="sg-event-28"></a>

28. **假大将军司马景王黄钺。** 癸巳，假大将军司马景王黄钺，入朝不趋，奏事不名，劒履上殿。 [[28]](#sg-note-28)

<a id="sg-event-29"></a>

29. **黄龙见于邺井中。** 戊戌，黄龙见于邺井中。 [[29]](#sg-note-29)

<a id="sg-event-30"></a>

30. **命有司论废立定策之功。** 甲辰，命主管官员论废立定策之功，封爵、增邑、进位、班赐各有差。 [[30]](#sg-note-30)

<a id="sg-event-31"></a>

31. **李丰、夏侯玄等案。** 李丰合皇后父张缉图谋除司马师，意欲以夏侯玄代任，被司马师先行处置。 [[31]](#sg-note-31)

<a id="sg-event-32"></a>

32. **姜维出陇西、徙三县居民。** 姜维夏再出陇西，冬迁三县人口至绵竹、繁县。 [[32]](#sg-note-32)

<a id="sg-event-33"></a>

33. **孙英谋杀孙峻不成。** 吴侯孙英谋杀专政的孙峻，事被察觉，孙英自杀。 [[33]](#sg-note-33)

<a id="sg-event-34"></a>

34. **持节兼太常，奉法驾。** 嘉平六年，持节兼太常，奉法驾，迎高贵乡公于元城。 [[34]](#sg-note-34)

<a id="sg-event-35"></a>

35. **刘靖去世。** 刘靖于本年去世。 [[35]](#sg-note-35)

<a id="sg-event-36"></a>

36. **以琬袭昂爵为丰王。** 嘉平六年，以琬袭昂爵为丰王。 [[36]](#sg-note-36)

<a id="sg-event-37"></a>

37. **诏曰“故楚王彪”。** 正元元年诏曰：「故楚王彪，背国附奸，身死嗣替，虽自取之，犹哀矜焉。夫含垢藏疾，亲亲之道也，其封彪世子嘉为常山真定王。」 [[37]](#sg-note-37)

<a id="sg-event-38"></a>

38. **下诏襃扬，赐其家钱糓。** 嘉平六年，下诏襃扬，赐其家钱糓。 [[38]](#sg-note-38)

<a id="sg-event-39"></a>

39. **吴侯英谋杀峻，英事泄死。** 五凤元年，吴侯英谋杀峻，英事泄死。 [[39]](#sg-note-39)

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p004)** · [仓内TXT L240](../../sources/本地分卷/三国志/三国志-卷004.md#L240)

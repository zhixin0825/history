## 本年概述

魏中书令李丰等谋更换辅政者，事败被诛。九月司马师废曹芳，十月曹髦入洛即位，魏改元正元。姜维进兵陇右，吴国则发生谋杀孙峻的密谋。

1. **李丰等被诛，曹芳废张后、立王后。** 二月庚戌，中书令李丰与张皇后的父亲张缉等谋更换辅政大臣，欲以太常夏侯玄取代司马师。事发，涉案者被诛。次日辛亥大赦。三月曹芳废张皇后，四月立王氏并大赦。五月封王后的父亲王夔为广明乡侯、光禄大夫，位特进。王夔的妻子田氏封宣阳乡君。 [[1]](#sg-note-3)

2. **司马师废曹芳，曹芳迁居河内齐王宫。** 九月，司马师向郭太后提出废立。甲戌，郭太后下令废曹芳，命高柔以兼太尉身份奉策告庙。司马师会集公卿，群臣联奏请收曹芳的玺绶，准其归藩。曹芳当日移居别宫，年二十三，后由持节使者护送，在河内重门按诸侯国制度营建齐王宫。司马师原拟立彭城王曹据。郭太后提出为曹叡立嗣，坚持改迎高贵乡公曹髦。 [[2]](#sg-note-9)

3. **许允被徙途中去世，阮氏保全其家。** 许允未赴任即因散发官物而交廷尉，发配乐浪，死在路上。 门生告许允死，阮氏镇静，认为二子不应牵连；后钟会来探二子才具，二人照母劝诚恳应答，终免。 [[3]](#sgz-note-41)

13. **姜维进兵陇西，蜀迁三县居民。** 正月，姜维自上年围南安之役回到成都，蜀大赦。是年姜维加督中外军事，夏又出陇西。张嶷从越巂召回成都，百姓扶车哭送，旄牛邑君来迎，百余人随他到蜀郡朝贡；张嶷到成都后任荡寇将军。冬，姜维迁狄道、河间、临洮三县居民至绵竹、繁县。 [[13]](#sg-note-32)

<a id="sg-event-33"></a>

14. **谋杀孙峻事败，吴侯孙英身亡。** 孙和被杀后，吴中出现谋杀孙峻的密谋，牵涉吴侯孙英。事败后，孙英和涉事将吏身亡，孙英的封国撤除。 [[14]](#sg-note-33)

15. **毌丘俭奏合肥守兵刘整、郑像之功，魏追赏二人。** 二月己丑，镇东将军毌丘俭上奏，追述[上年诸葛恪围合肥新城](ce-0253.md)时，魏军士卒刘整、郑像先后出城传讯而被俘。刘整拒绝供出军情；郑像不肯照敌军的话劝城内投降，反高喊援军已近。朝廷追授两人为关中侯，准其子承袭。 [[15]](#sg-note-1)

<a id="sgz-event-46"></a>

<a id="sgz-event-47"></a>

17. **斗、牛见彗星。** 冬十一月，记录斗、牛之域见彗星。 [[17]](#sgz-note-47)

<a id="sgz-event-48"></a>

18. **交阯有稗草变稻的传闻。** 交阯传说稗草变成了稻。 [[18]](#sgz-note-48)

### 2. 司马师废曹芳，曹芳迁居河内齐王宫

<a id="sg004-l237-e9"></a>

<a id="wei004-l74-6"></a>

**[《三國志·三少帝紀》正文](../../拆分史书/三国志/卷004.md#edition-wei004-l74-6)** · [TXT L74](../../拆分史书/三国志/卷004.txt#L74)

> 秋九月，大將軍司馬景王將謀廢帝，以聞皇太后。

**釋讀與歸年** 九月司马师已谋废曹芳，先报告郭太后；下文甲戌太后令及其后会议、奏请是正式程序。

<a id="sgz004-p-013-1"></a>

**归年** 正文记正秋废帝；谋杀为《世语》《魏氏春秋》异载，须读下一段裴松之驳议。

<a id="wei004-l75-1"></a>

**[《三國志·三少帝紀》裴注](../../拆分史书/三国志/卷004.md#edition-wei004-l75-1)** · [TXT L75](../../拆分史书/三国志/卷004.txt#L75)

> 世語及魏氏春秋並云：此秋，姜維寇隴右。時安東將軍司馬文王鎮許昌，徵還擊維，至京師，帝於平樂觀以臨軍過。中領軍許允與左右小臣謀，因文王辭，殺之，勒其衆以退大將軍。已書詔於前。文王入，帝方食栗，優人雲午等唱曰：「青頭雞，青頭雞。」青頭雞者，鴨也。帝懼不敢發。文王引兵入城，景王因是謀廢帝。

**釋讀與歸年** 《世语》《魏氏春秋》把九月废帝的起因系于姜维进兵时曹芳、许允等谋杀司马昭，并称伶人用青头鸡暗示放弃；裴松之据许允此前去职被杀驳斥，不能把这段当成确凿军政实录。

**[《三國志·三少帝紀》正文](../../拆分史书/三国志/卷004.md#edition-wei004-l76-1)** · [TXT L76](../../拆分史书/三国志/卷004.txt#L76)

> 甲戌，太后令曰：「皇帝芳春秋已長，不親萬機，耽淫內寵，沈漫女德，日延倡優，縱其醜謔；迎六宮家人留止內房，毀人倫之叙，亂男女之節；恭孝日虧，悖慠滋甚，不可以承天緒，奉宗廟。使兼太尉高柔奉策，用一元大武告于宗廟，遣芳歸藩于齊，以避皇位。」

**釋讀與歸年** 九月甲戌郭太后令指控曹芳失德，命高柔以兼太尉奉策告宗庙，以一元大武即一头祭牛，遣曹芳归为齐王。照录废黜文书一方的指控。

> 魏書曰：是日，景王承皇太后令，詔公卿中朝大臣會議，羣臣失色。景王流涕曰：「皇太后令如是，諸君其若王室何！」咸曰：「昔伊尹放太甲以寧殷，霍光廢昌邑以安漢，夫權定社稷以濟四海，二代行之於古，明公當之於今，今日之事，亦唯公命。」景王曰：「諸君所以望師者重，師安所避之？」

**[《三國志·吳主五子傳》正文](../../拆分史书/三国志/卷059.md#edition-wu059-l18-2)** · [TXT L18](../../拆分史书/三国志/卷059.txt#L18)

> 五鳳元年，英以大將軍孫峻擅權，謀誅峻，事覺自殺，國除。

**釋讀** 本傳記孫英不滿大將軍孫峻專權，參與謀誅，事泄後自殺，封國廢除。

**歸年** 卷048《孫亮傳》同記五鳳元年秋，以孫英為謀主並載自殺。《吳歷》另稱桓慮欲推戴孫英、孫英實不知，接下文合讀。

<a id="sgz059-p-005-1"></a>

<a id="wu059-l19-1"></a>

**[《三國志·吳主五子傳》裴注 005](../../拆分史书/三国志/卷059.md#edition-wu059-l19-1)** · [TXT L19](../../拆分史书/三国志/卷059.txt#L19)

> 吳歷曰：孫和以無罪見殺，衆庶皆懷憤歎，前司馬桓慮因此招合將吏，欲共殺峻立英，事覺，皆見殺，英實不知。

**釋讀** 《吳歷》說孫和無罪而被殺，引起民間憤慨。前司馬桓慮因而聚合將吏，要殺孫峻、擁立孫英。事泄後眾人被殺，孫英其實不知此謀。

**歸年** 孫和死是前情，卷059下文繫於253年。《資治通鑑》卷076將254年的謀主記為桓慮，與本傳不同。孫英是否知情、如何身死仍須保留差別。

**[《三國志·三少帝紀》正文](../../拆分史书/三国志/卷004.md#edition-wei004-l72-1)** · [TXT L72](../../拆分史书/三国志/卷004.txt#L72)

> 六年春二月己丑，鎮東將軍毌丘儉上言：「昔諸葛恪圍合肥新城，城中遣士劉整出圍傳消息，爲賊所得，考問所傳，語整曰：『諸葛公欲活汝，汝可具服。』整罵曰：『死狗，此何言也！我當必死爲魏國鬼，不苟求活，逐汝去也。欲殺我者，便速殺之。』終無他辭。又遣士鄭像出城傳消息，或以語恪，恪遣馬騎尋圍跡索，得像還。四五人靮頭靣縛，將繞城表，勑語像，使大呼，言『大軍已還洛，不如早降。』像不從其言，更大呼城中曰：『大軍近在圍外，壯士努力！』賊以刀築其口，使不得言，像遂大呼，令城中聞知。整、像爲兵，能守義執節，子弟宜有差異。」

**釋讀與歸年** 嘉平六年二月己丑毌丘俭上言；所述刘整、郑像乃253年诸葛恪围合肥新城时守城传信者。完整奏文系奏报年，前一年战事可互见。

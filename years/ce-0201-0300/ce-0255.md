# 公元255年｜魏正元二年／蜀延熙十八年／吴五凤二年

[← 公元254年](ce-0254.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元256年 →](ce-0256.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **毌丘俭、文钦起兵，司马师出征。** 毌丘俭与文钦在淮南起兵，司马师自洛阳率军出征。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **车骑将军郭淮薨。** 癸未，车骑将军郭淮去世。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **文钦兵败投吴，毌丘俭被杀。** 闰月己亥，破钦于乐嘉。钦遁走，遂奔吴。甲辰，安风津都尉斩俭，传首京都。壬子，复特赦淮南士民诸为俭、钦所诖误者。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **以镇南将军诸葛诞为镇东大将军。** [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **司马景王薨于许昌。** [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **以衞将军司马文王为大将军。** 二月丁巳，以衞将军司马文王为大将军，录尚书事。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **吴大将孙峻等衆号十万至寿春。** 甲子，吴大将孙峻等衆号十万至寿春，诸葛诞拒击破之，斩吴左将军留赞，献捷于京都。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **立皇后卞氏，大赦。** 三月，立皇后卞氏，大赦。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **封后父卞隆为列侯。** 夏四月甲寅，封后父卞隆为列侯。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **以征南大将军王昶为骠骑将军。** 甲戌，以征南大将军王昶为骠骑将军。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **以征东大将军胡遵为衞将军。** 秋七月，以征东大将军胡遵为衞将军，镇东大将军诸葛诞为征东大将军。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **蜀大将军姜维寇狄道，雍州刺史王经与战洮西。** 八月辛亥，蜀大将军姜维寇狄道，雍州刺史王经与战洮西，经大败，还保狄道城。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **以长水校尉邓艾行安西将军。** 辛未，以长水校尉邓艾行安西将军，与征西将军陈泰并力拒维。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **复遣太尉司马孚为后继。** 戊辰，复遣太尉司马孚为后继。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **讲尚书业终，赐执经亲授者司空郑冲、侍中郑小同等各有差。** 九月庚子，讲尚书业终，赐执经亲授者司空郑冲、侍中郑小同等各有差。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **姜维退还。** 甲辰，姜维退还。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **诏曰“朕以寡德”。** 冬十月，诏曰：「朕以寡德，不能式遏寇虐，乃令蜀贼陆梁边陲。洮西之战，至取负败，将士死亡，计以千数，或没命战场，冤魂不反，或牵掣虏手，流离异域，吾深痛愍，为之悼心。其令所在郡典农及安抚夷二护军各部大吏慰恤其门户，无差赋役一年；其力战死事者，皆如旧科，勿有所漏。」 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **以陇右四郡及金城连年受敌。** 十一月甲午，以陇右四郡及金城连年受敌，或亡叛投贼，其亲戚留在本土者不安，皆特赦之。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **诏曰“往者洮西之战”。** 癸丑，诏曰：「往者洮西之战，将吏士民或临阵战亡，或沉溺洮水，骸骨不収，弃于原野，吾常痛之。其告征西、安西将军，各令部人于战处及水次鈎求屍丧，収敛藏埋，以慰存亡。」 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **以乐陵王茂子阳都乡公竦继铄后。** 正元二年，以乐陵王茂子阳都乡公竦继铄后。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **弟辰谓辂曰“大​​将军待君意厚”。** 正元二年，弟辰谓辂曰：「大​​将军待君意厚，冀当富贵乎？」 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **假节，与峻等袭寿春。** 五凤二年，假节，与峻等袭寿春，还遇魏将曹珍，破之于高亭。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **讨山贼陈毖于零陵。** 五凤二年，讨山贼陈毖于零陵。 [[23]](#sg-note-23)

<a id="sgz-event-24"></a>

24. **姜维上半年回成都。** 延熙十八年春季，姜维回成都。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **孙仪谋杀孙峻事败，朱公主受牵连被害。** 全公主诬称朱公主同谋，孙峻杀朱主。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **孙休恐惧，遣朱夫人至建业又复归。** 朱氏与孙休持手而泣，至建业后孙峻命其回来。 [[26]](#sgz-note-26)

<a id="sg044-l2075-e12"></a>

**[《三国志·蒋琬费祎姜维传》](../../sources/摘录/三国志-卷044-蒋琬费祎姜维传.md#p003)** · [仓内TXT L2075](../../sources/本地分卷/三国志/三国志-卷044.md#l2075)

<a id="sg045-l2093-e12"></a>

**[《三国志·邓张宗杨传》](../../sources/摘录/三国志-卷045-邓张宗杨传.md#p002)** · [仓内TXT L2093](../../sources/本地分卷/三国志/三国志-卷045.md#l2093)

> 十八年，與衛將軍姜維俱還成都。維議復出軍，唯翼廷爭，以為國小民勞，不宜黷武。維不聽，將翼等行，進翼位鎮南大將軍。維至狄道，大破魏雍州刺史王經，經眾死於洮水者以萬計。翼曰：「可止矣，不宜復進，進或毀此大功。」維大怒。曰：「為蛇畫足。」維竟圍經於狄道，城不能克。

<a id="sgz033-b-1715-2"></a>

**[《三国志·后主传》仓内原文 L1715](../../sources/本地分卷/三国志/三国志-卷033.md#l1715)**

> 夏，復率諸軍出狄道，與魏雍州剌史王經戰於洮西，大破之。經退保狄道城，維卻住鍾題。

**释读** 姜维自狄道出军，大败王经。王经退保狄道城，姜维后退住钟题。

**归年** 延熙十八年、《高贵乡公纪》正元二年；本传把出军列夏，魏纪把洮西交战列秋八月，可以有先后。

<a id="sgz044-b-2075-6"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2075](../../sources/本地分卷/三国志/三国志-卷044.md#l2075)**

> 後十八年，復與車騎將軍夏侯霸等俱出狄道，大破魏雍州刺史王經於洮西，經眾死者數萬人。

**释读** 延熙十八年，姜维和夏侯霸出狄道，于洮西击破王经，王经军死数以万计，余退保狄道。

**归年** 《后主传》《高贵乡公纪》同年材料对读，夏与秋差。

<a id="sgz045-b-2093-2"></a>

**[《三国志·邓张宗杨传》仓内原文 L2093](../../sources/本地分卷/三国志/三国志-卷045.md#l2093)**

> 維不聽，將翼等行，進翼位鎮南大將軍。維至狄道，大破魏雍州刺史王經，經眾死於洮水者以萬計。

**释读** 姜维不听，将张翼带去，进其为镇南大将军。在狄道洮水边击破魏雍州刺史王经，死者以万计。

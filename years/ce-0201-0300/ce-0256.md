### 4. 曹髦到太学问《易》《尚书》《礼记》

[返回正文第4条](#sg-event-4)

<a id="sg004-l248-e4"></a>

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p005)** · [仓内TXT L248](../../sources/本地分卷/三国志/三国志-卷004.md#l248)

> 丙辰，帝幸太學，問諸儒曰：「聖人幽贊神明，仰觀俯察，始作八卦，後聖重之為六十四，立爻以極數，凡斯大義，罔有不備，而夏有連山，殷有歸藏，周曰周易，易之書，其故何也？」

<a id="sg004-l248-e5"></a>

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p005)** · [仓内TXT L248](../../sources/本地分卷/三国志/三国志-卷004.md#l248)

> 易博士淳于俊對曰：「包羲因燧皇之圖而制八卦，神農演之為六十四，黃帝、堯、舜通其變，三代隨時，質文各繇其事。故易者，變易也，名曰連山，似山出內雲氣，連天地也；歸藏者，萬事莫不歸藏於其中也。」

<a id="sg004-l248-e6"></a>

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p005)** · [仓内TXT L248](../../sources/本地分卷/三国志/三国志-卷004.md#l248)

> 帝又曰：「若使包羲因燧皇而作易，孔子何以不雲燧人氏沒包羲氏作乎？」

<a id="sgz004-b-248-3"></a>

**[《三国志·三少帝纪》仓内原文 L248](../../sources/本地分卷/三国志/三国志-卷004.md#l248)**

> 帝又曰：「若使包羲因燧皇而作易，孔子何以不雲燧人氏沒包羲氏作乎？」俊不能荅。

**释读** 曹髦问若伏羲继承燧人，孔子为什么没有说燧人没而伏羲作，淳于俊无法作答。

**归年** 承同日太学讨论。

<a id="sg004-l248-e7"></a>

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p005)** · [仓内TXT L248](../../sources/本地分卷/三国志/三国志-卷004.md#l248)

> 俊不能荅。

<a id="sg004-l248-e8"></a>

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p005)** · [仓内TXT L248](../../sources/本地分卷/三国志/三国志-卷004.md#l248)

> 帝又問曰：「孔子作彖、象，鄭玄作注，雖聖賢不同，其所釋經義一也。今彖、象不與經文相連，而注連之，何也？」

<a id="sgz004-b-248-4"></a>

**[《三国志·三少帝纪》仓内原文 L248](../../sources/本地分卷/三国志/三国志-卷004.md#l248)**

> 帝又問曰：「孔子作彖、象，鄭玄作注，雖聖賢不同，其所釋經義一也。今彖、象不與經文相連，而注連之，何也？」俊對曰；「鄭玄合彖、象於經者，欲使學者尋省易了也。」帝曰：「若鄭玄合之，於學誠便，則孔子曷為不合以了學者乎？」俊對曰：「孔子恐其與文王相亂，是以不合，此聖人以不合為謙。」帝曰：「若聖人以不合為謙，則鄭玄何獨不謙邪？」俊對曰：「古義弘深，聖問奧遠，非臣所能詳盡。」

**释读** 曹髦问孔子彖、象未连经而郑玄把它们并入经文何故；淳于俊先说为读者方便，又用孔子谦逊解释，曹髦反问郑玄为何没有同样的顾虑。淳于俊说自己无法详答。

**归年** 承256年四月太学问《易》。

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p005)** · [仓内TXT L248](../../sources/本地分卷/三国志/三国志-卷004.md#l248)

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p005)** · [仓内TXT L248](../../sources/本地分卷/三国志/三国志-卷004.md#l248)

> 帝又問曰：「繫辭雲『黃帝、堯、舜垂衣裳而天下治』，此包羲、神農之世為無衣裳。但聖人化天下，何殊異爾邪？」

<a id="sgz004-b-248-5"></a>

**[《三国志·三少帝纪》仓内原文 L248](../../sources/本地分卷/三国志/三国志-卷004.md#l248)**

> 帝又問曰：「繫辭雲『黃帝、堯、舜垂衣裳而天下治』，此包羲、神農之世為無衣裳。但聖人化天下，何殊異爾邪？」俊對曰：「三皇之時，人寡而禽獸衆，故取其羽皮而天下用足，及至黃帝，人衆而禽獸寡，是以作為衣裳以濟時變也。」

**释读** 曹髦问伏羲、神农到黄帝、尧、舜何以服制不同；淳于俊答早期人少兽多，以羽皮为衣，人口多而禽兽少后才制衣裳。

**归年** 承256年四月太学问《易》；上古为问学理论。

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p005)** · [仓内TXT L248](../../sources/本地分卷/三国志/三国志-卷004.md#l248)

<a id="sg004-l248-e16"></a>

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p005)** · [仓内TXT L248](../../sources/本地分卷/三国志/三国志-卷004.md#l248)

> 然輅獨在少府官舎無家人子弟随之其亡没之際好竒不哀䘮者盗輅書惟餘易林風角及鳥鳴書還耳

# 公元256年｜魏甘露元年／蜀延熙十九年／吴太平元年

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **青龙见轵县井中。** 甘露元年春正月辛丑，青龙见轵县井中。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **沛王林薨。** 乙巳，沛王林去世。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **赐大将军司马文王衮冕之服。** 夏四月庚戌，赐大将军司马文王衮冕之服，赤舄副焉。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **曹髦到太学问经。** 丙辰，帝幸太学，问诸儒曰：「圣人幽赞神明，仰观俯察，始作八卦，后圣重之为六十四，立爻以极数，凡斯大义，罔有不备，而夏有连山，殷有归藏，周曰周易，易之书，其故何也？」 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **易博士淳于俊对曰“包羲因燧皇之图而制八卦”。** 易博士淳于俊对曰：「包羲因燧皇之图而制八卦，神农演之为六十四，黄帝、尧、舜通其变，三代随时，质文各繇其事。故易者，变易也，名曰连山，似山出内云气，连天地也；归藏者，万事莫不归藏于其中也。」 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **帝又曰“若使包羲因燧皇而作易”。** 帝又曰：「若使包羲因燧皇而作易，孔子何以不云燧人氏没包羲氏作乎？」 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **俊不能荅。** [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **帝又问曰“孔子作彖、象”。** 帝又问曰：「孔子作彖、象，郑玄作注，虽圣贤不同，其所释经义一也。今彖、象不与经文相连，而注连之，何也？」 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **俊对曰，「郑玄合彖、象于经者。** 俊对曰；「郑玄合彖、象于经者，欲使学者寻省易了也。」 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **帝曰“若郑玄合之”。** 帝曰：「若郑玄合之，于学诚便，则孔子曷为不合以了学者乎？」 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **俊对曰“孔子恐其与文王相乱”。** 俊对曰：「孔子恐其与文王相乱，是以不合，此圣人以不合为谦。」 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **帝曰“若圣人以不合为谦”。** 帝曰：「若圣人以不合为谦，则郑玄何独不谦邪？」 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **俊对曰“古义弘深”。** 俊对曰：「古义弘深，圣问奥远，非臣所能详尽。」 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **帝又问曰“系辞云『黄帝、尧、舜垂衣裳而天下治”。** 帝又问曰：「系辞云『黄帝、尧、舜垂衣裳而天下治』，此包羲、神农之世为无衣裳。但圣人化天下，何殊异尔邪？」 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **俊对曰“三皇之时”。** 俊对曰：「三皇之时，人寡而禽兽衆，故取其羽皮而天下用足，及至黄帝，人衆而禽兽寡，是以作为衣裳以济时变也。」 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **帝又问，「乾为天。** 帝又问：「乾为天，而复为金，为玉，为老马，与细物并邪？」 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **俊对曰“圣人取象”。** 俊对曰：「圣人取象，或远或近，近取诸物，远则天地。」 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **讲易毕，复命讲尚书。** [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **帝问曰“郑玄云『稽古同天”。** 帝问曰：「郑玄云『稽古同天，言尧同于天也』。王肃云『尧顺考古道而行之』。二义不同，何者为是？」 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **博士庾峻对曰“先儒所执”。** 博士庾峻对曰：「先儒所执，各有乖异，臣不足以定之。然洪范称『三人占，从二人之言』。贾、马及肃皆以为『顺考古道』。以洪范言之，肃义为长。」 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **帝曰“仲尼言『唯天为大”。** 帝曰：「仲尼言『唯天为大，唯尧则之』。尧之大美，在乎则天，顺考古道，非其至也。今发篇开义以明圣德，而舍其大，更称其细，岂作者之意邪？」 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **峻对曰“臣奉遵师说”。** 峻对曰：「臣奉遵师说，未喻大义，至于折中，裁之圣思。」 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **次及四岳举鲧，帝又问曰“夫大人者”。** 次及四岳举鲧，帝又问曰：「夫大人者，与天地合其德，与日月合其明，思无不周，明无不照，今王肃云『尧意不能明鲧，是以试用』。如此，圣人之明有所未尽邪？」 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **峻对曰“虽圣人之弘”。** 峻对曰：「虽圣人之弘，犹有所未尽，故禹曰『知人则哲，惟帝难之』，然卒能改授圣贤，缉熈庶绩，亦所以成圣也。」 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **帝曰“夫有始有卒”。** 帝曰：「夫有始有卒，其唯圣人。若不能始，何以为圣？其言『惟帝难之』，然卒能改授，盖谓知人，圣人所难，非不尽之言也。经云：『知人则哲，能官人。』若尧疑鲧，试之九年，官人失叙，何得谓之圣哲？」 [[25]](#sg-note-25)

<a id="sg-event-26"></a>

26. **峻对曰“臣窃观经传”。** 峻对曰：「臣窃观经传，圣人行事不能无失，是以尧失之四凶，周公失之二叔，仲尼失之宰予。」 [[26]](#sg-note-26)

<a id="sg-event-27"></a>

27. **帝曰“尧之任鲧”。** 帝曰：「尧之任鲧，九载无成，汨陈五行，民用昏垫。至于仲尼失之宰予，言行之间，轻重不同也。至于周公、管、蔡之事，亦尚书所载，皆博士所当通也。」 [[27]](#sg-note-27)

<a id="sg-event-28"></a>

28. **峻对曰“此皆先贤所疑”。** 峻对曰：「此皆先贤所疑，非臣寡见所能究论。」 [[28]](#sg-note-28)

<a id="sg-event-29"></a>

29. **次及「有鳏在下曰虞舜」，帝问曰“当尧之时”。** 次及「有鳏在下曰虞舜」，帝问曰：「当尧之时，洪水为害，四凶在朝，宜速登贤圣济斯民之时也。舜年在旣立，圣德光明，而乆不进用，何也？」 [[29]](#sg-note-29)

<a id="sg-event-30"></a>

30. **峻对曰“尧咨嗟求贤”。** 峻对曰：「尧咨嗟求贤，欲逊己位，岳曰『否德忝帝位』。尧复使岳扬举仄陋，然后荐舜。荐舜之本，实由于尧，此盖圣人慾尽衆心也。」 [[30]](#sg-note-30)

<a id="sg-event-31"></a>

31. **帝曰“尧旣闻舜而不登用”。** 帝曰：「尧旣闻舜而不登用，又时忠臣亦不进达，乃使狱扬仄陋而后荐举，非急于用圣恤民之谓也。」 [[31]](#sg-note-31)

<a id="sg-event-32"></a>

32. **峻对曰“非臣愚见所能逮及”。** 峻对曰：「非臣愚见所能逮及。」 [[32]](#sg-note-32)

<a id="sg-event-33"></a>

33. **于是复命讲《礼记》。** [[33]](#sg-note-33)

<a id="sg-event-34"></a>

34. **帝问曰“太上立德”。** 帝问曰：「『太上立德，其次务施报』。为治何由而教化各异；皆修何政而能致于立德，施而不报乎？」 [[34]](#sg-note-34)

<a id="sg-event-35"></a>

35. **博士马照对曰“太上立德”。** 博士马照对曰：「太上立德，谓三皇五帝之世以德化民，其次报施，谓三王之世以礼为治也。」 [[35]](#sg-note-35)

<a id="sg-event-36"></a>

36. **帝曰“二者致化薄厚不同”。** 帝曰：「二者致化薄厚不同，将主有优劣邪？时使之然乎？」 [[36]](#sg-note-36)

<a id="sg-event-37"></a>

37. **照对曰“诚由时有朴文”。** 照对曰：「诚由时有朴文，故化有薄厚也。」 [[37]](#sg-note-37)

<a id="sg-event-38"></a>

38. **邺及上洛并言甘露降。** 五月，邺及上洛并言甘露降。 [[38]](#sg-note-38)

<a id="sg-event-39"></a>

39. **改元为甘露。** 夏六月丙午，改元为甘露。 [[39]](#sg-note-39)

<a id="sg-event-40"></a>

40. **青龙见元城县界井中。** 乙丑，青龙见元城县界井中。 [[40]](#sg-note-40)

<a id="sg-event-41"></a>

41. **衞将军胡遵薨。** 秋七月己卯，衞将军胡遵去世。 [[41]](#sg-note-41)

<a id="sg-event-42"></a>

42. **安西将军邓艾大破蜀大将姜维于上邽，诏曰“兵未极武”。** 癸未，安西将军邓艾大破蜀大将姜维于上邽，诏曰：「兵未极武，丑虏摧破，斩首获生，动以万计，自顷战克，无如此者。今派使者犒赐将士，大会临飨，饮宴终日，称朕意焉。」 [[42]](#sg-note-42)

<a id="sg-event-43"></a>

43. **命大将军司马文王加号大都督。** 八月庚午，命大将军司马文王加号大都督，奏事不名，假黄钺。 [[43]](#sg-note-43)

<a id="sg-event-44"></a>

44. **以太尉司马孚为太傅。** 癸酉，以太尉司马孚为太傅。 [[44]](#sg-note-44)

<a id="sg-event-45"></a>

45. **以司徒高柔为太尉。** 九月，以司徒高柔为太尉。 [[45]](#sg-note-45)

<a id="sg-event-46"></a>

46. **以司空郑冲为司徒，尚书左仆射卢毓为司空。** 冬十月，以司空郑冲为司徒，尚书左仆射卢毓为司空。 [[46]](#sg-note-46)

<a id="sg-event-47"></a>

47. **段谷之战，姜维败于邓艾。** 胡济未按期赴会，姜维为邓艾所破，退回成都。 [[47]](#sg-note-47)

<a id="sg-event-48"></a>

48. **孙峻死，孙綝掌吴军政。** 孙峻原拟以文钦等伐魏，九月死，区处朝政由从弟孙綝接掌，撤回吕据诸军。 [[48]](#sg-note-48)

<a id="sg-event-49"></a>

49. **王肃去世。** 王肃于本年去世。 [[49]](#sg-note-49)

<a id="sg-event-50"></a>

50. **疾病，逊位。** 正元三年，疾病，逊位。 [[50]](#sg-note-50)

<a id="sg-event-51"></a>

51. **吴贼欲向徐堨，计诞所督兵马足以待之。** 甘露元年冬，吴贼欲向徐堨，计诞所督兵马足以待之，而复请十万众守寿春，又求临淮筑城以备寇，内欲保有淮南。 [[51]](#sg-note-51)

<a id="sg-event-52"></a>

52. **帅师侵魏，未及淮。** 太平元年，帅师侵魏，未及淮，闻孙峻死，以从弟綝自代，据大怒，引军还，欲废綝。 [[52]](#sg-note-52)

<a id="sy-event-53"></a>

53. **吴大司马吕岱去世。** 吕岱去世，传载九十六岁。其子吕凯依遗命使用素棺、从俭办丧。 [[53]](#sy-note-53)

### 12. 帝曰“若圣人以不合为谦”

[返回正文第12条](#sg-event-12)

<a id="sg004-l248-e12"></a>

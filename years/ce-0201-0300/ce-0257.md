[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **青龙见温县井中。** 二年春二月，青龙见温县井中。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **司空卢毓薨。** 三月，司空卢毓去世。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **诏曰“玄菟郡高显县吏民反叛”。** 夏四月癸卯，诏曰：「玄菟郡高显县吏民反叛，长郑熙为贼所杀。民王简负担熙丧，晨夜星行，远致本州，忠节可嘉。其特拜简为忠义都尉，以旌殊行。」 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **以征东大将军诸葛诞为司空。** 甲子，以征东大将军诸葛诞为司空。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **帝幸辟雍，会命群臣赋诗。** 五月辛未，帝幸辟雍，会命群臣赋诗。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **侍中和逌、尚书陈骞等作诗稽留。** 侍中和逌、尚书陈骞等作诗稽留，主管官员奏免官，诏曰：「吾以暗昧，爱好文雅，广延诗赋，以知得失，而乃尔纷纭，良用反仄。其原逌等。主者宜勑自今以后，群臣皆当玩习古义，修明经典，称朕意焉。」 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **诸葛诞据寿春，向吴请援。** 诸葛诞拒召，杀扬州刺史乐綝，据寿春。五月派将军朱成向吴称臣，送儿子诸葛靓、长史吴纲及将吏子弟为质。魏军随后围城，吴出兵增援。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **诏，「吴使持节都督夏口诸军事镇军将军沙羡侯孙壹。** 六月乙巳，诏：「吴使持节都督夏口诸军事镇军将军沙羡侯孙壹，贼之枝属，位为上将，畏天知命，深鉴祸福，翻然举衆，远归大国，虽微子去殷，乐毅遁燕，无以加之。其以壹为侍中车骑将军、假节、交州牧、吴侯，开府辟召仪同三司，依古侯伯八命之礼，衮冕赤舄，事从丰厚。」 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **司马昭围寿春，吴出兵援诸葛诞。** 魏令尚书随司马昭出征。六月，吴遣文钦、唐咨、全端等领步骑三万援诸葛诞。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **乃令散骑常侍裴秀、给事黄门侍郎锺会咸与大将军俱行。** [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **诏曰“昔燕刺王谋反”。** 秋八月，诏曰：「昔燕刺王谋反，韩谊等谏而死，汉朝显登其子。诸葛诞创造凶乱，主簿宣隆、部曲督秦絜秉节守义，临事固争，为诞所杀，所谓无比干之亲而受其戮者。其以隆、絜子为骑都尉，加以赠赐，光示远近，以殊忠义。」 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **大赦。** 九月，大赦。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **吴大将全端、全怿等率衆降。** 冬十二月，吴大将全端、全怿等率衆降。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **诸葛诞反魏，姜维出骆谷。** 姜维闻诸葛诞据寿春，率军出骆谷至芒水。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **孙亮开始亲政。** 孙亮四月临正殿大赦、亲自听政，屡诘问孙綝奏请，并简择十五至十八岁将士子弟练兵。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **吴再遣军援寿春，孙綝杀朱异。** 七月，孙綝驻镬里，遣朱异、丁奉率军再援寿春。朱异军缺粮撤退，九月朔被孙綝杀于镬里。辛未，孙綝回建业。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **河东乐详年九十余，上书讼畿之遗绩。** 甘露二年，河东乐详年九十余，上书讼畿之遗绩，朝廷感焉。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>



<a id="sgz-event-23"></a>

<a id="sg-event-19"></a>

19. **拜骠骑将军。** 太平二年，拜骠骑将军。 [[19]](#sg-note-19)

<a id="sy-event-20"></a>

20. **孙基盗乘御马，孙亮赦宫中。** 孙基盗乘御马下狱。孙亮与刁玄议罪，随后颁赦宫中，孙基获免。 [[20]](#sy-note-20)

<a id="sgz-event-21"></a>

21. **蜀汉本年大赦。** 蜀在当年施大赦。 [[21]](#sgz-note-21)

<a id="sgz-event-22"></a>

22. **安平王刘承去世。** 刘承为安平王，二十年卒。 [[22]](#sgz-note-22)

<a id="sgz-event-24"></a>

24. **吴连记大雨雷电与大雪。** 二月甲寅大雨打雷，乙卯下雪严寒。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **吴设湘东、衡阳、临海、临川郡。** 分长沙东西部为湘东衡阳，分会稽东部为临海、豫章东部为临川。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **会稽南部、鄱阳与新都起事。** 会稽南部杀都尉；鄱阳、新都也乱，丁密、郑胄、钟离牧领军讨伐。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **吴九月大赦。** 甲申施行大赦。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **曹髦东征时屯项，修贾逵祠。** 高贵乡公称赞贾逵遗爱，说先帝也在这里亲自褒诏，下令查修祠堂缺漏。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **司马昭东征，常时称病获罪。** 司马昭率军东讨诸葛诞时，常时称病，因而获罪。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **蒋班焦彝逾寿春投魏。** 原为诸葛诞谋士，见势难支弃诞。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **张昌蒲去世，魏廷加赙并议名礼。** 甘露二年二月暴病死，五十九。皇帝嘱司马昭厚赠，议者依成风、定姒故事称成侯命妇并按古礼殡葬。 [[31]](#sgz-note-31)

<a id="sgz028-p-021-1"></a>

> 世語曰司馬文王既秉朝政長史賈充以為宜遣參佐慰勞四征於是遣充至夀春充還啓文王誕再在〔四库字图3951〕州有威名民望所歸今徵必不来禍小事淺不徵事遲禍大乃以為司空

**释读** 贾充由寿春回，说诸葛诞既有兵望，早征虽不来而祸小；朝廷从而征之。

> 魏末傳曰賈充與誕相見談説時事因謂誕曰洛中諸賢皆願禪代君所知也君以為云何誕厲色曰卿非賈豫州子世受魏恩如何負國欲以魏室輸人乎非吾所忍聞若洛中有難吾當死之充黙然

**释读** 诸葛诞斥其受魏恩却拟以魏给人，称若洛中有事必赴死；贾充默然。

**归年** 257贾充访诸葛诞同去寿春。

### 7. 诸葛诞据寿春，向吴请援

<a id="sgz048-b-2343-1"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sgz048-b-2343-1)** · [TXT L28](../../sources/本地分卷/三国志/三国志-卷048.txt#L28)

> 五月，魏征東大將軍諸葛誕以淮南之衆保壽春城，遣將軍朱成稱臣上疏，又遣子靚、長史吳綱諸牙門子弟爲質。

**诸葛诞据寿春向吴请降并送质** 诸葛诞令朱成向吴称臣，遣儿子诸葛靓、吴纲和诸将子弟为质。

**归年依据** 《高贵乡公纪》《诸葛诞传》甘露二年五月。

<a id="sg004-l258-e7"></a>

**[《三国志·三少帝纪》](../../sources/本地分卷/三国志/三国志-卷004.md#p006)** · [仓内TXT L258](../../sources/本地分卷/三国志/三国志-卷004.md#l258)

> 乙亥，諸葛誕不就徵，發兵反，殺揚州刺史樂綝。丙子，赦淮南將吏士民為誕所詿誤者。丁丑，詔曰：「諸葛誕造為凶亂，盪覆揚州。昔黥布逆叛，漢祖親戎，隗嚻違戾，光武西伐，及烈祖明皇帝躬征吳、蜀，皆所以奮揚赫斯，震耀威武也。今宜皇太后與朕暫共臨戎，速定醜虜，時寧東夏。」己卯，詔曰：「諸葛誕造構逆亂，迫脅忠義，平寇將軍臨渭亭侯龐會、騎督偏將軍路蕃，各將左右，斬門突出，忠壯勇烈，所宜嘉異。其進會爵鄉侯，蕃封亭侯。」

<a id="sg028-l1462-e7"></a>

**[《三国志·王毌丘诸葛邓钟传》](../../sources/本地分卷/三国志/三国志-卷028.md#p003)** · [仓内TXT L1462](../../sources/本地分卷/三国志/三国志-卷028.md#l1462)

> 二年五月，徵為司空。誕被詔書，愈恐，遂反。

<a id="sgz004-b-258-1"></a>

**[《三国志·三少帝纪》仓内原文 L258](../../sources/本地分卷/三国志/三国志-卷004.md#l258)**

> 乙亥，諸葛誕不就徵，發兵反，殺揚州刺史樂綝。

**释读** 诸葛诞不接受中央征召，起兵并杀扬州刺史乐綝。

**归年** 甘露二年五月乙亥。

<a id="sgz004-b-258-2"></a>

**[《三国志·三少帝纪》仓内原文 L258](../../sources/本地分卷/三国志/三国志-卷004.md#l258)**

> 丙子，赦淮南將吏士民為誕所詿誤者。

**释读** 朝廷赦免受诸葛诞牵连的淮南军民。

**归年** 甘露二年五月丙子。

<a id="sgz004-b-258-4"></a>

**[《三国志·三少帝纪》仓内原文 L258](../../sources/本地分卷/三国志/三国志-卷004.md#l258)**

> 己卯，詔曰：「諸葛誕造構逆亂，迫脅忠義，平寇將軍臨渭亭侯龐會、騎督偏將軍路蕃，各將左右，斬門突出，忠壯勇烈，所宜嘉異。其進會爵鄉侯，蕃封亭侯。」

**释读** 诏称龐会、路蕃在诸葛诞起兵时斩门冲出，进龐会乡侯、封路蕃亭侯。

**归年** 甘露二年五月己卯。

<a id="sgz017-b-879-10"></a>

**[《三国志·二张乐于徐传》仓内原文 L879](../../sources/本地分卷/三国志/三国志-卷017.md#l879)**

> 諸葛誕反，掩襲殺綝，詔悼惜之，追贈衛尉，諡曰愍侯。子肇嗣。

**释读** 朝廷追赠乐綝卫尉、谥愍侯，儿子乐肇承袭。

**归年** 《三少帝纪》甘露二年记诸葛诞起兵并杀乐綝；封谥承袭未载另年。

**孙亮亲政，用少年所成军队** 孙亮登正殿亲理政事、大赦；常质问孙綝奏事，选三千余名十五至十八岁军户子弟编军，在苑中操练。

**归年依据** 本传太平二年夏四月。

<a id="sgz048-p-005-1"></a>

**[《三國志·三嗣主傳》 裴注 005·1](../../sources/本地分卷/三国志/三国志-卷048.md#pei-005-1)** · [TXT L26](../../sources/本地分卷/三国志/三国志-卷048.txt#L26)

> 吳歷曰：亮數出中書視孫權舊事，問左右侍臣：「先帝數有特制，今大將軍問事，但令我書可邪！」亮後出西苑，方食生梅，使黃門至中藏取蜜漬梅，蜜中有鼠矢，召問藏吏，藏吏叩頭。亮問吏曰：「黃門從汝求蜜邪？」吏曰：「向求，實不敢與。」黃門不服，侍中刁玄、張邠啟：「黃門、藏吏辭語不同，請付獄推盡。」亮曰：「此易知耳。」令破鼠矢，矢裏燥。亮大笑謂玄、邠曰：「若矢先在蜜中，中外當俱溼，今外溼裏燥，必是黃門所爲。」黃門首服，左右莫不驚悚。

**释读** 孙亮查先帝特制，质疑将军只许自己署书。又察出蜜中鼠粪是宦官后来所投。
**归年** 附太平二年孙亮亲政；果实与蜂蜜故事的年月无明书，为该时期异闻。

> 江表傳曰：亮使黃門以銀碗并蓋就中藏吏取交州所獻甘蔗餳。黃門先恨藏吏，以鼠矢投餳中，啟言藏吏不謹。亮呼吏持餳器入，問曰：「此器旣蓋之，且有掩覆，無緣有此，黃門將有恨於汝邪？」吏叩頭曰：「嘗從某求宮中莞席，宮席有數，不敢與。」亮曰：「必是此也。」覆問黃門，具首伏。即於目前加髠鞭，斥付外署。

**释读** 黄门与藏吏有旧怨，将鼠粪投交州糖浆中。孙亮从器盖及相怨查证，黄门服罪受刑。

> 將軍蔣班、焦彝，皆誕爪牙計事者也，棄誕，逾城自歸大將軍。

**归年** 《通鉴》卷七十七甘露二年十一月。

<a id="sgz028-p-023-1"></a>

**[《三国志·王毌丘诸葛邓钟传》裴注 023·1](../../sources/本地分卷/三国志/三国志-卷028.md#pei-023-1)**

> 漢晉春秋曰蔣班焦彛言於諸葛誕曰朱異等以大衆来而不能進孫綝殺異而歸江東外以發兵為名而内實坐須成敗其歸可見矣今宜及衆心尚固士卒思用并力决死攻其一面雖不能盡克猶可有全者文欽曰江東乗戰勝之威乆矣未有難北方者也况公今舉十餘萬之衆内附而欽與全端等皆同居死地父兄子弟俱在江表就孫綝不欲主上及其親戚豈肯聽乎且中國無嵗無事軍民並疲今守我一年勢力已困異圖生心變故将起以往準今可計日而望也班彛固勸之欽怒而誕欲殺班二人懼且知誕之必敗也十一月乃相擕而降

**释读** 俩人见吴援已废，建议集中破围。文钦见连吴诸将家在江南，料吴必来援，诸葛诞疑欲杀二人，俩人十一月逾城降。

**归年** 《汉晋春秋》明十一月；《通鉴》卷七十七甘露二年，同正文“蒋班焦彝逾寿春投魏”。

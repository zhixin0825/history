[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **青龙见温县井中。** 二年春二月，青龙见温县井中。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **司空卢毓薨。** 三月，司空卢毓去世。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **诏曰“玄菟郡高显县吏民反叛”。** 夏四月癸卯，诏曰：「玄菟郡高显县吏民反叛，长郑熙为贼所杀。民王简负担熙丧，晨夜星行，远致本州，忠节可嘉。其特拜简为忠义都尉，以旌殊行。」 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **以征东大将军诸葛诞为司空。** 甲子，以征东大将军诸葛诞为司空。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **帝幸辟雍，会命群臣赋诗。** 五月辛未，帝幸辟雍，会命群臣赋诗。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **侍中和逌、尚书陈骞等作诗稽留。** 侍中和逌、尚书陈骞等作诗稽留，主管官员奏免官，诏曰：「吾以暗昧，爱好文雅，广延诗赋，以知得失，而乃尔纷纭，良用反仄。其原逌等。主者宜勑自今以后，群臣皆当玩习古义，修明经典，称朕意焉。」 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **诸葛诞据寿春起兵。** 诸葛诞拒召，杀扬州刺史乐綝后据寿春。魏朝赦免受胁的当地军民，并出兵包围。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **诏，「吴使持节都督夏口诸军事镇军将军沙羡侯孙壹。** 六月乙巳，诏：「吴使持节都督夏口诸军事镇军将军沙羡侯孙壹，贼之枝属，位为上将，畏天知命，深鉴祸福，翻然举衆，远归大国，虽微子去殷，乐毅遁燕，无以加之。其以壹为侍中车骑将军、假节、交州牧、吴侯，开府辟召仪同三司，依古侯伯八命之礼，衮冕赤舄，事从丰厚。」 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **司马昭围寿春，吴出兵援诸葛诞。** 甲子，诏曰：「今车驾驻项，大将军恭行天罚，前临淮浦。昔相国大司马征讨，皆与尚书俱行，今宜如旧。」 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **乃令散骑常侍裴秀、给事黄门侍郎锺会咸与大将军俱行。** [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **诏曰“昔燕刺王谋反”。** 秋八月，诏曰：「昔燕刺王谋反，韩谊等谏而死，汉朝显登其子。诸葛诞创造凶乱，主簿宣隆、部曲督秦絜秉节守义，临事固争，为诞所杀，所谓无比干之亲而受其戮者。其以隆、絜子为骑都尉，加以赠赐，光示远近，以殊忠义。」 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **大赦。** 九月，大赦。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **吴大将全端、全怿等率衆降。** 冬十二月，吴大将全端、全怿等率衆降。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **诸葛诞反魏，姜维出骆谷。** 姜维闻诸葛诞据寿春，率军出骆谷至芒水。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **孙亮开始亲政。** 孙亮四月临正殿大赦、亲自听政，屡诘问孙綝奏请，并简择十五至十八岁将士子弟练兵。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **吴出兵援寿春失利，孙綝杀朱异。** 朱异先督兵救寿春，军中缺粮后退；孙綝在九月初一杀朱异。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **河东乐详年九十余，上书讼畿之遗绩。** 甘露二年，河东乐详年九十余，上书讼畿之遗绩，朝廷感焉。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **卢毓去世。** 卢毓于本年去世。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **拜骠骑将军。** 太平二年，拜骠骑将军。 [[19]](#sg-note-19)

<a id="sy-event-20"></a>

20. **孙基盗乘御马，孙亮赦宫中。** 孙基盗乘御马下狱。孙亮与刁玄议罪，随后颁赦宫中，孙基获免。 [[20]](#sy-note-20)

<a id="sgz-event-21"></a>

21. **蜀汉本年大赦。** 蜀在当年施大赦。 [[21]](#sgz-note-21)

<a id="sgz-event-22"></a>

22. **安平王刘承去世。** 刘承为安平王，二十年卒。 [[22]](#sgz-note-22)

<a id="sgz-event-23"></a>

23. **施绩任骠骑将军。** 施绩拜骠骑将军。 [[23]](#sgz-note-23)

<a id="sgz-event-24"></a>

24. **吴连记大雨雷电与大雪。** 二月甲寅大雨打雷，乙卯下雪严寒。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **吴设湘东、衡阳、临海、临川郡。** 分长沙东西部为湘东衡阳，分会稽东部为临海、豫章东部为临川。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **会稽南部、鄱阳与新都起事。** 会稽南部杀都尉；鄱阳、新都也乱，丁密、郑胄、钟离牧领军讨伐。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **吴九月大赦。** 甲申施行大赦。 [[27]](#sgz-note-27)

> 六月乙巳，詔：「吳使持節都督夏口諸軍事鎮軍將軍沙羡侯孫壹，賊之枝屬，位為上將，畏天知命，深鑒禍福，翻然舉衆，遠歸大國，雖微子去殷，樂毅遁燕，無以加之。其以壹為侍中車騎將軍、假節、交州牧、吳侯，開府辟召儀同三司，依古侯伯八命之禮，袞冕赤舄，事從豐厚。」

<a id="sgz004-p-022-1"></a>

**[《三国志·三少帝纪》裴注 022·1](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-022-1)**

> 臣松之以為壹畏逼歸命事無可嘉格以古義欲蓋而彌彰者也當時之宜未得逺遵式典固應量才受賞足以醻其來情而已至乃光錫八命禮同台鼎不亦過乎於招攜致逺又無取焉何者若使彼之將守與時無嫌終不悦於殊寵坐生叛心以叛而愧辱孰甚焉如其憂危將及非奔不免則必逃死茍存無希榮利矣然則髙位厚禄何為者哉魏初有孟達黃權在晉有孫秀孫楷達權爵賞比壹為輕秀楷禮秩優異尤甚及至吳平而降黜數等不承權輿豈不縁在始失中乎

**释读** 裴松之认为孙壹是受逼来投，不当获近三公的八命之礼，并比较孟达、黄权、晋时孙秀孙楷归降后所受待遇及后来的降等。

**归年** 附257年孙壹降魏及授官条，其他投降案例是举例，非同年发生；裴氏评语自身无确年。

**[《三国志·朱治朱然吕范朱桓传》裴注 014·1](../../sources/摘录/三国志-卷056-朱治朱然吕范朱桓传裴注.md#pei-014-1)**

> 吳書曰綝要異相見將往恐陸抗止之異曰子通家人耳當何所疑乎

**释读** 孙綝约见朱异，陆抗劝阻，朱异认为宗亲相约无须怀疑。

**归年** 《三嗣主传》太平二年秋九月杀朱异，《吴书》补前因；底本「將往恐陸抗止之」有讹，普通本作「將往，陸抗止之」。

<a id="sgz056-p-014-2"></a>

**[《三国志·朱治朱然吕范朱桓传》裴注 014·2](../../sources/摘录/三国志-卷056-朱治朱然吕范朱桓传裴注.md#pei-014-2)**

> 遂往綝使力人於坐上取之異曰我吳國忠臣冇何罪乎乃拉殺之

**释读** 朱异赴会，孙綝命力士当场擒杀，朱异说自己忠于吴国、并无罪。

**归年** 《三嗣主传》太平二年九月朔。

<a id="sgz048-b-2343-4"></a>

**[《三国志·三嗣主传》仓内原文 L2343](../../sources/本地分卷/三国志/三国志-卷048.md#l2343)**

> 秋七月，綝率衆救壽春，次於鑊里，朱異至自夏口，綝使異爲前部督，與丁奉等將介士五萬解圍。

**释读** 孙綝援寿春驻镬里，令朱异以前部督与丁奉等率五万解围。

**归年** 本传七月，援兵与随后九月失败同条。

<a id="sgz048-b-2343-6"></a>

**[《三国志·三嗣主传》仓内原文 L2343](../../sources/本地分卷/三国志/三国志-卷048.md#l2343)**

> 朱異以軍士乏食引還，綝大怒，九月朔己巳，殺異於鑊里。辛未，綝自鑊里還建業。

**释读** 吴军缺粮，朱异退还。孙綝九月己巳在镬里杀朱异，辛未回建业。

**归年** 《朱异传》《通鉴》卷077同年。

<a id="sgz064-b-3021-4"></a>

**[《三国志·诸葛滕二孙濮阳传》仓内原文 L3021](../../sources/本地分卷/三国志/三国志-卷064.md#l3021)**

> 朱異帥三萬人屯安豐城，為文欽勢。魏兗州刺史州泰據異於陽淵，異敗退，為泰所追，死傷二幹人。

**释读** 朱异三万人屯安丰援文钦，被州泰在阳渊击退并追击，伤亡二千。

**归年** 《通鉴》卷七十七甘露二年，魏方同参《钟会传》。

<a id="sgz064-b-3021-5"></a>

**[《三国志·诸葛滕二孙濮阳传》仓内原文 L3021](../../sources/本地分卷/三国志/三国志-卷064.md#l3021)**

> 林於是大發率出屯鑊裡，復遣異率將軍丁奉、黎斐等五萬人攻魏，留輜重於都陸。

**释读** 孙綝出屯镬里，使朱异、丁奉、黎斐率军再攻，军粮器具留都陆。

**归年** 《孙亮传》太平二年秋七月；「林」指孙綝。

<a id="sgz064-b-3021-6"></a>

**[《三国志·诸葛滕二孙濮阳传》仓内原文 L3021](../../sources/本地分卷/三国志/三国志-卷064.md#l3021)**

> 異屯黎漿，遣將軍任度、張震等慕勇敢六千人，於屯西六里為浮橋夜渡，築偃月壘。為魏監軍石苞及州泰所破，軍卻退就高。異復作車箱圍趣五木城。苞、泰攻異，異敗歸，而魏太山太守胡烈以奇兵五千詭道襲都陸，盡焚異資糧。

**释读** 朱异遣勇士夜渡筑垒，被石苞、州泰攻破；再趋五木城又败，胡烈袭击都陆焚其军粮。

**归年** 同一太平二年援寿春，《通鉴》077详载。

<a id="sgz064-b-3021-7"></a>

**[《三国志·诸葛滕二孙濮阳传》仓内原文 L3021](../../sources/本地分卷/三国志/三国志-卷064.md#l3021)**

> 綝授兵三萬人使異死戰，異不從，綝斬之於鑊裡，而遣弟恩救。

**释读** 孙綝再给三万人令朱异死战，朱异不从，被杀于镬里，孙綝另外派孙恩去救。

**归年** 《孙亮传》九月朔杀朱异；另遣孙恩在其后。

### 20. 孙基盗乘御马，孙亮赦宫中

[返回正文第20条](#sy-event-20)

<a id="sy-sg059-l2833-e20"></a>

**[《三国志·吴主五子传》](../../sources/摘录/三国志-卷059-吴主五子传.md#p004)** · [仓内TXT L2833](../../sources/本地分卷/三国志/三国志-卷059.md#l2833)

> 太平二年，盜乘御馬，收付獄。亮問侍中刁玄曰：「盜乘御馬罪云何？」玄對曰：「科應死。然魯王早終，惟陛下哀原之。」亮曰：「法者，天下所共，何得阿以親親故邪？當思惟可以釋此者，柰何以情相迫乎？」玄曰：「舊赦有大小，或天下，亦有千里、五百里赦，隨意所及。」亮曰：「解人不當爾邪！」乃赦宮中，基以得免。

**归年与互校** 《吴主五子传》明记太平二年，上文孙基获封和后来孙皓夺爵均不在此年。

<a id="sgz059-b-2833-2"></a>

**[《三国志·吴主五子传》仓内原文 L2833](../../sources/本地分卷/三国志/三国志-卷059.md#l2833)**

> 基侍孫亮在內，太平二年，盜乘御馬，收付獄。亮問侍中刁玄曰：「盜乘御馬罪云何？」玄對曰：「科應死。然魯王早終，惟陛下哀原之。」亮曰：「法者，天下所共，何得阿以親親故邪？當思惟可以釋此者，柰何以情相迫乎？」玄曰：「舊赦有大小，或天下，亦有千里、五百里赦，隨意所及。」亮曰：「解人不當爾邪！」乃赦宮中，基以得免。

**释读** 孙基盗乘御马依科当死，孙亮拒为亲属私免，听刁玄建议赦及宫中。

**归年** 本传太平二年，公元257。

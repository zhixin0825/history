# 公元258年｜魏甘露三年／蜀景耀元年／吴永安元年

[← 公元257年](ce-0257.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元259年 →](ce-0259.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **司马昭攻陷寿春，诸葛诞死。** 司马昭围攻寿春，次年二月攻入城中，诸葛诞被杀。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **诏曰“古者克敌”。** 三月，诏曰：「古者克敌，收其屍以为京观，所以惩昏逆而章武功也。汉孝武元鼎中，改桐乡为闻喜，新乡为获嘉，以着南越之亡。大将军亲总六戎，营据丘头，内夷群凶，外殄寇虏，功济兆民，声振四海。克敌之地，宜有令名，其改丘头为武丘，明以武平乱，后世不忘，亦京观二邑之义也。」 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **命大将军司马文王为相国。** 夏五月，命大将军司马文王为相国，封晋公，食邑八郡，加之九锡，文王前后九让乃止。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **诏曰“昔南阳郡山贼扰攘”。** 六月丙子，诏曰：「昔南阳郡山贼扰攘，欲劫质故太守东里衮，功曹应余独身扞衮，遂免于难。余颠沛殒毙，杀身济君。其下司徒，署余孙伦吏，使蒙伏节之报。」 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **大论淮南之功，封爵行赏各有差。** 辛卯，大论淮南之功，封爵行赏各有差。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **以骠骑将军王昶为司空。** 秋八月甲戌，以骠骑将军王昶为司空。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **诏曰“夫养老兴教”。** 丙寅，诏曰：「夫养老兴教，三代所以树风化垂不朽也，必有三老、五更以崇至敬，乞言纳诲，着在惇史，然后六合承流，下观而化。宜妙简德行，以充其选。关内侯王祥，履仁秉义，雅志淳固。关内侯郑小同，温恭孝友，帅礼不忒。其以祥为三老，小同为五更。」 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **车驾亲率群司，躬行古礼焉。** [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **是岁，青龙、黄龙仍见顿丘、冠军、阳夏县界井中。** 当年，青龙、黄龙仍见顿丘、冠军、阳夏县界井中。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **曹奂封常道乡公。** 燕王曹宇之子获封安次县常道乡公。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **蜀汉改元景耀，黄皓专政。** 姜维还成都，史官报景星，蜀改元；宦官黄皓开始掌政。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **孙綝废孙亮立孙休。** 吴大将军孙綝废黜孙亮，改立琅邪王孙休。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **陈祗去世。** 陈祗景耀元年去世，刘禅哀痛，追谥忠侯。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **诸葛诞兵败，姜维还成都。** 姜维获悉诸葛诞已经兵败，从芒水退回成都，复拜大将军。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **孙綝废孙亮为会稽王。** 孙亮与全尚、刘丞谋诛孙綝，事泄后孙綝捕全尚、杀刘丞，废孙亮。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **孙休于腊会诛孙綝。** 孙休与张布私下定计，十二月腊日百官升殿时拿下孙綝，当日处死。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **以疾徵还成都。** 景耀元年，以疾徵还成都。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **诏曰“故丞相雍”。** 永安元年，诏曰：「故丞相雍，至德忠贤，辅国以礼，而侯统废绝。朕甚愍之。其以雍次子裕袭爵为醴陵候，以明着旧勳。」 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **封爲章安侯。** 太平三年，封爲章安侯。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **徵为西陵督，封都亭侯。** 永安元年，徵为西陵督，封都亭侯，后转左虎林。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **建业中谣言明会有变。** 永安元年十二月丁卯，建业中谣言明会有变。 [[21]](#sg-note-21)

### 7. 诏曰“夫养老兴教”

[返回正文第7条](#sg-event-7)

<a id="sg004-l266-e7"></a>

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p006)** · [仓内TXT L266](../../sources/本地分卷/三国志/三国志-卷004.md#l266)

> 丙寅，詔曰：「夫養老興教，三代所以樹風化垂不朽也，必有三老、五更以崇至敬，乞言納誨，著在惇史，然後六合承流，下觀而化。宜妙簡德行，以充其選。關內侯王祥，履仁秉義，雅志淳固。關內侯鄭小同，溫恭孝友，帥禮不忒。其以祥為三老，小同為五更。」

<a id="sgz004-b-266-7"></a>

**[《三国志·三少帝纪》仓内原文 L266](../../sources/本地分卷/三国志/三国志-卷004.md#l266)**

> 鄭玄注文王世子曰「三老、五更各一人，皆年老更事致仕者也」。注樂記曰「皆老人更知三德五事者也」。蔡邕明堂論云：「更」應作「叟」。叟，長老之稱，字與「更」相似，書者遂誤以為「更」。「嫂」字「女」傍「叟」，今亦以為「更」，以此驗知應為「叟」也。臣松之以為邕謂「更」為「叟」，誠為有似，而諸儒莫之從，未知孰是。〉

**释读** 郑玄解释三老、五更为有丰富经历的老人，蔡邕则说“五更”的“更”是“叟”字抄误；裴松之认为字形相似但未能定论。

**归年** 随258年养老礼释制度字义，与裴注第24同材料，无独立史事年份。

<a id="sgz004-p-024-5"></a>

**[《三国志·三少帝纪》裴注 024·5](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-024-5)**

> 鄭玄注文王世子曰三老五更各一人皆年老更事致仕者也注樂記曰皆老人更知三德五事者也蔡邕明堂論曰更應作叟叟長老之稱字與更相似書者遂誤以為更嫂字女傍叟今亦以為更以此驗知應為叟也臣松之以為邕謂更為叟誠為有似而諸儒莫之從未知孰是

**释读** 郑玄两处注解释皆为阅历多的致仕老人。蔡邕以字形“更”“叟”近似推“五更”本应作“五叟”，裴松之认为虽似有理但诸儒多不从。

**归年** 随258年养老礼释制度名义。与仓内TXT L266误混入正文者为同一古注。

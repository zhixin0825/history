# 公元260年｜魏景元元年／蜀景耀三年／吴永安三年

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **日有蚀之。** 五年春正月朔，发生日食。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **诏有司率遵前命，复进大将军司马文王位为相国。** 夏四月，诏主管官员率遵前命，复进大将军司马文王位为相国，封晋公，加九锡。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **曹髦出讨司马昭，被成济刺死。** 五月己丑，曹髦召王沈、王经、王业等，决定率宫中人出讨司马昭。王沈、王业先行告密。贾充率军拦阻，成济刺杀曹髦。魏廷随后以郭太后令公布事由。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **太傅孚、大将军文王、太尉柔、司徒冲稽首言。** 庚寅，太傅孚、大将军文王、太尉柔、司徒冲稽首言：「伏见中令，故高贵乡公悖逆不道，自陷大祸，依汉昌邑王罪废故事，以民礼葬。臣等备位，不能匡救祸乱，式遏奸逆，奉令震悚，肝心悼栗。春秋之义，王者无外，而书『襄王出居于郑』，不能事母，故绝之于位也。今高贵乡公肆行不轨，几危社稷，自取倾覆，人神所绝，葬以民礼，诚当旧典。然臣等伏惟殿下仁慈过隆，虽存大义，犹垂哀矜，臣等之心实有不忍，以为可加恩以王礼葬之。」 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **太后从之。** [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **使使持节行中护军中垒将军司马炎北迎常道乡公璜嗣明帝后。** [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **群公奏太后曰“殿下圣德光隆”。** 辛卯，群公奏太后曰：「殿下圣德光隆，宁济六合，而犹称令，与藩国同。请自今殿下令书，皆称诏制，如先代故事。」 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **大将车固让相国、晋公、九锡之宠。** 癸卯，大将车固让相国、晋公、九锡之宠。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **太后诏曰“夫有功不隐”。** 太后诏曰：「夫有功不隐，周易大义，成人之美，古贤所尚，今听所执，出表示外，以章公之谦光焉。」 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **大将军文王上言，「高贵乡公率将从驾人兵。** 戊申，大将军文王上言：「高贵乡公率将从驾人兵，拔刃鸣金鼓向臣所止；惧兵刃相接，即勑将士不得有所伤害，违令以军法从事。骑督成倅弟太子舍人济，横入兵阵伤公，遂至陨命；輙收济行军法。臣闻人臣之节，有死无二，事上之义，不敢逃难。前者变故卒至，祸同发机，诚欲委身守死，唯命所裁。然惟本谋乃欲上危皇太后，倾覆宗庙。臣忝当大任，义在安国，惧虽身死，罪责弥重。欲遵伊、周之权，以安社稷之难，即骆驿申勑，不得迫近辇舆，而济遽入阵间，以致大变。哀怛痛恨，五内摧裂，不知何地可以陨坠？科律大逆无道，父母妻子同产皆斩。济凶戾悖逆，干国乱纪，罪不容诛。辄勑侍御史收济家属，付廷尉，结正其罪。」 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **太后诏曰“夫五刑之罪”。** 太后诏曰：「夫五刑之罪，莫大于不孝。夫人有子不孝，尚告治之，此儿岂复成人主邪？吾妇人不达大义，以谓济不得便为大逆也。然大将军志意恳切，发言恻怆，故听如所奏。当班下远近，使知本末也。」 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **诏曰“古者人君之为名字”。** 六月癸丑，诏曰：「古者人君之为名字，难犯而易讳。今常道乡公讳字甚难避，其朝臣博议改易，列奏。」 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **封安次县常道乡公。** 甘露三年，封安次县常道乡公。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **高贵乡公卒，公卿议迎立公。** [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **入于洛阳，见皇太后。** 六月甲寅，入于洛阳，见皇太后，是日即皇帝位于太极前殿，大赦，改年，赐民爵及谷帛各有差。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **故汉献帝夫人节薨，帝临于华林园。** 己未，故汉献帝夫人节薨，帝临于华林园，使使持节追谥夫人为献穆皇后。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **及葬，车服制度皆如汉氏故事。** [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **以尚书右仆射王观为司空。** 癸亥，以尚书右仆射王观为司空，冬十月，观去世。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **燕王上表贺冬至，称臣。** 十一月，燕王上表贺冬至，称臣。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **诏曰“古之王者”。** 诏曰：「古之王者，或有所不臣，王将宜依此义。表不称臣乎！又当为报。夫后大宗者，降其私亲，况所继者重邪！若便同之臣妾，亦情所未安。其皆依礼典处，当务尽其宜。」 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **有司奏，以为「礼莫崇于尊祖。** 主管官员奏，以为「礼莫崇于尊祖，制莫大于正典。陛下稽德期运，抚临万国，绍大宗之重，隆三祖之基。伏惟燕王体尊戚属，正位藩服，躬秉虔肃，率蹈恭德以先万国；其于正典，阐济大顺，所不得制。圣朝诚宜崇以非常之制，奉以不臣之礼。臣等平议以为燕王章表，可听如旧式。中诏所施，或存好问，准之义类，则『燕觌之敬』也，可少顺圣敬，加崇仪称，示不敢斥，宜曰『皇帝敬问大王侍御』。至于制书，国之正典，朝廷所以辨章公制，宣昭轨仪于天下者也，宜循法，故曰『制诏燕王』。凡诏命、制书、奏事、上书诸称燕王者，可皆上平。其非宗庙助祭之事，皆不得称王名，奏事、上书、文书及吏民皆不得触王讳，以彰殊礼，加于群后。其余见同号原文。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **黄龙见华阴县井中。** 十二月甲申，黄龙见华阴县井中。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **以司隷校尉王祥为司空。** 甲午，以司隷校尉王祥为司空。 [[23]](#sg-note-23)

<a id="sg-event-24"></a>

24. **陈泰薨。** 陈泰去世，追赠司空，谥穆。 [[24]](#sg-note-24)

<a id="sg-event-25"></a>

25. **追谥关羽等五臣。** 九月追谥关羽、张飞、马超、龐统、黄忠。 [[25]](#sg-note-25)

<a id="sg-event-26"></a>

26. **前吴主孙亮途中自杀。** 会稽谣称孙亮将复立，孙休贬其为候官侯，孙亮赴封国途中自杀。 [[26]](#sg-note-26)

<a id="sg-event-27"></a>

27. **增邑，并前二千五百户。** 景元元年，增邑，并前二千五百户。 [[27]](#sg-note-27)

<a id="sg-event-28"></a>

28. **都尉严密建丹杨湖田，作浦里塘。** 永安三年，都尉严密建丹杨湖田，作浦里塘。 [[28]](#sg-note-28)

### 3. 曹髦出讨司马昭，被成济刺死

<a id="sg004-l270-e3"></a>

**归年与互校** 本纪写卒，并录郭太后令。另见《资治通鉴》据诸书详述成济下手、贾充在场。

<a id="sg004-l270-e3-2"></a>

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p007)** · [仓内TXT L270](../../sources/本地分卷/三国志/三国志-卷004.md#l270)

> 皇太后令曰：「吾以不德，遭家不造，昔援立東海王子髦，以為明帝嗣，見其好書疏文章，兾可成濟，而情性暴戾，日月滋甚。吾數呵責，遂更忿恚，造作醜逆不道之言以誣謗吾，遂隔絕兩宮。其所言道，不可忍聽，非天地所覆載。吾即密有令語大將軍，不可以奉宗廟，恐顛覆社稷，死無面目以見先帝。大將軍以其尚幼，謂當改心為善，殷勤執據。而此兒忿戾，所行益甚，舉弩遙射吾宮，祝當令中吾項，箭親墮吾前。吾語大將軍，不可不廢之，前後數十。此兒具聞，自知罪重，便圖為弒逆，賂遺吾左右人，令因吾服藥，密行酖毒，重相設計。事已覺露，直欲因際會舉兵入西宮殺吾，出取大將軍，呼侍中王沈、散騎常侍王業、尚書王經，出懷中黃素詔示之，言今日便當施行。吾之危殆，過於累卵。吾老寡，豈復多惜餘命邪？但傷先帝遺意不遂，社稷顛覆為痛耳。賴宗廟之靈，沈、業即馳語大將軍，得先嚴警，而此兒便將左右出雲龍門，雷戰鼓，躬自拔刃，與左右雜衞共入兵陣間，為前鋒所害。此兒旣行悖逆不道，而又自陷大禍，重令吾悼心不可言。昔漢昌邑王以罪廢為庶人，此兒亦宜以民禮葬之，當令內外咸知此兒所行。又尚書王經，凶逆無狀，其收經及家屬皆詣廷尉。」

**[《三国志·三少帝纪》裴注 026·1](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-026-1)**

> 漢晉春秋曰帝見威權日去不勝其忿乃召侍中王沈尚書王經散騎常侍王業謂曰司馬昭之心路人所知也吾不能坐受廢辱今日當與卿自出討之王經曰昔魯昭公不忍季氏敗走失國為天下笑今權在其門為日久矣朝廷四方皆為之致死不顧逆順之理非一日也且宿衛空闕兵甲寡弱陛下何所資用而一旦如此無乃欲除疾而更深之邪禍殆不測宜見重詳帝乃出懐中版令投地曰行之決矣正使死何所懼况不必死邪於是入白太后沈業奔走告文王文王為之備

**释读** 《汉晋春秋》记曹髦说“司马昭之心路人所知”，王经以鲁昭公事和宿卫空虚劝阻。曹髦决去，入白太后，王沈、王业先向司马昭报讯。

**归年** 承甘露五年五月己丑曹髦遇害条，是当日起兵前的情节。

<a id="sgz004-p-026-2"></a>

**[《三国志·三少帝纪》裴注 026·2](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-026-2)**

> 帝遂帥僮僕數百鼔譟而出文王弟屯騎校尉伷入遇帝於東止車門左右呵之伷衆奔走中䕶軍賈充又逆帝戰於南闕下帝自用劒衆欲退太子舍人成濟問充曰事急矣當云何充曰畜養汝等正謂今日今日之事無所問也濟即前刺帝刃出於背文王聞大驚自投於地曰天下其謂我何太傅孚奔往枕帝股而哭哀甚曰殺陛下者臣之罪也

**释读** 引《汉晋春秋》，曹髦率数百人出，司马伷部走；贾充拦截，成济听贾充授意刺死曹髦。司马昭称恐天下议论，司马孚抱曹髦而哭。

**归年** 甘露五年五月己丑；与本纪司马昭称下令禁伤的奏书相异。

<a id="sgz004-p-026-3"></a>

**[《三国志·三少帝纪》裴注 026·3](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-026-3)**

> 臣松之以為習鑿齒書雖最後出然述此事差有次第故先載習語以其餘所言㣲異者次其後世語曰王沈王業馳告文王尚書王經以正直不出因沈業申意晉諸公贊曰沈業將出呼王經經不從曰吾子行矣

**释读** 裴松之称习凿齿虽较晚出，叙事最有次序，故列在前。《世语》说王经托王沈、王业转告；《晋诸公赞》说二人招他同去，王经拒绝。

**归年** 同260年五月曹髦遇害之役；评的是记叙方式，托报与不从并存。

<a id="sgz004-p-026-4"></a>

**[《三国志·三少帝纪》裴注 026·4](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-026-4)**

> 于寶晉紀曰成濟問賈充曰事急矣若之何充曰公畜養汝等為今日之事也夫何疑濟曰然乃抽戈犯蹕

**释读** 干宝书称贾充以司马氏养兵正为今日明示，成济抽戈冒犯御驾。

**归年** 同260年五月事件，注文“于寶”保留底本字形，他本作干宝。

<a id="sgz004-p-026-5"></a>

**[《三国志·三少帝纪》裴注 026·5](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-026-5)**

> 魏氏春秋曰戊子夜帝自將冗從僕射李昭黄門從官焦伯等下陵雲臺鎧仗授兵欲因際會自出討文王會雨有司奏却日遂見王經等出黄素詔於懐曰是可忍也孰不可忍也今日便當决行此事入白太后遂拔劒升輦帥殿中宿衛蒼頭官僮擊戰鼔出雲龍門賈充自外而入帝師潰散猶稱天子手劒奮擊衆莫敢逼充帥厲將士騎督成倅弟成濟以矛進帝崩于師時暴雨雷霆晦㝠

**释读** 记前夜曹髦召左右下陵云台武装，因下雨延迟，继而向王经等出示黄素诏、入白太后、出云龙门；贾充遇曹髦，成济持矛刺死。

**归年** 甘露五年五月戊子夜至次日己丑；与《晋书·文帝纪》相近。

<a id="sy-sg064-l3031-e28"></a>

**[《三国志·诸葛滕二孙濮阳传》](../../sources/摘录/三国志-卷064-诸葛滕二孙濮阳传.md#p006)** · [仓内TXT L3031](../../sources/本地分卷/三国志/三国志-卷064.md#L3031)

> 詔百官會議，咸以為用功多而田不保成，唯興以為可成。遂會諸兵民就作，功傭之費不可勝數，士卒死亡，或自賊殺，百姓大怨之。

**本段所记** 百官多认为造田工程耗费巨大、未必成功，濮阳兴支持兴建。征发兵民后，工程费用和死伤严重，引发民怨。

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **日有蚀之。** 二年夏五月朔，发生日食。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **乐浪外夷韩、濊貊各率其属来朝贡。** 秋七月，乐浪外夷韩、濊貊各率其属来朝贡。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **赵王干薨。** 八月戊寅，赵王干去世。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **复命大将军进爵晋公，加位相国。** 甲寅，复命大将军进爵晋公，加位相国，备礼崇锡，一如前诏；又固辞乃止。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **赵云被追谥。** 蜀汉三月追谥赵云。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **杨戏去世。** 因与姜维不合而免官为民，杨戏于景耀四年病卒。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **吴使周弈、石伟巡察风俗。** 孙休遣二位光禄大夫访察各地吏治与民间疾苦，为官员黜陟做准备。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **襄阳太守表吴贼邓由等欲来归化。** 景元二年，襄阳太守表吴贼邓由等欲来归化，基被诏，当因此震荡江表。 [[8]](#sg-note-8)

<a id="sgz-event-19"></a>

<a id="sg-event-9"></a>

9. **州泰去世。** 州泰于本年去世。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **诏曰“安平王”。** 景耀四年诏曰：「安平王，先帝所命。三世早夭，国嗣颓绝，朕用伤悼。其以武邑侯辑袭王位。」 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **为行都护卫将军，与辅国大将军南乡侯董厥并平尚书事。** 景耀四年，为行都护卫将军，与辅国大将军南乡侯董厥并平尚书事。 [[11]](#sg-note-11)

<a id="sgz-event-12"></a>

12. **蜀汉十月大赦。** 蜀汉冬十月大赦。 [[12]](#sgz-note-12)

<a id="sgz-event-13"></a>

13. **吴遇暴雨，水泉上涨。** 五月大雨，水泉涌溢。 [[13]](#sgz-note-13)

<a id="sgz-event-14"></a>

14. **布山县报告见白龙。** 九月布山称见白龙。 [[14]](#sgz-note-14)

<a id="sgz-event-15"></a>

15. **安吴陈焦死后复生的传闻。** 传称安吴民陈焦下葬六日后，从土中穿出重新活了。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **王基去世，赠司空、谥景侯。** 王基死，子王徽承嗣。 [[16]](#sgz-note-16)

<a id="sgz-event-17"></a>

17. **孙休使薛珝至蜀求马。** 五官中郎将薛珝奉使蜀汉求马；归来答孙休，以燕雀处堂比刘禅暗弱、臣下自保、百姓饥色不觉危亡。 [[17]](#sgz-note-17)

<a id="sgz-event-18"></a>

18. **孙该卒于官。** 景元二年。 [[18]](#sgz-note-18)

### 8. 襄阳太守表吴贼邓由等欲来归化

[返回正文第8条](#sg-event-8)

<a id="sg027-l1437-e8"></a>

**[《三国志·徐胡二王传》](../../sources/本地分卷/三国志/三国志-卷027.md#p004)** · [仓内TXT L1437](../../sources/本地分卷/三国志/三国志-卷027.md#l1437)

> 景元二年，襄陽太守表吳賊鄧由等欲來歸化，基被詔，當因此震蕩江表。

**归年与互校** 原传明记年号和年次；后续回叙见本卷。

<a id="sgz027-b-1437-1"></a>

**[《三国志·徐胡二王传》仓内原文 L1437](../../sources/本地分卷/三国志/三国志-卷027.md#l1437)**

> 景元二年，襄陽太守表吳賊鄧由等欲來歸化，基被詔，當因此震蕩江表。基疑其詐，馳驛陳狀。且曰：「嘉平以來，累有內難，當今之務，在於鎮安社稷，綏寧百姓，未宜動衆以求外利。」文王報書曰：「凡處事者，多曲相從順，鮮能確然共盡理實。誠感忠愛，每見規示，輙敬依來指。」後由等竟不降。

**释读** 王基疑吴降有诈，言国内迭有事变，应安社稷绥民。司马昭采纳，吴方果不降。

**归年** 本传景元二年，裴注《战略》及《通鉴》卷七十七明记春事。

<a id="sgz027-p-015-1"></a>

**[《三国志·徐胡二王传》裴注 015·1](../../sources/本地分卷/三国志/三国志-卷027.md#pei-015-1)**

> 司馬彪戰畧載基此事詳於本傳曰景元二年春三月襄陽太守胡烈表上吳賊鄧由李光等同謀十八屯欲来歸化遣将張吳鄧生并送質任克期欲令郡軍臨江迎㧞大将軍司馬文王啓聞詔征南将軍王基部分諸軍使烈督萬人徑造沮水荆州義陽南屯宜城承書夙發若由等如期到者便當因此震蕩江表

**释读** 胡烈奏吴十八屯愿降，遣张吴、邓生送人质，约期迎接。司马昭转奏，令王基部分军队，胡烈率万军去沮水，各屯将发。

**归年** 《战略》明景元二年三月，《通鉴》卷七十七同事。

<a id="sgz027-p-015-2"></a>

**[《三国志·徐胡二王传》裴注 015·2](../../sources/本地分卷/三国志/三国志-卷027.md#pei-015-2)**

> 基疑賊詐降誘致官兵馳驛止文王説由等可疑之状且當清澄未宜便舉重兵深入應之又曰夷陵東道當由車御至赤岸乃得渡沮西道當出箭谿口乃趣平土皆山險狹竹木叢蔚卒有要害弩馬不陳今者筋角弩弱水潦方降廢盛農之務徼難必之利此事之危者也

**释读** 王基猜疑敌计，分析夷陵两路皆险、梅雨不便，认为不宜弃农时谋未必之利。

**归年** 春季同一次决策，地理引据见原文。

<a id="sgz027-p-015-3"></a>

**[《三国志·徐胡二王传》裴注 015·3](../../sources/本地分卷/三国志/三国志-卷027.md#pei-015-3)**

> 昔子午之役兵行數百里而值淋雨橋閣破壊後糧腐敗前軍縣乏姜維深入不待輜重士衆饑餓覆軍上邽文欽唐咨舉吳重兵昧利夀春身沒不反此皆近事之鍳戒也嘉平以來累有内難當今之宜當鎮安社稷撫寧上下力農務本懐柔百姓未宜動衆以求外利也得之未足為多失之傷損威重

**释读** 借子午之役、姜维深入吃败仗、吴军陷寿春为戒。自嘉平以来多内难，应务农、安抚百姓，得失需要权衡。

**归年** 同一景元二年奏劝；当中诸役讨论为旧事。

<a id="sgz027-p-015-4"></a>

**[《三国志·徐胡二王传》裴注 015·4](../../sources/本地分卷/三国志/三国志-卷027.md#pei-015-4)**

> 文王累得基書意疑尋勅諸軍已上道者且權停住所在須後節度基又言於文王曰昔漢祖納酈生之説欲封六國寤張良之謀而趣銷印基謀慮淺短誠不及留侯亦懼襄陽有食其之謬

**释读** 司马昭渐有疑虑，命在原处候节度。王基再以张良谏罢封六国比况，劝其收回成命。

**归年** 《战略》景元二年同一史事。

<a id="sgz027-p-015-5"></a>

**[《三国志·徐胡二王传》裴注 015·5](../../sources/本地分卷/三国志/三国志-卷027.md#pei-015-5)**

> 文王於是遂罷軍嚴後由等果不降

**释读** 王基进言后，司马昭止军，后来邓由等没有来降。

**归年** 同年，正文略记果不降，裴注补决策详细进程。

**释读** 诸葛瞻始参与统理朝事，廖化想邀宗预拜会，宗预说两人皆逾七十、没什么要求年轻人，未去。

**归年** 《诸葛亮传》附诸葛瞻，景耀四年为行都护卫将军，与董厥并平尚书事。

## 本年概述

樂浪外韓、濊貊等部向魏朝貢。魏再命司馬昭進封相國、晉公。吳遣使蜀求馬並派員巡察州郡，蜀追諡趙雲。

## 魏廷政事與邊務

<a id="sg-event-1"></a>

1. **魏五月日食。** 五月朔，魏记日食。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **乐浪以外的韩、濊貊遣使来魏。** 七月，乐浪郡外的韩、濊貊各率所部来朝贡。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **魏赵王曹干去世。** 八月戊寅，赵王曹干去世。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **魏复命司马昭进位，司马昭仍辞。** 八月甲寅，魏再命大将军司马昭封晋公、进位相国，加九锡，礼同前诏；司马昭坚辞。 [[4]](#sg-note-4)

<a id="sg-event-8"></a>

5. **吴将称降，王基劝魏暂缓出兵。** 三月，襄阳太守胡烈报告，吴将邓由、李光等十八屯愿降，并已遣使送来人质。魏原命王基调兵，令胡烈率一万人向沮水接应。王基怀疑对方诱敌，又指出夷陵山路险窄，雨季将至，仓促出兵还会耽误农耕。司马昭先命已出发的军队停在原地，随后撤销接应。邓由等果然没有归降。 [[5]](#sg-note-8)

<a id="sgz-event-19"></a>

<a id="sg-event-9"></a>

6. **州泰去世。** 州泰去世，魏追赠卫将军，谥壮侯。 [[6]](#sg-note-9)

<a id="sgz-event-16"></a>

7. **王基去世，赠司空、谥景侯。** 王基本年去世，魏追赠司空，谥景侯，由儿子王徽承袭。 [[7]](#sgz-note-16)

### 5. 襄阳太守表吴贼邓由等欲来归化

[返回正文第5条](#sg-event-8)

<a id="wei027-l86-1"></a>

<a id="wei027-l87-1"></a>

**[《三國志·徐胡二王傳》](../../拆分史书/三国志/卷027.md#edition-wei027-l86-1)** · [TXT L86](../../拆分史书/三国志/卷027.txt#L86) · [TXT L87（裴注）](../../拆分史书/三国志/卷027.txt#L87)

> 景元二年，襄陽太守表吳賊鄧由等欲來歸化，基被詔，當因此震蕩江表。基疑其詐，馳驛陳狀。且曰：「嘉平以來，累有內難，當今之務，在於鎮安社稷，綏寧百姓，未宜動衆以求外利。」文王報書曰：「凡處事者，多曲相從順，鮮能確然共盡理實。誠感忠愛，每見規示，輙敬依來指。」後由等竟不降。
>
> **〔裴注〕**
> 司馬彪戰畧載基此事，詳於本傳。曰：「景元二年春三月，襄陽太守胡烈表上『吳賊鄧由、李光等，同謀十八屯，欲來歸化，遣將張吳、鄧生，并送質任。克期欲令郡軍臨江迎拔』。大將軍司馬文王啟聞。詔征南將軍王基部分諸軍，使烈督萬人徑造沮水，荊州、義陽南屯宜城，承書夙發。若由等如期到者，便當因此震蕩江表。基疑賊詐降，誘致官兵，馳驛止文王，說由等可疑之狀。『且當清澄，未宜便舉重兵深入應之』。又曰：『夷陵東道，當由車御，至赤岸乃得渡坦，西道當出箭谿口，乃趣平土，皆山險狹，竹木叢蔚，卒有要害，弩馬不陳。今者筋角弩弱，水潦方降，廢盛農之務，徼難必之利，此事之危者也。昔子午之役，兵行數百里而值霖雨，橋閣破壞，後糧腐敗，前軍縣乏。姜維深入，不待輜重，士衆飢餓，覆軍上邽。文欽、唐咨，舉吳重兵，昧利壽春，身歿不反。此皆近事之鑒戒也。嘉平以來，累有內難。當今之宜，當鎮安社稷，撫寧上下，力農務本，懷柔百姓，未宜動衆以求外利也。得之未足爲多，失之傷損威重。』文王累得基書，意疑。尋勑諸軍已上道者，且權停住所在，須後節度。基又言於文王曰：『昔漢祖納酈生之說，欲封六國，寤張良之謀，而趣銷印。基謀慮淺短，誠不及留侯，亦懼襄陽有食其之謬。』文王於是遂罷軍嚴，後由等果不降。」

**釋讀與歸年** 景元二年吳將鄧由等稱將歸降，王基疑有詐，馳驛勸司馬昭以安定社稷民生為先。司馬昭從其議，鄧由等果未降。裴注詳記同事在三月。

**釋讀與歸年** 司馬彪《戰略》載襄陽太守胡烈稱鄧由、李光等十八屯願降，魏詔軍進沮水、宜城；王基以地勢、水潦、農時與近期深進敗績為由，連書請先審真偽，終使司馬昭止軍。[《資治通鑑》卷七十七](../../史书/025-资治通鉴/KR2b0007_077.txt#L572-L598)亦繫景元二年三月。裴注所引章表、往返書與本傳合讀。

> 秋八月，遣光祿大夫周弈、石偉巡行風俗，察將吏清濁，民所疾苦，爲黜陟之詔。

### 18. 孙休使薛珝至蜀求马

[返回正文第18条](#sgz-event-17)

<a id="sgz053-p-022-1"></a>

<a id="wu053-l83-1"></a>

**[《三國志·張嚴程闞薛傳》裴注 022](../../拆分史书/三国志/卷053.md#edition-wu053-l83-1)** · [TXT L83](../../拆分史书/三国志/卷053.txt#L83)

> 漢晉春秋曰：孫休時，珝爲五官中郎將，遣至蜀求馬。及還，休問蜀政得失，對曰：「主闇而不知其過，臣下容身以求免罪，入其朝不聞正言，經其野民皆菜色。臣聞燕雀處堂，子母相樂，自以爲安也，突決棟焚，而燕雀怡然不知禍之將及，其是之謂乎！」

**釋讀** 孫休派五官中郎將薛珝出使求馬。回國後，他以堂上燕雀未察屋將被燒作比，指出蜀主昏昧、臣下求自保，百姓有饑色。

**歸年** 裴注引《漢晉春秋》只作孫休時。《資治通鑑》卷七十七把薛珝出使及回國後的答話繫於蜀景耀四年（261），今從此。《建康實錄》卷三把遣使繫於吳永安三年（260）春。

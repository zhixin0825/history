# 公元261年｜魏景元二年／蜀景耀四年／吴永安四年

[← 公元260年](ce-0260.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元262年 →](ce-0262.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **日有蚀之。** 二年夏五月朔，发生日食。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **乐浪外夷韩、濊貊各率其属来朝贡。** 秋七月，乐浪外夷韩、濊貊各率其属来朝贡。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **赵王干薨。** 八月戊寅，赵王干去世。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **复命大将军进爵晋公，加位相国。** 甲寅，复命大将军进爵晋公，加位相国，备礼崇锡，一如前诏；又固辞乃止。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **赵云被追谥。** 蜀汉三月追谥赵云。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **杨戏去世。** 因与姜维不合而免官为民，杨戏于景耀四年病卒。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **吴使周弈、石伟巡察风俗。** 孙休遣二位光禄大夫访察各地吏治与民间疾苦，为官员黜陟做准备。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **襄阳太守表吴贼邓由等欲来归化。** 景元二年，襄阳太守表吴贼邓由等欲来归化，基被诏，当因此震荡江表。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **州泰去世。** 州泰于本年去世。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **诏曰“安平王”。** 景耀四年诏曰：「安平王，先帝所命。三世早夭，国嗣颓绝，朕用伤悼。其以武邑侯辑袭王位。」 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **为行都护卫将军，与辅国大将军南乡侯董厥并平尚书事。** 景耀四年，为行都护卫将军，与辅国大将军南乡侯董厥并平尚书事。 [[11]](#sg-note-11)

<a id="sgz-event-12"></a>

12. **蜀汉十月大赦。** 蜀汉冬十月大赦。 [[12]](#sgz-note-12)

<a id="sgz034-b-1746-9"></a>

**[《三国志·二主妃子传》仓内原文 L1746](../../sources/本地分卷/三国志/三国志-卷034.md#l1746)**

> 景耀四年詔曰：「安平王，先帝所命。三世早夭，國嗣頹絕，朕用傷悼。其以武邑侯輯襲王位。」輯，理子也，

**释读** 刘禅以安平三代王都早逝、国嗣衰落为由，命武邑侯刘辑袭王；刘辑是刘理之子。

**归年** 本传明书景耀四年，即261。

# 公元261年｜魏景元二年／蜀景耀四年／吴永安四年

[← 公元260年](ce-0260.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元262年 →](ce-0262.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **日有蚀之。** 二年夏五月朔，发生日食。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **乐浪外夷韩、濊貊各率其属来朝贡。** 秋七月，乐浪外夷韩、濊貊各率其属来朝贡。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **赵王干薨。** 八月戊寅，赵王干去世。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **复命大将军进爵晋公，加位相国。** 甲寅，复命大将军进爵晋公，加位相国，备礼崇锡，一如前诏；又固辞乃止。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **赵云被追谥。** 蜀汉三月追谥赵云。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **杨戏去世。** 因与姜维不合而免官为民，杨戏于景耀四年病卒。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **吴使周弈、石伟巡察风俗。** 孙休遣二位光禄大夫访察各地吏治与民间疾苦，为官员黜陟做准备。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **襄阳太守表吴贼邓由等欲来归化。** 景元二年，襄阳太守表吴贼邓由等欲来归化，基被诏，当因此震荡江表。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **州泰去世。** 州泰于本年去世。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **诏曰“安平王”。** 景耀四年诏曰：「安平王，先帝所命。三世早夭，国嗣颓绝，朕用伤悼。其以武邑侯辑袭王位。」 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **为行都护卫将军，与辅国大将军南乡侯董厥并平尚书事。** 景耀四年，为行都护卫将军，与辅国大将军南乡侯董厥并平尚书事。 [[11]](#sg-note-11)

<a id="sgz-event-12"></a>

12. **蜀汉十月大赦。** 蜀汉冬十月大赦。 [[12]](#sgz-note-12)

<a id="sgz-event-13"></a>

13. **吴遇暴雨，水泉上涨。** 五月大雨，水泉涌溢。 [[13]](#sgz-note-13)

<a id="sgz-event-14"></a>

14. **布山县报告见白龙。** 九月布山称见白龙。 [[14]](#sgz-note-14)

<a id="sgz-event-15"></a>

15. **安吴陈焦死后复生的传闻。** 传称安吴民陈焦下葬六日后，从土中穿出重新活了。 [[15]](#sgz-note-15)

<a id="sgz036-b-1815-3"></a>

**释读** 赵云也获追谥，舆论视为荣光。

**归年** 《后主传》景耀四年赵云追谥；“时论”是历次追谥的反响。

<a id="sgz036-p-022-1"></a>

**[《三国志·关张马黄赵传》裴注 022·1](../../sources/摘录/三国志-卷036-关张马黄赵传裴注.md#pei-022-1)**

> 雲别傳載後主詔曰雲昔從先帝功績既著朕以㓜冲渉塗艱難頼恃忠順濟於危險夫諡所以叙元勲也外議雲宜諡

**释读** 刘禅说赵云曾事刘备且幼时救己，勋可入谥议。

**归年** 《后主传》景耀四年明确谥赵云。

<a id="sgz036-p-022-2"></a>

**[《三国志·关张马黄赵传》裴注 022·2](../../sources/摘录/三国志-卷036-关张马黄赵传裴注.md#pei-022-2)**

> 大將軍姜維等議以為雲昔從先帝勞績既著經營天下遵奉法度功效可書當陽之役義貫金石忠以衛上君念其賞禮以厚下臣忘其死死者有知足以不朽生者感恩足以殞身謹按諡法柔賢慈恵曰順執事有班曰平克定祸亂曰平應諡雲曰順平侯

**释读** 姜维等以事主、守法和长坂救主说明其功，以柔贤慈惠、执事有班、克定祸乱议顺平。

**归年** 景耀四年赵云追谥，关张等在上年已谥。

**[《三国志·二主妃子传》](../../sources/摘录/三国志-卷034-二主妃子传.md#p003)** · [仓内TXT L1746](../../sources/本地分卷/三国志/三国志-卷034.md#l1746)

<a id="sgz034-b-1746-9"></a>

**[《三国志·二主妃子传》仓内原文 L1746](../../sources/本地分卷/三国志/三国志-卷034.md#l1746)**

> 景耀四年詔曰：「安平王，先帝所命。三世早夭，國嗣頹絕，朕用傷悼。其以武邑侯輯襲王位。」輯，理子也，

**释读** 刘禅以安平三代王都早逝、国嗣衰落为由，命武邑侯刘辑袭王；刘辑是刘理之子。

**归年** 本传明书景耀四年，即261。

> 時都護諸葛瞻初統朝事，廖化過預，欲與預共詣瞻許。預曰：「吾等年逾七十，所竊已過，但少一死耳，何求於年少輩而屑屑造門邪？」遂不往。

**释读** 诸葛瞻始参与统理朝事，廖化想邀宗预拜会，宗预说两人皆逾七十、没什么要求年轻人，未去。

**归年** 《诸葛亮传》附诸葛瞻，景耀四年为行都护卫将军，与董厥并平尚书事。

## 本年概述

姜維攻洮陽，鄧艾出兵抵禦。魏任鍾會鎮西將軍，令他督關中軍事。吳立朱氏為皇后並立太子，任濮陽興為丞相。

## 魏蜀交兵與魏廷紀事

<a id="sg-event-3"></a>

1. **姜维请诛黄皓未果，后来兵败侯和。** 《华阳国志》本年条先记姜维请求刘禅诛杀黄皓，刘禅未从，命黄皓向姜维道歉；姜维又求在沓中种麦，以避朝内逼迫。到冬十月，姜维进攻洮阳，被魏镇西将军邓艾击败于侯和，退驻沓中；《华阳国志》把此战列为秋，两书记月有异。《姜维传》以黄皓、阎宇的排挤说明姜维不再回成都，不能把请杀黄皓的前情倒放在败后。《汉晋春秋》记廖化在这次出兵时批评姜维用兵无休，认为其智力未胜敌而兵力较少，难以持久。 [[1]](#sg-note-3)

<a id="sg-event-6"></a>

2. **魏任钟会为镇西将军，准备攻蜀。** 冬，魏命钟会为镇西将军，假节都督关中诸军事，准备攻蜀。司马昭让青、徐、兖、豫、荆、扬六州造船，又命唐咨建造海船，向外示意将攻吴。辛宪英问羊祜钟会为何出镇。得知将要伐蜀后，她担心钟会恃权另有所图。 [[2]](#sg-note-6)

<a id="sg-event-1"></a>

3. **轵县报井中见青龙。** 二月，轵县报井中出现青龙。 [[3]](#sg-note-1)

<a id="sg-event-2"></a>

4. **肃慎遣使来魏进贡。** 四月，辽东郡报告肃慎多次转译遣使来贡，献三十张弓、长三尺五寸的楛矢、三百枚石箭头、二十领皮骨铁杂铠及四百枚貂皮。 [[4]](#sg-note-2)

<a id="sg-event-4"></a>

5. **魏在曹操庙庭祭祀郭嘉。** 这一年，朝廷下诏在曹操庙庭祭祀已故军祭酒郭嘉。 [[5]](#sg-note-4)

<a id="sy-event-8"></a>

6. **谯周忧蜀政，题字示意。** 在黄皓已弄权的背景下，本年宫中大树折断。谯周忧虑国势，以“曹”“魏”“备”“禅”的字义写下题柱隐语，暗指魏将统一、刘氏将让国。 [[6]](#sy-note-8)

<a id="sgz-event-9"></a>

7. **西河王刘琮去世。** 刘琮于正月去世。 [[7]](#sgz-note-9)

<a id="sgz-event-15"></a>

8. **吕安和嵇康一同被杀。** 吕安与嵇康交好。吕巽侵害弟弟吕安的妻子，又诬告吕安不孝，吕安被收系，嵇康为他作证，也被下狱。钟会向司马昭进言，二人终于一同被杀。临刑时，嵇康索琴弹奏。 [[8]](#sgz-note-15)

### 1. 姜维请诛黄皓未果，后来兵败侯和

[返回正文第1条](#sg-event-3)

<a id="shu044-l64-2"></a>

**[《三國志·蔣琬費禕姜維傳》正文及裴注](../../拆分史书/三国志/卷044.md#edition-shu044-l64-2)** · [TXT L64](../../拆分史书/三国志/卷044.txt#L64) · [TXT L65](../../拆分史书/三国志/卷044.txt#L65)

> 維本羈旅託國，累年攻戰，功績不立，而宦臣黃皓等弄權於內，右大將軍閻宇與皓恊比，而皓陰欲廢維樹宇。維亦疑之。故自危懼，不復還成都。
>
> **〔裴注〕**
>
> 華陽國志曰；維惡黃皓恣擅，啟後主欲殺之。後主曰：「皓趨走小臣耳，往董允切齒，吾常恨之，君何足介意！」維見皓枝附葉連，懼於失言，遜辭而出。後主勑皓詣維陳謝。維說皓求沓中種麥，以避內逼爾。

**释读** 本传说姜维作为入蜀之人，连年攻战却未建立决定性的功业；黄皓在朝中专权，与右大将军阎宇相结，想废去姜维、改用阎宇。姜维也有所怀疑，担忧自身处境，因而不再回成都。《华阳国志》另记姜维曾请求刘禅诛杀黄皓，刘禅却把黄皓看成供役使的小臣，认为不必在意；姜维见黄皓党羽众多，担心失言，改以谦辞退出。刘禅命黄皓向姜维道歉，姜维又向黄皓求在沓中种麦，以避开朝内逼迫。

**归年与互校** [《华阳国志》卷七景耀五年条](../../史书/062-华阳国志/KR2i0003_007.txt#L337-L347)在侯和战事以前记请诛黄皓、后主答话、黄皓道歉及求种麦，故这组问答依原引书系262。裴注摘录没有带出年标，不能据摘录无年便忽略原书明年。黄皓树党、姜维长期处境及“功绩不立”仍属背景评价，不都当成262新事。该书侯和作秋，[《三少帝纪》](../../拆分史书/三国志/卷004.txt#L189)作冬十月；战役主叙从魏纪，月份异载并存。

**归年与互校** 景耀五年即262年，[《后主传》](../../拆分史书/三国志/卷033.txt#L97)、[《邓艾传》景元三年条](../../拆分史书/三国志/卷028.txt#L113)一致；[《三少帝纪》](../../拆分史书/三国志/卷004.txt#L189)明确在冬十月，并先记寇洮阳。本底本“出汉、侯和”的原字与标点照录，不据此擅分成两场同年战役。


<a id="shu045-l33-1"></a>

**[《三國志·鄧張宗楊傳》注文](../../拆分史书/三国志/卷045.md#edition-shu045-l33-1)** · [TXT L33](../../拆分史书/三国志/卷045.txt#L33)

> **〔裴注〕**
>
> 漢晉春秋曰：景耀五年，姜維率衆出狄道，廖化曰：「『兵不戢，必自焚』，伯約之謂也。智不出敵，而力少於寇，用之無厭，何以能立？詩云『不自我先，不自我後』，今日之事也。」

**释读** 《汉晋春秋》记，景耀五年，姜维率军出狄道，廖化说：“兵力不加节制地使用，必将反过来烧毁自己”，说的就是伯约。廖化认为，姜维的智谋不超过敌手，兵力又少于敌人，却仍无休止地用兵，国家怎能立得住？他又借《诗》“不自我先，不自我后”感叹，这种祸患偏偏不在自己之前、也不在自己之后发生，自己正碰上了这样的时代。

**归年与互校** 裴注明确景耀五年（262）。[《后主传》](../../拆分史书/三国志/卷033.txt#L97)同年记姜维出侯和、为邓艾所破；本注写“出狄道”，保留各自地名，不擅改成同一句原文。廖化的忧虑是当时人物发言，不据蜀汉后来灭亡倒写为必然预言。

> 景耀五年，宮中大樹無故自折，周深憂之，無所與言，乃書柱曰：「衆而大，期之會，具而授，若何復？」言曹者衆也，魏者大也，衆而大，天下其當會也。具而授，如何復有立者乎？

> 吳錄載休詔曰：「人之有名，以相紀別，長爲作字，憚其名耳。禮，名子欲令難犯易避，五十稱伯仲，古或一字。今人競作好名好字，又令相配，所行不副，此瞽字伯明者也，孤常哂之。或師友父兄所作，或自己爲；師友尚可，父兄猶非，自爲最不謙。孤今爲四男作名字：太子名𩅦，𩅦音如湖水灣澳之灣，字莔，莔音如迄今之迄；次子名𩃙，𩃙音如兕觥之觥，字𧟨，𧟨音如玄礥首之礥；次子名壾，壾音如草莽之莽，字昷，昷音如舉物之舉；次子名𠅬，𠅬音如襃衣下寬大之襃，字㷏，㷏音如有所擁持之擁。此都不與世所用者同，故鈔舊文會合作之。夫書八體損益，因事而生，今造此名字，旣不相配，又字但一，庶易棄避，其普告天下，使咸聞知。」

> 休欲與愽士祭酒韋曜、博士盛沖講論道藝，曜、沖素皆切直，布恐入侍，發其陰失，令己不得專，因妄飾說以拒遏之。休荅曰：「孤之涉學，羣書略徧，所見不少也；其明君闇王，姦臣賊子，古今賢愚成敗之事，無不覽也。今曜等入，但欲與論講書耳，不爲從曜等始更受學也。縱復如此，亦何所損？君特當以曜等恐道臣下姦變之事，以此不欲令入耳。如此之事，孤已自備之，不須曜等然後乃解也。此都無所損，君意特有所忌故耳。」布得詔陳謝，重自序述，又言懼妨政事。休荅曰：「書籍之事，患人不好，好之無傷也。此無所爲非，而君以爲不宜，是以孤有所及耳。王務學業，其流各異，不相妨也。不圖君今日在事，更行此於孤也，良所不取。」布拜表叩頭，休荅曰：「聊相開悟耳，何至叩頭乎！如君之忠誠，遠近所知。往者所以相感，今日之巍巍也。詩云：『靡不有初，鮮克有終。』終之實難，君其終之。」

**附敘** 接敘張布倚仗舊寵、阻孫休與韋曜及盛冲論學。傳文在拜相之後回顧朝中用人，論學事的確年未載。

> 又欲延曜侍講，而左將軍張布近習寵幸，事行多玷，憚曜侍講儒士，又性精确，懼以古今警戒休意，固爭不可。休深恨布，語在休傳。然曜竟止不入。

**釋讀** 孫休想請韋曜侍講。受寵的左將軍張布行為多有污點，因韋曜學問明審而持論精確，怕他援引古今警戒孫休，極力阻止。孫休對張布不滿，韋曜終究沒有入內講學。

**歸年** [《孫休傳》](../../拆分史书/三国志/卷048.txt#L58)與張布典宮省、濮陽興掌軍國連敘，兼記擬召盛沖。附262年委政一條，講學之議無獨立確年。

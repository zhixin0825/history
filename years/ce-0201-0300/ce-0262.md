[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **青龙见于轵县井中。** 三年春二月，青龙见于轵县井中。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **辽东郡言肃慎国遣使重译入贡。** 夏四月，辽东郡言肃慎国派使重译入贡，献其国弓三十张，长三尺五寸，楛矢长一尺八寸，石砮三百枚，皮骨铁杂铠二十领，貂皮四百枚。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **蜀大将姜维寇洮阳，镇西将军邓艾拒之。** 冬十月，蜀大将姜维寇洮阳，镇西将军邓艾拒之，破维于侯和，维遁走。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **是岁，诏祀故军祭酒郭嘉于太祖庙庭。** 当年，诏祀故军祭酒郭嘉于太祖庙庭。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **孙休立朱氏为后，立子为太子。** 永安五年八月立朱皇后和太子，十月任濮阳兴为丞相。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **以会为镇西将军、假节都督关中诸军事。** 景元三年冬，以会为镇西将军、假节都督关中诸军事。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **立夫人为皇后。** 永安五年，立夫人为皇后。 [[7]](#sg-note-7)

<a id="sy-event-8"></a>

8. **谯周忧蜀政，题字示意。** 宦官黄皓弄权时，宫中大树折断。谯周忧虑国势，以题柱隐语暗指魏将吞并蜀。 [[8]](#sy-note-8)

<a id="sgz-event-9"></a>

9. **西河王刘琮去世。** 刘琮于正月去世。 [[9]](#sgz-note-9)

> 五年，維率眾出漢、侯和，為鄧艾所破，還住沓中。

<a id="sgz044-p-012-2"></a>

**[《三国志·蒋琬费祎姜维传》裴注 012·2](../../sources/摘录/三国志-卷044-蒋琬费祎姜维传裴注.md#pei-012-2)**

> 維說皓求沓中種麥以避内逼爾

**释读** 姜维说服黄皓，让自己在沓中种麦，借此避开成都朝中的排挤和压力。

**归年** 《资治通鉴》卷078明系景元三年姜维返自洮阳后求屯种，吕思勉等后世辨说不作为本条依据。

<a id="sgz045-p-007-1"></a>

**[《三国志·邓张宗杨传》裴注 007·1](../../sources/摘录/三国志-卷045-邓张宗杨传裴注.md#pei-007-1)**

> 漢晉春秋曰景耀五年姜維率衆出狄道廖化曰兵不戢必自焚伯約之謂也知不出敵而力少於㓂用之無厭何以能立詩云不自我先不自我後今日之事也

**释读** 《汉晋春秋》记姜维出狄道，廖化引“兵不戢，必自焚”，指出实力不足而连年动兵难以立国，又以《诗》句伤叹正当其时。

**归年** 注文景耀五年；《通鉴》卷078在洮阳、侯和之战前列此进谏。与《陈留王纪》洮阳地名叙写角度不同，从当年同次出师。

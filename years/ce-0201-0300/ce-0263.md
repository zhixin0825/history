[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **二月诏增司马昭爵邑，他辞谢。** 四年春二月，复命大将军进位爵赐一如前诏，又固辞乃止。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **魏出兵攻蜀。** 魏五月诏邓艾和诸葛绪攻蜀，另派钟会从骆谷出兵。同年秋三路军进发。蜀派张翼、廖化等抵御，改元炎兴。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **太尉高柔薨。** 秋九月，太尉高柔去世。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **十月再诏增司马昭爵邑。** 冬十月甲寅，复命大将军进位爵赐一如前诏。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **立皇后卞氏，十一月。** 癸卯，立皇后卞氏，十一月，大赦。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **刘禅降魏。** 刘禅采纳谯周的劝告，派人向邓艾请降，随后亲至军营。魏军接管巴蜀。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **以司徒郑冲为太保。** 十二月庚戌，以司徒郑冲为太保。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **分益州为梁州。** 壬子，分益州为梁州。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **特赦益州士民，复除租赋之半。** 癸丑，特赦益州士民，复除租赋之半。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **魏授邓艾为太尉、钟会为司徒。** 五年乙卯，以征西将军邓艾为太尉，镇西将军锺会为司徒。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **明元郭太后去世。** 皇太后崩。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **邓艾越阴平破绵竹。** 邓艾由阴平险道进军，降江由守将马邈，继而在绵竹斩诸葛瞻等。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **姜维率蜀军降钟会。** 钟会攻剑阁未下，邓艾破绵竹后刘禅命姜维投降；姜维在郪县令人放下兵器，赴钟会军。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **沔阳立诸葛亮庙。** 蜀于沔阳立庙，钟会进军汉川时祭庙并禁扰墓侧。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **绵竹战败，蜀汉降魏。** 诸葛瞻率军与邓艾交战，阵亡于绵竹。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **蜀汉降魏后的南中与巴东。** 霍弋与罗宪各保一方，听命内附，朝廷保留其职。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **姜维守剑阁。** 姜维、张翼、董厥等并军守剑阁，钟会因粮运困难考虑退军。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **交阯吕兴等起事，杀太守孙諝。** 交阯吏吕兴等因地方官频繁征发工匠，联结当地兵民起事，杀孙諝。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **魏攻蜀，吴分军援救。** 吴军分路行动，丁奉向寿春，留平到南郡与施绩商议，丁封、孙异到沔中。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **蜀亡后吴遣钟离牧镇武陵。** 魏灭蜀后，吴廷担心武陵五溪边境动乱，任钟离牧为平魏将军、武陵太守。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **蜀亡后华覈陈忧。** 华覈闻蜀被魏吞并，赴宫门上表，忧西部屏障已失。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **钟毓去世。** 钟毓于本年去世。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **封肃子恂爲兰陵侯。** 景元四年，封肃子恂爲兰陵侯。 [[23]](#sg-note-23)

<a id="sgz-event-24"></a>

24. **蜀汉大赦、改元炎兴。** 蜀汉大赦，改元炎兴。 [[24]](#sgz-note-24)

> 夏五月，詔曰：「蜀，蕞爾小國，土狹民寡，而姜維虐用其衆，曾無廢志；往歲破敗之後，猶復耕種沓中，刻剝衆羌，勞役無已，民不堪命。夫兼弱攻昧，武之善經，致人而不至於人，兵家之上略。蜀所恃賴，唯維而已，因其遠離巢窟，用力為易。今使征西將軍鄧艾督帥諸軍，趣甘松、沓中以羅取維，雍州刺史諸葛緒督諸軍趣武都、高樓，首尾踧討。若禽維，便當東西並進，掃滅巴蜀也。」

**归年** 《常道乡公纪》景元四年十一月记刘禅降，《谯周传》详廷议。

<a id="sgz033-b-1724-1"></a>

**[《三国志·后主传》仓内原文 L1724](../../sources/本地分卷/三国志/三国志-卷033.md#l1724)**

> 限分江、漢，遇值深遠，階緣蜀土，斗絕一隅，干運犯冒，漸苒歷載，遂與京畿攸隔萬里。每惟黃初中，文皇帝命虎牙將軍鮮于輔，宣溫密之詔，申三好之恩，開示門戶，大義炳然，而否德闇弱，竊貪遣緒，俯仰累紀，未率大教。

**释读** 刘禅叙汉、魏多年隔绝，追述魏文帝曾命虎牙将军鲜于辅传密诏开示出路，以说明此时愿归顺。

**归年** 为景元四年降书；鲜于辅所送之诏只写黄初中220–226，无确年。

<a id="sgz033-b-1724-2"></a>

**[《三国志·后主传》仓内原文 L1724](../../sources/本地分卷/三国志/三国志-卷033.md#l1724)**

> 天威既震，人鬼歸能之數，怖駭王師，神武所次，敢不革面，順以從命！輒敕群帥投戈釋甲，官府帑藏一無所毀。百姓布野，餘糧棲畝，以俟後來之惠，全元元之命。

**释读** 降书称已命各部放下武器、勿毁官府藏储，并请求魏廷宽免蜀中百姓。

**归年** 同一降书，保全安排是降书所述。

<a id="sgz033-b-1724-3"></a>

**[《三国志·后主传》仓内原文 L1724](../../sources/本地分卷/三国志/三国志-卷033.md#l1724)**

> 伏惟大魏布德施化，宰輔伊、周，含覆藏疾。謹遣私署侍中張紹、光祿大夫譙周、駙馬都尉鄧良奉繼印綬，請命告誠，敬輸忠款，存亡敕賜，惟所裁之。輿櫬在近，不復縷陳。

**释读** 降表请求魏宽恕处置，称遣张绍、谯周、邓良奉印绶、请命，并说降者近将乘车带棺而来。

**归年** 同一降书；正文下注张绍、邓良先与邓艾遇于雒县，与《邓艾传》可并校。

<a id="sgz033-b-1725-2"></a>

**[《三国志·后主传》仓内原文 L1725](../../sources/本地分卷/三国志/三国志-卷033.md#l1725)**

> 紹、良與艾相遇於雒縣。艾得書，大喜，即報書，遣紹良先還。

**释读** 张绍、邓良途中遇邓艾，邓艾见书喜，写回书并送二人先回成都。

**归年** 接景元四年同一次归降，《蜀记》保存答书。

<a id="sgz033-b-1725-3"></a>

**[《三国志·后主传》仓内原文 L1725](../../sources/本地分卷/三国志/三国志-卷033.md#l1725)**

> 艾至城北，後主興櫬自縛，詣軍壘門。艾解縛焚櫬，延請相見。

**释读** 邓艾到成都城北，刘禅自绑带棺到营门，邓艾解缚焚棺并请相见；原文“興櫬”，四库本作“輿櫬”。

**归年** 承景元四年降蜀，《邓艾传》记群臣随行，有《晋诸公赞》不同叙法。

<a id="sgz033-b-1725-4"></a>

**[《三国志·后主传》仓内原文 L1725](../../sources/本地分卷/三国志/三国志-卷033.md#l1725)**

> 因承製拜後主為驃騎將軍。諸圍守悉被後主敕，然後降下。艾使後主止其故宮，身往造焉。

**释读** 邓艾依权授刘禅骠骑将军，诸守收到刘禅命令后降，令刘禅暂住故宫并亲自去见。

> 魏遣漢葭縣長郭純試守武陵太守，率涪陵民入蜀遷陵界，屯於赤沙，誘致諸夷邑君，或起應純，又進攻酉陽縣，郡中震懼。

**本段所记** 魏以郭纯试守武陵太守，进驻赤沙，招诱与蜀地接界的地方势力，并进攻酉阳，武陵郡震惧。

**归年与互校** 《钟离牧传》承永安六年蜀亡至钟离牧赴武陵；随后钟离牧平五溪路程长而无明月，不硬定战毕日期。

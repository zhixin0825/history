<a id="sg-event-1"></a>

1. **二月诏增司马昭爵邑，他辞谢。** 四年春二月，复命大将军进位爵赐一如前诏，又固辞乃止。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **魏出兵攻蜀。** 魏五月诏邓艾和诸葛绪攻蜀，另派钟会从骆谷出兵。同年秋三路军进发。蜀派张翼、廖化等抵御，改元炎兴。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **太尉高柔薨。** 秋九月，太尉高柔去世。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **十月再诏增司马昭爵邑。** 冬十月甲寅，复命大将军进位爵赐一如前诏。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **立皇后卞氏，十一月。** 癸卯，立皇后卞氏，十一月，大赦。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **刘禅降魏。** 刘禅采纳谯周的劝告，派人向邓艾请降，随后亲至军营。魏军接管巴蜀。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **以司徒郑冲为太保。** 十二月庚戌，以司徒郑冲为太保。 [[7]](#sg-note-7)

<a id="sg-event-8"></a>

8. **分益州为梁州。** 壬子，分益州为梁州。 [[8]](#sg-note-8)

<a id="sg-event-9"></a>

9. **特赦益州士民，复除租赋之半。** 癸丑，特赦益州士民，复除租赋之半。 [[9]](#sg-note-9)

<a id="sg-event-10"></a>

10. **魏授邓艾为太尉、钟会为司徒。** 五年乙卯，以征西将军邓艾为太尉，镇西将军锺会为司徒。 [[10]](#sg-note-10)

<a id="sg-event-11"></a>

11. **明元郭太后去世。** 皇太后崩。 [[11]](#sg-note-11)

<a id="sg-event-12"></a>

12. **邓艾越阴平破绵竹。** 邓艾由阴平险道进军，降江由守将马邈，继而在绵竹斩诸葛瞻等。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **姜维率蜀军降钟会。** 钟会攻剑阁未下，邓艾破绵竹后刘禅命姜维投降；姜维在郪县令人放下兵器，赴钟会军。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **沔阳立诸葛亮庙。** 蜀于沔阳立庙，钟会进军汉川时祭庙并禁扰墓侧。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **绵竹战败，蜀汉降魏。** 诸葛瞻率军与邓艾交战，阵亡于绵竹。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **蜀汉降魏后的南中与巴东。** 霍弋与罗宪各保一方，听命内附，朝廷保留其职。 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **姜维守剑阁。** 姜维、张翼、董厥等并军守剑阁，钟会因粮运困难考虑退军。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **交阯吕兴等起事，杀太守孙諝。** 交阯吏吕兴等因地方官频繁征发工匠，联结当地兵民起事，杀孙諝。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **魏攻蜀，吴分军援救。** 吴军分路行动，丁奉向寿春，留平到南郡与施绩商议，丁封、孙异到沔中。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **蜀亡后吴遣钟离牧镇武陵。** 魏灭蜀后，吴廷担心武陵五溪边境动乱，任钟离牧为平魏将军、武陵太守。 [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **蜀亡后华覈陈忧。** 华覈闻蜀被魏吞并，赴宫门上表，忧西部屏障已失。 [[21]](#sg-note-21)

<a id="sg-event-22"></a>

22. **钟毓去世。** 钟毓于本年去世。 [[22]](#sg-note-22)

<a id="sg-event-23"></a>

23. **封肃子恂爲兰陵侯。** 景元四年，封肃子恂爲兰陵侯。 [[23]](#sg-note-23)

<a id="sgz-event-24"></a>

24. **蜀汉大赦、改元炎兴。** 蜀汉大赦，改元炎兴。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **赵广随姜维在沓中战死。** 次子赵广为牙门将，随姜维守沓中，阵亡。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **钟会围汉乐城，蒋舒降、傅佥战死。** 钟会围汉、乐城，另遣兵攻阳安关。蒋舒开门降，傅佥抵抗而死；钟会未攻下乐城，得知关口已下继续进兵。 [[26]](#sgz-note-26)

<a id="sgz-event-31"></a>

### 2. 魏出兵攻蜀

[返回正文第2条](#sg-event-2)

<a id="sg004-l284-e2"></a>

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p008)** · [仓内TXT L284](../../sources/本地分卷/三国志/三国志-卷004.md#l284)

> 夏五月，詔曰：「蜀，蕞爾小國，土狹民寡，而姜維虐用其衆，曾無廢志；往歲破敗之後，猶復耕種沓中，刻剝衆羌，勞役無已，民不堪命。夫兼弱攻昧，武之善經，致人而不至於人，兵家之上略。蜀所恃賴，唯維而已，因其遠離巢窟，用力為易。今使征西將軍鄧艾督帥諸軍，趣甘松、沓中以羅取維，雍州刺史諸葛緒督諸軍趣武都、高樓，首尾踧討。若禽維，便當東西並進，掃滅巴蜀也。」

<a id="sg004-l284-e2-2"></a>

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p008)** · [仓内TXT L284](../../sources/本地分卷/三国志/三国志-卷004.md#l284)

> 又命鎮西將軍鍾會由駱谷伐蜀。

<a id="sg028-l1479-e2"></a>

**[《三国志·王毌丘诸葛邓钟传》](../../sources/摘录/三国志-卷028-王毌丘诸葛邓钟传.md#p004)** · [仓内TXT L1479](../../sources/本地分卷/三国志/三国志-卷028.md#L1479)

**归年与互校** 《陈留王纪》记夏五月下诏，列传记秋季战役展开，两个时间节点可并记。

<a id="sg033-l1723-e2"></a>

**[《三国志·后主传》](../../sources/摘录/三国志-卷033-后主传.md#p007)** · [仓内TXT L1723](../../sources/本地分卷/三国志/三国志-卷033.md#l1723)

> 六年夏，魏大興徒從眾，命征西將軍鄧艾、鎮西將軍鍾會、雍州剌史諸葛緒數道並攻。於是遣左右車騎將軍張翼、廖化、輔國大將軍董厥等拒之。大赦。改元為炎興。

<a id="sg044-l2079-e2"></a>

**[《三国志·蒋琬费祎姜维传》](../../sources/摘录/三国志-卷044-蒋琬费祎姜维传.md#p003)** · [仓内TXT L2079](../../sources/本地分卷/三国志/三国志-卷044.md#l2079)

> 六年，維表後主：「聞鐘會治兵關中，欲規進取，宜並遣張翼、廖化詣督堵軍分護陽安關口、陰平橋頭，以防未然。」皓徵信鬼巫，謂敵終不自致。啟後主寢其事，而群臣不知。

<a id="sgz033-b-1723-1"></a>

**[《三国志·后主传》仓内原文 L1723](../../sources/本地分卷/三国志/三国志-卷033.md#l1723)**

> 六年夏，魏大興徒從眾，命征西將軍鄧艾、鎮西將軍鍾會、雍州剌史諸葛緒數道並攻。

**释读** 魏命邓艾、钟会、诸葛绪分道攻蜀。

**归年** 蜀景耀六年，魏景元四年。《常道乡公纪》记五月下令、秋进军。

<a id="sgz044-b-2064-2"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2064](../../sources/本地分卷/三国志/三国志-卷044.md#l2064)**

> 魏大將軍鐘會至漢城，與斌書曰：「巴蜀賢智文武之士多矣，至於足下、諸葛思遠，譬諸草木，吾氣類也。桑梓之敬，古今所敦。西到，欲奉瞻尊大君公侯墓，當灑掃墳塋，奉祠致敬。願告其所在！」斌答書曰：「知惟臭味意眷之隆，雅托通流，未拒來謂也。亡考昔遭疾疢，亡於涪縣，卜雲其吉，遂安厝之。知君西邁，乃欲屈駕修敬墳墓。視予猶父，顏子之仁也，聞命感愴，以增情思。」會得斌書報，嘉歎意義，及至涪如其書雲。

**释读** 钟会至汉城，称蒋斌、诸葛瞻为同气，请祭蒋琬墓。蒋斌回书告其墓在涪县并谢。钟会到涪后如其言。

**归年** 钟会景耀六年入汉中，见《钟会传》；实际祭墓沿行程，未独日。

<a id="sgz044-b-2079-4"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2079](../../sources/本地分卷/三国志/三国志-卷044.md#l2079)**

> 及鐘會將向駱谷，鄧艾將入沓中。然後乃遣右車騎廖化詣沓中為維援，左車騎張翼、輔國大將軍董厥等詣陽安關口以為諸圍外助。比至陰平，聞魏將諸葛緒向建威，故住待之。

**释读** 钟会将入骆谷，邓艾将到沓中，才派廖化支援姜维、张翼和董厥赴关口协防。到阴平因听诸葛绪趋建威停候。

**归年** 《后主传》景耀六年魏分路伐蜀，《通鉴》卷078夏至秋。

<a id="sgz044-b-2079-5"></a>

**[《三国志·蒋琬费祎姜维传》仓内原文 L2079](../../sources/本地分卷/三国志/三国志-卷044.md#l2079)**

> 月餘，維為鄧艾所摧，還住陰平。

**释读** 月余，姜维被邓艾击败，回守阴平。

**归年** 《通鉴》卷078叙沓中遭魏路军至阴平，炎兴元年改元前后。

<a id="sgz048-p-037-3"></a>

**[《三国志·三嗣主传》裴注 037·3](../../sources/摘录/三国志-卷048-三嗣主传裴注.md#pei-037-3)**

> 魏伐蜀呉人問悌曰司馬氏得政以來大難屢作智力雖豐而百姓未服也今又竭其資力逺征巴蜀兵勞民疲而不知恤敗於不暇何以能濟昔夫差伐齊非不克勝所以危亡不憂其本也况彼之争地乎悌曰不然曹操雖功葢中夏威震四海崇詐杖術征伐無已民畏其威而不懐其徳也丕叡承之係以慘虐内興宫室外懼雄豪東西驅馳無嵗獲安彼之失民為日久矣司馬懿父子自握其柄累有大功除其煩苛而布其平惠為之謀主而救其疾民心歸之亦已乆矣故淮南三叛而腹心不擾曹髦之死四方不動摧堅敵如折枯蕩異同如反掌任賢使能各盡其心非智勇兼人孰能如之其威武張矣本根固矣羣情服矣奸計立矣今蜀閹宦専朝國無政令而玩戎黷武民勞卒弊競於外利不修守備彼彊弱不同智算亦勝因危而伐殆其克乎若其不克不過無功終無退北之憂覆軍之慮也何為不可哉昔楚劒利而秦昭懼孟明用而晉人憂彼之得志故我之大患也呉人笑其言而蜀米降於魏

**释读** 有人以吴王夫差亡国为比，料魏远征必败。张悌分析曹氏失民已久而司马氏抚众，蜀内乱外疲，兵劳却无防备，魏足以得胜，吴应为其得志担忧。

**归年** 《襄阳记》置魏伐蜀时，即景元四年；所引淮南反及曹髦之死为旧事。

**归年** 本传永安六年，蜀亡同年。

<a id="sgz060-b-2887-3"></a>

**[《三国志·贺全吕周钟离传》仓内原文 L2887](../../sources/本地分卷/三国志/三国志-卷060.md#l2887)**

> 牧問朝吏曰：「西蜀傾覆，邊境見侵，何以禦之？」皆對曰：「今二縣山險，諸夷阻兵，不可以軍驚擾，驚擾則諸夷盤結。宜以漸安，可遣恩信吏宣教慰勞。」

**释读** 钟离牧向郡吏问御敌之策，众议山险且易惊诸夷，应派素有信义的官吏告教慰劳。

**归年** 同役军议。

<a id="sgz060-b-2887-4"></a>

**[《三国志·贺全吕周钟离传》仓内原文 L2887](../../sources/本地分卷/三国志/三国志-卷060.md#l2887)**

> 牧曰：「不然。外境內侵，誑誘人民，當及其根柢未深而撲取之，此救火貴速之勢也。」敕外趣嚴，掾史沮儀者便行軍法。

**释读** 钟离牧认为敌人新入境、根基未稳，应如救火一样速攻，下令整备并治军法。

**归年** 同役军议。

<a id="sgz060-b-2887-5"></a>

**[《三国志·贺全吕周钟离传》仓内原文 L2887](../../sources/本地分卷/三国志/三国志-卷060.md#l2887)**

> 撫夷將軍高尚說牧曰：「昔潘太常督兵五萬，然後以討五谿夷耳。是時劉氏連和，諸夷率化，今既無往日之援，而郭純已據遷陵，而明府以三千兵深入，尚未見其利也。」牧曰：「非常之事，何得循舊？」

**释读** 高尚援引潘濬从前以五万军讨五溪，指出今无蜀援、郭纯已至迁陵，疑三千兵不能深入取胜。钟离牧认为形势已变。

**归年** 同役军议，潘濬之战只是引用前事。

<a id="sgz060-b-2887-6"></a>

**[《三国志·贺全吕周钟离传》仓内原文 L2887](../../sources/本地分卷/三国志/三国志-卷060.md#l2887)**

> 即率所領，晨夜進道，緣山險行，垂二千里，從塞上，斬惡民懷異心者魁帥百餘人及其支黨凡於余級，純等散，五谿平。

12. **追命舞阳宣文侯为晋宣王。** 癸未，追命舞阳宣文侯为晋宣王，舞阳忠武侯为晋景王。 [[12]](#sg-note-12)

<a id="sg-event-13"></a>

13. **镇西将军衞瓘上雍州兵于成都县获璧玉印各一。** 六月，镇西将军衞瓘上雍州兵于成都县获璧玉印各一，印文似「成信」字，依周成王归禾之义，宣示百官，藏于相国府。 [[13]](#sg-note-13)

<a id="sg-event-14"></a>

14. **魏援永安，吴军解罗宪之围。** 吴军围攻驻守永安的罗宪，魏派胡烈率军入西陵救援。七月陆抗等撤军。 [[14]](#sg-note-14)

<a id="sg-event-15"></a>

15. **命中抚军司马炎副贰相国事。** 八月庚寅，命中抚军司马炎副贰相国事，以同鲁公拜后之义。 [[15]](#sg-note-15)

<a id="sg-event-16"></a>

16. **诏曰“前逆臣锺会构造反乱”。** 癸巳，诏曰：「前逆臣锺会构造反乱，聚集征行将士，劫以兵威，始吐奸谋，发言桀逆，逼胁衆人，皆使下议，仓卒之际，莫不惊慑。相国左司马夏侯和、骑士曹属朱抚时使在成都，中领军司马贾辅、郎中羊琇各参会军事；和、琇、抚皆抗节不挠，拒会凶言，临危不顾，词指正烈。辅语散将王起，说『会奸逆凶暴，欲尽杀将士』，又云『相国已率三十万衆西行讨会』，欲以称张形势，感激衆心。起出，以辅言宣语诸军，遂命将领士益怀奋励。宜加显宠，以彰忠义。其进和、辅爵为乡侯，琇、抚爵关内侯。起宣传辅言，告令将士，所宜赏异。其以起为部曲将。」 [[16]](#sg-note-16)

<a id="sg-event-17"></a>

17. **以衞将军司马望为骠骑将军。** 癸卯，以衞将军司马望为骠骑将军。 [[17]](#sg-note-17)

<a id="sg-event-18"></a>

18. **以中抚军司马炎为抚军大将军。** 九月戊午，以中抚军司马炎为抚军大将军。 [[18]](#sg-note-18)

<a id="sg-event-19"></a>

19. **诏曰“吴贼政刑暴虐”。** 辛未，诏曰：「吴贼政刑暴虐，赋敛无极。孙休派使邓句，勑交址太守锁送其民，发以为兵。吴将吕兴因民心愤怒，又承王师平定巴蜀，即纠合豪杰，诛除句等，驱逐太守长吏，抚和吏民，以待国命。九真、日南郡闻兴去逆即顺，亦齐心响应，与兴恊同。兴移书日南州郡，开示大计，兵临合浦，告以祸福；遣都尉唐谱等诣进乘县，因南中都督护军霍弋上表自陈。又交址将吏各上表，言『兴创造事业，大小承命。郡有山寇，入连诸郡，惧其计异，各有携贰。权时之宜，以兴为督交址诸军事、上大将军、定安县侯，乞赐褒奖，以慰边荒』。乃心欵诚，形于辞旨。昔仪父朝鲁，春秋所美；窦融归汉，待以殊礼。今国威远震，抚怀六合，方包举殊裔，混一四表。其余见同号原文。 [[19]](#sg-note-19)

<a id="sg-event-20"></a>

20. **策命未至，兴为下人所杀。** [[20]](#sg-note-20)

<a id="sg-event-21"></a>

21. **诏曰“昔圣帝明王”。** 冬十月丁亥，诏曰：「昔圣帝明王，静乱济世，保大定功，文武殊涂，勳烈同归。是故或舞干戚以训不庭，或陈师旅以威暴慢。至于爱民全国，康惠庶类，必先修文教，示之轨仪，不得已然后用兵，此盛德之所同也。往者季汉分崩，九土颠覆，刘备、孙权乘间作祸。三祖绥宁中夏，日不暇给，遂使遗寇僭逆历世。幸赖宗庙威灵，宰辅忠武，爰发四方，拓定庸、蜀，役不浃时，一征而克。自顷江表衰弊，政刑荒闇，巴、汉平定，孤危无援，交、荆、扬、越靡然向风。今交址伪将吕兴已帅三郡，万里归命；武陵邑侯相严等纠合五县，请为臣妾；豫章庐陵山民举衆叛吴，以助北将军为号。又孙休病死，主帅改易，国内乖违，人各有心。其余见同号原文。 [[21]](#sg-note-21)

43. **刘禅举家东迁洛阳。** 成都事变后，刘禅携家属迁往洛阳。张皇后随行。 [[43]](#sg-note-43)

<a id="sg-event-44"></a>

44. **宗预、廖化在东迁途中去世。** 魏咸熙元年春，二人同被迁至洛阳，途中病逝。 [[44]](#sg-note-44)

<a id="sg-event-45"></a>

45. **吴主孙休去世。** 孙休七月去世，谥景皇帝。 [[45]](#sg-note-45)

<a id="sg-event-46"></a>

46. **孙皓即位，改元元兴。** 因蜀亡和交阯之乱，吴丞相濮阳兴等与朱太后商定立较年长的孙皓。 [[46]](#sg-note-46)

<a id="sg-event-47"></a>

47. **孙皓杀濮阳兴、张布。** 二人曾支持孙皓即位，后来对其施政失望，孙皓闻谗，于十一月诛杀二人。 [[47]](#sg-note-47)

<a id="sy-event-48"></a>

48. **钟会兵变后，魏处置钟氏家属。** 钟邕随钟会一同死。魏廷下诏赦免钟峻、钟辿，理由是钟繇、钟毓有功；钟毅及钟邕之子仍伏法。 [[48]](#sy-note-48)

<a id="sgz-event-49"></a>

49. **司马昭设宴奏蜀乐观察刘禅反应。** 《汉晋春秋》称司马昭宴请刘禅时奏蜀乐，旁人伤感而刘禅欢笑，司马昭与贾充评论蜀亡。 [[49]](#sgz-note-49)

<a id="sgz-event-50"></a>

50. **刘禅向司马昭称在洛阳不思蜀。** 司马昭后来问刘禅是否思蜀，刘禅称此间快乐。郤正教他再次回答时提及蜀地祖坟，司马昭听后指出近似郤正之言，刘禅承认。 [[50]](#sgz-note-50)

<a id="sgz-event-51"></a>

51. **霍弋派兵援吕兴，交州三郡归魏。** 霍弋后来派兵援吕兴，注概括为平交趾、日南、九真，以此功封侯进号。 [[51]](#sgz-note-51)

<a id="sgz-event-52"></a>

52. **武陵举众归附，罗宪领武陵太守。** 武陵四县反吴，罗宪领武陵太守、巴东监军。 [[52]](#sgz-note-52)

<a id="sgz-event-53"></a>

53. **卫瓘在成都得璧和印。** 《襄阳记》称魏咸熙元年六月卫瓘到成都，得一璧一印，似成信字，魏示百官后藏相国府。向充借此称预兆司马炎接续蜀汉。 [[53]](#sgz-note-53)

<a id="sgz-event-54"></a>

54. **向充为梓潼太守。** 向充获任梓潼太守。 [[54]](#sgz-note-54)

**释读** 三月丁亥，魏帝临轩使太常嘉册刘禅为安乐县公；策文述帝王治民及作为受命者的责任。

**释读** 魏策以自家史观述汉室失统、曹操兴起及刘备保有蜀地、与中原隔绝。

**释读** 册文述自东西隔绝后久有战争，称整兵梁、益为完成父祖统一之愿。

### 21. 诏曰“昔圣帝明王”

[返回正文第21条](#sg-event-21)

<a id="sg004-l293-e21"></a>

**[《三国志·三少帝纪》](../../sources/摘录/三国志-卷004-三少帝纪.md#p009)** · [仓内TXT L293](../../sources/本地分卷/三国志/三国志-卷004.md#l293)

> 冬十月丁亥，詔曰：「昔聖帝明王，靜亂濟世，保大定功，文武殊塗，勳烈同歸。是故或舞干戚以訓不庭，或陳師旅以威暴慢。至於愛民全國，康惠庶類，必先脩文教，示之軌儀，不得已然後用兵，此盛德之所同也。往者季漢分崩，九土顛覆，劉備、孫權乘間作禍。三祖綏寧中夏，日不暇給，遂使遺寇僭逆歷世。幸賴宗廟威靈，宰輔忠武，爰發四方，拓定庸、蜀，役不浹時，一征而克。自頃江表衰弊，政刑荒闇，巴、漢平定，孤危無援，交、荊、揚、越靡然向風。今交阯偽將呂興已帥三郡，萬里歸命；武陵邑侯相嚴等糾合五縣，請為臣妾；豫章廬陵山民舉衆叛吳，以助北將軍為號。又孫休病死，主帥改易，國內乖違，人各有心。偽將施績，賊之名臣，懷疑自猜，深見忌惡。衆叛親離，莫有固志，自古及今，未有亡徵若此之甚。若六軍震曜，南臨江、漢，吳會之域必扶老攜幼以迎王師，必然之理也。然興動大衆，猶有勞費，宜告喻威德，開示仁信，使知順附和同之利。相國參軍事徐紹、水曹掾孫彧，昔在壽春，並見虜獲。紹本偽南陵督，才質開壯；彧，孫權支屬，忠良見事。其遣紹南還，以彧為副，宣揚國命，告喻吳人，諸所示語，皆以事實，若其覺悟，不損征伐之計，蓋廟勝長筭，自古之道也。其以紹兼散騎常侍，加奉車都尉，封都亭侯；彧兼給事黃門侍郎，賜爵關內侯。紹等所賜妾及男女家人在此者，悉聽自隨，以明國恩，不必使還，以開廣大信。」

> 會兄子邕，隨會與俱死，會所養兄子毅及峻、辿等下獄，當伏誅。司馬文王表天子下詔曰：「峻等祖父繇，三祖之世，極位臺司，佐命立勳，饗食廟庭。父毓，歷職內外，幹事有績。昔楚思子文之治，不滅斗氏之祀；晉錄成宣之忠，用存趙氏之後。以會、邕之罪，而絕繇、毓之類，吾有愍然！峻、辿兄弟特原，有官爵者如故。惟毅及邕息伏法。」

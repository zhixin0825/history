## 本年概述

司马昭去世，司马炎继晋王、相国，年底接受曹奂禅位，建立晋朝。新朝追尊先世、封王授官，颁赦免赋，并优礼魏主及前朝宗室。吴遣使北行，又由建业迁都武昌。

1. **魏追奖张脩，封其弟张倚。** 二月庚戌，魏封张倚为关内侯。上年张脩在成都驰告各营钟会反叛，因此身死，魏以此奖其弟。 [[1]](#sgz-note-8)

3. **吴遣纪陟、弘璆回访魏廷。** 三月，孙皓派纪陟、弘璆随魏使回访。徐绍到濡须后，被孙皓召回杀害。四月，吴使到洛阳，献上方物；十一月，纪陟、弘璆返回吴国。 [[3]](#sg-note-1)

5. **晋世子进为晋王太子。** 五月曹奂命司马昭用十二旒冕、天子旌旗、出警入跸、金根车驾六马、五时副车、旄头云罕、八佾乐舞、钟虡宫悬，位在燕王上；王妃进王后，世子进太子，王女王孙爵命礼仪皆如帝者。这些是晋王获得的殊礼，司马昭生前仍未称皇帝。 司马昭奏除烦苛禁令及不合时宜的法式；晋国设御史大夫、侍中、常侍、尚书、中领军、卫将军等官。 [[5]](#jin002-note-jin-royal)

14. **曹奂禅位，司马炎登坛即帝位。** 十二月壬戌，曹魏下诏备禅礼。甲子，曹奂逊居金墉城，命太保郑冲奉策授位于晋王司马炎。策文称晋德已使天下归心，曹奂已知天命另有所归；又以虞舜为曹氏先祖，说舜受尧禅让、再传于夏，三位圣王升天后仍显扬其德，后来天命转归汉，汉火德衰而归魏高祖。曹奂自称不敢与虞夏等四代盛德相比，赞晋王祖父恪守明哲、辅魏有功、德及四海，感通天地神灵，使土地平治、万国安定，应承上天之命、合天下之中正。自己恭承天序，敬授帝位，嘱晋王持守中道、长保天禄，敬顺天命、遵循典教、安定四方，保住上天赐福及魏二祖的功业。司马炎先以礼辞让，何曾、王沈等再三劝进，才接受。丙寅，百官、南匈奴单于及四方来会者数万人列位南郊，司马炎用黑色公牛，燔柴告祭上帝，正式即帝位。告天文以“皇帝臣炎”自称，说魏帝考察天运，将上天明命交付自己；追述尧传舜、舜传禹的德教，称汉德衰后曹操拨乱救时、扶持刘氏，魏又受命于汉。魏室数世多故，几乎倾覆，靠晋匡救才保宗庙祭祀、渡过艰难，故晋对魏有大功。告文又称四方无不敬从，梁岷已经廓清，扬越也在怀服之中，天下同轨、祥瑞屡至、天人响应；自己因此效法三后而受大命，虽德不足、辞让亦未获准，公卿百官、贤者与卑役、四方君长都说上天已察民苦而下成命，不能以谦让拒绝，天序不可无人承继，人神不可久无共主。司马炎于是敬畏天威、择吉登坛，受禅告天，以答众望。礼毕回洛阳宫，临太极前殿下诏，称祖父宣王圣哲明察、顺应时运而开基，伯父景王践道宣谋、光大中原，父亲文王睿哲、应天顺时、仁功及于天下与天地神灵；魏帝鉴古、效尧舜，询问群后而将大命付己。自己畏天命而不敢违，却德薄而任重，居王公之上、君临四海，惴惴忧惧，不知怎样完成大业。诏书勉文武忠臣承其祖父辅佐先王的功劳，继续光大事业，与天下共享福祚。 [[14]](#sg-note-4)

<a id="jin003-u121-3-event"></a>

15. **即位后大赦、免赋并赐爵赈孤。** 司马炎即位后大赦，改元泰始。天下人各赐爵五级，不能自存的鳏寡孤独每人赐谷五斛；免一年租赋与关市税，不再追收陈年欠债。消除旧怨，解除禁锢，失官失爵者恢复官爵。 [[15]](#jin003-u121-3-note)

<a id="jin003-u122-1-event"></a>

16. **遣刘原告祭太庙。** 十二月丁卯，遣太仆刘原告祭太庙。 [[16]](#jin003-u122-1-note)

<a id="jin003-u122-2-event"></a>

17. **封曹奂陈留王，保留魏礼。** 十二月丁卯，封曹奂为陈留王，食邑万户，居邺宫，魏诸王降为县侯。己巳，准曹奂用天子旌旗、五时副车，沿用魏历，郊祀天地及礼乐制度依魏旧，上书不称臣。魏济北王曹志另改封鄄城县公。 [[17]](#jin003-u122-2-note)

<a id="jin003-u122-3-event"></a>

18. **追尊先世，尊王氏为皇太后。** 十二月丁卯，追尊司马懿、司马师、司马昭为宣皇帝、景皇帝、文皇帝，司马懿陵号高原、司马师陵号峻平，追尊张氏为宣穆皇后；尊太妃王氏为皇太后，居崇化宫。 [[18]](#jin003-u122-3-note)

<a id="jin003-u122-5-event"></a>

19. **封司马氏宗室为王。** 十二月丁卯，封叔祖司马孚为安平王；叔父干为平原王、亮为扶风王、伷为东莞王、骏为汝阴王、肜为梁王、伦为琅邪王；弟攸为齐王、鉴为乐安王、机为燕王；从伯父望为义阳王；从叔父辅为渤海王、晃为下邳王、瑰为太原王、珪为高阳王、衡为常山王、子文为沛王、泰为陇西王、权为彭城王、绥为范阳王、遂为济南王、逊为谯王、睦为中山王、陵为北海王、斌为陈王；从兄洪为河间王、从弟楙为东平王。 [[19]](#jin003-u122-5-note)

<a id="jin003-u122-6-event"></a>

20. **晋朝授官、进爵并普增文武位。** 十二月丁卯，以骠骑将军石苞为大司马、乐陵公；车骑将军陈骞封高平公；卫将军贾充升车骑将军、封鲁公；尚书令裴秀封钜鹿公，又授左光禄大夫，侍中荀勖封济北公。太保郑冲升太傅、封寿光公，太尉王祥改太保、封睢陵公，丞相何曾改太尉、封朗陵公，御史大夫王沈升骠骑将军、封博陵公，司空荀顗封临淮公，镇北大将军卫瓘封菑阳公。其余增封进爵各有等差，文武普增位二等。郭建、甄德、甄温加特进，王基因任重而不营私产，其家获赐奴婢二人。 [[20]](#jin003-u122-6-note)

<a id="jin003-u122-8-event"></a>

21. **改称太始历，规定腊社祭日。** 十二月，把景初历改称太始历，腊祭用酉日，社祭用丑日。 [[21]](#jin003-u122-8-note)

22. **以御府珍玩分赐王公。** 十二月戊辰，司马炎下诏崇尚俭约，把御府珠玉和玩好之物按等次赐给王公以下。 [[22]](#jin003-u123-1-note)

<a id="jin003-u123-2-event"></a>

23. **置中军将军统宿卫。** 十二月，设中军将军，统领宿卫七军。 [[23]](#jin003-u123-2-note)

24. **刘康、刘禅各一子弟授驸马都尉。** 十二月，赐山阳公刘康、安乐公刘禅各一名子弟任驸马都尉。 [[24]](#jin003-u124-2-note)

<a id="jin003-u124-3-event"></a>

25. **司马孚任太宰。** 十二月乙亥，以安平王司马孚为太宰，假黄钺，任大都督，统领中外诸军。 [[25]](#jin003-u124-3-note)

<a id="jin003-u124-4-event"></a>

26. **赦王凌邓艾家属并省刑役。** 十二月，司马炎赦王凌、邓艾家属，准立后继祀。他说王凌虽谋废曹芳，曹芳终未保住帝位；邓艾虽恃功失节，却已束手受罪，故应兴灭继绝、约法省刑。同时解除魏宗室禁锢；将吏遭三年之丧可归家终丧，百姓相应免徭役；取消部曲将、长吏以下家属为质的制度，减少郡国额外征调，禁止乐府奢华百戏和雕饰、游猎用具，开放直言，设谏官。又因王经守志，任其孙为郎中。 [[26]](#jin003-u124-4-note)

<a id="jin003-u125-1-event"></a>
<a id="jin003-l125-event"></a>

27. **郡国报祥瑞。** 十二月，各郡国报告凤凰六次、青龙三次、白龙两次和麒麟一次。 [[27]](#jin003-u125-1-note)

28. **魏咸熙二年追赠荀彧太尉。** 咸熙二年追赠荀彧为太尉。 [[28]](#sgz-note-25)

<a id="sg-event-3"></a>

30. **孙皓由建业迁都武昌。** 孙皓采纳西陵督步阐的建议，迁都武昌，留丁固、诸葛靓镇守建业。武昌左部督范慎治军严整，孙皓颇为忌惮。孙皓次年还建业。 [[30]](#sg-note-3)

<a id="sgz-event-26"></a>

31. **吴以蒋陵甘露改元大赦。** 蒋陵报见甘露，吴改元甘露并赦。 [[31]](#sgz-note-26)

32. **吴分立始安、始兴两郡。** 设零陵南部为始安郡，桂阳南部为始兴郡。 [[32]](#sgz-note-27)

<a id="sg-event-6"></a>

33. **巴郡文立从洛阳还蜀，过见周。** 咸熙二年夏，巴郡文立从洛阳还蜀，途经汉中看望因病停留的谯周。谯周写下“典午忽兮，月酉没兮”的隐语，本传把它解释为对司马昭八月去世的预言。 [[33]](#sg-note-6)

<a id="sgz-event-21"></a>

34. **康居、大宛献名马。** 闰月庚辰，康居、大宛贡马，交相国府。 [[34]](#sgz-note-21)

> 干寶晉紀曰：陟、璆奉使如魏，入境而問諱，入國而問俗。壽春將王布示之馬射，旣而問之曰：「吳之君子亦能斯乎？」陟曰：「此軍人騎士肄業所及，士大夫君子未有爲之者矣。」布大慙。旣至，魏帝見之，使儐問曰：「來時吳王何如？」陟對曰：「來時皇帝臨軒，百寮陪位，御膳無恙。」晉文王饗之，百寮畢會，使儐者告曰：「某者安樂公也，某者匈奴單于也。」陟曰：「西主失土，爲君王所禮，位同三代，莫不感義，匈奴邊塞難羈之國，君王懷之，親在坐席，此誠威恩遠著。」又問：「吳之戍備幾何？」對曰：「自西陵以至江都，五千七百里。」又問曰：「道里甚遠，難爲堅固？」對曰：「疆界雖遠，而其險要必爭之地，不過數四，猶人雖有八尺之軀靡不受患，其護風寒亦數處耳。」文王善之，厚爲之禮。

**释读** 在寿春说骑射乃军人之事。见魏帝及司马昭后，数称吴君为帝、妥答防守要隘等问题，司马昭厚礼之。

> 是時晉德既洽，四海宅心。於是天子知曆數有在，乃使太保鄭沖奉策曰：「咨爾晉王：我皇祖有虞氏誕膺靈運，受終於陶唐，亦以命於有夏。惟三後陟配於天，而咸用光敷聖德。自茲厥後，天又輯大命於漢。火德既衰，乃眷命我高祖。方軌虞夏四代之明顯，我不敢知。惟王乃祖乃父，服膺明哲，輔亮我皇家，勳德光於四海。格爾上下神祇，罔不克順，地平天成，萬邦以乂。應受上帝之命，協皇極之中。肆予一人，祗承天序，以敬授爾位，曆數實在爾躬。允執其中，天祿永終。於戲！王其欽順天命。率循訓典，底綏四國，用保天休，無替我二皇之弘烈。」帝初以禮讓，魏朝公卿何曾、王沈等固請，乃從之。泰始元年冬十二月丙寅，設壇於南郊，百僚在位及匈奴南單于四夷會者數萬人，柴燎告類於上帝曰：「皇帝臣炎敢用玄牡明告於皇皇后帝：魏帝稽協皇運，紹天明命以命炎。昔者唐堯，熙隆大道，禪位虞舜，舜又以禪禹，邁德垂訓，多歷年載。暨漢德既衰，太祖武皇帝撥亂濟時，扶翼劉氏，又用受命於漢。粵在魏室，仍世多故，幾於顛墜，實賴有晉匡拯之德，用獲保厥肆祀，弘濟於艱難，此則晉之有大造於魏也。誕惟四方，罔不祗順，廓清梁岷，包懷揚越，八紘同軌，祥瑞屢臻，天人協應，無思不服。肆予憲章三後，用集大命於茲。炎維德不嗣，辭不獲命。於是群公卿士，百辟庶僚，黎獻陪隸，暨於百蠻君長，僉曰：『皇天鑒下，求人之瘼，既有成命，固非克讓所得距違。天序不可以無統，人神不可以曠主。』炎虔奉皇運，寅畏天威，敬簡元辰，升壇受禪，告類上帝，永答眾望。」禮畢，即洛陽宮幸太極前殿，詔曰：「昔朕皇祖宣王，聖哲欽明，誕應期運，熙帝之載，肇啟洪基。伯考景王，履道宣猷，緝熙諸夏。至於皇考文王，叡哲光遠，允協靈祇，應天順時，受茲明命。仁濟於宇宙，功格於上下。肆魏氏弘鑒於古訓，儀刑於唐虞，疇咨群後，爰輯大命於朕身。予一人畏天之命，用不敢違。惟朕寡德，負荷洪烈，託於王公之上，以君臨四海，惴惴惟懼，罔知所濟。惟爾股肱爪牙之佐，文武不貳之臣，乃祖乃父，實左右我先王，光隆我大業。思與萬國，共享休祚。」

**释读与归年** 禅位、辞让、告天和即位诏为同一禅代过程，各篇原文在本号连续引录。策文的祖先、天命和告天“八纮同轨”等均为政治合法性颂词；此时孙吴尚存。月日依古史年条，不等同公历十二月。

### 33. 巴郡文立从洛阳还蜀，过见周

[返回正文第33条](#sg-event-6)

<a id="sg042-l2005-e6"></a>

<a id="shu042-l85-3"></a>

**[《三國志·杜周杜許孟來尹李譙郤傳》正文](../../拆分史书/三国志/卷042.md#edition-shu042-l85-3)** · [TXT L85](../../拆分史书/三国志/卷042.txt#L85)

> 咸熈二年夏，巴郡文立從洛陽還蜀，過見周。周語次，因書版示立曰：「典午忽兮，月酉沒兮。」典午者謂司馬也，月酉者謂八月也，

**释读** 咸熙二年夏，文立从洛阳返回蜀地，经过汉中看望谯周。交谈时，谯周在板上写出“典午忽兮，月酉没兮”；本传把典午解释为司马，把月酉解释为八月，以之联系司马昭后来去世。

**归年与互校** 本传明记咸熙二年夏，系265年。隐语及其应验关系是传中的叙述，不当作占术有效的证明；“月酉”是作者所记的八月指代，并非月相的说法。后面的八月卒事单独分读。

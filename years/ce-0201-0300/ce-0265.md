# 公元265年｜魏咸熙二年／晋泰始元年／吴甘露元年

[← 公元264年](ce-0264.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元266年 →](ce-0266.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **吴遣纪陟、弘璆赴魏。** 吴派纪陟、弘璆随魏使回访，二人抵洛时司马昭已卒。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓杀朱太后及孙休子。** 秋七月，朱太后被逼死；孙皓送孙休四子至吴小城，后来追杀两名年长者。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **孙皓由建业迁都武昌。** 九月孙皓依西陵督步阐奏请迁都武昌，并留丁固、诸葛靓镇建业，次年复还。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **晋受魏禅。** 吴书在甘露元年末也记录晋受禅。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **晋室践阼，诏曰“昔太尉王凌谋废齐王”。** 泰始元年，晋室践阼，诏曰：「昔太尉王凌谋废齐王，而王竟不足以守位。征西将军邓艾，矜功失节，实应大辟。然被书之日，罢遣人众，束手受罪，比于求生遂为恶者，诚复不同。今大赦得还，若无子孙者听使立后，令祭祀不绝。」 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **巴郡文立从洛阳还蜀，过见周。** 咸熙二年夏，巴郡文立从洛阳还蜀，过见周。 [[6]](#sg-note-6)

<a id="sgz-event-7"></a>

7. **朐䏰送灵龟至相国府。** 朐䏰县获灵龟以献，送相国府。 [[7]](#sgz-note-7)

<a id="sgz-event-8"></a>

8. **张修因报钟会起兵而受褒。** 诏称虎贲张修先前在成都跑马通知诸营钟会谋反，因此身死，今封其弟张倚为关内侯。 [[8]](#sgz-note-8)

<a id="sgz-event-9"></a>

9. **南深泽报告甘露。** 南深泽县报甘露降。 [[9]](#sgz-note-9)

<a id="sgz-event-10"></a>

10. **魏诏把孙皓所贡归司马昭。** 诏称吴受司马昭文告感召遣使献礼，宜将贡品归司马昭；司马昭坚辞，遂止。 [[10]](#sgz-note-10)

<a id="sgz-event-11"></a>

11. **晋王获准用天子车服礼仪。** 朝廷许司马昭戴十二旒冕、建天子旌旗、出入警跸、乘六马金根车并用天子乐舞。 [[11]](#sgz-note-11)

<a id="sgz-event-12"></a>

12. **晋国王后和太子礼制升格。** 王妃为王后、世子为太子，其它王子女及王孙的爵命按旧仪。 [[12]](#sgz-note-12)

<a id="sgz-event-13"></a>

13. **魏五月大赦。** 五月癸未，魏大赦天下。 [[13]](#sgz-note-13)

<a id="sgz-event-14"></a>

14. **晋文王司马昭去世。** 相国晋王司马昭去世。 [[14]](#sgz-note-14)

<a id="sgz-event-15"></a>

15. **司马炎嗣晋王与相国职。** 晋太子司马炎承袭封爵，总领政事并沿用原有礼制。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **襄武县报大人出现。** 县报告有白发黄衣、身高三丈多的人，告诉当地民人王始“今当太平”。 [[16]](#sgz-note-16)

<a id="sgz-event-17"></a>

17. **魏九月大赦。** 朝廷大赦。 [[17]](#sgz-note-17)

<a id="sgz-event-18"></a>

18. **何曾任晋丞相。** 魏司徒何曾出任晋丞相。 [[18]](#sgz-note-18)

<a id="sgz-event-19"></a>

19. **司马望、石苞、陈骞改官。** 任司马望为司徒、石苞为骠骑将军、陈骞为车骑将军。 [[19]](#sgz-note-19)

<a id="sgz-event-20"></a>

20. **晋文王司马昭下葬。** 安葬晋文王。 [[20]](#sgz-note-20)

<a id="sgz-event-21"></a>

21. **康居大宛献名马。** 康居、大宛的贡马归相国府，魏廷称为怀柔远邦的成果。 [[21]](#sgz-note-21)

<a id="sgz-event-22"></a>

22. **晋受禅后郭建、郭德、甄温加特进。** 晋代魏时三人均加位特进。 [[22]](#sgz-note-22)

<a id="sgz-event-23"></a>

23. **晋武帝称王经守志，任王经孙为郎中。** 晋武帝念王经守其志节并悯其家衰，诏其孙为郎中。 [[23]](#sgz-note-23)

<a id="sgz-event-24"></a>

24. **罗宪改封西鄂侯，家属安居洛阳。** 晋泰始元年罗宪改封西鄂县侯，妻儿迁洛阳，武帝用其子为给事中。 [[24]](#sgz-note-24)

<a id="sgz-event-25"></a>

25. **魏咸熙二年追赠荀彧太尉。** 咸熙二年追赠荀彧为太尉。 [[25]](#sgz-note-25)

<a id="sgz-event-26"></a>

26. **吴以蒋陵甘露改元大赦。** 蒋陵报见甘露，吴改元甘露并赦。 [[26]](#sgz-note-26)

<a id="sgz-event-27"></a>

27. **吴分立始安、始兴两郡。** 设零陵南部为始安郡，桂阳南部为始兴郡。 [[27]](#sgz-note-27)

<a id="sgz-event-28"></a>

28. **晋武帝赐王基家奴婢。** 诏称王基立功、任重而保持清素，去世后家无私蓄，赐给家人二人。 [[28]](#sgz-note-28)

<a id="sgz-event-29"></a>

29. **司马望于魏晋禅代之际任司徒。** 《晋诸公赞》称魏咸熙中官至司徒。 [[29]](#sgz-note-29)

<a id="sgz-event-30"></a>

30. **晋封司马望义阳王。** 司马望入晋为义阳王。 [[30]](#sgz-note-30)

<a id="sgz-event-31"></a>

31. **司马洪封河间王。** 司马洪字孔业，封河间王。 [[31]](#sgz-note-31)

<a id="sgz-event-32"></a>

32. **贾充封鲁公。** 贾充以辅晋之功获封。 [[32]](#sgz-note-32)

<a id="sgz-event-33"></a>

33. **司马炎践阼任王祥太保。** 任太保，封雎陵公。 [[33]](#sgz-note-33)

<a id="sgz-event-34"></a>

34. **晋受禅进裴秀鉅鹿公。** 为左光禄大夫，改封公。 [[34]](#sgz-note-34)

<a id="sgz-event-35"></a>

35. **晋武帝受禅封陈骞高平郡公。** 以参与佐命，陈骞受封高平郡公。 [[35]](#sgz-note-35)

### 1. 吴遣纪陟、弘璆赴魏

[返回正文第1条](#sg-event-1)

<a id="sg048-l2359-e1"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p007)** · [仓内TXT L2359](../../sources/本地分卷/三国志/三国志-卷048.md#l2359)

> 今遣光祿大夫紀陟、五官中郎將弘璆宣明至懷。

**归年与互校** 《孙皓传》三月遣出，《陈留王纪》四月记请和。

<a id="sgz004-b-295-4"></a>

**[《三国志·三少帝纪》仓内原文 L295](../../sources/本地分卷/三国志/三国志-卷004.md#l295)**

> 吳遣使紀陟、弘璆請和。

**释读** 吴以纪陟、弘璆为使，向魏求和。

**归年** 咸熙二年四月，《吴主传》所记使者名称部分不尽相同。

<a id="sgz048-b-2359-1"></a>

**[《三国志·三嗣主传》仓内原文 L2359](../../sources/本地分卷/三国志/三国志-卷048.md#l2359)**

> ﻿甘露元年三月，皓遣使隨紹、彧報書曰：「知以高世之才，處宰輔之任，漸導之功，勤亦至矣。孤以不德，階承統緒，思與賢良共濟世道，而以壅隔未有所緣，嘉意允著，深用依依。今遣光祿大夫紀陟、五官中郎將弘璆宣明至懷。」

**释读** 孙皓遣纪陟、弘璆随魏使返，以书称愿同司马昭共济世道，遣二人陈述。

**归年** 本传甘露元年三月；甘露作为全岁追号，4月才施改元。

<a id="sgz048-b-2359-2"></a>

**[《三国志·三嗣主传》仓内原文 L2359](../../sources/本地分卷/三国志/三国志-卷048.md#l2359)**

> 紹行到濡須，召還殺之，徙其家屬建安，始有白紹稱美中國者故也。

**释读** 徐绍到濡须时因有人告他赞美中国，被召回杀死，家属迁建安。

**归年** 265吴回使阶段。

<a id="sgz048-b-2359-6"></a>

**[《三国志·三嗣主传》仓内原文 L2359](../../sources/本地分卷/三国志/三国志-卷048.md#l2359)**

> 陟、璆至洛，遇晉文帝崩，十一月，乃遣還。

**释读** 二人到洛阳时遇晋文帝去世，十一月才被遣还。

**归年** 司马昭咸熙二年八月卒，返吴日期本传十一月。

<a id="sgz048-p-019-1"></a>

**[《三国志·三嗣主传》裴注 019·1](../../sources/摘录/三国志-卷048-三嗣主传裴注.md#pei-019-1)**

> 江表傳曰晧書兩頭言白稱名言而不著姓

**释读** 《江表传》说孙皓在开头末尾都称白，只用名不写姓。

**归年** 甘露元年三月回书的文字体例，与本传同件。

<a id="sgz048-p-019-4"></a>

**[《三国志·三嗣主传》裴注 019·4](../../sources/摘录/三国志-卷048-三嗣主传裴注.md#pei-019-4)**

> 干寳晉紀曰陟璆奉使如魏入境而問諱入國而問俗夀春將王布示之馬射既而問之曰呉之君子亦能斯乎陟曰此軍人騎士肄業所及士大夫君子未有為之者矣布大慙既至魏帝見之使儐問曰來時呉王何如陟對曰來時皇帝臨軒百寮陪位御膳無恙晉文王饗之百寮畢㑹使儐者告曰某者安樂公也某者匃奴單于也陟曰西王失土為君王所禮位同三代莫不感義匃奴邊塞難覊之國君王懐之親在坐席此誠恩威逺著又問呉之戍備幾何對曰自西陵以至江都五千七百里又問曰道里甚逺難為堅固對曰疆界雖逺而其險要必争之地不過數四猶人雖有八尺之軀靡不受患其䕶風寒亦數處耳文王善之厚為之禮

**释读** 在寿春说骑射乃军人之事。见魏帝及司马昭后，数称吴君为帝、妥答防守要隘等问题，司马昭厚礼之。

**归年** 本传甘露元年遣二使；宴会发生司马昭死前。

**释读** 范慎在武昌治军整顿，孙皓徙都时敬惮他。

**归年** 《三嗣主传》甘露元年孙皓迁武昌。“憚”保持原文，未明是敬畏还是另有所防。

<a id="sgz048-p-022-1"></a>

> 漢晉春秋曰初望氣者云荆州有王氣破楊州而建業宫不利故晧徙武昌遣使者發民掘荆州界大臣名家冡與山岡連者以厭之

**释读** 术士声称荆州王气将克扬州，孙皓迁武昌，并命发掘荆州名家与山连的坟冢以压王气。

**归年** 本传甘露元年迁都；望气与掘冢是另书记动机。

### 4. 晋受魏禅

[返回正文第4条](#sg-event-4)

<a id="sg048-l2359-e4"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p007)** · [仓内TXT L2359](../../sources/本地分卷/三国志/三国志-卷048.md#l2359)

> 十二月，晉受禪。

<a id="sgz004-b-297-1"></a>

**[《三国志·三少帝纪》仓内原文 L297](../../sources/本地分卷/三国志/三国志-卷004.md#l297)**

> 十二月壬戌，天祿永終，歷數在晉。詔羣公卿士具儀設壇於南郊，使使者奉皇帝璽綬冊，禪位於晉嗣王，如漢魏故事。

**释读** 曹魏诏称天命在晋，命群臣设南郊坛，使者奉皇帝玺绶册书，以汉魏交替时的礼仪禅位。

**归年** 咸熙二年十二月壬戌是备礼、发诏日，甲子实际奉策，晋丙寅登坛。

<a id="sgz004-b-297-2"></a>

**[《三国志·三少帝纪》仓内原文 L297](../../sources/本地分卷/三国志/三国志-卷004.md#l297)**

> 甲子，使使者奉策。

**释读** 正式遣使奉上禅代册命。

**归年** 咸熙二年十二月甲子；《晋书·礼志》同，另记司马炎丙寅登坛。

<a id="sgz004-b-297-3"></a>

**[《三国志·三少帝纪》仓内原文 L297](../../sources/本地分卷/三国志/三国志-卷004.md#l297)**

> 遂改次於金墉城，而終館於鄴，時年二十。

**释读** 曹奂退出帝位后迁至金墉城，随后在邺居住。原文记“时年二十”。

**归年** 逊位在咸熙二年十二月。《魏世谱》另记封为陈留王与太安元年卒；不能将“終館”误译为265年去世。

<a id="sgz004-p-016-2"></a>

**[《三国志·三少帝纪》裴注 016·2](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-016-2)**

> 魏世譜曰晉受禪封齊王為邵陵縣公

**释读** 《魏世谱》记晋受魏禅，曹芳由齐王改封邵陵县公。

**归年** 咸熙二年、晋泰始元年（265），可与《通鉴》卷079受禅后降封对读。

<a id="sgz004-p-033-1"></a>

**[《三国志·三少帝纪》裴注 033·1](../../sources/摘录/三国志-卷004-三少帝纪裴注.md#pei-033-1)**

> 魏世譜曰封帝為陳留王

**释读** 《魏世谱》称魏禅晋后，曹奂封陈留王。

**归年** 接咸熙二年魏禅晋，《晋书·武帝纪》亦载。

<a id="sgz041-p-006-3"></a>

**[《三国志·霍王向张杨费传》裴注 006·3](../../sources/摘录/三国志-卷041-霍王向张杨费传裴注.md#pei-006-3)**

> 明年十二月而晋武帝即尊位炎興於是乎徴焉

**释读** 次年十二月司马炎即皇帝位，注中把蜀汉末代年号炎兴附会为征兆。

**归年** 《晋书·武帝纪》泰始元年十二月；265为中国史的传统年度折标，实际西历日有266年初换算。

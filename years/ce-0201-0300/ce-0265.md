## 本年概述

司马昭去世后，司马炎继为晋王，年末受魏禅。晋改官并封赏旧臣。吴与魏往来使者返国，孙皓同年迁都武昌。

2. **司马炎受魏禅，晋褒录故臣并封赏宗室勋臣。** 司马炎受魏禅，晋改元泰始。他下诏宽免王凌、邓艾后人，准无子孙者立后奉祀；称王经守志，任命其孙为郎中。晋给郭建、郭德、甄温加特进，赐王基家奴婢，以王祥为太保、封睢陵公，任裴秀为左光禄大夫、进封钜鹿公，又封司马望为义阳王、司马洪为河间王、贾充为鲁公、陈骞为高平郡公。 [[2]](#sg-note-4)

<a id="sgz-event-10"></a>

3. **魏诏把孙皓所贡归司马昭。** 诏称吴受司马昭文告感召遣使献礼，宜将贡品归司马昭；司马昭坚辞，遂止。 [[3]](#sgz-note-10)

<a id="sgz-event-17"></a>

5. **魏九月大赦。** 朝廷大赦。 [[5]](#sgz-note-17)

<a id="sgz-event-25"></a>

6. **魏咸熙二年追赠荀彧太尉。** 咸熙二年追赠荀彧为太尉。 [[6]](#sgz-note-25)

<a id="sgz-event-24"></a>

7. **罗宪改封西鄂侯，家属安居洛阳。** 晋泰始元年罗宪改封西鄂县侯，妻儿迁洛阳，武帝用其子为给事中。 [[7]](#sgz-note-24)

<a id="sgz-event-8"></a>

8. **张修因报钟会起兵而受褒。** 诏称虎贲张修先前在成都跑马通知诸营钟会谋反，因此身死，今封其弟张倚为关内侯。 [[8]](#sgz-note-8)

## 吴使北行与迁都

<a id="sg-event-1"></a>

9. **吴遣纪陟、弘璆回访魏廷。** 三月，孙皓派纪陟、弘璆随魏使回访。徐绍到濡须后，被孙皓召回杀害。纪陟、弘璆出使洛阳，至十一月回吴。 [[9]](#sg-note-1)

<a id="sg-event-2"></a>

10. **孙皓逼死朱皇后，处置孙休诸子。** 秋七月，孙皓逼死景皇后朱氏，她与孙休合葬定陵。孙皓送孙休四子至吴小城，后来追杀两名年长者。 [[10]](#sg-note-2)

<a id="sg-event-3"></a>

11. **孙皓由建业迁都武昌。** 本传在九月记孙皓从西陵督步阐议，迁都武昌，留丁固、诸葛靓镇建业。《资治通鉴》将迁都记在冬，孙皓次年还建业。 [[11]](#sg-note-3)

<a id="sgz-event-26"></a>

12. **吴以蒋陵甘露改元大赦。** 蒋陵报见甘露，吴改元甘露并赦。 [[12]](#sgz-note-26)

<a id="sgz-event-27"></a>

13. **吴分立始安、始兴两郡。** 设零陵南部为始安郡，桂阳南部为始兴郡。 [[13]](#sgz-note-27)

### 2. 司马炎受魏禅，晋褒录故臣并封赏宗室勋臣

<a id="sg048-l2359-e4"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sg048-l2359-e4)** · [TXT L82](../../sources/本地分卷/三国志/三国志-卷048.txt#L82)

> 十二月，晉受禪。

**晋受魏禅** 晋于十二月受魏禅。

**归年依据** 《晋书·武帝纪》魏咸熙二年十二月丙寅。

<a id="sgz021-p-023-4b"></a>

> 晉室踐阼

**释读** 司马炎受禅即位。

**归年** 西晋代魏在265年，以下官历须分读。

<a id="sgz004-b-297-1"></a>

**[《三国志·三少帝纪》仓内原文 L297](../../sources/本地分卷/三国志/三国志-卷004.md#l297)**

> 十二月壬戌，天祿永終，歷數在晉。詔羣公卿士具儀設壇於南郊，使使者奉皇帝璽綬冊，禪位於晉嗣王，如漢魏故事。

**释读** 曹魏诏称天命在晋，命群臣设南郊坛，使者奉皇帝玺绶册书，以汉魏交替时的礼仪禅位。

**归年** 咸熙二年十二月壬戌是备礼、发诏日，甲子实际奉策，晋丙寅登坛。

<a id="sgz004-b-297-2"></a>

**[《三国志·三少帝纪》仓内原文 L297](../../sources/本地分卷/三国志/三国志-卷004.md#l297)**

> 甲子，使使者奉策。

**释读** 正式遣使奉上禅代册命。

**归年** 咸熙二年十二月甲子；《晋书·礼志》同，另记司马炎丙寅登坛。

<a id="sgz004-b-297-3"></a>

**[《三国志·三少帝纪》仓内原文 L297](../../sources/本地分卷/三国志/三国志-卷004.md#l297)**

> 遂改次於金墉城，而終館於鄴，時年二十。

**释读** 曹奂退出帝位后迁至金墉城，随后在邺居住。原文记“时年二十”。

**归年** 逊位在咸熙二年十二月。《魏世谱》另记封为陈留王与太安元年卒；不能将“終館”误译为265年去世。

<a id="sgz004-p-016-2"></a>

**[《三国志·三少帝纪》裴注 016·2](../../sources/本地分卷/三国志/三国志-卷004.md#pei-016-2)**

**释读** 《魏世谱》记晋受魏禅，曹芳由齐王改封邵陵县公。

**归年** 咸熙二年、晋泰始元年（265），可与《通鉴》卷079受禅后降封对读。

**归年** 接咸熙二年魏禅晋，《晋书·武帝纪》亦载。

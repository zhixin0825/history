# 公元266年｜晋泰始二年／吴宝鼎元年

[← 公元265年](ce-0265.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元267年 →](ce-0267.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **吴遣使吊祭司马昭。** 孙皓遣张俨、丁忠吊祭。丁忠归后主张乘晋暂无守备袭弋阳，陆凯反对，孙皓暂未出兵。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **吴改元宝鼎、任陆凯万彧为左右丞相。** 八月，各地报发现大鼎，孙皓改元并大赦，以陆凯、万彧分掌左右丞相。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **施但胁孙谦起兵，被丁固等击败。** 冬十月，施但聚众挟孙谦趋建业。丁固、诸葛靓在牛屯迎击，施但败走，孙谦自杀。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **吴分设东阳、吴兴、邵陵三郡。** 从会稽分设东阳，从吴郡、丹杨分设吴兴，又以零陵北部置邵陵。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **孙皓从武昌还都建业。** 吴主十二月还建业，滕牧留守武昌。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **孙皓杀散骑常侍王蕃。** 丁忠使晋仍吴后，孙皓宴饮群臣，王蕃醉伏后不改进退，孙皓命杀；滕牧、留平劝阻不成。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **迁左丞相。** 宝鼎元年，迁左丞相。 [[7]](#sg-note-7)

<a id="sgz-event-8"></a>

8. **晋合圜丘、方丘之祭于南北郊。** 晋泰始二年，把圜丘和方丘的冬至、夏至祭祀合并在南郊和北郊举行。 [[8]](#sgz-note-8)

<a id="sgz-event-9"></a>

9. **夏侯佐死无嗣，晋武帝诏择夏侯劭继封。** 《晋阳秋》载泰始二年夏侯惇孙高安乡侯夏侯佐卒无嗣，晋武帝念夏侯惇功劳，命择近属夏侯劭续封。 [[9]](#sgz-note-9)

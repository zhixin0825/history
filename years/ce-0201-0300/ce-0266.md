# 公元266年｜晋泰始二年／吴宝鼎元年

[← 公元265年](ce-0265.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元267年 →](ce-0267.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **吴遣使吊祭司马昭。** 孙皓遣张俨、丁忠吊祭。丁忠归后主张乘晋暂无守备袭弋阳，陆凯反对，孙皓暂未出兵。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **吴改元宝鼎、任陆凯万彧为左右丞相。** 八月，各地报发现大鼎，孙皓改元并大赦，以陆凯、万彧分掌左右丞相。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **施但胁孙谦起兵，被丁固等击败。** 冬十月，施但聚众挟孙谦趋建业。丁固、诸葛靓在牛屯迎击，施但败走，孙谦自杀。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **吴分设东阳、邵陵。** 从会稽分设东阳，又以零陵北部置邵陵；同段[吴兴郡专诏](#sgz-note-10)另见本年第10条。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **孙皓从武昌还都建业。** 吴主十二月还建业，滕牧留守武昌。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **孙皓杀散骑常侍王蕃。** 丁忠使晋仍吴后，孙皓宴饮群臣，王蕃醉伏后不改进退，孙皓命杀；滕牧、留平劝阻不成。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>



<a id="sgz-event-8"></a>

8. **晋合圜丘、方丘之祭于南北郊。** 晋泰始二年，把圜丘和方丘的冬至、夏至祭祀合并在南郊和北郊举行。 [[8]](#sgz-note-8)

<a id="sgz-event-9"></a>

9. **夏侯佐死无嗣，晋武帝诏择夏侯劭继封。** 《晋阳秋》载泰始二年夏侯惇孙高安乡侯夏侯佐卒无嗣，晋武帝念夏侯惇功劳，命择近属夏侯劭续封。 [[9]](#sgz-note-9)

<a id="sgz-event-10"></a>

10. **分吴、丹杨九县设吴兴郡。** 吴兴郡治乌程，置守并奉祭孙和。 [[10]](#sgz-note-10)

<a id="sgz-event-11"></a>

11. **文立任济阴太守。** 文立拜济阴太守。 [[11]](#sgz-note-11)

<a id="sgz-event-12"></a>

12. **曹翕遣世子曹琨奉表，武帝加赏。** 曹琨入朝，晋武帝称曹翕为魏宗之良，给曹琨世子印绶，加骑都尉，赐服、钱并令按才任用。 [[12]](#sgz-note-12)

<a id="sgz-event-13"></a>

13. **都武昌后陆凯上疏请息役养民。** 孙皓迁都武昌后，扬州百姓逆流输送物资，苦于劳费，加以政事失当，陆凯上疏。 [[13]](#sgz-note-13)

<a id="sgz-event-14"></a>

14. **丁忠劝袭弋阳，陆凯反对。** 丁忠称晋防备不足。陆凯说晋新并巴蜀、势强，此时使者求亲意在息兵，袭取无利。 [[14]](#sgz-note-14)

<a id="sgz-event-15"></a>

15. **刘纂建议侦察，孙皓未发兵而断往来。** 刘纂赞成先查晋方虚实。孙皓暗认同，却因蜀新平没有发兵，自此与晋断交。 [[15]](#sgz-note-15)

### 1. 吴遣使吊祭司马昭

> 遣大鴻臚張儼、五官中郎將丁忠弔祭晉文帝。

<a id="sgz061-b-2897-11"></a>

**释读** 使者丁忠回吴后谓晋的弋阳可袭，陆凯劝吴主审视晋新并巴蜀之势，孙皓未出兵。

**归年** 《三嗣主传》宝鼎元年正月发使，回国后进说；《通鉴》卷七十九将回使列晋泰始二年春。

**释读** 大鸿胪张俨和五官中郎将丁忠到晋吊祭司马昭。张俨在归途中病死。

**归年** 本传正月；实改元宝鼎在八月。

<a id="sgz048-p-020-1"></a>

**[《三国志·三嗣主传》裴注 020·1](../../sources/摘录/三国志-卷048-三嗣主传裴注.md#pei-020-1)**

> 呉録曰儼字子節呉人也弱冠知名歴顯位以博聞多識拜大鴻臚使於晉晧謂儼曰今南北通好以君為有出境之才故相屈行對曰皇皇者華䝉其榮耀無古人延譽之美磨厲鋒鍔思不辱命既至車騎將軍賈充尚書令裴秀侍中荀朂等欲傲以所不知而不能屈尚書僕射羊祜尚書何禎並結縞帶之好

**释读** 张俨受孙皓派遣赴晋，说将努力不辱使命。到晋后，贾充、裴秀等试图用难题压倒他而不能，羊祜、何桢与他交好。

**归年** 本传当年吊晋文帝；早年历位为同注回顾。

### 2. 吴改元宝鼎、任陆凯万彧为左右丞相

<a id="sg048-l2360-e2"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p007)** · [仓内TXT L2360](../../sources/本地分卷/三国志/三国志-卷048.md#l2360)

> 八月，所在言得大鼎，於是改年，大赦。以陸凱爲左丞相，常侍萬彧爲右丞相。

<a id="sgz061-b-2897-12"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2897](../../sources/本地分卷/三国志/三国志-卷061.md#l2897)**

> 寶鼎元年，遷左丞相。

**释读** 陆凯迁左丞相。

**归年** 本传及《三嗣主传》宝鼎元年；年页另有同事简条E7。

<a id="sgz061-b-2898-1"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2898](../../sources/本地分卷/三国志/三国志-卷061.md#l2898)**

> 皚性不好人視己，郡臣侍見，精莫敢進。凱說皓曰：「夫君臣無不相識之道，若率有不虞，不知所赴。」皓聽凱自視。

**释读** 孙皓不喜臣下抬头直视，陆凯以君臣遇急须相识相知为由相劝，孙皓许陆凯本人可直视。

**归年** 《通鉴》卷七十九泰始二年列于陆凯拜相后，未记独立年月；底本「皚」等疑字照录。

<a id="sgz061-b-2915-1"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2915](../../sources/本地分卷/三国志/三国志-卷061.md#l2915)**

> 臣聞宰相國之柱也，不可不強，是故漢有蕭、曹之佐，先帝有顧、步之相。而萬彧瑣才凡庸之質，昔從家隸，超步紫闥，於彧已豐，於器已溢，而陛下愛其細介，不訪大趣，榮以尊輔，越尚舊臣。賢良憤惋，智士赫吒，是不遵先帝三也；

**释读** 疏说宰相为国柱，以萧曹及吴顾、步为例，批评以资望不足的万彧为宰辅，引起贤者不满。

**归年** 只有万彧拜相确在266，《三嗣主传》明记，疏文的成文及进呈年未定。

### 3. 施但胁孙谦起兵，被丁固等击败

[返回正文第3条](#sg-event-3)

<a id="sg048-l2360-e3"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p007)** · [仓内TXT L2360](../../sources/本地分卷/三国志/三国志-卷048.md#l2360)

> 丁固、諸葛靚逆之於牛屯，大戰，但等敗走。獲謙，謙自殺。

<a id="sgz059-p-013-2"></a>

**[《三国志·吴主五子传》裴注 013·2](../../sources/摘录/三国志-卷059-吴主五子传裴注.md#pei-013-2)**

> 晧在武昌吳興施但因民之不堪命聚萬餘人刼謙將至秣陵欲立之未至三十里住擇吉日但遣使以謙命詔丁固諸葛靚靚即斬其使但遂前到九里固靚出擊大破之但兵祼身無鎧甲臨陣皆披散謙獨坐車中遂生獲之

**释读** 施但利用不满集众，胁孙谦至秣陵，丁固、诸葛靓击破之，孙谦被生擒。

**归年** 《三嗣主传》宝鼎元年十月；败于牛屯，同事。

<a id="sgz059-p-013-3"></a>

**[《三国志·吴主五子传》裴注 013·3](../../sources/摘录/三国志-卷059-吴主五子传裴注.md#pei-013-3)**

> 固不敢殺以狀告晧晧酖之母子皆死

**释读** 丁固不肯擅杀，奏孙皓后孙谦及母被毒死。

**归年** 宝鼎元年施但败，同年正史作孙谦自杀，两说并存。

<a id="sgz051-b-2464-14"></a>

**[《三国志·宗室传》仓内原文 L2464](../../sources/本地分卷/三国志/三国志-卷051.md#l2464)**

> 初永安賊施但等劫皓弟謙，襲建業，或白楷二端不即赴討者，

**释读** 施但等劫持孙皓之弟孙谦袭向建业，孙楷被人告以持两端、未立即赶往讨伐。

**归年** 《三嗣主传》宝鼎元年冬十月；告发是否随当时无确证，事由承此。

<a id="sgz048-b-2360-5"></a>

**[《三国志·三嗣主传》仓内原文 L2360](../../sources/本地分卷/三国志/三国志-卷048.md#l2360)**

> 冬十月，永安山賊施但等聚衆數千人，劫皓庶弟永安侯謙出烏程，取孫和陵上鼓吹曲蓋。比至建業，衆萬餘人。丁固、諸葛靚逆之於牛屯，大戰，但等敗走。獲謙，謙自殺。

**释读** 施但胁永安侯孙谦出乌程，取孙和陵用仪仗，进抵建业附近。丁固、诸葛靓在牛屯击败之，孙谦被获后自尽。

**归年** 本传宝鼎元年十月。

<a id="sgz048-p-022-2"></a>

**[《三国志·三嗣主传》裴注 022·2](../../sources/摘录/三国志-卷048-三嗣主传裴注.md#pei-022-2)**

> 既聞但反自以為徙土得計也使數百人皷譟入建業殺但妻子云天子使荆州兵來破楊州賊以厭前氣

**释读** 闻施但反，孙皓自认获迁都之利，派人鼓噪入建业杀施但妻儿，宣称荆州兵打败扬州反者。

**归年** 本传宝鼎元年施但起兵被讨，《汉晋春秋》记其政治表演。

### 5. 孙皓从武昌还都建业

[返回正文第5条](#sg-event-5)

<a id="sg048-l2360-e5"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p007)** · [仓内TXT L2360](../../sources/本地分卷/三国志/三国志-卷048.md#l2360)

> 十二月，皓還都建業，衞將軍滕牧留鎮武昌。

<a id="sgz061-b-2910-3"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2910](../../sources/本地分卷/三国志/三国志-卷061.md#l2910)**

> 或曰寶鼎元年十二月，凱與大司馬丁奉、御史大夫丁固謀，因皓謁廟，欲廢皓立孫休子。時左將軍留平領兵先驅，故密語平，平拒而不許，誓以不洩，是以所圖不果。

**释读** 异说称陆凯、丁奉、丁固拟在孙皓谒庙时改立孙休子，先与领兵的留平商量，留平拒绝但答应保密，未实行。

**归年** 本传明作「或曰」且标266十二月；《通鉴》考异明确不采，丁奉官称与本纪时段有疑，不作确定行动。

<a id="sgz061-b-2910-4"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2910](../../sources/本地分卷/三国志/三国志-卷061.md#l2910)**

> 太史郎陳苗奏皓久陰不雨，風氣回逆，將有陰謀，皓深警懼雲。

**释读** 陈苗据久阴少雨、风气回逆，称可能有阴谋，孙皓深为戒惧。

**归年** 原文系于宝鼎元年十二月异说相邻叙事，真伪及独立日期未证。

<a id="sgz061-p-007-1"></a>

**[《三国志·潘濬陆凯传》裴注 007·1](../../sources/摘录/三国志-卷061-潘濬陆凯传裴注.md#pei-007-1)**

> 吳録曰舊拜廟選兼大将軍領三千兵為衛凱欲因此兵以圗之令選曹白用丁奉晧偶不欲曰更選凱令執據雖蹔兼然宜得其人晧曰用留平凱令其子禕以謀語平

**释读** 吴旧例谒庙选兼大将军为卫，传说陆凯想借此，荐丁奉，孙皓改选留平。陆凯遣子陆祎探意。

**归年** 承本传或曰266十二月事项；《通鉴》考异不取。

<a id="sgz061-p-007-2"></a>

**[《三国志·潘濬陆凯传》裴注 007·2](../../sources/摘录/三国志-卷061-潘濬陆凯传裴注.md#pei-007-2)**

> 平素與丁奉有隙禕未及得宣凱旨平語禕曰聞野猪入丁奉營此凶徴也有喜色禕乃不敢言還因具啓凱故輟止

**释读** 留平向来与丁奉有隙，在陆祎尚未吐露来意前就喜谈丁奉军中不祥，陆祎遂不敢说，回来报告，谋因而停止。

**归年** 同一原传传闻；与正文留平已听明确内容而拒的叙述不同。

### 6. 孙皓杀散骑常侍王蕃

[返回正文第6条](#sg-event-6)

<a id="sg065-l3037-e6"></a>

**[《三国志·王楼贺韦华传》](../../sources/摘录/三国志-卷065-王楼贺韦华传.md#p001)** · [仓内TXT L3037](../../sources/本地分卷/三国志/三国志-卷065.md#l3037)

> 甘露二年，丁忠使晉還，皓大會群臣，蕃沉醉頓伏。

**归年与互校** 《吴主传》宝鼎元年正月派丁忠赴晋、八月改年。本传仍书甘露二年，二号同是266。

<a id="sgz065-b-3037-1"></a>

**[《三国志·王楼贺韦华传》仓内原文 L3037](../../sources/本地分卷/三国志/三国志-卷065.md#l3037)**

> 甘露二年，丁忠使晉還，皓大會群臣，蕃沉醉頓伏。皓疑而不悅，舉蕃出外。頃之請還，酒亦不解。蕃性有威嚴，行止自若，皓大怒，呵左右於殿下斬之。衛將軍滕牧、征西將軍留平請，不能得。

**释读** 王蕃酒醉伏席，出后复入。孙皓疑其有意，令殿下斩之，滕牧、留平请救未果。

**归年** 甘露二年即宝鼎元年、晋泰始二年。《通鉴》卷079列266年春，与丁忠受使还吴相合。

<a id="sgz065-b-3038-2"></a>

**[《三国志·王楼贺韦华传》仓内原文 L3038](../../sources/本地分卷/三国志/三国志-卷065.md#l3038)**

> 蕃死時年三十九，皓徙蕃家屬廣州。

**释读** 王蕃被杀时年三十九，孙皓移其家于广州。

**归年** 本传承266年杀王蕃；家属迁徙为后续，日月无载。

<a id="sgz065-p-001-1"></a>

**[《三国志·王楼贺韦华传》裴注 001·1](../../sources/摘录/三国志-卷065-王楼贺韦华传裴注.md#pei-001-1)**

> 江表傳曰晧用巫史之言謂建業宮不利乃西廵武昌仍有遷都之意恐羣臣不從乃大請㑹賜將吏問蕃射不主皮為力不同科其義云何蕃思維未答即於殿上斬蕃出登來山使親近將跳蕃首作虎跳狼爭咋齧之頭皆碎壊欲以示威使衆不敢犯也此與本傳不同

**释读** 因巫言西巡及谋迁都，孙皓集众问王蕃射义，答案未出便斩，后使人抛掷毁首。

**归年** 与266杀王蕃同一人物和结果，设问、迁都先后与醉酒说不同，传中时序不单取。

<a id="sgz061-b-2914-1"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2914](../../sources/本地分卷/三国志/三国志-卷061.md#l2914)**

> 臣聞有國以賢為本，夏殺龍逢，殷獲伊摯。斯前世之明效，今日之師表也。中常侍王蕃黃中通理，處朝忠謇，斯社稷之重鎮，大吳之龍逢也，而陛下忿其苦辭，惡其直對，梟之殿堂，屍骸暴棄。邦內傷心，有識悲悼，咸以吳國夫差復存，先帝親賢，陛下反之，是陛下不遵先帝二也；

**释读** 疏以王蕃为吴之关龙逢，称他忠直，因直言被斩并弃尸，吴人痛惜。

**归年** 只有王蕃之死确系266，《王蕃传》及《通鉴》同；本疏本身未定年，附作王蕃死的传载评价。

### 13. 都武昌后陆凯上疏请息役养民

[返回正文第13条](#sgz-event-13)

<a id="sgz061-b-2899-1"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2899](../../sources/本地分卷/三国志/三国志-卷061.md#l2899)**

> 皓時徒都武昌，揚土百姓溯流供給，以為患苦，又政事多謬，黎無窮匱。凱上疏曰：

**归年** 《三嗣主传》载265迁武昌、266归建业；《通鉴》卷七十九把此疏系266年。

<a id="sgz061-b-2900-1"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2900](../../sources/本地分卷/三国志/三国志-卷061.md#l2900)**

> 臣聞有道之君，以樂樂民。無道之君，以樂樂身。樂民者，其樂彌長。樂身者，不久而亡。夫民者，國之根也，誠宜重其食，愛其命。民安則君安，民樂則君樂。自頃年以來。君威傷於桀、紂，君明暗於奸雄，君惠閉於群孽。無災而民命盡，無為而國財空，辜無罪，賞無功，使君有謬誤之愆，天為作妖。而諸公卿媚上以求愛，因民以求饒，導君於不義，敗政於淫俗，臣竊為痛心。今鄰國交好。四邊無事，當務息役養士，實其廩庫，以待天時。而更傾動天心，騷擾萬姓，使民不安，大小呼嗟，此非保國養民之術也。

**释读** 陆凯以百姓为国家根本，批评刑赏失当、臣僚媚上，主张边境无事时应停徭役、养士卒、实仓储。

**归年** 同一266年疏。

<a id="sgz061-b-2901-1"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2901](../../sources/本地分卷/三国志/三国志-卷061.md#l2901)**

> 臣聞吉凶在天，猶影之在形，響之在聲也，形動則影動，形止則影止。此分數乃有所繫，非在口之所進退也。昔秦所以亡天下者，但坐賞輕而罰重，政刑錯亂，民力盡於奢侈，目眩於美色，志濁於財寶。邪臣在位，賢哲隱藏，百姓業業，天下苦之。是以遂有覆巢破卵之憂。漢所以強者，躬行誠信，聽諫納賢，惠及負薪，躬請巖穴，廣采博察，以成其謀。此往事之明證也。

**释读** 陆凯以形影声响说明灾福由行为而来，举秦赏轻罚重、奢淫亡国与汉纳贤亲民的对照。

**归年** 同一266年疏；秦汉史事是奏疏举例。

<a id="sgz061-b-2902-1"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2902](../../sources/本地分卷/三国志/三国志-卷061.md#l2902)**

> 近者漢之衰末，三家鼎立，曹失綱紀，晉有其政。又益州危險。兵多精強，閉門固守，可保萬世，而劉氏以奪乖錯，賞罰失所，君恣意於奢侈，民力竭於不急，是以為晉所伐，君臣見虜，此目前之明驗也。

**释读** 陆凯用魏权归晋、蜀虽险强仍因政治失当而败亡作近期例证。

**归年** 同一266年疏；灭蜀263、代魏265为回叙。

<a id="sgz061-b-2903-1"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2903](../../sources/本地分卷/三国志/三国志-卷061.md#l2903)**

> 臣暗於大理，文不及義，智慧淺劣，無復冀望，竊為陛下惜天下耳。臣謹奏耳目所聞見，百姓所為煩苛，刑政所為錯亂，願陛下息大功，損百役，務寬蕩，忽苛政。又武昌土地，實危險而瘠確，非王都安國養民之處，船泊則沉漂，陵居則峻危，旦童謠曰：『寧飲建業水，不食武昌魚，寧還建業死，不止武昌居。』臣聞翼星為變，熒惑作妖，童謠之言，生於天心，乃以安居而比死，足明天意，如民所若也。

**释读** 他请求停大工程、减百姓徭役，说武昌地险土薄，不宜建都，并引宁归建业的民谣及天象劝令体察民意。

**归年** 同一266年疏；民谣也见《通鉴》卷七十九，未独立纪年。

<a id="sgz061-b-2904-1"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2904](../../sources/本地分卷/三国志/三国志-卷061.md#l2904)**

> 臣聞國無三年之儲，渭之非國，而今無一年之畜，此臣下責也。而諸公卿位處人上，祿延子孫，曾無致命之節，匡救之術，苟進小利於君，以求容媚，荼毒百姓，不為君計也。自從孫弘造義兵以來，耕種既廢，所在無復輸入，而分一家父子異役，廩食日張，畜積日耗。民有離散之怨，國有露根之漸，而莫之恤也。民力因窮，鬻賣兒子，調賦相仍，日以疲極，所在長吏，不加隱括，加有監官，既不愛民，務行威勢，所在騷擾，更為煩苛，民苦二端，財力再耗，此為無益而有損也。願陛下一息此輩。矜哀孤弱，以鎮撫百姓之心。此猶色鱉得免毒螫之淵，烏獸得離羅網之綱，四方之民襁負而至。如此，民可得保，先王之國存焉。

**释读** 陆凯说国储不足一年，长期用兵废农、父子分役耗尽积蓄，赋役、长吏与监官叠加，使民户穷到卖子；请撤苛扰以保民。

**归年** 同一266年疏；养民与监官形势非一时颁令。「孫弘」底本如此，不据此另立起兵年。

<a id="sgz061-b-2905-1"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2905](../../sources/本地分卷/三国志/三国志-卷061.md#l2905)**

> 臣聞五音令人耳不聰，五色令人目不明，此無益於政，有損於事者也。自昔先帝時，後宮列女，及諸織絡，數不滿百，米有畜積，貨財有餘。先帝崩後，幼、景在位，更改奢侈，不蹈先跡。伏聞織絡及諸徒坐，乃有千數，計其所長，不足為國財。然坐食宮廩，歲歲相承，此為無益。願陛下料出賦嫁，給與無妻者。如此，上應天心，下合地意，天下幸甚。

**释读** 陆凯比较孙权时宫中人数少、财物有余，孙亮孙休以后织造宫人达千数、坐耗国粮，请择宫人出嫁。

**归年** 同一266年疏；往朝宫人数是其论证。

<a id="sgz061-b-2906-1"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2906](../../sources/本地分卷/三国志/三国志-卷061.md#l2906)**

> 臣聞殷湯取士於商賈，齊桓取士於車轅，周武取士於負新，大漢取士於奴僕。明王聖主取士以賢，不拘卑賤。故其功德洋溢，名流竹素，非求顏色而取好服、捷口、容悅者也。臣伏見當今內寵之臣，位非其人，任非其量，不能輔國匡時，群黨相扶，害忠隱賢。願陛下簡文將之臣。各勤其官，州牧督將，藩鎮方外，公卿尚書，務修仁化，上助陛下，下拯黎民，各盡其忠，拾貴萬一。則康哉之歌作，刑錯之理清。願陛下留神思臣愚言。

**释读** 陆凯以多朝从卑贱选才为例，批评内宠不称其职、结党害忠，希望选任适当的人、令外将和公卿各尽职。

**归年** 同一266年疏。

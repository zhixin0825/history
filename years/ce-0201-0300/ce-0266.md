## 本年概述

晋立杨艳为皇后，调整宗庙、郊祀与军职，广开谏诤，赈省赋役。吴改元宝鼎，施但挟孙谦起兵失败，孙皓年底迁回建业。

1. **侯史光等巡察四方。** 正月丙戌，遣兼侍中侯史光等持节巡察四方风俗，撤除不在祀典中的禳灾祝祷。 [[1]](#jin003-u126-1-note)

<a id="jin003-u126-2-event"></a>

2. **司马炎拒建七庙。** 正月丁亥，有司请求营建七庙，司马炎认为劳役太重，没有准许。 [[2]](#jin003-u126-2-note)

<a id="jin003-u126-3-event"></a>

3. **停用鸡鸣歌。** 正月庚寅，停止鸡鸣歌。 [[3]](#jin003-u126-3-note)

<a id="jin003-u126-4-event"></a>

4. **尊羊氏为景皇后。** 正月辛丑，尊司马师夫人羊氏为景皇后，宫名弘训。 [[4]](#jin003-u126-4-note)

<a id="jin003-u126-5-event"></a>

5. **立杨艳为皇后。** 正月丙午，立杨艳为皇后。 [[5]](#jin003-u126-5-note)

<a id="sgz-event-14"></a>

6. **吴使吊祭与答书礼制。** 正月，孙皓遣张俨、丁忠吊祭司马昭。三月戊戌，晋廷接见吴使；有司拟以诏回复，司马炎说汉文帝待赵佗、光武帝待公孙述，都未先定君臣礼，以笼络尚未归服者，吴使出发时又尚不知晋朝成立，此次只用书信回复。张俨在回程中病死。丁忠回吴后建议袭取弋阳，陆凯以晋新并巴蜀、势正强反对；刘纂请先派人侦察，孙皓暗中采其意，最终没有发兵，吴晋往来却就此断绝。 [[6]](#sg-note-1)

<a id="sg-event-6"></a>

7. **孙皓杀散骑常侍王蕃。** 春，丁忠使晋归吴，孙皓召集群臣宴饮。王蕃平日为人刚直，曾受万彧、陈声排挤。宴上孙皓命人斩王蕃于殿廷，滕牧、留平求情未果。王蕃年三十九，其家属被迁往广州。陆凯上疏痛惜王蕃，指责孙皓杀害直臣并抛弃其遗体。 [[7]](#sg-note-6)

<a id="jin003-u127-1-event"></a>
<a id="jin003-l127-event"></a>

8. **解除汉宗室禁锢。** 二月，解除汉宗室的禁锢。 [[8]](#jin003-u127-1-note)

<a id="jin003-u127-2-event"></a>

9. **常山王司马衡去世。** 二月己未，常山王司马衡去世。 [[9]](#jin003-u127-2-note)

<a id="jin003-u127-3-event"></a>

10. **五等爵旧封次子另受爵。** 二月，诏令酬录旧勋：原县侯的次子传封亭侯，原乡侯的次子封关内侯，原亭侯的次子封关中侯，各食原封户的十分之一。 [[10]](#jin003-u127-3-note)

<a id="jin003-u127-4-event"></a>

11. **郊祀以宣帝配天、明堂宗祀文帝。** 二月，郊祀时以宣帝配天，在明堂宗祀文帝、配上帝。 [[11]](#jin003-u127-4-note)

<a id="jin003-u127-5-event"></a>

12. **选侍中常侍兼谏职。** 二月，命在侍中、常侍中选能严正匡救君主过失的人兼领谏职。诏书说古代百官本有规谏之责，保氏又以谏诤为专职，如今侍中、常侍正应承担这个位置。 [[12]](#jin003-u127-5-note)

<a id="jin003-u129-1-event"></a>
<a id="jin003-l129-event"></a>

13. **非大事由陈留王国官代上表。** 五月，司马炎认为陈留王曹奂谦逊、事事亲自上表不合优礼故主之意，令主管转告，非重大事务均由王国官属代为上表。 [[13]](#jin003-u129-1-note)

<a id="jin003-u129-2-event"></a>

14. **王沈去世。** 五月，骠骑将军、博陵公王沈去世。 [[14]](#jin003-u129-2-note)

<a id="jin003-l130-event"></a>

15. **济南王司马遂去世。** 六月壬申，济南王司马遂去世。 [[15]](#jin003-u130-1-note)

<a id="jin003-l131-event"></a>

16. **营建太庙。** 七月辛巳，营建太庙，运来荆山木材、采华山石材，铸十二根铜柱，涂金、雕刻各种物象，并缀明珠。 [[16]](#jin003-u131-1-note)

<a id="jin003-u131-2-event"></a>

17. **谯王司马逊去世。** 七月戊戌，谯王司马逊去世。 [[17]](#jin003-u131-2-note)

<a id="jin003-u131-3-event"></a>

18. **七月晦日食。** 七月丙午晦，发生日食。 [[18]](#jin003-u131-3-note)

<a id="jin003-l132-event"></a>

19. **省右将军。** 八月丙辰，撤销右将军一职。 [[19]](#jin003-u132-1-note)

<a id="jin003-u133-1-event"></a>

20. **司马炎坚持父丧礼。** 八月戊辰，有司请求司马炎改服、进膳，他不准。此前父亲下葬后，他虽依汉魏制度除去丧服，仍穿深衣、戴素冠，降低坐席、减撤膳食，保持居丧般的哀敬；一直到丧礼终了才恢复吉服。 [[20]](#jin003-u133-1-note)

<a id="sg-event-2"></a>

21. **吴改元宝鼎、任陆凯万彧为左右丞相。** 八月，各地报发现大鼎，孙皓改元并大赦，以陆凯、万彧分掌左右丞相。孙皓不喜欢臣下抬眼看他。陆凯劝他说，君臣当能辨识彼此，遇突发变故才知道如何护驾，孙皓准许陆凯正视他。 [[21]](#sg-note-2)

<a id="jin003-u133-4-event"></a>
<a id="jin003-l133d-event"></a>

22. **皇甫陶、傅玄谏诤受阻。** 九月乙未，皇甫陶、傅玄领谏官，上书规谏，有司请求压下不行。司马炎指出，臣下谈君主过失本来最难，忠直者历来苦于意见不被听纳；事情交主管后却多严苛处置，还说宽贷须由君主施恩，这并非合理说法，命重新详议。 [[22]](#jin003-u133-4-note)

<a id="jin003-u134-1-event"></a>
<a id="jin003-l134-event"></a>

23. **沿用前代正朔服色。** 九月戊戌，有司奏请沿用前代正朔和服色，援舜承尧位而沿旧制为例；司马炎批准。 [[23]](#jin003-u134-1-note)

<a id="jin003-u135-1-event"></a>
<a id="jin003-l135-event"></a>

24. **十月朔日食。** 十月丙午朔，发生日食。 [[24]](#jin003-u135-1-note)

<a id="jin003-u135-2-event"></a>

25. **停迁陵墓十里内居民。** 十月丁未，司马炎援舜葬苍梧、禹葬成纪而不扰农市的故事，说祖父、父亲主张清简，命停止迁走陵墓十里内居民，以免烦扰。 [[25]](#jin003-u135-2-note)

<a id="sg-event-3"></a>

26. **施但挟孙谦起兵，丁固等破之。** 冬十月，孙皓仍在武昌，施但在永安召集不堪徭命的民众，挟永安侯孙谦往建业，打算拥立他，并取孙和陵上的鼓吹与曲盖。施但先遣使假传孙谦的命令，诸葛靓斩来使。丁固、诸葛靓在牛屯迎击，施但所部败散，孙谦被俘，随后死亡。 [[26]](#sg-note-3)

<a id="jin003-u136-1-event"></a>

27. **倭人献方物。** 十一月己卯，倭人来献地方物产。 [[27]](#jin003-u136-1-note)

<a id="sg-event-7"></a>
<a id="sgz-event-8"></a>

28. **圜丘、方丘祭并入南北郊。** 十一月，晋把圜丘、方丘祭分别并入南郊、北郊，冬至、夏至之祭也相应合并。 [[28]](#sgz-note-8)

<a id="jin003-u136-3-event"></a>

29. **撤山阳公国督军。** 十一月，撤山阳公国督军，解除对该国的相关禁制。 [[29]](#jin003-u136-3-note)

<a id="jin003-u136-4-event"></a>

30. **追尊夏侯氏为景怀皇后。** 十一月己丑，追尊司马师夫人夏侯氏为景怀皇后。 [[30]](#jin003-u136-4-note)

<a id="jin003-u136-5-event"></a>

31. **迁神主入太庙。** 十一月辛卯，将祖、父辈神主迁入太庙。 [[31]](#jin003-u136-5-note)

<a id="jin003-u137-1-event"></a>
<a id="jin003-l137-event"></a>

32. **废农官改郡县。** 十二月，撤屯田农官，将其所辖地区改为郡县。 [[32]](#jin003-u137-1-note)

<a id="jin003-u138-1-event"></a>
<a id="jin003-l138-event"></a>

33. **全年祥瑞报闻。** 本年，各郡国报告凤凰六次、青龙十次、黄龙九次和麒麟一次。 [[33]](#jin003-u138-1-note)

<a id="sg-event-5"></a>
<a id="sgz-event-13"></a>

34. **陆凯在武昌劝孙皓息役，吴还都建业。** 扬州百姓向武昌逆流输送物资，苦于劳费。陆凯上疏说，国库连一年的储粮都没有，征调又使农耕废弛、父子分役，地方监官反添苛扰。他指出武昌地险土瘠，又借童谣说百姓盼还建业，劝孙皓减徭役、宽刑政、裁减宫中人员、选任贤能。十二月，孙皓还都建业，留滕牧镇守武昌。还都后有陆凯等打算趁孙皓谒庙废立的传闻，其中说留平听闻野猪闯入丁奉军营，认为是凶兆。 [[34]](#sg-note-5)

<a id="sg-event-4"></a>
<a id="sgz-event-10"></a>

35. **吴分置东阳、吴兴、邵陵三郡。** 孙皓分吴郡、丹杨九县置吴兴郡，治乌程，设太守，四时奉祀孙和。他本年还分会稽置东阳郡，分零陵北部置邵陵郡。 [[35]](#sg-note-4)

<a id="sgz-event-9"></a>

36. **夏侯佐死无嗣，晋武帝诏择近属继封。** 高安乡侯夏侯佐是夏侯惇的孙子，去世后无嗣。晋武帝念夏侯惇的功劳，下诏选他的近支族人继续其封爵。 [[36]](#sgz-note-9)

<a id="sgz-event-11"></a>

37. **文立任济阴太守。** 文立拜济阴太守。 [[37]](#sgz-note-11)

<a id="sgz-event-12"></a>

38. **曹翕遣世子曹琨奉表，武帝加赏。** 曹琨入朝，晋武帝称曹翕为魏宗之良，给曹琨世子印绶，加骑都尉，赐服、钱并令按才任用。 [[38]](#sgz-note-12)

> 寶鼎元年正月，遣大鴻臚張儼、五官中郎將丁忠弔祭晉文帝。及還，儼道病死。

**吴遣张俨、丁忠吊祭，张俨归途卒** 大鸿胪张俨和五官中郎将丁忠到晋吊祭司马昭。张俨在归途中病死。

**归年依据** 本传正月；实改元宝鼎在八月。

<a id="sgz048-p-020-1"></a>

**[《三國志·三嗣主傳》 裴注 020·1](../../拆分史书/三国志/卷048.md#pei-020-1)** · [TXT L85](../../拆分史书/三国志/卷048.txt#L85)

> 吳錄曰：儼字子節，吳人也。弱冠知名，歷顯位，以博聞多識，拜大鴻臚。使于晉，皓謂儼曰：「今南北通好，以君爲有出境之才，故相屈行。」對曰：「皇皇者華，蒙其榮耀，無古人延譽之美，磨厲鋒鍔，思不辱命。」旣至，車騎將軍賈充、尚書令裴秀、侍中荀勗等欲傲以所不知而不能屈。尚書僕射羊祜、尚書何楨並結縞帶之好。

**释读** 张俨受孙皓派遣赴晋，说将努力不辱使命。到晋后，贾充、裴秀等试图用难题压倒他而不能，羊祜、何桢与他交好。
**归年** 本传当年吊晋文帝；早年历位为同注回顾。

> 忠說皓曰：「北方守戰之具不設，弋陽可襲而取。」皓訪羣臣，鎮西大將軍陸凱曰：「夫兵不得已而用之耳，且三國鼎立已來，更相侵伐，無歲寧居。今彊敵新并巴蜀，有兼土之實，而遣使求親，欲息兵役，不可謂其求援於我。今敵形勢方彊，而欲徼幸求勝，未見其利也。」

**丁忠劝袭弋阳，陆凯反对** 丁忠称晋防备不足。陆凯说晋新并巴蜀、势强，此时使者求亲意在息兵，袭取无利。

**归年依据** 接同年使节返回。

<a id="sgz048-b-2360-3"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2360-3)** · [TXT L86](../../拆分史书/三国志/卷048.txt#L86)

> 車騎將軍劉纂曰：「天生五才，誰能去兵？譎詐相雄，有自來矣。若其有闕，庸可棄乎？宜遣閒諜，以觀其勢。」皓陰納纂言，且以蜀新平，故不行，然遂自絕。

**刘纂建议侦察，孙皓未发兵而断往来** 刘纂赞成先查晋方虚实。孙皓暗认同，却因蜀新平没有发兵，自此与晋断交。

**归年依据** 本传宝鼎元年吴晋使节事后；和丁忠议同一新条。

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l25-10)** · [TXT L25](../../拆分史书/三国志/卷061.txt#L25)

> 孫皓與晉平，使者丁忠自北還，說皓弋陽可襲，凱諫止，語在皓傳。

**釋讀** 吳晉議和，出使晉國的丁忠回來後勸孫皓偷襲弋陽，陸凱進諫阻止。詳情見孫皓本傳。

**歸年** 〈孫皓傳〉記266年正月張儼、丁忠出使、接敘丁忠回奏，《通鑑》卷079同繫泰始二年。

> 三月戊戌，吳人來弔祭，有司奏爲答詔。帝曰：「昔漢文、光武懷撫尉他、公孫述，皆未正君臣之儀，所以羈縻未賓也。皓遣使之始，未知國慶，但以書答之。」

### 7. 孙皓杀散骑常侍王蕃

[返回正文第7条](#sg-event-6)

<a id="wu065-l7-2"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l7-2)** · [TXT L7](../../拆分史书/三国志/卷065.txt#L7)

> 彧與皓有舊，俗王挾侵，謂蕃自輕。又中書丞陳聲，皓之嬖臣，數譖毀蕃。蕃體氣高亮，不能承顏順指，時或迕意，積以見責。

**釋讀** 萬彧與孫皓有舊，認為王蕃輕慢自己。孫皓的寵臣中書丞陳聲也屢次進讒。王蕃性情高潔剛直，不能逢迎順旨，屢次頂撞孫皓，遂逐漸遭到責罰。

**歸年** 這些衝突發生於孫皓初立後至王蕃遇害前，各次無年月。《通鑑》卷079[繫入遇害前情](../../史书/025-资治通鉴/KR2b0007_079.txt#L100-L104)。定本作「俗王挾侵」，[倉內舊本](../../史书/004-三国志/三国志-CCDH.txt#L3036)作「俗士挾侵」，引文照錄。

<a id="sg065-l3037-e6"></a>

<a id="sgz065-b-3037-1"></a>

<a id="wu065-l9-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l9-1)** · [TXT L9](../../拆分史书/三国志/卷065.txt#L9)

> 甘露二年，丁忠使晉還，皓大會羣臣，蕃沈醉頓伏，皓疑而不恱，轝蕃出外。頃之請還，酒亦不解。蕃性有威嚴，行止自若，皓大怒，呵左右於殿下斬之。衞將軍滕牧、征西將軍留平請，不能得。

**釋讀** 甘露二年，丁忠從晉返回。孫皓宴請群臣，王蕃沉醉伏倒。孫皓生疑，使人把他抬出去，片刻後又召回。王蕃仍然醉著，但平素威嚴，舉止如常。孫皓大怒，喝令侍從在殿下殺他。衛將軍滕牧、征西將軍留平請求寬免，未能挽救。

**歸年** 甘露二年為266年，《孫皓傳》用該年八月所改的年號「寶鼎元年」追書正月派使，《通鑑》卷079置於泰始二年春三月赴晉報弔後，裴注也明言丁忠春日返吳。兩書所記出遣和到晉月份可並讀。

<a id="sgz065-p-001-1"></a>

<a id="wu065-l10-1"></a>

**[《三國志·王樓賀韋華傳》裴注 001](../../拆分史书/三国志/卷065.md#edition-wu065-l10-1)** · [TXT L10](../../拆分史书/三国志/卷065.txt#L10)

> 江表傳曰：皓用巫史之言，謂建業宮不利，乃西巡武昌，仍有遷都之意，恐羣臣不從，乃大請會，賜將吏。問蕃「射不主皮，爲力不同科，其義云何」？蕃思惟未荅，即於殿上斬蕃。出登來山，使親近將跳蕃首，作虎跳狼爭咋齧之，頭皆碎壞，欲以示威，使衆不敢犯也。此與本傳不同。

**釋讀** 《江表傳》說孫皓相信巫史所言，認為建業宮不吉，西巡武昌並想遷都，恐群臣反對，便召集將吏賜宴。孫皓問王蕃，射禮何以不以射穿箭靶為準，射者氣力不同是什麼意思。王蕃思索尚未作答，孫皓便斬他。又登來山，命親近人投擲王蕃首級，模仿虎躍狼爭啃咬，將其毀壞以示威。裴注指出此說與本傳不同。

**歸年** 同一王蕃死事。會上問射禮與醉伏是互異記法；《通鑑》卷079採醉伏說，又收來山毀首事。卷048明載265年九月徙武昌、266年冬還建業，不能據《江表傳》的敘事把王蕃之死移到265年。

<a id="wu065-l10-2"></a>

**[《三國志·王樓賀韋華傳》裴注 001](../../拆分史书/三国志/卷065.md#edition-wu065-l10-2)** · [TXT L10](../../拆分史书/三国志/卷065.txt#L10)

> 　吳錄曰：皓每於會，因酒酣，輒令侍臣嘲謔公卿，以爲笑樂。萬彧旣爲左丞相，蕃嘲彧曰：「魚潛於淵，出水煦沫。何則？物有本性，不可橫處非分也。彧出自谿谷，羊質虎皮，虛受光赫之寵，跨越三九之位，犬馬猶能識養，將何以報厚施乎！」彧曰：「唐虞之朝無謬舉之才，造父之門無駑蹇之質，蕃上誣明選，下訕楨幹，何傷於日月，適多見其不知量耳。」

**釋讀** 《吳錄》說孫皓宴會酒酣時，常令侍臣嘲弄公卿取樂。它稱萬彧任左相後，王蕃以魚離淵、羊披虎皮為喻，譏萬彧才位不相稱，又追問他如何報答孫皓的大恩。萬彧自稱明主不會錯用人才，好御者手下沒有劣馬，回斥王蕃誣蔑君王選用賢才、嘲弄國家棟樑，只看出王蕃自不量力。

**歸年** 裴松之引此與本傳對照。此說所載萬彧先拜相與王蕃春日死事不合，且卷048稱萬彧為右丞相。將全文附在266年王蕃遇害條作辨異，不能據此推定另有一次或某月的爭辯。

<a id="wu065-l10-3"></a>

**[《三國志·王樓賀韋華傳》裴注 001](../../拆分史书/三国志/卷065.md#edition-wu065-l10-3)** · [TXT L10](../../拆分史书/三国志/卷065.txt#L10)

> 　臣松之按本傳云丁忠使晉還，皓爲大會，於會中殺蕃，檢忠從北還在此年之春，彧時尚未爲丞相，至秋乃爲相耳。吳錄所言爲乖互不同。

**釋讀** 裴松之核對本傳與丁忠使事，指出丁忠由北返吳在此年春天，孫皓在迎宴殺王蕃；萬彧那時還不是丞相，到秋才受命，《吳錄》的說法因而有衝突。

**歸年** 卷048[八月改元及拜相](../../拆分史书/三国志/卷048.txt#L86)及同年[改元拜相條](ce-0266.md#sg-note-2)證萬彧受任晚於春宴。

<a id="wu065-l12-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l12-1)** · [TXT L12](../../拆分史书/三国志/卷065.txt#L12)

> 丞相陸凱上疏曰：「常侍王蕃黃中通理，知天知物，處朝忠蹇，斯社稷之重鎮，大吳之龍逢也。昔事景皇，納言左右，景皇欽嘉，歎爲異倫。而陛下忿其苦辭，惡其直對，梟之殿堂，尸骸暴棄，邦內傷心，有識悲悼。」其痛蕃如此。

**釋讀** 陸凱痛惜王蕃，奏稱他通曉事理與天人之變，居朝忠直，是國家重臣，可比夏桀時直諫的關龍逢。王蕃從前侍奉景皇孫休，參議政事，深得賞識。陸凱指孫皓厭惡王蕃直言，殺於殿廷，又棄其遺體，使國人和有識者痛惜。

**歸年** 疏中追論266年王蕃被殺，隨所論事件合讀。陸凱266年秋拜相，269年卒；同疏名義或為傳文追稱，具體奏進年月未明。卷061裴注《吳錄》二十事疏有措辭相近的一節，陳壽對該長疏是否送出存疑。

**釋讀** 王蕃死時三十九歲，孫皓把他的家屬徙往廣州。

> 皓時徙都武昌，揚土百姓泝流供給，以爲患苦，又政事多謬，黎元窮匱。凱上疏曰：
>
> 臣聞有道之君，以樂樂民；無道之君，以樂樂身。樂民者，其樂弥長；樂身者，不乆而亡。夫民者，國之根也，誠宜重其食，愛其命。民安則君安，民樂則君樂。自頃年以來，君威傷於桀紂，君明闇於姦雄，君惠閉於羣孽。無災而民命盡，無爲而國財空，辜無罪，賞無功，使君有謬誤之愆，天爲作妖。而諸公卿媚上以求愛，困民以求饒，導君於不義，敗政於淫俗，臣竊爲痛心。今鄰國交好，四邊無事，當務息役養士，實其廩庫，以待天時。而更傾動天心，搔擾萬姓，使民不安，大小呼嗟，此非保國養民之術也。
>
> 臣聞吉凶在天，猶影之在形，響之在聲也，形動則影動，形止則影止，此分數乃有所繫，非在口之所進退也。昔秦所以亡天下者，但坐賞輕而罰重，政刑錯亂，民力盡於奢侈，目眩於美色，志濁於財寶，邪臣在位，賢哲隱藏，百姓業業，天下苦之，是以遂有覆巢破卵之憂。漢所以彊者，躬行誠信，聽諫納賢，惠及負薪，躬請巖穴，廣采博察，以成其謀。此往事之明證也。
>
> 近者漢之衰末，三家鼎立，曹失綱紀，晉有其政。又益州危險，兵多精彊，閉門固守，可保萬世，而劉氏與奪乖錯，賞罰失所，君恣意於奢侈，民力竭於不急，是以爲晉所伐，君臣見虜。此目前之明驗也。
>
> 臣闇於大理，文不及義，智慧淺劣，無復兾望，竊爲陛下惜天下耳。臣謹奏耳目所聞見，百姓所爲煩苛，刑政所爲錯亂，願陛下息大功，損百役，務寬盪，忽苛政。
>
> 又武昌土地，實危險而塉确，非王都安國養民之處，船泊則沈漂，陵居則峻危，且童謠言：「寧飲建業水，不食武昌魚；寧還建業死，不止武昌居。」臣聞翼星爲變，熒惑作妖，童謠之言，生於天心，乃以安居而比死，足明天意，知民所苦也。
>
> 臣聞國無三年之儲，謂之非國，而今無一年之畜，此臣下之責也。而諸公卿位處人上，祿延子孫，曾無致命之節，匡救之術，苟進小利於君，以求容媚，荼毒百姓，不爲君計也。自從孫弘造義兵以來，耕種旣廢，所在無復輸入，而分一家父子異役，廩食日張，畜積日耗，民有離散之怨，國有露根之漸，而莫之恤也。民力困窮，鬻賣兒子，調賦相仍，日以疲極，所在長吏，不加隱括，加有監官，旣不愛民，務行威勢，所在搔擾，更爲煩苛，民苦二端，財力再耗，此爲無益而有損也。願陛下一息此輩，矜哀孤弱，以鎮撫百姓之心。此猶魚龞得免毒螫之淵，鳥獸得離羅網之綱，四方之民繈負而至矣。如此，民可得保，先王之國存焉。
>
> 臣聞五音令人耳不聦，五色令人目不明，此無益於政，有損於事者也。自昔先帝時，後宮列女，及諸織絡，數不滿百，米有畜積，貨財有餘。先帝崩後，幼、景在位，更改奢侈，不蹈先迹。伏聞織絡及諸徒坐，乃有千數，計其所長，不足爲國財，然坐食官廩，歲歲相承，此爲無益，願陛下料出賦嫁，給與無妻者。如此，上應天心，下合地意，天下幸甚。
>
> 臣聞殷湯取士於商賈，齊桓取士於車轅，周武取士於負薪，大漢取士於奴僕。明王聖主取士以賢，不拘卑賤，故其功德洋溢，名流竹素，非求顏色而取好服、捷口、容恱者也。臣伏見當今內寵之臣，位非其人，任非其量，不能輔國匡時，羣黨相扶，害忠隱賢。願陛下簡文武之臣，各勤其官，州牧督將，藩鎮方外，公卿尚書，務脩仁化，上助陛下，下拯黎民，各盡其忠，拾遺萬一，則康哉之歌作，刑錯之理清。願陛下留神思臣愚言。

**釋讀** 孫皓遷都武昌後，揚州百姓要逆流運送物資，深以為苦。朝政又多失當，百姓窮困，陸凱因而上疏。

**歸年** 〈武昌上疏〉同一奏疏。《孫皓傳》記265年遷都武昌，266年底還建業；《通鑑》卷079將此疏繫266年八月拜相後。

**釋讀** 陸凱說施政有道的君主以百姓的快樂為樂，只取悅自己終將敗亡。百姓是國本，衣食和生命有保障，君國才得安樂。近年刑賞失當，公卿逢迎取寵，盤剝百姓求自身富足，陸凱深感痛心。既然鄰國通好、四境無事，宜停徭役、養士、充實倉庫、等待時機。

**釋讀** 陸凱比天道吉凶如影隨形、回聲應聲，皆有原因，難靠言語改變。秦因賞輕罰重、政刑失序、奢侈美色耗盡民力，邪臣得位而賢者退隱，致天下苦而亡。漢以誠信施政、納諫求賢、施惠百姓，連隱居之士也親自訪求，所以能強盛。

**歸年** 〈武昌上疏〉同一奏疏。《孫皓傳》記265年遷都武昌，266年底還建業；《通鑑》卷079將此疏繫266年八月拜相後。秦漢舊事為疏中引論。

**釋讀** 陸凱說漢末三國鼎立，曹氏失去綱紀而政權歸晉。蜀據險有精兵，本可固守，卻因封賞刑罰不當、君主奢侈、民力耗於不急之事而亡，君臣被俘。

**歸年** 〈武昌上疏〉同一奏疏。《孫皓傳》記265年遷都武昌，266年底還建業；《通鑑》卷079將此疏繫266年八月拜相後。疏稱蜀「爲晉所伐」，是從後來政權歸晉立論，實際出兵滅蜀時仍為曹魏（263），司馬炎在265年受魏禪。

**釋讀** 陸凱自陳才智有限，無所求望，只是替孫皓惋惜天下。他列舉親見的苛擾、刑政失當，祈請停大工程、減徭役、務求寬政。

**釋讀** 陸凱說武昌地勢險、土地瘠薄，船停泊容易沉漂，在高處營居又有險阻。民謠說寧喝建業水也不吃武昌魚，寧回建業死也不留在武昌住。陸凱以翼星、熒惑的變化和童謠，一起證明自己所見的百姓疾苦。

**歸年** 〈武昌上疏〉同一奏疏。《孫皓傳》記265年遷都武昌，266年底還建業；《通鑑》卷079將此疏繫266年八月拜相後。《通鑑》卷079亦錄此童謠，未另載作成時間。

**釋讀** 陸凱說糧儲本應足用三年，如今不足一年，公卿世受祿位卻不救時，反以小利取悅君主、荼毒百姓。疏以「孫弘造義兵」為起點，說從那以後耕種荒廢，父子調服異役，供糧日增而積儲日減，民間甚至賣兒，官吏不加存恤，監官更仗勢加重負擔。他勸罷擾民之官、憐惜孤弱，百姓才會攜家而來、國家才可保全。

**歸年** 〈武昌上疏〉同一奏疏。《孫皓傳》記265年遷都武昌，266年底還建業；《通鑑》卷079將此疏繫266年八月拜相後。「孫弘造義兵」依底本文字保留，未能據疏另定所指與起兵年月。

**釋讀** 陸凱以聲色有損政事起論，說孫權時宮女及織作人員不到百人，糧財有結餘。孫亮、孫休以後日漸奢侈，織作等人數千，所產不足補耗費。宜選擇宮人出嫁，配與無妻者。

**歸年** 〈武昌上疏〉同一奏疏。《孫皓傳》記265年遷都武昌，266年底還建業；《通鑑》卷079將此疏繫266年八月拜相後。孫權、孫亮、孫休在位時的後宮情況是疏中追敘。

**釋讀** 陸凱說商湯、齊桓公、周武王及漢用人不問卑賤。當今內寵不稱職，結黨害忠而埋沒賢才，宜選文武使各盡職，州牧督將守外、尚書公卿助君惠民，令政事清明。

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l55-1)** · [TXT L55](../../拆分史书/三国志/卷061.txt#L55)

> 或曰寶鼎元年十二月，凱與大司馬丁奉、御史大夫丁固謀，因皓謁廟，欲廢皓立孫休子。時左將軍留平領兵先驅，故密語平，平拒而不許，誓以不泄，是以所圖不果。太史郎陳苗奏皓乆陰不雨，風氣迴逆，將有陰謀，皓深警懼云。

**釋讀** 一說266年十二月陸凱、丁奉、丁固擬趁孫皓謁廟廢他、立孫休之子。當時留平先率兵，便向他透露。留平拒絕但誓不外泄，計議遂未成。太史郎陳苗以久陰不雨、風氣回逆奏稱有陰謀，孫皓大為警惕。

**歸年與互校** 「或曰」一說明繫寶鼎元年十二月。《晉書》卷二十九〈五行志〉同繫該月，記太史奏久陰不雨與留平拒絕。《資治通鑑》卷七十九《考異》認為留平若知密謀恐會泄露，又質疑陸凱會參與廢立，故不採。

<a id="wu061-l56-1"></a>

**[《三國志·潘濬陸凱傳》裴注 007](../../拆分史书/三国志/卷061.md#edition-wu061-l56-1)** · [TXT L56](../../拆分史书/三国志/卷061.txt#L56)

> 吳錄曰：舊拜廟，選兼大將軍領三千兵爲衞，凱欲因此兵圖之，令選曹白用丁奉。皓偶不欲，曰：「更選。」凱令執據，雖蹔兼，然宜得其人。皓曰：「用留平。」凱令其子禕謀語平。平素與丁奉有隙，禕未及得宣凱旨，平語禕曰：「聞野豬入丁奉營，此凶徵也。」有喜色。禕乃不敢言，還，因具啟凱，故輟止。

**釋讀** 吳主謁廟舊例臨時選大將領三千人護衛。按《吳錄》所傳，陸凱想借衛兵行事，令選官薦丁奉，孫皓不願。陸凱命選官據理再請，說臨時兼任也得選得其人，孫皓改選留平。陸凱遣陸禕去向留平傳意；留平一向與丁奉不合，陸禕未說來意，他已面露喜色地說野豬進了丁奉營是凶兆。陸禕不敢開口，回來稟告陸凱，於是取消。

**異文** 本傳說留平已知而拒，裴注引《吳錄》則稱陸禕根本未向留平開口。

### 36. 夏侯佐死无嗣，晋武帝诏择近属继封

**《諸夏侯曹傳》互見** [TXT 第16行](../../拆分史书/三国志/卷009.md#edition-wei009-l16-1)

<a id="wei009-l17-1"></a>

**[《三國志·諸夏侯曹傳》裴注](../../拆分史书/三国志/卷009.md#edition-wei009-l17-1)** · [TXT L17](../../拆分史书/三国志/卷009.txt#L17)

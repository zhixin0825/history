[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **右丞相万彧镇守巴丘。** 宝鼎二年春朝廷大赦，万彧出镇巴丘。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓兴营新宫。** 六月开建昭明宫，十二月迁入。夹注述兴作耗费人力甚多及陆凯劝谏。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **吴增设安成郡。** 分豫章、庐陵、长沙一部分置安成郡。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **使守大匠薛珝营立寝堂。** 宝鼎二年七月，使守大匠薛珝营立寝堂，号曰清庙。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **皓更营新宫，制度弘广。** 宝鼎二年，皓更营新宫，制度弘广，饰以珠玉，所费甚多。 [[5]](#sg-note-5)

# 公元267年｜晋泰始三年／吴宝鼎二年

[← 公元266年](ce-0266.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元268年 →](ce-0268.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **右丞相万彧镇守巴丘。** 宝鼎二年春朝廷大赦，万彧出镇巴丘。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓兴营新宫。** 六月开建昭明宫，十二月迁入。夹注述兴作耗费人力甚多及陆凯劝谏。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **吴增设安成郡。** 分豫章、庐陵、长沙一部分置安成郡。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **使守大匠薛珝营立寝堂。** 宝鼎二年七月，使守大匠薛珝营立寝堂，号曰清庙。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **皓更营新宫，制度弘广。** 宝鼎二年，皓更营新宫，制度弘广，饰以珠玉，所费甚多。 [[5]](#sg-note-5)

<a id="sgz-event-6"></a>

6. **张掖太守焦胜据柳谷石纹绘图献晋。** 晋泰始三年，焦胜把张掖石纹所见与郡中旧图对校，详图上献，图案、文字多寡有别。 [[6]](#sgz-note-6)

<a id="sgz-event-7"></a>

7. **罗宪入朝进冠军将军。** 泰始三年冬罗宪入朝，进冠军将军、假节。 [[7]](#sgz-note-7)

<a id="sgz-event-8"></a>

8. **孟仁等到明陵迎孙和神主。** 孟仁、姚信率仪仗前往；孙皓在庭亲拜。灵舆至后祭祀频繁，官员劝以礼节制。 [[8]](#sgz-note-8)

### 6. 张掖太守焦胜据柳谷石纹绘图献晋

[返回正文第6条](#sgz-event-6)

<a id="sgz003-p-020-3"></a>

**[《三国志·明帝纪》裴注 020·3](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-020-3)**

> 至晉泰始三年張掖太守焦勝上言以留郡本國圖校今石文文字多少不同謹具圖上按其文有五馬象其一有人平上幘執㦸而乘之其一有若馬形而不成其字有金有中有大司馬有王有大吉有正有開壽其一成行曰金當取之

**归年** 注文明确泰始三年；《晋书·武帝纪》L142同年四月戊午载焦胜献玄石图。与魏青龙年间的旧传相隔三十余年。

### 8. 孟仁等到明陵迎孙和神主

[返回正文第8条](#sgz-event-8)

<a id="sgz059-b-2829-6"></a>

**[《三国志·吴主五子传》仓内原文 L2829](../../sources/本地分卷/三国志/三国志-卷059.md#l2829)**

> 十二月，遣守丞相孟仁、太常姚信等備官寮中軍步騎二千人，以靈輿法駕，東迎神於明陵。皓引見仁，親拜送於庭。靈輿當至，使丞相陸凱奉三牲祭於近郊，皓於金城外露宿。明日，望拜於東門之外。其翌日，拜廟薦祭，歔欷悲感。比七日三祭，倡技晝夜娛樂。有司奏言「祭不欲數，數則黷，宜以禮斷情」，然後止。

**归年** 同年十二月，《通鉴》卷079有迎神与下拜记事。

<a id="sgz059-p-012-1"></a>

**[《三国志·吴主五子传》裴注 012·1](../../sources/摘录/三国志-卷059-吴主五子传裴注.md#pei-012-1)**

> 吳書曰比仁還中使手詔曰使相繼奉問神靈起居動止巫覡言見和被服顔色如平生日晧悲喜涕淚悉召公卿尚書詣闕門下受賜

**释读** 巫声称见孙和如平生，孙皓悲喜流泪，召百官受赏。

**归年** 宝鼎二年十二月迎神仪仗，接正文祭事。

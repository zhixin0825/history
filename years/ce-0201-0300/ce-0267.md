## 本年概述

晋立司马衷为皇太子，准二千石终丧，议增官俸，调整三公及军职。张掖石纹被奏为祥瑞，年内又有石崩、昼昏等灾异记载。


<a id="jin003-u139-1-event"></a>
<a id="jin003-l139-event"></a>

1. **弘农、渑池白龙汇报。** 正月，弘农、渑池报告白龙两次。 [[1]](#jin003-u139-1-note)

<a id="jin003-u140-1-event"></a>
<a id="jin003-l140-event"></a>

2. **立司马衷为太子而不行例惠。** 正月丁卯，立皇子司马衷为皇太子。司马炎下诏说，自己德薄而居天下之上，常怀敬畏，怕不能安济四海，想与天下共同申明王道、正本清源，所以置嗣立嫡并非原先最急的事务。近世每立太子便赦罪施惠，自己间或不得已，也只是顺从王公卿士的建议。如今天下将平，应以德义和明确的好恶教民，使百姓消除侥幸得赦的念头、始终守正，不取局部恩惠与小仁，命天下知悉。 [[2]](#jin003-u140-1-note)

<a id="jin003-u141-1-event"></a>
<a id="jin003-l141-event"></a>

3. **准二千石终三年丧。** 三月戊寅，开始准许二千石官员居满三年之丧。 [[3]](#jin003-u141-1-note)

<a id="jin003-u141-2-event"></a>

4. **白昼昏暗。** 三月丁未，白昼昏暗。 [[4]](#jin003-u141-2-note)

<a id="jin003-u141-3-event"></a>

5. **撤武卫将军。** 三月，撤销武卫将军一职。 [[5]](#jin003-u141-3-note)

<a id="jin003-u141-4-event"></a>

6. **李憙任太子太傅。** 三月，任李憙为太子太傅。 [[6]](#jin003-u141-4-note)

<a id="jin003-u141-5-event"></a>

7. **太山石崩。** 三月，太山发生石崩。 [[7]](#jin003-u141-5-note)

<a id="sg-event-5"></a>
<a id="sgz-event-6"></a>

8. **焦胜献石纹图。** 四月戊午，张掖太守焦胜报告氐池县大柳谷口有玄石，白纹成字，认为是晋朝祥瑞，与郡中旧图比较，辨其图案、文字多寡，绘图上献。朝廷以礼币告太庙，将图藏于天府。 [[8]](#sgz-note-6)

<a id="sg-event-2"></a>

9. **孙皓营建昭明宫，十二月移居。** 六月，孙皓在建业营建昭明宫，令二千石以下官员入山督办伐木，又拆旧营扩建苑囿、修筑楼观，耗费甚多。陆凯屡谏减轻徭役。华覈指出蜀亡后外援已失，交州与海防告急，盛夏伐木营建又耽误耕作和备粮，请停止宫役、先顾边防。孙皓以旧宫不利为由，继续兴建。十二月，孙皓迁入新宫。 [[9]](#sg-note-2)

<a id="sgz-event-8"></a>
<a id="sg-event-4"></a>

10. **孙皓建清庙，从明陵迎孙和神灵。** 有司奏请在京城为孙和建庙。七月，孙皓命代理大匠薛珝修建寝堂，名为清庙。十二月，他在朝廷亲自拜送守丞相孟仁、太常姚信，两人领官属、中军步骑二千，备法驾赴明陵奉迎。灵舆将至，陆凯奉三牲郊祭，孙皓在金城外露宿，次日在东门外望拜，再次日入庙荐祭。七天内接连三祭，又命乐工昼夜作乐。有司劝他依礼节制，孙皓才停。 [[10]](#sg-note-4)

<a id="jin003-u143-1-event"></a>
<a id="jin003-l143-event"></a>

11. **罢都护将军。** 八月，撤都护将军，把所辖五署交还光禄勋。 [[11]](#jin003-u143-1-note)

<a id="jin003-u144-1-event"></a>

12. **议增官吏俸禄。** 九月甲申，司马炎下诏议增吏俸，说古代按德授爵、按功定禄，下士收入也相当于上等农户，足以奉公养亲；如今在位者俸禄不足代耕，不利教化。又分等赐王公以下帛。 [[12]](#jin003-u144-1-note)

<a id="sgz-event-12"></a>

13. **何曾、司马望、荀顗迁三公。** 九月，以太尉何曾为太保、义阳王司马望为太尉、司空荀顗为司徒。 [[13]](#sgz-note-12)

<a id="jin003-u145-1-event"></a>
<a id="jin003-l145-event"></a>

14. **准士卒奔父母丧。** 十月，准许不在边境作战的士卒在父母去世时赴丧。 [[14]](#jin003-u145-1-note)

<a id="jin003-u146-1-event"></a>
<a id="jin003-l146-event"></a>

15. **孔震改封奉圣亭侯。** 十二月，将宗圣侯孔震改封为奉圣亭侯。 [[15]](#jin003-u146-1-note)

<a id="jin003-u146-2-event"></a>

16. **刘康来朝。** 十二月，山阳公刘康来朝。 [[16]](#jin003-u146-2-note)

<a id="jin003-u146-3-event"></a>

17. **禁星气谶纬之学。** 十二月，禁止星气、谶纬之学。 [[17]](#jin003-u146-3-note)

<a id="sg-event-1"></a>

18. **右丞相万彧镇守巴丘。** 宝鼎二年春朝廷大赦，万彧出镇巴丘。 [[18]](#sg-note-1)

<a id="sg-event-3"></a>

19. **吴增设安成郡。** 分豫章、庐陵、长沙一部分置安成郡。 [[19]](#sg-note-3)

<a id="sgz-event-7"></a>

20. **罗宪入朝进冠军将军。** 泰始三年冬罗宪入朝，进冠军将军、假节。 [[20]](#sgz-note-7)

<a id="sgz-event-9"></a>

21. **晋征李密为太子洗马，李密上《陈情表》请求终养。** 晋武帝立司马衷为太子，征李密为太子洗马，诏书屡下，地方官催他赴任。李密上表，陈述幼年丧父、母亲再嫁，由祖母刘氏抚养成人，祖孙相依为命；祖母已九十六岁、病重无人照料，自己四十四岁，仍有余年效忠朝廷，请先准其奉养祖母至终。武帝称许他的诚恳，准许辞召，又赐奴婢二人，命郡县供给祖母饮食。表文及答诏随本年任命缘起附读，各次催召、上表的日月未载。 [[21]](#sgz-note-9)

<a id="sgz-event-10"></a>

22. **谯周抵洛阳，病中授骑都尉。** 谯周抱病乘车到洛阳，于泰始三年抵达，因病不起，就地授骑都尉；谯周认为无功，辞还封爵未准。 [[22]](#sgz-note-10)

<a id="sgz-event-11"></a>

23. **吴春大赦。** 吴在春季施大赦。 [[23]](#sgz-note-11)

<a id="sgz-event-13"></a>

24. **段灼上疏为邓艾申理。** 段灼追述邓艾守陇右、率将士耕种和攻取巴蜀的经过，认为邓艾战后权授蜀人官职是为安抚新附，可以议处，但不应判为谋反。他请求收葬邓艾、归还田宅，并使孙辈承袭封爵。 [[24]](#sgz-note-13)

> 丁卯，立皇子衷爲皇太子。詔曰：「朕以不德，託於四海之上，兢兢祗畏，懼無以康濟宇內，思與天下式明王度，正本清源，於置胤樹嫡，非所先務。又近世每建太子，寬宥施惠之事，間不獲已，順從王公卿士之議耳。方今世運垂平，將陳之以德義，示之以好惡，使百姓蠲多幸之慮，篤終始之行，曲惠小仁，故無取焉。咸使知聞。」

**释读与归年** 本纪在泰始三年正月；诏书反对立太子便赦罪施惠，不能概括为一概拒立太子。

### 9. 孙皓营建昭明宫，十二月移居

[返回正文第9条](#sg-event-2)

<a id="sg048-l2361-e2"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sg048-l2361-e2)** · [TXT L94](../../拆分史书/三国志/卷048.txt#L94)

> 夏六月，起顯明宮，

**孙皓建昭明宫** 吴夏六月兴建昭明宫，避晋国司马昭之讳称显明。

**归年依据** 本传宝鼎二年夏六月；所附尺寸、施工为注024。

**归年与互校** 该句之后夹入避晋讳「昭明」写成「顯明」及《吴历》《江表传》的材料。TXT 同行正文和夹注分界残缺。

<a id="sgz048-p-024-1"></a>

**[《三國志·三嗣主傳》 裴注 024·1](../../拆分史书/三国志/卷048.md#pei-024-1)** · [TXT L95](../../拆分史书/三国志/卷048.txt#L95)

> 太康三年地記曰：吳有太初宮，方三百丈，權所起也。昭明宮方五百丈，皓所作也。避晉諱，故曰顯明。　吳歷云：顯明在太初之東。

**释读** 太初宫方三百丈，是孙权所建；昭明宫五百丈，是孙皓所建，在太初东，因避晋讳称显明。
**归年** 按所述昭明工程系267，同注引书成于282，旧宫营建不以编地记年为准。

<a id="sgz048-p-024-2"></a>

> 江表傳曰：皓營新宮，二千石以下皆自入山督攝伐木。又破壞諸營，大開園囿，起土山樓觀，窮極伎巧，功役之費以億萬計。陸凱固諫，不從。

**释读** 二千石以下入山督摄伐木，废旧军营以拓园囿，建土山楼观，花费甚多；陆凯力谏无效。

> 初，皓始起宮，凱上表諫，不聽，凱重表曰：「臣聞宮功當起，夙夜反側，是以頻煩上事，往往留中，不見省報，於邑歎息，企想應罷。昨食時，被詔曰：『君所諫，誠是大趣，然未合鄙意，如何？此宮殿不利，宜當避之，乃可以妨勞役，長坐不利宮乎？父之不安，子亦何倚？』臣拜紙詔，伏讀一周，不覺氣結於胷，而涕泣雨集也。臣年已六十九，榮祿已重，於臣過望，復何所兾？所以勤勤數進苦言者，臣伏念大皇帝創基立業，勞苦勤至，白髮生於鬢膚，黃耇被於甲冑。天下始靜，晏駕早崩，自含息之類，能言之倫，無不歔欷，如喪考妣。幼主嗣統，柄在臣下，軍有連征之費，民有彫殘之損。賊臣干政，公家空竭。今彊敵當塗，西州傾覆，孤罷之民，宜當畜養，廣力肆業，以備有虞。且始徙都，屬有軍征，戰士流離，州郡搔擾，而大功復起，徵召四方，斯非保國致治之漸也。臣聞爲人主者，攘災以德，除咎以義。故湯遭大旱，身禱桑林，熒惑守心，宋景退殿，是以旱魃銷亡，妖星移舍。今宮室之不利，但當克己復禮，篤湯、宋之至道，愍黎庶之困苦，何憂宮之不安，災之不銷乎？陛下不務脩德，而務築宮室，若德之不脩，行之不貴，雖殷辛之瑤臺，秦皇之阿房，何止而不喪身覆國，宗廟作墟乎？夫興土功，高臺榭，旣致水旱，民又多疾，其不疑也？爲父長安，使子無倚，此乃子離於父，臣離於陛下之象也。臣子一離，雖念克骨，茅茨不翦，復何益焉？是以大皇帝居于南宮，自謂過於阿房。故先朝大臣，以爲宮室宜厚，備衞非常，大皇帝曰：『逆虜游魂，當愛育百姓，何聊趣於不急？』然臣下懇惻，由不獲已，故裁調近郡，苟副衆心，比當就功，猶豫三年。當此之時，寇鈔懾威，不犯我境，師徒奔北，且西阻岷、漢，南州無事，尚猶沖讓，未肯築宮，況陛下危惻之世，又乏大皇帝之德，可不慮哉？願陛下留意，臣不虛言。」

**釋讀** 孫皓起建宮室，陸凱諫阻未從，於是再上疏說自己夙夜不安，奏書往往留中無回音。孫皓答說諫意雖好，卻不合他的主張，舊宮不吉必須避開，也以父親不安、兒子無依反問。陸凱讀詔後氣結流涕。

**歸年** 《三嗣主傳》於266年還建業後的267年六月記起顯明宮，裴注同引《江表傳》載陸凱堅諫。以同一新宮之議合讀，書中自報年齡與卒年差異見下。

**釋讀** 陸凱自稱六十九歲，所享俸祿已過所望。他因孫權辛勞創業、國勢剛穩便早逝，後又有幼主繼統、權臣擅權及連年征戰，才反覆進諫。蜀亡後強敵當道，吳國百姓疲困，應使人民休養營生、以備緩急；新遷都與用兵已使軍民離散，再發大役有損於安國。

**歸年** 此段承《江表傳》新宮疏。自稱六十九、269年卒年七十二，若按同一歲數法推算，則指266年。卷048明繫267年營宮，並引同書陸凱固諫，故附267年營宮條，保留疏在正式開工前已有奏諫的可能。

**釋讀** 陸凱以商湯禱桑林、宋景公避殿應對熒惑為例，說舊宮不利當修德憫民，不能靠大建宮室消災。殷紂瑤臺、秦皇阿房也沒有保住社稷。高臺樓榭既耗民力，君臣父子離心之後，即使回頭求儉已無益處。

**歸年** 同一營宮疏。歷史典故按此疏所舉的論證合讀。

**釋讀** 孫權住南宮，自認已勝過阿房。大臣希望增建以備守衛，孫權說敵尚在，應先愛養百姓；在群臣懇請下也只從近郡徵調，到動工還猶豫三年。陸凱說當時外患較少尚能克制，孫皓如今更應顧及國勢，請他採納。

**歸年** 同一營宮疏結段。孫權的營建之議屬回顧，這段未指明年月。

> 寶鼎二年，皓更營新宮，制度弘廣，飾以珠玉，所費甚多。是時盛夏興工，農守並廢，覈上疏諫曰：
>
> 臣聞漢文之世，九州晏然，秦民喜去慘毒之苛政，歸劉氏之寬仁，省役約法，與之更始，分王子弟以藩漢室，當此之時，皆以爲泰山之安，無窮之基也。至於賈誼，獨以爲可痛哭及流涕者三，可爲長嘆息者六，乃曰當今之勢何異抱火於積薪之下而寢其上，火未及然而謂之安。其後變亂，皆如其言。臣雖下愚，不識大倫，竊以曩時之事，揆今之勢。
>
> 誼曰復數年閒，諸王方剛，漢之傅相稱疾罷歸，欲以此爲治，雖堯舜不能安。今大敵據九州之地，有太半之衆，習攻戰之餘術，乘戎馬之舊勢，欲與中國爭相吞之計，其猶楚漢勢不兩立，非徒漢之諸王淮南、濟北而已。誼之所欲痛哭，比今爲緩，抱火卧薪之喻，於今而急。大皇帝覽前代之如彼，察今勢之如此，故廣開農桑之業，積不訾之儲，恤民重役，務養戰士，是以大小感恩，各思竭命。期運未至，早棄萬國。自是之後，彊臣專政，上詭天時，下違衆議，亡安存之本，邀一時之利，數興軍旅，傾竭府藏，兵勞民困，無時獲安。今之存者乃創夷之遺衆，哀苦之餘民耳。遂使軍資空匱，倉廩不實，布帛之賜，寒暑不周，重以失業，家戶不贍。而北積穀養民，專心東向，無復他警。蜀爲西藩，土地險固，加承先主統御之術，謂其守御足以長乆，不圖一朝，奄至傾覆。脣亡齒寒，古人所懼。交州諸郡，國之南土，交阯、九真二郡已沒，日南孤危，存亡難保，合浦以北，民皆搖動，因連避役，多有離叛，而備戍減少，威鎮轉輕，常恐呼吸復有變故。昔海虜窺窬東縣，多得離民，地習海行，狃於往年，鈔盜無日，今胷背有嫌，首尾多難，乃國朝之厄會也。誠宜住建立之役，先備豫之計，勉墾殖之業，爲饑乏之救。惟恐農時將過，東作向晚，有事之日，整嚴未辦。若舍此急，盡力功作，卒有風塵不虞之變，當委版築之役，應烽燧之急，驅怨苦之衆，赴白刃之難，此乃大敵所因爲資也。如但固守，曠日持乆，則軍糧必乏，不待接刃，而戰士已困矣。
>
> 昔太戊之時，桑穀生庭，懼而脩德，怪消殷興。熒惑守心，宋以爲災，景公下從瞽史之言，而熒惑退舍，景公延年。夫脩德於身而感異類，言發於口而通神明，臣以愚蔽，誤忝近署，不能翼宣仁澤以感靈祇，仰慙俯愧，無所投處。退伏思惟，熒惑桑穀之異，天示二主，至於他餘錙介之妖，近是門庭小神所爲，驗之天地，無有他變，而徵祥符瑞前後屢臻，明珠旣覿，白雀繼見，萬億之祚，實靈所挺，以九域爲宅，天下爲家，不與編戶之民轉徙同也。又今之宮室，先帝所營，卜土立基，非爲不祥。又楊市土地與宮相接，若大功畢竟，輿駕遷住，門行之神，皆當轉移，猶恐長乆未必勝舊。屢遷不可，留則有嫌，此乃愚臣所以夙夜爲憂灼也。臣省月令，季夏之月，不可以興土功，不可以會諸侯，不可以起兵動衆，舉大事必有大殃。今雖諸侯不會，諸侯之軍與會無異。六月戊己，土行正王，旣不可犯，加又農月，時不可失。昔魯隱公夏城中丘，春秋書之，垂爲後戒。今築宮爲長世之洪基，而犯天地之大禁，襲春秋之所書，廢敬授之上務，臣以愚管，竊所未安。
>
> 又恐所召離民，或有不至，討之則廢役興事，不討則日月滋慢。若悉並到，大衆聚會，希無疾病。且人心安則念善，苦則怨叛。江南精兵，北土所難，欲以十卒當東一人。天下未定，深可憂惜之。如此宮成，死叛五千，則北軍之衆更增五萬，若到萬人，則倍益十萬，病者有死亡之損，叛者傳不善之語，此乃大敵所以歡喜也。今當角力中原，以定彊弱，正於際會，彼益我損，加以勞困，此乃雄夫智士所以深憂。
>
> 臣聞先王治國無三年之儲，曰國非其國，安寧之世戒備如此，況敵彊大而忽農忘畜。今雖頗種殖，閒者大水沈沒，其餘存者當須耘穫，而長吏怖期，上方諸郡，身涉山林，盡力伐材，廢農棄務，士民妻孥羸小，墾殖又薄，若有水旱則永無所獲。州郡見米，當待有事，冗食之衆，仰官供濟。若上下空乏，運漕不供，而北敵犯疆，使周、召更生，良、平復出，不能爲陛下計明矣。臣聞君明者臣忠，主聖者臣直，是以慺慺，昧犯天威，乞垂哀省。

**釋讀** 孫皓大建新宮，飾以珠玉，花費甚多。盛夏興工，妨礙農事和防務，華覈因此上疏。

**歸年** 本傳明記寶鼎二年；[《孫皓傳》](../../拆分史书/三国志/卷048.txt#L94-L96)記六月建顯明宮，裴注記本名昭明，入晉後避諱改名。

**釋讀** 漢文帝免去秦的苛法重役，分封宗室，當時人以為天下穩固。賈誼仍警告形勢如把火種放在柴堆底下，人卻睡在上面，後來事變應驗。華覈要用這段往事衡量吳國當時的局面。

**歸年** 寶鼎二年同一篇諫疏。賈誼及漢文帝事是疏中舉例。

**釋讀** 賈誼所憂是漢內部的諸侯，吳面對的北方政權領地廣、兵熟戰，形勢比漢時更急。孫權曾務農積儲、養兵恤民，後來權臣連年用兵，致民疲儲竭。北方專力向東，蜀已亡，交阯、九真已失，日南危孤，海上鈔掠也威脅東境。當務之急是停止營宮，趕上農時，先備軍糧和邊防。否則有警便須中斷工程，以怨苦之兵出戰，久守也難供糧。

**歸年** 寶鼎二年同一篇諫疏。蜀亡、交州離叛等是奏議回顧的背景，文中各郡情勢是華覈當時所陳。

**釋讀** 華覈先引殷太戊、宋景公因修德消災的故事，主張宮中小異未必是天降大災。舊宮是先帝所卜，新址又接近舊宮，遷徙未必能去災。季夏不宜動土、聚眾，六月又是農月，他以《月令》和《春秋》所記魯隱公夏築中丘作戒。

**歸年** 寶鼎二年同一篇諫疏，其中六月、季夏與當年營宮記載相應。

**釋讀** 逃徭者未必應召，追討會耽誤工程，放任又恐日久鬆弛。大批軍民聚集會生病；賦役過重容易使人逃亡或反叛。華覈按北軍需要十人當東吳一人的說法，推想吳損五千或一萬便等於敵多五萬或十萬，藉此勸孫皓保存人力。

**歸年** 寶鼎二年同一篇諫疏。五千、一萬等數為其推演。

**釋讀** 平時尚要存三年之糧，當下敵強，更應備荒。近日洪水淹沒部分田地，剩下的正須耕作收成；州郡官吏為趕工期率眾伐木，已妨農務。若糧盡、漕運不繼，再遇敵軍入境，即使周公、召公、張良、陳平復生也難以補救。華覈請孫皓容納直言。

**歸年** 寶鼎二年同一篇諫疏結尾，洪水未另記月日。

<a id="sgz045-p-008-6"></a>

原引文分读：[晋武帝读表后准许李密奉养祖母](#shu045-l44-6)。


<a id="shu045-l44-4"></a>

**[《三國志·鄧張宗楊傳》注文](../../拆分史书/三国志/卷045.md#edition-shu045-l44-4)** · [TXT L44](../../拆分史书/三国志/卷045.txt#L44)

**释读** 晋武帝立皇太子后，征召李密担任太子洗马，诏书不止一次下达，郡县催促遣送他赴任。

**归年与互校** [《晋书·武帝纪》](../../史书/005-晋书/晋书-CCDH.txt#L139-L140)明记泰始三年（267）正月丁卯立司马衷为皇太子；[《通鉴》卷七十九](../../史书/025-资治通鉴/KR2b0007_079.txt#L218-L245)在同年载征李密为太子洗马、因祖母老而获准辞命。[《晋书·李密传》](../../史书/005-晋书/晋书-CCDH.txt#L8356)只说泰始初。故依立太子的缘起附267年，累诏催遣的逐次日月未载。

<a id="shu045-l44-5"></a>

**[《三國志·鄧張宗楊傳》注文](../../拆分史书/三国志/卷045.md#edition-shu045-l44-5)** · [TXT L44](../../拆分史书/三国志/卷045.txt#L44)

> **〔裴注〕**
>
> 於是密上書曰：「臣以險舋，夙遭閔凶，生孩六月，慈父見背，行年四歲，舅奪母志。祖母劉，愍臣孤弱，躬見撫養。臣少多疾病，九歲不行，零丁孤苦，至於成立，旣無伯叔，終鮮兄弟，門衰祚薄，晚有兒息。外無朞功彊近之親，內無應門五尺之童，煢煢孑立，形影相弔。而劉早嬰疾病，常在牀蓐，臣侍湯藥，未曾廢離。逮奉聖朝，沐浴清化，前太守臣逵察臣孝廉，後刺史臣榮舉臣秀才，臣以供養無主，辭不赴命。詔書特下，拜臣郎中，尋蒙國恩，除臣洗馬，猥以微賤，當侍東宮，非臣隕首所能上報。臣具表聞，辭不就職。詔書切峻，責臣逋慢，郡縣偪迫，催臣上道，州司臨門，急於星火。臣欲奉詔奔馳，則劉病日篤，苟順私情，則告訴不許，臣之進退，實爲狼狽。伏惟聖朝以孝治天下，凡在故老，猶蒙矜愍，況臣孤苦，特爲尤甚。且臣少仕偽朝，歷職郎署，本圖宦達，不矜名節。今臣亡國賤俘，至微至陋，猥蒙拔擢，寵命優渥，豈敢盤桓，有所希兾？但以劉日薄西山，氣息奄奄，人命危淺，朝不慮夕。臣無祖母，無以至今日，祖母無臣，亦無以終餘年，母孫二人，更相爲命，是以區區不敢廢遠。臣今年四十有四，祖母劉今年九十有六，是臣盡節於陛下之日長，報養劉之日短也。烏鳥私情，願乞終養。臣之辛苦，非徒蜀之人士及二州牧伯所見明知，皇天后土，實所共鑒。願陛下矜愍愚誠，聽臣微志，庶劉僥倖，保卒餘年。臣生當隕首，死當結草，臣不勝犬馬怖懼之情！」

**释读** 李密于是上表说：臣命运艰险，很早就遭遇忧患。出生六个月，父亲便去世；四岁时，舅父使母亲改嫁。祖母刘氏怜悯臣孤单幼弱，亲自抚养。臣小时多病，九岁还不能走路，孤苦伶仃地长大；没有伯叔，也没有兄弟，家门衰微，福分浅薄，很晚才有儿子。外面没有期、功服亲之内能够扶助的近亲，家中没有能应门的小僮，只有孤身和影子相伴。祖母早已疾病缠身，常卧病床，臣侍奉汤药，从未离开。

进入晋朝后，臣蒙受清明教化：前太守逵察举臣为孝廉，后刺史荣举臣为秀才，臣都因祖母无人供养而辞谢。朝廷又特下诏书拜臣郎中，不久再任洗马。以臣这样卑微的人能侍奉东宫，即使牺牲性命也报答不尽。臣上表说明情况，辞不就职，诏书却严厉责备臣逃避怠慢，郡县逼迫臣上路，州吏登门催促，急迫得比流星飞逝还快。臣若遵诏赶赴任所，祖母病情一天天加重；若顺从私情奉养，申诉又不被准许，进退实在两难。

臣想，圣朝以孝治理天下，年高前辈尚蒙怜恤，何况臣这样格外孤苦的人。臣年轻时曾在蜀汉任郎官，本求仕途通达，并不以守节自夸；如今身为亡国之人，卑微低下，仍蒙优厚提拔，怎敢迟疑观望、另有希求！只是祖母如日将落山，气息微弱，生命危急，早晨已不能指望晚上。没有祖母，臣不能长大至今；没有臣，祖母也不能安度余年。祖孙相依为命，因此臣不敢弃养远去。臣今年四十四岁，祖母九十六岁，臣将来尽忠陛下之日还长，而报养祖母的日子已短。臣怀着乌鸟反哺般的私情，请求准许奉养她直到去世。

臣的辛酸处境，不但蜀地人士和两州长官明白，天地也共同鉴察。愿陛下怜悯臣的愚诚，准许这微小心愿，使祖母能够侥幸安度余年。臣活着愿以性命报恩，死后也愿像结草报恩的故事那样报答，谨怀犬马般惶恐的心情上陈。

**归年与互校** 整篇表文接晋立太子后的征召，依[《通鉴》卷七十九](../../史书/025-资治通鉴/KR2b0007_079.txt#L239-L245)系李密辞洗马于267年，随征召附读；[《晋书·李密传》](../../史书/005-晋书/晋书-CCDH.txt#L8356-L8360)也在泰始初征召后载表。上表没有独立日月，表中往事不改系267年；自称四十四岁、祖母九十六岁均照原文，不据此强推本注未载的卒年。“伪朝”“贱俘”为李密上奏晋廷时的自陈措辞。

> 三年，議郎段灼上疏理艾曰：「艾心懷至忠而荷反逆之名，平定巴蜀而受夷滅之誅，臣竊悼之。惜哉，言艾之反也！艾性剛急，輕犯雅俗，不能恊同朋類，故莫肯理之。臣敢言艾不反之狀。昔姜維有斷隴右之志，艾脩治備守，積糓彊兵。值歲凶旱，艾爲區種，身被烏衣，手執耒耜，以率將士。上下相感，莫不盡力。艾持節守邊，所統萬數，而不難僕虜之勞，士民之役，非執節忠勤，孰能若此？故落門、段谷之戰，以少擊多，摧破彊賊。先帝知其可任，委艾廟勝，授以長策。艾受命忘身，束馬縣車，自投死地，勇氣陵雲，士衆乘勢，使劉禪君臣靣縛，叉手屈膝。艾功名以成，當書之竹帛，傳祚萬世。七十老公，反欲何求！艾誠恃養育之恩，心不自疑，矯命承制，權安社稷；雖違常科，有合古義，原心定罪，本在可論。鍾會忌艾威名，搆成其事。忠而受誅，信而見疑，頭縣馬巿，諸子并斬，見之者垂泣，聞之者歎息。陛下龍興，闡弘大度，釋諸嫌忌，受誅之家，不拘叙用。昔秦民憐白起之無罪，吳人傷子胥之寃酷，皆爲立祠。今天下民人爲艾悼心痛恨，亦猶是也。臣以爲艾身首分離，捐棄草土，宜收尸喪，還其田宅。以平蜀之功，紹封其孫，使闔棺定謚，死無餘恨。赦寃魂於黃泉，收信義於後世，葬一人而天下慕其行，埋一魂而天下歸其義，所爲者寡而恱者衆矣。」

**釋讀與歸年** 泰始三年議郎段灼上疏，據鄧艾守隴、段谷戰功及平蜀所為為之申理，請殮葬、還田宅、紹封其孫。全文含守邊與伐蜀回敘；上疏歸267年，與265年詔和273年授鄧朗官有別。

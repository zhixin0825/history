# 公元268年｜晋泰始四年／吴宝鼎三年

<a id="sgz-event-5"></a>

<a id="sg-event-1"></a>

1. **丁固和孟仁分任司徒、司空。** 左右御史大夫丁固、孟仁在二月分别改任司徒与司空。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓出东关，丁奉、诸葛靓进攻合肥。。** 秋，孙皓出东关，遣丁奉与诸葛靓攻合肥，晋将司马骏率军击退。丁奉曾写信给晋将石苞，企图使晋廷疑忌石苞；晋廷也收到王琛的密告，同年征还石苞。 **《武帝纪》补记：** 十一月，本纪称丁奉等出芍陂，司马骏与司马望击走吴军。吴纪却记九月至合肥，司马望传有晋援未至吴军已退之说，胜负用语和月份各依史源。己未，诏王公、卿尹和郡国守相荐举贤良方正、敢直言者。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **刘俊、脩则进攻交阯战败。** 吴军入击交阯，被晋将毛炅击败，刘俊、脩则战死，残军退还合浦。 **《武帝纪》补记：** 冬十月，本纪记吴将施绩进江夏、万郁侵襄阳，晋遣司马望屯龙陂，胡烈击败万郁。又记顾容攻郁林，毛炅击败吴军，杀交州刺史刘俊、将军修则。吴传、陶璜传等所记战场与毛炅任官先后不同，不能把交趾、合浦、郁林混为同地；万郁与万彧也保存异写。 [[3]](#sg-note-3)

<a id="sgz-event-4"></a>

4. **罗宪在华林园荐蜀地士人。** 三月，罗宪随晋武帝宴于华林园。武帝问蜀国大臣子弟和宜任用的前辈，罗宪荐举常忌、杜轸、寿良、陈寿、高轨、吕雅、许国、费恭、诸葛京、陈裕，诸人随后得到任用。 [[4]](#sgz-note-4)

<a id="sgz-event-6"></a>

6. **司马望后任大司马，父司马孚为太宰。** 名位比肩，《赞》谓父子俱居上公为中世所罕见。 [[6]](#sgz-note-6)

<a id="sgz-event-7"></a>

7. **西晋太保王祥去世。** 夏四月戊戌，西晋太保、睢陵公王祥去世。 **《武帝纪》补记：** 四月戊戌，太保、睢陵公王祥去世。己亥，将文明皇后王氏附葬崇阳陵；撤振威、扬威护军，设左、右积弩将军。 [[7]](#sgz-note-7)

<a id="sgz-event-8"></a>

8. **西晋任裴秀为司空。** 正月辛未，西晋任尚书令裴秀为司空。裴秀撰《易》《乐》论，并编绘《禹贡地域图》十八篇。盟会图和有关官制的著述尚未完成。 [[8]](#sgz-note-8)

<a id="jin003-l148-event"></a>

9. **律令完成、亲耕与大赦。** 丙戌，律令完成，分别封爵赐帛；轸宿记有孛星。丁亥，司马炎在籍田亲耕。戊子，下诏反思古代象征性刑罚即可止恶、如今重至族刑仍不能止奸的差距，称先帝怜悯百姓而命群臣修律，自己承业，希望与天下共享清静无为的治理，并欲简法、务农、惠民；春耕开始，亲率王公卿士耕千亩籍田，律令既成颁天下，应宽罪使人自新，故大赦。长吏、郡丞、长史各赐马一匹。 [[9]](#jin003-l148-note)

<a id="jin003-l149-event"></a>

10. **山阳公国官属与中军改制。** 二月庚子，增山阳公国相、郎中令、陵令、杂工宰人，以及鼓吹车马等礼遇；罢中军将军，设北军中候。甲寅，因东海刘俭德行卓著，拜为郎。以羊祜为尚书左仆射，东莞王司马伷为尚书右仆射。 [[10]](#jin003-l149-note)

<a id="jin003-l150-event"></a>

11. **皇太后王氏去世。** 三月戊子，皇太后王氏去世。 [[11]](#jin003-l150-note)

<a id="jin003-l152-event"></a>

12. **命守相三年春巡属县。** 六月丙申朔，下诏令郡国守相每三年春巡属县：会见长吏，察风俗、校礼律度量，问候耆老并亲见百岁者，审录囚徒、平反冤狱，详察政刑得失和百姓疾苦，不分远近如同皇帝亲临。推广父义母慈、兄友弟恭子孝等教化，劝农勉学、重正典，不逐诸家浮末。荐举好学笃道、孝悌忠信、清白有异行者；纠治不孝、不悌、悖礼违法者。以田亩开辟、生计修治、礼教禁令施行为良吏标准，以贫困荒田、盗起狱繁、上下失序为失职；又分别细察公廉直节不求虚名者和贪污谄媚、公事不立而私家日富者。要求扬清激浊、举善弹违，由良守相负责，皇帝总其纲。底本作丙申，与斠注所校甲申本不同。 [[12]](#jin003-l152-note)

<a id="jin003-l153-event"></a>

13. **石崩、星流与侯史光巡行。** 秋七月，太山石崩，群星向西流。戊午，遣侯史光巡行天下；己卯，拜谒崇阳陵。 [[13]](#jin003-l153-note)

<a id="jin003-l154-event"></a>

14. **四州水灾与准言诏命不便。** 九月，青、徐、兖、豫四州大水，伊水洛水泛溢、与黄河连成一片，朝廷开仓赈济。诏令即使是皇帝所欲、已经奏准的事情，只要实际不便，也不可隐瞒实情。 [[14]](#jin003-l154-note)

<a id="jin003-l157-event"></a>

15. **五条诏书、录囚与外使。** 十二月，向郡国颁五条诏：端正自身、勤恤百姓、抚孤寡、重农业根本而息逐末之业、去除私相请托馈赠的“人事”。庚寅，司马炎到听讼观，审录廷尉、洛阳狱囚，亲自裁决。扶南、林邑各遣使献方物。 [[15]](#jin003-l157-note)

**[《三國志·霍王向張楊費傳》裴注](../../拆分史书/三国志/卷041.md#edition-shu041-l8-17)** · [TXT L8](../../拆分史书/三国志/卷041.txt#L8)

> **〔裴注〕**

> 四年三月，從帝宴于華林園，詔問蜀大臣子弟，後問先輩宜時叙用者，憲薦蜀郡常忌、杜軫、壽良、巴西陳壽、南郡高軌、南陽呂雅、許國、江夏費恭、琅邪諸葛京、汝南陳裕，即皆叙用，咸顯於世。

> 六月丙申朔，詔曰：「郡國守相，三載一巡行屬縣，必以春，此古者所以述職宣風展義也。見長吏，觀風俗，協禮律，考度量，存問耆老，親見百年。錄囚徒，理冤枉，詳察政刑得失，知百姓所患苦。無有遠近，便若朕親臨之。敦喻五教，勸務農功，勉勵學者，思勤正典，無爲百家庸末，致遠必泥。士庶有好學篤道，孝弟忠信，清白異行者，舉而進之；有不孝敬於父母，不長悌於族黨，悖禮棄常，不率法令者，糾而罪之。田疇闢，生業修，禮教設，禁令行，則長吏之能也。人窮匱，農事荒，姦盜起，刑獄煩，下陵上替，禮義不興，斯長吏之否也。若長吏在官公廉，慮不及私，正色直節，不飾名譽者，及身行貪穢，諂黷求容，公節不立，而私門日富者，並謹察之。揚清激濁，舉善彈違，此朕所以垂拱總綱，責成於良二千石也。於戲戒哉！」

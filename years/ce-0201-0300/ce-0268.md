# 公元268年｜晋泰始四年／吴宝鼎三年

[← 公元267年](ce-0267.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元269年 →](ce-0269.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sgz-event-5"></a>

<a id="sg-event-1"></a>

1. **丁固和孟仁分任司徒、司空。** 左右御史大夫丁固、孟仁在二月分别改任司徒与司空。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓出东关、丁奉至合肥。** 九月孙皓出东关，丁奉到合肥。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **刘俊、脩则进攻交阯战败。** 吴军入击交阯，被晋将毛炅击败，刘俊、脩则战死，残军退还合浦。 [[3]](#sg-note-3)

<a id="sgz-event-4"></a>

4. **罗宪在华林园荐蜀地士人。** 随晋武帝宴华林园，武帝问蜀国大臣子弟和宜任用的人，罗宪荐举常忌、杜轸、寿良、陈寿等人，后来皆获任用。 [[4]](#sgz-note-4)

<a id="sgz-event-6"></a>

6. **司马望后任大司马，父司马孚为太宰。** 名位比肩，《赞》谓父子俱居上公为中世所罕见。 [[6]](#sgz-note-6)

<a id="sgz-event-7"></a>

7. **西晋太保王祥去世。** 王祥在晋初去世。 [[7]](#sgz-note-7)

<a id="sgz-event-8"></a>

8. **西晋任裴秀为司空。** 撰《易》《乐》论及十八篇地域图，其他修志尚未完。 [[8]](#sgz-note-8)

### 1. 丁固和孟仁分任司徒、司空

[返回正文第1条](#sg-event-1)

<a id="sgz048-b-2362-1"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sgz048-b-2362-1)** · [TXT L98](../../sources/本地分卷/三国志/三国志-卷048.txt#L98)

> 三年春二月，以左右御史大夫丁固、孟仁爲司徒、司空。

**丁固孟仁任司徒司空** 左、右御史大夫丁固和孟仁分任司徒、司空。

**归年依据** 本传宝鼎三年二月。

<a id="period-sgz048-p-025-1"></a>

**[《三國志·三嗣主傳》 裴注 025·1](../../sources/本地分卷/三国志/三国志-卷048.md#pei-025-1)** · [TXT L99](../../sources/本地分卷/三国志/三国志-卷048.txt#L99)

> 吳書曰：初，固爲尚書，夢松樹生其腹上，謂人曰：「松字十八公也，後十八歲，吾其爲公乎！」卒如夢焉。

**釋讀** 丁固做尚书时梦腹上生松，以拆字推十八年后任三公。

**附敘** 《吳書》在丁固任司徒處回敘其夢松故事，傳文未直接記夢年。

<a id="sg048-l2362-e1"></a>

見[本卷引文](ce-0268.md#sgz048-b-2362-1)。

<a id="sgz057-p-011-6"></a>

**[《三国志·虞陆张骆陆吾朱传》裴注 011·6](../../sources/本地分卷/三国志/三国志-卷057.md#pei-011-6)**

> 孫晧即位遷司徒

**释读** 《会稽典录》把丁固迁司徒接在孙皓即位后。

**归年** 《孙皓传》明记268年二月丁固、孟仁分任司徒、司空。裴注用“即位”串叙，不能据以定在264。

### 2. 孙皓出东关、丁奉至合肥

[返回正文第2条](#sg-event-2)

<a id="sg048-l2362-e2"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sg048-l2362-e2)** · [TXT L100](../../sources/本地分卷/三国志/三国志-卷048.txt#L100)

> 秋九月，皓出東關，丁奉至合肥。

**孙皓出东关，丁奉赴合肥** 孙皓九月出东关，丁奉至合肥。

**归年依据** 本传宝鼎三年九月。

<a id="sg055-l2673-e2"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》](../../sources/本地分卷/三国志/三国志-卷055.md#p011)** · [仓内TXT L2673](../../sources/本地分卷/三国志/三国志-卷055.md#l2673)

> 寶鼎三年，皓命奉與諸葛靚攻合肥。

<a id="sgz055-b-2673-2"></a>

**[《三国志·程黄韩蒋周陈董甘凌徐潘丁传》仓内原文 L2673](../../sources/本地分卷/三国志/三国志-卷055.md#l2673)**

> 寶鼎三年，皓命奉與諸葛靚攻合肥。奉與晉大將石苞書，搆而間之，苞以徵還。

**释读** 孙皓命丁奉和诸葛靓进攻合肥，丁奉致书离间石苞，其后石苞被征还。

**归年** 《通鉴》卷079考异认为石苞免官在268，依据《三十国春秋》《晋春秋》。《晋书》本传不明月日，丁奉传记为离间得逞，晋方另记王琛告发。

<a id="sg-note-3"></a>

### 3. 刘俊、脩则进攻交阯战败

[返回正文第3条](#sg-event-3)

<a id="sg048-l2362-e3"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sg048-l2362-e3)** · [TXT L100](../../sources/本地分卷/三国志/三国志-卷048.txt#L100)

> 是歲，遣交州刺史劉俊、前部督脩則等入擊交阯，爲晉將毛炅等所破，皆死，兵散還合浦。

**刘俊、脩则攻交阯，败死** 吴军被晋将毛炅等击破，领兵的刘俊、脩则死，部众逃回合浦。

**归年依据** 本传宝鼎三年；《晋书·陶璜传》记败于古城。

<a id="sgz048-p-027-4"></a>

**[《三國志·三嗣主傳》 裴注 027·4](../../sources/本地分卷/三国志/三国志-卷048.md#pei-027-4)** · [TXT L109](../../sources/本地分卷/三国志/三国志-卷048.txt#L109)

> 初，毛炅與吳軍戰，殺前部督脩則。

**释读** 《华阳国志》追述早前毛炅战杀脩则。
**归年** 本传宝鼎三年《晋书·陶璜传》同役。下句吴方处置毛炅已入271。

<a id="sgz041-p-001-13"></a>

**[《三国志·霍王向张杨费传》裴注 001·13](../../sources/本地分卷/三国志/三国志-卷041.md#pei-001-13)**

> 四年三月從帝宴于華林園詔問蜀大臣子弟後問先軰宜時叙用者憲薦蜀郡常忌杜軫壽良巴西陳夀南郡髙軌高陽吕雅許國江夏費恭琅琊諸葛京汝南陳裕即皆叙用咸顯於世

### 6. 司马望后任大司马，父司马孚为太宰

[返回正文第6条](#sgz-event-6)

<a id="sgz015-p-006-5"></a>

**[《三国志·刘司马梁张温贾传》裴注 006·5](../../sources/本地分卷/三国志/三国志-卷015.md#pei-006-5)**

<a id="sgz-note-7"></a>

### 7. 西晋太保王祥去世

[返回正文第7条](#sgz-event-7)

**异文与补证** 王隐《晋书》记王祥卒于泰始四年，年八十九。《晋书·武帝纪》系于泰始四年，《王祥传》系于泰始五年。

<a id="sgz018-p-012-7"></a>

**[《三国志·二李臧文吕许典二庞阎传》裴注 012·7](../../sources/本地分卷/三国志/三国志-卷018.md#pei-012-7)**

> 泰始四年年八十九薨

**归年** 《晋书·武帝纪》同系泰始四年（268）四月戊戌，《王祥传》却作泰始五年（269）；该本传亦承王太后崩后逾月，太后崩见《武帝纪》268。

### 8. 西晋任裴秀为司空

[返回正文第8条](#sgz-event-8)

<a id="sgz023-p-019-6"></a>

**[《三国志·和常杨杜赵裴传》裴注 019·6](../../sources/本地分卷/三国志/三国志-卷023.md#pei-019-6)**

# 公元268年｜晋泰始四年／吴宝鼎三年

[← 公元267年](ce-0267.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元269年 →](ce-0269.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sgz-event-5"></a>

<a id="sg-event-1"></a>

1. **丁固和孟仁分任司徒、司空。** 左右御史大夫丁固、孟仁在二月分别改任司徒与司空。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓出东关，丁奉、诸葛靓进攻合肥。。** 秋，孙皓出东关，遣丁奉与诸葛靓攻合肥，晋将司马骏率军击退。丁奉曾写信给晋将石苞，企图使晋廷疑忌石苞；晋廷也收到王琛的密告，同年征还石苞。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **刘俊、脩则进攻交阯战败。** 吴军入击交阯，被晋将毛炅击败，刘俊、脩则战死，残军退还合浦。 [[3]](#sg-note-3)

<a id="sgz-event-4"></a>

4. **罗宪在华林园荐蜀地士人。** 随晋武帝宴华林园，武帝问蜀国大臣子弟和宜任用的人，罗宪荐举常忌、杜轸、寿良、陈寿等人，后来皆获任用。 [[4]](#sgz-note-4)

<a id="sgz-event-6"></a>

6. **司马望后任大司马，父司马孚为太宰。** 名位比肩，《赞》谓父子俱居上公为中世所罕见。 [[6]](#sgz-note-6)

<a id="sgz-event-7"></a>

7. **西晋太保王祥去世。** 夏四月戊戌，西晋太保、睢陵公王祥去世。 [[7]](#sgz-note-7)

<a id="sgz-event-8"></a>

8. **西晋任裴秀为司空。** 正月辛未，西晋任尚书令裴秀为司空。裴秀撰《易》《乐》论，并编绘《禹贡地域图》十八篇。盟会图和有关官制的著述尚未完成。 [[8]](#sgz-note-8)

### 1. 丁固和孟仁分任司徒、司空

[返回正文第1条](#sg-event-1)

<a id="sgz048-b-2362-1"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2362-1)** · [TXT L98](../../拆分史书/三国志/卷048.txt#L98)

> 三年春二月，以左右御史大夫丁固、孟仁爲司徒、司空。

**丁固孟仁任司徒司空** 左、右御史大夫丁固和孟仁分任司徒、司空。

**归年依据** 本传宝鼎三年二月。

<a id="period-sgz048-p-025-1"></a>

**[《三國志·三嗣主傳》 裴注 025·1](../../拆分史书/三国志/卷048.md#pei-025-1)** · [TXT L99](../../拆分史书/三国志/卷048.txt#L99)

> 吳書曰：初，固爲尚書，夢松樹生其腹上，謂人曰：「松字十八公也，後十八歲，吾其爲公乎！」卒如夢焉。

**釋讀** 丁固做尚书时梦腹上生松，以拆字推十八年后任三公。

**附敘** 《吳書》在丁固任司徒處回敘其夢松故事，傳文未直接記夢年。



<a id="sgz057-p-011-6"></a>

<a id="wu057-l39-6"></a>

**[《三國志·虞陸張駱陸吾朱傳》裴注 011](../../拆分史书/三国志/卷057.md#edition-wu057-l39-6)** · [TXT L39](../../拆分史书/三国志/卷057.txt#L39)

> 孫皓即位，遷司徒。

**釋讀** 孙皓即位后，丁固迁任司徒。

**歸年** 孙皓即位在264，注略叙其即位后的任官。《三嗣主传》明载宝鼎三年二月拜司徒，即268年。

### 2. 孙皓出东关，丁奉、诸葛靓进攻合肥。

[返回正文第2条](#sg-event-2)

<a id="sg048-l2362-e2"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sg048-l2362-e2)** · [TXT L100](../../拆分史书/三国志/卷048.txt#L100)

> 秋九月，皓出東關，丁奉至合肥。

**孙皓出东关，丁奉赴合肥** 孙皓九月出东关，丁奉至合肥。

**归年依据** 本传宝鼎三年九月。



<a id="sg055-l2673-e2"></a>

<a id="sgz055-b-2673-2"></a>

<a id="wu055-l173-2"></a>

**[《三國志·程黃韓蔣周陳董甘凌徐潘丁傳》正文](../../拆分史书/三国志/卷055.md#edition-wu055-l173-2)** · [TXT L173](../../拆分史书/三国志/卷055.txt#L173)

> 寶鼎三年，皓命奉與諸葛靚攻合肥。奉與晉大將石苞書，搆而間之，苞以徵還。

**釋讀** 孫皓命丁奉和諸葛靚攻合肥。丁奉寫信給西晉將領石苞，試圖造成其與吳私通的疑慮，之後石苞被徵還。

**歸年** 本傳明記寶鼎三年。卷048記丁奉九月至合肥；《資治通鑑》卷079繫出芍陂攻合肥、司馬駿退吳軍於十一月，不能確定兩書記的是同一日或同一階段。卷079另據《三十國春秋》《晉春秋》繫石苞罷免於本年；《晉書·石苞傳》記王琛密告及淮北傳言，不能獨以丁奉來書解釋石苞被徵。

<a id="sg-note-3"></a>

### 3. 刘俊、脩则进攻交阯战败

[返回正文第3条](#sg-event-3)

<a id="sg048-l2362-e3"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sg048-l2362-e3)** · [TXT L100](../../拆分史书/三国志/卷048.txt#L100)

> 是歲，遣交州刺史劉俊、前部督脩則等入擊交阯，爲晉將毛炅等所破，皆死，兵散還合浦。

**刘俊、脩则攻交阯，败死** 吴军被晋将毛炅等击破，领兵的刘俊、脩则死，部众逃回合浦。

**归年依据** 本传宝鼎三年；《晋书·陶璜传》记败于古城。

<a id="sgz048-p-027-4"></a>

**[《三國志·三嗣主傳》 裴注 027·4](../../拆分史书/三国志/卷048.md#pei-027-4)** · [TXT L109](../../拆分史书/三国志/卷048.txt#L109)

> 初，毛炅與吳軍戰，殺前部督脩則。

**释读** 《华阳国志》追述早前毛炅战杀脩则。
**归年** 本传宝鼎三年《晋书·陶璜传》同役。下句吴方处置毛炅已入271。

### 6. 司马望后任大司马，父司马孚为太宰

[返回正文第6条](#sgz-event-6)

<a id="wei015-l30-5"></a>

**[《三國志·劉司馬梁張溫賈傳》裴注](../../拆分史书/三国志/卷015.md#edition-wei015-l30-5)** · [TXT L30](../../拆分史书/三国志/卷015.txt#L30)

> 、大司馬。時孚爲太宰，父子居上公位，自中代已來未之有也。

**釋讀與歸年** 司马望由太尉进大司马，其父司马孚已是太宰，父子一同居上公。[《资治通鉴》卷79](../../史书/025-资治通鉴/KR2b0007_079.txt#L333-L345)系泰始四年十一月。后续率军备孙皓见[《晋书》](../../史书/005-晋书/晋书-CCDH.txt#L5000-L5001)。

<a id="sgz015-p-006-5"></a>

[本卷同事原句](#wei015-l30-5)。

**归年** 《资治通鉴》卷七十九泰始四年，司马望改大司马；司马孚在受禅之年已任太宰。

<a id="sgz-note-7"></a>

### 7. 西晋太保王祥去世

[返回正文第7条](#sgz-event-7)

**异文与补证** 王隐《晋书》记王祥卒于泰始四年，年八十九。《晋书·武帝纪》系于泰始四年，《王祥传》系于泰始五年。

<a id="wei018-l57-7"></a>

**[《三國志·二李臧文呂許典二龐閻傳》裴注](../../拆分史书/三国志/卷018.md#edition-wei018-l57-7)** · [TXT L57](../../拆分史书/三国志/卷018.txt#L57)

> 泰始四年，年八十九薨。

**釋讀與歸年** 王隐《晋书》系王祥卒于泰始四年、享年八十九。[《晋书·武帝纪》](../../史书/005-晋书/晋书-CCDH.txt#L151)明确四年四月戊戌；[《晋书·王祥传》](../../史书/005-晋书/晋书-CCDH.txt#L4711-L4712)记录遗令自称八十五、卒于泰始五年。年页从纪，保留本传卒年与年龄之异。

<a id="sgz018-p-012-7"></a>

[本卷同事原句](#wei018-l57-7)。

**归年** 《晋书·武帝纪》同系泰始四年（268）四月戊戌，《王祥传》却作泰始五年（269）；该本传亦承王太后崩后逾月，太后崩见《武帝纪》268。

### 8. 西晋任裴秀为司空

[返回正文第8条](#sgz-event-8)

<a id="wei023-l93-6"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l93-6)** · [TXT L93](../../拆分史书/三国志/卷023.txt#L93)

> 遷司空。著易及樂論，又畫地域圖十八篇，傳行於世。盟會圖及典治官制皆未成。

**釋讀與歸年** 泰始四年裴秀任司空。[《晉書·武帝紀》](../../史书/005-晋书/晋书-CCDH.txt#L147)明記正月辛未。此附其《易》《樂》論及《禹貢地域圖》十八篇等任內事，撰成月年不另定。

<a id="sgz023-p-019-6"></a>

[本卷同事原句](#wei023-l93-6)。

**归年** 《晋书·武帝纪》泰始四年正月裴秀为司空。著作陆续，有别于官年。

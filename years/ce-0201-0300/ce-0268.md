## 本年概述

晋律令修成，司马炎亲耕并大赦，又颁守相春巡考课诏。皇太后王氏、太保王祥去世，吴晋交战于江夏、襄阳、合肥及交州，四州水灾引发赈济。


<a id="sgz-event-8"></a>

1. **裴秀任司空。** 正月辛未，以尚书令裴秀为司空。裴秀曾撰《易》《乐》论，编绘《禹贡地域图》十八篇；盟会图及有关官制的著述尚未完成。 [[1]](#sgz-note-8)

<a id="jin003-u148-1-event"></a>
<a id="jin003-l148-event"></a>

2. **律令完成，亲耕并大赦。** 正月丙戌，律令修成，分别封爵赐帛。丁亥，司马炎在籍田亲耕。戊子，下诏说古时象征性刑罚即可使人不犯，如今重至族刑仍不能止奸；先帝怜悯百姓、命群臣修律，自己承业，希望与天下共享清静治理。春耕开始，他亲率王公卿士耕千亩籍田，律令也将颁行天下，以简法、务农、惠民，故大赦，使罪人得以自新。长吏、郡丞、长史各赐马一匹。 [[2]](#jin003-u148-1-note)

<a id="jin003-u148-2-event"></a>

3. **轸宿见孛星。** 正月，轸宿出现孛星。 [[3]](#jin003-u148-2-note)

<a id="jin003-u149-1-event"></a>
<a id="jin003-l149-event"></a>

4. **增山阳公国官属与礼遇。** 二月庚子，增加山阳公国相、郎中令、陵令、杂工宰人，以及鼓吹、车马等，等差有别。 [[4]](#jin003-u149-1-note)

<a id="jin003-u149-2-event"></a>

5. **罢中军将军，置北军中候。** 二月，撤中军将军，设置北军中候。 [[5]](#jin003-u149-2-note)

<a id="jin003-u149-3-event"></a>

6. **刘俭因至行拜郎。** 二月甲寅，因东海刘俭德行卓著，任他为郎。 [[6]](#jin003-u149-3-note)

<a id="jin003-u149-4-event"></a>

7. **羊祜、司马伷任尚书仆射。** 二月，以中军将军羊祜为尚书左仆射，东莞王司马伷为尚书右仆射。 [[7]](#jin003-u149-4-note)

<a id="sgz-event-5"></a>
<a id="sg-event-1"></a>

8. **丁固和孟仁分任司徒、司空。** 左右御史大夫丁固、孟仁在二月分别改任司徒与司空。 [[8]](#sg-note-1)

<a id="jin003-u150-1-event"></a>
<a id="jin003-l133c-event"></a>
<a id="jin003-l150-event"></a>

9. **皇太后王氏去世。** 三月戊子，皇太后王氏去世。司马炎居母丧，也沿用父丧时除服后仍穿深衣、戴素冠、降低坐席和减撤膳食的做法。 [[9]](#jin003-u150-1-note)

<a id="sgz-event-4"></a>

10. **罗宪在华林园荐蜀地士人。** 三月，罗宪随晋武帝宴于华林园。武帝问蜀国大臣子弟和宜任用的前辈，罗宪荐举常忌、杜轸、寿良、陈寿、高轨、吕雅、许国、费恭、诸葛京、陈裕，诸人随后得到任用。 [[10]](#sgz-note-4)

<a id="sgz-event-7"></a>

11. **王祥去世。** 四月戊戌，太保、睢陵公王祥去世。 [[11]](#sgz-note-7)

<a id="jin003-u151-2-event"></a>

12. **王氏附葬崇阳陵。** 四月己亥，将文明皇后王氏附葬崇阳陵。 [[12]](#jin003-u151-2-note)

<a id="jin003-u151-3-event"></a>

13. **改护军为左右积弩将军。** 四月，撤振威、扬威护军，设左、右积弩将军。 [[13]](#jin003-u151-3-note)

<a id="jin003-u152-1-event"></a>
<a id="jin003-l152-event"></a>

14. **命守相三年春巡属县。** 六月，命郡国守相每三年于春季巡行属县，会见长吏，察风俗，校礼律和度量，问候耆老、亲见百岁老人，审录囚徒、平反冤枉，详察政刑得失和百姓疾苦，不分远近，如皇帝亲临。又令推广父义母慈、兄友弟恭子孝等教化，劝农勉学、重正典，勿逐诸家浮末。荐举好学笃道、孝悌忠信、清白有异行者，纠治不孝不悌、悖礼违法者。长吏的政绩，要看田亩是否开辟、生计是否改善、礼教禁令是否施行；贫困荒田、盗起狱繁、上下失序则是失职。还须分辨公廉直节、不求虚名者与贪污谄媚、公事不立而私家日富者，扬清激浊、举善弹违，由守相负责，皇帝总其纲。 [[14]](#jin003-u152-1-note)

<a id="jin003-u153-1-event"></a>
<a id="jin003-l153-event"></a>

15. **太山石崩、众星西流。** 七月，太山石崩，众星向西流动。 [[15]](#jin003-u153-1-note)

<a id="jin003-u153-2-event"></a>

16. **侯史光巡行天下。** 七月戊午，遣使者侯史光巡行天下。 [[16]](#jin003-u153-2-note)

<a id="jin003-u153-3-event"></a>

17. **谒崇阳陵。** 七月己卯，司马炎拜谒崇阳陵。 [[17]](#jin003-u153-3-note)

<a id="jin003-u154-1-event"></a>
<a id="jin003-l154-event"></a>

18. **四州大水，开仓赈灾。** 九月，青、徐、兖、豫四州大水，伊水、洛水泛滥，与黄河相连，朝廷开仓赈济。 [[18]](#jin003-u154-1-note)

<a id="jin003-u154-2-event"></a>

19. **令群臣如实陈述政令不便。** 九月，司马炎命群臣，即使皇帝有意实行、奏请也已获准，只要实际上不便，仍须如实陈述，不可隐瞒。 [[19]](#jin003-u154-2-note)

<a id="jin003-u155-1-event"></a>

20. **晋军抵御施绩、万郁。** 十月，吴将施绩进攻江夏，万郁侵襄阳。晋遣太尉、义阳王司马望屯龙陂，荆州刺史胡烈击败万郁。 [[20]](#jin003-u155-1-note)

<a id="sg-event-3"></a>

21. **毛炅击败吴交州军。** 吴军进攻交趾，被晋将毛炅击败，交州刺史刘俊、将军修则战死，残军退还合浦。 [[21]](#sg-note-3)

<a id="sg-event-2"></a>

22. **丁奉出芍陂后退军。** 孙皓出东关，遣丁奉、诸葛靓进攻合肥、芍陂一带，晋遣司马骏、司马望抵御，吴军退去。丁奉曾写信给晋将石苞，企图使晋廷疑忌石苞；晋廷也收到王琛的密告，同年征还石苞。 [[22]](#sg-note-2)

<a id="jin003-u156-2-event"></a>

23. **荐举贤良方正直言者。** 十一月己未，诏令王公、卿尹及郡国守相荐举贤良方正、敢直言的人。 [[23]](#jin003-u156-2-note)

<a id="jin003-u157-1-event"></a>
<a id="jin003-l157-event"></a>

24. **向郡国颁五条诏书。** 十二月，向郡国颁五条诏书：端正自身，勤恤百姓，抚养孤寡，重本业、息末业，杜绝私下请托。 [[24]](#jin003-u157-1-note)

<a id="jin003-u157-2-event"></a>

25. **临听讼观亲决狱囚。** 十二月庚寅，司马炎到听讼观，审录廷尉、洛阳狱囚，亲自平决。 [[25]](#jin003-u157-2-note)

<a id="jin003-u157-3-event"></a>

26. **扶南、林邑来献。** 十二月，扶南、林邑各遣使来献。 [[26]](#jin003-u157-3-note)

<a id="sgz-event-6"></a>

27. **司马望后任大司马，父司马孚为太宰。** 名位比肩，《赞》谓父子俱居上公为中世所罕见。 [[27]](#sgz-note-6)

> 丙戌，律令成，封爵賜帛各有差。

**《晋书·武帝纪》泰始4年正月，L148（节引）** · [原文1](../../拆分史书/晋书/卷003.md#edition-jin003-l148-3) · [原文2](../../拆分史书/晋书/卷003.md#edition-jin003-l148-4)

> 丁亥，帝耕於藉田。戊子，詔曰：「古設象刑而眾不犯，今雖參夷而姦不絕，何德刑相去之遠哉！先帝深愍黎元，哀矜庶獄，乃命群後，考正典刑。朕守遺業，永惟保乂皇基，思與萬國以無爲爲政。方今陽春養物，東作始興，朕親率王公卿士耕藉田千畝。又律令既就，班之天下，將以簡法務本，惠育海內。宜寬有罪，使得自新，其大赦天下。長吏、郡丞、長史各賜馬一匹。」

**释读与归年** 修律、亲耕与赦令是连续三日相承的同项施政叙述；本纪丙戌，不误借前任裴秀日辛未。籍田千亩为礼制范围。

### 10. 罗宪在华林园荐蜀地士人

[返回正文第10条](#sgz-event-4)

<a id="sgz041-p-001-13"></a>

<a id="shu041-l8-17"></a>

**[《三國志·霍王向張楊費傳》裴注](../../拆分史书/三国志/卷041.md#edition-shu041-l8-17)** · [TXT L8](../../拆分史书/三国志/卷041.txt#L8)

> **〔裴注〕**
>
> 四年三月，從帝宴于華林園，詔問蜀大臣子弟，後問先輩宜時叙用者，憲薦蜀郡常忌、杜軫、壽良、巴西陳壽、南郡高軌、南陽呂雅、許國、江夏費恭、琅邪諸葛京、汝南陳裕，即皆叙用，咸顯於世。

**释读** 泰始四年三月，罗宪随晋武帝在华林园宴饮。武帝询问蜀国大臣子弟及当时宜任用的前辈，罗宪推荐常忌、杜轸、寿良、陈寿、高轨、吕雅、许国、费恭、诸葛京、陈裕，诸人随后得到任用，显名于世。

**归年与互校** 明记泰始四年三月，即268年三月。列名、籍贯依固定TXT，吕雅作“南阳”、诸葛京作“琅邪”；不沿用旧引文“高阳”等异字。随后的历官及成名是结果概述，不补每人任命为同一日。

### 11. 王祥去世

[返回正文第11条](#sgz-event-7)

[返回正文第14条](#jin003-u152-1-event)

<a id="jin003-l152-note"></a>

<a id="jin003-u152-1"></a>

**《晋书·武帝纪》泰始4年六月，L152（原文）** · [原文1](../../拆分史书/晋书/卷003.md#edition-jin003-l152-1)

> 六月丙申朔，詔曰：「郡國守相，三載一巡行屬縣，必以春，此古者所以述職宣風展義也。見長吏，觀風俗，協禮律，考度量，存問耆老，親見百年。錄囚徒，理冤枉，詳察政刑得失，知百姓所患苦。無有遠近，便若朕親臨之。敦喻五教，勸務農功，勉勵學者，思勤正典，無爲百家庸末，致遠必泥。士庶有好學篤道，孝弟忠信，清白異行者，舉而進之；有不孝敬於父母，不長悌於族黨，悖禮棄常，不率法令者，糾而罪之。田疇闢，生業修，禮教設，禁令行，則長吏之能也。人窮匱，農事荒，姦盜起，刑獄煩，下陵上替，禮義不興，斯長吏之否也。若長吏在官公廉，慮不及私，正色直節，不飾名譽者，及身行貪穢，諂黷求容，公節不立，而私門日富者，並謹察之。揚清激濁，舉善彈違，此朕所以垂拱總綱，責成於良二千石也。於戲戒哉！」

**释读与归年** 原文丙申朔；斠注所据本作甲申并有校说，保留底本。诏书的考课标准和各项职责完整连读；“致远必泥”比喻舍正典而逐末将致滞碍。

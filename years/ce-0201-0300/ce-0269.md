# 公元269年｜晋泰始五年／吴建衡元年

[← 公元268年](ce-0268.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元270年 →](ce-0270.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **立孙瑾为太子及封诸王。** 正月孙皓立孙瑾为太子，薛莹兼任太子少傅。孙皓另封淮阳王和东平王；十月改元建衡，大赦。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **吴左丞相陆凯去世。** 陆凯曾当面斥责得宠的何定。病重时，孙皓遣中书令董朝探问。陆凯说何定不宜参与国政，奚熙所议重办[浦里田](ce-0260.md#sg-note-28)也不宜推行，又荐姚信、楼玄、贺邵、张悌、郭逴、薛莹、滕修及陆喜、陆抗，请孙皓向他们询问时务。十一月，陆凯去世，年七十二。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **吴派陶璜等分路攻交阯。** 虞汜、薛珝、陶璜从荆州，李勗、徐存从建安海道，向合浦会师后进攻交阯。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **丁奉修治徐塘，进攻晋谷阳。。** 丁奉再率军至徐塘整治防务，并进攻西晋谷阳。当地居民得讯撤走，吴军无所俘获，孙皓因此杀了丁奉的向导。 [[4]](#sg-note-4)

<a id="sgz-event-5"></a>

5. **陈寿辞别谯周，谯周自言不久将死。** 陈寿任本郡中正，处理完事务后请假还乡，去辞别谯周。谯周引孔子、刘向、扬雄的寿数，说自己已过七十，恐怕活不过明年、两人不会再见；陈寿怀疑这是他借古人寿数表达术数预知。 [[5]](#sgz-note-5)

<a id="sgz-event-6"></a>

6. **吴改元建衡并大赦。** 冬十月改年，大赦。 [[6]](#sgz-note-6)

<a id="sgz-event-7"></a>

7. **辛宪英去世。** 年七十九，晋泰始五年卒。 [[7]](#sgz-note-7)

<a id="sgz-event-8"></a>

8. **应贞去世。** 曹魏旧臣应贞卒于晋泰始五年。《晋书·应贞传》与裴注所记同。 [[8]](#sgz-note-8)

<a id="sgz-event-9"></a>

9. **文立请任用蜀臣子孙，晋诏量才任用诸葛京。** 文立建议按才任用原蜀汉大官及尽忠死事者的后人，司马炎采纳。二月，晋下诏量才任用诸葛京。文立奏议依《资治通鉴》及其考异编入本年，所引《华阳国志》本身未署年月。 **《武帝纪》补记：** 己未，下诏量才任用诸葛亮之孙诸葛京。本纪接在二月段，校家据干支推或脱三月，正文保留任用在本年的结论，具体月份不强定。 [[9]](#sgz-note-9)

<a id="sgz-event-10"></a>

10. **晋诏免傅佥二子为庶人。** 司马炎以傅肜、傅佥父子为蜀死节，诏免傅佥之子傅著、傅募为庶人。 [[10]](#sgz-note-10)

<a id="jin003-l158-event"></a>

11. **劝农、录囚与荥阳祥瑞。** 正月癸巳，告诫郡国计吏及守相、令长充分利用土地，禁止游食和商贩逐末；丙申，到听讼观审录囚徒，多有赦免遣归。荥阳报告青龙两次。禁止商贩是本诏的政策，不能泛写成晋代所有商业均被禁止。 [[11]](#jin003-l158-note)

<a id="jin003-l159a-event"></a>

12. **置秦州、调任都督与考课令史。** 二月，以雍州陇右五郡、凉州金城、梁州阴平合置秦州。辛巳，赵国报白龙两次；青、徐、兖三州水灾，遣使赈恤。壬寅，以羊祜督荆州，卫瓘督青州，司马伷任镇东大将军、督徐州。丁亥，诏说古代每年记官吏能否、三年赏罚，如今令史考核只淘汰差劣者而不奖进能者，不是真正黜陟；令逐年列报特别勤能者，朝廷将议其功。壬寅、丁亥等先后与月次有校勘疑问，不能据此精定同月日序。 [[12]](#jin003-l159a-note)

<a id="jin003-l160-event"></a>

13. **四月地震。** 夏四月，发生地震；本纪此句没有列地点和损失。 [[13]](#jin003-l160-note)

<a id="jin003-l161-event"></a>

14. **赵国凤凰与交州特赦。** 五月辛卯朔，赵国报告凤凰。对交趾、九真、日南三郡实行特赦，范围为五年刑以下，不扩大为全国所有罪刑。 [[14]](#jin003-l161-note)

<a id="jin003-l162-event"></a>

15. **郭廙直谏获擢、麴路获免。** 六月，邺奚官督郭廙上疏陈五事，言辞切直，擢为屯留令。西平麴路击登闻鼓，其言被认为多有妖妄诽谤，有司请在市中处死；司马炎自认过失，释放而不追究。撤镇军将军，恢复左、右将军。 [[15]](#jin003-l162-note)

<a id="jin003-l163-event"></a>

16. **召群公求直言。** 秋七月，延见群公，询问正直意见。 [[16]](#jin003-l163-note)

<a id="jin003-l164-event"></a>

17. **紫宫孛星。** 九月，紫宫记有孛星；紫宫是星区名。 [[17]](#jin003-l164-note)

<a id="jin003-l165-event"></a>

18. **奖励汲郡太守王宏。** 冬十月丙子，因汲郡太守王宏有政绩，赐谷一千斛。 [[18]](#jin003-l165-note)

<a id="jin003-l166-event"></a>

19. **追封司马兆与景度继嗣。** 十一月，追封谥皇弟司马兆为城阳哀王，以皇子司马景度继嗣。 [[19]](#jin003-l166-note)

<a id="jin003-l167-event"></a>

20. **荐勇猛秀异人才。** 十二月，命州郡荐举勇猛、秀异之才。 [[20]](#jin003-l167-note)

<a id="wu061-l47-1"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l47-1)** · [TXT L47](../../拆分史书/三国志/卷061.txt#L47)

> 時殿上列將何定佞巧便辟，貴幸任事，凱面責定曰：「卿見前後事主不忠，傾亂國政，寧有得以壽終者邪！何以專爲佞邪，穢塵天聽？宜自改厲。不然，方見卿有不測之禍矣。」定大恨凱，思中傷之，凱終不以爲意，乃心公家，義形於色，表疏皆指事不飾，忠懇內發。

**釋讀** 殿上列將何定善於巧言逢迎，得孫皓寵信而掌事。陸凱當面斥他以佞言擾亂國政，說以往事君不忠者少能壽終，勸他自改，否則將遇禍。何定怨恨他，想進讒中傷。陸凱心在公家，仍直陳政事，奏疏毫無粉飾。

**歸年** 《通鑑》卷079在269年陸凱臨終重論何定之前，用「初」追敘面斥。此段隨臨終紀事作前因，面斥確年未詳。

<a id="sgz061-b-2908-1"></a>

<a id="wu061-l49-1"></a>

<a id="wu061-l49-2"></a>

<a id="full-wu061-l49-1"></a>

**[《三國志·潘濬陸凱傳》](../../拆分史书/三国志/卷061.md#full-wu061-l49-1)** · [TXT L49](../../拆分史书/三国志/卷061.txt#L49)

> 建衡元年，疾病，皓遣中書令董朝問所欲言，凱陳：「何定不可任用，宜授外任，不宜委以國事。奚熙小吏，建起浦里田，欲復嚴密故迹，亦不可聽。姚信、樓玄、賀卲、張悌、郭逴、薛瑩、滕脩及族弟喜、抗，或清白忠勤，或姿才卓茂，皆社稷之楨幹，國家之良輔，願陛下重留神思，訪以時務，各盡其忠，拾遺萬一。」遂卒，時年七十二。

**釋讀** 陸凱病重，孫皓遣中書令董朝詢問遺言。陸凱勸讓何定外任，莫委以國事，也不要採用奚熙重辦浦里屯田、恢復嚴密舊議的主張。

**歸年** 本傳明指建衡元年，〈孫皓傳〉記此年十一月陸凱卒，《通鑑》卷079同年記臨終問言。〈孫休傳〉曾記永安三年（260）採嚴密之議作浦里塘，奚熙重提此議是後事。

**釋讀** 陸凱薦姚信、樓玄、賀卲、張悌、郭逴、薛瑩、滕脩及同族之弟陸喜、陸抗，稱他們或清白忠勤、或才質出眾，都是國家的柱石，望孫皓留心召問他們並採納忠言。陸凱不久去世，享年七十二。

**歸年** 同一臨終問言及去世紀事。〈孫皓傳〉記十一月去世，臨終詢問未載日。

### 5. 陈寿辞别谯周，谯周自言不久将死

[返回正文第5条](#sgz-event-5)

<a id="sgz042-b-2006-3"></a>

<a id="shu042-l89-1"></a>

**[《三國志·杜周杜許孟來尹李譙郤傳》正文](../../拆分史书/三国志/卷042.md#edition-shu042-l89-1)** · [TXT L89](../../拆分史书/三国志/卷042.txt#L89)

> 五年，予甞爲本郡中正，清定事訖，求休還家，往與周別。周語予曰：「昔孔子七十二、劉向、揚雄七十一而沒，今吾年過七十，庶慕孔子遺風，可與劉、揚同軌，恐不出後歲，必便長逝，不復相見矣。」疑周以術知之，假此而言也。

**释读** 泰始五年，陈寿处理完本郡中正事务，请假还乡，去向谯周告别。谯周以孔子、刘向、扬雄的寿数为例，说自己已过七十，恐怕活不过明年，两人不会再见；陈寿怀疑这是谯周凭术数预知，借古人寿数表达。

**归年与互校** “五年”承上文泰始，系269年；“予”指作者陈寿。“后岁”即来年，与下文泰始六年冬去世相接，不读成再下一年。所引孔子等人的年龄属于谯周当时谈话，不用于另立古人寿命定论；陈寿所说“疑”保留为推测，不能变为占术预知的事实断言。

> **〔裴注〕**
>
> 立上言：「故蜀大官及盡忠死事者子孫，雖仕郡國，或有不才，同之齊民爲劇；又諸葛亮、蔣琬、費禕等子孫流徙中畿，各宜量才叙用，以慰巴、蜀之心，傾吳人之望。」事皆施行。

**释读** 文立上言，蜀汉大官及尽忠死事者的后人不应一概与普通平民同列；诸葛亮、蒋琬、费祎等人的子孙流徙中原，应按才量用，以安慰巴蜀人心，并影响吴人的观望态度。朝廷采纳了这些建议。

### 10. 晋诏免傅佥二子为庶人

[返回正文第10条](#sgz-event-10)

<a id="sgz045-p-014-1"></a>

原引文分读：[晋武帝褒扬傅氏父子，免傅佥二子为庶人](#shu045-l137-8)。


<a id="shu045-l137-8"></a>

**[《三國志·鄧張宗楊傳》注文](../../拆分史书/三国志/卷045.md#edition-shu045-l137-8)** · [TXT L137](../../拆分史书/三国志/卷045.txt#L137)

> **〔裴注〕**
>
> 　蜀記載晉武帝詔曰：「蜀將軍傅僉，前在關城，身拒官軍，致死不顧。僉父肜，復爲劉備戰亡。天下之善一也，豈由彼此以爲異？」僉息著、募，後沒入奚官，免爲庶人。

**释读** 《蜀记》载晋武帝诏书，称傅佥当年在关城抵抗己方军队，至死不退，而其父傅肜也曾为刘备战亡；天下的善行是相通的，不应因敌我而区别对待。傅佥的儿子傅著、傅募原被没入奚官，诏令免其役籍，恢复庶人身份。

**归年与互校** 《蜀记》这段本身未署年；[《资治通鉴》卷七十九](../../史书/025-资治通鉴/KR2b0007_079.txt#L346-L373)在泰始五年（269）二月，任用诸葛京的诏书后紧接此诏，故依其编年收于269年。“息”指儿子，“著”“募”为两人之名；诏中的“官军”是晋廷追称263年的魏军，不能改写为傅佥当年抵抗晋军。

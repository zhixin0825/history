# 公元269年｜晋泰始五年／吴建衡元年

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **立孙瑾为太子及封诸王。** 正月孙皓立孙瑾为太子，另封淮阳王和东平王；十月改元建衡，大赦。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **吴左丞相陆凯去世。** 十一月，任左丞相的陆凯去世。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **吴派陶璜等分路攻交阯。** 虞汜、薛珝、陶璜从荆州，李勗、徐存从建安海道，向合浦会师后进攻交阯。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **奉复帅衆治徐塘，因攻晋谷阳。** 建衡元年，奉复帅衆治徐塘，因攻晋谷阳。 [[4]](#sg-note-4)

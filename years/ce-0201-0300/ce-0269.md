# 公元269年｜晋泰始五年／吴建衡元年

[← 公元268年](ce-0268.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元270年 →](ce-0270.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **立孙瑾为太子及封诸王。** 正月孙皓立孙瑾为太子，另封淮阳王和东平王；十月改元建衡，大赦。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **吴左丞相陆凯去世。** 十一月，任左丞相的陆凯去世。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **吴派陶璜等分路攻交阯。** 虞汜、薛珝、陶璜从荆州，李勗、徐存从建安海道，向合浦会师后进攻交阯。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **奉复帅衆治徐塘，因攻晋谷阳。** 建衡元年，奉复帅衆治徐塘，因攻晋谷阳。 [[4]](#sg-note-4)

<a id="sgz-event-5"></a>

5. **陈寿辞别谯周，谯周自言不久将死。** 陈寿任本郡中正、完事请假还乡，去辞别谯周。谯周引孔子、刘向、扬雄寿数，说自己逾七十，或过不了下年。陈寿推测是其占术。 [[5]](#sgz-note-5)

<a id="sgz-event-6"></a>

6. **吴改元建衡并大赦。** 冬十月改年，大赦。 [[6]](#sgz-note-6)

<a id="sgz-event-7"></a>

7. **辛宪英去世。** 年七十九，晋泰始五年卒。 [[7]](#sgz-note-7)

<a id="sgz-event-8"></a>

8. **应贞去世。** 曹魏旧臣应贞卒于晋泰始五年。《晋书·应贞传》与裴注所记同。 [[8]](#sgz-note-8)

<a id="sgz-event-9"></a>

9. **文立请任用蜀臣子孙，晋诏量才任用诸葛京。** 文立建议任用故蜀名臣的后人，司马炎采纳。二月，晋下诏按才能任用诸葛京。《晋书·武帝纪》与《通鉴》所记干支日有异。 [[9]](#sgz-note-9)

<a id="sgz-event-10"></a>

10. **晋诏免傅佥二子为庶人。** 司马炎以傅肜、傅佥父子为蜀死节，诏免傅佥之子傅著、傅募为庶人。 [[10]](#sgz-note-10)

### 2. 吴左丞相陆凯去世

[返回正文第2条](#sg-event-2)

<a id="sg048-l2363-e2"></a>

**陆凯去世** 十一月左丞相陆凯去世。

**归年依据** 本传建衡元年。

<a id="sgz061-b-2908-1"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2908](../../sources/本地分卷/三国志/三国志-卷061.md#l2908)**

> 建衡元年，疾病。皓遣中書令董朝問所欲言，凱陳：「何定不可任用，宣授外任，不宜委以國事。奚熙小吏，建起浦裡田，欲復嚴密故跡，亦不可聽。

**释读** 陆凯病重，孙皓遣中书令董朝来问；陆凯说何定宜外任不可任国事，奚熙要复建浦里田的建议也不该听。

**归年** 本传建衡元年，《通鉴》卷七十九同。

<a id="sgz061-b-2908-2"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2908](../../sources/本地分卷/三国志/三国志-卷061.md#l2908)**

> 姚信、樓玄、賀劭、張悌、郭逴、薛瑩、滕脩及族弟喜，抗，或清白忠勤，或姿才卓茂，皆社稷之楨干，國家之良輔。願陛下重留神思，訪以時務，各盡其忠，拾遺萬一。」

**释读** 陆凯向孙皓举荐姚信、楼玄、贺劭、张悌、郭逴、薛莹、滕脩、陆喜、陆抗，希望召问时务。

**归年** 同一次建衡元年临终问言。

<a id="sgz061-b-2908-3"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2908](../../sources/本地分卷/三国志/三国志-卷061.md#l2908)**

> 遂卒，時年七十二。

**释读** 陆凯七十二岁去世。

**归年** 本传建衡元年。

### 3. 吴派陶璜等分路攻交阯

[返回正文第3条](#sg-event-3)

<a id="sg048-l2363-e3"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sg048-l2363-e3)** · [TXT L102](../../sources/本地分卷/三国志/三国志-卷048.txt#L102)

> 遣監軍虞汜、威南將軍薛珝、蒼梧太守陶璜由荊州，監軍李勗、督軍徐存從建安海道，皆就合浦擊交阯。

**孙皓发兵分路会合合浦攻交阯** 虞汜、薛珝、陶璜从荆州方向出军，李勗、徐存由建安海道，都要到合浦会兵。

**归年依据** 本传建衡元年冬；海道撤回、交阯终克在随后各年。

<a id="sgz053-b-2548-1"></a>

**[《三国志·张严程阚薛传》仓内原文 L2548](../../sources/本地分卷/三国志/三国志-卷053.md#l2548)**

> 子珝，官至威南將軍，徵交阯

**释读** 薛综子薛珝做到威南将军，参加交阯军事。

**归年** 《孙皓传》建衡元年以威南将军会攻交阯；本传未计其初拜年。

<a id="sgz057-b-2724-3"></a>

**[《三国志·虞陆张骆陆吾朱传》仓内原文 L2724](../../sources/本地分卷/三国志/三国志-卷057.md#l2724)**

> 後為監軍使者，

**释读** 虞汜后来任监军使者。

**归年** 《三嗣主传》建衡元年十一月明载。

[返回正文第5条](#sgz-event-5)

<a id="sgz042-b-2006-3"></a>

**[《三国志·二杜周许孟来尹李谯郤传》仓内原文 L2006](../../sources/本地分卷/三国志/三国志-卷042.md#l2006)**

> 五年，予常為本郡中正，清定事訖，求休還家，往與周別。周語予曰：「昔孔子七十二、劉向、楊雄七十一而沒，今吾年過七十，庶慕孔子遺風，可與劉、楊同軌，恐不出後歲，必便長逝，不復相見矣。」疑周以術知之，假而此言也。

### 9. 文立请任用蜀臣子孙，晋诏量才任用诸葛京

[返回正文第9条](#sgz-event-9)

<a id="sgz042-p-014-4b"></a>

**[《三国志》卷042裴注 014·4b](../../sources/本地分卷/三国志/三国志-卷042.md#pei-014-4b)**

> 立上言故蜀大官及盡忠死事者子孫雖仕郡國或有不才同之齊民為劇又諸葛亮蔣琬費褘等子孫流徙中畿各宜量才敘用以慰巴蜀之心傾吳人之望事皆施行

**释读** 文立请适当授职给诸葛亮、蒋琬、费祎等蜀臣的后人，晋帝采纳。

**归年** 《资治通鉴》卷七十九在泰始五年二月授任诸葛京诏前记此奏议，《通鉴考异》说明据诏书判断先后。

<a id="sgz035-p-031-1"></a>

**[《三国志·诸葛亮传》裴注 031·1](../../sources/本地分卷/三国志/三国志-卷035.md#pei-031-1)**

> 案諸葛氏譜云京字行宗晋㤗始起居注載詔曰諸葛亮在蜀盡其心力其子瞻臨難而死義天下之善士也其孫京随才署吏

**释读** 诸葛京为诸葛瞻之子。晋初诏命量才任用。

**归年** 《晋书·武帝纪》泰始五年二月己未，《资治通鉴》同月作乙未。

### 10. 晋诏免傅佥二子为庶人

[返回正文第10条](#sgz-event-10)

<a id="sgz045-p-014-1"></a>

**[《三国志·邓张宗杨传》裴注 014·1](../../sources/本地分卷/三国志/三国志-卷045.md#pei-014-1)**

> 蜀記載晉武帝詔曰蜀將軍傅僉前在闗城身拒官軍致死不顧僉父肜復為劉備戰亡天下之善一也豈由彼此以為異僉息著募後没入奚官免為庻人

**释读** 晋武帝褒扬傅肜、傅佥父子死节，其二子获免。

**归年** 《资治通鉴》卷七十九系泰始五年，紧接录用诸葛京的诏书。两道诏分别记事。

## 本年概述

胡烈在万斛堆战死，晋遣石鉴、田章出讨，赈免陇右受害五郡。吴将孙秀奔晋并受封，晋整顿军职、续录国事，又在辟雍行礼。


<a id="jin003-u168-1-event"></a>
<a id="jin003-l168-event"></a>

1. **元旦临朝不设乐。** 正月丁亥朔，司马炎临朝，不奏乐。 [[1]](#jin003-u168-1-note)

<a id="jin003-u168-2-event"></a>

2. **丁奉涡口之役的异年记载。** 丁奉率吴军进入涡口，扬州刺史牵弘抵御，吴军退去。 [[2]](#jin003-u168-2-note)

<a id="jin003-u169-1-event"></a>
<a id="jin003-l169-event"></a>

3. **赦五年刑以下。** 三月，赦免五年刑以下罪人。 [[3]](#jin003-u169-1-note)

<a id="sg-event-3"></a>

4. **吴境大火。** 三月大火烧毁一万余家，传载死七百人。 [[4]](#sg-note-3)

<a id="jin003-u170-1-event"></a>
<a id="jin003-l170-event"></a>

5. **东莞白龙汇报。** 四月，东莞报告白龙两次。 [[5]](#jin003-u170-1-note)

<a id="sg-event-4"></a>

6. **施绩去世，陆抗继镇乐乡。** 夏四月左大司马施绩去世，孙皓随后命陆抗都督信陵、西陵、夷道、乐乡、公安五地军务，驻乐乡。 [[6]](#sg-note-4)

<a id="jin003-u171-1-event"></a>
<a id="jin003-l171-event"></a>

7. **司马承封南宫王。** 五月，立寿安亭侯司马承为南宫王。 [[7]](#jin003-u171-1-note)

<a id="jin003-u172-1-event"></a>
<a id="jin003-l172-event"></a>

8. **胡烈战死与石鉴、田章出讨。** 六月戊午，秦州刺史胡烈在万斛堆与叛军作战，力战身亡。朝廷遣尚书石鉴行安西将军、都督秦州诸军，与奋威护军田章出讨。 [[8]](#jin003-u172-1-note)

<a id="jin003-u173-1-event"></a>
<a id="jin003-l173-event"></a>

9. **赈免陇右五郡。** 七月丁酉，免陇右五郡遭战乱者租赋，不能自存者发给或借贷口粮。 [[9]](#jin003-u173-1-note)

<a id="jin003-u173-2-event"></a>

10. **城阳王司马景度去世。** 七月乙巳，城阳王司马景度去世。 [[10]](#jin003-u173-2-note)

<a id="jin003-u173-3-event"></a>

11. **诏令秘书续录国事。** 七月，诏令将泰始以来大事撰录于秘书、另写副本，此后有事随时续集，作为常制。 [[11]](#jin003-u173-3-note)

<a id="jin003-u173-4-event"></a>

12. **司马骏督雍凉军事。** 七月丁未，以汝阴王司马骏为镇西大将军、都督雍凉两州诸军。 [[12]](#jin003-u173-4-note)

<a id="jin003-u174-1-event"></a>
<a id="jin003-l174-event"></a>

13. **大宛、焉耆来献。** 九月，大宛献汗血马，焉耆进贡地方物产。 [[13]](#jin003-u174-1-note)

<a id="sg-event-6"></a>
<a id="sg-event-5"></a>

14. **孙秀奔晋及授官。** 秋九月，孙皓遣何定率五千人到夏口出猎。夏口督、前将军孙秀素疑孙皓将加害于己，见何定远道带兵到来，夜率妻儿和亲兵数百人奔晋。十二月，晋任孙秀骠骑将军、开府仪同三司，封会稽公；孙皓将其改姓厉。 [[14]](#sg-note-5)

<a id="jin003-u175-1-event"></a>
<a id="jin003-l175-event"></a>

15. **辟雍行乡饮酒礼。** 十一月，司马炎到辟雍行乡饮酒礼，按等差赐太常博士、学生帛、牛、酒。 [[15]](#jin003-u175-1-note)

<a id="jin003-u175-2-event"></a>

16. **司马柬封汝南王。** 十一月，封皇子司马柬为汝南王。 [[16]](#jin003-u175-2-note)

<a id="jin003-u176-2-event"></a>
<a id="jin003-l176b-event"></a>

17. **复设镇军。** 十二月戊辰，恢复镇军官。 [[17]](#jin003-u176-2-note)

<a id="sg-event-1"></a>

18. **谯周去世。** 晋泰始六年秋，朝廷授谯周散骑常侍，他病重未能拜受，冬季去世。朝廷赐朝服、衣物和钱；谯熙遵父遗命上还衣服，获准，并得到棺木费用。 [[18]](#sg-note-1)

<a id="sg-event-2"></a>

19. **李勗、徐存因海道退军获罪。** 李勗以建安海道难行杀领路将领冯斐，撤军后受何定奏劾，李勗、徐存的家属亦伏诛。 [[19]](#sg-note-2)

<a id="sg-event-7"></a>
<a id="sgz-event-8"></a>

20. **罗宪去世，谥烈侯。** 罗宪去世，追赠安南将军，谥烈侯。 [[20]](#sgz-note-8)

<a id="sgz-event-9"></a>

21. **孙皓因继位传闻诛杀宗室。** 左夫人王氏死后，孙皓朝夕哭临，数月不露面。民间误传他已去世，孙奋或上虞侯孙奉即将被拥立。豫章太守张俊疑以为实，清扫了孙奋母亲仲姬的坟墓。孙皓将张俊车裂、夷其三族，十名豫章官吏请求代死，孙皓未准。孙奉也因传言被杀。孙奋被拘禁，孙皓命察战送毒药。孙奋叩头求留性命，孙皓不许，孙奋与五子皆死，章安国被废。孙奋卒年仍有异说，[274年会稽也曾出现拥立他的传闻](ce-0274.md#sg-note-2)。 [[21]](#sgz-note-9)

<a id="sgz-event-10"></a>

22. **万彧还建业。** 右丞相万彧回建业。 [[22]](#sgz-note-10)

<a id="sgz-event-11"></a>

23. **吴本年大赦。** 同年吴施大赦。 [[23]](#sgz-note-11)

<a id="sgz-event-12"></a>

24. **陆抗疏陈时宜十七条。** 陆抗担忧吴国对外没有盟援，内政衰敝，面对势强的晋国，只靠长江、群山守不住疆土。他以六国、楚汉与蜀汉的兴亡为戒，上疏陈述十七条时务。孙皓未采纳。 [[24]](#sgz-note-12)

<a id="sgz-event-13"></a>

25. **陆抗疏谏何定、宦官弄权。** 何定、宦官干预朝政，陆抗上疏反对把大权交给近幸，主张从现任官员中按才授职，罢退弄权者。 [[25]](#sgz-note-13)

### 24. 陆抗疏陈时宜十七条

[返回正文第24条](#sgz-event-12)

<a id="sgz058-b-2798-1"></a>

<a id="sgz058-b-2799-1"></a>

<a id="sgz058-b-2799-2"></a>

<a id="wu058-l76-1"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l76-1)** · [TXT L76](../../拆分史书/三国志/卷058.txt#L76)

> 抗聞都下政令多闕，憂深慮遠，乃上疏曰：「臣聞德均則衆者勝寡，力侔則安者制危，蓋六國所以兼并於彊秦，西楚所以北面於漢高也。今敵跨制九服，非徒關右之地；割據九州，豈但鴻溝以西而已。國家外無連國之援，內非西楚之彊，庶政陵遲，黎民未乂，而議者所恃，徒以長川峻山，限帶封域，此乃書傳之末事，非智者之所先也。臣每遠惟戰國存亡之符，近覽劉氏傾覆之釁，考之典籍，驗之行事，中夜撫枕，臨餐忘食。昔匈奴未滅，去病辭館；漢道未純，賈生哀泣。況臣王室之出，世荷光寵，身名否泰，與國同慼，死生契闊，義無苟且，夙夜憂怛，念至情慘。夫事君之義犯而勿欺，人臣之節匪躬是殉，謹陳時宜十七條如左。」十七條失本，故不載。

**釋讀** 陸抗說兩國德勢相若時人多者勝，國力相近時安定者勝。晉已兼有大片疆域，吳外無盟國、內政衰敝，長江山險不足以自保。他以六國、楚漢、蜀漢興亡為鑑，並以霍去病、賈誼憂國自勉，陳述十七條時務。傳記只保留疏的引言，十七條已失。

**歸年** [《資治通鑑》卷079](../../史书/025-资治通鉴/KR2b0007_079.txt#L409-L422)接施績卒、陸抗督西方軍事，載於泰始六年。十七條正文已佚。

### 25. 陆抗疏谏何定、宦官弄权

[返回正文第25条](#sgz-event-13)

<a id="sgz058-b-2801-1"></a>

<a id="sgz058-b-2802-1"></a>

<a id="wu058-l78-1"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l78-1)** · [TXT L78](../../拆分史书/三国志/卷058.txt#L78)

> 時何定弄權，閹官預政；抗上疏曰：「臣聞開國承家，小人勿用，靖譖庸回，唐書攸戒，是以雅人所以怨刺，仲尼所以歎息也。春秋已來，爰及秦、漢，傾覆之釁，未有不由斯者也。小人不明理道，所見旣淺，雖使竭情盡節，猶不足任，況其姦心素篤，而憎愛移易哉？苟患失之，無所不至。今委以聦明之任，假以專制之威，而兾雍熈之聲作，肅清之化立，不可得也。方今見吏，殊才雖少，然或冠冕之胄，少漸道教，或清苦自立，資能足用，自可隨才授職，抑黜羣小，然後俗化可清，庶政無穢也。」

**釋讀** 何定、宦官干預朝政，陸抗疏指小人素昧政理、任職又好惡無常，不可付以專斷之權。他請從現有官員中按才授任，貶退結黨弄權的人。

**歸年** [《資治通鑑》卷079](../../史书/025-资治通鉴/KR2b0007_079.txt#L423-L431)將此疏隨何定用事附敘於泰始六年，疏未具月日。何定伏誅另在272年。

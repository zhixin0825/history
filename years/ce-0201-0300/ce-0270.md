# 公元270年｜晋泰始六年／吴建衡二年

[← 公元269年](ce-0269.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元271年 →](ce-0271.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **谯周去世。** 晋泰始六年封散骑常侍，谯周重病不能受，冬季去世。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **李勗、徐存因海道退军获罪。** 李勗以建安海道难行杀领路将领冯斐，撤军后受何定奏劾，李勗、徐存的家属亦伏诛。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **吴境大火。** 三月大火烧毁一万余家，传载死七百人。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **吴左大司马施绩去世。** 夏四月左大司马施绩去世。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **孙秀投晋。** 秋，吴都督孙秀投奔晋。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **皓遣何定将五千人至夏口猎。** 建衡二年，皓遣何定将五千人至夏口猎。 [[6]](#sg-note-6)

<a id="sg-event-7"></a>

7. **左大司马施绩卒，拜抗都督信陵、西陵、夷道、乐乡、公安诸军事。** 建衡二年，左大司马施绩卒，拜抗都督信陵、西陵、夷道、乐乡、公安诸军事，治乐乡。 [[7]](#sg-note-7)

<a id="sgz-event-8"></a>

8. **罗宪去世，谥烈侯。** 罗宪去世，追赠安南将军，谥烈侯。 [[8]](#sgz-note-8)

<a id="sgz-event-9"></a>

9. **宠妃死后谣言流传，孙皓杀张俊与孙奋父子。** 孙皓屡哭王夫人，民间猜其已死。张俊修孙奋母墓，孙皓杀张俊、夷族，孙奋及子亦遇害；TXT记五子，四库作三子。 [[9]](#sgz-note-9)

### 1. 谯周去世

[返回正文第1条](#sg-event-1)

<a id="sg042-l2006-e1"></a>

**[《三国志·二杜周许孟来尹李谯郤传》](../../sources/摘录/三国志-卷042-二杜周许孟来尹李谯郤传.md#p004)** · [仓内TXT L2006](../../sources/本地分卷/三国志/三国志-卷042.md#l2006)

> 六年秋，為散騎常侍，疾篤不拜，至冬卒。

<a id="sgz042-p-015-1"></a>

**[《三国志·二杜周许孟来尹李谯郤传》裴注 015·1](../../sources/摘录/三国志-卷042-二杜周许孟来尹李谯郤传裴注.md#pei-015-1)**

> 晉陽秋載詔曰朕甚悼之賜朝服一具衣一襲錢十五萬

**释读** 《晋阳秋》诏书说晋武帝悼谯周，并赐朝服、衣和钱。

**归年** 本传泰始六年冬卒，赐物承丧事，同年同号。

<a id="sgz042-p-015-2"></a>

**[《三国志·二杜周许孟来尹李谯郤传》裴注 015·2](../../sources/摘录/三国志-卷042-二杜周许孟来尹李谯郤传裴注.md#pei-015-2)**

> 周息熙上言周臨終屬熙曰乆抱疾未㑹朝見若國恩賜朝服衣物者勿以加身當還舊墓道險行難豫作輕棺殯斂已畢上還所賜詔曰還衣服給棺直

**释读** 谯周交代儿子不要用朝廷所赐衣物殓身，蜀道险远，要先作轻棺归葬。谯熙上言还所赐，朝廷退衣给棺钱。

**归年** 遗命及奏还与270谯周病卒丧事相接。

### 5. 孙秀投晋

[返回正文第5条](#sg-event-5)

<a id="sg048-l2364-e5"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p008)** · [仓内TXT L2364](../../sources/本地分卷/三国志/三国志-卷048.md#L2364)

> 都督孫秀奔晉。

<a id="sgz051-b-2459-6"></a>

**[《三国志·宗室传》仓内原文 L2459](../../sources/本地分卷/三国志/三国志-卷051.md#l2459)**

> 先是，民間歛言秀當見圖，而定遠獵，秀遂驚，夜將妻子親兵數百人奔晉。

**释读** 传有孙秀将被算计的流言，孙秀见何定远来而惊，携妻儿、亲兵数百夜奔晋。

**归年** 《三嗣主传》建衡二年秋九月连记何定出猎与孙秀奔晋；《晋书·武帝纪》同年十二月记来奔授官。

<a id="sgz051-b-2459-7"></a>

**[《三国志·宗室传》仓内原文 L2459](../../sources/本地分卷/三国志/三国志-卷051.md#l2459)**

> 晉以秀為驃騎將軍、儀同三司，封會稽公。

**释读** 晋授骠骑将军、仪同三司，封会稽公。

**归年** 《晋书·武帝纪》泰始六年十二月，承降晋事。

<a id="sgz051-p-015-1"></a>

**[《三国志·宗室传》裴注 015·1](../../sources/摘录/三国志-卷051-宗室传裴注.md#pei-015-1)**

> 江表傳曰晧大怒追改秀姓曰厲

**释读** 孙秀奔晋后，孙皓大怒将其改姓厉。

**归年** 《江表传》承本传建衡二年来降，未记颁令月份。

### 9. 宠妃死后谣言流传，孙皓杀张俊与孙奋父子

[返回正文第9条](#sgz-event-9)

<a id="sgz059-b-2837-1"></a>

**[《三国志·吴主五子传》仓内原文 L2837](../../sources/本地分卷/三国志/三国志-卷059.md#l2837)**

> ﻿建衡二年，孫皓左夫人王氏卒。皓哀念過甚，朝夕哭臨，數月不出，由是民間或謂皓死，訛言奮與上虞侯奉當有立者。奮母仲姬墓在豫章，豫章太守張俊疑其或然，掃除墳塋。皓聞之，車裂俊，夷三族，誅奮及其五子，國除。

**归年** 本传建衡二年标题及裴注同称建衡二年，公元270。《三嗣主传》另载274会稽妖言孙奋当立，不能据相似传闻把两条合为同事。

<a id="sgz059-p-016-1"></a>

**[《三国志·吴主五子传》裴注 016·1](../../sources/摘录/三国志-卷059-吴主五子传裴注.md#pei-016-1)**

> 江表傳曰豫章吏十人乞代俊死晧不聼奮以此見疑

**释读** 孙皓不允，以谣言追究孙奋。

**归年** 《孙奋传》建衡二年，《三嗣主传》另记274会稽的同类传言。

<a id="sgz059-p-016-3"></a>

**[《三国志·吴主五子传》裴注 016·3](../../sources/摘录/三国志-卷059-吴主五子传裴注.md#pei-016-3)**

> 晧大怒遣察戰齎藥賜奮奮不受藥叩頭千下曰老臣自將兒子治生求活無豫國事乞丐餘年晧不聼父子皆飲藥死

**释读** 孙奋叩头求生未获准，父子被迫服药。

**归年** 同正文建衡二年之死，注异记死法与经过。

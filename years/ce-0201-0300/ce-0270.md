# 公元270年｜晋泰始六年／吴建衡二年

[← 公元269年](ce-0269.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元271年 →](ce-0271.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **谯周去世。** 晋泰始六年封散骑常侍，谯周重病不能受，冬季去世。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **李勗、徐存因海道退军获罪。** 李勗以建安海道难行杀领路将领冯斐，撤军后受何定奏劾，李勗、徐存的家属亦伏诛。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **吴境大火。** 三月大火烧毁一万余家，传载死七百人。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **施绩去世，陆抗继镇乐乡。** 夏四月左大司马施绩去世，孙皓随后命陆抗都督信陵、西陵、夷道、乐乡、公安五地军务，驻乐乡。 [[4]](#sg-note-4)

<a id="sg-event-6"></a>

<a id="sg-event-5"></a>

5. **何定领兵至夏口，孙秀率众投晋。** 秋九月，孙皓派何定率五千人赴夏口出猎。吴夏口督孙秀听说孙皓要对他下手，见何定远道带兵来到，便在夜里率妻儿和亲兵数百人投晋。十二月，晋授孙秀骠骑将军、仪同三司，封会稽公。孙皓得知后将孙秀改为厉姓。 [[5]](#sg-note-5)

<a id="sg-event-7"></a>



<a id="sgz-event-8"></a>

8. **罗宪去世，谥烈侯。** 罗宪去世，追赠安南将军，谥烈侯。 [[8]](#sgz-note-8)

<a id="sgz-event-9"></a>

9. **孙皓因继位传闻诛杀宗室。** 左夫人王氏死后，孙皓朝夕哭临，数月不露面。民间误传他已去世，孙奋或上虞侯孙奉即将被拥立。豫章太守张俊疑以为实，清扫了孙奋母亲仲姬的坟墓。孙皓将张俊车裂、夷其三族，十名豫章官吏请求代死，孙皓未准。孙奉也因传言被杀。孙奋被拘禁，孙皓命察战送毒药。孙奋叩头求留性命，孙皓不许，孙奋与五子皆死，章安国被废。孙奋卒年仍有异说，[274年会稽也曾出现拥立他的传闻](ce-0274.md#sg-note-2)。 [[9]](#sgz-note-9)

<a id="sgz-event-10"></a>

10. **万彧还建业。** 右丞相万彧回建业。 [[10]](#sgz-note-10)

<a id="sgz-event-11"></a>

11. **吴本年大赦。** 同年吴施大赦。 [[11]](#sgz-note-11)

<a id="sgz-event-12"></a>

12. **陆抗疏陈时宜十七条。** 陆抗担忧吴国对外没有盟援，内政衰敝，面对势强的晋国，只靠长江、群山守不住疆土。他以六国、楚汉与蜀汉的兴亡为戒，上疏陈述十七条时务。孙皓未采纳。 [[12]](#sgz-note-12)

<a id="sgz-event-13"></a>

13. **陆抗疏谏何定、宦官弄权。** 何定、宦官干预朝政，陆抗上疏反对把大权交给近幸，主张从现任官员中按才授职，罢退弄权者。 [[13]](#sgz-note-13)

**[《三國志·吳主五子傳》正文](../../拆分史书/三国志/卷059.md#edition-wu059-l69-1)** · [TXT L69](../../拆分史书/三国志/卷059.txt#L69)

> 建衡二年，孫皓左夫人王氏卒。皓哀念過甚，朝夕哭臨，數月不出，由是民間或謂皓死，訛言奮與上虞侯奉當有立者。奮母仲姬墓在豫章，豫章太守張俊疑其或然，掃除墳塋。皓聞之，車裂俊，夷三族，誅奮及其五子，國除。

**釋讀** 孫皓的左夫人王氏去世，孫皓朝夕哭臨、數月不露面。民間因此傳他已死，將擁立孫奮或上虞侯孫奉。豫章太守張俊信疑相半，掃除孫奮之母仲姬的墓，孫皓將張俊車裂、夷其三族，殺孫奮及五子，廢其封國。

**歸年** 卷059本傳明記建衡二年（270），裴松之下文同稱建衡二年。卷048〈三嗣主傳〉記274年會稽又有孫奮當立之誤傳，未記該年殺奮；《資治通鑑》卷080則把孫奮之死繫於274，考異另錄275年說並明未審死年。卷046〈孫策傳〉附載孫奉因擁立訛言而死，未給年次。

**歸年** 同張俊、孫奮案；《江表傳》補州吏所請，未給日期。

**釋讀** 《江表傳》稱孫奮自章安遷回吳城遭禁錮，家中男女不得通婚，有人三四十歲仍未婚。孫奮請准子女自行婚配。

**歸年** 同一案的裴注；婚禁和年齡是《江表傳》所述，下文裴松之就年差考辨。

<a id="sgz059-p-016-3"></a>

<a id="wu059-l70-3"></a>

**[《三國志·吳主五子傳》裴注 016](../../拆分史书/三国志/卷059.md#edition-wu059-l70-3)** · [TXT L70](../../拆分史书/三国志/卷059.txt#L70)

> 皓大怒，遣察戰齎藥賜奮，奮不受藥，叩頭千下，曰：「老臣自將兒子治生求治，無豫國事，乞丐餘年。」皓不聽，父子皆飲藥死。

**釋讀** 孫皓怒，使察戰官送毒藥。孫奮起初不受，以自己和兒子只求平常生活、未參政乞免。孫皓不許，孫奮父子飲藥而死。

**歸年** 與正文的誅奮及五子合讀，裴注補賜藥及乞命經過；卒年異說互見正文考證。

<a id="wu059-l70-4"></a>

**[《三國志·吳主五子傳》裴注 016](../../拆分史书/三国志/卷059.md#edition-wu059-l70-4)** · [TXT L70](../../拆分史书/三国志/卷059.txt#L70)

> 　臣松之案：建衡二年至奮之死，孫皓即位，尚猶未乆。若奮未被疑之前，兒女年二十左右，至奮死時，不得年三十四十也。若先已長大，自失時未婚娶，則不由皓之禁錮矣。此雖欲增皓之惡，然非實理。

**釋讀** 裴松之按孫皓至建衡二年即位未久，認為若孫奮子女被禁前只有二十歲左右，短期間不可能增至三四十；若禁前已成年未婚，亦不能都歸於禁令。

**歸年** 裴松之依年差考證同案的婚姻說，並不另記事件或另定年。

### 12. 陆抗疏陈时宜十七条

[返回正文第12条](#sgz-event-12)

<a id="sgz058-b-2798-1"></a>

<a id="sgz058-b-2799-1"></a>

<a id="sgz058-b-2799-2"></a>

<a id="wu058-l76-1"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l76-1)** · [TXT L76](../../拆分史书/三国志/卷058.txt#L76)

> 抗聞都下政令多闕，憂深慮遠，乃上疏曰：「臣聞德均則衆者勝寡，力侔則安者制危，蓋六國所以兼并於彊秦，西楚所以北面於漢高也。今敵跨制九服，非徒關右之地；割據九州，豈但鴻溝以西而已。國家外無連國之援，內非西楚之彊，庶政陵遲，黎民未乂，而議者所恃，徒以長川峻山，限帶封域，此乃書傳之末事，非智者之所先也。臣每遠惟戰國存亡之符，近覽劉氏傾覆之釁，考之典籍，驗之行事，中夜撫枕，臨餐忘食。昔匈奴未滅，去病辭館；漢道未純，賈生哀泣。況臣王室之出，世荷光寵，身名否泰，與國同慼，死生契闊，義無苟且，夙夜憂怛，念至情慘。夫事君之義犯而勿欺，人臣之節匪躬是殉，謹陳時宜十七條如左。」十七條失本，故不載。

**釋讀** 陸抗說兩國德勢相若時人多者勝，國力相近時安定者勝。晉已兼有大片疆域，吳外無盟國、內政衰敝，長江山險不足以自保。他以六國、楚漢、蜀漢興亡為鑑，並以霍去病、賈誼憂國自勉，陳述十七條時務。傳記只保留疏的引言，十七條已失。

**歸年** [《資治通鑑》卷079](../../史书/025-资治通鉴/KR2b0007_079.txt#L409-L422)接施績卒、陸抗督西方軍事，載於泰始六年。十七條正文已佚。

### 13. 陆抗疏谏何定、宦官弄权

[返回正文第13条](#sgz-event-13)

<a id="sgz058-b-2801-1"></a>

<a id="sgz058-b-2802-1"></a>

<a id="wu058-l78-1"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l78-1)** · [TXT L78](../../拆分史书/三国志/卷058.txt#L78)

> 時何定弄權，閹官預政；抗上疏曰：「臣聞開國承家，小人勿用，靖譖庸回，唐書攸戒，是以雅人所以怨刺，仲尼所以歎息也。春秋已來，爰及秦、漢，傾覆之釁，未有不由斯者也。小人不明理道，所見旣淺，雖使竭情盡節，猶不足任，況其姦心素篤，而憎愛移易哉？苟患失之，無所不至。今委以聦明之任，假以專制之威，而兾雍熈之聲作，肅清之化立，不可得也。方今見吏，殊才雖少，然或冠冕之胄，少漸道教，或清苦自立，資能足用，自可隨才授職，抑黜羣小，然後俗化可清，庶政無穢也。」

**釋讀** 何定、宦官干預朝政，陸抗疏指小人素昧政理、任職又好惡無常，不可付以專斷之權。他請從現有官員中按才授任，貶退結黨弄權的人。

**歸年** [《資治通鑑》卷079](../../史书/025-资治通鉴/KR2b0007_079.txt#L423-L431)將此疏隨何定用事附敘於泰始六年，疏未具月日。何定伏誅另在272年。

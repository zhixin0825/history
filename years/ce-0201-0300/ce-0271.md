# 公元271年｜晋泰始七年／吴建衡三年

[← 公元270年](ce-0270.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元272年 →](ce-0272.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **刘禅卒于洛阳。** 安乐公刘禅在晋泰始七年死于洛阳。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓出华里，因进谏而还。** 孙皓举众出华里，母妃皆随行，华覈等力谏后回返。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **吴重取交阯、九真、日南。** 虞汜、陶璜破交阯并杀晋方守将，九真、日南也重归吴。此后分置新昌、武平等郡。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **范慎任太尉、丁奉与孟仁去世。** 孙皓任武昌督范慎为太尉，右大司马丁奉、司空孟仁同年去世。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **孙皓命薛莹继承薛综遗文。** 孙皓想起薛综留下的文辞，命儿子薛莹继续创作，薛莹因而献诗。 [[5]](#sg-note-5)

<a id="sgz-event-6"></a>

6. **西晋从南中分置宁州。** 晋泰始间始分置宁州。 [[6]](#sgz-note-6)

<a id="sgz-event-7"></a>

7. **吴赦并置新昌、武平郡。** 大赦；分交阯置新昌，军破扶严后置武平郡。 [[7]](#sgz-note-7)

<a id="sgz-event-8"></a>

8. **吴西苑报凤凰，次年改号。** 西苑报告凤凰到集，朝廷遂改下一年年号。 [[8]](#sgz-note-8)

<a id="sgz-event-9"></a>

9. **西晋凉州刺史牵弘战亡。** 牵弘在边地军败而死。 [[9]](#sgz-note-9)

<a id="sgz-event-10"></a>

10. **何定议凿圣谿，薛莹督工。** 何定建议凿圣谿连通江淮，孙皓命薛莹带万人开凿，因盘石多难做而罢役。 [[10]](#sgz-note-10)

<a id="sgz-event-11"></a>

11. **晋武帝任郑袤司空，郑袤固辞。** 不受公位，终老家中。 [[11]](#sgz-note-11)

<a id="sgz-event-12"></a>

12. **裴秀卒，追谥元公。** 少子裴頠袭封，裴秀配享。 [[12]](#sgz-note-12)

### 2. 孙皓出华里，因进谏而还

[返回正文第2条](#sg-event-2)

<a id="sg048-l2365-e2"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p008)** · [仓内TXT L2365](../../sources/本地分卷/三国志/三国志-卷048.md#l2365)

> 皓舉大衆出華里，皓母及妃妾皆行，東觀令華覈等固爭，乃還。

<a id="sgz048-b-2365-1"></a>

**[《三国志·三嗣主传》仓内原文 L2365](../../sources/本地分卷/三国志/三国志-卷048.md#l2365)**

> ﻿三年春正月晦，皓舉大衆出華里，皓母及妃妾皆行，東觀令華覈等固爭，乃還。

**释读** 孙皓大举出行，母亲、妃妾同往，东观令华覈等坚决反对，孙皓返回。

**归年** 本传建衡三年春正月晦。

<a id="sgz048-p-026-2"></a>

**[《三国志·三嗣主传》裴注 026·2](../../sources/摘录/三国志-卷048-三嗣主传裴注.md#pei-026-2)**

> 即載其母妻子及後宫數千人從牛渚陸道西上云青葢入洛陽以順天命行遇大雪道塗䧟壞兵士被甲持仗百人共引一車寒凍殆死兵人不堪皆曰若遇敵便當倒戈耳晧聞之乃還

**释读** 孙皓携母妻子和后宫，自牛渚西行欲应“青盖入洛”；雪塞路，兵众疲冻怨言，孙皓回军。

**归年** 本传建衡三年春华里行动同事；《江表传》所补动机及情状有史源署名。

<a id="sgz048-p-029-1"></a>

**[《三国志·三嗣主传》裴注 029·1](../../sources/摘录/三国志-卷048-三嗣主传裴注.md#pei-029-1)**

> 江表傳曰初晧㳺華里彧與丁奉留平宻謀曰此行不急若至華里不歸社稷事重不得不自還此語頗泄晧聞知以彧等舊臣且以計忍而隂衘之

**释读** 三人说行程不急，若孙皓到华里停留，就为社稷自还。话泄露后，孙皓暂忍而怨。

**归年** 《江表传》回顾建衡三年正月华里。

### 3. 吴重取交阯、九真、日南

[返回正文第3条](#sg-event-3)

<a id="sg048-l2365-e3"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p008)** · [仓内TXT L2365](../../sources/本地分卷/三国志/三国志-卷048.md#l2365)

> 是歲，汜、璜破交阯，禽殺晉所置守將，九真、日南皆還屬。

<a id="sgz048-p-027-2"></a>

**[《三国志·三嗣主传》裴注 027·2](../../sources/摘录/三国志-卷048-三嗣主传裴注.md#pei-027-2)**

> 稷等日未滿而糧盡乞降於璜璜不許而給糧使守呉人並諫璜曰霍弋已死無能來者可須其糧盡然後乃受使彼來無罪而我取有義内訓吾民外懐鄰國不亦可乎稷炅糧盡救不至乃納之

**释读** 守军未到百日已无粮。陶璜暂拒其降并给粮，待无援、期限届满才纳降。

**归年** 本传建衡三年重取交阯；《晋书·陶璜传》同类叙事。

<a id="sgz048-p-027-3"></a>

**[《三国志·三嗣主传》裴注 027·3](../../sources/摘录/三国志-卷048-三嗣主传裴注.md#pei-027-3)**

> 華陽國志曰稷犍為人炅建寧人稷等城中食盡死亡者半將軍王約反降呉人得入城獲稷炅皆囚之孫晧使送稷下都稷至合浦歐血死晉追贈交州刺史

**释读** 守城者粮尽死众多，王约先降，吴军入城缚二将。杨稷被送吴途中在合浦吐血亡，晋追赠交州刺史。

**归年** 同年交阯陷，两书城陷过程与受降经过分明。

<a id="sgz048-p-027-5"></a>

**[《三国志·三嗣主传》裴注 027·5](../../sources/摘录/三国志-卷048-三嗣主传裴注.md#pei-027-5)**

> 陶潢等以炅壮勇欲赦之而則子允固求殺炅炅亦不為璜等屈璜等怒靣縛炅詰之曰晉兵賊炅厲聲曰呉狗何等為賊呉人生剖其腹允割其心肝罵曰庸復作賊炅猶罵不止曰尚欲斬汝孫晧汝父何死狗也乃斬之晉武帝聞而哀矜即詔使炅長子襲爵餘三子皆關内侯此與漢晉春秋所説不同

**释读** 脩则子脩允索报父仇，陶璜原欲赦，毛炅不屈被杀。晋武帝哀怜，使其长子袭爵、三子封关内侯。

**归年** 同交阯陷。此处异叙“允”是《华阳国志》所录脩则子，不径与后文郭马所属脩允判同。

### 5. 孙皓命薛莹继承薛综遗文

[返回正文第5条](#sg-event-5)

<a id="sg053-l2550-e5"></a>

**[《三国志·张严程阚薛传》](../../sources/摘录/三国志-卷053-张严程阚薛传.md#p003)** · [仓内TXT L2550](../../sources/本地分卷/三国志/三国志-卷053.md#l2550)

<a id="sgz053-b-2550-7"></a>

**[《三国志·张严程阚薛传》仓内原文 L2550](../../sources/本地分卷/三国志/三国志-卷053.md#l2550)**

> 建衡三年，皓追歎瑩父綜遺文，且命瑩繼作。瑩獻詩曰：

**释读** 孙皓追怀薛综文才，命其子薛莹继作，薛莹献诗。

**归年** 本传明书建衡三年。

<a id="sgz053-b-2551-1"></a>

**[《三国志·张严程阚薛传》仓内原文 L2551](../../sources/本地分卷/三国志/三国志-卷053.md#l2551)**

> 惟臣之先，昔仕於漢，奕世綿綿，頗涉臺觀。暨臣父綜，遭時之難，卯金失禦，邦家毀亂。適茲樂土，庶存孑遺，天啟其心，東南是歸。厥初流隸，困於蠻垂，

**释读** 薛氏世代仕汉，汉末生乱，薛综为保性命避居东南边地。

**归年** 271献诗追述，无先世细年。

<a id="sgz053-b-2551-2"></a>

**[《三国志·张严程阚薛传》仓内原文 L2551](../../sources/本地分卷/三国志/三国志-卷053.md#l2551)**

> 大皇開基，恩德遠施。特蒙招命，拯擢泥污，釋放巾褐，受職剖符。作守合浦，在海之隅，遷入京輦，遂升機樞。枯瘁更榮，絕統復紀，自微而顯，非願之始。

**释读** 孙权拔薛综出布衣，任合浦太守，又入居中枢，使家道复兴。

**归年** 271年献诗回顾。

<a id="sgz053-b-2551-3"></a>

**[《三国志·张严程阚薛传》仓内原文 L2551](../../sources/本地分卷/三国志/三国志-卷053.md#l2551)**

> 亦惟寵遇，心存足止，重值文皇，建號東宮，乃作少傅，光華益隆。明明聖嗣，至德謙祟，禮遇兼加，惟渥惟豐。哀哀先臣，念竭其忠，洪恩未報，委世以終。

**释读** 薛综作孙和少傅，受宠遇，却未能报恩便去世。

**归年** 271年献诗回顾父任少傅242、卒243。

<a id="sgz053-b-2551-4"></a>

**[《三国志·张严程阚薛传》仓内原文 L2551](../../sources/本地分卷/三国志/三国志-卷053.md#l2551)**

> 嗟臣蔑賤，惟昆及弟，幸生幸育，托綜遺體。過庭既訓，頑蔽難啟。堂構弗克，志存耦耕。豈悟聖朝，仁澤流盈。追錄先臣，愍其無成，是濟是拔，被以殊榮。珝忝千里，受命南征，旌旗備物，金革揚聲。

**释读** 兄弟受父教，薛莹自谦未继才德；皇恩又及兄弟，薛珝领命南征。

**归年** 271年献诗回顾南征；起事269。

<a id="sgz053-b-2551-5"></a>

**[《三国志·张严程阚薛传》仓内原文 L2551](../../sources/本地分卷/三国志/三国志-卷053.md#l2551)**

> 及臣斯陋，實暗實微，既顯前軌，人物之機。復傅東宮，繼世荷輝，才不逮先，是忝是違。

**释读** 自己像父亲一样担当太子少傅，却自知才能不及父亲。

**归年** 271年献诗回顾269领少傅。

<a id="sgz053-b-2551-6"></a>

**[《三国志·张严程阚薛传》仓内原文 L2551](../../sources/本地分卷/三国志/三国志-卷053.md#l2551)**

> 乾德博好，文雅是貴，追悼亡臣，冀存遺類。如何愚胤，曾無彷彿！瞻彼舊寵，顧此頑虛，孰能忍愧，臣實與居。夙夜反側，克心自論，父子兄弟，累世蒙恩，死惟結草，生誓殺身，雖則灰隕，無報萬分。

**释读** 感激孙皓好文，追先及后，自己因才不足而惭愧，愿誓报皇恩。

**归年** 271年献诗结语。

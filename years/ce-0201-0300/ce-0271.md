# 公元271年｜晋泰始七年／吴建衡三年

[← 公元270年](ce-0270.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元272年 →](ce-0272.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **刘禅卒于洛阳。** 安乐公刘禅在洛阳去世，谥思，儿子刘恂承袭爵位。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓出华里，因进谏而还。** 孙皓举众出华里，母妃皆随行，华覈等力谏后回返。 **《武帝纪》补记：** 三月，孙皓率众趋寿阳，晋遣大司马司马望屯淮北抵御。与吴纪所载出华里后因谏回返合读，不据动员便断言发生决战。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

<a id="sgz-event-7"></a>

3. **吴收复交阯等地，增置新昌、武平郡。** 四月，吴军进攻晋九真太守董元，董元死后，杨稷改派王素继任。虞汜、陶璜同年攻破交阯，俘获晋守将，九真、日南也重归吴。吴随后大赦，从交阯划出新昌郡，击破扶严后置武平郡。虞汜因功任交州刺史、冠军将军，封余姚侯。 **《武帝纪》补记：** 夏四月，吴将虞汜进攻九真，太守董元兵败而死。底本写虞氾，与吴传虞汜异写并存，不误作其父虞翻。《华阳国志》另有董元病亡的记载，死因保存分歧。 **《武帝纪》补记：** 陶璜等围交趾，晋太守杨稷、郁林太守毛炅以及日南等三郡归吴。本纪用“降”概括，吴传另详围城、俘获与死事经过，不能把各人后续结局全部说成同日投降。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **范慎任太尉、丁奉与孟仁去世。** 孙皓任武昌督范慎为太尉。范慎自称年老，军士依恋他，纷纷为他落泪。右大司马丁奉、司空孟仁同年去世。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **孙皓命薛莹继承薛综遗文。** 孙皓想起薛综留下的文辞，命儿子薛莹继续创作，薛莹献诗追述父亲避乱交州、出仕辅教太子，以及兄长薛珝南征与自己任东宫少傅的经历。 [[5]](#sg-note-5)

<a id="sgz-event-6"></a>

6. **西晋从南中分置宁州。** 泰始七年，晋廷因益州辖境广大，分益州的建宁、兴古、云南及交州的永昌四郡，设置宁州。 **《武帝纪》补记：** 从南中四郡设置宁州，对四郡实行死罪以下特赦。《地理志》详为益州建宁、兴古、云南和交州永昌，不能因本纪概称南中就把永昌也写作原属益州。 [[6]](#sgz-note-6)

<a id="sgz-event-8"></a>

7. **吴西苑报凤凰，次年改号。** 西苑报告凤凰到集，朝廷遂改下一年年号。 [[7]](#sgz-note-8)

<a id="sgz-event-9"></a>

8. **西晋凉州刺史牵弘战亡。** 四月，北地胡部进犯金城，凉州刺史牵弘出兵抵御，遭围于青山，兵败战死。 **《武帝纪》补记：** 北地胡部进犯金城，凉州刺史牵弘出讨；诸部在其境内反叛，将他围在青山，牵弘兵败战死。 [[8]](#sgz-note-9)

<a id="sgz-event-10"></a>

9. **何定议凿圣谿，薛莹督工。** 何定建议凿圣谿连通江淮，孙皓命薛莹带万人开凿，因磐石太多难以开凿，工程停止。薛莹回来后出任武昌左部督。 [[9]](#sgz-note-10)

<a id="sgz-event-11"></a>

10. **晋武帝任郑袤司空，郑袤固辞。** 十二月，晋武帝任光禄大夫郑袤为司空。郑袤屡次送还印绶，最终获准辞任，以侯就第。 [[10]](#sgz-note-11)

<a id="sgz-event-12"></a>

11. **裴秀卒，追谥元公。** 三月丙戌，司空、钜鹿公裴秀去世，年四十八，谥元。长子裴浚承袭。配享和其弟裴頠继封见[275年](ce-0275.md#wei023-pei-xiu-temple-and-son)。 [[11]](#sgz-note-12)

<a id="jin003-l177-event"></a>

12. **太子冠礼与刘猛出塞。** 正月丙午，皇太子司马衷行冠礼，按等赐王公以下帛。匈奴首领刘猛反晋，率部出塞。 [[12]](#jin003-l177-note)

<a id="jin003-l178c-event"></a>

13. **尚书仆射任命与何崇来降。** 癸巳，以中护军王业为尚书左仆射，高阳王司马珪为尚书右仆射。孙秀部将何崇率五千人来降。 [[13]](#jin003-l178c-note)

<a id="jin003-l180-event"></a>

14. **立司马宪、三州饥荒与赦罪。** 五月，立皇子司马宪为城阳王。雍、凉、秦三州饥荒，赦境内死罪以下者。 [[14]](#jin003-l180-note)

<a id="jin003-l181-event"></a>

15. **雩祭减膳及南方免户调。** 闰月，举行大雩求雨，太官减少御膳；诏交趾三郡和南中诸郡免本年户调。 [[15]](#jin003-l181-note)

<a id="jin003-l182-event"></a>

16. **举将帅、司马望卒与水灾。** 六月，命公卿以下各举将帅一人。辛丑，大司马、义阳王司马望去世。连日大雨，伊、洛、黄河泛滥，冲走居民四千余家，死三百余人；下诏赈贷并给棺安葬。 [[16]](#jin003-l182-note)

<a id="jin003-l183a-event"></a>

17. **贾充出督秦凉。** 七月癸酉，以车骑将军贾充都督秦、凉两州军事。《通鉴考异》辨另有次年之说，本页主从本纪本年。 [[17]](#jin003-l183a-note)

<a id="jin003-l184a-event"></a>

18. **卫瓘改督幽州。** 八月丙戌，以征东大将军卫瓘为征北大将军，都督幽州军事。 [[18]](#jin003-l184a-note)

<a id="jin003-l184b-event"></a>

19. **城阳王司马宪去世。** 丙申，城阳王司马宪去世。 [[19]](#jin003-l184b-note)

<a id="jin003-l185-event"></a>

20. **十月日食。** 冬十月丁丑记日食；天文志另有“朔”字，不擅补改底本。 [[20]](#jin003-l185-note)

<a id="jin003-l186-event"></a>

21. **卫公姬署去世。** 十一月丁巳，卫公姬署去世。 [[21]](#jin003-l186-note)

<a id="jin003-l187a-event"></a>

22. **十二月雪灾与军职合并。** 十二月，大雪；撤中领军，将其职任并入北军中候。此义据《通鉴》胡注说明，不译成北军中候也一并撤销。 [[22]](#jin003-l187a-note)

### 2. 孙皓出华里，因进谏而还

[返回正文第2条](#sg-event-2)

<a id="sgz048-b-2365-1"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2365-1)** · [TXT L106](../../拆分史书/三国志/卷048.txt#L106)

> 三年春正月晦，皓舉大衆出華里，皓母及妃妾皆行，東觀令華覈等固爭，乃還。

**孙皓率家眷出华里，因华覈进谏返** 孙皓大举出行，母亲、妃妾同往，东观令华覈等坚决反对，孙皓返回。

**归年依据** 本传建衡三年春正月晦。

<a id="period-sgz048-p-026-1"></a>

**[《三國志·三嗣主傳》 裴注 026·1](../../拆分史书/三国志/卷048.md#pei-026-1)** · [TXT L107](../../拆分史书/三国志/卷048.txt#L107)

> 江表傳曰：初丹楊刁玄使蜀，得司馬徽與劉廙論運命歷數事。玄詐增其文以誑國人曰：「黃旗紫蓋見於東南，終有天下者，荊、揚之君乎！」又得中國降人，言壽春下有童謠曰「吳天子當上」。皓聞之，喜曰：「此天命也。」

**釋讀** 刁玄把得到的司马徽刘廙议论加工，传播黄旗紫盖在东南、荆扬君会得天下。降人更传寿春童谣，孙皓相信。

**附敘** 《江表傳》補敘刁玄使蜀所得文字、增文和壽春童謠，使孫皓相信此行有天命。刁玄改文的時間未載。

<a id="sgz048-p-026-2"></a>

**[《三國志·三嗣主傳》 裴注 026·2](../../拆分史书/三国志/卷048.md#pei-026-2)** · [TXT L107](../../拆分史书/三国志/卷048.txt#L107)

> 即載其母妻子及後宮數千，從牛渚陸道西上，云青蓋入洛陽，以順天命。行遇大雪，道塗陷壞，兵士被甲持仗，百人共引一車，寒凍殆死。兵人不堪，皆曰：「若遇敵便當倒戈耳。」皓聞之，乃還。

**释读** 孙皓携母妻子和后宫，自牛渚西行欲应“青盖入洛”；雪塞路，兵众疲冻怨言，孙皓回军。
**归年** 本传建衡三年春华里行动同事；《江表传》所补动机及情状有史源署名。

<a id="sgz048-p-029-1"></a>

**[《三國志·三嗣主傳》 裴注 029·1](../../拆分史书/三国志/卷048.md#pei-029-1)** · [TXT L115](../../拆分史书/三国志/卷048.txt#L115)

> 江表傳曰：初皓游華里，彧與丁奉、留平密謀曰：「此行不急，若至華里不歸，社稷事重，不得不自還。」此語頗泄。皓聞知，以彧等舊臣，且以計忍而陰銜之。

**释读** 三人说行程不急，若孙皓到华里停留，就为社稷自还。话泄露后，孙皓暂忍而怨。
**归年** 《江表传》回顾建衡三年正月华里。

### 3. 吴收复交阯等地，增置新昌、武平郡

[返回正文第3条](#sg-event-3)

<a id="wu057-cross-dongyuan"></a>

**[《晋书·武帝纪》仓内原文 L179](../../史书/005-晋书/晋书-CCDH.txt#L179)**

> 夏四月，九真太守董元爲吳將虞氾所攻，軍敗，死之。

**[《资治通鉴》卷七十九仓内原文 L472](../../史书/025-资治通鉴/KR2b0007_079.txt#L472)**

> 夏四月吳交州刺史陶璜襲九真太守董元
> 殺之楊稷以其将王素代之

**归年与互校** 《晋书·武帝纪》明记泰始七年夏四月，出战者作虞氾，即虞汜。《资治通鉴》同月作陶璜袭杀董元，《晋书·陶璜传》也记陶璜击败董元。[《资治通鉴考异》卷三](../../史书/028-资治通鉴考异/KR2b0008_003.txt#L232)引《华阳国志》作董元病亡、杨稷改派王素，并据《晋书·武帝纪》取阵亡说，推测王素已奉命而尚未到郡，董元即已战死。攻董元与稍后攻取交阯属于同年南征的不同阶段。

<a id="sg048-l2365-e3"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sg048-l2365-e3)** · [TXT L108](../../拆分史书/三国志/卷048.txt#L108)

> 是歲，汜、璜破交阯，禽殺晉所置守將，九真、日南皆還屬。

**吴夺回交阯、九真、日南** 虞汜、陶璜攻破交阯，俘杀晋将，九真、日南也归吴。

**归年依据** 本传建衡三年，《晋书·陶璜传》同次大举。

<a id="period-sgz048-p-027-1"></a>

**[《三國志·三嗣主傳》 裴注 027·1](../../拆分史书/三国志/卷048.md#pei-027-1)** · [TXT L109](../../拆分史书/三国志/卷048.txt#L109)

> 漢晉春秋曰：初霍弋遣楊稷、毛炅等戍，與之誓曰：「若賊圍城，未百日而降者，家屬誅；若過百日而城沒者，刺史受其罪。」

**釋讀** 霍弋以百日为界，令守军期限前投降罚家属，过期限守不住由刺史担罪。

**附敘** 《漢晉春秋》先記霍弋派遣戍軍和百日誓約，才敘陶璜給糧待其期滿。派遣和立約並無獨立確年。

<a id="sgz048-p-027-2"></a>

**[《三國志·三嗣主傳》 裴注 027·2](../../拆分史书/三国志/卷048.md#pei-027-2)** · [TXT L109](../../拆分史书/三国志/卷048.txt#L109)

> 稷等日未滿而糧盡，乞降於璜。璜不許，而給糧使守。吳人並諫，璜曰：「霍弋已死，無能來者，可須其糧盡，然後乃受，使彼來無罪，而我取有義，內訓吾民，外懷鄰國，不亦可乎！」稷、炅糧盡，救不至，乃納之。

**释读** 守军未到百日已无粮。陶璜暂拒其降并给粮，待无援、期限届满才纳降。
**归年** 本传建衡三年重取交阯；《晋书·陶璜传》同类叙事。

<a id="sgz048-p-027-3"></a>

**[《三國志·三嗣主傳》 裴注 027·3](../../拆分史书/三国志/卷048.md#pei-027-3)** · [TXT L109](../../拆分史书/三国志/卷048.txt#L109)

> 華陽國志曰：稷，犍爲人。炅，建寧人。稷等城中食盡，死亡者半，將軍王約反降，吳人得入城，獲稷、炅，皆囚之。孫皓使送稷下都，稷至合浦，歐血死。晉追贈交州刺史。

**释读** 守城者粮尽死众多，王约先降，吴军入城缚二将。杨稷被送吴途中在合浦吐血亡，晋追赠交州刺史。
**归年** 同年交阯陷，两书城陷过程与受降经过分明。

<a id="sgz048-p-027-5"></a>

**[《三國志·三嗣主傳》 裴注 027·5](../../拆分史书/三国志/卷048.md#pei-027-5)** · [TXT L109](../../拆分史书/三国志/卷048.txt#L109)

> 陶璜等以炅壯勇，欲赦之。而則子允固求殺炅，炅亦不爲璜等屈，璜等怒，靣縛炅詰之，曰：「晉兵賊！」炅厲聲曰：「吳狗，何等爲賊？」吳人生剖其腹，允割其心肝，罵曰：「庸復作賊？」炅猶罵不止，曰：「尚欲斬汝孫皓，汝父何死狗也！」乃斬之。晉武帝聞而哀矜，即詔使炅長子襲爵，餘三子皆關內侯。此與漢晉春秋所說不同。

**释读** 脩则子脩允索报父仇，陶璜原欲赦，毛炅不屈被杀。晋武帝哀怜，使其长子袭爵、三子封关内侯。
**归年** 同交阯陷。此处异叙“允”是《华阳国志》所录脩则子，不径与后文郭马所属脩允判同。

<a id="sgz-note-7"></a>

<a id="sgz048-b-2365-3"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2365-3)** · [TXT L110](../../拆分史书/三国志/卷048.txt#L110)

> 大赦，分交阯爲新昌郡。諸將破扶嚴，置武平郡。

**吴赦并置新昌、武平郡** 大赦；分交阯置新昌，军破扶严后置武平郡。

> 吳錄曰：仁字恭武，江夏人也，本名宗，避皓字，易焉。少從南陽李肅學。其母爲作厚褥大被，或問其故，母曰：「小兒無德致客，學者多貧，故爲廣被，庶可得與氣類接也。」其讀書夙夜不懈，肅奇之，曰：「卿宰相器也。」初爲驃騎將軍朱據軍吏，將母在營。旣不得志，又夜雨屋漏，因起涕泣，以謝其母，母曰：「但當勉之，何足泣也？」據亦稍知之，除爲塩池司馬。自能結網，手以捕魚，作鮓寄母，母因以還之，曰：「汝爲魚官，而以鮓寄我，非避嫌也。」遷吳令。時皆不得將家之官，每得時物，來以寄母，常不先食。及聞母亡，犯禁委官，語在權傳。特爲減死一等，復使爲官，蓋優之也。

> 建衡三年，皓追歎瑩父綜遺文，且命瑩繼作。瑩獻詩曰：「惟臣之先，昔仕于漢，奕世緜緜，頗涉臺觀。曁臣父綜，遭時之難，卯金失御，邦家毀亂。適茲樂土，庶存孑遺，天啟其心，東南是歸。厥初流隷，困于蠻垂。大皇開基，恩德遠施。特蒙招命。拯擢泥汙，釋放巾褐，受職剖符。作守合浦，在海之隅，遷入京輦，遂升機樞。枯瘁更榮，絕統復紀，自微而顯，非願之始。亦惟寵遇，心存足止。重值文皇，建號東宮，乃作少傅，光華益隆。明明聖嗣，至德謙崇，禮遇兼加，惟渥惟豐。哀哀先臣，念竭其忠，洪恩未報，委世以終。嗟臣蔑賤，惟昆及弟，幸生幸育，託綜遺體。過庭旣訓，頑蔽難啟。堂構弗克，志存耦耕。豈悟聖朝，仁澤流盈。追錄先臣，愍其無成，是濟是拔，被以殊榮。珝忝千里，受命南征，旌旗備物，金革揚聲。及臣斯陋，實闇實微，旣顯前軌，人物之機；復傅東宮，繼世荷煇，才不逮先，是忝是違。乾德博好，文雅是貴，追悼亡臣，兾存遺類。如何愚胤，曾無髣髴！瞻彼舊寵，顧此頑虛，孰能忍媿，臣實與居。夙夜反側，克心自論，父子兄弟，累世蒙恩，死惟結草，生誓投身，雖則灰隕，無報萬分。」

# 公元271年｜晋泰始七年／吴建衡三年

[← 公元270年](ce-0270.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元272年 →](ce-0272.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **刘禅卒于洛阳。** 安乐公刘禅在晋泰始七年死于洛阳。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓出华里，因进谏而还。** 孙皓举众出华里，母妃皆随行，华覈等力谏后回返。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **吴重取交阯、九真、日南。** 虞汜、陶璜破交阯并杀晋方守将，九真、日南也重归吴。此后分置新昌、武平等郡。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **范慎任太尉、丁奉与孟仁去世。** 孙皓任武昌督范慎为太尉，右大司马丁奉、司空孟仁同年去世。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **孙皓命薛莹继承薛综遗文。** 孙皓想起薛综留下的文辞，命儿子薛莹继续创作，薛莹因而献诗。 [[5]](#sg-note-5)

<a id="sgz-event-6"></a>

6. **西晋从南中分置宁州。** 晋泰始间始分置宁州。 [[6]](#sgz-note-6)

> 公泰始七年薨於洛陽。

<a id="sgz033-p-014-1"></a>

**[《三国志·后主传》裴注 014·1](../../sources/摘录/三国志-卷033-后主传裴注.md#pei-014-1)**

> 蜀記云謚曰思公子恂嗣

**释读** 刘禅获谥思公，子刘恂继嗣。

**归年** 本传明书晋泰始七年卒，《通鉴》卷079同年称安乐思公，《蜀记》附记刘恂袭爵而无独立日期。《二主妃子传》裴注引《蜀世谱》记其兄弟迁徙和后裔事，未明记晋廷的这次袭爵。

<a id="sgz059-p-002-3"></a>

**[《三国志·吴主五子传》裴注 002·3](../../sources/摘录/三国志-卷059-吴主五子传裴注.md#pei-002-3)**

> 詔曰慎勲徳俱茂朕所敬慿宜登上公以副衆望以為太尉慎自恨久為將遂託老耄軍士戀之舉營為之隕涕

**释读** 范慎因长期为将而不乐就新任，托老；军中爱戴而流泪。

**归年** 《三嗣主传》建衡三年十二月以范慎为太尉，其心事及士卒反应附任命。

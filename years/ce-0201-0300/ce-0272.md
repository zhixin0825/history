# 公元272年｜晋泰始八年／吴凤凰元年

[← 公元271年](ce-0271.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元273年 →](ce-0273.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **步阐降晋、陆抗取西陵。** 步阐不应征命，守西陵并降晋；陆抗进围取胜，步阐及同谋遭夷族。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **万彧忧死、何定被诛。** 万彧受谴忧死，子弟徙庐陵。同年何定罪发受诛。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **诏曰“正昔在成都”。** 泰始八年诏曰：「正昔在成都，颠沛守义，不违忠节，及见受用，尽心干事，有治理之绩，其以正为巴西太守。」 [[3]](#sg-note-3)

<a id="sgz-event-4"></a>

4. **楼玄、贺邵被诬，楼玄发广州。** 有人把楼玄与贺邵谈笑说成谤政，孙皓追责并把楼玄发交广州。 [[4]](#sgz-note-4)

<a id="sgz-event-5"></a>

5. **华覈上疏求起用楼玄。** 华覈官东观令时上疏。 [[5]](#sgz-note-5)

<a id="sgz-event-6"></a>

6. **楼玄被转徙交阯，后见密敕自杀。** 楼玄与子楼据被付张奕，孙皓密令杀之。儿子先病亡，楼玄同行作战，张奕暴卒时楼玄发现敕书，自尽。 [[6]](#sgz-note-6)

<a id="sgz-event-7"></a>

7. **贺邵疏谏孙皓。** 本传称孙皓骄暴日甚，贺邵为国政进疏。 [[7]](#sgz-note-7)

<a id="sgz-event-8"></a>

8. **万彧受谴忧死，子弟迁庐陵。** 右丞相万彧因被责忧死，家族子弟迁往庐陵。 [[8]](#sgz-note-8)

<a id="sgz-event-9"></a>

9. **何定被杀，追改名为布。** 何定罪事暴露被诛，孙皓称其作恶像张布，死后改其名为布。 [[9]](#sgz-note-9)

<a id="sgz-event-10"></a>

10. **《江表传》说万彧、留平遭下毒的异说。** 称孙皓命给万彧、留平毒酒，留平及时解毒，万彧自杀，留平抑郁逾月后死。 [[10]](#sgz-note-10)

<a id="sgz-event-11"></a>

11. **陆抗疏请停小规模进兵。** 兵旅不断，百姓疲敝，陆抗再上疏。 [[11]](#sgz-note-11)

<a id="sgz-event-12"></a>

12. **陆抗与羊祜交好。** 《晋阳秋》说两将有季札、子产之交，陆抗馈酒、羊祜无疑；陆抗有病，亦信羊祜所馈药，时人比华元、子反。 [[12]](#sgz-note-12)

**[《三国志·三嗣主传》仓内原文 L2366](../../sources/本地分卷/三国志/三国志-卷048.md#l2366)**

> ﻿鳳皇元年秋八月，徵西陵督步闡。闡不應，據城降晉。遣樂鄉都督陸抗圍取闡，闡衆悉降。闡及同計數十人皆夷三族。大赦。

**释读** 朝廷征召镇西陵的步阐，他据城降晋。陆抗围克西陵，步阐及共谋数十人被夷三族，朝廷大赦。

**释读** 陆机称晋在江边配合城内，陆抗据险深屯，分兵又拒江上水军，终于两向抵挡并取胜。

**归年** 步阐叛与陆抗克西陵皆在凤凰元年，和《陆抗传》《晋书》同号。

**释读** 西陵督步阐占城归晋，陆抗遣左奕、吾彦、蔡贡等急赴西陵。

> 敕軍營更築嚴圍，自赤谿至故市，內以圍闡，外以禦寇，晝夜催切，如敵以至，眾甚苦之。諸將咸諫曰：「今及三軍之銳，亟以攻闡，比晉救至，闡必可拔。何事於圍，而以弊士民之力乎？」抗曰：「此城處勢既固，糧谷又足，且所繕修備御之具，皆抗所宿規。今反身攻之，既非可卒克，且北救必至，至而無備，表裡受難，何以御之？」

**释读** 命修赤溪到故市严围，以内困步阐、外挡晋援；诸将建议攻取，陆抗说明城坚粮足、攻不克会受内外夹击。

**释读** 雷谭劝请甚急，陆抗让试攻一次，无利后围垒才合。

**归年** 西陵之战围城阶段。

<a id="sgz058-b-2803-4"></a>

**释读** 羊祜进江陵，陆抗认为即使一时失掉江陵也比西陵失控、引发南山群夷响应好，决定先救西陵。

**释读** 江陵先筑堰淹平地绝交通，羊祜声称决堰欲通步兵，实欲借水运粮；陆抗抢决，迫羊祜改用车辆。

<a id="sgz065-b-3042-1"></a>

> 臣竊以治國之體，其猶治家。主田野者，皆宜良信。又宜得一人總其條目，為作維綱，眾事乃理。《論語》曰：『無為而治者其舜也與!恭己正南面而己。』言所任得其人，放優遊而自逸也。今海內未定，天下多事，事無大小，皆當關聞，動經御坐，勞損聖慮。陛下既垂意博古，綜極藝文，加勤心好道，隨節致氣，宜得閑靜以展神思，呼翕清淳，與天同極。臣夙夜思惟，諸吏之中，任干之事，足委丈者，無勝於樓玄。玄清忠奉公，冠冕當世，眾服其操，無與爭先。失清者則心平而意直，忠者惟正道而履之，如玄之性，終始可保，乞陛下赦玄前愆，使得自新，擢之宰司，責其後效。使為官擇人，隨才授任，則舜之恭己，近亦可得。

**释读** 举舜任贤而治，称楼玄品德才干为最佳，请原其过授以宰职。

**归年** 接楼玄案续事；舜为经文所引旧典。

### 6. 楼玄被转徙交阯，后见密敕自杀

[返回正文第6条](#sgz-event-6)

<a id="sgz065-b-3043-1"></a>

**[《三国志·王楼贺韦华传》仓内原文 L3043](../../sources/本地分卷/三国志/三国志-卷065.md#l3043)**

> 皓話玄名聲，復徙玄及子據，付交阯將張奕，使以戰自效，陰別敕奕令殺之。據到交阯，病死。玄一身隨亦討賊，持刀步涉，見亦輒拜，亦未忍殺。會亦暴卒，玄殯斂亦，於器中見敕書，還便自殺。

> 孫晧聞二境交和以詰於抗抗曰夫一邑一鄉不可以無信義之人而況大國乎臣不如是正足以彰其徳耳於祜無傷也或以祜抗為失臣節兩譏之

**释读** 孙皓质问与晋交好，陆抗说国家必须讲信义，自己若失信只彰羊祜之德，也有人讥两人失臣节。

**归年** 《通鉴》随272西陵战后列。

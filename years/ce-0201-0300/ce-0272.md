1. **王濬在蜀造舰，吾彦请增兵建平。** 晋廷令益州刺史王濬停止屯田，赶造战舰。王濬采用别驾何攀的建议，召集诸郡万余人造船，由何攀主持。造船的木屑顺江漂下，吴建平太守吾彦取木屑呈给孙皓，请增建平守军，孙皓没有采纳。吾彦遂以铁索阻断江路。 [[1]](#wu048-shipbuilding-note)

<a id="sg-event-1"></a>

2. **步阐据西陵降晋，陆抗退援克城。** 秋八月，吴廷征召西陵督步阐为绕帐督。步阐自以为失职，怕遭谗害，便据西陵降晋，遣步玑、步璿入洛为质。晋封步阐为宜都公，授步玑、步璿军职与爵位。陆抗派左弈、吾彦、蔡贡等赴西陵，从赤溪到故市筑垒，内围步阐，外防晋军。诸将希望在晋援抵达前攻城，陆抗指出西陵险固、粮足。宜都太守雷谭固请，试攻果然失利，随后完成包围。晋将羊祜趋江陵，徐胤率水军赴建平，杨肇进援西陵。陆抗以江陵守备充足，令张咸守城、孙遵巡江南岸，命留虑、朱琬抵御徐胤，自率主力阻击杨肇。羊祜想借江陵堰蓄水行船运粮，陆抗先令张咸决堰，晋军只得改用车运。朱乔、俞赞投晋，陆抗料杨肇会打探守军薄弱处，连夜换上老兵，次日击退来攻之敌。杨肇相持约一月后夜撤，吴军鸣鼓扰敌，再遣轻兵追击，晋各路援军退去。十二月，陆抗攻克西陵，诛步阐及其宗族、主要将吏，其余数万人请赦。陆抗修整城防，回乐乡，随后加都护。步璿在晋得以承续步氏祭祀。 [[2]](#sg-note-1)

<a id="sg-event-3"></a>

3. **诏曰“正昔在成都”。** 泰始八年诏曰：「正昔在成都，颠沛守义，不违忠节，及见受用，尽心干事，有治理之绩，其以正为巴西太守。」 [[3]](#sg-note-3)

4. **楼玄与贺邵被诬，华覈申救未成，楼玄死于交趾。** 楼玄任大司农时，万彧劝孙皓选任清正的近臣，楼玄遂奉命掌管殿中。他奉法办事，多次直言惹怒孙皓。贺邵上疏进谏后，有人诬称楼玄和贺邵相遇谈笑是在诽谤国政，两人都受责问。贺邵获准复职，楼玄被遣往广州。东观令华覈上疏称楼玄清忠有才，劝孙皓赦免并任他选拔官员，孙皓却把楼玄与其子楼据转交交趾将领张弈，暗令张弈杀他。楼据到交趾病死，楼玄也因孙皓的密令而死。 [[4]](#sgz-note-4)

<a id="sgz-event-7"></a>

5. **贺邵疏谏孙皓。** 贺邵上疏，指陈近臣弄权、忠直者不敢开口，以王蕃被杀、葛奚饮烈酒而死为例。他指责何定征发守江士卒围猎，又指出赋役日重、民户流散，国库无积粮而后宫仰食者逾万。贺邵请孙皓罢退弄权近臣，广纳直言，减轻税役，赈济穷困，优恤戍卒。他以秦、蜀亡国为戒，劝孙皓整饬政事，莫独恃长江之险。孙皓读后深恨贺邵。 [[5]](#sgz-note-7)

6. **万彧受谴而死，子弟迁庐陵。** 右丞相万彧受孙皓责罚而死，子弟迁往庐陵。何定伏诛另见[本年第7条](#sgz-note-9)。 [[6]](#sgz-note-8)

<a id="sgz-event-9"></a>

7. **何定伏诛，孙皓追究圣谿工程。** 何定罪事败露，被孙皓处死，死后改名为布。后来孙皓追究开凿圣谿的旧事，将督工的薛莹下狱，流徙广州。陆抗曾上疏请赦薛莹、召回楼玄。下狱、流徙的年月未详。 [[7]](#sgz-note-9)

<a id="sgz-event-11"></a>

8. **陆抗疏请停小规模进兵。** 连年用兵，吴国兵民疲敝。陆抗认为诸将为求功频繁出兵，所得抵不上损失，劝孙皓暂停小规模进攻，务农积谷、量才授职、严明赏罚，养民蓄力以待时机。孙皓未采纳。 [[8]](#sgz-note-11)

<a id="sgz-event-12"></a>

9. **陆抗与羊祜交好。** 西陵撤军后，羊祜在边境以守信安民。陆抗也告诫守军各守疆界，不贪小利。两境不取对方田中余粮，牛马误入可告知取回，猎得对方先射伤的猎物也送还。陆抗送酒，羊祜饮而不疑。陆抗病时求药，也服下羊祜送来的药。孙皓质问陆抗为何与晋交好，陆抗答说两国交界也需要信用，吴若失信，只会越发显出羊祜的声望。 [[9]](#sgz-note-12)

### 2. 步阐据西陵降晋，陆抗退援克城

[返回正文第2条](#sg-event-1)

<a id="sgz048-b-2366-1"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2366-1)** · [TXT L114](../../拆分史书/三国志/卷048.txt#L114)

> 鳳皇元年秋八月，徵西陵督步闡。闡不應，據城降晉。遣樂鄉都督陸抗圍取闡，闡衆悉降。闡及同計數十人皆夷三族。大赦。

**步阐降晋，陆抗围克西陵** 朝廷征召镇西陵的步阐，他据城降晋。陆抗围克西陵，步阐及共谋数十人被夷三族，朝廷大赦。

**归年依据** 本传以凤凰元年秋八月吴廷召步阐起叙。下引《晋书·武帝纪》在晋泰始八年九月记步阐来降。

**[《晉書》卷003〈武帝紀〉](../../史书/005-晋书/晋书-CCDH.txt#L192)**

> 九月，吳西陵督步闡來降，拜衛將軍、開府儀同三司，封宜都公。吳將陸抗攻闡，遣車騎將軍羊祜帥眾出江陵，荊州刺史楊肇迎闡於西陵，巴東監軍徐胤擊建平以救闡。

**互校** 吴纪八月记征召。《建康實錄》卷四于八月记「是月，西陵督步闡反，降晉」，晋纪于九月记步阐来降并载授官及遣兵救援。两种月次可能分别指据城宣布投降和晋廷受降，步阐据城的具体日子未载。

<a id="period-sgz048-p-041-4"></a>

**[《三國志·三嗣主傳》 裴注 041·4](../../拆分史书/三国志/卷048.md#pei-041-4)** · [TXT L161](../../拆分史书/三国志/卷048.txt#L161)

> 陸抗之克步闡，皓意張大，乃使尚廣筮并天下，遇同人之頤，對曰：「吉。庚子歲，青蓋當入洛陽。」故皓不脩其政，而恒有窺上國之志。是歲也，實在庚子。

**釋讀** 陆抗克步阐后孙皓夸大自信，尚广占云庚子青盖入洛；干宝联系后来孙皓归降入洛，而非他得天下。

**附敘** 《干寶晉紀》記陸抗克步闡後，孫皓令尚廣筮取天下，《資治通鑑》同放此役之後。末句「實在庚子」追指八年後孫皓降晉入洛。

<a id="sgz048-p-044-11"></a>

**[《三國志·三嗣主傳》 裴注 044·11](../../拆分史书/三国志/卷048.md#pei-044-11)** · [TXT L169](../../拆分史书/三国志/卷048.txt#L169)

> 逮步闡之亂，憑保城以延彊寇，重資幣以誘羣蠻。于時大邦之衆，雲翔電發，縣旌江介，築壘遵渚，襟帶要害，以止吳人之西，而巴漢舟師沿江東下。陸公以偏師三萬，北據東坑，深溝高壘，案甲養威。反虜踠跡待戮，而不敢北闚生路，彊寇敗績宵遁，喪師大半，分命銳師五千，西禦水軍，東西同捷，獻俘萬計。信哉賢人之謀，豈欺我哉！

**释读** 陆机称晋在江边配合城内，陆抗据险深屯，分兵又拒江上水军，终于两向抵挡并取胜。
**归年** 步阐叛与陆抗克西陵皆在凤凰元年，和《陆抗传》《晋书》同号。

<a id="sgz058-b-2803-2"></a>

<a id="wu058-l80-2"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l80-2)** · [TXT L80](../../拆分史书/三国志/卷058.txt#L80)

> 勑軍營更築嚴圍，自赤谿至故市，內以圍闡，外以禦寇，晝夜催切，如敵以至，衆甚苦之。諸將咸諫曰：「今及三軍之銳，亟以攻闡，比晉救至，闡必可拔。何事於圍，而以弊士民之力乎？」抗曰：「此城處勢旣固，糧穀又足，且所繕脩備禦之具，皆抗所宿規。今反身攻之，旣非可卒克，且北救必至，至而無備，表裏受難，何以禦之？」

**釋讀** 陸抗命軍士從赤谿到故市日夜築圍，內困步闡，外禦援晉。諸將想先急攻，他說西陵險固、糧械充足，又由自己先前布置，必須防晉兵到時內外受敵。

**歸年** 同一圍城的防備與將領間的爭議。

**釋讀** 雷譚懇請攻城，陸抗准其一試，果然不利，遂完成包圍。

<a id="wu058-l80-4"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l80-4)** · [TXT L80](../../拆分史书/三国志/卷058.txt#L80)

> 晉車騎將軍羊祜率師向江陵，諸將咸以抗不宜上，抗曰：「江陵城固兵足，無所憂患。假令敵沒江陵，必不能守，所損者小。如使西陵槃結，則南山羣夷皆當擾動，則所憂慮，難可竟言也。吾寧棄江陵而赴西陵，況江陵牢固乎？」

**釋讀** 晉將羊祜進向江陵。陸抗認為江陵守備充足，即使暫失也不如讓晉軍在西陵立足嚴重；西陵若失，南方部族亦將震動。

**歸年** 江陵與西陵是同一戰役的兩處目標。

<a id="sgz058-b-2803-5"></a>

<a id="wu058-l80-5"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l80-5)** · [TXT L80](../../拆分史书/三国志/卷058.txt#L80)

> 初，江陵平衍，道路通利，抗勑江陵督張咸作大堰遏水，漸漬平中，以絕寇叛。祜欲因所遏水，浮船運糧，揚聲將破堰以通步車。抗聞，使咸亟破之。諸將皆惑，屢諫不聽。祜至當陽，聞堰敗，乃改船以車運，大費損功力。

**釋讀** 張咸原在江陵築堰浸濕平地以禦敵。羊祜聲稱要毀堰，實要利用蓄水行船運糧。陸抗先令張咸破堰，羊祜赴當陽後只得改為車運。

> 東觀令華覈上疏曰：「臣竊以治國之體，其猶治家。主田野者，皆宜良信。又宜得一人緫其條目，爲作維綱，衆事乃理。論語曰：『無爲而治者其舜也與！恭己正南面而已。』言所任得其人，故優遊而自逸也。今海內未定，天下多事，事無大小，皆當關聞，動經御坐，勞損聖慮。陛下旣垂意愽古，綜極藝文，加勤心好道，隨節致氣，宜得閑靜以展神思，呼翕清淳，與天同極。臣夙夜思惟，諸吏之中，任幹之事，足委杖者，無勝於樓玄。玄清忠奉公，冠冕當世，衆服其操，無與爭先。夫清者則心平而意直，忠者惟正道而履之，如玄之性，終始可保，乞陛下赦玄前愆，使得自新，擢之宰司，責其後效，使爲官擇人，隨才授任，則舜之恭己，近亦可得。」

**釋讀** 東觀令華覈說治國如治家，田野事務須有可靠的人掌理，更須有人統籌，才能使諸事有條理。《論語》稱舜端身面南而治，正因任人得當。當今海內未定，無論事情大小都聞奏皇帝，徒增勞神。孫皓精通文章學術、有意修養精神，宜得清靜以養氣。華覈遍思諸臣，認為樓玄最可托付，清正而忠心奉公，眾人服其節操，朝中無人比得上。請孫皓赦他前愆、任以輔政職務，責其後效，讓他選任合適的人才，如此才能近於舜垂拱而治。

**歸年** 疏為樓玄被遣廣州後的營救，與272年樓玄案合讀。原傳未記上奏年月，舜是奏疏引例。

<a id="wu065-l27-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l27-1)** · [TXT L27](../../拆分史书/三国志/卷065.txt#L27)

> 古之聖王，所以潛處重闈之內而知萬里之情，垂拱袵席之上，明照八極之際者，任賢之功也。陛下以至德淑姿，統承皇業，宜率身履道，恭奉神器，旌賢表善，以康庶政。自頃年以來，朝列紛錯，真偽相貿，上下空任，文武曠位，外無山嶽之鎮，內無拾遺之臣；佞諛之徒拊翼天飛，干弄朝威，盜竊榮利，而忠良排墜，信臣被害。是以正士摧方，而庸臣苟媚，先意承旨，各希時趣，人執反禮之評，士吐詭道之論，遂使清流變濁，忠臣結舌。陛下處九天之上，隱百重之室，言出風靡，令行景從，親洽寵媚之臣，日聞順意之辭，將謂此輩實賢，而天下已平也。臣心所不安，敢不以聞。

**釋讀** 古代聖王深居能知遠方與四境，靠的是賢臣。孫皓應以身循道，表彰賢善，使政事安定。如今名位失序、賢愚混雜，內外缺少稱職之臣，諂媚者攀高弄權、竊取榮利，忠良反遭排擠和陷害。正直者被迫磨去稜角，庸人揣摩旨意、倒置是非，竟使正士噤聲。孫皓居於深宮，周圍只說順耳的話，恐會把這些人當賢能，以為天下太平。

**歸年** 是此疏首段。[《通鑑》卷079](../../史书/025-资治通鉴/KR2b0007_079.txt#L699-L707)從朝臣用舍處節錄。

<a id="wu065-l29-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l29-1)** · [TXT L29](../../拆分史书/三国志/卷065.txt#L29)

> 臣聞興國之君樂聞其過，荒亂之主樂聞其譽；聞其過者過日消而福臻，聞其譽者譽日損而禍至。是以古之人君，揖讓以進賢，虛己以求過，譬天位於乘犇，以虎尾爲警戒。至於陛下，嚴刑法以禁直辭，黜善士以逆諫臣，眩燿毀譽之實，沈淪近習之言。昔高宗思佐，夢寐得賢，而陛下求之如忘，忽之如遺。故常侍王蕃忠恪在公，才任輔弼，以醉酒之間加之大戮。近鴻臚葛奚，先帝舊臣，偶有逆迕，昏醉之言耳，三爵之後，禮所不諱，陛下猥發雷霆，謂之輕慢，飲之醇酒，中毒隕命。自是之後，海內悼心，朝臣失圖，仕者以退爲幸，居者以出爲福，誠非所以保光洪緒，熈隆道化也。

**釋讀** 能興國的君主願聞過失，日益改過而有福。荒亂之主好聽讚譽，愛聽讚譽則日益敗壞而招禍。古代君主禮讓延賢，虛心求過，把帝位視為難以駕馭、須如履虎尾。孫皓卻以刑法阻塞直言、貶黜善士，使近臣混淆是非。商高宗思慕輔臣，夢中求得賢人。孫皓把賢士忘在一旁，王蕃忠敬盡職、有輔政才，竟因酒醉被殺。老臣葛奚醉後偶失言，古禮三爵後不責怪醉語，孫皓卻怒其輕慢，命飲烈酒，葛奚中毒而死。此後朝臣無所措手，已任官者幸能退下，任職者有幸外出方得避禍。

**歸年** 是此疏所舉的前事。[王蕃之死](../ce-0201-0300/ce-0266.md#sg-note-6)在266年，葛奚之死只知在疏前。此處保留賀邵借兩人勸諫的完整原意。

<a id="sgz065-b-3049-1"></a>

<a id="wu065-l31-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l31-1)** · [TXT L31](../../拆分史书/三国志/卷065.txt#L31)

> 又何定本趨走小人，僕隷之下，身無錙銖之行，能無鷹犬之用，而陛下愛其佞媚，假其威柄，使定恃寵放恣，自擅威福，口正國議，手弄天機，上虧日月之明，下塞君子之路。夫小人求入，必進姦利，定間妄興事役，發江邊戍兵以驅麋鹿，結罝山陵，芟夷林莽，殫其九野之獸，聚其重圍之內，上無益時之分，下有損耗之費。而兵士罷於運送，人力竭於驅逐，老弱饑凍，大小怨歎。臣竊觀天變，自比年以來陰陽錯謬，四時逆節，日食地震，中夏隕霜，參之典籍，皆陰氣陵陽，小人弄勢之所致也。臣甞覽書傳，驗諸行事，災祥之應，所爲寒慄。昔高宗脩己以消鼎雉之異，宋景崇德以退熒惑之變，願陛下上懼皇天譴告之誚，下追二君攘災之道，遠覽前代任賢之功，近寤今日謬授之失，清澄朝位，旌叙俊乂，放退佞邪，抑奪姦勢，如是之輩，一勿復用，廣延淹滯，容受直辭，祗承乾指，敬奉先業，則大化光敷，天人望塞也。

**釋讀** 何定原是供人奔走的下役，既無德行，也無可用的才力。孫皓喜其逢迎而委以權柄，致使他擅自號令賞罰、操弄國事，蒙蔽君主，壅塞正士。他調江邊戍卒圍獵，遍設網罟、鏟去草木，聚獸於重圍之內，徒耗人力物力。士卒運輸疲憊，勞力用於逐獸，老弱飢寒，人人怨嘆。賀邵依災異說，把近年的日食、地震和夏霜歸於小人弄權，舉商高宗修德止雉異、宋景公以德退熒惑，勸孫皓敬畏天戒，汲取古人用賢的教訓，整治朝廷，罷黜佞臣，招用沉滯之士並容納直言，延續先業。

**歸年** 此段隨上疏繫272年。[何定往夏口出獵](../ce-0201-0300/ce-0270.md#sg-note-5)見於270年，[何定伏誅](../ce-0201-0300/ce-0272.md#sgz-note-9)在疏後。日食、地震、降霜在此為論政所舉，原疏沒有逐項年月。

<a id="sgz065-b-3050-1"></a>

<a id="wu065-l33-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l33-1)** · [TXT L33](../../拆分史书/三国志/卷065.txt#L33)

> 傳曰：「國之興也，視民如赤子；其亡也，以民爲草芥。」陛下昔韜神光，潛德東夏，以聖哲茂姿，龍飛應天，四海延頸，八方拭目，以成康之化必隆於旦夕也。自登位以來，法禁轉苛，賦調益繁；中宮內豎，分布州郡，橫興事役，競造姦利；百姓罹杼軸之困，黎民罷無已之求，老幼饑寒，家戶菜色，而所在長吏，迫畏罪負，嚴法峻刑，苦民求辦。是以人力不堪，家戶離散，呼嗟之聲，感傷和氣。又江邊戍兵，遠當以拓土廣境，近當以守界備難，宜特優育，以待有事，而徵發賦調，煙至雲集，衣不全短褐，食不贍朝夕，出當鋒鏑之難，入抱無聊之慼。是以父子相棄，叛者成行。願陛下寬賦除煩，振恤窮乏，省諸不急，盪禁約法，則海內樂業，大化普洽。夫民者國之本，食者民之命也，今國無一年之儲，家無經月之畜，而後宮之中坐食者萬有餘人。內有離曠之怨，外有損耗之費，使庫廩空於無用，士民饑於糟糠。

**釋讀** 賀邵援引古語，國興時視民如子，國亡時視民如草芥。孫皓在東土未登位時德聲內藏，登位時天下有望，近來卻法禁愈苛、賦調愈密，內侍分赴州郡興役取利。百姓家無餘糧，疲於應付無休止的索取，長吏為免獲罪又以嚴刑催辦，使民戶離散。江邊戍兵本應優恤，以備出擊或守邊，卻徵發湧至、衣食不足，出則冒兵矢，入則生計無著，竟至父子相棄、叛逃成行。他請求寬免賦役，賑濟貧民，省去急務之外的差役，減除苛禁。國以民為本，民以食為命，而國家儲糧不足一年、民家存糧不足一月，後宮仰食者逾萬人，宮外耗費巨大，國庫空而士民無食。

**歸年** 是此疏所陳民力與用度之弊。[《通鑑》卷079](../../史书/025-资治通鉴/KR2b0007_079.txt#L715-L722)有節錄，儲糧與後宮數目是賀邵在奏疏中所陳。

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l35-1)** · [TXT L35](../../拆分史书/三国志/卷065.txt#L35)

> 又北敵注目，伺國盛衰，陛下不恃己之威德，而怙敵之不來，忽四海之困窮，而輕虜之不爲難，誠非長策廟勝之要也。昔大皇帝勤身苦體，創基南夏，割據江山，拓土萬里，雖承天贊，實由人力也。餘慶遺祚，至於陛下，陛下宜勉崇德器，以光前烈，愛民養士，保全先軌，何可忽顯祖之功勤，輕難得之大業，忘天下之不振，替興衰之巨變哉？臣聞否泰無常，吉凶由人，長江之限不可乆恃，苟我不守，一葦可航也。昔秦建皇帝之號，據殽函之阻，德化不脩，法政苛酷，毒流生民，忠臣杜口，是以一夫大呼，社稷傾覆。近劉氏據三關之險，守重山之固，可謂金城石室，萬世之業，任授失賢，一朝喪沒，君臣係頸，共爲羈僕。此當世之明鑒，目前之烱戒也。願陛下遠考前事，近鑒世變，豐基彊本，割情從道，則成康之治興，聖祖之祚隆矣。

**釋讀** 北方敵國正看著吳國的盛衰，孫皓卻不修威德、自恃敵不來，也輕忽天下的窮困。孫權辛勤開創江南基業，雖說有天意，實賴人力。後人應崇德愛民、養士，保全這份來之不易的基業。吉凶由人，江險不可常恃，若無守備，一葉葦筏也可渡江。秦據殽函，因法政酷烈、忠臣絕言，一呼便亡。蜀有關山之險，因用人失當，朝夕間君臣就作俘虜。賀邵勸孫皓借鑒古今，充實國家根本，節制私欲而循正道，以延續孫權所建的王業。

**歸年** 此為原疏末段。秦亡及[蜀漢亡國](../ce-0201-0300/ce-0263.md#sg-note-6)為歷史借鑒，段落隨賀邵奏疏。[《通鑑》卷079](../../史书/025-资治通鉴/KR2b0007_079.txt#L721-L725)節錄江防及養民之論。

### 8. 陆抗疏请停小规模进兵

<a id="sgz058-b-2808-1"></a>

<a id="sgz058-b-2808-2"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l85-1)** · [TXT L85](../../拆分史书/三国志/卷058.txt#L85)

> 時師旅仍動，百姓疲弊，抗上疏曰：「臣聞易貴隨時，傳美觀釁，故有夏多罪而殷湯用師，紂作淫虐而周武授鉞。苟無其時，玉臺有憂傷之慮，孟津有反旆之軍。今不務富國彊兵，力農畜穀，使文武之才效展其用，百揆之署無曠厥職，明黜陟以厲庶尹，審刑賞以示勸沮，訓諸司以德，而撫百姓以仁，然後順天乘運，席卷宇內，而聽諸將徇名，窮兵黷武，動費萬計，士卒彫瘁，寇不爲衰，而我已大病矣！今爭帝王之資，而昧十百之利，此人臣之姦便，非國家之良策也。昔齊魯三戰，魯人再克而亡不旋踵。何則？大小之勢異也。況今師所克獲，不補所喪哉？且阻兵無衆，古之明鑒，誠宜蹔息進取小規，以畜士民之力，觀釁伺隙，庶無悔吝。」

**釋讀** 陸抗說兵事須有時機，應務農積穀、發揮人才、嚴明官員陟罰與軍民賞刑。他譏諸將為小利求戰，損失難以抵償，舉弱魯雖多次勝齊而終亡為戒，勸朝廷暫停小規模進取、養民候變。

**歸年** [《資治通鑑》卷079](../../史书/025-资治通鉴/KR2b0007_079.txt#L744-L753)繫於272年，記孫皓未從。

### 9. 陆抗与羊祜交好

[返回正文第9条](#sgz-event-12)

<a id="sgz058-p-012-1"></a>

<a id="wu058-l81-1"></a>

**[《三國志·陸遜傳》裴注 012](../../拆分史书/三国志/卷058.md#edition-wu058-l81-1)** · [TXT L81](../../拆分史书/三国志/卷058.txt#L81)

> 晉陽秋曰：抗與羊祜推僑、札之好。抗嘗遺祜酒，祜飲之不疑。抗有疾，祜饋之藥，抗亦推心服之。于時以爲華元、子反復見於今。

**釋讀** 《晉陽秋》以子產（僑）、季札的友好比陸抗與羊祜，記陸抗送酒、羊祜送藥，彼此不疑，時人比作春秋時華元與子反。

**歸年** [《資治通鑑》卷079](../../史书/025-资治通鉴/KR2b0007_079.txt#L730-L743)隨西陵事後記兩將交往，贈酒、用藥沒有各自年月。

<a id="sgz058-p-012-2"></a>

<a id="wu058-l81-2"></a>

**[《三國志·陸遜傳》裴注 012](../../拆分史书/三国志/卷058.md#edition-wu058-l81-2)** · [TXT L81](../../拆分史书/三国志/卷058.txt#L81)

> 　漢晉春秋曰：羊祜旣歸，增脩德信，以懷吳人。陸抗每告其邊戍曰：「彼專爲德，我專爲暴，是不戰而自服也。各保分界，無求細益而已。」於是吳、晉之間，餘糧栖畝而不犯，牛馬逸而入境，可宣告而取也。沔上獵，吳獲晉人先傷者，皆送而相還。

**釋讀** 羊祜還軍後以德信招懷吳人，陸抗告誡邊吏只守界，不貪小利。兩國士民不侵田糧，逸出牛馬可告取，打獵時先為對方所傷之獸也會送還。

**歸年** 《漢晉春秋》以「羊祜旣歸」承西陵退兵，交往做法非一日之事。

<a id="sgz058-p-012-3"></a>

<a id="wu058-l81-3"></a>

**[《三國志·陸遜傳》裴注 012](../../拆分史书/三国志/卷058.md#edition-wu058-l81-3)** · [TXT L81](../../拆分史书/三国志/卷058.txt#L81)

> 抗嘗疾，求藥於祜，祜以成合與之，曰：「此上藥也，近始自作，未及服，以君疾急，故相致。」抗得而服之，諸將或諫，抗不荅。

**釋讀** 陸抗病中向羊祜求藥，羊祜送自己新合尚未服用的藥，陸抗服用。部分將領勸阻，陸抗沒有應答。

**歸年** 《漢晉春秋》補求藥、贈藥細節，未指明是哪一次病，也無年月。

<a id="sgz058-p-012-4"></a>

<a id="wu058-l81-4"></a>

**[《三國志·陸遜傳》裴注 012](../../拆分史书/三国志/卷058.md#edition-wu058-l81-4)** · [TXT L81](../../拆分史书/三国志/卷058.txt#L81)

> 孫皓聞二境交和，以詰於抗，抗曰：「夫一邑一鄉，不可以無信義之人，而況大國乎？臣不如是，正足以彰其德耳，於祜無傷也。」或以祜、抗爲失臣節，兩譏之。

**釋讀** 孫皓質疑兩境交好。陸抗說鄉里與大國都不可無信義，若吳失信，只會襯出羊祜的聲望。也有人批評兩將有失臣節。

**歸年** 承接兩國邊民與將領交往問題，原文保留反對者的評語。孫皓質詢日月未載。

<a id="wu058-l81-5"></a>

**[《三國志·陸遜傳》裴注 012](../../拆分史书/三国志/卷058.md#edition-wu058-l81-5)** · [TXT L81](../../拆分史书/三国志/卷058.txt#L81)

> 　習鑿齒曰：夫理勝者天下之所保，信順者萬人之所宗，雖大猷旣喪，義聲乆淪，狙詐馳於當塗，權略周乎急務，負力從橫之人，臧獲牧豎之智，未有不憑此以創功，捨茲而獨立者也。是故晉文退舍，而原城請命；穆子圍鼓，訓之以力；冶夫獻策，而費人斯歸；樂毅緩攻，而風烈長流。觀其所以服物制勝者，豈徒威力相詐而已哉！自今三家鼎足四十有餘年矣，吳人不能越淮、沔而進取中國，中國不能陵長江以爭利者，力均而智侔，道不足以相傾也。夫殘彼而利我，未若利我而無殘；振武以懼物，未若德廣而民懷。匹夫猶不可以力服，而況一國乎？力服猶不如以德來，而況不制乎？是以羊祜恢大同之略，思五兵之則，齊其民人，均其施澤，振義網以羅彊吳，明兼愛以革暴俗，易生民之視聽，馳不戰乎江表。故能德音恱暢，而襁負雲集，殊鄰異域，義讓交弘，自吳之遇敵，未有若此者也。抗見國小主暴，而晉德彌昌，人積兼己之善，而己無固本之規，百姓懷嚴敵之德，闔境有棄主之慮，思所以鎮定民心，緝寧外內，奮其危弱，抗權上國者，莫若親行斯道，以侔其勝。使彼德靡加吾，而此善流聞，歸重邦國，弘明遠風，折衝於枕席之上，校勝於帷幄之內，傾敵而不以甲兵之力，保國而不浚溝池之固，信義感於寇讎，丹懷體於先日。豈設狙詐以危賢，徇己身之私名，貪外物之重我，闇服之而不備者哉！由是論之，苟守局而保疆，一卒之所能；協數以相危，小人之近事；積詐以防物，臧獲之餘慮；威勝以求安，明哲之所賤。賢人君子所以拯世垂範，舍此而取彼者，其道良弘故也。

**釋讀** 習鑿齒舉晉文退舍、叔孫穆子圍鼓、冶夫獻策及樂毅緩攻，說明取勝亦可依靠信義。吳晉對立，羊祜藉施惠收人心，陸抗因吳勢弱，主動以信用安內、防邊，以免吳民因仰慕晉而背離。習鑿齒認為二人的做法比守險、用詐或恃武求安深遠。

**歸年** 後人綜論兩境之事。原位接在上述贈酒、用藥與交往異議之後，整段附讀。

**异文与补证** 《晋阳秋》以季札、子产相比，又载时人以华元、子反相比。馈赠的具体年月未详。

1. **陆抗拜大司马，司徒丁固去世。** 凤皇二年三月，陆抗在任所拜大司马，兼领荆州牧。司徒丁固在本年去世，享年七十六。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓封诸王并授兵。** 改淮阳王为鲁王，改东平王为齐王，又增封九王，各授三千兵。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **司市中郎将陈声被杀。** 陈声依法约束孙皓宠妾派去抢掠的人员；孙皓借他事处死陈声。 [[3]](#sg-note-3)

4. **孙皓下狱并杀韦曜，华覈上疏营救。** 韦曜掌管国史时，孙皓要替父亲孙和作本纪。韦曜认为孙和未即帝位，应当写列传。他也质疑各地报来的祥瑞。韦曜饮酒量小，受礼遇时，孙皓曾暗中赐茶代酒。后来韦曜屡被强饮，又不肯奉命在宴后讥嘲公卿，只借经义相问。孙皓积怨，凤皇二年把韦曜下狱。韦曜托狱吏上书，请朝廷取阅《洞纪》《官职训》《辩释名》。孙皓反因书稿污损责问他。华覈多次上疏，将韦曜比作司马迁，请免其死罪，使他完成尚缺叙赞的《吴书》。孙皓没有同意，杀韦曜，将其家属迁往零陵。 [[4]](#sgz-note-4)

<a id="sgz-event-8"></a>

5. **吴太尉范慎去世。** 吴太尉范慎去世，其子范耀后来继嗣。卒年另有[274年一说](ce-0274.md#sgz-note-7)。 [[5]](#sgz-note-8)

<a id="sgz-event-9"></a>

6. **司马炎授邓艾嫡孙邓朗郎中。** 诏称邓艾有功，怜其子孙长期处于民隶。 [[6]](#sgz-note-9)

### 4. 孙皓下狱并杀韦曜，华覈上疏营救

[返回正文第4条](#sgz-event-4)

<a id="wu065-l56-2"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l56-2)** · [TXT L56](../../拆分史书/三国志/卷065.txt#L56)

> 職省，爲侍中，常領左國史。

**釋讀** 中書僕射一職被裁省後，韋曜改任侍中，仍兼掌左國史。

**歸年** 264年孫皓即位後、273年獄案前，改任無確年，附記事所繫當年的案前經過。

<a id="wu065-l56-3"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l56-3)** · [TXT L56](../../拆分史书/三国志/卷065.txt#L56)

> 時所在承指數言瑞應。皓以問曜，曜荅曰：「此人家筐篋中物耳。」又皓欲爲父和作紀，曜執以和不登帝位，宜名爲傳。如是者非一，漸見責怒。

**釋讀** 地方見風使舵，頻報祥瑞。孫皓問韋曜，韋曜說這只是人家竹箱中的物件。孫皓又想為父親孫和作本紀，韋曜認為未登帝位，史書當用列傳。類似的事一再發生，韋曜漸遭責怒。

**歸年** 附273年韋曜獄案。孫皓264年追尊父親，何時命作本紀未載。[《通鑑》卷080](../../史书/025-资治通鉴/KR2b0007_080.txt#L41-L56)同於獄案前總敘舊事。

<a id="wu065-l56-4"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l56-4)** · [TXT L56](../../拆分史书/三国志/卷065.txt#L56)

> 曜益憂懼，自陳衰老，求去侍、史二官，乞欲成所造書，以從業別有別付，皓終不聽。時有疾病，醫藥監護，持之愈急。

**釋讀** 韋曜愈加憂怕，自陳年老，想卸下侍中與國史兩職以完成正在寫作的史書，孫皓不准。韋曜染病，孫皓派人監護醫藥，管束更嚴。

**歸年** 請解職、病中受監無確年，附273年案前經過。底本「以從業別有別付」文義不明，照錄。

<a id="wu065-l58-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l58-1)** · [TXT L58](../../拆分史书/三国志/卷065.txt#L58)

> 皓每饗宴，無不竟日，坐席無能否率以七升爲限，雖不悉入口，皆澆灌取盡。曜素飲酒不過二升，初見禮異時，常爲裁減，或密賜茶荈以當酒，至於寵衰，更見偪彊，輒以爲罪。

**釋讀** 孫皓宴飲常終日，每人定為七升，即使沒有全喝下，也要灌酒到用盡定額。韋曜平時只飲得兩升，受禮遇時常獲減量，有時秘密賜茶代酒。後來失寵，屢被強飲並以此獲罪。

**歸年** 本傳回述韋曜由受禮到失寵的經過，未記茶代酒的確年，附273年獄案。

<a id="wu065-l58-2"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l58-2)** · [TXT L58](../../拆分史书/三国志/卷065.txt#L58)

> 又於酒後使侍臣難折公卿，以嘲弄侵克，發摘私短以爲歡。時有愆過，或誤犯皓諱，輒見收縛，至於誅戮。曜以爲外相毀傷，內長尤恨，使不濟濟，非佳事也，故但示難問經義言論而已。

**釋讀** 孫皓酒後命侍臣折難公卿，揭人短處取樂，有過失或觸犯名諱者就被捆縛，甚至遭殺。韋曜認為此舉公開傷人，暗中滋長怨恨，使滿朝不和，便只用經義難問。

**歸年** 為下文孫皓認定韋曜未奉詔命的前因，單次宴會無確年。

<a id="sgz065-b-3060-6"></a>

<a id="wu065-l58-3"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l58-3)** · [TXT L58](../../拆分史书/三国志/卷065.txt#L58)

> 皓以爲不承用詔命，意不忠盡，遂積前後嫌忿，收曜付獄，是歲鳳皇二年也。

**釋讀** 孫皓認為韋曜不奉行命令、未盡忠誠，累積之前的嫌怨，遂下韋曜於獄。

**歸年** 本傳明記鳳皇二年，與《通鑑》泰始九年相合。

<a id="sgz065-b-3061-1"></a>

<a id="sgz065-b-3062-1"></a>

<a id="wu065-l60-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l60-1)** · [TXT L60](../../拆分史书/三国志/卷065.txt#L60)

> 曜因獄吏上辭曰：「囚荷恩見哀，無與爲比，曾無芒氂有以上報，孤辱恩寵，自陷極罪。念當灰滅，長棄黃泉，愚情慺慺，竊有所懷，貪令上聞。囚昔見世間有古歷注，其所紀載旣多虛無，在書籍者亦復錯謬。囚尋按傳記，考合異同，采摭耳目所及，以作洞紀，起自庖犧，至於秦、漢，凡爲三卷，當起黃武以來，別作一卷，事尚未成。又見劉熙所作釋名，信多佳者，然物類衆多，難得詳究，故時有得失，而爵位之事，又有非是。愚以官爵，今之所急，不宜乖誤。囚自忘至微，又作官職訓及辯釋名各一卷，欲表上之。新寫始畢，會以無狀，幽囚待命，泯沒之日，恨不上聞，謹以先死列狀，乞上言祕府，於外料取，呈內以聞。追懼淺蔽，不合天聽，抱怖雀息，乞垂哀省。」

**釋讀** 韋曜托獄吏上辭，自稱受厚恩卻無以報答，臨死想留下著述。他見舊曆注和書籍記載多有虛妄或錯誤，便考合傳記異同及所得見聞，作《洞紀》三卷，自庖犧至秦漢，還想另寫吳黃武以後的一卷，未能完稿。他認為劉熙《釋名》有可取，卻不能詳考各類事物，尤其爵位一項有誤，遂撰《官職訓》《辯釋名》各一卷。兩書謄寫完便遭拘繫，請秘府在外收取，呈皇帝閱覽。

**歸年** 本傳接鳳皇二年下獄之事，呈文有此年依據，三書的撰寫起訖未逐一載明。

<a id="sgz065-b-3063-1"></a>

<a id="wu065-l62-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l62-1)** · [TXT L62](../../拆分史书/三国志/卷065.txt#L62)

> 曜兾以此求免，而皓更怪其書之垢，故又以詰曜。曜對曰：「囚撰此書，實欲表上，懼有誤謬，數數省讀，不覺點污。被問寒戰，形氣吶吃。謹追辭叩頭五百下，兩手自搏。」

**釋讀** 韋曜希望以獻書求免，孫皓反因書稿污舊而責問。韋曜說他本想把書呈上，唯恐錯謬，反覆省讀而不覺沾污，受問之時寒戰口吃，遂補呈書辭，叩頭五百下，以手自打。

**歸年** 接鳳皇二年獄中獻書。

<a id="sgz065-b-3064-1"></a>

<a id="wu065-l62-2"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l62-2)** · [TXT L62](../../拆分史书/三国志/卷065.txt#L62)

> 而華覈連上疏救曜曰：「曜運值千載，特蒙哀識，以其儒學，得與史官，貂蟬內侍，承荅天問，聖朝仁篤，慎終追遠，迎神之際，垂涕勑曜。曜愚惑不達，不能敷宣陛下大舜之美，而拘繫史官，使聖趣不叙，至行不彰，實曜愚蔽當死之罪。然臣慺慺，見曜自少勤學，雖老不倦，探綜墳典，溫故知新，及意所經識古今行事，外吏之中少過曜者。昔李陵爲漢將，軍敗不還而降匈奴，司馬遷不加疾惡，爲陵遊說，漢武帝以遷有良史之才，欲使畢成所撰，忍不加誅，書卒成立，垂之無窮。今曜在吳，亦漢之史遷也。伏見前後符瑞彰著，神指天應，繼出累見，一統之期，庶不復乆。

**釋讀** 華覈連疏求救。他先說韋曜以儒學掌史、備顧問，未能彰明皇帝迎神時垂涕追思的孝行，已觸重罪。繼而稱韋曜從小好學，博通典籍，熟悉古今行事，外朝官員很少能勝過他。華覈援引漢武帝留司馬遷性命使其成書的例子，說韋曜是東吳的司馬遷，並以屢見祥瑞表達天下將一統的期許。

**歸年** 鳳皇二年獄案中的救援奏疏，漢武帝、司馬遷等舊事是華覈用來勸說的例證。

<a id="sgz065-b-3065-1"></a>

<a id="wu065-l62-3"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l62-3)** · [TXT L62](../../拆分史书/三国志/卷065.txt#L62)

> 事平之後，當觀時設制，三王不相因禮，五帝不相沿樂，質文殊塗，損益異體，宜得曜輩依準古義，有所改立。漢氏承秦，則有叔孫通定一代之儀，曜之才學亦漢通之次也。又吳書雖已有頭角，叙贊未述。昔班固作漢書，文辭典雅，後劉珍、劉毅等作漢記，遠不及固，叙傳尤劣。今吳書當垂千載，編次諸史，後之才士論次善惡，非得良才如曜者，實不可使闕不朽之書。如臣頑蔽，誠非其人。

**釋讀** 華覈認為天下平定後應因時立禮樂，三王五帝的禮樂原本各有損益，韋曜能像叔孫通一樣參酌古義、制定新制。《吳書》已有輪廓，卻還沒寫敘贊。班固所作《漢書》文雅，劉珍、劉毅等的《漢記》則遠不及，敘傳尤劣。《吳書》要長傳後世，需要如韋曜般能論次善惡的史才，華覈自認不能勝任。

**歸年** 同一份救援奏疏。

<a id="sgz065-b-3066-1"></a>

<a id="wu065-l62-4"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l62-4)** · [TXT L62](../../拆分史书/三国志/卷065.txt#L62)

> 曜年已七十，餘數無幾，乞赦其一等之罪，爲終身徒，使成書業，永足傳示，垂之百世。謹通進表，叩首百下。」

**釋讀** 華覈陳稱韋曜已七十歲、餘年無多，請減死一等、改為終身徒刑，讓他可以完成史書，傳下百世。

**歸年** 七十是華覈疏所陳年齡，不能據此認定生辰。

> 皓不許，遂誅曜，徙其家零陵。

**釋讀** 孫皓不允華覈所請，殺韋曜，把他的家屬遷往零陵。

**歸年** 本傳接鳳皇二年下獄，未載處決月日。[《通鑑》卷080](../../史书/025-资治通鉴/KR2b0007_080.txt#L54-L57)同繫273年。

### 5. 吴太尉范慎去世

[返回正文第5条](#sgz-event-8)

<a id="sgz048-b-2367-4"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2367-4)** · [TXT L119](../../拆分史书/三国志/卷048.txt#L119)

> 是歲，太尉范慎卒。

**吴太尉范慎去世** 范慎于同年卒。

**归年依据** 本传凤凰二年。



<a id="wu059-l8-4"></a>

**[《三國志·吳主五子傳》裴注 002](../../拆分史书/三国志/卷059.md#edition-wu059-l8-4)** · [TXT L8](../../拆分史书/三国志/卷059.txt#L8)

> 鳳凰三年卒，子耀嗣。

**釋讀** 《吳錄》作范慎鳳凰三年卒，兒子范耀承嗣。

**歸年** 卷048《孫皓傳》於鳳凰二年記「是歲，太尉范慎卒」。《吳錄》作三年，對應274年。兩說同指一人一事，合附本紀所載273年條，范耀承嗣的具體年月不詳。

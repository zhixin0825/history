# 公元274年｜晋泰始十年／吴凤凰三年

[← 公元273年](ce-0273.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元275年 →](ce-0275.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **陈寿进《诸葛氏集》。** 陈寿奉晋廷命分类编订诸葛亮文书，晋泰始十年二月呈进。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **会稽传孙奋将立，郭诞、奚熙被追究。** 何氏外戚势重，民间流传孙皓已经死去、由何氏子顶替，又有会稽将拥立孙奋之说。郭诞只上报奚熙的书信，未报拥立传闻，因而获罪。功曹邵畴欲承担责任，自尽，郭诞获免死，被发往建安造船。奚熙发兵拒捕，最终被杀。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **吴分遣使者核查逃亡叛离。** 七月遣使二十五人赴州郡核查逃亡、叛离。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **陆抗病中上疏论西线防务，秋季去世。** 夏，陆抗病重，上疏说晋军若顺江疾进，西陵、建平难以及时得到外援。陆逊也曾说西陵是吴国西门，失之则荆州难保。陆抗先前请求三万精兵没有获准，西陵战后兵力又有损耗。他请求召回依附宦官占募的逃兵，补足西线所部到八万人，并请自己死后仍以防守西方为重。秋，陆抗去世，陆晏袭爵，和弟弟陆景、陆玄、陆机、陆云分领父兵。[晋军顺江东下见280年](ce-0280.md#sg-note-1)。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **吴疫病延续，分鬱林置桂林郡。** 改元以来连年大疫，这一年从鬱林分设桂林郡。 [[5]](#sg-note-5)

<a id="sgz-event-6"></a>

6. **曹芳去世，谥邵陵厉公。** 西晋邵陵公曹芳去世，谥厉公。 [[6]](#sgz-note-6)

<a id="sgz-event-8"></a>

7. **鲁淑死，鲁睦继爵领兵。** 鲁淑去世，其子鲁睦继侯、领其部兵。 [[7]](#sgz-note-8)

### 1. 陈寿进《诸葛氏集》

[返回正文第1条](#sg-event-1)

<a id="sg035-l1782-e1"></a>

**[《三国志·诸葛亮传》](../../sources/本地分卷/三国志/三国志-卷035.md#p005)** · [仓内TXT L1782](../../sources/本地分卷/三国志/三国志-卷035.md#l1782)

> 泰始十年二月一日癸巳，平陽侯相臣陳壽上。

<a id="sgz035-b-1777-1"></a>

**[《三国志·诸葛亮传》仓内原文 L1777](../../sources/本地分卷/三国志/三国志-卷035.md#l1777)**

> 諸葛氏集目錄：開府作牧第一 權制第二 南征第三 北出第四 計算第五 訓厲第六 綜覈上第七 綜覈下第八 雜言上第九雜言第十 貴和第十一 兵要第十二 傳運第十三 與孫權書第十四 與諸葛謹書第十五 與孟達書第十六 廢李平第十七 法檢上第十八 法檢下第十九 科令上第二十 科令下第二十一 軍令上第二十二 軍令中第二十三 軍令下第二十四，右二十四篇，凡十萬四千一百一十二字。

**释读** 所进全书二十四篇，从开府、征伐、书札到科令军令，原记十万四千一百一十二字。

**归年** 次后上表尾署泰始十年二月一日，目录为所附同年文书。

<a id="sgz035-b-1778-1"></a>

**[《三国志·诸葛亮传》仓内原文 L1778](../../sources/本地分卷/三国志/三国志-卷035.md#l1778)**

> 臣壽等言：臣前在著作郎，侍中領中書監濟北侯臣荀勖、中書令關內侯臣和嶠奏：使臣定故蜀丞相諸葛亮故事。亮毗佐危國，負阻不賓，然猶存錄其言，恥善有遺，誠是大晉光明至德，澤被無疆，自古以來，未有之倫也。輒刪除複重，隨類相從，凡為二十四篇。篇名如右。

**释读** 荀勖、和峤奏命编定事文。陈寿感称晋保留异国文书，说明去重分类，编为二十四篇。

**归年** 泰始十年奏；所受命年份未在前句另标，不把编纂全程简单等同奏上日。

<a id="sgz035-b-1779-1"></a>

**[《三国志·诸葛亮传》仓内原文 L1779](../../sources/本地分卷/三国志/三国志-卷035.md#l1779)**

> 亮少有逸眾之才，英霸之器，身長八尺，容貌甚偉，時人異焉。造漢末亂，隨叔父玄避難荊州，躬耕于野，不求聞達。時左將軍劉備以亮有殊量，乃三顧亮於草廬之中﹔亮深謂備雄姿傑出，遂解帶寫誠，厚相結納。

**释读** 述诸葛亮才貌、随叔父入荆州躬耕，刘备三顾后诸葛亮尽诚响应。

**归年** 表作于274年，汉末旧事另系相应正文。

<a id="sgz035-b-1779-2"></a>

**[《三国志·诸葛亮传》仓内原文 L1779](../../sources/本地分卷/三国志/三国志-卷035.md#l1779)**

> 及魏武帝南征荊州，劉琮舉州委質，而備失勢眾寡，無立錐之地。亮時年二十七，乃建奇策，身使孫權，求援吳會。權既宿服仰備，又觀亮奇雅，甚敬重之，即遣兵三萬以助備。備得用與武帝交戰，大破其軍，乘勝克捷，江南悉平。後備又西取益州。益州既定，以亮為軍師將軍。

**释读** 曹操取荆州后诸葛亮赴吴求援，孙权遣兵助刘备，破曹军并取江南；后取益州，任诸葛亮军师将军。

**归年** 同一274年表；出使和赤壁在208年，平蜀在214年。

<a id="sgz035-b-1779-3"></a>

**[《三国志·诸葛亮传》仓内原文 L1779](../../sources/本地分卷/三国志/三国志-卷035.md#l1779)**

> 備稱尊號，拜亮為丞相，錄尚書事。及備殂沒，嗣子幼弱，事無巨細，亮皆專之。於是外連東吳，內平南越，立法施度，整理戎旅，工械技巧，物究其極，科教嚴明，賞罰必信，無惡不懲，無善不顯，至於吏不容奸，人懷自厲，道不拾遺，彊不侵弱，風化肅然也。

**释读** 述刘备称帝任丞相，刘备死后托政，以外联、平南、修法、军备和奖惩教化的成效为例。

**归年** 同一274年表；所述221至225年相应史事另标。

<a id="sgz035-b-1780-1"></a>

**[《三国志·诸葛亮传》仓内原文 L1780](../../sources/本地分卷/三国志/三国志-卷035.md#l1780)**

> 當此之時，亮之素志，進欲龍驤虎視，包括四海，退欲跨陵邊疆，震蕩宇內。又自以為無身之日，則未有能蹈涉中原、抗衡上國者，是以用兵不戢，屢耀其武。然亮才，於治戎為長，奇謀為短，理民之干，優於將略。而所與對敵，或值人傑，加眾寡不侔，攻守異體，故雖連年動眾，未能有克。昔蕭何荐韓信，管仲舉王子城父，皆忖己之長，未能兼有故也。亮之器能政理，抑亦管、蕭之亞匹也，而時之名將無城父、韓信，故使功業陵遲，大義不及邪？蓋天命有歸，不可以智力爭也。

**释读** 称其用兵连年以定边、抗魏，治军与理民胜于奇谋将略；胜少亦缘对手、兵力与攻守态势，并以管仲、萧何荐将为比。

**归年** 同一274年表文，史评不另定作诸葛亮在世某年。

<a id="sgz035-b-1781-1"></a>

**[《三国志·诸葛亮传》仓内原文 L1781](../../sources/本地分卷/三国志/三国志-卷035.md#l1781)**

> 青龍二年春，亮帥眾出武功，分兵屯田，為久駐之基。其秋病卒，黎庶追思，以為口實。至今梁、益之民，咨述亮者，言猶在耳，雖甘棠之詠召公，鄭人之歌子產，無以遠譬也。孟軻有云：「以逸道使民，雖勞不怨﹔以生道殺人，雖死不忿。」信矣！

**释读** 称青龙二年屯田武功、秋卒，百姓追念如爱召公、子产，借孟子论合理为政。

**归年** 表文系274，五丈原卒实为234年。

<a id="sgz035-b-1781-2"></a>

**[《三国志·诸葛亮传》仓内原文 L1781](../../sources/本地分卷/三国志/三国志-卷035.md#l1781)**

> 論者或怪亮文彩不艷，而過於丁寧周至。臣愚以為咎繇大賢也，周公聖人也，考之尚書，咎繇之謨略而雅，周公之誥煩而悉。何則？咎繇與舜、禹共談，周公與群下矢誓故也。亮所與言，盡眾人凡士，故其文指不得及遠也。然其聲教遺言，皆經事綜物，公誠之心，形於文墨，足以知其人之意理，而有補於當世。

**释读** 有人嫌文辞不华，陈寿比皋陶言与周公告诰，说明对象不同；诸葛亮文书周至、诚实，足为当世借鉴。

**归年** 同一274年表的论辩。

<a id="sgz035-b-1782-1"></a>

**[《三国志·诸葛亮传》仓内原文 L1782](../../sources/本地分卷/三国志/三国志-卷035.md#l1782)**

> 伏惟陛下邁蹤古聖，蕩然無忌，故雖敵國誹謗之言，咸肆其辭而無所革諱，所以明大通之道也。謹錄寫上詣著作。臣壽誠惶誠恐，頓首頓首，死罪死罪。泰始十年二月一日癸巳，平陽侯相臣陳壽上。

**释读** 赞晋帝不改避魏蜀敌对辞章。陈寿于泰始十年二月初一癸巳进书。

**归年** 本传明记泰始十年（274）呈进。

### 2. 会稽传孙奋将立，郭诞、奚熙被追究

[返回正文第2条](#sg-event-2)

**异文与补证** 孙奋及五子何时被诛，各书记载有异。《孙奋传》系于[270 年](ce-0270.md#sgz-note-9)，不等同于本条的会稽谣言；《资治通鉴》叙其死于本年，《通鉴考异》另录275年之说并未断定。

<a id="sgz048-b-2368-1"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sgz048-b-2368-1)** · [TXT L121](../../sources/本地分卷/三国志/三国志-卷048.txt#L121)

> 三年，會稽妖言章安侯奮當爲天子。臨海太守奚熈與會稽太守郭誕書，非論國政。誕但白熈書，不白妖言，送付建安作船。

**歸年** 本傳將郭誕、奚熙案列於鳳皇三年（274）。同題謠言也見《孫奮傳》，孫奮卒年異說見年頁正文。

<a id="sgz048-p-031-1"></a>

**[《三國志·三嗣主傳》 裴注 031·1](../../sources/本地分卷/三国志/三国志-卷048.md#pei-031-1)** · [TXT L122](../../sources/本地分卷/三国志/三国志-卷048.txt#L122)

> 會稽邵氏家傳曰：邵疇字溫伯，時爲誕功曹。誕被收，惶遽無以自明。疇進曰：「疇今自在，疇之事，明府何憂？」遂詣吏自列，云不白妖言，事由於己，非府君罪。吏上疇辭，皓怒猶盛。疇慮誕卒不免，遂自殺以證之。

**释读** 郭诞被收，功曹邵畴承认不报谣言是己见，以死自明。
**归年** 本传凤凰三年郭诞、奚熙案。仓TXT误夹此注段，仅注文全文系年。

<a id="sgz048-p-031-2"></a>

**[《三國志·三嗣主傳》 裴注 031·2](../../sources/本地分卷/三国志/三国志-卷048.md#pei-031-2)** · [TXT L122](../../sources/本地分卷/三国志/三国志-卷048.txt#L122)

> 臨亡，置辭曰：「疇生長邊陲，不閑教道，得以門資，厠身本郡，踰越儕類，位極朝右，不能贊揚盛化，養之以福。今妖訛橫興，干國亂紀，疇以噂𠴲之語，本非事實，雖家誦人詠，不足有慮。天下重器，而匹夫橫議，疾其醜聲，不忍聞見，欲含垢藏疾，不彰之翰筆，鎮躁歸靜，使之自息。愚心勤勤，每執斯旨，故誕屈其所是，默以見從。此之爲愆，實由於疇。謹不敢逃死，歸罪有司，唯乞天鑒，特垂清察。」吏收疇喪，得辭以聞，皓乃免誕大刑，送付建安作船。疇亡時，年四十。皓嘉疇節義，詔郡縣圖形廟堂。

**释读** 邵畴遗言称民间谣言不足惊国，郭诞从其见，自己愿负罪。孙皓减郭诞死罪，仍送去造船，又命为邵畴绘像。
**归年** 274同案，图字据对校解释。

<a id="sgz048-b-2368-3"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sgz048-b-2368-3)** · [TXT L123](../../sources/本地分卷/三国志/三国志-卷048.txt#L123)

> 遣三郡督何植收熈，熈發兵自衞，斷絕海道。熈部曲殺熈，送首建業，夷三族。

**奚熙举兵拒捕，被部下所杀** 吴遣三郡督何植拘奚熙，奚熙发兵断绝海道，被部曲所杀，首送建业，夷三族。

**归年依据** 与凤凰三年奚熙、郭诞案同年同号。



<a id="wu050-l79-4"></a>

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l79-4)** · [TXT L79](../../sources/本地分卷/三国志/三国志-卷050.txt#L79)

> 吳末昬亂，何氏驕僭，子弟橫放，百姓患之。故民譌言「皓乆死，立者何氏子」云。

**釋讀** 何氏子弟橫行，民間訛傳孫皓已死、何氏子在位。

**歸年** 卷048及《資治通鑑》卷080繫奚熙案於274年。本傳概述流言背景，流言起時未明。

<a id="sgz050-p-019-4"></a>

<a id="wu050-l80-4"></a>

**[《三國志·妃嬪傳》裴注 018](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l80-4)** · [TXT L80](../../sources/本地分卷/三国志/三国志-卷050.txt#L80)

> 國人見葬太奢麗，皆謂皓已死，所葬者是也。皓舅子何都顏狀似皓，云都代立。臨海太守奚熈信譌言，舉兵欲還秣陵誅都，都叔父植時爲備海督，擊殺熈，夷三族，譌言乃息，而人心猶疑。

**釋讀** 何都面貌像孫皓，葬禮鋪張之後出現替立傳聞。奚熙信以為真，想往秣陵殺何都。《江表傳》將奚熙之死歸於何植。

**歸年** 《資治通鑑》卷080於鳳凰三年並敘流言與奚熙案，從奚熙部曲殺他。標點 TXT 作何植，舊引作何信。不同交戰經過均留於史料。

> 三年夏，疾病，上疏曰：「西陵、建平，國之蕃表，旣處下流，受敵二境。若敵汎舟順流，舳艫千里，星奔電邁，俄然行至，非可恃援他部以救倒縣也。此乃社稷安危之機，非徒封疆侵陵小害也。臣父遜昔在西垂陳言，以爲西陵國之西門，雖云易守，亦復易失。若有不守，非但失一郡，則荊州非吳有也。如其有虞，當傾國爭之。臣往在西陵，得涉遜迹，前乞精兵三萬，而主者循常，未肯差赴。自步闡以後，益更損耗。今臣所統千里，受敵四處，外禦彊對，內懷百蠻，而上下見兵財有數萬，羸弊日乆，難以待變。臣愚以爲諸王幼沖，未統國事，可且立傅相，輔導賢姿，無用兵馬，以妨要務。又黃門豎宦，開立占募，兵民怨役，逋逃入占。乞特詔簡閱，一切料出，以補疆埸受敵常處，使臣所部足滿八萬，省息衆務，信其賞罰，雖韓、白復生，無所展巧。若兵不增，此制不改，而欲克諧大事，此臣之所深慼也。若臣死之後，乞以西方爲屬。願陛下思覽臣言，則臣死且不朽。」

**釋讀** 陸抗病中上疏，指出西陵、建平都在晉軍順流而下的正面，事急時不能仰賴外援。他追述父親陸遜稱西陵是吳國西門，說先請三萬精兵未得，步闡戰後又有損耗。他請停派幼王領兵，查出投宦官占募的逃亡兵民補西疆，使所部達八萬，並望死後仍以西線為重。

**歸年** 鳳皇三年夏明文，接秋卒。疏中提到陸遜舊議、前請精兵及272步闡之役，均屬據以說明當下防務的回敘。

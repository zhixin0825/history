[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **陈寿进《诸葛氏集》。** 陈寿奉晋廷命分类编订诸葛亮文书，晋泰始十年二月呈进。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **章安侯孙奋谣言及郭诞、奚熙案。** 会稽传言孙奋将立，郭诞只呈奚熙书信未报谣言而获罪，奚熙拒捕后被部属杀。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **吴分遣使者核查逃亡叛离。** 七月遣使二十五人赴州郡核查逃亡、叛离。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **吴大司马陆抗去世。** 大司马陆抗这一年去世。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **吴疫病延续，分鬱林置桂林郡。** 改元以来连年大疫，这一年从鬱林分设桂林郡。 [[5]](#sg-note-5)

<a id="sgz-event-6"></a>

6. **曹芳去世，谥邵陵厉公。** 《魏世谱》记末句明记曹芳在泰始十年去世、谥厉公，“年四十三”置于受禅封公与卒年之间。 [[6]](#sgz-note-6)

<a id="sgz-event-7"></a>

7. **范慎去世，子范耀继嗣。** 注称范慎在凤凰三年死，儿子继爵；又附刁玄、羊衜籍贯。 [[7]](#sgz-note-7)

<a id="sgz-event-8"></a>

8. **鲁淑死，鲁睦继爵领兵。** 鲁淑去世，其子鲁睦继侯、领其部兵。 [[8]](#sgz-note-8)

### 1. 陈寿进《诸葛氏集》

**[《三国志·诸葛亮传》](../../sources/本地分卷/三国志/三国志-卷035.md#p005)** · [仓内TXT L1782](../../sources/本地分卷/三国志/三国志-卷035.md#l1782)

> 泰始十年二月一日癸巳，平陽侯相臣陳壽上。

<a id="sgz035-b-1777-1"></a>

**[《三国志·诸葛亮传》仓内原文 L1777](../../sources/本地分卷/三国志/三国志-卷035.md#l1777)**

> 諸葛氏集目錄：開府作牧第一 權制第二 南征第三 北出第四 計算第五 訓厲第六 綜覈上第七 綜覈下第八 雜言上第九雜言第十 貴和第十一 兵要第十二 傳運第十三 與孫權書第十四 與諸葛謹書第十五 與孟達書第十六 廢李平第十七 法檢上第十八 法檢下第十九 科令上第二十 科令下第二十一 軍令上第二十二 軍令中第二十三 軍令下第二十四，右二十四篇，凡十萬四千一百一十二字。

**释读** 所进全书二十四篇，从开府、征伐、书札到科令军令，原记十万四千一百一十二字。

**归年** 次后上表尾署泰始十年二月一日，目录为所附同年文书。

<a id="sgz035-b-1778-1"></a>

**[《三国志·诸葛亮传》仓内原文 L1778](../../sources/本地分卷/三国志/三国志-卷035.md#l1778)**

> 臣壽等言：臣前在著作郎，侍中領中書監濟北侯臣荀勖、中書令關內侯臣和嶠奏：使臣定故蜀丞相諸葛亮故事。亮毗佐危國，負阻不賓，然猶存錄其言，恥善有遺，誠是大晉光明至德，澤被無疆，自古以來，未有之倫也。輒刪除複重，隨類相從，凡為二十四篇。篇名如右。

**释读** 荀勖、和峤奏命编定事文。陈寿感称晋保留异国文书，说明去重分类，编为二十四篇。

**归年** 泰始十年奏；所受命年份未在前句另标，不把编纂全程简单等同奏上日。

<a id="sgz035-b-1779-1"></a>

**[《三国志·诸葛亮传》仓内原文 L1779](../../sources/本地分卷/三国志/三国志-卷035.md#l1779)**

> 亮少有逸眾之才，英霸之器，身長八尺，容貌甚偉，時人異焉。造漢末亂，隨叔父玄避難荊州，躬耕于野，不求聞達。時左將軍劉備以亮有殊量，乃三顧亮於草廬之中﹔亮深謂備雄姿傑出，遂解帶寫誠，厚相結納。

**释读** 述诸葛亮才貌、随叔父入荆州躬耕，刘备三顾后诸葛亮尽诚响应。

**归年** 表作于274年，汉末旧事另系相应正文。

<a id="sgz035-b-1779-2"></a>

**[《三国志·诸葛亮传》仓内原文 L1779](../../sources/本地分卷/三国志/三国志-卷035.md#l1779)**

> 及魏武帝南征荊州，劉琮舉州委質，而備失勢眾寡，無立錐之地。亮時年二十七，乃建奇策，身使孫權，求援吳會。權既宿服仰備，又觀亮奇雅，甚敬重之，即遣兵三萬以助備。備得用與武帝交戰，大破其軍，乘勝克捷，江南悉平。後備又西取益州。益州既定，以亮為軍師將軍。

**释读** 曹操取荆州后诸葛亮赴吴求援，孙权遣兵助刘备，破曹军并取江南；后取益州，任诸葛亮军师将军。

**归年** 同一274年表；出使和赤壁在208年，平蜀在214年。

<a id="sgz035-b-1779-3"></a>

**[《三国志·诸葛亮传》仓内原文 L1779](../../sources/本地分卷/三国志/三国志-卷035.md#l1779)**

> 備稱尊號，拜亮為丞相，錄尚書事。及備殂沒，嗣子幼弱，事無巨細，亮皆專之。於是外連東吳，內平南越，立法施度，整理戎旅，工械技巧，物究其極，科教嚴明，賞罰必信，無惡不懲，無善不顯，至於吏不容奸，人懷自厲，道不拾遺，彊不侵弱，風化肅然也。

**释读** 述刘备称帝任丞相，刘备死后托政，以外联、平南、修法、军备和奖惩教化的成效为例。

**归年** 同一274年表；所述221至225年相应史事另标。

<a id="sgz035-b-1780-1"></a>

**[《三国志·诸葛亮传》仓内原文 L1780](../../sources/本地分卷/三国志/三国志-卷035.md#l1780)**

> 當此之時，亮之素志，進欲龍驤虎視，包括四海，退欲跨陵邊疆，震蕩宇內。又自以為無身之日，則未有能蹈涉中原、抗衡上國者，是以用兵不戢，屢耀其武。然亮才，於治戎為長，奇謀為短，理民之干，優於將略。而所與對敵，或值人傑，加眾寡不侔，攻守異體，故雖連年動眾，未能有克。昔蕭何荐韓信，管仲舉王子城父，皆忖己之長，未能兼有故也。亮之器能政理，抑亦管、蕭之亞匹也，而時之名將無城父、韓信，故使功業陵遲，大義不及邪？蓋天命有歸，不可以智力爭也。

**释读** 称其用兵连年以定边、抗魏，治军与理民胜于奇谋将略；胜少亦缘对手、兵力与攻守态势，并以管仲、萧何荐将为比。

**归年** 同一274年表文，史评不另定作诸葛亮在世某年。

<a id="sgz035-b-1781-1"></a>

**[《三国志·诸葛亮传》仓内原文 L1781](../../sources/本地分卷/三国志/三国志-卷035.md#l1781)**

> 青龍二年春，亮帥眾出武功，分兵屯田，為久駐之基。其秋病卒，黎庶追思，以為口實。至今梁、益之民，咨述亮者，言猶在耳，雖甘棠之詠召公，鄭人之歌子產，無以遠譬也。孟軻有云：「以逸道使民，雖勞不怨﹔以生道殺人，雖死不忿。」信矣！

**释读** 称青龙二年屯田武功、秋卒，百姓追念如爱召公、子产，借孟子论合理为政。

**归年** 表文系274，五丈原卒实为234年。

<a id="sgz035-b-1781-2"></a>

**[《三国志·诸葛亮传》仓内原文 L1781](../../sources/本地分卷/三国志/三国志-卷035.md#l1781)**

> 論者或怪亮文彩不艷，而過於丁寧周至。臣愚以為咎繇大賢也，周公聖人也，考之尚書，咎繇之謨略而雅，周公之誥煩而悉。何則？咎繇與舜、禹共談，周公與群下矢誓故也。亮所與言，盡眾人凡士，故其文指不得及遠也。然其聲教遺言，皆經事綜物，公誠之心，形於文墨，足以知其人之意理，而有補於當世。

**释读** 有人嫌文辞不华，陈寿比皋陶言与周公告诰，说明对象不同；诸葛亮文书周至、诚实，足为当世借鉴。

**归年** 同一274年表的论辩。

<a id="sgz035-b-1782-1"></a>

**[《三国志·诸葛亮传》仓内原文 L1782](../../sources/本地分卷/三国志/三国志-卷035.md#l1782)**

> 伏惟陛下邁蹤古聖，蕩然無忌，故雖敵國誹謗之言，咸肆其辭而無所革諱，所以明大通之道也。謹錄寫上詣著作。臣壽誠惶誠恐，頓首頓首，死罪死罪。泰始十年二月一日癸巳，平陽侯相臣陳壽上。

**释读** 赞晋帝不改避魏蜀敌对辞章。陈寿于泰始十年二月初一癸巳进书。

**归年** 本传明记泰始十年（274）呈进。

### 2. 章安侯孙奋谣言及郭诞、奚熙案

[返回正文第2条](#sg-event-2)

<a id="sg048-l2368-e2"></a>

**[《三国志·三嗣主传》](../../sources/本地分卷/三国志/三国志-卷048.md#p008)** · [仓内TXT L2368](../../sources/本地分卷/三国志/三国志-卷048.md#l2368)

> 三年，會稽妖言章安侯奮當爲天子。臨海太守奚熙與會稽太守郭誕書，非論國政。

<a id="sgz050-p-019-4"></a>

**[《三国志·妃嫔传》裴注 019·4](../../sources/本地分卷/三国志/三国志-卷050.md#pei-019-4)**

> 國人見葬大奢麗皆謂晧已死所〔四库字图1593〕者是也晧舅子何都顔状似晧云都代立臨海太守奚熙信譌言舉兵欲還誅都都叔父信時為備海督擊殺熙夷三族譌言乃息而人心猶疑

**释读** 传言孙皓死、何都冒立。临海太守奚熙据此欲举兵，何信击杀奚熙，夷三族。

**归年** 《三嗣主传》凤凰三年记奚熙和另一系的孙奋当立传言，二说存异；传言开始未载。

<a id="sgz048-b-2368-1"></a>

**[《三国志·三嗣主传》仓内原文 L2368](../../sources/本地分卷/三国志/三国志-卷048.md#l2368)**

> ﻿三年，會稽妖言章安侯奮當爲天子。臨海太守奚熙與會稽太守郭誕書，非論國政。誕但白熙書，不白妖言，送付建安作船。

**释读** 临海太守奚熙给郭诞写信批评国政，郭只上报信而略去谣言，被送建安造船。

**归年** 本传凤凰三年；《孙奋传》吴侯孙奋伏诛另见建衡二年，后发妖言不回改其卒年。

<a id="sgz048-b-2368-3"></a>

**[《三国志·三嗣主传》仓内原文 L2368](../../sources/本地分卷/三国志/三国志-卷048.md#l2368)**

> 遣三郡督何植收熙，熙發兵自衞，斷絕海道。熙部曲殺熙，送首建業，夷三族。

**释读** 吴遣三郡督何植拘奚熙，奚熙发兵断绝海道，被部曲所杀，首送建业，夷三族。

**归年** 与凤凰三年奚熙、郭诞案同年同号。

<a id="sgz048-p-031-1"></a>

**[《三国志·三嗣主传》裴注 031·1](../../sources/本地分卷/三国志/三国志-卷048.md#pei-031-1)**

> 㑹稽邵氏家傳曰邵疇字温伯時為誕功曹誕被收惶遽無以自明疇進曰疇今自在疇之事明府何憂遂詣吏自列云不白妖言事由於已非府君罪吏上疇辭晧怒猶盛疇慮誕卒不免遂自殺以證之

**释读** 郭诞被收，功曹邵稠承认不报谣言是己见，以死自明。

**归年** 本传凤凰三年郭诞、奚熙案。仓TXT误夹此注段，仅注文全文系年。

<a id="sgz048-p-031-2"></a>

**[《三国志·三嗣主传》裴注 031·2](../../sources/本地分卷/三国志/三国志-卷048.md#pei-031-2)**

> 臨亡置辭曰疇生長邊陲不閑教道得以門資厠身本郡踰越儕類位極朝右不能贊〔四库字图3951〕盛化養之以福今妖訛横興干國亂紀疇以噂〔四库字图1019〕之語本非事實雖家誦人詠不足有慮天下重器而匹夫横議疾其醜聲不忍聞見欲含垢藏疾不彰之翰華鎮躁歸静使之自息愚心勤勤每執斯旨故誕屈其所是黙以見從此之為愆實由於疇謹不敢逃死歸罪有司唯乞天鑒特垂清察吏收疇喪得辭以聞晧乃免誕大刑送付建安作船疇亡時年四十晧嘉疇節義詔郡縣圗形廟堂

**释读** 邵稠遗言称民间谣言不足惊国，郭诞从其见，自己愿负罪。孙皓减郭诞死罪，仍送去造船，又命为邵稠绘像。

**归年** 274同案，图字据对校解释。

### 4. 吴大司马陆抗去世

[返回正文第4条](#sg-event-4)

<a id="sg048-l2368-e4"></a>

**[《三国志·三嗣主传》](../../sources/本地分卷/三国志/三国志-卷048.md#p008)** · [仓内TXT L2368](../../sources/本地分卷/三国志/三国志-卷048.md#l2368)

> 大司馬陸抗卒。

<a id="sg058-l2812-e4"></a>

**[《三国志·陆逊传》](../../sources/本地分卷/三国志/三国志-卷058.md#p007)** · [仓内TXT L2812](../../sources/本地分卷/三国志/三国志-卷058.md#l2812)

> 秋遂卒，子晏嗣。晏及弟景、玄、機、雲、分領抗兵。

**归年与互校** 上接凤凰三年病奏，同年。

<a id="sgz058-b-2810-1"></a>

**[《三国志·陆逊传》仓内原文 L2810](../../sources/本地分卷/三国志/三国志-卷058.md#l2810)**

> 三年夏，疾病。上疏曰：

**释读** 陆抗夏季病重，仍进疏论战略。

**归年** 承凤凰三年。

<a id="sgz058-b-2811-1"></a>

**[《三国志·陆逊传》仓内原文 L2811](../../sources/本地分卷/三国志/三国志-卷058.md#l2811)**

> 西陵、建平，國之蕃表，既處下流，受敵二境。若敵泛舟順流，舳艫千里，星奔電邁，俄然行至，非可恃援他部以救倒縣也。此乃社稷安危之機，非徒封疆侵陵小害也。

**释读** 两地近国境，晋船顺江可骤至，援军难及，关乎社稷。

**归年** 凤凰三年病中疏。

<a id="sgz058-b-2811-2"></a>

**[《三国志·陆逊传》仓内原文 L2811](../../sources/本地分卷/三国志/三国志-卷058.md#l2811)**

> 臣父遜昔在西垂陳言，以為西陵國之西門，雖雲易守，亦復易失。若有不守，非但失一郡，則荊州非吳有也。如其有虞，當傾國爭之。臣往在西陵，得涉遜跡，前乞精兵三萬，而（至）者循常，未肯差赴。自步闡以後，益更損耗。今臣所統千里，受敵四處，外御強對，內懷百蠻，而上下見兵財有數萬，羸弊日久，難以待變。

**释读** 父陆逊视西陵为国门；陆抗先请三万人未获，步阐后损失更重，现兵少疲、内外受敌。

**归年** 同一遗疏；父亲曾陈言确年未载。

<a id="sgz058-b-2811-3"></a>

**[《三国志·陆逊传》仓内原文 L2811](../../sources/本地分卷/三国志/三国志-卷058.md#l2811)**

> 臣愚以為諸王幼沖，未統國事，可且立傅相，輔導賢姿，無用兵馬，以妨要務。又黃門豎宦，開立占募，兵民怨役，逋逃入占。乞特詔簡閱，一切料出，以補疆場受敵常處，使臣所部足滿八萬，省息眾務，信其賞罰，雖韓、白復生，無所展巧。

**释读** 诸王年少可置师傅，勿分兵；宦者招纳逃役者，宜清查补边，使所部达八万并明责赏。

**归年** 同一遗疏。

<a id="sgz058-b-2811-4"></a>

**[《三国志·陆逊传》仓内原文 L2811](../../sources/本地分卷/三国志/三国志-卷058.md#l2811)**

> 若兵不增，此制不改，而欲克諧大事，此臣之所深戚也。若臣死之後，乞以西方為屬。願陛下思覽臣言，則臣死且不朽。

**释读** 若兵制不改难成大事，请君主留意其死后西部的安排。

**归年** 同一遗疏结。

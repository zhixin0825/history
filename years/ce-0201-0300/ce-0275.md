[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **孙皓因银铭改元天册。** 吴郡上报掘得刻有年月的银片，孙皓借此大赦、改元。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **贺邵受谗被杀。** 贺邵因中风失语离职，孙皓疑为托病，将他逮捕拷问；贺邵被杀，家属迁往临海。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **东观令华覈因小过免官。** 华覈历次上书推荐人才、陈述政事，天册元年因小过免职，数年后死。 [[3]](#sg-note-3)

<a id="sgz-event-4"></a>

4. **陆祎、陆式被徙建安。** [陆抗去世](ce-0274.md#sg-event-4)后，孙皓把陆凯之子陆祎与陆胤之子陆式迁往建安。 [[4]](#sgz-note-4)

### 2. 贺邵受谗被杀

[返回正文第2条](#sg-event-2)

<a id="sgz065-p-004-1"></a>

**[《三国志·王楼贺韦华传》裴注 004·1](../../sources/本地分卷/三国志/三国志-卷065.md#pei-004-1)**

> 邵子循字彦先虞預晉書曰循丁家禍流放海濵

**释读** 贺邵之子贺循，家中遭祸后被流放海滨。

**归年** 贺邵在275年被诛，其家被徙海滨，本注接记子循流放。

<a id="sg065-l3052-e2"></a>

**[《三国志·王楼贺韦华传》](../../sources/本地分卷/三国志/三国志-卷065.md#p003)** · [仓内TXT L3052](../../sources/本地分卷/三国志/三国志-卷065.md#l3052)

> 邵卒無一語，竟見殺害，家屬徙臨海。並下詔誅玄子孫，是歲天冊元年也

<a id="sgz065-b-3052-2"></a>

**[《三国志·王楼贺韦华传》仓内原文 L3052](../../sources/本地分卷/三国志/三国志-卷065.md#l3052)**

> 後邵中惡風，口不能言，去職數月，皓疑其託疾，收付酒藏，掠考千所，邵卒無一語，竟見殺害，家屬徙臨海。並下詔誅玄子孫，是歲天冊元年也，邵年四十九。

**释读** 孙皓以为托病，贺邵受酷刑不言，终遭杀。家属徙临海，又诛楼玄子孙。

**归年** 本传注明天册元年，公元275。楼玄本人之死与家族被诛分开。

### 4. 陆祎、陆式被徙建安

[返回正文第4条](#sgz-event-4)

<a id="sgz061-b-2910-2"></a>

<a id="wu061-l53-1"></a>

**[《三國志·潘濬陸凱傳》正文](../../sources/本地分卷/三国志/三国志-卷061.md#edition-wu061-l53-1)** · [TXT L53](../../sources/本地分卷/三国志/三国志-卷061.txt#L53)

> 初，皓常銜凱數犯顏忤旨，加何定譖構非一，旣以重臣，難繩以法，又陸抗時爲大將在疆埸，故以計容忍。抗卒後，竟徙凱家於建安。

**釋讀** 孫皓早已因陸凱犯顏直諫而怨恨，又屢聽何定讒毀。陸凱為重臣、陸抗又握兵在外，孫皓一時容忍。陸抗去世後，孫皓終將陸凱家人徙往建安。

**歸年** 陸抗卒於274年。同卷〈陸胤傳〉明記天冊元年（275）陸禕與陸式皆徙建安。前半為長期背景。《通鑑》卷079接269年陸凱去世以「乆之」追敘此事，並無明斷同年。

<a id="sgz061-b-2938-2"></a>

<a id="wu061-l114-2"></a>

**[《三國志·潘濬陸凱傳》正文](../../sources/本地分卷/三国志/三国志-卷061.md#edition-wu061-l114-2)** · [TXT L114](../../sources/本地分卷/三国志/三国志-卷061.txt#L114)

> 天策元年，與從兄禕俱徙建安。

**釋讀** 天策元年，孫皓把陸式和他的堂兄陸禕一同遷往建安。

**歸年** 本傳底本作「天策」，卷048〈孫皓傳〉記275年改元「天冊」。卷061前文又載陸抗（274年卒）死後孫皓徙陸凱家於建安，可與此處互證。陸禕是陸凱之子，陸式是陸胤之子。

**互見** 〈陸凱傳〉記陸抗去世後陸凱家被徙，〈陸胤附傳〉具名陸禕、陸式。

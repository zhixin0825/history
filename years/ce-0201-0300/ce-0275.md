# 公元275年｜晋咸宁元年／吴天册元年

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **孙皓因银铭改元天册。** 吴郡上报掘得刻有年月的银片，孙皓借此大赦、改元。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓杀贺邵，流徙其家并诛楼玄子孙。** 贺邵中风失语，离任数月。孙皓疑他托病，命人反复拷问。贺邵始终未发一言，终于被杀，年四十九岁。家属被流徙临海，其子贺循也被放逐海滨。孙皓又下诏杀楼玄子孙。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **东观令华覈因小过免官。** 华覈历次上书推荐人才、陈述政事，天册元年因小过免职，数年后去世，确年无载。 [[3]](#sg-note-3)

<a id="sgz-event-4"></a>

4. **陆祎、陆式被徙建安。** [陆抗去世](ce-0274.md#sg-event-4)后，孙皓把陆凯之子陆祎与陆胤之子陆式迁往建安。 [[4]](#sgz-note-4)

## 西晋朝政

<a id="wei023-event-l93-8"></a>

5. **晋以裴秀配享，封其子裴頠为钜鹿公。** 八月，晋廷将故司空裴秀等功臣列入配享。裴秀死后长子裴浚先袭爵，裴浚早逝，十二月，晋廷以其弟裴頠承封钜鹿公。 [[5]](#wei023-pei-xiu-temple-and-son)

### 2. 孙皓杀贺邵，流徙其家并诛楼玄子孙

[返回正文第2条](#sg-event-2)

<a id="sg065-l3052-e2"></a>

<a id="sgz065-b-3052-2"></a>

<a id="wu065-l37-2"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l37-2)** · [TXT L37](../../拆分史书/三国志/卷065.txt#L37)

> 後邵中惡風，口不能言，去職數月，皓疑其託疾，收付酒藏，掠考千所，邵卒無一語，竟見殺害，家屬徙臨海。并下詔誅玄子孫，是歲天冊元年也，邵年四十九。

**釋讀** 賀邵中風失語而去職數月，孫皓疑他裝病，把他交酒藏拷訊，頻加刑責。賀邵始終未說一句話，終被殺害，年四十九。其家人徙臨海，孫皓又下令誅殺樓玄子孫。

**歸年** 本傳明言天冊元年。[《通鑑》卷080](../../史书/025-资治通鉴/KR2b0007_080.txt#L215-L220)同繫咸寧元年，載殺賀邵、徙其家並誅樓玄子孫，回指樓玄本人已在泰始八年一案中遇害。《建康實錄》卷四將賀邵遇害置於天冊、天璽兩次改元合敘之後，稱他與樓玄同見殺。本傳分載樓玄本人早死及天冊元年再誅其子孫，故本頁從有明文的本傳。

**旁證** 《建康實錄》另記燒鋸截頭，[《晉書·賀循傳》](../../史书/005-晋书/晋书-CCDH.txt#L7061)也載司馬睿曾向賀循提及此事；本傳只記受刑被殺，未寫所用刑具。本傳所記卒年與四十九歲，若按虛歲倒推為227年生；另見以275減49得226年之說，兩者均為推算。

<a id="sgz065-p-004-1"></a>

<a id="wu065-l38-1"></a>

**[《三國志·王樓賀韋華傳》裴注 004](../../拆分史书/三国志/卷065.md#edition-wu065-l38-1)** · [TXT L38](../../拆分史书/三国志/卷065.txt#L38)

> 邵子循，字彥先。虞預晉書曰：循丁家禍，流放海濵，

**釋讀** 賀邵之子賀循，字彥先。《虞預晉書》記他少年遭到這場家禍，被放逐至海邊。

**歸年** 《虞預晉書》附於賀邵死及家屬流徙之後。[《晉書·賀循傳》](../../史书/005-晋书/晋书-CCDH.txt#L7058)同記父遇害、少遭家難而徙。

### 4. 陆祎、陆式被徙建安

[返回正文第4条](#sgz-event-4)

<a id="sgz061-b-2910-2"></a>

<a id="wu061-l53-1"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l53-1)** · [TXT L53](../../拆分史书/三国志/卷061.txt#L53)

> 初，皓常銜凱數犯顏忤旨，加何定譖構非一，旣以重臣，難繩以法，又陸抗時爲大將在疆埸，故以計容忍。抗卒後，竟徙凱家於建安。

**釋讀** 孫皓早已因陸凱犯顏直諫而怨恨，又屢聽何定讒毀。陸凱為重臣、陸抗又握兵在外，孫皓一時容忍。陸抗去世後，孫皓終將陸凱家人徙往建安。

**歸年** 陸抗卒於274年。同卷〈陸胤傳〉明記天冊元年（275）陸禕與陸式皆徙建安。前半為長期背景。《通鑑》卷079接269年陸凱去世以「乆之」追敘此事，並無明斷同年。

<a id="sgz061-b-2938-2"></a>

<a id="wu061-l114-2"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l114-2)** · [TXT L114](../../拆分史书/三国志/卷061.txt#L114)

> 天策元年，與從兄禕俱徙建安。

**釋讀** 天策元年，孫皓把陸式和他的堂兄陸禕一同遷往建安。

**歸年** 本傳底本作「天策」，卷048〈孫皓傳〉記275年改元「天冊」。卷061前文又載陸抗（274年卒）死後孫皓徙陸凱家於建安，可與此處互證。陸禕是陸凱之子，陸式是陸胤之子。

**互見** 〈陸凱傳〉記陸抗去世後陸凱家被徙，〈陸胤附傳〉具名陸禕、陸式。

### 5. 晋以裴秀配享，封其子裴頠为钜鹿公

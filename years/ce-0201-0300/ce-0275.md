## 本年概述

晋改元咸宁，给予五女之家赋役优免，赐帛奖廉，树机能送质请降。朝廷列功臣铭飨，追定先帝庙号；年末大疫，裴頠承封钜鹿公。

<a id="西晋朝政"></a>

<a id="jin003-u217-1-event"></a>
<a id="jin003-l217-event"></a>

1. **改元咸宁。** 正月戊午朔，大赦，改元咸宁。 [[1]](#jin003-u217-1-note)

<a id="jin003-u218-1-event"></a>
<a id="jin003-l218-event"></a>

2. **五女之家免赋役。** 二月，因将士中应当娶妻者多，准家有五女者免赋役。 [[2]](#jin003-u218-1-note)

<a id="jin003-u218-2-event"></a>

3. **赐夏谡谷百斛。** 二月辛酉，因故邺令夏谡有清廉名声，赐谷一百斛。 [[3]](#jin003-u218-2-note)

<a id="jin003-u218-3-event"></a>

4. **因俸禄薄赐帛。** 二月，因俸禄微薄，按等差赐公卿以下帛。 [[4]](#jin003-u218-3-note)

<a id="jin003-u218-4-event"></a>

5. **树机能送人质请降。** 二月，树机能送来人质，请求归降。 [[5]](#jin003-u218-4-note)

<a id="jin003-u219-1-event"></a>
<a id="jin003-l219-event"></a>

6. **下邳、广陵风灾。** 五月，下邳、广陵大风，拔树、毁民房。 [[6]](#jin003-u219-1-note)

<a id="jin003-u220-1-event"></a>
<a id="jin003-l220-event"></a>

7. **力微遣子来献。** 六月，鲜卑力微派儿子来献。 [[7]](#jin003-u220-1-note)

<a id="jin003-u220-2-event"></a>

8. **吴军进犯江夏。** 六月，吴军进犯江夏。 [[8]](#jin003-u220-2-note)

<a id="jin003-u220-3-event"></a>

9. **马循击破鲜卑叛军。** 六月，西域戊己校尉马循击破反叛的鲜卑军，斩其首领。 [[9]](#jin003-u220-3-note)

<a id="jin003-u220-4-event"></a>

10. **设太子詹事。** 六月戊申，设置太子詹事。 [[10]](#jin003-u220-4-note)

<a id="jin003-u221-1-event"></a>
<a id="jin003-l221-event"></a>

11. **七月晦日食。** 七月甲申晦，发生日食。 [[11]](#jin003-u221-1-note)

<a id="jin003-u221-2-event"></a>

12. **郡国螟害。** 本年，郡国发生螟害。 [[12]](#jin003-u221-2-note)

<a id="jin003-u222-1-event"></a>

13. **司马子文去世。** 八月壬寅，沛王司马子文去世。 [[13]](#jin003-u222-1-note)

<a id="wei023-event-l93-8"></a>

14. **功臣列入铭飨。** 八月，把已故郑冲、荀顗、石苞、裴秀、王沈、司马孚，以及在世何曾、贾充、陈骞、荀勖、羊祜、司马攸等列入铭记功勋、享祭的名次。 [[14]](#wei023-pei-xiu-temple-and-son)

<a id="jin003-u223-1-event"></a>
<a id="jin003-l223-event"></a>

15. **青州螟害、徐州水灾。** 九月甲子，青州螟害，徐州大水。 [[15]](#jin003-u223-1-note)

<a id="jin003-u224-1-event"></a>
<a id="jin003-l224-event"></a>

16. **司马殷去世。** 十月乙酉，常山王司马殷去世。 [[16]](#jin003-u224-1-note)

<a id="jin003-u224-2-event"></a>

17. **司马权去世。** 十月癸巳，彭城王司马权去世。 [[17]](#jin003-u224-2-note)

<a id="jin003-u225-1-event"></a>
<a id="jin003-l225-event"></a>

18. **宣武观阅军。** 十一月癸亥，在宣武观大阅，至己巳结束。 [[18]](#jin003-u225-1-note)

<a id="jin003-u226-1-event"></a>
<a id="jin003-l226a-event"></a>

19. **三祖庙号。** 十二月丁亥，追定宣帝庙号高祖、景帝世宗、文帝太祖。 [[19]](#jin003-u226-1-note)

<a id="jin003-u226-2-event"></a>
<a id="jin003-l226b-event"></a>

20. **洛阳疫病。** 十二月，大疫，洛阳死者超过一半。 [[20]](#jin003-u226-2-note)

<a id="jin003-u226-3-event"></a>

21. **裴頠封钜鹿公。** 十二月，封裴頠为钜鹿公，承其兄裴浚之后。 [[21]](#jin003-u226-3-note)

<a id="sg-event-1"></a>

22. **孙皓因银铭改元天册。** 吴郡上报掘得刻有年月的银片，孙皓借此大赦、改元。 [[22]](#sg-note-1)

<a id="sg-event-2"></a>

23. **孙皓杀贺邵，流徙其家并诛楼玄子孙。** 贺邵中风失语，离任数月。孙皓疑他托病，命人反复拷问。贺邵始终未发一言，终于被杀，年四十九岁。家属被流徙临海，其子贺循也被放逐海滨。孙皓又下诏杀楼玄子孙。 [[23]](#sg-note-2)

<a id="sg-event-3"></a>

24. **东观令华覈因小过免官。** 华覈历次上书推荐人才、陈述政事，天册元年因小过免职，数年后去世，确年无载。 [[24]](#sg-note-3)

<a id="sgz-event-4"></a>

25. **陆祎、陆式被徙建安。** [陆抗去世](ce-0274.md#sg-event-4)后，孙皓把陆凯之子陆祎与陆胤之子陆式迁往建安。 [[25]](#sgz-note-4)

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l37-2)** · [TXT L37](../../拆分史书/三国志/卷065.txt#L37)

> 後邵中惡風，口不能言，去職數月，皓疑其託疾，收付酒藏，掠考千所，邵卒無一語，竟見殺害，家屬徙臨海。并下詔誅玄子孫，是歲天冊元年也，邵年四十九。

**釋讀** 賀邵中風失語而去職數月，孫皓疑他裝病，把他交酒藏拷訊，頻加刑責。賀邵始終未說一句話，終被殺害，年四十九。其家人徙臨海，孫皓又下令誅殺樓玄子孫。

**歸年** 本傳明言天冊元年。[《通鑑》卷080](../../史书/025-资治通鉴/KR2b0007_080.txt#L215-L220)同繫咸寧元年，載殺賀邵、徙其家並誅樓玄子孫，回指樓玄本人已在泰始八年一案中遇害。《建康實錄》卷四將賀邵遇害置於天冊、天璽兩次改元合敘之後，稱他與樓玄同見殺。本傳分載樓玄本人早死及天冊元年再誅其子孫，故本頁從有明文的本傳。

**旁證** 《建康實錄》另記燒鋸截頭，[《晉書·賀循傳》](../../史书/005-晋书/晋书-CCDH.txt#L7061)也載司馬睿曾向賀循提及此事；本傳只記受刑被殺，未寫所用刑具。本傳所記卒年與四十九歲，若按虛歲倒推為227年生；另見以275減49得226年之說，兩者均為推算。

<a id="wu065-l38-1"></a>

**[《三國志·王樓賀韋華傳》裴注 004](../../拆分史书/三国志/卷065.md#edition-wu065-l38-1)** · [TXT L38](../../拆分史书/三国志/卷065.txt#L38)

> 邵子循，字彥先。虞預晉書曰：循丁家禍，流放海濵，

**釋讀** 賀邵之子賀循，字彥先。《虞預晉書》記他少年遭到這場家禍，被放逐至海邊。

**歸年** 《虞預晉書》附於賀邵死及家屬流徙之後。[《晉書·賀循傳》](../../史书/005-晋书/晋书-CCDH.txt#L7058)同記父遇害、少遭家難而徙。

### 25. 陆祎、陆式被徙建安

[返回正文第25条](#sgz-event-4)

<a id="sgz061-b-2910-2"></a>

<a id="wu061-l53-1"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l53-1)** · [TXT L53](../../拆分史书/三国志/卷061.txt#L53)

> 初，皓常銜凱數犯顏忤旨，加何定譖構非一，旣以重臣，難繩以法，又陸抗時爲大將在疆埸，故以計容忍。抗卒後，竟徙凱家於建安。

**釋讀** 孫皓早已因陸凱犯顏直諫而怨恨，又屢聽何定讒毀。陸凱為重臣、陸抗又握兵在外，孫皓一時容忍。陸抗去世後，孫皓終將陸凱家人徙往建安。

**歸年** 陸抗卒於274年。同卷〈陸胤傳〉明記天冊元年（275）陸禕與陸式皆徙建安。前半為長期背景。《通鑑》卷079接269年陸凱去世以「乆之」追敘此事，並無明斷同年。

<a id="sgz061-b-2938-2"></a>

<a id="wu061-l114-2"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l114-2)** · [TXT L114](../../拆分史书/三国志/卷061.txt#L114)

> 天策元年，與從兄禕俱徙建安。

**釋讀** 天策元年，孫皓把陸式和他的堂兄陸禕一同遷往建安。

**歸年** 本傳底本作「天策」，卷048〈孫皓傳〉記275年改元「天冊」。卷061前文又載陸抗（274年卒）死後孫皓徙陸凱家於建安，可與此處互證。陸禕是陸凱之子，陸式是陸胤之子。

**互見** 〈陸凱傳〉記陸抗去世後陸凱家被徙，〈陸胤附傳〉具名陸禕、陸式。

# 公元275年｜晋咸宁元年／吴天册元年

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **孙皓因银铭改元天册。** 吴郡上报掘得刻有年月的银片，孙皓借此大赦、改元。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **贺邵受谗被杀。** 贺邵因中风失语离职，孙皓疑为托病，将他逮捕拷问；贺邵被杀，家属迁往临海。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **东观令华覈因小过免官。** 华覈历次上书推荐人才、陈述政事，天册元年因小过免职，数年后死。 [[3]](#sg-note-3)

<a id="sgz-event-4"></a>

4. **陆凯之子陆祎与陆式被徙建安。** [陆抗去世](ce-0274.md#sg-event-4)后，孙皓将陆凯之子陆祎和陆式迁往建安。《陆凯传》称陆凯一家被徙，《陆逊传》附传明确写出两人。 [[4]](#sgz-note-4)

### 1. 孙皓因银铭改元天册

[返回正文第1条](#sg-event-1)

<a id="sg048-l2369-e1"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p009)** · [仓内TXT L2369](../../sources/本地分卷/三国志/三国志-卷048.md#l2369)

> 天冊元年，吳郡言掘地得銀，長一尺，廣三分，刻上有年月字，於是大赦，改年。

<a id="sgz048-b-2369-1"></a>

**[《三国志·三嗣主传》仓内原文 L2369](../../sources/本地分卷/三国志/三国志-卷048.md#l2369)**

> ﻿天冊元年，吳郡言掘地得銀，長一尺，廣三分，刻上有年月字，於是大赦，改年。

**释读** 吴郡说土中得到刻年月字的银，朝廷大赦改元。

**归年** 本传天册元年。

<a id="sg-note-2"></a>

### 2. 贺邵受谗被杀

[返回正文第2条](#sg-event-2)

<a id="sgz065-p-004-1"></a>

**[《三国志·王楼贺韦华传》裴注 004·1](../../sources/摘录/三国志-卷065-王楼贺韦华传裴注.md#pei-004-1)**

> 邵子循字彦先虞預晉書曰循丁家禍流放海濵

**释读** 贺邵之子贺循，家中遭祸后被流放海滨。

**归年** 贺邵在275年被诛，其家被徙海滨，本注接记子循流放。

<a id="sg065-l3052-e2"></a>

**[《三国志·王楼贺韦华传》](../../sources/摘录/三国志-卷065-王楼贺韦华传.md#p003)** · [仓内TXT L3052](../../sources/本地分卷/三国志/三国志-卷065.md#l3052)

> 邵卒無一語，竟見殺害，家屬徙臨海。並下詔誅玄子孫，是歲天冊元年也

<a id="sgz065-b-3052-2"></a>

**[《三国志·王楼贺韦华传》仓内原文 L3052](../../sources/本地分卷/三国志/三国志-卷065.md#l3052)**

> 後邵中惡風，口不能言，去職數月，皓疑其託疾，收付酒藏，掠考千所，邵卒無一語，竟見殺害，家屬徙臨海。並下詔誅玄子孫，是歲天冊元年也，邵年四十九。

**释读** 孙皓以为托病，贺邵受酷刑不言，终遭杀。家属徙临海，又诛楼玄子孙。

**归年** 本传注明天册元年，公元275。楼玄本人之死与家族被诛分开。

### 3. 东观令华覈因小过免官

[返回正文第3条](#sg-event-3)

<a id="sg065-l3081-e3"></a>

**[《三国志·王楼贺韦华传》](../../sources/摘录/三国志-卷065-王楼贺韦华传.md#p006)** · [仓内TXT L3081](../../sources/本地分卷/三国志/三国志-卷065.md#l3081)

> 天冊元年以微譴免，數歲卒。

**归年与互校** 确年只及免官，去世不作精确归年。

<a id="sgz065-b-3081-2"></a>

> 天冊元年以微譴免，

**释读** 天册元年华覈被免。

**归年** 本传明天册元年。

<a id="sgz-note-4"></a>

### 4. 陆凯之子陆祎与陆式被徙建安

[返回正文第4条](#sgz-event-4)

<a id="sgz061-b-2910-2"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2910](../../sources/本地分卷/三国志/三国志-卷061.md#l2910)**

> 抗卒後，竟徙凱家於建安。

**释读** 陆抗死后，陆凯家人被迁往建安。

**归年** 同卷明记陆祎、陆式在天册元年被徙。274年陆抗死是此前背景。

<a id="sgz061-b-2938-2"></a>

**[《三国志·潘濬陆凯传》仓内原文 L2938](../../sources/本地分卷/三国志/三国志-卷061.md#l2938)**

> 天策元年，與從兄禕俱徙建安。

**归年** 本传「天策」同吴孙皓天册元年，参《三嗣主传》275改元；符合上文陆抗274卒后。

## 本年概述

晋因疫停朝，司马炎病愈拒收贺礼，设国子学、建仓，册立杨芷。孙楷奔晋，边地交战与归附相继，久旱至六月始雨。


<a id="jin003-u227-1-event"></a>
<a id="jin003-l227-event"></a>

1. **因疫停朝。** 正月，因疫病停止朝会。 [[1]](#jin003-u227-1-note)

<a id="jin003-u227-2-event"></a>

2. **赐散吏士卒丝。** 正月，按等差赐散吏以至士卒丝。 [[2]](#jin003-u227-2-note)

<a id="jin003-u228-1-event"></a>
<a id="jin003-l228-event"></a>

3. **司马洪去世。** 二月丙戌，河间王司马洪去世。 [[3]](#jin003-u228-1-note)

<a id="jin003-u228-2-event"></a>

4. **赦五岁刑以下。** 二月甲午，赦免五年刑以下罪人。 [[4]](#jin003-u228-2-note)

<a id="jin003-u228-3-event"></a>

5. **东夷八国归附。** 二月，东夷八国归附。 [[5]](#jin003-u228-3-note)

<a id="jin003-u228-4-event"></a>

6. **胡奋击退并州犯塞军。** 二月，并州诸部犯塞，监并州诸军胡奋击败来军。 [[6]](#jin003-u228-4-note)

<a id="jin003-u229-1-event"></a>
<a id="jin003-l229-event"></a>

7. **令狐氏占敦煌与杨欣平定。** 凉州刺史杨欣讨杀令狐宏，传首洛阳。此前敦煌太守尹璩去世，州以敦煌令梁澄代理郡事；议郎令狐丰废梁澄、自领太守，令狐丰死后由弟令狐宏接替，至此被杨欣诛杀。 [[7]](#jin003-u229-1-note)

<a id="jin003-u230-1-event"></a>
<a id="jin003-l230-event"></a>

8. **病愈拒绝称寿。** 司马炎此前患病，病愈后群臣祝寿。他说，想到近期疫病死者便悲痛，不能因自己身体康复而忘百姓艰难，命停止进献贺礼。 [[8]](#jin003-u230-1-note)

<a id="jin003-u231-1-event"></a>
<a id="jin003-l231-event"></a>

9. **司马骏斩吐敦。** 五月，镇西大将军、汝阴王司马骏讨北胡，杀其首领吐敦。 [[9]](#jin003-u231-1-note)

<a id="jin003-u231-2-event"></a>

10. **设国子学。** 五月，设立国子学。 [[10]](#jin003-u231-2-note)

<a id="jin003-u231-3-event"></a>

11. **大雩求雨。** 五月庚午，举行大雩求雨。 [[11]](#jin003-u231-3-note)

<a id="jin003-u232-1-event"></a>
<a id="jin003-l232a-event"></a>

12. **荐荔枝于太庙。** 六月癸丑，向太庙荐献荔枝。 [[12]](#jin003-u232-1-note)

<a id="jin003-u232-2-event"></a>

13. **氐宿见孛星。** 六月甲戌，氐宿出现孛星。 [[13]](#jin003-u232-2-note)

<a id="jin003-u232-3-event"></a>

14. **久旱至六月始雨。** 自春季以来一直干旱，至六月才降雨。 [[14]](#jin003-u232-3-note)

<a id="sg-event-3"></a>
<a id="sg-event-5"></a>

15. **孙楷降晋与授爵。** 六月，孙皓征京下督孙楷为宫下镇骠骑将军。孙楷疑惧，率妻儿及亲兵奔晋，晋授车骑将军、封丹杨侯。 [[15]](#sg-note-3)

<a id="jin003-u232-5-event"></a>
<a id="jin003-l232c-event"></a>

16. **新兴井中白龙。** 六月，新兴井中报告白龙两次。 [[16]](#jin003-u232-5-note)

<a id="jin003-u233-1-event"></a>
<a id="jin003-l233-event"></a>

17. **大角见孛星。** 七月，大角星附近出现孛星。 [[17]](#jin003-u233-1-note)

<a id="jin003-u233-2-event"></a>

18. **临平湖自行疏通。** 七月，吴临平湖自汉末淤塞，到这时自行疏通。父老相传说，湖塞则天下乱，湖开则天下平。 [[18]](#jin003-u233-2-note)

<a id="jin003-u233-3b-event"></a>

19. **司马隆去世。** 七月癸丑，安平王司马隆去世。 [[19]](#jin003-u233-3b-note)

<a id="jin003-u233-4-event"></a>

20. **东夷十七国归附。** 七月，东夷十七国归附。 [[20]](#jin003-u233-4-note)

<a id="jin003-u233-5-event"></a>

21. **河南、魏郡暴水，给棺收葬。** 七月，河南、魏郡暴水，死百余人，朝廷给棺收葬。 [[21]](#jin003-u233-5-note)

<a id="jin003-u233-6-event"></a>

22. **马循讨阿罗多。** 鲜卑阿罗多等侵边，西域戊己校尉马循出讨，斩首四千余级，俘九千余人，其众随后归降。 [[22]](#jin003-u233-6-note)

<a id="jin003-u234-1-event"></a>
<a id="jin003-l234-event"></a>

23. **河东、平阳地震。** 八月庚辰，河东、平阳地震。 [[23]](#jin003-u234-1-note)

<a id="jin003-u234-2-event"></a>

24. **调整太傅及三公。** 八月己亥，以太保何曾为太傅、太尉陈骞为大司马、司空贾充为太尉、镇军大将军齐王司马攸为司空。 [[24]](#jin003-u234-2-note)

<a id="jin003-u234-3-event"></a>

25. **太微、翼宿见孛星。** 八月，太微出现孛星，九月又见于翼宿。 [[25]](#jin003-u234-3-note)

<a id="sg-event-1"></a>
<a id="sg-event-4"></a>

26. **孙皓因石函改元，遣使赴阳羡国山行礼。** 吴郡报临平湖复通，并获刻有「皇帝」字样之石，孙皓改元大赦。同年七、八月，吴廷先后遣官辨读所谓天谶石文，并刻石纪功，后称《天发神谶碑》。孙皓又因鄱阳石文及阳羡石室而遣董朝、周处至阳羡封禅，次年又改元。 [[26]](#sg-note-1)

<a id="jin003-u234-4-event"></a>

27. **建太仓与常平仓。** 九月丁未，在城东建太仓，在东西两市建常平仓。 [[27]](#jin003-u234-4-note)

<a id="jin003-u235-1-event"></a>
<a id="jin003-l235-event"></a>

28. **荆州水灾。** 闰月，荆州五郡水灾，冲走居民四千余家。 [[28]](#jin003-u235-1-note)

<a id="jin003-u236-1-event"></a>
<a id="jin003-l236-event"></a>

29. **司马骏、羊祜进大将军。** 十月，以汝阴王司马骏为征西大将军、平南将军羊祜为征南大将军。 [[29]](#jin003-u236-1-note)

<a id="jin003-u236-2-event"></a>

30. **立杨芷为皇后。** 十月丁卯，立杨芷为皇后，大赦，分等赏赐王公以下及鳏寡。 [[30]](#jin003-u236-2-note)

<a id="jin003-u237-1-event"></a>
<a id="jin003-l237-event"></a>

31. **梁国白龙。** 十一月，梁国报告白龙两次。 [[31]](#jin003-u237-1-note)

<a id="jin003-u238-1a-event"></a>
<a id="jin003-l238-event"></a>

32. **征皇甫谧为太子中庶子。** 十二月，征安定处士皇甫谧为太子中庶子。 [[32]](#jin003-u238-1a-note)

<a id="jin003-u238-1b-event"></a>

33. **杨骏封临晋侯。** 十二月，封皇后之父、镇军将军杨骏为临晋侯。 [[33]](#jin003-u238-1b-note)

<a id="jin003-u238-2-event"></a>

34. **傅询、孟桓以清白受赏。** 十二月，因平州刺史傅询、前广平太守孟桓清白有闻，赐傅询帛二百匹，孟桓一百匹。 [[34]](#jin003-u238-2-note)

<a id="sgz-event-6"></a>
<a id="sgz-event-7"></a>
<a id="sg-event-2"></a>

35. **孙皓杀会稽太守车浚、湘东太守张咏。** 孙皓杀会稽太守车浚、湘东太守张咏，将二人首级示于诸郡。 [[35]](#sg-note-2)

<a id="sgz-event-8"></a>

36. **孙皓杀尚书熊睦。** 尚书熊睦见孙皓施政严酷，婉言相劝，被孙皓命人以刀环击杀。 [[36]](#sgz-note-8)

### 26. 孙皓因石函改元，遣使赴阳羡国山行礼

[返回正文第26条](#sg-event-1)

<a id="sgz048-b-2370-1"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2370-1)** · [TXT L127](../../拆分史书/三国志/卷048.txt#L127)

> 天璽元年，吳郡言臨平湖自漢末草穢壅塞，今更開通。長老相傳，此湖塞，天下亂，此湖開，天下平。又於湖邊得石函，中有小石，青白色，長四寸，廣二寸餘，刻上作皇帝字，於是改年，大赦。

**吴以临平湖开与石函为瑞，改元天玺** 当地报临平湖复通，又获石函刻有皇帝字。孙皓信为吉祥，改元并赦。

**归年依据** 本传天玺元年。

<a id="sg048-l2370-e1"></a>

見[本卷引文](ce-0276.md#sgz048-b-2370-1)。

<a id="wu-tianfa-shenchen"></a>

**金石补证** 严可均《全三国文》卷七十五据碑本录《天发神谶碑》，纪年作「天玺元年桼月」，下文又记「以八月一日，詔遣」，叙多次遣官释读石文，随后称刊铭。国家图书馆所藏明拓著录为天玺元年七月立，碑中七月、八月是查验和释读的时日，现存文字未见立碑确日。

**撰书异说** 《建康实录》卷四记岩山立石纪吴功德，引《吴录》称华覈撰文，记有皇象书写一说又表示怀疑。碑末存「蘭臺東觀令」而姓名残缺，华覈在[275 年已免官](ce-0275.md#wu065-l88-2)，严可均因此将碑文编入阙名类。

<a id="sg-note-4"></a>

<a id="sg-note-5"></a>

<a id="sgz048-b-2370-4"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2370-4)** · [TXT L129](../../拆分史书/三国志/卷048.txt#L129)

> 鄱陽言歷陽山石文理成字，凡二十，云「楚九州渚，吳九州都，揚州士，作天子，四世治，太平始」。

<a id="sgz048-p-033-1"></a>

**[《三國志·三嗣主傳》 裴注 033·1](../../拆分史书/三国志/卷048.md#pei-033-1)** · [TXT L130](../../拆分史书/三国志/卷048.txt#L130)

> 江表傳曰：歷陽縣有石山臨水，高百丈，其三十丈所，有七穿駢羅，穿中色黃赤，不與本體相似，俗相傳謂之石印。又云，石印封發，天下當太平。下有祠屋，巫祝言石印神有三郎。時歷陽長表上言石印發，皓遣使以太牢祭歷山。巫言，石印三郎說「天下方太平」。使者作高梯，上看印文，詐以朱書石作二十字，還以啟皓。皓大喜曰：「吳當爲九州作都、渚乎！從大皇帝逮孤四世矣，太平之主，非孤復誰？」重遣使，以印綬拜三郎爲王，又刻石立銘，襃贊靈德，以荅休祥。

**释读** 地方传有石印开启可太平，巫说三郎掌石印，孙皓遣使祭祀。使者登梯窥石，假用朱笔写二十字，孙皓信而封神并立碑。
**归年** 天玺元年历阳石文、阳羡封禅背景；解释为造假是引书原说。

<a id="sgz048-b-2370-4-cont-l131"></a>

**[《三國志·三嗣主傳》續文](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2370-4-cont-l131)** · [TXT L131](../../拆分史书/三国志/卷048.txt#L131)

> 又吳興陽羨山有空石，長十餘丈，名曰石室，在所表爲大瑞。乃遣兼司徒董朝、兼太常周處至陽羨縣，封襌國山。明年改元，大赦，以恊石文。

**吴谣传历阳石文与阳羡石室，封禅国山** 历阳山称有石文二十字，阳羡山石室也被上报为瑞。吴遣董朝、周处在阳羡封禅国山，次年用石文意旨改元、赦。

**归年依据** 本传天玺元年遣使，下一年改天纪；《江表传》又称石文作伪。

**校讀** 本傳作「歷陽山」。《資治通鑑》胡三省注以鄱陽郡有歷陵，疑「陽」當作「陵」。

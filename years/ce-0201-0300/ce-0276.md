# 公元276年｜晋咸宁二年／吴天玺元年

[← 公元275年](ce-0275.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元277年 →](ce-0277.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

<a id="sg-event-4"></a>

1. **孙皓因石函改元，遣使赴阳羡国山行礼。** 吴郡报临平湖复通，并获刻有「皇帝」字样之石，孙皓改元大赦。同年七、八月，吴廷先后遣官辨读所谓天谶石文，并刻石纪功，后称《天发神谶碑》。孙皓又因鄱阳石文及阳羡石室而遣董朝、周处至阳羡封禅，次年又改元。 [[1]](#sg-note-1)

<a id="sgz-event-6"></a>

<a id="sgz-event-7"></a>

<a id="sg-event-2"></a>

2. **孙皓杀会稽太守车浚、湘东太守张咏。** 孙皓杀会稽太守车浚、湘东太守张咏，将二人首级示于诸郡。 [[2]](#sg-note-2)

<a id="sgz-event-8"></a>

3. **孙皓杀尚书熊睦。** 尚书熊睦见孙皓施政严酷，婉言相劝，被孙皓命人以刀环击杀。 [[3]](#sgz-note-8)

<a id="sg-event-3"></a>

<a id="sg-event-5"></a>

4. **孙楷被吴征召后奔晋。** 孙皓征召京下督孙楷为宫下镇骠骑将军。孙楷疑惧，率妻儿及亲兵奔晋。晋授孙楷车骑将军，封丹杨侯。 **《武帝纪》补记：** 吴京下督孙楷率众来降，晋任车骑将军、封丹杨侯。原吴方被征召的缘由与来降过程在同号史料合读。 [[4]](#sg-note-3)

<a id="jin003-l227-event"></a>

5. **因疫停朝与赐丝。** 正月，因疾疫停止朝会，分等级赐散吏至士卒丝。 [[5]](#jin003-l227-note)

<a id="jin003-l228-event"></a>

6. **司马洪卒、赦罪及边事。** 二月丙戌，河间王司马洪去世。甲午，赦五年刑以下者；东夷八国归附。并州边部入塞，监并州军事胡奋击败其众。 [[6]](#jin003-l228-note)

<a id="jin003-l229-event"></a>

7. **令狐氏占敦煌与杨欣平定。** 本纪回叙敦煌太守尹璩死后，州令敦煌令梁澄兼郡事，议郎令狐丰废梁澄、自领太守；丰死后由弟令狐宏接掌。到本年，凉州刺史杨欣斩令狐宏，传首洛阳。此前接掌的每一阶段未另给年份，不一概归276年。 [[7]](#jin003-l229-note)

<a id="jin003-l230-event"></a>

8. **病愈拒绝称寿。** 司马炎此前患病，痊愈后群臣上寿。他诏称想到近来疫病死者仍悲伤，怎能因自己一人康复就忘百姓艰难，拒绝诸臣进上的庆贺礼物。 [[8]](#jin003-l230-note)

<a id="jin003-l231-event"></a>

9. **司马骏破北胡、立国子学与雩祭。** 夏五月，镇西大将军司马骏讨北方胡部，斩首领吐敦。设国子学。庚午，举行大雩求雨。 [[9]](#jin003-l231-note)

<a id="jin003-l232a-event"></a>

10. **荐荔枝、孛星与旱后得雨。** 六月癸丑，向太庙荐荔枝；甲戌，氐宿记有孛星。自春一直干旱，直到本月才降雨。 [[10]](#jin003-l232a-note)

<a id="jin003-l232c-event"></a>

11. **新兴井中白龙。** 新兴井中报告白龙两次，作为原书祥瑞记述。 [[11]](#jin003-l232c-note)

<a id="jin003-l233-event"></a>

12. **临平湖传言、安平王卒与边灾。** 七月有孛星于大角。吴临平湖自汉末淤塞，到此自行疏通，父老相传湖塞则天下乱、湖开则天下平；这是传言，不以湖况证明天命。癸丑，安平王司马隆去世；东夷十七国归附。河南、魏郡暴水，死百余人，诏给棺。鲜卑阿罗多等侵边，戊己校尉马循讨之，本纪称斩首四千余级、俘九千余人，其众随后投降。 [[12]](#jin003-l233-note)

<a id="jin003-l234-event"></a>

13. **地震、三公调任与仓储建设。** 八月庚辰，河东、平阳地震。己亥，何曾由太保为太傅，陈骞由太尉为大司马，贾充由司空为太尉，司马攸由镇军大将军为司空。有孛星于太微，九月又见翼宿。丁未，在城东建太仓，在东、西市建常平仓。 [[13]](#jin003-l234-note)

<a id="jin003-l235-event"></a>

14. **荆州水灾。** 闰月，荆州五郡水灾，冲走四千余家。 [[14]](#jin003-l235-note)

<a id="jin003-l236-event"></a>

15. **任征将军与立杨芷。** 冬十月，以司马骏为征西大将军，羊祜为征南大将军。丁卯，立杨氏即杨芷为皇后，大赦，按等赐王公以下及鳏寡。她与274年去世的元皇后杨艳不是同一人。 [[15]](#jin003-l236-note)

<a id="jin003-l237-event"></a>

16. **梁国白龙。** 十一月，梁国报告白龙两次。 [[16]](#jin003-l237-note)

<a id="jin003-l238-event"></a>

17. **征皇甫谧、封杨骏与奖清白官。** 十二月，征安定处士皇甫谧为太子中庶子；此为征召，不据此断言已就职。封皇后之父镇军将军杨骏临晋侯。因平州刺史傅询、前广平太守孟桓清白有声，分别赐帛二百匹、一百匹。 [[17]](#jin003-l238-note)

### 1. 孙皓因石函改元，遣使赴阳羡国山行礼

[返回正文第1条](#sg-event-1)

<a id="sgz048-b-2370-1"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2370-1)** · [TXT L127](../../拆分史书/三国志/卷048.txt#L127)

> 天璽元年，吳郡言臨平湖自漢末草穢壅塞，今更開通。長老相傳，此湖塞，天下亂，此湖開，天下平。又於湖邊得石函，中有小石，青白色，長四寸，廣二寸餘，刻上作皇帝字，於是改年，大赦。

**吴以临平湖开与石函为瑞，改元天玺** 当地报临平湖复通，又获石函刻有皇帝字。孙皓信为吉祥，改元并赦。

**归年依据** 本传天玺元年。

<a id="sg048-l2370-e1"></a>

見[本卷引文](ce-0276.md#sgz048-b-2370-1)。

<a id="wu-tianfa-shenchen"></a>

**金石补证** 严可均《全三国文》卷七十五据碑本录《天发神谶碑》，纪年作「天玺元年桼月」，下文又记「以八月一日，詔遣」，叙多次遣官释读石文，随后称刊铭。国家图书馆所藏明拓著录为天玺元年七月立，碑中七月、八月是查验和释读的时日，现存文字未见立碑确日。

**撰书异说** 《建康实录》卷四记岩山立石纪吴功德，引《吴录》称华覈撰文，记有皇象书写一说又表示怀疑。碑末存「蘭臺東觀令」而姓名残缺，华覈在[275 年已免官](ce-0275.md#wu065-l88-2)，严可均因此将碑文编入阙名类。

<a id="sg-note-4"></a>

<a id="sg-note-5"></a>

<a id="sgz048-b-2370-4"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2370-4)** · [TXT L129](../../拆分史书/三国志/卷048.txt#L129)

> 鄱陽言歷陽山石文理成字，凡二十，云「楚九州渚，吳九州都，揚州士，作天子，四世治，太平始」。

<a id="sgz048-p-033-1"></a>

**[《三國志·三嗣主傳》 裴注 033·1](../../拆分史书/三国志/卷048.md#pei-033-1)** · [TXT L130](../../拆分史书/三国志/卷048.txt#L130)

> 江表傳曰：歷陽縣有石山臨水，高百丈，其三十丈所，有七穿駢羅，穿中色黃赤，不與本體相似，俗相傳謂之石印。又云，石印封發，天下當太平。下有祠屋，巫祝言石印神有三郎。時歷陽長表上言石印發，皓遣使以太牢祭歷山。巫言，石印三郎說「天下方太平」。使者作高梯，上看印文，詐以朱書石作二十字，還以啟皓。皓大喜曰：「吳當爲九州作都、渚乎！從大皇帝逮孤四世矣，太平之主，非孤復誰？」重遣使，以印綬拜三郎爲王，又刻石立銘，襃贊靈德，以荅休祥。

**释读** 地方传有石印开启可太平，巫说三郎掌石印，孙皓遣使祭祀。使者登梯窥石，假用朱笔写二十字，孙皓信而封神并立碑。
**归年** 天玺元年历阳石文、阳羡封禅背景；解释为造假是引书原说。

<a id="sgz048-b-2370-4-cont-l131"></a>

**[《三國志·三嗣主傳》續文](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2370-4-cont-l131)** · [TXT L131](../../拆分史书/三国志/卷048.txt#L131)

> 又吳興陽羨山有空石，長十餘丈，名曰石室，在所表爲大瑞。乃遣兼司徒董朝、兼太常周處至陽羨縣，封襌國山。明年改元，大赦，以恊石文。

**吴谣传历阳石文与阳羡石室，封禅国山** 历阳山称有石文二十字，阳羡山石室也被上报为瑞。吴遣董朝、周处在阳羡封禅国山，次年用石文意旨改元、赦。

**归年依据** 本传天玺元年遣使，下一年改天纪；《江表传》又称石文作伪。

**校讀** 本傳作「歷陽山」。《資治通鑑》胡三省注以鄱陽郡有歷陵，疑「陽」當作「陵」。

**异文与补证** 《孙皓传》称二人因不出算缗被斩；裴注引《江表传》另述车浚因会稽大旱请赈，被孙皓认为收买人心而杀害。

<a id="sgz048-b-2370-2"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2370-2)** · [TXT L127](../../拆分史书/三国志/卷048.txt#L127)

> 會稽太守車浚、湘東太守張詠不出筭緡，就在所斬之，徇首諸郡。

**车浚张咏因算缗案被杀** 会稽车浚、湘东张咏未缴算缗钱，吴朝在当地杀二人并传首。

**归年依据** 本传天玺元年，《江表传》车浚还因荒旱奏振贷。

<a id="sgz048-p-032-1"></a>

**[《三國志·三嗣主傳》 裴注 032·1](../../拆分史书/三国志/卷048.md#pei-032-1)** · [TXT L128](../../拆分史书/三国志/卷048.txt#L128)

> 江表傳曰：浚在公清忠，值郡荒旱，民無資糧，表求振貸。皓謂浚欲樹私恩，遣人梟首。

**归年** 天玺元年车浚事，正文只言不出算缗；两种解释并存。

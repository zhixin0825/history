# 公元276年｜晋咸宁二年／吴天玺元年

[← 公元275年](ce-0275.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元277年 →](ce-0277.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **孙皓借临平湖石函改元天玺。** 吴郡报临平湖复通，并获刻有「皇帝」字样之石，孙皓改元大赦。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **车浚、张咏因算缗被杀。** 会稽太守车浚、湘东太守张咏因未出算缗就地受诛，首级示诸郡。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **孙楷投晋。** 秋八月，吴京下督孙楷投降西晋。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **吴遣使阳羡封禅国山。** 孙皓因鄱阳石文及阳羡空石而遣董朝、周处至阳羡封禅，次年又改元。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **征楷为宫下镇骠骑将军。** 天玺元年，征楷为宫下镇骠骑将军。 [[5]](#sg-note-5)

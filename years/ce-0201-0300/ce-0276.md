# 公元276年｜晋咸宁二年／吴天玺元年

[← 公元275年](ce-0275.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元277年 →](ce-0277.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **孙皓借临平湖石函改元天玺。** 吴郡报临平湖复通，并获刻有「皇帝」字样之石，孙皓改元大赦。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **车浚、张咏因算缗被杀。** 会稽太守车浚、湘东太守张咏因未出算缗就地受诛，首级示诸郡。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **孙楷投晋。** 秋八月，吴京下督孙楷投降西晋。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **吴遣使阳羡封禅国山。** 孙皓因鄱阳石文及阳羡空石而遣董朝、周处至阳羡封禅，次年又改元。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **征楷为宫下镇骠骑将军。** 天玺元年，征楷为宫下镇骠骑将军。 [[5]](#sg-note-5)

<a id="sgz-event-6"></a>

6. **车浚张咏因算缗案被杀。** 会稽车浚、湘东张咏未缴算缗钱，吴朝在当地杀二人并传首。 [[6]](#sgz-note-6)

<a id="sgz-event-7"></a>

7. **《江表传》记车浚为荒民请发公粮被杀。** 会稽荒旱，车浚上表请赈，孙皓指他行私恩，遣人杀害。 [[7]](#sgz-note-7)

### 1. 孙皓借临平湖石函改元天玺

[返回正文第1条](#sg-event-1)

<a id="sg048-l2370-e1"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p009)** · [仓内TXT L2370](../../sources/本地分卷/三国志/三国志-卷048.md#l2370)

> 又於湖邊得石函，中有小石，青白色，長四寸，廣二寸餘，刻上作皇帝字，於是改年，大赦。

<a id="sgz048-b-2370-1"></a>

**[《三国志·三嗣主传》仓内原文 L2370](../../sources/本地分卷/三国志/三国志-卷048.md#l2370)**

> ﻿天璽元年，吳郡言臨平湖自漢末草穢壅塞，今更開通。長老相傳，此湖塞，天下亂，此湖開，天下平。又於湖邊得石函，中有小石，青白色，長四寸，廣二寸餘，刻上作皇帝字，於是改年，大赦。

**释读** 当地报临平湖复通，又获石函刻有皇帝字。孙皓信为吉祥，改元并赦。

**归年** 本传天玺元年。

### 3. 孙楷投晋

[返回正文第3条](#sg-event-3)

<a id="sg048-l2370-e3"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p009)** · [仓内TXT L2370](../../sources/本地分卷/三国志/三国志-卷048.md#l2370)

> 秋八月，京下督孫楷降晉。

<a id="sgz051-b-2464-13"></a>

**[《三国志·宗室传》仓内原文 L2464](../../sources/本地分卷/三国志/三国志-卷051.md#l2464)**

> 天璽元年，征楷為宮下鎮驃騎將軍。

**释读** 孙皓征召孙楷，改任宫下镇骠骑将军。

**归年** 本传明记天玺元年；随后孙楷来降晋。

<a id="sgz051-b-2464-16"></a>

**[《三国志·宗室传》仓内原文 L2464](../../sources/本地分卷/三国志/三国志-卷051.md#l2464)**

> 而卒被召，遂將妻子親兵數百人歸晉，晉以為車騎將軍，封丹楊侯。

**释读** 孙楷终于被召时携妻儿与亲兵数百投晋，晋任车骑将军、丹杨侯。

**归年** 《三嗣主传·孙皓传》天玺元年秋八月，《晋书·武帝纪》咸宁二年夏六月，月份异，均276年。

<a id="sg-note-4"></a>

### 4. 吴遣使阳羡封禅国山

[返回正文第4条](#sg-event-4)

<a id="sg048-l2370-e4"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p009)** · [仓内TXT L2370](../../sources/本地分卷/三国志/三国志-卷048.md#l2370)

> 乃遣兼司徒董朝、兼太常周處至陽羨縣，封襌國山。

<a id="sgz048-b-2370-4"></a>

**[《三国志·三嗣主传》仓内原文 L2370](../../sources/本地分卷/三国志/三国志-卷048.md#l2370)**

> 鄱陽言歷陽山石文理成字，凡二十，雲「楚九州渚，吳九州都，揚州士，作天子，四世治，太平始」。又吳興陽羨山有空石，長十餘丈，名曰石室，在所表爲大瑞。乃遣兼司徒董朝、兼太常周處至陽羨縣，封襌國山。明年改元，大赦，以恊石文。

**释读** 历阳山称有石文二十字，阳羡山石室也被上报为瑞。吴遣董朝、周处在阳羡封禅国山，次年用石文意旨改元、赦。

**归年** 本传天玺元年遣使，下一年改天纪；《江表传》又称石文作伪。

<a id="sgz048-p-033-1"></a>

**[《三国志·三嗣主传》裴注 033·1](../../sources/摘录/三国志-卷048-三嗣主传裴注.md#pei-033-1)**

> 江表傳曰歴陽縣有石山臨水髙百丈其三十丈所有七穿駢羅穿中色黄赤不與本體相似俗相傳謂之石印又云石印封發天下當太平下有祠屋巫祝言石印神有三郎時歴陽長表上言石印發晧遣使以太牢祭歴山巫言石印三郎説天下方太平使者作髙梯上看印文詐以朱書石作二十字還以啓晧晧大喜曰呉當為九州作都渚乎從大皇帝及孤四世矣太平之主非孤復誰重遣使以印綬拜三郎為王又刻石立銘褒贊靈徳以答休祥

**释读** 地方传有石印开启可太平，巫说三郎掌石印，孙皓遣使祭祀。使者登梯窥石，假用朱笔写二十字，孙皓信而封神并立碑。

**归年** 天玺元年历阳石文、阳羡封禅背景；解释为造假是引书原说。

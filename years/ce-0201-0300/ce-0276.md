1. **孙皓因石函改元，遣使赴阳羡国山行礼。** 吴郡报临平湖复通，并获刻有「皇帝」字样之石，孙皓改元大赦。 孙皓因鄱阳石文及阳羡空石而遣董朝、周处至阳羡封禅，次年又改元。 [[1]](#sg-note-1)

<a id="sgz-event-6"></a>

2. **孙皓杀会稽太守车浚、湘东太守张咏。** 孙皓杀会稽太守车浚、湘东太守张咏，将二人首级示于诸郡。 [[2]](#sg-note-2)

<a id="sgz-event-8"></a>

3. **孙皓杀尚书熊睦。** 尚书熊睦见孙皓施政严酷，婉言相劝，被孙皓命人以刀环击杀。 [[3]](#sgz-note-8)

<a id="sg-event-3"></a>

<a id="sg-event-5"></a>

4. **孙楷被吴征召后奔晋。** 孙皓征召京下督孙楷为宫下镇骠骑将军。孙楷疑惧，率妻儿及亲兵奔晋。晋授孙楷车骑将军，封丹杨侯。 [[4]](#sg-note-3)

## 本年相关史料

<a id="sg-note-1"></a>

### 1. 孙皓因石函改元，遣使赴阳羡国山行礼

[返回正文第1条](#sg-event-1)

<a id="sgz048-b-2370-1"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sgz048-b-2370-1)** · [TXT L127](../../sources/本地分卷/三国志/三国志-卷048.txt#L127)

> 天璽元年，吳郡言臨平湖自漢末草穢壅塞，今更開通。長老相傳，此湖塞，天下亂，此湖開，天下平。又於湖邊得石函，中有小石，青白色，長四寸，廣二寸餘，刻上作皇帝字，於是改年，大赦。

**吴以临平湖开与石函为瑞，改元天玺** 当地报临平湖复通，又获石函刻有皇帝字。孙皓信为吉祥，改元并赦。

**归年依据** 本传天玺元年。

見[本卷引文](ce-0276.md#sgz048-b-2370-1)。

<a id="sg-note-4"></a>

<a id="sg-note-5"></a>

<a id="sgz048-b-2370-4"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sgz048-b-2370-4)** · [TXT L129](../../sources/本地分卷/三国志/三国志-卷048.txt#L129)

> 鄱陽言歷陽山石文理成字，凡二十，云「楚九州渚，吳九州都，揚州士，作天子，四世治，太平始」。

<a id="sgz048-p-033-1"></a>

**[《三國志·三嗣主傳》 裴注 033·1](../../sources/本地分卷/三国志/三国志-卷048.md#pei-033-1)** · [TXT L130](../../sources/本地分卷/三国志/三国志-卷048.txt#L130)

> 江表傳曰：歷陽縣有石山臨水，高百丈，其三十丈所，有七穿駢羅，穿中色黃赤，不與本體相似，俗相傳謂之石印。又云，石印封發，天下當太平。下有祠屋，巫祝言石印神有三郎。時歷陽長表上言石印發，皓遣使以太牢祭歷山。巫言，石印三郎說「天下方太平」。使者作高梯，上看印文，詐以朱書石作二十字，還以啟皓。皓大喜曰：「吳當爲九州作都、渚乎！從大皇帝逮孤四世矣，太平之主，非孤復誰？」重遣使，以印綬拜三郎爲王，又刻石立銘，襃贊靈德，以荅休祥。

**释读** 地方传有石印开启可太平，巫说三郎掌石印，孙皓遣使祭祀。使者登梯窥石，假用朱笔写二十字，孙皓信而封神并立碑。
**归年** 天玺元年历阳石文、阳羡封禅背景；解释为造假是引书原说。

<a id="sgz048-b-2370-4-cont-l131"></a>

**[《三國志·三嗣主傳》續文](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sgz048-b-2370-4-cont-l131)** · [TXT L131](../../sources/本地分卷/三国志/三国志-卷048.txt#L131)

> 又吳興陽羨山有空石，長十餘丈，名曰石室，在所表爲大瑞。乃遣兼司徒董朝、兼太常周處至陽羨縣，封襌國山。明年改元，大赦，以恊石文。

**吴谣传历阳石文与阳羡石室，封禅国山** 历阳山称有石文二十字，阳羡山石室也被上报为瑞。吴遣董朝、周处在阳羡封禅国山，次年用石文意旨改元、赦。

**归年依据** 本传天玺元年遣使，下一年改天纪；《江表传》又称石文作伪。

**校讀** 本傳作「歷陽山」。《資治通鑑》胡三省注以鄱陽郡有歷陵，疑「陽」當作「陵」。

### 2. 孙皓杀会稽太守车浚、湘东太守张咏

[返回正文第2条](#sg-event-2)

<a id="sgz-note-6"></a>

<a id="sgz-note-7"></a>

**异文与补证** 《孙皓传》称二人因不出算缗被斩；裴注引《江表传》另述车浚因会稽大旱请赈，被孙皓认为收买人心而杀害。

<a id="sgz048-b-2370-2"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sgz048-b-2370-2)** · [TXT L127](../../sources/本地分卷/三国志/三国志-卷048.txt#L127)

> 會稽太守車浚、湘東太守張詠不出筭緡，就在所斬之，徇首諸郡。

**车浚张咏因算缗案被杀** 会稽车浚、湘东张咏未缴算缗钱，吴朝在当地杀二人并传首。

**归年依据** 本传天玺元年，《江表传》车浚还因荒旱奏振贷。

<a id="sgz048-p-032-1"></a>

**[《三國志·三嗣主傳》 裴注 032·1](../../sources/本地分卷/三国志/三国志-卷048.md#pei-032-1)** · [TXT L128](../../sources/本地分卷/三国志/三国志-卷048.txt#L128)

> 江表傳曰：浚在公清忠，值郡荒旱，民無資糧，表求振貸。皓謂浚欲樹私恩，遣人梟首。

**归年** 天玺元年车浚事，正文只言不出算缗；两种解释并存。

### 3. 孙皓杀尚书熊睦

[返回正文第3条](#sgz-event-8)

**异文与补证** 《江表传》书其遇害，《资治通鉴》系于天玺元年。

<a id="period-sgz048-p-032-2"></a>

**[《三國志·三嗣主傳》 裴注 032·2](../../sources/本地分卷/三国志/三国志-卷048.md#pei-032-2)** · [TXT L128](../../sources/本地分卷/三国志/三国志-卷048.txt#L128)

> 又尚書熊睦見皓酷虐，微有所諫，皓使人以刀環撞殺之，身無完肌。

**釋讀** 尚书熊睦见孙皓酷虐稍加劝谏，被人用刀环击杀。

**时段与依据** 孙皓在位，忤旨与受刑的年无载。

**歸年** 《資治通鑑》卷八十繫於吳天璽元年。

### 4. 孙楷被吴征召后奔晋

[返回正文第4条](#sg-event-3)

**异文与补证** 孙楷奔晋，《孙皓传》系秋八月，《晋书·武帝纪》《资治通鉴》系六月。

<a id="sg048-l2370-e3"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sg048-l2370-e3)** · [TXT L129](../../sources/本地分卷/三国志/三国志-卷048.txt#L129)

> 秋八月，京下督孫楷降晉。

**孙楷降晋** 京下督孙楷于秋八月逃晋。

**归年依据** 本传天玺元年，《晋书·武帝纪》亦载。

> 而卒被召，遂將妻子親兵數百人歸晉，晉以爲車騎將軍，封丹楊侯。

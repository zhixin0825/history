## 本年概述

晋任司马亮为宗师，大规模调整宗室封国，并命文俶等讨边。孙慎出兵江夏、汝南，掳走居民；多州水灾、风霜寒冻并见。


<a id="jin003-u239-1-event"></a>
<a id="jin003-l239-event"></a>

1. **正月朔日食。** 正月丙子朔，发生日食。 [[1]](#jin003-u239-1-note)

<a id="jin003-u239-2-event"></a>

2. **司马裕、司马敦封王。** 正月，立皇子司马裕为始平王，安平穆王司马隆之弟司马敦为安平王。 [[2]](#jin003-u239-2-note)

<a id="jin003-u239-3-event"></a>

3. **司马亮任宗师。** 正月，以卫将军、扶风王司马亮为宗师，宗族当施行的事务向他咨询。诏书说，宗室是国家枝叶，本应奉德义为天下表率，但富贵中能慎行者少，援召穆公纠合兄弟、赋《常棣》的故事说明敦睦宗族。 [[3]](#jin003-u239-3-note)

<a id="jin003-u239-4-event"></a>

4. **司马裕去世。** 正月庚寅，始平王司马裕去世。 [[4]](#jin003-u239-4-note)

<a id="jin003-u239-5-event"></a>

5. **西方见孛星。** 正月，西方出现孛星。 [[5]](#jin003-u239-5-note)

<a id="jin003-u239-6-event"></a>

6. **卫瓘讨鲜卑力微。** 正月，命征北大将军卫瓘讨鲜卑力微。 [[6]](#jin003-u239-6-note)

<a id="sgz-event-3"></a>

7. **文淑讨树机能。** 三月，平虏护军文俶出讨树机能等，击破各部。 [[7]](#sgz-note-3)

<a id="jin003-u240-2-event"></a>
<a id="jin003-l240b-event"></a>

8. **胃宿见孛星。** 三月，胃宿出现孛星。 [[8]](#jin003-u240-2-note)

<a id="jin003-u240-3-event"></a>

9. **因惜麦苗停止射雉。** 三月乙未，司马炎将要射雉，担心损伤麦苗而停止。 [[9]](#jin003-u240-3-note)

<a id="jin003-u241-1-event"></a>
<a id="jin003-l241-event"></a>

10. **邵凯、夏祥率众归附。** 五月戊子，吴将邵凯、夏祥率七千余人来降。 [[10]](#jin003-u241-1-note)

<a id="jin003-u242-1-event"></a>
<a id="jin003-l242-event"></a>

11. **益梁水灾。** 六月，益、梁两州八郡水灾，死三百余人，军储邸阁及别仓被淹。 [[11]](#jin003-u242-1-note)

<a id="jin003-u243-1-event"></a>
<a id="jin003-l243-event"></a>

12. **王浑都督扬州。** 七月，改都督豫州诸军王浑为都督扬州诸军。 [[12]](#jin003-u243-1-note)

<a id="jin003-u243-2-event"></a>

13. **司马睦降丹水侯。** 七月，中山王司马睦因罪被废为丹水侯。 [[13]](#jin003-u243-2-note)

<a id="jin003-u244-1-event"></a>
<a id="jin003-l244-event"></a>

14. **诸王徙封。** 八月癸亥，司马亮由扶风徙汝南，司马伷由东莞徙琅邪，司马骏由汝阴徙扶风，司马伦由琅邪徙赵，司马辅由渤海徙太原，司马颙由太原徙河间，司马陵由北海徙任城，司马斌由陈徙西河，司马柬由汝南徙南阳，司马耽由济南徙中山，司马威由河间徙章武。 [[14]](#jin003-u244-1-note)

<a id="jin003-u244-2-event"></a>

15. **封皇子，诏改封羊祜。** 八月，封皇子司马玮为始平王、允为濮阳王、该为新都王、遐为清河王；诏改钜平侯羊祜为南城侯，羊祜辞而未受，司马炎准许。 [[15]](#jin003-u244-2-note)

<a id="jin003-u244-3-event"></a>

16. **司马亮任镇南大将军。** 八月，以汝南王司马亮为镇南大将军。 [[16]](#jin003-u244-3-note)

<a id="jin003-u244-4-event"></a>

17. **大风暴寒与霜灾。** 八月，大风拔树，骤寒结冰，五郡国降霜，损伤谷物。 [[17]](#jin003-u244-4-note)

<a id="jin003-u245-1-event"></a>
<a id="jin003-l245-event"></a>

18. **胡奋督江北。** 九月戊子，以左将军胡奋都督江北诸军。 [[18]](#jin003-u245-1-note)

<a id="jin003-u245-2-event"></a>

19. **七州水灾，朝廷赈给。** 九月，兖、豫、徐、青、荆、益、梁七州大水，伤秋作物，诏令赈给。 [[19]](#jin003-u245-2-note)

<a id="jin003-u245-3-event"></a>

20. **司马蕤、司马赞封王。** 九月，封齐王之子司马蕤为辽东王、司马赞为广汉王。 [[20]](#jin003-u245-3-note)

<a id="jin003-u246-1-event"></a>
<a id="jin003-l246-event"></a>

21. **宣武观阅军。** 十一月丙戌，司马炎临宣武观大阅，至壬辰结束。 [[21]](#jin003-u246-1-note)

<a id="sg-event-1"></a>

22. **孙慎掠江夏汝南。** 吴夏口督孙慎出兵江夏、汝南，烧掠居民，掳走一千余家后退去。 [[22]](#sg-note-1)

<a id="jin003-u248-1-event"></a>
<a id="jin003-l248-event"></a>

23. **本年诸部归附汇报。** 本年，西北诸部及鲜卑、匈奴、五溪诸部、东夷三国等，前后十余批各率部落归附。 [[23]](#jin003-u248-1-note)

<a id="sg-event-2"></a>

24. **孙皓宠臣张俶被诛。** 张俶以谗言进身，任司直中郎将并封侯，后奸情暴露伏诛。 [[24]](#sg-note-2)

### 24. 孙皓宠臣张俶被诛

[返回正文第24条](#sg-event-2)

<a id="sgz048-b-2371-2"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2371-2)** · [TXT L133](../../拆分史书/三国志/卷048.txt#L133)

> 初，騶子張俶多所譖白，累遷爲司直中郎將，封侯，甚見寵愛，是歲姦情發聞，伏誅。

**孙皓诛亲幸张俶** 张俶靠谮告升司直中郎将、封侯，取得宠信；当年奸事败露被诛。

**归年依据** 本传天纪元年，历官是早事回顾。

<a id="sgz048-p-034-1"></a>

**[《三國志·三嗣主傳》 裴注 034·1](../../拆分史书/三国志/卷048.md#pei-034-1)** · [TXT L134](../../拆分史书/三国志/卷048.txt#L134)

> 江表傳曰：俶父，會稽山陰縣卒也，知俶不良，上表云：「若用俶爲司直，有罪乞不從坐。」皓許之。俶表正彈曲二十人，專糾司不法，於是愛惡相攻，互相謗告。彈曲承言，收繫囹圄，聽訟失理，獄以賄成。人民窮困，無所措手足。俶奢淫無厭，取小妻三十餘人，擅殺無辜，衆姦並發，父子俱見車裂。

**释读** 父张俶有预防连坐之请。张俶设二十人纠治，控告混杂、枉狱受贿；因奢侈、擅杀暴露，张俶父子都受车裂。
**归年** 本传天纪元年奸情发而诛；长期办事属前史，附末事。

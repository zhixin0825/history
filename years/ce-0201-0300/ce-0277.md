# 公元277年｜晋咸宁三年／吴天纪元年

[← 公元276年](ce-0276.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元278年 →](ce-0278.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **孙慎出兵江夏、汝南。** 《吴主传》系夏，吴夏口督孙慎出兵江夏、汝南，史载其烧掠居民；《武帝纪》系十二月，并记掳走一千余家后退去。两书记月不同，不拆成两次同样的行动。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓宠臣张俶被诛。** 张俶以谗言进身，任司直中郎将并封侯，后奸情暴露伏诛。 [[2]](#sg-note-2)

<a id="sgz-event-3"></a>

3. **文俶督军破凉州樹机能等。** 三月，平虏护军文俶率军击破树机能等。 **《武帝纪》补记：** 三月，平虏护军文淑讨树机能等叛乱诸部，击破其军。文淑即文俶的姓名异写，不另造一名将领。 [[3]](#sgz-note-3)

<a id="jin003-l239-event"></a>

4. **日食、封王与司马亮任宗师。** 正月丙子朔日食；封皇子司马裕始平王、司马隆之弟司马敦安平王。诏说宗室是国家枝叶，希望以德义为天下表率，但富贵中慎行者少，举召穆公合兄弟、赋《常棣》（本纪作“唐棣”）的故事，任卫将军司马亮为宗师，宗族施行之事向他咨询。庚寅，司马裕去世；西方有孛星；命卫瓘讨鲜卑力微。 [[4]](#jin003-l239-note)

<a id="jin003-l240b-event"></a>

5. **孛星与停止射雉。** 胃宿有孛星。乙未，司马炎将射雉，担心损伤麦苗而停止。 [[5]](#jin003-l240b-note)

<a id="jin003-l241-event"></a>

6. **邵凯、夏祥率众归附。** 夏五月戊子，吴将邵凯、夏祥率七千余人归降。 [[6]](#jin003-l241-note)

<a id="jin003-l242-event"></a>

7. **益梁水灾。** 六月，益、梁八郡水灾，死三百余人，官府邸阁及别仓被淹。 [[7]](#jin003-l242-note)

<a id="jin003-l243-event"></a>

8. **王浑调督扬州与司马睦降爵。** 七月，以原督豫州军事的王浑改督扬州；中山王司马睦因罪废为丹水侯。 [[8]](#jin003-l243-note)

<a id="jin003-l244-event"></a>

9. **八月宗王徙封与灾害。** 八月癸亥，徙司马亮扶风为汝南，伷东莞为琅邪，骏汝阴为扶风，伦琅邪为赵，辅渤海为太原，颙太原为河间，陵北海为任城，斌陈为西河，柬汝南为南阳，耽济南为中山，威河间为章武。封皇子玮始平王、允濮阳王、该新都王、遐清河王；诏改封羊祜为南城侯；《羊祜传》另记他辞让而未接受、皇帝准许，故这里是授封命令，不能直接写成已受新爵。任司马亮镇南大将军。大风拔树，骤寒结冰，五郡国降霜伤谷。徙封前后的王号不能混用为同一时期的爵号。 [[9]](#jin003-l244-note)

<a id="jin003-l245-event"></a>

10. **胡奋督江北、七州水灾与齐王子受封。** 九月戊子，以左将军胡奋都督江北军事。兖、豫、徐、青、荆、益、梁七州大水，伤秋庄稼，诏赈给。封齐王之子司马蕤辽东王、司马赞广汉王。 [[10]](#jin003-l245-note)

<a id="jin003-l246-event"></a>

11. **宣武观阅军。** 冬十一月丙戌，到宣武观大阅，至壬辰结束。 [[11]](#jin003-l246-note)

<a id="jin003-l248-event"></a>

12. **本年诸部归附汇报。** 本年西北各部及鲜卑、匈奴、五溪诸部、东夷三国，前后十余批各率族众部落来附。本纪未为每批分别标日，也不把“归附”一律等同于全境纳入郡县。 [[12]](#jin003-l248-note)

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2371-2)** · [TXT L133](../../拆分史书/三国志/卷048.txt#L133)

> 初，騶子張俶多所譖白，累遷爲司直中郎將，封侯，甚見寵愛，是歲姦情發聞，伏誅。

**孙皓诛亲幸张俶** 张俶靠谮告升司直中郎将、封侯，取得宠信；当年奸事败露被诛。

**归年依据** 本传天纪元年，历官是早事回顾。

<a id="sgz048-p-034-1"></a>

**[《三國志·三嗣主傳》 裴注 034·1](../../拆分史书/三国志/卷048.md#pei-034-1)** · [TXT L134](../../拆分史书/三国志/卷048.txt#L134)

> 江表傳曰：俶父，會稽山陰縣卒也，知俶不良，上表云：「若用俶爲司直，有罪乞不從坐。」皓許之。俶表正彈曲二十人，專糾司不法，於是愛惡相攻，互相謗告。彈曲承言，收繫囹圄，聽訟失理，獄以賄成。人民窮困，無所措手足。俶奢淫無厭，取小妻三十餘人，擅殺無辜，衆姦並發，父子俱見車裂。

**释读** 父张俶有预防连坐之请。张俶设二十人纠治，控告混杂、枉狱受贿；因奢侈、擅杀暴露，张俶父子都受车裂。
**归年** 本传天纪元年奸情发而诛；长期办事属前史，附末事。

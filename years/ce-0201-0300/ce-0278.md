# 公元278年｜晋咸宁四年／吴天纪二年

[← 公元277年](ce-0277.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元279年 →](ce-0279.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **郤正去世。** 郤正入晋后历任安阳令、巴西太守，咸宁四年卒。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **吴封成纪、宣威等十一王。** 秋七月孙皓立十一王，每王给兵三千，同时大赦。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **孙皓召陆式还建业，恢复官爵。** 陆式在天纪二年被召还建业，复将军及侯爵。 [[3]](#sg-note-3)

<a id="sgz-event-4"></a>

4. **李胤任西晋司徒。** 晋以尚书令李胤为司徒。 [[4]](#sgz-note-4)

<a id="sgz-event-5"></a>

5. **何曾去世谥元公。** 何曾八十余岁去世，谥元公。 [[5]](#sgz-note-5)

<a id="sgz-event-6"></a>

6. **王恂去世，赠车骑将军。** 四十余岁卒，赠车骑将军。 [[6]](#sgz-note-6)

<a id="sgz-event-7"></a>

7. **杜预代羊祜督荆州。** 《杜氏新书》总称晋功及任征南大将军、开府。 [[7]](#sgz-note-7)

<a id="sgz-event-8"></a>

8. **卢钦去世，赠卫将军与开府。** 卢钦卒于咸宁四年，死后追赠卫将军、开府。 [[8]](#sgz-note-8)

<a id="wu065-event-hua-he-death"></a>

9. **吴右国史华覈去世。** 五月，华覈去世，年六十。他曾任东观令、领右国史，275 年免职。 [[9]](#wu065-note-hua-he-death)

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l114-3)** · [TXT L114](../../拆分史书/三国志/卷061.txt#L114)

### 9. 吴右国史华覈去世

[返回正文第9条](#wu065-event-hua-he-death)

<a id="wu065-l88-3"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l88-3)** · [TXT L88](../../拆分史书/三国志/卷065.txt#L88)

**归年** 本传记华覈于[天册元年（275）免官](ce-0275.md#wu065-l88-2)，数年后卒。唐许嵩《建康实录》卷四明确记为天纪二年（278）夏五月：“二年夏五月，右國史、徐陵亭侯華覈卒。”又记“卒，時年六十”。句末韦曜、华覈著述传世是本传总结，无独立纪年。

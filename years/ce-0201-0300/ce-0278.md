# 公元278年｜晋咸宁四年／吴天纪二年

[← 公元277年](ce-0277.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元279年 →](ce-0279.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **郤正去世。** 郤正入晋后历任安阳令、巴西太守，咸宁四年卒。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **吴封成纪、宣威等十一王。** 秋七月孙皓立十一王，每王给兵三千，同时大赦。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **孙皓召陆式还建业，恢复官爵。** 陆式在天纪二年被召还建业，复将军及侯爵。 [[3]](#sg-note-3)

<a id="sgz-event-4"></a>

4. **李胤任西晋司徒。** 晋以尚书令李胤为司徒。 [[4]](#sgz-note-4)

<a id="sgz-event-5"></a>

5. **何曾去世，后改谥元。** 十二月丁未，太宰何曾去世，年约八十，初谥孝，太康末改谥为元。 [[5]](#sgz-note-5)

<a id="sgz-event-6"></a>

6. **王恂去世，赠车骑将军。** 四十余岁卒，赠车骑将军。 [[6]](#sgz-note-6)

<a id="sgz-event-7"></a>

7. **杜预代羊祜督荆州。** 羊祜病中举荐杜预自代。十一月羊祜去世，晋廷任杜预统领荆州诸军，号镇南大将军。 [[7]](#sgz-note-7)

<a id="sgz-event-8"></a>

8. **卢钦去世，赠卫将军与开府。** 三月甲申，尚书左仆射卢钦去世，晋追赠卫将军、开府仪同三司。 [[8]](#sgz-note-8)

<a id="wu065-event-hua-he-death"></a>

9. **吴右国史华覈去世。** 五月，华覈去世，年六十。他曾任东观令、领右国史，275 年免职。 [[9]](#wu065-note-hua-he-death)

<a id="sgz-event-10"></a>

10. **张尚获罪，被遣建安造船，后来遇害。** 秋，孫皓因張尚以「百觚」形容他的酒量，認定張尚譏諷自己，將他收押，並追究此前教琴時的答話。尚書岑昏領百餘人為張尚求情，孫皓免他死罪，遣往建安造船，後來仍將他殺害。 [[10]](#sgz-note-10)

### 10. 张尚获罪，被遣建安造船，后来遇害

[返回正文第10条](#sgz-event-10)

<a id="wu053-l32-3"></a>

**[《三國志·張嚴程闞薛傳》正文](../../拆分史书/三国志/卷053.md#edition-wu053-l32-3)** · [TXT L32](../../拆分史书/三国志/卷053.txt#L32)

> 後積他事下獄，皆追以此爲詰，

**釋讀** 張尚後因別事下獄，又遭追究先前的琴事。

<a id="wu053-l33-2"></a>

**[《三國志·張嚴程闞薛傳》裴注 012](../../拆分史书/三国志/卷053.md#edition-wu053-l33-2)** · [TXT L33](../../拆分史书/三国志/卷053.txt#L33)

> 後問：「孤飲酒以方誰？」尚對曰：「陛下有百觚之量。」皓云：「尚知孔丘之不王，而以孤方之！」因此發怒收尚。尚書岑昏率公卿已下百餘人，詣宮叩頭請，尚罪得減死。

**釋讀** 孫皓問其酒量可比誰。張尚稱他有百觚酒量，孫皓覺得是在以孔子不為王來比自己，遂捕張尚。岑昏率群臣乞免，張尚得減死。

<a id="wu053-l34-1"></a>

**[《三國志·張嚴程闞薛傳》正文](../../拆分史书/三国志/卷053.md#edition-wu053-l34-1)** · [TXT L34](../../拆分史书/三国志/卷053.txt#L34)

> 送建安作船。乆之，又就加誅。

**釋讀** 張尚被送往建安造船。過了一段時間，仍被殺害。

**歸年與異說** [《資治通鑑》卷080](../../史书/025-资治通鉴/KR2b0007_080.txt#L419-L429)在西晉咸寧四年九月條敘張尚下獄，接敘遣往建安、後被殺。本傳以「乆之」說明遣往造船與處決之間隔了一段時間，處決確切月日不詳。《通鑑考異》另引《三十國春秋》說岑昏等請代死、張尚被徙廣州，司馬光參用本傳與《環氏吳紀》，正文取建安說。

# 公元278年｜晋咸宁四年／吴天纪二年

[← 公元277年](ce-0277.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元279年 →](ce-0279.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **郤正去世。** 郤正入晋后历任安阳令、巴西太守，咸宁四年卒。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **吴封成纪、宣威等十一王。** 秋七月孙皓立十一王，每王给兵三千，同时大赦。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **召还建业，复将军、候。** 天纪二年，召还建业，复将军、候。 [[3]](#sg-note-3)

<a id="sgz-event-4"></a>

4. **李胤任西晋司徒。** 《晋阳秋》称李胤官至司徒。 [[4]](#sgz-note-4)

<a id="sgz-event-5"></a>

5. **何曾去世谥元公。** 何曾八十余岁去世，谥元公。 [[5]](#sgz-note-5)

<a id="sgz-event-6"></a>

6. **王恂去世，赠车骑将军。** 四十余岁卒，赠车骑将军。 [[6]](#sgz-note-6)

<a id="sgz-event-7"></a>

7. **杜预代羊祜督荆州。** 《杜氏新书》总称晋功及任征南大将军、开府。 [[7]](#sgz-note-7)

<a id="sgz-event-8"></a>

8. **卢钦去世，赠卫将军与开府。** 卢钦卒于咸宁四年，死后追赠卫将军、开府。 [[8]](#sgz-note-8)

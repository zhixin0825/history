2. **郭马在广州起兵，吴分路征讨。** 修允死后，部曲督郭马不愿旧兵被分拨，又逢吴廷核实广州户口，乃与何典、王族等起事，杀广州督虞授、南海太守刘略，逐刺史徐旗。已迁居广州的王氏兄弟王著、王延不肯受郭马任用，被杀。孙皓任张悌为丞相、何植为司徒，遣滕循从东、陶濬从西，命陶璜调兵协力。晋军南下后，陶濬留武昌。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **晋多路进兵伐吴。** 晋军自涂中、牛渚、武昌、夏口、江陵及长江上游等路攻吴，贾充驻节居中，吴将陶濬因此留在武昌。 **《武帝纪》补记：** 十一月，大举伐吴：司马伷出涂中，安东将军王浑出江西，建威将军王戎出武昌，平南将军胡奋出夏口，镇南大将军杜预出江陵，龙骧将军王濬与广武将军唐彬率巴蜀兵顺江东下，东西合二十余万。太尉贾充任大都督，代理冠军将军杨济为副，统辖各路。本纪“江西”的路线记法与已有牛渚等记法并读，不擅替换原字。 [[3]](#sg-note-3)

<a id="sgz-event-4"></a>

4. **吴以两种菜为瑞，封黄耇吴平。** 黄耇家有鬼目菜，吴平家有另一种形类枇杷的菜。东观按图认作芝、平虑草，授黄耇侍芝郎、吴平平虑郎。 [[4]](#sgz-note-4)

<a id="jin003-l259-event"></a>

5. **树机能陷凉州、马隆出师。** 正月，树机能攻陷凉州。乙丑，命讨虏护军、武威太守马隆征讨。 [[5]](#jin003-l259-note)

<a id="jin003-l260-event"></a>

6. **平原白麟汇报。** 二月甲午，平原报告白麟。 [[6]](#jin003-l260-note)

<a id="jin003-l261-event"></a>

7. **部落归附、饥荒减膳与孛星。** 三月，匈奴都督拔弈虚率部落归附。乙亥，因百姓饥荒，减少一半御膳；柳宿有孛星。 [[7]](#jin003-l261-note)

<a id="jin003-l262-event"></a>

8. **赦罪、解除质任与雹灾。** 夏四月，女御星区又见孛星；大赦，解除部曲督以下家属为质的限制。丁亥，八郡国降雹，伤庄稼、毁居民房屋。本纪把丁亥接在四月段，校家据《五行志》疑其前脱五月；原文仍保留伤秋稼的季节用语，不据缺字另造一次灾害。 [[8]](#jin003-l262-note)

<a id="jin003-l263-event"></a>

9. **紫宫孛星。** 秋七月，紫宫记有孛星。 [[9]](#jin003-l263-note)

<a id="jin003-l264-event"></a>

10. **河南麟瑞汇报。** 九月甲午，河南报告麟。 [[10]](#jin003-l264-note)

<a id="jin003-l265-event"></a>

11. **独雍归附与汲冢竹书纪年。** 冬十月戊寅，匈奴余渠都督独雍等率部归附。汲郡人不准盗掘战国魏王墓，出土竹简古书十余万言，藏于秘府；本纪称小篆、魏襄王墓。出土事本纪系咸宁五年（279），卫恒《四体书势》系太康元年（280），《束晳传》系太康二年（281），又载安釐王墓一说。三个年页互见同一出土事件的异年记载，不写成三次发掘；书体和墓主的不同说法也不强行合一。 [[11]](#jin003-l265-note)

<a id="jin003-l267-event"></a>

12. **马隆平凉州与肃慎贡使。** 十二月，马隆大败树机能军，斩树机能，凉州平定。肃慎献楛木箭、石箭头。 [[12]](#jin003-l267-note)

### 2. 郭马在广州起兵，吴分路征讨

[返回正文第2条](#sg-event-2)

<a id="sgz048-b-2373-1"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2373-1)** · [TXT L138](../../拆分史书/三国志/卷048.txt#L138)

> 三年夏，郭馬反。馬本合浦太守脩允部曲督。允轉桂林太守，疾病，住廣州，先遣馬將五百兵至郡安撫諸夷。允死，兵當分給，馬等累世舊軍，不樂離別。皓時又科實廣州戶口，馬與部曲將何典、王族、吳述、殷興等因此恐動兵民，合聚人衆，攻殺廣州督虞授。馬自號都督交廣二州諸軍事、安南將軍，興廣州刺史，述南海太守。典攻蒼梧，族攻始興。

**郭马及旧部因分拨和核户起事** 原合浦太守脩允病死，部曲将郭马等不愿被分拨；又逢核清广州户口，聚兵民杀广州督虞授。郭马自领都督，与殷兴、吴述等分据、攻苍梧始兴。

**归年依据** 本传天纪三年夏；脩允先时任官和病给本事线索，任期无独立确年。

<a id="period-sgz048-p-035-1"></a>

**[《三國志·三嗣主傳》 裴注 035·1](../../拆分史书/三国志/卷048.md#pei-035-1)** · [TXT L139](../../拆分史书/三国志/卷048.txt#L139)

> 漢晉春秋曰：先是，吳有說讖者曰：「吳之敗，兵起南裔，亡吳者公孫也。」皓聞之，文武職位至于卒伍有姓公孫者，皆徙於廣州，不令停江邊。

**釋讀** 预言说吴亡起于南方、同公孙有关，孙皓命把公孙姓官兵迁往广州，不留江边。

**附敘** 《漢晉春秋》以遷徙公孫氏避讖為郭馬起兵後孫皓之言的背景，遷徙確年未載。

<a id="sgz048-p-035-2"></a>

**[《三國志·三嗣主傳》 裴注 035·2](../../拆分史书/三国志/卷048.md#pei-035-2)** · [TXT L139](../../拆分史书/三国志/卷048.txt#L139)

> 及聞馬反，大懼曰：「此天亡也。」

**释读** 听说郭马起兵，孙皓自叹天要灭吴。
**归年** 本传天纪三年，注记一种反应。

<a id="sgz048-b-2373-2"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2373-2)** · [TXT L140](../../拆分史书/三国志/卷048.txt#L140)

> 八月，以軍師張悌爲丞相，牛渚都督何植爲司徒。執金吾滕循爲司空，未拜，轉鎮南將軍，假節領廣州牧，率萬人從東道討馬，與族遇於始興，未得前。

**张悌任丞相，何植为司徒，滕循领兵议讨郭马** 张悌升丞相，何植任司徒；滕循原任司空尚未受拜，调镇南将军、领广州牧，率万人讨逆，在始兴不能前进。

**归年依据** 本传天纪三年八月。

<a id="sgz048-b-2373-3"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2373-3)** · [TXT L140](../../拆分史书/三国志/卷048.txt#L140)

> 馬殺南海太守劉略，逐廣州刺史徐旗。皓又遣徐陵督陶濬將七千人從西道，命交州牧陶璜部伍所領及合浦、鬱林諸郡兵，當與東西軍共擊馬。

**郭马进一步夺南海，吴三路发军** 郭马杀刘略、逐徐旗。孙皓遣陶濬率军从西路，令交州牧陶璜等配合东西二军。

**归年依据** 本传天纪三年郭马之乱后续。



<a id="sgz065-b-3038-3"></a>

<a id="wu065-l12-3"></a>

**[《三國志·王樓賀韋華傳》正文](../../拆分史书/三国志/卷065.md#edition-wu065-l12-3)** · [TXT L12](../../拆分史书/三国志/卷065.txt#L12)

> 二弟著、延皆作佳器，郭馬起事，不爲馬用，見害。

**釋讀** 王蕃的兩個弟弟王著、王延俱有才器。郭馬起事時，兩人不肯受他任用，因而被殺。

**歸年** 卷048〈孫皓傳〉明記天紀三年夏郭馬在廣州起兵。王氏兄弟之死隨同一場起事合讀，確日未載。

### 4. 吴以两种菜为瑞，封黄耇吴平

[返回正文第4条](#sgz-event-4)

<a id="sgz048-b-2374-1"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2374-1)** · [TXT L142](../../拆分史书/三国志/卷048.txt#L142)

> 有鬼目菜生工人黃耇家，依緣棗樹，長丈餘，莖廣四寸，厚三分。又有買菜生工人吳平家，高四尺，厚三分，如枇杷形，上廣尺八寸，下莖廣五寸，兩邊生葉綠色。東觀案圖，名鬼目作芝草，買菜作平慮草，遂以耇爲侍芝郎，平爲平慮郎，皆銀印青綬。

**吴以两种菜为瑞，封黄耇吴平** 黄耇家有鬼目菜，吴平家有另一种形类枇杷的菜。东观按图认作芝、平虑草，授黄耇侍芝郎、吴平平虑郎。

**归年依据** 本传天纪三年，植物称瑞是政权记录。

### 11. 独雍归附与汲冢竹书纪年

[返回正文第11条](#jin003-l265-event)


<a id="jin003-l265"></a>

> 冬十月戊寅，匈奴餘渠都督獨雍等帥部落歸化。汲郡人不準掘魏襄王冢，得竹簡小篆古書十餘萬言，藏於祕府。

**释读与归年** 依本纪年号年次归入279年；月日仍为史书历日，原文中的追叙、异年与干支疑问见本条正文。 《四体书势》见本书[卫恒传L4937](../../史书/005-晋书/晋书-CCDH.txt#L4937)，亦见《三国志·卫觊传》裴注；[束晳传L6037](../../史书/005-晋书/晋书-CCDH.txt#L6037)明记太康二年。互见[280年](ce-0280.md#jin003-bamboo-280)、[281年](ce-0281.md#jin003-bamboo-281)。

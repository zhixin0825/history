## 本年概述

树机能陷凉州，马隆奉命出讨，年底平定凉州。晋于十一月多路伐吴；汲冢竹书出土暂依本纪归入本年，异年在同号注对读。


<a id="jin003-u259-1-event"></a>
<a id="jin003-l259-event"></a>
<a id="jin003-l267-event"></a>

1. **马隆收复凉州。** 正月，树机能攻陷凉州。乙丑，晋遣讨虏护军、武威太守马隆出讨。十二月，马隆击破树机能军，斩树机能，凉州平定。 [[1]](#jin003-u259-1-note)

<a id="jin003-u260-1-event"></a>
<a id="jin003-l260-event"></a>

2. **平原白麟汇报。** 二月甲午，平原报告白麟出现。 [[2]](#jin003-u260-1-note)

<a id="jin003-u261-1-event"></a>
<a id="jin003-l261-event"></a>

3. **拔弈虚率部归附。** 三月，匈奴都督拔弈虚率部归附。 [[3]](#jin003-u261-1-note)

<a id="jin003-u261-2-event"></a>

4. **因饥荒减御膳。** 三月乙亥，因百姓饥馑，司马炎减御膳一半。 [[4]](#jin003-u261-2-note)

<a id="jin003-u261-3-event"></a>
<a id="jin003-l262-event"></a>

5. **柳宿、女御见孛星。** 三月，柳宿出现孛星，四月又见于女御星区。 [[5]](#jin003-u261-3-note)

<a id="jin003-u262-2-event"></a>

6. **赦罪并解除质任。** 四月，大赦，并解除部曲督以下家属为质的限制。 [[6]](#jin003-u262-2-note)

<a id="jin003-u262-3-event"></a>

7. **八郡国雨雹。** 五月至六月间，八郡国降雹，伤秋作物，毁民房。 [[7]](#jin003-u262-3-note)

<a id="jin003-l263-event"></a>

<a id="jin003-l264-event"></a>

<a id="jin003-l265-event"></a>

10. **独雍率部归附。** 十月戊寅，匈奴余渠都督独雍等率部归附。 [[10]](#jin003-u265-1-note)

<a id="jin003-u265-2-event"></a>

11. **汲冢竹书出土。** 汲郡人不准盗掘一座战国魏王墓，获得竹简古书十余万言，收藏于秘府。 [[11]](#sgz-note-17)

<a id="sg-event-3"></a>

12. **大举多路伐吴。** 十一月，晋大举伐吴，琅邪王司马伷出涂中，安东将军王浑出江西，建威将军王戎出武昌，平南将军胡奋出夏口，镇南大将军杜预出江陵，龙骧将军王濬与广武将军唐彬率巴蜀兵顺江东下，东西合二十余万人。太尉贾充为大都督，行冠军将军杨济为副，总统各军。 [[12]](#sg-note-3)

<a id="jin003-u267-2-event"></a>

13. **肃慎献楛矢石砮。** 十二月，肃慎献楛矢、石砮。 [[13]](#jin003-u267-2-note)

<a id="sg-event-2"></a>
<a id="sg-event-1"></a>

14. **郭马在广州起兵，吴分路征讨。** 修允死后，部曲督郭马不愿旧兵被分拨，又逢吴廷核实广州户口，乃与何典、王族等起事，杀广州督虞授、南海太守刘略，逐刺史徐旗。已迁居广州的王氏兄弟王著、王延不肯受郭马任用，被杀。孙皓任张悌为丞相、何植为司徒，遣滕循从东、陶濬从西，命陶璜调兵协力。晋军南下后，陶濬留武昌。 [[14]](#sg-note-2)

<a id="sgz-event-4"></a>

15. **吴以两种菜为瑞，封黄耇吴平。** 黄耇家有鬼目菜，吴平家有另一种形类枇杷的菜。东观按图认作芝、平虑草，授黄耇侍芝郎、吴平平虑郎。 [[15]](#sgz-note-4)

### 11. 汲冢竹书出土

[返回正文第11条](#jin003-u265-2-event)

<a id="wei021-l129-3"></a>

**[《三國志·王衞二劉傅傳》裴注](../../拆分史书/三国志/卷021.md#edition-wei021-l129-3)** · [TXT L129](../../拆分史书/三国志/卷021.txt#L129)

> 其序古文曰：「自秦用篆書，焚燒先典，而古文絕矣。漢武帝時，魯恭王壞孔子宅，得尚書、春秋、論語、孝經，時人已不復知有古文，謂之科斗書，漢世祕藏，希得見之。魏初傳古文者，出於邯鄲淳。敬侯寫淳尚書，後以示淳，而淳不別。至正始中，立三字石經，轉失淳法。因科斗之名，遂效其法。太康元年，汲縣民盜發魏襄王冢，得策書十餘萬言。案敬侯所書，猶有髣髴。」敬侯謂覬也。

**釋讀與歸年** 衛恒追述秦用篆、魯恭王得孔宅古文諸經及邯鄲淳傳魏初古文，並以衛覬所習字體與太康元年汲縣出土古簡相驗。裴注引衛恒《四體書勢》繫太康元年（280），稱所發是魏襄王墓。[《晉書·武帝紀》](../../史书/005-晋书/晋书-CCDH.txt#L262-L268)記咸寧五年冬十月（279），同稱魏襄王墓。[《晉書·束皙傳》](../../史书/005-晋书/晋书-CCDH.txt#L6037)則繫太康二年（281），又載安釐王墓一說。此處隨《四體書勢》歸280年一處。正始三字石經等為古文書體之追敘，保留全段。

### 14. 郭马在广州起兵，吴分路征讨

[返回正文第14条](#sg-event-2)

<a id="sgz048-b-2373-1"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2373-1)** · [TXT L138](../../拆分史书/三国志/卷048.txt#L138)

> 三年夏，郭馬反。馬本合浦太守脩允部曲督。允轉桂林太守，疾病，住廣州，先遣馬將五百兵至郡安撫諸夷。允死，兵當分給，馬等累世舊軍，不樂離別。皓時又科實廣州戶口，馬與部曲將何典、王族、吳述、殷興等因此恐動兵民，合聚人衆，攻殺廣州督虞授。馬自號都督交廣二州諸軍事、安南將軍，興廣州刺史，述南海太守。典攻蒼梧，族攻始興。

**郭马及旧部因分拨和核户起事** 原合浦太守脩允病死，部曲将郭马等不愿被分拨；又逢核清广州户口，聚兵民杀广州督虞授。郭马自领都督，与殷兴、吴述等分据、攻苍梧始兴。

**归年依据** 本传天纪三年夏；脩允先时任官和病给本事线索，任期无独立确年。

<a id="period-sgz048-p-035-1"></a>

**[《三國志·三嗣主傳》 裴注 035·1](../../拆分史书/三国志/卷048.md#pei-035-1)** · [TXT L139](../../拆分史书/三国志/卷048.txt#L139)

> 漢晉春秋曰：先是，吳有說讖者曰：「吳之敗，兵起南裔，亡吳者公孫也。」皓聞之，文武職位至于卒伍有姓公孫者，皆徙於廣州，不令停江邊。

**釋讀** 预言说吴亡起于南方、同公孙有关，孙皓命把公孙姓官兵迁往广州，不留江边。

**附敘** 《漢晉春秋》以遷徙公孫氏避讖為郭馬起兵後孫皓之言的背景，遷徙確年未載。

<a id="sgz048-p-035-2"></a>

**[《三國志·三嗣主傳》 裴注 035·2](../../拆分史书/三国志/卷048.md#pei-035-2)** · [TXT L139](../../拆分史书/三国志/卷048.txt#L139)

> 及聞馬反，大懼曰：「此天亡也。」

**释读** 听说郭马起兵，孙皓自叹天要灭吴。
**归年** 本传天纪三年，注记一种反应。

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2373-2)** · [TXT L140](../../拆分史书/三国志/卷048.txt#L140)

> 八月，以軍師張悌爲丞相，牛渚都督何植爲司徒。執金吾滕循爲司空，未拜，轉鎮南將軍，假節領廣州牧，率萬人從東道討馬，與族遇於始興，未得前。

**张悌任丞相，何植为司徒，滕循领兵议讨郭马** 张悌升丞相，何植任司徒；滕循原任司空尚未受拜，调镇南将军、领广州牧，率万人讨逆，在始兴不能前进。

**归年依据** 本传天纪三年八月。

<a id="sgz048-b-2373-3"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2373-3)** · [TXT L140](../../拆分史书/三国志/卷048.txt#L140)

> 馬殺南海太守劉略，逐廣州刺史徐旗。皓又遣徐陵督陶濬將七千人從西道，命交州牧陶璜部伍所領及合浦、鬱林諸郡兵，當與東西軍共擊馬。

**郭马进一步夺南海，吴三路发军** 郭马杀刘略、逐徐旗。孙皓遣陶濬率军从西路，令交州牧陶璜等配合东西二军。

**归年依据** 本传天纪三年郭马之乱后续。

> 二弟著、延皆作佳器，郭馬起事，不爲馬用，見害。

**釋讀** 王蕃的兩個弟弟王著、王延俱有才器。郭馬起事時，兩人不肯受他任用，因而被殺。

**歸年** 卷048〈孫皓傳〉明記天紀三年夏郭馬在廣州起兵。王氏兄弟之死隨同一場起事合讀，確日未載。

### 15. 吴以两种菜为瑞，封黄耇吴平

[返回正文第15条](#sgz-event-4)

<a id="sgz048-b-2374-1"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2374-1)** · [TXT L142](../../拆分史书/三国志/卷048.txt#L142)

> 有鬼目菜生工人黃耇家，依緣棗樹，長丈餘，莖廣四寸，厚三分。又有買菜生工人吳平家，高四尺，厚三分，如枇杷形，上廣尺八寸，下莖廣五寸，兩邊生葉綠色。東觀案圖，名鬼目作芝草，買菜作平慮草，遂以耇爲侍芝郎，平爲平慮郎，皆銀印青綬。

**吴以两种菜为瑞，封黄耇吴平** 黄耇家有鬼目菜，吴平家有另一种形类枇杷的菜。东观按图认作芝、平虑草，授黄耇侍芝郎、吴平平虑郎。

**归年依据** 本传天纪三年，植物称瑞是政权记录。

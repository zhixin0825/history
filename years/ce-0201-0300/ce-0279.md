# 公元279年｜晋咸宁五年／吴天纪三年

[← 公元278年](ce-0278.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元280年 →](ce-0280.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **郭马在广州起兵。** 部曲督郭马不愿旧兵被分拨，又值清查广州户口，结众杀广州督虞授，兵分苍梧、始兴等地。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **张悌任丞相，滕循、陶濬等讨郭马。** 吴廷任张悌为丞相、何植为司徒。滕循领州兵从东，陶濬从西出兵，陶璜再调交州诸军协同。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **晋多路进兵伐吴。** 晋军自涂中、牛渚、武昌、夏口、江陵及长江上游等路攻吴，贾充驻节居中，吴将陶濬因此留在武昌。 [[3]](#sg-note-3)

<a id="sgz-event-4"></a>

4. **吴以两种菜为瑞，封黄耇吴平。** 黄耇家有鬼目菜，吴平家有另一种形类枇杷的菜。东观按图认作芝、平虑草，授黄耇侍芝郎、吴平平虑郎。 [[4]](#sgz-note-4)

### 2. 张悌任丞相，滕循、陶濬等讨郭马

[返回正文第2条](#sg-event-2)

<a id="sg048-l2373-e2"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p009)** · [仓内TXT L2373](../../sources/本地分卷/三国志/三国志-卷048.md#l2373)

> 八月，以軍師張悌爲丞相，牛渚都督何植爲司徒。

<a id="sgz048-b-2373-1"></a>

**[《三国志·三嗣主传》仓内原文 L2373](../../sources/本地分卷/三国志/三国志-卷048.md#l2373)**

> ﻿三年夏，郭馬反。馬本合浦太守脩允部曲督。允轉桂林太守，疾病，住廣州，先遣馬將五百兵至郡安撫諸夷。允死，兵當分給，馬等累世舊軍，不樂離別。皓時又科實廣州戶口，馬與部曲將何典、王族、吳述、殷興等因此恐動兵民，合聚人衆，攻殺廣州督虞授。馬自號都督交廣二州諸軍事、安南將軍，興廣州刺史，述南海太守。典攻蒼梧，族攻始興。

**释读** 原合浦太守脩允病死，部曲将郭马等不愿被分拨；又逢核清广州户口，聚兵民杀广州督虞授。郭马自领都督，与殷兴、吴述等分据、攻苍梧始兴。

**归年** 本传天纪三年夏；脩允先时任官和病给本事线索，任期无独立确年。

<a id="sgz048-b-2373-2"></a>

**[《三国志·三嗣主传》仓内原文 L2373](../../sources/本地分卷/三国志/三国志-卷048.md#l2373)**

> 八月，以軍師張悌爲丞相，牛渚都督何植爲司徒。執金吾滕循爲司空，未拜，轉鎮南將軍，假節領廣州牧，率萬人從東道討馬，與族遇於始興，未得前。

**释读** 张悌升丞相，何植任司徒；滕循原任司空尚未受拜，调镇南将军、领广州牧，率万人讨逆，在始兴不能前进。

**归年** 本传天纪三年八月。

<a id="sgz048-b-2373-3"></a>

**[《三国志·三嗣主传》仓内原文 L2373](../../sources/本地分卷/三国志/三国志-卷048.md#l2373)**

> 馬殺南海太守劉略，逐廣州刺史徐旗。皓又遣徐陵督陶濬將七千人從西道，命交州牧陶璜部伍所領及合浦、鬱林諸郡兵，當與東西軍共擊馬。

**释读** 郭马杀刘略、逐徐旗。孙皓遣陶濬率军从西路，令交州牧陶璜等配合东西二军。

**归年** 本传天纪三年郭马之乱后续。

<a id="sgz048-p-035-2"></a>

**[《三国志·三嗣主传》裴注 035·2](../../sources/摘录/三国志-卷048-三嗣主传裴注.md#pei-035-2)**

> 及聞馬反大懼曰此天亡也

**释读** 听说郭马起兵，孙皓自叹天要灭吴。

**归年** 本传天纪三年，注记一种反应。

### 3. 晋多路进兵伐吴

[返回正文第3条](#sg-event-3)

<a id="sg048-l2375-e3"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p010)** · [仓内TXT L2375](../../sources/本地分卷/三国志/三国志-卷048.md#l2375)

> 冬，晉命鎮東大將軍司馬伷向塗中，安東將軍王渾、揚州刺史周浚向牛渚，建威將軍王戎向武昌，平南將軍胡奮向夏口，鎮南將軍杜預向江陵，龍驤將軍王濬、廣武將軍唐彬浮江東下，太尉賈充爲大都督，量宜處要，盡軍勢之中。

<a id="sgz048-b-2375-1"></a>

**[《三国志·三嗣主传》仓内原文 L2375](../../sources/本地分卷/三国志/三国志-卷048.md#l2375)**

> ﻿冬，晉命鎮東大將軍司馬伷向塗中，安東將軍王渾、揚州刺史周浚向牛渚，建威將軍王戎向武昌，平南將軍胡奮向夏口，鎮南將軍杜預向江陵，龍驤將軍王濬、廣武將軍唐彬浮江東下，太尉賈充爲大都督，量宜處要，盡軍勢之中。

**释读** 晋命司马伷、王浑、周浚、王戎、胡奋、杜预、王濬、唐彬等分兵诸道，贾充为大都督。

**归年** 本传天纪三年冬；《晋书·武帝纪》咸宁五年十一月发大军。

<a id="sgz048-b-2375-2"></a>

**[《三国志·三嗣主传》仓内原文 L2375](../../sources/本地分卷/三国志/三国志-卷048.md#l2375)**

> 陶濬至武昌，聞北軍大出，停駐不前。

**释读** 陶濬到武昌时听闻晋军进兵，停止向广州。

**归年** 本传天纪三年冬，同年平郭马的动员经过此处转折。

### 4. 吴以两种菜为瑞，封黄耇吴平

[返回正文第4条](#sgz-event-4)

<a id="sgz048-b-2374-1"></a>

**[《三国志·三嗣主传》仓内原文 L2374](../../sources/本地分卷/三国志/三国志-卷048.md#l2374)**

> ﻿有鬼目菜生工人黃耇家，依緣棗樹，長丈餘，莖廣四寸，厚三分。又有買菜生工人吳平家，高四尺，厚三分，如枇杷形，上廣尺八寸，下莖廣五寸，兩邊生葉綠色。東觀案圖，名鬼目作芝草，買菜作平慮草，遂以耇爲侍芝郎，平爲平慮郎，皆銀印青綬。

**归年** 本传天纪三年，植物称瑞是政权记录。

# 公元280年｜晋太康元年／吴天纪四年

[← 公元279年](ce-0279.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元282年 →](ce-0282.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **晋军连克吴城，张悌等战死。** 王濬、唐彬沿江取城，杜预灭江陵守军，王浑一路斩吴丞相张悌等。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓应左右之请杀岑昏。** 三月丙寅，数百近臣求杀岑昏，孙皓应允。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **孙皓分遣使者向晋军奉书。** 陶濬召集的兵士逃散。依薛莹、胡冲等建议，孙皓分别向王濬、司马伷、王浑送降书。 [[3]](#sg-note-3)

<a id="sg-event-4"></a>

4. **王濬受孙皓之降。** 王濬先至建业、收降孙皓，吴亡。孙皓在投降过程中另遣使向司马伷交印绶。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **孙皓迁洛阳并封归命侯。** 孙皓入洛，晋廷先诏封归命侯，赐田粮车服，其子分别给以官职。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **王濬顺江伐吴，陆晏陆景遇害。** 晋军沿江取诸城，陆晏被王浚别部杀死，陆景次日也遇害。 [[6]](#sg-note-6)

<a id="sgz-event-7"></a>

7. **《江表传》据孙皓归降所送六玺反证。** 《江表传》说太康初孙皓送来六枚金玺，没有玉料，故以此反驳孙坚曾取得传国玺。 [[7]](#sgz-note-7)

### 4. 王濬受孙皓之降

[返回正文第4条](#sg-event-4)

<a id="sg048-l2380-e4"></a>

**[《三国志·三嗣主传》](../../sources/摘录/三国志-卷048-三嗣主传.md#p010)** · [仓内TXT L2380](../../sources/本地分卷/三国志/三国志-卷048.md#L2380)

> 壬申，王濬最先到，於是受皓之降，解縛焚櫬，延請相見。

<a id="sgz065-p-004-2"></a>

**[《三国志·王楼贺韦华传》裴注 004·2](../../sources/摘录/三国志-卷065-王楼贺韦华传裴注.md#pei-004-2)**

> 吳平還鄉里

**释读** 吴亡后贺循得归。

**归年** 《晋书·贺循传》同作吴平乃还本郡，太康元年，归乡具体月日不载。

<a id="sgz051-p-015-2"></a>

**[《三国志·宗室传》裴注 015·2](../../sources/摘录/三国志-卷051-宗室传裴注.md#pei-015-2)**

> 干寳晉紀曰秀在晉朝初聞晧降羣臣畢賀秀稱疾不與南向流涕曰昔討逆弱冠以一校創業今後主舉江南而棄之宗廟山陵於此為墟悠悠蒼天此何人哉朝廷美之

**释读** 晋群臣闻孙皓降纷纷祝贺，孙秀称病不与，南向流泪，叹孙策初创、孙皓却举江南而弃，晋人称美。

**归年** 《晋书·武帝纪》太康元年，《通鉴》卷八十一并记入晋旧臣与吴亡。

<a id="sgz051-p-015-3"></a>

**[《三国志·宗室传》裴注 015·3](../../sources/摘录/三国志-卷051-宗室传裴注.md#pei-015-3)**

> 晉諸公贊曰呉平降為伏波將軍開府如故

**释读** 《晋诸公赞》说晋灭吴后，将孙秀由原来将军降为伏波将军，仍许开府。

**归年** 《通鉴》卷八十一随太康元年吴亡后记降官。

<a id="sgz051-p-019-1"></a>

**[《三国志·宗室传》裴注 019·1](../../sources/摘录/三国志-卷051-宗室传裴注.md#pei-019-1)**

> 晉諸公贊曰呉平降為渡遼將軍

**释读** 《晋诸公赞》说平吴后孙楷降为渡辽将军。

**归年** 《通鉴》卷八十一载在太康元年吴亡后处置。

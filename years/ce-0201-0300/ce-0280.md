## 本年概述

晋军从多路攻吴，张悌等战死，王濬顺江抵建业，孙皓出降。晋授孙皓归命侯，把他迁往洛阳，并陆续安置吴臣、调整地方名称。

2. **晋军顺江进兵，吴主孙皓投降。** 晋军分路攻吴。王濬自上游顺江而下，此前[陆抗曾警告西线难以等到外援](ce-0274.md#sg-note-4)。二月庚申，王濬攻克西陵，俘获留宪、成据和宜都太守虞忠。虞忠在这场守御中遇害，确日未详。壬戌，夷道监陆晏被王濬别军杀死，癸亥陆景也遇害。虞昺受命持节统督武昌以上诸军，先交还节、盖、印绶，再向晋军归降。吴水军督钟离徇战死。张悌督军北渡，在版桥败死。孙皓命陶濬领军迎战，部众在出发前散去。孙皓采纳薛莹、胡冲等人的建议，分别派使者向王濬、司马伷、王浑奉降书。王濬率军抵建业，孙皓出降。 **《武帝纪》补记：** 正月己丑朔，记五色气环日。癸丑，王浑攻取吴寻阳、赖乡等城，获武威将军周兴。本纪以太康元年追称本年，大赦改元按《通鉴》在四月乙酉；本纪把改元接在三月吴降之后、未另标四月，不能写成正月已经改元。 **《武帝纪》补记：** 二月戊午，王濬、唐彬攻取丹杨城。庚申，克西陵，本纪称杀留宪、成璩、郑广；壬戌又克夷道、乐乡，杀陆晏、陆景。甲戌，杜预克江陵、斩伍延，胡奋克江安，乐乡、荆门诸戍相继归降。乙亥，王濬加督益梁军事。诏令王濬、唐彬东下扫巴丘，会胡奋、王戎平夏口、武昌，再顺流至秣陵，与胡奋、王戎共同斟酌进退；杜预安定零陵、桂阳、衡阳，认为主力经过后南荆州可传檄而定，令预拨一万人给濬、七千人给彬，胡奋平夏口后再拨七千人给濬，王戎平武昌后再拨六千人给彬，贾充移屯项总督。王濬继续攻下夏口、武昌顺流东下；王浑、周浚在版桥击败张悌，杀张悌、孙震、沈莹，传首洛阳。孙皓困迫，请降，送玺绶给司马伷。各军战果、将领姓名及死亡日期与吴传分歧见同号注，不把奏报命令当成每批援兵都已按数到达的证明。 **《武帝纪》补记：** 三月壬寅，王濬水军至建业石头，孙皓以缚身载棺的方式到军门投降。王濬持节解缚焚棺，送往京师。收取吴地图、户籍，本纪记得州四、郡四十三、县三百一十三，户五十二万三千，吏三万二千，兵二十三万，男女二百三十万口；这些是所收登记数字，不把户、吏、兵与男女口相加为另一人口总数。牧守以下暂仍用吴原任官，废苛政、示以简易，本纪称吴人悦服。本纪续记乙酉大赦、改太康，准民众会饮五日，优恤孤老困穷。本纪固定底本作三月壬寅，《通鉴考异》所引本纪作壬申，并指出各书月份、干支不能全合；《通鉴》正文把大赦改元定在四月乙酉。这里分别交代吴降与改元，不把本纪缺四月字的接叙强作三月改元。 [[2]](#sg-note-1)

4. **晋安置孙皓，封赏平吴将领，吴臣入晋。** 晋封孙皓为归命侯。五月，孙皓及家属抵达洛阳，滕皇后也随他西迁。吴平后，原居候官的孙亮夫人全惠解得以返归，被流放海滨的贺循也回到故乡。曾任吴黄门侍郎的孙拯在吴平后赴洛阳。薛莹到洛阳后获任散骑常侍。晋武帝问吴国为何灭亡，薛莹答称孙皓亲近小人、滥施刑罚，大臣人人自危，遂有亡国之祸。 晋平吴后建威将军王戎到石伟处探视。 吴亡后周处仕晋。杜预因平吴进封当阳侯，王浑也因功进爵为公。先前赴吴的毌丘宗兄弟归还中原，诸葛靓也在吴平后归晋。 **《武帝纪》补记：** 本纪系五月辛亥，记封孙皓归命侯，其太子任中郎、诸子任郎中；按才任用吴地旧望。孙氏战死大将之家迁寿阳；渡江的将吏免赋役十年，百姓、百工二十年。此“复”是赋役优免，不是返回原地。 《吴主传》及《通鉴》却系封侯在四月甲申，保留这处异月，不拼作同一天。 **《武帝纪》补记：** 丙寅，司马炎临朝大集群臣，引孙皓上殿，群臣称万岁。丁卯，荐酃渌酒于太庙；本纪记六郡国降雹、伤秋作物，校家指出“六”下或脱“雨”字，又与《五行志》五郡国的计数不同。庚午，诏六十岁以上士卒归家；庚辰，以王濬为辅国大将军、襄阳侯，封杜预当阳侯、王戎安丰侯、唐彬上庸侯，贾充、司马伷以下增封，依功行封，分等赐公卿以下帛。本月记日有次序疑点，封赏事实与精确日序分别处理。 [[4]](#sg-note-5)

## 晋廷其他纪事

<a id="sgz-event-10"></a>

8. **赈慰扬越与灾异。** 四月，河东、高平雹灾，原文称伤秋稼；派兼侍中张侧、黄门侍郎朱震分赴扬越，慰抚新附地区。顿丘报白麟。三河、魏郡、弘农降雹，伤越冬小麦。 [[8]](#jin003-l271-note)

9. **翊军校尉、司马睦复封与外附。** 六月丁丑，初设翊军校尉，封丹水侯司马睦高阳王。甲申，东夷十国来附。 [[9]](#jin003-l274-note)

<a id="jin003-l275-event"></a>

10. **西平浩亹边事与魏舒升任。** 七月，轲成泥部侵西平、浩亹，杀督将以下三百余人。东夷二十国朝献。庚寅，以尚书魏舒为尚书右仆射。 [[10]](#jin003-l275-note)

11. **车师遣子、司马延祚封王及白龙。** 八月，车师前部遣子入朝侍奉。己未，封皇弟司马延祚乐平王。永昌报告白龙三次。 [[11]](#jin003-l276-note)

<a id="jin003-l277-event"></a>

12. **辞封禅。** 九月，群臣以天下统一，屡请举行封禅，司马炎辞让不准。不能因请求而写作已登泰山行礼。 [[12]](#jin003-l277-note)

13. **取消五女户复免。** 冬十月丁巳，取消五女户赋役优免；与275年设置该优免互见。 [[13]](#jin003-l278-note)

<a id="jin003-l279-event"></a>

### 2. 晋军顺江进兵，吴主孙皓投降

[返回正文第2条](#sg-event-1)

<a id="sgz048-b-2377-2"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sgz048-b-2377-2)** · [TXT L149](../../拆分史书/三国志/卷048.txt#L149)

> 濬、彬所至，則土崩瓦解，靡有禦者。預又斬江陵督伍延，渾復斬丞相張悌、丹楊太守沈瑩等，所在戰克。

**吴军沿江溃退，伍延张悌沈莹等死** 王濬、唐彬两军所向，吴军崩溃。杜预斩江陵督伍延，王浑一路斩张悌、沈莹等。

**归年依据** 本传天纪四年，晋太康元年，《晋书·武帝纪》及诸将传可核。

<a id="sgz048-p-037-1"></a>

**[《三國志·三嗣主傳》 裴注 037·1](../../拆分史书/三国志/卷048.md#pei-037-1)** · [TXT L150](../../拆分史书/三国志/卷048.txt#L150)

> 干寶晉紀曰：吳丞相軍師張悌、護軍孫震、丹楊太守沈瑩帥衆三萬濟江，圍成陽都尉張喬於楊荷橋，衆才七千，閉柵自守，舉白接告降。吳副軍師諸葛靚欲屠之，悌曰：「彊敵在前，不宜先事其小；且殺降不祥。」靚曰：「此等以救兵未至而力少，故且偽降以緩我，非來伏也。因其無戰心而盡阬之，可以成三軍之氣。若舍之而前，必爲後患。」悌不從，撫之而進。與討吳護軍張翰、揚州刺史周浚成陣相對。沈瑩領丹楊銳卒刀楯五千，號曰青巾兵，前後屢陷堅陣，於是以馳淮南軍，三衝不動。退引亂，薛勝、蔣班因其亂而乘之，吳軍以次土崩，將帥不能止，張喬又出其後，大敗吳軍于阪橋，獲悌、震、瑩等。

**释读** 张悌拒诸葛靓预先杀降的建议。沈莹率精锐三冲未果，吴军后退生乱，晋军乘势，张乔从背后攻击，大败吴军于版桥。
**归年** 晋太康元年二三月灭吴，《晋书·武帝纪》与吴本传同；战地细节来自干宝。

<a id="period-sgz048-p-037-2"></a>

**[《三國志·三嗣主傳》 裴注 037·2](../../拆分史书/三国志/卷048.md#pei-037-2)** · [TXT L150](../../拆分史书/三国志/卷048.txt#L150)

> 襄陽記曰：悌字巨先，襄陽人，少有名理，孫休時爲屯騎校尉。

**釋讀** 张悌字巨先，襄阳人，少有名，在孙休时任屯骑校尉。

**附敘** 《襄陽記》於張悌戰死處補敘籍貫、名聲及孫休時任校尉的履歷，官職確年未載。

<a id="sgz048-p-037-4"></a>

**[《三國志·三嗣主傳》 裴注 037·4](../../拆分史书/三国志/卷048.md#pei-037-4)** · [TXT L150](../../拆分史书/三国志/卷048.txt#L150)

> 晉來伐吳，皓使悌督沈瑩、諸葛靚，率衆三萬渡江逆之。至牛渚，沈瑩曰：「晉治水軍於蜀乆矣，今傾國大舉，萬里齊力，必悉益州之衆浮江而下。我上流諸軍，無有戒備，名將皆死，幼少當任，恐邊江諸城，盡莫能禦也。晉之水軍，必至于此矣！宜畜衆力，待來一戰。若勝之日，江西自清，上方雖壞，可還取之。今渡江逆戰，勝不可保，若或摧喪，則大事去矣。」悌曰：「吳之將亡，賢愚所知，非今日也。吾恐蜀兵來至此，衆心必駭懼，不可復整。今宜渡江，可用決戰力爭。若其敗喪，則同死社稷，無所復恨。若其克勝，則北敵奔走，兵勢萬倍，便當乘威南上，逆之中道，不憂不破也。若如子計，恐行散盡，相與坐待敵到，君臣俱降，無復一人死難者，不亦辱乎！」

**释读** 沈莹主张集中力量等晋的益州水军。张悌说众闻蜀船将至会先乱，渡江战败则共殉，胜能反击晋舟师，故选择渡江决战。
**归年** 太康元年张悌与晋军交战阶段，细节见此传和干宝。

<a id="sgz048-p-037-5"></a>

**[《三國志·三嗣主傳》 裴注 037·5](../../拆分史书/三国志/卷048.md#pei-037-5)** · [TXT L150](../../拆分史书/三国志/卷048.txt#L150)

> 遂渡江戰，吳軍大敗。諸葛靚與五六百人退走，使過迎悌，悌不肯去，靚自往牽之，謂曰：「且夫天下存亡有大數，豈卿一人所知，如何故自取死爲？」悌垂涕曰：「仲思，今日是我死日也。且我作兒童時，便爲卿家丞相所拔，常恐不得其死，負名賢知顧。今以身徇社稷，復何遁邪？莫牽曳之如是。」靚流涕放之，去百餘步，已見爲晉軍所殺。

**释读** 吴军大败，诸葛靓折回劝退，张悌忆诸葛家知遇，执意留下，晋军杀之。
**归年** 卷048正文及《晋书·武帝纪》太康元年张悌战死。

<a id="period-sgz048-p-037-6"></a>

**[《三國志·三嗣主傳》 裴注 037·6](../../拆分史书/三国志/卷048.md#pei-037-6)** · [TXT L150](../../拆分史书/三国志/卷048.txt#L150)

> 吳錄曰：悌少知名，及處大任，希合時趣，將護左右，清論譏之。

**釋讀** 张悌早有名，但在高位时常随时势、照顾左右，引来舆论讥评。

**附敘** 《吳錄》另評張悌居高位後的行事，附於其戰死條。

<a id="sgz048-p-037-7"></a>

**[《三國志·三嗣主傳》 裴注 037·7](../../拆分史书/三国志/卷048.md#pei-037-7)** · [TXT L150](../../拆分史书/三国志/卷048.txt#L150)

> 搜神記曰：臨海松陽人柳榮從悌至楊府，榮病死船中二日，時軍已上岸，無有埋之者，忽然大呼，言「人縛軍師！人縛軍師！」聲激揚，遂活。人問之，榮曰：「上天北斗門下卒見人縛張悌，意中大愕，不覺大呼，言『何以縛張軍師。』門下人怒榮，叱逐使去。榮便去，怖懼，口餘聲發揚耳。」其日，悌戰死。榮至晉元帝時猶在。

**释读** 柳荣随张悌出征，病死两天，传称苏醒后说在天上见张悌被绑，该日张悌果然战死。柳荣到东晋元帝时还活着。
**归年** 附280同次战死的神异叙述；元帝在位317–323，是见证下限。

### 7. 汲冢古文竹简出土

[返回正文第7条](#sgz-event-17)

<a id="wei021-l129-3"></a>

**[《三國志·王衞二劉傅傳》裴注](../../拆分史书/三国志/卷021.md#edition-wei021-l129-3)** · [TXT L129](../../拆分史书/三国志/卷021.txt#L129)

> 其序古文曰：「自秦用篆書，焚燒先典，而古文絕矣。漢武帝時，魯恭王壞孔子宅，得尚書、春秋、論語、孝經，時人已不復知有古文，謂之科斗書，漢世祕藏，希得見之。魏初傳古文者，出於邯鄲淳。敬侯寫淳尚書，後以示淳，而淳不別。至正始中，立三字石經，轉失淳法。因科斗之名，遂效其法。太康元年，汲縣民盜發魏襄王冢，得策書十餘萬言。案敬侯所書，猶有髣髴。」敬侯謂覬也。

**釋讀與歸年** 衛恒追述秦用篆、魯恭王得孔宅古文諸經及邯鄲淳傳魏初古文，並以衛覬所習字體與太康元年汲縣出土古簡相驗。裴注引衛恒《四體書勢》繫太康元年（280），稱所發是魏襄王墓。[《晉書·武帝紀》](../../史书/005-晋书/晋书-CCDH.txt#L262-L268)記咸寧五年冬十月（279），同稱魏襄王墓。[《晉書·束皙傳》](../../史书/005-晋书/晋书-CCDH.txt#L6037)則繫太康二年（281），又載安釐王墓一說。此處隨《四體書勢》歸280年一處。正始三字石經等為古文書體之追敘，保留全段。

<a id="sgz021-p-044-3"></a>

[本卷同事原句](#wei021-l129-3)。

**归年** 注文太康元年，晋书不同叙层有279、281诸说，保留本文。

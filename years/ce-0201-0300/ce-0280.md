# 公元280年｜晋太康元年／吴天纪四年

[← 公元279年](ce-0279.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元282年 →](ce-0282.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **版桥交战，张悌等战死。** 吴丞相张悌与沈莹、孙震等渡江迎战王浑一路晋军，在版桥一带兵败战死。晋军上游推进另见本年第6条。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓应左右之请杀岑昏。** 三月丙寅，数百近臣求杀岑昏，孙皓应允。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **孙皓分遣使者向晋军奉书。** 陶濬召集的兵士逃散。依薛莹、胡冲等建议，孙皓分别向王濬、司马伷、王浑送降书。 [[3]](#sg-note-3)

<a id="sgz-event-7"></a>

<a id="sg-event-4"></a>

4. **王濬入建业，受孙皓之降。** 三月，王濬先至建业，孙皓到军门请降。《晋书·武帝纪》《通鉴》作壬寅，《孙皓传》作壬申。《通鉴考异》据《长历》认为本月无壬申。另遣使奉降书、交印绶见本年第3条。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **晋封孙皓为归命侯，孙皓迁到洛阳。** 孙皓及其家属在五月到洛阳。吴主本传记封归命侯诏在四月甲申，《晋书·武帝纪》作五月辛亥。《通鉴》采用四月甲申。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **王濬自上游进军，陆晏、陆景遇害。** 王濬、唐彬沿江攻下吴地。陆晏在夷道遇害，陆景也在晋军进兵中被杀。《陆抗传》系陆晏于壬戌、陆景于癸亥。《通鉴》记壬戌克夷道、乙丑克乐乡，《晋书·武帝纪》在壬戌一并叙及二人。 [[6]](#sg-note-6)

<a id="sgz-event-8"></a>

8. **孙皓又封十一王并大赦。** 在亡吴之年的春天封中山、代等十一王，施大赦。 [[8]](#sgz-note-8)

<a id="sgz-event-9"></a>

9. **平吴后王戎访石伟。** 晋平吴后建威将军王戎到石伟处探视。 [[9]](#sgz-note-9)

<a id="sgz-event-10"></a>

10. **胡威太康元年卒，死所异文。** 《胡质传》正文写「卒於安定」。《晋书·胡威传》作太康元年卒于青州任上，裴注《晋阳秋》同年。 [[10]](#sgz-note-10)

<a id="sgz-event-11"></a>

11. **晋改临水为临安。** 临水入晋后改为临安。 [[11]](#sgz-note-11)

<a id="sgz-event-12"></a>

12. **周处入晋。** 吴亡后周处仕晋。 [[12]](#sgz-note-12)

<a id="sgz-event-13"></a>

13. **晋改新定为遂安。** 新定县入晋后改名遂安。 [[13]](#sgz-note-13)

<a id="sgz-event-14"></a>

14. **晋改休阳为海宁。** 休阳县入晋后改名海宁。 [[14]](#sgz-note-14)

<a id="sgz-event-15"></a>

15. **晋改罗阳县为安固。** 吴罗阳县经孙皓改安阳后，入晋改安固。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **平吴后杜预获封当阳侯。** 封当阳侯，食邑八千。 [[16]](#sgz-note-16)

<a id="sgz-event-17"></a>

17. **汲冢古文竹简出土。** 《四体书势》记汲县民盗发魏襄王冢得简书，类卫觊所写；出土年另有咸宁五年的纪年。 [[17]](#sgz-note-17)

<a id="sgz-event-18"></a>

18. **毌丘宗兄弟在吴亡后还中国。** 兄弟在吴亡之后还，后毌丘宗官至零陵太守，其子毌丘奥任巴东、益州军政。 [[18]](#sgz-note-18)

<a id="sgz-event-19"></a>

19. **诸葛靓因吴亡归晋。** 吴平还晋，后子恢官至尚书令、赠左光禄大夫开府。 [[19]](#sgz-note-19)

> 濬、彬所至，則土崩瓦解，靡有禦者。預又斬江陵督伍延，渾復斬丞相張悌、丹楊太守沈瑩等，所在戰克。

**释读** 王濬、唐彬两军所向，吴军崩溃。杜预斩江陵督伍延，王浑一路斩张悌、沈莹等。

**归年** 本传天纪四年，晋太康元年，《晋书·武帝纪》及诸将传可核。

<a id="sgz048-p-037-1"></a>

**[《三国志·三嗣主传》裴注 037·1](../../sources/本地分卷/三国志/三国志-卷048.md#pei-037-1)**

> 干寳晉紀曰呉丞相軍師張悌護軍孫震丹陽太守沈瑩帥衆三萬濟江圍成陽都尉張喬於楊荷喬衆才七千閉柵自守舉白接告降呉副軍師諸葛靚欲屠之悌曰彊敵在前不宜先事其小且殺降不祥靚曰此等以救兵未至而力少故且偽降以緩我非來伏也因其無戰心而盡阬之可以成三軍之氣若舎之而前必為後患悌不從撫之而進與討呉䕶軍張翰揚州刺史周浚成陣相對沈瑩領丹陽鋭卒刀楯五千號曰青巾兵前後屢陷堅陣於是以馳淮南軍三衝不動退引亂薛勝蔣班因其亂而乗之呉軍以次土崩將帥不能止張喬又出其後大敗呉軍於版橋獲悌震瑩等

**释读** 张悌拒诸葛靓预先杀降的建议。沈莹率精锐三冲未果，吴军后退生乱，晋军乘势，张乔从背后攻击，大败吴军于版桥。

**归年** 晋太康元年二三月灭吴，《晋书·武帝纪》与吴本传同；战地细节来自干宝。

<a id="sgz048-p-037-4"></a>

**[《三国志·三嗣主传》裴注 037·4](../../sources/本地分卷/三国志/三国志-卷048.md#pei-037-4)**

> 晉來伐呉晧使悌督沈瑩諸葛靚帥衆三萬渡江逆之至牛渚沈瑩曰晉治水軍於蜀乆矣今傾國大舉萬里齊力必悉益州之衆浮江而下我上流諸軍無有戒備名將皆死㓜少當任恐邊江諸城盡莫能禦也晉之水軍必至於此矣宜蓄衆力待來一戰若勝之日江西自清上方雖壊可還取之今渡江逆戰勝不可保若或摧喪則大事去矣悌曰呉之將亡賢愚所知非今日也吾恐蜀兵來至此衆心必駭懼不可復整今宜渡江可用决戰力争若其敗䘮則同死社稷無所復恨若其克勝則北敵奔走兵勢萬倍便當乘威南上逆之中道不憂不破也若如子計恐行〔四库字图340〕盡相與坐待敵到君臣俱降無復一人死難者不亦辱乎

**释读** 沈莹主张集中力量等晋的益州水军。张悌说众闻蜀船将至会先乱，渡江战败则共殉，胜能反击晋舟师，故选择渡江决战。

**归年** 太康元年张悌与晋军交战阶段，细节见此传和干宝。

<a id="sgz048-p-037-5"></a>

**[《三国志·三嗣主传》裴注 037·5](../../sources/本地分卷/三国志/三国志-卷048.md#pei-037-5)**

> 遂渡江戰呉軍大敗諸葛靚與五六百人退走使過迎悌悌不肯去靚自往牽之謂曰且夫天下存亡有大數豈卿一人所知如何故自取死為悌垂涕曰仲思今日是我死日也且我作兒童時便為卿家丞相所㧞常恐不得其死負名賢知顧今以身徇社稷復何遁耶莫牽曵之如是靚流涕放之去百餘歩已見為晉軍所殺

**释读** 吴军大败，诸葛靓折回劝退，张悌忆诸葛家知遇，执意留下，晋军杀之。

**归年** 卷048正文及《晋书·武帝纪》太康元年张悌战死。

<a id="sgz048-p-037-7"></a>

**[《三国志·三嗣主传》裴注 037·7](../../sources/本地分卷/三国志/三国志-卷048.md#pei-037-7)**

> 搜神記曰臨海松陽人栁榮從悌至楊州榮病死〔四库字图551〕中二日時軍已上岸無冇埋之者忽然大呼言人縛軍師人縛軍師聲激揚遂活人問之榮曰上天北斗門下卒見人縛張悌意中大愕不覺大呼言何以縛張軍師門下人怒榮叱逐使去榮便去怖懼日餘聲發揚耳其日悌戰死榮至晉元帝時猶在

**释读** 柳荣随张悌出征，病死两天，传称苏醒后说在天上见张悌被绑，该日张悌果然战死。柳荣到东晋元帝时还活着。

**归年** 附280同次战死的神异叙述；元帝在位317–323，是见证下限。

<a id="sgz048-b-2379-1"></a>

> ﻿戊辰，陶濬從武昌還，即引見，問水軍消息，對曰：「蜀船皆小，今得二萬兵，乘大船戰，自足擊之。」於是合衆，授濬節鉞。明日當發，其夜衆悉逃走。

**释读** 陶濬称晋水军船小，希望率二万人用大船出战。孙皓给他兵、节钺，部众却在出发前一晚散逃。

**归年** 本传太康元年三月戊辰。

<a id="sgz048-b-2379-2"></a>

**[《三国志·三嗣主传》仓内原文 L2379](../../sources/本地分卷/三国志/三国志-卷048.md#l2379)**

> 而王濬順流將至，司馬伷、王渾皆臨近境。皓用光祿勳薛瑩、中書令胡沖等計，分遣使奉書於濬、伷、渾曰：「昔漢室失統，九州分裂，先人因時，略有江南，遂分阻山川，與魏乖隔。今大晉龍興，德覆四海。闇劣偷安，未喻天命。至於今者，猥煩六軍，衡蓋路次，遠臨江渚，舉國震惶，假息漏刻。敢緣天朝含弘光大，謹遣私署太常張夔等奉所佩印綬，委質請命，惟垂信納，以濟元元。」

**释读** 吴采薛莹、胡冲之计，以张夔等奉印绶、书信，向王濬、司马伷、王浑请降保民。

**归年** 本传天纪四年三月，纳降次第见下一条。

<a id="sgz048-p-039-1"></a>

**[《三国志·三嗣主传》裴注 039·1](../../sources/本地分卷/三国志/三国志-卷048.md#pei-039-1)**

> 江表傳載晧將敗與舅何植書曰昔大皇帝以神武之略奮三千之卒割據江南席卷交廣開拓洪基欲祚之萬世至孤末徳嗣守成緒不能懐集黎元多為咎闕以違天度闇昧之變反謂之祥致使南蠻逆亂征討未克聞晉大衆逺來臨江庶竭勞瘁衆皆摧退而張悌不反喪軍過半孤甚愧悵於今無聊得陶濬表云武昌以西並復不守不守者非糧不足非城不固兵將背戰耳兵之背戰豈怨兵耶孤之罪也天文縣變於上士民憤歎於下觀此事勢危如累卵吳祚終訖何其局哉天匪亡呉孤所招也瞑目黄壤當復何顔見四帝乎公其朂勉竒謨飛筆以聞

**释读** 孙皓由孙权开业说到自己失众、南方乱、张悌败战。见陶濬报武昌以西无守，反省在己不在军，求何植速献办法。

**归年** 《江表传》明言将败，280张悌死后。

<a id="sgz048-p-039-2"></a>

**[《三国志·三嗣主传》裴注 039·2](../../sources/本地分卷/三国志/三国志-卷048.md#pei-039-2)**

> 晧又遺羣臣書曰孤以不徳沗繼先軌處位歴年政教凶悖遂令百姓久困塗炭至使一朝歸命有道社稷傾覆宗廟無主慙愧山積没有餘罪自惟空薄過偷尊號才瑣質穢任重王公故周易有折鼎之戒詩人有彼其之譏自居宫室仍抱篤疾計有不足思慮失中多所荒替邊側小人因生酷虐虐毒横流忠順被害闇昧不覺尋其壅蔽孤負諸君事已難圖覆水不可收也今大晉平治四海勞心務於擢賢誠是英俊展節之秋也管仲極讐桓公用之良平去楚入為漢臣舎亂就理非不忠也莫以移朝改朔用損厥志嘉朂休尚愛敬動靜夫復何言投茟而已

**释读** 孙皓承认吴国之亡系自己无德，称既无法挽回，望旧臣投效能招贤的晋廷，不因改朝而改其志。

**归年** 同年向晋纳降前后的文书，正文进退同段。

# 公元280年｜晋太康元年／吴天纪四年

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **版桥交战，张悌等战死。** 吴丞相张悌与沈莹、孙震等渡江迎战王浑一路晋军，在版桥一带兵败战死。晋军上游推进另见本年第6条。 [[1]](#sg-note-1)

<a id="sg-event-2"></a>

2. **孙皓应左右之请杀岑昏。** 晋兵逼近，数百近臣请求杀岑昏，孙皓应允。传文记三月丙寅，《资治通鉴考异》指出本月无此干支。 [[2]](#sg-note-2)

<a id="sg-event-3"></a>

3. **陶濬受命迎敌未发，孙皓分遣使者奉降书。** 陶濬自武昌还，请得二万兵乘大船抵御晋军，士卒在出发前一夜逃散。孙皓采薛莹、胡冲之计，分遣使者向王濬、司马伷、王浑送降书。陶濬回朝，本传记为戊辰，《资治通鉴考异》存疑。 [[3]](#sg-note-3)

<a id="sgz-event-7"></a>

<a id="sg-event-4"></a>

4. **王濬入建业，受孙皓之降。** 三月，王濬先至建业，孙皓缚身舆榇到军门请降。王濬解缚焚榇。《晋书·武帝纪》《资治通鉴》作壬寅，本传作壬申；《通鉴考异》据《长历》指出本月无壬申。奉降书、交印绶见[同年第3条](#sg-note-3)。 [[4]](#sg-note-4)

<a id="sg-event-5"></a>

5. **晋封孙皓为归命侯，孙皓迁到洛阳。** 孙皓及其家属在五月到洛阳。吴主本传记封归命侯诏在四月甲申，《晋书·武帝纪》作五月辛亥。《通鉴》采用四月甲申。 [[5]](#sg-note-5)

<a id="sg-event-6"></a>

6. **王濬自上游进军，陆晏、陆景遇害。** 王濬、唐彬沿江攻下吴地。陆晏在夷道遇害，陆景也在晋军进兵中被杀。《陆抗传》系陆晏于壬戌、陆景于癸亥。《通鉴》记壬戌克夷道、乙丑克乐乡，《晋书·武帝纪》在壬戌一并叙及二人。 [[6]](#sg-note-6)

<a id="sgz-event-8"></a>

8. **孙皓又封十一王并大赦。** 在亡吴之年的春天封中山、代等十一王，施大赦。 [[8]](#sgz-note-8)

<a id="sgz-event-9"></a>

9. **平吴后王戎访石伟。** 晋平吴后建威将军王戎到石伟处探视。 [[9]](#sgz-note-9)

<a id="sgz-event-10"></a>

10. **胡威太康元年卒，死所异文。** 《胡质传》正文写「卒於安定」。《晋书·胡威传》作太康元年卒于青州任上，裴注《晋阳秋》同年。 [[10]](#sgz-note-10)

<a id="sgz-event-11"></a>

11. **晋改临水为临安。** 临水入晋后改为临安。 [[11]](#sgz-note-11)

<a id="sgz-event-12"></a>

12. **周处入晋。** 吴亡后周处仕晋。 [[12]](#sgz-note-12)

<a id="sgz-event-13"></a>

13. **晋改新定为遂安。** 新定县入晋后改名遂安。 [[13]](#sgz-note-13)

<a id="sgz-event-14"></a>

14. **晋改休阳为海宁。** 休阳县入晋后改名海宁。 [[14]](#sgz-note-14)

<a id="sgz-event-15"></a>

15. **晋改罗阳县为安固。** 吴罗阳县经孙皓改安阳后，入晋改安固。 [[15]](#sgz-note-15)

<a id="sgz-event-16"></a>

16. **平吴后杜预获封当阳侯。** 封当阳侯，食邑八千。 [[16]](#sgz-note-16)

<a id="sgz-event-17"></a>

17. **汲冢古文竹简出土。** 《四体书势》记汲县民盗发魏襄王冢得简书，类卫觊所写；出土年另有咸宁五年的纪年。 [[17]](#sgz-note-17)

<a id="sgz-event-18"></a>

18. **毌丘宗兄弟在吴亡后还中国。** 兄弟在吴亡之后还，后毌丘宗官至零陵太守，其子毌丘奥任巴东、益州军政。 [[18]](#sgz-note-18)

<a id="sgz-event-19"></a>

19. **诸葛靓因吴亡归晋。** 吴平还晋，后子恢官至尚书令、赠左光禄大夫开府。 [[19]](#sgz-note-19)

### 1. 版桥交战，张悌等战死

[返回正文第1条](#sg-event-1)

<a id="sgz048-b-2377-2"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sgz048-b-2377-2)** · [TXT L149](../../sources/本地分卷/三国志/三国志-卷048.txt#L149)

> 濬、彬所至，則土崩瓦解，靡有禦者。預又斬江陵督伍延，渾復斬丞相張悌、丹楊太守沈瑩等，所在戰克。

**吴军沿江溃退，伍延张悌沈莹等死** 王濬、唐彬两军所向，吴军崩溃。杜预斩江陵督伍延，王浑一路斩张悌、沈莹等。

**归年依据** 本传天纪四年，晋太康元年，《晋书·武帝纪》及诸将传可核。

<a id="sgz048-p-037-1"></a>

**[《三國志·三嗣主傳》 裴注 037·1](../../sources/本地分卷/三国志/三国志-卷048.md#pei-037-1)** · [TXT L150](../../sources/本地分卷/三国志/三国志-卷048.txt#L150)

> 干寶晉紀曰：吳丞相軍師張悌、護軍孫震、丹楊太守沈瑩帥衆三萬濟江，圍成陽都尉張喬於楊荷橋，衆才七千，閉柵自守，舉白接告降。吳副軍師諸葛靚欲屠之，悌曰：「彊敵在前，不宜先事其小；且殺降不祥。」靚曰：「此等以救兵未至而力少，故且偽降以緩我，非來伏也。因其無戰心而盡阬之，可以成三軍之氣。若舍之而前，必爲後患。」悌不從，撫之而進。與討吳護軍張翰、揚州刺史周浚成陣相對。沈瑩領丹楊銳卒刀楯五千，號曰青巾兵，前後屢陷堅陣，於是以馳淮南軍，三衝不動。退引亂，薛勝、蔣班因其亂而乘之，吳軍以次土崩，將帥不能止，張喬又出其後，大敗吳軍于阪橋，獲悌、震、瑩等。

**释读** 张悌拒诸葛靓预先杀降的建议。沈莹率精锐三冲未果，吴军后退生乱，晋军乘势，张乔从背后攻击，大败吴军于版桥。
**归年** 晋太康元年二三月灭吴，《晋书·武帝纪》与吴本传同；战地细节来自干宝。

<a id="period-sgz048-p-037-2"></a>

**[《三國志·三嗣主傳》 裴注 037·2](../../sources/本地分卷/三国志/三国志-卷048.md#pei-037-2)** · [TXT L150](../../sources/本地分卷/三国志/三国志-卷048.txt#L150)

> 襄陽記曰：悌字巨先，襄陽人，少有名理，孫休時爲屯騎校尉。

**釋讀** 张悌字巨先，襄阳人，少有名，在孙休时任屯骑校尉。

**附敘** 《襄陽記》於張悌戰死處補敘籍貫、名聲及孫休時任校尉的履歷，官職確年未載。

<a id="sgz048-p-037-4"></a>

**[《三國志·三嗣主傳》 裴注 037·4](../../sources/本地分卷/三国志/三国志-卷048.md#pei-037-4)** · [TXT L150](../../sources/本地分卷/三国志/三国志-卷048.txt#L150)

> 晉來伐吳，皓使悌督沈瑩、諸葛靚，率衆三萬渡江逆之。至牛渚，沈瑩曰：「晉治水軍於蜀乆矣，今傾國大舉，萬里齊力，必悉益州之衆浮江而下。我上流諸軍，無有戒備，名將皆死，幼少當任，恐邊江諸城，盡莫能禦也。晉之水軍，必至于此矣！宜畜衆力，待來一戰。若勝之日，江西自清，上方雖壞，可還取之。今渡江逆戰，勝不可保，若或摧喪，則大事去矣。」悌曰：「吳之將亡，賢愚所知，非今日也。吾恐蜀兵來至此，衆心必駭懼，不可復整。今宜渡江，可用決戰力爭。若其敗喪，則同死社稷，無所復恨。若其克勝，則北敵奔走，兵勢萬倍，便當乘威南上，逆之中道，不憂不破也。若如子計，恐行散盡，相與坐待敵到，君臣俱降，無復一人死難者，不亦辱乎！」

**释读** 沈莹主张集中力量等晋的益州水军。张悌说众闻蜀船将至会先乱，渡江战败则共殉，胜能反击晋舟师，故选择渡江决战。
**归年** 太康元年张悌与晋军交战阶段，细节见此传和干宝。

<a id="sgz048-p-037-5"></a>

**[《三國志·三嗣主傳》 裴注 037·5](../../sources/本地分卷/三国志/三国志-卷048.md#pei-037-5)** · [TXT L150](../../sources/本地分卷/三国志/三国志-卷048.txt#L150)

> 遂渡江戰，吳軍大敗。諸葛靚與五六百人退走，使過迎悌，悌不肯去，靚自往牽之，謂曰：「且夫天下存亡有大數，豈卿一人所知，如何故自取死爲？」悌垂涕曰：「仲思，今日是我死日也。且我作兒童時，便爲卿家丞相所拔，常恐不得其死，負名賢知顧。今以身徇社稷，復何遁邪？莫牽曳之如是。」靚流涕放之，去百餘步，已見爲晉軍所殺。

**释读** 吴军大败，诸葛靓折回劝退，张悌忆诸葛家知遇，执意留下，晋军杀之。
**归年** 卷048正文及《晋书·武帝纪》太康元年张悌战死。

<a id="period-sgz048-p-037-6"></a>

**[《三國志·三嗣主傳》 裴注 037·6](../../sources/本地分卷/三国志/三国志-卷048.md#pei-037-6)** · [TXT L150](../../sources/本地分卷/三国志/三国志-卷048.txt#L150)

> 吳錄曰：悌少知名，及處大任，希合時趣，將護左右，清論譏之。

**釋讀** 张悌早有名，但在高位时常随时势、照顾左右，引来舆论讥评。

**附敘** 《吳錄》另評張悌居高位後的行事，附於其戰死條。

<a id="sgz048-p-037-7"></a>

**[《三國志·三嗣主傳》 裴注 037·7](../../sources/本地分卷/三国志/三国志-卷048.md#pei-037-7)** · [TXT L150](../../sources/本地分卷/三国志/三国志-卷048.txt#L150)

> 搜神記曰：臨海松陽人柳榮從悌至楊府，榮病死船中二日，時軍已上岸，無有埋之者，忽然大呼，言「人縛軍師！人縛軍師！」聲激揚，遂活。人問之，榮曰：「上天北斗門下卒見人縛張悌，意中大愕，不覺大呼，言『何以縛張軍師。』門下人怒榮，叱逐使去。榮便去，怖懼，口餘聲發揚耳。」其日，悌戰死。榮至晉元帝時猶在。

**释读** 柳荣随张悌出征，病死两天，传称苏醒后说在天上见张悌被绑，该日张悌果然战死。柳荣到东晋元帝时还活着。
**归年** 附280同次战死的神异叙述；元帝在位317–323，是见证下限。

### 2. 孙皓应左右之请杀岑昏

[返回正文第2条](#sg-event-2)

<a id="period-sgz048-b-2376-3"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-period-sgz048-b-2376-3)** · [TXT L146](../../sources/本地分卷/三国志/三国志-卷048.txt#L146)

> 岑昬險諛貴幸，致位九列，好興功役，衆所患苦。是以上下離心，莫爲皓盡力，蓋積惡已極，不復堪命故也。

**岑昏兴役及朝廷离心** 岑昏善迎合获宠，位列九卿，多兴工役，众人怨苦。陈寿以此说明吴廷离心。

**附敘** 本傳追敘岑昏受寵、興役而失眾，作為三月近臣請殺岑昏的前情，各項工程未載確年。

<a id="sgz048-b-2378-1"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sgz048-b-2378-1)** · [TXT L152](../../sources/本地分卷/三国志/三国志-卷048.txt#L152)

> 三月丙寅，殿中親近數百人叩頭請皓殺岑昏，皓惶憒從之。

**孙皓允近臣请求杀岑昏** 近臣数百叩头请杀岑昏，孙皓惊惶地同意。

**归年依据** 本传三月丙寅，干宝《晋纪》另有劝阻来不及经过。

**紀日異說** 本傳書三月丙寅。《資治通鑑考異》據《長曆》指出本月無丙寅，具體日存疑。

<a id="sgz048-p-038-1"></a>

**[《三國志·三嗣主傳》 裴注 038·1](../../sources/本地分卷/三国志/三国志-卷048.md#pei-038-1)** · [TXT L153](../../sources/本地分卷/三国志/三国志-卷048.txt#L153)

> 干寶晉紀曰：皓殿中親近數百人叩頭請皓曰：「北軍日近，而兵不舉刃，陛下將如之何！」皓曰：「何故？」對曰：「坐岑昏。」皓獨言：「若爾，當以奴謝百姓。」衆因曰：「唯！」遂並起收昏。皓駱驛追止，已屠之也。

**释读** 近臣百人说兵不抵抗缘于岑昏，孙皓松口后众人拿了岑昏；孙皓数次使人追止时已经被杀。
**归年** 本传天纪四年三月丙寅，同号。

### 3. 陶濬受命迎敌未发，孙皓分遣使者奉降书

[返回正文第3条](#sg-event-3)

<a id="sgz048-b-2379-1"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sgz048-b-2379-1)** · [TXT L155](../../sources/本地分卷/三国志/三国志-卷048.txt#L155)

> 戊辰，陶濬從武昌還，即引見，問水軍消息，對曰：「蜀船皆小，今得二萬兵，乘大船戰，自足擊之。」於是合衆，授濬節鉞。明日當發，其夜衆悉逃走。

**陶濬请得水军抵抗，下属逃散** 陶濬称晋水军船小，希望率二万人用大船出战。孙皓给他兵、节钺，部众却在出发前一晚散逃。

**归年依据** 本传太康元年三月戊辰。

**紀日異說** 本傳書戊辰。《資治通鑑考異》據《長曆》指出本月無戊辰，具體日存疑。

<a id="sgz048-b-2379-2"></a>

**[《三國志·三嗣主傳》](../../sources/本地分卷/三国志/三国志-卷048.md#edition-sgz048-b-2379-2)** · [TXT L155](../../sources/本地分卷/三国志/三国志-卷048.txt#L155)

> 而王濬順流將至，司馬伷、王渾皆臨近境。皓用光祿勳薛瑩、中書令胡沖等計，分遣使奉書於濬、伷、渾曰：「昔漢室失統，九州分裂，先人因時，略有江南，遂分阻山川，與魏乖隔。今大晉龍興，德覆四海。闇劣偷安，未喻天命。至於今者，猥煩六軍，衡蓋路次，遠臨江渚，舉國震惶，假息漏刻。敢緣天朝含弘光大，謹遣私署太常張夔等奉所佩印綬，委質請命，惟垂信納，以濟元元。」

**孙皓分别向晋三路将发降使** 吴采薛莹、胡冲之计，以张夔等奉印绶、书信，向王濬、司马伷、王浑请降保民。

**归年依据** 本传天纪四年三月，纳降次第见下一条。

<a id="sgz048-p-039-1"></a>

**[《三國志·三嗣主傳》 裴注 039·1](../../sources/本地分卷/三国志/三国志-卷048.md#pei-039-1)** · [TXT L156](../../sources/本地分卷/三国志/三国志-卷048.txt#L156)

> 江表傳載皓將敗，與舅何植書曰：「昔大皇帝以神武之略，奮三千之卒，割據江南，席卷交、廣，開拓洪基，欲祚之萬世。至孤末德，嗣守成緒，不能懷集黎元，多爲咎闕，以違天度。闇昧之變，反謂之祥，致使南蠻逆亂，征討未克。聞晉大衆，遠來臨江，庶竭勞瘁，衆皆摧退，而張悌不反，喪軍過半。孤甚愧悵，于今無聊。得陶濬表云武昌以西並復不守。不守者，非糧不足，非城不固，兵將背戰耳。兵之背戰，豈怨兵邪？孤之罪也。天文縣變於上，士民憤歎於下，觀此事勢，危如累卵，吳祚終訖，何其局哉！天匪亡吳，孤所招也。瞑目黃壤，當復何顏見四帝乎！公其勗勉奇謨，飛筆以聞。」

**释读** 孙皓由孙权开业说到自己失众、南方乱、张悌败战。见陶濬报武昌以西无守，反省在己不在军，求何植速献办法。

**[《三國志·三嗣主傳》 裴注 043·1](../../sources/本地分卷/三国志/三国志-卷048.md#pei-043-1)** · [TXT L167](../../sources/本地分卷/三国志/三国志-卷048.txt#L167)

> 孫盛曰：夫古之立君，所以司牧羣黎，故必仰協乾坤，覆燾萬物；若乃淫虐是縱，酷被羣生，則天殛之，勦絕其祚，奪其南面之尊，加其獨夫之戮。是故湯、武抗鉞，不犯不順之譏；漢高奮劒，而無失節之議。何者？誠四海之酷讎，而人神之所擯故也。況皓罪爲逋寇，虐過辛、癸，梟首素旗，猶不足以謝冤魂，洿室荐社，未足以紀暴迹，而乃優以顯命，寵錫仍加，豈龔行天罰，伐罪弔民之義乎？是以知僭逆之不懲，而凶酷之莫戒。詩云：「取彼譖人，投畀豺虎。」聊譖猶然，矧僭虐乎？且神旗電掃，兵臨偽窟，理窮勢迫，然後請命，不赦之罪旣彰，三驅之義又塞，極之權道，亦無取焉。

**釋讀** 孙盛主张伤害民众的国君应被剥夺君位惩处，孙皓穷困才乞降，不合既宽赦又加礼遇之义。

**附敘** 孫盛評論西晉封賞已降的孫皓，隨封歸命侯的史料對讀。

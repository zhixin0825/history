# 公元281年｜西晋太康二年

[← 公元280年](ce-0280.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元282年 →](ce-0282.md)

[本年相关史料](#sources-start)

<a id="sgz-event-1"></a>

1. **晋诏授石伟议郎二千石，石伟辞爵。** 晋廷称许石伟身处乱世仍清廉，因年迈不召远行，给议郎和二千石秩，石伟装作疯瞎不受。 [[1]](#sgz-note-1)

<a id="jin003-l280-event"></a>

2. **淮南丹杨地震。** 二月，淮南、丹杨地震。 [[2]](#jin003-l280-note)

<a id="jin003-l281-event"></a>

3. **司马敦卒、分赐吴俘与采吴宫人。** 三月丙申，安平王司马敦去世。把吴的被俘人口按等赐给王公以下；诏选孙皓妓妾五千人入晋宫。东夷五国朝献。“生口”为被支配、分赐的人口，不译成一般自愿移民。 [[3]](#jin003-l281-note)

<a id="jin003-l282-event"></a>

4. **来附与雹风水灾。** 六月，东夷五国来附。十六郡国降雹，大风拔树、毁房；江夏、泰山水灾，冲走三百余家。 [[4]](#jin003-l282-note)

<a id="jin003-l283-event"></a>

5. **上党风雹。** 七月，上党再次暴风降雹，损伤秋庄稼。 [[5]](#jin003-l283-note)

<a id="jin003-l284-event"></a>

6. **张宿孛星。** 八月，张宿记有孛星。 [[6]](#jin003-l284-note)

<a id="jin003-l285-event"></a>

7. **昌黎鲜卑入寇的首领异说。** 冬十月，鲜卑进犯昌黎。本纪称首领慕容廆，《通鉴考异》据燕书世系认为此时其父涉归尚在，应为涉归；保留父子人名分歧，不把它确认为廆本人已发动的一役。 [[7]](#jin003-l285-note)

<a id="jin003-l286-event"></a>

8. **陈骞卒、孛星及辽西战事。** 十一月壬寅，陈骞去世，本纪沿称大司马，而本传记他此前已辞位。轩辕星区有孛星。鲜卑侵辽西，平州刺史鲜于婴讨破之。 [[8]](#jin003-l286-note)

<a id="jin003-bamboo-281-event"></a>

9. **汲冢竹书出土的太康二年异说。** 《束晳传》把汲郡不准盗发魏王墓、得竹书数十车系在太康二年（281），又记墓主或为安釐王。与《武帝纪》的279年、《四体书势》的280年并列；本条是同一事件的系年异说，不能当作又一次发掘。参看[279年](ce-0279.md#jin003-l265)、[280年](ce-0280.md#jin003-bamboo-280)。 [[9]](#jin003-bamboo-281-note)

## 本年概述

晋处置吴宫人口，安平王司马敦、高平公陈骞去世。鲜卑进犯昌黎、辽西，地震、风雹与水灾相继发生。


<a id="jin003-u280-1-event"></a>
<a id="jin003-l280-event"></a>

1. **淮南丹杨地震。** 二月，淮南、丹杨地震。 [[1]](#jin003-u280-1-note)

<a id="jin003-u281-1-event"></a>
<a id="jin003-l281-event"></a>

2. **司马敦去世。** 三月丙申，安平王司马敦去世。 [[2]](#jin003-u281-1-note)

<a id="jin003-u281-2-event"></a>

3. **以吴生口赐王公。** 三月，分等赐王公以下吴地俘获的人口。 [[3]](#jin003-u281-2-note)

<a id="jin003-u281-3-event"></a>

4. **选孙皓妓妾入宫。** 三月，下诏选孙皓妓妾五千人入宫。 [[4]](#jin003-u281-3-note)

<a id="jin003-u281-4-event"></a>

5. **东夷五国朝献。** 三月，东夷五国来朝献。 [[5]](#jin003-u281-4-note)

<a id="jin003-u282-1-event"></a>
<a id="jin003-l282-event"></a>

6. **东夷五国归附。** 六月，东夷五国归附。 [[6]](#jin003-u282-1-note)

<a id="jin003-u282-2-event"></a>

7. **十六郡国雨雹大风。** 六月，十六郡国降雹，大风拔树、毁民房。 [[7]](#jin003-u282-2-note)

<a id="jin003-u282-3-event"></a>

8. **江夏、泰山水灾。** 六月，江夏、泰山水灾，冲走居民三百余家。 [[8]](#jin003-u282-3-note)

<a id="jin003-u283-1-event"></a>
<a id="jin003-l283-event"></a>

9. **上党风雹。** 七月，上党又遭暴风、雨雹，损伤秋作物。 [[9]](#jin003-u283-1-note)

<a id="jin003-u284-1-event"></a>
<a id="jin003-l284-event"></a>

10. **张宿孛星。** 八月，张宿出现孛星。 [[10]](#jin003-u284-1-note)

<a id="jin003-u285-1-event"></a>
<a id="jin003-l285-event"></a>

11. **昌黎鲜卑入寇的首领异说。** 十月，鲜卑涉归部进犯昌黎。 [[11]](#jin003-u285-1-note)

<a id="jin003-u286-1-event"></a>
<a id="jin003-l286-event"></a>

12. **陈骞去世。** 十一月壬寅，高平公陈骞去世。 [[12]](#jin003-u286-1-note)

<a id="jin003-u286-2-event"></a>

13. **轩辕见孛星。** 十一月，轩辕星区出现孛星。 [[13]](#jin003-u286-2-note)

<a id="jin003-u286-3-event"></a>

14. **鲜于婴击退辽西鲜卑。** 十一月，鲜卑侵辽西，平州刺史鲜于婴击败来军。 [[14]](#jin003-u286-3-note)

<a id="sgz-event-1"></a>

15. **晋诏授石伟议郎二千石，石伟辞爵。** 晋廷称许石伟身处乱世仍清廉，因年迈不召远行，给议郎和二千石秩，石伟装作疯瞎不受。 [[15]](#sgz-note-1)

### 15. 晋诏授石伟议郎二千石，石伟辞爵

[返回正文第15条](#sgz-event-1)

<a id="sgz048-p-010-5"></a>

**[《三國志·三嗣主傳》 裴注 010·5](../../拆分史书/三国志/卷048.md#pei-010-5)** · [TXT L53](../../拆分史书/三国志/卷048.txt#L53)

> 太康二年，詔曰：「吳故光祿大夫石偉，秉志清白，皓首不渝，難處危亂，廉節可紀。年已過邁，不堪遠涉，其以偉爲議郎，加二千石秩，以終厥世。」偉遂陽狂及盲，不受晉爵。

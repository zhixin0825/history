# 公元282年｜晋太康三年

<a id="sg-event-1"></a>

1. **薛莹去世。** 吴亡入晋后获官的薛莹于太康三年去世。 [[1]](#sg-note-1)

<a id="sgz-event-2"></a>

2. **郭德、王济谏留齐王司马攸。** 郭德与王济谏止让司马攸出国，晋武帝不满，将郭德出为大鸿胪。 [[2]](#sgz-note-2)

<a id="sgz-event-4"></a>

<a id="sgz-event-3"></a>

3. **贾充卒后赠太宰，谥武。** 晋廷追赠贾充太宰，谥武。 [[3]](#sgz-note-3)

<a id="sgz-event-5"></a>

5. **裴松之据《太康三年地记》驳陈群所估魏户数。** 该书载晋有三百七十七万户，裴松之以吴蜀不足占半，推知魏不能少至等同汉一大郡。 [[5]](#sgz-note-5)

### 2. 郭德、王济谏留齐王司马攸

[返回正文第2条](#sgz-event-2)

<a id="sgz005-p-014-1d"></a>

**[《三国志》卷005裴注 014·1d](../../sources/本地分卷/三国志/三国志-卷005.md#pei-014-1d)**

> 太康中大司馬齊王攸當之藩悳與左衛將軍王濟共諫請時人嘉之世祖以此望悳由此出悳為大鴻臚加侍中光禄大夫

**释读** 齐王司马攸将出藩，郭德、王济谏留。郭德触怒晋武帝，出为大鸿胪，加侍中、光禄大夫。

**归年** 《晋书·武帝纪》及《资治通鉴》卷八十一系太康三年，其他任官与本事前后相接。

<a id="sgz005-p-012-6"></a>

**[《三国志·后妃传》裴注 012·6](../../sources/本地分卷/三国志/三国志-卷005.md#pei-012-6)**

> 太康中大司馬齊王攸當之藩悳與左衛將軍王濟共諫請時人嘉之世祖以此望悳由此出悳為大鴻臚加侍中光禄大夫

**归年** 《晋书·武帝纪》太康三年十二月诏出齐王。《资治通鉴》卷081同年记此谏与郭德出任大鸿胪。后续卒年另分。

### 5. 裴松之据《太康三年地记》驳陈群所估魏户数

[返回正文第5条](#sgz-event-5)

<a id="sgz022-p-005-2"></a>

**[《三国志·桓二陈徐卫卢传》裴注 005·2](../../sources/本地分卷/三国志/三国志-卷022.md#pei-005-2)**

> 案晉太康三年地記晉戸有三百七十七萬吳蜀戸不能居半以此言之魏雖始承喪亂方晉亦當無乃大殊長文之言於是為過

**归年** 裴注书名明确太康三年（282）；《晋书·地理志》太康元年平吴总户数为另一数字、另年，不能互换。

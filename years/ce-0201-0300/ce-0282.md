# 公元282年｜晋太康三年

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **薛莹去世。** 吴亡入晋后获官的薛莹于太康三年去世。 [[1]](#sg-note-1)

<a id="sgz-event-2"></a>

2. **郭德、王济谏留齐王司马攸。** 郭德与王济谏止让司马攸出国，晋武帝不满，将郭德出为大鸿胪。 [[2]](#sgz-note-2)

<a id="sgz-event-3"></a>

3. **晋追赠贾充太宰。** 《赞》列贾充晋最高荣官太宰。 [[3]](#sgz-note-3)

<a id="sgz-event-4"></a>

4. **贾充卒后谥武。** 贾充谥武。 [[4]](#sgz-note-4)

### 2. 郭德、王济谏留齐王司马攸

[返回正文第2条](#sgz-event-2)

<a id="sgz005-p-012-6"></a>

**[《三国志·后妃传》裴注 012·6](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-012-6)**

> 太康中大司馬齊王攸當之藩悳與左衛將軍王濟共諫請時人嘉之世祖以此望悳由此出悳為大鴻臚加侍中光禄大夫

**归年** 《晋书·武帝纪》太康三年十二月诏出齐王。《资治通鉴》卷081同年记此谏与郭德出任大鸿胪。后续卒年另分。

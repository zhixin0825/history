## 本年概述

晋撤秦州并入雍州，任张华督幽州，调整三公及宗王军职，齐王出镇引起谏争。贾充、李胤去世，晋军平定吴故将起兵。


<a id="jin003-u287-1-event"></a>
<a id="jin003-l287-event"></a>

1. **秦州并入雍州。** 正月丁丑，撤秦州，并入雍州。 [[1]](#jin003-u287-1-note)

<a id="jin003-u287-2-event"></a>

2. **张华都督幽州。** 正月甲午，以尚书张华都督幽州诸军。 [[2]](#jin003-u287-2-note)

<a id="jin003-u288-1-event"></a>
<a id="jin003-l288-event"></a>

3. **严询在昌黎破鲜卑。** 三月，安北将军严询在昌黎击败鲜卑涉归部，杀伤数万人。 [[3]](#jin003-u288-1-note)

<a id="sgz-event-4"></a>
<a id="sgz-event-3"></a>

4. **贾充去世。** 四月庚午，太尉、鲁公贾充去世，年六十六，追赠太宰，谥武。 [[4]](#sgz-note-3)

<a id="jin003-u290-1-event"></a>
<a id="jin003-l290-event"></a>

5. **李胤去世。** 闰月，司徒、广陆侯李胤去世。 [[5]](#jin003-u290-1-note)

<a id="jin003-u290-2-event"></a>

6. **济南报白龙。** 济南报告白龙两次。 [[6]](#jin003-u290-2-note)

<a id="jin003-u291-1-event"></a>
<a id="jin003-l291-event"></a>

7. **平宁刺史入奏制度的疑句。** 七月，平州、宁州刺史制度有变动，三年入奏的具体规定尚有疑义。 [[7]](#jin003-u291-1-note)

<a id="jin003-u292-1-event"></a>
<a id="jin003-l292-event"></a>

8. **东夷二十九国来献。** 九月，东夷二十九国归附，献地方物产。 [[8]](#jin003-u292-1-note)

<a id="jin003-u292-2-event"></a>

9. **嵇喜平莞恭、帛奉。** 九月，吴故将莞恭、帛奉起兵，杀建业令，继而围扬州；徐州刺史嵇喜将其讨平。 [[9]](#jin003-u292-2-note)

<a id="sgz-event-2"></a>

10. **司马攸等迁任三公。** 十二月甲申，以司空齐王司马攸为大司马、督青州诸军，琅邪王司马伷为大将军；汝南王司马亮为太尉，光禄大夫山涛为司徒，尚书令卫瓘为司空。同月命司马攸赴封国，甄德、王济进谏挽留，司马炎不满，改任甄德为大鸿胪，加侍中、光禄大夫。 [[10]](#sgz-note-2)

<a id="jin003-u293-2-event"></a>

11. **免重灾区田租。** 十二月丙申，免各地水旱灾害严重者田租。 [[11]](#jin003-u293-2-note)

<a id="sg-event-1"></a>

12. **薛莹去世。** 吴亡入晋后获官的薛莹于太康三年去世。 [[12]](#sg-note-1)

<a id="sgz-event-5"></a>

13. **西晋统计户口。** 太康三年的一项记录列西晋有三百七十七万户。 [[13]](#sgz-note-5)

<a id="wei005-l48-6"></a>

**釋讀與歸年** 齐王司马攸出镇的任命与劝阻系太康三年，王赴国及去世在次年；《资治通鉴》在太康三年十二月出镇议内并记甄德、王济进谏及甄德改任大鸿胪，两事无干支；加侍中、光禄大夫以本注为据。

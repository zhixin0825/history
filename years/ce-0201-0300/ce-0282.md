1. **薛莹去世。** 吴亡入晋后获官的薛莹于太康三年去世。 [[1]](#sg-note-1)

<a id="sgz-event-2"></a>

2. **甄德、王济谏留齐王司马攸。** 十二月，朝廷命齐王司马攸赴封国，甄德与王济进谏。晋武帝不满，改任甄德为大鸿胪，加侍中、光禄大夫。 [[2]](#sgz-note-2)

<a id="sgz-event-4"></a>

<a id="sgz-event-3"></a>

3. **贾充卒后赠太宰，谥武。** 晋廷追赠贾充太宰，谥武。 [[3]](#sgz-note-3)

<a id="sgz-event-5"></a>

4. **西晋统计户口。** 太康三年的一项记录列西晋有三百七十七万户。 [[4]](#sgz-note-5)

### 2. 甄德、王济谏留齐王司马攸

[返回正文第2条](#sgz-event-2)

<a id="sgz005-p-014-1d"></a>

[本卷同事原句](#wei005-l48-6)。

**归年** 《晋书·武帝纪》及《资治通鉴》卷八十一系太康三年，其他任官与本事前后相接。

<a id="sgz005-p-012-6"></a>

**归年** 《晋书·武帝纪》太康三年十二月诏出齐王。《资治通鉴》卷081同年记此谏与郭德出任大鸿胪。后续卒年另分。

<a id="wei005-l48-6"></a>

**[《三國志·后妃傳》裴注](../../拆分史书/三国志/卷005.md#edition-wei005-l48-6)** · [TXT L48](../../拆分史书/三国志/卷005.txt#L48)

> 太康中，大司馬齊王攸當之藩，德與左衞將軍王濟共諫請，時人嘉之。世祖以此望德，由此出德爲大鴻臚，加侍中、光祿大夫，

**釋讀與歸年** 齐王司马攸出镇的任命与劝阻系太康三年，王赴国及去世在次年；《资治通鉴》在太康三年十二月出镇议内并记甄德、王济进谏及甄德改任大鸿胪，两事无干支；加侍中、光禄大夫以本注为据。

### 4. 西晋统计户口

[返回正文第4条](#sgz-event-5)

**异文与补证** 《太康三年地记》载此数。裴松之据此认为原吴、蜀户数不足其半，以此质疑陈群所估魏户数，认为魏地户数不至于少到只相当于汉朝一大郡。

<a id="sgz022-p-005-2"></a>

**[《三国志·桓二陈徐卫卢传》裴注 005·2](../../拆分史书/三国志/卷022.md#pei-005-2)**

> 案晉太康三年地記晉戸有三百七十七萬吳蜀戸不能居半以此言之魏雖始承喪亂方晉亦當無乃大殊長文之言於是為過

**归年** 裴注书名明确太康三年（282）；《晋书·地理志》太康元年平吴总户数为另一数字、另年，不能互换。

# 公元282年｜晋太康三年

[← 公元281年](ce-0281.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元283年 →](ce-0283.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **薛莹去世。** 吴亡入晋后获官的薛莹于太康三年去世。 [[1]](#sg-note-1)

<a id="sgz-event-2"></a>

2. **甄德、王济谏留齐王司马攸。** 十二月，朝廷命齐王司马攸赴封国，甄德与王济进谏。晋武帝不满，改任甄德为大鸿胪，加侍中、光禄大夫。 **《武帝纪》补记：** 十二月甲申，任司马攸为大司马、督青州，司马伷为抚军大将军，司马亮太尉，山涛司徒，卫瓘司空；司马攸出督与当时谏留事件合读。本纪“抚军大将军”另有衍字校说，不能覆盖本传、职官志。丙申，诏水旱特别严重地区免田租。 [[2]](#sgz-note-2)

<a id="sgz-event-4"></a>

<a id="sgz-event-3"></a>

3. **贾充卒后赠太宰，谥武。** 四月庚午，太尉、鲁公贾充去世，年六十六。晋廷追赠太宰，谥武。 [[3]](#sgz-note-3)

<a id="sgz-event-5"></a>

4. **西晋统计户口。** 太康三年的一项记录列西晋有三百七十七万户。 [[4]](#sgz-note-5)

<a id="jin003-l287-event"></a>

5. **撤秦州与张华督幽州。** 正月丁丑，撤秦州并入雍州。甲午，以尚书张华都督幽州军事。 [[5]](#jin003-l287-note)

<a id="jin003-l288-event"></a>

6. **严询在昌黎破鲜卑。** 三月，安北将军严询在昌黎击败鲜卑，本纪称慕容廆部，称杀伤数万人；与上年同有涉归、慕容廆父子归名的疑问。数目依本纪，不另作人口统计。 [[6]](#jin003-l288-note)

<a id="jin003-l290-event"></a>

7. **李胤卒及济南白龙的日序。** 闰月丙子，司徒、广陆侯李胤去世；癸丑，济南报告白龙两次。两干支不能同在一月，记事保留，具体历日待考。 [[7]](#jin003-l290-note)

<a id="jin003-l291-event"></a>

8. **平宁刺史入奏制度的疑句。** 七月，本纪记“罢平州、宁州刺史三年一入奏事”，断句及制度含义有争议。若连续读，是取消两州刺史三年一次入奏的安排；也有把罢州、刺史入奏分别读的说法，不能据此断言两州同时废除。《地理志》废宁州入益州系本年，《通鉴》从《华阳国志》移到284年，沿革异年与本句制度疑义分别保留。斠注所据本纪又作八月，本底本作七月，不默改月次。 [[8]](#jin003-l291-note)

<a id="jin003-l292-event"></a>

9. **外附与吴故将起兵。** 九月，东夷二十九国来附、献方物。吴故将莞恭、帛奉起兵，攻杀建业令，继围扬州治所，徐州刺史嵇喜讨平。原本姓名与别本作薛莹等有异，不能把已仕晋、同年卒的薛莹无据写成起兵者。 [[9]](#jin003-l292-note)

## 本年概述

山涛、司马攸、司马陵、司马伷相继去世，朝廷增九卿礼秩、调整诸王及军职。边地归附、遣子入侍与多地水灾并见。


<a id="jin003-u294-1-event"></a>
<a id="jin003-l294-event"></a>

1. **魏舒、司马晃迁仆射。** 正月，以尚书右仆射魏舒为左仆射，下邳王司马晃为右仆射。 [[1]](#jin003-u294-1-note)

<a id="jin003-u294-2-event"></a>

2. **山涛去世。** 正月，司徒山涛去世。 [[2]](#jin003-u294-2-note)

<a id="jin003-u295-1-event"></a>
<a id="jin003-l295-event"></a>

3. **立司马寔北海王。** 二月己丑，立长乐亭侯司马寔为北海王。 [[3]](#jin003-u295-1-note)

<a id="jin003-u296-1-event"></a>
<a id="jin003-l296-event"></a>

4. **三月朔日食。** 三月辛丑朔，发生日食。 [[4]](#jin003-u296-1-note)

<a id="jin003-u296-2-event"></a>

5. **司马攸去世。** 三月癸丑，大司马、齐王司马攸去世。 [[5]](#jin003-u296-2-note)

<a id="jin003-u297-1-event"></a>
<a id="jin003-l297-event"></a>

6. **任城王司马陵去世。** 四月，任城王司马陵去世。 [[6]](#jin003-u297-1-note)

<a id="jin003-u298-1-event"></a>
<a id="jin003-l298-event"></a>

7. **司马伷去世。** 五月己亥，大将军、琅邪王司马伷去世。 [[7]](#jin003-u298-1-note)

<a id="jin003-u298-2-event"></a>

8. **司马蕤徙东莱。** 五月，辽东王司马蕤改封东莱王。 [[8]](#jin003-u298-2-note)

<a id="jin003-u299-1-event"></a>
<a id="jin003-l299-event"></a>

9. **增加九卿礼秩。** 六月，增加九卿礼遇及俸秩。 [[9]](#jin003-u299-1-note)

<a id="jin003-u299-2-event"></a>

10. **牂柯诸部归附。** 六月，牂柯獠二千余部落归附。 [[10]](#jin003-u299-2-note)

<a id="jin003-u300-1-event"></a>
<a id="jin003-l300-event"></a>

11. **司马晃都督青州。** 七月壬子，以尚书右仆射、下邳王司马晃都督青州诸军。 [[11]](#jin003-u300-1-note)

<a id="jin003-u300-2-event"></a>

12. **兖州大水，免田租。** 七月丙寅，兖州大水，免其田租。 [[12]](#jin003-u300-2-note)

<a id="jin003-u301-1-event"></a>
<a id="jin003-l301-event"></a>

13. **鄯善遣子入侍。** 八月，鄯善遣子入侍，授归义侯的名号。 [[13]](#jin003-u301-1-note)

<a id="jin003-u301-2-event"></a>

14. **司马泰任尚书右仆射。** 八月，以陇西王司马泰为尚书右仆射。 [[14]](#jin003-u301-2-note)

<a id="jin003-u302-1-event"></a>
<a id="jin003-l302-event"></a>

15. **司马该去世。** 十一月戊午，新都王司马该去世。 [[15]](#jin003-u302-1-note)

<a id="jin003-u302-2-event"></a>

16. **魏舒任司徒。** 十一月，以尚书左仆射魏舒为司徒。 [[16]](#jin003-u302-2-note)

<a id="jin003-u303-1-event"></a>
<a id="jin003-l303-event"></a>

17. **十二月大阅。** 十二月庚午，在宣武观大阅。 [[17]](#jin003-u303-1-note)

<a id="jin003-u304-1-event"></a>
<a id="jin003-l304-event"></a>

18. **全年水灾。** 本年，河内及荆州、扬州大水。 [[18]](#jin003-u304-1-note)

<a id="sgz-event-2"></a>

19. **曹志反对司马攸出藩，晋武帝免其官。** 晋武帝要礼官议齐王出藩当赐的典仪；曹志认为才亲兼具不应使其远在海隅，奏谏甚切，皇帝大怒免官。 [[19]](#sgz-note-2)

### 19. 曹志反对司马攸出藩，晋武帝免其官

[返回正文第19条](#sgz-event-2)

**《任城陳蕭王傳》互見** [TXT 第98行第5段](../../拆分史书/三国志/卷019.md#edition-wei019-l98-5) · [TXT 第98行第7段](../../拆分史书/三国志/卷019.md#edition-wei019-l98-7)

<a id="wei019-l98-6"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l98-6)** · [TXT L98](../../拆分史书/三国志/卷019.txt#L98)

> 及齊王攸當之藩，下禮官議崇錫之典，志歎曰：「安有如此之才，如此之親，而不得樹本助化，而遠出海隅者乎？」乃建議以諫，辭旨甚切。帝大怒，免志官。

**釋讀與歸年** 晉廷討論齊王司馬攸出藩禮儀，曹志稱才德與至親兼具的人不當遠出，力諫，因而被免官。[《資治通鑑》卷81](../../史书/025-资治通鉴/KR2b0007_081.txt#L488-L504)繫太康四年正月，出鎮任命另見上年。

<a id="sgz019-p-020-7"></a>

[本卷同事原句](#wei019-l98-6)。

**归年** 《晋书·武帝纪》282年十二月授攸大司马督青州；《资治通鉴》卷081明确崇锡议与曹志获免在太康四年正月条，故系283年。

此处保存太康四年十二月的卒年异说。返回[孙皓在洛阳去世](ce-0284.md#sg-event-1)。

<a id="sgz-note-1"></a>

**异文与补证** 《吴录》系于太康四年十二月，称孙皓四十二岁、葬河南县境。太康四年以西历 283 年为对应年号年，该年十二月已在西历 284 年初。陈寿本传将同一卒事系于[太康五年](ce-0284.md#sg-note-1)。

<a id="sgz048-p-042-1"></a>

**[《三國志·三嗣主傳》 裴注 042·1](../../拆分史书/三国志/卷048.md#pei-042-1)** · [TXT L163](../../拆分史书/三国志/卷048.txt#L163)

> 吳錄曰：皓以四年十二月死，時年四十二，葬河南縣界。

**归年** 四库与通行本同作四年，和本传五年（284）异。拟入283异载并互链，不能写作两次死亡。

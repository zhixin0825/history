# 公元284年｜晋太康五年

[← 公元283年](ce-0283.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元285年 →](ce-0285.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="sg-event-1"></a>

1. **孙皓死于洛阳。** 归晋后受封归命侯的孙皓在洛阳去世。 [[1]](#sg-note-1)

<a id="jin003-l305-event"></a>

2. **武库井青龙。** 正月己亥，武库井中报告青龙两次；《五行志》有癸卯的记日异说。 [[2]](#jin003-l305-note)

<a id="jin003-l306-event"></a>

3. **司马玷封王与地震。** 二月丙寅，立南宫王之子司马玷为长乐王；壬辰，地震。“玷”与本传异字保留，不把爵嗣姓名默改。 [[3]](#jin003-l306-note)

<a id="jin003-l307-event"></a>

4. **池水变色与宣帝庙梁折。** 夏四月，任城、鲁国池水红如血；五月丙午，宣帝庙梁折。变色和庙损是原书灾异记述，不据此证明某个政治预兆。 [[4]](#jin003-l307-note)

<a id="jin003-l308-event"></a>

5. **黄沙狱的初置异年。** 六月，本纪记初设黄沙狱；《职官志》却在268年说已设黄沙狱侍御史，两书初置年代或相关官署关系有疑，不把二者强合。 [[5]](#jin003-l308-note)

<a id="jin003-l309-event"></a>

6. **皇子恢卒、灾害与减户课。** 七月戊申，皇子司马恢去世。任城、梁国、中山据本纪有雹、伤秋庄稼，其他志区分暴雨和雹灾，地区也有异。减少全国户课三分之一。 [[6]](#jin003-l309-note)

<a id="jin003-l310-event"></a>

7. **南安风雪异记及郡国灾害。** 九月，本纪记南安大风折木；《五行志》相关条作霖雨暴雪或大雪折木。另有五郡国水灾、降霜，伤秋作物，分别保留灾种与地域。 [[7]](#jin003-l310-note)

<a id="jin003-l311-event"></a>

8. **太原王司马辅去世。** 冬十一月甲辰，太原王司马辅去世。 [[8]](#jin003-l311-note)

<a id="jin003-l312-event"></a>

9. **大赦及林邑大秦贡使。** 十二月庚午，大赦。林邑、大秦国各遣使献物；不把古国名径等同于现代国家行政边界。 [[9]](#jin003-l312-note)

<a id="jin003-l313-event"></a>

10. **杜预去世。** 闰月，镇南大将军、当阳侯杜预去世。本页按太康五年年号归284年，阴历年末可能已跨西历年，不能据此擅改其传统卒年。 [[10]](#jin003-l313-note)

## 本年相关史料

<a id="sg-note-1"></a>

### 1. 孙皓死于洛阳

[返回正文第1条](#sg-event-1)

**异文与补证** 《孙皓传》系太康五年在洛阳去世，裴注所引《吴录》作[太康四年十二月](ce-0283.md#sgz-note-1)，换算在西历 284 年初。两书所记年号年不同，《孙皓传》未载月日。

<a id="sg048-l2380-e1"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sg048-l2380-e1)** · [TXT L162](../../拆分史书/三国志/卷048.txt#L162)

> 五年，皓死于洛陽。

**孙皓死于洛阳** 孙皓太康五年在洛阳死。

**归年依据** 陈寿正文太康五年；《吴录》作四年十二月，保异说。

**归年与互校** 此五年承同行太康元年，皇帝纪年已从吴天纪转入晋太康，勿系同段之280。

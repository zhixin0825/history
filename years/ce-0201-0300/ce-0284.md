## 本年概述

晋设黄沙狱，减户课三分之一，多地遭水、雹、霜雪等灾害。太原王司马辅、杜预去世，宣帝庙梁折，朝廷年末大赦。


<a id="jin003-u305-1-event"></a>
<a id="jin003-l305-event"></a>

1. **武库井青龙。** 正月，武库井中报告青龙两次。 [[1]](#jin003-u305-1-note)

<a id="jin003-u306-1-event"></a>
<a id="jin003-l306-event"></a>

2. **司马玷封长乐王。** 二月丙寅，立南宫王之子司马玷为长乐王。 [[2]](#jin003-u306-1-note)

<a id="jin003-u306-2-event"></a>

3. **二月地震。** 二月壬辰，发生地震。 [[3]](#jin003-u306-2-note)

<a id="jin003-u307-1-event"></a>
<a id="jin003-l307-event"></a>

4. **任城、鲁国池水变红。** 四月，任城、鲁国池水红如血。 [[4]](#jin003-u307-1-note)

<a id="jin003-u307-2-event"></a>

5. **宣帝庙梁折。** 五月丙午，宣帝庙梁折。 [[5]](#jin003-u307-2-note)

<a id="jin003-u308-1-event"></a>
<a id="jin003-l308-event"></a>

6. **黄沙狱的初置异年。** 六月，初设黄沙狱。 [[6]](#jin003-u308-1-note)

<a id="jin003-u309-1-event"></a>
<a id="jin003-l309-event"></a>

7. **皇子司马恢去世。** 七月戊申，皇子司马恢去世。 [[7]](#jin003-u309-1-note)

<a id="jin003-u309-2-event"></a>

8. **任城等地雨雹。** 七月，任城、梁国、中山遭雨雹，秋作物受损。 [[8]](#jin003-u309-2-note)

<a id="jin003-u309-3-event"></a>

9. **减天下户课三分之一。** 七月，减天下户课三分之一。 [[9]](#jin003-u309-3-note)

<a id="jin003-u310-1-event"></a>
<a id="jin003-l310-event"></a>

<a id="jin003-u311-1-event"></a>
<a id="jin003-l311-event"></a>

11. **太原王司马辅去世。** 十一月甲辰，太原王司马辅去世。 [[11]](#jin003-u311-1-note)

<a id="jin003-u312-1-event"></a>
<a id="jin003-l312-event"></a>

<a id="jin003-u312-2-event"></a>

13. **林邑、大秦来献。** 十二月，林邑、大秦各遣使来献。 [[13]](#jin003-u312-2-note)

<a id="jin003-u313-1-event"></a>
<a id="jin003-l313-event"></a>

14. **杜预去世。** 闰十二月，镇南大将军、当阳侯杜预去世。 [[14]](#jin003-u313-1-note)

<a id="sg-event-1"></a>

15. **孙皓死于洛阳。** 归晋后受封归命侯的孙皓在洛阳去世。 [[15]](#sg-note-1)

<a id="sg-note-1"></a>

### 15. 孙皓死于洛阳

[返回正文第15条](#sg-event-1)

**异文与补证** 《孙皓传》系太康五年在洛阳去世，裴注所引《吴录》作[太康四年十二月](ce-0283.md#sgz-note-1)，换算在西历 284 年初。两书所记年号年不同，《孙皓传》未载月日。

<a id="sg048-l2380-e1"></a>

**[《三國志·三嗣主傳》](../../拆分史书/三国志/卷048.md#edition-sg048-l2380-e1)** · [TXT L162](../../拆分史书/三国志/卷048.txt#L162)

> 五年，皓死于洛陽。

**孙皓死于洛阳** 孙皓太康五年在洛阳死。

**归年依据** 陈寿正文太康五年；《吴录》作四年十二月，保异说。

**归年与互校** 此五年承同行太康元年，皇帝纪年已从吴天纪转入晋太康，勿系同段之280。

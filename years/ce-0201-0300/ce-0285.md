## 本年概述

晋因歉收免租税、官贷积欠，调整扬荆军职，并减绵绢征收。刘康、王濬去世；巴西地震，南安山崩，朝廷举行宣武观大阅。


<a id="jin003-u314-1-event"></a>
<a id="jin003-l314-event"></a>

1. **免租税、官贷积欠。** 正月甲申朔，因连年歉收，免租税及官贷旧欠。 [[1]](#jin003-u314-1-note)

<a id="jin003-u314-2-event"></a>

2. **王浑迁仆射，褚䂮、杨济分督扬荆。** 以王浑为尚书左仆射，尚书褚䂮都督扬州诸军，杨济都督荆州诸军。 [[2]](#jin003-u314-2-note)

<a id="jin003-u315-1-event"></a>
<a id="jin003-l315-event"></a>

3. **霜伤桑麦。** 三月，六郡国降霜，损伤桑、麦。 [[3]](#jin003-u315-1-note)

<a id="jin003-u316-1-event"></a>
<a id="jin003-l316-event"></a>

4. **扶南等来献、参离归附。** 四月，扶南等十国来献，参离四千余部落归附。 [[4]](#jin003-u316-1-note)

<a id="jin003-u316-2-event"></a>

5. **郡国旱涝。** 四月，四郡国干旱，十郡国大水，居民房屋被毁。 [[5]](#jin003-u316-2-note)

<a id="jin003-u317-1-event"></a>
<a id="jin003-l317-event"></a>

6. **巴西地震。** 七月，巴西地震。 [[6]](#jin003-u317-1-note)

<a id="jin003-u318-1-event"></a>
<a id="jin003-l318-event"></a>

7. **八月朔日食。** 八月丙戌朔，发生日食。 [[7]](#jin003-u318-1-note)

<a id="jin003-u318-2-event"></a>

8. **减绵绢三分之一。** 八月，减百姓绵绢征收额三分之一。 [[8]](#jin003-u318-2-note)

<a id="jin003-u318-3-event"></a>

9. **京兆报白龙。** 八月，京兆报告白龙出现。 [[9]](#jin003-u318-3-note)

<a id="jin003-u318-4-event"></a>

10. **王濬任抚军大将军。** 八月，以镇军大将军王濬为抚军大将军。 [[10]](#jin003-u318-4-note)

<a id="hh-event-1"></a>

11. **山阳公刘康去世。** 九月丙子，山阳公刘康去世。 [[11]](#hh-note-1)

<a id="jin003-u320-1-event"></a>
<a id="jin003-l320-event"></a>

12. **南安山崩涌水。** 十月，南安山崩，有水涌出。 [[12]](#jin003-u320-1-note)

<a id="jin003-u320-2-event"></a>

13. **南阳获两足兽。** 十月，南阳郡捕获一只两足兽。 [[13]](#jin003-u320-2-note)

<a id="jin003-u320-3-event"></a>

14. **龟兹、焉耆遣子入侍。** 十月，龟兹、焉耆各遣子入侍。 [[14]](#jin003-u320-3-note)

<a id="jin003-u321-1-event"></a>
<a id="jin003-l321-event"></a>

15. **宣武观大阅十日。** 十二月甲申，在宣武观大阅，十日后结束。 [[15]](#jin003-u321-1-note)

<a id="jin003-u321-2-event"></a>

16. **王濬去世。** 十二月庚子，抚军大将军、襄阳侯王濬去世。 [[16]](#jin003-u321-2-note)

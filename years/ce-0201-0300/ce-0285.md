# 公元285年｜晋太康六年

[← 公元284年](ce-0284.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元287年 →](ce-0287.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **山阳公刘康去世。** 献帝之孙刘康袭爵，《武帝纪》记本年九月丙子去世。 [[1]](#hh-note-1)

<a id="jin003-l314-event"></a>

2. **免积欠及王浑等任官。** 正月甲申朔，因连年歉收，免租税、官贷积欠。戊辰，以王浑为尚书左仆射，褚䂮督扬州、杨济督荆州。本纪称王浑征南大将军，本传作征东；甲申朔到戊辰又不能同在正月，事实与官号、月日分开保存。 [[2]](#jin003-l314-note)

<a id="jin003-l315-event"></a>

3. **霜伤桑麦。** 三月，六郡国降霜，伤桑树、小麦。 [[3]](#jin003-l315-note)

<a id="jin003-l316-event"></a>

4. **诸国来献、参离归附及灾害。** 夏四月，扶南等十国来献，参离四千余落来附；四郡国旱、十郡国水灾，毁民房。各数是不同灾区或归附单位，不混作同一统计。 [[4]](#jin003-l316-note)

<a id="jin003-l317-event"></a>

5. **巴西地震。** 七月，巴西地震。 [[5]](#jin003-l317-note)

<a id="jin003-l318-event"></a>

6. **日食、减绵绢及王濬迁任。** 八月丙戌朔日食；减少百姓绵绢课三分之一；京兆报告白龙。以镇军大将军王濬为抚军大将军。 [[6]](#jin003-l318-note)

<a id="jin003-l320-event"></a>

7. **南安山崩、异兽及西域遣子。** 冬十月，南安山崩涌水；南阳获两足兽，种属未详。龟兹、焉耆遣子入侍。 [[7]](#jin003-l320-note)

<a id="jin003-l321-event"></a>

8. **阅军与王濬去世。** 十二月甲申，宣武观大阅，十日后结束。庚子，抚军大将军、襄阳侯王濬去世。 [[8]](#jin003-l321-note)

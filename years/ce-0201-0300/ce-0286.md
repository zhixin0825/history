## 晋廷与各地记事

<a id="jin003-l322-event"></a>

1. **日食后令大臣直言。** 正月甲寅朔日食。乙卯，诏说近年灾异屡发，岁首、月首、日始的日食及地震山崩，国家治理不善在于自己，命公卿大臣各上密封奏书，直陈原因、不要避讳。“日蚀三朝”指正旦三始，不译成三个朝代。 [[1]](#jin003-l322-note)

<a id="jin003-l323-event"></a>

2. **旱灾与慕容廆侵辽东。** 夏五月，十三郡国旱。鲜卑慕容廆侵辽东；与281、282年父子归名有争议的昌黎事件区别。 [[2]](#jin003-l323-note)

<a id="jin003-l324-event"></a>

3. **朱提山崩、犍为地震。** 秋七月，朱提山崩，犍为地震。 [[3]](#jin003-l324-note)

<a id="jin003-l325-event"></a>

4. **东夷来附与京兆地震。** 八月，东夷十一国来附；京兆地震。 [[4]](#jin003-l325-note)

<a id="jin003-l326-event"></a>

5. **司马骏去世与水灾。** 九月戊寅，骠骑将军、扶风王司马骏去世。八郡国大水。 [[5]](#jin003-l326-note)

<a id="jin003-l327-event"></a>

6. **司马泰督关中。** 冬十一月壬子，以陇西王司马泰都督关中军事。 [[6]](#jin003-l327-note)

<a id="jin003-l328-event"></a>

7. **巡水灾、遣宫人归家与终丧令。** 十二月，遣侍御史巡察遭水灾诸郡；放后宫才人、妓女以下二百七十人归家，诸书人数尚有异记。开始规定大臣可终三年之丧。己亥，河阴降红雪，面积二顷。终丧规定与267年二千石、士卒的规定对象不同，不删去其中一条作重复。 [[7]](#jin003-l328-note)

<a id="jin003-l329-event"></a>

8. **全年外使。** 本年扶南等二十一国、马韩等十一国遣使献物，不把“等”后的各组国数简单视为没有交叠的总国数。 [[8]](#jin003-l329-note)

## 本年概述

元旦日食后，司马炎命公卿密奏直言。年内旱涝、山崩、地震相继，慕容廆侵辽东；朝廷巡察水灾、遣宫人归家，并准大臣终丧。


<a id="jin003-u322-1-event"></a>
<a id="jin003-l322-event"></a>

1. **日食后令大臣直言。** 正月甲寅朔，发生日食。翌日乙卯，司马炎因近年灾异屡发、日食当正旦三始，又有地震山崩，自责治理不善，命公卿大臣各上密封奏书，直陈原因，不要避讳。 [[1]](#jin003-u322-1-note)

<a id="jin003-u323-1-event"></a>
<a id="jin003-l323-event"></a>

2. **十三郡国旱。** 五月，十三郡国干旱。 [[2]](#jin003-u323-1-note)

<a id="jin003-u323-2-event"></a>

3. **慕容廆侵辽东。** 五月，鲜卑慕容廆进犯辽东。 [[3]](#jin003-u323-2-note)

<a id="jin003-u324-1-event"></a>
<a id="jin003-l324-event"></a>

4. **朱提山崩、犍为地震。** 七月，朱提山崩，犍为地震。 [[4]](#jin003-u324-1-note)

<a id="jin003-u325-1-event"></a>
<a id="jin003-l325-event"></a>

5. **东夷十一国归附。** 八月，东夷十一国归附。 [[5]](#jin003-u325-1-note)

<a id="jin003-u325-2-event"></a>

6. **京兆地震。** 八月，京兆地震。 [[6]](#jin003-u325-2-note)

<a id="jin003-u326-1-event"></a>
<a id="jin003-l326-event"></a>

7. **司马骏去世。** 九月戊寅，骠骑将军、扶风王司马骏去世。 [[7]](#jin003-u326-1-note)

<a id="jin003-u326-2-event"></a>

8. **八郡国大水。** 九月，八郡国大水。 [[8]](#jin003-u326-2-note)

<a id="jin003-u327-1-event"></a>
<a id="jin003-l327-event"></a>

9. **司马泰督关中。** 十一月壬子，以陇西王司马泰都督关中诸军。 [[9]](#jin003-u327-1-note)

<a id="jin003-u328-1-event"></a>
<a id="jin003-l328-event"></a>

10. **侍御史巡水灾诸郡。** 十二月，遣侍御史巡察遭水灾的各郡。 [[10]](#jin003-u328-1-note)

<a id="jin003-u328-2-event"></a>

11. **遣宫人二百七十人归家。** 十二月，遣后宫才人、女乐等二百七十人归家。 [[11]](#jin003-u328-2-note)

<a id="jin003-u328-3-event"></a>

12. **准大臣终三年丧。** 十二月，开始规定大臣可居满三年之丧。 [[12]](#jin003-u328-3-note)

<a id="jin003-u328-4-event"></a>

13. **河阴降红雪。** 十二月己亥，河阴降红雪，覆盖二顷。 [[13]](#jin003-u328-4-note)

<a id="jin003-u329-1-event"></a>
<a id="jin003-l329-event"></a>

14. **全年外使。** 本年，扶南等二十一国、马韩等十一国遣使来献。 [[14]](#jin003-u329-1-note)

### 1. 日食后令大臣直言

[返回正文第1条](#jin003-u322-1-event)

<a id="jin003-l322"></a>
<a id="jin003-l322-note"></a>

<a id="jin003-u322-1"></a>

**《晋书·武帝纪》太康7年正月，L322（原文）** · [原文1](../../拆分史书/晋书/卷003.md#edition-jin003-l322-1) · [原文2](../../拆分史书/晋书/卷003.md#edition-jin003-l322-2)

> 七年春正月甲寅朔，日有蝕之。乙卯，詔曰：「比年災異屢發，日蝕三朝，地震山崩。邦之不臧，實在朕躬。公卿大臣各上封事，極言其故，勿有所諱。」

**释读与归年** “三朝”指岁首、月首、日始三始，并非三个朝代；诏书灾异归责为当时政治思想。

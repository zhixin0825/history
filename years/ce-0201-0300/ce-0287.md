# 公元287年｜西晋太康八年

[← 公元285年](ce-0285.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元288年 →](ce-0288.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="ce287-event-1"></a>

1. **王范进呈《交广二州春秋》。** 广州大中正王范进呈记述交州和广州的《交广二州春秋》。 [[1]](#ce287-note-1)

<a id="jin003-l330-event"></a>

2. **日食与太庙殿陷。** 正月戊申朔日食，太庙殿陷落。 [[2]](#jin003-l330-note)

<a id="jin003-l331-event"></a>

3. **临商观震动。** 三月乙丑，临商观震动；原书用“震”，不无据扩写为整座建筑被雷电摧毁。 [[3]](#jin003-l331-note)

<a id="jin003-l332-event"></a>

4. **齐国天水霜害。** 夏四月，齐国、天水降霜，伤麦。固定底本已作天水，斠注所据“大水”的本子有校说，不再把底本改回讹字。 [[4]](#jin003-l332-note)

<a id="jin003-l333-event"></a>

5. **鲁国风灾与郡国水灾。** 六月，鲁国大风拔树、毁民房，八郡国大水。 [[5]](#jin003-l333-note)

<a id="jin003-l334-event"></a>

6. **前殿地陷与破船。** 秋七月，前殿地面陷落数丈深，其中发现破船。本纪只记这一现象，不臆造船的年代与来源。 [[6]](#jin003-l334-note)

<a id="jin003-l335-event"></a>

7. **东夷二国来附。** 八月，东夷二国归附。 [[7]](#jin003-l335-note)

<a id="jin003-l336-event"></a>

8. **改建太庙。** 九月，重新营建太庙，与289年完成新庙分记。 [[8]](#jin003-l336-note)

<a id="jin003-l337-event"></a>

9. **李丰起兵。** 冬十月，南康平固县吏李丰聚众攻郡县，自号将军。此人与254年被杀的魏中书令李丰不是同一人。 [[9]](#jin003-l337-note)

<a id="jin003-l338-event"></a>

10. **萧辅起兵。** 十一月，海安县令萧辅聚众起兵。 [[10]](#jin003-l338-note)

<a id="jin003-l339-event"></a>

11. **蒋迪围阳羡与外使。** 十二月，吴兴蒋迪聚众围阳羡，州郡捕讨；本纪接前文说起兵者均被诛。扶南、康居各遣使来献。 [[11]](#jin003-l339-note)

<a id="jin003-l340-event"></a>

12. **全年地震汇总的差别。** 本纪汇称本年五郡国地震；校家对照《五行志》只核得其中三次，保留记录范围与计数分歧，不补造缺失的两个地名。 [[12]](#jin003-l340-note)

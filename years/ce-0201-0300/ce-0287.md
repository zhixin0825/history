## 本年概述

太庙殿陷后，朝廷重新营建太庙。李丰、萧辅、蒋迪先后起兵，州郡出兵捕讨；各地又有风水霜震等灾害。


<a id="jin003-u330-1-event"></a>
<a id="jin003-l330-event"></a>

1. **元旦日食。** 正月戊申朔，发生日食。 [[1]](#jin003-u330-1-note)

<a id="jin003-u330-2-event"></a>

2. **太庙殿陷。** 正月，太庙殿下陷。 [[2]](#jin003-u330-2-note)

<a id="jin003-u331-1-event"></a>
<a id="jin003-l331-event"></a>

3. **临商观震动。** 三月乙丑，临商观震动。 [[3]](#jin003-u331-1-note)

<a id="jin003-u332-1-event"></a>
<a id="jin003-l332-event"></a>

4. **齐国天水霜害。** 四月，齐国、天水降霜，伤麦。 [[4]](#jin003-u332-1-note)

<a id="jin003-u333-1-event"></a>
<a id="jin003-l333-event"></a>

5. **鲁国大风。** 六月，鲁国大风，拔树、毁民房。 [[5]](#jin003-u333-1-note)

<a id="jin003-u333-2-event"></a>

6. **八郡国大水。** 六月，八郡国大水。 [[6]](#jin003-u333-2-note)

<a id="jin003-u334-1-event"></a>
<a id="jin003-l334-event"></a>

7. **前殿地陷与破船。** 七月，前殿地面陷落数丈深，里面发现一艘破船。 [[7]](#jin003-u334-1-note)

<a id="jin003-u335-1-event"></a>
<a id="jin003-l335-event"></a>

8. **东夷二国来附。** 八月，东夷二国归附。 [[8]](#jin003-u335-1-note)

<a id="jin003-u336-1-event"></a>
<a id="jin003-l336-event"></a>

9. **改建太庙。** 九月，重新营建太庙。 [[9]](#jin003-u336-1-note)

<a id="jin003-u337-1-event"></a>
<a id="jin003-l337-event"></a>

10. **李丰起兵。** 十月，南康平固县吏李丰聚众攻郡县，自号将军。 [[10]](#jin003-u337-1-note)

<a id="jin003-u338-1-event"></a>
<a id="jin003-l338-event"></a>

11. **萧辅起兵。** 十一月，海安县令萧辅聚众起兵。 [[11]](#jin003-u338-1-note)

<a id="jin003-u339-1-event"></a>
<a id="jin003-l339-event"></a>

12. **蒋迪围阳羡，州郡讨平。** 十二月，吴兴人蒋迪聚众围阳羡，州郡捕讨，起事者均被诛。 [[12]](#jin003-u339-1-note)

<a id="jin003-u339-2-event"></a>

13. **扶南、康居来献。** 十二月，扶南、康居各遣使来献。 [[13]](#jin003-u339-2-note)

<a id="jin003-u340-1-event"></a>
<a id="jin003-l340-event"></a>

14. **全年地震汇总的差别。** 本年，五郡国发生地震。 [[14]](#jin003-u340-1-note)

<a id="ce287-event-1"></a>

15. **王范进呈《交广二州春秋》。** 广州大中正王范进呈记述交州和广州的《交广二州春秋》。 [[15]](#ce287-note-1)

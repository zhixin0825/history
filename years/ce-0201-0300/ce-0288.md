# 公元288年｜西晋太康九年

[← 公元287年](ce-0287.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元289年 →](ce-0289.md)

[本年相关史料](#sources-start)

<a id="sgz-event-1"></a>

1. **曹志去世，谥定公。** 曹志此前居母丧过哀，生病后喜怒失常。本年去世，朝廷听从崔褒之议，谥定公。 [[1]](#sgz-note-1)

<a id="jin003-l341-event"></a>

2. **正旦日食、纠吏诏与江东地震。** 正月壬申朔日食。诏说教化根本在政平讼理，指责二千石和长吏不恤民隐，挟私扩大刑狱、贪污扰民；命刺史、二千石纠劾污吏、荐公清者，由有司议升黜，内外举清能、拔寒素。江东四郡地震；志所列地区数量有异，不把本纪汇数当作无争议统计。 [[2]](#jin003-l341-note)

<a id="jin003-l342-event"></a>

3. **胡奋卒、朱整任仆射。** 二月，尚书右仆射、阳夏侯胡奋去世；以尚书朱整继任右仆射。 [[3]](#jin003-l342-note)

<a id="jin003-l343-event"></a>

4. **皇后亲桑与合二社。** 三月丁丑，皇后在西郊亲行蚕桑礼，分等赐帛。壬辰，开始将两社合为一社；与翌年恢复二社分记。 [[4]](#jin003-l343-note)

<a id="jin003-l344-event"></a>

5. **江南地震、陇西霜害。** 夏四月，江南八郡国地震；陇西降霜，伤越冬小麦。 [[5]](#jin003-l344-note)

<a id="jin003-l345-event"></a>

6. **司马奇降爵与举守令。** 五月，义阳王司马奇因罪降三纵亭侯。命内外群臣荐举可任郡守、县令的人。 [[6]](#jin003-l345-note)

<a id="jin003-l346-event"></a>

7. **日食、徙封与旱灾。** 六月庚子朔日食，章武王司马威徙封义阳王。三十二郡国大旱、伤麦；《五行志》汇数作三十三，并另列伤麦地区，不把各区域一概认作损失相同。 [[7]](#jin003-l346-note)

<a id="jin003-l347-event"></a>

8. **流星与决遣轻刑囚。** 秋八月壬子，星坠如雨。诏各郡国决遣五年刑以下案件，不使庶狱长期滞留。 [[8]](#jin003-l347-note)

<a id="jin003-l348-event"></a>

9. **东夷归附与螟灾。** 九月，东夷七国赴校尉处归附；二十四郡国有螟害。 [[9]](#jin003-l348-note)

<a id="jin003-l349-event"></a>

10. **章武王嗣封与龙瑞。** 十二月癸卯，立河间平王司马洪之子英为章武王。戊申，鲁国报告青龙、黄龙各一。司马洪传所记子名为威、混，且同族另有英，校家疑本纪“英”字有误；不默定唯一姓名。 [[10]](#jin003-l349-note)

### 1. 曹志去世，谥定公

[返回正文第1条](#sgz-event-1)

<a id="wei019-l98-8"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l98-8)** · [TXT L98](../../拆分史书/三国志/卷019.txt#L98)

> 志遭母憂，居喪盡哀，因得疾病，喜怒失常，太康九年卒，謚曰定公。

**釋讀與歸年** 曹志為母服喪過哀，因而患病，喜怒失常。太康九年卒，諡定公。[《晉書·曹志傳》](../../史书/005-晋书/晋书-CCDH.txt#L5914)記太常曾擬惡諡，崔褒反對以病況定諡，遂諡定。母卒與得病是卒年之前的經過。

<a id="sgz019-p-020-10"></a>

[本卷同事原句](#wei019-l98-8)。

**归年** 《曹志别传》明太康九年，《晋书·曹志传》同。

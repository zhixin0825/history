## 本年概述

晋诏察污吏、举清能寒素，皇后亲桑，二社合一。胡奋去世，朱整继任；多地大旱、地震与螟害，朝廷催决久狱。


<a id="jin003-u341-1-event"></a>
<a id="jin003-l341-event"></a>

1. **元旦日食。** 正月壬申朔，发生日食。 [[1]](#jin003-u341-1-note)

<a id="jin003-u341-2-event"></a>

2. **诏察污吏、举清能寒素。** 正月，司马炎说教化根本在政平讼理，责二千石和长吏不恤民隐，挟私扩大刑狱，又贪污扰民；命刺史、二千石纠劾污吏、荐公清者，由有司议升黜，并令内外群臣举清能、拔寒素。 [[2]](#jin003-u341-2-note)

<a id="jin003-u341-3-event"></a>

3. **江东四郡地震。** 正月，江东四郡地震。 [[3]](#jin003-u341-3-note)

<a id="jin003-u342-1-event"></a>
<a id="jin003-l342-event"></a>

4. **胡奋卒、朱整任仆射。** 二月，尚书右仆射、阳夏侯胡奋去世，以尚书朱整继任右仆射。 [[4]](#jin003-u342-1-note)

<a id="jin003-u343-1-event"></a>
<a id="jin003-l343-event"></a>

5. **皇后亲桑。** 三月丁丑，皇后在西郊亲行蚕桑礼，分等赐帛。 [[5]](#jin003-u343-1-note)

<a id="jin003-u343-2-event"></a>

6. **两社合一。** 三月壬辰，开始将天子社、太社合为一社。 [[6]](#jin003-u343-2-note)

<a id="jin003-u344-1-event"></a>
<a id="jin003-l344-event"></a>

7. **江南地震、陇西霜害。** 四月，江南八郡国地震；陇西降霜，伤越冬小麦。 [[7]](#jin003-u344-1-note)

<a id="jin003-u345-1-event"></a>
<a id="jin003-l345-event"></a>

8. **司马奇降亭侯。** 五月，义阳王司马奇因罪被降为三纵亭侯。 [[8]](#jin003-u345-1-note)

<a id="jin003-u345-2-event"></a>

9. **举守令人才。** 五月，命内外群臣荐举可任郡守、县令的人。 [[9]](#jin003-u345-2-note)

<a id="jin003-u346-1-event"></a>
<a id="jin003-l346-event"></a>

10. **六月朔日食。** 六月庚子朔，发生日食。 [[10]](#jin003-u346-1-note)

<a id="jin003-u346-2-event"></a>

11. **司马威徙义阳王。** 六月，章武王司马威改封义阳王。 [[11]](#jin003-u346-2-note)

<a id="jin003-u346-3-event"></a>

12. **三十二郡国大旱。** 六月，三十二郡国大旱，伤麦。 [[12]](#jin003-u346-3-note)

<a id="jin003-u347-1-event"></a>
<a id="jin003-l347-event"></a>

13. **星坠如雨。** 八月壬子，星坠如雨。 [[13]](#jin003-u347-1-note)

<a id="jin003-u347-2-event"></a>

14. **决遣五岁刑以下狱案。** 八月，命郡国尽快审结、遣放五年刑以下案件，不让众狱长期滞留。 [[14]](#jin003-u347-2-note)

<a id="jin003-u348-1-event"></a>
<a id="jin003-l348-event"></a>

15. **东夷七国赴校尉归附。** 九月，东夷七国到校尉处归附。 [[15]](#jin003-u348-1-note)

<a id="jin003-u348-2-event"></a>

16. **二十四郡国螟害。** 九月，二十四郡国发生螟害。 [[16]](#jin003-u348-2-note)

<a id="jin003-u349-1-event"></a>
<a id="jin003-l349-event"></a>

17. **司马洪之子封章武王。** 十二月癸卯，立河间平王司马洪之子为章武王。 [[17]](#jin003-u349-1-note)

<a id="jin003-u349-2-event"></a>

18. **鲁国报青龙、黄龙。** 十二月戊申，鲁国报告青龙、黄龙各一次。 [[18]](#jin003-u349-2-note)

<a id="sgz-event-1"></a>

19. **曹志去世，谥定公。** 曹志此前居母丧过哀，生病后喜怒失常。本年去世，朝廷听从崔褒之议，谥定公。 [[19]](#sgz-note-1)

### 2. 诏察污吏、举清能寒素

[返回正文第2条](#jin003-u341-2-event)

<a id="jin003-u341-2"></a>

**《晋书·武帝纪》太康9年正月，L341（原文）** · [原文1](../../拆分史书/晋书/卷003.md#edition-jin003-l341-2)

> 詔曰：「興化之本，由政平訟理也。二千石長吏不能勤恤人隱，而輕挾私故，興長刑獄，又多貪濁，煩撓百姓。其敕刺史二千石糾其穢濁，舉其公清，有司議其黜陟。令內外群官舉清能，拔寒素。」

**释读与归年** “寒素”指家世寒微、素无显位者，不是只荐无家产之人。

### 19. 曹志去世，谥定公

[返回正文第19条](#sgz-event-1)

<a id="wei019-l98-8"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l98-8)** · [TXT L98](../../拆分史书/三国志/卷019.txt#L98)

> 志遭母憂，居喪盡哀，因得疾病，喜怒失常，太康九年卒，謚曰定公。

**釋讀與歸年** 曹志為母服喪過哀，因而患病，喜怒失常。太康九年卒，諡定公。[《晉書·曹志傳》](../../史书/005-晋书/晋书-CCDH.txt#L5914)記太常曾擬惡諡，崔褒反對以病況定諡，遂諡定。母卒與得病是卒年之前的經過。

[本卷同事原句](#wei019-l98-8)。

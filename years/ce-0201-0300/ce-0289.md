## 本年概述

太庙建成，迁神主并祫祭，朝廷大赦、增位，恢复二社。司马炎病愈，调整宗室封爵与出镇，司马亮任大司马；荀勖等去世。


<a id="jin003-u350-1-event"></a>
<a id="jin003-l350-event"></a>

1. **刘霄、梁柳以政绩获赐。** 四月，京兆太守刘霄、阳平太守梁柳因有政绩，各赐谷一千斛。 [[1]](#jin003-u350-1-note)

<a id="jin003-u350-2-event"></a>

2. **八郡国降霜。** 四月，八郡国降霜。 [[2]](#jin003-u350-2-note)

<a id="jin003-u350-3-event"></a>

3. **太庙完成，迁神主并祫祭。** 四月，太庙建成。乙巳，迁神主入新庙，司马炎在路左迎接，随后合祭祖先。大赦，文武增位一等，造庙者二等。 [[3]](#jin003-u350-3-note)

<a id="jin003-u350-6-event"></a>

4. **朱整去世。** 四月丁未，尚书右仆射、广兴侯朱整去世。 [[4]](#jin003-u350-6-note)

<a id="jin003-u350-7-event"></a>

5. **崇贤殿火灾。** 四月癸丑，崇贤殿发生火灾。 [[5]](#jin003-u350-7-note)

<a id="jin003-u351-1-event"></a>
<a id="jin003-l351-event"></a>

6. **慕容廆归降与外附。** 五月，鲜卑慕容廆来降，东夷十一国归附。 [[6]](#jin003-u351-1-note)

<a id="hh-event-1"></a>

7. **刘瑾去世。** 六月庚子，山阳公刘瑾去世。 [[7]](#hh-note-1)

<a id="jin003-u352-2-event"></a>

8. **恢复二社。** 六月，恢复天子社、太社两社。 [[8]](#jin003-u352-2-note)

<a id="jin003-u353-1-event"></a>
<a id="jin003-l353-event"></a>

9. **司马承徙封。** 十月壬子，南宫王司马承改封武邑王。 [[9]](#jin003-u353-1-note)

<a id="jin003-u354-1-event"></a>
<a id="jin003-l354-event"></a>

10. **荀勖去世。** 十一月丙辰，守尚书令、左光禄大夫荀勖去世。 [[10]](#jin003-u354-1-note)

<a id="jin003-u354-2-event"></a>

11. **病愈赐帛。** 十一月，司马炎病愈，按等差赐王公以下帛。 [[11]](#jin003-u354-2-note)

<a id="jin003-u354-3-event"></a>

12. **含章殿鞠室火灾。** 十一月，含章殿鞠室失火。 [[12]](#jin003-u354-3-note)

<a id="jin003-u355-1-event"></a>
<a id="jin003-l355-event"></a>

13. **司马亮任大司马。** 十一月甲申，以汝南王司马亮为大司马、大都督，假黄钺。 [[13]](#jin003-u355-1-note)

<a id="jin003-u355-2-event"></a>

14. **司马柬、玮、允出镇。** 十一月，司马柬由南阳王改秦王，司马玮由始平王改楚王，司马允由濮阳王改淮南王，均持节赴封国，各统方州军事。 [[14]](#jin003-u355-2-note)

<a id="jin003-u355-3-event"></a>

15. **封诸皇子及宗室。** 十一月，封皇子司马乂为长沙王、颖为成都王、晏为吴王、炽为豫章王、演为代王，皇孙司马遹为广陵王；濮阳王之子迪为汉王、始平王之子仪为毗陵王、汝南王次子羕为西阳公。扶风王司马畅徙顺阳王，畅弟歆封新野公；琅邪王司马觐之弟澹封东武公、繇东安公、漼广陵公、卷东莞公。 [[15]](#jin003-u355-3-note)

<a id="jin003-u355-6-event"></a>

16. **王国相改内史。** 十一月，将诸王国相改称内史。 [[16]](#jin003-u355-6-note)

<a id="jin003-u356-1-event"></a>
<a id="jin003-l356-event"></a>

17. **太庙梁折的月次争议。** 十一月，太庙梁折。 [[17]](#jin003-u356-1-note)

<a id="jin003-u357-1-event"></a>
<a id="jin003-l357-event"></a>

18. **远方诸国来献。** 本年，远方东夷三十余国、西南夷二十余国来献。 [[18]](#jin003-u357-1-note)

<a id="jin003-u357-2-event"></a>

19. **奚轲部归降。** 本年，奚轲部男女十万人来降。 [[19]](#jin003-u357-2-note)

> 立皇子乂爲長沙王，穎爲成都王，晏爲吳王，熾爲豫章王，演爲代王，皇孫遹爲廣陵王。立濮陽王子迪爲漢王，始平王子儀爲毗陵王，汝南王次子羕爲西陽公。徙扶風王暢爲順陽王，暢弟歆爲新野公，琅邪王覲弟澹爲東武公，繇爲東安公，漼爲廣陵公，卷爲東莞公。

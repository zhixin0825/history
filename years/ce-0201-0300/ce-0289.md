# 公元289年｜晋太康十年

[← 公元288年](ce-0288.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元290年 →](ce-0290.md)

<a id="reading-start"></a>

[本年相关史料](#sources-start)

<a id="hh-event-1"></a>

1. **山阳公刘瑾去世。** 刘瑾继承山阳公，《武帝纪》记本年六月庚子去世。同段又记恢复天子社与太社两社，承接[288年合社](ce-0288.md#jin003-l343)的制度变化。 [[1]](#hh-note-1)

<a id="jin003-l350-event"></a>

2. **太庙成、赏官与朱整卒。** 夏四月，以京兆太守刘霄、阳平太守梁柳有政绩，各赐谷千斛；八郡国降霜。太庙建成，乙巳迁神主入新庙，皇帝在路左迎接，合祭祖先；大赦，文武增位一等、造庙者二等。丁未，尚书右仆射、广兴侯朱整去世。癸丑，崇贤殿火灾。 [[2]](#jin003-l350-note)

<a id="jin003-l351-event"></a>

3. **慕容廆归降与外附。** 五月，慕容廆来降；东夷十一国归附。 [[3]](#jin003-l351-note)

<a id="jin003-l353-event"></a>

4. **司马承徙封。** 冬十月壬子，南宫王司马承徙封武邑王。 [[4]](#jin003-l353-note)

<a id="jin003-l354-event"></a>

5. **荀勖卒、皇帝病愈与宫火。** 十一月丙辰，代理尚书令、左光禄大夫荀勖去世。司马炎病愈，按等赐王公以下帛。含章殿球室失火，此火在《五行志》等记月有异，不改作另一场已证实的火灾。 [[5]](#jin003-l354-note)

<a id="jin003-l355-event"></a>

6. **宗王分镇与王国官名。** 甲申，以司马亮为大司马、大都督，假黄钺。改司马柬为秦王、玮为楚王、允为淮南王，都持节赴封国、掌地方军务；封皇子乂长沙王、颖成都王、晏吴王、炽豫章王、演代王，皇孙遹广陵王。又封濮阳王之子迪汉王、始平王之子仪毗陵王、汝南王次子羕西阳公；徙司马畅顺阳王，封其弟歆新野公，司马觐之弟澹东武公、繇东安公、漼广陵公、卷东莞公。把诸王国相改称内史。封爵、出镇与末年辅政谋议相关，但不擅把所有商议也定在这一日。 [[6]](#jin003-l355-note)

<a id="jin003-l356-event"></a>

7. **太庙梁折的月次争议。** 本纪记十二月庚寅太庙梁折；《通典》所引孙平子封事及干支推校支持十一月。正文保留梁折在本年的结论，月次并列，原文不改。 [[7]](#jin003-l356-note)

<a id="jin003-l357-event"></a>

8. **全年外使与奚轲归附。** 本年极远的东夷三十余国、西南夷二十余国来献，奚轲部男女十万人来降。人数依本纪汇报，不据数字制造逐年迁入名单。 [[8]](#jin003-l357-note)

# 公元290年｜西晋太熙元年／永熙元年

1. **石伟太熙元年去世。** 石伟享年八十三。 [[1]](#sgz-note-1)

<a id="sgz-event-2"></a>

2. **晋惠帝即位任韩寿为散骑常侍。** 惠帝即位，韩寿任近侍。 [[2]](#sgz-note-2)

<a id="sgz-event-3"></a>

3. **晋立愍怀太子，以和峤为少保。** 晋惠帝立司马遹为皇太子，为他选任师傅，以和峤为太子少保，兼散骑常侍。 [[3]](#sgz-note-3)

## 晋廷任命

<a id="wei027-event-l66-3"></a>

4. **晋任王浑为司徒。** 正月己巳，西晋任尚书左仆射王浑为司徒，同日升司空卫瓘为太保。 [[4]](#wei027-wanghun-situ)

<a id="jin003-l358a-event"></a>

5. **改元太熙。** 正月辛酉朔，改元太熙，不能因惠帝后来改永熙而把本年年号混为一个。 [[5]](#jin003-l358a-note)

<a id="jin003-l359-event"></a>

6. **东夷来贡与司马觐卒。** 二月辛丑，东夷七国朝贡；琅邪王司马觐去世。 [[6]](#jin003-l359-note)

<a id="jin003-l360-event"></a>

7. **石鉴任司空。** 三月甲子，以右光禄大夫石鉴为司空。 [[7]](#jin003-l360-note)

<a id="jin003-l361-event"></a>

8. **杨骏任辅臣、武帝卒葬。** 夏四月辛丑，以侍中、车骑将军杨骏为太尉，都督中外军事，录尚书事。己酉，司马炎在含章殿去世，年五十五，葬峻阳陵，庙号世祖。卒与葬是两项仪节，本纪此句没另列葬日；天文志另有庚申、乙酉等讹异，不把它们合成同一天的共同记载。 本纪记司马炎临终病重，开国元勋多已死，群臣惶惑；稍愈时曾下诏命司马亮辅政，还想选数名有名望的年轻朝士佐之，杨骏却隐而不宣。皇帝再度神志不清，杨皇后自行为诏使杨骏辅政，催司马亮出发；皇帝短暂清醒后问司马亮到否，想见他付托，左右说未到，随后病势再重。史臣把中朝动乱之始归于此，这是对临终安排的史源叙述与归责，不能与正式任杨骏的本纪条抹成同一份无异议遗诏。 [[8]](#jin003-l361-note)

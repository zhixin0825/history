## 本年概述

晋改元太熙，王浑、卫瓘、石鉴等迁三公。司马炎病重，杨骏掌辅政，四月武帝去世；临终安排及身后称号与史臣追叙在同号史料中分读。

<a id="晋廷任命"></a>

<a id="jin003-u358-1-event"></a>
<a id="jin003-l358a-event"></a>

1. **改元太熙。** 正月辛酉朔，改元太熙。 [[1]](#jin003-u358-1-note)

<a id="wei027-event-l66-3"></a>

2. **王浑司徒、卫瓘太保。** 正月己巳，以尚书左仆射王浑为司徒、司空卫瓘为太保。 [[2]](#wei027-wanghun-situ)

<a id="jin003-u359-1-event"></a>
<a id="jin003-l359-event"></a>

3. **东夷七国朝贡。** 二月辛丑，东夷七国朝贡。 [[3]](#jin003-u359-1-note)

<a id="jin003-u359-2-event"></a>

4. **司马觐去世。** 二月，琅邪王司马觐去世。 [[4]](#jin003-u359-2-note)

<a id="jin003-u360-1-event"></a>
<a id="jin003-l360-event"></a>

5. **石鉴任司空。** 三月甲子，以右光禄大夫石鉴为司空。 [[5]](#jin003-u360-1-note)

<a id="jin003-u361-1-event"></a>
<a id="jin003-l361-event"></a>
<a id="jin003-l363e-event"></a>

6. **武帝病重，杨骏专辅政。** 四月辛丑，任侍中、车骑将军杨骏为太尉，都督中外诸军，录尚书事。司马炎此时病重，开国元勋多已先死，群臣惶惑。他稍愈时曾下诏命汝南王司马亮辅政，还想选数名有名望的年轻朝士辅佐，杨骏却隐而不宣。皇帝再度神志不清，杨皇后自为诏令，使杨骏辅政，催司马亮离开。司马炎短暂清醒后又问司马亮是否已到，想见他付托，左右答未到，随后病势转重。 [[6]](#jin003-u361-1-note)

<a id="jin003-u361-2-event"></a>

7. **司马炎去世，葬峻阳陵。** 四月己酉，司马炎在含章殿去世，年五十五。后来葬峻阳陵，庙号世祖。 [[7]](#jin003-u361-2-note)

<a id="sgz-event-1"></a>

8. **石伟太熙元年去世。** 石伟享年八十三。 [[8]](#sgz-note-1)

<a id="sgz-event-2"></a>

9. **晋惠帝即位任韩寿为散骑常侍。** 惠帝即位，韩寿任近侍。 [[9]](#sgz-note-2)

<a id="sgz-event-3"></a>

10. **晋立愍怀太子，以和峤为少保。** 晋惠帝立司马遹为皇太子，为他选任师傅，以和峤为太子少保，兼散骑常侍。 [[10]](#sgz-note-3)

**《晋书·武帝纪》太熙元年四月，L361（节引）** · [原文1](../../拆分史书/晋书/卷003.md#edition-jin003-l361-1)

> 夏四月辛丑，以侍中車騎將軍楊駿爲太尉、都督中外諸軍、錄尚書事。

**《晋书·武帝纪》太熙元年四月，L363（节引）** · [原文1](../../拆分史书/晋书/卷003.md#edition-jin003-l363-13) · [原文2](../../拆分史书/晋书/卷003.md#edition-jin003-l363-14) · [原文3](../../拆分史书/晋书/卷003.md#edition-jin003-l363-15) · [原文4](../../拆分史书/晋书/卷003.md#edition-jin003-l363-16) · [原文5](../../拆分史书/晋书/卷003.md#edition-jin003-l363-17) · [原文6](../../拆分史书/晋书/卷003.md#edition-jin003-l363-18)

> 既而寢疾彌留，至於大漸，佐命元勳，皆已先沒，群臣惶惑，計無所從。會帝小差，有詔以汝南王亮輔政，又欲令朝士之有名望年少者數人佐之，楊駿祕而不宣。帝復尋至迷亂，楊後輒爲詔以駿輔政，促亮進發。帝尋小間，問汝南王來未，意欲見之，有所付託。左右答言未至，帝遂困篤。中朝之亂，實始於斯矣。

**释读与归年** 任杨骏为本纪四月正式记事；其后五句为卷末追叙的病榻安排，无各自独立日。史臣“中朝之乱，实始于斯”是对辅政安排的归责，不抹成一份各方无异议的遗诏。

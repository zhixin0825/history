# 公元291年｜西晋元康元年

[← 公元290年](ce-0290.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元292年 →](ce-0292.md)

[本年相关史料](#sources-start)

<a id="sgz-event-1"></a>

1. **杨骏被诛，同案李斌、张劭、武茂遇害。** 晋惠帝元康元年三月诛杨骏，与杨骏有亲的河南尹李斌、中护军张劭和侍中尚书武茂同遭杀害。武茂从前拒与荀恺结交，荀恺借这次清查把他列作杨骏党羽，时人认为武茂死得冤枉。 [[1]](#sgz-note-1)

<a id="sgz-event-2"></a>

2. **贾后借楚王司马玮之手杀卫瓘、司马亮。** 杨骏伏诛后，卫瓘与汝南王司马亮共同辅政。卫瓘支持司马亮遣诸王归藩，楚王司马玮因而怀恨。六月，贾后命司马玮收治二人，卫瓘与儿孙一同遇害。朝廷随后以擅杀卫瓘、司马亮为由诛司马玮。 [[2]](#sgz-note-2)

<a id="sgz-event-3"></a>

3. **司马亮辅政任卫权，傅咸劝勿越资任用。** 卫权是贵妃的兄子；傅咸说虽有文才可为郎，却尚未历东宫职，过去杨骏用亲已遭非议，应免众人效尤。 [[3]](#sgz-note-3)

<a id="sgz-event-4"></a>

4. **晋廷授卢浮秘书监，卢浮未就。** 永平年间，朝廷授卢浮为秘书监。他先前因病废职，这次也未赴任。 [[4]](#sgz-note-4)

## 本年相关史料

<a id="sgz-note-1"></a>

### 1. 杨骏被诛，同案李斌、张劭、武茂遇害

[返回正文第1条](#sgz-event-1)

<a id="wei027-l24-5"></a>

**[《三國志·徐胡二王傳》裴注](../../拆分史书/三国志/卷027.md#edition-wei027-l24-5)** · [TXT L24](../../拆分史书/三国志/卷027.txt#L24)

> 元康元年，楊駿被誅。愷時爲尚書僕射，以茂駿之姨弟，陷爲駿黨，遂枉見殺，衆咸冤痛之。

**釋讀與歸年** 元康元年三月，楊駿被誅。荀愷因為武茂是楊駿的姨弟，誣為其黨，武茂遇害，時人稱冤。[《晉書·惠帝紀》](../../史书/005-晋书/晋书-CCDH.txt#L371-L373)、[《武陔傳》](../../史书/005-晋书/晋书-CCDH.txt#L5632-L5635)均有旁證。

<a id="wei011-l31-2"></a>

**[《三國志·袁張涼國田王邴管傳》裴注](../../拆分史书/三国志/卷011.md#edition-wei011-l31-2)** · [TXT L31](../../拆分史书/三国志/卷011.txt#L31)

> 承孫邵，晉中護軍，與舅楊駿俱被誅。事見晉書。

**釋讀與歸年** 张承孙张邵仕晋为中护军，与舅父杨骏一同被诛。《晋书》作「張劭」，载元康元年三月辛卯。[《晋书·惠帝纪》](../../史书/005-晋书/晋书-CCDH.txt#L373)

<a id="wei009-l185-14"></a>

**[《三國志·諸夏侯曹傳》裴注](../../拆分史书/三国志/卷009.md#edition-wei009-l185-14)** · [TXT L185](../../拆分史书/三国志/卷009.txt#L185)

> 翼子斌，楊駿外甥也。晉惠帝初，爲河南尹，與駿俱死，見晉書。

**釋讀與歸年** 李翼之子李斌是杨骏外甥，任河南尹，与杨骏同被诛。[《晋书·惠帝纪》](../../史书/005-晋书/晋书-CCDH.txt#L373)明记元康元年三月辛卯。

<a id="sgz009-p-043-14"></a>

[本卷同事原句](#wei009-l185-14)。

**归年** 《晋书·惠帝纪》元康元年三月诛杨骏，注末言俱死；河南尹任命无确日。

<a id="sgz011-p-007-2"></a>

[本卷同事原句](#wei011-l31-2)。

**归年** 《晋书·惠帝纪》元康元年辛卯明书张劭与杨骏同诛；与裴注所载同案李斌合列。

<a id="sgz027-p-004-5"></a>

[本卷同事原句](#wei027-l24-5)。

**归年** 虞预《晋书》明元康元年，与《晋书·惠帝纪》杨骏案同年同案。

<a id="sgz028-p-028-4"></a>

**[《三国志·王毌丘诸葛邓钟传》裴注 028·4](../../拆分史书/三国志/卷028.md#pei-028-4)**

> 東安公繇諸葛誕外孫欲殺俶因誅楊駿誣俶謀逆遂夷三族

**释读** 司马繇为诸葛诞外孙，欲报仇，借杨骏案称文俶谋逆而夷族。

**归年** 《晋书·惠帝纪》《通鉴》元康元年春诛杨骏，人物诬陷在同案。

### 3. 司马亮辅政任卫权，傅咸劝勿越资任用

[返回正文第3条](#sgz-event-3)

<a id="wei022-l90-2"></a>

**[《三國志·桓二陳徐衞盧傳》裴注](../../拆分史书/三国志/卷022.md#edition-wei022-l90-2)** · [TXT L90](../../拆分史书/三国志/卷022.txt#L90)

> 晉大司馬汝南王亮輔政，以權爲尚書郎。傅咸與亮牋曰：「衞伯輿貴妃兄子，誠有才章，應作臺郎，然未得東宮官屬。東宮官屬，前患楊駿，親理塞路，今有伯輿，復越某作郎。一犬吠形，羣犬吠聲，懼於羣犬，遂至回聽。」

**釋讀與歸年** 汝南王司馬亮輔政，以衞權為尚書郎；傅咸指出衞權為貴妃兄子，有才可任而資望尚不足超遷，以為不宜重蹈楊駿任用親黨覆轍。與[《晉書·惠帝紀》](../../史书/005-晋书/晋书-CCDH.txt#L373)元康元年司馬亮輔政同時。

<a id="sgz022-p-018-2"></a>

[本卷同事原句](#wei022-l90-2)。

**归年** 《晋书·惠帝纪》元康元年三月杨骏死后命司马亮共辅政，六月即遇害，故此札和除授限291。

### 4. 卢浮在晋永平间任秘书监

<a id="wei022-l105-5"></a>

**[《三國志·桓二陳徐衞盧傳》裴注](../../拆分史书/三国志/卷022.md#edition-wei022-l105-5)** · [TXT L105](../../拆分史书/三国志/卷022.txt#L105)

**釋讀與歸年** 《晉諸公贊》記晉惠帝永平年間（291）任盧浮為祕書監，[《晉書·盧浮傳》](../../史书/005-晋书/晋书-CCDH.txt#L5542)載亦未赴官。

# 公元300年｜西晋永康元年

[← 公元297年](ce-0297.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元301年 →](../ce-0301-0400/ce-0301.md)

[本年相关史料](#sources-start)

<a id="sgz-event-1"></a>

1. **张燕曾孙张林参与赵王伦政变。** 陆机《晋惠帝起居注》记通事令史张林是张飞燕曾孙，加入赵王司马伦的政变。 [[1]](#sgz-note-1)

<a id="sgz-event-2"></a>

2. **赵王伦诛贾谧。** 贾谧、韩蔚被诛，韩家此系绝。 [[2]](#sgz-note-2)

<a id="sgz-event-3"></a>

3. **赵王伦召李重，李重固辞。** 李重知赵王伦将乱，辟为右司马后以疾不就；逼上官数日病死，赠散骑常侍。 [[3]](#sgz-note-3)

<a id="sgz-event-4"></a>

4. **赵王伦杀裴頠。** 赵王伦以其名望忌惮，知与贾后不同党，仍枉害。 [[4]](#sgz-note-4)

<a id="sgz-event-5"></a>

5. **西晋任陈准为太尉。** 陈佐之子陈准官至太尉。 [[5]](#sgz-note-5)

1. **赵王伦夺权，诛贾谧、裴頠等。** 通事令史张林是张燕的曾孙。他参与赵王司马伦的政变。 贾谧、韩蔚被诛，韩家此系绝。 李重知赵王伦将乱，辟为右司马后以疾不就；逼上官数日病死，赠散骑常侍。 赵王伦以其名望忌惮，知与贾后不同党，仍枉害。 [[1]](#sgz-note-1)

<a id="sgz-event-5"></a>

2. **西晋任陈准为太尉。** 陈佐之子陈准官至太尉。 [[2]](#sgz-note-5)

## 本年相关史料

<a id="sgz-note-1"></a>

### 1. 赵王伦夺权，诛贾谧、裴頠等

[返回正文第1条](#sgz-event-1)

<a id="sgz008-p-039-1"></a>

**[《三国志·二公孙陶四张传》裴注 039·1](../../sources/本地分卷/三国志/三国志-卷008.md#pei-039-1)**

> 陸機晉惠帝起居注曰門下通事令史張林飛燕之曽孫林與趙王倫為亂

**归年** 《晋书·赵王伦传》先叙张林作为内应参与废贾后；《惠帝纪》系废贾后于永康元年，即300。

<a id="sgz-note-2"></a>

<a id="sgz024-p-005-7"></a>

**[《三国志·韩崔高孙王传》裴注 005·7](../../sources/本地分卷/三国志/三国志-卷024.md#pei-005-7)**

> 並為趙王倫所誅韓氏遂滅

**归年** 《晋书·惠帝纪》永康元年四月诛贾谧，同事。

<a id="sgz-note-3"></a>

<a id="sgz018-p-005-6"></a>

**[《三国志·二李臧文吕许典二庞阎传》裴注 005·6](../../sources/本地分卷/三国志/三国志-卷018.md#pei-005-6)**

> 相國趙王倫以重望取為右司馬重以倫將為亂辭疾不就倫逼之不已重遂不復自活至於困篤扶曳受拜數日卒贈散騎常侍

**归年** 《晋书·李重传》及《惠帝纪》：赵王伦诛贾后掌权在永康元年，受任后一病遂卒，未书月日。

<a id="sgz-note-4"></a>

<a id="sgz023-p-019-9"></a>

**[《三国志·和常杨杜赵裴传》裴注 019·9](../../sources/本地分卷/三国志/三国志-卷023.md#pei-019-9)**

> 趙王倫以其望重畏而惡之知其不與賈氏同心猶被枉害

**归年** 《晋书·惠帝纪》永康元年诛张华裴頠。

### 2. 西晋任陈准为太尉

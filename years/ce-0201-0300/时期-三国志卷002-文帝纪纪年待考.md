## 《文帝纪》跨年及未定年材料

<a id="period-sgz002-b-127-1"></a>

### 曹丕名号及家世

[《三国志·文帝纪》仓内原文 L127](../../拆分史书/三国志/卷002.md#l127)

魏文帝曹丕字子桓，是曹操之子。

**时段与依据** 纪首名号、家世，无独立事年。

<a id="wei002-l3-1"></a>

**[《三國志·文帝紀》正文](../../拆分史书/三国志/卷002.md#edition-wei002-l3-1)** · [TXT L3](../../拆分史书/三国志/卷002.txt#L3)

> 文皇帝諱丕，字子桓，武帝太子也。

**釋讀與歸年** 纪首记曹丕的名、字与魏武帝储嗣身份，属于身份提要。

### 曹丕的文学著述

[《三国志·文帝纪》仓内原文 L164](../../拆分史书/三国志/卷002.md#l164)

曹丕长期从事著述，本纪记他亲自撰成约百篇。

**时段与依据** “初”回叙一生志趣及累积著述；裴注引《魏书》有东宫时的著述线索，无逐作完成年月。

<a id="wei002-l150-1"></a>

**[《三國志·文帝紀》正文](../../拆分史书/三国志/卷002.md#edition-wei002-l150-1)** · [TXT L150](../../拆分史书/三国志/卷002.txt#L150)

> 初，帝好文學，以著述爲務，自所勒成垂百篇。

**釋讀與歸年** 本纪追述曹丕好文学，自己撰成作品将近百篇。各作品的年月未逐一记载。

<a id="period-sgz002-b-164-2"></a>

### 曹丕命诸儒按类编纂《皇览》

[《三国志·文帝纪》仓内原文 L164](../../拆分史书/三国志/卷002.md#l164)

曹丕使儒者把经传典籍按内容归类，成千余篇，题《皇览》。

**时段与依据** 《刘劭传》（TXT L1156）写黄初中受诏，故保留220至226年期间。

<a id="wei002-l150-2"></a>

**[《三國志·文帝紀》正文](../../拆分史书/三国志/卷002.md#edition-wei002-l150-2)** · [TXT L150](../../拆分史书/三国志/卷002.txt#L150)

> 又使諸儒撰集經傳，隨類相從，凡千餘篇，號曰皇覽。

**釋讀與歸年** 曹丕令诸儒分类编纂经传，题作《皇览》。《刘劭传》说刘劭于黄初中受诏参与，可限定在曹丕为帝时，未载下诏年月。

<a id="period-sgz002-b-165-1"></a>

### 陈寿评曹丕

[《三国志·文帝纪》仓内原文 L165](../../拆分史书/三国志/卷002.md#l165)

陈寿赞曹丕能文博学、多才多艺，也认为尚须更宽宏、公平、广德。

**时段与依据** 陈寿评语不属于曹丕在位某年。

<a id="wei002-l153-1"></a>

**[《三國志·文帝紀》正文](../../拆分史书/三国志/卷002.md#edition-wei002-l153-1)** · [TXT L153](../../拆分史书/三国志/卷002.txt#L153)

> 評曰：文帝天資文藻，下筆成章，博聞彊識，才藝兼該；

**釋讀與歸年** 卷末陈寿说魏文帝天资有文才、学识博洽且多能，此为史家总结。

<a id="wei002-l155-1"></a>

**[《三國志·文帝紀》正文](../../拆分史书/三国志/卷002.md#edition-wei002-l155-1)** · [TXT L155](../../拆分史书/三国志/卷002.txt#L155)

> 若加之曠大之度，勵以公平之誠，邁志存道，克廣德心，則古之賢主，何遠之有哉！

**釋讀與歸年** 接上陈寿卷末史评。陈寿认为曹丕若更宽宏、公平诚恳、志存德道，也可以比拟古代贤主。此是评论并无单事之年。

<a id="period-sgz002-p-001-2"></a>

### 曹丕少时作文并学骑射击剑

[《三国志·文帝纪》裴注 001·2](../../拆分史书/三国志/卷002.md#pei-001-2)

曹丕八岁能作文，广读经传百家，善骑射、击剑，曾被举为茂才而未就。

**时段与依据** 若从187年冬按虚岁算，八岁约194年；读书及茂才无确年。

<a id="wei002-l4-2"></a>

**[《三國志·文帝紀》裴注](../../拆分史书/三国志/卷002.md#edition-wei002-l4-2)** · [TXT L4](../../拆分史书/三国志/卷002.txt#L4)

> 年八歲，能屬文。有逸才，遂博貫古今經傳諸子百家之書。善騎射，好擊劔。舉茂才，不行。

**釋讀與歸年** 八岁作文按187年生、虚岁推约194年。广读经传、习骑射击剑和不就茂才均无确切年月。

### 高元吕为曹丕相面

[《三国志·文帝纪》裴注 002·1](../../拆分史书/三国志/卷002.md#pei-002-1)

《魏略》说曹操迟迟未定储嗣时，曹丕召高元吕相问。高元吕预言极贵并说四十岁会有小灾。

**时段与依据** 在217年立魏太子前，“無㡬”未明历年。

<a id="wei002-l6-1"></a>

**[《三國志·文帝紀》裴注](../../拆分史书/三国志/卷002.md#edition-wei002-l6-1)** · [TXT L6](../../拆分史书/三国志/卷002.txt#L6)

> 魏略曰：太祖不時立太子，太子自疑。是時有高元呂者，善相人，乃呼問之，對曰：「其貴乃不可言。」問：「壽幾何？」元呂曰：「其壽，至四十當有小苦，過是無憂也。」

**釋讀與歸年** 《魏略》记迟迟未立太子时，高元吕为曹丕相面。相面在217年立储以前，原文说“不久”而未载确年。

### 《献帝传》禅代文书的四库电子异文

[《三国志·文帝纪》裴注 023·1](../../拆分史书/三国志/卷002.md#pei-023-1)

### 邢史子臣预言被联系到魏兴

[《三国志·文帝纪》裴注 024·3](../../拆分史书/三国志/卷002.md#pei-024-3)

《搜神记》记宋景公询天道，邢史子臣预言自身死亡、吴亡、宋君终和邾姓得国，后人以曹姓附会魏兴；注指出年数不合。

**时段与依据** 起点周敬王三十七年、后段数百年和魏兴有多层叙述；不以志怪预言推算单一年份。

<a id="wei002-l61-4"></a>

**[《三國志·文帝紀》裴注](../../拆分史书/三国志/卷002.md#edition-wei002-l61-4)** · [TXT L61](../../拆分史书/三国志/卷002.txt#L61)

> 干竇搜神記曰：宋大夫邢史子臣明於天道，周敬王之三十七年，景公問曰：「天道其何祥？」對曰：「後五年五月丁亥，臣將死；死後五年五月丁卯，吳將亡；亡後五年，君將終；終後四百年，邾王天下。」俄而皆如其言。所云邾王天下者，謂魏之興也。邾，曹姓，魏亦曹姓，皆邾之後。其年數則錯，未知邢史失其數邪，將年代久遠，注記者傳而有謬也？

**釋讀與歸年** 宋景公问祥、邢史子臣预言自身与吴、宋之事，传说又以曹姓邾国后裔附会曹魏兴起。原注已经指出年数错乱，周敬王三十七年只是故事设定的起点，志怪留附受禅。

<a id="period-sgz002-p-030-2"></a>

### 杨彪退职十余年

[《三国志·文帝纪》裴注 030·2](../../拆分史书/三国志/卷002.md#pei-030-2)

杨彪见汉祚将终，因累世为汉三公，以足疾长期不出。

**时段与依据** 《杨彪传》连建安十一年削恩泽侯后而记，不载退避单独确日；事情延续多年。

<a id="wei002-l82-2"></a>

**[《三國志·文帝紀》裴注](../../拆分史书/三国志/卷002.md#edition-wei002-l82-2)** · [TXT L82](../../拆分史书/三国志/卷002.txt#L82)

> 續漢書曰：彪見漢祚將終，自以累世爲三公，恥爲魏臣，遂稱足攣，不復行。積十餘年，

**釋讀與歸年** 《续汉书》追记汉末杨彪以累世汉公，不愿做魏臣，称足病而不出。到曹丕即王位时相距十余年，初辞病之年没有确载。

<a id="period-sgz002-p-040-2"></a>

### 裴松之从卢毓旧议推知魏出师告郊

[《三国志·文帝纪》裴注 040·2](../../拆分史书/三国志/卷002.md#pei-040-2)

裴松之据尚书卢毓议制比较前后文，认为曹魏出师皆行郊告。

**时段与依据** 制度解释及旧奏没有明确事年；附223年十月出师告祀。

<a id="wei002-l123-2"></a>

**[《三國志·文帝紀》裴注](../../拆分史书/三国志/卷002.md#edition-wei002-l123-2)** · [TXT L123](../../拆分史书/三国志/卷002.txt#L123)

> 臣松之按：魏郊祀奏中，尚書盧毓議祀厲殃事云：「具犧牲祭器，如前後師出告郊之禮。」如此，則魏氏出師，皆告郊也。

**釋讀與歸年** 裴松之据卢毓《魏郊祀奏》中引用以往出师告郊旧制，推曹魏出师通常有告郊仪节。卢毓奏议本身确年未载，同时互见223年告郊。

<a id="period-sgz002-p-048-2"></a>

### 曹丕编著《典论》等，与诸儒讲论

[《三国志·文帝纪》裴注 048·2](../../拆分史书/三国志/卷002.md#pei-048-2)

曹丕整理《典论》、诗赋，召儒者讨论，推重汉文帝宽政；见有人认为文帝不如贾谊，写《太宗论》分别君主与贤臣之长。

**时段与依据** 在位前后写作与论辩未独标年；下文另明黄初三年公布。

<a id="wei002-l151-2"></a>

**[《三國志·文帝紀》裴注](../../拆分史书/三国志/卷002.md#edition-wei002-l151-2)** · [TXT L151](../../拆分史书/三国志/卷002.txt#L151)

> 故論撰所著典論、詩賦，蓋百餘篇，集諸儒於肅城門內，講論大義，侃侃無倦。常嘉漢文帝之爲君，寬仁玄默，務欲以德化民，有賢聖之風。時文學諸儒，或以爲孝文雖賢，其於聦明，通達國體，不如賈誼。帝由是著太宗論曰：「昔有苗不賔，重華舞以干戚，尉他稱帝，孝文撫以恩德，吳王不朝，錫之几杖以撫其意，而天下賴安；乃弘三章之教，愷悌之化，欲使曩時累息之民，得闊步高談，無危懼之心。若賈誼之才敏，籌畫國政，特賢臣之器，管、晏之姿，豈若孝文大人之量哉？」

**釋讀與歸年** 曹丕整理《典论》、诗赋百余篇，在肃城门内与诸儒论议，推崇汉文帝宽政，又因有人认为文帝不如贾谊而作《太宗论》。写作、讨论的确切年月未载。

<a id="period-sgz002-p-048-4"></a>

### 曹丕评汉文帝治政不足

[《三国志·文帝纪》裴注 048·4](../../拆分史书/三国志/卷002.md#pei-048-4)

曹丕另一次表示不赞成汉文帝杀薄昭、宠邓通、使慎夫人衣不曳地等做法，论外戚可恩养而不应借权。

**时段与依据** “他日”没有年代，亦不可用《太宗论》公布年替代。

<a id="wei002-l151-4"></a>

**[《三國志·文帝紀》裴注](../../拆分史书/三国志/卷002.md#edition-wei002-l151-4)** · [TXT L151](../../拆分史书/三国志/卷002.txt#L151)

> 他日又從容言曰：「顧我亦有所不取於漢文帝者三：殺薄昭；幸鄧通；慎夫人衣不曳地，集上書囊爲帳帷。以爲漢文儉而無法，舅后之家，但當養育以恩而不當假借以權，旣觸罪法，又不得不害矣。」其欲秉持中道，以爲帝王儀表者如此。

**釋讀與歸年** 曹丕另一次谈论汉文帝，批评杀薄昭、宠邓通与节俭失法，认为外戚可恩养而不应借权。原注称“他日”，无确年。

**时段与依据** 史书未说明送书年月；区分从东宫写作和黄初三年传布《太宗论》。

<a id="wei002-l151-5"></a>

**[《三國志·文帝紀》裴注](../../拆分史书/三国志/卷002.md#edition-wei002-l151-5)** · [TXT L151](../../拆分史书/三国志/卷002.txt#L151)

<a id="period-sgz002-p-049-1"></a>

### 曹丕回忆董卓害少帝和何太后

[《三国志·文帝纪》裴注 049·1](../../拆分史书/三国志/卷002.md#pei-049-1)

曹丕《典论》把董卓杀少帝和鸩何太后连叙，认为百姓早已难堪汉末与董卓之政。

**时段与依据** 首句概称“初平之元”，但被害何太后在189年，少帝在190年（《献帝纪》），同一语段兼指两年。

<a id="wei002-l154-1"></a>

**[《三國志·文帝紀》裴注](../../拆分史书/三国志/卷002.md#edition-wei002-l154-1)** · [TXT L154](../../拆分史书/三国志/卷002.txt#L154)

> 典論帝自敘曰：初平之元，董卓殺主鴆后，盪覆王室。是時四海旣困中平之政，兼惡卓之凶逆，家家思亂，人人自危。

**釋讀與歸年** 曹丕在《典论·自叙》中总称初平元年董卓杀主、鸩太后，实合两年之事。何太后中平六年（189）九月遇害，汉少帝弘农王初平元年（190）正月被杀。

<a id="period-sgz002-p-049-4"></a>

### 曹丕幼时随曹操学习骑射

[《三国志·文帝纪》裴注 049·4](../../拆分史书/三国志/卷002.md#pei-049-4)

曹丕说战乱百姓逃亡、尸骨遍地，父亲五岁教自己射箭，六岁会射后学马术，八岁能骑射，常随征。

**时段与依据** 按187年生虚岁约191至194；各活动分跨数年，叙事局势为背景。

<a id="wei002-l154-4"></a>

**[《三國志·文帝紀》裴注](../../拆分史书/三国志/卷002.md#edition-wei002-l154-4)** · [TXT L154](../../拆分史书/三国志/卷002.txt#L154)

> 會黃巾盛於海、岱，山寇暴於并、兾，乘勝轉攻，席卷而南，鄉邑望煙而奔，城郭覩塵而潰，百姓死亡，暴骨如莽。余時年五歲，上以世方擾亂，教余學射，六歲而知射，又教余騎馬，八歲而能騎射矣。以時之多故，每征，余常從。

**釋讀與歸年** 曹丕回忆海岱黄巾、并冀山寇之乱，并以五、六、八岁分述从父学射、学骑及开始随征，跨早年数岁，不能按同一初平年次硬系。

### 曹丕自述长期爱好弓马

[《三国志·文帝纪》裴注 049·6](../../拆分史书/三国志/卷002.md#pei-049-6)

曹丕说生长在战乱中，向来喜好射猎，常逐禽驰射，仍不觉疲倦。

**时段与依据** 是成长经历及长期习性，无独立年。

<a id="wei002-l154-6"></a>

**[《三國志·文帝紀》裴注](../../拆分史书/三国志/卷002.md#edition-wei002-l154-6)** · [TXT L154](../../拆分史书/三国志/卷002.txt#L154)

> 夫文武之道，各隨時而用，生於中平之季，長於戎旅之間，是以少好弓馬，于今不衰；逐禽輒十里，馳射常百步，日多體健，心每不猒。

**釋讀與歸年** 曹丕概述生于中平末、长于军旅，终始爱好骑射追禽，这些是长期经历。

<a id="period-sgz002-p-049-8"></a>

### 曹丕与前来犒军的荀彧谈骑射

[《三国志·文帝纪》裴注 049·8](../../拆分史书/三国志/卷002.md#pei-049-8)

军南征至曲蠡，荀彧奉命犒军，与曹丕谈左右开弓与在野地驰射的难处，张京在座。

**时段与依据** 荀彧212年卒，不能和220年文帝丙午至曲蠡混同；旧事确年未见。

<a id="wei002-l154-8"></a>

**[《三國志·文帝紀》裴注](../../拆分史书/三国志/卷002.md#edition-wei002-l154-8)** · [TXT L154](../../拆分史书/三国志/卷002.txt#L154)

> 後軍南征次內蠡，尚書令荀彧奉使犒軍，見余談論之末，彧言：「聞君善左右射，此實難能。」余言：「執事未覩夫項發口縱，俯馬蹄而仰月支也。」彧喜笑曰：「乃爾！」余曰：「埒有常徑，的有常所，雖每發輒中，非至妙也。若馳平原，赴豐草，要狡獸，截輕禽，使弓不虛彎，所中必洞，斯則妙矣。」時軍祭酒張京在坐，顧彧拊手曰「善」。

**釋讀與歸年** 曹丕回忆军至内蠡时荀彧前来犒军，与自己谈左右开弓和驰射，张京在座。底本“內蠡”，旧引“曲蠡”。荀彧卒于212年，不得与曹丕220年行至曲蠡并作一事，确年待考。

<a id="period-sgz002-p-049-9"></a>

### 曹丕学习剑术并与邓展切磋

[《三国志·文帝纪》裴注 049·9](../../拆分史书/三国志/卷002.md#pei-049-9)

曹丕讲京师王越与史阿的剑术传承，自己师史阿，又曾在宴饮时以甘蔗与邓展较技。

**时段与依据** 王越声名在桓灵间；曹丕学艺及同邓展、刘勋饮宴均未载确年。

<a id="wei002-l154-9"></a>

**[《三國志·文帝紀》裴注](../../拆分史书/三国志/卷002.md#edition-wei002-l154-9)** · [TXT L154](../../拆分史书/三国志/卷002.txt#L154)

> 余又學擊劔，閱師多矣，四方之法各異，唯京師爲善。桓、靈之閒，有虎賁王越善斯術，稱於京師。河南史阿言昔與越遊，具得其法，余從阿學之精熟。甞與平虜將軍劉勳、奮威將軍鄧展等共飲，宿聞展善有手臂，曉五兵，又稱其能空手入白刃。余與論劔良久，謂言將軍法非也，余顧甞好之，又得善術，因求與余對。時酒酣耳熱，方食芋蔗，便以爲杖，下殿數交，三中其臂，左右大笑。展意不平，求更爲之。余言吾法急屬，難相中面，故齊臂耳。展言願復一交，余知其欲突以取交中也，因偽深進，展果尋前，余却脚鄛，正截其顙，坐中驚視。余還坐，笑曰：「昔陽慶使淳于意去其故方，更授以祕術，今余亦願鄧將軍捐棄故伎，更受要道也。」一坐盡歡。

**釋讀與歸年** 曹丕述虎贲王越传剑术至史阿，自随史阿学习，又在与刘勋、邓展饮宴时以甘蔗与邓展较技。曹丕搏剑、饮宴的确年均未载。

<a id="period-sgz002-p-049-10"></a>

### 曹丕向袁敏学习，并谈弹棋与读书

[《三国志·文帝纪》裴注 049·10](../../拆分史书/三国志/卷002.md#pei-049-10)

曹丕说袁敏教他以单兵器对付双兵器，亦谈弹棋、曹操常在军旅读书及自己所读典籍。

**时段与依据** 是多阶段经历，所述人物和作品无独立确年。

<a id="wei002-l154-10"></a>

**[《三國志·文帝紀》裴注](../../拆分史书/三国志/卷002.md#edition-wei002-l154-10)** · [TXT L154](../../拆分史书/三国志/卷002.txt#L154)

> 夫事不可自謂己長，余少曉持複，自謂無對；俗名雙戟爲坐鐵室，鑲楯爲蔽木戶；後從陳國袁敏學，以單攻複，每爲若神，對家不知所出，先曰若逢敏於狹路，直決耳！余於他戲弄之事少所喜，唯彈棊略盡其巧，少爲之賦。昔京師先工有馬合鄉侯、東方安世、張公子，常恨不得與彼數子者對。上雅好詩書文籍，雖在軍旅，手不釋卷，每每定省從容，常言人少好學則思專，長則善忘，長大而能勤學者，唯吾與袁伯業耳。余是以少誦詩、論，及長而備歷五經、四部，史、漢、諸子百家之言，靡不畢覽。

**釋讀與歸年** 曹丕自述袁敏教他用单兵器应对双兵器，又及弹棋略有所长。进而回忆父亲军旅中勤学，自己从少时诵书到遍观经史诸子。这些事跨多年。

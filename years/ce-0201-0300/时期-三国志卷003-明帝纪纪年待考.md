<a id="sgz003-period"></a>

## 《明帝纪》跨年及未定年材料

<a id="period-sgz003-b-167-1"></a>

### 曹叡名讳与身份

[《三国志·明帝纪》仓内原文 L167](../../拆分史书/三国志/卷003.md#l167)

魏明帝名叡，字元仲，是魏文帝的太子。

**时段与依据** 篇首传主名号，太子册立另见同一行黄初七年记事。

<a id="wei003-l3-1"></a>

**[《三國志·明帝紀》正文](../../拆分史书/三国志/卷003.md#edition-wei003-l3-1)** · [TXT L3](../../拆分史书/三国志/卷003.txt#L3)

> 明皇帝諱叡，字元仲，文帝太子也。

**釋讀與歸年** 纪首先交代曹叡的名、字及储嗣身份。立太子实见黄初七年五月。

<a id="period-sgz003-b-167-2"></a>

### 曹操喜爱幼年曹叡

[《三国志·明帝纪》仓内原文 L167](../../拆分史书/三国志/卷003.md#l167)

曹操从曹叡小的时候就喜爱他，常让他跟随在身边。

**时段与依据** 本纪“生而”“常”指多年；确定在曹操建安二十五年去世前，226年第12条错把早年事挂在即位年。裴注另载曹操称其“我基於爾三世矣”，未记某年。

<a id="wei003-l3-2"></a>

**[《三國志·明帝紀》正文](../../拆分史书/三国志/卷003.md#edition-wei003-l3-2)** · [TXT L3](../../拆分史书/三国志/卷003.txt#L3)

> 生而太祖愛之，常令在左右。

**釋讀與歸年** 曹操喜爱曹叡、常使他留在左右，是建安二十五年曹操去世前的多年情状。本句未载曹叡生年，年龄说法见本卷封侯及末尾卒条。

<a id="period-sgz003-b-175-2"></a>

### 曹叡在听讼观临听大案

[《三国志·明帝纪》仓内原文 L175](../../拆分史书/三国志/卷003.md#l175)

曹叡认为刑狱维系天下性命，大案审理时往往亲往听讼观听审。

**时段与依据** “常言”“每斷”是改名后习惯，历时而没有各案具体纪年。可在229年第5条参见其作用。

<a id="wei003-l36-2"></a>

**[《三國志·明帝紀》正文](../../拆分史书/三国志/卷003.md#edition-wei003-l36-2)** · [TXT L36](../../拆分史书/三国志/卷003.txt#L36)

> 帝常言「獄者，天下之性命也」，每斷大獄，常幸觀臨聽之。

**釋讀與歸年** 曹叡视刑狱为人命大事，每遇大狱常到听讼观临听，是改名以后的经常做法，不能把一系列刑案硬系229年十月。

<a id="period-sgz003-b-176-1"></a>

### 洛阳宗庙未成前神主在邺

[《三国志·明帝纪》仓内原文 L176](../../拆分史书/三国志/卷003.md#l176)

洛阳宗庙尚未建成的时候，神主移置或奉设在邺的庙内。

**时段与依据** 本纪“初”概叙229年新庙建成之前，建庙本身自227年始，神主在邺为此前状态；229年第6条宜作背景。

<a id="wei003-l38-1"></a>

**[《三國志·明帝紀》正文](../../拆分史书/三国志/卷003.md#edition-wei003-l38-1)** · [TXT L38](../../拆分史书/三国志/卷003.txt#L38)

> 初，洛陽宗廟未成，神主在鄴廟。

**釋讀與歸年** 曹魏在洛阳宗庙建成以前将神主奉安邺庙。洛阳营庙始于227年，完成于229年，背景在229年迎神主条互见。

<a id="period-sgz003-b-201-3"></a>

### 孙权遣使通高句骊，欲袭辽东

[《三国志·明帝纪》仓内原文 L201](../../拆分史书/三国志/卷003.md#l201)

此前孙权派遣使者浮海与高句骊联系，意图袭取辽东。

**时段与依据** 本纪以“初”引毌丘俭讨辽东之前的吴外交。卷047《吴主传》嘉禾二年、五年（233、236）先后使高句骊，L197载236年吴使被斩，未明此句指单轮还是连叙；旧237年第18条不能作为赴使发生年。

<a id="wei003-l109-3"></a>

**[《三國志·明帝紀》正文](../../拆分史书/三国志/卷003.md#edition-wei003-l109-3)** · [TXT L109](../../拆分史书/三国志/卷003.txt#L109)

> 初，權遣使浮海與高句驪通，欲襲遼東。

**釋讀與歸年** 本纪以“初”回叙孙吴通高句骊以谋辽东。《吴主传》裴注[《吴书》](../../拆分史书/三国志/卷047.txt#L138)明载233年秦旦等因辽东之变赴高句骊，又载后续通使；本纪另记236年胡卫等被斩。此句未指明哪一轮派使，作为出兵前因互见。

<a id="period-sgz003-b-208-3"></a>

### 登女在曹叡末次病中被杀

[《三国志·明帝纪》仓内原文 L208](../../拆分史书/三国志/卷003.md#l208)

到曹叡病重时，饮用她的水没有效果，登女被杀。

**时段与依据** “及帝疾”承L207景初二年十二月患病，止于L209景初三年正月丁亥帝卒。按史书仅能定位238岁末至239正月之间，未给跨年点前后确证。

<a id="wei003-l135-2"></a>

**[《三國志·明帝紀》正文](../../拆分史书/三国志/卷003.md#edition-wei003-l135-2)** · [TXT L135](../../拆分史书/三国志/卷003.txt#L135)

> 及帝疾，飲水無驗，於是殺焉。

**釋讀與歸年** 曹叡久病后饮水无效，登女被杀。末次病自景初二年十二月起，至三年正月丁亥帝卒止，具体发生在换岁前后未详。

<a id="period-sgz003-b-210-1"></a>

### 陈寿论曹叡明断与营宫之失

[《三国志·明帝纪》仓内原文 L210](../../拆分史书/三国志/卷003.md#l210)

陈寿称曹叡深沉刚毅、明识决断，有君主气度；又批评天下分崩、民生困惫时急于仿效秦皇、汉武营造宫室，未先拓展祖业。

**时段与依据** “評曰”是本卷作者对其一朝的总结，借秦始皇、汉武帝指责宫室营建，无单一事件年。

<a id="wei003-l147-1"></a>

**[《三國志·明帝紀》正文](../../拆分史书/三国志/卷003.md#edition-wei003-l147-1)** · [TXT L147](../../拆分史书/三国志/卷003.txt#L147)

> 評曰：明帝沉毅斷識，任心而行，蓋有君人之至槩焉。于時百姓彫弊，四海分崩，不先聿脩顯祖，闡拓洪基，而遽追秦皇、漢武，宮館是營，格之遠猷，其殆疾乎！

**釋讀與歸年** 陈寿肯定曹叡沉毅明断、能自决政事，批评他在民生疲弊、天下分裂时忙于效仿秦皇、汉武营造宫馆，未先修明祖业、扩充国基。史评纵论一朝，可参235年洛阳营建及谏疏。

<a id="period-sgz003-p-001-1"></a>

### 曹操器重幼时的曹叡

[《三国志·明帝纪》裴注 001·1](../../拆分史书/三国志/卷003.md#pei-001-1)

《魏书》说曹叡年仅数岁便显出聪慧，曹操说子孙三世的基业在他身上，往往让他和侍中近臣同列帷幄；曹叡还爱读书，关注法律。

**时段与依据** 童年及反复伴随曹操无具体年，至迟在曹操220年去世以前。“我基於爾三世”是所引对话，不给出处日期。

<a id="wei003-l4-1"></a>

**[《三國志·明帝紀》裴注](../../拆分史书/三国志/卷003.md#edition-wei003-l4-1)** · [TXT L4](../../拆分史书/三国志/卷003.txt#L4)

> 魏書曰：帝生數歲而有岐嶷之姿，武皇帝異之，曰：「我基於爾三世矣。」每朝宴會同，與侍中近臣並列帷幄。好學多識，特留意於法理。

**釋讀與歸年** 《魏书》记曹叡幼时早慧、被曹操视为第三代继业之望，随近臣参加朝宴，并称其博学、特别留心法理。所记并非同一日，曹操朝宴部分至迟在220年以前。

<a id="period-sgz003-p-002-1"></a>

### 曹丕让郭皇后养曹叡，并曾考虑京兆王

[《三国志·明帝纪》裴注 002·1](../../拆分史书/三国志/卷003.md#pei-002-1)

《魏略》说曹丕令无子的郭皇后以曹叡为子；曹叡因甄氏死不平，后来不得已问候郭后，郭后对他转而慈爱。曹丕曾有意立另一妃嫔所生的京兆王，因此较晚立曹叡为太子。

**时段与依据** 甄氏死于221年，郭氏立皇后于222年，曹叡立太子在226年。收养、转变态度和另择太子的各次决定未见确年。“京兆王”也可能是追称。

<a id="wei003-l6-1"></a>

**[《三國志·明帝紀》裴注](../../拆分史书/三国志/卷003.md#edition-wei003-l6-1)** · [TXT L6](../../拆分史书/三国志/卷003.txt#L6)

> 魏略曰：文帝以郭后無子，詔使子養帝。帝以母不以道終，意甚不平。後不獲已，乃敬事郭后，旦夕因長御問起居，郭后亦自以無子，遂加慈愛。文帝始以帝不恱，有意欲以他姬子京兆王爲嗣，故久不拜太子。

**釋讀與歸年** 《魏略》以甄氏死后曹叡由郭氏抚养、母子关系渐趋和缓及曹丕一度考虑立曹礼解释推迟立储。《郭皇后传》裴注引《汉晋春秋》亦记郭氏养曹叡。曹礼于黄初三年改封京兆王、六年改封元城王，见《武文世王公传》。“京兆王”可能沿旧称，并不能据此定曹丕犹豫的确年。

<a id="period-sgz003-p-002-2"></a>

### 猎鹿故事解释曹丕立储之意

[《三国志·明帝纪》裴注 002·2](../../拆分史书/三国志/卷003.md#pei-002-2)

《魏末传》说曹丕猎杀母鹿、让曹叡射小鹿，曹叡想起母子关系，含泪拒绝，曹丕由此决定立他为太子。

**时段与依据** 这是另一个文献对立储动机的解释，狩猎没有明确日期，只能置于226年立储之前。

<a id="wei003-l6-2"></a>

**[《三國志·明帝紀》裴注](../../拆分史书/三国志/卷003.md#edition-wei003-l6-2)** · [TXT L6](../../拆分史书/三国志/卷003.txt#L6)

> 魏末傳曰：帝常從文帝獵，見子母鹿。文帝射殺鹿母，使帝射鹿子，帝不從，曰：「陛下已殺其母，臣不忍復殺其子。」因涕泣。文帝即放弓箭，以此深奇之，而樹立之意定。

**釋讀與歸年** 《魏末传》以曹叡不忍射杀幼鹿解释曹丕决定立储。狩猎具体年月未载，《明帝纪》以曹丕病笃解释正式册立，这里仍随立储前的回叙。

<a id="period-sgz003-p-004-1"></a>

### 孟他以家财结交张让家奴、拜凉州刺史

[《三国志·明帝纪》裴注 004·1](../../拆分史书/三国志/卷003.md#pei-004-1)

《三辅决录》及其注称孟他字伯郎，扶风人。孟他用尽家财结交张让家奴，家奴假装厚待他，引其他求见者献赠财物。孟他转献张让，又送蒲萄酒而得拜凉州刺史。

**时段与依据** 仅称灵帝在位、张让掌事，未载孟他获任日期。

<a id="wei003-l16-1"></a>

**[《三國志·明帝紀》裴注](../../拆分史书/三国志/卷003.md#edition-wei003-l16-1)** · [TXT L16](../../拆分史书/三国志/卷003.txt#L16)

> 三輔決錄曰：伯郎，涼州人，名不令休。其注曰：伯郎姓孟，名他，扶風人。靈帝時。中常侍張讓專朝政，讓監奴典護家事。他仕不遂，乃盡以家財賂監奴，與共結親，積年家業爲之破盡。衆奴皆慙，問他所欲，他曰：「欲得卿曹拜耳。」奴被恩久，皆許諾。時賔客求見讓者，門下車常數百乘，或累日不得通。他最後到，衆奴伺其至，皆迎車而拜，徑將他車獨入。衆人悉驚，謂他與讓善，爭以珍物遺他。他得之，盡以賂讓，讓大喜。他又以蒲桃酒一斛遺讓，即拜涼州刺史。

**釋讀與歸年** 《三辅决录》与其注记灵帝时孟他以家财营结张让奴、收礼转贿张让，再献蒲萄酒而拜凉州刺史。《后汉书·宦者列传》同记孟佗厚结张让家奴、转赠珍玩而获任，未记蒲萄酒。两者都未给拜官确年。

<a id="period-sgz003-p-004-2"></a>

### 孟达是孟他之子，早年入蜀

[《三国志·明帝纪》裴注 004·2](../../拆分史书/三国志/卷003.md#pei-004-2)

孟他生孟达；孟达年轻时入蜀，相关事见《刘封传》。

**时段与依据** 卷040载孟达与法正入蜀过程，注自身“少入蜀”不明是入刘璋幕府哪一年。

<a id="wei003-l16-2"></a>

**[《三國志·明帝紀》裴注](../../拆分史书/三国志/卷003.md#edition-wei003-l16-2)** · [TXT L16](../../拆分史书/三国志/卷003.txt#L16)

> 他生達，少入蜀。其處蜀事迹在劉封傳。

**釋讀與歸年** 附叙孟达为孟他之子、少入蜀。《刘封传》亦记孟达与法正一同入蜀依刘璋，缺确年。

<a id="period-sgz003-p-004-6"></a>

### 孟达受曹丕宠遇，与桓阶、夏侯尚善

[《三国志·明帝纪》裴注 004·6](../../拆分史书/三国志/卷003.md#pei-004-6)

孟达受曹丕优待，也与桓阶、夏侯尚亲善。

**时段与依据** 这一交往跨曹丕在位数年，本注未给单一时点。

<a id="wei003-l16-7"></a>

**[《三國志·明帝紀》裴注](../../拆分史书/三国志/卷003.md#edition-wei003-l16-7)** · [TXT L16](../../拆分史书/三国志/卷003.txt#L16)

> 達旣爲文帝所寵，又與桓階、夏侯尚親善，

**釋讀與歸年** 曹丕礼遇孟达自220年归魏始；他与桓阶、夏侯尚交好，具体年月无载。

<a id="period-sgz003-p-009-2"></a>

### 郝昭籍贯、早年军历与镇河西

[《三国志·明帝纪》裴注 009·2](../../拆分史书/三国志/卷003.md#pei-009-2)

郝昭字伯道，太原人。年轻时在军中从部曲督等处任事，积功为杂号将军，镇守河西十余年。

**时段与依据** 注以生平回顾插入陈仓战事。“十餘年”未给起讫，不与228年的陈仓筑城混时。

<a id="wei003-l29-2"></a>

**[《三國志·明帝紀》裴注](../../拆分史书/三国志/卷003.md#edition-wei003-l29-2)** · [TXT L29](../../拆分史书/三国志/卷003.txt#L29)

> 昭字伯道，太原人，爲人雄壯，少入軍爲部曲督，數有戰功，爲雜號將軍，遂鎮守河西十餘年，民夷畏服。

**釋讀與歸年** 郝昭早年由部曲督至杂号将军，镇河西十数年，民夷畏服。原注未给每次升任或镇守起讫年。

<a id="period-sgz003-p-009-5"></a>

### 郝昭因守陈仓受爵，受曹叡慰劳后病卒

[《三国志·明帝纪》裴注 009·5](../../拆分史书/三国志/卷003.md#pei-009-5)

郝昭获列侯。曹叡召见他，向孙资称许其乡里有良将，打算重用，郝昭却病死，并嘱儿子郝凯从俭殓葬、勿拘故墓。

**时段与依据** 接陈仓战后，至少晚于228年十二月，赏爵、召见、病卒之间年月未明。

<a id="wei003-l29-6"></a>

**[《三國志·明帝紀》裴注](../../拆分史书/三国志/卷003.md#edition-wei003-l29-6)** · [TXT L29](../../拆分史书/三国志/卷003.txt#L29)

> 會病亡，遺令戒其子凱曰：「吾爲將，知將不可爲也。吾數發冢，取其木以爲攻戰具，又知厚葬無益於死者也。汝必斂以時服。且人生有處所耳，死復何在邪？今去本墓遠，東西南北，在汝而已。」

**釋讀與歸年** 获朝廷慰劳后，郝昭病亡，令子郝凯薄葬。他提及此前为攻战取墓木，以此说明厚葬无益。卒年及遗令的确切时间未载。

<a id="period-sgz003-p-010-4"></a>

### 孙盛以古礼解释迎迁神主

[《三国志·明帝纪》裴注 010·4](../../拆分史书/三国志/卷003.md#pei-010-4)

孙盛认为死者也应如在世般事奉，祭祀当如神在，迎迁神主合礼。

**时段与依据** 为晋代史论，没有评论成文确年，所评论即229年第7条。

### 《搜神记》记谶言及柳谷石纹渐显说

[《三国志·明帝纪》裴注 020·2](../../拆分史书/三国志/卷003.md#pei-020-2)

**时段与依据** 自西汉到曹魏分多阶段，各仅帝号或年号，不能用一个年页贯穿，也不从谶语倒定实事年代。

<a id="wei003-l88-2"></a>

**[《三國志·明帝紀》裴注](../../拆分史书/三国志/卷003.md#edition-wei003-l88-2)** · [TXT L88](../../拆分史书/三国志/卷003.txt#L88)

> 搜神記曰：初，漢元、成之世，先識之士有言曰，魏年有和，當有開石於西三千餘里，繫五馬，文曰「大討曹」。及魏之初興也，張掖之柳谷，有開石焉，始見於建安，形成於黃初，文備於太和，周圍七尋，中高一仞，蒼質素章，龍馬、麟鹿、鳳皇、仙人之象，粲然咸著，此一事者，魏、晉代興之符也。

**釋讀與歸年** 《搜神记》追记汉元、成时的谶言，以及魏建安初见、黄初成形、太和文备的渐变叙述，均未标单年，也不应把谶语当成当时已经证实的现象。

### 《汉晋春秋》记氐池石纹的另一形状与后传

[《三国志·明帝纪》裴注 020·4](../../拆分史书/三国志/卷003.md#pei-020-4)

**时段与依据** 同一祥瑞叙事的异本，虽随本注235年报道可互参，但本说难以精确限定发现、凿石和“晉初”显纹日期。

<a id="wei003-l88-4"></a>

**[《三國志·明帝紀》裴注](../../拆分史书/三国志/卷003.md#edition-wei003-l88-4)** · [TXT L88](../../拆分史书/三国志/卷003.txt#L88)

> 漢晉春秋曰：氐池縣大柳谷口夜激波涌溢，其聲如雷，曉而有蒼石立水中，長一丈六尺，高八尺，白石畫之，爲十三馬，一牛，一鳥，八卦玉玦之象，皆隆起，其文曰「大討曹，適水中，甲寅」。帝惡其「討」也，使鑿去爲「計」，以蒼石窒之，宿昔而白石滿焉。至晉初，其文愈明，馬象皆煥徹如玉焉。

**釋讀與歸年** 《汉晋春秋》称发现地点为氐池县大柳谷，石面十三马等形象与《魏氏春秋》有异，又称曹叡将“討”改为“計”、晋初纹形更明。未确书改字的年月，《资治通鉴》卷073把两家记石合叙于235。

<a id="wei003-l145-2"></a>

### 孙盛记曹叡容貌、处置辅政大臣并议得失

[《三国志·明帝纪》裴注 035·3](../../拆分史书/三国志/卷003.md#pei-035-3)

**时段与依据** 史评无成文年，含在位与死后的长时段评议；曹魏以后权力更移不以此一段泛论硬系某年。

**[《三國志·明帝紀》裴注](../../拆分史书/三国志/卷003.md#edition-wei003-l145-3)** · [TXT L145](../../拆分史书/三国志/卷003.txt#L145)

**釋讀與歸年** 孙盛据长老称曹叡发长、口吃少言而有决断，即位后让原辅臣各掌地方，亲自执政，优待直谏之臣；又批评他没有稳固宗室和藩屏，以致死后权归一门。此段综述其在位前后及事后评议。

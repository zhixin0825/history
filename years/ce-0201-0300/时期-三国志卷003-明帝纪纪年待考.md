<a id="sgz003-period"></a>

## 《明帝纪》跨年及未定年材料

<a id="period-sgz003-b-167-1"></a>

### 曹叡名讳与身份

[《三国志·明帝纪》仓内原文 L167](../../sources/本地分卷/三国志/三国志-卷003.md#l167)

> 明皇帝諱叡，字元仲，文帝太子也。

魏明帝名叡，字元仲，是魏文帝的太子。

**时段与依据** 篇首传主名号，太子册立另见同一行黄初七年记事。

<a id="period-sgz003-b-167-2"></a>

### 曹操喜爱幼年曹叡

[《三国志·明帝纪》仓内原文 L167](../../sources/本地分卷/三国志/三国志-卷003.md#l167)

> 生而太祖愛之，常令在左右。

曹操从曹叡小的时候就喜爱他，常让他跟随在身边。

**时段与依据** 本纪“生而”“常”指多年；确定在曹操建安二十五年去世前，226年第12条错把早年事挂在即位年。裴注另载曹操称其“我基於爾三世矣”，未记某年。

<a id="period-sgz003-b-175-2"></a>

### 曹叡在听讼观临听大案

[《三国志·明帝纪》仓内原文 L175](../../sources/本地分卷/三国志/三国志-卷003.md#l175)

> 帝常言「獄者，天下之性命也」，每斷大獄，常幸觀臨聽之。

曹叡认为刑狱维系天下性命，大案审理时往往亲往听讼观听审。

**时段与依据** “常言”“每斷”是改名后习惯，历时而没有各案具体纪年。可在229年第5条参见其作用。

<a id="period-sgz003-b-176-1"></a>

### 洛阳宗庙未成前神主在邺

[《三国志·明帝纪》仓内原文 L176](../../sources/本地分卷/三国志/三国志-卷003.md#l176)

> 初，洛陽宗廟未成，神主在鄴廟。

洛阳宗庙尚未建成的时候，神主移置或奉设在邺的庙内。

**时段与依据** 本纪“初”概叙229年新庙建成之前，建庙本身自227年始，神主在邺为此前状态；229年第6条宜作背景。

<a id="period-sgz003-b-201-3"></a>

### 孙权遣使通高句骊，欲袭辽东

[《三国志·明帝纪》仓内原文 L201](../../sources/本地分卷/三国志/三国志-卷003.md#l201)

> 初，權遣使浮海與高句驪通，欲襲遼東。

此前孙权派遣使者浮海与高句骊联系，意图袭取辽东。

**时段与依据** 本纪以“初”引毌丘俭讨辽东之前的吴外交。卷047《吴主传》嘉禾二年、五年（233、236）先后使高句骊，L197载236年吴使被斩，未明此句指单轮还是连叙；旧237年第18条不能作为赴使发生年。

<a id="period-sgz003-b-208-3"></a>

### 登女在曹叡末次病中被杀

[《三国志·明帝纪》仓内原文 L208](../../sources/本地分卷/三国志/三国志-卷003.md#l208)

> 及帝疾，飲水無驗，於是殺焉。

到曹叡病重时，饮用她的水没有效果，登女被杀。

**时段与依据** “及帝疾”承L207景初二年十二月患病，止于L209景初三年正月丁亥帝卒。按史书仅能定位238岁末至239正月之间，未给跨年点前后确证。

<a id="period-sgz003-b-210-1"></a>

### 陈寿论曹叡明断与营宫之失

[《三国志·明帝纪》仓内原文 L210](../../sources/本地分卷/三国志/三国志-卷003.md#l210)

> 評曰：明帝沉毅斷識，任心而行，蓋有君人之至槩焉。於時百姓彫弊，四海分崩，不先聿脩顯祖，闡拓洪基，而遽追秦皇、漢武，宮館是營，格之遠猷，其殆疾乎！

陈寿称曹叡深沉刚毅、明识决断，有君主气度；又批评天下分崩、民生困惫时急于仿效秦皇、汉武营造宫室，未先拓展祖业。

**时段与依据** “評曰”是本卷作者对其一朝的总结，借秦始皇、汉武帝指责宫室营建，无单一事件年。

<a id="period-sgz003-p-001-1"></a>

### 曹操器重幼时的曹叡

[《三国志·明帝纪》裴注 001·1](../../sources/本地分卷/三国志/三国志-卷003.md#pei-001-1)

> 魏書曰帝生數歲而有岐嶷之姿武皇帝異之曰我基於爾三世矣每朝宴會同與侍中近臣並列帷幄好學多識特留意於法理

《魏书》说曹叡年仅数岁便显出聪慧，曹操说子孙三世的基业在他身上，往往让他和侍中近臣同列帷幄；曹叡还爱读书，关注法律。

**时段与依据** 童年及反复伴随曹操无具体年，至迟在曹操220年去世以前。“我基於爾三世”是所引对话，不给出处日期。

<a id="period-sgz003-p-002-1"></a>

### 曹丕让郭皇后养曹叡，并曾考虑京兆王

[《三国志·明帝纪》裴注 002·1](../../sources/本地分卷/三国志/三国志-卷003.md#pei-002-1)

> 魏畧曰文帝以郭后無子詔使子養帝帝以母不以道終意甚不平後不獲已乃敬事郭后旦夕因長御問起居郭后亦自以無子遂加慈愛文帝始以帝不悅有意欲以他姬子京兆王為嗣故久不拜太子

《魏略》说曹丕令无子的郭皇后以曹叡为子；曹叡因甄氏死不平，后来不得已问候郭后，郭后对他转而慈爱。曹丕曾有意立另一妃嫔所生的京兆王，因此较晚立曹叡为太子。

**时段与依据** 甄氏死于221年，郭氏立皇后于222年，曹叡立太子在226年。收养、转变态度和另择太子的各次决定未见确年。“京兆王”也可能是追称。

<a id="period-sgz003-p-002-2"></a>

### 猎鹿故事解释曹丕立储之意

[《三国志·明帝纪》裴注 002·2](../../sources/本地分卷/三国志/三国志-卷003.md#pei-002-2)

> 魏末傳曰帝常從文帝獵見子母鹿文帝射殺鹿母使帝射鹿子帝不從曰陛下已殺其母臣不忍復殺其子因涕泣文帝即放弓箭以此深竒之而樹立之意定

《魏末传》说曹丕猎杀母鹿、让曹叡射小鹿，曹叡想起母子关系，含泪拒绝，曹丕由此决定立他为太子。

**时段与依据** 这是另一个文献对立储动机的解释，狩猎没有明确日期，只能置于226年立储之前。

<a id="period-sgz003-p-004-1"></a>

### 孟他以家财结交张让家奴、拜凉州刺史

[《三国志·明帝纪》裴注 004·1](../../sources/本地分卷/三国志/三国志-卷003.md#pei-004-1)

> 三輔決錄曰伯郎涼州人名不令休其注曰伯郎姓孟名他扶風人靈帝時中常侍張讓專朝政讓監奴典䕶家事他仕不遂乃盡以家財賂監奴與共結親積年家業為之破盡衆奴皆慙問他所欲他曰欲得卿曹拜耳奴被恩久皆許諾時賔客求見讓者門下車常數百乘或累日不得通他最後到衆奴伺其至皆迎車而拜徑將他車獨入衆人悉驚謂他與讓善爭以珍物遺他他得之盡以賂讓讓大喜他又以蒲桃酒一斛遺讓即拜涼州刺史

《三辅决录》及其注称孟他字伯郎，扶风人。孟他用尽家财结交张让家奴，家奴假装厚待他，引其他求见者献赠财物。孟他转献张让，又送蒲萄酒而得拜凉州刺史。

**时段与依据** 仅称灵帝在位、张让掌事，未载孟他获任日期。

<a id="period-sgz003-p-004-2"></a>

### 孟达是孟他之子，早年入蜀

[《三国志·明帝纪》裴注 004·2](../../sources/本地分卷/三国志/三国志-卷003.md#pei-004-2)

> 他生達少入蜀其處蜀事迹在劉封傳

孟他生孟达；孟达年轻时入蜀，相关事见《刘封传》。

**时段与依据** 卷040载孟达与法正入蜀过程，注自身“少入蜀”不明是入刘璋幕府哪一年。

<a id="period-sgz003-p-004-6"></a>

### 孟达受曹丕宠遇，与桓阶、夏侯尚善

[《三国志·明帝纪》裴注 004·6](../../sources/本地分卷/三国志/三国志-卷003.md#pei-004-6)

> 達既為文帝所寵又與桓階夏侯尚親善

孟达受曹丕优待，也与桓阶、夏侯尚亲善。

**时段与依据** 这一交往跨曹丕在位数年，本注未给单一时点。

<a id="period-sgz003-p-009-2"></a>

### 郝昭籍贯、早年军历与镇河西

[《三国志·明帝纪》裴注 009·2](../../sources/本地分卷/三国志/三国志-卷003.md#pei-009-2)

> 昭字伯道太原人為人雄壯少入軍為部曲督數有戰功為雜號將軍遂鎮守河西十餘年民夷畏服

郝昭字伯道，太原人。年轻时在军中从部曲督等处任事，积功为杂号将军，镇守河西十余年。

**时段与依据** 注以生平回顾插入陈仓战事。“十餘年”未给起讫，不与228年的陈仓筑城混时。

<a id="period-sgz003-p-009-5"></a>

### 郝昭因守陈仓受爵，受曹叡慰劳后病卒

[《三国志·明帝纪》裴注 009·5](../../sources/本地分卷/三国志/三国志-卷003.md#pei-009-5)

> 詔嘉昭善守賜爵列侯及還帝引見慰勞之顧謂中書令孫資曰卿鄉里乃有爾曹快人為將灼如此朕復何憂乎仍欲大用之會病亡遺令戒其子凱曰吾為將知將不可為也吾數發塚取其木以為攻戰具又知厚葬無益於死者也汝必歛以時服且人生有處所耳死復何在耶今去本墓逺東西南北在汝而已

郝昭获列侯。曹叡召见他，向孙资称许其乡里有良将，打算重用，郝昭却病死，并嘱儿子郝凯从俭殓葬、勿拘故墓。

**时段与依据** 接陈仓战后，至少晚于228年十二月，赏爵、召见、病卒之间年月未明。

<a id="period-sgz003-p-010-4"></a>

### 孙盛以古礼解释迎迁神主

[《三国志·明帝纪》裴注 010·4](../../sources/本地分卷/三国志/三国志-卷003.md#pei-010-4)

> 孫盛曰事亡猶存祭如神在迎遷神主正斯宜矣

孙盛认为死者也应如在世般事奉，祭祀当如神在，迎迁神主合礼。

**时段与依据** 为晋代史论，没有评论成文确年，所评论即229年第7条。

<a id="period-sgz003-p-011-3"></a>

### 裴松之质疑单独设坛受祭

[《三国志·明帝纪》裴注 011·3](../../sources/本地分卷/三国志/三国志-卷003.md#pei-011-3)

> 此雖前代已行故事然為壇以祀天而壇非神也今無事於上帝而致祀於虚壇求之義典未詳所據

裴松之认为祭天之坛是祭祀地点而非神明，单独祭空坛，未见合乎礼义的依据。

**时段与依据** 晋宋间史注的礼议，无单独成文年；讨论230年魏祭坛。

<a id="period-sgz003-p-014-1"></a>

### 秦朗名字、家乡及秦宜禄的前事

[《三国志·明帝纪》裴注 014·1](../../sources/本地分卷/三国志/三国志-卷003.md#pei-014-1)

> 魏氏春秋曰朗字元明新興人獻帝傳曰朗父名宜祿為吕布使詣袁術術妻以漢宗室女其前妻杜氏留下邳

秦朗字元明，新兴人。其父秦宜禄从吕布，出使袁术，袁术为他娶汉宗室女子，其前妻杜氏仍在下邳。

**时段与依据** 秦朗籍贯、婚姻和出使确年无明文。秦宜禄留布与出使仅可定位到吕布下邳败前，不能按注所附秦朗233年返军入年。

<a id="period-sgz003-p-014-5"></a>

### 秦朗随母养于曹操家

[《三国志·明帝纪》裴注 014·5](../../sources/本地分卷/三国志/三国志-卷003.md#pei-014-5)

> 朗随母氏畜于公宫太祖甚愛之每坐席謂賔客曰世有人愛假子如孤者乎魏畧曰朗遊遨諸侯間歴武文之世而無尤也

秦朗随母被养在曹操家中，曹操喜欢他，曾自夸喜爱养子无人能及；《魏略》又说秦朗历曹操、曹丕两代在诸侯间往来，未受责备。

**时段与依据** 曹操接纳杜氏后至两朝，属长时段和逸事，无确年。

<a id="period-sgz003-p-014-7"></a>

### 秦朗在明帝朝亲近获赏，不以直谏著称

[《三国志·明帝纪》裴注 014·7](../../sources/本地分卷/三国志/三国志-卷003.md#pei-014-7)

> 時明帝喜發舉數有以輕微而致大辟者朗終不能有所諫止又未嘗進一善人帝亦以是親愛每顧問之多呼其小字阿蘇數加賞賜為起大第於京城中四方雖知朗無能為益猶以附近至尊多賂遺之富均公侯

《魏略》批评曹叡常因小过处以死刑，秦朗既不谏也不荐贤；曹叡喜爱并以小字阿苏呼他、屡次赐赏，为他建造大宅，各地也向他行贿。

**时段与依据** 注概叙明帝朝宠用与批评，未列一项确年，宫第建造勿混作235年大修行宫。

<a id="period-sgz003-p-014-8"></a>

### 秦秀任晋武帝博士，附秦朗与孔桂的分类

[《三国志·明帝纪》裴注 014·8](../../sources/本地分卷/三国志/三国志-卷003.md#pei-014-8)

> 世語曰朗子秀勁厲能直言為晉武帝博士魏畧以朗與孔桂俱在佞倖篇

《世语》说秦朗的儿子秦秀正直敢言，为晋武帝博士。《魏略》把秦朗与孔桂归入《佞幸篇》。

**时段与依据** 晋武帝在位265至290，秦秀的博士任年本注未记。著作分类也无年。

<a id="period-sgz003-p-014-9"></a>

### 孔桂早年从杨秋通曹，因博弈蹴鞠得宠

[《三国志·明帝纪》裴注 014·9](../../sources/本地分卷/三国志/三国志-卷003.md#pei-014-9)

> 桂字叔林天水人也建安初數為將軍楊秋使詣太祖太祖表拜騎都尉桂性便辟曉博奕蹹鞠故太祖愛之每在左右出入随從桂察太祖意喜樂之時因言次曲有所陳事多見從數得賞賜人多餽遺桂由此侯服玉食

孔桂字叔林，天水人，建安初多次为杨秋出使曹操，被表为骑都尉，擅长博弈、踢球，受曹操信任和赏赐。

**时段与依据** 只有“建安初”范围。卷015杨秋在关中事迹有不同时间，未直载孔桂出使授官确年。

<a id="period-sgz003-p-014-10"></a>

### 孔桂转亲曹植、疏曹丕

[《三国志·明帝纪》裴注 014·10](../../sources/本地分卷/三国志/三国志-卷003.md#pei-014-10)

> 太祖既愛桂五官將及諸侯亦皆親之其後桂見太祖久不立太子而有意於臨菑侯因更親附臨菑侯而簡於五官將將甚衘之

因曹操宠爱孔桂，曹丕和其他诸侯都亲近他。孔桂见曹操久不立太子而有意曹植，便疏远五官将曹丕，使曹丕怀恨。

**时段与依据** 曹丕任五官中郎将及立太子提供211至217范围，差别待遇没有确年。

<a id="period-sgz003-p-014-12"></a>

### 孔桂受西域贿赂而被杀

[《三国志·明帝纪》裴注 014·12](../../sources/本地分卷/三国志/三国志-卷003.md#pei-014-12)

> 而桂私受西域貨賂許為人事事發有詔收問遂殺之

孔桂私收西域货财、许诺代办事情，事发后被诏收问而处死。

**时段与依据** 附220年转官后，注没有发觉、处刑年月，不能据同句硬系同年。

<a id="period-sgz003-p-014-13"></a>

### 鱼豢论佞幸使赏赐失当

[《三国志·明帝纪》裴注 014·13](../../sources/本地分卷/三国志/三国志-卷003.md#pei-014-13)

> 魚豢曰為上者不虚授處下者不虚受然後外無伐檀之歎内無尸素之刺雍熈之美著太平之律顯矣而佞倖之徒但姑息人主至乃無徳而榮無功而祿如是焉得不使中正日朘傾邪滋多乎以武皇帝之慎賞明皇帝之持法而猶有若此等人而况下斯者乎

鱼豢认为爵禄须与德功相应。佞幸凭迎合获得荣禄，会损害公正；武帝、明帝时代尚有其人，遑论后世。

**时段与依据** 《魏略》编者史论，无单一事件日年。

<a id="period-sgz003-p-015-1"></a>

### 毕轨送自称年高的鲜卑奴

[《三国志·明帝纪》裴注 015·1](../../sources/本地分卷/三国志/三国志-卷003.md#pei-015-1)

《搜神记》追溯汉元帝、成帝时的谶言，又说张掖柳谷石纹在建安间初见、黄初间成形、太和间完备，视作魏晋递代的符命。

### 《汉晋春秋》记氐池石纹的另一形状与后传

[《三国志·明帝纪》裴注 020·4](../../sources/本地分卷/三国志/三国志-卷003.md#pei-020-4)

> 漢晉春秋曰氐池縣大栁谷口夜激波涌溢其聲如雷曉而有蒼石立水中長一丈六尺高八尺白石畫之為十三馬一牛一鳥八卦玉玦之象皆隆起其文曰大討曹適水中甲寅帝惡其討也使鑿去為計以蒼石窒之宿昔而白石滿焉至晉初其文愈明馬象皆煥徹如玉焉

《汉晋春秋》说氐池大柳谷口夜里波涌，天明水中有苍石，纹样如马、牛、鸟和八卦等；皇帝厌恶其中“討”字，令人凿埋，故事又说晋初纹象越发清楚。

**时段与依据** 同一祥瑞叙事的异本，虽随本注235年报道可互参，但本说难以精确限定发现、凿石和“晉初”显纹日期。

### 裴松之解释景初服牲旗制的古礼

[《三国志·明帝纪》裴注 023·1](../../sources/本地分卷/三国志/三国志-卷003.md#pei-023-1)

> 臣松之按魏為土行故服色尚黄行殷之時以建丑為正故犧牲旌旗一用殷禮禮記云夏后氏尚黑故戎事乘驪牲用玄殷人尚白戎事乘翰牲用白周人尚赤戎事乘騵牲用騂鄭玄云夏后氏以建寅為正物生色黑殷以建丑為正物牙色白周以建子為正物萌色赤翰白色馬也易曰白馬翰如周禮巾車職建大赤以朝大白以即戎此則周以正色之旗以朝先代之旗即戎今魏用殷禮變周之制故建大白以朝大赤即戎

裴松之说魏自认为土德，色尚黄而用建丑之正，戎马、牲色及旗帜多参考殷、周之礼，并援《礼记》、郑玄、《易》《周礼》说明朝会用白旗、军事用赤旗的缘由。

### 裴松之据受纳时间、改历推曹叡生年和享年

[《三国志·明帝纪》裴注 034·2](../../sources/本地分卷/三国志/三国志-卷003.md#pei-034-2)

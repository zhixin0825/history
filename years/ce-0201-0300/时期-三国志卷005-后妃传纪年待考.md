## 《后妃传》跨年及未定年材料

<a id="period-sgz005-b-300-1"></a>

### 后妃制度序论

[《三国志·后妃传》仓内原文 L300](../../拆分史书/三国志/卷005.md#l300)

陈寿用《周易》内外之分说明后妃制度的意义，举舜、周、春秋礼说，批评后世妃嫔过多、以色为尚。

**时段与依据** 经义、历代典例和史臣总论均无本卷独立纪年，各时代不得并入一岁。

<a id="wei005-l3-1"></a>

**[《三國志·后妃傳》正文](../../拆分史书/三国志/卷005.md#edition-wei005-l3-1)** · [TXT L3](../../拆分史书/三国志/卷005.txt#L3)

> 易稱「男正位乎外，女正位乎內；男女正，天地之大義也」。古先哲王，莫不明后妃之制，順天地之德，故二妃嬪媯，虞道克隆，任、姒配姬，周室用熈，廢興存亡，恒此之由。春秋說云天子十二女，諸侯九女，考之情理，不易之典也。而末世奢縱，肆其侈欲，至使男女怨曠，感動和氣，惟色是崇，不本淑懿，故風教陵遲而大綱毀泯，豈不惜哉！嗚呼，有國有家者，其可以永鑒矣！

**釋讀與歸年** 序以《易》男女内外分位、虞周婚配为鉴，并引《春秋》说论统治者婚制，批评后世奢纵。这是陈寿总论，涉及的先代例证没有可系的个别年份。

<a id="period-sgz005-b-301-1"></a>

### 汉代后妃称号和内官等第

[《三国志·后妃传》仓内原文 L301](../../拆分史书/三国志/卷005.md#l301)

汉朝称帝祖母为太皇太后、母为皇太后、正妻为皇后，内官另有十四等。

**时段与依据** 制度通叙。十四等沿革另见《汉书·外戚传》，本条无始制年。

<a id="wei005-l5-1"></a>

**[《三國志·后妃傳》正文](../../拆分史书/三国志/卷005.md#edition-wei005-l5-1)** · [TXT L5](../../拆分史书/三国志/卷005.txt#L5)

> 漢制，帝祖母曰太皇太后，帝母曰皇太后，帝妃曰皇后，其餘內官十有四等。

**釋讀與歸年** 序列汉制中太皇太后、皇太后、皇后名号及内官十四等，为下文沿革的制度背景。

<a id="period-sgz005-b-301-2"></a>

### 魏沿用汉后妃称号

[《三国志·后妃传》仓内原文 L301](../../拆分史书/三国志/卷005.md#l301)

魏沿用母后称号，夫人以下历朝有增减。

**时段与依据** 三世制度概述，不指定某次诏令。

<a id="wei005-l5-2"></a>

**[《三國志·后妃傳》正文](../../拆分史书/三国志/卷005.md#edition-wei005-l5-2)** · [TXT L5](../../拆分史书/三国志/卷005.txt#L5)

> 魏因漢法，母后之號皆如舊制，自夫人以下，世有增損。

**釋讀與歸年** 曹魏沿汉制称母后，夫人以下历朝有所增减；总述制度，具体施行见下各段。

### 魏文帝增置内官

[《三国志·后妃传》仓内原文 L301](../../拆分史书/三国志/卷005.md#l301)

曹丕增加贵嫔、淑媛、脩容、顺成和良人五等。

**时段与依据** 220—226曹丕在位期间的沿革，何年首置诸号未记。

<a id="wei005-l5-4"></a>

**[《三國志·后妃傳》正文](../../拆分史书/三国志/卷005.md#edition-wei005-l5-4)** · [TXT L5](../../拆分史书/三国志/卷005.txt#L5)

> 文帝增貴嬪、淑媛、脩容、順成、良人。

**釋讀與歸年** 曹丕在位时增设贵嫔、淑媛、脩容、顺成、良人，各品设立年份未详。

<a id="period-sgz005-b-301-5"></a>

### 魏明帝增减内官

[《三国志·后妃传》仓内原文 L301](../../拆分史书/三国志/卷005.md#l301)

曹叡增加淑妃、昭华、脩仪，取消顺成；太和年间恢复夫人，使其位在淑妃之上。

**时段与依据** 明帝在位226—239。恢复夫人在太和年间227—233年初，细年未载。

<a id="wei005-l5-5"></a>

**[《三國志·后妃傳》正文](../../拆分史书/三国志/卷005.md#edition-wei005-l5-5)** · [TXT L5](../../拆分史书/三国志/卷005.txt#L5)

> 明帝增淑妃、昭華、脩儀；除順成官。太和中始復命夫人，登其位於淑妃之上。

**釋讀與歸年** 曹叡增淑妃、昭华、脩仪，撤顺成，确年未载。太和年间（227年至233年初）恢复夫人，位列淑妃之上，具体年份未载。

<a id="period-sgz005-b-302-1"></a>

### 魏后宫十二等的秩禄或比爵

[《三国志·后妃传》仓内原文 L302](../../拆分史书/三国志/卷005.md#l302)

贵嫔和夫人位次皇后。淑妃比诸侯王，以下依次比县公、县侯、乡侯、亭侯、关内侯或各等俸秩。

**时段与依据** 制度名目表，沿本文前述曹魏多次调整，无单独施行年。

<a id="wei005-l5-6"></a>

**[《三國志·后妃傳》正文](../../拆分史书/三国志/卷005.md#edition-wei005-l5-6)** · [TXT L5](../../拆分史书/三国志/卷005.txt#L5)

> 自夫人以下爵凡十二等：貴嬪、夫人，位次皇后，爵無所視；淑妃位視相國，爵比諸侯王；淑媛位視御史大夫，爵比縣公；昭儀比縣侯；昭華比鄉侯；脩容比亭侯；脩儀比關內侯；倢伃視中二千石；容華視真二千石；美人視比二千石；良人視千石。

**釋讀與歸年** 这十二等是序总结的曹魏后宫品秩，原文以相国、御史大夫、各级封爵及俸秩标其等序；各等不同阶段的变更已经在前文交代。

### 丁氏离去，卞氏为继室、抚养诸子

[《三国志·后妃传》仓内原文 L304](../../拆分史书/三国志/卷005.md#l304)

丁夫人离去后，卞氏成为继室。曹操令她抚养没有母亲的诸子。

**时段与依据** 只称建安初，裴注把丁氏离去与曹昂战死（197）相连，未标死后何年正式更立继室。

<a id="wei005-l11-3"></a>

**[《三國志·后妃傳》正文](../../拆分史书/三国志/卷005.md#edition-wei005-l11-3)** · [TXT L11](../../拆分史书/三国志/卷005.txt#L11)

> 建安初，丁夫人廢，遂以后爲繼室。諸子無母者，太祖皆令后養之。

**釋讀與歸年** 丁夫人离去后，卞氏成为继室，并奉曹操之命抚育诸丧母子。依裴注，丁氏被遣缘于曹昂在197年战死；正式废立与诸子交养无确年。

### 甄氏世系、失父和赈济宗族

[《三国志·后妃传》仓内原文 L309](../../拆分史书/三国志/卷005.md#l309)

甄氏出自中山无极世宦之家，父甄逸任上蔡令，甄氏三岁丧父。天下乱且饥，家中买金玉，甄氏十余岁劝以粮食救助家族邻里，全家听从。

**时段与依据** 据注载182年末生，三岁和十余岁只能推阶段。父卒及赈济年月未见，不随生年。

<a id="wei005-l31-1"></a>

**[《三國志·后妃傳》正文](../../拆分史书/三国志/卷005.md#edition-wei005-l31-1)** · [TXT L31](../../拆分史书/三国志/卷005.txt#L31)

> 文昭甄皇后，中山無極人，明帝母，漢太保甄邯後也，世吏二千石。父逸，上蔡令。后三歲失父。

**釋讀與歸年** 甄氏为中山无极人，父甄逸任上蔡令。传称她三岁丧父，实岁、虚岁的口径未明，父卒没有独立日期。

<a id="wei005-l33-1"></a>

**[《三國志·后妃傳》正文](../../拆分史书/三国志/卷005.md#edition-wei005-l33-1)** · [TXT L33](../../拆分史书/三国志/卷005.txt#L33)

> 後天下兵亂，加以饑饉，百姓皆賣金銀珠玉寶物，時后家大有儲穀，頗以買之。后年十餘歲，白母曰：「今世亂而多買寶物，匹夫無罪，懷璧爲罪。又左右皆饑乏，不如以穀振給親族鄰里，廣爲恩惠也。」舉家稱善，即從后言。

**釋讀與歸年** 甄氏十余岁时逢战乱饥荒，劝家人将余粮分给亲邻。没有具体战事或灾年可供互证。

### 汉献帝之女入魏后宫，甄氏失宠

[《三国志·后妃传》仓内原文 L311](../../拆分史书/三国志/卷005.md#l311)

山阳公献两女入魏后宫，郭氏、李氏和阴氏受宠，甄氏渐遭冷落。

**时段与依据** 本传仅称践阼后。纳女与失宠处于220称帝至221六月之间，作为相关背景，具体年月未定。

<a id="wei005-l38-4"></a>

**[《三國志·后妃傳》正文](../../拆分史书/三国志/卷005.md#edition-wei005-l38-4)** · [TXT L38](../../拆分史书/三国志/卷005.txt#L38)

<a id="period-sgz005-b-315-1"></a>

### 曹叡厚待甄畅、为甄像母设观庙

<a id="wei005-l12-3"></a>

**[《三國志·后妃傳》裴注](../../拆分史书/三国志/卷005.md#edition-wei005-l12-3)** · [TXT L12](../../拆分史书/三国志/卷005.txt#L12)

**时段与依据** 只给十四岁，依光和五年生年虚岁推约195年前后，未独证公元年；另可参甄俨234年获追谥。

**[《三國志·后妃傳》裴注](../../拆分史书/三国志/卷005.md#edition-wei005-l34-1)** · [TXT L34](../../拆分史书/三国志/卷005.txt#L34)

<a id="wei005-l37-3"></a>

**[《三國志·后妃傳》裴注](../../拆分史书/三国志/卷005.md#edition-wei005-l37-3)** · [TXT L37](../../拆分史书/三国志/卷005.txt#L37)

### 郭后调护后宫与侍奉太后

[《三国志·后妃传》裴注 021·2](../../拆分史书/三国志/卷005.md#pei-021-2)

**时段与依据** 从东宫至立后后有长时范围，各事未具年月；该官书评价可和其他注文互校。

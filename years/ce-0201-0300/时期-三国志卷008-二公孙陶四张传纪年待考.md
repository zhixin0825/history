## 引文与纪年

### 公孙瓒籍贯、师从卢植

[《三国志·二公孙陶四张传》仓内原文 L402](../../sources/本地分卷/三国志/三国志-卷008.md#l402)

> 公孫瓚字伯珪，遼西令支人也。為郡門下書佐。有姿儀，大音聲，侯太守器之，以女妻焉，遣詣涿郡盧植讀經。

公孙瓒是辽西令支人，做郡门下书佐。太守见重，给他女儿为妻，并遣他去涿郡随卢植学经。

**时段与依据** 早年无年记。此“侯太守”的姓及与后任刘太守区别照原文。

<a id="period-sgz008-b-402-2"></a>

### 公孙瓒护送刘太守、北邙辞祖

[《三国志·二公孙陶四张传》仓内原文 L402](../../sources/本地分卷/三国志/三国志-卷008.md#l402)

> 後復為郡吏。劉太守坐事徵詣廷尉，瓚為御車，身執徒養。及劉徙日南，瓚具米肉，於北芒上祭先人，舉觴祝曰：「昔為人子，今為人臣，當詣日南。日南瘴氣，或恐不還，與先人辭於此。」再拜慷慨而起，時見者莫不歔欷。劉道得赦還。

刘太守被征至廷尉，公孙瓒为他驾车照料。听说刘要流徙日南，公孙瓒取酒肉祭别祖先，准备同行；刘途中遇赦。

**时段与依据** “後”“及”仅说明先后，太守征案年份未载。

<a id="period-sgz008-b-402-3"></a>

### 公孙瓒任辽东属国长史、经历边塞遇敌

[《三国志·二公孙陶四张传》仓内原文 L402](../../sources/本地分卷/三国志/三国志-卷008.md#l402)

> 瓚以孝廉為郎，除遼東屬國長史。嘗從數十騎出行塞，見鮮卑數百騎，瓚乃退入空亭中，約其從騎曰：「今不沖之，則死盡矣。」瓚乃自持矛，兩頭施刃，馳出刺胡，殺傷數十人，亦亡其從騎半，遂得免。鮮卑懲艾，後不敢復入塞。遷為涿令。

被举孝廉后任郎和辽东属国长史，出塞遇数百鲜卑骑，退入空亭后率部突击得脱，再迁涿令。

**时段与依据** 官历与轶事均在讨张纯之前，俱无可确的年次；《后汉书》参读。

<a id="period-sgz008-b-402-4"></a>

### 汉调幽州骑兵赴凉州

[《三国志·二公孙陶四张传》仓内原文 L402](../../sources/本地分卷/三国志/三国志-卷008.md#l402)

> 光和中，涼州賊起，發幽州突騎三千人，假瓚都督行事傳，使將之。

朝廷调幽州突骑三千，授公孙瓒临时都督的行事传符，命他统率。

**时段与依据** 本传称“光和中”，同时与紧跟的187年张纯起兵不同年段；《后汉书·公孙瓒传》系于中平年间张温西讨，实月无载。

<a id="period-sgz008-b-402-7"></a>

### 贪至王降附、公孙瓒屯属国多年

[《三国志·二公孙陶四张传》仓内原文 L402](../../sources/本地分卷/三国志/三国志-卷008.md#l402)

> 屬國烏丸貪至王率種人詣瓚降。遷中郎將，封都亭侯，進屯屬國，與胡相攻擊五六年。

乌丸贪至王率部归降，公孙瓒升中郎将、受封都亭侯，屯属国与边地各部争战多年。

**时段与依据** 本传以五六年综记；《后汉书》记先后略有不同，升迁、封侯、降附无独立确年。

篇中转述刘虞行事。

**时段与依据** 分节题，无事件年份。

<a id="period-sgz008-b-408-3"></a>

### 公孙瓒返蓟并筑小城防刘虞

[《三国志·二公孙陶四张传》仓内原文 L408](../../sources/本地分卷/三国志/三国志-卷008.md#l408)

> 與範俱還薊，於大城東南築小城，與虞相近，稍相恨望。

公孙瓒与公孙范返回蓟，在城东南筑小城，与刘虞互相怨望。

**时段与依据** 班师后的宿怨持续至193年，筑城无独立年月；《后汉书·刘虞传》也只记前后。

<a id="period-sgz008-b-409-3"></a>

### 传记批评公孙瓒杀刘虞后行事

[《三国志·二公孙陶四张传》仓内原文 L409](../../sources/本地分卷/三国志/三国志-卷008.md#l409)

> 瓚遂驕矜，記過忘善，多所賊害。

作者说公孙瓒遂骄横，爱记过而忘记别人的好处，对多人加害。

**时段与依据** 总叙其一时期表现，不当作某年个案。

<a id="period-sgz008-b-409-6"></a>

### 公孙瓒备易京壕楼储粮、等待袁绍自疲

[《三国志·二公孙陶四张传》仓内原文 L409](../../sources/本地分卷/三国志/三国志-卷008.md#l409)

> 為圍塹十重，於塹裡築京，皆高五六丈，為樓其上；中塹為京，特高十丈，自居焉，積穀三百萬斛。瓚曰：「昔謂天下事可指麾而定，今日視之，非我所決，不如休兵，力田畜谷。兵法，百樓不攻。今吾樓櫓千重，食盡此谷，足知天下之事矣。」欲以此弊紹。紹遣將攻之，連年不能拔。

公孙瓒在易京筑多重壕沟高楼，居最高楼，积粮坚守，认为天下大势已无法主导，宁以此疲敝袁绍军；袁军连年未克。

**时段与依据** 自195年进入易京至199年攻破期间；无筑完、谈话确年，三百万斛系原传数字。

<a id="period-sgz008-b-410-1"></a>

### 袁绍书追叙与公孙瓒旧盟及阳城冲突

[《三国志·二公孙陶四张传》仓内原文 L410](../../sources/本地分卷/三国志/三国志-卷008.md#l410)

> 孤與足下，既有前盟舊要，申以討亂之誓，愛過夷、叔，分著丹青，謂為旅力同軌，足踵齊、晉，故解印釋紱，以北帶南，分割膏腴，以奉執事，此非孤赤情之明驗邪？豈寤足下棄烈士之高義，尋禍亡之險蹤，輟而改慮，以好易怨，盜遣士馬，犯暴豫州。始聞甲卒在南，親臨戰陳，懼於飛矢迸流，狂刃橫集，以重足下之禍，徒增孤（子）之咎釁也，故為薦書懇惻，冀可改悔。而足下超然自逸，矜其威詐，謂天罔可吞，豪雄可滅，果令貴弟殞於鋒刃之端。

袁绍自陈两人曾盟誓讨乱、自己割地相助，指责公孙瓒改盟遣兵犯豫州，致其弟在战阵中死。

**时段与依据** 书写在双方历次交锋及麴义结局之后，未标年；此处追叙191年阳城公孙越死。

<a id="period-sgz008-b-410-2"></a>

### 袁绍书追论界桥、龙河战果

[《三国志·二公孙陶四张传》仓内原文 L410](../../sources/本地分卷/三国志/三国志-卷008.md#l410)

> 斯言猶在於耳，而足下曾不尋討禍源，克心罪己，苟欲逞其無疆之怒，不顧逆順之津，匿怨害民，聘於餘躬。遂躍馬控弦，處我疆土，毒遍生民，辜延白骨。孤辭不獲已，以登界橋之役。是時足下兵氣霆震，駿馬電發；僕師徒肇合，機械不嚴，強弱殊科，眾寡異論，假天之助，小戰大克，遂陵躡奔背，因壘館谷，此非天威棐諶，福豐有禮之符表乎？足下志猶未厭，乃復糾合餘燼，率我蛑賊，以焚爇勃海。孤又不獲寧，用及龍河之師。羸兵前誘，大軍未濟，而足下膽破眾散，不鼓而敗，兵眾擾亂，君臣並奔。此又足下之為，非孤之咎也。

袁绍指责公孙瓒不自查而入其地，自己先在界桥以弱胜强，再在所谓龙河用弱兵引诱使对手溃败。

**时段与依据** 界桥、龙河之事参192年《资治通鉴》，该书将龙河和龙凑相参；这封信自身未定年。

<a id="period-sgz008-b-410-3"></a>

### 袁绍书指责公孙瓒反复与各部离心

[《三国志·二公孙陶四张传》仓内原文 L410](../../sources/本地分卷/三国志/三国志-卷008.md#l410)

> 自此以後，禍隙彌深，孤之師旅，不勝其忿，遂至積屍為京，頭顱滿野，愍彼無辜，未嘗不慨然失涕也。後比得足下書，辭意婉約，有改往脩來之言。僕既欣於舊好克復，且愍兆民之不寧，每輒引師南駕，以順簡書。弗盈一時，而北邊羽檄之文，未嘗不至。孤是用痛心疾首，靡所錯情。夫處三軍之帥，當列將之任，宜令怒如嚴霜，喜如時雨，臧否好惡，坦然可觀。而足下二三其德，強弱易謀，急則曲躬，緩則放逸，行無定端，言無質要，為壯士者固若此乎！既乃殘殺老弱，幽土怨，眾叛親離，孑然無黨。又烏丸、濊貊，皆足下同州，僕與之殊俗，各奮迅激怒，爭為鋒銳；又東西鮮卑，舉踵來附。此非孤德所能招，乃足下驅而致之也。夫當荒危之世，處干戈之險，內違同盟之誓，外失戎狄之心，兵興州壤，禍發蕭牆，將以定霸，不亦難乎！

袁绍说兵祸使百姓受害，公孙瓒书信时称修好但随后仍侵边，虐杀群众、失去亲属民众及周边乌丸鲜卑支持。

**时段与依据** 这是袁绍劝降的自述与指控，所举跨年，无信件确年。

<a id="period-sgz008-b-410-4"></a>

### 袁绍书追叙麴义并劝公孙瓒修好

[《三国志·二公孙陶四张传》仓内原文 L410](../../sources/本地分卷/三国志/三国志-卷008.md#l410)

> 前以西山陸梁，出兵平討，會麴義餘殘，畏誅逃命，故遂住大軍，分兵撲盪，此兵孤之前行，乃界橋搴旗拔壘，先登制敵者也。始聞足下鐫金紆紫，命以元帥，謂當因茲奮發，以報孟明之恥，是故戰夫引領，竦望旌旆，怪遂含光匿影，寂爾無聞，卒臻屠滅，相為惜之。夫有平天下之怒，希長世之功，權禦師徒，帶養戎馬，叛者無討，服者不收，威懷並喪，何以立名？今舊京克復，天罔雲補，罪人斯亡，忠幹翼化，華夏儼然，望於穆之作，將戢干戈，放散牛馬，足下獨何守區區之士，保內之廣，甘惡名以速朽，亡令德之久長？壯而籌之，非良策也。宜釋憾除嫌，敦我舊好。若斯言之玷，皇天是聞。

袁绍忆西山出兵、麴义及旧部曾是拔界桥旗的先锋，指责公孙瓒不敢出兵，劝其认清形势、休兵释嫌。

**时段与依据** 原文说“前”，纪年仅能限在易京最后败亡之前，所述多为追叙。

### 公孙度早年家世及公孙琙资助

[《三国志·二公孙陶四张传》仓内原文 L422](../../sources/本地分卷/三国志/三国志-卷008.md#l422)

> 公孫度字升濟，本遼東襄平人也。度父延，避吏居玄菟，任度為郡吏。時玄菟太守公孫琙，子豹，年十八歲，早死。度少時名豹，又與琙子同年，琙見而親愛之，遣就師學，為取妻。

辽东襄平人，父公孙延避官吏居玄菟，公孙度为郡吏，幼名豹；玄菟太守公孙琙因其同名同年而爱之，为他就学娶妻。

**时段与依据** 同一文告，见于太和六年周贺战败后及青龙元年辽东斩吴使前这一时段。

### 东汉末骆曜、张角、张脩创教

[《三国志·二公孙陶四张传》裴注 042·1](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-042-1)

> 典略曰熹平中妖賊大起三輔有駱燿光和中東方有張角漢中有張脩駱燿教民緬匿法角為太平道脩為五斗米道

《典略》述熹平中三辅骆曜及光和中东部张角、汉中张脩各有教法，张角为太平道，张脩为五斗米道。

**时段与依据** 注以熹平、光和为时代范围，未逐人标明创教之年。

### 《典略》记太平道为病者行法

[《三国志·二公孙陶四张传》裴注 042·2](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-042-2)

> 太平道者師持九節杖為符祝教病人叩頭思過因以符水飲之得病或日淺而愈者則云此人信道其或不愈則為不信道

太平道之师执九节杖，为患病者祝祷，教叩头思过及饮符水，解释病愈与否为信或不信道。

**时段与依据** 教法无单年；《后汉书·皇甫嵩传》也记张角以符水和叩头认过施教。

<a id="period-sgz008-p-042-3"></a>

### 《典略》记张脩静室、祭酒及三官手书

[《三国志·二公孙陶四张传》裴注 042·3](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-042-3)

> 脩法略與角同加施静室使病者處其中思過又使人為姦令祭酒祭酒主以老子五千文使都習號為姦令為鬼吏主為病者請禱請禱之法書病人姓名説服罪之意作三通其一上之天著山上其一埋之地其一沉之水謂之三官手書使病者家出米五斗以為常故號曰五斗米師實無益于治病但為淫妄然小人昏愚競共事之

张脩令病人居静室思过，以祭酒教习《老子》、为患者祈祷，将手书分别置山上、埋地中或沉水中，又令患者家交五斗米。

**时段与依据** 教法形成与变行无确年，贬抑用语出自《典略》作者。

### 《典略》记张脩后来亦亡

[《三国志·二公孙陶四张传》裴注 042·5](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-042-5)

> 脩亦亡

《典略》在张角之后说张脩亦亡，没有给出先后年距。

**时段与依据** 本传记张鲁杀张脩，刘焉《传》记二人出兵攻汉中，出兵、张脩死的各自具体年有歧异，不能照搬张角死年。

### 张鲁在汉中继承张脩教法及推行义舍

[《三国志·二公孙陶四张传》裴注 042·6](../../sources/摘录/三国志-卷008-二公孙陶四张传裴注.md#pei-042-6)

> 及魯在漢中因其民信行脩業遂増飾之教使作義舍以米肉置其中以止行人又教使自隐有小過者當治道百步則罪除又依月令春夏禁殺又禁酒流移寄在其地者不敢不奉

张鲁在汉中增益原有教法，令作义舍供米肉、使轻罪者修路百步抵罚，春夏禁杀，又禁酒，境内流寓者也遵行。

**时段与依据** 张鲁长期治汉中的制度，未标创制诸年的先后。

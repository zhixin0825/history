### 夏侯惇姓名与宗族

[《三国志·诸夏侯曹传》仓内原文 L445](../../拆分史书/三国志/卷009.md#l445)

夏侯惇字元让，是沛国谯人，传称汉初夏侯婴的后裔。

**时段与依据** 世系总叙，无夏侯惇出生年。

<a id="wei009-l5-1"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l5-1)** · [TXT L5](../../拆分史书/三国志/卷009.txt#L5)

> 夏侯惇字元讓，沛國譙人，夏侯嬰之後也。

**釋讀與歸年** 夏侯惇字元让，沛国谯人，汉初夏侯婴的后人。

### 夏侯惇十四岁杀辱师者

[《三国志·诸夏侯曹传》仓内原文 L445](../../拆分史书/三国志/卷009.md#l445)

夏侯惇十四岁求学，有人侮辱他的老师，他杀死那人，以性情刚烈闻名。

**时段与依据** 只记年龄，无可据以换算的生年。

<a id="wei009-l5-2"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l5-2)** · [TXT L5](../../拆分史书/三国志/卷009.txt#L5)

> 年十四，就師學，人有辱其師者，惇殺之，由是以烈氣聞。

**釋讀與歸年** 夏侯惇十四岁随师学习，为老师受辱而杀人，因而以性烈闻名。只有岁数，无可据以换算出生或事发之年。

<a id="period-sgz009-b-445-5"></a>

### 夏侯惇迁折冲校尉、领东郡

[《三国志·诸夏侯曹传》仓内原文 L445](../../拆分史书/三国志/卷009.md#l445)

夏侯惇升折冲校尉、领东郡太守。

**时段与依据** 卷001 L17记曹操初平二年任东郡；卷010 L504明确194年夏侯惇已经领东郡，无任命年月。

<a id="wei009-l5-5"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l5-5)** · [TXT L5](../../拆分史书/三国志/卷009.txt#L5)

> 遷折衝校尉，領東郡太守。

**釋讀與歸年** 此后夏侯惇迁折冲校尉、领东郡太守。《夏侯惇传》无确年，[《后汉书·荀彧传》](../../史书/003-后汉书/后汉书-CCDH.txt#L5089)兴平元年兖州事中已称他为东郡太守。

<a id="period-sgz009-b-446-2"></a>

### 夏侯惇领陈留济阴，加建武将军

[《三国志·诸夏侯曹传》仓内原文 L446](../../拆分史书/三国志/卷009.md#l446)

夏侯惇复领陈留和济阴太守，加建武将军，封高安乡侯。

**时段与依据** 本传记在左目伤后，不明连贯任命的确年。

<a id="wei009-l10-1"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l10-1)** · [TXT L10](../../拆分史书/三国志/卷009.txt#L10)

> 復領陳留、濟陰太守，加建武將軍，封高安鄉侯。

**釋讀與歸年** 夏侯惇后来领陈留、濟阴太守，进建武将军，封高安乡侯。传文接伤目，确切授任年月未载。

<a id="period-sgz009-b-446-3"></a>

### 夏侯惇筑陂并劝种稻

[《三国志·诸夏侯曹传》仓内原文 L446](../../拆分史书/三国志/卷009.md#l446)

大旱蝗起，夏侯惇截太寿水筑陂，亲自负土，带将士教种稻，百姓获益。

**时段与依据** 兴平元年兖州及建安初皆有旱蝗，本传未注明作陂年月。

<a id="wei009-l10-2"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l10-2)** · [TXT L10](../../拆分史书/三国志/卷009.txt#L10)

> 時大旱，蝗蟲起，惇乃斷太壽水作陂，身自負土，率將士勸種稻，民賴其利。

**釋讀與歸年** 逢旱蝗，夏侯惇截太寿水筑陂，自己背土，领将士劝民种稻。传文连于他任陈留、济阴太守后，取水、筑成日期均无明载。

<a id="period-sgz009-b-446-4"></a>

### 夏侯惇转领河南尹

[《三国志·诸夏侯曹传》仓内原文 L446](../../拆分史书/三国志/卷009.md#l446)

夏侯惇转领河南尹。

**时段与依据** 下接邺平后仍领尹，受职至迟204年前，确年未载。

<a id="wei009-l10-3"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l10-3)** · [TXT L10](../../拆分史书/三国志/卷009.txt#L10)

> 轉領河南尹。

**釋讀與歸年** 夏侯惇后来转领河南尹。下文说邺破后仍领尹，故授任在204年邺城陷落之前。

<a id="period-sgz009-b-446-13"></a>

### 夏侯惇督军还寿春后移屯召陵

[《三国志·诸夏侯曹传》仓内原文 L446](../../拆分史书/三国志/卷009.md#l446)

夏侯惇督诸军还寿春，随后徙屯召陵。

**时段与依据** 承219摩陂授官、220三月升大将军前，任期过年边界，移屯缺确日。

<a id="wei009-l12-1"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l12-1)** · [TXT L12](../../拆分史书/三国志/卷009.txt#L12)

> 督諸軍還壽春，徙屯召陵。

**釋讀與歸年** 夏侯惇后来督各军还寿春，移屯召陵。传列在任前将军后、曹丕进拜大将军前，即219年末至220年初之间，未明两次移营确年。

<a id="period-sgz009-b-447-1"></a>

### 夏侯惇从师、俭朴与施财

[《三国志·诸夏侯曹传》仓内原文 L447](../../拆分史书/三国志/卷009.md#l447)

夏侯惇在军中也请师受业，生活俭朴，有余便分赠，短缺才靠官俸，并未置产业。

**时段与依据** 传末概述生平习尚。

<a id="wei009-l14-1"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l14-1)** · [TXT L14](../../拆分史书/三国志/卷009.txt#L14)

> 惇雖在軍旅，親迎師受業。性清儉，有餘財輒以分施，不足資之於官，不治產業。

**釋讀與歸年** 夏侯惇在军中迎师受业，为人俭朴，财有余则分给他人，不足则取给官府，不营产业。是长期行状。

<a id="period-sgz009-b-447-3"></a>

### 魏帝追念夏侯惇，封七子二孙

[《三国志·诸夏侯曹传》仓内原文 L447](../../拆分史书/三国志/卷009.md#l447)

帝念其功，分其食邑一千户，封七子二孙皆为关内侯。

**时段与依据** 本传在薨后记帝追思，未明诏年。

<a id="wei009-l14-3"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l14-3)** · [TXT L14](../../拆分史书/三国志/卷009.txt#L14)

> 帝追思惇功，欲使子孫畢侯，分惇邑千戶，賜惇七子二孫爵皆關內侯。

**釋讀與歸年** 曹丕追念夏侯惇功劳，从他食邑分千户，封七子二孙为关内侯。本传接卒谥而言，未明分封在卒年还是稍后。

### 韩浩与史涣官历

[《三国志·诸夏侯曹传》仓内原文 L449](../../拆分史书/三国志/卷009.md#l449)

韩浩是河内人，沛国史涣与他同以忠勇显名，分别官至中护军和中领军，都掌禁兵、封列侯。

**时段与依据** 本句总叙，韩浩改中护军细见建安十二年裴注，史涣拜中领军未得确年。

<a id="wei009-l19-1"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l19-1)** · [TXT L19](../../拆分史书/三国志/卷009.txt#L19)

**釋讀與歸年** 韩浩是河内人，史涣是沛国人，皆因忠勇著称。韩浩官至中护军，史涣官至中领军，均掌禁兵，封列侯。具体封爵时间未载。

[《三国志·诸夏侯曹传》仓内原文 L451](../../拆分史书/三国志/卷009.md#l451)

夏侯渊字妙才，是夏侯惇族弟；曹操居家时曾卷入官司，夏侯渊替他承担重罪，曹操设法救免。

**时段与依据** 事在曹操起兵之前，传不载何年。

<a id="wei009-l24-1"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l24-1)** · [TXT L24](../../拆分史书/三国志/卷009.txt#L24)

**釋讀與歸年** 夏侯渊字妙才，为夏侯惇族弟。曹操未起兵时牵涉官司，夏侯渊替他负重罪，曹操设法救免他。原传只说曹操居家时。

曹肇有才识，官散骑常侍、屯骑校尉。

> 肇有當世才度，爲散騎常侍、屯騎校尉。

**釋讀與歸年** 曹肇有才干，曾任散骑常侍、屯骑校尉；后职是明帝病重时所任，初授年月未载。

### 曹肇正始中卒，子曹兴嗣

[《三国志·诸夏侯曹传》仓内原文 L471](../../拆分史书/三国志/卷009.md#l471)

曹肇正始中去世，追赠卫将军，子曹兴嗣侯。

**时段与依据** 只说“正始中”，240–249之间。

<a id="wei009-l108-3"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l108-3)** · [TXT L108](../../拆分史书/三国志/卷009.txt#L108)

> 正始中薨。追贈衞將軍。子興嗣。

**釋讀與歸年** 曹肇死于正始年间，追赠卫将军，子曹兴袭爵。此年号跨240至249年，确年未载。

### 曹丕分曹休封户，封曹纂列侯

[《三国志·诸夏侯曹传》仓内原文 L471](../../拆分史书/三国志/卷009.md#l471)

曹丕分曹休食户三百给曹肇弟曹纂列侯之封。

**时段与依据** 曹丕在位时，未给年份。

<a id="wei009-l108-4"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l108-4)** · [TXT L108](../../拆分史书/三国志/卷009.txt#L108)

> 初，文帝分休戶三百封肇弟纂爲列侯，

**釋讀與歸年** 曹丕曾从曹休封户分三百户，封曹肇弟曹纂为列侯。此为曹肇死后承接的前事，具体年未载。

## 曹休任中领军

<a id="wei009-l102-1"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l102-1)** · [TXT L102](../../拆分史书/三国志/卷009.txt#L102)

> 太祖拔漢中，諸軍還長安，拜休中領軍。

**釋讀與歸年** 曹休传与[《晋书·职官志》](../../史书/005-晋书/晋书-CCDH.txt#L3609)均把授中领军接在曹操取得汉中、军还长安后，未载某年。[《三国志·武帝纪》](../../拆分史书/三国志/卷001.txt#L268-L271)记建安二十冬取得汉中后曹操自南郑还、次年春至邺；[《三国志·武帝纪》](../../拆分史书/三国志/卷001.txt#L297-L299)另记建安二十四年与刘备争汉中不利、还长安。取得和撤出是两次军情，不能把本句据后一次纪年断定为219年。

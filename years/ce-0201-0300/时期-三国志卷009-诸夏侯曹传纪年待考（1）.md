## 引文与纪年

<a id="period-sgz009-b-445-1"></a>

### 夏侯惇姓名与宗族

[《三国志·诸夏侯曹传》仓内原文 L445](../../拆分史书/三国志/卷009.md#l445)

> 夏侯惇字元讓，沛國譙人，夏侯嬰之後也。

夏侯惇字元让，是沛国谯人，传称汉初夏侯婴的后裔。

**时段与依据** 世系总叙，无夏侯惇出生年。

<a id="period-sgz009-b-445-2"></a>

### 夏侯惇十四岁杀辱师者

[《三国志·诸夏侯曹传》仓内原文 L445](../../拆分史书/三国志/卷009.md#l445)

> 年十四，就師學，人有辱其師者，惇殺之，由是以烈氣聞。

夏侯惇十四岁求学，有人侮辱他的老师，他杀死那人，以性情刚烈闻名。

**时段与依据** 只记年龄，无可据以换算的生年。

<a id="period-sgz009-b-445-5"></a>

### 夏侯惇迁折冲校尉、领东郡

[《三国志·诸夏侯曹传》仓内原文 L445](../../拆分史书/三国志/卷009.md#l445)

> 遷折衝校尉，領東郡太守。

夏侯惇升折冲校尉、领东郡太守。

**时段与依据** 卷001 L17记曹操初平二年任东郡；卷010 L504明确194年夏侯惇已经领东郡，无任命年月。

<a id="period-sgz009-b-446-2"></a>

### 夏侯惇领陈留济阴，加建武将军

[《三国志·诸夏侯曹传》仓内原文 L446](../../拆分史书/三国志/卷009.md#l446)

> 復領陳留、濟陰太守，加建武將軍，封高安鄉侯。

夏侯惇复领陈留和济阴太守，加建武将军，封高安乡侯。

**时段与依据** 本传记在左目伤后，不明连贯任命的确年。

<a id="period-sgz009-b-446-3"></a>

### 夏侯惇筑陂并劝种稻

[《三国志·诸夏侯曹传》仓内原文 L446](../../拆分史书/三国志/卷009.md#l446)

> 時大旱，蝗蟲起，惇乃斷太壽水作陂，身自負土，率將士勸種稻，民賴其利。

大旱蝗起，夏侯惇截太寿水筑陂，亲自负土，带将士教种稻，百姓获益。

**时段与依据** 兴平元年兖州及建安初皆有旱蝗，本传未注明作陂年月。

<a id="period-sgz009-b-446-4"></a>

### 夏侯惇转领河南尹

[《三国志·诸夏侯曹传》仓内原文 L446](../../拆分史书/三国志/卷009.md#l446)

> 轉領河南尹。

夏侯惇转领河南尹。

**时段与依据** 下接邺平后仍领尹，受职至迟204年前，确年未载。

<a id="period-sgz009-b-446-13"></a>

### 夏侯惇督军还寿春后移屯召陵

[《三国志·诸夏侯曹传》仓内原文 L446](../../拆分史书/三国志/卷009.md#l446)

> 督諸軍還壽春，徙屯召陵。

夏侯惇督诸军还寿春，随后徙屯召陵。

**时段与依据** 承219摩陂授官、220三月升大将军前，任期过年边界，移屯缺确日。

<a id="period-sgz009-b-447-1"></a>

### 夏侯惇从师、俭朴与施财

[《三国志·诸夏侯曹传》仓内原文 L447](../../拆分史书/三国志/卷009.md#l447)

> 惇雖在軍旅，親迎師受業。性清儉，有餘財輒以分施，不足資之於官，不治產業。

夏侯惇在军中也请师受业，生活俭朴，有余便分赠，短缺才靠官俸，并未置产业。

**时段与依据** 传末概述生平习尚。

<a id="period-sgz009-b-447-3"></a>

### 魏帝追念夏侯惇，封七子二孙

[《三国志·诸夏侯曹传》仓内原文 L447](../../拆分史书/三国志/卷009.md#l447)

> 帝追思惇功，欲使子孫畢侯，分惇邑千戶，賜惇七子二孫爵皆關內侯。

帝念其功，分其食邑一千户，封七子二孙皆为关内侯。

**时段与依据** 本传在薨后记帝追思，未明诏年。

<a id="period-sgz009-b-447-4"></a>

### 夏侯廉和夏侯楙早已封列侯

[《三国志·诸夏侯曹传》仓内原文 L447](../../拆分史书/三国志/卷009.md#l447)

> 惇弟廉及子楙素自封列侯。

夏侯惇的弟弟夏侯廉和儿子夏侯楙原已有列侯爵。

**时段与依据** 未载具体授爵年。

<a id="period-sgz009-b-447-5"></a>

### 夏侯楙娶清河公主

[《三国志·诸夏侯曹传》仓内原文 L447](../../拆分史书/三国志/卷009.md#l447)

> 初，太祖以女妻楙，即清河公主也。

曹操以女清河公主嫁夏侯楙。

**时段与依据** 传仅曰“初”，无婚年。

<a id="period-sgz009-b-447-6"></a>

### 夏侯楙历任侍中尚书及安西镇东将军

[《三国志·诸夏侯曹传》仓内原文 L447](../../拆分史书/三国志/卷009.md#l447)

> 楙歷位侍中尚書、安西鎮東將軍，假節。

夏侯楙历任侍中、尚书、安西将军、镇东将军和假节。

**时段与依据** 正文总叙；《魏略》分明220安西和228还为尚书，其余无任年。

<a id="period-sgz009-b-447-7"></a>

### 夏侯充薨，子夏侯廙嗣侯

[《三国志·诸夏侯曹传》仓内原文 L447](../../拆分史书/三国志/卷009.md#l447)

> 充薨，子廙嗣。

夏侯充去世后，夏侯廙继嗣。

**时段与依据** 本传未载两事之年。

<a id="period-sgz009-b-447-8"></a>

### 夏侯廙薨，子夏侯劭嗣侯

[《三国志·诸夏侯曹传》仓内原文 L447](../../拆分史书/三国志/卷009.md#l447)

> 廙薨，子劭嗣。

夏侯廙去世后，夏侯劭继嗣。

**时段与依据** 本传未纪年；《晋阳秋》另记266夏侯佐死后择近属封夏侯劭，不能据此径定夏侯廙死年。

<a id="period-sgz009-b-448-1"></a>

### 韩浩、史涣分段题

[《三国志·诸夏侯曹传》仓内原文 L448](../../拆分史书/三国志/卷009.md#l448)

> 韓浩、史渙

下叙韩浩和史涣。

**时段与依据** 卷内分节题。

<a id="period-sgz009-b-449-1"></a>

### 韩浩与史涣官历

[《三国志·诸夏侯曹传》仓内原文 L449](../../拆分史书/三国志/卷009.md#l449)

> 韓浩者，河內人。及沛國史渙與浩俱以忠勇顯。浩至中護軍，渙至中領軍，皆掌禁兵，封列侯。

韩浩是河内人，沛国史涣与他同以忠勇显名，分别官至中护军和中领军，都掌禁兵、封列侯。

**时段与依据** 本句总叙，韩浩改中护军细见建安十二年裴注，史涣拜中领军未得确年。

<a id="period-sgz009-b-450-1"></a>

### 夏侯渊分段题

[《三国志·诸夏侯曹传》仓内原文 L450](../../拆分史书/三国志/卷009.md#l450)

> 夏侯淵

下叙夏侯渊传。

**时段与依据** 卷内分节题。

<a id="period-sgz009-b-451-1"></a>

### 夏侯渊姓名宗族及曾为曹操承担罪名

[《三国志·诸夏侯曹传》仓内原文 L451](../../拆分史书/三国志/卷009.md#l451)

> 夏侯淵字妙才，惇族弟也。太祖居家，曾有縣官事，淵代引重罪，太祖營救之，得免。

夏侯渊字妙才，是夏侯惇族弟；曹操居家时曾卷入官司，夏侯渊替他承担重罪，曹操设法救免。

**时段与依据** 事在曹操起兵之前，传不载何年。

<a id="period-sgz009-b-451-3"></a>

### 夏侯渊迁陈留、颍川太守

[《三国志·诸夏侯曹传》仓内原文 L451](../../拆分史书/三国志/卷009.md#l451)

> 遷陳留、潁川太守。

夏侯渊先后任陈留、颍川太守。

**时段与依据** 置于初起与官渡战之间，两任无确年。

<a id="period-sgz009-b-451-6"></a>

### 夏侯渊和于禁讨昌豨

[《三国志·诸夏侯曹传》仓内原文 L451](../../拆分史书/三国志/卷009.md#l451)

> 昌豨反，遣于禁擊之，未拔，復遣淵與禁並力，遂擊豨，降其十餘屯，豨詣禁降。淵還，拜典軍校尉。

昌豨反，于禁先攻未克，夏侯渊受命与他合兵，克十余屯，昌豨降于禁。夏侯渊回来拜典军校尉。

**时段与依据** 这次于禁受降可能对应卷017 L882冀州平后的昌豨复叛、于禁斩昌豨，不能与200曹操击破、201张辽夏侯渊围降合并；本传无年。

<a id="period-sgz009-b-451-7"></a>

### 夏侯渊讨徐和、司马俱等

[《三国志·诸夏侯曹传》仓内原文 L451](../../拆分史书/三国志/卷009.md#l451)

> 濟南、樂安黃巾徐和、司馬俱等攻城，殺長吏，淵將泰山、齊、平原郡兵擊，大破之，斬和，平諸縣，收其糧穀以給軍士。

济南、乐安黄巾攻城杀官；夏侯渊率泰山、齐、平原诸郡兵击破，斩徐和，平诸县，所得粮谷供军。

**时段与依据** 卷018《臧霸》《吕虔》同叙，无主战确年；《后汉书·献帝纪》建安十二年济南王刘赟为黄巾杀，无法确认杀王和徐和被斩在同年。

<a id="period-sgz009-b-452-3"></a>

### 马超围冀城，夏侯渊未及救韦康

[《三国志·诸夏侯曹传》仓内原文 L452](../../拆分史书/三国志/卷009.md#l452)

> 馬超圍涼州刺史韋康於冀，淵救康，未到，康敗。

马超围凉州刺史韦康于冀城，夏侯渊救兵未到，韦康已败。

**时段与依据** 《通鉴》卷066 L503–519系213围冀，《武帝纪》两见（212年九月破凉州杀韦康，213年复害、命夏侯渊讨）；《马超传》从渭南败后即追叙。争议并列。

<a id="period-sgz009-b-452-4"></a>

### 马超迎击夏侯渊，汧氐反，夏侯渊引还

[《三国志·诸夏侯曹传》仓内原文 L452](../../拆分史书/三国志/卷009.md#l452)

> 去冀二百餘里，超來逆戰，軍不利。汧氐反，淵引軍還。

夏侯渊离冀城二百余里，马超迎击，夏侯军失利，汧氐反，夏侯渊撤兵。

**时段与依据** 《通鉴》卷066 L516–520按213年援冀失败后叙。与本传韦康被围的212、213异说相连。

<a id="period-sgz009-b-453-1"></a>

### 宋建自称河首平汉王

[《三国志·诸夏侯曹传》仓内原文 L453](../../拆分史书/三国志/卷009.md#l453)

> 初，枹罕宋建因涼州亂，自號河首平漢王。

宋建趁凉州乱占据枹罕，自称河首平汉王。

**时段与依据** 曹操建安十九年诏说“三十余年”，数为略举，开端年不载。

<a id="period-sgz009-b-453-6"></a>

### 夏侯渊在下辩攻武都氐羌

[《三国志·诸夏侯曹传》仓内原文 L453](../../拆分史书/三国志/卷009.md#l453)

> 還擊武都氐羌下辯，收氐穀十餘萬斛。

夏侯渊回军攻下辩武都氐羌，得谷十余万斛。

**时段与依据** 本传前记216增封，后追述215曹操西征汉中，句次不足独证武都之战是哪年。亦不能混为217–218下辩曹洪拒吴兰。

<a id="period-sgz009-b-453-8"></a>

### 曹操以夏侯渊威名震慑羌胡

[《三国志·诸夏侯曹传》仓内原文 L453](../../拆分史书/三国志/卷009.md#l453)

> 太祖每引見羌、胡，以淵畏之。

曹操接见羌胡时常引夏侯渊使之畏服。

**时段与依据** 承休亭会合及其后数次接见，常态事无单年。

<a id="period-sgz009-b-454-1"></a>

### 曹操戒夏侯渊以智辅勇

[《三国志·诸夏侯曹传》仓内原文 L454](../../拆分史书/三国志/卷009.md#l454)

> 初，淵雖數戰勝，太祖常戒曰：「爲將當有怯弱時，不可但恃勇也。將當以勇爲本，行之以智計；但知任勇，一匹夫敵耳。」

曹操常劝战胜甚多的夏侯渊，不可只靠勇猛，须用智谋，否则只敌一匹夫。

**时段与依据** 本传记常戒，《通鉴》在219定军山之前附叙，未定每一次劝诫。

夏侯渊妻是曹操内妹，长子夏侯衡娶曹操弟海阳哀侯之女，特受恩宠。

> 衡襲爵，轉封安寧亭侯。

夏侯衡承袭父亲爵位，改封安宁亭侯。

**时段与依据** 初袭在219年后，后转封年月未载。

<a id="period-sgz009-b-456-3"></a>

### 黄初、太和分别封夏侯霸兄弟

[《三国志·诸夏侯曹传》仓内原文 L456](../../拆分史书/三国志/卷009.md#l456)

> 黃初中，賜中子霸，太和中，賜霸四弟，爵皆關內侯。

黄初年间封夏侯霸，太和年间封夏侯霸四弟，都是关内侯。

**时段与依据** 黄初220–226、太和227–233，明确分别限年号，各授封年未知。

<a id="period-sgz009-b-456-4"></a>

### 夏侯霸任讨蜀护军右将军，受曹爽厚待

[《三国志·诸夏侯曹传》仓内原文 L456](../../拆分史书/三国志/卷009.md#l456)

> 霸，正始中爲討蜀護軍右將軍，進封博昌亭侯，素爲曹爽所厚。

正始间夏侯霸任讨蜀护军、右将军，进博昌亭侯，原受曹爽厚待。

**时段与依据** 正始240–249，注文又跨说此前为右将军、先后屯陇西；不能尽系一确年。

<a id="period-sgz009-b-456-6"></a>

### 夏侯霸弟威、惠、和的官职

[《三国志·诸夏侯曹传》仓内原文 L456](../../拆分史书/三国志/卷009.md#l456)

> 霸弟威，官至兗州刺史。威弟惠，樂安太守。惠弟和，河南尹。

夏侯威官至兖州刺史，夏侯惠任乐安太守，夏侯和任河南尹。

**时段与依据** 正文及裴注有其官历，任职年月不全。

<a id="period-sgz009-b-456-7"></a>

### 仓本夹注夏侯称幼时率童儿演阵

[《三国志·诸夏侯曹传》仓内原文 L456](../../拆分史书/三国志/卷009.md#l456)

> 曰：「稱字叔權。自孺子而好合聚童兒，爲之渠帥，戲必爲軍旅戰陣之事，有違者輒嚴以鞭捶，眾莫敢逆。

夏侯称字叔权，自小聚童儿操演军阵，自任主帅，严惩违令者。

**时段与依据** 正文底本夹入《世语》所录夏侯湛作序文字，与本卷裴注同见；幼时无年。

<a id="period-sgz009-b-456-8"></a>

### 夏侯称不愿读兵书

[《三国志·诸夏侯曹传》仓内原文 L456](../../拆分史书/三国志/卷009.md#l456)

> 淵陰奇之，使讀《項羽傳》及兵書，不肯，曰：『能則自爲耳，安能學人？』

### 曹休姓名与宗族

[《三国志·诸夏侯曹传》仓内原文 L470](../../拆分史书/三国志/卷009.md#l470)

> 曹休字文烈，太祖族子也。

曹休字文烈，是曹操族子。

**时段与依据** 传首出身，不载生年。

<a id="period-sgz009-b-470-2"></a>

### 曹休少年丧父，奉母渡江

[《三国志·诸夏侯曹传》仓内原文 L470](../../拆分史书/三国志/卷009.md#l470)

> 天下亂，宗族各散去鄉里。休年十餘歲，喪父，獨與一客擔喪假葬，攜將老母，渡江至吳。

战乱使族人离乡，曹休十多岁丧父，与客担送父柩暂葬，带母过江到吴地。

**时段与依据** 年龄与乱世只指阶段。

<a id="period-sgz009-b-470-3"></a>

### 曹休变姓名间行北归，受曹操抚养

[《三国志·诸夏侯曹传》仓内原文 L470](../../拆分史书/三国志/卷009.md#l470)

> 以太祖舉義兵，易姓名轉至荊州，間行北歸，見太祖。太祖謂左右曰：「此吾家千里駒也。」使與文帝同止，見待如子。

闻曹操起兵，曹休改姓名经荆州间行北归，曹操称曹休千里驹，让他与曹丕同住、视若亲子。

**时段与依据** 只因闻起兵后北归而有下限，不载曹休何年到达。

### 曹休领虎豹骑宿卫

[《三国志·诸夏侯曹传》仓内原文 L470](../../拆分史书/三国志/卷009.md#l470)

> 常從征伐，使領虎豹騎宿衛。

曹休时常随军征讨，领虎豹骑警卫。

**时段与依据** 多年习常官历，无单一年。

<a id="period-sgz009-b-470-10"></a>

### 曹休破历阳屯军并焚芜湖营

[《三国志·诸夏侯曹传》仓内原文 L470](../../拆分史书/三国志/卷009.md#l470)

> 孫權遣將屯歷陽，休到，擊破之，又別遣兵渡江，燒賊蕪湖營數千家。

孙权遣将屯历阳，曹休击破，另遣兵过江烧芜湖营数千家。

**时段与依据** 本传系于曹休220获镇南将军之后、222督洞口以前，未有年月。

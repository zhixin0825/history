### 曹真姓名宗族

[《三国志·诸夏侯曹传》仓内原文 L473](../../拆分史书/三国志/卷009.md#l473)

> 曹真字子丹，太祖族子也。

曹真字子丹，是曹操族子。

**时段与依据** 本传的宗属说，与《魏略》本姓秦有异。

<a id="period-sgz009-b-473-3"></a>

### 曹操收养孤幼的曹真

[《三国志·诸夏侯曹传》仓内原文 L473](../../拆分史书/三国志/卷009.md#l473)

> 太祖哀真少孤，收養與諸子同，使與文帝共止。

曹操怜曹真幼年丧父，按儿子一样收养，让他和曹丕一同生活。

**时段与依据** 与曹邵亡紧承，收养年未录。

<a id="period-sgz009-b-473-4"></a>

### 曹真射倒追虎，曹操使将虎豹骑

[《三国志·诸夏侯曹传》仓内原文 L473](../../拆分史书/三国志/卷009.md#l473)

> 常獵，爲虎所逐，顧射虎，應聲而倒。太祖壯其鷙勇，使將虎豹騎。

曹真打猎时被虎追，回射应声使虎倒下，曹操称其勇，让统虎豹骑。

**时段与依据** 魏文帝《典论》佚文提205年在邺西同猎，未明这次遇虎即同游。

<a id="period-sgz009-b-473-5"></a>

### 曹真破灵丘贼，封灵寿亭侯

[《三国志·诸夏侯曹传》仓内原文 L473](../../拆分史书/三国志/卷009.md#l473)

> 討靈丘賊，拔之，封靈壽亭侯。

曹真讨破灵丘的贼众，封灵寿亭侯。

**时段与依据** 本传置下辩攻蜀以前，灵丘之役未另见确年。

<a id="period-sgz009-b-473-15"></a>

### 曹真转中军大将军，加给事中

> 轉拜中軍大將軍，加給事中。

曹真升中军大将军，加给事中。

**时段与依据** 在江陵功后、226受文帝顾命之前，未给确年。

曹真增邑后共两千九百户。

**时段与依据** 本传接于退蜀后，未明确加邑年月。

### 曹真早年和曹遵朱赞同事曹操

曹真少时和同宗曹遵、同乡朱赞一同供事曹操。

**时段与依据** 人物早期关系无确年。

<a id="period-sgz009-b-475-2"></a>

### 曹真乞分食邑给曹遵、朱赞后代

[《三国志·诸夏侯曹传》仓内原文 L475](../../拆分史书/三国志/卷009.md#l475)

> 遵、贊早亡，真愍之，乞分所食邑封遵、贊子。詔曰：「大司馬有叔向撫孤之仁，篤晏平久要之分。君子成人之美，聽分真邑賜遵、贊子爵關內侯，各百戶。」

两人早逝，曹真上奏欲分己邑封其子；魏帝褒真义行，许各为关内侯，食邑百户。

**时段与依据** 诏称曹真大司马，已在230二月至231三月之间，未确哪年。

<a id="period-sgz009-b-475-3"></a>

### 曹真与军士同劳，出私财补赏

[《三国志·诸夏侯曹传》仓内原文 L475](../../拆分史书/三国志/卷009.md#l475)

> 真每征行，與將士同勞苦，軍賞不足，輒以家財班賜，士卒皆原爲用。

曹真从军与人同苦，军赏不足则用家财弥补，因此军士愿为他出力。

**时段与依据** 多次行军作风，不系独年。

曹真病中返回洛阳，魏明帝亲到宅第探视。

**时段与依据** 230撤蜀归后、231三月薨前，未明探视年。

### 曹爽在东宫时期受曹叡亲爱

[《三国志·诸夏侯曹传》仓内原文 L477](../../拆分史书/三国志/卷009.md#l477)

> 爽字昭伯，少以宗室謹重，明帝在東宮，甚親愛之。

曹爽字昭伯，少时谨重，在曹叡待于东宫期间与之亲善。

**时段与依据** 《明帝纪》只载曹叡226临立为太子，传称东宫可泛指即位前，不能把少年交谊系一日。

<a id="period-sgz009-b-477-3"></a>

### 曹爽历迁城门校尉等

[《三国志·诸夏侯曹传》仓内原文 L477](../../拆分史书/三国志/卷009.md#l477)

曹爽从城门校尉加散骑常侍，转武卫将军，受特殊恩宠。

**时段与依据** 官历多段，未见各确年。

<a id="period-sgz009-b-478-1"></a>

### 曹羲曹训曹彦等分掌禁军及侍从

[《三国志·诸夏侯曹传》仓内原文 L478](../../拆分史书/三国志/卷009.md#l478)

> 爽弟羲爲中領軍，訓武衞將軍，彥散騎常侍侍講，其餘諸弟皆以列侯侍從，出入禁闥，貴寵莫盛焉。

曹羲为中领军，曹训为武卫将军，曹彦为散骑常侍侍讲，其他兄弟也以列侯出入宫禁。

**时段与依据** 曹爽辅政始239，高平陵事时已有这些官，正文未给各任命年。

<a id="period-sgz009-b-478-2"></a>

### 魏明帝压抑何晏等浮华名士

[《三国志·诸夏侯曹传》仓内原文 L478](../../拆分史书/三国志/卷009.md#l478)

何晏、邓飏、李胜、丁谧、毕轨都有时名，魏明帝嫌其浮华而压黜。

**时段与依据** 明帝在位时期内发生，部分人有别传，本文合述不硬定一岁。

<a id="period-sgz009-b-478-3"></a>

> 及爽秉政，乃復進敘，任爲腹心。

曹爽秉政后重新起用这些人，作为亲信。

**时段与依据** 范围从239辅政到244伐蜀等人已见任用，未明同年全部擢升。

<a id="period-sgz009-b-479-1"></a>

### 曹爽初以父礼事司马懿

[《三国志·诸夏侯曹传》仓内原文 L479](../../拆分史书/三国志/卷009.md#l479)

曹爽早先因司马懿年高望重，以侍父之礼对他，不敢专断。

**时段与依据** 本传记共同辅政前期；是一段时间的相处。

<a id="period-sgz009-b-479-2"></a>

### 何晏等劝曹爽独权，党人分居要职

[《三国志·诸夏侯曹传》仓内原文 L479](../../拆分史书/三国志/卷009.md#l479)

> 及晏等進用，咸共推戴，說爽以權重不宜委之於人。乃以晏、颺、謐爲尚書，晏典選舉，軌司隷校尉，勝河南尹，諸事希復由宣王。

何晏等得用后推重曹爽，劝勿授权于人，继而何晏、邓飏、丁谧为尚书，毕轨任司隶、李胜任河南尹，事少经司马懿。

**时段与依据** 正始初到247以前的累进，本传未给所有任命月年。

<a id="period-sgz009-b-479-4"></a>

### 何晏等占官田、官物并索求州郡

[《三国志·诸夏侯曹传》仓内原文 L479](../../拆分史书/三国志/卷009.md#l479)

> 晏等專政，共分割洛陽、野王典農部桑田數百頃，及壞湯沐地以爲產業，承勢竊取官物，因緣求欲州郡。有司望風，莫敢忤旨。

何晏等擅政，分洛阳、野王典农桑田数百顷，毁汤沐地营产业，并利用势位取官物、向州郡索求，官吏不敢抗。

**时段与依据** 曹爽专政期多事概叙，未见每件日期。

<a id="period-sgz009-b-479-5"></a>

### 何晏等因盧毓属吏小过收其印绶

[《三国志·诸夏侯曹传》仓内原文 L479](../../拆分史书/三国志/卷009.md#l479)

> 晏等與廷尉盧毓素有不平，因毓吏微過，深文致毓法，使主者先收毓印綬，然後奏聞。其作威如此。

何晏等与廷尉卢毓有隙，借下吏小过重究法律，先收其印后才上奏。

**时段与依据** 卷022《卢毓传》另载丁谧称其持法急、免后为光禄勋，详细年不载。

<a id="period-sgz009-b-479-6"></a>

### 曹爽逾制且取先帝才人、良家子

[《三国志·诸夏侯曹传》仓内原文 L479](../../拆分史书/三国志/卷009.md#l479)

> 爽飲食車服擬於乘輿，尚方珍玩充牣其家，妻妾盈後庭，又私取先帝才人七八人，及將吏、師工、鼓吹、良家子女三十三人，皆以爲伎樂。

曹爽衣食车服比乘舆，家藏珍器，妻妾众多；又私取先帝才人及将吏、良家子弟作乐。

**时段与依据** 曹爽柄权时期的概述；数项不必同年。

<a id="period-sgz009-b-479-7"></a>

### 曹爽诈诏发才人并营窟室聚饮

[《三国志·诸夏侯曹传》仓内原文 L479](../../拆分史书/三国志/卷009.md#l479)

> 詐作詔書，發才人五十七人送鄴臺，使先帝倢伃教習爲伎。擅取太樂樂器、武庫禁兵。作窟室，綺疏四周，數與晏等會其中，飲酒作樂。

曹爽伪造诏书送才人往邺学习伎艺，擅用太乐乐器、武库兵器，营窟室与何晏等聚饮。

**时段与依据** 专政时期合叙，实际年月未载。

<a id="period-sgz009-b-479-8"></a>

### 曹羲屡谏曹爽，著三篇告戒

[《三国志·诸夏侯曹传》仓内原文 L479](../../拆分史书/三国志/卷009.md#l479)

> 羲深以爲大憂，數諫止之。又著書三篇，陳驕淫盈溢之致禍敗，辭旨甚切，不敢斥爽，託戒諸弟以示爽。爽知其爲己發也，甚不恱。羲或時以諫喻不納，涕泣而起。

曹羲以兄长行为为忧，屡谏不纳，作三篇说骄侈会招祸，借戒诸弟给曹爽看，甚至泣谏。

**时段与依据** 《通鉴》卷075 L163–171附叙盛衰，历次劝谏年月未载。

<a id="period-sgz009-b-485-3"></a>

### 仓本夹入裴松之考金乡公主与何晏是否同母

[《三国志·诸夏侯曹传》仓内原文 L485](../../拆分史书/三国志/卷009.md#l485)

> ，沛王出自杜夫人所生。晏母姓尹，公主若與沛王同生，焉得言與晏同母？

沛王是杜夫人所生，何晏母姓尹，裴松之据此质疑公主若是沛王同母，何以又称何晏同母。

**时段与依据** 底本句首多一标点，本段系《魏末传》说的校议，仍逐字保全。

<a id="period-sgz009-b-485-4"></a>

### 夏侯令女寡居，断发以明志

[《三国志·诸夏侯曹传》仓内原文 L485](../../拆分史书/三国志/卷009.md#l485)

> 皇甫謐《烈女傳》曰：爽從弟文叔，妻譙郡夏侯文寧之女，名令女。文叔早死，服闋，自以年少無子，恐家必嫁己，乃斷髮以爲信。

本传底本夹《烈女传》，曹文叔之妻是夏侯文宁女夏侯令女。文叔早亡、服毕后，令女怕被改嫁，断发以表守志。

**时段与依据** 与本卷裴注所存皇甫谧引文平行，前事各未载年。

<a id="period-sgz009-b-485-5"></a>

### 夏侯令女拒绝再嫁，长期依曹爽

[《三国志·诸夏侯曹传》仓内原文 L485](../../拆分史书/三国志/卷009.md#l485)

> 其後，家果欲嫁之，令女聞，即復以刀截兩耳，居止常依爽。

家人果欲再嫁她，令女割两耳拒绝，居住一直依靠曹爽。

**时段与依据** 发生于曹爽249年被诛之前。

<a id="period-sgz009-b-485-7"></a>

**时段与依据** 同封以秦汉旧制为历史论证。

### 夏侯玄议裁郡守留刺史，减费归农

[《三国志·诸夏侯曹传》仓内原文 L492](../../拆分史书/三国志/卷009.md#l492)

> 今之長吏，皆君吏民，橫重以郡守，累以刺史。若郡所攝，唯在大較，則與州同，無爲再重。宜省郡守，但任刺史；刺史職存，則監察不廢，郡吏萬數還親農業，以省煩費，豐財殖穀，一也。

县长以上又有郡守、刺史，监察重复；建议裁郡守而留刺史，使郡吏返农，减开支增收成。

**时段与依据** 为其减省重官第一利。

<a id="period-sgz009-b-492-5"></a>

### 夏侯玄论裁郡能减少文事及意见冲突

[《三国志·诸夏侯曹传》仓内原文 L492](../../拆分史书/三国志/卷009.md#l492)

> 大縣之才，皆堪郡守，是非之訟，每生意異，順從則安，直己則爭。夫和羹之美，在於合異，上下之益，在能相濟，順從乃安，此琴瑟一聲也，蕩而除之，則官省事簡，二也。

大县长官才堪郡守而受多一层长吏管制，持异易争，一味顺从又不能相济，裁撤后可官省事简。

**时段与依据** 为同议第二利。

<a id="period-sgz009-b-492-6"></a>

### 夏侯玄论裁郡能堵地方官徇亲

[《三国志·诸夏侯曹传》仓内原文 L492](../../拆分史书/三国志/卷009.md#l492)

> 又幹郡之吏，職監諸縣，營護黨親，鄉邑舊故，如有不副，而因公掣頓，民之困弊，咎生於此，若皆併合，則亂原自塞，三也。

郡吏监县时易照顾乡亲，借公权掣肘县政。裁并可堵此源。

**时段与依据** 为同议第三利。

<a id="period-sgz009-b-492-7"></a>

### 夏侯玄论裁郡可把好吏派到亲民职位

[《三国志·诸夏侯曹传》仓内原文 L492](../../拆分史书/三国志/卷009.md#l492)

> 今承衰弊，民人彫落，賢才鮮少，任事者寡，郡縣良吏往往非一，郡受縣成，其劇在下，而吏之上選，郡當先足，此爲親民之吏，專得厎下，吏者民命，而常頑鄙，今如並之，吏多選清良者造職，大化宣流，民物獲寧，四也。

贤才稀少，郡督县成而优先用好吏，最亲民的县吏反多不胜任；裁并使好吏直接治民。

**时段与依据** 为同议第四利。

<a id="period-sgz009-b-492-8"></a>

### 夏侯玄提出按户数定官号并以考课进用

[《三国志·诸夏侯曹传》仓内原文 L492](../../拆分史书/三国志/卷009.md#l492)

> 制使萬戶之縣名之郡守，五千以上名之都尉，千戶以下令長如故，自長以上考課遷用，轉以能升，所牧亦增，此進才効功之敘也，若經制一定，則官才有次，治功齊明，五也。

万户县长称郡守，五千以上称都尉，千户以下沿旧。按能力和政绩迁官，使官才各有次序。

**时段与依据** 为同议第五利，系政策建议。

<a id="period-sgz009-b-492-9"></a>

### 夏侯玄总结裁省郡守可使县政直达

[《三国志·诸夏侯曹传》仓内原文 L492](../../拆分史书/三国志/卷009.md#l492)

> 若省郡守，縣皆徑達，事不擁隔，官無留滯，三代之風雖未可必，簡一之化庶幾可致，便民省費在於此矣。」

裁去中间官层，县政直达，少阻滞积压，即使难尽复古也可便民省费。

**时段与依据** 同次书信第二议结尾。

<a id="period-sgz009-b-493-1"></a>

### 夏侯玄以文质变化论应节制奢侈

[《三国志·诸夏侯曹传》仓内原文 L493](../../拆分史书/三国志/卷009.md#l493)

> 又以爲：「文質之更用，猶四時之迭興也，王者體天理物，必因弊而濟通之，時彌質則文之以禮，時泰侈則救之以質。今承百王之末，秦漢餘流，世俗彌文，宜大改之以易民望。

文质交替如四时，治体应对风俗矫弊。承秦汉风尚而日饰，夏侯玄因此主张改度。

**时段与依据** 同封书第三议，问答年月不详。

<a id="period-sgz009-b-493-2"></a>

### 夏侯玄认为服制逾等助长奢靡

[《三国志·诸夏侯曹传》仓内原文 L493](../../拆分史书/三国志/卷009.md#l493)

> 今科制自公、列侯以下，位從大將軍以上，皆得服綾錦、羅綺、紈素、金銀飾鏤之物，自是以下，雜綵之服通於賤人，雖上下等級，各示有差，然朝臣之制已得侔至尊矣，玄黃之采已得通於下矣。欲使市不鬻華麗之色，商不通難得之貨，工不作雕刻之物，不可得也。

朝臣服饰近至尊、彩服通卑贱，车服崇华使农工商难以不经营奢品。

**时段与依据** 同次改服制建议的现状分析。

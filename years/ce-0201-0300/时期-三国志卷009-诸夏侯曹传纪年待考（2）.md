**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l113-1)** · [TXT L113](../../拆分史书/三国志/卷009.txt#L113)

> 曹真字子丹，太祖族子也。

**釋讀與歸年** 曹真字子丹，本传称为曹操族子，裴注《魏略》另记说法，见下。

### 曹操收养孤幼的曹真

[《三国志·诸夏侯曹传》仓内原文 L473](../../拆分史书/三国志/卷009.md#l473)

曹操怜曹真幼年丧父，按儿子一样收养，让他和曹丕一同生活。

**时段与依据** 与曹邵亡紧承，收养年未录。

<a id="wei009-l115-1"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l115-1)** · [TXT L115](../../拆分史书/三国志/卷009.txt#L115)

> 太祖哀真少孤，收養與諸子同，使與文帝共止。

**釋讀與歸年** 曹真少孤，曹操将他和自己的儿子一同抚养，让他与曹丕同住；收养没有独立年次。

<a id="period-sgz009-b-473-4"></a>

### 曹真射倒追虎，曹操使将虎豹骑

[《三国志·诸夏侯曹传》仓内原文 L473](../../拆分史书/三国志/卷009.md#l473)

曹真打猎时被虎追，回射应声使虎倒下，曹操称其勇，让统虎豹骑。

**时段与依据** 魏文帝《典论》佚文提205年在邺西同猎，未明这次遇虎即同游。

<a id="wei009-l115-2"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l115-2)** · [TXT L115](../../拆分史书/三国志/卷009.txt#L115)

> 常獵，爲虎所逐，顧射虎，應聲而倒。太祖壯其鷙勇，使將虎豹騎。

**釋讀與歸年** 曹真打猎遇虎回身射倒老虎。曹操赏识其勇，使统虎豹骑；此事在下辩之战以前，确年未载。

曹真讨破灵丘的贼众，封灵寿亭侯。

**时段与依据** 本传置下辩攻蜀以前，灵丘之役未另见确年。

<a id="wei009-l115-3"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l115-3)** · [TXT L115](../../拆分史书/三国志/卷009.txt#L115)

**釋讀與歸年** 曹真攻破灵丘的敌军，封灵寿亭侯，原文置于建安末下辩战事之前，未能确定出兵年。

<a id="period-sgz009-b-473-15"></a>

曹真升中军大将军，加给事中。

**时段与依据** 在江陵功后、226受文帝顾命之前，未给确年。

<a id="wei009-l115-10"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l115-10)** · [TXT L115](../../拆分史书/三国志/卷009.txt#L115)

### 曹真乞分食邑给曹遵、朱赞后代

[《三国志·诸夏侯曹传》仓内原文 L475](../../拆分史书/三国志/卷009.md#l475)

两人早逝，曹真上奏欲分己邑封其子；魏帝褒真义行，许各为关内侯，食邑百户。

**时段与依据** 诏称曹真大司马，已在230二月至231三月之间，未确哪年。

<a id="wei009-l121-2"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l121-2)** · [TXT L121](../../拆分史书/三国志/卷009.txt#L121)

> 遵、讚早亡，真愍之，乞分所食邑封遵、讚子。詔曰：「大司馬有叔向撫孤之仁，篤晏平乆要之分。君子成人之羙，聽分真邑賜遵、讚子爵關內侯，各百戶。」

**釋讀與歸年** 曹遵、朱赞早逝，曹真请求分邑封其子，诏准各给关内侯一百户。诏称「大司馬」，约在曹真230年升任后到231年卒前，颁詔确年没有明文。

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l121-3)** · [TXT L121](../../拆分史书/三国志/卷009.txt#L121)

**釋讀與歸年** 曹真出征与将士共劳苦，军赏不足时拿家财补给；此为总叙多次征行。

### 曹爽在东宫时期受曹叡亲爱

[《三国志·诸夏侯曹传》仓内原文 L477](../../拆分史书/三国志/卷009.md#l477)

曹爽字昭伯，少时谨重，在曹叡待于东宫期间与之亲善。

**时段与依据** 《明帝纪》只载曹叡226临立为太子，传称东宫可泛指即位前，不能把少年交谊系一日。

<a id="wei009-l125-1"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l125-1)** · [TXT L125](../../拆分史书/三国志/卷009.txt#L125)

> 爽字昭伯，少以宗室謹重，明帝在東宮，甚親愛之。

**釋讀與歸年** 曹爽字昭伯，年轻时以宗室谨慎稳重受还在东宫的曹叡亲爱。关系起于曹叡登位前，此处未载始年。

**时段与依据** 曹爽辅政始239，高平陵事时已有这些官，正文未给各任命年。

### 何晏等劝曹爽独权，党人分居要职

[《三国志·诸夏侯曹传》仓内原文 L479](../../拆分史书/三国志/卷009.md#l479)

何晏等得用后推重曹爽，劝勿授权于人，继而何晏、邓飏、丁谧为尚书，毕轨任司隶、李胜任河南尹，事少经司马懿。

**时段与依据** 正始初到247以前的累进，本传未给所有任命月年。

<a id="wei009-l132-2"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l132-2)** · [TXT L132](../../拆分史书/三国志/卷009.txt#L132)

> 及晏等進用，咸共推戴，說爽以權重不宜委之於人。乃以晏、颺、謐爲尚書，晏典選舉，軌司隷校尉，勝河南尹，諸事希復由宣王。

**釋讀與歸年** 何晏等劝曹爽揽权，何晏、邓飏、丁谧为尚书，何晏掌选举，毕轨任司隶校尉、李胜任河南尹。数任未必同年，政务渐少经过司马懿。

### 何晏等占官田、官物并索求州郡

[《三国志·诸夏侯曹传》仓内原文 L479](../../拆分史书/三国志/卷009.md#l479)

何晏等擅政，分洛阳、野王典农桑田数百顷，毁汤沐地营产业，并利用势位取官物、向州郡索求，官吏不敢抗。

**时段与依据** 曹爽专政期多事概叙，未见每件日期。

<a id="wei009-l134-1"></a>

**[《三國志·諸夏侯曹傳》正文](../../拆分史书/三国志/卷009.md#edition-wei009-l134-1)** · [TXT L134](../../拆分史书/三国志/卷009.txt#L134)

> 晏等專政，共分割洛陽、野王典農部桑田數百頃，及壞湯沐地以爲產業，承勢竊取官物，因緣求欲州郡。有司望風，莫敢忤旨。

**釋讀與歸年** 何晏等分割典农部桑田及汤沐地，占用官物，向州郡求取私物。此为掌权期间的连续行为，无各项确年。

### 何晏等因盧毓属吏小过收其印绶

[《三国志·诸夏侯曹传》仓内原文 L479](../../拆分史书/三国志/卷009.md#l479)

何晏等与廷尉卢毓有隙，借下吏小过重究法律，先收其印后才上奏。

**时段与依据** 卷022《卢毓传》另载丁谧称其持法急、免后为光禄勋，详细年不载。

<a id="wei009-l134-2"></a>

### 夏侯玄与司马懿论选官、裁郡和车服

司马懿任太傅后向夏侯玄问时事，夏侯玄提出三项建议，两人又就施行和服制改易往返通信。书信约在239年司马懿任太傅之后、244年夏侯玄出征之前。

<a id="wei009-l170-1"></a>

<a id="wei009-l172-1"></a>

<a id="wei009-l174-1"></a>

<a id="wei009-l176-1"></a>

<a id="wei009-l178-1"></a>

**[《三國志·諸夏侯曹傳》](../../拆分史书/三国志/卷009.md#edition-wei009-l170-1)** · [TXT L170](../../拆分史书/三国志/卷009.txt#L170) · [TXT L172](../../拆分史书/三国志/卷009.txt#L172) · [TXT L174](../../拆分史书/三国志/卷009.txt#L174) · [TXT L176](../../拆分史书/三国志/卷009.txt#L176) · [TXT L178](../../拆分史书/三国志/卷009.txt#L178)

> 太傅司馬宣王問以時事，玄議以爲：「夫官才用人，國之柄也，故銓衡專於臺閣，上之分也，孝行存乎閭巷，優劣任之鄉人，下之叙也。夫欲清教審選，在明其分叙，不使相涉而已。何者？上過其分，則恐所由之不本，而干勢馳騖之路開；下踰其叙，則恐天爵之外通，而機權之門多矣。夫天爵下通，是庶人議柄也；機權多門，是紛亂之原也。自州郡中正品度官才之來，有年載矣，緬緬紛紛，未聞整齊，豈非分叙參錯各失其要之所由哉！若令中正但考行倫輩，倫輩當行均，斯可官矣。何者？夫孝行著於家門，豈不忠恪於在官乎？仁恕稱於九族，豈不達於爲政乎？義斷行於鄉黨，豈不堪於事任乎？三者之類，取於中正，雖不處其官名，斯任官可知矣。行有大小，比有高下，則所任之流，亦渙然明別矣。奚必使中正干銓衡之機於下，而執機柄者有所委仗於上，上下交侵，以生紛錯哉？且臺閣臨下，考功校否，衆職之屬，各有官長，旦夕相考，莫究於此；閭閻之議，以意裁處，而使匠宰失位，衆人驅駭，欲風俗清靜，其可得乎？天臺縣遠，衆所絕意。所得至者，更在側近，孰不脩飾以要所求？所求有路，則脩己家門者，已不如自達於鄉黨矣。自達鄉黨者，已不如自求之於州邦矣。苟開之有路，而患其飾真離本，雖復嚴責中正，督以刑罰，猶無益也。豈若使各帥其分，官長則各以其屬能否獻之臺閣，臺閣則據官長能否之第，參以鄉閭德行之次，擬其倫比，勿使偏頗。中正則唯考其行迹，別其高下，審定輩類，勿使升降。臺閣總之，如其所簡，或有參錯，則其責負自在有司。官長所第，中正輩擬，比隨次率而用之，如其不稱，責負在外。然則內外相參，得失有所，互相形檢，孰能相飾？斯則人心定而事理得，庶可以靜風俗而審官才矣。」
>
> 又以爲：「古之建官，所以濟育羣生，統理民物也，故爲之君長以司牧之。司牧之主，欲一而專，一則官任定而上下安，專則職業脩而事不煩。夫事簡業脩，上下相安而不治者，未之有也。先王建萬國，雖其詳未可得而究，然分彊畫界，各守土境，則非重累羈絆之體也。下考殷、周五等之叙，徒有小大貴賤之差，亦無君官臣民而有二統互相牽制者也。夫官統不一，則職業不脩；職業不脩，則事何得而簡？事之不簡，則民何得而靜？民之不靜，則邪惡並興，而姦偽滋長矣。先王達其如此，故專其職司而一其統業。始自秦世，不師聖道，私以御職，姦以待下；懼宰官之不脩，立監牧以董之，畏督監之容曲，設司察以糾之；宰牧相累，監察相司，人懷異心，上下殊務。漢承其緒，莫能匡改。魏室之隆，日不暇及，五等之典，雖難卒復，可粗立儀準以一治制。今之長吏，皆君吏民，橫重以郡守，累以刺史。若郡所攝，唯在大較，則與州同，無爲再重。宜省郡守，但任刺史；刺史職存，則監察不廢，郡吏萬數還親農業，以省煩費，豐財殖穀，一也。大縣之才，皆堪郡守，是非之訟，每生意異，順從則安，直己則爭。夫和羹之美，在於合異，上下之益，在能相濟，順從乃安，此琴瑟一聲也，蕩而除之，則官省事簡，二也。又幹郡之吏，職監諸縣，營護黨親，鄉邑舊故，如有不副，而因公掣頓，民之困弊，咎生於此，若皆并合，則亂原自塞，三也。今承衰弊，民人彫落，賢才鮮少，任事者寡，郡縣良吏往往非一，郡受縣成，其劇在下，而吏之上選，郡當先足，此爲親民之吏，專得厎下，吏者民命，而常頑鄙，今如并之，吏多選清良者造職，大化宣流，民物獲寧，四也。制使萬戶之縣名之郡守，五千以上名之都尉，千戶以下令長如故，自長以上考課遷用，轉以能升，所牧亦增，此進才効功之叙也，若經制一定，則官才有次，治功齊明，五也。若省郡守，縣皆徑達，事不擁隔，官無留滯，三代之風雖未可必，簡一之化庶幾可致，便民省費在於此矣。」
>
> 又以爲：「文質之更用，猶四時之迭興也，王者體天理物，必因弊而濟通之，時彌質則文之以禮，時泰侈則救之以質。今承百王之末，秦漢餘流，世俗彌文，宜大改之以易民望。今科制自公、列侯以下，位從大將軍以上，皆得服綾錦、羅綺、紈素、金銀飾鏤之物，自是以下，雜綵之服通于賤人，雖上下等級，各示有差，然朝臣之制已得侔至尊矣，玄黃之采已得通於下矣。欲使市不鬻華麗之色，商不通難得之貨，工不作雕刻之物，不可得也。是故宜大理其本，準度古法，文質之宜，取其中則，以爲禮度。車輿服章，皆從質樸，禁除末俗華麗之事，使幹朝之家，有位之室，不復有錦綺之飾，無兼采之服、纖巧之物，自上以下至於樸素之差，示有等級而已，勿使過一二之覺。若夫功德之賜，上恩所特加，皆表之有司，然後服用之。夫上之化下，猶風之靡草。樸素之教興於本朝，則彌侈之心自消於下矣。」
>
> 宣王報書曰：「審官擇人，除重官，改服制，皆大善。禮鄉閭本行，朝廷考事，大指如所示。而中間一相承習，卒不能改。秦時無刺史，但有郡守長吏。漢家雖有刺史，奉六條而已，故刺史稱傳車，其吏言從事，居無常治，吏不成臣，其後轉更爲官司耳。昔賈誼亦患服制，漢文雖身服弋綈，猶不能使上下如意。恐此三事，當待賢能然後了耳。」
>
> 玄又書曰：「漢文雖身衣弋綈，而不革正法度，內外有僭擬之服，寵臣受無限之賜，由是觀之，似指立在身之名，非篤齊治制之意也。今公侯命世作宰，追蹤上古，將隆至治，抑末正本，若制定於上，則化行於衆矣。夫當宜改之時，留殷勤之心，令發之日，下之應也猶響尋聲耳，猶垂謙謙，曰『待賢能』，此伊周不正殷姬之典也。竊未喻焉。」

**釋讀與歸年** 夏侯玄答太傅司马懿，第一议厘清选官职责：中正只评乡里德行与等第，官长考评业务，台阁参酌两方作决定，分别追究举荐和任用责任。司马懿239年转太傅，夏侯玄244年出师前已督雍、凉，本传系在外任之前，只能划定此阶段。

**釋讀與歸年** 第二议主张减少郡、州叠设，省郡守而保留刺史监察，按县户数设官名，依考绩晋升，并列人员、吏治和财用五项得失。殷周、秦汉的制度均为论据。

**釋讀與歸年** 第三议从文质互济谈到奢侈、等级与市工风俗，建议朝廷先简化车服、以明确差等代替奢饰，遇特赐则报有司登记。

**釋讀與歸年** 司马懿回书赞同选官、减重官、改服制三议，举秦无刺史、汉初刺史奉六条及贾谊论服制说明积弊难改，谓仍须有才者实行。

**釋讀與歸年** 夏侯玄再答说汉文帝个人服饰节俭，未能消除臣属僭服和过度赏赐，劝司马懿立即定制，从朝廷带动社会，不必以等待后贤作辞。

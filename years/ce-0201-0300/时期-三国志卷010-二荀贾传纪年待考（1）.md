<a id="wei010-l5-1"></a>

**釋讀與歸年** 荀彧字文若，颍川颍阴人。祖父荀淑字季和，任朗陵县令，知名于顺帝、桓帝之间，八子号「八龙」；父荀绲任济南相。[《后汉书·荀淑传》](../../史书/003-后汉书/后汉书-CCDH.txt#L4531-L4535)记荀淑出补朗陵侯相，与裴注官称相同。

### 荀彧弃亢父令回乡，劝亲族离颍川

[《三国志·二荀贾传》仓内原文 L504](../../拆分史书/三国志/卷010.md#l504)

**时段与依据** 在董卓入洛后、191年抵冀州前，离职没有年号。

<a id="wei010-l10-2"></a>

**[《三國志·荀彧荀攸賈詡傳》正文](../../拆分史书/三国志/卷010.md#edition-wei010-l10-2)** · [TXT L10](../../拆分史书/三国志/卷010.txt#L10)

> 董卓之亂，求出補吏。除亢父令，遂棄官歸，謂父老曰：「潁川，四戰之地也，天下有變，常爲兵衝，宜亟去之，無乆留。」鄉人多懷土猶豫，

**釋讀與歸年** 董卓乱后，荀彧求出补官，受任亢父令而弃官，劝父老离开易遭兵冲的颍川；多数乡里亲土迟疑。传文只说明在董卓乱后、赴冀州前。

<a id="wei010-l19-1"></a>

<a id="wei010-l20-1"></a>

> 常居中持重，
>
> **〔裴注〕**
> 典略曰：彧折節下士，坐不累席。其在臺閣，不以私欲撓意。彧有羣從一人，才行實薄，或謂彧：「以君當事，不可不以某爲議郎邪？」彧笑曰：「官者所以表才也，若如來言，衆人其謂我何邪！」其持心平正皆類此。

### 荀衍察高干谋袭邺，诛来兵受封

[《三国志·二荀贾传》仓内原文 L511](../../拆分史书/三国志/卷010.md#l511)

**时段与依据** 曹操攻袁尚和收邺跨203–205，高干服叛反复；事在荀衍守邺之后，未见袭击、封爵具体年。

<a id="wei010-l35-3"></a>

**[《三國志·荀彧荀攸賈詡傳》正文](../../拆分史书/三国志/卷010.md#edition-wei010-l35-3)** · [TXT L35](../../拆分史书/三国志/卷010.txt#L35)

<a id="wei010-l127-1"></a>

<a id="wei010-l128-1"></a>

<a id="wei010-l129-1"></a>

<a id="wei010-l130-1"></a>

**[《三國志·荀彧荀攸賈詡傳》](../../拆分史书/三国志/卷010.md#edition-wei010-l127-1)** · [TXT L127](../../拆分史书/三国志/卷010.txt#L127) · [TXT L128（裴注）](../../拆分史书/三国志/卷010.txt#L128) · [TXT L129](../../拆分史书/三国志/卷010.txt#L129) · [TXT L130（裴注）](../../拆分史书/三国志/卷010.txt#L130)

> 評曰：荀彧清秀通雅，有王佐之風，然機鑒先識，未能充其志也。
>
> **〔裴注〕**
> 世之論者，多譏彧協規魏氏，以傾漢祚；君臣易位，實彧之由。雖晚節立異，無救運移；功旣違義，識亦疚焉。陳氏此評，蓋亦同乎世識。　臣松之以爲斯言之作，誠未得其遠大者也。彧豈不知魏武之志氣，非衰漢之貞臣哉？良以于時王道旣微，橫流已及，雄豪虎視，人懷異心，不有撥亂之資，仗順之略，則漢室之亡忽諸，黔首之類殄矣。夫欲翼讚時英，一匡屯運，非斯人之與而誰與哉？是故經綸急病，若救身首，用能動于嶮中，至于大亨，蒼生蒙舟航之接，劉宗延二紀之祚，豈非荀生之本圖，仁恕之遠致乎？及至霸業旣隆，翦漢迹著，然後亡身殉節，以申素情，全大正於當年，布誠心於百代，可謂任重道遠，志行義立。謂之未充，其殆誣歟！
>
> **〔正文續〕**
> 荀攸、賈詡，庶乎筭無遺策，經達權變，其良、平之亞與！
>
> **〔裴注〕**
> 臣松之以爲列傳之體，以事類相從。張子房青雲之士，誠非陳平之倫。然漢之謀臣，良、平而已。若不共列，則餘無所附，故前史合之，蓋其宜也。魏氏如詡之儔，其比幸多，詡不編程、郭之篇，而與二荀並列；失其類矣。且攸、詡之爲人，其猶夜光之與蒸燭乎！其照雖均，質則異焉。今荀、賈之評，共同一稱，尤失區別之宜也。

**釋讀與歸年** 陈寿评荀彧有辅佐王业的风度，但有识见而志向未能实现。与裴松之下文的反驳连续阅读。

**釋讀與歸年** 裴松之先概括时人批评荀彧助曹倾汉的说法，继而主张荀彧借曹操平乱、延续汉祚，等代汉意图明显时为所持之义而死，不能以其志未遂概括。

**釋讀與歸年** 陈寿以善于权变、谋无遗策评荀攸与贾诩，拟为张良、陈平之亚。

**釋讀與歸年** 裴松之认为贾诩更适宜与程昱、郭嘉等合传，荀攸与贾诩虽都善谋，品格却有区别。全录按语。

### 荀氏里因八子改名高阳

[《三国志·二荀贾传》裴注 001·6](../../拆分史书/三国志/卷010.md#pei-001-6)

苑康把荀淑故里西豪里改名高阳里，以古高阳氏有八才子为比。

**时段与依据** 《后汉书》L4533同载，苑康改名未给确年。

<a id="wei010-l6-5"></a>

**[《三國志·荀彧荀攸賈詡傳》裴注](../../拆分史书/三国志/卷010.md#edition-wei010-l6-5)** · [TXT L6](../../拆分史书/三国志/卷010.txt#L6)

> 淑舊居西豪里，縣令苑康曰昔高陽氏有才子八人，署其里爲高陽里。靖字叔慈，亦有至德，名幾亞爽，隱居終身。　皇甫謐逸士傳：或問許子將，靖與爽孰賢？子將曰：「二人皆玉也，慈明外朗，叔慈內潤。」

**釋讀與歸年** 县令苑康因荀淑八子有才，把荀氏居住的西豪里改称高阳里。荀靖字叔慈，名望几与荀爽相当，隐居终身。皇甫谧并记许劭以二人内外不同的品格作比。

### 典略称荀绲慕权收唐衡女为荀彧妻

[《三国志·二荀贾传》裴注 002·1](../../拆分史书/三国志/卷010.md#pei-002-1)

唐衡先欲嫁女给傅公明，傅辞，改嫁荀彧，《典略》说荀绲慕其势，议者讥。

**时段与依据** 择婚确年不详，裴松之另引唐衡亡年质疑慕势说。

<a id="wei010-l9-1"></a>

**[《三國志·荀彧荀攸賈詡傳》裴注](../../拆分史书/三国志/卷010.md#edition-wei010-l9-1)** · [TXT L9](../../拆分史书/三国志/卷010.txt#L9)

> 典略曰：中常侍唐衡欲以女妻汝南傅公明，公明不娶，轉以與彧。父緄慕衡勢，爲彧娶之。彧爲論者所譏。　臣松之案：漢紀云唐衡以桓帝延熹七年死，計彧于時年始二歲，則彧婚之日，衡之沒乆矣。慕勢之言爲不然也。臣松之又以爲緄八龍之一，必非苟得者也，將有逼而然，何云慕勢哉？昔鄭忽以違齊致譏，雋生以拒霍見美，致譏在於失援，見美嘉其慮遠，並無交至之害，故得各全其志耳。至於閹豎用事，四海屏氣；左悺、唐衡殺生在口。故于時諺云「左迴天，唐獨坐」，言威權莫二也。順之則六親以安，忤違則大禍立至；斯誠以存易亡，蒙恥期全之日。昔蔣詡姻于王氏，無損清高之操，緄之此婚，庸何傷乎！

**釋讀與歸年** 《典略》说荀绲慕唐衡权势，为儿子娶其女。裴松之据唐衡死于延熹七年且当时荀彧约二岁，认为成婚时唐衡已经亡故，不赞成「慕势」说。他又以当时权宦杀生之威解释婚约也可能迫不得已，提出另一种解释。婚期未有明文。[《后汉书·荀彧传》](../../史书/003-后汉书/后汉书-CCDH.txt#L5086)

### 祢衡建安初由荆州到许，气高好品评

[《三国志·二荀贾传》裴注 006·2](../../拆分史书/三国志/卷010.md#pei-006-2)

祢衡字正平，建安初北游许都，恃才傲物，称量人过于严厉，多人不喜；孔融重其才。

**时段与依据** 《后汉书·祢衡传》L5938也作“建安初”；《通鉴》卷062 L307–318把其与曹操、刘表、黄祖始末附叙在196年底，后续具体年份另考。

<a id="wei010-l21-2"></a>

**[《三國志·荀彧荀攸賈詡傳》裴注](../../拆分史书/三国志/卷010.md#edition-wei010-l21-2)** · [TXT L21](../../拆分史书/三国志/卷010.txt#L21)

> 又平原禰衡傳曰：衡字正平，建安初，自荊州北游許都，恃才傲逸，臧否過差，見不如己者不與語，人皆以是憎之。唯少府孔融高貴其才，上書薦之曰：「淑質貞亮，英才卓犖。初涉藝文，升堂覩奧；目所一見，輒誦於口，耳所暫聞，不忘於心。性與道合，思若有神。弘羊心計，安世默識，以衡準之，誠不足恠。」衡時年二十四。是時許都雖新建，尚饒人士。衡嘗書一刺懷之，字漫滅而無所適。或問之曰：「何不從陳長文、司馬伯達乎？」衡曰：「卿欲使我從屠沽兒輩也！」又問曰：「當今許中，誰最可者？」衡曰：「大兒有孔文舉，小兒有楊德祖。」又問：「曹公、荀令君、趙盪寇皆足蓋世乎？」衡稱曹公不甚多；又見荀有儀容，趙有腹尺，因荅曰：「文若可借面吊喪，稚長可使監厨請客。」其意以爲荀但有貌，趙健啖肉也。於是衆人皆切齒。衡知衆不恱，將南還荊州。裝束臨發，衆人爲祖道，先設供帳於城南，自共相誡曰：「衡數不遜，今因其後到，以不起報之。」及衡至，衆人皆坐不起，衡乃號咷大哭。衆人問其故，衡曰：「行屍柩之間，能不悲乎？」衡南見劉表，表甚禮之。將軍黃祖屯夏口，祖子射與衡善，隨到夏口。祖嘉其才，每在坐，席有異賔，介使與衡談。後衡驕蹇，荅祖言徘優饒言，祖以爲罵己也，大怒，顧伍伯捉頭出。左右遂扶以去，拉而殺之。

**釋讀與歸年** 《平原祢衡传》由建安初入许，次叙孔融荐书、祢衡评论陈群等许都人物、被送别者轻慢、南见刘表，终被黄祖命人杀死。[《后汉书·祢衡传》](../../史书/003-后汉书/后汉书-CCDH.txt#L5938-L5946)也叙建安初始来许下、后来死于黄祖，称卒年二十六，未明确具体年份。保留荐文、问答和叙事全文。

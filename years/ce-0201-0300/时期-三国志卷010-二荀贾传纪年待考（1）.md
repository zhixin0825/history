# 《三国志·二荀贾传》跨年及未定年材料 1

<a id="period-sgz010-b-503-1"></a>

### 荀彧表字和籍贯

[《三国志·二荀贾传》仓内原文 L503](../../拆分史书/三国志/卷010.md#l503)

> 荀彧字文若，潁川潁陰人也。

荀彧字文若，是颍川颍阴人。

**时段与依据** 身份无明确出生年。

<a id="period-sgz010-b-503-2"></a>

### 荀淑为朗陵令，有八子

[《三国志·二荀贾传》仓内原文 L503](../../拆分史书/三国志/卷010.md#l503)

> 祖父淑，字季和，朗陵令。當漢順、桓之間，知名當世。有子八人，號曰八龍。

祖荀淑字季和，曾任朗陵令，顺、桓帝之间闻名。他有八子，人称八龙。

**时段与依据** 由东汉两朝为时限，任、称均无单年。

<a id="period-sgz010-b-503-3"></a>

### 荀彧父荀绲为济南相

[《三国志·二荀贾传》仓内原文 L503](../../拆分史书/三国志/卷010.md#l503)

> 彧父緄，濟南相。

荀彧父亲荀绲任济南相。

**时段与依据** 任年不载。

<a id="period-sgz010-b-504-1"></a>

### 何颙称年轻荀彧有王佐才

[《三国志·二荀贾传》仓内原文 L504](../../拆分史书/三国志/卷010.md#l504)

> 彧年少時，南陽何顒異之，曰：「王佐才也。」

南阳何颙见少年荀彧，赞其为辅佐君主的才士。

**时段与依据** 传只云年少。

<a id="period-sgz010-b-504-3"></a>

### 荀彧弃亢父令回乡，劝亲族离颍川

[《三国志·二荀贾传》仓内原文 L504](../../拆分史书/三国志/卷010.md#l504)

> 董卓之亂，求出補吏。除亢父令，遂棄官歸，謂父老曰：「潁川，四戰之地也，天下有變，常爲兵衝，宜亟去之，無久留。」

董卓之乱，荀彧请出为地方吏，拜亢父令后弃归，劝乡里及早离开易遭兵争的颍川。

**时段与依据** 在董卓入洛后、191年抵冀州前，离职没有年号。

<a id="period-sgz010-b-504-4"></a>

### 韩馥遣骑迎荀彧，荀氏移居冀州

[《三国志·二荀贾传》仓内原文 L504](../../拆分史书/三国志/卷010.md#l504)

> 鄉人多懷土猶豫，會冀州牧同郡韓馥遣騎迎之，莫有隨者，彧獨將宗族至冀州。

乡人眷恋本土而观望。韩馥遣骑来接，只有荀彧带宗族前往冀州。

**时段与依据** 韩馥掌冀始189、191失位。发邀、启程前年或同年，仅到冀州后见袁绍。

<a id="period-sgz010-b-504-6"></a>

### 荀谌辛评郭图为袁绍所用

[《三国志·二荀贾传》仓内原文 L504](../../拆分史书/三国志/卷010.md#l504)

> 彧弟諶及同郡辛評、郭圖，皆爲紹所任。

荀彧弟荀谌和同乡辛评、郭图都受袁绍任用。

**时段与依据** 三人任职未逐一明年。荀谌、郭图191年参与韩馥让位，可参同年。

<a id="period-sgz010-b-504-13"></a>

### 荀彧常以司马随曹操

[《三国志·二荀贾传》仓内原文 L504](../../拆分史书/三国志/卷010.md#l504)

> 彧常以司馬從。

荀彧长期以司马身份相从。

**时段与依据** 191授司马后的持续职掌。

<a id="period-sgz010-b-506-11"></a>

### 荀彧掌中枢，多与曹操共谋军国

[《三国志·二荀贾传》仓内原文 L506](../../拆分史书/三国志/卷010.md#l506)

> 常居中持重，太祖雖征伐在外，軍國事皆與彧籌焉。

荀彧在朝持重；曹操虽在外征战，军国事务都与他计议。

**时段与依据** 这是任尚书令以后的长时概括。

<a id="period-sgz010-b-506-13"></a>

### 荀彧曾荐戏志才

[《三国志·二荀贾传》仓内原文 L506](../../拆分史书/三国志/卷010.md#l506)

> 先是，彧言策謀士，進戲志才。

荀彧先前谈谋士时举荐戏志才。

**时段与依据** “先是”指定先后，未给任用时间。

<a id="period-sgz010-b-506-15"></a>

### 曹操认可荀彧知人善举

[《三国志·二荀贾传》仓内原文 L506](../../拆分史书/三国志/卷010.md#l506)

> 太祖以彧爲知人，諸所進達皆稱職，

曹操称荀彧懂得识人，他推荐者都能称职。

**时段与依据** 历任举荐的总结。

<a id="period-sgz010-b-506-16"></a>

原句及归年依据已移至 [199年第5条](../ce-0101-0200/ce-0199.md#sgz010-b-506-16)。

<a id="period-sgz010-b-506-17"></a>

### 荀彧所荐韦康出任凉州

[《三国志·二荀贾传》仓内原文 L506](../../拆分史书/三国志/卷010.md#l506)

> 韋康爲涼州，

韦康获任凉州长官。

**时段与依据** 《三辅决录》说继韦端出任，不具确年。

<a id="period-sgz010-b-506-18"></a>

### 严象、韦康都在州任上遭杀

[《三国志·二荀贾传》仓内原文 L506](../../拆分史书/三国志/卷010.md#l506)

> 後敗亡。

严象、韦康后来都出事身亡。

**时段与依据** 严象200被李术杀，韦康212或213被马超杀，二人非同年，本卷注文及卷009异说。

<a id="period-sgz010-b-507-2"></a>

### 袁绍势力大，众人畏之

[《三国志·二荀贾传》仓内原文 L507](../../拆分史书/三国志/卷010.md#l507)

> 紹旣並河朔，天下畏其彊。

袁绍兼并黄河以北势力，天下畏其强。

**时段与依据** 概述建安前期的扩张；彻底并四州在199，不能将总叙硬系于下面宛城事。

<a id="period-sgz010-b-508-3"></a>

### 曹操与袁绍渐成对峙

[《三国志·二荀贾传》仓内原文 L508](../../拆分史书/三国志/卷010.md#l508)

> 遂與袁紹相拒。

继定徐州后，曹操和袁绍形成对峙。

**时段与依据** 承198战后至200官渡多阶段，单句过渡不限定一年。

<a id="period-sgz010-b-511-1"></a>

### 荀攸长期为曹操谋主

[《三国志·二荀贾传》仓内原文 L511](../../拆分史书/三国志/卷010.md#l511)

> 是時荀攸常爲謀主。

曹操征河北时，荀攸经常是主要谋士。

**时段与依据** 战期跨年，卷中本传从197前后至214。

<a id="period-sgz010-b-511-3"></a>

### 荀衍察高干谋袭邺，诛来兵受封

[《三国志·二荀贾传》仓内原文 L511](../../拆分史书/三国志/卷010.md#l511)

> 太祖之徵袁尚也，高幹密遣兵謀襲鄴，衍逆覺，盡誅之，以功封列侯。

曹操征袁尚，高干暗派兵谋袭邺，荀衍预先察觉并诛众，以功封列侯。

**时段与依据** 曹操攻袁尚和收邺跨203–205，高干服叛反复；事在荀衍守邺之后，未见袭击、封爵具体年。

<a id="period-sgz010-b-511-4"></a>

### 曹操女嫁荀恽，后称安阳公主

[《三国志·二荀贾传》仓内原文 L511](../../拆分史书/三国志/卷010.md#l511)

> 太祖以女妻彧長子惲，後稱安陽公主。

曹操把女儿嫁给荀彧长子荀恽，后来称安阳公主。

**时段与依据** 婚姻及后封不见准确年月。

<a id="period-sgz010-b-511-5"></a>

### 荀彧荀攸禄赐周宗族故友

[《三国志·二荀贾传》仓内原文 L511](../../拆分史书/三国志/卷010.md#l511)

> 彧及攸並貴重，皆謙沖節儉，祿賜散之宗族知舊，家無餘財。

荀彧和荀攸地位贵重而谦俭，把所得俸赏散给亲族故交，家无余财。

**时段与依据** 跨年品行概叙。

<a id="period-sgz010-b-514-1"></a>

### 荀恽嗣侯并官至虎贲中郎将

[《三国志·二荀贾传》仓内原文 L514](../../拆分史书/三国志/卷010.md#l514)

> 子惲，嗣侯，官至虎賁中郎將。

荀彧子荀恽承袭，后来任虎贲中郎将。

**时段与依据** 接212荀彧卒，官历跨年，具体年月未给。

<a id="period-sgz010-b-514-2"></a>

### 曹丕曹植有储位之议时曹丕礼事荀彧

[《三国志·二荀贾传》仓内原文 L514](../../拆分史书/三国志/卷010.md#l514)

> 初，文帝與平原侯植並有擬論，文帝曲禮事彧。

曹丕与平原侯曹植被并行议论时，曹丕对荀彧备加礼遇。

**时段与依据** 曹植211封平原，荀彧212卒，交往只约在此间，无确年。

<a id="period-sgz010-b-514-3"></a>

### 荀恽与曹植相善，人际嫌隙引起曹丕不满

[《三国志·二荀贾传》仓内原文 L514](../../拆分史书/三国志/卷010.md#l514)

> 及彧卒，惲又與植善，而與夏侯尚不穆，文帝深恨惲。

荀彧死后荀恽与曹植相善、与夏侯尚不睦，曹丕因而厌恨荀恽。

**时段与依据** 关系概叙，荀彧卒后未定哪年。

<a id="period-sgz010-b-514-4"></a>

### 荀恽早卒，其两子仍受曹氏厚待

[《三国志·二荀贾传》仓内原文 L514](../../拆分史书/三国志/卷010.md#l514)

> 惲早卒，子甝、霬，以外甥故猶寵待。

荀恽早卒，儿子荀甝、荀霬虽为其子，因是外甥仍受优待。

**时段与依据** 生卒、受宠均无年月。

<a id="period-sgz010-b-514-5"></a>

### 荀俁、荀诜官历及早卒

[《三国志·二荀贾传》仓内原文 L514](../../拆分史书/三国志/卷010.md#l514)

> 惲弟俁，御史中丞，俁弟詵，大將軍從事中郎，皆知名，早卒。

荀恽弟荀俁为御史中丞，荀诜为大将军从事中郎，两人有名而早卒。

**时段与依据** 未给具体年。

<a id="period-sgz010-b-514-7"></a>

### 荀甝袭爵并封广阳乡侯，荀頵嗣

[《三国志·二荀贾传》仓内原文 L514](../../拆分史书/三国志/卷010.md#l514)

> 惲子甝，嗣爲散騎常侍，進爵廣陽鄉侯，年三十薨。子頵嗣。

荀甝以散骑常侍承袭，进封广阳乡侯，三十岁去世，子荀頵继爵。

**时段与依据** 各次任封与死没有确年，年龄无独立生年。

<a id="period-sgz010-b-514-8"></a>

### 荀霬为中领军，死后获赠，荀恺继嗣

[《三国志·二荀贾传》仓内原文 L514](../../拆分史书/三国志/卷010.md#l514)

> 霬官至中領軍，薨，謚曰貞侯，追贈驃騎將軍。子愷嗣。

荀霬任中领军，卒后谥贞侯、追赠骠骑将军，子荀恺承袭。

**时段与依据** 仅历官与寿终先后，确年未详。

<a id="period-sgz010-b-514-9"></a>

### 荀霬娶司马师与司马昭之妹

[《三国志·二荀贾传》仓内原文 L514](../../拆分史书/三国志/卷010.md#l514)

> 霬妻，司馬景王、文王之妹也，二王皆與親善。

荀霬妻是司马师、司马昭的妹妹，两人均与荀霬亲善。

**时段与依据** 婚年、友往无明确纪年。

<a id="period-sgz010-b-515-1"></a>

### 荀攸分段题

[《三国志·二荀贾传》仓内原文 L515](../../拆分史书/三国志/卷010.md#l515)

> 荀攸

下叙荀攸传。

**时段与依据** 卷内分节题。

<a id="period-sgz010-b-516-1"></a>

### 荀攸家世及童年孤苦

[《三国志·二荀贾传》仓内原文 L516](../../拆分史书/三国志/卷010.md#l516)

> 荀攸字公達，彧從子也。祖父曇，廣陵太守。攸少孤。

荀攸字公达，是荀彧从子；祖荀昙任广陵太守，荀攸少孤。

**时段与依据** 只叙家世和少年处境。

<a id="period-sgz010-b-516-2"></a>

### 荀昙死后旧吏张权求守墓

[《三国志·二荀贾传》仓内原文 L516](../../拆分史书/三国志/卷010.md#l516)

> 及曇卒，故吏張權求守曇墓。

荀昙去世，故吏张权主动要求替他守墓。

**时段与依据** 只可定位在荀攸十三岁事前后，荀昙死亡无确年。

<a id="period-sgz010-b-516-3"></a>

### 荀攸少年识出张权是亡命犯

[《三国志·二荀贾传》仓内原文 L516](../../拆分史书/三国志/卷010.md#l516)

> 攸年十三，疑之，謂叔父衢曰：「此吏有非常之色，殆將有姦！」衢寤，乃推問，果殺人亡命。由是異之。

荀攸十三岁怀疑张权有异，告叔父荀衢，查问发现张权因杀人逃亡，荀衢因而奇其才。

**时段与依据** 年龄是十三。注给214年死、年五十八可推大致生年，虚岁和生日不能精确得该事件实际年。

<a id="period-sgz010-b-517-6"></a>

### 荀攸还乡后被公府擢任任城相未赴

[《三国志·二荀贾传》仓内原文 L517](../../拆分史书/三国志/卷010.md#l517)

> 棄官歸，復辟公府，舉高第，遷任城相，不行。

荀攸弃官归，后被公府再辟，举高第而为任城相，未就任。

**时段与依据** 在192董卓死后、196奉迎都许前，逐任无确年。

<a id="period-sgz010-b-517-7"></a>

### 荀攸请任蜀郡太守，道阻驻荆州

[《三国志·二荀贾传》仓内原文 L517](../../拆分史书/三国志/卷010.md#l517)

> 攸以蜀漢險固，人民殷盛，乃求爲蜀郡太守，道絕不得至，駐荊州。

荀攸认为蜀道险、人口多，求为蜀郡太守，却因道路隔断未达而滞荆州。

**时段与依据** 在196曹操征其入朝前，未载具体年。

<a id="period-sgz010-b-522-1"></a>

### 荀攸常助曹操军谋而严守秘密

[《三国志·二荀贾传》仓内原文 L522](../../拆分史书/三国志/卷010.md#l522)

> 攸深密有智防，自從太祖征伐，常謀謩帷幄，時人及子弟莫知其所言。

荀攸周密，随军征讨多谋帷幄，他人和儿孙都不知其所说。

**时段与依据** 是历次随征的概说。

<a id="period-sgz010-b-522-2"></a>

### 曹操多次褒荀攸内智内勇

[《三国志·二荀贾传》仓内原文 L522](../../拆分史书/三国志/卷010.md#l522)

> 太祖每稱曰：「公達外愚內智，外怯內勇，外弱內彊，不伐善，無施勞，智可及，愚不可及，雖顏子、寗武不能過也。」

曹操称荀攸外愚内智、外怯内勇、外弱内强，不自夸，实难及。

**时段与依据** 原文“每稱”并非一次。

<a id="period-sgz010-b-522-3"></a>

### 曹操令曹丕尊荀攸，曹丕曾探病下拜

[《三国志·二荀贾传》仓内原文 L522](../../拆分史书/三国志/卷010.md#l522)

> 文帝在東宮，太祖謂曰：「荀公達，人之師表也，汝當盡禮敬之。」攸曾病，世子問病，獨拜牀下，其見尊異如此。

曹操告诉在东宫的曹丕荀攸是人师，应尽礼敬；荀攸病时曹丕到床前问候并拜。

**时段与依据** 荀攸214去世，曹丕在本传称世子和东宫是尊称，217才正式立太子，不据称谓误排至217。

<a id="period-sgz010-b-522-4"></a>

### 钟繇称荀攸常能修正他的谋虑

[《三国志·二荀贾传》仓内原文 L522](../../拆分史书/三国志/卷010.md#l522)

> 攸與鍾繇善，繇言：「我每有所行，反覆思惟，自謂無以易；以咨公達，輒復過人意。」

钟繇和荀攸友好，说自己反复思量无可改，问荀攸后总得高见。

### 荀靖终身隐居，许劭评荀靖荀爽如玉

[《三国志·二荀贾传》裴注 001·7](../../拆分史书/三国志/卷010.md#pei-001-7)

### 典略称荀绲慕权收唐衡女为荀彧妻

[《三国志·二荀贾传》裴注 002·1](../../拆分史书/三国志/卷010.md#pei-002-1)

> 典略曰中常侍唐衡欲以女妻汝南傅公明公明不娶轉以與彧父緄慕衡勢為彧娶之彧為論者所譏

### 裴松之辨荀绲允婚亦可能受权宦胁迫

[《三国志·二荀贾传》裴注 002·3](../../拆分史书/三国志/卷010.md#pei-002-3)

> 臣松之又以為緄八龍之一必非茍得者也将有逼而然何云慕勢哉昔鄭忽以違齊致譏雋生以拒霍見美致譏在于失援見美嘉其慮逺並無交至之害故得各全其志耳至于閹䜿用事四海屏氣左悺唐衡殺生在口故于時諺云左廻天唐獨坐言威權莫二也順之則六親以安忤違則大禍立至斯誠以存易亡蒙恥期全之日昔蔣詡姻于王氏無損清髙之操緄之此婚庸何傷乎

裴松之称荀绲为八龙之一，不会苟求。用郑忽、隽不疑旧事比照，说明当权宦官威逼下顺逆关乎家族存亡，举蒋诩婚事说不损品节。

**时段与依据** 按语涉及多个历史事例和长期环境，无独立确年；宦官唐衡、左悺曾在159年同诛梁冀。

<a id="period-sgz010-p-003-1"></a>

### 裴松之以荀彧的十万之言质疑官渡曹军不足一万

[《三国志·二荀贾传》裴注 003·1](../../拆分史书/三国志/卷010.md#pei-003-1)

> 臣松之以為于時徐州未平兖州又叛而云十萬之衆雖是抑抗之言要非寡弱之稱益知官渡之役不得云兵不滿萬也

裴松之说195年徐州未平、兖州又叛时荀彧仍称十万，即使话有夸张，可见官渡说曹兵不足万可疑。

**时段与依据** 校议串195阻徐州与200官渡两时，已分别列史事。

### 荀彧在台阁推让礼士，不任不才的族人

[《三国志·二荀贾传》裴注 005·1](../../拆分史书/三国志/卷010.md#pei-005-1)

> 典略曰彧折節下士坐不累席其在䑓閣不以私欲撓意彧有羣從一人才行實薄或謂彧以君當事不可不以某為議郎邪彧笑曰官者所以表才也若如來言衆人其謂我何邪其持心平正皆類此

荀彧折节礼下，处台阁不因私欲扰公事；有人想任才行不足的族人为议郎，荀彧笑说官要表才，无才不任。

**时段与依据** 《典略》概述荀彧在台阁长期做法，轶事未纪年。

### 祢衡建安初由荆州到许，气高好品评

[《三国志·二荀贾传》裴注 006·2](../../拆分史书/三国志/卷010.md#pei-006-2)

> 曰衡字正平建安初自荆州北游許都恃才傲逸臧否過差見不如己者不與語人皆以是憎之惟少府孔融髙貴其才

祢衡字正平，建安初北游许都，恃才傲物，称量人过于严厉，多人不喜；孔融重其才。

**时段与依据** 《后汉书·祢衡传》L5938也作“建安初”；《通鉴》卷062 L307–318把其与曹操、刘表、黄祖始末附叙在196年底，后续具体年份另考。

<a id="period-sgz010-p-006-3"></a>

### 孔融上疏举荐祢衡

[《三国志·二荀贾传》裴注 006·3](../../拆分史书/三国志/卷010.md#pei-006-3)

> 上書薦之曰淑質貞亮英才卓犖初渉藝文升堂覩奥目所一見輙誦於口耳所暫聞不忘於心性與道合思若有神宏羊心計安世黙識以衡凖之誠不足怪衡時年二十四

孔融称赞祢衡资质纯正、天赋卓异，读听即记，机思出众，认为桑弘羊的心算、张安世的默记尚不奇。祢衡时年二十四。

**时段与依据** 《后汉书》L5939–5940存荐表全文，未署年；引录年龄不足换算实际年份。

### 祢衡在许无所就，讥陈群、司马朗、荀彧等

[《三国志·二荀贾传》裴注 006·4](../../拆分史书/三国志/卷010.md#pei-006-4)

> 是時許都雖新建尚饒人士衡嘗書一刺懐之字漫滅而無所適或問之曰何不從陳長文司馬伯達乎衡曰卿欲使我從屠沽兒軰也又問曰當今許中誰最可者衡曰大兒有孔文舉小兒有楊徳祖又問曺公荀令君趙盪寇皆足盖世乎衡稱曹公不甚多又見荀有儀容趙有腹尺因答曰文若可借面弔䘮稚長可使監厨請客其意以為荀但有貌趙健啖肉也於是衆人皆切齒

许都新建，祢衡怀名帖久无拜访，鄙陈群、司马朗，独称孔融、杨修，并借荀彧容貌、赵融食量作讽，众怨。

**时段与依据** 建安初在许，无确年；《后汉书》L5938叙大略相合。

### 袁涣郡望字号

[《三国志·袁张凉国田王邴管传》仓内原文 L534](../../sources/本地分卷/三国志/三国志-卷011.md#l534)

> 袁渙字曜卿，陳郡扶樂人也。

袁涣字曜卿，陈郡扶乐人。

**时段与依据** 本传开篇。

<a id="period-sgz011-b-535-1"></a>

### 袁涣持礼

[《三国志·袁张凉国田王邴管传》仓内原文 L535](../../sources/本地分卷/三国志/三国志-卷011.md#l535)

> 當時諸公子多越法度，而渙清靜，舉動必以禮。

当时许多公卿子弟越法，袁涣安静守礼。

**时段与依据** 传首概叙。

<a id="period-sgz011-b-535-2"></a>

### 袁涣任郡功曹

[《三国志·袁张凉国田王邴管传》仓内原文 L535](../../sources/本地分卷/三国志/三国志-卷011.md#l535)

> 郡命為功曹，郡中姧吏皆自引去。

郡里任命袁涣为功曹，奸吏自行离开。

**时段与依据** 无系年。

<a id="period-sgz011-b-535-3"></a>

### 袁涣早年官历

[《三国志·袁张凉国田王邴管传》仓内原文 L535](../../sources/本地分卷/三国志/三国志-卷011.md#l535)

> 後辟公府，舉高第，遷侍御史。除譙令，不就。

被公府辟召，评为高第，迁侍御史，后授谯令而未赴。

**时段与依据** 无系年。

<a id="period-sgz011-b-535-4"></a>

### 刘备举袁涣为茂才

[《三国志·袁张凉国田王邴管传》仓内原文 L535](../../sources/本地分卷/三国志/三国志-卷011.md#l535)

> 劉備之為豫州，舉渙茂才。

刘备为豫州官时荐举袁涣。

**时段与依据** 《通鉴》系建安元年事时追述；刘备先后任豫州，不据追叙定举荐年。

<a id="period-sgz011-b-535-5"></a>

### 袁涣避地江淮、受袁术礼遇

[《三国志·袁张凉国田王邴管传》仓内原文 L535](../../sources/本地分卷/三国志/三国志-卷011.md#l535)

> 後避地江、淮間，為袁術所命。術每有所咨訪，渙常正議，術不能抗，然敬之不敢不禮也。

避乱江淮后受袁术任命；对袁术屡陈正议，袁术无法反驳，却仍尊重他。

**时段与依据** 在袁术生前，具体未详。

<a id="period-sgz011-b-535-6"></a>

### 吕布攻袁术于阜陵并留袁涣

[《三国志·袁张凉国田王邴管传》仓内原文 L535](../../sources/本地分卷/三国志/三国志-卷011.md#l535)

> 頃之，呂布擊術於阜陵，渙往從之，遂復為布所拘留。

吕布进攻袁术，袁涣往随他，又被拘留。

**时段与依据** 《武帝纪》《吕布传》所载吕布与袁术相攻没有阜陵这一地名，尚待互证。

<a id="period-sgz011-b-535-7"></a>

### 吕布与刘备由和而隙

[《三国志·袁张凉国田王邴管传》仓内原文 L535](../../sources/本地分卷/三国志/三国志-卷011.md#l535)

> 布初與劉備和親，後離隙。

吕布和刘备起初亲善，后来失和。

**时段与依据** 二人不止一次由和转战，此处未明所指。

<a id="period-sgz011-b-535-8"></a>

### 吕布强令袁涣写信侮辱刘备

[《三国志·袁张凉国田王邴管传》仓内原文 L535](../../sources/本地分卷/三国志/三国志-卷011.md#l535)

> 布欲使渙作書詈辱備，渙不可，再三彊之，不許。

吕布屡次催逼袁涣写信辱骂刘备，袁涣拒绝。

**时段与依据** 《通鉴》系建安元年，本传述阜陵被留以后而未著年。

<a id="period-sgz011-b-535-9"></a>

### 吕布威逼袁涣

[《三国志·袁张凉国田王邴管传》仓内原文 L535](../../sources/本地分卷/三国志/三国志-卷011.md#l535)

> 布大怒，以兵脅渙曰：「為之則生，不為則死。」

吕布大怒，用武力逼他在执笔与死之间选择。

**时段与依据** 同前。

<a id="period-sgz011-b-535-10"></a>

### 袁涣以德辩辱

[《三国志·袁张凉国田王邴管传》仓内原文 L535](../../sources/本地分卷/三国志/三国志-卷011.md#l535)

> 渙顏色不變，笑而應之曰：「渙聞唯德可以辱人，不聞以罵。使彼固君子邪，且不恥將軍之言，彼誠小人邪，將復將軍之意，則辱在此不在於彼。

袁涣不改神色，说明君子不会因流言耻辱，而若骂了小人倒反过来暴露将军的心意。

**时段与依据** 同前。

<a id="period-sgz011-b-535-11"></a>

### 袁涣拒骂故主，吕布惭止

[《三国志·袁张凉国田王邴管传》仓内原文 L535](../../sources/本地分卷/三国志/三国志-卷011.md#l535)

> 且渙他日之事劉將軍，猶今日之事將軍也，如一旦去此，復罵將軍，可乎？」布慙而止。

袁涣说从前侍奉刘备和现在侍奉吕布一样，反问若他离开后也痛骂吕布可不可；吕布惭愧而止。

**时段与依据** 同前。

<a id="period-sgz011-b-536-2"></a>

### 袁涣论以仁义行师

[《三国志·袁张凉国田王邴管传》仓内原文 L536](../../sources/本地分卷/三国志/三国志-卷011.md#l536)

> 渙言曰：「夫兵者，兇器也，不得已而用之。鼓之以道德，征之以仁義，兼撫其民而除其害。夫然，故可與之死而可與之生。

袁涣说兵器不祥，不得已而用，应以道德激励、仁义征讨，抚民除害，才能与人共生死。

**时段与依据** 本传置于198归附后。

<a id="period-sgz011-b-536-3"></a>

### 袁涣论乱世政治

[《三国志·袁张凉国田王邴管传》仓内原文 L536](../../sources/本地分卷/三国志/三国志-卷011.md#l536)

> 自大亂以來十數年矣，民之欲安，甚於倒縣，然而暴亂未息者，何也？意者政失其道歟！渙聞明君善於救世，故世亂則齊之以義，時偽則鎮之以樸；世異事變，治國不同，不可不察也。

袁涣说大乱十余年，百姓渴望安定，乱久恐因施政失当，明主须因时以义、以质朴调整治道。

**时段与依据** 同上。

<a id="period-sgz011-b-536-4"></a>

### 袁涣论制度可变而爱民不变

[《三国志·袁张凉国田王邴管传》仓内原文 L536](../../sources/本地分卷/三国志/三国志-卷011.md#l536)

> 夫制度損益，此古今之不必同者也。若夫兼愛天下而反之於正，雖以武平亂而濟之以德，誠百王不易之道也。

制度可以调整，兼爱天下、以武定乱兼以德济之，是历朝共守的常道。

**时段与依据** 同上。

<a id="period-sgz011-b-536-5"></a>

### 曹操纳袁涣之言，拜沛南部都尉

[《三国志·袁张凉国田王邴管传》仓内原文 L536](../../sources/本地分卷/三国志/三国志-卷011.md#l536)

> 公明哲超世，古之所以得其民者，公旣勤之矣，今之所以失其民者，公旣戒之矣，海內賴公，得免於危亡之禍，然而民未知義，其唯公所以訓之，則天下幸甚！」太祖深納焉。拜為沛南部都尉。

袁涣劝曹操教民明义，曹操赞许，拜为沛南部都尉。

**时段与依据** 叙次能与归曹相接，具体上言、任命日期均未署。

<a id="period-sgz011-b-537-1"></a>

### 袁涣劝曹操屯田从自愿

[《三国志·袁张凉国田王邴管传》仓内原文 L537](../../sources/本地分卷/三国志/三国志-卷011.md#l537)

> 是時新募民開屯田，民不樂，多逃亡。渙白太祖曰：「夫民安土重遷，不可卒變，易以順行，難以逆動，宜順其意，樂之者乃取，不欲者勿彊。」太祖從之，百姓大恱。

新募屯田多逃亡，袁涣以安土重迁为由建议从民自愿，曹操接受，百姓欢喜。

**时段与依据** 袁涣198后始归曹；建安元年曹操初置屯田与本事分别。

<a id="period-sgz011-b-537-2"></a>

[《三国志·袁张凉国田王邴管传》仓内原文 L537](../../sources/本地分卷/三国志/三国志-卷011.md#l537)

> 遷為梁相。

袁涣升任梁相。

**时段与依据** 无系年。

<a id="period-sgz011-b-537-3"></a>

### 袁涣告诸县存恤、彰礼

[《三国志·袁张凉国田王邴管传》仓内原文 L537](../../sources/本地分卷/三国志/三国志-卷011.md#l537)

> 渙每勑諸縣：「務存鰥寡高年，表異孝子貞婦。常談曰『世治則禮詳，世亂則禮簡』，全在斟酌之間耳。方今雖擾攘，難以禮化，然在吾所以為之。」

袁涣命各县救济鳏寡老人，表彰孝子贞妇，认为治世礼详、乱世礼简，当从实际斟酌教化。

**时段与依据** 同其梁相任内。

<a id="period-sgz011-b-537-4"></a>

### 袁涣在梁的施政及去官

[《三国志·袁张凉国田王邴管传》仓内原文 L537](../../sources/本地分卷/三国志/三国志-卷011.md#l537)

> 為政崇教訓，恕思而後行，外溫柔而內能斷。以病去官，百姓思之。

重视训教，宽仁有决断，因病离任后常为百姓思念。

**时段与依据** 无系年。

<a id="period-sgz011-b-537-5"></a>

### 袁涣为谏议大夫、丞相军祭酒

[《三国志·袁张凉国田王邴管传》仓内原文 L537](../../sources/本地分卷/三国志/三国志-卷011.md#l537)

> 後徵為諫議大夫、丞相軍祭酒。

曹操征袁涣任谏议大夫和丞相军祭酒。

**时段与依据** 曹操208封丞相，袁涣213已为郎中令。

<a id="period-sgz011-b-537-6"></a>

### 袁涣散赏廉清

[《三国志·袁张凉国田王邴管传》仓内原文 L537](../../sources/本地分卷/三国志/三国志-卷011.md#l537)

> 前後得賜甚多，皆散盡之，家無所儲，終不問產業，乏則取之於人，不為皦察之行，然時人服其清。

所受赏赐都分给他人，不经营产业，困乏时求助，也不矫饰清白，而当世佩服他的廉行。

**时段与依据** 概叙一生。

<a id="period-sgz011-b-538-2"></a>

### 袁涣倡议搜集典籍与推行文教

[《三国志·袁张凉国田王邴管传》仓内原文 L538](../../sources/本地分卷/三国志/三国志-卷011.md#l538)

> 渙言於太祖曰：「今天下大難已除，文武並用，長久之道也。以為可大收篇籍，明先聖之教，以易民視聽，使海內斐然向風，則遠人不服可以文德來之。」太祖善其言。

认为天下大难初除，文武并用可长治，宜广搜典籍阐明圣教，使民向化并及远人，曹操赞许。

**时段与依据** 置于魏国建立后的郎中令任内。

<a id="period-sgz011-b-538-3"></a>

### 袁涣独不贺刘备死讯

[《三国志·袁张凉国田王邴管传》仓内原文 L538](../../sources/本地分卷/三国志/三国志-卷011.md#l538)

> 時有傳劉備死者，羣臣皆賀；渙以甞為備舉吏，獨不賀。

传言刘备死去，众臣祝贺，袁涣认为自己曾由刘备举荐，独不祝贺。

**时段与依据** 传语既误，不以刘备实际卒年编排。

<a id="period-sgz011-b-538-4"></a>

### 袁涣在官数年卒

[《三国志·袁张凉国田王邴管传》仓内原文 L538](../../sources/本地分卷/三国志/三国志-卷011.md#l538)

> 居官數年卒，太祖為之流涕，

袁涣在郎中令任数年后去世，曹操为之流泪。

**时段与依据** 始任213、卒于曹操生前，未明具体年。

<a id="period-sgz011-b-538-5"></a>

### 曹操以官俸及私情分别赐谷

[《三国志·袁张凉国田王邴管传》仓内原文 L538](../../sources/本地分卷/三国志/三国志-卷011.md#l538)

> 賜穀二千斛，一教「以太倉穀千斛賜郎中令之家」，一教「以垣下穀千斛與曜卿家」，外不解其意。教曰：「以太倉穀者，官法也；以垣下穀者，親舊也。」

曹操以太仓谷千斛给郎中令家，另以垣下谷千斛给曜卿家，区别法定抚赐和故交情谊。

**时段与依据** 袁涣卒后。

<a id="period-sgz011-b-538-6"></a>

### 袁敏谈袁涣的勇决

[《三国志·袁张凉国田王邴管传》仓内原文 L538](../../sources/本地分卷/三国志/三国志-卷011.md#l538)

> 又帝聞渙昔拒呂布之事，問渙從弟敏：「渙勇怯何如？」敏對曰：「渙貌似和柔，然其臨大節，處危難，雖賁、育不過也。」

帝问袁敏袁涣拒吕布是否出于勇敢，袁敏答说他外貌柔和，临大节、处危难甚至胜过孟贲夏育。

**时段与依据** 帝未具名，具体年月无征。

袁涣子袁侃清纯朴素，有父亲风范，历任郡守、尚书。

**时段与依据** 无系年。

<a id="period-sgz011-b-539-1"></a>

袁霸行事公谨有才，魏初任大司农，与同郡何夔齐名。

**时段与依据** 魏初未指具体一岁，不与213王脩任大司农混列。

袁霸子袁亮、何夔子何曾与袁侃声望相当，亦友好。

**时段与依据** 无系年。

<a id="period-sgz011-b-539-3"></a>

袁亮坚贞好学，作文讥评何晏、邓飏等人，后来任河南尹、尚书。

**时段与依据** 二人在世时著论，官职另无确年。

袁徽有清儒之名，乱中避居交州，不赴司徒的辟召。

[《三国志·袁张凉国田王邴管传》仓内原文 L547](../../sources/本地分卷/三国志/三国志-卷011.md#l547)

> 時有投書誹謗者，太祖疾之，欲必知其主。淵請留其本書，而不宣露。

有人投书诽谤，曹操欲查作者，国渊请留原书并保密。

**时段与依据** 任魏郡太守后，无系年。

<a id="period-sgz011-b-547-2"></a>

### 国渊用《二京赋》寻线索

[《三国志·袁张凉国田王邴管传》仓内原文 L547](../../sources/本地分卷/三国志/三国志-卷011.md#l547)

> 其書多引二京賦，淵勑功曹曰：「此郡旣大，今在都輦，而少學問者。其簡開解年少，欲遣就師。」

书引《二京赋》，于是令功曹选开悟少年去求师，以找能读赋的人。

**时段与依据** 同案。

<a id="period-sgz011-b-547-3"></a>

### 国渊选少年三人与暗授机宜

[《三国志·袁张凉国田王邴管传》仓内原文 L547](../../sources/本地分卷/三国志/三国志-卷011.md#l547)

> 功曹差三人，臨遣引見，訓以「所學未及，二京賦，博物之書也，世人忽略，少有其師，可求能讀者從受之。」又密喻旨。

功曹选三人，国渊令寻精于《二京赋》的老师，又私下告知目的。

**时段与依据** 同案。

<a id="period-sgz011-b-547-4"></a>

### 国渊由笔迹查获投书人

[《三国志·袁张凉国田王邴管传》仓内原文 L547](../../sources/本地分卷/三国志/三国志-卷011.md#l547)

> 旬日得能讀者，遂往受業。吏因請使作箋，比方其書，與投書人同手。收攝案問，具得情理。

十日找到通晓赋学之人，书吏邀其代写，笔迹相同，遂拘问得情。

**时段与依据** 同案。

<a id="period-sgz011-b-547-5"></a>

> 遷太僕。居列卿位，布衣蔬食，祿賜散之舊故宗族，以恭儉自守，卒官。

升太仆后仍布衣粗食，俸赐分给亲族故交，恭俭自持，在任上去世。

**时段与依据** 无确年。

田畴字子泰，右北平无终人，好书与剑。

**时段与依据** 传首。

<a id="period-sgz011-b-550-1"></a>

### 田畴由塞外至长安复命

[《三国志·袁张凉国田王邴管传》仓内原文 L550](../../sources/本地分卷/三国志/三国志-卷011.md#l550)

> 旣取道，疇乃更上西關，出塞，傍北方，直趣朔方，循閒徑去，遂至長安致命。

取道西关、沿塞外趋朔方，沿小路抵长安，传达刘虞使命。

**时段与依据** 190派遣、193刘虞死之间；《通鉴》回叙并辨《后汉书》刘和出京与出使关系。

<a id="period-sgz011-b-550-2"></a>

### 田畴辞骑都尉

[《三国志·袁张凉国田王邴管传》仓内原文 L550](../../sources/本地分卷/三国志/三国志-卷011.md#l550)

> 詔拜騎都尉。疇以為天子方蒙塵未安，不可以荷佩榮寵，固辭不受。朝廷高其義。

获拜骑都尉，以天子流离未安，推辞荣宠，朝廷称义。

**时段与依据** 抵长安之后。

<a id="period-sgz011-b-551-1"></a>

### 田畴率族人北归盟誓

[《三国志·袁张凉国田王邴管传》仓内原文 L551](../../sources/本地分卷/三国志/三国志-卷011.md#l551)

> 疇得北歸，率舉宗族他附從數百人，埽地而盟曰：「君仇不報，吾不可以立於世！」

田畴返回北面，率族人及跟随者数百人举誓，要报刘虞之仇。

**时段与依据** 193获释以后，未见精确年。

<a id="period-sgz011-b-551-4"></a>

### 田畴为民众推为首领

[《三国志·袁张凉国田王邴管传》仓内原文 L551](../../sources/本地分卷/三国志/三国志-卷011.md#l551)

> 疇謂其父老曰：「諸君不以疇不肖，遠來相就。衆成都邑，而莫相統一，恐非久安之道，願推擇其賢長者以為之主。」皆曰：「善。」同僉推疇。

为使人群有统属，田畴提议选择贤长，众人一致推举他。

**时段与依据** 聚居后。

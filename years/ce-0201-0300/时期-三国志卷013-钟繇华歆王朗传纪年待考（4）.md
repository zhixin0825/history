### 贾洪外任阴泉长

[《三国志·钟繇华歆王朗传》裴注 038·21](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-21)

> 晚乃出為隂泉長

后任阴泉长。

**时段与依据** “晚”而未载哪一岁。

<a id="period-sgz013-p-038-23"></a>

### 白马王重贾洪文才，贾洪病卒

[《三国志·钟繇华歆王朗传》裴注 038·23](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-23)

> 善能談戲王彪亦雅好文學常師宗之過扵三卿數嵗病亡亡時年五十餘時人為之恨仕不至二千石

白马王好文学，尊礼贾洪过于三卿；贾洪后卒五十余岁，未任二千石为时人所惜。

**时段与依据** 由相王数年后，未以虚岁定卒年。“王彪”指王名彪。

<a id="period-sgz013-p-038-24"></a>

### 严苞历县、黄初为秘书丞卒官

[《三国志·钟繇华歆王朗传》裴注 038·24](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-24)

> 而嚴苞亦歴守二縣黄初中以髙才入為秘書丞數奏文賦文帝異之出為西平太守卒官

任两县官，黄初因才为秘书丞，上奏文赋为文帝所异，后来任西平太守卒官。

**时段与依据** 多年仕历。

<a id="period-sgz013-p-038-25"></a>

### 薛夏不降天水四姓，东往得曹操礼遇

[《三国志·钟繇华歆王朗传》裴注 038·25](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-25)

> 薛夏字宣聲天水人也博學有才天水舊有姜閻任趙四姓常推扵郡中而夏為單家不為降屈四姓欲共治之夏乃㳺逸東詣京師太祖宿聞其名甚禮遇之

薛夏单家而有才，当地姜阎任赵四族想制驭未成，东来京师，曹操以早闻名礼待。

**时段与依据** 曹操据朝时期。

<a id="period-sgz013-p-038-26"></a>

### 天水四姓构陷薛夏，曹操释之

[《三国志·钟繇华歆王朗传》裴注 038·26](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-26)

> 後四姓又使囚遥引夏闗移潁川收捕繫獄時太祖已在冀州聞夏為夲部所質撫掌曰夏無罪也漢陽兒軰直欲殺之耳乃告潁川使理出之召署軍謀掾

四姓教囚徒攀引薛夏，颍川拘系，曹操知无罪令释放并辟军谋掾。

**时段与依据** 曹操已据冀州以后。

<a id="period-sgz013-p-038-27"></a>

### 薛夏为秘书丞，曹丕论书传礼遇

[《三国志·钟繇华歆王朗传》裴注 038·27](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-27)

> 文帝又嘉其才黄初中為秘書丞帝每與夏推論書傳未嘗不終日也每呼之不名而謂之薛君夏居甚貧帝又顧其衣薄觧所御服袍賜之

曹丕每同薛夏讲经书尽日，称薛君；贫衣薄，帝解己袍给他。

**时段与依据** 黄初跨年。

<a id="period-sgz013-p-038-28"></a>

### 曹丕向曹休介绍薛夏

[《三国志·钟繇华歆王朗传》裴注 038·28](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-28)

> 其後征東將軍曹休來朝時帝方與夏有所咨論而外啓休到帝引入坐定帝顧夏言之於休曰此君秘書丞天水薛宣聲也宜共談其見遇如此㝷欲用之㑹文帝崩

曹休入朝，曹丕让坐并请和薛夏共谈，想进一步用夏，却遇曹丕死。

**时段与依据** 曹休任征东跨年，曹丕卒另确226。

<a id="period-sgz013-p-038-29"></a>

### 薛夏为秘书署争与兰台公文往来

[《三国志·钟繇华歆王朗传》裴注 038·29](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-29)

> 至太和中甞以公事移蘭臺蘭臺自以臺也而秘書署耳謂夏為不得儀也推使當有坐者夏報之曰蘭臺為外臺秘書為内閣臺閣一也何不相移之有蘭臺屈無以折自是之後遂以為常

兰台自谓署官无通用资格，薛夏说兰台外台、秘书内阁一样，兰台屈服，互相移文成例。

**时段与依据** 《魏略》称太和中。

<a id="period-sgz013-p-038-30"></a>

### 薛夏病卒，嘱子不回天水

[《三国志·钟繇华歆王朗传》裴注 038·30](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-30)

> 後數嵗病亡勅其子無還天水

过数年病卒，告儿不返故乡。

**时段与依据** 相对年距。

<a id="period-sgz013-p-038-31"></a>

### 隗禧早年好学，初平避三辅乱

[《三国志·钟繇华歆王朗传》裴注 038·31](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-31)

> 隗禧字子牙京兆人也世單家少好學初平中三輔亂禧南客荆州不以荒擾擔負經書每以採梠餘日則誦習之

出单家，乱中南客荆州，仍负书并采樵诵习。

**时段与依据** 初平数年。

<a id="period-sgz013-p-038-33"></a>

### 隗禧为谯王郎中授经

[《三国志·钟繇华歆王朗传》裴注 038·33](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-33)

> 黄初中為譙王郎中王宿聞其儒者常虗心從學禧亦敬恭以授王由是大得賜遺以病還拜郎中

谯王虚心受教，隗禧恭授，受赐多，后病退拜郎中。

**时段与依据** 黄初中，当谯王为王后，未见确年。

<a id="period-sgz013-p-038-34"></a>

### 隗禧八十余岁居家，治经察天象

[《三国志·钟繇华歆王朗传》裴注 038·34](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-34)

> 年八十餘以老處家就之學者甚多禧既明經又善星官常仰瞻天文嘆息謂魚豢曰天下兵戈尚猶未息如之何

多来请学，为天象所见而叹战争尚未停止。

**时段与依据** 仅有年龄。

<a id="period-sgz013-p-038-35"></a>

### 隗禧告鱼豢治《易》《礼》《诗》各有长

[《三国志·钟繇华歆王朗传》裴注 038·35](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-35)

> 豢又嘗從問左氏傳禧答曰欲知幽㣲莫若易人倫之紀莫若禮多識山川草木之名莫若詩左氏直相斫書耳不足精意也

求幽微莫如易、论伦纪莫如礼、识物名莫如诗，左传多战事，不值得过专。

**时段与依据** 学术谈话。

<a id="period-sgz013-p-038-36"></a>

### 隗禧通四家诗，著经解，未誊写而聋

[《三国志·钟繇华歆王朗传》裴注 038·36](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-36)

> 豢因從問詩禧説齊韓魯毛四家義不復執文有如諷誦又撰作諸經觧數十萬言未及繕寫而得聾後數嵗病亡也

不用执文能诵四家，撰数十万言，经稿未完而聋，数年后病卒。

**时段与依据** 总叙著述与晚年。

<a id="period-sgz013-p-038-37"></a>

### 鱼豢说明邯郸淳等另见他传

[《三国志·钟繇华歆王朗传》裴注 038·37](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-37)

> 其邯鄲淳事在王粲傳蘇林事在劉邵髙堂隆傳樂詳亊在杜畿傳

苏林在刘劭高堂隆传、乐详在杜畿传，各有记叙。

**时段与依据** 《魏略》编例；TXT L678夹该句部分。

<a id="period-sgz013-p-038-38"></a>

### 鱼豢论学习可以益才如蓝染素

[《三国志·钟繇华歆王朗传》裴注 038·38](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-38)

> 魚豢曰學之資扵人也其猶藍之染扵素乎故雖仲尼稱曰吾非生而知之者况凡品哉且世人所以不貴學者必見夫有誦詩三百而不能専對扵四方故也余以為是則下科耳不當顧中庸以上材質適等而加之以文乎

孔子尚说不生知，不能只因读诗却不能专对的下等例，就否认中等以上人学习可增进。

**时段与依据** 史家论。

<a id="period-sgz013-p-038-39"></a>

### 鱼豢论七人以持学由此成名

[《三国志·钟繇华歆王朗传》裴注 038·39](../../sources/摘录/三国志-卷013-钟繇华歆王朗传裴注.md#pei-038-39)

> 今此數賢者畧余之所識也檢其事能誠不多也但以守學不輟乃上為帝王所嘉下為國家名儒非由學乎由是觀之學其胡可以已哉

若干熟悉人物所事能未必多，却坚持学，获帝王重视为国之儒，岂非学之故。

**时段与依据** 史家论；与正文底本末句对应。

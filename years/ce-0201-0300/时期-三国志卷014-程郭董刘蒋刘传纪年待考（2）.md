### 刘放涂改孙权来信以离间吴蜀

[《三国志·程郭董刘蒋刘传》仓内原文 L773](../../拆分史书/三国志/卷014.md#l773)

魏边候得孙权信，刘放涂改使呈似孙权拟归满宠，递交诸葛亮；亮经步骘示孙权，孙权力作解释。

**时段与依据** 本传仅“青龍初”，事情起讫无月；诸葛亮于234年卒，可限233—234。

<a id="wei014-l151-2"></a>

**[《三國志·程郭董劉蔣劉傳》正文](../../拆分史书/三国志/卷014.md#edition-wei014-l151-2)** · [TXT L151](../../拆分史书/三国志/卷014.txt#L151)

> 青龍初，孫權與諸葛亮連和，欲俱出爲寇。邊候得權書，放乃改易其辭，往往換其本文而傅合之，與征東將軍滿寵，若欲歸化，封以示亮。亮騰與吳大將步隲等，以見權。權懼亮自疑，深自解說。

**釋讀與歸年** 青龙初吴与蜀谋共伐魏，刘放改吴书措辞，假托满宠想归附蜀，寄示诸葛亮。诸葛亮转给步骘等，孙权唯恐蜀有疑心而特作解释。青龙初只给时段，234年吴蜀确有同时出师，可互见；不能由此确定改书就在234年某月。

### 刘放、孙资掌机要的褒贬

[《三国志·程郭董刘蒋刘传》仓内原文 L776](../../拆分史书/三国志/卷014.md#l776)

刘放才计优而修身不足，二人惯于顺主、压辛毗助王思受人非议，也时助臣下争谏、提出损益之策。

**时段与依据** 传末总论，王思等事不具时。

<a id="wei014-l163-1"></a>

**[《三國志·程郭董劉蔣劉傳》正文](../../拆分史书/三国志/卷014.md#edition-wei014-l163-1)** · [TXT L163](../../拆分史书/三国志/卷014.txt#L163)

> 放才計優資，而自脩不如也。放、資旣善承順主上，又未嘗顯言得失，抑辛毗而助王思，以是獲譏於世。然時因群臣諫諍，扶贊其義，并時密陳損益，不專導諛言云。

**釋讀與歸年** 评刘放才谋优于孙资，修身则不及。两人顺上意、抑辛毗助王思受讥，也曾赞助群臣谏议、密陈得失，不能尽作谄媚看。是一段总叙。

### 陈寿论程昱至孙资诸人

[《三国志·程郭董刘蒋刘传》仓内原文 L778](../../拆分史书/三国志/卷014.md#l778)

赞程昱等五人筹画后果足与荀攸并论；刘放、孙资文翰勤慎，掌握机要，失之不够直亮，世俗谗议也过其实。

**时段与依据** 陈寿卷末评论。

<a id="wei014-l166-1"></a>

**[《三國志·程郭董劉蔣劉傳》正文](../../拆分史书/三国志/卷014.md#edition-wei014-l166-1)** · [TXT L166](../../拆分史书/三国志/卷014.txt#L166)

> 評曰：程昱、郭嘉、董昭、劉曄、蔣濟才策謀略，世之奇士，雖清治德業殊於荀攸，而籌畫所料是其倫也。劉放文翰，孫資勤慎，並管喉舌，權聞當時，雅亮非體，是故譏諛之聲，每過其實矣。

**釋讀與歸年** 陈寿合评程昱、郭嘉、董昭、刘晔、蒋济之才策，认为可比荀攸的谋略，但清治德业并不相同；刘放擅文翰、孙资勤谨，两人掌机密所受讥论往往过实。为全卷论赞。

### 《世语》谓程昱以人脯筹粮导致失朝望

[《三国志·程郭董刘蒋刘传》裴注 005·2](../../拆分史书/三国志/卷014.md#pei-005-2)

《世语》把早年曹军乏食时程昱提供三日粮、杂以人脯与后来不至三公相联系。

**时段与依据** 注文只说“初太祖乏食”，兖州乏食非仅一时；因果是该书自说。

<a id="wei014-l21-2"></a>

**[《三國志·程郭董劉蔣劉傳》裴注](../../拆分史书/三国志/卷014.md#edition-wei014-l21-2)** · [TXT L21](../../拆分史书/三国志/卷014.txt#L21)

> 世語曰：初，太祖乏食，昱略其本縣，供三日糧，頗雜以人脯，由是失朝望，故位不至公。

**釋讀與歸年** 《世语》称曹操初乏粮，程昱掠本县供三日粮，所供杂有人脯，以此解释未至公位。传文没给该次供粮确年，将此说附在生平，勿从濮阳粮尽径定。

### 曹操征刘晔蒋济等五人，独任刘晔腹心

[《三国志·程郭董刘蒋刘传》裴注 020·1](../../拆分史书/三国志/卷014.md#pei-020-1)

曹操征召扬州五有名之士，沿途诸人竞习答问而刘晔闭口，刘晔见曹操只发远言留待独问，曹操知其意果任之腹心，日夜封函相询。

**时段与依据** 《傅子》传体轶事，依附刘晔受辟，未载年月。

<a id="wei014-l92-1"></a>

**[《三國志·程郭董劉蔣劉傳》裴注](../../拆分史书/三国志/卷014.md#edition-wei014-l92-1)** · [TXT L92](../../拆分史书/三国志/卷014.txt#L92)

> 傅子曰：太祖徵曄及蔣濟、胡質等五人，皆揚州名士。每舍亭傳，未曾不講，所以見重；內論國邑先賢、禦賊固守、行軍進退之宜，外料敵之變化、彼我虛實、戰爭之術，夙夜不解。而曄獨卧車中，終不一言。濟怪而問之，曄荅曰：「對明主非精神不接，精神可學而得乎？」及見太祖，太祖果問揚州先賢，賊之形勢。四人爭對，待次而言，再見如此，太祖每和恱，而曄終不一言。四人笑之。後一見太祖止無所復問，曄乃設遠言以動太祖，太祖適知便止。若是者三。其旨趣以爲遠言宜徵精神，獨見以盡其機，不宜於猥坐說也。太祖已探見其心矣，坐罷，尋以四人爲令，而授曄以心腹之任；每有疑事，輒以函問曄，至一夜數十至耳。

**釋讀與歸年** 《傅子》叙曹操征刘晔、蒋济、胡质等五人。刘晔同行少言，见曹操时不与其余四人争对，等到独见才论及深远之事；曹操授以心腹之任，多次以书函问策。传未明征召与本传寿春任职同日。

**时段与依据** 志怪只说蒋济为领军时，239—242年间，不能作确年现实实录。

<a id="wei014-l127-1"></a>

**[《三國志·程郭董劉蔣劉傳》裴注](../../拆分史书/三国志/卷014.md#edition-wei014-l127-1)** · [TXT L127](../../拆分史书/三国志/卷014.txt#L127)

> 列異傳曰：濟爲領軍，其婦夢見亡兒涕泣曰：「死生異路，我生時爲卿相子孫，今在地下爲泰山五伯，憔悴困辱，不可復言。今太廟西謳士孫阿，今見召爲泰山令，願母爲白侯，屬阿令轉我得樂處。」言訖，母忽然驚寤，明日以白濟。濟曰：「夢爲爾耳，不足恠也。」明日暮，復夢曰：「我來迎新君，止在廟下。未發之頃，暫得來歸。新君明日日中當發，臨發多事，不復得歸，永辭於此。侯氣彊，難感悟，故自訴於母，願重啟侯，何惜不一試驗之？」遂道阿之形狀，言甚備悉。天明，母重啟侯：「雖云夢不足恠，此何太適？適亦何惜不一驗之？」濟乃遣人詣太廟下，推問孫阿，果得之，形狀證驗悉如兒言。濟涕泣曰：「幾負吾兒！」於是乃見孫阿，具語其事。阿不懼當死，而喜得爲泰山令，惟恐濟言不信也。曰：「若如節下言，阿之願也。不知賢子欲得何職？」濟曰：「隨地下樂者與之。」阿曰：「輒當奉教。」乃厚賞之，言訖遣還。濟欲速知其驗，從領軍門至廟下，十步安一人，以傳消息。辰時傳阿心痛，巳時傳阿劇，日中傳阿亡。濟泣曰：「雖哀吾兒之不幸，自喜亡者有知。」後月餘，兒復來語母曰：「已得轉爲錄事矣。」

**釋讀與歸年** 《列异传》记蒋济任领军将军时，其妻梦亡儿托孙阿在冥府转职。蒋济访得孙阿，孙阿死后亡儿复入梦说已为录事。这是任领军期间的传闻，确月年不详。

<a id="wei014-l129-1"></a>

**[《三國志·程郭董劉蔣劉傳》裴注](../../拆分史书/三国志/卷014.md#edition-wei014-l129-1)** · [TXT L129](../../拆分史书/三国志/卷014.txt#L129)

### 蒋济辩郊祭不宜以舜为曹祖

[《三国志·程郭董刘蒋刘传》裴注 029·4](../../拆分史书/三国志/卷014.md#pei-029-4)

蒋济和高堂隆、缪袭辨驳郊礼，反对无据据舜为族并降太祖配天。又以豺獭只祭本先驳郑玄，裴松之认为虽诙谐尚有义。

**时段与依据** 高堂隆议成立于景初，双方往返与批评郑玄分别未载年。

<a id="wei014-l129-4"></a>

**[《三國志·程郭董劉蔣劉傳》裴注](../../拆分史书/三国志/卷014.md#edition-wei014-l129-4)** · [TXT L129](../../拆分史书/三国志/卷014.txt#L129)

> 尋濟難隆，及與尚書繆襲往反，並有理據，文多不載。濟亦未能定氏族所出，但謂「魏非舜後而橫祀非族，降黜太祖，不配正天，皆爲繆妄」。然于時竟莫能正。濟又難：鄭玄注祭法云「有虞以上尚德，禘郊祖宗，配用有德，自夏已下，稍用其姓氏」。濟曰：「夫虯龍神於獺，獺自祭其先，不祭虯龍也。騏驎白虎仁於豺，豺自祭其先，不祭騏虎也。如玄之說，有虞已上，豺獺之不若邪？臣以爲祭法所云，見疑學者乆矣，鄭玄不考正其違而就通其義。」濟豺獺之譬，雖似俳諧，然其義旨，有可求焉。

**釋讀與歸年** 蒋济与高堂隆、缪袭辩郊祀，反对曹氏祀非其族及降黜太祖，以豺、獭自祭其先驳郑玄注。《裴注》认为此譬虽近俳谐而有义理。论辩可与景初元年礼议合读，确切著文年未见。

<a id="wei014-l145-3"></a>

**[《三國志·程郭董劉蔣劉傳》裴注](../../拆分史书/三国志/卷014.md#edition-wei014-l145-3)** · [TXT L145](../../拆分史书/三国志/卷014.txt#L145)

> 友人河東賈逵謂資曰：「足下抱逸群之才，值舊邦傾覆，主將殷勤，千里延頸，宜崇古賢桑梓之義。而乆盤桓，拒違君命，斯猶曜和璧於秦王之庭，而塞以連城之價耳。竊爲足下不取也！」資感其言，遂往應之。到署功曹，舉計吏。尚書令荀彧見資，歎曰：「北州承喪亂已乆，謂其賢智零落，今日乃復見孫計君乎！」表留以爲尚書郎。辭以家難，得還河東。

**釋讀與歸年** 贾逵以故土倾覆、守长想延揽劝孙资应命，孙资遂任功曹并举计吏。荀彧见而举为尚书郎，孙资因家难辞归。[《荀彧传》](../../拆分史书/三国志/卷010.txt#L14-L25)可参荀彧掌尚书时期，本段无独立年月。

### 《资别传》记孙资议兵政及救满宠徐邈

[《三国志·程郭董刘蒋刘传》裴注 036·1](../../拆分史书/三国志/卷014.md#pei-036-1)

孙资参议频繁军务却主张公开与众讨论，择善而不彰己功，为受谗满宠徐邈辨其素行。

**时段与依据** “是时”承青龙初而所说“无岁不有军征”及平生综评，无单年。

<a id="wei014-l152-1"></a>

**[《三國志·程郭董劉蔣劉傳》裴注](../../拆分史书/三国志/卷014.md#edition-wei014-l152-1)** · [TXT L152](../../拆分史书/三国志/卷014.txt#L152)

> 資別傳曰：是時，孫權、諸葛亮號稱劇賊，無歲不有軍征。而帝總攝群下，內圖禦寇之計，外規廟勝之畫，資皆管之。然自以受腹心，常讓事於帝曰：「動大衆，舉大事，宜與群下共之；旣以示明，且於探求爲廣。」旣朝臣會議，資奏當其是非，擇其善者推成之，終不顯己之德也。若衆人有譴過及愛憎之說，輒復爲請解，以塞譖潤之端。如征東將軍滿寵、涼州刺史徐邈，並有譖毀之者，資皆盛陳其素行，使卒無纖介。寵、邈得保其功名者，資之力也。

**釋讀與歸年** 《资别传》说孙资历年参预防吴蜀军政，主张谋大事与众议，自行分辨异同却不矜功；还为受人谗毁的满宠、徐邈辨解。属历年行事。

<a id="period-sgz014-p-036-2"></a>

### 孙资化解田豫等旧怨并扶持其子

[《三国志·程郭董刘蒋刘传》裴注 036·2](../../拆分史书/三国志/卷014.md#pei-036-2)

田豫、宗艳、杨丰先谮孙资，孙资不怨，与田氏结亲、助其子举孝廉，为触怒明帝的杨丰子求免。

**时段与依据** 《资别传》前期结怨与后来显贵解怨跨期。

<a id="wei014-l152-2"></a>

**[《三國志·程郭董劉蔣劉傳》裴注](../../拆分史书/三国志/卷014.md#edition-wei014-l152-2)** · [TXT L152](../../拆分史书/三国志/卷014.txt#L152)

> 初，資在邦邑，名出同類之右。鄉人司空掾田豫、梁相宗豔皆妬害之，而楊豐黨附豫等，專爲資構造謗端，怨隙甚重。資旣不以爲言，而終無恨意。豫等慙服，求釋宿憾，結爲婚姻。資謂之曰：「吾無憾心，不知所釋。此爲卿自薄之，卿自厚之耳！」乃爲長子宏取其女。及當顯位，而田豫老疾在家。資遇之甚厚，又致其子於本郡，以爲孝廉。而楊豐子後爲尚方吏，帝以職事譴怒，欲致之法，資請活之。其不念舊惡如此。

**釋讀與歸年** 田豫、宗艳、杨丰等旧日妒孙资，后来田豫等求和，孙资为长子孙宏娶田豫之女；他也优待年老的田豫、举其子，向皇帝求免杨丰之子。家传未标独立纪年。

<a id="period-sgz014-p-037-2"></a>

### 《资别传》记魏明帝与孙资议亲贵与托付

[《三国志·程郭董刘蒋刘传》裴注 037·2](../../拆分史书/三国志/卷014.md#pei-037-2)

明帝拟令诸亲掌兵并补射声校尉，孙资劝令亲藩有轻重节制，评平、勃、金、霍之任须亲信且经事检验。

**时段与依据** 《资别传》未明说与景初二年临终顾命为同一谈话；随注保存。

<a id="wei014-l156-2"></a>

**[《三國志·程郭董劉蔣劉傳》裴注](../../拆分史书/三国志/卷014.md#edition-wei014-l156-2)** · [TXT L156](../../拆分史书/三国志/卷014.txt#L156)

> 資別傳曰：帝詔資曰：「吾年稍長，又歷觀書傳中，皆歎息無所不念。圖萬年後計，莫過使親人廣據職勢，兵任又重。今射聲校尉缺，乆欲得親人，誰可用者？」資曰：「陛下思深慮遠，誠非愚臣所及。書傳所載，皆聖聽所究，向使漢高不知平、勃能安劉氏，孝武不識金、霍付屬以事，殆不可言！文皇帝始召曹真還時，親詔臣以重慮，及至晏駕，陛下即阼，猶有曹休外內之望，賴遭日月，御勒不傾，使各守分職，纖介不間。以此推之，親臣貴戚，雖當據勢握兵，宜使輕重素定。若諸侯典兵，力均衡平，寵齊愛等，則不相爲服；不相爲服，則意有異同。今五營所領見兵，常不過數百，選授校尉，如其輩類，爲有疇匹。至於重大之任，能有所維綱者，宜以聖意簡擇，如平、勃、金、霍、劉章等一二人，漸殊其威重，使相鎮固，於事爲善。」帝曰：「然。如卿言，當爲吾遠慮所圖。今日可參平、勃，侔金、霍，雙劉章者，其誰哉？」資曰：「臣聞知人則哲，惟帝難之。唐虞之聖，凡所進用，明試以功。陳平初事漢祖，絳、灌等謗平有受金盜嫂之罪。周勃以吹簫引彊，始事高祖，亦未知名也；高祖察其行跡，然後知可付以大事。霍光給事中二十餘年，小心謹慎，乃見親信。日磾夷狄，以至孝質直，特見擢用，左右尚曰『妄得一胡兒而重貴之』。平、勃雖安漢嗣，其終，勃被反名，平劣自免於呂須之讒。上官桀、桑弘羊與霍光爭權，幾成禍亂。此誠知人之不易，爲臣之難也。又所簡擇，當得陛下所親，當得陛下所信，誠非愚臣之所能識別。」

**釋讀與歸年** 《资别传》录曹叡请孙资议让宗亲典兵和谁可重托。孙资认为分权宜有轻重，以汉陈平、周勃、霍光、金日磾等成事后的才行为例，最终请曹叡自行审择。诏问确年未见，以顾命诸说参读。

### 裴松之驳孙氏家传掩饰改议顾命

[《三国志·程郭董刘蒋刘传》裴注 037·3](../../拆分史书/三国志/卷014.md#pei-037-3)

裴松之批评两位机要臣受托问大事却言辞两端；本传诸书都写他们劝赞曹爽和召司马懿，亡国由此开端，家传欲掩不能。

**时段与依据** 评的是景初末顾命与其后魏亡，非单年记事。

<a id="wei014-l156-3"></a>

**[《三國志·程郭董劉蔣劉傳》裴注](../../拆分史书/三国志/卷014.md#edition-wei014-l156-3)** · [TXT L156](../../拆分史书/三国志/卷014.txt#L156)

> 臣松之以爲孫、劉于時號爲專任，制斷機密，政事無不綜。資、放被託付之問，當安危所斷，而更依違其對，無有適莫。受人親任，理豈得然？案本傳及諸書並云放、資稱贊曹爽，勸召宣王，魏室之亡，禍基於此。資之別傳，出自其家，欲以是言掩其大失，然恐負國之玷，終莫能磨也。

**釋讀與歸年** 裴松之认为孙资、刘放身任中枢而回答依违，并据正文与诸书记两人参与改命，质疑家传有意掩饰。史家论断不与受诏同时作年。

### 《孙氏谱》《晋阳秋》记孙宏及后人

[《三国志·程郭董刘蒋刘传》裴注 040·1](../../拆分史书/三国志/卷014.md#pei-040-1)

孙宏做南阳太守；孙楚受王济赏知，为护军、冯翊太守；后人孙洵、孙盛、孙绰也有仕历及文名。

**时段与依据** 此为跨数世汇叙，TXT正文栏亦夹注录入，不宜强并为咸熙元年一事。

<a id="wei014-l164-1"></a>

**[《三國志·程郭董劉蔣劉傳》裴注](../../拆分史书/三国志/卷014.md#edition-wei014-l164-1)** · [TXT L164](../../拆分史书/三国志/卷014.txt#L164)

> 案孫氏譜：宏爲南陽太守。宏子楚，字子荊。晉陽秋曰：楚鄉人王濟，豪俊公子也，爲本州大中正。訪問關求楚品狀，濟曰：「此人非卿所能名。」自狀之曰：「天才英博，亮拔不羣。」楚位至討虜護軍、馮翊太守。

**釋讀與歸年** 《孙氏谱》记孙宏任南阳太守，子孙楚字子荆。《晋阳秋》有王济亲评孙楚才学、孙楚仕至馮翊太守等事。[《晋书·孙楚传》](../../史书/005-晋书/晋书-CCDH.txt#L6299-L6320)载入仕较详，王济品评与几次任官不能并定一年。

<a id="wei014-l164-2"></a>

**[《三國志·程郭董劉蔣劉傳》裴注](../../拆分史书/三国志/卷014.md#edition-wei014-l164-2)** · [TXT L164](../../拆分史书/三国志/卷014.txt#L164)

> 楚子洵，潁川太守。洵子盛，字安國，給事中，祕書監。盛從父弟綽，字興公，廷尉正。楚及盛、綽，並有文藻，盛又善言名理，諸所論著，並傳於世。

### 苏则经营金城、救济流民并教农

[《三国志·任苏杜郑仓传》仓内原文 L830](../../拆分史书/三国志/卷016.md#l830)

招羌胡得牲畜养贫老，共粮招回数千家，立赏罚、教耕种，丰收后归附日多。

**时段与依据** 多项措施及成效跨其金城任内。

<a id="wei016-l15-5"></a>

**[《三國志·任蘇杜鄭倉傳》正文](../../拆分史书/三国志/卷016.md#edition-wei016-l15-5)** · [TXT L15](../../拆分史书/三国志/卷016.txt#L15)

> 是時喪亂之後，吏民流散饑窮，戶口損耗，則撫循之甚謹。外招懷羌胡，得其牛羊，以養貧老。與民分糧而食，旬月之閒，流民皆歸，得數千家。乃明爲禁令，有干犯者輒戮，其從教者必賞。親自教民耕種，其歲大豐收，由是歸附者日多。

**釋讀與歸年** 金城战乱后户口流散，苏则抚恤百姓，招来羌胡，以所得牛羊赡养贫老，并与民分粮；旬月间收聚流民数千家。整顿赏罚、亲授耕作后获丰收，来归者日益增多。第18行张既另以登记户及归羌落数说明复苏规模。

### 曹丕谈受禅后哭者，苏则以为问己

[《三国志·任苏杜郑仓传》仓内原文 L832](../../拆分史书/三国志/卷016.md#l832)

在洛阳，曹丕质问何以有人哭，苏则须张欲正面回答。

**时段与依据** 曹丕已经受禅并在洛阳，故事不书确年。

<a id="wei016-l22-3"></a>

<a id="wei016-l23-1"></a>

<a id="wei016-l24-1"></a>

**[《三國志·任蘇杜鄭倉傳》](../../拆分史书/三国志/卷016.md#edition-wei016-l22-3)** · [TXT L22](../../拆分史书/三国志/卷016.txt#L22) · [TXT L23（裴注）](../../拆分史书/三国志/卷016.txt#L23) · [TXT L24](../../拆分史书/三国志/卷016.txt#L24)

> 帝在洛陽，嘗從容言曰：「吾應天而禪，而聞有哭者，何也？」則謂爲見問，鬚髯悉張，欲正論以對。侍中傅巽掐
>
> **〔裴注〕**
> 苦洽反。
>
> **〔正文續〕**
> 則曰：「不謂卿也。」於是乃止。

**釋讀與歸年** 曹丕在洛阳提起自己受禅时有人哭泣，苏则误以为帝指自己，欲出言；傅巽揪他示警。曹丕最迟220年末已到洛阳，实际对答在受禅以后、苏则出任东平相以前。

**釋讀與歸年** 为「掐」标音，接在傅巽阻止苏则的同一段。

**釋讀與歸年** 傅巽告诉苏则皇帝没有问他，苏则于是止住。行首「則」承第22行「傅巽掐」，是被揪的人。

<a id="wei016-l25-3"></a>

<a id="wei016-l25-4"></a>

**[《三國志·任蘇杜鄭倉傳》](../../拆分史书/三国志/卷016.md#edition-wei016-l25-3)** · [TXT L25（裴注）](../../拆分史书/三国志/卷016.txt#L25)

> **〔裴注〕**
> 其後文帝出游，追恨臨菑，顧謂左右曰：「人心不同，當我登大位之時，天下有哭者。」時從臣知帝此言，有爲而發也，而則以爲爲己，欲下馬謝。侍中傅巽目之，乃悟。
>
> **〔裴注〕**
> 孫盛曰：夫士不事其所非，不非其所事，趣舍出處，而豈徒哉！則旣策名新朝，委質異代，而方懷二心生忿，欲奮爽言，豈大雅君子去就之分哉？詩云：「士也罔極，二三其德。」士之二三，猶喪妃偶，況人臣乎？

**釋讀與歸年** 《魏略》以曹丕出游时发言、苏则要下马谢罪、傅巽以目示意为经过；正文记为洛阳闲谈与傅巽掐劝。二说不能据语境分立为两件有日期的事。

**釋讀與歸年** 孙盛以人臣去就应当一致为出发点，批评苏则已在魏受官，仍想以激切言语发泄不满，并引《诗经》说明操守不一之患。这是对上述对答的史评。

### 苏则请免杀从猎吏

[《三国志·任苏杜郑仓传》仓内原文 L833](../../拆分史书/三国志/卷016.md#l833)

猎场拦木脱落放走鹿，曹丕欲杀督吏，苏则冒死劝君莫为禽兽害人。诸吏得赦，皇帝亦因此忌憚。

**时段与依据** 本传不具哪次出猎。

<a id="wei016-l26-2"></a>

**[《三國志·任蘇杜鄭倉傳》正文](../../拆分史书/三国志/卷016.md#edition-wei016-l26-2)** · [TXT L26](../../拆分史书/三国志/卷016.txt#L26)

> 後則從行獵，槎桎拔，失鹿，帝大怒，踞胡牀拔刀，悉收督吏，將斬之。則稽首曰：「臣聞古之聖王不以禽獸害人，今陛下方隆唐堯之化，而以獵戲多殺羣吏，愚臣以爲不可。敢以死請！」帝曰：「卿，直臣也。」遂皆赦之。然以此見憚。

**釋讀與歸年** 随曹丕打猎时因槎桎脱开跑掉一鹿，曹丕欲杀主管人员。苏则以不能为禽兽害人死谏，曹丕称其正直，赦免众吏，却由此对他有所忌惮。出猎次数多，本文无日期；不径定此次为223年荥阳校猎。

<a id="wei016-l70-1"></a>

**[《三國志·任蘇杜鄭倉傳》](../../拆分史书/三国志/卷016.md#edition-wei016-l68-1)** · [TXT L68](../../拆分史书/三国志/卷016.txt#L68) · [TXT L70](../../拆分史书/三国志/卷016.txt#L70)

> 乃上疏曰：
>
> 帝王之道，莫尚乎安民；安民之術，在於豐財。豐財者，務本而節用也。方今二賊未滅。戎車亟駕，此自熊虎之士展力之秋也。然搢紳之儒，橫加榮慕，搤腕抗論，以孫、吳爲首，州郡牧守，咸共忽恤民之術，脩將率之事。農桑之民，競干戈之業，不可謂務本。帑藏歲虛而制度歲廣，民力歲衰而賦役歲興，不可謂節用。今大魏奄有十州之地，而承喪亂之弊，計其戶口不如往昔一州之民，然而二方僭逆，北虜未賔，三邊遘難，繞天略帀；所以統一州之民，經營九州之地，其爲艱難，譬策羸馬以取道里，豈可不加意愛惜其力哉？以武皇帝之節儉，府藏充實，猶不能十州擁兵；郡且二十也。今荊、揚、青、徐、幽、并、雍、涼緣邊諸州皆有兵矣，其所恃內充府庫外制四夷者，惟兖、豫、司、兾而已。臣前以州郡典兵，則專心軍功，不勤民事，宜別置將守，以盡治理之務；而陛下復以兾州寵秩呂昭。兾州戶口最多，田多墾闢，又有桑棗之饒，國家徵求之府，誠不當復任以兵事也。若以北方當須鎮守，自可專置大將以鎮安之。計所置吏士之費，與兼官無異。然昭於人才尚復易；中朝苟乏人，兼才者勢不獨多。以此推之，知國家以人擇官，不爲官擇人也。官得其人，則政平訟理；政平故民富實，訟理故囹圄空虛。陛下踐阼，天下斷獄百數十人，歲歲增多，至五百餘人矣。民不益多，法不益峻。以此推之，非政教陵遲，牧守不稱之明效歟？往年牛死，通率天下十能損二；麥不半收，秋種未下。若二賊游魂於疆埸，飛芻輓粟，千里不及。究此之術，豈在彊兵乎？武士勁卒愈多，愈多愈病耳。夫天下猶人之體，腹心充實，四支雖病，終無大患；今兖、豫、司、兾亦天下之腹心也。是以愚臣慺慺，實願四州之牧守，獨脩務本之業，以堪四支之重。然孤論難持，犯欲難成，衆怨難積，疑似難分，故累載不爲明主所察。凡言此者，類皆疏賤；疏賤之言，實未易聽。若使善策必出於親貴，親貴固不犯四難以求忠愛，此古今之所常患也。

**釋讀與歸年** 承吕昭兼刺史，杜恕上疏。

**釋讀與歸年** 杜恕以安民须务本节用立论，指出边州从军、农桑废弛、用费和徭役却增加。魏有十州而户口不足承平时一州，须以兖、豫、司、冀为财政粮食腹心，尤其不宜以兵事牵累冀州；另设将帅，并不比兼官多费。他又举案件由年百余增至五百、上年牛死两成、麦不半收等事实，指出非多添士卒可以解决，并力陈疏贱之臣直言难进。疏所说「往年」相对于疏年，疏年本无明确纪年，故不能据此直接定全国牛疫年份。

<a id="period-sgz016-b-869-2"></a>

### 曹操在淮南屯田，以仓慈为绥集都尉

[《三国志·任苏杜郑仓传》仓内原文 L869](../../拆分史书/三国志/卷016.md#l869)

淮南征募屯田，任仓慈主管招集。

**时段与依据** 仅“建安中”；不是已明建安元年的许下屯田。

<a id="wei016-l132-2"></a>

**[《三國志·任蘇杜鄭倉傳》正文](../../拆分史书/三国志/卷016.md#edition-wei016-l132-2)** · [TXT L132](../../拆分史书/三国志/卷016.txt#L132)

> 建安中，太祖開募屯田於淮南，以慈爲綏集都尉。

**釋讀與歸年** 建安间曹操在淮南招募屯田，任仓慈为绥集都尉。正文只给建安年号，淮南又屡有屯田安排，保留范围。

<a id="period-sgz016-b-869-3"></a>

### 黄初末仓慈任长安令，吏民畏爱

[《三国志·任苏杜郑仓传》仓内原文 L869](../../拆分史书/三国志/卷016.md#l869)

施政清约有方。

**时段与依据** “黃初末”约225—226，未记年。

<a id="wei016-l132-3"></a>

**[《三國志·任蘇杜鄭倉傳》正文](../../拆分史书/三国志/卷016.md#edition-wei016-l132-3)** · [TXT L132](../../拆分史书/三国志/卷016.txt#L132)

> 黃初末，爲長安令，清約有方，吏民畏而愛之。

**釋讀與歸年** 黄初末，仓慈任长安令，为政清约，吏民敬畏而爱戴他。黄初末横跨曹丕末年，本传无任命确年。

<a id="period-sgz016-b-869-4"></a>

### 太和中仓慈领敦煌及当地形势

[《三国志·任苏杜郑仓传》仓内原文 L869](../../拆分史书/三国志/卷016.md#l869)

乱中敦煌曾与朝廷隔绝、二十年无太守，地方大姓把持，近年先来太守尹奉等仍循旧。

**时段与依据** “太和中”227—233年，前史二十年只相对称久。

<a id="wei016-l132-4"></a>

**[《三國志·任蘇杜鄭倉傳》正文](../../拆分史书/三国志/卷016.md#edition-wei016-l132-4)** · [TXT L132](../../拆分史书/三国志/卷016.txt#L132)

> 太和中，遷燉煌太守。郡在西陲，以喪亂隔絕，曠無太守二十歲，大姓雄張，遂以爲俗。前太守尹奉等，循故而已，無所匡革。

**釋讀與歸年** 太和间，仓慈迁敦煌太守。战乱中敦煌曾约二十年无太守，豪族坐大，尹奉等前任未能纠正旧弊。两件事分别说明敦煌旧状与仓慈任命，只能确认太和年间。

<a id="period-sgz016-b-869-5"></a>

### 仓慈敦煌抑豪强、均分田地

[《三国志·任苏杜郑仓传》仓内原文 L869](../../拆分史书/三国志/卷016.md#l869)

根据人口割地给穷小户，渐清偿地价。

**时段与依据** 任内处置，未书时日。

<a id="wei016-l132-5"></a>

**[《三國志·任蘇杜鄭倉傳》正文](../../拆分史书/三国志/卷016.md#edition-wei016-l132-5)** · [TXT L132](../../拆分史书/三国志/卷016.txt#L132)

> 慈到，抑挫權右，撫恤貧羸，甚得其理。舊大族田地有餘，而小民無立錐之土；慈皆隨口割賦，稍稍使畢其本直。

**釋讀與歸年** 仓慈抑制敦煌豪强，怜恤贫弱，按人口从大族有余田地中划给无田小民，再渐次补足原价。

## 引文与纪年

<a id="period-sgz017-b-873-1"></a>

### 张辽籍贯、聂氏改姓与早年仕历

[《三国志·二张乐于徐传》仓内原文 L873](../../sources/本地分卷/三国志/三国志-卷017.md#l873)

> 張遼字文遠，雁門馬邑人也。本聶壹之後，以避怨變姓。少為郡吏。

张辽字文远，籍贯雁门马邑，出自聂壹之后，家族为避怨改姓，他少年时做过郡吏。

**时段与依据** 身世和早年任职无年，聂壹乃汉武帝时人，不能把改姓直接归入马邑之谋的年份。

<a id="period-sgz017-b-873-5"></a>

### 张辽随吕布东赴徐州，领鲁相

[《三国志·二张乐于徐传》仓内原文 L873](../../sources/本地分卷/三国志/三国志-卷017.md#l873)

> 布為李傕所敗，從布東奔徐州，領魯相，時年二十八。

吕布败后先出关辗转，张辽后来同赴徐州，年二十八并领鲁相。

**时段与依据** 《吕布传》到徐州在195年，张辽任鲁相本传没有单年，约在195至198年。

<a id="period-sgz017-b-873-7"></a>

### 张辽积功迁裨将军

[《三国志·二张乐于徐传》仓内原文 L873](../../sources/本地分卷/三国志/三国志-卷017.md#l873)

> 數有戰功，遷裨將軍。

张辽屡有军功，迁裨将军。

**时段与依据** 约系下邳归曹之后及平鲁国之前，确年不见。

<a id="period-sgz017-b-873-8"></a>

### 张辽平定鲁国各县

[《三国志·二张乐于徐传》仓内原文 L873](../../sources/本地分卷/三国志/三国志-卷017.md#l873)

> 袁紹破，別遣遼定魯國諸縣。

袁绍败后，曹操另令张辽平定鲁国各县。

**时段与依据** 在200年官渡战后、202至203年黎阳战前，平鲁确年未明。

<a id="period-sgz017-b-873-12"></a>

### 张辽在黎阳击二袁，代理中坚将军

[《三国志·二张乐于徐传》仓内原文 L873](../../sources/本地分卷/三国志/三国志-卷017.md#l873)

> 從討袁譚、袁尚於黎陽，有功，行中堅將軍。

张辽随攻袁谭、袁尚于黎阳，有功而行中坚将军。

**时段与依据** 《武帝纪》自202年秋渡河至203年春继续交战，个人受任月份不详。

<a id="period-sgz017-b-873-16"></a>

### 张辽击江夏、屯临颍、封都亭侯

[《三国志·二张乐于徐传》仓内原文 L873](../../sources/本地分卷/三国志/三国志-卷017.md#l873)

> 復別擊荊州，定江夏諸縣，還屯臨潁，封都亭侯。

张辽另进攻荆州，平定江夏属县，回屯临颍，获封都亭侯。

**时段与依据** 袁谭败后、远征柳城前，荆州这一支军的具体年份无直接记载。

<a id="period-sgz017-b-876-2"></a>

### 曹操在摩陂慰劳张辽，张辽回屯陈郡

[《三国志·二张乐于徐传》仓内原文 L876](../../sources/本地分卷/三国志/三国志-卷017.md#l876)

> 遼與太祖會摩陂。遼軍至，太祖乘輦出勞之，還屯陳郡。

张辽到摩陂，曹操乘辇出劳，张辽再驻陈郡。

**时段与依据** 《武帝纪》曹操219年冬次摩陂，220年正月回洛阳；张辽会见日无法精确到年界一侧。

<a id="period-sgz017-b-876-8"></a>

### 张辽在雍丘病，曹丕探视

[《三国志·二张乐于徐传》仓内原文 L876](../../sources/本地分卷/三国志/三国志-卷017.md#l876)

> 遼還屯雍丘，得疾。帝遣侍中劉曄將太醫視疾，虎賁問消息，道路相屬。疾未瘳，帝迎遼就行在所，車駕親臨，執其手，賜以御衣，太官日送御食。疾小差，還屯。

张辽返雍丘患疾，曹丕派刘晔率太医诊视，后接至行在，亲自探疾，赐衣食，稍好后返屯。

**时段与依据** 在黄初二年朝洛阳和黄初三年出兵洞口之间，病情与探视未分纪年。

<a id="period-sgz017-b-876-13"></a>

张虎官偏将军，去世后儿子张统承袭。

**时段与依据** 两代任卒和袭爵均无确年。

### 乐进籍贯、早年从军募兵

[《三国志·二张乐于徐传》仓内原文 L878](../../sources/本地分卷/三国志/三国志-卷017.md#l878)

> 樂進字文謙，陽平衛國人也。容貌短小，以膽烈從太祖，為帳下吏。遣還本郡募兵，得千餘人，還為軍假司馬、陷陳都尉。

乐进字文谦，阳平卫国人，以胆勇成为曹操帐下吏，回乡募千余人，历军假司马、陷陈都尉。

本传合叙三役均先登有功，获封广昌亭侯。

**时段与依据** 最迟一役197年，进封独立年月无载。

<a id="period-sgz017-b-878-12"></a>

### 乐进在黎阳斩严敬，行游击将军

[《三国志·二张乐于徐传》仓内原文 L878](../../sources/本地分卷/三国志/三国志-卷017.md#l878)

乐进随曹军在黎阳攻袁谭、袁尚，斩袁军将领严敬，行游击将军。

**时段与依据** 黎阳战事见202年秋至203年春，严敬卒及乐进代理此职未记月日。

乐进受遣击黄巾军，定乐安郡。

**时段与依据** 本传置于黎阳之后、邺城之围之前，确年未载。

<a id="period-sgz017-b-879-3"></a>

### 乐进先屯阳翟

曹操在荆州尚未归附时令乐进屯阳翟。

**时段与依据** 在征管承后、208年入荆前，本传无曰月。

<a id="period-sgz017-b-879-5"></a>

### 乐进讨刘备的临沮长和旌阳长

乐进击破临沮长杜普、旌阳长梁大。

**时段与依据** 在随曹操进荆州之后，地方战具体年份不详。

<a id="period-sgz017-b-879-7"></a>

### 乐进进右将军，分户封一子

曹操因乐进多有军功，分五百户封其一子为列侯；乐进迁右将军。

**时段与依据** 在屯合肥之后、建安二十三年卒之前，缺确年。

### 于禁攻徐州广威，任陷阵都尉

[《三国志·二张乐于徐传》仓内原文 L881](../../sources/本地分卷/三国志/三国志-卷017.md#l881)

**时段与依据** 叙次在曹操领兖州之后，濮阳战之前；曹操193、194年两征徐州，攻广威的确年未明。

<a id="period-sgz017-b-882-10"></a>

### 于禁与其他四将常作先锋、后殿

[《三国志·二张乐于徐传》仓内原文 L882](../../sources/本地分卷/三国志/三国志-卷017.md#l882)

> 是時，禁與張遼、樂進、張郃、徐晃俱為名將，太祖每征伐，咸遞行為軍鋒，還為後拒；而禁持軍嚴整，得賊財物，無所私入，由是賞賜特重。然以法御下，不甚得士眾心。

五将轮流作先锋与撤退后的阻敌部队。于禁治军整肃，不私分战利品，多受赏赐，也因严法失士卒之心。

**时段与依据** 长期履历与概评，无单年。

<a id="period-sgz017-b-882-11"></a>

### 曹操命于禁收朱灵所部

[《三国志·二张乐于徐传》仓内原文 L882](../../sources/本地分卷/三国志/三国志-卷017.md#l882)

> 太祖常恨硃靈，欲奪其營。以禁有威重，遣禁將數十騎，齎令書，徑詣靈營奪其軍，靈及其部眾莫敢動；乃以靈為禁部下督，眾皆震服，其見憚如此。

曹操不满朱灵，派于禁率少数骑兵持令收其军，营中不敢反抗，朱灵降为于禁部下督将。

**时段与依据** 本传未载年，任命在襄樊被俘前；纳入时期。

<a id="period-sgz017-b-882-12"></a>

### 于禁升左将军、假节钺

于禁迁左将军、假节钺，分五百户封其一子为列侯。

**时段与依据** 本传无年，仅知在樊城出援前，不能据通称反推受任日。

<a id="period-sgz017-b-888-2"></a>

### 张郃推卑湛为博士

[《三国志·二张乐于徐传》仓内原文 L888](../../sources/本地分卷/三国志/三国志-卷017.md#l888)

> 郃雖武將而愛樂儒士，嘗薦同鄉卑湛經明行修，詔曰：「昔祭遵為將，奏置五經大夫，居軍中，與諸生雅歌投壺。今將軍外勒戎旅，內存國朝。朕嘉將軍之意，今擢湛為博士。」

张郃虽为武将而礼重儒者，推荐同乡卑湛；皇帝以祭遵为比，任卑湛为博士。

**时段与依据** 此段叙事在太和初年，未给荐举年份，祭遵是诏中引例。

<a id="period-sgz017-b-892-6"></a>

### 徐晃、曹洪破㶏强祝臂

[《三国志·二张乐于徐传》仓内原文 L892](../../sources/本地分卷/三国志/三国志-卷017.md#l892)

> 與曹洪擊氵隱強賊祝臂，破之，

[《三国志·二张乐于徐传》裴注 002·1](../../sources/摘录/三国志-卷017-二张乐于徐传裴注.md#pei-002-1)

> 孫盛曰夫兵固詭道竒正相資若乃命將出征推轂委權或頼率然之形或慿犄角之勢羣帥不和則棄師之道也至於合肥之守縣弱無援專任勇者則好戰生患專任怯者則懼心難保且彼衆我寡必懐貪墮以致命之兵擊貪墮之卒其勢必勝勝而後守守則必固是以魏武推選方員參以同異為之密敎節宣其用事至而應若合符契妙矣夫

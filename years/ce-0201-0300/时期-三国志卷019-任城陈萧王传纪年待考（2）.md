### 杨修教曹植违门禁以应试

[《三国志·任城陈萧王传》裴注 009·30](../../拆分史书/三国志/卷019.md#pei-009-30)

曹操让两人从邺不同城门出、又秘密命不得放行；曹丕折返，曹植按杨修所教强行越禁。

**时段与依据** 《世语》是择储试才异说，原文不明年月；与正传私开司马门的文本证据分别。

<a id="wei019-l30-14"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l30-14)** · [TXT L30](../../拆分史书/三国志/卷019.txt#L30)

> 太祖遣太子及植各出鄴城一門，密勑門不得出，以觀其所爲。太子至門，不得出而還。脩先戒植：「若門不出侯，侯受王命，可斬守者。」植從之。

**釋讀與歸年** 《世語》另記曹操遣曹丕與曹植分出鄴城諸門，又私令不得放行。曹丕折返，曹植依楊脩所教以奉王命為由斬守者。下文以此解釋楊脩被殺，本傳從馳道私開司馬門另敘，不併作兩個確日事件。

<a id="period-sgz019-p-009-32"></a>

### 杨修后世有杨嚣、杨准

[《三国志·任城陈萧王传》裴注 009·32](../../拆分史书/三国志/卷019.md#pei-009-32)

杨嚣与杨准在晋有名；杨嚣泰始初任典军将军，受委心腹而早卒。

**时段与依据** 泰始初及“早卒”都不是明确年标签。

<a id="wei019-l30-16"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l30-16)** · [TXT L30](../../拆分史书/三国志/卷019.txt#L30)

> 脩子嚻，嚻子準，皆知名於晉世。嚻，泰始初爲典軍將軍，受心膂之任，早卒。

**釋讀與歸年** 楊脩子楊嚻與孫楊準皆在晉有名。太始初楊嚻任典軍將軍，受寵而早卒。[《晉書》](../../史书/005-晋书/晋书-CCDH.txt#L5540)見咸寧四年詔中已稱「故」典軍將軍楊囂，可知卒在278年及以前。太始初非單一任命年。

<a id="period-sgz019-p-009-33"></a>

### 杨准在惠帝末任冀州刺史

[《三国志·任城陈萧王传》裴注 009·33](../../拆分史书/三国志/卷019.md#pei-009-33)

杨准字始丘，于晋惠帝末任州长官。

**时段与依据** 《世语》仅记“惠帝末”。

<a id="wei019-l30-17"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l30-17)** · [TXT L30](../../拆分史书/三国志/卷019.txt#L30)

> 準字始丘，惠帝末爲兾州刺史。

**釋讀與歸年** 楊準字始丘，晉惠帝末任冀州刺史。只存帝世及任官範圍。

<a id="period-sgz019-p-009-34"></a>

### 荀绰记杨准纵酒、受成都王礼遇

[《三国志·任城陈萧王传》裴注 009·34](../../拆分史书/三国志/卷019.md#pei-009-34)

杨准见朝纲衰落，渐纵酒不理官事；成都王司马颖惜其名，召为军谋祭酒，府罢后归家。

**时段与依据** 晋惠帝末政争阶段；“府散”前后无独立时标。

<a id="wei019-l30-18"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l30-18)** · [TXT L30](../../拆分史书/三国志/卷019.txt#L30)

> 荀綽兾州記曰：準見王綱不振，遂縱酒，不以官事爲意，逍遙卒歲而已。成都王知準不治，猶以其爲名士，惜而不責，召以爲軍謀祭酒。

**釋讀與歸年** 荀綽《兾州記》記楊準見王綱不振，縱酒而少理事。成都王司馬穎愛惜其名士身份，徵為軍謀祭酒。召任繫惠帝末司馬穎用事期間，未能確年。

<a id="period-sgz019-p-009-35"></a>

### 诸侯拟补杨准三公，未行而卒

[《三国志·任城陈萧王传》裴注 009·35](../../拆分史书/三国志/卷019.md#pei-009-35)

关东诸侯议以起用贤人名义补杨准三公，尚未实行杨准便卒。

**时段与依据** 《翼州记》未定具体年。

<a id="wei019-l30-19"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l30-19)** · [TXT L30](../../拆分史书/三国志/卷019.txt#L30)

> 府散停家，關東諸侯議欲以準補三事，以示懷賢尚德之舉。事未施行而卒。

**釋讀與歸年** 成都王幕府散後，楊準居家，關東諸侯議推他補三公，未行而卒。只知在前任軍謀祭酒之後。

<a id="period-sgz019-p-009-36"></a>

### 杨峤、杨髦与裴頠、乐广的品鉴

[《三国志·任城陈萧王传》裴注 009·36](../../拆分史书/三国志/卷019.md#pei-009-36)

杨准使二子谒裴頠、乐广，裴重杨峤，乐重杨髦，杨准说二家品评相反近于二人高下，舆评更合乐广之言。

**时段与依据** 《翼州记》记人物交游品评，乐裴亡年只限上界。

<a id="wei019-l30-20"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l30-20)** · [TXT L30](../../拆分史书/三国志/卷019.txt#L30)

> 準子嶠字國彥，髦字士彥，並爲後出之俊。準與裴頠、樂廣善，遣往見之。頠性弘方，愛嶠之有高韻，謂準曰：「嶠當及卿，然髦小減也。」廣性清淳，愛髦之有神檢，謂準曰：「嶠自及卿，然髦尤精出。」準歎曰：「我二兒之優劣，乃裴、樂之優劣也。」評者以爲嶠雖有高韻，而神檢不逮，廣言爲得。

**釋讀與歸年** 楊準兩子楊嶠字國彥、楊髦字士彥。裴頠喜嶠高韻，樂廣尤賞髦之精出，楊準以兩子優劣寄寓對裴、樂的品評。兩人評語不具年月。

<a id="period-sgz019-p-009-37"></a>

### 傅畅补评杨嶠、杨俊及其官历

[《三国志·任城陈萧王传》裴注 009·37](../../拆分史书/三国志/卷019.md#pei-009-37)

傅畅说杨嶠似父而疏略，弟杨俊清拔；嶠、髦均至二千石，俊任太傅掾。

**时段与依据** 无独立任官年，可见晋时后裔仕历。

<a id="wei019-l30-21"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l30-21)** · [TXT L30](../../拆分史书/三国志/卷019.txt#L30)

> 傅暢云：「嶠似準而踈。」嶠弟俊，字惠彥，最清出。嶠、髦皆爲二千石。俊，太傅掾。

**釋讀與歸年** 傅暢說楊嶠似父而疏略，弟楊俊字惠彥最清出。嶠、髦皆為二千石，俊為太傅掾。這是晉代楊氏任官和品評的補敘。

### 丁仪家世与丁冲交曹操

[《三国志·任城陈萧王传》裴注 011·1](../../拆分史书/三国志/卷019.md#pei-011-1)

丁仪字正礼，沛郡人；父丁冲早与曹操亲近。

**时段与依据** 魏略人物背景。

<a id="wei019-l35-1"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l35-1)** · [TXT L35](../../拆分史书/三国志/卷019.txt#L35)

> 魏略曰：丁儀字正禮，沛郡人也。父沖，宿與太祖親善，時隨乘輿。

**釋讀與歸年** 丁儀字正禮，沛郡人。父丁沖素與曹操親善，曾隨漢獻帝車駕。

### 丁冲嗜酒伤身而死

[《三国志·任城陈萧王传》裴注 011·4](../../拆分史书/三国志/卷019.md#pei-011-4)

丁冲常到访诸将，嗜酒难止，终因饮酒伤肠去世。

**时段与依据** 随后之事，无年。

<a id="wei019-l35-3"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l35-3)** · [TXT L35](../../拆分史书/三国志/卷019.txt#L35)

> 後數來過諸將飲，酒美不能止，醉爛腸死。太祖以沖前見開導，常德之。

**釋讀與歸年** 丁沖常訪諸將飲宴，終因飲酒過量傷身而死。曹操感謝他先前引導奉迎天子。卒年未書。

### 曹操曾拟嫁女丁仪，听曹丕言另择夏侯楙

[《三国志·任城陈萧王传》裴注 011·5](../../拆分史书/三国志/卷019.md#pei-011-5)

曹操感念丁冲、闻丁仪名，本想嫁爱女给他；曹丕以丁仪眼疾可能不为女子所悦提出夏侯楙，曹操照办。

**时段与依据** 曹丕时称五官中郎将（211–217），婚议无确年。

<a id="wei019-l35-4"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l35-4)** · [TXT L35](../../拆分史书/三国志/卷019.txt#L35)

> 聞儀爲令士，雖未見，欲以愛女妻之，以問五官將。五官將曰：「女人觀貌，而正禮目不便，誠恐愛女未必恱也。以爲不如與伏波子楙。」太祖從之。

**釋讀與歸年** 曹操聽說丁儀才行佳，曾想將愛女嫁給他；曹丕以丁儀一眼有疾，勸父另嫁夏侯楙，曹操採納。以曹丕為五官將，事在211年至217年間。

<a id="period-sgz019-p-011-6"></a>

### 曹操辟丁仪为掾并悔改婚议

[《三国志·任城陈萧王传》裴注 011·6](../../拆分史书/三国志/卷019.md#pei-011-6)

与丁仪论事后赞其才，认为即使双眼失明也可嫁女，责曹丕误己。

**时段与依据** 魏略承婚议，此任在储争前，无年月。

<a id="wei019-l35-5"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l35-5)** · [TXT L35](../../拆分史书/三国志/卷019.txt#L35)

> 尋辟儀爲掾，到與論議，嘉其才朗，曰：「丁掾，好士也，即使其兩目盲，尚當與女，何況但眇？是吾兒誤我。」

**釋讀與歸年** 曹操徵丁儀為掾，面談後喜其才，懊悔聽曹丕之言改婚。曹操徵用的年月未詳。

### 丁仪怨失婚而专赞曹植

[《三国志·任城陈萧王传》裴注 011·7](../../拆分史书/三国志/卷019.md#pei-011-7)

### 曹丕调丁仪右刺奸掾，逼其自尽

[《三国志·任城陈萧王传》裴注 011·9](../../拆分史书/三国志/卷019.md#pei-011-9)

魏略说曹丕调丁仪任右刺奸掾，以期其自杀；丁仪叩中领军夏侯尚求情，对方泣而无力救。

**时段与依据** 在217年曹丕立太子后、220年杀丁仪前，实际调掾与请托确年缺。

<a id="wei019-l35-7"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l35-7)** · [TXT L35](../../拆分史书/三国志/卷019.txt#L35)

> 及太子立，欲治儀罪，轉儀爲右刺姦掾，欲儀自裁而儀不能。乃對中領軍夏侯尚叩頭求哀，尚爲涕泣而不能救。

**釋讀與歸年** 曹丕立太子後想治丁儀，轉他為右刺姦掾，意欲迫其自盡。丁儀向中領軍夏侯尚求免，夏侯尚落淚而不能救。此為220年入獄被殺的前事，調任與求情未記確年。

### 丁廙是丁仪弟，建安中任黄门侍郎

[《三国志·任城陈萧王传》裴注 011·11](../../拆分史书/三国志/卷019.md#pei-011-11)

《文士传》称丁廙少有才姿、博学洽闻，受公府征辟，建安中任黄门侍郎。

**时段与依据** 建安中无独年。

<a id="wei019-l35-9"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l35-9)** · [TXT L35](../../拆分史书/三国志/卷019.txt#L35)

> 廙字敬禮，儀之弟也。文士傳曰：廙少有才姿，博學洽聞。初辟公府，建安中爲黃門侍郎。

**釋讀與歸年** 丁廙字敬禮，丁儀之弟。《文士傳》說他少年有才，博學洽聞，先受辟公府，建安中任黃門侍郎。就官年月未見。

<a id="period-sgz019-p-011-12"></a>

### 丁廙向曹操举荐曹植

[《三国志·任城陈萧王传》裴注 011·12](../../拆分史书/三国志/卷019.md#pei-011-12)

丁廙称曹植孝仁聪俊、才学卓绝，能结交天下贤士有益曹魏，希望劝动曹操。

**时段与依据** 建安间曹植为临菑侯、储位未定阶段。

<a id="wei019-l35-10"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l35-10)** · [TXT L35](../../拆分史书/三国志/卷019.txt#L35)

> 廙嘗從容謂太祖曰：「臨菑侯天性仁孝，發於自然，而聦明智達，其殆庶幾。至於博學淵識，文章絕倫。當今天下之賢才君子，不問少長，皆願從其游而爲之死，實天下所以鍾福於大魏，而永授無窮之祚也。」欲以勸動太祖。太祖荅曰：「植，吾愛之，安能若卿言！吾欲立之爲嗣，何如？」廙曰：「此國家之所以興衰，天下之所以存亡，非愚劣瑣賤者所敢與及。廙聞知臣莫若於君，知子莫若於父。至於君不論明闇，父不問賢愚，而能常知其臣子者何？蓋由相知非一事一物，相盡非一旦一夕。況明公加之以聖哲，習之以人子。今發明達之命，吐永安之言，可謂上應天命，下合人心，得之於須臾，垂之於萬世者也。廙不避斧鉞之誅，敢不盡言！」太祖深納之。

**釋讀與歸年** 丁廙向曹操盛稱曹植仁孝、文才和君子歸心，勸曹操立儲。曹操問能否立曹植，丁廙以父君之知勝於他人，明言同意。具體問答年月未記，在立太子前。

### 雍门狄为越甲至齐请死

### 再征藩国士息，曹植上书要求留还

[《三国志·任城陈萧王传》裴注 018·1](../../拆分史书/三国志/卷019.md#pei-018-1)

《魏略》记朝廷大量征发诸国士息和士卒，曹植称前番已调，其遗孤稚弱几无余者，如今又征，故上书。

**时段与依据** 裴注承太和五年（231）两疏优文答报后，终于曹植太和六年（232）死前；裴注只说“是後”，独立年月未载。

<a id="wei019-l93-1"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l93-1)** · [TXT L93](../../拆分史书/三国志/卷019.txt#L93)

> 魏略曰：是後大發士息，及取諸國士。植以近前諸國士息已見發，其遺孤稚弱，在者無幾，而復被取，乃上書曰：「臣聞古者聖君，與日月齊其明，四時等其信，是以戮凶無重，賞善無輕，怒若驚霆，喜若時雨，恩不中絕，教無二可，以此臨朝，則臣下知所死矣。受任在萬里之外，審主之所以受官，必以之所投命，雖有構會之徒，泊然不以爲懼者，蓋君臣相信之明效也。昔章子爲齊將，人有告之反者，威王曰：『不然。』左右曰：『王何以明之？』王曰：『聞章子改葬死母；彼尚不欺死父，顧當叛生君乎？』此君之信臣也。昔管仲親射桓公，後幽囚從魯檻車載，使少年挽而送齊。管仲知桓公之必用己，懼魯之悔，謂少年曰：『吾爲汝唱，汝爲和，聲和聲，宜走。』於是管仲唱之，少年走而和之，日行數百里，宿昔而至。至則相齊，此臣之信君也。臣初受封，策書曰：『植受茲青社，封于東土，以屏翰皇家，爲魏藩輔。』而所得兵百五十人，皆年在耳順，或不踰矩，虎賁官騎及親事凡二百餘人。正復不老，皆使年壯，備有不虞，檢校乘城，顧不足以自救，況皆復耄耋罷曳乎？而名爲魏東藩，使屏翰王室，臣竊自羞矣。就之諸國，國有士子，合不過五百人。伏以爲三軍益損，不復賴此。方外不定，必當須辨者，臣願將部曲倍道奔赴，夫妻負襁，子弟懷糧，蹈鋒履刃，以徇國難，何但習業小兒哉？愚誠以揮涕增河，鼷鼠飲海，於朝萬無損益，於臣家計甚有廢損。又臣士息前後三送，兼人已竭。惟尚有小兒，七八歲已上，十六七已還，三十餘人。今部曲皆年耆，卧在牀席，非糜不食，眼不能視，氣息裁屬者，凡三十七人；疲瘵風靡，疣盲聾聵者，二十三人。惟正須此小兒，大者可備宿衞，雖不足以禦寇，粗可以警小盜；小者未堪大使，爲可使耘鉏穢草，驅護鳥雀。休候人則一事廢，一日獵則衆業散，不親自經營則功不攝；常自躬親，不委下吏而已。陛下聖仁，恩詔三至，士子給國，長不復發。明詔之下，有若皦日，保金石之恩，必明神之信，畫然自固，如天如地。定習業者並復見送，晻若晝晦，悵然失圖。伏以爲陛下旣爵臣百寮之右，居藩國之任，爲置卿士，屋名爲宮，冢名爲陵，不使其危居獨立，無異於凡庶。若柏成欣於野耕，子仲樂於灌園；蓬戶茅牖，原憲之宅也；陋巷單瓢，顏子之居也：臣才不見效用，常慨然執斯志焉。若陛下聽臣悉還部曲，罷官屬，省監官，使解璽釋紱，追柏成、子仲之業，營顏淵、原憲之事，居子臧之廬，宅延陵之室。如此，雖進無成功，退有可守，身死之日，猶松、喬也。然伏度國朝終未肯聽臣之若是，固當羈絆於世繩，維繫於祿位，懷屑屑之小憂，執無已之百念，安得蕩然肆志，逍遙於宇宙之外哉？此願未從，陛下必欲崇親親，篤骨肉，潤白骨而榮枯木者，惟遂仁德以副前恩詔。」皆遂還之。

**釋讀與歸年** 《魏略》記在這兩疏後，朝廷又大量徵發藩國兵卒及兵卒子弟。曹植具陳老病殘卒、可用幼弱者和前次已遣之數，援齊威王信章子、管仲信桓公說君臣互信，責先前承諾留士息如今又徵，或求解印省官、即使仍為藩王也請照前詔留人。朝廷終把被徵者還給各國。注文以「是後」相接，時在太和末，確月年未記，全文與結果並讀。所用管仲受囚歸齊的舊事另見[前685年](../bce-0700-0601/bce-0685.md#reading-note-1)。

### 孙盛评曹魏藩国封建过弱

### 司马炎令曹志任乐平太守，后历章武赵郡

[《三国志·任城陈萧王传》裴注 020·4](../../拆分史书/三国志/卷019.md#pei-020-4)

西晋先诏用曹志任乐平太守，后来迁章武、赵郡。

**时段与依据** 《晋书·曹志传》诏自称此前少有空缺，任命不必同受禅年；郡任亦无独年。

<a id="wei019-l98-4"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l98-4)** · [TXT L98](../../拆分史书/三国志/卷019.txt#L98)

> 發詔以志爲樂平太守，歷章武、趙郡，

**釋讀與歸年** 晉武帝用曹志為樂平太守，後歷章武、趙郡。[《晉書·曹志傳》](../../史书/005-晋书/晋书-CCDH.txt#L5911)另載任命詔和曹志請為博士置吏卒。各郡授官未明確年。

<a id="period-sgz019-p-020-5"></a>

### 曹志迁散骑常侍、国子博士

[《三国志·任城陈萧王传》裴注 020·5](../../拆分史书/三国志/卷019.md#pei-020-5)

朝廷擢曹志为散骑常侍兼国子博士。

**时段与依据** 《晋书·曹志传》系咸宁初；《职官志》记咸宁四年初立国子学，相关表述难据以硬定个人除授年。

<a id="wei019-l98-5"></a>

**[《三國志·任城陳蕭王傳》裴注](../../拆分史书/三国志/卷019.md#edition-wei019-l98-5)** · [TXT L98](../../拆分史书/三国志/卷019.txt#L98)

> 遷散騎常侍、國子博士，後轉博士祭酒。

**釋讀與歸年** 曹志入朝為散騎常侍、國子博士，後任博士祭酒。[《晉書·曹志傳》](../../史书/005-晋书/晋书-CCDH.txt#L5912-L5913)把前一任命繫咸寧初；[《晉書·職官志》](../../史书/005-晋书/晋书-CCDH.txt#L3589)又記咸寧四年初立國子學並置祭酒、博士，故保留時段，祭酒之任至283年議齊王出藩時可確知。

### 曹志复任散骑常侍

[《三国志·任城陈萧王传》裴注 020·8](../../拆分史书/三国志/卷019.md#pei-020-8)

**时段与依据** 《晋书·曹志传》亦只说“頃之”，283年被免后、288年卒前。

### 鱼豢评曹彰、曹植遭遇与魏廷储争

[《三国志·任城陈萧王传》裴注 021·2](../../拆分史书/三国志/卷019.md#pei-021-2)

鱼豢称曹彰含恨，亲附曹植的杨修、丁仪因此受害；又赞曹植文采思若神明，理解曹操为其动心。

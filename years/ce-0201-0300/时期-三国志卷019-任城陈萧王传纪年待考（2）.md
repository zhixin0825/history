### 杨修教曹植违门禁以应试

[《三国志·任城陈萧王传》裴注 009·30](../../拆分史书/三国志/卷019.md#pei-009-30)

> 太祖遣太子及植各出鄴城一門宻勑門不得出以觀其所為太子至門不得出而還修先戒植若門不出侯侯受王命可斬守者植從之

曹操让两人从邺不同城门出、又秘密命不得放行；曹丕折返，曹植按杨修所教强行越禁。

**时段与依据** 《世语》是择储试才异说，原文不明年月；与正传私开司马门的文本证据分别。

<a id="period-sgz019-p-009-32"></a>

### 杨修后世有杨嚣、杨准

[《三国志·任城陈萧王传》裴注 009·32](../../拆分史书/三国志/卷019.md#pei-009-32)

> 修子囂囂子準皆知名於晉世囂泰始初為典軍將軍受心膂之任早卒

杨嚣与杨准在晋有名；杨嚣泰始初任典军将军，受委心腹而早卒。

**时段与依据** 泰始初及“早卒”都不是明确年标签。

<a id="period-sgz019-p-009-33"></a>

### 杨准在惠帝末任冀州刺史

[《三国志·任城陈萧王传》裴注 009·33](../../拆分史书/三国志/卷019.md#pei-009-33)

> 準字始丘惠帝末為冀州刺史

杨准字始丘，于晋惠帝末任州长官。

**时段与依据** 《世语》仅记“惠帝末”。

<a id="period-sgz019-p-009-34"></a>

### 荀绰记杨准纵酒、受成都王礼遇

[《三国志·任城陈萧王传》裴注 009·34](../../拆分史书/三国志/卷019.md#pei-009-34)

> 荀綽翼州記曰準見王綱不振遂縱酒不以官事為意逍遥卒嵗而已成都王知準不治猶以其為名士惜而不責召以為軍謀祭酒府散停家

杨准见朝纲衰落，渐纵酒不理官事；成都王司马颖惜其名，召为军谋祭酒，府罢后归家。

**时段与依据** 晋惠帝末政争阶段；“府散”前后无独立时标。

<a id="period-sgz019-p-009-35"></a>

### 诸侯拟补杨准三公，未行而卒

[《三国志·任城陈萧王传》裴注 009·35](../../拆分史书/三国志/卷019.md#pei-009-35)

> 關東諸侯議欲以準補三事以示懐賢尚徳之舉事未施行而卒

关东诸侯议以起用贤人名义补杨准三公，尚未实行杨准便卒。

**时段与依据** 《翼州记》未定具体年。

<a id="period-sgz019-p-009-36"></a>

### 杨峤、杨髦与裴頠、乐广的品鉴

[《三国志·任城陈萧王传》裴注 009·36](../../拆分史书/三国志/卷019.md#pei-009-36)

> 準子嶠字國彦髦字士彦並為後出之俊準與裘頠樂廣善遣往見之頠性弘方愛嶠之有髙韻謂準曰嶠當及卿然髦少減也廣性清淳愛髦之有神檢謂準曰嶠自及卿然髦尤精出準歎曰我二兒之優劣乃裴樂之優劣也評者以為嶠雖有髙韻而神檢不逮廣言為得

杨准使二子谒裴頠、乐广，裴重杨峤，乐重杨髦，杨准说二家品评相反近于二人高下，舆评更合乐广之言。

**时段与依据** 《翼州记》记人物交游品评，乐裴亡年只限上界。

<a id="period-sgz019-p-009-37"></a>

### 傅畅补评杨嶠、杨俊及其官历

[《三国志·任城陈萧王传》裴注 009·37](../../拆分史书/三国志/卷019.md#pei-009-37)

> 傅暢云嶠似準而疎嶠弟俊宇惠彦最清出嶠髦皆為二千石俊太傅椽

傅畅说杨嶠似父而疏略，弟杨俊清拔；嶠、髦均至二千石，俊任太傅掾。

**时段与依据** 无独立任官年，可见晋时后裔仕历。

<a id="period-sgz019-p-011-1"></a>

### 丁仪家世与丁冲交曹操

[《三国志·任城陈萧王传》裴注 011·1](../../拆分史书/三国志/卷019.md#pei-011-1)

> 魏畧曰丁儀字正禮沛郡人也父沖宿與太祖親善

丁仪字正礼，沛郡人；父丁冲早与曹操亲近。

**时段与依据** 魏略人物背景。

<a id="period-sgz019-p-011-4"></a>

### 丁冲嗜酒伤身而死

[《三国志·任城陈萧王传》裴注 011·4](../../拆分史书/三国志/卷019.md#pei-011-4)

> 後數來過諸將飲酒美不能止醉爛腸死

丁冲常到访诸将，嗜酒难止，终因饮酒伤肠去世。

**时段与依据** 随后之事，无年。

<a id="period-sgz019-p-011-5"></a>

### 曹操曾拟嫁女丁仪，听曹丕言另择夏侯楙

[《三国志·任城陈萧王传》裴注 011·5](../../拆分史书/三国志/卷019.md#pei-011-5)

> 太祖以沖前見開導常徳之聞儀為令士雖未見欲以愛女妻之以問五官將五官將曰女人觀貎而正禮目不便誠恐愛女未必悦也以為不如與伏波子楙太祖從之

曹操感念丁冲、闻丁仪名，本想嫁爱女给他；曹丕以丁仪眼疾可能不为女子所悦提出夏侯楙，曹操照办。

**时段与依据** 曹丕时称五官中郎将（211–217），婚议无确年。

<a id="period-sgz019-p-011-6"></a>

### 曹操辟丁仪为掾并悔改婚议

[《三国志·任城陈萧王传》裴注 011·6](../../拆分史书/三国志/卷019.md#pei-011-6)

> 尋辟儀為掾到與論議嘉其才朗曰丁掾好士也即使其兩目盲尚當與女何況但眇是吾兒誤我

与丁仪论事后赞其才，认为即使双眼失明也可嫁女，责曹丕误己。

**时段与依据** 魏略承婚议，此任在储争前，无年月。

<a id="period-sgz019-p-011-7"></a>

### 丁仪怨失婚而专赞曹植

[《三国志·任城陈萧王传》裴注 011·7](../../拆分史书/三国志/卷019.md#pei-011-7)

> 時儀亦恨不得尚公主而與臨菑侯親善數稱其竒才太祖既有意欲立植而儀又共贊之

丁仪未能尚主而结交曹植，屡称其才；曹操有意立植，丁仪也助赞。

**时段与依据** 称曹植临菑侯，214至217年储争阶段。

<a id="period-sgz019-p-011-9"></a>

### 曹丕调丁仪右刺奸掾，逼其自尽

[《三国志·任城陈萧王传》裴注 011·9](../../拆分史书/三国志/卷019.md#pei-011-9)

> 轉儀為右刺姦掾欲儀自裁而儀不能乃對中領軍夏侯尚叩頭求哀尚為涕泣而不能救

魏略说曹丕调丁仪任右刺奸掾，以期其自杀；丁仪叩中领军夏侯尚求情，对方泣而无力救。

**时段与依据** 在217年曹丕立太子后、220年杀丁仪前，实际调掾与请托确年缺。

<a id="period-sgz019-p-011-11"></a>

### 丁廙是丁仪弟，建安中任黄门侍郎

[《三国志·任城陈萧王传》裴注 011·11](../../拆分史书/三国志/卷019.md#pei-011-11)

> 廙字敬禮儀之弟也文士傳曰廙少有才姿博學洽聞初辟公府建安中為黄門侍郎

《文士传》称丁廙少有才姿、博学洽闻，受公府征辟，建安中任黄门侍郎。

**时段与依据** 建安中无独年。

<a id="period-sgz019-p-011-12"></a>

### 丁廙向曹操举荐曹植

[《三国志·任城陈萧王传》裴注 011·12](../../拆分史书/三国志/卷019.md#pei-011-12)

> 廙甞從容謂太祖曰臨菑侯天性仁孝發於自然而聰明智逹其殆庶幾至於博學淵識文章絶倫當今天下之賢才君子不問少長皆願從其游而為之死實天之所以鍾福於大魏而永授無窮之祚也欲以勸動太祖

丁廙称曹植孝仁聪俊、才学卓绝，能结交天下贤士有益曹魏，希望劝动曹操。

**时段与依据** 建安间曹植为临菑侯、储位未定阶段。

<a id="period-sgz019-p-011-13"></a>

### 曹操问丁廙是否立曹植为嗣

[《三国志·任城陈萧王传》裴注 011·13](../../拆分史书/三国志/卷019.md#pei-011-13)

> 太祖答曰植吾愛之安能若卿言吾欲立之為嗣何如

曹操承认钟爱曹植，问立他如何。

**时段与依据** 同一储位对话，年未详。

<a id="period-sgz019-p-011-14"></a>

### 丁廙借知子莫若父劝曹操决策

[《三国志·任城陈萧王传》裴注 011·14](../../拆分史书/三国志/卷019.md#pei-011-14)

> 廙曰此國家之所以興衰天下之所以存亡非愚劣瑣賤者所敢與及廙聞知臣莫若於君知子莫若於父至於君不論明闇父不問賢愚而能常知其臣子者何蓋由相知非一亊一物相盡非一旦一夕況明公加之以聖哲習之以人子今發明達之命吐永安之言可謂上應天命下合人心得之於須臾垂之於萬世者也廙不避斧鉞之誅敢不盡言太祖深納之

先称储嗣关系国家兴衰、不敢多议，又说君父最知臣子，以曹操圣明爱子，决断可应天命人心，曹操深为认同。

**时段与依据** 同一储位对话，年未详。

<a id="period-sgz019-p-014-1"></a>

### 雍门狄为越甲至齐请死

[《三国志·任城陈萧王传》裴注 014·1](../../拆分史书/三国志/卷019.md#pei-014-1)

> 劉向說苑曰越甲至齊雍門狄請死之齊王曰鼔鐸之聲未聞矢石未交長兵未接子何務死知為人臣之禮邪

《说苑》称越军到齐，雍门狄求死，齐王说军鼓未鸣、军兵未交，为何就死。

**时段与依据** 刘向《说苑·立节》旧事，原不具齐越君王世次与年。

<a id="period-sgz019-p-014-2"></a>

### 雍门狄举车右昔为君自尽的故事

[《三国志·任城陈萧王传》裴注 014·2](../../拆分史书/三国志/卷019.md#pei-014-2)

> 雍門狄對曰臣聞之昔者王田於囿左轂鳴車右請死之王曰子何為死車右曰為其鳴吾君也王曰左轂鳴者此工師之罪也子何事之有焉車右對曰吾不見工師之乘而見其鳴吾君也遂刎頸而死有是乎王曰有之

雍门狄举齐王打猎时车毂作声，车右虽曰工师失职，却曾自责冒犯君主而自尽。

**时段与依据** 故事内再追叙往事，年月更不可定。

<a id="period-sgz019-p-014-3"></a>

### 雍门狄自刎，齐王礼葬

[《三国志·任城陈萧王传》裴注 014·3](../../拆分史书/三国志/卷019.md#pei-014-3)

> 雍門狄曰今越甲至其鳴吾君豈左轂之下哉車右可以死左轂而臣獨不可以死越甲邪遂刎頸而死是日越人引軍而退七十里曰齊王有臣鈞如雍門狄疑使越社稷不血食遂歸齊王葬雍門狄以上卿之禮

雍门狄说外军辱君远甚毂响而死；越军闻之退七十里，因敬畏这样的臣子而归，齐王以上卿礼葬。

**时段与依据** 《说苑》同一旧事，没有独立可定年月。

<a id="period-sgz019-p-015-1"></a>

### 裴松之引鲁仲连说曹子三战三败

[《三国志·任城陈萧王传》裴注 015·1](../../拆分史书/三国志/卷019.md#pei-015-1)

> 臣松之案秦用敗軍之將事顯故不注魯連與燕將書曰曹子為魯將三戰三北而亡地五百里向使曹子計不反顧義不旋踵刎頸而死則亦不免為敗軍之將矣

秦任败将事著故略；《鲁连与燕将书》说曹子为鲁将三败失地，若只自杀，不能改其败将之名。

**时段与依据** 三战本身无具体年；已附柯盟事件前史，宜保留短分期。

<a id="period-sgz019-p-016-1"></a>

### 裴松之辨楚庄王绝缨、秦穆公赦盗马的引文

[《三国志·任城陈萧王传》裴注 016·1](../../拆分史书/三国志/卷019.md#pei-016-1)

> 臣松之案楚荘掩絶纓之罪事亦顯故不書秦穆公有赦盜馬事趙則未聞蓋以秦亦趙姓故互文以避上秦字也

楚庄王掩绝缨者的罪故事显见；秦穆公赦盗马、赵无此事，认为秦同为赵姓，借赵字变文。

**时段与依据** 裴氏训释；秦晋韩原之战在前645，盗马获赦在战前，楚绝缨也未见具体年。

<a id="period-sgz019-p-018-1"></a>

### 再征藩国士息，曹植上书要求留还

[《三国志·任城陈萧王传》裴注 018·1](../../拆分史书/三国志/卷019.md#pei-018-1)

> 魏畧曰是後大發士息及取諸國士植以近前諸國士息已見發其遺孤稚弱在者無幾而復被取乃上書曰

《魏略》记朝廷大量征发诸国士息和士卒，曹植称前番已调，其遗孤稚弱几无余者，如今又征，故上书。

**时段与依据** 裴注承太和五年（231）两疏优文答报后，终于曹植太和六年（232）死前；裴注只说“是後”，独立年月未载。

<a id="period-sgz019-p-018-2"></a>

### 曹植论君臣互信、赏罚一贯

[《三国志·任城陈萧王传》裴注 018·2](../../拆分史书/三国志/卷019.md#pei-018-2)

> 臣聞古者聖君與日月齊其明四時等其信是以戮凶無重賞善無輕怒若驚霆喜若時雨恩不中絶敎無二可以此臨朝則臣下知所死矣受任在萬里之外審主之所以受官必巳之所以投命雖有構㑹之徒泊然不以為懼者蓋君臣相信之明效也

明君赏善惩恶而信约不二，臣受命远方也会信君而效死，不怕构陷。

**时段与依据** 同一反对再征士息的上书。

<a id="period-sgz019-p-018-3"></a>

### 曹植举齐威王信任章子为例

[《三国志·任城陈萧王传》裴注 018·3](../../拆分史书/三国志/卷019.md#pei-018-3)

> 昔章子為齊将人有告之反者威王曰不然左右曰王何以明之王曰聞章子改葬死母彼尚不欺死父顧當叛生君乎此君之信臣也

齐威王拒信章子谋反的告发，以章子不欺死父断定亦不负生君。

**时段与依据** 上书用古事说明君臣信用，章子改葬母及谗告均无确年。

<a id="period-sgz019-p-018-5"></a>

### 曹植陈述藩国兵少且老

[《三国志·任城陈萧王传》裴注 018·5](../../拆分史书/三国志/卷019.md#pei-018-5)

> 臣初受封䇿書曰植受兹青社封于東土以屏翰皇家為魏藩輔而所得兵百五十人皆年在耳順或不踰矩虎賁官騎及親事凡二百餘人正復不老皆使年壯備有不虞檢校乘城顧不足以自救況皆復耄耋罷曳乎而名為魏東藩使屏翰王室臣竊自羞矣

初受策书要盾卫王室，实际给兵百五十、总从卫二百余，许多年老体弱，纵皆壮盛亦不足应变。

**时段与依据** 上书追述早期领兵限额和当时人员情形，各无独立年。

<a id="period-sgz019-p-018-6"></a>

### 曹植陈诸国兵子人数少，自请藩兵赴难

[《三国志·任城陈萧王传》裴注 018·6](../../拆分史书/三国志/卷019.md#pei-018-6)

> 就之諸國國有士子合不過五百人伏以為三軍益損不復頼此方外不定必當須辨者臣願將部曲倍道奔赴夫妻負襁子弟懐糧蹈鋒履刃以徇國難何但習業小兒哉

说诸国士子合计不足五百，送与不送对三军影响甚小；真有战事愿率部曲携家口粮赶赴。

### 桓阶传题

[《三国志·桓二陈徐卫卢传》仓内原文 L1174](../../拆分史书/三国志/卷022.md#l1174)

> 桓階

以下记桓阶。

**时段与依据** 篇目。

<a id="period-sgz022-b-1175-1"></a>

### 桓阶乡里、早年官职与父丧

[《三国志·桓二陈徐卫卢传》仓内原文 L1175](../../拆分史书/三国志/卷022.md#l1175)

> 桓階字伯緒，長沙臨湘人也。仕郡功曹。太守孫堅舉階孝廉，除尚書郎。父喪還鄉里。

桓阶字伯绪，长沙临湘人，做郡功曹，孙坚举孝廉后授尚书郎，遭父丧还乡。

**时段与依据** 孙坚曾任长沙太守，辟举和丁忧年月未明。

<a id="period-sgz022-b-1175-8"></a>

### 张羡病死、城破、桓阶隐匿

[《三国志·桓二陈徐卫卢传》仓内原文 L1175](../../拆分史书/三国志/卷022.md#l1175)

> 而表急攻羨，羨病死。城陷，階遂自匿。

刘表急攻，张羡病卒，城失守，桓阶隐匿。

**时段与依据** 《后汉书》另有张怿继立与刘表兼并的过程，具体卒破年月各缺。

<a id="period-sgz022-b-1175-9"></a>

### 刘表辟桓阶，桓阶拒婚辞疾

[《三国志·桓二陈徐卫卢传》仓内原文 L1175](../../拆分史书/三国志/卷022.md#l1175)

> 久之，劉表辟爲從事祭酒，欲妻以妻妹蔡氏。階自陳已結婚，拒而不受，因辭疾告退。

刘表任桓阶从事祭酒，想把蔡氏妻妹嫁给他；桓阶称已婚、不应，称病退职。

**时段与依据** 在荆州归曹操208年前，无确年。

<a id="period-sgz022-b-1176-2"></a>

### 桓阶任赵郡太守

[《三国志·桓二陈徐卫卢传》仓内原文 L1176](../../拆分史书/三国志/卷022.md#l1176)

> 遷趙郡太守。

桓阶转任赵郡太守。

**时段与依据** 在魏国初建前，单独任命年月未见。

<a id="period-sgz022-b-1176-4"></a>

### 桓阶先后劝立曹丕为储副

[《三国志·桓二陈徐卫卢传》仓内原文 L1176](../../拆分史书/三国志/卷022.md#l1176)

> 時太子未定，而臨菑侯植有寵。階數陳文帝德優齒長，宜爲儲副，公規密諫，前後懇至。

曹植受宠而继嗣未明，桓阶屡称曹丕年长德优，公开规劝、私下进谏，均很诚恳。

**时段与依据** 曹植临菑侯214、曹丕立储217，劝谏多次，确年不一。

<a id="period-sgz022-b-1176-6"></a>

### 桓阶善于引导与匡正，迁尚书典选

[《三国志·桓二陈徐卫卢传》仓内原文 L1176](../../拆分史书/三国志/卷022.md#l1176)

> 其將順匡救，多此類也。遷尚書，典選舉。

本传总评其推助与救正；另记任尚书后掌任官选举。

**时段与依据** 转官确年未列；其后219樊城战。

<a id="period-sgz022-b-1177-2"></a>

### 曹丕亲视桓阶病并言托孤

[《三国志·桓二陈徐卫卢传》仓内原文 L1177](../../拆分史书/三国志/卷022.md#l1177)

> 階疾病，帝自臨省，謂曰：「吾方託六尺之孤，寄天下之命於卿。勉之！」

桓阶有病，曹丕亲访，称想托皇嗣和国家给他，勉其振作。

**时段与依据** 曹丕朝，确年不明。桓阶亦见黄初三年曹丕议遣使与吴结盟，不能只由事序定卒年。

<a id="period-sgz022-b-1177-3"></a>

### 桓阶改封安乐乡侯及诸子受爵

[《三国志·桓二陈徐卫卢传》仓内原文 L1177](../../拆分史书/三国志/卷022.md#l1177)

> 徙封安樂鄉侯，邑六百戶，又賜階三子爵關內侯，祐以嗣子不封，

桓阶食邑六百，三子赐关内侯，而嗣子桓祐起初无封。

**时段与依据** 曹丕在位时，行封年月不见。

<a id="period-sgz022-b-1177-4"></a>

### 桓祐病逝，追赠关内侯

[《三国志·桓二陈徐卫卢传》仓内原文 L1177](../../拆分史书/三国志/卷022.md#l1177)

> 病卒，又追贈關內侯。

因其先以嗣子无封，卒后朝廷追赠关内侯。

**时段与依据** 与桓阶卒分别；桓祐具体卒年缺。

<a id="period-sgz022-b-1177-5"></a>

### 桓阶病重拜太常后卒，桓嘉承嗣

[《三国志·桓二陈徐卫卢传》仓内原文 L1177](../../拆分史书/三国志/卷022.md#l1177)

> 後階疾篤，遣使者即拜太常，薨，帝爲之流涕，諡曰貞侯。子嘉嗣。以階弟纂爲散騎侍郎，賜爵關內侯。

病笃时使者即就地拜太常；卒后曹丕流泪，谥贞侯，子桓嘉嗣；弟桓纂任散骑侍郎、赐关内侯。

**时段与依据** 曹丕在位内，原文无卒年，保留宽限。

<a id="period-sgz022-b-1177-6"></a>

### 桓嘉与升迁亭公主结婚

[《三国志·桓二陈徐卫卢传》仓内原文 L1177](../../拆分史书/三国志/卷022.md#l1177)

> 嘉尚升遷亭公主，

桓嘉尚升迁亭公主。

**时段与依据** 嘉平年间赴东关前，尚主年月不明。

### 陈群传题

[《三国志·桓二陈徐卫卢传》仓内原文 L1178](../../拆分史书/三国志/卷022.md#l1178)

> 陳羣

以下记陈群，后附其子陈泰。

**时段与依据** 篇目。

<a id="period-sgz022-b-1179-1"></a>

### 陈群家世和祖辈预许

[《三国志·桓二陈徐卫卢传》仓内原文 L1179](../../拆分史书/三国志/卷022.md#l1179)

> 陳羣字長文，潁川許昌（人）也。祖父寔，父紀，叔父諶，皆有盛名。羣爲兒時，寔常奇異之，謂宗人父老曰：「此兒必興吾宗。」

陈群字长文，颍川许昌人。祖陈寔、父陈纪、叔陈谌俱有名，陈寔看重幼时的群，称将兴家族。

**时段与依据** 人物概述；世系见裴注。

<a id="period-sgz022-b-1179-2"></a>

### 孔融先交陈纪后交陈群

[《三国志·桓二陈徐卫卢传》仓内原文 L1179](../../拆分史书/三国志/卷022.md#l1179)

> 魯國孔融高才倨傲，年在紀、羣之間，先與紀友，後與羣交，更爲紀拜，由是顯名。

孔融比纪年少、比群年长，先友陈纪，后交群、改向纪行尊长礼，陈群由此著名。

**时段与依据** 早年交游缺年。

<a id="period-sgz022-b-1179-7"></a>

### 陈群未赴柘令，随父避居徐州

[《三国志·桓二陈徐卫卢传》仓内原文 L1179](../../拆分史书/三国志/卷022.md#l1179)

> 舉茂才，除柘令，不行，隨紀避難徐州。

陈群被举茂才、任柘县令而没有赴任，随父陈纪到徐州避难。

**时段与依据** 下邳破前的安排，无独立年。

<a id="period-sgz022-b-1179-9"></a>

### 陈群反对曹操辟王模、周逵

[《三国志·桓二陈徐卫卢传》仓内原文 L1179](../../拆分史书/三国志/卷022.md#l1179)

> 時有薦樂安王模、下邳周逵者，太祖辟之。羣封還教，以爲模、逵穢德，終必敗，太祖不聽。後模、逵皆坐奸宄誅，太祖以謝羣。

陈群封还辟书，说二人德差终败，曹操不听；二人犯罪被杀，曹操向陈群道歉。

**时段与依据** 荐辟与诛杀无具体年。

<a id="period-sgz022-b-1179-10"></a>

### 陈群荐陈矫、戴乾

[《三国志·桓二陈徐卫卢传》仓内原文 L1179](../../拆分史书/三国志/卷022.md#l1179)

> 羣薦廣陵陳矯、丹陽戴乾，太祖皆用之。後吳人叛，乾忠義死難，矯遂爲名臣，世以羣爲知人。

曹操都任用，后来戴乾在吴人反叛中殉难、陈矫成名臣，时人由此认为陈群能识人。

**时段与依据** 推荐与戴乾之死不标年。

<a id="period-sgz022-b-1179-11"></a>

### 陈群历萧、赞、长平三令

[《三国志·桓二陈徐卫卢传》仓内原文 L1179](../../拆分史书/三国志/卷022.md#l1179)

> 除蕭、贊、長平令，

三处除令依传文先后，逐任年月未明。

**时段与依据** 建安中前期。

<a id="period-sgz022-b-1179-13"></a>

### 陈群从司徒府入曹操丞相府

[《三国志·桓二陈徐卫卢传》仓内原文 L1179](../../拆分史书/三国志/卷022.md#l1179)

> 後以司徒掾舉高第，爲治書侍御史，轉參丞相軍事。

以司徒掾被举高第，任治书侍御史，又转参丞相军事。

**时段与依据** 曹操208年为丞相给参军事上界，陈群任职年月不明。

<a id="period-sgz022-b-1183-1"></a>

### 陈群转侍中兼丞相东西曹掾

[《三国志·桓二陈徐卫卢传》仓内原文 L1183](../../拆分史书/三国志/卷022.md#l1183)

> 羣轉爲侍中，領丞相東西曹掾。在朝無適無莫，雅杖名義，不以非道假人。

朝中待人以名义，对非道之事不肯徇情。

**时段与依据** 建安中晚年，具体除授年未明。

<a id="period-sgz022-b-1183-2"></a>

### 曹丕在东宫礼待陈群如友

[《三国志·桓二陈徐卫卢传》仓内原文 L1183](../../拆分史书/三国志/卷022.md#l1183)

> 文帝在東宮，深敬器焉，待以交友之禮，常嘆曰：「自吾有回，門人日以親。」

尊敬器重陈群，称得他好比孔子得颜回，门人更加相亲。

**时段与依据** 曹丕魏太子217年底至220继王，原无确年。

<a id="period-sgz022-b-1183-6"></a>

### 陈群迁尚书令、进封颍乡侯

[《三国志·桓二陈徐卫卢传》仓内原文 L1183](../../拆分史书/三国志/卷022.md#l1183)

> 徙尚書令，進爵穎鄉侯。

自仆射迁尚书令并进爵。

**时段与依据** 黄初四年223《文帝纪》已作尚书令；早于此时，进封年月未知。

<a id="period-sgz022-b-1195-2"></a>

### 陈群拒受刘廙私谢

[《三国志·桓二陈徐卫卢传》仓内原文 L1195](../../拆分史书/三国志/卷022.md#l1195)

> 廙深德羣，羣曰：「夫議刑爲國，非爲私也；且自明主之意，吾何知焉？」其弘博不伐，皆此類也。

刘廙感谢，陈群说是国家议刑，且本出明主意，非个人恩德。

**时段与依据** 同案后未载谈谢年月；传以此称其谦厚。

以下附记陈群子陈泰。

**时段与依据** 篇目。

<a id="period-sgz022-b-1197-1"></a>

### 陈泰表字与早年为散骑侍郎

陈泰字玄伯，青龙中任散骑侍郎。

**时段与依据** 青龙从233年始至237年改元，原未明具体年。

<a id="period-sgz022-b-1197-2"></a>

### 陈泰守并州、护匈奴有惠

[《三国志·桓二陈徐卫卢传》仓内原文 L1197](../../拆分史书/三国志/卷022.md#l1197)

> 正始中，徙游擊將軍，爲并州刺史，加振威將軍，使持節，護匈奴中郎將，懷柔夷民，甚有威惠。

正始中转任游击将军，再任并州刺史，加振威将军、持节、护匈奴中郎将，招抚边民。

**时段与依据** 正始240–249，诸次任官无独年。

<a id="period-sgz022-b-1197-3"></a>

### 陈泰严拒京贵人以财求购奴婢

[《三国志·桓二陈徐卫卢传》仓内原文 L1197](../../拆分史书/三国志/卷022.md#l1197)

> 京邑貴人多寄寶貨，因泰市奴婢，泰皆掛之於壁，不發其封，及徵爲尚書，悉以還之。

京都权贵托付宝物，请他购奴婢；陈泰不拆封，只挂墙上，征为尚书时完全退还。

**时段与依据** 并州任末、嘉平初刺雍州前，确年缺。

<a id="period-sgz022-b-1201-2"></a>

### 陈泰战时惯于从简上报

[《三国志·桓二陈徐卫卢传》仓内原文 L1201](../../拆分史书/三国志/卷022.md#l1201)

> 泰每以一方有事，輒以虛聲擾動天下，故希簡白上事，驛書不過六百里。

陈泰认为过度传闻会惊动四方，一般少发公文，驿书不超过六百里。

**时段与依据** 陈泰性格与习惯概述，未限定该役。

<a id="period-sgz022-b-1202-1"></a>

### 陈泰入任尚书右仆射等职

[《三国志·桓二陈徐卫卢传》仓内原文 L1202](../../拆分史书/三国志/卷022.md#l1202)

> 後徵泰爲尚書右僕射，典選舉，加侍中光祿大夫。

被征为尚书右仆射管选举，加侍中光禄大夫。

**时段与依据** 255年狄道还后，256年孙峻出淮泗前，具体年月不具。

<a id="period-sgz022-b-1202-4"></a>

### 武陔比较陈泰和陈群

[《三国志·桓二陈徐卫卢传》仓内原文 L1202](../../拆分史书/三国志/卷022.md#l1202)

> 司馬景王、文王皆與泰親友，及沛國武陔亦與泰善。文王問陔曰：「玄伯何如其父司空也？」陔曰：「通雅博暢，能以天下聲教爲己任者，不如也；明統簡至，立功立事，過之。」

司马师、司马昭和武陔都与陈泰亲友，武陔对司马昭说陈泰不如父亲弘通，但办事得力、建功则胜。

**时段与依据** 父子总评，谈话实际年未载。

<a id="period-sgz022-b-1202-5"></a>

### 陈泰历功增食邑、子弟赐爵

[《三国志·桓二陈徐卫卢传》仓内原文 L1202](../../拆分史书/三国志/卷022.md#l1202)

> 泰前後以功增邑二千六百戶，賜子弟一人亭侯，二人關內侯。

陈泰历次获增至二千六百户，一名子弟获亭侯、两名获关内侯。

**时段与依据** “前後”各次确年无法分拆。

<a id="period-sgz022-b-1203-2"></a>

### 陈恂无子死，弟陈温承爵

陈泰子陈恂继爵后去世，弟陈温续封。

**时段与依据** 介于260年陈泰去世和咸熙封慎子之间；陈恂卒不具年。

**时段与依据** 篇目。

<a id="period-sgz022-b-1205-1"></a>

### 陈矫籍贯、避乱及辟召

[《三国志·桓二陈徐卫卢传》仓内原文 L1205](../../拆分史书/三国志/卷022.md#l1205)

> 陳矯字季弼，廣陵東陽人也。避亂江東及東城，辭孫策、袁術之命，還本郡。

陈矫字季弼、广陵东阳人。避乱江东、东城，辞孙策和袁术招用，返乡。

<a id="period-sgz022-b-1205-2"></a>

### 桓范荐徐宣任尚书仆射

**[《三国志·桓二陈徐卫卢传》全文](../../拆分史书/三国志/卷022.md#sg-full-022-l75-c25)** · [TXT L75–L77](../../拆分史书/三国志/卷022.txt#L75-L77)

> 中領軍桓範薦宣曰：「臣聞帝王用人，度世授才，爭奪之時，以策略爲先，分定之後，以忠義爲首。故晉文行舅犯之計而賞雍季之言，
>
> 〔裴注〕呂氏春秋曰：昔晉文公將與楚人戰於城濮，召咎犯而問曰：「楚衆我寡，柰何而可？」咎犯對曰：「臣聞繁禮之君，不足於文，繁戰之君，不足於詐，君亦詐之而已。」文公以咎犯言告雍季，雍季曰：「竭澤而漁，豈不得魚，而明年無魚。焚藪而田，豈不得獸，而明年無獸。詐偽之道，雖今偷可，後將無復，非長術也。」文公用咎犯之言，而敗楚人於城濮。反而爲賞，雍季在上。左右諫曰：「城濮之功，咎犯之謀也。君用其言而後其身，或者不可乎！」文公曰：「雍季之言，百代之利也；咎犯之言，一時之務也。焉有以一時之務，先百代之利乎？」
>
> 高祖用陳平之智而託後於周勃也。竊見尚書徐宣，體忠厚之行，秉直亮之性；清雅特立，不拘世俗；確然難動，有社稷之節；歷位州郡，所在稱職。今僕射缺，宣行掌後事；腹心任重，莫宜宣者。」

桓范担任中领军时荐徐宣。

### 徐宣以年六十八求退休，明帝不许

[《三国志·桓二陈徐卫卢传》仓内原文 L1214](../../拆分史书/三国志/卷022.md#l1214)

> 宣曰：「七十有縣車之禮，今已六十八，可以去矣。」乃固辭疾遜位，帝終不許。

用七十岁悬车退休之礼，固辞称病求去，明帝坚持不允。

**时段与依据** 卒前未定独年，不由所载年龄倒推未知生年。

### 卫臻传题

[《三国志·桓二陈徐卫卢传》仓内原文 L1216](../../拆分史书/三国志/卷022.md#l1216)

> 衛臻

以下记卫臻。

**时段与依据** 篇目。

<a id="period-sgz022-b-1217-1"></a>

### 卫臻家世与父卫兹不受辟

[《三国志·桓二陈徐卫卢传》仓内原文 L1217](../../拆分史书/三国志/卷022.md#l1217)

> 衛臻字公振，陳留襄邑人也。父茲，有大節，不應三公之辟。

卫臻字公振，陈留襄邑人。卫兹有大节，不应三公辟请。

**时段与依据** 家世与隐居，无独年。

<a id="period-sgz022-b-1217-4"></a>

### 曹操经陈留常遣使祭卫兹

[《三国志·桓二陈徐卫卢传》仓内原文 L1217](../../拆分史书/三国志/卷022.md#l1217)

> 太祖每涉郡境，輒遣使祠焉。

卫兹死后，曹操每经过其郡就派人祭祀。

**时段与依据** 反复发生，逐次年月未明。

<a id="period-sgz022-b-1218-1"></a>

### 夏侯惇举卫臻计吏，因宴礼龃龉而拘释

[《三国志·桓二陈徐卫卢传》仓内原文 L1218](../../拆分史书/三国志/卷022.md#l1218)

> 夏侯惇爲陳留太守，舉臻計吏，命婦出宴，臻以爲「末世之俗，非禮之正」。惇怒，執臻，既而赦之。

夏侯惇任陈留太守，荐卫臻为上计吏。惇命妻出宴，卫臻指非正礼，被捕后获赦。

**时段与依据** 同在陈留任职阶段，缺年。

<a id="period-sgz022-b-1218-2"></a>

### 卫臻任汉黄门侍郎，在朱越案中获信

[《三国志·桓二陈徐卫卢传》仓内原文 L1218](../../拆分史书/三国志/卷022.md#l1218)

> 後爲漢黃門侍郎。東郡硃越謀反，引臻。太祖令曰：「孤與卿君同共舉事，加欽令問。始聞越言，固自不信。及得荀令君書，具亮忠誠。」

东郡朱越谋叛供出卫臻，曹操信其忠，荀彧来书也明其实。

**时段与依据** 荀彧仍参与其事，卒于212年，案具体年不见。

<a id="period-sgz022-b-1218-3"></a>

### 卫臻奉使聘贵人后入曹操幕，获爵

[《三国志·桓二陈徐卫卢传》仓内原文 L1218](../../拆分史书/三国志/卷022.md#l1218)

> 會奉詔命，聘貴人於魏，因表留臻參丞相軍事。追錄臻父舊勛，賜爵關內侯，轉爲戶曹掾。

以诏出聘贵人，曹操表留其参丞相军事；追念其父旧绩，赐关内侯，转户曹掾。

**时段与依据** 贵人未明姓名，各任不独年。

### 卫臻迁尚书，转侍中吏部尚书

> 遷尚書，轉侍中吏部尚書。

自常侍转入尚书系统，后兼侍中。

**时段与依据** 继受禅后、224年前，任命具体年缺。

### 卫臻任右仆射兼侍中，掌选举

[《三国志·桓二陈徐卫卢传》仓内原文 L1219](../../拆分史书/三国志/卷022.md#l1219)

改任尚书右仆射典选，仍兼侍中。

**时段与依据** 景初元年迁司空前，任职确年未明。

<a id="period-sgz022-b-1219-3"></a>

### 蒋济、卫臻论是否可破格任官

[《三国志·桓二陈徐卫卢传》仓内原文 L1219](../../拆分史书/三国志/卷022.md#l1219)

> 中護軍蔣濟遺臻書曰：「漢祖遇亡虜爲上將，周武拔漁父爲太師；布衣廝養，可登王公，何必守文，試而後用？」臻答曰：「古人遺智慧而任度量，須考績而加黜陟；今子同牧野於成、康，喻斷於文、景，好不經之舉，開拔奇之津，將使天下馳騁而起矣。」

蒋济举韩信、吕尚自微贱擢用；卫臻强调古制考绩黜陟，担心过于求奇会使人竞进。

**时段与依据** 《通鉴》卷073景初元年后的回述标“初”，没有指定当年；应早于蒋济转护军将军。

<a id="period-sgz022-b-1219-5"></a>

### 卫臻屡谏曹叡盛治宫室

[《三国志·桓二陈徐卫卢传》仓内原文 L1219](../../拆分史书/三国志/卷022.md#l1219)

> 是時，帝方隆意於殿舍，臻數切諫。

曹叡特别在意宫殿建造，卫臻数次劝止。

**时段与依据** “數”是持续谏诤；下文殿中监独案可定235。

<a id="period-sgz022-b-1221-4"></a>

### 卫臻拒丁仪邀入曹植一派

[《三国志·桓二陈徐卫卢传》仓内原文 L1221](../../拆分史书/三国志/卷022.md#l1221)

> 初，太祖久不立太子，而方奇貴臨菑侯。丁儀等爲之羽翼，勸臻自結，臻以大義拒之。

曹操未定太子而宠曹植，丁仪等劝卫臻与之结交，卫臻以大义拒绝。

**时段与依据** 曹植封临菑侯214、曹丕立储217，询说无确年。

<a id="period-sgz022-b-1221-5"></a>

### 曹丕问卫臻平原侯曹叡如何

[《三国志·桓二陈徐卫卢传》仓内原文 L1221](../../拆分史书/三国志/卷022.md#l1221)

> 及文帝即位，東海王霖有寵，帝問臻：「平原侯何如？」臻稱明德美而終不言。

曹霖有宠之时曹丕询问，卫臻称明德美而不尽言。

**时段与依据** 黄初在位初“平原侯”有追叙称谓问题，《明帝纪》称曹叡先武德侯，黄初二年齐公、三年平原王，故不由此称号硬定。

**时段与依据** 曹爽辅政239起，辞前确年不详。

### 裴潜弟裴徽及诸子闻名

[《三国志·和常杨杜赵裴传》裴注 019·12](../../拆分史书/三国志/卷023.md#pei-019-12)

裴徽能玄谈，裴黎、康、楷、绰皆仕显，以裴楷名最重。

**时段与依据** 几代官历非单年。

<a id="wei023-l93-14"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l93-14)** · [TXT L93](../../拆分史书/三国志/卷023.txt#L93)

> 潛少弟徽，字文季，兾州刺史。有高才遠度，善言玄妙。事見荀粲、傅嘏、王弼、管輅諸傳。徽長子黎，字伯宗，一名演，游擊將軍。次康，字仲豫，太子左衞率。次楷，字叔則，侍中中書令、光祿大夫、開府。次綽，字季舒，黃門侍郎，早卒，追贈長水校尉。康、楷、綽皆爲名士，而楷才望最重。

**釋讀與歸年** 裴徽及裴黎（又名演）、裴康、裴楷、裴綽的才行官歷；裴楷最著名。裴綽卒贈長水校尉，年未詳。

### 钟会荐裴楷、王戎

[《三国志·和常杨杜赵裴传》裴注 019·13](../../拆分史书/三国志/卷023.md#pei-019-13)

司马昭辟两人为掾，裴楷著声，谢鲲称一时俊朗。

**时段与依据** 曹魏末，荐辟哪年未署。

<a id="wei023-l93-15"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l93-15)** · [TXT L93](../../拆分史书/三国志/卷023.txt#L93)

> 晉諸公贊曰：康有弘量，綽以明達爲稱，楷少與琅邪王戎俱爲掾發名，鍾會致之大將軍司馬文王曰：「裴楷清通，王戎簡要。」文王即辟爲掾，進歷顯位。謝鯤爲樂廣傳，稱楷儁朗有識具，當時獨步。

**釋讀與歸年** 鍾會薦裴楷與王戎給大將軍司馬昭，兩人受辟；謝鯤也在《樂廣傳》中盛讚裴楷。以司馬昭任大將軍和鍾會死作時限（255至264），荐辟無確年。

### 裴苞裴纯裴盾裴郃等历官

[《三国志·和常杨杜赵裴传》裴注 019·14](../../拆分史书/三国志/卷023.md#pei-019-14)

裴郃为安东将军长史，王旷称吴地士人敬其识量；裴氏子孙多显。

**时段与依据** 司马睿为安东将军阶段可约，多人不可强系一载。

<a id="wei023-l93-16"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l93-16)** · [TXT L93](../../拆分史书/三国志/卷023.txt#L93)

> 黎子苞，秦州刺史。康子純，黃門侍郎。次盾，徐州刺史。次郃，有器望。晉元帝爲安東將軍，郃爲長史，侍中王曠與司馬越書曰：「裴郃在此，雖不治事，然識量弘淹，此下人士大敬附之。」次廓，中壘將軍。

**釋讀與歸年** 列裴苞、裴純、裴盾、裴郃、裴廓仕歷。裴郃在司馬睿任安東將軍時為長史，王曠寫信稱其器量，書信與任職的確年未詳。

### 《魏略》记严干李义少时

[《三国志·和常杨杜赵裴传》裴注 019·17](../../拆分史书/三国志/卷023.md#pei-019-17)

同冯翊东部寒门，严干击剑、李义善丧仪，为士族所识；三辅乱仍居故地。

**时段与依据** 中平末二十余，乱时时段较宽，未署发生年。

<a id="wei023-l93-19"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l93-19)** · [TXT L93](../../拆分史书/三国志/卷023.txt#L93)

> 嚴幹字公仲，李義字孝懿，皆馮翊東縣人也。馮翊東縣舊無冠族，故二人並單家，其器性皆重厚。當中平末，同年二十餘，幹好擊劒，義好辦護喪事。馮翊甲族桓、田、吉、郭及故侍中鄭文信等，頗以其各有器實，共紀識之。會三輔亂，人多流宕，而幹、義不去，與諸知故相浮沉，採樵自活。

**釋讀與歸年** 嚴幹、李義都出寒門，漢中平末同為二十餘歲，所長各異，得馮翊豪族賞識，三輔亂時留鄉採樵度日。各事未詳年。

### 建安初分冯翊与严干李义共仕东郡

[《三国志·和常杨杜赵裴传》裴注 019·18](../../拆分史书/三国志/卷023.md#pei-019-18)

一部分归左内史，郡治高陵；李义本应西属而附严干，两人皆仕东郡，历举辟迁官。

**时段与依据** 建安初，未署改县与举任的年。

<a id="wei023-l93-20"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l93-20)** · [TXT L93](../../拆分史书/三国志/卷023.txt#L93)

> 逮建安初，關中始開。詔分馮翊西數縣爲左內史郡，治高陵；以東數縣爲本郡，治臨晉。義於縣分當西屬，義謂幹曰：「西縣兒曹，不可與爭坐席，今當共作方牀耳。」遂相附結，皆仕東郡爲右職。司隷辟幹，不至。歲終，郡舉幹孝廉，義上計掾。義留京師，爲平陵令，遷宂從僕射，遂歷顯職。

**釋讀與歸年** 建安初分馮翊西數縣為左內史郡，其餘仍治臨晉。李義原當西屬，仍結交嚴幹、同在東郡任職；後嚴幹舉孝廉，李義歷平陵令與宂從僕射。建安初是區間，未硬定分郡之年。

### 严干与钟繇辨公羊左氏

[《三国志·和常杨杜赵裴传》裴注 019·24](../../拆分史书/三国志/卷023.md#pei-019-24)

钟繇善《左传》，贬公羊；严干虽口讷，答说自己为故吏服上司，公羊学未服。

**时段与依据** 两人共事时多有辩，未署年。

<a id="wei023-l93-28"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l93-28)** · [TXT L93](../../拆分史书/三国志/卷023.txt#L93)

> 幹從破亂之後，更折節學問，特善春秋公羊。司隷鍾繇不好公羊而好左氏，謂左氏爲太官，而謂公羊爲賣餅家，故數與幹共辯析長短。繇爲人機捷，善持論，而幹訥口，臨時屈無以應。繇謂幹曰：「公羊高竟爲左丘明服矣。」幹曰：「直故吏爲明使君服耳，公羊未肯也。」

**釋讀與歸年** 嚴幹好《公羊》，鍾繇好《左氏》，兩人以太官、賣餅與故吏之禮辯經。辯論在鍾繇任司隸時，未載確年。

### 韩宣任曹操军谋掾并路遇曹植

[《三国志·和常杨杜赵裴传》裴注 019·25](../../拆分史书/三国志/卷023.md#pei-019-25)

渤海人，字景然，雨后因泥不得回避临菑侯，持扇侧立。

**时段与依据** 建安间曹植封临菑后，无确年。

<a id="wei023-l93-29"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l93-29)** · [TXT L93](../../拆分史书/三国志/卷023.txt#L93)

> 韓宣字景然，勃海人也。爲人短小。建安中，丞相召署軍謀掾，宂散在鄴。嘗於鄴出入宮，於東掖門內與臨菑侯植相遇。時天新雨，地有泥潦。宣欲避之，閡潦不得去。乃以扇自障，住於道邊。植嫌宣旣不去，又不爲禮，乃駐車，使其常從問宣何官？宣云：「丞相軍謀掾也。」植又問曰：「應得唐突列侯否？」宣曰：「春秋之義，王人雖微，列于諸侯之上，未聞宰士而爲下士諸侯禮也。」植又曰：「即如所言，爲人父吏，見其子應有禮否？」宣又曰：「於禮，臣、子一例也，而宣年又長。」植知其枝柱難窮，乃釋去，具爲太子言，以爲辯。

**釋讀與歸年** 韓宣建安中為丞相軍謀掾，在鄴城東掖門遇臨菑侯曹植，以《春秋》之義回應問禮。曹植214年徙臨菑侯、221年進公，今據丞相尚在、曹丕已為太子的語境，約在217–219年間。

### 曹丕记韩宣旧事而免杖

[《三国志·和常杨杜赵裴传》裴注 019·27](../../拆分史书/三国志/卷023.md#pei-019-27)

韩宣以事待杖，皇帝认出曹植称誉者，赦而笑其脱袴奔去。

**时段与依据** 黄初中，无确年。

<a id="wei023-l93-30"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l93-30)** · [TXT L93](../../拆分史书/三国志/卷023.txt#L93)

> 黃初中，爲尚書郎，嘗以職事當受罰於殿前，已縛，束杖未行。文帝輦過，問：「此爲誰？」左右對曰：「尚書郎勃海韓宣也。」帝追念前臨菑侯所說，乃寤曰：「是子建所道韓宣邪！」特原之，遂解其縛。時天大寒，宣前以當受杖，豫脫袴，纏褌靣縛；及其原，褌腰不下，乃趨而去。帝目而送之，笑曰：「此家有瞻諦之士也。」

**釋讀與歸年** 黃初間，韓宣任尚書郎而當受杖。曹丕想起曹植曾稱韓宣善辯而特赦，笑看他解縛疾走。未載月年。

> 後出爲清河、東郡太守。明帝時，爲尚書大鴻臚，數歲卒。宣前後當官，在能否之間，然善以己恕人。始南陽韓曁以宿德在宣前爲大鴻臚，曁爲人賢，及宣在後亦稱職，故鴻臚中爲之語曰：「大鴻臚，小鴻臚，前後治行曷相如。」

**釋讀與歸年** 韓宣歷清河、東郡太守，明帝時任尚書、大鴻臚，與此前居同官的韓暨都稱職。卒年未載。

### 裴松之校韩宣传的著录

[《三国志·和常杨杜赵裴传》裴注 019·29](../../拆分史书/三国志/卷023.md#pei-019-29)

本志无传，《魏略》有传，《世语》列为名臣。

**时段与依据** 书例。

<a id="wei023-l93-32"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l93-32)** · [TXT L93](../../拆分史书/三国志/卷023.txt#L93)

> 案本志，宣名都不見，惟魏略有此傳，而世語列於名臣之流。

**釋讀與歸年** 裴松之說陳壽原傳未著韓宣，只有《魏略》作傳，《世語》列作名臣。

### 黄朗因父事奋志，结交王惠阳

[《三国志·和常杨杜赵裴传》裴注 019·30](../../拆分史书/三国志/卷023.md#pei-019-30)

沛郡人，父为县卒，求学知名；王惠阳与之深交，拜其母。

**时段与依据** 早年无确年。

<a id="wei023-l93-33"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l93-33)** · [TXT L93](../../拆分史书/三国志/卷023.txt#L93)

> 黃朗字文達，沛郡人也。爲人弘通有性實。父爲本縣卒，朗感其如此，抗志游學，由是爲方國及其郡士大夫所禮異。特與東平右姓王惠陽爲碩交，惠陽親拜朗母於牀下。

**釋讀與歸年** 黃朗出身縣卒之家，發憤遊學得名，與東平王惠陽結厚交，惠陽親拜其母。

### 黄朗黄初初仕，至明帝时卒

[《三国志·和常杨杜赵裴传》裴注 019·31](../../拆分史书/三国志/卷023.md#pei-019-31)

长吏、长安令，因母丧未赴，后历魏令、襄城典农、涿郡守。

**时段与依据** 黄初及明帝朝，无单年。

<a id="wei023-l93-34"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l93-34)** · [TXT L93](../../拆分史书/三国志/卷023.txt#L93)

> 朗始仕黃初中，爲長吏，遷長安令，會喪母不赴，復爲魏令，遷襄城典農中郎將、涿郡太守。以明帝時疾病卒。

**釋讀與歸年** 黃朗黃初間起仕，後為長安令因喪未赴，歷魏令、襄城典農中郎將、涿郡太守，明帝時病卒。各任與卒年未詳。

<a id="period-sgz023-p-019-32"></a>

### 黄朗任长官犹敬礼基层卒

[《三国志·和常杨杜赵裴传》裴注 019·32](../../拆分史书/三国志/卷023.md#pei-019-32)

因父旧职，不以役称呼他们；王惠阳亦历令守，时人称其厚待黄朗母亲。

**时段与依据** 合叙官履及操行。

<a id="wei023-l93-35"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l93-35)** · [TXT L93](../../拆分史书/三国志/卷023.txt#L93)

> 始朗爲君長，自以父故，常忌不呼鈴下伍伯，而呼其姓字，至於忿怒，亦終不言。朗旣仕至二千石，而惠陽亦歷長安令、酒泉太守。故時人謂惠陽外似麤疏而內堅密，能不顧朗之本末，事朗母如己母，爲通度也。

**釋讀與歸年** 黃朗念父曾為縣卒，接待下吏必稱姓名；王惠陽後歷長安令、酒泉太守，始終以親恩禮黃朗之母。

### 鱼豢合评严干等十人

[《三国志·和常杨杜赵裴传》裴注 019·33](../../拆分史书/三国志/卷023.md#pei-019-33)

举刘仲始受辱向学，比徐福严干转变；分别论李义张既韩宣黄朗才能，再称游楚与梁习赵俨裴潜。

**时段与依据** 后出合评，不定年。

<a id="wei023-l93-36"></a>

**[《三國志·和常楊杜趙裴傳》裴注](../../拆分史书/三国志/卷023.md#edition-wei023-l93-36)** · [TXT L93](../../拆分史书/三国志/卷023.txt#L93)

> 魚豢曰：世稱君子之德其猶龍乎，蓋以其善變也。昔長安巿儈有劉仲始者，一爲巿吏所辱，乃感激，蹋其尺折之，遂行學問，經門行脩，流名海內。後以有道徵，不肯就，衆人歸其高。余以爲前世偶有此耳，而今徐、嚴復參之，若皆非似龍之志也，其何能至於此哉？李推至道，張工度主，韓見識異，黃能拔萃，各著根於石上，而垂陰乎千里，亦未爲易也。游翁慷慨，展布腹心，全軀保郡，見延帝王，又放陸生，優游宴戲，亦一實也。梁、趙及裴，雖張、楊不足，至於檢己，老而益明，亦難能也。

**釋讀與歸年** 魚豢以劉仲始受辱自奮為例，評嚴幹等各能自立、各有所長，並特舉游楚、梁習、趙儼、裴潛自持。史評附《魏略》四傳。

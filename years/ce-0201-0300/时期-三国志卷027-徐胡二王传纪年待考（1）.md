### 徐邈传篇题

[《三国志·徐胡二王传》仓内原文 L1407](../../拆分史书/三国志/卷027.md#l1407)

> 徐邈

下文转入徐邈事。

**时段与依据** 篇题无纪年。

<a id="period-sgz027-b-1408-1"></a>

### 徐邈表字与籍贯

[《三国志·徐胡二王传》仓内原文 L1408](../../拆分史书/三国志/卷027.md#l1408)

> 徐邈字景山，燕國薊人也。

徐邈字景山，燕国蓟人。

**时段与依据** 本传无生年。

<a id="period-sgz027-b-1408-2"></a>

### 曹操召徐邈入军府，徐邈历任奉高与东曹

[《三国志·徐胡二王传》仓内原文 L1408](../../拆分史书/三国志/卷027.md#l1408)

> 太祖平河朔，召爲丞相軍謀掾，試守奉高令，入爲東曹議令史。

徐邈经征召为丞相军谋掾，试任奉高令，入东曹作议令史。

**时段与依据** 曹操204至207年平河北，丞相府建于208年，征召并转任的确年无载。

<a id="period-sgz027-b-1408-4"></a>

### 徐邈醉答「中圣人」，鲜于辅解释而免刑

[《三国志·徐胡二王传》仓内原文 L1408](../../拆分史书/三国志/卷027.md#l1408)

> 時科禁酒，而邈私飲至於沈醉。校事趙達問以曹事，邈曰：「中聖人。」達白之太祖，太祖甚怒。度遼將軍鮮于輔進曰：「平日醉客謂酒清者爲聖人，濁者爲賢人，邈性脩慎，偶醉言耳。」竟坐得免刑。

禁酒时徐邈醉了，称为中圣人。曹操闻而怒，鲜于辅说明以圣人称清酒、贤人称浊酒只是酒客惯语，徐邈得免刑。

**时段与依据** 事件在徐邈任尚书郎时间，停禁和赵达问话的确年无明文。

<a id="period-sgz027-b-1408-5"></a>

### 徐邈历任陇西、南安

[《三国志·徐胡二王传》仓内原文 L1408](../../拆分史书/三国志/卷027.md#l1408)

> 後領隴西太守，轉爲南安。

徐邈领陇西太守，后转南安。

**时段与依据** 叙于曹操末年至曹丕登基前，未记各年。

<a id="period-sgz027-b-1408-6"></a>

### 曹丕在位时徐邈历数郡及典农

[《三国志·徐胡二王传》仓内原文 L1408](../../拆分史书/三国志/卷027.md#l1408)

> 文帝踐阼，歷譙相，平陽、安平太守，潁川典農中郎將，所在著稱，賜爵關內侯。

徐邈历谯相、平阳安平太守、颍川典农中郎将，受爵关内侯。

**时段与依据** 220年曹丕践阼给下限。历官为多年总写，没有具体受爵年。

<a id="period-sgz027-b-1408-7"></a>

### 曹丕到许昌询徐邈饮酒，后来任军师

[《三国志·徐胡二王传》仓内原文 L1408](../../拆分史书/三国志/卷027.md#l1408)

> 車駕幸許昌，問邈曰：「頗復中聖人不？」邈對曰：「昔子反斃於穀陽，御叔罰於飲酒，臣嗜同二子，不能自懲，時復中之。然宿瘤以醜見傳，而臣以醉見識。」帝大笑，顧左右曰：「名不虛立。」遷撫軍大將軍軍師。

曹丕问还会否「中圣人」，徐邈借子反、御叔和宿瘤女答以自己因酒见知，皇帝笑答，随后徐邈迁抚军大将军军师。

**时段与依据** 黄初期间曹丕数幸许昌，抚军大将军一职到225年已有司马懿，本段缺明确到任日。

<a id="period-sgz027-b-1409-3"></a>

### 徐邈修盐池、兴水田并接济军民

[《三国志·徐胡二王传》仓内原文 L1409](../../拆分史书/三国志/卷027.md#l1409)

> 河右少雨，常苦乏糓，邈上脩武威、酒泉鹽池以收虜糓，又廣開水田，募貧民佃之，家家豐足，倉庫盈溢。乃支度州界軍用之餘，以市金帛犬馬，通供中國之費。

河西缺粮，修武威酒泉盐池，以盐收粮，开田募佃，仓廪充实；用军用之余购买金帛犬马，供给内地。

**时段与依据** 凉州任内多年治理，无单年。

<a id="period-sgz027-b-1409-4"></a>

### 徐邈收兵杖、兴教化并通西域

[《三国志·徐胡二王传》仓内原文 L1409](../../拆分史书/三国志/卷027.md#l1409)

> 以漸收斂民間私杖，藏之府庫。然後率以仁義，立學明訓，禁厚葬，斷淫祀，進善黜惡，風化大行，百姓歸心焉。西域流通，荒戎入貢，皆邈勳也。

逐步收民间私兵器，倡仁义学校，禁厚葬、淫祀，贬恶进善；本传归功于徐邈使西域贸易和来贡恢复。

**时段与依据** 分期施行及诸国入贡总述，不以某次使者代全部。

<a id="period-sgz027-b-1409-5"></a>

### 徐邈破叛羌柯吾进封都亭侯

[《三国志·徐胡二王传》仓内原文 L1409](../../拆分史书/三国志/卷027.md#l1409)

> 討叛羌柯吾有功，封都亭侯，邑三百戶，加建威將車。

战功使其受邑三百户、加建威将军。原文末字「車」作「軍」字义读。

**时段与依据** 确年未载；「將車」为仓内字形，四库以将军语通。

<a id="period-sgz027-b-1409-6"></a>

### 徐邈治理羌胡、把赏赐分给部众

[《三国志·徐胡二王传》仓内原文 L1409](../../拆分史书/三国志/卷027.md#l1409)

> 邈與羌、胡從事，不問小過；若犯大罪，先告部帥，使知，應死者乃斬以徇，是以信服畏威。賞賜皆散與將士，無入家者，妻子衣食不充；天子聞而嘉之，隨時供給其家。彈邪繩枉，州界肅清。

小过宽宥，重罪先告部族首领。本人不取军赏，家用不足获皇帝供给，州界肃清。

**时段与依据** 凉州长期治理、家居状况及赐给，均不落单年。

<a id="period-sgz027-b-1410-2"></a>

### 徐邈任司隶校尉、因公事去位

[《三国志·徐胡二王传》仓内原文 L1410](../../拆分史书/三国志/卷027.md#l1410)

> 遷爲司隷校尉，百僚敬憚之。公事去官。後爲光祿大夫，

朝官畏惧其执法，徐邈后去官，再任光禄大夫。

**时段与依据** 在240年回朝与248年擢司空之间，数职无具体年。

<a id="period-sgz027-b-1411-1"></a>

### 徐邈同郡韩观有治功

[《三国志·徐胡二王传》仓内原文 L1411](../../拆分史书/三国志/卷027.md#l1411)

> 邈同郡韓觀曼遊，有鑒識器幹，與邈齊名，而在孫禮、盧毓先，爲豫州刺史，甚有治功，卒官。

韩观字曼游，有识才，与徐邈齐名，先于孙礼、卢毓，历豫州刺史并卒官。

**时段与依据** 韩观任、卒没有纪年，裴注保杜恕荐表。

<a id="period-sgz027-b-1411-2"></a>

### 卢钦称徐邈清高宽厚，品行如一

[《三国志·徐胡二王传》仓内原文 L1411](../../拆分史书/三国志/卷027.md#l1411)

> 盧欽著書，稱邈曰：「徐公志高行絜，才博氣猛。其施之也，高而不狷，絜而不介，博而守約，猛而能寬。聖人以清爲難，而徐公之所易也。」

卢钦评徐邈志高而不狷、清洁而不偏、博学守约，刚猛能宽。

**时段与依据** 卢钦著书及评论确年不见。

<a id="period-sgz027-b-1411-3"></a>

### 卢钦解释徐邈早年被称通、后来被称介

[《三国志·徐胡二王传》仓内原文 L1411](../../拆分史书/三国志/卷027.md#l1411)

> 或問欽：「徐公當武帝之時，人以爲通，自在涼州及還京師，人以爲介，何也？」欽荅曰；「往者毛孝先、崔季珪等用事，貴清素之士，於時皆變易車服以求名高，而徐公不改其常，故人以爲通。比來天下奢靡，轉相倣效，而徐公雅尚自若，不與俗同，故前日之通，乃今日之介也。是世人之無常，而徐公之有常也。」

世尚清俭和世尚奢侈时徐邈都守常，所以同一行为获两种评议。

**时段与依据** 横跨曹操、凉州及返京三个阶段，记载的是后来的评语。

### 胡质传篇题

下文转入胡质事。

**时段与依据** 篇题无纪年。

<a id="period-sgz027-b-1413-1"></a>

### 胡质籍贯、早与蒋济朱绩著名

[《三国志·徐胡二王传》仓内原文 L1413](../../拆分史书/三国志/卷027.md#l1413)

> 胡質字文德，楚國壽春人也。少與蔣濟、朱績俱知名於江、淮間，仕州郡。

胡质字文德，楚国寿春人，少与蒋济、朱绩俱知名，曾为州郡吏。

**时段与依据** 早年无独立年。本传朱绩为淮南士人与东吴施绩非一事。

<a id="period-sgz027-b-1413-2"></a>

### 蒋济向曹操推荐胡质

[《三国志·徐胡二王传》仓内原文 L1413](../../拆分史书/三国志/卷027.md#l1413)

> 蔣濟爲別駕，使見太祖。太祖問曰：「胡通達，長者也，寧有子孫不？」濟曰：「有子曰質，規模大略不及於父，至於精良綜事過之。」

曹操问胡通达子嗣，蒋济说胡质规模稍逊父而善综理事务。

**时段与依据** 蒋济作别驾、曹操用胡质的谈话缺单年。

<a id="period-sgz027-b-1413-3"></a>

### 仓内夹入胡氏谱胡敏名号

[《三国志·徐胡二王传》仓内原文 L1413](../../拆分史书/三国志/卷027.md#l1413)

> ：通達名敏，以方正徵。〉

「通达名敏，以方正徵」是胡质父亲仕历。

**时段与依据** 四库本属裴注，原TXT保字；方正受征不详年。

<a id="period-sgz027-b-1413-4"></a>

### 胡质任顿丘令并平反馮谅案

[《三国志·徐胡二王传》仓内原文 L1413](../../拆分史书/三国志/卷027.md#l1413)

> 太祖即召質爲頓丘令。縣民郭政通於從妹，殺其夫程他，郡吏馮諒繫獄爲證。政與妹皆耐掠隱抵，諒不勝痛，自誣，當反其罪。質至官，察其情色，更詳其事，檢驗具服。

郭政与从妹通奸杀夫，刑讯使证人冯谅虚认。胡质核看神色、复验案情，罪犯供认。

**时段与依据** 本传未给任顿丘和此案年月。

<a id="period-sgz027-b-1414-1"></a>

### 胡质入丞相府，州府请为治中

[《三国志·徐胡二王传》仓内原文 L1414](../../拆分史书/三国志/卷027.md#l1414)

> 入爲丞相東曹議令史，州請爲治中。

由顿丘入丞相东曹，州府请胡质为治中。

**时段与依据** 曹操事务在丞相任内，胡质调官确年缺。

<a id="period-sgz027-b-1414-2"></a>

### 胡质劝张辽和武周复交

[《三国志·徐胡二王传》仓内原文 L1414](../../拆分史书/三国志/卷027.md#l1414)

> 將軍張遼與其護軍武周有隙。遼見刺史溫恢求請質，質辭以疾。遼出謂質曰：「僕委意於君，何以相辜如此？」質曰：「古人之交也，取多知其不貪，奔北知其不怯，聞流言而不信，故可終也。武伯南身爲雅士，往者將軍稱之不容於口，今以睚眥之恨，乃成嫌隙。況質才薄，豈能終好？是以不願也。」遼感言，復與周平。

张辽有嫌于武周，经温恢邀胡质，胡质以古人相知不信流言为说，婉拒并促使两位将领和好。

**时段与依据** 温恢为扬州刺史、张辽驻守为同期背景，未得此谈话日年。

<a id="period-sgz027-b-1415-1"></a>

### 胡质任曹操属吏，黄初间历常山与东莞

[《三国志·徐胡二王传》仓内原文 L1415](../../拆分史书/三国志/卷027.md#l1415)

> 太祖辟爲丞相屬。黃初中，徙吏部郎，爲常山太守，遷任東莞。

曹操征胡质为丞相属，黄初间转吏部郎、常山太守，继任东莞。

**时段与依据** 黄初年号范围220至226年，其内迁官名次有先后，确年未见。

<a id="period-sgz027-b-1415-2"></a>

### 胡质讯问邻少，查出杀卢显的李若

[《三国志·徐胡二王传》仓内原文 L1415](../../拆分史书/三国志/卷027.md#l1415)

> 士盧顯爲人所殺，質曰：「此士無讎而有少妻，所以死乎！」悉見其比居年少，書吏李若見問而色動，遂窮詰情狀。若即自首，罪人斯得。

胡质推测无仇而有少妻的卢显可能因邻里私情遇害，见李若神色变而深问，李若自首。

**时段与依据** 东莞任内案件，未给年。

<a id="period-sgz027-b-1415-3"></a>

### 胡质散军赏，治东莞九年

[《三国志·徐胡二王传》仓内原文 L1415](../../拆分史书/三国志/卷027.md#l1415)

> 每軍功賞賜，皆散之於衆，無入家者。在郡九年，吏民便安，將士用命。

军事赏赐散给部众，九年吏民安定、将士效命。

**时段与依据** 任郡九年是任期，传未另给上下年。

<a id="period-sgz027-b-1416-1"></a>

> 遷荊州刺史，加振威將軍，賜爵關內侯。

胡质受关内侯爵。

**时段与依据** 241年救樊以前已任荆州刺史，初授年月不详；237年亦已有参战记载。

<a id="period-sgz027-b-1416-3"></a>

### 胡质督青徐诸军，施屯田、开水渠

迁征东将军、假节，积谷、建东征台以耕守，疏通各郡渠道，沿海安定。

<a id="period-sgz027-b-1419-2"></a>

### 仓TXT夹入王柔、王泽和郭林宗的故事

### 王昶用知足之理训子侄

### 仓TXT夹入任嘏别传

[《三国志·徐胡二王传》仓内原文 L1423](../../拆分史书/三国志/卷027.md#l1423)

> 曰：嘏，樂安博昌人。世爲著姓，夙智性成，故鄉人爲之語曰：「蔣氏翁，任氏童。」父旐，字子旟，以至行稱。漢末，黃巾賊起，天下飢荒，人民相食。寇到博昌，聞旐姓字，乃相謂曰：「宿聞任子旟，天下賢人也。今雖作賊，那可入其鄉邪？」遂相帥而去。由是聲聞遠近，州郡並招舉孝廉，歷酸棗、祝阿令。嘏八歲喪母，號泣不絕聲，自然之哀，同於成人，故幼以至性見稱。年十四始學，疑不再問，三年中誦五經，皆究其義，兼包群言，無不綜覽，於時學者號之神童。遂遇荒亂，家貧賣魚，會官稅魚，魚貴數倍，嘏取直如常。又與人共買生口，各雇八匹。後生口家來贖，時價直六十匹。共買者欲隨時價取贖，嘏自取本價八匹。共買者慙，亦還取本價。比居者擅耕嘏地數十畝種之，人以語嘏，嘏曰：「我自以借之耳。」耕者聞之，慙謝還地。及邑中爭訟，皆詣嘏質之，然後意厭。其子弟有不順者，父兄竊數之曰：「汝所行，豈可令任君知邪！」其禮教所化，率皆如此。會太祖創業，召海內至德，嘏應其舉，爲臨菑侯庶子、相國東曹屬、尚書郎。文帝時，爲黃門侍郎。每納忠言，輒手書懷本，自在禁省，歸書不封。帝嘉其淑慎，累遷東郡、趙郡、河東太守，所在化行，有遺風餘教。嘏爲人淳粹凱弟，虛己若不足，恭敬如有畏。其脩身履義，皆沈默潛行，不顯其美，故時人少得稱之。著書三十八篇，凡四萬餘言。嘏卒後，故吏東郡程威、趙國劉固、河東上官崇等，錄其事行及所著書奏之。詔下祕書，以貫群言。〉

此段记任嘏家世、幼年孝行、与乡人贸易和争讼、历官与著述。

**时段与依据** 对校属裴注#013，全文详该处的逐事归年，保留仓TXT原范围。

**时段与依据** 幼年亲属和科教事无年。

<a id="period-sgz027-b-1429-2"></a>

### 王基十七岁辞郡吏而赴琅邪游学

[《三国志·徐胡二王传》仓内原文 L1429](../../拆分史书/三国志/卷027.md#l1429)

> 年十七，郡召爲吏，非其好也，遂去，入琅邪界游學。

郡召任吏不是其志，王基离开，游学琅邪。

**时段与依据** 本传仅载十七岁，无出生年可据。

<a id="period-sgz027-b-1429-3"></a>

### 王基黄初时察孝廉，王凌留其青州

[《三国志·徐胡二王传》仓内原文 L1429](../../拆分史书/三国志/卷027.md#l1429)

> 黃初中，察孝廉，除郎中。是時青土初定，刺史王凌特表請基爲別駕，後召爲秘書郎，凌復請還。頃之，司徒王朗辟基，淩不遣。朗書劾州曰：「凡家臣之良，則升於公輔，公臣之良，則入於王職，是故古者侯伯有貢士之禮。今州取宿衞之臣，留秘閣之吏，所希聞也。」淩猶不遣。淩流稱青土，蓋亦由基恊和之輔也。

王基被察孝廉任郎中。王凌请他作青州别驾，朝廷召为秘书郎又让他回来。王朗劾州府私留朝官，王凌仍不放，后来青州政绩亦有所助。

**时段与依据** 黄初跨220至226，征调与王朗争人各无确年。

<a id="period-sgz027-b-1429-4"></a>

### 司马懿辟王基，朝廷擢中书侍郎

[《三国志·徐胡二王传》仓内原文 L1429](../../拆分史书/三国志/卷027.md#l1429)

> 大將軍司馬宣王辟基，未至，擢爲中書侍郎。

王基未到司马懿府，先被擢为中书侍郎。

**时段与依据** 司马懿称大将军及235年以前王基作谏时已中书侍郎，可作区间，非单年。

<a id="period-sgz027-b-1431-1"></a>

### 王基与王肃论经礼，后坐事免安平太守

[《三国志·徐胡二王传》仓内原文 L1431](../../拆分史书/三国志/卷027.md#l1431)

> 散騎常侍王肅著諸經傳解及論定朝儀，改易鄭玄舊說，而基據持玄義，常與抗衡。遷安平太守，公事去官。

王肃改动郑玄旧说，王基据郑学与其抗辩。以后出任安平太守，因公事去官。

**时段与依据** 多次争议，按曹魏明帝末或更前后次序，确年不见。

<a id="period-sgz027-b-1431-2"></a>

### 曹爽用王基为从事中郎，后任安丰太守

[《三国志·徐胡二王传》仓内原文 L1431](../../拆分史书/三国志/卷027.md#l1431)

> 大將軍曹爽請爲從事中郎，出爲安豐太守。郡接吳寇，爲政清嚴有威惠，明設防備，敵不敢犯。加討寇將軍。

王基立威惠并严备吴军，加讨寇将军。

**时段与依据** 239年曹爽辅政至247年王基已守安丰，实际初任无独立年份。

### 王基作时要论，因病奉召

[《三国志·徐胡二王传》仓内原文 L1431](../../拆分史书/三国志/卷027.md#l1431)

曹爽专权之时，王基著书针砭时务，因病召还，拟就任河南尹。

**时段与依据** 在曹爽执政期间，著书及除授年未见。

<a id="period-sgz027-b-1432-3"></a>

### 王基筑上昶城，徙江夏治所以逼夏口

[《三国志·徐胡二王传》仓内原文 L1432](../../拆分史书/三国志/卷027.md#l1432)

> 基又表城上昶，徙江夏治之，以偪夏口，由是賊不敢輕越江。明制度，整軍農，兼脩學校，南方稱之。

王基在当地整军屯田、立学校，吴军不敢轻渡。

**时段与依据** 在州任内一段治理，城工和迁治未有独立年。

<a id="period-sgz027-b-1432-4"></a>

### 王基请先备水军和仓粮，朝廷缓伐吴

[《三国志·徐胡二王传》仓内原文 L1432](../../拆分史书/三国志/卷027.md#l1432)

> 時朝廷議欲伐吳，詔基量進趣之宜。基對曰：「夫兵動而無功，則威名折於外，財用窮於內，故必全而後用也。若不資通川聚糧水戰之備，則雖積兵江內，無必渡之勢矣。今江陵有沮、漳二水，溉灌膏腴之田以千數。安陸左右，陂池沃衍。若水陸並農，以實軍資，然後引兵詣江陵、夷陵，分據夏口，順沮、漳，資水浮糓而下。賊知官兵有經乆之勢，則拒天誅者意沮，而向王化者益固。然後率合蠻夷以攻其內，精卒勁兵以討其外，則夏口以上必拔，而江外之郡不守。如此，吳、蜀之交絕，交絕而吳禽矣。不然，兵出之利，未可必矣。」於是遂止。

王基认为胜负不止于兵多，须通舟运、屯田储谷再分路用军，否则不可判断其利，朝廷止议。

**时段与依据** 和具体一次曹魏南征的关联缺明确年，不强并252年东兴。

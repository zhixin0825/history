### 徐邈传篇题

[《三国志·徐胡二王传》仓内原文 L1407](../../拆分史书/三国志/卷027.md#l1407)

下文转入徐邈事。

**时段与依据** 篇题无纪年。

<a id="period-sgz027-b-1408-1"></a>

### 徐邈表字与籍贯

[《三国志·徐胡二王传》仓内原文 L1408](../../拆分史书/三国志/卷027.md#l1408)

徐邈字景山，燕国蓟人。

**时段与依据** 本传无生年。

<a id="wei027-l5-1"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l5-1)** · [TXT L5](../../拆分史书/三国志/卷027.txt#L5)

> 徐邈字景山，燕國薊人也。

**釋讀與歸年** 徐邈字景山，燕國薊縣人。

<a id="period-sgz027-b-1408-2"></a>

### 曹操召徐邈入军府，徐邈历任奉高与东曹

[《三国志·徐胡二王传》仓内原文 L1408](../../拆分史书/三国志/卷027.md#l1408)

徐邈经征召为丞相军谋掾，试任奉高令，入东曹作议令史。

**时段与依据** 曹操204至207年平河北，丞相府建于208年，征召并转任的确年无载。

<a id="wei027-l5-2"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l5-2)** · [TXT L5](../../拆分史书/三国志/卷027.txt#L5)

> 太祖平河朔，召爲丞相軍謀掾，試守奉高令，入爲東曹議令史。

**釋讀與歸年** 曹操平定河北後，辟徐邈為丞相軍謀掾。徐邈試守奉高令，再入府為東曹議令史。曹操於208年任丞相，魏國於213年立，這幾次任職敘在213年任魏尚書郎之前，逐次年月未詳。

<a id="period-sgz027-b-1408-4"></a>

### 徐邈醉答「中圣人」，鲜于辅解释而免刑

[《三国志·徐胡二王传》仓内原文 L1408](../../拆分史书/三国志/卷027.md#l1408)

禁酒时徐邈醉了，称为中圣人。曹操闻而怒，鲜于辅说明以圣人称清酒、贤人称浊酒只是酒客惯语，徐邈得免刑。

**时段与依据** 事件在徐邈任尚书郎时间，停禁和赵达问话的确年无明文。

<a id="wei027-l5-4"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l5-4)** · [TXT L5](../../拆分史书/三国志/卷027.txt#L5)

> 時科禁酒，而邈私飲至於沈醉。校事趙達問以曹事，邈曰：「中聖人。」達白之太祖，太祖甚怒。度遼將軍鮮于輔進曰：「平日醉客謂酒清者爲聖人，濁者爲賢人，邈性脩慎，偶醉言耳。」竟坐得免刑。

**釋讀與歸年** 禁酒時徐邈醉稱「中聖人」，趙達告於曹操。鮮于輔解釋酒客稱清酒為聖人、濁酒為賢人，為徐邈解圍。此事接魏國初建任官之後，確日不載。

<a id="period-sgz027-b-1408-5"></a>

### 徐邈历任陇西、南安

[《三国志·徐胡二王传》仓内原文 L1408](../../拆分史书/三国志/卷027.md#l1408)

徐邈领陇西太守，后转南安。

**时段与依据** 叙于曹操末年至曹丕登基前，未记各年。

<a id="wei027-l5-5"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l5-5)** · [TXT L5](../../拆分史书/三国志/卷027.txt#L5)

> 後領隴西太守，轉爲南安。

**釋讀與歸年** 徐邈後領隴西太守，再轉南安。任職年月未載。

<a id="period-sgz027-b-1408-6"></a>

### 曹丕在位时徐邈历数郡及典农

[《三国志·徐胡二王传》仓内原文 L1408](../../拆分史书/三国志/卷027.md#l1408)

徐邈历谯相、平阳安平太守、颍川典农中郎将，受爵关内侯。

**时段与依据** 220年曹丕践阼给下限。历官为多年总写，没有具体受爵年。

<a id="wei027-l5-6"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l5-6)** · [TXT L5](../../拆分史书/三国志/卷027.txt#L5)

> 文帝踐阼，歷譙相，平陽、安平太守，潁川典農中郎將，所在著稱，賜爵關內侯。

**釋讀與歸年** 曹丕即位後，徐邈歷任譙相、平陽與安平太守、潁川典農中郎將，屢有治績，賜關內侯。傳以黃初為範圍，各任免與封爵的年月未詳。

<a id="period-sgz027-b-1408-7"></a>

### 曹丕到许昌询徐邈饮酒，后来任军师

[《三国志·徐胡二王传》仓内原文 L1408](../../拆分史书/三国志/卷027.md#l1408)

曹丕问还会否「中圣人」，徐邈借子反、御叔和宿瘤女答以自己因酒见知，皇帝笑答，随后徐邈迁抚军大将军军师。

**时段与依据** 黄初期间曹丕数幸许昌，抚军大将军一职到225年已有司马懿，本段缺明确到任日。

<a id="wei027-l5-7"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l5-7)** · [TXT L5](../../拆分史书/三国志/卷027.txt#L5)

> 車駕幸許昌，問邈曰：「頗復中聖人不？」邈對曰：「昔子反斃於穀陽，御叔罰於飲酒，臣嗜同二子，不能自懲，時復中之。然宿瘤以醜見傳，而臣以醉見識。」帝大笑，顧左右曰：「名不虛立。」遷撫軍大將軍軍師。

**釋讀與歸年** 曹丕至許昌，又問徐邈是否曾「中聖人」。徐邈舉子反、御叔飲酒與宿瘤女故事作答，曹丕大笑。其後徐邈遷撫軍大將軍軍師。[《文帝紀》](../../拆分史书/三国志/卷002.txt)屢記曹丕幸許昌，無從指定哪一次。

<a id="period-sgz027-b-1409-3"></a>

### 徐邈修盐池、兴水田并接济军民

[《三国志·徐胡二王传》仓内原文 L1409](../../拆分史书/三国志/卷027.md#l1409)

河西缺粮，修武威酒泉盐池，以盐收粮，开田募佃，仓廪充实；用军用之余购买金帛犬马，供给内地。

**时段与依据** 凉州任内多年治理，无单年。

<a id="wei027-l7-3"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l7-3)** · [TXT L7](../../拆分史书/三国志/卷027.txt#L7)

> 河右少雨，常苦乏糓，邈上脩武威、酒泉鹽池以收虜糓，又廣開水田，募貧民佃之，家家豐足，倉庫盈溢。乃支度州界軍用之餘，以市金帛犬馬，通供中國之費。

**釋讀與歸年** 徐邈在涼州修武威、酒泉鹽池，以鹽易糧，又興修水田、招貧民耕作；結餘軍需用來購置金帛、犬馬，供給內地。這是涼州任內的累年施政，[《通鑑》](../../史书/025-资治通鉴/KR2b0007_071.txt#L110-L114)在228年受任後概述其農政。

<a id="period-sgz027-b-1409-4"></a>

### 徐邈收兵杖、兴教化并通西域

[《三国志·徐胡二王传》仓内原文 L1409](../../拆分史书/三国志/卷027.md#l1409)

逐步收民间私兵器，倡仁义学校，禁厚葬、淫祀，贬恶进善；本传归功于徐邈使西域贸易和来贡恢复。

**时段与依据** 分期施行及诸国入贡总述，不以某次使者代全部。

<a id="wei027-l7-4"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l7-4)** · [TXT L7](../../拆分史书/三国志/卷027.txt#L7)

> 以漸收斂民間私杖，藏之府庫。然後率以仁義，立學明訓，禁厚葬，斷淫祀，進善黜惡，風化大行，百姓歸心焉。西域流通，荒戎入貢，皆邈勳也。

**釋讀與歸年** 徐邈收儲民間兵仗，立學、禁厚葬與淫祀、表彰善行。史傳也將西域交通與諸部進貢歸功於他。這是河西任內的累年施政，並無各項始年。

<a id="period-sgz027-b-1409-5"></a>

### 徐邈破叛羌柯吾进封都亭侯

[《三国志·徐胡二王传》仓内原文 L1409](../../拆分史书/三国志/卷027.md#l1409)

战功使其受邑三百户、加建威将军。原文末字「車」作「軍」字义读。

**时段与依据** 确年未载；「將車」为仓内字形，四库以将军语通。

<a id="wei027-l7-5"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l7-5)** · [TXT L7](../../拆分史书/三国志/卷027.txt#L7)

> 討叛羌柯吾有功，封都亭侯，邑三百戶，加建威將車。

**釋讀與歸年** 徐邈因討柯吾有功，封都亭侯，食邑三百戶，加建威將軍。出兵與授封的確年待考；[《明帝紀》](../../拆分史书/三国志/卷003.txt#L127)景初二年另記燒當羌芒中、注詣等反，名字不同，不能據此將柯吾也定為同年。底本官名「建威將車」照錄。

<a id="period-sgz027-b-1409-6"></a>

### 徐邈治理羌胡、把赏赐分给部众

[《三国志·徐胡二王传》仓内原文 L1409](../../拆分史书/三国志/卷027.md#l1409)

小过宽宥，重罪先告部族首领。本人不取军赏，家用不足获皇帝供给，州界肃清。

**时段与依据** 凉州长期治理、家居状况及赐给，均不落单年。

<a id="wei027-l7-6"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l7-6)** · [TXT L7](../../拆分史书/三国志/卷027.txt#L7)

> 邈與羌、胡從事，不問小過；若犯大罪，先告部帥，使知，應死者乃斬以徇，是以信服畏威。賞賜皆散與將士，無入家者，妻子衣食不充；天子聞而嘉之，隨時供給其家。彈邪繩枉，州界肅清。

**釋讀與歸年** 徐邈對羌胡小過從寬，重罪先曉諭部帥再處置；所得賞賜都分給將士，家中常困乏，朝廷因而不時資助家室。這是涼州任內概述，《通鑑》隨228年任命敘政，未說各事同在當年。

<a id="period-sgz027-b-1410-2"></a>

### 徐邈任司隶校尉、因公事去位

[《三国志·徐胡二王传》仓内原文 L1410](../../拆分史书/三国志/卷027.md#l1410)

朝官畏惧其执法，徐邈后去官，再任光禄大夫。

**时段与依据** 在240年回朝与248年擢司空之间，数职无具体年。

<a id="wei027-l9-2"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l9-2)** · [TXT L9](../../拆分史书/三国志/卷027.txt#L9)

> 遷爲司隷校尉，百僚敬憚之。公事去官。後爲光祿大夫，

**釋讀與歸年** 徐邈遷司隷校尉，百官敬畏，因公事去官，後起為光祿大夫。遷校尉、免官與再起的年月未載。

<a id="period-sgz027-b-1411-1"></a>

### 徐邈同郡韩观有治功

[《三国志·徐胡二王传》仓内原文 L1411](../../拆分史书/三国志/卷027.md#l1411)

韩观字曼游，有识才，与徐邈齐名，先于孙礼、卢毓，历豫州刺史并卒官。

**时段与依据** 韩观任、卒没有纪年，裴注保杜恕荐表。

<a id="wei027-l11-1"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l11-1)** · [TXT L11](../../拆分史书/三国志/卷027.txt#L11)

> 邈同郡韓觀曼遊，有鑒識器幹，與邈齊名，而在孫禮、盧毓先，爲豫州刺史，甚有治功，卒官。

**釋讀與歸年** 徐邈同郡韓觀字曼遊，有鑒識和辦事才能，以政績著稱，卒於豫州刺史任。此句以孫禮、盧毓為仕序參照，沒有確年；「而在孫禮、盧毓先」接齊名而說，未必指三人先後同任豫州刺史。

<a id="period-sgz027-b-1411-2"></a>

### 卢钦称徐邈清高宽厚，品行如一

[《三国志·徐胡二王传》仓内原文 L1411](../../拆分史书/三国志/卷027.md#l1411)

卢钦评徐邈志高而不狷、清洁而不偏、博学守约，刚猛能宽。

**时段与依据** 卢钦著书及评论确年不见。

<a id="wei027-l13-1"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l13-1)** · [TXT L13](../../拆分史书/三国志/卷027.txt#L13)

> 盧欽著書，稱邈曰：「徐公志高行絜，才博氣猛。其施之也，高而不狷，絜而不介，博而守約，猛而能寬。聖人以清爲難，而徐公之所易也。」

**釋讀與歸年** 盧欽著書稱徐邈有才而守約，清而不狷，剛猛而有寬厚的一面。這是盧欽總評，未記寫作時間。

<a id="period-sgz027-b-1411-3"></a>

### 卢钦解释徐邈早年被称通、后来被称介

[《三国志·徐胡二王传》仓内原文 L1411](../../拆分史书/三国志/卷027.md#l1411)

世尚清俭和世尚奢侈时徐邈都守常，所以同一行为获两种评议。

**时段与依据** 横跨曹操、凉州及返京三个阶段，记载的是后来的评语。

<a id="wei027-l13-2"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l13-2)** · [TXT L13](../../拆分史书/三国志/卷027.txt#L13)

> 或問欽：「徐公當武帝之時，人以爲通，自在涼州及還京師，人以爲介，何也？」欽荅曰；「往者毛孝先、崔季珪等用事，貴清素之士，于時皆變易車服以求名高，而徐公不改其常，故人以爲通。比來天下奢靡，轉相倣效，而徐公雅尚自若，不與俗同，故前日之通，乃今日之介也。是世人之無常，而徐公之有常也。」

**釋讀與歸年** 有人問同一徐邈何以先被看作通達、後被看作耿介。盧欽答：毛玠、崔琰推重簡樸時，眾人改其車服迎合，徐邈仍一如平常；世俗轉向奢靡後，他也未改，變的是時風。此為後日回顧，問答未見確年。

<a id="period-sgz027-b-1413-1"></a>

### 胡质籍贯、早与蒋济朱绩著名

[《三国志·徐胡二王传》仓内原文 L1413](../../拆分史书/三国志/卷027.md#l1413)

胡质字文德，楚国寿春人，少与蒋济、朱绩俱知名，曾为州郡吏。

**时段与依据** 早年无独立年。本传朱绩为淮南士人与东吴施绩非一事。

<a id="wei027-l17-1"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l17-1)** · [TXT L17](../../拆分史书/三国志/卷027.txt#L17)

> 胡質字文德，楚國壽春人也。少與蔣濟、朱績俱知名於江、淮間，仕州郡。

**釋讀與歸年** 胡質字文德，楚國壽春人。少與蔣濟、朱績齊名於江淮，先仕州郡。朱績為同郡人名；原傳未繫始仕年月。

<a id="period-sgz027-b-1413-2"></a>

### 蒋济向曹操推荐胡质

[《三国志·徐胡二王传》仓内原文 L1413](../../拆分史书/三国志/卷027.md#l1413)

曹操问胡通达子嗣，蒋济说胡质规模稍逊父而善综理事务。

> 其爲兄子及子作名字，皆依謙實，以見其意，故兄子默字處靜，沈字處道，其子渾字玄冲，深字道冲。遂書戒之曰：
>
> 夫人爲子之道，莫大於寶身全行，以顯父母。此三者人知其善，而或危身破家，陷於滅亡之禍者，何也？由所祖習非其道也。夫孝敬仁義，百行之首，行之而立，身之本也。孝敬則宗族安之，仁義則鄉黨重之，此行成於內，名著於外者矣。人若不篤於至行，而背本逐末，以陷浮華焉，以成朋黨焉；浮華則有虛偽之累，朋黨則有彼此之患。此二者之戒，昭然著明，而循覆車滋衆，逐末彌甚，皆由惑當時之譽，昧目前之利故也。夫富貴聲名，人情所樂，而君子或得而不處，何也？惡不由其道耳。患人知進而不知退，知欲而不知足，故有困辱之累，悔吝之咨。語曰：「如不知足，則失所欲。」故知足之足常足矣。覽往事之成敗，察將來之吉凶，未有干名要利，欲而不厭，而能保世持家，永全福祿者也。欲使汝曹立身行己，遵儒者之教，履道家之言，故以玄默冲虛爲名，欲使汝曹顧名思義，不敢違越也。古者盤杅有銘，几杖有誡，俯仰察焉，用無過行；況在己名，可不戒之哉！夫物速成則疾亡，晚就則善終。朝華之草，夕而零落；松栢之茂，隆寒不衰。是以大雅君子惡速成，戒闕黨也。若范匄對秦客而武子擊之折其委笄，惡其掩人也。
>
> **〔裴注〕**
> 國語曰：范文子暮退於朝，武子曰：「何暮也？」對曰：「有秦客廋辭於朝，大夫莫之能對也，吾知三焉。」武子怒曰：「大夫非不能也，讓父兄也。尔童子而三掩人於朝，吾不在，晉國亡無日也。」擊之以杖，折其委笄。臣松之案：對秦客者，范燮也。此云范匄，蓋誤也。
>
> **〔正文續〕**
> 夫人有善鮮不自伐，有能者寡不自矜；伐則掩人，矜則陵人。掩人者人亦掩之，陵人者人亦陵之。故三郤爲戮於晉，王叔負罪於周，不惟矜善自伐好爭之咎乎？故君子不自稱，非以讓人，惡其蓋人也。夫能屈以爲伸，讓以爲得，弱以爲彊，鮮不遂矣。夫毀譽，愛惡之原而禍福之機也，是以聖人慎之。孔子曰：「吾之於人，誰毀誰譽；如有所譽，必有所試。」又曰：「子貢方人。賜也賢乎哉，我則不暇。」以聖人之德，猶尚如此，況庸庸之徒而輕毀譽哉？
>
> 昔伏波將軍馬援戒其兄子，言：「聞人之惡，當如聞父母之名；耳可得而聞，口不可得而言也。」斯戒至矣。
>
> **〔裴注〕**
> 臣松之以爲援之此誡，可謂切至之言，不刊之訓也。凡道人過失，蓋謂居室之愆，人未之知，則由己而發者也。若乃行事，得失已暴於世，因其善惡，即以爲誡，方之於彼，則有愈焉。然援誡稱龍伯高之美，言杜季良之惡，致使事徹時主，季良以敗。言之傷人，孰大於此？與其所誡，自相違伐。
>
> **〔正文續〕**
> 人或毀己，當退而求之於身。若己有可毀之行，則彼言當矣；若己無可毀之行，則彼言妄矣。當則無怨於彼，妄則無害於身，又何反報焉？且聞人毀己而忿者，惡醜聲之加人也，人報者滋甚，不如默而自脩己也。諺曰：「救寒莫如重裘，止謗莫如自脩。」斯言信矣。若與是非之士，凶險之人，近猶不可，況與對校乎？其害深矣。夫虛偽之人，言不根道，行不顧言，其爲浮淺較可識別；而世人惑焉，猶不檢之以言行也。近濟陰魏諷、山陽曹偉皆以傾邪敗沒，熒惑當世，挾持姦慝，驅動後生。雖刑於鈇鉞，大爲烱戒，然所汙染，固以衆矣。可不慎與！
>
> **〔裴注〕**
> 世語曰：黃初中，孫權通章表。偉以白衣登江上，與權交書求賂，欲以交結京師，故誅之。
>
> **〔正文續〕**
> 若夫山林之士，夷、叔之倫，甘長飢於首陽，安赴火於緜山，雖可以激貪勵俗，然聖人不可爲，吾亦不願也。今汝先人世有冠冕，惟仁義爲名，守慎爲稱，孝悌於閨門，務學於師友。吾與時人從事，雖出處不同，然各有所取。頴川郭伯益，好尚通達，敏而有知。其爲人弘曠不足，輕貴有餘；得其人重之如山，不得其人忽之如草。吾以所知親之昵之，不願兒子爲之。
>
> **〔裴注〕**
> 伯益名弈，郭嘉之子。
>
> **〔正文續〕**
> 北海徐偉長，不治名高，不求苟得，澹然自守，惟道是務。其有所是非，則託古人以見其意，當時無所褒貶。吾敬之重之，願兒子師之。東平劉公幹，博學有高才，誠節有大意，然性行不均，少所拘忌，得失足以相補。吾愛之重之，不願兒子慕之。
>
> **〔裴注〕**
> 臣松之以爲文舒復擬則文淵，顯言人之失。魏諷、曹偉，事陷惡逆，著以爲誡，差無可尤。至若郭伯益、劉公幹，雖其人皆往，善惡有定；然旣交之於昔，不宜復毀之於今，而乃形于翰墨，永傳後葉，於舊交則違久要之義，於子孫則揚人前世之惡。於夫鄙懷，深所不取。善乎東方之誡子也，以首陽爲拙，柳下爲工，寄旨古人，無傷當時。方之馬、王，不亦遠哉！
>
> **〔正文續〕**
> 樂安任昭先，淳粹履道，內敏外恕，推遜恭讓，處不避洿，怯而義勇，在朝忘身。吾友之善之，願兒子遵之。
>
> **〔裴注〕**
> 昭先名嘏。別傳曰：嘏，樂安博昌人。世爲著姓，夙智性成，故鄉人爲之語曰：「蔣氏翁，任氏童。」父旐，字子旟，以至行稱。漢末，黃巾賊起，天下飢荒，人民相食。寇到博昌，聞旐姓字，乃相謂曰：「宿聞任子旟，天下賢人也。今雖作賊，那可入其鄉邪？」遂相帥而去。由是聲聞遠近，州郡並招舉孝廉，歷酸棗、祝阿令。嘏八歲喪母，號泣不絕聲，自然之哀，同於成人，故幼以至性見稱。年十四始學，疑不再問，三年中誦五經，皆究其義，兼包群言，無不綜覽，於時學者號之神童。遂遇荒亂，家貧賣魚，會官稅魚，魚貴數倍，嘏取直如常。又與人共買生口，各雇八匹。後生口家來贖，時價直六十匹。共買者欲隨時價取贖，嘏自取本價八匹。共買者慙，亦還取本價。比居者擅耕嘏地數十畝種之，人以語嘏，嘏曰：「我自以借之耳。」耕者聞之，慙謝還地。及邑中爭訟，皆詣嘏質之，然後意厭。其子弟有不順者，父兄竊數之曰：「汝所行，豈可令任君知邪！」其禮教所化，率皆如此。會太祖創業，召海內至德，嘏應其舉，爲臨菑侯庶子、相國東曹屬、尚書郎。文帝時，爲黃門侍郎。每納忠言，輒手書懷本，自在禁省，歸書不封。帝嘉其淑慎，累遷東郡、趙郡、河東太守，所在化行，有遺風餘教。嘏爲人淳粹凱弟，虛己若不足，恭敬如有畏。其脩身履義，皆沈默潛行，不顯其美，故時人少得稱之。著書三十八篇，凡四萬餘言。嘏卒後，故吏東郡程威、趙國劉固、河東上官崇等，錄其事行及所著書奏之。詔下祕書，以貫群言。
>
> **〔正文續〕**
> 若引而伸之，觸類而長之，汝其庶幾舉一隅耳。及其用財先九族，其施舍務周急，其出入存故老，其論議貴無貶，其進仕尚忠節，其取人務實道，其處勢戒驕淫，其貧賤慎無戚，其進退念合宜，其行事加九思，如此而已。吾復何憂哉？

**釋讀與歸年** 王昶按謙退篤實為子侄命名，寫信勸戒。以下全文連原有裴注，撰書確年未載。[《資治通鑑》卷七十三](../../史书/025-资治通鉴/KR2b0007_073.txt#L293-L316)節引於236年王昶被舉後，未明言寫於本年。

**釋讀與歸年** 以孝敬仁義為立身根本，戒浮華朋黨、求名無厭，用命名勉後人顧名思義，再以草木與范氏朝見譬戒速成。

**釋讀與歸年** 裴注引《國語》范文子以答秦客自矜而受責，指出戒書作范匄有誤，應為范燮。古事隨本信原位。

**釋讀與歸年** 以晉三郤、周王叔為例戒自矜，又引孔子、子貢之語，勸慎加毀譽。

**釋讀與歸年** 王昶推許馬援不傳人短的家戒。

**釋讀與歸年** 裴松之肯定不播人所未聞的過失，也說已公開的成敗可供鑒戒；指出馬援稱龍伯高而批杜季良，結果使杜獲禍，與原訓有牴牾。

**釋讀與歸年** 王昶教子侄遇毀謗應先自省，勿爭辯報復，並引魏諷、曹偉兩人為戒。魏諷案另見219年，兩案均是戒書引例。

**釋讀與歸年** 《世語》稱曹偉黃初間私通孫權、求賂以結交京師，因而被誅。黃初是時限，故事附王昶用典。

**釋讀與歸年** 王昶說不求子侄效首陽、綿山隱者的決絕；勸守家風，評郭伯益通達而有取捨過甚的一面。

**釋讀與歸年** 裴注指出郭伯益名弈，是郭嘉之子。隨原信相應字句。

**釋讀與歸年** 王昶推許徐幹淡泊自守，盼後輩效法；肯定劉楨才學和志氣，但以少拘忌為戒。

**釋讀與歸年** 裴松之比對王昶與馬援兩篇戒書，肯定以魏諷、曹偉為戒，反對把郭奕、劉楨舊友的不足傳給後世；轉以東方朔託古言志為可取。

**釋讀與歸年** 王昶以任嘏謙讓無私、臨義能勇作後人典範。

**釋讀與歸年** 裴注所引《別傳》詳任嘏家世。其父任旐因德行使黃巾不入鄉，後歷酸棗及祝阿令；任嘏少孤而博學，荒亂中守商信、調解鄉里，後仕曹操、曹丕，歷三郡太守，死後故吏上其事行及著述。黃巾到博昌、任嘏卒與諸任年月未詳，全文附原書所舉友人。

**釋讀與歸年** 王昶以周濟族親、敬故老、慎毀譽、重名實、戒驕淫與知進退等原則收束家訓。

**时段与依据** 和具体一次曹魏南征的关联缺明确年，不强并252年东兴。

<a id="wei027-l76-5"></a>

**[《三國志·徐胡二王傳》正文](../../拆分史书/三国志/卷027.md#edition-wei027-l76-5)** · [TXT L76](../../拆分史书/三国志/卷027.txt#L76)

> 時朝廷議欲伐吳，詔基量進趣之宜。基對曰：「夫兵動而無功，則威名折於外，財用窮於內，故必全而後用也。若不資通川聚糧水戰之備，則雖積兵江內，無必渡之勢矣。今江陵有沮、漳二水，溉灌膏腴之田以千數。安陸左右，陂池沃衍。若水陸並農，以實軍資，然後引兵詣江陵、夷陵，分據夏口，順沮、漳，資水浮糓而下。賊知官兵有經乆之勢，則拒天誅者意沮，而向王化者益固。然後率合蠻夷以攻其內，精卒勁兵以討其外，則夏口以上必拔，而江外之郡不守。如此，吳、蜀之交絕，交絕而吳禽矣。不然，兵出之利，未可必矣。」於是遂止。

**釋讀與歸年** 魏廷議伐吳，王基請先在江陵、安陸等地墾田備糧、整備水軍，再分取江陵、夷陵、夏口。此時施行方案未成熟，伐吳因議停止；具體是哪次廷議未明，全文待考。

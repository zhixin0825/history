### 辰韩分划争端与弓遵死

[《三国志·乌丸鲜卑东夷传》仓内原文 L1613](../../拆分史书/三国志/卷030.md#l1613)

吴林拟给乐浪划辖辰韩八国，译文发生歧异，引起攻带方崎离营；弓遵和刘茂出击，弓遵阵亡。

**时段与依据** 正始六年245弓遵还与刘茂伐濊，正始八年247王颀到官。常推246，未见确年，不与两年已载事合并。“遂灭韩”依原文理解为本次击灭交战者，不扩大到三韩均绝。

<a id="wei030-l91-5"></a>

**[《三國志·烏丸鮮卑東夷傳》正文](../../拆分史书/三国志/卷030.md#edition-wei030-l91-5)** · [TXT L91](../../拆分史书/三国志/卷030.txt#L91)

> 部從事吳林以樂浪本統韓國，分割辰韓八國以與樂浪，吏譯轉有異同，臣智激韓忿，攻帶方郡崎離營。時太守弓遵、樂浪太守劉茂興兵伐之，遵戰死，二郡遂滅韓。

**釋讀與歸年** 吳林欲將辰韓八國轉隸樂浪，譯傳出入而起爭端，韓人攻帶方崎離營。兩郡出兵，弓遵戰死。弓遵、劉茂也見正始六年（245）伐東濊，王頎至正始八年（247）任帶方太守，僅能約束弓遵末任的先後。戰韓與戰東濊各有起因，不能同定一年。《三國史記·百濟本紀》古爾王十三年（246）記百濟乘隙襲樂浪，郡守寫作「朔方大守王遵」，全條未載王遵戰死。舊說合兩書而繫246，只能存疑。[《齊王紀》](../../拆分史书/三国志/卷004.txt#L34)正始七年另記韓那奚等數十國率眾來降，也無明文可以指為崎離營同事。

### 马韩聚落、居所和葬法

[《三国志·乌丸鲜卑东夷传》仓内原文 L1614](../../拆分史书/三国志/卷030.md#l1614)

诸邑各有帅，控制有限，不行跪拜，草屋土室全家共住，厚葬用牛马。

**时段与依据** 长期风俗。

<a id="wei030-l93-1"></a>

**[《三國志·烏丸鮮卑東夷傳》正文](../../拆分史书/三国志/卷030.md#edition-wei030-l93-1)** · [TXT L93](../../拆分史书/三国志/卷030.txt#L93)

> 其俗少綱紀，國邑雖有主帥，邑落雜居，不能善相制御。無跪拜之禮。居處作草屋土室，形如冢，其戶在上，舉家共在中，無長幼男女之別。其葬有棺無槨，不知乘牛馬，牛馬盡於送死。

**釋讀與歸年** 馬韓邑落雜居，諸首領未能彼此統攝。原文又記土室、家人同居、棺而無槨及送喪用牛馬等。

重珠饰轻金绣，着布袍和革履，男子发型形似中原士兵。

**时段与依据** 风俗概述。

<a id="wei030-l93-2"></a>

**[《三國志·烏丸鮮卑東夷傳》正文](../../拆分史书/三国志/卷030.md#edition-wei030-l93-2)** · [TXT L93](../../拆分史书/三国志/卷030.txt#L93)

> 以瓔珠爲財寶，或以綴衣爲飾，或以縣頸垂耳，不以金銀錦繡爲珍。其人性彊勇，魁頭露紒，如炅兵，衣布袍，足履革蹻蹋。

**釋讀與歸年** 馬韓以瓔珠綴衣及作首飾，又記髮式、布袍與皮履。

<a id="wei030-l93-3"></a>

### 马韩五月和十月祭礼

[《三国志·乌丸鲜卑东夷传》仓内原文 L1614](../../拆分史书/三国志/卷030.md#l1614)

播种后和秋收后祭神，集体踏舞饮酒。

**时段与依据** 两项季节性礼仪。

<a id="wei030-l93-4"></a>

**[《三國志·烏丸鮮卑東夷傳》正文](../../拆分史书/三国志/卷030.md#edition-wei030-l93-4)** · [TXT L93](../../拆分史书/三国志/卷030.txt#L93)

> 常以五月下種訖，祭鬼神，群聚歌舞，飲酒晝夜無休。其舞，數十人俱起相隨，踏地低昂，手足相應，節奏有似鐸舞。十月農功畢，亦復如之。

**釋讀與歸年** 馬韓在五月下種後、十月收成後祭祀，聚飲歌舞，記的是每年節俗。

### 马韩天君、苏涂和避罪之所

[《三国志·乌丸鲜卑东夷传》仓内原文 L1614](../../拆分史书/三国志/卷030.md#l1614)

立天君主祭，各国另设苏涂悬铃鼓，逃亡者入内常获容纳，作者比附浮屠。

**时段与依据** 宗教制度及作者观察。

<a id="wei030-l93-5"></a>

**[《三國志·烏丸鮮卑東夷傳》正文](../../拆分史书/三国志/卷030.md#edition-wei030-l93-5)** · [TXT L93](../../拆分史书/三国志/卷030.txt#L93)

> 信鬼神，國邑各立一人主祭天神，名之天君。又諸國各有別邑。名之爲蘇塗。立大木，縣鈴鼓，事鬼神。諸亡逃至其中，皆不還之，好作賊。其立蘇塗之義，有似浮屠，而所行善惡有異。

**釋讀與歸年** 各邑立天君主祭，又設蘇塗，懸鈴鼓奉神，逃人至此未被交還。陳壽以他所理解的浮屠制度相比。

### 马韩郡边习俗和特产

[《三国志·乌丸鲜卑东夷传》仓内原文 L1614](../../拆分史书/三国志/卷030.md#l1614)

传称靠郡地区较习郡礼，远地不同，又述大栗、长尾鸡和文身。

**时段与依据** 地理及风俗。

<a id="wei030-l93-6"></a>

**[《三國志·烏丸鮮卑東夷傳》正文](../../拆分史书/三国志/卷030.md#edition-wei030-l93-6)** · [TXT L93](../../拆分史书/三国志/卷030.txt#L93)

**釋讀與歸年** 記近郡諸國和遠處的風俗差別，又載大栗、長尾雞及偶有文身等。

### 州胡岛民与马韩通市

[《三国志·乌丸鲜卑东夷传》仓内原文 L1614](../../拆分史书/三国志/卷030.md#l1614)

马韩西海岛上居民语言和衣服不同，能养牛猪，乘船往马韩互市。

**时段与依据** 风俗和贸易无单年；州胡地望有多说。

<a id="wei030-l93-7"></a>

**[《三國志·烏丸鮮卑東夷傳》正文](../../拆分史书/三国志/卷030.md#edition-wei030-l93-7)** · [TXT L93](../../拆分史书/三国志/卷030.txt#L93)

> 又有州胡在馬韓之西海中大島上，其人差短小，言語不與韓同，皆髠頭如鮮卑，但衣韋，好養牛及豬。其衣有上無下，略如裸勢。乘船往來，巿買韓中。

**釋讀與歸年** 馬韓西面海島州胡的居民語言有別，蓄養牛豕，乘船至韓地貿易。未將此地望等同到任何確定的現代地名。

### 辰韩地望及避秦来韩传说

[《三国志·乌丸鲜卑东夷传》仓内原文 L1615](../../拆分史书/三国志/卷030.md#l1615)

辰韩位于马韩东，长老称先人避秦役，马韩分地相容，各地有城栅。

**时段与依据** 长老的秦汉之际来源传说，无迁徙确年。

<a id="wei030-l97-1"></a>

**[《三國志·烏丸鮮卑東夷傳》正文](../../拆分史书/三国志/卷030.md#edition-wei030-l97-1)** · [TXT L97](../../拆分史书/三国志/卷030.txt#L97)

> 辰韓在馬韓之東，其耆老傳世，自言古之亡人避秦役來適韓國，馬韓割其東界地與之。有城柵。其言語不與馬韓同，名國爲邦，弓爲弧，賊爲寇，行酒爲行觴。相呼皆爲徒，有似秦人，非但燕、齊之名物也。名樂浪人爲阿殘；東方人名我爲阿，謂樂浪人本其殘餘人。今有名之爲秦韓者。始有六國，稍分爲十二國。

**釋讀與歸年** 辰韓在馬韓以東，耆老傳言先民為避秦役而來，受馬韓割地。陳壽列「邦」「弧」「行觴」等語，並載「秦韓」異稱、原有六國後分十二國。這是傳述的族源及語言、聚落記載，秦亡人數次遷來及析國均無確年。

### 辰王的所属与推选

[《三国志·乌丸鲜卑东夷传》仓内原文 L1616](../../拆分史书/三国志/卷030.md#l1616)

十二国属辰王，辰王需马韩人且代代相传，不能自行称王。

**时段与依据** 制度概述，与《魏略》下附说明互证。

<a id="wei030-l101-2"></a>

<a id="wei030-l102-1"></a>

**[《三國志·烏丸鮮卑東夷傳》](../../拆分史书/三国志/卷030.md#edition-wei030-l101-2)** · [TXT L101](../../拆分史书/三国志/卷030.txt#L101) · [TXT L102（裴注）](../../拆分史书/三国志/卷030.txt#L102)

> 其十二國屬辰王。辰王常用馬韓人作之，世世相繼。辰王不得自立爲王。
>
> **〔裴注〕**
> 魏略曰：明其爲流移之人，故爲馬韓所制。

**釋讀與歸年** 十二國屬辰王，王以馬韓人世襲，辰韓人不能自立為辰王。

**釋讀與歸年** 裴注引《魏略》，用辰韓先民流徙及馬韓授地的舊說解釋辰王由馬韓人擔任的制度。

**[《三國志·烏丸鮮卑東夷傳》裴注](../../拆分史书/三国志/卷030.md#edition-wei030-l5-3)** · [TXT L5](../../拆分史书/三国志/卷030.txt#L5)

> 貴少賤老，其性悍驁，怒則殺父兄，而終不害其母，以母有族類，父兄以己爲種，無復報者故也。常推募勇健能理決鬬訟相侵犯者爲大人，邑落各有小帥，不世繼也。數百千落自爲一部，大人有所召呼，刻木爲信，邑落傳行，無文字，而部衆莫敢違犯。氏姓無常，以大人健者名字爲姓。大人已下，各自畜牧治產，不相徭役。

**釋讀與歸年** 《魏書》述烏丸親屬觀念、爭訟、推選大人及邑落首領，刻木為信，名姓與畜產各有習俗。

### 乌丸婚聘、妇人及髡发

送牲畜聘礼，婿役妻家，平日常从妇人筹划；所记女子鬟饰及夫死后续嫁均是旧俗。

**时段与依据** 婚姻、服饰风俗。

<a id="wei030-l5-4"></a>

**[《三國志·烏丸鮮卑東夷傳》裴注](../../拆分史书/三国志/卷030.md#edition-wei030-l5-4)** · [TXT L5](../../拆分史书/三国志/卷030.txt#L5)

> 其嫁娶皆先私通，畧將女去，或半歲百日，然後遣媒人送馬牛羊以爲聘娶之禮。婿隨妻歸，見妻家無尊卑，旦起皆拜，而不自拜其父母。爲妻家僕役二年，妻家乃厚遣送女，居處財物，一出妻家。故其俗從婦人計，至戰鬪時，乃自決之。父子男女，相對蹲踞，悉髠頭以爲輕便。婦人至嫁時乃養髮，分爲髻，著句決，飾以金碧，猶中國有冠步搖也。父兄死，妻後母執嫂；若無執嫂者，則己子以親之次妻伯叔焉，死則歸其故夫。

**釋讀與歸年** 《魏書》連記烏丸婚聘、男子服役於妻家、男女髠頭與婦人髮飾、父兄死後的婚配制度。

以鸟兽物候和布谷声安排耕种，记谷物、酒、兵器、皮毡、艾灸及放血等。

**时段与依据** 物候、生产与医疗风俗。

<a id="wei030-l5-5"></a>

**[《三國志·烏丸鮮卑東夷傳》裴注](../../拆分史书/三国志/卷030.md#edition-wei030-l5-5)** · [TXT L5](../../拆分史书/三国志/卷030.txt#L5)

> 俗識鳥獸孕乳，時以四節，耕種常用布穀鳴爲候。地宜青穄、東牆，東牆似蓬草，實如葵子，至十月熟。能作白酒，而不知作麴糱。米常仰中國。大人能作弓矢鞌勒，鍛金鐵爲兵器，能刺韋作文繡，織縷氊𣮷。有病，知以艾灸，或燒石自熨，燒地卧上，或隨痛病處，以刀決脉出血，及祝天地山川之神，無鍼藥。

**釋讀與歸年** 《魏書》記依鳥獸物候耕種、青穄及東牆、作酒與仰給米糧，也記製作器具、家庭手工與傳統療病方式。

### 乌丸送葬、赤山及祭祀

[《三国志·乌丸鲜卑东夷传》裴注 001·6](../../拆分史书/三国志/卷030.md#pei-001-6)

以犬马、衣物焚送亡灵，令其归赤山，并祭天地星辰、山川和前代名领。

**时段与依据** 丧葬及信仰风俗。

<a id="wei030-l5-6"></a>

**[《三國志·烏丸鮮卑東夷傳》裴注](../../拆分史书/三国志/卷030.md#edition-wei030-l5-6)** · [TXT L5](../../拆分史书/三国志/卷030.txt#L5)

> 貴兵死，斂屍有棺，始死則哭，葬則歌舞相送。肥養犬，以采繩嬰牽，并取亡者所乘馬、衣物、生時服飾，皆燒以送之。特屬累犬，使護死者神靈歸乎赤山。赤山在遼東西北數千里，如中國人以死之魂神歸泰山也。至葬日，夜聚親舊員坐，牽犬馬歷位，或歌哭者，擲肉與之。使二人口誦呪文，使死者魂神徑至，歷嶮阻，勿令橫鬼遮護，達其赤山，然後殺犬馬衣物燒之。敬鬼神，祠天地日月星辰山川，及先大人有健名者，亦同祠以牛羊，祠畢皆燒之。飲食必先祭。

**釋讀與歸年** 《魏書》記烏丸哭喪、歌舞送葬、犬馬祭祀及死者魂歸赤山的觀念。

### 乌丸相报、赎罪与放逐

[《三国志·乌丸鲜卑东夷传》裴注 001·7](../../拆分史书/三国志/卷030.md#pei-001-7)

违令或盗窃不停者可处死，杀人由部落报复或交首领调判、以牲畜赎；亡叛者被放逐雍狂地。

**时段与依据** 刑罚制度及地理传闻。

<a id="wei030-l5-7"></a>

**[《三國志·烏丸鮮卑東夷傳》裴注](../../拆分史书/三国志/卷030.md#edition-wei030-l5-7)** · [TXT L5](../../拆分史书/三国志/卷030.txt#L5)

> 其約法，違大人言死，盜不止死。其相殘殺，令都落自相報，相報不止，詣大人平之，有罪者出其牛羊以贖死命，乃止。自殺其父兄無罪。其亡叛爲大人所捕者，諸邑落不肯受，皆逐使至雍狂地。地無山，有沙漠、流水、草木，多蝮虵，在丁令之西南，烏孫之東北，以窮困之。

<a id="wei030-l18-1"></a>

<a id="wei030-l18-2"></a>

### 檀石槐出生传闻

[《三国志·乌丸鲜卑东夷传》裴注 004·17](../../拆分史书/三国志/卷030.md#pei-004-17)

投鹿侯在匈奴军中，妻在家生子，以吞雹的故事解释受孕；家人遂收养。

**时段与依据** 出生传说；《后汉书·鲜卑传》只给光和间死、年四十五，不能把虚岁推数作确年。

<a id="wei030-l18-17"></a>

**[《三國志·烏丸鮮卑東夷傳》裴注](../../拆分史书/三国志/卷030.md#edition-wei030-l18-17)** · [TXT L18](../../拆分史书/三国志/卷030.txt#L18)

> 投鹿侯從匈奴軍三年，其妻在家，有子。投鹿侯歸，怪欲殺之。妻言：「嘗晝行聞雷震，仰天視而雹入其口，因吞之，遂姙身，十月而產，此子必有奇異，且長之。」投鹿侯固不信。妻乃語家，令收養焉，號檀石槐，長大勇健，智畧絕衆。

**釋讀與歸年** 《魏書》載投鹿侯妻吞雹生檀石槐的傳說及少年成長。出生確年無明文，卒年與享年又有推算差異。

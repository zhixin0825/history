<a id="period-sgz031-b-1629-1"></a>

### 刘焉出身与鲁恭王后裔

[《三国志·刘二牧传》仓内原文 L1629](../../sources/本地分卷/三国志/三国志-卷031.md#l1629)

> 劉焉字君郎，江夏竟陵人也，漢魯恭王之後裔，章帝元和中徙封竟陵，支庶家焉。

刘焉字君郎，江夏竟陵人，出自鲁恭王宗支。章帝元和间宗支徙封竟陵并居于此。

**时段与依据** 籍贯、世系与元和年段为合叙；元和84—87，未见同是某年。

<a id="period-sgz031-b-1630-1"></a>

### 刘焉早年任官及居阳城讲学

[《三国志·刘二牧传》仓内原文 L1630](../../sources/本地分卷/三国志/三国志-卷031.md#l1630)

> 焉少仕州郡，以宗室拜中郎，後以師祝公喪去官。 居陽城山，積學教授，舉賢良方正，闢司徒府，歷雒陽令、冀州刺史、南陽太守、宗正、太常。

刘焉由宗室拜中郎，为师祝公服丧离职，后讲学、举贤良方正，历任州郡与宗室礼官。

**时段与依据** 祝恬去世见160年。刘焉去官、讲学及各官不具各自年月，早晚依传。

<a id="period-sgz031-b-1631-1"></a>

### 郤俭在益州聚敛

[《三国志·刘二牧传》仓内原文 L1631](../../sources/本地分卷/三国志/三国志-卷031.md#l1631)

> 會益州刺史郤儉賦斂煩擾，謠言遠聞，

益州刺史郤俭横征聚敛，民怨传远。

**时段与依据** 上任和恶政开始时间未载，至188年任命刘焉收治前。

<a id="period-sgz031-b-1632-3"></a>

### 张鲁之母出入刘焉家

[《三国志·刘二牧传》仓内原文 L1632](../../sources/本地分卷/三国志/三国志-卷031.md#l1632)

> 張魯母始以鬼道，又有少容，常往來焉家，

张鲁母能施鬼道，常与刘焉家往来。

**时段与依据** 张鲁被派汉中之前的背景，不确定哪年开始。

<a id="period-sgz031-b-1633-2"></a>

### 刘焉诸子分居长安、益州

[《三国志·刘二牧传》仓内原文 L1633](../../sources/本地分卷/三国志/三国志-卷031.md#l1633)

刘范、刘诞、刘璋在长安任官，只有刘瑁随父在蜀。

**时段与依据** 在献帝长安时期，四人各获任年月未载。

<a id="period-sgz031-b-1636-1"></a>

### 刘璋与张鲁反目，任庞羲护巴西

[《三国志·刘二牧传》仓内原文 L1636](../../sources/本地分卷/三国志/三国志-卷031.md#l1636)

> 璋字季玉，既襲焉位，而張魯稍驕恣，不承順璋，璋殺魯母及弟，遂為讎敵。璋累遣龐羲等攻魯，〔數為〕所破。魯部曲多在巴西，故以羲為巴西太守，領兵禦魯。

刘璋继领益州后，张鲁失去节制，刘璋杀张鲁母和弟弟，数遣庞羲攻鲁未克。任庞羲为巴西太守。

**时段与依据** 继位在194，双方交恶及屡次交战无共同确年。

<a id="period-sgz031-b-1636-2"></a>

### 庞羲后来与刘璋失和

[《三国志·刘二牧传》仓内原文 L1636](../../sources/本地分卷/三国志/三国志-卷031.md#l1636)

> 後羲與璋情好攜隙，

庞羲与刘璋关系生隙。

**时段与依据** 本传只说“后”，攻鲁后、赵韙兵败前后未详具体年月。

<a id="period-sgz031-b-1637-2"></a>

### 刘瑁病故

[《三国志·刘二牧传》仓内原文 L1637](../../sources/本地分卷/三国志/三国志-卷031.md#l1637)

> 瑁狂疾物故。

刘瑁患病去世。

**时段与依据** 在授平寇将军后；传文无卒年。

<a id="period-sgz031-b-1637-5"></a>

### 刘璋派法正与刘备通好并送援兵

[《三国志·刘二牧传》仓内原文 L1637](../../sources/本地分卷/三国志/三国志-卷031.md#l1637)

> 璋皆然之，遣法正連好先主，尋又令正及孟達送兵數千助先主守禦，正遂還。

刘璋听从建议，派法正联络刘备，又派法正、孟达送兵数千。

**时段与依据** 事件在张松回蜀以后、法正于211出迎刘备之前，初使年月无载。

<a id="period-sgz031-b-1639-1"></a>

### 刘璋去世

[《三国志·刘二牧传》仓内原文 L1639](../../sources/本地分卷/三国志/三国志-卷031.md#l1639)

> 璋卒，

刘璋在受任益州牧之后去世。

**时段与依据** 《通鉴》在219年取荆州后说“未几”，不足决定卒年。与雍闓降吴分开。

<a id="period-sgz031-b-1639-3"></a>

### 孙权用刘阐接掌边界

[《三国志·刘二牧传》仓内原文 L1639](../../sources/本地分卷/三国志/三国志-卷031.md#l1639)

> 權復以璋子闡為益州刺史，處交、益界首。

孙权又任刘璋子刘阐为益州刺史，住交州、益州边界。

**时段与依据** 在刘璋去世和诸葛亮南征之间。未载任命年。

<a id="period-sgz031-b-1639-5"></a>

### 刘循娶庞羲女

[《三国志·刘二牧传》仓内原文 L1639](../../sources/本地分卷/三国志/三国志-卷031.md#l1639)

>  初，璋長子循妻，龐羲女也。

刘璋长子刘循娶庞羲女为妻。

**时段与依据** “初”作倒叙，婚期无载。

<a id="period-sgz031-b-1639-7"></a>

### 刘璋两子分居吴蜀

[《三国志·刘二牧传》仓内原文 L1639](../../sources/本地分卷/三国志/三国志-卷031.md#l1639)

> 是以璋二子之後，分在吳、蜀。

刘阐一支在吴、刘循一支在蜀。

**时段与依据** 前文多年的归结，不是独立某年事件。

<a id="period-sgz031-b-1640-1"></a>

### 陈寿论刘焉、刘璋与谶言

[《三国志·刘二牧传》仓内原文 L1640](../../sources/本地分卷/三国志/三国志-卷031.md#l1640)

> 評曰：昔魏豹聞許負之言則納薄姬於室，劉歆見圖讖之文則名字改易，終於不免其身，而慶鍾二主。此則神明不可虛要，天命不可妄冀，必然之驗也。而劉焉聞董扶之辭則心存益土，聽相者之言則求婚吳氏，遽造輿服，圖竊神器，其惑甚矣。璋才非人雄，而據土亂世，負乘致寇，自然之理，其見奪取，非不幸也。

陈寿用魏豹、刘歆比照刘焉相信天子气、私造车舆的做法，又论刘璋据蜀而失国。

**时段与依据** 史家评语跨时代。魏豹、刘歆是论证，刘焉造车和刘璋降城已据相应记事另系。

### 何进推荐董扶，朝廷征为侍中

[《三国志·刘二牧传》裴注 004·4](../../sources/摘录/三国志-卷031-刘二牧传裴注.md#pei-004-4)

> 大將軍何進表薦扶曰資游夏之徳述孔氏之風内懐焦董消復之術方今幷涼騷擾西戎蠢叛宜勑公車特詔待以異禮諮謀竒策於是靈帝徴扶即拜侍中在朝稱為儒宗甚見器重求為蜀郡屬國都尉扶出一嵗而靈帝崩天下大亂後去官年八十二卒于家始扶發辭抗論益部少雙故號曰致止言人莫能當所至而談止也

何进称董扶通经、熟悉政事谶候，朝廷征拜侍中。

**时段与依据** 何进任大将军在184—189；董扶至少在188年与刘焉商谈时已任侍中，未见单一日期。

### 诸葛亮与秦宓谈董扶

诸葛亮向秦宓询问董扶所长，秦宓称他能辨很细微的善恶。

**时段与依据** 秦宓死于226，诸葛亮称丞相始221，问答未记哪一年。

### 董卓拘刘焉诸子于郿坞

刘焉拒奉董卓征调，董卓把刘范兄弟三人锁在郿坞。

### 庞羲救刘璋诸子及受任巴西

《英雄记》说庞羲本与刘璋相好，帮他诸子脱难，获得巴西太守之任并专权。

### 东州兵的来源及与旧人的冲突

[《三国志·刘二牧传》裴注 012·1](../../sources/摘录/三国志-卷031-刘二牧传裴注.md#pei-012-1)

> 英雄記曰先是南陽三輔人流入益州數萬家收以為兵名曰東州兵璋性寛柔無威畧東州人侵暴舊民璋不能禁政令多闕益州頗怨

南阳、三辅人流入益州后被收为东州兵，侵暴旧民，刘璋无法制止。

**时段与依据** 是赵韙反叛之前的多年背景。

### 朝廷任牛亶为益州刺史并征刘璋未果

《汉献帝春秋》说朝廷听闻益州乱，任牛亶为刺史，召刘璋为卿，刘璋未赴。

**时段与依据** 附200—201年益州乱事之后，未明发诏确年。

**时段与依据** 词义，问答没有确年，不能以刘瑁卒年定注。

### 习凿齿评论曹操失去统一机会

[《三国志·刘二牧传》裴注 014·2](../../sources/摘录/三国志-卷031-刘二牧传裴注.md#pei-014-2)

> 習鑿齒曰昔齊桓一矜其功而叛者九國曹操暫自驕伐而天下三分皆勤之於數十年之内而棄之於俯仰之頃豈不惜哉是以君子勞謙日昃慮以下人功髙而居之以讓勢尊而守之以卑情近於物故雖貴而人不厭其重徳洽羣生故業廣而天下愈欣其慶夫然故能有其富貴保其功業隆顯當時傳福百世何驕矜之有哉君子是以知曹操之不能遂兼天下者也

习凿齿比较齐桓公及曹操，劝掌功势者用谦德，认为曹操自夸使人背离。

**时段与依据** 史评，无独立日期。

### 许负身份与汉初封爵异说

[《三国志·刘二牧传》裴注 019·1](../../sources/摘录/三国志-卷031-刘二牧传裴注.md#pei-019-1)

> 孔衍漢魏春秋曰許負河内温縣之婦人漢髙祖封為明雌亭侯臣松之以為今東人呼母為負衍以許負為婦人如為有似然漢髙祖時封皆列侯未有鄉亭之爵疑此封為不然

孔衍说许负为河内温县妇人，汉高祖封明雌亭侯。裴松之认为高祖时乡亭侯未见，爵号可疑。

<a id="period-sgz031-p-020-1"></a>

### 张璠评论刘璋与张松、法正

[《三国志·刘二牧传》裴注 020·1](../../sources/摘录/三国志-卷031-刘二牧传裴注.md#pei-020-1)

> 張璠曰劉璋愚弱而守善言斯亦宋㐮公徐偃王之徒未為無道之主也張松法正雖君臣之義不正然固己委名附質進不顯陳事勢若韓嵩劉光之説劉表退不告絶奔七若陳平韓信之去項羽而両端擕貳為謀不忠罪之次也

张璠说刘璋软弱但不是无道。张松、法正既委身事人，应明谏或告绝，不应暗中两属，遂引古人离主的行为相比较。

**时段与依据** 整段是对益州易主和臣下行为的史论，写作年代未具。

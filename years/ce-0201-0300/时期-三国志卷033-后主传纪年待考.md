## 引文与纪年

<a id="period-sgz033-b-1682-1"></a>

### 后主传篇题

[《三国志·后主传》仓内原文 L1682](../../sources/本地分卷/三国志/三国志-卷033.md#l1682)

> 後主 劉禪

本篇记蜀汉后主刘禅。

**时段与依据** 篇题无单一纪年。

<a id="period-sgz033-b-1683-1"></a>

### 刘禅名号与亲属

[《三国志·后主传》仓内原文 L1683](../../sources/本地分卷/三国志/三国志-卷033.md#l1683)

> 後主諱禪，字公嗣，先主子也。

刘禅字公嗣，是先主刘备之子。

**时段与依据** 名号与亲属是人物总述。

<a id="period-sgz033-b-1683-9"></a>

### 裴松之驳小沛失子和诸葛亮为太子太傅

[《三国志·后主传》仓内原文 L1683](../../sources/本地分卷/三国志/三国志-卷033.md#l1683)

> 而魚豢雲備敗於小沛，禪時年始生，及奔荊州，能識其父字玄德，計當五六歲。備敗於小沛時，建安五年也，至禪初立，首尾二十四年，禪應過二十矣。以事相驗，理不得然。此則《魏略》之妄說，乃至二百餘言，異也！又案諸書記及《諸葛亮集》，亮亦不為太子太傅。〉

裴松之比较《魏略》所述年龄与刘备败小沛到刘禅即位的年距，又查诸书记和诸葛亮文集，否定失散奇闻及太子太傅一职。

**时段与依据** 小沛败为200年，争点横跨200至223等年份，驳论本身无同时代年。全书TXT混入此注后半，参同卷第002条。

<a id="period-sgz033-b-1684-3"></a>

### 越巂夷王高定背蜀

[《三国志·后主传》仓内原文 L1684](../../sources/本地分卷/三国志/三国志-卷033.md#l1684)

> 越巂夷王高定亦背叛。

高定也叛离蜀汉，属于南中诸郡先后反蜀之一。

**时段与依据** 本传承“先是”无独立日月。《马忠传》亦概称先主薨后诸郡叛乱；高定终在225年南征中败。

<a id="period-sgz033-b-1725-5"></a>

### 蜀汉归降后刘禅尚未启程

[《三国志·后主传》仓内原文 L1725](../../sources/本地分卷/三国志/三国志-卷033.md#l1725)

> 資嚴未發，

刘禅一行行装准备后，仍未离成都。

**时段与依据** 句叙降后、次年邓艾被收前状态，跨263冬和264春，无独立日期。

<a id="period-sgz033-b-1730-1"></a>

### 陈寿论刘禅用人与政治变化

[《三国志·后主传》仓内原文 L1730](../../sources/本地分卷/三国志/三国志-卷033.md#l1730)

> 評曰：後主任賢相則為循理之君，惑閹堅則為昏暗之後，傳曰『素絲無常，唯所染之』，信矣哉！

陈寿认为刘禅任用贤相可以按理治理，受宦官迷惑便昏暗，以素丝染色为喻。

**时段与依据** 篇末总评，涉及诸葛亮和黄皓等不同时期。

<a id="period-sgz033-b-1730-3"></a>

### 陈寿评蜀国史官及记事制度

[《三国志·后主传》仓内原文 L1730](../../sources/本地分卷/三国志/三国志-卷033.md#l1730)

> 又國不置史，注記無官，是以行事多遺，災異靡書。諸葛亮雖達於為政，凡此之類，猶有未周焉。

陈寿说蜀的史职与注记制度不完备，因而行事、灾异多有遗失，将其列为诸葛亮治政缺处。

**时段与依据** 涵盖蜀汉政治制度，非个别任官年份。

<a id="period-sgz033-b-1730-4"></a>

### 陈寿评建兴十二年未改元、战争频繁但少赦

[《三国志·后主传》仓内原文 L1730](../../sources/本地分卷/三国志/三国志-卷033.md#l1730)

> 然經載十二而年名不易，軍旅屢興而赦不妄下，不亦卓乎！自亮沒後，茲制漸虧，優劣著矣。

陈寿赞诸葛亮辅政的建兴十二年长期用一个年号、用兵亦少轻下赦令，认为其卒后逐渐变易。

**时段与依据** 评论跨建兴年间和诸葛亮死后，参同卷第015条裴注的不同评价。

<a id="period-sgz033-p-002-3"></a>

### 《魏略》称张鲁验明刘禅身份并送还益州

[《三国志·后主传》裴注 002·3](../../sources/本地分卷/三国志/三国志-卷033.md#pei-002-3)

> 初禅與偹相失時識其父字玄徳比舍人有姓簡者及偹得益州而簡為將軍備遣簡到漢中舍都邸禅乃詣簡簡相檢訊事皆符驗簡喜以語張魯魯乃洗沐送詣益州備乃立以為太子

《魏略》说刘禅少时记得父字和简氏，刘备取得益州后派姓简的使者到汉中，认出刘禅，张鲁送其归蜀，刘备立为太子。

**时段与依据** 故事称在刘备得益州后、立太子前，部分又与张鲁建安二十年降曹相冲突。全段为异说，无确年。

<a id="period-sgz033-p-002-4"></a>

### 《魏略》说诸葛亮受托总内外政务

[《三国志·后主传》裴注 002·4](../../sources/本地分卷/三国志/三国志-卷033.md#pei-002-4)

> 初備以諸葛亮為太子太傅及禅立以亮為丞相委以諸事謂亮曰政由葛氏祭則寡人亮亦以禪未閑於政遂總内外

《魏略》称刘备先任诸葛亮为太子太傅，刘禅继位后以丞相委国政，说葛氏掌政、自己祭祀，诸葛亮遂总内外。

**时段与依据** 任丞相据本书《诸葛亮传》在刘备称帝时，太子太傅无同代依据；上文把不同时期交叙，声音依《魏略》记录。

<a id="period-sgz033-p-002-8"></a>

### 裴松之驳小沛失子和诸葛亮为太子太傅

[《三国志·后主传》裴注 002·8](../../sources/本地分卷/三国志/三国志-卷033.md#pei-002-8)

> 而魚豢云備敗扵小沛禪時年始生及奔荆州能識其父字玄徳計當五六嵗備則敗扵小沛時建安五年也至禪初立首尾二十四年禪應過三十矣以事相驗理不得然此則魏畧之妄説乃至二百餘言異也又案諸書記及諸葛亮集亮亦不為太子太傅

裴松之指鱼豢所云幼年、虚岁与200年小沛至223年即位的年距不合，并查书与集均无诸葛亮任太子太傅。

**时段与依据** 属编注者对几个年份和官位的互校。四库本末称过“三十”，整书TXT仓本称过“二十”，依来源分别保留，不以异数字为实龄。

<a id="period-sgz033-p-003-1"></a>

### 《魏氏春秋》记常房查朱褒与遭杀

[《三国志·后主传》裴注 003·1](../../sources/本地分卷/三国志/三国志-卷033.md#pei-003-1)

> 魏氏春秋曰初益州從事常房行部聞褒將有異志收其主簿按問殺之襃怒攻殺房誣以謀反諸葛亮誅房諸子徙其四弟於越巂欲以安之

常房行部时查朱褒的主簿并杀之，朱褒怒而杀常房，诬以谋反；注又称诸葛亮为安抚朱褒杀常房诸子、徙其弟。

**时段与依据** 在朱褒建兴元年夏公开叛乱前，常房遭杀与所谓处置家属无独立年次，末有裴松之驳斥。

<a id="period-sgz033-p-003-3"></a>

### 裴松之驳诸葛亮妄杀常房诸子之说

[《三国志·后主传》裴注 003·3](../../sources/本地分卷/三国志/三国志-卷033.md#pei-003-3)

> 臣松之案以為房為襃所誣執政所宜澄察安有妄殺不辜以悦奸慝斯殆妄矣

裴松之说常房为朱褒所诬，执政者应该查明，不应滥杀无辜以讨好奸恶，因而质疑《魏氏春秋》。

**时段与依据** 后代文本批评，无前代事件日期。

<a id="period-sgz033-p-004-1"></a>

### 李严所筑大城与巴郡故城

[《三国志·后主传》裴注 004·1](../../sources/本地分卷/三国志/三国志-卷033.md#pei-004-1)

> 今巴郡故城是

裴注以当时所称巴郡旧城就是李严所筑大城。

**时段与依据** 解释古迹，所指营建事件见226年；地名说明自身无确年。

### 斜谷之斜的反切释音

[《三国志·后主传》裴注 006·1](../../sources/本地分卷/三国志/三国志-卷033.md#pei-006-1)

> 余奢反

“余奢反”注斜谷之“斜”。

**时段与依据** 四库本此注紧接“曹真由斜”之后；只释音，所附战役见230年。

<a id="period-sgz033-p-008-1"></a>

### 湔县隶蜀郡及读音

[《三国志·后主传》裴注 008·1](../../sources/本地分卷/三国志/三国志-卷033.md#pei-008-1)

> 臣松之案湔縣名也屬蜀郡音翦

裴松之释湔为蜀郡县名，注明音“翦”。

**时段与依据** 附236年刘禅到县史事的地名解释，注语本身无时点。

<a id="period-sgz033-p-015-1"></a>

### 诸葛亮与刘备谈赦免，《华阳国志》说法

[《三国志·后主传》裴注 015·1](../../sources/本地分卷/三国志/三国志-卷033.md#pei-015-1)

> 華陽國志曰丞相亮時有言公惜赦者亮答曰治世以大徳不以小恵故匡衡吴漢不願為赦先帝亦言吾周旋陳元方鄭康成間每見啟告治亂之道悉矣曽不語赦也若劉景升季玉父子嵗嵗赦宥何益於治

诸葛亮答责其吝赦者，以匡衡和吴汉之例说明治理不靠小惠；又引刘备说陈纪、郑玄谈治乱时未以赦为法，刘表、刘璋年年赦也未曾有益。

**时段与依据** 统摄刘备和诸葛亮两阶段言论，无可核定的对白年月。

<a id="period-sgz033-p-015-2"></a>

### 裴松之称许慎赦，驳久不改元的评论

[《三国志·后主传》裴注 015·2](../../sources/本地分卷/三国志/三国志-卷033.md#pei-015-2)

> 臣松之以為赦不妄下誠為可稱至於年名不易猶所未逹案建武建安之號皆久而不改未聞前史以為美談經載十二盖何足云豈别有他意求之未至乎亮歿後延熙之號數盈二十兹制漸虧事又不然也

裴松之同意慎赦可称，但举建武、建安久未改元及蜀延熙二十年，指出沿用年号超过十二年不足为美，且与诸葛亮身后不久改元之论不合。

**时段与依据** 为裴松之驳陈寿的跨年史评；实际延熙238至257，景耀258开始，可由本传复核。

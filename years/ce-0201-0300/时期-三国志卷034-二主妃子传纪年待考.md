### 皇后部分篇题

[《三国志·二主妃子传》仓内原文 L1732](../../拆分史书/三国志/卷034.md#l1732)

从此记刘备和刘禅的皇后。

**时段与依据** 分部题，无事件年份。

<a id="period-sgz034-b-1733-1"></a>

### 甘氏的籍贯和后来称号

[《三国志·二主妃子传》仓内原文 L1733](../../拆分史书/三国志/卷034.md#l1733)

刘备的甘皇后是沛人；“皇后”是传称其后来的追尊。

**时段与依据** 身世总述，出生年月无载。

<a id="shu034-l5-1"></a>

**[《三國志·二主妃子傳》正文](../../拆分史书/三国志/卷034.md#edition-shu034-l5-1)** · [TXT L5](../../拆分史书/三国志/卷034.txt#L5)

> 先主甘皇后，沛人也。

**釋讀與歸年** 甘氏是沛人。「甘皇后」是依其身後追諡所稱。

<a id="period-sgz034-b-1733-2"></a>

### 刘备屯小沛时纳甘氏

[《三国志·二主妃子传》仓内原文 L1733](../../拆分史书/三国志/卷034.md#l1733)

甘氏在刘备活动于豫州、驻小沛时被纳为妾。

**时段与依据** 《先主传》先记陶谦表豫州刺史屯小沛，吕布据下邳后又屯小沛；甘氏入门究属何次，无独立日月。

<a id="shu034-l5-2"></a>

**[《三國志·二主妃子傳》正文](../../拆分史书/三国志/卷034.md#edition-shu034-l5-2)** · [TXT L5](../../拆分史书/三国志/卷034.txt#L5)

> 先主臨豫州，住小沛，納以爲妾。

**釋讀與歸年** 劉備領豫州、住小沛時納甘氏為妾。[《先主傳》](../../拆分史书/三国志/卷032.txt#L22)記194年陶謙表劉備為豫州刺史時屯小沛。[同傳](../../拆分史书/三国志/卷032.txt#L26-L32)記196年與呂布和後再住小沛，此後又受曹操表為豫州牧。本句無明年，無法定是哪次住小沛時。

<a id="period-sgz034-b-1733-3"></a>

### 甘氏长期代理家事

[《三国志·二主妃子传》仓内原文 L1733](../../拆分史书/三国志/卷034.md#l1733)

刘备屡失嫡妻，甘氏常掌内事。

**时段与依据** 属一段家事的概述，未载嫡室各人去世年。

<a id="shu034-l5-3"></a>

**[《三國志·二主妃子傳》正文](../../拆分史书/三国志/卷034.md#edition-shu034-l5-3)** · [TXT L5](../../拆分史书/三国志/卷034.txt#L5)

> 先主數喪嫡室，常攝內事。

**釋讀與歸年** 劉備屢失嫡室，甘氏常理家事，為一段時期的概述。

<a id="period-sgz034-b-1733-6"></a>

### 甘氏去世并初葬南郡

[《三国志·二主妃子传》仓内原文 L1733](../../拆分史书/三国志/卷034.md#l1733)

甘氏后来去世，初葬南郡。

**时段与依据** 本传只知在长坂后至222年追谥前；无法据刘备续婚推精确卒年。

<a id="shu034-l5-6"></a>

**[《三國志·二主妃子傳》正文](../../拆分史书/三国志/卷034.md#edition-shu034-l5-6)** · [TXT L5](../../拆分史书/三国志/卷034.txt#L5)

> 后卒，葬于南郡。

**釋讀與歸年** 甘氏長阪脫險後去世，初葬南郡。其卒年介於建安十三年（208）長阪後、章武二年（222）追諡前或同年追諡之前，無確年。

**时段与依据** 入蜀与婚事仅相邻，结婚未给明确年月。

<a id="shu034-l11-3"></a>

**釋讀與歸年** 劉焉聽說相者稱吳氏將大貴，為同行的兒子劉瑁娶吳氏。婚期無明年，不能僅因上文相鄰而定188年。

### 黄皓谗刘永致其十余年不得朝见

[《三国志·二主妃子传》仓内原文 L1744](../../拆分史书/三国志/卷034.md#l1744)

刘永憎恶黄皓。黄皓受宠掌事后，在刘禅面前谗毁刘永，后主逐渐与刘永疏远。

**时段与依据** “十余年”是大略时长。《后主传》黄皓景耀元年始专政，同卷称早已信任用事，谗疏起讫不详。

<a id="shu034-l29-4"></a>

**[《三國志·二主妃子傳》正文](../../拆分史书/三国志/卷034.md#edition-shu034-l29-4)** · [TXT L29](../../拆分史书/三国志/卷034.txt#L29)

> 初，永憎宦人黃皓，皓旣信任用事，譖構永於後主，後主稍踈外永，至不得朝見者十餘年。

**釋讀與歸年** 劉永不喜黃皓，黃皓得信後在劉禪面前讒毀劉永，劉永多年不得朝見。本傳「十餘年」只記相對長度，黃皓景耀元年始專政也不是劉永最初失寵之年。

### 习凿齿批评法正援晋文公说婚

[《三国志·二主妃子传》裴注 003·1](../../拆分史书/三国志/卷034.md#pei-003-1)

习凿齿认为晋文公为借力而暂行权宜，引用子犯的话说明情势。刘备婚配没有同类迫切需要，法正轻引前例，刘备从之有失。

**时段与依据** 评的是刘备平蜀后纳吴氏，以春秋旧事作比较；习凿齿的评论属另一时代，无撰写年月。

### 吴壹孙吴乔在成汉不屈

[《三国志·二主妃子传》裴注 004·1](../../拆分史书/三国志/卷034.md#pei-004-1)

孙盛《蜀世谱》记吴壹之孙吴乔在李雄控制下三十年，不肯屈从。

**时段与依据** 《晋书·李雄载记》可知李雄据蜀的时代，但注所称“三十年”与其具体入居、所处政治条件未详，不能换算为一年。

<a id="shu034-l16-1"></a>

**[《三國志·二主妃子傳》裴注](../../拆分史书/三国志/卷034.md#edition-shu034-l16-1)** · [TXT L16](../../拆分史书/三国志/卷034.txt#L16)

> 孫盛蜀世譜曰：壹孫喬，沒李雄中三十年，不爲雄屈也。

**釋讀與歸年** 《蜀世譜》記吳壹孫吳喬在李雄統治下三十年不屈。所記為跨年情況，無吳喬起訖年。

### 魏以蜀宫人赐诸将及李昭仪自杀

[《三国志·二主妃子传》裴注 005·1](../../拆分史书/三国志/卷034.md#pei-005-1)

《汉晋春秋》称魏把蜀宫女赐给无妻将领，李昭仪拒绝重复受辱而自杀。

**时段与依据** 随张皇后东迁条为蜀亡后之事，未写分赐及李昭仪死是否同步、具体月年。

<a id="shu034-l25-1"></a>

**[《三國志·二主妃子傳》裴注](../../拆分史书/三国志/卷034.md#edition-shu034-l25-1)** · [TXT L25](../../拆分史书/三国志/卷034.txt#L25)

> 漢晉春秋曰：魏以蜀宮人賜諸將之無妻者，李昭儀曰：「我不能二三屈辱。」乃自殺。

**釋讀與歸年** 《漢晉春秋》記蜀亡後魏將蜀宮人分給無妻諸將，李昭儀拒受而自殺。附張皇后東遷的同一背景，原文未把分賜繫於東遷同年。

### 《蜀世谱》列刘璿六弟

[《三国志·二主妃子传》裴注 006·1](../../拆分史书/三国志/卷034.md#pei-006-1)

孙盛列刘瑶、刘琮、刘瓒、刘谌、刘询、刘璩六人；“詢”与卷033恂，“璩”与该卷虔有异写。

**时段与依据** 属于世系补记，无统一生年。

<a id="shu034-l38-1"></a>

**[《三國志·二主妃子傳》裴注](../../拆分史书/三国志/卷034.md#edition-shu034-l38-1)** · [TXT L38](../../拆分史书/三国志/卷034.txt#L38)

> 孫盛蜀世譜曰：璿弟，瑤、琮、瓚、諶、恂、璩六人。

**釋讀與歸年** 孫盛《蜀世譜》列劉璿六弟劉瑤、劉琮、劉瓚、劉諶、劉恂、劉璩，原文字形照錄。

<a id="period-sgz034-p-006-4"></a>

### 蜀汉宗室后裔在永嘉乱中死亡

[《三国志·二主妃子传》裴注 006·4](../../拆分史书/三国志/卷034.md#pei-006-4)

孙盛说刘禅迁中原的后裔遇永嘉大乱而绝。

**时段与依据** “永嘉大乱”指307至313年间的动乱；文中没有各宗室遇难的具体年。

<a id="shu034-l38-4"></a>

**[《三國志·二主妃子傳》裴注](../../拆分史书/三国志/卷034.md#edition-shu034-l38-4)** · [TXT L38](../../拆分史书/三国志/卷034.txt#L38)

> 值永嘉大亂，子孫絕滅。

**釋讀與歸年** 《蜀世譜》說劉禪遷洛後的後裔在永嘉亂中亡絕，未載各人確年，劉永一支另見下文。

<a id="period-sgz034-p-006-5"></a>

### 刘永之孙刘玄奔蜀，李雄以安乐公奉刘禅后

[《三国志·二主妃子传》裴注 006·5](../../拆分史书/三国志/卷034.md#pei-006-5)

刘永孙刘玄逃到蜀地，成汉李雄授其安乐公，令继刘禅世祀。

**时段与依据** 结合“永嘉大乱”与《晋书·李雄载记》知授封在李雄卒前；刘玄入蜀及受命的确年无法核实。

<a id="shu034-l38-5"></a>

**[《三國志·二主妃子傳》裴注](../../拆分史书/三国志/卷034.md#edition-shu034-l38-5)** · [TXT L38](../../拆分史书/三国志/卷034.txt#L38)

> 唯永孫玄奔蜀，李雄偽署安樂公以嗣禪後。

**釋讀與歸年** 劉永孫劉玄入蜀，李雄署為安樂公以奉劉禪祀。可知在李雄在世時，劉玄到蜀及受封確年皆不載。

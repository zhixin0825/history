# 《三國志·妃嬪傳》跨年及未定年材料

## 吴夫人家世与孙坚婚姻

吴夫人原居吴地，后来迁居钱唐。她早年失去父母，与弟弟吴景同住。孙坚求婚时，吴氏亲属一度打算拒绝，吴夫人担心招祸，劝家人同意，两人婚后生四男一女。吴景在孙坚征战期间曾随军立功，获任骑都尉。

<a id="period-sgz050-b-2409-1"></a>

<a id="wu050-l5-1"></a>

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l5-1)** · [TXT L5](../../sources/本地分卷/三国志/三国志-卷050.txt#L5)

> 孫破虜吳夫人，吳主權母也。本吳人，徙錢唐，早失父母，與弟景居。

**釋讀** 吴夫人是孙坚的妻子、孙权的母亲。她自吴迁至钱唐，早年失去父母，与弟弟吴景同住。

**時段與依據** 地望、迁徙、孤居均无确年，同组保留家庭前史。

<a id="period-sgz050-b-2409-2"></a>

<a id="wu050-l5-2"></a>

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l5-2)** · [TXT L5](../../sources/本地分卷/三国志/三国志-卷050.txt#L5)

> 孫堅聞其才貌，欲娶之。吳氏親戚嫌堅輕狡，將拒焉，堅甚以慙恨。夫人謂親戚曰：「何愛一女以取禍乎？如有不遇，命也。」於是遂許爲婚，生四男一女。

**釋讀** 孙坚求婚，吴氏亲友认为孙坚轻狡，一度准备回绝。吴夫人劝亲戚接受，婚后二人生四男一女。

**時段與依據** 婚娶及各子女的出生年月无载；从传述保留婚约争执，不从子女年龄硬推婚期。

<a id="wu050-l6-1"></a>

**[《三國志·妃嬪傳》裴注 001](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l6-1)** · [TXT L6](../../sources/本地分卷/三国志/三国志-卷050.txt#L6)

> 搜神記曰：初，夫人孕而夢月入其懷，旣而生策。及權在孕，又夢日入其懷，以告堅曰：「昔姙策，夢月入我懷，今也又夢日入我懷，何也？」堅曰：「日月者陰陽之精，極貴之象，吾子孫其興乎！」

**釋讀** 干宝传述吴夫人怀孙策时梦月、怀孙权时梦日，孙坚以日月为高贵兴盛的象征。

**時段與依據** 生育附会之梦仅作逸闻，梦兆不能独立建立生年，不入年页正文。

> 景常隨堅征伐有功，拜騎都尉。

**釋讀** 吴景随孙坚征战立功，被任为骑都尉。

**時段與依據** 授骑都尉无确年；早期从孙坚事不混作袁术授郡。

## 吴景在袁术部下领广陵

袁术与刘备争徐州期间，任吴景为广陵太守。

<a id="period-sgz050-b-2410-5"></a>

<a id="wu050-l8-5"></a>

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l8-5)** · [TXT L8](../../sources/本地分卷/三国志/三国志-卷050.txt#L8)

> 術方與劉備爭徐州，以景爲廣陵太守。

**釋讀** 袁术在与刘备争徐州时，以吴景为广陵太守。

**時段與依據** 本传只给相对时序：在战刘繇和197年吴景弃郡之间，徐州争战延续数年。

## 吴夫人劝孙策宽免魏腾

孙策拟杀因进谏获罪的功曹魏腾。吴夫人劝他礼待士人、宽过记功，以投井相争，孙策释放魏腾。

## 吴奋领兵封侯，吴安承爵

吴景之子吴奋受命领兵，封新亭侯。他去世后，吴安承袭侯爵。

<a id="period-sgz050-b-2412-2"></a>

<a id="wu050-l17-2"></a>

> 子奮授兵爲將，封新亭侯，卒。

**釋讀** 吴景的儿子吴奋受兵领军，封为新亭侯，后来去世。

**時段與依據** 授兵、封新亭侯及卒皆无绝对年月；不因为上句吴景卒是203就一并记为203。另见第18行镇吴郡。

> 子安嗣，

**釋讀** 吴奋之子吴安承爵。

**時段與依據** 绍袭无年，不能以250年被诛逆推出袭封年份。

## 吴祺任治讼，吴纂承袭封爵

吴奋的弟弟吴祺与张温、顾谭交好，受命参与审理讼事，受封都亭侯。吴祺去世后，儿子吴纂承爵。

<a id="wu050-l19-3"></a>

> 奮弟祺，

**釋讀** 吴祺是吴奋的弟弟。

**時段與依據** 本句跨裴注至第21行，单述亲属无年，随吴祺、吴纂承爵事。

**時段與依據** 三人交往、受官无确年。“關平辭訟事”是参与平理诉讼，非涉及关羽之子关平。

## 孙权聘谢氏，后纳徐氏，徐氏抚养孙登

谢夫人是会稽山阴人，经吴夫人作主嫁给孙权。徐氏原嫁同郡陆尚，陆尚死后，孙权又聘徐氏为妃，令她抚养孙登。孙权欲使谢氏居徐氏之下，谢氏不肯，后来失宠早卒。徐氏后来也失宠，被留置于吴。

<a id="period-sgz050-b-2414-1"></a>

<a id="wu050-l25-1"></a>

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l25-1)** · [TXT L25](../../sources/本地分卷/三国志/三国志-卷050.txt#L25)

> 吳主權謝夫人，會稽山陰人也。父㷡，漢尚書郎、徐令。

**釋讀** 谢夫人是会稽山阴人，父亲谢㷡曾任汉尚书郎和徐令。

**時段與依據** 身世背景连读吴夫人聘谢氏。任职无确年；本TXT作“㷡”，旧索引“煚”只是异写。

<a id="period-sgz050-b-2414-2"></a>

<a id="wu050-l27-1"></a>

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l27-1)** · [TXT L27](../../sources/本地分卷/三国志/三国志-卷050.txt#L27)

> 權母吳，爲權聘以爲妃，愛幸有寵。後權納姑孫徐氏，欲令謝下之，謝不肯，由是失志，早卒。

**釋讀** 孙权母亲聘谢氏为妃，谢氏有宠。后来孙权纳表亲徐氏，想让谢氏居其下；谢氏不肯，抑郁而早卒。

**時段與依據** 谢氏嫁孙权在吴氏生前，后纳徐氏在孙权为讨虏将军、居吴时期。谢氏生卒未明，与第38行互见，不能由吴氏两种卒年强定婚丧。

<a id="period-sgz050-b-2417-1"></a>

<a id="wu050-l38-1"></a>

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l38-1)** · [TXT L38](../../sources/本地分卷/三国志/三国志-卷050.txt#L38)

> 琨生夫人，初適同郡陸尚。尚卒，權爲討虜將軍在吳，聘以爲妃，使母養子登。

**釋讀** 徐琨之女初嫁同郡陆尚。陆尚死后，孙权任讨虏将军在吴，聘徐氏为妃并使她抚养孙登。

**時段與依據** 孙权建安五年领讨虏将军；“在吴”并非具体年份，陆尚亡、再嫁与开始抚养均不补确年。与卷059孙登传互见。

<a id="wu050-l38-2"></a>

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l38-2)** · [TXT L38](../../sources/本地分卷/三国志/三国志-卷050.txt#L38)

> 後權遷移，以夫人妬忌，廢處吳。

**釋讀** 孙权后来迁往他处，以嫉妒为由废置徐氏，将她留在吴地。

**時段與依據** 迁移与留置并未明记年、地；卷059孙登立储前徐氏已在吴，故不能以229迁都建业解释此处。“嫉妒”为当时所归责。

## 谢氏家世及谢承仕宦著述

谢夫人的父亲谢㷡曾任尚书郎、徐令，叔父谢贞举孝廉后任建昌长。弟弟谢承后来历任五官郎中、长沙东部都尉、武陵太守，撰《后汉书》。谢承的儿子谢崇、谢勗也在孙吴任官。

<a id="period-sgz050-p-008-1"></a>

<a id="wu050-l26-1"></a>

**[《三國志·妃嬪傳》裴注 007](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l26-1)** · [TXT L26](../../sources/本地分卷/三国志/三国志-卷050.txt#L26)

> 㷡子承撰後漢書，稱㷡幼以仁孝爲行，明達有令才。㷡弟貞，履蹈法度，篤學尚義，舉孝廉，建昌長，卒官。

**釋讀** 谢承撰《后汉书》，记父亲谢㷡年少以仁孝为行，明达有才；叔父谢贞守法好学，举孝廉，任建昌长，死在任上。

**時段與依據** 谢㷡、谢贞的德行与官历无确年；谢承成书另无年月。

> 後十餘年，弟承拜五官郎中，稍遷長沙東部都尉、武陵太守，撰後漢書百餘卷。

**時段與依據** 生平、属官和子辈任官皆无确年，连谢氏家世与著述。

## 徐氏家世，徐琨从孙坚起兵

徐夫人是吴郡富春人。祖父徐真娶孙坚的妹妹，生徐琨。徐琨曾任州郡吏，乱起后离职，从孙坚征战立功，受任偏将军。

<a id="wu050-l32-1"></a>

> 吳主權徐夫人，吳郡富春人也。祖父真，與權父堅相親，堅以妹妻真，生琨。

**釋讀** 徐夫人是吴郡富春人。祖父徐真与孙坚交好，娶孙坚的妹妹，生下徐琨。

**時段與依據** 婚配、出生无确年；“姑孙徐氏”以此家系印证。

## 徐琨取丹杨并领太守

孙策命徐琨进攻袁胤，徐琨一度领丹杨太守。

## 徐琨迁平虏将军，后从讨黄祖战死

徐琨升任平虏将军，后来随军进讨黄祖，中流箭去世。

<a id="period-sgz050-b-2416-6"></a>

<a id="wu050-l36-2"></a>

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l36-2)** · [TXT L36](../../sources/本地分卷/三国志/三国志-卷050.txt#L36)

> 遷平虜將軍。後從討黃祖，中流矢卒。

**釋讀** 徐琨升平虏将军，后来随军攻黄祖，中流箭死去。

**時段與依據** 孙权至少在203、207、208三次进攻黄祖；本传无地名、年号或其他能唯一定位的证据。升迁、阵亡皆保留未定年。

## 吴廷议徐氏、步氏立后，徐夫人终未受册

孙权为吴王后立孙登为太子，孙登曾请先册皇后并提到养母徐氏。孙权称帝前后，群臣主张立徐夫人为后，孙权属意步氏，徐氏终未获册，后来病卒。

## 全公主与朱公主因争储生隙

孙和在东宫时，全公主孙鲁班攻击他的母亲王夫人，主张改立鲁王孙霸。朱公主孙鲁育不肯赞同，姐妹由此生隙。

<a id="period-sgz050-b-2432-4"></a>

<a id="wu050-l72-5"></a>

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l72-5)** · [TXT L72](../../sources/本地分卷/三国志/三国志-卷050.txt#L72)

> 初，孫和爲太子時，全主譖害王夫人，欲廢太子，立魯王，朱主不聽，由是有隙。

**釋讀** 全公主想废孙和、另立鲁王，朱公主反对，遂与全公主不和。

**時段與依據** 孙和在东宫为242—250年。卷059可互证王夫人受谮与孙和失宠，朱主反对的具体时点无载；同255鲁育死事为前情。

## 孙皓寻找朱公主墓的传说

孙皓即位后曾打算改葬朱公主。石子冈诸墓相邻，宫中流传遣两名巫者辨墓、开墓时见死者衣服相符的故事。

<a id="period-sgz050-p-017-2"></a>

<a id="wu050-l73-2"></a>

**[《三國志·妃嬪傳》裴注 016](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l73-2)** · [TXT L73](../../sources/本地分卷/三国志/三国志-卷050.txt#L73)

> 歸命即位，將欲改葬之。冢墓相亞，不可識別，而宮人頗識主亡時所著衣服，乃使兩巫各住一處以伺其靈，使察鑒之，不得相近。乆時，二人俱白：見一女人年可三十餘，上著青錦束頭，紫白袷裳，丹綈絲履，從石子岡上半岡，而以手抑膝長太息，小住須臾，進一冢上便住，徘徊良乆，奄然不見。二人之言，不謀而同，於是開冢，衣服如之。

**釋讀** 孙皓欲改葬朱主而难辨墓。两名巫者分守，不许互通，后来都说看见同样容貌、服饰的女人走到一座墓前消失。打开墓后，所见衣服相符。

**時段與依據** 「归命」是孙皓降晋后封号，在此用来追称他，事情发生在其即吴位以后。注无辨墓、开墓确年，改葬是否完成也未明，应按吴末时期保留；辨墓异事属传说。

## 何氏入宮與孫皓出生

何氏是丹楊句容人，父親何遂原為騎士。孫權在營中出遊時見到她，召入後給孫和。何氏生孫皓，孫權為他取名彭祖。

> 孫和何姬，丹楊句容人也。父遂，本騎士。孫權甞游幸諸營，而姬觀於道中，權望見異之，命宦者召入，以賜子和。

**釋讀** 何姬之父何遂出身騎士。她從觀道而被召入，後侍孫和。

**時段與依據** 入宮及賜給孫和尚無確年。

## 何氏後人的承爵與官職

何洪去世後，兒子何邈襲爵，曾任武陵監軍，後為晉軍所殺。何植官至司徒，吳末參與朝廷軍政。

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l79-3)** · [TXT L79](../../sources/本地分卷/三国志/三国志-卷050.txt#L79)

## 張布女兒入宮及身後

張布遇害後，他的女兒先後入宮。後入宮的長女原嫁馮純，後為左夫人。孫皓寵愛她，她死後，孫皓厚葬，久不出宮。

<a id="period-sgz050-p-019-1"></a>

<a id="wu050-l80-1"></a>

**[《三國志·妃嬪傳》裴注 018](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l80-1)** · [TXT L80](../../sources/本地分卷/三国志/三国志-卷050.txt#L80)

> 江表傳曰：皓以張布女爲美人，有寵，皓問曰：「汝父所在？」荅曰：「賊以殺之。」皓大怒，棒殺之。後思其顏色，使巧工刻木作美人形象，恒置座側。

**釋讀** 一女因直指其父被殺而觸怒孫皓，被打死。孫皓事後思念她，命人刻木像。

**時段與依據** 張布於264年遇害，兩女入宮及身後確年未載。卷059另記王氏左夫人，不徑認為同一人。

<a id="period-sgz050-p-019-2"></a>

<a id="wu050-l80-2"></a>

**[《三國志·妃嬪傳》裴注 018](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l80-2)** · [TXT L80](../../sources/本地分卷/三国志/三国志-卷050.txt#L80)

> 問左右：「布復有女否？」荅曰：「布大女適故衞尉馮朝子純。」即奪純妻入宮，大有寵，拜爲左夫人，晝夜與夫人房宴，不聽朝政，使尚方以金作華燧、步搖、假髻以千數。令宮人著以相撲，朝成夕敗，輒出更作，工匠因緣偷盜，府藏爲空。

**釋讀** 張布長女已嫁馮純，孫皓納為左夫人。宮中耗金製作首飾，工匠乘機盜竊。

**時段與依據** 這些宮中往事先後可辨，未有獨立月年。

<a id="wu050-l80-3"></a>

**釋讀** 左夫人死後，孫皓以厚葬相送，居喪半年不出。

**時段與依據** 卷059孫奮傳所記建衡二年王氏左夫人去世，和本注張氏身分不同。確年未詳。

## 滕氏家世與嫁孫皓

滕氏父親是滕牧，她和太常滕胤同族。孫皓在烏程侯時娶她。

## 滕后失寵，滕牧被遣蒼梧

朝臣推滕牧進諫。滕后逐漸失寵，何太后扶持她，孫皓仍保留她的皇后名位。滕牧被遣往蒼梧，途中憂死。滕后仍受朝賀，后印也曾被孫皓的寵姬佩戴。

<a id="period-sgz050-b-2436-6"></a>

<a id="wu050-l84-6"></a>

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l84-6)** · [TXT L84](../../sources/本地分卷/三国志/三国志-卷050.txt#L84)

> 後朝士以牧尊戚，頗推令諫爭。而夫人寵漸衰，皓滋不恱，皓母何恒左右之。又太史言，於運歷，后不可易，皓信巫覡，故得不廢，常供養升平宮。

**釋讀** 滕牧為朝臣推舉進諫。滕后失寵後何太后仍照應她。太史認為依運歷不可易后，孫皓遂未廢后。

**時段與依據** 滕牧266年仍在武昌任事，後出居蒼梧及卒日無明文。

<a id="wu050-l84-7"></a>

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l84-7)** · [TXT L84](../../sources/本地分卷/三国志/三国志-卷050.txt#L84)

> 牧見遣居蒼梧郡，雖爵位不奪，其實裔也，遂道路憂死。長秋官僚備員而已，受朝賀表疏如故。而皓內諸寵姬，佩皇后璽紱者多矣。

**釋讀** 滕牧雖未被削爵，實際被遠徙，途中憂死。滕后名義上照常受賀，諸寵姬曾戴后璽紱。

**時段與依據** 與滕氏失寵同屬在位後期，欠缺獨立月年。

**時段與依據** 卷048鳳凰三年另有採選將吏女子的紀事。此段為制度與長期情形，未只指同一批。

## 陳壽論孫吳宮廷與嫡庶

<a id="period-sgz050-b-2437-1"></a>

<a id="wu050-l88-1"></a>

**[《三國志·妃嬪傳》正文](../../sources/本地分卷/三国志/三国志-卷050.md#edition-wu050-l88-1)** · [TXT L88](../../sources/本地分卷/三国志/三国志-卷050.txt#L88)

> 評曰：易稱「正家而天下定」。詩云：「刑于寡妻，至于兄弟，以御于家邦。」誠哉，是言也！遠觀齊桓，近察孫權，皆有識士之明，傑人之志，而嫡庶不分，閨庭錯亂，遺笑古今，殃流後嗣。由是論之，惟以道義爲心、平一爲主者，然後克免斯累邪！

**釋讀** 陳壽引《易》《詩》，比較齊桓公與孫權，認為兩人雖能識士，嫡庶之別未明，終於禍流後嗣。

**時段與依據** 卷末史論橫跨兩個時代，保留為評論。

### 吴夫人传题

[《三国志·妃嫔传》仓内原文 L2408](../../sources/本地分卷/三国志/三国志-卷050.md#l2408)

> 吳夫人

本节记孙坚妻、孙权母。

**时段与依据** 卷内标题。

<a id="period-sgz050-b-2409-1"></a>

### 吴夫人孤居钱唐

[《三国志·妃嫔传》仓内原文 L2409](../../sources/本地分卷/三国志/三国志-卷050.md#l2409)

> 孫破虜吳夫人，吳主權母也。本吳人，徙錢唐，早失父母。與弟景居。

原居吴地，迁钱唐，早年失父母，与弟吴景同居。

**时段与依据** 家庭迁徙和父母去世都未记年。

<a id="period-sgz050-b-2409-2"></a>

### 孙坚娶吴夫人

[《三国志·妃嫔传》仓内原文 L2409](../../sources/本地分卷/三国志/三国志-卷050.md#l2409)

> 孫堅聞其才貌，欲娶之。吳氏親戚嫌堅輕狡，將拒焉，堅甚以慚恨。夫人謂親戚曰：「何愛一女以取禍乎？如有不遇，命也。」於是遂許為婚，生四男一女。

亲族起先嫌孙坚轻狡，吴夫人劝避免祸而同意，婚后生四男一女。

**时段与依据** 无婚娶年月，子女生于不同年。

<a id="period-sgz050-b-2410-1"></a>

### 吴景从孙坚受骑都尉

[《三国志·妃嫔传》仓内原文 L2410](../../sources/本地分卷/三国志/三国志-卷050.md#l2410)

> 景常隨堅征伐有功，拜騎都尉。

因随征有功任骑都尉。

**时段与依据** 从战多年，任命无年。

<a id="period-sgz050-b-2410-3"></a>

### 吴景、孙贲被刘繇逼退，重依袁术

[《三国志·妃嫔传》仓内原文 L2410](../../sources/本地分卷/三国志/三国志-卷050.md#l2410)

> 會為劉繇所迫，景復北依術，術以為督軍中郎將，與孫賁共討樊能、於麋於橫江，又擊笮融、薛禮於秣陵。

袁术授吴景督军中郎将，二人据横江、秣陵等处讨敌。

**时段与依据** 从撤出曲阿到攻江边历岁余，跨194—195。

<a id="period-sgz050-b-2410-5"></a>

### 袁术以吴景为广陵太守

[《三国志·妃嫔传》仓内原文 L2410](../../sources/本地分卷/三国志/三国志-卷050.md#l2410)

> 術方與劉備爭徐州，以景為為廣陵太守。

正与刘备争徐州时任吴景。

**时段与依据** 徐州争战跨195后数年，本传只附相对史事。

<a id="period-sgz050-b-2412-2"></a>

### 吴奋领兵、新亭侯，死后吴安袭封

[《三国志·妃嫔传》仓内原文 L2412](../../sources/本地分卷/三国志/三国志-卷050.md#l2412)

> 子奮授兵為將，封新亭侯，卒。子安嗣，

吴奋为将，其子吴安嗣。

**时段与依据** 官职、侯爵和父卒年月未见。

<a id="period-sgz050-b-2412-4"></a>

### 吴祺、吴纂接续封爵

[《三国志·妃嫔传》仓内原文 L2412](../../sources/本地分卷/三国志/三国志-卷050.md#l2412)

> 奮弟祺嗣，封都亭侯，卒。子纂嗣。纂妻即滕胤女也，

吴祺封都亭侯，卒后子吴纂嗣，吴纂娶滕胤女。

**时段与依据** 继封、吴祺死及婚期失载。

**时段与依据** 篇内标题。

<a id="period-sgz050-b-2414-1"></a>

### 谢夫人籍贯家世，吴夫人为孙权聘谢氏

[《三国志·妃嫔传》仓内原文 L2414](../../sources/本地分卷/三国志/三国志-卷050.md#l2414)

> 吳主權謝夫人，會稽山陰人也。父煚，漢尚書郎、徐令。權母吳，為權聘以為妃，愛幸有寵。

其父谢煚历尚书郎、徐令。谢氏由孙权母聘为妃。

**时段与依据** 职官和成婚无明年。

<a id="period-sgz050-b-2414-2"></a>

### 孙权纳徐氏，谢夫人不肯居其下

[《三国志·妃嫔传》仓内原文 L2414](../../sources/本地分卷/三国志/三国志-卷050.md#l2414)

> 後權納姑孫徐氏，欲令謝下之，謝不肯，由是失志。早卒。

谢氏失意，早死。

**时段与依据** 后妃先后明确，谢氏卒年欠载。

<a id="period-sgz050-b-2414-3"></a>

### 谢承仕孙吴并撰《后汉书》

[《三国志·妃嫔传》仓内原文 L2414](../../sources/本地分卷/三国志/三国志-卷050.md#l2414)

> 後十餘年，弟承拜五官郎中，稍遷長沙東部都尉、武陵太守，撰《後漢書》百餘卷。

谢夫人死十余年，其弟谢承获任五官郎中，渐迁诸职，成书百余卷。

**时段与依据** 相隔十余年没有绝对锚，授官和成书亦非同年。

### 徐夫人传题

[《三国志·妃嫔传》仓内原文 L2415](../../sources/本地分卷/三国志/三国志-卷050.md#l2415)

> 徐夫人

本节记徐夫人及祖父亲族。

**时段与依据** 篇内标题。

<a id="period-sgz050-b-2416-1"></a>

### 徐夫人家世及孙坚妹与徐真婚配

[《三国志·妃嫔传》仓内原文 L2416](../../sources/本地分卷/三国志/三国志-卷050.md#l2416)

> 吳主權徐夫人，吳郡富春人也。祖父真，與權父堅相親，堅以妹妻真，生琨。

徐夫人出富春。祖徐真与孙坚交好，娶孙坚妹，其子徐琨。

**时段与依据** 家系及婚娶无年月。

<a id="period-sgz050-b-2416-2"></a>

### 徐琨少为郡吏，辞职从孙坚

[《三国志·妃嫔传》仓内原文 L2416](../../sources/本地分卷/三国志/三国志-卷050.md#l2416)

> 琨少仕州郡，漢末擾亂，去吏，隨堅征伐有功，拜偏將軍。

从征立功，拜偏将军。

**时段与依据** 从征及授命无独立年次。

<a id="period-sgz050-b-2416-4"></a>

### 徐琨曾领丹杨，吴景归后接任

[《三国志·妃嫔传》仓内原文 L2416](../../sources/本地分卷/三国志/三国志-卷050.md#l2416)

> 策表琨領丹楊太守，會吳景委廣陵來東，復為丹楊守。

孙策暂表徐琨守郡，吴景从广陵回后复任。

**时段与依据** 吴景归在袁术197称帝之后；徐琨先任可能早些，不强系同年。

<a id="period-sgz050-b-2416-6"></a>

### 徐琨从讨黄祖，中箭而死

[《三国志·妃嫔传》仓内原文 L2416](../../sources/本地分卷/三国志/三国志-卷050.md#l2416)

> 後從討黃祖，中流矢卒。

随孙权讨黄祖时中流矢亡。

**时段与依据** 孙权203、207、208数征黄祖，传无明纪。

<a id="period-sgz050-b-2417-1"></a>

### 徐夫人初嫁陆尚，后为孙权妃并养孙登

[《三国志·妃嫔传》仓内原文 L2417](../../sources/本地分卷/三国志/三国志-卷050.md#l2417)

> 琨生夫人，初適同郡陸尚。尚卒，極為討虜將軍在吳，聘以為妃，使母養子登。後權遷移，以夫人妒忌，廢處吳。

陆尚死后，孙权在吴时聘徐氏。孙权迁移，徐氏因妒被废留吴。

**时段与依据** “極為討虜將軍”四库作“權為”，任讨虏将军从200开始。初婚、入宫及被留时间缺确年。

<a id="period-sgz050-b-2417-2"></a>

### 徐氏与步氏立后之议，徐氏后病卒

[《三国志·妃嫔传》仓内原文 L2417](../../sources/本地分卷/三国志/三国志-卷050.md#l2417)

> 積十餘年，權為吳王及即尊號，登為太子，群臣請立夫人為后，權意在步氏，卒不許。後以疾卒。

孙权为王、即帝、立太子后，群臣多主张徐氏为后，孙权倾向步氏，终未立徐氏。

**时段与依据** 由221吴王至229帝位后，议论多年。徐氏死年未载，不能从相对十余年求精确日期。

<a id="period-sgz050-b-2417-3"></a>

### 徐矫、徐祚袭爵并任军职

[《三国志·妃嫔传》仓内原文 L2417](../../sources/本地分卷/三国志/三国志-卷050.md#l2417)

> 兄矯，嗣父琨侯，討平山越，拜偏將軍，先夫人卒，無子。弟祚襲封，亦以戰功至（於）蕪湖督、平魏將軍。

徐矫讨山越任偏将军，先于徐夫人死且无子。徐祚继封，至芜湖督、平魏将军。

**时段与依据** 讨山越、袭爵、升迁诸次皆缺年。

[《三国志·妃嫔传》仓内原文 L2419](../../sources/本地分卷/三国志/三国志-卷050.md#l2419)

**时段与依据** 亲属地望，无具体纪年。

<a id="period-sgz050-b-2419-3"></a>

### 步夫人生孙鲁班、孙鲁育及二女婚配

[《三国志·妃嫔传》仓内原文 L2419](../../sources/本地分卷/三国志/三国志-卷050.md#l2419)

> 生二女，長曰魯班，字大虎，前配周瑜子循，後配全琮。少曰魯育，字小虎，前配朱據，後配劉纂。

长女先嫁周循再嫁全琮，次女先嫁朱据后嫁刘纂。

**时段与依据** 生女与数次婚嫁跨年。

<a id="period-sgz050-b-2420-1"></a>

### 步夫人受宠并被宫中称后

[《三国志·妃嫔传》仓内原文 L2420](../../sources/本地分卷/三国志/三国志-卷050.md#l2420)

> 夫人性不妒忌，多所推近，故久見愛待。權為王及帝，意欲以為后，而群臣議在徐氏，權依違者十餘年，然宮內皆稱皇后，親戚上疏稱中宮。

步氏不妒且多次推举他人。孙权本欲册后，舆议支持徐氏，未决多年，宫中已称后。

**时段与依据** 从为王到称帝后的多年礼议，称号与正式册名应区分。

<a id="period-sgz050-b-2424-1"></a>

### 琅邪王夫人入宫，生孙和

[《三国志·妃嫔传》仓内原文 L2424](../../sources/本地分卷/三国志/三国志-卷050.md#l2424)

> 吳主權王夫人，琅邪人也。夫人以選入宮，黃武中得幸，生（孫）和，寵次步氏。

黄武中得宠，宠遇仅次于步氏。

**时段与依据** 黄武222—229。孙和242年十九推约224，原传未明生时年次。

<a id="period-sgz050-b-2424-2"></a>

### 孙权拟立王夫人，全公主谮之

[《三国志·妃嫔传》仓内原文 L2424](../../sources/本地分卷/三国志/三国志-卷050.md#l2424)

> 步氏薨後，和立為太子，權將立夫人為后，而全公主素憎夫人，稍稍譖毀。及權寢疾。言有喜色，由是權深責怒，以憂死。

步氏死后孙和成为太子，孙权拟立其母。全公主谮称王夫人幸灾，孙权怒责，王夫人忧死。

**时段与依据** 从238步氏死、242立和到250太子废的数年，忧死未给绝对年。

**时段与依据** 孙和242立太子；遣居、死葬暂无确年。

### 潘夫人父获罪，两姊妹入织室，潘氏入宫

潘氏为句章人，父坐法死，姐妹输织，孙权召潘氏入后宫。

### 潘夫人生孙亮，传有龙头梦兆

**时段与依据** 孙亮258年十六虚岁推约243，原文未记；梦只属传说。

**时段与依据** 家世与交际无确年。

<a id="period-sgz050-b-2430-4"></a>

### 全尚迭掌太常与卫将军，全氏多领兵

[《三国志·妃嫔传》仓内原文 L2430](../../sources/本地分卷/三国志/三国志-卷050.md#l2430)

> 代滕胤為太常、衛將軍，進封永平侯，錄尚書事。時全氏侯有五人，並典兵馬。其餘為侍郎、騎都尉，宿衛左右，自吳興，外戚貴盛莫及。

全尚进永平侯并录尚书；全氏多人居侯、典兵及护卫。

**时段与依据** 滕胤死于256；全尚后续官爵的确日有别，本段合叙全氏贵势。

> 江表傳曰晧以張布女為美人有寵晧問曰汝父所在答曰賊以殺之晧大怒棒殺之後思其顔色使巧工刻木作美人形象恒置座側

小女回答父亲遭杀，孙皓怒杀之，后又刻木像怀念。

**时段与依据** 张布264被诛后，女入宫和被杀无年。

### 孙皓夺冯纯妻张氏为左夫人

[《三国志·妃嫔传》裴注 019·2](../../sources/摘录/三国志-卷050-妃嫔传裴注.md#pei-019-2)

> 問左右布復有女否答曰布大女適故衛尉馮朝子純即奪純妻入宫大有寵拜為左夫人晝夜與夫人房宴不聽朝政使尚方以金作華燧步揺假髻以千數令宫人著以相撲朝成夕敗輙出更作工匠因縁偷盗府藏為空

后一女入宫受宠，注称孙皓沉于房宴，宫中服饰器用奢靡。

**时段与依据** 两女经历分开，进左夫人的确年不详。

<a id="period-sgz050-p-019-3"></a>

### 左夫人死，孙皓厚葬并长时不出

[《三国志·妃嫔传》裴注 019·3](../../sources/摘录/三国志-卷050-妃嫔传裴注.md#pei-019-3)

> 㑹夫人死晧哀愍思念〔四库字图1593〕於苑中大作冡使工匠刻栢作木人内冡中以為兵衛以金銀珍玩之物送葬不可稱計巳葬之後晧治䘮於内半年不出

张氏葬苑中，宝物繁多；传称半年不出，因而引起谣言。

**时段与依据** 《孙奋传》270记左夫人王氏死、谣及孙奋，此作张氏，不能因同一叙型把两人、葬礼和年份合一。

### 孙皓命黄门按官员家选宫女

[《三国志·妃嫔传》裴注 020·1](../../sources/摘录/三国志-卷050-妃嫔传裴注.md#pei-020-1)

> 江表傳曰晧又使黄門備行州郡科取将吏家女其二千石大臣子女皆當〔四库字图2902〕嵗言名年十五六一簡閲簡閱不中乃得出嫁後宫千數而採擇無已

到州郡挑选将吏女，先列二千石家女子年龄姓名，简阅不入宫的才得婚嫁。

**时段与依据** 孙皓在位时反复行使，不能判唯一年。

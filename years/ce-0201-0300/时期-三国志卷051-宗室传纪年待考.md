# 《三國志·宗室傳》跨年及未定年材料

## 孫靜集眾自保及家系

孫靜是孫堅幼弟。孫堅起事時，他集合鄉人和宗族五六百人自保，後來在家中去世。孫靜之子孫暠有綽、超、恭三子，孫綝、孫峻分別是孫綽、孫恭之子。

<a id="period-sgz051-b-2440-1"></a>

<a id="period-sgz051-b-2440-2"></a>

<a id="wu051-l5-1"></a>

**[《三國志·宗室傳》正文](../../拆分史书/三国志/卷051.md#edition-wu051-l5-1)** · [TXT L5](../../拆分史书/三国志/卷051.txt#L5)

> 孫靜字幼臺，堅季弟也。堅始舉事，靜糾合鄉曲及宗室五六百人以爲保障，衆咸附焉。

**釋讀** 孫靜字幼臺，是孫堅最幼的弟弟。孫堅起事時，他糾集同鄉、宗族五六百人自保，眾人歸附。

**時段與依據** 原句僅說「堅始舉事」。《孫破虜傳》先敘募兵討許昌，後敘在長沙起兵討董卓，無從由此確定指的是哪一次。

**[《三國志·宗室傳》正文](../../拆分史书/三国志/卷051.md#edition-wu051-l9-3)** · [TXT L9](../../拆分史书/三国志/卷051.txt#L9)

> 終於家。有五子，暠、瑜、皎、奐、謙。暠三子：綽、超、恭。超爲偏將軍。恭生峻。綽生綝。

**釋讀** 孫靜最終在家中去世。其子孫暠、孫瑜、孫皎、孫奐、孫謙。孫暠的三子為孫綽、孫超、孫恭，孫超任偏將軍。孫綝是孫綽之子，孫峻是孫恭之子。

**時段與依據** 孫靜卒在遷昭義中郎將之後，未載年月。後附宗支世系與官職。

## 周昕從陳蕃受學並任丹楊太守

周昕少時遊學京師，師從陳蕃，博覽書籍，擅長據風候推測災異。受太尉府徵辟、考列高第，後任丹楊太守。

<a id="period-sgz051-p-002-1"></a>

<a id="wu051-l8-1"></a>

**[《三國志·宗室傳》裴注 002](../../拆分史书/三国志/卷051.md#edition-wu051-l8-1)** · [TXT L8](../../拆分史书/三国志/卷051.txt#L8)

> 會稽典錄曰：昕字大明。少游京師，師事太傅陳蕃，博覽羣書，明於風角，善推災異。辟太尉府，舉高第，稍遷丹楊太守。

**釋讀** 周昕字大明，少時在京師師從陳蕃，擅風角和推斷災異。太尉府辟用、考列高第，漸遷丹楊太守。

**時段與依據** 周昕受業在陳蕃遇害（168）前，任太守已見《武帝紀》初平元年（190）。科第與升遷年月未載。

## 孫瑜初領兵，安撫部將

孫瑜以恭義校尉領兵，虛心安撫多從江西來的賓客和諸將，得到他們擁戴。

<a id="wu051-l13-1"></a>

**[《三國志·宗室傳》正文](../../拆分史书/三国志/卷051.md#edition-wu051-l13-1)** · [TXT L13](../../拆分史书/三国志/卷051.txt#L13)

> 瑜字仲異，以恭義校尉始領兵衆。是時賔客諸將多江西人，瑜虛心綏撫，得其歡心。

**釋讀** 孫瑜以恭義校尉始領部眾，安撫多從江西來的賓客和部將，得其擁戴。

**時段與依據** 初任在本傳下文建安九年領丹楊太守之前，無明年。

## 孫瑜遷屯牛渚，招納廬江降附者

孫瑜升奮威將軍，仍領丹楊，由溧陽移屯牛渚。他命饒助任襄安長，顏連任居巢長，招納廬江一帶的降附者。

> 遷奮威將軍，領郡如故，自溧陽徙屯牛渚。瑜以永安人饒助爲襄安長，無錫人顏連爲居巢長，使招納廬江二郡，各得降附。

**釋讀** 孫瑜為奮威將軍，仍領丹楊，由溧陽移屯牛渚。他派饒助任襄安長、顏連任居巢長，招納廬江一帶的降附者。

**時段與依據** 本傳敘在濡須之戰後、孫瑜二十年卒前；遷官、移營、薦任與招撫各欠明年。「廬江二郡」原字照錄。

## 孫瑜禮馬普，在軍府興學

孫瑜厚待篤學的濟陰人馬普，讓兩府將吏子弟數百人跟隨他讀書，又設置學官、親臨宴飲與講習。孫瑜在軍旅中也不輟讀書。

> 濟陰人馬普篤學好古，瑜厚禮之，使二府將吏子弟數百人就受業，遂立學官，臨饗講肄。是時諸將皆以軍務爲事，而瑜好樂墳典，雖在戎旅，誦聲不絕。

**釋讀** 孫瑜厚待篤學的馬普，命兩府將吏子弟從學，設學官且親臨饗宴講習。孫瑜在軍旅中也常誦讀典籍。

**時段與依據** 任內興學與講習屬連續治理，確年未載。

## 孫瑜的五子

孫瑜有彌、熈、燿、曼、紘五子。孫曼官至將軍並封侯。

> 瑜五子：彌、熈、燿、曼、紘。曼至將軍，封侯。

## 孫皎任護軍，拒曹於濡須並接掌夏口

孫皎起初任護軍校尉，統兵二千餘。曹操數次攻濡須，孫皎領精兵迎拒。後來孫皎接替程普督夏口，兼領黃蓋、孫瑜舊部，得沙羨等地為奉邑。

> 皎字叔朗，始拜護軍校尉，領衆二千餘人。是時曹公數出濡須，皎每赴拒，號爲精銳。

**釋讀** 孫皎初任護軍校尉，統兵二千餘人；曹操數攻濡須，孫皎屢率精兵迎拒。

## 孫皎任用僚屬，禁擾江淮百姓

孫皎與諸葛瑾交厚，委劉靖等人分掌軍府事務。他送還部下俘獲的女子，下令不得侵擾老弱，江淮百姓多有歸附。

<a id="wu051-l17-3"></a>

> 輕財能施，善於交結，與諸葛瑾至厚，委廬江劉靖以得失，江夏李允以衆事，廣陵吳碩、河南張梁以軍旅，而傾心親待，莫不自盡。

**釋讀** 孫皎輕財善交，厚待諸葛瑾、劉靖、李允、吳碩、張梁，知人任事。

**時段與依據** 軍府治理的概述。孫奐接領江夏後仍禮遇劉靖等人。

> 皎嘗遣兵候獲魏邊將吏美女以進皎，皎更其衣服送還之，下令曰：「今所誅者曹氏，其百姓何罪？自今以往，不得擊其老弱。」由是江淮間多歸附者。

**時段與依據** 巡邊捕獲及下令時點未載，附孫皎守邊始末。

## 孫皎與甘寧失和，孫權致書勸解

孫皎酒後冒犯甘寧。甘寧不願因孫皎出身宗室而屈從，請改隸呂蒙。孫權以書責孫皎，告誡他善待將士、寬容自省，又遣諸葛瑾轉達。孫皎上疏謝過，與甘寧和好。

**[《三國志·宗室傳》](../../拆分史书/三国志/卷051.md#full-wu051-l17-5)** · [TXT L17](../../拆分史书/三国志/卷051.txt#L17)

> 嘗以小故與甘寧忿爭，或以諫寧，寧曰：「臣子一例，征虜雖公子，何可專行侮人邪！吾值明主，但當輸効力命，以報所天，誠不能隨俗屈曲矣。」權聞之，以書讓皎曰：「自吾與北方爲敵，中間十年，初時相遲年小，今者且三十矣。孔子言『三十而立』，非但謂五經也。授卿以精兵，委卿以大任，都護諸將於千里之外，欲使如楚任昭奚恤，揚威於北境，非徒相使逞私志而已。近聞卿與甘興霸飲，因酒發作，侵陵其人，其人求屬呂蒙督中。此人雖麤豪，有不如人意時，然其較略大丈夫也。吾親之者，非私之也。吾親愛之，卿踈憎之；卿所爲每與吾違，其可乆乎？夫居敬而行簡，可以臨民；愛人多容，可以得衆。二者尚不能知，安可董督在遠，禦寇濟難乎？卿行長大，特受重任，上有遠方瞻望之觀，下有部曲朝夕從事，何可恣意有盛怒邪？人誰無過，貴其能改，宜追前愆，深自咎責。今故煩諸葛子瑜重宣吾意。臨書摧愴，心悲淚下。」

**釋讀** 孫皎與甘寧因小事爭執，甘寧稱宗室與其他臣下一樣，不應恃身分辱人。孫權聞訊責書。

**時段與依據** 甘寧之卒及此事未書確年。書信所稱「中間十年」「今者且三十矣」均為相對語，無足以獨立確定的起點。

**釋讀** 孫權勉孫皎以三十而立，在外帶兵督將，當效楚臣昭奚恤揚威北境。

**時段與依據** 同一封責書，借「且三十」及楚國往事勉孫皎。

**釋讀** 孫權指出孫皎酒後侵犯甘寧，甘寧因此請改隸呂蒙；孫權說甘寧雖粗豪，仍是值得任用的人。

**時段與依據** 同一封書，呂蒙在此已有可收甘寧部屬的督任。

**釋讀** 孫權勸孫皎敬簡寬容、自省改過，煩請諸葛瑾轉告自己的意思。

**時段與依據** 承同一封書。

## 孫皎諸子封爵、襲爵與國除

孫權念孫皎的功勞，封其子孫胤為丹楊侯。孫胤無子，死後弟孫晞襲侯，後因罪自殺，封國撤除。孫咨、孫彌、孫儀也都官至將軍並封侯。孫咨任羽林督，後來被滕胤殺害。

**釋讀** 孫權追錄孫皎之功，封其子孫胤為丹楊侯。孫胤卒後，孫晞繼封領兵，後因罪自殺，國除。

## 孫奐接掌江夏，沿用孫皎舊臣

孫皎死後，弟孫奐接管其兵，以揚武中郎將領江夏太守。他循孫皎舊法，禮待劉靖、李允、吳碩、張梁與閭舉，採納他們的建議，受到軍民稱許。

> 吳錄曰：楷處事嚴整不如孫秀，而人聞知名，過也。

**釋讀** 孫楷處事不及孫秀嚴整，人所聞知的名望卻勝過孫秀。

**時段與依據** 這是二人的行事與名望比較。

## 孫桓及孫河一家的前事

孫桓字叔武，父親是孫河。孫河另有孫助、孫誼等子。孫桓善於論議應對，受孫權賞識。

<a id="period-sgz051-b-2466-1"></a>

<a id="wu051-l82-1"></a>

**[《三國志·宗室傳》正文](../../拆分史书/三国志/卷051.md#edition-wu051-l82-1)** · [TXT L82](../../拆分史书/三国志/卷051.txt#L82)

> 孫桓字叔武，河之子也。

**釋讀** 孫桓字叔武，是孫河之子。

**時段與依據** 傳首交代家世，孫桓的武職和戰功另見下文。

<a id="period-sgz051-p-020-1"></a>

<a id="wu051-l83-1"></a>

**[《三國志·宗室傳》裴注 020](../../拆分史书/三国志/卷051.md#edition-wu051-l83-1)** · [TXT L83](../../拆分史书/三国志/卷051.txt#L83)

> 吳書曰：河有四子。長助，曲阿長。次誼，海鹽長。並早卒。次桓，儀容端正，器懷聦朗，博學彊記，能論議應對，權常稱爲宗室顏淵，擢爲武衞都尉。

**釋讀** 孫河的長子孫助任曲阿長，次子孫誼任海鹽長，兩人都早卒。孫桓善於論議，孫權將他比作顏淵，提拔為武衛都尉。

**時段與依據** 兩兄的任官和早卒、孫桓獲任武衛都尉皆無確年；武衛都尉是隨軍前的履歷。

## 孫桓督牛渚、築橫江塢

夷陵戰後，孫桓下督牛渚，修築橫江塢，期間去世。

<a id="period-sgz051-b-2466-5"></a>

<a id="wu051-l84-4"></a>

**[《三國志·宗室傳》正文](../../拆分史书/三国志/卷051.md#edition-wu051-l84-4)** · [TXT L84](../../拆分史书/三国志/卷051.txt#L84)

> 下督牛渚，作橫江塢，會卒。

**釋讀** 孫桓下督牛渚，築橫江塢，適逢去世。

**時段與依據** 本傳以夷陵受賞為前限。赴任、築塢和卒均無確年。標點 TXT 作「牛渚」，舊引作「牛港」。

## 孫俊諸子與孫丞在吳任職

孫俊死後，長子孫建襲爵，任平虜將軍。少子孫慎任鎮南將軍。孫慎之子孫丞以文章知名，與顧榮一同在吳廷侍從。

<a id="period-sgz051-p-021-3"></a>

<a id="wu051-l85-2"></a>

**[《三國志·宗室傳》裴注 021](../../拆分史书/三国志/卷051.md#edition-wu051-l85-2)** · [TXT L85](../../拆分史书/三国志/卷051.txt#L85)

> 長子建襲爵，平虜將軍。少子慎，鎮南將軍。慎子丞，字顯世。　

**釋讀** 孫建襲爵，孫慎任鎮南將軍。孫慎之子孫丞，字顯世。

**時段與依據** 孫俊卒在250年，子孫仕歷只有相對先後。《晉書·陸機傳》附傳作「孫拯」，同字顯世。

<a id="period-sgz051-p-021-4"></a>

<a id="wu051-l85-3"></a>

**[《三國志·宗室傳》裴注 021](../../拆分史书/三国志/卷051.md#edition-wu051-l85-3)** · [TXT L85](../../拆分史书/三国志/卷051.txt#L85)

> 文士傳曰：丞好學，有文章，作螢火賦行於世。爲黃門侍郎，與顧榮俱爲侍臣。歸命世內侍多得罪尤，惟榮、丞獨獲全。常使二人記事，丞荅顧問，乃下詔曰：「自今已後，用侍郎皆當如今宗室丞、顧榮疇也。」

**釋讀** 孫丞好學能文，撰有《螢火賦》。他任黃門侍郎，與顧榮同在孫皓宮中侍從、記事；孫皓曾以二人為用人標準。

**時段與依據** 見孫皓在位期間，確年未詳。《晉書》附傳同敘孫拯、顧榮在孫皓時獲全。

## 孫丞入晉後任涿令

晉滅吳後，孫丞出任范陽涿縣令，有政績。

<a id="period-sgz051-p-021-6"></a>

<a id="wu051-l85-5"></a>

**[《三國志·宗室傳》裴注 021](../../拆分史书/三国志/卷051.md#edition-wu051-l85-5)** · [TXT L85](../../拆分史书/三国志/卷051.txt#L85)

> 爲范陽涿令，甚有稱績。

**釋讀** 孫丞任范陽涿令，治績受到稱譽。

**時段與依據** 在280年赴洛後、入陸機幕府前，赴任時間無確年。

## 陳壽論孫氏宗室

陳壽以親族應當互相扶助為義，記孫氏宗親參與創業、鎮守邊地的事跡。

<a id="period-sgz051-b-2467-1"></a>

<a id="wu051-l87-1"></a>

**[《三國志·宗室傳》正文](../../拆分史书/三国志/卷051.md#edition-wu051-l87-1)** · [TXT L87](../../拆分史书/三国志/卷051.txt#L87)

> 評曰：夫親親恩義，古今之常。宗子維城，詩人所稱。況此諸孫，或贊興初基，或鎮據邊垂，克堪厥任，不忝其榮者乎！故詳著云。

**釋讀** 陳壽引《詩》「宗子維城」，肯定孫氏宗室協助建立基業、守衛邊境的作用。

**時段與依據** 卷末總評。

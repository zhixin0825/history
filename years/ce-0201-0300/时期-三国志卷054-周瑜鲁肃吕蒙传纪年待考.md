## 周瑜的鄉里與家世

周瑜有二子一女。兒子周循娶公主孫魯班，拜騎都尉，有父親的風範，早逝。

<a id="period-sgz054-p-001-1"></a>

<a id="period-sgz054-p-001-2"></a>

<a id="wu054-l6-1"></a>

**[《三國志·周瑜魯肅呂蒙傳》裴注 001](../../拆分史书/三国志/卷054.md#edition-wu054-l6-1)** · [TXT L6](../../拆分史书/三国志/卷054.txt#L6)

> 謝承後漢書曰：景字仲嚮，少以廉能見稱，以明學察孝廉，辟公府。後爲豫州刺史，辟汝南陳蕃爲別駕，潁川李膺、荀緄、杜密、沛國朱㝢爲從事，皆天下英俊之士也。

**釋讀** 周景字仲嚮，少以廉能著稱，因通經學被察為孝廉，受公府辟召。後任豫州刺史，辟陳蕃為別駕，李膺、荀緄、杜密、朱㝢為從事。

**時段與依據** 本注未載察舉及辟召年月。《後漢書·周景傳》有其辟梁冀府、任豫州刺史的先後，字作「仲饗」。

**[《三國志·周瑜魯肅呂蒙傳》裴注 001](../../拆分史书/三国志/卷054.md#edition-wu054-l6-3)** · [TXT L6](../../拆分史书/三国志/卷054.txt#L6)

> 張璠漢紀曰：景父榮，章、和世爲尚書令。初景歷位牧守，好善愛士，每歲舉孝廉，延請入，上後堂，與家人宴會，如此者數四。及贈送旣備，又選用其子弟，常稱曰：「移臣作子，於之何有？」先是，司徒韓縯爲河內太守，在公無私，所舉一辭而已，後亦不及其門戶，曰：「我舉若可矣，不令恩偏稱一家也。」當時論者，或兩譏焉。

**釋讀** 張璠記周景之父周榮在章帝、和帝時任尚書令。周景任州郡長官時禮遇人才，常邀所舉孝廉入後堂與家人多次宴飲，贈送財物，還延用其子弟，認為待部屬如子有何不可。前任河內太守韓縯只在被舉者臨行時致辭，不再照顧其家人，免使恩惠偏及一門。當時有人對二者都有批評。

**時段與依據** 《後漢書·周榮傳》記榮為周景祖父，周景是周興之子。榮在章帝時出仕，和帝時升任尚書令。周景、韓縯在河內的薦士舊事均無確年；范書作「韓演」。

## 孫權下令保護周瑜、程普的故客

孫權下令，周瑜和程普故有賓客，一律不得追問。

<a id="period-sgz054-b-2568-7"></a>

<a id="wu054-l37-2"></a>

**[《三國志·周瑜魯肅呂蒙傳》正文](../../拆分史书/三国志/卷054.md#edition-wu054-l37-2)** · [TXT L37](../../拆分史书/三国志/卷054.txt#L37)

> 後著令曰：「故將軍周瑜、程普，其有人客，皆不得問。」

**釋讀** 孫權另外下令，周瑜與程普故有賓客，官府不得追問。

**時段與依據** 令稱周瑜、程普均為故將軍，發令年月未載，置於兩人死後。

## 周瑜以臣禮事孫權

孫策與周瑜友善，太妃也命孫權待周瑜如兄。孫權任將軍時，群下行禮仍簡略，周瑜先以臣禮事之。

<a id="period-sgz054-b-2569-1"></a>

<a id="wu054-l37-3"></a>

**[《三國志·周瑜魯肅呂蒙傳》正文](../../拆分史书/三国志/卷054.md#edition-wu054-l37-3)** · [TXT L37](../../拆分史书/三国志/卷054.txt#L37)

> 初瑜見友於策，太妃又使權以兄奉之。是時權位爲將軍，諸將賔客爲禮尚簡，而瑜獨先盡敬，便執臣節。

**釋讀** 孫策與周瑜友善，太妃又命孫權以兄禮奉周瑜；孫權居將軍位，周瑜率先以臣子之禮事之。

**時段與依據** 本傳回顧孫策在時與孫權為將軍時的交往，太妃命令與行禮確年均無載。

## 程普從輕慢到敬重周瑜

周瑜器量寬宏，與程普起初不睦。程普倚仗年長屢次輕慢周瑜，周瑜總能謙讓，程普終於折服，把交往比作飲美酒、不知不覺便醉。

<a id="period-sgz054-b-2569-2"></a>

<a id="wu054-l37-4"></a>

**[《三國志·周瑜魯肅呂蒙傳》正文](../../拆分史书/三国志/卷054.md#edition-wu054-l37-4)** · [TXT L37](../../拆分史书/三国志/卷054.txt#L37)

> 性度恢廓，大率爲得人，惟與程普不睦。

**釋讀** 周瑜器量寬宏，多能得人，與程普卻一度不睦。

**時段與依據** 本傳總敘性情與交往；裴注補述二人從不睦到相重。

**[《三國志·周瑜魯肅呂蒙傳》裴注 011](../../拆分史书/三国志/卷054.md#edition-wu054-l38-1)** · [TXT L38](../../拆分史书/三国志/卷054.txt#L38)

> 江表傳曰：普頗以年長數陵侮瑜。瑜折節容下，終不與校。普後自敬服而親重之，乃告人曰：「與周公瑾交，若飲醇醪，不覺自醉。」時人以其謙讓服人如此。

**釋讀** 程普憑年長屢次欺侮周瑜，周瑜謙抑忍讓，程普後來敬服親重，以飲美酒比喻二人的交往。

**時段與依據** 《江表傳》補述周瑜與程普相處的變化，沒有年月。

## 周瑜聲望與曹操、劉備的疑忌

周瑜軍功顯著，聲名傳遠，曹操和劉備都對他有所顧忌。

<a id="period-sgz054-p-011-6"></a>

<a id="wu054-l38-5"></a>

**[《三國志·周瑜魯肅呂蒙傳》裴注 011](../../拆分史书/三国志/卷054.md#edition-wu054-l38-5)** · [TXT L38](../../拆分史书/三国志/卷054.txt#L38)

> 瑜威聲遠著，故曹公、劉備咸欲疑譖之。

**釋讀** 《江表傳》以周瑜聲望甚高，解釋曹操、劉備何以想設法使人疑忌他。

**時段與依據** 這是裴注所引史料的總評，未敘單一可定年的行動。

## 周瑜善辨音律

周瑜自幼精研音樂，飲酒之後仍能察覺演奏失誤，時人說「曲有誤，周郎顧」。

<a id="period-sgz054-b-2570-1"></a>

<a id="wu054-l40-1"></a>

**[《三國志·周瑜魯肅呂蒙傳》正文](../../拆分史书/三国志/卷054.md#edition-wu054-l40-1)** · [TXT L40](../../拆分史书/三国志/卷054.txt#L40)

> 瑜少精意於音樂，雖三爵之後，其有闕誤，瑜必知之，知之必顧，故時人謠曰：「曲有誤，周郎顧。」

**釋讀** 周瑜自幼研習音樂，三杯酒後仍能聽出曲中錯誤而回顧演奏者，因而有「曲有誤，周郎顧」的歌謠。

**時段與依據** 本傳記才能與時人歌謠，起年不可考。

## 周胤領兵屯公安，後獲罪徙廬陵

周胤起初任興業都尉，娶孫氏宗室女，領兵千人屯公安。黃龍元年封都鄉侯後，因罪徙居廬陵。

## 周峻因周瑜之功授官，周護未獲任用

周瑜侄兒周峻因其舊功任偏將軍，領吏士千人。周峻死後，全琮推舉周峻子周護；孫權仍念周瑜之功，但因周護品行不佳，終未任用。

> 峻卒，全琮表峻子護爲將。權曰：「昔走曹操，拓有荊州，皆是公瑾，常不忘之。初聞峻亡，仍欲用護，聞護性行危險，用之適爲作禍，故便止之。孤念公瑾，豈有已乎？」

**釋讀** 周峻去世，全琮表薦其子周護。孫權追念周瑜破曹操、取荊州之功，原想起用周護，因聽說他品行險惡，怕他生禍而止。

**時段與依據** 周峻卒年和全琮薦舉的確切年月未載。

## 孫權問劉備取蜀之議

周瑜和甘寧力主乘劉璋守勢衰弱而取蜀。孫權徵詢劉備，劉備也想圖取益州，以與劉璋同宗、願共扶漢室為由，請孫權寬待劉璋。

<a id="period-sgz054-b-2583-1"></a>

<a id="wu054-l74-1"></a>

**[《三國志·周瑜魯肅呂蒙傳》正文](../../拆分史书/三国志/卷054.md#edition-wu054-l74-1)** · [TXT L74](../../拆分史书/三国志/卷054.txt#L74)

> 先是，益州牧劉璋綱維頹弛，周瑜、甘寧並勸權取蜀，權以咨備，備內欲自規，乃偽報曰：「備與璋託爲宗室，兾憑英靈，以匡漢朝。今璋得罪左右，備獨竦懼，非所敢聞，願加寬貸。若不獲請，備當放髮歸於山林。」

**釋讀** 周瑜、甘寧見劉璋守勢衰弛，勸孫權取蜀。孫權問劉備，劉備自己也想取蜀，託詞與劉璋同宗，請孫權寬待劉璋。

**時段與依據** 《先主傳》裴注引《獻帝春秋》亦有劉備反對孫權取蜀之說。此處追敘諸人先前之議，周瑜卒於210，各次議論未分年月。

## 魯淑鎮守武昌、夏口

魯肅的遺腹子魯淑成年後受到濡須督張承器重。永安年間，魯淑任昭武將軍、都亭侯、武昌督；建衡年間獲假節，改督夏口，所部軍紀嚴明。

> 肅遺腹子淑旣壯，濡須督張承謂終當到至。永安中，爲昭武將軍、都亭侯、武昌督。建衡中，假節，遷夏口督。所在嚴整，有方幹。

## 呂蒙請保留故將子弟部曲

成當、宋定、徐顧去世後，孫權要將其部眾撥給呂蒙。呂蒙三次上書請保存故將子弟所部，又為他們延師輔導。

<a id="period-sgz054-b-2588-3"></a>

<a id="wu054-l97-1"></a>

**[《三國志·周瑜魯肅呂蒙傳》正文](../../拆分史书/三国志/卷054.md#edition-wu054-l97-1)** · [TXT L97](../../拆分史书/三国志/卷054.txt#L97)

> 時蒙與成當、宋定、徐顧屯次比近，三將死，子弟幼弱，權悉以兵并蒙。蒙固辭，陳啟顧等皆勤勞國事，子弟雖小，不可廢也。書三上，權乃聽。蒙於是又爲擇師，使輔導之，其操心率如此。

**釋讀** 同駐鄰近軍營的成當、宋定、徐顧去世。孫權要把三部併給呂蒙，呂蒙三次上書辭讓，請給有功舊將的年幼子弟保留部曲，再為他們延師。

**時段與依據** 成當等三人卒年無記，原文先後敘事不足以與上條會面同年。

## 呂蒙挫謝奇於皖田鄉

曹操所任的蘄春典農謝奇屯兵皖田鄉，多次擾邊。呂蒙伺機襲擊，謝奇退縮，部下孫子才、宋豪等帶家眷歸吳。

<a id="period-sgz054-b-2589-1"></a>

<a id="wu054-l99-1"></a>

**[《三國志·周瑜魯肅呂蒙傳》正文](../../拆分史书/三国志/卷054.md#edition-wu054-l99-1)** · [TXT L99](../../拆分史书/三国志/卷054.txt#L99)

> 魏使廬江謝奇爲蘄春典農，屯皖田鄉，數爲邊寇。蒙使人誘之，不從，則伺隙襲擊，奇遂縮退，其部伍孫子才、宋豪等，皆攜負老弱，詣蒙降。

**釋讀** 謝奇屯田皖田鄉，不時侵擾吳境。呂蒙誘其出戰未成，伺機襲擊使其退縮，謝奇部眾孫子才、宋豪等攜老弱歸附。

**時段與依據** 此段在呂蒙拒曹於濡須前，謝奇屯田和部伍歸降的確年未詳。底本「魏」為回稱。

## 呂蒙返尋陽後平廬陵

呂蒙返回尋陽後不到一年，廬陵起兵。諸將未能平定，孫權改派呂蒙。呂蒙誅首惡，釋放其餘人，使其復為平民。

<a id="period-sgz054-b-2590-4"></a>

<a id="wu054-l105-2"></a>

**[《三國志·周瑜魯肅呂蒙傳》正文](../../拆分史书/三国志/卷054.md#edition-wu054-l105-2)** · [TXT L105](../../拆分史书/三国志/卷054.txt#L105)

> 蒙還尋陽，未期而廬陵賊起，諸將討擊不能禽，權曰：「鷙鳥累百，不如一鶚。」復令蒙討之。蒙至，誅其首惡，餘皆釋放，復爲平民。

**釋讀** 呂蒙回尋陽未滿一年，廬陵有亂。孫權命呂蒙出討；他只誅首惡，其餘人釋為平民。

**時段與依據** 從214攻皖後敘來，回尋陽後「未期」，下接215三郡爭，未能判定為214或215。

## 孫權與陸遜品評周瑜、魯肅、呂蒙

<a id="period-sgz054-b-2599-1"></a>

<a id="period-sgz054-b-2600-1"></a>

<a id="period-sgz054-b-2600-2"></a>

<a id="period-sgz054-b-2600-3"></a>

<a id="period-sgz054-b-2600-4"></a>

<a id="period-sgz054-b-2600-5"></a>

<a id="wu054-l125-1"></a>

**[《三國志·周瑜魯肅呂蒙傳》正文](../../拆分史书/三国志/卷054.md#edition-wu054-l125-1)** · [TXT L125](../../拆分史书/三国志/卷054.txt#L125)

> 孫權與陸遜論周瑜、魯肅及蒙曰：「公瑾雄烈，膽略兼人，遂破孟德，開拓荊州，邈焉難繼，君今繼之。公瑾昔要子敬來東，致達於孤，孤與宴語，便及大略帝王之業，此一快也。後孟德因獲劉琮之勢，張言方率數十萬衆水步俱下。孤普請諸將，咨問所宜，無適先對，至子布、文表，俱言宜遣使脩檄迎之，子敬即駮言不可，勸孤急呼公瑾，付任以衆，逆而擊之，此二快也。且其決計策，意出張蘇遠矣；後雖勸吾借玄德地，是其一短，不足以損其二長也。周公不求備於一人，故孤忘其短而貴其長，常以比方鄧禹也。又子明少時，孤謂不辭劇易，果敢有膽而已；及身長大，學問開益，籌略奇至，可以次於公瑾，但言議英發不及之耳。圖取關羽，勝於子敬。子敬荅孤書云：『帝王之起，皆有驅除，羽不足忌。』此子敬內不能辨，外爲大言耳，孤亦恕之，不苟責也。然其作軍，屯營不失，令行禁止，部界無廢負，路無拾遺，其法亦美也。」

**釋讀** 孫權以陸遜繼周瑜；稱魯肅初見即談帝業、赤壁力主抗曹，雖曾勸借地給劉備，仍深得其器重。呂蒙由果敢進而多學善謀，襲取荊州的謀劃勝過魯肅；魯肅治軍嚴整也自有可取。

**時段與依據** 回顧建安五年魯肅入幕、十三年議抗曹、十五年借地與二十四年擒關羽。《資治通鑑》卷068於呂蒙死後以「權後」引述；談話的確年未詳。

## 卷末合評周瑜、魯肅、呂蒙

<a id="period-sgz054-b-2601-1"></a>

<a id="period-sgz054-b-2601-2"></a>

<a id="wu054-l127-1"></a>

**[《三國志·周瑜魯肅呂蒙傳》正文](../../拆分史书/三国志/卷054.md#edition-wu054-l127-1)** · [TXT L127](../../拆分史书/三国志/卷054.txt#L127)

> 評曰：曹公乘漢相之資，挾天子而掃羣桀，新盪荊城，仗威東夏，于時議者莫不疑貳。周瑜、魯肅建獨斷之明，出衆人之表，實奇才也。呂蒙勇而有謀斷，識軍計，譎郝普，禽關羽，最其妙者。初雖輕果妄殺，終於克己，有國士之量，豈徒武將而已乎！孫權之論，優劣允當，故載錄焉。

**釋讀** 陳壽稱許周瑜、魯肅在曹操聲勢最盛時力主抗曹，也肯定呂蒙說降郝普、擒關羽展現的謀略；呂蒙從年輕時輕率殺人到後來能克己，有國士器度。

**時段與依據** 史評並論建安十三年赤壁、二十年說降郝普、二十四年擒關羽及呂蒙生平。

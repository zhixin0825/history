## 程普早歲與孫氏起兵

程普早年任州郡吏，後隨孫堅征戰，屢有創傷。

> 程普字德謀，右北平土垠人也。初爲州郡吏，有容貌計略，善於應對。

**釋讀** 程普字德謀，右北平土垠人，曾任州郡小吏，善於應對而有計略。

## 程普在吳、丹楊的戰事

孫策定會稽前，程普已隨軍進兵數縣。其後他移駐丹楊石城，平定多處反抗，也曾救孫策脫離祖郎的包圍。

<a id="wu055-l7-4"></a>

**[《三國志·程黃韓蔣周陳董甘凌徐潘丁傳》正文](../../sources/本地分卷/三国志/三国志-卷055.md#edition-wu055-l7-4)** · [TXT L7](../../sources/本地分卷/三国志/三国志-卷055.txt#L7)

> 進破烏程、石木、波門、陵傳、餘杭，普功爲多。

**釋讀** 孫策軍取烏程、石木、波門、陵傳、餘杭，程普功多。

**時段與依據** 本傳列於破曲阿以後及入會稽以前；餘杭、烏程亦見《孫策傳》裴注《吳錄》的後續部署，具體戰事不作強合。

## 黃蓋歷任縣長及丹楊都尉

黃蓋面對山越及縣境反抗，屢出任縣長。石城嚴懲犯法的掾吏，後又調任春穀、尋陽，最終遷丹楊都尉。

<a id="period-sgz055-b-2610-1"></a>

<a id="wu055-l21-1"></a>

**[《三國志·程黃韓蔣周陳董甘凌徐潘丁傳》正文](../../sources/本地分卷/三国志/三国志-卷055.md#edition-wu055-l21-1)** · [TXT L21](../../sources/本地分卷/三国志/三国志-卷055.txt#L21)

> 諸山越不賔，有寇難之縣，輙用蓋爲守長。石城縣吏，特難檢御，蓋乃署兩掾，分主諸曹。教曰：「令長不德，徒以武功爲官，不以文吏爲稱。今賊寇未平，有軍旅之務，一以文書委付兩掾，當檢攝諸曹，糾擿謬誤。兩掾所署，事入諾出，若有姦欺，終不加以鞭杖，宜各盡心，無爲衆先。」初皆怖威，夙夜恭職；久之，吏以蓋不視文書，漸容人事。蓋亦嫌外懈怠，時有所省，各得兩掾不奉法數事。乃悉請諸掾吏，賜酒食，因出事詰問。兩掾辭屈，皆叩頭謝罪。蓋曰：「前已相勑，終不以鞭杖相加，非相欺也。」遂殺之。縣中震慄。

**釋讀** 山越不服、縣境有事時，黃蓋常被派任守長。任石城長時，他讓兩掾分管各曹，表明有作奸者也不施鞭杖。兩人初畏懼而盡職，後來徇私。黃蓋查得違法事實，召諸掾飲酒，席間詰問兩人。他們叩頭請罪，黃蓋依其先言不用鞭杖，將兩人處死，縣中震懼。

**時段與依據** [《資治通鑑》卷064建安八年](../../sources/资治通鉴/KR2b0007_064.txt#L239-L241) 記黃蓋等任劇縣令長，本傳未載石城事的具體年份。

<a id="period-sgz055-b-2610-2"></a>

<a id="wu055-l21-2"></a>

**[《三國志·程黃韓蔣周陳董甘凌徐潘丁傳》正文](../../sources/本地分卷/三国志/三国志-卷055.md#edition-wu055-l21-2)** · [TXT L21](../../sources/本地分卷/三国志/三国志-卷055.txt#L21)

> 後轉春穀長，尋陽令。凡守九縣，所在平定。遷丹楊都尉，抑彊扶弱，山越懷附。

## 黃蓋平武陵、益陽及身後追思

黃蓋曾出任武陵太守，平定武陵後又平益陽山賊，後病卒在任。當地百姓思念他，曾畫像按時祭祀。

<a id="period-sgz055-b-2611-4"></a>

<a id="wu055-l25-2"></a>

**[《三國志·程黃韓蔣周陳董甘凌徐潘丁傳》正文](../../sources/本地分卷/三国志/三国志-卷055.md#edition-wu055-l25-2)** · [TXT L25](../../sources/本地分卷/三国志/三国志-卷055.txt#L25)

> 武陵蠻夷反亂，攻守城邑，乃以蓋領太守。時郡兵才五百人，自以不敵，因開城門，賊半入，乃擊之，斬首數百，餘皆奔走，盡歸邑落。誅討魁帥，附從者赦之。自春訖夏，寇亂盡平，諸幽邃巴、醴、由、誕邑侯君長，皆改操易節，奉禮請見，郡境遂清。

**釋讀** 武陵有部眾攻佔城邑，黃蓋出任太守，以五百郡兵誘對方入城，趁半數已入時出擊，殺數百人，餘眾逃歸邑落。黃蓋誅其首領，赦免附從者，從春到夏平亂，巴、醴、由、誕等邑侯君長亦上禮求見。

**時段與依據** 本傳只記春夏，未載年次。《孫皎傳》說黃蓋卒後其兵併入孫皎麾下，孫皎219年卒，提供相關事蹟的時間上限。

## 甘宁率敢死士夜袭濡须

<a id="period-sgz055-b-2642-1"></a>

<a id="wu055-l105-1"></a>

**[《三國志·程黃韓蔣周陳董甘凌徐潘丁傳》正文](../../sources/本地分卷/三国志/三国志-卷055.md#edition-wu055-l105-1)** · [TXT L105](../../sources/本地分卷/三国志/三国志-卷055.txt#L105)

> 後曹公出濡須，寧爲前部督，受勑出斫敵前營。權特賜米酒衆殽，寧乃料賜手下百餘人食。食畢，寧先以銀盌酌酒，自飲兩盌，乃酌與其都督。都督伏，不肯時持。寧引白削置膝上，呵謂之曰：「卿見知於至尊，孰與甘寧？甘寧尚不惜死，卿何以獨惜死乎？」都督見寧色厲，即起拜待酒次，通酌兵各一銀盌。至二更時，銜枚出斫敵。敵驚動，遂退。寧益貴重，增兵二千人。

**釋讀** 曹操出濡须，甘宁督领前部，受命袭曹军前营。孙权赐酒食，甘宁与部下百余人分食，再饮酒激励都督和士卒，二更含枚袭营，惊退敌军，此后又增领二千兵。

**時段與依據** 候选为[建安十八年](ce-0213.md#ce0213-note-1)及[建安二十二年](ce-0217.md#ce0217-note-1)两次濡须之战。本传此段置于攻皖与合肥之间，然而建安十九年攻皖又倒叙于建安二十年相拒益阳后，不能据篇次坐实。

<a id="period-sgz055-p-016-1"></a>

<a id="wu055-l106-1"></a>

**[《三國志·程黃韓蔣周陳董甘凌徐潘丁傳》裴注 016](../../sources/本地分卷/三国志/三国志-卷055.md#edition-wu055-l106-1)** · [TXT L106](../../sources/本地分卷/三国志/三国志-卷055.txt#L106)

> 江表傳曰：「曹公出濡須，號步騎四十萬，臨江飲馬。權率衆七萬應之，使寧領三千人爲前部督。權密勑寧，使夜入魏軍。寧乃選手下健兒百餘人，徑詣曹公營下，使拔鹿角，踰壘入營，斬得數十級。北軍驚駭鼓譟，舉火如星，寧已還入營，作鼓吹，稱萬歲。因夜見權，權喜曰：「足以驚駭老子否？聊以觀卿膽耳。」即賜絹千匹，刀百口。權曰：「孟德有張遼，孤有興霸，足相敵也。」停住月餘，北軍便退。

**釋讀** 《江表传》称曹军号步骑四十万，孙权举七万应敌，以甘宁督三千。甘宁奉密敕率百余人拔鹿角、翻营垒、斩数十人，乱中撤回。孙权赐绢千匹、刀百口，称甘宁可敌张辽。曹军驻一个多月才退。

**時段與依據** 同一夜袭，注给两军兵数是该书口径；其余细节不足以独定为某次濡须之战。

## 孙权、吕蒙调解甘宁与凌统之怨

<a id="period-sgz055-p-017-1"></a>

<a id="wu055-l109-1"></a>

**[《三國志·程黃韓蔣周陳董甘凌徐潘丁傳》裴注 017](../../sources/本地分卷/三国志/三国志-卷055.md#edition-wu055-l109-1)** · [TXT L109](../../sources/本地分卷/三国志/三国志-卷055.txt#L109)

> 吳書曰：凌統怨寧殺其父操，寧常備統，不與相見。權亦命統不得讎之。甞於呂蒙舍會，酒酣，統乃以刀舞。寧起曰：「寧能雙戟舞。」蒙曰：「寧雖能，未若蒙之巧也。」因操刀持楯，以身分之。後權知統意，因令寧將兵，遂徙屯於半州。

**釋讀** 凌统怨甘宁杀父，甘宁防他，不相会见，孙权也不许凌统报仇。一次在吕蒙家酒酣舞刀，甘宁说能舞双戟，吕蒙拿刀和盾立在二人之间。后孙权知凌统心意，命甘宁领兵移驻半州。

**時段與依據** 此怨起自凌操战死，宴席、移屯确年都未载。逍遥津同战不能为此段定年。

> 寧厨下兒曾有過，走投呂蒙。蒙恐寧殺之，故不即還。後寧齎禮禮蒙母，臨當與升堂，乃出厨下兒還寧。寧許蒙不殺。斯須還船，縛置桑樹，自挽弓射殺之。畢，勑船人更增舸纜，解衣卧船中。蒙大怒，擊鼓會兵，欲就船攻寧。寧聞之，故卧不起。蒙母徒跣出諫蒙曰：「至尊待汝如骨肉，屬汝以大事，何有以私怒而欲攻殺甘寧？寧死之日，縱至尊不問，汝是爲臣下非法。」蒙素至孝，聞母言，即豁然意釋，自至寧舩，笑呼之曰：「興霸，老母待卿食，急上！」寧涕泣歔欷曰：「負卿。」與蒙俱還見母，歡宴竟日。

**釋讀** 甘宁厨下少年犯过投吕蒙，吕蒙怕被杀未即交还。甘宁行礼拜吕蒙之母，得到少年，许诺不杀，却回船把人缚在桑树上射死。吕蒙怒而击鼓聚兵，母亲赤脚出来，劝他勿为私怒擅杀同僚。吕蒙随即释怒，到甘宁船边请他上岸。甘宁流泪认负，二人见母宴饮终日。

**時段與依據** 只知在甘宁、吕蒙共同任事时，无确年。

## 凌統夜迎盛暹

<a id="period-sgz055-b-2651-1"></a>

<a id="wu055-l127-1"></a>

**[《三國志·程黃韓蔣周陳董甘凌徐潘丁傳》正文](../../sources/本地分卷/三国志/三国志-卷055.md#edition-wu055-l127-1)** · [TXT L127](../../sources/本地分卷/三国志/三国志-卷055.txt#L127)

> 時有薦同郡盛暹於權者，以爲梗槩大節有過於統，權曰：「且令如統足矣。」後召暹夜至，時統已卧，聞之，攝衣出門，執其手以入。其愛善不害如此。

**釋讀** 有人薦盛暹，認為他的剛直氣節勝過凌統。孫權說能像凌統便夠了。盛暹夜間被召到，凌統已睡下，聞訊立刻披衣出門，握住他的手一同進去。

**時段與依據** 本傳無年月，所敘用於寫凌統愛善而無嫉害。

## 凌統撫募山中壯士與病卒

<a id="period-sgz055-b-2652-1"></a>

<a id="wu055-l129-1"></a>

**[《三國志·程黃韓蔣周陳董甘凌徐潘丁傳》正文](../../sources/本地分卷/三国志/三国志-卷055.md#edition-wu055-l129-1)** · [TXT L129](../../sources/本地分卷/三国志/三国志-卷055.txt#L129)

> 統以山中人尚多壯悍，可以威恩誘也，權令東占且討之，命勑屬城，凡統所求，皆先給後聞。統素愛士，士亦慕焉。得精兵萬餘人，過本縣，步入寺門，見長吏懷三版，恭敬盡禮，親舊故人，恩意益隆。

**釋讀** 凌統認為山中尚多壯士，可用威德招撫。孫權令他往東招撫兼征討，命所屬諸城先行給付其所請，後再上報。凌統得精兵萬餘人。經過故鄉餘杭時，他步行進入官署，懷名版禮見長吏，厚待故舊。

**時段與依據** 本傳次於合肥戰後，未標招募年；本縣為凌統籍貫餘杭。

<a id="period-sgz055-b-2652-2"></a>

<a id="wu055-l129-2"></a>

**[《三國志·程黃韓蔣周陳董甘凌徐潘丁傳》正文](../../sources/本地分卷/三国志/三国志-卷055.md#edition-wu055-l129-2)** · [TXT L129](../../sources/本地分卷/三国志/三国志-卷055.txt#L129)

> 事畢當出，會病卒，時年四十九。權聞之，拊牀起坐，哀不能自止，數日減膳，言及流涕，使張承爲作銘誄。

**釋讀** 招募完畢，凌統將率部出發，遇病去世，本傳說享年四十九。孫權悲痛減膳，命張承作銘誄。

**時段與依據** 卷057〈駱統傳〉先敘凌統去世後兼領其兵，再敘夷陵與濡須。217年既有考證轉引《建康實錄》繫於建安二十二年、年二十九；兩記年齡不同，卷055正文也未明載卒年，先以合肥戰後、駱統黃武七年（228）去世以前為界。凌統若在孫權掌軍後以十五歲承父兵，至228年未滿四十九，兩個年齡也難與駱統的事序相合。 [217 年舊注](ce-0217.md#ce0217-note-3) · [卷057〈駱統傳〉](../../sources/本地分卷/三国志/三国志-卷057.md#txt-l85)。

## 孫權撫育凌統二子

<a id="period-sgz055-b-2653-1"></a>

<a id="wu055-l131-1"></a>

**[《三國志·程黃韓蔣周陳董甘凌徐潘丁傳》正文](../../sources/本地分卷/三国志/三国志-卷055.md#edition-wu055-l131-1)** · [TXT L131](../../sources/本地分卷/三国志/三国志-卷055.txt#L131)

> 二子烈、封，年各數歲，權內養於宮，愛待與諸子同，賔客進見，呼示之曰：「此吾虎子也。」及八九歲，令葛光教之讀書，十日一令乘馬，追錄統功，封烈亭侯，還其故兵。後烈有罪免，封復襲爵領兵。

**釋讀** 孫權將凌烈、凌封養在宮中，視同己子，向賓客稱他們為虎子。二人稍長，孫權令葛光教他們讀書，每十日讓他們騎馬一次。孫權追錄凌統功勞，封凌烈為亭侯，還其父舊部；凌烈因罪免爵，凌封承襲並領兵。

**時段與依據** 收養、讀書習騎、授爵和承襲前後數年，均無明確年次，保留本傳相承次序。

<a id="period-sgz055-p-019-1"></a>

<a id="wu055-l132-1"></a>

**[《三國志·程黃韓蔣周陳董甘凌徐潘丁傳》裴注 019](../../sources/本地分卷/三国志/三国志-卷055.md#edition-wu055-l132-1)** · [TXT L132](../../sources/本地分卷/三国志/三国志-卷055.txt#L132)

> 孫盛曰：觀孫權之養士也，傾心竭思，以求其死力，泣周泰之夷，殉陳武之妾，請呂蒙之命，育凌統之孤，卑曲苦志，如此之勤也。是故雖令德無聞，仁澤內著，而能屈彊荊吳，僭擬年歲者，抑有由也。

**釋讀** 孫盛以孫權為周泰身上的傷流淚、令陳武之妾殉葬、為呂蒙求命、撫養凌統遺孤幾事，說明他刻意求將士為之效死。

**時段與依據** 裴注評孫權待將士之道，以數傳事例作比較，隨凌統遺孤事讀。

<a id="period-sgz055-p-019-2"></a>

<a id="wu055-l132-2"></a>

**[《三國志·程黃韓蔣周陳董甘凌徐潘丁傳》裴注 019](../../sources/本地分卷/三国志/三国志-卷055.md#edition-wu055-l132-2)** · [TXT L132](../../sources/本地分卷/三国志/三国志-卷055.txt#L132)

> 然霸王之道，期於大者遠者，是以先王建德義之基，恢信順之宇，制經略之綱，明貴賤之叙，易簡而其親可乆，體全而其功可大，豈踒璅近務，邀利於當年哉？語曰「雖小道，必有可觀者焉，致遠恐泥」，其是之謂乎！

**釋讀** 孫盛再論王霸應立德義、明綱紀、求長遠，引《論語》說小道雖有可觀，施於長遠恐有滯礙。

**時段與依據** 承上為史家評語，仍附在凌統遺孤受養段落。

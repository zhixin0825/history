## 虞翻早年與初任功曹

虞翻是會稽餘姚人，少年好學，言辭直率，後任會稽太守王朗的功曹。

<a id="period-sgz057-b-2714-1"></a>

<a id="wu057-l5-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》正文](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l5-1)** · [TXT L5](../../sources/本地分卷/三国志/三国志-卷057.txt#L5)

> 虞翻字仲翔，會稽餘姚人也，

**釋讀** 虞翻字仲翔，會稽餘姚人。

**時段與依據** 籍貫、名字為傳首資料。

<a id="period-sgz057-p-001-1"></a>

<a id="wu057-l6-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》裴注 001](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l6-1)** · [TXT L6](../../sources/本地分卷/三国志/三国志-卷057.txt#L6)

> 吳書曰：翻少好學，有高氣。年十二，客有候其兄者，不過翻，翻追與書曰：「僕聞虎魄不取腐芥，磁石不受曲鍼，過而不存，不亦宜乎！」客得書奇之，由是見稱。

**釋讀** 虞翻少時好學，有傲氣。十二歲時，客人來拜訪他兄長，未見他，虞翻用琥珀不吸腐芥、磁石不吸曲針而客人過門不問的譬喻致信，客人讀後稱奇，虞翻由此得名。

**時段與依據** 《吳書》只載年齡。卒年雖可用遼東出使事定位約略時段，尚不足確定這封書信的絕對年。

<a id="wu057-l7-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》正文](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l7-1)** · [TXT L7](../../sources/本地分卷/三国志/三国志-卷057.txt#L7)

> 太守王朗命爲功曹。

**釋讀** 會稽太守王朗任虞翻為功曹。

**時段與依據** 卷057裴注《會稽典錄》稱王朗於初平末出任會稽太守，虞翻受命在王朗拒孫策前，所任年月未明。

## 虞翻扈從孫策出山

孫策征討山越時與部下失散，虞翻持矛前導，護送他到大路，再吹角集合部眾。

<a id="period-sgz057-p-005-1"></a>

<a id="wu057-l15-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》裴注 005](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l15-1)** · [TXT L15](../../sources/本地分卷/三国志/三国志-卷057.txt#L15)

> 吳書曰：策討山越，斬其渠帥，悉令左右分行逐賊，獨騎與翻相得山中。翻問左右安在，策曰：「悉行逐賊。」翻曰：「危事也！」令策下馬：「此草深，卒有驚急，馬不及縈策，但牽之，執弓矢以步。翻善用矛，請在前行。」得平地，勸策乘馬。策曰：「卿無馬柰何？」荅曰：「翻能步行，日可三百里，自征討以來，吏卒無及翻者，明府試躍馬，翻能疏步隨之。」行及大道，得一鼓吏，策取角自鳴之，部曲識聲，小大皆出，遂從周旋，平定三郡。　

**釋讀** 孫策討山越，斬其首領，讓隨從四散追敵，身邊只餘虞翻。虞翻認為危險，勸孫策在深草中牽馬執弓步行，自己持矛在前，到平地才勸孫策乘馬，自稱每日可步行三百里，能徒步隨上。兩人到了大路遇鼓吏，孫策吹角召集部曲，此後平定三郡。

**時段與依據** 《吳書》以事證孫策輕騎之險，未明討山越是何年、何役。「平定三郡」總敘其後。

## 虞翻辭徵、往來論學

虞翻曾謝絕漢廷和曹操徵辟，也與孔融、張紘通信談論自己的《易》注和學問。

<a id="period-sgz057-b-2716-2"></a>

<a id="wu057-l19-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》正文](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l19-1)** · [TXT L19](../../sources/本地分卷/三国志/三国志-卷057.txt#L19)

> 後翻州舉茂才，漢召爲侍御史，曹公爲司空辟，皆不就。

**釋讀** 州舉虞翻為茂才。漢廷徵為侍御史、曹操任司空時辟召，他均未就任。

**時段與依據** 在200年孫策死後，曹操建安十三年由司空轉為丞相之前，辟舉各事未載獨立年次。

<a id="period-sgz057-p-007-1"></a>

<a id="wu057-l20-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》裴注 007](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l20-1)** · [TXT L20](../../sources/本地分卷/三国志/三国志-卷057.txt#L20)

> 吳書曰：翻聞曹公辟，曰：「盜跖欲以餘財污良家邪？」遂拒不受。

**釋讀** 虞翻聽說曹操辟召，以盜跖拿餘財來玷污良家為喻，拒絕赴任。

**時段與依據** 《吳書》解釋他拒絕曹操府辟的態度，未記新年次。

<a id="period-sgz057-b-2717-1"></a>

<a id="period-sgz057-b-2717-2"></a>

<a id="wu057-l22-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》正文](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l22-1)** · [TXT L22](../../sources/本地分卷/三国志/三国志-卷057.txt#L22)

> 翻與少府孔融書，并示以所著易注。融荅書曰：「聞延陵之理樂，覩吾子之治易，乃知東南之美者，非徒會稽之竹箭也。又觀象雲物，察應寒溫，原其禍福，與神合契，可謂探賾窮通者也。」會稽東部都尉張紘又與融書曰：「虞仲翔前頗爲論者所侵，美寶爲質，彫摩益光，不足以損。」

**釋讀** 虞翻致書少府孔融，示以自己所著易注。孔融拿延陵季札論樂相比，稱虞翻學識如東南出產的良材，又稱他的易學能推究雲物、寒溫、禍福。會稽東部都尉張紘也致書孔融，說虞翻曾遭議論，但美質如玉，磨礪益光。

**時段與依據** 《後漢書·孔融傳》記其遷少府與208年遇害；《張紘傳》記張紘在孫權初統事時任會稽東部都尉，書信年月均未載。

## 虞翻任騎都尉，徙丹楊涇縣

虞翻曾任騎都尉，因屢次直言進諫及遭毀謗而被徙到丹楊涇縣。

<a id="period-sgz057-b-2718-1"></a>

<a id="wu057-l24-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》正文](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l24-1)** · [TXT L24](../../sources/本地分卷/三国志/三国志-卷057.txt#L24)

> 孫權以爲騎都尉。翻數犯顏諫爭，權不能恱，又性不協俗，多見謗毀，坐徙丹楊涇縣。

**釋讀** 孫權任虞翻為騎都尉。虞翻屢次直諫，孫權不喜，其性與俗不容也屢受毀謗，坐罪徙丹楊涇縣。

**時段與依據** 在孫權繼事後、呂蒙219年圖取關羽以前，授官與遷徙無確年。

## 虞翻两次斥责麋芳

<a id="period-sgz057-b-2721-1"></a>

<a id="wu057-l31-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》正文](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l31-1)** · [TXT L31](../../sources/本地分卷/三国志/三国志-卷057.txt#L31)

> 翻甞乘船行，與麋芳相逢，芳船上人多欲令翻自避，先驅曰：「避將軍船！」翻厲聲曰：「失忠與信，何以事君？傾人二城，而稱將軍，可乎？」芳闔戶不應而遽避之。

**釋讀** 虞翻乘船与麋芳相遇。对方叫他避开将军的船。虞翻斥责失忠失信者不能事君，指麋芳使两座城池陷落，却仍称将军。麋芳关上船门，不作答，匆匆避开。

**時段與依據** 在[219年麋芳降吴](ce-0219.md#ce0219-note-4)后、虞翻徙交州前，哪年相遇未载。

<a id="period-sgz057-b-2721-2"></a>

<a id="wu057-l31-2"></a>

**[《三國志·虞陸張駱陸吾朱傳》正文](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l31-2)** · [TXT L31](../../sources/本地分卷/三国志/三国志-卷057.txt#L31)

> 後翻乘車行，又經芳營門，吏閉門，車不得過。翻復怒曰：「當閉反開，當開反閉，豈得事宜邪？」芳聞之，有慙色。

**釋讀** 虞翻后来乘车经过麋芳营门，吏员关门阻住。他讥讽该关闭的时候打开、该开的时候反关，麋芳听说后面有惭色。

**時段與依據** “後”承上次船上相遇。话中讥刺麋芳当年献城，营门事件本身无年。

## 虞翻被迁交州并继续讲学

<a id="period-sgz057-b-2721-3"></a>

<a id="wu057-l33-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》正文](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l33-1)** · [TXT L33](../../sources/本地分卷/三国志/三国志-卷057.txt#L33)

> 翻性疏直，數有酒失。權與張昭論及神仙，翻指昭曰：「彼皆死人，而語神仙，世豈有仙人也！」權積怒非一，遂徙翻交州。

**釋讀** 虞翻直率，屡次因饮酒失礼。孙权和张昭谈神仙，虞翻指张昭说世上没有仙人。孙权屡受冒犯，终于把虞翻流放交州。

**時段與依據** [《通鉴》卷七十二](../../sources/资治通鉴/KR2b0007_072.txt#L217-L226)于232年周贺求马前用“初”追叙；[229年贺表](ce-0229.md#ce0229-note-1)说“全宥九載”，不足以等同已流放九年。初徙确年未载。

> 雖處罪放，而講學不倦，門徒常數百人。

**釋讀** 虞翻虽被放逐，仍持续讲学，弟子常有数百人。

**時段與依據** 讲学是流放期间的常事。

> 又爲老子、論語、國語訓注，皆傳於世。

## 虞翻治《易》、校经与裴松之辨字

<a id="period-sgz057-p-010-1"></a>

<a id="wu057-l36-1"></a>

**[《三國志·虞陸張駱陸吾朱傳》裴注 010](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l36-1)** · [TXT L36](../../sources/本地分卷/三国志/三国志-卷057.txt#L36)

> 翻別傳曰：翻初立易注，奏上曰：「臣聞六經之始，莫大陰陽，是以伏羲仰天縣象，而建八卦，觀變動六爻爲六十四，以通神明，以類萬物。臣高祖父故零陵太守光，少治孟氏易，曾祖父故平輿令成，纘述其業，至臣祖父鳳爲之最密。臣亡考故日南太守歆，受本於鳳，最有舊書，世傳其業，至臣五世。前人通講，多玩章句，雖有祕說，於經疏闊。臣生遇世亂，長於軍旅，習經於枹鼓之間，講論於戎馬之上，蒙先師之說，依經立注。

**釋讀** 虞翻上呈《易注》，先说伏羲观天象而立八卦，六爻变为六十四卦。高祖虞光任零陵太守，习孟氏《易》，曾祖虞成任平舆令，祖虞凤钻研尤深，父虞歆任日南太守，承家传旧书，至虞翻五代。他认为前人常拘泥章句，自己虽在战乱军旅中仍讲经，依经及师说立注。

**時段與依據** 《别传》仅言“初立易注”。与本卷早年出示孔融者可互参，无法据此锁定奏上时间。

<a id="period-sgz057-p-010-2"></a>

<a id="wu057-l36-2"></a>

**[《三國志·虞陸張駱陸吾朱傳》裴注 010](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l36-2)** · [TXT L36](../../sources/本地分卷/三国志/三国志-卷057.txt#L36)

> 又臣郡吏陳桃夢臣與道士相遇，放髮被鹿裘，布易六爻，撓其三以飲臣，臣乞盡吞之。道士言易道在天，三爻足矣。豈臣受命，應當知經！所覽諸家解不離流俗，義有不當實，輒悉改定，以就其正。孔子曰：『乾元用九而天下治。』聖人南面，蓋取諸离，斯誠天子所宜協陰陽致麟鳳之道矣。謹正書副上，惟不罪戾。」

**釋讀** 郡吏陈桃梦到虞翻遇披发穿鹿裘的道士，授以六爻中的三爻供饮。虞翻借梦设问是否受命知经，称有不合原义的注解便加以改定。引孔子“乾元用九而天下治”，用“南面”取象离卦，说明君主协调阴阳、致麟凤之理，并奏副本。

**時段與依據** 承首奏立《易注》；梦兆与经义是奏书议论。

<a id="period-sgz057-p-010-3"></a>

<a id="wu057-l36-3"></a>

**[《三國志·虞陸張駱陸吾朱傳》裴注 010](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l36-3)** · [TXT L36](../../sources/本地分卷/三国志/三国志-卷057.txt#L36)

> 翻又奏曰：「經之大者，莫過於易。自漢初以來，海內英才，其讀易者，解之率少。至孝靈之際，潁川荀諝號爲知易，臣得其注，有愈俗儒，至所說西南得朋，東北喪朋，顛倒反逆，了不可知。孔子歎易曰：『知變化之道者，其知神之所爲乎！』以美大衍四象之作，而上爲章首，尤可怪笑。又南郡太守馬融，名有俊才，其所解釋，復不及諝。孔子曰『可與共學，未可與適道』，豈不其然！若乃北海鄭玄，南陽宋忠，雖各立注，忠小差玄而皆未得其門，難以示世。」

**釋讀** 虞翻另奏说能解《易》者少，荀谞的注说虽胜俗儒，于“西南得朋，东北丧朋”仍颠倒不明，又把孔子赞大衍四象的语句放在篇首。虞翻认为马融还不及荀谞，宋忠略胜郑玄，但两家均未得其门。

**時段與依據** 经学评论，没有独立年月。篇末裴注说明荀谞是荀爽别名。

<a id="period-sgz057-p-010-4"></a>

<a id="wu057-l36-4"></a>

**[《三國志·虞陸張駱陸吾朱傳》裴注 010](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l36-4)** · [TXT L36](../../sources/本地分卷/三国志/三国志-卷057.txt#L36)

> 又奏鄭玄解尚書違失事目：「臣聞周公制禮以辨上下，孔子曰『有君臣然後有上下，有上下然後禮義有所錯』，是故尊君卑臣，禮之大司也。伏見故徵士北海鄭玄所注尚書，以顧命康王執瑁，古『月』似『同』，從誤作『同』，旣不覺定，復訓爲杯，謂之酒杯；成王疾困憑几，洮頮爲濯，以爲澣衣成事，『洮』字虛更作『濯』，以從其非；又古大篆『卯』字讀當爲『柳』，古『柳』『卯』同字，而以爲昧；『分北三苗』，『北』古『別』字，又訓北，言北猶別也。若此之類，誠可怪也。玉人職曰天子執瑁以朝諸侯，謂之酒杯；天子頮面，謂之澣衣；古篆『卯』字，反以爲昧。甚違不知蓋闕之義。於此數事，誤莫大焉，宜命學官定此三事。

**釋讀** 虞翻又上奏纠驳郑玄《尚书》注，先论周公制礼，用君臣上下之分申礼制。他指出郑玄把《顾命》的“瑁”误作“同”并训酒杯，把“洮頮”说成洗衣，按“昧”解应为“柳”的大篆“卯”，对“分北三苗”曲从“北”字另作训释。他引用《玉人职》所记朝诸侯执瑁，主张学官校定三项大误。

**時段與依據** 同组奏书，列举古文、古篆及礼书互证。

<a id="wu057-l36-5"></a>

**[《三國志·虞陸張駱陸吾朱傳》裴注 010](../../sources/本地分卷/三国志/三国志-卷057.md#edition-wu057-l36-5)** · [TXT L36](../../sources/本地分卷/三国志/三国志-卷057.txt#L36)

> 又馬融訓注亦以爲同者大同天下，今經益『金』就作『銅』字，詁訓言天子副璽，雖皆不得，猶愈於玄。然此不定，臣沒之後，而奮乎百世，雖世有知者，懷謙莫或奏正。又玄所注五經，違義尤甚者百六十七事，不可不正。行乎學校，傳乎將來，臣竊恥之。」

**釋讀** 虞翻说马融以大同天下解“同”，经文当时另有加金旁作“銅”的写法，训天子副玺，虽仍不合经义，胜于郑玄。虞翻担心身后无人敢奏请订正，又举郑玄《五经》注中一百六十七项大误，认为不应流传学官。

**時段與依據** 承前考校《尚书》奏书。

> 翻放棄南方，云「自恨疏節，骨體不媚，犯上獲罪，當長沒海隅，生無可與語，死以青蠅爲弔客，使天下一人知己者，足以不恨。」以典籍自慰，依易設象，以占吉凶。又以宋氏解玄頗有繆錯，更爲立法，并著明楊、釋宋以理其滯。

**釋讀** 虞翻谪居南方，自责性直而不能取媚，怕埋骨海隅、死后只有苍蝇吊唁，以得一知己为愿。他以读书自遣，用《易》设象占吉凶，见宋氏解扬雄《太玄》有误，重立方法，作《明杨》《释宋》以疏通经义。

**時段與依據** “放棄南方”只给持续阶段，未记著作确年。

> 　臣松之案：翻云「古大篆『卯』字讀當言『柳』，古『柳』『卯』同字」，竊謂翻言爲然。故「劉」「留」「聊」「柳」同用此字，以從聲故也，與日辰「卯」字字同音異。然漢書王莽傳論卯金刀，故以爲日辰之「卯」，今未能詳正。然世多亂之，故翻所說云。荀諝，荀爽之別名。

**釋讀** 裴松之认可“柳”“卯”字同，指出“劉、留、聊、柳”借此表声，与地支“卯”字同音异。《汉书·王莽传》解“卯金刀”又以“卯”为地支；裴松之未能确断，只记当世常混用，并注明荀谞即荀爽。

**時段與依據** 校字附于虞翻《尚书》辨误之后。

## 陸績幼年見袁術，後在吳與張昭等論治道

<a id="period-sgz057-b-2726-2"></a>

<a id="wu057-l59-1"></a>

> 績年六歲，於九江見袁術。術出橘，績懷三枚，去，拜辭墮地，術謂曰：「陸郎作賔客而懷橘乎？」績跪荅曰：「欲歸遺母。」術大奇之。

**釋讀** 陸績六歲在九江見袁術，藏了袁術拿出的三枚橘。拜辭時橘子掉落，袁術詢問，陸績答要帶回給母親，袁術稱奇。

**時段與依據** 卷001〈武帝紀〉和《資治通鑑》卷060載袁術初平四年敗走九江，建安四年病死。這段只記陸績六歲，未明相見在袁術據淮南的哪年。《後漢書》卷031也提此事而無年。

> 是時徵役繁數，重以疫癘，民戶損耗，統上疏曰：「臣聞君國者，以據疆土爲彊富，制威福爲尊貴，曜德義爲榮顯，永世胤爲豐祚。然財須民生，彊賴民力，威恃民勢，福由民殖，德俟民茂，義以民行，六者旣備，然後應天受祚，保族宜邦。書曰：『衆非后無能胥以寧，后非衆無以辟四方。』推是言之，則民以君安，君以民濟，不易之道也。今彊敵未殄，海內未乂，三軍有無已之役，江境有不釋之備，徵賦調數，由來積紀，加以殃疫死喪之災，郡縣荒虛，田疇蕪曠，聽聞屬城，民戶浸寡，又多殘老，少有丁夫，聞此之日，心若焚燎。思尋所由，小民無知，旣有安土重遷之性，且又前後出爲兵者，生則困苦無有溫飽，死則委棄骸骨不反，是以尤用戀本畏遠，同之於死。每有徵發，羸謹居家重累者先見輸送。小有財貨，傾居行賂，不顧窮盡。輕剽者則迸入險阻，黨就羣惡。百姓虛竭，嗷然愁擾，愁擾則不營業，不營業則致窮困，致窮困則不樂生，故口腹急，則姧心動而攜叛多也。又聞民間非居處小能自供，生產兒子，多不起養；屯田貧兵，亦多棄子。天則生之，而父母殺之，旣懼干逆和氣，感動陰陽。且惟殿下開基建國，乃無窮之業也，彊鄰大敵非造次所滅，疆埸常守非期月之戍，而兵民減耗，後生不育，非所以歷遠年，致成功也。夫國之有民，猶水之有舟，停則以安，擾則以危，愚而不可欺，弱而不可勝，是以聖王重焉，禍福由之，故與民消息，觀時制政。方今長吏親民之職，惟以辨具爲能，取過目前之急，少復以恩惠爲治，副稱殿下天覆之仁，勤恤之德者。官民政俗，日以彫弊，漸以陵遲，勢不可乆。夫治疾及其未篤，除患貴其未深，願殿下少以萬機餘閑，留神思省，補復荒虛，深圖遠計，育殘餘之民，阜人財之用，參曜三光，等崇天地。臣統之大願，足以死而不朽矣。」權感統言，深加意焉。

**釋讀** 駱統上疏說國家富強、威福都依靠百姓。久戍重役和瘟疫使田地荒蕪、人丁稀少；徵發失平、納賄、逃徙相因，養不起孩子的百姓與屯兵以至棄子。他勸孫權在禍患未深前寬恤殘民、恢復生計。孫權因其言而重視。

**時段與依據** 原疏以「是時」承前敘任事，提徵役與疫癘，未記某次疫病的年份。整篇與採納語同讀。

> 評曰：虞翻古之狂直，固難免乎末世，然權不能容，非曠宇也。陸績之於楊玄，是仲尼之左丘明，老聃之嚴周矣；以瑚璉之器，而作守南越，不亦賊夫人歟！張溫才藻俊茂，而智防未備，用致艱患。駱統抗明大義，辭切理至，值權方閉不開。陸瑁篤義規諫，君子有稱焉。吾粲、朱據遭罹屯蹇，以正喪身，悲夫！

**釋讀** 陳壽說虞翻如古人般狂直，難免遭忌，孫權也有欠包容。以左丘明之於孔子及底本所寫的「老聃之嚴周」為比，稱陸績能闡明揚雄《太玄》，並以宗廟禮器「瑚璉」比陸績的才具，惋惜孫權使他出守南越。張溫才華出眾卻未善於自保，駱統據義直言也未能挽回孫權的心意。陸瑁忠厚而能規諫，吾粲、朱據因持正而遇害。

**時段與依據** 跨七傳評論，完整保留評語。

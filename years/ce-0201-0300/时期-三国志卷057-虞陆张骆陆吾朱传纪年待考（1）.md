### 虞翻小传题头

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2713](../../sources/本地分卷/三国志/三国志-卷057.md#l2713)

> 虞翻

以下为虞翻传。

**时段与依据** 分传题头。

<a id="period-sgz057-b-2714-1"></a>

### 虞翻早年任王朗功曹

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2714](../../sources/本地分卷/三国志/三国志-卷057.md#l2714)

> 虞翻字仲翔，會稽餘姚人也。太守王朗命為功曹。

虞翻字仲翔，是会稽余姚人，受太守王朗任为功曹。

**时段与依据** 在孙策攻会稽以前。 《会稽典录》追记“初平末年”王朗任会稽。

<a id="period-sgz057-b-2715-3"></a>

### 虞翻出任富春长

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2715](../../sources/本地分卷/三国志/三国志-卷057.md#l2715)

> 翻出為富春長。

虞翻出任富春县长。

**时段与依据** 本传在孙策卒前，裴注另记孙策死时仍为功曹。

<a id="period-sgz057-b-2716-2"></a>

### 虞翻不就汉征及曹操辟召

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2716](../../sources/本地分卷/三国志/三国志-卷057.md#l2716)

> 後翻州舉茂才，漢召為侍御使，曹公為司空辟，皆不就。

虞翻受州举茂才，汉召为侍御史，曹操任司空时也辟召，他均不应。

**时段与依据** 在孙策死后、曹操208年转任丞相前，诸项未独纪年。底本“侍御使”，四库作“侍御史”。

<a id="period-sgz057-b-2717-1"></a>

### 虞翻出示《易注》，孔融回信

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2717](../../sources/本地分卷/三国志/三国志-卷057.md#l2717)

> 翻與少府孔融書，並示以所著《易注》。融答書曰："聞延陵之理樂，睹吾子之治《易》，乃知東南之美者，非徒會稽之竹箭也。又觀象雲物，察應寒溫，原其禍福，與神合契，可謂探賾窮通者也。"

虞翻写信给少府孔融，附自己所著《易注》。孔融赞其学与观象、察寒温、解吉凶之深，称东南有才。

**时段与依据** 200—208年之间，孔融建安十三年遇害，书札未纪年。

<a id="period-sgz057-b-2717-2"></a>

### 张纮致孔融书称誉虞翻

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2717](../../sources/本地分卷/三国志/三国志-卷057.md#l2717)

> 會稽東部都尉張紘又與融書曰："虞仲翔前頗為論者所侵，美寶為質，雕摩益光，不足以損。"

张纮称虞翻虽被人毁谤，其美质有如宝石，越磨越亮。

**时段与依据** 《张纮传》于200年后出任会稽东部都尉，孔融208年卒。

<a id="period-sgz057-b-2718-1"></a>

### 虞翻获授骑都尉并徙泾县

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2718](../../sources/本地分卷/三国志/三国志-卷057.md#l2718)

> 孫權以為騎都尉。翻數犯顏諫爭，權不能悅。又性不協俗，多見謗毀，坐徙丹楊涇縣。

孙权用虞翻为骑都尉，虞翻多次当面劝谏，性情也与俗不合，受到毁谤，被徙丹杨泾县。

**时段与依据** 在吕蒙219年取荆州以前，迁授、徙置均无确年。

<a id="period-sgz057-b-2721-1"></a>

### 虞翻遇麋芳船斥其失忠

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2721](../../sources/本地分卷/三国志/三国志-卷057.md#l2721)

> 翻常乘船行，與麋芳相逢，芳船上人多欲令翻自避，先驅曰：「避將軍船！」翻厲聲曰："失忠與信，何以事君？傾人二城，而稱將軍，可乎？"芳闔戶不應而遽避之。

麋芳船上人喝道要虞翻避让，虞翻以麋芳降吴斥其失忠信，麋芳闭门避开。

**时段与依据** 麋芳219年降吴后，交州流放前，未确年。

<a id="period-sgz057-b-2721-2"></a>

### 虞翻讥麋芳营门开闭失宜

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2721](../../sources/本地分卷/三国志/三国志-卷057.md#l2721)

> 後翻乘車行，又經芳營勞，吏閉門，車不得過。翻復怒曰："當閉反開。當開反閉。豈得事宜邪？"芳聞之，有慚色。

虞翻过麋芳营门被拒，以该闭不闭、该开偏闭之语讥刺，麋芳惭愧。

**时段与依据** 同在麋芳降吴后。

<a id="period-sgz057-b-2721-3"></a>

### 虞翻与张昭争神仙说，徙交州

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2721](../../sources/本地分卷/三国志/三国志-卷057.md#l2721)

> 翻性疏直，數有酒失。權與張昭論及神仙，翻指昭曰："彼皆死人，而語神仙，世豈有仙人也！"權積怒非一，遂徙翻交州。

虞翻直率好酒，孙权与张昭议神仙时，虞翻不信并当面指斥，孙权连积前怒，将他徙交州。

**时段与依据** 《通鉴》卷七十二在232年求马叙述中以“初”追记。《翻别传》229年贺表已言获宥九载，确切始年有疑。

<a id="period-sgz057-b-2721-4"></a>

### 虞翻在交州授徒著书

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2721](../../sources/本地分卷/三国志/三国志-卷057.md#l2721)

> 雖處罪放，而講學不倦，門徒常數百人。又為《老子》、《論語》、《國語》訓注，皆傳於世。

虞翻虽被放逐，仍讲学，弟子有数百，注《老子》《论语》《国语》。

**时段与依据** 放逐阶段的持续著述。

<a id="period-sgz057-b-2722-1"></a>

### 虞翻识拔丁览、徐陵

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2722](../../sources/本地分卷/三国志/三国志-卷057.md#l2722)

> 初，山陰丁覽，太末徐陵，或在縣吏之中，或眾所未識，翻一見之，便與友善，終鹹顯名。

虞翻在丁览、徐陵身分低微时便亲近交游，二人后来显名。

**时段与依据** 本传“初”，没有纪年。两人事亦见《会稽典录》。

<a id="period-sgz057-b-2722-2"></a>

### 虞翻卒于岭南、家属归葬

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2722](../../sources/本地分卷/三国志/三国志-卷057.md#l2722)

> 在南十餘年，年七十卒。歸葬舊墓，妻子得還。

本传说虞翻南居十余年、年七十而卒，归葬旧墓，妻儿获准回乡。

**时段与依据** 《通鉴》置于232年周贺遇袭后，但只说诏召时已卒，《孙登传》241年遗疏仍举其名，与年寿、虞汜南海出生且十六丧父的记载互有张力，卒年待考。

虞翻有十一子，第四子虞汜名声最著。

### 虞汜病卒

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2724](../../sources/本地分卷/三国志/三国志-卷057.md#l2724)

> 病卒，

虞汜因病而死。

**时段与依据** 在扶严战后，《会稽典录》说获授官爵后“寻卒”，未独定年。

<a id="period-sgz057-b-2724-6"></a>

### 虞忠与虞耸、虞昺仕历

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2724](../../sources/本地分卷/三国志/三国志-卷057.md#l2724)

> 汜弟忠，宜都太守。聳，越騎校尉。累遷廷尉，湘東、河間太守；昺，廷尉尚書，濟陰太守。

虞忠任宜都太守，虞耸任越骑校尉，历廷尉、湘东和河间长官；虞昺历廷尉、尚书、济阴太守。

**时段与依据** 兄弟入仕历吴晋，各任缺确年；裴注可另互证确年战事。

<a id="period-sgz057-b-2725-1"></a>

### 陆绩小传题头

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2725](../../sources/本地分卷/三国志/三国志-卷057.md#l2725)

> 陸績

以下为陆绩传。

**时段与依据** 分传题头。

<a id="period-sgz057-b-2726-1"></a>

### 陆绩家世

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2726](../../sources/本地分卷/三国志/三国志-卷057.md#l2726)

> 陸績字公紀，吳郡吳人也。父康，漢末為廬江太守。

陆绩字公纪，是吴郡吴人；父陆康在汉末任庐江太守。

**时段与依据** 《后汉书·陆康传》详仕历，始任只见“灵帝末”。

<a id="period-sgz057-b-2726-2"></a>

### 陆绩见袁术怀橘归母

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2726](../../sources/本地分卷/三国志/三国志-卷057.md#l2726)

> 績年六歲，於九江見袁術。術出橘，績懷三枚，去，拜辭墮地，術謂曰：「陸郎作賓客而懷橘乎？」績跪答曰："欲歸遺母。"術大奇之。

陆绩六岁在九江见袁术，藏三橘打算带给母亲，拜辞时掉出，袁术知其意而称异。

**时段与依据** 仅据时年六岁及见袁术地点，不能定年。

<a id="period-sgz057-b-2726-3"></a>

### 陆绩辩先修德教

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2726](../../sources/本地分卷/三国志/三国志-卷057.md#l2726)

> 孫策在吳，張昭、張紘、秦松為上賓，共論四海未泰，須當用武治而平之，績年少末坐，遙大聲言曰："昔管夷吾相齊桓公，九合諸候，一匡天下，不用兵車。孔子曰：'遠人不服，則修文德以來之。'今論者不務道德懷取之術，而惟尚武，績雖童蒙，竊所未安也。"昭等異焉。

孙策在吴，张昭等议武力平天下，少年陆绩引管仲、孔子，主张远人不服应先修文德，张昭等称奇。

**时段与依据** 孙策占吴后、200年去世以前。

<a id="period-sgz057-b-2727-1"></a>

### 陆绩学问及友人

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2727](../../sources/本地分卷/三国志/三国志-卷057.md#l2727)

> 績容貌雄壯，博學多識，星歷算數無不該覽。虞翻舊齒名盛，龐統荊州令士，年亦差長，皆與績友善。

陆绩博览，长于星历算数，虽比虞翻、庞统年轻，仍受二人重视。

**时段与依据** 人物概述。《庞统传》裴注载210年昌门相会，为友谊之一事。

<a id="period-sgz057-b-2727-3"></a>

### 陆绩出守郁林

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2727](../../sources/本地分卷/三国志/三国志-卷057.md#l2727)

> 以直道見憚，出為鬱林太守，加偏將軍，給兵二千人。績既有躄疾，又意在儒雅，非其志也。

陆绩因正直受忌，出任郁林太守兼偏将军，得兵二千。他有足疾且志在文事，不喜领军。

**时段与依据** 孙权统事后，出镇年待考。

<a id="period-sgz057-b-2727-4"></a>

### 陆绩著《浑天图》、注《易》及释《玄》

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2727](../../sources/本地分卷/三国志/三国志-卷057.md#l2727)

> 雖有軍事，著述不廢，作《渾天圖》，注《易》釋《玄》，皆傳於世。

陆绩在军职仍研究天文经学，著《浑天图》、注《易》释《太玄》，成果后来流传。

**时段与依据** 著述阶段，没有成书年。

<a id="period-sgz057-b-2727-5"></a>

### 陆绩预撰辞叙其生平

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2727](../../sources/本地分卷/三国志/三国志-卷057.md#l2727)

> 豫自知亡日，乃為辭曰："有漢志士吳郡陸績，幼敦《詩》、《書》，長玩《禮》、《易》受命南征，遘疾遇厄，遭命不幸，嗚呼悲隔！"又曰："從今已去，六十年之外，車同軌，書同文，恨不及見也。"

陆绩自作临终辞，从幼读诗书写到受命南征而遇疾病，又望六十年后统一，叹无缘见。

**时段与依据** 不以预言反推死亡年。

<a id="period-sgz057-b-2727-6"></a>

### 陆绩年三十二卒及二子仕历

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2727](../../sources/本地分卷/三国志/三国志-卷057.md#l2727)

> 年三十二卒。長子宏，會稽南部都尉，次子睿，長水校尉。

陆绩三十二岁去世，长子陆宏任会稽南部都尉，次子陆睿任长水校尉。

**时段与依据** 出生和卒没有独立绝对年，六十年后车同轨不是精确纪年依据。

> 張溫

以下为张温传。

**时段与依据** 分传题头。

<a id="period-sgz057-b-2729-1"></a>

### 张温家世与早年品行

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2729](../../sources/本地分卷/三国志/三国志-卷057.md#l2729)

> 張溫字惠恕，吳郡吳人也。父允，以輕財重士，名顯州郡，為孫權東曹掾。卒。溫少修節操，容貌奇偉。

张温字惠恕，吴郡人。父张允轻财重士，为孙权东曹掾。张温年少谨修操行，形貌出众。

**时段与依据** 早年概述；张允之卒与诸任缺年。

<a id="period-sgz057-b-2729-2"></a>

### 孙权问刘基顾雍张温为人

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2729](../../sources/本地分卷/三国志/三国志-卷057.md#l2729)

> 權聞之，以問公卿曰：「溫當今與誰為比？」大（司）農劉基曰："可與全琮為輩。"太常顧雍曰："基未詳其為人也。溫當今無輩。"權曰："如是，張允不死也。"

孙权向众臣比较张温，刘基以全琮相比，顾雍称张温无人可比，孙权以为能继父业。

**时段与依据** 在张温受征见以前，顾雍太常期间，确年不见。

<a id="period-sgz057-b-2729-3"></a>

### 张温获孙权礼待

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2729](../../sources/本地分卷/三国志/三国志-卷057.md#l2729)

> 徵到延見，文辭占對，觀者傾竦，權改容加禮。罷出，張昭執其手曰："老夫托意，君宜明之。"

张温奉征入见，应答使满座肃然。孙权礼遇，张昭握其手嘱托。

**时段与依据** 赴征及问对无年。

<a id="period-sgz057-b-2729-4"></a>

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2743](../../sources/本地分卷/三国志/三国志-卷057.md#l2743)

> 思尋所由，小民無知，既有安土重遷之性，且又前後出為兵者，生則困苦無有溫飽，死則委棄骸骨不反，是以尤用戀本畏遠，同之於死。每有徵發，羸謹居家重累者先見輸送。小有財貨，傾居行賂，不顧窮盡。輕剽者則迸入險阻，黨就羣惡。百姓虛竭，嗷然愁擾，愁擾則不營業，不營業則致窮困，致窮困則不樂生，故口腹急，則姦心動而攜叛多也。

骆统说民众顾乡里，见出征者活则饥寒、死而不返，征发时有家者先被押送，有财者行贿，轻捷的逃入山险，百姓愈穷愈可能背叛。

### 陈寿评虞翻

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2762](../../sources/本地分卷/三国志/三国志-卷057.md#l2762)

> 評曰：虞翻古之狂直，因難免乎末世，然權不能容，非曠宇也。

陈寿称虞翻为古之狂直，生于乱末难得善终，也批评孙权不能相容。

**时段与依据** 卷末史评。

<a id="period-sgz057-b-2762-2"></a>

### 陈寿评陆绩

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2762](../../sources/本地分卷/三国志/三国志-卷057.md#l2762)

> 陸績之於揚《玄》，是仲尼之左丘明，老聘之嚴周矣；以瑚璉之器，而作守南越，不亦賊夫人歟！

陈寿将陆绩阐释扬雄《太玄》比为左丘明传孔子、庄周阐老子，又认为以儒才往守南越有损其用。

**时段与依据** 卷末史评。“老聘”可据四库“老聃”读。

<a id="period-sgz057-b-2762-3"></a>

### 陈寿评张温、骆统

[《三国志·虞陆张骆陆吾朱传》仓内原文 L2762](../../sources/本地分卷/三国志/三国志-卷057.md#l2762)

> 張溫才藻俊茂，而智防未備，用致艱患。駱統抗明大義，辭切理至，值權方閉不開。

陈寿称张温才华富而不能自护，骆统能进切理之谏，但孙权没有充分纳受。

**时段与依据** 卷末史评。

### 虞翻少年致书责客见称

[《三国志·虞陆张骆陆吾朱传》裴注 001·1](../../sources/摘录/三国志-卷057-虞陆张骆陆吾朱传裴注.md#pei-001-1)

> 吳書曰翻少好學有髙氣年十二客有〔四库字图1974〕其兄者不過翻翻追與書曰僕聞虎魄不取腐芥磁石不受曲鍼過而不存不亦宜乎客得書竒之由是見稱

客人拜谒其兄而不访虞翻，十二岁的虞翻以琥珀、磁石为比，写信讥讽对方，反获其赏识。

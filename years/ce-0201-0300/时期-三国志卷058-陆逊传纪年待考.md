## 陸遜家世與少年

陸遜是吳郡吳人，本名議，出自江東陸氏。幼年喪父後，曾在從祖陸康任官之所生活。

<a id="period-sgz058-b-2764-1"></a>

<a id="period-sgz058-b-2765-1"></a>

<a id="wu058-l3-1"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l3-1)** · [TXT L3](../../拆分史书/三国志/卷058.txt#L3)

> 陸遜字伯言，吳郡吳人也。本名議，世江東大族。

**釋讀** 陸遜字伯言，本名議，吳郡吳縣人，家族世居江東，為當地大族。

**時段與依據** 傳首名籍無年次。舊本在傳題另出「陸遜」，對接本句。

<a id="period-sgz058-p-001-1"></a>

<a id="wu058-l4-1"></a>

**[《三國志·陸遜傳》裴注 001](../../拆分史书/三国志/卷058.md#edition-wu058-l4-1)** · [TXT L4](../../拆分史书/三国志/卷058.txt#L4)

> 陸氏世頌曰：遜祖紆，字叔盤，敏淑有思學，守城門校尉。父駿，字季才，淳懿信厚，爲邦族所懷，官至九江都尉。

**釋讀** 陸遜的祖父陸紆字叔盤，聰敏好學，守城門校尉。父親陸駿字季才，敦厚誠信，得到鄉里宗族擁護，官至九江都尉。

**時段與依據** 《陸氏世頌》記家世及祖父父親的官位，各任年月未載。

<a id="wu058-l5-1"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l5-1)** · [TXT L5](../../拆分史书/三国志/卷058.txt#L5)

> 遜少孤，隨從祖廬江太守康在官。

**釋讀** 陸遜幼年喪父，跟隨從祖陸康在廬江太守任所生活。

**時段與依據** 《後漢書·陸康傳》載陸康平黃穰後領廬江及袁術攻郡事；陸遜何時依隨沒有明文。

## 陸遜領海昌，開倉賑旱

陸遜出掌海昌縣務，遇連年旱災，開倉救濟，督勸農桑。

<a id="period-sgz058-b-2766-2"></a>

<a id="wu058-l7-2"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l7-2)** · [TXT L7](../../拆分史书/三国志/卷058.txt#L7)

> 出爲海昌屯田都尉，并領縣事。

**釋讀** 陸遜出任海昌屯田都尉，兼管縣務。

**時段與依據** 出任海昌與縣內各次旱災在此無明年，僅知仕幕之後。

> 陸氏祠堂像贊曰：海昌，今鹽官縣也。

**釋讀** 《陸氏祠堂像贊》說海昌相當於作者時代的鹽官縣。

**時段與依據** 為海昌任職段的地名注文，未另記改名年月。

> 縣連年亢旱，遜開倉穀以振貧民，勸督農桑，百姓蒙賴。

**釋讀** 海昌連年嚴重乾旱，陸遜開倉發糧救濟貧民，勸督農耕蠶桑，百姓因此受益。

**時段與依據** 本傳只說旱情延續數年，無各年或出倉月日。

## 陸遜請募兵，破會稽潘臨

陸遜曾請募兵，由此逐步擴充部曲，並討平長期為患的會稽潘臨。

<a id="period-sgz058-b-2766-3"></a>

<a id="period-sgz058-b-2766-4"></a>

<a id="wu058-l9-2"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l9-2)** · [TXT L9](../../拆分史书/三国志/卷058.txt#L9)

> 時吳、會稽、丹楊多有伏匿，遜陳便宜，乞與募焉。會稽山賊大帥潘臨，舊爲所在毒害，歷年不禽。遜以手下召兵，討治深險，所向皆服，部曲已有二千餘人。

**釋讀** 吳、會稽、丹楊有許多逃避官府的人，陸遜陳述可行辦法，請求參與召募。會稽潘臨為患多年，陸遜召集兵士深入險地平討，各地相繼歸服，其部曲增至二千餘人。

**時段與依據** 本傳將徵募、破潘臨置於早期仕途，先於216年討尤突，未見各自紀年。

## 呂範徵陸遜為別駕，舉茂才

孫權想讓已為將軍、列侯的陸遜仍經州里選薦，命揚州牧呂範辟他為別駕從事、舉茂才。

<a id="period-sgz058-p-003-1"></a>

<a id="wu058-l20-1"></a>

**[《三國志·陸遜傳》裴注 003](../../拆分史书/三国志/卷058.md#edition-wu058-l20-1)** · [TXT L20](../../拆分史书/三国志/卷058.txt#L20)

> 吳書曰：權嘉遜功德，欲殊顯之，雖爲上將軍列侯，猶欲令歷本州舉命，乃使揚州牧呂範就辟別駕從事，舉茂才。

**釋讀** 孫權嘉許陸遜的功德，想特別表彰他，讓他雖已身為上將、列侯，仍經州里舉命一途。於是命揚州牧呂範就地辟他為別駕從事，並舉為茂才。

**時段與依據** 注文依附陸遜既封侯的仕歷。卷056《呂範傳》記呂範於洞口拒魏、還軍後才拜揚州牧，可將此政令置222年戰後至呂範228年薨前，確年未明。

## 陸遜建議擢用荊州士人

荊州初歸吳後，陸遜建議選拔當地士人，以延攬人才、收攬人心。

<a id="period-sgz058-b-2771-5"></a>

<a id="wu058-l22-1"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l22-1)** · [TXT L22](../../拆分史书/三国志/卷058.txt#L22)

> 時荊州士人新還，仕進或未得所，遜上疏曰：「昔漢高受命，招延英異，光武中興，羣俊畢至，苟可以熙隆道教者，未必遠近。今荊州始定，人物未達，臣愚慺慺，乞普加覆載抽拔之恩，令並獲自進，然後四海延頸，思歸大化。」權敬納其言。

**釋讀** 荊州新歸，當地士人未盡得以出仕。陸遜舉漢高祖與光武帝延攬遠近俊才為例，請孫權廣加選拔，准士人自己求進，使四方人心歸向。孫權敬納。

**時段與依據** 荊州初定為遷徙、進用的時段，奏疏與施行均未紀年。

## 孙权交陆逊斟酌对蜀书信

<a id="period-sgz058-b-2778-6"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l35-4)** · [TXT L35](../../拆分史书/三国志/卷058.txt#L35)

> 時事所宜，權輒令遜語亮，并刻權印，以置遜所。權每與禪、亮書，常過示遜，輕重可否，有所不安，便令改定，以印封行之。

**釋讀** 孙权常请陆逊向诸葛亮传话，另刻一枚孙权的印给陆逊。每次写给刘禅、诸葛亮的书信都送陆逊审定，有不妥处可由他改定，再封印发出。

**時段與依據** 吴蜀恢复邦交之后多次通信的办法，未载授印或各次改信的确年。

## 陆逊上疏请宽刑并起用获罪才吏

<a id="period-sgz058-b-2780-6"></a>

<a id="wu058-l43-1"></a>

<a id="wu058-l43-2"></a>

<a id="wu058-l43-3"></a>

<a id="full-wu058-l43-1"></a>

**[《三國志·陸遜傳》](../../拆分史书/三国志/卷058.md#full-wu058-l43-1)** · [TXT L43](../../拆分史书/三国志/卷058.txt#L43)

> 遜雖身在外，乃心於國，上疏陳時事曰：「臣以爲科法嚴峻，下犯者多。頃年以來，將吏罹罪，雖不慎可責，然天下未一，當圖進取，小宜恩貸，以安下情。且世務日興，良能爲先，自不姦穢入身，難忍之過，乞復顯用，展其力效。此乃聖王忘過記功，以成王業。昔漢高舍陳平之愆，用其奇略，終建勳祚，功垂千載。夫峻法嚴刑，非帝王之隆業；有罰無恕，非懷遠之弘規也。」

**釋讀** 陆逊在外任仍关切国家，上表议时政。

**時段與依據** 本传接辅太子、督军国群段。上表未纪年月。

**釋讀** 陆逊说法令过严，近年将吏获罪的多。从政失慎当然可责，但天下未统一，应宽免小过安定下情。国事日多，需要能干的人，未犯贪污奸恶等难以宽忍的罪者，可重新起用，让他们效力。

**時段與依據** “頃年以來”是奏书中的相对时间。

**釋讀** 陆逊以汉高祖宽赦陈平过失、用其谋略而得功业为例，说明帝王当记人之功，峻法严刑、有罚不恕无益于建国和安抚远方。

**時段與依據** 汉高祖用陈平为比喻旧事，与本疏同一论证。

## 陸遜偽作書信離間魏將逯式、文休

<a id="wu058-l55-1"></a>

<a id="wu058-l56-1"></a>

<a id="wu058-l57-1"></a>

<a id="wu058-l57-2"></a>

<a id="wu058-l58-1"></a>

**[《三國志·陸遜傳》](../../拆分史书/三国志/卷058.md#full-wu058-l55-1)** · [TXT L55](../../拆分史书/三国志/卷058.txt#L55) · [TXT L56（裴注）](../../拆分史书/三国志/卷058.txt#L56) · [TXT L57](../../拆分史书/三国志/卷058.txt#L57) · [TXT L58（裴注）](../../拆分史书/三国志/卷058.txt#L58)

> 又魏江夏太守逯式
>
> **〔裴注〕**
> 逯音錄。
>
> 兼領兵馬，頗作邊害，而與北舊將文聘子休宿不協。遜聞其然，即假作荅式書云：「得報懇惻，知與休乆結嫌隙，勢不兩存，欲來歸附，輒以密呈來書表聞，撰衆相迎。宜潛速嚴，更示定期。」以書置界上，式兵得書以見式，式惶懼，遂自送妻子還洛。由是吏士不復親附，遂以免罷。
>
> **〔裴注〕**
> 臣松以爲邊將爲害，蓋其常事，使逯式得罪，代者亦復如之，自非狡焉思肆，將成大患，何足虧損唯慮，尚爲小詐哉？以斯爲美，又所不取。

**釋讀** 逯式任魏江夏太守。

**時段與依據** 與下兩行合讀為同一事件，逯式免官年月未記。

**釋讀** 裴注說「逯」讀如「錄」。

**時段與依據** 音注緊隨逯式之名。

**釋讀** 逯式兼掌兵馬，在邊境用兵，和魏舊將文聘之子文休有舊隙。陸遜偽造回信，假稱已代為呈報逯式投吳之意，將備兵相迎，請暗中準備並再約日期。

**時段與依據** 本傳置這事在北征與吳遽起事之間。卷018〈文聘傳〉又載文休為文聘嗣子，無逯式免官確年。

**釋讀** 陸遜把信留在邊界，逯式部下拾到交給逯式。逯式害怕，把妻兒送還洛陽；吏士逐漸疏離，逯式遭免官。

**時段與依據** 接同一反間事件，未載免官月日。

**釋讀** 裴松之認為邊將彼此侵害本是常情，換人並不能消除；逯式不足成大患，便不值得因小事施詐，更不能以詐術為美。

**時段與依據** 此篇對逯式事件的評議仍隨正文。

## 謝淵、謝厷議興利，陸遜主張先養民

<a id="period-sgz058-b-2790-1"></a>

<a id="wu058-l64-1"></a>

<a id="wu058-l65-1"></a>

<a id="wu058-l65-2"></a>

<a id="wu058-l65-3"></a>

<a id="wu058-l66-1"></a>

<a id="full-wu058-l64-1"></a>

**[《三國志·陸遜傳》](../../拆分史书/三国志/卷058.md#full-wu058-l64-1)** · [TXT L64](../../拆分史书/三国志/卷058.txt#L64) · [TXT L65（裴注）](../../拆分史书/三国志/卷058.txt#L65) · [TXT L66](../../拆分史书/三国志/卷058.txt#L66)

> 時謝淵、謝厷等各陳便宜，欲興利改作，
>
> **〔裴注〕**
> 會稽典錄曰：謝淵字休德，少脩德操，躬秉耒耜，旣無慼容，又不易慮，由是知名。舉孝廉，稍遷至建武將軍，雖在戎旅，猶垂意人物。駱統子名秀，被門庭之謗，衆論狐疑，莫能證明。淵聞之歎息曰：「公緒早夭，同盟所哀。聞其子志行明辯，而被闇昧之謗，望諸夫子烈然高斷，而各懷遲疑，非所望也。」秀卒見明，無復瑕玷，終爲顯士，淵之力也。　吳歷稱云，謝厷才辯有計術。
>
> 以事下遜。遜議曰：「國以民爲本，彊由民力，財由民出。夫民殷國弱，民瘠國彊者，未之有也。故爲國者，得民則治，失之則亂，若不受利，而令盡用立效，亦爲難也。是以詩歎『宜民宜人，受祿于天』。乞垂聖恩，寧濟百姓，數年之間，國用小豐，然後更圖。」

**釋讀** 謝淵、謝厷各向朝廷建議興利改作。

**時段與依據** 本傳只用「時」接在呂壹事後，未具年。

**釋讀** 《會稽典錄》載謝淵字休德，年少親事農耕而不改常度，以德行出名。舉孝廉後漸遷至建武將軍，在軍中仍關心人才。

**時段與依據** 裴注補謝淵身世，未記孝廉、拜建武將軍年月。

**釋讀** 駱統之子駱秀被有關家門的讒言牽累，謝淵認為他素行明辨，責眾人不肯分辨。駱秀冤枉得明，終成顯士。

**時段與依據** 駱統卒於黃武七年（228）；本事僅指出發生在其死後，謝淵申辯年月未詳。

**釋讀** 《吳歷》稱謝厷善辯有謀。

**時段與依據** 附注人品才能，無獨立年。

**釋讀** 朝廷下問陸遜。陸遜說國用與國力都來自百姓，國強當先使百姓富足。施行新制若不能使人受益，又求他們盡力見效，難以辦到，宜先休養數年，國用稍裕再改作。

**時段與依據** 與本傳謝氏進議相承，不由呂壹案推定同年。

## 陸遜見諸葛恪、楊笁行事而先有所戒

<a id="period-sgz058-b-2795-2"></a>

<a id="wu058-l72-2"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l72-2)** · [TXT L72](../../拆分史书/三国志/卷058.txt#L72)

> 又謂諸葛恪曰：「在我前者，吾必奉之同升；在我下者，則扶持之。今觀君氣陵其上，意蔑乎下，非安德之基也。」

**釋讀** 陸遜告誡諸葛恪應奉助在上者、扶持在下者，指他氣凌上級、輕慢下級，不能安立德業。

**時段與依據** 本傳只作陸遜識人事例，未載交談年月。

<a id="period-sgz058-b-2795-3"></a>

<a id="wu058-l72-3"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l72-3)** · [TXT L72](../../拆分史书/三国志/卷058.txt#L72)

> 又廣陵楊笁少獲聲名，而遜謂之終敗，勸笁兄穆令與別族。其先覩如此。

**釋讀** 廣陵楊笁少年得名，陸遜預料終將敗亡，勸其兄楊穆及早與他分族。傳以此見陸遜先識人事。

**時段與依據** 《資治通鑑》卷075在250年誅楊笁事下回敘，陸遜先時勸楊穆的年次不詳。

## 陸景的婚姻、仕履與著述

<a id="period-sgz058-b-2812-4"></a>

<a id="wu058-l89-4"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l89-4)** · [TXT L89](../../拆分史书/三国志/卷058.txt#L89)

> 景字士仁，以尚公主拜騎都尉，封毗陵侯，旣領抗兵，拜偏將軍、中夏督，澡身好學，著書數十篇也。

**釋讀** 陸景字士仁，娶公主，先後任騎都尉、偏將軍、中夏督，封毗陵侯；接領陸抗一部後，仍好學自持，著書數十篇。

**時段與依據** 分領父軍可繫274年，尚主、遷官和著述無各自年月。凡史料未明的履歷連讀。

<a id="wu058-l90-1"></a>

> 文士傳曰：陸景母張承女，諸葛恪外生。

**釋讀** 陸景母親是張承的女兒、諸葛恪的外甥女。

**時段與依據** 家世附敘。

**[《三國志·陸遜傳》裴注 013](../../拆分史书/三国志/卷058.md#edition-wu058-l90-3)** · [TXT L90](../../拆分史书/三国志/卷058.txt#L90)

> 景少爲祖母所育養，及祖母亡，景爲之心喪三年。

**釋讀** 陸景自小由祖母撫養，祖母去世後為她守心喪三年。

**時段與依據** 守心喪指以哀悼持喪，祖母卒年未載。

> 景妻，孫皓適妹，與景俱張承外孫也。

**釋讀** 陸景的妻子是孫皓嫡妹，和陸景同為張承外孫。

**時段與依據** 承陸景尚主之事，無婚期。

## 陸機、陸雲入晉與早期仕履

<a id="period-sgz058-p-014-1"></a>

<a id="wu058-l92-1"></a>

**[《三國志·陸遜傳》裴注 014](../../拆分史书/三国志/卷058.md#edition-wu058-l92-1)** · [TXT L92](../../拆分史书/三国志/卷058.txt#L92)

> 景弟機，字士衡，雲字士龍。

**釋讀** 陸機字士衡，陸雲字士龍，是陸景的弟弟。

**時段與依據** 名與字為兄弟履歷之始。

<a id="period-sgz058-p-014-2"></a>

<a id="wu058-l92-2"></a>

**[《三國志·陸遜傳》裴注 014](../../拆分史书/三国志/卷058.md#edition-wu058-l92-2)** · [TXT L92](../../拆分史书/三国志/卷058.txt#L92)

> 機雲別傳曰：晉太康末，俱入洛，造司空張華，華一見而奇之，曰：「伐吳之役，利在獲二儁。」遂爲之延譽，薦之諸公。

**釋讀** 太康末，陸機、陸雲到洛陽，拜訪張華。張華稱平吳之利在得到他們兩位才俊，向公卿推薦。

**時段與依據** 《機雲別傳》只說太康末。《晉書·陸機傳》亦稱太康末，沒有各自入洛、見張華的確年。

<a id="period-sgz058-p-014-3"></a>

<a id="period-sgz058-p-014-4"></a>

<a id="wu058-l92-3"></a>

**[《三國志·陸遜傳》裴注 014](../../拆分史书/三国志/卷058.md#edition-wu058-l92-3)** · [TXT L92](../../拆分史书/三国志/卷058.txt#L92)

> 太傅楊駿辟機爲祭酒，轉太子洗馬、尚書著作郎。

**釋讀** 太傅楊駿徵陸機為祭酒，後轉太子洗馬、尚書著作郎。

**時段與依據** 楊駿任太傅、主持朝政在晉惠帝初，徵聘至轉任各自年月未明，後續遷官不限於楊駿在世。

<a id="period-sgz058-p-014-5"></a>

<a id="wu058-l92-4"></a>

**[《三國志·陸遜傳》裴注 014](../../拆分史书/三国志/卷058.md#edition-wu058-l92-4)** · [TXT L92](../../拆分史书/三国志/卷058.txt#L92)

> 雲爲吳王郎中令，出宰浚儀，甚有惠政，吏民懷之，生爲立祠。後並歷顯位。

**釋讀** 陸雲曾任吳王郎中令，出任浚儀縣令，治理有惠，百姓為他立祠。後來兄弟二人均居顯位。

**時段與依據** 本注先敘郎中令後敘浚儀，倉內《晉書·陸雲傳》則先敘浚儀，後說「尋拜吳王晏郎中令」。同存敘次差異。

<a id="period-sgz058-p-014-6"></a>

<a id="wu058-l92-5"></a>

**[《三國志·陸遜傳》裴注 014](../../拆分史书/三国志/卷058.md#edition-wu058-l92-5)** · [TXT L92](../../拆分史书/三国志/卷058.txt#L92)

> 機天才綺練，文藻之美，獨冠於時。雲亦善屬文，清新不及機，而口辯持論過之。

**釋讀** 陸機文章華美，冠於一時；陸雲也善文，文章評價與兄有別，而辯論比兄更強。

**時段與依據** 二人才學的概述。

<a id="period-sgz058-p-014-7"></a>

<a id="wu058-l92-6"></a>

**[《三國志·陸遜傳》裴注 014](../../拆分史书/三国志/卷058.md#edition-wu058-l92-6)** · [TXT L92](../../拆分史书/三国志/卷058.txt#L92)

> 于時朝廷多故，機、雲並自結於成都王頴。頴用機爲平原相，雲清河內史。

**釋讀** 西晉政局屢變，陸機、陸雲依附成都王司馬穎。司馬穎任陸機為平原相、陸雲為清河內史。

**時段與依據** 《機雲別傳》未給兩人受任確年，早於303年司馬穎遣陸機為都督。

<a id="period-sgz058-p-014-14"></a>

<a id="wu058-l92-13"></a>

**[《三國志·陸遜傳》裴注 014](../../拆分史书/三国志/卷058.md#edition-wu058-l92-13)** · [TXT L92](../../拆分史书/三国志/卷058.txt#L92)

> 機文章爲世所重，雲所著亦傳於世。

**釋讀** 陸機文章世人珍重，陸雲的作品也流傳。

**時段與依據** 作品流傳概況，未載年代。

## 卷末總評

<a id="period-sgz058-b-2813-1"></a>

<a id="period-sgz058-b-2813-2"></a>

<a id="wu058-l94-1"></a>

**[《三國志·陸遜傳》正文](../../拆分史书/三国志/卷058.md#edition-wu058-l94-1)** · [TXT L94](../../拆分史书/三国志/卷058.txt#L94)

> 評曰：劉備天下稱雄，一世所憚，陸遜春秋方壯，威名未著，摧而克之，罔不如志。予旣奇遜之謀略，又歎權之識才，所以濟大事也。及遜忠誠懇至，憂國亡身，庶幾社稷之臣矣。抗貞亮籌幹，咸有父風，弈世載美，具體而微，可謂克構者哉！

**釋讀** 陳壽稱劉備以天下雄才為人忌憚，陸遜正年輕而名望未起，已能謀劃破蜀；也讚孫權知人、能成其大事。陸遜忠誠憂國而亡身，幾可稱社稷之臣；陸抗貞正有謀、有父風，足以承繼父業。

**時段與依據** 陸遜、陸抗兩世總評；夷陵、陸遜卒與陸抗諸事各可依本卷前文對讀。

## 孫登的出身與養母徐氏

孫登是孫權的長子，幼年由徐夫人撫養，徐氏被廢後仍尊敬她。

<a id="period-sgz059-b-2816-1"></a>

<a id="wu059-l5-1"></a>

**[《三國志·吳主五子傳》正文](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l5-1)** · [TXT L5](../../sources/本地分卷/三国志/三国志-卷059.txt#L5)

> 孫登字子高，權長子也。

**釋讀** 孫登字子高，是孫權的長子。

**時段與依據** 此句只記名、字、排行。

<a id="period-sgz059-b-2818-1"></a>

<a id="wu059-l12-1"></a>

**[《三國志·吳主五子傳》正文](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l12-1)** · [TXT L12](../../sources/本地分卷/三国志/三国志-卷059.txt#L12)

> 初，登所生庶賤，徐夫人少有母養之恩，後徐氏以妬廢處吳，而步夫人最寵。步氏有賜，登不敢辭，拜受而已。徐氏使至，所賜衣服，必沐浴服之。

**釋讀** 孫登生母地位低，由徐夫人撫養。其後徐氏因妒被廢居吳，步夫人最受寵。孫登拜受步氏之賜，徐氏派人送來衣服，他必沐浴後才穿。

**時段與依據** 早年養育與往後對兩位夫人長期持禮，未載各事具年。

## 范慎的早年、著述與初仕

范慎出自廣陵，撰《矯非》二十篇，後任武昌左部督，以治軍整嚴著稱。

<a id="period-sgz059-p-002-1"></a>

<a id="wu059-l8-1"></a>

**[《三國志·吳主五子傳》裴注 002](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l8-1)** · [TXT L8](../../sources/本地分卷/三国志/三国志-卷059.txt#L8)

> 吳錄曰：慎字孝敬，廣陵人，竭忠知己之君，纏綿三益之友，時人榮之。著論二十篇，名曰矯非。後爲侍中，出補武昌左部督，治軍整頓。

**釋讀** 范慎字孝敬，廣陵人。竭忠於知己之君，親近有益之友，受時人敬重。作論二十篇，名矯非。後任侍中、武昌左部督，治軍整嚴。

**時段與依據** 此為范慎仕學總敘，著書、任侍中與左部督各無明載年月。

## 東宮賓客刁玄、羊衜

刁玄出自丹楊，羊衜出自南陽，兩人都曾為孫登東宮賓客。羊衜後官至桂陽太守。

> 玄，丹楊人。衜，南陽人。　

**釋讀** 刁玄是丹楊人，羊衜是南陽人。

**時段與依據** 兩人籍貫與范慎卒年無涉，無獨立日期。

**[《三國志·吳主五子傳》裴注 002](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l8-8)** · [TXT L8](../../sources/本地分卷/三国志/三国志-卷059.txt#L8)

**釋讀** 羊衜官至桂陽太守，後卒。

## 孫登出行、待民與約束侍從

孫登出獵避踏莊稼，查驗彈丸後釋放被疑者，對取走金馬盂的侍從則責而遣歸。

<a id="period-sgz059-b-2817-2"></a>

<a id="period-sgz059-b-2817-3"></a>

<a id="period-sgz059-b-2817-4"></a>

<a id="wu059-l10-2"></a>

**[《三國志·吳主五子傳》正文](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l10-2)** · [TXT L10](../../sources/本地分卷/三国志/三国志-卷059.txt#L10)

> 登或射獵，當由徑道，常遠避良田，不踐苗稼，至所頓息，又擇空閑之地，其不欲煩民如此。嘗乘馬出，有彈丸過，左右求之。有一人操彈佩丸，咸以爲是，辭對不服，從者欲捶之，登不聽，使求過丸，比之非類，乃見釋。又失盛水金馬盂，覺得其主，左右所爲，不忍致罰，呼責數之，長遣歸家，勑親近勿言。

**釋讀** 孫登射獵避開良田及莊稼，選空地歇息。他有一次騎馬出行遇彈丸飛過，隨從欲打攜弓彈之人，他命找出飛過的彈丸核對，發現不同便將人釋放。又一次察出盛水金馬盂被身邊人所取，召其責備而遣歸，囑侍從勿外傳。

**時段與依據** 三事敘其行事，無年月。「長遣」指使其長久離去。

## 孫登親敬弟孫和

孫登敬重受寵的弟弟孫和，曾有相讓儲位之意。

<a id="period-sgz059-p-003-1"></a>

<a id="wu059-l13-1"></a>

**[《三國志·吳主五子傳》裴注 003](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l13-1)** · [TXT L13](../../sources/本地分卷/三国志/三国志-卷059.txt#L13)

> 吳書曰：弟和有寵於權，登親敬，待之如兄，常有欲讓之心。

**釋讀** 孫和受孫權寵愛，孫登與他親近而敬之，待如兄長，常有意將儲位相讓。

**時段與依據** 寫孫登生前待孫和的長期態度。原注未記具體行讓之年或已交儲位。

## 謝景治豫章、卒於任上

謝景任豫章太守，吏民把他的政績與先前的顧劭相提並論。他後來在任上去世。

<a id="period-sgz059-b-2821-1"></a>

<a id="wu059-l21-1"></a>

**[《三國志·吳主五子傳》正文](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l21-1)** · [TXT L21](../../sources/本地分卷/三国志/三国志-卷059.txt#L21)

> 謝景者字叔發，南陽宛人。在郡有治迹，吏民稱之，以爲前有顧劭，其次即景。數年卒官。

**釋讀** 謝景字叔發，南陽宛人。治理豫章有成績，吏民稱道，以為可接續前任顧劭。其後數年卒於任上。

**時段與依據** 241年奔喪時已任豫章太守，始任與卒年未定。

## 孫慮的早年與任事

孫慮自幼有才，受孫權愛重。開府後遵守法度，聽取師友的勸告。

<a id="period-sgz059-b-2823-1"></a>

<a id="wu059-l25-1"></a>

**[《三國志·吳主五子傳》正文](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l25-1)** · [TXT L25](../../sources/本地分卷/三国志/三国志-卷059.txt#L25)

> 孫慮字子智，登弟也。少敏惠有才藝，權器愛之。

**釋讀** 孫慮字子智，是孫登的弟弟，少有才藝，聰敏而受孫權愛重。

**時段與依據** 本句為出身、才藝概述。

<a id="period-sgz059-b-2823-5"></a>

<a id="wu059-l27-1"></a>

**[《三國志·吳主五子傳》正文](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l27-1)** · [TXT L27](../../sources/本地分卷/三国志/三国志-卷059.txt#L27)

> 慮以皇子之尊，富於春秋，遠近嫌其不能留意。及至臨事，遵奉法度，敬納師友，過於衆望。

**釋讀** 孫慮身份尊貴而年少，眾人起初擔心他不肯用心。孫慮實際任事時遵守制度、敬納師友，超出眾人期待。

**時段與依據** 開府後表現的總述，起訖不詳。

## 孙和受宠、阚泽教书艺

<a id="period-sgz059-b-2825-1"></a>

<a id="wu059-l31-1"></a>

**[《三國志·吳主五子傳》正文](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l31-1)** · [TXT L31](../../sources/本地分卷/三国志/三国志-卷059.txt#L31)

> 孫和字子孝，慮弟也。少以母王有寵見愛，年十四，爲置宮衞，使中書令闞澤教以書藝。好學下士，甚見稱述。

**釋讀** 孙和字子孝，是孙虑的弟弟。其母王夫人得宠，孙权也喜爱孙和。孙和十四岁时获配宫卫，孙权使中书令阚泽教他书艺。孙和好学、敬重士人，颇受称誉。

**時段與依據** [242年立太子](ce-0242.md#sg-note-8)时年十九，据记龄可推十四岁约在237年。原传未给确年，宫卫与师傅先后随早年合叙。

## 孙和受宠好学、礼遇宾客

<a id="period-sgz059-p-007-1"></a>

<a id="wu059-l32-1"></a>

**[《三國志·吳主五子傳》裴注 007](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l32-1)** · [TXT L32](../../sources/本地分卷/三国志/三国志-卷059.txt#L32)

> 吳書曰：和少岐嶷有智意，故權尤愛幸，常在左右，衣服禮秩雕玩珍異之賜，諸子莫得比焉。好文學，善騎射，承師涉學，精識聦敏，尊敬師傅，愛好人物。穎等每朝見進賀，和常降意，歡以待之。講校經義，綜察是非，及訪諮朝臣，考績行能，以知優劣，各有條貫。

**釋讀** 《吴书》说孙和从小聪慧，孙权使他常在左右，衣服、礼仪、雕刻珍玩等赏赐超过诸子。他好文学、善骑射，随师精读，敬重师傅、爱好人物。蔡颖等入见祝贺，他都谦逊亲切。讲经辨析、访问朝臣和按政绩品行辨别贤能，各有条理。

**時段與依據** 上半写自少受宠，下半及东宫待士、讲学和察人常态，没有单独年月。

## 张纯早年仕行与入东宫

<a id="period-sgz059-p-007-3"></a>

<a id="wu059-l32-3"></a>

**[《三國志·吳主五子傳》裴注 007](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l32-3)** · [TXT L32](../../sources/本地分卷/三国志/三国志-卷059.txt#L32)

> 張純字元基，敦之子。吳錄曰：純少厲操行，學博才秀，切問捷對，容止可觀。拜郎中，補廣德令，治有異績，擢爲太子輔義都尉。

**釋讀** 张纯字元基，是张敦之子。《吴录》说他少时砥砺品行、学问才识过人，答问敏捷，举止可观。任郎中、广德令，有突出政绩，擢为太子辅义都尉。

**時段與依據** 《吴录》未记具体任命年月。张纯后来谏废孙和被处死，见[250年](ce-0250.md#sg-note-8)。

## 孙和抑制属官相讦

<a id="period-sgz059-b-2826-1"></a>

<a id="wu059-l34-1"></a>

**[《三國志·吳主五子傳》正文](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l34-1)** · [TXT L34](../../sources/本地分卷/三国志/三国志-卷059.txt#L34)

> 是時有司頗以條書問事，和以爲姦妄之人，將因事錯意，以生禍心，不可長也，表宜絕之。

**釋讀** 有司多以条列文书问事，孙和担心奸妄者会借机安排构陷，上表建议停止。

**時段與依據** 承其东宫时期，“是時”未明确是哪一年。

<a id="period-sgz059-b-2826-2"></a>

<a id="wu059-l34-2"></a>

**[《三國志·吳主五子傳》正文](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l34-2)** · [TXT L34](../../sources/本地分卷/三国志/三国志-卷059.txt#L34)

> 又都督劉寶白庶子丁晏，晏亦白寶，和謂晏曰：「文武在事，當能幾人，因隙構簿，圖相危害，豈有福哉？」遂兩釋之，使之從厚。

**釋讀** 都督刘宝与庶子丁晏互相检举。孙和指出能担当文武职务的人本就不多，乘隙罗织罪状只会使对方遇害，便宽免两人，要求以宽厚相待。

**時段與依據** 东宫属官事例，无确年。

## 孙和劝戒博弈、韦曜作文

<a id="period-sgz059-b-2826-3"></a>

<a id="wu059-l34-3"></a>

**[《三國志·吳主五子傳》正文](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l34-3)** · [TXT L34](../../sources/本地分卷/三国志/三国志-卷059.txt#L34)

> 常言當世士人宜講脩術學，校習射御，以周世務，而但交游博弈以妨事業，非進取之謂。後羣寮侍宴，言及博弈，以爲妨事費日而無益於用，勞精損思而終無所成，非所以進德脩業，積累功緒者也。且志士愛日惜力，君子慕其大者，高山景行，恥非其次。夫以天地長乆，而人居其間，有白駒過隙之喻，年齒一暮，榮華不再。凡所患者，在於人情所不能絕，誠能絕無益之欲以奉德義之塗，棄不急之務以脩功業之基，其於名行，豈不善哉？夫人情猶不能無嬉娛，嬉娛之好，亦在於飲宴琴書射御之間，何必博弈，然後爲歡。乃命侍坐者八人，各著論以矯之。

**釋讀** 孙和常说士人应研究术学、练习射御以应世务，交游和博弈误事。有次宴谈，他说博弈费时间心力而无实际所得，耽误德业。人生短促、华年难再，宜放下无益欲望，养品行、立功业。闲暇仍可宴饮、学琴读书、练习射御。他命在座八人各作文规劝。

**時段與依據** 由经常劝说转入一次宴谈，原传未记年月。

<a id="period-sgz059-b-2826-4"></a>

<a id="wu059-l34-4"></a>

**[《三國志·吳主五子傳》正文](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l34-4)** · [TXT L34](../../sources/本地分卷/三国志/三国志-卷059.txt#L34)

> 於是中庶子韋曜退而論奏，和以示賔客。時蔡穎好弈，直事在署者頗斆焉，故以此諷之。

**釋讀** 中庶子韦曜写成论说呈上，孙和给宾客传看。蔡颖爱好博弈，署内值班官吏多仿效，孙和借此规劝。

**時段與依據** 承八臣作文，确年未载。

## 太子与鲁王争议扩大，朝臣分立

<a id="period-sgz059-b-2827-2"></a>

<a id="wu059-l36-2"></a>

**[《三國志·吳主五子傳》正文](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l36-2)** · [TXT L36](../../sources/本地分卷/三国志/三国志-卷059.txt#L36)

> 魯王霸覬覦滋甚，陸遜、吾粲、顧譚等數陳適庶之義，理不可奪，全寄、楊笁爲魯王霸支黨，譖愬日興。

**釋讀** 鲁王孙霸更加想夺太子位。陆逊、吾粲、顾谭主张嫡庶名分不能动摇，全寄、杨笁站在鲁王一边，不断进谗。

**時段與依據** 二宫争议历年。245年的后果见[陆逊诸疏](ce-0245.md#sg-note-12)、[顾谭被徙](ce-0245.md#sgz-note-19)、[吾粲被诛](ce-0245.md#sgz-note-20)。

<a id="period-sgz059-p-008-2"></a>

<a id="wu059-l37-2"></a>

**[《三國志·吳主五子傳》裴注 008](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l37-2)** · [TXT L37](../../sources/本地分卷/三国志/三国志-卷059.txt#L37)

> 自侍御賔客造爲二端，仇黨疑貳，滋延大臣。丞相陸遜、大將軍諸葛恪、太常顧譚、驃騎將軍朱據、會稽太守滕胤、大都督施績、尚書丁密等奉禮而行，宗事太子，驃騎將軍步隲、鎮南將軍呂岱、大司馬全琮、左將軍呂據、中書令孫弘等附魯王，中外官僚將軍大臣舉國中分。

**釋讀** 《通语》说，从侍从、宾客彼此结党波及大臣。陆逊、诸葛恪、顾谭、朱据、滕胤、施绩、丁密奉事太子。步骘、吕岱、全琮、吕据、孙弘依附鲁王。内外将臣分为两方。

**時段與依據** 名单纵述多年。陆逊在[245年](ce-0245.md#sg-note-12)卒，而全琮、诸葛恪在[246年](ce-0246.md#sg-note-14)方分别授右大司马、大将军，官衔并列不能推定所有人于某年同任。裴松之对步骘是否确曾附霸也留疑。

<a id="period-sgz059-p-008-3"></a>

<a id="wu059-l37-4"></a>

**[《三國志·吳主五子傳》裴注 008](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l37-4)** · [TXT L37](../../sources/本地分卷/三国志/三国志-卷059.txt#L37)

> 　臣松之以爲袁紹、劉表謂尚、琮爲賢，本有傳後之意，異於孫權旣以立和而復寵霸，坐生亂階，自構家禍，方之袁、劉，昏悖甚矣。步隲以德度著稱，爲吳良臣，而阿附於霸，事同楊笁，何哉？和旣正位，適庶分定，就使才德不殊，猶將義不黨庶，況霸實無聞，而和爲令嗣乎？夫邪僻之人，豈其舉體無善，但一爲不善，衆美皆亡耳。隲若果有此事，則其餘不足觀矣！呂岱、全琮之徒，蓋所不足論耳。

**釋讀** 裴松之认为袁绍、刘表本想传位给自己认可的袁尚、刘琮，孙权先正式立孙和却又宠孙霸，是亲自引起这一争端。他质问一向有德名的步骘为何附孙霸，认为名分已定、孙和有美才，即使二人才德相当也不应偏助庶子。他用“若果有此事”评论步骘，连同吕岱、全琮一并批评。

**時段與依據** 裴松之在《通语》记载之后作评论。步骘附鲁王名单据《通语》一说，保留原案语的条件判断。

<a id="period-sgz059-p-013-4"></a>

> 俊，張承外孫，聦明辨惠，爲遠近所稱，皓又殺之。

**釋讀** 孫俊是張承的外孫，聰慧善辯、為遠近稱道，孫皓也殺了他。

## 孫霸二子五鳳中受封

<a id="period-sgz059-b-2833-1"></a>

> 霸二子，基、壹。五鳳中，封基爲吳侯，壹宛陵侯。

**釋讀** 孫霸二子孫基、孫壹。孫亮五鳳年間封孫基為吳侯，孫壹為宛陵侯。

## 陳壽總評孫權五子

<a id="period-sgz059-b-2838-1"></a>

<a id="wu059-l72-1"></a>

**[《三國志·吳主五子傳》正文](../../sources/本地分卷/三国志/三国志-卷059.md#edition-wu059-l72-1)** · [TXT L72](../../sources/本地分卷/三国志/三国志-卷059.txt#L72)

> 評曰：孫登居心所存，足爲茂美之德。慮、和並有好善之姿，規自砥礪，或短命早終，或不得其死，哀哉！霸以庶干適，奮不遵軌度，固取危亡之道也。然奮之誅夷，橫遇飛禍矣。

**釋讀** 陳壽稱讚孫登的存心與德行，惋惜有好善之心的孫慮早逝、孫和不得善終；認為孫霸以庶干嫡、孫奮不守法度都有招禍之行，又指出孫奮父子遭誅是橫禍。

**時段與依據** 全卷總評，跨孫權五子生平，不附任何單一年份。

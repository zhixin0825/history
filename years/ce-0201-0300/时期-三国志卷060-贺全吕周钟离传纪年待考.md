## 賀齊家世與賀純改姓

<a id="period-sgz060-b-2840-1"></a>

<a id="wu060-l5-1"></a>

**[《三國志·賀全呂周鍾離傳》正文](../../sources/本地分卷/三国志/三国志-卷060.md#edition-wu060-l5-1)** · [TXT L5](../../sources/本地分卷/三国志/三国志-卷060.txt#L5)

> 賀齊字公苗，會稽山陰人也。

**釋讀** 賀齊字公苗，會稽郡山陰縣人。

**時段與依據** 本傳開首交代姓名、郡望，未紀生年。

<a id="period-sgz060-p-001-1"></a>

<a id="wu060-l6-1"></a>

**[《三國志·賀全呂周鍾離傳》裴注 001](../../sources/本地分卷/三国志/三国志-卷060.md#edition-wu060-l6-1)** · [TXT L6](../../sources/本地分卷/三国志/三国志-卷060.txt#L6)

> 虞預晉書曰：賀氏本姓慶氏。齊伯父純，儒學有重名，漢安帝時爲侍中、江夏太守，

**釋讀** 虞預《晉書》說賀氏原姓慶。賀齊伯父賀純以儒學知名，漢安帝時任侍中、江夏太守。

**時段與依據** 漢安帝在位為106至125年，各次授官的年月不詳。

<a id="period-sgz060-p-001-3"></a>

<a id="wu060-l6-3"></a>

**[《三國志·賀全呂周鍾離傳》裴注 001](../../sources/本地分卷/三国志/三国志-卷060.md#edition-wu060-l6-3)** · [TXT L6](../../sources/本地分卷/三国志/三国志-卷060.txt#L6)

> 避安帝父孝德皇帝諱，改爲賀氏。齊父輔，永寧長。

**釋讀** 慶氏避安帝父親劉慶的名諱，改姓賀。賀齊父賀輔曾任永寧長。

**時段與依據** 《晉書》〈賀循傳〉也記改姓。《後漢書》〈安帝紀〉建光元年（121）追尊其父為孝德皇。改姓及賀輔任官皆無確年。

## 賀齊早年任剡、太末長

<a id="period-sgz060-b-2841-1"></a>

<a id="period-sgz060-b-2841-2"></a>

<a id="period-sgz060-b-2841-3"></a>

**[《三國志·賀全呂周鍾離傳》正文](../../sources/本地分卷/三国志/三国志-卷060.md#edition-wu060-l7-1)** · [TXT L7](../../sources/本地分卷/三国志/三国志-卷060.txt#L7)

> 少爲郡吏，守剡長。縣吏斯從輕俠爲姧，齊欲治之，主簿諫曰：「從，縣大族，山越所附，今日治之，明日寇至。」齊聞大怒，便立斬從。從族黨遂相糾合，衆千餘人，舉兵攻縣。齊率吏民，開城門突擊，大破之，威震山越。

**釋讀** 賀齊年少任郡吏，署理剡長。縣吏斯從仗勢犯法，主簿說他是縣中大族、山越依附，今日治罪明日便有兵來。賀齊當場處斬斯從。斯從族黨集結千餘人攻縣，賀齊率吏民開門突擊，擊潰來兵，震懾山越。

**時段與依據** 在孫策建安元年入會稽前，任職和戰鬥確年待考。標點 TXT 作「斬從」。

> 後太末、豐浦民反，轉守太末長，誅惡養善，期月盡平。

**釋讀** 後來太末、豐浦民眾起事，賀齊轉署太末長，誅首惡而撫善良，一月之間平定。

**時段與依據** 上下文在建安元年以前，無獨立年月。

## 韓晏兵敗後，賀齊終平候官

<a id="period-sgz060-b-2841-8"></a>

<a id="period-sgz060-b-2841-9"></a>

<a id="wu060-l9-2"></a>

**[《三國志·賀全呂周鍾離傳》正文](../../sources/本地分卷/三国志/三国志-卷060.md#edition-wu060-l9-2)** · [TXT L9](../../sources/本地分卷/三国志/三国志-卷060.txt#L9)

> 晏爲升所敗，齊又代晏領都尉事。升畏齊威名，遣使乞盟。齊因告喻，爲陳禍福，升遂送上印綬，出舍求降。賊帥張雅、詹彊等不願升降，反共殺升，雅稱無上將軍，彊稱會稽太守。

**釋讀** 韓晏敗給商升，賀齊接掌南部都尉事。商升懾於賀齊聲威，先遣使請盟，經賀齊陳說利害，交印出舍求降。張雅、詹彊殺商升，分別自稱無上將軍、會稽太守。

**時段與依據** 196年王朗去東冶後、203年本傳追敘「候官旣平」前。其間各階段未見確年。

<a id="period-sgz060-b-2841-10"></a>

<a id="period-sgz060-b-2841-11"></a>

<a id="wu060-l9-3"></a>

**[《三國志·賀全呂周鍾離傳》正文](../../sources/本地分卷/三国志/三国志-卷060.md#edition-wu060-l9-3)** · [TXT L9](../../sources/本地分卷/三国志/三国志-卷060.txt#L9)

> 賊盛兵少，未足以討，齊住軍息兵。雅與女壻何雄爭勢兩乖，齊令越人因事交構，遂致疑隙，阻兵相圖。齊乃進討，一戰大破雅，彊黨震懼，率衆出降。

**釋讀** 賀齊見敵盛兵少，留軍休整。張雅和女婿何雄爭權，賀齊讓越人乘隙離間，兩人起疑，以兵相圖。賀齊趁勢大敗張雅，詹彊部眾畏懼而降。

**時段與依據** 同一候官戰事後半段，203年進兵建安時候官已平，終戰年月無從反推。

## 賀達、賀景與其子賀質、賀邵

<a id="period-sgz060-b-2850-4"></a>

<a id="wu060-l38-4"></a>

**[《三國志·賀全呂周鍾離傳》正文](../../sources/本地分卷/三国志/三国志-卷060.md#edition-wu060-l38-4)** · [TXT L38](../../sources/本地分卷/三国志/三国志-卷060.txt#L38)

> 子達及弟景皆有令名，爲佳將。

**釋讀** 賀齊之子賀達及賀達的弟弟賀景都有聲名，是良將。

**時段與依據** 家世回敘。《晉書》〈賀循傳〉明記賀循曾祖為賀齊、祖父為賀景、父為賀邵，可知賀景是賀齊之子。

> 會稽典錄曰：景爲滅賊校尉，御衆嚴而有恩，兵器精飾，爲當時冠絕，早卒。

**釋讀** 《會稽典錄》記賀景任滅賊校尉，治軍嚴而待部下有恩，武器製作精良為一時之冠，早逝。

**時段與依據** 只稱「早卒」，無授官及卒年。

> 達頗任氣，多所犯迕，故雖有征戰之勞，而爵位不至，然輕財貴義，膽烈過人。子質，位至虎牙將軍。

**釋讀** 賀達任性不羈，屢有冒犯，雖有戰功，爵位仍不顯。然而他輕財重義，膽力過人。賀達之子賀質官至虎牙將軍。

**時段與依據** 性行、所述戰功與賀質遷官缺確年。〈吳主傳〉另記賀達233年奉命出使遼東。

## 全琮散米救急

<a id="period-sgz060-b-2852-5"></a>

<a id="period-sgz060-b-2852-6"></a>

<a id="wu060-l43-4"></a>

**[《三國志·賀全呂周鍾離傳》正文](../../sources/本地分卷/三国志/三国志-卷060.md#edition-wu060-l43-4)** · [TXT L43](../../sources/本地分卷/三国志/三国志-卷060.txt#L43)

> 柔甞使琮齎米數千斛到吳，有所市易。琮至，皆散用，空船而還。柔大怒，琮頓首曰：「愚以所市非急，而士大夫方有倒縣之患，故便振贍，不及啟報。」柔更以奇之。

**釋讀** 全柔命全琮載數千斛米到吳地易物，全琮盡數散給陷於危困的士大夫，空船回來。父親大怒，全琮叩頭說貨物並非急需，救人來不及請示。全柔反而更以他為奇。

**時段與依據** 父子軼事未繫年月，緊接著敘中州士人南渡受助。

<a id="period-sgz060-p-009-1"></a>

<a id="period-sgz060-p-009-2"></a>

<a id="wu060-l44-1"></a>

**[《三國志·賀全呂周鍾離傳》裴注 009](../../sources/本地分卷/三国志/三国志-卷060.md#edition-wu060-l44-1)** · [TXT L44](../../sources/本地分卷/三国志/三国志-卷060.txt#L44)

> 徐衆評曰：禮，子事父無私財，又不敢私施，所以避尊上也。棄命專財而以邀名，未盡父子之禮。　臣松之以爲子路問「聞斯行諸」？子曰「有父兄在」。琮輒散父財，誠非子道，然士類縣命，憂在朝夕，權其輕重，以先人急，斯亦馮煖市義、汲黯振救之類，全謂邀名，或負其心。

**釋讀** 徐眾認為子為人子不可私財或擅施，全琮違父命動用財物求名，有失子道。裴松之援子路受孔子教誡，承認此舉不合常禮，同時認為士人性命旦夕，權衡而急人之困，可比馮煖市義及汲黯賑災，指斥邀名恐有負其本心。

**時段與依據** 附全琮擅散家米的故事，評論自身無事件年代。

<a id="period-sgz060-b-2852-7"></a>

<a id="wu060-l45-1"></a>

**[《三國志·賀全呂周鍾離傳》正文](../../sources/本地分卷/三国志/三国志-卷060.md#edition-wu060-l45-1)** · [TXT L45](../../sources/本地分卷/三国志/三国志-卷060.txt#L45)

> 是時中州士人避亂而南，依琮居者以百數，琮傾家給濟，與共有無，遂顯名遠近。

**釋讀** 數百名避亂南下的中州士人依附全琮，他傾家資助，與他們有無相通，因此名聞遠近。

**時段與依據** 與散米同階段，避亂來歸非一日之事。

## 全琮由敢戰到持重

<a id="period-sgz060-p-012-1"></a>

<a id="wu060-l56-1"></a>

**[《三國志·賀全呂周鍾離傳》裴注 012](../../sources/本地分卷/三国志/三国志-卷060.md#edition-wu060-l56-1)** · [TXT L56](../../sources/本地分卷/三国志/三国志-卷060.txt#L56)

> 吳書曰：初，琮爲將甚勇決，當敵臨難，奮不顧身。及作督帥，養威持重，每御軍，常任計策，不營小利。

**釋讀** 全琮初為將勇敢果決，臨敵奮不顧身，任統帥之後以威重自持，御軍多仗計策，無意於小利。

**時段與依據** 一生行事概述，與注文下段諫止太子出征一併讀。

<a id="period-sgz060-p-012-2"></a>

<a id="wu060-l56-2"></a>

**[《三國志·賀全呂周鍾離傳》裴注 012](../../sources/本地分卷/三国志/三国志-卷060.md#edition-wu060-l56-2)** · [TXT L56](../../sources/本地分卷/三国志/三国志-卷060.txt#L56)

> 　江表傳曰：權使子登出征，已出軍，次于安樂，羣臣莫敢諫。琮密表曰：「古來太子未甞偏征也，故從曰撫軍，守曰監國。今太子東出，非古制也，臣竊憂疑。」權即從之，命登旋軍，議者咸以爲琮有大臣之節也。

**釋讀** 孫權遣孫登出征，太子軍已至安樂，群臣不敢諫。全琮密疏說古來太子隨軍為撫軍、留守為監國，不能偏領一方面出征，孫權從之，命孫登回師，議者稱其具大臣之節。

**時段與依據** 孫登在221年為王太子、229年為皇太子，241年卒；本注無年，卷059未有這次到安樂可對繫的年月，不能因注在黃龍元年之下便定某歲。

## 全琮進規宛轉

<a id="period-sgz060-b-2856-2"></a>

<a id="wu060-l61-2"></a>

**[《三國志·賀全呂周鍾離傳》正文](../../sources/本地分卷/三国志/三国志-卷060.md#edition-wu060-l61-2)** · [TXT L61](../../sources/本地分卷/三国志/三国志-卷060.txt#L61)

> 爲人恭順，善於承顏納規，言辭未甞切迕。

**釋讀** 全琮為人恭順，善於體察君意而進諫，措詞不曾激切衝撞。

**時段與依據** 人物概述，與多年行事放在一起。

<a id="wu060-l61-5"></a>

> 徐衆評曰：牧蹈長者之規。問者曰：「如牧所行，犯而不校，又從而救之，直而不有，又還而不受，可不謂之仁讓乎哉？」荅曰：「異乎吾所聞。原憲之問於孔子曰：『克伐怨欲不行焉，可以爲仁乎？』孔子曰：『可以爲難矣，仁則吾不知也。』『惡不仁者，其爲仁矣。』今小民不展四體，而認人之稻，不仁甚矣，而牧推而與之，又救其罪，斯爲讓非其義，所救非人，非所謂惡不仁者。苟不惡不仁，安得爲仁哉！蒼梧澆娶妻而美，讓於其兄；尾生篤信，水至不去而死；直躬好直，證父攘羊；申鳴奉法，盡忠於君而執其父。忠信直讓，此四行者，聖賢之所貴也。然不貴蒼梧之讓，非讓道也；不取尾生之信，非信所也；不許直躬之直，非直體也；不嘉申鳴之忠，非忠意也。今牧犯而不校，還而不取，可以爲難矣，未得爲仁讓也。夫聖人以德報德，以直報怨，而牧欲以德報怨，非也。必不得已，二者何從？吾從孔子也。」

**時段與依據** 後出的徐眾史評隨永興讓稻合讀。

> 會稽典錄曰：牧之在濡須，深以進取可圖，而不敢陳其策，與侍中東觀令朱育宴，慨然歎息。育謂牧恨於策爵未副，因謂牧曰：「朝廷諸君，以際會坐取高官，亭侯功無與比，不肯在人下，見顧者猶以於邑，況於侯也！」牧笑而荅曰：「卿之所言，未獲我心也。馬援有言，人當功多而賞薄。吾功不足錄，而見寵已過當，豈以爲恨？國家不深相知，而見害朝人，是以默默不敢有所陳。若其不然，當建進取之計，以報所受之恩，不徒自守而已，憤歎以此也。」育復曰：「國家已自知侯，以侯之才，無爲不成。愚謂自可陳所懷。」牧曰：「武安君謂秦王云：『非成業難，得賢難；非得賢難，用之難；非用之難，任之難。』武安君欲爲秦王并兼六國，恐授事而不見任，故先陳此言。秦王旣許而不能，卒隕將成之業，賜劒杜郵。今國家知吾，不如秦王之知武安，而害吾者有過范雎。大皇帝時，陸丞相討鄱陽，以二千人授吾，潘太常討武陵，吾又有三千人，而朝廷下議，棄吾於彼，使江渚諸督，不復發兵相繼。蒙國威靈自濟，今日何爲常。向使吾不料時度宜，苟有所陳，至見委以事，不足兵勢，終有敗績之患，何無不成之有？」

**釋讀** 鍾離牧在濡須認為有進取的機會，卻不敢陳策，宴中嘆息。朱育以為他嫌爵位低，鍾離牧引用馬援的話，說自己的功本不多而受寵已過，只是怕朝廷未知己、又有官員從中阻害。朱育勸他直陳，鍾離牧引白起兼併六國的設想及終遭賜死為鑑，認為吳廷對自己的信任還不及秦王對白起。他回顧從陸遜討鄱陽受兵兩千、隨潘濬討武陵有兵三千，兩次無後續援兵，勉強渡過危局，指出若不度時宜便進言、到受命時兵力仍不足，終將敗事。

**時段與依據** 屬改督濡須時的一次對談。陸遜與潘濬舊役是對話中的回顧，潘濬討五谿可參《通鑑》卷七十二太和五年，鄱陽一事未據此另定年，亦不反定濡須對話年。

## 陳壽論平定內難及諸臣得失

> 評曰：山越好爲叛亂，難安易動，是以孫權不遑外禦，卑詞魏氏。凡此諸臣，皆克寧內難，綏靜邦域者也。呂岱清恪在公；周魴譎略多奇；鍾離牧蹈長者之規；全琮有當世之才，貴重於時，然不檢姧子，獲譏毀名云。

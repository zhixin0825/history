### 贺齐小传题头

[《三国志·贺全吕周钟离传》仓内原文 L2840](../../sources/本地分卷/三国志/三国志-卷060.md#l2840)

> 賀齊

以下为贺齐传。

**时段与依据** 分传题头。

<a id="period-sgz060-b-2841-1"></a>

### 贺齐早年出守剡县

[《三国志·贺全吕周钟离传》仓内原文 L2841](../../sources/本地分卷/三国志/三国志-卷060.md#l2841)

> 賀齊字公苗，會稽山陰人也。少為郡吏，守剡長。

贺齐字公苗，是会稽山阴人，少年任郡吏，署理剡长。

**时段与依据** 本传“少”。

<a id="period-sgz060-b-2841-2"></a>

### 贺齐处置剡吏斯从

[《三国志·贺全吕周钟离传》仓内原文 L2841](../../sources/本地分卷/三国志/三国志-卷060.md#l2841)

> 縣吏斯從輕俠為奸，齊欲治之。主簿諫曰：「從，縣大族，山越所附，今日治之，明日寇至。」齊聞大怒，便立斬眾。

县吏斯从挟势犯法。主簿担心大族和山越报复，贺齐仍下令处斩。

**时段与依据** 承署剡长，未记年。底本“斬眾”，四库点校本作“斬從”。

<a id="period-sgz060-b-2841-3"></a>

### 贺齐破斯从族党

[《三国志·贺全吕周钟离传》仓内原文 L2841](../../sources/本地分卷/三国志/三国志-卷060.md#l2841)

> 從族黨遂相糾合，眾千餘人，舉兵攻縣。齊率吏民，開城門突擊，大破之，威震山越。

斯从族党千余人攻城，贺齐率吏民开门突击取胜。

**时段与依据** 承斩斯从。

<a id="period-sgz060-b-2841-4"></a>

### 贺齐平太末、丰浦

[《三国志·贺全吕周钟离传》仓内原文 L2841](../../sources/本地分卷/三国志/三国志-卷060.md#l2841)

> 後太末、豐浦民反，轉守太末長，誅惡養善，期用盡平。

太末、丰浦民众起事，贺齐转署太末长，诛恶抚善，平定当地。

**时段与依据** 在入孙策幕前。

<a id="period-sgz060-b-2841-8"></a>

### 贺齐接掌讨商升之军

[《三国志·贺全吕周钟离传》仓内原文 L2841](../../sources/本地分卷/三国志/三国志-卷060.md#l2841)

> 晏為升所敗，齊又代晏領都尉事。升畏齊威名，遣使乞盟。

韩晏兵败，贺齐接掌都尉事务，商升因畏惧贺齐派人求盟。

**时段与依据** 在孙策攻取会稽之后、建安八年侯官平定以前。

<a id="period-sgz060-b-2841-9"></a>

### 商升请降，张雅等杀商升

[《三国志·贺全吕周钟离传》仓内原文 L2841](../../sources/本地分卷/三国志/三国志-卷060.md#l2841)

> 齊因告喻，為陳禍福，升遂送上印綬，出捨求降。賊帥張雅、詹強等不願升降，反共殺升，雅稱無上將軍，強稱會稽太守。

贺齐陈说利害，商升交印而降，张雅、詹强杀商升，自称将军与会稽太守。

**时段与依据** 承韩晏败，确年待考。

<a id="period-sgz060-b-2841-10"></a>

### 贺齐利用张雅、何雄相争

[《三国志·贺全吕周钟离传》仓内原文 L2841](../../sources/本地分卷/三国志/三国志-卷060.md#l2841)

> 賊盛兵少，未足以討，齊住軍息兵。雅與女婿何雄爭勢兩乖，齊令越人因事交構。遂至疑隙，阻兵相圖。

贺齐因兵少按兵休整，借越人离间张雅和女婿何雄，两方生隙，各自准备动武。

**时段与依据** 承商升被杀。

<a id="period-sgz060-b-2841-11"></a>

### 贺齐破张雅，詹强余众归降

[《三国志·贺全吕周钟离传》仓内原文 L2841](../../sources/本地分卷/三国志/三国志-卷060.md#l2841)

> 齊乃進討，一戰大破雅，強黨震懼，率眾出降。

贺齐乘机进军击破张雅，詹强部众因畏惧而降。

**时段与依据** 下文建安八年已称侯官平定，不能反推具体年。

<a id="period-sgz060-b-2849-1"></a>

### 贺齐治军器与舰船

[《三国志·贺全吕周钟离传》仓内原文 L2849](../../sources/本地分卷/三国志/三国志-卷060.md#l2849)

> 齊性奢綺，尤好軍事，兵甲器械極為精好，所乘船雕刻丹鏤，青蓋絳襜，干櫓戈矛，葩爪文畫，弓弩矢箭，咸取上材，蒙衝鬥艦之屬，望之若山。

贺齐喜军务、服用华丽，甲兵工良，舟舰雕饰，弓弩用材上等，舰阵壮盛。

**时段与依据** 性情与军装备概述。

<a id="period-sgz060-b-2849-3"></a>

### 贺齐任后将军

[《三国志·贺全吕周钟离传》仓内原文 L2849](../../sources/本地分卷/三国志/三国志-卷060.md#l2849)

> 遷後將軍，假節領徐州牧。

贺齐迁后将军、假节、领徐州牧。

**时段与依据** 本传接曹休撤军，授官具体日期未见。

<a id="period-sgz060-b-2850-1"></a>

### 晋宗叛吴投魏

[《三国志·贺全吕周钟离传》仓内原文 L2850](../../sources/本地分卷/三国志/三国志-卷060.md#l2850)

> 初，晉宗為戲口將，以眾叛如魏，還為蘄春太守，圖襲安樂，取其保質。

戏口将晋宗率众投魏，任蕲春太守，企图袭安乐夺取人质。

**时段与依据** 《吴主传》将叛魏追记作擒宗前事，没有独立年。

<a id="period-sgz060-b-2850-4"></a>

### 贺齐之子贺达、贺景

[《三国志·贺全吕周钟离传》仓内原文 L2850](../../sources/本地分卷/三国志/三国志-卷060.md#l2850)

> 子達及弟景皆有令名，為佳將。

贺达及贺达之弟贺景同有名，为良将。

**时段与依据** 家传概述，裴注分别叙二子及贺景之子贺邵。

### 全琮小传题头

[《三国志·贺全吕周钟离传》仓内原文 L2851](../../sources/本地分卷/三国志/三国志-卷060.md#l2851)

> 全琮

以下为全琮传。

**时段与依据** 分传题头。

<a id="period-sgz060-b-2852-1"></a>

### 全琮家世及父亲全柔初仕

[《三国志·贺全吕周钟离传》仓内原文 L2852](../../sources/本地分卷/三国志/三国志-卷060.md#l2852)

> 全琮字子璜，吳郡錢唐人也。父柔，漢靈帝時舉孝廉。補尚書郎右丞，

全琮字子璜，吴郡钱唐人。父全柔在灵帝时举孝廉，补尚书郎右丞。

**时段与依据** 只明灵帝时，具体年待考。

<a id="period-sgz060-b-2852-2"></a>

### 全柔弃官与复职

[《三国志·贺全吕周钟离传》仓内原文 L2852](../../sources/本地分卷/三国志/三国志-卷060.md#l2852)

> 董卓之亂，棄官歸。州辟別駕從事，詔書就拜會稽東部都尉。

董卓作乱时，全柔弃官回乡，后来应州辟任别驾，诏授会稽东部都尉。

**时段与依据** 前事在189—192年间，后续各职未见确年。

<a id="period-sgz060-b-2852-3"></a>

### 全柔从孙策

[《三国志·贺全吕周钟离传》仓内原文 L2852](../../sources/本地分卷/三国志/三国志-卷060.md#l2852)

> 孫策到吳，柔舉兵先附，策表柔為丹楊都尉。

孙策到吴，全柔率兵先归附，孙策表授丹杨都尉。

**时段与依据** 在孙策平江东阶段，未记明确月年。

<a id="period-sgz060-b-2852-5"></a>

### 全琮赈济士人

[《三国志·贺全吕周钟离传》仓内原文 L2852](../../sources/本地分卷/三国志/三国志-卷060.md#l2852)

> 柔嘗使琮齎米數千斛到吳，有所市易。琮至，皆散用，空船而還。

全柔令全琮运粮到吴地交易，全琮把粮财发散，空船返家。

**时段与依据** 父子轶事未载纪年。

<a id="period-sgz060-b-2852-6"></a>

### 全琮向全柔陈说赈饥

[《三国志·贺全吕周钟离传》仓内原文 L2852](../../sources/本地分卷/三国志/三国志-卷060.md#l2852)

> 柔大怒，琮頓首曰：「愚以所市非急，而士大夫方有倒縣之患，故便振贍，不及啟報。」柔更以奇之。

全柔怒问，全琮告知所购物非急，士人却危困，来不及请示，父亲反以为奇。

**时段与依据** 承散粮。

<a id="period-sgz060-b-2852-7"></a>

### 全琮接济避乱士人

[《三国志·贺全吕周钟离传》仓内原文 L2852](../../sources/本地分卷/三国志/三国志-卷060.md#l2852)

> 是時中州士人避亂而南，依琮居者以百數，琮傾家給濟，與共有無，遂顯名遠近。

中州避乱来依附全琮者数百，他倾家援助，因此闻名。

**时段与依据** 中州士人南渡为一时期。

<a id="period-sgz060-b-2852-8"></a>

### 全琮招募军士屯牛渚

[《三国志·贺全吕周钟离传》仓内原文 L2852](../../sources/本地分卷/三国志/三国志-卷060.md#l2852)

> 後權以為奮威校尉，授兵數千人，使討山越。因開募召，得精兵萬餘人，出屯牛渚，稍遷偏將軍。

孙权授全琮奋威校尉，付数千兵讨山越。全琮招精兵万余屯牛渚，渐迁偏将军。

**时段与依据** 相对次序，居关羽之役前。

<a id="period-sgz060-b-2854-6"></a>

### 全琮治理东安、招降山民

[《三国志·贺全吕周钟离传》仓内原文 L2854](../../sources/本地分卷/三国志/三国志-卷060.md#l2854)

> 至，明賞罰。招誘降附，數年中，得萬餘人。

到任明确赏罚，招纳降附者，数年招得万余人。

**时段与依据** 东安存续约226—228年，累计数不可定于一岁。

<a id="period-sgz060-b-2856-2"></a>

### 全琮委婉进规

[《三国志·贺全吕周钟离传》仓内原文 L2856](../../sources/本地分卷/三国志/三国志-卷060.md#l2856)

> 為人恭順，善於承顏納規，言辭未嘗切迕。

全琮待人谦恭，能婉转进规，措辞从不激烈。

**时段与依据** 人物概述。

<a id="period-sgz060-b-2856-3"></a>

### 全琮反对远征海岛

[《三国志·贺全吕周钟离传》仓内原文 L2856](../../sources/本地分卷/三国志/三国志-卷060.md#l2856)

> 初，權將圍珠崖及夷州，皆先問琮。

孙权拟用兵珠崖、夷州，都问全琮意见。

**时段与依据** 《吴主传》分别记230年遣人求夷洲、242年出兵珠崖，传文合叙。

<a id="period-sgz060-b-2856-4"></a>

### 全琮反对远征海岛

[《三国志·贺全吕周钟离传》仓内原文 L2856](../../sources/本地分卷/三国志/三国志-卷060.md#l2856)

> 琮曰：「以聖朝之威，何向而不克?然殊方異域，隔絕障海，水土氣毒，自古有之，兵入民出，必生疾病，轉相污染，往者懼不能反，所獲何可多致？猥虧江岸之兵，以冀萬一之利，愚臣猶所不安。」

全琮认为南海地远水土殊异，深入易疫，削减江防换微利，风险过大。

**时段与依据** 传文把两事合叙，此段答语归属缺少明证。

<a id="period-sgz060-b-2856-5"></a>

### 全琮追论海岛用兵

[《三国志·贺全吕周钟离传》仓内原文 L2856](../../sources/本地分卷/三国志/三国志-卷060.md#l2856)

> 權不聽。軍行經歲，士眾疾疫死者十有八九，權深悔之。後言次及之，琮對曰："當是時，群臣有不諫者，臣以為不忠。"

孙权不听，军行逾年，多死于疫，深悔；后来重提，全琮说当时不谏即不忠。

**时段与依据** 《吴主传》见夷洲船师230年出、231年回，珠崖战另在242年。本传前接两事，未明此番对答年及疫事与珠崖之关系。

<a id="period-sgz060-b-2857-1"></a>

### 全琮宗族受宠

[《三国志·贺全吕周钟离传》仓内原文 L2857](../../sources/本地分卷/三国志/三国志-卷060.md#l2857)

> 琮既親重，宗族子弟並蒙寵貴，賜累千金，然猶謙虛接士，貌無驕色。

孙权亲重全琮，全氏子弟获宠封与厚赐，而全琮仍谦虚待士。

**时段与依据** 多年情形。

<a id="period-sgz060-b-2857-3"></a>

> 後襲業領兵，

全怿随后承袭父业、领兵。

**时段与依据** 卒年有异说，且没有接兵独立纪年。

吕岱字定公，广陵海陵人，曾任郡县吏，因乱南渡。

**时段与依据** 未载年月。

<a id="period-sgz060-b-2859-3"></a>

### 吕岱以明法受任余姚

[《三国志·贺全吕周钟离传》仓内原文 L2859](../../sources/本地分卷/三国志/三国志-卷060.md#l2859)

> 權親斷諸縣倉庫及囚系，長丞皆見，岱處法應問，甚稱權意，召署錄事，出補餘姚長，召募精健，得千餘人。

孙权问各县仓储和狱案，吕岱应答合意，署录事，出为余姚长，募兵千余。

**时段与依据** 在孙权统事后，诸任缺独年。

<a id="period-sgz060-b-2859-4"></a>

### 吕岱、蒋钦平东冶五县

[《三国志·贺全吕周钟离传》仓内原文 L2859](../../sources/本地分卷/三国志/三国志-卷060.md#l2859)

> 會稽東冶五縣賊呂合、秦狼等為亂，權以岱為督軍校尉，與將軍蔣欽等將兵討之，遂擒合、狼，五縣平定，拜昭信中郎將。

吕合、秦狼等起事，吕岱任督军校尉，与蒋钦等擒其首，五县平，升昭信中郎将。

**时段与依据** 《蒋钦传》也载，置于208年黟战之前，无法定某年。

<a id="period-sgz060-b-2860-4"></a>

### 吴砀、袁龙据县响应关羽

[《三国志·贺全吕周钟离传》仓内原文 L2860](../../sources/本地分卷/三国志/三国志-卷060.md#l2860)

> 安成長吳碭及中郎將袁龍等首尾關羽，復為反亂。碭據攸縣，龍在醴陵。

安成长吴砀、中郎将袁龙与关羽呼应，吴砀据攸县，袁龙据醴陵。

**时段与依据** 215年平三郡后、鲁肃217年去世前。《吴主传》未详此后续。

<a id="period-sgz060-b-2860-5"></a>

### 鲁肃、吕岱分击吴砀袁龙

[《三国志·贺全吕周钟离传》仓内原文 L2860](../../sources/本地分卷/三国志/三国志-卷060.md#l2860)

> 權遣橫江將軍魯肅攻攸，碭得突走。岱攻醴陵，遂禽斬龍。

### 《抱朴子》记贺将军以木棒破术

[《三国志·贺全吕周钟离传》裴注 004·1](../../sources/摘录/三国志-卷060-贺全吕周钟离传裴注.md#pei-004-1)

> 抱朴子曰昔吳遣賀將軍討山賊賊中有善禁者毎當交戰官軍刀劔不得㧞弓弩射矢皆還自向輒致不利賀將軍長情有思乃曰吾聞金有刃者可禁蟲有毒者可禁其無刃之物無毒之蟲則不可禁彼必是能禁吾兵者也必不能禁無刃物矣乃多作勁木白棓選有力精卒五千人為先登盡捉棓彼山賊恃其有善禁者了不嚴備於是官軍以白棓擊之彼禁者果不復行所擊殺者萬計

葛洪书载山兵善禁刀箭，官军受阻，贺将军认为无刃物可用，改令五千勇士持棒冲击，最后斩获甚多。

### 孙权与贺齐谈开国功

[《三国志·贺全吕周钟离传》裴注 006·1](../../sources/摘录/三国志-卷060-贺全吕周钟离传裴注.md#pei-006-1)

> 吳書曰權謂齊曰今定天下都中國使殊俗貢珍狡獸率舞非君誰與齊曰殿下以神武應期廓開王業臣幸遭際㑹得驅馳風塵之下佐助末行效鷹犬之用臣之願也若殊俗貢珍狡獸率舞宜在聖徳非臣所能

《吴书》记孙权说定天下、外族献珍，有赖贺齐，贺齐自称愿效驱驰，远人来归出自君德。

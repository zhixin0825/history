## 潘濬的籍貫與受學

<a id="period-sgz061-b-2892-1"></a>

<a id="wu061-l5-1"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l5-1)** · [TXT L5](../../拆分史书/三国志/卷061.txt#L5)

> 潘濬字承明，武陵漢壽人也。弱冠從宋仲子受學。

**釋讀** 潘濬字承明，武陵郡漢壽人，約二十歲從宋仲子受學。

**時段與依據** 傳文只記弱冠，未載出生與從師年月。宋仲子即宋忠，參卷042〈尹默傳〉正文與裴注。

<a id="wu061-l6-1"></a>

**[《三國志·潘濬陸凱傳》裴注 001](../../拆分史书/三国志/卷061.md#edition-wu061-l6-1)** · [TXT L6](../../拆分史书/三国志/卷061.txt#L6)

> 吳書曰：濬爲人聦察，對問有機理，山陽王粲見而貴異之。由是知名，爲郡功曹。

**釋讀** 潘濬聰敏明察，答問有條理。山陽王粲見了他，覺得與眾不同。潘濬因而成名，當上郡功曹。

**時段與依據** 《吳書》記知遇和任郡官的先後，兩事無確年。

> 年未三十，荊州牧劉表辟爲部江夏從事。時沙羡長贓穢不脩，濬按殺之，一郡震竦。後爲湘鄉令，治甚有名。

**釋讀** 未滿三十歲時，荊州牧劉表徵辟潘濬為從事，分管江夏。沙羡縣令貪污失德，潘濬按治並將他處死，江夏一郡震動。後任湘鄉令，以治理得名。

**時段與依據** 劉表據荊州時徵用潘濬。本傳把湘鄉令記於劉備領荊州之前，兩任與沙羡案皆未載確年。

## 芮祉供職孫堅

<a id="period-sgz061-p-003-2"></a>

<a id="wu061-l12-2"></a>

**[《三國志·潘濬陸凱傳》裴注 003](../../拆分史书/三国志/卷061.md#edition-wu061-l12-2)** · [TXT L12](../../拆分史书/三国志/卷061.txt#L12)

> 玄字文表，丹楊人。父祉，字宣嗣，從孫堅征伐有功，堅薦祉爲九江太守，後轉吳郡，所在有聲。

**釋讀** 芮玄字文表，丹楊人。父親芮祉字宣嗣，跟隨孫堅征討有功，獲薦為九江太守，後轉任吳郡太守，各任均有聲譽。

**時段與依據** 裴注在芮玄卒事下追敘家世；芮祉的征戰、薦官與轉任各無確年。

<a id="period-sgz061-p-003-3"></a>

<a id="wu061-l12-3"></a>

**[《三國志·潘濬陸凱傳》裴注 003](../../拆分史书/三国志/卷061.md#edition-wu061-l12-3)** · [TXT L12](../../拆分史书/三国志/卷061.txt#L12)

> 玄兄良，字文鸞，隨孫策平定江東，策以爲會稽東部都尉，卒，玄領良兵，拜奮武中郎將，以功封溧陽侯。

**釋讀** 芮玄的哥哥芮良字文鸞，跟從孫策平定江東，被任為會稽東部都尉。芮良死後，芮玄接手其兵，拜奮武中郎將，以功封溧陽侯。

**時段與依據** 孫策取江東在興平、建安之際，任芮良、芮良死及芮玄接兵遷封均無確年。

<a id="wu061-l12-4"></a>

**[《三國志·潘濬陸凱傳》裴注 003](../../拆分史书/三国志/卷061.md#edition-wu061-l12-4)** · [TXT L12](../../拆分史书/三国志/卷061.txt#L12)

> 權爲子登揀擇淑媛，羣臣咸稱玄父祉兄良並以德義文武顯名三世，故遂娉玄女爲妃焉。

**釋讀** 孫權為兒子孫登選妃，群臣稱芮氏父兄累世有德義文武之名，於是孫權為孫登娉芮玄的女兒為妃。

**時段與依據** 《吳書》未記聘娶年月；卷059另記孫登娶周瑜之女，兩位妃子各隨原文著錄。

## 潘濬諫止孫權射雉

<a id="period-sgz061-p-004-1"></a>

<a id="wu061-l14-1"></a>

**[《三國志·潘濬陸凱傳》裴注 004](../../拆分史书/三国志/卷061.md#edition-wu061-l14-1)** · [TXT L14](../../拆分史书/三国志/卷061.txt#L14)

> 江表傳曰：權數射雉，濬諫權，權曰：「相與別後，時時蹔出耳，不復如往日之時也。」濬曰：「天下未定，萬機務多，射雉非急，弦絕括破，皆能爲害，乞特爲臣故息置之。」濬出，見雉翳故在，乃手自撤壞之。權由是自絕，不復射雉。

**釋讀** 孫權常射雉。潘濬進諫，孫權說別後只偶爾出獵，已不像以往。潘濬說天下未定、政務繁多，射雉並非急事，弓弦與箭尾有損也可能傷人，請孫權停下。潘濬出去後見遮身待雉的掩蔽物仍在，親手拆毀，孫權自此戒射。

**時段與依據** 《江表傳》作插敘，未記年月。孫權說「相與別後」，無法單憑此語繫某次離合。

## 潘濬勸孫權勿許步隲自行募兵

<a id="period-sgz061-p-005-1"></a>

<a id="wu061-l16-1"></a>

**[《三國志·潘濬陸凱傳》裴注 005](../../拆分史书/三国志/卷061.md#edition-wu061-l16-1)** · [TXT L16](../../拆分史书/三国志/卷061.txt#L16)

> 吳書曰：驃騎將軍步隲屯漚口，求召募諸郡以增兵。權以問濬，濬曰：「豪將在民間，耗亂爲害，加隲有名勢，在所所媚，不可聽也。」權從之。

**釋讀** 驃騎將軍步隲駐漚口，請在各郡募兵擴軍。潘濬說豪強將領在民間多成侵耗之害，步隲又有名望權勢，所到的官員競相取悅，不應聽許。孫權接受他的意見。

**時段與依據** 卷052記步隲226年徙屯漚口，229年升驃騎將軍、督西陵。注文將官號、駐屯合敘，請募具體年次未載。

<a id="period-sgz061-p-005-2"></a>

<a id="wu061-l16-2"></a>

**[《三國志·潘濬陸凱傳》裴注 005](../../拆分史书/三国志/卷061.md#edition-wu061-l16-2)** · [TXT L16](../../拆分史书/三国志/卷061.txt#L16)

> 中郎將豫章徐宗，有名士也，甞到京師，與孔融交結，然儒生誕節，部曲寬縱，不奉節度，爲衆作殿，濬遂斬之。其奉法不憚私議，皆此類也。

**釋讀** 豫章名士徐宗任中郎將，曾到京師與孔融交遊。他身為儒生卻不守約束，縱容部曲，違背軍紀，在諸軍中居末，潘濬將他處死。《吳書》以此為潘濬執法而不畏私議的例證。

**時段與依據** 孔融是徐宗早年交遊的背景；徐宗任官、犯軍令及被殺均無確年。

## 潘濬女配孫慮

**釋讀** 潘濬的女兒嫁給建昌侯孫慮。

<a id="period-sgz061-p-006-1"></a>

<a id="period-sgz061-p-006-2"></a>

<a id="wu061-l21-1"></a>

**[《三國志·潘濬陸凱傳》裴注 006](../../拆分史书/三国志/卷061.md#edition-wu061-l21-1)** · [TXT L21](../../拆分史书/三国志/卷061.txt#L21)

> 吳書曰：翥字文龍，拜騎都尉，後代領兵，早卒。翥弟祕，權以姊陳氏女妻之，調湘鄉令。

**釋讀** 潘翥字文龍，拜騎都尉，後來代領軍隊，早年去世。弟弟潘祕娶孫權姐姐陳氏所生的女兒，被調為湘鄉令。

**時段與依據** 本傳載潘翥239年承爵；拜騎都尉、代領兵及早卒無年月。潘祕婚娶與調任湘鄉同樣無確年。

<a id="period-sgz061-p-006-3"></a>

<a id="wu061-l21-2"></a>

**[《三國志·潘濬陸凱傳》裴注 006](../../拆分史书/三国志/卷061.md#edition-wu061-l21-2)** · [TXT L21](../../拆分史书/三国志/卷061.txt#L21)

> 　襄陽記曰：襄陽習溫爲荊州大公平。大公平，今之州都。祕過辭於溫，問曰：「先君昔曰君侯當爲州里議主，今果如其言，不審州里誰當復相代者？」溫曰：「無過於君也。」後祕爲尚書僕射，代溫爲公平，甚得州里之譽。

**釋讀** 襄陽人習溫任荊州大公平，即引書作者時稱的州都。潘祕行前辭別，說父親曾預言習溫會主持州里議論，今已應驗，問誰可繼任。習溫說只有潘祕最合適。潘祕後任尚書僕射，代習溫任公平，深獲鄉里稱譽。

**時段與依據** 《襄陽記》只敘問答與後來的任官次序，並無年月。

## 陸凱家世及早年任官

<a id="period-sgz061-b-2897-1"></a>

<a id="wu061-l25-1"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l25-1)** · [TXT L25](../../拆分史书/三国志/卷061.txt#L25)

> 陸凱字敬風，吳郡吳人，丞相遜族子也。黃武初爲永興、諸曁長，所在有治迹，拜建武都尉，領兵。

**釋讀** 陸凱字敬風，吳郡吳縣人，是丞相陸遜同族的子侄。黃武初任永興長及諸暨長，所到之處有政績，後任建武都尉領兵。

**時段與依據** 黃武年號為222至229，原文稱「初」，兩縣任職和後續升任無確月日。

<a id="period-sgz061-b-2897-2"></a>

<a id="wu061-l25-2"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l25-2)** · [TXT L25](../../拆分史书/三国志/卷061.txt#L25)

> 雖統軍衆，手不釋書。好太玄，論演其意，以筮輒驗。

**釋讀** 陸凱雖統軍，仍然手不釋卷，喜歡揚雄《太玄》，推演其義理。傳稱他用此占筮屢有應驗。

**時段與依據** 人物治學與日常習行，上承領兵以來之事。

## 陸禕先領兵，後任東宮官

<a id="period-sgz061-b-2909-1"></a>

<a id="period-sgz061-b-2909-2"></a>

<a id="wu061-l51-1"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l51-1)** · [TXT L51](../../拆分史书/三国志/卷061.txt#L51)

> 子禕，初爲黃門侍郎，出領部曲，拜偏將軍。凱亡後，入爲太子中庶子。

**釋讀** 陸凱之子陸禕起初任黃門侍郎，出掌部曲、任偏將軍。陸凱去世後，入朝任太子中庶子。

**時段與依據** 曾鞏《元豐類稿》卷五十錄[《晉陸禕碑》](ce-0243.md#wu061-lu-yi-inscription)，記陸禕於243年被召為宿衞郎中，後遷黃門侍郎。後續官職無確年；太子中庶子在269年陸凱死後，由本傳其後被徙建安可推在275年前。

<a id="period-sgz061-b-2909-3"></a>

<a id="wu061-l51-2"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l51-2)** · [TXT L51](../../拆分史书/三国志/卷061.txt#L51)

> 右國史華覈表薦禕曰：「禕體質方剛，器幹彊固，董率之才，魯肅不過。及被召當下，徑還赴都，道由武昌，曾不迴顧，器械軍資，一無所取，在戎果毅，臨財有節。夫夏口，賊之衝要，宜選名將以鎮戍之，臣竊思惟，莫善於禕。」

**釋讀** 右國史華覈推薦陸禕，稱他體力方壯、才幹剛強，統率之才可比魯肅。此前受召立即回都，過武昌不停，器械軍資分毫未取，既能治軍又不貪財。夏口是對敵要地，華覈認為莫如命陸禕鎮戍。

**時段與依據** 華覈疏在陸禕奉召之後，傳文未給授守夏口的詔命或舉薦年月。

> 予連從荊、揚來者得凱所諫皓二十事，博問吳人，多云不聞凱有此表。又按其文殊甚切直，恐非皓之所能容忍也。或以爲凱藏之篋笥，未敢宣行，病困，皓遣董朝省問欲言，因以付之。虛實難明，故不著于篇，然愛其指擿皓事，足爲後戒，故鈔列于凱傳左云。

**釋讀** 陳壽從荊、揚來人取得相傳為陸凱所作的二十條諫議，向吳人廣詢，多人不知有這篇奏疏。文字極為切直，陳壽懷疑孫皓能否容忍。另說陸凱藏起未送，病重時董朝來問才交予他。陳壽說虛實難明，因其指摘可為後戒，抄列於傳後。

**時段與依據** 二十事涉及266年王蕃遇害、萬彧拜相，若確出陸凱之手，成文約在266至269年。是否呈進及董朝受文之說欠證。《通鑑》卷079考異引陳壽自述而不採二十事為實事。

> 皓遣親近趙欽口詔報凱前表曰：「孤動必遵先帝，有何不平？君所諫非也。又建業宮不利，故避之，而西宮室宇摧朽，須謀移都，何以不可徙乎？」凱上疏曰：
>
> 臣竊見陛下執政以來，陰陽不調，五星失晷，職司不忠，姦黨相扶，是陛下不遵先帝之所致。
>
> **〔裴注〕**
> 江表傳載凱此表曰：「臣拜受明詔，心與氣結。陛下何心之難悟，意不聦之甚也！」
>
> 夫王者之興，受之於天，脩之由德，豈在宮乎？而陛下不諮之公輔，便盛意驅馳，六軍流離悲懼，逆犯天地，天地以災，童歌其謠。縱令陛下一身得安，百姓愁勞，何以用治？此不遵先帝一也。
>
> 臣聞有國以賢爲本，夏殺龍逄，殷獲伊摯，斯前世之明效，今日之師表也。中常侍王蕃黃中通理，處朝忠謇，斯社稷之重鎮，大吳之龍逄也，而陛下忿其苦辭，惡其直對，梟之殿堂，尸骸暴棄。邦內傷心，有識悲悼，咸以吳國夫差復存。先帝親賢，陛下反之，是陛下不遵先帝二也。
>
> 臣聞宰相國之柱也，不可不彊，是故漢有蕭、曹之佐，先帝有顧、步之相。而萬彧瑣才凡庸之質，昔從家隷，超步紫闥，於彧已豐，於器已溢，而陛下愛其細介，不訪大趣，榮以尊輔，越尚舊臣。賢良憤惋，智士赫咤，是不遵先帝三也。
>
> 先帝愛民過於嬰孩，民無妻者以妾妻之，見單衣者以帛給之，枯骨不收而取埋之。而陛下反之，是不遵先帝四也。
>
> 昔桀紂滅由妖婦，幽厲亂在嬖妾，先帝鑒之，以爲身戒，故左右不置淫邪之色，後房無曠積之女。今中宮萬數，不備嬪嬙，外多鰥夫，女吟於中。風雨逆度，正由此起，是不遵先帝五也。
>
> 先帝憂勞萬機，猶懼有失。陛下臨阼以來，游戲後宮，眩惑婦女，乃令庶事多曠，下吏容姦，是不遵先帝六也。
>
> 先帝篤尚朴素，服不純麗，宮無高臺，物不彫飾，故國富民充，姦盜不作。而陛下徵調州郡，竭民財力，土被玄黃，宮有朱紫，是不遵先帝七也。
>
> 先帝外仗顧、陸、朱、張，內近胡綜、薛綜，是以庶績雍熈，邦內清肅。今者外非其任，內非其人，陳聲、曹輔，斗筲小吏，先帝之所棄，而陛下幸之，是不遵先帝八也。
>
> 先帝每宴見羣臣，抑損醇醲，臣下終日無失慢之尤，百寮庶尹，並展所陳。而陛下拘以視瞻之敬，懼以不盡之酒。夫酒以成禮，過則敗德，此無異商辛長夜之飲也，是不遵先帝九也。
>
> 昔漢之桓、靈，親近宦豎，大失民心。今高通、詹廉、羊度，黃門小人，而陛下賞以重爵，權以戰兵。若江渚有難，烽燧互起，則度等之武不能禦侮明也，是不遵先帝十也。
>
> 今宮女曠積，而黃門復走州郡，條牒民女，有錢則舍，無錢則取，怨呼道路，母子死訣，是不遵先帝十一也。
>
> 先帝在時，亦養諸王太子，若取乳母，其夫復役，賜與錢財，給其資糧，時遣歸來，視其弱息。今則不然，夫婦生離，夫故作役，兒從後死，家爲空戶，是不遵先帝十二也。
>
> 先帝歎曰：「國以民爲本，民以食爲天，衣其次也，三者，孤存之於心。」今則不然，農桑並廢，是不遵先帝十三也。
>
> 先帝簡士，不拘卑賤，任之鄉閭，效之於事，舉者不虛，受者不妄。今則不然，浮華者登，朋黨者進，是不遵先帝十四也。
>
> 先帝戰士，不給他役，使春惟知農，秋惟收稻，江渚有事，責其死效。今之戰士，供給衆役，廩賜不贍，是不遵先帝十五也。
>
> 夫賞以勸功，罰以禁邪，賞罰不中，則士民散失。今江邊將士，死不見哀，勞不見賞，是不遵先帝十六也。
>
> 今在所監司，已爲煩猥，兼有內使，擾亂其中，一民十吏，何以堪命？昔景帝時，交阯反亂，實由茲起，是爲遵景帝之闕，不遵先帝十七也。
>
> 夫校事，吏民之仇也。先帝末年，雖有呂壹、錢欽，尋皆誅夷，以謝百姓。今復張立校曹，縱吏言事，是不遵先帝十八也。
>
> 先帝時，居官者咸乆於其位，然後考績黜陟。今州縣職司，或莅政無幾，便徵召遷轉，迎新送舊，紛紜道路，傷財害民，於是爲甚，是不遵先帝十九也。
>
> 先帝每察竟解之奏，常留心推桉，是以獄無冤囚，死者吞聲。今則違之，是不遵先帝二十也。
>
> 若臣言可錄，藏之盟府；如其虛妄，治臣之罪。願陛下留意。

**釋讀** 傳本說，孫皓派親近的趙欽口傳答詔，自稱事事遵循先帝，否認陸凱的指斥，又稱建業宮不吉、西宮廢舊，故有移都之議。陸凱接著上疏答覆。

**時段與依據** 本句承陳壽辨疑。遷都武昌見265年，266年還建業；下文涉及266年王蕃遇害及萬彧拜相，陳壽又錄病中可能交疏一說。口詔、答疏的真實性與年月皆存疑。

**釋讀** 疏中說孫皓執政以來陰陽失調、五星失常，官員不忠而奸黨相扶，歸因於孫皓違背先帝的做法。

**時段與依據** 二十事疏傳本的連續論旨，與陳壽辨疑同讀。

**釋讀** 裴注引《江表傳》，答疏開頭還有陸凱奉詔後氣結，直責孫皓難以醒悟的話。

**時段與依據** 《江表傳》的文字是本疏異文，與答疏同讀，仍無從確定曾經奏進及進呈之年。

**釋讀** 王者受天命而靠德行振興，關鍵豈在宮室。孫皓沒有徵詢輔臣便執意移都，六軍離散驚懼，童謠與災異並起。即使君主得安，百姓勞苦，國事也難治。

**時段與依據** 本條以遷都為議論背景。孫皓265年自建業徙武昌，266年還建業。

**釋讀** 治國以賢才為本，夏桀殺關龍逄而亡，商湯得伊尹而興。王蕃通達忠直，陸凱比之為吳國的龍逄。疏中指孫皓厭惡他的直言而斬首棄屍，使舉國悲痛，有識者以為重見夫差。

**時段與依據** 王蕃遇害由卷048、065與《通鑑》繫266年；此為疏中文辭與成文下限之一，原有王蕃遇害事仍在該年。

**釋讀** 宰相是國家支柱，漢有蕭何、曹參，孫權有顧雍、步隲。疏中稱萬彧自家隸驟擢宮廷，本已超過其才，孫皓卻因小節看重他，把相位授他並置舊臣之上，士人憤惋。

**時段與依據** 萬彧於266年八月拜右丞相見卷048，為本疏傳本涉及時事的下限之一。

**釋讀** 上疏者列舉孫權憐民如嬰孩，為無妻者給配偶，為衣單者給帛，收葬無人看顧的枯骨，指孫皓行為相反。

**釋讀** 疏中以桀、紂、幽王、厲王惑於嬖妾為例，稱孫權以此自戒，後房不積聚宮女。孫皓後宮納女過多，宮內女子怨苦，外有眾多鰥夫，疏中還將風雨失常歸於此。

**釋讀** 孫權日理萬機，常怕有所疏漏。陸凱指孫皓即位來只在後宮遊戲，荒廢眾務，讓下吏得以容留奸弊。

**釋讀** 孫權尚樸素，服飾不全用華麗的，宮中不築高臺，器物不雕飾，因此國富民足、少有奸盜。疏中指孫皓向州郡徵調，耗盡財力，工料、宮室都講究華飾。

**釋讀** 孫權對外倚顧、陸、朱、張諸臣，對內親近胡綜、薛綜，政務因而整肅。疏中指孫皓內外任人不當，反寵信先帝不用的小吏陳聲、曹輔。

**釋讀** 孫權宴見群臣時節制厚酒，使臣下不至失禮，並讓百官各述所見。孫皓卻拘責臣下的目視禮節，又逼人飲盡。酒能成禮，過量則敗德，疏中比為商紂長夜之飲。

**釋讀** 疏中以漢桓、靈二帝親近宦官而失人心為鑑，指孫皓把重爵、戰兵交給高通、詹廉、羊度等黃門，若沿江邊防告急，他們顯然不能禦敵。

**釋讀** 宮女已多，黃門仍奔走州郡，登記民女，有錢可免，無錢便取，路上怨聲不絕，母子訣別。

**釋讀** 孫權養育諸王太子時，徵選乳母便免其夫徭役，給以錢糧，還准她間或回家看護幼兒。此時乳母夫妻分離，丈夫仍服役，子女跟著死去，家中成了空戶。

**釋讀** 孫權以民為國本，以食為民天、衣次之，自稱常存這三事於心。陸凱指孫皓朝農桑俱廢。

**釋讀** 孫權不拘卑賤選才，先在鄉里任用，再以實事考效，薦舉與任用皆求其實。陸凱指孫皓朝反讓浮華之士和朋黨升遷。

**釋讀** 孫權不另役戰士，平時只使他們春耕秋收，沿江有警再責其效死。此時戰士要供眾役，官給糧米又不夠。

**釋讀** 賞以勸功，罰以制止奸事，賞罰失當，人心便離散。疏中指沿江將士死者無哀恤，有功勞者不獲賞。

**釋讀** 疏中說地方監司本多而繁，再增內使，百姓難以承受。它把孫休時交阯反亂歸因於這種擾民作法，認為孫皓重蹈其失。

**時段與依據** 交阯呂興起事另見263年。此處是疏中歸因，並非新的交阯事變。

**釋讀** 疏中稱校事為吏民之仇，說孫權末年處死呂壹、錢欽以謝民，責孫皓又設校曹並縱容胥吏告言。

**時段與依據** 疏中以呂壹等前事為鑑。呂壹伏誅另見238年；錢欽沿用本疏原字，其身份與被誅確年無從依此一段定出。

**釋讀** 孫權使官員久任，考績後才行升黜。如今有些州縣官到任不久就被徵調，迎新送舊不絕，使百姓損失財力。

**釋讀** 孫權聽到審結的刑案奏報，仍親自留心覆查，疏中說因此少生冤獄。陸凱指當時已不照做。

**釋讀** 若所言可取，請收藏於盟府；若有虛妄，請治臣罪。請皇帝留意。

**時段與依據** 二十事疏末段，接文書正文。陳壽明言未能斷定虛實。

> 江表傳曰：皓所行彌暴，凱知其將亡，上表曰：「臣聞惡不可積，過不可長；積惡長過，喪亂之源也。是以古人懼不聞非，故設進善之旌，立敢諫之鼓。武公九十，思聞警戒，詩美其德，士恱其行。臣察陛下無思警戒之義，而有積惡之漸，臣深憂之，此禍兆見矣。故略陳其要，寫盡愚懷。陛下宜克己復禮，述脩前德，不可捐棄臣言，而放奢意。意奢情至，吏日欺民；民離則上不信下，下當疑上，骨肉相克，公子相奔。臣雖愚，闇於天命，以心審之，敗不過二十稔也。臣常忿亡國之人夏桀、殷紂，亦不可使後人復忿陛下也。臣受國恩，奉朝三世，復以餘年，值遇陛下，不能循俗，與衆沈浮。若比干、伍員，以忠見戮，以正見疑，自謂畢足，無所餘恨，灰身泉壤，無負先帝，願陛下九思，社稷存焉。」

**釋讀** 陸凱說積惡與不肯改過是亡亂之源，引古人廣開諫路和衛武公年高仍求警戒。孫皓應克己復禮、修先德；若縱奢容吏欺民，上下離心、骨肉相攻，恐二十年內便亡國。陸凱自陳歷事三朝，寧如比干、伍子胥因直言獲罪，也不負先帝，請孫皓深思以保社稷。

**時段與依據** 《江表傳》另存一疏，只記孫皓在位而未詳月年；以264年孫皓即位至269年陸凱卒為時段。

## 陸胤早年仕履

陸胤是陸凱的弟弟，字敬宗。任御史、尚書選曹郎時得到太子孫和禮遇。後因兩宮之爭被收獄，出獄後曾任衡陽督軍都尉。

<a id="period-sgz061-b-2935-1"></a>

<a id="wu061-l107-1"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l107-1)** · [TXT L107](../../拆分史书/三国志/卷061.txt#L107)

> 胤字敬宗，凱弟也。始爲御史、尚書選曹郎，太子和聞其名，待以殊禮。

**釋讀** 陸胤字敬宗，是陸凱的弟弟。起初做御史、尚書選曹郎；太子孫和聞知他的名聲，待他以殊禮。

**時段與依據** 卷059與〈吳主傳〉記孫和於242年立為太子，250年被廢；此事在立儲後及本傳所敘獄事前，陸胤初仕及受禮確年未載。

> 後爲衡陽督軍都尉。

**釋讀** 陸胤後來出任衡陽督軍都尉。

**時段與依據** 《資治通鑑》卷075於248年記他以衡陽督軍都尉出任交州刺史；此為先前所任，初授年月未載。

## 陸胤平蒼梧建陵並補充軍伍

## 華覈薦陸胤入朝及所述交州惠政

陸胤離交州、受任西陵督後又轉左虎林。華覈舉他昔日安撫流民、蓄水濟民與持身廉潔為證，請調他回朝任要職。

<a id="period-sgz061-b-2937-1"></a>

<a id="period-sgz061-b-2937-2"></a>

<a id="period-sgz061-b-2937-3"></a>

<a id="period-sgz061-b-2937-4"></a>

<a id="period-sgz061-b-2937-5"></a>

<a id="wu061-l112-2"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l112-2)** · [TXT L112](../../拆分史书/三国志/卷061.txt#L112)

> 後轉左虎林。中書丞華覈表薦胤曰：「胤天姿聦朗，才通行絜，昔歷選曹，遺跡可紀。還在交州，奉宣朝恩，流民歸附，海隅肅清。蒼梧、南海，歲有舊風瘴氣之害，風則折木，飛砂轉石，氣則霧鬱，飛鳥不經。自胤至州，風氣絕息，商旅平行，民無疾疫，田稼豐稔。州治臨海，海流秋鹹，胤又畜水，民得甘食。惠風橫被，化感人神，遂憑天威，招合遺散。至被詔書當出，民感其恩，以忘戀土，負老攜幼，甘心景從，衆無攜貳，不煩兵衞。自諸將合衆，皆脅之以威，未有如胤結以恩信者也。銜命在州，十有餘年，賔帶殊俗，寶玩所生，而內無粉黛附珠之妾，家無文甲犀象之珍，方之今臣，實難多得。宜在輦轂，股肱王室，以贊唐虞康哉之頌。江邊任輕，不盡其才，虎林選督，堪之者衆。若召還都，寵以上司，則天工畢脩，庶績咸熈矣。」

**釋讀** 陸胤後來改督左虎林。中書丞華覈上表說，陸胤聰明正直，早在選曹已有可紀的政績，任交州時使流民歸附。蒼梧、南海素受暴風瘴氣困擾；華覈說陸胤到州後風瘴止息、商旅安行、百姓無疫且作物豐收。州治近海，秋季水鹹，陸胤蓄水以供百姓飲用，招合流散人口。受召離任時，百姓扶老攜幼自願跟隨，不須兵士督持；其他將領以威力聚眾，陸胤則以恩信結人。華覈又稱陸胤在交州十餘年，當地盛產珍玩，他家中卻無珠飾妾侍或飾甲、犀象等珍物。華覈認為江防職位不足以用其才，宜召還都城、授以重任。

**時段與依據** 表中明指當時陸胤已任左虎林，追述248年出任交州與受召離任的舊事。卷065〈華覈傳〉可參華覈由祕府郎遷中書丞及後來為東觀令；轉左虎林及薦表確年未明。風瘴止息等是表中頌語。

## 陳壽總評潘濬、陸凱、陸胤

<a id="period-sgz061-b-2939-1"></a>

<a id="wu061-l116-1"></a>

**[《三國志·潘濬陸凱傳》正文](../../拆分史书/三国志/卷061.md#edition-wu061-l116-1)** · [TXT L116](../../拆分史书/三国志/卷061.txt#L116)

> 評曰：潘濬公清割斷，陸凱忠壯質直，皆節槩梗梗，有大丈夫格業。胤身絜事濟，著稱南土，可謂良牧矣。

**釋讀** 陳壽評潘濬公正清廉而果斷，陸凱忠勇直率，兩人都堅持節操而有大丈夫的器局與事業。陸胤操守清白、任事有成，在南方留有聲名，可稱賢良的地方長官。

**時段與依據** 這是卷末史家總評，分別總括三人一生的品行與事功。

## 是儀的籍貫、仕宦與改姓

<a id="period-sgz062-b-2942-1"></a>

<a id="period-sgz062-b-2942-2"></a>

<a id="wu062-l5-1"></a>

**[《三國志·是儀胡綜傳》正文](../../sources/本地分卷/三国志/三国志-卷062.md#edition-wu062-l5-1)** · [TXT L5](../../sources/本地分卷/三国志/三国志-卷062.txt#L5)

> 是儀字子羽，北海營陵人也。本姓氏，初爲縣吏，後仕郡，郡相孔融嘲儀，言「氏」字「民」無上，可改爲「是」，乃遂改焉。

**釋讀** 是儀字子羽，北海營陵人，本姓氏。起初作縣吏，後來在郡中任職。北海相孔融以拆字取笑，說「氏」就是「民」少了上面的一畫，勸他改作「是」。是儀於是改姓。

**時段與依據** 孔融在北海任相時的前後見《後漢書·孔融傳》。改姓在是儀服事孔融期間、依劉繇以前，其月年無載。

<a id="period-sgz062-p-001-1"></a>

<a id="period-sgz062-p-001-2"></a>

<a id="wu062-l6-1"></a>

**[《三國志·是儀胡綜傳》裴注 001](../../sources/本地分卷/三国志/三国志-卷062.md#edition-wu062-l6-1)** · [TXT L6](../../sources/本地分卷/三国志/三国志-卷062.txt#L6)

> 徐衆評曰：古之建姓，或以所生，或以官號，或以祖名，皆有義體，以明氏族。故曰胙之以土而命之氏，此先王之典也，所以明本重始，彰示功德，子孫不忘也。今離文析字，橫生忌諱，使儀易姓，忘本誣祖，不亦謬哉！教人易姓，從人改族，融旣失之，儀又不得也。

**釋讀** 徐眾認為古人的姓氏或因血緣、官號、祖先名字而定，各有由來，用來表明宗族。先王賜人土地、命定姓氏，是要後代明本重始、記得功德。孔融卻拆字強生忌諱，叫是儀忘本改姓。徐眾認為教人改姓和聽從別人而改姓，雙方皆有失。

**時段與依據** 此評附改姓故事。授土命氏語見倉內《左傳》隱公八年「胙之土而命之氏」；其歷史典故不另外推定是儀改姓的時間。

## 是儀依劉繇在江東避亂

<a id="period-sgz062-b-2942-3"></a>

<a id="wu062-l7-1"></a>

**[《三國志·是儀胡綜傳》正文](../../sources/本地分卷/三国志/三国志-卷062.md#edition-wu062-l7-1)** · [TXT L7](../../sources/本地分卷/三国志/三国志-卷062.txt#L7)

> 後依劉繇，避亂江東。

**釋讀** 是儀後來依附劉繇，在江東躲避戰亂。

**時段與依據** 卷049〈劉繇傳〉敘劉繇避亂淮浦、受任揚州刺史後渡江至曲阿。是儀開始跟隨劉繇、來到江東的確切年次無載。

## 是儀封都亭侯、守侍中並辭兵

<a id="period-sgz062-b-2942-10"></a>

<a id="wu062-l13-2"></a>

**[《三國志·是儀胡綜傳》正文](../../sources/本地分卷/三国志/三国志-卷062.md#edition-wu062-l13-2)** · [TXT L13](../../sources/本地分卷/三国志/三国志-卷062.txt#L13)

> 後封都亭侯，守侍中。欲復授兵，儀自以非材，固辭不受。

**釋讀** 是儀後來封都亭侯、代理侍中。孫權還想交他部隊，他自以為才力不及，固辭未受。

**時段與依據** 本卷〈胡綜傳〉記孫權在221年受魏封吳王時，是儀、胡綜、徐詳均封亭侯，是否正是此處所稱都亭侯，不能由「亭侯」斷定。守侍中及辭授兵的年月亦無明文。

## 是儀後任尚書僕射

<a id="wu062-l18-2"></a>

**[《三國志·是儀胡綜傳》正文](../../sources/本地分卷/三国志/三国志-卷062.md#edition-wu062-l18-2)** · [TXT L18](../../sources/本地分卷/三国志/三国志-卷062.txt#L18)

> 後拜尚書僕射。

**釋讀** 是儀在使蜀之後獲任尚書僕射。

**時段與依據** 本傳只說「後拜」。242年任魯王傅時已領本職，《通鑑》明列尚書僕射，授官確年未載。

## 是儀居處儉樸，孫權辨鄰宅

<a id="period-sgz062-b-2944-1"></a>

<a id="wu062-l22-1"></a>

**[《三國志·是儀胡綜傳》正文](../../sources/本地分卷/三国志/三国志-卷062.md#edition-wu062-l22-1)** · [TXT L22](../../sources/本地分卷/三国志/三国志-卷062.txt#L22)

> 不治產業，不受施惠，爲屋舍財足自容。鄰家有起大宅者，權出望見，問起大室者誰，左右對曰：「似是儀家也。」權曰：「儀儉，必非也。」問果他家。其見知信如此。

**釋讀** 是儀不營產業，不受別人的饋贈，住屋僅能容身。鄰人造大宅，有侍從以為是是儀的宅子。孫權知道他儉樸，斷定不是，查問果然是別家。傳文以此明孫權知悉並信任是儀。

**時段與依據** 本傳總敘持身與鄰宅逸事，無確年。

<a id="period-sgz062-b-2944-2"></a>

<a id="wu062-l24-1"></a>

**[《三國志·是儀胡綜傳》正文](../../sources/本地分卷/三国志/三国志-卷062.md#edition-wu062-l24-1)** · [TXT L24](../../sources/本地分卷/三国志/三国志-卷062.txt#L24)

> 服不精細，食不重膳，拯贍貧困，家無儲畜。權聞之，幸儀舍，求視蔬飯，親甞之，對之歎息，即增俸賜，益田宅。儀累辭讓，以恩爲戚。

**釋讀** 是儀衣著樸素、飲食簡單，以財物周濟貧困，家無積蓄。孫權聞訊到是儀家，見他只吃蔬飯，親自嘗過，感歎而加俸、賜田宅；是儀卻因受恩而不安，屢次推辭。

**時段與依據** 同段敘儉約、賑濟和孫權加賜，各無確年。

<a id="period-sgz062-b-2945-1"></a>

<a id="wu062-l26-1"></a>

**[《三國志·是儀胡綜傳》正文](../../sources/本地分卷/三国志/三国志-卷062.md#edition-wu062-l26-1)** · [TXT L26](../../sources/本地分卷/三国志/三国志-卷062.txt#L26)

> 時時有所進達，未甞言人之短。權常責儀以不言事，無所是非，儀對曰：「聖主在上，臣下守職，懼於不稱，實不敢以愚管之言，上干天聽。」

**釋讀** 是儀偶有推舉，從不談別人的短處。孫權曾責問為何不進言、不置是非。是儀說在聖主之下各守其職，尚怕不能稱職，實不敢以淺陋的意見煩擾皇帝。

**時段與依據** 本傳以此敘人品與時常行事，孫權問對的日期不明。

## 是儀病中遺命薄葬

<a id="period-sgz062-b-2946-1"></a>

<a id="wu062-l30-1"></a>

> 及寢疾，遺令素棺，斂以時服，務從省約，年八十一卒。

## 胡綜兼左執法、領辭訟

> 拜綜偏將軍，兼左執法，領辭訟。

> 性嗜酒，酒後歡呼極意，或推引杯觴，搏擊左右。權愛其才，弗之責也。

**釋讀** 胡綜嗜酒，酒後盡情喧呼，有時推引酒杯，揮拳打身邊的人。孫權愛惜他的才能，沒有因此責罰。

**釋讀** 孫權主持政務以來，各種誥命、冊命和給鄰國的書信符牒，大體都出自胡綜之手。

## 胡冲在吳任中書令

<a id="period-sgz062-b-2959-2"></a>

<a id="wu062-l60-2"></a>

**[《三國志·是儀胡綜傳》正文](../../sources/本地分卷/三国志/三国志-卷062.md#edition-wu062-l60-2)** · [TXT L60](../../sources/本地分卷/三国志/三国志-卷062.txt#L60)

> 冲平和有文幹，天紀中爲中書令

**釋讀** 胡冲性格平和、擅長文章，在孫皓天紀年間任中書令。

**時段與依據** 天紀為277至280年。卷048〈三嗣主傳〉L155與《晉書》〈王濬傳〉皆明記280年胡冲仍以中書令參議請降，確切授任年無載。

<a id="wu062-l61-1"></a>

> 吳錄曰：冲後仕晉尚書郎、吳郡太守。

## 徐詳籍貫及卒年上限

<a id="period-sgz062-b-2960-1"></a>

<a id="period-sgz062-b-2961-1"></a>

<a id="wu062-l63-1"></a>

**[《三國志·是儀胡綜傳》正文](../../sources/本地分卷/三国志/三国志-卷062.md#edition-wu062-l63-1)** · [TXT L63](../../sources/本地分卷/三国志/三国志-卷062.txt#L63)

> 徐詳者字子明，吳郡烏程人也，先綜死。

**釋讀** 徐詳字子明，是吳郡烏程人，死在胡綜之前。

**時段與依據** 本傳記徐詳先於胡綜去世；胡綜卒於243年。卷064〈諸葛恪傳〉裴注《江表傳》記徐詳死後諸葛亮致信陸遜，勸勿使諸葛恪掌軍糧，若據此說，徐詳在諸葛亮234年八月去世之前已卒。徐詳229年入侍中，卒年可限此段，確年未詳。

## 陳壽總評是儀、徐詳、胡綜

<a id="period-sgz062-b-2962-1"></a>

<a id="period-sgz062-b-2963-1"></a>

<a id="wu062-l65-1"></a>

**[《三國志·是儀胡綜傳》正文](../../sources/本地分卷/三国志/三国志-卷062.md#edition-wu062-l65-1)** · [TXT L65](../../sources/本地分卷/三国志/三国志-卷062.txt#L65)

> 評曰：是儀、徐詳、胡綜，皆孫權之時幹興事業者也。儀清恪貞素，詳數通使命，綜文采才用，各見信任，譬之廣夏，其榱椽之佐乎！

**釋讀** 陳壽說，是儀、徐詳、胡綜都在孫權時承擔事業。是儀清廉謹慎、守正質樸，徐詳多次承擔往來出使，胡綜富有文采而有才幹，三人都受孫權信任。若將政權比作大屋，他們就像支承屋頂的椽木。

**時段與依據** 陳壽綜評三人長期為孫權任事，與各年所見事跡互讀。 徐詳奉使可參217年濡須戰後赴曹營、議修好。

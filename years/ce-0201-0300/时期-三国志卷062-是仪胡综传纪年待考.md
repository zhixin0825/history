### 是仪传题

[《三国志·是仪胡综传》仓内原文 L2941](../../sources/本地分卷/三国志/三国志-卷062.md#l2941)

> 是儀

本节记是仪。

**时段与依据** 篇内标题。

<a id="period-sgz062-b-2942-1"></a>

### 是仪出身、为县吏郡吏

[《三国志·是仪胡综传》仓内原文 L2942](../../sources/本地分卷/三国志/三国志-卷062.md#l2942)

> 是儀字子羽，北海營陵人也。本姓氏，初為縣吏，後仕郡。

是仪字子羽，北海营陵人，本姓氏，先任县吏再在郡仕官。

**时段与依据** 身世和起仕年月无载。

<a id="period-sgz062-b-2942-2"></a>

### 孔融嘲解氏字，是仪改姓

[《三国志·是仪胡综传》仓内原文 L2942](../../sources/本地分卷/三国志/三国志-卷062.md#l2942)

> 郡相孔融嘲儀，言"氏"字"民"無上，可改為"是"，乃遂改焉。

北海相孔融拆解氏字，是仪改作是姓。

**时段与依据** 《后汉书·孔融传》授北海相在汉末；改姓发生在任内而无确年。徐众评此事见注001。

<a id="period-sgz062-b-2942-3"></a>

### 是仪随刘繇到江东

[《三国志·是仪胡综传》仓内原文 L2942](../../sources/本地分卷/三国志/三国志-卷062.md#l2942)

> 後依劉繇，避亂江東。

是仪早年随刘繇，在江东避乱。

**时段与依据** 从刘繇迁徙的年月无载。

<a id="period-sgz062-b-2942-5"></a>

### 是仪迁会稽

[《三国志·是仪胡综传》仓内原文 L2942](../../sources/本地分卷/三国志/三国志-卷062.md#l2942)

> 儀徙會稽。

是仪于刘繇败后迁居会稽。

**时段与依据** 随败局叙下，迁徙没有独立年次。

<a id="period-sgz062-b-2942-6"></a>

### 孙权征是仪，使掌机密

[《三国志·是仪胡综传》仓内原文 L2942](../../sources/本地分卷/三国志/三国志-卷062.md#l2942)

> 孫權承攝大業，優文征儀。到見親任，專典機密，拜騎都尉。

孙权接掌江东后征召是仪，加亲任并拜骑都尉。

**时段与依据** 时间因“承攝”起自200年，但征召及授职年月无载。

<a id="period-sgz062-b-2942-8"></a>

### 是仪拜官致谢，孙权以周舍相期

[《三国志·是仪胡综传》仓内原文 L2942](../../sources/本地分卷/三国志/三国志-卷062.md#l2942)

> 儀陳謝，權令曰："孤雖非趙簡子，卿安得不自屈為周捨邪？"

孙权以赵简子与周舍旧事说明希望是仪敢于告其过。

**时段与依据** 叙在获忠义校尉之后，语无明年。赵简子周舍为典故。

<a id="period-sgz062-b-2942-10"></a>

### 是仪封侯守侍中、辞领兵

[《三国志·是仪胡综传》仓内原文 L2942](../../sources/本地分卷/三国志/三国志-卷062.md#l2942)

> 後封都亭侯，守侍中。欲復授兵，儀自以非材，固辭不受。

是仪后来封侯，守侍中，自认为无带兵才具而辞。

**时段与依据** 封亭侯可参L2948吴王初封胡综等记载；但都亭侯与任侍中及辞兵不是同一有日的任命。

<a id="period-sgz062-b-2942-12"></a>

### 是仪掌内外政务并教诸公子学书

[《三国志·是仪胡综传》仓内原文 L2942](../../sources/本地分卷/三国志/三国志-卷062.md#l2942)

> 遷偏將軍，入闕省尚書事，外總平諸官，兼領辭訟，又令都諸公於書學。

获升偏将军、入省尚书事，对外协调众官和司法，并负责诸公子书学。

**时段与依据** 接石亭之战以后，授命与教学具体年月缺。四库本“又令教諸公子書學”校底本“都諸公於”。

<a id="period-sgz062-b-2943-2"></a>

### 孙登信任是仪，是仪进都乡侯

[《三国志·是仪胡综传》仓内原文 L2943](../../sources/本地分卷/三国志/三国志-卷062.md#l2943)

> 太子敬之，事先咨詢，然後施行。進封都鄉侯。

孙登遇事先问是仪再行，是仪进侯。

**时段与依据** 守武昌期间，封侯无确年。

<a id="period-sgz062-b-2943-3"></a>

### 是仪随后还建业任侍中中执法

[《三国志·是仪胡综传》仓内原文 L2943](../../sources/本地分卷/三国志/三国志-卷062.md#l2943)

> 後從太子還建業，復拜侍中、中執法，平諸官事、領辭訟如舊。

是仪随孙登回建业，仍协理诸官事及诉讼。

**时段与依据** 《孙登传》嘉禾三年陆逊奉召代孙登镇武昌，据此可推还都大致时间；是仪任命不明年。

<a id="period-sgz062-b-2943-6"></a>

### 诸葛亮死后，是仪奉使重申吴蜀盟好

[《三国志·是仪胡综传》仓内原文 L2943](../../sources/本地分卷/三国志/三国志-卷062.md#l2943)

> 權垂心西州，遣儀使蜀申固盟好。奉使稱意，後拜尚書僕射。

孙权闻诸葛亮死后遣是仪赴蜀，出使合意，后来授尚书仆射。

**时段与依据** 诸葛亮卒于234年；是仪出发、抵蜀和升官各缺年月。

<a id="period-sgz062-b-2943-8"></a>

### 是仪在鲁王府规谏，为政恭勤

[《三国志·是仪胡综传》仓内原文 L2943](../../sources/本地分卷/三国志/三国志-卷062.md#l2943)

> 為傅盡忠，動輒規諫；事上勤，與人恭。

任傅时常进规言，侍上勤劳、待人谦恭。

**时段与依据** 长期表现开始于鲁王府建立后。

<a id="period-sgz062-b-2944-1"></a>

### 是仪薄产廉俭，孙权辨宅

[《三国志·是仪胡综传》仓内原文 L2944](../../sources/本地分卷/三国志/三国志-卷062.md#l2944)

> 不治產業，不受施惠，為屋舍財足自容。鄰家有起大宅者，權出望見，問起大室者誰。左右對曰："似是儀家也。"權曰："儀儉，必非也。"問果他家。其見知信如此。

是仪无蓄产之心，房屋只须自容。孙权闻旁人误认新宅是是仪家，依据是仪素来俭朴，判断宅主另有其人。

**时段与依据** 性行总结及邻宅轶事均无年次。

<a id="period-sgz062-b-2944-2"></a>

### 是仪赈贫，孙权尝蔬食并加赐

[《三国志·是仪胡综传》仓内原文 L2944](../../sources/本地分卷/三国志/三国志-卷062.md#l2944)

> 服不精細，食不重膳，拯贍貧困，家無儲畜。權聞之，幸儀捨，求視蔬飯，親嘗之，對之歎息，即增俸賜，益田宅。儀累辭讓，以恩為戚。

是仪不重衣食，以家财助穷，孙权到其家尝蔬饭，下命增俸并给房田，是仪多次推辞。

**时段与依据** 年月未载。

<a id="period-sgz062-b-2945-1"></a>

### 是仪举善不议短，答孙权询问

[《三国志·是仪胡综传》仓内原文 L2945](../../sources/本地分卷/三国志/三国志-卷062.md#l2945)

> 時時有所進達，未嘗盲人之短。權常責儀以不言事，無是所非，儀對曰："聖主在上，臣下守職，懼於不稱，實不敢以愚管之畜，上干天聽。"

是仪常推举别人、不揭短；孙权问他何不进言，是仪说自守其职、不敢妄议。

**时段与依据** 长期行事和一次问答缺年。“盲”与“畜”在四库本作“言”。

<a id="period-sgz062-b-2945-2"></a>

### 是仪长期供职，吕壹无从劾其过

[《三国志·是仪胡综传》仓内原文 L2945](../../sources/本地分卷/三国志/三国志-卷062.md#l2945)

> 事國數十年，未嘗有過。呂壹歷白將相大臣，或一人以罪聞者數四，獨無以白儀。權歎曰："使人盡如是儀，當安用科法為?"

吕壹多次劾奏将相，却拿不到是仪的过失，孙权据此称赞。

**时段与依据** 吕壹于238伏诛，可约束在此前。孙权称许当年的具体年月未记。

<a id="period-sgz062-b-2946-1"></a>

### 是仪遗令薄葬，年八十一卒

[《三国志·是仪胡综传》仓内原文 L2946](../../sources/本地分卷/三国志/三国志-卷062.md#l2946)

> 及寢疾，遺令素棺，斂以時服，務從省約，年八十一卒。

是仪病时遗命用素棺、常服，务求省约，八十一而卒。

**时段与依据** 在领鲁王傅之后，生卒具体年无传文。

### 胡综出身、少孤避难

[《三国志·是仪胡综传》仓内原文 L2948](../../sources/本地分卷/三国志/三国志-卷062.md#l2948)

> 胡綜字偉則。汝南固始人也。少孤，母將避難江東。

胡综字伟则，汝南固始人，少孤，母携他避难到江东。

**时段与依据** 迁徙纪年未载。

<a id="period-sgz062-b-2948-2"></a>

### 胡综在会稽为循行、与孙权读书

[《三国志·是仪胡综传》仓内原文 L2948](../../sources/本地分卷/三国志/三国志-卷062.md#l2948)

> 孫策領會稽太守，綜年十四，為門下循行，留吳與孫權共讀書。

胡综十四岁任孙策门下循行，留在吴地与孙权同读。

**时段与依据** 孙策任会稽太守间，约195年后至200年，岁数不能独立确定任职年。

<a id="period-sgz062-b-2948-4"></a>

### 胡综从征黄祖，拜鄂长

[《三国志·是仪胡综传》仓内原文 L2948](../../sources/本地分卷/三国志/三国志-卷062.md#l2948)

> 從討黃祖，拜鄂長。

胡综参与孙权的讨黄祖战事，随后治理鄂县。

**时段与依据** 孙权203、207、208三次征讨，传未说明哪次即拜鄂长。

<a id="period-sgz062-b-2948-5"></a>

### 胡综在京口参与掌军国机密

[《三国志·是仪胡综传》仓内原文 L2948](../../sources/本地分卷/三国志/三国志-卷062.md#l2948)

> 權為將軍，都京，召綜還，為書部。與是儀、徐詳俱典軍國密事。

孙权召回胡综使任书部，与是仪、徐详同掌机密。

**时段与依据** 京即京口；孙权建安中治京，召回具体年月无载。

<a id="period-sgz062-b-2956-1"></a>

### 伪文流行时吴质已入任侍中

[《三国志·是仪胡综传》仓内原文 L2956](../../sources/本地分卷/三国志/三国志-卷062.md#l2956)

> 此文既流行，而質已人為侍中矣。

伪文传布时，吴质已回魏廷任侍中。

**时段与依据** 底本“已人”四库作“已入”。《吴质传》裴注引《魏略》只称太和中入为侍中；传布日月无明文。

胡综醉后喧呼任意，搡打身边人，孙权因才而未责。

**时段与依据** 长期性情事件，缺年月。

孙权掌事后所用策命和外交文书多由胡综撰成。

**时段与依据** 综述长期职务，不限于一年的文书活动。

### 徐众论是仪改姓

[《三国志·是仪胡综传》裴注 001·1](../../sources/摘录/三国志-卷062-是仪胡综传裴注.md#pei-001-1)

> 徐衆評曰古之建姓或以所生或以官號或以祖名皆有義體以明氏族故曰胙之以土而命之氏此先王之典也所以明本重始彰示功徳子孫不忘也

徐众说古姓依生、依官、依祖，意在辨宗亲并显先德。

**时段与依据** 论姓氏制度与典故；前半无同一确年。

<a id="period-sgz062-p-001-2"></a>

### 徐众批评孔融戏改是仪姓氏

[《三国志·是仪胡综传》裴注 001·2](../../sources/摘录/三国志-卷062-是仪胡综传裴注.md#pei-001-2)

> 今離文柝字横生忌諱使儀易姓忘本誣祖不亦謬哉教人易姓從人改族融既失之儀又不得也

徐众批评孔融拆字让人抛弃本姓，也认为是仪不应改。

**时段与依据** 系后出史评，所评改姓在孔融任北海相间，年月无载。

[《三国志·是仪胡综传》裴注 002·1](../../sources/摘录/三国志-卷062-是仪胡综传裴注.md#pei-002-1)

> 徐衆評曰是儀以羇旅異方客仕吳朝值讒邪殄行當嚴毅之威命縣漏刻禍急危機不雷同以害人不苟免以傷義可謂忠勇公正之士雖祁奚之免叔向慶忌之濟朱雲何以尚之忠不䧟君勇不懾聳公不存私正不黨邪

徐众认为是仪临威胁仍尽忠守正、不加害人，并列前代不畏强权诸人。

**时段与依据** 论赞之文。原事随《通鉴》吕壹案件挂238；举典不从此年。

### 徐众论是仪辅二宫

[《三国志·是仪胡综传》裴注 002·2](../../sources/摘录/三国志-卷062-是仪胡综传裴注.md#pei-002-2)

> 資此四徳加之以文敏崇之以謙約履之以和順保傅二宫存身愛名不亦宜乎

以其忠勇公正、宽约和顺，肯定其辅佐宫府。

**时段与依据** 同注综评是仪多年任职，无单一纪年。

### 《吴录》谓魏明帝派隐蕃假降离间

[《三国志·是仪胡综传》裴注 003·1](../../sources/摘录/三国志-卷062-是仪胡综传裴注.md#pei-003-1)

> 吳録曰蕃有口才魏明帝使詐叛如吳令求作廷尉職重案大臣以離間之既為廷尉監衆人以據普與蕃親善常車馬雲集賓客盈堂

隐蕃有辩才，奉魏明帝之命假降吴，设法任廷尉监以排间吴廷。朱据、郝普与隐蕃密切。

**时段与依据** 入吴确在230，授命只有《吴录》叙出且无日期；本片叙命令和入吴后交往。

### 胡冲在晋任尚书郎和吴郡太守

[《三国志·是仪胡综传》裴注 004·1](../../sources/摘录/三国志-卷062-是仪胡综传裴注.md#pei-004-1)

> 吴録曰沖後仕晉尚書郎吳郡太守

《吴录》记胡冲在吴亡后仕晋，曾任尚书郎与吴郡太守。

**时段与依据** 先后可知，晋朝任官日期缺载。

## 吳範早年、通曆數而不赴京

<a id="period-sgz063-b-2966-1"></a>

<a id="wu063-l5-1"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l5-1)** · [TXT L5](../../sources/本地分卷/三国志/三国志-卷063.txt#L5)

> 吳範字文則，會稽上虞人也。以治歷數，知風氣，聞於郡中。舉有道，詣京都，世亂不行。

**釋讀** 吳範字文則，會稽上虞人。他研習曆法和術數，善於觀察風氣，在本郡有名。被推舉為有道，原擬赴京，遇上天下動亂而沒有成行。

**時段與依據** 籍貫、受薦與未赴京皆無確年。

<a id="wu063-l5-2"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l5-2)** · [TXT L5](../../sources/本地分卷/三国志/三国志-卷063.txt#L5)

> 會孫權起於東南，範委身服事，每有災祥，輒推數言狀，其術多效，遂以顯名。

**釋讀** 適逢孫權在東南崛起，吳範投身事奉他。每逢災異或祥瑞，吳範便據術數推測情況。傳中稱他的術數常見成效，因此名聲顯著。

**時段與依據** 孫權在200年接掌江東。本句概述吳範來投和此後多次推占，未載來投年月，先於207年議討黃祖。

## 呂岱經白帝還吳，孫權詰問吳範

<a id="period-sgz063-b-2967-5"></a>

<a id="wu063-l9-2"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l9-2)** · [TXT L9](../../sources/本地分卷/三国志/三国志-卷063.txt#L9)

> 後呂岱從蜀還，遇之白帝，說備部衆離落，死亡且半，事必不克。權以難範，範曰：「臣所言者天道也，而岱所見者人事耳。」

**釋讀** 後來呂岱從蜀返回，途中在白帝遇到劉備，說劉備部眾離散、死去近半，判斷此事不會成功。孫權拿這話責問吳範，吳範說自己所論是天道，而呂岱所見是人事。

**時段與依據** 本傳敘在壬辰年的話以後、甲午年取蜀以前，往返和問答均無確年。卷060裴注另記211年呂岱出兵漢興寋城誘張魯，無白帝遇劉備的記載，不據以定此趟往返。

## 吳範對孫權與魏通好的警告

<a id="period-sgz063-b-2968-3"></a>

<a id="wu063-l13-1"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l13-1)** · [TXT L13](../../sources/本地分卷/三国志/三国志-卷063.txt#L13)

> 後權與魏爲好，範曰：「以風氣言之，彼以貌來，其實有謀，宜爲之備。」

**釋讀** 孫權後來和魏交好。吳範說，從風氣推測，對方表面通好而內有謀劃，應該提防。

**時段與依據** 接219年關羽被擒而敘。卷047等載漢末孫權與曹操往來、220–221年與曹丕交涉、222年決裂，本句沒有指明使者、會盟或受冊之日，按通好至交兵的前事閱讀。

## 吳範任騎都尉、太史令，未向孫權傳術

<a id="period-sgz063-b-2968-5"></a>

<a id="wu063-l15-1"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l15-1)** · [TXT L15](../../sources/本地分卷/三国志/三国志-卷063.txt#L15)

> 權以範爲騎都尉，領太史令，數從訪問，欲知其決。範祕惜其術，不以至要語權。權由是恨之。

**釋讀** 孫權任吳範為騎都尉，兼太史令，屢次問他而想知道判斷的訣竅。吳範珍惜自己的方法，不肯把其中的要義告訴孫權，孫權因此怨他。

**時段與依據** 本傳不記任命以及問答的年月。

<a id="period-sgz063-p-001-1"></a>

<a id="wu063-l16-1"></a>

**[《三國志·吳範劉惇趙達傳》裴注 001](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l16-1)** · [TXT L16](../../sources/本地分卷/三国志/三国志-卷063.txt#L16)

> 吳錄曰：範獨心計，所以見重者術，術亡則身棄矣，故終不言。

**釋讀** 《吳錄》說，吳範心中盤算，自己受到重用正因掌握這門術數；假如失去這個依憑，自己也就會被棄置，因此始終不說。

**時段與依據** 裴注補述吳範的用意，與上文是同一組材料。

## 吳範稱江南有王氣，孫權允諾若驗則封侯

<a id="period-sgz063-b-2969-1"></a>

<a id="wu063-l18-1"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l18-1)** · [TXT L18](../../sources/本地分卷/三国志/三国志-卷063.txt#L18)

> 初，權爲將軍時，範甞白言江南有王氣，亥子之間有大福慶。權曰：「若終如言，以君爲侯。」

**釋讀** 孫權還是將軍時，吳範曾聲稱江南有王者之氣，亥、子之間會有大福慶。孫權說如果真的如他所言，就封他為侯。

**時段與依據** 「亥子」是吳範預測的時段，本傳未載發話年月或所指事。冊吳王以前相近的亥、子年有207–208、219–220；孫權領荊州牧與漢魏易代在219–220，魏冊孫權為吳王在221辛丑。不能由受冊倒定發話年，或斷言「大福慶」指受冊。

## 論功將封，孫權刪去吳範名字

<a id="period-sgz063-b-2969-3"></a>

<a id="wu063-l18-3"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l18-3)** · [TXT L18](../../sources/本地分卷/三国志/三国志-卷063.txt#L18)

> 及後論功行封，以範爲都亭侯。詔臨當出，權恚其愛道於己也，削除其名。

**釋讀** 後來論功封賞，吳範原擬封都亭侯。詔書快頒布時，孫權氣他珍惜術數而不肯傳給自己，就從詔書中刪去他的名字。

**時段與依據** 上承221年魏冊孫權為吳王，下限為吳範226年去世；論功及削名沒有明年。

## 吳範剃髮自縛，為魏滕求免

<a id="period-sgz063-b-2970-1"></a>

<a id="period-sgz063-b-2971-1"></a>

<a id="wu063-l20-1"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l20-1)** · [TXT L20](../../sources/本地分卷/三国志/三国志-卷063.txt#L20)

> 範爲人剛直，頗好自稱，然與親故交接有終始。素與魏滕同邑相善。滕甞有罪，權責怒甚嚴，敢有諫者死，範謂滕曰：「與汝偕死。」滕曰：「死而無益，何用死爲？」範曰：「安能慮此，坐觀汝邪？」乃髠頭自縛詣門下，使鈴下以聞。鈴下不敢，曰：「必死，不敢白。」範曰：「汝有子邪？」曰：「有。」曰：「使汝爲吳範死，子以屬我。」鈴下曰：「諾。」乃排閤入。言未卒，權大怒，欲便投以戟。逡巡走出，範因突入，叩頭流血，言與涕並。良乆，權意釋，乃免滕。滕見範謝曰：「父母能生長我，不能免我於死。丈夫相知，如汝足矣，何用多爲！」

**釋讀** 吳範剛直而頗愛自誇，待親友始終如一，與同鄉魏滕素來交好。魏滕獲罪，孫權震怒，並說敢求情者死。吳範表示願與魏滕同死；魏滕說死了也沒有益處，吳範答自己豈能坐視。他剃髮自縛，到府門請侍從通報。侍從怕死，吳範問他可有兒子，答應若他為自己而死，便照顧其子。侍從推門稟報，話還未完，孫權大怒，要向他投戟，他趕緊退走。吳範乘機進去叩頭，血流不止，流著淚請求。許久孫權怒意平息，寬免了魏滕。魏滕道謝，說父母能生養自己，卻不能救自己免死，知己有吳範一人已足。

**時段與依據** 在孫權統事之後、吳範226年去世以前，罪由及年月未載。卷050〈吳夫人傳〉裴注所記為魏滕觸忤孫策、吳夫人勸免，係另一事，本傳注文亦分敘。

<a id="period-sgz063-p-002-1"></a>

<a id="wu063-l21-1"></a>

**[《三國志·吳範劉惇趙達傳》裴注 002](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l21-1)** · [TXT L21](../../sources/本地分卷/三国志/三国志-卷063.txt#L21)

> 會稽典錄曰：滕字周林，祖父河內太守朗，字少英，列在八俊。滕性剛直，行不苟合，雖遭困偪，終不迴撓。

**釋讀** 魏滕字周林，祖父魏朗任河內太守，字少英，是東漢士人所稱的八俊之一。魏滕為人剛直，行事不苟且迎合，雖被逼迫也始終不屈。

**時段與依據** 《會稽典錄》為家世與性行情境的補述。卷057裴注亦稱魏少英屬八俊，《後漢書》卷067有魏朗本傳及八俊名單。

<a id="wu063-l21-3"></a>

**[《三國志·吳範劉惇趙達傳》裴注 002](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l21-3)** · [TXT L21](../../sources/本地分卷/三国志/三国志-卷063.txt#L21)

> 歷歷陽、鄱陽、山陰三縣令，鄱陽太守。

**釋讀** 魏滕歷任歷陽、鄱陽、山陰三縣縣令，並任鄱陽太守。

**時段與依據** 卷047載建安十五年（210）析豫章置鄱陽郡，魏滕出任鄱陽太守須在立郡後。三縣令及太守的任、免年月均無明文。

## 劉惇避亂廬陵，成為孫輔軍師

<a id="period-sgz063-b-2974-1"></a>

<a id="wu063-l28-1"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l28-1)** · [TXT L28](../../sources/本地分卷/三国志/三国志-卷063.txt#L28)

> 劉惇字子仁，平原人也。遭亂避地，客遊廬陵，事孫輔。以明天官達占數顯於南土。每有水旱寇賊，皆先時處期，無不中者。輔異焉，以爲軍師，軍中咸敬事之，號曰神明。

**釋讀** 劉惇字子仁，是平原人。為避亂而客居廬陵，事奉孫輔，因熟悉星象與占算而在南方出名。本傳說，每遇水旱或寇賊，他總提前判定時日，無不應驗。孫輔認為他非同尋常，任他為軍師，軍中都敬重他，稱他為「神明」。

**時段與依據** 卷051敘孫輔在孫策西取豫章後進據廬陵、領太守，與《資治通鑑》卷063建安四年（199）孫策分置廬陵事相參。劉惇避亂、受任軍師及各次占事無明載年月。

<a id="period-sgz063-b-2975-3"></a>

<a id="wu063-l32-1"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l32-1)** · [TXT L32](../../sources/本地分卷/三国志/三国志-卷063.txt#L32)

> 惇於諸術皆善，尤明太一，皆能推演其事，窮盡要妙，著書百餘篇，名儒刁玄稱以爲奇。惇亦寶愛其術，不以告人，故世莫得而明也。

**釋讀** 劉惇通曉多種術數，尤明太一，能推演其中道理，窮究微妙，著書百餘篇，名儒刁玄稱奇。劉惇珍惜其術，不教給別人，世人遂無從明瞭。

**時段與依據** 本傳未記著書、刁玄稱許及不傳其術的具體年代。卷059見刁玄曾為229年孫登東宮賓客，這一任用不能決定他何時見到劉惇著述。

## 趙達的籍貫、從學與渡江

<a id="period-sgz063-b-2977-1"></a>

<a id="wu063-l36-1"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l36-1)** · [TXT L36](../../sources/本地分卷/三国志/三国志-卷063.txt#L36)

> 趙達，河南人也。少從漢侍中單甫受學，用思精密，謂東南有王者氣，可以避難，故脫身渡江。

**釋讀** 趙達是河南人。年少時跟從漢侍中單甫學習，思慮精密。趙達認為東南有王者之氣，可以避難，於是離開故地，渡過長江。

**時段與依據** 從師和渡江都沒有明載年月。篇末孫盛也談趙達渡江，並以曹魏受命反駁其望氣，但那段評論所舉的魏受禪年不能定為渡江年。

## 九宮一算及估豆、測藏酒、辨空倉

<a id="period-sgz063-b-2977-2"></a>

<a id="wu063-l36-2"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l36-2)** · [TXT L36](../../sources/本地分卷/三国志/三国志-卷063.txt#L36)

> 治九宮一筭之術，究其微旨，是以能應機立成，對問若神，至計飛蝗，射隱伏，無不中效。或難達曰：「飛者固不可校，誰知其然，此殆妄耳。」達使其人取小豆數斗，播之席上，立處其數，驗覆果信。甞過知故，知故爲之具食。食畢，謂曰：「倉卒乏酒，又無嘉肴，無以叙意，如何？」達因取盤中隻箸，再三從橫之，乃言：「卿東壁下有美酒一斛，又有鹿肉三斤，何以辭無？」時坐有他賔，內得主人情，主人慙曰：「以卿善射有無，欲相試耳，竟效如此。」遂出酒酣飲。又有書簡上作千萬數，著空倉中封之，令達筭之。達處如數，云：「但有名無實。」其精微若是。

**釋讀** 趙達精研九宮一算，傳中稱他遇問立能推算，連飛蝗的數目和藏起的東西都能估中。有人懷疑飛蝗無從點驗，趙達便讓此人把幾斗小豆撒在席上，當場說出數目，覆點果然相合。趙達有次到熟人家用餐，主人推說倉促間沒有酒和好菜。他從盤裡取一支筷子，反覆縱橫擺弄，說東牆下明明有一斛好酒、三斤鹿肉。席間另有客人知曉主人的用意，主人承認想試他的本事，隨即拿出酒同飲。又有人在簡上寫下千萬之數，封入空倉，趙達說出相合的數目，卻說只有名數、沒有實物。傳文以此形容其術精微。

**時段與依據** 估豆、宴飲和空倉的記載都沒有紀年。三事以趙達的九宮一算為共同主題，隨同一段讀。

## 闞澤、殷禮與公孫滕求術，趙達仍未傳授

<a id="period-sgz063-b-2978-1"></a>

<a id="wu063-l38-1"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l38-1)** · [TXT L38](../../sources/本地分卷/三国志/三国志-卷063.txt#L38)

> 達寶惜其術，自闞澤、殷禮皆名儒善士，親屈節就學，達祕而不告。太史丞公孫滕少師事達，勤苦累年，達許教之者有年數矣，臨當喻語而輒復止。滕他日齎酒具，候顏色，拜跪而請，達曰：「吾先人得此術，欲圖爲帝王師，至仕來三世，不過太史郎，誠不欲復傳之。且此術微妙，頭乘尾除，一筭之法，父子不相語。然以子篤好不倦，今真以相授矣。」飲酒數行，達起取素書兩卷，大如手指，達曰：「當寫讀此，則自解也。吾乆廢，不復省之，今欲思論一過，數日當以相與。」滕如期往，至乃陽求索書，驚言失之，云：「女壻昨來，必是渠所竊。」遂從此絕。

**釋讀** 趙達珍惜此術，闞澤、殷禮這樣有名望的儒者親來求學，他也秘而不告。太史丞公孫滕年輕時拜趙達為師，勤學多年，趙達數次說要教他，到了該傳授時總是作罷。公孫滕後來帶酒等候，察顏觀色，跪請傳授。趙達說祖先習得此術，曾希望用它做帝王之師，但三代仕宦也只做到太史郎，便不願再傳；又說從頭乘、從尾除的「一算」微妙到父子也不相告，但公孫滕好學不倦，此次願意傳給他。幾巡酒後，趙達取出兩卷手指大小的素書，叫公孫滕抄讀，卻又說書久未用，要先重看一遍，過幾天再交付。公孫滕如期來取，趙達假意找書，驚稱遺失，又推說是昨日來訪的女婿偷了，傳授就此作罷。

**時段與依據** 從學和推諉累年，太史丞也只是傳中所稱官職，未載任命年月。闞澤見卷053，殷禮於224年隨張溫使蜀見卷057；這些經歷沒有交代向趙達求學的年月。

<a id="period-sgz063-b-2979-1"></a>

<a id="wu063-l40-1"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l40-1)** · [TXT L40](../../sources/本地分卷/三国志/三国志-卷063.txt#L40)

> 初孫權行師征伐，每令達有所推步，皆如其言。權問其法，達終不語，由此見薄，祿位不至。

**釋讀** 孫權從前出師征討時，常命趙達推算，傳文說結果都像他所講的那樣。孫權問他用甚麼方法，他始終不肯說，因此受到冷落，未得高位厚祿。

**時段與依據** 本文總說孫權多次用兵時向趙達問算，沒有指明戰役和授官年月。

## 趙達自算卒期，孫權發棺求書

<a id="period-sgz063-b-2979-2"></a>

<a id="wu063-l43-1"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l43-1)** · [TXT L43](../../sources/本地分卷/三国志/三国志-卷063.txt#L43)

> 達常笑謂諸星氣風術者曰：「當迴筭帷幕，不出戶牖以知天道，而反晝夜暴露以望氣祥，不亦難乎！」閒居無爲，引筭自校，乃歎曰：「吾筭訖盡某年月日，其終矣。」達妻數見達效，聞而哭泣。達欲弭妻意，乃更步筭，言：「向者謬誤耳，尚未也。」後如期死。權聞達有書，求之不得，乃錄問其女，及發棺無所得，法術絕焉。

**釋讀** 趙達曾取笑觀星望氣的人，說在帷幕下運算，不出門窗就能知道天道，何必晝夜露天觀候。閒居時，他拿籌重新推算，自歎年月日數已盡，死期就在某時。妻子屢見其算應驗，聞言啼哭；趙達為了寬慰她，重新推算後說剛才有錯、死期還沒到。傳文說他後來仍在所言之期去世。孫權聽說趙達有書，尋訪不得，於是拘訊他的女兒，連棺也打開查看，仍一無所獲，這門術遂失傳。

**時段與依據** 正文只記「某年月日」，無法由「如期」推出卒年。孫權在趙達死後求書，故卒在孫權生前；若連繫裴注所載即帝位問算，趙達至少在229年尚在世，卒年可限於229至252年間，仍無確年月。226年吳範卒後以趙達為薦舉比準，也未明言趙達已去世。

## 皇象書法與江東八絕

<a id="period-sgz063-p-005-1"></a>

<a id="wu063-l44-1"></a>

**[《三國志·吳範劉惇趙達傳》裴注 005](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l44-1)** · [TXT L44](../../sources/本地分卷/三国志/三国志-卷063.txt#L44)

> 吳錄曰：皇象字休明，廣陵江都人。幼工書。時有張子並、陳梁甫能書。甫恨逋，並恨峻，象斟酌其閒，甚得其妙，中國善書者不能及也。嚴武字子卿，衞尉畯再從子也，圍棊莫與爲輩。宋壽占夢，十不失一。曹不興善畫，權使畫屏風，誤落筆點素，因就以作蠅。旣進御，權以爲生蠅，舉手彈之。孤城鄭嫗能相人，及範、惇、達八人，世皆稱妙，謂之八絕云。

**釋讀** 《吳錄》說皇象字休明，廣陵江都人，自幼擅長書法。當時張子並、陳梁甫也擅書，陳梁甫的筆勢嫌遲緩，張子並又嫌峻急，皇象折衷兩人的長處，掌握妙處，中原擅書者也比不上他。嚴武字子卿，是衛尉嚴畯的再從子，圍棋無人能比。宋壽解夢，幾乎不會出錯。曹不興善畫，孫權命他畫屏風，他不慎在白絹上落了一點墨，便就勢畫成蒼蠅；屏風進呈後，孫權以為是真的，抬手去彈。孤城的鄭姓老婦善於相人，這五人加上吳範、劉惇、趙達，時人合稱八絕。

**時段與依據** 人物技能與軼事共述，成名、受命和八絕稱號的確年均無載。曹不興畫屏只知孫權在時。卷064〈孫綝傳〉裴注引《文士傳》，記張溫曾到山陰從皇象學書，後任選部尚書；卷057〈張溫傳〉敘張溫任選曹尚書在224年使蜀前，僅可確知這一段從學先於使蜀。

## 葛衡作機動渾天

<a id="period-sgz063-p-005-2"></a>

<a id="wu063-l44-2"></a>

**[《三國志·吳範劉惇趙達傳》裴注 005](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l44-2)** · [TXT L44](../../sources/本地分卷/三国志/三国志-卷063.txt#L44)

> 　晉陽秋曰：吳有葛衡字思真，明達天官，能爲機巧，作渾天，使地居于中，以機動之，天轉而地止，以上應晷度。

**釋讀** 《晉陽秋》記吳人葛衡字思真，通曉天文，善製精巧器物。他製作渾天儀象，讓象徵大地的部分居中，發動機械後，天體部分轉動，大地部分靜止，用來與晷度（用日影測知的時度）相應。

**時段與依據** 《晉陽秋》只說「吳有葛衡」。《隋書·天文志》也把造器置於吳時，說後來南朝宋錢樂之仿照此法，仍未給葛衡造器確年。

## 陳壽、孫盛與裴松之論術數

<a id="period-sgz063-b-2980-1"></a>

<a id="wu063-l46-1"></a>

**[《三國志·吳範劉惇趙達傳》正文](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l46-1)** · [TXT L46](../../sources/本地分卷/三国志/三国志-卷063.txt#L46)

> 評曰：三子各於其術精矣，其用思妙矣，然君子等役心神，宜於大者遠者，是以有識之士，舍彼而取此也。

**釋讀** 陳壽說三人各自精通所治方術，用心也巧妙。然而君子應把心力用在更宏大、長遠的事上，有識者因此捨這些小術而取其大。

**時段與依據** 卷末史評，概論三人所學及用心取捨。

<a id="period-sgz063-p-006-1"></a>

<a id="wu063-l47-1"></a>

**[《三國志·吳範劉惇趙達傳》裴注 006](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l47-1)** · [TXT L47](../../sources/本地分卷/三国志/三国志-卷063.txt#L47)

> 孫盛曰：夫玄覽未然，逆鑒來事，雖裨竈、梓慎其猶病諸，況術之下此者乎？吳史書達知東南當有王氣，故輕舉濟江。魏承漢緒，受命中畿，達不能豫覩兆萌，而流竄吳越。又不知吝術之鄙，見薄於時，安在其能逆覩天道而審帝王之符瑞哉？昔聖王觀天地之文，以畫八卦之象，故亹亹成於蓍策，變化形乎六爻，是以三易雖殊，卦繇理一，安有迴轉一籌，可以鉤深測隱，意對逆占，而能遂知來物者乎？流俗好異，妄設神奇，不幸之中，仲尼所棄，是以君子志其大者，無所取諸。

**釋讀** 孫盛說未發生之事難以預知，裨竈、梓慎尚且難以做到。他以魏在中原代漢為論據，質疑趙達既說東南有王氣而渡江，為何沒有預見魏之興；趙達又因秘術被慢待，也未能預知。他認為古人觀天地作八卦，用蓍策、六爻推求變化，三易雖不同，卦爻辭原理相通；轉動一籌便探隱知來，只是偶中被好奇者神化，孔子和志向遠大的君子不採。

**時段與依據** 孫盛對趙達渡江和一算術的後評。「魏承漢緒」是孫盛的立場，與裴松之下文分讀。

<a id="period-sgz063-p-006-2"></a>

<a id="wu063-l47-2"></a>

**[《三國志·吳範劉惇趙達傳》裴注 006](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l47-2)** · [TXT L47](../../sources/本地分卷/三国志/三国志-卷063.txt#L47)

> 　臣松之以爲盛云「君子志其大者，無所取諸」，故評家之旨，非新聲也。其餘所譏，則皆爲非理。自中原酷亂，至于建安，數十年間，生民殆盡，比至小康，皆百死之餘耳。江左雖有兵革，不能如中國之甚也，焉知達不筭其安危，知禍有多少，利在東南，以全其身乎？而責不知魏氏將興，流播吳越，在京房之籌，猶不能自免刑戮，況達但以祕術見薄，在悔吝之間乎！古之道術，蓋非一方，探賾之功，豈惟六爻，苟得其要，則可以易而知之矣，迴轉一籌，胡足怪哉？達之推筭，窮其要妙以知幽測隱，何愧於古！而以裨、梓限之，謂達爲妄，非篤論也。

**釋讀** 裴松之同意應志於大事，說這是陳壽原有的旨意。他指出中原直到建安連年兵亂，百姓死傷極多，江左雖有兵事，禍害較輕；趙達也許正是衡量兩地禍福才選東南。京房會算也未能免於殺身，趙達只是因不傳術而遭輕視，何必以此責其不能預知。古代探求幽隱的方法不止六爻，得其要領，轉一籌也無可怪；他視趙達推算為精妙，認為只拿裨竈、梓慎來限斷其為妄，並非篤論。

**時段與依據** 裴松之後出的辨論，直接回應孫盛與卷末陳壽總評。建安之亂及京房是辨論事例。

## 裴注所錄吳宮方術傳聞

裴注連錄《抱朴子》《神仙傳》的逸聞，末錄裴松之對引書的評論。介象故事提到的張溫使蜀，可另讀[224 年吳蜀通使](ce-0224.md#ce224-note-4)。

<a id="wu063-l47-3"></a>

**[《三國志·吳範劉惇趙達傳》裴注 006](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l47-3)** · [TXT L47](../../sources/本地分卷/三国志/三国志-卷063.txt#L47)

> 　抱朴子曰：時有葛仙公者，每飲酒醉，常入人家門前陂水中卧，竟日乃出。曾從吳主別，到洌州，還遇大風，百官船多沒，仙公船亦沒淪，吳主甚悵恨。明日使人鉤求公船，而登高以望焉。乆之，見公步從水上來，衣履不沾，而有酒色。旣見而言曰：「臣昨侍從而伍子胥見請，暫過設酒，忽忽不得，即委之。」

**釋讀** 《抱朴子》說葛仙公醉後常到人家門前池水中躺臥一整天。一次隨吳主往洌州，返程風大，百官的船多沉沒，他的船也沉了。次日吳主遣人搜尋，登高等待，竟看見他踏水而來，衣鞋不濕且有酒意。葛仙公自稱被伍子胥請去喝酒，才剛離席。

**時段與依據** 葛洪引述的方術傳聞。未記吳主此行的年月，文字中的遇風、渡水和酒宴皆隨傳聞全文保留。

> 又有姚光者，有火術。吳主身臨試之，積荻數千束，使光坐其上，又以數千束荻裹之，因猛風而燔之。荻了盡，謂光當以化爲燼，而光端坐灰中，振衣而起，把一卷書。吳主取其書視之，不能解也。

**釋讀** 《抱朴子》又說姚光有火術，吳主在場試驗。眾人以荻薪施火，火盡以為姚光已被燒死，書中卻說他從灰中整衣站起，手持一卷書，吳主取閱而不能解。

**時段與依據** 方術傳聞，只稱吳主親臨，沒有獨立年月。

<a id="period-sgz063-p-006-5"></a>

<a id="wu063-l47-5"></a>

**[《三國志·吳範劉惇趙達傳》裴注 006](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l47-5)** · [TXT L47](../../sources/本地分卷/三国志/三国志-卷063.txt#L47)

> 又曰：吳景帝有疾，求覡視者，得一人。景帝欲試之，乃殺鵝而埋於苑中，架小屋，施牀几，以婦人屐履服物著其上，乃使覡視之。告曰：「若能說此冢中鬼婦人形狀者，當加賞而即信矣。」竟日盡夕無言，帝推問之急，乃曰：「實不見有鬼，但見一頭白鵝立墓上，所以不即白之，疑是鬼神變化作此相，當候其真形而定。無復移易，不知何故，不敢不以實上聞。」景帝乃厚賜之。然則鵝死亦有鬼也。

**釋讀** 《抱朴子》又說吳景帝孫休病時求巫覡看病。為試其本領，他埋一隻鵝，在墓上搭屋置床幾與婦人服物，叫巫覡說出墓中女鬼的樣貌。巫覡受追問後只說看見白鵝，原等它變回鬼神真形卻始終未變，因此不敢妄報。孫休厚賞他。引文最後反問或推說，這樣連死鵝也有鬼了。

**時段與依據** 引文稱景帝，可知故事背景在孫休在位期間（258–264），患病與試覡之年欠詳，不能逕同264年臨終疾病。

**[《三國志·吳範劉惇趙達傳》裴注 006](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l47-6)** · [TXT L47](../../sources/本地分卷/三国志/三国志-卷063.txt#L47)

> 　葛洪神仙傳曰：仙人介象，字元則，會稽人，有諸方術。吳主聞之，徵象到武昌，甚敬貴之，稱爲介君，爲起宅，以御帳給之，賜遺前後累千金，從象學蔽形之術。試還後宮，及出殿門，莫有見者。又使象作變化，種瓜菜百果，皆立生可食。吳主共論鱠魚何者最美，象曰：「鯔魚爲上。」吳主曰：「論近道魚耳，此出海中，安可得邪？」象曰：「可得耳。」乃令人於殿庭中作方埳，汲水滿之，并求鉤。象起餌之，垂綸於埳中。須臾，果得鯔魚。吳主驚喜，問象曰：「可食不？」象曰：「故爲陛下取以作生鱠，安敢取不可食之物！」乃使厨下切之。吳主曰：「聞蜀使來，得蜀薑作韲甚好，恨爾時無此。」象曰：「蜀薑豈不易得，願差所使者，并付直。」吳主指左右一人，以錢五十付之。象書一符，以著青竹杖中，使行人閉目騎杖，杖止，便買薑訖，復閉目。此人承其言騎杖，須臾止，已至成都，不知是何處，問人，人言是蜀市中，乃買薑。于時吳使張溫先在蜀，旣於市中相識，甚驚，便作書寄其家。此人買薑畢，捉書負薑，騎杖閉目，須臾已還到吳，厨下切鱠適了。

**釋讀** 葛洪說會稽人介象字元則，擅多種方術。吳主召至武昌，稱介君，為他置宅、賜御帳及財物，還向他學隱形。故事又說介象能讓瓜果即種即熟，在殿庭灌水的土穴釣到本產於海的鯔魚，供吳主作生鱠。吳主想要蜀薑做佐料，介象將符放進竹杖，讓持五十錢的侍從閉眼騎杖，傳說此人轉眼到了成都，在市上買薑、遇見出使的張溫，替他帶回家書，回吳時廚下剛切好魚。

**時段與依據** 張溫聘蜀的史事在224年。引書用張溫在蜀作情節線索，介象受召與其餘方術傳說沒有可確定的年月。

**[《三國志·吳範劉惇趙達傳》裴注 006](../../sources/本地分卷/三国志/三国志-卷063.md#edition-wu063-l47-7)** · [TXT L47](../../sources/本地分卷/三国志/三国志-卷063.txt#L47)

> 臣松之以爲葛洪所記，近爲惑衆，其書文頗行世，故撮取數事，載之篇末也。神仙之術，詎可測量，臣之臆斷，以爲惑衆，所謂夏蟲不知冷氷耳。

**釋讀** 裴松之認為葛洪的記載近於惑眾，因其書流傳甚廣，選錄數事在篇末。他又自謙，神仙之術難以測量，自以為荒誕，也可能如夏蟲不知寒冰，只是受見識所限。

**時段與依據** 裴松之對引書的後評。與《抱朴子》《神仙傳》數則傳聞連讀。

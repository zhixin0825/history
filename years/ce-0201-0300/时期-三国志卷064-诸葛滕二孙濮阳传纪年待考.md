## 諸葛恪的家世

<a id="period-sgz064-b-2983-1"></a>

<a id="wu064-l5-1"></a>

**[《三國志·諸葛滕二孫濮陽傳》正文](../../拆分史书/三国志/卷064.md#edition-wu064-l5-1)** · [TXT L5](../../拆分史书/三国志/卷064.txt#L5)

> 諸葛恪字元遜，瑾長子也。少知名。

**釋讀** 諸葛恪字元遜，是諸葛瑾的長子，年少已有名聲。

**時段與依據** 傳首交代家世與少時聲名，未記生年或得名確年。

<a id="period-sgz064-p-001-1"></a>

<a id="period-sgz064-p-001-2"></a>

<a id="wu064-l6-1"></a>

**[《三國志·諸葛滕二孫濮陽傳》裴注 001](../../拆分史书/三国志/卷064.md#edition-wu064-l6-1)** · [TXT L6](../../拆分史书/三国志/卷064.txt#L6)

> 江表傳曰：恪少有才名，發藻岐嶷，辯論應機，莫與爲對。權見而奇之，謂瑾曰：「藍田生玉，真不虛也。」　吳錄曰：恪長七尺六寸，少鬚眉，折頞廣額，大口高聲。

**釋讀** 諸葛恪少年便顯露才思，辯論臨機應答，少有對手。孫權見而驚異，對諸葛瑾說藍田果然生玉。《吳錄》記他高七尺六寸，鬚眉稀少，鼻梁低、額頭寬，口大聲高。

**時段與依據** 少時性狀與形貌附在傳首，孫權初見確年未載。

<a id="wu064-l7-1"></a>

**[《三國志·諸葛滕二孫濮陽傳》正文](../../拆分史书/三国志/卷064.md#edition-wu064-l7-1)** · [TXT L7](../../拆分史书/三国志/卷064.txt#L7)

> 弱冠拜騎都尉，

**釋讀** 諸葛恪約二十歲時受任為騎都尉。

**時段與依據** 「弱冠」表年齡。本傳與孫登傳只確立入侍孫登的年代，騎都尉授官無獨立紀年。

## 為父親解席間戲言

<a id="period-sgz064-b-2983-2"></a>

<a id="wu064-l9-1"></a>

**[《三國志·諸葛滕二孫濮陽傳》正文](../../拆分史书/三国志/卷064.md#edition-wu064-l9-1)** · [TXT L9](../../拆分史书/三国志/卷064.txt#L9)

> 恪父瑾靣長似驢，孫權大會羣臣，使人牽一驢入，長檢其靣，題曰諸葛子瑜。恪跪曰：「乞請筆益兩字。」因聽與筆。恪續其下曰「之驢。」舉坐歡笑，乃以驢賜恪。

**釋讀** 諸葛瑾臉長，孫權宴請群臣時牽進一頭驢，給驢臉掛長牌，上寫「諸葛子瑜」。諸葛恪求筆添上「之驢」二字，滿座歡笑，孫權把驢賜給他。

**時段與依據** 本傳以接續數事說明諸葛恪的應對才捷，宴會確年未載。

<a id="period-sgz064-b-2983-3"></a>

<a id="wu064-l9-2"></a>

**[《三國志·諸葛滕二孫濮陽傳》正文](../../拆分史书/三国志/卷064.md#edition-wu064-l9-2)** · [TXT L9](../../拆分史书/三国志/卷064.txt#L9)

> 他日復見，權問恪曰：「卿父與叔父孰賢？」對曰：「臣父爲優。」權問其故，對曰：「臣父知所事，叔父不知，以是爲優。」權又大噱。

**釋讀** 孫權另一天問諸葛恪父親與叔父何人賢明，諸葛恪以父親懂得選擇侍奉的人、叔父不懂為父優的理由，孫權大笑。

**時段與依據** 本傳以接續數事說明諸葛恪的應對才捷，宴會確年未載。

<a id="period-sgz064-b-2983-4"></a>

<a id="wu064-l9-3"></a>

**[《三國志·諸葛滕二孫濮陽傳》正文](../../拆分史书/三国志/卷064.md#edition-wu064-l9-3)** · [TXT L9](../../拆分史书/三国志/卷064.txt#L9)

> 命恪行酒，至張昭前，昭先有酒色，不肯飲，曰：「此非養老之禮也。」權曰：「卿其能令張公辭屈，乃當飲之耳。」恪難昭曰：「昔師尚父九十，秉旄仗鉞，猶未告老也。今軍旅之事，將軍在後，酒食之事，將軍在先，何謂不養老也？」昭卒無辭，遂爲盡爵。

**釋讀** 張昭已帶醉意，推辭說勸他飲酒不合養老之禮。諸葛恪舉九十歲的姜太公仍秉旄持鉞為例，說張昭在軍事上居後、在宴席上居先，正是敬老。張昭辭窮，飲盡杯中酒。

**時段與依據** 張昭卒於236年，席間問答確年未載。

<a id="period-sgz064-b-2983-5"></a>

<a id="wu064-l9-4"></a>

**[《三國志·諸葛滕二孫濮陽傳》正文](../../拆分史书/三国志/卷064.md#edition-wu064-l9-4)** · [TXT L9](../../拆分史书/三国志/卷064.txt#L9)

> 後蜀使至，群臣並會，權謂使曰：「此諸葛恪雅好騎乘，還告丞相，爲致好馬。」恪因下謝，權曰：「馬未至而謝何也？」恪對曰：「夫蜀者陛下之外廄，今有恩詔，馬必至也，安敢不謝？」恪之才捷，皆此類也。

**釋讀** 蜀使到吳時，孫權讓他轉告丞相送良馬給喜歡騎馬的諸葛恪。諸葛恪當即謝恩，稱蜀地就像孫權的外廄，命令既下，良馬必至。

**時段與依據** 原文未記使者姓名，蜀吳往來多次；不能因下附費禕應對就認作同次出使。

<a id="period-sgz064-p-002-1"></a>

<a id="wu064-l10-1"></a>

**[《三國志·諸葛滕二孫濮陽傳》裴注 002](../../拆分史书/三国志/卷064.md#edition-wu064-l10-1)** · [TXT L10](../../拆分史书/三国志/卷064.txt#L10)

> 恪別傳曰：權甞饗蜀使費禕，先逆勑羣臣：「使至，伏食勿起。」禕至，權爲輟食，而羣下不起。禕啁之曰：「鳳皇來翔，騏驎吐哺，驢騾無知，伏食如故。」恪荅曰：「爰植梧桐，以待鳳皇，有何燕雀，自稱來翔？何不彈射，使還故鄉！」禕停食餅，索筆作麥賦，恪亦請筆作磨賦，咸稱善焉。

**釋讀** 孫權宴請費禕前命群臣伏案吃飯，不起迎接。費禕以鳳皇來翔、驢騾仍吃相嘲，諸葛恪說梧桐等的是鳳皇，如今飛來的燕雀該給射回去。費禕停下手中餅寫《麥賦》，諸葛恪寫《磨賦》應答，二賦都獲稱許。

**時段與依據** 卷044〈費禕傳〉記其多次出使，並稱到吳後與諸葛恪等辭辯相難，這一場宴席未單獨紀年。

<a id="period-sgz064-p-002-3"></a>

<a id="period-sgz064-p-002-4"></a>

<a id="period-sgz064-p-002-5"></a>

<a id="wu064-l10-2"></a>

**[《三國志·諸葛滕二孫濮陽傳》裴注 002](../../拆分史书/三国志/卷064.md#edition-wu064-l10-2)** · [TXT L10](../../拆分史书/三国志/卷064.txt#L10)

> 權甞問恪：「頃何以自娛，而更肥澤？」恪對曰：「臣聞富潤屋，德潤身，臣非敢自娛，脩己而已。」又問：「卿何如滕胤？」恪荅曰：「登階躡履，臣不如胤；迴籌轉策，胤不如臣。」恪甞獻權馬，先𨪕其耳。范慎時在坐，嘲恪曰：「馬雖大畜，稟氣於天，今殘其耳，豈不傷仁？」恪荅曰：「母之於女，恩愛至矣，穿耳附珠，何傷於仁？」太子甞嘲恪：「諸葛元遜可食馬矢。」恪曰：「願太子食雞卵。」權曰：「人令卿食馬矢，卿使人食雞卵何也？」恪曰：「所出同耳。」權大笑。

**釋讀** 孫權問諸葛恪為何養得肥潤，諸葛恪以德能潤身、自己只求修養作答。他說禮節上的舉止不如滕胤，運籌謀略則滕胤不如自己。范慎譏他先穿馬耳才獻馬，有失仁心；諸葛恪反問慈母為女兒穿耳戴珠何曾傷仁。太子戲言讓他吃馬糞，他回請太子食雞卵，說兩物出處相同，孫權大笑。

**時段與依據** 所涉多次問答未各署年。此處有孫權與太子同席的情節，不能據以指明某次宴會的年份。

> 　江表傳曰：曾有白頭鳥集殿前，權曰：「此何鳥也？」恪曰：「白頭翁也。」張昭自以坐中最老，疑恪以鳥戲之，因曰：「恪欺陛下，未甞聞鳥名白頭翁者，試使恪復求白頭母。」恪曰：「鳥名鸚母，未必有對，試使輔吳復求鸚父。」昭不能荅，坐中皆歡笑。

**釋讀** 一隻白頭鳥飛到殿前，諸葛恪說它叫白頭翁。自認席上最老的張昭以為遭揶揄，讓諸葛恪找白頭母。諸葛恪便舉「鸚母」反請張昭尋「鸚父」，張昭答不出，座中皆笑。

**時段與依據** 稱張昭為輔吳，可與卷052所敘受官相參；張昭卒年可知，這次鳥名問答只可置於其在世任官期間。

## 孫權命諸葛恪掌軍糧

<a id="period-sgz064-b-2983-6"></a>

<a id="wu064-l11-1"></a>

**[《三國志·諸葛滕二孫濮陽傳》正文](../../拆分史书/三国志/卷064.md#edition-wu064-l11-1)** · [TXT L11](../../拆分史书/三国志/卷064.txt#L11)

> 權甚異之，欲試以事，令守節度。節度掌軍糧穀，文書繁猥，非其好也。

**釋讀** 孫權看重諸葛恪的才智，想試他的辦事能力，便讓他暫代節度，掌理軍中糧穀。文書繁多瑣碎，並非諸葛恪喜好的工作。

**時段與依據** 孫權為吳王時始置節度。諸葛恪繼徐詳任職的年份未載，另見下附《江表傳》。

<a id="period-sgz064-p-003-2"></a>

<a id="wu064-l12-2"></a>

**[《三國志·諸葛滕二孫濮陽傳》裴注 003](../../拆分史书/三国志/卷064.md#edition-wu064-l12-2)** · [TXT L12](../../拆分史书/三国志/卷064.txt#L12)

> 詳死，將用恪。諸葛亮聞恪代詳，書與陸遜曰：「家兄年老，而恪性踈，今使典主糧穀，糧穀軍之要最，僕雖在遠，竊用不安。足下特爲啟至尊轉之。」遜以白權，即轉恪領兵。

**釋讀** 徐詳死後，諸葛恪接掌節度。諸葛亮寫信給陸遜，說兄長諸葛瑾已老，諸葛恪性情疏略，糧穀又是軍中要務，他人在遠方仍不安心，請陸遜代向孫權陳請改任。陸遜奏報後，孫權讓諸葛恪轉任領兵。

**時段與依據** 承徐詳死後，諸葛亮信當在其234年去世以前，徐詳去世和改任的確年均未載。

## 設兵封山，待穀將熟而芟刈

<a id="period-sgz064-b-2984-5"></a>

<a id="wu064-l16-2"></a>

**[《三國志·諸葛滕二孫濮陽傳》正文](../../拆分史书/三国志/卷064.md#edition-wu064-l16-2)** · [TXT L16](../../拆分史书/三国志/卷064.txt#L16)

> 乃分內諸將，羅兵幽阻，但繕藩籬，不與交鋒，候其穀稼將熟，輒縱兵芟刈，使無遺種。舊穀旣盡，新田不収，平民屯居，略無所入，於是山民饑窮，漸出降首。

**釋讀** 諸葛恪分派部將往幽深險處設防，修築藩籬而不正面交戰，每逢稻穀將熟便出兵割除，不留種子。山民舊糧吃完，新糧不能收，又因外縣平民集中居住，無處獲糧，逐漸因飢困而出山歸降。

**時段與依據** 自234年到任後施行，到237年收取山民告成。這是持續做法，難分配到某一實施年；《通鑑》卷073在告成處追敘。

## 轉述楊敬叔相助惜才之論

<a id="period-sgz064-b-2988-2"></a>

<a id="period-sgz064-b-2989-1"></a>

<a id="wu064-l20-2"></a>

<a id="wu064-l20-3"></a>

<a id="wu064-l20-4"></a>

<a id="wu064-l20-5"></a>

<a id="full-wu064-l20-2"></a>

**[《三國志·諸葛滕二孫濮陽傳》](../../拆分史书/三国志/卷064.md#full-wu064-l20-2)** · [TXT L20](../../拆分史书/三国志/卷064.txt#L20)

> 與丞相陸遜書曰：「楊敬叔傳述清論，以爲方今人物彫盡，守德業者不能復幾，宜相左右，更爲輔車，上熙國事，下相珍惜。又疾世俗好相謗毀，使已成之器，中有損累；將進之徒，意不歡笑。聞此喟然，誠獨擊節。愚以爲君子不求備於一人，自孔氏門徒大數三千，見其異者七十二人，至于子張、子路、子貢等七十之徒，亞聖之德，然猶各有所短，師辟由喭，賜不受命，豈况下此而無所闕？且仲尼不以數子之不備而引以爲友，不以人所短棄其所長也。加以當今取士，宜寬於徃古，何者？時務從橫，而善人單少，國家職司，常苦不充。苟令性不邪惡，志在陳力，便可獎就，騁其所任。若於小小宜適，私行不足，皆宜闊略，不足縷責。且士誠不可纖論苛克，苛克則彼賢聖猶將不全，況其出入者邪？故曰以道望人則難，以人望人則易，賢愚可知。自漢末以來，中國士大夫如許子將輩，所以更相謗訕，或至爲禍，原其本起，非爲大讎，惟坐克己不能盡如禮，而責人專以正義。夫己不如禮，則人不服。責人以正義，則人不堪。內不服其行，外不堪其責，則不得不相怨。相怨一生，則小人得容其閒。得容其閒，則三至之言，浸潤之譖，紛錯交至，雖使至明至親者處之，猶難以自定，况己爲隙，且未能明者乎？是故張、陳至於血刃，蕭、朱不終其好，本由於此而已。夫不捨小過，纖微相責，乆乆至於家戶爲怨，一國無復全行之士也。」

**釋讀** 諸葛恪致書陸遜，轉述楊敬叔的話：時下人才凋零，守德有業者少，宜相互扶助，上以振興國事，下以珍惜彼此；相互攻訐只會損傷已成之才，也使後進失意。諸葛恪說自己聽後深以為然。

**時段與依據** 書在本傳編排於赤烏中移柴桑之後、陸遜去世之前；若「丞相」是當時官稱，約244年至245年初，無確年。

**釋讀** 諸葛恪說，君子不應要求一人事事完備。孔門徒眾三千，顯異者七十二，子張、子路、子貢雖德近聖賢，也各有偏失。孔子仍與他們往來，因為不能用短處抹煞長處。

**釋讀** 當世政事紛繁、賢人稀少，官職常難補足；凡品行不邪、願意盡力者，即可依其才任使。細節不妥和私行欠缺應酌情寬免，若求全過細，便連賢聖也難以保全。以理想尺度責人難，以尋常人情考量，才容易分辨賢愚。

**釋讀** 許子將等漢末士人互相譏訕而招禍，往往因自己行止未能合禮，卻以嚴格規範責求他人，招來不服與怨恨。一旦生隙，反覆的讒言便可離間，即使親近明達的人也難自定。張耳、陳餘相攻，蕭育、朱博友誼不終，此為前例；細過不恕，終會家家結怨，國中無一人能保全品行名聲。

**時段與依據** 同信所述許劭、張耳與陳餘、蕭育與朱博皆為取譬或回顧，不另作本段當年事件。

## 諸葛綽因與魯王交關被父親鴆殺

> 恪長子綽，騎都尉，以交關魯王事，權遣付恪，令更教誨，恪鴆殺之。

**釋讀** 諸葛恪長子綽任騎都尉，因同魯王孫霸交關，孫權把他交給諸葛恪重新管教，諸葛恪以毒酒殺了他。

**時段與依據** 孫霸於242年封魯王、250年獲賜死。諸葛綽之罪與魯王相連，鴆殺在孫權在世時，本傳未交代是否與250年處分同時。

<a id="wu064-l58-1"></a>

**[《三國志·諸葛滕二孫濮陽傳》裴注 010](../../拆分史书/三国志/卷064.md#edition-wu064-l58-1)** · [TXT L58](../../拆分史书/三国志/卷064.txt#L58)

> 江表傳曰：朝臣有乞爲恪立碑以銘其勳績者，博士盛沖以爲不應。孫休曰：「盛夏出軍，士卒傷損，無尺寸之功，不可謂能；受託孤之任，死於豎子之手，不可謂智。沖議爲是。」遂寢。

**釋讀** 《江表傳》說有朝臣請為諸葛恪立碑銘功，博士盛沖不贊成。孫休指諸葛恪盛夏出師，士卒傷損卻無尺寸之功；身負託孤之任竟遭孫峻所殺，也算不上明智。他認可盛沖的意見，事情遂停。

**時段與依據** 此為孫休就政事表態，約在其在位時（258–264）。《江表傳》未載立碑之議發生於哪一年。

## 留贊斬吳桓受傷，自治其足

<a id="period-sgz064-p-016-1"></a>

<a id="wu064-l83-1"></a>

**[《三國志·諸葛滕二孫濮陽傳》裴注 016](../../拆分史书/三国志/卷064.md#edition-wu064-l83-1)** · [TXT L83](../../拆分史书/三国志/卷064.txt#L83)

> 吳書曰：留贊字正明，會稽長山人。少爲郡吏，與黃巾賊帥吳桓戰，手斬得桓。贊一足被創，遂屈不伸。然性烈，好讀兵書及三史，每覽古良將戰攻之勢，輒對書獨歎，因呼諸近親謂曰：「今天下擾亂，英豪並起，歷觀前世，富貴非有常人，而我屈躄在閭巷之閒，存亡無以異。今欲割引吾足，幸不死而足申，幾復見用，死則已矣。」親戚皆難之。有閒，贊乃以刀自割其筋，血流滂沱，氣絕良乆。家人驚怖，亦以旣爾，遂引申其足。足申創愈，以得蹉步。

**釋讀** 留贊字正明，會稽長山人。少年任郡吏，與黃巾首領吳桓交戰，親手斬得吳桓，一腳負傷，自此彎曲不能伸直。他性情剛烈，愛讀兵書與三史，見到古代良將攻戰的形勢，總對書獨自歎息。他召近親說，天下動亂、豪傑並起，歷代富貴不專屬固定的一些人，自己跛瘸困在里巷，活著與死了相差無幾。他想割筋把腳拉直，幸而未死、腳能伸開，或有再被任用的機會，死就罷了。親戚都認為難以做到。過一會兒，他用刀自行割筋，血大量流出，昏厥許久。家人嚇壞，見事情已經如此，便把腳拉直。腳伸直、傷癒後，他得以蹣跚行走。

**時段與依據** 《吳書》未記吳桓活動及留贊受傷、治足的年月；黃巾名號延續多年，不能只據名號繫於184年。

**[《三國志·諸葛滕二孫濮陽傳》裴注 016](../../拆分史书/三国志/卷064.md#edition-wu064-l83-2)** · [TXT L83](../../拆分史书/三国志/卷064.txt#L83)

**釋讀** 凌統聞事請求見他，認為他很不尋常，上表薦舉，留贊遂受試用。留贊多次立戰功，逐步升為屯騎校尉。每遇政事有得失，他常規勸，直言不順從上意，孫權因此對他有所忌憚。

## 華融早年與張溫、皇象交遊

<a id="period-sgz064-p-017-1"></a>

<a id="period-sgz064-p-017-2"></a>

<a id="wu064-l93-1"></a>

**[《三國志·諸葛滕二孫濮陽傳》裴注 017](../../拆分史书/三国志/卷064.md#edition-wu064-l93-1)** · [TXT L93](../../拆分史书/三国志/卷064.txt#L93)

> 文士傳曰：華融字德蕤，廣陵江都人。祖父避亂，居山陰蕋山下。時皇象亦寓居山陰，吳郡張溫來就象學，欲得所舍。或告溫曰：「蕋山下有華德蕤者，雖年少，美有令志，可舍也。」溫遂止融家，朝夕談講。俄而溫爲選部尚書，乃擢融爲太子庶子，遂知名顯達。

**釋讀** 華融祖父避亂遷至山陰蕋山。張溫到山陰向皇象求學，借住華融家，二人朝夕談講；張溫任選部尚書後，擢華融為太子庶子。

**時段與依據** 可參[張溫本傳](../../拆分史书/三国志/卷057.txt)，但借住、授職未見可互證的確年。

## 陳壽總評本卷五人

<a id="period-sgz064-b-3032-1"></a>

<a id="period-sgz064-b-3032-2"></a>

<a id="period-sgz064-b-3032-3"></a>

<a id="wu064-l130-1"></a>

**[《三國志·諸葛滕二孫濮陽傳》正文](../../拆分史书/三国志/卷064.md#edition-wu064-l130-1)** · [TXT L130](../../拆分史书/三国志/卷064.txt#L130)

> 評曰：諸葛恪才氣幹略，邦人所稱，然驕且吝，周公無觀，況在於恪？矜己陵人，能無敗乎！若躬行所與陸遜及弟融之書，則悔吝不至，何尤禍之有哉？滕胤厲脩士操，遵蹈規矩，而孫峻之時猶保其貴，必危之理也。峻、綝凶豎盈溢，固無足論者。濮陽興身居宰輔，慮不經國，協張布之邪，納萬彧之說，誅夷其宜矣。

**釋讀** 陳壽稱諸葛恪有才略而驕吝凌人，若能親行寫給陸遜及弟諸葛融信中所言，或可免禍。滕胤守規矩卻在孫峻掌權時保有富貴，正因而危。孫峻、孫綝兇暴；濮陽興為宰相不能經國，附張布、納萬彧之議，自招族誅。

**時段與依據** 卷末史評綜論不同年份的人事。涉及事件分見本卷引文，這段總評保留在原有文序和時期頁。

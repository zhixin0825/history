## 王蕃早年官歷、使蜀與掌夏口

<a id="period-sgz065-b-3035-1"></a>

<a id="wu065-l5-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l5-1)** · [TXT L5](../../sources/本地分卷/三国志/三国志-卷065.txt#L5)

> 王蕃字永元，廬江人也。愽覽多聞，兼通術藝。始爲尚書郎，去官。

**釋讀** 王蕃字永元，廬江人，博學多聞，也精通術數等技藝。初任尚書郎，後離職。

**時段與依據** 離職原因和初任年月都未記。《晉書·天文志》稱他通曉數術，承習劉洪《乾象曆》，製作渾儀。

<a id="period-sgz065-b-3035-3"></a>

<a id="wu065-l5-3"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l5-3)** · [TXT L5](../../sources/本地分卷/三国志/三国志-卷065.txt#L5)

> 遣使至蜀，蜀人稱焉，還爲夏口監軍。

**釋讀** 吳派王蕃出使蜀國，蜀人稱許他；回國後出任夏口監軍。

**時段與依據** 傳文排在孫休258年即位與孫皓264年即位之間。蜀263年亡，這次使蜀不晚於蜀亡，回任夏口尚無獨立紀年。

## 賀循以禮自持，出任陽羨及武康縣令

<a id="period-sgz065-p-004-3"></a>

<a id="wu065-l38-3"></a>

**[《三國志·王樓賀韋華傳》裴注 004](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l38-3)** · [TXT L38](../../sources/本地分卷/三国志/三国志-卷065.txt#L38)

> 節操高厲，童齔不羣，言行舉動必以禮讓。好學博聞，尤善三禮。舉秀才，除陽羨、武康令。

**釋讀** 賀循節操高峻，自幼舉止不同於人，言行必依禮讓。勤學博聞，尤通三禮。舉為秀才，先後任陽羨、武康縣令。

**時段與依據** 晉平吳後的才學與官履，[《晉書·賀循傳》](../../sources/二十四史/txt/05_jinshu_full.txt#L7058)敘州郡薦舉、兩縣任職的先後，未載確年。

<a id="period-sgz065-p-004-4"></a>

<a id="wu065-l38-4"></a>

**[《三國志·王樓賀韋華傳》裴注 004](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l38-4)** · [TXT L38](../../sources/本地分卷/三国志/三国志-卷065.txt#L38)

> 顧榮、陸機、陸雲表薦循曰：「伏見吳興武康令賀循德量邃茂，才鑒清遠，服膺道素，風操凝峻，歷踐三城，刑政肅穆，守職下縣，編名凡萃，出自新邦，朝無知己，恪居遐外，志不自營，年時倏忽，而邈無階緒，實州黨愚智所爲悵然。臣等並以凡才，累授飾進，被服恩澤，忝豫朝末，知良士後時，而守局無言，懼有蔽賢之咎，是以不勝愚管，謹冒死表聞。」久之，召爲太子舍人。

**釋讀** 顧榮、陸機、陸雲上表，稱武康令賀循有德量、見識遠，奉行正道，品行高潔，曾治理三城，政教刑獄有條理。他在下縣守職，身列眾吏間，從新歸附之地入仕，朝中無人了解他。他身在遠方而不為自己奔競，歲月流逝、遷升無門，鄉里無論賢愚都為他惋惜。三人自陳蒙恩忝居朝列，知道賢者將被埋沒，恐有蔽賢之責，冒罪上奏。後來賀循被召為太子舍人。

**時段與依據** 此表在陸機、陸雲遇害前。[《晉書·賀循傳》](../../sources/二十四史/txt/05_jinshu_full.txt#L7058-L7059)引陸機薦表，並薦郭訥，稱賀循歷試二城，與《虞預晉書》署顧榮、二陸及「三城」有別，不能據此定確年。

## 孫和居東宮命韋曜作《博弈論》

<a id="period-sgz065-b-3054-2"></a>

<a id="wu065-l44-2"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l44-2)** · [TXT L44](../../sources/本地分卷/三国志/三国志-卷065.txt#L44)

> 時蔡頴亦在東宮，性好博弈，太子和以爲無益，命曜論之。其辭曰：

**釋讀** 同在東宮的蔡頴好博弈，太子孫和認為這有損正業，命韋曜作論勸戒。

**時段與依據** [《孫和傳》](../../sources/本地分卷/三国志/三国志-卷059.txt#L31-L34)補記孫和共命在座八人著論，將韋曜的論文傳給賓客，因署中值事者多效法蔡穎而藉此規勸。孫和242年為太子、250年被廢，作論無確年。

<a id="period-sgz065-b-3055-1"></a>

<a id="wu065-l46-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l46-1)** · [TXT L46](../../sources/本地分卷/三国志/三国志-卷065.txt#L46)

> 蓋聞君子恥當年而功不立，疾沒世而名不稱，故曰學如不及，猶恐失之。是以古之志士，悼年齒之流邁，而懼名稱之不立也。故勉精厲操，晨興夜寐，不遑寧息，經之以歲月，累之以日力，若寗越之勤，董生之篤，漸漬德義之淵，棲遲道藝之域。且以西伯之聖，姬公之才，猶有日昃待旦之勞，故能隆興周道，垂名億載，況在臣庶，而可以已乎？歷觀古今立功名之士，皆有累積殊異之迹，勞身苦體，契闊勤思，平居不墮其業，窮困不易其素，是以卜式立志於耕牧，而黃霸受道於囹圄，終有榮顯之福，以成不朽之名。故山甫勤於夙夜，而吳漢不離公門，豈有游墮哉？

**釋讀** 韋曜說君子以壯年不能立功、身後沒有令名為憾，所以學習唯恐趕不上，也怕有所失去。古代志士憂歲月消逝，早起晚睡，積累歲月工夫，像寗越勤勉、董生篤實，逐漸涵養德義、精通道藝。連周文王、周公都日昃忘食、待旦辦事，臣民更不能懈怠。有所成就者平時不荒業、窮困不改其操守。卜式在耕牧間立志，黃霸在獄中受學，終能顯名。仲山甫夙夜勤勞，吳漢守在公門，皆無遊惰。

**時段與依據** 全段屬太子孫和命作的論文，所引古人是勸學例證。

<a id="period-sgz065-b-3056-1"></a>

<a id="wu065-l48-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l48-1)** · [TXT L48](../../sources/本地分卷/三国志/三国志-卷065.txt#L48)

> 今世之人多不務經術，好翫博弈，廢事棄業，忘寢與食，窮日盡明，繼以脂燭。當其臨局交爭，雌雄未決，專精銳意，心勞體倦，人事曠而不脩，賔旅闕而不接，雖有太牢之饌，韶夏之樂，不暇存也。至或賭及衣物，徙棊易行，廉恥之意弛，而忿戾之色發，然其所志不出一枰之上，所務不過方罫之間，勝敵無封爵之賞，獲地無兼土之實，技非六藝，用非經國；立身者不階其術，徵選者不由其道。求之於戰陣，則非孫、吳之倫也；考之於道藝，則非孔氏之門也；以變詐爲務，則非忠信之事也；以劫殺爲名，則非仁者之意也；而空妨日廢業，終無補益。是何異設木而擊之，置石而投之哉！且君子之居室也勤身以致養，其在朝也竭命以納忠，臨事且猶旰食，而何博弈之足耽？夫然，故孝友之行立，貞純之名彰也。

**釋讀** 當時有人不務經術，日夜沉迷博弈，廢學忘食、疏於人事與賓客，至於賭衣、移換棋子和爭吵。勝敵未受爵，取地未得土，此技不在六藝，不能經國，也不能憑它立身或獲選。棋局的用兵不可與孫武、吳起相比，技藝不出孔門，變詐有違忠信，劫殺不合仁義，徒費光陰。君子居家勤於奉養、在朝盡忠，有事甚至晚食，應把時間用來成就孝友貞純。

**時段與依據** 太子孫和命作的同一篇論文。

<a id="period-sgz065-b-3057-1"></a>

<a id="wu065-l50-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l50-1)** · [TXT L50](../../sources/本地分卷/三国志/三国志-卷065.txt#L50)

> 方今大吳受命，海內未平，聖朝乾乾，務在得人，勇略之士則受熊虎之任，儒雅之徒則處龍鳳之署，百行兼苞，文武並騖，博選良才，旌簡髦俊，設程試之科，垂金爵之賞，誠千載之嘉會，百世之良遇也。當世之士，宜勉思至道，愛功惜力，以佐明時，使名書史籍，勳在盟府，乃君子之上務，當今之先急也。

**釋讀** 韋曜說東吳立國，天下尚未統一，朝廷急需人才，勇略之士任武職，儒雅之士居文署，考選俊才並以爵位相獎。士人應惜力用功，輔佐當世，名入國史、勳錄盟府。

**時段與依據** 太子孫和命作的同一篇論文。

<a id="period-sgz065-b-3058-1"></a>

<a id="wu065-l52-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l52-1)** · [TXT L52](../../sources/本地分卷/三国志/三国志-卷065.txt#L52)

> 夫一木之枰孰與方國之封？枯棊三百孰與萬人之將？衮龍之服，金石之樂，足以兼棊局而貿博弈矣。假令世士移博弈之力而用之於詩書，是有顏、閔之志也；用之於智計，是有良、平之思也；用之於資貨，是有猗頓之富也；用之於射御，是有將帥之備也。如此，則功名立而鄙賤遠矣。

**釋讀** 一方棋盤比不了受封一國，三百枚棋子比不了統領萬人。章服與金石之樂所代表的功名，勝過棋局。若將弈棋的心力用於詩書，就能有顏回、閔子騫的志行；用於智謀，可有張良、陳平的思慮；用於經營資財，可得猗頓的富足；用於騎射駕御，可具備為將的才幹。如此才能成名立業。

**時段與依據** 太子孫和命作的同一篇論文末段。

## 華覈辭東觀令，孫皓命其留任

<a id="period-sgz065-b-3076-2"></a>

<a id="wu065-l82-2"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l82-2)** · [TXT L82](../../sources/本地分卷/三国志/三国志-卷065.txt#L82)

> 後遷東觀令，領右國史，覈上疏辭讓，皓荅曰：「得表，以東觀儒林之府，當講校文藝，處定疑難，漢時皆名學碩儒乃任其職，乞更選英賢。聞之，以卿研精墳典，博覽多聞，可謂恱禮樂敦詩書者也。當飛翰騁藻，光贊時事，以越楊、班、張、蔡之疇，怪乃謙光，厚自菲薄，宜勉脩所職，以邁先賢，勿復紛紛。」

**釋讀** 華覈後任東觀令，領右國史，以東觀主校文藝、論疑難，請擇碩儒代任。孫皓回覆說他博覽經典，足以接續揚雄、班固、張衡、蔡邕，勉他繼續任職。

**時段與依據** 本傳排在267年諫營宮之後。[《孫皓傳》](../../sources/本地分卷/三国志/三国志-卷048.txt#L106)和[《通鑑》卷079](../../sources/资治通鉴/KR2b0007_079.txt#L456-L470)於271年孫皓出華里時已稱華覈為東觀令，授職、辭讓未載確年。

## 華覈請省徭務農、禁奢積儲

<a id="period-sgz065-b-3077-1"></a>

<a id="period-sgz065-b-3078-1"></a>

<a id="wu065-l84-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l84-1)** · [TXT L84](../../sources/本地分卷/三国志/三国志-卷065.txt#L84)

> 時倉廩無儲，世務滋侈，覈上疏曰：「今寇虜充斥，征伐未已，居無積年之儲，出無應敵之畜，此乃有國者所宜深憂也。夫財穀所生，皆出於民，趨時務農，國之上急。而都下諸官，所掌別異，各自下調，不計民力，輒與近期。長吏畏罪。晝夜催民，委舍佃事，遑赴會日，定送到都，或蘊積不用，而徒使百姓消力失時。到秋收月，督其限入，奪其播殖之時，而責其今年之稅，如有逋懸，則籍沒財物，故家戶貧困，衣食不足。宜暫息衆役，專心農桑，古人稱一夫不耕，或受其饑，一女不織，或受其寒，是以先王治國，惟農是務。軍興以來，已向百載，農人廢南畝之務，女工停機杼之業。推此揆之，則蔬食而長饑，薄衣而履冰者，固不少矣。

**釋讀** 華覈說戰事未止，府庫缺糧。京城各官署分別徵役，限期急迫，令百姓誤農；物資運到京城又可能積而不用。秋收仍催稅，欠稅即沒收財物。他請暫減諸役，使人民得以耕織。

**時段與依據** 本疏在任東觀令記事之後，免官以前，確切作年未載。

<a id="period-sgz065-b-3078-2"></a>

<a id="wu065-l84-2"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l84-2)** · [TXT L84](../../sources/本地分卷/三国志/三国志-卷065.txt#L84)

> 臣聞主之所求於民者二，民之所望於主者三。二謂求其爲己勞也，求其爲己死也。三謂饑者能食之，勞者能息之，有功者能賞之。民以致其二事而主失其三望者，則怨心生而功不建。今帑藏不實，民勞役猥，主之二求已備，民之三望未報。且饑者不待美饌而後飽，寒者不俟狐狢而後溫，爲味者口之奇，文繡者身之飾也。

**釋讀** 君主向人民要求勞動和效死，人民盼君主能給飢者糧食、讓勞者休息、給有功者獎賞。徭役已多而布施賞賜不足，民怨由此而生。食能充飢、衣能禦寒便夠，珍味錦繡只添裝飾。

**時段與依據** 同一勸省徭節用的奏疏。

<a id="period-sgz065-b-3078-3"></a>

<a id="wu065-l84-3"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l84-3)** · [TXT L84](../../sources/本地分卷/三国志/三国志-卷065.txt#L84)

> 今事多而役繁，民貧而俗奢，百工作無用之器，婦人爲綺靡之飾，不勤麻枲，並繡文黼黻，轉相倣效，恥獨無有。兵民之家，猶復逐俗，內無儋石之儲，而出有綾綺之服，至於富賈商販之家，重以金銀，奢恣尤甚。天下未平，百姓不贍，宜一生民之原，豐穀帛之業，而棄功於浮華之巧，妨日於侈靡之事，上無尊卑等級之差，下有耗財費力之損。

**釋讀** 庶民貧困卻競相奢侈，工匠造無用器物，紡織多作貴飾。連沒有存糧的人家也穿綾綺，富商加用金銀，既失尊卑之別，又耗用財力，妨礙糧與布帛的生產。

**時段與依據** 同疏以各家競奢說明失去生產時間。

<a id="period-sgz065-b-3078-4"></a>

<a id="wu065-l84-4"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l84-4)** · [TXT L84](../../sources/本地分卷/三国志/三国志-卷065.txt#L84)

> 今吏士之家，少無子女，多者三四，少者一二，通令戶有一女，十萬家則十萬人，人織績一歲一束，則十萬束矣。使四疆之內同心戮力，數年之間，布帛必積。恣民五色，惟所服用，但禁綺繡無益之飾。且美貌者不待華采以崇好，豔姿者不待文綺以致愛，五采之飾，足以麗矣。若極粉黛，窮盛服，未必無醜婦；廢華采，去文繡，未必無美人也，若實如論，有之無益廢之無損者，何愛而不暫禁以充府藏之急乎？此救乏之上務，富國之本業也，使筦、晏復生，無以易此。

**釋讀** 華覈以十萬戶每戶一女、每人年織一束為例，推算幾年即可累積布帛。五色衣服可照常穿用，應暫禁費工的綺繡。他說華服不會使人由醜變美，故裁減裝飾而省財，才是當務之急。

**時段與依據** 人數與織績均為推算，說明疏中的節用主張。

<a id="period-sgz065-b-3078-5"></a>

<a id="wu065-l84-5"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l84-5)** · [TXT L84](../../sources/本地分卷/三国志/三国志-卷065.txt#L84)

> 漢之文、景，承平繼統，天下已定，四方無虞，猶以彫文之妨農事，錦繡之害女紅，開富國之利，杜饑寒之本。況今六合分乖，犲狼充路，兵不離疆，甲不解帶，而可以不廣生財之原，充府藏之積哉？」

**釋讀** 漢文、景帝時天下已定，尚以雕飾妨礙農務、錦繡妨礙紡織為戒。如今吳外敵未退，士兵未解甲，更當廣開生財之路，充實府庫。

**時段與依據** 同一奏疏末段；漢文、景之治是援引的先例。

## 華覈奉命草文

<a id="period-sgz065-b-3079-1"></a>

<a id="period-sgz065-b-3080-1"></a>

<a id="wu065-l86-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l86-1)** · [TXT L86](../../sources/本地分卷/三国志/三国志-卷065.txt#L86)

> 皓以覈年老，勑令草表，覈不敢。又勑作草文，停立待之。覈爲文曰：「咨覈小臣，草芥凡庸。遭眷值聖，受恩特隆。越從朽壤，蟬蛻朝中。熈光紫闥，青璅是憑。毖挹清露，沐浴凱風。效無絲氂，負闕山崇。滋潤含垢，恩貸累重。穢質被榮，局命得融。欲報罔極，委之皇穹。聖恩雨注，哀棄其尤。猥命草對，潤被下愚。不敢違勑，懼速罪誅。冐承詔命，魂逝形留。」

**釋讀** 孫皓因華覈年老，命他草表。華覈起初不敢，孫皓再命他立時作辭。辭中以凡庸小臣自況，感謝知遇與寬恕，又說自己報恩無力、擔心違命招罪，勉強奉詔作答。

**時段與依據** 本傳只記當時華覈已年老，寫作年月未載。

## 薛瑩、胡冲與陳壽評本卷五人

<a id="period-sgz065-b-3082-1"></a>

<a id="period-sgz065-b-3082-2"></a>

<a id="period-sgz065-b-3082-3"></a>

<a id="wu065-l90-1"></a>

**[《三國志·王樓賀韋華傳》正文](../../sources/本地分卷/三国志/三国志-卷065.md#edition-wu065-l90-1)** · [TXT L90](../../sources/本地分卷/三国志/三国志-卷065.txt#L90)

> 評曰：薛瑩稱王蕃器量綽異，弘博多通；樓玄清白節操，才理條暢；賀邵厲志高潔，機理清要；韋曜篤學好古，博見羣籍，有記述之才。胡冲以爲玄、邵、蕃一時清妙，略無優劣。必不得已，玄宜在先，邵當次之。華覈文賦之才，有過於曜，而典誥不及也。予觀覈數獻良規，期於自盡，庶幾忠臣矣。然此數子，處無妄之世而有名位，強死其理，得免爲幸耳。

**釋讀** 薛瑩稱王蕃博通，樓玄清白、條理明晰，賀邵志節高潔、議論精要，韋曜博古、富於著述。胡冲認為樓、賀、王三人難分高下，如必須排次則樓先賀次，並比較華覈才長於文賦、韋曜長於典誥。陳壽許華覈屢獻良規、竭忠盡職，感慨諸人在險惡時世有名有位，多不得善終。

**時段與依據** 卷末綜合評論，按本卷文序閱讀。

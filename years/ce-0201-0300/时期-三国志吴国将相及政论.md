# 吴国将相、士人及政论

[本世纪目录](README.md) · [全部世纪](../README.md) · [《三国志》分卷目录](../../sources/三国志读本目录.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **张昭辅孙氏及子侄。** 张昭通经能书，与孙策共建政务，孙策托孙权于昭。孙权称帝后进封，张昭仍敢于直谏，多次与孙权意见相左。张承、张休、张奋等另见本段。 [[1]](#note-1)

<a id="event-2"></a>

2. **顾雍处政与顾氏后人。** 顾雍由县长、会稽郡丞升丞相，择才处事，少言持重。顾劭礼士，顾谭、顾承入朝，家族后来卷入南鲁争储。 [[2]](#note-2)

<a id="event-3"></a>

3. **诸葛瑾维系吴蜀与荆州事务。** 诸葛瑾避乱来吴，以宽厚周旋见信，出使蜀而与兄弟诸葛亮严格分公私。其后领南郡等军政，传文兼及诸子仕吴、仕蜀。 [[3]](#note-3)

<a id="event-4"></a>

4. **步骘及周昭论士。** 步骘自避乱贫居转入孙权幕府，经营交州，后镇守西陵而入相。后附周昭论人物及入狱，陈寿分叙张昭、顾雍、诸葛瑾、步骘所长。 [[4]](#note-4)

<a id="event-5"></a>

5. **张纮献计、出使及议治秣陵。** 张纮在孙策时参与谋划、同汉廷联系，归附孙权后建议以秣陵为都治之一。传中列出他对主将不宜亲立战阵的劝说。 [[5]](#note-5)

<a id="event-6"></a>

6. **严畯、程秉、阚泽。** 严畯以经学和笃厚知名，坚辞接领兵官；程秉承郑玄之学，为孙登师傅；阚泽靠抄书研读，兼究历数，后来入朝掌经学及政务。 [[6]](#note-6)

<a id="event-7"></a>

7. **薛综、薛莹及父子文书。** 薛综曾在交州任职，对刺史、郡守的选用和南方治理上疏。其子薛莹随孙皓用事，参与吴史相关著述，吴亡后续仕晋。末附陈寿论诸士。 [[7]](#note-7)

<a id="event-8"></a>

8. **周瑜从孙策、辅孙权并主张拒曹。** 周瑜与孙策早有交谊，随军袭皖，孙策死后留吴共掌众务。曹操下荆州时群议有迎降者，周瑜据北军环境与补给等判断主战。 [[8]](#note-8)

<a id="event-9"></a>

9. **赤壁、江陵及周瑜后事。** 孙刘合兵遇曹军于赤壁，黄盖用火攻。周瑜再与曹仁争南郡，受创仍巡营督战。后筹议西取益州，途中病逝；周氏后人承爵及获谏求免见下。 [[9]](#note-9)

<a id="event-10"></a>

10. **鲁肃联刘备、稳定荆州边界。** 鲁肃以济贫结士为务，与周瑜相友，在孙权前议江东大计。刘表死后赴长阪与刘备相会，主张共同抗曹，又劝借地；后来在益阳与关羽会谈。 [[10]](#note-10)

<a id="event-11"></a>

11. **吕蒙成军、破黄祖及争三郡。** 吕蒙早随邓当，后获任领军，在征黄祖等战立功。吴蜀争长沙、桂阳和零陵时，吕蒙以言辞使郝普出降，后又参与合肥、濡须等战。 [[11]](#note-11)

<a id="event-12"></a>

12. **袭江陵、擒关羽与史评。** 鲁肃死后吕蒙镇陆口，称病离防以使关羽撤兵；吴军西上接收公安和南郡，抚恤军民。吕蒙病卒，孙权兼评周瑜、鲁肃、吕蒙治事，陈寿论其识断。 [[12]](#note-12)

<a id="event-13"></a>

13. **程普仕孙氏三代。** 程普随孙坚讨黄巾和董卓，后随孙策定江东。孙权时与周瑜拒曹并参与南郡争夺，以老将参与军政。 [[13]](#note-13)

<a id="event-14"></a>

14. **黄盖立法与赤壁献策。** 黄盖从征经历孙坚、孙策和孙权，治理山越地区敢用严法。赤壁请用火攻，其后平定武陵等地，并因守土功封赏。 [[14]](#note-14)

<a id="event-15"></a>

15. **韩当及子韩综。** 韩当随孙坚出入战阵，后随孙策、孙权历战，曾任都督，督水军征蜀。子韩综后来转投魏。 [[15]](#note-15)

<a id="event-16"></a>

16. **蒋钦与周泰。** 蒋钦历守诸县，从孙策过江并随孙权出战。周泰曾在宣城救护孙权，后镇濡须，孙权用其累战创伤向诸将表明信任。 [[16]](#note-16)

<a id="event-17"></a>

17. **陈武及陈脩、陈表。** 陈武从孙策过江，专领庐江精兵，合肥之战死。其子陈脩长于安抚新兵；陈表虽是支庶，仍在吴东宫任职，护友而见重。 [[17]](#note-17)

<a id="event-18"></a>

18. **董袭攻江夏与守濡须。** 董袭自会稽从孙策，以勇力闻。孙权承事后参与破黄祖水军，后来守濡须，遇风船覆身亡。 [[18]](#note-18)

<a id="event-19"></a>

19. **甘宁归吴、攻战与计议。** 甘宁从州郡与游侠活动转入刘表、黄祖军，后归孙权献取荆州之策。战场勇猛，既获孙权信用，也与同僚发生冲突。 [[19]](#note-19)

<a id="event-20"></a>

20. **凌统守义、合肥护主。** 凌统承父凌操军功，早年与甘宁有隙，随军攻守多次。合肥撤兵遭张辽追击时护孙权脱险，后以抚士获得称誉。 [[20]](#note-20)

<a id="event-21"></a>

21. **徐盛拒魏及江岸防务。** 徐盛守柴桑抵御黄祖方面，后任诸军将领。曹丕临江时曾以沿江设防造成防线浩大的声势，传文另记与同僚关系。 [[21]](#note-21)

<a id="event-22"></a>

22. **潘璋军功与治军争议。** 潘璋以募兵起家，参与合肥等战，部将马忠获关羽，后随陆逊拒刘备。陈寿同时写其骄纵、敛财及孙权仍以功待之。 [[22]](#note-22)

<a id="event-23"></a>

23. **丁奉救东兴、参与诛孙綝及末年。** 丁奉以勇战受任，东兴之战先登，孙休时助诛孙綝，孙皓时位至右大司马。传末合评吴诸武将。 [[23]](#note-23)

<a id="event-24"></a>

24. **朱治从孙坚并助定吴郡。** 朱治起自县吏，随孙坚征伐，孙策时进入吴郡并长期治理。孙氏三世对其有礼遇，子弟的官爵承继附后。 [[24]](#note-24)

<a id="event-25"></a>

25. **朱然、施绩守江陵。** 朱然本姓施，受朱治收养。以兵守江陵抵曹真等久攻，后屡攻魏；其子施绩守西境，并与诸葛融等协调防务。 [[25]](#note-25)

<a id="event-26"></a>

26. **吕范、吕据。** 吕范自袁术境内归孙策，参加江东军政。孙权时督军，东兴以前年事见传；其子吕据于孙峻死后反抗孙綝，失败身亡。 [[26]](#note-26)

<a id="event-27"></a>

27. **朱桓、朱异的濡须与淮南用兵。** 朱桓赈疫收众，抵御曹仁，在石亭之战又献策。朱异继领其部，多次攻魏，救寿春不利后被孙綝杀。卷末总叙四位主传及后人。 [[27]](#note-27)

<a id="event-28"></a>

28. **虞翻从王朗到流放交州。** 虞翻在王朗时劝其避孙策，后来转事孙氏，处理军务、外交及札疏。性格直率，常因直言与孙权及同僚冲突，终谪交州。 [[28]](#note-28)

<a id="event-29"></a>

29. **陆绩及在郁林著述。** 陆绩幼年怀橘奉母，后任郁林太守，兼习天文历算和易学，去世较早。 [[29]](#note-29)

<a id="event-30"></a>

30. **张温聘蜀与暨艳案。** 张温受孙权重用，奉命使蜀，并受对方礼遇。后因暨艳选官案被追责而罢，骆统抗表为他申辩。 [[30]](#note-30)

<a id="event-31"></a>

31. **骆统体察役民。** 骆统由县邑入朝，关注赋役和流民，议如何爱护劳力、宽缓征求。另载其出征以及为张温求免。 [[31]](#note-31)

<a id="event-32"></a>

32. **陆瑁礼士、谏征公孙渊。** 陆瑁贫中好士，在朝时谏孙权不要因辽东公孙渊背盟而亲自远征。奏文从地理、守备与远近缓急说明取舍。 [[32]](#note-32)

<a id="event-33"></a>

33. **吾粲维护太子名分。** 吾粲由小吏进入孙氏幕府，参与抗击魏军，主张太子孙和、鲁王孙霸分居守礼，因争储牵连遇害。 [[33]](#note-33)

<a id="event-34"></a>

34. **朱据仕吴与卷末史评。** 朱据反对暨艳尽行黜退有瑕疵的官吏，后因谏废孙和而受责，终奉伪传诏令自尽。陈寿兼论本卷儒士的才性与坎坷。 [[34]](#note-34)

<a id="event-35"></a>

35. **陆逊治理吴郡，参与袭荆州和秭归之战。** 陆逊起自江东陆氏，招抚山越、整编兵众，建议孙权选任良吏。吕蒙谋取荆州时以陆逊接防麻痹关羽，战后陆逊领宜都。 [[35]](#note-35)

<a id="event-36"></a>

36. **陆逊破刘备、守西陵。** 刘备东征，孙权任陆逊为大都督。陆逊暂拒诸将求战，待蜀军疲惫时出击，取胜后仍主张慎待魏军，继而参与吴蜀通好。 [[36]](#note-36)

<a id="event-37"></a>

37. **石亭、襄阳及对军政的劝议。** 陆逊督兵破曹休，辅太子守武昌。又率军北向，判断襄阳援兵及淮南利害，制约诸将求功；对吴政严刑及征役也屡上疏。 [[37]](#note-37)

<a id="event-38"></a>

38. **陆逊入相、谏争储位及去世。** 陆逊继顾雍任丞相。孙和、孙霸势均而争，他反对使二宫势敌，主张维护太子名分，并因受责忧死。 [[38]](#note-38)

<a id="event-39"></a>

39. **陆抗继父将兵、分守西方。** 陆抗为孙策外孙，父死后面对中使追问逐条解释，孙权终于承认前失。此后任地方督守，谏孙皓任贤自强。 [[39]](#note-39)

<a id="event-40"></a>

40. **平西陵步阐及为薛莹求免。** 步阐据西陵降晋，陆抗筑垒内围外拒，分别抵御羊祜、徐胤、杨肇的应援。战后陆抗上疏救下狱的薛莹，并论应保存人才。 [[40]](#note-40)

<a id="event-41"></a>

41. **陆抗边防遗奏及陆氏后人。** 陆抗谏不要在国力疲敝时累兴兵事，答以充实农储、整肃用人。病中指出晋可顺江下兵，须保障西陵和建平，后晋军进兵果如其虑。 [[41]](#note-41)

<a id="event-42"></a>

42. **太子孙登及东宫僚友。** 孙登辞魏封侯，成为吴太子，聚诸葛恪、张休等为宾友。留守武昌时宽礼将吏，与孙权论荐贤，临终再举可任用者。 [[42]](#note-42)

<a id="event-43"></a>

43. **建昌侯孙虑。** 孙虑受孙权喜爱，群臣希望进封为王。孙权未遽从，授军职；孙虑后早死。 [[43]](#note-43)

<a id="event-44"></a>

44. **孙和由太子被废及赐死。** 孙和好学下士，在成为太子后受到孙权和辅臣关照。全公主与鲁王党争激化，他被废为南阳王，孙权死后孙峻逼其自尽。 [[44]](#note-44)

<a id="event-45"></a>

45. **鲁王孙霸与争嫡。** 孙霸受宠不亚于太子孙和，二宫近臣彼此交结不睦。羊衜上疏劝持名分，孙权最终赐孙霸死，并处置其党。 [[45]](#note-45)

<a id="event-46"></a>

46. **孙奋失爵及身死。** 孙奋以亲王居武昌，孙权死后被迁豫章。他不服调遣，因逾越法度而失爵，后来虽复封，终因谣言被孙皓处死。 [[46]](#note-46)

<a id="event-47"></a>

47. **贺齐平山越与东南郡县经营。** 贺齐以县吏起家，多次对地方武装用兵，分置郡县，收编守军。继而参加濡须、合肥等战，晚年继续治当地兵事。 [[47]](#note-47)

<a id="event-48"></a>

48. **全琮平地方、出战淮南及子侄。** 全琮早通事理，奉孙权命在江东治军政；从破刘备，出战淮南。因尚全公主而受亲任，全氏子侄后与储位冲突相涉。 [[48]](#note-48)

<a id="event-49"></a>

49. **吕岱平交州、广陵和荆州防务。** 吕岱归孙权后主管县治，后督州郡军，平交阯士徽事变并对越地用兵。位极大司马，仍以清俭为人所称。 [[49]](#note-49)

<a id="event-50"></a>

50. **周鲂平彭绮与诈降诱曹休。** 周鲂治钱唐及丹杨，以平彭绮见任。在石亭之战前，设计以书诈降并割发取信，诱魏军入，战后仍受重用。 [[50]](#note-50)

<a id="event-51"></a>

51. **钟离牧治县守边及史评。** 钟离牧从躬耕让稻的小事获得乡里名誉，后招抚地方并稳守边地。卷末评论各人对吴国安内的作用。 [[51]](#note-51)

<a id="event-52"></a>

52. **潘濬治荆州、击五溪。** 潘濬先后事刘表、刘备，孙权取荆州后任其为辅。整治贪吏，主持对五溪战事，与吕壹用事亦有冲突。 [[52]](#note-52)

<a id="event-53"></a>

53. **陆凯治州攻守与屡谏孙皓。** 陆凯早在县邑留下治迹，后历任州郡、将领与丞相。对孙皓迁都、施政、任人和财政等屡劝，传中保留大量主要奏疏。 [[53]](#note-53)

<a id="event-54"></a>

54. **陆胤平交州与卷末评语。** 陆胤早因太子孙和受知，被卷入东宫党争，后坐镇南方，重在招降抚绥。陈寿称潘濬、陆凯有节概，陆胤善治南土。 [[54]](#note-54)

<a id="event-55"></a>

55. **是仪清素奉职。** 是仪避乱后入孙权幕府，掌机密，兼为宗室提供规谏。曾顶住压力拒绝妄证，日常俭约，陈寿特书其清恪。 [[55]](#note-55)

<a id="event-56"></a>

56. **胡综典诰、徐详通使与史评。** 胡综与徐详从孙权经营军政，胡综编辖军队，又起草外交与盟誓文书。徐详数奉使传命，卷末分叙两人和是仪的职掌。 [[56]](#note-56)

<a id="event-57"></a>

57. **吴范的风气占候及魏滕。** 吴范以历数、风气占候受孙权任用，传中将预言和战事、称帝等关联。亦载以州郡守法和性情见称的魏滕。 [[57]](#note-57)

<a id="event-58"></a>

58. **刘惇、赵达及史评。** 刘惇以星占闻名，避乱南来。赵达以算术推衍见称，史书并载术士身世与术秘不传。陈寿肯定其精，亦论技术与经世的轻重。 [[58]](#note-58)

<a id="event-59"></a>

59. **诸葛恪入东宫、平丹杨及受遗。** 诸葛恪少善应对，与顾谭等伴太子读书；后督丹杨，围截山中粮道使山民出降，升任军事官。孙权末年委之辅政。 [[59]](#note-59)

<a id="event-60"></a>

60. **东兴获胜后再围新城、诸葛恪被诛。** 诸葛恪增筑东兴，击破魏军后欲乘胜北伐，不听诸臣劝阻。围新城遭疫大损，入朝后被孙峻杀害，末载臧均上表请收葬。 [[60]](#note-60)

<a id="event-61"></a>

61. **聂友与滕胤。** 聂友以才学入幕，谏恪不要轻举再攻。滕胤受孙权遗命辅少主，孙綝接权之后与吕据互相联结，终遭杀害。 [[61]](#note-61)

<a id="event-62"></a>

62. **孙峻掌政与留赞战死。** 孙峻以宿卫辅政，杀诸葛恪后执政。吴攻寿春接纳文钦，留赞在退军中遭追击战死。孙峻计划再伐魏，旋病死。 [[62]](#note-62)

<a id="event-63"></a>

63. **孙綝废孙亮、拥孙休及被诛。** 孙綝承孙峻权势，反驳吕据等人请求，进兵诛滕胤等；救寿春失败后擅杀朱异，废孙亮，拥立孙休。孙休后来以腊会设计收捕。 [[63]](#note-63)

<a id="event-64"></a>

64. **濮阳兴辅孙休、改立孙皓及史评。** 濮阳兴早为使者、太守，在孙休时以旧交参与政事。吴廷在孙休死后改立孙皓，他反受杀害，陈寿并评本卷辅政群臣。 [[64]](#note-64)

<a id="event-65"></a>

65. **王蕃博学与宴中遇害。** 王蕃兼通术艺，孙休时任散骑常侍。孙皓时因宴饮、进退等得咎被杀，卷内保留其才华与政局背景。 [[65]](#note-65)

<a id="event-66"></a>

66. **楼玄用事、华覈营救与死。** 楼玄因清直任官，掌宫中事务后被谗，华覈上疏辩护。孙皓仍将其流徙并密令加害，楼玄见敕书后自尽。 [[66]](#note-66)

<a id="event-67"></a>

67. **贺邵直谏及遇害。** 贺邵曾任吴郡太守、左典军、中书令等，陈政得失，直陈君臣关系与政事疲弊。后因谗毁与中风不能言被拷杀。 [[67]](#note-67)

<a id="event-68"></a>

68. **韦曜论博弈、修吴史与狱中著述。** 韦曜少好学，按太子孙和命作博弈论；后与华覈、薛莹修吴史。孙皓时反对为未称帝的孙和作帝纪，并屡因直答见责；狱中陈述著述缘起，华覈力救而不免。 [[68]](#note-68)

<a id="event-69"></a>

69. **华覈忧蜀亡、谏营宫。** 蜀亡后华覈上表忧吴失去外援。孙皓大兴宫室，他从民力、农储、军用等角度进谏，原文保留了长篇奏议。 [[69]](#note-69)

<a id="event-70"></a>

70. **华覈任东观及卷末人物评。** 华覈辞东观清职，孙皓仍命其校书论学。他再陈仓廪、征用和农桑得失。陈寿引用薛莹、胡冲对同卷诸人的评价，以华覈谏议作结。 [[70]](#note-70)

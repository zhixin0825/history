# 孙氏创业、吴国后宫及宗室

[本世纪目录](README.md) · [全部世纪](../README.md) · [《三国志》分卷目录](../../sources/三国志读本目录.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **孙坚出身及早年任事。** 孙坚字文台，吴郡富春人。早年任县吏，因击退海贼受地方征用，继而参与讨平会稽许昌。 [[1]](#note-1)

<a id="event-2"></a>

2. **孙坚攻刘表及身死。** 袁术命孙坚征刘表。孙坚击破黄祖，围襄阳后在岘山被射死。初平年次有异，旧军由孙贲率领归袁术。 [[2]](#note-2)

<a id="event-3"></a>

3. **孙策经营江东。** 安顿家属，结交周瑜，从袁术收回父亲旧部，渡江与刘繇交战。继取会稽、再平严白虎，分置长吏。 [[3]](#note-3)

<a id="event-4"></a>

4. **决裂袁术、袭庐江及孙策遇刺。** 孙策与称帝的袁术绝交，后袭取刘勋在庐江的据点。欲乘官渡相持北上时遭许贡门客袭击，临终托孙权；评语并论父子用兵与身死。 [[4]](#note-4)

<a id="event-5"></a>

5. **孙权早年、承继及征黄祖。** 孙权曾任阳羡长，随后随兄征庐江。孙策死后张昭等促其掌军，与周瑜、鲁肃等共事。多次征黄祖，同时应付内部郡县动乱。 [[5]](#note-5)

<a id="event-6"></a>

6. **濡须、皖城、荆州及曹魏代汉。** 曹操进攻濡须，孙权坚守；随后取皖城，与刘备围绕荆州诸郡争执。关羽在襄樊用兵时，吴军夺公安和江陵，终于擒关羽；次年曹丕代汉。 [[6]](#note-6)

<a id="event-7"></a>

7. **吴王、夷陵之战及重修蜀好。** 孙权迁鄂改名武昌，受魏册封。刘备东下，陆逊督军在夷陵击败蜀军。随后魏军三道来攻，吴将分别抗击；吴遣郑泉向白帝复通。 [[7]](#note-7)

<a id="event-8"></a>

8. **黄武后期朝政及石亭之胜。** 遣张温使蜀，应付魏军临江，调整宰相人选。孙权与陆逊讨论农事、刑法；周鲂诈降诱曹休，陆逊等在石亭破敌。 [[8]](#note-8)

<a id="event-9"></a>

9. **黄龙称帝、吴蜀盟约及迁建业。** 孙权在武昌即帝位，追尊父母兄长，立孙登为太子。蜀使陈震来贺，两国约定各自希望收复的地域。孙权迁建业，以陆逊辅孙登留守武昌，后遣卫温、诸葛直航海。 [[9]](#note-9)

<a id="event-10"></a>

10. **嘉禾年间的辽东、合肥和郡县治理。** 周贺自辽东归途被田豫截击，公孙渊先向吴称臣再杀其使。孙权围合肥新城未成，诏宽减逋欠并铸大钱，亦与臣下讨论在任官员闻丧能否离职。 [[10]](#note-10)

<a id="event-11"></a>

11. **赤乌初年，吕壹案及赈恤。** 铸当千大钱、议改年号。吕壹伏诛后，孙权引咎，诏询诸将。辽东用兵与岭南廖式作乱亦见本段，后来下令禁在农时违规役民并开仓济饥。 [[11]](#note-11)

<a id="event-12"></a>

12. **孙权晚年废和立亮及去世。** 太初宫重建，多名吴将相继去世。孙权废太子和、赐鲁王霸死，改立孙亮；立潘氏为后。神凤元年孙权去世，葬蒋陵，史评兼述其任才与晚岁猜忌。 [[12]](#note-12)

<a id="event-13"></a>

13. **孙亮即位、东兴之胜与孙峻杀诸葛恪。** 孙权病重安排诸葛恪、滕胤辅政，死后孙亮继立。诸葛恪救东兴击退魏军，次年围合肥新城遇疫而返，孙峻随后在朝会伏杀诸葛恪。 [[13]](#note-13)

<a id="event-14"></a>

14. **孙休即位与孙綝被诛。** 孙休从琅邪王被迎立，初授孙綝及其族高位安抚，后在腊会设谋诛孙綝，并下诏兴学、设五经博士。 [[14]](#note-14)

<a id="event-15"></a>

15. **交阯之变、吴军援蜀及孙休末年。** 交阯郡吏杀孙諝。魏攻蜀时吴分军策应，蜀亡后吴军争夺巴东，罗宪得援解围。孙休病重以幼子托付濮阳兴，死后皇位转入孙皓一支。 [[15]](#note-15)

<a id="event-16"></a>

16. **晋军伐吴、孙皓归降及评语。** 晋从各路进兵，陶濬所集兵士逃散。孙皓遣书乞降，王濬先到而受降；孙皓西迁洛阳，封归命侯。陈寿合评孙亮、孙休和孙皓。 [[16]](#note-16)

<a id="event-17"></a>

17. **刘繇任扬州刺史。** 刘繇早年能救被劫亲属、纠举贪吏，与兄刘岱并有声名。汉末出任扬州刺史，从寿春一带退至江南治曲阿，与袁术、孙策相争。 [[17]](#note-17)

<a id="event-18"></a>

18. **笮融及刘繇后事。** 笮融截取三郡漕运，兴建浮图祠，后因曹操攻徐州而南走，先后夺人财众。刘繇去世后孙策收其丧，子刘基在孙权幕府以孝行及直谏受知。 [[18]](#note-18)

<a id="event-19"></a>

19. **太史慈救孔融、归孙策及镇海昏。** 太史慈奉母意赴都昌救孔融，突出围请刘备救援。后在神亭遇孙策，败后获释归附，召安刘繇旧众并镇抚海昏，虎将之名又见善射诸事。 [[19]](#note-19)

<a id="event-20"></a>

20. **士燮在交阯的家世与治理。** 士氏世居交州，士燮通《春秋》，兄弟分据列郡。袁徽称其招抚流亡、长期保境，地方礼节与势力在传中并叙。 [[20]](#note-20)

<a id="event-21"></a>

21. **步骘至交州与士徽之变。** 步骘至交州，士燮率兄弟接受其节制。士燮死后吴拟分交、广二州，士徽自任太守拒命，吕岱进兵处置。陈寿区分士燮前期治理与子孙失政。 [[21]](#note-21)

<a id="event-22"></a>

22. **吴夫人与吴景。** 吴夫人嫁孙坚，生四子一女，孙权即位前辅助军国，临终召张昭等托付后事。其弟吴景助孙策夺取江东，景之后裔及党争案亦附本段。 [[22]](#note-22)

<a id="event-23"></a>

23. **谢夫人、徐夫人与皇后之议。** 谢氏拒在徐氏之下，失宠早卒。徐氏曾抚养孙登，后遭废处。群臣请立徐氏与孙权属意步氏形成分歧。 [[23]](#note-23)

<a id="event-24"></a>

24. **步夫人受宠及追谥。** 步夫人生鲁班、鲁育二公主，宫中称后而长期未正式册立。赤乌元年卒后，孙权追赠皇后印绶，策文叙其内助。 [[24]](#note-24)

<a id="event-25"></a>

25. **琅邪、南阳二王夫人。** 孙和母与全公主有隙，忧死后因孙皓获追尊。南阳王夫人生孙休，先出居公安，孙休继位后改葬追尊。 [[25]](#note-25)

<a id="event-26"></a>

26. **潘皇后与孙亮全皇后。** 潘氏自织室入宫，生孙亮，后来受册与遇害。全氏由全公主赞成婚配而立后，全尚父女的荣辱随孙亮的政局变化。 [[26]](#note-26)

<a id="event-27"></a>

27. **朱、何、滕三后及史评。** 孙休妃朱氏与全公主争执，孙和姬何氏生孙皓，滕氏因孙皓登位成为皇后。篇末把吴后宫矛盾和嗣位斗争相联系。 [[27]](#note-27)

<a id="event-28"></a>

28. **孙静筹攻会稽、孙瑜掌丹杨。** 孙静建议孙策改由险道攻会稽王朗。孙瑜招集江西士卒，掌丹杨，曾与周瑜破屯和参与军务。 [[28]](#note-28)

<a id="event-29"></a>

29. **孙皎镇夏口与孙奐承军。** 孙皎代程普督夏口，和甘宁有隙，经孙权劝戒后修好，又在袭取江陵时从吕蒙。孙奐承其部众，为江夏太守，礼遇当地士人及儒生。 [[29]](#note-29)

<a id="event-30"></a>

30. **孙贲、孙辅随父兄创业。** 孙贲在孙坚死后接管旧部，先从袁术，后随孙策平江东任豫章太守。孙辅亦从战，以截断交通和招集流民受知，后来私通曹操而遭处置。 [[30]](#note-30)

<a id="event-31"></a>

31. **孙翊遇害与孙匡一系。** 孙翊掌丹杨，被部下边鸿所杀。孙匡年轻早卒，子孙泰在合肥作战中去世，后嗣孙秀在孙皓时求自保而奔晋。 [[31]](#note-31)

<a id="event-32"></a>

32. **孙河、孙韶守京城与孙桓抗刘备。** 孙河遭妫览等杀害，孙韶接收余众修筑京城，受孙权任用。孙桓随陆逊抵抗刘备，封丹徒侯。卷末说明诸孙在创业与守边中的作用。 [[32]](#note-32)

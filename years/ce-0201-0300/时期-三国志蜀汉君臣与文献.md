# 蜀地经营、蜀汉君臣与文献

[本世纪目录](README.md) · [全部世纪](../README.md) · [《三国志》分卷目录](../../sources/三国志读本目录.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **刘焉议置州牧及其在蜀得失。** 刘焉建议遣重臣为州牧，因董扶之说而求益州。贾龙平马相、赵祗后迎他入蜀。刘焉阻断汉廷交通，营造逾制车具，其子助马腾袭长安而死；刘焉迁治成都，旋病故。 [[1]](#note-1)

<a id="event-2"></a>

2. **刘璋继领益州与成都出降。** 刘璋与张鲁、赵韙相争。张松从曹操处折返后建议迎刘备，刘备后来转攻成都。成都兵粮尚足，刘璋为避免百姓伤亡出降；其后刘氏子弟分在吴、蜀。陈寿批评刘焉信谶、刘璋不足守土。 [[2]](#note-2)

<a id="event-3"></a>

3. **刘备世系、从学与起兵。** 刘备记为中山靖王之后，早年织席贩履，与公孙瓒同师卢植。黄巾起时从邹靖作战，历任安喜尉等县职，后依公孙瓒。 [[3]](#note-3)

<a id="event-4"></a>

4. **荆州撤退、赤壁与荆南四郡。** 曹操南下时刘琮请降，刘备经当阳败走，又到夏口联合孙权。曹军退后，刘备收服荆南四郡；殷观反对轻率答应孙权共取蜀地。 [[4]](#note-4)

<a id="event-5"></a>

5. **汉中王名号、魏延守汉中与关羽败亡。** 群臣上表并将刘备推为汉中王，于沔阳筑坛受冠。刘备另向献帝说明受号讨曹；其后任魏延镇汉中，关羽攻樊而遭孙权袭杀。 [[5]](#note-5)

<a id="event-6"></a>

6. **曹丕代汉，刘备称帝及伐吴。** 误闻献帝被杀后刘备发丧，群臣引谶瑞劝进，刘备在成都武担南即位。章武元年立后、储君和诸王；张飞被杀，刘备拒和出师。 [[6]](#note-6)

<a id="event-7"></a>

7. **夷陵败、永安托孤与史评。** 刘备进至猇亭败于陆逊，退守永安，病重以诸葛亮、李严托孤，死后谥昭烈、葬惠陵。陈寿肯定其识人、宽厚和托付，也评其谋略不及曹操。 [[7]](#note-7)

<a id="event-8"></a>

8. **刘禅继位及南中、孙吴。** 刘禅先为王太子，后立皇太子，章武三年五月继位。朱褒、雍闿、高定叛离，诸葛亮遣邓芝与吴恢复往来。 [[8]](#note-8)

<a id="event-9"></a>

9. **魏分道伐蜀，刘禅出降。** 邓艾破诸葛瞻于绵竹，刘禅从谯周议降，刘谌自杀。降书及面缚仪式俱保留。邓艾次年被收，钟会在成都败亡。 [[9]](#note-9)

<a id="event-10"></a>

10. **受封安乐公与陈寿史评。** 刘禅及随从官员东迁，魏赐给刘禅爵邑，泰始七年刘禅死于洛阳。陈寿将用贤相与亲宦官的政治后果相比较。 [[10]](#note-10)

<a id="event-11"></a>

11. **甘夫人及追尊合葬。** 甘氏随刘备在荆州生刘禅，长坂时由赵云保护。甘氏死后迁柩，诸葛亮议追尊昭烈皇后、与刘备合葬。 [[11]](#note-11)

<a id="event-12"></a>

12. **穆皇后和张氏姊妹。** 吴壹之妹先嫁刘瑁，后成刘备皇后。张飞长女为刘禅敬哀后，病逝后刘禅立其妹，传中存有册立辞。 [[12]](#note-12)

<a id="event-13"></a>

13. **刘永、刘理及太子璿。** 刘永、刘理由鲁、梁二王改封甘陵、安平。刘璿立储后在蜀亡次年成都乱中遇害。卷评以夫妇、父子说明一国体制。 [[13]](#note-13)

<a id="event-14"></a>

14. **隆中对与孙刘结盟。** 徐庶荐诸葛亮，刘备三访。诸葛亮议据荆益、结孙权并待时北向；长坂败后又赴柴桑说孙权抗曹。 [[14]](#note-14)

<a id="event-15"></a>

15. **永安托孤、南征与出师表。** 诸葛亮助定益州，刘备病重托孤。亮平南中、盟孙权并屯汉中，上表请刘禅同宫府赏罚、亲贤纳谏。 [[15]](#note-15)

<a id="event-16"></a>

16. **街亭、陈仓和再出祁山。** 马谡违节度而败，诸葛亮自贬；后围陈仓斩王双，取武都、阴平，复出祁山时张郃追击战死。L1767《后出师表》在通行裴注中是引文，仓内混排，来源及真伪有争。 [[16]](#note-16)

<a id="event-17"></a>

17. **五丈原、葬定军山及立庙。** 诸葛亮据五丈原并屯田，相持百余日而死，遗令薄葬、谥忠武。卷内记录军用器物与后世沔阳立庙。 [[17]](#note-17)

<a id="event-18"></a>

18. **《诸葛氏集》与陈寿奏表。** 陈寿奉命整理诸葛亮政军言教为二十四篇，列篇目及泰始十年呈书。奏表论亮用兵和治民之长短。 [[18]](#note-18)

<a id="event-19"></a>

19. **诸葛乔、诸葛瞻及董厥、樊建。** 诸葛乔由诸葛瑾家出继。诸葛瞻后来战死绵竹，董厥、樊建参与蜀汉后期军政。陈寿从治国及用兵评价诸葛亮。 [[19]](#note-19)

<a id="event-20"></a>

20. **关羽白马之战及荆州失守。** 关羽随刘备，暂入曹军后斩颜良而归。后督荆州，攻樊擒于禁，孙吴袭后路后兵散遇害。 [[20]](#note-20)

<a id="event-21"></a>

21. **张飞长坂拒敌、入蜀和遇害。** 张飞长坂断后，入川释严颜，守巴西败张郃。东征前因部曲怨恨遇害。 [[21]](#note-21)

<a id="event-22"></a>

22. **马超由关陇至蜀。** 马超承马腾旧部联合韩遂拒曹操，败于关中后辗转陇右、汉中，投刘备并参与成都之围，章武二年死。 [[22]](#note-22)

<a id="event-23"></a>

23. **黄忠、赵云及追谥。** 黄忠归刘备后随军入蜀，于定军山破夏侯渊。赵云长坂护刘禅与甘氏，入蜀分兵，北伐守箕谷，卒后被追谥。卷末并论诸将长短。 [[23]](#note-23)

<a id="event-24"></a>

24. **龐统受荐与谋取益州。** 司马徽识龐统，鲁肃和诸葛亮推荐，刘备任其参谋。龐统提议先取关隘，后攻雒县中矢而死。 [[24]](#note-24)

<a id="event-25"></a>

25. **法正与益州、汉中之策。** 法正在刘璋下不受任，经张松通刘备，后写书劝刘璋。其又劝刘备用许靖、夺汉中。陈寿肯定其谋画并记录德行争议。 [[25]](#note-25)

<a id="event-26"></a>

26. **许靖在汉末辗转及受蜀礼遇。** 许靖以人伦品题知名，先后在汉廷、扬州、交州和益州，最终为刘备所用；传存书疏与人品争议。 [[26]](#note-26)

<a id="event-27"></a>

27. **麋竺、孙乾、简雍及伊籍。** 麋竺迎刘备领徐州并倾财相助；孙乾奉命联络诸方，简雍以辞辩周旋，伊籍参与蜀汉制度。 [[27]](#note-27)

<a id="event-28"></a>

28. **秦宓的谏争与辩难。** 秦宓以学术辞辩成名，曾谏东征被囚，后复进用；与吴使张温问答所用天人典故见原文，卷末合评诸人。 [[28]](#note-28)

<a id="event-29"></a>

29. **董和与刘巴。** 董和清俭且能理政，与诸葛亮协事。刘巴在荆、交、益三州辗转，刘备定蜀后任其撰制诰。 [[29]](#note-29)

<a id="event-30"></a>

30. **马良与马谡。** 马良协刘备，使吴后随军东征，为乱兵所害。马谡好谈军计，亮遣其督街亭，战败而死。 [[30]](#note-30)

<a id="event-31"></a>

31. **陈震聘吴与政争。** 陈震随刘备入蜀，后使吴祝贺孙权称帝并定盟。传中另载出使前陈震对李严的评价。 [[31]](#note-31)

<a id="event-32"></a>

32. **董允、陈祗和吕乂。** 董允遵诸葛亮委付，抑黄皓而敢谏。陈祗续掌机务后黄皓渐进；吕乂在各郡理政，诸传共见内外用人。 [[32]](#note-32)

<a id="event-33"></a>

33. **刘封、孟达与上庸。** 刘封为刘备养子，与孟达在上庸不和，未发兵救关羽；孟达归魏。上庸失守后刘封返成都，被刘备责令自尽。 [[33]](#note-33)

<a id="event-34"></a>

34. **彭羕与廖立。** 彭羕受赏而放言触忌，在狱中致书诸葛亮，仍被诛。廖立因讥评政事被废徙，闻亮死而悲叹。 [[34]](#note-34)

<a id="event-35"></a>

35. **李严的督粮案及刘琰案。** 李严与诸葛亮受遗诏，后因督运不继且转嫁责任而废徙。刘琰殴妻被处死，朝廷随之调整命妇朝贺之礼。 [[35]](#note-35)

<a id="event-36"></a>

36. **魏延、杨仪争执和各自结局。** 魏延镇汉中、随亮北伐，屡有别议。诸葛亮死后魏延拒从杨仪退军，二人相争，魏延被杀；杨仪因怨言获罪。 [[36]](#note-36)

<a id="event-37"></a>

37. **霍峻守葭萌、霍弋守南中、王连理盐铁。** 霍峻以少拒众，霍弋镇抚南中、蜀亡后等候刘禅安危消息再归附。王连先守梓潼，后为蜀汉管盐铁并举荐官员。 [[37]](#note-37)

<a id="event-38"></a>

38. **向朗、向宠及张裔。** 向朗历郡守与长史，免官后研学；向宠治宿卫。张裔被雍闿送吴，邓芝交涉得还，后任诸葛亮留府长史。 [[38]](#note-38)

<a id="event-39"></a>

39. **杨洪与何祗。** 杨洪建议速援汉中、参与平黄元，又提拔有办理事务之才的何祗；史传以此说明诸葛亮知人用人。 [[39]](#note-39)

<a id="event-40"></a>

40. **费诗谏称帝及卷评。** 费诗传命关羽，认为未克敌而称帝会使人疑惑。随诸葛亮南行后，又反对信任孟达，卷评称其直率而犯忌。 [[40]](#note-40)

<a id="event-41"></a>

41. **杜微辞疾及诸葛亮劝留。** 杜微长期不仕，诸葛亮访求后以书问计并劝留，借礼遇贤者为朝廷示范。 [[41]](#note-41)

<a id="event-42"></a>

42. **周群与杜琼。** 周群承父学，以天象预言汉中战局。杜琼博学少言，卷内保留其讨论术数、谶语与政局之词。 [[42]](#note-42)

<a id="event-43"></a>

43. **蜀汉经学诸儒。** 许慈参与礼制，孟光博古敢谏，来敏以言失官，尹默、李譔传习经史，反映荆益学风交汇。 [[43]](#note-43)

<a id="event-44"></a>

44. **谯周上疏、《仇国论》及劝降。** 谯周戒游宴、慎言用兵，作《仇国论》。魏攻蜀时反对入南或归吴，劝刘禅降魏；附其后仕及孙谯秀。 [[44]](#note-44)

<a id="event-45"></a>

45. **郤正掌秘府并随刘禅迁洛。** 郤正博学善文，蜀亡后从刘禅东迁。陈寿在结语中比较诸儒的学行与处变之能。 [[45]](#note-45)

<a id="event-46"></a>

46. **黄权从益州至江北降魏。** 黄权先谏刘璋勿迎刘备，继为刘备筹军。夷陵后退路断绝，率江北军降魏，刘备保全其家。 [[46]](#note-46)

<a id="event-47"></a>

47. **李恢定建宁与吕凯守永昌。** 李恢在昆明遭围，设法退敌，参与南中平定。吕凯、王伉拒雍闿守永昌，传中保存檄答和诸葛亮的表赏。 [[47]](#note-47)

<a id="event-48"></a>

48. **马忠治南中、王平守兴势及句扶。** 马忠治南方并平刘胄。王平谏马谡不从，后来镇守汉中，与刘敏拒曹爽；卷附同郡将领句扶。 [[48]](#note-48)

<a id="event-49"></a>

49. **张嶷治理越巂、从姜维出战。** 张嶷以招抚和用兵恢复越巂及盐铁，开通旄牛道。曾进言警示诸葛恪政局，末从姜维出兵阵亡。 [[49]](#note-49)

<a id="event-50"></a>

50. **蒋琬继政与东下计划。** 蒋琬在诸葛亮死后接掌军政，驻屯汉中，考虑由汉水攻魏兴、上庸，因病和众议退屯涪。附蒋斌、刘敏及兴势拒魏。 [[50]](#note-50)

<a id="event-51"></a>

51. **费祎使吴、接政及遇害。** 费祎使吴善辩，调解魏延、杨仪，继蒋琬理国。领兵赴兴势，后在岁首大宴被魏降人郭循所杀。 [[51]](#note-51)

<a id="event-52"></a>

52. **姜维北伐、汉中改防与成都败亡。** 姜维由魏归蜀，历南安、洮西、段谷诸战，更改汉中防守。魏攻蜀时固守剑阁，奉诏归钟会，后于成都兵变中遇害。 [[52]](#note-52)

<a id="event-53"></a>

53. **邓芝使吴与治军。** 邓芝力主吴蜀重修旧好，说孙权共同抗魏；后镇边、平涪陵，身居将位而不累私财。 [[53]](#note-53)

<a id="event-54"></a>

54. **张翼、宗预、廖化。** 张翼治南中并反对姜维过度用兵。宗预数使吴并为永安防备辩解，廖化由吴返蜀；两人晚年同因东迁在途中病卒。 [[54]](#note-54)

<a id="event-55"></a>

55. **杨戏与《季汉辅臣赞》缘起。** 杨戏掌刑狱时平当，与姜维有隙而免官。延熙四年撰赞，陈寿说明所赞而缺单传者由他附叙行事。 [[55]](#note-55)

<a id="event-56"></a>

56. **辅臣赞所述开国人物和早期将相。** 韵文先颂刘备、诸葛亮，继及许靖、关羽、张飞、马超、法正、龐统、黄忠及董和等，间附邓方、费观、王连的事迹。 [[56]](#note-56)

<a id="event-57"></a>

57. **辅臣赞所述官吏和边将。** 所赞含刘巴、麋竺、周群、吴壹、李恢、黄权和赵云等；李严、魏延、杨仪的赞语也指出其失节或难处。 [[57]](#note-57)

<a id="event-58"></a>

58. **辅臣赞其余小传、佚闻与卷评。** 从马良及荆州故吏写到益州僚属、夷陵死者和降吴诸人。传注明部分人的名籍事迹已佚；附陈寿对邓芝、张翼、宗预和杨戏的评语。 [[58]](#note-58)

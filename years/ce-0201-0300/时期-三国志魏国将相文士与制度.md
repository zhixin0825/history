# 魏国将相、文士与制度

[本世纪目录](README.md) · [全部世纪](../README.md) · [《三国志》分卷目录](../../sources/三国志读本目录.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **夏侯惇与韩浩史涣。** 夏侯惇早从曹操，参与兖州争夺及官渡前后作战，也主持地方劝农和水利。韩浩于夏侯惇被劫时坚决处置，后与史涣均以忠勇掌禁兵。 [[1]](#note-1)

<a id="event-2"></a>

2. **夏侯渊经营陇右、战死定军山。** 夏侯渊从官渡、关中至陇右连年领兵，后留守汉中，定军山被黄忠军击杀。传末记其诸子，包括由魏入蜀的夏侯霸。 [[2]](#note-2)

<a id="event-3"></a>

3. **曹仁守江陵、樊城。** 曹仁从征袁术、吕布、袁绍等，以骑兵机动见长。周瑜围江陵时，他率人出救部将；关羽围樊城时与守军坚持，后来位至大司马。 [[3]](#note-3)

<a id="event-4"></a>

4. **曹洪。** 曹洪在荥阳曹操兵败时让马，后多次随征。曹丕因旧怨曾欲处死，卞太后干预，曹洪得免死；明帝朝复官封爵。 [[4]](#note-4)

<a id="event-5"></a>

5. **曹休从虎豹骑至石亭败军。** 曹休自江南归曹，领兵护卫，后在下辩判断蜀军虚实。文帝、明帝时督东南诸军，被周鲂诱深入吴境，在石亭败退，未久病死。 [[5]](#note-5)

<a id="event-6"></a>

6. **曹真都督关陇、建议伐蜀。** 曹真少孤而受曹操抚养，以勇力和统兵任事。诸葛亮初出祁山时，他遣兵御蜀，提前布防陈仓。后来从子午等道攻蜀，遭连雨道路断绝，奉诏还师。 [[6]](#note-6)

<a id="event-7"></a>

7. **曹爽辅政、高平陵事变与何晏等。** 曹爽受明帝托孤，以弟兄和何晏等掌中枢，逐渐排挤司马懿。皇帝出谒高平陵时，司马懿控制洛阳，曹爽没有采用桓范建议，交兵权后以谋反罪与党属同诛。 [[7]](#note-7)

<a id="event-8"></a>

8. **夏侯尚、夏侯玄与许允王经。** 夏侯尚领军争江陵，与曹丕私交甚厚。夏侯玄与司马懿论选官、地方职权、服制，后随曹爽出兵骆谷，又牵入李丰案。卷末附许允和王经的政治遭遇及陈寿评论。 [[8]](#note-8)

<a id="event-9"></a>

9. **荀彧奉迎献帝、谋定官渡及晚年分歧。** 荀彧由袁绍转曹操，力劝先保兖州，奉献帝都许。在官渡军粮将尽时建议坚持；又劝乘胜统一河北。他反对董昭等推动曹操进魏公、受九锡，后留寿春病卒。 [[9]](#note-9)

<a id="event-10"></a>

10. **荀攸在官渡、下邳及平河北出谋。** 荀攸早与同僚谋诛董卓而入狱，获释后由曹操征召。攻吕布、白马、延津、乌巢及袁氏兄弟相争时，他参与决策，有些谋议因保密没有流传下来。 [[10]](#note-10)

<a id="event-11"></a>

11. **贾诩由关西军入曹及魏初论政。** 董卓与牛辅死后，贾诩劝李傕等西取长安；转而依张绣并促成其归曹。贾诩曾劝曹操暂缓由荆州顺江东进，又以袁绍、刘表父子之事回应立嗣问题。曹丕用他为太尉。 [[11]](#note-11)

<a id="event-12"></a>

12. **袁涣、张范及张承。** 袁涣往来于刘备、袁术和吕布之间，不肯替吕布辱骂刘备，归曹后议田政、伤死之礼。张范、张承在乱世保身，又受曹操征召，传文着重其施助贫弱及辞让的行事。 [[12]](#note-12)

<a id="event-13"></a>

13. **凉茂与国渊。** 凉茂先后治泰山、乐浪、魏郡，反对公孙度盲目出兵。国渊师郑玄，参与曹操屯田，强调考校公平，并审读匿名书信追究其来源。 [[13]](#note-13)

<a id="event-14"></a>

14. **田畴从刘虞出使、拒爵与卢龙引路。** 田畴受刘虞命赴长安通问，刘虞被杀后归乡集众，维持徐无山秩序。曹操征乌丸时，田畴引军由卢龙出塞，屡辞因功封赏，重申不愿借事取爵。 [[14]](#note-14)

<a id="event-15"></a>

15. **王脩与脂习、郭宪。** 王脩幼年丧母，后来侍奉孔融、袁谭。袁谭兵败后，王脩请收葬其尸，归曹后掌财赋与政务。又载脂习哭孔融、郭宪庇韩约的事。仓本此处插有“王褒”标题，标题之后仍接王脩事及附注。 [[15]](#note-15)

<a id="event-16"></a>

16. **邴原与曹魏征聘。** 邴原与管宁相友，避乱辽东，归乡后曹操聘用。他兼以学行和守节著称，传中连带记录公孙度与避地士人关系。 [[16]](#note-16)

<a id="event-17"></a>

17. **管宁与王烈及论赞。** 管宁避乱渡辽东、归北海，面对魏廷多次征聘仍持退处。王烈亦在辽东以德行著名。史家把诸人进退异同及其乡里声望一同论述。 [[17]](#note-17)

<a id="event-18"></a>

18. **崔琰与孔融。** 崔琰师事郑玄、归曹后参与选官与曹氏储嗣议论，书信被追问后被赐死。夹附孔融对当时朝政及曹操的批评和被收杀的异文。 [[18]](#note-18)

<a id="event-19"></a>

19. **毛玠清选用人及获罪。** 毛玠建议曹操尊奉天子、修耕植、蓄军资，又负责铨选，力推清正节俭。崔琰案后他被人告发，桓阶、和洽等为之辩护，最终免官。 [[19]](#note-19)

<a id="event-20"></a>

20. **徐奕与何夔。** 徐奕参与平关中和稳抚地方，后与校事卢洪、赵达政见不合。何夔归曹后先后治长广、东莱等地，处理地区动荡，参与魏礼与官员制度。 [[20]](#note-20)

<a id="event-21"></a>

21. **邢颙与鲍勋。** 邢颙从田畴，归曹后治郡并任曹氏诸王属官。鲍勋屡谏曹丕，官至御史中丞，在监察军营一案中遭免官获罪，廷尉议轻而曹丕不许。 [[21]](#note-21)

<a id="event-22"></a>

22. **司马芝议法、政务与卷末史评。** 司马芝以孝行、依法决断著称。领河南等地时拒绝宦官转达太后之令，处理淫祀及官吏请托；传中还录其论禁令、诉讼与地方政务，陈寿合评诸人清直。 [[22]](#note-22)

<a id="event-23"></a>

23. **钟繇与钟毓。** 钟繇早侍献帝，受曹操委任镇关中，参与调停地方势力与击郭援，后位列魏三公。子钟毓早得名，明帝议亲征时主张朝中决策、慎于出动。 [[23]](#note-23)

<a id="event-24"></a>

24. **华歆。** 华歆出仕汉廷，后守豫章，接受孙策进入其郡，继而应朝廷征召，位至魏初三公。传内重视他接待僚友、廉于财物及与王朗共议的言行。 [[24]](#note-24)

<a id="event-25"></a>

25. **王朗与朝廷奏议。** 王朗师杨赐，守会稽时拒孙策而失败，后归曹并入魏为三公。其奏议涉及恤刑、储备、边防、礼制和对民役使用的限制。 [[25]](#note-25)

<a id="event-26"></a>

26. **王肃经学、礼法与卷末论赞。** 王肃从宋忠治学，对曹真伐蜀的转输困难上奏。又注释群经并和郑学论辨，参与郊祀、宗庙等礼制讨论。卷末合评钟繇、华歆、王朗及王肃。 [[26]](#note-26)

<a id="event-27"></a>

27. **程昱保东阿、佐曹平兖州。** 程昱在东阿组织吏民抵抗黄巾时的叛乱。曹操征徐州、兖州叛时，与荀彧分守城邑；在对刘备、袁绍及孙权的决策中，他主张据实际兵势取舍。 [[27]](#note-27)

<a id="event-28"></a>

28. **郭嘉谋袁氏、吕布与乌丸。** 郭嘉见袁绍不足以成功，归曹后负责军谋。他劝在袁氏兄弟相争时等待变化，又赞成急取乌丸、轻兵先发。回师后病死，曹操追念其筹策。 [[28]](#note-28)

<a id="event-29"></a>

29. **董昭促成迁许、魏国建立及内政议论。** 董昭先从袁绍，继入曹营，以书信联络杨奉，参与迎献帝并献迁许之策。又推动曹操受封魏公、加九锡，曹魏时任高官，进言留意后宫任用、浮华和朋党。 [[29]](#note-29)

<a id="event-30"></a>

30. **刘晔议平汉中、看吴蜀及明帝朝问策。** 刘晔为汉宗室后裔，初于淮南追随地方势力，后归曹操。汉中平定时劝乘势攻蜀；孙权对魏称臣时，又分析吴国忍让的目的和攻吴时机。曹魏诸帝多向他问军国谋略。 [[30]](#note-30)

<a id="event-31"></a>

31. **蒋济解合肥之围、议迁都与边战。** 孙权围合肥时蒋济假作援军将至的文书，使吴军引退。关羽围樊时反对迁都，主张利用孙刘嫌隙。又参与防吴、迁官及高平陵事变，传中保留多篇对制度和用人的意见。 [[31]](#note-31)

<a id="event-32"></a>

32. **刘放孙资掌中书及论赞。** 刘放劝王松归曹，与孙资长期掌管机密诏令。明帝病重时，两人参与更定顾命人员，使曹爽与司马懿受命辅政。卷末评其文案办事才能与权势，并与前列谋臣相比较。 [[32]](#note-32)

<a id="event-33"></a>

33. **刘馥经营合肥。** 刘馥在扬州局势破碎时入合肥，招回流户，设置学校、屯田、水利和城防。孙权后来围城，守军利用他留下的设施与储备。 [[33]](#note-33)

<a id="event-34"></a>

34. **司马朗守乡与参与曹魏州政。** 司马朗幼有名，董卓西迁之际引族人归乡。曹操用其治县、领兖州；从军逢疫时，他亲巡病者，配给药物，自己亦病死。 [[34]](#note-34)

<a id="event-35"></a>

35. **梁习平并州与附王思。** 并州新附时，梁习征调豪强赴郡府、招抚部众并安置人员，推行法令以恢复州政。附载王思任事苛急，与梁习的性情和治理手段有异。 [[35]](#note-35)

<a id="event-36"></a>

36. **张既安定关陇及附游楚。** 张既借钟繇之任说马腾等解除对郭援的支持，又从曹操平关中，主张抚集人口。后来负责雍、凉诸州与羌胡交涉。附载游楚在诸葛亮北出时守陇西。 [[36]](#note-36)

<a id="event-37"></a>

37. **温恢与孟建。** 温恢厚施宗族，入曹后治州，判断樊城受水和边军形势。孟建与蜀地士人有旧，在曹魏以才能与名望受用。 [[37]](#note-37)

<a id="event-38"></a>

38. **贾逵的州政与救援曹休。** 贾逵早守绛邑，不向郭援屈服，归曹后参与河东及豫州治理。曹休入吴而败时，贾逵由别道赴援，保障退路，两人在事后仍有争执。陈寿以诸人事迹说明刺史由监察官向州政主管转变。 [[38]](#note-38)

<a id="event-39"></a>

39. **任峻归曹与许下屯田。** 任峻在中牟招集人员归曹，负责车运与军粮，参与枣祗提出的屯田，并以车队和营地制度保障供给。 [[39]](#note-39)

<a id="event-40"></a>

40. **苏则平河西。** 苏则治酒泉、金城等郡，遇饥荒动员豪强救济。河西州郡叛乱时，先分化各部，再进兵平定。曹丕即位后，他以直言获称。 [[40]](#note-40)

<a id="event-41"></a>

41. **杜畿治河东。** 杜畿早年处理郑县疑狱，后由荀彧荐掌河东，以缓急有度使地方武装难以合谋，又劝农兴学，支持曹军关中军事。 [[41]](#note-41)

<a id="event-42"></a>

42. **杜恕述政及附乐详。** 杜恕在朝进言，议君臣职责、官员考课和地方政策，直陈近习用事与长吏多迁带来的问题。他后来治州获罪，传末并载其著述及乐详授经。 [[42]](#note-42)

<a id="event-43"></a>

43. **郑浑、仓慈与卷末史评。** 郑浑在各郡安集流户，组织生产并兴修陂渠。仓慈治敦煌，抑制豪强占田，简化与西域商旅的交易和来往。陈寿把这些政绩与任峻、苏则、杜畿并论。 [[43]](#note-43)

<a id="event-44"></a>

44. **张辽攻柳城、定天山与守合肥。** 张辽辗转从丁原、董卓、吕布，到曹操军中领兵。北征乌丸当先，平陈兰、梅成于天山。守合肥时，他与李典等在孙权大军围城前出击，撤退时又交战。 [[44]](#note-44)

<a id="event-45"></a>

45. **乐进随征。** 乐进从募兵入曹营，参与击吕布、袁绍、袁谭及关羽部众。后与张辽、李典守合肥，受封列侯。 [[45]](#note-45)

<a id="event-46"></a>

46. **于禁治军、降关羽与晚年。** 于禁以军纪严整著称，宛城败军时约束部众，不避有亲旧的将士。樊城大水使麾下诸军被围，于禁降关羽，后归魏，在羞愧中去世。 [[46]](#note-46)

<a id="event-47"></a>

47. **张郃由袁归曹至木门战死。** 张郃在官渡前属袁绍，争论救乌巢和攻曹营后归曹。以后经营陇蜀，破马谡于街亭；追击诸葛亮时中箭，死于木门。 [[47]](#note-47)

<a id="event-48"></a>

48. **徐晃解樊围、附朱灵及论赞。** 徐晃从杨奉护送献帝，后归曹。战樊城时袭关羽屯围、接通曹仁守军，曹操称赞其军纪。卷末附朱灵，并评五将的能力、行事和史料详略。 [[48]](#note-48)

<a id="event-49"></a>

49. **李典与李通。** 李典家族以部众从曹，参与督运、攻袁和守合肥，主张守将先同力御敌。李通聚众汝南，官渡时不受袁绍诱降，后援曹仁并战关羽部。 [[49]](#note-49)

<a id="event-50"></a>

50. **臧霸和孙观。** 臧霸早年救父，后在泰山一带与孙观等结众，曾依陶谦、吕布。归曹后受命治理青、徐并参与淮南边战；孙观也以军功受封。 [[50]](#note-50)

<a id="event-51"></a>

51. **文聘、吕虔与王祥。** 文聘在刘琮降后方归曹，长任江夏太守，守备江汉。吕虔治泰山并领徐州，以厚待士人著称，任王祥为别驾，王祥协理州政。 [[51]](#note-51)

<a id="event-52"></a>

52. **许褚与典韦。** 许褚从宗族自守转而护卫曹操，战关中时随侍渡河，并以勇力威慑马超。典韦由张邈军归曹，留守营门挡住张绣军，在宛城战死。 [[52]](#note-52)

<a id="event-53"></a>

53. **庞德在西线及樊城战死。** 庞德从马腾、马超，后经张鲁入曹。奉命援樊时遇大水，仍率部抵抗；被关羽俘获后拒降被杀。 [[53]](#note-53)

<a id="event-54"></a>

54. **庞淯、阎温、张恭及论赞。** 庞淯违张猛禁令吊丧，又为酒泉求援；阎温出城求援被获，拒绝替马超传话而死。张恭在河西局势未定时保全郡府并与朝廷相通。 [[54]](#note-54)

<a id="event-55"></a>

55. **任城威王曹彰。** 曹彰勇于力战，也奉曹操之命学习兵书。率军平代郡乌丸后回师，曹丕即位后数次改封，黄初四年入朝时去世。 [[55]](#note-55)

<a id="event-56"></a>

56. **曹植早年受宠与储位竞争。** 曹植少以文章受曹操喜爱，册封、出入宫门和受命出征等事影响其处境。原行夹载杨修与曹植相交、《魏略》等材料，并有大段曹植文辞。 [[56]](#note-56)

<a id="event-57"></a>

57. **曹植宗室处境及奏疏。** 曹植在文帝与明帝时屡改封国，陈说宗室拘束、骨肉离隔，要求得到为国任事的机会。传中保存他的上疏、答诏及对过往行为的申陈。 [[57]](#note-57)

<a id="event-58"></a>

58. **曹植申论求试、结局与曹熊。** 后半多曹植请求效力、通亲和负责政务的表文，能见文体与封国制度。卷末记其晚年居陈及死后诸子、曹熊封谥和陈寿评论。 [[58]](#note-58)

<a id="event-59"></a>

59. **曹操诸子曹昂至曹林。** 曹昂从征张绣而死，后来追封并以宗室子继嗣。曹冲有称象、救吏等故事，早卒。曹据、曹宇、曹林等由侯进公进王并屡迁封，曹宇为后来常道乡公曹奂之父。 [[59]](#note-59)

<a id="event-60"></a>

60. **曹衮、曹峻、曹幹与曹彪。** 曹衮以学习、节俭及遵守封国禁令受称，死后追谥。曹峻等屡有迁封。曹彪后来牵入王凌案而被赐死，须与卷028并读。 [[60]](#note-60)

<a id="event-61"></a>

61. **曹操其余诸子。** 本段续记早夭、无嗣、追封和过继者，以及经历国号变化的曹整、曹均、曹徽、曹茂等。其名爵沿革常在一段内越过数朝。 [[61]](#note-61)

<a id="event-62"></a>

62. **曹丕诸子与封国制度史评。** 逐一记录曹协、曹蕤、曹鉴、曹霖、曹礼等人的追封、嗣立和迁封。曹霖之子曹髦继魏帝位。陈寿批评诸王徒有国名、严遭拘隔、封号屡易。 [[62]](#note-62)

<a id="event-63"></a>

63. **王粲及建安文士、阮籍嵇康吴质。** 王粲避地荆州，后劝刘琮归曹，以博闻与文章受重，参与朝仪。卷内列建安文人的风格和交游，又附阮籍、嵇康、吴质等生平与注家材料。 [[63]](#note-63)

<a id="event-64"></a>

64. **卫觊论关中与朝政。** 卫觊在关中面对诸将观望，提出整治盐运、吸引流民与维持局势的办法，也参与礼制法令及曹魏朝政，传中有较长奏疏。 [[64]](#note-64)

<a id="event-65"></a>

65. **刘廙进谏与著述。** 刘廙兄长在荆州获罪，刘廙归曹后历任文职，在魏讽案中受牵连，曹操宽宥。传内保留其论治政、读书和君臣关系的言论。 [[65]](#note-65)

<a id="event-66"></a>

66. **刘劭、缪袭、仲长统等。** 刘劭参与官礼、律令及考课制度，记录对日食、军事和人才的判断。附见缪袭助修史礼、仲长统的政论，以及苏林、韦诞等作家学者。 [[66]](#note-66)

<a id="event-67"></a>

67. **傅嘏议吴战和人才及论赞。** 傅嘏受陈群荐用，因与何晏等见解不合外任。后来参与对吴军事判断以及选举、州郡安排，卷末按文章、政论和才能合评诸人。 [[67]](#note-67)

<a id="event-68"></a>

68. **桓阶从长沙入曹。** 桓阶为孙坚求归尸，劝张羡以长沙诸郡响应曹操，起兵先后见《后汉书·刘表传》与《资治通鉴》卷六十二考异，后任魏尚书令，又在曹丕与曹植争储时维护长嫡名分。 [[68]](#note-68)

<a id="event-69"></a>

69. **陈群议选官、礼法与辅政。** 陈群出身颍川名家，曾随刘备、吕布治下辗转，归曹后参与选官，创设九品官人法。又就复肉刑、征吴、兴役和亲贵任事等问题陈说。 [[69]](#note-69)

<a id="event-70"></a>

70. **陈泰平关陇。** 陈泰曾为并州刺史，后督雍凉军。面对姜维攻狄道，他进兵解围，传内列争议与用兵结果，也记其官职变化及家族嗣封。 [[70]](#note-70)

<a id="event-71"></a>

71. **陈矫与徐宣。** 陈矫为陈登出使许都，后任魏郡、尚书令，曹操去世时参与迅速定策。徐宣传记同样由广陵写起，任职多以守职、持节著称。 [[71]](#note-71)

<a id="event-72"></a>

72. **卫臻。** 卫臻守魏国法度，为曹丕、曹叡承担军政和近侍差遣，与司马懿在辽东方向和备边上有所论议。 [[72]](#note-72)

<a id="event-73"></a>

73. **卢毓任选职及卷末史评。** 卢毓由早年养寡嫂孤侄写起，临政时以守法著称，在明帝朝负责选官，强调履行职务及考核实绩，也牵涉曹爽、司马氏权势消长。 [[73]](#note-73)

<a id="event-74"></a>

74. **和洽与许混。** 和洽曾避兵荆州，不肯附袁绍，归曹后主张选人不偏尚刻苦外表，又为毛玠受诬出言。附有许劭子许混及家族识鉴。 [[74]](#note-74)

<a id="event-75"></a>

75. **常林。** 常林乱世耕守，后进入曹魏，议地方赋役、人事和袒护的危害。晚年以大夫致仕，陈寿称其不以三司为念。 [[75]](#note-75)

<a id="event-76"></a>

76. **杨俊论人和获罪。** 杨俊从边让学，避兵时扶助老弱，又好荐拔人才。曹丕、曹植继嗣相争时他的判断未获曹丕谅解，后在宛城案中自杀。 [[76]](#note-76)

<a id="event-77"></a>

77. **杜袭。** 杜袭避乱荆州，不乐受刘表招揽，归曹后经营地方，后于平汉中前后安抚归附者，并参与朝廷军议。 [[77]](#note-77)

<a id="event-78"></a>

78. **赵俨。** 赵俨从荆州归曹，治朗陵时挫豪族，任军司时协调诸将。关羽围樊时劝各军审势先保守城与补给。 [[78]](#note-78)

<a id="event-79"></a>

79. **裴潜治代郡、入朝及论赞。** 裴潜避乱荆州、长沙，后为曹操治代郡，整饬地方军政。历魏三帝任朝职，持廉俭。卷末评数人为清和、刚毅及能守职。 [[79]](#note-79)

<a id="event-80"></a>

80. **韩暨用水排鼓风及晚年任公。** 韩暨早年为父报仇，避乱后入曹幕，主持冶铸，改用水排以节省人畜劳力，使铸造供应军用，后位至司徒。 [[80]](#note-80)

<a id="event-81"></a>

81. **崔林。** 崔林从县令起步，任幽州刺史时对使者与边地事务持节，反对用高名引诱外患。后来任大鸿胪、司空，按职行事。 [[81]](#note-81)

<a id="event-82"></a>

82. **高柔论法律、牧民与三公。** 高柔由地方县职入朝，用法宽平，曾退回皇帝拟重处的案件。又针对逃役、弓弩禁令、宦官干预和猎禁奏事，至曹魏后期任三公。 [[82]](#note-82)

<a id="event-83"></a>

83. **孙礼。** 孙礼少从曹操，明帝时劝减劳役，敢陈狩猎之险。又在曹爽、司马懿相持时由司隶校尉出守，参与扬州及边军事务。 [[83]](#note-83)

<a id="event-84"></a>

84. **王观与卷末论赞。** 王观出身孤贫，历县令和郡守而有治名，朝中任少府时不徇近幸，并在曹爽失势后参与查办。陈寿赞五人各有公辅之资。 [[84]](#note-84)

<a id="event-85"></a>

85. **辛毗从袁谭使曹，论储备和伐蜀。** 辛毗从袁氏出使请援，曹操用其策取河北；以后在曹魏当廷直谏，反对迁徙冀州士家及轻动大军。诸葛亮与魏军对峙时，辛毗持节约束出战。 [[85]](#note-85)

<a id="event-86"></a>

86. **杨阜抗马超并劝省营建。** 杨阜与陇右同僚谋击马超，战后抚治地方。明帝朝反对多兴高台、增宫人及奢侈耗农，又辨刘晔等人朝议。 [[86]](#note-86)

<a id="event-87"></a>

87. **高堂隆议礼乐、灾异和营造。** 高堂隆通礼，参与正朔、郊祀、宗庙、乐舞等议。明帝修宫殿或出现灾异时，他常以古礼和节用劝止，临终还藉奏议告戒。 [[87]](#note-87)

<a id="event-88"></a>

88. **栈潜与卷末评论。** 栈潜在明帝大修宫室时上疏，强调务农节用。陈寿并赞诸臣忠直，对高堂隆改正朔、推尧舜世系的主张保留评价。 [[88]](#note-88)

<a id="event-89"></a>

89. **满宠守樊城、合肥及淮南。** 满宠为许令时依法治人，守樊城坚持不退。后来统辖淮南，提议在便于防守处另建合肥新城，几次抵御孙权，军议中重在预判敌人行动。 [[89]](#note-89)

<a id="event-90"></a>

90. **田豫治北边并迎击东吴海上使者。** 田豫早年依刘备又归公孙瓒，后从曹魏处理北方部族。其后在海上截获吴使周贺，对北边与青州军政均得声名。 [[90]](#note-90)

<a id="event-91"></a>

91. **牵招在北方抚边。** 牵招敬师而冒兵乱收殓乐隐，后来任雁门、平虏等职，处置乌丸与鲜卑边患，兼行招抚、屯备、耕作与人才荐举。 [[91]](#note-91)

<a id="event-92"></a>

92. **郭淮据陇右、防御蜀军。** 郭淮见蜀军动向后多能预作准备，先后应对诸葛亮、姜维军，并经营氐羌。陈寿认为满宠、田豫、牵招、郭淮均以军略和治边见长。 [[92]](#note-92)

<a id="event-93"></a>

93. **徐邈治凉州。** 徐邈以饮酒逸事见称，任凉州刺史后安辑吏民、开盐池、通水利、积军粮，并以节俭抑制边地弊政。 [[93]](#note-93)

<a id="event-94"></a>

94. **胡质与胡威。** 胡质从州郡入仕，平断楚地讼狱，督荆州军政时有所积蓄。子胡威后来以廉谨著称，注中也录其家门清约。 [[94]](#note-94)

<a id="event-95"></a>

95. **王昶戒子及守荆州。** 王昶对儿辈以谦实命名，戒结党与奢纵，又论复五等爵、整顿兵农及沿江军务，多次督兵拒吴。 [[95]](#note-95)

<a id="event-96"></a>

96. **王基议攻吴、平寿春与论赞。** 王基早以学行见称，任地方军政时进言军政、律令。诸葛诞据寿春后，王基临阵判断不能轻易迁营，事后参与安顿淮南。 [[96]](#note-96)

# 魏国边地、方技及魏晋之际

[本世纪目录](README.md) · [全部世纪](../README.md) · [《三国志》分卷目录](../../sources/三国志读本目录.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **王凌、令狐愚谋立楚王。** 王凌在边州屡建军功，与令狐愚因曹爽事变后的局势议立楚王曹彪。风声泄露，司马懿率军到寿春，王凌出降而自杀，宗族及有关人员被清算。 [[1]](#note-1)

<a id="event-2"></a>

2. **毌丘俭征高句丽及与文钦起兵。** 毌丘俭任幽州时两度攻高句丽。后镇淮南，与文钦举兵反司马师，兵败，毌丘俭死，文钦奔吴。 [[2]](#note-2)

<a id="event-3"></a>

3. **诸葛诞守寿春、吴军来援。** 诸葛诞因淮南政局和自身处境起兵，向吴送质借兵，文钦、唐咨等来救。司马昭围困寿春，诸葛诞杀文钦，城陷后被杀，吴将或降或死。 [[3]](#note-3)

<a id="event-4"></a>

4. **邓艾经营屯田与备蜀。** 邓艾自幼孤贫，受司马懿重用考察淮河水利、屯田和漕运。后来在陇西判断姜维行动，增修防御设施并参与接连数年对蜀战事。 [[4]](#note-4)

<a id="event-5"></a>

5. **邓艾入阴平、刘禅降及邓艾死。** 魏军伐蜀时，邓艾走阴平入江油，败诸葛瞻，于成都受刘禅降。其后因自行封授又遭钟会告发，被押解，最终遭杀。晋初关于其罪责和子孙待遇有不同诏议。 [[5]](#note-5)

<a id="event-6"></a>

6. **钟会伐蜀、成都兵变与陈寿论赞。** 钟会参与司马氏机密，在寿春用计，并与司马昭筹划伐蜀。受蜀将投降后欲据成都兵变，诸军反抗，钟会与姜维一起被杀；夹附王弼及传末对诸将权力与用兵的评议。 [[6]](#note-6)

<a id="event-7"></a>

7. **华佗看病与传术。** 列华佗出诊的病例、手术药物及五禽戏等材料，保留以当时医理作出的解释。华佗为曹操医治，后被收杀；吴普、樊阿等传其技术。 [[7]](#note-7)

<a id="event-8"></a>

8. **杜夔复雅乐与马钧制器。** 杜夔按乐律整饬雅乐器、研究古乐谱与度量。夹附马钧织机、指南车、水转百戏等制器材料，并记注家对技术未获尽用的感慨。 [[8]](#note-8)

<a id="event-9"></a>

9. **朱建平相人、周宣占梦。** 朱建平以相术知名，传中并列生死与祸福的应验故事。周宣为郡吏，擅占梦，常以语言双关、时事和梦中物件解释所闻。 [[9]](#note-9)

<a id="event-10"></a>

10. **管辂的易筮与卷末评。** 管辂行迹若干有正书和别传两层，叙卜筮、论辩与人物交往，常将预断和后人所记结果并列。陈寿以《史记》方术列传类比诸人。 [[10]](#note-10)

<a id="event-11"></a>

11. **匈奴及乌丸。** 简述南匈奴在汉末至魏的地位。乌丸部分叙部族来历、丘力居与蹋顿的归并，以及曹操北征后部众的安置。 [[11]](#note-11)

<a id="event-12"></a>

12. **鲜卑、轲比能与部落消长。** 叙檀石槐壮大及鲜卑内部变化，分列轲比能、步度根等部与魏廷往来、交战和相互冲突。 [[12]](#note-12)

<a id="event-13"></a>

13. **东夷叙例与夫余。** 篇首交代边郡道路与记录来源，再说明夫余地理、政制、风俗、祭礼和王系，并记其与高句丽、魏郡县之间的往来。 [[13]](#note-13)

<a id="event-14"></a>

14. **高句丽。** 记地理、婚俗、祭礼、狱法、诸部官号及与辽东、玄菟关系。正始年间毌丘俭征高句丽的节点可与卷028及《齐王纪》对读。 [[14]](#note-14)

<a id="event-15"></a>

15. **东沃沮与挹娄。** 描述东沃沮、北沃沮及海滨诸地习俗与粮食生产；挹娄部分记山地环境、衣食、居所、弓箭和与夫余的关系。 [[15]](#note-15)

<a id="event-16"></a>

16. **濊与韩。** 濊条写山川、同姓婚禁和祭祀；韩条分述马韩、辰韩、弁辰的国邑、物产和交易，并记录带方、乐浪及韩诸部交涉。 [[16]](#note-16)

<a id="event-17"></a>

17. **倭人诸国、卑弥呼遣使及论赞。** 依带方郡航路次序记诸国道里、邑落、物产和礼俗，又载倭女王卑弥呼遣使、魏廷授印、援解纠纷及王位更替。景初二年与景初三年有传本、旁证和辽东交通问题，按史料分别说明。 [[17]](#note-17)

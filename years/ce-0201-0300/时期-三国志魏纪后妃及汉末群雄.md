# 汉末魏初的帝纪、后妃与群雄

[本世纪目录](README.md) · [全部世纪](../README.md) · [《三国志》分卷目录](../../sources/三国志读本目录.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **曹操家世、入仕与在己吾起兵。** 曹操出自沛国谯县，祖曹腾为宦官，父曹嵩为其养子，本纪说曹嵩生家已不可考。桥玄、何颙早识曹操；他先后为洛阳北部尉、议郎和颍川讨黄巾的骑都尉。董卓废立后，曹操避出洛阳，至陈留出资募兵，冬十二月在己吾举兵。 [[1]](#note-1)

<a id="event-2"></a>

2. **讨董卓联盟与曹操入东郡。** 关东各军起兵推袁绍为盟主。董卓迁献帝至长安、焚洛阳宫室，诸军徘徊；曹操在汴水败给徐荣，随后招兵回河内。袁绍取冀州，曹操击破白绕，接掌东郡。 [[2]](#note-2)

<a id="event-3"></a>

3. **黄巾降兖、徐州用兵与兖州反叛。** 曹操先对付黑山军，又乘刘岱死取得兖州，击降青州黄巾，将所收精锐编为青州兵。袁术败于匡亭；曹操先后两次攻徐州，后一次因张邈、陈宫迎吕布而撤兵。荀彧、程昱保住少数县，曹操得以回攻。 [[3]](#note-3)

<a id="event-4"></a>

4. **兖州收复、迎献帝都许与攻灭吕布。** 曹操攻取定陶，重新控制兖州。他迎献帝到许后介入朝政，破杨奉并任司空。张绣先降后叛，曹昂、曹安民遇害；曹操后来在安众破敌，又围下邳擒杀吕布。袁绍并公孙瓒后，双方争夺祭朝权力和河北、河南各地。 [[4]](#note-4)

<a id="event-5"></a>

5. **官渡和袁氏兄弟之争。** 曹操先破刘备，后救白马、战延津、守官渡，并袭烧袁绍乌巢的储粮。袁绍败后仍经营河北，去世后袁谭、袁尚争立。曹操取邺后免河北当年租赋，以冀州为据。 [[5]](#note-5)

<a id="event-6"></a>

6. **汉中失守、樊城围解与曹操死。** 夏侯渊在汉中战死，曹操亲自到阳平后撤回。关羽趁大水俘于禁，徐晃进兵解樊城围，孙权也从荆州后方取地。曹操建安二十五年正月死于洛阳，遗命简葬；陈寿把其成功归于用人和谋略。 [[6]](#note-6)

<a id="event-7"></a>

7. **曹丕承袭魏王与延康政局。** 曹丕早任五官中郎将、丞相副手，后成为魏太子。曹操死后，他继为魏王、丞相，改建安二十五年为延康。此段记人事、边郡叛服、南下和地方献瑞。 [[7]](#note-7)

<a id="event-8"></a>

8. **黄初四至七年与曹丕遗命。** 曹丕禁私仇、立太学及课试法，巡淮、到广陵察看渡江条件。病重时命曹真、陈群、曹休和司马懿辅政。陈寿记其著述及《皇览》，并评其文才与处政。 [[8]](#note-8)

<a id="event-9"></a>

9. **平辽东及曹叡托孤。** 司马懿率军围襄平，公孙渊败死。明帝病重时任用曹爽、司马懿共辅少主，旋死于嘉福殿。陈寿称其决断，批评天下未合就大兴宫室。 [[9]](#note-9)

<a id="event-10"></a>

10. **高平陵政变后至嘉平五年。** 司马懿借皇帝出谒高平陵奏免曹爽兄弟，继而诛灭曹爽集团。王凌谋立楚王曹彪又败。魏吴先战东关，随后吴军围合肥新城而退。 [[10]](#note-10)

<a id="event-11"></a>

11. **李丰案、废齐王、迎曹髦。** 李丰等谋以夏侯玄代司马师，事败被诛。曹芳退位归藩，太后令立曹髦。曹髦入洛阳时辞前殿与法驾，司马师仍总军政。 [[11]](#note-11)

<a id="event-12"></a>

12. **曹髦遇害、身后礼及曹奂入继。** 曹髦死后，纪中连收太后令、诸臣奏和司马昭自陈，显示当时各方正式表述。曹奂原为常道乡公，入洛阳后即帝位；异说应并读《通鉴》及相关传。 [[12]](#note-12)

<a id="event-13"></a>

13. **咸熙改制、钟会之变及晋代魏。** 钟会在成都兵变，钟会、邓艾先后被杀。朝廷平蜀之后处理吴军、交州来附及屯田官。司马炎累进为晋世子，曹奂在咸熙二年末禅位。评价回溯明帝择嗣、少主废立及曹髦之死。 [[13]](#note-13)

<a id="event-14"></a>

14. **魏后宫名位与沿革。** 魏基本沿用汉朝太皇太后、皇太后、皇后等称号，内官品级经曹操、曹丕、曹叡增损。卷首列贵嫔以下各等可比官爵。 [[14]](#note-14)

<a id="event-15"></a>

15. **武宣卞氏及外家。** 卞氏出身倡家，早年从曹操至洛。曹操起兵时她劝部曲不要因误传而散。封王后、太后及追谥外亲牵涉陈群对因外戚分土授爵的意见。 [[15]](#note-15)

<a id="event-16"></a>

16. **甄氏由袁家到魏及追尊。** 甄氏幼时赈给亲里，原为袁熙妻；曹氏平邺后被曹丕所纳，生曹叡。她在黄初二年被赐死，曹叡即位后为其追谥、建庙，并优礼母族。 [[16]](#note-16)

<a id="event-17"></a>

17. **文德郭氏与外家约束。** 郭氏因机谋得宠，曹丕立她为皇后。她告诫亲族勿倚权势强婚，并拒过度役劳和厚葬。曹叡朝尊为太后，追封郭氏亲族。 [[17]](#note-17)

<a id="event-18"></a>

18. **毛皇后受宠与被赐死。** 毛氏由东宫受宠，曹叡即位后为皇后。郭氏得宠后，毛后因知北园曲宴一事触怒曹叡，被赐死。 [[18]](#note-18)

<a id="event-19"></a>

19. **明元郭氏临朝名义与陈寿总评。** 郭氏由河右大族入宫，在曹叡病重时被立为后；其太后名义见于曹爽被诛及曹芳、曹髦、曹奂诸次废立。陈寿比较魏与东汉外戚，并讨论朝廷约束。 [[19]](#note-19)

<a id="event-20"></a>

20. **董卓进京、迁都和遇诛。** 董卓在陇西结交羌中豪帅，后来领兵入洛阳，借禁中政变收并兵众，以废立擅权。关东各州郡举兵后，他把天子迁到长安，留军洛阳，并焚毁宫室。王允、士孙瑞与吕布约定内外响应，董卓入朝时被杀。 [[20]](#note-20)

<a id="event-21"></a>

21. **李傕郭汜据长安与献帝东归。** 董卓死后，李傕等因求赦未果听从贾诩，收兵围长安，掌控朝廷。李傕、郭汜互攻，各自扣押天子和公卿。献帝由杨奉等护送向洛阳，后由曹操迎都许。此段把不同年份的郭汜死和李傕覆灭连叙，需与《献帝纪》及《武帝纪》分年核查。 [[21]](#note-21)

<a id="event-22"></a>

22. **袁绍据河北及败于官渡。** 袁绍出身累世公卿之家，与何进谋诛宦官。反对董卓废立后出奔，从韩馥手中取得冀州，最终击败公孙瓒。迎天子、攻许、用将等事上，郭图、沮授和田丰意见不同。官渡败后，袁绍回河北收拾余部，建安七年病死。 [[22]](#note-22)

<a id="event-23"></a>

23. **袁谭、袁尚相争及河北改属。** 袁绍未定继承人，审配等立少子袁尚，袁谭不服。曹操一度答应援袁谭，继而围邺。袁尚离邺后投袁熙，袁谭收其军、在南皮抵抗曹操。 [[23]](#note-23)

<a id="event-24"></a>

24. **袁术在淮南称帝。** 袁术由洛阳走南阳，借兵孙坚与刘表争荆州，后来转至寿春。他用家世和图谶劝百官承认新位，主簿阎象以周文王仍事殷相劝。江淮饥馑、军资不足，袁术失势后死于路途。 [[24]](#note-24)

<a id="event-25"></a>

25. **刘表守荆州、刘琮举州降及史评。** 刘表以襄阳为根据，拒孙坚、控江汉。官渡相持时答应袁绍求助而未出兵。曹操南下时刘表病死，蔡瑁等扶刘琮继位，蒯越、傅巽等劝其降曹。陈寿合论董卓、袁术、袁绍、刘表的用人和成败。 [[25]](#note-25)

<a id="event-26"></a>

26. **吕布从并州到长安、河北。** 吕布杀丁原归董卓，后与王允合谋杀董卓。李傕等攻破长安后，吕布先求袁术容纳，继而依袁绍，与张燕作战，最终又离开袁绍。 [[26]](#note-26)

<a id="event-27"></a>

27. **张邈迎吕布、吕布败亡。** 曹操征徐州时，张邈、陈宫等迎吕布据兖州，张邈之弟张超后来死于雍丘。吕布转入徐州，夺下邳，与刘备、袁术时合时战。陈珪劝断袁术婚议；曹操围下邳后吕布被执而死。 [[27]](#note-27)

<a id="event-28"></a>

28. **陈宫与陈登。** 陈宫被俘后不请求曹操宽赦自身，把老母及女儿交给曹操处置。陈登与曹操夹攻吕布，以功迁伏波将军；刘备评他有湖海豪气。 [[28]](#note-28)

<a id="event-29"></a>

29. **臧洪发起会盟、拒袁绍及卷末评论。** 臧洪劝张超动员郡兵讨董卓，在诸郡结盟时登坛陈词。此后任袁绍所置东郡太守，因袁绍拒援张超而与其决裂，守城至粮尽。陈琳来书劝降而未能改变其决定；城陷后臧洪与陈容一同被杀。 [[29]](#note-29)

<a id="event-30"></a>

30. **公孙瓒边功、与刘虞冲突。** 公孙瓒以边将起家，参与征讨张纯，朝廷同时任刘虞安抚幽州。讨董之际袁绍、韩馥推刘虞为帝而受拒。公孙瓒与袁绍交兵失利，又与刘虞争权，最后杀刘虞。 [[30]](#note-30)

<a id="event-31"></a>

31. **易京战败与幽州部众归向。** 袁绍在书中数说公孙瓒先前交兵之事，后来围易京。公孙瓒多筑京垒自守，外援没有来得及解围，城破后自杀。鲜于辅、阎柔后来陆续接受朝命或归曹操。 [[31]](#note-31)

<a id="event-32"></a>

32. **陶谦治徐州及曹操两次东征。** 陶谦平徐州黄巾，以使者绕道通长安，又获州牧之任。曹操在初平四年与兴平元年两度东征；陶谦于后一年的交兵期间病死。 [[32]](#note-32)

<a id="event-33"></a>

33. **张杨拥护献帝回洛阳。** 张杨由西园部将转据河内，曾向献帝供粮并修洛阳宫室。曹操迎献帝都许后，张杨留屯野王；后来被部将杨丑所杀，眭固又杀杨丑。 [[33]](#note-33)

<a id="event-34"></a>

34. **公孙氏在辽东从起势到覆亡。** 公孙度以辽东太守割据海东，子康杀袁尚、袁熙并送首级。公孙恭接任后被公孙渊所夺。公孙渊接受魏吴两方往来，一度杀吴使，最终称燕王，司马懿围襄平后灭其政权。 [[34]](#note-34)

<a id="event-35"></a>

35. **张燕与张绣。** 张燕联络黑山诸部，与袁绍、公孙瓒等势力周旋，后率部降曹。张绣继张济屯宛，与刘表相援，依贾诩之谋先叛后再归曹操。 [[35]](#note-35)

<a id="event-36"></a>

36. **张鲁治理汉中、降魏与论赞。** 张鲁继祖父、父亲所传道法，设置祭酒和义舍，治理汉中。曹操攻阳平关后，张鲁退入巴地，未焚仓库，最终归降。陈寿把辽东、公孙瓒和其余割据者一同评说。 [[36]](#note-36)

## 《武帝纪》未定年、跨年及论说

下列材料按卷内次序列出。范围、相对次序及所据史料随引文列明。

<a id="wu-period-b-003-1"></a>

### 曹操籍贯与世系

[《三国志·武帝纪》仓内原文 L3](../../sources/本地分卷/三国志/三国志-卷001.md#l3)

> 太祖武皇帝，沛國譙人也，姓曹，諱操，字孟德，漢相國參之後。

曹操字孟德，沛国谯人，史书称其为汉相国曹参的后裔。

**时段与依据** 传首身份和家世，原书不载形成时间。

<a id="wu-period-b-003-3"></a>

### 曹嵩为曹腾养子并承嗣

[《三国志·武帝纪》仓内原文 L3](../../sources/本地分卷/三国志/三国志-卷001.md#l3)

> 養子嵩嗣，

曹腾养曹嵩为子，曹嵩承嗣。

**时段与依据** 收养和承嗣的确年均无记。

<a id="wu-period-b-003-5"></a>

### 曹嵩本生世系未详

[《三国志·武帝纪》仓内原文 L3](../../sources/本地分卷/三国志/三国志-卷001.md#l3)

> 莫能審其生出本末。

陈寿说曹嵩本生的家世无法审定。

**时段与依据** 作者说明世系证据的限度。

<a id="wu-period-b-003-6"></a>

### 曹操约生于155年

[《三国志·武帝纪》仓内原文 L3](../../sources/本地分卷/三国志/三国志-卷001.md#l3)

> 嵩生太祖。

曹嵩生曹操。据曹操卒年年龄可推其约生于永寿元年。

**时段与依据** 据同卷 L124 载建安二十五年（220）曹操卒、年六十六，按传统虚岁回推为155年。《后汉书》桓帝纪为永寿元年；本句不载生年月。

<a id="wu-period-b-004-1"></a>

### 曹操少时与桥玄、何颙品评

[《三国志·武帝纪》仓内原文 L4](../../sources/本地分卷/三国志/三国志-卷001.md#l4)

> 太祖少機警，有權數，而任俠放蕩，不治行業，故世人未之奇也；惟梁國橋玄、南陽何顒異焉。玄謂太祖曰：「天下將亂，非命世之才不能濟也，能安之者，其在君乎！」

曹操少时机警善权变、任侠不拘，桥玄、何颙器重他，桥玄预言他可能安定天下。

**时段与依据** 传文仅称“少”；《后汉书》桥玄传载曹操少时见桥玄，但未记会见确年。

<a id="wu-period-b-004-2"></a>

### 曹操约174年举孝廉为郎

[《三国志·武帝纪》仓内原文 L4](../../sources/本地分卷/三国志/三国志-卷001.md#l4)

> 年二十，舉孝廉爲郎，

曹操二十岁时被推举为孝廉，入朝为郎。

**时段与依据** 据本纪 L124 的220年卒、年六十六，按虚岁生年155推为174；原书仅记年龄。

<a id="wu-period-b-004-3"></a>

### 曹操任洛阳北部尉、顿丘令、议郎

[《三国志·武帝纪》仓内原文 L4](../../sources/本地分卷/三国志/三国志-卷001.md#l4)

> 除洛陽北部尉，遷頓丘令，徵拜議郎。

曹操又任洛阳北部尉，迁顿丘令，后被征拜议郎。

**时段与依据** 本纪将三官续叙于二十岁举孝廉之后、184年讨黄巾之前，各任没有独立年纪，不能把三次任命并系举孝廉之年。 《后汉书·刘陶传》明记曹操光和五年（182）已以议郎身份与陈耽上书，初拜之年仍不详。

<a id="wu-period-b-005-2"></a>

### 曹操任济南相，罢治贪吏与淫祀

[《三国志·武帝纪》仓内原文 L5](../../sources/本地分卷/三国志/三国志-卷001.md#l5)

> 遷爲濟南相，國有十餘縣，長吏多阿附貴戚，贓污狼藉，於是奏免其八；禁斷淫祀，姦宄逃竄，郡界肅然。

曹操迁为济南相，奏免阿附贵戚且贪污的八县长吏，禁止非礼的祭祀活动，地方治安好转。

**时段与依据** 明在中平元年从军以后、为典军校尉以前；本书仅记“遷”，任命和一系列处置无独立年记。

<a id="wu-period-b-005-3"></a>

### 曹操辞东郡太守、称病居乡

[《三国志·武帝纪》仓内原文 L5](../../sources/本地分卷/三国志/三国志-卷001.md#l5)

> 久之，徵還爲東郡太守；不就，稱疾歸鄉里。

久后曹操被征任东郡太守，他推辞称病返乡。

**时段与依据** 传文“久之”不能精确换算；区别于191年袁绍表曹操为东郡太守。

<a id="wu-period-b-013-2"></a>

### 袁绍向曹操示玉印

[《三国志·武帝纪》仓内原文 L13](../../sources/本地分卷/三国志/三国志-卷001.md#l13)

> 紹又甞得一玉印，於太祖坐中舉向其肘，太祖由是笑而惡焉。

袁绍曾得一枚玉印，在与曹操同座时举给他看，曹操暗自反感。

**时段与依据** 本纪仅称“甞”；与拥刘虞一事相邻，未提供与当年或同次会面相锁的证据。

<a id="wu-period-b-024-2"></a>

### 孙策数年间经营江东

[《三国志·武帝纪》仓内原文 L24](../../sources/本地分卷/三国志/三国志-卷001.md#l24)

> 數年閒遂有江東。

孙策渡江后用数年时间建立江东基业。

**时段与依据** 本纪明说“數年閒”，综合叙述渡江、据会稽及往后平定诸郡，未给出一个完成年。

<a id="wu-period-b-025-2"></a>

### 曹嵩去官后避难琅邪

[《三国志·武帝纪》仓内原文 L25](../../sources/本地分卷/三国志/三国志-卷001.md#l25)

> 初，太祖父嵩去官後還譙，董卓之亂，避難琅邪，

曹操父曹嵩卸任后返谯，董卓之乱时避难琅邪。

**时段与依据** 《后汉书·灵帝纪》188年载曹嵩罢太尉；L25的居谯和避琅邪只知在董卓之乱期间，不能系一个年。

<a id="wu-period-b-033-1"></a>

### 何仪等此前曾依附袁术和孙坚

[《三国志·武帝纪》仓内原文 L33](../../sources/本地分卷/三国志/三国志-卷001.md#l33)

> 汝南、潁川黃巾何儀、劉辟、黃邵、何曼等，衆各數萬，初應袁術，又附孫堅。

汝南、颍川的何仪、刘辟、黄邵、何曼等各有数万人，先响应袁术，又依附孙坚。

**时段与依据** 本纪用“初”回叙，孙坚在191至193年间已去世，明非196年；各部首次依附的年不明。可在196年第28条以此前背景互参，不把背景发生年系196。

<a id="wu-period-b-033-11"></a>

### 献帝西迁后朝政日乱

[《三国志·武帝纪》仓内原文 L33](../../sources/本地分卷/三国志/三国志-卷001.md#l33)

> 自天子西遷，朝廷日亂，

从献帝迁往长安起，朝廷逐渐陷于混乱。

**时段与依据** 由190年西迁至196年迁许的多年总述；非独记本年一事。

<a id="wu-period-b-041-8"></a>

### 臧霸等在泰山、徐州聚众

[《三国志·武帝纪》仓内原文 L41](../../sources/本地分卷/三国志/三国志-卷001.md#l41)

> 太山臧霸、孫觀、吳敦、尹禮、昌狶各聚衆。

臧霸与孙观、吴敦、尹礼、昌狶分别聚众。

**时段与依据** 本纪回叙；卷018《臧霸传》说臧霸从陶谦击黄巾后聚众、屯开阳；无各部聚众的确年。

<a id="wu-period-b-042-1"></a>

### 曹操任毕谌为别驾

[《三国志·武帝纪》仓内原文 L42](../../sources/本地分卷/三国志/三国志-卷001.md#l42)

> 初，公爲兗州，以東平畢諶爲別駕。

曹操治兖州时任命东平人毕谌为别驾。

**时段与依据** 初平三年起曹操领兖州；本句未载任命年月，可约束在192年领兖州后至194年张邈反叛前。

<a id="wu-period-b-044-1"></a>

### 曹操举魏种孝廉

[《三国志·武帝纪》仓内原文 L44](../../sources/本地分卷/三国志/三国志-卷001.md#l44)

> 初，公舉種孝廉。

曹操先前举荐魏种为孝廉。

**时段与依据** 《通鉴》卷六十三明言在兖州时，早于兴平元年张邈叛，确年待考。

<a id="wu-period-b-054-1"></a>

### 桓帝朝黄星传闻

[《三国志·武帝纪》仓内原文 L54](../../sources/本地分卷/三国志/三国志-卷001.md#l54)

> 初，桓帝時有黃星見於楚、宋之分，遼東殷馗善天文，言後五十歲當有真人起於梁、沛之閒，其鋒不可當。

据纪文，桓帝时楚宋一带见黄星，遼东殷馗以此预言梁沛一带将兴起强人。

**时段与依据** 桓帝朝约146至167，首段无确年；“五十年”为应验叙事，无法据以精确反推天象年月。

<a id="wu-period-b-069-1"></a>

### 袁绍任高干领并州

[《三国志·武帝纪》仓内原文 L69](../../sources/本地分卷/三国志/三国志-卷001.md#l69)

> 初，袁紹以甥高幹領并州牧，

袁绍任外甥高干领并州牧。

**时段与依据** 《后汉书·袁绍传》记袁氏分命诸子及高干据州，无确年。高干初领与204复任须拆。

<a id="wu-period-b-071-1"></a>

### 三郡乌丸进入幽州

[《三国志·武帝纪》仓内原文 L71](../../sources/本地分卷/三国志/三国志-卷001.md#l71)

> 三郡烏丸承天下亂，破幽州，略有漢民合十餘萬戶。

三郡乌丸乘汉末动乱侵扰幽州，控制十余万户汉民。

**时段与依据** 《武帝纪》《乌丸传》《通鉴》为一段时期背景，具体起讫均未载。

<a id="wu-period-b-071-3"></a>

### 蹋顿受袁绍厚待

[《三国志·武帝纪》仓内原文 L71](../../sources/本地分卷/三国志/三国志-卷001.md#l71)

> 遼西單于蹋頓尤彊，爲紹所厚，

辽西单于蹋顿势力强盛，袁绍对他颇为优厚。

**时段与依据** 袁绍在世相交，《乌丸传》与《后汉书·乌桓列传》记当中始末。

陇西宋建聚众枹罕，称河首平汉王，另用年号、设置百官，持续三十余年。

陈寿回顾汉末大乱、群雄并立，认为袁绍曾雄踞四州、势力强盛。

<a id="wu-period-b-125-2"></a>

### 陈寿评价曹操的谋略和用人

[《三国志·武帝纪》仓内原文 L125](../../sources/本地分卷/三国志/三国志-卷001.md#l125)

> 太祖運籌演謀，鞭撻宇內，擥申、商之法術，該韓、白之奇策，官方授材，各因其器，矯情任筭，不念舊惡，終能總御皇機，克成洪業者，惟其明略最優也。

陈寿称曹操善于筹划，兼采申不害、商鞅的治政方法与韩信、白起的兵略，任官量才，抑制个人情绪、不计旧怨，终于主持国政。

**时段与依据** 陈寿史论概括曹操生涯，涉及多年，并未标明评语作年。

陈寿最后称曹操是才略出众的非常之人。

**时段与依据** 篇末评价，无可归之单一年。

<a id="wu-period-p-001-1"></a>

### 曹操别名及曹氏上古世系的说法

[《三国志·武帝纪》裴注 001·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-001-1)

> 太祖一名吉利小字阿瞞王沈魏書曰其先出於黃帝當高陽世陸終之子曰安是為曹姓周武王克殷存先世之後封曹俠於邾春秋之世與於盟會逮至戰國為楚所滅子孫分流或家于沛

曹操一名吉利、小字阿瞒。王沈《魏书》上推祖源到黄帝、高阳、陆终与曹安，据称周武王封曹侠于邾，春秋时参与盟会，战国为楚所灭，后人流散，部分居沛。

**时段与依据** 《魏书》累计叙述数代和多个时代，不能连成可逐年判定的世系；邾为楚所灭的年份亦未见本句或同事确证。

<a id="wu-period-p-001-3"></a>

### 曹参后代袭封和恢复

[《三国志·武帝纪》裴注 001·3](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-001-3)

> 世襲爵土絶而復紹至今適嗣國於容城

曹氏后代继承爵土，中间断绝后又恢复；《魏书》叙至编者时代嫡嗣居容城。

**时段与依据** 多代合述。东汉建初二年（77）章帝重新封曹湛为平阳侯，可互见77年第9条，但本注未逐代说明断绝、恢复及转封容城的具体年份。

<a id="wu-period-p-002-1"></a>

### 曹腾家世、父曹节让猪与初仕

[《三国志·武帝纪》裴注 002·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-002-1)

> 司馬彪續漢書曰騰父節字元偉素以仁厚稱鄰人有亡豕者與節豕相類詣門認之節不與爭後所亡豕自還其家豕主人大慙送所認豕幷辭謝節節笑而受之由是鄉黨貴歎焉長子伯興次子仲興次子叔興騰字季興少除黃門從官

《续汉书》说曹节仁厚，有邻人误认曹节家的猪，曹节不争，邻人找回自家猪才送还致歉；又举曹节四子，称曹腾少时任黄门从官。

**时段与依据** 让猪与曹氏兄弟无确年。《后汉书·曹腾传》仅称他在安帝朝任黄门从官。

<a id="wu-period-p-002-4"></a>

### 曹腾历仕与荐举

[《三国志·武帝纪》裴注 002·4](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-002-4)

> 遷至中常侍大長秋在省闥三十餘年歴事四帝未嘗有過好進達賢能終無所毁傷其所稱薦若陳留虞放邊韶南陽延固張温弘農張奐潁川堂谿典等皆致位公卿而不伐其善

曹腾后来迁中常侍、大长秋，在宫中任事三十余年、经历四帝，推荐虞放、边韶等人，不自居功。

**时段与依据** 分属多朝；《后汉书》L5572说明中常侍在顺帝时，大长秋在桓帝得立后，本句为合述。

<a id="wu-period-p-002-5"></a>

### 种暠劾曹腾未成

[《三国志·武帝纪》裴注 002·5](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-002-5)

> 蜀郡太守因計吏修敬於騰益州刺史种暠於函谷關搜得其牋上太守并奏騰内臣外交所不當為請免官治罪帝曰牋自外來騰書不出非其罪也乃寢暠奏騰不以介意常稱歎暠以為暠得事上之節

益州刺史种暠搜得蜀郡太守给曹腾的信，认为其不当结交外官，请治罪。皇帝以信由外面寄来为由不追究，曹腾也称赏种暠尽职，未记恨他。

**时段与依据** 《后汉书·曹腾传》L5573 并载，但未系年；该书所载地名作斜谷关，与注作函谷关有异。

### 曹嵩早年官职及操守

> 續漢書曰嵩字巨高質性敦愼所在忠孝為司隸校尉

《续汉书》称曹嵩字巨高，为人谨慎忠孝，曾任司隶校尉。

**时段与依据** 曹嵩司隶校尉任年未见。此处仅转录《续汉书》对曹嵩的品评与职官记载。

[《三国志·武帝纪》裴注 003·2](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-003-2)

> 靈帝擢拜大司農大鴻臚

注引《续汉书》称灵帝擢曹嵩为大司农、大鸿胪。

**时段与依据** 《灵帝纪》只可确证187年由大司农迁太尉。注中并列两官，先后与各任年不详。

<a id="wu-period-p-003-5"></a>

### 曹嵩出身夏侯氏异说

[《三国志·武帝纪》裴注 003·5](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-003-5)

> 吳人作曹瞞傳及郭頒世語並云嵩夏侯氏之子夏侯惇之叔父太祖於惇為從父兄弟

《曹瞒传》和郭颁《世语》都称曹嵩出自夏侯氏，是夏侯惇的叔父；照此说，曹操与夏侯惇同祖父。

**时段与依据** 异说只于传首交代家世，本纪称“莫能審其生出本末”；无从依这两说确定收养年。

<a id="wu-period-p-004-1"></a>

### 曹操少时装病骗过叔父

[《三国志·武帝纪》裴注 004·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-004-1)

> 曹瞞傳云太祖少好飛鷹走狗游蕩無度其叔父數言之於嵩太祖患之後逢叔父於路乃陽敗面喎口叔父怪而問其故太祖曰卒中惡風叔父以告嵩嵩驚愕呼太祖太祖口貌如故嵩問曰叔父言汝中風已差乎太祖曰初不中風但失愛於叔父故見罔耳嵩乃疑焉自後叔父有以告嵩終不復信太祖於是益得肆意矣

《曹瞒传》说曹操年少时爱放鹰走狗，被叔父屡次告知父亲曹嵩。曹操假装中风，叔父报告后曹嵩召见却发现他神色正常，自此不再相信叔父的议论。

**时段与依据** 原注只说“少”“後”，没有年。底本署名为《曹瞞傳》；点校影印相关校补及异文见卷页校记。

<a id="wu-period-p-005-1"></a>

### 桥玄识曹操及桥玄为人

[《三国志·武帝纪》裴注 005·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-005-1)

> 魏書曰太尉橋玄世名知人覩太祖而異之曰吾見天下名士多矣未有若君者也君善自持吾老矣願以妻子為託由是聲名益重續漢書曰玄字公祖嚴明有才略長於人物張璠漢紀曰玄歴位中外以剛斷稱謙儉下士不以王爵私親

《魏书》记桥玄十分看重曹操，并想托付妻儿，曹操因此知名。《续汉书》说桥玄有才略、善识人；张璠《汉纪》说他任职中外、刚断谦俭。

**时段与依据** 《后汉书·桥玄传》L3865说曹操微时拜见，无确年。在引文中“太尉”可以是回称，不能直接当会见时的现职。

<a id="wu-period-p-005-5"></a>

### 曹操见许劭、闯张让宅及研究兵法

[《三国志·武帝纪》裴注 005·5](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-005-5)

> 世語曰玄謂太祖曰君未有名可交許子將太祖乃造子將子將納焉由是知名孫盛異同雜語云太祖嘗私入中常侍張讓室讓覺之乃舞手㦸於庭踰垣而出才武絶人莫之能害博覽羣書特好兵法抄集諸家兵法名曰接要又注孫武十三篇皆傳於世嘗問許子將我何如人子將不答固問之子將曰子治世之能臣亂世之姦雄太祖大笑

《世语》称桥玄荐曹操去见许劭，曹操因而取得声名。孙盛说曹操闯入张让居处后挥戟翻墙脱身，遍览群书、编《接要》并注《孙武》十三篇，又问许劭自己怎样，许劭以“治世之能臣、乱世之姦雄”品评。

**时段与依据** 会见许劭、越墙、著述均未明年。《后汉书·许劭传》另记品评措辞，不能用赞语在本纪的位置定著述年。

<a id="wu-period-p-006-1"></a>

### 曹操任北部尉立五色棒，后迁顿丘

[《三国志·武帝纪》裴注 006·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-006-1)

> 曹瞞傳曰太祖初入尉廨繕治四門造五色棒縣門左右各十餘枚有犯禁者不避豪彊皆棒殺之後數月靈帝愛幸小黃門蹇碩叔父夜行卽殺之京師歛迹莫敢犯者近習寵臣咸疾之然不能傷於是共稱薦之故遷為頓丘令

《曹瞒传》说曹操整饬尉署，设五色棒，违禁不避权贵。数月后，他棒杀小黄门蹇硕的叔父；宫中权贵因而忌恨，反借举荐将他调做顿丘令。

**时段与依据** 仅“初入”“後數月”，与正文L4的任职先后吻合；各事件年月均无独立记载，不以举孝廉推年硬定。

> 後以能明古學復徵拜議郎

曹操通晓古学，后来又被征任议郎。

> 太祖上書陳武等正直而見陷害姦邪盈朝善人壅塞其言甚切靈帝不能用

曹操上书为窦武和陈蕃申辩，指斥宦官壅塞忠直之士，灵帝未采纳。

### 曹操此后停止献言

> 是後政敎日亂豪猾益熾多所摧毁太祖知不可匡正遂不復獻言

《魏书》称此后政教愈乱、豪猾益炽，曹操认为难以挽回，停止进言。

<a id="wu-period-p-008-1"></a>

### 曹操任济南相举免贪吏，毁禁淫祠

[《三国志·武帝纪》裴注 008·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-008-1)

> 魏書曰長吏受取貪饕依倚貴勢歴前相不見舉聞太祖至咸皆舉免小大震怖姦宄遁逃竄入他郡政敎大行一郡淸平初城陽景王劉章以有功於漢故其國為立祠靑州諸郡轉相倣效濟南尤盛至六百餘祠賈人或假二千石輿服導從作倡樂奢侈日甚民坐貧窮歴世長吏無敢禁絶者太祖到皆毁壞祠屋止絶官吏民不得祠祀

《魏书》交代官吏依倚权贵聚财，曹操到任后奏免，奸宄外逃；又记城阳祭刘章的祠俗扩散，济南多至六百余所，曹操毁祠禁祀。

**时段与依据** 同正文L5，接184年讨黄巾、在188年任典军校尉以前；刘章封王及定吕功可分别互参前178年及前180年，兴建其祠与曹操取缔不能跟着封王年入年。

**时段与依据** 原注推论长期成效，未举特定一道政令和年号。

### 曹操请求留宿卫，托病归乡居处

[《三国志·武帝纪》裴注 009·1](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-009-1)

> 魏書曰於是權臣專朝貴戚横恣太祖不能違道取容數數干忤恐為家禍遂乞留宿衛拜議郎常託疾病輒告歸鄉里築室城外春夏習讀書傳秋冬弋獵以自娛樂

曹操抵触专权的贵戚，担心祸及家族，请留任宿卫，拜议郎；又多次称病返乡，筑屋城外，春夏读书，秋冬打猎。

### 王次仲、师宜官与梁鹄书法旧事

> 衞恒四體書勢序曰上谷王次仲善隸書始為楷法至靈帝好書世多能者而師宜官為最甚矜其能每書輒削焚其札梁鵠乃益為版而飲之酒候其醉而竊其札鵠卒以攻書至選部尚書

《四体书势》说王次仲创楷法，灵帝好书时师宜官名气最大；梁鹄得其手迹苦学，后做到选部尚书。

### 梁鹄昔任曹操为洛阳北部尉，后依刘表

[《三国志·武帝纪》裴注 072·2](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-072-2)

> 於是公欲為洛陽令鵠以為北部尉鵠後依劉表

据卫恒，曹操欲为洛阳令，梁鹄当时改任其为北部尉；梁鹄后来投奔刘表。

**时段与依据** 北部尉是曹操早年官职，具体年份未明；梁鹄投刘表在曹操取荆州以前的年代待考。

<a id="wu-period-p-072-4"></a>

### 曹操赏梁鹄书法，魏宫殿题署多出自梁鹄

[《三国志·武帝纪》裴注 072·4](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-072-4)

> 公嘗懸著帳中及以釘壁玩之謂勝宜官鵠字孟黃安定人魏宫殿題署皆鵠書也

曹操悬挂梁鹄的书迹观玩，认为书法胜过师宜官；史料又称魏宫殿所题文字多出自梁鹄。

**时段与依据** 二事是延后持续的实践，具体时间不详，不能与208征用强并。

<a id="wu-period-p-072-5"></a>

### 王俊早年与曹操为友，并谈袁氏

[《三国志·武帝纪》裴注 072·5](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-072-5)

> 皇甫謐逸士傳曰汝南王儁字子文少為范滂許章所識與南陽岑晊善公之為布衣特愛儁儁亦稱公有治世之具及袁紹與弟術喪母歸葬汝南儁與公會之會者三萬人公於外密語儁曰天下將亂為亂魁者必此二人也欲濟天下為百姓請命不先誅此二子亂今作矣儁曰如卿之言濟天下者舍卿復誰相對而笑

《逸士传》记王俊早年为范滂、许章所知，亲善于岑晊、曹操。袁氏兄弟归葬母亲，曹操与王俊私下谈到袁氏可能引发天下大乱。

**时段与依据** 曹操布衣时及袁氏母丧为相对年代，未载确年。

<a id="wu-period-p-072-6"></a>

### 王俊避地武陵，献帝都许后拒绝出仕

[《三国志·武帝纪》裴注 072·6](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-072-6)

> 儁為人外静而内明不應州郡三府之命公車徵不到避地居武陵歸儁者一百餘家帝之都許復徵為尚書又不就

王俊先后辞州郡和公府之请，避居武陵，百余家归附；献帝迁许后再征为尚书，他仍不就。

**时段与依据** 迁许是196年的起点，本次召用只知在196之后、新一段劝刘表/去世之前。

<a id="wu-period-p-072-7"></a>

### 王俊劝刘表无倚仗袁绍，卒于武陵

[《三国志·武帝纪》裴注 072·7](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-072-7)

> 劉表見紹彊陰與紹通儁謂表曰曹公天下之雄也必能興霸道繼桓文之功者也今乃釋近而就逺如有一朝之急遥望漠北之救不亦難乎表不從儁年六十四以壽終於武陵公聞而哀傷

刘表暗通袁绍；王俊称曹操可成霸业、不应舍近求远，刘表未听，王俊后六十四岁死。

**时段与依据** 谈话约束在刘表治荆州及袁绍仍在世时；王俊卒年只能定在曹操迎葬即208年以前。

曹操说自己早年被举孝廉，希望治理一郡、建立声誉。

**时段与依据** 令出210年；正文称年二十举孝廉，依传统虚岁约174，明确年月未载。

**时段与依据** 袁谭205年被曹操斩、袁尚207年被公孙康斩送首级，同一谓语总括两年，分见205年第1条及207年第4条。

《江表传》载献帝问孔融郗虑所长，孔融说他足以共学而不足权变，郗虑反讥孔融治理北海失当，二人不睦，曹操写信劝和。

《曹瞒传》说曹操为王后在邺召司马防饮酒，半开玩笑问自己还能否作尉，司马防回答从前正适合做尉，曹操大笑。

**时段与依据** 作者考辨，无独立史事年份。

### 曹操命征辟王必统领长史事务

《魏武故事》保存曹操任命文，赞王必自创业之初追随、忠勤坚定，命征辟并仍由他以领长史主持事务。

《魏书》称曹操善识人，不拘微贱，从军中拔于禁、乐进，从降将中用张辽、徐晃，又擢用众多出身卑微的人为地方长官。

[《三国志·武帝纪》裴注 117·3](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-117-3)

> 是以剏造大業文武並施御軍三十餘年手不捨書晝則講武䇿夜則思經傳登高必賦及造新詩被之管絃皆成樂章才力絶人手射飛鳥躬禽猛獸常於南皮一日射雉獲六十三頭及造作宫室繕制器械無不為之法則皆盡其意

> 雅性節儉不好華麗後宫衣不錦繡侍御履不二采帷帳屏風壞則補納茵蓐取温無有緣飾攻城拔邑得靡麗之物則悉以賜有功勲勞宜賞不吝千金無功望施分毫不與四方獻御與羣下共之常以送終之制襲稱之數繁而無益俗又過之故預自制終亡衣服四篋而已

《魏书》说后宫避免织绣饰物，寝具破了就补；战利品赏有功者，功应赏时不吝，亦不滥赏；以丧制用衣繁冗，预备殓服只四箱。

**时段与依据** 总叙生前习惯，没有按年记载所述赏赐、备衣。

### 傅子记曹操节俭嫁女

[《三国志·武帝纪》裴注 117·5](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-117-5)

> 傅子曰太祖愍嫁娶之奢僭公女適人皆以皁帳從婢不過十人

《傅子》说曹操不满婚嫁奢华，女儿出嫁用黑帐，从婢不超过十人。

**时段与依据** 只见行为惯例，无特定婚嫁或年份。

<a id="wu-period-p-117-6"></a>

### 博物志记曹操艺能与方术

[《三国志·武帝纪》裴注 117·6](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-117-6)

> 張華博物志曰漢世安平崔瑗瑗子實弘農張芝芝弟昶並善草書而太祖亞之桓譚蔡邕善音樂馮翊山子道王九眞郭凱等善圍棋太祖皆與埓能又好養性法亦解方藥招引方術之士廬江左慈譙郡華佗甘陵甘始陽城郄儉無不畢至又習啖野葛至一尺亦得少多飲鴆酒

《博物志》拿曹操与崔瑗、张芝等书家及音乐、弈棋高手相比，又称其研习养生与方药，招左慈、华佗等方术之士，并有野葛、鸩酒的传说。

**时段与依据** 合述一个长时期的艺能与方术故事，未逐项标时，异事仍按原书说法。

<a id="wu-period-p-117-7"></a>

### 傅子记曹操制定帢帽

[《三国志·武帝纪》裴注 117·7](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-117-7)

> 傅子曰漢末王公多委王服以幅巾為雅是以袁紹崔豹之徒雖為將帥皆著縑巾魏太祖以天下凶荒資財乏匱擬古皮弁裁縑帛以為帢合于簡易隨時之義以色别其貴賤于今施行可謂軍容非國容也

《傅子》说汉末王公以幅巾为雅，曹操因财用不足仿古皮弁裁帛为帢，以颜色辨贵贱，认为这是军中服制。

**时段与依据** 文只明“漢末”及长期施行，未记制定确年。

<a id="wu-period-p-117-8"></a>

### 曹瞒传论曹操日常与严刑

[《三国志·武帝纪》裴注 117·8](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-117-8)

> 曹瞞傳曰太祖為人佻易無威重好音樂倡優在側常以日達夕被服輕綃身自佩小鞶囊以盛手巾細物時或冠帢㡌以見賔客每與人談論戲弄言誦盡無所隱及歡悅大笑至以頭没柸案中肴膳皆沾汚巾幘其輕易如此然持法峻刻諸將有計畫勝出己者隨以法誅之及故人舊怨亦皆無餘其所刑殺輙對之垂涕嗟痛之終無所活

《曹瞒传》称曹操喜乐舞、服饰轻便、谈笑戏谑而少威仪，同时称其用法苛严，对谋略胜己者及旧怨者不宽贷，行刑时虽落泪仍处死。

**时段与依据** 生平评价，与《魏书》立场并列，未见单一史事日期。

<a id="wu-period-p-117-9"></a>

### 袁忠欲依法治曹操，桓邵轻曹操

[《三国志·武帝纪》裴注 117·9](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-117-9)

> 初袁忠為沛相嘗欲以法治太祖沛國桓邵亦輕之

《曹瞒传》称沛相袁忠曾想依法处治曹操，沛国桓邵也轻视曹操。

**时段与依据** “初”起追叙，未给事件年份；《后汉书·袁安传》记袁忠初平年间（190–193）任沛相，不能缩至一个年。

<a id="wu-period-p-117-10"></a>

### 曹操诛边让及其家

[《三国志·武帝纪》裴注 117·10](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-117-10)

> 及在兖州陳留邊讓言議頗侵太祖太祖殺讓族其家

《曹瞒传》称曹操在兖州时，陈留边让出言冒犯，曹操杀边让并族其家。

**时段与依据** 《通鉴》卷061叙入194年兖州叛变的前因，使用“嘗”，《后汉书·边让传》称建安中，《袁绍传》所录陈琳檄文把此事放在失兖州前，纪年相冲，暂归时期。

<a id="wu-period-p-117-11"></a>

### 袁忠、桓邵避交州及曹操追杀的异载

[《三国志·武帝纪》裴注 117·11](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-117-11)

> 忠邵俱避難交州太祖遣使就太守士燮盡族之桓邵得出首拜謝於庭中太祖謂曰跪可解死邪遂殺之

《曹瞒传》称袁忠、桓邵逃往交州，曹操遣使通知士燮诛其族，桓邵出来自首仍被处死。

**时段与依据** 原注未标年；《后汉书·袁安传》称袁忠徵为卫尉未到而卒，与此说须保留分别，不能因边让之事推定年。

<a id="wu-period-p-117-12"></a>

### 曹操军中禁践麦与割发

[《三国志·武帝纪》裴注 117·12](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-117-12)

> 常出軍行經麥中令士卒無敗麥犯者死騎士皆下馬付麥以相持於是太祖馬騰入麥中勑主簿議罪主簿對以春秋之義罰不加於尊太祖曰制法而自犯之何以帥下然孤為軍帥不可自殺請自刑因援劒割髮以置地

《曹瞒传》记曹操下令禁军士践麦，自马入麦后要求议罚；主簿援引尊者不受罚，曹操遂割发作为自刑。

**时段与依据** 只记“常出軍”，无地无年，不能以小说情节替史料定年。

《曹瞒传》称侍妾没有照嘱咐叫醒熟睡的曹操，曹操醒来把她打死。

### 曹操以小斛给粮并斩粮吏的记载

[《三国志·武帝纪》裴注 117·14](../../sources/摘录/三国志-卷001-武帝纪裴注.md#pei-117-14)

> 常討賊廪穀不足私謂主者曰如何主者曰可以小斛以足之太祖曰善後軍中言太祖欺衆太祖謂主者曰特當借君死以厭衆不然事不解乃斬之取首題徇曰行小斛盜官穀斬之軍門其酷虐變詐皆此之類也

《曹瞒传》称一次军粮不足，曹操同意用小斛发粮；军中不满时，他借粮吏之死平众议，宣称粮吏盗粮。

**时段与依据** 原注不载讨何人、何地与何年，不能据后世演义推定。

## 《文帝纪》跨年及未定年材料

<a id="period-sgz002-b-127-1"></a>

### 曹丕名号及家世

[《三国志·文帝纪》仓内原文 L127](../../sources/本地分卷/三国志/三国志-卷002.md#l127)

> 文皇帝諱丕，字子桓，武帝太子也。

魏文帝曹丕字子桓，是曹操之子。

**时段与依据** 纪首名号、家世，无独立事年。

<a id="period-sgz002-b-164-1"></a>

### 曹丕的文学著述

[《三国志·文帝纪》仓内原文 L164](../../sources/本地分卷/三国志/三国志-卷002.md#l164)

> 初，帝好文學，以著述爲務，自所勒成垂百篇。

曹丕长期从事著述，本纪记他亲自撰成约百篇。

**时段与依据** “初”回叙一生志趣及累积著述；裴注引《魏书》有东宫时的著述线索，无逐作完成年月。

<a id="period-sgz002-b-164-2"></a>

### 曹丕命诸儒按类编纂《皇览》

[《三国志·文帝纪》仓内原文 L164](../../sources/本地分卷/三国志/三国志-卷002.md#l164)

> 又使諸儒撰集經傳，隨類相從，凡千餘篇，號曰《皇覽》。

曹丕使儒者把经传典籍按内容归类，成千余篇，题《皇览》。

**时段与依据** 《刘劭传》（TXT L1156）写黄初中受诏，故保留220至226年期间。

<a id="period-sgz002-b-165-1"></a>

### 陈寿评曹丕

[《三国志·文帝纪》仓内原文 L165](../../sources/本地分卷/三国志/三国志-卷002.md#l165)

> 評曰：文帝天資文藻，下筆成章，博聞彊識，才藝兼該；若加之曠大之度，勵以公平之誠，邁志存道，克廣德心，則古之賢主，何遠之有哉！

陈寿赞曹丕能文博学、多才多艺，也认为尚须更宽宏、公平、广德。

**时段与依据** 陈寿评语不属于曹丕在位某年。

<a id="period-sgz002-p-001-2"></a>

### 曹丕少时作文并学骑射击剑

[《三国志·文帝纪》裴注 001·2](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-001-2)

> 年八歲能屬文有逸才遂博貫古今經傳諸子百家之書善騎射好擊劒舉茂才不行

曹丕八岁能作文，广读经传百家，善骑射、击剑，曾被举为茂才而未就。

**时段与依据** 若从187年冬按虚岁算，八岁约194年；读书及茂才无确年。

### 高元吕为曹丕相面

[《三国志·文帝纪》裴注 002·1](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-002-1)

> 魏畧曰太祖不時立太子太子自疑是時有高元吕者善相人乃呼問之對曰其貴乃不可言問壽㡬何元吕曰其壽至四十當有小苦過是無憂也

《魏略》说曹操迟迟未定储嗣时，曹丕召高元吕相问。高元吕预言极贵并说四十岁会有小灾。

**时段与依据** 在217年立魏太子前，“無㡬”未明历年。

裴注指向《王凌传》所载黄华后任兖州刺史。

**时段与依据** 《王凌传》可知其251年已在该职，始任年月不载。

### 《王凌传》可见黄华后来任兖州刺史

<a id="period-sgz002-p-023-1"></a>

### 《献帝传》禅代文书的四库电子异文

> 獻帝傳載禪代衆事曰左中郎將李伏表魏王曰昔先王初建魏國在境外者聞之未審皆以為拜王武都李庶姜合覉旅漢中謂臣曰必為魏公未便王也定天下者魏公子桓神之所命當合符䜟以應天人之位臣以合辭語鎮南將軍張魯魯亦問合知書所出合曰孔子玉版也天子歴數雖百世可知是後月餘有亡人來寫得册文卒如合辭合長於内學闗右知名魯雖有懷國之心沈溺異道變化不果寤合之言後密與臣議䇿質國人不協或欲西通魯即怒曰寧為魏公奴不為劉備上客也言發惻痛誠有由然合先迎王師徃歲病亡於鄴自臣在朝每為所親宣說此意時未有宜弗敢顯言殿下即位初年禎祥衆瑞日月而至有命自天昭然著見然聖徳洞達符表豫明實乾坤挺慶萬國作孚臣每慶賀欲言合驗事君盡禮人以為謟况臣名行穢賤入朝日淺言為罪尤自抑而已今洪澤被四表靈恩格天地海内翕習殊方歸服兆應竝集以揚休命始終允臧臣不勝喜舞謹具表通王令曰以示外薄徳之人何能致此未敢當也斯誠先王至徳通于神明固非人力也魏王侍中劉廙辛毗劉曄尚書令桓階尚書陳矯陳羣給事黃門侍郎王毖童遇等言臣伏讀左中郎將李伏上事考圖緯之言以效神明之應稽之古代未有不然者也故堯稱歴數在躬璇璣以明天道周武未戰而赤烏銜書漢祖未兆而神母告符孝宣仄微字成木葉光武布衣名已勒䜟是天之所命以著聖哲非有言語之聲芬芳之臭可得而知也徒縣象以示人徵物以效意耳自漢徳之衰漸染數世桓靈之末皇極不建暨于大亂二十餘年天之不冺誕生明聖以濟其難是以符䜟先著以彰至徳殿下踐阼未朞而靈象變于上羣瑞應于下四方不覊之民歸心向義唯懼在後雖典籍所傳未若今之盛也臣妾逺近莫不鳬藻王令曰犂牛之駮似虎莠之幼似禾事有似是而非者今日是矣覩斯言事良重吾不徳于是尚書僕射宣告官寮咸使聞知辛亥太史丞許芝條魏代漢見䜟緯於魏王曰易傳曰聖人受命而王黃龍以戊巳日見七月四日戊寅黃龍見此帝王受命之符瑞最著明者也又曰初六履霜陰始凝也又有積蟲大穴天子之宫厥咎然今蝗蟲見應之也又曰聖人以徳親比天下仁恩洽普厥應麒麟以戊巳日至厥應聖人受命又曰聖人淸浄行中正賢人福至民從命厥應麒麟來春秋漢含孶曰漢以魏魏以徵春秋玉版䜟曰代赤眉者魏公子春秋佐助期曰漢以許昌失天下故白馬令李雲上事曰許昌氣見於當塗高當塗高者當昌於許當塗高者魏也象魏者兩觀闕是也當道而高大者魏魏當代漢今魏基昌於許漢徵絶於許乃今效見如李雲之言許昌相應也佐助期又曰漢以蒙孫亡說者以蒙孫漢二十四帝童蒙愚昏以弱亡或以雜文為蒙其孫當失天下以為漢帝非正嗣少時為董侯名不正蒙亂之荒惑其子孫以弱亡孝經中黃䜟曰日載東絶火光不横一聖聰明四百之外易姓而勝喜舞謹具表通王令曰以示外薄徳之人何能致此未敢當也斯誠先王至徳通于神明固非人力也魏王侍中劉廙辛毗劉曄尚書令桓階尚書陳矯陳羣給事黃門侍郎王毖童遇等言臣伏讀左中郎將李伏上事考圖緯之言以效神明之應稽之古代未有不然者也故堯稱歴數在躬璇璣以明天道周武未戰而赤烏銜書漢祖未兆而神母告符孝宣仄微字成木葉光武布衣名已勒䜟是天之所命以著聖哲非有言語之聲芬芳之臭可得而知也徒縣象以示人徵物以效意耳自漢徳之衰漸染數世桓靈之末皇極不建暨于大亂二十餘年天之不冺誕生明聖以濟其難是以符䜟先著以彰至徳殿下踐阼未朞而靈象變于上羣瑞應于下四方不覊之民歸心向義唯懼在後雖典籍所傳未若今之盛也臣妾逺近莫不鳬藻王令曰犂牛之駮似虎莠之幼似禾事有似是而非者今日是矣覩斯言事良重吾不徳于是尚書僕射宣告官寮咸使聞知辛亥太史丞許芝條魏代漢見䜟緯於魏王曰易傳曰聖人受命而王黃龍以戊巳日見七月四日戊寅黃龍見此帝王受命之符瑞最著明者也又曰初六履霜陰始凝也又有積蟲大穴天子之宫厥咎然今蝗蟲見應之也又曰聖人以徳親比天下仁恩洽普厥應麒麟以戊巳日至厥應聖人受命又曰聖人淸浄行中正賢人福至民從命厥應麒麟來春秋漢含孶曰漢以魏魏以徵春秋玉版䜟曰代赤眉者魏公子春秋佐助期曰漢以許昌失天下故白馬令李雲上事曰許昌氣見於當塗高當塗高者當昌於許當塗高者魏也象魏者兩觀闕是也當道而高大者魏魏當代漢今魏基昌於許漢徵絶於許乃今效見如李雲之言許昌相應也佐助期又曰漢以蒙孫亡說者以蒙孫漢二十四帝童蒙愚昏以弱亡或以雜文為蒙其孫當失天下以為漢帝非正嗣少時為董侯名不正蒙亂之荒惑其子孫以弱亡孝經中黃䜟曰日載東絶火光不横一聖聰明四百之外易姓而明膺七百之禪代當湯武之期運值天命之移授河洛所表圖䜟所載昭然明白天下學士所共見也臣職在史官考符察徵圖䜟效見際會之期謹以上聞王令曰昔周文三分天下有其二以服事殷仲尼歎其至徳公旦履天子之籍聽天下之斷終然復子明辟書美其人吾雖徳不及二聖敢忘高山景行之義哉若夫唐堯舜禹之蹟皆以聖質茂徳處之故能上和靈祗下寧萬姓流稱今日今吾徳至薄也人至鄙也遭遇際會幸承先王餘業恩未被四海澤未及天下雖傾倉竭府以振魏國百姓猶寒者未盡煖饑者未盡飽夙夜憂懼弗敢遑寧庶欲保全髮齒長守今日以没於地以全魏國下見先王以塞負荷之責望狹志局守此而已雖屢蒙祥瑞當之戰惶五色無主若芝之言豈所聞乎心慄手悼書不成字辭不宣口吾間作詩曰喪亂悠悠過紀白骨從橫萬里哀哀下民靡恃吾將佐時整理復子明辟致仕庶欲守 伏讀令書深執克讓聖意懇惻至誠外昭臣等有所不安何者石户北人匹夫狂狷行不合義事不經見者是以史遷謂之不然誠非聖明所當希慕且有虞不逆放勛之禪夏禹亦無辭位之語故傳曰舜陟帝位若固有之斯誠聖人知天命不可逆歴數弗可辭也伏惟陛下應乾符運至徳發聞升昭于天是三靈降瑞人神以和休徵雜㳫萬國響應雖欲勿用將焉避之而固執謙虚違天逆衆慕匹夫之微分背上聖之所蹈違經䜟之明文信百氏之穿鑿非所以奉答天命光慰衆望也臣等昧死以請輒整頓壇場至吉日受命如前奏分别寫令宣下王令曰昔栢城子高辭夏禹而匿野顔闔辭魯幣而逺跡夫以王者之重諸侯之貴而二子忽之何則其節高也故烈士狥榮名義夫高貞介雖蔬食瓢飲樂在其中是以仲尼師王駘而子産嘉申徒今諸卿皆孤股肱腹心足以明孤而今咸若斯則諸卿遊於形骸之内而孤求為形骸之外其不相知未足多怪亟為上章還璽綬勿復紛紛也輔國將軍等一百二十人又奏曰臣聞符命不虚見衆心弗可違故孔子曰周公其為不聖乎以天下讓是天地日月輕去萬物也是以舜嚮天下不拜而受命今火徳氣盡炎上數終帝遷明徳祚隆大魏符瑞昭晳受命既固光天之下神人同應雖有虞儀鳳成周躍魚方今之事未足以喻而陛下違天命以飾小行逆人心以守私志上忤皇穹眷命之㫖中忘聖人達節之數下孤人臣翹首之望非所以揚聖道之高衢乘無窮之懿勲也臣等聞事君有獻可替否之道奉上有逆鱗固爭之義臣等敢以死請令曰太古聖王之治也至徳合乾坤恵澤均造化禮教優乎昆蟲仁恩洽乎草木日月所照戴天履地含氣有生之類靡不被服淸風沐浴玄徳是以金革不起苛慝不作風雨應節禎祥觸類而見今百姓寒者未暖饑者未飽鰥者未室寡者未嫁權備尚存未可舞以干戚方將整以齊斧戎役未息於外士民未安於内耳未聞康哉之歌目未覩擊壤之戲嬰兒未可託於高巢餘糧未可以宿於田畝人事未備至於此也夜未曜景星治未通眞人河未出龍馬山未出象車蓂莢未植階庭萐莆未生庖厨王母未獻白環渠搜未見珍裘靈瑞未效又如彼也昔東戸季子容成大庭軒轅赫胥之君咸得以此就功勒名今諸卿獨不可少假孤精心竭慮以和天人以格至理使彼衆事備羣瑞效然後安乃議此乎何遽相愧相廹之如是也速為讓章上還璽綬無重吾不徳也侍中劉廙等奏曰伏惟陛下以大聖之純懿當天命之歴數觀天象則符瑞著明考圖緯則文義煥炳察人事則四海齊心稽前代則異世同歸而固拒禪命未踐尊位聖意懇惻臣等敢不奉詔輒具章遣使者奉令曰泰伯三以天下讓人無得而稱焉仲尼歎其至徳孤獨何人庚申魏王上書曰皇帝陛下奉被今月乙夘璽書伏聼册命五内驚震精爽散越不知所處臣前上還相位退守藩國聖恩聼許臣雖無古人量徳度身自定之志保己存性實其私願不寤陛下猥損過謬之命發不世之詔以加無徳之臣且聞堯禪重華舉其克諧之徳舜授文命採其齊聖之美猶下咨四岳上觀璿璣今臣徳非虞夏行非二君而承歴數之咨應選授之命内自揆撫無徳以稱且許由匹夫猶拒帝位善卷布衣而逆虞詔臣雖鄙蔽敢忘守節以當大命不勝至願謹拜章陳情使行相國永壽少府糞土臣毛宗奏并上璽綬辛酉給事中博士蘇林董巴上表曰天有十二次以為分野王公之國各有所屬周在鶉火魏在大梁歲星行歴十二次國天子受命諸侯以封周文王始受命歲在鶉火至武王伐紂十三年歲星復在鶉火故春秋傳曰武王伐紂歲在鶉火歲之所在即我有周之分野也昔光和七年歲在大梁武王始受命為時將討黃巾是歲改年為中平元年建安元年歲復在大梁始拜大將軍十三年復在大梁始拜丞相今二十五年歲復在大梁陛下受命此魏得歲與周文王受命相應今年靑龍在庚子詩推度災曰庚者更也子者滋也聖命天下治又曰王者布徳於子治成於丑此言今年天更命聖人制治天下布徳于民也魏以改制天下與時協矣顓頊受命歲在豕韋衛居其地亦在豕韋故春秋傳曰衛顓頊之墟也今十月斗之建則顓頊受命之分也始魏以十月受禪此同符始祖受命之驗也魏之氏族出自顓頊與舜同祖見于春秋世家舜以土徳承堯之火今魏亦以土徳承漢之火於行運會於堯舜授受之次臣聞天之去就固有常分聖人當之昭然不疑故堯捐骨肉而禪有虞終無恡色舜發壠畝而君天下若固有之其相授受間不替漏天下已傳矣所以急天命天下不可一日無君也今漢期運已終妖異絶之已審陛下受天之命符瑞告徵丁寧詳悉反覆備至雖言語相喻無以代此今既發詔書璽綬未御固執謙讓上逆天命下違民望臣謹按古之典籍參以圖緯魏之行運及天道所在即尊之驗在於今年此月昭晰分明唯陛下遷思易慮以時即位顯告天帝而告天下然後改正朔易服色正大號天下幸甚令曰凡斯皆宜聖徳故曰茍非其人道不虚行天瑞雖彰須徳而光吾徳薄之人胡足以當之今讓冀見聼許外内咸使聞知壬戌册詔曰皇帝問魏王言遣宗奉庚申書到所稱引聞之朕惟漢家世踰二十年過四百運周數終行祚已訖天心已移兆民望絶天之所廢有自來矣今大命有所底止神器當歸聖徳違天不順逆衆不祥王其體有虞之盛徳應歴數之嘉會是以禎祥告符圖䜟表錄神人同應受命咸宜朕畏上帝致位于王天不可違衆不可拒且重華不逆堯命大禹不辭舜位若夫由卷匹夫不載聖籍固非皇材帝器所當稱慕今使音奉皇帝璽綬王其陟帝位無逆朕命以祗奉天心焉於是尚書令桓階等奏曰今漢使音奉璽書到臣等以為天命不可稽神器不可瀆周武中流有白魚之應不待師期而大號已建舜受大麓桑蔭未移而已陟帝位皆所以祗承天命若此之速也故無固讓之義不以守節為貴必道信於神靈符合於天地而已易曰其受命如響無有逺近幽深遂知來物非天下之至精其孰能與於此今陛下應期運之數為皇天所子而復稽滯於辭讓低囘於大號非所以則天地之道副萬國之望臣等敢以死請輙勑有司脩治壇場擇吉日受禪命發璽綬令曰冀三讓而不見聼何汲汲於斯乎甲子魏王上書曰奉今月戊戍璽書重被聖命伏聼册告肝膽戰悸不知所措天下神器禪代重事故堯將禪舜納于大麓舜之命禹玄圭告功烈風不迷九州攸平詢事考言然後乃命而猶執謙讓于徳不嗣况臣頑固質非二聖乃應天統受終明詔敢守微節歸志箕山不勝大願謹拜表陳情使并奉上璽綬侍中劉廙等奏曰臣等聞聖帝不違時明主不逆人故易稱通天下之志斷天下之疑伏惟陛下體有虞之上聖承土徳之行運當亢陽明夷之會應漢氏祚終之數合契皇極同符兩儀是以聖瑞表徵天下同應歴運去就深切著明論之天命無所與議比之時宜無所與爭故受命之期時淸日晏曜靈施光休氣雲蒸是乃天道悅懌民心欣戴而仍見閉拒於禮何居且羣生不可一日無主神器不可以斯須無統故臣有違君以成業下有矯上以立事臣等敢不重以死請王令曰天下重器王者正統以聖徳當之猶有懼心吾何人哉且公卿未至乏主斯豈小事且宜以待固譲之後乃當更議其可耳丁夘册詔魏王曰天訖漢祚辰象著明朕祗天命致位于王仍陳歴數於詔册喻符運於翰墨神器不可以辭拒皇位不可以謙讓稽於天命至於再三且四海不可一日曠主萬㡬不可以斯須無統故建大業者不拘小節知天命者不繫細物是以舜受大業之命而無遜讓之辭聖人達節不亦逺乎今使音奉皇帝璽綬王其欽承以答天下嚮應之望焉相國華歆太尉賈詡御史大夫王朗及九卿上言曰臣等被召到伏見太史丞許芝左中郎將李伏所上圖䜟符命侍中劉廙等宣叙衆心人靈同謀又漢朝知陛下聖化通于神明聖徳參于虞夏因瑞應之備至聼歴數之所在遂獻璽綬固讓尊號能言之倫莫不抃舞河圖洛書天命瑞應人事協于天時民言協于天叙而陛下性秉勞謙體尚克讓明詔懇切未肯聼許臣妾小人莫不伊邑臣等聞自古及今有天下者不常在乎一姓考以徳勢則盛衰在乎彊弱論以終始則廢興在乎期運唐虞歴數不在厥子而在舜禹舜禹雖懐克讓之意廹羣后執玉帛而朝之兆民懐欣戴而歸之率土揚謌謠而詠之故其守節之拘不可得而常處達節之權不可得而久避是以或遜位而不恡或受禪而不辭不恡者未必厭皇寵不辭者未必渴帝祚各廹天命而不得以已既禪之後則唐氏之子為賔于有虞虞氏之胄為客于夏代然則禪代之義非獨受之者實應天福授之者亦與有餘慶焉漢自章和之後世多變故稍以陵遲洎乎孝靈不恒其心虐賢害仁聚歛無度政在嬖䜿視民如讐遂令上天震怒百姓從風如歸當時則四海鼎沸既没則禍發宫庭寵勢竝竭帝室遂卑若在帝舜之末節猶擇聖代而授之荆人抱玉璞猶思良工而刋之况漢國既徃莫之能匡推器移君委之聖哲固其宜也漢朝委質既願禪禮之速定也天祚率土必將有主主率土者非陛下其孰能任之所謂論徳無與為比考功無推讓矣天命不可久稽民望不可久違臣等慺慺不勝大願伏請陛下割撝謙之志修受禪之禮副人神之意慰外内之願令曰以徳則孤不足以時則戎虜未滅若以羣賢之靈得保首領終君魏國於孤足矣若孤者胡足以辱四海至乎天瑞人事皆先王聖徳遺慶孤何有焉是以未敢聞命己巳魏王上書曰臣聞舜有賔于四門之勲乃受禪于陶唐禹有存國七百之功乃承祿於有虞臣以䝉蔽徳非二聖猥當天統不敢聞命敢屢抗疏畧陳私願庶章通紫庭得全微節情達宸極永守本志而音重復銜命申制詔臣臣實戰惕不發璽書而音廹於嚴詔不敢復命願陛下馳傳騁驛召音還臺不勝至誠謹使宗奉書相國歆太尉詡御史大夫朗及九卿奏曰臣等伏讀詔書於悒益甚臣等聞易稱聖人奉天時論語云君子畏天命天命有去就然後帝者有禪代是以唐之禪虞命在爾躬虞之順唐謂之受終堯知天命去已故不得不禪舜舜知歴數在躬故不敢不受不得不禪奉天時也不敢不受畏天命也漢朝雖承季末陵遲之餘猶務奉天命以則堯之道是以願禪帝位而歸二女而陛下正於大魏受命之初抑虞夏之達節尚延陵之讓退而所枉者大所直者小所詳者輕所畧者重中人凡士猶為陛下陋之没者有靈則重華必忿憤於蒼梧之神墓大禹必鬱悒於會稽之山隂武王必不悅於商陵之玄宫矣是以臣等敢以死請且漢政在閹宦祿去帝室七世矣遂集矢石于其宫殿而二京為之丘墟當是之時四海蕩覆天下分崩武王親衣甲而冠胄沐雨而櫛風為民請命則活萬國為世撥亂則致升平鳩民而立長築宫而置吏元元無過罔干前業而始有造於華夏陛下即位光昭文徳以翊武功勤恤民隐視之如傷懼者寧之勞者息之寒者以暖饑者以充逺人以恩復冦敵以恩降邁恩種徳光被四表稽古篤睦茂于放勛網漏吞舟弘乎周文是以布政未朞人神竝和皇天則降甘露而臻四靈后土則挺芝草而吐醴泉虎豹鹿兎皆素其色雉鳩燕雀亦白其羽連理之木同心之瓜五采之魚珍祥瑞物雜㳫於其間者無不畢備古人有言微禹吾其魚乎微大魏則臣等之白骨交橫于曠野矣伏省羣臣外内前後章奏所以陳叙陛下之符命者莫不條河洛之圖書據天地之瑞應因漢朝之欵誠宣萬方之景附可謂信矣省矣三王無以及五帝無以加民命之懸於魏政三十有餘年矣此乃千世時至之會萬載一遇之秋達節廣度宜昭於斯際拘牽小節不施於此時仰稽天命罪在臣等輒營壇場具禮儀擇吉日昭告昊天上帝秩羣神之禮須禋祭畢會羣寮於朝堂議年號正朔服色當施行上復令曰昔者大舜飯糗茹草將終身焉斯則孤之前志也及至承堯禪被袗衣妻二女若固有之斯則順天命也羣公卿士誠以天命不可拒民望不可違孤亦曷以辭焉庚午册詔魏王曰昔堯以配天之徳秉六合之重猶覩歴運之數移於有虞委讓帝位忽如遺跡今天既訖我漢命乃眷北顧帝皇之業實在大魏朕守空名以竊古義顧視前事猶有慙徳而王遜讓至於三四朕用懼焉夫不辭萬乘之位者知命達節之數也虞夏之君處之不疑故勲烈垂于萬載美名傳於無窮今遣守尚書令侍中顗喻王其速陟帝位以順天人之心副朕之大願於是尚書令桓階等奏曰今漢氏之命已四至而陛下前後固辭臣等伏以為上帝之臨聖徳期運之隆大魏斯豈數載傳稱周之有天下非甲子之朝殷之去帝位非牧野之日也故詩序商湯追本玄王之至述姬周上錄后稷之生是以受命既固厥徳不囘漢氏衰廢行次已絶三辰垂其徵史官著其驗耆老記先古之占百姓協謌謠之聲陛下應天受禪當速即壇場柴燎上帝誠不宜久停神器拒億兆之願臣輒下太史令擇元辰今月二十九日可登壇受命請詔王公羣卿具條禮儀别奏令曰可

### 邢史子臣预言被联系到魏兴

[《三国志·文帝纪》裴注 024·3](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-024-3)

> 干寳搜神記曰宋大夫邢史子臣明于天道周敬王之三十七年景公問曰天道其何祥對曰後五十年五月丁亥臣將死死後五年五月丁夘吳將亡亡後五年君將終終後四百年邾王天下俄而皆如其言所云邾王天下者謂魏之興也邾曹姓魏亦曹姓皆邾之後其年數則錯未知邢史失其數邪將年代久逺注記者傳而有謬也

《搜神记》记宋景公询天道，邢史子臣预言自身死亡、吴亡、宋君终和邾姓得国，后人以曹姓附会魏兴；注指出年数不合。

**时段与依据** 起点周敬王三十七年、后段数百年和魏兴有多层叙述；不以志怪预言推算单一年份。

> 續漢書曰彪見漢祚將終自以累世為三公耻為魏臣遂稱足攣不復行積十餘年

杨彪见汉祚将终，因累世为汉三公，以足疾长期不出。

**时段与依据** 《杨彪传》连建安十一年削恩泽侯后而记，不载退避单独确日；事情延续多年。

### 裴松之从卢毓旧议推知魏出师告郊

[《三国志·文帝纪》裴注 040·2](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-040-2)

> 臣松之按魏郊祀奏中尚書盧毓議祀厲殊事云具犧牲祭器如前後師出告郊之禮如此則魏氏出師皆告郊也

裴松之据尚书卢毓议制比较前后文，认为曹魏出师皆行郊告。

**时段与依据** 制度解释及旧奏没有明确事年；附223年十月出师告祀。

<a id="period-sgz002-p-048-2"></a>

### 曹丕编著《典论》等，与诸儒讲论

[《三国志·文帝纪》裴注 048·2](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-048-2)

> 故論撰所著典論詩賦蓋百餘篇集諸儒於肅城門内講論大義侃侃無倦常嘉漢文帝之為君寛仁玄黙務欲以徳化民有賢聖之風時文學諸儒或以為孝文雖賢其於聰明通達國體不如賈誼帝由是著太宗論曰昔有苗不賔重華舞以干戚尉佗稱帝孝文撫以恩徳吳王不朝錫之几杖以撫其意而天下賴安乃弘三章之教愷悌之化欲使曩時累息之民得濶歩髙談無危懼之心若賈誼之才敏籌畫國政特賢臣之器管晏之資豈若孝文大人之量哉

曹丕整理《典论》、诗赋，召儒者讨论，推重汉文帝宽政；见有人认为文帝不如贾谊，写《太宗论》分别君主与贤臣之长。

**时段与依据** 在位前后写作与论辩未独标年；下文另明黄初三年公布。

<a id="period-sgz002-p-048-4"></a>

### 曹丕评汉文帝治政不足

[《三国志·文帝纪》裴注 048·4](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-048-4)

> 他日又從容言曰顧我亦有所不取于漢文帝者三殺薄昭幸鄧通慎夫人衣不曵地集上書囊為帳帷以為漢文儉而無法舅后之家但當飬育以恩而不當假借以權既觸罪法又不得不害矣其欲秉持中道以為帝王儀表者如此

曹丕另一次表示不赞成汉文帝杀薄昭、宠邓通、使慎夫人衣不曳地等做法，论外戚可恩养而不应借权。

**时段与依据** “他日”没有年代，亦不可用《太宗论》公布年替代。

<a id="period-sgz002-p-048-5"></a>

### 曹丕将《典论》等赠予孙权、张昭

[《三国志·文帝纪》裴注 048·5](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-048-5)

> 胡沖吳歴曰帝以素書所著典論及詩賦餉孫權又以紙寫一通與張昭

《吴历》载曹丕以绢写《典论》及诗赋赠孙权，又纸写一通给张昭。

**时段与依据** 史书未说明送书年月；区分从东宫写作和黄初三年传布《太宗论》。

<a id="period-sgz002-p-049-1"></a>

### 曹丕回忆董卓害少帝和何太后

[《三国志·文帝纪》裴注 049·1](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-049-1)

> 典論帝自叙曰初平之元董卓殺主鴆后蕩覆王室是時四海既困中平之政兼惡卓之凶逆家家思亂人人自危

曹丕《典论》把董卓杀少帝和鸩何太后连叙，认为百姓早已难堪汉末与董卓之政。

**时段与依据** 首句概称“初平之元”，但被害何太后在189年，少帝在190年（《献帝纪》），同一语段兼指两年。

<a id="period-sgz002-p-049-4"></a>

### 曹丕幼时随曹操学习骑射

[《三国志·文帝纪》裴注 049·4](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-049-4)

> 會黄巾盛於海嶽山寇暴於并冀乘勝轉攻席卷而南鄉邑望烟而奔城郭覩塵而潰百姓死亡暴骨如莽時余年五歲上以世方擾亂教余學射六歲而知射又教余騎馬八歲而能騎射矣以時之多故每征余常從

曹丕说战乱百姓逃亡、尸骨遍地，父亲五岁教自己射箭，六岁会射后学马术，八岁能骑射，常随征。

**时段与依据** 按187年生虚岁约191至194；各活动分跨数年，叙事局势为背景。

<a id="period-sgz002-p-049-6"></a>

### 曹丕自述长期爱好弓马

[《三国志·文帝纪》裴注 049·6](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-049-6)

> 夫文武之道各隨時而用生于中平之季長于戎旅之間是以少好弓馬于今不衰逐禽輒十里馳射常百歩日多體健心每不厭

曹丕说生长在战乱中，向来喜好射猎，常逐禽驰射，仍不觉疲倦。

**时段与依据** 是成长经历及长期习性，无独立年。

<a id="period-sgz002-p-049-8"></a>

### 曹丕与前来犒军的荀彧谈骑射

[《三国志·文帝纪》裴注 049·8](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-049-8)

> 後軍南征次曲蠡尚書令荀彧奉使犒軍見余談論之末彧言聞君善左右射此實難能余言執事未覩夫項發口縱俯馬蹄而仰月支也彧喜笑曰乃爾余曰埓有常徑的有常所雖每發輒中非至妙也若馳平原赴豐草要狡獸截輕禽使弓不虚彎所中必洞斯則妙矣時軍祭酒張京在坐顧彧拊手曰善

军南征至曲蠡，荀彧奉命犒军，与曹丕谈左右开弓与在野地驰射的难处，张京在座。

**时段与依据** 荀彧212年卒，不能和220年文帝丙午至曲蠡混同；旧事确年未见。

<a id="period-sgz002-p-049-9"></a>

### 曹丕学习剑术并与邓展切磋

[《三国志·文帝纪》裴注 049·9](../../sources/摘录/三国志-卷002-文帝纪裴注.md#pei-049-9)

> 余又學擊劒閱師多矣四方之法各異唯京師為善桓靈之間有虎賁王越善斯術稱於京師河南史阿言昔與越遊具得其法余從阿學之精熟嘗與平虜將軍劉勲奮威將軍鄧展等共飲宿聞展善有手臂曉五兵又稱其能空手入白刃余與論劒良久謂言將軍法非也余顧嘗好之又得善術因求與余對時酒酣耳熱方食竿蔗便以為杖下殿數交三中其臂左右大笑展意不平求更為之余言吾法急屬難相中面故齊臂耳展言願復一交余知其欲突以取交中也因偽深進展果尋前余却脚勦正截其顙坐中驚視余還坐笑曰昔陽慶使淳于意去其故方更授以秘術今余亦願鄧將軍捐棄故技更受要道也一坐盡歡

曹丕讲京师王越与史阿的剑术传承，自己师史阿，又曾在宴饮时以甘蔗与邓展较技。

**时段与依据** 王越声名在桓灵间；曹丕学艺及同邓展、刘勋饮宴均未载确年。

### 曹丕向袁敏学习，并谈弹棋与读书

> 夫事不可自謂已長余少曉持複自謂無對俗名雙㦸為坐鐵室鑲楯為蔽木户後從陳國袁敏學以單攻複每為若神對家不知所出先曰若逢敏於狹路直決耳余於他戲弄之事少所喜惟彈棊畧盡其巧少為之賦昔京師先工有馬合鄉侯東方安世張公子常恨不得與彼數子者對上雅好詩書文籍雖在軍旅手不釋卷每每定省從容常言人少好學則思專長則善忘長大而能勤學者唯吾與袁伯業耳余是以少誦詩論及長而備歴五經四部史漢諸子百家之言靡不畢覽

<a id="sgz003-period"></a>

## 《明帝纪》跨年及未定年材料

<a id="period-sgz003-b-167-1"></a>

### 曹叡名讳与身份

[《三国志·明帝纪》仓内原文 L167](../../sources/本地分卷/三国志/三国志-卷003.md#l167)

> 明皇帝諱叡，字元仲，文帝太子也。

魏明帝名叡，字元仲，是魏文帝的太子。

**时段与依据** 篇首传主名号，太子册立另见同一行黄初七年记事。

<a id="period-sgz003-b-167-2"></a>

### 曹操喜爱幼年曹叡

[《三国志·明帝纪》仓内原文 L167](../../sources/本地分卷/三国志/三国志-卷003.md#l167)

> 生而太祖愛之，常令在左右。

曹操从曹叡小的时候就喜爱他，常让他跟随在身边。

**时段与依据** 本纪“生而”“常”指多年；确定在曹操建安二十五年去世前，226年第12条错把早年事挂在即位年。裴注另载曹操称其“我基於爾三世矣”，未记某年。

<a id="period-sgz003-b-175-2"></a>

### 曹叡在听讼观临听大案

[《三国志·明帝纪》仓内原文 L175](../../sources/本地分卷/三国志/三国志-卷003.md#l175)

> 帝常言「獄者，天下之性命也」，每斷大獄，常幸觀臨聽之。

曹叡认为刑狱维系天下性命，大案审理时往往亲往听讼观听审。

**时段与依据** “常言”“每斷”是改名后习惯，历时而没有各案具体纪年。可在229年第5条参见其作用。

<a id="period-sgz003-b-176-1"></a>

### 洛阳宗庙未成前神主在邺

[《三国志·明帝纪》仓内原文 L176](../../sources/本地分卷/三国志/三国志-卷003.md#l176)

> 初，洛陽宗廟未成，神主在鄴廟。

洛阳宗庙尚未建成的时候，神主移置或奉设在邺的庙内。

**时段与依据** 本纪“初”概叙229年新庙建成之前，建庙本身自227年始，神主在邺为此前状态；229年第6条宜作背景。

<a id="period-sgz003-b-201-3"></a>

### 孙权遣使通高句骊，欲袭辽东

[《三国志·明帝纪》仓内原文 L201](../../sources/本地分卷/三国志/三国志-卷003.md#l201)

> 初，權遣使浮海與高句驪通，欲襲遼東。

此前孙权派遣使者浮海与高句骊联系，意图袭取辽东。

**时段与依据** 本纪以“初”引毌丘俭讨辽东之前的吴外交。卷047《吴主传》嘉禾二年、五年（233、236）先后使高句骊，L197载236年吴使被斩，未明此句指单轮还是连叙；旧237年第18条不能作为赴使发生年。

<a id="period-sgz003-b-208-3"></a>

### 登女在曹叡末次病中被杀

[《三国志·明帝纪》仓内原文 L208](../../sources/本地分卷/三国志/三国志-卷003.md#l208)

> 及帝疾，飲水無驗，於是殺焉。

到曹叡病重时，饮用她的水没有效果，登女被杀。

**时段与依据** “及帝疾”承L207景初二年十二月患病，止于L209景初三年正月丁亥帝卒。按史书仅能定位238岁末至239正月之间，未给跨年点前后确证。

<a id="period-sgz003-b-210-1"></a>

### 陈寿论曹叡明断与营宫之失

[《三国志·明帝纪》仓内原文 L210](../../sources/本地分卷/三国志/三国志-卷003.md#l210)

> 評曰：明帝沉毅斷識，任心而行，蓋有君人之至槩焉。於時百姓彫弊，四海分崩，不先聿脩顯祖，闡拓洪基，而遽追秦皇、漢武，宮館是營，格之遠猷，其殆疾乎！

陈寿称曹叡深沉刚毅、明识决断，有君主气度；又批评天下分崩、民生困惫时急于仿效秦皇、汉武营造宫室，未先拓展祖业。

**时段与依据** “評曰”是本卷作者对其一朝的总结，借秦始皇、汉武帝指责宫室营建，无单一事件年。

<a id="period-sgz003-p-001-1"></a>

### 曹操器重幼时的曹叡

[《三国志·明帝纪》裴注 001·1](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-001-1)

> 魏書曰帝生數歲而有岐嶷之姿武皇帝異之曰我基於爾三世矣每朝宴會同與侍中近臣並列帷幄好學多識特留意於法理

《魏书》说曹叡年仅数岁便显出聪慧，曹操说子孙三世的基业在他身上，往往让他和侍中近臣同列帷幄；曹叡还爱读书，关注法律。

**时段与依据** 童年及反复伴随曹操无具体年，至迟在曹操220年去世以前。“我基於爾三世”是所引对话，不给出处日期。

<a id="period-sgz003-p-002-1"></a>

### 曹丕让郭皇后养曹叡，并曾考虑京兆王

[《三国志·明帝纪》裴注 002·1](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-002-1)

> 魏畧曰文帝以郭后無子詔使子養帝帝以母不以道終意甚不平後不獲已乃敬事郭后旦夕因長御問起居郭后亦自以無子遂加慈愛文帝始以帝不悅有意欲以他姬子京兆王為嗣故久不拜太子

《魏略》说曹丕令无子的郭皇后以曹叡为子；曹叡因甄氏死不平，后来不得已问候郭后，郭后对他转而慈爱。曹丕曾有意立另一妃嫔所生的京兆王，因此较晚立曹叡为太子。

**时段与依据** 甄氏死于221年，郭氏立皇后于222年，曹叡立太子在226年。收养、转变态度和另择太子的各次决定未见确年。“京兆王”也可能是追称。

<a id="period-sgz003-p-002-2"></a>

### 猎鹿故事解释曹丕立储之意

[《三国志·明帝纪》裴注 002·2](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-002-2)

> 魏末傳曰帝常從文帝獵見子母鹿文帝射殺鹿母使帝射鹿子帝不從曰陛下已殺其母臣不忍復殺其子因涕泣文帝即放弓箭以此深竒之而樹立之意定

《魏末传》说曹丕猎杀母鹿、让曹叡射小鹿，曹叡想起母子关系，含泪拒绝，曹丕由此决定立他为太子。

**时段与依据** 这是另一个文献对立储动机的解释，狩猎没有明确日期，只能置于226年立储之前。

[《三国志·明帝纪》裴注 020·4](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-020-4)

> 漢晉春秋曰氐池縣大栁谷口夜激波涌溢其聲如雷曉而有蒼石立水中長一丈六尺高八尺白石畫之為十三馬一牛一鳥八卦玉玦之象皆隆起其文曰大討曹適水中甲寅帝惡其討也使鑿去為計以蒼石窒之宿昔而白石滿焉至晉初其文愈明馬象皆煥徹如玉焉

《汉晋春秋》说氐池大柳谷口夜里波涌，天明水中有苍石，纹样如马、牛、鸟和八卦等；皇帝厌恶其中“討”字，令人凿埋，故事又说晋初纹象越发清楚。

**时段与依据** 同一祥瑞叙事的异本，虽随本注235年报道可互参，但本说难以精确限定发现、凿石和“晉初”显纹日期。

### 裴松之解释景初服牲旗制的古礼

[《三国志·明帝纪》裴注 023·1](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-023-1)

> 臣松之按魏為土行故服色尚黄行殷之時以建丑為正故犧牲旌旗一用殷禮禮記云夏后氏尚黑故戎事乘驪牲用玄殷人尚白戎事乘翰牲用白周人尚赤戎事乘騵牲用騂鄭玄云夏后氏以建寅為正物生色黑殷以建丑為正物牙色白周以建子為正物萌色赤翰白色馬也易曰白馬翰如周禮巾車職建大赤以朝大白以即戎此則周以正色之旗以朝先代之旗即戎今魏用殷禮變周之制故建大白以朝大赤即戎

### 裴松之据受纳时间、改历推曹叡生年和享年

[《三国志·明帝纪》裴注 034·2](../../sources/摘录/三国志-卷003-明帝纪裴注.md#pei-034-2)

裴松之疑曹叡生于建安十年，推至过世为整三十四年，魏改建丑正朔所造成的名年差最多可算三十五，不能得三十六。

**时段与依据** 《明帝纪》239年记卒年三十六，220年封武德侯时十五则虚岁可反推206年。裴松之的205是推测，二年均没有可独证的生日，年龄异说仍详239年第1条。

### 底本内嵌裴注述郑小同的祖父、父亲及得名

[《三国志·三少帝纪》仓内原文 L266](../../sources/本地分卷/三国志/三国志-卷004.md#l266)

> 小同，鄭玄孫也。《玄別傳》曰：「玄有子，為孔融吏，舉孝廉。融之被圍，往赴，為賊所害。有遺腹子，以丁卯日生；而玄以丁卯歲生，故名曰小同。」

郑小同是郑玄孙。引《玄别传》记其父做孔融属吏，赴孔融围困之难被杀；郑小同为遗腹子，生于丁卯日，与祖父生于丁卯年照应得名。

**时段与依据** 底本本处混入注书，父子事见裴注第24。孔融受围的具体年份有不同可能，不能据此定郑小同出生年。

<a id="period-sgz004-b-266-5"></a>

### 底本内嵌裴注载华歆表荐郑小同

[《三国志·三少帝纪》仓内原文 L266](../../sources/本地分卷/三国志/三国志-卷004.md#l266)

> 《魏名臣奏》載太尉華歆表曰：「臣聞勵俗宣化，莫先於表善，班祿敘爵，莫美於顯能，是以楚人思子文之治，復命其胤，漢室嘉江公之德，用顯其世。伏見故漢大司農北海鄭玄，當時之學，名冠華夏，為世儒宗。文皇帝旌錄先賢，拜玄適孫小同以為郎中，長假在家。小同年踰三十，少有令質，學綜六經，行著鄉邑。海、岱之人莫不嘉其自然，美其氣量。跡其所履，有質直不渝之性，然而恪恭靜默，色養其親，不治可見之美，不競人間之名，斯誠清時所宜式敘，前後明詔所斟酌而求也。臣老病委頓，無益視聽，謹具以聞。」

华歆表述郑玄为一时儒宗，魏文帝曾任小同郎中，称小同通晓六经、孝亲且品行可荐。

**时段与依据** 华歆表署太尉，早于华歆太和五年（231）十二月卒，未记表奏的确年。与裴注第24同材料。

### 陈寿论君位传继

陈寿从公天下与按嫡承统谈起，认为嫡系无继时应选旁支贤者，举汉文帝、汉宣帝为例。

<a id="period-sgz004-b-298-2"></a>

### 陈寿论曹叡托孤与曹芳被废

[《三国志·三少帝纪》仓内原文 L298](../../sources/本地分卷/三国志/三国志-卷004.md#l298)

> 明帝旣不能然，情繫私愛，撫養嬰孩，傳以大器，託付不專，必參枝族，終於曹爽誅夷，齊王替位。

陈寿批评曹叡因私爱收养幼童并授帝位，托孤不专，加入宗室共同辅政，终于曹爽被诛、曹芳被废。

**时段与依据** 总评239年托孤、249年诛曹爽、254年废曹芳，论说无作年。

<a id="period-sgz004-b-298-3"></a>

### 陈寿论曹髦好学及其遭遇

[《三国志·三少帝纪》仓内原文 L298](../../sources/本地分卷/三国志/三国志-卷004.md#l298)

> 高貴公才慧夙成，好問尚辭，蓋亦文帝之風流也；然輕躁忿肆，自蹈大禍。

陈寿认为曹髦早慧好问，有魏文帝风采，也批评他急躁愤慨导致灾祸。

**时段与依据** 史家总评曹髦生涯，不能把作者的褒贬当作260年当事人记录。

<a id="period-sgz004-b-298-4"></a>

### 陈寿论曹奂逊魏及封国

[《三国志·三少帝纪》仓内原文 L298](../../sources/本地分卷/三国志/三国志-卷004.md#l298)

> 陳留王恭己南面，宰輔統政，仰遵前式，揖讓而禪，遂饗封大國，作賔於晉，比之山陽，班寵有加焉。

陈寿说曹奂在位时政由宰辅，沿旧例禅位给晋，仍受封大国，以宾礼相待，比汉献帝所得礼数更高。

**时段与依据** 史评涉及曹奂在位及后续处遇，非单年事件。

## 《后妃传》跨年及未定年材料

<a id="period-sgz005-b-300-1"></a>

### 后妃制度序论

[《三国志·后妃传》仓内原文 L300](../../sources/本地分卷/三国志/三国志-卷005.md#l300)

> 易稱「男正位乎外，女正位乎內；男女正，天地之大義也」。古先哲王，莫不明后妃之制，順天地之德，故二妃嬪媯，虞道克隆，任、姒配姬，周室用熈，廢興存亡，恆此之由。春秋說雲天子十二女，諸侯九女，考之情理，不易之典也。而末世奢縱，肆其侈欲，至使男女怨曠，感動和氣，惟色是崇，不本淑懿，故風教陵遲而大綱毀泯，豈不惜哉！嗚呼，有國有家者，其可以永鑒矣！

陈寿用《周易》内外之分说明后妃制度的意义，举舜、周、春秋礼说，批评后世妃嫔过多、以色为尚。

**时段与依据** 经义、历代典例和史臣总论均无本卷独立纪年，各时代不得并入一岁。

<a id="period-sgz005-b-301-1"></a>

### 汉代后妃称号和内官等第

[《三国志·后妃传》仓内原文 L301](../../sources/本地分卷/三国志/三国志-卷005.md#l301)

> 漢制，帝祖母曰太皇太后，帝母曰皇太后，帝妃曰皇后，其餘內官十有四等。

汉朝称帝祖母为太皇太后、母为皇太后、正妻为皇后，内官另有十四等。

**时段与依据** 制度通叙。十四等沿革另见《汉书·外戚传》，本条无始制年。

郭氏出自河右大族，黄初年间随西平郡叛乱被没入宫中。

### 郭太后亲属受封并掌宿卫

### 陈寿论魏后妃及外戚

[《三国志·后妃传》仓内原文 L327](../../sources/本地分卷/三国志/三国志-卷005.md#l327)

### 曹操与丁夫人断绝，卞氏厚待丁氏

[《三国志·后妃传》裴注 002·3](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-002-3)

> 後太祖就見之夫人方織外人傳云公至夫人踞機如故太祖到撫其背曰顧我共載歸乎夫人不顧又不應太祖却行立於户外復云得無尚可邪遂不應太祖曰真訣矣遂與絶欲其家嫁之其家不敢初丁夫人既為嫡加有子脩丁視后母子不足后為繼室不念舊惡因太祖出行常四時使人饋遺又私迎之延以上坐而已下之迎來送去有如昔日丁謝曰廢放之人夫人何能常爾邪其後丁亡后請太祖殯葬許之乃葬許城南

### 郭建、郭德与甄温晋封

[《三国志·后妃传》裴注 012·3](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-012-3)

> 咸熙初封郭建為臨渭縣公悳廣安縣公邑皆千八百户温本國侯進為輔國大將軍加侍中領射聲校尉悳鎮軍大將軍

郭建为临渭县公、郭德为广安县公，甄温官至辅国大将军等。

**时段与依据** 咸熙初主要是264，但原注把多项进封、迁职合记，仅有年段，细项先后未明。

<a id="period-sgz005-p-012-5"></a>

### 郭德在晋朝升迁

[《三国志·后妃传》裴注 012·5](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-012-5)

> 悳為人貞素加以世祖姊夫是以遂貴當世悳暮年官更轉為宗正遷侍中

《晋诸公赞》说郭德持身朴素，又是司马炎姊夫，一时尊贵，后来任宗正、侍中。

**时段与依据** 任官及转迁均无独立年份，至迟在282年争齐王事前。

<a id="period-sgz005-p-012-7"></a>

### 郭德病逝，郭喜承袭

[《三国志·后妃传》裴注 012·7](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-012-7)

> 尋疾薨贈中軍大將軍開府侍中如故諡恭公子喜嗣喜精粹有器美歴中書郎右衛將軍侍中位至輔國大將軍加散騎常侍喜與國姻親而經趙王倫齊王冏事故能不豫際會良以其才短然亦以退靜免之

郭德去世，追赠中军大将军，谥恭公。郭喜承袭，历任多职，后来避开司马伦、司马冏之争。

**时段与依据** 郭德病卒和郭喜官历无明确年。司马伦、司马冏之事在301年前后，注文只说郭喜经历其时而不参与，不能据以分配具体行为。

### 郭永、董氏和郭后兄弟姊妹

[《三国志·后妃传》裴注 013·1](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-013-1)

> 魏書曰父永官至南郡太守諡敬后母姓董氏即堂陽君生三男二女長男浮高唐令次女昱次即后后弟都弟成

《魏书》叙郭永为南郡太守，追谥敬，母姓董，列出五名子女。

**时段与依据** 世系和父亲任官无确年；追谥见正文230年及236年改封。

### 四库电子本重出的郭德传记

[《三国志·后妃传》裴注 014·1](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-014-1)

> 字彦孫司馬景王輔政以女妻悳妻早亡文王復以女繼室即京兆長公主景文二王欲自結於郭后是以頻繁為婚悳雖無才學而恭謹謙順甄温字仲舒與郭建及悳等皆后族以事宜見寵咸熙初封郭建為臨渭縣公悳廣安縣公邑皆千八百户温本國侯進為輔國大將軍加侍中領射聲校尉悳鎮軍大將軍泰始元年晉受禪加建悳温三人位特進悳為人貞素加以世祖姊夫是以遂貴當世悳暮年官更轉為宗正遷侍中太康中大司馬齊王攸當之藩悳與左衛將軍王濟共諫請時人嘉之世祖以此望悳由此出悳為大鴻臚加侍中光禄大夫尋疾薨贈中軍大將軍開府侍中如故諡恭公子喜嗣喜精粹有器美歴中書郎右衛將軍侍中位至輔國大將軍加散騎常侍喜與國姻親而經趙王倫齊王冏事故能不豫際會良以其才短然亦以退靜免之

这一段从“字彦孙”起复写前面的《晋诸公赞》郭德、郭建、甄温、郭喜事，截去了前半，又被误接到郭后定嗣句后。

**时段与依据** 同本注012后半，参照012各具体年代。校本如此处接曹丕继位，郭德传只在前篇。

### 郭后告诫郭表、孟武

[《三国志·后妃传》裴注 016·1](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-016-1)

郭后称汉宫外戚多因骄奢不能保全，警告亲属谨慎。

**时段与依据** 《魏书》仅说“常勅戒”，无某年。

### 孙盛论魏三后出身

[《三国志·后妃传》裴注 018·1](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-018-1)

> 孫盛曰古之王者必求令淑以對揚至德恢王化於關雎致淳風於麟趾及臻三季並亂茲緒義以情溺位由寵昏貴賤無章下陵上替興衰隆廢皆是物也魏自武王暨于烈祖三后之升起自幽賤本既卑矣何以長世詩云絺兮綌兮凄其以風其此之謂矣

孙盛认为古礼应择贤德为后，批评魏三后起于微贱并以《诗》为论据。

**时段与依据** 后世史论，概括武帝以来后妃，无独立史事日期。

### 晋初郭建去世，郭嘏承嗣

[《三国志·后妃传》裴注 020·1](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-020-1)

> 晉諸公贊曰建字叔始有器局而彊問泰始中疾薨子嘏嗣為給事中

《晋诸公赞》称郭建有器局，泰始中病死，子郭嘏继爵并任给事中。

**时段与依据** 泰始265—274，未记何年死或拜官。

<a id="period-sgz005-p-021-2"></a>

### 郭后调护后宫与侍奉太后

[《三国志·后妃传》裴注 021·2](../../sources/摘录/三国志-卷005-后妃传裴注.md#pei-021-2)

> 后自在東宮及即尊位雖有異寵心愈恭肅供養永夀宮以孝聞是時柴貴人亦有寵后教訓奬導之後宮諸貴人時有過失常彌覆之有譴讓輙為帝言其本末帝或大有所怒至為之頓首請罪是以六宮無怨性儉約不好音樂常慕漢明德馬后之為人

《魏书》说郭氏奉事永寿宫卞太后，劝导柴贵人，常为宫中人请求减免罪责，日常以节俭自持。

**时段与依据** 从东宫至立后后有长时范围，各事未具年月；该官书评价可和其他注文互校。

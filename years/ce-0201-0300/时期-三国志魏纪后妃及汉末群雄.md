# 汉末魏初的帝纪、后妃与群雄

[本世纪目录](README.md) · [全部世纪](../README.md) · [《三国志》分卷目录](../../拆分史书/三国志/README.md)

[本期相关史料](#sources-start)

<a id="event-1"></a>

1. **曹操家世、入仕与在己吾起兵。** 曹操出自沛国谯县，祖曹腾为宦官，父曹嵩为其养子，本纪说曹嵩生家已不可考。桥玄、何颙早识曹操；他先后为洛阳北部尉、议郎和颍川讨黄巾的骑都尉。董卓废立后，曹操避出洛阳，至陈留出资募兵，冬十二月在己吾举兵。 [[1]](#note-1)

<a id="event-2"></a>

2. **讨董卓联盟与曹操入东郡。** 关东各军起兵推袁绍为盟主。董卓迁献帝至长安、焚洛阳宫室，诸军徘徊；曹操在汴水败给徐荣，随后招兵回河内。袁绍取冀州，曹操击破白绕，接掌东郡。 [[2]](#note-2)

<a id="event-3"></a>

3. **黄巾降兖、徐州用兵与兖州反叛。** 曹操先对付黑山军，又乘刘岱死取得兖州，击降青州黄巾，将所收精锐编为青州兵。袁术败于匡亭；曹操先后两次攻徐州，后一次因张邈、陈宫迎吕布而撤兵。荀彧、程昱保住少数县，曹操得以回攻。 [[3]](#note-3)

<a id="event-4"></a>

4. **兖州收复、迎献帝都许与攻灭吕布。** 曹操攻取定陶，重新控制兖州。他迎献帝到许后介入朝政，破杨奉并任司空。张绣先降后叛，曹昂、曹安民遇害；曹操后来在安众破敌，又围下邳擒杀吕布。袁绍并公孙瓒后，双方争夺祭朝权力和河北、河南各地。 [[4]](#note-4)

<a id="event-5"></a>

5. **官渡和袁氏兄弟之争。** 曹操先破刘备，后救白马、战延津、守官渡，并袭烧袁绍乌巢的储粮。袁绍败后仍经营河北，去世后袁谭、袁尚争立。曹操取邺后免河北当年租赋，以冀州为据。 [[5]](#note-5)

<a id="event-6"></a>

6. **汉中失守、樊城围解与曹操死。** 夏侯渊在汉中战死，曹操亲自到阳平后撤回。关羽趁大水俘于禁，徐晃进兵解樊城围，孙权也从荆州后方取地。曹操建安二十五年正月死于洛阳，遗命简葬；陈寿把其成功归于用人和谋略。 [[6]](#note-6)

<a id="event-7"></a>

7. **曹丕承袭魏王与延康政局。** 曹丕早任五官中郎将、丞相副手，后成为魏太子。曹操死后，他继为魏王、丞相，改建安二十五年为延康。此段记人事、边郡叛服、南下和地方献瑞。 [[7]](#note-7)

<a id="event-8"></a>

8. **黄初四至七年与曹丕遗命。** 曹丕禁私仇、立太学及课试法，巡淮、到广陵察看渡江条件。病重时命曹真、陈群、曹休和司马懿辅政。陈寿记其著述及《皇览》，并评其文才与处政。 [[8]](#note-8)

<a id="event-9"></a>

9. **平辽东及曹叡托孤。** 司马懿率军围襄平，公孙渊败死。明帝病重时任用曹爽、司马懿共辅少主，旋死于嘉福殿。陈寿称其决断，批评天下未合就大兴宫室。 [[9]](#note-9)

<a id="event-10"></a>

10. **高平陵政变后至嘉平五年。** 司马懿借皇帝出谒高平陵奏免曹爽兄弟，继而诛灭曹爽集团。王凌谋立楚王曹彪又败。魏吴先战东关，随后吴军围合肥新城而退。 [[10]](#note-10)

<a id="event-11"></a>

11. **李丰案、废齐王、迎曹髦。** 李丰等谋以夏侯玄代司马师，事败被诛。曹芳退位归藩，太后令立曹髦。曹髦入洛阳时辞前殿与法驾，司马师仍总军政。 [[11]](#note-11)

<a id="event-12"></a>

12. **曹髦遇害、身后礼及曹奂入继。** 曹髦死后，纪中连收太后令、诸臣奏和司马昭自陈，显示当时各方正式表述。曹奂原为常道乡公，入洛阳后即帝位；异说应并读《通鉴》及相关传。 [[12]](#note-12)

<a id="event-13"></a>

13. **咸熙改制、钟会之变及晋代魏。** 钟会在成都兵变，钟会、邓艾先后被杀。朝廷平蜀之后处理吴军、交州来附及屯田官。司马炎累进为晋世子，曹奂在咸熙二年末禅位。评价回溯明帝择嗣、少主废立及曹髦之死。 [[13]](#note-13)

<a id="event-14"></a>

14. **魏后宫名位与沿革。** 魏基本沿用汉朝太皇太后、皇太后、皇后等称号，内官品级经曹操、曹丕、曹叡增损。卷首列贵嫔以下各等可比官爵。 [[14]](#note-14)

<a id="event-15"></a>

15. **武宣卞氏及外家。** 卞氏出身倡家，早年从曹操至洛。曹操起兵时她劝部曲不要因误传而散。封王后、太后及追谥外亲牵涉陈群对因外戚分土授爵的意见。 [[15]](#note-15)

<a id="event-16"></a>

16. **甄氏由袁家到魏及追尊。** 甄氏幼时赈给亲里，原为袁熙妻；曹氏平邺后被曹丕所纳，生曹叡。她在黄初二年被赐死，曹叡即位后为其追谥、建庙，并优礼母族。 [[16]](#note-16)

<a id="event-17"></a>

17. **文德郭氏与外家约束。** 郭氏因机谋得宠，曹丕立她为皇后。她告诫亲族勿倚权势强婚，并拒过度役劳和厚葬。曹叡朝尊为太后，追封郭氏亲族。 [[17]](#note-17)

<a id="event-18"></a>

18. **毛皇后受宠与被赐死。** 毛氏由东宫受宠，曹叡即位后为皇后。郭氏得宠后，毛后因知北园曲宴一事触怒曹叡，被赐死。 [[18]](#note-18)

<a id="event-19"></a>

19. **明元郭氏临朝名义与陈寿总评。** 郭氏由河右大族入宫，在曹叡病重时被立为后；其太后名义见于曹爽被诛及曹芳、曹髦、曹奂诸次废立。陈寿比较魏与东汉外戚，并讨论朝廷约束。 [[19]](#note-19)

<a id="event-20"></a>

20. **董卓进京、迁都和遇诛。** 董卓在陇西结交羌中豪帅，后来领兵入洛阳，借禁中政变收并兵众，以废立擅权。关东各州郡举兵后，他把天子迁到长安，留军洛阳，并焚毁宫室。王允、士孙瑞与吕布约定内外响应，董卓入朝时被杀。 [[20]](#note-20)

<a id="event-21"></a>

21. **李傕郭汜据长安与献帝东归。** 董卓死后，李傕等因求赦未果听从贾诩，收兵围长安，掌控朝廷。李傕、郭汜互攻，各自扣押天子和公卿。献帝由杨奉等护送向洛阳，后由曹操迎都许。此段把不同年份的郭汜死和李傕覆灭连叙，需与《献帝纪》及《武帝纪》分年核查。 [[21]](#note-21)

<a id="event-22"></a>

22. **袁绍据河北及败于官渡。** 袁绍出身累世公卿之家，与何进谋诛宦官。反对董卓废立后出奔，从韩馥手中取得冀州，最终击败公孙瓒。迎天子、攻许、用将等事上，郭图、沮授和田丰意见不同。官渡败后，袁绍回河北收拾余部，建安七年病死。 [[22]](#note-22)

<a id="event-23"></a>

23. **袁谭、袁尚相争及河北改属。** 袁绍未定继承人，审配等立少子袁尚，袁谭不服。曹操一度答应援袁谭，继而围邺。袁尚离邺后投袁熙，袁谭收其军、在南皮抵抗曹操。 [[23]](#note-23)

<a id="event-24"></a>

24. **袁术在淮南称帝。** 袁术由洛阳走南阳，借兵孙坚与刘表争荆州，后来转至寿春。他用家世和图谶劝百官承认新位，主簿阎象以周文王仍事殷相劝。江淮饥馑、军资不足，袁术失势后死于路途。 [[24]](#note-24)

<a id="event-25"></a>

25. **刘表守荆州、刘琮举州降及史评。** 刘表以襄阳为根据，拒孙坚、控江汉。官渡相持时答应袁绍求助而未出兵。曹操南下时刘表病死，蔡瑁等扶刘琮继位，蒯越、傅巽等劝其降曹。陈寿合论董卓、袁术、袁绍、刘表的用人和成败。 [[25]](#note-25)

<a id="event-26"></a>

26. **吕布从并州到长安、河北。** 吕布杀丁原归董卓，后与王允合谋杀董卓。李傕等攻破长安后，吕布先求袁术容纳，继而依袁绍，与张燕作战，最终又离开袁绍。 [[26]](#note-26)

<a id="event-27"></a>

27. **张邈迎吕布、吕布败亡。** 曹操征徐州时，张邈、陈宫等迎吕布据兖州，张邈之弟张超后来死于雍丘。吕布转入徐州，夺下邳，与刘备、袁术时合时战。陈珪劝断袁术婚议；曹操围下邳后吕布被执而死。 [[27]](#note-27)

<a id="event-28"></a>

28. **陈宫与陈登。** 陈宫被俘后不请求曹操宽赦自身，把老母及女儿交给曹操处置。陈登与曹操夹攻吕布，以功迁伏波将军；刘备评他有湖海豪气。 [[28]](#note-28)

<a id="event-29"></a>

29. **臧洪发起会盟、拒袁绍及卷末评论。** 臧洪劝张超动员郡兵讨董卓，在诸郡结盟时登坛陈词。此后任袁绍所置东郡太守，因袁绍拒援张超而与其决裂，守城至粮尽。陈琳来书劝降而未能改变其决定；城陷后臧洪与陈容一同被杀。 [[29]](#note-29)

<a id="event-30"></a>

30. **公孙瓒边功、与刘虞冲突。** 公孙瓒以边将起家，参与征讨张纯，朝廷同时任刘虞安抚幽州。讨董之际袁绍、韩馥推刘虞为帝而受拒。公孙瓒与袁绍交兵失利，又与刘虞争权，最后杀刘虞。 [[30]](#note-30)

<a id="event-31"></a>

31. **易京战败与幽州部众归向。** 袁绍在书中数说公孙瓒先前交兵之事，后来围易京。公孙瓒多筑京垒自守，外援没有来得及解围，城破后自杀。鲜于辅、阎柔后来陆续接受朝命或归曹操。 [[31]](#note-31)

<a id="event-32"></a>

32. **陶谦治徐州及曹操两次东征。** 陶谦平徐州黄巾，以使者绕道通长安，又获州牧之任。曹操在初平四年与兴平元年两度东征；陶谦于后一年的交兵期间病死。 [[32]](#note-32)

<a id="event-33"></a>

33. **张杨拥护献帝回洛阳。** 张杨由西园部将转据河内，曾向献帝供粮并修洛阳宫室。曹操迎献帝都许后，张杨留屯野王；后来被部将杨丑所杀，眭固又杀杨丑。 [[33]](#note-33)

<a id="event-34"></a>

34. **公孙氏在辽东从起势到覆亡。** 公孙度以辽东太守割据海东，子康杀袁尚、袁熙并送首级。公孙恭接任后被公孙渊所夺。公孙渊接受魏吴两方往来，一度杀吴使，最终称燕王，司马懿围襄平后灭其政权。 [[34]](#note-34)

<a id="event-35"></a>

35. **张燕与张绣。** 张燕联络黑山诸部，与袁绍、公孙瓒等势力周旋，后率部降曹。张绣继张济屯宛，与刘表相援，依贾诩之谋先叛后再归曹操。 [[35]](#note-35)

<a id="event-36"></a>

36. **张鲁治理汉中、降魏与论赞。** 张鲁继祖父、父亲所传道法，设置祭酒和义舍，治理汉中。曹操攻阳平关后，张鲁退入巴地，未焚仓库，最终归降。陈寿把辽东、公孙瓒和其余割据者一同评说。 [[36]](#note-36)

## 《武帝纪》未定年、跨年及论说

下列材料按卷内次序列出。范围、相对次序及所据史料随引文列明。

<a id="wu-period-b-003-1"></a>

### 曹操籍贯与世系

[《三国志·武帝纪》仓内原文 L3](../../拆分史书/三国志/卷001.md#l3)

曹操字孟德，沛国谯人，史书称其为汉相国曹参的后裔。

**时段与依据** 传首身份和家世，原书不载形成时间。

<a id="wei001-l3-1"></a>

**[《三國志·武帝紀》正文](../../拆分史书/三国志/卷001.md#edition-wei001-l3-1)** · [TXT L3](../../拆分史书/三国志/卷001.txt#L3)

> 太祖武皇帝，沛國譙人也，姓曹，諱操，字孟德，漢相國參之後。

**釋讀與歸年** 曹操名操、字孟德，沛国谯人。陈寿追叙曹氏出自汉相曹参，传首身份、谱系无独立年次。

<a id="wu-period-b-003-3"></a>

### 曹嵩为曹腾养子并承嗣

[《三国志·武帝纪》仓内原文 L3](../../拆分史书/三国志/卷001.md#l3)

曹腾养曹嵩为子，曹嵩承嗣。

**时段与依据** 收养和承嗣的确年均无记。

<a id="wei001-l7-1"></a>

**[《三國志·武帝紀》正文](../../拆分史书/三国志/卷001.md#edition-wei001-l7-1)** · [TXT L7](../../拆分史书/三国志/卷001.txt#L7)

> 養子嵩嗣，

**釋讀與歸年** 曹腾的养子曹嵩承嗣，何时收养、袭爵无确年。

<a id="wu-period-b-003-5"></a>

### 曹嵩本生世系未详

[《三国志·武帝纪》仓内原文 L3](../../拆分史书/三国志/卷001.md#l3)

陈寿说曹嵩本生的家世无法审定。

**时段与依据** 作者说明世系证据的限度。

<a id="wei001-l7-3"></a>

**[《三國志·武帝紀》正文](../../拆分史书/三国志/卷001.md#edition-wei001-l7-3)** · [TXT L7](../../拆分史书/三国志/卷001.txt#L7)

> 莫能審其生出本末。

**釋讀與歸年** 陈寿称曹嵩的本生谱系无从核实。其出自夏侯氏是下文裴注所引一种说法。

<a id="wu-period-b-003-6"></a>

### 曹操约生于155年

[《三国志·武帝纪》仓内原文 L3](../../拆分史书/三国志/卷001.md#l3)

曹嵩生曹操。据曹操卒年年龄可推其约生于永寿元年。

**时段与依据** 据同卷 L124 载建安二十五年（220）曹操卒、年六十六，按传统虚岁回推为155年。《后汉书》桓帝纪为永寿元年；本句不载生年月。

<a id="wei001-l9-1"></a>

**[《三國志·武帝紀》正文](../../拆分史书/三国志/卷001.md#edition-wei001-l9-1)** · [TXT L9](../../拆分史书/三国志/卷001.txt#L9)

> 嵩生太祖。

**釋讀與歸年** 曹嵩生曹操。以卷末220年卒、虚岁六十六逆推，曹操约生于155年，卷首未记出生年月。

<a id="wu-period-b-004-1"></a>

### 曹操少时与桥玄、何颙品评

[《三国志·武帝纪》仓内原文 L4](../../拆分史书/三国志/卷001.md#l4)

曹操少时机警善权变、任侠不拘，桥玄、何颙器重他，桥玄预言他可能安定天下。

**时段与依据** 传文仅称“少”；《后汉书》桥玄传载曹操少时见桥玄，但未记会见确年。

<a id="wei001-l11-1"></a>

**[《三國志·武帝紀》正文](../../拆分史书/三国志/卷001.md#edition-wei001-l11-1)** · [TXT L11](../../拆分史书/三国志/卷001.txt#L11)

> 太祖少機警，有權數，而任俠放蕩，不治行業，故世人未之奇也；

**釋讀與歸年** 曹操年少机警善权变，又任侠放荡，时人多未看重；少年经历没有一个确年。

<a id="wei001-l13-1"></a>

**[《三國志·武帝紀》正文](../../拆分史书/三国志/卷001.md#edition-wei001-l13-1)** · [TXT L13](../../拆分史书/三国志/卷001.txt#L13)

> 惟梁國橋玄、南陽何顒異焉。玄謂太祖曰：「天下將亂，非命世之才不能濟也，能安之者，其在君乎！」

**釋讀與歸年** 桥玄、何颙赏识曹操，桥玄说乱世须命世之才方能安定天下。《后汉书·桥玄传》称曹操“微时”往见，无年月。

<a id="wu-period-b-004-2"></a>

### 曹操约174年举孝廉为郎

[《三国志·武帝纪》仓内原文 L4](../../拆分史书/三国志/卷001.md#l4)

曹操二十岁时被推举为孝廉，入朝为郎。

**时段与依据** 据本纪 L124 的220年卒、年六十六，按虚岁生年155推为174；原书仅记年龄。

<a id="wei001-l15-1"></a>

**[《三國志·武帝紀》正文](../../拆分史书/三国志/卷001.md#edition-wei001-l15-1)** · [TXT L15](../../拆分史书/三国志/卷001.txt#L15)

> 年二十，舉孝廉爲郎，

**釋讀與歸年** 曹操二十岁举孝廉为郎。若依220年卒年六十六按虚岁回推，约174年，正文未记年号。

<a id="wu-period-b-004-3"></a>

### 曹操任洛阳北部尉、顿丘令、议郎

[《三国志·武帝纪》仓内原文 L4](../../拆分史书/三国志/卷001.md#l4)

曹操又任洛阳北部尉，迁顿丘令，后被征拜议郎。

**时段与依据** 本纪将三官续叙于二十岁举孝廉之后、184年讨黄巾之前，各任没有独立年纪，不能把三次任命并系举孝廉之年。 《后汉书·刘陶传》明记曹操光和五年（182）已以议郎身份与陈耽上书，初拜之年仍不详。

<a id="wei001-l15-2"></a>

**[《三國志·武帝紀》正文](../../拆分史书/三国志/卷001.md#edition-wei001-l15-2)** · [TXT L15](../../拆分史书/三国志/卷001.txt#L15)

> 除洛陽北部尉，遷頓丘令，

**釋讀與歸年** 曹操任洛阳北部尉，后转顿丘令，均在举孝廉之后，各任无确年。

<a id="wei001-l17-1"></a>

**[《三國志·武帝紀》正文](../../拆分史书/三国志/卷001.md#edition-wei001-l17-1)** · [TXT L17](../../拆分史书/三国志/卷001.txt#L17)

> 徵拜議郎。

**釋讀與歸年** 曹操受征拜议郎。《后汉书·刘陶传》记他光和五年（182）以议郎上疏，初拜年不详；裴注另叙宋奇案后复任。

<a id="wu-period-b-005-2"></a>

### 曹操任济南相，罢治贪吏与淫祀

[《三国志·武帝纪》仓内原文 L5](../../拆分史书/三国志/卷001.md#l5)

曹操迁为济南相，奏免阿附贵戚且贪污的八县长吏，禁止非礼的祭祀活动，地方治安好转。

**时段与依据** 明在中平元年从军以后、为典军校尉以前；本书仅记“遷”，任命和一系列处置无独立年记。

<a id="wei001-l20-2"></a>

**[《三國志·武帝紀》正文](../../拆分史书/三国志/卷001.md#edition-wei001-l20-2)** · [TXT L20](../../拆分史书/三国志/卷001.txt#L20)

> 遷爲濟南相，國有十餘縣，長吏多阿附貴戚，贓污狼藉，於是奏免其八；禁斷淫祀，姦宄逃竄，郡界肅然。

**釋讀與歸年** 曹操迁济南相，奏免八县贪污长吏，禁淫祀。任相在184年参加讨黄巾之后，始任及处置年月未载。

<a id="wu-period-b-005-3"></a>

### 曹操辞东郡太守、称病居乡

[《三国志·武帝纪》仓内原文 L5](../../拆分史书/三国志/卷001.md#l5)

久后曹操被征任东郡太守，他推辞称病返乡。

**时段与依据** 传文“久之”不能精确换算；区别于191年袁绍表曹操为东郡太守。

<a id="wei001-l22-1"></a>

**[《三國志·武帝紀》正文](../../拆分史书/三国志/卷001.md#edition-wei001-l22-1)** · [TXT L22](../../拆分史书/三国志/卷001.txt#L22)

> 乆之，徵還爲東郡太守；不就，稱疾歸鄉里。

**釋讀與歸年** 曹操被征为东郡太守，辞而称疾归乡。“乆之”无确月，区别于191年实际出任东郡太守。

<a id="wu-period-b-013-2"></a>

### 袁绍向曹操示玉印

[《三国志·武帝纪》仓内原文 L13](../../拆分史书/三国志/卷001.md#l13)

袁绍曾得一枚玉印，在与曹操同座时举给他看，曹操暗自反感。

**时段与依据** 本纪仅称“甞”；与拥刘虞一事相邻，未提供与当年或同次会面相锁的证据。

<a id="wei001-l56-1"></a>

**[《三國志·武帝紀》正文](../../拆分史书/三国志/卷001.md#edition-wei001-l56-1)** · [TXT L56](../../拆分史书/三国志/卷001.txt#L56)

> 紹又甞得一玉印，於太祖坐中舉向其肘，太祖由是笑而惡焉。

**釋讀與歸年** 袁绍向曹操出示所得玉印，曹操嘲笑并恶其所为。原文只说“甞”，邻接刘虞事仍不能断为同年。

<a id="wu-period-b-024-2"></a>

### 孙策数年间经营江东

[《三国志·武帝纪》仓内原文 L24](../../拆分史书/三国志/卷001.md#l24)

孙策渡江后用数年时间建立江东基业。

**时段与依据** 本纪明说“數年閒”，综合叙述渡江、据会稽及往后平定诸郡，未给出一个完成年。

<a id="wei001-l73-4"></a>

**[《三國志·武帝紀》正文](../../拆分史书/三国志/卷001.md#edition-wei001-l73-4)** · [TXT L73](../../拆分史书/三国志/卷001.txt#L73)

> 數年閒遂有江東。

**釋讀與歸年** 孙策渡江后经过数年才取得江东。对曲阿、会稽等郡的用兵各有年次，不把这句数年回顾压为一年。

<a id="wu-period-b-025-2"></a>

### 曹嵩去官后避难琅邪

[《三国志·武帝纪》仓内原文 L25](../../拆分史书/三国志/卷001.md#l25)

曹操父曹嵩卸任后返谯，董卓之乱时避难琅邪。

**时段与依据** 《后汉书·灵帝纪》188年载曹嵩罢太尉；L25的居谯和避琅邪只知在董卓之乱期间，不能系一个年。

<a id="wei001-l75-2"></a>

**[《三國志·武帝紀》正文](../../拆分史书/三国志/卷001.md#edition-wei001-l75-2)** · [TXT L75](../../拆分史书/三国志/卷001.txt#L75)

> 初，太祖父嵩去官後還譙，董卓之亂，避難琅邪，

**釋讀與歸年** 曹嵩去官返谯，在董卓之乱中避居琅邪。《后汉书·灵帝纪》记他188年罢太尉，迁居年月未载。

<a id="wu-period-b-033-1"></a>

### 何仪等此前曾依附袁术和孙坚

[《三国志·武帝纪》仓内原文 L33](../../拆分史书/三国志/卷001.md#l33)

### 曹操别名及曹氏上古世系的说法

[《三国志·武帝纪》裴注 001·1](../../拆分史书/三国志/卷001.md#pei-001-1)

曹操一名吉利、小字阿瞒。王沈《魏书》上推祖源到黄帝、高阳、陆终与曹安，据称周武王封曹侠于邾，春秋时参与盟会，战国为楚所灭，后人流散，部分居沛。

**时段与依据** 《魏书》累计叙述数代和多个时代，不能连成可逐年判定的世系；邾为楚所灭的年份亦未见本句或同事确证。

<a id="wei001-l4-1"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l4-1)** · [TXT L4](../../拆分史书/三国志/卷001.txt#L4)

> 太祖一名吉利，小字阿瞞。　王沈魏書曰：其先出於黃帝。當高陽世，陸終之子曰安，是爲曹姓。周武王克殷，存先世之後，封曹俠於邾。春秋之世，與於盟會，逮至戰國，爲楚所滅。子孫分流，或家于沛。

**釋讀與歸年** 吉利、阿瞒是曹操的别名与小字。王沈《魏书》又从黄帝、高阳、陆终叙至邾灭于楚与族裔分居，属于跨世谱系。

### 曹腾家世、父曹节让猪与初仕

[《三国志·武帝纪》裴注 002·1](../../拆分史书/三国志/卷001.md#pei-002-1)

《续汉书》说曹节仁厚，有邻人误认曹节家的猪，曹节不争，邻人找回自家猪才送还致歉；又举曹节四子，称曹腾少时任黄门从官。

**时段与依据** 让猪与曹氏兄弟无确年。《后汉书·曹腾传》仅称他在安帝朝任黄门从官。

<a id="wei001-l6-1"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l6-1)** · [TXT L6](../../拆分史书/三国志/卷001.txt#L6)

> 司馬彪續漢書曰：騰父節，字元偉，素以仁厚稱。鄰人有亡豕者，與節豕相類，詣門認之，節不與爭；後所亡豕自還其家，豕主人大慙，送所認豕，并辭謝節，節笑而受之。由是鄉黨貴歎焉。長子伯興，次子仲興，次子叔興。騰字季興，少除黃門從官。

**釋讀與歸年** 曹腾父曹节曾让邻人误认的猪，邻人后来归还，乡里因此称道。曹节诸子排行及曹腾少任黄门从官，均无确年。

[《三国志·武帝纪》裴注 002·4](../../拆分史书/三国志/卷001.md#pei-002-4)

**时段与依据** 分属多朝；《后汉书》L5572说明中常侍在顺帝时，大长秋在桓帝得立后，本句为合述。

### 种暠劾曹腾未成

[《三国志·武帝纪》裴注 002·5](../../拆分史书/三国志/卷001.md#pei-002-5)

益州刺史种暠搜得蜀郡太守给曹腾的信，认为其不当结交外官，请治罪。皇帝以信由外面寄来为由不追究，曹腾也称赏种暠尽职，未记恨他。

**时段与依据** 《后汉书·曹腾传》L5573 并载，但未系年；该书所载地名作斜谷关，与注作函谷关有异。

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l6-5)** · [TXT L6](../../拆分史书/三国志/卷001.txt#L6)

> 蜀郡太守因計吏修敬於騰，益州刺史种暠於函谷關搜得其牋，上太守，并奏騰內臣外交，所不當爲，請免官治罪。帝曰：「牋自外來，騰書不出，非其罪也。」乃寑暠奏。騰不以介意，常稱歎暠，以爲暠得事上之節。

**釋讀與歸年** 益州刺史种暠截获蜀郡太守送曹腾的信，指控太守及曹腾。皇帝搁置弹劾，曹腾反赞种暠尽职。《后汉书·曹腾传》作斜谷关，注文作函谷关，两者都未记确年。

### 曹操少时装病骗过叔父

[《三国志·武帝纪》裴注 004·1](../../拆分史书/三国志/卷001.md#pei-004-1)

《曹瞒传》说曹操年少时爱放鹰走狗，被叔父屡次告知父亲曹嵩。曹操假装中风，叔父报告后曹嵩召见却发现他神色正常，自此不再相信叔父的议论。

**时段与依据** 原注只说“少”“後”，没有年。底本署名为《曹瞞傳》；点校影印相关校补及异文见卷页校记。

<a id="wei001-l12-1"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l12-1)** · [TXT L12](../../拆分史书/三国志/卷001.txt#L12)

> 曹瞞傳云：太祖少好飛鷹走狗，游蕩無度，其叔父數言之於嵩。太祖患之，後逢叔父於路，乃陽敗面喎口；叔父怪而問其故，太祖曰：「卒中惡風。」叔父以告嵩。嵩驚愕，呼太祖，太祖口貌如故。嵩問曰：「叔父言汝中風，已差乎？」太祖曰：「初不中風，但失愛於叔父，故見罔耳。」嵩乃疑焉。自後叔父有所告，嵩終不復信，太祖於是益得肆意矣。

**釋讀與歸年** 《曹瞒传》说少年曹操故意歪嘴装中风，使曹嵩不信叔父对其游荡的告诫。该书仅称“少”，无确年。

### 桥玄识曹操及桥玄为人

[《三国志·武帝纪》裴注 005·1](../../拆分史书/三国志/卷001.md#pei-005-1)

《魏书》记桥玄十分看重曹操，并想托付妻儿，曹操因此知名。《续汉书》说桥玄有才略、善识人；张璠《汉纪》说他任职中外、刚断谦俭。

**时段与依据** 《后汉书·桥玄传》L3865说曹操微时拜见，无确年。在引文中“太尉”可以是回称，不能直接当会见时的现职。

<a id="wei001-l14-1"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l14-1)** · [TXT L14](../../拆分史书/三国志/卷001.txt#L14)

> 魏書曰：太尉橋玄，世名知人，覩太祖而異之，曰：「吾見天下名士多矣，未有若君者也！君善自持。吾老矣！願以妻子爲託。」由是聲名益重。　續漢書曰：玄字公祖，嚴明有才略，長於人物。　張璠漢紀曰：玄歷位中外，以剛斷稱，謙儉下士，不以王爵私親。

**釋讀與歸年** 《魏书》写桥玄欣赏曹操、欲托付家人；《续汉书》《张璠汉纪》述桥玄方正而礼士。称桥玄为太尉可属回称，见曹操之年待考。

### 曹操见许劭、闯张让宅及研究兵法

[《三国志·武帝纪》裴注 005·5](../../拆分史书/三国志/卷001.md#pei-005-5)

《世语》称桥玄荐曹操去见许劭，曹操因而取得声名。孙盛说曹操闯入张让居处后挥戟翻墙脱身，遍览群书、编《接要》并注《孙武》十三篇，又问许劭自己怎样，许劭以“治世之能臣、乱世之姦雄”品评。

**时段与依据** 会见许劭、越墙、著述均未明年。《后汉书·许劭传》另记品评措辞，不能用赞语在本纪的位置定著述年。

<a id="wei001-l14-5"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l14-5)** · [TXT L14](../../拆分史书/三国志/卷001.txt#L14)

> 世語曰：玄謂太祖曰：「君未有名，可交許子將。」太祖乃造子將，子將納焉，由是知名。孫盛異同雜語云：太祖甞私入中常侍張讓室，讓覺之；乃舞手戟於庭，踰垣而出。才武絕人，莫之能害。博覽群書，特好兵法，抄集諸家兵法，名曰接要，又注孫武十三篇，皆傳於世。甞問許子將：「我何如人？」子將不荅。固問之，子將曰：「子治世之能臣，亂世之姦雄。」太祖大笑。

**釋讀與歸年** 《世语》说桥玄劝曹操结识许劭，曹操由此知名；孙盛《异同杂语》兼述曹操武艺、辑兵法《接要》、注孙武及许劭的品评。此数事各无确年，《后汉书·许劭传》所录品评措辞另异。

### 曹操任北部尉立五色棒，后迁顿丘

[《三国志·武帝纪》裴注 006·1](../../拆分史书/三国志/卷001.md#pei-006-1)

《曹瞒传》说曹操整饬尉署，设五色棒，违禁不避权贵。数月后，他棒杀小黄门蹇硕的叔父；宫中权贵因而忌恨，反借举荐将他调做顿丘令。

**时段与依据** 仅“初入”“後數月”，与正文L4的任职先后吻合；各事件年月均无独立记载，不以举孝廉推年硬定。

<a id="wei001-l16-1"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l16-1)** · [TXT L16](../../拆分史书/三国志/卷001.txt#L16)

### 曹操任济南相举免贪吏，毁禁淫祠

**时段与依据** 同正文L5，接184年讨黄巾、在188年任典军校尉以前；刘章封王及定吕功可分别互参前178年及前180年，兴建其祠与曹操取缔不能跟着封王年入年。

<a id="wei001-l21-1"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l21-1)** · [TXT L21](../../拆分史书/三国志/卷001.txt#L21)

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l110-1)** · [TXT L110](../../拆分史书/三国志/卷001.txt#L110)

> 魏書曰：袁紹宿與故太尉楊彪、大長秋梁紹、少府孔融有隙，欲使公以他過誅之。公曰：「當今天下土崩瓦解，雄豪並起，輔相君長，人懷怏怏，各有自爲之心，此上下相疑之秋也，雖以無嫌待之，猶懼未信；如有所除，則誰不自危？且夫起布衣，在塵垢之間，爲庸人之所陵陷，可勝怨乎！高祖赦雍齒之讎而羣情以安，如何忘之？」紹以爲公外託公義，內實離異，深懷怨望。

**釋讀與歸年** 《魏書》稱袁紹欲借曹操之手誅楊彪、梁紹、孔融，曹操拒絕，袁紹心中生怨。這段引語未記年月，曹操所舉劉邦赦雍齒是說理用典。

《四体书势》说王次仲创楷法，灵帝好书时师宜官名气最大；梁鹄得其手迹苦学，后做到选部尚书。

**时段与依据** 参《晋书·卫恒传》；王次仲不系灵帝朝，“至靈帝”指下文，师宜官、梁鹄的具体年月未载。

<a id="wei001-l188-1"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l188-1)** · [TXT L188](../../拆分史书/三国志/卷001.txt#L188)

**时段与依据** 曹操布衣时及袁氏母丧为相对年代，未载确年。

<a id="wei001-l188-5"></a>

> 皇甫謐逸士傳曰：汝南王儁，字子文，少爲范滂、許章所識，與南陽岑晊善。公之爲布衣，特愛儁；儁亦稱公有治世之具。及袁紹與弟術喪母，歸葬汝南，儁與公會之，會者三萬人。公於外密語儁曰：「天下將亂，爲亂魁者必此二人也。欲濟天下，爲百姓請命，不先誅此二子，亂今作矣。」儁曰：「如卿之言，濟天下者，舍卿復誰？」相對而笑。

**时段与依据** 谈话约束在刘表治荆州及袁绍仍在世时；王俊卒年只能定在曹操迎葬即208年以前。

### 曹操追述济南任内整治政务与退居

[《三国志·武帝纪》裴注 074·3](../../拆分史书/三国志/卷001.md#pei-074-3)

**时段与依据** 令出210年；本纪L5载黄巾初战后迁济南相，后请退，未逐项记确年。

<a id="wei001-l195-3"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l195-3)** · [TXT L195](../../拆分史书/三国志/卷001.txt#L195)

> 故在濟南，始除殘去穢，平心選舉，違迕諸常侍。以爲彊豪所忿，恐致家禍，故以病還。去官之後，年紀尚少，顧視同歲中，年有五十，未名爲老，內自圖之，從此却去二十年，待天下清，乃與同歲中始舉者等耳。故以四時歸鄉里，於譙東五十里築精舍，欲秋夏讀書，冬春射獵，求底下之地，欲以泥水自蔽，絕賔客往來之望，然不能得如意。

**釋讀與歸年** 曹操回顧在濟南整肅吏治，得罪常侍及豪強而稱病回鄉。又說曾在譙東五十里築精舍，打算退處二十年，讀書、射獵以避交遊。退居和築舍具體年月未詳。

### 魏书记曹操读书赋诗与技艺

[《三国志·武帝纪》裴注 117·3](../../拆分史书/三国志/卷001.md#pei-117-3)

《魏书》载曹操三十余年用兵而手不释书，白天讲兵策、夜读经传，会赋诗作乐，又善射猎，曾在南皮一天获雉六十三只，并对建造器械多有制定。

**时段与依据** 总叙多年，南皮射雉无年，不能仅凭地点把故事定在攻南皮当年。

<a id="wei001-l310-3"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l310-3)** · [TXT L310](../../拆分史书/三国志/卷001.txt#L310)

> 是以刱造大業，文武並施，御軍三十餘年，手不捨書，晝則講武策，夜則思經傳，登高必賦，及造新詩，被之管絃，皆成樂章。才力絕人，手射飛鳥，躬禽猛獸，甞於南皮一日射雉獲六十三頭。及造作宮室，繕治器械，無不爲之法則，皆盡其意。

**釋讀與歸年** 《魏書》總記曹操好書、作詩譜樂、擅獵及擬造作法則。一日射雉六十三的事僅明南皮，未載年月。

<a id="wu-period-p-117-4"></a>

### 魏书记曹操节用、赏赐与预备殓服

[《三国志·武帝纪》裴注 117·4](../../拆分史书/三国志/卷001.md#pei-117-4)

《魏书》说后宫避免织绣饰物，寝具破了就补；战利品赏有功者，功应赏时不吝，亦不滥赏；以丧制用衣繁冗，预备殓服只四箱。

**时段与依据** 总叙生前习惯，没有按年记载所述赏赐、备衣。

<a id="wei001-l310-4"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l310-4)** · [TXT L310](../../拆分史书/三国志/卷001.txt#L310)

> 雅性節儉，不好華麗，後宮衣不錦繡，侍御履不二采，帷帳屏風，壞則補納，茵蓐取溫，無有緣飾。攻城拔邑，得靡麗之物，則悉以賜有功，勳勞宜賞，不吝千金，無功望施，分豪不與，四方獻御，與羣下共之。常以送終之制，襲稱之數，繁而無益，俗又過之，故預自制終亡衣服，四篋而已。

**釋讀與歸年** 《魏書》說曹操日用節儉，把繳獲賞給有功者，並自製殮服四篋。這是跨年概述。

<a id="wu-period-p-117-5"></a>

### 傅子记曹操节俭嫁女

[《三国志·武帝纪》裴注 117·5](../../拆分史书/三国志/卷001.md#pei-117-5)

《傅子》说曹操不满婚嫁奢华，女儿出嫁用黑帐，从婢不超过十人。

**时段与依据** 只见行为惯例，无特定婚嫁或年份。

<a id="wei001-l312-1"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l312-1)** · [TXT L312](../../拆分史书/三国志/卷001.txt#L312)

> 傅子曰：太祖愍嫁娶之奢僭，公女適人，皆以皁帳，從婢不過十人。

**釋讀與歸年** 《傅子》說曹操反對厚嫁，嫁女用皁帳、侍婢不過十人，未繫單一婚事。

<a id="wu-period-p-117-6"></a>

### 博物志记曹操艺能与方术

[《三国志·武帝纪》裴注 117·6](../../拆分史书/三国志/卷001.md#pei-117-6)

《博物志》拿曹操与崔瑗、张芝等书家及音乐、弈棋高手相比，又称其研习养生与方药，招左慈、华佗等方术之士，并有野葛、鸩酒的传说。

**时段与依据** 合述一个长时期的艺能与方术故事，未逐项标时，异事仍按原书说法。

<a id="wei001-l314-1"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l314-1)** · [TXT L314](../../拆分史书/三国志/卷001.txt#L314)

> 張華博物志曰：漢世，安平崔瑗、瑗子寔、弘農張芝、芝弟昶並善草書，而太祖亞之。桓譚、蔡邕善音樂，馮翊山子道、王九真、郭凱等善圍棊，太祖皆與埒能。又好養性法，亦解方藥，招引方術之士，廬江左慈、譙郡華他、甘陵甘始、陽城郄儉無不畢至，又習啖野葛至一尺，亦得少多飲鴆酒。

**釋讀與歸年** 張華《博物志》記曹操草書、音樂和圍棊，又列養生、醫藥、招方士。野葛、鴆酒及術士說屬原書異聞，事時不詳。

<a id="wu-period-p-117-7"></a>

### 傅子记曹操制定帢帽

[《三国志·武帝纪》裴注 117·7](../../拆分史书/三国志/卷001.md#pei-117-7)

《傅子》说汉末王公以幅巾为雅，曹操因财用不足仿古皮弁裁帛为帢，以颜色辨贵贱，认为这是军中服制。

**时段与依据** 文只明“漢末”及长期施行，未记制定确年。

<a id="wei001-l316-1"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l316-1)** · [TXT L316](../../拆分史书/三国志/卷001.txt#L316)

> 傅子曰：漢末王公，多委王服，以幅巾爲雅，是以袁紹、崔豹之徒，雖爲將帥，皆著縑巾。魏太祖以天下凶荒，資財乏匱，擬古皮弁，裁縑帛以爲帢，合于簡易隨時之義，以色別其貴賤，于今施行，可謂軍容，非國容也。

**釋讀與歸年** 《傅子》以漢末軍將用幅巾為背景，說曹操因物資匱乏，裁帛為帢、依色辨等級；具體制定年份不載。

<a id="wu-period-p-117-8"></a>

### 曹瞒传论曹操日常与严刑

[《三国志·武帝纪》裴注 117·8](../../拆分史书/三国志/卷001.md#pei-117-8)

《曹瞒传》称曹操喜乐舞、服饰轻便、谈笑戏谑而少威仪，同时称其用法苛严，对谋略胜己者及旧怨者不宽贷，行刑时虽落泪仍处死。

**时段与依据** 生平评价，与《魏书》立场并列，未见单一史事日期。

<a id="wei001-l318-1"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l318-1)** · [TXT L318](../../拆分史书/三国志/卷001.txt#L318)

> 曹瞞傳曰：太祖爲人佻易無威重，好音樂，倡優在側，常以日達夕。被服輕綃，身自佩小鞶囊，以盛手巾細物，時或冠帢帽以見賔客。每與人談論，戲弄言誦，盡無所隱，及歡恱大笑，至以頭沒柸案中，肴膳皆沾洿巾幘，其輕易如此。然持法峻刻，諸將有計畫勝出己者，隨以法誅之，及故人舊怨，亦皆無餘。其所刑殺，輒對之垂涕嗟痛之，終無所活。

**釋讀與歸年** 《曹瞞傳》先述曹操服飾、歌舞、待客言談，再以峻刑相對。屬原書跨年評述。

<a id="wu-period-p-117-9"></a>

### 袁忠欲依法治曹操，桓邵轻曹操

[《三国志·武帝纪》裴注 117·9](../../拆分史书/三国志/卷001.md#pei-117-9)

《曹瞒传》称沛相袁忠曾想依法处治曹操，沛国桓邵也轻视曹操。

**时段与依据** “初”起追叙，未给事件年份；《后汉书·袁安传》记袁忠初平年间（190–193）任沛相，不能缩至一个年。

<a id="wei001-l318-2"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l318-2)** · [TXT L318](../../拆分史书/三国志/卷001.txt#L318)

> 初，袁忠爲沛相，甞欲以法治太祖，沛國桓邵亦輕之，

**釋讀與歸年** 袁忠任沛相時曾想依法治曹操，桓邵也輕視曹操，年月無明文。

<a id="wu-period-p-117-10"></a>

### 曹操诛边让及其家

[《三国志·武帝纪》裴注 117·10](../../拆分史书/三国志/卷001.md#pei-117-10)

《曹瞒传》称曹操在兖州时，陈留边让出言冒犯，曹操杀边让并族其家。

**时段与依据** 《通鉴》卷061叙入194年兖州叛变的前因，使用“嘗”，《后汉书·边让传》称建安中，《袁绍传》所录陈琳檄文把此事放在失兖州前，纪年相冲，暂归时期。

<a id="wei001-l318-3"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l318-3)** · [TXT L318](../../拆分史书/三国志/卷001.txt#L318)

> 及在兖州，陳留邊讓言議頗侵太祖，太祖殺讓，族其家。

**釋讀與歸年** 《曹瞞傳》述曹操領兖州後，邊讓言議相侵而被殺並及家人。《後漢書·邊讓傳》只稱建安初，確年待考。

<a id="wu-period-p-117-11"></a>

### 袁忠、桓邵避交州及曹操追杀的异载

[《三国志·武帝纪》裴注 117·11](../../拆分史书/三国志/卷001.md#pei-117-11)

《曹瞒传》称袁忠、桓邵逃往交州，曹操遣使通知士燮诛其族，桓邵出来自首仍被处死。

**时段与依据** 原注未标年；《后汉书·袁安传》称袁忠徵为卫尉未到而卒，与此说须保留分别，不能因边让之事推定年。

<a id="wei001-l318-4"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l318-4)** · [TXT L318](../../拆分史书/三国志/卷001.txt#L318)

> 忠、邵俱避難交州，太祖遣使就太守止燮盡族之。桓邵得出首，拜謝於庭中，太祖謂曰：「跪可解死邪！」遂殺之。

**釋讀與歸年** 《曹瞞傳》說袁忠、桓邵逃交州，曹操遣使求殺，桓邵出首仍被殺。底本「止燮」與通常所稱士燮不同，保持原字，二人結局另有異載。

<a id="wu-period-p-117-12"></a>

### 曹操军中禁践麦与割发

[《三国志·武帝纪》裴注 117·12](../../拆分史书/三国志/卷001.md#pei-117-12)

《曹瞒传》记曹操下令禁军士践麦，自马入麦后要求议罚；主簿援引尊者不受罚，曹操遂割发作为自刑。

**时段与依据** 只记“常出軍”，无地无年，不能以小说情节替史料定年。

<a id="wei001-l318-5"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l318-5)** · [TXT L318](../../拆分史书/三国志/卷001.txt#L318)

> 甞出軍，行經麥中，令「士卒無敗麥，犯者死」。騎士皆下馬，付麥以相付，於是太祖馬騰入麥中，勑主簿議罪；主簿對以春秋之義，罰不加於尊。太祖曰：「制法而自犯之，何以帥下？然孤爲軍帥，不可自殺，請自刑。」因援劔割髮以置地。

**釋讀與歸年** 《曹瞞傳》記軍中禁踐麥，曹操失控的馬入麥田，自割髮示罰。原文未說是哪一場出兵。

<a id="wu-period-p-117-13"></a>

### 曹操杀侍妾的传闻

[《三国志·武帝纪》裴注 117·13](../../拆分史书/三国志/卷001.md#pei-117-13)

《曹瞒传》称侍妾没有照嘱咐叫醒熟睡的曹操，曹操醒来把她打死。

**时段与依据** 原注未载时间。

<a id="wei001-l318-6"></a>

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l318-6)** · [TXT L318](../../拆分史书/三国志/卷001.txt#L318)

> 又有幸姬常從晝寢，枕之卧，告之曰：「須臾覺我。」姬見太祖卧安，未即寤，及自覺，棒殺之。

**釋讀與歸年** 《曹瞞傳》說曹操令侍妾喚醒他，侍妾因不忍打擾而遭殺。未見時地。

<a id="wu-period-p-117-14"></a>

### 曹操以小斛给粮并斩粮吏的记载

[《三国志·武帝纪》裴注 117·14](../../拆分史书/三国志/卷001.md#pei-117-14)

《曹瞒传》称一次军粮不足，曹操同意用小斛发粮；军中不满时，他借粮吏之死平众议，宣称粮吏盗粮。

**时段与依据** 原注不载讨何人、何地与何年，不能据后世演义推定。

**[《三國志·武帝紀》裴注](../../拆分史书/三国志/卷001.md#edition-wei001-l318-7)** · [TXT L318](../../拆分史书/三国志/卷001.txt#L318)

> 常討賊，廩穀不足，私謂主者曰：「如何？」主者曰：「可以小斛以足之。」太祖曰：「善。」後軍中言太祖欺衆，太祖謂主者曰：「特當借君死以猒衆，不然事不解。」乃斬之，取首題徇曰：「行小斛，盜官穀，斬之軍門。」其酷虐變詐，皆此之類也。

**釋讀與歸年** 《曹瞞傳》記軍糧不足、用小斛發糧，曹操殺掌糧人以平息怨言。原文僅稱討賊，不能將故事硬系特定戰役。

# 《晋书》卷一〈宣帝纪〉｜未确年材料与跨代评论

[卷一原文](../../拆分史书/晋书/卷001.md) · [本世纪目录](README.md) · [全部世纪](../README.md)

不能独立确年的材料按时期阅读；有确年事件分入对应年页，跨年及跨代原段保留全文，并说明边界。“帝”在宣帝纪通常指追尊的司马懿，不表示其生前已称皇帝。

## 时期阅读

<a id="jin001-period-event-l4"></a>

1. **世系与早年识人。** 司马氏世系、司马懿少时志趣及杨俊、崔琰的识人言论没有分别标明年份。它们作为早年背景阅读；杨俊的“南阳太守”是传中冠称，不能据此断定相遇时已任该官。 [[1]](#jin001-l4)

<a id="jin001-period-event-l5"></a>

2. **再辟以后的一串迁官。** 建安六年首次征辟归201年，曹操为丞相后再辟为文学掾归208年。其后黄门侍郎、议郎、东曹属、主簿的升迁次序可知，各自年、月待考。 [[2]](#jin001-l5)

<a id="jin001-period-event-l7"></a>

3. **太子中庶子与“四友”的起始年。** “魏国既建”与迁太子中庶子连叙。魏国213年建，曹丕217年才正式立为魏太子；本段未说明任命在何月，也不能把“四友”形成硬定213年。 [[3]](#jin001-l7)

<a id="jin001-period-event-l8"></a>

4. **军司马、屯田建议与边将判断。** 司马懿任军司马、建议且耕且守，以及预言胡修、傅方不能守边，均未标独立年月。胡、傅后来于219年降关羽是确定事件；先前建议不因应验叙事而一并定219年。 [[4]](#jin001-l8)

<a id="jin001-period-event-l10"></a>

5. **关羽败后的迁民之议。** 关羽新败后，曹操拟迁荆州遗民、颍川屯田人口，司马懿反对，认为会伤害安居百姓并阻碍逃亡者归来。事件只能定位在219年末至曹操220年正月去世以前，尚不足分入某一个年页。 [[5]](#jin001-l10)

<a id="jin001-period-event-l22"></a>

6. **边户隐实与伐吴规划。** 孟达事后，魏欲核实新附边郡户口。司马懿入朝建议从宽，并回答先攻吴还是先攻蜀的问题，提出由皖城牵动孙权、从夏口进击的设想。 [[6]](#jin001-l22)

<a id="jin001-period-event-l74"></a>

7. **未载年月的改谥与终制。** 司马懿曾预定薄葬、作顾命三篇，斂以时服，不设明器，不许后来去世者合葬。本卷没有给预作终制、改谥宣文的年月，也没有保存顾命三篇全文。 [[7]](#jin001-l74)

<a id="jin001-period-event-l75"></a>

8. **史臣总评、狼顾故事与晋明帝问答。** 本段混合人物总评、曹操时期的狼顾与“三马同槽”故事、238年辽东杀戮、249年诛曹爽党，以及晋明帝听王导讲述得国经过而掩面的问答。不同年代的材料不能整体塞入司马懿卒年；梦兆、相术也不能作已验证的预言。 [[8]](#jin001-l75)

<a id="jin001-period-event-l77"></a>

9. **卷末“制曰”。** 卷末论赞既评司马懿军政才略，也批评其对诸葛亮持重及背负顾命、发动高平陵政变。它是修史者的后世评价，不能写成司马懿当时的自白，也不能把论赞中的用典移到相关古代年份当作新史事。 [[9]](#jin001-l77)

## 同号史料

### 1. 世系与早年识人

[返回正文第1条](#jin001-period-event-l4)

<a id="jin001-l4"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L4)**

> 宣皇帝諱懿，字仲達，河內溫縣孝敬里人，姓司馬氏。其先出自帝高陽之子重黎，為夏官祝融。歷唐、虞、夏、商，世序其職。及周，以夏官為司馬。其後程伯休父，周宣王時，以世官克平徐方，錫以官族，因而為氏。楚漢間，司馬卬為趙將，與諸侯伐秦。秦亡，立為殷王，都河內。漢以其地為郡，子孫遂家焉。自卬八世，生征西將軍鈞，字叔平。鈞生豫章太守量，字公度。量生潁川太守儁，字元異。儁生京兆尹防，字建公。帝即防之第二子也。少有奇節，聰朗多大略，博學洽聞，伏膺儒教。漢末大亂，常慨然有憂天下心。南陽太守同郡楊俊名知人，見帝，未弱冠，以為非常之器。尚書清河崔琰與帝兄朗善，亦謂朗曰：「君弟聰亮明允，剛斷英特，非子所及也。」

**釋讀與歸年** 本段为世系与早年总叙。只说杨俊见司马懿时其未弱冠，不据后来推算虚岁强造相遇年；古远世系是本纪自述，不在远古年表补成逐年事实。

### 2. 再辟以后的一串迁官

[返回正文第2条](#jin001-period-event-l5)

<a id="jin001-l5"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L5)**

> 漢建安六年，郡舉上計掾。魏武帝為司空，聞而辟之。帝知漢運方微，不欲屈節曹氏，辭以風痹，不能起居。魏武使人夜往密刺之，帝堅臥不動。及魏武為丞相，又辟為文學掾，敕行者曰：「若復盤桓，便收之。」帝懼而就職。於是使與太子游處，遷黃門侍郎，轉議郎、丞相東曹屬，尋轉主簿。

**釋讀與歸年** 为读清官职次序保留全段；确年事件仍见[201年](ce-0201.md)和[208年](ce-0208.md)，此处仅承接没有独立年月的迁官，不能将后续诸官都归208年。

### 3. 太子中庶子与“四友”的起始年

[返回正文第3条](#jin001-period-event-l7)

<a id="jin001-l7"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L7)**

> 魏國既建，遷太子中庶子。每與大謀，輒有奇策，為太子所信重，與陳羣、吳質、朱鑠號曰四友。

**釋讀與歸年** “魏国既建”为相对背景，不能取代任职日期。相关确年背景分见[213年](ce-0213.md)、[217年](ce-0217.md)，本页保存任官与四友的未确年边界。

### 4. 军司马、屯田建议与边将判断

[返回正文第4条](#jin001-period-event-l8)

<a id="jin001-l8"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L8)**

> 遷為軍司馬，言於魏武曰：「昔箕子陳謀，以食為首。今天下不耕者蓋二十餘萬，非經國遠籌也。雖戎甲未卷，自宜且耕且守。」魏武納之，於是務農積穀，國用豐贍。帝又言荊州刺史胡脩粗暴，南鄉太守傅方驕奢，並不可居邊。魏武不之察。及蜀將關羽圍曹仁於樊，于禁等七軍皆沒，脩、方果降羽，而仁圍甚急焉。

**釋讀與歸年** 全段保留前因后果；末尾关羽围樊及胡、傅降羽见[219年](ce-0219.md)。二十余万不耕者、屯田建议的具体提出时间暂不独立定年。

### 5. 关羽败后的迁民之议

[返回正文第5条](#jin001-period-event-l10)

<a id="jin001-l10"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L10)**

> 魏武以荊州遺黎及屯田在潁川者逼近南寇，皆欲徙之。帝曰：「荊楚輕脫，易動難安。關羽新破，諸為惡者藏竄觀望。今徙其善者，既傷其意，將令去者不敢復還。」從之。其後諸亡者悉復業。

**釋讀與歸年** “关羽新破”给出时间下限，曹操在世给出上限；归还本业还可能延续更久。未用段落紧邻位置虚造某一月日。

### 6. 边户隐实与伐吴规划

[返回正文第6条](#jin001-period-event-l22)

<a id="jin001-l22"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L22)**

> 時邊郡新附，多無戶名，魏朝欲加隱實。屬帝朝於京師，天子訪之於帝。帝對曰：「賊以密網束下，故下棄之。宜弘以大綱，則自然安樂。」又問二虜宜討，何者為先？對曰：「吳以中國不習水戰，故敢散居東關。凡攻敵，必扼其喉而摏其心。夏口、東關，賊之心喉。若為陸軍以向皖城，引權東下，為水戰軍向夏口，乘其虛而擊之，此神兵從天而墮，破之必矣。」天子並然之，復命帝屯於宛。

**釋讀與歸年** 此段接228年平孟达、收申仪之后，在太和四年（230）出师以前，无独立年号。故只定位228—230年前后；两次问答完整保留，不把规划写成已实施的战役。

### 7. 未载年月的改谥与终制

[返回正文第7条](#jin001-period-event-l74)

<a id="jin001-l74"></a>

**[《晉書·宣帝紀》節引](../../拆分史书/晋书/卷001.md#L74)**

> 九月庚申，葬於河陰，諡曰文，後改諡宣文。先是，預作終制，於首陽山為土藏，不墳不樹；作顧命三篇，斂以時服，不設明器，後終者不得合葬。一如遺命。

**釋讀與歸年** 节引；[本段全文与251年卒葬](ce-0251.md#jin001-l74)。这里只收未确年的遗制及改谥；264、265追尊各有年页，不反推遗制也作于251年。

### 8. 史臣总评、狼顾故事与晋明帝问答

[返回正文第8条](#jin001-period-event-l75)

<a id="jin001-l75"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L75)**

> 帝內忌而外寬，猜忌多權變。魏武察帝有雄豪志，聞有狼顧相，欲驗之。乃召使前行，令反顧，面正向後而身不動。又嘗夢三馬同食一槽，甚惡焉。因謂太子丕曰：「司馬懿非人臣也，必預汝家事。」太子素與帝善，每相全佑，故免。帝於是勤於吏職，夜以忘寢，至於芻牧之間，悉皆臨履，由是魏武意遂安。及平公孫文懿，大行殺戮。誅曹爽之際，支黨皆夷及三族，男女無少長，姑姊妹女子之適人者皆殺之，既而竟遷魏鼎雲。明帝時，王導侍坐。帝問前世所以得天下，導乃陳帝創業之始，及文帝末高貴鄉公事。明帝以面覆牀曰：「若如公言，晉祚復安得長遠！」跡其猜忍，蓋有符於狼顧也。

**釋讀與歸年** 曹操在世的故事未署年，曹丕为太子的称呼亦可能是追叙用称。“明帝时”依王导在场及所论晋祚，指东晋明帝时代（323—325），不是魏明帝；问答未署某年。“文帝末高贵乡公事”是对司马昭时期曹髦死事的追述，不能理解成司马懿亲历。238年、249年的杀戮分见相应年页，本段仍作为史臣论断全文保存。

### 9. 卷末“制曰”

[返回正文第9条](#jin001-period-event-l77)

<a id="jin001-l77"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L77)**

> 【評】
>
> 制曰：夫天地之大，黎元為本；邦國之貴，元首為先。治亂無常，興亡有運。是故五帝之上，居萬乘以為憂；三王已來，處其憂而為樂。競智力，爭利害，大小相吞，強弱相襲。逮乎魏室，三方鼎峙，干戈不息，氛霧交飛。宣皇以天挺之姿，應期佐命，文以纘治，武以棱威。用人如在己，求賢若不及；情深阻而莫測，性寬綽而能容。和光同塵，與時舒捲，戢鱗潛翼，思屬風雲。飾忠於已詐之心，延安於將危之命。觀其雄略內斷，英猷外決，殄公孫於百日，擒孟達於盈旬，自以兵動若神，謀無再計矣。既而擁眾西舉，與諸葛相持。抑其甲兵，本無鬭志，遺其巾幗，方發憤心。杖節當門，雄圖頓屈，請戰千里，詐欲示威。且秦蜀之人，勇懦非敵，夷險之路，勞逸不同，以此爭功，其利可見。而返閉軍固壘，莫敢爭鋒，生怯實而未前，死疑虛而猶遁，良將之道，失在斯乎！文帝之世，輔翼權重，許昌同蕭何之委，崇華甚霍光之寄。當謂竭誠盡節，伊傅可齊。及明帝將終，棟樑是屬，受遺二主，佐命三朝，既承忍死之託，曾無殉生之報。天子在外，內起甲兵，陵土未乾，遽相誅戮，貞臣之體，寧若此乎！盡善之方，以斯為惑。夫征討之策，豈東智而西愚？輔佐之心，何前忠而後亂？故晉明掩面，恥欺偽以成功；石勒肆言，笑姦回以定業。古人有云，「積善三年，知之者少；為惡一日，聞於天下」，可不謂然乎！雖自隱過當年，而終見嗤後代。亦猶竊鍾掩耳，以眾人為不聞；銳意盜金，謂市中為莫覩。故知貪於近者則遺遠，溺於利者則傷名；若不損己以益人，則當禍人而福己。順理而舉易為力，背時而動難為功。況以未成之晉基，逼有餘之魏祚？雖復道格區宇，德被蒼生，而天未啟時，寶位猶阻，非可以智競，不可以力爭，雖則慶流後昆，而身終於北面矣。

**釋讀與歸年** 连同上行“【評】”标签保存完整论赞，标明为修史评语。篇中对秦蜀士卒、战争正当性及忠逆的判断属于作者立场，不以论赞覆盖本卷正文与其他史书的具体证据。

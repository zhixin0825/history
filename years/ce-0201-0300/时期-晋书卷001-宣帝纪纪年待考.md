# 《晋书》卷一〈宣帝纪〉｜未确年材料与跨代评论

## 时期阅读

<a id="jin001-period-event-l4"></a>

1. **司马氏的家世与司马懿早年的声望。** 司马懿字仲达，河内温县孝敬里人。《晋书》把司马氏远祖追溯到高阳氏后裔重黎，说这一族世掌夏官，到周代以司马为官，程伯休父在周宣王时平定徐方后，后人便以官名为姓。这是本纪保存的世系说。书中又以楚汉间的司马卬为这一支先人：他曾为赵将、参加反秦，后封殷王、定都河内，汉在其地设郡后，子孙遂在当地安家。封王、置郡分别可参读[前206年](../bce-0300-0201/bce-0206.md)与[前205年](../bce-0300-0201/bce-0205.md)。本纪接列征西将军司马钧（字叔平）、豫章太守司马量（字公度）、颍川太守司马儁（字元异）、京兆尹司马防（字建公），司马懿是司马防的第二子，[179年出生（据享年推算）](../ce-0101-0200/ce-0179.md#jin001-note-birth)。它形容司马懿少时聪敏、有大略、熟悉儒学，并常为汉末乱局忧虑。同郡杨俊在他未满二十岁时见过他，认为他不是平常人物；崔琰与司马朗友善，也称许其弟聪明公允、刚断出众，认为才器在司马朗之上。《三国志·杨俊传》记相遇时司马懿十六七岁，据179年生及虚岁推得约194—195年，仍不能唯一确定哪一年；崔琰称许之事亦无确年，“南阳太守”是传中称杨俊的官号，并不能证明见面时已经在任。 [[1]](#jin001-l4)

<a id="jin001-period-event-l5"></a>

2. **再辟入幕以后继续迁官。** 司马懿[201年辞曹操征召](ce-0201.md#jin001-l5)，到曹操任丞相后的[208年才应辟为文学掾](ce-0208.md#jin001-l5)。本纪接着说，曹操让他与曹丕往来，他又先后任黄门侍郎、议郎、丞相东曹属及主簿；这串迁官的先后可知，各职的任年却没有分别记下，书中“太子”也可能使用了后来的称呼。 [[2]](#jin001-l5)

<a id="jin001-period-event-l7"></a>

3. **司马懿任太子中庶子，与陈群等并称“四友”。** 本纪说，魏国建立以后，司马懿改任太子中庶子，常参与重大谋议、提出计策，受到曹丕信任；他与陈群、吴质、朱铄并称“四友”。魏国建于213年，曹丕至217年才正式成为魏太子。原文只给相对先后，没有为这一任命及“四友”形成各标确年，故在这里保留其事，不把它们一并提前到213年。 [[3]](#jin001-l7)

<a id="jin001-period-event-l8"></a>

4. **司马懿建议边耕边守，并批评胡修、傅方不宜守边。** 升任军司马以后，司马懿用箕子论政先重粮食的例子劝曹操：底本称天下有二十余万人不从事耕作，长期如此不利国用（周家禄疑“万”为“年”，则指长期未耕而非人数），即使战事未停，也应一面屯守、一面生产。曹操采纳，安排务农积谷，本纪说国用由此充足。他还认为荆州刺史胡修粗暴、南乡太守傅方骄奢，不适合放在前线，曹操没有听从。后来关羽围樊、于禁军遭水灾覆没，两人果然投降；这一结局可确定在[219年](ce-0219.md#jin001-l8)，但此前进言及迁军司马的年月没有独立记载。 [[4]](#jin001-l8)

<a id="jin001-period-event-l10"></a>

5. **关羽败后，司马懿劝曹操暂缓迁走荆州遗民。** 按本纪，曹操认为荆州遗民和颍川屯田人口接近孙吴（《通鉴》作汉川，地名有异），想把他们内迁。司马懿反对，说荆楚居民容易因变故迁动，安顿下来却不容易；关羽刚败，原来参与其事的人还在躲藏观望，此时再搬走守法安居者，不但伤害这些人，也会使逃亡者不敢回来。曹操接受意见，本纪说后来逃亡人口陆续恢复本业。这次议论在关羽败后、曹操220年正月去世前，可能跨219、220年；人口归业的成效则可能延续更久。 [[5]](#jin001-l10)

<a id="jin001-period-event-l22"></a>

6. **司马懿反对严查新附户口，提出从皖城牵动孙权、由夏口进击的计划。** 平孟达以后，一些新附边郡户口没有登记，魏廷想查核。司马懿入朝时，曹叡问他的意见，他认为这些人正因对方管制过密才来归附，应先以宽简办法安定他们。曹叡又问吴、蜀应先攻哪一方，他回答说，孙吴仗着中原军队不熟水战，才敢分散部署；要攻它，应抓住夏口、东关等要害。他设想用陆军指向皖城，吸引孙权向东，再派水军向夏口，乘空虚而击。曹叡赞同，仍命他回宛驻守。本段记的是朝议和作战设想，没有说计划已经实行，也没有独立标出入朝的年月。 [[6]](#jin001-l22)

<a id="jin001-period-event-l74"></a>

7. **司马懿预定薄葬，后来改谥宣文的年月未详。** 司马懿生前已安排在首阳山用土穴安葬，不起坟、不植树；作顾命三篇，规定用平常衣服入殓，不陈设明器，也不准后去世的家属与他合葬。本纪说实际照遗命办理，但没有给出遗命写成的年份，也没有录出顾命三篇全文。251年葬时谥“文”，后来改谥“宣文”的具体年月，本卷同样未记。 [[7]](#jin001-l74)

<a id="jin001-period-event-l75"></a>

8. **狼顾、“三马同槽”及晋明帝掩面，都是本纪回顾司马氏兴起时收录的故事。** 史臣形容司马懿内心猜忌、外表宽厚，擅长权变。书中说，曹操听闻他有“狼顾”之相，便让他走到前面再回头，见他身体不转而脸能正向后方；曹操又曾梦见三匹马同吃一槽，因而告诫曹丕，说司马懿并非甘居人下之人，将来会干预曹家国事。曹丕与司马懿相善，多方保全他。司马懿此后昼夜勤办事务，甚至忘记睡觉，连草料、牧养等小事也亲自巡察，才使曹操逐渐安心。这些说法未标确年，相术和梦兆也只是原书的叙述。史臣随即举[238年辽东大杀戮](ce-0238.md#jin001-l40)、[249年诛曹爽党及家属](ce-0249.md#jin001-l75-249)，并追叙其后嗣最终[移魏为晋](ce-0265.md#jin001-l75-265)。他又记东晋明帝问王导晋朝怎样取得天下，王导讲起司马懿创业及司马昭末年高贵乡公曹髦遇害，明帝便用脸贴着床、掩面叹息：若事情正如王导所说，晋朝国运又怎能长远。这里的明帝是东晋明帝，司马昭是晋朝追尊的“文帝”，不是魏明帝和曹丕。问答本身没有署年。 [[8]](#jin001-l75)

<a id="jin001-period-event-l77"></a>

9. **卷末“制曰”既赞军政才略，也责问受托之臣为何转而夺权。** 论赞先说百姓是天下根本、君主对国家安危负有重责，治乱兴亡自有运数；又以五帝忧虑帝位之责、后世君主反而贪图其乐作对照，再赞司马懿有文武才略，能用人、求贤、容纳他人，也善于收敛锋芒、等待时机。它把平孟达、灭公孙渊当作其用兵迅速的例子，却批评他与诸葛亮相持时坚守不战：诸葛亮在世时，司马懿不敢交锋；诸葛亮去世后，他又疑心有诈，它还把秦地魏军与蜀兵的强弱、双方道路的险易及劳逸差别，当作魏军本有优势的理由；这些同样是作者的判断。论赞又说，司马懿受曹丕、曹叡两代托付，本应像伊尹、傅说那样尽忠，却趁皇帝在外起兵、诛除同受顾命者。作者据此追问，为什么东征辽东时能英明果断，西面对蜀军时却如此疑怯；辅佐魏室又为何前忠后乱，并举晋明帝掩面、石勒讥笑凭奸诈立业的说法，说明眼前得利也可能损害后世名声。它还以掩耳盗钟、在闹市取金却以为无人看见作比，认为当时掩饰过错，终究不能阻止后人议论；一心谋取近利，便容易舍远害人。末尾论及，司马懿终身仍以臣身份事魏，晋的帝业由后嗣完成；作者将之归于时运，认为单靠智力不能强取尚未到来的帝位。这些是唐代修史论赞的政治和军事判断，读者可与本卷具体史事及各书异说分开考察。 [[9]](#jin001-l77)

<a id="jin001-period-event-l43"></a>

10. **本纪在明帝临终托孤前，追述司马懿在襄平做过的梦。** 书中说，他梦见曹叡枕在自己膝上，要他看自己的脸；他低头看去，觉得皇帝面貌异于往常，因而不安。这是原书用来铺叙后来托孤的梦兆故事，无法据以证明预知皇帝病危；召还及受命的具体经过见[239年](ce-0239.md#jin001-l43)。 [[10]](#jin001-l43)

### 1. 世系与早年识人

[返回正文第1条](#jin001-period-event-l4)

<a id="jin001-l4"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L4)**

> 宣皇帝諱懿，字仲達，河內溫縣孝敬里人，姓司馬氏。其先出自帝高陽之子重黎，為夏官祝融。歷唐、虞、夏、商，世序其職。及周，以夏官為司馬。其後程伯休父，周宣王時，以世官克平徐方，錫以官族，因而為氏。楚漢間，司馬卬為趙將，與諸侯伐秦。秦亡，立為殷王，都河內。漢以其地為郡，子孫遂家焉。自卬八世，生征西將軍鈞，字叔平。鈞生豫章太守量，字公度。量生潁川太守儁，字元異。儁生京兆尹防，字建公。帝即防之第二子也。少有奇節，聰朗多大略，博學洽聞，伏膺儒教。漢末大亂，常慨然有憂天下心。南陽太守同郡楊俊名知人，見帝，未弱冠，以為非常之器。尚書清河崔琰與帝兄朗善，亦謂朗曰：「君弟聰亮明允，剛斷英特，非子所及也。」

**釋讀與歸年** 本段为世系与早年总叙。只说杨俊见司马懿时其未弱冠，不据后来推算虚岁强造相遇年；古远世系是本纪自述，不在远古年表补成逐年事实。

### 2. 再辟以后的一串迁官

[返回正文第2条](#jin001-period-event-l5)

<a id="jin001-l5"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L5)**

> 漢建安六年，郡舉上計掾。魏武帝為司空，聞而辟之。帝知漢運方微，不欲屈節曹氏，辭以風痹，不能起居。魏武使人夜往密刺之，帝堅臥不動。及魏武為丞相，又辟為文學掾，敕行者曰：「若復盤桓，便收之。」帝懼而就職。於是使與太子游處，遷黃門侍郎，轉議郎、丞相東曹屬，尋轉主簿。

**釋讀與歸年** 为读清官职次序保留全段；确年事件仍见[201年](ce-0201.md)和[208年](ce-0208.md)，此处仅承接没有独立年月的迁官，不能将后续诸官都归208年。

### 3. 太子中庶子与“四友”的起始年

[返回正文第3条](#jin001-period-event-l7)

<a id="jin001-l7"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L7)**

> 魏國既建，遷太子中庶子。每與大謀，輒有奇策，為太子所信重，與陳羣、吳質、朱鑠號曰四友。

**釋讀與歸年** “魏国既建”为相对背景，不能取代任职日期。相关确年背景分见[213年](ce-0213.md)、[217年](ce-0217.md)，本页保存任官与四友的未确年边界。

### 4. 军司马、屯田建议与边将判断

[返回正文第4条](#jin001-period-event-l8)

<a id="jin001-l8"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L8)**

> 遷為軍司馬，言於魏武曰：「昔箕子陳謀，以食為首。今天下不耕者蓋二十餘萬，非經國遠籌也。雖戎甲未卷，自宜且耕且守。」魏武納之，於是務農積穀，國用豐贍。帝又言荊州刺史胡脩粗暴，南鄉太守傅方驕奢，並不可居邊。魏武不之察。及蜀將關羽圍曹仁於樊，于禁等七軍皆沒，脩、方果降羽，而仁圍甚急焉。

**釋讀與歸年** 全段保留前因后果；末尾关羽围樊及胡、傅降羽见[219年](ce-0219.md)。二十余万不耕者、屯田建议的具体提出时间暂不独立定年。《晋书斠注》引周家禄《晋书校勘记》疑“二十余万”为“二十余年”；白话保留底本读法并标校说，不将疑文当作确定人口统计。见[专项复核](../../拆分史书/晋书/卷001-系年复核.md#early)。

### 5. 关羽败后的迁民之议

[返回正文第5条](#jin001-period-event-l10)

<a id="jin001-l10"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L10)**

> 魏武以荊州遺黎及屯田在潁川者逼近南寇，皆欲徙之。帝曰：「荊楚輕脫，易動難安。關羽新破，諸為惡者藏竄觀望。今徙其善者，既傷其意，將令去者不敢復還。」從之。其後諸亡者悉復業。

**釋讀與歸年** “关羽新破”给出时间下限，曹操在世给出上限；归还本业还可能延续更久。未用段落紧邻位置虚造某一月日。《晋书斠注》引《读史举正》指出颍川距吴较远，《通鉴》作汉川。正文并列地名，不改原文。见[专项复核](../../拆分史书/晋书/卷001-系年复核.md#early)。

### 6. 边户隐实与伐吴规划

[返回正文第6条](#jin001-period-event-l22)

<a id="jin001-l22"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L22)**

> 時邊郡新附，多無戶名，魏朝欲加隱實。屬帝朝於京師，天子訪之於帝。帝對曰：「賊以密網束下，故下棄之。宜弘以大綱，則自然安樂。」又問二虜宜討，何者為先？對曰：「吳以中國不習水戰，故敢散居東關。凡攻敵，必扼其喉而摏其心。夏口、東關，賊之心喉。若為陸軍以向皖城，引權東下，為水戰軍向夏口，乘其虛而擊之，此神兵從天而墮，破之必矣。」天子並然之，復命帝屯於宛。

**釋讀與歸年** 此段接228年平孟达、收申仪之后，在太和四年（230）出师以前，无独立年号。故只定位228—230年前后；两次问答完整保留，不把规划写成已实施的战役。

### 8. 史臣总评、狼顾故事与晋明帝问答

[返回正文第8条](#jin001-period-event-l75)

<a id="jin001-l75"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L75)**

> 帝內忌而外寬，猜忌多權變。魏武察帝有雄豪志，聞有狼顧相，欲驗之。乃召使前行，令反顧，面正向後而身不動。又嘗夢三馬同食一槽，甚惡焉。因謂太子丕曰：「司馬懿非人臣也，必預汝家事。」太子素與帝善，每相全佑，故免。帝於是勤於吏職，夜以忘寢，至於芻牧之間，悉皆臨履，由是魏武意遂安。及平公孫文懿，大行殺戮。誅曹爽之際，支黨皆夷及三族，男女無少長，姑姊妹女子之適人者皆殺之，既而竟遷魏鼎雲。明帝時，王導侍坐。帝問前世所以得天下，導乃陳帝創業之始，及文帝末高貴鄉公事。明帝以面覆牀曰：「若如公言，晉祚復安得長遠！」跡其猜忍，蓋有符於狼顧也。

**釋讀與歸年** 曹操在世的故事未署年，曹丕为太子的称呼亦可能是追叙用称。“明帝时”依王导在场及所论晋祚，指东晋明帝时代（323—325），不是魏明帝；问答未署某年。“文帝末高贵乡公事”是对司马昭时期曹髦死事的追述，不能理解成司马懿亲历。238年、249年的杀戮分见相应年页，本段仍作为史臣论断全文保存。

### 9. 卷末“制曰”

[返回正文第9条](#jin001-period-event-l77)

<a id="jin001-l77"></a>

**[《晉書·宣帝紀》原文](../../拆分史书/晋书/卷001.md#L77)** · [上行“評”标记](../../拆分史书/晋书/卷001.md#L76)

> 【評】
>
> 制曰：夫天地之大，黎元為本；邦國之貴，元首為先。治亂無常，興亡有運。是故五帝之上，居萬乘以為憂；三王已來，處其憂而為樂。競智力，爭利害，大小相吞，強弱相襲。逮乎魏室，三方鼎峙，干戈不息，氛霧交飛。宣皇以天挺之姿，應期佐命，文以纘治，武以棱威。用人如在己，求賢若不及；情深阻而莫測，性寬綽而能容。和光同塵，與時舒捲，戢鱗潛翼，思屬風雲。飾忠於已詐之心，延安於將危之命。觀其雄略內斷，英猷外決，殄公孫於百日，擒孟達於盈旬，自以兵動若神，謀無再計矣。既而擁眾西舉，與諸葛相持。抑其甲兵，本無鬭志，遺其巾幗，方發憤心。杖節當門，雄圖頓屈，請戰千里，詐欲示威。且秦蜀之人，勇懦非敵，夷險之路，勞逸不同，以此爭功，其利可見。而返閉軍固壘，莫敢爭鋒，生怯實而未前，死疑虛而猶遁，良將之道，失在斯乎！文帝之世，輔翼權重，許昌同蕭何之委，崇華甚霍光之寄。當謂竭誠盡節，伊傅可齊。及明帝將終，棟樑是屬，受遺二主，佐命三朝，既承忍死之託，曾無殉生之報。天子在外，內起甲兵，陵土未乾，遽相誅戮，貞臣之體，寧若此乎！盡善之方，以斯為惑。夫征討之策，豈東智而西愚？輔佐之心，何前忠而後亂？故晉明掩面，恥欺偽以成功；石勒肆言，笑姦回以定業。古人有云，「積善三年，知之者少；為惡一日，聞於天下」，可不謂然乎！雖自隱過當年，而終見嗤後代。亦猶竊鍾掩耳，以眾人為不聞；銳意盜金，謂市中為莫覩。故知貪於近者則遺遠，溺於利者則傷名；若不損己以益人，則當禍人而福己。順理而舉易為力，背時而動難為功。況以未成之晉基，逼有餘之魏祚？雖復道格區宇，德被蒼生，而天未啟時，寶位猶阻，非可以智競，不可以力爭，雖則慶流後昆，而身終於北面矣。

**釋讀與歸年** 连同上行“【評】”标签保存完整论赞，标明为修史评语。篇中对秦蜀士卒、战争正当性及忠逆的判断属于作者立场，不以论赞覆盖本卷正文与其他史书的具体证据。

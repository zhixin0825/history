## 白话编年附录

本页仅收不能确定单一年份的早年、迁官及卷末史评；208年、211年推算生年另见相应年页。不把追称帝号当作在位事实。

<a id="jin002-period-event-early-shi"></a>

1. **司马师家世与早年声望。** 司马师字子元，是司马懿长子，仪表风采出众，沉着果断、有大略，少年即享美名，与夏侯玄、何晏齐名；何晏认为他能察事物细微征兆而成天下大事。 [[1]](#jin002-period-note-early-shi)

<a id="jin002-period-event-office-shi"></a>

2. **司马师景初年间任官。** 景初（237—239）年间拜散骑常侍，后累迁中护军；他制定选拔办法，举用不逾功劳，吏员不得徇私。具体迁中护军的年月未记，不把整个任官过程压在237年。 [[2]](#jin002-period-note-office-shi)

<a id="jin002-period-event-early-zhao"></a>

3. **司马昭姓名及亲属。** 司马昭字子上，是司马师同母弟，母张氏。 [[3]](#jin002-period-note-early-zhao)

<a id="jin002-period-event-office-zhao"></a>

4. **正始初典农与迁官。** 正始初司马昭为洛阳典农中郎将，面对魏明帝奢侈营建之后的民困，除去苛碎政令、不夺农时，百姓悦服，后转散骑常侍。正始初不等于确指240年，迁官确月不详。 [[4]](#jin002-period-note-office-zhao)

<a id="jin002-period-event-review"></a>

5. **史臣总评。** 史臣称世宗司马师明睿创基、太祖司马昭雄才完成大业，却指出他们虽有事殷的臣节外观，剪商代主的志向日深；逾剑阁平蜀、淮南定乱是功业，废君则有怨恨。又以周公留恋辅政、曹操得意、享天子式轩悬之乐和封国等典故论其身为名臣却享帝王权势，慨叹兼包天人与做人臣、君主之难。 赞称司马师继承父业，国家大权未分，三千士从之如云；司马昭拓疆使蜀地平静，却直指虽讨叛乱终归弑君。卷末评赞对司马氏权力扩张持褒贬并存的立场。 [[5]](#jin002-period-note-review)

### 5. 史臣总评

[返回正文第5条](#jin002-period-event-review)

<a id="jin002-l111-1"></a>

**[《晉書》L111：史臣总评](../../拆分史书/晋书/卷002.md#edition-jin002-l111-1)**

> 史臣曰：世宗以睿略創基，太祖以雄才成務。事殷之跡空存，翦商之志彌遠，三分天下，功業在焉。及逾劍銷氛，浮淮靜亂，桐宮胥怨，或所不堪。若乃體以名臣，格之端揆，周公流連於此歲，魏武得意於茲日。軒懸之樂，大啟南陽，師摯之圖，於焉北面。壯矣哉，包舉天人者也！為帝之主，不亦難乎。

<a id="jin002-l112-1"></a>

> 贊曰：世宗繼文，邦權未分。三千之士，其從如雲。太祖無外，靈關靜氛。反雖討賊，終為弒君。

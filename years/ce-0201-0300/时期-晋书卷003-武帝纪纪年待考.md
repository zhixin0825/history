1. **司马炎的家世。** 司马炎字安世，是司马昭的长子，为人宽惠仁厚，深沉而有度量。 [[1]](#jin003-u115-1-note)

<a id="jin003-u115-3-event"></a>
<a id="jin003-l115b-event"></a>

2. **封侯与早年官历。** 司马炎在魏嘉平年间封北平亭侯，随后历任给事中、奉车都尉、中垒将军，加散骑常侍，逐步升至中护军、假节。 [[2]](#jin003-u115-3-note)

<a id="jin003-u115-5-event"></a>
<a id="jin003-l115d-event"></a>

3. **迁中抚军、进封乡侯。** 司马炎升中抚军，进封新昌乡侯。 [[3]](#jin003-u115-5-note)

<a id="jin003-u362-1-event"></a>
<a id="jin003-l362-event"></a>

4. **史论标题。** 本纪纪事之后，接史臣总论和御制论。 [[4]](#jin003-u362-1-note)

<a id="jin003-u363-1-event"></a>
<a id="jin003-l363a-event"></a>

5. **史臣评价武帝的宽厚与俭约。** 史臣称司马炎宽厚，仓促间仍能仁恕，容纳正直之言而不怒，明达有谋、能断大事，因此安定四方；又称魏末奢侈苛刻后百姓思古风，武帝以恭俭寡欲引导。有司曾报御牛的青丝牵绳断了，他命用青麻代替。史臣借此说明俭约，又赞其临朝宽裕、法度有常。 [[5]](#jin003-u363-1-note)

<a id="jin003-u363-5-event"></a>
<a id="jin003-l363b-event"></a>

6. **许奇任用及许允死事的异说。** 许允之子许奇任太常丞。司马炎将祭太庙，朝臣以许奇为受害者家属，不愿让他接近皇帝，拟外任长史。司马炎反而追称许允旧日名望及许奇才干，擢许奇为祠部郎，时论称赞其旷达。 [[6]](#jin003-u363-5-note)

<a id="jin003-u363-8-event"></a>
<a id="jin003-l363c-event"></a>

7. **平吴后至末年的史臣批评。** 史臣认为，平吴后天下安定，司马炎逐渐怠政、沉溺游宴，宠爱后族，使亲贵掌权，旧臣不能专任，常制紊乱废弛，私下请托盛行。 [[7]](#jin003-u363-8-note)

<a id="jin003-u363-9-event"></a>
<a id="jin003-l363d-event"></a>

8. **末年储位与宗王分镇谋议。** 晚年，司马炎知道太子难负重任，却因皇孙聪慧而不愿废立；又担心皇孙不是贾妃所生，日后会受危害，遂与亲信谋后事。意见纷纭，久未定，最后采王佑之谋，令太子同母弟秦王司马柬督关中，楚王玮、淮南王允镇守要地以强皇室。又怕杨氏逼权，任王佑为北军中候、掌禁兵。 [[8]](#jin003-u363-9-note)

<a id="jin003-u364-1-event"></a>
<a id="jin003-l364-event"></a>

9. **制曰对武帝善始失终的论断。** 唐太宗先赞司马炎承三世基础、受天命而统治天下，以安逸代劳苦、以治理代战乱，停止丝织品的进贡、去雕饰，抑奢俗、复淳朴；又赞其喜直言、任刘毅裴楷等质直者，不因旧怨弃嵇绍许奇，以仁宽得众，有帝王度量。当时民生丰足，整军拓境，内断军略而出人意表，马隆西讨、王濬南征迅速成功，称敌军迅速消散、平吴几乎不费兵刃，使前代未通的地方贯通、未曾归服的地方归服，以祥瑞和风教颂其功。他随即批评武帝统一后虽辞封禅，却滋生骄心，以为广土可传万世、太平可保千年；只有居广思狭、处治思危，才能长保。立嗣不当、委任失人，却想求太平，犹如要去越国却走沙漠、要登山却乘舟，越走越背离目标。新基未固，贾充、杨骏掌权，皇帝丧期未终，宗王疏亲、辅臣变节，各拥兵相争，不数年纲纪大乱、宗庙南迁，作者又以“文身”“被发”形容晋室南迁及北方局势，感叹晋室丢失大片土地而仅据较小疆域自保，反遭天下讥笑，皆因失慎在先、遗患在后。贤父应知子，明君应知臣；子不贤则家亡，臣不忠则国乱，必须防患于初。世祖却受荀勖、王浑之谋影响，随众口动摇；刘渊当除而未除，惠帝可废而未废，终于倾覆基业。作者以保一人和救天下、弃一子和安社稷权衡，责其承三世事业却容两名祸端毁之，取轻舍重、畏小忍而忘大孝，认为圣贤之道不应如此，以武帝善始却不能善终作结，说读史至此不能不慷慨感叹。 [[9]](#jin003-u364-1-note)

<a id="jin003-wu-zhouchu-event"></a>

10. **周处仕晋。** 吴亡后，周处转入晋朝效力。 [[10]](#jin003-wu-zhouchu-note)

> 制曰：武皇承基，誕膺天命，握圖御宇，敷化導民，以佚代勞，以治易亂。絕縑綸之貢，去雕琢之飾，制奢俗以變儉約，止澆風而反淳樸。雅好直言，留心采擢，劉毅、裴楷以質直見容，嵇紹、許奇雖仇讎不棄。仁以御物，寬而得眾，宏略大度，有帝王之量焉。於時民和俗靜，家給人足，聿修武用，思啟封疆。決神算於深衷，斷雄圖於議表。馬隆西伐，王濬南征，師不延時，獯虜削跡，兵無血刃，揚越爲墟。通上代之不通，服前王之未服。禎祥顯應，風教肅清，天人之功成矣，霸王之業大矣。雖登封之禮，讓而不爲，驕泰之心，因斯以起。見土地之廣，謂萬葉而無虞；睹天下之安，謂千年而永治。不知處廣以思狹，則廣可長廣；居治而忘危，則治無常治。加之建立非所，委寄失才，志欲就於昇平，行先迎於禍亂。是猶將適越者指沙漠以遵途，欲登山者涉舟航而覓路，所趣逾遠，所尚轉難，南北倍殊，高下相反，求其至也，不亦難乎！況以新集易動之基，而無久安難拔之慮，故賈充凶豎，懷姦志以擁權；楊駿豺狼，苞禍心以專輔。及乎宮車晚出，諒闇未周，藩翰變親以成疏，連兵競滅其本；棟梁回忠而起僞，擁眾各舉其威。曾未數年，綱紀大亂，海內版蕩，宗廟播遷。帝道王猷，反居文身之俗；神州赤縣，翻成被髮之鄉。棄所大以資人，掩其小而自託，爲天下笑，其故何哉？良由失慎於前，所以貽患於後。且知子者賢父，知臣者明君；子不肖則家亡，臣不忠則國亂；國亂不可以安也，家亡不可以全也。是以君子防其始，聖人閑其端。而世祖惑荀勖之姦謀，迷王渾之僞策，心屢移於眾口，事不定於己圖。元海當除而不除，卒令擾亂區夏；惠帝可廢而不廢，終使傾覆洪基。夫全一人者德之輕，拯天下者功之重，棄一子者忍之小，安社稷者孝之大；況乎資三世而成業，延二孽以喪之，所謂取輕德而捨重功，畏小忍而忘大孝。聖賢之道，豈若斯乎！雖則善始於初，而乖令終於末，所以殷勤史策，不能無慷慨焉。

**释读与归年** “制曰”为唐太宗御制史论，全篇在本号连续引录。兵无血刃为颂词，不能覆盖前文杀伤与战死记数；文身、被发为作者描写江南与北方异族的族群修辞，不作人群优劣事实；杀刘渊、废惠帝即可免乱是作者的反事实政治判断，不是已获证明的历史规律。

> 虞預晉書曰：處入晉，

**釋讀** 虞預《晉書》記周處在吳亡後入晉。

**歸年** 吳亡於晉太康元年。本句隨政權交替繫年，其後歷官別列時期。

**释读与归年** 本句只有处入晋，未别载任官年；吴亡提供时间下限，后续历官不全塞入280。

## 时期阅读

<a id="jin003-l115a-event"></a>

1. **司马炎的姓名、家世与品评。** 司马炎字安世，是司马昭的长子。本纪形容他宽惠仁厚、深沉而有度量；这是原书的人物评价。 [[1]](#jin003-l115a-note)

<a id="jin003-l115b-event"></a>

2. **司马炎在曹魏的早年官爵。** 嘉平年间，司马炎封北平亭侯，历任给事中、奉车都尉、中垒将军，加散骑常侍，逐步迁中护军、假节。嘉平为249—254年的年号范围，本句没有逐职标出授任年月。 [[2]](#jin003-l115b-note)

<a id="jin003-l115d-event"></a>

3. **中抚军与新昌乡侯。** 本纪接叙司马炎迁中抚军、进封新昌乡侯，不能仅因它们紧随迎立一句，就断言两项都在260年授任。 [[3]](#jin003-l115d-note)

<a id="jin003-l116a-event"></a>

4. **司马昭择嗣时的司马炎、司马攸之争。** 司马昭认为兄司马师是司马懿嫡子、早死无后，让自己的儿子司马攸继司马师后，对攸特别宠爱，自称只是暂居相位，死后大业应归攸，常说天下属于景王，自己有何参与。议立世子时，他意属司马攸。何曾等坚持司马炎聪明有超世才略，又以头发垂地、手过膝为异相，称不是普通人臣之相，储位才定。相貌与命运的联系是原书所载劝说，不能作为独立证据；商议始末未单独标年，与264年正式立世子分开。 [[4]](#jin003-l116a-note)

<a id="jin003-l133a-event"></a>

5. **司马炎为父居丧的追述。** 本纪回叙，司马炎虽按汉魏制度在安葬后除服，却仍穿深衣、戴素冠，降低坐席、撤减饮食，保持哀敬如居丧。父丧起于265年，不把回叙全作266年新发生。 [[5]](#jin003-l133a-note)

<a id="jin003-l133c-event"></a>

6. **母丧礼制的跨年追叙。** 本纪说后来皇太后去世，司马炎也依同样方式居丧。母亲王氏卒于268年，丧礼延续的过程不归入266年。 [[6]](#jin003-l133c-note)

<a id="jin003-l362-event"></a>

7. **史论标题。** “史论”是固定底本的段落标签，不另当作一个历史事件。 [[7]](#jin003-l362-note)

<a id="jin003-l363a-event"></a>

8. **史臣的性格品评与青麻故事。** 史臣赞司马炎宽厚，仓促间也能仁恕，容直言而不怒，明达有谋、能断大事，故安定四方；又称魏末奢侈苛刻后百姓思古风，他以恭俭寡欲引导。御牛青丝牵绳断，有司奏报，他诏改用青麻；史臣以此说明俭约，并赞其临朝宽裕、法度有常。未记具体年月，不造某年诏令。 [[8]](#jin003-l363a-note)

<a id="jin003-l363b-event"></a>

9. **许奇任用及许允死事的异说。** 本纪说许允被“文帝”杀，许奇任太常丞，武帝将祭太庙时，朝臣以其为受害者家属、不宜近侍，拟外任长史；司马炎反追称许允旧望及许奇才能，擢许奇为祠部郎，时论赞其旷达。许允死事按《三国志》在254年司马师掌政时，流徙乐浪途中死，本纪归于司马昭的说法不能直接当作无争议事实；许奇任用年未详。 [[9]](#jin003-l363b-note)

<a id="jin003-l363c-event"></a>

10. **平吴后至末年的史臣批评。** 史臣认为平吴后司马炎怠政、沉溺游宴，宠后族、使亲贵掌权，旧臣不得专任，常制废弛，私相请托盛行。这是对280年以后政治风气的总评，不把它作为280年某日可独立确认的一道政策。 [[10]](#jin003-l363c-note)

<a id="jin003-l363d-event"></a>

11. **末年储位与宗王分镇谋议。** 本纪称晚年司马炎知道后来惠帝难负重任，却因皇孙聪慧而不愿废太子，又怕皇孙不是贾妃所生而遭危害，与近臣谋后事，意见纷纭久未定，终于采用王佑之谋，使太子同母弟秦王柬督关中，楚王玮、淮南王允守要地以强皇室；又怕杨氏逼权，任王佑北军中候掌禁兵。分封本事见289年，商议起讫及王佑任职未独立标年；“惠帝”“贾后”是后来的称号回用于此前。 [[11]](#jin003-l363d-note)

<a id="jin003-l364-event"></a>

12. **制曰对武帝善始失终的论断。** “制曰”先赞武帝承三世基础，以治理替战乱，禁奢贡雕饰、崇俭朴，喜直言、用刘毅裴楷等质直者，不因旧怨弃嵇绍许奇，以仁宽得众；又赞民生丰足、整军拓境，称他内断军略、出人意表，马隆西讨、王濬南征迅速成功，开前王未通之境，以祥瑞和风教颂其功。所谓兵不血刃是论赞修辞，不覆盖前文战死、杀伤数字。作者继批统一后虽拒封禅却生骄心，误以广土可传万世、太平可保千年；只有居广思狭、处治思危才能长保。他责其立嗣不当、委任失人，以欲去越国却走沙漠、欲登山却乘舟比喻手段与目标背离；又贬斥贾充、杨骏，认为新基不固、辅臣与宗王各拥兵权，帝丧未终便争斗，不数年纲纪大乱、宗庙南迁。又责晋室丢失大片中原土地使他人得利，仅据较小疆域自保而贻笑天下，归因于失慎在先、遗患在后。原文以文身、被发描写江南与北方异族，属于唐代史家的族群修辞，不作为人群优劣事实。其后强调贤父知子、明君知臣，儿子不贤则家亡，臣子不忠则国乱，家亡国乱便难保全，须防患于初，斥荀勖、王浑之谋使皇帝随众口动摇；认为未除元海即刘渊、未废惠帝导致后患，以保一人与救天下、忍弃一子与安社稷相权衡，将两人并视为祸端，责其取轻舍重。全篇以善始而不善终作结。这是作者的反事实判断和政治伦理主张，不证明若杀刘渊或改立储君就必能避免后世动乱。 [[12]](#jin003-l364-note)

> 制曰：武皇承基，誕膺天命，握圖御宇，敷化導民，以佚代勞，以治易亂。絕縑綸之貢，去雕琢之飾，制奢俗以變儉約，止澆風而反淳樸。雅好直言，留心采擢，劉毅、裴楷以質直見容，嵇紹、許奇雖仇讎不棄。仁以御物，寬而得眾，宏略大度，有帝王之量焉。於時民和俗靜，家給人足，聿修武用，思啟封疆。決神算於深衷，斷雄圖於議表。馬隆西伐，王濬南征，師不延時，獯虜削跡，兵無血刃，揚越爲墟。通上代之不通，服前王之未服。禎祥顯應，風教肅清，天人之功成矣，霸王之業大矣。雖登封之禮，讓而不爲，驕泰之心，因斯以起。見土地之廣，謂萬葉而無虞；睹天下之安，謂千年而永治。不知處廣以思狹，則廣可長廣；居治而忘危，則治無常治。加之建立非所，委寄失才，志欲就於昇平，行先迎於禍亂。是猶將適越者指沙漠以遵途，欲登山者涉舟航而覓路，所趣逾遠，所尚轉難，南北倍殊，高下相反，求其至也，不亦難乎！況以新集易動之基，而無久安難拔之慮，故賈充凶豎，懷姦志以擁權；楊駿豺狼，苞禍心以專輔。及乎宮車晚出，諒闇未周，藩翰變親以成疏，連兵競滅其本；棟梁回忠而起僞，擁眾各舉其威。曾未數年，綱紀大亂，海內版蕩，宗廟播遷。帝道王猷，反居文身之俗；神州赤縣，翻成被髮之鄉。棄所大以資人，掩其小而自託，爲天下笑，其故何哉？良由失慎於前，所以貽患於後。且知子者賢父，知臣者明君；子不肖則家亡，臣不忠則國亂；國亂不可以安也，家亡不可以全也。是以君子防其始，聖人閑其端。而世祖惑荀勖之姦謀，迷王渾之僞策，心屢移於眾口，事不定於己圖。元海當除而不除，卒令擾亂區夏；惠帝可廢而不廢，終使傾覆洪基。夫全一人者德之輕，拯天下者功之重，棄一子者忍之小，安社稷者孝之大；況乎資三世而成業，延二孽以喪之，所謂取輕德而捨重功，畏小忍而忘大孝。聖賢之道，豈若斯乎！雖則善始於初，而乖令終於末，所以殷勤史策，不能無慷慨焉。

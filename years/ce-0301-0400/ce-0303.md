# 公元303年｜西晋太安二年

[← 公元302年](ce-0302.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元308年 →](ce-0308.md)

[本年相关史料](#sources-start)

<a id="sgz-event-1"></a>

1. **石冰攻扬州，贺循起兵。** 贺循随江东响应起兵，反击石冰。 [[1]](#sgz-note-1)

<a id="sgz-event-2"></a>

2. **孙惠谏陆机辞都督，陆氏兄弟被杀。** 司马颖征长沙王乂，使陆机作前锋；孙惠劝陆机让与王粹，陆机恐遭猜忌，随后遭诛，陆云、陆耽也被杀。 [[2]](#sgz-note-2)

<a id="sgz-event-3"></a>

3. **陆机及其司马孙拯被杀。** 司马颖任陆机为大都督，陆机以孙拯为司马。陆机因诬陷被杀，孙拯被拷问而不肯诬陆机，死于狱。 [[3]](#sgz-note-3)

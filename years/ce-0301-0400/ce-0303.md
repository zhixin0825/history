# 公元303年｜西晋太安二年

[← 公元302年](ce-0302.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元308年 →](ce-0308.md)

[本年相关史料](#sources-start)

<a id="sgz-event-1"></a>

1. **石冰攻扬州，贺循起兵。** 贺循随江东响应起兵，反击石冰。 [[1]](#sgz-note-1)

<a id="sgz-event-2"></a>

2. **孙惠谏陆机辞都督，陆氏兄弟被杀。** 司马颖征长沙王乂，使陆机作前锋；孙惠劝陆机让与王粹，陆机恐遭猜忌，随后遭诛，陆云、陆耽也被杀。 [[2]](#sgz-note-2)

<a id="sgz-event-3"></a>

3. **陆机及其司马孙拯被杀。** 司马颖任陆机为大都督，陆机以孙拯为司马。陆机因诬陷被杀，孙拯被拷问而不肯诬陆机，死于狱。 [[3]](#sgz-note-3)

<a id="sgz-event-4"></a>

4. **刘弘奏选伍朝、皮初等守宰。** 刘弘推许武陵征士伍朝与牙门将皮初。裴注“零陵太守”疑有脱文，伍朝才是被举为此郡太守的人。 [[4]](#sgz-note-4)

<a id="sgz-event-5"></a>

5. **刘弘荐皮初作襄阳太守，不许女婿出任。** 朝廷意欲以夏侯陟替望轻的皮初，刘弘以任贤和避亲旧令拒绝，皮初得任。 [[5]](#sgz-note-5)

### 2. 孙惠谏陆机辞都督，陆氏兄弟被杀

[返回正文第2条](#sgz-event-2)

<a id="sgz051-p-008-8"></a>

**[《三国志·宗室传》裴注 008·8](../../sources/摘录/三国志-卷051-宗室传裴注.md#pei-008-8)**

> 是時頴将有事於長沙以陸機為前鋒都督惠與機鄉里親厚憂其致禍謂之曰子盍譲都督於王粹乎機曰將謂吾避賊首䑕更速其害機尋被戮二弟雲耽亦見殺惠甚傷恨之

**归年** 《晋书·陆机传》《孙惠传》及《通鉴》卷八十五均证太安二年。

<a id="sgz058-p-014-8"></a>

**[《三国志·陆逊传》裴注 014·8](../../sources/摘录/三国志-卷058-陆逊传裴注.md#pei-014-8)**

> 無幾而與長沙王搆隙遂舉兵攻洛以機行後將軍督王椊牽秀等諸軍二十萬士龍著南征賦以羙其事

**释读** 司马颖与长沙王司马乂决裂，使陆机为行后将军统王粹、牵秀等二十万人；陆云作《南征赋》称其事。

**归年** 《晋书·惠帝纪》《陆机传》《通鉴》卷八十五均纪晋太安二年；别传将号与本纪别传略异。

<a id="sgz058-p-014-9"></a>

**[《三国志·陆逊传》裴注 014·9](../../sources/摘录/三国志-卷058-陆逊传裴注.md#pei-014-9)**

> 機吴人羇旅單宦頓居羣士之右多不厭服機屢戰失利死散過半

**释读** 陆机外来地位骤高，部众多人不服，战不利而部伍死散过半。

**归年** 同太安二年攻洛。

<a id="sgz058-p-014-11"></a>

**[《三国志·陆逊传》裴注 014·11](../../sources/摘录/三国志-卷058-陆逊传裴注.md#pei-014-11)**

> 是役也玖弟超亦領衆配機不奉軍令機繩之以法超宣言曰陸機將反

**释读** 孟超领兵隶陆机而违令，被陆机制裁后宣称陆机反。

**归年** 《通鉴》卷八十五太安二年洛阳战。

<a id="sgz058-p-014-12"></a>

**[《三国志·陆逊传》裴注 014·12](../../sources/摘录/三国志-卷058-陆逊传裴注.md#pei-014-12)**

> 及牽秀等譖機於頴以為持兩端玖又搆之於内頴信之遣收機并收雲及弟耽竝伏法

**释读** 称陆机持两端，司马颖遣人捕杀陆机、陆云、陆耽。

**归年** 《晋书·陆机传》《陆云传》《通鉴》同太安二年，被捕、遇害经过详略不同。

<a id="sgz058-p-014-13"></a>

**[《三国志·陆逊传》裴注 014·13](../../sources/摘录/三国志-卷058-陆逊传裴注.md#pei-014-13)**

> 機兄弟既江南之秀亦著名諸夏竝以無罪夷滅天下痛惜之

**释读** 兄弟为江南俊才，在中原也知名，世人痛惜无罪遭夷灭。

**归年** 同年处死史评。

<a id="sgz058-p-014-16"></a>

**[《三国志·陆逊传》裴注 014·16](../../sources/摘录/三国志-卷058-陆逊传裴注.md#pei-014-16)**

> 及機之誅三族無遺

**释读** 陆机被诛时三族遭夷，别传把此与父辈杀俘的旧事相联。

**归年** 同《晋书》太安二年；报应是史家归因。

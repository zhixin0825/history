2. **陆机被诬杀，陆云、陆耽及孙拯相继遇害。** 司马颖命陆机领军抗司马乂。孙惠曾劝陆机辞都督，陆机未从。陆机被诬而遇害，陆云、陆耽也被杀。陆机的司马孙拯受拷不肯诬其主，死于狱。 [[2]](#sgz-note-2)

<a id="sgz-event-5"></a>

<a id="sgz-event-4"></a>

4. **刘弘奏选守宰，力荐皮初任襄阳太守。** 刘弘荐伍朝、皮初等守宰。朝廷欲改用他的女婿夏侯陟，刘弘以任才、避亲为由反对，皮初得任襄阳太守。 [[4]](#sgz-note-4)

### 2. 陆机被诬杀，陆云、陆耽及孙拯相继遇害

[返回正文第2条](#sgz-event-2)



<a id="sgz051-p-008-8"></a>

<a id="wu051-l38-6"></a>

**[《三國志·宗室傳》裴注 008](../../sources/本地分卷/三国志/三国志-卷051.md#edition-wu051-l38-6)** · [TXT L38](../../sources/本地分卷/三国志/三国志-卷051.txt#L38)

> 成都王穎召爲大將軍參軍。是時穎將有事於長沙，以陸機爲前鋒都督。惠與機鄉里親厚，憂其致禍，謂之曰：「子盍讓都督於王粹乎？」機曰：「將謂吾避賊首鼠，更速其害。」機尋被戮，二弟雲、耽亦見殺，惠甚傷恨之。

**釋讀** 司马颖召孙惠为大将军参军。陆机出任前锋都督后，孙惠担心陆机得祸，劝他让位于王粹。陆机担心被指临阵退缩而拒绝。陆机及弟陆云、陆耽被杀，孙惠十分痛惜。

**歸年** 《晉書·陸機傳》《孫惠傳》《資治通鑑》卷八十五均可对读太安二年（303）讨长沙王司马乂、陆机被杀。孙惠入幕是战前背景，参军授任未载确日。

<a id="sgz051-p-021-7"></a>

<a id="wu051-l85-6"></a>

**[《三國志·宗室傳》裴注 021](../../sources/本地分卷/三国志/三国志-卷051.md#edition-wu051-l85-6)** · [TXT L85](../../sources/本地分卷/三国志/三国志-卷051.txt#L85)

> 永安中，陸機爲成都王大都督，請丞爲司馬，與機俱被害。

**釋讀** 孫丞被陸機延請為司馬，因陸機案一同遇害。

**歸年** 原注作「永安中」。《晉書·惠帝紀》《陸機傳》及《資治通鑑》卷085繫陸機遇害於太安二年（303），永安改元在304年。附傳所記孫拯與此處孫丞同字、同歷，作陸機死後被拷問而死於獄中，卒日未載。

<a id="sgz058-p-014-8"></a>

**[《三国志·陆逊传》裴注 014·8](../../sources/本地分卷/三国志/三国志-卷058.md#pei-014-8)**

> 無幾而與長沙王搆隙遂舉兵攻洛以機行後將軍督王椊牽秀等諸軍二十萬士龍著南征賦以羙其事

**释读** 司马颖与长沙王司马乂决裂，使陆机为行后将军统王粹、牵秀等二十万人；陆云作《南征赋》称其事。

**归年** 《晋书·惠帝纪》《陆机传》《通鉴》卷八十五均纪晋太安二年；别传将号与本纪别传略异。

<a id="sgz058-p-014-9"></a>

**[《三国志·陆逊传》裴注 014·9](../../sources/本地分卷/三国志/三国志-卷058.md#pei-014-9)**

> 機吴人羇旅單宦頓居羣士之右多不厭服機屢戰失利死散過半

**释读** 陆机外来地位骤高，部众多人不服，战不利而部伍死散过半。

**归年** 同太安二年攻洛。

<a id="sgz058-p-014-11"></a>

**[《三国志·陆逊传》裴注 014·11](../../sources/本地分卷/三国志/三国志-卷058.md#pei-014-11)**

> 是役也玖弟超亦領衆配機不奉軍令機繩之以法超宣言曰陸機將反

**释读** 孟超领兵隶陆机而违令，被陆机制裁后宣称陆机反。

**归年** 《通鉴》卷八十五太安二年洛阳战。

<a id="sgz058-p-014-12"></a>

**[《三国志·陆逊传》裴注 014·12](../../sources/本地分卷/三国志/三国志-卷058.md#pei-014-12)**

> 及牽秀等譖機於頴以為持兩端玖又搆之於内頴信之遣收機并收雲及弟耽竝伏法

**释读** 称陆机持两端，司马颖遣人捕杀陆机、陆云、陆耽。

**归年** 《晋书·陆机传》《陆云传》《通鉴》同太安二年，被捕、遇害经过详略不同。

<a id="sgz058-p-014-13"></a>

**[《三国志·陆逊传》裴注 014·13](../../sources/本地分卷/三国志/三国志-卷058.md#pei-014-13)**

> 機兄弟既江南之秀亦著名諸夏竝以無罪夷滅天下痛惜之

**释读** 兄弟为江南俊才，在中原也知名，世人痛惜无罪遭夷灭。

**归年** 同年处死史评。

<a id="sgz058-p-014-16"></a>

**[《三国志·陆逊传》裴注 014·16](../../sources/本地分卷/三国志/三国志-卷058.md#pei-014-16)**

> 及機之誅三族無遺

**释读** 陆机被诛时三族遭夷，别传把此与父辈杀俘的旧事相联。

**归年** 同《晋书》太安二年；报应是史家归因。

### 4. 刘弘奏选守宰，力荐皮初任襄阳太守

[返回正文第4条](#sgz-event-4)

<a id="sgz015-p-001-4"></a>

**[《三国志·刘司马梁张温贾传》裴注 001·4](../../sources/本地分卷/三国志/三国志-卷015.md#pei-001-4)**

> 時帝在長安命弘得選用宰守徵士武陵伍朝髙尚其事牙門將皮初有勲江漢弘上朝為零陵太守

**归年** 《晋书·刘弘传》同一奏内明确伍朝补零陵、皮初补襄阳，《资治通鉴》卷八十五系惠帝太安二年；《晋阳秋》“帝在长安”与303年行止相抵，保留异说。

<a id="sgz015-p-001-5"></a>

**[《三国志·刘司马梁张温贾传》裴注 001·5](../../sources/本地分卷/三国志/三国志-卷015.md#pei-001-5)**

> 初為襄陽太守詔書以襄陽顯郡初資名輕淺以弘壻夏侯陟為襄陽弘曰夫統天下者當與天下同心治一國者當與一國推實吾統荆州十郡安得十女壻然後為治哉乃表陟姻親舊制不得相監臨事初勲宜見酬報聼之衆益服其公

**归年** 《资治通鉴》卷八十五惠帝太安二年接讨张昌收此，与《晋书·刘弘传》相合。

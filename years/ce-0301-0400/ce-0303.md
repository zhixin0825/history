# 公元303年｜西晋太安二年

[← 公元302年](ce-0302.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元304年 →](ce-0304.md)

<a id="sgz-event-1"></a>

1. **石冰攻扬州，贺循起兵。** 石冰进据扬州。十二月，周玘、王矩等在江东举兵，推顾秘总领扬州九郡兵马，传檄州郡讨伐石冰。贺循在会稽起兵响应。 [[1]](#sgz-note-1)

<a id="sgz-event-3"></a>

<a id="sgz-event-2"></a>

2. **陆机被诬杀，陆云、陆耽及孙拯相继遇害。** 司马颖命陆机督王粹、牵秀等军攻洛阳，陆云作《南征赋》。孙惠曾劝陆机辞都督，陆机未从。陆机统兵时诸将多不服，又连遭败绩。孟玖之弟孟超不遵军令，被陆机依法追究，反指陆机谋反。牵秀等也告陆机持两端，孟玖从中构陷，司马颖遂捕杀陆机。陆云曾批评孟玖擅权，也与弟弟陆耽一同遇害。孙惠后来写信哀悼三人。陆机的司马孙拯受拷不肯诬其主，死于狱。 [[2]](#sgz-note-2)

<a id="sgz-event-5"></a>

<a id="sgz-event-4"></a>

4. **刘弘奏选守宰，力荐皮初任襄阳太守。** 刘弘荐伍朝、皮初等守宰。朝廷欲改用他的女婿夏侯陟，刘弘以任才、避亲为由反对，皮初得任襄阳太守。 [[4]](#sgz-note-4)

### 2. 陆机被诬杀，陆云、陆耽及孙拯相继遇害

[返回正文第2条](#sgz-event-2)



<a id="sgz051-p-008-8"></a>

<a id="wu051-l38-6"></a>

**[《三國志·宗室傳》裴注 008](../../拆分史书/三国志/卷051.md#edition-wu051-l38-6)** · [TXT L38](../../拆分史书/三国志/卷051.txt#L38)

> 成都王穎召爲大將軍參軍。是時穎將有事於長沙，以陸機爲前鋒都督。惠與機鄉里親厚，憂其致禍，謂之曰：「子盍讓都督於王粹乎？」機曰：「將謂吾避賊首鼠，更速其害。」機尋被戮，二弟雲、耽亦見殺，惠甚傷恨之。

**釋讀** 司马颖召孙惠为大将军参军。陆机出任前锋都督后，孙惠担心陆机得祸，劝他让位于王粹。陆机担心被指临阵退缩而拒绝。陆机及弟陆云、陆耽被杀，孙惠十分痛惜。

**歸年** 《晉書·陸機傳》《孫惠傳》《資治通鑑》卷八十五均可对读太安二年（303）讨长沙王司马乂、陆机被杀。孙惠入幕是战前背景，参军授任未载确日。

<a id="sgz051-p-021-7"></a>

<a id="wu051-l85-6"></a>

**[《三國志·宗室傳》裴注 021](../../拆分史书/三国志/卷051.md#edition-wu051-l85-6)** · [TXT L85](../../拆分史书/三国志/卷051.txt#L85)

> 永安中，陸機爲成都王大都督，請丞爲司馬，與機俱被害。

**釋讀** 孫丞被陸機延請為司馬，因陸機案一同遇害。

**歸年** 原注作「永安中」。《晉書·惠帝紀》《陸機傳》及《資治通鑑》卷085繫陸機遇害於太安二年（303），永安改元在304年。附傳所記孫拯與此處孫丞同字、同歷，作陸機死後被拷問而死於獄中，卒日未載。



<a id="sgz058-p-014-8"></a>

<a id="wu058-l92-8"></a>

**[《三國志·陸遜傳》裴注 014](../../拆分史书/三国志/卷058.md#edition-wu058-l92-8)** · [TXT L92](../../拆分史书/三国志/卷058.txt#L92)

> 無幾而與長沙王搆隙，遂舉兵攻洛，以機行後將軍，督王粹、牽秀等諸軍二十萬，士龍著南征賦以美其事。

**釋讀** 司馬穎和長沙王司馬乂交惡，舉兵攻洛陽，命陸機督王粹、牽秀等軍。陸雲作《南征賦》頌此役。

**歸年** 《資治通鑑》卷085系303年。底本作「行後將軍」，通鑑作前將軍、前鋒都督，所領軍二十萬為裴注記數。

<a id="sgz058-p-014-9"></a>

<a id="wu058-l92-9"></a>

**[《三國志·陸遜傳》裴注 014](../../拆分史书/三国志/卷058.md#edition-wu058-l92-9)** · [TXT L92](../../拆分史书/三国志/卷058.txt#L92)

> 機吳人，羇旅單宦，頓居羣士之右，多不厭服。機屢戰失利，死散過半。

**釋讀** 陸機是吳人，在晉單身出仕，突然統領許多將士，人多不服。屢戰失利，部眾死散甚多。

**歸年** 承上攻洛之役，《資治通鑑》卷085記陸機軍於鹿苑敗。

<a id="wu058-l92-10"></a>

**[《三國志·陸遜傳》裴注 014](../../拆分史书/三国志/卷058.md#edition-wu058-l92-10)** · [TXT L92](../../拆分史书/三国志/卷058.txt#L92)

> 初，宦人孟玖，頴所嬖幸，乘寵豫權，雲數言其短，頴不能納，玖又從而毀之。

**釋讀** 孟玖受司馬穎寵信而干預政事，陸雲多次說他有過，司馬穎不聽，孟玖反而毀謗陸雲。

**歸年** 本段明用「初」回敘，年月不明，保留為303年進讒前因。

<a id="sgz058-p-014-11"></a>

<a id="wu058-l92-11"></a>

**[《三國志·陸遜傳》裴注 014](../../拆分史书/三国志/卷058.md#edition-wu058-l92-11)** · [TXT L92](../../拆分史书/三国志/卷058.txt#L92)

> 是役也，玖弟超亦領衆配機，不奉軍令。機繩之以法，超宣言曰陸機將反。

**釋讀** 孟玖弟孟超受陸機節制卻不守軍令，陸機依法處置，孟超公開聲稱陸機要反。

**歸年** 本注承攻洛之役。《資治通鑑》卷085載孟超不遵軍令及告反。

<a id="sgz058-p-014-12"></a>

<a id="sgz058-p-014-13"></a>

<a id="wu058-l92-12"></a>

**[《三國志·陸遜傳》裴注 014](../../拆分史书/三国志/卷058.md#edition-wu058-l92-12)** · [TXT L92](../../拆分史书/三国志/卷058.txt#L92)

> 及牽秀等譖機於頴，以爲持兩端，玖又搆之於內，頴信之，遣收機，并收雲及弟耽，並伏法。機兄弟旣江南之秀，亦著名諸夏，並以無罪夷滅，天下痛惜之。

**釋讀** 牽秀等誣指陸機兩端，孟玖在內附和，司馬穎信而遣人收捕。陸機、陸雲和弟陸耽相繼被殺，世人哀惜。

**歸年** 本注連記三人遇害；《資治通鑑》卷085、《晉書·陸機傳》與〈陸雲傳〉互見審問、申辯和被殺的先後。

<a id="sgz058-p-014-16"></a>

<a id="wu058-l92-15"></a>

**[《三國志·陸遜傳》裴注 014](../../拆分史书/三国志/卷058.md#edition-wu058-l92-15)** · [TXT L92](../../拆分史书/三国志/卷058.txt#L92)

> 及機之誅，三族無遺，孫惠與朱誕書曰：「馬援擇君，凡人所聞，不意三陸相攜暴朝，殺身傷名，可爲悼歎。」事亦並在晉書。

**釋讀** 《別傳》說陸機案誅及三族，並引孫惠給朱誕的信，借馬援擇君追悼三陸一同出仕、喪身受辱。

**歸年** 孫惠的書信在陸機等遇害後，日期未明，隨303年案附讀。倉內《晉書·陸雲傳》末也載此信，措辭不同。

### 4. 刘弘奏选守宰，力荐皮初任襄阳太守

[返回正文第4条](#sgz-event-4)

<a id="sgz015-p-001-4"></a>

**[《三国志·刘司马梁张温贾传》裴注 001·4](../../拆分史书/三国志/卷015.md#pei-001-4)**

> 時帝在長安命弘得選用宰守徵士武陵伍朝髙尚其事牙門將皮初有勲江漢弘上朝為零陵太守

<a id="sgz015-p-001-5"></a>

**[《三国志·刘司马梁张温贾传》裴注 001·5](../../拆分史书/三国志/卷015.md#pei-001-5)**

> 初為襄陽太守詔書以襄陽顯郡初資名輕淺以弘壻夏侯陟為襄陽弘曰夫統天下者當與天下同心治一國者當與一國推實吾統荆州十郡安得十女壻然後為治哉乃表陟姻親舊制不得相監臨事初勲宜見酬報聼之衆益服其公

**归年** 《资治通鉴》卷八十五惠帝太安二年接讨张昌收此，与《晋书·刘弘传》相合。

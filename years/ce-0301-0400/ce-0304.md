# 公元304年｜西晋永兴元年

[← 公元303年](ce-0303.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元305年 →](ce-0305.md)

[本年相关史料](#sources-start)

<a id="sgz-event-1"></a>

1. **石冰败死，贺循解众归隐。** 事平后贺循闭门不出。 [[1]](#sgz-note-1)

<a id="sgz-event-2"></a>

2. **孙惠诣司马越并劝勤王。** 惠帝幸邺，东海王司马越在下邳练兵，孙惠用化名致书劝勤王，司马越设法求得其人、引为记室参军。 [[2]](#sgz-note-2)

<a id="sgz-event-3"></a>

3. **西晋渡辽将军孙楷去世。** 归晋后曾任渡辽将军的孙楷去世。 [[3]](#sgz-note-3)

<a id="sgz-event-4"></a>

4. **嵇绍于荡阴护帝，战败遇害。** 随惠帝伐成都王，百官奔散，嵇绍护帝遇害，追谥忠穆公。 [[4]](#sgz-note-4)

## 本年相关史料

<a id="sgz-note-1"></a>

### 1. 石冰败死，贺循解众归隐

[返回正文第1条](#sgz-event-1)

<a id="sgz065-p-004-6"></a>

**[《三国志·王楼贺韦华传》裴注 004·6](../../sources/本地分卷/三国志/三国志-卷065.md#pei-004-6)**

> 事平杜門不出

**归年** 《通鉴》卷085永兴元年三月石冰被杀，周玘、贺循皆散众归。

<a id="sgz-note-2"></a>

### 2. 孙惠诣司马越并劝勤王

[返回正文第2条](#sgz-event-2)

<a id="sgz051-p-008-9"></a>

**[《三国志·宗室传》裴注 008·9](../../sources/本地分卷/三国志/三国志-卷051.md#pei-008-9)**

> 永興元年乗輿幸鄴司空東海王越治兵下邳惠以書干越詭其姓名自稱南岳逸民秦秘之勉以勤王匡世之畧辭義甚美越省其書牓題道衢推求其人惠乃出見越即以為記室參軍

**归年** 本注明记永兴元年，惠帝幸邺同《晋书·惠帝纪》。

<a id="sgz-note-3"></a>

### 3. 西晋渡辽将军孙楷去世

[返回正文第3条](#sgz-event-3)

**异文与补证** 《晋诸公赞》系孙楷之死于永安元年，此处是晋惠帝的永安年号。

<a id="sgz051-p-019-2"></a>

**[《三国志·宗室传》裴注 019·2](../../sources/本地分卷/三国志/三国志-卷051.md#pei-019-2)**

> 永安元年卒

**归年** 承晋灭吴后迁官，年号当指西晋；《晋书·惠帝纪》明载304年改元永安，故依注所记系304。

<a id="sgz-note-4"></a>

### 4. 嵇绍于荡阴护帝，战败遇害

[返回正文第4条](#sgz-event-4)

<a id="sgz021-p-025-14"></a>

**[《三国志·王卫二刘傅传》裴注 025·14](../../sources/本地分卷/三国志/三国志-卷021.md#pei-025-14)**

> 以侍中從恵帝北伐成都王王師敗績百官奔走惟紹獨以身扞衛遂死於帝側故累見褒崇追贈太尉謚曰忠穆公

**归年** 《晋书·惠帝纪》《嵇绍传》永兴元年荡阴。赠谥有后年，不硬同。

# 公元304年｜西晋永兴元年

[← 公元303年](ce-0303.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元305年 →](ce-0305.md)

[本年相关史料](#sources-start)

<a id="sgz-event-1"></a>

1. **石冰败死，贺循解众归隐。** 三月，陈敏、周玘等击败石冰。石冰投奔封云，封云司马张统杀二人投降。扬州、徐州平定，周玘、贺循遣散部众归里，贺循闭门不出。 [[1]](#sgz-note-1)

<a id="sgz-event-2"></a>

2. **孙惠上书司马越，入幕掌文书。** 晋惠帝到邺后，孙惠化名秦秘之，上书东海王司马越，劝他联络诸王扶助朝廷。司马越张榜求其人，任孙惠为记室参军，掌文书并参与谋议。 [[2]](#sgz-note-2)

<a id="sgz-event-3"></a>

3. **西晋渡辽将军孙楷去世。** 归晋后曾任渡辽将军的孙楷去世。 [[3]](#sgz-note-3)

<a id="sgz-event-4"></a>

4. **嵇绍于荡阴护帝，战败遇害。** 随惠帝伐成都王，百官奔散，嵇绍护帝遇害，追谥忠穆公。 [[4]](#sgz-note-4)

### 2. 孙惠上书司马越，入幕掌文书

[返回正文第2条](#sgz-event-2)

<a id="sgz051-p-008-9"></a>

<a id="wu051-l38-7"></a>

**[《三國志·宗室傳》裴注 008](../../sources/本地分卷/三国志/三国志-卷051.md#edition-wu051-l38-7)** · [TXT L38](../../sources/本地分卷/三国志/三国志-卷051.txt#L38)

> 永興元年，乘輿幸鄴，司空東海王越治兵下邳，惠以書干越，詭其姓名，自稱南岳逸民秦祕之，勉以勤王匡世之略，辭義甚美。越省其書，牓題道衢，招求其人。惠乃出見，越即以爲記室參軍，專掌文疏，豫參謀議。

**釋讀** 晋惠帝至邺，孙惠化名南岳逸民秦秘之上书司马越，劝他勤王。司马越张榜求见，任孙惠为记室参军，掌文书并参与谋议。

**歸年** 本文明记永兴元年（304），《資治通鑑》卷八十五在惠帝至邺、司马越由下邳返东海后记上书及任官。本注称司马越在下邳治兵，保留两种叙法。《晉書·孫惠傳》作「南嶽逸士秦秘之」。

### 3. 西晋渡辽将军孙楷去世

[返回正文第3条](#sgz-event-3)

<a id="sgz051-p-019-2"></a>

<a id="wu051-l78-2"></a>

**[《三國志·宗室傳》裴注 019](../../sources/本地分卷/三国志/三国志-卷051.md#edition-wu051-l78-2)** · [TXT L78](../../sources/本地分卷/三国志/三国志-卷051.txt#L78)

> 永安元年卒。

**釋讀** 孫楷於西晉惠帝永安元年去世。

**歸年** 「永安」接入晉後官歷，是西晉惠帝永安元年（304）；《晉書·惠帝紀》同年記改元。

**异文与补证** 《晋诸公赞》系孙楷之死于永安元年，此处是晋惠帝的永安年号。

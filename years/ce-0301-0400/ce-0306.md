1. **河间王任牵秀为平北将军，牵秀后被杀。** 河间王司马颙任牵秀为平北将军、授假节，使他屯驻冯翊。东海王司马越的部将前来，畏其兵势不敢进。司马颙的长史杨腾为自保，诈传王命让牵秀罢兵，随后在万年杀了牵秀。 [[1]](#sgz-note-1)

<a id="sgz-event-2"></a>

<a id="sgz-event-3"></a>

2. **刘弘进任车骑将军，病卒襄阳。** 刘弘在荆州宽刑劝农，常亲笔写信督促州郡官吏。晋廷进他为车骑将军。刘弘病重，准备交卸所领事务，未及上表便在襄阳去世。朝廷赠新城郡公。 [[2]](#sgz-note-2)

## 本年相关史料

<a id="sgz-note-1"></a>

### 1. 河间王任牵秀为平北将军，牵秀后被杀

[返回正文第1条](#sgz-event-1)

**异文与补证** 《冀州记》说牵秀在冯翊遇害，时人惋惜他的才干；《晋书》与《资治通鉴》所载杀牵秀者不同，详见同号史料。

<a id="wei026-l65-5"></a>

**[《三國志·滿田牽郭傳》裴注](../../拆分史书/三国志/卷026.md#edition-wei026-l65-5)** · [TXT L65](../../拆分史书/三国志/卷026.txt#L65)

> 河間王以秀爲平北將軍，假節，在馮翊遇害。世人玩其辭賦，惜其材幹。

**釋讀與歸年** 河間王司馬顒以牽秀為平北將軍、假節屯馮翊。其長史楊騰假冒王命，騙牽秀罷兵而殺之。[《資治通鑑》卷八十六](../../史书/025-资治通鉴/KR2b0007_086.txt#L274-L284)繫光熙元年，[《晉書·牽秀傳》](../../史书/005-晋书/晋书-CCDH.txt#L6550)明記其遇害地為萬年。文末惋惜其才，隨卒事。

<a id="sgz026-p-007-6"></a>

[本卷同事原句](#wei026-l65-5)。

**归年** 《通鉴》卷八十六光熙元年六月，更取杨腾假命杀秀的细节；《晋书·河间王颙传》作麋晃斩秀，记事同年而死因存异。

### 2. 刘弘进任车骑将军，病卒襄阳

[返回正文第2条](#sgz-event-2)

**《劉司馬梁張溫賈傳》互見** [TXT 第12行第3段](../../拆分史书/三国志/卷015.md#edition-wei015-l12-3) · [TXT 第12行第4段](../../拆分史书/三国志/卷015.md#edition-wei015-l12-4) · [TXT 第12行第7段](../../拆分史书/三国志/卷015.md#edition-wei015-l12-7)

<a id="wei015-l12-2"></a>

**[《三國志·劉司馬梁張溫賈傳》裴注](../../拆分史书/三国志/卷015.md#edition-wei015-l12-2)** · [TXT L12](../../拆分史书/三国志/卷015.txt#L12)

> 晉西朝之末，弘爲車騎大將軍開府，荊州刺史，假節都督荊、交、廣州諸軍事，封新城郡公。

**釋讀與歸年** 裴注合叙刘弘晋末车骑大将军、开府、荆州刺史、假节都督诸军，及封新城郡公。[《晋书》](../../史书/005-晋书/晋书-CCDH.txt#L6915-L6917)记永兴三年进号车骑将军，卒后赠新城郡公。《晋阳秋》汇列车骑大将军等官号与封爵。[《晋书·惠帝纪》](../../史书/005-晋书/晋书-CCDH.txt#L482-L484)在305年已分别称车骑大将军、镇南大将军。车骑大将军的授任年月未见。

<a id="wei015-l12-6"></a>

**[《三國志·劉司馬梁張溫賈傳》裴注](../../拆分史书/三国志/卷015.md#edition-wei015-l12-6)** · [TXT L12](../../拆分史书/三国志/卷015.txt#L12)

> 晉諸公贊曰：于時天下雖亂，荊州安全。弘有劉景升保有江漢之志，不附太傅司馬越。越甚銜之。會弘病卒。

**釋讀與歸年** 《晋诸公赞》说刘弘保有江汉且不附司马越，越因此不满，刘弘随后病卒。[《晋书》](../../史书/005-晋书/晋书-CCDH.txt#L6914-L6917)称他曾受越节度，遣刘盘会越迎惠帝，所叙立场有异；卒于永兴三年，卒地襄阳。

<a id="sgz015-p-001-2"></a>

[本卷同事原句](#wei015-l12-2)。

**归年** 《晋书·刘弘传》记永兴三年（306）进车骑将军，死后赠新城郡公，开府与刺荆州已有在先；本注压缩先后于一语。

<a id="sgz-note-3"></a>

<a id="sgz015-p-001-8"></a>

[本卷同事原句](../ce-0201-0300/时期-三国志卷015-刘司马梁张温贾传纪年待考（2）.md#wei015-l12-7)。

**归年** 《资治通鉴》卷八十六光熙元年八月，刘弘卒，郭舒等推刘璠平乱。《晋书·刘弘传》叙刘璠为顺阳内史、越骑校尉等，《晋阳秋》另存北中郎将而不具任年。

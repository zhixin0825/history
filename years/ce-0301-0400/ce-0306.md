1. **河间王任牵秀为平北将军，牵秀后被杀。** 河间王司马颙任牵秀为平北将军，授假节。牵秀后来被杀。 [[1]](#sgz-note-1)

<a id="sgz-event-2"></a>

2. **刘弘晚任荆州及封新城郡公。** 《晋阳秋》总列车骑大将军、开府、刺荆州，都督荆交广并封新城郡公。 [[2]](#sgz-note-2)

<a id="sgz-event-3"></a>

3. **刘弘病卒。** 刘弘病逝，其子刘璠为北中郎将。 [[3]](#sgz-note-3)

## 本年相关史料

<a id="sgz-note-1"></a>

### 1. 河间王任牵秀为平北将军，牵秀后被杀

[返回正文第1条](#sgz-event-1)

**异文与补证** 《冀州记》说牵秀在冯翊遇害，时人惋惜他的才干；《晋书》与《资治通鉴》所载杀牵秀者不同，详见同号史料。

<a id="sgz026-p-007-6"></a>

**[《三国志·满田牵郭传》裴注 007·6](../../sources/本地分卷/三国志/三国志-卷026.md#pei-007-6)**

> 河間王以秀為平北將軍假節在馮翊遇害世人玩其辭賦惜其材幹

**归年** 《通鉴》卷八十六光熙元年六月，更取杨腾假命杀秀的细节；《晋书·河间王颙传》作麋晃斩秀，记事同年而死因存异。

<a id="sgz-note-2"></a>

### 2. 刘弘晚任荆州及封新城郡公

[返回正文第2条](#sgz-event-2)

<a id="sgz015-p-001-2"></a>

**[《三国志·刘司马梁张温贾传》裴注 001·2](../../sources/本地分卷/三国志/三国志-卷015.md#pei-001-2)**

> 晉西朝之末弘為車騎大將軍開府荆州刺史假節都督荆交廣州諸軍事封新城郡公

**归年** 《晋书·刘弘传》记永兴三年（306）进车骑将军，死后赠新城郡公，开府与刺荆州已有在先；本注压缩先后于一语。

<a id="sgz-note-3"></a>

### 3. 刘弘病卒

[返回正文第3条](#sgz-event-3)

<a id="sgz015-p-001-8"></a>

**[《三国志·刘司马梁张温贾传》裴注 001·8](../../sources/本地分卷/三国志/三国志-卷015.md#pei-001-8)**

> 㑹弘病卒子璠北中郎將

**归年** 《资治通鉴》卷八十六光熙元年八月，刘弘卒，郭舒等推刘璠平乱。《晋书·刘弘传》叙刘璠为顺阳内史、越骑校尉等，《晋阳秋》另存北中郎将而不具任年。

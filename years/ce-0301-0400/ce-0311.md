# 公元311年｜西晋永嘉五年

[← 公元309年](ce-0309.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元312年 →](ce-0312.md)

[本年相关史料](#sources-start)

<a id="sgz-event-1"></a>

1. **罗徽被王如杀。** 罗袭子罗徽任顺阳内史，永嘉五年被王如杀。 [[1]](#sgz-note-1)

<a id="sgz-event-2"></a>

2. **王裒因眷恋坟墓不渡江。** 洛阳陷落后，王裒的亲族想迁往江东，王裒因眷恋亲人坟墓而留下。后来寇势愈急，他南行到泰山，遇害的具体年份未载。 [[2]](#sgz-note-2)

<a id="sgz-event-3"></a>

3. **西晋洛阳陷后卢谌北投刘琨。** 洛阳陷落后，卢谌跟随父亲卢志北投刘琨，途中一度被刘粲扣留，后来才到刘琨处。 [[3]](#sgz-note-3)

### 2. 王裒因眷恋坟墓不渡江

[返回正文第2条](#sgz-event-2)

**《袁張涼國田王邴管傳》互見** [TXT 第86行](../../拆分史书/三国志/卷011.md#edition-wei011-l86-7)

<a id="wei011-l86-6"></a>

**[《三國志·袁張涼國田王邴管傳》裴注](../../拆分史书/三国志/卷011.md#edition-wei011-l86-6)** · [TXT L86](../../拆分史书/三国志/卷011.txt#L86)

> 及洛都傾覆，寇賊蠭起，襃宗親悉欲移江東，襃戀墳壠。

**釋讀與歸年** 洛阳倾覆，王裒亲族欲迁江东，他因眷恋坟茔留下。311年是洛阳陷落的年份，后续出走、遇害未能独立定年。[《晋书·王裒传》](../../史书/005-晋书/晋书-CCDH.txt#L8373-L8374)

<a id="sgz011-p-023-9"></a>

[本卷同事原句](#wei011-l86-6)。

**归年** 《晋书·怀帝纪》永嘉五年陷洛；本句连叙若干去留，未署迁泰山月日。

<a id="sgz-note-3"></a>

### 3. 西晋洛阳陷后卢谌北投刘琨

[返回正文第3条](#sgz-event-3)

<a id="wei022-l105-9"></a>

**[《三國志·桓二陳徐衞盧傳》裴注](../../拆分史书/三国志/卷022.md#edition-wei022-l105-9)** · [TXT L105](../../拆分史书/三国志/卷022.txt#L105)

> 洛陽傾覆，北投劉琨，

**釋讀與歸年** 洛陽失守後盧諶北依劉琨。[《晉書·盧諶傳》](../../史书/005-晋书/晋书-CCDH.txt#L5552)補載他隨父盧志北走，為劉粲所俘後才再赴劉琨。歸永嘉五年洛陽陷落本事。

<a id="sgz022-p-020-9"></a>

[本卷同事原句](#wei022-l105-9)。

**归年** 《晋书·怀帝纪》永嘉五年六月洛阳失陷；别传以此为北投背景。下文任官另分。

# 公元317年｜西晋建兴五年／东晋建武元年

1. **司马睿为晋王，任贺循中书令，贺循辞而改太常。** 司马睿受晋王号后，任贺循为中书令，贺循以年老有病辞谢，改任太常。江东朝廷的宗庙礼制多由贺循议定。 [[1]](#sgz-note-1)

<a id="wu064-huatan-first-event"></a>

2. **晋王府初建，华谭辞秘书监。** 建武初，朝廷授华谭秘书监，他坚辞未拜。华谭此前曾在司马睿府中任军谘祭酒。 [[2]](#wu064-huatan-first)

### 1. 司马睿为晋王，任贺循中书令，贺循辞而改太常

[返回正文第1条](#sgz-event-1)

<a id="sgz065-p-004-9"></a>

<a id="wu065-l38-10"></a>

**[《三國志·王樓賀韋華傳》裴注 004](../../拆分史书/三国志/卷065.md#edition-wu065-l38-10)** · [TXT L38](../../拆分史书/三国志/卷065.txt#L38)

> 帝爲晉王，以循爲中書令，固讓不受，轉太常，

**釋讀** 司馬睿為晉王時，欲以賀循任中書令。賀循一再辭讓，於是改任太常。

**歸年** [《通鑑》卷090](../../史书/025-资治通鉴/KR2b0007_090.txt#L69-L85)及[《晉書·賀循傳》](../../史书/005-晋书/晋书-CCDH.txt#L7068)同繫建武初年，通鑑記賀循以老病辭。

<a id="wu064-huatan-first"></a>

### 2. 晋王府初建，华谭辞秘书监

[返回正文第2条](#wu064-huatan-first-event)

**[《晉書·華譚傳》](../../史书/005-晋书/晋书-CCDH.txt#L6090)**

> 建武初，授秘書監，固讓不拜。

**[《三國志·孫綝傳》裴注引《文士傳》](../../拆分史书/三国志/卷064.md#edition-wu064-l93-3)** · [TXT L93](../../拆分史书/三国志/卷064.txt#L93)

> 次子譚，以才辯稱，晉祕書監。

**歸年** 建武始於317年三月，次年三月改元太興。傳文作「建武初」，繫於建元之年，月日未載。太興初[實任祕書監](ce-0318.md#wu064-huatan-office)。

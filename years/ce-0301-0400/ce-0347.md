# 公元347年｜东晋永和三年

[← 公元343年](ce-0343.md) · [本世纪目录](README.md) · [全部世纪](../README.md) · [公元350年 →](ce-0350.md)

[本年相关史料](#sources-start)

<a id="sgz-event-1"></a>

1. **孙盛随晋军平李势，在成都见到刘玄。** 孙盛记东晋攻李势时自己参与军旅，在成都见到刘玄。 [[1]](#sgz-note-1)

<a id="sgz-event-2"></a>

2. **桓温平蜀上表推荐谯秀。** 桓温称谯秀在成汉威逼下坚持不仕，地方称美，请朝廷礼聘以崇尚德义。 [[2]](#sgz-note-2)

<a id="sgz-event-3"></a>

3. **萧敬文作乱，谯秀引族乡人避难宕渠。** 萧敬文作乱时，谯秀避到宕渠川，数百宗族乡人依从，他们要替八十岁的他背物，谯秀请先帮助各家老弱。 [[3]](#sgz-note-3)

<a id="sgz-event-4"></a>

4. **常璩记蜀地长老所述陈寿与诸葛瞻。** 长老称陈寿曾为诸葛瞻吏并受辱，故后来将恶归黄皓并说瞻不能匡矫。 [[4]](#sgz-note-4)

## 本年相关史料

<a id="sgz-note-1"></a>

### 1. 孙盛随晋军平李势，在成都见到刘玄

[返回正文第1条](#sgz-event-1)

<a id="sgz034-p-006-6"></a>

**[《三国志·二主妃子传》裴注 006·6](../../sources/摘录/三国志-卷034-二主妃子传裴注.md#pei-006-6)**

> 永和三年討李勢盛参戎行見玄於成都也

**归年** 注明晋永和三年，《晋书·穆帝纪》《桓温传》证永和二年出兵、三年攻取成都。

<a id="sgz044-p-016-3"></a>

**[《三国志·蒋琬费祎姜维传》裴注 016·3](../../sources/摘录/三国志-卷044-蒋琬费祎姜维传裴注.md#pei-016-3)**

> 孫盛晉陽秋曰盛以永和初從安西將軍平蜀見諸故老及

**释读** 孙盛追记自己在晋永和初随安西将军平蜀，见了当地故老、并提及下文姜维密疏。

**归年** 《晋书·穆帝纪》桓温永和二年十一月伐蜀、三年三月克成都；见故老连入永和三年。

### 2. 桓温平蜀上表推荐谯秀

[返回正文第2条](#sgz-event-2)

<a id="sgz042-p-017-3"></a>

**[《三国志·二杜周许孟来尹李谯郤传》裴注 017·3](../../sources/摘录/三国志-卷042-二杜周许孟来尹李谯郤传裴注.md#pei-017-3)**

> 永和三年安西將軍桓温平蜀表薦秀曰臣聞大朴既虧則髙尚之標顯道喪時昏則忠貞之義彰故有洗耳投淵以振玄邈之風亦有秉心矯迹以惇在三之節是以上代之君莫不崇重斯軌所以篤俗訓民靜一流競伏惟大晉應符御世運無常通時有屯〔四库字图2874〕神州丘墟三方圯裂兎置絶響於中林白駒無聞於空谷斯有識之所悼心大雅之所歎息者也陛下聖徳嗣興方恢天緒臣昔奉役有事西土鯨鯢既縣思宣大化訪諸故老捜揚潛逸庶武羅於羿浞之墟想王蠋於亡齊之境竊聞巴西譙秀植操貞固抱徳肥遁揚清渭波于時皇極遘道消之㑹羣黎蹈顛沛之艱中華有顧瞻之哀幽谷無遷喬之望凶命屢招姦威仍偪身寄虎吻危同朝露而能抗節玉立誓不降辱杜門絶跡不面偽庭進免龔勝亡身之禍退無薛方詭對之譏雖園綺之棲啇洛管寧之黙遼海方之於秀殆無以過于今西土以為美談夫旌徳禮賢化道之所先崇表殊節聖哲之上務方今六合未康豺狼當路遺黎偸薄義聲弗聞益宜振起道義之徒以敦流遁之弊若秀蒙蒲帛之徴足以鎭靜頽風軌訓嚻俗幽遐仰流九服知化矣

**归年** 《晋书·穆帝纪》永和三年桓温平蜀，注文同年；推荐表与孙盛见故老并列两个行动。

### 4. 常璩记蜀地长老所述陈寿与诸葛瞻

[返回正文第4条](#sgz-event-4)

<a id="sgz035-p-033-2"></a>

**[《三国志·诸葛亮传》裴注 033·2](../../sources/摘录/三国志-卷035-诸葛亮传裴注.md#pei-033-2)**

1. **孙盛随晋军平李势，在成都见到刘玄。** 孙盛记东晋攻李势时自己参与军旅，在成都见到刘玄。 [[1]](#sgz-note-1)

<a id="sgz-event-2"></a>

2. **桓温平蜀上表推荐谯秀。** 桓温称谯秀在成汉威逼下坚持不仕，地方称美，请朝廷礼聘以崇尚德义。 [[2]](#sgz-note-2)

<a id="sgz-event-3"></a>

3. **萧敬文起兵，谯秀避难的确年待考。** 十二月，萧敬文夺取涪城，继而占据巴西。裴注另记谯秀在这场动乱中避难宕渠、照顾乡族；动乱延续数年，避难与他当时年八十的具体年份未载，详见[时期材料](../ce-0201-0300/时期-三国志卷042-二杜周许孟来尹李谯郤传纪年待考（2）.md#shu042-l96-3)。 [[3]](#sgz-note-3)

<a id="sgz-event-4"></a>

4. **常璩记蜀地长老所述陈寿与诸葛瞻。** 长老称陈寿曾为诸葛瞻吏并受辱，故后来将恶归黄皓并说瞻不能匡矫。 [[4]](#sgz-note-4)

### 2. 桓温平蜀上表推荐谯秀

[返回正文第2条](#sgz-event-2)

<a id="sgz042-p-017-3"></a>

<a id="shu042-l96-2"></a>

**[《三國志·杜周杜許孟來尹李譙郤傳》裴注](../../拆分史书/三国志/卷042.md#edition-shu042-l96-2)** · [TXT L96](../../拆分史书/三国志/卷042.txt#L96)

> **〔裴注〕**
>
> 永和三年，安西將軍桓溫平蜀，表薦秀曰：「臣聞大朴旣虧，則高尚之標顯；道喪時昏，則忠貞之義彰。故有洗耳投淵以振玄邈之風，亦有秉心矯迹以惇在三之節。是以上代之君，莫不崇重斯軌，所以篤俗訓民，靜一流競。伏惟大晉應符御世，運無常通，時有屯蹇，神州丘墟，三方圮裂，兔罝絕響於中林，白駒無聞於空谷，斯有識之所悼心，大雅之所歎息者也。陛下聖德嗣興，方恢天緒。臣昔奉役，有事西土，鯨鯢旣縣，思宣大化；訪諸故老，搜楊潛逸，庶武羅於羿、浞之墟，想王蠋於亡齊之境。切聞巴西譙秀，植操貞固，抱德肥遁，揚清渭波。于時皇極遘道消之會，群黎蹈顛沛之艱，中華有顧瞻之哀，幽谷無遷喬之望；凶命屢招，姦威仍偪，身寄虎吻，危同朝露，而能抗節玉立，誓不降辱，杜門絕跡，不面偽庭，進免龔勝亡身之禍，退無薛方詭對之譏；雖園、綺之棲商、洛，管寧之默遼海，方之於秀，殆無以過。于今西土，以爲美談。夫旌德禮賢，化道之所先，崇表殊節，聖哲之上務。方今六合未康，豺狼當路，遺黎偷薄，義聲弗聞，益宜振起道義之徒，以敦流遁之弊。若秀蒙蒲帛之徵，足以鎮靜頹風，軌訓嚻俗；幽遐仰流，九服知化矣。」

**释读** 永和三年，桓温平定成汉，上表推荐谯秀。他称谯秀在成汉威逼下仍守志不仕，品格足与商山四皓、管宁相比，请朝廷以礼征聘，让天下看见朝廷崇德尚节的态度。荐表全文说明，举用隐士既是尊重其个人操守，也是希望借其名望改变士风。

**归年与互校** 《晋阳秋》明记永和三年，即347年；荐表中的西晋覆败、成汉征召等是追述。只把桓温平蜀后荐举系本年，下一段萧敬之乱中的避难及更后的死亡分开，不据前一个明确年包办全段。

### 4. 常璩记蜀地长老所述陈寿与诸葛瞻

[返回正文第4条](#sgz-event-4)

<a id="shu035-l124-2"></a>

**[《三國志·諸葛亮傳》裴注](../../拆分史书/三国志/卷035.md#edition-shu035-l124-2)** · [TXT L124](../../拆分史书/三国志/卷035.txt#L124)

> 晉永和三年，蜀史常璩說蜀長老云：「陳壽甞爲瞻吏，爲瞻所辱，故因此事歸惡黃皓，而云瞻不能匡矯也。」

**釋讀與歸年** 孫盛所記永和三年常璩對蜀中長老之語，稱陳壽曾為瞻吏而受辱，因而把政局之失歸於黃皓。此爲常璩所述，不作陳壽故意失實的定論。

<a id="sgz035-p-033-2"></a>

[本卷同事原句](#shu035-l124-2)。

**归年** 《异同记》明永和三年。仅系所得口述，不据它断陈寿动机为事实。

# 上古传说时代｜黄帝、颛顼与帝喾

[上古目录](README.md) · [全部时间入口](../README.md) · [继续：尧舜至禹 →](02-尧舜至禹.md)

神农氏衰落后，轩辕在诸侯之间聚起力量，先在阪泉与炎帝交战，又在涿鹿击败蚩尤，最后被推举为共主。黄帝去世后，接位的人先出自昌意一支，再转到玄嚣一支，直到帝挚之后由尧接掌。

这段上古传说按《五帝本纪》所传的先后讲述，公元纪年未定。[纪年依据](../../meta/考证/上古纪年与断代工程.md)

<a id="event-1"></a>

1. **轩辕先战炎帝，后败蚩尤，被诸侯尊为黄帝。** 轩辕是少典之子，姓公孙。传说中，他年幼时便显得不同寻常。等到他在诸侯中出头，神农氏的势力已经衰落，各地彼此攻打，神农氏也无力制止。轩辕整备军队，征讨不肯服从者，一批诸侯由此前来归附。炎帝又要侵扰诸侯，诸侯转而依靠轩辕。轩辕整顿兵众、经营农事、安抚民众，随后在阪泉与炎帝交战，打过三次才取胜。

   蚩尤仍不听从号令。轩辕调集诸侯的军队，在涿鹿交战，擒杀蚩尤。诸侯这才共同尊轩辕为天子，让他取代神农氏，这就是黄帝。 [[1]](#note-1)

<a id="huangdi-rule"></a>
<a id="成为黄帝以后征行农事和祭祀都由他统领"></a>
<a id="event-2"></a>

2. **黄帝往来四方，任用风后等人料理民事。** 受尊立后，黄帝仍四处征行。遇有不服从的地方就出兵，平定以后便离开，也曾劈山开路。传说写他东到海边和岱宗，西到空桐、鸡头，南到江边和熊、湘，向北驱逐荤粥，在釜山合符，又在涿鹿附近建邑。他居处不定，往来以兵众护卫。

   黄帝以云命官，设置左右大监，又任用风后、力牧、常先、大鸿。治民也包括安排播种、节用水火物资，祭祀山川鬼神，观测日月以推算时日。传说用土德的祥瑞解释他的帝号。 [[2]](#note-2)

<a id="huangdi-family"></a>
<a id="嫘祖的两个儿子把后面的几条世系连在一起"></a>
<a id="event-3"></a>

3. **黄帝葬于桥山，昌意之子高阳继位。** 黄帝有二十五个儿子，传说其中十四人得姓。他在轩辕之丘娶西陵氏女嫘祖为正妃，两人生了玄嚣和昌意。玄嚣又叫青阳，居于江水；昌意居于若水，娶蜀山氏女昌仆，生下高阳。黄帝去世，葬在桥山，接位的是孙辈的高阳，也就是颛顼。 [[3]](#note-3)

<a id="zhuanxu"></a>
<a id="颛顼接位帝喾却来自另一支"></a>
<a id="event-4"></a>

4. **颛顼去世，帝位转到玄嚣之孙高辛。** 高阳在位时，传说中的治事重心是因地取材、顺时行事、教化民众和诚心祭祀。幽陵、交阯、流沙、蟠木是叙事列出的四方远地。高阳有个儿子叫穷蝉。他去世后，继位的人却出自玄嚣一支：玄嚣的儿子是蟜极，蟜极的儿子是高辛。玄嚣、蟜极在这一条继承线上都没有在位，高辛接掌帝位，成为帝喾。 [[4]](#note-4)

<a id="diku"></a>
<a id="帝喾以后先是帝挚再到尧"></a>
<a id="event-5"></a>

5. **帝喾之后，帝挚先立，弟弟放勋继位。** 传说高辛一出生便能说出自己的名字。成年后，他关心民众的急务，取用土地物产而力求节俭，也安排历日、祭祀和教养民众的事务。他娶陈锋氏女，生下放勋；又娶娵訾氏女，生下挚。帝喾去世后，挚先即位，后来帝位传到他的弟弟放勋，也就是尧。 [[5]](#note-5)

### 阪泉、涿鹿与尊立

本纪先说诸侯归附轩辕，再写阪泉、涿鹿，最后才说诸侯尊他为天子。原文在涿鹿交战处先用后来的称号“黃帝”，叙事上的尊立仍在擒杀蚩尤之后。战斗次数“三戰”照本纪保存；“教熊羆貔貅貙虎”的所指存疑。这里的“天子”“诸侯”是传世文本的称谓，兵力、伤亡和行军路线都无从由本段落实。[返回第1条原文](#note-1)

<a id="geography-reading"></a>

### 四方地名、礼仪与治世观念

黄帝行迹与颛顼四至采用原书的相对方位。涿鹿“之阿”可理解为山旁或山脚，幽陵、交阯等仍按古书名目保存。宝鼎、封禅、土德等属于传说及其治世解释，地名罗列也不足以画出同时存在的行政疆界。[黄帝行迹原文](#note-2) · [颛顼四至原文](#note-4)

### 卷十三对读｜夏、商、周的族系

《三代世表》把昌意、玄嚣两支并列。昌意一支经颛顼连到舜和禹；玄嚣一支经蟜极、高辛连到尧，以及商的先祖契、周的先祖后稷。舜的传说世系另接[舜的登场](02-尧舜至禹.md#shun-early)。表格各栏同一横行只方便并读，王位先后与亲族世系各有自己的次序。鲧与颛顼的代数也有异文。[七支世系表](../../sources/摘录/史记-卷013-三代世表.md#t001) · [世数与异文](../../meta/考证/史记-卷013-纪年与异说.md#异文与世数)

<a id="dizhi-reading"></a>

### 帝挚怎样离位

仓库工作本在“不善”后有“崩”。仓内三家注把该字写作“不善（崩）”，《索隐》还记载“不著／不善”异文，并引卫宏说挚禅位；《正义》所引《帝王纪》也保存禅位叙事。正文采用两种说法都能支持的先后，帝挚是否在放勋即位前去世存疑。引文中的“九年”属于注家保存的传统，未换算成公元纪年。[《史记三家注·五帝本纪》帝挚条](../../sources/史记三家注/卷001.md#p11)

> 衞宏云：「摯立九年而唐侯德盛，因禪位焉。」

> 摯在位九年，政微弱，而唐侯德盛，諸侯歸之，摯服其義，乃率羣臣造唐而致禪。

### 卷024｜黄帝合乐的后世追述

晋平公听乐的故事里，师旷借黄帝合鬼神的旧传劝戒平公。风雨飞瓦与晋国大旱发生在这个故事的晋国叙事中；黄帝合乐本身只是师旷所说的前事，时间和地点未详。[《乐书》P065](../../sources/摘录/史记-卷024-乐书.md#p065) · [濮水故事与平行文本](../../meta/考证/史记-卷024-纪年与异说.md#濮水传说) · [逐段互校](../../meta/记录/史记-卷024-逐段互校.md#p065)

> 昔者黃帝以大合鬼神，今君德義薄，不足以聽之，聽之將敗。

### 卷025｜兵论中的黄帝、颛顼例证

《律书》把黄帝在涿鹿用兵与颛顼对阵共工并列，接着说到成汤，借历代胜者论用兵。文颖把“火災”“水害”分别联系神农子孙和共工为水官的传说。颛顼故事里的共工与尧舜故事中的共工，身份关系存疑。[《律书》P005](../../sources/摘录/史记-卷025-律书.md#p005) · [兵论及史例性质](../../meta/考证/史记-卷025-纪年与异说.md#兵论与史例) · [三家注卷025](../../sources/本地引用/史記三家註-卷025.md#ref-a81167055e21d7)

> 昔黃帝有涿鹿之戰，以定火災；顓頊有共工之陳，以平水害；成湯有南巢之伐，以殄夏亂。遞興遞廢，勝者用事，所受於天也。

### 卷026、027｜历数传统与重、黎分职

《历书》从黄帝考定星历、校正闰余讲起，接着写少暤衰世时九黎扰乱秩序，以及颛顼任命重、黎分掌天、地，分别主神事、民事。“南正重”“火正黎”照底本保留，古注另有兼官和“北正”异说。《天官书》以“高辛之前”定位重、黎，保留相对先后。[《历书》P003](../../sources/摘录/史记-卷026-历书.md#p003) · [《历书》P004](../../sources/摘录/史记-卷026-历书.md#p004) · [《天官书》P113](../../sources/摘录/史记-卷027-天官书.md#p113) · [历书上古材料分层](../../meta/考证/史记-卷026-纪年与异说.md#上古)

> 太史公曰：神農以前尚矣。蓋黃帝考定星曆，建立五行，起消息，正閏餘，於是有天地神祇物類之官，是謂五官。各司其序，不相亂也。民是以能有信，神是以能有明德。民神異業，敬而不瀆，故神降之嘉生，民以物享，災禍不生，所求不匱。

> 少暤氏之衰也，九黎亂德，民神雜擾，不可放物，禍菑薦至，莫盡其氣。顓頊受之，乃命南正重司天以屬神，命火正黎司地以屬民，使復舊常，無相侵瀆。

> 昔之傳天數者：高辛之前，重、黎；於唐、虞，羲、和；有夏，昆吾；殷商，巫咸；周室，史佚、萇弘；於宋，子韋；鄭則裨灶；在齊，甘公；楚，唐眛；趙，尹皋；魏，石申。

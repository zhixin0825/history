# 上古传说时代｜黄帝、颛顼与帝喾

[上古目录](README.md) · [全部时间入口](../README.md) · [继续：尧舜至禹 →](02-尧舜至禹.md)

神农氏衰落后，轩辕在诸侯之间聚起力量，先在阪泉与炎帝交战，又在涿鹿击败蚩尤，最后被推举为共主。黄帝去世后，接位的人先出自昌意一支，再转到玄嚣一支，直到帝挚之后由尧接掌。

这段上古传说按《五帝本纪》所传的先后讲述，公元纪年未定。[纪年依据](#kao-2b974da3ad)

1. **轩辕先战炎帝，后败蚩尤，被诸侯尊为黄帝。** 轩辕是少典之子，姓公孙。传说中，他年幼时便显得不同寻常。等到他在诸侯中出头，神农氏的势力已经衰落，各地彼此攻打，神农氏也无力制止。轩辕整备军队，征讨不肯服从者，一批诸侯由此前来归附。炎帝又要侵扰诸侯，诸侯转而依靠轩辕。轩辕整顿兵众、经营农事、安抚民众，随后在阪泉与炎帝交战，打过三次才取胜。

   蚩尤仍不听从号令。轩辕调集诸侯的军队，在涿鹿交战，擒杀蚩尤。诸侯这才共同尊轩辕为天子，让他取代神农氏，这就是黄帝。 [[1]](#note-1)

<a id="huangdi-rule"></a>
<a id="成为黄帝以后征行农事和祭祀都由他统领"></a>
<a id="event-2"></a>

2. **黄帝往来四方，任用风后等人料理民事。** 受尊立后，黄帝仍四处征行。遇有不服从的地方就出兵，平定以后便离开，也曾劈山开路。传说写他东到海边和岱宗，西到空桐、鸡头，南到江边和熊、湘，向北驱逐荤粥，在釜山合符，又在涿鹿附近建邑。他居处不定，往来以兵众护卫。

   黄帝以云命官，设置左右大监，又任用风后、力牧、常先、大鸿。治民也包括安排播种、节用水火物资，祭祀山川鬼神，观测日月以推算时日。传说用土德的祥瑞解释他的帝号。 [[2]](#note-2)

<a id="huangdi-family"></a>
<a id="嫘祖的两个儿子把后面的几条世系连在一起"></a>
<a id="event-3"></a>

3. **黄帝葬于桥山，昌意之子高阳继位。** 黄帝有二十五个儿子，传说其中十四人得姓。他在轩辕之丘娶西陵氏女嫘祖为正妃，两人生了玄嚣和昌意。玄嚣又叫青阳，居于江水；昌意居于若水，娶蜀山氏女昌仆，生下高阳。黄帝去世，葬在桥山，接位的是孙辈的高阳，也就是颛顼。 [[3]](#note-3)

<a id="zhuanxu"></a>
<a id="颛顼接位帝喾却来自另一支"></a>
<a id="event-4"></a>

4. **颛顼去世，帝位转到玄嚣之孙高辛。** 高阳在位时，传说中的治事重心是因地取材、顺时行事、教化民众和诚心祭祀。幽陵、交阯、流沙、蟠木是叙事列出的四方远地。高阳有个儿子叫穷蝉。他去世后，继位的人却出自玄嚣一支：玄嚣的儿子是蟜极，蟜极的儿子是高辛。玄嚣、蟜极在这一条继承线上都没有在位，高辛接掌帝位，成为帝喾。 [[4]](#note-4)

<a id="diku"></a>
<a id="帝喾以后先是帝挚再到尧"></a>
<a id="event-5"></a>

5. **帝喾之后，帝挚先立，弟弟放勋继位。** 传说高辛一出生便能说出自己的名字。成年后，他关心民众的急务，取用土地物产而力求节俭，也安排历日、祭祀和教养民众的事务。他娶陈锋氏女，生下放勋；又娶娵訾氏女，生下挚。帝喾去世后，挚先即位，后来帝位传到他的弟弟放勋，也就是尧。 [[5]](#note-5)

---

<a id="sj040-chu-origins-event"></a>

6. **楚人的祖源谱系追溯到颛顼，并以祝融解释先祖职掌。** 传世谱系以黄帝之子昌意、昌意之子颛顼高阳为起点，以下为称、卷章、重黎。重黎任帝喾火正，因功号祝融；讨共工未尽，被诛后由弟吴回承任，诛杀只记庚寅而无绝对年。吴回生陆终，其六子昆吾、参胡、彭祖、会人、曹姓、季连，相传以剖腹方式出生，季连为芈姓，楚是其后裔。季连以下为附沮、穴熊，其后家族衰微，散居中原与蛮夷地区，世次已不可尽纪。剖产是祖源传说，不能按世数平均推年。 [[6]](#sj040-chu-origins-note)

## 帝挚继位与禅位传统｜三家注卷001

来源为[仓内三家注卷001的p11完整段](../../拆分史书/史记/卷001.md#part-2-p11)，该读本来自既有[原始HTML](../../史书/001-史记/三家注原始HTML/001.htm)，上游为Ancient-China-Books/shiji的`OEBPS/Text/001.htm`，依据汉川草庐重制。它不是维基文库固定修订副本。此见证正文呈现为“不善（崩）”；索隐保留“不著／不善”异文及衞宏禅位说，正义保留帝王纪禅位说。括号形态照存，不据此改写原文，也不宣称与旧核查网页逐字同版。

> 帝嚳娶陳鋒氏女，〔索隱〕鋒音峯。案：系本作「陳酆氏」。皇甫謐云「陳鋒氏女曰慶都」。慶都，名也。〔正義〕鋒音峯。又作「豐」。帝王紀云「帝俈有四妃，卜其子皆有天下。元妃有邰氏女，曰姜嫄，生后稷。次妃有娀氏女，曰簡狄，生卨，次妃陳豐氏女，曰慶都，生放勛。次妃娵訾氏女，曰常儀，生帝摯」也。生放勳。〔正義〕放音方往反。勳亦作「勛」，音許云反。言堯能放上代之功，故曰放勛。謚堯。姓伊祁氏。帝王紀云：「帝堯陶唐氏，祁姓也。母慶都，十四月生堯。」娶娵訾氏女，生摯。〔索隱〕案：皇甫謐云「女名常宜」也。〔正義〕娵，足須反。訾，紫移反。帝嚳崩，〔集解〕皇甫謐曰：「在位七十年，年百五歲。」皇覽曰：「帝嚳冢在東郡濮陽頓丘城南臺陰野中。」而摯代立。帝摯立，不善（崩），〔索隱〕古本作「不著」，音張慮反。俗本作「不善」。不善謂微弱，不著猶不著明。衞宏云：「摯立九年而唐侯德盛，因禪位焉。」〔正義〕帝王紀云：「帝摯之母於四人中班最在下，而摯於兄弟最長，得登帝位。封異母弟放勛爲唐侯。摯在位九年，政微弱，而唐侯德盛，諸侯歸之，摯服其義，乃率羣臣造唐而致禪。唐侯自知有天命，乃受帝禪，乃封摯於高辛。」今定州唐縣也。而弟放勳立，是爲帝堯。

#### 断代工程并不是同一精度的一张表
| 材料层级 | 本项目如何放置 |
|---|---|
| 五帝传统 | 保留世系与相对先后，写入`years/上古/`，不套公元年；本轮所用工程资料不提供五帝逐王年代 |
| 夏 | 采用约前2070—前1600的王朝框架，在时期页中讲述；不替十七王平均分年、不造禹或启的确切即位年 |
| 商前期 | 先采用阶段及事件次序；材料确实支持的框架才标明约年 |
| 商后期、西周 | 工程提出较细王年，但每次实际使用仍要核出处、证据和异议；不能只因表中有数字就当无争议 |
| 能明确归年的后段 | 按原有世纪目录一年一页，不由上古例外撤销正常年页规则 |

以夏为例，李伯谦说明工程结合传世文献的积年与遗址分期、测年区间来估定起讫；这不是从遗址直接读出“禹元年”的纪年文字。考古年代、遗存的文化归属、遗址是否某位君主的都城，是三个需要分别论证的问题，不能把其中一项成立当作另外两项也自动成立。

<a id="kao-2b974da3ad-063ddc680"></a>

#### 本轮几个具体取舍
五帝页不写黄帝、尧、舜的传统公元生卒年。《五帝本纪》的年龄、摄政期和在位数放在同号注中，不与夏代约略上限机械拼接。鲧九载与禹十三年也是文本相对年数，不创建对应的一串空年页。

《夏本纪》的九州、九山、九川、五服作为文献中的治理与地理框架完整处理；不把它们解释成工程已经逐项证实的夏初疆域。中康羲和失职一节本身不具备可直接唯一反推的天象信息，故不自选一次古代日食给它安上日期。

对于二里头与夏的关系，本轮没有用一个标签替代争论。李伯谦在所引文章中支持把若干考古文化与夏对应，同时回顾多种划分意见；正文不据此推出特定器物属于禹、特定宫室属于启。新发现可以修订框架，但修订须附实际读到的研究，不只附新闻标题。

### 阪泉、涿鹿与尊立

本纪先说诸侯归附轩辕，再写阪泉、涿鹿，最后才说诸侯尊他为天子。原文在涿鹿交战处先用后来的称号“黃帝”，叙事上的尊立仍在擒杀蚩尤之后。战斗次数“三戰”照本纪保存；“教熊羆貔貅貙虎”的所指存疑。这里的“天子”“诸侯”是传世文本的称谓，兵力、伤亡和行军路线都无从由本段落实。[返回第1条原文](#note-1)

### 帝挚怎样离位

仓库工作本在“不善”后有“崩”。仓内三家注把该字写作“不善（崩）”，《索隐》还记载“不著／不善”异文，并引卫宏说挚禅位；《正义》所引《帝王纪》也保存禅位叙事。正文采用两种说法都能支持的先后，帝挚是否在放勋即位前去世存疑。引文中的“九年”属于注家保存的传统，未换算成公元纪年。[《史记三家注·五帝本纪》帝挚条](../../拆分史书/史记/卷001.md#part-2-p11)

### 卷024｜黄帝合乐的后世追述

### 卷025｜兵论中的黄帝、颛顼例证

《律书》把黄帝在涿鹿用兵与颛顼对阵共工并列，接着说到成汤，借历代胜者论用兵。文颖把“火災”“水害”分别联系神农子孙和共工为水官的传说。颛顼故事里的共工与尧舜故事中的共工，身份关系存疑。[《律书》P005](../../拆分史书/史记/卷025.md#p005) · [兵论及史例性质](../../拆分史书/史记/卷025.md#kao-665a23541f-62ea55315) · [三家注卷025](../../拆分史书/史记/卷025.md#part-2-text)

> 昔黃帝有涿鹿之戰，以定火災；顓頊有共工之陳，以平水害；成湯有南巢之伐，以殄夏亂。遞興遞廢，勝者用事，所受於天也。

### 卷026、027｜历数传统与重、黎分职

《历书》从黄帝考定星历、校正闰余讲起，接着写少暤衰世时九黎扰乱秩序，以及颛顼任命重、黎分掌天、地，分别主神事、民事。“南正重”“火正黎”照底本保留，古注另有兼官和“北正”异说。《天官书》以“高辛之前”定位重、黎，保留相对先后。[《历书》P003](../../拆分史书/史记/卷026.md#p003) · [《历书》P004](../../拆分史书/史记/卷026.md#p004) · [《天官书》P113](../../拆分史书/史记/卷027.md#part-1-p113) · [历书上古材料分层](../../拆分史书/史记/卷026.md#kao-52578ba700-befb76f1e)

> 少暤氏之衰也，九黎亂德，民神雜擾，不可放物，禍菑薦至，莫盡其氣。顓頊受之，乃命南正重司天以屬神，命火正黎司地以屬民，使復舊常，無相侵瀆。

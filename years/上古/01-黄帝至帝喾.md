# 上古传说时代｜黄帝、颛顼与帝喾

[上古目录](README.md) · [全部时间入口](../README.md) · [继续：尧舜至禹 →](02-尧舜至禹.md)

> **时间口径：只有传统叙事的先后，不填写公元起讫年。** 本页讲述《史记》保存的上古传统，不把人物世系、神异描写、巡行范围当作已经逐项得到考古证明的事实。夏商周断代工程不是五帝逐年年表，不能从夏代的约略年代倒推黄帝的生卒年。
>
> 本页主线：神农氏的权威衰落，轩辕在战争中成为诸侯共同尊奉的人；随后帝位沿着几个不同的亲族支系传承，最后转到尧。分段依据见[卷001原文去向](../../meta/记录/史记-卷001-引文去向.md)。

<a id="轩辕先在诸侯之间的战争中站了出来"></a>

<a id="event-1"></a>

1. **轩辕先在诸侯之间的战争中站了出来。** **轩辕就是后来被称作黄帝的人。** 他被记为少典之子，姓公孙。故事开头用出生不久便能说话等描写，突出他的不同寻常；接下来才交代他怎样取得支配诸侯的位置。 [[1]](#note-1)

   当时神农氏的权势已经衰落，各方彼此侵攻，原有共主不能平息争端。轩辕一面组织作战，一面安排种植、抚养民众。炎帝与他在阪泉交战，经过三次战斗，轩辕取胜。随后他又征集诸侯的兵力，在涿鹿与蚩尤交战，擒杀蚩尤。诸侯于是共同尊轩辕为天子，用他取代神农氏。

   这不是“黄帝本来已经统治全国，后来出去平叛”的简单故事。叙事先写原有秩序衰落，再写诸侯在冲突中向轩辕归附，最后才写共同尊立。阪泉与涿鹿是两个不同的战事，不合并成一次战争；也不根据这些句子补出确切兵力、伤亡和现代地图上的行军路线。

<a id="huangdi-rule"></a>
<a id="成为黄帝以后征行农事和祭祀都由他统领"></a>

<a id="event-2"></a>

2. **成为黄帝以后，征行、农事和祭祀都由他统领。** **取得共主名位以后，黄帝仍在各地往来，并不是长期安坐在一座都城中。** 叙事把他东到海边、西到空桐、南到江边、北逐荤粥的行动连在一起，又记合符于釜山、居于涿鹿附近。遇到不服从的地方便出兵，平定以后离开；山间道路也随征行而开辟。 [[2]](#note-2)

   他以“云”命名官职，设置左右大监，又任用风后、力牧、常先、大鸿管理事务。这里的事务既有耕种百谷、节约水火和物资，也有观察日月星辰、安排祭祀、推算时日。所谓“土德之瑞”，属于这套古代解释帝号与统治秩序的观念。

<a id="huangdi-family"></a>
<a id="嫘祖的两个儿子把后面的几条世系连在一起"></a>

<a id="event-3"></a>

3. **嫘祖的两个儿子，把后面的几条世系连在一起。** **黄帝之后的继承，不是一条父亲传长子的直线。** 全篇说黄帝有二十五个儿子，其中十四人得姓；展开叙述的主要是正妃嫘祖所生的玄嚣与昌意两支。 [[3]](#note-3)

   玄嚣又称青阳，居于江水；昌意居于若水，娶蜀山氏女昌仆，生下高阳。黄帝死后葬于桥山，接位的是昌意之子高阳，也就是颛顼。昌意本人没有在这个继承次序中登上帝位。

<a id="zhuanxu"></a>
<a id="颛顼接位帝喾却来自另一支"></a>

<a id="event-4"></a>

4. **颛顼接位，帝喾却来自另一支。** **颛顼号高阳，帝喾号高辛，两人不是父子。** 颛顼这一段主要概述他利用土地、顺应时序、安排教化和祭祀，没有铺开一组可逐年排列的战争或政令。叙述又把北方幽陵、南方交阯、西方流沙、东方蟠木列为其声威所及之处。 [[4]](#note-4)

   颛顼有子穷蝉；但他死后，接位的不是穷蝉，而是玄嚣之孙高辛。顺着前面的世系，高辛的父亲是蟜极，祖父是玄嚣，曾祖父是黄帝。玄嚣和蟜极都没有在位，到高辛才取得帝位，这就是帝喾。

   <a id="sj013-five-branches"></a>
   ### 卷十三对读｜夏、商、周并不出自一条直接传位的直线

   **再把三代的远祖并起来看，便能读懂为什么帝位与家族先后不是一回事。** [《三代世表》](../../sources/摘录/史记-卷013-三代世表.md#t001)从黄帝的昌意支列颛顼、鲧与禹，又从玄嚣支列帝喾、尧以及契、后稷，再分别通向商、周。各支在同一表格横向并排，不意味着他们同年出生或同时在位。舜也被放到昌意、颛顼经穷蝉的一条远亲支系中，具体链条接[舜的登场](02-尧舜至禹.md#shun-early)。

   **司马迁自己没有把这张世系说成上古精确年代的证明。** 卷十三序说明古代年数传本多异，取“疑则传疑”的原则；它体现的是汉代所传王统谱系，不能据此把黄帝、尧舜、三代的世代数平均换成公元年，也不能把传统远祖关系当作现代遗传学检验所得。[原文和归年限制](../../meta/考证/史记-卷013-纪年与异说.md#年代与表格)

<a id="diku"></a>
<a id="帝喾以后先是帝挚再到尧"></a>

<a id="event-5"></a>

5. **帝喾以后，先是帝挚，再到尧。** **帝喾的叙事重点仍是如何理民，而不是逐年的事件。** 他被描绘为把土地出产用于民众、节约财物、安排历日和祭祀的统治者。出生便能说出自己姓名的故事，同样属于这一篇的神异描写，不另列成可核年的史实。 [[5]](#note-5)

   帝喾娶陈锋氏女，生放勋；又娶娵訾氏女，生挚。帝喾死后先由挚继位，后来其弟放勋接位，就是尧。帝挚离位的经过有传本与注家异说，不能只写成挚死以后尧才继位。这里不能把“五帝”误读成全文只有五个人：帝挚也出现在继承链中，只是记述很短。

### 1. 轩辕先在诸侯之间的战争中站了出来

[返回正文第1条](#event-1)

**[《史記》卷001 · L3、L4](../../sources/本地分卷/史记/史记-卷001.md#L3)**

> 黃帝者，少典之子，姓公孫，名曰軒轅。生而神靈，弱而能言，幼而徇齊，長而敦敏，成而聰明。
>
> 軒轅之時，神農氏世衰。諸侯相侵伐，暴虐百姓，而神農氏弗能征。於是軒轅乃習用干戈，以征不享，諸侯咸來賓從。而蚩尤最爲暴，莫能伐。炎帝欲侵陵諸侯，諸侯咸歸軒轅。軒轅乃修德振兵，治五氣，蓺五種，撫萬民，度四方，教熊羆貔貅貙虎，以與炎帝戰於阪泉之野。三戰，然後得其志。蚩尤作亂，不用帝命。於是黃帝乃徵師諸侯，與蚩尤戰於涿鹿之野，遂禽殺蚩尤。而諸侯咸尊軒轅爲天子，代神農氏，是爲黃帝。天下有不順者，黃帝從而征之，平者去之，披山通道，未嘗寧居。

<a id="s1"></a>
<a id="s1轩辕的名字与神异开篇"></a>

**S1｜轩辕的名字与神异开篇**

P001：“黃帝者，少典之子，姓公孫，名曰軒轅。生而神靈，弱而能言。”名字、世系与神异描写一同出现在原文，整理时分别理解，不把后者转成现代可验证的人体能力记录。

<a id="s2"></a>
<a id="s2阪泉涿鹿与尊立的顺序"></a>

**S2｜阪泉、涿鹿与尊立的顺序**

P002：“神農氏世衰”“與炎帝戰於阪泉之野。三戰，然後得其志”“與蚩尤戰於涿鹿之野，遂禽殺蚩尤”“諸侯咸尊軒轅爲天子”。同段的“教熊羆貔貅貙虎”保留为原文，不擅自裁定为真实猛兽军团、六个部落，或现代兵种。这里的“天子”“诸侯”是成文叙事的用语，不据它倒推已经证实的五帝行政制度。

### 2. 成为黄帝以后，征行、农事和祭祀都由他统领

[返回正文第2条](#event-2)

**[《史記》卷001 · L5](../../sources/本地分卷/史记/史记-卷001.md#L5)**

> 東至于海，登丸山，及岱宗。西至于空桐，登雞頭。南至于江，登熊、湘。北逐葷粥，合符釜山，而邑于涿鹿之阿。遷徙往來無常處，以師兵爲營衞。官名皆以雲命，爲雲師。置左右大監，監于萬國。萬國和，而鬼神山川封禪與爲多焉。獲寶鼎，迎日推筴。舉風后、力牧、常先、大鴻以治民。順天地之紀、幽明之占、死生之說、存亡之難。時播百穀草木，淳化鳥獸蟲蛾，旁羅日月星辰水波土石金玉，勞勤心力耳目，節用水火材物。有土德之瑞，故號黃帝。

<a id="s3"></a>
<a id="s3巡行官名和土德"></a>

**S3｜巡行、官名和土德**

P003：“遷徙往來無常處，以師兵爲營衞”“官名皆以雲命”“舉風后、力牧、常先、大鴻以治民”“有土德之瑞，故號黃帝”。这一段同时包含四方空间描写、祭祀与圣王治世的概括；不将其直接画成有精确边界的疆域图。宝鼎、历数、封禅也在该段，不据此声称黄帝时代已有相应可确年的器物或仪式遗址。

### 5. 帝喾以后，先是帝挚，再到尧

[返回正文第5条](#event-5)

**[《史記》卷001 · L13、L14](../../sources/本地分卷/史记/史记-卷001.md#L13)**

> 高辛生而神靈，自言其名。普施利物，不於其身。聰以知遠，明以察微。順天之義，知民之急。仁而威，惠而信，脩身而天下服。取地之財而節用之，撫教萬民而利誨之，曆日月而迎送之，明鬼神而敬事之。其色郁郁，其德嶷嶷。其動也時，其服也士。帝嚳溉執中而徧天下，日月所照，風雨所至，莫不從服。
>
> 帝嚳娶陳鋒氏女，生放勳。娶娵訾氏女，生摯。帝嚳崩，而摯代立。帝摯立，不善，崩。而弟放勳立，是爲帝堯。

<a id="s6帝喾的治世概述与帝挚"></a>

**S6｜帝喾的治世概述与帝挚**

P009：“取地之財而節用之”“曆日月而迎送之”。P010：“帝嚳崩，而摯代立。帝摯立，不善，崩。而弟放勳立，是爲帝堯。”工作本的“崩”字照录；[《史记三家注》卷一](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7001.md#ref-afb01dddf86241)的整理文本在此标删“崩”，《索隐》引卫宏、《正义》引《帝王世纪》又保存帝挚禅位的传统。因此，正文只确定所传的继承先后，不断定帝挚必在尧继位前去世，也不把注家所述在位年数换成确切公元纪年。

### 卷025｜兵论中的黄帝、颛顼例证

[《律书》P005](../../sources/摘录/史记-卷025-律书.md#p005)以黄帝涿鹿、颛顼与共工之阵说明古代君主用兵。这里是跨代论证，不为两事另定公元年；其“定火灾”“平水害”，《集解》文颖分别联系神农子孙暴虐、共工任水官而作虐解释，不能只按字面编成两份有据的火灾、水灾实测记录。

本段颛顼与共工的传说，与后世尧舜时期共工材料有不同叙事体系；不将相同名号一律并为一个人的连续官历。黄帝涿鹿仍接本页旧核心事件，没有由《律书》再制造第二场同名战争。

[兵论及史例性质](../../meta/考证/史记-卷025-纪年与异说.md#兵论与史例) · [三家注卷025](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7025.md#ref-a81167055e21d7)。

### 卷026｜历数传统与重、黎分职

**颛顼又被记为让重掌天事、黎掌地事，使民与神的职掌各有分属。** 这一传统先说少暤衰世九黎扰乱秩序，再说颛顼恢复旧常；它与前文黄帝统领历数、祭祀的总述相接，没有可核的公元年。[原文与材料层次](../../sources/摘录/史记-卷026-历书.md#p003)

[《历书》P003—P004](../../sources/摘录/史记-卷026-历书.md#p004)将黄帝考定星历、正闰余及民神分职连叙。《三家注》对“南正重”“火正黎／北正黎”有兼官与字形等不同解释，原称不静默改字；“五官”是文本中的传统职掌分类，不凭它倒推出黄帝朝已有可独立验证的完整官制。“灾祸不生”“所求不匮”等为圣王治世的理想描述，不当作远古逐年灾害统计。见[上古材料分层](../../meta/考证/史记-卷026-纪年与异说.md#上古)。

《天官书》[P113](../../sources/摘录/史记-卷027-天官书.md#p113)又把“高辛之前，重、黎”列在天数传承之首，与本页重、黎分职的传统互见。只保存相对时代，不以高辛或颛顼的传说世数换算公元年，也不把分列的重、黎自动合成一个单名人物。

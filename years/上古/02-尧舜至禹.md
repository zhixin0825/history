# 上古传说时代｜尧舜的交接与禹的治水

[← 黄帝至帝喾](01-黄帝至帝喾.md) · [上古目录](README.md) · [全部时间入口](../README.md) · [继续：夏代 →](03-夏代.md)

<a id="reading-start"></a>

[本期同号原文](#sources-start) · [归年与考证](#appendix-start)

洪水淹过山陵，鲧多年未能平息水患。尧随后举用舜，舜先代行政务，在尧死后继位。禹接过鲧留下的治水任务，随后又成为舜选定的继承人。

本页按传世文献的人物阶段和相对先后编排。涉及禅让、族源和神异的故事保留其传说性质，未定公元年份。

<a id="gun"></a>
<a id="event-1"></a>

1. **尧命羲和安排农时，又请鲧试治洪水。** 尧名放勋。按传世叙事，他先使亲族和睦，再协调各方。他命羲和观察日月星辰，把节令告诉百姓。羲仲居东方，迎日出，安排春作；羲叔在南方掌夏事；和仲在西方候日落，安排秋收；和叔在北方掌冬藏。四时各有辨认的星象和物候，遇到岁月与季节不合，便用闰月调节。后来尧问群臣谁能承担政务，先后否决了放齐举荐的丹朱和讙兜举荐的共工。洪水漫过山陵，四岳又推举鲧治水。尧本来疑虑鲧会违命，四岳坚持让他一试。鲧治理九载，水患仍未平息。 [[1]](#note-1)

<a id="shun-early"></a>
<a id="舜登场前先是一个不断谋生又遭家人迫害的人"></a>
<a id="sj013-shun-line"></a>
<a id="event-2"></a>

2. **四岳举荐舜，举出他在家中的经历。** 鲧治水未成，尧也在访求接手政事的人。他让群臣既举荐亲贵，也举荐疏远隐居的人，四岳推举了名叫重华的舜。舜的世系上溯颛顼，从穷蝉往下却世代为平民。舜曾在历山耕田、雷泽捕鱼、河滨制陶，也在寿丘做器具，到负夏谋生。父亲瞽叟双目失明，舜的生母去世后，他再娶而生象。瞽叟偏爱后妻和象，几次想杀舜。舜遇险便躲开，家人需要他时仍回去。四岳用这段经历说明，他在家人难以相处的处境中，仍能尽自己的本分。 [[2]](#note-2)

<a id="tests"></a>
<a id="尧没有立即交位而是先把亲属和政事交给舜"></a>
<a id="event-3"></a>

3. **尧考察舜，先让他成家，继而试办政务。** 尧把两个女儿嫁给舜，让九个儿子同他往来，观察他在家内外如何待人。舜在妫汭与二女成家。关于他早年谋生的地方，故事还说历山耕者相让田界，雷泽渔者互让位置，河滨所制的器物不再粗劣；他所住的地方渐由村落聚成城邑。尧赏给舜衣、琴、牛羊，为他修建粮仓。瞽叟使舜登仓涂抹，从下纵火，舜借两顶笠脱身。后来瞽叟又让舜掘井，与象一同填土；舜从预留的旁道逃了出去。象以为舜已死，坐在他的屋里弹琴，见他回来，改口说自己想念哥哥。尧又让舜办理教化和官务、接待四方来宾，并让他进入山林川泽。传说舜经历暴风雷雨也没有迷路。试办政事数年以后，舜在正月到尧的祖庙受命。 [[3]](#note-3)

<a id="regency"></a>
<a id="舜代行政事巡行会见各方与处理刑罚"></a>
<a id="event-4"></a>

4. **舜代尧理政，巡访四方并整顿礼制。** 尧年老，让舜代行天子政务。舜先整治观测仪器，核对天象与历时，祭告上帝与山川诸神，再见各方首领。巡行从二月东赴岱宗开始，五月到南方，八月到西方，十一月到北方；各方核对历月、日序、音律、度量衡和礼节。叙事还写下五年一巡、分置十二州和疏通河川等安排。刑罚依责任和场合区别处理，鞭、扑、赎、流各有用途，偶然的过失可赦，怙恶不悛者则受刑。 [[4]](#note-4)

<a id="four-guilts"></a>
<a id="四罪与四凶是两组不能随手混成一组的材料"></a>
<a id="event-5"></a>

5. **舜请处置四罪，另有起用善族、迁徙凶族的传说。** 共工虽曾被尧否决，后来仍曾试任工师，结果行事不正。三苗也在江淮与荆州屡生动乱。舜向尧建议把共工流放到幽陵、驩兜放逐到崇山、三苗迁到三危，鲧则在羽山受到处置。另一组故事回叙舜接待四方来宾时的做法，把浑沌、穷奇、梼杌、饕餮四个被厌弃的族迁到边地。相传舜还起用了高阳氏的八恺与高辛氏的八元，前者掌管土地、协调百事，后者向四方传播父义、母慈、兄友、弟恭、子孝五教。 [[5]](#note-5)

<a id="accession"></a>
<a id="尧去世以后丹朱并没有承接帝位"></a>
<a id="event-6"></a>

6. **尧死后，舜服丧、避让丹朱，随后即位。** 尧认为丹朱不足以托付天下，选择让舜接手。尧死后，舜服三年之丧，随后退居南河以南，避开丹朱。按禅让故事，诸侯来朝、百姓诉讼，都转而找舜，歌谣也转而称颂舜。舜见各方归向自己，才登上帝位。即位以后，他仍以儿子的礼节去见瞽叟，也把弟弟象封为诸侯。 [[6]](#note-6)

<a id="xie"></a>
<a id="契的出身与他在治水教化中的任务"></a>
<a id="event-7"></a>

7. **契参与治水，受命掌教化。** 契是商人奉为先祖的人。关于他的出身，商族传说把有娀氏女子简狄说成帝喾的次妃。简狄与另外两人外出洗浴时见玄鸟掉下一枚卵，吞下后生了契。契长大后协助禹治理洪水。舜分派政务时，见亲族失和，便命契任司徒，让他以宽厚的办法教导民众如何相处。契封在商，受赐子姓。 [[7]](#note-7)

<a id="houji"></a>
<a id="弃的登场前事从学种谷物到任后稷"></a>
<a id="event-8"></a>

8. **弃从耕种入仕，后来受封为后稷。** 周人奉后稷为先祖，他名弃。周族的出生传说说，帝喾元妃姜原踩了巨人的足迹，后来生下孩子。她起初以为不祥，把孩子遗弃，牛马绕行，飞鸟展开翅膀护住他，姜原才把他抱回，取名弃。弃小时候便会种麻、菽，长大后能看地势和土质，选合适的作物来种。尧听说后让他做农师。舜又让他按时播种百谷，封在邰，号后稷，别姓姬。 [[8]](#note-8)

<a id="officials"></a>
<a id="舜把臣属分派到不同事务上"></a>
<a id="event-9"></a>

9. **舜给群臣分定职掌，定期考察功绩。** 禹、皋陶等人在尧时已获任用，舜即位后为他们分定职掌。禹负责平治水土，弃任后稷，契任司徒，皋陶掌刑狱。垂领百工，益管理山泽鸟兽，由朱虎、熊罴协助；伯夷主持祭礼，夔掌乐并教导年轻人，龙传达君命，务求消息可信。舜也告诫十二牧，处事要厚道，远离善于奉承的人。群臣每三年考察一次，经过三次考察再依成效升降。 [[9]](#note-9)

<a id="ying-origin"></a>
<a id="大费辅佐禹嬴姓先世进入这条叙事"></a>
<a id="event-10"></a>

10. **大费辅佐禹治水，后来受赐嬴姓。** 与禹同治水土的人中，有一位秦人奉为先祖的大费。秦人的起源故事从女修说起，传说她吞下玄鸟卵生大业，大业娶女华，生下大费。治水告成时，禹得到玄圭，把一份功劳归给大费。舜也赏赐大费，为他婚配，并命他照管鸟兽。他又称柏翳，受赐嬴姓。 [[10]](#note-10)

<a id="yu-works"></a>
<a id="禹接手父亲没有完成的事治水也要解决吃饭与居住"></a>
<a id="event-11"></a>

11. **禹续接鲧的工作，疏导水道、调粮并安排迁居。** 禹名文命，是鲧的儿子。舜摄政巡行时发现鲧的治水没有成效。鲧死于羽山后，舜让禹接手，后来又通过四岳重申他的水土职掌。禹曾推让给稷、契和皋陶，舜仍命他前去。禹与益、后稷动员各地人力，在山林留记号，考察山川，疏导河流与田间沟渠。他在平地乘车，入水乘船，泥地用橇，山地用檋，又以准绳、规矩测量。益发放稻种，让人们利用低湿地种植；后稷也帮助供给粮食。缺粮的地方从有余的地方调补，难以居住的地方另行安置。禹减少宫室开支，把财用投到沟渠。传说他在外十三年，经过家门也不敢进去；他与涂山氏女成婚后有了启，治水期间无暇照料孩子。 [[11]](#note-11)

<a id="nine-regions"></a>
<a id="九州水土贡物和运输道路被写成一个体系"></a>
<a id="event-12"></a>

12. **禹由冀州起行，九州各有水土、田赋和贡道。** 禹的行程从冀州说起，接着列出沇、青、徐、扬、荆、豫、梁、雍八州。各州的水土不同，所需治理和所产之物也不同。比如沇州疏通水道以后，居民得以下丘居住，桑地可以养蚕；青州既有沿海盐碱地，也以盐、细葛布和海产进贡；扬州物产包括金属、竹箭、羽革和橘柚。各州还分列田地和赋税等级，借河道运送贡物。 [[12]](#note-12)

    逐州的田赋、贡物与路线见[考证中的九州表](#s15)。

<a id="mountains-rivers"></a>
<a id="九山九川另用山系和水系把地理次序连起来"></a>
<a id="event-13"></a>

13. **九山和九川分别串联山地与水道。** 九州各有贡道，山脉和河流又穿过不止一州。山地从汧、岐至荆山一线说起，另有壶口、雷首至太岳等线路。水道从弱水流向合黎、余水入流沙说起，黄河一条则经积石、龙门、砥柱等处，到大陆以北分为九河，合流入海。汉水、长江、济水、淮水、渭水、洛水各有不同的来路和去向。 [[13]](#note-13)

    山脉和河流的各条路线见[考证中的九山九川](#s16)。

<a id="five-zones"></a>
<a id="五服从近处贡粮到远方的不同联系"></a>
<a id="event-14"></a>

14. **治水告成，五服列出各地与王畿的关系。** 九州水土既定，文献接着叙述分土、征赋和五服。五服按离中心的远近分为甸服、侯服、绥服、要服、荒服，每层五百里。甸服从近到远，交纳不同加工程度的谷物；侯服分列采、任国和诸侯；绥服一部分推行文教，一部分承担武卫；要服、荒服分别列出同中心更疏远的关系。帝赐给禹玄圭，把治水完成的消息告于天下。 [[14]](#note-14)

<a id="governance"></a>
<a id="治水以外皋陶与禹谈的是怎样用人和纠正君主"></a>
<a id="event-15"></a>

15. **皋陶与禹谈用人，舜请臣下直言纠正自己。** 皋陶和禹在舜面前谈治国。皋陶把要务归于知人、安民：懂得人的长短，才能给他合适的职位；让百姓有安定的生活，才会得到拥护。他列出九组相济的品德，如宽厚而有原则、柔和而有主见、刚强而笃实。禹随后提醒君主在位要谨慎。舜说臣下是自己的耳目手足，自己走偏时应出面规谏，别当面奉承、退后非议。舜又举丹朱为戒；禹说起自己治水期间顾不上孩子，又提醒三苗仍有不从者。皋陶随后要求民众效法禹的做法，违者依刑法处置。 [[15]](#note-15)

<a id="music"></a>
<a id="乐舞与君臣歌把赞颂和警戒放在同一场景中"></a>
<a id="event-16"></a>

16. **夔奏乐，舜与皋陶以歌相勉。** 夔奏起乐来，场景中有祖先来临、鸟兽随乐起舞、凤凰来仪。舜歌唱臣下振作、君主勤勉，百官的事务便能兴盛。皋陶先请舜谨守法度，再以两首歌作答：君主明达、臣下尽责，众事就安定；君主琐碎苛烦、臣下懈怠，万事便会废弛。舜接受了这番提醒。 [[16]](#note-16)

<a id="handoff"></a>
<a id="舜的最后交接又回到传给儿子还是传给臣属的问题"></a>
<a id="event-17"></a>

17. **舜举荐禹，禹在舜死后即位。** 舜选择禹为继承人，向天举荐。此后舜南巡，死于苍梧之野，葬在九疑。禹服丧三年后退避到阳城，避让舜子商均。诸侯却离开商均来朝见禹，于是禹即天子位，国号夏后，姓姒。丹朱和商均仍有土地奉祀先祖，也保留相应礼乐，朝见天子时以宾客相待。禹即位后的皋陶、益、启等人，见[夏代时期页](03-夏代.md)。 [[17]](#note-17)

### 3. 尧考察舜，先让他成家，继而试办政务

[返回正文第3条](#event-3)

### 舜的年数与两次交接的异说

卷001 L22在尧得舜以后写“二十年而老”及“堯辟位凡二十八年而崩”；L30把舜用事二十年、正式摄政八年分开；L32则列舜三十被举、五十摄政、五十八遇尧崩、六十一践位。《孟子》用“舜相堯二十有八載”概括尧死前的阶段，并将舜、禹即位解释为天意和民众归向。卷001 L32又写舜践位三十九年、荐禹十七年后去世，两个数字起点不同。各段支持的相对次序是被举、办事、摄政、服丧、继位。没有可靠的公元纪年可供套用。

《古本竹书纪年辑校》所收按语转引《史记·五帝本纪》正义等书，保存舜囚尧、阻断丹朱与尧相见的说法。它所展示的是后世引文流传，并非直接出土的原简。辑校按语也区分《纪年》与《琐语》的归属。本页循《五帝本纪》讲述禅让传统，另一说在此保留。至于禹退避阳城，《夏本纪》和《孟子》都有此地名。《五帝本纪》另补丹朱、商均可保有疆土、奉祀祖先。

**[《史记·五帝本纪》L22](../../sources/本地分卷/史记/史记-卷001.md#L22)**

> 堯立七十年得舜，二十年而老，令舜攝行天子之政，薦之於天。堯辟位凡二十八年而崩。

**[《史记·五帝本纪》L30](../../sources/本地分卷/史记/史记-卷001.md#L30)**

> 舜得舉，用事二十年，而堯使攝政。攝政八年而堯崩。

**[《史记·五帝本纪》L32](../../sources/本地分卷/史记/史记-卷001.md#L32)**

> 舜年二十以孝聞，年三十堯舉之，年五十攝行天子事，年五十八堯崩，年六十一代堯踐帝位。

**[《孟子·万章上》L207](../../sources/补充古籍/阅读本/孟子-萬章上.md#L207)**

> 舜相堯二十有八載，非人之所能為也，天也。堯崩，三年之喪畢，舜避堯之子於南河之南。天下諸侯朝覲者，不之堯之子而之舜；訟獄者，不之堯之子而之舜；謳歌者，不謳歌堯之子而謳歌舜，故曰天也。

**[《古本竹书纪年辑校》L263](../../sources/补充古籍/阅读本/古本竹書紀年輯校.md#L263)**

> 《史記·五帝本紀》正義引《竹書》云：「昔堯德衰，爲舜所囚也」，又引《竹書》云：「舜囚堯，復偃塞丹朱，使不與父相見也」

**[《孟子·万章上》L209](../../sources/补充古籍/阅读本/孟子-萬章上.md#L209)**

> 昔者舜薦禹於天，十有七年，舜崩。三年之喪畢，禹避舜之子於陽城。天下之民從之，若堯崩之後，不從堯之子而從舜也。

### 九山九川各条

卷002 L53、L54的九山、九川另按山脉和水道安排顺序。山水名保留底本文字层次。

九山的九组次序是：①汧、岐至荆山而逾河；②壶口、雷首至太岳；③砥柱、析城至王屋；④太行、常山至碣石入海；⑤西倾、朱圉、鸟鼠至太华；⑥熊耳、外方、桐柏至负尾；⑦嶓冢至荆山；⑧内方至大别；⑨汶山之阳至衡山，经九江至敷浅原。

|---|---|
| 弱水 | 至合黎，余波入流沙 |
| 黑水 | 经三危入南海 |
| 河 | 积石、龙门、华阴、砥柱、盟津、雒汭、大邳、降水、大陆，分为九河再入海 |
| 瀁／汉 | 嶓冢发端，东为汉、苍浪，经三澨、大别而入江，又联系彭蠡与北江入海 |

| 渭 | 鸟鼠同穴起，会沣、泾，过漆沮入河 |
| 雒 | 熊耳起，会涧、瀍、伊，入河 |

### 九德、规谏与三苗

九德原文全列于第15条同号注。皋陶把三德、六德、九德联系到不同程度的用人。卷002 L62“苗頑不即功”和卷001 L21迁三苗、L30分北三苗的语境不同。无法把这些话全部定成同一场战役或可独立确年的会议。

### 君臣歌、山川神主与南风

卷002 L64在君臣歌之后，又写尊禹的度数、声乐，为山川神主；该段的位置在叙述禹即位以前。卷024 P001借《虞书》君臣相勉引出礼乐主题，P019和P062以五弦琴和南风说明乐教。它们为古人论乐留下材料，无可确年的一次作曲记录。见[乐书异说](../../meta/考证/史记-卷024-纪年与异说.md#乐论释读)及[乐书逐段互校](../../meta/记录/史记-卷024-逐段互校.md#p019)。

> 昔者舜作五弦之琴，以歌南風；夔始作樂，以賞諸侯。

### 共同祖先与司马迁取材

> 自黃帝至舜、禹，皆同姓而異其國號，以章明德。故黃帝爲有熊，帝顓頊爲高陽，帝嚳爲高辛，帝堯爲陶唐，帝舜爲有虞。帝禹爲夏后而別氏，姓姒氏。契爲商，姓子氏。弃爲周，姓姬氏。

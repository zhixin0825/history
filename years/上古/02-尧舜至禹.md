# 上古传说时代｜尧舜的交接与禹的出现

[← 黄帝至帝喾](01-黄帝至帝喾.md) · [上古目录](README.md) · [全部时间入口](../README.md)

> **时间口径：按文献中的先后和人物阶段安排，不设公元年份。** 本页是在讲清古书保存的上古叙事，不是把其中所有制度、言辞、年龄和神异故事宣布为确证。尧、舜的年数仍留在史料说明中，不由夏代约略起点反推。
>
> 本页主线：尧安排农时，面对洪水与接班人问题；舜先经历家庭与政事考验，再代尧处理事务，最后取得帝位。禹从治理水土的臣属，成为下一次继承的中心人物。

<a id="yao"></a>
## 尧先要处理的，是农时、洪水和用人

**尧名放勋。** 他接位以后，叙述先从亲族和各方关系写起：先使九族相亲，再协调百姓与诸侯。随后出现了一件与日常生计有关的事务——什么时候耕作、什么时候收藏，不能任由各处混乱。[看原文](#s1)

<a id="calendar"></a>
**羲、和受命观察日月星辰，安排四时。** 羲仲在东方迎日，羲叔掌南方的夏事，和仲在西方安排秋收，和叔掌北方冬藏。原文分别用日长、昏中星与鸟兽生长换毛等现象，描述春、夏、秋、冬的辨别，并以置闰协调四季。[看四时与历数](#s2)

<a id="gun"></a>
**洪水迟迟不能治理，尧与群臣在用人上有过分歧。** 放齐举荐丹朱，讙兜举荐共工，尧都没有按提议直接交付大任。洪水淹过山陵、使民众受困时，四岳又共同推荐鲧。尧原先不赞成，但四岳要求先试一试，他终于同意。鲧治水九载，没有完成任务。[看荐人和治水](#s3)

<a id="shun-early"></a>
## 舜登场前，先是一个不断谋生、又遭家人迫害的人

**舜名重华，并不是以在位君主之子的身份走进这个故事。** 世系把他追溯到颛顼，但又说明，从穷蝉以下许多代已是平民。他在历山耕田、雷泽捕鱼、河边制陶，也在寿丘制作器物，在负夏经营生计。[看家世与早年](#s4)

舜的生母死后，父亲瞽叟再娶，生下象。父亲偏爱后妻和象，几次要置舜于死地；舜避开杀害，却又回去侍奉家人。这个家庭关系，是后来四岳推荐他时特别提出的考验：一个人处在这样的环境中，怎样与亲人相处。[看前事原文](#s4)

<a id="tests"></a>
## 尧没有立即交位，而是先把亲属和政事交给舜

**四岳推荐以后，尧安排了持续的考察。** 尧把两个女儿嫁给舜，让九个儿子与他相处，既看家内关系，也看家外行事。故事说舜耕作的地方，人们不再争田界；捕鱼的地方，人们互让位置；制陶的地方，器物不再粗劣。他居住的地方逐渐聚起更多人。[看考察与聚居](#s5)

在这之后，家中的谋害仍没有停止。瞽叟让舜上仓廪修整，随后从下面纵火；舜用两个笠护住自己脱身。再后来，父亲让他掘井，又与象填井，舜从预先开出的旁道逃走。象以为舜已死，准备取得舜的妻子、琴和居所；舜突然出现，象只好改口说自己思念哥哥。焚廪与填井是两次叙述，不能合成一次。[看完整情节与边界](#s5)

尧继续让舜办理教化、各类官务和接待四方来客的事务，又以进入山林、经历风雨作进一步考验。随后舜在祖庙接受政事。这里先是**代行事务**，还不是说尧在同一天去世、舜在同一天正式完成继位。[看受终与摄政](#s6)

<a id="regency"></a>
## 舜代行政事：巡行、会见各方与处理刑罚

**舜把受命与祭祀、巡行、统一礼制的活动连在一起。** 他祭告上帝、山川与诸神，接见四岳及各地负责人，检查历日、律、度量衡和礼仪。叙述安排他二月东巡、五月南巡、八月西巡、十一月北巡，又以五年一巡描述常制。[看巡狩与礼制](#s7)

刑罚也被列进政务：流放、鞭扑、赎刑等分别适用，过失可以宽赦，反复作恶则加以刑罚。这一段的重点是区分不同责任，不是把所有过错一律处理。它同时提到分置十二州、疏通河川；这些制度性概述不硬拆成十二个可确年的行政事件。[看刑罚原文](#s7)

<a id="four-guilts"></a>
## 四罪与四凶，是两组不能随手混成一组的材料

**共工、驩兜、三苗与鲧的处置，和浑沌、穷奇、梼杌、饕餮的故事，分别保留。** 前一组写舜请示尧，将共工流放幽陵，驩兜放到崇山，三苗迁到三危，鲧处置于羽山。后一组则叙述四个长期为人所恶的“凶族”，被迁往四方边远地区。[看两组原文](#s8)

与迁去凶族相对，舜还起用“八恺”“八元”：前者负责土地及各项事务，后者传播父义、母慈、兄友、弟恭、子孝五教。这一部分以十六族的善行代代相承来组织人物，不在没有根据时补出十六人的独立年表。[看八恺八元](#s8)

<a id="accession"></a>
## 尧去世以后，丹朱并没有承接帝位

**正式继位，被写成一段包含服丧、退让和诸侯归向的过程。** 尧死后，舜服丧三年，避开丹朱，迁到南河之南。前来朝见、诉讼和歌颂的人却都转向舜，而不是丹朱，舜最后才取得天子之位。[看尧舜交接](#s9)

这段把“不让天下受损而只利一人”写成尧的选择理由，也把各方是否归附作为继承的关键。它是古书保存的禅让叙事；本页不把对白当成现场记录，也不把另一种政治制度直接套上来替它命名。[看年数与叙事层次](#s9)

<a id="officials"></a>
## 舜把臣属分派到不同事务上

**在位以后，舜不是让所有人只围着一种事务转。** 禹负责水土；弃任后稷，安排谷物种植；契掌教化，皋陶掌刑；垂领百工，益管理山泽鸟兽，伯夷掌礼，夔掌乐，龙负责命令传达。对十二牧，叙述另强调厚德、远离佞人及协调四方。[看任职名单](#s10)

夔的音乐职责，也包括教导年轻人：可以刚强，但不要残虐；可以宽厚，但要有约束；可以简约，但不要傲慢。龙则要防止谗言与虚假消息混进命令。舜要求臣属敬谨办事，以三年考绩、三次考绩后升降的办法检验成效。[看考绩与乐教](#s10)

<a id="yu-works"></a>
## 禹的任务，是把治水和各地的生产联系起来

**禹在这一阶段首先是治水土的臣属，不是已经登位的夏王。** 他拜受任命时先推让给稷、契和皋陶，舜仍要他承担这项事务。随后叙述概括其开山、通泽、决河、定九州，使各地按条件进贡；与之同时，弃、益等也各自完成农业和山泽方面的职责。[看禹与其他臣属](#s11)

本篇用“四海”归服、凤凰来翔等语句结束这段治世描述。地理范围与祥瑞是这里的叙事部分，不由它推定禹实际行走过的全部现代地点，也不把凤凰当成已证实的动物记录。[看记载边界](#s11)

<a id="handoff"></a>
## 舜的最后交接，又回到“传给儿子还是传给臣属”的问题

**舜在位以后仍去见父亲，并把象封为诸侯；接班人却选了禹。** 原文把商均的品行作为没有直接传位给他的理由。舜向天举荐禹，后来南巡死于苍梧，葬在江南九疑。服丧以后，禹也像舜对丹朱那样，先退让于商均；诸侯转而朝见禹，他才取得帝位。[看禹的登位与旧族](#s12)

丹朱与商均没有因此从叙事中消失。他们保有封地，继续奉祀先人，保留相应礼乐；见天子时受到宾客式的对待。故事在这里既写新的继承，也交代旧君后人的位置。[看结尾](#s12)

## 原文与出处

本页依据[《史记》卷001固定版本](https://zh.wikisource.org/w/index.php?oldid=7903634&title=史記/卷001)。P编号与[整卷去向表](../../meta/记录/史记-卷001-引文去向.md)一致；原有回叙、复叙并入同一事件，不按原文出现次数重复计事。

<a id="s1"></a>
### S1｜尧的开篇

P011：“帝堯者，放勳”“九族既睦，便章百姓。百姓昭明，合和萬國”。衣冠车马描写为“黃收純衣，彤車乘白馬”，保留在此，不另造一次服制改革。

<a id="s2"></a>
### S2｜四时与置闰

P012分别写羲仲、羲叔、和仲、和叔，以及星鸟、星火、星虚、星昴，最后说“歲三百六十六日，以閏月正四時”。这是文本的历法叙述，不等于已经找到了能唯一反推尧某年、某地观测的天文数据；此处也不把“三百六十六日”改成现代平年实际长度。

<a id="s3"></a>
### S3｜鲧治水不成

P013：“皆曰鯀可”“九載，功用不成”。九载是本篇相对年数，不填写为一段确定公元年区间。原文没有在这里写“鲧只堵、禹只疏”这种整齐的技术二分，正文不补造。

<a id="s4"></a>
### S4｜舜的世系与生计

P018世系依次为颛顼—穷蝉—敬康—句望—桥牛—瞽叟—舜；“自從窮蟬以至帝舜，皆微爲庶人”。P019—P020交代父母与象，以及“耕歷山，漁雷澤，陶河濱，作什器於壽丘，就時於負夏”。这里是首次登场前事，不按世代平均年数配公元年。

<a id="s5"></a>
### S5｜两女九男与焚廪填井

P021：“以二女妻舜以觀其內，使九男與處以觀其外”“一年而所居成聚，二年成邑，三年成都”“舜乃以兩笠自扞而下”“舜從匿空出”。两女的后世通称、笠如何承重、暗道如何施工，都不是这几句给出的信息。家庭迫害与脱险属于所传故事，不将其包装成考古复原。

<a id="s6"></a>
### S6｜考验与受终

P014：“乃使舜慎和五典”“乃徧入百官”“賓於四門”“舜受終於文祖”。P024再次回顾用事、摄政与继位，不当作第二次推荐、第二次尧死。

<a id="s7"></a>
### S7｜巡狩、礼制与刑罚

P015包括璇玑玉衡、七政、六宗、五瑞、五礼、五玉及礼物等成套用语，且说“眚烖過，赦；怙終賊，刑”。保留这些概念所在的原文段，不用现代官制逐项硬译，不推定这些制度均一次完成。“肇十有二州”与后文九州同时存在，本轮保留文献层次，不能因数字不同静默删掉一方。

<a id="s8"></a>
### S8｜四罪、四凶与八恺八元

P016以共工、驩兜、三苗、鲧为四罪；P023叙浑沌、穷奇、梼杌、饕餮四凶族。未把两组逐个对号入座。P022：“此十六族者，世濟其美”“舜舉八愷，使主后土”“舉八元，使布五教于四方”。本篇前面的共工人名，与P024“以垂爲共工”的职名也不机械等同。

<a id="s9"></a>
### S9｜尧舜年数与丹朱

P017写“堯立七十年得舜，二十年而老”，又写“堯辟位凡二十八年而崩”；P024较明白地分出舜用事二十年、摄政八年。P026再列舜二十以孝闻、三十被举、五十摄政、五十八尧死、六十一践位。保留这些文本年数与叙述差别，不把所有数字当作连续的在位年数相加，也不靠它们生成绝对年表。

<a id="s10"></a>
### S10｜官员与考绩

P024任职长段以“女二十有二人”总括十二牧及诸臣，记“三歲一考功，三考絀陟”；P025逐项叙其功。伯夷在这里为掌礼者，不能仅凭同名认作商周之际首阳山故事中的伯夷。彭祖也在先前举用名单中，但未因此另补一个本段没有的职官。

<a id="s11"></a>
### S11｜禹与九州

P025：“披九山，通九澤，決九河，定九州，各以其職來貢”。同段所列交阯、北发、析枝、渠廋、氐、羌、山戎、息慎、鸟夷等保留为文本称谓，不能直接证明一张夏代或舜代国界图。“九招”“鳳皇來翔”是乐舞与祥瑞叙述，不漏掉，也不据此创造一件可确年的天象事件。

<a id="s12"></a>
### S12｜舜死、禹继承与旧君后人

P026：“踐帝位三十九年，南巡狩，崩於蒼梧之野”“舜乃豫薦禹於天。十七年而崩”“諸侯歸之，然後禹踐天子位”。三十九年在位与荐禹后十七年不是相继的两届在位期。丹朱、商均之封为“以奉先祀”“天子弗臣”，原文没有在此给他们封地的确定现代坐标。

<a id="s13"></a>
### S13｜篇末的共同祖先与司马迁的取材说明

P027把黄帝有熊、颛顼高阳、帝喾高辛、尧陶唐、舜有虞，与夏后姒姓、商契子姓、周弃姬姓串成共同起源。这是整篇的世系解释，不是新发生的一件事，也不等于现代意义上所有人都同一个姓。

P028是司马迁自己的论述：他比较古书、诸子与地方长老传说，择取自认为较为雅驯的记载，所以把本篇放在书首。它说明材料怎样被组织，不能据此宣布黄帝至舜所有故事已经独立证实。仓库工作TXT此段的若干书名脱落，公开对读文本保留《尚书》《宰予问五帝德》《帝系姓》《春秋》《国语》等名称；本轮未改原始TXT，详见[卷001版本说明](../../meta/记录/史记-卷001-引文去向.md#text-limit)。

# 上古传说时代｜尧舜的交接与禹的治水

[← 黄帝至帝喾](01-黄帝至帝喾.md) · [上古目录](README.md) · [全部时间入口](../README.md) · [继续：夏代 →](03-夏代.md)

> **时间口径：按文献中的先后和人物阶段安排，不设公元年份。** 本页是在讲清古书保存的上古叙事，不是把其中所有制度、言辞、年龄和神异故事宣布为确证。尧、舜的年数仍留在史料说明中，不由夏代约略起点反推。
>
> 本页主线：尧面对洪水与接班人问题；舜经过考验，代尧处理事务，最后取得帝位。禹先治理水土，后来成为继承人。《五帝本纪》《夏本纪》重叠的事情只讲一次，后者增加的治水、地理、政事材料补入这里。

<a id="yao"></a>
<a id="尧先要处理的是农时洪水和用人"></a>

<a id="event-1"></a>

1. **尧先要处理的，是农时、洪水和用人。** **尧名放勋。** 他接位以后，叙述先从亲族和各方关系写起：先使九族相亲，再协调百姓与诸侯。随后出现了一件与日常生计有关的事务——什么时候耕作、什么时候收藏，不能任由各处混乱。 [[1]](#note-1)

   <a id="calendar"></a>
   **羲、和受命观察日月星辰，安排四时。** 羲仲在东方迎日，羲叔掌南方的夏事，和仲在西方安排秋收，和叔掌北方冬藏。原文分别用日长、昏中星与鸟兽生长换毛等现象，描述春、夏、秋、冬的辨别，并以置闰协调四季。

   <a id="gun"></a>
   **洪水迟迟不能治理，尧与群臣在用人上有过分歧。** 放齐举荐丹朱，讙兜举荐共工，尧都没有按提议直接交付大任。洪水淹过山陵、使民众受困时，四岳又共同推荐鲧。尧原先不赞成，但四岳要求先试一试，他终于同意。鲧治水九载，没有完成任务。

<a id="shun-early"></a>
<a id="舜登场前先是一个不断谋生又遭家人迫害的人"></a>

<a id="event-2"></a>

2. **舜登场前，先是一个不断谋生、又遭家人迫害的人。** **舜名重华，并不是以在位君主之子的身份走进这个故事。** 世系把他追溯到颛顼，但又说明，从穷蝉以下许多代已是平民。他在历山耕田、雷泽捕鱼、河边制陶，也在寿丘制作器物，在负夏经营生计。 [[2]](#note-2)

   舜的生母死后，父亲瞽叟再娶，生下象。父亲偏爱后妻和象，几次要置舜于死地；舜避开杀害，却又回去侍奉家人。这个家庭关系，是后来四岳推荐他时特别提出的考验：一个人处在这样的环境中，怎样与亲人相处。

   <a id="sj013-shun-line"></a>
   **后来的《三代世表》把这一支再排列成明确的世系：**黄帝—昌意—颛顼—穷蝉—敬康—句望—蟜牛（桥牛）—瞽叟—舜。它帮助读者理解为什么舜虽被写成黄帝后裔，在眼前的故事里仍要靠农耕、捕鱼和制陶谋生；这不是证明各代都能找到确切生卒年的名单。[卷十三表与异写](../../sources/摘录/史记-卷013-三代世表.md#t001)

<a id="tests"></a>
<a id="尧没有立即交位而是先把亲属和政事交给舜"></a>

<a id="event-3"></a>

3. **尧没有立即交位，而是先把亲属和政事交给舜。** **四岳推荐以后，尧安排了持续的考察。** 尧把两个女儿嫁给舜，让九个儿子与他相处，既看家内关系，也看家外行事。故事说舜耕作的地方，人们不再争田界；捕鱼的地方，人们互让位置；制陶的地方，器物不再粗劣。他居住的地方逐渐聚起更多人。 [[3]](#note-3)

   在这之后，家中的谋害仍没有停止。瞽叟让舜上仓廪修整，随后从下面纵火；舜用两个笠护住自己脱身。再后来，父亲让他掘井，又与象填井，舜从预先开出的旁道逃走。象以为舜已死，准备取得舜的妻子、琴和居所；舜突然出现，象只好改口说自己思念哥哥。焚廪与填井是两次叙述，不能合成一次。

   尧继续让舜办理教化、各类官务和接待四方来客的事务，又以进入山林、经历风雨作进一步考验。随后舜在祖庙接受政事。这里先是**代行事务**，还不是说尧在同一天去世、舜在同一天正式完成继位。

<a id="regency"></a>
<a id="舜代行政事巡行会见各方与处理刑罚"></a>

<a id="event-4"></a>

4. **舜代行政事：巡行、会见各方与处理刑罚。** **舜把受命与祭祀、巡行、统一礼制的活动连在一起。** 他祭告上帝、山川与诸神，接见四岳及各地负责人，检查历日、律、度量衡和礼仪。叙述安排他二月东巡、五月南巡、八月西巡、十一月北巡，又以五年一巡描述常制。 [[4]](#note-4)

   刑罚也被列进政务：流放、鞭扑、赎刑等分别适用，过失可以宽赦，反复作恶则加以刑罚。这一段的重点是区分不同责任，不是把所有过错一律处理。它同时提到分置十二州、疏通河川；这些制度性概述不硬拆成十二个可确年的行政事件。

<a id="four-guilts"></a>
<a id="四罪与四凶是两组不能随手混成一组的材料"></a>

<a id="event-5"></a>

5. **四罪与四凶，是两组不能随手混成一组的材料。** **共工、驩兜、三苗与鲧的处置，和浑沌、穷奇、梼杌、饕餮的故事，分别保留。** 前一组写舜请示尧，将共工流放幽陵，驩兜放到崇山，三苗迁到三危，鲧处置于羽山。后一组则叙述四个长期为人所恶的“凶族”，被迁往四方边远地区。 [[5]](#note-5)

   与迁去凶族相对，舜还起用“八恺”“八元”：前者负责土地及各项事务，后者传播父义、母慈、兄友、弟恭、子孝五教。这一部分以十六族的善行代代相承来组织人物，不在没有根据时补出十六人的独立年表。

<a id="accession"></a>
<a id="尧去世以后丹朱并没有承接帝位"></a>

<a id="event-6"></a>

6. **尧去世以后，丹朱并没有承接帝位。** **正式继位，被写成一段包含服丧、退让和诸侯归向的过程。** 尧死后，舜服丧三年，避开丹朱，迁到南河之南。前来朝见、诉讼和歌颂的人却都转向舜，而不是丹朱，舜最后才取得天子之位。 [[6]](#note-6)

   这段把“不让天下受损而只利一人”写成尧的选择理由，也把各方是否归附作为继承的关键。它是古书保存的禅让叙事；本页不把对白当成现场记录，也不把另一种政治制度直接套上来替它命名。

<a id="xie"></a>
<a id="契的出身与他在治水教化中的任务"></a>

<a id="event-7"></a>

7. **契的出身与他在治水、教化中的任务。** **契是简狄之子，简狄出于有娀氏，被列为帝喾的次妃。** 商族起源故事说，简狄与另外两人外出洗浴，吞下一枚玄鸟之卵，后来生契。这里先交代的是商人祖先的所传来历；吞卵生子的部分仍是传说，不为它补上绝对年代。 [[7]](#note-7)

   契长大后参与禹的治水，后来任司徒，负责教化。舜要求他让人们懂得亲族间的责任，又特别强调宽厚施教；契被封于商，赐子姓。这个任职与下面原有官员名单中的契是同一人、同一项职掌，不因为《殷本纪》又写到就另算一次任命。

<a id="houji"></a>
<a id="弃的登场前事从学种谷物到任后稷"></a>

<a id="event-8"></a>

8. **弃的登场前事：从学种谷物到任后稷。** **弃后来成为周人奉为始祖的后稷，最先与他相连的是农事。** 他小时候便喜欢摆弄麻、菽等作物，长大后观察土地，选择合适的谷物种植。尧任用他主管农业；到了舜时，他受封于邰，号后稷，别姓姬。这补充了下文“弃任后稷”的来历，不是另一次任命。 [[8]](#note-8)

   关于出生，传统说他的母亲姜原出自有邰氏，是帝喾的元妃。姜原在野外踩到巨人的足迹，后来生下孩子，以为不祥而遗弃；牛马避开他，鸟翼护着他，姜原才重新收养，并因最初的弃置给他取名弃。这是周族讲述始祖的神异故事，不能拿来推算帝喾与尧舜的公元年代。

<a id="officials"></a>
<a id="舜把臣属分派到不同事务上"></a>

<a id="event-9"></a>

9. **舜把臣属分派到不同事务上。** **在位以后，舜不是让所有人只围着一种事务转。** 禹负责水土；弃任后稷，安排谷物种植；契掌教化，皋陶掌刑；垂领百工，益管理山泽鸟兽，伯夷掌礼，夔掌乐，龙负责命令传达。对十二牧，叙述另强调厚德、远离佞人及协调四方。 [[9]](#note-9)

   夔的音乐职责，也包括教导年轻人：可以刚强，但不要残虐；可以宽厚，但要有约束；可以简约，但不要傲慢。龙则要防止谗言与虚假消息混进命令。舜要求臣属敬谨办事，以三年考绩、三次考绩后升降的办法检验成效。

<a id="ying-origin"></a>
<a id="大费辅佐禹嬴姓先世进入这条叙事"></a>

<a id="event-10"></a>

10. **大费辅佐禹，嬴姓先世进入这条叙事。** 与禹一起治理水土的臣属中，还有大费，亦称柏翳。告成受赐时，禹把功劳也归于大费；舜给他赏赐和婚配，又让他照管鸟兽，赐姓嬴。秦人的先世由此被接入舜、禹的共同历史。 [[10]](#note-10)

    **登场前事。** 这条世系从颛顼后裔女修写起：女修吞玄鸟卵生大业，大业娶女华而生大费。它与商契的玄鸟起源叙事并列存在，各自属于所传的族源故事，不是同一个孩子的两次出生。

<a id="yu-works"></a>
<a id="禹接手父亲没有完成的事治水也要解决吃饭与居住"></a>

<a id="event-11"></a>

11. **禹接手父亲没有完成的事，治水也要解决吃饭与居住。** **禹名文命，是鲧的儿子；这时首先是治水土的臣属，不是已经登位的夏王。** 《夏本纪》把他的父系写为黄帝—昌意—颛顼—鲧—禹。鲧在羽山受诛后，禹接续其任务；拜受任命时，他曾推让给稷、契和皋陶，舜仍命他办理水土事务。 [[11]](#note-11)

    禹与益、后稷组织人力，查看山川，在行经的山林留下标记，按地势疏导水道。他在平地乘车，入水乘船，泥地用橇，山地用檋；又使用准绳、规矩等测量工具。其目的不只是使水退去，还要让水田、旱地和人们的居处重新可用。

    **有地可住之后，还要有粮食可吃。** 益给民众稻种，使低湿处可以种稻；后稷帮助取得缺少的食物。粮少的地方，由有余之处调补；不适宜居住的地方，安排迁居。禹后来在朝上谈治水时又说到这些做法，本页并入同一件事，不当成第二轮独立治水。

    个人生活被放在治水之后。故事写禹节省衣食、降低宫室用度，把财用投到沟渠；长期在外，经过家门不敢进去。他娶涂山氏女，生下启，却因治水不能顾上孩子。这里的“在外十三年”、婚后“辛壬癸甲”都是文献自身的时间说法，不自动对应一段确定的公元年。

<a id="five-zones"></a>
<a id="五服从近处贡粮到远方的不同联系"></a>

<a id="event-14"></a>

14. **五服：从近处贡粮，到远方的不同联系。** **山川与九州之后，原文把与中心的关系写成五层。** 甸服、侯服、绥服、要服、荒服，各以五百里为一层，由近及远安排贡纳、封国、文教、武卫及更疏远地区的关系。这是文本中的空间秩序，不把古里换算成公里后画出一个已证实的巨大夏朝国界。 [[14]](#note-14)

    | 名称 | 原文安排 |
    |---|---|
    | 甸服 | 以离中心远近，分别纳总、铚、秸服、粟、米；谷物加工与交纳形式有区别 |
    | 侯服 | 用采、任国、诸侯区分内外层次 |
    | 绥服 | 一部分推行文教，一部分组织武卫 |
    | 要服 | 分列夷、蔡 |
    | 荒服 | 分列蛮、流 |

    整段以“九州攸同”、整理财赋、赐土姓收束，最后由帝赐禹玄圭，宣布治水之功。制度、地理和告成功在叙述上连起来了，但不能据此说这些制度都在同一个可确定的年份首次建立。

<a id="governance"></a>
<a id="治水以外皋陶与禹谈的是怎样用人和纠正君主"></a>

<a id="event-15"></a>

15. **治水以外，皋陶与禹谈的是怎样用人和纠正君主。** **皋陶把政事分成“知人”和“安民”两项。** 能了解人，才好把他放到合适的职位；能使民众安定，才可能得到归附。他列举的九德，故意不只取一种性情：宽厚而有约束，柔和而有主见，谨厚而恭敬，有条理而敬慎，和顺而坚毅，正直而温和，简约而廉正，刚强而笃实，强而合义。 [[15]](#note-15)

    禹回应自己的工作时，没有另提一套神奇办法，而是再次讲疏水、供粮、调余、迁居；这一复述已并入前面的治水过程。接着，禹劝君主谨慎处位，舜则要求臣子真正做自己的耳目手足：辨明礼服上的日月星辰等象征，听清礼乐与言辞，尤其要在他走偏时纠正，而不是当面奉承、退后议论。

    舜又以丹朱为戒，禹说明涂山婚姻与启的出生，并提醒三苗仍有不从的情况。皋陶要求民众遵行禹所示的规范，并以刑罚制约违背者。这些话是本篇保存的政事论述，不能当成已经确年的会议逐字记录。

<a id="music"></a>
<a id="乐舞与君臣歌把赞颂和警戒放在同一场景中"></a>

<a id="event-16"></a>

16. **乐舞与君臣歌，把赞颂和警戒放在同一场景中。** **夔奏乐以后，场景转为君臣唱和。** 舜的歌把臣属尽职与政事兴盛联系起来；皋陶先提醒谨守法度，随后既唱君主明、臣属良则众事安康，又反过来唱君主烦碎、臣属怠惰则万事荒废。 [[16]](#note-16)

    祖先来格、鸟兽起舞、凤凰来仪，是这一场景中的礼乐与祥瑞描写。叙述以众人尊重禹的度数声乐、推为山川神主作结，不能把这一段仅摘成一句“凤凰出现”，也不能因有歌辞就自造一年的国家庆典。

<a id="handoff"></a>
<a id="舜的最后交接又回到传给儿子还是传给臣属的问题"></a>

<a id="event-17"></a>

17. **舜的最后交接，又回到“传给儿子还是传给臣属”的问题。** **舜在位以后仍去见父亲，并把象封为诸侯；接班人却选了禹。** 原文把商均的品行作为没有直接传位给他的理由。舜向天举荐禹，后来南巡死于苍梧，葬在江南九疑。服丧以后，禹也像舜对丹朱那样，先退让于商均；诸侯转而朝见禹，他才取得帝位。 [[17]](#note-17)

    丹朱与商均没有因此从叙事中消失。他们保有封地，继续奉祀先人，保留相应礼乐；见天子时受到宾客式的对待。故事在这里既写新的继承，也交代旧君后人的位置。

    禹登位以后的皋陶、益、启与后来的夏王世系，继续在[夏代时期页](03-夏代.md)接写。这里不另建一个“禹即位年”来复制同一段交接。

### 5. 四罪与四凶，是两组不能随手混成一组的材料

[返回正文第5条](#event-5)

**[《史記》卷001 · L21、L28、L29](../../sources/本地分卷/史记/史记-卷001.md#L21)**

> 讙兜進言共工，堯曰不可，而試之工師，共工果淫辟。四嶽舉鯀治鴻水，堯以爲不可，嶽彊請試之，試之而無功，故百姓不便。三苗在江淮、荆州數爲亂。於是舜歸而言於帝，請流共工於幽陵，以變北狄；放驩兜於崇山，以變南蠻；遷三苗於三危，以變西戎；殛鯀於羽山，以變東夷：四辠而天下咸服。
>
> 昔高陽氏有才子八人，世得其利，謂之「八愷」。高辛氏有才子八人，世謂之「八元」。此十六族者，世濟其美，不隕其名。至於堯，堯未能舉。舜舉八愷，使主后土，以揆百事，莫不時序。舉八元，使布五教于四方，父義，母慈，兄友，弟恭，子孝，內平外成。
>
> 昔帝鴻氏有不才子，掩義隱賊，好行凶慝，天下謂之渾沌。少暤氏有不才子，毀信惡忠，崇飾惡言，天下謂之窮奇。顓頊氏有不才子，不可教訓，不知話言，天下謂之檮杌。此三族世憂之。至于堯，堯未能去。縉雲氏有不才子，貪于飲食，冒于貨賄，天下謂之饕餮。天下惡之，比之三凶。舜賓於四門，乃流四凶族，遷于四裔，以御螭魅，於是四門辟，言毋凶人也。

**S8｜四罪、四凶与八恺八元**

### 6. 尧去世以后，丹朱并没有承接帝位

[返回正文第6条](#event-6)

**[《史記》卷001 · L22](../../sources/本地分卷/史记/史记-卷001.md#L22)**

> 堯立七十年得舜，二十年而老，令舜攝行天子之政，薦之於天。堯辟位凡二十八年而崩。百姓悲哀，如喪父母。三年，四方莫舉樂，以思堯。堯知子丹朱之不肖，不足授天下，於是乃權授舜。授舜，則天下得其利而丹朱病；授丹朱，則天下病而丹朱得其利。堯曰「終不以天下之病而利一人」，而卒授舜以天下。堯崩，三年之喪畢，舜讓辟丹朱於南河之南。諸侯朝覲者不之丹朱而之舜，獄訟者不之丹朱而之舜，謳歌者不謳歌丹朱而謳歌舜。舜曰：「天也夫！」而後之中國踐天子位焉，是爲帝舜。

### 9. 舜把臣属分派到不同事务上

**[《史記》卷001 · L30、L31](../../sources/本地分卷/史记/史记-卷001.md#L30)**

> 舜入于大麓，烈風雷雨不迷，堯乃知舜之足授天下。堯老，使舜攝行天子政，巡狩。舜得舉，用事二十年，而堯使攝政。攝政八年而堯崩。三年喪畢，讓丹朱，天下歸舜。而禹、皋陶、契、后稷、伯夷、夔、龍、倕、益、彭祖自堯時而皆舉用，未有分職。於是舜乃至於文祖，謀于四嶽，辟四門，明通四方耳目，命十二牧論帝德，行厚德，遠佞人，則蠻夷率服。舜謂四嶽曰：「有能奮庸美堯之事者，使居官相事？」皆曰：「伯禹爲司空，可美帝功。」舜曰：「嗟，然！禹，汝平水土，維是勉哉。」禹拜稽首，讓於稷、契與皋陶。舜曰：「然，往矣。」舜曰：「弃，黎民始飢，汝后稷，播時百穀。」舜曰：「契，百姓不親，五品不馴，汝爲司徒，而敬敷五教，在寬。」舜曰：「皋陶，蠻夷猾夏，寇賊姦軌，汝作士，五刑有服，五服三就；五流有度，五度三居：維明能信。」舜曰：「誰能馴予工？」皆曰垂可。於是以垂爲共工。舜曰：「誰能馴予上下草木鳥獸？」皆曰益可。於是以益爲朕虞。益拜稽首，讓于諸臣朱虎、熊羆。舜曰：「往矣，汝諧。」遂以朱虎、熊羆爲佐。舜曰：「嗟！四嶽，有能典朕三禮？」皆曰伯夷可。舜曰：「嗟！伯夷，以汝爲秩宗，夙夜維敬，直哉維靜絜。」伯夷讓夔、龍。舜曰：「然。以夔爲典樂，教稺子，直而溫，寬而栗，剛而毋虐，簡而毋傲；詩言意，歌長言，聲依永，律和聲，八音能諧，毋相奪倫，神人以和。」夔曰：「於！予擊石拊石，百獸率舞。」舜曰：「龍，朕畏忌讒說殄僞，振驚朕衆，命汝爲納言，夙夜出入朕命，惟信。」舜曰：「嗟！女二十有二人，敬哉，惟時相天事。」三歲一考功，三考絀陟，遠近衆功咸興。分北三苗。
>
> 此二十二人咸成厥功：皋陶爲大理，平，民各伏得其實；伯夷主禮，上下咸讓；垂主工師，百工致功；益主虞，山澤辟；弃主稷，百穀時茂；契主司徒，百姓親和；龍主賓客，遠人至；十二牧行而九州莫敢辟違；唯禹之功爲大，披九山，通九澤，決九河，定九州，各以其職來貢，不失厥宜。方五千里，至于荒服。南撫交阯、北發，西戎、析枝、渠廋、氐、羌，北山戎、發、息慎，東長、鳥夷，四海之內咸戴帝舜之功。於是禹乃興之樂，致異物，鳳皇來翔。天下明德皆自虞帝始。

### 11. 禹接手父亲没有完成的事，治水也要解决吃饭与居住

[返回正文第11条](#event-11)

**[《史記》卷002 · L38、L40、L41、L43](../../sources/本地分卷/史记/史记-卷002.md#L38)**

> 夏禹，名曰文命。禹之父曰鯀，鯀之父曰帝顓頊，顓頊之父曰昌意，昌意之父曰黃帝。禹者，黃帝之玄孫而帝顓頊之孫也。禹之曾大父昌意及父鯀皆不得在帝位，爲人臣。
>
> 當帝堯之時，鴻水滔天，浩浩懷山襄陵，下民其憂。堯求能治水者，羣臣四嶽皆曰鯀可。堯曰：「鯀爲人負命毀族，不可。」四嶽曰：「等之未有賢於鯀者，願帝試之。」於是堯聽四嶽，用鯀治水。九年而水不息，功用不成。於是帝堯乃求人，更得舜。舜登用，攝行天子之政，巡狩。行視鯀之治水無狀，乃殛鯀於羽山以死。天下皆以舜之誅爲是。於是舜舉鯀子禹，而使續鯀之業。
>
> 堯崩，帝舜問四嶽曰：「有能成美堯之事者使居官？」皆曰：「伯禹爲司空，可成美堯之功。」舜曰：「嗟，然！」命禹：「女平水土，維是勉之。」禹拜稽首，讓於契、后稷、皋陶。舜曰：「女其往視爾事矣。」
>
> 禹乃遂與益、后稷奉帝命，命諸侯百姓興人徒以傅土，行山表木，定高山大川。禹傷先人父鯀功之不成受誅，乃勞身焦思，居外十三年，過家門不敢入。薄衣食，致孝于鬼神。卑宮室，致費於溝淢。陸行乘車，水行乘船，泥行乘橇，山行乘檋。左準繩，右規矩，載四時，以開九州，通九道，陂九澤，度九山。令益予衆庶稻，可種卑溼。命后稷予衆庶難得之食。食少，調有餘相給，以均諸侯。禹乃行相地宜所有以貢，及山川之便利。

<a id="s14"></a>
<a id="s14两卷的治水材料怎样合并"></a>

**S14｜两卷的治水材料怎样合并**

卷002 P001记禹名文命与鲧、颛顼世系；P002从鲧失败、受诛接到禹续业；P003以“堯崩，帝舜問四嶽”引出司空任命，与卷001正式在位后的任官段相接。推荐、续业与再次明定职掌不强制切成三个有绝对年月的事件。

P004以“敏給克勤”等概括禹的品行，连同声律、身度的赞语归于人物描写，不解释成真实可用的人体测量标准。P005的关键句为“居外十三年，過家門不敢入”“卑宮室，致費於溝淢”“食少，調有餘相給”；本篇没有写“三次”过家门，正文不补这个次数。P021朝廷对话再次描述同一治水办法和迁居，合并处理。P023以涂山氏婚姻、启出生而未能照顾，补充禹家事；“辛壬癸甲”不直接换算为某个公元年月日。

### 12. 九州：水土、贡物和运输道路被写成一个体系

> 禹行自冀州始。冀州：既載壺口，治梁及岐。既脩太原，至于嶽陽。覃懷致功，至於衡漳。其土白壤。賦上上錯，田中中，常、衞既從，大陸既爲。鳥夷皮服。夾右碣石，入于海。

>

>
> 淮、海維揚州：彭蠡既都，陽鳥所居。三江既入，震澤致定。竹箭既布。其草惟夭，其木惟喬，其土塗泥。田下下，賦下上上雜。貢金三品，瑤、琨、竹箭，齒、革、羽、旄，島夷卉服，其篚織貝，其包橘、柚錫貢。均江海，通淮、泗。
>
> 荆及衡陽維荆州：江、漢朝宗于海。九江甚中，沱、涔已道，雲土、夢爲治。其土塗泥。田下中，賦上下。貢羽、旄、齒、革，金三品，杶、榦、栝、柏，礪、砥、砮、丹，維箘簬、楛，三國致貢其名，包匭菁茅，其篚玄纁璣組，九江入賜大龜。浮于江、沱、涔、漢，踰于雒，至于南河。
>
> 荆、河惟豫州：伊、雒、瀍、澗既入于河，滎播既都，道荷澤，被明都。其土壤，下土墳壚。田中上，賦雜上中。貢漆、絲、絺、紵，其篚纖絮，錫貢磬錯。浮於雒，達於河。
>
> 華陽、黑水惟梁州：汶、嶓既蓺，沱、涔既道，蔡、蒙旅平，和夷厎績。其土青驪。田下上，賦下中三錯。貢璆、鐵、銀、鏤、砮、磬，熊、羆、狐、貍、織皮。西傾因桓是來，浮于潛，踰于沔，入于渭，亂于河。
>
> 黑水、西河惟雍州：弱水既西，涇屬渭汭。漆、沮既從，灃水所同。荆、岐已旅，終南、敦物至于鳥鼠。原隰厎績，至于都野。三危既度，三苗大序。其土黃壤。田上上，賦中下。貢璆、琳、琅玕。浮于積石，至于龍門西河，會于渭汭。織皮昆侖、析支、渠搜，西戎即序。

<a id="s16九山九川不是逐年工程表"></a>

**S16｜九山九川不是逐年工程表**

卷002 P015段首“道九山”，P016“道九川”。本页按文本列全九组山与九条水系。“黑水入南海”“河分九河”“瀁为汉”等是文献地理的连接方式，尚未在本轮逐项解决对应地点、古今河道或水系变迁，不把表中箭头理解为现代实测地图。

<a id="note-14"></a>

### 14. 五服：从近处贡粮，到远方的不同联系

**S17｜五服与告成功**

<a id="note-15"></a>

### 15. 治水以外，皋陶与禹谈的是怎样用人和纠正君主

[返回正文第15条](#event-15)

**[《史記》卷002 · L59、L61、L62、L63](../../sources/本地分卷/史记/史记-卷002.md#L59)**

> 皋陶作士以理民。帝舜朝，禹、伯夷、皋陶相與語帝前。皋陶述其謀曰：「信其道德，謀明輔和。」禹曰：「然，如何？」皋陶曰：「於！慎其身脩，思長，敦序九族，衆明高翼，近可遠在已。」禹拜美言，曰：「然。」皋陶曰：「於！在知人，在安民。」禹曰：「吁！皆若是，惟帝其難之。知人則智，能官人；能安民則惠，黎民懷之。能知能惠，何憂乎驩兜，何遷乎有苗，何畏乎巧言善色佞人？」皋陶曰：「然，於！亦行有九德，亦言其有德。」乃言曰：「始事事，寬而栗，柔而立，愿而共，治而敬，擾而毅，直而溫，簡而廉，剛而實，彊而義，章其有常，吉哉。日宣三德，蚤夜翊明有家。日嚴振敬六德，亮采有國。翕受普施，九德咸事，俊乂在官，百吏肅謹。毋教邪淫奇謀。非其人居其官，是謂亂天事。天討有辠，五刑五用哉。吾言厎可行乎？」禹曰：「女言致可績行。」皋陶曰：「余未有知，思贊道哉。」
>
> 禹曰：「於，帝！慎乃在位，安爾止。輔德，天下大應。清意以昭待上帝命，天其重命用休。」帝曰：「吁，臣哉，臣哉！臣作朕股肱耳目。予欲左右有民，女輔之。余欲觀古人之象，日月星辰，作文繡服色，女明之。予欲聞六律五聲八音，來始滑，以出入五言，女聽。予即辟，女匡拂予。女無面諛，退而謗予。敬四輔臣。諸衆讒嬖臣，君德誠施皆清矣。」禹曰：「然。帝即不時，布同善惡則毋功。」
>
> 帝曰：「毋若丹朱傲，維慢游是好，毋水行舟，朋淫于家，用絕其世。予不能順是。」禹曰：「予娶塗山，辛壬癸甲；生啓，予不子，以故能成水土功。輔成五服，至于五千里，州十二師，外薄四海，咸建五長，各道有功。苗頑不即功，帝其念哉。」帝曰：「道吾德，乃女功序之也。」
>
> 皋陶於是敬禹之德，令民皆則禹。不如言，刑從之。舜德大明。

<a id="s18"></a>
<a id="s18九德规谏与三苗"></a>

**S18｜九德、规谏与三苗**

卷002 P020列“寬而栗，柔而立，愿而共，治而敬，擾而毅，直而溫，簡而廉，剛而實，彊而義”，又把三德、六德、九德同不同层次的任用相联系；正文概括其用人原则，不漏掉九组对举。P022：“予即辟，女匡拂予。女無面諛，退而謗予。”P023—P024接丹朱之戒、禹家事、三苗未服以及皋陶要求效法禹、违者施刑。这里的三苗记述，不自动与前面的迁三苗合并成一个确定日期的战役。

### 16. 乐舞与君臣歌，把赞颂和警戒放在同一场景中

[返回正文第16条](#event-16)

**[《史記》卷002 · L64](../../sources/本地分卷/史记/史记-卷002.md#L64)**

> 於是夔行樂，祖考至，羣后相讓，鳥獸翔舞，九成，鳳皇來儀，百獸率舞，百官信諧。帝用此作歌曰：「陟天之命，維時維幾。」乃歌曰：「股肱喜哉，元首起哉，百工熙哉！」皋陶拜手稽首揚言曰：「念哉，率爲興事，慎乃憲，敬哉！」乃更爲歌曰：「元首明哉，股肱良哉，庶事康哉！」又歌曰：「元首叢脞哉，股肱惰哉，萬事墮哉！」帝拜曰：「然，往欽哉！」於是天下皆宗禹之明度數聲樂，爲山川神主。

<a id="s19乐舞和君臣歌"></a>

**S19｜乐舞和君臣歌**

卷002 P025既写“股肱喜哉，元首起哉，百工熙哉”，又写“元首明哉，股肱良哉，庶事康哉”以及“元首叢脞哉，股肱惰哉，萬事墮哉”。赞颂、提醒和反面警告均保留其意思。最后的山川神主属于文献的礼乐解释，不与禹即位自动等同。

### 17. 舜的最后交接，又回到“传给儿子还是传给臣属”的问题

[返回正文第17条](#event-17)

**[《史記》卷001 · L32](../../sources/本地分卷/史记/史记-卷001.md#L32)**

> 舜年二十以孝聞，年三十堯舉之，年五十攝行天子事，年五十八堯崩，年六十一代堯踐帝位。踐帝位三十九年，南巡狩，崩於蒼梧之野。葬於江南九疑，是爲零陵。舜之踐帝位，載天子旗，往朝父瞽叟，夔夔唯謹，如子道。封弟象爲諸侯。舜子商均亦不肖，舜乃豫薦禹於天。十七年而崩。三年喪畢，禹亦乃讓舜子，如舜讓堯子。諸侯歸之，然後禹踐天子位。堯子丹朱，舜子商均，皆有疆土，以奉先祀。服其服，禮樂如之。以客見天子，天子弗臣，示不敢專也。

**[《史記》卷002 · L66](../../sources/本地分卷/史记/史记-卷002.md#L66)**

> 帝舜薦禹於天，爲嗣。十七年而帝舜崩。三年喪畢，禹辭辟舜之子商均於陽城。天下諸侯皆去商均而朝禹。禹於是遂即天子位，南面朝天下，國號曰夏后，姓姒氏。

<a id="s12"></a>
<a id="s12舜死禹继承与旧君后人"></a>

**S12｜舜死、禹继承与旧君后人**

卷001 P026：“踐帝位三十九年，南巡狩，崩於蒼梧之野”“舜乃豫薦禹於天。十七年而崩”“諸侯歸之，然後禹踐天子位”。三十九年在位与荐禹后十七年不是相继的两届在位期。丹朱、商均之封为“以奉先祀”“天子弗臣”，原文没有在此给他们封地的确定现代坐标。卷002 P026补记禹退避于阳城，与同一次交接合并，不另造一次让位。

### 卷026｜羲和历职与禅让告诫互见

#### S11｜禹与九州的第一层概括

#### S13｜篇末的共同祖先与司马迁的取材说明

卷001 P027把黄帝有熊、颛顼高阳、帝喾高辛、尧陶唐、舜有虞，与夏后姒姓、商契子姓、周弃姬姓串成共同起源。这是整篇的世系解释，不是新发生的一件事，也不等于现代意义上所有人都同一个姓。

P028是司马迁自己的论述：他比较古书、诸子与地方长老传说，择取自认为较为雅驯的记载，所以把本篇放在书首。它说明材料怎样被组织，不能据此宣布黄帝至舜所有故事已经独立证实。仓库工作TXT此段的若干书名脱落，公开对读文本保留《尚书》《宰予问五帝德》《帝系姓》《春秋》《国语》等名称；本轮未改原始TXT，详见[卷001版本说明](../../meta/记录/史记-卷001-引文去向.md#text-limit)。

# 夏代｜禹、启的传承与汤的兴起

[← 尧舜至禹](02-尧舜至禹.md) · [上古目录](README.md) · [全部时间入口](../README.md) · [继续：商代前期 →](04-商代前期.md)

> **约公元前2070年至前1600年。** 这是夏商周断代工程提出的夏代约略范围。下文依传世文献的王序和叙事展开，各事通常没有可确定的公元年。[年代依据](#s1)
>
> [上一页](02-尧舜至禹.md)讲禹治水及舜禹交接。本页从诸侯朝禹写起，接着讲启的继位、夏王的传承和商汤兴起。

<a id="yu-accession"></a>
<a id="禹取得帝位先考虑的继承人却不是启"></a>

<a id="event-1"></a>

1. **禹受诸侯朝见，先荐皋陶，再任用益。** [舜禹交接](02-尧舜至禹.md#handoff)之后，诸侯离开商均，前来朝见禹。禹登上天子之位，国号夏后，姓姒。他选中皋陶，打算把政事交给他，皋陶却先去世。禹封赏皋陶的后人，随后举荐益，让他主持政事。 [[1]](#note-1)

<a id="qi-accession"></a>
<a id="禹死以后诸侯转向启"></a>

<a id="event-2"></a>

2. **禹死于会稽，诸侯归向启。** 禹东巡到会稽去世，留下由益接掌天下的安排。启是禹与涂山氏女子所生。《夏本纪》说，禹的三年之丧期满，益让位退到箕山南面，诸侯纷纷前去朝见启，说启是他们君主禹的儿子。启由此继位。关于益怎样退位，古书另有[争位异说](#s3)。 [[2]](#note-2)

<a id="gan"></a>
<a id="启打败有扈氏要求军中各司其职"></a>

<a id="event-3"></a>

3. **启在甘地誓师，击败有扈氏。** 有扈氏不肯服从，启率军在甘迎战。开战前，他召集六卿，告诫战车上左右两人各守职责，御者驾好车马。他以代天行罚为出兵理由，命令听从军令者在祖先面前受赏，违令者在社受罚，家属也会受牵连。启打败有扈氏，诸侯随后前来朝见。 [[3]](#note-3)

<a id="taikang"></a>
<a id="太康失国中康时又有羲和失职"></a>

<a id="event-4"></a>

4. **太康失国，弟弟中康继位。** 启去世后，儿子太康接位，后来丢掉了国。五兄弟在洛水汇流处等待，留下《五子之歌》的故事。太康去世后，弟弟中康继位。羲、和因沉湎而耽误了按时办理的历日事务，胤出兵征讨。这是传世《胤征》所系的故事。 [[4]](#note-4)

<a id="succession"></a>
<a id="从相到孔甲多数只有继承关系没有完整的事迹年表"></a>

<a id="event-5"></a>

5. **夏王由中康一支传到孔甲。** 中康去世，儿子相继位，相之后是儿子少康。接下来的王位多在父子之间传递。到不降之后，王位先转给弟弟扃，再传给扃的儿子廑，随后回到不降的儿子孔甲。把开头的禹和最后的桀一起算入，传世夏王序共列十七人。 [[5]](#note-5)

<a id="shaokang"></a>
<a id="后羿寒浞与少康复夏是另一组文献保存的前史"></a>

<a id="event-6"></a>

6. **后羿夺取夏政，少康与旧臣恢复夏室。** 相与少康之间，另有一段失国复国的传说。夏政衰弱时，有穷后羿凭借夏民取代夏政。他倚仗射术，荒废政事，任用寒浞为相。寒浞逐渐笼络内外，后羿后来被家众杀死，旧臣靡逃到有鬲氏。寒浞命儿子浇攻灭斟灌、斟寻，相也在这场争夺中覆亡。 [[6]](#note-6)

   相的妻子怀着孩子逃回有仍，生下少康。少康长大后在有仍管放牧，遭到浇派人搜捕，又逃往有虞，掌管膳食。虞思将两名姚姓女子嫁给他，给他纶地。少康凭这块立足之地召集夏众，恢复旧有官职，派女艾侦察浇，派季杼引出豷。靡也收拢两国余众，打败寒浞、拥立少康。传说最后以少康在过灭浇、后杼在戈灭豷收束。

<a id="kongjia"></a>
<a id="孔甲的故事把诸侯离心与养龙传说放在一起"></a>

<a id="event-7"></a>

7. **诸侯疏远孔甲，刘累留下御龙传说。** 孔甲执政时热衷于求神问鬼，政事逐渐失序，诸侯多有离去。与他相连的传说还说，天降一雌一雄两条龙，孔甲不会饲养。陶唐氏后人刘累学过驯龙，前来侍奉，获赐御龙氏之号。雌龙死后，刘累把它做成食物献给夏王。夏王再叫人去找龙，刘累害怕被追究，便迁走了。 [[7]](#note-7)

<a id="tang-background"></a>
<a id="汤登场以前商的先祖已经传了许多代"></a>

<a id="event-8"></a>

8. **成汤承接商的先世，迁居于亳。** 成汤名天乙，是主癸的儿子。他的先世追溯到[佐禹治水、被任命为司徒的契](02-尧舜至禹.md#xie)。从契到汤，商人传下的世系依次为契、昭明、相土、昌若、曹圉、冥、振、微、报丁、报乙、报丙、主壬、主癸和成汤。商的居处在这段时间多次变动，传世叙事合称八迁。到汤时，商人来到先王住过的亳。 [[8]](#note-8)

<a id="yiyin"></a>
<a id="伊尹来到汤身边征伐诸侯之前先谈怎样治理"></a>

<a id="event-9"></a>

9. **伊尹辅佐成汤，汤首先出兵攻葛。** 汤得到伊尹，委以国政。伊尹曾离汤到夏，见到夏政以后又回到亳。汤出兵征伐诸侯，首先以葛伯不行祭祀为由攻葛。汤与伊尹谈起怎样看出政事治得好不好，汤打了个比方：人在水中能看见自己的样貌，从民众的处境也能看出治理的得失。 [[9]](#note-9)

<a id="tang-net"></a>
<a id="汤让捕猎的人撤去三面网"></a>

<a id="event-10"></a>

10. **成汤撤去捕网的三面。** 汤出行时见到有人四面张网，祈求四方禽兽都进网。他说这样就要捕尽了，便叫人撤去三面的网，让禽兽可以往左或往右离开。诸侯听到此事，称赞汤对禽兽也肯留一条生路。 [[10]](#note-10)

<a id="fall"></a>
<a id="桀囚禁过汤却没有阻止汤取代夏"></a>

<a id="event-11"></a>

11. **成汤起兵攻桀，夏军在鸣条一线败退。** 孔甲之后，王位经皋、发传到履癸，也就是桀。诸侯离心的局面已经持续多时，桀仍靠武力压迫民众。他曾把汤召来关在夏台，随后释放。汤争得诸侯支持，率军先灭夏代侯伯昆吾氏，再攻桀，伊尹跟随出征。 [[11]](#note-11)

    征战让一些人担心离开田地会耽误农事。汤在誓师时回应这些抱怨，将征伐归于夏政失道，许下承诺，又以严惩约束违令者。他在这段故事里自号武王。《殷本纪》说桀先在有娀之墟战败，退到鸣条，夏军在那里溃败。桀后来遭放逐而死。汤接着攻三㚇，取得宝玉。他想迁动夏社，未能如愿。诸侯归附后，汤登上天子之位。战后的诰命与治理见[商代前期](04-商代前期.md#tang-government)。

<a id="feichang"></a>
<a id="费昌离夏投汤参与鸣条之战"></a>

<a id="event-12"></a>

12. **费昌由夏投商，为汤驾车出战。** 费昌是大费的后人。大费一支传出大廉、若木两系，子孙散居各地。夏桀在位时，费昌离开夏，转投成汤，在汤的战车上担任御者。他参加的就是上一条所述的鸣条之战。 [[12]](#note-12)

<a id="zhou-ancestors"></a>
<a id="夏时的另一条族源线不窋到公刘"></a>

<a id="event-13"></a>

13. **周的先祖由不窋传到公刘。** 与夏王世系并行，周人也有一段先祖的传说。后稷去世后，儿子不窋继承。夏政衰弱，稷官不再受到重视，不窋失去职守，迁入戎狄之间。世系随后传到鞠，再到公刘。 [[13]](#note-13)

    公刘恢复耕种，察看不同土地是否适合生产，从漆、沮渡过渭水，取得人们出行和定居所需的物资。越来越多人迁来归附。公刘去世后，儿子庆节在豳立国。更晚的[周人迁岐故事](06-商末与周初.md#zhou-family)接续这条世系。

<a id="after"></a>
<a id="夏以后夏人的后裔与记忆仍被保存"></a>

<a id="event-14"></a>

14. **商汤封夏后，周代又封其后人为杞君。** 成汤取得天下之后，给夏的后裔保留了封国。到了周代，夏的后人又受封于杞。传世记忆还把若干族氏追溯到姒姓，并把历法、贡赋和会稽地名的解释与夏联系起来。这些后世传承和说法见[篇末考证](#s9)。 [[14]](#note-14)

### 6. 后羿夺取夏政，少康与旧臣恢复夏室

[返回正文第6条](#event-6)

**[《左传·襄公四年》魏绛追述](../../sources/春秋左传/有标点原文/bce-0569.md#t010)**

> 昔有夏之方衰也，后羿自鉏迁于穷石，因夏民以代夏政。恃其射也，不修民事而淫于原兽。弃武罗、伯因、熊髡、尨圉而用寒浞。寒浞，伯明氏之谗子弟也。伯明后寒弃之，夷羿收之，信而使之，以为己相。浞行媚于内而施赂于外，愚弄其民而虞羿于田，树之诈慝以取其国家，外内咸服。羿犹不悛，将归自田，家众杀而亨之，以食其子。其子不忍食诸，死于穷门。靡奔有鬲氏。浞因羿室，生浇及豷，恃其谗慝诈伪而不德于民。使浇用师，灭斟灌及斟寻氏。处浇于过，外豷于戈。靡自有鬲氏，收二国之烬，以灭浞而立少康。少康灭浇于过，后杼灭豷于戈。有穷由是遂亡，失人故也。

**[《左传·哀公元年》伍员追述](../../sources/春秋左传/有标点原文/bce-0494.md#zhuan)**

> 昔有过浇杀斟灌以伐斟，灭夏后相。后方娠，逃出自窦，归于有仍，生少康焉，为仍牧正。惎浇，能戒之。浇使椒求之，逃奔有虞，为之庖正，以除其害。虞思于是妻之以二姚，而邑诸纶。有田一成，有众一旅，能布其德，而兆其谋，以收夏众，抚其官职。使女艾谍浇，使季杼诱豷，遂灭过、戈，复禹之绩。祀夏配天，不失旧物。

## 归年与考证

<a id="原文与出处"></a>

《夏本纪》引文链接到仓内分卷的原行；[卷002引文对照](../../meta/记录/史记-卷002-引文去向.md)另列传世段落与所读版本，便于核对分卷中缺失的篇名。[原始TXT](../../sources/二十四史/txt/01_shiji_full.txt)保留原样。

<a id="补充史料与异说"></a>

### 补充史料与异说

<a id="s1"></a>
<a id="s1夏后氏开端与约略年代"></a>

### 夏代的年代框架

夏商周断代工程提出约公元前2070年至前1600年的夏代框架。它综合传世文献和考古序列等资料讨论王朝始末，不能逐一确定王位交接或战争发生的公元年。二里头遗址的分期是对遗存的判断，哪些分期属于夏、哪些属于商，还有不同意见；遗址分期本身也不能确认某层就是某位夏王的在位期。参见[断代工程成果概述](../../meta/来源/开放参考/ref-f76a794228f47bf6.md#checked)、[二里头分期与夏商归属的不同意见](../../meta/来源/开放参考/ref-e841d25c35f7d5de.md#cite-1)和[年代依据与限制](../../meta/考证/上古纪年与断代工程.md)。

<a id="s2"></a>
<a id="s2推荐皋陶再推荐益"></a>

### 皋陶后人的封地

《夏本纪》在“英、六”之后保留“或在許”。这句同时保存了另一种地点说法，无法据此断定英、六、许都是同一次分封的结果。

<a id="s3"></a>
<a id="s3禹死与益启交接"></a>

### 益与启：退让还是争位

《夏本纪》说益在禹的三年之丧后让位，《晋书·束皙传》转述汲冢所出的《纪年》却说“益幹啟位，啟殺之”。后者是《晋书》保存的古本《竹书纪年》佚文，与《史记》说法相冲突。这两条传承无法合成一条确定经过。《夏本纪》这段以“十年”开头，不足以推出禹的确切在位长度；两种说法也都不给这次交接提供可独立换算的公元年。

<a id="s4"></a>
<a id="s4甘之战与誓令"></a>

### 《甘誓》的传本与军令

《夏本纪》的仓内分卷在“將戰，作”后缺篇名，《三代世表》明确写“作甘誓”，可与誓辞互读。五行、三正与代天行罚都是誓辞中的出兵理由。文字交代了战车左右和御者的职责，没有交代兵力和可核定的战场位置。

<a id="s5"></a>
<a id="s5太康与中康的短记"></a>

### 《五子之歌》、《胤征》与日食

仓内《夏本纪》分卷这两处只作“作。”，篇名见[卷002引文对照 P031、P032](../../meta/记录/史记-卷002-引文去向.md)。本纪提到“廢時亂日”，没有提供可据以唯一确定一场日食的观测时刻和地点。这段文字不能把中康的在位年固定到某个公元年。

<a id="s6"></a>
<a id="s6王序不是绝对年表"></a>

### 夏王世系与少康复夏的两段追述

<a id="sj013-xia-compare"></a>

《三代世表》也列出从禹到桀的十七王，注明仲康、扃分别承兄之位，孔甲出自不降一支。表文的“仲康”即本纪的“中康”；本纪的“予”也按原字保留。表末的“从禹至桀十七世”和“从黄帝至桀二十世”是表中的世次说法。三家注另存鲧的父系与颛顼之间相隔数代的说法。参见[原表摘录](../../sources/摘录/史记-卷013-三代世表.md#t002)和[异文与世数](../../meta/考证/史记-卷013-纪年与异说.md#异文与世数)。

[襄公四年](../bce-0600-0501/bce-0569.md#note-11)记魏绛用后羿的故事劝晋侯，[哀公元年](../bce-0500-0401/bce-0494.md#note-3)记伍员以少康复国劝吴王。前569年和前494年是两次劝谏所属的年份。对于复夏本身，魏绛的故事交代靡灭寒浞、少康灭浇、后杼灭豷，伍员的故事则写少康的母亲出逃和少康从有虞聚众。两段都没有给出这些夏代行动的确切年份；“女艾”一名也不足以确定人物性别。

<a id="s7"></a>
<a id="s7御龙氏故事"></a>

### 孔甲与御龙氏

《夏本纪》把诸侯离心归于夏后氏德衰，又以养龙传说说明御龙氏之名，并说刘累承豕韦之后。这里所能确定的是这些说法见于同一段记载。传说本身不能用来辨认龙是什么动物，也不能确定孔甲的在位年。

<a id="s10"></a>
<a id="s10契至汤的先世"></a>

### 从契到汤的世系与迁徙

《殷本纪》合称“八遷”，指从契到汤的几代人的迁徙。篇中“从先王居，作帝诰”也不能用来确定亳的现代位置。振与甲骨所见王亥的对应、先公关系等，详见[《殷本纪》世系考证](../../meta/考证/史记-卷003-纪年与异说.md#genealogy)。个别名字的对应不能证明整条世系的年代。

<a id="s11"></a>
<a id="s11伊尹的两种登场说法与征葛"></a>

### 伊尹如何来到汤身边

《殷本纪》先说伊尹作为有莘氏女的陪嫁之臣来到汤身边，借鼎俎谈滋味和治国；又以“或曰”引出另一说：他原为处士，汤五次遣人聘请，他才出仕。两说各自解释伊尹出仕，无法连成一个确定过程。本篇称阿衡为伊尹之名；其他文献中的“阿衡”要依各篇语境判断。

<a id="s12"></a>
<a id="s12撤去三面不是只开一面"></a>

### 撤掉三面网的说法

《殷本纪》原文“乃去其三面”，明确说撤去三面。这个动作与后来“网开一面”一语的字面意思有别。诸侯听闻称德属于故事的叙述。

<a id="s8"></a>
<a id="s8夏台鸣条与夏亡"></a>

### 《夏本纪》和《殷本纪》的夏商更替

《夏本纪》写桀曾囚禁汤，后来败走鸣条，遭放逐而死；《殷本纪》补有昆吾、有娀之虚、三㚇、宝玉和夏社等情节。约前1600年只用作王朝分界的参考，不是对战役年份的独立测定。桀后悔未在夏台杀汤，是《夏本纪》归给桀的言辞。

<a id="s13"></a>
<a id="s13昆吾有娀鸣条与战后处置"></a>

### 昆吾、鸣条与战后处置

《殷本纪》先写伐昆吾，再写汤伐桀，并叙三㚇和宝玉。三㚇的字义及相关地点的现代位置未定。《汤誓》中的“天命”和“帑僇”分别是出兵的理由和连同家属一起惩罚的威吓；战后段另列《典宝》《夏社》，并写伊尹复命。成汤自号武王，此处称号指汤。

《天官书》[P113](../../sources/摘录/史记-卷027-天官书.md#p113)另列夏代传天数者“昆吾”。[《正义》](../../sources/摘录/史记-卷027-三家注对照.md#p113)以陆终之子、封昆吾的传统解释这个名称。人名、氏名和国名可能同名，不能据此把天数家当成汤征伐昆吾时的同一个人。

<a id="sj005-002-note"></a>
<a id="sj005-002费昌离夏投汤参与鸣条之战"></a>

### 费昌的世系

《秦本纪》称费昌为“其玄孫”，同段又记大廉为鸟俗氏、若木为费氏。这些都是族属和世系的叙述；本段没有为每一世提供可换算的年距。

<a id="sj004-zhou-ancestors"></a>
<a id="卷四补充夏时的另一条族源线不窋到公刘"></a>

### 不窋去职的年代

《周本纪》只说不窋末年“夏后氏政衰”，没有指明夏王。《周本纪》[P026](../../sources/摘录/史记-卷004-周本纪.md#p026)后来在祭公的劝谏中重述这段家世。不窋去职及此后数代的活动不必与鸣条之战放在同一年。

<a id="s9"></a>
<a id="s9后裔夏时与会稽异说"></a>

### 夏后裔、夏时与会稽

《夏本纪》篇末列出夏后、有扈、有男、斟寻、彤城、褒、费、杞、缯、辛、冥、斟戈十二氏，并记孔子正夏时及虞夏贡赋。会稽还有一条以“或言”引出的地名说法：禹在那里会诸侯、计功而死，因而称会稽。这与本纪前文禹东巡至会稽去世的记法并存；贡赋与夏时则是太史公回顾夏代的概括。

<a id="sj025-note"></a>
<a id="卷025南巢之伐与汤灭夏互见"></a>

### 卷025｜南巢之伐与汤灭夏互见

[《律书》P005](../../sources/摘录/史记-卷025-律书.md#p005)以“成湯有南巢之伐，以殄夏亂”作为用兵平乱的例证。《殷本纪》讲鸣条败绩，《律书》另提南巢，单凭这些记载无法为南巢之战另定年份。

三家注《正义》引《淮南子》时连及历山与末喜同舟；[四库本卷025考证](../../meta/%E6%9D%A5%E6%BA%90/%E6%97%A7%E5%BC%95%E6%96%87/%E5%8F%B2%E8%A8%98%E9%9B%86%E8%A7%A3%20%28%E5%8F%B8%E9%A6%AC%E9%81%B7%2C%20%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29-%E5%8D%B7025.md#ref-4a198df24acb85)指出所引《脩务训》只有整兵鸣条、困夏南巢、责过放历山，未见末喜同舟的那一层。[《淮南子·脩务训》原段](../../sources/补充古籍/阅读本/淮南子-脩務訓.md#L38)把鸣条、南巢、历山连起来写。这一传承补充了桀的去向，无法据以确定一条现代行军路线。

[兵论与史例](../../meta/考证/史记-卷025-纪年与异说.md#兵论与史例)。

<a id="sj026-note"></a>

### 卷026｜三正是制度追述，不能据此填满三代历谱

[《历书》P006](../../sources/摘录/史记-卷026-历书.md#p006)以夏正正月、殷正十二月、周正十一月说明三正循环；这里将其作为夏、商、周的历制传统互见，不给夏王朝再补一个确定的改历年月。上述月名是相对于夏正的对照，分别对应建寅、建丑、建子；并非说每个王朝自己总把岁首称为夏历的同号月份。

[商初改正朔](04-商代前期.md#s2)已有原事，商周之际仍见[既有时期页](06-商末与周初.md)。三正的传世整齐框架不等于商周出土历日和置闰实践已经逐项证明，亦不能将周正建子当作整个西周无例外的历日换算公式。见[三正与研究边界](../../meta/考证/史记-卷026-纪年与异说.md#三正)。

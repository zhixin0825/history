# 夏代｜禹、启的传承与汤的兴起

[← 尧舜至禹](02-尧舜至禹.md) · [上古目录](README.md) · [全部时间入口](../README.md) · [继续：商代前期 →](04-商代前期.md)

> **年代范围：采用夏商周断代工程的基本框架，约公元前2070年至前1600年。** 这是一个王朝层级的约略范围，不是禹即位、鸣条之战已经精确到公元某年的结论；不按这个区间给十七王平均分配在位年数。[年代依据与限制](../../meta/考证/上古纪年与断代工程.md)
>
> 本页按《史记》保存的世系和事件先后讲述。禹治水、舜荐禹与交接过程已放在前一页；这里从禹取得帝位接写，不重写一套“夏本纪版治水”。没有足够记事的君主保留在同一张世系表中，不造空年页。

<a id="yu-accession"></a>
## 禹取得帝位，先考虑的继承人却不是启

**禹在舜死后接受诸侯朝见，国号夏后，姓姒。** 他向商均退让而最终继位的过程，见[上一页的同一事件](02-尧舜至禹.md#handoff)。这一步是本篇所写的夏后氏开端；“约前2070年”只给读者一个断代工程中的时代位置，不当成当天发生的精确日期。[看登位原文](#s1)

禹取得帝位后先推荐皋陶，并打算把政事交给他；皋陶却先去世。禹于是封其后人于英、六等地，另推荐益，让益参与政事。这样，后来的父子相继，不能倒过来写成“禹从一开始就宣布传子”。[看皋陶与益](#s2)

<a id="qi-accession"></a>
## 禹死以后，诸侯转向启

**禹东巡到会稽去世，随后发生的是益与启之间的交接。** 故事先写禹把天下交给益；三年之丧结束以后，益让位给禹之子启，退居箕山之阳。诸侯离开益而朝见启，启最终继位。[看交接原文](#s3)

原文给出的解释有两层：一是启受到拥戴，二是益辅助禹的时间较短，尚未得到广泛认可。诸侯又以“我们君主禹的儿子”称启，父子关系在这次交接中成为明说的理由。这里叙述《史记》的版本；《晋书》保存的古本《竹书纪年》佚文却说益与启争位、启杀益，两种传统不能拼成一次已经证实的和平交接。[看版本分歧](#s3)

<a id="gan"></a>
## 启打败有扈氏，要求军中各司其职

**启的继位并没有让所有人马上服从，有扈氏拒绝归服。** 启出兵，在甘与有扈氏作战，战前向六卿申说誓令，宣称出兵是执行天罚。[看甘之战](#s4)

誓令接着落到战车上的具体职责：在左方的人要尽左方的责任，在右方的人要尽右方的责任，御者必须把马驾驭好。服从命令者在祖先之前受赏，不服从者在社受到惩罚，惩罚还涉及家属。最后，启取胜，有扈氏被灭。[看《甘誓》的内容](#s4)

<a id="taikang"></a>
## 太康失国，中康时又有羲和失职

**启以后，由儿子太康继位，但太康失去了国。** 五个兄弟在洛水汇入处等待，作《五子之歌》。本篇在这里写得很短，没有交代失国的整个军事过程。[看太康段](#s5)

太康死后，由弟弟中康接位。中康在位时，羲、和因沉湎失职，破坏了按时办理的历日事务，胤前往征讨，留下《胤征》的名称。这两句话没有直接提供一场能唯一换算成年月日的日食观测。[看中康段](#s5)

<a id="succession"></a>

**这一段不能写成连续的战争故事，因为本篇提供的主要是王位怎样传下去。** 它有父子相继，也有兄终弟及和转回另一支；资料少的王照样保留，但不补造政绩、寿命与在位年份。[看完整世系原文](#s6)

**卷十三《三代世表》也完整排出上述夏王十七名，并特别注明中康是太康之弟、扃是不降之弟、孔甲出自不降一支。** 卷十三又记“从禹至桀十七世、从黄帝至桀二十世”；这些是传世计算法，不能因为数字整齐就变成已核实的十七段在位年代。尤其禹的父亲鲧，表文把父系接在颛顼之后，三家注却引《汉书·律历志》说相隔数代；此处仍只记两种材料，不虚构中间姓名。[原表摘录](../../sources/摘录/史记-卷013-三代世表.md#t002) · [差异考证](../../meta/考证/史记-卷013-纪年与异说.md#异文与世数)

这里的十七人是本篇列出的王序，不等于每一代都是父子，也不等于掌握了十七个精确的公元在位区间。少康在《夏本纪》中只有继承短记；后羿、寒浞与少康复夏的详细传统，须结合《左传》的追述来读。[看王序与补充来源](#s6)

<a id="shaokang"></a>
## 后羿、寒浞与少康复夏，是另一组文献保存的前史

**《左传》保存了夏政失落而后恢复的故事。** 襄公四年，魏绛劝晋悼公不要沉迷田猎时，讲到有穷后羿依靠夏民取代夏政，却荒废民事，信用寒浞。寒浞在内外培植势力，后羿最终被家众杀死；原来随羿的靡逃到有鬲氏。寒浞让儿子浇攻灭斟灌、斟寻，把浇、豷分别安置在过、戈。[魏绛所引原文](../bce-0600-0501/bce-0569.md#note-11)

**哀公元年，伍员劝吴王不要留下越国后患，又讲到少康如何保全并聚众。** 浇灭夏后相时，相的妻子已怀孕，逃回有仍，生下少康。少康先在有仍任牧正，受到追索后逃到有虞任庖正；虞思将两名姚姓女子嫁给他，并给他纶地。少康由此收聚夏众、恢复旧官职，又使女艾侦察浇、季杼对付豷。[伍员所引原文](../bce-0500-0401/bce-0494.md#note-3)

**复夏并非一人完成。** 魏绛所引叙事把灭寒浞归于靡，并说靡拥立少康；少康灭浇于过，后杼灭豷于戈。这里保留不同人物的行动，不把三次胜利都改成少康一人亲手完成。两段《左传》都是春秋人物援引的上古故事，用来说明当时的政治选择；它们补足夏代传统，却不能提供已经验证的夏代战役年份，也不使有穷后羿自动等同于射日神话中的羿。[材料性质与归属](#s6)

<a id="kongjia"></a>
## 孔甲的故事，把诸侯离心与养龙传说放在一起

**到孔甲时，叙事开始重新展开。** 孔甲被写为沉迷鬼神、行为失序，诸侯逐渐离开夏后氏。接着出现一则养龙故事：天降雌雄二龙，孔甲不会饲养；陶唐氏后人刘累学过驯龙，于是前来服事，得到御龙氏之号。[看孔甲与刘累](#s7)

雌龙死后，刘累把它做成食物献给夏王。夏王再求龙，刘累害怕追究，便迁走。此处的龙和驯养情节保留为古书传说，不改说成现代某一种已经确定的动物；从养龙故事本身也推不出孔甲的在位年代。[看原文](#s7)

<a id="tang-background"></a>
## 汤登场以前，商的先祖已经传了许多代

**成汤名天乙，是主癸的儿子；其先世被追溯到佐禹治水、任司徒的契。** 契的出身和任职已在[尧舜时期的首次登场处](02-尧舜至禹.md#xie)补叙。到汤这一代，商这一支不再只是夏王朝之下的一方势力，而逐渐成为挑战夏王的人。[原文与说明](#s10)

本纪保留的次序是：**契—昭明—相土—昌若—曹圉—冥—振—微—报丁—报乙—报丙—主壬—主癸—天乙（成汤）**。多数名字在本卷只有世系关系，没有足够事迹可独立成篇；它们共同保存在这里，不给每代平均分年，也不把所有对应关系都说成已由甲骨逐字证实。[原文与说明](#s10)

从契到汤，居处曾多次变动。本纪总称八迁，到汤时居亳，援引先王旧居，并留下《帝诰》的篇名。八迁跨越多个世代，不是说汤一人搬了八次，也不凭“亳”字就指定一座已经核定的现代遗址。[原文与说明](#s10)

<a id="yiyin"></a>
## 伊尹来到汤身边，征伐诸侯之前先谈怎样治理

**伊尹怎样接近汤，本纪自己就保留了两种说法。** 一说他随有莘氏女子出嫁而来，携鼎俎，以烹调滋味说到治国；另一说他原是处士，汤反复遣人聘请，五次往返后他才答应。两种叙述都把他引到辅佐国政的位置，但不能无依据地串成先后都发生的一套故事。[原文与说明](#s11)

伊尹曾离汤到夏，后来不满夏政，又返回亳。汤开始征诸侯，以葛伯不祭祀为理由先攻葛。汤与伊尹的谈话则把治理的成效同百姓处境相联系：如同照水看形貌，也要看民众的生活，才知道国家治得怎样。[原文与说明](#s11)

<a id="tang-net"></a>
## 汤让捕猎的人撤去三面网

**有一次，汤看见人在野外四面张网，祈求四方禽兽全落入网中。** 他认为这样会捕尽，便撤去三面，让想往左、往右的禽兽都能离开。诸侯听说后，以他连禽兽都肯留生路来赞扬他。[原文与说明](#s12)

这个故事放在开战以前，解释叙事中的诸侯归向；不把它当成已有现场记录、且直接决定每一个诸侯选择的证据。[原文与说明](#s12)

<a id="fall"></a>
## 桀囚禁过汤，却没有阻止汤取代夏

**孔甲以后，王位经过皋、发，传给履癸，也就是桀。** 本篇把夏后氏的离心问题追溯到孔甲，不将全部衰落都压在桀一人登位的一刻。桀又以武力伤害民众，诸侯与民众进一步转向汤。[看夏末叙事](#s8)

桀曾把汤召来，囚禁在夏台，后来又放走。汤取得诸侯归附，率军先攻昆吾，再攻桀，伊尹也随军。誓辞里并不只有慷慨赴战：民众还抱怨君主不顾大家，放下农事而兴师；汤一面以夏罪与天命解释征伐，一面许赏并以惩罚约束不听命者。[看夏台与誓师](#s8)[看卷三补充](#s13)

战事从有娀之虚写到鸣条，夏军败退。桀最终被放逐而死；汤又攻三㚇，取得宝玉。随后他想迁动夏社却未能如愿，最后接受诸侯归附，取得天子之位。这里把两卷互见合成同一场夏商更替，不能因为《夏本纪》《殷本纪》分别记了一遍，就出现两次汤灭夏。[看共同结局](#s8)[看卷三的地点与次序](#s13)

开战时汤自号武王，指的是成汤本人，不是数百年后的周武王。取得天下后的诰命与治理，继续见[商代前期](04-商代前期.md#tang-government)。[原文与说明](#s13)

<a id="feichang"></a>
## 费昌离夏投汤，参与鸣条之战

大费之后分出大廉、若木等支系。到夏末，费昌离开夏桀而归附汤，在汤的战车上担任御者，随军参与击败桀的战争。这项人物补充并入夏商更替，不另写第二次鸣条之战。 [原文与说明](#sj005-002-note)


<a id="zhou-ancestors"></a>
## 夏时的另一条族源线：不窋到公刘

**在夏后氏之外，周人的先世也以世代延续的农事来解释自己的来历。** 弃之后是不窋；夏政衰落、不再重视稷官时，不窋失去职守，退处戎狄之间。接着传给鞠，再传给公刘。这里的长时间跨度不能仅按“父子”两字平均折算成年份。

公刘重新经营耕种，察看土地，足迹涉及漆、沮、渭水一带；他让人取得木材和其他物资，安排迁居与生产，聚集起更多归附者。其子庆节在豳立居。后面的祖先世系和古公迁岐，见[商末另一支力量的兴起](06-商末与周初.md#zhou-family)。 [原文与说明](#sj004-zhou-ancestors)

<a id="after"></a>
## 夏以后，夏人的后裔与记忆仍被保存

**更替不等于原来的人和祭祀都从历史中消失。** 本篇说汤封存夏的后人，又把视野带到周时封于杞。这是追述后世，不把周代封杞放入“夏亡当年”。[看后裔记载](#s9)

篇末还列出姒姓分支与夏时传统，并保存“禹在江南会诸侯、计算功绩，因而称会稽”的另一说。世系、历法传统、贡赋评论和地名解释都归在下面的史料说明，不为它们捏造一组夏代事件日期。[看太史公论](#s9)

## 原文与出处

以下P编号对应[卷002整卷引文去向](../../meta/记录/史记-卷002-引文去向.md)。直接采用已读的[维基文库《夏本纪》](https://zh.wikisource.org/wiki/史記/卷002)本纪文字；[仓库TXT](../../sources/二十四史/txt/01_shiji_full.txt)继续原样保存。现代网页校勘记是另一个文本层，不冒称已与中华书局扫描页逐字校毕。

<a id="s1"></a>
### S1｜夏后氏开端与约略年代

P026：“禹於是遂即天子位，南面朝天下，國號曰夏后，姓姒氏。”这一句本身没有公元年。约前2070—前1600年的框架见袁靖《深入推进多学科合作的考古学研究》（2022-11-10）对断代工程成果的说明；它明确区分夏的基本框架、商前期框架和较晚王年：[原文](https://www.cppcc.gov.cn/zxww/2022/11/10/ARTI1668053116436252.shtml)。不据该框架反推五帝起讫年。

<a id="s2"></a>
### S2｜推荐皋陶，再推荐益

P027：“帝禹立而舉皋陶薦之，且授政焉，而皋陶卒”“封皋陶之後於英、六，或在許”“而后舉益，任之政”。“或在许”在原文中已经保留差别，不把三个地方无条件并成一次确定分封。

<a id="s3"></a>
### S3｜禹死与益启交接

P028：“十年，帝禹東巡狩，至于會稽而崩”“三年之喪畢，益讓帝禹之子啓”“故諸侯皆去益而朝啓”。公开正文作“十年”，网页校勘另有讨论；本轮不以这一个有校勘问题的数字推出禹的确切在位长度。P029再次介绍启为禹与涂山氏女之子，合并到同一人物入口。

[《晋书·束皙传》](https://zh.wikisource.org/wiki/晉書/卷051)介绍汲冢所出《纪年》时，明列“益幹啟位，啟殺之”，并指出它与经传不同。这是后书保存的古本佚文，不能据此保证今本《竹书纪年》的全部文字可靠；也不能把它与本纪的益让启位叙述拼成先禅让、后战争的确定年表。两种传统均不为本页提供可独立换算的公元年。

<a id="s4"></a>
### S4｜甘之战与誓令

P030：“有扈氏不服，啓伐之，大戰於甘”“用命，賞于祖；不用命，僇于社，予則帑僇女”。天罚、五行、三正是誓辞中的出兵理由；白话转述不替它确认天意。原文列战车左右与御者职责，不在没有具体史料时补兵力、车型或战场坐标。

<a id="s5"></a>
### S5｜太康与中康的短记

P031：“帝太康失國，昆弟五人，須于洛汭，作五子之歌。”P032：“羲、和湎淫，廢時亂日。胤往征之，作胤征。”《夏本纪》此处只提作品与事由，没有提供本页可以使用的完整日食观测记录。不用网上一张夏王年表代替该段所缺的年代证明。

<a id="s6"></a>
### S6｜王序不是绝对年表

P033从“中康崩，子帝相立”接写至孔甲，P034再写皋、发、履癸。前面的禹、启、太康、中康与之合成十七王顺序。原文“予”与其他材料的对应需另校；本轮不在改变字形后再声称完全照录。

《夏本纪》没有展开后羿、寒浞与少康复夏；本页另据已入库的[《左传·襄公四年》T010](../../sources/春秋左传/有标点原文/bce-0569.md#t010)和[《左传·哀公元年》伍员谏吴段](../bce-0500-0401/bce-0494.md#note-3)补述。襄公四年分别记靡灭浞、少康灭浇、后杼灭豷；哀公元年补述后相之妻逃亡、少康聚众及女艾与季杼的行动。故事的发生时代放在夏代，前569、前494年仍只记当年的引述与劝谏，不给古事强配两次春秋日期。“二姚”按两名姚姓女子理解；原文也没有把女艾的性别、六年复国战或寒浞受凌迟写成可据的细节。

<a id="s7"></a>
### S7｜御龙氏故事

P033：“天降龍二，有雌雄”“劉累，學擾龍于豢龍氏”“龍一雌死，以食夏后”。该段还记刘累受豕韦之后；这是其受封／族属解释的一部分，不据此补一场本篇没有写的战争。

<a id="s8"></a>
### S8｜夏台、鸣条与夏亡

P034：“迺召湯而囚之夏臺，已而釋之”“桀走鳴條，遂放而死”“湯乃踐天子位，代夏朝天下”。篇中还把后悔未杀汤的话归于桀；这是所传言辞，不是可独立验证的心理记录。约前1600年作为夏商分界参考，不将它进一步细化为战役的确月确日。

<a id="s9"></a>
### S9｜后裔、夏时与会稽异说

P034末记“湯封夏之後，至周封於杞也”。P035列夏后、有扈、有男、斟寻、彤城、褒、费、杞、缯、辛、冥、斟戈十二氏，并说孔子正夏时、学者传《夏小正》，以及虞夏贡赋的评论。以上是太史公对后世传承的总括，不逐条伪造为夏初行政记录。对会稽，原文用“或言”引出会诸侯、计功而死的解释；与正文东巡而死的表述一并保留。

<a id="s10"></a>
### S10｜契至汤的先世

[卷003 P002—P003](../../sources/摘录/史记-卷003-殷本纪.md#p002)按所读文本列出世系与八迁。振与甲骨所见王亥的对应、先公关系等，须看具体考证，不能由一项对应成立推出全链已逐一确证。本轮保留原名，相关研究边界见[卷003考证](../../meta/考证/史记-卷003-纪年与异说.md#genealogy)。

<a id="s11"></a>
### S11｜伊尹的两种登场说法与征葛

[卷003 P004—P005](../../sources/摘录/史记-卷003-殷本纪.md#p004)。本纪以“或曰”明确给出异说；媵臣与受聘处士不被拼成确定的先后。《汤征》《女鸠女房》等篇名及伊尹在北门遇女鸠、女房的短记全部保存在原文。P005称阿衡为伊尹之名，本页不据这一句断定所有文献中阿衡都只能是人名。

<a id="s12"></a>
### S12｜撤去三面，不是只开一面

[卷003 P006](../../sources/摘录/史记-卷003-殷本纪.md#p006)作“乃去其三面”。本页保留其动作，不拿后来常说的“网开一面”反过来改成留下三面网；诸侯称德是故事中的反应，不另造一项已有年月的狩猎法令。

<a id="s13"></a>
### S13｜昆吾、有娀、鸣条与战后处置

[卷003 P007—P008](../../sources/摘录/史记-卷003-殷本纪.md#p007)先写伐昆吾、遂伐桀，再写有娀之虚、鸣条、三㚇与宝玉。三㚇的难字、诸地的位置未在本轮独立考定；不给读者一条假装精确的现代行军路线。《典宝》《夏社》及伊尹复命的短记，与战后处置一并有出处。誓辞称天罚及惩及家属，属于出兵动员中的言辞，不替它确认天意。

<a id="sj004-zhou-ancestors"></a>
### 卷四补充｜夏时的另一条族源线：不窋到公刘

[卷004 P003](../../sources/摘录/史记-卷004-周本纪.md#p003)。 P003以“夏后氏政衰”交代不窋去职，但没有给夏王名。本条作为与夏王序并行的族源传统，不宣布不窋去职、鞠、公刘、庆节全发生在夏亡当年。P026后来在祭公说辞中重述这一传统，不再重复造事件。

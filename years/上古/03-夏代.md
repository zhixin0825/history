# 夏代｜禹、启的传承与汤的兴起

[← 尧舜至禹](02-尧舜至禹.md) · [上古目录](README.md) · [全部时间入口](../README.md) · [继续：商代前期 →](04-商代前期.md)

> **年代范围：采用夏商周断代工程的基本框架，约公元前2070年至前1600年。** 这是一个王朝层级的约略范围，不是禹即位、鸣条之战已经精确到公元某年的结论；不按这个区间给十七王平均分配在位年数。[年代依据与限制](../../meta/考证/上古纪年与断代工程.md)
>
> 本页按《史记》保存的世系和事件先后讲述。禹治水、舜荐禹与交接过程已放在前一页；这里从禹取得帝位接写，不重写一套“夏本纪版治水”。没有足够记事的君主保留在同一张世系表中，不造空年页。

<a id="yu-accession"></a>
<a id="禹取得帝位先考虑的继承人却不是启"></a>

<a id="event-1"></a>

1. **禹取得帝位，先考虑的继承人却不是启。** **禹在舜死后接受诸侯朝见，国号夏后，姓姒。** 他向商均退让而最终继位的过程，见[上一页的同一事件](02-尧舜至禹.md#handoff)。这一步是本篇所写的夏后氏开端；“约前2070年”只给读者一个断代工程中的时代位置，不当成当天发生的精确日期。 [[1]](#note-1)

   禹取得帝位后先推荐皋陶，并打算把政事交给他；皋陶却先去世。禹于是封其后人于英、六等地，另推荐益，让益参与政事。这样，后来的父子相继，不能倒过来写成“禹从一开始就宣布传子”。

<a id="qi-accession"></a>
<a id="禹死以后诸侯转向启"></a>

<a id="event-2"></a>

2. **禹死以后，诸侯转向启。** **禹东巡到会稽去世，随后发生的是益与启之间的交接。** 故事先写禹把天下交给益；三年之丧结束以后，益让位给禹之子启，退居箕山之阳。诸侯离开益而朝见启，启最终继位。 [[2]](#note-2)

   原文给出的解释有两层：一是启受到拥戴，二是益辅助禹的时间较短，尚未得到广泛认可。诸侯又以“我们君主禹的儿子”称启，父子关系在这次交接中成为明说的理由。这里叙述《史记》的版本；《晋书》保存的古本《竹书纪年》佚文却说益与启争位、启杀益，两种传统不能拼成一次已经证实的和平交接。

<a id="gan"></a>
<a id="启打败有扈氏要求军中各司其职"></a>

<a id="event-3"></a>

3. **启打败有扈氏，要求军中各司其职。** **启的继位并没有让所有人马上服从，有扈氏拒绝归服。** 启出兵，在甘与有扈氏作战，战前向六卿申说誓令，宣称出兵是执行天罚。 [[3]](#note-3)

   誓令接着落到战车上的具体职责：在左方的人要尽左方的责任，在右方的人要尽右方的责任，御者必须把马驾驭好。服从命令者在祖先之前受赏，不服从者在社受到惩罚，惩罚还涉及家属。最后，启取胜，有扈氏被灭。

<a id="taikang"></a>
<a id="太康失国中康时又有羲和失职"></a>

<a id="event-4"></a>

4. **太康失国，中康时又有羲和失职。** **启以后，由儿子太康继位，但太康失去了国。** 五个兄弟在洛水汇入处等待，作《五子之歌》。本篇在这里写得很短，没有交代失国的整个军事过程。 [[4]](#note-4)

   太康死后，由弟弟中康接位。中康在位时，羲、和因沉湎失职，破坏了按时办理的历日事务，胤前往征讨，留下《胤征》的名称。这两句话没有直接提供一场能唯一换算成年月日的日食观测。

<a id="succession"></a>
<a id="从相到孔甲多数只有继承关系没有完整的事迹年表"></a>

<a id="event-5"></a>

5. **从相到孔甲，多数只有继承关系，没有完整的事迹年表。** **这一段不能写成连续的战争故事，因为本篇提供的主要是王位怎样传下去。** 它有父子相继，也有兄终弟及和转回另一支；资料少的王照样保留，但不补造政绩、寿命与在位年份。 [[5]](#note-5)

   **卷十三《三代世表》也完整排出上述夏王十七名，并特别注明中康是太康之弟、扃是不降之弟、孔甲出自不降一支。** 卷十三又记“从禹至桀十七世、从黄帝至桀二十世”；这些是传世计算法，不能因为数字整齐就变成已核实的十七段在位年代。尤其禹的父亲鲧，表文把父系接在颛顼之后，三家注却引《汉书·律历志》说相隔数代；此处仍只记两种材料，不虚构中间姓名。[原表摘录](../../sources/摘录/史记-卷013-三代世表.md#t002) · [差异考证](../../meta/考证/史记-卷013-纪年与异说.md#异文与世数)

   这里的十七人是本篇列出的王序，不等于每一代都是父子，也不等于掌握了十七个精确的公元在位区间。少康在《夏本纪》中只有继承短记；后羿、寒浞与少康复夏的详细传统，须结合《左传》的追述来读。

<a id="shaokang"></a>
<a id="后羿寒浞与少康复夏是另一组文献保存的前史"></a>

<a id="event-6"></a>

6. **后羿、寒浞与少康复夏，是另一组文献保存的前史。** **《左传》保存了夏政失落而后恢复的故事。** 襄公四年，魏绛劝晋悼公不要沉迷田猎时，讲到有穷后羿依靠夏民取代夏政，却荒废民事，信用寒浞。寒浞在内外培植势力，后羿最终被家众杀死；原来随羿的靡逃到有鬲氏。寒浞让儿子浇攻灭斟灌、斟寻，把浇、豷分别安置在过、戈。[魏绛所引原文](../bce-0600-0501/bce-0569.md#note-11) [[6]](#note-6)

   **哀公元年，伍员劝吴王不要留下越国后患，又讲到少康如何保全并聚众。** 浇灭夏后相时，相的妻子已怀孕，逃回有仍，生下少康。少康先在有仍任牧正，受到追索后逃到有虞任庖正；虞思将两名姚姓女子嫁给他，并给他纶地。少康由此收聚夏众、恢复旧官职，又使女艾侦察浇、季杼对付豷。[伍员所引原文](../bce-0500-0401/bce-0494.md#note-3)

   **复夏并非一人完成。** 魏绛所引叙事把灭寒浞归于靡，并说靡拥立少康；少康灭浇于过，后杼灭豷于戈。这里保留不同人物的行动，不把三次胜利都改成少康一人亲手完成。两段《左传》都是春秋人物援引的上古故事，用来说明当时的政治选择；它们补足夏代传统，却不能提供已经验证的夏代战役年份，也不使有穷后羿自动等同于射日神话中的羿。

<a id="kongjia"></a>
<a id="孔甲的故事把诸侯离心与养龙传说放在一起"></a>

<a id="event-7"></a>

7. **孔甲的故事，把诸侯离心与养龙传说放在一起。** **到孔甲时，叙事开始重新展开。** 孔甲被写为沉迷鬼神、行为失序，诸侯逐渐离开夏后氏。接着出现一则养龙故事：天降雌雄二龙，孔甲不会饲养；陶唐氏后人刘累学过驯龙，于是前来服事，得到御龙氏之号。 [[7]](#note-7)

   雌龙死后，刘累把它做成食物献给夏王。夏王再求龙，刘累害怕追究，便迁走。此处的龙和驯养情节保留为古书传说，不改说成现代某一种已经确定的动物；从养龙故事本身也推不出孔甲的在位年代。

<a id="tang-background"></a>
<a id="汤登场以前商的先祖已经传了许多代"></a>

<a id="event-8"></a>

8. **汤登场以前，商的先祖已经传了许多代。** **成汤名天乙，是主癸的儿子；其先世被追溯到佐禹治水、任司徒的契。** 契的出身和任职已在[尧舜时期的首次登场处](02-尧舜至禹.md#xie)补叙。到汤这一代，商这一支不再只是夏王朝之下的一方势力，而逐渐成为挑战夏王的人。 [[8]](#note-8)

   本纪保留的次序是：**契—昭明—相土—昌若—曹圉—冥—振—微—报丁—报乙—报丙—主壬—主癸—天乙（成汤）**。多数名字在本卷只有世系关系，没有足够事迹可独立成篇；它们共同保存在这里，不给每代平均分年，也不把所有对应关系都说成已由甲骨逐字证实。

   从契到汤，居处曾多次变动。本纪总称八迁，到汤时居亳，援引先王旧居，并留下《帝诰》的篇名。八迁跨越多个世代，不是说汤一人搬了八次，也不凭“亳”字就指定一座已经核定的现代遗址。

<a id="yiyin"></a>
<a id="伊尹来到汤身边征伐诸侯之前先谈怎样治理"></a>

<a id="event-9"></a>

9. **伊尹来到汤身边，征伐诸侯之前先谈怎样治理。** **伊尹怎样接近汤，本纪自己就保留了两种说法。** 一说他随有莘氏女子出嫁而来，携鼎俎，以烹调滋味说到治国；另一说他原是处士，汤反复遣人聘请，五次往返后他才答应。两种叙述都把他引到辅佐国政的位置，但不能无依据地串成先后都发生的一套故事。 [[9]](#note-9)

   伊尹曾离汤到夏，后来不满夏政，又返回亳。汤开始征诸侯，以葛伯不祭祀为理由先攻葛。汤与伊尹的谈话则把治理的成效同百姓处境相联系：如同照水看形貌，也要看民众的生活，才知道国家治得怎样。

<a id="tang-net"></a>
<a id="汤让捕猎的人撤去三面网"></a>

<a id="event-10"></a>

10. **汤让捕猎的人撤去三面网。** **有一次，汤看见人在野外四面张网，祈求四方禽兽全落入网中。** 他认为这样会捕尽，便撤去三面，让想往左、往右的禽兽都能离开。诸侯听说后，以他连禽兽都肯留生路来赞扬他。 [[10]](#note-10)

    这个故事放在开战以前，解释叙事中的诸侯归向；不把它当成已有现场记录、且直接决定每一个诸侯选择的证据。

<a id="fall"></a>
<a id="桀囚禁过汤却没有阻止汤取代夏"></a>

<a id="event-11"></a>

11. **桀囚禁过汤，却没有阻止汤取代夏。** **孔甲以后，王位经过皋、发，传给履癸，也就是桀。** 本篇把夏后氏的离心问题追溯到孔甲，不将全部衰落都压在桀一人登位的一刻。桀又以武力伤害民众，诸侯与民众进一步转向汤。 [[11]](#note-11)

    桀曾把汤召来，囚禁在夏台，后来又放走。汤取得诸侯归附，率军先攻昆吾，再攻桀，伊尹也随军。誓辞里并不只有慷慨赴战：民众还抱怨君主不顾大家，放下农事而兴师；汤一面以夏罪与天命解释征伐，一面许赏并以惩罚约束不听命者。

    战事从有娀之虚写到鸣条，夏军败退。桀最终被放逐而死；汤又攻三㚇，取得宝玉。随后他想迁动夏社却未能如愿，最后接受诸侯归附，取得天子之位。这里把两卷互见合成同一场夏商更替，不能因为《夏本纪》《殷本纪》分别记了一遍，就出现两次汤灭夏。

    开战时汤自号武王，指的是成汤本人，不是数百年后的周武王。取得天下后的诰命与治理，继续见[商代前期](04-商代前期.md#tang-government)。

<a id="feichang"></a>
<a id="费昌离夏投汤参与鸣条之战"></a>

<a id="event-12"></a>

12. **费昌离夏投汤，参与鸣条之战。** 大费之后分出大廉、若木等支系。到夏末，费昌离开夏桀而归附汤，在汤的战车上担任御者，随军参与击败桀的战争。这项人物补充并入夏商更替，不另写第二次鸣条之战。 [[12]](#note-12)

<a id="zhou-ancestors"></a>
<a id="夏时的另一条族源线不窋到公刘"></a>

<a id="event-13"></a>

13. **夏时的另一条族源线：不窋到公刘。** **在夏后氏之外，周人的先世也以世代延续的农事来解释自己的来历。** 弃之后是不窋；夏政衰落、不再重视稷官时，不窋失去职守，退处戎狄之间。接着传给鞠，再传给公刘。这里的长时间跨度不能仅按“父子”两字平均折算成年份。 [[13]](#note-13)

    公刘重新经营耕种，察看土地，足迹涉及漆、沮、渭水一带；他让人取得木材和其他物资，安排迁居与生产，聚集起更多归附者。其子庆节在豳立居。后面的祖先世系和古公迁岐，见[商末另一支力量的兴起](06-商末与周初.md#zhou-family)。

<a id="after"></a>
<a id="夏以后夏人的后裔与记忆仍被保存"></a>

<a id="event-14"></a>

14. **夏以后，夏人的后裔与记忆仍被保存。** **更替不等于原来的人和祭祀都从历史中消失。** 本篇说汤封存夏的后人，又把视野带到周时封于杞。这是追述后世，不把周代封杞放入“夏亡当年”。 [[14]](#note-14)

    篇末还列出姒姓分支与夏时传统，并保存“禹在江南会诸侯、计算功绩，因而称会稽”的另一说。世系、历法传统、贡赋评论和地名解释都归在下面的史料说明，不为它们捏造一组夏代事件日期。

### 1. 禹取得帝位，先考虑的继承人却不是启

[返回正文第1条](#event-1)

**[《史記》卷002 · L66、L67](../../sources/本地分卷/史记/史记-卷002.md#L66)**

> 帝舜薦禹於天，爲嗣。十七年而帝舜崩。三年喪畢，禹辭辟舜之子商均於陽城。天下諸侯皆去商均而朝禹。禹於是遂即天子位，南面朝天下，國號曰夏后，姓姒氏。
>
> 帝禹立而舉皋陶薦之，且授政焉，而皋陶卒。封皋陶之後於英、六，或在許。而后舉益，任之政。

<a id="s1"></a>
<a id="s1夏后氏开端与约略年代"></a>

**S1｜夏后氏开端与约略年代**

P026：“禹於是遂即天子位，南面朝天下，國號曰夏后，姓姒氏。”这一句本身没有公元年。约前2070—前1600年的框架见袁靖《深入推进多学科合作的考古学研究》（2022-11-10）对断代工程成果的说明；它明确区分夏的基本框架、商前期框架和较晚王年：[袁靖的年代说明](../../sources/补充阅读/开放参考/ref-f76a794228f47bf6.md#checked)。不据该框架反推五帝起讫年。

<a id="s2"></a>
<a id="s2推荐皋陶再推荐益"></a>

**S2｜推荐皋陶，再推荐益**

P027：“帝禹立而舉皋陶薦之，且授政焉，而皋陶卒”“封皋陶之後於英、六，或在許”“而后舉益，任之政”。“或在许”在原文中已经保留差别，不把三个地方无条件并成一次确定分封。

<a id="note-2"></a>

### 2. 禹死以后，诸侯转向启

[返回正文第2条](#event-2)

**[《史記》卷002 · L68、L70](../../sources/本地分卷/史记/史记-卷002.md#L68)**

> 十年，帝禹東巡狩，至于會稽而崩。以天下授益。三年之喪畢，益讓帝禹之子啓，而辟居箕山之陽。禹子啓賢，天下屬意焉。及禹崩，雖授益，益之佐禹日淺，天下未洽。故諸侯皆去益而朝啓，曰「吾君帝禹之子也」。於是啓遂即天子之位，是爲夏后帝啓。
>
> 夏后帝啓，禹之子，其母塗山氏之女也。

<a id="s3"></a>
<a id="s3禹死与益启交接"></a>

**S3｜禹死与益启交接**

> 當是時，夏桀為虐政淫荒，而諸侯昆吾氏為亂。湯乃興師率諸侯，伊尹從湯，湯自把鉞以伐昆吾，遂伐桀。湯曰：「格女眾庶，來，女悉聽朕言。匪台小子，敢行舉亂，有夏多罪，予維聞女眾言，夏氏有罪。予畏上帝，不敢不正。今夏多罪，天命殛之。今女有眾，女曰：『我君不恤我眾，舍我嗇事而割政』。女其曰：『有罪，其柰何』？夏王率止眾力，率奪夏國。有眾率怠不和，曰：『是日何時喪？予與女皆亡』！夏德若茲，今朕必往。爾尚及予一人致天之罰，予其大理女。女毋不信，朕不食言。女不從誓言，予則帑僇女，無有攸赦。」以告令師，作湯誓。於是湯曰：「吾甚武」，號曰武王。

**[P113](../../sources/摘录/史记-卷027-天官书.md#p113)**

> 昔之傳天數者：高辛之前，重、黎；於唐、虞，羲、和；有夏，昆吾；殷商，巫咸；周室，史佚、萇弘；於宋，子韋；鄭則裨灶；在齊，甘公；楚，唐眛；趙，尹皋；魏，石申。

<a id="s8"></a>
<a id="s8夏台鸣条与夏亡"></a>

**S8｜夏台、鸣条与夏亡**

P034：“迺召湯而囚之夏臺，已而釋之”“桀走鳴條，遂放而死”“湯乃踐天子位，代夏朝天下”。篇中还把后悔未杀汤的话归于桀；这是所传言辞，不是可独立验证的心理记录。约前1600年作为夏商分界参考，不将它进一步细化为战役的确月确日。

<a id="s13"></a>
<a id="s13昆吾有娀鸣条与战后处置"></a>

**S13｜昆吾、有娀、鸣条与战后处置**

[卷003 P007—P008](../../sources/摘录/史记-卷003-殷本纪.md#p007)先写伐昆吾、遂伐桀，再写有娀之虚、鸣条、三㚇与宝玉。三㚇的难字、诸地的位置未在本轮独立考定；不给读者一条假装精确的现代行军路线。《典宝》《夏社》及伊尹复命的短记，与战后处置一并有出处。誓辞称天罚及惩及家属，属于出兵动员中的言辞，不替它确认天意。

《天官书》[P113](../../sources/摘录/史记-卷027-天官书.md#p113)另列夏代天数家“昆吾”。[《正义》](../../sources/摘录/史记-卷027-三家注对照.md#p113)以陆终之子、封昆吾的传统解释；本页汤伐昆吾则是夏商更替故事。人物、氏族与方国的同名须分别辨认，不据两句同名文字便给一位天数家确定卒于汤伐昆吾之年。

> 大費生子二人：一曰大廉，實鳥俗氏；二曰若木，實費氏。其玄孫曰費昌，子孫或在中國，或在夷狄。費昌當夏桀之時，去夏歸商，為湯御，以敗桀於鳴條。大廉玄孫曰孟戲、中衍，鳥身人言。帝太戊聞而卜之使御，吉，遂致使御而妻之。自太戊以下，中衍之後，遂世有功，以佐殷國，故嬴姓多顯，遂為諸侯。

<a id="note-13"></a>

### 13. 夏时的另一条族源线：不窋到公刘

[返回正文第13条](#event-13)

**[卷004 P003](../../sources/摘录/史记-卷004-周本纪.md#p003)**

> 后稷卒，子不窋立。不窋末年，夏后氏政衰，去稷不務，不窋以失其官而犇戎狄之間。不窋卒，子鞠立。鞠卒，子公劉立。公劉雖在戎狄之間，復修后稷之業，務耕種，行地宜，自漆、沮度渭，取材用，行者有資，居者有畜積，民賴其慶。百姓懷之，多徙而保歸焉。周道之興自此始，故詩人歌樂思其德。公劉卒，子慶節立，國於豳。

<a id="sj004-zhou-ancestors"></a>
<a id="卷四补充夏时的另一条族源线不窋到公刘"></a>

**卷四补充｜夏时的另一条族源线：不窋到公刘**

[卷004 P003](../../sources/摘录/史记-卷004-周本纪.md#p003)。 P003以“夏后氏政衰”交代不窋去职，但没有给夏王名。本条作为与夏王序并行的族源传统，不宣布不窋去职、鞠、公刘、庆节全发生在夏亡当年。P026后来在祭公说辞中重述这一传统，不再重复造事件。

### 14. 夏以后，夏人的后裔与记忆仍被保存

[返回正文第14条](#event-14)

**[《史記》卷002 · L76、L77](../../sources/本地分卷/史记/史记-卷002.md#L76)**

> 太史公論
>
> 太史公曰：禹爲姒姓，其後分封，用國爲姓，故有夏后氏、有扈氏、有男氏、斟尋氏、彤城氏、襃氏、費氏、杞氏、繒氏、辛氏、冥氏、斟戈氏。孔子正夏時，學者多傳云。自虞、夏時，貢賦備矣。或言禹會諸侯江南，計功而崩，因葬焉，命曰會稽。會稽者，會計也。

<a id="s9"></a>
<a id="s9后裔夏时与会稽异说"></a>

**S9｜后裔、夏时与会稽异说**

P034末记“湯封夏之後，至周封於杞也”。P035列夏后、有扈、有男、斟寻、彤城、褒、费、杞、缯、辛、冥、斟戈十二氏，并说孔子正夏时、学者传《夏小正》，以及虞夏贡赋的评论。以上是太史公对后世传承的总括，不逐条伪造为夏初行政记录。对会稽，原文用“或言”引出会诸侯、计功而死的解释；与正文东巡而死的表述一并保留。

### 卷025｜南巢之伐与汤灭夏互见

[《律书》P005](../../sources/摘录/史记-卷025-律书.md#p005)将“成汤有南巢之伐，以殄夏乱”用作平乱用兵的例证，接本页鸣条、桀败奔南巢的既有故事，不另造一场有独立确年的南巢战役。

### 卷026｜三正是制度追述，不能据此填满三代历谱

[《历书》P006](../../sources/摘录/史记-卷026-历书.md#p006)以夏正正月、殷正十二月、周正十一月说明三正循环；这里将其作为夏、商、周的历制传统互见，不给夏王朝再补一个确定的改历年月。上述月名是相对于夏正的对照，分别对应建寅、建丑、建子；并非说每个王朝自己总把岁首称为夏历的同号月份。

[商初改正朔](04-商代前期.md#s2)已有原事，商周之际仍见[既有时期页](06-商末与周初.md)。三正的传世整齐框架不等于商周出土历日和置闰实践已经逐项证明，亦不能将周正建子当作整个西周无例外的历日换算公式。见[三正与研究边界](../../meta/考证/史记-卷026-纪年与异说.md#三正)。

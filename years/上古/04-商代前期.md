# 商代前期｜成汤之后，王位怎样传下去

[← 夏代与汤的兴起](03-夏代.md) · [上古目录](README.md) · [时间总目录](../README.md) · [继续：盘庚与武丁 →](05-盘庚与武丁.md)

> **时间口径：约前1600年至前1300年这一大框架内，主要按传世王序组织。** 不给各王平均分配年数，也不把“某王三年”直接换成公元某年。年代取夏商周断代工程的分层精度；有分歧的王序、世系和评价见同号说明。

汤的出身、伊尹登场与灭夏经过已经补在[上一时期](03-夏代.md#tang-background)，这里从胜利以后的治理接写。

<a id="tang-government"></a>
<a id="1-打败夏以后汤要求诸侯拿出安民的实绩"></a>

<a id="event-1"></a>

1. **打败夏以后，汤要求诸侯拿出安民的实绩。** 成汤灭夏后返回亳，召集诸侯，要求他们勤勉办事、给民众带来实惠，否则就要受罚。他拿禹、皋陶在外治水和后稷教人种谷作例，说明前代治理怎样让人有居处和粮食。随汤回朝的政事还牵涉伊尹、咎单及几篇诰训，篇名见文末说明。 [[1]](#note-1)


<a id="calendar"></a>
<a id="2-朝会与服色也要显示新的政治秩序"></a>

<a id="event-2"></a>

2. **朝会与服色，也要显示新的政治秩序。** 汤改变了历法所用的岁首制度和礼仪服色，崇尚白色，白天举行朝会。现有记载只留下这些简要变化。 [[2]](#note-2)


<a id="succession"></a>
<a id="3-汤死后帝位绕过了早逝的太子"></a>

<a id="event-3"></a>

3. **汤死后，帝位绕过了早逝的太子。** 原来的太子太丁比汤先去世。汤死后，太丁的两个弟弟外丙、中壬先后接位。中壬去世，伊尹拥立太丁的儿子太甲，王位这才回到汤的嫡长孙一支。太甲即位之初，伊尹作训诰。 [[3]](#note-3)


<a id="taijia"></a>
<a id="4-太甲被送到桐宫伊尹暂时代行政事"></a>

<a id="event-4"></a>

4. **太甲被送到桐宫，伊尹暂时代行政事。** 太甲即位后违背成汤的法度。伊尹把他放到桐宫，自己主持政事，接受诸侯朝见。太甲在桐宫住了三年，反省过失，伊尹迎他回朝并交还政权。太甲改善施政，诸侯重新归附，百姓安定。伊尹作训褒扬，太甲后来称太宗。 [[4]](#note-4)


<a id="woding"></a>
<a id="5-到沃丁时伊尹去世"></a>

<a id="event-5"></a>

5. **到沃丁时，伊尹去世。** 太甲去世后，儿子沃丁接位。伊尹在这一时期去世，葬于亳。咎单随后讲述伊尹的事，留下《沃丁》的篇名。 [[5]](#note-5)


<a id="taiwu"></a>
<a id="6-太庚以下短暂的衰落与整顿交替出现"></a>

<a id="event-6"></a>

6. **太庚以下，短暂的衰落与整顿交替出现。** 沃丁去世，弟弟太庚继位。太庚之后是小甲，再由小甲的弟弟雍己接位。到了雍己时，商势渐衰，有的诸侯不再来朝。弟弟太戊继位后，任伊陟为相。传说亳的朝廷上桑树和穀树一同长出，一夜之间变得很大。太戊害怕，伊陟劝他检查施政有何缺失。故事接着讲到太戊改政、树木枯去，巫咸也帮助治理王家，诸侯重新归附。太戊后来称中宗。 [[6]](#note-6)


<a id="ying-shang"></a>
<a id="孟戏中衍担任御者后人世代服事商王"></a>

<a id="event-7"></a>

7. **孟戏、中衍担任御者，后人世代服事商王。** 太戊时，大廉的后人孟戏和中衍进入商廷。传说太戊卜问得吉，让两人驾车，又给他们安排婚配。后来，中衍的后裔历代服事商王，嬴姓中一些支系由此显达。 [[7]](#note-7)


<a id="middle-kings"></a>
<a id="7-中丁以后迁居与继承纷争相互交织"></a>

<a id="event-8"></a>

8. **中丁以后，迁居与继承纷争相互交织。** 太戊之后，中丁即位并迁到隞。中丁、外壬、河亶甲先后接位，河亶甲住在相。再后来的祖乙迁到邢，任用巫贤，商的统治一度恢复。王位随后传给祖辛、沃甲、祖丁、南庚和阳甲，几度在兄弟及其后人之间转移。 [[8]](#note-8)


<a id="nine-generations"></a>
<a id="8-继承不定诸侯也越来越不愿服从"></a>

<a id="event-9"></a>

9. **继承不定，诸侯也越来越不愿服从。** 从中丁到阳甲，王位几次转到原本继承顺序以外的兄弟或子侄，有时各支相争，诸侯也逐渐疏远商王。阳甲去世后，弟弟盘庚继位，下一段接[盘庚迁都](05-盘庚与武丁.md)。 [[9]](#note-9)

## 归年与考证

<a id="s1"></a>
<a id="s1诰辞旧事与篇名"></a>

### S1｜诰辞、旧事与篇名

[卷003 P009](../../拆分史书/史记/卷003.md#p009)。“維三月”只有月名而无可独立换算的公元年；禹、皋陶、后稷及蚩尤都是诰辞引用的旧事，不改成汤在位时发生。泰卷陶、中𤳹等字样保留在原文；难字与古地理未据这一条解决。

<a id="s2"></a>
<a id="s2正朔与尚白"></a>

### S2｜正朔与尚白

[卷003 P010](../../拆分史书/史记/卷003.md#p010)原文只写改正朔、易服色、上白、朝会以昼。本条不额外宣布商代全国在同一日采用一套已知历法。

<a id="s3"></a>
<a id="s3未即位的太丁与继承次序"></a>

### S3｜未即位的太丁与继承次序

[卷003 P011](../../拆分史书/史记/卷003.md#p011)。外丙“三年”、中壬“四年”依本次底本保留，不换算绝对年代；其他文本的年数异文不静默改入。这里的太丁是成汤之子，与商末武乙之后的太丁不是同一人。伊尹所作《伊训》《肆命》《徂后》一并保留在出处，篇名不另算历史事件。

<a id="s4"></a>
<a id="s4桐宫与还政"></a>

### S4｜桐宫与还政

[卷003 P012—P013](../../拆分史书/史记/卷003.md#p012)分别写离位、摄政、返政。“既立三年”与“居桐宫三年”属于不同阶段，不能把后两段的桐宫三年又重复相加。本轮沿用本纪这一叙事，不将它扩称为已经独立证实的全部政治内幕。

[《晋书·束皙传》](../../拆分史书/晋书/卷051.md#text)所录古本《竹书纪年》异文有“太甲殺伊尹”，与太甲悔过、伊尹还政并在沃丁时去世的传世主线不能相容。本页保留《史记》叙述，同时明列这一相反传统；不将两说串成“还政后又被杀”，也不据晚出引文替太甲、伊尹排定绝对年代。

<a id="s5"></a>
<a id="s5伊尹之死"></a>

### S5｜伊尹之死

[卷003 P014](../../拆分史书/史记/卷003.md#p014)。本页只按本纪所列沃丁时期安放，未增添死亡岁数、死日或后来传说。古本《竹书纪年》太甲杀伊尹说见[上一条](#s4)；它不能再与这里合成伊尹的两次死亡。

<a id="s6"></a>
<a id="s6太戊的政事与灾异"></a>

### S6｜太戊的政事与灾异

[卷003 P015—P016](../../拆分史书/史记/卷003.md#p015)。相邻王名按传世文本保存，不因列成顺序就声称各家对继位次序均无分歧。“桑穀”及一暮长大的描述是原书灾异故事，正文不把“改过造成树木枯死”写成自然因果；伊陟不是伊尹，巫咸也不与下一段巫贤合为一人。

《天官书》[P113](../../拆分史书/史记/卷027.md#part-1-p113)以“殷商，巫咸”列入天数传承，与本页太戊时巫咸材料互见。列名不补造本年新官职、著书年月或生卒年；本卷《正义》关于籍贯、墓地与后人的说法是后注层，不凭它增补已经确证的家族史。

<a id="s7"></a>
<a id="s7九王三次迁居与祖乙父系"></a>

### S7｜九王、三次迁居与祖乙父系

| 传世王序 | 本纪所写的继承关系或记事 |
|---|---|
| 中丁 | 接太戊；迁隞。原文同时用“仲丁”这一写法，并说明相关书已残缺 |
| 外壬 | 中丁之弟 |
| 河亶甲 | 外壬之弟；居相，王朝再次衰落 |
| 祖乙 | 接河亶甲；迁邢，巫贤任职。其父系有异，见S7，不在正文断作河亶甲之子 |
| 祖辛 | 祖乙之子 |
| 沃甲 | 祖辛之弟 |
| 祖丁 | 祖辛之子，即王位转回沃甲兄长这一支 |
| 南庚 | 沃甲之子；不是上一任祖丁之子 |
| 阳甲 | 祖丁之子；又转回祖丁这一支 |

[卷003 P017](../../拆分史书/史记/卷003.md#p017)开头先总提三王居处，再按继承叙述，故拆开理解。本纪写祖乙为河亶甲之子；赵生群讨论王国维的卜辞考证时引出祖乙为中丁之子的修正，正文因此不直接重复有争议的父系。见赵生群《二重证据视野下的〈史记〉文本研究》。该网页转述中有一句主语与所引王国维原话不一致，本项目以其实际引文说明分歧，不转抄成另一套错乱父系。

### S8｜九世之乱的精度

[卷003 P018](../../拆分史书/史记/卷003.md#p018)是总括性判断，不提供九次叛乱的具体日期、参战者及胜负。这里保留继承冲突与诸侯疏离的关系，不把其政治评价无限扩成商代所有时期都适用的继承法。

# 商代前期｜成汤之后，王位怎样传下去

[← 夏代与汤的兴起](03-夏代.md) · [上古目录](README.md) · [时间总目录](../README.md) · [继续：盘庚与武丁 →](05-盘庚与武丁.md)

> **时间口径：约前1600年至前1300年这一大框架内，主要按传世王序组织。** 不给各王平均分配年数，也不把“某王三年”直接换成公元某年。年代取夏商周断代工程的分层精度；有分歧的王序、世系和评价见同号说明。
>
> 汤的出身、伊尹登场与灭夏经过已经补在[上一时期](03-夏代.md#tang-background)，这里从胜利以后的治理接写。

<a id="tang-government"></a>
## 1. 打败夏以后，汤要求诸侯拿出安民的实绩

**汤回到亳，不只宣布换了君主，还要求各方尽职办事。** 他告诫诸侯，必须对民众有所贡献，不可只占据位置；又拿禹、皋陶长久在外治水、后稷教人种谷作例子，说明先人受拥戴是因为使百姓有地方居住、有粮食可吃。诰辞同时保留了严厉的一面：不遵命、不能治理的人要受惩罚。[原文与说明](#s1)

返回途中还有在泰卷陶作诰的短记。伊尹、咎单分别与《咸有一德》《明居》相联系。这些篇名构成古书追述开国政事的线索，不能因有篇名就说现今同名文本均已验证为当时原件。[原文与说明](#s1)

<a id="calendar"></a>
## 2. 朝会与服色，也要显示新的政治秩序

**汤更改正朔和服色，崇尚白色，并在白天举行朝会。** 这一段很短，能够交代的是制度表述发生了改变；没有列出一份可以直接换算成现代日期的历表，也没有写各地完成改制的时间。[原文与说明](#s2)

<a id="succession"></a>
## 3. 汤死后，帝位绕过了早逝的太子

**太子太丁没有即位便已去世，外丙、中壬先后接位，之后才轮到太丁的儿子太甲。** 太甲是成汤的嫡长孙，由伊尹辅立。伊尹在他即位之初作训诰，向新君说明应当遵守的准则。[原文与说明](#s3)

这里既有兄弟相继，也有转回长兄后人的安排。不能把这些名字排成一张全是“父传子”的表，更不能把未即位的太丁另算作在位一任的商王。[原文与说明](#s3)

<a id="taijia"></a>
## 4. 太甲被送到桐宫，伊尹暂时代行政事

**按《史记》的叙述，太甲即位后不遵成汤的法度，伊尹把他放逐到桐宫。** 他离开王廷期间，伊尹代行政事、接受诸侯朝见。经过三年，太甲悔过，伊尹才迎他回来，将政事交还。[原文与说明](#s4)另有太甲杀伊尹的古本《竹书纪年》传统，与这条悔过还政主线不同，详见同号说明。

复位以后，太甲改善施政，诸侯重新归附，民众安定。伊尹于是作《太甲训》三篇加以褒扬，太甲被称为太宗。放逐与还政属于同一段政治冲突的前后，不写成两次不同人物的更替。[原文与说明](#s4)

<a id="woding"></a>
## 5. 到沃丁时，伊尹去世

**本纪接写太甲之后沃丁即位，并把伊尹去世、葬亳放在这一阶段。** 咎单讲述伊尹的事，留下《沃丁》的篇名。新君继承与老臣去世之外，本段没有更多独立事件，不补写伊尹的精确年龄或现代墓址。[原文与说明](#s5)

<a id="taiwu"></a>
## 6. 太庚以下，短暂的衰落与整顿交替出现

**沃丁死后，其弟太庚接位；太庚之子小甲以后，又由小甲之弟雍己、雍己之弟太戊先后继承。** 较完整的政事故事集中在太戊身上。 太庚、小甲的本段材料主要是继承关系；雍己一节则说，有诸侯不再来朝。太戊任用伊陟，又有巫咸参与王室事务。[原文与说明](#s6)

**本纪与另一张王表在一处父系上并不一致。** 这一页按《殷本纪》写小甲是太庚之子；[卷十三《三代世表》](../../sources/摘录/史记-卷013-三代世表.md#t005)却说小甲为太庚之弟，《三家注》也指出两说相反。两书都是传本文献，目前只把冲突记在这里，**不因是两种称谓便虚构两个小甲**，也不凭此给任何一位君主新增确年。[异文说明](../../meta/考证/史记-卷013-纪年与异说.md#异文与世数)

一次，亳的朝廷中出现桑与穀并生、很快长大的异象。太戊害怕，伊陟没有让他只顾祭祷，而是劝他反省施政。故事把太戊改过、异常树木枯去、诸侯再来朝连在一起，以此解释他获得中宗之称。[原文与说明](#s6)

太戊还在宗庙褒奖伊陟，表示不以普通臣礼待他，伊陟辞让。巫咸治王家有成，以及《咸艾》《太戊》《原命》等篇名，也在这一组记载中；它们不是另外几次已知年月的任命。[原文与说明](#s6)

<a id="ying-shang"></a>
## 孟戏、中衍担任御者，后人世代服事商王

太戊在位的叙事中，又出现大廉后裔孟戏、中衍。太戊通过占卜决定任他们驾车，并安排婚配。此后，中衍的后人不断服事商王，嬴姓支系因而逐渐显达。 [原文与说明](#sj005-003-note)


<a id="middle-kings"></a>
## 7. 中丁以后，迁居与继承纷争相互交织

**中丁迁隞，河亶甲居相，祖乙迁邢。** 这三件事在开头被总括到一起，随后才逐王叙述；不是中丁一人连续迁了三个都城。祖乙时有巫贤任职，朝廷一度恢复力量。后面的继承又多次转到兄弟或另一支后人，至阳甲时再次衰落。[原文与说明](#s7)

| 传世王序 | 本纪所写的继承关系或记事 |
|---|---|
| 中丁 | 接太戊；迁隞。原文同时用“仲丁”这一写法，并说明相关书已残缺 |
| 外壬 | 中丁之弟 |
| 河亶甲 | 外壬之弟；居相，王朝再次衰落 |
| 祖乙 | 接河亶甲；迁邢，巫贤任职。其父系有异，见S7，不在正文断作河亶甲之子 |
| 祖辛 | 祖乙之子 |
| 沃甲 | 祖辛之弟 |
| 祖丁 | 祖辛之子，即王位转回沃甲兄长这一支 |
| 南庚 | 沃甲之子；不是上一任祖丁之子 |
| 阳甲 | 祖丁之子；又转回祖丁这一支 |

<a id="nine-generations"></a>
## 8. 继承不定，诸侯也越来越不愿服从

**不同支系争相取得王位，使商王对诸侯的号召力不断受损。** 本纪用“比九世乱”概括中丁以下的局势。这不是九件有精确年月的政变清单；上表保存了全部九位君主，但不会为每一位补造一次夺位战争。[原文与说明](#s8)

阳甲之后由弟弟盘庚接位。迁居与恢复统治的下一轮努力，见[盘庚与武丁](05-盘庚与武丁.md)。

## 原文与出处

本页所引P编号见[卷003完整阅读原文](../../sources/摘录/史记-卷003-殷本纪.md)，不是古籍原有段号。正文采用能讲通的事件主线，传世文本的王序不冒称为已经逐一校定的甲骨王表。

<a id="s1"></a>
### S1｜诰辞、旧事与篇名

[卷003 P009](../../sources/摘录/史记-卷003-殷本纪.md#p009)。“維三月”只有月名而无可独立换算的公元年；禹、皋陶、后稷及蚩尤都是诰辞引用的旧事，不改成汤在位时发生。泰卷陶、中𤳹等字样保留在原文；难字与古地理未据这一条解决。

<a id="s2"></a>
### S2｜正朔与尚白

[卷003 P010](../../sources/摘录/史记-卷003-殷本纪.md#p010)原文只写改正朔、易服色、上白、朝会以昼。本条不额外宣布商代全国在同一日采用一套已知历法。

<a id="s3"></a>
### S3｜未即位的太丁与继承次序

[卷003 P011](../../sources/摘录/史记-卷003-殷本纪.md#p011)。外丙“三年”、中壬“四年”依本次底本保留，不换算绝对年代；其他文本的年数异文不静默改入。这里的太丁是成汤之子，与商末武乙之后的太丁不是同一人。伊尹所作《伊训》《肆命》《徂后》一并保留在出处，篇名不另算历史事件。

<a id="s4"></a>
### S4｜桐宫与还政

[卷003 P012—P013](../../sources/摘录/史记-卷003-殷本纪.md#p012)分别写离位、摄政、返政。“既立三年”与“居桐宫三年”属于不同阶段，不能把后两段的桐宫三年又重复相加。本轮沿用本纪这一叙事，不将它扩称为已经独立证实的全部政治内幕。

[《晋书·束皙传》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E6%99%89%E6%9B%B8-%E5%8D%B7051.md#ref-d5b84751049c46)所录古本《竹书纪年》异文有“太甲殺伊尹”，与太甲悔过、伊尹还政并在沃丁时去世的传世主线不能相容。本页保留《史记》叙述，同时明列这一相反传统；不将两说串成“还政后又被杀”，也不据晚出引文替太甲、伊尹排定绝对年代。

<a id="s5"></a>
### S5｜伊尹之死

[卷003 P014](../../sources/摘录/史记-卷003-殷本纪.md#p014)。本页只按本纪所列沃丁时期安放，未增添死亡岁数、死日或后来传说。古本《竹书纪年》太甲杀伊尹说见[上一条](#s4)；它不能再与这里合成伊尹的两次死亡。

<a id="s6"></a>
### S6｜太戊的政事与灾异

[卷003 P015—P016](../../sources/摘录/史记-卷003-殷本纪.md#p015)。相邻王名按传世文本保存，不因列成顺序就声称各家对继位次序均无分歧。“桑穀”及一暮长大的描述是原书灾异故事，正文不把“改过造成树木枯死”写成自然因果；伊陟不是伊尹，巫咸也不与下一段巫贤合为一人。

《天官书》[P113](../../sources/摘录/史记-卷027-天官书.md#p113)以“殷商，巫咸”列入天数传承，与本页太戊时巫咸材料互见。列名不补造本年新官职、著书年月或生卒年；本卷《正义》关于籍贯、墓地与后人的说法是后注层，不凭它增补已经确证的家族史。

<a id="s7"></a>
### S7｜九王、三次迁居与祖乙父系

[卷003 P017](../../sources/摘录/史记-卷003-殷本纪.md#p017)开头先总提三王居处，再按继承叙述，故拆开理解。本纪写祖乙为河亶甲之子；赵生群讨论王国维的卜辞考证时引出祖乙为中丁之子的修正，正文因此不直接重复有争议的父系。见[赵生群《二重证据视野下的〈史记〉文本研究》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-8eddc10a7c90a5e4.md#cite-2)。该网页转述中有一句主语与所引王国维原话不一致，本项目以其实际引文说明分歧，不转抄成另一套错乱父系。

<a id="s8"></a>
### S8｜九世之乱的精度

[卷003 P018](../../sources/摘录/史记-卷003-殷本纪.md#p018)是总括性判断，不提供九次叛乱的具体日期、参战者及胜负。这里保留继承冲突与诸侯疏离的关系，不把其政治评价无限扩成商代所有时期都适用的继承法。

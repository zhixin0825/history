# 商代中后期｜盘庚迁都，武丁求贤

[← 商代前期](04-商代前期.md) · [上古目录](README.md) · [时间总目录](../README.md) · [继续：商末与周初 →](06-商末与周初.md)

> **年代参考：盘庚迁殷取约前1300年，武丁在位取工程方案前1250—前1192年。** 它们标识时期，不使本篇的梦、任命或鼎耳鸣雉突然都有了确切发生年。盘庚、小辛、小乙的合计时段不拆成三个虚构的精确王年。[年代与地理依据](../../meta/考证/史记-卷003-纪年与异说.md)

<a id="pangeng"></a>
<a id="1-盘庚想迁都先要面对不愿走的人"></a>

<a id="event-1"></a>

1. **盘庚想迁都，先要面对不愿走的人。** **阳甲去世以后，盘庚接位；迁居却遭到民众抱怨。** 人们不愿离开原来的地方，盘庚向诸侯和大臣申说：当年成汤与大家的祖先共同建立王朝，留下的法度应该继续实行，不能任其废弛。 [[1]](#note-1)

   盘庚最后完成迁居，重新整顿政事，诸侯又来朝见。这段故事的转折不是“搬家自然带来繁荣”，而是迁都、援引祖先共同立国的关系、恢复施政三件事连在一起。

<a id="xiaoxin-xiaoyi"></a>
<a id="2-盘庚以后兄弟先后接位"></a>

<a id="event-2"></a>

2. **盘庚以后，兄弟先后接位。** **盘庚死后先是小辛，小辛死后再是小乙；两人都是盘庚这一代的兄弟。** 到小辛时，统治再度衰落，民众怀念盘庚的整顿。本纪把《盘庚》三篇联系到这种追思；具体篇章的成文与编次不能仅凭这句话定论。 [[2]](#note-2)

   **横读《三代世表》时还须留心：**它把盘庚、小辛、小乙、武丁接在商王表中，却没有给出他们逐年的公元日期。尤其上一页所述祖乙和盘庚之间的几次转支继承，不因排列为单行名字就能判定哪次国政变化发生在何年。[商代全王序摘录](../../sources/摘录/史记-卷013-三代世表.md#t005) · [年代边界](../../meta/考证/史记-卷013-纪年与异说.md#年代与表格)

<a id="wuding"></a>
<a id="3-武丁即位以后先把政事交给冢宰"></a>

<a id="event-3"></a>

3. **武丁即位以后，先把政事交给冢宰。** **小乙死后，儿子武丁接位。** 他希望恢复商的力量，却还没有找到合意的辅佐者；最初三年不发言，由冢宰决定政事，同时观察国情。 [[3]](#note-3)

   在此以前，武丁曾在外劳作、接触普通人的生活。《无逸》用这段经历说明他知道民众的艰难；这是登位前的背景，不误当成即位后三年又从头发生的一次外出。

<a id="fuyue"></a>
<a id="4-在傅险筑作的人被带到武丁面前"></a>

<a id="event-4"></a>

4. **在傅险筑作的人，被带到武丁面前。** **武丁寻找的辅臣，最后来自王廷之外。** 所传故事说，他梦见一位名叫“说”的人，逐一看过群臣都不像，才派人到外面寻访。寻访者在傅险找到正在服役筑作的说，将他带来；武丁与他交谈后任为相，称为傅说。 [[4]](#note-4)

   故事把梦中识人、野外寻访、实际交谈和任职连成四步。正文保留傅说从役作者进入朝廷的情节，不把梦本身当作任命年代的证据，也不另添本段没有的神通。

<a id="zuji"></a>
<a id="5-雉鸟停在鼎耳上祖己却让武丁先看自己的政事"></a>

<a id="event-5"></a>

5. **雉鸟停在鼎耳上，祖己却让武丁先看自己的政事。** **祭祀成汤后的第二天，一只雉鸟登上鼎耳鸣叫，武丁为此忧惧。** 祖己劝他先修政事，接着把话题转到君主怎样对待民众：不能只拿天命解释一切，更不能放下自己该承担的责任。 [[5]](#note-5)

   武丁随后整顿施政，商的统治重新振作。这一段与太戊遇桑穀异象的故事相似，都把君主面对灾异时的选择写为政治教训；二者不是同一件事件，也不是同一个进谏者。

<a id="gaozong"></a>
<a id="6-武丁去世以后祖庚接位高宗之称留了下来"></a>

<a id="event-6"></a>

6. **武丁去世以后，祖庚接位，高宗之称留了下来。** **武丁死后，儿子祖庚继位。** 本纪说祖己赞扬武丁能够因异象而修政，为他立庙，称为高宗，并记《高宗肜日》及训的篇名。 [[6]](#note-6)

   这一段交代后人如何纪念武丁，并没有把下一代的所有事都展开。祖庚、祖甲以后的继承，见[商末与周初](06-商末与周初.md)。

### 1. 盘庚想迁都，先要面对不愿走的人

[返回正文第1条](#event-1)

**[卷003 P019](../../sources/摘录/史记-卷003-殷本纪.md#p019)**

> 帝陽甲崩，弟盤庚立，是為帝盤庚。帝盤庚之時，殷已都河北，盤庚渡河南，復居成湯之故居，迺五遷，無定處。殷民咨胥皆怨，不欲徙。盤庚乃告諭諸侯大臣曰：「昔高后成湯與爾之先祖俱定天下，法則可修。舍而弗勉，何以成德！」乃遂涉河南，治亳，行湯之政，然後百姓由寧，殷道復興。諸侯來朝，以其遵成湯之德也。

<a id="s1"></a>
<a id="s1迁都不能直接画成一条确定路线"></a>

**S1｜迁都不能直接画成一条确定路线**

[卷003 P019](../../sources/摘录/史记-卷003-殷本纪.md#p019)写“渡河南”“复居成汤之故居”“治亳”，与通常所说盘庚迁殷的安阳定位之间不能不加说明地等同。正文取迁居、反对与整顿的共同主线，不把河南、河北译作现代省名，也不凭一字“亳”指定一座已发掘宫殿。

牛世山的研究将洹北商城和殷墟商邑区分为时代相接、规划不同的两座城市，说明考古分期需要具体分析。它不能替本段逐一确认盘庚渡哪条河、到哪个院落。见[《从洹北商城到殷墟商邑：城市规划与建设的嬗变》](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-e0467dcd4ffc5788.md#cite-2)。本纪所谓五迁与前面契至汤八迁分属不同阶段，不相互替换。

### 3. 武丁即位以后，先把政事交给冢宰

[返回正文第3条](#event-3)

**[卷003 P021](../../sources/摘录/史记-卷003-殷本纪.md#p021)**

> 帝小乙崩，子帝武丁立。帝武丁即位，思復興殷，而未得其佐。三年不言，政事決定於冢宰，以觀國風。武丁夜夢得聖人，名曰說。以夢所見視群臣百吏，皆非也。於是迺使百工營求之野，得說於傅險中。是時說為胥靡，筑於傅險。見於武丁，武丁曰是也。得而與之語，果聖人，舉以為相，殷國大治。故遂以傅險姓之，號曰傅說。

<a id="s3"></a>
<a id="s3三年不言与在位五十九年"></a>

**S3｜三年不言与在位五十九年**

[卷003 P021](../../sources/摘录/史记-卷003-殷本纪.md#p021)与[《尚书·无逸》](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%B0%9A%E6%9B%B8-%E7%84%A1%E9%80%B8.md#ref-4bf0b495408999)互见。《无逸》写高宗在外劳作、三年不言，并记享国五十九年；《殷本纪》强调未得其佐、观察国风。两种侧重都保留，不擅定为三年不能说话的疾病，也不把三年加到五十九年之后。

**S4｜傅说的身份**

[卷003 P021](../../sources/摘录/史记-卷003-殷本纪.md#p021)作“胥靡”“筑于傅险”，本页用服役筑作概述，不在没有进一步证据时确定其犯罪、契约或人身身份的所有法律细节。“说”在此为人名，傅来自本篇以地名解释其称谓的说法。

### 5. 雉鸟停在鼎耳上，祖己却让武丁先看自己的政事

[返回正文第5条](#event-5)

**[卷003 P022](../../sources/摘录/史记-卷003-殷本纪.md#p022)**

> 帝武丁祭成湯，明日，有飛雉登鼎耳而呴，武丁懼。祖己曰：「王勿憂，先修政事。」祖己乃訓王曰：「唯天監下典厥義，降年有永有不永，非天夭民，中絕其命。民有不若德，不聽罪，天既附命正厥德，乃曰其柰何。鳴呼！王嗣敬民，罔非天繼，常祀毋禮于棄道。」武丁修政行德，天下咸驩，殷道復興。

<a id="s5"></a>
<a id="s5祖己劝政"></a>

**S5｜祖己劝政**

[卷003 P022](../../sources/摘录/史记-卷003-殷本纪.md#p022)。祖己不是太戊时期的伊陟，亦不是后来向帝辛告急的祖伊。训辞关于寿夭、天命、祭祀的解释在原文中完整保留；本页不把这些观念当作自然科学规律。

# 商末与周初｜王廷分裂，周人取代商王

[← 盘庚与武丁](05-盘庚与武丁.md) · [上古目录](README.md) · [时间总目录](../README.md)

> **范围：武丁之后至商周更替及周初殷人安置。** 商亡采用断代工程前1046年的方案，其他情节不因处于相邻段落而取得确切年份。本文以传世叙事讲清人物和因果；射天、酒池肉林、剖心等所传细节与金文直接支持的征商事实分层阅读，依据放在同号注。

<a id="later-kings"></a>
<a id="1-祖庚之后王位经过几次兄弟与父子间的转移"></a>

<a id="event-1"></a>

1. **祖庚之后，王位经过几次兄弟与父子间的转移。** **祖庚去世，弟弟祖甲接位；再往下是廪辛、庚丁、武乙。** 本纪对这几位君主多是短记，因此先将继承关系列清，不用一句“商衰”替所有人补出相同的政治经历。 [[1]](#note-1)

   | 次序 | 本纪所列王名 | 继承关系及阅读提醒 |
   |---|---|---|
   | 1 | 祖庚 | 武丁之子，接位已见上一页 |
   | 2 | 祖甲，又称帝甲 | 祖庚之弟；不同文献对他的施政评价不一致 |
   | 3 | 廪辛 | 祖甲之子 |
   | 4 | 庚丁 | 廪辛之弟；与太庚、盘庚不是同一人 |
   | 5 | 武乙 | 庚丁之子；迁居河北记载的王世归属有异，见下文说明 |
   | 6 | 太丁 | 武乙之子；商末的太丁，不是成汤之子太丁 |
   | 7 | 帝乙 | 太丁之子 |
   | 8 | 帝辛 | 帝乙之子，即后世通常所称的纣 |

   <a id="sj013-migration"></a>
   **在庚丁、武乙前后的传承中，还记有商王室向河以北迁居。** 这是原有迁居线索的补充，并不是因为换了一位君主，就能再确定一次走相同路线的迁都。具体王世与地点的差别见。

<a id="wuyi"></a>
<a id="2-武乙的射天故事与一次雷暴中死亡相连"></a>

<a id="event-2"></a>

2. **武乙的射天故事，与一次雷暴中死亡相连。** **武乙被写成故意戏弄神明的人。** 所传故事说，他制作偶人称为天神，让人代它博戏，偶人输了就加以侮辱；又把血装入皮囊，仰射皮囊，称为射天。后来他在河、渭之间狩猎，遇暴雷而死。 [[2]](#note-2)

   武乙死后，太丁、帝乙相继在位。本纪没有在这里展开他们的完整政事；将名号和继承关系保留，比套用武乙的故事替他们补写一段生平更可靠。

<a id="dixin"></a>
<a id="3-帝乙的长子没有继位接位的是辛"></a>

<a id="event-3"></a>

3. **帝乙的长子没有继位，接位的是辛。** **微子启年长，辛年幼，但辛因母亲的正后身份取得继承位置。** 帝乙死后，辛成为商王。本纪所给的原因是母亲地位与继承资格，并不是兄弟年龄排序本身。 [[3]](#note-3)

   帝辛的朝廷积聚财物、粮食与珍玩，扩大宫室和沙丘苑台。师涓制作乐舞，妲己受到宠爱；夜饮、酒池肉林等描写，则构成传世文献对宫廷生活的强烈批评。

<a id="zhou-family"></a>
<a id="另一支力量在岐下聚集古公迁居与季历继承"></a>

<a id="event-4"></a>

4. **另一支力量在岐下聚集：古公迁居与季历继承。** **公刘以后，周人的世系依次接到庆节、皇仆、差弗、毁隃、公非、高圉、亚圉、公叔祖类，再到古公亶父。** 古公仍住豳时，戎狄先索财物，后来要求土地与人口。他不愿让人为了保住自己而送死，带着亲近者迁往岐山下，豳人和附近归附者也相继跟来。 [[4]](#note-4)

   **卷十三《三代世表》把这条周人先公谱系向上接回帝喾和后稷，并把黄帝至武王合计为“十九世”。** 这不是十九位周王：后稷、古公、季历乃至西伯昌都不等于后来王朝中按年即位的周天子。与卷四一样，表文没有给出不窋、公刘至古公每个人能够核实的在位公元年份。[完整周先公链](../../sources/摘录/史记-卷013-三代世表.md#t004) · [谱系与王年](../../meta/考证/史记-卷013-纪年与异说.md#异文与世数)

   到了岐下，周人改变原先穴居的环境，营筑城郭房屋，分设官职。古公的三个儿子是太伯、虞仲和季历；季历娶太任，生昌。太伯、虞仲知道父亲想传位给季历一支，便离开赴荆蛮，以不同习俗表明退让。古公死后，季历继承，继续维系诸侯归附；季历死后，昌接位，就是下文的西伯。

   <a id="sj031-taibo-descendants"></a>
   **太伯让位不意味着吴地这一支从此失去后继。** 太伯在当地号为句吴的故事，属于吴国追述的起源；他死后没有儿子，弟弟仲雍接位，再传季简、叔达、周章，前后跨过好几代。这里交代的是一支宗族的承接，**不能把后面数代人都写成古公或季历当年同时活动**。其后周章受封与周北虞国分支见[武王克殷后的安置](#sj031-zhouzhang)。[卷031 P001起源](../../sources/摘录/史记-卷031-吴太伯世家.md#p001) · [卷031 P002继承](../../sources/摘录/史记-卷031-吴太伯世家.md#p002)

   西伯昌礼遇老人，也不断接纳投奔的人。伯夷、叔齐、太颠、闳夭、散宜生、鬻子、辛甲等先后来归。周的力量由此不只是一个不断增长的家族，还包括围绕它聚合的人才与盟友。

   <a id="sj032-lvshang-first"></a>
   **吕尚进入周人的辅佐集团，成为西伯的重要谋臣。** 他本姓姜，以先人的吕地封号为氏，后世称为太公望、师尚父。关于家世，传说他来自东海一带，先祖任四岳、辅佐禹治水，受封于吕或申；到夏商时期，后代有人保有封地，有人成为平民。入周前贫困、年老才遇合的经历，也保存在他的身世叙述中。这里先交代这位人物，不能据这些传说倒推出出生、垂钓或归周的绝对年。

<a id="punishments"></a>
<a id="4-九侯鄂侯被杀西伯昌也遭到拘禁"></a>

<a id="event-5"></a>

5. **九侯、鄂侯被杀，西伯昌也遭到拘禁。** **帝辛加重刑罚以后，王廷与诸侯的冲突进一步扩大。** 九侯献女入宫，女子触怒帝辛，父女被杀；鄂侯激烈争辩，也被杀。西伯昌听到这些事私下叹息，崇侯虎将其反应报告帝辛，西伯遂被囚在羑里。 [[5]](#note-5)

   西伯的臣属闳夭等搜求美女、奇物和良马进献，才使西伯获释。出狱后，西伯献洛西之地，请求除去炮格之刑，帝辛答应，并赐弓矢斧钺，使他得以征伐。与此同时，费中、恶来受到任用，诸侯对王廷越来越疏远。

   <a id="release-details"></a>
   **营救西伯并非只送一次笼统的礼物。** 闳夭等搜求有莘氏女子、骊戎文马、有熊九驷及其他奇物，经费仲献给帝辛。西伯获释后，被告知告发来自崇侯虎；随后献洛西之地，请除炮格。

<a id="zhou-grows"></a>
<a id="5-西伯的力量增长祖伊向帝辛发出警告"></a>

<a id="event-6"></a>

6. **西伯的力量增长，祖伊向帝辛发出警告。** **西伯回去以后，更多诸侯转向周，帝辛的权势随之受到削弱。** 比干劝谏未被接受，受到百姓敬重的商容又被废黜。 [[6]](#note-6)

   西伯攻灭一国以后，祖伊赶来告急。他把危险归到帝辛的施政：民众失去安定生活，希望王朝受罚；君主不能认为祖先和天命会永远替自己兜底。帝辛却以自己受命于天作答，祖伊退下后认为已无法再劝。

   <a id="wen-campaigns"></a>
   **虞、芮为田界争执来求裁断，走进周地以后，先看到当地人让田界、让长者。** 两方觉得自己的争端有愧，尚未见到西伯便相让而返。这则故事把诸侯转向周的原因放在日常秩序上，而不只放在战争上。

   其后西伯先后征犬戎、密须、耆、邘、崇。耆被攻灭，正是祖伊向帝辛告急的那次事件；“耆”“黎”和卷003的异字不拆成几场不同战争。攻崇之后，周人在丰营建，离岐而居丰。西伯死，太子发继承。

   文王在位五十年、在羑里演《易》、受命后十年而死，以及后人追尊古公、季历为王，都属于这段保存的解释与年数，不能只凭这些数字便倒推出每一役的绝对年。

<a id="mengjin"></a>
<a id="6-武王第一次会合诸侯还没有立刻决战"></a>

<a id="event-7"></a>

7. **武王第一次会合诸侯，还没有立刻决战。** **西伯昌死后，周武王率兵东行，到盟津与反商诸侯会合。** 诸侯要求进兵，武王却认为时机未到，领军回去。本纪所记的盟津会合和后来的牧野决战是两次行动，不能合并成“到了盟津便在当天灭商”。 [[7]](#note-7)

   <a id="wu-council"></a>
   **发接位以后，让太公望为师，周公旦为辅，召公、毕公等也围绕他办事。** 这批人各有承担，并不是只有武王一人作全部决定。到第一次盟津会合时，武王先在毕祭告，奉文王木主随军，仍把这次行动解释为承接父亲事业。

<a id="court-break"></a>
<a id="7-微子离去比干被杀箕子被囚王廷继续分裂"></a>

<a id="event-8"></a>

8. **微子离去、比干被杀、箕子被囚，王廷继续分裂。** **微子多次劝谏无效，与大师、少师商议后离开。** 比干仍坚持进谏，被帝辛杀死；箕子恐惧，装作疯癫、沦为奴役，后来又被囚禁。大师、少师携祭祀与乐用器物逃往周方。 [[8]](#note-8)

   几个人并不是同时采取同一种办法：有人离开，有人留下强谏，有人隐忍求存，有人带走器物投向对手。把这些分别讲清，才能看出王廷关系如何一步步破裂。

   <a id="musicians"></a>
   **周方又接到商朝乐官携器物而来的消息。** 卷四把出走者记为太师疵、少师彊，并在武王与诸侯将领商议继续进军的背景下叙述他们。商廷内部的离散，和外部联军的动员由此连在一起。

<a id="muye"></a>
<a id="8-甲子日商军在牧野败北"></a>

<a id="event-9"></a>

9. **甲子日，商军在牧野败北。** **武王再次率诸侯出兵，帝辛发兵到牧野抵御，商军在甲子日战败。** 帝辛退回鹿台，穿上饰有宝玉的衣服，赴火而死。武王斩下他的头悬于大白旗；商王嬖妾的结局，两篇本纪的细节不同，见同号说明。 [[9]](#note-9)

   与前面的盟津之会不同，这次败战结束了帝辛的统治。利簋铭文对武王在甲子日清晨征商提供了出土文字依据；但它并不逐一证明本纪所记的宫廷逸事，也不是一件自身写有“公元前1046年”的文物。

   <a id="muye-orders"></a>
   **再次出兵以前，武王召集诸侯，宣布商王罪状，联军渡河后逼近商郊。** 太公望先驱，周公等分辅军政；在牧野誓师时，武王向诸国君长和军职人员提出行军、整队与接敌要求：前进几步便校正队形，数次攻击以后仍要停下整顿，不要阻挡已经奔来的降者。

   开战时，太公率先进击，武王的大队随后跟上；商军一方出现倒戈，阵势瓦解。这补出了前文“甲子日战败”的过程，不是另一场牧野之战。

<a id="feilian-ancestry"></a>
<a id="恶来死于商周更替蜚廉之死另有不同叙述"></a>

<a id="event-10"></a>

10. **恶来死于商周更替，蜚廉之死另有不同叙述。** 商末为纣服务的恶来，是蜚廉之子；其家又上承经营西垂的中潏。恶来随商王朝覆灭而死。父子同样以才能获用，后来命运却在不同本纪中留下差别：恶来的死亡可与前文接合，蜚廉的归来、死亡则只保留为异说。 [[10]](#note-10)

<a id="settlement"></a>
<a id="9-周人先保留了商王后裔再建立自己的统治"></a>

<a id="event-11"></a>

11. **周人先保留了商王后裔，再建立自己的统治。** **战后，武王释放箕子，培封比干之墓，表彰商容的居处，又让帝辛之子武庚禄父延续殷祀。** 他要求武庚修行盘庚之政，试图以商人熟悉的祖先政治传统安顿商的遗民，而不是把所有旧王族一并消灭。 [[11]](#note-11)

    武王成为天子，商的后人转为周之下的诸侯。本纪在这一处又讨论“帝”与“王”的称号，属于作者对历史名号的解释，不另造一次有确日的改名仪式。

    <a id="settlement-more"></a>
    **战后第二天，周人先除治道路、整修社坛，再在殷众面前举行受命仪式。** 毛叔郑、卫叔封、周公旦、召公奭、毕公等分任仪仗与辅导，尹佚读祝文，以商王失德、周受命解释更替。民众被告知不必惊惧。

    周人不只安置武庚，还让管叔、蔡叔在旁协助约束殷地；同时释放囚徒，取出鹿台财物、钜桥积粟散给民众。旧王朝后裔与功臣分别获得封地：黄帝、尧、舜、禹之后，以及齐、鲁、燕、管、蔡等国，都列在这套战后安排中。封地不等于相关人物同一天已经在当地建成完整国家。

    <a id="sj032-yingqiu-lai"></a>
    **吕尚赴齐就封时，莱侯发兵争夺营丘。** 吕尚东行起初走得慢，在旅舍听人提醒时机容易错过，便连夜赶路，黎明抵达这处与莱地相邻的封地。

    <a id="sj031-zhouzhang"></a>
    **吴国的周章不是到武王克殷这时才成为君主。** 他在此以前已接续仲雍、季简、叔达一系治理吴地；周武王寻得这支宗亲时，确认他在吴的地位，同时另将周章的弟弟封在故夏虚的虞地。一个是吴国原有统治获得承认，另一个是中原虞国受封，不能并成一次「周章由吴迁虞」；相关君主的个人即位年份尚不能独立求出。[卷031 P002原文与校勘](../../sources/摘录/史记-卷031-吴太伯世家.md#p002) · [同名虞仲三家注](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7031.md#ref-3434e8f2f6c969)

    天下初定，武王仍为未安的地方忧虑，夜里不能入睡。他与周公谈到在洛、伊一带营建、安置四方的计划，又在回师时放马、放牛，表示暂息兵事。克殷后二年，他还向箕子询问天道。

<a id="wu-death"></a>
<a id="武王病逝以后幼主面前还有未稳的天下"></a>

<a id="event-12"></a>

12. **武王病逝以后，幼主面前还有未稳的天下。** **武王病重时，周公请向神明祈告，希望自己代替武王承担灾难。** 这是周公在文献中表明与王室关系的方式，不是已经证实的祈祷换命。武王后来去世，太子诵继位，即成王；成王年幼，周公开始代行政事。 [[12]](#note-12)

    管叔、蔡叔等对这种安排产生疑虑，武庚也参与其间，战后刚建立的政治秩序再次破裂。

<a id="wugeng"></a>
<a id="10-武王死后武庚再起微子后来被立于宋"></a>

<a id="event-13"></a>

13. **武王死后，武庚再起，微子后来被立于宋。** **最初的安排并没有终结冲突。** 武王死后，武庚与管叔、蔡叔联合，成王命周公加以讨伐；周人后来立微子于宋，使他延续商的后祀。 [[13]](#note-13)

    这一连串事发生在武王死后，不放到牧野战败的同一年，也不因为本篇用一句话写完，就把商亡、周公出征、封宋压成同一天。本轮卷四增补了这些现有位置，周初的治理继续见下一时期。

    <a id="wugeng-outcome"></a>
    **周公奉成王命征讨以后，武庚、管叔被诛，蔡叔被放逐，处置并不相同。** 微子封宋，康叔又领受一部分殷民而建立卫国。唐叔得到嘉谷、成王把谷交到周公军中的故事，与《归禾》《嘉禾》等篇名连在一起。传世叙事说这次讨伐历时三年，周公摄政七年后归政；平乱与归政是不同阶段，不因连写在一段便同年完成。

### 5. 九侯、鄂侯被杀，西伯昌也遭到拘禁

**[卷003 P029](../../sources/摘录/史记-卷003-殷本纪.md#p029)**

> 百姓怨望而諸侯有畔者，於是紂乃重刑辟，有炮格之法。以西伯昌、九侯、鄂侯為三公。九侯有好女，入之紂。九侯女不憙淫，紂怒，殺之，而醢九侯。鄂侯爭之彊，辨之疾，并脯鄂侯。西伯昌聞之，竊嘆。崇侯虎知之，以告紂，紂囚西伯羑里。西伯之臣閎夭之徒，求美女奇物善馬以獻紂，紂乃赦西伯。西伯出而獻洛西之地，以請除炮格之刑。紂乃許之，賜弓矢斧鉞，使得征伐，為西伯。而用費中為政。費中善諛，好利，殷人弗親。紂又用惡來。惡來善毀讒，諸侯以此益疏。

**[卷004 P008](../../sources/摘录/史记-卷004-周本纪.md#p008)**

> 崇侯虎譖西伯於殷紂曰：「西伯積善累德，諸侯皆向之，將不利於帝。」帝紂乃囚西伯於羑里。閎夭之徒患之。乃求有莘氏美女，驪戎之文馬，有熊九駟，他奇怪物，因殷嬖臣費仲而獻之紂。紂大說，曰：「此一物足以釋西伯，況其多乎！」乃赦西伯，賜之弓矢斧鉞，使西伯得征伐。曰：「譖西伯者，崇侯虎也。」西伯乃獻洛西之地，以請紂去炮格之刑。紂許之。

### 6. 西伯的力量增长，祖伊向帝辛发出警告

[返回正文第6条](#event-6)

**[卷003 P030](../../sources/摘录/史记-卷003-殷本纪.md#p030)**

> 西伯歸，乃陰修德行善，諸侯多叛紂而往歸西伯。西伯滋大，紂由是稍失權重。王子比干諫，弗聽。商容賢者，百姓愛之，紂廢之。及西伯伐飢國，滅之，紂之臣祖伊聞之而咎周，恐，奔告紂曰：「天既訖我殷命，假人元龜，無敢知吉，非先王不相我後人，維王淫虐用自絕，故天弃我，不有安食，不虞知天性，不迪率典。今我民罔不欲喪，曰『天曷不降威，大命胡不至』？今王其柰何？」紂曰：「我生不有命在天乎！」祖伊反，曰：「紂不可諫矣。」西伯既卒，周武王之東伐，至盟津，諸侯叛殷會周者八百。諸侯皆曰：「紂可伐矣。」武王曰：「爾未知天命。」乃復歸。

**[卷004 P009](../../sources/摘录/史记-卷004-周本纪.md#p009)**

> 西伯陰行善，諸侯皆來決平。於是虞、芮之人有獄不能決，乃如周。入界，耕者皆讓畔，民俗皆讓長。虞、芮之人未見西伯，皆慚，相謂曰：「吾所爭，周人所恥，何往為，秖取辱耳。」遂還，俱讓而去。諸侯聞之，曰「西伯蓋受命之君」。

**[卷004 P010](../../sources/摘录/史记-卷004-周本纪.md#p010)**

> 明年，伐犬戎。明年，伐密須。明年，敗耆國。殷之祖伊聞之，懼，以告帝紂。紂曰：「不有天命乎？是何能為！」明年，伐邘。明年，伐崇侯虎。而作豐邑，自岐下而徙都豐。明年，西伯崩，太子發立，是為武王。

**[卷004 P011](../../sources/摘录/史记-卷004-周本纪.md#p011)**

> 西伯蓋即位五十年。其囚羑里，蓋益易之八卦為六十四卦。詩人道西伯，蓋受命之年稱王而斷虞芮之訟。後十年而崩，謚為文王。改法度，制正朔矣。追尊古公為太王，公季為王季：蓋王瑞自太王興。

### 10. 恶来死于商周更替，蜚廉之死另有不同叙述

> 其玄孫曰中潏，在西戎，保西垂。生蜚廉。蜚廉生惡來。惡來有力，蜚廉善走，父子俱以材力事殷紂。周武王之伐紂，并殺惡來。是時蜚廉為紂石北方，還，無所報，為壇霍太山而報，得石棺，銘曰「帝令處父不與殷亂，賜爾石棺以華氏」。死，遂葬於霍太山。蜚廉復有子曰季勝。季勝生孟增。孟增幸於周成王，是為宅皋狼。皋狼生衡父，衡父生造父。造父以善御幸於周繆王，得驥、溫驪、驊騮、騄耳之駟，西巡狩，樂而忘歸。徐偃王作亂，造父為繆王御，長驅歸周，一日千里以救亂。繆王以趙城封造父，造父族由此為趙氏。自蜚廉生季勝已下五世至造父，別居趙。趙衰其後也。惡來革者，蜚廉子也，蚤死。有子曰女防。女防生旁皋，旁皋生太幾，太幾生大駱，大駱生非子。以造父之寵，皆蒙趙城，姓趙氏。

> 其明日，除道，修社及商紂宮。及期，百夫荷罕旗以先驅。武王弟叔振鐸奉陳常車，周公旦把大鉞，畢公把小鉞，以夾武王。散宜生、太顛、閎夭皆執劍以衛武王。既入，立于社南大卒之左，［左］右畢從。毛叔鄭奉明水，衛康叔封布茲，召公奭贊采，師尚父牽牲。尹佚筴祝曰：「殷之末孫季紂，殄廢先王明德，侮蔑神祇不祀，昏暴商邑百姓，其章顯聞于天皇上帝。」於是武王再拜稽首，曰：「膺更大命，革殷，受天明命。」武王又再拜稽首，乃出。

**[卷004 P018](../../sources/摘录/史记-卷004-周本纪.md#p018)**

> 封商紂子祿父殷之餘民。武王為殷初定未集，乃使其弟管叔鮮、蔡叔度相祿父治殷。已而命召公釋箕子之囚。命畢公釋百姓之囚，表商容之閭。命南宮括散鹿臺之財，發鉅橋之粟，以振貧弱萌隸。命南宮括、史佚展九鼎保玉。命閎夭封比干之墓。命宗祝享祠于軍。乃罷兵西歸。行狩，記政事，作武成。封諸侯，班賜宗彝，作分殷之器物。武王追思先聖王，乃褒封神農之後於焦，黃帝之後於祝，帝堯之後於薊，帝舜之後於陳，大禹之後於杞。於是封功臣謀士，而師尚父為首封。封尚父於營丘，曰齊。封弟周公旦於曲阜，曰魯。封召公奭於燕。封弟叔鮮于管，弟叔度於蔡。餘各以次受封。

**[卷004 P019](../../sources/摘录/史记-卷004-周本纪.md#p019)**

> 武王徵九牧之君，登豳之阜，以望商邑。武王至于周，自夜不寐。周公旦即王所，曰：「曷為不寐？」王曰：「告女：維天不饗殷，自發未生於今六十年，麋鹿在牧，蜚鴻滿野。天不享殷，乃今有成。維天建殷，其登名民三百六十夫，不顯亦不賓滅，以至今。我未定天保，何暇寐！」王曰：「定天保，依天室，悉求夫惡，貶從殷王受。日夜勞來定我西土，我維顯服，及德方明。自洛汭延于伊汭，居易毋固，其有夏之居。我南望三涂，北望嶽鄙，顧詹有河，粵詹雒、伊，毋遠天室。」營周居于雒邑而後去。縱馬於華山之陽，放牛於桃林之虛；偃干戈，振兵釋旅：示天下不復用也。

### 卷024｜大武六成与商周记忆

### 卷025｜武王吹律听声的传说与解释

[《律书》P003](../../sources/摘录/史记-卷025-律书.md#p003)把武王伐纣与吹律听声、杀气和宫音联系起来。它属于古代以声律察军气、解释胜负的说法，不能当作已经验证的军事预测方法，也不由“推孟春以至于季冬”另编一份十二个月的征商作战日历。

所见《索隐》说此事出处未详；[四库本考证](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E9%9B%86%E8%A7%A3%20%28%E5%8F%B8%E9%A6%AC%E9%81%B7%2C%20%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29-%E5%8D%B7025.md#ref-7162032885e444)则指向《国语》。本次实读[《国语·周语下》景王问律段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%9C%8B%E8%AA%9E-%E5%8D%B703.md#ref-2fb4fd10182b92)，确见伶州鸠追述武王于牧野以黄钟下宫布戎、入商以太蔟下宫布令等说法。两篇不是字字相同的独立战场记录；既有牧野主线、断代工程的时期口径和同号异说继续保留，不凭音律推算再定一个新的克商年。

# 商末与周初｜王廷分裂，周人取代商王

[← 盘庚与武丁](05-盘庚与武丁.md) · [上古目录](README.md) · [时间总目录](../README.md)

> **范围：武丁去世至周公平定武庚之乱。** 商末王序、周的扩张与克商，主要按《史记》叙述串联。牧野之战采用夏商周断代工程的前1046年方案，其余事件按史料能确认的先后排列。

<a id="1-祖庚之后王位经过几次兄弟与父子间的转移"></a>
<a id="event-1"></a>
<a id="sj013-migration"></a>

1. **祖甲接替祖庚，商王此后几次在兄弟间传位。** 武丁死后，儿子祖庚继位；祖庚死后，王位传给弟弟祖甲。接着是祖甲之子廪辛、廪辛之弟庚丁、庚丁之子武乙。《殷本纪》还在这一段记了商人离开亳、迁往河北；《三代世表》把迁徙写在庚丁名下。两处排列不同，无法据此定出迁都是哪一年。 [[1]](#note-1)

<a id="wuyi"></a>
<a id="2-武乙的射天故事与一次雷暴中死亡相连"></a>
<a id="event-2"></a>

2. **武乙死于雷暴，王位传到帝乙。** 《殷本纪》说，武乙把木偶当作天神来玩博戏，又用装血的皮囊“射天”；后来他在黄河、渭水一带打猎时遇雷暴身亡。这是本纪把君王行为和死因连在一起的讲法。武乙之后，儿子太丁继位，太丁死后又由儿子帝乙接位。 [[2]](#note-2)

<a id="dixin"></a>
<a id="3-帝乙的长子没有继位接位的是辛"></a>
<a id="event-3"></a>

3. **帝乙的长子微子启没能继位，帝辛接位。** 帝乙的长子是微子启，但本纪说他的母亲地位较低，少子辛的母亲是正后，因而由辛继承王位。后世称他为纣。《殷本纪》说帝辛宠信妲己，命师涓作乐，加重赋税，把钱聚在鹿台、粮聚在钜桥，又扩建沙丘园苑。司马迁把这些宫廷叙事与后文的民怨连在一起。 [[3]](#note-3)

<a id="zhou-family"></a>
<a id="另一支力量在岐下聚集古公迁居与季历继承"></a>
<a id="event-4"></a>
<a id="sj031-taibo-descendants"></a>
<a id="sj032-lvshang-first"></a>

4. **周人迁到岐下，季历和昌相继主政。** 商末另一支力量在西方聚集。《周本纪》说，古公亶父遭戎狄逼迫，带着随从离开豳，渡漆、沮，越梁山到岐下；豳地的民众也跟来，在新居筑城设官。古公属意幼子季历，希望日后由季历的儿子昌继承。长子太伯和次子虞仲避往荆蛮；《吴太伯世家》称虞仲为仲雍，并记当地人拥立太伯。季历接位后传给昌，昌后来成为西伯。《周本纪》写伯夷、叔齐等人前来投奔；《齐太公世家》记吕尚归周有几种传说，共同点是他后来成为文王、武王的老师。 [[4]](#note-4)

<a id="punishments"></a>
<a id="4-九侯鄂侯被杀西伯昌也遭到拘禁"></a>
<a id="event-5"></a>
<a id="release-details"></a>

5. **九侯和鄂侯被杀，西伯昌被囚后获释。** 按《殷本纪》的叙述，帝辛加重刑罚，设炮格；九侯被杀，鄂侯为他争辩，也遭杀害。西伯昌私下叹息，崇侯虎告发，帝辛把昌关在羑里。《周本纪》还说，闳夭等人托商臣费仲献上美女、良马和异物，换得西伯获释；帝辛赐西伯弓矢斧钺，准他征伐。西伯献洛西之地，请帝辛除去炮格，帝辛应允。商廷仍倚重费中和恶来，诸侯日渐疏远。 [[5]](#note-5)

<a id="zhou-grows"></a>
<a id="5-西伯的力量增长祖伊向帝辛发出警告"></a>
<a id="event-6"></a>
<a id="wen-campaigns"></a>

6. **西伯的势力向外扩大，祖伊告急。** 西伯获释后，诸侯渐渐来周求决争端。《周本纪》用虞、芮争界作例，说两国人到了周境后主动退让。周随后对犬戎、密须等用兵；攻下一国后，商臣祖伊赶去告警，帝辛仍说自己有天命。西伯又讨伐邘和崇侯虎，把周的都邑从岐下迁到丰。西伯死后，儿子发继位，就是周武王。 文王正妻太姒所生的十个儿子，依次是伯邑考、发、管叔鲜、周公旦、蔡叔度、曹叔振铎、成叔武、霍叔处、康叔封、冉季载。发与旦曾共同辅佐文王；文王立发为继承人，伯邑考则已先去世。 [[6]](#note-6)

<a id="mengjin"></a>
<a id="6-武王第一次会合诸侯还没有立刻决战"></a>
<a id="event-7"></a>
<a id="wu-council"></a>

7. **武王首次在盟津会合诸侯，随后退兵。** 武王继位后，让太公望任师、周公旦辅政，召公、毕公也在左右。《周本纪》说武王先在毕祭祀，再东行到盟津；军中载着文王木主，武王仍自称太子发，表明自己奉文王出师。到盟津会合的诸侯认为可以攻商，武王却说时机未到，领军回去。 [[7]](#note-7)

<a id="court-break"></a>
<a id="7-微子离去比干被杀箕子被囚王廷继续分裂"></a>
<a id="event-8"></a>
<a id="musicians"></a>

8. **微子离去，比干被杀，箕子被囚。** 微子劝谏不被采纳，和太师、少师商议后离开。比干留下劝谏，被帝辛杀死；箕子假装发狂，把自己降为奴仆，仍遭囚禁。商廷的太师疵、少师彊随后携礼乐用的器物投奔周。商王身边的人有人离去，有人受刑，武王也以这些消息向诸侯说明再次伐商的理由。 在这一组传统故事里，箕子从象牙筷子想到奢侈将不断扩张；劝谏不听后，他不愿以离国揭君之恶，选择佯狂为奴、鼓琴自悲。微子则认为君臣以义相合，反复劝谏无效可以离去。三人的不同选择后来同获“三仁”之评，不能压成完全相同的行事。 [[8]](#note-8)

<a id="muye"></a>
<a id="8-甲子日商军在牧野败北"></a>
<a id="event-9"></a>
<a id="muye-orders"></a>

9. **甲子日，武王在牧野击败商军。** 武王再次出兵，与诸侯渡过黄河，在商都郊外的牧野列阵。他在誓师时要求士卒前进若干步、击刺若干次就停下整队，并告诫不要拦阻能奔来投降的人。太公望先率人出击，周军继进；《周本纪》说商兵无心作战，倒转兵器，让周军冲入。帝辛退到鹿台，投火身亡；武王随后斩其首示众。利簋铭文也记武王征商发生在甲子日；本页采用夏商周断代工程的前1046年方案。 [[9]](#note-9)

<a id="feilian-ancestry"></a>
<a id="恶来死于商周更替蜚廉之死另有不同叙述"></a>
<a id="event-10"></a>

10. **恶来在克商时被杀，蜚廉葬于霍太山。** 《秦本纪》把蜚廉、恶来写作父子，父子都凭才能侍奉帝辛；恶来在武王伐商时被杀。书里说蜚廉当时在北方，返回后已无法向商王复命，便到霍太山设坛，死后也葬在那里。这段还带有石棺与铭文的故事。 [[10]](#note-10)

<a id="settlement"></a>
<a id="9-周人先保留了商王后裔再建立自己的统治"></a>
<a id="event-11"></a>
<a id="settlement-more"></a>
<a id="sj032-yingqiu-lai"></a>
<a id="sj031-zhouzhang"></a>

11. **武王安置殷民，又分封同族和功臣。** 克商后，武王在商的社坛行礼，让帝辛的儿子武庚禄父管领一部分殷民，延续殷人的祭祀，派管叔、蔡叔协助。他又释放箕子、修比干墓、表彰商容，拿出鹿台的钱财和钜桥的粮食赈济。周接着分封前代之后、宗室和功臣：吕尚封营丘为齐，周公封曲阜为鲁，召公封燕，管叔、蔡叔分别封管、蔡。吕尚赶到营丘时，莱侯也来争地；《吴太伯世家》则说，武王找到太伯、仲雍之后的周章，承认他已在吴为君，另封其弟于故夏墟。武王还筹划在洛邑营建居处，后来又向箕子问殷亡的缘由。 曹叔振铎、成叔武、霍叔处也各受封国；康叔封和冉季载当时尚幼，这一阶段还未受封。 妫满受封于陈，以承续舜的祭祀；东楼公受封于杞，以承续夏禹的祭祀。 微子也携祭器到周军门前请命，以袒身受缚、牵羊执茅的方式表示臣服；武王解其束缚，使他恢复原位。这还不是后来的正式封宋。 [[11]](#note-11)

<a id="wu-death"></a>
<a id="武王病逝以后幼主面前还有未稳的天下"></a>
<a id="event-12"></a>

12. **武王死后，年幼的成王继位。** 《周本纪》说，武王病重时，新政权尚未站稳，大臣为此忧惧，周公曾祈求代武王受病；武王一度好转，后来去世，太子诵继位为成王。成王年幼，周公怕诸侯叛离，于是代掌王政；管叔、蔡叔等人却怀疑周公的用意。 [[12]](#note-12)

<a id="wugeng"></a>
<a id="10-武王死后武庚再起微子后来被立于宋"></a>
<a id="event-13"></a>
<a id="wugeng-outcome"></a>

13. **周公平定武庚之乱，微子受封于宋。** 武庚与管叔、蔡叔反周。周公以成王之命出兵，杀武庚和管叔，放逐蔡叔。周改由微子在宋承继殷人的祭祀，又划出一部分殷民给受封于卫的康叔。本纪还说，晋唐叔献嘉禾，成王把它转送到周公军中。按《周本纪》，这次战争历三年才平定；周公摄政七年，成王长成，周公归政。 蔡叔流放时获给十乘车、七十名随从。季载随后受封冉；康叔和冉季又受推荐，分别以司寇、司空辅佐成王。 微子在宋继承殷祀，周又以《微子之命》申明其地位；殷遗民拥戴他。 [[13]](#note-13)

<a id="sj038-hongfan-outline-event"></a>

14. **克商后的问政传说以《洪范》九畴总论治道。** 以下回读克商后武王向箕子求教的问答，属于治道篇章，不是武庚之乱后的新事。箕子先以鲧禹的授受故事说明九畴由来，再列五行、五事、八政、五纪、皇极、三德、稽疑、庶征以及五福六极。五行把水火木金土的性质和五味对应起来；五事要求举止恭、言语顺、视明、听聪、思睿。八政分掌食、货、祭祀、土木、教养、刑法、宾客、军事，五纪则安排岁、月、日、星辰与历数。这些是古代政治与宇宙分类，不是某一年已经实行的制度清单。 [[14]](#sj038-hongfan-outline-note)

<a id="sj038-hongfan-huangji-event"></a>

15. **皇极与三德要求统治者守正并调剂刚柔。** 同一问答接着要求君主建立共同准则，把福惠给予百姓，不欺孤弱、不畏显贵、不结党偏私，任用有能力、有操守的人，使正直者有生计。三德是正直、刚克、柔克，须随处境与对象调整；赏罚威福不能任由臣下私掌。这是以天子为中心的政治理想，读时须与实际王政分开。 [[15]](#sj038-hongfan-huangji-note)

<a id="sj038-hongfan-divination-event"></a>

16. **大疑要兼听人谋与卜筮。** 《洪范》的决疑法先择掌卜筮者，三人占断时从两人之言；大事还要询问君主自己、卿士、庶民以及龟卜蓍筮。各方同意称“大同”，意见不同则分情形处理。龟筮共同与人意相反时，主张静守；只有君与龟赞同时，内事、外事又有不同判断。这里保存的是古代决策规范，不叙一场有确年可排的占卜。 [[16]](#sj038-hongfan-divination-note)

<a id="sj038-hongfan-weather-event"></a>

17. **庶征与五福六极把治道联系民生。** 篇章把雨、晴、暖、寒、风的时序与政德对应，认为过度或缺失会损害百谷和生活，又要求君、卿、官分别以岁、月、日察事。它以寿、富、康宁、好德、善终为五福，以凶折、疾、忧、贫、恶、弱为六极。天象与政治之间的对应属于这一篇章的思想，不能当作已经证明的气候机制。 [[17]](#sj038-hongfan-weather-note)

<a id="sj038-jizi-korea-maixiu-event"></a>

18. **箕子封朝鲜与过殷墟，留在传世故事层次。** 克商以后的另一组传说称，武王封箕子于朝鲜，却不以通常臣礼约束他；后来箕子朝周经过殷墟，见宫室荒坏、禾黍生长，作《麦秀》之歌寄托故国之悲，殷人闻歌流泪。这里没有可靠的确年、疆界和迁徙路线，也不能仅凭故事排出朝鲜建国年代。 [[18]](#sj038-jizi-korea-maixiu-note)

<a id="sj039-tangshu-event"></a>

19. **唐叔虞的诞生与封唐，留下了梦兆和桐叶的传说。** 叔虞是武王之子、成王之弟。传说武王梦见天命他将有名虞的儿子，并许以唐地；孩子出生时，手掌纹路又被解释为“虞”字，因而取名虞。武王去世后唐地发生变乱，周公平定。成王与叔虞游戏，把削成圭形的桐叶交给他，戏言封给他；史佚以天子言语须由史官记录、礼乐落实为由请成王践言，叔虞遂受封于唐，唐地被描述为在河、汾以东、方百里。诞生梦兆、掌文与桐叶故事按传说层阅读，受封则系于成王时期，不给它们虚定绝对年份。 [[19]](#sj039-tangshu-note)

<a id="sj040-pengzu-end-event"></a>

20. **彭祖氏的部族传承在商末终结。** 彭祖列在陆终六子之中，其后裔在商代曾为侯伯，至商末被灭；传文没有给出具体王年，也不等于一个人活到商末。 [[20]](#sj040-pengzu-end-note)

<a id="sj040-yuxiong-chu-event"></a>

21. **鬻熊事奉文王，其后裔熊绎在成王时受封楚地。** 季连后裔鬻熊事周而早逝，其后相传为熊丽、熊狂、熊绎。成王追念文武功臣之后，以子男等级的田地封熊绎于楚，居丹阳。熊绎与鲁伯禽、卫康叔子牟、晋侯燮、齐太公之子吕伋一同事成王；这份名单说明诸侯与周室的关系，不强定同一次朝会的日期。 [[21]](#sj040-yuxiong-chu-note)

- 《殷本纪》批评祖甲，《无逸》则称他知道庶民的处境、体恤百姓。两书的说法见[第1条](#note-1)。迁徙记在庚丁名下或武乙即位后，仍不能据此认定发生在哪位商王的哪一年；参见[商王横表](../../sources/摘录/史记-卷013-三代世表.md#t004)和[异文说明](../../meta/考证/史记-卷013-纪年与异说.md#异文与世数)。武乙之子太丁与成汤未继位的儿子太丁是两人。
- 酒池肉林、手搏猛兽见[《殷本纪》P028](../../sources/摘录/史记-卷003-殷本纪.md#p028)，是本纪塑造帝辛形象的材料。子贡谈到天下的恶名容易聚到一人身上，见[《论语集注》所录经文](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%9B%9B%E6%9B%B8%E7%AB%A0%E5%8F%A5%E9%9B%86%E8%A8%BB-%E8%AB%96%E8%AA%9E%E9%9B%86%E6%B3%A8%E5%8D%B7%E5%8D%81.md#ref-30efbc5b4dbfb7)。比干被杀在《殷本纪》《周本纪》均有记载；剖心和七窍的细节见[《殷本纪》P031](../../sources/摘录/史记-卷003-殷本纪.md#p031)。
- 吴的世系按[《吴太伯世家》L2947](../../sources/本地分卷/史记/史记-卷031.md#L2947)是太伯无子，弟仲雍接位，之后是季简、叔达、周章。武王另外封的虞仲是周章之弟。吕尚归周的三种说法分别是渭水相遇、先事商再归周、经散宜生与闳夭邀请。[《齐太公世家》L2999](../../sources/本地分卷/史记/史记-卷032.md#L2999) · [L3000](../../sources/本地分卷/史记/史记-卷032.md#L3000) · [三家注](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E4%B8%89%E5%AE%B6%E8%A8%BB-%E5%8D%B7032.md#ref-0f5bcaac7dde93)。
- 西伯攻下的国名，《殷本纪》写“飢”，《周本纪》写“耆”，《尚书》写“黎”；几篇都把祖伊告警连到这次战事，但地名保留异文。[《周本纪》P011](../../sources/摘录/史记-卷004-周本纪.md#p011)另记文王在位五十年、在羑里演《易》及受命后十年而死，不能据此给文王历次征伐配上公元年。

### 牧野甲子与周初的相对年数

- [利簋铭文及释读](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-d28aaaa133fdafd0.md#cite-2)记武王征商在甲子日，不能直接换算成公元纪年。本页用[断代工程前1046年方案](../../meta/考证/史记-卷003-纪年与异说.md#dates)；[《周本纪》P015](../../sources/摘录/史记-卷004-周本纪.md#p015)记二月甲子，[《齐太公世家》L3003](../../sources/本地分卷/史记/史记-卷032.md#L3003)记十一年正月甲子。两种月序并存，正文只写“甲子日”。
- [《周本纪》P013](../../sources/摘录/史记-卷004-周本纪.md#p013)所记盟津白鱼、赤乌是祥瑞叙事，“八百诸侯”也无名单可校；两次出兵的九年、十一年是本纪相对年数。[P014](../../sources/摘录/史记-卷004-周本纪.md#p014)、[P015](../../sources/摘录/史记-卷004-周本纪.md#p015)、[P016](../../sources/摘录/史记-卷004-周本纪.md#p016)的戎车三百、甲士四万五千、诸侯兵车四千、商兵七十万，各指不同对象，不能合成经证实的兵力。《殷本纪》说武王杀妲己；《周本纪》记两名嬖妾自尽，未点妲己之名。
- [《周本纪》P019](../../sources/摘录/史记-卷004-周本纪.md#p019)说武王纵马放牛、收兵示意休战；[P020](../../sources/摘录/史记-卷004-周本纪.md#p020)把武王问箕子放在“克殷后二年”。[《天官书》P113](../../sources/摘录/史记-卷027-天官书.md#p113)的史佚和社坛的尹佚是否一人，见[古注](../../sources/摘录/史记-卷027-三家注对照.md#p113)。周公摄政七年与讨伐管蔡三年，各指不同阶段；清华简《系年》另记商邑叛周、杀三监并立禄子耿，见[研读札记](../../sources/%E8%A1%A5%E5%85%85%E9%98%85%E8%AF%BB/%E5%BC%80%E6%94%BE%E5%8F%82%E8%80%83/ref-730e33db843eb1f3.md#cite-2)。

### 卷024｜大武六成与商周记忆

[《乐书》P044—P058](../../sources/摘录/史记-卷024-乐书.md#p044)用孔子与宾牟贾问答解释大武之舞，六成依次象征北出、灭商、南向、疆理、分陕、复位尊天子等。它是舞蹈结构及其后世政治解释，不是按六年逐项发生的商周年表；克商、封建、周召分治等阶段仍按本页既有材料分别看。P058将封前代后裔、释箕子、散马休兵等合为理想秩序，也不把微子封宋等后续一律移到克商下车当日。

[P062](../../sources/摘录/史记-卷024-乐书.md#p062)以舜与纣所好之乐对照治乱，属于论证；[P063](../../sources/摘录/史记-卷024-乐书.md#p063)故事称商末师延作乐、投濮水，春秋闻声记录者为师涓。本页《殷本纪》的师涓字样与之有差，原文各存，不将两个时代的乐官强作一个活过数百年的人物。

### 卷025｜武王吹律听声的传说与解释

[《律书》P003](../../sources/摘录/史记-卷025-律书.md#p003)把武王伐纣与吹律听声、杀气和宫音联系起来。它属于古代以声律察军气、解释胜负的说法，不能当作已经验证的军事预测方法，也不由“推孟春以至于季冬”另编一份十二个月的征商作战日历。

所见《索隐》说此事出处未详；[四库本考证](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%8F%B2%E8%A8%98%E9%9B%86%E8%A7%A3%20%28%E5%8F%B8%E9%A6%AC%E9%81%B7%2C%20%E5%9B%9B%E5%BA%AB%E5%85%A8%E6%9B%B8%E6%9C%AC%29-%E5%8D%B7025.md#ref-7162032885e444)则指向《国语》。本次实读[《国语·周语下》景王问律段](../../sources/%E6%9C%AC%E5%9C%B0%E5%BC%95%E7%94%A8/%E5%9C%8B%E8%AA%9E-%E5%8D%B703.md#ref-2fb4fd10182b92)，确见伶州鸠追述武王于牧野以黄钟下宫布戎、入商以太蔟下宫布令等说法。两篇不是字字相同的独立战场记录；既有牧野主线、断代工程的时期口径和同号异说继续保留，不凭音律推算再定一个新的克商年。

### 太史公对周初宗亲的评论

司马迁虽然批评管蔡之乱，仍认为成叔、冉季等宗亲帮助幼主、维持诸侯对周的归属，故将各支附在世家中。他的“十人”是回指兄弟群体，不表示武王死时十兄弟都在世并一同辅政；这段是汉代作者的评论。

**[《史记·管蔡世家》P023](../../sources/摘录/史记-卷035-管蔡世家.md#p023)**

> 太史公曰：管蔡作亂，無足載者。然周武王崩，成王少，天下既疑，賴同母之弟成叔、冉季之屬十人為輔拂，是以諸侯卒宗周，故附之世家言。

# 商末与周初｜王廷分裂，周人取代商王

[← 盘庚与武丁](05-盘庚与武丁.md) · [上古目录](README.md) · [时间总目录](../README.md)

> **范围：武丁之后至商周更替及周初殷人安置。** 商亡采用断代工程前1046年的方案，其他情节不因处于相邻段落而取得确切年份。本文以传世叙事讲清人物和因果；射天、酒池肉林、剖心等所传细节与金文直接支持的征商事实分层阅读，依据放在同号注。

<a id="later-kings"></a>
## 1. 祖庚之后，王位经过几次兄弟与父子间的转移

**祖庚去世，弟弟祖甲接位；再往下是廪辛、庚丁、武乙。** 本纪对这几位君主多是短记，因此先将继承关系列清，不用一句“商衰”替所有人补出相同的政治经历。[原文与说明](#s1)

| 次序 | 本纪所列王名 | 继承关系及阅读提醒 |
|---|---|---|
| 1 | 祖庚 | 武丁之子，接位已见上一页 |
| 2 | 祖甲，又称帝甲 | 祖庚之弟；不同文献对他的施政评价不一致 |
| 3 | 廪辛 | 祖甲之子 |
| 4 | 庚丁 | 廪辛之弟；与太庚、盘庚不是同一人 |
| 5 | 武乙 | 庚丁之子；迁居河北记载的王世归属有异，见下文说明 |
| 6 | 太丁 | 武乙之子；商末的太丁，不是成汤之子太丁 |
| 7 | 帝乙 | 太丁之子 |
| 8 | 帝辛 | 帝乙之子，即后世通常所称的纣 |

<a id="sj013-migration"></a>
**在庚丁、武乙前后的传承中，还记有商王室向河以北迁居。** 这是原有迁居线索的补充，并不是因为换了一位君主，就能再确定一次走相同路线的迁都。具体王世与地点的差别见[同一事件的史料说明](#sj013-migration-note)。

<a id="wuyi"></a>
## 2. 武乙的射天故事，与一次雷暴中死亡相连

**武乙被写成故意戏弄神明的人。** 所传故事说，他制作偶人称为天神，让人代它博戏，偶人输了就加以侮辱；又把血装入皮囊，仰射皮囊，称为射天。后来他在河、渭之间狩猎，遇暴雷而死。[原文与说明](#s2)

武乙死后，太丁、帝乙相继在位。本纪没有在这里展开他们的完整政事；将名号和继承关系保留，比套用武乙的故事替他们补写一段生平更可靠。[原文与说明](#s2)

<a id="dixin"></a>
## 3. 帝乙的长子没有继位，接位的是辛

**微子启年长，辛年幼，但辛因母亲的正后身份取得继承位置。** 帝乙死后，辛成为商王。本纪所给的原因是母亲地位与继承资格，并不是兄弟年龄排序本身。[原文与说明](#s3)

帝辛的朝廷积聚财物、粮食与珍玩，扩大宫室和沙丘苑台。师涓制作乐舞，妲己受到宠爱；夜饮、酒池肉林等描写，则构成传世文献对宫廷生活的强烈批评。[原文与说明](#s4)

<a id="zhou-family"></a>
## 另一支力量在岐下聚集：古公迁居与季历继承

**公刘以后，周人的世系依次接到庆节、皇仆、差弗、毁隃、公非、高圉、亚圉、公叔祖类，再到古公亶父。** 古公仍住豳时，戎狄先索财物，后来要求土地与人口。他不愿让人为了保住自己而送死，带着亲近者迁往岐山下，豳人和附近归附者也相继跟来。

**卷十三《三代世表》把这条周人先公谱系向上接回帝喾和后稷，并把黄帝至武王合计为“十九世”。** 这不是十九位周王：后稷、古公、季历乃至西伯昌都不等于后来王朝中按年即位的周天子。与卷四一样，表文没有给出不窋、公刘至古公每个人能够核实的在位公元年份。[完整周先公链](../../sources/摘录/史记-卷013-三代世表.md#t004) · [谱系与王年](../../meta/考证/史记-卷013-纪年与异说.md#异文与世数)

到了岐下，周人改变原先穴居的环境，营筑城郭房屋，分设官职。古公的三个儿子是太伯、虞仲和季历；季历娶太任，生昌。太伯、虞仲知道父亲想传位给季历一支，便离开赴荆蛮，以不同习俗表明退让。古公死后，季历继承，继续维系诸侯归附；季历死后，昌接位，就是下文的西伯。

<a id="sj031-taibo-descendants"></a>
**太伯让位不意味着吴地这一支从此失去后继。** 太伯在当地号为句吴的故事，属于吴国追述的起源；他死后没有儿子，弟弟仲雍接位，再传季简、叔达、周章，前后跨过好几代。这里交代的是一支宗族的承接，**不能把后面数代人都写成古公或季历当年同时活动**。其后周章受封与周北虞国分支见[武王克殷后的安置](#sj031-zhouzhang)。[卷031 P001起源](../../sources/摘录/史记-卷031-吴太伯世家.md#p001) · [卷031 P002继承](../../sources/摘录/史记-卷031-吴太伯世家.md#p002)


西伯昌礼遇老人，也不断接纳投奔的人。伯夷、叔齐、太颠、闳夭、散宜生、鬻子、辛甲等先后来归。周的力量由此不只是一个不断增长的家族，还包括围绕它聚合的人才与盟友。 [原文与说明](#sj004-zhou-family)

<a id="sj032-lvshang-first"></a>
**吕尚进入周人的辅佐集团，成为西伯的重要谋臣。** 他本姓姜，以先人的吕地封号为氏，后世称为太公望、师尚父。关于家世，传说他来自东海一带，先祖任四岳、辅佐禹治水，受封于吕或申；到夏商时期，后代有人保有封地，有人成为平民。入周前贫困、年老才遇合的经历，也保存在他的身世叙述中。这里先交代这位人物，不能据这些传说倒推出出生、垂钓或归周的绝对年。[^sj032-p001]

[^sj032-p001]: **卷032 P001｜归周三说与未定年。** 《齐太公世家》先写西伯出猎，在渭水北岸遇到垂钓的吕尚，交谈投契，同车载归而尊为师；“太公望”的称号，在这则故事中由西伯追述先君期盼贤人而来。另有一说，吕尚曾事纣，离开后游说诸侯不遇，最终西归；又一说，他隐居海滨，西伯被囚羑里时由散宜生、闳夭招来，三人搜求美女奇物营救西伯。三说是不同的来历传承，不串成三次归周；本段阅读位置也不表示营救故事发生在被囚以前。篇末以吕尚为文、武之师作共同结论。《索隐》还保留“尚”“牙”的名、字解释差别；不据注家所引年龄和异迹另造生年。见[卷032原文](https://zh.wikisource.org/wiki/史記/卷032)及[三家注首段](https://zh.wikisource.org/wiki/史記三家註/卷032)。

<a id="punishments"></a>
## 4. 九侯、鄂侯被杀，西伯昌也遭到拘禁

**帝辛加重刑罚以后，王廷与诸侯的冲突进一步扩大。** 九侯献女入宫，女子触怒帝辛，父女被杀；鄂侯激烈争辩，也被杀。西伯昌听到这些事私下叹息，崇侯虎将其反应报告帝辛，西伯遂被囚在羑里。[原文与说明](#s5)

西伯的臣属闳夭等搜求美女、奇物和良马进献，才使西伯获释。出狱后，西伯献洛西之地，请求除去炮格之刑，帝辛答应，并赐弓矢斧钺，使他得以征伐。与此同时，费中、恶来受到任用，诸侯对王廷越来越疏远。[原文与说明](#s5)

<a id="release-details"></a>
**营救西伯并非只送一次笼统的礼物。** 闳夭等搜求有莘氏女子、骊戎文马、有熊九驷及其他奇物，经费仲献给帝辛。西伯获释后，被告知告发来自崇侯虎；随后献洛西之地，请除炮格。 [原文与说明](#sj004-release-details)


<a id="zhou-grows"></a>
## 5. 西伯的力量增长，祖伊向帝辛发出警告

**西伯回去以后，更多诸侯转向周，帝辛的权势随之受到削弱。** 比干劝谏未被接受，受到百姓敬重的商容又被废黜。[原文与说明](#s6)

西伯攻灭一国以后，祖伊赶来告急。他把危险归到帝辛的施政：民众失去安定生活，希望王朝受罚；君主不能认为祖先和天命会永远替自己兜底。帝辛却以自己受命于天作答，祖伊退下后认为已无法再劝。[原文与说明](#s6)

<a id="wen-campaigns"></a>
**虞、芮为田界争执来求裁断，走进周地以后，先看到当地人让田界、让长者。** 两方觉得自己的争端有愧，尚未见到西伯便相让而返。这则故事把诸侯转向周的原因放在日常秩序上，而不只放在战争上。

其后西伯先后征犬戎、密须、耆、邘、崇。耆被攻灭，正是祖伊向帝辛告急的那次事件；“耆”“黎”和卷003的异字不拆成几场不同战争。攻崇之后，周人在丰营建，离岐而居丰。西伯死，太子发继承。

文王在位五十年、在羑里演《易》、受命后十年而死，以及后人追尊古公、季历为王，都属于这段保存的解释与年数，不能只凭这些数字便倒推出每一役的绝对年。 [原文与说明](#sj004-wen-campaigns)


<a id="mengjin"></a>
## 6. 武王第一次会合诸侯，还没有立刻决战

**西伯昌死后，周武王率兵东行，到盟津与反商诸侯会合。** 诸侯要求进兵，武王却认为时机未到，领军回去。本纪所记的盟津会合和后来的牧野决战是两次行动，不能合并成“到了盟津便在当天灭商”。[原文与说明](#s7)

<a id="wu-council"></a>
**发接位以后，让太公望为师，周公旦为辅，召公、毕公等也围绕他办事。** 这批人各有承担，并不是只有武王一人作全部决定。到第一次盟津会合时，武王先在毕祭告，奉文王木主随军，仍把这次行动解释为承接父亲事业。 [原文与说明](#sj004-wu-council)


<a id="court-break"></a>
## 7. 微子离去、比干被杀、箕子被囚，王廷继续分裂

**微子多次劝谏无效，与大师、少师商议后离开。** 比干仍坚持进谏，被帝辛杀死；箕子恐惧，装作疯癫、沦为奴役，后来又被囚禁。大师、少师携祭祀与乐用器物逃往周方。[原文与说明](#s8)

几个人并不是同时采取同一种办法：有人离开，有人留下强谏，有人隐忍求存，有人带走器物投向对手。把这些分别讲清，才能看出王廷关系如何一步步破裂。[原文与说明](#s8)

<a id="musicians"></a>
**周方又接到商朝乐官携器物而来的消息。** 卷四把出走者记为太师疵、少师彊，并在武王与诸侯将领商议继续进军的背景下叙述他们。商廷内部的离散，和外部联军的动员由此连在一起。 [原文与说明](#sj004-musicians)


<a id="muye"></a>
## 8. 甲子日，商军在牧野败北

**武王再次率诸侯出兵，帝辛发兵到牧野抵御，商军在甲子日战败。** 帝辛退回鹿台，穿上饰有宝玉的衣服，赴火而死。武王斩下他的头悬于大白旗；商王嬖妾的结局，两篇本纪的细节不同，见同号说明。[原文与说明](#s9)

与前面的盟津之会不同，这次败战结束了帝辛的统治。利簋铭文对武王在甲子日清晨征商提供了出土文字依据；但它并不逐一证明本纪所记的宫廷逸事，也不是一件自身写有“公元前1046年”的文物。[原文与说明](#s9)

<a id="muye-orders"></a>
**再次出兵以前，武王召集诸侯，宣布商王罪状，联军渡河后逼近商郊。** 太公望先驱，周公等分辅军政；在牧野誓师时，武王向诸国君长和军职人员提出行军、整队与接敌要求：前进几步便校正队形，数次攻击以后仍要停下整顿，不要阻挡已经奔来的降者。

开战时，太公率先进击，武王的大队随后跟上；商军一方出现倒戈，阵势瓦解。这补出了前文“甲子日战败”的过程，不是另一场牧野之战。 [原文与说明](#sj004-muye-orders)

<a id="feilian-ancestry"></a>
## 恶来死于商周更替，蜚廉之死另有不同叙述

商末为纣服务的恶来，是蜚廉之子；其家又上承经营西垂的中潏。恶来随商王朝覆灭而死。父子同样以才能获用，后来命运却在不同本纪中留下差别：恶来的死亡可与前文接合，蜚廉的归来、死亡则只保留为异说。 [原文与说明](#sj005-004-note)


<a id="settlement"></a>
## 9. 周人先保留了商王后裔，再建立自己的统治

**战后，武王释放箕子，培封比干之墓，表彰商容的居处，又让帝辛之子武庚禄父延续殷祀。** 他要求武庚修行盘庚之政，试图以商人熟悉的祖先政治传统安顿商的遗民，而不是把所有旧王族一并消灭。[原文与说明](#s10)

武王成为天子，商的后人转为周之下的诸侯。本纪在这一处又讨论“帝”与“王”的称号，属于作者对历史名号的解释，不另造一次有确日的改名仪式。[原文与说明](#s10)

<a id="settlement-more"></a>
**战后第二天，周人先除治道路、整修社坛，再在殷众面前举行受命仪式。** 毛叔郑、卫叔封、周公旦、召公奭、毕公等分任仪仗与辅导，尹佚读祝文，以商王失德、周受命解释更替。民众被告知不必惊惧。

周人不只安置武庚，还让管叔、蔡叔在旁协助约束殷地；同时释放囚徒，取出鹿台财物、钜桥积粟散给民众。旧王朝后裔与功臣分别获得封地：黄帝、尧、舜、禹之后，以及齐、鲁、燕、管、蔡等国，都列在这套战后安排中。封地不等于相关人物同一天已经在当地建成完整国家。

<a id="sj031-zhouzhang"></a>
**吴国的周章不是到武王克殷这时才成为君主。** 他在此以前已接续仲雍、季简、叔达一系治理吴地；周武王寻得这支宗亲时，确认他在吴的地位，同时另将周章的弟弟封在故夏虚的虞地。一个是吴国原有统治获得承认，另一个是中原虞国受封，不能并成一次「周章由吴迁虞」；相关君主的个人即位年份尚不能独立求出。[卷031 P002原文与校勘](../../sources/摘录/史记-卷031-吴太伯世家.md#p002) · [同名虞仲三家注](https://zh.wikisource.org/wiki/史記三家註/卷031)


天下初定，武王仍为未安的地方忧虑，夜里不能入睡。他与周公谈到在洛、伊一带营建、安置四方的计划，又在回师时放马、放牛，表示暂息兵事。克殷后二年，他还向箕子询问天道。 [原文与说明](#sj004-settlement-more)


<a id="wu-death"></a>
## 武王病逝以后，幼主面前还有未稳的天下

**武王病重时，周公请向神明祈告，希望自己代替武王承担灾难。** 这是周公在文献中表明与王室关系的方式，不是已经证实的祈祷换命。武王后来去世，太子诵继位，即成王；成王年幼，周公开始代行政事。

管叔、蔡叔等对这种安排产生疑虑，武庚也参与其间，战后刚建立的政治秩序再次破裂。 [原文与说明](#sj004-wu-death)

<a id="wugeng"></a>
## 10. 武王死后，武庚再起，微子后来被立于宋

**最初的安排并没有终结冲突。** 武王死后，武庚与管叔、蔡叔联合，成王命周公加以讨伐；周人后来立微子于宋，使他延续商的后祀。[原文与说明](#s11)

这一连串事发生在武王死后，不放到牧野战败的同一年，也不因为本篇用一句话写完，就把商亡、周公出征、封宋压成同一天。本轮卷四增补了这些现有位置，周初的治理继续见下一时期。[原文与说明](#s11)

<a id="wugeng-outcome"></a>
**周公奉成王命征讨以后，武庚、管叔被诛，蔡叔被放逐，处置并不相同。** 微子封宋，康叔又领受一部分殷民而建立卫国。唐叔得到嘉谷、成王把谷交到周公军中的故事，与《归禾》《嘉禾》等篇名连在一起。传世叙事说这次讨伐历时三年，周公摄政七年后归政；平乱与归政是不同阶段，不因连写在一段便同年完成。 [原文与说明](#sj004-wugeng-outcome)


## 原文与出处

<a id="s1"></a>
### S1｜王序与祖甲评价

[卷003 P023—P027](../../sources/摘录/史记-卷003-殷本纪.md#p023)。本纪用负面短评写祖甲，《无逸》却赞其知民间疾苦、保惠庶民，并给出享国三十三年。正文不把“祖甲使商衰败”写成无争议事实；也不只凭一篇褒辞倒转成所有政绩均已证实。见[《无逸》](https://zh.wikisource.org/wiki/尚書/無逸)。

<a id="s2"></a>
### S2｜射天、迁居及两个太丁

[卷003 P025—P026](../../sources/摘录/史记-卷003-殷本纪.md#p025)。本纪在武乙前后还写离亳徙河北；正文保留这一迁居记录，不无条件宣传“盘庚以后再无任何迁动”。射天和雷死是所传叙事，不能认定雷暴是对行为的自然报应。此处太丁与成汤早逝太子年代、父亲不同；本轮仍保留本纪王名，不为此另配精确王年，更不把两位并为一人。

<a id="sj013-migration-note"></a>
**卷013互见：迁河北的王世有差别。** [《三代世表》殷段](https://zh.wikisource.org/wiki/史記/卷013#殷)把“殷徙河北”接在庚丁条；[《殷本纪》](https://zh.wikisource.org/wiki/史記/卷003)则在庚丁死、武乙立以后记“殷复去亳，徙河北”。本页不把两处近似记载拆成庚丁、武乙各迁一次，而在同一时期保留归属差别。河北在这里是河流方位，不是现代河北省；目的地、路线及绝对年，不能只靠这几句确定。其与殷墟考古分期怎样对应仍待专题核对，文字互见不等于两次迁都或某一现代遗址已获证实。

<a id="s3"></a>
### S3｜微子与帝辛

[卷003 P027](../../sources/摘录/史记-卷003-殷本纪.md#p027)用“母贱”“正后”解释不能承嗣与取得继承资格。本页据此叙述这项传世解释，不宣称已核定商代所有嫡庶规则。微子启也不是夏王启。

<a id="s4"></a>
### S4｜宫廷批评不等于现代调查记录

[卷003 P028](../../sources/摘录/史记-卷003-殷本纪.md#p028)从才能、拒谏、宠妲己写到厚赋、鹿台、钜桥、苑台、歌舞与长夜之饮。关于捷辩、材力与自矜的开篇，是本纪人物描写；本页没有把手格猛兽当作现代测得的能力。厚赋入鹿台、钜桥以及广苑搜求珍禽奇物，合在宫廷积聚一节；“慢于鬼神”保留为古书的宗教性批评。不把“好女色”作为本项目替王朝覆亡作出的单一解释，更不添加狐妖等后世小说情节。《论语·子张》所记子贡已提醒，恶名可能使各种罪过都归到一人身上；这也不是替帝辛一概翻案的证明。见[《论语集注》卷十所载经文](https://zh.wikisource.org/wiki/四書章句集註/論語集注卷十)。

<a id="s5"></a>
### S5｜处刑、西伯被囚与获释

[卷003 P029](../../sources/摘录/史记-卷003-殷本纪.md#p029)完整保留九侯、鄂侯尸体被辱的记载。炮格的具体构造未在该段说明，不靠小说补造刑具；西伯在本段前后已以该称号出现，赐征伐权不径直解成此时才第一次获得一切身份。

<a id="s6"></a>
### S6｜饥国、黎国与祖伊告急

[卷003 P030](../../sources/摘录/史记-卷003-殷本纪.md#p030)所读版本作“饥国”，[《尚书·西伯戡黎》](https://zh.wikisource.org/wiki/尚書/西伯戡黎)写“西伯既戡黎”，接祖伊奔告；此处先写攻灭一国，不凭这个异字杜撰两场战争。祖伊与祖己分开；告辞、帝辛答语为所传言辞，非可验证的现场实录。下一卷核读西伯战争时再合并其更具体时间线。

<a id="s7"></a>
### S7｜盟津与八百

[卷003 P030](../../sources/摘录/史记-卷003-殷本纪.md#p030)说来会诸侯八百，且明记武王退归。八百作为原载数字保留在这里，不视为逐国清点的现代统计，不由它自算两年或若干月后必然发生牧野之战。

<a id="s8"></a>
### S8｜三人不同的处境与乐官出走

[卷003 P031前部](../../sources/摘录/史记-卷003-殷本纪.md#p031)将剖心与七窍之说联系；正文记比干被杀，细节留原文，不当成解剖知识。大师、少师在此是人员称谓，出走者不另补私人姓名。箕子装狂与被囚不写成真实病情诊断。

<a id="s9"></a>
### S9｜征商有出土证据，绝对年另有推算

[卷003 P031中部](../../sources/摘录/史记-卷003-殷本纪.md#p031)记甲子战败及帝辛结局。中国国家博物馆的[利簋藏品说明](https://www.chnmuseum.cn/zp/zpml/kgfjp/202108/t20210802_250931.shtml)释出武王征商、甲子朝的铭文。前1046年采用工程方案，依据见[年代说明](../../meta/考证/史记-卷003-纪年与异说.md#dates)，不声称只读利簋就能独立得出这个绝对年，也不在本轮另给公历月日。

<a id="s10"></a>
### S10｜战后安置与称号

[卷003 P031后部](../../sources/摘录/史记-卷003-殷本纪.md#p031)写释箕子、封比干墓、表商容闾、封武庚、使修盘庚之政。“封比干之墓”不是说比干复活后受封；武庚与禄父为同一人，不列成两位商后。

<a id="s11"></a>
### S11｜武庚之役不能挤进灭商当天

[卷003 P032](../../sources/摘录/史记-卷003-殷本纪.md#p032)明确以“周武王崩”另起后事。人物与先后全留，卷四已补出武庚、管叔被诛、蔡叔被放逐；仍不能从“诛之”扩大为所有参加者同日同样处死。

<a id="s12"></a>
### S12｜太史公论与七个姓氏

[卷003 P033](../../sources/摘录/史记-卷003-殷本纪.md#p033)说明契的材料以《颂》排次，汤以下采《书》《诗》；又列殷、来、宋、空桐、稚、北殷、目夷七氏，以及殷车与尚白的评论。它们属于作者的来源和后世传承说明，不改编成商亡当年的七次分封，不把文本姓氏表当作现代遗传学证明。

<a id="sj004-zhou-family"></a>
### 卷四补充｜另一支力量在岐下聚集：古公迁居与季历继承

[卷004 P004](../../sources/摘录/史记-卷004-周本纪.md#p004) · [卷004 P005](../../sources/摘录/史记-卷004-周本纪.md#p005) · [卷004 P006](../../sources/摘录/史记-卷004-周本纪.md#p006) · [卷004 P007](../../sources/摘录/史记-卷004-周本纪.md#p007)。 太姜为古公正妃，太任为季历之妻，两代不混。原文描述太伯、虞仲文身断发，作为离开继承秩序的叙事，不用来推定所有吴地人的统一习俗。昌出生祥瑞保留于P005，不作确年证据。祖先世系跨多代，读于此不等于与商末诸王逐个同时。

<a id="sj004-release-details"></a>
### 卷四补充｜西伯获释

[卷004 P008](../../sources/摘录/史记-卷004-周本纪.md#p008)。 卷003侧重西伯私叹后被囚；卷004又写崇侯虎以西伯积善聚众、将不利于帝辛相告。两说解释同一次拘禁，不另立第二次入狱。美女、马匹、弓矢斧钺按传世叙述保存，不能证明每次交付的精确日期。

<a id="sj004-wen-campaigns"></a>
### 卷四补充｜西伯征行

[卷004 P009](../../sources/摘录/史记-卷004-周本纪.md#p009) · [卷004 P010](../../sources/摘录/史记-卷004-周本纪.md#p010) · [卷004 P011](../../sources/摘录/史记-卷004-周本纪.md#p011)。 P010反复使用“明年”排列战争，保留相对先后。P011对文王“称王”的叙述是后来的受命观念，不把全篇仍使用的西伯称谓一律改成当时已普遍接受的王号。

<a id="sj004-wu-council"></a>
### 卷四补充｜盟津与武王辅臣

[卷004 P012](../../sources/摘录/史记-卷004-周本纪.md#p012) · [卷004 P013](../../sources/摘录/史记-卷004-周本纪.md#p013)。 P013称“九年”，P014称“十一年”，本轮保留其相对纪年，未判为武王即位后独立重新起算的九年、十一年。白鱼入舟、赤鸟化乌是兆瑞传统；八百诸侯为原载，不作现代统计。

<a id="sj004-musicians"></a>
### 卷四补充｜商朝乐官出走

[卷004 P014](../../sources/摘录/史记-卷004-周本纪.md#p014)。 卷003只列大师、少师而未写姓名；此处补入卷004所载名字，不再制造另一组同时携器出逃的乐官。比干、箕子遭遇已见本节，不重写。

<a id="sj004-muye-orders"></a>
### 卷四补充｜牧野军令与败战

[卷004 P014](../../sources/摘录/史记-卷004-周本纪.md#p014) · [卷004 P015](../../sources/摘录/史记-卷004-周本纪.md#p015) · [卷004 P016](../../sources/摘录/史记-卷004-周本纪.md#p016)。 P014甲士四万五千、戎车三百，P015诸侯兵车四千，P016商军七十万，分属不同叙述对象，原数都保留在引文，不能相加当作核实兵力。十一年十二月戊午渡河、二月甲子至牧野，属古纪年体系，未转换公历月日。卷003说杀妲己；卷004写两名嬖妾已自杀，武王又射尸斩首，二者并不完全一致。正文不再无条件指定妲己的被杀方式；原有记载改为说明中的异说。

<a id="sj004-settlement-more"></a>
### 卷四补充｜战后安置与营洛

[卷004 P017](../../sources/摘录/史记-卷004-周本纪.md#p017) · [卷004 P018](../../sources/摘录/史记-卷004-周本纪.md#p018) · [卷004 P019](../../sources/摘录/史记-卷004-周本纪.md#p019) · [卷004 P020](../../sources/摘录/史记-卷004-周本纪.md#p020)。 P018“封比干墓”是整治墓葬，不是给在世比干封国。P019归马牛是叙事中的息兵表示，不据此宣布周人以后不再战争。P020只说问天道，不能把他卷《洪范》全文假装已在本段展开。洛邑营建计划不等于武王立即定都洛邑，参见卷末太史公说明及下一时期。

<a id="sj004-wu-death"></a>
### 卷四补充｜武王病逝以后，幼主面前还有未稳的天下

[卷004 P021](../../sources/摘录/史记-卷004-周本纪.md#p021) · [卷004 P022](../../sources/摘录/史记-卷004-周本纪.md#p022)。 卷004没有在武王病逝这几句给出可独立换算的公元年，本轮不按前1046方案擅自补成某一年。太子诵与文王太子发不是同一代。

<a id="sj004-wugeng-outcome"></a>
### 卷四补充｜武庚之役与归政

[卷004 P022](../../sources/摘录/史记-卷004-周本纪.md#p022)。 更早清华简《系年》相应段有商邑兴反、杀三监、立禄子耿的不同叙述，现读到的整理讨论见[清华读书会研读札记](https://fdgwz.org.cn/Web/Show/1760)。它与传世“管蔡同武庚反”不能逐句等同；此处叙事暂保留传世主线，明确异说，不声称独立证实所有动机。“鲁天子之命”是工作TXT的可疑字句，原样保留，不擅造一次鲁国天子册命。

## 补充史料与异说

<a id="sj005-004-note"></a>
### sj005-004｜恶来死于商周更替，蜚廉之死另有不同叙述

[卷005 P003](../../sources/摘录/史记-卷005-秦本纪.md#p003)。

**说明：**《殷本纪》写杀蜚廉，《秦本纪》则说蜚廉当时在北方，回来后在霍太山设坛报命，得带铭文石棺，死后葬在那里。两者不能同时改写成确定的时间线。原文“为纣石北方”字句可疑，不擅补出确切使命；石棺神授也不作为出土证明。

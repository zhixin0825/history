# 西周｜从成康治理到厉王危机

[← 商末与周初](06-商末与周初.md) · [上古目录](README.md) · [全部时间](../README.md) · [继续：前841年 →](../bce-0900-0801/bce-0841.md)

> **范围：成王亲政前后至厉王出奔以前。** 这里按事件先后与王序阅读，不按同一精度给所有早周故事配公元年。前1046年的克商采用工程方案；相对年数、制度性长段和史家评论仍分层。从共和元年前841年起，接入按世纪排列的年度页。

<a id="return"></a>
## 1. 成王开始亲政，周人仍同时经营西土与东方

**周公归政以后退回臣位，成王承担王政。** 摄政七年是本纪的相对年数，不在这一页虚拟七张年度文件。成王住丰，召公继续营建洛邑，周公又复核卜居；周人把洛邑看成四方道路较均衡的中心，安置九鼎，并迁入一部分殷民。

这不是“周一灭商就只剩洛阳一个都城”。宗周的丰、镐与东方成周同时具有作用；本纪末尾也明确反对把武王克商后立刻定都洛邑当成简单结论。 [原文与说明](#s1)

<a id="east"></a>
## 2. 东方仍有反抗，征奄、淮夷与迁民相继展开

**平定商邑以后，东方的局势仍不完全听命于周。** 周公、召公辅政，周人向淮夷、奄等地进兵，又迁徙被征服地区的君主与民众。成王从奄归来，在宗周告诫各方，礼制、官职和地域秩序也在这些行动中逐渐安排。

东方息慎来贺，王又以相关赏赐和文告回应。这类朝贡、文告与征服记事连在一起，说明周初统治仍须经营，不是牧野一战便把所有地方永久统一。 [原文与说明](#s2)

<a id="cheng-kang"></a>
## 3. 成王留下辅佐安排，康王在祖庙中接位

**成王临终前担心太子钊不能独当其任，命召公、毕公带领诸侯辅佐。** 成王死后，太子在先王庙中受命，两位辅臣重新说明文王、武王创业艰难，要求节俭、少欲、守信。钊继位，是为康王，再向诸侯申明继承文武事业。

康王又命毕公安排成周郊外居民的居里。成康时期“刑措四十余年不用”的说法，表现后人对安宁政治的理想概括，不能当成一份证明全国四十年没有任何刑案的统计。 [原文与说明](#s3)

<a id="zhao"></a>
## 4. 昭王南行未归，穆王继承一个出现困难的王室

**康王死，儿子昭王瑕继位。** 昭王南巡没有回来，死在江上，王室没有照常向诸侯报丧；传世解释说，这是在避讳这场死亡。它没有在本段写出胶船、沉船阴谋或确定的落水地点，正文也不补这些细节。

昭王之子满继位，即穆王。本纪说他即位时已五十岁，并记他命伯臩申明太仆的职责，以恢复被认为已衰的文武旧制。年龄照原书保存，但不据此给其出生建立一个确年页面。 [原文与说明](#s4)

<a id="mu-expedition"></a>
## 5. 祭公劝穆王不要为显示武力远征犬戎

**穆王准备讨犬戎，祭公谋父反对，理由不只是怕打不赢。** 他先说军队应在需要时使用，而不能常拿来炫耀；治理应使民众明白利害、发展生产、改善器用。讲到先世时，他从后稷、不窋重述到文武，说明祖先的战争在其叙事中是为除民害，不应变成好战。

接着他把不同区域的义务分开：邦内甸服、邦外侯服、侯卫宾服、夷蛮要服、戎翟荒服，各有祭、祀、享、贡、王的联系，频率也不同。若一方不来，应先修正自己所施的教化与名分，逐层采用告诫、责让等手段，而不是一开始便让民众远征。

穆王没有采纳，仍出兵，带回四只白狼、四只白鹿。叙事随即说远方荒服不再前来。所得奇兽与疏远后果并列，正是本段的结尾；不能只写“远征大胜”而删掉劝谏和代价。 [原文与说明](#s5)

<a id="punishments"></a>
## 6. 甫刑把审案、疑罪与赎罚联系起来

**诸侯之间有不睦，甫侯向王谈刑罚的整治。** 文告先要求两方到场、审听不同陈述，再核对事实；不能轻易定刑时，要检查罚与过的层次，对仍有疑问的刑罚保留赦免的可能。它把审案责任放在用刑者身上，不是只罗列残酷刑名。

随后分别列黥、劓、膑、宫、大辟及其疑罪赎罚，使用百率、倍洒、倍差、五百率、千率等数语。最后按刑类列一千、一千、五百、三百、二百，合为三千。这里记录的是古书法制观念，未把赎罚换成现代货币，也不把各刑类条数当成已经出土的三千份法条全文。 [原文与说明](#s6)

<a id="succession"></a>
## 7. 共、懿、孝、夷之间，继承也不是一直父子相传

**穆王死后，共王繄扈继位；其后依次是懿王、孝王、夷王，再到厉王。** 懿王是共王之子，孝王却是共王之弟；孝王死后，诸侯又立懿王之子燮，即夷王。王位在两支之间转回，不能简单写成五次父传子。

共王还有一则密康公故事：三名女子奔向密康公，其母劝他献给共王，以拥有美物过多、可能招祸相警。密康公没有献，次年共王灭密。本页保留战争与其传世故事，却不采用“女子是灾祸根源”作解释，也不把母亲的话当成已证实的全部战争原因。 [原文与说明](#s7)

<a id="li"></a>
## 8. 厉王任用荣夷公，王室与民众的冲突逐渐积累

**夷王之子胡继位，即厉王，后来重用主张专利的荣夷公。** 芮良夫反对把百物所出的利益独占，认为为王者应当引导利益在上下之间流通；独占会使更多人怨恨，甚至使普通人难以生活。厉王仍让荣夷公做卿士。

对施政的不满扩大以后，厉王又让卫巫监视批评者，告发者一到便杀人。人们不敢开口，只在路上以眼色示意。召公认为这不是消除了怨言，而是把出口堵住：民怨如壅水，越堵越可能突然决裂；君主应当通过公卿、乐人、史官、百工、庶人和老人听到不同意见，再决定施政。

厉王没有听从，危机终于转成公开反抗。具体经过接到[前841年](../bce-0900-0801/bce-0841.md)，从这里起用年度页接续。 [原文与说明](#s8)

## 原文与出处

<a id="s1"></a>
### S1｜成王开始亲政，周人仍同时经营西土与东方

[卷004 P022](../../sources/摘录/史记-卷004-周本纪.md#p022) · [卷004 P023](../../sources/摘录/史记-卷004-周本纪.md#p023) · [卷004 P082](../../sources/摘录/史记-卷004-周本纪.md#p082)。 叙述成王营建不据本纪顺叙推出每件事都在归政之后同年完成。“天下之中”是当时空间观念，不是现代全国几何中心。《召诰》《洛诰》《多士》《无佚》等篇名在P023作相关文献线索；未把今传文本的全部内容自动算成本卷正文。

<a id="s2"></a>
### S2｜东方仍有反抗，征奄、淮夷与迁民相继展开

[卷004 P023](../../sources/摘录/史记-卷004-周本纪.md#p023)。 工作TXT“迁其君薄泵”字句可疑；叙事只保留迁其君，不把薄泵硬配为现代地名。原文列《多方》《周官》《贿息慎之命》等，完整篇名及原字见引文。本轮没有重建全部东征军线。

<a id="s3"></a>
### S3｜成王留下辅佐安排，康王在祖庙中接位

[卷004 P024](../../sources/摘录/史记-卷004-周本纪.md#p024)。 P024将康王即位文告标作《康诰》，与今传《康王之诰》的篇名层次有别；引文不静默改字。成王临终、康王即位、《毕命》是几个场景，不因合读便合成一次政令。

<a id="s4"></a>
### S4｜昭王南行未归，穆王继承一个出现困难的王室

[卷004 P025](../../sources/摘录/史记-卷004-周本纪.md#p025)。 臩命的字形、今传书篇与出土简篇并非本轮已经完整解决的版本问题；这里仅述本纪记任命、作命。昭王死于江上是文本事件，“讳之”则是史家的解释。

<a id="s5"></a>
### S5｜祭公劝穆王不要为显示武力远征犬戎

[卷004 P026](../../sources/摘录/史记-卷004-周本纪.md#p026)。 此段五服为甸、侯、宾、要、荒，和禹贡叙述的甸、侯、绥、要、荒不同，不强行统一名称。“日祭、月祀、时享、岁贡、终王”是文献中的礼制分等，不证明已实际覆盖一个等距同心圆疆域。

<a id="s6"></a>
### S6｜甫刑把审案、疑罪与赎罚联系起来

[卷004 P027](../../sources/摘录/史记-卷004-周本纪.md#p027)。 疑赦、赎罚与核罪各有步骤，不译成任何罪名都能随意用钱买免。书名用本纪《甫刑》，异称与术语解释仍需专题核对；本轮保留原字，不提供现代法律上的类比结论。

<a id="s7"></a>
### S7｜共、懿、孝、夷之间，继承也不是一直父子相传

[卷004 P028](../../sources/摘录/史记-卷004-周本纪.md#p028) · [卷004 P029](../../sources/摘录/史记-卷004-周本纪.md#p029)。 穆王“立五十五年”和“即位五十岁”是两个不同数字，本轮不据相加生成其生卒年。懿王时诗人讥刺王室，是史家总括，不能从本段单独定出某篇诗的作年。

<a id="s8"></a>
### S8｜厉王任用荣夷公，王室与民众的冲突逐渐积累

[卷004 P030](../../sources/摘录/史记-卷004-周本纪.md#p030) · [卷004 P031](../../sources/摘录/史记-卷004-周本纪.md#p031)。 本纪厉王三十年、三十四年、后三年是一套相对纪年；不倒推每项政策的精确启动年。“专利”在这里是独占利益之意，不是现代知识产权；原文没有把制度写成一份完整山林国有化法令，正文不扩造。

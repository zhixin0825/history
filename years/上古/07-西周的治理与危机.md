# 西周｜从成康治理到厉王危机

[← 商末与周初](06-商末与周初.md) · [上古目录](README.md) · [全部时间](../README.md) · [继续：前841年 →](../bce-0900-0801/bce-0841.md)

> **范围：成王亲政前后至厉王出奔以前。** 这里按事件先后与王序阅读，不按同一精度给所有早周故事配公元年。前1046年的克商采用工程方案；相对年数、制度性长段和史家评论仍分层。从共和元年前841年起，接入按世纪排列的年度页。

<a id="return"></a>
<a id="1-成王开始亲政周人仍同时经营西土与东方"></a>

<a id="event-1"></a>

1. **成王开始亲政，周人仍同时经营西土与东方。** **周公归政以后退回臣位，成王承担王政。** 摄政七年是本纪的相对年数，不在这一页虚拟七张年度文件。成王住丰，召公继续营建洛邑，周公又复核卜居；周人把洛邑看成四方道路较均衡的中心，安置九鼎，并迁入一部分殷民。 [[1]](#note-1)

   这不是“周一灭商就只剩洛阳一个都城”。宗周的丰、镐与东方成周同时具有作用；本纪末尾也明确反对把武王克商后立刻定都洛邑当成简单结论。

<a id="east"></a>
<a id="2-东方仍有反抗征奄淮夷与迁民相继展开"></a>

<a id="event-2"></a>

2. **东方仍有反抗，征奄、淮夷与迁民相继展开。** **平定商邑以后，东方的局势仍不完全听命于周。** 周公、召公辅政，周人向淮夷、奄等地进兵，又迁徙被征服地区的君主与民众。成王从奄归来，在宗周告诫各方，礼制、官职和地域秩序也在这些行动中逐渐安排。 [[2]](#note-2)

   东方息慎来贺，王又以相关赏赐和文告回应。这类朝贡、文告与征服记事连在一起，说明周初统治仍须经营，不是牧野一战便把所有地方永久统一。

<a id="cheng-kang"></a>
<a id="3-成王留下辅佐安排康王在祖庙中接位"></a>

<a id="event-3"></a>

3. **成王留下辅佐安排，康王在祖庙中接位。** **成王临终前担心太子钊不能独当其任，命召公、毕公带领诸侯辅佐。** 成王死后，太子在先王庙中受命，两位辅臣重新说明文王、武王创业艰难，要求节俭、少欲、守信。钊继位，是为康王，再向诸侯申明继承文武事业。 [[3]](#note-3)

   康王又命毕公安排成周郊外居民的居里。成康时期“刑措四十余年不用”的说法，表现后人对安宁政治的理想概括，不能当成一份证明全国四十年没有任何刑案的统计。

<a id="zhao"></a>
<a id="4-昭王南行未归穆王继承一个出现困难的王室"></a>

<a id="event-4"></a>

4. **昭王南行未归，穆王继承一个出现困难的王室。** **康王死，儿子昭王瑕继位。** 昭王南巡没有回来，死在江上，王室没有照常向诸侯报丧；传世解释说，这是在避讳这场死亡。它没有在本段写出胶船、沉船阴谋或确定的落水地点，正文也不补这些细节。 [[4]](#note-4)

   昭王之子满继位，即穆王。本纪说他即位时已五十岁，并记他命伯臩申明太仆的职责，以恢复被认为已衰的文武旧制。年龄照原书保存，但不据此给其出生建立一个确年页面。

<a id="mu-expedition"></a>
<a id="5-祭公劝穆王不要为显示武力远征犬戎"></a>

<a id="event-5"></a>

5. **祭公劝穆王不要为显示武力远征犬戎。** **穆王准备讨犬戎，祭公谋父反对，理由不只是怕打不赢。** 他先说军队应在需要时使用，而不能常拿来炫耀；治理应使民众明白利害、发展生产、改善器用。讲到先世时，他从后稷、不窋重述到文武，说明祖先的战争在其叙事中是为除民害，不应变成好战。 [[5]](#note-5)

   接着他把不同区域的义务分开：邦内甸服、邦外侯服、侯卫宾服、夷蛮要服、戎翟荒服，各有祭、祀、享、贡、王的联系，频率也不同。若一方不来，应先修正自己所施的教化与名分，逐层采用告诫、责让等手段，而不是一开始便让民众远征。

   穆王没有采纳，仍出兵，带回四只白狼、四只白鹿。叙事随即说远方荒服不再前来。所得奇兽与疏远后果并列，正是本段的结尾；不能只写“远征大胜”而删掉劝谏和代价。

<a id="zaofu"></a>
<a id="造父为穆王驾车秦赵的世系在这里分支"></a>

<a id="event-6"></a>

6. **造父为穆王驾车，秦赵的世系在这里分支。** 蜚廉还有另一子季胜。季胜之后依次为孟增、衡父、造父；孟增获成王亲近，造父则以善御受穆王重用。穆王西行时，造父驾驭骏马随行；徐偃王起兵的消息传来，他又赶车送王回返，获封赵城，其族由此称赵氏。 [[6]](#note-6)

   恶来的后裔则经女防、旁皋、太几、大骆，传到非子。两条世系不是两位造父，也不能把季胜误作恶来的儿子。《秦本纪》把秦人称赵氏与造父受封联系起来，篇末还从嬴姓分出的不同族氏回顾共同来历。

<a id="punishments"></a>
<a id="6-甫刑把审案疑罪与赎罚联系起来"></a>

<a id="event-7"></a>

7. **甫刑把审案、疑罪与赎罚联系起来。** **诸侯之间有不睦，甫侯向王谈刑罚的整治。** 文告先要求两方到场、审听不同陈述，再核对事实；不能轻易定刑时，要检查罚与过的层次，对仍有疑问的刑罚保留赦免的可能。它把审案责任放在用刑者身上，不是只罗列残酷刑名。 [[7]](#note-7)

   随后分别列黥、劓、膑、宫、大辟及其疑罪赎罚，使用百率、倍洒、倍差、五百率、千率等数语。最后按刑类列一千、一千、五百、三百、二百，合为三千。这里记录的是古书法制观念，未把赎罚换成现代货币，也不把各刑类条数当成已经出土的三千份法条全文。

<a id="succession"></a>
<a id="7-共懿孝夷之间继承也不是一直父子相传"></a>

<a id="event-8"></a>

8. **共、懿、孝、夷之间，继承也不是一直父子相传。** **穆王死后，共王繄扈继位；其后依次是懿王、孝王、夷王，再到厉王。** 懿王是共王之子，孝王却是共王之弟；孝王死后，诸侯又立懿王之子燮，即夷王。王位在两支之间转回，不能简单写成五次父传子。 [[8]](#note-8)

   共王还有一则密康公故事：三名女子奔向密康公，其母劝他献给共王，以拥有美物过多、可能招祸相警。密康公没有献，次年共王灭密。本页保留战争与其传世故事，却不采用“女子是灾祸根源”作解释，也不把母亲的话当成已证实的全部战争原因。

<a id="feizi"></a>
<a id="非子因养马获得秦邑但没有取代大骆的嫡子"></a>

<a id="event-9"></a>

9. **非子因养马获得秦邑，但没有取代大骆的嫡子。** 孝王时，居犬丘的非子以善于养马闻名，被召到汧、渭之间管理王马，马匹大量繁殖。孝王曾想让他做大骆的继承人，但大骆与申侯之女已生嫡子成。申侯强调两家婚姻与西方族群的关系，请王不要破坏原有继承。 [[9]](#note-9)

   孝王最后保留成的嫡子身份，另外给非子秦邑，使为附庸、继续嬴氏祭祀，号秦嬴。因此“受秦邑”和“替代嫡子”不是同一结果。秦嬴以后是秦侯、公伯、秦仲：本纪说秦侯在位十年、公伯三年，仍不足以给非子受封安一个没有争议的公元年。

   厉王时期，西方族群反抗王室，犬丘大骆这一支遭到灭族。秦仲本系与犬丘大骆一系的灾难和后来土地合并，在后文由宣王讨戎接续。

<a id="li"></a>
<a id="8-厉王任用荣夷公王室与民众的冲突逐渐积累"></a>

<a id="event-10"></a>

10. **厉王任用荣夷公，王室与民众的冲突逐渐积累。** **夷王之子胡继位，即厉王，后来重用主张专利的荣夷公。** 芮良夫反对把百物所出的利益独占，认为为王者应当引导利益在上下之间流通；独占会使更多人怨恨，甚至使普通人难以生活。厉王仍让荣夷公做卿士。 [[10]](#note-10)

    对施政的不满扩大以后，厉王又让卫巫监视批评者，告发者一到便杀人。人们不敢开口，只在路上以眼色示意。召公认为这不是消除了怨言，而是把出口堵住：民怨如壅水，越堵越可能突然决裂；君主应当通过公卿、乐人、史官、百工、庶人和老人听到不同意见，再决定施政。

    厉王没有听从，危机终于转成公开反抗。具体经过接到[前841年](../bce-0900-0801/bce-0841.md)，从这里起用年度页接续。

<a id="sj013-kingdoms"></a>
<a id="9-西周并不只有一支王室诸侯国也有各自的承继"></a>

<a id="event-11"></a>

11. **西周并不只有一支王室：诸侯国也有各自的承继。** **把周王与各国君主放在一起读，王室怎样延续、诸侯怎样换人，就能同时看出来。** [《三代世表》](../../sources/摘录/史记-卷013-三代世表.md#t006)从成王、康王、昭王、穆王、共王、懿王、孝王、夷王、厉王一直列到共和，旁边依次把鲁、齐、晋、秦、楚、宋、卫、陈、蔡、曹、燕十一支放到同一张对照表里。鲁国自周公旦、伯禽以下传承；齐国以太公尚、吕伋为开头；晋有唐叔虞、晋侯燮；宋有微子启、微仲。这些人不是同一王都的十一个官员，而是不同国族的谱系。 [[11]](#note-11)

    <a id="sj013-brother-succession"></a>
    **各国的君位也会在兄弟之间转移。** 鲁国考公之后由弟弟炀公承继，厉公之后又由弟弟献公承继；宋国微子启之后接弟弟微仲，丁公之后接弟弟湣公，湣公之后又接弟弟炀公。这些关系分属各国自己的先后，不是几国在同一年同时改立兄弟，也不能把整列人名画成一条全是父子的家谱。

    **不要把表中同一横行误译为“周成王某年十一国同时受封”。** 周公与太公封国有武王时期的背景，伯禽赴鲁在其后；恶来生于殷周之际并助纣，根本不是在成王年新封的“秦王”。秦人的后裔非子到孝王时才获得秦邑；楚国熊绎、陈国胡公满、卫国康叔等的封立背景，也须分别依本国世家读，不能由横格自动推出相同日期。[原表及逐国对照](../../sources/摘录/史记-卷013-三代世表.md#t006) · [横表考证](../../meta/考证/史记-卷013-纪年与异说.md#周诸侯横表)

    **这张表也没有把缺失资料变成已知人物。** 燕国一列只概括“九世至惠侯”，并未逐名开列九人；共和最后是王室由谁主持政事的争论，不是一位名叫“共和”的周王。周召二相与共伯和异说仍到[前841年](../bce-0900-0801/bce-0841.md)分辨。读者可以先沿本页了解各国背景，之后再随有确年的春秋年页阅读各国兴衰。

    **表格的末尾还会接到共和以后。** 鲁栏与共和并排写到武公，其承兄真公的关系已接到[前825年的原年页](../bce-0900-0801/bce-0825.md#sj013-lu-wugong)。这正说明主栏以共和收束，不等于所有旁栏人物都在前841年同时登位。[原文与归年说明](../bce-0900-0801/bce-0825.md#sj013-lu-wugong-note)

### 3. 成王留下辅佐安排，康王在祖庙中接位

[返回正文第3条](#event-3)

**[卷004 P024](../../sources/摘录/史记-卷004-周本纪.md#p024)**

> 成王將崩，懼太子釗之不任，乃命召公、畢公率諸侯以相太子而立之。成王既崩，二公率諸侯，以太子釗見於先王廟，申告以文王、武王之所以為王業之不易，務在節儉，毋多欲，以篤信臨之，作顧命。太子釗遂立，是為康王。康王即位，遍告諸侯，宣告以文武之業以申之，作《康誥》。故成康之際，天下安寧，刑錯四十餘年不用。康王命作策畢公分居里，成周郊，作《畢命》。

### 5. 祭公劝穆王不要为显示武力远征犬戎

[返回正文第5条](#event-5)

**[卷004 P026](../../sources/摘录/史记-卷004-周本纪.md#p026)**

> 穆王將征犬戎，祭公謀父諫曰：「不可。先王燿德不觀兵。夫兵戢而時動，動則威，觀則玩，玩則無震。是故周文公之頌曰：『載戢干戈，載櫜弓矢，我求懿德，肆于時夏，允王保之。』先王之於民也，茂正其德而厚其性，阜其財求而利其器用，明利害之鄉，以文修之，使之務利而辟害，懷德而畏威，故能保世以滋大。昔我先王世后稷以服事虞、夏。及夏之衰也，棄稷不務，我先王不窋用失其官，而自竄於戎狄之閒。不敢怠業，時序其德，遵修其緒，修其訓典，朝夕恪勤，守以敦篤，奉以忠信。奕世載德，不忝前人。至于文王、武王，昭前之光明而加之以慈和，事神保民，無不欣喜。商王帝辛大惡于民，庶民不忍，訢載武王，以致戎于商牧。是故先王非務武也，勸恤民隱而除其害也。夫先王之制，邦內甸服，邦外侯服，侯衛賓服，夷蠻要服，戎翟荒服。甸服者祭，侯服者祀，賓服者享，要服者貢，荒服者王。日祭，月祀，時享，歲貢，終王。先王之順祀也，有不祭則修意，有不祀則修言，有不享則修文，有不貢則修名，有不王則修德，序成而有不至則修刑。於是有刑不祭，伐不祀，征不享，讓不貢，告不王。於是有刑罰之辟，有攻伐之兵，有征討之備，有威讓之命，有文告之辭。布令陳辭而有不至，則增修於德，無勤民於遠。是以近無不聽，遠無不服。今自大畢、伯士之終也，犬戎氏以其職來王，天子曰『予必以不享征之，且觀之兵』，無乃廢先王之訓，而王幾頓乎？吾聞犬戎樹敦，率舊德而守終純固，其有以御我矣。」王遂征之，得四白狼四白鹿以歸。自是荒服者不至。

### 10. 厉王任用荣夷公，王室与民众的冲突逐渐积累

[返回正文第10条](#event-10)

**[卷004 P030](../../sources/摘录/史记-卷004-周本纪.md#p030)**

> 夷王崩，子厲王胡立。厲王即位三十年，好利，近榮夷公。大夫芮良夫諫厲王曰：「王室其將卑乎？夫榮公好專利而不知大難。夫利，百物之所生也，天地之所載也，而有專之，其害多矣。天地百物皆將取焉，何可專也？所怒甚多，不備大難。以是教王，王其能久乎？夫王人者，將導利而布之上下者也。使神人百物無不得極，猶日怵惕懼怨之來也。故《頌》曰『思文后稷，克配彼天，立我蒸民，莫匪爾極』。大雅曰『陳錫載周』。是不布利而懼難乎，故能載周以至于今。今王學專利，其可乎？匹夫專利，猶謂之盜，王而行之，其歸鮮矣。榮公若用，周必敗也。」厲王不聽，卒以榮公為卿士，用事。

**[卷004 P031](../../sources/摘录/史记-卷004-周本纪.md#p031)**

> 王行暴虐侈傲，國人謗王。召公諫曰：「民不堪命矣。」王怒，得衛巫，使監謗者，以告則殺之。其謗鮮矣，諸侯不朝。三十四年，王益嚴，國人莫敢言，道路以目。厲王喜，告召公曰：「吾能弭謗矣，乃不敢言。」召公曰：「是鄣之也。防民之口，甚於防水。水壅而潰，傷人必多，民亦如之。是故為水者決之使導，為民者宣之使言。故天子聽政，使公卿至於列士獻詩，瞽獻曲，史獻書，師箴，瞍賦，矇誦，百工諫，庶人傳語，近臣盡規，親戚補察，瞽史教誨，耆艾修之，而後王斟酌焉，是以事行而不悖。民之有口也，猶土之有山川也，財用於是乎出：猶其有原隰衍沃也，衣食於是乎生。口之宣言也，善敗於是乎興。行善而備敗，所以產財用衣食者也。夫民慮之於心而宣之於口，成而行之。若壅其口，其與能幾何？」王不聽。於是國莫敢出言，三年，乃相與畔，襲厲王。厲王出奔於彘。

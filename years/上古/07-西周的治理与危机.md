# 西周｜从成康治理到厉王危机

[← 商末与周初](06-商末与周初.md) · [上古目录](README.md) · [全部时间](../README.md) · [继续：前841年 →](../bce-0900-0801/bce-0841.md)

> **范围：成王亲政前后至厉王出奔。** 这一时期按王序和史料所记的事件先后来读；没有把各王在位数直接换成公元年。厉王出奔后的共和元年接[前841年](../bce-0900-0801/bce-0841.md)。

<a id="return"></a>
<a id="1-成王开始亲政周人仍同时经营西土与东方"></a>
<a id="event-1"></a>

1. **成王亲政，周人在丰与洛邑之间经营王畿。** 《周本纪》说，周公摄政七年，等成王长成才归还王政，回到臣位。成王住在丰，派召公继续营建洛邑；周公再去占卜并察看，完工后九鼎置于洛邑。周人认为那里便于四方往来进贡，又把一部分殷民迁到东方，由周公代王宣告。《周本纪》篇末特别指出，周人在营洛后仍以丰、镐为都。 [[1]](#note-1)

<a id="east"></a>
<a id="2-东方仍有反抗征奄淮夷与迁民相继展开"></a>
<a id="event-2"></a>

2. **周军继续东征，攻奄并迁其君。** 商邑平定以后，周在东方还要用兵。《周本纪》说，召公为保、周公为师，周军东攻淮夷，打败奄国并迁走其君。成王从奄回到宗周，告诫各方；本纪接着记再攻淮夷、归丰作《周官》以及整顿礼乐。东征以后，息慎前来祝贺，王命荣伯作与息慎有关的文告。 [[2]](#note-2)

<a id="cheng-kang"></a>
<a id="3-成王留下辅佐安排康王在祖庙中接位"></a>
<a id="event-3"></a>

3. **成王托付辅政，太子钊在先王庙中接位。** 成王临终担心太子钊不能独当其任，命召公、毕公率诸侯辅佐。成王死后，二公领太子到先王庙，讲文王、武王创业的艰难，嘱咐他节俭、少欲、守信。太子即位为康王，又向诸侯重申文武的事业，随后命毕公安排成周郊外居民的居里。司马迁以“四十余年不用刑”概括成康时期的安宁。 [[3]](#note-3)

<a id="zhao"></a>
<a id="4-昭王南行未归穆王继承一个出现困难的王室"></a>
<a id="event-4"></a>

4. **昭王南巡死在江上，儿子满继位。** 康王死后，儿子瑕继位，即昭王。《周本纪》说，昭王南巡没有回来，死在江上，王室避讳此事，没有对外报丧；本纪没有说明他为何身亡。昭王之子满继位为穆王。按本纪，穆王即位时已五十岁，又命伯臩向太仆重申政务，希望整顿日渐衰微的王政。 [[4]](#note-4)

<a id="mu-expedition"></a>
<a id="5-祭公劝穆王不要为显示武力远征犬戎"></a>
<a id="event-5"></a>

5. **穆王不听祭公劝告，出兵犬戎。** 穆王准备远征犬戎，祭公谋父说，先王平时不炫耀武力，只有需要时才用兵。各地与王室的礼仪和贡纳关系有区别；犬戎已按自己的职责来朝，不能因为它没有行别处的礼便出兵。他主张先整顿自身政教，再逐步告诫或责让。穆王仍出兵，带回四只白狼、四只白鹿；本纪接着说，荒服从此不再来朝。 [[5]](#note-5)

<a id="zaofu"></a>
<a id="造父为穆王驾车秦赵的世系在这里分支"></a>
<a id="event-6"></a>

6. **造父为穆王驾车，因功受封赵城。** 《秦本纪》从蜚廉分叙两支。季胜一支传到孟增、衡父和造父；造父善于驾车，受穆王重用。穆王向西游巡时，徐偃王起兵，造父为穆王赶车回周救乱，获封赵城，这支家族由此称赵氏。蜚廉的另一个儿子恶来，其后裔经女防、旁皋、太几、大骆传到非子；《秦本纪》说这一支也因造父受宠而称赵氏。 赵氏谱系称季胜生孟增，孟增受成王宠、号宅皋狼，继而传衡父、造父。造父选良马，并以桃林的盗骊、骅骝、绿耳献穆王；故事还说穆王西行见西王母而忘归，造父驾车日驰千里助王破徐，因而受赵城、成为赵氏得姓之祖。这些奇异细节保留为传述。 [[6]](#note-6)

<a id="punishments"></a>
<a id="6-甫刑把审案疑罪与赎罚联系起来"></a>
<a id="event-7"></a>

7. **甫侯议刑，主张核实双方说法并审慎处置疑案。** 诸侯不和，甫侯向穆王提议整顿刑罚，史书把这份文告称作《甫刑》。审案时先让双方到场，听完陈述再核实；刑罚是否适用要查明，仍有疑问可以赦免。文告还列出黥、劓、膑、宫、大辟五类刑罚及其疑罪赎罚，五类合称三千条。 [[7]](#note-7)

<a id="succession"></a>
<a id="7-共懿孝夷之间继承也不是一直父子相传"></a>
<a id="event-8"></a>

8. **王位从懿王一支转出，后来传回懿王之子。** 穆王去世后，儿子共王繄扈继位。《周本纪》说，共王出游时有三名女子投奔随行的密康公，密康公的母亲劝他将人送到王廷；密康公没听从，次年共王灭密。共王死后，儿子懿王接位；懿王去世后改由辟方为王，是为孝王。两种《史记》记载对辟方的辈分有分歧；都记载孝王死后，王位回到懿王的儿子燮手中，即夷王。 [[8]](#note-8)

<a id="feizi"></a>
<a id="非子因养马获得秦邑但没有取代大骆的嫡子"></a>
<a id="event-9"></a>

9. **非子因养马受封秦邑，大骆的嫡子仍是成。** 非子住在犬丘，以善养马出名。孝王召他到汧、渭之间主管王马，马匹增多，孝王一度想让他承继大骆。申侯指出，自己的女儿嫁给大骆，已生嫡子成，这桩婚事维系着和西方族群的关系。孝王于是保留成的嫡子身份，另给非子秦邑，让他以附庸身份延续嬴氏祭祀，号秦嬴。非子一支后来传到秦侯、公伯、秦仲；厉王时，反周的西戎灭了犬丘大骆一支。 [[9]](#note-9)

<a id="li"></a>
<a id="8-厉王任用荣夷公王室与民众的冲突逐渐积累"></a>
<a id="event-10"></a>

10. **厉王重用荣夷公，又监视批评王政的人。** 夷王之子胡继位，是为厉王。荣夷公主张独占利益，芮良夫劝王让上下都能从物产中获利，以免积怨，厉王仍让荣夷公出任卿士。国人批评王政，厉王命卫巫监视，告发到王廷便杀人；人们在路上只敢使眼色。召公劝说，压住怨言像堵河，一旦决口，伤害会更大；君主应该听取公卿、百工和庶人的意见。厉王没有听从，后来国人公开反抗，厉王逃往彘，接到[前841年](../bce-0900-0801/bce-0841.md)。 [[10]](#note-10)

<a id="sj013-kingdoms"></a>
<a id="9-西周并不只有一支王室诸侯国也有各自的承继"></a>
<a id="event-11"></a>
<a id="sj013-brother-succession"></a>

11. **诸侯有各自的世系，鲁、宋也有兄弟相继。** 《三代世表》在周王一栏旁并列鲁、齐、晋、秦、楚、宋、卫、陈、蔡、曹、燕十一支。鲁栏从周公旦、伯禽写起，齐栏从太公尚、吕伋写起，晋栏从唐叔虞、晋侯燮写起，宋栏从微子启、微仲写起。有些君位是在兄弟间交接的：鲁国考公之后是弟弟炀公，厉公之后是弟弟献公；宋国微子启之后是弟弟微仲，丁公之后是弟弟湣公，湣公之后又是弟弟炀公。表格用横行并列各国世系，不能用一行给各国君主定同一年。 蔡国从蔡仲胡传给儿子荒，再父子相传为宫侯、厉侯、武侯。 曹国则从振铎传给儿子太伯脾，此后依次为仲君平、宫伯侯、孝伯云、夷伯喜。 陈国从胡公满传到儿子犀侯、犀侯之弟皋羊，再回到犀侯之子突，随后为圉戎、宁；杞国早期则传为东楼、西楼、题、谋娶、武诸公，前几代都没有逐年可核的绝对年代。 卫国则从康叔以下依次列康伯、考伯、嗣伯、偼伯、靖伯、贞伯、顷侯；各代姓名与君次仍有异谱。 宋的早期承继还经历争位：炀公熙被湣公之子鲋祀杀死，鲋祀自立为厉公，传子釐公举。微子、微仲、宋公稽以下的前几代仍只能按世系阅读。 晋国唐叔虞之后，依次为燮、武侯宁族、成侯服人、厉侯福、靖侯宜臼，前几代缺少可逐年核对的在位数。 [[11]](#note-11)

<a id="sj032-early-qi-event"></a>

12. **齐哀公被烹、胡公迁都，献公又袭杀胡公夺位。** 《齐太公世家》说，纪侯进谗后，周王烹杀齐哀公，改立其弟静为胡公，胡公迁都；哀公同母弟山又率营丘人袭杀胡公，自立为献公，驱逐胡公诸子，转治临淄。献公第九年去世，子寿为武公。这些没有可靠的独立公元纪年，放在西周时期按先后阅读，不倒推确定年份。 [[12]](#sj032-early-qi-note)


<a id="sj033-zhou-flight-event"></a>

13. **周公奔楚与迎回，是本篇保留的一则异传。** 《鲁周公世家》记周公曾为幼年的成王祷病，后来遭谗奔楚，成王读到祝辞而迎回。古注已指出这件事在经典中缺少对应，另引异说讨论。这里作为无法确年的传世故事保存，不制造确定的出奔年份，也不与为武王请命混成一次祈祷。 [[13]](#sj033-zhou-flight-note)


<a id="sj033-zhou-advice-event"></a>

14. **周公劝成王勤政，不要只看帝王享乐。** 本篇把周公的劝诫联系《多士》《毋逸》：先王经历劳苦，能体察百姓；在富贵中长大者若不知农事艰难，容易失德。所举帝王年数是劝诫中的历史论据，不能直接据它们排成没有争议的夏商周年表。 [[14]](#sj033-zhou-advice-note)


<a id="sj033-zhou-death-event"></a>

15. **周公葬毕、金縢故事与鲁礼的由来。** 本篇记周公希望葬成周以示不离成王，成王却葬他于毕，与文王相从；又把风雷开金縢接在周公死后，并用王室尊崇解释鲁国获得的祭礼、礼乐特许。《尚书》相关叙事与古注所论时序不同，不能强行接成一条确定年月的灾异履历。 [[15]](#sj033-zhou-death-note)

<a id="sj034-shaogong-junshi-event"></a>

16. **召公与周公分掌东西，传世《君奭》叙事讨论辅政。** 召公奭列三公，陕地以西由召公主持，以东由周公主持。周公向召公列举商代伊尹、伊陟、臣扈、巫咸、巫贤、甘般等贤臣，说明王业须由臣下接续辅成。召公曾疑周公、随后释疑，是这一篇章的传统讲法；作篇背景和召公实际态度仍有不同解释。 [[16]](#sj034-shaogong-junshi-note)

<a id="sj034-shaogong-gantang-event"></a>

17. **召公巡行听讼，甘棠树成为身后追思的象征。** 传世故事说，他在棠树下裁断诉讼、处理政事，使侯伯与庶人各得安置。召公去世以后，百姓怀念他的治理，不忍砍伐那棵树，歌咏留下《甘棠》之诗。这是任政与身后纪念相连的叙事，具体年次未明。 [[17]](#sj034-shaogong-gantang-note)

<a id="sj035-cai-zhong-event"></a>

18. **蔡仲胡因修德而重新受封蔡。** 蔡叔流放后去世，儿子胡改行修德，受到周公起用。胡治事有成，周公又向成王推荐，使他承续蔡叔的祭祀，称蔡仲。任卿士的地点和具体先后有异说，不强定公元年份。 [[18]](#sj035-cai-zhong-note)

<a id="sj037-kang-advice-event"></a>

19. **周公告诫康叔访贤爱民，以殷亡为鉴。** 康叔到卫国治理殷民，周公叮嘱他向当地贤者、长者请教，了解商朝兴亡，约束酒色、爱护民众。传世叙事把《康诰》《酒诰》《梓材》联系到这些训诫，并称康叔使封国内部逐渐安定；篇章形成与具体年代仍有讨论。 [[19]](#sj037-kang-advice-note)

<a id="sj037-qing-rank-event"></a>

20. **卫国从早期诸伯传到顷侯，侯号的解释留下分歧。** 传世卫君谱从康叔以下相承至顷侯、釐侯。关于顷侯时称侯，有厚赂周夷王而获爵的讲法，也有本来已是侯爵、后来失去方伯地位的解释。这里只说明称号变化的争议，不强定公元年份。 [[20]](#sj037-qing-rank-note)

<a id="sj040-chu-early-event"></a>

21. **楚国从熊绎一系传到熊渠，扩张与王号也随周室强弱变化。** 熊绎之后相传为熊艾、熊亶、熊胜；熊胜传弟熊杨，熊杨生熊渠。夷王时周室衰弱，熊渠得到江汉间民众支持，攻庸、杨蠆，兵至鄂，自称不受中原名号约束，封康为句亶王、红为鄂王、执疵为越章王。到厉王时惧周来伐，又撤王号。此后毋康早死，熊渠卒而挚红承位，熊延再经争夺继位，传至熊勇；争位文字有脱讹，不能补出确定受害者。 [[21]](#sj040-chu-early-note)

### 1. 成王亲政，周人在丰与洛邑之间经营王畿

[《史记·周本纪》 P022](../../sources/摘录/史记-卷004-周本纪.md#p022)：

[《史记·周本纪》 P023](../../sources/摘录/史记-卷004-周本纪.md#p023)：

> 成王在豐，使召公復營洛邑，如武王之意。周公復卜申視，卒營筑，居九鼎焉。曰：「此天下之中，四方入貢道里均。」作召誥、洛誥。成王既遷殷遺民，周公以王命告，作多士、無佚。

[《史记·周本纪》 P082](../../sources/摘录/史记-卷004-周本纪.md#p082)：

> 學者皆稱周伐紂，居洛邑，綜其實不然。武王營之，成王使召公卜居，居九鼎焉，而周復都豐、鎬。至犬戎敗幽王，周乃東徙于洛邑。

### 2. 周军继续东征，攻奄并迁其君

[《史记·周本纪》 P023](../../sources/摘录/史记-卷004-周本纪.md#p023)：

> 召公為保，周公為師，東伐淮夷，殘奄，遷其君薄泵。成王自奄歸，在宗周，作多方。既絀殷命，襲淮夷，歸在豐，作周官。興正禮樂，度制於是改，而民和睦，頌聲興。成王既伐東夷，息慎來賀，王賜榮伯作賄息慎之命。

[返回正文第2条](#event-2)

<a id="sj033-cite-015"></a>

**[《史记·鲁周公世家》P014](../../sources/摘录/史记-卷033-鲁周公世家.md#p014)**

> 伯禽即位之後，有管、蔡等反也，淮夷、徐戎亦并興反。於是伯禽率師伐之於肸，作肸誓，曰：「陳爾甲胄，無敢不善。無敢傷牿。馬牛其風，臣妾逋逃，勿敢越逐，敬復之。無敢寇攘，踰墻垣。魯人三郊三隧，峙爾芻茭、糗糧、楨榦，無敢不逮。我甲戌筑而征徐戎，無敢不及，有大刑。」作此肸誓，遂平徐戎，定魯。

## 归年与考证

### 营洛、东征与穆王时期的记载

- [《周本纪》P022](../../sources/摘录/史记-卷004-周本纪.md#p022)写周公摄政七年，[P023](../../sources/摘录/史记-卷004-周本纪.md#p023)接写营洛、迁殷民、征奄与淮夷。篇章顺序不足以把营洛、周公归政和每次东征排成逐年大事表。P023写“遷其君薄泵”，后两字在工作文本中可疑，正文只写迁走奄君。
- [《周本纪》P024](../../sources/摘录/史记-卷004-周本纪.md#p024)的“刑错四十余年不用”是本纪对成康政治的概括，不是四十余年刑案统计。穆王即位时五十岁见[P025](../../sources/摘录/史记-卷004-周本纪.md#p025)，在位五十五年见[P028](../../sources/摘录/史记-卷004-周本纪.md#p028)，前者是年龄，后者是在位时长。
- 祭公说的五服是甸、侯、宾、要、荒；《禹贡》所列第三服是绥。见[《周本纪》P026](../../sources/摘录/史记-卷004-周本纪.md#p026)。礼仪义务分等不等于当时疆域已整齐划成同心圆；“荒服者不至”是本纪记述的远征后果。
- 《甫刑》原文的百率、倍洒、倍差、五百率和千率见[《周本纪》P027](../../sources/摘录/史记-卷004-周本纪.md#p027)，没有换算成现代金额。五刑各类原书记一千、一千、五百、三百、二百；不能视为已出土的三千篇法条。[《秦本纪》篇末](../../sources/摘录/史记-卷005-秦本纪.md#p072)另从嬴姓分支回顾秦人与造父受封的关系。

### 孝王辈分和诸侯横表

- [《周本纪》P029](../../sources/摘录/史记-卷004-周本纪.md#p029)称孝王辟方是共王弟，[《三代世表》L829](../../sources/本地分卷/史记/史记-卷013.md#L829)却称他是懿王弟；两处都说后来由懿王之子燮继位。《周本纪》把共王灭密与密康公不献三女连在一起，不能凭这则故事断定战争的全部起因。
- [《三代世表》周王与诸侯横表](../../sources/摘录/史记-卷013-三代世表.md#t006)把诸侯各国与周王一并列出，各列有自己的继承次序。周公、太公受封可上溯武王，伯禽赴鲁在其后；表首秦栏的恶来侍奉帝辛，非子到孝王时才受秦邑。燕栏“九世至惠侯”没有列全九世名号。[横表考证](../../meta/考证/史记-卷013-纪年与异说.md#周诸侯横表)。
- 横表在共和一行同时列出鲁武公；他的继承另见[前825年](../bce-0900-0801/bce-0825.md#sj013-lu-wugong)及[归年说明](../bce-0900-0801/bce-0825.md#sj013-lu-wugong-note)。原表所说“共和，二伯行政”与其他解释的差异见[前841年共和原文](../bce-0900-0801/bce-0841.md#note-3)。

### 十兄弟后裔的跨时期去向

这一段回顾各支后裔：发为周王室，旦一支为鲁，度一支为蔡，振铎一支为曹，封一支为卫；管叔被诛后没有继续封国的后裔。伯邑考后裔的封地、成叔武和冉季载的后世事迹，本篇都没有记明。霍国延续到晋献公时代才被灭，实际事件在[前661年](../bce-0700-0601/bce-0661.md#note-6)。这是一份跨数百年的世系回顾，所列终局不属西周同年。

**[《史记·管蔡世家》P022](../../sources/摘录/史记-卷035-管蔡世家.md#p022)**

> 伯邑考，其後不知所封。武王發，其後為周，有本紀言。管叔鮮作亂誅死，無後。周公旦，其後為魯，有世家言。蔡叔度，其後為蔡，有世家言。曹叔振鐸，有後為曹，有世家言。成叔武，其後世無所見。霍叔處，其後晉獻公時滅霍。康叔封，其後為衛，有世家言。冉季載，其後世無所見。

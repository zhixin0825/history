## 阅读覆盖

上古部分已依次整理卷001《五帝本纪》、卷002《夏本纪》、卷003《殷本纪》、卷004《周本纪》、卷005《秦本纪》。工作单元数分别为28、35、33、82、72，划分不是原书统一段号。鲧禹治水、舜禹交接、契任官、汤灭夏等重叠材料合并，神异、制度、地理、人物评价与论赞分层。

## 后续时间线

西周接[前841年](../bce-0900-0801/bce-0841.md)。卷004已读到周亡及汉代封嘉的后记；卷006从[前246年](../bce-0300-0201/bce-0246.md)接读，卷007以[前210年项氏观巡](../bce-0300-0201/bce-0210.md#sj007-first)接入，卷008补[前209年刘邦前事](../bce-0300-0201/bce-0209.md#sj008-liuji)和汉初到[前195年](../bce-0200-0101/bce-0195.md)的主线。卷009继续接惠帝、高后，直至[前180年的诛吕和改立](../bce-0200-0101/bce-0180.md)。

卷010补文帝前后元年，卷011从[前156年](../bce-0200-0101/bce-0156.md)继续至[前141年刘彻即位](../bce-0200-0101/bce-0141.md)。卷012《孝武本纪》已将武帝祠祭、方士与封禅若干年次并入统一年页，但不能代表武帝全部史事已写完；卷013《三代世表》已按上古分层精度汇入，正文分散在原有时期页，不另建平行年表。卷014《十二诸侯年表》正在核对前841年以来诸侯国年次，表序与逐年行均有保存，但整卷审校尚未完成。

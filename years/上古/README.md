## 本次覆盖

上古部分已依次整卷整理《史记》卷001《五帝本纪》、卷002《夏本纪》、卷003《殷本纪》、卷004《周本纪》、卷005《秦本纪》。本项目阅读单元数依次为28、35、33、82、72，均有明确去向；不同卷的划分并非原书统一段号。重叠的鲧禹治水、舜禹交接、契任官和汤灭夏合并，不重复造事件。太史公论、神异、制度、地理与人物评价分层说明。

顺序工作随后完成卷006《秦始皇本纪》的79个单元、卷007《项羽本纪》的46个单元、卷008《高祖本纪》的72个单元。后面三卷主要在世纪年页阅读；秦先君世系与前五卷互见，项氏、刘邦早年在人物登场处补叙，不另建平行传记年表。

## 后续时间线

西周时期接[前841年](../bce-0900-0801/bce-0841.md)，其后已确定的事进入同一套世纪年页；未写出的年份不以空页填满。卷004已读到周亡及汉代封嘉的篇末后记。卷006从[前246年](../bce-0300-0201/bce-0246.md)接读，卷007以[前210年项氏观巡](../bce-0300-0201/bce-0210.md#sj007-first)接入同一时间线；卷008补[前209年的刘邦前事](../bce-0300-0201/bce-0209.md#sj008-liuji)及汉初治理、战争、继承，接至[前195年](../bce-0200-0101/bce-0195.md)。

下一卷为009《吕太后本纪》。卷008篇末的惠帝、高后年页只是后叙落点，不表示后续时期已经整卷完成。

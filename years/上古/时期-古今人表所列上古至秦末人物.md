# 古今人表所列上古至秦末人物

[本世纪目录](README.md) · [全部世纪](../README.md)

这里按原卷保留表序、栏头、谱系和无法确系单一年度的材料。确年原句由各卷去向连接对应年份。


<a id="event-1"></a>

1. **表序与九等的原则。** 班固说明，早期君臣的名字见于经传、诸子，传说有的无法由孔氏典籍核实，但仍可用于褒善戒恶。他引孔子论仁、圣及学习的层次，又以尧舜能与人行善、桀纣拒谏、齐桓公用管仲则霸而用竖貂则乱，说明上智、下愚与可受辅佐影响的中人。表由此分九等，兼取各类旧书，按人物世次安排。 [[1]](#note-1)


<a id="event-2"></a>

2. **九栏与四个品目。** 九栏从上上、上中、上下到下上、下中、下下。圣人、仁人、智人和愚人是表头的品目。TXT已失栏位，单凭行内空格不能把人名判给某一等级。 [[2]](#note-2)


<a id="event-3"></a>

3. **古帝传说：伏羲、女娲、神农与黄帝诸人。** 太昊、女娲、共工、神农、黄帝等并见，名号中混有族称、帝号与个人称谓。仓颉、力牧、风后、鬼臾区等随黄帝传说群出现。表把这些说法排成相承的次序，不能从行距推算实际年代。 [[3]](#note-3)


<a id="event-4"></a>

4. **五帝传说与尧时人物。** 少昊、颛顼、帝喾以至帝尧一带既有帝号，也有五鸟、五鸠一类集体官号，以及重黎、吴回、后土等神官称谓。末段许由、巢父等属于尧世让位故事的传说人物。 [[4]](#note-4)


<a id="event-5"></a>

5. **舜与传说中的唐虞群臣。** 娥皇、象、商均与舜的家庭及继承故事有关。契（TXT作禼）、伯益（栢益）、龙、夔等来自唐虞治水、教民和礼乐叙事。董父、柏阳等同段列名，各名仍按TXT原次查阅。 [[5]](#note-5)


<a id="event-6"></a>

6. **夏世人物。** 由禹、启、太康、中康、相下接少康一系及夏末关龙逢、桀。羿、逢门子、寒浞相关名字与夏政权的失复相间出现，表格所见人名未自带在位年或事发年。 [[6]](#note-6)


<a id="event-7"></a>

7. **商初、中期王系与伊尹等臣。** 汤与仲虺、伊尹、咎单等商初人物并录，后续见太甲、沃丁、太戊、河亶甲、祖乙等王及巫咸、巫贤。商王名常用干支字，类似名号须按王序与本纪辨人。 [[7]](#note-7)


<a id="event-8"></a>

8. **殷末及周初兴起的前事。** 商末王臣、微子一系、伯夷叔齐及商礼乐职官同段出现。关乎殷亡的人名和周方人物相邻，既反映两方交接，也保留臣僚与乐官的独立称谓。 [[8]](#note-8)


<a id="event-9"></a>

9. **周文王、武王与克商前后的人物。** 大姒、虢仲虢叔及文王诸臣先后入表，武王以下见发迹和封建故事中的吕尚、召公等人物。表中的周初称谓以谥、氏、封地或官名行用。 [[9]](#note-9)


<a id="event-10"></a>

10. **成王、康王与周初宗室诸臣。** 成王诵、康王钊与周公、召公及若干封国先君、礼官同见。人物的编排与周初政治传统相连，条内未载营建、东征或受封的年月。 [[10]](#note-10)


<a id="event-11"></a>

11. **西周中叶及诸侯世次。** 王号与诸侯名交替出现，楚、齐、鲁等各系的传承同列。西周诸王及伯、侯的活动常需另读《周本纪》与世家后再定位。 [[11]](#note-11)


<a id="event-12"></a>

12. **西周末、宣幽与秦襄公。** 近宣王、幽王一带有申侯、褒姒与秦襄公等名称。它们可以用来互见西周覆亡、东迁相关史传，各人的在位、事件年次须由载年原典确定。 [[12]](#note-12)


<a id="event-13"></a>

13. **平王东迁后与鲁隐公一代。** 由平王宜臼以下见东方诸侯、郑国君臣和鲁隐公。鲁国君臣姓名在春秋文献中可互校，表同一行并列仅为编排。 [[13]](#note-13)


<a id="event-14"></a>

14. **春秋初期郑、齐、卫与鲁诸人。** 有郑昭公忽、公子黔牟、齐襄公、连称等。称公的多为君号，称公子的宗室身份仍须结合本国世系，同名人不能直接合为一人。 [[14]](#note-14)


<a id="event-15"></a>

15. **春秋前期诸国与齐桓公时代。** 齐、鲁、郑、卫、陈等君臣交错。与齐桓公霸业相关的称名可和表序所举管仲、竖貂对照，名册本身不载会盟和战役月日。 [[15]](#note-15)


<a id="event-16"></a>

16. **宋襄公、秦穆公及晋楚角逐。** 这一段见宋襄公、秦国蹇叔、晋国先轸、楚成王与子玉等。诸侯与使臣、武将同列，涵盖春秋前期到晋楚争霸的交接。 [[16]](#note-16)


<a id="event-17"></a>

17. **晋楚争霸中的各国君臣。** 周匡王、鲁宣公、晋成公以及陈、郑诸侯先后见名。各行混有不同国家的活动人物，不能用其中一位国君的元年给整行定年。 [[17]](#note-17)


<a id="event-18"></a>

18. **楚庄王以后、晋郑与诸侯外交。** 楚、郑、晋、鲁、燕等国并见，乐伯、钟仪、韩厥和秦医缓各以不同身份入表。钟仪等人的处境与故事可与各国史传交读。 [[18]](#note-18)


<a id="event-19"></a>

19. **春秋中后期晋楚齐鲁及吴人。** 鲁襄公、晋臣羊舌职和士鞅、楚康王及近世人物密集。读此段宜辨名字、氏族和谥号，尤其数代相继的卿族。 [[19]](#note-19)


<a id="event-20"></a>

20. **子产、晏婴与孔门前后。** 郑子产、晏平仲与仲尼及门人相邻出现，又有老子、师旷等。孔门弟子与列国政治人物共同入表，各自时代有交叠，表序未给精确年月。 [[20]](#note-20)


<a id="event-21"></a>

21. **楚平王及春秋末诸国。** 楚平王、鲁定公及季氏等并列，可对读吴楚、鲁政的传世记载。此段涉及称王或称公的不同诸侯，不用爵号高低推定表列的品等。 [[21]](#note-21)


<a id="event-22"></a>

22. **鲁哀公、孔门及吴越更迭人物。** 季氏、鲁哀公、齐悼公以及孔门人物在此段密集出现。部分称谓兼名号或谥号；人名留作《左传》《论语》及《史记》检索入口。 [[22]](#note-22)


<a id="event-23"></a>

23. **春秋末到三家扩张。** 名录从孔门后学、列国晚春秋人物延至晋卿与三家。前后夹列与君臣活动相关的人物，不能将整段一律从三家封侯的某年起算。 [[23]](#note-23)


<a id="event-24"></a>

24. **战国初年各君与变法用人。** 魏文侯、段干木、李悝、吴起活动前后的列国人物相接，田氏、韩赵魏及秦、楚诸君亦入表。称田大公和者，可与齐世家田和对读。 [[24]](#note-24)


<a id="event-25"></a>

25. **战国中前期魏、韩、赵、秦等人物。** 韩烈侯、魏武侯、吴起、聂政、魏惠王与秦孝公等相继出现。刺客、变法者和诸侯同为名单项目，变法或刺杀各见相应载年原典。 [[25]](#note-25)


<a id="event-26"></a>

26. **诸国变法、合纵连横及学者。** 各国诸侯、游说者、学者与卿相相间。表所列称名可连接史传人物，但苏秦、张仪等活动的异年不能由相邻排次裁定。 [[26]](#note-26)


<a id="event-27"></a>

27. **秦武王、秦昭襄王前后的战国人物。** 秦武王、燕昭王、范雎、乐毅、郭隗与秦昭襄王等可与战国世家列传互见。名录没有燕伐齐、即墨之战或范雎任相的年款。 [[27]](#note-27)


<a id="event-28"></a>

28. **战国后期名将、四公子和各国末世。** 白起、田单、赵奢、廉颇、蔺相如、鲁仲连及四公子相关人物等先后见名。后接秦孝文王、王翦、楚考烈王、吕不韦等；TXT将“孫”“卿”分置两行，读名仍作孙卿。 [[28]](#note-28)


<a id="event-29"></a>

29. **秦并天下至秦末人物。** 秦始皇、韩非、李牧、李斯、荆轲、秦二世、赵高、子婴及秦末陈胜、吴广、项羽等在卷末。表止于这一段人物，不以单列姓名当作生卒年或对应一场战事。 [[29]](#note-29)

### 1. 表序与九等的原则

[返回正文第1条](#event-1)

<a id="hs020-p001"></a>

**[《汉书·古今人表》P001](../../拆分史书/汉书/卷020.md#p001)** · [仓内TXT L3321—L3321](../../拆分史书/汉书/卷020.md#part-1-L3321)

> 自書契之作，先民可得而聞者，經傳所稱，唐虞以上，帝王有號謚。輔佐不可得而稱矣，而諸子頗言之，雖不考虖孔氏，然猶著在篇籍，歸乎顯善昭惡，勸戒後人，故博采焉。孔子曰：「若聖與仁，則吾豈敢？」又曰：「何事於仁，必也聖乎！」「未知，焉得仁？」「生而知之者，上也；學而知之者，又其次也；困而不學，民斯為下矣。」又曰：「中人以上，可以語上也。」「唯上智與下愚不移。」傳曰：譬如堯舜，禹、稷、禼與之為善則行，鮌、讙兜欲與為惡則誅。可與為善，不可與為惡，是謂上智。桀紂，龍逢、比干欲與之為善則誅，于莘、崇侯與之為惡則行。可與為惡，不可與為善，是謂下愚。齊桓公，管仲相之則霸，竪貂輔之則亂。可與為善，可與為惡，是謂中人。因茲以列九等之序，究極經傳，繼世相次，緫備古今之略要云。

### 24. 战国初年各君与变法用人

## 影印與定位

原件為 Wikimedia Commons 同件號公版文獻掃描檔「二十四史月日考 第4冊」，共79頁。本地節錄 PDF 依次保留原檔第63、64、66頁；每頁仍為完整對開，未刪水印、頁邊或旁注。原檔 SHA-256：`a6f0c15e1c77f017a652ac568b0bba44e5b9f7e85f93a6618be3a251fe3a1128`。

原第63頁左半內題為「三國志二」「月日攷十七」，因此引作**卷十七**。識典古籍的導航題作卷十八，與內題不合；本目錄按影印本立卷，不把導航序號當成原書卷次。數位題錄的國圖入口由 Commons 元資料提供，本次已核的是下載影印與 Commons 題錄，未宣稱已成功讀取國圖原站頁面。

## 223年：劉備卒日

原稿第64頁右半，轉錄見[TXT](卷017-蜀书两段摘录.txt#L6-L12)，影印見節錄PDF第2頁。汪氏據蜀沿漢四分術，推四月己未朔、二十四日壬午；潘眉以乾象術得到戊午朔、二十四日辛巳，汪氏指出吳用之術不能直接代蜀用之術。《先主傳》及《通鑑》的「癸巳」與報喪表「今月二十四日」之間仍存在異記。

年頁正文採表記二十四日，兩處原文照錄，並列潘眉與汪氏的算法差別，見[223年同號注](../../years/ce-0201-0300/ce-0223.md#shu032-l140-1)。這項選擇不是把汪氏推算改寫進陳壽原文。

## 244年：閏三月與閏二月之辨

原稿第66頁右半，轉錄見[TXT](卷017-蜀书两段摘录.txt#L14-L20)，影印見節錄PDF第3頁。汪氏指毛本「閏二月」多一「二」字，以四分術推三月二十九日丙戌穀雨、閏三月十五日辛丑立夏、四月一日丁巳小滿，判為閏三月；並稱魏景初術、吳乾象術此年亦同。

本專案《後主傳》固定底本僅作「閏月」，照錄不補字。年頁分記魏二月詔伐、三月進軍、蜀閏月赴援與魏五月撤軍，並附此校說，見[244年同號注](../../years/ce-0201-0300/ce-0244.md#shu033-l60-1)。

## 孫破虜吳夫人傳

<a id="txt-l5"></a>

<a id="l2409"></a>

<a id="edition-wu050-l5-1"></a>

孫破虜吳夫人，吳主權母也。本吳人，徙錢唐，早失父母，與弟景居。

[吴夫人家世与孙坚婚姻](../../years/ce-0201-0300/时期-三国志卷050-妃嫔传纪年待考.md#wu050-l5-1)

<a id="edition-wu050-l5-2"></a>

孫堅聞其才貌，欲娶之。吳氏親戚嫌堅輕狡，將拒焉，堅甚以慙恨。夫人謂親戚曰：「何愛一女以取禍乎？如有不遇，命也。」於是遂許爲婚，生四男一女。

[吴夫人家世与孙坚婚姻](../../years/ce-0201-0300/时期-三国志卷050-妃嫔传纪年待考.md#wu050-l5-2)

<a id="txt-l6"></a>

<a id="pei-002-1"></a>

<a id="pei-002"></a>

<a id="edition-wu050-l6-1"></a>

> 〔裴注〕搜神記曰：初，夫人孕而夢月入其懷，旣而生策。及權在孕，又夢日入其懷，以告堅曰：「昔姙策，夢月入我懷，今也又夢日入我懷，何也？」堅曰：「日月者陰陽之精，極貴之象，吾子孫其興乎！」

[吴夫人家世与孙坚婚姻](../../years/ce-0201-0300/时期-三国志卷050-妃嫔传纪年待考.md#wu050-l6-1)

[吴夫人家世与孙坚婚姻](../../years/ce-0201-0300/时期-三国志卷050-妃嫔传纪年待考.md#wu050-l8-1)

<a id="edition-wu050-l8-2"></a>

袁術上景領丹楊太守，討故太守周昕，遂據其郡。孫策與孫河、呂範依景，合衆共討涇縣山賊祖郎，郎敗走。

[194 年第 12 條](../../years/ce-0101-0200/ce-0194.md#wu050-l8-2)

<a id="edition-wu050-l8-3"></a>

會景爲劉繇所迫，復北依術，術以爲督軍中郎將，與孫賁共討樊能、于麋於橫江，又擊笮融、薛禮於秣陵。

[194 年第 14 條](../../years/ce-0101-0200/ce-0194.md#wu050-l8-3)

<a id="edition-wu050-l8-4"></a>

時策被創牛渚，降賊復反，景攻討，盡禽之。從討劉繇，繇奔豫章，策遣景、賁到壽春報術。

[195 年第 13 條](../../years/ce-0101-0200/ce-0195.md#wu050-l8-4)

術方與劉備爭徐州，以景爲廣陵太守。

[吴景在袁术部下领广陵](../../years/ce-0201-0300/时期-三国志卷050-妃嫔传纪年待考.md#wu050-l8-5)

<a id="txt-l25"></a>

<a id="l2414"></a>

<a id="edition-wu050-l25-1"></a>

<a id="pei-008"></a>

<a id="edition-wu050-l26-1"></a>

[谢氏家世及谢承仕宦著述](../../years/ce-0201-0300/时期-三国志卷050-妃嫔传纪年待考.md#wu050-l26-1)

<a id="txt-l32"></a>

<a id="l2416"></a>

[徐氏家世，徐琨从孙坚起兵](../../years/ce-0201-0300/时期-三国志卷050-妃嫔传纪年待考.md#wu050-l32-1)

<a id="edition-wu050-l32-2"></a>

[徐氏家世，徐琨从孙坚起兵](../../years/ce-0201-0300/时期-三国志卷050-妃嫔传纪年待考.md#wu050-l32-2)

<a id="edition-wu050-l32-3"></a>

堅薨，隨孫策討樊能、于麋等於橫江，擊張英於當利口，而船少，欲駐軍更求。琨母時在軍中，謂琨曰：「恐州家多發水軍來逆人，則不利矣，如何可駐邪？宜伐蘆葦以爲泭，佐船渡軍。」

[195 年第 13 條](../../years/ce-0101-0200/ce-0195.md#wu050-l32-3)

## 纪年与异文

<a id="kao-70d5738fe8"></a>

<a id="kao-70d5738fe8-67d81e7cf"></a>

### 〈妃嬪傳〉紀年
- **孫策破廬江與步氏東渡。** 孫策受袁術命圍陸康，《呂範傳》接敘破廬江及東渡。建安四年他又襲皖破劉勳。〈妃嬪傳〉只說「廬江爲孫策所破」，未記人名或年號。保留母女遷移的先後，原列 199 年的引文移入時期頁。[攻陸康](../../years/ce-0101-0200/ce-0194.md#ce194-note-13) · [襲皖](../../years/ce-0101-0200/ce-0199.md#ce0199-note-7) · [母女東渡](../../years/ce-0201-0300/时期-三国志卷050-妃嫔传纪年待考.md#wu050-l42-2)
- **吳夫人卒年及吳景卒。** 本傳在建安七年（202）記吳夫人臨終託事，裴注引《志林》據會稽貢舉簿推為建安十二年（207）。兩說同號對讀。「八年，景卒官」承正文的建安年號，吳景卒於 203 年。[吳夫人卒年](../../years/ce-0201-0300/ce-0202.md#ce202-note-5) · [吳景卒](../../years/ce-0201-0300/ce-0203.md#ce203-note-7)
- **徐氏、步氏立后與步氏追冊。** 孫權於 221 年立孫登為吳王太子，229 年立為皇太子。徐、步兩傳概述稱王至稱帝前後的立后之議。步氏在生時宮中稱后，赤烏元年（238）閏月戊子有追冊策文，薨日及葬日未別書。[221 年立儲](../../years/ce-0201-0300/ce-0221.md#ce221-note-8) · [229 年稱帝](../../years/ce-0201-0300/ce-0229.md#ce0229-note-1) · [238 年追冊](../../years/ce-0201-0300/ce-0238.md#wu050-l45-3)
- **兩王夫人。** 〈孫和傳〉與本卷所載全公主進讒、琅邪王氏憂死為同一事，《資治通鑑》卷七十四繫赤烏八年（245）。南陽王氏是孫休生母，孫和立儲後出居公安，卒年未詳。258 年孫休即位後追尊並改葬。[琅邪王氏](../../years/ce-0201-0300/ce-0245.md#sgz-note-29) · [南陽王氏](../../years/ce-0201-0300/ce-0258.md#wu050-l55-4)
- **孫亮即位與孫峻掌權。** 何姬傳連敘孫亮即位、孫峻輔政。《三嗣主傳》在 252 年記孫亮繼位時諸葛恪執政，253 年十月記孫峻殺諸葛恪。孫和被賜死、張妃自殺及何氏撫育孫皓兄弟，隨 253 年孫和一條合讀。[孫亮即位](../../years/ce-0201-0300/ce-0252.md#wu050-l77-5) · [孫峻掌權](../../years/ce-0201-0300/ce-0253.md#sg-note-8) · [孫和死](../../years/ce-0201-0300/ce-0253.md#sg-note-9)
- **孫魯育與朱氏母女。** 本卷以「五鳳中」敘孫魯育被冤殺，《三嗣主傳》在五鳳二年（255）七月記孫儀案，《孫峻傳》接敘牽連魯育。朱熊、朱損遇害，《資治通鑑》卷七十七繫 258 年秋；朱氏受尊太后與降為景皇后在 264 年，次年七月被逼死後與孫休合葬。[255 年孫魯育](../../years/ce-0201-0300/ce-0255.md#sgz-note-25) · [258 年朱熊、朱損](../../years/ce-0201-0300/ce-0258.md#sgz-note-42) · [264 年朱氏降號](../../years/ce-0201-0300/ce-0264.md#sgz-note-63) · [265 年朱氏死](../../years/ce-0201-0300/ce-0265.md#sg-note-2)
- **全氏降魏、全尚與全惠解。** 卷048分十一月全禕、全儀攜母投魏，十二月全端、全懌等由壽春降；卷050作「全煒」，卷028注引《漢晉春秋》作「全輝」。全尚任太常、衛將軍在滕胤死後、258 年廢立之前。《資治通鑑》卷七十七將全尚被徙、被殺繫於孫亮被廢後。全惠解於 260 年隨孫亮赴候官，280 年吳亡始歸，歸處未載，卒於晉惠帝永寧年間（301—302）。[壽春降魏](../../years/ce-0201-0300/ce-0257.md#wu050-l65-5) · [全尚被徙](../../years/ce-0201-0300/ce-0258.md#wu050-l65-9) · [全惠解卒](../../years/ce-0201-0300/时期-三国志卷050-妃嫔传纪年待考.md#wu050-l66-3)
- **會稽流言與奚熙之死。** 卷048與《通鑑》卷八十於鳳皇三年（274）敘郭誕、奚熙獲罪，正文與裴注並記會稽有擁立孫奮之說及孫皓已死、何都代立之說。卷048記奚熙為部曲所殺，本卷注引《江表傳》記何植擊殺。左夫人之葬及流言始發月日未詳，張氏與卷059所記王氏分讀。[274 年奚熙案](../../years/ce-0201-0300/ce-0274.md#sg-note-2) · [張氏左夫人](../../years/ce-0201-0300/时期-三国志卷050-妃嫔传纪年待考.md#wu050-l80-3)

## 是儀傳

<a id="txt-l5"></a>

<a id="l2942"></a>

[是儀的籍貫、仕宦與改姓](../../years/ce-0201-0300/时期-三国志卷062-是仪胡综传纪年待考.md#wu062-l5-1)

<a id="txt-l38"></a>

時魏降人或云魏都督河北振威將軍吳質，頗見猜疑，綜乃偽爲質作降文三條：

[229 年第 5 條](../../years/ce-0201-0300/ce-0229.md#wu062-l42-2)

<a id="txt-l44"></a>

<a id="l2953"></a>

<a id="edition-wu062-l44-1"></a>

其一曰：「天綱弛絕，四海分崩，羣生憔悴，士人播越，兵寇所加，邑無居民，風塵煙火，往往而處，自三代以來，大亂之極，未有若今時者也。臣質志薄，處時無方，繫於土壤，不能飜飛，遂爲曹氏執事戎役，遠處河朔，天衢隔絕，雖望風慕義，思託大命，媿無因緣，得展其志。每往來者，竊聽風化，伏知陛下齊德乾坤，同明日月，神武之姿，受之自然，敷演皇極，流化萬里，自江以南，戶受覆燾。英雄俊傑，上達之士，莫不心歌腹詠，樂在歸附者也。今年六月末，奉聞吉日，龍興踐阼，恢弘大繇，整理天綱，將使遺民，覩見定主。昔武王伐殷，殷民倒戈；高祖誅項，四面楚歌。方之今日，未足以喻。臣質不勝昊天至願，謹遣所親同郡黃定恭行奉表，及託降叛，間關求達，其欲所陳，載列于左。」

[229 年第 5 條](../../years/ce-0201-0300/ce-0229.md#wu062-l44-1)

<a id="txt-l46"></a>

<a id="l2954"></a>

<a id="edition-wu062-l46-1"></a>

其二曰：「昔伊尹去夏入商，陳平委楚歸漢，書功竹帛，遺名後世，世主不謂之背誕者，以爲知天命也。臣昔爲曹氏所見交接，外託君臣，內如骨肉，恩義綢繆，有合無離，遂受偏方之任，總河北之軍。當此之時，志望高大，永與曹氏同死俱生，惟恐功之不建，事之不成耳。及曹氏之亡，後嗣繼立，幼沖統政，讒言彌興。同儕者以勢相害，異趣者得間其言，而臣受性簡略，素不下人，視彼數子，意實迫之，此亦臣之過也。遂爲邪議所見搆會，招致猜疑，誣臣欲叛。雖識真者保明其心，世亂讒勝，餘嫌猶在，常懼一旦橫受無辜，憂心孔疚，如履冰炭。昔樂毅爲燕昭王立功於齊，惠王即位，疑奪其任，遂去燕之趙，休烈不虧。彼豈欲二三其德，蓋畏功名不建，而懼禍之將及也。昔遣魏郡周光以賈販爲名，託叛南詣，宣達密計。時以倉卒，未敢便有章表，使光口傳而已。以爲天下大歸可見，天意所在，非吳復誰？此方之民，思爲臣妾，延頸舉踵，惟恐兵來之遲耳。若使聖恩少加信納，當以河北承望王師，欵心赤實，天日是鑒。而光去經年，不聞咳唾，未審此意竟得達不？瞻望長歎，日月以幾，魯望高子，何足以喻！又臣今日見待稍薄，蒼蠅之聲，緜緜不絕，必受此禍，遲速事耳。臣私度陛下未垂明慰者，必以臣質貫穿仁義之道，不行若此之事，謂光所傳，多虛少實，或謂此中有他消息，不知臣質搆讒見疑，恐受大害也。且臣質若有罪之，且自當奔赴鼎鑊，束身待罪，此蓋人臣之宜也。今日無罪，橫見譖毀，將有商鞅、白起之禍。尋惟事勢，去亦宜也。死而弗義，不去何爲！樂毅之出，吳起之走，君子傷其不遇，未有非之者也。願陛下推古況今，不疑怪於臣質也。又念人臣獲罪，當如伍員奉己自效，不當徼幸因事爲利。然今與古，厥勢不同，南北悠遠，江湖隔絕，自不舉事，何得濟免！是以忘志士之節，而思立功之義也。

[229 年第 5 條](../../years/ce-0201-0300/ce-0229.md#wu062-l46-1)

<a id="edition-wu062-l46-2"></a>

### 〈是儀胡綜傳〉紀年與異說
- **是儀遷會稽、胡綜初任及召掌書部。** 〈是儀傳〉以劉繇敗敘是儀遷會稽，敗戰依《通鑑》考異所採興平二年（195），遷居無獨立年月。胡綜十四歲任門下循行，附196年孫策領會稽後任用，同任期間未記具體年。孫權200年接掌後徵是儀、任胡綜為金曹從事。胡綜所從黃祖之役欠確年；本傳載孫權行車騎將軍、在京時召胡綜掌書部，與209年行車騎將軍、211年徙秣陵兩端互校。[劉繇敗](../../years/ce-0101-0200/ce-0195.md#ce195-note-13) · [孫策領會稽](../../years/ce-0101-0200/ce-0196.md#ce0196-note-10) · [孫權承業](../../years/ce-0101-0200/ce-0200.md#ce0200-note-10) · [孫權行車騎將軍](../../years/ce-0201-0300/ce-0209.md#ce209-note-2) · [通鑑考異](../../史书/025-资治通鉴/KR2b0007_061.txt#L478-L481)

- **黃龍改元與胡綜擬吳質降文。** 本傳以黃武八年續記孫權即位、改元及命作大牙賦，《吳主傳》載即位在229年四月丙申。首篇擬文「今年六月末」是文中假託吳質聞訊之語。三篇隨229年記事全文合讀，擬文流傳時吳質已入為侍中，《吳質別傳》明載入侍中在太和四年（230）。[黃龍大牙賦](../../years/ce-0201-0300/ce-0229.md#ce0229-note-4) · [三篇擬降文](../../years/ce-0201-0300/ce-0229.md#ce0229-note-5) · [吳質入魏廷](../../years/ce-0201-0300/ce-0230.md#ce0230-note-4) · [吳質附傳裴注](卷021.txt#L66)

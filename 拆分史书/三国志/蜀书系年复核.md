# 蜀書十五卷系年復核

[分卷目錄](README.md) · [逐項核查明細](蜀书系年复核-核查明细.md) · [按年讀史](../../years/README.md)

復核日期：2026年11月24—25日。範圍為《三國志》卷031—045，即蜀書卷一至卷十五，連同所接年頁、時期頁、同號注及舊入口。

本輪以既有全文拆分為基礎，對讀維基百科相關人物條目、《資治通鑑》及《考異》、盧弼《三國志集解》，再以《華陽國志》《三國史辨誤》、汪曰楨《二十四史月日考》稿本及相關本紀、列傳覆核。整理成 **104筆核查記錄**，其中同一事件可能涉及不同卷，不能把104筆理解為104處獨立錯誤，也不表示每一生平細節都取得三部書各自獨立的年月證明。

可據外證定年的材料已移入年頁正文及同號注；推算所得的年明標推定；不能唯一決定的年月，保留時期頁或並列異說。原《三國志》TXT與源頁原文字序不變，搬移、拆句後的完整引文仍可雙向往返，舊錨點繼續接到現行位置。

<a id="method"></a>

## 一、如何判斷系年

1. **先辨明誰記了哪個年月。** 本傳、同書本紀、裴注引書及後世編年書分別標明；本傳不署年而《通鑑》系某年的，寫成「依《通鑑》附某年」，不冒稱本傳明載。
2. **區分事件的不同階段。** 下詔、出發、到達、會師、撤軍、卒日及消息傳到他國，不因長段連敘便合為一個月或一年。書信與奏疏中的追敘，也不一概視為成文當年的新事件。
3. **通篇讀編年上下文。** 《通鑑》的「初」「先是」及倒敘不能直接當成當年發生；年首、月標要核到實際段落。張飛宕渠之戰仍在建安二十年條，不能因靠近二十一年年首便移到216。
4. **校說需要回到所據材料。** 《集解》是彙集互校的重要入口，但各家未必同說；陰陽曆推步、版本異字、官稱與史事相衝，均保留論證的層次。
5. **維基百科用於比較與發現問題。** 生卒欄、表格與概括段落不能取代原書。若百科採用一種推年，須回查其引據；沒有獨立書證，就不補出確月、確日或唯一生年。

## 四、曆日與官稱不能僅按表面換算

### 關羽：漢曆建安二十四年十二月與西曆220年初

[219年頁](../../years/ce-0201-0300/ce-0219.md#shu036-l26-2)保留史書年次「建安二十四年十二月」，同時明註這一漢曆月份落在西曆220年初。[220年頁](../../years/ce-0201-0300/ce-0220.md#shu036-l27-2)按《武帝紀》建安二十五年正月的收首記錄附讀《吳歷》材料。這是不同曆法的年界及消息傳遞階段，不能據兩個頁名推成兩次遇害，也不補原書未載的確日。

<a id="leap-month"></a>

### 劉備卒日與244年閏月：核到汪氏原稿

223年《先主傳》作四月癸巳，諸葛亮表作今月二十四日。《集解》所載潘眉推算與汪曰楨所用曆術不同；汪氏認為蜀沿漢四分術，不能直接以吳乾象術代之，推二十四日為壬午。現保留原文兩種記錄，正文依報喪表記二十四日，完整算法分歧見[223年注](../../years/ce-0201-0300/ce-0223.md#shu032-l140-1)與[稿本摘錄](../../史书/064-二十四史月日考/README.md#wang-223)。

244年固定底本只作「閏月」；《集解》所錄毛本、潘眉說涉及閏二月。汪氏原稿據節氣與各曆術判作閏三月，認為毛本的「二」是衍字。現沒有把二或三無說明地補入陳壽原文，年頁並列校說，見[244年注](../../years/ce-0201-0300/ce-0244.md#shu033-l60-1)及[稿本原頁](../../史书/064-二十四史月日考/README.md#wang-244)。

兩段在原第4冊PDF第64、66頁，卷題在第63頁，內題明為卷十七。舊注依識典導航寫卷十八，已改正。轉錄對「夏侯元」「耳」「譌」「攷」等字及行間補字逐一核圖，保留原貌，並註明未轉錄的一列旁增。

<a id="didao-days"></a>

### 255年：辛未與戊辰不能照行文寫成同月先後

《三少帝紀》在同一八月先敘辛未詔、後敘戊辰遣兵。若兩干支均無誤，戊辰在辛未前三日；按順文理解成下一個戊辰，則相隔五十七日，不能同屬一月。《集解》引陳景雲說及[《三國史辨誤》](../../史书/063-三国史辨误/KR2a0013_001.txt#L36-L38)均已辨其倒置。

現保留原紀兩字，在[255年正文與注](../../years/ce-0201-0300/ce-0255.md#wei004-l98-1)撤去白話新增的「辛未之後再於戊辰」次序；不自行猜改其中一個干支。

<a id="donghe-office"></a>

### 董和：214年「左將軍大司馬府」可以保留

《先主傳》在[211年劉備入蜀](卷032.txt#L84)已記劉璋推先主行大司馬、領司隸校尉，因此不能以219年稱漢中王的官稱套回去，斷言214年「大司馬府」不可能存在。「推行」與漢廷正式授命也要區分。現[董和214年並署府事](../../years/ce-0201-0300/ce-0214.md#shu039-l9-1)保留，補明官稱內證；《集解》所收胡三省、何焯說亦未要求把本事強移219。

## 五、費禕使吳：改正「首次」之說

《費禕傳》的「亮以初從南歸」是諸葛亮剛從南中回來，不是費禕初次使吳。[《鄧芝傳》](卷045.md#text)另記劉備生前已屢遣費禕等答聘，《集解》PDF1192亦提示此點。

因此[225年附記](../../years/ce-0201-0300/ce-0225.md#ce225-note-3)、[時期頁完整問答](../../years/ce-0201-0300/时期-三国志卷044-蒋琬费祎姜维传纪年待考.md#shu044-l27-5)、源頁標題及目錄均改稱「南征後費禕使吳」。這一次行程仍限定在225年末南歸後至227年北駐漢中前，出發、歸國的確年不硬補。改的是「生平首次」的錯誤釋讀，不是把完整出使問答縮成一句。

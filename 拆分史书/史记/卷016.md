<a id="preface-1"></a>
## 表序第一段

> 太史公讀秦楚之際，曰：初作難，發於陳涉；虐戾滅秦，自項氏；撥亂誅暴，平定海內，卒踐帝祚，成於漢家。五年之閒，號令三嬗。自生民以來，未始有受命若斯之亟也。

<a id="preface-2"></a>
## 表序第二段

> 昔虞、夏之興，積善累功數十年，德洽百姓，攝行政事，考之于天，然後在位。湯、武之王，乃由契、后稷修仁行義十餘世，不期而會孟津八百諸侯，猶以為未可，其后乃放弒。秦起襄公，章於文、繆，獻、孝之後，稍以蠶食六國，百有餘載，至始皇乃能并冠帶之倫。以德若彼，用力如此，蓋一統若斯之難也。

<a id="preface-3"></a>
## 表序第三段

> 秦既稱帝，患兵革不休，以有諸侯也，於是無尺土之封，墮壞名城，銷鋒鏑，鉏豪桀，維萬世之安。然王跡之興，起於閭巷，合從討伐，軼於三代，鄉秦之禁，適足以資賢者為驅除難耳。故憤發其所為天下雄，安在無土不王。此乃傳之所謂大聖乎？豈非天哉，豈非天哉！非大聖孰能當此受命而帝者乎？

三段释义与作者观念见[纪年与异说第八节](#kao-af57f6d27a)。

<p><a id="part-1-L1484"></a>太史公讀秦楚之際，曰：初作難，發於陳涉；虐戾滅秦，自項氏；撥亂誅暴，平定海內，卒踐帝祚，成於漢家。五年之閒，號令三嬗。自生民以來，未始有受命若斯之亟也。</p>

<p><a id="part-1-L1486"></a>秦既稱帝，患兵革不休，以有諸侯也，於是無尺土之封，墮壞名城，銷鋒鏑，鉏豪桀，維萬世之安。然王跡之興，起於閭巷，合從討伐，軼於三代，鄉秦之禁，適足以資賢者為驅除難耳。故憤發其所為天下雄，安在無土不王。此乃傳之所謂大聖乎？豈非天哉，豈非天哉！非大聖孰能當此受命而帝者乎？</p>

## 全文及三家注

<a id="part-2-p0"></a>

### p0

> 〔索隱〕張晏曰：「時天下未定，參錯變易，不可以年記，故列其月。」今案秦楚之際，擾攘僭篡，運數又促，故以月紀事名表也。

<a id="part-2-p1"></a>

### p1

> 太史公讀秦楚之際，曰：初作難，發於陳涉；虐戾滅秦，自項氏；撥亂誅暴，平定海內，卒踐帝祚，成於漢家。五年之間，號令三嬗。〔集解〕音善。〔索隱〕古「禪」字，音巿戰反。三嬗，謂陳涉、項氏、漢高祖也。自生民以來，未始有受命若斯之亟也。〔索隱〕音己力反。亟訓急也。

<a id="part-2-p2"></a>

### p2

> 昔虞、夏之興，積善累功數十年，德洽百姓，攝行政事，考之于天，〔集解〕韋昭曰：「謂舜受禪，在璇璣玉衡以齊七政。」然後在位。湯、武之王，乃由契、后稷修仁行義十餘世，不期而會孟津八百諸侯，猶以爲未可，其後乃放弒。〔索隱〕後乃放殺。殺音弒，謂湯放桀，武王討紂也。秦起襄公，章於文、繆，獻、孝之後，稍以蠶食六國，百有餘載，至始皇乃能并冠帶之倫。以德若彼，〔索隱〕即契、后稷及秦襄公、文公、穆公也。用力如此，〔索隱〕謂湯、武及始皇。蓋一統若斯之難也。

<a id="part-2-p3"></a>

### p3

> 秦旣稱帝，患兵革不休，以有諸侯也，於是無尺土之封，墮壞名城，銷鋒鏑，〔集解〕徐廣曰：「一作『鍉』。」〔索隱〕鏑音的。注「鍉」字亦音的。案：秦銷鋒鏑，作金人十二，以弱天下之兵也。鉏豪桀，維萬世之安。〔索隱〕維訓度，謂計度令萬代安也。然王跡之興，起於閭巷，合從討伐，軼於三代，鄉秦之禁，適足以資賢者爲驅除難耳。〔索隱〕鄉秦之禁適足資賢者。鄉音向，許亮反。謂秦前時之禁兵及不封樹諸侯，適足以資後之賢者，即高帝也。言驅除患難耳。故憤發其所爲天下雄，〔索隱〕指漢高祖。安在無土不王。〔集解〕白虎通曰：「聖人無土不王，使舜不遭堯，　當如夫子老於闕里也。」此乃傳之所謂大聖乎？〔索隱〕言高祖起布衣，卒傳之天位，實所謂大聖。豈非天哉，豈非天哉！非大聖孰能當此受命而帝者乎？

<a id="part-2-p4"></a>

### p4

> 索隱述贊曰：秦失其鹿，羣雄競逐。狐鳴楚祠，龍興沛谷。武臣自王，魏豹必復。田儋據齊，英布居六。項王主命，義帝見戮。以月繫年，道悠運速。洶洶天下，瞻烏誰屋？真人霸上，卒享天祿。

### 一、月份与年页不是公历日期
沿项目既有口径，二世元年至三年分别入前209—207年页，汉元年至五年入前206—202年页。秦汉初以十月为岁首，所以十月、十一月、十二月在同一古史年条的正月以前。汉元年十月子婴降汉，通常按公历年界仍在前207年，本项目接在前206年文件，不表示过了一整年，更不是公历前206年10月。[既有说明](卷006.md#kao-8531c8d91a-f2af61e00)。

原表有二世二年、汉二年、汉五年三个“后九月”，均独立保留。全表90个位置由3、13、12、12、13、12、12、13个月组成，不能按八个年份各乘十二，也不把后九月吞入九月。“端月”按正月阅读，原字不改。“二年一月”“三年一月”常是本国纪月计数重启，不是该行实际都到了正月；楚、项、赵等栏的数字不能套用汉栏年号。

表序“五年之间，号令三嬗”是作者概括权力递换的说法，不是全表只有60个月的计数说明。陈涉七月格“起兵入秦”亦为压缩概括，不能把周文九月到戏的经历提前到七月，或说陈胜亲自进了咸阳。

<a id="kao-af57f6d27a-d0704bc9c"></a>

### 二、分栏改变与王国改名
前31个月份位置沿“秦、楚、项、赵、齐、汉、燕、魏、韩”九栏；汉元年正月起扩成20个实际位置。后段源网页的合并表头不能直接当成每行只有八国。摘录页采用编辑性展开列名，以位置追踪楚／义帝、西楚、衡山、临江、九江、常山、代、齐、济北、胶东、汉、雍、塞、翟、燕、辽东、西魏、殷、韩、河南，并标明后续改属。

陈馀的代王在原常山栏续记，赵歇的赵国在原代栏续记；后来张耳赵王又写入前者。韩信迁楚续入项栏，长沙又写到原河南栏。它们是表的空间安排，不证明这些王国始终位于同一片土地。特别“分临江为长沙国”不能译成申阳的河南国实际迁成长沙。

原表20位置包括义帝和项羽，十八王是另十八位，不能据20列造出“项羽分封二十王”。分封的名号、预定都城、实际就国和军事控制分开：三月“都南郑”等不是所有国君都已同月抵达的旅行记录，四月才另记罢兵就国；韩成后来仍未获准就国。

<a id="kao-af57f6d27a-d81a5d1c9"></a>

### 三、前209—208年的起兵与重立旧国
项梁“号武信君”在二世元年九月格，《项羽本纪》却接在二世二年拥立怀王后。正文保留既有前208年授号主线，前209年只留异年注，不另造两次封号。魏咎元年九月已有“始”，但同格明言仍在陈；二年十二月归国就位，是两个阶段。田儋二年十月格回顾杀狄令称王，不再立第二次齐王。

韩成在二年六月栏登场，补入本年复韩；《留侯世家》记张良劝项梁立韩诸公子横阳君成、任韩司徒，两人略韩地，所得数城又为秦夺，往来颍川。本段只为复韩背景和当年行动，不把张良全部早年移到这里。[卷055](卷055.md#part-1-text)。

秦嘉为上将军、周市赴齐楚求援、魏豹自立、连月大雨等分别入正文或该月注。秦嘉、景驹之死从较详的本纪区分战死与逃死，不因表格合称“击杀”就编同处处刑。六月陈婴任柱国与月表七月有差别，保留两个位置；七八月东阿救援跨栏叙次不强拼成两场相同解围。

<a id="kao-af57f6d27a-c93827fe7"></a>

### 四、巨鹿、张陈决裂与西路行军
月表十二月记巨鹿大破秦军，端月再记俘王离；《汉书》《通鉴》将主要胜利和俘将连写在十二月。正文保持一个战局，注中说明阶段与异月，不宣布已确证两个月各有一场独立巨鹿决战。刘邦在成武南破“王离军”不是刘邦也在巨鹿俘王离；十二月汉栏“（救赵）”不作为其北渡救赵的可靠新行程。

张耳怨陈馀不救，陈馀交印离开，由《张耳陈馀列传》解开原表“张耳怒陈馀，弃将印去”的省略主语。弃印者为陈馀，不是张耳。八月陈馀居南皮、赵歇留赵和张耳随后入关相接。[卷089](卷089.md#part-1-text)。

司马欣四月入秦、五月逃回，六月议降未定、七月盟降、八月改编降军，按多阶段连读；降约许雍王与次年分封是衔接关系。南阳守齮战败的地点，表作阳城郭东，本纪、汉书作犨东，正文沿既有南阳战线，异地留注。申阳下河南、降楚在韩栏借记，不因此改成韩国国君。九月“不战皆降”与本纪、汉书的蓝田战事不合，正文仍保留作战与劝降两种手段，不抹去已记战斗。

<a id="kao-af57f6d27a-a2ec897dc"></a>

### 五、分封、三秦与齐燕韩变局
元年十二月格预述“分天下”，正月列拆分、二月列王、三月列都、四月就国。继续以二月为封王主叙，注明不同层次，不能把同一分封重办四次。义帝迁郴月表系二月，本纪连于四月后，正文只记本年受催迁；次年十月遇害另列。

五月田都败逃、六月田市死、七月田安与韩成死、八月韩广败亡及郑昌受立，分月互见。田都不按《高祖本纪》孤立“杀”字再处死一次。刘邦还定三秦沿本纪与《通鉴》八月，月表八月废丘受围、塞翟归汉可与之衔接；《汉书》五月仍在旧注保留。九月郡名是原表行政归属记录，不假定汉军当天已控制原境全部。

<a id="kao-af57f6d27a-3cd671d69"></a>

### 六、汉二年至四年的重复、改属和临江继承
汉二年十月张耳降汉、赵歇复赵，十二月陈馀得代王，是分阶段；三月魏豹降汉与五月反汉亦不相互抵消。田假再被楚立、遭田横逐走后为楚所杀，补到本年；不与前208年首次逃楚混为一次。章邯六月“汉杀邯”采用本纪、汉书水攻后自杀的详记，表语留注。

汉三年十一月表在陈馀原栏写“太原郡”，与汉书常山、代郡等记载及魏亡后的郡名有出入。仅记录归属变化，不画一个未经核定的郡界图。黥布十二月身降汉而其地属项羽，说明国王归附不等于完整交出九江国；四年七月淮南封号另立。

临江王共敖三年七月卒、八月子继，补足父子更替。表称驩，汉书称共尉，沿原项目作同一末代临江王异名处理，不能让共敖在汉五年再次被俘。

荥阳材料尤不能硬拼：三年七月“王出荥阳”、八月周苛枞公杀魏豹，四年三月周苛入楚死、四月又“王出荥阳，豹死”。正文仍沿汉书、通鉴三年五月刘邦脱身、六月陷城的主线。月表两组原格都留注，未裁定具体哪处错简；不让魏豹、周苛死两次，也不靠复述格子制造第三次脱险。田广十一月“击杀”与汉书“虏”不同，正文只写败被俘，死亡日未定；田横投彭越是另一人。

<a id="kao-af57f6d27a-6af703cf8"></a>

### 七、汉五年终局与两项后年材料
项栏十二月“诛籍”与汉栏正月“杀项籍，天下平”视为同一终局的不同编排。继续取十二月垓下、项羽死，正月重分王国；不多造一次死亡。临江被俘表系十二月，本纪有围攻数月后降的过程，正文不强定与垓下同日解决。彭越正月“复置梁国”、二月“王始”，与汉书正月封王相接，表位与授命月份不强称完全一致。

即帝位同为二月甲午，表称定陶，本纪、汉书称氾水之阳；可能有地区与具体地点层次差别，本轮不径以两名定为互不相干的两次登极。原文“为为”等重复照存，不据网页错字生新事。

韩王信迁北方、都马邑，月表放汉五年正月，汉书、通鉴六年有明确安排，仍归[前201年](../../years/bce-0300-0201/bce-0201.md#sj016-forward)。楚王韩信献钟离眛首，表五年九月，列传、通鉴接六年云梦会，亦沿前201。后者详记钟离眛自杀后韩信持首，不能改成韩信在五年亲斩。两位韩信分清，两个异年不强造第二次迁国和死亡。[卷092](卷092.md#part-1-text) · [《通鉴》卷十一](../资治通鉴/卷011.md#text)。

张耳、吴芮七月死、张敖吴臣八月开始计月，补足既有继承链，不把谥号当作个人原名。臧荼七月反、九月俘沿汉书；表八月皇帝亲征可作期间行动，九月栏“反汉，虏荼”压缩起讫；后九月卢绾王始保留与汉书九月议立的差别。

### 八、表序与述赞的作者层次
表序先论陈涉、项氏、汉家之间迅速转移的号令，再将虞夏商周与秦的累世积累作对照，最后反思秦不封诸侯、销兵除豪的防乱措施，却未能阻止闾巷豪杰取代。这是司马迁的史论；“天”“大圣”“受命”是他的解释，不作现代因果证明，也不从序文再生成一组上古确年事件。

篇末《索隐述赞》属唐代司马贞，赞陈涉、刘邦与群雄竞逐，并以汉受天禄收束。狐鸣、龙兴、瞻乌等意象作为评论读，不另造神异事件。表前《索隐》引张晏论“不可以年记，故列其月”，是后世对体例的解释，也不冒充司马迁自述。

## 经

<a id="all-20261109-j001"></a>

七年春，王正月，鼷鼠食郊牛角，改卜牛。

<a id="all-20261109-j002"></a>

鼷鼠又食其角，乃免牛。

<a id="all-20261109-j003"></a>

吴伐郯。

<a id="all-20261109-j004"></a>

夏五月，曹伯来朝。

<a id="all-20261109-j005"></a>

不郊，犹三望。

<a id="all-20261109-j006"></a>

秋，楚公子婴齐帅师伐郑。

<a id="all-20261109-j007"></a>

公会晋侯、齐侯、宋公、卫侯、曹伯、莒子、邾子、杞伯救郑。

<a id="all-20261109-j008"></a>

八月戊辰，同盟于马陵。

<a id="all-20261109-j009"></a>

公至自会。

<a id="all-20261109-j010"></a>

吴入州来。

<a id="all-20261109-j011"></a>

冬，大雩。

<a id="all-20261109-j012"></a>

卫孙林父出奔晋。

## 传

<a id="all-20261109-t001"></a>

七年春，吴伐郯，郯成。季文子曰：“中国不振旅，蛮夷入伐，而莫之或恤，无吊者也夫！《诗》曰：‘不吊昊天，乱靡有定。’其此之谓乎！有上不吊，其谁不受乱？吾亡无日矣！”君子曰：“知惧如是，斯不亡矣。”

<a id="all-20261109-t002"></a>

郑子良相成公以如晋，见且拜师。

<a id="all-20261109-t003"></a>

夏，曹宣公来朝。

<a id="all-20261109-t004"></a>

秋，楚子重伐郑，师于氾。诸侯救郑。郑共仲、侯羽军楚师，囚郧公钟仪，献诸晋。八月，同盟于马陵，寻虫牢之盟，且莒服故也。晋人以钟仪归，囚诸军府。

<a id="all-20261109-t005"></a>

楚围宋之役，师还。子重请取于申、吕以为赏田，王许之。申公巫臣曰：“不可。此申、吕所以邑也，是以为赋，以御北方。若取之，是无申、吕也。晋、郑必至于汉。”王乃止。子重是以怨巫臣。子反欲取夏姬，巫臣止之，遂取以行。子反亦怨之。及共王即位，子重、子反杀巫臣之族子阎、子荡及清尹弗忌及襄老之子黑要，而分其室。子重取子阎之室，使沈尹与王子罢分子荡之室，子反取黑要与清尹之室。巫臣自晋遗二子书曰：“尔以谗慝贪惏事君，而多杀不辜。余必使尔罢于奔命以死。”

<a id="all-20261109-t006"></a>

巫臣请使于吴，晋侯许之。吴子寿梦说之。乃通吴于晋。以两之一卒適吴，舍偏两之一焉。与其射御，教吴乘车，教之战陈，教之叛楚。寘其子狐庸焉，使为行人于吴。吴始伐楚，伐巢，伐徐。子重奔命。马陵之会，吴入州来。子重自郑奔命。子重、子反于是乎一岁七奔命。蛮夷属于楚者，吴尽取之。是以始大，通吴于上国。卫定公恶孙林父。

<a id="all-20261109-t007"></a>

冬，孙林父出奔晋。卫侯如晋，晋反戚焉。

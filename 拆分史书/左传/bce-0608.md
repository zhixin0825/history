## 经

<a id="batch-20261109-j001"></a>

元年春，王正月，公即位。公子遂如齐逆女。

<a id="batch-20261109-j002"></a>

三月，遂以夫人妇姜至自齐。

<a id="batch-20261109-j003"></a>

夏，季孙行父如齐。

<a id="batch-20261109-j004"></a>

晋放其大夫胥甲父于卫。

<a id="batch-20261109-j005"></a>

公会齐侯于平州。

<a id="batch-20261109-j006"></a>

公子遂如齐。

<a id="batch-20261109-j007"></a>

六月，齐人取济西田。

<a id="batch-20261109-j008"></a>

秋，邾子来朝。

<a id="batch-20261109-j009"></a>

楚子、郑人侵陈，遂侵宋。

<a id="batch-20261109-j010"></a>

晋赵盾帅师救陈。

<a id="batch-20261109-j011"></a>

宋公、陈侯、卫侯、曹伯会晋师于棐林，伐郑。

<a id="batch-20261109-j012"></a>

冬，晋赵穿帅师侵崇。

<a id="batch-20261109-j013"></a>

晋人、宋人伐郑。

## 传

<a id="batch-20261109-t001"></a>

元年春，王正月，公子遂如齐逆女，尊君命也。

<a id="batch-20261109-t002"></a>

三月，遂以夫人妇姜至自齐，尊夫人也。

<a id="batch-20261109-t003"></a>

夏，季文子如齐，纳赂以请会。

<a id="batch-20261109-t004"></a>

晋人讨不用命者，放胥甲父于卫，而立胥克。先辛奔齐。

<a id="batch-20261109-t005"></a>

会于平州以定公位。东门襄仲如齐拜成。

<a id="batch-20261109-t006"></a>

六月，齐人取济西之田，为立公故，以赂齐也。

<a id="batch-20261109-t007"></a>

宋人之弑昭公也，晋荀林父以诸侯之师伐宋，宋及晋平。宋文公受盟于晋，又会诸侯于扈，将为鲁讨齐，皆取赂而还。

<a id="batch-20261109-t008"></a>

郑穆公曰：“晋不足与也。”遂受盟于楚。陈共公之卒，楚人不礼焉。陈灵公受盟于晋。

<a id="batch-20261109-t009"></a>

秋，楚子侵陈，遂侵宋。晋赵盾帅师救陈、宋。会于棐林，以伐郑也。楚蒍贾救郑，遇于北林。囚晋解扬，晋人乃还。

<a id="batch-20261109-t010"></a>

晋欲求成于秦，赵穿曰：“我侵崇，秦急崇，必救之。吾以求成焉。”

<a id="batch-20261109-t011"></a>

冬，赵穿侵崇，秦弗与成。晋人伐郑，以报北林之役。

<a id="batch-20261109-t012"></a>

于是，晋侯侈，赵宣子为政，骤谏而不入，故不竞于楚。

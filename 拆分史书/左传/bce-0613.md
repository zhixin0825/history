## 经

<a id="j001"></a>

<a id="batch-20261109-j001"></a>

十有四年春，王正月，公至自晋。

<a id="j002"></a>

<a id="batch-20261109-j002"></a>

邾人伐我南鄙。

<a id="j003"></a>

<a id="batch-20261109-j003"></a>

叔彭生帅师伐邾。

<a id="j004"></a>

<a id="batch-20261109-j004"></a>

夏五月乙亥，齐侯潘卒。

<a id="j005"></a>

<a id="batch-20261109-j005"></a>

六月，公会宋公、陈侯、卫侯、郑伯、许男、曹伯、晋赵盾，癸酉，同盟于新城。

<a id="j006"></a>

<a id="batch-20261109-j006"></a>

秋七月，有星孛入于北斗。

<a id="j007"></a>

<a id="batch-20261109-j007"></a>

公至自会。

<a id="j008"></a>

<a id="batch-20261109-j008"></a>

晋人纳捷菑于邾，弗克纳。

<a id="j009"></a>

<a id="batch-20261109-j009"></a>

九月甲申，公孙敖卒于齐。

<a id="j010"></a>

<a id="batch-20261109-j010"></a>

齐公子商人弑其君舍。

<a id="j011"></a>

<a id="batch-20261109-j011"></a>

宋子哀来奔。

<a id="j012"></a>

<a id="batch-20261109-j012"></a>

冬，单伯如齐。

<a id="j013"></a>

<a id="batch-20261109-j013"></a>

齐人执单伯。

<a id="j014"></a>

<a id="batch-20261109-j014"></a>

齐人执子叔姬。

## 传

<a id="t001"></a>

<a id="batch-20261109-t001"></a>

十四年春，顷王崩。周公阅与王孙苏争政，故不赴。凡崩、薨，不赴则不书。祸、福，不告亦不书。惩不敬也。

<a id="t002"></a>

<a id="batch-20261109-t002"></a>

邾文公之卒也，公使吊焉，不敬。邾人来讨，伐我南鄙，故惠伯伐邾。

<a id="t003"></a>

<a id="batch-20261109-t003"></a>

子叔姬妃齐昭公，生舍。叔姬无宠，舍无威。公子商人骤施于国，而多聚士，尽其家，贷于公、有司以继之。

<a id="t004"></a>

<a id="batch-20261109-t004"></a>

夏五月，昭公卒，舍即位。

<a id="t005"></a>

<a id="batch-20261109-t005"></a>

邾文公元妃齐姜生定公，二妃晋姬生捷菑。文公卒，邾人立定公，捷菑奔晋。

<a id="t006"></a>

<a id="batch-20261109-t006"></a>

六月，同盟于新城，从于楚者服，且谋邾也。

<a id="t007"></a>

<a id="batch-20261109-t007"></a>

秋七月乙卯夜，齐商人弑舍而让元。元曰：“尔求之久矣。我能事尔，尔不可使多蓄憾。将免我乎？尔为之。”

<a id="t008"></a>

<a id="batch-20261109-t008"></a>

有星孛入于北斗，周内史叔服曰：“不出七年，宋、齐、晋之君皆将死乱。”

<a id="t009"></a>

<a id="batch-20261109-t009"></a>

晋赵盾以诸侯之师八百乘纳捷菑于邾。邾人辞曰：“齐出貜且长。”宣子曰：“辞顺而弗从，不祥。”乃还。

<a id="t010"></a>

<a id="batch-20261109-t010"></a>

周公将与王孙苏讼于晋，王叛王孙苏，而使尹氏与聃启讼周公于晋。赵宣子平王室而复之。

<a id="t011"></a>

<a id="batch-20261109-t011"></a>

楚庄王立，子孔、潘崇将袭群舒，使公子燮与子仪守，而伐舒蓼。二子作乱，城郢而使贼杀子孔，不克而还。八月，二子以楚子出，将如商密。庐戢棃及叔麇诱之，遂杀鬥克及公子燮。

<a id="t012"></a>

<a id="batch-20261109-t012"></a>

初，鬥克囚于秦，秦有殽之败，而使归求成。成而不得志，公子燮求令尹而不得，故二子作乱。

<a id="t013"></a>

<a id="batch-20261109-t013"></a>

穆伯之从己氏也，鲁人立文伯。穆伯生二子于莒而求复，文伯以为请。襄仲使无朝。听命，复而不出，三年而尽室以复適莒。文伯疾而请曰：“穀之子弱，请立难也。”许之。文伯卒，立惠叔。穆伯请重赂以求复，惠叔以为请，许之。将来，九月卒于齐，告丧请葬，弗许。

<a id="t014"></a>

<a id="batch-20261109-t014"></a>

宋高哀为萧封人，以为卿，不义宋公而出，遂来奔。书曰：“宋子哀来奔。”贵之也。

<a id="t015"></a>

<a id="batch-20261109-t015"></a>

齐人定懿公，使来告难，故书以九月。齐公子元不顺懿公之为政也，终不曰“公”，曰“夫己氏”。

<a id="t016"></a>

<a id="batch-20261109-t016"></a>

襄仲使告于王，请以王宠求昭姬于齐。曰：“杀其子，焉用其母？请受而罪之。”

<a id="t017"></a>

<a id="batch-20261109-t017"></a>

冬，单伯如齐，请子叔姬。齐人执之。又执子叔姬。

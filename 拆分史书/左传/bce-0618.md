## 经

<a id="j001"></a>

<a id="batch-20261109-j001"></a>

九年春，毛伯来求金。

<a id="j002"></a>

<a id="batch-20261109-j002"></a>

夫人姜氏如齐。

<a id="j003"></a>

<a id="batch-20261109-j003"></a>

二月，叔孙得臣如京师。

<a id="j004"></a>

<a id="batch-20261109-j004"></a>

辛丑，葬襄王。

<a id="j005"></a>

<a id="batch-20261109-j005"></a>

晋人杀其大夫先都。

<a id="j006"></a>

<a id="batch-20261109-j006"></a>

三月，夫人姜氏至自齐。

<a id="j007"></a>

<a id="batch-20261109-j007"></a>

晋人杀其大夫士縠及箕郑父。

<a id="j008"></a>

<a id="batch-20261109-j008"></a>

楚人伐郑。

<a id="j009"></a>

<a id="batch-20261109-j009"></a>

公子遂会晋人、宋人、卫人、许人救郑。

<a id="j010"></a>

<a id="batch-20261109-j010"></a>

夏，狄侵齐。

<a id="j011"></a>

<a id="batch-20261109-j011"></a>

秋八月，曹伯襄卒。

<a id="j012"></a>

<a id="batch-20261109-j012"></a>

九月癸酉，地震。

<a id="j013"></a>

<a id="batch-20261109-j013"></a>

冬，楚子使椒来聘。

<a id="j014"></a>

<a id="batch-20261109-j014"></a>

秦人来归僖公、成风之襚。

<a id="j015"></a>

<a id="batch-20261109-j015"></a>

葬曹共公。

## 传

<a id="t001"></a>

<a id="batch-20261109-t001"></a>

九年春，王正月己酉，使贼杀先克。乙丑，晋人杀先都、梁益耳。

<a id="t002"></a>

<a id="batch-20261109-t002"></a>

毛伯卫来求金，非礼也。不书王命，未葬也。

<a id="t003"></a>

<a id="batch-20261109-t003"></a>

二月，庄叔如周。葬襄王。

<a id="t004"></a>

<a id="batch-20261109-t004"></a>

三月甲戌，晋人杀箕郑父、士縠、蒯得。

<a id="t005"></a>

<a id="batch-20261109-t005"></a>

范山言于楚子曰：“晋君少，不在诸侯，北方可图也。”楚子师于狼渊以伐郑。囚公子坚、公子尨及乐耳。郑及楚平。公子遂会晋赵盾、宋华耦、卫孔达、许大夫救郑，不及楚师。卿不书，缓也，以惩不恪。

<a id="t006"></a>

<a id="batch-20261109-t006"></a>

夏，楚侵陈，克壶丘，以其服于晋也。

<a id="t007"></a>

<a id="batch-20261109-t007"></a>

秋，楚公子朱自东夷伐陈，陈人败之，获公子茷。陈惧，乃及楚平。

<a id="t008"></a>

<a id="batch-20261109-t008"></a>

冬，楚子越椒来聘，执币傲。叔仲惠伯曰：“是必灭若敖氏之宗。傲其先君，神弗福也。”

<a id="t009"></a>

<a id="batch-20261109-t009"></a>

秦人来归僖公、成风之襚，礼也。诸侯相吊贺也，虽不当事，苟有礼焉，书也，以无忘旧好。

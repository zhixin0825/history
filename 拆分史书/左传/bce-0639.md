## 经

<a id="batch-20261109-j001"></a>

二十有一年春，狄侵卫。

<a id="batch-20261109-j002"></a>

宋人、齐人、楚人盟于鹿上。

<a id="batch-20261109-j003"></a>

夏，大旱。

<a id="batch-20261109-j004"></a>

秋，宋公、楚子、陈侯、蔡侯、郑伯、许男、曹伯会于盂。

<a id="batch-20261109-j005"></a>

执宋公以伐宋。

<a id="batch-20261109-j006"></a>

冬，公伐邾。

<a id="batch-20261109-j007"></a>

楚人使宜申来献捷。

<a id="batch-20261109-j008"></a>

十有二月癸丑，公会诸侯盟于薄，释宋公。

<a id="zhuan"></a>

## 传

<a id="batch-20261109-t001"></a>

二十一年春，宋人为鹿上之盟，以求诸侯于楚。楚人许之。公子目夷曰：“小国争盟，祸也。宋其亡乎，幸而后败。”

<a id="batch-20261109-t002"></a>

夏，大旱，公欲焚巫尪。臧文仲曰：“非旱备也。修城郭，贬食省用，务穑劝分，此其务也。巫尪何为？天欲杀之，则如勿生，若能为旱，焚之滋甚。”公从之。是岁也，饥而不害。

<a id="batch-20261109-t003"></a>

秋，诸侯会宋公于盂。子鱼曰：“祸其在此乎！君欲已甚，其何以堪之？”于是楚执宋公以伐宋。

<a id="batch-20261109-t004"></a>

冬，会于薄以释之。子鱼曰：“祸犹未也，未足以惩君。”任、宿、须句、颛臾，风姓也，实司大皞与有济之祀，以服事诸夏。邾人灭须句，须句子来奔，因成风也。成风为之言于公曰：“崇明祀，保小寡，周礼也。蛮夷猾夏，周祸也。若封须句是崇皞、济而修祀纾祸也。”

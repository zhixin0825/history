## 经

<a id="batch-20261109-j001"></a>

十有六年春，王正月戊申朔，陨石于宋五。

<a id="batch-20261109-j002"></a>

是月，六鹢退飞过宋都。

<a id="batch-20261109-j003"></a>

三月壬申，公子季友卒。

<a id="batch-20261109-j004"></a>

夏四月丙申，鄫季姬卒。

<a id="batch-20261109-j005"></a>

秋七月甲子，公孙兹卒。

<a id="batch-20261109-j006"></a>

冬十有二月，公会齐侯、宋公、陈侯、卫侯、郑伯、许男、邢侯、曹伯于淮。

<a id="zhuan"></a>

## 传

<a id="batch-20261109-t001"></a>

十六年春，陨石于宋五，陨星也。六鹢退飞过宋都，风也。周内史叔兴聘于宋。宋襄公问焉，曰：“是何祥也？吉凶焉在？”对曰：“今兹鲁多大丧，明年齐有乱，君将得诸侯而不终。”退而告人曰：“君失问。是阴阳之事，非吉凶所在也。吉凶由人，吾不敢逆君故也。”

<a id="batch-20261109-t002"></a>

夏，齐伐厉不克，救徐而还。

<a id="batch-20261109-t003"></a>

秋，狄侵晋，取狐厨、受铎，涉汾，及昆都，因晋败也。

<a id="batch-20261109-t004"></a>

王以戎难告于齐，齐征诸侯而戍周。

<a id="batch-20261109-t005"></a>

冬，十一月乙卯，郑杀子华。

<a id="batch-20261109-t006"></a>

十二月会于淮，谋鄫，且东略也。城鄫，役人病。有夜登丘而呼曰：“齐有乱。”不果城而还。

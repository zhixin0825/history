## 经

<a id="j001"></a>

<a id="batch-20261109-j001"></a>

二年春，王正月，城楚丘。

<a id="j002"></a>

<a id="batch-20261109-j002"></a>

夏五月辛巳，葬我小君哀姜。

<a id="j003"></a>

<a id="batch-20261109-j003"></a>

虞师、晋师灭下阳。

<a id="j004"></a>

<a id="batch-20261109-j004"></a>

秋九月，齐侯、宋公、江人、黄人盟于贯。

<a id="j005"></a>

冬十月，不雨。楚人侵郑。

## 传

<a id="t001"></a>

<a id="batch-20261109-t001"></a>

二年春，诸侯城楚丘而封卫焉。不书所会，后也。

<a id="t002"></a>

<a id="batch-20261109-t002"></a>

晋荀息请以屈产之乘，与垂棘之璧，假道于虞以伐虢。公曰：“是吾宝也。”对曰：“若得道于虞，犹外府也。”公曰：“宫之奇存焉。”对曰：“宫之奇之为人也，懦而不能强谏，且少长于君，君暱之，虽谏，将不听。”乃使荀息假道于虞，曰：“冀为不道，入自颠軨，伐鄍三门。冀之既病，则亦唯君故。今虢为不道，保于逆旅，以侵敝邑之南鄙。敢请假道以请罪于虢。”虞公许之，且请先伐虢。宫之奇谏，不听，遂起师。

<a id="t003"></a>

<a id="batch-20261109-t003"></a>

夏，晋里克、荀息帅师会虞师伐虢，灭下阳。先书虞，贿故也。

<a id="t004"></a>

<a id="batch-20261109-t004"></a>

秋，盟于贯，服江、黄也。

<a id="t005"></a>

<a id="batch-20261109-t005"></a>

齐寺人貂始漏师于多鱼。

<a id="t006"></a>

<a id="batch-20261109-t006"></a>

虢公败戎于桑田。晋卜偃曰：“虢必亡矣，亡下阳不惧，而又有功，是天夺之鉴，而益其疾也。必易晋而不抚其民矣，不可以五稔。”

<a id="t007"></a>

<a id="batch-20261109-t007"></a>

冬，楚人伐郑，鬥章囚郑耼伯。

## 传

<a id="t001"></a>

<a id="batch-20261109-t001"></a>

二十年春，郑伯和王室，不克。执燕仲父。

<a id="t002"></a>

<a id="batch-20261109-t002"></a>

夏，郑伯遂以王归，王处于栎。

<a id="t003"></a>

<a id="batch-20261109-t003"></a>

秋，王及郑伯入于邬。遂入成周，取其宝器而还。

<a id="t004"></a>

<a id="batch-20261109-t004"></a>

冬，王子颓享五大夫，乐及徧舞。郑伯闻之，见虢叔，曰：“寡人闻之，哀乐失时，殃咎必至。今王子颓歌舞不倦，乐祸也。夫司寇行戮，君为之不举，而况敢乐祸乎！奸王之位，祸孰大焉？临祸忘忧，忧必及之。盍纳王乎？”虢公曰：“寡人之愿也。”

## 经

<a id="j001"></a>

<a id="batch-20261109-j001"></a>

十年春，王正月，公败齐师于长勺。

<a id="j002"></a>

<a id="batch-20261109-j002"></a>

二月，公侵宋。

<a id="j003"></a>

<a id="batch-20261109-j003"></a>

三月，宋人迁宿。

<a id="j004"></a>

<a id="batch-20261109-j004"></a>

夏六月，齐师、宋师次于郎。公败宋师于乘丘。

<a id="j005"></a>

<a id="batch-20261109-j005"></a>

秋九月，荆败蔡师于莘，以蔡侯献舞归。

<a id="j006"></a>

冬十月，齐师灭谭。谭子奔莒。

<a id="zhuan"></a>

## 传

<a id="t001"></a>

<a id="batch-20261109-t001"></a>

十年春，齐师伐我。公将战，曹刿请见。其乡人曰：“肉食者谋之，又何间焉。”刿曰：“肉食者鄙，未能远谋。”乃入见。问何以战。公曰：“衣食所安，弗敢专也，必以分人。”对曰：“小惠未徧，民弗从也。”公曰：“牺牲玉帛，弗敢加也，必以信。”对曰：“小信未孚，神弗福也。”公曰：“小大之狱，虽不能察，必以情。”对曰：“忠之属也，可以一战。战则请从。”公与之乘。战于长勺，公将鼓之。刿曰：“未可。”齐人三鼓，刿曰：“可矣。”齐师败绩。公将驰之。刿曰：“未可。”下视其辙，登轼而望之，曰：“可矣。”遂逐齐师。

<a id="t002"></a>

<a id="batch-20261109-t002"></a>

既克，公问其故。对曰：“夫战，勇气也。一鼓作气，再而衰，三而竭。彼竭我盈，故克之。夫大国难测也，惧有伏焉。吾视其辙乱，望其旗靡，故逐之。”

<a id="t003"></a>

<a id="batch-20261109-t003"></a>

夏六月，齐师、宋师次于郎。公子偃曰：“宋师不整，可败也。宋败，齐必还，请击之。”公弗许。自雩门窃出，蒙皋比而先犯之。公从之，大败宋师于乘丘。齐师乃还。蔡哀侯娶于陈，息侯亦娶焉。息妫将归，过蔡。蔡侯曰：“吾姨也。”止而见之，弗宾。息侯闻之，怒，使谓楚文王曰：“伐我，吾求救于蔡而伐之。”楚子从之。

<a id="t004"></a>

<a id="batch-20261109-t004"></a>

秋九月，楚败蔡师于莘，以蔡侯献舞归。齐侯之出也，过谭，谭不礼焉。及其入也，诸侯皆贺，谭又不至。

<a id="t005"></a>

<a id="batch-20261109-t005"></a>

冬，齐师灭谭，谭无礼也。谭子奔莒，同盟故也。

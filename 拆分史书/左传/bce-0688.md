## 经

<a id="batch-20261109-j001"></a>

六年春，王正月，王人子突救卫。

<a id="batch-20261109-j002"></a>

夏六月，卫侯朔入于卫。

<a id="batch-20261109-j003"></a>

秋，公至自伐卫。螟。

<a id="batch-20261109-j004"></a>

冬，齐人来归卫俘。

## 传

<a id="batch-20261109-t001"></a>

六年春，王人救卫。

<a id="batch-20261109-t002"></a>

夏，卫侯入，放公子黔牟于周，放甯跪于秦，杀左公子洩、右公子职，乃即位。君子以二公子之立黔牟为不度矣。夫能固位者必度于本末而后立衷焉。不知其本，不谋。知本之不枝，弗强。《诗》云：“本枝百世。”

<a id="batch-20261109-t003"></a>

冬，齐人来归卫宝，文姜请之也。

<a id="batch-20261109-t004"></a>

楚文王伐申，过邓。邓祁侯曰：“吾甥也。”止而享之。骓甥、耼甥、养甥请杀楚子，邓侯弗许。三甥曰：“亡邓国者，必此人也。若不早图，后君噬齐，其及图之乎？图之，此为时矣。”邓侯曰：“人将不食吾馀。”对曰：“若不从三臣，抑社稷实不血食，而君焉取余。”弗从。还年，楚子伐邓。十六年，楚复伐邓，灭之。

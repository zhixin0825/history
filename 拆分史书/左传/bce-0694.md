## 经

<a id="batch-20261109-j001"></a>

十有八年春，王正月，公会齐侯于泺。公与夫人姜氏遂如齐。

<a id="batch-20261109-j002"></a>

夏四月丙子，公薨于齐。丁酉，公之丧至自齐。

<a id="batch-20261109-j003"></a>

秋七月。

<a id="batch-20261109-j004"></a>

冬十有二月己丑，葬我君桓公。

## 传

<a id="batch-20261109-t001"></a>

十八年春，公将有行，遂与姜氏如齐。申𦈡曰：“女有家，男有室，无相渎也，谓之有礼。易此必败。”公会齐侯于泺，遂及文姜如齐。齐侯通焉。公谪之，以告。

<a id="batch-20261109-t002"></a>

夏四月丙子，享公。使公子彭生乘公，公薨于车。

<a id="batch-20261109-t003"></a>

鲁人告于齐曰：“寡君畏君之威，不敢宁居，来修旧好，礼成而不反，无所归咎，恶于诸侯。请以彭生除之。”齐人杀彭生。

<a id="batch-20261109-t004"></a>

秋，齐侯师于首止，子亹会之，高渠弥相。七月戊戌，齐人杀子亹而轘高渠弥，祭仲逆郑子于陈而立之。是行也，祭仲知之，故称疾不往。人曰：“祭仲以知免。”仲曰：“信也。”

<a id="batch-20261109-t005"></a>

周公欲弑庄王而立王子克。辛伯告王，遂与王杀周公黑肩。王子克奔燕。初，子仪有宠于桓王，桓王属诸周公。辛伯谏曰：“并后，匹嫡，两政，耦国，乱之本也。”周公弗从，故及。

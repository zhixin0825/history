## 经

<a id="batch-20261109-j001"></a>

十有七年春正月丙辰，公会齐侯、纪侯盟于黄。

<a id="batch-20261109-j002"></a>

二月丙午，公会邾仪父，盟于趡。

<a id="batch-20261109-j003"></a>

夏五月丙午，及齐师战于奚。

<a id="batch-20261109-j004"></a>

六月丁丑，蔡侯封人卒。

<a id="batch-20261109-j005"></a>

秋八月，蔡季自陈归于蔡。癸巳，葬蔡桓侯。及宋人、卫人伐邾。

<a id="batch-20261109-j006"></a>

冬十月朔，日有食之。

<a id="zhuan"></a>

## 传

<a id="batch-20261109-t001"></a>

十七年春，盟于黄，平齐、纪，且谋卫故也。及邾仪父盟于趡，寻蔑之盟也。

<a id="batch-20261109-t002"></a>

夏，及齐师战于奚，疆事也。于是齐人侵鲁疆。疆吏来告，公曰：“疆埸之事，慎守其一而备其不虞，姑尽所备焉。事至而战，又何谒焉。”蔡桓侯卒，蔡人召蔡季于陈。

<a id="batch-20261109-t003"></a>

秋，蔡季自陈归于蔡，蔡人嘉之也。伐邾，宋志也。

<a id="batch-20261109-t004"></a>

冬十月朔，日有食之。不书日，官失之也。天子有日官，诸侯有日御。日官居卿以厎日，礼也。日御不失日，以授百官于朝。

<a id="batch-20261109-t005"></a>

初，郑伯将以高渠弥为卿，昭公恶之，固谏不听。昭公立，惧其杀己也。辛卯，弑昭公而立公子亹。君子谓昭公知所恶矣。公子达曰：“高伯其为戮乎，复恶已甚矣。”

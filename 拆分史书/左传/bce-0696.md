## 经

<a id="batch-20261109-j001"></a>

十有六年春正月，公会宋公、蔡侯、卫侯于曹。

<a id="batch-20261109-j002"></a>

夏四月，公会宋公、卫侯、陈侯、蔡侯伐郑。

<a id="batch-20261109-j003"></a>

秋七月，公至自伐郑。

<a id="batch-20261109-j004"></a>

冬，城向。

<a id="batch-20261109-j005"></a>

十有一月，卫侯朔出奔齐。

<a id="zhuan"></a>

## 传

<a id="batch-20261109-t001"></a>

十六年春正月，会于曹，谋伐郑也。

<a id="batch-20261109-t002"></a>

夏，伐郑。

<a id="batch-20261109-t003"></a>

秋七月，公至自伐郑，以饮至之礼也。

<a id="batch-20261109-t004"></a>

冬，城向。书时也。

<a id="batch-20261109-t005"></a>

初，卫宣公烝于夷姜，生急子，属诸右公子。为之娶于齐而美，公取之，生寿及朔，属寿于左公子。夷姜缢。宣姜与公子朔构急子。公使诸齐，使盗待诸莘，将杀之。寿子告之，使行。不可，曰：“弃父之命，恶用子矣！有无父之国则可也。”及行，饮以酒。寿子载其旌以先，盗杀之。急子至，曰：“我之求也。此何罪？请杀我乎！”又杀之。二公子故怨惠公。十一月，左公子洩、右公子职立公子黔牟。惠公奔齐。

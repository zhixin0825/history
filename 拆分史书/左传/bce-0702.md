## 经

<a id="all-20261109-j001"></a>

十年春，王正月庚申，曹伯终生卒。

<a id="all-20261109-j002"></a>

夏五月，葬曹桓公。

<a id="all-20261109-j003"></a>

秋，公会卫侯于桃丘，弗遇。

<a id="all-20261109-j004"></a>

冬十有二月丙午，齐侯、卫侯、郑伯来战于郎。

## 传

<a id="all-20261109-t001"></a>

十年春，曹桓公卒。

<a id="all-20261109-t002"></a>

虢仲谮其大夫詹父于王。詹父有辞，以王师伐虢。夏，虢公出奔虞。

<a id="all-20261109-t003"></a>

秋，秦人纳芮伯万于芮。

<a id="all-20261109-t004"></a>

初，虞叔有玉，虞公求旃，弗献。既而悔之，曰：“周谚有之：‘匹夫无罪，怀璧其罪。’吾焉用此，其以贾害也。”乃献之。又求其宝剑。叔曰：“是无厌也。无厌，将及我。”遂伐虞公，故虞公出奔共池。

<a id="all-20261109-t005"></a>

冬，齐、卫、郑来战于郎，我有辞也。初，北戎病齐，诸侯救之，郑公子忽有功焉。齐人饩诸侯，使鲁次之。鲁以周班后郑。郑人怒，请师于齐。齐人以卫师助之，故不称侵伐。先书齐、卫，王爵也。

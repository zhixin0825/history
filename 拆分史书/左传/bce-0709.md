## 经

<a id="all-20261109-j001"></a>

三年春正月，公会齐侯于嬴。

<a id="all-20261109-j002"></a>

夏，齐侯、卫侯胥命于蒲。

<a id="all-20261109-j003"></a>

六月，公会杞侯于郕。

<a id="all-20261109-j004"></a>

秋七月壬辰朔，日有食之，既。

<a id="all-20261109-j005"></a>

公子翚如齐逆女。

<a id="all-20261109-j006"></a>

九月，齐侯送姜氏于讙。公会齐侯于讙。夫人姜氏至自齐。

<a id="all-20261109-j007"></a>

冬，齐侯使其弟年来聘。

<a id="all-20261109-j008"></a>

有年。

<a id="zhuan"></a>

## 传

<a id="all-20261109-t001"></a>

三年春，曲沃武公伐翼，次于陉庭。韩万御戎，梁弘为右，逐翼侯于汾隰，骖絓而止。夜获之，及栾共叔。

<a id="all-20261109-t002"></a>

会于嬴，成昏于齐也。

<a id="all-20261109-t003"></a>

夏，齐侯、卫侯胥命于蒲，不盟也。

<a id="all-20261109-t004"></a>

公会杞侯于郕，杞求成也。

<a id="all-20261109-t005"></a>

秋，公子翚如齐逆女。修先君之好，故曰公子。齐侯送姜氏，非礼也。凡公女嫁于敌国，姊妹则上卿送之，以礼于先君；公子则下卿送之；于大国，虽公子亦上卿送之；于天子，则诸卿皆行，公不自送；于小国，则上大夫送之。

<a id="all-20261109-t006"></a>

冬，齐仲年来聘，致夫人也。

<a id="all-20261109-t007"></a>

芮伯万之母芮姜恶芮伯之多宠人也，故逐之，出居于魏。

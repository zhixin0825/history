## 卷一的阅读范围

确定年份的史事已并入原有年页，包括前206年司马卬封王、前205年置河内、179年司马懿出生（据251年享年推算），以及201—251年间相关年份和264、265年的追尊。世系、未确年迁官、屯田建议、关羽败后迁民之议、边户隐实、遗制和跨代评论见[未确年材料与跨代评论](../../years/ce-0201-0300/时期-晋书卷001-宣帝纪纪年待考.md)。各段仍可返回本卷对应L锚点，书信、诏奏和对话全文连续收读。

本卷依据仓内转录本与《三国志》正文、裴注、《资治通鉴》及其注文核对。未将原书人物评价、祥瑞、梦兆或政治指控写成已获各书共同证实的事实；尚存异说在同号史料中保留。本次对照复核同时检查逐事白话、原文去向和同号史料；不把仅有原文链接视为白话已完整，也不表示所有古籍争议均已有定论。

## 卷一的阅读范围

确定年份的史事已并入原有年页，覆盖201—251年间相关年份，以及264、265年的追尊。世系、未确年迁官、屯田建议、关羽败后迁民之议、边户隐实、遗制和跨代评论见[未确年材料与跨代评论](../../years/ce-0201-0300/时期-晋书卷001-宣帝纪纪年待考.md)。各段仍可返回本卷对应L锚点，书信、诏奏和对话全文连续收读。

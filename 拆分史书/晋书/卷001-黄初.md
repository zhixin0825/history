# 《晋书》卷001：黄初段原文摘录

[史料总目录](../../史书/README.md) · [全卷编年入口](README.md)

本文件只保存实际引用的原文，不构成另一套编年正文。对应《晋书》卷一《帝纪第一·宣帝》，从“黄初二年”至“迁骠骑将军”。原文中的“帝”指司马懿，“天子”主要指曹丕；不得因此把司马懿写成本时在位的皇帝。

**核对来源：** [仓内CCDH转录本《晋书》卷001](卷001.md#text)。本页保留早期摘录的字形与标点，完整原段以全卷读本及其所指年页为准；正文另作白话叙述。本次未逐页校勘中华书局扫描本，不把网络转录冒称点校本原页。仓库完整TXT仍保留在[二十四史原文目录](../../史书/005-晋书/晋书-CCDH.txt)。古籍原文属公有领域，现代校刊附记未混入以下引文。

## HC02｜黄初五年留镇许昌

> 五年，天子南巡，觀兵吳疆。帝留鎮許昌，改封向鄉侯，轉撫軍、假節，領兵五千，加給事中、錄尚書事。帝固辭。天子曰：「吾於庶事，以夜繼晝，無須臾寧息。此非以為榮，乃分憂耳。」

[回读224年留镇许昌](../../years/ce-0201-0300/ce-0224.md#jin001-l14)

<a id="hc03"></a>
## HC03｜黄初六年留守及南征还朝

> 六年，天子復大興舟師征吳，復命帝居守，內鎮百姓，外供軍資。臨行，詔曰：「吾深以後事為念，故以委卿。曹參雖有戰功，而蕭何為重。使吾無西顧之憂，不亦可乎！」天子自廣陵還洛陽，詔帝曰：「吾東，撫軍當總西事；吾西，撫軍當總東事。」於是帝留鎮許昌。

#### 三个已经发现的编纂问题
<a id="kao-a8a8e206f6-36f68c383"></a>

##### 1. 魏国建立和太子中庶子任职
“魏国既建，迁太子中庶子”出现在“从讨张鲁”“从讨孙权”之后。《通鉴》和《三国志·武帝纪》同以建安十八年（213）为曹操封魏公、魏立社稷宗庙之年。《武帝纪》《文帝纪》另记曹丕建安二十二年（217）才被正式册立为魏太子。213年页以“魏国既建”为背景保留原段，任职及“四友”的起始年另待确证。[建安七页复核](#kao-f512ace202-f1b3b8954)

<a id="kao-a8a8e206f6-acaca555d"></a>

##### 2. 219年的劝曹操不迁都，不宜只写成司马懿一人之功
《晋书》卷一只让司马懿发言；《资治通鉴》则写“丞相军司马司马懿、西曹属蒋济言于操曰”，把司马懿和蒋济并列。

因此 [219年页](../../years/ce-0201-0300/ce-0219.md) 正文采用“司马懿、蒋济劝曹操”的写法，同时在史料说明里交代《晋书》的个人传记视角。

<a id="kao-a8a8e206f6-15bc6b61e"></a>

##### 3. 220年治丧，司马懿与司马孚的记载不能粗暴合并
《晋书》卷一说司马懿“纲纪丧事，内外肃然，乃奉梓宫还邺”；《通鉴》在邺城继承危机的段落中，却明确写司马孚整顿群臣、禁卫并“治丧事”。

这可能是两人负责了不同地点或不同环节，也可能反映材料取舍差异。现有编年并列记录，不把其中一条抹掉。

### 宣帝纪-未定年

<a id="kao-9716f431d7-6aca677a0"></a>

本节保留旧讨论锚点，完整白话及同号史料已集中到[未确年材料与跨代评论](../../years/ce-0201-0300/时期-晋书卷001-宣帝纪纪年待考.md)。证据不足的事件按时段阅读，不以转录段落的位置代替确年。

<a id="kao-9716f431d7-c640e1b03"></a>

#### 司马懿的早年经历与人物评价
《晋书》卷一先交代司马氏世系、司马懿为司马防第二子，又记杨俊在司马懿未满二十岁时称许他，崔琰也曾对司马朗说其弟“聪亮明允，刚断英特”。

这些材料能说明司马懿在201年正式进入可编年事件以前已经有士人声望，但本段没有分别给出确切年份。完整世系、早年品行与杨俊、崔琰的评价见[时期页第1条](../../years/ce-0201-0300/时期-晋书卷001-宣帝纪纪年待考.md#jin001-l4)，[201年](../../years/ce-0201-0300/ce-0201.md)仅将之作为征辟以前的背景互见。

原文：《晋书》卷一第4行（原始来源记录：`https://github.com/zhixin0825/history/blob/be6f5437767f09cd474107cefee81050d9d0605b/texts/05_jinshu_full.txt#L4`）。

<a id="kao-9716f431d7-38b9740af"></a>

#### 208年以后的一串升迁
《晋书》把“文学掾—黄门侍郎—议郎—丞相东曹属—主簿”连在同一段里，但没有给后四项逐一标年。

[208年](../../years/ce-0201-0300/ce-0208.md#jin001-l5)收文学掾任命；其余迁官按次序在[时期页第2条](../../years/ce-0201-0300/时期-晋书卷001-宣帝纪纪年待考.md#jin001-l5)叙明，不擅自分配到208—213年。

原文：《晋书》卷一第5行（原始来源记录：`https://github.com/zhixin0825/history/blob/be6f5437767f09cd474107cefee81050d9d0605b/texts/05_jinshu_full.txt#L5`）。

<a id="kao-9716f431d7-c99f7ca02"></a>

#### 军司马、屯田与边将判断
《晋书》记司马懿迁军司马后，建议“且耕且守”，曹操采纳；又说他曾认为荆州刺史胡修、南乡太守傅方不宜居边。到219年关羽围樊时，胡、傅果然投降。

问题是，这段只给出“后来在219年得到验证”的下限，没有告诉我们建议本身是哪一年提出。故：

- 胡修、傅方在219年投降，属于219年的确定事件；
- 司马懿此前的判断，只作为该事件背景；
- “且耕且守”的政策建议暂不定年。

原文：《晋书》卷一第8行（原始来源记录：`https://github.com/zhixin0825/history/blob/be6f5437767f09cd474107cefee81050d9d0605b/texts/05_jinshu_full.txt#L8`）。

<a id="kao-9716f431d7-66cdcd270"></a>

#### 关羽败后是否迁民
《晋书》紧接着记曹操想把荆州遗民及颍川屯田户内迁，司马懿反对，认为关羽刚败，此时迁走守法百姓反而让流亡者不敢回来；曹操听从，其后逃亡者复业。

从叙述位置看，它明显在关羽败亡以后，但当前段落没有独立年号。现归[时期页第5条](../../years/ce-0201-0300/时期-晋书卷001-宣帝纪纪年待考.md#jin001-l10)，说明219年末至220年曹操去世前的时间界限；暂不分入某一个单年。

原文：《晋书》卷一第10行（原始来源记录：`https://github.com/zhixin0825/history/blob/be6f5437767f09cd474107cefee81050d9d0605b/texts/05_jinshu_full.txt#L10`）。

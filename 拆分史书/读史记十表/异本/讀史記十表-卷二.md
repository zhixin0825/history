　　十二諸侯年表第二¶

<a id="L12"></a>

太史公讀春秋厯譜諜(索𨼆曰案劉杳云三代系表旁/行邪上並效周譜譜起周代藝)¶

<a id="L13"></a>

(文志有古帝王譜又自古為春秋學者有年厯譜諜/之說故杜元凱作春秋長厯及公子譜蓋因于舊說)至¶

<a id="L14"></a>

周厲王未嘗不廢書而歎也曰嗚呼師摯見之矣(鄭𤣥/曰魯)¶

<a id="L15"></a>

(太師摯識關雎之/聲首理其亂也)紂為象箸而箕子唏(索隠曰鄒氏及/劉氏箸皆音直)¶

<a id="L16"></a>

&lt;pb:KR2a0005_WYG_002-1b&gt;¶

<a id="L17"></a>

(慮反即筯也今案箕子云為象/箸必為玉杯則箸者是樽也)周道缺詩人本之袵席¶

<a id="L18"></a>

關雎作仁義陵遲鹿鳴刺焉及至厲王以惡聞其過公¶

<a id="L19"></a>

卿懼誅而禍作厲王遂奔于彘(索隠曰彘地名在河/東後為永安縣也)亂¶

<a id="L20"></a>

自京師始而共和行政焉是後或力政强乘弱興師不¶

<a id="L21"></a>

請天子然挾王室之義以討伐為會盟主政由五伯諸¶

<a id="L22"></a>

侯恣行淫侈不軌賊臣簒子滋起矣齊晉秦楚其在成¶

<a id="L23"></a>

周微甚封或百里或五十里晉阻三河齊負東海楚介¶

<a id="L24"></a>

江淮(索隠曰介音界言/楚以江淮為界)秦因雍州之固四國迭興更為¶

<a id="L25"></a>

&lt;pb:KR2a0005_WYG_002-2a&gt;¶

<a id="L26"></a>

伯主文武所褒大封皆威而服焉是以孔子明王道干¶

<a id="L27"></a>

七十餘君莫能用故西觀周室論史記舊聞興于魯而¶

<a id="L28"></a>

次春秋上記𨼆下至哀之獲麟約其辭文去其煩重(索/隠)¶

<a id="L29"></a>

(曰言約史記修春秋/去其重複之文也)以制義法王道備人事浹七十子¶

<a id="L30"></a>

之徒口受其𫝊指為有所刺譏褒諱挹損之文辭不可¶

<a id="L31"></a>

以書見也魯君子左丘明懼弟子人人異端各安其意¶

<a id="L32"></a>

失其真故因孔子史記叙論其語成左氏春秋鐸椒為¶

<a id="L33"></a>

楚威王傅為王不能盡觀春秋采取成敗卒四十章為¶

<a id="L34"></a>

&lt;pb:KR2a0005_WYG_002-2b&gt;¶

<a id="L35"></a>

鐸氏微(索隠曰鐸椒所撰名鐸氏微/者春秋有微婉之辭故也)趙孝成王時其相¶

<a id="L36"></a>

虞卿上采春秋下觀近世亦著八篇為虞氏春秋吕不¶

<a id="L37"></a>

韋者本莊襄王相亦上觀尚古刪拾春秋集六國時事¶

<a id="L38"></a>

以為八覽六論十二紀為吕氏春秋及如荀卿孟子公¶

<a id="L39"></a>

孫固韓非之徒各往往捃摭春秋之文以著書不可勝¶

<a id="L40"></a>

紀(索隠曰荀况孟軻韓非皆著書自稱子宋有/公孫固無所述此固蓋齊人韓固傳詩者也)漢相張¶

<a id="L41"></a>

蒼歴譜五徳(索隠曰按張蒼著/終始五徳傳也)上大夫董仲舒推春秋¶

<a id="L42"></a>

義頗著文焉(索隠曰作春秋繁露是○徐孚逺曰惟董/生所作推明春秋之指其餘雖沿其名自)¶

<a id="L43"></a>

&lt;pb:KR2a0005_WYG_002-3a&gt;¶

<a id="L44"></a>

(别記事不/屬春秋也)¶

<a id="L45"></a>

太史公曰儒者斷其義馳說者騁其辭不務綜其終始¶

<a id="L46"></a>

厯人取其年月數家(索隠曰謂隂陽/術數之家也)隆于神運譜諜獨¶

<a id="L47"></a>

記世諡其辭畧欲一觀諸要難于是譜十二諸侯自共¶

<a id="L48"></a>

和訖孔子表見春秋國語學者所譏盛衰大指著于篇¶

<a id="L219"></a>

　讀十二諸侯年表以周為主¶

<a id="L220"></a>

茅坤曰孔子作春秋而太史公得因之以表本末盛衰¶

<a id="L221"></a>

之迹也¶

<a id="L222"></a>

索隱云篇言十二實叙十三者賤夷狄不數吳又霸在¶

<a id="L223"></a>

後故也不數吳而叙之者闔閭霸盟上國故也¶

<a id="L224"></a>

蘇洵曰越不與中國㑹盟故不叙(有越世家而/不列于表)¶

<a id="L225"></a>

　按十二諸侯年表並與三代世表之末相接續魯始¶

<a id="L226"></a>

&lt;pb:KR2a0005_WYG_002-79b&gt;¶

<a id="L227"></a>

　真公齊始武公晉始靖侯秦始秦仲楚始熊勇宋始¶

<a id="L228"></a>

　釐公衛始釐侯陳始幽公蔡始武侯曹始夷伯燕始¶

<a id="L229"></a>

　惠侯皆所謂自共和也三代世表下十二國無鄭者¶

<a id="L230"></a>

　鄭至周宣王始封其母弟友也吳夀夢始見于周簡¶

<a id="L231"></a>

　王元年¶

<a id="L232"></a>

　冠周于上尊王室也書甲子于周之上紀天道也(共/和)¶

<a id="L233"></a>

　(元年庚申以/後但書六甲)表元年諸侯各以次相及詳厯數也書¶

<a id="L234"></a>

　孔子生尊聖人也書孔子去留悼道之不行也書諸¶

<a id="L235"></a>

&lt;pb:KR2a0005_WYG_002-80a&gt;¶

<a id="L237"></a>

<a id="L238"></a>

　也書弑逆臣明法也諸侯之事必舉其要謂春秋國¶
